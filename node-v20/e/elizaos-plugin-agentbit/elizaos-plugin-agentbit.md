# elizaos-plugin-agentbit

> 标签: agent, ai-agent, base, eliza, elizaos, mcp, onchain, plugin, router, usdc, x402

## 简介

elizaOS plugin for the AgentBIT Router — give your agent one action that runs any of 14,000+ x402 tools and returns the result. Pay-per-call in USDC on Base.
