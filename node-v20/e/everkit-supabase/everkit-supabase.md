# everkit-supabase

> 标签: auth, expo, profiles, react-native, secure-store, supabase

## 简介

Reusable, app-agnostic Supabase foundation for React Native / Expo apps: a client factory, an auth gate, and a canonical profiles model. Each app injects its own config.
