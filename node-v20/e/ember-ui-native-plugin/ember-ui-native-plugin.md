# ember-ui-native-plugin

> 标签: android, config-plugin, expo, ios, ui

## 简介

Expo config plugin for Ember UI-native bridges: scoped contact picker, native alerts, prompts and sharing, Android dynamic color and system bars, and iOS Liquid Glass.
