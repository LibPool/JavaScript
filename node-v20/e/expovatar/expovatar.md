# expovatar

> 标签: avatar, deterministic, dither, expo, gradient, halftone, identicon, jazzicon, react-native, skia, wallet, web3

## 简介

Deterministic avatars from any string for React Native + Expo — gradient & dither, Skia-rendered. A port of hashvatar.
