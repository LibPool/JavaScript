# ember-oauther

> 标签: auth, authenticator, ember-addon, oauth, oauth 1.0a, oauth 2.0

## 简介

Ember OAuther is a set of providers and routers to connect OAuth 1.0a and OAuth 2.0 services like facebook, google etc.
