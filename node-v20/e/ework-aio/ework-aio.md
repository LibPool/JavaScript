# ework-aio

> 标签: ai-agent, ework, installer, issue-tracker, opencode, self-hosted

## 简介

All-in-one installer for ework (issue tracker) + ework-daemon (AI bridge) + opencode-ework (plugin). One command: npm i -g ework-aio && ework-aio install.
