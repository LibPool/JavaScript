# eslint-plugin-pet-peeves

> 标签: code-style, complexity, eslint, eslint-plugin, eslintplugin, jsx, logical-expression, opinionated, react, readability

## 简介

Opinionated ESLint rules for JavaScript and JSX readability — limit long &&/||/?? expressions, pad large JSX siblings, and keep internal modules from re-exporting.
