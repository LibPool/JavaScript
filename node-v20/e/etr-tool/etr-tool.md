# etr-tool

> 标签: JavaScript

## 简介

etr即为easy-test-redux,顾名思义就是用来轻松测试react+redux项目       众所周知,redux采用的是函数式编程思想,action+reducer的架构,       可以让我们轻松实现应用状态的管理,也就可以轻松实现redux的单元测试       但是集成测试还是需要我们手动写很多的测试案例,因此etr就是为了方便开发人员做**集成测试**而生的
