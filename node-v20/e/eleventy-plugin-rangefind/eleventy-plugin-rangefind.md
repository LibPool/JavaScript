# eleventy-plugin-rangefind

> 标签: eleventy, eleventy-plugin, range-requests, rangefind, search, static-search

## 简介

Eleventy plugin that indexes your built site with Rangefind (static index + HTTP Range requests, no search server) and drops in the search Web Component.

- 官网：https://rangefind.dev/docs/plugins/
