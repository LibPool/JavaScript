# ephor-gate

> 标签: ai-agents, audit, governance, human-in-the-loop, mcp

## 简介

Ephor gate — the identity & policy layer for AI agents. Standard MCP gateway (stdio + HTTP): every agent action risk-scored, policy-checked, human-approved when it matters, and recorded in a tamper-evident audit chain. https://ephor.dev
