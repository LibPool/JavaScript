# ejsinbrowser

> 标签: JavaScript

## 简介

Packages ejs templates as external javascript so they can be rendered in the browser without runtime. By Harald Rudell.

## 官网

- 源码仓库：git://github.com/haraldrudell/ejsinbrowser.git
- npm 页面：https://www.npmjs.com/package/ejsinbrowser
