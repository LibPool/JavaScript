# excel-processing

> 标签: Excel, Excel处理, excel, 生成excel模板, 表格处理

## 简介

这是一个用来处理Excel文件的包 内置两个方法 1.下载Excel的模板（自定义）2.解析Excel里面的数据（处理成数组和对象）
