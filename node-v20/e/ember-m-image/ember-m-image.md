# ember-m-image

> 标签: ember-addon, image-ajax-loader, image-error, image-fetch-loader, image-loader, image-loading, image-preloader

## 简介

A simple Ember addon to load the image through DOM or API approaches and display image's loading/error states using the same <img> tag
