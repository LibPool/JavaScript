# engagement-guard

> 标签: ai-agents, audit-log, authorization, claude-code, mcp, pentest, rules-of-engagement, scope, security

## 简介

Authorisation-bounded agent execution: an engagement file, a scope engine, a shell-command target extractor, a fail-closed decision matrix and a hash-chained audit log for AI agents that run security tools.
