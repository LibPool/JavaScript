# evidentia

> 标签: citation, crossref, doi, evidence-based-medicine, fact-check, hallucination, mcp, medical, openalex, pubmed

## 简介

Catch AI-fabricated medical citations before you publish. Verifies DOIs/PMIDs against CrossRef, PubMed, and OpenAlex; grades the result in a 4-tier classification. CLI + MCP server.
