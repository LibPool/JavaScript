# enmap-rethink

> 标签: JavaScript

## 简介

Enmap-Rethink is a provider for the [Enmap](https://www.npmjs.com/package/enmap) module. It enables the use of a persistent data structure using RethinkDB as a backend (well, `rethinkdbdash` really).
