# escorlib

> 标签: .net, dotnet, es6, escorlib, javascript, microsoft, mono, node

## 简介

EcmaScript6+ oriented implementations of Microsoft Common Object Runtime Library (mscorlib.dll), the primary assembly of the .NET Framework.
