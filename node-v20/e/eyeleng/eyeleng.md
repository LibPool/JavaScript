# eyeleng

> 标签: Datalog, RDF, RDF 1.2, SPARQL-RL, SRL, reasoner

## 简介

The EYE Logic Engine: a JavaScript implementation of SPARQL 1.2 RL (SRL) with RDF 1.2 input via rdf-parse.
