# electricblaze

> 标签: ai-agent, astro, claude-code, cli, codex, instagram, instagram-feed, nextjs, social-feed, tiktok, youtube

## 简介

Social feeds for AI-built sites. CLI: add an Instagram feed component with demo data, preview the feed as JSON, check the setup, install the agent skill. One schema for every source; TikTok and YouTube planned.
