# even-agent-home

> 标签: agent-home, agents, ai, bridge, claude, codex, even-realities, glasses, opencode

## 简介

Agent Home backend — HTTP bridge server that exposes multi-provider AI agents (Claude, Codex, OpenCode, Hermes, Antigravity, pi, oh-my-pi, openclaw) to the Agent Home glasses client.
