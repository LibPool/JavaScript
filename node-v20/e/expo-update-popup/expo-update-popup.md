# expo-update-popup

> 标签: eas, expo, expo-updates, ota, over-the-air, push, react-native, rollback, update

## 简介

In-app 'Update Now' popup + one-command OTA push (with archive & rollback) for Expo apps using expo-updates / EAS Update.
