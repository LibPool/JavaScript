# easy-language-model

> 标签: built-in-ai, gemini-nano, language-model, prompt-api, sanitizer, streaming-markdown

## 简介

A near drop-in wrapper for the Prompt API's LanguageModel with sanitized output, streaming HTML, session compacting, always-on download reporting, and user activation handling.
