# edhindex

> 标签: code-index, code-search, codebase-search, hybrid-search, knowledge-graph, local-first, mcp, offline, semantic-search, tree-sitter

## 简介

Local-first hybrid code search engine — 42 adapters, BM25 + vector + rerank, binary doc/image indexing, lazy background mode, MCP server
