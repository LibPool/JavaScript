# erc1155

> 标签: EIP1155, ERC1155, Ethereum, NFT

## 简介

an implementation of the ERC1155 token standard that fixes 2 issues with @openzeppelin's implementation. URI changes emit events, and the uri() function returns different values based on the passed token ID
