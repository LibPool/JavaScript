# easy-qaap1

> 标签: editor, email, email-editor, mjml

## 简介

This is a simple email editor built with React and Vite. It allows users to compose and send emails with various features such as drag-and-drop functionality, email templates, and a rich text editor. The project is designed to be easy to use and customize
