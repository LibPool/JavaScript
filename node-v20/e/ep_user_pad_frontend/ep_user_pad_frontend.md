# ep_user_pad_frontend

> 标签: etherpad-lite, group, group pads, user, user-management

## 简介

With the user_pad plugin it's possible to create password saved pads in groups. It's a User-Management System. It allows User to register, authenticate, to create groups and to create pads in groups. This package is the frontend part
