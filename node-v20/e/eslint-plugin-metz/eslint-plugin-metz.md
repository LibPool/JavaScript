# eslint-plugin-metz

> 标签: clean-code, eslint, eslint-plugin, eslintplugin, poodr, react, react-native, sandi-metz, typescript

## 简介

ESLint rules for Sandi Metz's rules: counted-line limits, parameter limits, one component per file, one view model per screen, and reasoned waivers.
