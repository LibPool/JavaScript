# ed25519-to-x25519.wasm

> 标签: crypto, curve25519, ed25519, emscripten, wasm, webassembly, x25519

## 简介

Library for Ed25519 signing key pair into X25519/Curve25519 key pair suitable for Diffie-Hellman key exchange
