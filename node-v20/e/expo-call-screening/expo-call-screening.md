# expo-call-screening

> 标签: call-directory, call-screening, caller-id, callkit, config-plugin, expo, expo-module, react-native

## 简介

Caller ID for Expo apps: register phone number / display name pairs with the iOS Call Directory Extension and the Android call screening service.
