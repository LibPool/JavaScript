# empire-memory-mcp

> 标签: agent-tooling, ai-agents, anthropic, claude, claude-code, knowledge-base, markdown, mcp, memory, model-context-protocol, rag

## 简介

An MCP server that exposes a flat directory of Markdown memory files to Claude Code (and any MCP client) via 5 read-only tools: list, get, search, list-wiki, get-wiki. Originally built for the Humanity Group empire memory store but agnostic to any Markdow
