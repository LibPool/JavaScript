# expose-to-window-plugin

> 标签: expose, plugin, webpack, window

## 简介

插件实现原由：webpack打包出来的bundle.js里面的代码都包裹在一个IIFE函数（闭包）里面，导致外面环境无法访问里面的变量和函数。
