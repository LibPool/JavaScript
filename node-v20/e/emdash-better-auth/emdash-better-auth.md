# emdash-better-auth

> 标签: astro, auth, authentication, better-auth, cloudflare, emdash, emdash-plugin, oauth

## 简介

Email/password + social (Google, GitHub) authentication for EmDash CMS, powered by Better Auth with prebuilt Better Auth UI sign-in/sign-up pages, mandatory email verification, and an admin settings page.
