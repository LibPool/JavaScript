# echarts.js

> 标签: canvas, chart, charts, echarts, graph, graphs, svg, vml, webpack

## 简介

Enterprise Charts, build for webpack. 基于Canvas，纯Javascript图表库，提供直观，生动，可交互，可个性化定制的数据可视化表。
