# excel-analyser-mcp

> 标签: MCP, analysis, chunks, csv, excel, json, nodejs, pagination, xlsx

## 简介

A Node.js tool to read and analyse Excel (.xlsx), CSV (.csv), and JSON (.json) files using MCP with automatic pagination support.
