# eslint-plugin-vue-html-format

> 标签: class, eslint, eslint-plugin, eslintplugin, format, html, normalize, sfc, style, template, vue, vue-eslint-parser, whitespace

## 简介

ESLint plugin to normalize whitespace in static Vue template attributes (class, style). Works with any ESLint + vue-eslint-parser setup.
