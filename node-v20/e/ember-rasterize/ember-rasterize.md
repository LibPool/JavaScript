# ember-rasterize

> 标签: HTML to image, SVG to image, ember rasterization, ember-addon, rasterization, rasterize, rasterize HTML, rasterize SVG, rasterize chart for PDF

## 简介

Rasterize HTML or SVG to an image in Ember. Useful for rendering HTML and SVG charts in PDFs.
