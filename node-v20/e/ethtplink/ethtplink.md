# ethtplink

> 标签: cli, ethereum, ethermine, hs100, hs110, iot, kasa, mining, smartplug, tplink

## 简介

node.js daemon to reboot mining rigs using TP-Link HS100/HS110 sockets in case of issues mining on ethermine.org
