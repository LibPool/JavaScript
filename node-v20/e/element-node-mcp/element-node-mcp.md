# element-node-mcp

> 标签: ai-agents, claude, cms, element-node, mcp, modelcontextprotocol

## 简介

Official MCP server for Element Node CMS — lets AI agents (Claude Code, Cursor, Windsurf…) build and manage Element Node sites via the REST API.
