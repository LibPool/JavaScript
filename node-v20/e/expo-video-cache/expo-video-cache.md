# expo-video-cache

> 标签: avplayer, cache, caching, expo, expo-av, expo-module, expo-video, expo-video-cache, hls, local-server, m3u8, media-cache, mp4, offline, offline-video, performance, prefetch, preload, proxy, react-native, react-native-video, streaming, video-cache

## 简介

High-performance video caching for expo-video, react-native-video and React Native. Features a local proxy for instant HLS (.m3u8), offline support, prefetching, and advanced cache management.
