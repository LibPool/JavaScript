# emojifyi

> 标签: codepoint, css, emoji, encoding, html, metadata, search, surrogate-pairs, unicode, utf16, utf8, zwj

## 简介

Pure TypeScript emoji toolkit -- encoding, lookup, search for 3,781 emojis from Unicode Emoji 16.0. Zero dependencies.
