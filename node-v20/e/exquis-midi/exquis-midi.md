# exquis-midi

> 标签: exquis, hex-grid, intuitive-instruments, isomorphic-keyboard, microtonal, midi, mpe, sysex, web-midi

## 简介

Full-control TypeScript library for the Intuitive Instruments Exquis MPE controller (LEDs, input, microtonal layouts) over its Developer Mode MIDI API. Works in Node and the browser.
