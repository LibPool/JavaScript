# eslint-plugin-import-fsd

> 标签: architecture, boundaries, eslint, eslint-plugin, eslintplugin, feature-sliced, feature-sliced-design, fsd, hierarchy, import, infrastructure, layers, lint

## 简介

A smart ESLint plugin that helps you enforce and maintain Feature-Sliced Design (FSD) architecture. Automatically validates layer hierarchy and import boundaries to prevent architectural leaks.
