# enhanced-k-grid

> 标签: JavaScript

## 简介

The goal of this project was to create an excel like grid based on the existing kendo-grid. I didn't want to create a spreadsheet component, but a grid, which holds regular array data, which we can edit, select, copy, paste, with wich we can do calculatio
