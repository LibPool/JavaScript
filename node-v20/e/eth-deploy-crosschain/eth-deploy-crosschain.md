# eth-deploy-crosschain

> 标签: create1, deploy, ethereum, nicks method

## 简介

This library create a raw transaction to deploy contracts at the same address on different EVM chains. This method is known as [Nick's method](https://medium.com/@weka/how-to-send-ether-to-11-440-people-187e332566b7).
