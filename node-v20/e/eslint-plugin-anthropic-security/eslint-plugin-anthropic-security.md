# eslint-plugin-anthropic-security

> 标签: agents, ai-security, anthropic, anthropic-sdk, appsec, claude, claude-agent-sdk, code-quality, cwe, eslint, eslint-plugin, eslintplugin, interlace-security, linting, llm, llm-security, owasp, sast, security, static-analysis, typescript, vulnerability

## 简介

ESLint plugin for Anthropic SDK security — catches hardcoded Claude API keys, the browser escape hatch that ships them to every visitor, and system prompts assembled from untrusted input.
