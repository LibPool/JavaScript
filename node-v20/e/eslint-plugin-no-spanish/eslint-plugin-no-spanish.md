# eslint-plugin-no-spanish

> 标签: code-style, eslint, eslint-plugin, eslintplugin, i18n, localization, no-spanish, spanish

## 简介

ESLint rules that flag Spanish comments and Spanish variable/function/class names to keep language usage consistent in a JS/TS codebase.
