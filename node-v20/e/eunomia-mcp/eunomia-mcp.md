# eunomia-mcp

> 标签: ai-agent, mcp, model-context-protocol, soroban, spending-policy, stellar, treasury, x402

## 简介

MCP server + TypeScript SDK that lets any AI agent spend from a Eunomia treasury on Stellar — inside an owner-set on-chain budget, blocked by the contract when out of policy, with x402 payment requirements and owner-approved exceptions.
