# engram-walrus

> 标签: agent, ai, claude, cursor, llm, mcp, memory, model-context-protocol, sui, walrus

## 简介

Portable, verifiable memory for AI agents — an MCP server on Walrus. Personal & team scope, typed capture. Connect it to any AI: store a fact in one, recall it in another.
