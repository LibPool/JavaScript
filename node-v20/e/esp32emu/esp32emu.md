# esp32emu

> 标签: emulator, esp32, firmware, iot, microcontroller, simulator, wasm, xtensa

## 简介

Fast ESP32 (Xtensa LX6, dual-core) emulator — a WASM-compiled Xtensa core with native peripherals, runnable from Node.js and web workers.
