# erpspan

> 标签: accounting, api-client, dynamics-gp, econnect, erp, great-plains

## 简介

Typed TypeScript client for ERPSpan — the REST + MCP API for Microsoft Dynamics GP. Read and write customers, vendors, invoices, GL, and orders through a client generated from the OpenAPI spec.
