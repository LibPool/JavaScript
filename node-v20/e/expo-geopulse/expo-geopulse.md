# expo-geopulse

> 标签: ExpoGeopulse, expo, expo-geopulse, react-native

## 简介

Open-source background geolocation SDK for React Native + Expo (Android): fused location, Kalman sensor-fusion (C++/NDK), geofencing, battery-smart motion detection, offline sync.
