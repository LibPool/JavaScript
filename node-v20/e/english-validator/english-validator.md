# english-validator

> 标签: detector, english, is-english, language, language-detection, nlp, non-english, sentence-detection, text-analysis, typescript, validator

## 简介

Detect whether a sentence is English or non-English. Returns true/false with high accuracy using dictionary lookup and trigram analysis.
