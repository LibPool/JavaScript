# effect-playground

> 标签: course, effect, effect-ts, learning, playground, typescript

## 简介

Interactive course for Effect v4 (TypeScript): plain-English lessons, fix-the-code challenges, build-it problems, and recall cards, with real type checking and execution in the browser
