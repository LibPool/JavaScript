# extforge

> 标签: browser-extension, build-tool, bundler, chrome-extension, cli, cross-browser, edge-extension, esbuild, firefox-addon, hmr, hot-reload, manifest-v3, mv3, safari-extension, scaffold, webextension

## 简介

Lightning-fast browser extension build system with first-class HMR, interactive scaffolding, and cross-browser support (Chrome, Firefox, Safari, Edge — Manifest V3).
