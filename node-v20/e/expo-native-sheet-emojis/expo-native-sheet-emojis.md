# expo-native-sheet-emojis

> 标签: android, bottom-sheet, emoji, expo, input, ios, keyboard, native, picker, react-native

## 简介

A fully native emoji picker bottom sheet for React Native. Built with Swift and Kotlin for maximum performance. Features search with multilingual keywords, skin tones, frequently used tracking, theming, and configurable layout.
