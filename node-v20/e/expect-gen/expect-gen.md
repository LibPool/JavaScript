# expect-gen

> 标签: generator-testing, generators, redux-saga, redux-saga-testing, snapshot-testing, testing, testing-sagas, unit-testing

## 简介

Assertion library for unit testing JS generators. Works well with redux-saga. Allows snapshot testing.
