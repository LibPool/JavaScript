# ergonames

> 标签: blockchain, ergo, ergonames, naming, resolver, web3

## 简介

Resolve ErgoNames (~name) to Ergo addresses and back — via the ErgoNames API or directly from any Ergo node/explorer. Zero dependencies; browsers, Node 18+, and Bun.
