# eslint-plugin-auto-inferred-types

> 标签: auto-inferred-types, eslint, eslint-plugin, eslintplugin, typedef, typescript

## 简介

ESLint plugin that detects missing type annotations in TypeScript and autofixes them from the compiler's type inference, including auto-import of referenced types
