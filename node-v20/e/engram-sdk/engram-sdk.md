> 标签: agent-memory, agents, ai, claude, claude-code, consolidation, context-window, cursor, embeddings, engram, knowledge-graph, llm, mcp, memory, persistent-memory, rag, semantic-memory, sqlite, vector-search

## 简介

Semantic memory with knowledge graphs, consolidation, and spreading activation for AI agents. 80% LOCOMO accuracy vs 28.8% for file-based memory. MCP server included.
