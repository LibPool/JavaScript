# element-pages

> 标签: JavaScript

## 简介

vue@2.\*管理后台页面组件封装，依赖于`element-ui`二次封装；包括页面的顶部搜索、表格、分页。主要是用数据驱动的方式配置管理后台的基础页面。（对于自定义度较高的页面，不推荐使用）。
