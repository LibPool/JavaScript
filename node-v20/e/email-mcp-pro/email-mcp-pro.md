# email-mcp-pro

> 标签: 163-mail, auto-config, claude-desktop, email, email-client, email-server, enterprise-email, gmail, imap, imap-id, imapflow, mcp, model-context-protocol, netease-mail, nodejs, outlook, qq-mail, rfc-2971, smtp

## 简介

通用邮箱 MCP 服务器 - 基于 imapflow 重写 IMAP 实现，支持 IMAP ID 命令(RFC 2971)，完美兼容网易邮箱(163/126/yeah)，支持 QQ、Gmail、Outlook、企业邮箱等
