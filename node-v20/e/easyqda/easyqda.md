# easyqda

> 标签: content-analysis, csvqda, intercoder-reliability, officeqda, qda, qualitative-data-analysis, refi-qda, textqda

## 简介

easyQDA — qualitative data analysis in the editor you already use. This release ships the machine-readable easyQDA format contracts (officeQDA, textQDA, csvQDA); the full toolkit (CLI + desktop app) is in closed alpha and will be published under this name
