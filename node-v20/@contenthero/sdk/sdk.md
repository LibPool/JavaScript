# @contenthero/sdk

> 标签: ai, contenthero, generative-media, image-generation, sdk, text-to-speech, video-generation

## 简介

Official ContentHero SDK. Programmatic media generation (image, video, audio) on the ContentHero Studio API. The shared kernel the ContentHero MCP and CLI sit on.
