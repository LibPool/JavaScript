# @kilaslab/ccprovider

> 标签: anthropic, claude-code, cli, deepseek, glm, llm, mcp, openrouter, profiles, zai

## 简介

Provider profiles for Claude Code — run it against DeepSeek, OpenRouter, Kimi, GLM and other Anthropic-compatible endpoints, each with isolated session state and correct model tier mapping.
