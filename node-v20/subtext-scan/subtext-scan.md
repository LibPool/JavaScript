# subtext-scan

> 标签: ai-agents, document-ai, docx, hidden-text, html, indirect-prompt-injection, llm-security, mcp, pdf, prompt-injection, rag

## 简介

Catch the instructions hidden in a document before your agent follows them. Finds text a model reads but a person cannot see in PDF, DOCX and HTML (white-on-white, tiny, off-page, invisible render mode, hidden layers, covered text, metadata and annotation
