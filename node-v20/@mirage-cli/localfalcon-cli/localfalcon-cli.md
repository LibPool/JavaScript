# @mirage-cli/localfalcon-cli

> 标签: arp, atrp, cli, geo-grid, local-falcon, local-seo, localfalcon, mirage, rank-tracking, solv

## 简介

Local Falcon CLI — geo-grid rank tracking: locations, scan reports (ARP/ATRP/SoLV + map images), keyword rollups, and new scans. Mirage / Cloudflare-Worker compatible.
