# @qkix/chartkit-vue-renderer

> 标签: chart, chartkit, charts, nuxt, ssr, strapi, svg, vue, vue3, zero-js

## 简介

Vue 3 renderer for Chartkit charts - server-rendered SVG with zero client-side JavaScript, and the Better Blocks block plugin that draws a chart inside a document
