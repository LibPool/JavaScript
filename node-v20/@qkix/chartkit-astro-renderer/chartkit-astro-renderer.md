# @qkix/chartkit-astro-renderer

> 标签: astro, chart, chartkit, charts, ssr, strapi, svg, zero-js

## 简介

Astro renderer for Chartkit charts - server-rendered SVG with zero client-side JavaScript, and the Better Blocks block plugin that draws a chart inside a document
