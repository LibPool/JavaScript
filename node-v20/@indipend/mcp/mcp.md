# @indipend/mcp

> 标签: JavaScript

## 简介

Model Context Protocol server for Indipend — multi-business SaaS for Vietnamese SMBs. 37 tools, 3 prompts, 1 resource over stdio. Local PAT-based auth (no network credentials).
