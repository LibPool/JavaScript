# @craftedxp/sdk-node

> 标签: agent, api-client, sdk, voice, voice-ai

## 简介

Node.js / TypeScript SDK for the voice agent platform. Server-side API client — mint call tokens, manage agents, query calls, upload knowledge-base docs.
