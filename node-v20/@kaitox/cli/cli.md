# @kaitox/cli

> 标签: article, cli, kaitox, markdown, publishing, twitter, x

## 简介

The kaitox command line — CLI product of the Kaitox personal toolkit. Current feature: style-check, bundle and deliver local Markdown to the local relay as X (Twitter) Article drafts (kaitox x push).
