# @kaitox/x-article

> 标签: article, content-state, draft-js, kaitox, markdown, publishing, twitter, x

## 简介

Publish Markdown as X (Twitter) Article drafts: Markdown → content_state converter, X private-API client, end-to-end publish orchestration, and an X-friendliness style checker. Works in browsers (same-origin) and Node.
