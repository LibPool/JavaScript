# tripwires

> 标签: agent-safety, ai-agents, claude-code, codex, coding-agent, guardrails, hooks, pretooluse

## 简介

Turn the mistakes your coding agent keeps repeating into guardrails that fire before the tool runs. PreToolUse hooks for Claude Code and Codex CLI, with the incident, the fix, a test and a weekly verdict attached to every rule.
