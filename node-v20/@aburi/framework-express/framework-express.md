# @aburi/framework-express

> 标签: JavaScript

## 简介

Aburi Express framework plugin: recognizes Express Router instances, route handlers (get/post/put/patch/delete/all), middleware (arity-3), error middleware (arity-4), and mount points (app.use('/prefix', router)) — emitting framework:express:* extKinds
