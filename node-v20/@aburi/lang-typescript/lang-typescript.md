# @aburi/lang-typescript

> 标签: JavaScript

## 简介

Aburi TypeScript / TSX language plugin: tree-sitter WASM-based parseFile / extractSymbols / walkBody / normalizeAst, JSDoc-aware Signature + throws extraction, decorator + drop-hint contract, Category B / C drop rules per the drop-list design
