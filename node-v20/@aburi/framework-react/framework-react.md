# @aburi/framework-react

> 标签: JavaScript

## 简介

Aburi React framework plugin: recognizes React function components, custom hooks, contexts, forwardRef / memo wrappers, context providers, and higher-order components across .tsx / .jsx sources — emitting framework:react:* extKinds
