# @reputify/sdk

> 标签: api, reputation, reputify, reviews, sdk, trustscore

## 简介

JavaScript/TypeScript client for the Reputify API (api.reputify.io): reviews, scores, surveys, invitations, embeds, OAuth and webhook verification.

- 官网：https://api.reputify.io/

- npm 页面：https://www.npmjs.com/package/@reputify/sdk
