# @react-input-validator/rules-file

> 标签: form, input, react, react-native, validation, validator

## 简介

The validation rule objects to validate file input. It can used by `@react-input-validator/web` package. It can also used by `@react-input-validator/native` package which is utilized by RN app whose an appropriate input component.
