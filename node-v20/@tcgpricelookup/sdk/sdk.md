## 简介

Official JavaScript / TypeScript SDK for the TCG Price Lookup API — live trading card prices for Pokemon, MTG, Yu-Gi-Oh!, One Piece, Lorcana, Star Wars: Unlimited, Flesh and Blood, and Pokemon Japan.
