# @faqir-ui/mcp

> 标签: agent-native, claude, cursor, faqir, mcp, model-context-protocol, stdio, ui

## 简介

Faqir UI MCP server — a stdio Model Context Protocol server exposing the Faqir registry, manifests, themes, and project context to any MCP host (Claude Code, Cursor, …). Wraps the same TypeScript internals as the CLI.
