# @hyperscroll/core

> 标签: chat, chat-history, dynamic-height, infinite-list, infinite-scroll, log-viewer, performance, virtual-list, virtual-scroll, virtualization, windowing, zero-dependency

## 简介

Anchor-driven virtualization engine for 10M+ dynamic-height items in a single scroll view. Zero dependencies, framework-agnostic, CSS/Tailwind compatible.
