# @silasch/sentry-edge

> 标签: deno, edge-function, error-reporting, sentry, supabase

## 简介

Minimal HTTP-only Sentry integration for Deno Supabase Edge Functions (no SDK dep). Pure-TS payload builders + Deno I/O wrapper. PII scrubbing baked in.
