# @kody-ade/brain

> 标签: JavaScript

## 简介

Kody Brain control plane — brain store/runtime/image management, service resolver, terminal connect decision, brain-proxy chat backend, API route handlers. Depends on terminal + fly (one direction); hosts wire registerBrainHostHooks() in instrumentation.t
