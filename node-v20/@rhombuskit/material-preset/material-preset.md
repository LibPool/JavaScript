# @rhombuskit/material-preset

> 标签: angular, angular-material, design-tokens, material-design, rhombuskit, scss, theming

## 简介

SCSS bridge mapping Angular Material's M3 system tokens (--mat-sys-*) onto the RhombusKit token contract, so Material components follow the active theme.
