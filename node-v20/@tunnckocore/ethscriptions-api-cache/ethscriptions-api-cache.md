# @tunnckocore/ethscriptions-api-cache

> 标签: JavaScript

## 简介

Ethscriptions API Cache Proxy. A Cloudflare Worker that caches and unifies Ethscriptions (or any other) API's responses, according to ESIP-9. Includes support for resolving ENS on-chain / off-chain names, and Ethscriptions names.
