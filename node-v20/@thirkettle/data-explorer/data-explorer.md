# @thirkettle/data-explorer

> 标签: accessible, explorer, graph, pixi, pixijs, react, tree, visualisation, zoomable

## 简介

A continuous zoomable explorer for any tree- or graph-shaped data, drawn with PixiJS behind an accessible outline.
