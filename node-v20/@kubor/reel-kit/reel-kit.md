# @kubor/reel-kit

> 标签: cli, content-creation, ffmpeg, short-video, tts, vertical-video, video, video-generation

## 简介

竖版短视频合成工作台 —— 素材 + 逐句文案 + BGM，套模板出片。把一次性的 ffmpeg 命令固化成可复用流程。
