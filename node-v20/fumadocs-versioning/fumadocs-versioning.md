# fumadocs-versioning

> 标签: documentation, docusaurus, fumadocs, nextjs, versioned-docs, versioning

## 简介

Docusaurus-style versioned docs for Fumadocs: a snapshot CLI, versions.json, /docs/next, a version dropdown that keeps your page, and version banners
