> 标签: audit, cd, ci, ci-cd, cli, crawler, health-score, pipeline, pixyscan, scan, seo

## 简介

SEO health-score scans for PixyScan — a CLI and a typed Node.js API for running scans from CI/CD with a client secret and a branch.
