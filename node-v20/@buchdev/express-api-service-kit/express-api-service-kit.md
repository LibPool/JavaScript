# @buchdev/express-api-service-kit

> 标签: api, bootstrap, error-handler, express, health, idempotency, microservice, readiness, rest

## 简介

Express REST service bootstrap: createApp (JSON, /health, /ready, router mounting, centralized error handler) + HttpError + asyncHandler, with an optional Redis idempotency middleware.
