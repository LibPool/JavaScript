# @solvejet/whatsapp-cloud-api

> 标签: business-messaging, chatbot, cloud-api, graph-api, messaging, meta, nodejs, sdk, send-whatsapp-message, typescript, typescript-sdk, whatsapp, whatsapp-api, whatsapp-business, whatsapp-business-api, whatsapp-business-platform, whatsapp-cloud-api, whatsapp-sdk, whatsapp-templates, whatsapp-webhooks

## 简介

TypeScript SDK for the WhatsApp Cloud API (Meta WhatsApp Business Platform). Send WhatsApp messages, media, templates, and interactive messages, verify and parse webhooks, and manage phone numbers, WhatsApp Business Accounts (WABA), and message templates.
