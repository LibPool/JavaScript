# @vicimpa/rsp

> 标签: bindings, checkbox, computed, forms, frontend, inputs, preact, props, radio, react, react-component, react-hooks, react-library, react-signals, reactivity, signals, signals-react, state, ui

## 简介

A lightweight React layer for @preact/signals-react that lets you use signals as props and bind inputs, textareas, radios, and checkboxes without boilerplate.
