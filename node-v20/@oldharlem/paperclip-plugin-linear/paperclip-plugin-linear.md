# @oldharlem/paperclip-plugin-linear

> 标签: issue-tracker, linear, linear-app, paperclip, paperclip-plugin, paperclipai, sync

## 简介

Paperclip plugin that connects a Paperclip instance to a Linear workspace — issue sync, comments, status mirroring, webhooks, and an agent tool.
