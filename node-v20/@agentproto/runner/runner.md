# @agentproto/runner

> 标签: agentic, agentproto, aip-17, defineRunner, open-standard, runner

## 简介

@agentproto/runner — AIP-17 RUNNER.md reference implementation. A composable schema block defining the `runner` field — engine (in-process / subprocess / sandbox), optional container image, declarative dependency needs, and resource limits — reused by eve
