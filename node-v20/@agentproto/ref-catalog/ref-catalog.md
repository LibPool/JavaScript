# @agentproto/ref-catalog

> 标签: agentic, agentproto, aip-54, open-standard, ref, reference, registry

## 简介

@agentproto/ref-catalog — AIP-54 reference implementation. One typed, cross-AIP reference primitive: ArtifactRef ({aip, id, version}) + aip:// URI serialization, resolved through per-family AIP-43 registries joined by RefCatalog. One reference mechanism f
