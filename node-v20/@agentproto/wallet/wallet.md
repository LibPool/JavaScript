# @agentproto/wallet

> 标签: agentic, agentproto, aip-49, erc-1400, erc-20, event-sourcing, ledger, open-standard, wallet

## 简介

@agentproto/wallet — AIP-49 principal-owned multi-asset wallet primitive. Assets declared ERC-20-style (ref/symbol/decimals/standard/peg/ruleSet) ⊃ partitions (ERC-1410 tranches) ⊃ lots. Event-sourced journal, restriction lattice (no-arbitrage convert), c
