# @agentproto/adapter-mastracode

> 标签: adapter, agent-cli, agentproto, aip-45, mastra, mastracode, print

## 简介

@agentproto/adapter-mastracode — AIP-45 AGENT-CLI adapter for Mastra Code. Spawns the documented headless CLI via `npx -y mastracode`; current Mastra Code does not expose a discoverable ACP subcommand.
