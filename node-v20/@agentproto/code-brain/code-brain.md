# @agentproto/code-brain

> 标签: agentic, agentproto, aip-14, aip-30, ask-codebase, code-brain, code-intelligence, open-standard

## 简介

Pure, backend-agnostic code-intelligence contract (ICodeBrainProvider) + the AIP-14 `ask_codebase` tool, its AIP-30 builtin provider, and AIP-29/31/32 surface projections. Names no code-intelligence engine — a backend is injected via the tool context.
