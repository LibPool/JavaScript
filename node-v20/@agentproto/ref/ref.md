# @agentproto/ref

> 标签: agentic, agentproto, agentref, aip-27, aip-54, open-standard, pointer, ref, reference, registry

## 简介

AIP-54 REF reference implementation — one package, two schemes. The canonical cross-AIP artifact reference: ArtifactRef ({aip, id, version}) + aip:// URI serialization, resolved through per-family AIP-43 registries joined by RefCatalog. Also ships the sup
