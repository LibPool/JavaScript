# @agentproto/adapter-codex

> 标签: acp, adapter, agent-cli, agentproto, aip-45, codex, openai

## 简介

@agentproto/adapter-codex — AIP-45 AGENT-CLI adapter for OpenAI's Codex CLI via @agentclientprotocol/codex-acp. Spawns the ACP wrapper over stdio JSON-RPC.
