# @agentproto/adapter-opencode

> 标签: acp, adapter, agent-cli, agentproto, aip-45, opencode, sst

## 简介

@agentproto/adapter-opencode — AIP-45 AGENT-CLI adapter for sst/opencode. Spawns `opencode acp` (via npx -y opencode-ai) and drives OpenCode as an agentproto agent CLI over stdio JSON-RPC.
