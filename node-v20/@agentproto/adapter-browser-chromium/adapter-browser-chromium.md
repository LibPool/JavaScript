# @agentproto/adapter-browser-chromium

> 标签: agentproto, browser, cdp, chromium, playwright, provider

## 简介

Chromium browser provider for agentproto: a defineBrowser provider that launches Playwright's Chromium on a dedicated profile dir, with an idempotent launch, CDP access and a BrowserDriver.
