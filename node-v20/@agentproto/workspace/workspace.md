# @agentproto/workspace

> 标签: agentic, agentproto, aip-34, defineWorkspace, open-standard, workspace

## 简介

@agentproto/workspace — AIP-34 WORKSPACE.md reference implementation. A markdown + frontmatter format for declaring a workspace's identity — globally addressable id, owner, storage choice, defaults, publish posture. The root manifest of every AIP-organize
