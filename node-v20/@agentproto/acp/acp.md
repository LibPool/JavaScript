# @agentproto/acp

> 标签: acp, agent-client-protocol, agentic, agentproto, aip-44, defineAcp, open-standard

## 简介

@agentproto/acp — AIP-44 ACP.md reference implementation. An agentproto profile of the Agent Client Protocol (agentclientprotocol.com). Wraps @agentclientprotocol/sdk with createAcpClient (drives subprocess agents) and createAcpServer (exposes AIP-9 opera
