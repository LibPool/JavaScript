# @agentproto/driver-cli

> 标签: agentproto, aip-29, cli, provider, subprocess

## 简介

agentproto/cli-runtime — AIP-29 CLI provider specialisation. Sugar over @agentproto/driver for command-line binaries: argv templating, subprocess invocation, exit-code mapping, output parsing. v0.1 ships subprocess invocation; OS-level sandbox enforcement
