# @magpieloans/magpie-agent

> 标签: agent-sdk, ai-agents, borrow, defi, lending, magpie, sdk, solana, x402

## 简介

TypeScript SDK for Magpie x402 — the first x402-native permissionless lending protocol on Solana. Agents borrow, lend, liquidate, and post conditional intents in one line of code.
