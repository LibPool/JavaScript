> 标签: airtime, api, data, esim, gsubz, nigeria, sdk, sms, vtu

## 简介

Unofficial TypeScript/JavaScript SDK for the GSUBZ API — airtime, data, cable TV, electricity, exam pins, social media, eSIM, bulk SMS and wallet.
