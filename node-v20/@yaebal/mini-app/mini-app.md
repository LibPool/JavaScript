# @yaebal/mini-app

> 标签: ed25519, init-data, mini-app, telegram, telegram-bot, tma, web-app, webapp, yaebal

## 简介

yaebal mini-app — the Telegram Mini Apps server protocol: HMAC + Ed25519 (third-party) initData validation, a typed parser and test signer, an Authorization: tma header helper, answerWebAppQuery, and a WebAppInfo/deep-link url generator.
