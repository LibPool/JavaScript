# @yaebal/audit-log

> 标签: audit-log, logging, observability, telegram, telegram-bot, yaebal

## 简介

yaebal audit-log — correlated, redacted-by-default structured logging of incoming updates and outgoing api calls, with formatters, filters, sampling, and telegram-native sinks.
