# @yaebal/feature-flags

> 标签: ab-testing, feature-flags, growthbook, launchdarkly, rollout, telegram, telegram-bot, yaebal

## 简介

yaebal feature-flags — ctx.flags.isEnabled(key)/getVariant(key): typed boolean & A/B/n flags, telegram-native targeting, global overrides, guard/whenFlag, admin commands, and adapters for external providers (LaunchDarkly, GrowthBook, env).
