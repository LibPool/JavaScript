# @yaebal/preview

> 标签: chat, link-preview, mockup, preview, reactions, screenshot, svg, telegram, telegram-bot, yaebal

## 简介

yaebal preview — render a telegram-style chat (with reply/forward/reactions/link-preview, custom themes, and message grouping) from plain objects to an SVG string. zero deps, zero runtime.
