# @yaebal/analytics

> 标签: analytics, clickhouse, funnel, gdpr, plausible, posthog, sqlite, telegram, telegram-bot, yaebal

## 简介

yaebal analytics — typed ctx.track(event, properties) middleware with pluggable sinks (posthog, plausible, sqlite, clickhouse, http, console), privacy controls, auto-capture, and an in-chat admin surface.
