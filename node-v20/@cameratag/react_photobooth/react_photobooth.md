# @cameratag/react_photobooth

> 标签: cameratag, player, recorder, transcoding, upload, video, webrtc

## 简介

A React Component wrapping CameraTag's Photo Booth (<photobooth>). Allows users to snap or upload photos from your product using their webcam or mobile device. Requires a CameraTag account.
