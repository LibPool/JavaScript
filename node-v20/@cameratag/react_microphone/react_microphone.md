# @cameratag/react_microphone

> 标签: cameratag, player, recorder, transcoding, upload, video, webrtc

## 简介

A React Component wrapping CameraTag's audio recorder (<microphone>). Allows users to record or upload audio from your product using their webcam or mobile device. Requires a CameraTag account.
