# @lanlance/pi-multi-skill

> 标签: pi, pi-coding-agent, pi-package, skills, slash-command

## 简介

pi extension: stack multiple /skill:name references on leading lines of one message — each renders its own collapsible [skill] chip, remaining lines become the trailing message
