> 标签: ai-tools, blockchain, chatgpt, claude, claude-code, crypto, cursor, defi, gram, hermes, mcp, model-context-protocol, openapi, tegro, tegro-mcp, tegroton, the-open-network, ton, tonapi, toncoin, wallet, web3

## 简介

Read-only MCP server + OpenAPI for The Open Network (TON) and its native token GRAM (formerly Toncoin): balances, tokens, transactions, prices, NFTs, DNS. Works with Claude, Cursor, Claude Code, ChatGPT and Hermes Agent. No keys, no signing.
