# @opendeviceio/adapters

> 标签: adapter, av, cad, dxf, easyschematic, odio, opendeviceio

## 简介

Adapters that convert validated OpenDeviceIO (.odio.json) documents into design-tool import formats. EasySchematic, AutoCAD-DXF, is fully implemented; AVCAD is a registered stub.
