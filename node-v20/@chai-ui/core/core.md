# @chai-ui/core

> 标签: ai, ai-engine, ai-ui, chai-ui, design-system, fal, generative-ai, headless, openrouter, vercel-ai-gateway

## 简介

Chai UI headless core — the Request/Run/Result data model and pluggable generation engines (Fal.ai, OpenRouter, Vercel AI Gateway, mock). No framework, no rendering.
