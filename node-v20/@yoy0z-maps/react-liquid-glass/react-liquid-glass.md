# @yoy0z-maps/react-liquid-glass

> 标签: glassmorphism, liquid-glass, react, svg, ui

## 简介

A lightweight React component that recreates a **liquid glass / distorted edge** card using pure CSS + SVG filters.   You can freely control layout, motion, and drag — this component only focuses on the visual effect.
