# @assistant-ui/vite

> 标签: assistant-ui, generative, plugin, tanstack-start, use generative, vite

## 简介

Vite plugin for assistant-ui: the "use generative" directive compiler that colocates a tool's schema, server-only execute, and client-only render in one file. Works with Vite apps and TanStack Start.
