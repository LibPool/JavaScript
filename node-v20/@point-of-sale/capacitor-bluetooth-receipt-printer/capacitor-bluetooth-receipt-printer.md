# @point-of-sale/capacitor-bluetooth-receipt-printer

> 标签: bluetooth, capacitor, epson, escpos, receipt, receiptprinter, star

## 简介

This is an library that allows you to print to a Bluetooth connected receipt printer using WebBluetooth.
