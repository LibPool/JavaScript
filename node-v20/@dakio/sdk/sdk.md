# @dakio/sdk

> 标签: bangladesh, cod, dakio, ecommerce, headless, nextjs, react, storefront, webhooks

## 简介

Build any store on Dakio — catalog, sale prices, COD checkout with fake-order protection, couriers and Nova behind your own React or Next.js site.
