# @recode-software/cookidoo-api

> 标签: api, client, cookidoo, recipe, thermomix, tm6, tm7, vorwerk

## 简介

TypeScript client for the Cookidoo custom-recipes API (Thermomix). Browser OAuth login, CRUD, typed TTS/INGREDIENT annotation builders, and a Polish step-text parser.
