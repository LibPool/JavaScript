# @dsh-sparrow/dsh-file-manage

> 标签: JavaScript

## 简介

Manage DeepSeek Files API cloud files from the sidebar — list with cursor pagination, delete, and copy file_id (reuses the official DeepSeekFilesClient, no extra credentials)
