# @dsh-sparrow/dsh-chat-fim

> 标签: JavaScript

## 简介

Chat input suggestions via DeepSeek FIM completion (Beta) — a card suggests what you may type next, Tab adopts, Esc dismisses; trigger sensitivity adjustable (high/medium/low)
