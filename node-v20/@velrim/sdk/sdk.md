# @velrim/sdk

> 标签: confidence, data-extraction, document-extraction, json-schema, llm, ocr, pdf, structured-data, zod

## 简介

Official Velrim TypeScript SDK. Bring your own Zod schema; get back a parsed, typed object plus per-field state (present, null, missing) and source anchors. Ships the webhook signature verifier.
