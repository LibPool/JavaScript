# @velrim/langchain

> 标签: agent-tool, confidence, document-extraction, document-loader, json-schema, langchain, llm, pdf, structured-data, zod

## 简介

LangChain.js integration for the Velrim document-extraction API: a document loader that turns files into Documents with per-field state, confidence, and source anchors in metadata, plus an agent tool.
