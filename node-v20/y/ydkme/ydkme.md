# ydkme

> 标签: JavaScript

## 简介

Nodejs实现的一个临时邮件服务，当你需要在某些网站注册用户，但又不想透露自己的邮箱时，可以使用 ydkme 生成的临时的邮箱。ydkme 会在收到邮件时，自动生成邮箱。你可以通过邮箱的名称来命令 ydkme 如何处理收到的邮件。 :D
