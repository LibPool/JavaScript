# yanogen-ts

> 标签: client, generator, openapi, typescript, zod

## 简介

Generates fully-typed Zod v4 schemas and type-safe TypeScript REST API clients and server from OpenAPI 2.0, 3.0.x, and 3.1.x specifications.
