# ytdl-to-apple-music

> 标签: JavaScript

## 简介

Download a YouTube / YouTube Music playlist with yt-dlp, tag it, and import it into Apple Music via the hot folder.

## 官网

- npm 页面：https://www.npmjs.com/package/ytdl-to-apple-music

## 历史版本号

- 当前版本：0.1.0

- 0.0.0-stage
- 0.1.0

## 获取地址

- npm 安装：`npm install ytdl-to-apple-music`
- npm registry：https://registry.npmjs.org/ytdl-to-apple-music
- Node 要求：>=18.3
