# youtube-thumbnail-url

> 标签: image, maxresdefault, shorts, thumbnail, thumbnails, url, video, webp, youtube, ytimg

## 简介

Build every YouTube thumbnail URL (maxresdefault, sddefault, hqdefault, WebP, Shorts oar2) and resolve the largest one that really exists, with a fallback that checks HTTP status and real pixel width.
