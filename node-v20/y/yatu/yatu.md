# yatu

> 标签: JavaScript

## 简介

* 1、通过官网查看cookie * 2、设置环境变量 yaCookie 为 上一步的cookie (步骤1和步骤2 只要cookie不失效 可以一直用下去，否则要重新设置) * 3、开始压缩图片。 默认图片文件夹名称为 images 。执行命令 `yatu`。 如果你的图片文件夹名称是img1, 则执行 `yatu path=img1`
