# yt-dlp-ex-mcp

> 标签: dive, llm, mcp, youtube, yt-dlp

## 简介

An MCP server implementation that integrates with yt-dlp, providing video and audio content download capabilities (e.g. YouTube, Facebook, Tiktok, etc.) for LLMs.
