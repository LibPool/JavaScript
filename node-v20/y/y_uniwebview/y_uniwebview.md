# y_uniwebview

> 标签: postMessage, uniWebview, uniapp

## 简介

解决官方提供的uniWebview文件在uniapp项目打包后生成的H5页面引入uniWebview 后 uni对象会被覆盖导致postMessage等一系列方法不生效

## 官网

- npm 页面：https://www.npmjs.com/package/y_uniwebview

## 历史版本号

- 当前版本：1.0.0

- 1.0.0

## 获取地址

- npm 安装：`npm install y_uniwebview`
- npm registry：https://registry.npmjs.org/y_uniwebview
