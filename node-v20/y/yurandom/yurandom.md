# yurandom

> 标签: avatar, data generation, deterministic, mock, prng, procedural, random, rng, seed, seeded, shuffle, testing, uuid, xoroshiro

## 简介

Deterministic seed-based random generator using Xoroshiro128+. Useful for avatars, testing, procedural content, and more.
