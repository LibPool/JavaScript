# yume-dsl-rich-text

> 标签: ast, blog-engine, custom-markup, dsl, markdown-alternative, no-regex, parser, pluggable, recursive, rich-text, single-pass, tokenizer

## 简介

Single-pass recursive rich-text DSL parser without regex, with pluggable tag handlers. Markdown alternative.
