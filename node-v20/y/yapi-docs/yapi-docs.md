# yapi-docs

> 标签: agent, api-docs, llm, markdown, skill, yapi

## 简介

把 YApi 接口/项目链接一键转成 Markdown 接口文档（供 AI Agent 使用），npx 即用，一键安装为 Agent skill

## 官网

- npm 页面：https://www.npmjs.com/package/yapi-docs

## 历史版本号

- 当前版本：0.1.0

- 0.1.0

## 获取地址

- npm 安装：`npm install yapi-docs`
- npm registry：https://registry.npmjs.org/yapi-docs
- Node 要求：>=20
