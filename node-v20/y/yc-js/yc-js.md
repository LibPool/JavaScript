# yc-js

> 标签: JavaScript

## 简介

一些常用js组件，包括数组处理，Obj对象处理，url地址处理，str字符串处理，file文件处理，storage缓存处理，time时间处理，base64加密解密，md5加密，Area全国地区代码，Validate表单验证，Id唯一id生成等基础功能js插件
