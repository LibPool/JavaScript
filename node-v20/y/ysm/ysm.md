# ysm

> 标签: npm, registry, yarn

## 简介

Yarn registry manager can help you easy and fast switch between different npm registries, now include: cnpm, taobao, nj(nodejitsu), rednpm, edunpm

## 官网

- 官网：https://github.com/Retroxs/yrm#readme
- 源码仓库：git+ssh://git@github.com/Retroxs/yrm.git
- npm 页面：https://www.npmjs.com/package/ysm
