# yanzi-monaco-editor

> 标签: editor, emmet, monaco, yanzi, 代码高亮, 燕子编辑器

## 简介

这是一个基于微软的monaco和vue封装的一个代码编辑器，浏览器可运行。主要功能有:html、javascript、css代码编辑，高亮显示，语法错误提示等，可以帮您的项目很快的拥有一个web端的代码编辑器
