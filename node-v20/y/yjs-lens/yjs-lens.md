# yjs-lens

> 标签: collaborative-editing, convergence, crdt, debugging, local-first, yjs

## 简介

Verifies the convergence guarantee actually holds for a set of Yjs updates, and summarizes causal update history -- debugging tooling for Yjs beyond Y.logUpdate().
