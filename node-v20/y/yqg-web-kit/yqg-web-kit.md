# yqg-web-kit

> 标签: JavaScript

## 简介

一个支持跨框架的业务组件和SDK工具包，专为infra团队设计。提供基于Web Components的跨平台解决方案，支持Vue、React、Angular、原生JavaScript等任何现代前端框架。
