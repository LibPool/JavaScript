# youtube-search-api

> 标签: Youtube, api, channel, live, play, playlist, search, typescript, youtube, youtube playlist, youtube-api, youtube-search

## 简介

Node.js and TypeScript library to get YouTube search results with playlist by provided keywords, no Login or API key required!
