# yapi-plugin-intl-auto-test

> 标签: YAPI, auto test, elasticsearch, yapi-plugin

## 简介

YAPI自动化测试插件，支持在YAPI设置测试计划，历史测试结果存入ES,界面显示测试结果，自定义通知。
