# yolocard-sdk

> 标签: apdu, iso7816, smart-card, smartcard, webusb, yolocard

## 简介

WebUSB SDK for the YoloCard ISO 7816 device: a USB link layer, the raw APDU-line wire protocol, and ISO 7816-4 APDU/byte helpers
