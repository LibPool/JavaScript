# ydf-inference

> 标签: decision-forest, decision-tree, gradient-boosting, interpretable, machine-learning, random-forest, tabular-data, tensorflow-decision-forest, ydf

## 简介

With this package, you can generate predictions of machine learning models trained with YDF in browser and with NodeJS.
