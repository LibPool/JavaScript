# @modular-frontend/compositions-engine

> 标签: JavaScript

## 简介

Framework-neutral compositions engine: runtime, scoped stores, validation, authoring helpers, and types for arranging modules into named zones on a single screen. No UI-framework dependency — the outlet and hooks live in a binding package.
