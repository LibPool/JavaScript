# @aqua0/mcp

> 标签: 1inch, aqua0, arc, mcp, model-context-protocol, swapvm, the-graph

## 简介

Aqua0 MCP server: shared-liquidity FX strategies on 1inch Aqua and SwapVM, Arc Testnet, with The Graph reads. Stdio by default, prepare-only unless MCP_WRITE_MODE=execute.
