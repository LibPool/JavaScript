# crypto-pulse-mcp

> 标签: binance, bybit, claude, coingecko, crypto, defillama, mcp, model-context-protocol

## 简介

Read-only crypto market data for AI assistants over MCP: cross-exchange prices, funding and open interest, market overview, DeFi TVL and stablecoin flows. No API keys.
