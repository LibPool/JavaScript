# neyoframework

> 标签: forms, framework, hooks, lightweight, naira, nigeria, react-like, slow-network, state, ui, virtual-dom

## 简介

Tiny dependency-free framework for fast web apps on slow networks: React-style rendering, API cache and retry, state, forms, naira and Nigerian phone formatting.
