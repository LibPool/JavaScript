# @tanzhenxing/zx-barrage

> 标签: barrage, 弹幕效果的组件

## 简介

`zx-barrage` 是一个用于在 uniapp 应用中实现弹幕效果的组件，支持 H5、小程序和 App 端。它允许开发者轻松地在视频或其他内容区域展示滚动的评论性字幕。
