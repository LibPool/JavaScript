# @tanzhenxing/zx-login

> 标签: app, component, h5, login, miniprogram, mobile, uniapp, vue

## 简介

一个功能完整的登录组件，支持账号密码登录和手机验证码登录两种方式，兼容 H5、小程序和 App 平台
