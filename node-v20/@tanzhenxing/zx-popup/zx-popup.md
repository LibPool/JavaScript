# @tanzhenxing/zx-popup

> 标签: uni-app, zx-popup, 弹出层, 弹出层功能, 弹出层组件

## 简介

zx-popup 是一个功能完善的弹出层组件，支持多种弹出方式和动画效果。组件兼容 H5、小程序、App 等多个平台。
