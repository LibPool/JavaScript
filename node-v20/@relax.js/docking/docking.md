# @relax.js/docking

> 标签: custom-elements, docking, relaxjs, split-pane, tabs, web-components, workbench

## 简介

Native Web Components for docked app layouts: resizable split panes, a closable and draggable tab strip, an editor area of splittable tab groups, and an IDE-style workbench.
