# @zoijs/testing

> 标签: dom, fireEvent, no-build, no-jsx, render, test, testing, waitFor, zoijs

## 简介

Tiny first-party testing helpers for Zoijs: render, queries, fireEvent, waitFor — drive the real DOM. No custom renderer, no build step.
