# @adastracomputing/aer-emit

> 标签: aer, agent, event-sink, instrumentation, observability

## 简介

Shared best-effort AER emit core: an EventSink that lazily opens an AER session, batches events and completes on close. Fail-open, never throws. Used by aer-mcp-recorder and aer-hooks for consistent behavior.
