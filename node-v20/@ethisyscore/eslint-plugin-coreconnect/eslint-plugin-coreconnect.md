# @ethisyscore/eslint-plugin-coreconnect

> 标签: conventions, eslint, eslintplugin, ethisyscore, plugin

## 简介

ESLint rules enforcing EthisysCore plugin frontend conventions. Published so a new rule reaches every plugin on a version bump, rather than being copied into each scaffold and drifting.
