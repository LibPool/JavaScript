# @apitrail/core

> 标签: api-logger, apm, developer-tools, instrumentation, logger, middleware, monitoring, next, nextjs, observability, opentelemetry, otel, postgres, request-logger, self-hosted, supabase, telemetry, tracing, vercel

## 简介

Self-hosted request logging for Next.js. Capture every HTTP request with bodies, headers, and the full child-span waterfall — persisted to your own Postgres. The open-source alternative to Sentry & Datadog for API observability. Zero SaaS.
