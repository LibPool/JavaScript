# @ckeditor/ckeditor5-watchdog

> 标签: ckeditor, ckeditor 5, ckeditor5, ckeditor5-lib

## 简介

A watchdog feature for CKEditor 5 editors. It keeps a CKEditor 5 editor instance running.
