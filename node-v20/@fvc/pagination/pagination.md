# @fvc/pagination

> 标签: antd, design-system, fe-vis-core, fvc, pagination, react, react-component, ui

## 简介

`@fvc/pagination` wraps Ant Design's `Pagination` component with the AVIS UI design system styling. It exposes a clean, predictable React API that supports both controlled and uncontrolled usage while preserving antd's built-in accessibility and keyboard
