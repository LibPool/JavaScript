# @clipto/uploader

> 标签: browser, multipart, node, presigned-url, resumable, s3, typescript, upload

## 简介

S3 预签名直传上传器:分片 + 断点续传 + 实时网速,Node/浏览器双端通用,AK/SK 由服务端维护
