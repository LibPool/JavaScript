# @alana-aomt/live-md

> 标签: cli, katex, live-reload, markdown, mermaid, presentation, preview, viewer

## 简介

Servidor local com hot-reload para navegar e visualizar Markdown de qualquer pasta. Também disponível como app web estática (File System Access API).
