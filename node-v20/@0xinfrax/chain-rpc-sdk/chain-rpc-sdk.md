# @0xinfrax/chain-rpc-sdk

> 标签: broadcast, chain-rpc, gateway, infrax, rpc, subscription

## 简介

InfraX Chain RPC SDK — thin wrapper over @0xinfrax/infrax-dk exposing the chain-rpc gateway surface (read /v1/rpc/:chain, broadcast /v1/broadcast/:chain with independent broadcast key, status/health + MQ-16 subscription plans). Same-source, synced release
