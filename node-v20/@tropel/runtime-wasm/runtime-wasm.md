# @tropel/runtime-wasm

> 标签: k6, load-testing, postman, tropel, wasi, wasm, webassembly

## 简介

Browser/Node host for the tropel load-testing runtime compiled to wasm32-wasip1: postcard C ABI driver, WASI preview1 wiring, and the HTTP bridge that answers each request the runtime makes.
