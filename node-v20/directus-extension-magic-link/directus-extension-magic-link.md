# directus-extension-magic-link

> 标签: directus, directus-extension, directus-extension-bundle, magic-link, passwordless

## 简介

Passwordless magic-link login for Directus that follows the core login rules (user status, provider, 2FA, sessions), with Liquid email templates and pluggable validation.
