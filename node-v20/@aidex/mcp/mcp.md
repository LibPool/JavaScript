# @aidex/mcp

> 标签: ai, mcp, model-context-protocol, server, transport

## 简介

Aidex MCP — a reusable Model Context Protocol server foundation: transport, and Tool/Resource/Prompt registries. No engine execution, no providers, no workflows.
