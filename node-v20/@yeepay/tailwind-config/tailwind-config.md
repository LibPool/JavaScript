# @yeepay/tailwind-config

> 标签: JavaScript

## 简介

Tailwind CSS 工程基线，不包含公司视觉令牌。每个主应用和子应用都必须独立构建 CSS，并根据 Wujie 隔离模式显式决定是否加载 Preflight。
