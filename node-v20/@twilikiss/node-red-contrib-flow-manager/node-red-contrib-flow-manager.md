# @twilikiss/node-red-contrib-flow-manager

> 标签: Alon, Amir, aabluedragon, flow, manager, node, node-red, red

## 简介

Flow Manager separates your flow json to multiple files. Split Node-RED flows into separate files, with support for duplicated flow names.
