# psx-data-api

> 标签: finance, karachi, kse100, market-data, ohlcv, pakistan-stock-exchange, psx, stock-market, typescript

## 简介

Typed client for Pakistan Stock Exchange market data: live quotes, OHLCV history, indices, and sectors. Plain arrays and nulls, never formatted strings.
