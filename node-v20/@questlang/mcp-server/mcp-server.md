> 标签: android-xml, claude-code, csv, cursor, game-translation, i18n, ios-strings, json, l10n, localization, mcp, mcp-server, po, translation, vscode, xliff

## 简介

MCP server for AI-powered i18n file translation. Translates JSON, CSV, Android XML, iOS .strings, PO, and XLIFF into 29 languages.
