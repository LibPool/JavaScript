# @msm-core/replay

> 标签: agent, ai, deterministic, fixture, msm, record, replay, tape, testing

## 简介

Record a brain's calls onto a tape, then replay the run with no network, no API key and no model spend. A fingerprint over the exact input each recorded call was made with turns drift into a named error instead of a silent lie.
