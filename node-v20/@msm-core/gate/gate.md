# @msm-core/gate

> 标签: JavaScript

## 简介

Human-in-the-loop approval gate for @msm-core/mini agents (withApprovalGate + onBeforeTool hook) + an NL auto-approve classifier. Pure; storage injected via the ApprovalStore port.
