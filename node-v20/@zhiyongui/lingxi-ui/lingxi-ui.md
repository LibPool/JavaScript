# @zhiyongui/lingxi-ui

> 标签: ai, chat, component-library, element-plus, excel-editor, file-preview, knowledge-graph, mind-map, vue, vue-element-plus-x, vue2, vue3

## 简介

Vue 3 AI component library (chat, file preview, excel editor, knowledge graph, mind map) built on Element Plus & vue-element-plus-x, with a mount/update/unmount SDK for Vue 2.6 hosts.
