# @sanzhisoft/szmap

> 标签: JavaScript

## 简介

SzMap是基于Cesium进行二次开发的二、三维一体化WebGis应用框架，该框架优化了Cesium的使用并增加了一些附加功能，专为开发者快速构建WebGis应用而设计。
