# @hui-x/styled-engine

> 标签: emotion, hui, react, react-component

## 简介

This package is a wrapper around the `@emotion/react` package. It also provides a shared interface that can be used with other styled engines, like styled-components. It is used internally in the `@hui-x/system` package.
