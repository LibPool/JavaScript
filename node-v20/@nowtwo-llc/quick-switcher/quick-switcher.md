# @nowtwo-llc/quick-switcher

> 标签: cmd-k, command-palette, keyboard, navigation, quick-switcher, search, spotlight, typeahead

## 简介

Keyboard-driven command palette for the web, with nested drill-down searches, breadcrumb navigation, and usage-based result ranking. No runtime dependencies.
