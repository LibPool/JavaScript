# @affixio/mcp

> 标签: affixio, agent-trust, attestation, local-first, mcp, ml-dsa, model-context-protocol, post-quantum, tool-gate

## 简介

Local stdio MCP server that wraps the affixio SDK. Signed yes/no attestations that an action happened on the host. PII never leaves the host.
