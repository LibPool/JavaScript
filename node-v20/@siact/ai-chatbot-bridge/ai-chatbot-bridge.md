# @siact/ai-chatbot-bridge

> 标签: JavaScript

## 简介

用于在父容器页面与嵌入的 iframe 之间建立双向指令通信的轻量桥接库。基于 [Comlink](https://github.com/GoogleChromeLabs/comlink) 的 RPC 机制，通过 `HostBridge` 和 `ClientBridge`，宿主应用可以暴露受控的命令，iframe 客户端可发现并调用这些命令，实现对父容器的安全控制。
