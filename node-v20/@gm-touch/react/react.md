# @gm-touch/react

> 标签: JavaScript

## 简介

@gm-touch/react 是 gm-touch 组件库的核心包，提供了一套专为触屏设备设计的 React UI 组件。该组件库主要用于工位屏系统，包括新架构和老架构的应用场景。
