# @wallets-e2e/evidence

> 标签: e2e, evidence, netlify, playwright, report, video, wallet, web3

## 简介

Turns a Playwright JSON report of a wallet e2e run into a static evidence site: every spec and test with its video, screenshots and transaction links, ready to open or deploy.
