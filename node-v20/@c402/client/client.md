# @c402/client

> 标签: attestation, c402, confidential-compute, ethereum, fetch, iexec, tee, x402

## 简介

Consume a c402 endpoint like a normal fetch. Reads the compute contract, pays via x402, verifies the TEE attestation - invisibly.
