# @checkthiscloud/mjml-i18n

> 标签: email, email-templates, i18n, internationalization, interpolation, mjml, mjml-v5, preprocessor, translation

## 简介

i18n and variable interpolation for MJML v5 email templates — a single preprocessor with co-located, vue-i18n-style translations. Experimental (pre-1.0); API may change.
