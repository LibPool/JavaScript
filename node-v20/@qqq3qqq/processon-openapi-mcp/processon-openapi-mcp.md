## 简介

ProcessOn MCP Server - Create diagrams & mind maps with AI. Supports all Mermaid types (flowchart, sequence, class, state, ER, gantt, journey, gitGraph, pie, C4) and Markdown mind maps. One-click install for Claude Desktop, Codex, Cursor, dsh, and more.
