# @sld-kit/svelte

> 标签: diagram, electrical, single-line-diagram, sld, svelte, svg

## 简介

Svelte 4 components for single-line (electrical) diagrams: a headless pan/zoom canvas, element views, and event-dispatching editor chrome built on @sld-kit/core.
