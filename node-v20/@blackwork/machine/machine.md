# @blackwork/machine

> 标签: blackwork, markdown, mdx, react

## 简介

@blackwork/machine is a tattoo-machine-inspired Markdown and MDX engine designed specifically for the Blackwork React UI ecosystem. It is built to power Blackwork-based blogs and documentation sites, rather than to serve as a fully generic content framewo
