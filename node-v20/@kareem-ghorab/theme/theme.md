# @kareem-ghorab/theme

> 标签: css-variables, design-tokens, doodle-ui, shadcn, tailwind, theme

## 简介

Childish, hand-drawn design tokens for Doodle UI: light/dark CSS variables, Neucha + Cabin Sketch fonts, and the signature blob border-radius system for shadcn/ui.
