# @simpine/control-fetch

> 标签: ajax, fetch, http

## 简介

- 基于原生Fetch API封装 - 支持GET/POST/PUT/DELETE方法 - 支持自定义请求方法 - 请求/响应拦截器 - 请求取消功能 - 请求缓存功能 - 请求控制并发数量 - 多种响应数据格式处理 - 精度丢失自动处理
