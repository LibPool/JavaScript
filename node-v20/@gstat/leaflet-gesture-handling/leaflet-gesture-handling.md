# @gstat/leaflet-gesture-handling

> 标签: Gesture, Handling, Leaflet, Maps, fingers, mobile, scroll, two

## 简介

[FORK] Prompt mobile user to use 2 fingers to move the map. Prompt desktop users to use Ctrl+Mouse Wheel to zoom. Brings Google Maps gesture handling into Leaflet.
