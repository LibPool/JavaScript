# @cennso/theme

> 标签: JavaScript

## 简介

Design tokens for Cennso products — color, spacing, radius and typography — as CSS variables, a Tailwind preset and a TypeScript object. The single source of truth behind [`@cennso/ui`](https://www.npmjs.com/package/@cennso/ui).
