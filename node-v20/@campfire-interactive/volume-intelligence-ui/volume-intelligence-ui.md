# @campfire-interactive/volume-intelligence-ui

> 标签: JavaScript

## 简介

Shared Volume Intelligence UI components (volume import) for the Campfire Suite — embedded by the VI webapp and by consuming apps (OMSF) so there is one import surface, not two that drift.
