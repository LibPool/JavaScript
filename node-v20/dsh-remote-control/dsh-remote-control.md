# dsh-remote-control

> 标签: cordis, deepseek, deepseek-harness, dsh, e2e-encryption, miniprogram, plugin, qrcode, relay, remote-control, websocket, wechat

## 简介

DSH Remote Control host plugin: pairs a running DeepSeek Harness with the DRC relay so a WeChat Mini Program can send prompts, watch streamed output, and answer approvals. Payload-level E2E encryption; the relay never sees plaintext. Pairing is one click
