# @persian-web/core

> 标签: esm, farsi, i18n, iran, iranian, jalali, jalali-calendar, javascript, localization, persian, persian-calendar, persian-date, persian-digits, persian-javascript, persian-numbers, persian-typescript, persian-typography, persian-web, rtl, rtl-javascript, typescript, utilities

## 简介

Modern JavaScript and TypeScript utilities for Persian and Farsi web development — Jalali calendar dates, Persian digits and number formatting, RTL helpers, typography, Iranian phone numbers, and national ID validation.
