# meta-beacon

> 标签: github-action, html, meta-description, meta-tags, og-image, open-graph, sarif, seo, static-site, title, twitter-card

## 简介

Audit titles, meta descriptions, Open Graph and Twitter/X card tags across a built static site: presence, duplicates in the head, length, absolute URLs and real og:image files (dimensions, format, size). Text/JSON/SARIF/Markdown, allowlist with expiry, Gi
