# @mrfentmen/ebay-mcp

> 标签: ebay, ecommerce, mcp, search, shopping

## 简介

Query the eBay Browse API (OAuth user token; set EBAY_OAUTH_TOKEN, Bearer): item search, item details. App keys alone cannot call Browse — a user token is required.
