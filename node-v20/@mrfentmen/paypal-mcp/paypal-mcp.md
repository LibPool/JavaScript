# @mrfentmen/paypal-mcp

> 标签: fintech, mcp, payments, paypal, sandbox

## 简介

Query PayPal sandbox (set PAYPAL_SANDBOX_CLIENT_ID + PAYPAL_SANDBOX_SECRET, OAuth auto-token): orders, captures, billing plans. Sandbox only.
