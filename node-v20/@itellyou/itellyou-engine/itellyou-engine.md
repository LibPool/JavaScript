# @itellyou/itellyou-engine

> 标签: JavaScript

## 简介

编辑器核心库，纯js编写，不依赖 React，提供编辑能力，插件接口 ### React 编辑器（[itellyou-editor](https://github.com/itellyou-com/itellyou-editor)） 在 itellyou-engine 基础上扩展编辑能力，提供更多丰富的插件
