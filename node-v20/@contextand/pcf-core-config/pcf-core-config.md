# @contextand/pcf-core-config

> 标签: JavaScript

## 简介

Self-contained PCF configuration foundation: a configuration dialog with built-in Theme + Translations, plus org-wide theming and localization. Depends only on React, Fluent UI v9, and the PCF host context surface.
