# @classcad/renderer

> 标签: buerli, cad, classcad, deterministic, isometric, png, renderer, snapshot, svg

## 简介

Deterministic renderer for ClassCAD session data — solids (z-buffer, assembly transforms), constrained sketches (dimensions, constraints, label de-overlap), curves, and work geometry. Fixed CAD views (iso/top/front/…), auto-fit, reproducible output. Porta
