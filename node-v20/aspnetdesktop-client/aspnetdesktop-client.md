# aspnetdesktop-client

> 标签: angular, aspnetcore, desktop, httpclient, ipc, react, vue, webview

## 简介

DesktopHttpClient: isolated, HTTP-shaped calls from the WebView UI to the in-process ASP.NET Core API over ipc://localhost, with Angular, React and Vue integrations. Never touches the global fetch or Angular's HttpClient.
