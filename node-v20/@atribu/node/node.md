# @atribu/node

> 标签: atribu, instagram, messaging, oauth, sdk, webhooks, whatsapp

## 简介

Official Node.js SDK for the Atribu API — authorize users, send WhatsApp & Instagram messages, and verify signed webhook deliveries.
