# @sodacore/ws

> 标签: @bun, bun, decorator, engine, framework, soda, sodacore, sodacore-plugin, typescript, websocket, websockets, ws, wss

## 简介

Sodacore ws is a core plugin that extends the Http plugin offering WebSocket support to the Sodacore framework.
