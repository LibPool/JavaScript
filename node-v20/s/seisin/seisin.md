# seisin

> 标签: agent-permissions, ai-agents, bubblewrap, claude-code, code-ownership, codeowners, multi-agent, permissions, rbac, sandbox, seatbelt

## 简介

A permission layer for AI coding agents: role-scoped folders and keys, enforced by the OS, and when it blocks it tells you whose file it was.
