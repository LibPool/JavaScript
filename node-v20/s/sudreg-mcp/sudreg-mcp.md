> 标签: company-data, croatia, fina, hrvatska, mcp, mcp-server, oib, open-data, sudreg, sudski-registar

## 简介

MCP server for Croatian company data: Sudski registar, FINA RGFI, udruge, court notices, subsidies, EU tenders. Search by OIB or MBS.
