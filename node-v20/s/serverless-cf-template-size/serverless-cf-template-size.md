# serverless-cf-template-size

> 标签: serverless cloudformation, serverless cloudformation template invalid number of resources is greater than maximum allowed, serverless cloudformation template resource count, serverless plugin

## 简介

Serverless plugin that prints the number of resources in the generated CloudFormation template and warns if your project is close to the max 200 resource limit
