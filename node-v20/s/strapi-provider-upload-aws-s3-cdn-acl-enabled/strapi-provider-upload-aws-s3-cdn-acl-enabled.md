# strapi-provider-upload-aws-s3-cdn-acl-enabled

> 标签: aws, cdn, cloudfront, strapi, upload

## 简介

This Strapi upload provider adapts the strapi-provider-upload-aws-s3, bundled with Strapi, to support writes to non-public S3 buckets plus optional download from a CDN endpoint
