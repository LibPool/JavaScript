# shimmer-trace

> 标签: loader, loading, placeholder, react, shimmer, skeleton, skeleton-loader, ui

## 简介

High-performance React skeleton loaders that automatically trace your UI dimensions. Synchronized animations, zero CLS, and one-line implementation.
