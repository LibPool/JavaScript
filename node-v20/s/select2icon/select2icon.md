# select2icon

> 标签: dropdown, emoji selector, icon picker, react, vue

## 简介

**Select2Icon** is a lightweight, framework-agnostic JavaScript component for selecting icons with a modern, searchable UI. It supports input, dropdown, and inline modes, and is fully customizable and extendable.
