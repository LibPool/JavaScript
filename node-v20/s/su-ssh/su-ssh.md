# su-ssh

> 标签: devops, file-manager, journalctl, port-forwarding, remote-desktop, server-monitoring, sftp, socks5, ssh, ssh-tunnel, sysadmin, systemd, ubuntu, web-terminal, xterm

## 简介

A browser desktop for any Linux server, over nothing but SSH: files, terminal, editor, systemd services with live logs, port forwarding, and live CPU/memory/disk/latency meters.
