# statutor

> 标签: agents, governance, hooks, ledger, opencode, pre-commit, statutor

## 简介

OpenCode enforcement adapter for statutor, the typed project-ledger framework for agentic repos. In-loop mutation-policy checks via the Python kernel CLI (pip install statutor).
