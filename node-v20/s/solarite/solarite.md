# solarite

> 标签: JavaScript, UI, framework, library, minimal, reactive, vanilla, web component

## 简介

Solarite is a small (12.7KB with Brotli), fast, compilation-free JavaScript library that makes native web components fast to update, patching only the DOM that actually changed when you call render().
