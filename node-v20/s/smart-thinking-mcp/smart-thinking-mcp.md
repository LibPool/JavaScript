# smart-thinking-mcp

> 标签: ai-tools, exact-math, mcp, model-context-protocol, reasoning, verification

## 简介

Public remote MCP client for Smart-Thinking: exact math, verified reasoning, search and evidence. No token required; the engine runs on the hosted server.
