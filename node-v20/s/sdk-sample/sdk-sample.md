# sdk-sample

> 标签: JavaScript

## 简介

一个轻量的前端埋点/追踪 SDK，支持自动与手动埋点、动态事件协议（IDL/JSON）、三种上报策略（`xhr`/`beacon`/`img`），并提供 React Hooks 与基础 UI 组件封装，便于快速集成到业务应用。
