# shell-command-policy

> 标签: agent, allowlist, approval, bash, command, mcp, policy, sandbox, security, shell

## 简介

Decide whether a shell command may run: enumerate every command in the line, its redirections and every construct that cannot be decided statically, then match it against an allow/deny policy that fails closed.
