# strapi-plugin-mega-nav

> 标签: mega-menu, menu, navigation, plugin, strapi

## 简介

Smart navigation for Strapi — a visual mega-menu editor with true internal links, restart-free field config, native i18n, and a built-in importer for strapi-plugin-navigation data.
