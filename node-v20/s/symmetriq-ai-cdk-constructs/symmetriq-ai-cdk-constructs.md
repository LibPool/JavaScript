# symmetriq-ai-cdk-constructs

> 标签: ai, aws, cdk, constructs, symmetriq

## 简介

You should explore the contents of this project. It demonstrates a CDK Construct Library that includes a construct (`SymmetriqAiCdkConstructs`) which contains an Amazon SQS queue that is subscribed to an Amazon SNS topic.
