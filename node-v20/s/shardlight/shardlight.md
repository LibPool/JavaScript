# shardlight

> 标签: canvas, flare, glow, lens-flare, light, procedural, r3f, react, react-three-fiber, shards, three, threejs, webgl

## 简介

Procedural lens-flare lights for React, three.js and React Three Fiber. Build a light once and it looks the same everywhere.
