# symflow

> 标签: finite-state-machine, fsm, graphviz, guards, mermaid, middleware, nodejs, petri-net, react-flow, state-machine, statemachine, symflowbuilder, symfony, symfony-workflow, typescript, weighted-arcs, workflow, workflow-engine, yaml

## 简介

A Symfony-compatible workflow engine for TypeScript and Node.js. State machines, Petri nets, guards, events, validation, and YAML/JSON/TypeScript import/export.
