# strikeablock-mcp

> 标签: asic, bitcoin, cli, genesis-block, mcp, model-context-protocol, proof-of-work, sha256, strikeablock, verification

## 简介

MCP server and CLI for Strike a Block: let agents and people strike real proof-of-work genesis blocks, and verify any block's proof locally.
