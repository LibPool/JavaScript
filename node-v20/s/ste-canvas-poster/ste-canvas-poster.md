# ste-canvas-poster

> 标签: barcode, canvas, canvas-poster, declarative, flex-layout, poster, qrcode, schema-driven, uni-app, wechat-miniprogram

## 简介

基于 Canvas 2D API 的声明式海报绘制引擎，支持微信小程序、App、H5、抖音、支付宝及 QQ 小程序
