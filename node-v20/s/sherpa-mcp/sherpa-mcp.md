# sherpa-mcp

> 标签: agent-delegation, claude, claude-code, code-exploration, llama-cpp, lm-studio, local-llm, mcp, mcp-server, model-context-protocol, ollama, token-optimization

## 简介

Claude Code plugin: offload code exploration, search, and batch edits to your local LLM (Ollama / llama.cpp / LM Studio). Ships an MCP server plus a skill that tells Claude when to delegate.
