# stencil-ruby-output-target

> 标签: bridgetown, output-target, rails, ruby, sinatra, stencil, stenciljs, view_component, web-components

## 简介

Stencil output target that generates a Ruby gem from your web components: ViewComponents, helpers, a FormBuilder, head tags with preloads, RBS and tests, for Rails, Sinatra or Bridgetown.
