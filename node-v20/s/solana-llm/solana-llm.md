# solana-llm

> 标签: ai, blockchain, break-solana, gpt2, inference, llm, machine-learning, neural-network, on-chain, solana, tinystories, transformer

## 简介

On-chain LLM inference on Solana. Run GPT-2 (TinyStories-1M) entirely within blockchain transactions. Break Solana Edition 2.
