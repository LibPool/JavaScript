# sirenic-agents

> 标签: agents, company-data, france, kyb, langchain, sirenic, x402

## 简介

LangChain.js tools for Sirenic — official French & European company data, paid per call via x402 (USDC/EURC on Base). No account, no API key: bring a wallet key, set a price cap, done.
