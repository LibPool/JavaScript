# solana-resilience-kit

> 标签: @solana/kit, failover, jito, observability, resilience, rpc, solana, transaction, web3

## 简介

Vendor-neutral, client-side resilience and observability layer for Solana dApps, built on @solana/kit (web3.js v2).
