# streamify-audio

> 标签: audio, bot, discord, discordjs-voice, ffmpeg, lavalink, lavalink-alternative, music, soundcloud, spotify, streaming, youtube, yt-dlp

## 简介

Dual-mode audio library: HTTP streaming proxy + Discord player (Lavalink alternative). Supports YouTube, Spotify, SoundCloud with audio filters.
