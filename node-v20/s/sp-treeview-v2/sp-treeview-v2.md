# sp-treeview-v2

> 标签: checkbox, dropdown, tree, tree-select, tree-view, treeview, web-components

## 简介

Compatibility alias for the sp-treeview v4 rewrite — re-exports @sp-treeview/element (<sp-tree>, <sp-tree-select>) and @sp-treeview/core (TreeStore). New projects should install those packages directly.
