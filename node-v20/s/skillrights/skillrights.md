# skillrights

> 标签: agent-skills, ai, claude, codex, license, skillrights, skills, spdx, tdm, training-rights

## 简介

Apply and verify SkillRights declarations on AI agent skills: execution permitted, training rights reserved, in one line. No accounts, no telemetry; network used only by the optional register verb.
