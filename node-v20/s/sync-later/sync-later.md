# sync-later

> 标签: backoff, fetch, file-upload, indexeddb, mutation-queue, network-resilience, offline-first, persistence, queue, request-queue, resilience, rest-api, retry, typescript, zero-dependency

## 简介

Zero-dependency, offline-first mutation engine for REST APIs. Features reliable persistence, dependency chaining, automatic retries with backoff, and file upload support.
