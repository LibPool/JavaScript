# svg-to-react-native-tsx-cli

> 标签: component, react, react-native, svg

## 简介

Based on svg-to-react-native-cli. A command line utility that takes a svg image file and outputs a fully formatted stateless functional React Native component with `height` and `width` for props. With flags to toggle formatting and remove style attributes
