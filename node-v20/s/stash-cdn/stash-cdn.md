# stash-cdn

> 标签: cdn, file-sharing, stash, upload

## 简介

Client kecil buat upload/download file ke stash.cc.cd — auto chunking, retry, dedup, dan enkripsi client-side. Satu file, tanpa dependency.

## 官网

- npm 页面：https://www.npmjs.com/package/stash-cdn

- 1.0.0

## 获取地址

- npm 安装：`npm install stash-cdn`
- npm registry：https://registry.npmjs.org/stash-cdn
- Node 要求：>=18
