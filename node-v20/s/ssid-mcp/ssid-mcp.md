# ssid-mcp

> 标签: compliance, cyber-resilience-act, default-credentials, device-identity, mac-address, mcp, modelcontextprotocol, network, oui, psti, router-default-password, ssid

## 简介

ssid.ai MCP server: manufacturer-cited router default logins and the Router Compliance Index (409 models), plus MAC/OUI vendor lookup with randomized-address detection. Free, no API key.
