# scenic-forge-fluent

> 标签: builder, csg, fluent-api, generative-art, path-tracing, sdf, webgpu, wgsl

## 简介

A chainable API over scenic-forge: sphere(1).translate([0, 1, 0]).paint(materials.chrome), producing the same plain scene data.
