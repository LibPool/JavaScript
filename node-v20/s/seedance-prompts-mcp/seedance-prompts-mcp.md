# seedance-prompts-mcp

> 标签: ai-video, image-to-video, mcp, mcp-server, modelcontextprotocol, prompt-engineering, prompts, seedance, text-to-video, video-generation

## 简介

MCP server with 150 AI video prompts that were each rendered into a real video with Seedance 2 — search, inspect, audit and compose prompts, with the example video for every one.
