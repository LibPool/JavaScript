# strapi-plugin-backfill-db-migrations

> 标签: backfill, knex, migrations, plugin, post-schema-sync, strapi, strapi-plugin

## 简介

Run Knex-style database migrations *after* Strapi's schema sync, ideal for backfilling data into newly created columns.
