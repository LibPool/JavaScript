# spyglass-toc

> 标签: active-link, aria-current, docs, framework-agnostic, navigation, react, react-hook, scroll-spy, scrollspy, table-of-contents, toc

## 简介

Mark the table-of-contents link for the section on screen (scrollspy). Works on the page or inside any scrolling pane. Zero dependencies, any framework, optional React hook.
