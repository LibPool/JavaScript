# solana-vanity

> 标签: address-generator, agent, base58, ed25519, keypair, mcp, proof-of-grind, solana, split-key, vanity, vanity-address, vanity-wallet, wasm, web3, webassembly

## 简介

Open-source Solana vanity address generator: WebAssembly Ed25519 grinding in the browser, an exact Base58 difficulty model, signed proof-of-grind certificates, trustless split-key delegation, an HTTP API, a CLI and an MCP server.
