# sfco-sass-utils

> 标签: JavaScript

## 简介

--- ## About SASS Utils. is a library of SASS `mixins` and `functions` which aim to simplify common patterns for project writing styles. SASS Utils. is meant to compliment larger, more robust SASS libraries, such as [Thoughtbot's][1] [Bourbon][2].
