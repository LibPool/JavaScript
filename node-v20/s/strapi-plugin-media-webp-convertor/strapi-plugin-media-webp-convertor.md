# strapi-plugin-media-webp-convertor

> 标签: allowed-file-types, file-type-validation, file-upload, file-upload-security, image-converter, image-convertor, image-optimization, magic-bytes, malicious-file-upload, media, media-library, migration, optimization, pdf-validation, s3, strapi, strapi-plugin, strapi5, svg-sanitizer, svg-xss, upload, upload-security, upload-validation, webp, webp-converter, webp-convertor

## 简介

Secure and optimize Strapi 5 uploads: blocks malicious file uploads with magic-byte file type validation, scans SVG and PDF content, converts images to WebP, and migrates media to S3.
