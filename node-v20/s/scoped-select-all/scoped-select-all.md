# scoped-select-all

> 标签: JavaScript

## 简介

这个项目是一个全选的控制函数，当点击到某一个容器内，使用 cmd+A 快捷键时，可以控制哪些元素被选中，到哪一层级，比如，点击到一个表格内，使用 cmd+A 快捷键时，可以选择表格内的所有单元格，或者选择整张表格。
