# sfxmint

> 标签: audio, autoplay, cc0, game-audio, howler, mcp, public-domain, sfx, sound-effects, soundboard, ui-sounds, web-audio

## 简介

Add free CC0 sound effects to a web app or game by role name. CLI downloads verified files into your project; a tiny runtime handles autoplay unlock, preload and mute. No API key.
