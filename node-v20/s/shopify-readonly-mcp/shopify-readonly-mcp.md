# shopify-readonly-mcp

> 标签: ai-agent, claude, mcp, mcp-server, model-context-protocol, read-only, shopify, shopify-admin-api

## 简介

Read-only MCP server for a Shopify store: lets AI agents look up products, orders and low stock through the Admin GraphQL API, with no write access at all.
