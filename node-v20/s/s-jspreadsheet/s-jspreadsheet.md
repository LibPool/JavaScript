# s-jspreadsheet

> 标签: s-jspreadsheet

## 简介

Jspreadsheet is a lightweight, vanilla javascript plugin to create amazing web-based interactive tables and spreadsheets compatible with Excel, Google Spreadsheets and any other spreadsheet software.
