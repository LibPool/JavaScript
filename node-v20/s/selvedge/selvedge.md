# selvedge

> 标签: ai, ai-prompting, anthropic, chatgpt, claude, code-generation, developer-tools, dsl, language-model, llm, llm-dsl, natural-language, openai, prompt, prompt-builder, prompt-engineering, prompt-template, selvedge, structured-output, type-safe, typescript

## 简介

A type-safe, declarative DSL for building robust, composable LLM prompts and programs in TypeScript. Selvedge simplifies prompt engineering, structured output, and multi-model orchestration.
