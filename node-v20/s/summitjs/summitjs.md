# summitjs

> 标签: ai-agent, alpine, csp-safe, directives, framework, frontend, html, progressive-enhancement, reactivity, signals, summit, summitjs

## 简介

The open source, AI Agent Native JavaScript framework. Add reactive behavior directly in your HTML with signal-powered s- directives and $ magics. No build step, CSP-safe, about 16KB.
