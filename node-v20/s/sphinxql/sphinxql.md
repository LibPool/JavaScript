# sphinxql

> 标签: manticore, manticoresearch, mysql, query builder, search, search engine, sphinx, sphinxql, sphinxsearch, sql

## 简介

SphinxQL query builder for Node.JS. Supports Sphinx search(2.x and 3.x) and Manticore search
