# strapi-plugin-bff-views

> 标签: aggregate, backend-for-frontend, bff, headless-cms, performance, populate, strapi, strapi-plugin, strapi-v5

## 简介

Configurable BFF aggregate endpoints for Strapi v5: one request returns a fully populated, transformed page payload backed by parallel decomposed queries.
