# string-usefull-function

> 标签: capitalize, clean, reverse, string, utility

## 简介

A small utility library for manipulating strings. Features include: - 🔁 `reverseString`: Reverses any string. - 🔠 `capitalizeWords`: Capitalizes the first letter of every word. - 🧹 `removeExtraSpaces`: Cleans up extra spaces in a string.
