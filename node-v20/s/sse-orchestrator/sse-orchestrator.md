# sse-orchestrator

> 标签: fetch-stream, llm, server-sent-events, sse, streaming, type-safe, typescript

## 简介

A resilient, ultra-lightweight, type-safe client-side SSE orchestrator with dual ESM/CJS distribution, backoff-jitter reconnection pipelines, and extended HTTP configurations.
