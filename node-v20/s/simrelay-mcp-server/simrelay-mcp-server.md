# simrelay-mcp-server

> 标签: ai-tools, mcp, model-context-protocol, phone, sim, simrelay, sms

## 简介

MCP server for SimRelay — list SIMs, lock/release them, fetch message history, and stream incoming SMS in real time over WebSocket.
