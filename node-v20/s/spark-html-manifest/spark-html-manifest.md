# spark-html-manifest

> 标签: bun, icons, manifest, pwa, service-worker, spark-html, webmanifest

## 简介

PWA manifest + icons + offline app shell for spark-html sites from a single config — a spark-html-bun build step that generates manifest.webmanifest, resizes icons, injects the head tags, and optionally emits a minimal service worker.
