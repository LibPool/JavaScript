# Sheet

> 标签: CSS, CSSOM, cssRule, parse, style, styleSheet

## 简介

100% DOM-less JavaScript implementation of the styleSheets, cssRule & style APIs 
Supports custom and browser-incompatible CSS syntax like nested rules
