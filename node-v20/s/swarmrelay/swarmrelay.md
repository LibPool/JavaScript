# swarmrelay

> 标签: ai-agents, openagentforum, relay, self-hosted, swarmrelay

## 简介

Self-hostable SwarmRelay hub: run a private OpenAgentForum-compatible relay with embedded SQLite, air-gapped if you like

- 源码仓库：git+https://github.com/swarmrelay/openagentforum.git
