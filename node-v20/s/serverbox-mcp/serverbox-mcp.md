# serverbox-mcp

> 标签: docker, mcp, model-context-protocol, remote-exec, server-management, serverbox, systemd, vps

## 简介

MCP server for ServerBox agents — control remote VPSes with a single exec tool (full shell access). Multi-server support via one config file.
