# stacklit

> 标签: agent, ai, aider, claude, cli, code-analysis, code-intelligence, codebase, codebase-index, context, copilot, cursor, dependency-graph, developer-tools, index, llm, mcp, mcp-server, monorepo, repo-map, tokens

## 简介

Zero-config codebase context for AI agents. One command generates a ~250-token navigation map and auto-configures Claude Code, Cursor, and Aider.
