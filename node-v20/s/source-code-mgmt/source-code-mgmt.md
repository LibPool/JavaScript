# source-code-mgmt

> 标签: JavaScript

## 简介

DSH plugin: source code management. Registers「代码管理」as a dsh-better-sidebar sidebar Tab when installed; otherwise registers a button in the DSH session header's right-aligned utilities (beside "Session log"), with an empty-state entry pinned at the TOP-RIG
