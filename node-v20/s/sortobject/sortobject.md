# sortobject

> 标签: array, browser, comparator, deep, deeply, deno, deno-edition, deno-entry, denoland, es2022, export-default, keys, module, node, object, sort, typed, types, typescript

## 简介

Returns a copy of an object, sorted deeply by its keys, without mangling any arrays inside of it
