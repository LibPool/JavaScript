# snugkv-nest

> 标签: bullmq, cache, client, consumer-group, job-queue, lock, message-bus, microservices, nestjs, pubsub, queue, rate-limit, redis, snugkv, streams

## 简介

NestJS module and TypeScript client for SnugKV: data types, cache, locks, rate limits, pub/sub, transactions, job queues, flow tracing and a durable stream message bus.
