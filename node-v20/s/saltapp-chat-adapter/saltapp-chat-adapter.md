# saltapp-chat-adapter

> 标签: ai-agent, bot-framework, chat, chat-sdk, chatbot, pgp, salt, saltapp, typescript, webhook

## 简介

Vercel Chat SDK platform adapter for Salt (saltapp.ai) -- write a bot once with `chat`, run it on Salt as one more platform.
