# safecheck-mcp

> 标签: claude, maven, mcp, model-context-protocol, npm, pypi, security, supply-chain, vulnerability

## 简介

MCP server exposing PackageSafe's supply-chain risk scanning (npm/PyPI/Maven) as tools an AI agent can call directly.
