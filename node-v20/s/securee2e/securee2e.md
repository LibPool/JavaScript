# securee2e

> 标签: aes-gcm, composable, diffie-hellman, e2e, ecdh, ecdsa, end-to-end-encryption, hkdf, vue, webcrypto

## 简介

End-to-end encryption on the Web Crypto API: authenticated ECDH key exchange (ECDSA identity keys, HKDF, AES-256-GCM) with identity pinning. Framework-agnostic core plus a Vue 3 composable.
