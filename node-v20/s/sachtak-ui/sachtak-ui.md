# sachtak-ui

> 标签: component-library, react, sachtak-ui, tailwind, ui

## 简介

Sachtak UI is a lightweight React component library built with [Vite](https://vitejs.dev/) and styled using [Tailwind CSS](https://tailwindcss.com/). It provides reusable, customizable components to accelerate frontend development.
