# smarthivesms-mcp

> 标签: claude-desktop, cursor, mcp, model-context-protocol, otp, smarthivesms, sms, voice-otp, whatsapp

## 简介

Official Model Context Protocol (MCP) server for SmarthiveSMS. Enables AI agents (Cursor, Claude Desktop, Windsurf, LangChain) to send SMS, WhatsApp OTP, Voice OTP, Emails, and query balances.
