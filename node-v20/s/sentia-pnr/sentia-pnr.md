# sentia-pnr

> 标签: JavaScript

## 简介

sentia-pnr is a simple client for [cpr direkte](https://www.cpr.dk/kunder/private-virksomheder/cpr-direkte-program-til-program/) developed by [Sentia](http://sentia.ai). Sentia-pnr can either be used as a node library, or a standalone proxy for cpr direkt
