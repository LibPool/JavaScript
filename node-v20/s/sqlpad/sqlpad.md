# sqlpad

> 标签: crate, drill, hana, mssql, mysql, postgres, postgresql, presto, sap, sql, vertica

## 简介

Web app. Write SQL and visualize the results. Supports Postgres, MySQL, SQL Server, Crate, Vertica and SAP HANA.
