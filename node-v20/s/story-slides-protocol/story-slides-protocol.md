# story-slides-protocol

> 标签: deck, protocol, serialization, share, story-slides

## 简介

Portable formats for story-slides decks: a versioned DeckManifest (serialize/validate/share via URL) plus ShareableDeck (file-based JSON, compatible with the Swift SDK). No React, no backend required.
