# spark-html-sri

> 标签: bun, integrity, security, spark-html, sri, subresource-integrity, tofu

## 简介

Subresource Integrity for spark-html — auto-hash built assets and components, verify at runtime, and make URL-imported components safe with an origin allow list + trust-on-first-use. Zero dependencies.
