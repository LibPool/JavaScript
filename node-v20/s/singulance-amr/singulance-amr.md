# singulance-amr

> 标签: ai-agents, embeddings, hnsw, memory, mmap, qdrant-alternative, singulance, vector-database, vector-search

## 简介

SINGULANCE AMR — a memory filesystem for AI agents. Per-tenant mmap'd vector + temporal + graph store in the .amr format. Drop-in for Qdrant.
