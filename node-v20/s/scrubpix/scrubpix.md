# scrubpix

> 标签: cli, exif, exif-remover, gps, heic, image-metadata, jpeg, lossless, metadata, photo-privacy, png, privacy, remove-exif, strip-exif, webp, zero-dependency

## 简介

See and strip hidden image metadata — EXIF, GPS location, camera info, comments — from JPEG, PNG & WebP (+ HEIC read-only), losslessly and 100% locally. CLI + library + web app. No re-encoding, no upload. Zero runtime dependencies; works in the browser, N
