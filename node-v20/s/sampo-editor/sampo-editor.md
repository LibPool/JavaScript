# sampo-editor

> 标签: clash, config, editor, json-schema, mihomo, monaco, react, tailwind, vite, yaml

## 简介

Embeddable Monaco-based YAML/config editor for React + Vite + Tailwind v4 apps, with optional mihomo/clash JSON Schema and form-meta preset.
