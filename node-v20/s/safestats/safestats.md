# safestats

> 标签: analytics, anonymous, browser, ccpa, gdpr, isomorphic, metrics, nodejs, privacy, tracking, universal

## 简介

A lightweight, isomorphic analytics library that collects anonymous metrics without compromising user privacy. Works in Node.js and the browser.
