# sshmulti

> 标签: cjs, esm, git, multiple, multiple git account, multiple ssh, npm, package, ssh, ssh-keygen, switch multiple ssh key, typescript, umd

## 简介

SSHmulti is a node version of ruby gem SSHwitch that lets you manage different sets of keys in Unix-like systems.
