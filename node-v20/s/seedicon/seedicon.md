# seedicon

> 标签: avatar, blockies, deterministic, dicebear, ethereum, generative, hash, identicon, jdenticon, pixel-art, profile-picture, randomart, seed, ssr, stellar, svg, wallet, zero-dependency

## 简介

Deterministic SVG avatars generated from any string seed (wallet address, UUID, user id) — no image storage, no uploads.
