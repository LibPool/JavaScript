# snipcode

> 标签: agent-tools, ai-agent, browser-automation, claude-code, claude-code-plugin, cli, code-generation, component-extraction, css-extraction, design-system, design-tokens, html-to-react, html-to-tailwind, html-to-vue, playwright, web-to-code

## 简介

Your agent just got scissors. Cut any element from a live web page into clean code, or take the whole page's design. No LLM calls, no API keys.
