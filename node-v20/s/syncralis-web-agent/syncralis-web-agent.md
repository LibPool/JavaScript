# syncralis-web-agent

> 标签: browser-automation, claude, cursor, mcp, model-context-protocol, playwright, web-agent

## 简介

Enterprise-grade MCP server giving any MCP client a real, trust-checked, SSRF-protected browser: API-based web search (Tavily/Brave, no anti-bot blocking), verify sites, read pages and social/official feeds, click, and download files (images, PDFs, Office
