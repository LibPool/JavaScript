# scafflod

> 标签: JavaScript

## 简介

适用于单页应用的前端框架整合脚手架， 其中包含了   - [Magix](http://thx.github.io/magix/): 单页应用底层框架   - [Brix](https://thx.github.io/brix-book/): 组件库 (https://thx.github.io/brix-book/)   - [Vue](http://vuejs.org.cn/): 提供mvvm双向绑定   - [brix-animation](http://groups.alidemo.cn/thx/
