# sendfax

> 标签: agent, api, fax, mpp, sendfax, usdc, x402

## 简介

Official TypeScript SDK for SendFax.sh — send real faxes over HTTP, paid per page with x402 or MPP (USDC). No accounts, no API keys.

- 官网：https://sendfax.sh/docs
- 源码仓库：git+https://github.com/DanielSinclair/sendfax.git
