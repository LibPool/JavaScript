# shaderng

> 标签: angular, ng-add, orb, schematics, shader, shadercn, typegpu, vgpu, webgpu

## 简介

ng add shaderng: GPU shader orbs and rectangular fields for Angular 22, copied into your project. Unofficial Angular port of shadercn.
