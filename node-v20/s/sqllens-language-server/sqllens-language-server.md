# sqllens-language-server

> 标签: bigquery, databricks, dbt, duckdb, language-server, lsp, mysql, postgres, redshift, snowflake, sql, sql-language-server, sqlite, sqllens, trino, tsql

## 简介

A multi-dialect SQL language server (LSP) built on sqllens: diagnostics, hover, go-to-definition, references, completion, signature help, semantic tokens, and more. Source-first, semantics-first.
