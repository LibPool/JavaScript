# svg2wkt

> 标签: convert, geojson, geometry, gis, svg, typescript, well-known-text, wkt

## 简介

Convert an SVG string into a WKT (Well-Known Text) geometry string. Zero dependencies, TypeScript, ESM + CJS + UMD.
