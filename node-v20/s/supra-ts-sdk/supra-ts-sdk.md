> 标签: blockchain, crypto, dapp, dapp-development, javascript-sdk, move, move-lang, move-sdk, move-smart-contracts, smart-contracts, supra, supra-blockchain, supra-javascript, supra-l1, supra-l1-sdk, supra-sdk, supra-ts-sdk, supra-typescript, typescript-sdk, web3, web3-sdk

## 简介

A TypeScript SDK for interacting with the Supra blockchain and Move smart contracts. Provides type-safe utilities for transactions, contract calls, and on-chain data.
