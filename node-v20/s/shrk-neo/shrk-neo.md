# shrk-neo

> 标签: atomics, ipc, multiprocess, multithreading, nodejs, shared-memory, sharedarraybuffer, vexify, worker, worker-threads, zero-copy

## 简介

Pass JS objects between Node.js worker processes straight from SharedArrayBuffer — no JSON, no IPC/network, zero-copy buffers. powered by vexify
