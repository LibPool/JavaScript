# streetui

> 标签: forms, framework, hydration, i18n, no-virtual-dom, reactivity, renderer, router, signals, ssr, streetui, typescript, ui

## 简介

StreetUI — a complete TypeScript UI framework with its own compiler, semantic application graph, reactivity, DOM renderer, router, resources, forms, context, i18n, SSR, hydration, testing, devtools and CLI. One install, one import.
