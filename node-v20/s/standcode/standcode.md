# standcode

> 标签: agent, areco, cli, dispatcher, multi-agent, orchestration

## 简介

Caller/Thinker/Worker agent orchestration on top of areco — dispatch tasks to CLI agent Stands, results land in a pull-based inbox (zero polling)
