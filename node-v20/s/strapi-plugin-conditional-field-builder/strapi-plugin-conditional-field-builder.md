# strapi-plugin-conditional-field-builder

> 标签: conditional, dropdown, form-builder, plugin, strapi, strapi-custom-field, strapi-plugin, variant

## 简介

Strapi v5 custom field: pick an option, get a tailored set of sub-fields. An embedded form-builder, stored as a single JSON value.
