# sella-cli

> 标签: agentic-commerce, ai-agents, api-marketplace, claude, cli, cursor, data-marketplace, datasets, developer-tools, mcp, micropayments, model-context-protocol, onboarding, pay-per-call, usdc, x402

## 简介

Connect your AI agent to Sella, the marketplace where agents buy data and APIs, in one command: npx sella-cli. Installs the Sella MCP server into Claude Code, Cursor and more, then pairs, verifies, funds, and publishes.
