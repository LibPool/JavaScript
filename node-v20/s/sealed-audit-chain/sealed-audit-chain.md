# sealed-audit-chain

> 标签: audit, audit-log, canonical-json, cross-language, hash-chain, hmac, jcs, rfc8785, tamper-evident, test-vectors

## 简介

Tamper-evident, HMAC-sealed audit chain with byte-identical TypeScript and Python implementations, checked by shared test vectors and a cross-language parity suite.
