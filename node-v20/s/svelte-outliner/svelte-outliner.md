# svelte-outliner

> 标签: drag-and-drop, editor, hierarchical, outline, outliner, svelte, svelte5, tree

## 简介

A Svelte 5 outline editor with keyboard shortcuts, drag-and-drop, zoom, undo/redo, and optional markdown rendering
