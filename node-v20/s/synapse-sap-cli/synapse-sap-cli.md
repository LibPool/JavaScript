# synapse-sap-cli

> 标签: agent, ai-agent, cli, devtools, escrow, oobe, protocol, sap, solana, synapse, web3, x402

## 简介

CLI toolkit for the Synapse Agent Protocol (SAP v2) on Solana — register agents, manage escrows, automate x402 payments, publish tool manifests, and more. Aligned to SDK v0.18.0.
