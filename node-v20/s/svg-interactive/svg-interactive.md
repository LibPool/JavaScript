# svg-interactive

> 标签: calculator, data-visualization, diagram, draw.io, drawio, figma, flowchart, foreignObject, forms, illustrator, inkscape, input, interactive, nextjs, output, react, svg, typescript, ui-components, visualization, workflow

## 简介

Transform any SVG into an interactive form with embedded input/output fields. Works with draw.io, Figma, Inkscape, and custom SVGs.
