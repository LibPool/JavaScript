# sldz-easyplayer

> 标签: easyplayer, flv, hls, live, player, ptz, streaming, surveillance, video, voice-intercom, vue3

## 简介

基于 EasyPlayerPro SDK 封装的 Vue 3 视频播放器组件，支持直播流播放、云台控制、语音对讲、多清晰度切换等功能
