# storylark-contracts

> 标签: JavaScript

## 简介

StoryLark's file contracts — the brand/presentation/deployment JSON Schemas, their validator, the theme-package format and a dependency-free zip codec. Shared by the build, the packaging CLI and the deployment's import endpoint so all three agree.
