# ssr-leak

> 标签: axios, data-leak, lint, module-scope, nextjs, request-isolation, security, ssr, static-analysis, typescript

## 简介

Static checker that catches module-scope state (axios.defaults, interceptors, module-level variables, globalThis) leaking between SSR requests in Next.js
