# streamforge-player

> 标签: analytics, hls, metrics, streamforge, usage, video

## 简介

Browser SDK for reporting Streamforge video usage metrics (play_start, heartbeat, play_end) from HTML5 or HLS players.

## 官网

- npm 页面：https://www.npmjs.com/package/streamforge-player

- npm registry：https://registry.npmjs.org/streamforge-player
- Node 要求：>=18
