# semantic-state-estimator

> 标签: ema, embeddings, onnx, semantic, state, typescript, webworker

## 简介

A TypeScript library that tracks the implicit semantic intent, emotional state, or 'vibe' of a user/system using local text embeddings and EMA fusion.
