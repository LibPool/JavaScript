> 标签: agent, ai-agent, claude, cursor, diagnostics, mcp, model-context-protocol, rrweb, session-replay, shadow-monitor, uat, windsurf

## 简介

MCP server for inspecting Shadow Monitor diagnostic bundles (rrweb session replay, network, console, and storage capture) locally — works with any MCP client.
