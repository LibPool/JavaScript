# solmachina-sdk

> 标签: agent, ai-agents, autonomous, base, decision, defi, financial-firewall, mcp, policy, risk, solana, solmachina, trading, usdc, wallet, x402

## 简介

Official SDK for the SolMachina Agent Financial Firewall — one call returns EXECUTE/REVIEW/REJECT + risk index + evidence + a signed receipt, with a fail-closed policy gate, paid per call in USDC over x402 (Solana + Base).
