# sc-cordova-plugin-activityindicator

> 标签: JavaScript

## 简介

Plugin for Cordova 3.0+ that allows you to show a loading spinner and a message in your Android/iOS Cordova's app.

## 官网

- npm 页面：https://www.npmjs.com/package/sc-cordova-plugin-activityindicator
