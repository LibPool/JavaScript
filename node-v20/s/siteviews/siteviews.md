# siteviews

> 标签: client-side tracking, html widget, no backend, page views, plug and play, simple analytics, siteviews, toast notification, toastify, tracking, view counter, visitor counter, web counter, website analytics, website views, zero config

## 简介

Plug-and-play website views counter with zero configuration. Just add one script tag with a few attributes to start tracking visits and showing customizable view counts, user info, and toast notifications.
