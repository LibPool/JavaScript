# split-reveal

> 标签: animation-timeline, astro, css-animation, scroll-animation, scroll-driven-animations, split-text, text-reveal, zero-dependency

## 简介

Scroll-linked per-character text reveal in CSS. The split runs at build time, so nothing ships to the browser but markup and a stylesheet.
