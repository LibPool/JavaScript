# signalk-simple-switcher

> 标签: signalk, signalk-category-utility, signalk-node-server-plugin, signalk-webapp, switcher, tabs, webapp

## 简介

Minimal tab bar (top or bottom) for quickly switching between Signal K webapps and web pages. The same webapp can be added as several tabs.
