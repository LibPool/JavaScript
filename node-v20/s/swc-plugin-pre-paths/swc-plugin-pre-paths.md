# swc-plugin-pre-paths

> 标签: swc-plugin

## 简介

A [SWC](https://swc.rs) plugin to use [path mapping](https://www.typescriptlang.org/docs/handbook/module-resolution.html#path-mapping). This may be needed in other plugins.
