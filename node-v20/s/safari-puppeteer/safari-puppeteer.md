# safari-puppeteer

> 标签: applescript, automation, browser, headful, macos, mcp, model-context-protocol, puppeteer, safari, safaridriver, scraping, testing, webdriver, webkit

## 简介

Control local Safari with the Puppeteer API, backed by safaridriver (W3C WebDriver) and AppleScript.
