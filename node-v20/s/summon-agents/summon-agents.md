# summon-agents

> 标签: agents, ai, claude, claude-code, coding-agent, copilot, cursor, git-worktree, mcp, orchestrator, parallel

## 简介

Turn one approved plan into a team of AI coding agents that build it in parallel, in isolated git worktrees, from inside your editor.
