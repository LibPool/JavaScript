# soundcloud-api-ts

> 标签: api, audio, client, music, node, oauth2, pkce, rest-api, sdk, soundcloud, soundcloud api, soundcloud typescript, soundcloud-api, streaming, typescript, typescript api client

## 简介

TypeScript-first SoundCloud API client for accessing tracks, users, playlists, and search endpoints. Zero dependencies, native fetch, full OAuth 2.1 + PKCE support.
