# signalk-first-mate

> 标签: bluewater-cruising, cerbo, first-mate, signalk, signalk-category-cloud, signalk-node-server-plugin, victron

## 简介

Send this boat's battery, tank, engine, depth and position readings to First Mate, the Bluewater Cruising app.
