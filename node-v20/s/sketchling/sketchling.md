# sketchling

> 标签: ai, animation, cli, creative-coding, gsap, hand-drawn, illustration, llm, rough.js, sketch, svg

## 简介

A hand-drawn illustration and animation language for LLMs, like Manim but for expressive hand-drawn illustration and motion.
