# smithers-fusions

> 标签: agent, claude-code, cli, codex, ensemble, fusion, incur, llm, panel, skill, smithers, subscriptions

## 简介

Run model fusions locally. Fan a prompt across a panel of models, judge their answers, and synthesize one. Ships a plan -> implement -> review -> fix coding loop where every step is a fusion. Installable as an agent skill or used as a CLI. Powered by smit
