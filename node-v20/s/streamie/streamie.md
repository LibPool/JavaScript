# streamie

> 标签: async, async-iterator, backpressure, batch, batching, concurrency, data-processing, etl, filter, flatmap, map, pipeline, queue, stream, streams, typescript

## 简介

Async data pipelines with familiar array-style methods — per-stage concurrency, backpressure by default, batching, retries, and bridges to Web and Node streams.
