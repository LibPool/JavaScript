# sabpaisa-react-native

> 标签: bhim, gpay, payment-gateway, payments, paytm, phonepe, react-native, sabpaisa, upi

## 简介

SabPaisa Payment Gateway SDK for React Native (pure JavaScript) — native UPI, in-app gateway checkout for cards/net banking/wallets, and no-secret status verification.
