# saif-rn-a11y

> 标签: a11y, accessibility, contrast, expo, lint, react-native, static-analysis, wcag

## 简介

Static accessibility linter for React Native - catches WCAG contrast failures, undersized touch targets, and missing screen-reader labels at build time. No equivalent exists for RN's non-DOM component model.
