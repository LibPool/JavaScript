# snapapi-mcp-server

> 标签: claude, cursor, mcp, model-context-protocol, screenshot, snapapi, web-scraping, windsurf

## 简介

MCP server for SnapAPI — take screenshots of any website and scrape web content from Claude, Cursor, Windsurf, or any MCP client
