> 标签: api-client, axios, backend, browser, fetch, frontend, http, http-client, node, open-source, promise, request, rest, shape, shaperq, typescript, wrapper

## 简介

ShapeRQ 🚀 --- **ShapeRQ** is a **Promise-based HTTP client** for the browser, built on top of the native `Fetch API`   Its goal is to **save your time** by offering a clean and flexible API for making HTTP requests
