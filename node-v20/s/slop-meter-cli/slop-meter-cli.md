# slop-meter-cli

> 标签: ai-detection, ai-text-detector, cli, llm, slop, stylometry

## 简介

Marks each paragraph human-ish, machine-ish, mixed or can't tell, with calibrated odds. A 56 KB model that runs locally with no network calls.
