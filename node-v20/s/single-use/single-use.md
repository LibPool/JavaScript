# single-use

> 标签: atomic, concurrency, conformance, idempotency, magic-link, oauth, one-time, otp, race-condition, security, single-use, testing

## 简介

Prove your one-time credentials are actually one-time. A dependency-free conformance suite for single-use token redemption — OAuth codes, password resets, magic links, invites, idempotency keys.
