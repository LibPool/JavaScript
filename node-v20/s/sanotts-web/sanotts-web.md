# sanotts-web

> 标签: espeak, heart, neural-tts, offline, on-device, speech-synthesis, text-to-speech, tts, wasm, webassembly

## 简介

Browser-native neural text-to-speech, WebAssembly, no server. 294k to 2.27M parameters, 11 voices, 6 languages; weights stream from Hugging Face. Live at https://tts.ampixa.com/sanoTTS
