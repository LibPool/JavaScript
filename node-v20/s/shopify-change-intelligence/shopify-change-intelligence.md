# shopify-change-intelligence

> 标签: ai-agents, competitive-intelligence, competitor-analysis, ecommerce, mcp, model-context-protocol, price-monitoring, shopify, shopify-api, usdc, x402

## 简介

Remote MCP server to monitor any public Shopify store: free live snapshot, paid change intelligence (new/removed products, price moves, stock) and competitor reports in USDC via x402 on Base. Use npx shopify-change-intelligence to print client config.
