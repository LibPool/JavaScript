# sns-n8n

> 标签: automation, n8n, no-tracking, privacy, self-hosted, sns, tunnel, webhook, workflow, zero-telemetry

## 简介

SNS-n8n: Zero-telemetry n8n automation platform with enhanced privacy features. One-command setup with automatic HTTPS tunnel for webhooks.
