# secret-env

> 标签: config, dot-env, dotenv, env, env-file, env-variables, environment, environment-variables, nodejs, private-env, safe-dotenv, safe-env, secret, secret-dotenv, secret-env, security, sensitive

## 简介

A secure alternative to dotenv — prevents sensitive '.env.secret' files from being pushed to Git and creates '.env.secret.example' automatically. Supports CommonJS and ES Module.
