# story-scroll-studio

> 标签: claude, claude-code, claude-plugin, gsap, landing-page, nextjs, scroll-animation, scrolltrigger, seo

## 简介

A Claude plugin that builds story-driven, GSAP scroll-animated landing pages: it asks first, picks a layout direction, builds a tested Next.js site with full SEO, and checks it before you see it.
