# snapp-kit

> 标签: build-tool, cli, esbuild, framework, javascript, jsx, kit, live-server, snapp, snapp-kit, tsx, typescript

## 简介

A global build tool for Snapp Framework. Install once, use everywhere. Zero configuration - just compile your JSX/TSX files to vanilla JavaScript.
