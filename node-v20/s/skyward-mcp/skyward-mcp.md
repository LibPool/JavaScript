# skyward-mcp

> 标签: agent, ai-agent, game, mcp, model-context-protocol, multiplayer, skyward

## 简介

Connect any AI agent to a live Skyward world over the Model Context Protocol. Framework-neutral: Claude, Cursor, Cline, the OpenAI Agents SDK, LangChain, and more.
