# string-range-tokens

> 标签: esm, ranges, slice, srtokens, string, substring, tokens, typescript, zero-dependency

## 简介

Turn strings into per-letter token arrays and rebuild words, paths and URLs from index ranges. JS and TypeScript, zero dependencies.
