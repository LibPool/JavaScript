# superhuman-newsletter-mcp

> 标签: ai, claude, digest, mcp, model-context-protocol, newsletter, superhuman

## 简介

MCP server that fetches full post content from Superhuman AI and The Code newsletters for Claude digest generation. Supports local stdio and remote HTTP deployment.
