# ssh2proxy

> 标签: http, https, proxy, socks5, ssh, tunnel

## 简介

高性能SSH隧道代理服务器，支持HTTP、HTTPS、SOCKS5代理，可选择使用上游SOCKS5代理替代SSH隧道
