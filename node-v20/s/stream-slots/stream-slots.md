# stream-slots

> 标签: declarative-partial-updates, dpu, html, out-of-order, progressive-rendering, server-streaming, slots, streaming

## 简介

Out-of-order HTML streaming via Declarative Partial Updates. Define named slots, fill them in any order, and the browser renders content as it arrives.
