# sipral

> 标签: rtp, sip, softphone, telephony, voice-agent, voip

## 简介

Sipral - Session Initiation Protocol Rust Audio Layer. The SIP stack for Node.js: accounts, registration, calls, DTMF, transfer, presence, messages and conferences over UDP, TCP or TLS, with PCM media or the machine's own devices, over the C ABI.
