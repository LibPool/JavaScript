# spawnbox

> 标签: agent, ai, apple-container, container, containerization, eve, flue, linux, orbstack, sandbox, vm

## 简介

AI agent sandbox spawner across backends: OrbStack VMs or Apple's containerization framework, with streaming exec, file IO, and drop-in connectors for Vercel Eve and Flue.
