# svg-diagram

> 标签: diagram, documentation, dsl, svg, wireframe

## 简介

Declarative SVG diagram DSL for documents: boxes, flows, swimlanes, sequences, tables, UI wireframes and screen-transition diagrams — with layout, overlap/contrast verification, lint and rule checks.
