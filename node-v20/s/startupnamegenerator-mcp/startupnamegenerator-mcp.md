# startupnamegenerator-mcp

> 标签: agent, ai, domain, mcp, model-context-protocol, naming, startup, startup-name-generator, startup-names, trademark

## 简介

MCP client for Startup Name Generator: generate startup names with an available .com, checked live, then screen them against US and EU trademarks. Bridges any MCP client to the hosted server.
