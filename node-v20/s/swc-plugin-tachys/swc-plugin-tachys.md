# swc-plugin-tachys

> 标签: compiler, jsx, performance, swc, swc-plugin, tachys, templates, vdom

## 简介

SWC-based JSX compiler for Tachys. Produces the same CompiledIR and emitted output as babel-plugin-tachys, but parses via @swc/core so SWC-based toolchains (Vite, Next.js, Bun) can use the Tachys fast path without Babel.
