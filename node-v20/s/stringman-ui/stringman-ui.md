# stringman-ui

> 标签: JavaScript

## 简介

Browser cockpit UI for controlling a cranebot3 robot: 3D telemetry visualization, live camera feeds, and manual/LeRobot-assisted control. Ships as TypeScript source for a host app's own bundler (e.g. Vite) to compile.
