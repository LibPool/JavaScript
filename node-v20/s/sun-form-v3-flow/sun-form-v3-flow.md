# sun-form-v3-flow

> 标签: JavaScript

## 简介

`sun-form-v3` 是基于 `vue3`+`tailwindcss` 所编写的低代码框架引擎，其中 UI 基于 `element-plus`，表格基于 `vxe-table`。定位为前端开发人员提供快速搭建页面、实现不仅仅是表单的数据交互。
