# smart-pdf-js

> 标签: dom-to-pdf, html2canvas, jspdf, oklch, pdf, pdf-generation

## 简介

A powerful and easy-to-use library to generate PDFs from DOM elements, with support for OKLCH colors and multi-page documents.
