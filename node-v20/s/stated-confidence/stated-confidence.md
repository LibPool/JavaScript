# stated-confidence

> 标签: agents, confidence, grounding, hallucination, llm, pydantic-ai, zod

## 简介

Make LLM agents state the confidence level and the evidential basis behind each claim. TypeScript types, display vocabulary, prompt guidance, consistency checks, and a Zod schema, generated from the same taxonomy as the Python package.
