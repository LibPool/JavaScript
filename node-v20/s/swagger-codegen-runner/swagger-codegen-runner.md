# swagger-codegen-runner

> 标签: angular, api-client, axios, code-generation, codegen, openapi, swagger, swagger-codegen, typescript

## 简介

A fully-typed TypeScript runner for swagger-codegen-cli v3. Supports all generators (API clients, server stubs, documentation) with per-generator IntelliSense for additionalProperties.
