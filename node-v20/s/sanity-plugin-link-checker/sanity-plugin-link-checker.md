# sanity-plugin-link-checker

> 标签: broken-links, content-quality, dangling-references, dead-links, link-checker, sanity, sanity-plugin, sanity-studio, seo

## 简介

Scans a Sanity dataset for dangling document references and dead external links, with a Studio tool to review and jump to the offending documents.
