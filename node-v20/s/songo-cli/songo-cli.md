# songo-cli

> 标签: board-game, cli, mancala, songo, terminal-game

## 简介

Songo — mancala d'Afrique Centrale (variante classique 2×7) jouable dans le terminal, avec IA (5 niveaux), mode Dojo et support français/anglais.
