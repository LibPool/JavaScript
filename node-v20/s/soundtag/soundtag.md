# soundtag

> 标签: 3d-printing, 3mf, bambu, cli, keychain, laser-cutting, spotify, spotify-code, stl, svg

## 简介

Turn a song link into a printable keychain tag: a 3MF with the filament change already assigned, an STL, and an SVG for laser. No upload, no signup.
