# sfu-server

> 标签: av1, broadcast, datachannel, h264, h265, media-server, mediasoup, mediasoup-alternative, mediasoup-compat, no-bindings, no-native, opus, pure-javascript, rtp, sctp, sfu, simulcast, srtp, streaming, video-call, video-conferencing, voice-call, vp8, vp9, webrtc

## 简介

Selective Forwarding Unit for Node.js. Multi-party WebRTC routing with no native bindings, no C++ toolchain, and a complete mediasoup v3 server API as a drop-in.
