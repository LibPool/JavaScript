# simple-skill-manager

> 标签: agent, claude-code, codex, gemini-cli, mcp, skill-manager, skills

## 简介

Local web app that gathers the skills scattered across your AI coding agents (Claude Code, Codex, Gemini CLI, …) into one deduplicated library, with per-agent enable/disable, MCP overview, marketplace and GitHub sync.
