# singular-dc

> 标签: animation, canvas, chart, crossfilter, d3, dimensional, svg, visualization

## 简介

A fork of dc.js; a multi-dimensional charting library built to work natively with crossfilter and rendered using d3.js

- 官网：http://dc-js.github.io/dc.js/
- 源码仓库：git+https://github.com/dc-js/dc.js.git
