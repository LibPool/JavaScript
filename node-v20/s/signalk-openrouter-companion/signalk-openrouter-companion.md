> 标签: llm, marine, openrouter, signalk-category-cloud, signalk-category-notifications, signalk-category-utility, signalk-node-server-plugin, signalk-plugin-configurator

## 简介

OpenRouter-powered LLM analyzers for Signal K: plain-prose engine, battery, and weather reports. OpenRouter API key required.
