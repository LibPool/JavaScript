# spa-router-svelte

> 标签: JavaScript

## 简介

This is a simple SPA router for [Svelte](https://svelte.dev/) . This is mostly a "test" library to get familiar with Svelte itself and npm package publishing. Source code is included in the installation to view. Also provides types and nesting `Routers`.
