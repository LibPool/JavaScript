# sparkleware-mcp

> 标签: aeon, mcp, model-context-protocol, skill-packs, sparkleware

## 简介

MCP server for the Sparkleware registry of Aeon AI agent skill packs — search, browse, compose a loadout, and simulate it (MiroShark x402) from inside any agent.
