# sql-autocomplete

> 标签: autocomplete, database, mysql, oracle, plpgsql, plsql, postgresql, sql, sqlserver, tsql

## 简介

Autocomplete recommendations for SQL statements. Supports PostgreSQL, MySQL, SQL Server and Oracle (PL/SQL) dialects.
