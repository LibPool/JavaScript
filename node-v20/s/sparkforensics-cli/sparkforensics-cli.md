# sparkforensics-cli

> 标签: apache-spark, cli, diagnostics, event-log, performance, spark, spark-history-server

## 简介

CLI to analyze Apache Spark event logs for performance bottlenecks: skew, spill, GC pressure, stragglers, and more.
