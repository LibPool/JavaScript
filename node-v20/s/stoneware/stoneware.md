# stoneware

> 标签: bun, csp, html, islands, server-first, signals, ssr, web-framework

## 简介

Bun-native, server-first web framework where HTML is the default and JavaScript is opt-in. Islands for interactivity, signals inside islands, security on before you configure anything.
