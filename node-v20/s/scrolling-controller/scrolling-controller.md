# scrolling-controller

> 标签: dropdowns, gallery

## 简介

> * 下拉列表滚动控制器 > * 支持控制每次滚动落点相对位置与上一落点相同 > * 支持任意高度的着点元素，或者不同高度的着点元素 > * 支持循环选中
