# skelkit

> 标签: auto-skeleton, content-loader, css, html, loading, placeholder, shimmer, skeleton, skeleton-loading, ui, ux, vanilla-js, zero-config

## 简介

Zero-config automatic skeleton loading for any frontend. Just add data attributes and your UI gets beautiful shimmer placeholders.
