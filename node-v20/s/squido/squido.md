# squido

> 标签: blog, bootstrap, builder, cli, cms, dev, documentation, ejs, fast, framework, generator, handlebars, html, pug, squido, static, website

## 简介

A dead-simple static HTML website generator for super fast static websites which are easier to develop, more secure and dirt cheaper to host.
