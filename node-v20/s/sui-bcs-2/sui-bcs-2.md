# sui-bcs-2

> 标签: JavaScript

## 简介

This tool generates BCS types for the Sui blockchain. It fetches the Move modules of a specified package over the [Sui GraphQL API](https://docs.sui.io/references/sui-graphql) and creates the corresponding BCS type definitions in JavaScript.
