# strapi-plugin-uni-storage

> 标签: cloudflare, minio, provider, r2, s3, storage, strapi, strapi-plugin, upload

## 简介

Universal S3-compatible storage for Strapi 5 (AWS S3, Cloudflare R2, MinIO): upload provider + admin tools (status, migrate local files to bucket, transfer between buckets, change public domain).
