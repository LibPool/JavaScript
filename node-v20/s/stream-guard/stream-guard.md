# stream-guard

> 标签: backpressure, circuit-breaker, download, duplex, fs, heap-protection, http, memory-leak, monitoring, nodejs, oom, pipeline, production, readable, reliability, safe-streams, security, slowloris, stall-detection, stream, throughput, timeout, upload, writable, zero-dependency, zombie-connection

## 简介

The circuit breaker for Node.js streams. Prevent memory leaks, slow loris attacks, and zombie connections. Enforces timeouts, heap limits, and stall detection with zero dependencies.
