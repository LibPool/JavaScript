# shader-gallery

> 标签: JavaScript

## 简介

Vendor a shader.gallery shader into your project: `npx shader-gallery add <slug>`. Thin front-door to @shader-gallery/cli (the catalog itself is served from the CDN, not bundled here).

## 官网

- 官网：https://shader.gallery
- 源码仓库：git+https://github.com/shader-gallery/shaders.git
- npm 页面：https://www.npmjs.com/package/shader-gallery

## 获取地址

- npm 安装：`npm install shader-gallery`
- npm registry：https://registry.npmjs.org/shader-gallery
- Node 要求：>=18
