# salty-cli

> 标签: agents, ai, cli, crm, mcp, rest, salty, salty-crm, webhooks

## 简介

The CLI for Salty — the CRM for AI agents. Login, manage API keys, people, companies, deals, schema, search, webhooks, usage, and tail logs from the terminal.
