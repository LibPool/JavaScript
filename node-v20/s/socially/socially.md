# socially

> 标签: email-lookup, instagram, linkedin, mcp, osint, sdk, social-media, tiktok, trending, username-search, youtube

## 简介

Official TypeScript client for socially.run — public social profiles, username search, email lookup and trends over a flat REST API, with honest found / not found / undecided answers.
