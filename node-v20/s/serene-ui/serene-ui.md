# serene-ui

> 标签: components, design-system, react-native, social, ui

## 简介

Serene UI is a lightweight and versatile design system built for social-focused applications. It emphasizes simplicity, intuitive components, and warm, inviting colors that foster human connection and engagement. Designed for reuse across multiple project
