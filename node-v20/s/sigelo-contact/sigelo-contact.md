# sigelo-contact

> 标签: agent-identity, agent-messaging, ai-agents, did, end-to-end-encryption, ml-kem, mqtt, post-quantum, sigelo

## 简介

Agent contacts for sigelo identities: invite codes, a contact store, end-to-end encrypted envelopes with hybrid post-quantum key agreement, and an MQTT carrier. Client code (MIT); the relay server is csigelo/sigelo-relay (AGPL-3.0).
