# sheetlang

> 标签: excel, expression, formula, formulas, json-logic, json-logic-engine, parser, rules-engine, spreadsheet

## 简介

Excel-like formula language that compiles to JSON Logic (via grammatik) and executes on json-logic-engine — over arbitrary data, not just a grid.
