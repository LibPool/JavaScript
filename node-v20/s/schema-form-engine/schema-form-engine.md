# schema-form-engine

> 标签: form, form-builder, headless, json-schema, react, react-hook-form, shadcn, zod

## 简介

Headless, JSON-driven React form engine. Declarative schema compiled to Zod + React Hook Form, rendered through an injectable component adapter (shadcn-ready).
