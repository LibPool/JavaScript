# swls-wasm

> 标签: JavaScript

## 简介

The [Semantic Web Language Server](https://github.com/SemanticWebLanguageServer/swls) (Turtle, TriG, SPARQL, JSON-LD) compiled to WebAssembly, plus thin helpers for running it as a worker. Built with `wasm-pack --target web`, so it loads in browsers, bund
