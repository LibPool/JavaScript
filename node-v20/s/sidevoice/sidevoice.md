# sidevoice

> 标签: claude-code, cli, codex, coding-agent, cursor, mcp, sidevoice, speech, voice

## 简介

Give your coding agent a voice: Sidevoice turns your Claude Code, Codex or Cursor conversation into a voice call. Run `npx sidevoice install` on the machine where your agents run.
