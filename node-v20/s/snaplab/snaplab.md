# snaplab

> 标签: chromium, html to pdf, og image, open graph, pdf, screenshot, screenshot api, snaplab, website screenshot

## 简介

Zero-dependency TypeScript client for the snaplab rendering API — screenshots, PDFs and OG images from one call.
