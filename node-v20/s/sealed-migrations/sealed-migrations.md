# sealed-migrations

> 标签: checksum, database, dev-migrations, mariadb, migration-runner, migrations, mysql, schema, sql

## 简介

Checksum-tracked SQL migrations for MySQL/MariaDB with a dev-first lifecycle: migrations start unnumbered as dev_<slug>/ and are sealed to NNN_<slug>/ right before merge, so parallel branches never collide on numbers.
