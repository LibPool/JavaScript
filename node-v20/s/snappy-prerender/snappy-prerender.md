# snappy-prerender

> 标签: hydration, playwright, prerender, prerendering, react, seo, spa, ssg, static-site, vite

## 简介

Drop-in prerendering for existing single-page apps. Renders your built app in a real browser, writes static HTML per route, reports React hydration mismatches, and optimises the output with critical CSS, link hints and cached AJAX state.
