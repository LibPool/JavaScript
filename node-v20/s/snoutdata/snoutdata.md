# snoutdata

> 标签: agent, ai-agent, cli, database, devops, hosted-database, mcp, migrations, model-context-protocol, postgres, postgresql, serverless-postgres, snoutdata

## 简介

Hosted Postgres from a terminal or an agent. Create a database, get a DATABASE_URL, run migrations, and serve the same operations to an AI agent over MCP.
