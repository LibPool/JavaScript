# sea-blob-to-32bit

> 标签: 32-bit, blob, node, postject, sea, single-executable, size_t, win32, x86

## 简介

Convert a Node.js single executable (SEA) blob built on a 64-bit machine so it works in a 32-bit Node (8-byte size_t lengths -> 4-byte)
