# streamlined-gantt

> 标签: critical-path, gantt, htmx, programme, schedule, web-component

## 简介

Framework-free JavaScript Gantt chart and scheduling library: working-day calendars, critical path, payment milestones, accessible editing and an event API built for backend integration.
