# stem-mcp

> 标签: education, katex, latex, mathjax, mcp, slides, stem, sympy

## 简介

MCP server for STEM teaching: rendered math (KaTeX/MathJax + mhchem), SymPy checks, formula library, slide decks, channels, RBAC.
