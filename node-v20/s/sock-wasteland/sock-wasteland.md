# sock-wasteland

> 标签: Arma 3, Wasteland, persistency, sock-rpc, sock-rpc-stats, stats

## 简介

This is a set of Node.js scripts that can be used for managing Arma 3 Wasteland servers that use sock-rpc-stats module for persistence.
