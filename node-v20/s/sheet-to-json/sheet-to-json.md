# sheet-to-json

> 标签: cli csv to json, cli excel to json, command line csv to json, command line excel to json, csv, csv-reader, csv-streaming-parser, csv-to-json, excel, excel-reader, excel-streaming-parser, excel-to-json, json, large-files, parse-csv-to-json, parse-excel-to-json, parser, reader, sheet-to-json, stream-csv-to-json, stream-excel-to-json, streaming, xlsx

## 简介

A streaming library that converts Excel (.xlsx) and CSV files into JSON objects — row by row, sheet by sheet. It streams the file and emits each row as a plain JavaScript object via events, so it can handle large files without loading everything into memo
