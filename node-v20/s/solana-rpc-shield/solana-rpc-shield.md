# solana-rpc-shield

> 标签: failover, jito, opentelemetry, reliability, rpc, solana, transport, web3js

## 简介

Resilient RPC + transaction-reliability SDK for Solana dApps — health-scored multi-endpoint failover, Jito relay routing, dynamic fees, OpenTelemetry, and a diagnostics CLI. Built on @solana/web3.js v2 pluggable transports.
