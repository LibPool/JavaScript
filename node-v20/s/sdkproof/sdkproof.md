# sdkproof

> 标签: agents, ai, api-drift, benchmark, codegen, drift, llm, sdk, tsc, typescript

## 简介

Score how often an AI model writes library code that does not compile. Give it a package name, it writes real tasks, compiles every answer against the real installed package with tsc, and reports what broke.
