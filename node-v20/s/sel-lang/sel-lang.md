# sel-lang

> 标签: decimal, exact-arithmetic, expression-language, interpreter, isomorphic, rule-engine, rules, shared-validation, validation

## 简介

A small expression language for validation rules — one rule file evaluates identically on JavaScript, PHP, Python, C++23 and Common Lisp. Exact decimal arithmetic, no floating point, no truthiness.
