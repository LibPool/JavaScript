# storybook-events-inspector

> 标签: debugging, events, mcp, storybook-addon, web-components

## 简介

A Storybook panel (and standalone MCP server) that captures every custom event dispatched in a story with zero registration, flags shared names/retargeted origins/undocumented/not-composed events, and can dispatch a synthetic event back into the canvas.
