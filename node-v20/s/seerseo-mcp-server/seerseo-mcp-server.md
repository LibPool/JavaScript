# seerseo-mcp-server

> 标签: entityos, mcp, model-context-protocol, roblens, seerseo, seo

## 简介

MCP server for the SEER (SEER) API - exposes the EntityOS, DiagnosticOS, DriftOS, PageOS, BacklinkOS, CredentialOS, GBPOS, VisionOS, ChatGPT-OS and combined diagnostic tools to MCP clients.
