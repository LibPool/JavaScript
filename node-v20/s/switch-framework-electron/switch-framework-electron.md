# switch-framework-electron

> 标签: desktop, electron, switch-framework

## 简介

Electron desktop helpers for the Switch Framework ecosystem — child servers, dynamic ports, IPC, splash bootstrap, and window controls for building Electron apps with switch-framework and switch-framework-backend
