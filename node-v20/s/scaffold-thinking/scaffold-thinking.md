# scaffold-thinking

> 标签: adr, anthropic, cli, decision-making, llm, openai, prompt-engineering, typescript

## 简介

Four-stage thinking layer (Frame → Clarify → Diverge → Decide) that turns a vague engineering problem into genuinely different solution options + a Markdown decision brief. Provider-agnostic.
