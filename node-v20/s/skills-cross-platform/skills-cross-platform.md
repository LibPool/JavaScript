# skills-cross-platform

> 标签: JavaScript

## 简介

这是一个基于 **Model Context Protocol (MCP)** 的技能管理服务，专为 Agent 扩展能力而设计。它模拟了 Claude 的技能扩展机制，允许 Agent 通过标准化的 `SKILL.md` 指令文件来获取特定领域的专业知识。
