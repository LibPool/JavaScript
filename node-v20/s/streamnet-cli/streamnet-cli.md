# streamnet-cli

> 标签: agent-native, cli, korvex, mcp, opensubtitles, streaming, subtitles, torrent, vlc, webtorrent

## 简介

Torrent search + in-process WebTorrent streaming to native VLC with hash-based subtitles. Agent-native by design.
