# svelte-fusioncharts

> 标签: charting-library, fusioncharts, fusionmaps, fusiontime, fusionwidgets, powercharts, svelte, svelte-fusioncharts, svelte-wrapper, timeseries, wrapper

## 简介

A simple and lightweight official Svelte component for FusionCharts JavaScript charting library. `svelte-fusioncharts` enables you to add JavaScript charts in your Svelte application or project without any hassle. Works with both Svelte 4 and Svelte 5.
