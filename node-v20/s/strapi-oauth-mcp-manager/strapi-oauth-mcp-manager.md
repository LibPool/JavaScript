# strapi-oauth-mcp-manager

> 标签: admin-token, ai, authentication, chatgpt, claude, mcp, model-context-protocol, oauth, oauth2, pkce, plugin, strapi

## 简介

OAuth 2.1 authorization server for Strapi's official MCP server (/mcp). Lets Claude, ChatGPT, and other MCP clients connect with a Strapi admin login instead of a pasted token.
