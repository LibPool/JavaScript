# schwi

> 标签: browser, bun, client, deno, fetch, http, native, node, react-native, tauri, undici

## 简介

An HTTP client that uses native APIs on each JS runtimes, supporting Browsers, Node.js, Deno, Bun, React Native and Tauri.
