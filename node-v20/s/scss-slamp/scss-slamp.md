# scss-slamp

> 标签: clamp, css, css-clamp, css-functions, fluid-scaling, fluid-typography, frontend, responsive-design, responsive-typography, sass, scss, typography, web-design

## 简介

A small Sass/SCSS utility function to generate linear, fluid responsive values with CSS clamp() for typography, spacing and layout scaling.
