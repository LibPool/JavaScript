# sqlite-crud-gen

> 标签: auto-generate, crud, sqlite, typescript, zod

## 简介

Define the shape of your sqlite tables in a tables.ts file, and this tool will use it to generate schema files and a crud.ts file with all the basic CRUD operations against each table in the database.
