# scrawl-core

> 标签: diagram-as-code, diagrams, hand-drawn, llm, mermaid-alternative, rough-js, svg

## 简介

Parse and render scrawl diagrams to hand-drawn SVGs. Zero-coordinate, line-oriented diagram format — 57% fewer tokens than Mermaid.
