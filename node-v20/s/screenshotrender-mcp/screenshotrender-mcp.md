# screenshotrender-mcp

> 标签: ai, claude, cursor, llm, mcp, model-context-protocol, screenshot, screenshot-api, screenshotrender, website-screenshot

## 简介

MCP server for ScreenshotRender — let Claude, Cursor, and any MCP client capture website screenshots through the ScreenshotRender API.
