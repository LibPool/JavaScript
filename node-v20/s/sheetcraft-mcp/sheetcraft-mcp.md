# sheetcraft-mcp

> 标签: cli, google-sheets, google-workspace, mcp, mcp-server, model-context-protocol, sheets, spreadsheet

## 简介

SheetCraft MCP — reliable, token-efficient Google Sheets MCP server + CLI for AI agents. 32 tools, teaching errors, capped reads, dual auth (OAuth + service account).
