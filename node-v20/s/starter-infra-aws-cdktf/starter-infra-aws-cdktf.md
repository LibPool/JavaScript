# starter-infra-aws-cdktf

> 标签: cdk, cdktf

## 简介

Templates and general operational guidance that can be shared with devops and development teams. As part of this project, base templates are provided as a Construct using which we can provison infrastructure for applications. The tool being used is CDKTF
