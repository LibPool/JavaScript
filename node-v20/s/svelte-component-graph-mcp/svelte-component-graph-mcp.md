# svelte-component-graph-mcp

> 标签: claude, components, dependencies, graph, mcp, model-context-protocol, svelte, sveltekit

## 简介

MCP server exposing Svelte/SvelteKit component dependency graphs over stdio — the companion to the Svelte Component Visualizer VS Code extension.
