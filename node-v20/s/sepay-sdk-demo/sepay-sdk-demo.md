# sepay-sdk-demo

> 标签: JavaScript

## 简介

SePay SDK giúp bạn dễ dàng nhận payload từ WebHook của SePay, đồng thời tương tác với USER API. SDK hỗ trợ kiểm tra giao dịch và danh sách ngân hàng đã liên kết với SePay.
