# stellar-web-sdk

> 标签: aquarius, axelar, defi, dex, near-intents, soroban, soroswap, stellar, stellarbroker, swap

## 简介

Self-contained Stellar swap SDK: provider adapters (StellarBroker, Soroswap, Aquarius, Stellar DEX, NEAR, Axelar ITS), quote fetching and normalization, route construction, provider fan-out and best-output route selection, with client-native execution.
