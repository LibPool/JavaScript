# songfinder-mcp

> 标签: ai-agent, audio-analysis, bpm-detection, camelot-wheel, claude, dj-tools, harmonic-mixing, isrc, key-detection, mcp, mcp-server, modelcontextprotocol, music-metadata, music-recognition, shazam-alternative, song-identification

## 简介

MCP server for music recognition and audio analysis — identify any song from a URL or audio file, then get its BPM, musical key, Camelot code, and harmonically compatible tracks. Powered by Song Finder (songfinder.dev).
