# slither-charts

> 标签: canvas, charts, dataviz, dither-kit, meme, ouroboros, react, snakes, sparkline, zero-legs

## 简介

Composable React charts where every mark is a live snake. Line snakes, bar cobras, an ouroboros pie, a pit-of-snakes area, coiled-hatchling scatter, medusa radials, tail-chasing gauges, candlestick vipers, and worm sparklines. An unhinged homage to dither
