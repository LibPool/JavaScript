# @alikhalilll/ui

> 标签: components, headless, nuxt, phone-input, reka-ui, shadcn, tel-input, ui, vaul-vue, vue, vue3

## 简介

Headless, shadcn-vue style Vue 3 component library — every component is its own importable subpath (`@alikhalilll/ui/tell-input`, `@alikhalilll/ui/popover`, …) so users pay only for what they actually use.
