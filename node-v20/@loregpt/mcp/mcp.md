# @loregpt/mcp

> 标签: agents, ai, context, coordination, mcp, memory, model-context-protocol, multi-agent, read-your-writes

## 简介

Model Context Protocol server for Lore — coordination memory for multi-agent AI systems. Exposes create_run, memory_write, and memory_pack as MCP tools over stdio.
