# @transmitt0r/mycelium-index

> 标签: hybrid-search, rag, rrf, semantic-search, sqlite-vec, vector-search

## 简介

Local-first semantic index: sqlite-vec vector store, incremental content-hash sync, and hybrid lexical/semantic search via Reciprocal Rank Fusion.
