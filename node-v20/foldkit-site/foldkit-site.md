# foldkit-site

> 标签: effect, foldkit, navigation, routing, site

## 简介

The deployed route topology of a Foldkit application: stable route nodes, their hierarchy, typed targets, and per-node metadata, compiled to the Foldkit Router, Surface, and Bundle primitives the runtime already runs.
