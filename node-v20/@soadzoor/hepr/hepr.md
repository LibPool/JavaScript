# @soadzoor/hepr

> 标签: floorplan, pdf, renderer, three, threejs, vector, webgl, webgpu

## 简介

Highly-Efficient-PDF-Renderer is a GPU-first PDF renderer for large technical documents, floorplans, books, and more, using the latest technologies and various tricks to achieve high performance and visual fidelity.
