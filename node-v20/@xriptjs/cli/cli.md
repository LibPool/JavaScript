# @xriptjs/cli

> 标签: cli, extensibility, modding, toolchain, xript

## 简介

Unified CLI for the xript ecosystem — validate, generate types, generate docs, scaffold projects, sanitize fragments, scan annotations, run mods, and serve the same capabilities to agents over MCP.
