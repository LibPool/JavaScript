# @axiomify/native

> 标签: axiomify, high-performance, http-server, native-adapter, nodejs, sse, uwebsockets, uws, websocket

## 简介

uWebSockets.js adapter for Axiomify — highest-throughput transport. HTTP, native WebSocket, SSE, graceful shutdown, SO_REUSEPORT clustering.
