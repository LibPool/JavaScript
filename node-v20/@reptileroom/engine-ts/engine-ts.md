# @reptileroom/engine-ts

> 标签: interpreter, python, s-expression, sandbox, untrusted-code, user-scripting, web-worker

## 简介

Sandboxed TypeScript evaluator for the reptileroom s-expression dialect — runs the JSON form tree emitted by the Python parser, in Node or the browser.
