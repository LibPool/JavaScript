# @activity-com/auto-pop

> 标签: activity maker

## 简介

```bash yarn start              # 启动调试，Editor & 页面 yarn start --list       # 启动调试，自动打开活动列表页 yarn start -d           # 启动调试，禁止自动打开浏览器（配合 vscode debugger 调试时推荐） yarn start --editor     # 仅启动 editor 调试 yarn start --node       # 仅启动 SSR 页面调试
