# @nxgt/playwright

> 标签: accessibility, axe, csp, e2e, fixtures, hydration, mock-server, msw, page-object, playwright, pwa, react-router, screenshots, service-worker, storybook, vitest

## 简介

The Playwright boilerplate every app repeats, written once: a shared config, BasePage and FormPage, login and storage-state fixtures, msw network fixtures, hydration-aware navigation and fills, settled-page waits, axe accessibility checks, Content-Securit
