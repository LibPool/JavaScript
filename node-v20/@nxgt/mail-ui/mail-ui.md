# @nxgt/mail-ui

> 标签: components, email, maizzle, material, tailwindcss, vue

## 简介

E-mail components for a Maizzle project in the style of @nxgt/material-vue: NxLayout, NxButton, NxCard, NxBadge, NxAlert… with its variants, colours and tokens, rendered with tables and inlined styles.
