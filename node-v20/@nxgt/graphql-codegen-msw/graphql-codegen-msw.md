# @nxgt/graphql-codegen-msw

> 标签: codegen, graphql, graphql-codegen, mock, msw, typescript, validation, zod

## 简介

A graphql-codegen plugin that writes one typed msw 3 handler per named query and mutation, its variables checked by the Zod schemas of @nxgt/graphql-codegen-zod and an invalid input answered as your API answers it
