# @nxgt/janus-webhooks

> 标签: authentication, identity, janus, standard-webhooks, typescript, webhooks

## 简介

Signed webhooks for @nxgt/janus user events: Standard Webhooks signatures, retries with backoff through a pluggable durable queue, rotating secrets, and deliveries that run out reported — never dropped in silence
