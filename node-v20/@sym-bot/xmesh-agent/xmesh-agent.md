# @sym-bot/xmesh-agent

> 标签: agent-to-agent, autonomous-agent, cat7, collective-intelligence, mesh-memory-protocol, mmp, svaf, xmesh, xmesh-agent

## 简介

The autonomous agent runtime for xmesh — wake-on-admission reasoning with wake-budget, cycle detection, token cap, and approval gates, agent-to-agent over the open mesh.
