# @blackbelt-technology/pi-dashboard-app-kit

> 标签: oidc, pi-dashboard, pkce, websocket

## 简介

Client plumbing for a standalone SPA on its own origin that talks to a pi-dashboard host: runtime endpoint config, OIDC PKCE sign-in, bearer transport, single-use WebSocket tickets and a reconnecting socket.
