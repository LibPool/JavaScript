# @blackbelt-technology/pi-system-one

> 标签: JavaScript

## 简介

System-1 decision adapter: predict() over choice/score/noul via a user-controlled registry of typed decision backends (hosted, managed-local, chat-role fallback). Node built-ins only; usable from pi extensions and the dashboard server.
