# @blackbelt-technology/pi-dashboard-craft-web-plugin

> 标签: JavaScript

## 简介

Dashboard plugin that edits Office documents (.docx, and later .xlsx/.pptx) in the editor pane by embedding the matching ArtCraft web build (WordCraft first) in a sandboxed opaque-origin frame as an editor-pane-file-handler edit mode. Builds are provision
