# dbml-mcp

> 标签: dbml, mcp, model-context-protocol, mysql, postgres, schema, sqlserver

## 简介

An MCP server that lets AI agents import a PostgreSQL, MySQL or SQL Server schema as DBML, compare DBML with a live database, validate DBML and convert between DBML and SQL.
