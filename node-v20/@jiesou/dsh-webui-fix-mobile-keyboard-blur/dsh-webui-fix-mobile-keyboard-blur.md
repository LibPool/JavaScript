# @jiesou/dsh-webui-fix-mobile-keyboard-blur

> 标签: JavaScript

## 简介

On soft-keyboard (touch) devices, block dsh-webui's programmatic composer auto-focus at the source when a session is entered, so the soft keyboard stays down until the user taps the input. Hard-keyboard devices are untouched.
