# @baubap/mlflow

> 标签: category/infrastructure, kind/native, machine-learning, mlflow, mlops, model-registry

## 简介

A Pulumi provider to manage MLflow (2.x and 3.x) experiments, model registry and access control via the MLflow REST API.
