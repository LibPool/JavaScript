# @probabl/pi-ask-user-question

> 标签: ask-user-question, pi-extension, pi-package

## 简介

Pi extension. Structured questionnaire tool (ask_user_question) that scales past 4 questions and 4 options — fork of @juicesharp/rpiv-ask-user-question with configurable question/option caps, a windowed tab bar and scrolling option lists.
