# @mulmocast/beat-editor

> 标签: beat, deck, editor, mulmocast, mulmoscript, slide, tailwind, vue

## 简介

Vue 3 components for editing MulmoScript beats live in the browser — every beat type renders as a div, and every editor is swappable
