# @evoliv/aidr-agent

> 标签: agent-identity, ai-agents, aiaf, aidr, http-signatures, rfc9421, vercel-ai-sdk

## 简介

A verifiable AIAF identity for an AI agent in one line: enroll once with a token, then sign every request to the sites it may reach. Includes a Vercel AI SDK integration.
