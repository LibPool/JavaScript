# @dnsofmoney/a2a-protocol-core

> 标签: a2a, ai-agents, algorand, fas-1, iso20022, pay-uri, payments, usdc, verifiable-credentials, x402, xrpl

## 简介

Open, deterministic protocol core for the DNS of Money A2A payment surface — pay: addressing, canonical hashing, semantic normalization, and a payment-hook client. TypeScript port of the Python a2a-protocol-core, with byte-identical canonical hashes.
