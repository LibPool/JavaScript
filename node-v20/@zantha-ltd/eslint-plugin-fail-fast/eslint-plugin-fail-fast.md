# @zantha-ltd/eslint-plugin-fail-fast

> 标签: eslint, eslint-plugin, eslintplugin, fail-fast, zantha

## 简介

ESLint rules enforcing fail-fast error handling — nine rules covering silent catch swallows, error-to-null conversions, context-stripping re-throws, generic 5xx API responses (Next.js + Fastify), unguarded response parses, error-surface masking, no-else i
