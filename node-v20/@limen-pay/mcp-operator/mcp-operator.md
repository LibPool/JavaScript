# @limen-pay/mcp-operator

> 标签: anthropic, claude, limen, mcp, model-context-protocol, oauth, x402

## 简介

MCP server exposing the Limen admin API (transactions, endpoints, API keys, billing, analytics) as tools for LLM clients like Claude Desktop and Claude Code.
