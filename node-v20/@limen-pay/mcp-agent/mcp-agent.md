# @limen-pay/mcp-agent

> 标签: agentic, base, claude, limen, mcp, model-context-protocol, usdc, x402

## 简介

MCP server that lets an LLM-controlled wallet discover and pay for x402-priced APIs through Limen — quote, sign EIP-712 authorizations, and fetch the underlying response with one tool call.
