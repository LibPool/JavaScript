# @limen-pay/agent

> 标签: agent, agentic-payments, ai-agents, base, client, micropayments, paywall, solana, usdc, x402

## 简介

Client SDK for x402 paywalled APIs. Signs EIP-3009 (Base) and SPL+memo (Solana) USDC payments locally; agent owns the key.
