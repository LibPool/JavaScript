# @bgroup/jview

> 标签: JavaScript

## 简介

El componente `JView` es el componente de listado y tablas dinámicas que se encarga de visualizar datos de manera estructurada. Su importancia radica en su capacidad para gestionar y mostrar conjuntos de datos complejos en un formato de listado y tablas
