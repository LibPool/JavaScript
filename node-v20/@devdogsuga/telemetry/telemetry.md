# @devdogsuga/telemetry

> 标签: JavaScript

## 简介

Shared Sentry constants, options builder, scrubbers, and alert() for every service that reports telemetry. Standalone by design — devtools bundles this as a regular dep so error reporting works with no/broken repo.
