# @octa-labs/create-react-package

> 标签: JavaScript

## 简介

`create-react-package` is a CLI tool designed to simplify the creation of new React component projects. It sets up a new project by cloning a predefined template, customizing the `package.json`, and installing dependencies, making it easy to start develop
