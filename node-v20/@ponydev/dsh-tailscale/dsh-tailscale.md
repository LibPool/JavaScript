# @ponydev/dsh-tailscale

> 标签: deepseek-harness, dsh, dsh-plugin, remote-access, serve, tailnet, tailscale

## 简介

DSH Web 插件：把 DSH Web GUI 发布到 tailnet（远程入口），并把 tailnet 设备与可达性暴露为 ctx.tailscale 服务，供其他插件消费
