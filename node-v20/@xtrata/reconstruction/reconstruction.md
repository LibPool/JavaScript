# @xtrata/reconstruction

> 标签: bitcoin, clarity, inscriptions, nft, sbtc, sip-009, sip-010, stacks, xtrata

## 简介

Strict byte reconstruction for Xtrata inscriptions: batch chunk reads, fallback sources, diagnostics, and incremental hash verification.
