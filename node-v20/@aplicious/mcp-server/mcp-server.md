# @aplicious/mcp-server

> 标签: api, aplicious, mcp, model-context-protocol

## 简介

MCP server for APlicious — gives AI assistants (Claude, Cursor, Windsurf) direct access to 125+ live API endpoints across 10 namespaces: wellness, food, recipes, sports, education, finance, legal, property, jobs, and tools.
