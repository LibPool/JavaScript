# @springtype-org/rollup-plugin-ts

> 标签: browserslist, bundling, declaration, declarations, merging, plugin, rollup, treeshaking, typescript

## 简介

A Typescript Rollup plugin (fork of @wessberg/rollup-plugin-ts) that bundles declarations and respects Browserslists: tsc-only, no babel support/dependencies
