# @ek-aiot/2d-editor

> 标签: JavaScript

## 简介

2D 编辑器组件库（Vue 3 + Pinia + Konva）。支持拖拽入画、属性编辑、设备绑定与测点挂载、HTTP 数据源配置、`bindingValues` 运行时值渲染、JSON 导入导出、PNG 导出，以及 `edit / preview / display` 三态。
