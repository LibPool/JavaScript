# @estiva-app/protocol

> 标签: buzz, estiva, nip-01, nip-19, nip-98, nostr

## 简介

The Estiva wire format: Buzz-shaped Nostr event builders, NIP-01 ids, NIP-19 naddr, NIP-98 HTTP auth, and the relay clients. Speaks the protocol; interprets nothing.
