# @haimaker/connect

> 标签: anthropic, claude-code, cli, cline, codex, haimaker, hermes, inference, llm, openai-compatible, opencode, pi

## 简介

Pure-TypeScript npx CLI that writes each supported coding agent's native config so it talks directly to api.haimaker.ai, then exits. No router, no proxy, no telemetry.
