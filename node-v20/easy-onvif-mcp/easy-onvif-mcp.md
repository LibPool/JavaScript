# easy-onvif-mcp

> 标签: dart, ip-camera, mcp, model-context-protocol, nvr, onvif, ptz, rtsp

## 简介

MCP server for ONVIF IP cameras and NVRs, compiled from the Dart easy_onvif stack with dart2js. Runs over stdio: device information, media profiles, RTSP and snapshot URIs, PTZ control, and WS-Discovery.
