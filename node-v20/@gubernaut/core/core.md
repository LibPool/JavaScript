# @gubernaut/core

> 标签: agent-loop, agents, cost-control, deterministic, edge, governance, guardrails, gubernaut, llm, wasm

## 简介

The Gubernaut controller, in-process, for JavaScript. A deterministic runtime governor for LLM agents that reads three bounded numbers and no tokens, and hard-stops runaway loops. Embedded wasm, no dependencies, runs in Node, Deno, Bun, workerd and the br
