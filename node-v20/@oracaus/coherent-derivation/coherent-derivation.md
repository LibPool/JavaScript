# @oracaus/coherent-derivation

> 标签: async, atomic-commit, coherence, compute, react, react-hook, snapshot, streaming, trading-ui, web-worker

## 简介

A React hook for heavy async compute against streaming inputs. Emits (input, output) tagged to the same snapshot — prevents incoherent frames when async derivation outlasts the render.
