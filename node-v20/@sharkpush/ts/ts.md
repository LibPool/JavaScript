# @sharkpush/ts

> 标签: browser, javascript, messaging, node, notifications, push-notifications, realtime, sdk, sharkpush, sse, typescript, websocket

## 简介

Official TypeScript SDK for the SharkPush REST API. Supports identities, devices, events, the objective-based communicate() API, and real-time SSE/WebSocket subscriptions in Node.js and modern browsers.
