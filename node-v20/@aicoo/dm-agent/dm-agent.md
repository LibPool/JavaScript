# @aicoo/dm-agent

> 标签: agent, agent-to-agent, aicoo, approval, claude-code, local-agent

## 简介

Let a teammate ask your local agent. They DM you on Aicoo, a Claude Code session on your machine answers, and every file it opens is approved by you, one call at a time.
