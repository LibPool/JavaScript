# @skit/wxmini-promisify

> 标签: MicroMessager, MiniGame, MiniProgram, Wechat, Wechat-MiniGame, Wechat-MiniProgram, Weixin, Weixin-MiniGame, Weixin-MiniProgram, promise, promisify, weapp, wxapp, 小程序, 微信, 微信小游戏, 微信小程序

## 简介

为微信小程序、小游戏提供 TypeScript 支持，同时将其基于回调函数的异步 API 转化为 Promise 形式。
