# @orpc-ws/oidc-pkce

> 标签: JavaScript

## 简介

Browser-side OIDC + PKCE auth helper. Vanilla TS, framework-free. Uses OIDC Discovery (RFC 8414) — works against any compliant provider (Keycloak, Auth0, Okta, Cognito, ...). Produces a TokenProvider structurally compatible with @orpc-ws/client.
