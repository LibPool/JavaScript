# @klunqlabs/klunq-widget

> 标签: agent, ai, browser-automation, chatbot, embeddable, langchain, llm, preact, web-component, widget

## 简介

Embeddable AI chat widget built with Preact, Tailwind CSS v4, LangChain, and TypeScript. Designed to be dropped into any existing web page with zero side effects.
