# @guardianstack/guardianjs-free

> 标签: browser, device fingerprint, fingerprint, fingerprinting, fraud, fraud detection, fraud prevention, guardian, visitor id

## 简介

Open-source, purely client-side browser fingerprinting library that computes a Guardian anchor-based visitor identifier.
