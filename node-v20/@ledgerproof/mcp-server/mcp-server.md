# @ledgerproof/mcp-server

> 标签: ai-transparency, article-50, bitcoin, eu-ai-act, ledgerproof, mcp, model-context-protocol, provenance, scitt

## 简介

Model Context Protocol server for LedgerProof — issue and verify EU AI Act Article 50 transparency receipts (implements the IETF SCITT architecture drafts, Bitcoin-anchored) from any MCP client. Wraps @ledgerproof/sdk.
