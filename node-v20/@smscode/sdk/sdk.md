# @smscode/sdk

> 标签: 2fa, api-client, online-sms, otp, phone-verification, receive-sms-online, sdk, sms, sms-otp, sms-verification, smscode, temporary-phone-number, typescript, virtual-number, virtual-phone-number

## 简介

Official TypeScript/JavaScript SDK for the SMSCode virtual number API — rent temporary phone numbers and receive OTP/SMS verification codes programmatically.
