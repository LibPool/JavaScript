# @push.rocks/smartantivirus

> 标签: ClamAV, Docker, Node.js, antivirus, buffer scanning, data protection, file scanning, in-memory scanning, network security, security, software testing, stream scanning, virus scanning

## 简介

A Node.js package providing integration with ClamAV for anti-virus scanning, facilitating both Docker containerized management and direct connection to a ClamAV daemon.
