# @push.rocks/smartdns

> 标签: ACME, Cloudflare, DNS, DNS Server, DNS management, DNS records, DNS resolution, DNSSEC, Domain Propagation, Feature Flagging, Google DNS, HTTPS DNS, Let's Encrypt, Node.js, SSL Certificates, TypeScript, UDP DNS

## 简介

A robust TypeScript library providing advanced DNS management and resolution capabilities including support for DNSSEC, custom DNS servers, and integration with various DNS providers.
