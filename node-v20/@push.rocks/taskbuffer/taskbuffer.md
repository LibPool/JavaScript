# @push.rocks/taskbuffer

> 标签: TypeScript, debounced tasks, distributed coordination, parallel tasks, task buffering, task chains, task dependencies, task execution, task management, task scheduling

## 简介

A flexible task management library supporting TypeScript, allowing for task buffering, scheduling, and execution with dependency management.
