# @push.rocks/smarts3

> 标签: AWS S3 Compatibility, Bucket Management, CI/CD Integration, Cloud Storage, Developer Onboarding, Development Tool, File Storage, File Upload, Local Development, Local S3, Node.js, S3 Endpoint, S3 Mock Server, S3 Simulation, Testing, TypeScript

## 简介

A Node.js TypeScript package to create a local S3 endpoint for simulating AWS S3 operations using mapped local directories for development and testing purposes.
