# @push.rocks/smartclickhouse

> 标签: CRUD, ClickHouse, MergeTree, ODM, ReplacingMergeTree, TypeScript, analytics, builder pattern, bulk insertion, data management, database, fluent API, observables, query builder, real-time data, schema evolution, streaming, time-series

## 简介

A TypeScript-based ODM for ClickHouse databases with full CRUD support, fluent query builder, configurable engines, and automatic schema evolution.
