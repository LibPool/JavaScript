# @mnemonik-xyz/mcp

> 标签: ai, mcp, memory, mnemonic, shim

## 简介

MCP shim for Mnemonic Protocol. Downloads + verifies the matching mnemonik-mcp Rust binary from GitHub Releases on first invocation; provides install/install --check/mcp-stdio/doctor subcommands. No postinstall script — lazy install on first run. See Deci
