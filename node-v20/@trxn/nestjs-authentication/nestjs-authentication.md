# @trxn/nestjs-authentication

> 标签: JavaScript

## 简介

The nestjs-authentication module is that will handle your authentication. It will by give you access to some standard guard to use jwt and login based strategy authentication. Under the hood this module use jwt and passport to authenticate the connections
