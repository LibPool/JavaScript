# @trxn/nestjs-user

> 标签: JavaScript

## 简介

The nestjs-user module is a wrapper module around the UserService that will be used in another `@trxn/nestjs-` user based packages. This module ask you to provide a UserService that need to implement an interface to be used to fetch and update a user
