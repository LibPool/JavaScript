# @dsh-so/dsh-code-security

> 标签: audit, bundle, codex-security, deepseek-harness, dsh, preset, security

## 简介

DeepSeek Harness security bundle: auto-audits newly installed plugins with the harness's own model (settings panel + batch tools), and ships the Security-Audit-Mode agent preset with the OpenAI Codex Security workflow skills and dsh_security_* scan tools.
