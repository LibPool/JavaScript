# @tzam-org/ui

> 标签: JavaScript

## 简介

Componentes React do Tzam para Next.js (App Router): shell, DataTable com filtros, Dialog, ações de linha, formulários, busca com seleção, consentimento de cookies, gráficos, ícones e navegador/sistema de um User-Agent. Server Components por padrão, 'use
