# openstamps

> 标签: cstp, cts, drand, mcp, offline, provenance, rfc3161, timestamp, verification

## 简介

Check a Cosmic Time Stamp (.cts) on your own machine: npx openstamps check file.cts [original]. Offline, no dependencies, checks only — it never stamps.
