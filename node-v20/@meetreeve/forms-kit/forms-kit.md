# @meetreeve/forms-kit

> 标签: JavaScript

## 简介

React forms kit for Reeve.Forms: SurveyJS-backed renderer, submit client (partial-on-blur + on-complete), DNA theme mapper. Consumed directly by in-app hosts and by the iframe embed app.
