# @meetreeve/status

> 标签: health, meetreeve, monitor, reeve, status, uptime

## 简介

Reeve.Monitor Status surface — one tool instanced per build. Framework-agnostic InstanceStatus contract + resolveInstanceStatus aggregator (core, browser-safe), a Node-only TLS cert-expiry probe (./node), and a pure React StatusSurface renderer (./react).
