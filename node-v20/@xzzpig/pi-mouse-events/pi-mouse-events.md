# @xzzpig/pi-mouse-events

> 标签: mouse, pi-extension, pi-package, pi-tui, tui

## 简介

Mouse event dispatch for Pi's fullscreen TUI: Component.onMouse, a global mouse event channel, and handler slots for other extensions.
