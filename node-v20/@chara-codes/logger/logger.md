# @chara-codes/logger

> 标签: chara, console, debug, dump, logger, logging, object-formatting, pino, pretty-print, variable-inspection

## 简介

A flexible and powerful logging utility for Chara applications built on Pino with beautiful object pretty-printing using @base2/pretty-print-object
