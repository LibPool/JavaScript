# @giuliobmb/exam-sheet-mcp

> 标签: exam, flashcards, mcp, mcp-app, modelcontextprotocol, study

## 简介

An MCP App that generates a timed exam on any topic (true/false, multiple choice, open questions) and renders an interactive exam sheet with live grading and a final grade out of 100.
