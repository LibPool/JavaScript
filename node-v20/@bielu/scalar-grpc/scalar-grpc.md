# @bielu/scalar-grpc

> 标签: api-reference, asyncapi, grpc, grpc-web, plugin, scalar

## 简介

Interactive gRPC console plugin for the Scalar API Reference. Reads gRPC AsyncAPI bindings and lets you invoke unary and server-streaming methods over gRPC-Web.
