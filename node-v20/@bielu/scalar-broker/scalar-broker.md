# @bielu/scalar-broker

> 标签: amqp, api-reference, asyncapi, broker, kafka, mqtt, plugin, scalar

## 简介

Interactive message-broker console plugin for the Scalar API Reference. Reads Kafka/MQTT/AMQP AsyncAPI bindings and publishes to and tails channels through an opt-in server-side bridge.
