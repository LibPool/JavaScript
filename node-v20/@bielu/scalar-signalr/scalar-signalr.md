# @bielu/scalar-signalr

> 标签: api-reference, asyncapi, plugin, scalar, signalr, websocket

## 简介

Interactive SignalR console plugin for the Scalar API Reference. Reads SignalR AsyncAPI bindings and lets you connect to hubs, invoke methods and subscribe to server events.
