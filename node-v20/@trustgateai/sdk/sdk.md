# @trustgateai/sdk

> 标签: ai-gateway, langchain, n8n, openai, security, self-hosted, trustgate, vercel

## 简介

Node.js client for TrustGate, a self-hosted AI security gateway. Point it at your own gateway; there is no default endpoint.
