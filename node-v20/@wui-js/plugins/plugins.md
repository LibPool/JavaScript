# @wui-js/plugins

> 标签: components, css, frontend, javascript, library, ui, vanilla, wui

## 简介

WUI/JS Plugins Lib - WUI/JS Plugins Lib is an open-source JavaScript/CSS library that provides a collection of plugins for WUI/JS Main Lib classes.
