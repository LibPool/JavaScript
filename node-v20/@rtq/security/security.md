# @rtq/security

> 标签: fail-closed, invariants, mcp, network, policy, risk, rtq, runtime, sandbox, security

## 简介

RTQ umbrella package: capability authorization, risk-aware policy, clarification, approvals (incl. QR/mobile verification), cryptographic authorization tickets, OS sandboxing and audit — one ergonomic API.
