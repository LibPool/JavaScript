# @nick-qi/qrm

> 标签: NPM, custom, manager, npm, pnpm, registry, yarn

## 简介

NPM registry manager can help you easy and fast switch between different npm registries, now include: cnpm, taobao, nj(nodejitsu), rednpm, edunpm, support yarn, npm, pnpm
