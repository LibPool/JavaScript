# @chimok/jxltran-js

> 标签: container, crop, image-transformation, jpeg-xl, jxl, jxltran, libjxl, lossless, metadata, orientation, remux, transform, wasm, webassembly

## 简介

Lossless JPEG XL transformations (container remux, orientation, crop, metadata edits) as a WebAssembly module, built from libjxl's jxltran.
