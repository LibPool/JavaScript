# @osqd/admin-panel-builder

> 标签: admin-panel, dashboard, feature-flags, metrics, operator, runtime-config, typescript

## 简介

Admin panels for Node applications, declared next to the variables they show: viewable() and modifiable() values, grouped, charted and themed, served on a path, on a port of their own, or embedded as HTML.
