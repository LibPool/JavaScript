# @simplycms/plugin-sdk

> 标签: JavaScript

## 简介

Plugin SDK for SimplyCMS: definePlugin contract, module validation, plugin i18n and plg_* data port. The only surface a plugin is allowed to import (Tier 2).

- 源码仓库：https://github.com/simplyCMS/simplyCMS.git
