# @xarlizard/react-temporal

> 标签: calendar, date, datetime, hooks, intl, javascript, polyfill, react, react-hooks, temporal, temporal-api, time, timezone

## 简介

React hooks for date and time using the JavaScript Temporal API — native in modern browsers, polyfill-ready for Node.js and Safari.
