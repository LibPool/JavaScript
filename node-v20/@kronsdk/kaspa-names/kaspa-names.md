# @kronsdk/kaspa-names

> 标签: .kaspa, kaspa, kns, name-service, resolver, wallet

## 简介

Resolve .kaspa names — read-only SDK for the KNS covenant-backed name service on Kaspa L1 (forward/reverse resolution, profiles, canonical normalization, on-chain proof verification).
