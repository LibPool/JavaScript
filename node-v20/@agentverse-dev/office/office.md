# @agentverse-dev/office

> 标签: 3d, agentverse, ai-agents, claude-code, visualization

## 简介

The AgentVerse 3D office as a single command — bundled UI plus a Node event server. `npx @agentverse-dev/office` and watch your agents work. No clone, no Python.
