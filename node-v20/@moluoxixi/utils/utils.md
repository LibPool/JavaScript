# @moluoxixi/utils

> 标签: JavaScript

## 简介

跨框架的 TypeScript 工具包，主打 **ESM 优先、纯函数优先、契约显式**。通用函数从包根导入，依赖 Node.js 的项目清单能力从 `@moluoxixi/utils/node` 导入。
