# @moluoxixi/config-form-vue-backend

> 标签: JavaScript

## 简介

ConfigForm Canonical IR 的 Vue 运行时后端。它把 Compiler 产出的不可变页面编译结果绑定到 Vue 组件、校验器和只读渲染协议，生成 `ConfigFormRenderer` 可直接消费的渲染配置。
