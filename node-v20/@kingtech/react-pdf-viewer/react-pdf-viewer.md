# @kingtech/react-pdf-viewer

> 标签: a11y, accessible, document-viewer, pdf, pdf-viewer, pdf.js, pdfjs, pdfjs-dist, react, ssr, viewer

## 简介

Accessible, themeable React PDF viewer built on PDF.js: zoom, rotation, fullscreen, search, thumbnails, download and print, with no UI-kit dependency.
