# @txpass/client

> 标签: ai-agents, authfetch, brc-103, bsv, txpass

## 简介

Txpass client helpers: request sessions over AuthFetch/BRC-103, sign delegations and agent policies, publisher receipt requests, safe 402 handling, and the "Continue with Txpass" sign-in popup (PKCE code exchange).
