# @starhikari/koishi-plugin-group-whitelist

> 标签: chatbot, group-whitelist, koishi, plugin, whitelist, 群白名单, 群聊白名单

## 简介

实现koishi全局白名单，群聊不在白名单内时bot将不再处理该群的任何消息与指令
