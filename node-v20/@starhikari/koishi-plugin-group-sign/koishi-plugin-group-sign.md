# @starhikari/koishi-plugin-group-sign

> 标签: group-sign, koishi, koishi-plugin, napcat, onebot, qq, sign, 打卡, 群打卡

## 简介

基于 NapCat 的 OneBot QQ 机器人自动群打卡插件，支持定时打卡、多群管理、自定义打卡时间与间隔
