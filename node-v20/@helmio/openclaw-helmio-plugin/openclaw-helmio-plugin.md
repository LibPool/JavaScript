# @helmio/openclaw-helmio-plugin

> 标签: JavaScript

## 简介

OpenClaw plugin bridging Helmio's WorkspaceHub to per-agent turns inside the agent VM (chat + task_*/doc_* tools). Installed at cloud-init via `openclaw plugins install npm:@helmio/openclaw-helmio-plugin@<pinned>`. ADR-0008 / ADR-0017.
