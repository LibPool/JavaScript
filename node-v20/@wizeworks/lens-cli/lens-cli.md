# @wizeworks/lens-cli

> 标签: cli, nextjs, source maps, sourcemaps, vite-plugin, webpack-plugin, wizelens

## 简介

The WizeLens command line, and build plugins for Vite, webpack, and Next.js that upload browser source maps to a hub or the cloud.
