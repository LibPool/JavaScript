# @wizeworks/lens-node

> 标签: drizzle, elasticsearch, express, fastify, graphql, hono, ioredis, koa, mongodb, nestjs, nextjs, node, opentelemetry, prisma, profiler, redis, tracing, typeorm, wizelens

## 简介

WizeLens add-on for Node.js: request timeline, outgoing HTTP, database calls, logs, errors, and an in-app dashboard.
