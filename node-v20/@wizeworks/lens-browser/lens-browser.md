# @wizeworks/lens-browser

> 标签: browser, profiler, rum, tracing, web-vitals, wizelens

## 简介

WizeLens for any web page: links browser fetch and XHR calls to server traces, and sends page views, Web Vitals, errors, and console lines. No framework needed.
