# @geoscene/file-batch-script

> 标签: JavaScript

## 简介

* 支持多进程任务 * 通配符查找过滤文件。通配符的用法可以查阅[glob文档](https://www.npmjs.com/package/glob) * 可自定义处理文件 * 可输出基础操作日志 * 可扩展日志处理
