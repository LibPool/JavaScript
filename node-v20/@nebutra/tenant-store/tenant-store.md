# @nebutra/tenant-store

> 标签: JavaScript

## 简介

Neutral lowest-layer multi-tenant primitives: per-(tenant,resource) serialization lock + tenant-scoped in-memory store base. Depended on by atelier-canvas and reel; depends on neither.
