# orpc-fn

> 标签: cli, expo, hono, live-query, mastra, mcp, opentelemetry, orpc, pubsub, react, react-native, redis, rpc, tanstack-query, typescript, vue, zod

## 简介

Define a backend function once: a typed oRPC procedure with tracing, logging, guards, injected handler extras, nested calls and live queries over Redis.
