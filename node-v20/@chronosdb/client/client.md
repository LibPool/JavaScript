# @chronosdb/client

> 标签: ai-agents, branching, chronos, chronosdb, database, postgres, vector-search

## 简介

TypeScript/JavaScript client for Chronos DB's HTTP API: worlds (copy-on-write branches of the whole database), rows, search, diff and merge. One file, no dependencies.
