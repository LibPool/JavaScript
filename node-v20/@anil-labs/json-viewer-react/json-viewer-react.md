# @anil-labs/json-viewer-react

> 标签: json, json-tree, json-viewer, react, syntax-highlighting

## 简介

React bindings for @anil-labs/json-viewer-core — a JSON tree viewer with expand/collapse, syntax highlighting, type badges, dark/light themes and copy-to-clipboard.
