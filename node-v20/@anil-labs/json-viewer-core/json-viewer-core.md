# @anil-labs/json-viewer-core

> 标签: collapsible, framework-agnostic, json, json-tree, json-viewer, syntax-highlighting, tree-view, typescript

## 简介

Framework-agnostic JSON tree viewer — expand/collapse with persistent state, syntax highlighting, rainbow brackets, type badges, dark/light themes and copy-to-clipboard. Renders its own DOM. Zero dependencies.
