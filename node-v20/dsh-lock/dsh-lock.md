# dsh-lock

> 标签: deepseek-harness, dsh, lock, password, plugin, security

## 简介

密码门禁：打开 DSH 时先显示密码界面，解锁后才能使用；支持手动锁定与自动锁定，密码以 scrypt 单向哈希存储。
