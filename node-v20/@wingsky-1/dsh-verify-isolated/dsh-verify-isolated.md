# @wingsky-1/dsh-verify-isolated

> 标签: deepseek-harness, dsh, isolated, skill, verification

## 简介

DSH 插件开发的隔离环境浏览器验证 skill：临时 DSH_HOME + 独立 verify_<随机> profile 双重隔离，一键拉起隔离 dsh web（自动构建/挂载/启动/清理），不污染正在使用的 web profile
