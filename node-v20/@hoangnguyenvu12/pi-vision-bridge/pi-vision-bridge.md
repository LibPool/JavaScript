# @hoangnguyenvu12/pi-vision-bridge

> 标签: compare-images, describe-image, describe-video, ffmpeg, frame-extraction, image, multimodal, pi-extension, pi-package, video, vision, vision-bridge

## 简介

Give non-vision pi models the ability to understand images AND video: images are described in-context before the request (plus a describe_image tool with task modes and region zoom, and a compare_images diff tool), videos are watched via ffmpeg frame samp
