# @reharik/graphql-codegen-smart-enum-preset

> 标签: graphql, graphql-codegen, graphql-codegen-preset, smart-enum, typescript

## 简介

GraphQL Code Generator preset for end-to-end smart-enum integration. Auto-derives enumValues maps and orchestrates smart-enum codegen plugins.
