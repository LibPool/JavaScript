# @wocart/storefront

> 标签: algeria, astro, cash-on-delivery, cod, ecommerce, sdk, storefront, typescript, wocart

## 简介

Typed, validated SDK for Wocart cash-on-delivery storefronts: catalog reads, basket, checkout, OTP and order tracking, with Astro adapters.
