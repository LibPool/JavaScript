# @fin.cx/einvoice

> 标签: PDF library, PDF manipulation, XML embedding, XML parsing, ZUGFeRD, document generation, einvoice, esm, financial documents, financial technology, invoice processing, typescript

## 简介

A TypeScript module for creating, manipulating, and embedding XML data within PDF files specifically tailored for electronic invoice (einvoice) packages.
