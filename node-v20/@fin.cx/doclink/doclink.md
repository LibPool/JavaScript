# @fin.cx/doclink

> 标签: docbox, document intake, printer, protocol, scanner, typedrequest, typedsocket

## 简介

The doclink protocol: a standing TypedSocket from a document client such as DocBox to the services it delivers documents to, with ready server and client classes, and the local scanners and printers a client exposes
