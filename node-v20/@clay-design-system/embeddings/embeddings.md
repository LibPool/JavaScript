# @clay-design-system/embeddings

> 标签: JavaScript

## 简介

The optional query embedder for Clay's semantic search: all-MiniLM-L6-v2 (int8 ONNX) weights, a BERT tokenizer and a runtime on onnxruntime-node. No network, no download.
