# @animastor/ai-analysis

> 标签: JavaScript

## 简介

AI Analysis — semantic analysis layer: structure, character, location, scene, unit analysis and voice authoring. Uses @animastor/ai-agent for the execution mechanism; owns prompts, contracts, and domain-specific analysis logic.
