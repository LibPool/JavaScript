# @conciv/ui-kit-terminal

> 标签: conciv, solid-js, terminal, tty, ui-kit, xterm

## 简介

Internal to @conciv/it (installed automatically, do not install directly). Compound SolidJS terminal components for conciv tty mode: a headless xterm.js model + primitives (Root/Screen/Banner) plus a styled terminal surface.
