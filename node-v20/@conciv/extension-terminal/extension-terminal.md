# @conciv/extension-terminal

> 标签: conciv, extension, pty, terminal, xterm

## 简介

Internal to @conciv/it (installed automatically, do not install directly). The terminal built-in extension: a live harness TUI panel view over a server pty: OSC 9;4 busy tracking, replay-first WebSocket wire, and session-token handoff with chat.
