# @conciv/plugin

> 标签: conciv, esbuild, nextjs, rollup, rspack, vite-plugin, webpack

## 简介

Internal to @conciv/it (installed automatically, do not install directly). The conciv dev agent as an unplugin: vite (full: viteBridge + widget middleware + boot), webpack/rspack (boot the engine), rollup/esbuild (build-only no-ops). One factory, per-bund
