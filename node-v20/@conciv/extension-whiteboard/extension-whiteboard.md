# @conciv/extension-whiteboard

> 标签: ai, canvas, conciv, excalidraw, extension, whiteboard

## 简介

Internal to @conciv/it (installed automatically, do not install directly). The whiteboard built-in extension: an Excalidraw canvas the user and the AI share over the dev app, with source-anchored comments and pins, running on a local drizzle/libSQL db wit
