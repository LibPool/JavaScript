# @amjadiqbal/tanstack-ai-rag

> 标签: chunking, citations, embeddings, llm, pgvector, rag, rerank, retrieval-augmented-generation, semantic-search, tanstack, tanstack-ai, vector-search

## 简介

RAG kit for TanStack AI: token-aware markdown and text chunking, embed-and-store with any TanStack AI embedding adapter, pgvector and in-memory vector stores, a retrieval tool for chat() with citations, and optional rerank().
