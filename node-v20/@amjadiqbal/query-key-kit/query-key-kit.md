> 标签: cache-invalidation, query-key-factory, query-keys, query-options, react-query, solid-query, svelte-query, tanstack, tanstack-query, typescript, vue-query

## 简介

Typed query-key hierarchy and invalidation helpers for TanStack Query v5, built on queryOptions(). A maintained successor to @lukemorales/query-key-factory with the same API. Framework-agnostic (query-core only).
