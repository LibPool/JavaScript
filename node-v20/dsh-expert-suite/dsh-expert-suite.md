# dsh-expert-suite

> 标签: deepseek-harness, dsh, dsh-plugin, expert, expert-team, multi-agent, orchestration, subagent

## 简介

DSH「专家体系」插件：单角色专家（人设 + 方法论 + 工具白名单）与多 Agent 专家团（团长编排、串并行执行、整合交付），支持手动创建 / 文件导入 / AI 生成。
