# @tecpoint/short-id

> 标签: base64url, csharp, dotnet, guid, short-id, shortguid, uuid, uuidv7

## 简介

URL-safe 22-character IDs that round-trip with .NET Guid.ToByteArray() (TecPoint ShortId / CSharpVitamins.ShortGuid).
