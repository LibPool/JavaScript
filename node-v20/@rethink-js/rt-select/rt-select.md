# @rethink-js/rt-select

> 标签: choices, choices-js, custom-select, dropdown, form, javascript, multi-select, native-fallback, rethink-js, select, windows

## 简介

A lightweight select enhancement package that upgrades native select fields with a customizable Choices.js-powered dropdown when needed.
