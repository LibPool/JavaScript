# @rethink-js/alpha-video-cli

> 标签: alpha, cli, ffmpeg, hevc, rethink, transparent, video, webm

## 简介

Rethink CLI to convert PNG frame sequences with alpha into WebM + HEVC transparent videos and a ready-to-use HTML preview (macOS only).
