# @nodegx/node-spec

> 标签: JavaScript

## 简介

Each NodeGX node's behaviour written once, as an executable spec (pure reducers), plus the interpreter that runs a spec as a node and records a JSON trace, and the conformance runner that grades any target against it. Phase 107 (NSP-001); a browser entry
