# @quonfig/cli

> 标签: oclif

## 简介

Quonfig CLI.

  Inject configs/secrets as env vars (preferred for scripts and CI):
    qfg run --env DATABASE_URL=db.url --env API_KEY=stripe.key -- ./bin/migrate

  Other common usage:
    qfg get <key> --environment <env>     read a single value
    qfg
