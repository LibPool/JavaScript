# @ocp-catalog/skill

> 标签: agent, catalog, claude-code, codex, ocp, open-commerce-protocol, skill

## 简介

One-command installer for the OCP Catalog agent skill. Run `npx @ocp-catalog/skill` to add it to Claude Code, Codex, or any agent that reads a skills directory.
