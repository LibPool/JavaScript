# @exmg/exm-slider

> 标签: lit-element, tooltip, web-components

## 简介

Material 3 styled slider with an editable value pill, built with [Lit](https://lit.dev) and [@material/web](https://material-web.dev/). Next to the slider track a pill shows the current value; double clicking the pill opens a small input to type a new val
