# @nagellabs/libi

> 标签: acp, agent, ai, claude-code, codex, electron, ffmpeg, mcp, video, video-editor

## 简介

AI video studio — a desktop editor that connects CLI coding agents (Claude Code, Codex) over ACP and lets them compose, edit and export video.
