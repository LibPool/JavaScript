# opsecforge-mcp

> 标签: claude-code, codex, cursor, jwt, mcp, model-context-protocol, redaction, secrets, security, webhook

## 简介

Local MCP server for AI coding agents: redact secrets from files, scan before commit, verify webhook signatures and inspect JWTs without sending anything off your machine.
