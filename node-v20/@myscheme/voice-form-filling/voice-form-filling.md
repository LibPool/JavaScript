# @myscheme/voice-form-filling

> 标签: JavaScript

## 简介

Voice-driven form filling library. v2 uses Sarvam AI (live STT + streaming TTS) with Amazon Bedrock for answer routing and label/option translation. v1 (Azure Speech) is preserved frozen as legacy.
