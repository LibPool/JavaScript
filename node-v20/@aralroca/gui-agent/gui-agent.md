# @aralroca/gui-agent

> 标签: agent, ai, automation, browser, gui-agent, llm, mcp, model-context, page-agent, webmcp

## 简介

An open-source WebMCP-powered in-page GUI agent. Let a natural-language agent live inside your web app and drive its UI — no script injection, no browser extension, no headless browser.
