# @designtools/manifest

> 标签: cli, cva, data-slot, design-system, design-tokens, deterministic, docgen, documentation, manifest, react, tailwind-variants

## 简介

Reads a React design system (components, variants, data-slots, examples, tokens, rules, patterns, taxonomy and brand assets) into committed JSON that docs, checks and agents read from. Deterministic CLI: build, check, diff, agents, prose-check.
