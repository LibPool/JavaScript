# dsh-pivot-join

> 标签: aggregate, csv, data-pipeline, dsh, group-by, join, pivot, plugin, table

## 简介

Table pipeline toolkit for DeepSeek Harness: join two CSV/JSON tables (inner/left/right/outer), build pivot tables, and run group-by aggregations with readable aligned output. Zero runtime dependencies, read-only.
