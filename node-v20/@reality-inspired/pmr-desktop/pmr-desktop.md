# @reality-inspired/pmr-desktop

> 标签: JavaScript

## 简介

Poor Man's RTC: React SPA with configurable tenant and client id allowing RTC back and forth using OneDrive files of the logged in user as a simple signaling relay. App registration of the client id requires Files.ReadWrite.AppFolder permission.
