# @nexus-aethra/dshell-buffer

> 标签: JavaScript

## 简介

dshell cross-session buffer: user-established links between sessions, deferred requests one agent hands to another, a durable ticket queue with progress reports, scoped revocable folder grants, and a watchdog that guarantees the requester is always woken
