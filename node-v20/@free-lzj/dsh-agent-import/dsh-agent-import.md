# @free-lzj/dsh-agent-import

> 标签: claude-code, codex, cordis-plugin, deepseek-harness, dsh, dsh-client-plugin, mcp, skills

## 简介

Imports the MCP servers Codex or Claude Code already declares into DeepSeek Harness, and manages the skills every agent tool keeps by linking them into dsh's own skills directory, with the Settings page that configures both
