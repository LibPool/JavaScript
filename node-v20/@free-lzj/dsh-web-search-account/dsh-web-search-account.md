# @free-lzj/dsh-web-search-account

> 标签: cordis-plugin, deepseek-account, deepseek-harness, dsh, web-search

## 简介

Search with the DeepSeek account you are already signed in to, whatever model the conversation runs on, so web search keeps working on a gateway or third-party model route without a separate search API key
