# @byted-apaas/client-sdk

> 标签: JavaScript

## 简介

飞书低代码平台提供一个统一的自定义组件开发SDK（@byted-apaas/client-sdk）。该SDK可以划分为多个模块，这些模块通过子路径的方式组织。
