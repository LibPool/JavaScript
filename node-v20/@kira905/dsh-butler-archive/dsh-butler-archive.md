# @kira905/dsh-butler-archive

> 标签: archive, deepseek-harness, dsh, dsh-plugin, session-manager, sessions

## 简介

DSH web plugin: browse, preview, restore and delete sessions that were physically moved out of the sessions directory (archived sessions). Zero runtime dependencies.
