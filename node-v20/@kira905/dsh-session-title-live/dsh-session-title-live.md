# @kira905/dsh-session-title-live

> 标签: cordis, deepseek-harness, dsh, dsh-plugin, plugin, session-title

## 简介

Live session-title provider for dsh: regenerates the session title after EVERY user message (automatic: "all-prompts"), summarizing the most recent messages within a byte budget. Zero dependencies.
