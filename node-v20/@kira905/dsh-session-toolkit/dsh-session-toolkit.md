# @kira905/dsh-session-toolkit

> 标签: deepseek-harness, dsh, dsh-plugin, handoff, session-archive, session-context, session-relay, sessions, toolkit

## 简介

Session-lifecycle toolkit for DeepSeek Harness: handoff fact collection, model-facing session tails, cross-machine session landing, context pressure check, session axis marks, and inactive-session archiving. Zero runtime dependencies.
