# @mindknotio/cli

> 标签: agent, claude-code, cli, context, knowledge-graph, mindknot, notes

## 简介

mindknot — read and write one Mindknot graph from the command line, built for coding agents: ranked search with snippets, section reads, atomic appends, and a self-describing guide.
