# @dhcckb/mcp-server-dila-time

> 标签: buddhist-studies, chinese-calendar, dila, era-conversion, ganzhi, mcp, sexagenary-cycle, time-authority, western-calendar

## 简介

MCP Server for Chinese-Western calendar conversion using DILA Buddhist Studies Time Authority Database. Supports precise day-level conversion via drill-down through dynasty→era→year→month→day.
