# @dhcckb/wenxianxue-mcp

> 标签: chinese-classics, digital-humanities, literature-resources, mcp, wenxianxue

## 简介

奎章阁（wenxianxue.cn）数字人文资源检索 MCP Server — 支持模糊关键词全资源检索（分类作为关键词维度之一），模型侧自动进行同义词扩展，所有检索限定在「搜资源」标签页范围内。
