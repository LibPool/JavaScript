# @dhcckb/cnkgraph-mcp-server

> 标签: classical-chinese-literature, cnkgraph, digital-humanities, knowledge-graph, mcp, model-context-protocol

## 简介

古典文献知识图谱 MCP Server — 封装 open.cnkgraph.com REST API 为 MCP Tools，支持人物搜索、文献检索、关系查询、图谱漫游等数字人文研究场景
