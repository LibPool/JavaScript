# @fasterfixes/widget

> 标签: annotation, bug-reporting, feedback, qa, screenshot, script-embed, user-feedback, visual-feedback, widget

## 简介

The FasterFixes feedback widget for any website, with no framework required. Reviewers annotate elements and submit visual feedback.
