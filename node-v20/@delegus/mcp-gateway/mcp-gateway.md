# @delegus/mcp-gateway

> 标签: JavaScript

## 简介

Delegus MCP gateway: a reverse proxy that checks every MCP tools/call against the caller's delegated authority before forwarding it to any web-facing MCP server, in any language. Built on delegus.mcp().
