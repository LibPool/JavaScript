# @nomicore/doc-runtime

> 标签: JavaScript

## 简介

Yjs materialization, logical reads, and validated mutations for VFSL-described namespaces. Consumed through `@nomicore/namespace-registry` leases in ordinary applications; see the [repository README](https://github.com/welltop-jim-wang/nomicore#readme).
