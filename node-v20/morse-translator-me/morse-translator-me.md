# morse-translator-me

> 标签: cw, decoder, encoder, ham-radio, morse, morse-code, morse-code-translator, telegraph, translator

## 简介

Zero-dependency Morse code encoder/decoder with the full ITU-R M.1677-1 table, opt-in Spanish extended letters and honest warnings. Powers https://morsetranslator.me.
