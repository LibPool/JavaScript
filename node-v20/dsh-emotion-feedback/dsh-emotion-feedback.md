# dsh-emotion-feedback

> 标签: agent-state, deepseek, dsh, dsh-plugin, emotion, emotion-feedback, harness, self-reflection

## 简介

DSH plugin: judges the working model's own emotion each turn and silently re-injects it before the next turn.
