# @wjx-ai/dsh-selenium-test

> 标签: automation, browser, cordis, deepseek-harness, dsh, plugin, selenium, test, tool, webdriver

## 简介

DSH（DeepSeek Harness）Selenium 浏览器自动化测试工具插件：注册 selenium_test 工具，通过真实浏览器对网页执行点击/输入/截图/等待/断言/跳转/执行 JS 等操作并返回每步结果与截图路径。
