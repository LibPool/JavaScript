# @tenxtools/bugfixbot

> 标签: autofix, bugbot, cli, cursor, github, pr, review

## 简介

Local-first PR review autopilot for Cursor Bugbot - watches GitHub PR comments, applies fixes via Cursor CLI, and commits in cycles
