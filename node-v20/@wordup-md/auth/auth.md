# @wordup-md/auth

> 标签: forgejo, gitea, github, gitlab, google-drive, oauth, oauth2, oidc, openid-connect, pkce, spa

## 简介

Universal OAuth 2.0 + PKCE login from the browser: GitLab, GitHub, Forgejo, Gitea, Google… with an optional token proxy for providers that require a client secret.
