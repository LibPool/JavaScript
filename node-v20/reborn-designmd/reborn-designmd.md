# reborn-designmd

> 标签: claude, claude-code, design-md, design-system, korean, skill

## 简介

유명 브랜드 웹사이트의 디자인 시스템을 정리한 DESIGN.md(Refero Styles 에서 직접 받은 파일)를 읽고, 그 색·글꼴·간격·컴포넌트·Do/Don't 를 지켜 UI 를 짓는 클로드 코드 스킬(designmd-style)을 스킬 폴더에 놓고, 파일이 실제로 늘었는지 다시 셉니다. 사이트를 대신 긁어 오지 않습니다.
