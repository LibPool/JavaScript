# @mambalabsdev/mcp-sequencer-event-poller

> 标签: apify, clay, cold-email, heyreach, instantly, lemlist, mcp, model-context-protocol, replies, smartlead

## 简介

MCP server for Sequencer Event Poller. Replies, bounces, unsubscribes, meetings, and LinkedIn replies from your own Instantly, Smartlead, HeyReach, and lemlist accounts, one row per event. Read only. Runs on Apify.
