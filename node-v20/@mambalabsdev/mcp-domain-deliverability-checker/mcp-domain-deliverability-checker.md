# @mambalabsdev/mcp-domain-deliverability-checker

> 标签: apify, blacklist, clay, dkim, dmarc, dns, email-deliverability, mcp, model-context-protocol, spf

## 简介

MCP server for the Mamba Labs Domain Deliverability Checker actor on Apify. Audit a domain's email deliverability: SPF, DKIM, DMARC, MX, mail provider, catch-all, blacklist, domain age, and a 0 to 100 health score. Clay-ready output.
