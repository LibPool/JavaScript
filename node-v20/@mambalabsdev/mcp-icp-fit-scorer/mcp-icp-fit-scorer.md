# @mambalabsdev/mcp-icp-fit-scorer

> 标签: apify, clay, icp, lead-generation, lead-scoring, mcp, model-context-protocol, qualification

## 简介

MCP server for ICP Fit Scorer. Scores a company against your ideal customer profile with weighted signals via Apify. Returns a 0 to 100 score, a tier, and a per-signal breakdown. Clay-ready output.
