# @mambalabsdev/mcp-local-rank-map-pack-tracker

> 标签: apify, clay, google-maps, local-seo, map-pack, mcp, model-context-protocol, rank-tracker, serp

## 简介

MCP server for Local Rank and Map Pack Tracker. Google organic position, map pack position, and local finder position of a business for each keyword and location, searched from the location itself, with ratings, competitors, and rank change. Runs on Apify
