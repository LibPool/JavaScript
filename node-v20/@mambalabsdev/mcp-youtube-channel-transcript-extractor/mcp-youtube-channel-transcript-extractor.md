# @mambalabsdev/mcp-youtube-channel-transcript-extractor

> 标签: apify, channel-stats, clay, mcp, model-context-protocol, subscribers, transcripts, youtube

## 简介

MCP server for the Mamba Labs YouTube Channel Stats Extractor actor on Apify. Resolve a company domain or YouTube handle to the channel with subscriber count and channel metadata.
