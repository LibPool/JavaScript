# @mambalabsdev/mcp-contact-classifier

> 标签: apify, clay, contact-enrichment, mcp, model-context-protocol, title-classification

## 简介

MCP server for the Mamba Labs Contact Classifier actor on Apify. Contact title in, department and seniority out, with an optional check on whether the person still holds the role.
