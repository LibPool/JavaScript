# @mambalabsdev/mcp-wcag-accessibility-audit

> 标签: accessibility, ada, apify, axe-core, clay, european-accessibility-act, mcp, model-context-protocol, section-508, wcag

## 简介

MCP server for WCAG Accessibility Audit. Audit any website with axe-core in a real browser and get one row per domain: WCAG 2.0, 2.1, and 2.2 issues found by automated checks by severity, top failing rules, sample elements, a score, European Accessibility
