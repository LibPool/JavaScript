# @codeforbreakfast/beady-eye-mcp

> 标签: JavaScript

## 简介

The MCP server of the beady-eye Claude Code plugin. It tells a session when a bead it watches changes. beady-eye shows you, live, what every agent is doing across your projects, and tells agents and scripts when the beads they wait on change.
