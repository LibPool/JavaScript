# lisp-polycall

> 标签: asdf, cffi, common-lisp, libpolycall, peer-to-peer, polycall

## 简介

Common Lisp (CFFI) binding for the Polycall binding ABI v1 (libpolycall >= 1.1.0): config validation, RPC calls and peer nodes
