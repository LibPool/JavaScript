# tr-plugin-cli-agents

> 标签: JavaScript

## 简介

All nine adapters share one plugin: Claude Code, Codex, Antigravity, Cursor, DSH, Grok, Muse, Pi and Hermes. `runtime <agent> ...` exposes their native runtime commands; DSH observations and Hermes gateway management live here as well.
