# @bluefields/mcp-server

> 标签: ai-agents, bluefields, crawling, extraction, firecrawl, markdown, mcp, model-context-protocol, rag, scraping, web-scraping

## 简介

MCP server for BlueFields — give AI agents native scrape, map, crawl, search, and extract tools (clean Markdown / structured JSON). A Firecrawl-compatible web data API.
