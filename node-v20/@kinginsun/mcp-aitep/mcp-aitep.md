# @kinginsun/mcp-aitep

> 标签: aitep, cli, mcp, model-context-protocol, pde, pharmaceutical

## 简介

A CLI tool for retrieving PDE (Permitted Daily Exposure) reports for Active Pharmaceutical Ingredients (APIs) via Model Context Protocol.
