# @quizplayer/core

> 标签: cue-points, e-learning, edtech, html5-video, interactive-video, lms, quiz, vanilla-js, video, video-player

## 简介

Interactive HTML5 video player that pauses at cue points, beeps and asks embedded quiz questions. Zero dependencies, works with any framework and any backend.
