# @wycord/nigeria-mcp-quidax-crypto

> 标签: bitcoin, crypto, mcp, model-context-protocol, naira, ngn, nigeria, quidax, ticker

## 简介

Live crypto tickers in Naira (BTC/NGN, ETH/NGN, USDT/NGN, and more) from the Nigerian exchange Quidax, as read-only MCP tools. Public market data, keyless, no trading. A Wycord product, built by Braynex Services Ltd.
