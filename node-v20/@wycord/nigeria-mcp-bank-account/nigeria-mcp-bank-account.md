# @wycord/nigeria-mcp-bank-account

> 标签: account-resolution, bank, mcp, model-context-protocol, nigeria, nuban, paystack

## 简介

Nigeria Bank Resolve MCP — resolve a NUBAN + bank code to the account name, and list banks (Paystack, free), as MCP tools. A Wycord product, built by Braynex Services Ltd.
