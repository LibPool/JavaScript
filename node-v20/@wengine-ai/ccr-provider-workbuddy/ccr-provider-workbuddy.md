# @wengine-ai/ccr-provider-workbuddy

> 标签: ccr-provider-plugin, claude-code-router, provider-plugin, workbuddy

## 简介

WorkBuddy (CN + international) provider plugin for claude-code-router: dual-site account pool, browser login + desktop import, transformer, managed runtime, admin routes, config protector and UI card.
