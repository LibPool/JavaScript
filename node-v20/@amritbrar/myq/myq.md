# @amritbrar/myq

> 标签: chamberlain, craftsman, door, garage, garage door, liftmaster, myq, remote

## 简介

It is forked from hjdhjd/myq to support login with refresh token only. HomeKit integration for myQ enabled devices such as those from LiftMaster and Chamberlain.
