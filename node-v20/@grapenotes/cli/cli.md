# @grapenotes/cli

> 标签: agent, ai, cli, grape, grape.cool, markdown, mcp, note-taking, notes

## 简介

The official command line tool for Grape, the AI note app. Read, search and write your notes and folders from a terminal, a script or an AI agent.
