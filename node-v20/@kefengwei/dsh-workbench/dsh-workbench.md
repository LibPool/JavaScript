# @kefengwei/dsh-workbench

> 标签: cordis, deepseek, deepseek-harness, dsh, editor, explorer, files, git, monaco, plugin, terminal, workbench

## 简介

VSCode-style workbench for the DeepSeek Harness (dsh) web GUI: a resizable drawer with a workspace file tree, Monaco editor, global search & replace, Git source control, a persistent terminal, and C#/TypeScript LSP support.
