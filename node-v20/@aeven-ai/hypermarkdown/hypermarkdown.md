# @aeven-ai/hypermarkdown

> 标签: gfm, katex, llm, markdown, mermaid, react, renderer, streaming

## 简介

Ridiculously fast Markdown for React and AI. Streaming-native renderer that caches settled code lines, table rows, and list items so growing LLM output does not re-parse finished work.
