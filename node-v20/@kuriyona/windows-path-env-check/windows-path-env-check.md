# @kuriyona/windows-path-env-check

> 标签: cli, diagnostics, environment-variables, path, path-check, path-environment-variable, powershell, registry, shadowed-commands, windows

## 简介

Inspect the Windows system/user PATH and other environment variables, and report which commands each directory actually resolves, which are shadowed, and which entries are dead or duplicated
