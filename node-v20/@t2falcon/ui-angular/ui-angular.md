# @t2falcon/ui-angular

> 标签: JavaScript

## 简介

Typed Angular directives for the Falcon design system's custom elements — a typed template surface (inputs forwarded to element properties, outputs as lazy fromEvent streams) generated from @falcon/ui-core's own component metadata.
