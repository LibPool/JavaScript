# @globules-io/cordova-plugin-background-mode

> 标签: background, cordova, cordova-android, cordova-ios, ecosystem:cordova, foreground-service, wakelock

## 简介

Prevent Cordova apps from sleeping in background using foreground service + wake lock. Fully Android 16 (API 36) compatible.
