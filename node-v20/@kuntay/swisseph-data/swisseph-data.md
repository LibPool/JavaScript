# @kuntay/swisseph-data

> 标签: astrology, astronomy, de441, ephemeris-data, se1, swiss-ephemeris

## 简介

Swiss Ephemeris .se1 data files for 1800-2399 CE. Optional companion to @kuntay/swisseph — upgrades calculations from the built-in Moshier theory to the full JPL DE441-derived ephemeris.
