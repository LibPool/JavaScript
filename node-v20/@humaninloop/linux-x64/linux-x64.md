# @humaninloop/linux-x64

> 标签: JavaScript

## 简介

Linux x64 binary for humaninloop (AskHuman). Installed automatically as an optional dependency of `humaninloop`. GUI popup requires system WebKitGTK.

- 官网：https://github.com/Naituw/AskHuman
- 源码仓库：git+https://github.com/Naituw/AskHuman.git
