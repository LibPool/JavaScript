# @sz.ws/encke

> 标签: app-clip, app-clip-code, app-clip-code-generator, appclip, appclipcode, appclipcodegenerator, apple, cloudflare-workers, generator, ios, nextjs, nfc, qrcode-alternative, react, reed-solomon, ring-code, scannable-code, svg, typescript, url-compression

## 简介

Apple App Clip Code generator in pure TypeScript. Renders the scannable ring code to SVG, bit-for-bit identical to Apple's AppClipCodeGenerator, with no macOS and no native binary. Works in Node, Next.js, React, browsers and Cloudflare Workers.
