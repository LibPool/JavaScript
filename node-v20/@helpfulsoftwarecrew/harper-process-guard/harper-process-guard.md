# @helpfulsoftwarecrew/harper-process-guard

> 标签: child-process, harper, harperdb, lock, pid, pidfile, supervisor, worker-threads

## 简介

One winner per node for a long-lived child process: a compare-and-swap PID lock, identification by argv, supervision, and a reaper that outlives the host
