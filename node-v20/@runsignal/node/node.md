# @runsignal/node

> 标签: alerting, background-jobs, bullmq, cron, heartbeat, monitoring, newrelic, observability, opentelemetry

## 简介

Monitor Node.js background work that no HTTP status code describes (scheduled jobs, BullMQ queues, sync loops) with OpenTelemetry, and alert on missed, overrunning, stalled or low-output jobs.
