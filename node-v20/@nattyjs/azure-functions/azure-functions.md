# @nattyjs/azure-functions

> 标签: azure, azure-functions, microsoft, natty, nattyjs, nodejs, serverless, typescript

## 简介

Azure Functions adapter for NattyJS. Run Natty controllers on Microsoft's serverless platform with zero adapter code.
