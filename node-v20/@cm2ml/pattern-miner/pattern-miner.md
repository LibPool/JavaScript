# @cm2ml/pattern-miner

> 标签: JavaScript

## 简介

This package provides a pattern miner for the CM2ML framework. Based on the work of [Fumagalli et al.](https://link.springer.com/chapter/10.1007/978-3-031-17995-2_4)
