# @springbrand/http

> 标签: JavaScript

## 简介

一个包提供共享 HTTP 合同、Axios 客户端、Query 接入和框架无关的服务端辅助函数。错误规则由 SDK 维护，消费者提供 Token、通知和业务回调。
