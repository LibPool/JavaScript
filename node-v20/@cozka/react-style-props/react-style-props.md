# @cozka/react-style-props

> 标签: emotion, react, style

## 简介

`@cozka/react-style-props` is a package that moves style-related properties set in component props to properties like React's standard `style` or Emotion's `css`. This feature is designed to make it easier to set frequently used style-related properties.
