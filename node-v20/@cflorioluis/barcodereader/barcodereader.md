# @cflorioluis/barcodereader

> 标签: barcode, camera, qr, rust, scanner, wasm

## 简介

Dependency-free 1D/2D barcode & QR decoder. One Rust core, WASM for web (Angular/React/Vue/Electron/Capacitor), native FFI later.
