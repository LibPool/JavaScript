# @opengovsg/logging

> 标签: JavaScript

## 简介

A framework-agnostic structured logging core built on [pino](https://getpino.io/). It standardises the log wire format (newline-delimited JSON with custom syslog levels), provides a scoped logger with actions and contextual metadata, an oversized-context
