# @devlas/capacitor-thermal-printer

> 标签: android, bluetooth, boleta, capacitor, capacitor-plugin, esc-pos, escpos, impresora-termica, ios, lan, otg, point-of-sale, pos, punto-de-venta, spp, tcp, thermal-printer, ticket, usb, wifi

## 简介

Adaptador universal de impresión térmica ESC/POS para Capacitor: USB (OTG), TCP/LAN/WiFi y Bluetooth SPP en Android; TCP/LAN/WiFi en iOS. Una sola API de bytes crudos.
