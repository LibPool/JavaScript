# @nullifyads/core

> 标签: browser, clickjacking, malvertising, popup-blocker, prompt-injection, security

## 简介

Detection engine behind Nullify: stops click hijacks (invisible overlays, unwanted pop-ups and redirects, hidden instructions) inside the page.
