# @jacklika/dsh-llm-qoder

> 标签: JavaScript

## 简介

Qoder CLI as a dsh LLM provider: mounts the `qoder` and `qoder-byok` routes over the local qodercli login, with live model discovery, warm inner sessions, image input, and provider cache-bucket reporting.
