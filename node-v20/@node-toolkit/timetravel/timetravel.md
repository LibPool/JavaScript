# @node-toolkit/timetravel

> 标签: algod, algorand, boxes, history, time-travel, versions

## 简介

Framework-free client for a go-algorand time travel node (EnableTimeTravel): state at a past round, object version histories (accounts, applications, assets, boxes) with pagination, and the node probe. No dependencies, fetch only
