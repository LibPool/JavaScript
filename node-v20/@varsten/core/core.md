# @varsten/core

> 标签: circuit-breaker, fail-open, fallback, llm, varsten

## 简介

Provider-agnostic fail-open engine shared by Varsten's SDK wrappers: fallback decisions, the local circuit breaker, error taxonomy, and best-effort telemetry.
