# @kernelforge/sogen-runtime

> 标签: JavaScript

## 简介

Windows-userland track runtime: a sogen-shaped userspace emulation session (module list, process memory, pristine snapshots, modeled game actions) with a deterministic plain-JS reference backend, plus the kd-style console engine the userland labs are solv
