# @codai/axiom-axm

> 标签: axiom, axm, chevrotain, dsl, parser

## 简介

AXIOM v2 `.axm` front-end: Chevrotain lexer + CST parser that compiles the .axm DSL 1:1 into a Plan, with position-bearing diagnostics and a deterministic inverse printer
