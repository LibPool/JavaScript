# @codai/axiom-axm-lsp

> 标签: axiom, axm, language-server, lsp

## 简介

Language server for AXIOM `.axm` plans: diagnostics, completion, hover, document symbols, formatting and semantic tokens over LSP, reusing the @codai/axiom-axm Chevrotain parser (one grammar, zero drift)
