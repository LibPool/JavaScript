# @astrapi69/entity-kit

> 标签: beaninfo, components, descriptor, entity, headless, react, tanstack-table, typescript

## 简介

Headless, type-safe React component library implementing the BeanInfo pattern. Any object type describes itself via an EntityDescriptor and generic components render it.
