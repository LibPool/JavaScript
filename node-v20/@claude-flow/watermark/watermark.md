# @claude-flow/watermark

> 标签: eu-ai-act, llm, provenance, synthid, wasm, watermark

## 简介

SynthID-Text-style LLM text watermarking (generation + detection) as a WASM module — Tournament / non-distortionary / distortion-free schemes, indel-robust and short-text detectors. Node + browser. No watermark-removal tooling.
