# @starworks-dev/hero3d

> 标签: animation, camera, canvas, hero, perspective, react, svelte, typography, web-component, webgl2

## 简介

A small, dependency-free engine for flat, text-bearing planes seen through a moving perspective camera: Canvas 2D heroes, baked WebGL fields and small WebGL 2 heroes on one lifecycle.
