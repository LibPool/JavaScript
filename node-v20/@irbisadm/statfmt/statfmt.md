# @irbisadm/statfmt

> 标签: data, dta, parser, por, port, readstat, sas, sas7bcat, sas7bdat, sav, spss, stata, statistics, xport, xpt, zsav

## 简介

TypeScript port of ReadStat — read and write SPSS (.sav/.zsav/.por), Stata (.dta), and SAS (.sas7bdat/.sas7bcat/.xpt) data files. No native dependencies.
