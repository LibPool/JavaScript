# @kinocode/dsh-model-routes

> 标签: anthropic, claude, deepseek-harness, dsh, dsh-plugin, gemini, model-routes, openai

## 简介

DeepSeek Harness 用マルチプロバイダ・モデルルート管理プラグイン。Claude、OpenAI、Gemini 等のサブスク（OAuth）と API キーを独立登録し、モデル一覧での表示・非表示を制御可能にします。
