# @agentoracle/receipt-verify-browser

> 标签: agentoracle, browser, ed25519, jws, verification, webcrypto

## 简介

Browser-side verifier for AgentOracle receipts. Drop-in <script> tag for live SHA-256 + Ed25519 + on-chain anchor recompute. Reserved; full release shipping soon.
