# @dlunire/front-dlroute

> 标签: browser, dlroute, frontend, parser, router, routing

## 简介

Motor de rutas para UI: asocia URIs a componentes, funciones o cualquier recurso. Sin acoplarse a un framework de presentación ni a un backend específico.
