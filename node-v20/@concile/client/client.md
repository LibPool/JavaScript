# @concile/client

> 标签: JavaScript

## 简介

The framework-agnostic Concile client SDK: `ConcileClient` over a reactive WebSocket connection, with React bindings (`useQuery`/`useMutation`/`useAction`) at the `@concile/client/react` subpath.
