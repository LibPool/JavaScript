# @mazurovn/mazzy-vpn-pi

> 标签: amneziawg, mazzy, mazzy-vpn, pi, pi-extension, pi-package, vpn, wireguard

## 简介

Mazzy VPN extension for pi — connect to and manage Mazzy VPN from inside pi: auto-connect, live status widget, monitor + auto-reconnect, and LLM-callable tools to connect/switch/disconnect/recover/verify (bypass blocks). Drives the mazzy-vpn Go CLI.
