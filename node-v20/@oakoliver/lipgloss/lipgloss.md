> 标签: ansi, borders, bun, charmbracelet, colors, css, deno, layout, lipgloss, margins, multi-runtime, nodejs, padding, styling, terminal, tui, typescript, zero-dependencies

## 简介

CSS-like terminal styling for JavaScript. Zero dependencies, multi-runtime (Node.js, Bun, Deno). Fluent API for colors, borders, padding, margins, alignment, and layout.
