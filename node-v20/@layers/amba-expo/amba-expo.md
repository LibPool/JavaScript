# @layers/amba-expo

> 标签: JavaScript

## 简介

amba SDK for Expo apps — wraps @layers/amba-react-native with Expo-native conveniences: SecureStore-backed token persistence, expo-apple-authentication + expo-auth-session sign-in wrappers, expo-notifications push-token capture, config plugin for expo pre
