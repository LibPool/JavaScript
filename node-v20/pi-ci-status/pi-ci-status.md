# pi-ci-status

> 标签: ci, gh, github-actions, pi, pi-coding-agent, pi-extension, pi-package

## 简介

Lightweight CI status for the Pi coding agent: zero-token footer badge, on-demand ci_status tool, and edge-triggered one-line context injection on CI state changes. Zero LLM calls.
