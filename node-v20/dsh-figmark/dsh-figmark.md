# dsh-figmark

> 标签: annotation, deepseek-harness, dsh, dsh-plugin, figure, matplotlib, pdf, research, svg

## 简介

DSH 插件：在右侧栏预览里对科研配图、SVG、PDF、HTML 直接圈画批注，标注写进侧车文件并可一键交给智能体改图源
