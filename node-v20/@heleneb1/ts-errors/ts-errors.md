# @heleneb1/ts-errors

> 标签: api-errors, custom-errors, debug, developer-tools, diagnostics, error, error-handling, errors, exceptions, express, http-errors, javascript, logging, middleware, node, nodejs, ts, typed-errors, typescript, utilities

## 简介

Lightweight TypeScript library to create, manage and log typed, structured errors for Node.js, Express and modern JavaScript apps. Simplify error handling, improve debugging, and keep your API responses clean and consistent.
