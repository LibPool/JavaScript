# @kuraykaraaslan/kui-calendar

> 标签: calendar, kui, react, rrule, scheduler, typescript

## 简介

Standalone calendar component — vanilla TS core + optional React subpath. Multi-view (month/week/day/agenda/resource), RRULE recurrence, drag-create/move/resize, i18n.
