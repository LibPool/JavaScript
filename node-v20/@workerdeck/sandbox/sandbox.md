# @workerdeck/sandbox

> 标签: agent, claude, quickjs, sandbox, untrusted-code, wasm

## 简介

The WorkerDeck execution sandbox: QuickJS-NG-in-WASM guest for untrusted, LLM-generated scripts with an in-memory scratch VFS, a hardened by-value host bridge (capability host functions only - no ambient fs/network), and interpreter-enforced memory + wall
