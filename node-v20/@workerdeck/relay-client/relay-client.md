# @workerdeck/relay-client

> 标签: agent, gateway, peers, relay, workerdeck

## 简介

Gateway side of the WorkerDeck relay: the relay wire frames, the dial-out connection with auth, heartbeat and reconnect, the session registry publisher, and the remote peer directory. Lets agents on separate gateways list, peek at and message each other.
