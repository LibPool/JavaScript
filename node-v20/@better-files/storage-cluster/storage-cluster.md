# @better-files/storage-cluster

> 标签: better-iam, cluster, control-plane, data-room, replication, storage, typescript

## 简介

A storage control plane for Better Files: servers with local disks join as storage nodes; placement, replication, failover reads, drain and repair, exposed as a StorageAdapter
