# @better-files/storage-gcs

> 标签: better-iam, data-room, gcs, google-cloud, storage, typescript

## 简介

Google Cloud Storage adapter for Better Files over the JSON API and fetch, with service-account tokens and V4 signed URLs; no Google SDK.
