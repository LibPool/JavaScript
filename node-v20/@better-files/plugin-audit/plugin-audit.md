# @better-files/plugin-audit

> 标签: access-review, audit, better-iam, compliance, data-room, report, typescript

## 简介

Audit reports for Better Files: participants, the access matrix by group and folder, engagement per person and activity-chain integrity, as JSON or a PDF for closing binders and access reviews
