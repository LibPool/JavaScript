# @vibecontrols/vibe-plugin-security-deploy-alpha

> 标签: bun, deploy-alpha, headers, security, smoke, tls, vibe, vibe-plugin, vibecontrols

## 简介

Pure-JS smoke checks against alpha-environment URLs — TLS validity, presence of HSTS / X-Content-Type-Options / CSP, and an auth-challenge probe on /healthz. Registers as a security.release provider with @vibecontrols/vibe-plugin-security.
