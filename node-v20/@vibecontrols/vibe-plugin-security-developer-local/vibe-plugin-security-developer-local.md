# @vibecontrols/vibe-plugin-security-developer-local

> 标签: bun, developer-local, gitleaks, pre-commit, secrets, security, vibe, vibe-plugin, vibecontrols

## 简介

Local pre-commit secrets scanner for the developer.local lifecycle stage. Wraps `gitleaks protect` (uncommitted + staged changes only, fast). Semgrep --quick integration is planned for a follow-up.
