# @vibecontrols/vibe-plugin-security-dast-preview

> 标签: bun, dast, deploy-preview, owasp, security, vibe, vibe-plugin, vibecontrols, zap

## 简介

OWASP ZAP baseline DAST scan provider for the deploy.preview lifecycle stage. Runs zap-baseline.py against a preview-deploy URL via Docker and normalizes the JSON report into NormalizedFindings. Registers as a security.release provider with @vibecontrols/
