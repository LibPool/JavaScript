# @digta/open-protocol

> 标签: ascii, assembly-tool, atlas-copco, industrial, iot, mid, nutrunner, open-protocol, tcp, tightening, torque

## 简介

Atlas Copco Open Protocol for Node.js: MID frame codec plus an ergonomic TCP client (auto-reconnect, heartbeat, tightening events). Zero dependencies. Not related to Protocol Buffers.
