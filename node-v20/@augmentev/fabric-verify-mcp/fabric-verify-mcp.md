# @augmentev/fabric-verify-mcp

> 标签: ai-agents, audit, ed25519, mcp, model-context-protocol, transparency-log

## 简介

MCP server for Fabric Verify: your agent signs a record of each action locally and gets a public, offline-checkable proof that the record existed, unchanged, by a certain time.
