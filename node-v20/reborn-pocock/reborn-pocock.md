## 简介

Claude Code 공식 마켓플레이스에 등재된 플러그인 mattpocock-skills(mattpocock/skills · MIT)가 이 컴퓨터에 깔렸는지 재는 한국어 스킬과, 25개 스킬 중 「지금 하려는 일」로 무엇을 부를지 골라 주는 한국어 지도를 스킬 폴더에 놓고, 파일이 실제로 늘었는지 다시 셉니다. 원본은 싣지 않고 플러그인 명령으로 따로 깝니다.
