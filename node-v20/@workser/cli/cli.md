# @workser/cli

> 标签: ai-agent, claude-code, cli, codex, deploy, devops, mcp, workser

## 简介

Workser CLI — give your local AI agent native DevOps & infrastructure on Workser. The agent runs `workser …` to provision, deploy, and manage real apps.
