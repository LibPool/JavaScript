# @ultratestbro/wdk-protocol-staking-tonstakers-ton

> 标签: gram, liquid-staking, protocol, staking, staking-protocol, ton, tonstakers, tston, wdk

## 简介

A simple package that lets @tetherto/wdk-wallet-ton wallet accounts stake through Tonstakers: stake GRAM → tsTON, unstake instant / standard / best-rate, track payout bills, rates and APY.
