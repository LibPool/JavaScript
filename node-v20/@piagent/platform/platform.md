# @piagent/platform

> 标签: agent-guardrails, agent-harness, agent-security, ai-agent, coding-agent, context-engineering, developer-tools, llm-tool-policy, mcp, mcp-security, pi-extension, pi-package, pi-prompt, pi-skill, prompt-injection, secret-redaction

## 简介

Guardrails for AI coding agents: blocks secret reads, destructive commands, and unapproved MCP servers before the tool call runs. Ships project profiles, capability locks, a context engine, and task verification.
