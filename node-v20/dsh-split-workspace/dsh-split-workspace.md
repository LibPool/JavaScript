# dsh-split-workspace

> 标签: deepseek, deepseek-harness, desktop, dsh, dsh-desktop, dsh-plugin, grid, layout, multi-pane, multi-session, panes, split-pane, split-screen, split-view, tiling, workspace, 分屏, 多会话, 多窗口, 多窗格, 田字布局

## 简介

Split-screen workspace for DeepSeek Harness (DSH) Desktop: unlimited native panes, side-by-side, stacked and 2×2 grid layouts, drag to rearrange.
