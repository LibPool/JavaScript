# @lambo-design-mobile/lambo-button-group

> 标签: JavaScript

## 简介

LamboButtonGroup是一个按钮组展示组件,主要适用于表单最后的操作按钮的展示、弹出框底部响应按钮的展示等需要按钮交互的场景。
