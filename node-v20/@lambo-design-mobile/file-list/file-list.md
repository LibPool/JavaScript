# @lambo-design-mobile/file-list

> 标签: JavaScript

## 简介

### 介绍 FileList 是附件展示组件：根据 `raw`（fileId 串）拉取文件元数据，渲染附件名；按 `field.fileClickType` 决定行为（'2' 走在线预览，其它为下载链接），内嵌 FilePreview。用于动态列表卡片与明细中的 file 字段，与 PC 端文件列渲染逻辑保持一致。
