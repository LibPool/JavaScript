# @lambo-design-mobile/lambo-card

> 标签: JavaScript

## 简介

LamboCard 是一个卡片组件,主要用于配合LamboListPage，实现卡片列表页面。卡片包含标题，副标题，标记，标签，明细键值展示列表，及底部操作按钮元素，除标题外，其他元素不是必须的。
