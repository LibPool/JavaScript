# @geastack/vite-plugin-windows-native

> 标签: JavaScript

## 简介

Vite plugins for Windows-native Gea apps: lowers JSX over @geastack/windows/Controls classes into native control construction, records the module graph the native compiler reads, and emits an empty GEA IR for natively rendered apps.
