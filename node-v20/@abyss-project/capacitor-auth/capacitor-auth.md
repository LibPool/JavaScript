# @abyss-project/capacitor-auth

> 标签: capacitor, native, passkey, plugin, webauthn

## 简介

Plugin Capacitor natif pour l'authentification sans mot de passe d'Abyss : passkeys (Credential Manager / ASAuthorization), Google (Android et iOS), Sign in with Apple (iOS) et stockage sécurisé du refresh token.
