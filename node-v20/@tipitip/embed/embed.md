# @tipitip/embed

> 标签: celo, content, cusd, embed, micropayments, minipay, react, tipitip, tipping, writers

## 简介

Drop-in React component for per-paragraph cUSD tipping on Celo. Add a tippable article block to any blog with two lines of code.
