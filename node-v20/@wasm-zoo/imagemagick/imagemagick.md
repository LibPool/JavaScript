# @wasm-zoo/imagemagick

> 标签: browser, conversion, image, imagemagick, jpeg, png, wasm, wasm-zoo, webassembly

## 简介

ImageMagick 7.1.2-31 compiled for browser WebAssembly by WASM Zoo, with Consumer API v1 and bundled runtime assets.
