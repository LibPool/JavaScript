# @nuvorafy/theme-kit

> 标签: JavaScript

## 简介

Public theme kit for authoring Nuvorafy storefront themes: manifest schemas, field helpers, runtime snapshot contract, storefront fixture, token CSS and platform-neutral validation.

- npm 页面：https://www.npmjs.com/package/@nuvorafy/theme-kit
