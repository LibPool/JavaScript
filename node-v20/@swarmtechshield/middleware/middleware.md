# @swarmtechshield/middleware

> 标签: bot-protection, cloudflare-workers, deno, express, middleware, nextjs, rate-limit, security, swarmtech-shield, waf

## 简介

Drop-in SwarmTech Shield request screening for Express, Next.js, Cloudflare Workers and Base44/Deno. Rules are evaluated locally from a synced cache; logs are sent in the background.
