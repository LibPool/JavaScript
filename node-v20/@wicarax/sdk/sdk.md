# @wicarax/sdk

> 标签: agent, ai, chat-ui, chatbot, openai-compatible, sdk, typescript, wicarax

## 简介

Official client for using a Wicarax agent inside your own chat interface. Consume only: it sends messages and returns typed answers, and never changes agent configuration.
