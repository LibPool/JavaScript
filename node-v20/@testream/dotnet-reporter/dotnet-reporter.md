# @testream/dotnet-reporter

> 标签: automated-test-management, ci-cd, ctrf, dotnet, dotnet-jira, dotnet-reporter, jira, mstest, nunit, test-management, test-reporting, testream, trx, xunit

## 简介

Run .NET tests or ingest TRX, then publish xUnit, NUnit, and MSTest results to Testream and Jira.
