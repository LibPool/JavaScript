# @normalized-db/core

> 标签: Denormalizer, IndexedDB, JavaScript, NoSQL, Normalization, Normalizer, ObjectDB, Reverse references, TypeScript

## 简介

Core-module for related 'normalized-db'-libraries providing common models and utility functions as well as the `Schema` (implemented with `TypeScript`).
