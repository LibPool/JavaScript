# @codefusion-cc/web-push

> 标签: cloudflare-workers, rfc8291, rfc8292, vapid, web-push

## 简介

Web Push on WebCrypto alone: VAPID keys and tokens, aes128gcm payloads and sending from a Cloudflare Worker, subscribing and showing notifications in the browser, and the service worker that shows pushes
