# @codefusion-cc/passkeys

> 标签: cloudflare-workers, fido2, passkeys, reauthentication, step-up, webauthn, webcrypto

## 简介

WebAuthn passkeys on WebCrypto alone for a fresh step-up check before something sensitive: registration and assertions verified in a Cloudflare Worker (ES256, Ed25519, RS256), the ceremonies in the page, and a software authenticator for apps' tests
