# @jarroba/mcp

> 标签: cidr, claude, cursor, developer-tools, diagrams, logs, mcp, modelcontextprotocol, sparql, sql, testing, tokenizer

## 简介

MCP server (stdio, local) exposing 104 deterministic tools from Jarroba Tools, reusing the same code as the web app: read a CI log that does not fit in your context, audit tests, simulate make, run SQL against an ephemeral PostgreSQL, SPARQL, JTD diagrams
