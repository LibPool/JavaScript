# @mainstreet/mcp

> 标签: claude, gbp, google-business-profile, local-seo, maps, mcp, model-context-protocol, reviews, small-business

## 简介

Mainstreet MCP server — look up any local business's Google Business Profile, check local map-pack rank, and trigger a free 5-minute audit. Built for Claude Desktop / Claude Code and other MCP-compatible clients.
