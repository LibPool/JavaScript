# @daniilnikolaevich/figma-mcp-go

> 标签: ai, claude, design, figma, mcp, model-context-protocol

## 简介

Read Figma files from AI tools (Claude Code, Cursor, Copilot) through a local plugin. No Figma REST API, no rate limits.
