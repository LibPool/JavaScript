# @fuxi-ailabs/crowdmemory-dsh-adapter

> 标签: JavaScript

## 简介

Crowd Memory adapter for DeepSeek Harness: translates DSH session events into memory-agent-ingress/v1 and forwards memory tools to the local Runtime (fail-open, no storage).
