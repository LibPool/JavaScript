# @korveo/openclaw-diagnostics

> 标签: ai-agent, korveo, llm-monitoring, observability, openclaw, opentelemetry, tracing

## 简介

Korveo observability + Agent Firewall for OpenClaw — captures prompts, responses, tool I/O, and synchronously enforces firewall policies on every tool call.
