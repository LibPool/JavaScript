# dsh-pro-standards

> 标签: agent-skills, code-review, coding-standards, conventions, deepseek-harness, dsh, dsh-plugin, dsh-skill, skills

## 简介

专业规范守则：让 AI 编码助手动手前先做三步判断（找标准 → 看场景 → 查差距），在官方规范与行业惯例之间做情境化取舍。A DSH bundle that makes AI coding agents reason like a competent practitioner.
