# dsh-refresh-restart

> 标签: deepseek-harness, dsh-plugin, electron, plugin, reload, restart

## 简介

在 DeepSeek Harness 界面左上角（收起侧边栏按钮旁边）提供「刷新」「重启」两个快捷按钮。
