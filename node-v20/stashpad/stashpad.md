# stashpad

> 标签: agent-memory, agents-md, ai-agents, claude-code, cli, codex, cursor, encryption, local-first, markdown, mcp, mcp-server, memory, model-context-protocol

## 简介

Local memory for any AI agent: plain Markdown files with sources, dates, a review queue, search and optional encryption. CLI and MCP server, no dependencies.
