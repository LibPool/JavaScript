# @nevescloud/chat-compat

> 标签: chat-completions, cloudflare-workers, code-assist, codex, gemini, openai, proxy

## 简介

Make Codex (chatgpt.com) & Gemini (Code Assist) speak OpenAI Chat Completions — pure, runtime-agnostic (CJS) translation usable in Node and Cloudflare Workers.
