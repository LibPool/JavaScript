# drizzle-pgkit-migrator

> 标签: @pgkit/migra, @pgkit/migrator, cli, database-migrations, drift-detection, drizzle, drizzle-kit, drizzle-orm, migration, migrations, pg, pgkit, postgres, postgresql, schema, schema-diff, typescript

## 简介

CLI glue for managing a Drizzle schema with @pgkit/migrator and @pgkit/migra: generate schema.sql, diff to create migrations, run pgkit migrations.
