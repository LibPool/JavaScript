# dsh-mermaid-smooth

> 标签: JavaScript

## 简介

Render mermaid fences in dsh web chat as diagrams by default with smooth zoom/pan, per-fence diagram/code toggle at top-right, persisted per-fence preference, dark-mode follow, and full offline (bundled engine, zero CDN). DSH 对话 mermaid 围栏默认成图：丝滑缩放拖拽、图右上角
