# defanged

> 标签: agent, ai, claude, code-execution, interpreter, llm, python, safe-eval, sandbox

## 简介

A sandboxed Python interpreter written in TypeScript. Safely run Python code emitted by LLMs and agents — no filesystem, no network, no escape.
