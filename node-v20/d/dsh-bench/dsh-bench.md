# dsh-bench

> 标签: benchmark, deepseek-harness, dsh-bench, dsh-plugin, hub-ext

## 简介

虚拟 DSH 环境跑分机 — 插件/Skill 加载与工具调用基准（L1 零 token）。dsh-plugin-hub 生态的可扩展类插件：为 hub 提供独立性能评分（加载/工具调用各环节耗时）。
