# dsh-plugin-stylotrace

> 标签: agent, chinese-writing, deepseek-harness, deepseek-harness-plugin, dsh, dsh-plugin, mcp, style, writing

## 简介

Stylotrace 深度协作写作 Agent 的 DeepSeek Harness 插件：40 个 MCP 写作工具 + 完整技能包。风格学习（四层向量+外层调制器）、澄清→大纲→逐节写作→红队审计→读者群像，全流程可被 DSH Agent 调用。
