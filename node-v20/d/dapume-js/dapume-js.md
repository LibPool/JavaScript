# dapume-js

> 标签: dapume, jianpu, linear-score, midi, music, notation, simple-score

## 简介

打谱么 —— 将线性乐谱（dapume）解析为乐谱对象并渲染为 MIDI 文件。可在 Node 与浏览器环境运行。
