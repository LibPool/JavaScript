# dsh-plugin-global-prompt

> 标签: deepseek-harness, dsh, global-prompt, plugin, prompt

## 简介

DSH 插件：在「设置 → 通用设置」新增全局 Prompt 输入框，注入每次对话（含子代理）的系统提示词，保存即生效。
