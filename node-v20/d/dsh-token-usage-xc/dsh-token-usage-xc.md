# dsh-token-usage-xc

> 标签: deepseek-harness, dsh, plugin, statistics, token, usage

## 简介

DSH web plugin: 今日与最近 7 日 Token 用量统计，按模型分桶，提供页头摘要、缓存命中率和 7 日趋势图。
