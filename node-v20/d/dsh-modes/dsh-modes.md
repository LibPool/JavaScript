# dsh-modes

> 标签: agent-preset, cordis, deepseek-harness, dsh, dsh-plugin, system-prompt

## 简介

Mode manager for DeepSeek Harness (dsh): switch what each agent mode can do, edit its system prompt and tool descriptions, manage skills per mode with versions and imports from Codex and Claude Code, create modes from templates, and merge built-in updates
