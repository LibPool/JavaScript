# dsh-boot-animation

> 标签: animation, boot, deepseek, dsh, plugin, 启动动画

## 简介

鲸鱼娘启动加载动画：点击进入（Esc/空格放行）、多片随机、启动进度可见、失败有兜底。不改 DSH 本体源码。
