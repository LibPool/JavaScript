# data-crypt

> 标签: aes, aes-gcm, browser, cross-platform, crypto, encryption, file-encryption, nodejs, password-encryption, pbkdf2, typescript, webcrypto

## 简介

A lightweight and powerful encryption library for Node.js and browser. It allows you to encrypt and decrypt text or files using a password.
