# dsh-agimage

> 标签: JavaScript

## 简介

常驻版 Agnes AI 图片生成工具（原动态插件 img-2 / Image Generation Tool v13 固化交付）：注册 generate_image 模型工具，结果图在会话内以 240px 上限 + 宽高比适配显示。
