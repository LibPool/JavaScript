# docs-claude-plugins

> 标签: analytics, claude, claude-code, docs, docsbook, documentation, drift-detection, insights, mcp, observability, plugins, pre-push, subagents

## 简介

Claude Code plugins for documentation workflows — subagents, MCP servers, and git hooks bundled into one command. Ships docs-sync (drift detection), docs-create (URL or topic → researched + enriched docs → live with memory across runs), and docs-insights
