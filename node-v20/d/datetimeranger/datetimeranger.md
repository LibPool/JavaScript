# datetimeranger

> 标签: date, datepicker, daterange, datetime, datetimepicker, datetimerange, datetimeranger, jquery, picker, timepicker, timerange

## 简介

DateTimeRanger is a jQuery plugin for fast visual and interactive date + time (range) entry.
