# dsh-width-tiers

> 标签: deepseek-harness, dsh, layout, plugin, table, tiers, web, widescreen, width

## 简介

DSH Web client plugin: chat content width tiers (standard / medium / wide / ultra / full / custom) with a floating picker button. Drives the app's native width axis on DSH 0.1.7+, so the built-in drag handles keep working. UI copy follows the app language
