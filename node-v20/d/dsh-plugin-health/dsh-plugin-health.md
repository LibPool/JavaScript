# dsh-plugin-health

> 标签: compatibility, compatibility-matrix, deepseek, deepseek-harness, dsh, dsh-plugin, format-1, github-action, plugin-market, semver, upgrade-check, windows, wsl

## 简介

Upgrade check and multi-host compatibility matrix for DeepSeek Harness (dsh) plugins, with an official format-1 market index builder, Windows/WSL install doctor, and a reusable GitHub Action that comments a compatibility matrix on every plugin PR.
