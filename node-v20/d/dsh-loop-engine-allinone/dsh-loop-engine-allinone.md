# dsh-loop-engine-allinone

> 标签: acp, agent-loop, antigravity, claude-code, codex, coding-agent, deepseek-harness, dsh, dsh-plugin, grok, kimi, minimax

## 简介

Web-switchable agent loop engine selection for the DeepSeek Harness - out-of-tree plugin with a data-driven engine registry and a pluggable driver layer. Ten engines: Claude Code / Codex / Pi / Kimi Code / Antigravity / ZCode / Qoder CN / Hermes / Grok Bu
