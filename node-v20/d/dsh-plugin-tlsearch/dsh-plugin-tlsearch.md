# dsh-plugin-tlsearch

> 标签: agent, brave, context-engineering, cordis, deepseek-harness, dsh, exa, llm, low-token, plugin, search, searxng, tavily, web-search

## 简介

Low-token web search for dsh: compact, sanitized {title, url, snippet} results with a pluggable, auto-failing-over backend chain (Tavily / Exa / SearXNG / Brave / Google CSE) and a token budget you control
