# dsh-ko-locale

> 标签: deepseek-harness, dsh, dsh-locale, dsh-plugin, i18n, korean, locale, localization

## 简介

Korean (ko) language pack for the DeepSeek Harness desktop and web GUI: registers the ko locale catalog entry and serves Korean copy for every built-in client dictionary.
