# dsh-subagent-antigravity

> 标签: agy, antigravity, cli, coding-agent, deepseek-harness, delegation, dsh, dsh-plugin, gemini-4, gemini-4-argon, google-antigravity, subagent

## 简介

Run Google Antigravity CLI (agy) as a one-shot coding subagent in DeepSeek Harness: a subagent_antigravity delegation tool that can drive Gemini 4 Argon and the other Antigravity subscription models inside the parent workspace.
