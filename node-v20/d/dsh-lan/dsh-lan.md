# dsh-lan

> 标签: deepseek-harness, dsh, lan, plugin, remote, switch

## 简介

LAN gateway + machine switcher for the DeepSeek Harness Web GUI. Each machine exposes its loopback DSH over the LAN through a gateway (HTTP/WebSocket reverse proxy + UDP discovery); a sidebar button opens a switcher that embeds any discovered peer's GUI.
