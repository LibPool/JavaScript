# dsh-model-tier

> 标签: cost-optimization, dsh, dsh-plugin, llm, model-router, routing, tiered-routing

## 简介

Tiered model router for DeepSeek Harness: routes auxiliary calls (session title, compaction) and subtasks to light models, escalates hard tasks to strong ones — automatically, per request, across providers.
