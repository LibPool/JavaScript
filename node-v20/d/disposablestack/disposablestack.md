# disposablestack

> 标签: AsyncDisposableStack, DisposableStack, Symbol, Symbol.asyncDispose, Symbol.dispose, asyncDispose, dispose, ecmascript, javascript, management, polyfill, resource, shim, using

## 简介

An ESnext spec-compliant `DisposableStack`, `AsyncDisposableStack`, `Symbol.dispose`, and `Symbol.asyncDispose` shim/polyfill/replacement that works as far down as ES3.
