# devtools-guardian

> 标签: anti-debugging, block-inspect-element, debugger-protection, detector, devtools, devtools-detector, devtools-guardian, devtools-warning, disable-devtools, disable-f12, disable-right-click, nextjs-security, obfuscation, protect-source-code, react, react-security, security, web-security

## 简介

A lightweight, zero-dependency client-side security wrapper for React applications that detects Developer Tools usage and blocks unauthorized code inspection.
