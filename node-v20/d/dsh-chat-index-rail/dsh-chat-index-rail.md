# dsh-chat-index-rail

> 标签: chat, deepseek-harness, dsh, dsh-plugin, index, navigation, sidebar

## 简介

对话右侧悬浮"输入目录"：每条用户输入一根横条，悬停预览前 15 字（移入气泡展开到 40 字），点击平滑定位到对应消息，滚动时当前横条高亮。
