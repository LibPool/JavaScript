# deepseek-harness-launcher

> 标签: cli, deepseek, deepseek-harness, dsh, launcher, web-ui

## 简介

Friendly launcher for DeepSeek Harness (dsh): one command `deepseek` starts the Web UI, auto-detects updates, and auto-opens your default browser.
