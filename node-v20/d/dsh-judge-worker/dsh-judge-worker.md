# dsh-judge-worker

> 标签: agent, code-agent, deepseek-harness, deepseek-harness-plugin, dsh, dsh-plugin, dual-model, git-worktree, judge, orchestration, task-contract, verification, worker

## 简介

DSH plugin: dual-model orchestration for code tasks — a high-capability judge writes Task Contracts and reviews evidence, a cheap worker implements in a git worktree, and the plugin verifies with real commands.
