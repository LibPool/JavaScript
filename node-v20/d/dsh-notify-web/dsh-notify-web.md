# dsh-notify-web

> 标签: JavaScript

## 简介

dsh web GUI 提醒插件：当 agent 提问 / 请求授权 / 计划待审（窗口最小化或未聚焦）时，通过浏览器系统通知（Notification API）提醒你，避免错过询问浪费时间。仅系统通知，无声音、无标题闪烁。
