# dsh-background-by-model

> 标签: deepseek-harness, dsh, dsh-plugin, plugin, theme, wallpaper, web-ui

## 简介

Appearance plugin for DeepSeek Harness: an ordered list of model rules, each carrying its own wallpaper, theme color, layout mode, opacity and blur — the background follows the model you switch to.
