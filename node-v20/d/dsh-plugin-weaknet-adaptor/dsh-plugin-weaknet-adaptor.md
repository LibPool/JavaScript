# dsh-plugin-weaknet-adaptor

> 标签: cache, deepseek-harness, dsh, dsh-plugin, heartbeat, reconnect, resilience, retry, token-economy, weak-network

## 简介

Weak-network adaptor for the DeepSeek Harness: transparent long-backoff model-stream retries (10-min cap), local response replay cache, heartbeat auto-reconnect, degraded-mode token economy, and a bilingual (zh/en) settings page. / 弱网适配插件：模型流长退避重试、本地响应缓存、
