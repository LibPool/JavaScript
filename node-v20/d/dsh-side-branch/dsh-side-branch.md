# dsh-side-branch

> 标签: cordis, deepseek-harness, dsh, dsh-plugin, prefix-cache, read-only, side-branch, side-chat

## 简介

DSH 侧枝会话：从主会话派生一条只读分支，每轮追问都用主会话最新的已结算内容重建上下文以继续命中前缀缓存，答案不进入主会话的模型上下文。
