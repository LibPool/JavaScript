# dsh-int-session-workspaces

> 标签: JavaScript

## 简介

一个对话注册多个工作区：从官方工作区列表勾选、为每个注明只属于本对话的用途（每次对话注入），可随时追加，并允许在工作区权限下不经审批写入这些工作区。 · Tick workspaces from the official list for one conversation, give each a conversation-private purpose note injected every turn, and write into them without per-call approval.
