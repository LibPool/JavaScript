# dotcanvas

> 标签: board, bundle, canvas, container-format, deck, dotcanvas, file-format, grida, manifest, portable, presentation, reader, slides, svg, writer

## 简介

Tolerant, zero-dependency reader/writer for the .canvas format — a portable directory of standalone documents (SVG slides or a freeform board) plus a .canvas.json manifest (order, 2D layout, skip, self-heal). ESM-only.
