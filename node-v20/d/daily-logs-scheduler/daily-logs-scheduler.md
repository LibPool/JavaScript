# daily-logs-scheduler

> 标签: JavaScript

## 简介

This repository now includes a Node.js command line tool that can be installed globally via npm or yarn. The CLI opens a configured URL in your default browser on a recurring schedule, constrained to selected days of the week and a daily time window.
