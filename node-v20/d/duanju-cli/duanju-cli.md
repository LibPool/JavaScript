# duanju-cli

> 标签: AI写作, cli, duanju, novel, webnovel, writing, 写作, 女频, 小说, 短剧, 网文

## 简介

短剧向女频短故事创作命令行工具：一句话题材 → 选题包装 → 书名锻造 → 逐章正文 → 投稿导出，内置总裁/古言/女频现实情感/年代穿越四大主类创作方法论，支持 OpenAI / Claude / Gemini / DeepSeek 等模型
