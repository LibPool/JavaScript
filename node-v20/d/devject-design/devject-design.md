# devject-design

> 标签: JavaScript

## 简介

Devject Design 是一个基于 Vue 3 和 Element Plus 的可视化表单设计器与渲染器组件库。它允许用户通过拖拽方式快速创建表单布局，并支持将设计好的表单导出为 JSON 数据，或直接在应用中渲染。
