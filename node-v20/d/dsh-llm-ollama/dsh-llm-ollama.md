# dsh-llm-ollama

> 标签: JavaScript

## 简介

Private DeepSeek Harness plugin: registers Ollama (OpenAI-compatible /v1/chat/completions) as a local 'ollama' LLM provider route, so subagents/workflows can delegate to local models.
