# dinou

> 标签: dinou, esbuild, framework, react, react-19, react-framework, react-server-components, react-server-functions, rollup, rsc, ssr, streaming, webpack

## 简介

Lightweight-Ejectable Full-Stack React 19 Framework with support for React Server Components (RSC), Server Functions, Server-Side Rendering (SSR), Static Generation (SSG), Incremental Static Generation (ISG), and Incremental Static Regeneration (ISR)
