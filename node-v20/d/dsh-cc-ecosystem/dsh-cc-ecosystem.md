# dsh-cc-ecosystem

> 标签: bundle, claude-code, deepseek-harness, dsh, meta

## 简介

One-install bundle for the whole dsh-cc ecosystem: pulls in dsh-cc-loader plus the five Claude Code adapters (skills, permissions, agents, hooks, mcp) and mounts all of them in one profile layer.
