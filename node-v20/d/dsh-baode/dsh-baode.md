# dsh-baode

> 标签: baode, delegate, doubao, dsh, dsh-plugin, subagent

## 简介

把「不着急但需要 agent 能力」的活外包给豆包工作桌面端：任务卡 + 契约 + 台账 + 技能沉淀，省 DSH 的 token。运行时依赖只有 schemastery（宿主自带，用于设置页 schema）。
