# dsh-code-notes

> 标签: code-notes, deepseek-harness, dsh, explainer, markmap, mermaid, obsidian

## 简介

Explain code while coding: capture edits, explain them with a side-channel model call, and write Obsidian notes (Mermaid flow, Markmap mind map, Canvas) with an inline panel in DSH.
