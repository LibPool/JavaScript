# dsh-lluser-ui

> 标签: deepseek-harness, dsh, movie, plugin, theme, ui, video, wallpaper

## 简介

DSH Web UI 美化插件：主题色、壁纸轮换（图片/视频/本地上传）、流媒体电影背景（m3u8/mp4 直链与网页解析）、电影进度保存与固定控制条；配置持久化到 $DSH_HOME/wallpapers-config.json。
