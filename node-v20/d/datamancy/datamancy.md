# datamancy

> 标签: datamancer, datamancy, mcp, model-context-protocol, prompts, sha256, skills, verified

## 简介

Cryptographically verifiable static MCP server backed by datamancy.dev — every spell content is SHA-256 verified before any prompt reaches the LLM.
