# dither-flow

> 标签: 1-bit, bayer, creative-coding, curl-noise, dither, dithering, flow-field, fluid, ordered-dithering, shader, webgl, webgl2

## 简介

A 1-bit dithered flow field for the web. Cursor-stirred ink, curl-noise advection, Bayer ordered dithering — raw WebGL2, zero dependencies.
