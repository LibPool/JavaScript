# dbdock

> 标签: backup, backup-tool, cli, cli-tool, cloudflare-r2, cloudinary, compression, cross-database, database, database-backup, encryption, migration, mongodb, nestjs, pitr, point-in-time-recovery, postgres, postgresql, restore, s3, schema-migration, typescript

## 简介

Enterprise-grade database backup, restore, and cross-database migration (MongoDB ↔ PostgreSQL). CLI-first tool with encryption, compression, and multi-cloud storage.
