# deletedurationtest

> 标签: Object.defineProperty(o,pName,{enumerable:false}), array's element delete time, delete obj.property, obj.property=undefined, object's property delete time test, test operation time

## 简介

tests duration time of deleting object's property and array's elements by means of different instruments: delete o[pName]; or Object.defineProperty(o,pName,{enumerable:false}); or o[pName] = undefined; etc.
