# dsh-plugin-subagent-roles

> 标签: cordis, deepseek-harness, dsh, plugin, roles, subagent

## 简介

File-defined subagent roles for DeepSeek Harness: project (.dsh/roles) and global (~/.dsh/roles) role files, a compact role catalog, real per-role tool filtering, and a per-role tool-call budget.
