# dsh-model-filter

> 标签: client-plugin, deepseek, deepseek-harness, dsh, filter, model, model-select, plugin, search

## 简介

DSH (DeepSeek Harness) web client plugin: adds a type-to-filter search box to the composer model dropdown so you can find any model in a huge provider catalog in seconds.
