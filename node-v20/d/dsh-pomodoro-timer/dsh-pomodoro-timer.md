# dsh-pomodoro-timer

> 标签: deepseek, deepseek-harness, dsh, dsh-bundle, dsh-plugin, focus, pomodoro, productivity, timer

## 简介

Pomodoro timer for the DeepSeek Harness Web UI: a sidebar page with focus/short-break/long-break cycles plus a countdown pill beside the composer. · DSH Web 番茄钟：侧栏整页（专注/短休息/长休息）+ 输入框旁倒计时胶囊。
