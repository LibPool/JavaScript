# dsh-llm-hub

> 标签: availability, balance, deepseek, deepseek-harness, dsh, dsh-plugin, llm, model-availability, model-discovery

## 简介

给 DSH 模型页补上官方适配器缺的那半：网关可达性探测、模型目录拉取、DeepSeek 余额常驻，以及 MiniMax / 智谱 / Moonshot / StepFun 的余额与配额卡。零运行时依赖，不改动 DSH 安装。
