# docker-cookiecutter

> 标签: JavaScript

## 简介

```bash curl -O https://raw.githubusercontent.com/hmredmond/docker-cookiecutter/main/kickoff-time.sh chmod +x kickoff-time.sh  sh ./kickoff-time.sh <PAT> echo "now use cd <name of project> to see the contents of the created project" ```
