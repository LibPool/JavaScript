# dom-cutout

> 标签: badge, css-mask, cut-out, cutout, mask, notification-dot, react, svg-mask

## 简介

Cut the silhouette of one DOM element out of another — badge cutouts, notification dots, status halos — with a runtime-generated SVG mask that follows the overlay's contours. Zero-dependency core, React adapter included.
