# dsh-diff-assist

> 标签: deepseek-harness, diff, dsh, plugin, session

## 简介

会话更改可视化插件：会话页'对话|轨迹|DIFF'标签 + 工作区文件树侧栏 + CodeMirror 双栏 diff 编辑器（改动前/当前文件，可编辑保存），按文件聚合 AI 在会话中 write/edit 的修改。
