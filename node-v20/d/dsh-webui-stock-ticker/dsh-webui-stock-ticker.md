# dsh-webui-stock-ticker

> 标签: a-share, deepseek-harness, dsh, dsh-plugin, quotes, stock, web, 行情

## 简介

A 股实时行情小插件 —— DeepSeek Harness Web 客户端插件。设置页「插件」分区新增「行情」标签页：现价 / 涨跌幅 / 分时迷你走势图，每 5 秒自动刷新。Realtime A-share quotes as a DSH Web settings tab (iframe-embedded zero-dependency widget).
