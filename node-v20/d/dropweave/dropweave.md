# dropweave

> 标签: airdrop-alternative, anonymous, backpressure, cli, crockford-base32, cross-platform, data-channel, developer-tools, direct-transfer, file-sharing, file-transfer, magic-wormhole, os-agnostic, p2p, peer-to-peer, privacy, sha256, terminal, webrtc, zero-knowledge

## 简介

Fast, anonymous peer-to-peer file transfer CLI over WebRTC. Zero-knowledge, OS-agnostic AirDrop alternative. Direct data channels, no cloud storage.
