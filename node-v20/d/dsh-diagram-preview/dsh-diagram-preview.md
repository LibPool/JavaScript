# dsh-diagram-preview

> 标签: diagram, dsh, markdown, mermaid, plugin, preview, whiteboard

## 简介

Full-screen Markdown & Mermaid diagram visualizer and whiteboard for DSH Web GUI: view, zoom, pan, and export charts and code blocks in dedicated modal panels.
