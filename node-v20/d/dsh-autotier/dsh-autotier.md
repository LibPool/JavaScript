# dsh-autotier

> 标签: auto, cordis, cost, deepseek, deepseek-harness, dsh, dsh-plugin, model-tier, router

## 简介

Automatic strong/cheap model-tier routing for DeepSeek Harness: intent-gated tier landing on the agent/request waterfall, plan-mode handoff (strong plans, cheap implements), deterministic high-risk guards on tools/pre-execute, failure escalation with TTL
