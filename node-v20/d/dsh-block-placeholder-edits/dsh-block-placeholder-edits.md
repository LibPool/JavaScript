# dsh-block-placeholder-edits

> 标签: agent, deepseek, deepseek-harness, dsh, dsh-plugin, edit, elision, guard, lazy-code, placeholder

## 简介

DeepSeek Harness plugin that blocks file edits which replace real code with placeholder comments like '// ... existing code ...', and whole-file rewrites that silently drop most of a file.
