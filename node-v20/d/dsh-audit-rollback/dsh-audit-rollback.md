# dsh-audit-rollback

> 标签: audit, cordis, deepseek-harness, dsh, dsh-bundle, dsh-plugin, ledger, rollback, undo

## 简介

Persistent audit ledger + precise rollback for DeepSeek Harness file-tool edits: capture pre-edit bytes into a content-addressed store per turn, roll back offline via a standalone CLI.
