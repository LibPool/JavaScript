# dsh-eyecare

> 标签: deepseek-harness, dsh, eye-care, theme, 护眼

## 简介

DeepSeek Harness (DSH) Web 护眼模式插件:在设置→常规→外观下方添加护眼模式开关,豆沙绿科学护眼配色,浅色/深色均适配。
