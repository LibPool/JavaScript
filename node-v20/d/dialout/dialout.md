# dialout

> 标签: agent, ai-agent, claude-code, codex, daemon, developer-tools, devops-dashboard, dialout, http-tunnel, localhost-tunnel, port-scanner, pty, remote-access, remote-development, self-hosted, terminal, tmux, web-terminal, websocket

## 简介

Dialout agent — reach your office, home or build machine from any browser or phone. Remote tmux terminals, live port checks, filesystem browsing, process control and HTTP tunnels. The agent dials out: no inbound ports, no VPN, no port forwarding.
