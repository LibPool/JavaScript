# durable-x

> 标签: checkpoint, compensation, crash-recovery, dapr, durable-execution, fault-tolerance, idempotency, memoization, n8n, resilience, saga, temporal, windmill, workflow

## 简介

Lightweight durable execution with checkpoint memoization and saga cleanup—no sidecar required. Add Temporal/Dapr-style durability to Windmill workflows, APIs, background jobs, and CLI tools.
