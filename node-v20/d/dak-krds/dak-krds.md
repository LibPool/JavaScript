> 标签: accessibility, component-library, design-system, government, korea, korea-design-system, korean, krds, react, react-components, typescript, ui, ui-library, wcag, wcag-2-1-aa, 공공-웹사이트, 대한민국-정부-디자인시스템, 웹접근성, 전자정부, 정부-디자인시스템

## 简介

KRDS(Korea Design System, 대한민국 정부 디자인시스템) 기반 React UI 컴포넌트 라이브러리. 공공 웹사이트·전자정부 서비스를 위한 55개 표준 컴포넌트, WCAG 2.1 AA 웹접근성 준수, TypeScript.
