# dsh-db-browser

> 标签: coding-agent, cordis, database, database-browser, deepseek, deepseek-ai, deepseek-harness, dsh, dsh-plugin, plugin, read-only

## 简介

dsh 数据库浏览插件:会话顶部「数据库」视图 Tab,多连接管理、点表分页浏览,只读多层防护,驱动注册表架构目标支持尽可能多的数据库,dsh plugin add 一条命令安装
