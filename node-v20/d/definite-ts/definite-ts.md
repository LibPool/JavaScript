# definite-ts

> 标签: api-client, definite, definite-assurance, insurance, ira, kenya, motor-vehicle, mpesa, premium, proposal, typescript

## 简介

TypeScript client for the Definite Assurance motor insurance API — onboard clients and intermediaries, quote premiums, submit proposals, and initiate payments in Kenya.
