# dendrite-wiki-mcp

> 标签: agent-memory, ai-agent, ai-coding, claude-code, codex, copilot, cursor, documentation, documentation-automation, living-wiki, llm-wiki, local-first, mcp, mcp-server, model-context-protocol, project-memory, vitepress

## 简介

Local-first MCP server that gives AI coding agents a living, browser-viewable project wiki and a project-local memory store, so the agent stays oriented and the human stays in control.
