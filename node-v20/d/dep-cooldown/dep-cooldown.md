# dep-cooldown

> 标签: audit, bun, cooldown, lockfile, min-release-age, minimumReleaseAge, npm, pnpm, provenance, security, supply-chain, yarn

## 简介

Audit the dependency cooldown (min-release-age) of a JavaScript project from its lockfile: publish dates, age in days, provenance, deprecations, and ready-to-paste config for npm, pnpm, Yarn and Bun.
