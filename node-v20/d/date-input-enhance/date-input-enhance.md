# date-input-enhance

> 标签: date, date-input-enhance, element-ui-date-enhance, vue-date-input-enhance

## 简介

对element-ui日期组件输入功能增强，用户输入日期数字时自动替换光标位置后的日期文本，并自动保持日期格式,方便用户手动输入日期
