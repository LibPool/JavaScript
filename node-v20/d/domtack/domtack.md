# domtack

> 标签: browser-extension, claude-code, coding-agent, dom, mcp, native-messaging, screenshot

## 简介

Pin any element of a web page for your coding agent: screenshot, selector, HTML and context. CLI, MCP server and native host for the DomTack browser extension.
