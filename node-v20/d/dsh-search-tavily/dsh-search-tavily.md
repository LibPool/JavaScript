# dsh-search-tavily

> 标签: cordis, deepseek-harness, dsh, search-provider, tavily, web-search

## 简介

Tavily-backed search provider for the DeepSeek Harness web seam (ctx.web), with the bundled Web-search settings page (self-hosted settings channel, bypassing the apiproxy namespace whitelist).
