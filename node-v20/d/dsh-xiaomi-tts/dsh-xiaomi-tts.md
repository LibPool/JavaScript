# dsh-xiaomi-tts

> 标签: deepseek-harness, dsh-plugin, mimo, text-to-speech, tts, xiaomi

## 简介

为 DSH Web 添加 Xiaomi MiMo TTS 语音朗读、浏览器本地语音兜底和可选 UI 音效。
