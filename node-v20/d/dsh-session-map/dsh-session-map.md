# dsh-session-map

> 标签: conversation-view, cordis, deepseek-harness, dsh, dsh-plugin, session, tree, visualization

## 简介

Adds a draggable, zoomable radial map of your session tree to the DSH conversation view, so you can see which conversation branched off which, and switch by clicking a node.
