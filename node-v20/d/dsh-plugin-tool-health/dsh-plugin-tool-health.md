# dsh-plugin-tool-health

> 标签: deepseek-harness, dsh, dsh-plugin, memory, observability, reliability

## 简介

Remembers which DeepSeek Harness tools have been failing, across sessions, and tells the next session — so an agent stops rediscovering a dead endpoint one failed call at a time.
