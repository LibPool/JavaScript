# design-pick

> 标签: ai, claude, click-to-code, context, cursor, design, dev-server, dom, mcp, picker, source-mapping

## 简介

Click a component in your locally running design/app, copy an AI-ready context packet (file:line coordinates included) — so any AI coding agent edits exactly what you pointed at, zero searching.
