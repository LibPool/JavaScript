# dsh-memoryrouter

> 标签: agent-memory, ai-memory, cordis, deepseek, deepseek-harness, dsh, harness, memory, memoryrouter, persistent-memory

## 简介

MemoryRouter plugin for DeepSeek Harness (dsh): persistent, cross-session conversation memory. Stores clean user/assistant exchanges and recalls relevant memories at the start of every turn — channel-agnostic, hooked at the harness core.
