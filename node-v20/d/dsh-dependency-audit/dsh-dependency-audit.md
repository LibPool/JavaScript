# dsh-dependency-audit

> 标签: audit, deepseek-harness, dsh, dsh-plugin, osv, security, vulnerability, 依赖, 漏洞

## 简介

依赖安全审计：扫描项目依赖的已知漏洞（OSV.dev）并检测过期依赖（npm registry），返回漏洞严重级/修复版本与升级幅度
