# destreamed-mcp

> 标签: agent, claude, cursor, destreamed, mcp, model-context-protocol

## 简介

MCP bridge for Destreamed — exposes your streams, beats, tasks and approvals to any MCP-aware agent (Claude Code, Claude Desktop, Cursor).
