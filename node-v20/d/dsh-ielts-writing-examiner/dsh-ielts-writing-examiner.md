# dsh-ielts-writing-examiner

> 标签: JavaScript

## 简介

A DeepSeek Harness Plugin as AI examiner of IELTS writing tasks with scoring and comments, convinient to review practiing histories. IELTS 写作练习与 AI 评分。题目 → 作文 → AI 评分 + 学习记录层。DSH web-profile plugin.
