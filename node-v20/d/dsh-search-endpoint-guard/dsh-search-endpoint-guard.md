# dsh-search-endpoint-guard

> 标签: JavaScript

## 简介

Diagnose and align the web_search endpoint with your LLM provider endpoint, for users running DeepSeek Harness on a non-official (proxy/gateway) provider. / 诊断并对齐 web_search 端点，帮助使用非官方（代理/网关）提供商的 DeepSeek Harness 用户。
