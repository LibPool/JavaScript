# docker2wslc

> 标签: cli, compose, containers, devcontainer, docker, docker-compose, docker-desktop-alternative, windows, wsl, wsl2, wslc

## 简介

Translate Docker commands and Compose files to wslc, the native WSL container runtime on Windows 11

## 官网

- 官网：https://wslcontainers.com
- 源码仓库：git+https://github.com/ylwl1997/docker2wslc.git
- npm 页面：https://www.npmjs.com/package/docker2wslc
