# dsh-session-cost-cap

> 标签: agent, budget, cost, deepseek, deepseek-harness, dsh, dsh-plugin, guard, llm, pricing, tokens

## 简介

DeepSeek Harness plugin that caps what one session may spend on model calls. Tracks real token usage and prices, warns the model as the cap nears, and stops or asks before going over.
