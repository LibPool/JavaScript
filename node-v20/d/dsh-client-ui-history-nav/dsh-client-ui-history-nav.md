# dsh-client-ui-history-nav

> 标签: deepseek-harness, dsh, dsh-plugin, history, navigation

## 简介

Browser-style Back / Forward / Refresh controls in the DSH window title bar, shared by Sessions and plugin panels, with a confirmation before refreshing a running Session; display text follows the DSH locale (English / Chinese). 给 DSH 客户端加浏览器式页面后退、前进与刷新（顶
