> 标签: client-ui, cordis, cost-optimization, deepseek-harness, dsh, dsh-plugin, llm-pricing, model-clock, off-peak, plugin

## 简介

DeepSeek Harness 模型优惠时钟 —— 实时显示此刻最划算的模型、全天成本热力带、限时优惠倒计时与「等一等更省」调度建议，并汇总各家资源包特惠。内置国内 11 家平台的时间窗优惠数据，每条优惠均带官方来源与核实时间。
