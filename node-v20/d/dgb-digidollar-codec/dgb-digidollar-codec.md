# dgb-digidollar-codec

> 标签: codec, decoder, dgb, digibyte, digidollar, explorer, op_return, stablecoin, taproot

## 简介

Read DigiDollar without a wallet: DD/TD address codec (<-> taproot) and the DigiDollar OP_RETURN parser (mint / transfer / redeem), with Esplora-style transaction classification. Zero dependencies. Verified against every DigiDollar transaction of mainnet
