# dsh-plugin-toggle

> 标签: deepseek, deepseek-harness, dsh, dsh-plugin, plugin

## 简介

第三方插件开关：在设置页启用/禁用第三方插件（改写各 profile 的 cordis.patch.yml，DSH 热重载立即生效）
