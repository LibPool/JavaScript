# dsh-capability-scope

> 标签: agent-preset, deepseek-harness, dsh, dsh-plugin, mcp, mcp-tools, skills, workspace

## 简介

DeepSeek Harness plugin: switch MCP servers, MCP tools, and skills per session from the composer, and remember them (with the agent preset) per workspace directory.
