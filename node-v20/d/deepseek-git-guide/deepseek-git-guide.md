# deepseek-git-guide

> 标签: ai, cordis, deepseek, deepseek-harness, dsh, git, git-assistant, plugin

## 简介

DeepSeek Harness Cordis 插件（静态 npm 包形态）：把用户对 git 操作的自然语言描述，转成最简洁安全的命令建议与解释，并让用户在「直接执行 / 手动执行」之间选择。
