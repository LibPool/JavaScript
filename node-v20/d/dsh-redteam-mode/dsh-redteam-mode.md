# dsh-redteam-mode

> 标签: asset-management, deepseek-harness, deepseek-harness-plugin, dsh, dsh-plugin, knowledge-base, pentest, redteam, security, 攻防演练, 红队

## 简介

DSH RedTeam 模式：一句话拉起红队作战智能体（资产测绘 / 攻击链 / 得分目标 / 报告 / POC 知识库），含六个角色、13 个原生技能、常驻右侧控制台与一键自动更新
