# diglossia

> 标签: dictionary, i18n, internationalization, l10n, localization, react, react19, svelte, svelte5, sveltekit, translation

## 简介

A synchronous, in-memory i18n dictionary that resolves application chrome and database-backed entity content through one lookup. The core is framework-agnostic; adapters ship at diglossia/svelte and diglossia/react.
