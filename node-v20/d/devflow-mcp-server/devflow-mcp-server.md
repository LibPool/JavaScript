# devflow-mcp-server

> 标签: browser-automation, claude, claude-code, debugging, devflow, mcp, modelcontextprotocol

## 简介

MCP server exposing browser flows recorded by the DevFlow Chrome extension — steps, console errors, network calls and screenshots — to Claude Code.
