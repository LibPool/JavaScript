# dsh-fetch-timeouts

> 标签: deepseek-harness, dsh, dsh-plugin, ollama, timeout, undici

## 简介

Raise Node's HTTP timeouts for the whole DeepSeek Harness process so slow local models are not cut off at 5 minutes
