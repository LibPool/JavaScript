# dsh-tavern

> 标签: character-card, deepseek-harness, dsh, roleplay, sillytavern, tavern, worldbook

## 简介

DeepSeek Tavern - DSH roleplay plugin: character cards, worldbooks, presets, memory, relations, plot options. Install the companion plugins dsh-muv-engine and dsh-muv-table as well for the full experience (status bar, plot options, variable tables). PolyF
