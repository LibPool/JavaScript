# dsh-open-links

> 标签: cordis, deepseek, dsh, external, harness, link, plugin

## 简介

DeepSeek Harness 客户端插件：把对话中的外部 http/https 链接点击转发给外层宿主（如 VS Code Webview），由宿主在默认浏览器打开，避免 iframe 内部导航卡死。
