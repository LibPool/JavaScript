# dsh-host-fs

> 标签: deepseek, delete, dsh, dsh-plugin, filesystem, harness, host-process, move, remove

## 简介

Delete and move files from the DSH host process — including paths outside the workspace, where DSH's own fs tools have no delete and the sandboxed shell cannot write. Gated by a session allow/deny list and a path allow/deny list. · 在宿主进程里删除/移动文件，补上 DSH 文件
