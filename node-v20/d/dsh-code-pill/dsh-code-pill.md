# dsh-code-pill

> 标签: code, dsh, dsh-bundle, dsh-plugin, syntax-highlighting

## 简介

Customizable inline code rendering for DSH: six paired light/dark presets, audited syntax palettes, optional file icons and badges, typography controls, Font Lab overrides, and dual-tab host-integrated settings.
