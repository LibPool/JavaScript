# dsh-plugin-bwm-friend

> 标签: agent-identity, bwm-friend, deepseek-harness, digital-human, dsh, persona, presence

## 简介

BWM Friend × DSH「数字人沉浸式工作台」插件——AI Agent Identity Layer 的 DSH 入口（Presence/Context/Persona 皮肤层）。UI 与业务分离：原生 DSH 业务流 100% 原生，BWM 只做皮肤/外壳。
