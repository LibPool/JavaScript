# dsh-zoom-viewer

> 标签: deepseek-harness, dsh, dsh-plugin, image, plugin, sidebar, viewer, zoom

## 简介

Zoom and pan image viewer for the DSH right sidebar: pointer-anchored wheel zoom, drag to pan, double-click to reset, fit / width / 1:1 toolbar controls and a fullscreen overlay.
