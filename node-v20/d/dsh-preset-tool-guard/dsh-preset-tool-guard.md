# dsh-preset-tool-guard

> 标签: agent-scope, context-budget, cordis, deepseek-harness, dsh, dsh-bundle, dsh-plugin, preset, tool-restriction

## 简介

Per-preset tool visibility for DeepSeek Harness: apply ctx.tools.restrict() on an agent's own scope at agent/created, so a preset exposes only the tools it should while the heavy providers stay mounted.
