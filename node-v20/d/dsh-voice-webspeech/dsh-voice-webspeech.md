# dsh-voice-webspeech

> 标签: client-plugin, deepseek-harness, dsh, speech-to-text, voice, webspeech

## 简介

DSH Web 语音输入插件：默认使用浏览器内置 Web Speech API，也可按需下载本地模型离线识别。
