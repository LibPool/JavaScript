# dsh-paste-thumbnail

> 标签: clipboard, deepseek, dsh, harness, image, paste, plugin, thumbnail, vision, web

## 简介

DSH web GUI plugin: show a thumbnail preview for Ctrl+V pasted images (base64 clipboard images included) by routing them onto the official conversation image-attachment chain. The vision model sees real image blocks, not a text reference. Does not modify
