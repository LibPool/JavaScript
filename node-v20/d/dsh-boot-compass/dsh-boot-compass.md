# dsh-boot-compass

> 标签: boot-animation, cordis, deepseek-harness, dsh, dsh-plugin, plugin, splash, startup, web-ui

## 简介

桌面端全屏启动动画：在 DSH 加载卡出现前接住首帧，播放 4.5 秒五阶段罗盘序列后交接；点按任意处可跳过，从托盘重开窗口会重播。冷启动首帧可能顿一下，之后流畅。
