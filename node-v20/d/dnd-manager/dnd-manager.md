# dnd-manager

> 标签: JavaScript

## 简介

Simple, performant, and data-driven Drag-and-Drop library for vanilla JS, compatible with any framework, and designed for developers who want full control over drag-and-drop UX without being locked into specific component patterns or opinionated libraries
