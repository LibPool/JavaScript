# dsh-peak-scheduler

> 标签: cost, deepseek, dsh, harness, off-peak, peak, plugin, scheduler, task

## 简介

DeepSeek Harness 峰谷调度插件：任务队列，空闲时段自动在当前对话执行、高峰自动暂停；任务可导出/导入；面板含额度显示。
