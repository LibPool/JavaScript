# decimalsystem

> 标签: any, base, base conversion, base converter, bases, bin, conversion, convert, converter, dec, decimal, decimalsystem, decimalsystems, hex, int, integer, library, non-int, non-integer, number, numbers, oct, pi, radix, system, systems

## 简介

DecimalSystem is a powerful base conversion library that can convert any (real) number to any base (over 1), including non-integer bases like base PI.
