# dynamic-goal

> 标签: agent, goal, pi, pi-coding-agent, pi-extension, pi-package, planning, replanning

## 简介

Dynamic replanning extension for the Pi coding agent: persistent goal, evidence-driven plan revision, phase-scoped tools, ADaPT-style as-needed decomposition, staleness detection, and isolated completion verification.
