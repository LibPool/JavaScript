# dsh-proxy-switch

> 标签: clash, cordis, deepseek-harness, dsh, dsh-plugin, mihomo, proxy

## 简介

DSH 出站代理开关：本地路由器按模式在 Clash 与直连之间自动选路，界面一键切换，无需重启。Outbound proxy switch for DeepSeek Harness: local router picks Clash or direct per mode, with an in-UI switch.
