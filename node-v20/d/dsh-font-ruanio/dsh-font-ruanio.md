# dsh-font-ruanio

> 标签: deepseek-harness, dsh, font, plugin, typography

## 简介

自定义字体生成器（DSH 插件）：上传字体 → 生成字体插件包（@local/dsh-custom-font）→ 注入 @font-face 并重映射 --dsw-font-family（全局生效，热载无需重启）。无外部运行时依赖。
