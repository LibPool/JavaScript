# dataloupe

> 标签: api, cli, csv, data, dataframe, excel, explorer, html, json, library, local-first, ndjson, offline, parquet, privacy, report, table, viewer, xlsx

## 简介

Turn any CSV/TSV/JSON/NDJSON/Parquet/Excel file into a single, self-contained, fully-offline interactive HTML explorer. Nothing leaves your machine.
