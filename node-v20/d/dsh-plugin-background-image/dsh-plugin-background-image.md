# dsh-plugin-background-image

> 标签: background, background-image, cordis, deepseek, deepseek-harness, dsh, plugin, theme, ui

## 简介

DeepSeek Harness 界面背景图片插件：网络/本地图片与预设渐变背景，支持图片不透明度、沉浸式全屏/仅对话区域、毛玻璃模糊与分区不透明度调节。
