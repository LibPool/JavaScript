# dsh-siliconflow-vision

> 标签: cordis, dsh, dsh-plugin, image-captioning, image-recognition, ocr, siliconflow, vision

## 简介

DSH 插件：通过硅基流动(SiliconFlow)视觉大模型识别/分析图片，支持本地文件路径、http(s) 图片 URL 与 base64 data URL。含持久化的粘贴识别面板（web 端）。
