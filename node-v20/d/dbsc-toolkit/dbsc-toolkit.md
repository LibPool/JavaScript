# dbsc-toolkit

> 标签: auth, cookies, dbsc, device-bound-session-credentials, dpop, express, fastify, hono, nextjs, rfc9449, security, session, tpm, webauthn

## 简介

Server-side Device Bound Session Credentials (DBSC) for Node.js — Express, Fastify, Hono and Next.js adapters — plus a Web Crypto polyfill for Firefox, Safari, and older Chromium. Cookie-theft protection on every modern browser.
