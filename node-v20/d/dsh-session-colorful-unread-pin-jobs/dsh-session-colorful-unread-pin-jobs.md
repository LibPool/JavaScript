# dsh-session-colorful-unread-pin-jobs

> 标签: colorful, deepseek, dsh, dsh-plugin, harness, pin, pinned, session, sidebar, ui, unread

## 简介

会话标题按状态彩色标记：未读（运行中蓝 / 已完成绿）、置顶（黄，读官方 pin 集合），两种状态合成一条渐变；含未读会话设置分节。置顶、归档与排序由 DSH 官方提供，本插件不再重复实现，也不再改写官方 bundle（菜单走 sidebar.workspaces.session.menu.item 插槽、染色走行 DOM）。 Colors DSH sidebar session titles by state — unread (blue while running, green when finish
