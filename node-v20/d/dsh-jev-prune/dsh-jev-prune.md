# dsh-jev-prune

> 标签: compaction, context, cordis, deepseek-harness, dsh, dsh-plugin, jev, typesafe

## 简介

Jev-judged context compaction for DeepSeek Harness. Two layers: prune stale tool results (semantic instead of size-only), and replace spent tool-call ranges with a deterministic receipt instead of a model-written summary.
