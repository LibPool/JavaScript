# dsh-base64-codec

> 标签: base64, dsh, jwt, plugin

## 简介

Base64 codec plugin for DeepSeek Harness: encode/decode base64, base64url, hex, and URL percent-encoding with UTF-8 validation and binary fallback hints, plus JWT decode (no signature verification). Zero runtime dependencies.
