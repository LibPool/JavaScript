# dsh-prompt-inject

> 标签: cordis, deepseek-harness, dsh, plugin, prompt, prompt-injection, system-prompt, template

## 简介

System-prompt template injection for DeepSeek Harness: manage named prompt templates and inject the selected one (global default plus per-workspace overrides) into every session's system prompt.
