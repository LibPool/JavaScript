# dsh-intent-translator

> 标签: deepseek, dsh, intent, plugin, prompt, translator, vibecoding

## 简介

用 #66ccff 标出 1–3 处模糊描述，分别分叉成人话方向；点选只替换对应片段，支持撤回与换一组。
