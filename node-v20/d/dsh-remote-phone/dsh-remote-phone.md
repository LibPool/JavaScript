# dsh-remote-phone

> 标签: cloudflare, deepseek-harness, dsh, mobile, plugin, qr-code, quick-tunnel, remote-access, remote-control

## 简介

DSH Remote Web Gateway — DSH native plugin: one-click phone/tablet remote access to the DeepSeek Harness Web GUI via Cloudflare Quick Tunnel + QR/pairing-code pairing + device management
