# dsh-session-robustness

> 标签: deepseek-harness, dsh, dsh-plugin, retry, robustness, session, timeout

## 简介

工程级会话鲁棒：官方有限次 API 重试耗尽后，对超时/传输/限流等瞬时失败继续重试直到成功或取消，会话不因瞬时 API 故障中断。
