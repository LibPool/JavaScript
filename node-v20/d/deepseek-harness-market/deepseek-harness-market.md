# deepseek-harness-market

> 标签: catalog, deepseek, dsh, harness, install, market, marketplace, plugin

## 简介

DeepSeek Harness plugin market: browse and search the community catalog inside the sidebar, install, update, enable, disable and remove plugins without leaving the GUI. Ships a host half plus a web client half in one package.
