# dsh-plugin-deepsearch

> 标签: deepseek, deepseek-harness, dsh, dsh-plugin, search-api, tools, web-search

## 简介

Switch DSH's built-in web_search between the DeepSeek Search API (/v1/tools/search) and the default account search, with live fallback, a settings page and a sidebar switch.
