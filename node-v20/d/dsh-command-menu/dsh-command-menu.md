# dsh-command-menu

> 标签: cmdk, command-menu, command-palette, deepseek, deepseek-harness, dsh, dsh-plugin, harness, keyboard-shortcuts, search

## 简介

Cmd/Ctrl+K command menu for the DeepSeek Harness Web UI: search sessions by title and message text, run slash commands, open settings sections and workspaces, switch the session's model, and run app actions (new session, sidebar, theme) from one keyboard-
