# dsh-plugins-tui-keymap

> 标签: JavaScript

## 简介

TUI brick: leader-key bindings (ctrl+x m/c/t/x/u/s = model/compact/theme/export/undo/usage) + busy queue (Alt+Enter queue, Alt+Up take back) — OpenCode/Pi style.
