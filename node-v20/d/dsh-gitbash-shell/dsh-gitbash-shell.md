# dsh-gitbash-shell

> 标签: deepseek-harness, dsh, dsh-plugin, git-bash, shell, windows

## 简介

Windows 上让 agent 的每条 shell 命令改经 Git for Windows bash 执行;物化四个内置预设的 Git Bash 变体,统一 MSYS 盘根路径方言,侧栏终端接管可开关。· Run every agent shell command through Git for Windows bash on Windows; materialize Git Bash variants of the built-in presets, unify the MSYS drive-roo
