# date-universal

> 标签: add day,month,year,hour ,minutes,sec to datetime, date, date in desired format desired language and desired timezone., multilingual date, php date format, universal date format

## 简介

date-universal is a node module used to print date in desired format. It can be used for any localization you want to use in your node application.It can be easily used to add day,month,week hour,minute to a datetime value.you can use format using in php.
