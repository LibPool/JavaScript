# doc-pdf-highlight

> 标签: docx, dom, fuzzy-match, highlight, keyword, levenshtein, pdf.js, text-layer, text-search

## 简介

精准跨标签文本高亮库，支持 DOCX 转换 HTML 与 PDF.js 双场景。基于纯文本索引的 DOM 最小侵入包裹方案，精确匹配与 Levenshtein 模糊匹配双模式。
