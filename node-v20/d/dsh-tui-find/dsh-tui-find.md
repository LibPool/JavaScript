# dsh-tui-find

> 标签: cordis, cross-session, deepseek, dsh, dsh-tui, full-text-search, plugin, search

## 简介

Cross-session full-text search for dsh-TUI — /find over all local dsh session logs (zstd frame chains and plain JSONL), read-only.
