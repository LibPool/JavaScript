# dsh-figma-design-lens-cat

> 标签: ai-agent, claude, codex, design-system, design-to-code, figma, mcp, model-context-protocol, ui-analysis

## 简介

Figma design understanding for AI coding agents: extracts components, exports assets, cross-checks recognition with vision models, and scores how ready a screen is to implement. Ships an MCP server and a local review UI.
