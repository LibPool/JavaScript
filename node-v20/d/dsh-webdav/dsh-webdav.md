# dsh-webdav

> 标签: 123pan, 123云盘, alist, deepseek-harness, dsh, dsh-plugin, fnos, jianguoyun, nas, nextcloud, openlist, owncloud, seafile, synology, webdav, webdav-client, zspace, 坚果云, 极空间, 群晖, 飞牛

## 简介

Universal WebDAV drives for DeepSeek Harness: agent tools (webdav_*), a multi-remote file browser panel and a settings page. Works with 123pan, Jianguoyun, Nextcloud, Synology, fnOS, ZSpace, Alist, Seafile and any RFC 4918 server. · 通用 WebDAV 网盘插件：给 Agent
