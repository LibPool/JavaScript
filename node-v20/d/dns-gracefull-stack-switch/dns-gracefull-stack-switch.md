# dns-gracefull-stack-switch

> 标签: ENETUNREACH, IPv4, IPv6, dns, stack

## 简介

Gracefull stack switching in dns.lookup. This will fix ENETUNREACH in case you have IPv4 disabled on host, but IPv6 available.
