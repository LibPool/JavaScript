# dsh-round-rightclick

> 标签: context-menu, deepseek-harness, dsh-plugin, fork, radial-menu, session

## 简介

DeepSeek Harness 圆盘快捷菜单：按轮次分叉、打断生成、复制路径与会话 ID、打开目录和导出日志。
