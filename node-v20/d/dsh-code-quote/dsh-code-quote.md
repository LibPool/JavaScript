# dsh-code-quote

> 标签: code-quote, composer, deepseek, deepseek-harness, dsh

## 简介

粘贴「路径:行号 + 代码」到 DSH 输入框时自动折叠为紧凑引用，发送时把代码快照以独立上下文消息内联给模型。
