# dhamaka

> 标签: ai, browser, llm, local-first, on-device, privacy, rust, transformer, wasm, webassembly

## 简介

A reflex layer for every input on the web. Drop in SmartField / SmartForm / SmartText and get on-device autofill, contextual spellcheck, smart paste, and cross-field inference — zero latency, zero cost, zero privacy exposure.
