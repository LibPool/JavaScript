# distpkg

> 标签: build-tool, bun, bundler, cli, dependencies, deployment, dist, docker, node, package.json, post-build, secondary-install, typescript

## 简介

Post-build tool that generates minimal package.json in dist/ and re-installs deps to ensure bundled code runs correctly
