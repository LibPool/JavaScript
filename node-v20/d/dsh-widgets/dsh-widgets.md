# dsh-widgets

> 标签: cordis, dashboard, deepseek-harness, dsh, heatmap, plugin, session-stats, web-ui, widgets

## 简介

Right-hand widget rail for DeepSeek Harness Web UI: live session stats, task/context/heatmap/quote widgets, OpenCode Go quota, multi-column grid layouts (1/2/4 columns) with 2x4 long tiles, a continuous magnification wave, and per-instance sizing. Widgets
