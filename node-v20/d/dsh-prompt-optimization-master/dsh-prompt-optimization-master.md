# dsh-prompt-optimization-master

> 标签: composer, deepseek-harness, dsh, dsh-plugin, plugin, prompt, prompt-enhance, prompt-optimization, prompt-optimizer, workbuddy, 提示词优化, 提示词增强

## 简介

DSH 输入框一键提示词增强：把未发送的草稿改写为更清晰、更具体的提示词，可一键还原。照搬腾讯 WorkBuddy「增强提示词」的双层提示词机制；独立模型调用，不建会话、不写会话记录、不读对话历史。 / One-click prompt enhancement for the DeepSeek Harness composer: rewrite the unsent draft into a clearer, more specific prompt, then restore the original
