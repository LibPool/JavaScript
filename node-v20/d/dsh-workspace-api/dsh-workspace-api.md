# dsh-workspace-api

> 标签: agent-task, deepseek-harness, dsh, dsh-plugin, http-api, workspace-api

## 简介

DSH 插件：把 workspace 内容与 DSH agent 任务能力暴露为 HTTP API（/workspace-api/*），其他程序可查询目录、搜索文件、提交自然语言任务给 agent 处理。
