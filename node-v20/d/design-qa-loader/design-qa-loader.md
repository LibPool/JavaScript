# design-qa-loader

> 标签: babel, data-source, design-qa, jsx, nextjs, source-location, turbopack, webpack-loader

## 简介

Turbopack loader that injects data-source and data-component attributes into JSX host elements, so design QA tooling can map a rendered element back to its source location.
