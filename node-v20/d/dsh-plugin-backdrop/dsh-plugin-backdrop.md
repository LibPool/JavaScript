# dsh-plugin-backdrop

> 标签: backdrop, background, deepseek, dsh, dsh-plugin, harness, webgl, whale

## 简介

DeepSeek Harness 插件：把官网 Harness 鲸鱼背景注入 dsh Web UI——WebGL2 流体 + 字符鲸鱼游动（循环接缝赛博朋克故障转场）+ 发光鱼群 + 点线网格。
