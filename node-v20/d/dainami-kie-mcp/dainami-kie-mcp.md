# dainami-kie-mcp

> 标签: ai, claude, image-generation, kie, kie.ai, mcp, model-context-protocol, video-generation

## 简介

KIE.ai connector for MCP. Five generic tools — kie_post, kie_get, kie_upload_file, kie_download, kie_fetch_model_docs — give an agent every current and future KIE model. Model specs are pulled live from docs.kie.ai with a 3-day cache; the MCP never bundle
