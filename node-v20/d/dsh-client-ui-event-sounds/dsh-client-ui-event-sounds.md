# dsh-client-ui-event-sounds

> 标签: angelina, arknights, audio, dsh, dsh-plugin, sound, voice-line, web-ui

## 简介

DSH Web GUI 语音控制插件：对话「会话结束 / 弹出选项 / 请求许可 / 停止」时播放指定音效；可拖动悬浮球（靠边缩成半球）、可移动置顶配置弹窗；音效来自插件包 sounds/ 文件夹的本地音频；支持鲸鱼娘/纯白/纯黑三种外观；配置自动保存（浏览器 + 宿主 config.json 双持久化）；启动即预加载。Hot-pluggable — mounted via dsh plugin add + cordis.patch.yml, no dsh source changes.
