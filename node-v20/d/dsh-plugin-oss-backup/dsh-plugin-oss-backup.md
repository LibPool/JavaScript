# dsh-plugin-oss-backup

> 标签: backup, client-s3, deepseek-harness, dsh, dsh-plugin, oss, rustfs, s3

## 简介

DeepSeek Harness 插件：把工作区文件备份到 S3 兼容对象存储（RustFS / 阿里云 OSS / AWS S3）。AK/SK 只从环境变量读取，绝不落盘、绝不进日志。
