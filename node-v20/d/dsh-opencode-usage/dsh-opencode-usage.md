# dsh-opencode-usage

> 标签: dsh, monitor, opencode, opencode-go, plugin, quota, theft-detection, usage

## 简介

OpenCode Go 订阅用量监控：侧边栏底部常驻徽标（5h/周/月百分比，异常标红），点击在左侧弹出详情卡片（重置倒计时、趋势、告警、Key 配置），用量突增/超标标红提醒（防额度被他人盗刷）。
