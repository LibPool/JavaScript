# dsh-tailscale-console

> 标签: deepseek-harness, dsh, plugin, remote-access, tailscale

## 简介

DeepSeek Harness 的 Tailscale 远程访问运营面板：健康检查、HTTPS 入口开关、macOS 代理绕过、中继服务器运维、ACL 片段生成。
