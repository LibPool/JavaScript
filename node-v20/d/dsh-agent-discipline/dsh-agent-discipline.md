# dsh-agent-discipline

> 标签: agent, agent-team, behavior-layer, criteria, deepseek-harness, discipline, dsh, verification

## 简介

把「判据先行、坏样本先证明会失败、返工记账」这套工程纪律做成可运行的东西：判据运行器 + 元判据（每条判据必须先用坏样本证明它会红）+ 能力账本口径 + 行为层四层分工文档 + 一份自写的行为层示例条文。
