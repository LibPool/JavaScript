# dsh-oh-my-theme

> 标签: at-mentions, deepseek-harness, dsh, dsh-plugin, file-explorer, file-system, file-tree, markdown, plugin, skin, theme, web-ui

## 简介

Theme + file workspace plugin for DeepSeek Harness (dsh) web GUI: curated --dsw-alias-* skin palettes with live hover preview, @file mentions in the composer, a lazy-loading project file tree, and Markdown preview. 为 dsh 网页端定制的主题 + 文件工作台插件：精选皮肤与悬停预览、输入框 @
