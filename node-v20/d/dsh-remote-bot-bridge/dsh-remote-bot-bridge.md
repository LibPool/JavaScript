# dsh-remote-bot-bridge

> 标签: bot, deepseek-harness, ds-bot, ds-harness-remote, dsh, plugin, remote

## 简介

Bot-to-bot messaging across machines over ds-harness-remote: lets a local Bot send messages to a Bot on a remote Host, without switching the local window.
