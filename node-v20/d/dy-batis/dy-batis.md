# dy-batis

> 标签: database, dy-batis, my-batis, mybatis, mysql, orm, xml

## 简介

dy-batis是集成了mysql数据库驱动的工具。基于xml配置的SQL语句，可以更加灵活的操作数据库，降低开发和维护难度。
