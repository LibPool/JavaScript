# dsh-global-memory

> 标签: deepseek, dsh, dsh-plugin, harness, memory, plugin

## 简介

DSH 全局记忆插件：侧边栏「全局记忆」页，直接查看/编辑 ~/.dsh/AGENTS.md 与 ~/.dsh/memory/*.md。Host 半边注册 /api/dsh-memory 路由（回环限制），client 半边注入侧边栏入口与中心面板。热插拔挂载，不改 DSH 源码。
