# dragonbones-phaser3

> 标签: JavaScript

## 简介

* Clone or download [DragonBonesJS](https://github.com/DragonBones/DragonBonesJS/). * Install [Node.JS](https://nodejs.org/). * Open `DragonBonesJS/Phaser/3.x/` in command. * $ `npm install` * $ `npm run build`
