# dsh-sql

> 标签: database, deepseek-harness, dsh, dsh-plugin, mysql, plugin, postgresql, sql, sqlite

## 简介

DSH 工程师级数据库插件：sql_list/query/exec/schema/stats/health 六工具，SQLite/MySQL/PostgreSQL 三引擎、多连接、只读模式与写操作审批门、词法级只读保护、流式行数钳制与可配置查询/写超时。
