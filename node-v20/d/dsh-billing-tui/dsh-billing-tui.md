# dsh-billing-tui

> 标签: ascii-art, billing, cli, cordis, deepseek, deepseek-harness, dsh, peak-pricing, plugin, terminal, token-usage, tui

## 简介

DeepSeek Harness 峰谷计费插件:实时统计 token 用量,按 DeepSeek V4 峰谷定价计算费用,生成 ASCII 账单小票,支持 TUI 状态行与 /billing 命令
