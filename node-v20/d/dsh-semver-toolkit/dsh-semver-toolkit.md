# dsh-semver-toolkit

> 标签: compare, dsh, npm, plugin, range, satisfies, semver, version

## 简介

Zero-dependency semantic versioning toolkit for DeepSeek Harness: parse/validate SemVer 2.0.0 (prerelease, build), compare/sort with full precedence rules, and npm-style range matching (^ ~ > < x-range hyphen ||) with maxSatisfying. Uses only Node built-i
