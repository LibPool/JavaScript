# dziry-engine-linux-x64

> 标签: JavaScript

## 简介

The dziry native engine (SDL3 + Skia + Taffy), prebuilt for linux-x64. Installed automatically as an optional dependency of dziry — not something to depend on directly.

- 源码仓库：git+https://github.com/dziry-dev/dziry.git
- npm 页面：https://www.npmjs.com/package/dziry-engine-linux-x64
