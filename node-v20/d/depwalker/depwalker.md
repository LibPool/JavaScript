# depwalker

> 标签: ast, cli, code-analysis, dependency-analysis, developer-tools, function-tracking, git, impact-analysis, refactoring, static-analysis, typescript, variable-tracking

## 简介

A comprehensive TypeScript dependency analysis tool that tracks the impact of code changes, including function calls and variable usage across your codebase
