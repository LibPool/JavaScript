# demf-kpim-compare

> 标签: JavaScript

## 简介

The KPIM Compare microfrontend compares a KPI with others KPIs from a list of already existing KPIs with same features of main. The KPIM Compare works within the KPIM tool in which it is mounted, and is an hidden page accessed from KPI's list and compare
