# dsh-desktop-transparency

> 标签: deepseek-harness, dsh, dsh-plugin, electron, glassmorphism, theme, transparency, wallpaper

## 简介

DSH Desktop 的分区透明壁纸主题：按屏幕坐标钉住系统壁纸，让窗口看起来真的透到桌面，并可分区调节透明度。Screen-aligned wallpaper behind a per-region translucent UI.
