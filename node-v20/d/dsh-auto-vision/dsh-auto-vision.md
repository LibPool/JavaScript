# dsh-auto-vision

> 标签: cordis, deepseek-harness, dsh, dsh-plugin, image, multimodal, plugin, qwen, vision

## 简介

DeepSeek Harness 视觉桥：自动发现你已配置的多模态模型，给纯文本主模型装上 vision 工具，识别结果以纯文本返回。零配置，一条命令安装。
