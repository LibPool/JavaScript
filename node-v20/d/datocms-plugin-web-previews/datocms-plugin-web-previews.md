# datocms-plugin-web-previews

> 标签: datocms, datocms-plugin, links, preview, sidebar

## 简介

Add a Visual tab for full-screen side-by-side editing with click-to-edit overlays, preview links in the record sidebar, and inline iframe previews with viewport presets
