# dsh-plugin-shortcuts

> 标签: deepseek-harness, dsh, dsh-plugin, hotkeys, keyboard-shortcuts, productivity, web-ui

## 简介

Fully customizable keyboard shortcuts for the dsh web client: 34 pre-registered features across session, view, clipboard, model, permission and system groups, recordable bindings, and permission cycling that leaves no trace in the transcript.
