# dsh-rescue-toolbox

> 标签: deepseek-harness, dsh, emergency, plugin, rescue, toolbox

## 简介

DSH 插件应急工具箱：DSH 因插件 fail-loud 无法启动时的独立急救工具（诊断问题插件 + 禁用 + 备份恢复）

- npm 页面：https://www.npmjs.com/package/dsh-rescue-toolbox
