# deepseek-mcp

> 标签: agent, anthropic, claude, claude-code, deepseek, deepseek-v4, llm, mcp, model-context-protocol, subagent

## 简介

MCP server that spawns a DeepSeek-backed Claude Code sub-session as a tool. Lets an upper Claude Code delegate work to a sub-agent running on DeepSeek's Anthropic-compatible endpoint.
