# dsh-plugin-credential-guard

> 标签: credentials, deepseek-harness, dsh, dsh-plugin, secrets, security

## 简介

DeepSeek Harness plugin: deny read/read_image/grep/glob calls whose path matches credential-store or secret-file patterns (.credentials.yaml, .env, .ssh, id_* keys, ...).
