# dsh-n8n-plugin

> 标签: automation, deepseek-harness, dsh, dsh-plugin, n8n, workflow

## 简介

DeepSeek Harness Web GUI 的 n8n 工作流运维插件：设置页可管理多个 n8n 实例（每个实例一个别名 + 实例地址 + API Key，存储于 ~/.dsh/dsh-n8n-plugin.json），并提供 13 个 Agent 工具（n8n_instances、n8n_workflows、n8n_workflow_get/create/update/delete/publish/validate、n8n_executions、n8n_execution_get、n8n_tags
