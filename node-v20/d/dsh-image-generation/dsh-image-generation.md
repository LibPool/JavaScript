# dsh-image-generation

> 标签: cordis, deepseek, deepseek-harness, dsh, dsh-plugin, image-generation, plugin

## 简介

DSH 生图插件：在设置中配置多个生图供应商/模型，并在对话中通过 image_generate 调用当前选中的模型。
