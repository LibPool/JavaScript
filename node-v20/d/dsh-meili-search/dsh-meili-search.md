# dsh-meili-search

> 标签: cordis, deepseek-harness, dsh, meilisearch, plugin, search

## 简介

DSH 会话内容检索(Meilisearch): 增量索引同步(按 seq/时间戳) + 工作区自建内容搜索面板(每会话命中块/毛玻璃卡片/实时搜索) + 命中跳转定位与分词高亮 + Settings 配置卡
