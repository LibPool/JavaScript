# dsh-plugin-vault

> 标签: JavaScript

## 简介

通用存储层插件（一 ns 一库 + 全局内容寻址字节家）：vault_put_blob/vault_get_blob/vault_db_exec/vault_db_query/vault_ns_info 五工具；包根库面冻结（老调用方迁移波再断），插件壳走 ./cordis 子路径。
