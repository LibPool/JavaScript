# dateface

> 标签: date, datetime, esm, format, formatter, intl, lightweight, relative-time, time, timezone, typescript, tz, zero-dependency

## 简介

Tiny, dependency-free, timezone-aware date formatting for JavaScript and TypeScript. Simple showDate(input, format) API.
