# dsh-tool-generate-image

> 标签: antigravity, deepseek, dsh, dsh-plugin, gemini, generate-image, harness, image, image-generation, plugin, tool, vision

## 简介

Model-facing generate_image tool for DeepSeek Harness (dsh): generates brand-new images with the Google Gemini image-generation service via the Antigravity CLI, saves them, and returns the paths. Hot-pluggable — install with `dsh plugin --profile web add
