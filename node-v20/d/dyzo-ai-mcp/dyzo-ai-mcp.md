# dyzo-ai-mcp

> 标签: JavaScript

## 简介

`dyzo-ai-mcp` is a Model Context Protocol (MCP) server for [Dyzo AI](https://dyzo.ai). This package enables AI models to interact with the Dyzo platform directly, providing capabilities to query and manage projects, tasks, task comments, and time logs rig
