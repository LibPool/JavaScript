# directus-extension-beliq

> 标签: beliq, compliance, directus, directus-custom-extension, directus-extension, directus-extension-operation, e-invoice, einvoice, en16931, factur-x, peppol, xrechnung, zugferd

## 简介

Directus Flow operation for beliq: generate, validate, parse, and convert EU-compliant e-invoices (XRechnung, ZUGFeRD, Factur-X, Peppol BIS). Saves the result straight into Directus Files.
