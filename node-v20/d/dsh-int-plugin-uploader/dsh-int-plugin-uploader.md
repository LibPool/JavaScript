# dsh-int-plugin-uploader

> 标签: JavaScript

## 简介

把你自己写的 DSH 插件打包与发布：校验 → 打包 → 备份安装 / 发布 → 台账，含版本历史与一键回滚。支持发布到自己的 GitHub 仓库、发布到 npm，或只装到本机；发布目标全部由使用者自行配置。

## 官网

- npm 页面：https://www.npmjs.com/package/dsh-int-plugin-uploader
