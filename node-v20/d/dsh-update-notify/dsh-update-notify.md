# dsh-update-notify

> 标签: cordis, deepseek-harness, dsh, notification, npm, update

## 简介

Update reminders for the DeepSeek Harness CLI and profile-installed plugins: on-demand npm-registry check (10min cache, invalidates right after an upgrade) surfaced as a row in the Settings > General page.
