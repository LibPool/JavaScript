# devcodes-lavalink

> 标签: audio, devcodes, discord, discord.js, lavalink, lavalink-v4, music, music-bot, player-persistence, typescript

## 简介

A full-featured Lavalink v4 client for discord.js — zero config, TypeScript-first, auto-reconnect, and built-in player persistence that survives full system reboots.
