# dsh-educoder

> 标签: automation, cordis, deepseek-harness, dsh, dsh-plugin, educoder, homework, 头歌

## 简介

头歌（EduCoder）作业自动化 DSH 插件：全量扫描未完成作业并一次做完。选择题靠平台在提交响应里回吐的答案键零 token 通过，只有代码题才调用模型生成→上传→评测→按报错重试。
