# dsh-web-pets

> 标签: deepseek-harness, desktop-pet, dsh, dsh-plugin, plugin, web-pet

## 简介

DSH Web 桌宠插件：浏览器里养一只随会话状态换表情的桌宠（内置 demo/remiel），支持随时切换或替换宠物形象；自带设置面板、一键更新与反馈入口
