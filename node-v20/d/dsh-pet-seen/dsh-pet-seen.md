# dsh-pet-seen

> 标签: cordis, deepseek, deepseek-harness, desktop-pet, dsh, dsh-plugin, notifications, plugin, typescript

## 简介

Bridge between DeepSeek Harness and a local desktop pet: session event push, per-session progress buckets, and 'user has actually seen it' notice acknowledgement.
