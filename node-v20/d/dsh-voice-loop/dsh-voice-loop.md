# dsh-voice-loop

> 标签: deepseek, dsh, dsh-plugin, harness, speech, tts, voice, 语音

## 简介

DSH 语音闭环：内置语音转写完成后自动发送，并把每轮回答压成一两句用自然中文音色念出来。
