# dsql

> 标签: Hibernate, MyBatis, code generation, dao, sql

## 简介

dsql has been replaced by daosql, please use daosql, a tool to convert sql to dao method, easy to use than MyBatis and Hibernate, just write runnable sql, and use this tool to generate Dao class.
