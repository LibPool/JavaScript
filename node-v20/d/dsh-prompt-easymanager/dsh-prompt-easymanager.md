# dsh-prompt-easymanager

> 标签: deepseek, deepseek-harness, dsh, dsh-plugin, prompt, prompt-manager, system-prompt

## 简介

给 DeepSeek Harness 用的个人提示词管理器：把「个人提示词 + 系统提示词改动」存成预设，按会话或全局挂载，并能改写、关闭、还原 DSH 的原生段落，还能看清模型实际收到的最终提示词。
