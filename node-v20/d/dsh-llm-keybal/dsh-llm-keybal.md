# dsh-llm-keybal

> 标签: api-key, deepseek-harness, dsh, llm, load-balancing, multi-key, plugin, round-robin

## 简介

Multi-provider API-key load-balancing LLM adapter for DeepSeek Harness (dsh): each provider route (deepseek_pool, openai_pool, claude_pool, qwen_pool, …) owns per-model key pools with round-robin / random / least-used / health strategies, failure cooldown
