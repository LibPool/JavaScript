# dsh-net-proxy

> 标签: deepseek, dsh, dsh-plugin, harness, http, network, proxy, socks5

## 简介

DeepSeek Harness network-proxy plugin: route the agent's own network requests (web_search / web_fetch / external APIs) through a configured HTTP/HTTPS-CONNECT/SOCKS5 proxy — both the global fetch wrapper and the harness proxy layer that web_fetch actually
