# dsh-a2a

> 标签: a2a, agent, agent2agent, cordis, deepseek, deepseek-harness, dsh, protocol

## 简介

dsh-a2a: A2A v1.0 for DeepSeek Harness — expose the harness as an A2A agent and call remote A2A agents from agent tools.
