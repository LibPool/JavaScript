# dsh-plugin-choice-refresh

> 标签: ask-user, chat-ui, choice, cordis, deepseek, dsh, dsh-plugin, frontend, harness, more-options, options, plugin, question, refresh, regenerate-options, ux

## 简介

DSH 选择增强插件（生态唯一）：给 ask_user_question / ask_user_choice 的选择卡加「重新生成选项 / 更多选项」两个按钮——选项都不满意一键换一批（换角度/维度，5~8 个），选项太少一键补充到 6~10 个。纯前端交互实现，不改核心包、不新增工具，原生文字卡与图片选择卡通吃。
