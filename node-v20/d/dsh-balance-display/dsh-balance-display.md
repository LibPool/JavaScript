# dsh-balance-display

> 标签: api-key, balance, deepseek, deepseek-harness, dsh, plugin, web-ui

## 简介

DeepSeek API balance pill for the DSH Web GUI: shows remaining credit in the left sidebar footer with low-balance alerts, spend history, and a one-click top-up link. The API key never leaves the host process — the host half resolves it through the dsh cre
