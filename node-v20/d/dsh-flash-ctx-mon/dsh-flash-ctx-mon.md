# dsh-flash-ctx-mon

> 标签: JavaScript

## 简介

Context monitor provider for the `dsh-flash` Quick Control panel — registers a context-alert provider (session token usage estimation) via ctx.get('dockFlashAlerts') and tracks context window pressure through DSH session events.
