# dsh-toc-tail

> 标签: JavaScript

## 简介

对话目录尾栏 + 回溯：对话列右侧的轻量 TOC Tail，把每条用户请求压缩为一条横线形成纵向时间轴；目录面板支持一键回溯到任意用户请求节点（折叠其后的对话，可选 LLM 总结与代码状态恢复）。
