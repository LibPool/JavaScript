# deploy-mcp-eklps

> 标签: JavaScript

## 简介

这是一个基于 [Model Context Protocol (MCP)](https://modelcontextprotocol.io/) 的前端部署工具。它可以让 AI 助手（如 Claude Desktop）直接通过指令执行前端项目的静态部署。
