> 标签: discord, discord api, discord components, discord-forms, discord-modal, discord-modals, discord.js, discord.js components, discord.js modal, discord.js-forms, discord.js-modals, discordjs-modal, djs v13, forms, interaction modals, modal form, modal interactions, modal submit, modals, modalsubmit, shuruhatik, textinputs

## 简介

The package helps you to create a modal, which is a new feature of Disocrd, but it is not supported at the moment in djs, so this package will make it easier for you to do it with discord.js v13
