# dsh-diff-card

> 标签: code-review, deepseek-harness, diff, dsh, dsh-plugin, plugin

## 简介

Per-turn file-change card for DSH Desktop: +N −M badges, aligned diffs, and Mac/Windows file open (system app, Finder/Explorer, VS Code).
