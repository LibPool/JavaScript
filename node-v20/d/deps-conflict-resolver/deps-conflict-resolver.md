# deps-conflict-resolver

> 标签: alias, dependency-resolver, peer-dependencies, plugin, vite, vue2, vue3, webpack

## 简介

A webpack/vite plugin that automatically resolves peer dependency conflicts by creating aliases for conflicting versions
