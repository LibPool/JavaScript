# dsh-restart

> 标签: client-plugin, deepseek-harness, dsh, plugin, restart, watchdog

## 简介

DSH 重启插件：可配置的重启方式（Node 原生 / 旧 PowerShell 适配）、重启后自动继续的提示词、可选看门狗自动拉起。
