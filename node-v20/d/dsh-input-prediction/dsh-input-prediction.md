# dsh-input-prediction

> 标签: autocomplete, composer, deepseek-harness, dsh, dsh-plugin, input-prediction

## 简介

DSH 输入预测插件：在输入框里用灰字续写你可能要发的下一句（Tab 接受），每轮回复后再给 1–3 条可一键发送的建议。
