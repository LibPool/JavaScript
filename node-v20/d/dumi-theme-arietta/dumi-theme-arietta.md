# dumi-theme-arietta

> 标签: arietta-studio, dumi, dumi theme

## 简介

dumi-theme-arietta is a documentation site theme package designed for dumi2. It provides a more beautiful and user-friendly development and reading experience based on @arietta-studio/ui
