# dsh-computer-use-compat

> 标签: compat, computer-use, deepseek-harness, dsh, dsh-plugin, section-order, system-prompt

## 简介

Backfill prompt-section order keys that DSH core 0.1.5-rc.2 lacks, so the official DeepSeek Harness computer-use providers can load on an older host.
