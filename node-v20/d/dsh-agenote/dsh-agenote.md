# dsh-agenote

> 标签: JavaScript

## 简介

DeepSeek Harness 的 agenote 集成插件：动态上下文注入记忆简报与召回、会话开始注入知识库健康度、turn 结束检测完成信号并转交 agenote-review 流程、宿主侧 agenote_write 写入工具，外加 /agenote-summarize|curate|health 斜杠命令。行为规范由 agenote-skills 定义，插件只做事件触发、注入通道、命令快捷入口与写入通道。
