# deepadata-edm-sdk

> 标签: deepadata, edm, emotional-data-model, extraction, llm

## 简介

SDK for assembling EDM artifacts from user content. LLM-assisted extraction with interpretation constraints and profile support. Emitted artifacts stamp the installed edm-spec version.
