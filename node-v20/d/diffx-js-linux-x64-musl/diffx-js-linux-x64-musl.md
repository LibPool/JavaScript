# diffx-js-linux-x64-musl

> 标签: automation, ci-cd, comparison, configuration, csv, data-analysis, devops, diff, ini, json, napi-rs, rust, semantic, structured, toml, xml, yaml

## 简介

Node.js bindings for diffx - semantic diffing of JSON, YAML, TOML, XML, INI, and CSV files. Powered by Rust for blazing fast performance.
