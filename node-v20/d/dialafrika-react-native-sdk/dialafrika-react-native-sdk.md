# dialafrika-react-native-sdk

> 标签: Bonga, DialAfrika

## 简介

The DialAfrika React Native SDK allows you to integrate DialAfrika's Ticketing services into your React Native applications. This SDK provides access to features such as live chat and support ticket creation. ### Prerequisites
