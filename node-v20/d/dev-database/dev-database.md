# dev-database

> 标签: collections, database, db, discord, discord-bot, dot-notation, embedded-database, events, file-database, json, json-database, key-value, lightweight, multi-driver, mysql, nosql, sql, sqlite, storage, ttl, typescript

## 简介

A high-performance, typed multi-driver database with events, collections, dot notation, TTL, math/array operations, and zero core dependencies. Supports JSON, MySQL, SQLite. Perfect for Discord bots, small projects, and prototyping.
