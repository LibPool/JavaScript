# dsh-release-infringement-audit

> 标签: compliance, deepseek-harness, dsh, dsh-plugin, license-audit

## 简介

DSH plugin: one agent tool that audits a project for release-time infringement risk (licence contagion, copied third-party code, assets, trademarks, secrets) before publishing.
