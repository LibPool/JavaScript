# dsh-winstage-sandbox

> 标签: agent, approval, deepseek-harness, dsh-plugin, sandbox, staging, windows

## 简介

DeepSeek Harness (DSH) plugin: WinStage staging–candidate–selective-commit sandbox for Windows. AI changes land in a staging tree (files + registry); a review panel shows the diff and only approved changes are written to the real workspace.
