# dsh-live-data

> 标签: bilibili, deepseek-harness, dsh, dsh-plugin, fx, github, gold, live-data, npm, pypi, realtime, stock, weather, 天气, 实时数据, 汇率, 行情, 金价

## 简介

实时数据聚合：10 个工具，从 8 个免密钥公开接口拉取模型自身没有的实时数据——汇率（open.er-api.com）、天气（Open-Meteo）、npm 包版本、GitHub 仓库信息、PyPI 包版本（清华镜像）、B站视频信息、A股行情/大盘指数（新浪财经）、金价（上金所元/克 + 国际美元/盎司）、公网 IP 归属地。输出按中文习惯：中文货币名、「100 外币 = X 人民币」报价、风力「级」、涨跌额+涨跌幅、金额「万/亿」单位。设置面板可配置各工具默认参数。All-in-one live-da
