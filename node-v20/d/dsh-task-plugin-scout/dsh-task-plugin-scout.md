# dsh-task-plugin-scout

> 标签: agent-tools, cordis, deepseek-harness, dsh, dsh-plugin, plugin-discovery, plugin-manager

## 简介

Find the plugins that make a task easier — a DeepSeek Harness (DSH) plugin that ranks this profile's installed, disabled and marketplace plugins for the task at hand and prints the exact next step for each. · 按任务排序本机插件（已启用 / 未启用 / 市场可安装）并给出下一步。
