# dafy-whale-theme

> 标签: blue-whale, deepseek-harness, dsh, theme, web-plugin

## 简介

蓝色大肥鱼主题：DeepSeek Harness web 前端的海洋配色、游动鱼群与上升气泡，带「设置 → 海洋主题」可调面板。
