# dsh-lan-gateway

> 标签: JavaScript

## 简介

LAN/remote access gateway for the DeepSeek Harness Web UI: 0.0.0.0 binding, crypto.randomUUID polyfill, token gate v3 (401 login page incl. loopback + index-401 fallback), privileged-fence + settings-persistence exemptions. Trusted networks only.
