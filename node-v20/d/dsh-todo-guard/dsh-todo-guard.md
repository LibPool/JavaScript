# dsh-todo-guard

> 标签: checklist, deepseek-harness, dsh, dsh-plugin, guard, reminder, staleness, task-list, todo, todo-list, 任务清单, 待办, 提醒

## 简介

Task-list staleness guard for DeepSeek Harness: when the model stops updating its todo list but keeps working, the guard appends a short reminder before the next step so the list gets written back to the real progress. / 任务清单陈旧度守卫：模型建了清单却忘记回写时，在下一步之前自动追加一
