# domlens.js

> 标签: browser, canvas, capture, dom-to-image, foreignobject, html-to-image, html2canvas, png, rasterize, screen-capture, screenshot, svg

## 简介

Fast, high-fidelity DOM-to-image capture for the browser. Dual-engine (SVG foreignObject with a canvas-repaint fallback) successor to html2canvas.
