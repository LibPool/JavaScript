# detrzip

> 标签: cli, deterministic, zip

## 简介

Create zip with the same hash if it has the same content. Basically a wrapper around https://github.com/bitgenics/deterministic-zip to allow it to run on the command line.

- 源码仓库：https://gitlab.com/gordlea/detrzip.git
