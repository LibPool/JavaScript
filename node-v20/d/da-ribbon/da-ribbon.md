# da-ribbon

> 标签: component, quasar, ribbon, vue

## 简介

Componente **Ribbon** personalizable para **Vue**.   Ideal para mostrar versiones, etiquetas de entorno (DEV, QA, PROD)..., en cualquiera de las esquinas de un contenedor.
