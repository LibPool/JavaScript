# dsh-promptimizer

> 标签: deepseek-harness, dsh, optimizer, plugin, prompt

## 简介

Prompt optimizer for DeepSeek Harness (DSH): one click rewrites your prompt into a professional spec using the CURRENTLY SELECTED model — Light / Standard / Deep strengths, streaming, Esc-cancel, zh/en UI. Works with any OpenAI-compatible endpoint.
