# dsh-read-url

> 标签: deepseek-harness, dsh, dsh-plugin, markdown, readability, reader, url-reader, web

## 简介

DeepSeek Harness URL reader: fetch any webpage (HTML/JSON/RSS/Atom), auto-detect encoding (UTF-16 BOM/GBK/Big5/Shift-JIS), extract clean main content with auto-pagination, output compact text/Markdown to save tokens. Zero runtime dependencies, no API key,
