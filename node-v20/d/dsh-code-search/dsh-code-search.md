# dsh-code-search

> 标签: code-search, deepseek-harness, dsh, embedding, plugin, semantic-search

## 简介

代码库语义检索插件：本地索引会话工作区（bge-small-zh-v1.5 ONNX 内嵌），向 agent 注册 code_search 工具，语义定位相关代码。
