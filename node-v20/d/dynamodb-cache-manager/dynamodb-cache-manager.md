# dynamodb-cache-manager

> 标签: JavaScript

## 简介

Library is extenstion for [cache-manager](https://github.com/BryanDonovan/node-cache-manager).  DynamoDB is not typical usecase for caches, but can be used as backing engine to store your cache or configuration.
