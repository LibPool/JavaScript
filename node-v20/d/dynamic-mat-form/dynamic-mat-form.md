# dynamic-mat-form

> 标签: 'angular', 'dynamic, 'dynamic-form', 'multi, field', form', library'

## 简介

dynamic-mat-form is a library to generate a Form and field in Angular automatically based on certain configuration of field that passed as a props and layout based on bootstrap.
