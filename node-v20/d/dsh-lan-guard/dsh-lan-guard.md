# dsh-lan-guard

> 标签: cordis, deepseek-harness, dsh, lan, plugin, reverse-proxy

## 简介

DSH web plugin: expose the official desktop Web UI to the local network through a gated reverse proxy, without touching DSH's own loopback binding.
