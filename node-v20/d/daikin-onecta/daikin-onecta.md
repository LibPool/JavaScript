# daikin-onecta

> 标签: daikin, heatpump, onecta

## 简介

This zero-dependency Node.js module integrates with the Daikin Onecta API for controlling internet-connected heat pumps. It handles OAuth2 authentication, token refreshing, and provides access to key API features like retrieving user info, managing sites,
