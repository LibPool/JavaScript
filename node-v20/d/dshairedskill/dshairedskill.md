# dshairedskill

> 标签: JavaScript

## 简介

DSHairedskill 小工具箱：一个 stdio MCP server，向 DSH/Claude Code/Codex 等 MCP 客户端暴露红蓝队安全测试原语（侦察、交互、检测、制品与依赖扫描）。知识由 skills/ 提供，本包提供可调用的手。
