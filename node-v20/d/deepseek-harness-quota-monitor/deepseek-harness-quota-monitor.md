# deepseek-harness-quota-monitor

> 标签: deepseek-harness, dsh, monitor, plugin, quota, usage

## 简介

Multi-provider quota monitor for DeepSeek Harness: balance type (query + JS parser) and window type (local sliding-window metering), with Command Code support, live spend animation and refresh progress. Sidebar widget + Plugins page.
