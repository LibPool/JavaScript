# dbt-js

> 标签: analytics, dag, data-transformation, dbt, duckdb, elt, etl, mysql, postgres, sql, sqlite

## 简介

A minimalist, dbt-like SQL transformation tool for Node.js — compile SQL models, build a dependency DAG, and materialize them on any supported SQL database.
