# dsh-web-dock

> 标签: deepseek, dsh, embed, plugin, poc, proxy, web-dock

## 简介

DSH plugin: dock web apps (built-in: DeepSeek Web) into the DSH UI via a same-origin reverse proxy + Service Worker. Supports in-place login, chat, session persistence and diagnostics.
