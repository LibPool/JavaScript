# dsh-birthday

> 标签: birthday, calendar, deepseek-harness, dsh, dsh-plugin, hebrew, islamic, lunar

## 简介

DSH plugin: multi-calendar birthday library plus a 万年历 (perpetual calendar) — Gregorian / Lunar / Islamic / Hebrew with pluggable adapters
