# dsh-screen-capture-record-desktop

> 标签: cordis, deepseek-harness, dsh, dsh-plugin, screen-capture, screen-recording, screenshot, 录屏, 截图

## 简介

DSH 桌面版输入框工具条插件：在「听写」左边加「录屏」与「截图」两个按钮 —— 录屏前先弹「选择要录制的内容」框（屏幕/窗口/自定义区域），截图带选区 + 标注（拖完框选手一松就能画）。Screen capture & recording buttons for the DSH desktop composer.
