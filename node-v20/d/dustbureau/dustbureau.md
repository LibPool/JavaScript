# dustbureau

> 标签: ai-agents, audit, cardano, compliance, credentials, masumi, midnight, mip-003, secrets-management, vault

## 简介

TypeScript/JavaScript SDK for the Dust Bureau Agent Vault — call external APIs through a vault that holds the credentials, with on-chain-anchorable audit trail.
