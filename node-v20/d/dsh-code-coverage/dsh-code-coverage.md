# dsh-code-coverage

> 标签: ai-code, attribution, c8, code-coverage, deepseek-harness, dsh, dsh-plugin, testing

## 简介

AI 给你写的代码，到底有多少在被测试保护着？解析 DSH session 日志归因 AI 生成文件，叠加 c8 覆盖率，产出「AI 代码 vs 人工代码」覆盖率对比、未测 AI 文件风险清单与信任分。
