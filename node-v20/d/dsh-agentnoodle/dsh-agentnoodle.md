# dsh-agentnoodle

> 标签: ai, chat, deepseek, dsh, dsh-plugin, game, harness, narrative, rpg, tavern

## 简介

可扩展的 AI 群像聊天游戏框架（DeepSeek Harness 插件）：输入一个行动，多个 NPC 各自回应，带头像插图；世界、地点、NPC 与功能扩展都可在对话里让 agent 直接添加修改，无需写代码。
