# deepseek-token-monitor

> 标签: api, balance, deepseek, monitor, token, usage, windows

## 简介

Launch and install DeepSeek Token Monitor — a Windows desktop app that monitors your DeepSeek API balance, token usage and spending by signing into your DeepSeek Open Platform account.
