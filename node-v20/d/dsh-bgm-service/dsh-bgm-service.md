# dsh-bgm-service

> 标签: audio, bgm, cordis, deepseek-harness, dsh, music, player, plugin

## 简介

DBS (DSH BGM service) — 独立于 DET 的 DeepSeek Harness 音乐播放器插件：本地音乐库 + 浮动播放器 + AI 依据任务控制播放(模型工具 + 自动联动) + 网络下载入库 + 乐评爬取(尽力而为)。A standalone DeepSeek Harness BGM player plugin: local music library, floating player, AI-driven playback via model tools & auto-link
