# decidio

> 标签: agent-governance, ai-agents, approvals, authority, human-in-the-loop, verifiable-credentials

## 简介

The short name for the Decidio SDK's command line: `npx decidio` runs the same CLI as `npx @decidio/sdk` (this package holds nothing but that hand-off).
