# droppjs

> 标签: cloudflare-r2, cms, digital-asset-management, ecommerce, express, file-upload, image-processing, image-upload, media-library, media-management, multer, nestjs, nextjs, prisma, s3, saas, sharp

## 简介

Node.js media library for file uploads, image management, and S3/R2 storage. Works with Next.js, Express, NestJS, Prisma, and ecommerce or SaaS apps.
