# dbopt-engine

> 标签: autonomous, database, index, mysql, optimizer, performance, postgres, sqlserver

## 简介

Self-optimizing database engine: watches real query traffic, verifies missing indexes before creating them, drops unused ones, with a live dashboard and schema topology explorer. PostgreSQL, MySQL 8, SQL Server.
