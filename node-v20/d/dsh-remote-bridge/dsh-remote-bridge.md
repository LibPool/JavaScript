# dsh-remote-bridge

> 标签: android, deepseek-harness, dsh-plugin, remote-access, rest-api, vibe-coding

## 简介

Versioned REST bridge for DeepSeek Harness: remote access for trusted clients (chat, files, devices) plus a Phone-settings panel inside the DSH WebUI.
