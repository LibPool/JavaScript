# dwtest-release-tools

> 标签: JavaScript

## 简介

This package contains 3 tools: 1. Use Track2 Codegen to generate codes by inputting swagger, and then run `rush update & rush build`. 2. Use Track2 Codegen to generate codes in swagger pipeline. 3. Generate changelog and bump version for Azure Track2 JS S
