# demf-kpim-editor-formula

> 标签: JavaScript

## 简介

The KPIM Editor Formula microfrontend helps a user to conceptually define the KPI by describing it and assigning it a Formula for calculation it. The KPIM Editor Formula works within the KPIM tool in which it is mounted, and is a step of the KPI Editor mi
