# dsh-notify-bell

> 标签: JavaScript

## 简介

DSH notification plugin with semantic sounds (done/block/permission/question/error): final assistant answer, approval/asked, ask_user_question, goal block, and agent/error notify. Playback selector (browser SSE+Web Audio / backend BEL/WAV / none) in a Web
