# dsar-warden

> 标签: article-15, compliance, data-export, dsar, gdpr, github-action, privacy, sarif, subject-access-request

## 简介

Assemble Data Subject Access Request (DSAR / GDPR Article 15) exports from CSV, JSON and JSONL sources into one structured, checksummed bundle, and check it: subject matching, secret fields removed, third-party data flagged, Article 15 metadata, identity
