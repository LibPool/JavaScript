# dsh-attention

> 标签: approval, deepseek-harness, dsh, dsh-plugin, notification, toast, windows

## 简介

DeepSeek Harness 插件：审批/提问时弹出可操作的 Windows Toast，并在浏览器标签休眠后唤醒重连，避免提权卡片卡住
