# dsh-vscode-ui

> 标签: JavaScript

## 简介

DSH web plugin: a VSCode-like left-tree right-preview sidebar (explorer / editor / terminal / git / browser), isolated per conversation session. Fork from dsh-vscode-ui with VS Code style layout.
