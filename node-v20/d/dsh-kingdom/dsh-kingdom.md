# dsh-kingdom

> 标签: deepseek-harness, dsh, dsh-plugin, governance, kingdom, multi-agent

## 简介

个人 Agent 工作台：任务与交付、独立人类管理窗口、有界协作、权限与资源约束、用量和软预算；Worker Claim 经过主管审查才成为事实。
