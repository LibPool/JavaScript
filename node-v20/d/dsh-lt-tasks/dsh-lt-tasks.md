# dsh-lt-tasks

> 标签: deepseek-harness, dsh, long-running, plugin, task

## 简介

Multi-window long-running task management plugin for DeepSeek Harness: a task is a persistent folder (11-document archive + minimal handoff index), with lock-based concurrency, read-only references, 6-state machine, and a left-sidebar Tasks view.
