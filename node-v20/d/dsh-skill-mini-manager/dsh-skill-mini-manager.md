# dsh-skill-mini-manager

> 标签: deepseek-harness, dsh, dsh-plugin, skill, skill-manager, skill-mini-manager, skills

## 简介

Minimal skill manager for DSH Web: a Settings page beside Plugins that lists every installed skill with its summary, source and size, and removes any of them (recoverable trash). skill极简管理：与「插件」同级的一页，列出全部 skill 及简介并可逐个移除。
