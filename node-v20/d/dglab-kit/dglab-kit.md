# dglab-kit

> 标签: JavaScript

## 简介

DGLAB KIT 是面向 **DG-LAB 4 APP** 的 TypeScript SDK。它可以在 Bun、Node.js、浏览器或其他 JavaScript 运行环境中，通过 WebSocket 与 DG-LAB 4 APP 配对，并控制 APP 暴露的本地设备
