# dsh-ai-memory

> 标签: agent-disposed, ai-memory, cordis, deepseek-harness, dsh, dsh-plugin, finalize-session, memory, session-end

## 简介

Closes ai-memory's consolidation loop for DSH: when a DSH session ends, calls ai-memory finalize-session so its captured observations become searchable wiki pages the other harnesses ai-memory serves can retrieve. Skips subagents, queues concurrent sessio
