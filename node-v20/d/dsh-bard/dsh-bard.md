# dsh-bard

> 标签: bard, character-card, deepseek-harness, dsh, dsh-plugin, lorebook, roleplay

## 简介

Bard-style role-play for DeepSeek Harness: import SillyTavern character cards (JSON/PNG) and world books (lorebooks), pick Harness skills, save the combination as a native DSH agent preset, and emit the card opening text.
