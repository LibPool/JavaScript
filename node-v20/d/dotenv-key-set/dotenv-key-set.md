> 标签: .env, ci, cli, config, dotenv, dotenv-file, dotenv-key-set, dotenv-set, edit-env, env, env-file, env-writer, environment-variables, in-place, modify-dotenv, preserve-comments, scripts, set-env, update-env, update-env-file, upsert, version-bump, zero-dependencies

## 简介

Set, update, or add a single key in a .env (dotenv) file from the CLI or Node.js — preserves comments, ordering, and other keys. Zero dependencies.
