# dyeditor-balloon

> 标签: ckeditor5, dyeditor, react

## 简介

DYEditor-Balloon is 2nd DYEditor series of DYEditor which is custom made to use [CKEditor5](https://www.npmjs.com/package/ckeditor5) in React.
