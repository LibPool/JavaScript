# dsh-fence

> 标签: cordis, deepseek, deepseek-harness, dsh, dsh-plugin, guardrail, plugin, security, tool-fencing

## 简介

Declarative tool fencing for DeepSeek Harness: allow/deny/ask rules over tool invocations with argument globs, wired to the native approval flow, with an audit trail.
