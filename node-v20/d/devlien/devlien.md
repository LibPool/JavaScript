> 标签: /auth, backend, controller, devlien, expressive, framework, lightweight, minimal, model, mvc, no-dependencies, node-framework, nodejs, orm, pure-nodejs, rest-api, routing, service

## 简介

Devlien is a lightweight, zero-dependency Node.js framework with clean MVC structure, built-in ORM, and intuitive routing for rapid backend development.
