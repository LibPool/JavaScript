# dsh-workspace-acl-allow

> 标签: acl, deepseek-harness, dsh-plugin, windows

## 简介

DeepSeek Harness 插件：为用户显式声明的工作区目录预置 Windows ACL 完全控制 ACE，补上沙箱授权所需的 WRITE_OWNER 前提，消除危险模式弹框。
