# drillable-context

> 标签: agent, claude, context, conventions, drillable, grounding, mcp, memory

## 简介

Grounds your coding agent in YOUR project's facts — your docs, decisions, and conventions — so it drills them instead of guessing, and says "no record" instead of bluffing. A local, stdlib-only MCP server over a folder of markdown you point it at.
