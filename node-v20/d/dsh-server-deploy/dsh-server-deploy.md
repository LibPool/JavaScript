# dsh-server-deploy

> 标签: bundle, deepseek-harness, deploy, deployment, dsh, microservices, plugin, sftp, ssh, test-server

## 简介

DSH plugin bundle: one-click test-server deployment for single-service and microservice projects (per-service servers, zero local runtime deps) plus a right-side deployment status panel.
