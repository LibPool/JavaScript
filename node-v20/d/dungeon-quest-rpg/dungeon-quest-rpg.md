# dungeon-quest-rpg

> 标签: dungeon, embeded, game, javascript, quest, rpg

## 简介

The dungeon-quest-rpg is a simple, lightweight vanilla JavaScript game based on FreeCodeCamp course. It could be embeded to the page to add some oomph to it.
