# dsh-completion-reminder

> 标签: agent, browser-notification, completion, deepseek, dsh, harness, notification, plugin, reminder

## 简介

DSH client plugin — notify the user when an agent finishes. 10 directly-reachable channels incl. Feishu bots; settings live inside DSH's dialog; persistent config.
