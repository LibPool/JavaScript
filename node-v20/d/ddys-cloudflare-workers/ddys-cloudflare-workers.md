# ddys-cloudflare-workers

> 标签: api, cache, cloudflare, cloudflare-workers, ddys, edge, proxy, workers

## 简介

Official Cloudflare Workers integration for the DDYS API with an edge proxy, Cache API support, CORS, diagnostics, revalidation, and embeddable Worker factory.
