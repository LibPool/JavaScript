# dsh-catalog-refresh

> 标签: catalog, deepseek-harness, dsh, fireworks, models, opencode, openrouter, pi-ai, plugin

## 简介

Rebuild DSH's pi-ai model catalogues at runtime: fetches the live model lists from OpenRouter, OpenCode Zen, Fireworks, Groq, Together and DeepSeek and patches the harness's installed pi-ai MODELS registry, so the model picker and discovery show fresh mod
