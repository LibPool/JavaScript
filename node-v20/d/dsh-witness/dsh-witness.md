# dsh-witness

> 标签: background-jobs, deepseek-harness, dsh, dsh-plugin, job-queue, reliability, sandbox, windows-acl

## 简介

Witness jobs for DeepSeek Harness: crash-surviving background tasks where the filesystem is the source of truth - cross-restart adoption, autopsy reports, sandboxed execution, event sourcing. Tested on Windows 11 NTFS.
