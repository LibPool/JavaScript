# delirium-proxmox

> 标签: api, nest, node, proxmox, wrapper

## 简介

A Node.js library for interacting with the Proxmox API. It provides a simple and lightweight wrapper around the Proxmox API, making it easier to manage your Proxmox virtual environments from a Node.js application.
