# domainwright

> 标签: cloudflare, cloudflare-for-saas, custom-domains, custom-hostnames, dns, domain-registration, domains, multi-tenant, name.com, nextjs, saas, typescript, workers, workers-custom-domains

## 简介

Modular TypeScript SDK for custom-domain onboarding in multi-tenant SaaS apps on Cloudflare Workers: search, registration, zones, DNS, Worker routing, verification and resumable workflows.
