# dsh-bubble-fold

> 标签: beautify, client-plugin, collapse, composer, deepseek-harness, dsh, dsh-plugin, fold, search, sidebar, transcript, ui

## 简介

Display polish for the DeepSeek Harness conversation: fold overlong messages and work-step blocks, resize the composer and the right sidebar, and search folded content. Pure client-side and display-only.
