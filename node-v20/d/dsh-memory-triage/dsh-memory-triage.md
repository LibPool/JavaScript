# dsh-memory-triage

> 标签: deepseek-harness, dsh, dsh-plugin, memory, triage

## 简介

DeepSeek Harness 记忆分诊插件：自动判断记忆保留/归档，并自动路由到项目桶或总体桶（规则优先 + LLM 兜底）
