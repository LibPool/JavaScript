# dsh-command

> 标签: agent, code-review, deepseek-harness, dsh, git, plugin, slash-command

## 简介

DSH 拓展命令插件：/init 生成 AGENTS.md、/review 审计代码（git 改动或指定路径）、/git-commit 本地提交（绝不 push）
