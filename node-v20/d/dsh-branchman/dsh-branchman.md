# dsh-branchman

> 标签: agent-workspace, branching, cordis, deepseek-harness, dsh, dsh-plugin, git-worktree, session-fork

## 简介

Tree-branching workspace plugin for DeepSeek Harness: open an engineering direction as one atom — a git worktree plus a child session that inherits the conversation, wired into a tree you can see.
