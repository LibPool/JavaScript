# devicedeck

> 标签: android, e2e, emulator, ios, maestro, mcp, mobile-testing, playwright, simulator

## 简介

Automate your iOS and Android app like a web app: the simulator or emulator is served as a web page, so Playwright tests and AI agents drive the native app by selector.
