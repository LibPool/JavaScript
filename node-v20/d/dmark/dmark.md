# dmark

> 标签: automation, demarcation, demark, dry, iac, parameterizable, parametrize, stacks, stages, terraform, tf, wrapper

## 简介

Terraform wrapper for multi-stage and multi-stack which only add a config file. Perfect for no HCP projects.
