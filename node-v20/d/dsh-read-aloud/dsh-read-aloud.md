# dsh-read-aloud

> 标签: accessibility, deepseek, dsh, dsh-plugin, harness, read-aloud, speech, text-to-speech, tts

## 简介

A speaker button beside the Like button: read any assistant reply aloud with the browser's built-in speech engine, with speed and voice control. · 在点赞旁加一个小喇叭，朗读 DSH 的回复，支持倍速与音色。
