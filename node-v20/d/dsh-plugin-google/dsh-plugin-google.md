# dsh-plugin-google

> 标签: calendar, deepseek-harness, dsh, dsh-plugin, google-calendar, google-tasks, oauth2, tasks, todo

## 简介

DeepSeek Harness plugin for Google Calendar and Google Tasks: conversational CRUD over events, calendars, tasks and task lists, with built-in OAuth 2.0 loopback authorization
