# dash.js

> 标签: admin, components, console, dashboard, hanzo, hanzo-ui, react, shadcn, tailwind

## 简介

Hanzo Dashboard Kit — drop-in React building blocks for admin dashboards (shell layout, sidebar nav, stat + chart cards, sortable data table). Composes @hanzo/ui primitives; monochrome true-black tokens, red for errors only.
