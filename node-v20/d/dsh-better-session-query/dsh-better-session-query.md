# dsh-better-session-query

> 标签: block, cordis, deepseek-harness, dsh-plugin, fts5, search, session

## 简介

DSH 插件：给会话历史再挂一套块级并行索引——一条消息拆成 text/reasoning/tool-call/tool-result 等块，块是索引行，可按块检索与读取。不替换官方 session-query，不改任何 DSH 源码。
