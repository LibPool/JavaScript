# dsh-theme-windowsxp

> 标签: deepseek, dsh, dsh-plugin, harness, luna, skin, theme, windows-xp

## 简介

把 DSH 换成 Windows XP：Luna 蓝皮肤（米色面板、渐变按钮、#7F9DB9 输入框、圆角滚动条、Bliss 桌面壁纸）＋ 一轮跑完时的提示音与完成弹窗。
