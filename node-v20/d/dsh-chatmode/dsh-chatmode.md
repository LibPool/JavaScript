# dsh-chatmode

> 标签: agent-preset, chat-mode, deepseek-harness, dsh, dsh-plugin

## 简介

Your skill will be retained, but the model won't take any actions, and it will only generate an answer once. Being able to have an experience similar to a webpage will save a lot of tokens. / 将保留你的Skill，但是模型不会进行任何操作，并且思考也只会一次性生成答案。能做到和网页相似的体验，将会非常节省token。
