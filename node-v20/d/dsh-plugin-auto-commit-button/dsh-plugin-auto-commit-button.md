# dsh-plugin-auto-commit-button

> 标签: autocommit, commit, composer, cordis, cordis-plugin, deepseek, deepseek-harness, dsh, dsh-plugin, git, toggle

## 简介

Adds a menu to the DeepSeek Harness composer with two switches: Auto-commit commits the repository holding the session's workspace at the end of every turn, and Auto-push pushes each of those commits.
