# delta-sync

> 标签: conflict-free, crdt, database, delta-sync, distributed, file-sync, indexeddb, offline-first, real-time, replication, sync, typescript, versioning

## 简介

A lightweight framework for bi-directional database synchronization with automatic version tracking and conflict resolution.
