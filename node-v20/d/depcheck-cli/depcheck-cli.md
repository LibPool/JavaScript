# depcheck-cli

> 标签: cli, dependency-analyzer, dependency-checker, dependency-health, dependency-management, deprecated-packages, javascript-cli, node-cli, node-project-health, nodejs-optimizer, npm-audit, npm-cli-tool, optimize-node-modules, outdated-dependencies, package-cleaner, project-maintenance, reduce-bundle-size, remove-unused-packages, unused-dependencies

## 简介

CLI tool for Node.js projects to analyze dependencies: find unused packages, detect deprecated dependencies, and identify largest modules to reduce bundle size and improve performance.
