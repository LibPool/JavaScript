# dp-data-table

> 标签: data table, dp-data-table, easy data table, filterable data table, filterable grid, filterable table, react-component, simple data table, sortable data table, sortable table

## 简介

A simple and easy to customize data table with filter and sort functionalities. This component is build using React and can be directly used in static html as well.
