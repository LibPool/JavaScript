# dsh-fm

> 标签: cordis, dsh, dsh-plugin, file-manager, git

## 简介

工作目录文件管理器：树形浏览、只读预览（代码/图片/Markdown/Mermaid）、Git 变更管理/仓库初始化/索引管理
