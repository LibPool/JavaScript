# dsh-ops-console

> 标签: console, deepseek, dsh, dsh-plugin, harness, ops, remote-access, tailscale

## 简介

DeepSeek Harness 的简洁远程访问面板：准备 Tailscale 入口、检查就绪状态并生成本地访问二维码。
