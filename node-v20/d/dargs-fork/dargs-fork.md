# dargs-fork

> 标签: args, arguments, argv, bin, binary, cli, cmd, command, commander, construct, flags, inverse, invert, minimist, nopt, opposite, options, parse, parser, reverse, switch

## 简介

Patch for the [dargs][] package, that adds support for single flags. Convert an object of options into an array of command-line arguments.
