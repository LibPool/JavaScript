# dsh-arknights-theme

> 标签: acrylic, arknights, deepseek-harness, dsh, dsh-plugin, immersion, rhodes-island, theme, wallpaper

## 简介

为《明日方舟》玩家在 DSH Web 上构建沉浸感：12 张整屏壁纸（按画面自适应的边缘虚化）、按每张图解算的玻璃与文字色、罗德岛图标体系，以及签字式的授权与选择交互。 / Building immersion for Arknights players on the DSH Web GUI: twelve full-screen wallpapers with per-image edge blur, glass and ink solved from each picture, Rhodes Isla
