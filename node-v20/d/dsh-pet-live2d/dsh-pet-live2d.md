# dsh-pet-live2d

> 标签: deepseek-harness, desktop-pet, dsh, dsh-plugin, live2d, 桌宠

## 简介

Live2D 桌宠插件：为 DSH Web GUI 挂一只可拖动、会跟随鼠标、能换动作与表情的 Live2D 宠物。
