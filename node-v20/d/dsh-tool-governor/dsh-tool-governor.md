# dsh-tool-governor

> 标签: deepseek-harness, dsh-plugin, guardrails, token-budget, tool-governance

## 简介

A DeepSeek Harness plugin that intercepts repeated tool calls, caps per-turn budgets, and breaks failure loops to reduce token waste.
