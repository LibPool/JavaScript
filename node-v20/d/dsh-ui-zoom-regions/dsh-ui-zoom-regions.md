# dsh-ui-zoom-regions

> 标签: accessibility, deepseek-harness, dsh-plugin, header-resize, per-region, scale, ui, zoom

## 简介

Per-region UI zoom for DeepSeek Harness, with a two-channel header: Ctrl + wheel scales the header font (25 %-300 %), dragging the header bottom edge changes how much room the header takes (24 px up to half the conversation panel) without touching the fon
