# dsh-journal-calendar

> 标签: calendar, deepseek, diary, dsh, dsh-plugin, harness, journal

## 简介

Daily journal and calendar for DeepSeek Harness: the journal_record tool appends one JSON file per day, and the right sidebar draws it as a calendar.
