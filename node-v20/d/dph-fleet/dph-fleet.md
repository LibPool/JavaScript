# dph-fleet

> 标签: JavaScript

## 简介

NoFox Fleet：dph 多设备组网协作插件（mDNS 同网发现+密钥配对 + SSH 跨网直连）。装完 dph 会话内自动注册 4 个 fleet_* 工具，智能体（agent）直接调用；CLI 预编译，Node 22 即装即用。
