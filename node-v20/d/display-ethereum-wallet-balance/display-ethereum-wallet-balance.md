# display-ethereum-wallet-balance

> 标签: ETH, balance, blockchain, crypto, cryptocurrency, ethereum, ethereum-wallet, nodejs, wallet, web3

## 简介

A simple Node.js application to display the Ethereum wallet balance using the ethereum-wallet-interactor library. Ideal for quickly checking ETH balances directly from the command line.
