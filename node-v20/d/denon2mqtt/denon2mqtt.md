# denon2mqtt

> 标签: avr, denon, home-assistant, home-automation, marantz, mqtt, mqtt-interfaces, mqtt-smarthome, receiver, smarthome, telnet

## 简介

Interface between Denon and Marantz AV receivers (the telnet protocol on port 23) and MQTT
