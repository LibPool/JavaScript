# dsh-vault-wall

> 标签: dsh, dsh-plugin, privacy, security, vault

## 简介

保险区 Vault Wall — 让 DeepSeek Harness 无法感知、无法触碰用户指定敏感路径的隔离墙插件（隔离墙 + 人在回路审批 + 执行后验证 + 循环纠正 + 可回滚规则）
