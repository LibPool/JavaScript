# dsh-model-toolkit

> 标签: badge, capability, deepseek-harness, dsh, dsh-plugin, model, provider, reasoning, vision

## 简介

模型能力设置 + 提供商徽章与余额查询：为手写模型设置图片输入与推理强度，并在输入框显示当前模型所属提供商及其余量。
