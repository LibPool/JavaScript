# deepblame

> 标签: agent-trace, ai-agents, attribution, blame, claude-code, codex, coding-agents, cursor, git, opencode, provenance, revert

## 简介

Know which AI agent wrote each line of your code, why, and what it cost — then undo just that agent's work. Works with Claude Code, Cursor, Codex and OpenCode, and speaks Agent Trace.
