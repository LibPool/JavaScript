# dsh-plugin-agent-sprite-forge

> 标签: 2d, agent-skills, animation, cordis, deepseek-harness, dsh, dsh-plugin, game-assets, gamedev, godot, pixel-art, skill, sprite, spritesheet, tileset

## 简介

Agent Sprite Forge for DeepSeek Harness: ships the generate2dsprite, generate2dmap and video2dsprite skills as one installable plugin, so a DSH profile gains the whole 2D game-asset workflow without copying anything into a user skills directory.
