# dsh-tauri

> 标签: bridge, deepseek-harness, dsh, dsh-plugin, plugin, tauri

## 简介

`dsh-tauri` 是 DSH Tauri 桌面壳的基础插件。它提供一个无宿主行为的 host half，以及运行在 DSH iframe 中的客户端消息桥。
