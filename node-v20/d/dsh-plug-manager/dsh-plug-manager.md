# dsh-plug-manager

> 标签: deepseek-harness, dsh, dsh-plugin, marketplace, plugin-manager

## 简介

DeepSeek Harness 插件管理器：发现 GitHub dsh-plugin topic 下的插件仓库，通过 `dsh plugin` 安装/移除/更新 profile 插件，并在 设置 → 插件 → 插件市场 标签页中浏览管理。
