# dsh-im-wecom-bot

> 标签: agent, ai, bot, cordis, deepseek, deepseek-harness, dsh, plugin, wechat-work, wecom, 企业微信

## 简介

WeCom (企业微信) channel plugin for DeepSeek Harness (DSH) — scan one QR code to create an official WeCom AI bot, then chat with your DSH agent directly from WeCom.
