# dsh-bing-search

> 标签: bing, cn-bing, deepseek-harness, dsh, dsh-plugin, free, plugin, search, web-search

## 简介

Free Bing-backed web search provider for DeepSeek Harness (DSH). No API key needed, uses cn.bing.com for mainland China accessibility.
