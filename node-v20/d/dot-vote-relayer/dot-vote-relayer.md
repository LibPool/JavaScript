# dot-vote-relayer

> 标签: JavaScript

## 简介

Dot-Vote-Relayer relays signatures created on a Dot-Vote website. To use Dot-Vote-Relayer, import the relayer to your file using `const { Relayer } = require("dot-vote-relayer");`.
