# dsh-mode-boost

> 标签: JavaScript

## 简介

模式提升插件：任务感知思维模式路由的实测提升版——deep-persona 收敛提升（94%/100% vs 94%/81%）、boost 式重分类引导（路由 88% vs 69% @1024 / 相关链 69% vs 56%）、深度自适应分派（复杂 7.5 步更深 / 简单 1.0 步零浪费）。零依赖宿主平面插件，装配在官方 preset 之上，无需 fork preset。
