# dsh-balance-float

> 标签: balance, deepseek-api, deepseek-harness, dsh, plugin, widget

## 简介

DSH Web 插件：右上角悬浮窗实时显示 DeepSeek 余额，支持手动刷新与一键退出（Y/N 快捷键确认）。Floating balance widget + graceful exit for the DeepSeek Harness web UI.
