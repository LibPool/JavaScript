# dsh-web-fetch

> 标签: agent-tools, anti-bot, deepseek-harness, dsh, markdown, playwright, skill, waf-bypass, web-scraping

## 简介

DSH skill + CLI: fetch web pages with a real local browser (Edge/Chrome/Chromium via playwright-core) to pass WAF / anti-bot / JS-rendered pages. Auto system-proxy detection, cookie persistence, HTML/text/Markdown/screenshot/PDF output.
