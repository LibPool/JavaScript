# dynamicparticles

> 标签: 2d, 3d, canvas, dynamics, particle, particle effects

## 简介

Dynamic particle rendering. Make groups of particles and set custom rulesets. Comes with efficient boids (3.2K rendered in a canvas @60fps) and a toggleable default canvas renderer built in for quick testing.
