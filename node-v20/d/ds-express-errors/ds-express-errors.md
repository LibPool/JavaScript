# ds-express-errors

> 标签: api-error, async, custom loggers, error-handling, errors, express, express-middleware, express-validator support, graceful shutdown, joi support, jwt support, logger, middleware, mongoose support, pino support, prisma support, sequelize support, typescript, winston support, zod support

## 简介

Centralized typed error management library for ExpressJS with Zod/Joi/JWT/express-validator and DB (Prisma/Mongoose/Sequelize) support & graceful shutdown
