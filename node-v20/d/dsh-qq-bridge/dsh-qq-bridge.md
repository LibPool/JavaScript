# dsh-qq-bridge

> 标签: agent, bridge, deepseek-harness, dsh, dsh-plugin, qq, qq-bot, qq-robot, qqbot

## 简介

QQ official bot bridge plugin for DeepSeek Harness (port of pi-qq-bridge): bidirectional QQ (C2C + group chat) with isolated persistent agent sessions, commands, media pipeline and outbound file delivery.
