# domainlooker

> 标签: cli, csv-export, dns, domain, domain-analysis, json-export, mcp, model-context-protocol, port-scanner, rdap, ssl, subdomain, whois

## 简介

A fast CLI and MCP server for inspecting domains: WHOIS/RDAP, DNS, SSL, ports, subdomains, with CSV/JSON export.
