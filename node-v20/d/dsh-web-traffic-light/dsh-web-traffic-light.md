# dsh-web-traffic-light

> 标签: agent, dsh, dsh-plugin, dsh-web, status, traffic-light

## 简介

Photorealistic traffic-light status widget for the DSH Web GUI, docked to the right edge: red = agent working, amber = waiting for you, green = idle/done.
