# dsh-file-upload

> 标签: attachment, cordis, deepseek, docx, drag-and-drop, dsh, harness, markdown, markitdown, pdf, plugin, upload, xlsx

## 简介

DeepSeek Harness dual-face plugin: Claude-style drag-and-drop / paperclip uploads, fully bundled document→Markdown (MarkItDown engine, 20+ formats, image OCR), text inlining, voice input, audio transcription (optional ASR), read_document tool.
