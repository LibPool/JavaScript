# denpex-mcp

> 标签: cuda, denpex, diagnosis, gpu, mcp, ml-ops, model-context-protocol, nccl, pytorch

## 简介

Denpex MCP server, diagnose GPU/ML training failures (CUDA OOM, NCCL timeouts, Xid faults, NaN loss) from Claude Desktop, Cursor, or Claude Code, with optional explicit zero-egress mode.
