# dsh-remote-ui-gateway

> 标签: deepseek, dsh, gateway, reverse-proxy

## 简介

DSH plugin: authenticated reverse proxy for the web GUI. Forwards the browser Host and Origin unchanged and publishes those names as DSH 0.2 trustedHosts so the connection fence admits the remote session; mints the DSH browser cookie and completes device
