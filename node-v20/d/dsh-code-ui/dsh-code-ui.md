# dsh-code-ui

> 标签: code-ui, cursor, deepseek-harness, dsh, editor, plugin

## 简介

Cursor 风格的 AI 代码编辑器工作台插件（DSH）：文件树、多标签页编辑、语法高亮、引用/翻译行内标签给 AI、右侧停靠/悬浮窗口双布局
