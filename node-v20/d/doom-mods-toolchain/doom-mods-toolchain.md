# doom-mods-toolchain

> 标签: doom, mod, modding, mods

## 简介

Build and execute doom mods using node and GZDoom. Helps with packaging a folder to .pk3 and loading multiple mods (wads and pk3s). Intended to make the modding workflow a bit faster.
