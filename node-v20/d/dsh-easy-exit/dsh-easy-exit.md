# dsh-easy-exit

> 标签: deepseek, deepseek-harness, dsh, dsh-plugin, exit, shutdown

## 简介

Conveniently shut down the dsh web server: a conversation-header exit button plus an agent tool, using the launcher's bounded shutdown path.
