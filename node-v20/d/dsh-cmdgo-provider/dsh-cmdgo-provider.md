# dsh-cmdgo-provider

> 标签: cmdgo, commandcode, commandcode-go, deepseek-harness, dsh, dsh-plugin, llm-provider, oauth

## 简介

CommandCode Go 套餐供应商：/alpha/generate CLI 网关（官方 CLI 指纹伪装）接入 DSH 模型列表 + OAuth 登录（多账号池轮询/故障转移）+ 每账号 5 小时/周/月额度显示 + 会话右上角额度 HUD（全部账号合计 + 实测平均单次消耗推算的理论调用次数 + 会话级缓存读/写与命中率台账）+ 视觉模型多模态（图像输入）+ 工具调用双射与请求形状自愈
