# details-summary-state-change-announcement-polyfill

> 标签: NVDA, a11y, accessibility, announcement, details, html, javascript, polyfill, state, summary, voice, web development

## 简介

Lightweight and dependency-free vanilla JavaScript polyfill for the (currently) missing state change announcement for details/summary HTML tags in NVDA.
