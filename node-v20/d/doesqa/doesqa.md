# doesqa

> 标签: agent, browser-testing, cli, doesqa, e2e, end-to-end, mcp, qa, test-automation, testing

## 简介

The DOES.QA CLI: the bridge between the DOES.QA end-to-end web test automation platform and your terminal, CI, and AI agents. Author and run flows, trigger runs, pull results, and keep a versioned local mirror, all over a personal access token.
