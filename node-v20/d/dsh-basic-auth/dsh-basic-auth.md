# dsh-basic-auth

> 标签: JavaScript

## 简介

为 DSH Web 入口加一道 HTTP Basic Auth 门卫：浏览器原生弹出账号密码框，凭据由浏览器/密码管理器保管并跨设备同步，不再依赖 30 天过期的 token cookie。校验通过的请求会被标记为已认证，交给 DSH 原生链路继续处理。
