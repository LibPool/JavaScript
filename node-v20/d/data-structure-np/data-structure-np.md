# data-structure-np

> 标签: JavaScript

## 简介

一个用 TypeScript 实现的常用数据结构库，包含栈、队列、双端队列、链表（单链表、循环链表、双向链表）、集合、字典、哈希表、二叉搜索树等。适合学习数据结构原理、算法练习及前端项目集成。
