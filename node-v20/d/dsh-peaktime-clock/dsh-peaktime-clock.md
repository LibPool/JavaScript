# dsh-peaktime-clock

> 标签: clock, deepseek, dsh, peak, peaktime, pricing, whale

## 简介

Persistent DeepSeek peak-time whale widget: corner clock that turns red during DeepSeek peak-price windows and green off-peak, in local time.
