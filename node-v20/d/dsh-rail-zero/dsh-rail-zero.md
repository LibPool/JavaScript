# dsh-rail-zero

> 标签: collapse, deepseek-harness, dsh, dsh-plugin, layout, plugin, qol, rail, sidebar, ui

## 简介

DSH web plugin: zero the collapsed left sidebar's 56px rail and get a working expand control - prefers dsh-qol's hamburger, falls back to the official toggle, then to a tiny floating button.
