# dsh-ops

> 标签: deepseek-harness, dsh, dsh-plugin, repository-tools

## 简介

Native file and PTC tools for DSH on Windows x64, Linux x64 and macOS Apple Silicon; Windows-only optional Bash payload and host PowerShell integration
