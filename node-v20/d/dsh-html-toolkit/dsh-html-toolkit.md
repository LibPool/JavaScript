# dsh-html-toolkit

> 标签: clean, dom, dsh, html, markdown, plugin, sanitize, text

## 简介

Zero-dependency HTML toolkit for DeepSeek Harness: tolerant HTML parser + DOM tree, html_to_text (main-content extraction), html_to_markdown (reverse conversion with nested lists/tables), clean_html (sanitize scripts, event handlers, unsafe URLs). Uses on
