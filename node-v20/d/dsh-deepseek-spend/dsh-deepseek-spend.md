# dsh-deepseek-spend

> 标签: balance, deepseek, deepseek-harness, dsh, monitor, plugin, quota, spend, usage

## 简介

DeepSeek Harness (DSH) 插件：在页面实时显示 DeepSeek API 余额与累计消费/本月/今日消费统计（官方 GET /user/balance + platform.deepseek.com 后台统计）。
