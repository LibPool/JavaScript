# dsh-batch-triage

> 标签: batch, cordis-plugin, deepseek-harness, deterministic, dsh, dsh-plugin, no-network, phocinae, prefilter, triage

## 简介

Deterministic-first triage for DeepSeek Harness: a rule prefilter classifies every ticket, and anything no rule can place is needs_review rather than guessed at. No model, no service, no network.
