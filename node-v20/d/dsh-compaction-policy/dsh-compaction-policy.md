# dsh-compaction-policy

> 标签: compaction, context-compaction, context-window, cordis, cordis-plugin, deepseek-harness, dsh, dsh-plugin, llm

## 简介

Put DSH's automatic context compaction trigger where you want it, per provider/model. Stops DeepSeek Harness from condensing a conversation far earlier than the configured threshold on models with smaller context windows.
