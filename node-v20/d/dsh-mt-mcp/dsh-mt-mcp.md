# dsh-mt-mcp

> 标签: android, apk, deepseek-harness, dsh, dsh-plugin, dsh-plugins, file, mcp, mt, mt-manager, zip

## 简介

MT 管理器 MCP 连接（DeepSeek Harness 插件）：在 Web 设置页填写 MT 的 MCP 地址，手机文件/APK/ZIP 能力以 mcp__mt__* 工具可用
