# dsh-docintel

> 标签: deepseek, deepseek-harness, docintel, dsh, fts5, knowledge-base, pdf, plugin, rag

## 简介

Personal document knowledge base for DeepSeek Harness: add any PDF/Markdown/text file into a local SQLite FTS5 store with page-level locators, search it with Chinese-friendly retrieval, and get page-cited answers from the agent. Web drawer included (v0.2)
