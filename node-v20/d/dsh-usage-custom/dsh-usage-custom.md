# dsh-usage-custom

> 标签: JavaScript

## 简介

Usage statistics plugin for the dsh web GUI with custom-provider adapter support (fork of @linxin666/dsh-usage, Apache-2.0): per-provider balance, coding-plan quota, a live token usage ledger, and user-configured custom balance probes for any relay.
