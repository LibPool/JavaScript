# dsh-plugin-mermaid-gb-svg

## 简介

DSH 插件：Mermaid 流程图 → GB/T 1526-1989（等同 ISO 5807）国标流程图 SVG，符号合规、正交走线、超 A4/A3 自动分页。DeepSeek Harness plugin: Mermaid flowcharts to GB/T 1526-1989 (ISO 5807) compliant flowchart SVG with A4/A3 pagination.
