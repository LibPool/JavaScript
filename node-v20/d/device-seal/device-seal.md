# device-seal

> 标签: aes-256-gcm, cross-platform, e2ee, hkdf, local-first, passkey, passkeys, prf, quantum-resistant, secure-enclave, webauthn

## 简介

🦭 Device-bound, user-verified key custody and local encrypted storage (no backend). Browser implementation (WebAuthn PRF). Quantum-resistant symmetric core: AES-256-GCM + HKDF-SHA-512 (CNSA 2.0 symmetric/hash primitives, NIST PQC Cat 5)
