# dsh-vscode-bridge

> 标签: bridge, cordis, deepseek-harness, dsh, vscode

## 简介

Cordis plugin bridging the dsh-vscode extension to native DSH services (workspace grouping, session titles, archive, agent presets, permission presets, slash commands, skill catalog, session export) over a token-authenticated local JSON-RPC socket.
