# directus-extension-pixozip

> 标签: avif, directus, directus-custom-bundle, directus-extension, directus-extension-bundle, image-optimization, pixozip, webp

## 简介

Automatic image optimization for Directus via the Pixozip API — generates AVIF/WebP variants on upload, with a backfill endpoint and an admin dashboard. Sandboxed, Marketplace-ready.
