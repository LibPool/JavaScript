# dsh-kit-lan-auth

> 标签: JavaScript

## 简介

DSH 局域网鉴权网关（dsh-kit 全家桶功能包，由 dsh-kit 聚合包挂载）——自签名 TLS 反向代理，本机免登录，局域网需 token/登录，鉴权全放行
