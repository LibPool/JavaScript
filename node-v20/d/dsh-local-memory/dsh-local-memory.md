# dsh-local-memory

> 标签: deepseek-harness, dsh, dsh-plugin, local-memory, memory, runtime-context

## 简介

独立本地记忆插件：JSONL 记忆条目、每轮 runtime-context 注入、local_memory_search/local_memory_remember 工具、设置面板管理页。不依赖 Mnemon。
