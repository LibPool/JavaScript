# dsh-tauri-panel

> 标签: deepseek-harness, dsh, dsh-plugin, plugin, tauri

## 简介

`dsh-tauri-panel` 是 Tauri 桌面端面板能力的扩展入口。当前版本提供稳定的插件包结构和客户端注入点，后续面板组件将在此基础上演进。
