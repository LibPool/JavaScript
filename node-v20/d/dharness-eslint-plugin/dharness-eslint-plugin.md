# dharness-eslint-plugin

> 标签: architecture, dharness, eslint, eslint-plugin, jsdoc, lint, react-doctor, typescript

## 简介

The guardrails dharness enforces on generated code: file size, documentation, and role-file shape. Loadable by ESLint and by react-doctor.
