# dumi-theme-xieyezi

> 标签: dumi, dumi theme, xieyezi

## 简介

dumi-theme-xieyezi is a documentation site theme package designed for dumi2. It provides a more beautiful and user-friendly development and reading experience based on @lobehub/ui
