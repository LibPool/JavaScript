> 标签: cordis, deepseek-harness, dsh, dsh-plugin, integrity, npm-provenance, provenance, security, sigstore, supply-chain, supply-chain-security

## 简介

Supply-chain provenance checks for DeepSeek Harness plugins: verify what you install actually matches the source you read. Never executes the audited package.
