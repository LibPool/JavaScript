# docsify-print-to-pdf

> 标签: docsify, docsify-plugin, documentation, pdf, print, print-to-pdf, save-as-pdf

## 简介

A "Print to PDF" button for Docsify that assembles the whole documentation (cover, table of contents and all chapters) into a single paginated A4 document and opens the browser's print dialog.
