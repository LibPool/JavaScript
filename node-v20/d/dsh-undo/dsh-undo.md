# dsh-undo

> 标签: context, deepseek-harness, dsh, dsh-plugin, plugin, redo, undo

## 简介

User-side undo/redo for DeepSeek Harness (dsh): the /undo command rolls the transcript back to before the last message and /redo restores it.
