# dsh-browser-tool

> 标签: browser, chrome-devtools-protocol, cordis, dsh, dsh-plugin, puppeteer

## 简介

DSH browser tool: drive Chromium tabs (headless / CDP-attached / spawned apps / user's real Chrome via the OMP-style Browser Relay) with an open-close-run + tab scripting API, ported from oh-my-pi.
