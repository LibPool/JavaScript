# dock-editor

> 标签: deepseek-harness, dock, dsh, dsh-plugin, editor, plugin, text, web-ui

## 简介

Text file viewer and editor for the dock file explorer: undo/redo, Ctrl+S save, and unsaved-change confirmation.
