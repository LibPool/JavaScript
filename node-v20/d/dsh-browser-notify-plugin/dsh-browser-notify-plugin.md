# dsh-browser-notify-plugin

> 标签: JavaScript

## 简介

DSH 浏览器桌面通知插件：每轮对话（turn/end）完成后，在浏览器内用 Web Notification API 弹系统级桌面通知。独立 dsh.bundle + dsh.client 插件，可用原生 `dsh plugin add/remove` 安装/卸载。
