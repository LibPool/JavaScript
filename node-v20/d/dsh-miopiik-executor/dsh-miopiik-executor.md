# dsh-miopiik-executor

> 标签: cordis, deepseek-harness, dsh-plugin, orchestration, subagent

## 简介

MiOpIIk one-shot execution policy adapter over native DSH subagents: explicit zero-default routing, leaf depth, persona/tool scope, timeout/cancel and bounded result presentation. 原生 DSH subagent 上的执行策略适配层
