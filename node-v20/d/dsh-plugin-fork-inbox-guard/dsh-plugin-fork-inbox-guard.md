# dsh-plugin-fork-inbox-guard

> 标签: deepseek-harness, dsh, dsh-plugin, fork, guard, inbox, next-turn, session

## 简介

Stops a forked DeepSeek Harness session from inheriting the prompts its parent had queued but not yet delivered.
