# ds-require

> 标签: JavaScript

## 简介

用于 hack node.js 的 require，让 require(`${DSC}/some-module/a/b/c.js`) 能够解析到 `${config.dsAppRoot}/${config.dsComponentPrefix}/some-module/a/b/c.js`
