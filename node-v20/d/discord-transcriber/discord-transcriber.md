# discord-transcriber

> 标签: archive, chat-export, discord, discord.js, html-transcript, logging, ticket, transcript, transcripts

## 简介

Pixel-accurate, self-contained HTML transcripts for Discord channels. XSS-safe by construction, CSP-locked, split into parts when a file would exceed the guild's upload limit.
