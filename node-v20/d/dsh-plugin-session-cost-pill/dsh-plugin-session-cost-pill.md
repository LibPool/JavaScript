# dsh-plugin-session-cost-pill

> 标签: cordis-plugin, cost, deepseek-harness, dsh, dsh-plugin, pricing, usage

## 简介

Live session spend in the DeepSeek Harness composer dock, pricing every assistant step at DeepSeek's peak or off-peak rate for its own timestamp.
