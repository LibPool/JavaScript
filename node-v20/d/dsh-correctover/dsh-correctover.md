# dsh-correctover

> 标签: agent-security, ai-agent-security, ccs, ccs-verifier, correctover, deepseek, deepseek-harness, deepseek-harness-plugin, dsh, dsh-bundle, dsh-plugin, dsh-security, guardrail, mcp, mcp-security, prompt-injection, runtime-security, ssrf

## 简介

Correctover runtime security for DeepSeek Harness (DSH): CCS 7-dimension verification, command-injection/SSRF/credential-exfil blocking, Ed25519 receipts, audit-first. Install with `dsh plugin add dsh-correctover`.
