# @minnowdb/core

> 标签: browser, columnar, database, full-text-search, in-browser, indexeddb, offline-first, olap, opfs, query-engine, sql

## 简介

A columnar SQL database for the browser: PostgreSQL-style SQL over durable IndexedDB or OPFS data, with no server or WebAssembly module.
