# @rubydogjp/openkk-frontend

> 标签: JavaScript

## 简介

オープン会計 frontend ランタイム共通基盤 — bundle 非依存の Providers 配線・env パース・Next 設定を 3 バンドルアプリ(openkk/openkk_sim/openkk_demo)で共有する。
