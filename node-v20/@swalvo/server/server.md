# @swalvo/server

> 标签: sdk, server, swalvo, tokens, webhooks, webrtc

## 简介

Official server SDK for the Swalvo hosted platform — mint short-lived RTC tokens, manage rooms, and read connection/error diagnostics from your own backend. Never for use in a browser.
