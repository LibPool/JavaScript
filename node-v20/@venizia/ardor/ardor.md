# @venizia/ardor

> 标签: ardor, dependency-injection, framework, frontend, ignis, inversion-of-control, ra-core, react, react-admin, rest, spa, typescript, venizia

## 简介

ARDOR - frontend application framework for the VENIZIA family. One entry point over ardor-kernel, ardor-react and ardor-admin: IGNIS inversion of control, a REST data layer, auth and i18n providers, and the React bindings for a react-admin application.
