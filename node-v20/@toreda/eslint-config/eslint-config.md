# @toreda/eslint-config

> 标签: eslint, eslint-config, eslint-plugin-prettier, eslint10, eslintconfig, flat-config, prettier, shareable-config, toreda, typescript, typescript-eslint

## 简介

Shared base ESLint flat config for Toreda TypeScript projects. Extends typescript-eslint recommended and eslint-plugin-prettier recommended. Requires ESLint 10+.
