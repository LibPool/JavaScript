# @chloejs/core

> 标签: agent-framework, agent-runtime, agents, ai-agent, ai-agent-framework, ai-agent-runtime, ai-agents, cron, human-in-the-loop, jobs, llm, scheduler, self-hosted, typescript, workflow

## 简介

TypeScript AI agent runtime. Write your agents in code and choose how predictable they are: deterministic steps where they can be, an LLM only where a step needs judgement, all on your machine.
