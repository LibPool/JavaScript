# @dsh-self-evolving/candidate-sdk

> 标签: JavaScript

## 简介

Candidate contract SDK: canonical tar/SHA-256 identity, manifest validation, policy scanner, deterministic builder harness, capsule packing. Trusted code (TCB-adjacent): candidates depend on its types but cannot override its validators.
