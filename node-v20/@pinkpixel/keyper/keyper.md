# @pinkpixel/keyper

> 标签: aes-encryption, api-keys, argon2, credential-manager, credentials, emergency-recovery, encryption, keyper, multi-user, password-manager, progressive-web-app, pwa, react, secrets-management, security, self-hosted, supabase, typescript, vault, zero-knowledge

## 简介

🔐 A self-hosted credential manager with client-side encryption and per-account isolation. Store API keys, passwords and secrets in your own Supabase, Neon or local SQLite database.
