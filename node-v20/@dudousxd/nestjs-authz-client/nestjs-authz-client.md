# @dudousxd/nestjs-authz-client

> 标签: abilities, authorization, authz, can, client, nestjs

## 简介

Framework-neutral, in-memory ability store + can() resolver for @dudousxd/nestjs-authz — hydrate decisions once and answer client checks with no network request.
