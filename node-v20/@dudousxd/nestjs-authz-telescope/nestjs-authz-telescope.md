# @dudousxd/nestjs-authz-telescope

> 标签: authorization, authz, extension, nestjs, observability, telescope, watcher

## 简介

nestjs-telescope extension for @dudousxd/nestjs-authz — records every authorization decision (ability, allow/deny, reason) in the Telescope dashboard so 403s are debuggable.
