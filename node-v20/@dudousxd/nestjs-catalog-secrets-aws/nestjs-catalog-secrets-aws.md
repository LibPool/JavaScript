# @dudousxd/nestjs-catalog-secrets-aws

> 标签: aws, catalog, encryption, envelope-encryption, govcloud, kms, nestjs, secrets

## 简介

AWS KMS secret vault for @dudousxd/nestjs-catalog: envelope encryption with a per-secret data key, the secret's kind and field bound as KMS encryption context, and the resolved key ARN recorded on every row.
