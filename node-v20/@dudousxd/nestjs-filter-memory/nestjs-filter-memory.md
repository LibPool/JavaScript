# @dudousxd/nestjs-filter-memory

> 标签: array, filter, in-memory, nestjs, query, tanstack-intent

## 简介

In-memory adapter for @dudousxd/nestjs-filter: run the same structured filter/sort/paginate/search/distinct input against plain arrays.
