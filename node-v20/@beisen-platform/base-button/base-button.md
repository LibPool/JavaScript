# @beisen-platform/base-button

> 标签: beisen, es6, react-component

## 简介

按钮用于开始一个即时操作。基础组件的按钮中有主要按钮、次要按钮、弱化按钮、文字按钮、图标按钮；还有不同尺寸可选择
