# opencode-cmux-status

> 标签: cmux, opencode, opencode-plugin, sidebar, status

## 简介

OpenCode 2 plugin that surfaces agent activity in the cmux sidebar: status pills, progress, logs and notifications. Fork of opencode-tmux-session-status with the tmux backend replaced by cmux.
