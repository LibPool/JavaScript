# @e-llm-studio/appmod-usage-tracker

> 标签: activity-monitoring, e-llm-studio-lib, engagement, focus-tracking, usage-tracking

## 简介

Zero-config, local-first engagement tracking: measures how long each application is open and how much of that time the user is engaged.
