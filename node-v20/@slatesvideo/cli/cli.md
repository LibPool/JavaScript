> 标签: agent-skills, ai-video, claude, claude-code, cli, image-generation, kling, mcp, model-context-protocol, seedance, slates, veo, video-generation

## 简介

Slates CLI: drive the Slates AI video studio from your terminal or let Codex (with your ChatGPT account) or Claude Code shell out to it. Includes the bundled agent skills and an MCP client configurator.
