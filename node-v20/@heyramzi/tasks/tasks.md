# @heyramzi/tasks

> 标签: board, drag-and-drop, gantt, kanban, svelte, svelte5, tasks, timeline

## 简介

Svelte 5 task views: a drag-and-drop board, a grouped list and a gantt timeline from one config, plus status badges, dots and icons.
