# @bdxi/beldex-exchange

> 标签: bdxtobtc, beldex, beldex-to-bitcoin, beldextobitcoin, cryptocurrency-conversion, cryptocurrency-exchange

## 简介

This module is used by the desktop and web versions of the Belex wallet to facilitate the exchange of BDX into other cryptocurrencies. It can be used to facilitate transactions where a user converts one cryptocurrency into another.
