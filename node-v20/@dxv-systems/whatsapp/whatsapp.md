# @dxv-systems/whatsapp

> 标签: dxv, graph-api, messaging, meta, webhook, whatsapp, whatsapp-cloud-api

## 简介

WhatsApp Cloud API for DXV apps — typed outbound client (text, media, templates, interactive), signed webhook intake with Express and fetch-style adapters, template builders and phone normalisation. Zero runtime dependencies.
