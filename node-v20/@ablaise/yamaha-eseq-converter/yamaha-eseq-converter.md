# @ablaise/yamaha-eseq-converter

> 标签: clavinova, eseq, midi, piano, smartpianist, yamaha

## 简介

Yamaha E-Seq Converter is a ES6 JavaScript tool that helps to convert a midi file into the Yamaha's standard E-Seq format
