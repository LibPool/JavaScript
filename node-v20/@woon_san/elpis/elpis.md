# @woon_san/elpis

> 标签: bff, elpis, frontend-engineering, koa, koa2, middleware, mpa, multi-page, mvc, node, node-framework, nodejs, nunjucks, router, server-side-rendering, ssr, web-framework, webpack

## 简介

一个基于 Koa、Vue 3、Element Plus 和 JSON Schema 的企业级全栈应用框架。安装 `@woon_san/elpis` 后，可以通过约定目录扩展服务端能力，并使用 model/project 配置快速生成 Dashboard、Schema 表格、搜索栏和表单页面。
