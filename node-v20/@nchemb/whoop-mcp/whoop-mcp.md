# @nchemb/whoop-mcp

> 标签: claude, fitness, health, mcp, model-context-protocol, oauth, whoop

## 简介

MCP server giving Claude (or any MCP client) access to your Whoop data. OAuth via shared relay, data cached locally in SQLite. Zero native dependencies.
