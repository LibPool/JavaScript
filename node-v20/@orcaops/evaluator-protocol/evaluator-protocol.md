# @orcaops/evaluator-protocol

> 标签: JavaScript

## 简介

The package protocol for orcaops evaluators. Pure types, Zod schemas, a spec → resolved transform, and a picomatch-based glob helper. No fs, no network, no subprocess machinery — that lives in `@orcaops/evaluator-runner`.
