# transcribe-so

> 标签: ai-agent, asr, chapters, cli, diarization, podcast, speaker-labels, speech-to-text, srt, subtitles, transcribe, transcription, vtt, youtube

## 简介

transcribe.so CLI for agents and scripts: transcribe YouTube videos, podcasts, media URLs, and local files into speaker-labelled transcripts with chapters, sections, cited Q&A, and subtitles. Pure-JSON stdout.
