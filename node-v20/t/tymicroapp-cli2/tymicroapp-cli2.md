# tymicroapp-cli2

> 标签: JavaScript

## 简介

1. 安装node，然后使用node全局安装本脚手架工具 2. 安装git，项目模板通过git下载 3. 配置模板所在仓库信息，仓库配置在dist/config.json文件中，通过脚手架下载工程，要求必须拥有仓库的权限 4. 创建工程命令：tymicroapp-cli create <project-name> ## 配置说明 1. url：仓库地址，例如：https://gitee.com 2. group：仓库所在分组，例如：tymicro 3. repoName：仓库名称，例如：ty
