# tentacle-ethernet-ip

> 标签: CIP, PLC, allen, allen-bradley, bradley, communication, controller, ethernet, ethernet-ip, ethernet/ip, industrial, rockwell

## 简介

Fork of cmseaton's node-ethernet-ip (forked by SerafinTech then by TendIncs) javascript Ethernet/IP library. A simple node interface for Ethernet/IP.
