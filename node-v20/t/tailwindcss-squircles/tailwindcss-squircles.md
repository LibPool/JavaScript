# tailwindcss-squircles

> 标签: border-radius, corner-shape, progressive-enhancement, squircle, superellipse, tailwind, tailwindcss, tailwindcss-plugin

## 简介

Tailwind CSS v4 plugin that turns every rounded-* utility into a compensated squircle with CSS corner-shape as a seamless progressive enhancement.
