# tooltiki-image-tools

> 标签: aspect-ratio, avif, crop, dimensions, dpi, exif, gif, heic, image, image-size, jpeg, metadata, orientation, png, ppi, print, probe, resize, responsive-images, srcset, svg, webp, zero-dependency

## 简介

Zero-dependency image maths for Node: read dimensions, format, DPI and EXIF orientation straight from the bytes, compute fits and crops, build srcsets, and size images for print.
