# tiny-async-kit

> 标签: async, backoff, cjs, commonjs, concurrency, drop-in-replacement, dual-package, err-require-esm, esm, map, p-limit, p-map, p-queue, p-retry, parallel, promise, queue, retry, tiny, typescript, zero-dependency

## 简介

All tiny-* async utilities in one package. Drop-in replacements for p-limit, p-map, p-retry, p-queue. ESM + CJS, zero transitive dependencies.
