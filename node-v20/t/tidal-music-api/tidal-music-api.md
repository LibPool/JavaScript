# tidal-music-api

> 标签: api, music, opentidal, scrapper, tidal, tidal-api, tidal-api-wrapper, tidal-info, tidal-music-api, tidalapi, tidalpromise, ts-tidal-api

## 简介

Interact with the Tidal API to retrieve music information such as tracks, artists, albums, videos, playlists, and mixes by URL.
