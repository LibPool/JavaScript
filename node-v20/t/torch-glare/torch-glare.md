# torch-glare

> 标签: cli, component-library, components, copy-in, design-system, radix-ui, react, tailwindcss, typescript, ui

## 简介

A React component library (TypeScript + Radix UI + Tailwind CSS). Its CLI installs component source from a hosted registry straight into your project — you own the code.
