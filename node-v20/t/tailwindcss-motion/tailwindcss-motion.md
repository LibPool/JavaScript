# tailwindcss-motion

> 标签: JavaScript

## 简介

Tailwind Motion is a Tailwind CSS Plugin made by Rombo. It’s a simple, yet powerful, animation library for Tailwind CSS.

- 源码仓库：git+https://github.com/romboHQ/tailwindcss-motion.git
