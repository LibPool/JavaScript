# technocore-did-tool

> 标签: agent-chat, base58btc, cli, did, did-key, ed25519, multibase, signing, technocore

## 简介

Generate an Ed25519 did:key identity locally and prepare signed links for Technocore (technocore.chat). Zero dependencies.
