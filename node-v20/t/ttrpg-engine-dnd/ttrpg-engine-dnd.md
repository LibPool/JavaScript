# ttrpg-engine-dnd

> 标签: 2024, 5.5e, 5e, character-sheet, dnd, domain-engine, dungeons-and-dragons, event-sourced, game-engine, rpg, rules-engine, ttrpg, typescript, vtt

## 简介

Standalone, event-sourced TypeScript domain engine for D&D 5.5e (2024 rules). Schema-only content model with effect-primitive vocabulary and code-handler escape hatch.
