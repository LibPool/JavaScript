# typographic-base-css-stylus

> 标签: boilerplate, css, simple, stylus, typographic

## 简介

*Floor Typography* is a tiny CSS/Stylus library for a consistent and flexible typographic base for modern web products. The only layout rule you want to follow when using this library is to keep spaces between block elements `1rem` * an integer.
