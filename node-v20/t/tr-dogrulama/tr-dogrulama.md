# tr-dogrulama

> 标签: checksum, iban, tckn, tr, turkish, validation, vkn

## 简介

Checksum validators for Turkish TCKN, VKN and IBAN, plus structural Turkish phone number format checking. Zero dependencies, no network calls, no API key.
