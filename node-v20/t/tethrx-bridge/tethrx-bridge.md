# tethrx-bridge

> 标签: bridge, coding-agent, grok, grok-build, tethrx, xai

## 简介

Run Grok Build from your phone — the local bridge for the TethrX iOS app. Exposes a running Grok Build install to your phone over HTTP + SSE, with per-tool approvals.
