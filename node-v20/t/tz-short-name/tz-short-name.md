# tz-short-name

> 标签: IST, PKT, abbreviation, browser, dst, intl, long-name, short-name, time-zone, timezone, timezone-name, tz

## 简介

Time zone names from the browser: short (PKT, GST, EST/EDT) by default, or full (Pakistan Standard Time). Fills the gaps where Intl only returns GMT+5.
