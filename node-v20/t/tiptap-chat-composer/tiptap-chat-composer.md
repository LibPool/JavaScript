# tiptap-chat-composer

> 标签: chat, composer, hard-break, input-rules, markdown, message-input, prosemirror, shift-enter, tiptap, tiptap-extension

## 简介

Tiptap extensions for chat message inputs: markdown shortcuts that keep working after Shift+Enter, Enter-to-send that knows when to get out of the way, and typed [text](url) links.
