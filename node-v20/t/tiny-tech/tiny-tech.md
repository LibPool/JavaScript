# tiny-tech

> 标签: agent, claude, mcp, memory, model-context-protocol, repl, strands, strands-agents, tiny

## 简介

tiny.technology for every surface — MCP server + local REPL agent (Strands SDK): identity, cross-agent memory, DMs, tool forge, scheduled jobs, local shell/file/http tools, available to any MCP client or straight from your terminal.
