# translation-toolkit

> 标签: browser, cli, converter, csv, diff, export, gettext, i18n, import, internationalization, l10n, localization, po, preview, statistics, translation, validate

## 简介

Zero-dependency CLI toolkit for managing .po translation files — export to CSV, import, browser preview with inline editing, validate, stats, and diff.
