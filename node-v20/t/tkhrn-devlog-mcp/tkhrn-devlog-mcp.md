# tkhrn-devlog-mcp

> 标签: astro, blog, claude, claude-code, devlog, mcp, model-context-protocol

## 简介

MCP server that publishes blog posts to tkhrn devlog via AWS Lambda + GitHub PR. Credentials stored in OS keychain.
