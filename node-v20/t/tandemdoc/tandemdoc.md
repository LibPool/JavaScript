# tandemdoc

> 标签: agent, cli, google-docs, markdown, mcp, review, tandemdoc

## 简介

Share a Markdown file to a live Google Doc your reviewers comment in — a thin MIT client for the hosted TandemDoc review layer. Comments in, commits out.
