# toolwall

> 标签: ai-security, guardrail, mcp, model-context-protocol, prompt-injection, proxy, rug-pull, security, tool-poisoning

## 简介

Local-first MCP guardrail proxy. Continuously re-verifies tool definitions before every call to catch rug pulls. No account, no telemetry, no network calls.
