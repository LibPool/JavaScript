# tracepass-mcp-server

> 标签: digital-product-passport, dpp, epcis, gs1, mcp, model-context-protocol, tracepass

## 简介

Model Context Protocol server for TracePass — the EU Digital Product Passport platform. Lets AI assistants manage products, passports, and EPCIS supply-chain events.
