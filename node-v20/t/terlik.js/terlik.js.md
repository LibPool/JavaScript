# terlik.js

> 标签: bad-words, badwords, censor, chat-filter, content-filter, content-moderation, extensible, filter, isomorphic, kufur, küfür, moderation, multi-language, nodejs, nsfw, offensive-language, profanity, profanity-detection, profanity-filter, regex-engine, swear-words, text-moderation, turkce, turkish, typescript, word-filter, zero-dependency

## 简介

Ultra-fast, zero-dependency profanity detection engine. Ships with Turkish, English, Spanish & German — extensible to any language. Lazy compilation, deep agglutination support, ReDoS-safe regex patterns
