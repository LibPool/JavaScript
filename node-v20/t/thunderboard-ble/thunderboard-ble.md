# thunderboard-ble

> 标签: BLE, Bluetooth, Bluetooth Low Energy, Bluetooth Smart, IoT, Silabs, Silicon Laboratories, Silicon Labs, Thunderboard, Thunderboard React, Thunderboard Sense

## 简介

A library to help reading/writing characteristic and service values with Silicon Labs Thunderboards using JSON configurations for quick and easy setup.
