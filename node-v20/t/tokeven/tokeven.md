# tokeven

> 标签: ai, anthropic, cost, gemini, grok, llm, openai, tokeven, usage

## 简介

Alias for @tokeven/sdk, so `npm install tokeven` works. Per-call AI usage metrics for Claude, ChatGPT, Gemini and Grok; never sees prompts or provider keys.
