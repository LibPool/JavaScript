# termux-tools

> 标签: android, antigravity, channel-manager, claude-code, codex, release-pinning, termux

## 简介

Pinned stable/next channel managers for Claude Code (ccx), Codex (cdx) and Antigravity (agx) on Termux, plus the Termux tooling scripts from tribixbite/termux-tools
