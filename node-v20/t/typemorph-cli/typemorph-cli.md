# typemorph-cli

> 标签: breaking-changes, codegen, diff, go, graphql, json, json-schema-to-zod, json-to-go, json-to-typescript, json-to-zod, llm, openapi, openapi-to-zod, prisma, quality, rust, schema, structured-output, typescript, validate, validation, zod, zod-schema-generator

## 简介

Convert JSON to Zod, TypeScript, Go & 40+ formats with real type inference (detects email/uuid/url/datetime/enum/int) — plus schema quality grading and breaking-change detection.
