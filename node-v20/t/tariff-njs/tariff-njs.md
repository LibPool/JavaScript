# tariff-njs

> 标签: JavaScript

## 简介

**Tariff-NJS** 是一个恶搞的 Node.js 包，用于给 `require` 函数添加“关税”。通过配置关税比例，指定的模块在被 `require` 导入时会增加额外的耗时，模拟“关税”效果。
