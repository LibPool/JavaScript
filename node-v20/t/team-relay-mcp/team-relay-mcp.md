# team-relay-mcp

> 标签: agent, claude, claude-code, collaboration, discord, mcp, model-context-protocol, team

## 简介

An MCP server that lets teammates' separate local Claude Code sessions exchange questions, answers, and decisions through a shared chat channel — each on their own Claude subscription, no API key, no central server.
