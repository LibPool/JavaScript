# train-travel-sdk

> 标签: JavaScript

## 简介

Developer-friendly & type-safe Typescript SDK designed to help TypeScript users work with the [Train Travel API](https://bump.sh/bump-examples/doc/train-travel-api) from [Bump.sh](https://bump.sh/).
