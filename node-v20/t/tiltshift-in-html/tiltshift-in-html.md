# tiltshift-in-html

> 标签: bokeh, depth-of-field, dof, miniature, postprocessing, scheimpflug, three, threejs, tilt-shift, tiltshift, webgl

## 简介

Depth-aware tilt-shift optics for Three.js — a tilted (Scheimpflug) focus plane, physical depth of field, and an artistic screen band, in one drop-in pass.
