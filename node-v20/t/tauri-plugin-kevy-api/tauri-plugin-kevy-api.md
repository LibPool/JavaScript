# tauri-plugin-kevy-api

> 标签: embedded, kevy, kv, redis, tauri, tauri-plugin

## 简介

Guest (webview) binding for tauri-plugin-kevy: a typed kevy client over Tauri's invoke, backed by one shared in-process kevy engine in the Rust backend.
