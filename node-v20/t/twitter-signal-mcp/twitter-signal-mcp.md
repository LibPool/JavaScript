# twitter-signal-mcp

> 标签: agent, claude, cursor, mcp, model-context-protocol, monitoring, search, sentiment, social-media, trends, tweets, twitter, x, x402

## 简介

MCP server for live X/Twitter search and AI trend digests — no Twitter API key, no subscription. Pays per call in USDC on Base via x402 from your own wallet.
