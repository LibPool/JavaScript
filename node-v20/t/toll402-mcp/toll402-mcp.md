# toll402-mcp

> 标签: ai-agents, base, mcp, toll402, tools, usdc, x402

## 简介

MCP server for Toll402 (https://toll402.dev): every Toll402 tool as MCP tools, paid per call in USDC via x402. No accounts, no API keys.
