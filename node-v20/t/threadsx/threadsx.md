# threadsx

> 标签: browser, concurrency, esm, isomorphic, multithreading, nodejs, observable, parallel, pool, spawn, thread, thread-pool, threads, threadsx, typescript, web-worker, worker, worker-threads, worker_threads

## 简介

Make web workers & worker threads as simple as a function call. Maintained, modernized fork of threads.js — Node.js 20+, ESM & CommonJS, TypeScript, observables and thread pools.
