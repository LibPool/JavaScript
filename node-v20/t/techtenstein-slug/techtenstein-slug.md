# techtenstein-slug

> 标签: slug, slugify, techtenstein, transliterate, unicode, url

## 简介

Unicode-aware URL slug generator. Tiny client for the Techtenstein Slug API — handles German umlauts, French accents, Spanish tildes, and more.
