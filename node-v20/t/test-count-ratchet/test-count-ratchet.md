# test-count-ratchet

> 标签: ai-agent, ci, cli, coding-agent, github-actions, guardrails, jest, junit, mocha, playwright, pytest, ratchet, regression, test-count, test-integrity, testing, vitest

## 简介

Fail CI when fewer tests run than before. Reads JUnit, Vitest, Jest and Playwright reports, compares them with a committed baseline, and names the tests that silently stopped running: narrowed globs, skipIf, broken collection, empty shards.
