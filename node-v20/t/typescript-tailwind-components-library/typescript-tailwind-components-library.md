# typescript-tailwind-components-library

> 标签: JavaScript

## 简介

typescript-tailwind-components-library es una plantilla inicial para crear una librería de componentes de React utilizando TypeScript y TailwindCSS. Puedes usar esta plantilla como punto de partida para desarrollar y distribuir tu propia librería de compo
