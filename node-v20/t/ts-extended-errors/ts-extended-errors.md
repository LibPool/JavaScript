# ts-extended-errors

> 标签: cause, custom-error, custom-errors, deserialize, error, error-cause, error-chain, error-class, error-handling, error-serialization, errors, instanceof, json, serialize, serialize-error, typed-errors, typescript

## 简介

A zero-dependency error model for TypeScript applications that use native exceptions but need typed context, cause-chain inspection, and reliable JSON round trips.
