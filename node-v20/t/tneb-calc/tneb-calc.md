# tneb-calc

> 标签: bill, calculator, electricity, estimator, nodejs, tamilnadu, tneb, utility

## 简介

A customizable Node.js utility to estimate Tamil Nadu (TNEB) electricity bills with slab-wise calculation, fixed charges, and support for single/three phase.
