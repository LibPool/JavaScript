# tidemill

> 标签: agent, cli, ecp, mcp, roku, roku-remote, tidemill, utilities

## 简介

Command-line client for Tidemill: list and inspect the free browser tool catalogue, check a Pro license key, and run the Zero Remote bridge that lets a browser control a Roku on your LAN. No login, no API key -- Tidemill has no accounts.
