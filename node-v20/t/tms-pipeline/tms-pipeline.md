# tms-pipeline

> 标签: agent-skills, claude-code, codex, delivery-pipeline, methodology

## 简介

An opinionated AI-agent delivery pipeline for Claude Code and Codex: eight stages from ticket to gate, each in a fresh context with its own artifact, two owner stops (design and gate), one executor for implementation, and up to five independent review pas
