# toolnexus-web

> 标签: browser, cpu, embeddings, knowledge-base, llm, offline, onnx, rag, tool-calling, transformers.js, wasm, webgpu

## 简介

Run LLMs in the browser — GPU or CPU, same API. Tool calling, embeddings, RAG, offline knowledge bundles, and metrics. Hooks-style TypeScript over Transformers.js (injectable).
