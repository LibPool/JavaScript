# tdsh-emoji

> 标签: deepseek-harness, dsh, dsh-plugin, emoji, kaomoji, unicode-emoji

## 简介

Add widely-supported Unicode emoji to DeepSeek Harness (dsh) replies; prompt-injection plugin designed to coexist with dsh-kaomoji.
