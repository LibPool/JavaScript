# tbspcli

> 标签: JavaScript

## 简介

> 解决2.0中遗漏的问题, 简化工具使用流程解放双手。在2.0版本中往往需要每一个工程都添加npm 脚本并安装2.0的包,能否只安装一次适用于所有工程并且不需要配置npm script呢, 3.0版本采用node cli 形式 通过全局脚手架的形式保证只需要安装一次不需要配置脚本达到适配全部项目的目的。 ##  使用方式: 1. 安装包 `npm i tbspcli -g` 2. 部署包信息 3. 使用
