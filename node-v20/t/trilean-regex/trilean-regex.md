# trilean-regex

> 标签: finite-automaton, isomorphic, nfa, parser, regex, regular-expression, regular-language, trilean

## 简介

A portable regular-expression grammar -- a true regular language, with a Thompson-construction reference matcher -- so a pattern means the same thing in process and wherever trilean-sql can push it down to a database's own engine.
