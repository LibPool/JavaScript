# tiny-tts

> 标签: edge-tts, lightweight, node-tts, offline-tts, onnx, speech-synthesis, text-to-speech, tts

## 简介

Ultra-lightweight text-to-speech (1.6M params). Pure Node.js inference via ONNX Runtime — zero Python dependency.
