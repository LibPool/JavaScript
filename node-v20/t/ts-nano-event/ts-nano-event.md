# ts-nano-event

> 标签: emitter, event-bus, event-emitter, events, lightweight, mitt, nanoevents, pubsub, tiny, type-safe, typed, typescript, zero-dependency

## 简介

Tiny, fully-typed event emitter — catches wrong event names and payloads at compile time. 203 bytes gzipped. Zero dependencies.
