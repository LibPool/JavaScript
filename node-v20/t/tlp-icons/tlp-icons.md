# tlp-icons

> 标签: angular, animated-icons, icons, lucide, react, svg, tabler, vue, web-component

## 简介

26,278 free, open-source animated SVG icons in 35 categories (Lucide, Tabler and tlp originals), as one <tlp-icon> web component for HTML, React, Angular and Vue.
