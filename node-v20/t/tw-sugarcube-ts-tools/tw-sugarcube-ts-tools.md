# tw-sugarcube-ts-tools

> 标签: sugarcube, twee, twine, typescript

## 简介

Editor intelligence for SugarCube in TypeScript/JavaScript: real types on hover, parameter and return-type checking, completion, and go-to-definition for members of setup, State.variables, State.temporary, and settings.
