# tango-mirror

> 标签: adb, android, scrcpy, screen-mirroring, tango, webcodecs, ya-webadb

## 简介

View and control WiFi-connected Android devices from a browser. Self-hosted scrcpy over WebRTC P2P built on ya-webadb (Tango): video, audio, clipboard sync and an optional device shell.
