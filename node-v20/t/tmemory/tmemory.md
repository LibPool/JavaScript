# tmemory

> 标签: card-game, card-matching, concentration, game, ink, ink-playing-cards, memory, memory-game, playing-cards, terminal-game

## 简介

A terminal-based Memory card game built with React Ink. Features multiple grid sizes, AI opponent, and high scores.
