# tide-tui

> 标签: cli, code-review, diff, git, ide, ink, terminal, tui

## 简介

TIDE — a terminal-only IDE: file tree, live git diff, split diff, syntax-highlighted code, staging, commit, and editing. Great for watching Claude/agent edits.
