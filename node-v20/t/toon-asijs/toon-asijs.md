# toon-asijs

> 标签: ai, asijs, data, format, json, llm, serialization, token, toon, toon-format, yaml

## 简介

TOON (Token-Oriented Object Notation) adapter for AsiJS — token-optimized LLM format as a native DataFormat: ctx.parseBody() and setFormat() understand TOON out of the box
