# turbofely

> 标签: Pjax替代方案, SPA, 前端框架, 性能优化, 无刷新加载, 现代化界面, 路由管理, 页面加速

## 简介

TurboFeLy is a modernized interface non-refresh loading library and native SPA acceleration library, designed to provide a more modern solution than Pjax.
