# tailwindcss-plugin-debug-screens-tw4

> 标签: breakpoints, debug, development, plugin, responsive, screen-sizes, tailwindcss

## 简介

TailwindCSS v4.x plugin that displays current screen breakpoint in a fixed overlay. TypeScript port of tailwindcss-debug-screens with ES6 modules.
