# tspace-spear

> 标签: api, backend, controller, decorators, dependency-injection, e2e, end-to-end, fast, framework, high-performance, http, lightweight, low-overhead, middleware, native-http, node, nodejs, rest, rest-api, routing, server, tspace, tspace-spear, type-safe, typescript, uwebsockets, uwebsockets.js, uws, web

## 简介

tspace-spear is a lightweight, high-performance API framework for Node.js that leverages the native HTTP server and supports uWebSockets.js (C++) for maximum speed and efficiency.
