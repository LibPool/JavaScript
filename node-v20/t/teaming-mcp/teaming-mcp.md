# teaming-mcp

> 标签: feishu, lark, mcp, meeting, minutes, model-context-protocol, teaming

## 简介

会议动力分析 MCP：从飞书取会议逐字稿，按 Teaming 框架做团队动力分析，并把报告推送到飞书。可装进豆包工作 / WorkBuddy 等支持 MCP 的 AI 宿主。
