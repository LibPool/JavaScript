# tgv-logger

> 标签: JavaScript

## 简介

Esta es una librería compartida, con funciones pensadas para registrar/comunicar distintos eventos y acciones en base a ellos. Funciones implementadas:   trace: propuesto para trazabilidad de la navegación del usuario   mssge: propuesto para comunicación
