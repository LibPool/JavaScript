# tape-six-proc

> 标签: bun, cross-runtime, deno, es-modules, esm, harness, isolation, no-transpile, nodejs, parallel, process, subprocess, tap, tape-six, tape6, test, test-runner, testing, typescript, unit-test

## 简介

Process-isolated test runner for tape-six. Runs each test file in its own subprocess. Works with Node, Deno, and Bun. Supports TypeScript without transpilation.
