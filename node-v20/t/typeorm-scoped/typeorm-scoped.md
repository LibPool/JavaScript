# typeorm-scoped

> 标签: active record typeorm, data mapper typeorm, entity scopes, nestjs, typeorm, typeorm default scope, typeorm plugin, typeorm repository scope, typeorm scopes, typeorm-scoped

## 简介

TypeORM extension that adds scopes and default scopes to entities and repositories, supporting both Active Record and Data Mapper patterns.
