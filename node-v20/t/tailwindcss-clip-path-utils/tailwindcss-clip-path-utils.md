# tailwindcss-clip-path-utils

> 标签: circle, clip-path, clip-path-utils, clippath, css, ellipse, inset, polygon, shape, tailwind, tailwind-plugin, tailwindcss

## 简介

Tailwind CSS plugin providing intuitive clip-path utilities for circles, ellipses, polygons, and insets. Supports Tailwind CSS v3 & v4.
