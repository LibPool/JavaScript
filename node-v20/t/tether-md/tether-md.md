# tether-md

> 标签: agents, ai, annotations, claude, cli, comments, human-in-the-loop, markdown, mcp, mcp-server, model-context-protocol, review, suggest-mode, track-changes

## 简介

Anchored comments for Markdown that AI agents act on, but never apply. The `tether` CLI: comment, suggest, accept/reject, and export a byte-identical clean document.
