# toolgovern

> 标签: agent-security, ai-agents, audit-trail, llm-security, mcp, policy-enforcement, runtime-governance, scope-narrowing, tool-calling

## 简介

Runtime governance middleware for AI agent tool calls -- gate shell, filesystem, network, and credential access before a tool executes.
