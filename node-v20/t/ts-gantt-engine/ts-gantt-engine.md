> 标签: Canvas, Chart, Event timeline visualization, Gantt, Gantt Chart, Gantt Engine, Production scheduling systems, Project management dashboards, Resource planning tools, TypeScript, Workflow management applications, ts-gantt-engine

## 简介

Gantt Engine is a lightweight, high-performance JavaScript/TypeScript library for drawing interactive Gantt charts using the HTML5 Canvas API.
