# taskswarm-cli

> 标签: agent-orchestration, claude-code, cli, codex, coding-agent, cursor, event-driven, hooks, multi-agent, notifications, push-notifications, self-hosted, server-sent-events

## 简介

Self-hosted, event-driven coordination for parallel coding-agent sessions (Claude Code, Codex, Cursor). Push notifications the instant a session blocks, needs review, fails, or finishes, plus a live local status page.
