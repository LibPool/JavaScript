# tendermintelectronkey

> 标签: Ed25519, burrow, elliptic, finterra, hyperledger, tendermint

## 简介

A module for creating bip39 mnemonic, ed25519 key pair and ripemd160 address for Tendermint and Hyperledger Burrow
