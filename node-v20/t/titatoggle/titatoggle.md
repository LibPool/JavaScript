# titatoggle

> 标签: bootstrap, buttons, checkbox, css, form, less, toggle, togglebutton

## 简介

Default bootstrap 4 checkbox toggle buttons. Just default Bootstrap, add a class to use these awesome toggle buttons. Browser support: Internet Explorer 9/10,11, Edge, FireFox, Safari, Chrome, Safari Ios, Stock Android browser 4.2, Chrome Android
