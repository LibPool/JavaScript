# track-dev-time

> 标签: auto-tracking, cli, dev-time, dev-tracker, developer-tools, productivity, session-tracker, time-tracking, tracking

## 简介

CLI tool to track your coding sessions with start, pause and stop commands. Outputs session data to a JSON file.
