# test-diff-new

> 标签: npm包发布工具, npm发布, 推动机器人消息, 自动生成CHANGELOG.md

## 简介

支持一键发布npm包，集成自动更新version、自动生成CHANGELOG.md、发布时自动指向京东npm私服、发布、发布后自动推送京ME机器人消息等功能
