# telperion

> 标签: canopy, foliage, generator, geometry, procedural, rust, space-colonization, tree, webgpu, wgpu

## 简介

A procedural tree generator. Authored silhouette, one builder growing every axis from continuous botanical traits with attractor pull among them, local rules down to leaf-bearing twigs, conserved thickness, one continuous plaited surface, and foliage cull
