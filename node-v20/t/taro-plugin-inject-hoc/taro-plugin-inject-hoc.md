# taro-plugin-inject-hoc

> 标签: hoc, inject-hoc, loader, react, taro

## 简介

本loder主要是为了给小程序（taro）页面注入高阶组件所写的，众所周知小程序没有公共入口定义全局组件，所以想通过注入高阶组件的形式给页面注入公共代码。（纯react项目应该也能用）
