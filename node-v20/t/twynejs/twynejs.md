# twynejs

> 标签: ejs, liquid, markdown, pages, plugin, ssg, static-site, vite

## 简介

twine A Vite SSG plugin that turns .ts/.tsx pages, Markdown docs and Liquid/EJS templates into a multi-page static build with a virtual:pages module.
