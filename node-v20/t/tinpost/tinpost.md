# tinpost

> 标签: email, icap, lab, mail, mail-server, mailhog, mailpit, offline, phishing-simulation, security-testing, smtp, testing, webmail

## 简介

A self-contained mail server with a web interface for lab environments. Supports a message timeline, live SMTP logs viewing, ICAP scanning and gateway relay
