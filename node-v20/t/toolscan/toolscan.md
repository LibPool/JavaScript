# toolscan

> 标签: agents, ai, ci, cli, cross-platform, devops, discovery, mcp, path, scanner, tooling, xdg

## 简介

Cross-platform tool discovery beyond PATH: XDG + common install roots, bounded and truthful with fail-closed JSON output. For agent harnesses, skill installers, MCP servers, and CI drift checks.
