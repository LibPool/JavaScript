> 标签: ai-agent, coding-agent, debugging, dev-server, error-monitoring, mcp, mcp-server, model-context-protocol, runtime

## 简介

Runtime feedback MCP server for AI coding agents. ViewGraph sees the UI - TracePulse feels the backend.
