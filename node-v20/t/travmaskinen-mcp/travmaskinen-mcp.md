# travmaskinen-mcp

> 标签: betting, harness-racing, horse-racing, mcp, modelcontextprotocol, sports-data, sweden, trav, trotting

## 简介

MCP server for Nordic harness racing (trav) data — upcoming V-games, startlists, pool distribution and win probabilities from Travmaskinen.
