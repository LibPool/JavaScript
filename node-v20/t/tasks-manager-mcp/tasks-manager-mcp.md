# tasks-manager-mcp

> 标签: claude, mcp, model-context-protocol, sqlite, tasks-manager

## 简介

MCP server for the Tasks Manager desktop app — download the app at https://tasks-manager.com. Read and manage tasks, spaces, projects, sections, and tags programmatically (create/update/delete), with native image support for task descriptions.
