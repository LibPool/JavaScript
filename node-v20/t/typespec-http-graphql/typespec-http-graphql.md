# typespec-http-graphql

> 标签: codegen, graphql, openapi, typespec, typespec-emitter, zod

## 简介

TypeSpec emitter: generate the GraphQL surface a spec declares, as a graphql-js schema and its SDL, whose resolvers call the same handlers, validated by the same Zod schemas, as a generated HTTP server.
