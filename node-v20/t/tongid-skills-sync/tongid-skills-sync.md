# tongid-skills-sync

> 标签: agent-skills, cli, machine-token, oauth, pkce, skill-selling, skills, sync, tongid

## 简介

TongID 技能同步 CLI：本机登录绑定机器授权码，按角色权限安装/更新技能包（GitHub 直连下载），并软连接到各 Agent 平台技能目录。零运行时依赖。
