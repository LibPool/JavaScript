# tokolaku-sdk

> 标签: api, chatbot, messaging, sdk, tokolaku, whatsapp

## 简介

Official TypeScript SDK for the Tokolaku Engine API — AI bot replies, omnichannel messaging (WhatsApp/Instagram/Messenger), and webhook verification.
