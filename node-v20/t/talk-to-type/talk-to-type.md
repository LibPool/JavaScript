# talk-to-type

> 标签: accessibility, dictation, macos, push-to-talk, speech-to-text, whisper

## 简介

Push-to-talk local dictation for macOS -- hold a key, speak, and the text is typed into whatever app has focus. Runs fully offline (Whisper via faster-whisper), no cloud transcription.
