# tappy-avatar

> 标签: avatar, avatar-generator, default-avatar, deterministic, hash-avatar, identicon, identicon-generator, placeholder, svg, svg-avatar, tiny, zero-dependency

## 简介

Deterministic SVG avatar generator — the same string always renders the same avatar. Fast (~3 µs), tiny (~6 KB gzipped), zero dependencies, 12 styles, browser & Node.
