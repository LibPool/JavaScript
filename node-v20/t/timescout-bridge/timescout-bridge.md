# timescout-bridge

> 标签: ai-agents, bridge, pattern-detection, screenpipe, timescout

## 简介

TimeScout Screenpipe bridge — reads local Screenpipe data, runs pattern detection locally, and uploads observations to TimeScout. Screenshots/audio/clipboard are not uploaded, but observations include on-screen text and meeting transcript excerpts; secret
