# turbo-repo-updater

> 标签: JavaScript

## 简介

Turbo Repo Updater is a command-line utility that automates the process of updating dependencies in Turbo Repo's 'apps' and 'packages' directories, with options to skip certain folders and ignore post-install scripts.
