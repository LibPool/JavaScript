# tailwind-a11y

> 标签: a11y, accessibility, contrast, focus-visible, lint, tailwindcss, touch-target, wcag, wcag22

## 简介

Static analysis CLI that catches WCAG accessibility violations — color contrast, touch target size, and focus indicator removal/contrast — in Tailwind CSS class combinations before they ship.
