# truemoneyy

> 标签: Angpao, Truemoney, Truewallet, ทรูมันนี่, ทรูวอลเล็ต, อั่งเปา

## 简介

โปรเจกต์นี้เป็น Class JavaScript (`Truemoney`) สำหรับการรับซองอั่งเปา TrueMoney (Gift Voucher) อัตโนมัติ โดยจะยิง Request ไปยัง API ของ TrueMoney เพื่อรับซองอั่งเปาเข้าเบอร์โทรศัพท์ที่ระบุ
