# ts-sparse-set

> 标签: component-storage, data-structure, dense-array, ecs, entity-component-system, high-performance, id-based-collection, object-pool, sparse-set, typescript

## 简介

A high-performance, TypeScript-native SparseSet implementation for ECS and other ID-based collections. Provides O(1) add, remove, get, and has operations with dense storage and optional object pooling for components.
