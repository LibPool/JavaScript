# text-tooltip

> 标签: ellipsis tooltip, text ellipsis, text tooltip, text-tooltip

## 简介

text-tooltip是一个基于element-ui的tooltip组件封装的文本溢出省略，并启用tooltip悬浮提示的小组件，且可支持多行文本溢出隐藏。
