# tslint-simple-config

> 标签: JavaScript

## 简介

<h3> tslint + prettier + airbnb = 😍 </h3> 每次新建项目是不是都要重新配置tslint? 是不是每次都要从其它项目复制过来?为了减轻这种痛苦, 快来使用 `tslint-simple-config` 吧! 在集成了`prettier`, `react`和`airbnb`配置的基础上, 添加了一些个人的配置, 让其更加的严格和规范.
