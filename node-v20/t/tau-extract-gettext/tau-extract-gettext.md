# tau-extract-gettext

> 标签: extract, gettext, i18n, scan

## 简介

Extract message strings from intl.formatMessage('literal'), intl.formatHtmlMessage('<b>literal</b>') functions, and JSX component <FormattedMessage message="literal" />
