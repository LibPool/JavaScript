# thoxcode-daemon

> 标签: agent-sdk, claude, daemon, jetson, systemd, thox, thoxcode, thoxos

## 简介

ThoxCode daemon for ThoxOS — Unix socket service exposing the agent over JSONL framing. Includes systemd unit and install script.
