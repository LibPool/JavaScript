# twd-js

> 标签: angular, api-mocking, browser-testing, component-testing, frontend-testing, in-browser-testing, preact, react, react-testing, request-mocking, service-worker, solid, tdd, test-runner, testing, twd, typescript, ui-testing, vue

## 简介

Test While Developing (TWD): in-browser test runner with a live sidebar UI. Works with React, Vue, Angular, Solid, Astro, Nuxt, HTMX and vanilla JS, on Vite, Webpack, or a CDN. Built-in API and component mocking.
