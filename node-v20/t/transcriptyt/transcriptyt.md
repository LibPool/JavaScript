# transcriptyt

> 标签: captions, llm, mcp, srt, subtitles, transcript, vtt, youtube, youtube-transcript, youtube-transcript-api

## 简介

YouTube Transcript API client: get any YouTube video's transcript as JSON, text, SRT, or VTT in 150+ languages.
