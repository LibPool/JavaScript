# tweet-nacl-react-native-expo-crypto

> 标签: crypto, expo, getRandomBytesAsync, nacl, native, react, tweet

## 简介

Tweet NaCl for React Native Expo which uses expo-crypto to get random bytes (getRandomBytesAsync - equivalent to Node.js crypt.randomBytes),
