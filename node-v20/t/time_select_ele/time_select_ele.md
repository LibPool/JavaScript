# time_select_ele

> 标签: 最近日期(一周内,一月内,一年内)选择，基于element组件库，返回方法名为timeSelect，返回值为start,end,value分别是所选开始时间跟当前时间以及所选值，所选值用于对value的修改，需要安装moment插件,接受size参数控制大小,参数内容同element选择框,接受value参数，week表示周，month表示月，year表示年，默认为week
