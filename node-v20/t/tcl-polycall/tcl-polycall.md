# tcl-polycall

> 标签: extension, libpolycall, peer-to-peer, polycall, tcl, tcl8.6, tcl9

## 简介

Tcl 9.0 / 8.6 extension for the Polycall binding ABI v1 (libpolycall >= 1.1.0): config validation, RPC calls and peer nodes
