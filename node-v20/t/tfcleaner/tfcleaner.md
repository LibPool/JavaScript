# tfcleaner

> 标签: cleanup, cli, devops, disk-space, ink, terraform, terragrunt, tui

## 简介

Interactive CLI to find and safely clean Terraform/Terragrunt generated directories (.terraform, .terragrunt-cache) and reclaim disk space.
