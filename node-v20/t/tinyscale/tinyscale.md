# tinyscale

> 标签: ai-agent, changelog, claude-code, cloudflare, coding-agent, csv-import, cursor, feedback-widget, mcp, mcp-server, onboarding, saas, smoke-test, waitlist

## 简介

Small SaaS building blocks a coding agent can set up, verify and hand to a human: waitlists, feedback widgets, changelogs, deploy checks, onboarding checklists, CSV import and more. CLI and local MCP server.
