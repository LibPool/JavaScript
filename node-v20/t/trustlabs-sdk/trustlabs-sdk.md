# trustlabs-sdk

> 标签: authentication, badge, identity, javascript, plugin, react, sdk, security, trust, trustlabs, typescript, verification, vue, widget

## 简介

Easy-to-use SDK for displaying trust verification badges on websites. Supports React, Vue, vanilla JS, and CDN usage.
