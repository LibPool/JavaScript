> 标签: api client, binance, bitmex, crypto markets data replay, cryptocurrency, cryptocurrency api, cryptocurrency data feed, exchange, high granularity order book data, historical cryptocurrency market data replay API, historical cryptocurrency prices, historical data, market data, market data normalization, normalized cryptocurrency market data API, order book reconstruction, orderbook, real-time cryptocurrency market data feed, real-time normalized WebSocket cryptocurrency markets data, realtime, replay service, trading, websocket

## 简介

Locally runnable server with built-in data caching, providing both tick-level historical and consolidated real-time cryptocurrency market data via HTTP and WebSocket APIs
