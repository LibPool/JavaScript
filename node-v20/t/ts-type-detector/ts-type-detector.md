# ts-type-detector

> 标签: arguments, array, boolean, check, date, function, is, is-type, is-type-of, kind, kind-of, number, object, of, regexp, string, test, type, type-of, typeof, types

## 简介

Takes any JavaScript data type or object as an input and returns a string describing the type of the input.
