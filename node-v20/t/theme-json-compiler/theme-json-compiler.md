# theme-json-compiler

> 标签: WordPress, WordPress Theme JSON, generator, plugin, theme json, theme.json, webpack, webpack-plugin

## 简介

The Theme JSON Compiler recursively merges JSON and JavaScript files into a single theme.json file.
