# thinkaloud-mcp

> 标签: focus-group, mcp, model-context-protocol, synthetic-users, thinkaloud, ux-testing

## 简介

MCP server for ThinkAloud — run synthetic-recipient tests and focus groups from Claude Desktop/Code or any MCP client. Thin layer over the ThinkAloud REST API.
