# trimble-spec-kit

> 标签: ai, ai-agent, claude, code-generation, copilot, cursor, modus, spec-driven-development, specification, trimble

## 简介

Trimble Spec-Driven Development Toolkit with Modus Web Components integration. Uses AI agents to turn specifications into working code with Modus as the default design system.
