# typepressx

> 标签: api, client, express, mern-packages, merndev, nodejs, npm-pm, observability, openapi, router, schema, type-safe, typepressx, typescript, validation, zod

## 简介

Type-safe API framework for Express. Define routes once, get runtime validation, OpenAPI, TypeScript types, and a generated fetch client for free.
