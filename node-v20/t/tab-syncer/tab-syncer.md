# tab-syncer

> 标签: broadcastchannel, browser-tabs, cross-tab, localstorage, persistence, real-time, state-sync, tab, tab sync, tab-communication, tab-syncer, tabsyncer

## 简介

A lightweight (4KB) library for browser tab state synchronization and communication. Supports auto-persistence and real-time data sync between tabs.
