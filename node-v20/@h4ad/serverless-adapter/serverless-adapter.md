# @h4ad/serverless-adapter

> 标签: alb, api gateway, apollo server, aws, azure, azure functions, deepkit, deepkit http, digital ocean, digital ocean functions, digital ocean serverless, express, fastify, firebase, firebase functions, firebase http events, functiongraph, gcp, google cloud functions, hapi, http, http trigger v4, huawei, koa, lambda, lambda edge, lambda streaming, node.js, polka, response streaming, serverless, sns, sqs, trpc

## 简介

Run REST APIs and other web applications using your existing Node.js application framework (NestJS, Express, Koa, Hapi, Fastify and many others), on top of AWS, Azure, Digital Ocean and many other clouds.
