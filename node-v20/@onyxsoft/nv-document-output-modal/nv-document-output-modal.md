# @onyxsoft/nv-document-output-modal

> 标签: JavaScript

## 简介

Popup para generar y compartir un documento (PDF, Word, correo, WhatsApp) a partir de cualquier registro del sistema. Standalone, OnPush, signals, sin lógica de negocio.
