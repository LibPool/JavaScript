# @ruraldte/sdk

> 标签: boleta-electronica, chile, dte, factura-electronica, facturacion, ruraldte, sii

## 简介

SDK TypeScript del API v1 de RuralDTE — emisión de DTE ante el SII (emitir = encolar), folios/CAF, webhooks, pagos, cesiones y más.
