# @checkpoint-irl/react-native

> 标签: background-location, checkpoint, geofence, location, react-native, turbomodule

## 简介

Checkpoint location / geofence / ingest SDK for React Native (iOS + Android). A thin bridge over the @checkpoint-irl/capacitor native cores; all detection logic runs server-side.
