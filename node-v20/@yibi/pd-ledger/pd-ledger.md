# @yibi/pd-ledger

> 标签: JavaScript

## 简介

本机 agent 交互台账：ccusage 采集（Claude Code / Codex）+ WorkBuddy 本地直采 + session 对话投影 + SQLite 全文检索，附交互质量评审模块（pd-analyze）。npx 一次装好，并把用法 skill 装进 ~/.claude/skills 教会你的 agent。
