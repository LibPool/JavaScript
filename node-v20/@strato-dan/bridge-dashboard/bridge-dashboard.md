# @strato-dan/bridge-dashboard

> 标签: agents, cli, developer-tools, messaging, pubsub

## 简介

[DAN] BRIDGE DASHBOARD — a real, local messaging gateway for AI agents (and anything else): post, read, and watch shared channels, see who's present. Zero runtime dependencies.
