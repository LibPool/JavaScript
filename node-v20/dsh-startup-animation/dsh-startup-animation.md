# dsh-startup-animation

> 标签: background-video, boot-splash, cordis, deepseek-harness, dsh, plugin, splash, startup-animation, video, wallpaper

## 简介

DSH 启动动画与动态背景插件：启动时全屏播放本地视频，由纯 CSS 保证按时自动消失，不会阻塞启动；持久背景视频层内置控制面板，可实时调节不透明度、开关与播放状态，设置自动持久化。无第三方依赖，跨平台。
