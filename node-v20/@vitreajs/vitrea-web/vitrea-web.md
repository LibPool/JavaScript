# @vitreajs/vitrea-web

> 标签: backdrop-filter, glass, liquid-glass, material, ui, vanilla-js, webgpu

## 简介

Framework-agnostic browser host for vitrea: mount a glass root from any framework, or none. DOM host registration, plane management, backdrop proxies, CSS-tier renderer, WebGPU lifecycle.
