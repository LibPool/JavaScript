# @levgenij/nuxt-prune-html

> 标签: audit, bot, cheerio, dynamic-rendering, html, lighthouse, measure, modules, nuxt, nuxt-module, nuxtjs, optimization, optimization-algorithms, optimize, pagespeed-insight, performance, prune, pruning, vuejs, web-vitals

## 简介

🔌⚡ Nuxt module to prune html before sending it to the browser (it removes elements matching CSS selector(s)), useful for boosting performance showing a different HTML for bots/audits by removing all the scripts with dynamic rendering
