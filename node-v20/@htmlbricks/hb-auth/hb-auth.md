# @htmlbricks/hb-auth

> 标签: JavaScript

## 简介

Full authentication UI driven by the `type` attribute: local login and registration (with optional “remember me”), email activation, password recovery and related notices, OTP and two-factor setup/verification. Supports OAuth2 social providers via embedde
