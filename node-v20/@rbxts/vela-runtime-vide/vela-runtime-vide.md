# @rbxts/vela-runtime-vide

> 标签: classname, rbxts, roblox, roblox-ts, runtime, tailwind, tailwindcss, vela, vide

## 简介

The Vide host runtime behind vela-rbxts. Transformed modules import it when the project targets Vide; it builds on @rbxts/vela-runtime-core.
