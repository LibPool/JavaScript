# @rbxts/goap

> 标签: JavaScript

## 简介

A direct port of [crashkonijn/GOAP](https://github.com/crashkonijn/GOAP) to Roblox. Should work functionally the same: albeit a few differences. Eventually, this will support parallel Luau.
