# @rbxts/rbx-gc-tracker

> 标签: garbage collection, tracking

## 简介

GC tracker for Luau that provides more predictable (compared to `__gc`...) destructor invocation for dead objects. Supports ~constant time update cost by limiting the iteration count such that update can be called every frame with a small n for negligible
