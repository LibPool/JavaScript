# archipelago-x402-mcp

> 标签: arc, archipelago, mcp, usdc, x402

## 简介

MCP server for Archipelago's paid answers about Arc tokens and wallets (token report, exit cost, wallet balances), bought in USDC on Arc over x402 from a wallet you configure, within caps you set

## 官网

- 官网：https://archipelagodex.xyz/agents.html
- npm 页面：https://www.npmjs.com/package/archipelago-x402-mcp
