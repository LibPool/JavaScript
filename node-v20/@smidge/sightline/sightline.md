# @smidge/sightline

> 标签: accessibility, agent, aria, dom, llm, llm-agent, outline, screen-reader, screen-reader-outline

## 简介

What's on screen, as text an LLM agent can use. Runs in the page, reads the accessibility tree like a screen reader, never reads typed values.
