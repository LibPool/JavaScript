# @catesworks/skill-reflect-instructions

> 标签: JavaScript

## 简介

Provides an evidence-based workflow for analyzing an AI agent instruction file such as AGENTS.md or CLAUDE.md against observed conversation failures and proposing minimal, approved improvements.
