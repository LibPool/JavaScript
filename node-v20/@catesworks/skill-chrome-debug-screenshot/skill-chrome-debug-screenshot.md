# @catesworks/skill-chrome-debug-screenshot

> 标签: JavaScript

## 简介

Systematically diagnoses failing Chrome DevTools MCP screenshot calls by trying multiple path, uid, frame, and clip parameter combinations in order and reporting which one works.
