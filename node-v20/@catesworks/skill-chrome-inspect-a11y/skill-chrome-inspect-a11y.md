# @catesworks/skill-chrome-inspect-a11y

> 标签: JavaScript

## 简介

Produces a live accessibility report for a running page or specific element via Chrome DevTools MCP, checking ARIA roles, names, relationships, keyboard focus, and approximate contrast against WCAG…
