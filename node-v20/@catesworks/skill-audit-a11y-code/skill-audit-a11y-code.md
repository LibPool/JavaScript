# @catesworks/skill-audit-a11y-code

> 标签: JavaScript

## 简介

Performs a static, source-code accessibility review of a component or template, checking semantic structure, ARIA usage, keyboard access, forms, tables, and contrast against WCAG 2.1 AA criteria.
