# airouting-mcp

> 标签: JavaScript

## 简介

MCP control plane for an AIRouting LLM-gateway backend — invoke it to view or change live backend state: onboard/suspend/delete accounts (OAuth / API-key / Kiro), manage platforms & model mappings, groups, channels, organizations, plans, proxies, and diag
