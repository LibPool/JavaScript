# anjal-cli

> 标签: agent-experience, ai-agents, anjal, cli, developer-tools, email, linkedin, myagentmail

## 简介

Command-line interface for Anjal (formerly MyAgentMail). Provision inboxes, run LinkedIn intent signals, tunnel inbox events to localhost (Stripe-style), and drive every API surface from a shell or an agent loop. Token-economical alternative to the MCP se
