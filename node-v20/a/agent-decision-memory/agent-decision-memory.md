# agent-decision-memory

> 标签: ai-agents, claude, claude-code, cursor, mcp, mcp-server, model-context-protocol

## 简介

Persistent decision and constraint memory for coding agents: a local stdio MCP server and CLI that store ADR-style decisions as git-friendly markdown, linked to SpecGate requirement ids, tests and commits.
