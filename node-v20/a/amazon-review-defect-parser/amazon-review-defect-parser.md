# amazon-review-defect-parser

> 标签: amazon, claude, cli, defect-analysis, ecommerce, llm, nlp, openai, reviews, sentiment-analysis

## 简介

Parse 1-3 star Amazon reviews into structured defect categories (sizing, material, instructions, packaging) with an LLM, or run fully offline in mock mode. CLI + TypeScript library.
