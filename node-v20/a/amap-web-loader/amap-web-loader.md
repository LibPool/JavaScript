# amap-web-loader

> 标签: amap, amap-loader, amap-web-loader, 地图, 高德

## 简介

高德地图 JS API 加载器。AMap / AMapUI / Loca 模块级单例加载器，支持 callback 就绪判定、版本校验与引用计数清理。AMap JS API module-level singleton loader.
