# artoolkit5-es

> 标签: AR, AR.js, ARToolKit5, ARToolKit5-es, 增强现实

## 简介

ARToolKit5-es 是一个基于 ARToolKit5 的 JavaScript 库，用于在网页和移动设备上实现增强现实应用程序。它提供了一组 API 以便于开发人员进行图像处理、标记检测、图像跟踪和姿态估计等操作。
