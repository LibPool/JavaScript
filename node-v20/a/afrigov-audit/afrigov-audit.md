# afrigov-audit

> 标签: a11y, accessibility, africa, afrigov, audit, axe-core, cli, government, wcag

## 简介

Audit any website for accessibility from the command line. Runs axe-core at phone and desktop widths, adds checks for the failures common on government sites, and tells you which afrigov component fixes each one.
