# ansuko

> 标签: async, functional, geojson, gis, hiragana, japanese, json5, katakana, lodash, promise, turf, typescript, utilities, utility

## 简介

A modern JavaScript/TypeScript utility library that extends lodash with practical, intuitive behaviors. Fixes lodash quirks, adds Promise support, Japanese text processing, and GeoJSON utilities.
