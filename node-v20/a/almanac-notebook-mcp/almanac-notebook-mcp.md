# almanac-notebook-mcp

> 标签: ai, almanac, claude, flashcards, mcp, model-context-protocol, notebooklm, notebooks, study-notes

## 简介

MCP server that lets AI agents work with AlmanacNotebook notebooks: list and create notebooks, add YouTube/text sources, generate notes, and chat with sources.

- 官网：https://almanacnotebook.com/mcp

- npm 页面：https://www.npmjs.com/package/almanac-notebook-mcp
