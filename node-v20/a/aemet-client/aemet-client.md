# aemet-client

> 标签: aemet, api-client, cap, forecast, meteorology, opendata, radar, spain, warnings, weather

## 简介

Typed TypeScript client for the AEMET OpenData API (Spanish State Meteorological Agency). Used in production at snowy.es.
