# artur_dani-sdk

> 标签: JavaScript

## 简介

An sdk for the [The One API](https://the-one-api.dev/) which is a RESTful API based on the works of J.R.R. Tolkien. The sdk is written in TypeScript and uses [Axios](https://axios-http.com/) for the http requests.
