> 标签: ai-agent, ai-agents, bun, calendar, claude, claude-code, cli, cursor, excel, graph-api, llm, m365, markdown, mcp, mcp-server, microsoft-365, microsoft-graph, office-365, onedrive, onenote, outlook, planner, sharepoint, teams, typescript

## 简介

Microsoft Graph CLI + library — typed Bun/TypeScript wrapper around 150+ Graph operations (read + on-the-fly PDF/markdown conversion + federated Microsoft Search) reachable from a Teams browser-OAuth token.
