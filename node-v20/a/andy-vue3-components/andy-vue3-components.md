# andy-vue3-components

> 标签: andy, components, vue3

## 简介

1. 在vue3项目的main.js里引入 import andyComps from 'andy-vue3-components' app.use(andyComps) 2. 在任何一个.vue文件下, 可直接引入组件 <wc-button></wc-button>  <wc-date-range></wc-date-range> #### 2. 为组件编写文档 https://vuepress.vuejs.org/zh/guide/
