# agentdock-cli

> 标签: ai-coding-assistant, backup, claude-code, cli, codex, dotfiles, environment-migration, mcp, skills, versioning

## 简介

Migrate, back up, and version your AI coding assistant environment (Claude Code / Codex) — MCP servers, Skills, Agents, Plugins, Hooks, and memory — as a portable, secret-isolated package.
