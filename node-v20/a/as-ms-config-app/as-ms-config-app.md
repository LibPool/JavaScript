# as-ms-config-app

> 标签: JavaScript

## 简介

При создании нового микрофронтенда 1. Клонировать репозиторий нового пустого сервиса 2. Установите пакет: yarn add -D as-ms-config-app 3. В терминале (из папки проекта) запустите скрипт: npx new-app, после чего следуйте инструкции консоли. 	Посянение:
