# agmsg

> 标签: agent-to-agent, antigravity, claude-code, cli, codex, copilot-cli, gemini-cli, messaging, multi-agent, opencode, sqlite

## 简介

Cross-agent messaging via SQLite for CLI AI agents (Claude Code, Codex, Gemini CLI, GitHub Copilot CLI, Antigravity, OpenCode). The npm package is a thin bootstrapper that fetches and runs the canonical bash installer at https://github.com/fujibee/agmsg.
