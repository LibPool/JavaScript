# ahcut-mcp

> 标签: ahcut, mcp, model-context-protocol, stdio

## 简介

Connect an MCP client that speaks stdio to AhCut: the app on this computer, or the one on another computer through the cloud relay.

- npm 页面：https://www.npmjs.com/package/ahcut-mcp
