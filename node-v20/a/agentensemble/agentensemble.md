# agentensemble

> 标签: agentensemble, ai, anthropic, component, llm, llm-apps, mistral, multi-agent, openai, pipeline, react, reasoning

## 简介

Composable multi-agent reasoning pipeline for React. Define a council of agents with custom roles, choose sequential or parallel orchestration, plug in any LLM — get a live visual reasoning trace.
