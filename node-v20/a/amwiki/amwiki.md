# amwiki

> 标签: amWiki, api, doc, markdown, wiki

## 简介

amWiki 是一款由 JS 开发、依赖 Atom 或 Nodejs-Npm 的 Markdown 轻量级前端化开源文库系统。amWiki 致力于让大家可以更简单、更便捷的建设个人和团队文库！

## 官网

- 官网：https://amwiki.org
- 源码仓库：git+https://github.com/TevinLi/amWiki.git
- npm 页面：https://www.npmjs.com/package/amwiki
