# angular-ippopay

> 标签: Credit, Debit, IppoPay, Netbanking, Payments, UPI

## 简介

The Ippopay Payments plugin allows you to accept credit card, UPI, Netbanking and debit card payments via Ippopay payment gateway in your Angular JS.
