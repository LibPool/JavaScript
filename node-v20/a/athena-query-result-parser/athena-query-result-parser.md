# athena-query-result-parser

> 标签: athena, aws, aws-sdk, parser, query, result

## 简介

A small TypeScript library that parses Amazon Athena query result `ResultSet` objects (from `@aws-sdk/client-athena`) into header-based row objects. It handles metadata-driven headers, skips the header row when present, and supports custom row transformer
