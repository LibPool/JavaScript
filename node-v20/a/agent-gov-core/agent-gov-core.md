# agent-gov-core

> 标签: agent, claude-code, governance, jsonc, mcp, toml

## 简介

Shared primitives for the AI-agent governance suite: Finding schema, JSONC/TOML readers, line locators, MCP command normalization, shell tokenization, transcript-event types + JSONL parsers (Claude Code/Cursor/Codex), and GitHub Action helpers.
