# agent-scrum

> 标签: agent-orchestration, agentic, ai-agents, audit-trail, autonomous-agents, claude, claude-code, coding-agent, definition-of-done, guardrails, kanban, llm, multi-agent, orchestration, scrum, sqlite, subagents, task-board

## 简介

Guardrails for AI coding agents (Claude Code): tasks live in SQLite and cannot close on red tests, parallel agents cannot touch each other's files, every step leaves an audit trail — rules in the database, not in prompts.
