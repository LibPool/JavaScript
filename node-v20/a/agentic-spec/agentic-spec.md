# agentic-spec

> 标签: agentic, ai, claude, design-system, design-tokens, design-tokens-community-group, figma, mcp, spec

## 简介

Give any design system a machine-readable, enforceable contract that AI agents read before they write code. Closed token lists, named parts, required states — validated in CI and served to agents over MCP.
