# askone-mcp

> 标签: askone, live-qa, mcp, model-context-protocol, polls, slido-alternative

## 简介

MCP server for AskOne live Q&A and polls with free AI moderation: start rooms, launch polls, moderate and answer questions, then read the Q&A as a FAQ draft and the poll results.
