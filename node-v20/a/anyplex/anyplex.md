# anyplex

> 标签: agents, agents-api, anthropic, cloud-agents, cursor, gemini, interactions, managed-agents, openai, sdk

## 简介

LiteLLM for managed agents. One session interface for hosted agent runtimes: Anthropic Managed Agents, OpenAI Agents API, Gemini Managed Agents, Cursor Cloud Agents. Unified events, provider-reported spend, budget watchdog, stop, and lossless re-attach.
