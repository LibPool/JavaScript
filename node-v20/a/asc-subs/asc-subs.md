# asc-subs

> 标签: app-store, app-store-connect, app-store-connect-api, appstoreconnect, asc, auto-renewable-subscription, automation, ci, cli, declarative, devops, iap, in-app-purchase, infrastructure-as-code, ios, storekit, subscriptions

## 简介

App Store subscriptions as code. Describe an auto-renewable subscription group in one JSON file, then plan / push / pull it against the App Store Connect API — like Terraform, for iOS in-app purchases.
