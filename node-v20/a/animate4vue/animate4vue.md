# animate4vue

> 标签: animate, animate-website, animation, animation-library, frontend, gsap, transition, ui, vue, vue-animation, web-animation

## 简介

A library for ready-to-use animations designed for Vue.js applications, featuring over 100 high-performance UI animations crafted with GSAP, offering GPU-accelerated rendering with better performance and efficiency across all devices.
