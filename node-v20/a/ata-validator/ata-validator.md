# ata-validator

> 标签: ajv, ajv-alternative, fast, fastify, json, json-schema, napi, native, schema, simdjson, standard-schema, validation, validator

## 简介

JSON Schema validation that compiles for speed and still runs where code generation is blocked. Compiled and interpreted engines answer identically at 100% of the official suite. TypeScript inference, Standard Schema V1, and a build step that emits depend
