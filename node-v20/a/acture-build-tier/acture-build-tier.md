# acture-build-tier

> 标签: acture, deprecated, esbuild-plugin, experimental, internal, jsdoc, stable, tier-system, vite-plugin

## 简介

Build-time tier mirror. Scans .ts source for @stable / @experimental / @internal / @deprecated JSDoc tags on defineCommand calls and mirrors them into the runtime command's tier metadata. Ships an esbuild plugin and a Vite plugin.
