# agentenkit

> 标签: agents, ai, ai-sdk, durable-execution, human-in-the-loop, ports-and-adapters

## 简介

Durable runtime for AI agent runs — a platform-owned loop, queue-dispatched execution that outlives the request, HITL suspension, nested runs, and context compaction. Bring your own storage, queue, bus and kv via four ports.
