# acode-snip-install

> 标签: acode, cli, extension, snippets

## 简介

## Overview `acode-snip-install` is a command-line interface (CLI) tool designed to facilitate the download and installation of Visual Studio Code (VSCode) snippet extensions for users of the Acode editor.
