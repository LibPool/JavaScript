# all-sheet-db-js

> 标签: browser, crud, database, formula, gis, google-identity-services, google-sheets, google-sheets-api, googlefinance, indexeddb, joins, oauth2, orm, react, relational, schema-migration, sheet-model, sheets-api, spreadsheet, typescript

## 简介

Google Sheets as a database with relational joins and high-performance IndexedDB caching. Store, retrieve, and populate related data with a typed, ORM-like API.
