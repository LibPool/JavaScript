# approval-sentinel-mcp

> 标签: ai-agent, allowance, arbitrum, base, blockchain, bsc, crypto-security, defi-security, erc20, ethereum, mcp, model-context-protocol, onchain, polygon, revoke-approvals, token-approval, wallet-drainer, wallet-security, x402

## 简介

Audit a wallet's active ERC-20 token approvals for drain risk — the #1 way DeFi wallets get emptied. Flags unlimited allowances to EOAs, unknown or upgradeable spenders and returns the revoke calldata. CLEAN/REVIEW/AT_RISK verdict in one call. MCP server
