# atxswap-sdk

> 标签: agent, atx, atxswap, binance-smart-chain, bsc, defi, liquidity, pancakeswap, pancakeswap-v3, sdk, swap, viem, wallet

## 简介

TypeScript SDK for ATX token on-chain interactions (BSC / PancakeSwap V3) — wallet management, price/balance queries, swaps, concentrated liquidity, and transfers.
