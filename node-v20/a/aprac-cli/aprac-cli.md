# aprac-cli

> 标签: JavaScript

## 简介

1. 安装 node、npm、git  2. 通过 （Linux/MacOS需要加sudo） npm install aprac-cli -g 全局安装  3. 通过 （Linux/MacOS需要加sudo） npm install colors-cli -g 全局安装  4. 输入 aprac-cli init （项目名称或项目完整路径，使用前请确保盘符是否正确） （a：自动安装ApracJS） 初始化项目
