# astro-d1-search

> 标签: astro, astro-integration, cloudflare, cloudflare-d1, d1, fts5, full-text-search, search, sqlite

## 简介

Astro integration for site search backed by Cloudflare D1 (SQLite FTS5): build-time indexing, an injected search API endpoint, bm25 + recency ranking
