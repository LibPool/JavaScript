# applytop

> 标签: api, applytop, cli, client, cv, job-search, jobs, resume, sdk

## 简介

Command-line interface and Node client for the ApplyTop public API — search jobs and access your alerts, matches, saved jobs, and CVs (incl. AI tailoring) from the terminal or programmatically.
