# agent-backup

> 标签: ai-agents, backup, claude-code, codex, dotfiles, homelab, restic, restore

## 简介

Back up and restore AI agent setups (Claude Code, Codex, Gemini, opencode, Cursor, Hermes) and home-server apps with restic. Encrypted, per-component snapshots, pick-and-choose restore, cross-OS agent restore.
