# ancilla

> 标签: ancilla, cli, client, status

## 简介

Status client for the Ancilla platform. Fetches and renders the current project status from ancilla.live. Not the Ancilla platform itself.

## 官网

- 官网：https://ancilla.live
- 源码仓库：git+https://github.com/ancilla-live/ancilla-status-client.git
- npm 页面：https://www.npmjs.com/package/ancilla

## 历史版本号

- 当前版本：0.0.1

- 0.0.1

## 获取地址

- npm 安装：`npm install ancilla`
- npm registry：https://registry.npmjs.org/ancilla
- Node 要求：>=18
