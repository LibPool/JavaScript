# angular-recursive-object-search-filter

> 标签: Angular, AngularJS, filter, json, object, recursive, search

## 简介

Search recursively through an object literal (such as those generated by json) for a set of queries. Queries are supplied as a string, where each query is separated by spaces and a multi-word query can be wrapped in single or double quotes.
