# aio-ui-mcp

> 标签: JavaScript

## 简介

这是一个基于 Model Context Protocol (MCP) 的AIO多端组件库智能服务，支持： - 查询所有可用组件（支持小程序/PC端/移动端） - 获取组件详细信息 - 根据描述推荐组件
