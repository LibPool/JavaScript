# agentavow-trust

> 标签: agentavow, agentgraph, did, ed25519, jcs, jws, rfc8785, trust-score, verifiable

## 简介

Client-side verification of AgentAvow Trust Score v2 signed envelopes (JCS-canonical, Ed25519-over-SHA-256). Peer of the Python agentavow-sdk verify module. Formerly agentgraph-trust.
