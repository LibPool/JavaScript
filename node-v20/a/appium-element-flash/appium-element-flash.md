# appium-element-flash

> 标签: JavaScript

## 简介

This appium plugin will flash element before every action. This only is supported for espresso driver.

## 官网

- npm 页面：https://www.npmjs.com/package/appium-element-flash

## 历史版本号

- 0.0.1

## 获取地址

- npm 安装：`npm install appium-element-flash`
- npm registry：https://registry.npmjs.org/appium-element-flash
- Node 要求：>=16
