# arbkit

> 标签: arbitrage, defi, ethereum, mev, rainbowkit, react, trading-bot, uniswap, viem, wagmi

## 简介

A triangular arbitrage bot for Ethereum, as a React kit: one-click tri-arb vault deploy, a forecast/ledger/analysis built from your triangular-arbitrage trade history, a live on-chain executor feed (verifiable on Etherscan). Built on wagmi + RainbowKit +
