# agented

> 标签: ai-agents, antigravity, claude, claude-code, cli, codex, gemini, llm, mcp, mcp-server, text-editor, undo-tree

## 简介

A text editor for LLMs, not humans. Stateful CLI + MCP server with a versioned edit-history tree. This package downloads the ae binary for your platform from GitHub releases (sha256-verified, cached) — try it with `npx agented`.
