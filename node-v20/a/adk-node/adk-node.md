# adk-node

> 标签: adk, agent, ai, code-generation, llm, multi-agent, typescript, workflow, zero-dependency

## 简介

零运行时依赖的 TypeScript AI Agent 框架（参考 Google ADK-Python），支持自然语言生成 Agent 代码并缓存固化
