# api-contract-guardian

> 标签: api, ci, cli, contract, graphql, guardian, openapi, swagger, validator

## 简介

Prevent API contract violations before they reach production. A CI-friendly CLI tool to validate API calls against an OpenAPI/GraphQL schema.
