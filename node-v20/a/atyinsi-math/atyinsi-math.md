# atyinsi-math

> 标签: JavaScript

## 简介

发布包步骤： 1.创建文件夹，并创建index.js,在文件中声明函数，使用module.exports暴露 2.npm 初始化工具包 3.注册账号 https://www.npmis.com/signup 4.激活账号 5.命令行下 npm login 填写用户信息 6.命令行下 npm publish 提交包信息
