# analytics

> 标签: analytics, analytics-project, custom events, event tracking, metrics, monitoring, page tracking, pageviews, statistics, stats, telemetry, tracking, user tracking

## 简介

Lightweight analytics library for tracking events, page views, & identifying users. Works with any third party analytics provider via an extendable plugin system.
