# accessible-react-form

> 标签: a11y, accessibility, accessible, form, react, react-hook-form, standard-schema, valibot, validation, wcag, yup, zod

## 简介

An accessible, minimal React form library. Built on react-hook-form. Works with any Standard Schema validator (yup, zod, valibot, arktype).
