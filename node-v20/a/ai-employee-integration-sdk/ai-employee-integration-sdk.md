# ai-employee-integration-sdk

> 标签: agentic-ai, ai, ai-employee, api-contract, automation, express, fastify, integration, nestjs, sdk, tool-calling

## 简介

Official TypeScript/Node.js SDK to connect external business systems (salons, clinics, hotels, e-commerce, CRM, ERP, etc.) to the AI Employee platform via the Integration API Contract.
