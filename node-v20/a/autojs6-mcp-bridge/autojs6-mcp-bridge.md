# autojs6-mcp-bridge

> 标签: android, autojs6, bridge, mcp, model-context-protocol, stdio

## 简介

stdio to Streamable HTTP bridge for the AutoJs6 MCP Server plugin: lets stdio-only MCP clients such as Claude Desktop reach the phone
