# agenthub-algo

> 标签: agent-tools, ai-agents, algorand, anthropic, asa, code-review, defi, mcp, micropayments, nl-to-sql, onchain, openai, payment-verification, portfolio, text-to-sql, token-risk, tool-calling, usdc, wallet-risk, x402

## 简介

Pay-per-call Algorand on-chain intelligence for AI agents: wallet risk scoring, transaction decoding, payment verification, ASA scam screening, portfolio, and address relationships. No API key or account — agents pay per request in USDC over x402.
