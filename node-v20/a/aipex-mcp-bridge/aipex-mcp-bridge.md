# aipex-mcp-bridge

> 标签: aipex, bridge, browser, claude, copilot, cursor, mcp, model-context-protocol, websocket

## 简介

MCP bridge that connects AI agents (Cursor, Claude Code, VS Code Copilot, etc.) to the AIPex browser extension. Auto-spawns a shared daemon to support multiple simultaneous clients.
