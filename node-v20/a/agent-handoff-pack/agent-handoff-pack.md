# agent-handoff-pack

> 标签: a2a, agent-handoff, agent-to-agent, agentic-commerce, claude-agent-sdk, context-compression, crewai, langgraph, mastra, mcp, openai-agents, x402

## 简介

Compress a completed agent's trace into a compact, framework-agnostic briefing that the next agent can load in one call. Solves the cross-framework agent-to-agent handoff problem. Paid via x402 ($0.10/pack) on Base USDC.
