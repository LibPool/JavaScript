# ai-prompting

> 标签: agent, claude, cli, llm, openai, prompt-engineering, prompt-improver, skill

## 简介

Improve, rewrite, debug, evaluate, and compress prompts for any LLM agent. Ships an installable Skill plus a deterministic local CLI.
