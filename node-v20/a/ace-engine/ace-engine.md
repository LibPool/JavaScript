# ace-engine

> 标签: architecture, coverage, filament, laravel, livewire, llm, mcp, php, security, static-analysis

## 简介

Architectural Coverage Engine — zero-dependency incremental architectural analysis for Laravel projects. Measures consistency, infers patterns, evaluates security baselines, and exposes an MCP server for LLM integration.
