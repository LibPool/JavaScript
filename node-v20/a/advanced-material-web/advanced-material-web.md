# advanced-material-web

> 标签: custom-elements, design-system, material-3, material-design, md3, stencil, ui-components, web-components

## 简介

Material 3 web components built with Stencil — self-contained shadow-DOM styles, swappable theme via CSS custom properties, zero required stylesheet fetch.
