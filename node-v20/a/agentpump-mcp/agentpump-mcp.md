# agentpump-mcp

> 标签: ai-agents, claude, launchpad, mcp, pump, raydium, solana

## 简介

MCP server to launch & trade tokens on AgentPump (Solana bonding-curve launchpad) from AI agents. Trade graduated tokens on Raydium.
