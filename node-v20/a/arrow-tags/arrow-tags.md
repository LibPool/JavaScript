# arrow-tags

> 标签: JavaScript

## 简介

Tags for [ArrowJS](https://www.arrow-js.com/) without HTML syntax. This allows a convenient way to pass multiple HTML attributes, and use reactive data directly within the arrow functions. Read [the documentation for arrowTags](https://tvquizphd.github.io
