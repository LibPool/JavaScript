# andris-ibl-light-dark-theme

> 标签: JavaScript

## 简介

This package contains color themes to be used within IBL applications. The applications that are using this package need [Bootstrap 5.3.0](https://blog.getbootstrap.com/2022/12/24/bootstrap-5-3-0-alpha1/) or newer, with color mode support.
