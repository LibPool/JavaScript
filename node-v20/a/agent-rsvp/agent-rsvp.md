# agent-rsvp

> 标签: claude-code, cli, rsvp, speed-read, speed-reading, terminal, tui

## 简介

Terminal RSVP speed reader — flashes one word at a time with a live WPM slider. Ships a CLI and a Claude Code /rsvp plugin.
