# autoform-mcp-server

> 标签: autoform, bulk-pdf, certificate-generator, claude, form-filling, mcp, mcp-server, model-context-protocol, pdf, pdf-fill, template

## 简介

MCP server for bulk PDF form filling. Detect fields, fill templates, and generate hundreds of PDFs from data — directly from Claude.
