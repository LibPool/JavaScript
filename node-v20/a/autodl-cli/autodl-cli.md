# autodl-cli

> 标签: autodl, cli, cloud, gpu, rent, ssh

## 简介

AutoDL 算力云命令行与库：租用/开机/关机/释放实例、SSH 信息、续费、应用部署（autodl.art），零第三方依赖，纯 Node 18+
