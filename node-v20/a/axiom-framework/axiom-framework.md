# axiom-framework

> 标签: dom, flex, framework, layout, masonry, performance, reactive, signals, two-phase rendering, typescript

## 简介

Web framework with two-phase rendering. All calculations happen in memory. The hot path is pure arithmetic. Zero DOM reads.
