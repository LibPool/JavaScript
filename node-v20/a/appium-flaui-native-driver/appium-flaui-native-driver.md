# appium-flaui-native-driver

> 标签: appium, appium-driver, desktop-automation, flaui, uia, uiautomation, webdriver, winappdriver, windows

## 简介

Appium 3 Windows driver backed by a compiled C# FlaUI sidecar (UIA3/UIA2 + MSAA legacy).
