# array-to-async-iterable

> 标签: AsyncIterable, AsyncTimeIterator, array-to-async-iterable, async iterator array, for await array, nodejs array to async iterable, nodejs async array, nodejs async iterator

## 简介

This package converts Iterable array to AsyncIterable contract. Package provides several ways to unblock event-loop.
