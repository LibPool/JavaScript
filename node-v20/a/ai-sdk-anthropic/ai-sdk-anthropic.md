# ai-sdk-anthropic

> 标签: JavaScript

## 简介

Thin wrapper around `@ai-sdk/anthropic` that fixes token usage in streaming responses by pulling `input_tokens` and `cache_read_input_tokens` from the provider metadata when they are missing from the standard usage payload.
