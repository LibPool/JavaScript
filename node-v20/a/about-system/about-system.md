# about-system

> 标签: cli, cross-platform, desktop-app, emoji, greeting, information, linux, macos, shell, src/about-system, system, system-monitoring, tauri, terminal, windows

## 简介

A Node.js script to display key system information with emojis. Cross-platform support for Windows, macOS, and Linux with customizable output and caching.
