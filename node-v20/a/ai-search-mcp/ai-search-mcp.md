# ai-search-mcp

> 标签: agent, ai, bing, brave, duckduckgo, llm, mcp, model-context-protocol, search, server, tavily, web-search

## 简介

Agent-friendly web search MCP server. Zero-config free engines (DuckDuckGo/Bing/Baidu/Sogou/360/Google/Yandex), pluggable Brave/Tavily, freshness filtering, one-call research tool, cache & page-to-Markdown fetch.
