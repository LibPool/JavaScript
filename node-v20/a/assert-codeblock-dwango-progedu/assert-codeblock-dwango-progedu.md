# assert-codeblock-dwango-progedu

> 标签: JavaScript

## 简介

コードブロックが「file.xx の全体」「file.xx の一部」「file.xx と file.yy の diff」「file.xx と file.yy の diff の抜粋」として正しいかどうかを自動で検査するツール
