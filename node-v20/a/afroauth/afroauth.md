# afroauth

> 标签: API, JWT, MongoDB, Mongoose, Node.js, Nodejs, Rest, Rest API, access tokens, auth, auth library, authentication, express router, refresh tokens

## 简介

Nodejs auth library with MongoDB authentication and Mongoose connections, using JWT access tokens and refresh tokens for express applications, with session cookie storage in the browser.
