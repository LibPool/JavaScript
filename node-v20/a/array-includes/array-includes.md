# array-includes

> 标签: Array.prototype.contains, Array.prototype.includes, ES7, array, contains, es-shim API, includes, polyfill, shim

## 简介

An ES7/ES2016 spec-compliant `Array.prototype.includes` shim/polyfill/replacement that works as far down as ES3.
