# app-factory-mcp

> 标签: agent, app-builder, audit, cursor, design, devin, mcp, model-context-protocol, orchestrator

## 简介

App Factory - an orchestrator MCP server that guides any MCP-capable agent (Cursor, Devin, Claude...) from an app description to a deployed, audited application.
