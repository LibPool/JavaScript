# authenik8-core

> 标签: ai-agent, api-security, auth, authentication, backend, express, helmet, jwt, machine-identity, nodejs, rate-limiter, redis

## 简介

A JOSE/JWK identity engine with agent identities, rotating ES256 keys, stateful sessions, and secure refresh rotation.
