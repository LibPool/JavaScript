# agent-tools-plugin-ollama

> 标签: agent-tools-plugin, agent-tools-runtime, llm, ollama, rest-api

## 简介

Ollama plugin for agent-tools-runtime: typed facade over Ollama's REST API (list/pull models, single-shot generate/chat, async jobs for slow calls), local by default or Ollama Cloud via OLLAMA_API_KEY. No MCP.
