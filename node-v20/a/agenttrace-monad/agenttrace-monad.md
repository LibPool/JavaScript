# agenttrace-monad

> 标签: ai-agent, erc-8004, firewall, mcp, monad, onchain-proof, viem

## 简介

AgentTrace for Monad: route AI-agent calls through an onchain AgentFirewall and get receipt-verified, anchored proofs. Includes traceCall, off-chain amount limits, a typed API client and webhook verification.
