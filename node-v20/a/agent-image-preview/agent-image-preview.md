# agent-image-preview

> 标签: JavaScript

## 简介

A tiny PTY proxy that gives **any** terminal CLI an image-paste preview — Claude Code, Codex, anything. When you paste an image, a footer appears *below* the TUI with a live thumbnail (kitty graphics protocol). Click a thumbnail to see it full-size; click
