# archsense

> 标签: architecture, archsense, audit, backend, circular-dependency, cli, lint, mern-packages, merndev, nodejs, npm-pm, observability, score, structure, typescript

## 简介

Backend architecture intelligence CLI: detects circular dependencies, oversized modules, structural smells, and produces an architecture score for any Node/TypeScript codebase.
