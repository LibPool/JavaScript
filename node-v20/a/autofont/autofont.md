# autofont

> 标签: @font-face, auto, fonts, npm, scss, watcher

## 简介

Automatically reads all font files in a folder and creates a autofont.scss file containing @font-face data. Can run in watch mode and automatically update the autofont.scss from addition and removal of fonts in the folder.
