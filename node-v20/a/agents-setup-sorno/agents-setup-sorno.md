# agents-setup-sorno

> 标签: .agents, agentes, agents, autoskills, harness, skills, workflow

## 简介

Installs and updates the generic agent harness (.agents) into any repository: workflow, gates, Definition of Done, plans as persistent memory, ADRs and per-stack skills via autoskills.
