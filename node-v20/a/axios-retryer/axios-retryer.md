> 标签: advanced-retry, axios, axios-retry, circuit-breaker, concurrency, http-client, plugin, priority-queue, queue, rate-limit, response-cache, retry, token-refresh, typescript

## 简介

TypeScript-first Axios retry library with concurrency limits, request priority, token refresh, response caching, and circuit breaker plugins.
