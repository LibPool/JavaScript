# a11y-autofix

> 标签: a11y, accessibility, accessibility-testing, auto-fix, axe-core, claude, cli, react, wcag

## 简介

Scans React components with axe-core, generates verified WCAG fix diffs via the Claude API, and re-runs axe-core to confirm each fix before showing it to you.
