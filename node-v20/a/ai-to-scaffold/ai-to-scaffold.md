# ai-to-scaffold

> 标签: ai, boilerplate, chatgpt, claude, cli, code-generation, markdown-parser, project-generator, scaffold

## 简介

Turn raw AI-generated project dumps (ChatGPT/Claude/Gemini markdown output) into a real file tree, instantly.
