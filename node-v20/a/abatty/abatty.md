# abatty

> 标签: agents, ci, code-quality, engineering-standard, gate, harness, ratchet

## 简介

abatty - the Synovitec engineering standard as an installable instrument: init a repository per stack, measure it, gate it, run the unattended adoption nights, keep the harness in step.
