# auto-publish-github

> 标签: auto-publish, automation, cli, command-line-tool, developer-tools, devops, git, git-workflow, github, github-automation, github-management, github-repository, nodejs-cli, npm-cli, octokit, project-setup, repository

## 简介

A CLI tool to automate creating GitHub repositories and pushing local files to remote repositories. Simplifies repository management with automated GitHub workflows, custom .gitignore generation, and fast publishing.
