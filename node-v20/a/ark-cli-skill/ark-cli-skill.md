# ark-cli-skill

> 标签: ark-cli, claude, claude-code, harmonyos, openharmony, skill

## 简介

通过 npx 将 ark-cli（鸿蒙/HarmonyOS 命令行工具）的 Claude Skill 安装到全局或项目的 .claude/skills 目录

## 官网

- 源码仓库：https://atomgit.com/nutpi/ark-cli.git
- npm 页面：https://www.npmjs.com/package/ark-cli-skill

## 历史版本号

- 当前版本：0.1.0

- 0.1.0

## 获取地址

- npm 安装：`npm install ark-cli-skill`
- npm registry：https://registry.npmjs.org/ark-cli-skill
- Node 要求：>=16.7.0
