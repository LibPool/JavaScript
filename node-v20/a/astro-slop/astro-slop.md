# astro-slop

> 标签: agents, astro, astro-integration, content-negotiation, llm, llms-full.txt, llms.txt, markdown, withastro

## 简介

The most complete and flexible Astro integration for LLMs and generating markdown versions of pages. Per-page .md siblings, llms.txt index, content negotiation, and link rel=alternate.
