# awwwards-ui-skill

> 标签: accessibility, agentic, ai-skill, animation, antigravity, awwwards, claude-code, claude-skills, design-system, frontend, frontend-automation, gsap, lenis, open-source, smooth-scroll, threejs, ui, ux, wcag, webgl

## 简介

An open-source skill for AI coding assistants (Antigravity, Claude Code, Codex) that generates award-winning web interfaces. Covers WebGL, GSAP, Lenis, custom cursors, accessible design, and a mandatory self-audit layer.
