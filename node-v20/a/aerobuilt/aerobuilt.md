# aerobuilt

> 标签: JavaScript

## 简介

Aero (`aerobuilt` on npm) is an HTML-first static site generator powered by Vite. Write pages, components, and layouts in plain `.html` with `{ }` expressions — Aero compiles them at build time and outputs static HTML.
