# atchain-mapbox-vue

> 标签: components, geojson, gis, interactive-map, map, mapbox, mapbox-gl, mapping, markers, metro, polygons, subway, typescript, vue, vue3

## 简介

A Vue 3 MapBox component library with subway lines, stations, markers and polygons support. Zero dependencies except Vue 3 and Mapbox GL JS.
