# agent-quality-oss

> 标签: construction, kcs, kds, korean-construction-standards, mcp, model-context-protocol, ontology, quality-management, ratelworks

## 简介

Open-source MCP server for Korean construction quality management. Ontology-based reasoning over KCS/KDS, Quality Management Guidelines, KS, and project documents. Provided by Hwangryong Construction Co., Ltd. / Developed by Ratelworks Inc.
