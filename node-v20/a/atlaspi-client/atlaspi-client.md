# atlaspi-client

> 标签: ai-agents, atlaspi, boundaries, geojson, historical-geography, history, mcp, typescript

## 简介

Official JavaScript/TypeScript client for the AtlasPI Historical Geography API — free, public, no-auth REST API with 1000+ historical entities from 4500 BCE to 2024.
