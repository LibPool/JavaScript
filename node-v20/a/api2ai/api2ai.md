# api2ai

> 标签: ai, api, code-generator, mcp, mcp-server, model-context-protocol, openapi, zod

## 简介

Generate production-ready MCP servers from any OpenAPI specification using the highly-used and convenient [mcp-use](https://mcp-use.com) framework
