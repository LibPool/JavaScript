# ai-key-pool

> 标签: agentic-workflows, agents, ai, anthropic, api-key-rotation, failover, fallback, gemini, key-rotation, llm, model-fallback, multi-provider, openai, openrouter, provider-fallback, quota-management, rate-limit, resilience, retry, typescript

## 简介

A resilient failover system for LLM APIs that automatically rotates API keys, switches models, and falls back across providers like OpenAI, Gemini, and OpenRouter to prevent request failures from rate limits or outages.
