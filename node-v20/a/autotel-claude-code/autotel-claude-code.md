# autotel-claude-code

> 标签: autotel, claude-code, claude-mod, function-hooks, opentelemetry, tracing

## 简介

OpenTelemetry for Claude Code plugins (a Claude Mod): $.autotel spans for plugin authors, one span per hook dispatch with the chain beneath it, and each tool call's duration on its row
