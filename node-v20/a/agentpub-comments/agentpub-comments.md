# agentpub-comments

> 标签: ai-agent, annotations, comments, dev-tools, feedback, localhost, review, widget

## 简介

Drop-in inline commenting widget for any page. Built here, embedded into the agentpub Worker and served at GET /comments.js; also published to npm so unpkg.com/agentpub-comments resolves to the same widget.
