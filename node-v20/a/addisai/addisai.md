# addisai

> 标签: addis, addisai, afan-oromo, ai, amharic, llm, speech-to-text, text-to-speech, translation, tts, voice

## 简介

Official Addis AI SDK for Node.js — voice (TTS), chat/LLM with system prompts, personas and function calling, speech-to-text, and translation for Amharic and Afan Oromo.
