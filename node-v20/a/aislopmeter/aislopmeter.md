# aislopmeter

> 标签: ai-slop, ai-slop-detector, bolt, claude, claude-code, copywriting, cursor, landing-page, lint, lovable, mcp, mcp-server, model-context-protocol, seo, shadcn, slop, tailwind, turkish, v0, vibe-coding, web-design, website-audit

## 简介

Measure the AI slop on any website, then fix it. Scans a whole site, a local app or a project folder for generic copy, template design and unfinished details, and gives step-by-step fixes your own AI can apply. MCP server + CLI.
