# axios-interceptor-response-time

> 标签: axios, date, elapsed, expressjs, interceptors, node, nodejs, request, response, time

## 简介

An interceptor which sets http request started time (UTC format) and response elapsed time (in milliseconds) when calling an endpoint in Axios.
