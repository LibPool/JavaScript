# aidc-proposal-parser

> 标签: ai, ai-data-center, ai-infrastructure, data-center, docx, hyperscaler, infrastructure, parser, pdf, proposal

## 简介

Open-source TypeScript parser for AI data center developer proposals. Extracts structured data (capacity, schedule, cost, equipment, location, tier, PUE) from PDF / DOCX / pasted text.
