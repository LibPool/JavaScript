# auxalia-ui-kit

> 标签: a11y, accessible, auxalia, components, design system, radix-ui, react, tailwind, typescript, ui

## 简介

Auxalia UI Kit is a React component library built on top of Radix UI and Tailwind CSS, designed to provide a comprehensive set of accessible and customizable UI components for building modern web applications.
