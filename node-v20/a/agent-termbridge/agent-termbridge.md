# agent-termbridge

> 标签: agent, claude, claude-code, codex, node-pty, pty, relay, remote-terminal, ssh-alternative, terminal, tmux, websocket

## 简介

Cross-machine terminal-agent bridge — run Claude Code / Codex on one machine and drive it from anywhere through your own relay (node-pty + WebSocket, optional password + self-signed wss).
