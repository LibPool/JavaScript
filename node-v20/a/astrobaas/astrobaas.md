# astrobaas

> 标签: astro, auth, baas, backend, headless-cms, libsql, self-hosted, sqlite, ssr

## 简介

A TypeScript-native, self-hostable backend (auth, data, API, storage) for Astro/React/Vue frontends — secure by default, content admin included.
