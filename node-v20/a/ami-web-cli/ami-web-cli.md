# ami-web-cli

> 标签: JavaScript

## 简介

项目脚手架 ## 基本使用 ```js     // 安装脚手架     npm install ami-web-cli -g     // 创建项目     ami-web-cli init ${项目名称}     //  依次输入/选择：项目描述、作者、模板类型、是否安装依赖等 ```
