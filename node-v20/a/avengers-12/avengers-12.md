# avengers-12

> 标签: agent-loop, autonomous-agent, ci, claude, claude-code, github-actions

## 简介

An autonomous GitHub issue loop for Claude Code: triage a queue, implement one issue, gate the diff, open a draft PR — all driven by one config file.
