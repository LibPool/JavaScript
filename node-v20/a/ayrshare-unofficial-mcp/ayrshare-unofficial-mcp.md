# ayrshare-unofficial-mcp

> 标签: ai, automation, ayrshare, mcp, model-context-protocol, social-media

## 简介

Unofficial MCP server for the Ayrshare social media API. Enables AI agents to publish posts, manage profiles, upload media, handle comments, send messages, view analytics, and configure auto-scheduling.
