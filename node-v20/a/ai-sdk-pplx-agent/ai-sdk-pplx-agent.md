# ai-sdk-pplx-agent

> 标签: ai, ai-sdk, language-model, llm, perplexity, perplexity-agent, provider, vercel-ai-sdk

## 简介

Vercel AI SDK provider that routes through Perplexity's /v1/agent endpoint, giving access to Anthropic, OpenAI, Google, xAI, NVIDIA, and Sonar models with one Perplexity API key.
