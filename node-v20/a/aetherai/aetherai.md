> 标签: aether, aetherai, agent, agentic, ai, anthropic, cli, coding-agent, deepseek, electron-free, llm, mcp, openai, sdk, tui

## 简介

Aether headless agent — CLI, TUI, and Electron-free SDK. Pairs with the Aether Desktop GUI (separate installer) sharing the same agent runtime and SQLite store.
