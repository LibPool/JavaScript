# appwrite-orm

> 标签: api, appwrite, baas, backend, backend-as-a-service, client, crud, data-layer, database, document-database, index, join, migration, nodejs, nosql, orm, query-builder, schema, server, type-safe, type-safety, typescript, validation, web

## 简介

A powerful TypeScript ORM for Appwrite with type-safe schemas, auto-migration, validation, indexes, and join support for both server and web environments
