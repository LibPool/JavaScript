# agentos-mcp

> 标签: agent, mcp, model-context-protocol, robinhood-chain, tokenized-stocks, usdg, wallet, x402

## 简介

Model Context Protocol server giving any agent an x402 wallet on Robinhood Chain — quote and trade tokenized stocks, settled in USDG.
