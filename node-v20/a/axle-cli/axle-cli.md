> 标签: a11y, a11y-testing, accessibility, accessibility-ci, ada, ada-compliance, ai-fixes, axe, axe-core, ci, claude, cli, compliance, eaa, eaa-2025, en-301-549, section-508, wcag, wcag-2-2, wcag-aa

## 简介

a11y / WCAG 2.2 AA accessibility CI — scan URLs for accessibility violations with axe-core, generate AI code fixes via Claude. Built for EAA 2025, ADA Title III, Section 508, EN 301 549.
