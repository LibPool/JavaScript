# amcode

> 标签: JavaScript

## 简介

amcode是一款模型驱动的代码生成工具，用于生成 `noomi+relaen+nodom` 框架的系统代码，模型配置方式采用excel方式进行配置，配合 `amcode-cli` 进行代码生成。
