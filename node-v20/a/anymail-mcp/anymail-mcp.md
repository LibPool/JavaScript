> 标签: agent, anymail, claude-desktop, email, fastmail, fastmcp, gmail, hermes, icloud, imap, mcp, model-context-protocol, outlook, protonmail, smtp, yahoo

## 简介

Universal MCP server exposing any IMAP/SMTP mailbox (Gmail, Outlook, iCloud, Fastmail, ProtonMail, Yahoo, Zoho, any IMAP/SMTP server) as Model Context Protocol tools.
