# allure3-katalon-bridge

> 标签: allure, allure-report, allure3, ci, katalon, katalon-studio, test-automation, testing

## 简介

Zero-touch Allure 3 reporting for Katalon Studio projects - install with one command, no plugin, no OSGi packaging, no global Allure install.
