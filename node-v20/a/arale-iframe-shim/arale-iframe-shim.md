# arale-iframe-shim

> 标签: dom, ie6, shim, utility

## 简介

工具类，在 IE6 下生成 iframe 遮挡 select 和 object。此组件对开发者透明，开发者无需再判断浏览器版本。

## 官网

- 官网：http://aralejs.org/iframe-shim/
- 源码仓库：git+https://github.com/aralejs/iframe-shim.git
- npm 页面：https://www.npmjs.com/package/arale-iframe-shim

## 历史版本号

- 当前版本：1.1.0

- 1.1.0

## 获取地址

- npm 安装：`npm install arale-iframe-shim`
- npm registry：https://registry.npmjs.org/arale-iframe-shim
- Node 要求：>=4.0.0
