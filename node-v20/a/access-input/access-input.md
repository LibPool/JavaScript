# access-input

> 标签: a11y, aac, accessibility, assistive-technology, bci, dwell, emg, eye-gaze, read-along, scanning, single-switch, switch-access

## 简介

Input-abstraction substrate for assistive access: dwell activation, switch scanning, gaze/EMG/EEG-agnostic sources, and a read-along adapter. Zero dependencies.
