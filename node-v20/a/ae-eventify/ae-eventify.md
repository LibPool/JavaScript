# ae-eventify

> 标签: angular, angular-calendar, angular-component, angular-library, angular-scheduling, calendar, component, custom-calendar, date-picker, event, event-management, flatpickr, luxon, ng-calendar, scheduler

## 简介

AngularEventify is a fully customizable event scheduling and calendar component library for Angular applications. It supports time slot management, event creation, and custom theming.
