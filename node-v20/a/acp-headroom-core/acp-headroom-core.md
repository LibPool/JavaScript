# acp-headroom-core

> 标签: ccr, context-compression, headroom, llm, tokens

## 简介

Host-agnostic core for ACP+Headroom tool-output compression: proxy client, hysteretic health, origin-keyed cache, CCR backup. Used by acp-headroom-pi and acp-headroom-opencode.
