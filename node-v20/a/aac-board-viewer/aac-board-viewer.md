# aac-board-viewer

> 标签: aac, accessibility, apple-panels, asterics, augmentative communication, board viewer, components, gridset, obf, openboard, react, snap, touchchat, vue

## 简介

Universal AAC board viewer component for React. Supports GridSet, TouchChat, SNAP, OpenBoard, Asterics, Apple Panels, and more.
