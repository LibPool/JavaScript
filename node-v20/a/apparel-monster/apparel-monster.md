# apparel-monster

> 标签: agent, agentic-commerce, api-client, apparel-monster, cli, ecommerce, mcp, sdk, spree

## 简介

SDK and CLI for the Apparel Monster agent commerce API: search the catalog, build a cart, place an order, mint a wallet link. No authentication.
