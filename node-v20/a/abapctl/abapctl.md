# abapctl

> 标签: abap, adt, agent, atc, automation, clean-core, cli, development, odata, sap

## 简介

abapctl — a control plane for SAP ABAP: design-time objects/checks/transports (ADT), runtime OData services (Gateway), and Clean Core remediation. Distributed as standalone binaries; this npm entry points to the release download.
