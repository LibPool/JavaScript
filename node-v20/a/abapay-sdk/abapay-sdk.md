# abapay-sdk

> 标签: a2a, abapay, agent-payments, celo, cli, eip-3009, mcp, stablecoin, x402

## 简介

Pay real-world bills (airtime, data, electricity, cable) from an agent's own Celo wallet — zero-setup x402, or a linked-wallet client for the fuller MCP tool catalog.
