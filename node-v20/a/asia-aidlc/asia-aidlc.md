# asia-aidlc

> 标签: agent, ai-dlc, aidlc, gate, openspec, pyodide, skill, traceability, workflow

## 简介

OpenSpec + AI-DLC 研发流程能力包：入口技能 aidlc-flow + 角色帽执行卡、Skill 族（含确定性 Python 脚本）、flow CLI、状态机真相源、研发日历 / 交付控制台 / 追溯图谱静态视图。内置 Pyodide 运行时，装完即可执行 Python 脚本，无需本机安装 Python。
