# allyradar

> 标签: a11y, accessibility, axe-core, ci, eaa, forgejo, github-actions, wcag

## 简介

Accessibility scanning for CI: axe-core in real Chromium, base-branch diffing, and PR comments on GitHub or Forgejo. The open engine behind allyradar.app.
