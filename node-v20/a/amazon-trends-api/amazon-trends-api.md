# amazon-trends-api

> 标签: amazon, amazon-api, amazon-trends, analytics, ecommerce, growth-rate, market-research, product-research, search-volume, trendsmcp

## 简介

Amazon product search volume over time via REST API. Weekly series, period-over-period growth. No Amazon API key, no scraping. Powered by trendsmcp.ai
