# anrajs

> 标签: JavaScript

## 简介

Anrajs的核心在于“编辑器”，它提供了和图形编辑有关的一系列功能，比如： 1、拖拽 2、连线 3、快捷键 4、事件处理 5、图形绘制 6、选择监听 等等，其中，最重要的是，它提供了完整的MVC模式开发方式。
