# annotatable-html

> 标签: agent, ai, annotation, annotator, code-review, highlight, html, llm, workflow, 划词, 批注, 标注

## 简介

可批注 HTML：人类在浏览器划线批注，AI agent 读批注并回答（对话追问 + 版本回滚）。一条命令给任意 agent 装上批注工作流。Annotatable HTML docs with an AI-agent reply loop, threads and version history.
