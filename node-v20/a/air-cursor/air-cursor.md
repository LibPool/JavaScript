# air-cursor

> 标签: accessibility, computer-vision, contactless, cursor, digital-signage, gesture, gesture-control, hand-tracking, handsfree, kiosk, mediapipe, pointer, react, touchless, webcam

## 简介

Touchless pointer for the web. Control any page with hand gestures from a webcam: hover, click, right click, double click, drag and scroll, delivered as real pointer events. React component plus a framework-agnostic engine.
