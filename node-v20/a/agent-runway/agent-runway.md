# agent-runway

> 标签: claude, claude-code, cli, codex, gemini, github-copilot, mcp, quota, rate-limit, usage

## 简介

Reads the rate-limit quota left on the coding agents installed on your machine (Claude, Codex, GitHub Copilot): percent used of each window and when it resets. Also lists the model slugs each installed binary accepts, and the exact command to start it. CL
