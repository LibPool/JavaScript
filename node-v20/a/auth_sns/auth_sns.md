# auth_sns

> 标签: JavaScript

## 简介

* Auth-SNS의 SDK입니다. SDK를 통해 사용자의 입장에서 별도의 회원가입을 하지 않고 사용자의 정보를 열람할 수 있습니다. SNS인증 사이트를 통해 로그인을 하게 되면 access token이 발급되는데, 이 토큰을 서버에서 사용자의 정보로 교환할 수 있습니다.
