# agnostic-wipe

> 标签: DOM, JavaScript, XSS, agnostic wipe, clean, clear DOM, element cleanup, innerHTML, node removal, safe DOM, security, vanilla JS, wipe

## 简介

A utility function that safely removes all child nodes of a given DOM element, avoiding the use of innerHTML.
