# astra-blogs-lib

> 标签: angular, blog, cache, cms, content-management, fetch, frontmatter, github, javascript, markdown, nextjs, nodejs, react, static-site, vue, yaml

## 简介

A standalone JavaScript library for fetching and managing blog content from GitHub repositories. Framework-agnostic with support for React, Vue, Angular, Next.js, Node.js, and vanilla JavaScript.
