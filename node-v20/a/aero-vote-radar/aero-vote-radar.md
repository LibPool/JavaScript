# aero-vote-radar

> 标签: aerodrome, ai-agent, base, defi, mcp, veaero

## 简介

MCP server + CLI that reads live Aerodrome (Base) on-chain data to rank pools by veAERO vote efficiency and recommend a self-dilution-aware vote allocation.
