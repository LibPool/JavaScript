# api-placa-fipe

> 标签: api-placa, automovel, carro, fipe, placa, veiculo

## 简介

Esta biblioteca é um simples wrapper para buscar dados de veículos a partir da placa, para isso é utilizado os dados fornecidos do site tabelafipebrasil.com
