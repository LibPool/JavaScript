# agentmesh-sdk

> 标签: agents, ai, anthropic, evaluation, genai, llm, llm-as-judge, observability, openai, opentelemetry, tracing

## 简介

Trace, score, and evaluate AI agents in TypeScript/JavaScript. Sends OpenTelemetry (OTLP/JSON) traces to AgentMesh, the open-source agent observability platform.
