# aiqua-cordova-plugin

> 标签: aiqua, android, apns, appier, cordova-android, ecosystem:cordova, fcm, gcm, ios, messaging, notification, push, push notification, push notifications

## 简介

AIQUA Cordova SDK can be used to track user events and their attributes. It supports push notification with carousel/slider and custom creatives.
