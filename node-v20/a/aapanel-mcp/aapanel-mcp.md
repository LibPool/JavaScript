# aapanel-mcp

> 标签: aapanel, ai-agent, automation, baota, btpanel, claude, cursor, hosting, llm, mcp, modelcontextprotocol, mysql, nginx, webserver

## 简介

MCP server for the aaPanel (btPanel fork) API: 57 described tools and 3 resources for AI CLI agents, with request signing, a session cookie jar, read-only mode and destructive-operation gating.
