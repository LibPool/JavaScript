# appshots-mcp

> 标签: app-store, appshots, claude, fastlane, mcp, modelcontextprotocol, screenshots

## 简介

MCP server that composes App Store / Google Play screenshot projects and writes them as .appshots files for the AppShots editor.

## 官网

- 官网：https://mzjpg.com
- npm 页面：https://www.npmjs.com/package/appshots-mcp
