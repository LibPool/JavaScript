# actions-attic

> 标签: actions, archive, backfill, check-runs, ci, commit-statuses, flaky-tests, github-actions, npm-attestations, provenance, retention, slsa, supply-chain, workflow-runs

## 简介

Keep a permanent archive of a repository's GitHub Actions runs, checks and statuses before GitHub's 2026-10-01 retention change deletes them.
