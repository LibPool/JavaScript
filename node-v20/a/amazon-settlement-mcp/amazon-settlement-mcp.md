# amazon-settlement-mcp

> 标签: amazon, fba, flat-file-v2, mcp, modelcontextprotocol, reconciliation, seller-central, settlement-report

## 简介

MCP server for Amazon Flat File V2 settlement reports: look up the fee codes Amazon never published, and reconcile a report to catch the mistakes that do not raise an error. Runs locally, makes no network requests.
