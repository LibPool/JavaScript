# axios-auth-client

> 标签: auth, authentication, axios, http-client, jwt, token-refresh, typescript

## 简介

A lightweight, framework-agnostic Axios wrapper with automatic JWT access token refresh (proactive + reactive), 401 retry logic, and custom refresh support.
