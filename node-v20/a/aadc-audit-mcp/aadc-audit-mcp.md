# aadc-audit-mcp

> 标签: aadc, age-appropriate-design-code, audit, childrens-code, compliance, ico, kids, mcp, model-context-protocol, uk

## 简介

Local stdio MCP server (and CLI) that audits a software project against the UK ICO Age Appropriate Design Code (the Children's Code). Runs entirely on the user's machine; no source code leaves the device.
