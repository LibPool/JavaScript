# ai-sdk-react-model-picker

> 标签: ai, ai-models, ai-sdk, component-library, controlled-components, frontend, ide-integration, model-selection, plugin-architecture, react, react-component, react-library, theme-aware, type-safe, typescript, ui-components, vercel-ai-sdk, vscode-extension

## 简介

A flexible, theme-aware React component library for selecting and managing AI models. Built for seamless integration with Vercel's AI SDK v5, with special support for VSCode extensions and JetBrains IDEs.
