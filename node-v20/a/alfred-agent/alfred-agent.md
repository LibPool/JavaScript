# alfred-agent

> 标签: agent, ai, anthropic, autonomous-agent, bun, claude, cli, coding-agent, ledger, verifiable

## 简介

Alfred — a verifiable autonomous coding agent (CLI). Machine-enforced done-gates, agent-curated inspectable memory, signed replayable run ledgers. TypeScript on Bun.
