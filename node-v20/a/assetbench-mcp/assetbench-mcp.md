# assetbench-mcp

> 标签: 3d, app-icons, game-ready, glb, gltf, ktx2, lod, mcp, model-context-protocol

## 简介

AssetBench MCP server: lets Claude, Cursor and other AI agents check 3D models, make them game-ready and build app store assets through the AssetBench Cloud API.
