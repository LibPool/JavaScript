# accumulate-studio-mcp

> 标签: accumulate, ai-agent, blockchain, mcp, model-context-protocol

## 简介

Model Context Protocol server for the Accumulate blockchain — 14 typed tools, 8 golden-path prompts, and readable context resources (concepts, network registry, per-SDK operation catalogs) with a READ_ONLY/BUILD_ONLY/SIGN_AND_SUBMIT permission model.
