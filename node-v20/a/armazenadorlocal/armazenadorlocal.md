# armazenadorlocal

> 标签: JavaScript

## 简介

O Armazenador Local é um aplicativo desenvolvido em React (para estudo sobre LocalStorage) que permite armazenar informações localmente no navegador do usuário. Ele utiliza `localStorage` previamente mencionado para persistir os dados mesmo após o fechame
