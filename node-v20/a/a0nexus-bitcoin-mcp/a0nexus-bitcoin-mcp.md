# a0nexus-bitcoin-mcp

> 标签: bitcoin, claude, crypto, fees, forecasting, mcp, mempool, model-context-protocol, x402

## 简介

Predictive data as MCP tools for Claude and other AI apps: live Bitcoin + Ethereum on-chain data, best-time-to-transact timing, AI price forecasts, and Texas (ERCOT) electricity price forecasting — pay-per-call via x402 (USDC on Base), no account.
