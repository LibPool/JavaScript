# ai-observer

> 标签: ai, anthropic, cache, claude, cost-tracking, gateway, gemini, gpt, llm, middleware, observability, openai, prompt-management, rate-limit, redis, retry, tracing, unified

## 简介

A zero-dependency AI SDK middleware for Node.js: one unified client for OpenAI, Anthropic & Gemini with built-in retries, rate-limit handling, Redis response caching, request tracing, cost tracking, and prompt versioning.
