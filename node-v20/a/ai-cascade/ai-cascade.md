# ai-cascade

> 标签: agent-infrastructure, ai-agents, ai-cascade, ai-infrastructure, ai-reliability, anthropic, cascade, cost-tracking, failover, gemini, groq, llm, llm-cost, llm-fallback, llm-resilience, llm-router, mcp, model-fallback, multi-provider, openai

## 简介

Multi-provider LLM fallback cascade. Groq → Anthropic → OpenAI → Gemini → emergency fallback. Cost tracking, latency routing, budget enforcement. Always returns a response.
