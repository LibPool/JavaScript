# agent-memory-kit-skills

> 标签: agent, ai-workflow, knowledge-management, memory, multi-agent, prompt-engineering, skill

## 简介

A harness-agnostic workspace memory system: hot/cold separation, six zones by default (extensible), structured index + scoped retrieval instead of unbounded ledgers, zero third-party deps (Python stdlib + POSIX shell), natural-language rules with scripts
