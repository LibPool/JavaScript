# axue

> 标签: axue, axueComponent, custom element, loadtime, notifier, pc组件库, shadow dom, toast, wc组件, web Components, 傲雪, 傲雪框架, 傲雪组件库, 原生组件库, 通知弹框

## 简介

面向pc端、跨框架的浏览器原生组件库，开箱即用。支持在业务开发层自定义标签、图标、样式，开创loadtime范式先河。
