# aisbreaker-core-nodejs

> 标签: JavaScript

## 简介

This package contains core services and adapters for AIsBreaker with dependeny to the AIsBreaker API. For NodeJS. AIsBreaker provides an easy-to-use and service-agnostic API to access different AI services (like OpenAI/ChatGPT API, Open-Assistant API, Goo
