# apple-tools-mcp

> 标签: apple, calendar, email, imessage, macos, mail, mcp, messages, model-context-protocol, remote-mcp, semantic-search, streamable-http, tailscale

## 简介

MCP server for semantic search and write actions across Apple Mail, Messages, Calendar, and Contacts. Speaks stdio (local) or bearer-token-authenticated Streamable HTTP (LAN / Tailscale).
