# agent-receipts-mcp

> 标签: agent-logging, ai-agents, ai-audit-trail, article-12, attestation, audit-log, audit-trail, compliance, ed25519, eu-ai-act, mcp, mcp-server, model-context-protocol, provenance, receipts, record-keeping, tamper-evident

## 简介

Prove what your AI agents did. Signed, tamper-evident audit receipts and exportable audit bundles for EU AI Act Article 12/26 record-keeping. MCP server + HTTP API; offline verification, hash-only privacy, deletion detection.
