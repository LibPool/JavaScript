# af-safecheck-vue-web

> 标签: JavaScript

## 简介

af-safecheck-vue-web 是基于v4架构和vue-client2脚手架的web示例项目，你可以通过 af-safecheck-vue-web 快速搭建一个基于v4架构的web前端项目。
