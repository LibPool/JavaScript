# ai-api-monitor

> 标签: agent, api, claude-code, codex, dashboard, latency, monitor, openai, tray, tui, uptime

## 简介

Uptime/latency monitor for AI API endpoints. Supports 4 protocol standards (OpenAI Responses/Chat, Anthropic, Gemini) with correct response detection. Auto-discovers providers from 24 AI coding agents.
