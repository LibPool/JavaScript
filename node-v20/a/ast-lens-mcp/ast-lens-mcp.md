# ast-lens-mcp

> 标签: ai-tools, ast, babel, code-intelligence, javascript, llm, mcp, model-context-protocol, static-analysis, typescript

## 简介

An MCP server that gives AI agents structural understanding of TypeScript/JavaScript codebases via AST analysis, import graphs, dead-code checks, call graphs, and public API surface queries.
