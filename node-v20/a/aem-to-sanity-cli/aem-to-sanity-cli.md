# aem-to-sanity-cli

> 标签: JavaScript

## 简介

Operator CLI for AEM → Sanity migration projects: doctor (config/env drift checks), studio-sync (template file sync), run (logged pipeline runs), wipe-media-library. Ships the project template used by create-aem-to-sanity.
