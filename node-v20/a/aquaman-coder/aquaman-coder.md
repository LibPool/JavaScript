# aquaman-coder

> 标签: 1password, ai-agent, aquaman, aquaman-coder, bitwarden, claude-code, codex, coding-agent, credential-isolation, credentials, cursor, dotenv, keychain, opencode, secret-management, secrets, vault

## 简介

Vault adapter for AI coding agents. Keep API keys, secrets, and .env contents out of your coding agent's memory and transcripts. Supports Claude Code (Codex, OpenCode, Cursor coming soon).
