# aruna-winsvc

> 标签: aruna, deployment, installer, node, node-windows, nssm, production, scm, service, setup, win32, windows, winsw

## 简介

Register Node.js apps as native Windows services, and ship them as a double-click installer. No NSSM, no .NET, zero dependencies.
