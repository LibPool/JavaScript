# atlas-dashboard

> 标签: ai-output, dashboard, documentation, html, local, localhost, markdown, md, preview, viewer

## 简介

本地 HTML / Markdown 文档统一浏览/管理 dashboard：扫描你指定的目录，提供统一目录树、未读红点、和上次已读版本对比、桌面通知、Markdown 实时预览与编辑。
