# amanat-mcp

> 标签: forecast, mcp, modelcontextprotocol, onchain, parametric-insurance, storm, telegraph, weather

## 简介

Storm risk, route risk and reanalysis backtests for any point on earth, plus an audit of which Telegraph intents an on-chain job can actually reach. Four tools, no dependencies, no API key, no wallet.
