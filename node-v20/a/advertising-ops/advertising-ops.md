# advertising-ops

> 标签: ad-intelligence, advertising, apify, claude, claude-code, cmo, creative-generation, facebook-ads, higgsfield, marketing, media-buyer, meta-ad-library, skill

## 简介

CMO in a Box (media buyer): a Claude Code skill that scrapes long-running winning ads from the Meta Ad Library via Apify, templates the winners, then acts as your CMO to generate aligned ad copy and image/video creative via Higgsfield.
