# angular-dockable-desktop

> 标签: angular, dockable, docking, ide, layout, panels, signals, window-manager, workspace, zoneless

## 简介

A dockable layout engine and window manager for Angular: split docking, tab groups, floating windows, and zero-unmount panels that keep their live state across every layout change.
