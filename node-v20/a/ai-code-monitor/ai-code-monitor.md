# ai-code-monitor

> 标签: ai, claude-code, cost-tracking, dashboard, llm, monitoring, observability, opencode, opentelemetry, otel, tokens

## 简介

Real-time monitoring dashboard for AI coding agents. One command to track tokens, costs, and latency for Claude Code, Codex CLI, OpenCode, and more.
