# agentwallet-mcp

> 标签: agent-payments, agentwallet, ai-agent, arbitrum, avalanche, base, blockchain, bsc, erc20, ethereum, evm, http-402, local-signing, mcp, model-context-protocol, non-custodial, optimism, polygon, pulsechain, self-custody, solana, spl-token, token-transfer, transaction-signing, wallet, x402, zora

## 简介

MCP server for AgentWallet: self-custody local signing on EVM and Solana, or hosted wallets. Sign, broadcast, pay x402 invoices, and accept x402 payments.
