# auto-typegen

> 标签: api-response-types, automatic-types, automation, code-generation, data-to-types, developer-tools, interface-generator, json-to-typescript, mongoose-types, schema-to-types, sequelize-types, type-generator, type-safe, typescript, typescript-utility

## 简介

Automatically generate TypeScript interfaces from JSON data, API responses, or database schemas. Perfect for Mongoose, Sequelize, and raw data. Simplify your workflow and ensure type safety with just one function call!
