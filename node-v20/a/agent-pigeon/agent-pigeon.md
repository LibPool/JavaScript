# agent-pigeon

> 标签: claude-code, cli, codex, developer-tools, replay, session, verification

## 简介

See how your coding agent actually worked. Local, read-only CLI that turns Claude Code / Codex sessions into flight reports: edits, recognized verification runs, FAIL-to-PASS loops, and session comparisons.
