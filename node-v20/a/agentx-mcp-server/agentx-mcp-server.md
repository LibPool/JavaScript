# agentx-mcp-server

> 标签: agentx, ai-agents, governance, iam, mcp, model-context-protocol

## 简介

MCP server that puts any MCP-compatible AI agent under AgentX governance: permission checks, action declaration, audit trail, inter-agent messaging.
