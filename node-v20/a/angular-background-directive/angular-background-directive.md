# angular-background-directive

> 标签: JavaScript

## 简介

将图片处理成背景图片，@ng-model 为数据源,@http 是否为外部访问地址,@error 如果图片加载失败则使用默认图片,@size 为背景图片的展示方式。4个参数均为对象
