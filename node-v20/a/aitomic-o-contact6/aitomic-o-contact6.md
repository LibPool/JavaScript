# aitomic-o-contact6

> 标签: JavaScript

## 简介

A template of contact box based on element named 'm-list-thumb' (check a dependencies list). Include the template (stored in node modules folder) in module GenericList using macro `{layout '../path-to-latte-template'}`. Module add to page pattern.
