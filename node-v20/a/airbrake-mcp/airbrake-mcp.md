# airbrake-mcp

> 标签: ai-tools, airbrake, apm, errbit, error-tracking, llm-tools, mcp, mcp-server, model-context-protocol, observability

## 简介

MCP (Model Context Protocol) server exposing the Airbrake public API to LLM clients — projects, error groups, notices, deploys, v5 APM, source maps, and the v3 Notifier.
