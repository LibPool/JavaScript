# archview

> 标签: agent, architecture, archview, code-graph, code-visualization, codegraph, dashboard, llm, mcp, model-context-protocol, tree-sitter

## 简介

ArchView —— 代码架构面板：CodeGraph 的 tree-sitter 提供结构事实，LLM 只补语义摘要。单端口本地服务 + 交互式模块总览 + MCP server + agent 技能包。
