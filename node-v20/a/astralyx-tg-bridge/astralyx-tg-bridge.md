# astralyx-tg-bridge

> 标签: auth-key, gramjs, mtproto, pyrogram, session, tdata, telegram, telethon

## 简介

Convert Telegram tdata, .session files, and session strings (GramJS/Telethon/Pyrogram) into one readable JSON object — and back out to a Telethon .session or a GramJS/Telethon session string. Pure Node, zero dependencies, offline.
