# acoustic-room-mode-radar

> 标签: acoustics, audio-engineering, home-studio, mcp, model-context-protocol, podcasting, reverberation, room-modes, rt60, sound-treatment, speaker-placement

## 简介

Model Context Protocol (MCP) server for room acoustics engineering: Room modes (Axial, Tangential, Oblique), Bonello & Bolt criteria compliance, Schroeder cutoff frequency, Sabine & Norris-Eyring RT60 reverberation decay, and speaker/sweet-spot placement.
