# api2client

> 标签: axios, client, codegen, fetch, grab, hey-api, heyapi, openapi, rest, sdk, swagger, typescript

## 简介

Hey API client that sends generated OpenAPI SDK requests with grab instead of axios or fetch, adding caching, retries, rate limiting, deduplication and mocks.
