# azure_qnamaker_server

> 标签: Azure

## 简介

*A set of REST services for Azure QnAMaker APIs.These Binder APIs can be called from both Mobile and Web applications using the exposed endpoints. Dockerfile is included which would help containerize the service and also can be used seamlessly with Azure
