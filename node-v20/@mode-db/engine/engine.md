# @mode-db/engine

> 标签: JavaScript

## 简介

这是一个关于数据治理的引擎，旨在做一个能够形成数据资产图谱。他是一个超关系型数据引擎，我想使用他来建立物理关系。不在使用传统的数据库主外键关系来关联数据。但是，目前这个只是一个想法，还在实现与构思当中。
