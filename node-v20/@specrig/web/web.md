# @specrig/web

> 标签: ai-agents, bdd, contract-testing, openapi, playwright, playwright-bdd, spec-first

## 简介

A Playwright harness for a web app developed specification first: backends stood in for by their contract, and records of what the app can request and what its cases make it send.
