# @scribed/cli

> 标签: agent, cli, crm, mcp, scribed

## 简介

Command-line client + MCP server for Scribed — CRM records, phone + texting, inbox, calendar + booking, transcriptions, HR, Vault, automations, Creative Studio, and Documents, derived from the scribed-agent tool catalog.
