# @gloamtrade/mcp

> 标签: access-keys, agent-payments, ai-agents, gloam, mcp, model-context-protocol, payments, privacy, robinhood-chain, spending-limits, stablecoin, tempo, x402, zero-knowledge

## 简介

Gloam MCP server: private stablecoin payments for AI agents on Tempo and Robinhood Chain, live on mainnet (beta) with testnet for practice, under spending limits the agent cannot lift.
