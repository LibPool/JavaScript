# dsh-engramory-recall

> 标签: bm25, deepseek-harness, dsh, dsh-plugin, engramory, markdown, memory, recall

## 简介

Local BM25 auto-recall, fail-closed write guard, static doctor, account-keeping ledger and a memory panel for a local markdown memory store (Format v1) — no network, no model, no daemon, no dependencies.
