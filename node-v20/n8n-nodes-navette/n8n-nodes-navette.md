# n8n-nodes-navette

> 标签: agent, automation, browser, n8n, n8n-community-node-package, scraping, webview

## 简介

n8n community node for navette — the browser for agents. Drive the system WebView: navigate, read, screenshot, click, type, evaluate, cookie state, one-command login.
