# @fusorb/facet-docs

> 标签: component-library, docs, documentation, facet, react

## 简介

Installable, config-driven documentation site engine: component gallery with variant pages, per-variant usage tabs, install tabs, and an optional ecosystem links section. Mount <DocsApp config={...} /> with your own brand, pages, and nav.
