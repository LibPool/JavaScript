# @camille-hdl/hill-chart

> 标签: JavaScript

## 简介

Draws a minimalist, hand-drawn hill chart, as in [Shape Up, chapter 13 “Show Progress”](https://basecamp.com/shapeup/3.4-chapter-13), from a JSON list of scopes, to SVG or PNG.
