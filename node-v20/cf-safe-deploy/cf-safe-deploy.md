# cf-safe-deploy

> 标签: cf, cloud-foundry, deploy, guard, mta, predeploy, safety

## 简介

Safety net for manual Cloud Foundry MTA deployments: verifies the targeted org/space against a whitelist, enforces git branch rules for protected targets and asks for confirmation before the deploy proceeds
