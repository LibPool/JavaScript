> 标签: accessibility, admin-console, container-queries, css-custom-properties, design-tokens, react, typescript, wcag

## 简介

Host-agnostic UI foundation for React admin consoles, with a React entry, a React-free core entry, a DOM testing entry and a stylesheet.
