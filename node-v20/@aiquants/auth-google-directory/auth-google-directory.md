# @aiquants/auth-google-directory

> 标签: auth, cloud-identity, directory, google, typescript, workspace

## 简介

Google Workspace implementation of the @aiquants/auth-directory-core DirectoryProvider port: Admin SDK Directory for direct membership, Cloud Identity for nested membership, and a domain-wide delegation token provider. Read-only by construction — the inje
