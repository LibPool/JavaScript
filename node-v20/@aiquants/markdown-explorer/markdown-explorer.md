# @aiquants/markdown-explorer

> 标签: directory-tree, document-viewer, explorer, markdown, multi-panel, react, react-router, typescript

## 简介

Markdown document explorer for React Router 8 (framework mode): a source tree with a single-document view and a multi-panel reading view, storage-agnostic server ports, golden-ratio layout and an en / ja UI.
