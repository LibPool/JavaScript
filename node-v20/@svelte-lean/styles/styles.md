# @svelte-lean/styles

> 标签: cascade-layers, css, dark-mode, design-tokens, svelte, svelte-lean, svelte5, theme, ui

## 简介

Optional visual layer for Svelte Lean: design tokens and per-primitive CSS with granular entry points. No JavaScript.
