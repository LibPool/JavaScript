# @asylia/hw-trezor

> 标签: asylia, bip380, bip48, bitcoin, hardware-wallet, multisig, p2wsh, psbt, psbt-signing, self-custody, trezor, trezor-connect, typescript, xpub

## 简介

Auditable Trezor hardware-wallet TypeScript adapter for Connect initialization, environment checks, xpub export, address display, and P2WSH multisig PSBT signing.
