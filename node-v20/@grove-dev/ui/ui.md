> 标签: design-tokens, filter, format, framework-agnostic, grove, pagination, scoring, sort, ui

## 简介

Framework-agnostic UI primitives for Grove: filter, sort, paginate, score, format, and shared design tokens. V1 — typed against the discriminated IndexRecord union.
