# @tarantoj/sqs-replay-backoff

> 标签: cdk

## 简介

An [AWS CDK](https://docs.aws.amazon.com/cdk/v2/guide/home.html) construct library that replays messages back to an SQS queue with exponential backoff. Messages that repeatedly fail processing are driven through a `Queue -> ReplayQueue -> DeadLetterQueue`
