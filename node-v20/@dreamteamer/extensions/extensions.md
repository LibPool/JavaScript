# @dreamteamer/extensions

> 标签: JavaScript

## 简介

The shared core of a personal work vault as a package of dreamteamer modules — contacts, tasks, meetings, recordings, assets, perspective — installed with npm or as a git module and cherry-picked per module. No records, no personal data.
