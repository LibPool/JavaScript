# @ccatto/legal

> 标签: app-store, catto, consent, eula, legal, react, terms, typescript

## 简介

Catto Legal - app-agnostic legal-acceptance mechanism (Terms/EULA/Privacy). Pure core + server guard (React-free) + a headless React acceptance gate at ./react.
