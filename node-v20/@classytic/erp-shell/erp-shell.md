# @classytic/erp-shell

> 标签: JavaScript

## 简介

Domain-neutral ERP admin shell — multi-branch dashboard chrome (sidebar, route guard, branch context, member management, permission engine) on Arc + Better Auth + Fluid. Shared across verticals (commerce, hotel, ...).
