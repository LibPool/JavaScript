# @yatmo/sdk

> 标签: geocoding, isochrone, listing-enrichment, map, neighbourhood, poi, points-of-interest, proptech, real-estate, routing, seo, travel-time, yatmo

## 简介

Typed client for the Yatmo API: neighbourhood summaries, points of interest, travel times, isochrones, geocoding, routes and static maps for real estate websites. Zero dependency, Node 18+, browsers and edge runtimes.
