# @aikoql/client

> 标签: aikoql, knowledge-database, knowledge-graph, mcp, sdk

## 简介

Aikoql — the TypeScript SDK for the agent-first knowledge database. Node + browser-compatible core, async/await, AsyncIterable streaming, AbortSignal, pool. Zero runtime dependencies.
