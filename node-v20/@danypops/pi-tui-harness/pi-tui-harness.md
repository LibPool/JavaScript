# @danypops/pi-tui-harness

> 标签: pi, pi-tui, snapshot-testing, terminal, test-harness, testing, vt100

## 简介

Tests real @earendil-works/pi-tui Component instances without hand-rolled ANSI-stripping regexes: named-key input helpers, and a real VT state machine (@xterm/headless) for structured cell/plain-text assertions and golden-file snapshots -- Ghostty's libgh
