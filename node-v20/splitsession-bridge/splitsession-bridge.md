# splitsession-bridge

> 标签: chrome, containers, mcp, native-messaging, splitsession

## 简介

Companion program of the SplitSession (Full) Chrome extension: lets your own AI agent (Claude Code, Codex, Cursor) see and operate your Chrome tabs through a local MCP server.
