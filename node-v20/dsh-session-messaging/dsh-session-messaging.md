# dsh-session-messaging

> 标签: agent-collaboration, cordis, deepseek-harness, dsh, dsh-plugin, messaging, multi-agent, session

## 简介

Peer messaging between user-launched sessions in one workspace: discover peers, relay coordination messages, pause reception, and get advisory write-scope conflict warnings.
