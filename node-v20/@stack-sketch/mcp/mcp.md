# @stack-sketch/mcp

> 标签: architecture, claude, diagram, mcp, model-context-protocol, stacksketch

## 简介

Model Context Protocol server for StackSketch — read, create, and manage architecture diagrams from MCP clients (Claude Desktop, Claude Code, Cursor).
