# localnest-mcp

> 标签: agents, ai, ai-memory, code-assistant, code-intelligence, code-search, embeddings, knowledge-graph, local-first, localnest, mcp, memory, model-context-protocol, offline-ai, semantic-search, sqlite, temporal-graph

## 简介

The only MCP server combining semantic code search, temporal knowledge graph, and persistent AI memory. 74 tools, zero cloud, pure SQLite. Alternative to Mem0, GitNexus, Graphiti.
