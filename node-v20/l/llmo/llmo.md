# llmo

> 标签: jcs, jws, llmo, organizational-identity, rfc7515, rfc8615, rfc8785, signed-claims, well-known

## 简介

Reference CLI for the LLMO protocol. Sign and verify llmo.json documents per the v0.1 specification at https://llmo.org/spec/v0.1. Bundles the /llmo skill for guided publishing in Claude Code, OpenAI Codex, and GitHub Copilot.

## 官网

- 源码仓库：git+https://github.com/openllmo/cli.git
- npm 页面：https://www.npmjs.com/package/llmo
