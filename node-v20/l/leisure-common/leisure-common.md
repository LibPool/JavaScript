# leisure-common

> 标签: leisure, leisure-common, 京心数据

## 简介

leisure-common是京心数据在leisure-core基础上开发的一套后台管理系统基于故事的电商行业组件库，封装了大量实用的UI控件模板,方便开发者快速搭建前端应用
