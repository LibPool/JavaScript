# less-plugin-sass2less-fork

> 标签: convert sass to less, converter, less, sass, sass converter, sass to less, sass2less

## 简介

A plugin for less that converts SASS files into LESS. It comes with a cmd utility too.Support for more ScssToLess syntax.
