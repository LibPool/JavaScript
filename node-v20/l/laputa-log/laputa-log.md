# laputa-log

> 标签: JavaScript

## 简介

* 选择winston做封装 * 传送门 https://github.com/winstonjs/winston/ * 使用上希望不考虑配置，比如直接const logger = require('laputa-log') * 或者import logger from 'laputa-log' * 再或者const logger = require('laputa-log').createLogger()也可以接受 * 总之，不要在逻辑代码使用logger的时候，还去考虑logger的配置问题
