# logplex-player-react

> 标签: ads, analytics, continue-watching, hls, persian, player, react, resume, rtl, subtitles, video, vidstack

## 简介

A production React video player — Vidstack-based, HLS/MP4, fully skinned (RTL/LTR), with quality/audio/subtitle menus, pre/mid/post-roll ads, gestures, WebView-safe fullscreen, and optional built-in analytics + resume.
