# lwjgl-bridge

> 标签: bridge, game-dev, glfw, graphics, java, lwjgl, nodejs, opengl, rendering

## 简介

A Node.js bridge for LWJGL (Lightweight Java Game Library) that provides access to LWJGL JAR APIs from JavaScript.
