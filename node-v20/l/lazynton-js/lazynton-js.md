# lazynton-js

> 标签: axios, axum, e2ee, encryption, fetch, lazynton, lazyxchacha, x25519, xchacha20-poly1305

## 简介

E2EE client for lazynton (XChaCha20-Poly1305 + X25519): managed sessions, encrypted-at-rest storage, fetch/axios adapters
