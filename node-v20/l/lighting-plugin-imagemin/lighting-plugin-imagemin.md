# lighting-plugin-imagemin

> 标签: JavaScript

## 简介

> lighting-plugin-imagemin 是一款图片压缩插件，在工程打包阶段压缩 images 目录下的图片，支持 .jpg 和 .png 格式（不可与 native 插件联用）。
