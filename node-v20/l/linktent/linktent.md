# linktent

> 标签: hover, hover-intent, mouse-tracking, nextjs, performance-optimization, prediction, prefetch, preloading, react, react-router, ux-optimization, web-performance

## 简介

Predict user hover intents using mouse velocity and trajectory vectors to prefetch React links for optimized loading times.
