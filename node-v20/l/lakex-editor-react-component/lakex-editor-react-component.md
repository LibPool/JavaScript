# lakex-editor-react-component

> 标签: card, editor, lakex, mindmap, react, rich-text, yuque

## 简介

React wrapper for the lakex (语雀) document editor, shipped with a mind-map custom card and a reusable CardResizer (click-to-select + drag-to-resize + delete-on-Delete).
