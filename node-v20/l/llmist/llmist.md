# llmist

> 标签: agent, agentic, agents, ai, anthropic, chatbot, chatgpt, claude, function-calling, gadgets, gemini, generative-ai, gpt, hooks, language-model, llm, multi-provider, nodejs, openai, streaming, tool-calling, typescript, universal-client

## 简介

TypeScript LLM client with streaming tool execution. Tools fire mid-stream. Built-in function calling works with any model—no structured outputs or native tool support required.
