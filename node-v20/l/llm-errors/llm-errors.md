# llm-errors

> 标签: agents, ai, anthropic, backoff, claude, deepseek, error, errors, gemini, groq, llm, openai, openrouter, portability, provider, rate-limit, retry, retryable

## 简介

Normalize OpenAI, Anthropic and Gemini API errors into one shape: category, retryable flag and Retry-After delay. Zero dependencies.
