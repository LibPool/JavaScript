> 标签: blindspot, classroom, deterministic, knowledge-check, lingjing, mcp, model-context-protocol, no-hallucination, reasoning, teaching, 灵境

## 简介

LingJing Classroom — a deterministic (no-LLM) knowledge & blindspot MCP for AI agents: a teaching loop that returns 7-dimension blindspots and a summary. An independent gap-check layer, never hallucinates, never grades.
