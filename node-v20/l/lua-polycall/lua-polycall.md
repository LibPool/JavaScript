# lua-polycall

> 标签: libpolycall, lua, luarocks, peer-to-peer, polycall, rpc

## 简介

Lua binding for the Polycall binding ABI v1 (libpolycall >= 1.1.0): C module for PUC Lua 5.3/5.4 -- config validation, RPC calls and peer nodes
