# loading-button-react

> 标签: async, button, component, loading, loading-button, react, spinner, ui

## 简介

A composable React loading button — mix any button style with any loading animation. Zero runtime dependencies, fully themeable via CSS variables, with auto-managed async loading and success/error states.
