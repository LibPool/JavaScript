# labelproof

> 标签: barcode, ci, gs1, gs1-128, label, linter, shipping-label, thermal-printer, zebra, zpl

## 简介

Check ZPL label templates before they reach a printer. Finds barcodes that will not scan, fields that print off the edge, and labels that print differently on two printers of the same model.
