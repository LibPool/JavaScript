# looks-clean

> 标签: anomaly-detection, dart, error-handling, java, javascript, silent-failure, static-analysis, tree-sitter, typescript

## 简介

Finds places where a failure is indistinguishable from an empty result — by comparing a site with its own neighbours, not with a rulebook. JavaScript, TypeScript, Java and Dart.
