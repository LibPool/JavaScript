# local-sqs-trigger

> 标签: aws, aws-lambda, aws-sqs, development, event-source, lambda, local, local-development, localstack, message-queue, queue, simulation, sqs, sqs-trigger, testing, trigger, typescript

## 简介

Trigger AWS Lambda SQS handlers locally for development and testing. Simulate SQS events using LocalStack and let your handler code  runs unchanged and deploys to AWS as-is.
