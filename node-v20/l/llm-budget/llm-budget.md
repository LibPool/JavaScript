# llm-budget

> 标签: anthropic, budget, circuit-breaker, cost-control, llm, openai, quota, rate-limit, saas, tokens, usage-metering

## 简介

Per-user token and dollar budgets, rate limits, and a circuit breaker for LLM API calls - usage metering from OpenAI and Anthropic responses, shared-store adapters for multi-instance SaaS, Express middleware. Zero dependencies.
