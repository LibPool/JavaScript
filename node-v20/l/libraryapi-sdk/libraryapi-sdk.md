# libraryapi-sdk

> 标签: api, geocoding, imls, libraries, pls, public-library, sdk

## 简介

Official Node.js SDK for libraryapi.dev — US public library facility, hours, services, and statistics data. Install: npm i libraryapi-sdk · Import: require('libraryapi-sdk')
