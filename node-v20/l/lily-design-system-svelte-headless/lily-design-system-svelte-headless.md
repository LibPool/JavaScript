# lily-design-system-svelte-headless

> 标签: accessibility, components, design, headless, lily, svelte, system, wcag

## 简介

A comprehensive headless Svelte 5 component library with 491 accessible, unstyled components for building design systems. Targets WCAG 2.2 AAA.
