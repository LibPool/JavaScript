# limyx

> 标签: distributed, express, middleware, rate-limiter, rate-limiting, redis, sliding-window, token-bucket

## 简介

Distributed rate limiting middleware for Express, backed by Redis. Supports fixed window, sliding window log, sliding window counter, token bucket, and leaky bucket strategies.
