# lite-audio-manager

> 标签: audio, audio-manager, category, fade, game-audio, howler, howlerjs, ios-unlock, music, sfx, sound, web-audio

## 简介

Robust Howler.js audio manager with iOS unlock, category stopping, pitch variation, fade-safe teardown, and mute events.
