# lark-bridge-cli

> 标签: JavaScript

## 简介

Anti-overwrite guard for multi-agent editing of shared Feishu docs: transparent lark-cli PATH shim (fetch snapshot -> pre-write revision check -> conflict exit 42 -> self-heal).
