# leastpriv

> 标签: aws, cli, firebase, iam, least-privilege, permissions, security, static-analysis, stripe, supabase

## 简介

Static analysis tool that detects cloud, database, payment, and auth SDK calls in JavaScript and TypeScript code and maps them to the permissions they require.
