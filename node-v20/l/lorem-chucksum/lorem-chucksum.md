# lorem-chucksum

> 标签: chuck, chucksum, dummy, filler, fun, ipsum, lorem, norris, placeholder, text

## 简介

Generates passages of 'lorem ipsum'-like text based on Chuck Norris fun facts. Suitable for use as placeholder copy in web pages, graphics, and more. Works in the browser, NodeJS, and React Native.
