# llz-cli

> 标签: JavaScript

## 简介

* `inquirer`: 用户和命令行交互工具(问答环节) * `ora`: 加loading效果 * `download-git-repo`: 从github下载项目 * `ncp`: 目录copy * `metalsmith`: 模板文件流处理(填充模板)
