# lomkit-rest-client

> 标签: api, laravel-client, laravel-rest-api, nuxt, rest, sdk

## 简介

SDK for easily consuming lomkit/laravel-rest-api endpoints in Nuxt.js applications. Provides a typed, intuitive interface for handling resources.
