# llmemory-palace

> 标签: ai, ast, behavior-graph, code-analysis, code-genome, context, context-transfer, cxml, input-validation, llm, memory-palace, neural-code, pattern-library, safe-parsing, security, semantic-hash

## 简介

LLMemory-Palace: Code genome system for LLM context transfer. Maps codebases into portable format for LLM understanding. Now with MCP server and reference-based minimal context (90%+ token savings).
