# labag

> 标签: JavaScript

## 简介

LaBaG 是一款用 TypeScript 撰寫的高彈性拉霸機 (Slot Machine) 遊戲引擎，支援多種模式、自訂圖案權重與中獎組合，適合用於遊戲開發、教學或自訂玩法。
