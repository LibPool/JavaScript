# lannotebook

> 标签: basic-auth, lan, notebook, npx, share, textarea

## 简介

Shared LAN notebook: one full-page textarea served over HTTP, autosaved to a file, optional HTTP Basic auth. Thin wrapper around `lanshare note`.
