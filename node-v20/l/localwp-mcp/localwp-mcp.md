# localwp-mcp

> 标签: backup, developer-tools, localwp, logs, mcp, model-context-protocol, mysql, restore, wordpress, wp-cli

## 简介

A LocalWP-aware MCP server for WordPress developers with simple safe and full-access profiles, logs, doctor diagnostics, SQL access, backups, restore flows, MCP resources/prompts, and site-aware WP-CLI.
