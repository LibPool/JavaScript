# loopsmith-mcp

> 标签: fmod, game-audio, game-music, godot, loop, mcp, model-context-protocol, unity, unreal, wwise

## 简介

Use Loopsmith from AI apps (MCP): seamless game music loops that keep the reverb tail, Sections, and FMOD, Wwise and Unreal kits. Starts the MCP server inside your Loopsmith install (Windows; free demo available).
