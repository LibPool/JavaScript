# llm-stream-reformat

> 标签: gemini, llm, midstream, openrouter, reasoning, reformat, sse, streaming, thinking, wasm

## 简介

Inflight LLM-stream reformatting — separate a reasoning model's thinking from its answer, collapse repetition, and normalize whitespace, while the tokens are still arriving. Parses Google Vertex / OpenRouter / meta-llm SSE. Rust + WASM (built on ruvnet/mi
