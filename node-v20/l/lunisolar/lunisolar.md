# lunisolar

> 标签: lunar, lunisolar, solar, 八字, 农历, 地支, 天干, 宜忌, 阳历, 阴历

## 简介

专业农历库，支持公历阴历互转，支持各类黄历数据查询，如八字四柱、阴历、神煞宜忌、时辰吉凶、建除十二神、胎神占方、五行纳音等。支持自定义插件。
