# leat-mine

> 标签: crypto, cryptocurrencies, cryptocurrency, electroneum, etn, leatmine, miner, mining, monero, xmr

## 简介

Mine cryptocurrencies [Monero (XMR)](https://getmonero.org/) and [Electroneum (ETN)](http://electroneum.com/) using [leatMine](https://leat.io/) from node.js

- npm registry：https://registry.npmjs.org/leat-mine
- Node 要求：>=8.0
