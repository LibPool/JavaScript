# luminate-checkout-loader

> 标签: JavaScript

## 简介

This is a deployable front-end project that publishes a JS script to the Blackbaud CDN.
The end goal is to allow any webpage to be able to reference a JS file in the CDN and use it to display the bbps checkout modal by just calling the newBBPSModal method
