# logicnodes

> 标签: agent-payments, ai-agents, ap2, arbitrum, autonomous-agents, base, escrow, mcp, payments, proof-of-lock, stablecoin, usdc, x402

## 简介

Payment-lock layer for AI agents: lock funds, verify the work, then release or refund. Works keyless in test mode.
