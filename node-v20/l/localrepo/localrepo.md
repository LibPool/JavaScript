# localrepo

> 标签: clone, development, link, local, monorepo, npm, symlink, workspace

## 简介

Develop an npm dependency from a git checkout: resolve the package's repository from the registry, clone it, install inside the checkout, and symlink it into node_modules -- without touching package.json or package-lock.json.
