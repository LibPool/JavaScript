# learned-experience

> 标签: agent, claude, embeddings, experience, hooks, mcp, memory, model-context-protocol, self-improving

## 简介

Model-agnostic MCP server that gives any AI agent a persistent, self-improving catalogue of solved problems. Recall past fixes, record new ones, never learn the same thing twice.
