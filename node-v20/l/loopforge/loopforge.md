# loopforge

> 标签: ai-agent, claude-code, cognitive-stability, cognitive-state, constraint-management, durable-agent, llm, mcp

## 简介

External cognitive infrastructure for AI coding agents — breaks the summary cascade, provides independent verification, and enables model-directed prompt prioritization for 100+ round agent loops.
