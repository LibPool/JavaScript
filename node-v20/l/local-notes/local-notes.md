# local-notes

> 标签: backlinks, kanban, knowledge-graph, markdown, mindmap, monaco-editor, notes, obsidian, pdf-viewer, taskboard, vitepress, vitepress-theme

## 简介

把本地 Markdown 笔记库（vault）发布为可在线编辑的 VitePress 站点：Monaco 编辑、思维导图、任务看板、知识图谱、双链反链、PDF/附件预览。对笔记目录结构零假设。
