# leakspector

> 标签: cleanup, event-emitter, event-listener, jest, leak-detection, memory-leak, resource-tracking, test-helpers, test-utilities, testing, vitest

## 简介

A Node.js library for detecting memory leaks. Track resources at the start of each test and verify they're cleaned up at the end.
