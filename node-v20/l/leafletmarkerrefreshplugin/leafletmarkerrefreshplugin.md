# leafletmarkerrefreshplugin

> 标签: JavaScript

## 简介

传入新老数据，自动对比新老数据变化部分，从而达到只更新变化的marker，而不是全部重绘

- npm 页面：https://www.npmjs.com/package/leafletmarkerrefreshplugin
