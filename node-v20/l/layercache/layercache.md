# layercache

> 标签: backfill, cache, cache-manager, caching, circuit-breaker, disk, express, fastify, graphql, hono, invalidation, lru-cache, memory, multi-layer, nodejs, opentelemetry, redis, stale-while-revalidate, stampede, tag-invalidation, trpc, ttl, typescript

## 简介

Production-ready multi-layer caching for Node.js. Stack memory + Redis + disk behind one API with stampede prevention, tag invalidation, stale serving, and full observability.
