# louise-toolkit

> 标签: cloudflare-workers, cms, content, d1, edge, inline-editing, prosekit, solid-js

## 简介

Louise Toolkit — a V8-native toolkit for building editable sites on Cloudflare Workers. Framework-agnostic core primitives (content, db, commerce, email, queues), a SolidJS + ProseKit inline-edit client, and the daisyUI editor theme.
