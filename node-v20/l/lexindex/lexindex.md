# lexindex

> 标签: autocomplete, cache-language-model, code-completion, codemirror, completion, editor, helix, language-model, language-server, local-first, lsp, monaco, n-gram, naturalness, neovim, ngram, no-llm, offline, witten-bell, zero-dependency

## 简介

Per-repo statistical code completion for JavaScript. An n-gram index over your own repo blended with a cache over the current buffer. No model, no network, no dependencies.
