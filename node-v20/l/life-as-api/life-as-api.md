# life-as-api

> 标签: agents, api, audit, claims, consent, encryption, gdpr, personal-data, provenance, sqlite

## 简介

A personal context layer: typed, encrypted, consent-gated claim log letting authorised agents query structured facts about a person's life without exposing raw documents, crypto primitives, or the storage engine.
