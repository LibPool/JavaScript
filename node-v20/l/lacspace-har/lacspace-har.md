# lacspace-har

> 标签: cli, devtools, har, har-analyzer, har-diff, har-viewer, network, page-weight, performance, performance-budget, redact, third-party, typescript, waterfall, web-performance, web-vitals

## 简介

Read a browser .har export offline — ASCII + HTML waterfalls, diff two HARs, performance budgets (CI gate), filters, savings-quantified recommendations, HAR-derived web-vitals estimates, redaction and CSV/JSON export. Zero dependencies.
