# loading-companion

> 标签: ai, animation, css, loader, loaders, loading, mcp, progress, registry, skeleton, spinner, spinners

## 简介

A library of 2400+ loading animations as a machine-readable registry, plus an MCP server for AI agents. Import the catalog, or run the MCP.
