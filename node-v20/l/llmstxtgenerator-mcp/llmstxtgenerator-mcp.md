# llmstxtgenerator-mcp

> 标签: agentic-browsing, ai-search, generative-engine-optimization, geo, lighthouse, llms-txt, llmstxt, mcp, modelcontextprotocol, seo

## 简介

MCP stdio bridge to the llms.txt Generator - create, validate and audit llms.txt files, including Google's Lighthouse Agentic Browsing audit. Free, no API key.
