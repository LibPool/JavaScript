# lumo-cli

> 标签: cli, developer-tools, lumo, project-generator, scaffolding, template

## 简介

Launcher for the Lumo project scaffolding platform — installs the real `lumo` binary (github.com/intruder0007/Lumo) for your platform and runs it with full terminal passthrough.
