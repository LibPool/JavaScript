# leadval-mcp

> 标签: ai-agent, claude-desktop, crm, cursor, evas, identity-resolution, lead-qualification, lead-scoring, leadval, mcp, mcp-server, model-context-protocol, returning-customer, sales-automation, stdio

## 简介

MCP server for LeadVal — submit finished AI-agent conversations for scoring, poll them to a terminal state, and ask mid-conversation whether this workspace already knows the person you are speaking to. Four tools over stdio for Claude Desktop, Cursor or y
