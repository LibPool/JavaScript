# li-proxy

> 标签: JavaScript

## 简介

有时候咱们,线上地址排查问题复杂,还有项目中很多项目使用 iframe 嵌套,只有发布了才可以看到实际效果,所以为了解决这个问题,开发了当前工具

## 官网

- npm 页面：https://www.npmjs.com/package/li-proxy
