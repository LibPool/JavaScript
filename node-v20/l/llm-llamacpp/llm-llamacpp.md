# llm-llamacpp

> 标签: deepseek-harness, dsh, llama.cpp, llamacpp, llm, provider, qwen, reasoning

## 简介

A production-oriented llama.cpp LLM provider for DeepSeek Harness, with first-class Qwen reasoning support: streaming tool calls, adaptive inference policies, multi-endpoint reliability, capability-aware routing, discovery, observability, and diagnostics.
