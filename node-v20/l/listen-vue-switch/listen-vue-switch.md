# listen-vue-switch

> 标签: activate, deactivate, listen, listen vue switch, switch, vue, 切换, 失活, 激活, 监听, 监听状态切换

## 简介

listen-vue-switch 可让你在指定某类vue组件激活或失活时执行你自定义的操作
