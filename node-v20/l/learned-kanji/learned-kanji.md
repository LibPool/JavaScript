# learned-kanji

> 标签: grade, japanese, joyo-kanji, kanji, kyoiku-kanji, school, test, validation, 学年別漢字配当表, 常用漢字, 教育漢字

## 简介

Check whether Japanese text uses only the kanji taught by a given school grade in Japan (学年別漢字配当表 / 常用漢字表). Zero dependencies, fast, works in browsers.
