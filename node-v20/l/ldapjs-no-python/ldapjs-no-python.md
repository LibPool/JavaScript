# ldapjs-no-python

> 标签: JavaScript

## 简介

LDAP client and server APIs. No need Python installation. The original version uses a [bunyan] logger which requires Python installation. This version uses a [winston] logger and doesn't require any additional stuff to install

## 官网

- 官网：http://ldapjs.org
- 源码仓库：git://github.com/liamray/node-ldapjs.git
- npm 页面：https://www.npmjs.com/package/ldapjs-no-python
