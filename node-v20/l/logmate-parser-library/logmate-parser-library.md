# logmate-parser-library

> 标签: JavaScript

## 简介

* core - core classes for enabling bootstrap parsers by app * parsers - the collection of supported parsers * scripts - devops script for transport parsers from node to app project   * benchmark.js - benchmark test for ensure good parsing performance   *
