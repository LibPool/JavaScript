# lei-react-lib

> 标签: JavaScript

## 简介

这是一个react组件库，里面包含Toast组件、数字滚动NumberAnimation组件（老虎机效果）、图片懒加载LazyImage组件、Loading组件、Popup弹出层组件、Collapse折叠面板组件、数字动画组件、List组件，支持ts类型检查。
