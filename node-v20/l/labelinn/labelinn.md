# labelinn

> 标签: barcode, cloud-print, ecommerce, honeywell, label, labelinn, logistics, print-api, printer, shipping, thermal, thermal-printer, tsc, warehouse, zebra, zpl

## 简介

Official Node.js SDK for the LabelInn Cloud Print API. Send labels to Zebra, TSC, and Honeywell thermal printers from any system.
