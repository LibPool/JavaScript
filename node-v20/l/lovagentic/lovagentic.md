# lovagentic

> 标签: agent, agentic, ai-agents, automation, cli, codegen, lovable, lovable.dev, playwright

## 简介

Agentic CLI for Lovable.dev — agents in, apps out. Send prompts, verify builds, fix errors, and publish from the terminal.
