# luqi-device-detect

> 标签: device-detect, harmonyos, mobile, responsive, tablet, user-agent

## 简介

统一的前端访问设备判端（WEB / TABLET / MOBILE）：UA 特征 + 指针类型 + 视口宽度三重判定，支持平板单独识别，供各业务系统共用同一套口径
