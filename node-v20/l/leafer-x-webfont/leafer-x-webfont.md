# leafer-x-webfont

> 标签: canvas-font, chinese-font, font-subset, leafer, leaferjs, poster, webfont

## 简介

LeaferJS 字体插件 —— Text 元素自动按需加载字体子集（6 字 ≈ 6KB），让画布与导出图用上任意中文字体
