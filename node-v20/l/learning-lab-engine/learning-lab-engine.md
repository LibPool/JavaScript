# learning-lab-engine

> 标签: learning, mdx, next, nextjs, react, sandpack, shiki, textbook

## 简介

Engine for interactive textbooks on Next.js 16 + MDX: layouts, navigation, reading progress, live demos, Sandpack, code highlighting. Install, add a content/ folder — it works.
