# letter-count

> 标签: characters, count, count characters, count floats, count integers, count letters, count lines, count numbers, count spaces, count words, count wordsigns, letter, letters, lines, numbers, words, wordsigns

## 简介

This is a calculator which counts the number of letters/ characters/ lines/ words/ numbers or wordsigns in a text, useful for your tweets on Twitter, as well as a multitude of other applications.
