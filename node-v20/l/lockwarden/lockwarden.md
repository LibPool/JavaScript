# lockwarden

> 标签: audit, lockfile, malware, npm, postinstall, sarif, security, supply-chain

## 简介

Audit what your npm dependency tree can execute — lifecycle scripts, native build hooks, AI-agent hooks, IDE task files — and answer "am I hit?" during supply-chain incidents.
