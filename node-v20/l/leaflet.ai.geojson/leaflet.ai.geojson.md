# leaflet.ai.geojson

> 标签: ai, gemini, geojson, leaflet, leaflet-plugin, llm, map, openai, openrouter

## 简介

A Leaflet plugin that lets users query an LLM for geographic data and renders the returned GeoJSON on the map.
