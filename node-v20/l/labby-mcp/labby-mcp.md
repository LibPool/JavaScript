# labby-mcp

> 标签: ai-agents, automation, cli, code-mode, homelab, http-api, lab, labby, local-first, log-search, mcp, mcp-gateway, mcp-server, model-context-protocol, oauth, rust, web-ui

## 简介

Node launcher for Labby, a Rust MCP gateway with Code Mode, authentication, upstream discovery, protected routes, CLI, HTTP API, and operator web UI.
