# lettermark

> 标签: avatar, fallback, initials, lettermark, monogram, placeholder

## 简介

Turn a name into initials and a deterministic, WCAG-safe color for avatar fallbacks. Lightweight, zero-dependency, framework-agnostic and grapheme-correct via Intl.Segmenter.
