# llm-api-translator

> 标签: anthropic, api, chat-completions, claude, deepseek, llm, messages-api, openai, proxy, translator

## 简介

Translate between LLM API formats — Anthropic Messages API ↔ OpenAI Chat API. Route Claude Code, Cursor, or any Anthropic-format client through OpenAI-compatible backends like DeepSeek, Groq, Together, or any OpenAI-compatible provider.
