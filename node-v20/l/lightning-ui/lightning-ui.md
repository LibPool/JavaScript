# lightning-ui

> 标签: JavaScript

## 简介

一个基于vue3+ts的ui库，使用vite搭建，[官网地址](https://yolindeng.gitee.io/lightning-ui-website/#/) ### 安装组件 组件已通过rollup打包后，上传npm。  在vue3脚手架项目用运行： ``` npm install lightning-ui ``` 或   ``` yarn add lightning-ui ``` ### 本地运行项目 #### 1、安装依赖  `yarn ` #### 2、启动 `yarn dev` ####
