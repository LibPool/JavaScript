# localediff

> 标签: ci, cli, diff, drift, i18n, i18next, l10n, linter, locale, missing-translations, next-intl, pluralization, react-intl, translation, vue-i18n

## 简介

Find drift between i18n locale files — missing keys, CLDR-aware plural gaps, empty values. Framework-agnostic, zero dependencies.
