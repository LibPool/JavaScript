# lacspace-json

> 标签: canonical-json, canonicalize, cli, convert, csv, data, diff-patch, flatten, jq, json, json-diff, json-merge, json-patch, json-pointer, json-query, json-schema, jsonpath, minify, ndjson, pretty-print, rfc6901, rfc6902, sort-keys, stdin, toml, transform, typescript, unflatten, validate, yaml, zero-dependency

## 简介

The friendly jq — query (jq + JSONPath), convert (JSON/YAML/TOML/CSV/NDJSON), validate, diff, JSON Patch/Pointer, flatten, canonicalize and merge structured data from a file, glob or stdin. Zero dependencies.
