# lil-orm

> 标签: api-development, data-modeling, database, database-abstraction, database-mapping, flexible-orm, javascript-orm, lightweight-orm, modern-web-development, node-orm, nodejs, nodejs-database, orm, postgresql, query-builder, sql, sqlite, typescript-orm

## 简介

Lil ORM is a lightweight and flexible ORM for Node.js, designed with a clear and intuitive API to simplify database operations. Engineered for adaptability, it enables efficient interaction with databases.
