# lamdis-outcomeops

> 标签: cli, lamdis, mcp, outcome-ops, self-hosted, spec-driven-development

## 简介

Lamdis OutcomeOps CLI — one command to run Lamdis OutcomeOps locally (spec-driven outcome ops). No clone, no build: pulls prebuilt Docker images and starts everything.
