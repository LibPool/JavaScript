# lenoplot

> 标签: Node.js, Plotly, charting, lenoplot, machine learning, visualization

## 简介

Lenoplot is a Node.js charting library built on top of Plotly.js. It is designed to help Node.js developers and machine learning rookies to easily develop and visualize their work without switching between the Node.js environment
