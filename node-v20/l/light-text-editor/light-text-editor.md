# light-text-editor

> 标签: contenteditable, editor, lightweight, rich-text-editor, typescript, wysiwyg, zero-dependency

## 简介

A lightweight, zero-dependency, framework-agnostic rich text editor. Bold, italic, headings, lists, links, image insert, blockquote, and more.
