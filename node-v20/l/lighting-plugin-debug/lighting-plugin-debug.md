# lighting-plugin-debug

> 标签: JavaScript

## 简介

> lighting-plugin-debug 是一款辅助 light 工程进行开发调试的 lighting 插件，通过开启 debugServer，可以配合 Lightview 移动端调试真机设备的运行效果和报错异常。
