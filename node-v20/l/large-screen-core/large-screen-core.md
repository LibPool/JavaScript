# large-screen-core

> 标签: big-screen, dashboard, data-screen, data-visualization, large-screen, scale-to-fit, vue-plugin, vue3, 可视化大屏, 大屏组件, 大屏适配, 数据大屏, 自适应缩放

## 简介

A Vue 3 large-screen dashboard component library: scale-to-fit viewport container plus ECharts chart, panel and animated number components. | Vue 3 大屏组件库：自适应缩放容器（等比铺满、无黑边，含最小宽高保护）与 ECharts 图表/面板/数字滚动组件，专为大屏数据看板打造。
