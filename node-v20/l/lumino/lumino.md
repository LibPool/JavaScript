# lumino

> 标签: analogous, cmyk, color, colors, colour, colours, complementary, hex, hex to rgb, hex to rgba, hsl, hsl to rgb, hwb, javascript, monochromatic, ncol, rgb, rgb to hsl, rgba, rgba to rgb, split complementary, tetradic, triadic, typescript

## 简介

A simple library for handling conversion of color models (such as rgb, rgba, hex, hsl, etc) and generating different color harmonies (such as complementary, monochromatic, etc).
