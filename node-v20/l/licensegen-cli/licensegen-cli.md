# licensegen-cli

> 标签: apache, bsd, cli, generator, gpl, isc, license, mit, open-source, oss

## 简介

Generate LICENSE files for your projects from the command line. Supports MIT, Apache-2.0, GPL-3.0, BSD, ISC, MPL-2.0, and more.
