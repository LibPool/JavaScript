# lighty-errors-client

> 标签: error-reporting, error-tracking, exceptions, lightyerrors, monitoring, self-hosted, sentry, sentry-alternative

## 简介

Error reporting client for LightyErrors (lightweight, self-hosted error tracking) with a Sentry-like API: init, captureException, captureMessage, flush. Batches events, retries with backoff, flushes before the process exits. No dependencies.
