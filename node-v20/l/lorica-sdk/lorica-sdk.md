# lorica-sdk

> 标签: attest, attestation, audit, biometric, compliance, jwt, receipt

## 简介

Alias for lorica-node — the Node.js SDK for the Lorica biometric verification API. (lorica-sdk is the Python package name on PyPI; this npm alias re-exports lorica-node so both names work.)
