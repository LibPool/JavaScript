# linkpeek

> 标签: cloudflare-workers, edge-runtime, json-ld, link-metadata, link-preview, link-unfurling, metadata, metadata-parser, nodejs, oembed, og-parser, open-graph, open-graph-parser, opengraph, preview-card, ssrf, twitter-card, typescript, unfurl, url-metadata, url-preview, web-metadata

## 简介

Fast, safe TypeScript link preview library and URL metadata extractor for Open Graph, Twitter Cards, and JSON-LD on Node.js, Bun, Deno, and edge runtimes.
