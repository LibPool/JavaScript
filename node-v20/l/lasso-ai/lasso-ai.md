# lasso-ai

> 标签: ai, api, data-extraction, lasso, pdf-extraction, product-enrichment, product-extraction, sdk, structured-data, web-search

## 简介

Official TypeScript SDK for the Lasso API — AI-powered product data extraction, enrichment, and web search. Extract structured data from PDFs, URLs, and text. Enrich products with AI-generated descriptions, pricing, and specs.
