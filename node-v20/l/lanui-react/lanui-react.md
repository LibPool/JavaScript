# lanui-react

> 标签: lanui, lanui-react

## 简介

蓝UI，lanui-react是依赖与React快速开发 Web 应用程序的前端工具包。它使用了React Hooks技术，给你的 Web开发提供了时尚的版式，表单，buttons，表格，网格系统等等，目前不支持React 16.8以下版本的环境，持续更新中。。。
