# langchain-pi-ts

> 标签: adapter, chat-model, langchain, llm, pi, pi-ai

## 简介

LangChain BaseChatModel adapter for @earendil-works/pi-ai — use Pi with any provider, model and auth. Includes a native opencode/Zen chat model (no pi).
