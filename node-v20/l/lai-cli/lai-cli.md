# lai-cli

> 标签: ai, claude-code, cli, codex, coding-agent, launcher, llm, ollama, opencode, openrouter

## 简介

Launch AI coding tools (Claude Code, Codex, OpenCode, ...) against any model provider - OpenRouter, Ollama, or your own plugin.
