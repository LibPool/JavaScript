# logisheets-web

> 标签: browser, excel, formula, ooxml, rust, spreadsheet, spreadsheet-engine, wasm, webassembly, xlsx

## 简介

Browser SDK for LogiSheets — a Rust + WebAssembly spreadsheet engine that reads, edits, and writes real .xlsx (Excel) files (formulas, styles, and structure preserved) entirely in the browser.
