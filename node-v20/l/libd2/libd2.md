# libd2

> 标签: diablo2, drlg, map, procgen, seed

## 简介

Clean-room Diablo II 1.14d engine core as WebAssembly. Give it a seed and it produces the same world the game does: rooms, objects, monsters, level adjacency and subtile collision. Runs in Node, Bun, Deno and the browser.
