# language-translation-api

> 标签: Puppeteer, google, google-translate, js, library, translation

## 简介

Designed to effortlessly translate languages by leveraging the power of Google Translate. Utilizing Puppeteer, this package crawls the Google Translate web page, providing accurate and reliable translations.
