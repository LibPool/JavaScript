# lan-direct

> 标签: agent-skills, claude-code, codex, mcp, playwright, proxy, socket-binding, split-tunneling, vpn

## 简介

Skill + browser MCP for coding agents behind a full-tunnel VPN: the app under test reaches domestic services over the real ISP while the agent stays on the tunnel.
