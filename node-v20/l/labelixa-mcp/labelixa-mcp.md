# labelixa-mcp

> 标签: ai, barcode, cpcl, epl, label, label-printing, mcp, mcp-server, model-context-protocol, printing, thermal-printer, tspl, zebra, zpl

## 简介

Thermal label MCP server (local stdio): render, validate, debug and convert ZPL, EPL, TSPL and CPCL labels via the Labelixa API. Full tool set on the hosted server https://api.labelixa.com/mcp.
