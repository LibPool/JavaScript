# lily-design-system-html-headless

> 标签: JavaScript

## 简介

Lily Design System HTML headless components: 491 annotated semantic-HTML snippet files with ARIA and class hooks — copy them, template them, or read them via the tiny node helper. Zero CSS, zero dependencies. Targets WCAG 2.2 AAA.
