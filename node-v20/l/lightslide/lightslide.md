# lightslide

> 标签: a11y, accessibility, accessible, analytics, carousel, lightweight, loop, marquee, react, responsive, slider, swipe, swiper, ticker, wai-aria

## 简介

Lightweight, accessible-by-default React carousel & slider: WAI-ARIA semantics out of the box, infinite loop, center align, lazy mounting, and zero-CLS SSR in a ~6 kB core — navigation, pagination, autoplay, flow (ticker), wheel, free scrolling, adaptive
