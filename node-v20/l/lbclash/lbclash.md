# lbclash

> 标签: JavaScript

## 简介

lb clash 配置管理工具 ## 安装 ```shell npm i lbclash -g ``` ## 使用 ```shell # 初始化 lbclash init # 强制初始化 lbclash init -f ``` 按照提示初始化配置，然后在 clash 选择生成好的配置文件(lb-clash.yaml)即可。
