# llm-dock

> 标签: anthropic, claude, cli, deepseek, gateway, llm, openai, proxy

## 简介

Local model-name gateway: map any custom alias to any OpenAI-compatible model, so Claude Desktop / Claude Code / OpenAI clients can use DeepSeek, OpenRouter, local servers, etc.
