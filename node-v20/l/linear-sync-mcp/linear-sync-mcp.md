# linear-sync-mcp

> 标签: JavaScript

## 简介

MCP server that connects Claude and AI coding agents to Linear issue tracking. Sync code changes to issues, auto-update status, create linked issues from code comments, and orchestrate multi-agent workflows across Linear projects. Built with AI by Craftpi
