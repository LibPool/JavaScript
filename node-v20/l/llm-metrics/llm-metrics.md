> 标签: agent-metrics, ai-metrics, ai-sdk, anthropic, framework-agnostic, latency, llm, llm-metrics, metrics, monitoring, observability, openai, performance, request-timing, telemetry, tool-metrics

## 简介

Metrics collection system for LLMs and AI agents. Tracks performance, latency, and usage metrics for agents, tools, and LLM requests.
