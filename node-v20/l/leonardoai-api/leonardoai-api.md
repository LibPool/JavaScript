# leonardoai-api

> 标签: AI, api, generation, images, leonardo, leonardo.ai, midjourney, private-api, prompt

## 简介

This module is a Node.js wrapper for the Leonardo AI API. It provides an easy-to-use interface for generating images with the Leonardo AI platform.
