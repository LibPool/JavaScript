# linguin-api

> 标签: api, definitions, dictionary, i18n, language, linguin, localization, multilingual, reverse-dictionary, translation

## 简介

Official JavaScript client for the Linguin API: multilingual dictionary lookups, reverse dictionary, translation and UI localization.
