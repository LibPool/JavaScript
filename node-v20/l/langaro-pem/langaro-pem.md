# langaro-pem

> 标签: JavaScript

## 简介

Fork of pem that does not trim leading/trailing spaces from certificate passwords (needed for ICP-Brasil certificates). Create private keys and certificates with node.js and io.js

- 官网：https://github.com/fernandolangaro/pem-fork#readme
