# local-organizer

> 标签: JavaScript

## 简介

A simple local web dashboard for managing AI‑generated tasks and docs. - Simple task format that maps cleanly from AI‑generated tasks. - Built‑in prompt templates to generate and update docs with your AI coding tool. - Keeps all data in your repo.
