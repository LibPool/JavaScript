# local-deepwiki

> 标签: agent-skill, ast, claude-code, deepwiki, documentation, tree-sitter, wiki

## 简介

AST-powered deepwiki for your codebase, written by your own coding agent and browsed in your terminal. No LLM API calls — a skill, a scanner, and a TUI.
