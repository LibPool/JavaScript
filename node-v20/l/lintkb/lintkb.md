# lintkb

> 标签: agent, ai, claude, cursor, developer-experience, eslint, knowledge-base, lint, typescript

## 简介

AI-agnostic ESLint wrapper that enriches lint findings with concrete AI instructions pointing to a project-local Markdown knowledge base.
