# local-llmup

> 标签: cli, gpu, hardware-advisor, hardware-aware, llm, local-ai, ollama, tokens-per-second

## 简介

Hardware-aware CLI that scores your machine and tells you which local LLMs will run (yes/slow/no + tok/s) before recommending, installing, serving, and migrating them.
