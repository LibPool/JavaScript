# lt-public-transport-sdk

> 标签: bus, gps, gtfs, kaunas, klaipeda, lithuania, public-transport, real-time, sdk, stops-lt, transport-api, trolleybus, vilnius

## 简介

TypeScript SDK for real-time public transport data in Lithuanian cities. Provides vehicle GPS positions, GTFS routes, and stops from stops.lt.
