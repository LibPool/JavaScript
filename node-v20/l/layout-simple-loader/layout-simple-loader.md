# layout-simple-loader

> 标签: css, gulp, layout-simple, web

## 简介

layout-simple-loader是一个webpack loader，layout-simple是为web前端响应式布局而生的CSS布局框架，基于LESS开发，可实现灵活配置、自动生成符合需求的布局框架、自动LESS变量、可用于PC、Mobile或响应式布局等web开发。
