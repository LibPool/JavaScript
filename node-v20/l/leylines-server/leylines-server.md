# leylines-server

> 标签: leylinesjs, www.leylines.ch

## 简介

NodeJS server for leylines, consisting of a CORS proxy, proj4 CRS lookup service, ogr2ogr conversion service, and express static server.

- 官网：https://github.com/leylines/leylines-server
