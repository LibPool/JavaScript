# libzaungast

> 标签: indexeddb, leveldb, microsoft-teams, offline, read-only

## 简介

Read-only, offline reader for the local Microsoft Teams cache (Chromium IndexedDB-on-LevelDB): decodes it into clean, structured, query-able data — conversations, messages, people, events, calls. No Graph API, no cloud, no credentials. Not affiliated with
