# localstore-ts

> 标签: localstorage, sessionstorage, typed localstorage, typed sessionstorage, typed webstorage, typescript, webstorage, webstorage-api

## 简介

A typesafe api that supercharges local and session storage with database like capabilities. Inspired by [drizzle](https://orm.drizzle.team/).
