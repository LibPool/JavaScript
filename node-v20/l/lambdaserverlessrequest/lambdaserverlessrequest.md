# lambdaserverlessrequest

> 标签: amazon, api, api gateway, async, aws, axios, gateway, lambda, promise, request, server, serverless

## 简介

LambdaServerlessRequest provides an easy way to make requests to a Lambda serverless function instead of having to use API Gateway, with major interface inspiration from axios.
