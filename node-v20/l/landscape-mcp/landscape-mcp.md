# landscape-mcp

> 标签: ai-agents, catalog, landscape, mcp, memory, model-context-protocol

## 简介

Local-stdio MCP server exposing the AI agent infrastructure landscape catalog (912 records × 85 columns + 528 typed edges). Read-only query interface over data/landscape.json + data/landscape.edges.json.
