# lzh-browser-bridge

> 标签: agent, browser-automation, cdp, chrome, chrome-debugger, mcp, model-context-protocol

## 简介

Extension-held CDP bridge: an MV3 extension attaches chrome.debugger so agents never hit Chrome's allow-debugging prompt. MCP stdio server included (TypeScript, cross-platform, needs Node >= 22.6).
