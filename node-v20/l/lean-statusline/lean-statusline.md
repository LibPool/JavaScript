# lean-statusline

> 标签: claude, claude-code, cli, p10k, prompt, statusline

## 简介

statusline for claude code — minimal/compact/full presets, p10k-style configure wizard, inline pace ETA + urgency explainer, subagent renderer, auto-update on render, node-only, zero deps.
