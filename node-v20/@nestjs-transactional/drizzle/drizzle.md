# @nestjs-transactional/drizzle

> 标签: drizzle, drizzle-orm, nestjs, savepoint, transaction, transactional

## 简介

Drizzle ORM adapter for @nestjs-transactional/core: the db you inject joins the transaction, with savepoints and multiple databases
