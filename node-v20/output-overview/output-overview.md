# output-overview

> 标签: adoption, cordis, cost, deepseek, deepseek-harness, dsh, dsh-plugin, output, stats

## 简介

DSH 产出总览插件：统计 DSH 生成的代码行数、文档数、采纳率与成本，Web 面板展示。Output statistics for DeepSeek Harness: generated code lines, docs, adoption rates, and cost.
