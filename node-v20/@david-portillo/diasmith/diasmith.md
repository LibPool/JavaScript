# @david-portillo/diasmith

> 标签: library, utils

## 简介

diasmith helps you check and clean user text. It understands Unicode and accents, builds the right regexes for you, and lets you allow only certain languages or scripts—so you can safely accept multilingual text without writing tricky rules by hand.
