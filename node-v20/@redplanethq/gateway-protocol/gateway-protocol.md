# @redplanethq/gateway-protocol

> 标签: JavaScript

## 简介

Wire-level types and routes for the **CoreBrain Gateway** — the local process that runs on a user's machine (or a Docker host) and exposes their browser, coding agents, and shell to the CORE webapp over HTTP + WebSocket.
