# @liuli-util/mdbook-sdk

> 标签: JavaScript

## 简介

一个生成 epub 的 lib，提供低级的 API 生成 epub 文件。如果需要从 markdown 生成 epub，请使用 [@liuli-util/mdbook](https://www.npmjs.com/package/@liuli-util/mdbook)。
