> 标签: aviation, bearing, distance, expo, geo, geofence, geospatial, great-circle, haversine, nautical-mile, navigation, polygon, react-native, typescript, vincenty

## 简介

Lightweight, dependency-free geospatial math for React Native, Expo, web and Node — great-circle bearing/distance/destination, nautical-mile conversion, geo shape polygons, and path resampling.
