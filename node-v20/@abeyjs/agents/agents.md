# @abeyjs/agents

> 标签: JavaScript

## 简介

Agents package the **orthogonal logic** AbeyJs hangs next to flows: same `OmegaChannel` everyone listens to, but routing is **rule-first** instead of a long switchboard of manual subscriptions.
