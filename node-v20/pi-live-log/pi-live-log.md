# pi-live-log

> 标签: build, live-log, pi, pi-coding-agent, pi-extension, pi-package, watchdog, wsl

## 简介

Pi extension: live log tail inside running shell tool rows, plus a stall/max-runtime watchdog that stops hung builds and summarizes why.
