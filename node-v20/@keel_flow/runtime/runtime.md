# @keel_flow/runtime

> 标签: JavaScript

## 简介

Agent execution layer: pluggable `ModelProvider` abstraction (`createProvider`, supports `anthropic` and `openai-compatible` kinds covering OpenAI, DeepSeek, Kimi, Together, Groq, Ollama), multi-turn tool-calling loop (`runAgent`), spec compliance checker
