# @dgeable/dsh-web-search-tavily

> 标签: deepseek-harness, dsh, plugin, search-provider, tavily, web-search

## 简介

Tavily-backed WebSearchProvider plugin for the DeepSeek Harness (DSH) web capability seam (ctx.web). Fixes web_search "Insufficient Balance" by routing searches through Tavily.
