# @webpieces/openapi-import

> 标签: client, codegen, openapi, typescript, webpieces

## 简介

Generate a webpieces EXTERNAL_OUTBOUND contract (an @ApiPath class plus its DTO classes and string enums) from a vendor's OpenAPI 3.0/3.1 JSON document and a per-vendor import file. Node builtins only. Ships the wp-openapi-import bin.
