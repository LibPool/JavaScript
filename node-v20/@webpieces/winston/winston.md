# @webpieces/winston

> 标签: cloud-run, gcp, logging, webpieces, winston

## 简介

Node-only winston LoggerFactory backends for webpieces: Console (local pretty) + GCP (Cloud Run stdout JSON), auto-enriched with HeaderRegistry context keys
