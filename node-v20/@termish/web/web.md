# @termish/web

> 标签: herdr, mosh, remote, sftp, ssh, terminal, termish, tmux, web-terminal, xterm

## 简介

Termish Web — the browser window into your herdr agents: web terminal, SFTP and agent console, no client install. Part of the Termish family — also try the Termish mobile app (Android · iOS · Desktop) at https://termish.dev
