# @flux-gate/http

> 标签: express, fastify, hono, middleware, nextjs, prometheus, rate-limiter, rate-limiting

## 简介

Rate limiting for any HTTP stack: a framework-agnostic check(), adapters for Express, Fastify, Hono and the Fetch API (Next.js, Bun, Deno, Cloudflare Workers), and Prometheus metrics. No runtime dependencies besides @flux-gate/core.
