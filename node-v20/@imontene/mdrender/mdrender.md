# @imontene/mdrender

> 标签: cli, converter, html, inter, katex, latex, manrope, markdown, mermaid, pdf

## 简介

Command-line app for Windows and Linux that renders Markdown — with LaTeX equations and Mermaid diagrams — to PDF and HTML set in Manrope or Inter
