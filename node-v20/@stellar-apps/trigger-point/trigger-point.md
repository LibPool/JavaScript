# @stellar-apps/trigger-point

> 标签: JavaScript

## 简介

A component for triggering events when an element enters or exits the viewport. This component requires a top-level [ViewportProvider](https://github.com/jaredLunde/render-props/tree/master/packages/viewport#viewportprovider).
