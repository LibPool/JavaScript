# @openuidev/cli

> 标签: ai, chatbot, cli, code-generator, generative-ui, llm, nextjs, openui, react, scaffolding, system-prompt

## 简介

CLI for OpenUI — scaffold generative UI chat apps, mint Gateway API keys, and generate LLM system prompts from component libraries, and deploy projects
