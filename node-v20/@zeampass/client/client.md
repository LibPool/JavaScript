## 简介

The ZEAM :: Pass client puts a wallet in front of a paid MCP server or URL. Over MCP it pays x402 per call, or line time on a ZEAM :: Bridge seller, and, with a session escrow pinned, an MPP session. Over HTTP its paid_fetch tool pays a 402 as an x402 exa
