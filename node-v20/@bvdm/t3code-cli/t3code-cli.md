# @bvdm/t3code-cli

> 标签: agents, cli, codex, handover, orchestrator-v2, t3-code, threads

## 简介

Manage T3 Code projects, handover threads, and cross-thread messages. Requires a T3 Code build with orchestrator V2; for older T3 builds, install @bvdm/t3code-cli@0.2.
