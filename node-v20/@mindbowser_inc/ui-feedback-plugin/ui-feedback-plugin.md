# @mindbowser_inc/ui-feedback-plugin

> 标签: annotation, aws, comments, feedback, firebase, prototype, s3, screenshot, supabase, ui

## 简介

A floating widget for collecting annotated UI feedback on web prototypes — Figma-style comments, screenshots, reply threads, Firebase/Supabase/AWS support
