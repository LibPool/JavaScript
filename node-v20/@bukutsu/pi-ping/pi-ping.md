> 标签: alert, completion, decset-1004, desktop-notification, desktop-notifications, focus, focus-aware, ghostty, iterm2, kitty, minimal, notification, notifications, notify, osc-777, osc-9, osc-99, pi-coding-agent, pi-extension, pi-package, ping, run-completion, tab-marker, tab-title, terminal-focus, terminal-notification, tmux, unfocused, warp, wezterm, window-title

## 简介

Minimal, focus-aware desktop notifications for the Pi coding agent. Alerts for finished runs in an unfocused terminal, customizable messages, and unread tab markers. Unknown focus falls back to alerts.
