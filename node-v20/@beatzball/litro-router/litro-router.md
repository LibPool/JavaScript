# @beatzball/litro-router

> 标签: client-side-routing, custom-elements, elena, fast-element, history-api, lit, lit-element, router, spa, typescript, urlpattern, web-components, zero-dependencies

## 简介

Framework-agnostic client-side router for web components — works with Lit, FAST, Elena, or plain custom elements. Built on the native URLPattern API. Zero dependencies. Works standalone or as part of the Litro framework.
