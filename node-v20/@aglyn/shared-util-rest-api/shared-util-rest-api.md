# @aglyn/shared-util-rest-api

> 标签: JavaScript

## 简介

Helpers for writing JSON API routes in Next.js: one response envelope for both the Pages Router (`NextApiResponse`) and the App Router (Web `Response`), plus small middleware and cookie utilities. Published mainly as a building block for Aglyn's own apps;
