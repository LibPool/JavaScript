# @velocut/scene-sdk

> 标签: JavaScript

## 简介

Declarative editable 3D scenes: SceneSpec validation, pure scene edits, parametric assemblies, shared native geometry and instances, object-local anchors, CPU spatial queries, Three.js staging, GLB import, camera sampling, deterministic physics and frame
