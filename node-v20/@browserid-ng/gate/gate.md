# @browserid-ng/gate

> 标签: agent, browserid, gateway, mcp, oauth, proxy, stdio, warrant

## 简介

Publish stdio MCP servers as remote, BrowserID-gated HTTP endpoints. One command runs the gateway + web console (npx @browserid-ng/gate --admin you@example.com): add servers by name + mount + command, grant access with roles — per person, per server, per
