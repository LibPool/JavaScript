# @vacationrentalprotocol/vrp-verify

> 标签: ed25519, eddsa, jwks, jws, signed-offer, vacation-rental-protocol, verifier, vrp, zero-dependency

## 简介

Zero-dependency reference verifier for VRP (Vacation Rental Protocol) signed verified-stay offers: pure Ed25519 (EdDSA) verification of a host-domain signed offer against the host's own JWKS.
