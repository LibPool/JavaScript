# futures-calendar

> 标签: cme, cme-group, contract-symbol, expiration, finance, front-month, futures, last-trade-date, month-codes, roll-date, trading-calendar

## 简介

CME Group futures calendar — month codes, contract-symbol parsing (ESZ5, CLF26), last-trade dates from each exchange's termination rule for ES, NQ, CL, NG, GC, ZN, 6E, ZC, BTC and more, plus front-month and roll dates.
