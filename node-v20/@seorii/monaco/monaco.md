# @seorii/monaco

> 标签: JavaScript

## 简介

Svelte 5 wrappers for Monaco Editor and Monaco Diff Editor with model loading, LSP, TextMate grammars, Yjs collaboration, configurable language providers, markers, snippets, and decorations.
