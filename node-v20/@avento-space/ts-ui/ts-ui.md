# @avento-space/ts-ui

> 标签: JavaScript

## 简介

Librería de componentes UI agnóstica con arquitectura headless. Proporciona una capa **Foundation** (algoritmos puros sin DOM), **Controllers** compartidos, **Web Components** nativos y wrappers específicos por framework.
