# @velnai/chat-rn

> 标签: chat, expo, live-chat, mobile, react-native, support, velnai, webview, widget

## 简介

Drop the Velnai web-chat widget into any React Native app. WebView wrapper using the widget's headless ?embedded=1 mode.
