# @nextlyhq/plugin-mcp

> 标签: agents, ai, cms, headless-cms, mcp, model-context-protocol, nextly, nextly-plugin, plugin

## 简介

Experimental: serves a Model Context Protocol endpoint for AI agents, off by default and authenticated like every other Nextly route. Read-only, and the one tool it exposes reports what the connecting credential may read
