# @rinci/secrets

> 标签: 1password, aws-secrets-manager, azure-key-vault, bitwarden, bun, cli, doppler, dotenv, env, gcp-secret-manager, infisical, parameter-store, secrets, sops, vault

## 简介

One entry point for every secrets manager. Fetch from Infisical, Doppler, Vault, AWS, GCP, Azure, 1Password, Bitwarden, SOPS or any CLI and run any command with them injected.
