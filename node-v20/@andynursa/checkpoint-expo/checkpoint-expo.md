# @andynursa/checkpoint-expo

> 标签: background-location, checkpoint, expo, expo-config-plugin, geofence, location, react-native

## 简介

Checkpoint location / geofence / ingest SDK for Expo (SDK 51+). A config plugin that wires the iOS/Android background-location config plus a thin re-export of @andynursa/checkpoint-react-native — the JS API is identical. The SDK is a sensor; all detection
