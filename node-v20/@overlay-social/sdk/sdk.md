# @overlay-social/sdk

> 标签: brc-100, bsv, identity, metanet, overlay, peck, social

## 简介

Minimal read-only client for overlay.peck.to — identity resolution, profiles, feed and overlay state over the canonical BSV/BRC-100 social overlay.
