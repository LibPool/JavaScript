# @wanderwares/medusa-plugin-hub

> 标签: medusa, medusa-plugin, medusa-v2, plugin-hub, plugin-manager, wanderwares

## 简介

Medusa v2 plugin — lifecycle manager for the Wanderwares plugin ecosystem. Discover, install, verify, and manage Wanderwares plugins from the Medusa Admin.
