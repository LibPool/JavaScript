# @trashcodermaker/pi-pr-review-handler

> 标签: agentskills, code-review, github, pi-package, pi-skill, pr-review

## 简介

Systematically process GitHub PR review comments: triage for validity, fix code, and post replies. Pi package — install with `pi install npm:@trashcodermaker/pi-pr-review-handler`.
