# @fodx/codelens

> 标签: claude-code, code-graph, code-index, code-search, codex, cursor, gemini-cli, kiro, mcp, mcp-server, modelcontextprotocol, opencode, pi-package, tree-sitter

## 简介

Local, branch-aware code search & relation graph. SQLite FTS5 + tree-sitter symbols + source-graph edges, exposed as an MCP server and CLI. No chat LLM required.
