# @humans-md/cli

> 标签: agents, antigravity, claude-code, cline, codex, copilot, cursor, devin, hooks, humans-md, junie, opencode, profile

## 简介

Check your own HUMANS.md, print it for an agent's session-start hook, or copy it for clients without hooks. Plugins for Claude Code, Codex, Cursor, Copilot CLI, Antigravity, OpenCode, Devin and Junie need no hook setup. Draft format.
