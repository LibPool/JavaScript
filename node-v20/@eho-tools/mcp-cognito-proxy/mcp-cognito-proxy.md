# @eho-tools/mcp-cognito-proxy

> 标签: aws, claude, client-credentials, cognito, mcp, model-context-protocol, oauth2, proxy, stdio

## 简介

Local stdio proxy that connects MCP clients (Claude Desktop, Claude Code, Cursor, ...) to a remote Streamable HTTP MCP server protected by AWS Cognito, using either a machine identity (client_credentials) or a user login.
