# @precedence-dev/sdk

> 标签: JavaScript

## 简介

The client half of Precedence: installPrecedence collects, buffers, batches and delivers the events @precedence-dev/instrument bakes in, with an optional live plan overlay. Framework-agnostic, zero dependencies.
