# @rantir/connect

> 标签: browser, cdn, database, flows, jsdelivr, no-code, rantir, sdk, umd

## 简介

Tiny client SDK for Rantir tables and flows. Zero runtime dependencies. Works in browsers (ESM, UMD/IIFE for <script> tags) and Node/edge runtimes (CJS).
