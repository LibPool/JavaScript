# @klent/mcp-server

> 标签: agents, ai, guardrails, klent, llm, mcp, model-context-protocol, policy

## 简介

Model Context Protocol (MCP) server for Klent — let any MCP-aware client (Claude Desktop, Cursor, etc.) gate tool calls through Klent's policy engine.
