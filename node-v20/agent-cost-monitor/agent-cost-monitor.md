# agent-cost-monitor

> 标签: burn-rate, claude-code, codex, cost, deepseek, dsh, statusline, tokens

## 简介

Live cost and burn-rate tracking for AI coding agents: a Claude Code status line, and a floating window for Codex and DSH that have no status row of their own.
