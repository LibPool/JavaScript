# @jipika/dsh-think-ux

> 标签: client-plugin, deepseek-harness, dsh, dsh-plugin, scroll, ux, web

## 简介

Smooth think-row preview + bottom-follow glide for the DeepSeek Harness (dsh) Web UI: a pure DOM client plugin, no bundle changes. Local build: every open think body is line-capped and scrolls internally.
