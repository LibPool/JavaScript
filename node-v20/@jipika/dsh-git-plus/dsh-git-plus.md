# @jipika/dsh-git-plus

> 标签: JavaScript

## 简介

会话「Git」面板：双栏仓库操作控制台（GitHub Desktop / Fork 形态）—— 左栏分支+提交时间轴（可搜索），右栏工作区改动（stage/commit/diff）或 commit 详情（内联 diff）与真实作者头像。支持多仓库工作区（cwd 自身不是仓库、子目录才是仓库时按仓库切换）。
