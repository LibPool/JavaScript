# @qii404/ztree_v3

> 标签: html, jquery, node, plug-in, plugin, tree, ztree

## 简介

zTree is a multi-functional 'tree plug-ins.' based on jQuery. The main advantages of zTree includes excellent performance, flexible configuration, and the combination of multiple functions. Forked from ztree_v3, modified for ardm, you may not need it.
