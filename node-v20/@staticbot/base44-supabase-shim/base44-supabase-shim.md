# @staticbot/base44-supabase-shim

> 标签: JavaScript

## 简介

Drop-in shim mimicking @base44/sdk API but routing to a Supabase backend. Vendored into migrated apps by Staticbot's Base44 native migration so the customer's build doesn't need a live npm connection.
