# @kolkrabbi/design-editor

> 标签: compositor, design-editor, generative, kol, kolkrabbi

## 简介

The Kolkrabbi design editor as one embeddable React component — a DOM/SVG vector + generative compositor (canvas, layers, palette/pattern/type generators, kinetic type, boolean geometry, image export). Consumes the @kolkrabbi/kol-* design system as peers.
