# @alotop/dsh-notify-hub

> 标签: 5g-message, bark, cmcc, cordis, deepseek-harness, dsh, dsh-plugin, feishu, notification, webhook, wecom

## 简介

通知集合（Notification Hub）：DSH Host 端通知中枢，整合 Bark 推送、多路 Webhook（飞书自定义关键词与签名校验 / 企微 / 钉钉 / Slack / Discord / 自定义）、原生桌面通知，并新增「移动新消息」5G 消息推送通道。设置页通过专用 RPC 读写 Host 配置，全部密钥脱敏不回传浏览器。
