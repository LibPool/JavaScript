# @nvoo/auth

> 标签: JavaScript

## 简介

Nvoo — 后端无关的权限体系：AuthProvider 适配器 + 归一化权限引擎 + v-permission 指令（支持 Keycloak / 若伊 Sa-Token / 无权限）
