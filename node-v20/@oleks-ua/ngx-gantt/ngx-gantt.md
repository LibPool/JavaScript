# @oleks-ua/ngx-gantt

> 标签: angular, canvas, critical-path, evm, gantt, gantt-chart, project-management, resource-leveling, scheduling, timeline

## 简介

Enterprise Gantt chart library for Angular — canvas-rendered timeline, pure scheduling engine (CPM, resource leveling, EVM), Signals-based state, command bus with interceptors, and a headless engine entrypoint for Node.
