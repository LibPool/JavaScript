# @splicetree/plugin-pointer

> 标签: JavaScript

## 简介

采集节点点击事件，统一派发 `input:node-click` 语义事件，供行为插件消费（如 `@splicetree/plugin-selectable`、`@splicetree/plugin-checkable`）。
