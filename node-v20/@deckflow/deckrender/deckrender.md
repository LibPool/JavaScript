# @deckflow/deckrender

> 标签: cli, deckflow, document-conversion, docx, keynote, pdf, pptx, render, screenshot, thumbnail

## 简介

Render PPTX, PDF, DOCX, Keynote, HTML and Markdown into images, PDF or video. One command, predictable output.
