# @thomas-siegfried/jsi.jasmine

> 标签: JavaScript

## 简介

jsi.jasmine is an extension to the jsi library designed to facilitate unit testing with Jasmine and jsi. This utility exposes an AutoMocker, which can create mock objects for all dependencies, and also allows easy configuration of Mock objects using Jasmi
