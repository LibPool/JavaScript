# @wxy0715/uploader

> 标签: chunked-upload, element-plus, file-upload, sha256, upload, vue, vue3, 分片上传, 断点续传, 秒传

## 简介

基于 Vue 3 + Element Plus 的文件上传插件，缩略图列表 UI，支持分片上传、SHA256 秒传、断点续传、上传进度显示
