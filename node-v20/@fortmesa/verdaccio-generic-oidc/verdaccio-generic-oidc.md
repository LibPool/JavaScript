# @fortmesa/verdaccio-generic-oidc

> 标签: npm-registry, oauth2, oidc, openid-connect, sso, verdaccio, verdaccio-plugin

## 简介

Generic OpenID Connect authentication plugin for Verdaccio, with configurable groups/roles mapping and pluggable session storage (Redis, filesystem, or DynamoDB). Fork of verdaccio-openid-connect.
