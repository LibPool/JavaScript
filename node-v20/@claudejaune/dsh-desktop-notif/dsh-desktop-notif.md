# @claudejaune/dsh-desktop-notif

> 标签: JavaScript

## 简介

Browser desktop notifications for DeepSeek Harness web: hidden-tab toasts when a session finishes or asks for an interaction, with a session-header bell toggle persisted in localStorage.
