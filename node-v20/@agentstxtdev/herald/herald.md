# @agentstxtdev/herald

> 标签: agentic-web, agents-json, agents-txt, ai-crawler, cli, herald, llms-txt, robots-txt, security-txt, sitemap

## 简介

The agent-capabilities discovery layer for the agentic web. Emit robots.txt, llms.txt, agents.txt, agents.json, sitemap.xml, security.txt from one config.
