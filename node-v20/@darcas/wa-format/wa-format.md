# @darcas/wa-format

> 标签: chat, converter, format, formatter, html, markdown, mcp, parser, typescript, wa, whatsapp

## 简介

Convert WhatsApp formatted text into HTML and back. Supports bold, italic, strikethrough, inline code, code blocks, block quotes and lists. Works in Node.js and the browser, and exposes an MCP server.
