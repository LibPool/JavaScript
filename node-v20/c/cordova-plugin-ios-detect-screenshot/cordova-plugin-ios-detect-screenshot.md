# cordova-plugin-ios-detect-screenshot

> 标签: confide, cordova, cordova-ios, ecosystem:cordova, privacy, screenshieldkit, screenshot

## 简介

Simple cordova plugin for iOS that adds ability to detect when a screenshot is taken via a JavaScript event listener.
