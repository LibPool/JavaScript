# chat-arg-parser

> 标签: arg, argument, bot, chat, cmd, command, commands, discord, double, escape, escaping, game, gaming, parse, parser, prefix, quotation, quotations, quote, single

## 简介

Parses commands with a specified prefix, delimited by spaces, with support for double & single quotations, and no need for escaping.
