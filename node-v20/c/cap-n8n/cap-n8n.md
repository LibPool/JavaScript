# cap-n8n

> 标签: automation, cap, cds, n8n, sap, workflow

## 简介

CDS plugin mapping CAP onto n8n: programmatic Workflow API, @n8n.trigger annotations via the transactional outbox, and a typed `cds import --from n8n`.
