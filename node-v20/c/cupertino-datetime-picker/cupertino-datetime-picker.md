# cupertino-datetime-picker

> 标签: base-ui, cupertino, date-picker, datetime-picker, ios, react, shadcn, tailwind, time-picker, wheel-picker

## 简介

iOS-style compact date & time picker for React: an inline calendar with month/year wheels, and time wheels that also take typing. Built for shadcn/ui on Base UI.
