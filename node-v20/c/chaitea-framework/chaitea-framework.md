# chaitea-framework

> 标签: JavaScript

## 简介

Chai Tea is a back-end framework for nodejs, working over ExpressJS using MVC structure. Auto compiles JADE, STYLUS, COFFEESCRIPT and ES6 to clientside, no need to pre-compiling.
