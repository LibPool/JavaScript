# card-gate-frame

> 标签: creative-coding, decorative-borders, deterministic, frame, generative-art, javascript, ornament, procedural-generation, svg, svg-frame, svg-generator, typescript, zero-dependencies

## 简介

Generate ornamental SVG frames and decorative borders for HTML cards. French ironwork styles, seeded generation, TypeScript, zero runtime dependencies.
