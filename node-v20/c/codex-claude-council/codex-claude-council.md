# codex-claude-council

> 标签: chatgpt, claude, claude-code, codex, llm-council, mcp, plugin, second-opinion

## 简介

Ask OpenAI Codex (ChatGPT) and Claude the same question through your own signed-in CLIs; they answer independently, then reply to each other until they agree on one answer. MCP server + plugin for Claude Code, Claude Cowork and Codex.
