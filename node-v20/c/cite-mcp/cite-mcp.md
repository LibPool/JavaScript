# cite-mcp

> 标签: academic-papers, citation, crossref, mcp, model-context-protocol, openalex, paper-search, semantic-scholar

## 简介

MCP Server for academic paper research — 6 tools across Semantic Scholar, OpenAlex, and Crossref. Paper search, detail, recommendations, analysis, citation formatting, and auto-citation with S2-first progressive search. API keys via MCP env, ~/.cite-mcp.e
