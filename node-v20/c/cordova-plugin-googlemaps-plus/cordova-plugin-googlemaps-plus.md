# cordova-plugin-googlemaps-plus

> 标签: cordova-android, cordova-ios, ecosystem:cordova, geo, google, google maps, maps, nightstomp

## 简介

A forked version of Google Maps native SDK for Android and iOS with Play Services framework on + instead of 10+ for compatibillity with push plugins
