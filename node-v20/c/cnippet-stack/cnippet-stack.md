# cnippet-stack

> 标签: better-auth, cli, cnippet, installer, integrations, nextjs, prisma, scaffold

## 简介

CLI that installs full integrations (auth, payments, email, storage) into your existing Next.js app — detection, prompts, safe file injection, env setup.
