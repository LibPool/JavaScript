# claws-agent

> 标签: agent, ai, claws, cloud, deploy, ed25519, http-message-signatures, mcp, ucan

## 简介

Autonomous-agent CLI + TypeScript SDK for claws.software. Self-registers an Ed25519 identity, mints UCANs, signs RFC 9421 HTTP requests, and calls the MCP server. Designed to be invoked by LLM-driven agents (Hermes, Claude Code, Cursor) following an opera
