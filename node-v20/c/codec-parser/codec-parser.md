# codec-parser

> 标签: aac, aacp, flac, mp3, mpeg, ogg, ogg-flac, ogg-opus, ogg-vorbis, opus, vorbis

## 简介

Library that parses raw data from audio codecs into frames containing data, header values, duration, and other information.
