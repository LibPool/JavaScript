# contextrot

> 标签: agents, claude-code, cli, context-engineering, context-rot, developer-tools, llm, opencode

## 简介

Find out where your coding agent starts degrading. Personal context-rot analytics from your own agent sessions. (npm wrapper around the Python CLI — always runs the latest PyPI release via uv.)
