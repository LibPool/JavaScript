# connect-vault

> 标签: connect, sessionstore, vault

## 简介

This a session store library that uses the Vault ([HashiCorp](https://www.hashicorp.com)) key/value store. Requires [vault](https://www.vaultproject.io/downloads.html)>=1.1.0.
