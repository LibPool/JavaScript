# claude-account-sync

> 标签: accounts, claude, claude-code, cli, keychain, mcp, multi-account, profiles, sync

## 简介

Manage multiple Claude Code accounts/profiles — MCP drift sync, keychain secrets, and encrypted LAN replication between machines. CLI: ccprofiles (alias clp).
