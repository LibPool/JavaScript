# contentful-server-lib

> 标签: contentful, library, node, typescript

## 简介

A server-side TypeScript library for fetching, transforming, and serving Contentful content in Next.js applications. It abstracts the Contentful Delivery and Preview APIs behind a layered architecture: raw API access → ETL transformation → page-level asse
