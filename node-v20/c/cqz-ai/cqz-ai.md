# cqz-ai

> 标签: code-quality, offline-ai, onnx, playwright, test-automation

## 简介

Offline AI layer for Code Quality Zone — a ~104 MB local classifier that judges the fuzzy half of test quality (fragile selectors, test scope, assertion strength). No API key, no network at run time.
