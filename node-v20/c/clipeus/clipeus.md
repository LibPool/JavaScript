# clipeus

> 标签: ai-codegen, audit, cli, devsecops, gitleaks, owasp, sast, scanner, security, semgrep, static-analysis, vibe-coding, vulnerability

## 简介

Free, open-source security and vulnerability auditing CLI. Its scan command is read-only and adds custom detection for gaps common in AI-assisted development.
