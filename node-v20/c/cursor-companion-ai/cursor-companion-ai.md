# cursor-companion-ai

> 标签: ai, anthropic, assistant, claude, companion, cursor, guide, nextjs, onboarding, react, walkthrough

## 简介

AI cursor companion that reads any web page and guides users by pointing at exact elements. Works in React, Next.js, Vite, plain HTML — drop in via npm import or one-line <script> tag, BYOK direct from browser.
