# checkbox-mcp-server

> 标签: ai-agent, automation, checkbox, claude, compliance, cursor, mcp, model-context-protocol

## 简介

MCP server for the Checkbox capability API — lets AI assistants (Claude, Cursor, etc.) manage compliance plans, tasks, documents, and more through the Model Context Protocol.
