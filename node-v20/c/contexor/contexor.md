# contexor

> 标签: agent, ai, assistant, chatbot, context, sdk, widget

## 简介

Contexor  is a lightweight, plug-and-play AI assistant widget that can be embedded into any website—regardless of the tech stack—to provide users with instant, context-aware answers. Website owners simply add a script or npm package, enter their own AI AP
