# cscec-login-mcp

> 标签: cscec, login, mcp, qrcode, wecom, workbuddy

## 简介

Pure-Node.js MCP server for CSCEC (中建三局) WeCom QR-code login. Zero dependencies, zero Python: `npx -y cscec-login-mcp`.
