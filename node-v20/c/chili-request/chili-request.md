# chili-request

> 标签: JavaScript

## 简介

`chili-request` 使用 axois 来发送 http 请求，但尝试解决了 axios 里使用存在的几个缺陷: - axios 的 get/post 请求传参方式不一致 - axios 没有明确的针对于每一个接口的响应数据拦截器
