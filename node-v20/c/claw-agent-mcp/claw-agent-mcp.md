# claw-agent-mcp

> 标签: agent, claude, filesystem, mcp, model-context-protocol, tools

## 简介

MCP server providing filesystem tools (PowerShell, Edit, Glob, Grep, Read, Write) plus cd/pwd, all scoped to a ~/.agentmcp sandbox
