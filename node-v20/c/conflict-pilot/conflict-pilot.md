# conflict-pilot

> 标签: cli, conflict, conflict-resolution, developer-tools, diff3, git, merge, merge-conflict, mergetool, neovim, rebase, resolve, vscode, zdiff3

## 简介

Detects merge conflicts, explains what each one actually is, and resolves them once you approve. Zero dependencies, works from any code editor.
