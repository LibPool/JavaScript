# com.phantoms.actionnotificationmanager

> 标签: artoolkit, assetbundles, build, bundle, bundles, cache, server

## 简介

The action notification manager is a function in the ARMOD framework, which is used to provide messages and Actions execution in all modules. Corresponding modules will not depend on each other, only need to issue the corresponding Action-ID to execute.
