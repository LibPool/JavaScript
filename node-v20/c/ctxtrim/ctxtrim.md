# ctxtrim

> 标签: ai-coding, aiexclude, claude, claude-code, codex, context, cost, cursor, cursorignore, developer-tools, llm, token-count, tokens

## 简介

Trim what bloats your AI coding context. Scan a repo, find the high-cost/low-value files ballooning your Claude Code / Cursor / Codex context, and write ignore files to cut token cost. Zero dependencies.
