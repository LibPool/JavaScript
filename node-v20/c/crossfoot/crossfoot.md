# crossfoot

> 标签: accounts-payable, anthropic, claude, document-ai, extraction, invoice, llm, parsing, pdf

## 简介

Read invoices from PDF with an LLM that never writes a value: the model points at printed text, code reads it, and the document's own totals prove the read.
