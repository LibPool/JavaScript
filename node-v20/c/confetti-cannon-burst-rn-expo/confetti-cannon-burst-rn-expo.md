# confetti-cannon-burst-rn-expo

> 标签: animation, burst, cannon, celebration, confetti, expo, native-driver, particles, react-native, react-native-svg

## 简介

A physics-based confetti burst animation for React Native and Expo. Particles launch from the bottom corners like party poppers, follow a gravity arc, and run entirely on the native thread via useNativeDriver.
