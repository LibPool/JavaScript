# codedeep-mcp

> 标签: ai-agents, ast, code-analysis, code-intelligence, cognitive-complexity, cyclomatic-complexity, developer-tools, mcp, model-context-protocol, tree-sitter

## 简介

MCP server that gives AI coding agents structural understanding of a codebase — symbols, references, blast radius, cyclomatic/cognitive complexity, and behavioral-git signals across 14 languages (tree-sitter).
