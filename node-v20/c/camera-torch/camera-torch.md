# camera-torch

> 标签: applyconstraints, camera, exposure, flashlight, focus, getusermedia, mediastreamtrack, qr-scanner, react-hooks, torch, webrtc, zoom

## 简介

Torch, zoom, focus and exposure control for a live web camera stream. No Cordova, no Capacitor - just the browser's own MediaStreamTrack API, done right.
