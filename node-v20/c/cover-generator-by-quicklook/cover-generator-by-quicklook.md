# cover-generator-by-quicklook

> 标签: CB7, CBR, CBZ, Cover, PDF, Thumb, doc, jpg

## 简介

Mac OS X only! Extracts the first view (cover) of an document (PDF, iWork documents, Microsoft Office documents, epub, CBr, CBZ, C7...) in different sizes
