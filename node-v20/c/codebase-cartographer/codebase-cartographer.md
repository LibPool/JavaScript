# codebase-cartographer

> 标签: agents, ai, claude, codebase, context, cursor, developer-tools, llm, map

## 简介

Generate a living MAP.md of any codebase — module tree, dependency graph, churn hotspots — designed for AI coding agents. Deterministic skeleton by CLI, semantic descriptions by your agent.
