# common-qa-mcp

> 标签: ai-agent, mcp, model-context-protocol, qa, simplifyqa, test-automation, test-cases, testing, walnut

## 简介

Common QA MCP — one product-neutral MCP that routes test-case lifecycle requests to Walnut or SimplifyQA for any AI client. Launch over stdio via npx; install the Walnut QA agent with `init-agents`.
