> 标签: ai-agents, android, bug-reporting, coding-agent, crash-reporting, crumbtrail, debugging, developer-tools, expo, ios, mobile, observability, react-native, session-replay

## 简介

React Native and Expo SDK for Crumbtrail: capture errors, network, navigation and a view-tree snapshot around a bug. See https://crumbtrail.ai
