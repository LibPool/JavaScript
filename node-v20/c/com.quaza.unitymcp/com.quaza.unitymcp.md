# com.quaza.unitymcp

> 标签: Model Context Protocol, Unity AI Tool, Unity MCP, ai

## 简介

Integration between Model Context Protocol (MCP) and Unity, allowing AI assistants to understand and interact with Unity projects in real-time. Provides access to scene hierarchy, project settings, and code execution in the Unity Editor.
