# cordova-plugin-baidupush

> 标签: BaiduYun, Push, cordova-android, cordova-ios, ecosystem:cordova

## 简介

This plugin binds appId, userId, channelId of BaiduYun Push.
    It also accepts messages pushed by BaiduYun.
