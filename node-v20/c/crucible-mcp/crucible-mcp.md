# crucible-mcp

> 标签: ai-agents, claude-code, crucible, game-development, game-writing, linter, mcp, model-context-protocol, pixel-art

## 简介

MCP server and CLI that grade AI-agent game content against named craft knowledge: dialogue and UI text (Track B) and pixel-art sprites (Track A).
