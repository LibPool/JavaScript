# clearcheck-mcp

> 标签: agent, claude, fmcsa, government-data, mcp, model-context-protocol, public-records, usdc, x402

## 简介

MCP server for ClearCheck: one-call verdicts over authoritative US public records. Pay-per-call in USDC over x402, or run free and see the prices.
