# cockroach-browser

> 标签: accessibility-tree, agent-browser, ai-agent, appium, browser-automation, browser-evidence, browser-runtime, cockroach-crawler, firefox, maqam, mcp, playwright, puppeteer, qarinah, webdriver-bidi, webkit

## 简介

Open-source local-first Chromium, Firefox, WebKit, Playwright, and Puppeteer automation for AI agents with semantic page snapshots, model-directed execution, MCP, SDKs, and verifiable evidence.
