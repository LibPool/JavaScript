# carrel-cli

> 标签: agents, artifacts, carrel, cli, criticmarkup, desk, markdown

## 简介

Command-line client for a hosted Carrel desk — publish and read artifacts (markdown + HTML), run the comment loop, all over the hosted HTTP API.
