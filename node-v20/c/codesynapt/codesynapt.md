# codesynapt

> 标签: 3d, ai-coding-agent, blast-radius, code-visualization, dependency-graph, developer-tools, electron, mcp, three.js

## 简介

The MCP dependency map that shows AI agents what breaks before they edit — no wrong edges, unseen code flagged as candidates. Offline, far fewer tokens. MCP server + CLI (Claude Code/Cursor), optional 3D view.
