# capacitor-firebase-upload-file

> 标签: capacitor, native, plugin

## 简介

Capacitor Firebase Upload File use the Firebase Storage Native, With the plugin you can upload any type of formats, especially for MP4 for Videos and PNG/JPG for Images also compress the file.
