# cf-access-mock

> 标签: cf-authorization, cloudflare, cloudflare-access, jwks, jwt, local-development, mock, offline, warp, zero-trust

## 简介

Local mock of Cloudflare Access for offline development: serves a JWKS at /cdn-cgi/access/certs and mints RS256 CF_Authorization JWTs. No WARP, no internet, no real Cloudflare needed.
