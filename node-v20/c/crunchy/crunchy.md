# crunchy

> 标签: anime, crunchyroll, download

## 简介

Crunchy is a fork of Crunchyroll.js, capable of downloading anime episodes from the popular CrunchyRoll streaming service.

## 官网

- 官网：https://github.com/Godzil/crunchyroll.js#readme
- 源码仓库：git://github.com/Godzil/crunchyroll.js.git
- npm 页面：https://www.npmjs.com/package/crunchy
