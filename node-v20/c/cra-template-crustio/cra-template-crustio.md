# cra-template-crustio

> 标签: Create-react-app, Kilt, Polkadot, Substrate, cra, react, template

## 简介

The base Typescript template for Crust front end that can fetch an file off Crust IPFS and can then pin on Crust Maxwell (make sure to have sufficient CRU).
