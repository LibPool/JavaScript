# cordova-plugin-hot-updates

> 标签: app, cordova, cordova-android, cordova-ios, cross-platform, ecosystem:cordova, hot, manual, mobile, ota, over-the-air, reload, updates, webview

## 简介

Frontend-controlled manual hot updates for Cordova iOS and Android apps using WebView Reload approach. Manual updates only, JavaScript controls all decisions. 100% API compatibility between platforms.
