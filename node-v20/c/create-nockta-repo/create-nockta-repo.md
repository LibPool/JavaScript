# create-nockta-repo

> 标签: ai, cli, create, create-app, monorepo, nest, next, nockta, scaffolder, skills, starter, vite

## 简介

Creates new repositories or project targets by running official framework scaffolders, applying Nockta architecture overlays, and invoking inject-nockta-skills to render AI-tool adapter outputs.
