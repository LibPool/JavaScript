# create-redbelly-dapp

> 标签: JavaScript

## 简介

Scaffold an identity-gated dApp for Redbelly Network: Foundry contracts on the Gated base, a Next.js + wagmi web app, CI, rules files for coding agents, npm run dev for the local loop, doctor, gas and ship, and a deploy script that refuses chain 151 witho
