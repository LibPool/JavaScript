# clone-voice

> 标签: ai-voice, audioworklet, browser-tts, onnx, pocket-tts, speech-synthesis, text-to-speech, tts, voice-clone, voice-cloning, web-worker

## 简介

Browser & Node voice cloning SDK powered by Pocket TTS / ONNX Runtime. Clone any voice from a short audio clip and generate speech — entirely client-side.
