# comark-codemirror

> 标签: autocomplete, code-editor, codemirror, comark, editor, lezer, markdown, mdc

## 简介

A Comark code editor for CodeMirror 6 where you can autocomplete everything: components, props, values, slots, bindings and all plugin syntax, in chained menus.
