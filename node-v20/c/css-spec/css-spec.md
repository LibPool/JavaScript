# css-spec

> 标签: claude-code, css, design-spec, design-tokens, dev-tools, inspector, nextjs, overlay

## 简介

Dev-only CSS inspector overlay for Next.js App Router — DevTools-style hover inspection for your local dev environment, live design-token editing, and precise prompts for AI coding tools (Claude Code, Cursor).
