# cordova-contact-number-picker

> 标签: android, contact, cordova, cordova-android, cordova-ios, ecosystem:cordova, ios, number, phone, picker

## 简介

Cordova plugin for native contact number picker on Android and iOS. The picker shows only name and phone numbers.
