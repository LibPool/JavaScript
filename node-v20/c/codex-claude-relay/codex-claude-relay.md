# codex-claude-relay

> 标签: ai-agents, claude, claude-code, cli, codex, context, handoff, relay

## 简介

Stateless context handoff between OpenAI Codex CLI and Anthropic Claude Code. Reads native session transcripts, condenses them, and launches the other agent with the handoff as its initial prompt.
