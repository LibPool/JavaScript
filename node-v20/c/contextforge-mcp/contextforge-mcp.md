> 标签: ai, ai-agent-memory, claude, claude-code, context, copilot, cursor, knowledge-management, mcp, mcp-server, memory, model-context-protocol, persistent-memory

## 简介

Persistent memory MCP server for Claude Code, Cursor, and GitHub Copilot. Give your AI assistants long-term memory via the Model Context Protocol.
