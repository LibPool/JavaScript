# carwhere-vin-mcp

> 标签: anthropic, automotive, car-pricing, claude, mcp, model-context-protocol, nhtsa, openai, vehicle-recalls, vin, vin-decoder

## 简介

MCP server for the CarWhere VIN API. Decode any VIN, look up verified buyer prices, NHTSA safety recalls, and AI-generated vehicle insights from inside Claude Desktop, Cursor, Claude Code, Windsurf, and any other MCP-compatible client.
