# cordova-plugin-camdh-audioinput

> 标签: AudioNode, android, audio, cordova, cordova plugin, cordova-android, cordova-ios, ecosystem:cordova, ecosystem:phonegap, input, ios, mic, microphone, phonegap, source, waapi, web audio, web audio api, web-audio-api

## 简介

This cordova plugin enables audio capture from the device microphone, by in (near) real-time forwarding raw audio data to the web layer of your application.
