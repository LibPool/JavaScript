# checktss

> 标签: JavaScript

## 简介

Модуль для npm, позволяющий проверить решение задачи с Tss из любой ide (и даже из обычной командной строки).

## 官网

- npm 页面：https://www.npmjs.com/package/checktss

## 历史版本号

- 当前版本：1.2.0

- 1.2.0

## 获取地址

- npm 安装：`npm install checktss`
- npm registry：https://registry.npmjs.org/checktss
- Node 要求：>=14
