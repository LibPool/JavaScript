# coda-builder

> 标签: JavaScript

## 简介

`Coda-Builder` 是一个专为 TypeScript 多平台打造的现代化 Webpack 封装与标准化构建工具。旨在以极低的配置开销，统一管理和输出多平台项目（Node CLI、Node Server、VS Code 扩展、Chrome 扩展、Web等）
