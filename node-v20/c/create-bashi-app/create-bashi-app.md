# create-bashi-app

> 标签: ai-agents, ai-development, anthropic, bashi, claude, claude-code, developer-tools, low-code, mcp, orchestration, skills

## 简介

Set up Bashi in any project. 600+ skills across 26 domains via Cortex MCP. Standalone: 12 agents, 37 skills, 20 commands, 11 hooks. Light (--light): MCP-connected, skills load on-demand.
