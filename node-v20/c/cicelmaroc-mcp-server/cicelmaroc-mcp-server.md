# cicelmaroc-mcp-server

> 标签: ai-tools, claude, cursor, electronic-signature, loi-43-20, mcp, model-context-protocol, morocco, watiqa

## 简介

MCP server for Cicel Maroc / Watiqa — Moroccan electronic signature platform. Lets Claude, Cursor, and other AI assistants create documents, track signatures, and manage webhooks via the Watiqa API.
