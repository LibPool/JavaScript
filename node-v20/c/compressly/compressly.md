# compressly

> 标签: browser, client-side, compress-image, exif, image-compression, image-resize, image-upload, jpeg, nextjs, offscreen-canvas, react, resize-image, typescript, upload, web-worker, webp

## 简介

Compress and resize images in the browser before upload: target file size, max width, WebP/JPEG, EXIF rotation, batch + Web Worker. Zero deps, ~2.2 KB.
