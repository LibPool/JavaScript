# community-cordova-plugin-apple-ads-attribution

> 标签: adservices, apple-ads, apple-search-ads, attribution, campaign, cordova-ios, ecosystem:cordova

## 简介

Apple Ads (Search Ads) install attribution for Cordova iOS apps through the AdServices framework. No App Tracking Transparency prompt needed.
