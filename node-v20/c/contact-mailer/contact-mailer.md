# contact-mailer

> 标签: appointment-form, attachments, career-form, contact, contact-email, contact-form, contact-mail, contact-us, email, email-sender, enquiry-form, gmail, gmail-smtp, html-email, job-application, mailer, nextjs, nodejs, nodemailer, rate-limit, smtp, smtp-mailer, typescript

## 简介

Lightweight SMTP email library for Node.js, Next.js and TypeScript with HTML email templates, attachments, CC/BCC and built-in optional IP rate limiting.
