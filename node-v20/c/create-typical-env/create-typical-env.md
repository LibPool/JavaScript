> 标签: CSS AOS library, boxicons, cli, clsx, cn, react, react-bits, react-router, setup, tailwind, tailwind-merge, template, vite

## 简介

CLI to quickly set up a Typical Env. Features & technologies included: React, Vite, React Router, React Router DOM, Tailwind CSS, clsx, twmerge, cn, CSS AOS library, Boxions, Shadcn, and React Bits.
