# clipper-flash

> 标签: agent, claude-code, clips, codex, installer, shorts, youtube

## 简介

One-command installer for Clipper-Flash: turn YouTube livestreams into Shorts with your AI coding agent (Claude Code / Codex). Sets up everything: Python, FFmpeg, the cf toolkit, and the agent skill.
