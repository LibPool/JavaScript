# cloudscope

> 标签: amazon, aws, azure, cdn, cidr, cloud, cloud-provider, cloudflare, datacenter, digitalocean, exoscale, gcp, geolocation, google, hosting, ibm, ip, ip-address, ip-ranges, linode, lookup, microsoft, network, oracle, saas, subnet, vultr, whois

## 简介

A Node.js library to detect whether an IP address belongs to cloud, CDN, hosting, or SaaS/company ranges. Fetches and normalizes CIDR ranges, then lets you check IPv4 and IPv6 addresses efficiently.
