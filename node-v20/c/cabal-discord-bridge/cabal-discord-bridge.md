# cabal-discord-bridge

> 标签: JavaScript

## 简介

You can use this tool, to automatically send messages from Cabal to Discord and vice-versa.

## 官网

- npm 页面：https://www.npmjs.com/package/cabal-discord-bridge

## 历史版本号

- 当前版本：1.0.1

- 1.0.1

## 获取地址

- npm 安装：`npm install cabal-discord-bridge`
- npm registry：https://registry.npmjs.org/cabal-discord-bridge
- Node 要求：>=16.6
