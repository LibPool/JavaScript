# create-pepu-app

> 标签: create-pepu-app, pepe-unchained, pepu, scaffold, starter

## 简介

Scaffold a PEPU devkit starter template — consumer app, token-gated app, NFT mint, game, gas-sponsored demo, or sponsored session app — for Pepe Unchained V2.
