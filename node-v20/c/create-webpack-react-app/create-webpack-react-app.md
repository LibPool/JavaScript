# create-webpack-react-app

> 标签: babel, boilerplate, react, reactjs, webpack

## 简介

A command line to to initiate a boilerplate for a react application using webpack and babel.
To run the CLI, install the CLI globally by running 
$ npm i -g create-webpack-react-app 
and go to the directory where you want the root directory of your projec
