# claw-llm-router

> 标签: ai, classifier, llm, openclaw, openclaw-plugin, router

## 简介

OpenClaw plugin that cuts LLM costs 40-80% by routing prompts to the cheapest capable model. 15-dimension classifier, super fast local routing, automatic fallback chain.
