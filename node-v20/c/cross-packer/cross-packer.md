# cross-packer

> 标签: cross-platform, deb, electron, nsis, packaging

## 简介

Cross-platform Electron app packager — assemble Windows (NSIS), macOS (.app/.zip) and Linux (.deb) artifacts on any host OS, without electron-builder.
