# codex-camel

> 标签: JavaScript

## 简介

`codex-cli-camel` is a Codex CLI fork with integrated **CaMeL prompt-injection defense methodology**. This implementation is based on Google DeepMind's CaMeL work and adapted to Codex CLI runtime boundaries.
