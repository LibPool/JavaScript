# cgpa-calculator

> 标签: academic, cgpa, college-gpa, cumulative-gpa, education, gpa, gpa-calculator, grade-point-average, grades, semester-gpa, sgpa, student, university

## 简介

A lightweight JavaScript library for calculating GPA (Grade Point Average), CGPA (Cumulative GPA), and SGPA (Semester GPA). Supports 4.0, 5.0, and percentage grading scales.
