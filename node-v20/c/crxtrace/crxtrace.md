# crxtrace

> 标签: browser-extension, chrome-extension, content-script, crash-reporting, error-tracking, manifest-v3, mv3, observability, service-worker

## 简介

MV3-aware error tracking for Chrome extensions. Service worker lifecycle, content script errors by host, and release health.
