# create-deepseek-harness-plugin

> 标签: cordis, create-deepseek-harness-plugin, deepseek, deepseek-harness, dsh, plugin, scaffold

## 简介

Scaffold a DeepSeek Harness (DSH) plugin — basic / tool / service / app / events / webui templates, version pinning aligned to your installed dsh, and a --verify that actually boots the plugin.
