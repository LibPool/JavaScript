# chiltepin-core

> 标签: adr, api-documentation, architecture, ast, chiltepin, cross-references, developer-tools, diagrams-as-code, docs-as-code, documentation, documentation-as-code, markdown, parser, schema, system-design, technical-writing, typed-blocks, validation, yaml, zod

## 简介

Core engine for Chiltepin documentation-as-code: Markdown parser, Zod schemas for a rich family of typed YAML blocks (API docs, architecture & system design, data models, ADRs, planning, charts), strict validation, and `doc#id` cross-reference resolution.
