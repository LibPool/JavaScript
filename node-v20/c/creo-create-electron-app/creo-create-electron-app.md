# creo-create-electron-app

> 标签: JavaScript

## 简介

CLI scaffolding tool for [Creo](../../README.md) + [Electron](https://www.electronjs.org) cross-platform desktop apps. Creates a ready-to-run Electron application with Creo as the UI framework.
