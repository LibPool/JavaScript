# chronofast

> 标签: browser, calendar, date, date-math, datetime, dst, esm, format, i18n, iana, immutable, intl, iso8601, lightweight, locale, parse, performance, plaindate, temporal, time, timestamp, timezone, tree-shakable, typescript, tz, utc, zero-dependencies

## 简介

Fast, immutable date and time library with real IANA time zones and no tzdb bundled. Parsing, formatting, calendar math and Intl locale output. Fully typed, zero dependencies, ~8 kB gzipped.
