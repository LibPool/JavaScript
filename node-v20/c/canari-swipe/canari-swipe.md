# canari-swipe

> 标签: canari, carousel, gesture, horizontal, react, react-carousel, react-slider, slider, swipe, swipeable, swiper, touch, vertical

## 简介

Lightweight React swipe and carousel component with touch/mouse, fit-N slides, elastic/carousel ends, and programmatic goTo/next/prev — no heavy dependencies
