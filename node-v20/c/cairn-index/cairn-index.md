# cairn-index

> 标签: code-search, fts5, hybrid-search, knowledge-graph, local-first, mcp, rag, sqlite, sqlite-vec, tree-sitter, vector-search

## 简介

Local hybrid index (FTS5 + vector embeddings + AST graph) over a single sqlite file. Curate, ingest, retrieve.
