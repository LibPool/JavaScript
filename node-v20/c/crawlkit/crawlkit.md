# crawlkit

> 标签: a11y, accessibility, ajax, audit, axe, axs, crawl, crawler, crawlkit, htmlcs, phantom, scraping, webkit

## 简介

A crawler based on Phantom. Allows discovery of dynamic content and supports custom scrapers.
