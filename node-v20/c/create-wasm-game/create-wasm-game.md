# create-wasm-game

> 标签: create, emscripten, game, scaffold, wasm, webassembly

## 简介

Scaffold a WASM Game Framework game site: wasm-game.json, native adapter, exact @wasm-game-framework/browser pin, Docker image, and package-contract tests. Does not emit index.html, launcher CSS, a service worker, or a web manifest.
