# coreenmo-cors-middleware

> 标签: coreenmo, cors-middleware, package-manager, tea

## 简介

coreenmo (CORS Middleware) - Middleware for handling cross-origin resource sharing (CORS) policies within application servers, allowing cross-domain access for HTTP requests.
