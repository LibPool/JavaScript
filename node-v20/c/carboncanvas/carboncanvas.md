# carboncanvas

> 标签: canvas, comments, design-review, inspector, prototype, react

## 简介

Carbon Canvas — a JSX spatial review canvas + click-to-inspect Inspector, with a design-system adapter seam. The free, open client for the Carbon Canvas comments/realtime backend.
