# create-obsidian-react-app

> 标签: cli, create, dataview, obsidian, obsidian-vault, react, scaffold

## 简介

Scaffold an Obsidian vault that embeds a React 19 + TypeScript SPA, rendered inside a note by the Dataview community plugin.
