# create-valence

> 标签: claude-code, code-push, flutter, hybrid-app, offline-first, ota, sqlite, sveltekit, webview

## 简介

Keep the native core, swap the web shell: your web app as a Flutter app's interface, with signed UI releases that roll back on their own, offline-first SQLite and a typed bridge. One command sets it up.
