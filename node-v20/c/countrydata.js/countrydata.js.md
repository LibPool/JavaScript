# countrydata.js

> 标签: address, capital, cities, city, cli, country, country-data, country-picker, csv, currency, distance, geo, geolocation, i18n, iso3166, javascript, localization, location, offline, population, search, sql, state, states, timezone, typescript, validation

## 简介

Offline JavaScript/TypeScript library for country, state, and city data — 250 countries, 4,963 states, 148k+ cities, with fuzzy search, geo distance, validation, i18n names, and a CSV/SQL export CLI.
