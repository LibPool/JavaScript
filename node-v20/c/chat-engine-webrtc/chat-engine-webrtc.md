# chat-engine-webrtc

> 标签: JavaScript

## 简介

Adds the ability to do WebRTC audio/video with ChatEngine using `direct` events for [signaling](https://developer.mozilla.org/en-US/docs/Web/API/WebRTC_API/Signaling_and_video_calling)
