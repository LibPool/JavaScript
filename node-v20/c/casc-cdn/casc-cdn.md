# casc-cdn

> 标签: blizzard, casc, warcraft

## 简介

A modern and minimal TypeScript library for downloading and extracting files from Blizzard's CASC (Content Addressable Storage Container) archives via CDN.

- 官网：https://github.com/BogdanTretyakov/casc-cdn
