# cizgile

> 标签: esm, iri, percent-encoding, rfc3986, rfc3987, slug, slugify, transliterate, typescript, unicode, uri, url, zero-dependency

## 简介

RFC 3986/3987-grounded URL slugs. Transliteration, Unicode slugs, IRI to URI, percent-encoding, dot-segment removal. Zero dependencies, tree-shakeable.
