# cronforclaude-runner

> 标签: anthropic, claude, claude-code, cron, runner, scheduler

## 简介

Independent runner daemon for Cron for Claude (cronforclaude.com). Polls the scheduler API, claims due jobs, runs them locally with your Claude CLI login. Not affiliated with Anthropic.
