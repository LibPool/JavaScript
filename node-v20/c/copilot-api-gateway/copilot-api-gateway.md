# copilot-api-gateway

> 标签: anthropic, claude-code, copilot, gateway, github-copilot, openai, proxy

## 简介

Local OpenAI/Anthropic-compatible HTTP gateway that proxies to GitHub Copilot. Drop-in for Claude Code, Codex, and other LLM clients.
