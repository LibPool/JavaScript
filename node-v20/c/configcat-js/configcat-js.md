# configcat-js

> 标签: canary release, config, configcat, configcat client, configuration, feature flags, feature switch, feature toggle, release strategy, remote configuration, soft launch

## 简介

ConfigCat is a configuration as a service that lets you manage your features and configurations without actually deploying new code.
