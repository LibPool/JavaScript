# create-zephyr-framework

> 标签: ai-agent, create, mcp, model-context-protocol, scaffold, ui-framework, web-components, zephyr

## 简介

Scaffold a new Zephyr Framework project with MCP server integration. The fastest way to build agent-controlled UIs. Run with: npx create-zephyr-framework my-app
