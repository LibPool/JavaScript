# com.beanbag.firebase.auth

> 标签: Auth, Authentication, Firebase, FirebaseAuth, Google, vh-name:Firebase Authentication, vh-name:FirebaseAuth

## 简介

Easily sign-in and authenticate players.

Sign-in players using any identity provider with Firebase Authentication. It supports email and password, phone authentication, Facebook, Google, Twitter, and more. Out-of-the-box, you get a secure, end-to-end ide
