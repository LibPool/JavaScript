# capjs-core

> 标签: anti-abuse, anti-automation, anti-bot, anti-ddos, anti-spam, captcha-alternative, hashcash, instrumentation, pow, proof-of-work, stateless, verification

## 简介

Stateless server-side challenge generator and verifier for Cap, a lightweight, modern open-source CAPTCHA alternative. No storage, no filesystem - bring your own.
