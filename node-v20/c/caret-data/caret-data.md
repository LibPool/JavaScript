# caret-data

> 标签: caret, contenteditable, cursor, iframe, input, offset, position, textarea

## 简介

Get the caret's position in textarea, input & contenteditable (even iframe). Updated fork of caret-pos, which itself is a plain JavaScript version of Caret.js.
