# comwit-ui

> 标签: cli, comwit, copy-paste, registry, ui

## 简介

Comwit UI CLI — copy-paste 스타일 컴포넌트를 내 프로젝트로 설치한다 (comwit 자체 레지스트리, shadcn 툴 비의존). 설치되는 엔진은 @comwit/ui.
