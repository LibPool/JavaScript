# cdk8s-aws-lookups

> 标签: aws, aws-cdk, aws-sdk, cdk8s, cdk8s-lookup, cdk8s-lookup-cloudformation-outputs, cdk8s-plus, cloudformation, lookup, lookup-cloudformation-outputs, ssm

## 简介

A cdk8s lookup class that allows you to lookup AWS CloudFormation outputs and AWS SSM parameter values during synth time from CloudFormation stacks.
