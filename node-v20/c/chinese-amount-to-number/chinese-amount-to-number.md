# chinese-amount-to-number

> 标签: amount, chinese, converter, finance, number

## 简介

是一个简单的 JavaScript 库，用于将中文大写的金额转换为数字。它适用于财务应用和其他需要处理中文金额字符串的场景。Convert Chinese amount strings to numbers.
