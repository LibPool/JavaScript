## 简介

Thin alias for @tantainnovative/create-ndpr — the Nigeria Data Protection Act (NDPA) 2023 compliance scaffolder. Forwards to the scoped package so `npm create ndpr@latest` and `npx create-ndpr` work alongside the canonical `npx @tantainnovative/create-ndp
