# cag-demo

> 标签: JavaScript

## 简介

Bella's Italian Kitchen assistant using CAG (Cache-Augmented Generation). Demonstrates the CAG path: `KnowledgeSource -> Chunker -> KnowledgeRetriever (LLM) -> createCagTool -> Agent -> Runtime -> Hono`.
