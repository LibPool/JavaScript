# case-converters

> 标签: PascalCase, camel, camelCase, capital, case converter, case transformation, constant, constant-case, convert case, dot, is-lower, is-upper, javascript, kebab, kebab-case, locale-lower, locale-upper, lower, lower-case, lower-first, no, object key converter, pascal, path, sentence, sentence-case, snake, snake_case, sponge, spongeCase, string case, string casing, swap, swapCase, text transform, title, title-case, train, train-case, typescript, upper, upper-case, upper-first

## 简介

A modern TypeScript utility to convert strings and object keys between various case styles like camelCase, snake_case, PascalCase, kebab-case, spongeCase, and more.
