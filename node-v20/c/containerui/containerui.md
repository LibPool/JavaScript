# containerui

> 标签: bedrock, jsx, minecraft, reactive, script-api, signals, ui

## 简介

A reactive UI framework for Minecraft Bedrock container interfaces — signals, components, hooks and JSX, with a scheduler that respects the tick budget. Not an official Minecraft product; not approved by or associated with Mojang or Microsoft.
