# com.litefeel.bitmapfontimporter

> 标签: Bitmap, Font, Importer

## 简介

Bitmap Font Importer is just perfect Unity asset plugin to import any custom bitmap font to your project. 
It easy imports any bitmap font generated by third party tools like:littera, bmGlyph, Glyph Designer 2, ShoeBox and Bitmap Font Generator
