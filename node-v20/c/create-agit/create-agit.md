# create-agit

> 标签: agent, claude-code, cli, codex, cursor, mcp, opencode, session, version-control

## 简介

One-line installer for agit (npx create-agit) — thin wrapper around @einsia/agent-git that lands the CLI at ~/.local/bin and wires skills/hooks/MCP.
