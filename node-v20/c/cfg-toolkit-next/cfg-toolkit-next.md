# cfg-toolkit-next

> 标签: JavaScript

## 简介

基于React+Redux+Fusion，以后台控制面板做为基础UI, 适用多页面和单页混合的项目. 里面提供了简单的单页面案例,和复杂的多页案例, 完全满足大型项目需求.
