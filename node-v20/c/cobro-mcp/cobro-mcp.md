# cobro-mcp

> 标签: browser, claude-code, co-browse, codex, cursor, mcp, mcp-server, overlay, playwright, ui-feedback

## 简介

Co-browse for coding agents: pick elements in the browser, write a note, Send — the context lands in the agent's chat. MCP server with 6 tools.
