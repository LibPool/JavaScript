# com.hidano.shadow-only-shader

> 标签: character, render-pipeline, shader, shadow, skinned-mesh, urp, vtuber

## 简介

URP向けの影だけを表示するシェーダーシステム。仮想光源からの深度テクスチャ生成とプロジェクティブテクスチャマッピングにより、透明な床面上にキャラクターの影のみを描画します。
