# com.simetrica.cordova.plugin.canvascamera

> 标签: camera, canvas camera, take photos

## 简介

The purpose of the plugin is to create an platform independent javascript interface for Cordova based mobile applications to preview camera and to take picture.  It's a fork from Donald Pae
