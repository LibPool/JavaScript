# clientside-search

> 标签: BK-Tree, BM25, Damerau-Levenshtein-distance, TF-IDF, document-indexing, document-search, full-text-search, fuzzy-matching, information-retrieval, language-detection, multi-gram, multilingual, n-gram, natural-language-processing, search-engine, state-dehydration, state-hydration, text-analytics, text-processing, text-search

## 简介

A highly efficient, isomorphic, full-featured, multilingual text search engine library, providing full-text search, fuzzy matching, phonetic scoring, document indexing and more, with micro JSON state hydration/dehydration in-browser and server-side.
