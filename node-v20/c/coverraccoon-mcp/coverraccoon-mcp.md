# coverraccoon-mcp

> 标签: agent, cover, defi, insurance, mcp, model-context-protocol, nexus-mutual

## 简介

MCP server exposing Cover Raccoon's free DeFi cover (insurance) catalog and coverage-gap check as agent tools. Read-only, no wallet, no payment.
