# claude-spend-guard

> 标签: ai-agent, anthropic, budget, claude, claude-code, cli, cost-control, guardrail, safety, spend-limit

## 简介

Local-first CLI that wraps Claude Code and hard-kills it when a configurable dollar spend cap is breached mid-session. Zero telemetry, zero backend, zero account.
