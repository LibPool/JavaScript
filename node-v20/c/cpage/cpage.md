# cpage

> 标签: Cpage.js, TypeScript, chai, chen.js, cpage, javascript, js, mocha, test

## 简介

Cpage.js是一款轻量级的前端框架，使用TypeScript开发，可以方便地进行组件化开发，语法统一、简介明了，不依赖于第三方框架，适合中小项目开发。框架同时支持es5与es6语法，可参考example中示例。
