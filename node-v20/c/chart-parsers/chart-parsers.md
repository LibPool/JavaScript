> 标签: chart parser, chart parsing, feature structure, natural language processing, parser, parsing, type hierarchy, type lattice, typed feature structure, unification-based grammar

## 简介

This is a library of chart parsers for natural language processing using  context-free grammars and unification-based grammars.
