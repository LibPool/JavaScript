# class-validator-ex

> 标签: JavaScript

## 简介

这个库是扩展自validator-class，提供了额外的ComplexType用于校验复杂的类型，包括Foo内部字段是Bar的类型，Foo内部字段是Array，但是元素是Bar类型的一系列额外内部校验； 还提供了Nullable<T>类型，表示类型是T且可undefined和可null 需要用这边提供的validateClassSync而不是class-validator里的validateSync方法；                                              --by
