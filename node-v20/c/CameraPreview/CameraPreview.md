# CameraPreview

> 标签: android, cam, camera, camera-preview, cordova, cordova-android, cordova-ios, custom-camera, ecosystem:cordova, ionic, ios, phonegap, preview

## 简介

Cordova plugin that allows camera interaction from HTML code. Show camera preview popup on top of the HTML.
