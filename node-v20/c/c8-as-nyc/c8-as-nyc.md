# c8-as-nyc

> 标签: c8, code coverage, nyc

## 简介

This package simulates the [nyc package](https://www.npmjs.com/package/nyc) by linking [c8](https://www.npmjs.com/package/c8) at the position of [nyc](https://www.npmjs.com/package/nyc).
