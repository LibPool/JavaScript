# coronium-proxy-mcp

> 标签: 4g-proxy, 5g-proxy, ai-assistant, api, authentication, claude, coronium, mcp, mobile-proxy, model-context-protocol, proxy

## 简介

Model Context Protocol server for Coronium.io mobile (4G/5G) proxies — full lifecycle: list, rotate, replace, test, configure auto-rotation, manage subscriptions, check balances, open tickets.
