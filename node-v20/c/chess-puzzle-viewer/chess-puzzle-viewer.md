# chess-puzzle-viewer

> 标签: chess, pgn, puzzle

## 简介

Inspired by [lichess-org/pgn-viewer](https://github.com/lichess-org/pgn-viewer/), **Chess Puzzle Viewer** is a widget for viewing and interacting with chess puzzles.
