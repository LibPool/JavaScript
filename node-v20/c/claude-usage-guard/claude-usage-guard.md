# claude-usage-guard

> 标签: agents, claude, claude-code, mcp, model-context-protocol, orchestrator, rate-limit, usage

## 简介

MCP server that exposes Claude Code's real-time rate limit usage so orchestrators can check remaining capacity before launching subtasks.
