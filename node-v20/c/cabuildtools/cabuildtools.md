# cabuildtools

> 标签: JavaScript

## 简介

命令助手构建工具支持自动化构建[命令助手](https://gitee.com/projectxero/ca)、[命令助手Android](https://gitee.com/projectxero/cadroid)与[命令助手拓展包源](https://gitee.com/projectxero/caclib)。
