# create-neobit-app

> 标签: arabic, authentication, boilerplate, cli, firebase, i18n, neobit, react-native, rtl, scaffold, starter, template

## 简介

Scaffold a production-ready React Native app in one command. Auth, Firebase, Theme, i18n (Arabic + English RTL), Navigation — all wired up.
