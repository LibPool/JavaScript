# cesium-tsunamilab

> 标签: 3D, geospatial, globe, map, webgl

## 简介

Cesium is a JavaScript library for creating 3D globes and 2D maps in a web browser without a plugin. This a fork fixing issue #4935 on the official cesium repository.
