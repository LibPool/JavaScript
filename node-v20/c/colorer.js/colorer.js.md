# colorer.js

> 标签: 256, ansi, cli, color, colors, colour, command-line, console, formatting, log, logging, rgb, shell, str, string, style, styles, terminal, text, tty, xterm

## 简介

A terminal coloring. Can be colored with any colors with supported RGB, and Color Codes. A easy-to-use package that everyone can do. Also supported font styles like Bold, Italic, Strikethrough, and underline.
