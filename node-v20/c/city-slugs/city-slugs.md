# city-slugs

> 标签: cities, dataset, gazetteer, geocoding, geonames, slugs, timezone

## 简介

Canonical URL-safe ids and slugs for 234,136 cities and towns worldwide — a short id (ber, sf, nyc) and a written slug (berlin), both unique, assigned by population.
