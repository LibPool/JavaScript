# click-element-to-code

> 标签: click-to-source, developer-tools, inspector, nextjs, react, source-map, vite

## 简介

⌥ Option-click any element in your dev server to open its source in your editor. Dev-only, works with Next.js 16 (Turbopack) + Vite on React 19.
