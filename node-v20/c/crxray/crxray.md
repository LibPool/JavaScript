# crxray

> 标签: ai-agents, audit, beautify, chrome-extension, chrome-web-store, cli, crx, deobfuscate, diff, download, edge-addons, extension-source, git-clone, security, source-code, unpack

## 简介

git clone for Chrome Web Store extensions — paste a store link or ID, get full unpacked source on disk. Audit, deobfuscate, beautify, diff.
