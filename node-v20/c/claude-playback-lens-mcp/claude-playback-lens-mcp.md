# claude-playback-lens-mcp

> 标签: JavaScript

## 简介

MCP server over Claude Playback Lens — reports token/cost usage and session structure from Claude Code's own recorded transcripts. The npm package ships the engine and the MCP server; the dev-mode web UI ships with the git repo.
