# china-jpegtran-bin

> 标签: compress, image, imagemin, img, jpeg, jpegtran, jpg, minify, optimize

## 简介

jpegtran (part of libjpeg-turbo) bin-wrapper that makes it seamlessly available as a local dependency, 同步官方代码，解决国内下载jpegtran-bin,optipng-bin依赖的源码慢的问题

## 官网

- 官网：https://github.com/lscgzwd/jpegtran-bin#readme
- 源码仓库：git+ssh://git@github.com/lscgzwd/jpegtran-bin.git
- npm 页面：https://www.npmjs.com/package/china-jpegtran-bin
