# contexify

> 标签: binding, container, context, decorator, dependency-injection, esm, interceptor, inversion-of-control, ioc, minimal-dependencies, provider, typescript

## 简介

A TypeScript library providing a powerful dependency injection container with context-based IoC capabilities, inspired by LoopBack's Context system.
