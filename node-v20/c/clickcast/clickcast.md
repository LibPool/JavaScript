# clickcast

> 标签: ai-agent, browser-automation, clickcast, gif, mcp, playwright, screenshot

## 简介

Drive a browser through a website and hand back a reel + AI-readable feedback sidecar -- npm wrapper around the clickcast Python CLI, provisioned into an isolated venv on install.
