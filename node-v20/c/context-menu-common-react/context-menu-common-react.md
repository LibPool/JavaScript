# context-menu-common-react

> 标签: JavaScript

## 简介

> 前端经常有用到右键菜单扩展交互能力的需求，不同场景下菜单功能不同，且通常需要根据右键目标的不同显示不同的菜单操作，本文就记录了一种通用的右键菜单解决方案。
