# chiproof

> 标签: age-verification, attestation, emrtd, icao-9303, passport, privacy, selective-disclosure

## 简介

Verifier SDK for attested, windowed disclosure from ICAO 9303 chip documents. Part of the zkagent project. M1 buckets B1-B4 implemented and tested; no real-hardware M0 evidence backs it yet.
