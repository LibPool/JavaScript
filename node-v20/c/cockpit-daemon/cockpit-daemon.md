# cockpit-daemon

> 标签: ai-agent, claude, claude-code, cockpit, daemon, end-to-end-encryption, remote-control

## 简介

云展 Cockpit — 被控端 daemon：装在用户机器上，包装真实 claude code CLI，按 wire 协议端到端加密同步到 relay，并接收 console 下发的 RPC。
