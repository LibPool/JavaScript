# calldata-guardian-mcp

> 标签: ai-agent, arbitrum, base, blockchain, bsc, calldata-decoder, crypto-security, defi-security, ethereum, evm, mcp, model-context-protocol, onchain, permit2, polygon, transaction-decoder, wallet-drainer, wallet-security, what-am-i-signing, x402

## 简介

Decode and explain an EVM transaction BEFORE you sign it. Plain-English breakdown of the calldata, flagging unlimited approvals, EIP-2612/Permit2 gasless permits, setApprovalForAll, transferFrom drains and approvals to a plain-wallet (EOA) spender. SAFE/R
