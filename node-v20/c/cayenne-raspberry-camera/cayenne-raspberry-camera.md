# cayenne-raspberry-camera

> 标签: JavaScript

## 简介

Takes a photo using Raspberry Pi camera and send it with e-mail and through Slack image upload. Integrated with Cayenne dashboard.

- npm 页面：https://www.npmjs.com/package/cayenne-raspberry-camera
