# create-ai-orchestrator

> 标签: ai-agents, ai-development, ai-orchestrator, anthropic, claude, claude-code, developer-tools, orchestration, skills

## 简介

Set up The AI Orchestrator System in any project. Full mode: 12 agents, 37 skills, 20 commands, 11 hooks. Light mode (--light): MCP-connected, skills load on-demand from Cortex.
