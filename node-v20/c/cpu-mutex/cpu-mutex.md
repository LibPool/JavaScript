# cpu-mutex

> 标签: agents, ci, cpu, flock, lock, lockf, mutex, serialize, test-runner

## 简介

Machine-wide mutex for heavy commands — one CPU-saturating run at a time across every project, via the kernel's own file lock (lockf/flock). No stale locks, ever.
