> 标签: agent-tools, ai-agent, architecture, ast, claude, claude-code, code-analysis, code-intelligence, codebase, dependency-graph, javascript, static-analysis, typescript, visualization

## 简介

Code intelligence for Claude Code and AI agents: type-resolved answers about any JS/TS repo — who calls a symbol, its blast radius, route behaviour — plus a local visual map. Install as a Claude skill with `codinflow skill install`.
