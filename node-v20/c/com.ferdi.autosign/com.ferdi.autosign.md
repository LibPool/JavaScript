# com.ferdi.autosign

> 标签: Autosign, Ferdi, alias, key, keystore, password, signature

## 简介

Tired of clicking on Build & Run and being intercepted by the Editor because you haven't signed your project key? Autosign remembers your password, so you never have to worry about it again.
