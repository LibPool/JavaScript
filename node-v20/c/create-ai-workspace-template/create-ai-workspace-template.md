# create-ai-workspace-template

> 标签: agent, ai-workspace, boilerplate, create, create-ai-workspace, cursor, monorepo, nextjs, scaffold, supabase, template, vercel

## 简介

Scaffold an AI-agent workflow monorepo (Cursor rules, docs, task board, Next.js + Vercel) in one command. 한 줄로 에이전트 워크플로우 모노레포를 만듭니다.
