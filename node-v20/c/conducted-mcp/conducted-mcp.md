# conducted-mcp

> 标签: agent, ai, conducted-development, kickoff, mcp, methodology, model-context-protocol, modelcontextprotocol, planning, validator

## 简介

A stateless advisor + validator MCP server for the Conducted Development methodology — guided kickoff, artifact validation, phase procedures, and rule checks. Model- and tool-agnostic.
