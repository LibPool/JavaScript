# clickpay

> 标签: account-abstraction, checkout, cross-chain, crypto, eip-7702, embedded-wallet, magic, particle-network, payments, react, stablecoin, universal-account, web3

## 简介

Chain-abstracted crypto payments for any React app: email login → EIP-7702 Universal Account → one-click pay from a unified cross-chain balance. Drop-in <ClickProvider>, <ClickPayButton>, <ClickAccountButton> + hooks.
