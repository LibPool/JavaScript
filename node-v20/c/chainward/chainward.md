# chainward

> 标签: agent-security, ai-agent, blockchain, cli, guardrail, llm-proxy, llm-security, onchain, prompt-injection, sanitization, wallet-agent, web3

## 简介

Scan and sanitize attacker-writable on-chain text before it reaches an LLM. Zero-dependency prompt-injection guard for web3 AI agents — library, and a drop-in proxy.
