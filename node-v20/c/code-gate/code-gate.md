# code-gate

> 标签: DeepSeek, Ollama, code review, commit, diff2html, git

## 简介

Intelligent Git commit guard and code reviewer. Supports local (Ollama) and cloud models (DeepSeek, OpenAI, Anthropic, etc.) with a rich CLI UI.
