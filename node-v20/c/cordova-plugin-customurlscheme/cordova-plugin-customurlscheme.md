# cordova-plugin-customurlscheme

> 标签: Custom URL, Custom URL Scheme, Launch App, Launch My App, URL scheme, URLscheme, cordova-android, cordova-ios, cordova-windows, cordova-windows8, ecosystem:cordova

## 简介

Launch your app by using this URL:  mycoolapp://, you can add a path and even pass params like this: mycoolerapp://somepath?foo=bar
