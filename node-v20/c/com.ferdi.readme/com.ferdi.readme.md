# com.ferdi.readme

> 标签: Asset, Ferdi, ReadMe

## 简介

Automatically adds a ReadMe asset file in the Assets folder root. The ReadMe file appears as a text in the inspector window. You can directly edit the file in the inspector and use richtext formating.
