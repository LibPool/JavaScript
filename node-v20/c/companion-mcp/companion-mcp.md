> 标签: ascii, claude, cli, codex, companion, cursor, gacha, mcp, model-context-protocol, pet

## 简介

A terminal companion pet for Cursor, Claude Code, and Codex — deterministic gacha creatures with rarities, stats and ASCII sprites, exposed as an MCP server.
