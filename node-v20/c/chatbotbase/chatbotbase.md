# chatbotbase

> 标签: actions-on-google, alexa, chatbotbase, google-assistant, google-home, voice-app, voice-application, voice-assistant

## 简介

A modular node.js framework to write chatbots for different platforms like Google Home and Amazon Alexa at once.
