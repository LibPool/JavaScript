# create-guren-app

> 标签: bun, bun-framework, claude-code, create-app, drizzle, framework, fullstack, guren, hono, inertia, laravel, react, starter, typescript

## 简介

Scaffold a Guren app: a Bun-first fullstack TypeScript framework with Laravel-style conventions, Inertia.js + React, Drizzle ORM, and an agent harness for Claude Code and other coding agents.
