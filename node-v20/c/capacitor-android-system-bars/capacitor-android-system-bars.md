# capacitor-android-system-bars

> 标签: android, android-15, android-16, api-35, api-36, capacitor, edge-to-edge, fullscreen, immersive, native, navigation-bar, plugin, status-bar, system-bars

## 简介

Unified plugin to handle Android system bars (status bar & navigation bar), webview sizing, edge-to-edge display, and fullscreen mode with full compatibility for Android API 21-36+
