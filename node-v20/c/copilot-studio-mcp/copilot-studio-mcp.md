# copilot-studio-mcp

> 标签: copilot-studio, mcp, pac, power-platform

## 简介

MCP server for Microsoft Copilot Studio agent development: workspace sync via pac, YAML authoring (topics, knowledge, tools, flows), evaluations and chat-testing
