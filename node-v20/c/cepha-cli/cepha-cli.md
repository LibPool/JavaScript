# cepha-cli

> 标签: aspnet, blazor, cepha, cli, cloudflare, dotnet, dotnet-tool, mvc, spa, wasm, webassembly, workers

## 简介

🧬 Cepha CLI — Build, test, and deploy ASP.NET MVC apps that run entirely in WebAssembly. Runs on any platform with Node.js — no .NET runtime required.
