# cocos-ts-plugin

> 标签: cocos2d-html5, cocos2d-x, intellisense, language-service, ts-plugin, typescript, vscode

## 简介

TypeScript Language Service plugin that resolves `this.xxx` inside cocos2d-x / cocos2d-html5 cc.Class.extend({...}) literals — providing Go to Definition and hover info that tsserver alone can't compute.
