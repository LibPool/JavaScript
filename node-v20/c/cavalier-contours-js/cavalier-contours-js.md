# cavalier-contours-js

> 标签: 2d, arc, boolean, bulge, cad, cavalier-contours, geometry, offset, parallel-offset, polyline

## 简介

Pure TypeScript port of the cavalier_contours Rust library: 2D polyline parallel offsetting (with arc segments) and boolean operations.
