# cs-upgrade-mcp

> 标签: assessment, cloudsense, cpq, cursor, mcp, model-context-protocol, package-upgrade, salesforce, sow

## 简介

MCP server for CloudSense managed package upgrade assessments — package registry, breaking changes database, effort estimation, upgrade path recommendation, claim validation, and document generation (SOW, Assessment, Executive Slides).
