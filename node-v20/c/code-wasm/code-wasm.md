# code-wasm

> 标签: interpreter, language, playground, plugins, wasm, webassembly

## 简介

Run Code — a language with no user-defined functions, particle emission for behavior, and browser-embeddable third-party modules — in any browser or JS host. A small WASM bridge around the language's real parser and interpreter.
