# ccfleet

> 标签: aggregation, ccusage, claude, claude-code, cli, cost-tracking, ssh, token-usage

## 简介

Aggregate ccusage across every machine where you run Claude Code — one merged view of tokens, cost, and billing blocks, over SSH.
