# chrome-devtools-mcp-mux

> 标签: chrome-devtools, chrome-devtools-mcp, claude-code, mcp, multiplexer, puppeteer

## 简介

Drop-in chrome-devtools-mcp multiplexer: lets multiple MCP clients share one Chrome instance and profile, with per-client tab ownership so they don't step on each other's tabs.
