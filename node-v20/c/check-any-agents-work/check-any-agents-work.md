# check-any-agents-work

> 标签: aer-1, agent-skills, ai-agents, claude, cursor, mcp, receipts, verification, zambo

## 简介

Agent Skill: teach your AI to check any agent's work before trusting a done claim. Get the work record, verify it has not changed since it was saved, review the handover, sign off or dispute on the record. Built on Zambo, the verifiable work layer for AI.
