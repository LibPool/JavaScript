# codexgpt

> 标签: apps-sdk, chatgpt, cloudflare-tunnel, codex, codexgpt, local-development, mcp, ngrok, tailscale

## 简介

Windows-first, self-hosted MCP tools that connect ChatGPT to one local repository through a loopback server and an optional HTTPS tunnel.
