> 标签: ai-ml, audit-tool, automatic-documentation, cli-tool, code-analysis, code-archive, code-documentation, code-review, cross-platform, developer-tools, documentation-generator, file-scanner, llm-integration, nodejs-cli, pdf-export, pdf-generator, professional-pdf, project-documentation, project-summary, source-code, terminal-compatible

## 简介

Cross-platform CLI tool that generates PDF documentation and LLM-optimized Markdown for direct use with any chat-based LLM. Perfect for code reviews, audits, and AI-assisted development.
