# carly-ai

> 标签: agent, ai, bookings, calendar, carly, carly-ai, cli, mcp, scheduling

## 简介

Agent-native CLI and MCP server for Carly — the AI scheduling assistant. Read bookings, booking pages, event types, and slots from any MCP-compatible client or shell.
