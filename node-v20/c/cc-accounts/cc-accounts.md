# cc-accounts

> 标签: accounts, anthropic, claude, claude-code, cli, mirror, multi-account, switcher

## 简介

Run multiple Claude Code logins side by side. Like ccmirror, but for different claude accounts — claude-work, claude-personal, claude-team, with correct per-account billing isolation.
