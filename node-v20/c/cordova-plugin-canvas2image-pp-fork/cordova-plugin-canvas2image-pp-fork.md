# cordova-plugin-canvas2image-pp-fork

> 标签: canvas, cordova-android, cordova-ios, cordova-wp8, ecosystem:cordova, image, photo library

## 简介

This plugin allows you to save the contents of an HTML canvas tag to the iOS Photo Library, or Android Gallery from your app.
