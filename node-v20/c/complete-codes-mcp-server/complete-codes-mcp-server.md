# complete-codes-mcp-server

> 标签: ai-agents, bounties, complete-codes, github, mcp, model-context-protocol, usdc

## 简介

MCP server for Complete Codes — agent-native surface to discover, create, fund, update, and cancel sprints, plus track earnings. Read tools are public; write tools require a Web3Auth JWT in CC_API_TOKEN.
