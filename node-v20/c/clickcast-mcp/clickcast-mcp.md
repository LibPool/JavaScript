# clickcast-mcp

> 标签: ai-agent, browser-automation, clickcast, mcp, model-context-protocol, playwright, screenshot

## 简介

npx-first MCP (Model Context Protocol) server for clickcast -- browser sessions for AI agents. Wraps `clickcast mcp` via an isolated, auto-provisioned Python venv.
