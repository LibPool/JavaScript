# cvdsafe

> 标签: a11y, accessibility, color-blindness, color-vision, colorblind, colorblind-safe, contrast, cvd, daltonize, deuteranopia, palette, protanopia, tritanopia, wcag

## 简介

Is your palette colorblind-safe? Check and fix color palettes for color-vision deficiency (protan, deutan, tritan) with the published OpticQuiz engine — Machado 2009 + CIEDE2000.

## 官网

- 官网：https://opticquiz.com/checker/
- 源码仓库：git+https://github.com/vince-gonzalez/opticquiz.com.git
- npm 页面：https://www.npmjs.com/package/cvdsafe
