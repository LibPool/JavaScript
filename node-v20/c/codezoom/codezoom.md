# codezoom

> 标签: architecture, code-navigation, csharp, dependency-graph, dotnet, mcp, uml, unity

## 简介

Walk the architecture of a Unity or .NET C# project one type at a time: a UML view centred on one Focus, its Dependents above and Dependencies below, in your browser or through MCP tools for coding agents.
