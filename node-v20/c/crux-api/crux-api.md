# crux-api

> 标签: CLS, Chrome UX Report, Chrome User Experience Report, Core Web Vitals, CrUX, CrUX API, CrUX History API, Cumulative Layout Shift, FCP, FID, First Contentful Paint, First Input Delay, INP, Interation to Next Paint, LCP, Largest Contentful Paint, TTFB, Time to First Byte, Web Performance

## 简介

A tiny CrUX API wrapper that supports record & history API, handles errors, and provides types.
