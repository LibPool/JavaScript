# cordova-plugin-icpdonotbackup

> 标签: cordova-ios, ecosystem:cordova

## 简介

When using Google Analytics in your iOS app, this plugin prevent iCloud to backup files generated by GA by setting a special attribute. Otherwise, these files can lead your app to be rejected at App Store submission.
