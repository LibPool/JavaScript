# com.careboo.unity-algorand-sdk

> 标签: algorand, blockchain, crypto, sdk, tool

## 简介

Integrate your game with Algorand, a Pure Proof-of-Stake blockchain overseen by the Algorand Foundation.
Create Algorand transactions, Algorand accounts, and use Algorand's REST APIs.
