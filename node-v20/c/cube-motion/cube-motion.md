# cube-motion

> 标签: animation, entrance, exit, morph, motion, react, reduced-motion, reveal, solid, svelte, transition, vue, waapi, web-animations

## 简介

Four motions, no dials. rise, leave, morph and reveal on the Web Animations API, with React, Vue, Solid and Svelte adapters.
