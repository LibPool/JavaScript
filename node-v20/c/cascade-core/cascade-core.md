# cascade-core

> 标签: 3d, brep, cad, iges, modeling, occt, opencascade, parametric, step, wasm

## 简介

Reusable CAD modeling engine built on OpenCascade WASM. Evaluate CAD code in a Web Worker and get triangle mesh data back.
