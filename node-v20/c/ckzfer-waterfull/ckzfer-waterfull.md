# ckzfer-waterfull

> 标签: waterfull

## 简介

基于cool-uni下的cool-waterfull的数据改造版，原因是cool-waterfull要求的数据格式为二维数组，某些场景下list数据并不是二维数组，故此才有此版本的诞生，纯属个人折腾学习，不建议用到商业项目中。如需请移步到cool-uni上
