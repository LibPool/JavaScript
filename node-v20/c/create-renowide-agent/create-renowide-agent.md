# create-renowide-agent

> 标签: agent, canvas-kit, create-app, renowide, scaffolder

## 简介

One-line scaffolder for Renowide agents. `npm create renowide-agent@latest my-agent` produces a working Canvas Kit v2 agent ready to deploy. The build-and-distribute default for humans (the AI-coding-assistant path uses @renowide/mcp-server).
