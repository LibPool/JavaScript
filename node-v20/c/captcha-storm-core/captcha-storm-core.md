# captcha-storm-core

> 标签: JavaScript

## 简介

Universal, minimalistic multi-provider CAPTCHA loader.   Supports **Google reCAPTCHA**, **hCaptcha**, and **Cloudflare Turnstile**.   Designed to be used in custom UI integrations (e.g., React, Vue, Vanilla JS).
