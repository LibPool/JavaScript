# canvas-labeler

> 标签: annotation, canvas, circle, dot, image, label, line, marker, polygon, rect, 圆, 多边形, 折线, 标注, 标记, 点, 矩形

## 简介

一个用于图片标注的javascript库，基于canvas-select插件，简单轻量，支持矩形、旋转矩形、多边形、点、折线、圆形。
