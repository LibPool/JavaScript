# claude-ui-devtools

> 标签: developer-tools, devtools, element-picker, fiber, llm, prompt, react, source-path

## 简介

Floating in-browser devtools for React apps: pick any element and copy its component name, source file path, route, and computed styles as a ready-to-paste prompt block.
