# compact-delta

> 标签: binary-diff, compression, delta, delta-compression, delta-encoding, diff, esm, myers, patch, rolling-hash, vcdiff

## 简介

Generic optimal binary delta compression - auto-picks the smallest encoding (copy/insert, Myers LCS, or raw). Zero dependencies, works in Node and the browser.
