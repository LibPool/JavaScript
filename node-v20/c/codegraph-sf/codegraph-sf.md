# codegraph-sf

> 标签: apex, code-intelligence, knowledge-graph, lwc, mcp, salesforce, sobject, static-analysis

## 简介

CodeGraph for the Salesforce stack — a fork that indexes Apex/Visualforce/Aura/LWC + React↔Apex postMessage bridges and an SObject field-usage/impact layer (Layouts, Validation Rules, formulas). Tracks @colbymchenry/codegraph upstream.
