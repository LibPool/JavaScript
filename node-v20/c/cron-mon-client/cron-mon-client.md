# cron-mon-client

> 标签: alerting, cron, cron-mon, monitoring, reports

## 简介

This is the package which will enable to run the cron scheduled jobs, integrated with CRON-MON APP, which helps in monitoring the jobs and alerting for the job failures with other important features
