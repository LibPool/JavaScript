# credential

> 标签: PBKDF2, auth, authentication, authorization, brute, hash, login, password, passwords, rainbow, salt, security, sign in, stretching

## 简介

Easy password hashing and verification in Node. Protects against brute force, rainbow tables, and timing attacks.
