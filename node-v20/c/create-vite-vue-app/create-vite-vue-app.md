# create-vite-vue-app

> 标签: JavaScript

## 简介

这是一个支持 Vue2 和 Vue3 的 Vite 脚手架项目，帮助你快速创建现代化的 Vue 前端工程。内置 Element UI/Element Plus、Pinia、Vue Router、TypeScript、TailwindCSS 等主流技术栈，适用于后台管理系统或通用前端项目开发。
