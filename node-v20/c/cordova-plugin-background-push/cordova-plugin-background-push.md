# cordova-plugin-background-push

> 标签: background, cordova, ecosystem:cordova, push notifications

## 简介

This plugin allows your application to receive push notifications on Android, iOS, WP8 and Windows8 devices.
    Android uses Google Cloud Messaging (+ experimental background task support).
    iOS uses Apple APNS Notifications (+ experimental Sile
