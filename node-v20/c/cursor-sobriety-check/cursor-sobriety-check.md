# cursor-sobriety-check

> 标签: ai, cursor, cursor-ide, cursor-sobriety-check, durellem, hooks, observability

## 简介

A free, one-click add-on for Cursor. Reminds the agent of your rules, warns you when chat memory is compressed, and keeps a private local report.
