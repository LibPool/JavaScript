# cosmemilton-report

> 标签: cosmemilton, csv, nextjs, pdf, react, relatorio, report, report-builder, xlsx

## 简介

Report builder React para Next.js — definição declarativa de relatórios com export em PDF, CSV, XLSX, JSON e TSV, editor visual de layout e config em camadas.
