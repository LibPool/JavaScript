# cordova-plugin-ra-chart

> 标签: angular, chart, charts, cordova-android, cordova-browser, cordova-ios, dashboard, ecosystem:cordova, graph, ionic, mobile, no-dependencies, offline, svg

## 简介

Dependency-free SVG chart engine for Cordova and Ionic — 21 chart types with touch gestures, pinch-to-zoom, haptics and dark-mode theming. No native code, no build step.
