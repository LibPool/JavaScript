# cloudflare-smtp-gateway

> 标签: cloudflare, cloudflare-email-service, email, mail-proxy, smtp, smtp-gateway, smtp-relay, transactional-email, wordpress, wp-mail-smtp

## 简介

Self-hostable SMTP + HTTP sending gateway for Cloudflare Email Service. Point WordPress (or any app) at it and send transactional mail through Cloudflare.
