# conference-badge-generator

> 标签: astro, astro-integration, background-removal, badge, conference, emdash, emdash-plugin, event, linkedin

## 简介

Native EmDash + Astro badge generator plugin. Organisers configure the event in the EmDash admin (settings form, stats dashboard, widget); the plugin injects a public /badge page where visitors build a 1080x1080 shareable badge: photo crop, in-browser AI
