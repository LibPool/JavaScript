# codex-octo-channel

> 标签: bot, channel, chatbot, codex, codex-cli, im, octo, openai-codex, wukongim

## 简介

Octo IM channel for the Codex CLI: each DM, group, or thread drives its own persistent Codex session on your machine; committed answers return to Octo as text messages
