# captcha-ocr-model

> 标签: captcha, ddddocr, ocr, onnx, onnxruntime, onnxruntime-web, verification-code

## 简介

Lightweight ONNX captcha OCR model (4-char alphanumeric), cropped from ddddocr. 5MB, runs in browser via onnxruntime-web.
