# custom-svga

> 标签: animation, canvas, canvas animation, custom, custom-svga, dreamlife, offscreen canvas, svga, svga animation, svga player, svga vue, svga web, svgaplayerweb, vue, vue3 svga, web, web animation, web worker

## 简介

A lightweight, tree-shakable SVGA animation player for Vue 3 & modern web. Isomorphic inline worker parsing with main-thread MockWorker fallback, in-flight sprite/text replacement. Zero UI framework deps.(面向 Vue3 与现代浏览器的轻量 SVGA 动画播放器。同构内联 Worker 解析 + 主线程
