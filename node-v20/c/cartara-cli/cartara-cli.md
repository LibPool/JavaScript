# cartara-cli

> 标签: JavaScript

## 简介

Cartara CLI is a tool that detects changes in your source code and securely sends them to the Cartara server, where AI automatically creates or updates the corresponding documentation. Designed to run in your CI/CD pipeline, it ensures your documentation
