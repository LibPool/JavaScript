# cc-bgm

> 标签: audio, bgm, claude, claude-code, hooks, music, sfx, windows

## 简介

Game-style background music & sound effects for Claude Code (Windows). StarCraft-vibes for your coding agent — town theme while idle, battle theme while working, victory chime when done.
