# comet-skills

> 标签: agent-skill, claude, claude-code, claude-skill, cli, codex, registry

## 简介

Comet's AI coding-agent skills registry + CLI. `npx comet-skills add <skill>` installs a skill into Claude Code, Codex, and other agents.
