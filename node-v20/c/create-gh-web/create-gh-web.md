# create-gh-web

> 标签: JavaScript

## 简介

## 项目介绍 用于快速创建接入 SSO 的 Vue3 Web 项目，内置常用依赖与配置：Vue Router、Pinia、Element Plus、Axios、TailwindCSS、AG Grid 等。
