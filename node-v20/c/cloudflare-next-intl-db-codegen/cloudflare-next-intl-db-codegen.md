# cloudflare-next-intl-db-codegen

> 标签: cloudflare, codegen, deno, drizzle, edge-functions, postgres, supabase

## 简介

Drizzle schema codegen CLI for cloudflare-next-intl-db — introspects tracked SQL DDL (via embedded-postgres or a live Postgres) with drizzle-kit and generates typed Drizzle models. Extracted from cloudflare-next-intl-db so its runtime package never ships
