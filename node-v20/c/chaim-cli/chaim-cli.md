# chaim-cli

> 标签: ai, claude-code, cli, cline, codex, developer-profile, gemini-cli, leaderboard, opencode, tokens, usage

## 简介

Sync your AI coding usage (Claude Code, Codex, Gemini CLI, OpenCode, Cline and more) to your Chaim profile: tokens, models, streaks, badges and a global leaderboard.
