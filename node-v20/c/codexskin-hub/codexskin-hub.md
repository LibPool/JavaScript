# codexskin-hub

> 标签: codex, codexhost, dream-skin, macos, theme, windows

## 简介

Standalone Dream Skin theme management for codexhost-launched Codex: theme hot-switch, ZIP import, gallery, in-app settings page - non-invasive to Codex Dream Skin and codex-host
