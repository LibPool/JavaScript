# cache-install

> 标签: JavaScript

## 简介

可以加速 `npm install`，在有缓存的情况下，默认去从缓存拉取，然后再执行 `npm install`，完成后再将 `node_modules` 拷贝回缓存系统。主要用于 `cicd` 等流程中，它很快。
