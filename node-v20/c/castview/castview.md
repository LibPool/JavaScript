# castview

> 标签: lan, mirror, mjpeg, remote-display, screen-cast, screen-mirror, screen-share, second-screen, websocket

## 简介

Mirror your screen to any device with a browser over LAN. Zero install on the viewer, QR code to connect, works over WiFi or a USB cable.
