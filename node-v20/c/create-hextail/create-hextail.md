# create-hextail

> 标签: cms, create, hextail, scaffold, vue

## 简介

Start a new Hextail site with npm create hextail. Hextail is a self-hosted CMS for plain Vue SPAs, by Wondermake, planned for public release in 2027.

## 官网

- 官网：https://hextail.com
- npm 页面：https://www.npmjs.com/package/create-hextail

- 0.0.1

- npm registry：https://registry.npmjs.org/create-hextail
- Node 要求：>=20
