# cursor-agent-orchestrator-mcp

> 标签: agents, cursor, cursor-sdk, mcp, model-context-protocol, multi-agent, orchestrator

## 简介

MCP server that orchestrates many @cursor/sdk agents in parallel (local or cloud), inheriting the parent Cursor session by default. Built for Cursor 3.0.
