# create-codeverse-front

> 标签: antd, app-router, cli, codeverse, generator, nextjs, scaffold, tailwindcss

## 简介

Zero-config CLI to scaffold new Next.js 16 (App Router) projects from the official CodeVerse starter template — just run with npx.
