# chatrail-mcp

> 标签: chatrail, claude, cursor, mcp, model-context-protocol, whatsapp, whatsapp-api

## 简介

MCP server for ChatRail: inspect WhatsApp connections, groups, message delivery, schedules and webhook deliveries from Claude, Cursor and other MCP clients.
