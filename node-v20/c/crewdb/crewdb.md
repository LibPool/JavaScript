# crewdb

> 标签: JavaScript

## 简介

**CrewDB**, Node.js tabanlı, dosya sisteminde JSON formatında veri saklayan hafif bir veritabanı çözümüdür. Bu modül, verileri `crewdb.json` dosyasına yazmanızı, okumanızı ve yönetmenizi sağlar.
