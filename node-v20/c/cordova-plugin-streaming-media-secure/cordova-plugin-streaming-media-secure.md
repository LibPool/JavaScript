# cordova-plugin-streaming-media-secure

> 标签: cordova-android, cordova-fireos, cordova-ios, ecosystem:cordova, media, secure, streaming

## 简介

This plugin allows you to stream audio and secure video in a fullscreen, native player on Android and iOS.
