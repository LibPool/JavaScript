# cvp-lib

> 标签: JavaScript

## 简介

**cvp-lib** — плеер Cubic Vision для воспроизведения мультимедийного контента (видео, изображения) в виде JS библиотеки для встраивания. Библиотека управляет всем жизненным циклом плеера: авторизацией, загрузкой файлов, воспроизведением контента, отправко
