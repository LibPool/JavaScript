# claude-retro

> 标签: agent, anthropic, claude, claude-code, cli, developer-tools, retrospective, transcripts

## 简介

An automatic retrospective for your AI pair programmer. Mines your local Claude Code session transcripts for friction — tool errors, permission denials, corrections, retry loops — and drafts concrete fixes for your CLAUDE.md and settings.
