# corder-mcp

> 标签: ai, claude, corder, cursor, mcp, meetings, transcripts

## 简介

Model Context Protocol server for Corder — exposes your meetings, transcripts, summaries, and action items to any MCP-compatible client (Claude Desktop, Claude Code, Cursor, ChatGPT, ...).
