# cosa-opencode

> 标签: agents, cosa, cosa-skills, opencode, opencode-plugin, orchestration

## 简介

Cosa for opencode — registers the Consigliere, Famiglia Codice and Famiglia Disegno as opencode agents and points the skill loader at Cosa's doctrine skills.
