# claude-opencode-mcp-v2

> 标签: claude-code, coding-agent, mcp, model-context-protocol, opencode, opencode-v2

## 简介

MCP bridge that lets Claude Code delegate software-engineering tasks to OpenCode 2.x agents. Port of claude-opencode-mcp to the OpenCode v2 HTTP API.
