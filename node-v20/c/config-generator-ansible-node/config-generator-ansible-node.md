# config-generator-ansible-node

> 标签: ansible config node, config generator, config generator node, nodejs generate config nginx

## 简介

config-generator-ansible-node is a TypeScript library for generating configuration and secure delivery using ansible for any of your services like nginx or mysql from your NodeJS application.
