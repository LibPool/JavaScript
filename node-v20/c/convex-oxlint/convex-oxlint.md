# convex-oxlint

> 标签: convex, eslint, eslintplugin, linter, oxlint, oxlint-plugin

## 简介

Oxlint port of @convex-dev/eslint-plugin — a drop-in replacement that keeps the same rule ids, messages, spans and fixes.
