# check-dependencies-simple

> 标签: dependencies, dependency, modules, packages

## 简介

Checks if currently installed npm/bower dependencies are installed in the exact same versions that are specified in package.json/bower.json

- 官网：https://github.com/mgol/check-dependencies
- 源码仓库：git+https://github.com/mgol/check-dependencies.git
