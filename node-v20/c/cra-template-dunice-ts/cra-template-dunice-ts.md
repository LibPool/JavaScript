> 标签: airbnb, cra, create-react-app, eslint, prettier, react, stylelint, template, typescript

## 简介

Template for Create React App supporting TypeScript and SCSS files. Included with Prettier, Stylelint and ESlint config recommended by Airbnb and Husky with pre-commit hook.
