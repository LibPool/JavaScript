# ccip-router

> 标签: attestation, ccip-read, eip-3668, ens, erc-8004, ethereum, gateway, ocp, wyriwe

## 简介

The coordination layer CCIP-Read was missing. Peer sync, deduplication, and cryptographic attestation for any CCIP-Read gateway.
