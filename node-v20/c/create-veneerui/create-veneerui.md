# create-veneerui

> 标签: JavaScript

## 简介

Scaffold a new themed Vite, Next, or Expo + Tailwind v4 app, wired for Veneer UI — `npm create veneerui@latest`.

- 官网：https://veneerui.dev
- 源码仓库：git+https://github.com/offthegully/veneerui.git
