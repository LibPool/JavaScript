# chunk-match

> 标签: chunking, cosine-similarity, data-matching, embedding, information-retrieval, javascript, natural-language-processing, nlp, nodejs, query-matching, search, semantic, semantic-analysis, semantic-chunking, similarity-matching, text-analysis, text-chunking, text-embedding, text-matching, text-processing, text-similarity

## 简介

NodeJS library that semantically chunks text and matches it against a user query using cosine similarity for precise and relevant text retrieval
