# code-clean-coupang

> 标签: JavaScript

## 简介

* 参数1：rules目录 * 参数2：待处理的代码目录 * 参数3：清理类型AB、FF、GFC * 参数4：清理的key（AB时多个key使用','来拼接，例如"10,20"） * 参数5：清理的key对应的取值（AB则是A~G，FF则是对应值，GFC则是true或者false）
