# copilot-pr-footer

> 标签: ci, copilot, copilot-cli, footer, gh, github, pull-request, status-line, statusline

## 简介

Show the PRs/issues/gists your GitHub Copilot CLI session created or updated — with live CI/review/merge state — in the Copilot status-line footer.
