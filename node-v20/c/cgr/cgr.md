# cgr

> 标签: npm, registry, yarn

## 简介

yarn & npm registry manager can help you easy and fast switch between different registries, now include: cnpm, taobao, nj(nodejitsu), rednpm, edunpm

- 源码仓库：git://github.com/daysai/cgr.git
