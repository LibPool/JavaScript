# create-bawo-frontend

> 标签: cli, create-app, framer-motion, gsap, nextjs, react, react-query, redux, redux-toolkit, rtk-query, scaffold, shadcn-ui, starter, swr, tailwindcss, tailwindcss-v4, template, vite, zustand

## 简介

Scaffold React (Vite) or Next.js with Tailwind CSS (v3 default, v4 optional), state management, Prettier, optional shadcn/ui, Framer Motion, and GSAP.
