# crondis

> 标签: automate, automation, cron job, cron jobs, cronify, date, get cron, get-cron, node-cron, schedule, scheduler, task scheduler

## 简介

Schedule recurring JavaScript tasks from ISO dates without writing cron expressions. Built on get-cron and node-cron.
