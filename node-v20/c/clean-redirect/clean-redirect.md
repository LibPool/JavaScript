# clean-redirect

> 标签: 301, 302, chain, domain, enforce, force, http, https, middleware, naked, redirect, redirects, seo, slash, subdomain, trailing, url, www

## 简介

Enforce HTTPS, www to naked domains, remove trailing slash, to lower case, and your own custom redirect logic, all in one single redirect.
