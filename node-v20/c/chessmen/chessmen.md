# chessmen

> 标签: animation, board, chess, chess-board, chess-game, chess-pieces, chessboard, chessmen, diagram, embed, fen, pgn, pgn-parser, pgn-viewer, replay, svg, variations, widget, zero-dependency

## 简介

Chessboard for the web: replay PGN games, show FEN diagrams, with animated moves, arrows and variations. One script tag, no dependencies, no build step.
