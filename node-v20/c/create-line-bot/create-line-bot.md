# create-line-bot

> 标签: idempotency, liff, line, line-bot, line-messaging-api, line-oa, nextjs, rich-menu, starter, supabase, template, thailand, vercel, webhook

## 简介

Scaffold a LINE bot that survives production: 5-second webhook ack on Vercel, dispatcher/worker split, four-layer idempotency, role-based Rich Menu, LIFF login wired to Supabase.
