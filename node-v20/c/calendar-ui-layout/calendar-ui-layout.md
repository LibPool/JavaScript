# calendar-ui-layout

> 标签: calendar, headless, layout, overlap, react, scheduler, time-grid, typescript

## 简介

Headless time-grid layout engine: overlap-column resolution for calendar/scheduler week & day views. UI-agnostic, zero runtime dependencies.
