# chatbot-sdk-integro

> 标签: JavaScript

## 简介

SDK de chatbot con inteligencia artificial listo para integrar en cualquier proyecto React o sitio web mediante CDN. Se conecta a un backend NestJS que utiliza **Google Gemini** como motor de IA.
