# csvql-query

> 标签: agent, ai, analytics, cli, csv, dataframe, duckdb, etl, fast, llm, mcp, parser, query, simd, sql

## 简介

SQL on CSV files in place — no import, no database. Zig/SIMD engine for Node and AI agents (MCP). Read-only by design.
