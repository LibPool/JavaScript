# cgraph

> 标签: agent, ai, call-graph, cgraph, claude, code-search, codebase-indexing, context, copilot, cursor, developer-tools, impact-analysis, knowledge-graph, llm, mcp, model-context-protocol, static-analysis, tokens, tree-sitter

## 简介

Token-efficient code retrieval for AI agents. Builds a queryable graph of your codebase and serves it over MCP, so agents stop burning context on grep and whole-file reads.
