# claude-excalidraw-diagrams

> 标签: agent-skill, architecture-diagram, claude, claude-code, claude-skill, diagram, excalidraw, flowchart, installer, mermaid-alternative

## 简介

Installs a Claude Code skill that generates real, editable .excalidraw diagrams — flowcharts, architectures, mind maps, sequence diagrams, ERDs and slide decks — instead of ASCII art.
