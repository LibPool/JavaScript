# create-local-llm-app

> 标签: create-app, guardrails, llm-agents, local-llm, ollama, scaffold

## 简介

Scaffold a local-LLM (Ollama) app with output contracts, a human approval queue, and watchdogs pre-wired — the guardrails distilled from 8,000+ logged agent failures.
