# cube-icons

> 标签: algorithm, clock, color-scheme, cube, fto, icons, megaminx, oll, pll, puzzle, pyraminx, rubiks-cube, scramble, skewb, speedcubing, square-1, svg, theme, twisty, wca

## 简介

SVG icon library for Rubik's Cube and twisty puzzle diagrams. Supports NxN cubes, Skewb, Pyraminx, Megaminx, FTO, Square-1, and Clock with multiple views, color modes, scrambles, and algorithms.
