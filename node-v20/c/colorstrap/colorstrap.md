# colorstrap

> 标签: bootstrap, color, css, sass

## 简介

Bring color to your Bootstrap projects. Colorstrap adds new classes for all 140 named HTML colors to many of Bootstrap's components. Colorstrap provides a customiztion tool to allow developers to create their own color classes at http://www.colorstrap.com
