# canvas-select-plus

> 标签: Mask转Polygon, Polygon可添加删除边界点, canvas-select, canvas尺寸自适应, 保存图片, 分割一切（需后端接口支持）, 刷子、橡皮檫, 图形可添加备注, 复制, 撤销, 显示, 智能标注（需后端接口支持）, 标签字体与图片等比例缩放, 清空, 触碰控制点样式变化, 重做, 钢笔工具, 隐藏, 鼠标样式变化

## 简介

一款基于canvas的2D图像标注工具，在canvas-select的基础上，添加了清空、复制、撤销、重做、隐藏、显示和鼠标样式变化等功能，尚在开发和维护中...
