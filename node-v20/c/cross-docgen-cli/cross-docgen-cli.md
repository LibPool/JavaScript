# cross-docgen-cli

> 标签: ast, cli, components, documentation, generator, markdown, react, vue

## 简介

跨端组件文档一键生成器：扫描 React/Vue 组件代码，自动解析 AST 生成 Markdown 文档并实时同步更新。
