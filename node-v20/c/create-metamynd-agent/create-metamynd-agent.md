# create-metamynd-agent

> 标签: agent, agentsafe, ai, cli, create, governance, mandate, metamynd, policy, scaffold

## 简介

Scaffold a MetaMynd/AgentSafe-governed AI agent in one command — logs in, provisions the agent (identity + mandate + SOP + Standards) in a single call, writes agent.metamynd.json plus a runnable agent + separate tool-gateway process that closes direct-cal
