# chord-synth

> 标签: agent-tools, ai-tools, arpeggiator, audio, chord, generator, llm-tools, logic-pro, mcp, midi, model-context-protocol, music, progression, synthesizer, wav

## 简介

Generate chord progression WAV files. 28 presets, 22 arp patterns, 7 instruments, slash chords, transposition. CLI + MCP server + Node.js module. Zero dependencies.
