# catalog-doctor

> 标签: catalog, cli, dependencies, lint, monorepo, pnpm, pnpm-workspace, turborepo, workspace

## 简介

Health check for pnpm workspaces. Finds dependency drift, phantom imports and broken catalog entries before they bite.
