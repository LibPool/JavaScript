# castov-cli

> 标签: base64, castov, cli, cron, detect, dst, hash, jwt, objectid, snowflake, timestamp, timezone, ulid, unix, uuid, uuidv7

## 简介

Castov in your terminal: Unix timestamps, ID detector (ObjectId, Snowflake, UUIDv7, ULID), cron explainer, IANA time zone converter with DST handling, UUIDs (v4/v7), Base64, hashes, and JWT decoding. Zero-server, zero-config.
