# cozyevent

> 标签: async, emit, emitter, event-emitter, eventemitter, events, fast, lightweight, microtask, off, on, once, pubsub, react, react-hook, tiny, typed, typescript, useCozyEvent

## 简介

Tiny (430 B min+gzip), fast, fully typed event emitter (sync + microtask async) with an optional one-hook React binding. Zero dependencies.
