# cellula-mcp

> 标签: agents, cell, ckb, mcp, naming, nervos, payments

## 简介

An MCP server that lets an AI agent work with .cell names on the Nervos blockchain: where a name is paid, which name an address has, whether a name is free, a link to register one (with an invitation), and whether a statement was signed by a name. Holds n
