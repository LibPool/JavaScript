# command-map-mcp

> 标签: ai, claude, command-map, korean, mcp, model-context-protocol, productivity, prompt-engineering, prompt-library, prompts

## 简介

AI 업무 필수 명령어 맵 MCP — 6개 도메인 120개 업무를 6-파트 템플릿(역할→목표→맥락→작업→출력→검증) 실전 프롬프트로 꺼내 쓰는 MCP 서버. An MCP server that turns 120 professional tasks across 6 domains into ready-to-run structured prompts.
