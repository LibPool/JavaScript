# chosen-jquery-browserify

> 标签: chosen, jquery, selection, ux, widget

## 简介

Chosen is a JavaScript plugin that makes long, unwieldy select boxes much more user-friendly. This version is a fork of the original, made grunt- and browserify- and npm-friendly

## 官网

- 源码仓库：https://github.com/banno/chosen
- npm 页面：https://www.npmjs.com/package/chosen-jquery-browserify
