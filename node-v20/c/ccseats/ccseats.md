# ccseats

> 标签: claude, claude-code, cli, multi-account, statusline, usage

## 简介

Run several Claude Code accounts side by side on macOS and Linux: shared plugins, skills and transcripts, per-account logins, a usage table, and a limit-aware seat picker.
