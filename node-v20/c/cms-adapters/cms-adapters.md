# cms-adapters

> 标签: admin-ui, cms, headless-cms, hono, schema, sdk, sqlite, type-safe, typescript

## 简介

A JSON-first, type-safe headless CMS engine that plugs into any project through adapters, with a framework-agnostic frontend SDK.
