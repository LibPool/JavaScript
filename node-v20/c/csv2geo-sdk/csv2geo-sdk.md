# csv2geo-sdk

> 标签: address, address-to-coordinates, batch-geocoding, coordinates, csv2geo, geocode, geocoding, geolocation, gis, lat-long, latitude, longitude, maps, places, reverse-geocoding

## 简介

Node.js SDK for CSV2GEO Geocoding API — 504M+ addresses, 63 countries, 48+ endpoints. Forward, reverse, batch, places, boundaries (postcode → polygon, ancestors walk-up, children walk-down, consolidated cities), IP geolocation with county overlay, vector
