# creo-create-tauri-app

> 标签: JavaScript

## 简介

CLI scaffolding tool for [Creo](../../README.md) + [Tauri v2](https://v2.tauri.app) cross-platform apps. Creates a ready-to-run desktop and/or mobile application with Creo as the UI framework.
