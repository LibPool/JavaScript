# cordova-plugin-impactlabs-mlkit

> 标签: Barcode Scanning, ML Kit, MRZ, OCR, PDF417, cordova-android, ecosystem:cordova

## 简介

An Android Cordova plugin that allows users to display call on native classes defined in other MLKit Projects.
