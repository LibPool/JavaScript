# cypress-ajv-schema-validator

> 标签: ajv, cypress, json, plugin, schema, validator

## 简介

Lightweight Cypress plugin for API schema validation against plain JSON schemas, Swagger schema documents, or OpenAPI schema documents, leveraging the core-ajv-schema-validator powered by the Ajv JSON Schema Validator.
