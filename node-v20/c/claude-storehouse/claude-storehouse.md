# claude-storehouse

> 标签: agents, ai, anthropic, claude, claude-code, cli, dashboard, developer-tools, hooks, mcp, plugins, skills

## 简介

A local web dashboard for your Claude Code setup. See, edit, switch on or off, and favorite every skill, agent, plugin, hook, MCP server, setting, and CLAUDE.md, global and per project.
