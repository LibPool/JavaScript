# cinderwright-mcp-server

> 标签: agent-payments, ai-agents, discovery, l402, lightning, mcp, mcp-server, mpp, usdc, x402

## 简介

Cinderwright Discovery Hub MCP Server + CLI. Cross-protocol agent payments: x402, L402 (Lightning), MPP. 2,834 services. Try: npx cinderwright "Bitcoin price"
