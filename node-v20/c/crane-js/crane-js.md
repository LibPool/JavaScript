# crane-js

> 标签: container, dependency injection, di, ioc, mongoose, mvc, repository

## 简介

Does the heavy lifting for a javascript application by providing a simple MVC environment (built on mongoose), favoring fluent configuration, along with an IoC Container, built-in repository pattern, and more
