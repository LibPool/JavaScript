# canvas-student-mcp

> 标签: canvas, canvas-lms, claude, education, instructure, lms, mcp, model-context-protocol, student

## 简介

MCP server for Canvas LMS that works even when your school disables API tokens — session-cookie auth, read-only by design. 30 tools for Claude and any MCP client.
