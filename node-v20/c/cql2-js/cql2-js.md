# cql2-js

> 标签: JavaScript

## 简介

A parser for the [Common Query Language (CQL2)](https://docs.ogc.org/is/21-065r2/21-065r2.html). See more details about the language [here](https://www.ogc.org/publications/standard/cql2/).
