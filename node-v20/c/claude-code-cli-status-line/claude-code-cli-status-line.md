# claude-code-cli-status-line

> 标签: claude, claude-code, cli, rate-limits, status-line, statusline, usage

## 简介

Cross-platform Claude Code status line: model, effort, context tokens and percent, session and weekly usage with reset countdowns, plus the model-specific weekly limit.
