> 标签: audio, dailymotion, dash, facebook, hls, media, player, react, react-component, soundcloud, streamable, twitch, video, vimeo, wistia, youtube

## 简介

A React component for playing a variety of URLs, including file paths, YouTube, Facebook, Twitch, SoundCloud, Streamable, Vimeo, Wistia and DailyMotion. Forked from https://github/CookPete/react-player.
