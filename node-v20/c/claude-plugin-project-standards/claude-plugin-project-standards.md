# claude-plugin-project-standards

> 标签: claude-code, claude-plugin, code-compliance, coding-standards, development-standards, project-standards

## 简介

让 Claude Code AI 助手自动遵循项目规范。支持全局和模块级规范，会话启动时自动加载，开发过程中智能应用，并提供代码规范检查功能。
