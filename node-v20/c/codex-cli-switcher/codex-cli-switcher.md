# codex-cli-switcher

> 标签: 9router, cli, cliproxy, codex, codex-cli, macos, openai

## 简介

A macOS command-line switcher for routing OpenAI Codex CLI between native ChatGPT, CLIProxyAPI, and 9Router backends.
