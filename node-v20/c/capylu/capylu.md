# capylu

> 标签: JavaScript

## 简介

基于 Rust 编写的交互式命令行脚手架工具，主要用于快速生成 Vue 项目的前端模板代码，并支持从远程 Swagger/OpenAPI 文档自动拉取并生成接口请求代码
