# create-reagent-app

> 标签: CLJS, ClojureScript, Frontend, React, Reagent, SPA, Shadow-CLJS, Webapp

## 简介

Bootstrap a ClojureScript frontend app that uses Reagent for the user interface and Shadow-CLJS as its build tool / compiler.
