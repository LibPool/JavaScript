# contentful-schema-kit

> 标签: cli, content-model, content-type, contentful, migration, sanity, schema

## 简介

A Sanity-style, typed, code-first content modeling toolkit and CLI for Contentful. Define content types in TypeScript and preview, validate, sync, and pull your Contentful content model.
