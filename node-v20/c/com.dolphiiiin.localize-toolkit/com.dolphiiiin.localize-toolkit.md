# com.dolphiiiin.localize-toolkit

> 标签: unity

## 简介

Localize Toolkitは、Cluster Creator Kitの多言語リソース機能の設定をアシストするためのツールです。
簡単なステップでTextコンポーネントにローカライズを設定することができます。
