# cterm-for-react

> 标签: component, react, term, term for react, term for web, terminal, terminal component, terminal for web, web, web terminal, xterm, xterm-for-react

## 简介

Web terminal for reactjs. I tried to develop this component working similar terminal, not for real. This terminal is just looks like terminal. It doesn't communicate other server or something like outside of broswer stuff.
