# core-globe

> 标签: 3d, globe, map, three.js, visualization, webgl

## 简介

Interactive 3D globe for the web — markers, arcs, flyTo, cinematic camera flyovers. Built on Three.js. Same renderer as the core-globe Android/KMM library.
