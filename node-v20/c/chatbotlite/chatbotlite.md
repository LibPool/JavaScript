# chatbotlite

> 标签: ai, anthropic, chatbot, customer-service, deepseek, drop-in, fallback, groq, litellm, llm, multi-provider, openai, react, sdk, small-business, sms, widget

## 简介

Drop-in AI chatbot SDK + React widget. Multi-LLM with fallback, business config, anti-hallucination guards. One import, one config — your site has a chatbot.
