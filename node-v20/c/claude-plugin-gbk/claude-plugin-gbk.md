# claude-plugin-gbk

> 标签: chinese, claude-code, claude-plugin, encoding, gb2312, gbk

## 简介

Claude Code 插件：GBK/UTF-8 编码自动切换。开启后 .txt/.ini/.cfg 文件读写自动在 GBK ↔ UTF-8 间转换，适用于传奇私服等 GBK 编码脚本项目。
