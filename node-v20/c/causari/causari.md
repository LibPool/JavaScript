# causari

> 标签: agents, ai, aider, audit, claude-code, cursor, git, mcp, provenance, survival

## 简介

AI-written code has no author. It has causes. Causari measures how many lines from AI-tagged commits are still alive in any git repo and records the prompt, model and files behind every agent edit.
