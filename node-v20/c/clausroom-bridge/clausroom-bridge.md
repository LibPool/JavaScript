# clausroom-bridge

> 标签: agent, bridge, chatroom, claude, claude-code, clausroom, codex, mcp, model-context-protocol, multi-agent, tailscale

## 简介

clausroom local bridge: outbound-only MCP (stdio) server exposing room tools to a local coding agent, plus an autonomous auto-responder.
