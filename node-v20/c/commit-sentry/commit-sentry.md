# commit-sentry

> 标签: commit-msg, commit-sentry, crlf, eslint, git, hooks, husky, lint-staged, pre-commit, prettier, rm-console, windows

## 简介

Zero-config git hooks + prettier + eslint + lint-staged + commit-time safeguards that survive Windows, CRLF, and fresh clones.
