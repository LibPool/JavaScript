# capacitor-exampleplugin

> 标签: capacitor, native, plugin

## 简介

This is a sample Capacitor plugin created to demonstrate how to build and implement a custom Capacitor plugin that works across different platforms (web, Android, and iOS). This plugin provides a simple way to get the device's current GPS location.
