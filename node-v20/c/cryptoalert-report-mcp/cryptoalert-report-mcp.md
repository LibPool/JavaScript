# cryptoalert-report-mcp

> 标签: blacklist, claude, compliance, cryptoalert, ethereum, mcp, model-context-protocol, tether, tron, usdt

## 简介

MCP server for cryptoalert.report — query USDT (Tether) and USDC (Circle) blacklist events, addresses, and Tether multisig signer history from any MCP client (Claude Desktop, Cursor, etc.).
