# canaryhook

> 标签: ai-agents, canary-token, claude-code, cli, exfiltration, honeyfile, honeytoken, mcp, prompt-injection, security

## 简介

Honeyfiles and canary tokens for AI coding agents. Plants decoy credentials your agents should never touch, then trips on any read or exfiltration.
