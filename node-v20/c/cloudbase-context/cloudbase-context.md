# cloudbase-context

> 标签: cloudbase, js-sdk, 云数据库, 小程序, 腾讯云开发

## 简介

腾讯云开发云数据库统一管理工具包，之前全局前、后置处理请求所携带的信息，分离业务以及请求代码相关。方便后续开发容错，随时做处理。
