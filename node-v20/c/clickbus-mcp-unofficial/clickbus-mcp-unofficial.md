# clickbus-mcp-unofficial

> 标签: ai-agents, bus, clickbus, local-first, mcp, model-context-protocol, tickets

## 简介

Unofficial local-first ClickBus MCP for place search, trip prices and booking history. Never pays unless CLICKBUS_ALLOW_MUTATIONS and explicit_user_intent are both set.
