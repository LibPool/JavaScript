# claude-code-sound-alert

> 标签: audio-ducking, claude-code, cli, hooks, macos, notification, sound, windows

## 简介

Audio ducking notifications for Claude Code — lowers your music/movie volume, plays a clear alert, then restores. With retry polling for unattended permission prompts.
