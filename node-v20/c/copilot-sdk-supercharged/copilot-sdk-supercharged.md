# copilot-sdk-supercharged

> 标签: agent, ai, copilot, github, jsonrpc, llm, sdk, supercharged, tools

## 简介

GitHub Copilot SDK Supercharged - TypeScript SDK for programmatic control of GitHub Copilot CLI via JSON-RPC. Supports 40 languages.
