# cloud-upload-hub

> 标签: cloud, cloud-storage, cos, file-upload, multi-cloud, oss, upload

## 简介

支持将文件同时上传至单个或者多个云存储服务，当前支持阿里云 OSS 和腾讯云 COS，支持扩展到更多云服务。
