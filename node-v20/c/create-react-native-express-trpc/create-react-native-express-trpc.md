# create-react-native-express-trpc

> 标签: express, expressjs, node, nodejs, npx, react, react-native, trpc

## 简介

Scaffold a vanilla react-native, expressjs, and trpc app with this command npx create-react-native-express-trpc, updated regularly. For those who want simplicity in their codebase.
