# corpus-agent-wallet-plugin

> 标签: agent-wallet, compute, corpusai, kuru, metamask, monad, oclif-plugin, orderbook, x402

## 简介

MetaMask Agent Wallet plugin for corpusAI on Monad: buy cloud and GPU prices over x402 in USDC, read the on-chain compute price oracle, mint or redeem permanently funded compute tokens, and trade them on Kuru, every signature and transaction through the A
