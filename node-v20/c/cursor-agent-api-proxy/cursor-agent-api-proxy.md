> 标签: agent, ai, api-server, cursor, cursor-cli, llm, openai-compatible, openclaw, proxy

## 简介

Use your Cursor subscription with any OpenAI-compatible client. Wraps Cursor CLI (agent) as an OpenAI-compatible API server.
