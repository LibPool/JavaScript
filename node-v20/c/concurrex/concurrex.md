# concurrex

> 标签: adaptive, aqm, backpressure, concurrency, executor, fairness, lanes, load-shedding, prodel, queue, rate-limiting

## 简介

Fully adaptive task executor. Self-regulates concurrency limits, sheds load under pressure, and schedules fairly across lanes — no manual tuning, no environment-specific configuration.
