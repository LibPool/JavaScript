# cache-lib

> 标签: cache, expire, localstorge, sessionstorage, storage

## 简介

cache.js 是一个轻量级的 JS 库，对 `localStorage`、`sessionStorage`进行了扩展，增加了序列化方法和过期时间。可以直接存取JSON对象、设置过期时间。
