# create-artubeplate

> 标签: artube, artubeplate, create, igaming, pixijs, rgs, scaffold, slot, slots

## 简介

Scaffold an Artube RGS slot game on @artubeplate/core — `npm create artubeplate@latest`, optionally with your own math (`-- --math ./path`).
