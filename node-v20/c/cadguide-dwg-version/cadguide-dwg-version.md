# cadguide-dwg-version

> 标签: ac1027, ac1032, autocad, bim, cad-inspector, cad-tools, cadguide, dwg, dwg-version, dxf

## 简介

Zero-dependency AutoCAD DWG binary magic bytes inspector and version identification matrix (AC1009 to AC1032), maintained by CADGuide.tools.
