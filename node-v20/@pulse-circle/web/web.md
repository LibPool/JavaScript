# @pulse-circle/web

> 标签: analytics, events, offline-first, pulse, tracking, utm, web analytics

## 简介

Pulse analytics for the browser: a ≤10 KB, zero-dependency SDK with a persistent offline queue, idempotent delivery, and identity. Add analytics to your web app in two lines.
