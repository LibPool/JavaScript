# @huyz0/ztui

> 标签: ansi, bun, canvas, cli, ink, react, react-reconciler, terminal, textual, tui, widgets

## 简介

Declarative, React-based TUI framework for TypeScript and Bun — one widget tree, terminal and browser-canvas backends.
