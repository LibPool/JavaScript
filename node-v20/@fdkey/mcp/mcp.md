# @fdkey/mcp

> 标签: ai-agent, anti-bot, captcha, cloudflare-workers, edge, fdkey, mcp, middleware, model-context-protocol, verification

## 简介

FDKEY verification middleware for MCP servers — gate AI-agent access behind LLM-only puzzles. Runs on Node 18+, Cloudflare Workers, Bun, and Deno.
