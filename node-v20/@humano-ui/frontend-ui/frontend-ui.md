# @humano-ui/frontend-ui

> 标签: humano, mui, presets, react, ui

## 简介

Presets de UI compartidos para los dominios infoplan-*-web: barra de consulta, tablas, inputs, toolbars, LOVs, navegación, acciones, diálogos, feedback, layout de registro, carga de archivos y tema (marca y densidad)
