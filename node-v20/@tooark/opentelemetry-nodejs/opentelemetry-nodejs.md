# @tooark/opentelemetry-nodejs

> 标签: auto-instrumentation, logs, metrics, monitoring, nodejs, observability, opentelemetry, otel, tracing, typescript

## 简介

Pacote para configuração automática do OpenTelemetry em aplicações Node.js usando TypeScript. Ele fornece uma maneira fácil de configurar o OpenTelemetry com opções personalizáveis, permitindo que os desenvolvedores instrumentem suas aplicações sem a nece
