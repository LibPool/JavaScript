# opencode-forgekeeper

> 标签: code-review, forge, github, gitlab, merge-request, opencode, opencode-plugin, pull-request, session, title

## 简介

OpenCode plugin that tracks each session's GitHub and GitLab issues and PRs/MRs: title prefixes, a PR/MR status footer, and review notifications
