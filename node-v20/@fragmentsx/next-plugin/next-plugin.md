# @fragmentsx/next-plugin

> 标签: JavaScript

## 简介

Плагин для хоста на Next 16 (App Router, Turbopack): компилируемые фрагменты работают на React хоста. Симметричен `@fragmentsx/vite-plugin` — «плагин в конфиге и компонент в layout».
