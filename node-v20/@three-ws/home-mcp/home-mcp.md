# @three-ws/home-mcp

> 标签: agent, home-assistant, iot, mcp, model-context-protocol, smart-home, three.ws

## 简介

Give any MCP assistant safe control of a real Home Assistant house: floors, rooms and live state, the household's own scenes, and service calls behind a physical-action gate that refuses anything which opens the house.
