# @three-ws/x402-preflight

> 标签: agent, agent-payments, attestation, base, ed25519, micropayments, preflight, reliability, solana, three.ws, usdc, x402

## 简介

Ask an x402 seller whether it can actually settle, before you sign anything. Fetches and verifies a signed, time-bounded payability attestation, then routes you to a rail that works. The missing reliability layer for agent payments.
