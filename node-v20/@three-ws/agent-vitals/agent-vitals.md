# @three-ws/agent-vitals

> 标签: agent, ai-agent, attestation, autonomous, capability, health-check, healthcheck, liveness, monitoring, observability, readiness, root-cause, sre, three.ws

## 简介

Capability attestation for autonomous agents. Not "is it up" but "can it act": model an agent's preconditions as a causal graph, get back the root blocker and the command that fixes it.
