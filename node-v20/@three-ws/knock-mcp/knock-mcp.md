# @three-ws/knock-mcp

> 标签: agent-to-human, attention, knock, mcp, solana, three.ws, usdc, x402

## 简介

Let an agent reach a real person. Read what someone charges for one message, browse every open door, knock, and read the reply. Paid doors are quoted, never auto-paid: this server holds no wallet.
