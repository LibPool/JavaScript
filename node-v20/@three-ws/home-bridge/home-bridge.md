# @three-ws/home-bridge

> 标签: 3d, agent, home-assistant, iot, mcp, model-context-protocol, smart-home, three.ws, voice

## 简介

Connect a three.ws agent to a real Home Assistant instance: live entity state, safe service calls, a room graph for the 3D scene, and the optional Model Context Protocol capability channel.
