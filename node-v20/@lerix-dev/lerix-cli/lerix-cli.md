# @lerix-dev/lerix-cli

> 标签: cli, crash-reporting, error-tracking, lerix, source-maps, sourcemaps

## 简介

Lerix command line tool. `npx @lerix-dev/lerix-cli upload` uploads your web build's source maps so Lerix shows errors at the exact file and line of your original code.
