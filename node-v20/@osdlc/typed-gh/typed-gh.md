# @osdlc/typed-gh

> 标签: cli-wrapper, dependency-injection, gh, github, pull-request, typescript

## 简介

A typed GitHub client for TypeScript over the gh CLI. A total PullRequest/Review/CheckRun model, pure argv builders and parsers, and a tri-modal client — queries return parsed values, mutations throw, raw() is the escape hatch. Uses gh's own credentials;
