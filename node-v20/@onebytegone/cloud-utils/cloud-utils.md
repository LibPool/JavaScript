# @onebytegone/cloud-utils

> 标签: JavaScript

## 简介

A CLI toolkit for common AWS operations. Provides commands for interacting with DynamoDB, Lambda, SQS, and Step Functions; including querying and scanning tables, invoking functions, managing messages, and running state machine executions.
