# @haksanlulz/mcp-fairrent

> 标签: affordable-housing, ai, civic-tech, crosswalk, fair-market-rent, housing, hud, income-limits, lihtc, llm, mcp, model-context-protocol, section-8

## 简介

MCP (Model Context Protocol) server for HUD housing data: Fair Market Rents (per area or statewide), Section 8 income limits, LIHTC/MTSP income bands, computed affordability verdicts, and the USPS ZIP-to-jurisdiction crosswalk in both directions.
