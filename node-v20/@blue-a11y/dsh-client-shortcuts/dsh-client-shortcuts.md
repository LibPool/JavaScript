# @blue-a11y/dsh-client-shortcuts

> 标签: JavaScript

## 简介

Global keyboard shortcuts plugin for the DeepSeek Harness web GUI: ctx.shortcuts registry service, rebindable settings page, and default mod+l/mod+k/mod+shift+c bindings
