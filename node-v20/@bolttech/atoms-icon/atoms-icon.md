# @bolttech/atoms-icon

> 标签: JavaScript

## 简介

The `Icon` component is based on the [Material Symbols](https://fonts.google.com/icons?icon.style=Sharp&icon.set=Material+Symbols) icons. It includes all the icons with the **weight of 300**.
