# @bolttech/ob-molecules-date-input

> 标签: JavaScript

## 简介

A split date input molecule with optional calendar (datepicker). It renders three numeric fields (`DD`, `MM`, `YYYY`) and **emits a single controlled value** in the `YYYY-MM-DD` format.
