# @gaganalakruwan/react-native-tournament-bracket

> 标签: bracket, bracket-view, react-native, sports, tournament

## 简介

A customizable tournament bracket view for React Native. Supports bracket sizes of 4, 8, 16, and 32 teams (powers of 2).
