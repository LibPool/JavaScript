# @blockrun/mcp

> 标签: ai, anthropic, blockrun, claude, gemini, llm, mcp, micropayments, model-context-protocol, openai, x402

## 简介

BlockRun MCP Server - Give your AI agent web search, deep research, prediction markets, and crypto data. Pay per call from a USDC wallet (Solana or Base) or a BlockRun API key.
