# @harbymail/dm-breadcrumb

> 标签: breadcrumb, uni-app, uniapp, vue, 导航, 面包屑

## 简介

面包屑导航组件，支持路由模式和非路由模式，支持自定义分隔符、颜色、滚动动画等
