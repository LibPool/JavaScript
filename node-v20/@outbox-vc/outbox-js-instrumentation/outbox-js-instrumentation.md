# @outbox-vc/outbox-js-instrumentation

> 标签: JavaScript

## 简介

This package bootstraps OpenTelemetry tracing and logging for Node.js services, pre-configured for SigNoz. It instruments HTTP, BullMQ queues, and Winston logs, etc. automatically — zero boilerplate in your application code.
