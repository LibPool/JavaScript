# @tsdotnet/linq

> 标签: aggregate, enumerable, es2015, filter, filters, group by, group-by, groupBy, iterable, iterables, iterator, iterators, linq, map, order by, order-by, orderBy, reduce, resolutions, resolve, select, transforms, where

## 简介

A familiar set of functions that operate on JavaScript iterables (ES2015+) in a similar way to .NET's LINQ does with enumerables.
