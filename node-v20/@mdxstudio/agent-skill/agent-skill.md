# @mdxstudio/agent-skill

> 标签: agent-skills, agents.md, claude-code, cli, codex, cursor, documentation, mdx

## 简介

Installs the mdx-docs authoring skill and the standing documentation policy into any coding agent's instruction file (AGENTS.md, CLAUDE.md, GEMINI.md, ...).
