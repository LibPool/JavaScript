# @fil-technology/pushes-mcp

> 标签: JavaScript

## 简介

`@fil-technology/pushes-mcp` exposes Pushes Cloud as a local stdio MCP server for tools such as Claude Desktop, Cursor, and other MCP-compatible clients.
