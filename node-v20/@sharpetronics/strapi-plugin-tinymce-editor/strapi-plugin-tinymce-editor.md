# @sharpetronics/strapi-plugin-tinymce-editor

> 标签: editor, rich text, strapi, tiinymce, tinymce 6, wysiwyg

## 简介

Replaces the default Strapi WYSIWYG editor with a self-hosted build of the TinyMCE editor.
