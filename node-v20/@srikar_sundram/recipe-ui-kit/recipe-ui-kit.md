# @srikar_sundram/recipe-ui-kit

> 标签: custom-elements, recipe-finder, stencil, web-components

## 简介

Reusable StencilJS web-component library (recipe card, search bar, filter chips, meal-plan slot, modal, recipe form) built for the Recipe Finder & Meal Planner SvelteKit app.
