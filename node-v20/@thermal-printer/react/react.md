# @thermal-printer/react

> 标签: JavaScript

## 简介

React components and hooks for @thermal-printer/core + @thermal-printer/transports: <Receipt/> and usePrinter() for ESC/POS thermal, browser print, PDF, PNG/JPG and Excel output from one data schema.
