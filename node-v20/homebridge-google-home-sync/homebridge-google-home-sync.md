# homebridge-google-home-sync

> 标签: automation, device-sync, google-assistant, google-home, homebridge-plugin, homegraph, homekit, iot, ip-cameras, smart-home, smart-lights, smart-switches

## 简介

Homebridge plugin to automatically import and sync all Google Home devices to HomeKit, supporting lights, switches, cameras, sensors, and more from any manufacturer
