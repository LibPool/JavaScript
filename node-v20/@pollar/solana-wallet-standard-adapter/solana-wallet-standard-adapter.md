# @pollar/solana-wallet-standard-adapter

> 标签: JavaScript

## 简介

Solana Wallet Standard adapter for @pollar/core - connect user-controlled Solana wallets (Phantom, Solflare, Backpack, ...) via the Wallet Standard (@wallet-standard/* + @solana/wallet-standard-features), with SIWS login, without bundling any wallet SDK i
