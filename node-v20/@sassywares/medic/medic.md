> 标签: css, css-in-js, plugin, preset, tailwindcss

## 简介

Medic 🚑 is a minimal Tailwind Plugin that brings consistent, cross-breakpoint utilities to your applications. No need to set random padding and margin values, Medic's ergonomic API (stuff like p-layout) makes it easy to create consistent layouts across y
