# @sfroment/pi-herdr

> 标签: cli, herdr, multiplexer, pi-extension, pi-package, terminal

## 简介

Pi extension for the Herdr CLI — control workspaces, tabs, panes, and coding agents via a typed tool (direct CLI, requires HERDR_ENV=1).
