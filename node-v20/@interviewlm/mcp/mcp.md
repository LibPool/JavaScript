# @interviewlm/mcp

> 标签: hiring, interviewlm, mcp, oauth, stdio

## 简介

stdio MCP shim for InterviewLM — bridges stdio-only clients (Codex, Copilot, Claude Desktop) to the InterviewLM remote MCP server via OAuth 2.1 + PKCE
