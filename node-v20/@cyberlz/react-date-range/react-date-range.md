# @cyberlz/react-date-range

> 标签: calendar, date-picker, date-range, range-picker, react

## 简介

Modern maintained fork/rescue of react-date-range. Stable 1.4.x — responsive fluid calendars, configurable input popovers, UI slots, tokens, accessibility and RTL support.
