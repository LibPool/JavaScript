# @arcpx-org/sad

> 标签: csv-diff, diff, json-diff, merkle-tree, myers-diff, pdf-diff, text-diff

## 简介

Compares two files (JSON, CSV, TXT, PDF) and reports what changed, using a Merkle tree filter plus Myers diff for word-level detail.
