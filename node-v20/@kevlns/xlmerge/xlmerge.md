# @kevlns/xlmerge

> 标签: excel, git, merge-conflict, xlsm, xlsx

## 简介

Formula-aware visual resolver for unresolved Git merge conflicts in .xlsx/.xlsm workbooks: three-way sheet/row/cell diff, local UI, atomic write-back and commit.
