# @encoradb/prisma

> 标签: database, encryption, field-level-encryption, prisma, prisma-extension, security, typescript

## 简介

First-class **Prisma Client Extension** (`$extends`) for **EncoraDB**. Transparently encrypts sensitive fields on Prisma write operations and decrypts fields on read operations.
