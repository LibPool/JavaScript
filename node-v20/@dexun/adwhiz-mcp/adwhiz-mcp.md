# @dexun/adwhiz-mcp

> 标签: ad-management, claude, cursor, google-ads, mcp, meta-ads, model-context-protocol, tiktok-ads

## 简介

MCP server that lets Claude Desktop / Cursor talk to your DEXUN AdWhiz account. Lists ad accounts, surfaces AI recommendations, reports savings — all through your existing API key.
