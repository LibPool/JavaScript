# @zuminternet/sprite

> 标签: JavaScript

## 简介

SVG 파일들을 하나의 스프라이트로 결합하는 CLI 도구입니다. 이 도구를 사용하면 여러 SVG 파일을 하나의 스프라이트 파일로 최적화하고, SVG 아이콘 관리를 간소화할 수 있습니다.
