# @vdhewei/image-lib

> 标签: bun, canvas, crop, image, napi-rs, stamp, typescript, watermark

## 简介

基于 @napi-rs/canvas 的轻量图片处理库：动态文本印章生成 + 透明背景抠图，支持远程/本地/系统字体
