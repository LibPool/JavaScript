# @privos_ai/agent-harness

> 标签: acp, agent-client-protocol, cli, harness, privos

## 简介

Bridge CLI that pairs a PrivOS hub agent with a locally running ACP coding agent (Claude Code, Codex, Cursor, Goose, or a custom command).
