# @ecgear/fitimage

> 标签: batch, cli, compress, compression, convert, cross-platform, image, jpeg, jpg, mozjpeg, optimize, optimizer, png, sharp, webp

## 简介

Cross-platform batch image compressor with an interactive mode — shrink and convert between JPG/WebP/PNG/GIF, powered by sharp. No deprecated dependencies, no GPL codecs.
