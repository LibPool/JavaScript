# @port0.sh/sdk

> 标签: amm, constant-product, dex, miden, typescript, uniswap-v2, xyk

## 简介

TypeScript SDK for the port0.sh constant-product AMM. Builds XYK network notes, fee sponsorships, quotes, pool reads, and pool operations on top of @miden-sdk/miden-sdk.
