# @mahmulp/feedback-sdk

> 标签: annotation, comments, design-review, feedback, prototype, qa, screenshot, self-hosted, svelte

## 简介

Framework-agnostic visual feedback SDK for prototypes. Pin comments to UI elements, with stable DOM selectors plus screenshot capture. Svelte primary; works in React, Vue, and plain HTML.
