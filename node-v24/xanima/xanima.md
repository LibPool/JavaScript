> 标签: agent-continuity, agent-memory, ai-memory, claude, claude-code, cursor, fsrs, knowledge-graph, llm, long-term-memory, mcp, memory, model-context-protocol, multi-agent, openclaw, spaced-repetition, sqlite, vector-search, xanima

## 简介

Xanima: a portable agent continuity layer. An MCP server that remembers across sessions, tracks what it believes and how sure it is, forgets what stops mattering, and consolidates the rest. Works with OpenClaw, Claude Code, Cursor, and any MCP client.
