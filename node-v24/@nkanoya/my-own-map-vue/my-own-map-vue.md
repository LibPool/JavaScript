# @nkanoya/my-own-map-vue

> 标签: annotation, image-map, map, pan, primevue, vue, vue3, zoom

## 简介

Self-rolled PrimeVue-flavored image-map component for Vue 3 — any image, pan/zoom, pixel-space annotations with per-level zoom gating.
