# @samebase/alchemy-cloudflare-workers

> 标签: alchemy, cloudflare, effect, infrastructure-as-code, workers, workers-builds

## 简介

Alchemy v2 resources for Cloudflare Workers Builds: a Worker whose code Workers Builds deploys, the repository connection, the triggers, the build variables, and the Worker secrets.
