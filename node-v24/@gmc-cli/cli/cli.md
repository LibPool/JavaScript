# @gmc-cli/cli

> 标签: ci-cd, cli, content-api-migration, content-api-shopping, devops, ecommerce, feed-validation, feed-validator, google-merchant-center, google-shopping, google-shopping-feed, merchant-api, merchant-api-migration, merchant-center-next, preflight, product-feed, typescript

## 简介

Free, open-source CLI for the Google Merchant API. Migrate off the retired Content API, diagnose silent setup failures (gmc doctor), and preflight feeds offline to catch disapprovals before upload — typed, --json, CI-native. Provides the gmc command.
