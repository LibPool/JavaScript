# @well-played.gg/component-sdk

> 标签: JavaScript

## 简介

A lightweight SDK for building **Web Components** that run inside the WellPlayed platform. It provides a base custom element class (`WpElement`) with a built-in platform bridge for GraphQL, events, routing, theming, and user context, plus tagged-template
