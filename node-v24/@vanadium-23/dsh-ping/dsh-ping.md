# @vanadium-23/dsh-ping

> 标签: attention, cordis, deepseek-harness, dsh, notification, toast, windows

## 简介

Desktop notifications for DeepSeek Harness: a Windows toast (plus console line and optional webhook) the moment a turn finishes, an agent errors, or the agent is waiting on your approval or answer
