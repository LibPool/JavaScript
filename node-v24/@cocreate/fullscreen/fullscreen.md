# @cocreate/fullscreen

> 标签: collaboration, fullscreen, html5-framework, javascript-framework, low-code, realtime, realtime-framework, shared-editing

## 简介

Toggle any html element to view in fullscreen mode. Easy configuration and targeting using the fullscreen and target attribute.
