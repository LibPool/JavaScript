# @cocreate/crud-server

> 标签: cockroachdb, database-router, distributed-database, dynamodb, ferretdb, firestore, mariadb, mongodb, multi-database, multi-tenant-crud, mysql, oracle-db, parallel-writing, planetscale, postgresql, realtime-sync, redshift, sqlite, timescaledb, turso

## 简介

High-performance, multi-tenant server-side CRUD orchestration engine supporting parallel multi-database writing, real-time sync, and tenant-isolated data routing across 20+ database engines.
