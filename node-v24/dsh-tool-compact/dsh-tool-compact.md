# dsh-tool-compact

> 标签: agent-tool, compact, context, deepseek-harness, dsh-plugin

## 简介

DeepSeek Harness 插件：给模型一个可自行调用的 compact 工具，在它准备开启新项目或新步骤时当场压缩较早的历史，并把摘要作为工具结果返回。
