# @insession/space-state

> 标签: presence, realtime, reducer, state, store, sync

## 简介

transport/フレームワーク非依存のスペース状態 store。受信は純粋 reducer、送信は onSend に流すだけ。副作用（音/通知/タイマー/送信）は effects 記述子で返し、実行は消費者（useSpace）が担う
