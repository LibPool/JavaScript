# @lssm-tech/lib.voiceops-runtime

> 标签: JavaScript

## 简介

Canonical run engine for CompanyOS VoiceOps. Turns a transcript into a redacted, policy-checked, approval-aware run record plus a 16-key evidence receipt with a stable SHA-256 replay hash.
