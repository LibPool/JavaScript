# @pxlkit/core

> 标签: 16bit, 8bit, animated-icons, design-system, icon-library, icon-renderer, icon-toolkit, icons, mit-license, parallax-3d, pixel-art, pixel-art-icons, pixel-art-react, pxlkit, react, react-components, react-icons, retro, retro-ui, svg, svg-icons, toast-notifications, tree-shakeable, typescript

## 简介

Core rendering engine, React components, SVG utilities, and TypeScript types for the Pxlkit pixel art toolkit — tree-shakeable icon renderer, animated icon player, 3D parallax icons, toast notifications, and color utilities
