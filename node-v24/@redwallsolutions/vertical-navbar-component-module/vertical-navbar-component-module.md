# @redwallsolutions/vertical-navbar-component-module

> 标签: material bar, menu, navbar, vertical navbar

## 简介

Vertical Navbar is a react component that creates a vertical navbar in the left side of the page. It behaves completely responsive when accessing it in small devices transforming the vertical navbar to a horizontal navbar at the bottom of the page.
