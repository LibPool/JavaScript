# @wingsky-1/dsh-worktree-sidebar

> 标签: deepseek-harness, dsh, git, plugin, sidebar, worktree

## 简介

把某个 git worktree 登记给当前会话，使该会话的官方右侧栏文件树根指向该 worktree；会话 cwd 不变。官方提供原生 worktree 会话能力即退役的过渡适配层。
