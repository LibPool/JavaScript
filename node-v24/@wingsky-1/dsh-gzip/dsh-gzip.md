# @wingsky-1/dsh-gzip

> 标签: deepseek-harness, dsh, gzip, plugin

## 简介

DSH Web GUI 的 /api 响应 gzip 压缩插件：为远程/低带宽链路开启 /api 响应压缩，解决大响应无压缩导致的会话历史加载超时失败
