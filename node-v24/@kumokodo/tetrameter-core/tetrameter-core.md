# @kumokodo/tetrameter-core

> 标签: carbon, ghg-protocol, green-software, llm, sci, sustainability

## 简介

Tetrameter — four measures of AI inference: energy, carbon, water and land, plus cost. Reference implementation of the Green Software Foundation SCI for AI specification. Every number carries an evidence tier, an uncertainty range and its sources.
