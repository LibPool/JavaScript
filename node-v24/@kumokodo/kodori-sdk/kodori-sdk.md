# @kumokodo/kodori-sdk

> 标签: aec, ai, anthropic, claude, dms, document management, kodori, kumokodo, legal tech, mcp, model context protocol

## 简介

Official TypeScript SDK for Kodori — REST API wrapper plus Model Context Protocol client helpers. Authenticate once with a Kodori API key and call documents, collections, search, and the public MCP catalog with typed methods.
