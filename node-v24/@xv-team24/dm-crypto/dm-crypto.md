# @xv-team24/dm-crypto

> 标签: JavaScript

## 简介

V-TAMP DM（ダイレクトメッセージ）用の暗号化パッケージです。 [TweetNaCl](https://tweetnacl.js.org/) をベースに、XSalsa20-Poly1305 対称暗号化と Curve25519 ECDH 鍵交換を提供します。
