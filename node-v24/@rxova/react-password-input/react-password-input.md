# @rxova/react-password-input

> 标签: a11y, accessible, autocomplete, caps-lock, headless, new-password, password, password-field, password-input, password-meter, password-strength, react, reveal-password, show-password, strength-meter, zero-dependency, zxcvbn-free

## 简介

Reveal toggle, Caps Lock warning, and a strength meter that costs 1 kB instead of 400. A headless, zero-dependency React password input.
