# @rxova/react-time-input

> 标签: 12-hour, 24-hour, a11y, accessible, clock, headless, intl, iso-time, react, segmented, time, time-entry, time-field, time-input, time-picker, zero-dependency

## 简介

A segmented, keyboard-first time field with no clock popup and no date library. 12/24-hour from Intl. Headless, zero-dependency.
