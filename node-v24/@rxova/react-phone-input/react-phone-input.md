# @rxova/react-phone-input

> 标签: a11y, accessible, country-code, country-selector, e164, headless, international, international-phone, intl, msisdn, no-metadata, phone, phone-input, phone-number, react, tel, telephone, zero-dependency

## 简介

International phone input with no metadata blob: country names from Intl, flags from Unicode, 4 kB of dial codes. Headless, zero-dependency.
