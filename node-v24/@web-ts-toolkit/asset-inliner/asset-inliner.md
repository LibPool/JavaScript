# @web-ts-toolkit/asset-inliner

> 标签: asset, base64, css, data-url, esm, font, html, image, inliner, typescript

## 简介

Generic asset inliner for CSS and HTML — ESM-only Node 22+ Base64 data URL encoding, CSS url() and font source formatting, deterministic catalog and inlining pipeline
