# @zoffwallet/sdk

> 标签: canton, cip-0103, provider, wallet, zoff

## 简介

Reference implementation of @zoffwallet/provider-interface. Browser SDK that translates the canonical CantonWalletProvider contract into HTTP calls against the Zoff wallet backend, with cross-origin popup approval.
