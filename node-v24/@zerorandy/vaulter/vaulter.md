# @zerorandy/vaulter

> 标签: b2, backblaze, cloudflare, media, minio, private-bucket, proxy, r2, s3, storage

## 简介

Server-side file storage library for S3-compatible providers (Backblaze B2, Cloudflare R2, MinIO, AWS S3) with private bucket + proxy pattern.
