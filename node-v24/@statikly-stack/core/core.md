# @statikly-stack/core

> 标签: JavaScript

## 简介

No hassle full stack framework, for blog/static/content sites, amazing for prototype and build internal tools and seo optimize. Provide alternative for writing frontend "the old way", more and more hype is growing on server side ui, like next.js and remix
