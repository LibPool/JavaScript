# @layoutit/polycss-fonts

> 标签: 3d, css, extrude, font, matrix3d, opentype, polycss, text, truetype, ttf

## 简介

Turn fonts + text into extruded 3D polygon meshes for PolyCSS. Framework-agnostic — returns Polygon[].
