# @mcp-b/global

> 标签: ai-agents, ai-assistant, ai-integration, ai-tools, anthropic, browser, browser-ai, chatgpt, chromium, claude, copilot, cursor, gemini, iife, llm, mcp, model-context-protocol, navigator-modelcontext, openai, polyfill, tool-registration, w3c, web-ai, web-model-context, web-standard, webmcp

## 简介

W3C Web Model Context Protocol (WebMCP) API polyfill. Let AI agents like Claude, ChatGPT, and Gemini interact with your website via document.modelContext.
