# @immediately-run/verify-checks

> 标签: JavaScript

## 简介

Deterministic quality checks shared by the immediately.run core repos: clones (jscpd), unused exports (knip), untested logic (git merge-base + Untested trailers), dead CSS. Baselines are fingerprint sets that only shrink.
