> 标签: JavaScript

## 简介

``` let a = {x:1,y:{a:2}}; let b = {x:3,y:{a:4}}; let oldY = b.y; mergeTo(a,b); console.log(b.y.a) // 4 console.log(oldY === b.y) // true ```
