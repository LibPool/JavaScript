# @dhcckb/mcp-server-douban

> 标签: bibliography, book, citation, douban, mcp, reference

## 简介

通过豆瓣数据自动补全书籍元数据并按多规范生成参考文献格式的 MCP Server。新增豆瓣读书关键词搜索、ISBN 精确定位和详情页信息提取功能。
