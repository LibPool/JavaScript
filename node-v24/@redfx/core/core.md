# @redfx/core

> 标签: effect, effect-ts, redis, schema, stream, typescript

## 简介

Ergonomic Effect-native Redis core: typed commands, Schema-typed keys, pub/sub as Stream, Lua scripts, over a driver-agnostic send-level port.
