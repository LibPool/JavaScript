# @cap-js/data-privacy

> 标签: CAP, cds, cdsbuild

## 简介

CDS plugin providing an integration with the SAP Data Privacy Integration service for PII data retention and information retrieval based on annotations.

- 官网：https://cap.cloud.sap/
- 源码仓库：git+https://github.com/cap-js/data-privacy.git
