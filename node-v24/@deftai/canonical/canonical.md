# @deftai/canonical

> 标签: agent-workflow, agents-md, ai-agent, briefs, claude, task-runner

## 简介

The canonical pack: a compact, deterministic agent-workflow framework -- xBRIEF-based state, deterministic CLI verbs, fail-closed git gates. Install globally, run `canon init` in any project.
