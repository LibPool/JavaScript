# @l1yp/file-viewer

> 标签: archive, component, document-viewer, docx, file-preview, file-viewer, hex, office, pdf, pptx, vue, vue3, xlsx

## 简介

In-browser file viewer for 60+ formats (office / archives / images / code / …) as a Vue 3 component. Bytes never leave the browser.
