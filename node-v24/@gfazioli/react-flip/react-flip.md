# @gfazioli/react-flip

> 标签: 3d, animation, card, css-modules, flip, headless-friendly, react, react-component, transition, typescript

## 简介

Flip is a React component that wraps any two faces and animates a 3D rotation between them — accessible, themeable via CSS variables, zero runtime dependencies.
