> 标签: a11y, captions, component, extension, fullscreen, html5-video, mantine, mantine-ui, mantine-v9, media-player, picture-in-picture, playback, react, react-component, react-video, react-video-player, typescript, video, video-player

## 简介

A customizable video player component for React built with Mantine. Compound API in Mantine ecosystem style, headless useVideo hook, theme-aware styling, accessibility, and full Styles API.
