# @rafinery/retrieval

> 标签: mrr, rafinery, ranking, recall, retrieval

## 简介

The retrieval plane — rafa's deterministic lexical scorer, the typed knowledge graph it walks, the entry-point router, rank fusion, and the retrieval-quality metrics (recall@k, MRR) that gate all of it. Pure functions, no I/O, zero dependencies.
