# @webpieces/docs-site

> 标签: docs, openapi, static-site, typescript, webpieces

## 简介

Render a static, three-pane API reference site from any OpenAPI 3.0-or-3.1 document plus a directory of markdown prose. Node builtins only. Ships the wp-docs-site bin.
