# @vhyxchart/core

> 标签: animation, diagram, flowchart, sequence-diagram, svg, vhyxara, vhyxchart

## 简介

VhyxChart engine — parse Markdown-friendly diagram text, lay it out, and render animated SVG. Zero dependencies, works in Node and the browser.
