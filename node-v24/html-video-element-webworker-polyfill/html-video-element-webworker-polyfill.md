# html-video-element-webworker-polyfill

> 标签: canvas, frame-extraction, html5-video, htmlvideoelement, multithreading, off-main-thread, offscreencanvas, polyfill, video, video-processing, videoframe, web-worker, webcodecs, webgl, webgpu, webworker, worker

## 简介

HTMLVideoElement inside Web Workers: a main-thread <video> mirrored into the worker with synchronous state, events and VideoFrames, plus Canvas 2D / WebGL / WebGPU polyfills.
