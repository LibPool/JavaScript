# crowdmemory-runtime

> 标签: agent-memory, crowdmemory, deepseek-harness, dsh

## 简介

Crowd Memory local memory Runtime (Python) and its two default templates, delivered through npm: verified offline install into a private venv, host config and user-service file for the DSH adapter.
