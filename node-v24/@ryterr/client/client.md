# @ryterr/client

> 标签: ai, blog, content-api, headless-cms, nextjs, ryterr, webhook

## 简介

TypeScript client for the Ryterr Content API and webhooks. Auto-publish AI-generated blog posts to any JavaScript or TypeScript site.

- 官网：https://ryterr.com/integrations
- npm 页面：https://www.npmjs.com/package/@ryterr/client
