# @kunal_dutt/token-lens

> 标签: claude, cost, gateway, gemini, llm, mcp, mcp-server, openai, optimization, prompt, tokens

## 简介

Count and cut the tokens your prompts, chats and agents use, adapted to the model and task. MCP server and self-hosted gateway. Collects no data.
