# @llm-workbench/ui

> 标签: ai, human-in-the-loop, llm, observability, react, ui, workbench

## 简介

React control-surface components (WorkbenchShell) for inspecting and editing LLM Workbench runs — artifacts, rules, traces, gates, and bundle import/export.
