# @auphere/embed

> 标签: auphere, broadcast, embed, whatsapp, widget

## 简介

Auphere embed SDK — WhatsApp template broadcasts inside your own product. Thin loader: mounts the Auphere iframe, handshakes a short-lived session token, never touches credentials.
