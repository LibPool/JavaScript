# @teammeer/lite3d

> 标签: 3d, 3d-model, animation, animation-strip, hover, interactive, nextjs, react, sprite, sprite-strip, threejs

## 简介

A lightweight React package for generating and displaying 3D sprite strips with interactive hover effects. Perfect for integrating into existing forms and applications.
