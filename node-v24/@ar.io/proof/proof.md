# @ar.io/proof

> 标签: ar.io, arweave, ed25519, jcs, merkle, provenance, rfc8785, rfc9162, verification

## 简介

TypeScript kernel of the ar.io verification stack: RFC 8785 (JCS) canonicalization, SHA-256, and Ed25519 verification for Verifiable Event Envelopes. Full-family verifier (inline + external commitment); accepts ario.agent/v1, ario.mlflow/v1, ario.events/v
