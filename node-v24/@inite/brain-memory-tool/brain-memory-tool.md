# @inite/brain-memory-tool

> 标签: anthropic, brain, claude, context-editing, inite, memory, memory-tool, memory_20250818

## 简介

Backs Anthropic's memory tool (memory_20250818) with INITE Brain instead of a local directory. Drop-in: the agent loop keeps its own shape, the notes stop living on one machine's disk and start living in a tenant-fenced memory service.
