# @inite/brain-mcp

> 标签: brain, bridge, inite, mcp, memory, model-context-protocol, stdio

## 简介

First-party stdio MCP connector for the INITE Brain service. Lets stdio-only harnesses that can't attach auth headers (e.g. openclaw, Goose 1.x) use brain as long-term memory by transparently proxying every scoped tool over Streamable HTTP with Bearer aut
