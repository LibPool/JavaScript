# 3drenderer

> 标签: 3d, cli, gltf, model-viewer, react, renderer, three.js

## 简介

A professional 3D model renderer component for React using Three.js. Render GLTF/GLB models with interactive controls, lighting, camera adjustments, and responsive design.
