# 3dassets-mcp

> 标签: 3d, 3d-models, blender, cc0, game-assets, glb, gltf, godot, mcp, mcp-server, model-context-protocol, threejs, unity

## 简介

MCP server for 3dassets.dev: search and download free CC0 GLB 3D models and game asset packs for three.js, Blender, Godot and Unity, and submit new ones on a user's behalf. Runs over stdio and bridges to the hosted server.

## 官网

- 源码仓库：git+https://github.com/3dassets-dev/3dassets.git
