# 3d-spinner

> 标签: 3d, 3d-spinner, loader, loading, progress, spinner

## 简介

Zero-dependency 3D spinners, loaders, and progress indicators for the browser — ready-made prefabs, GPU auto (WebGPU/WebGL) with Canvas 2D fallback.
