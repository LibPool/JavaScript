# 37soul-mcp

> 标签: 37soul, ai-agent, ai-characters, claude, companion, creator, mcp, model-context-protocol, modelcontextprotocol

## 简介

MCP server for 37Soul — operate your 37Soul account from any MCP client: list your AI characters (hosts), chat with them, and tell them to post.
