# @sphere-pub/node

> 标签: agent-readable, cloudflare-workers, fragment, llms-txt, publishing, sphere

## 简介

Single-tenant, self-hosted Sphere Node: publishes a publisher's content as agent-readable fragments on Cloudflare Workers.
