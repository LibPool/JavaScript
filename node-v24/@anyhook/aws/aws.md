# @anyhook/aws

> 标签: anyhook, aws, dynamodb, lambda, sqs, webhooks

## 简介

AWS adapter for anyhook: SQS transport + single-table DynamoDB state + due_at-GSI scheduler with a fixed-interval sweeper
