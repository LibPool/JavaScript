# @nodii/onboarding

> 标签: browser, nodii, onboarding, recaptcha, sdk, self-signup

## 简介

Browser SDK for the Nodii self-signup onboarding flow. Headless form state, reCAPTCHA integration, and a default themeable vanilla-TS widget. D540/D537 contract client.
