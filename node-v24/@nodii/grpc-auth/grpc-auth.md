# @nodii/grpc-auth

> 标签: auth, grpc, interceptor, jwks, jwt, nodii, s2s

## 简介

gRPC service-to-service auth for Nodii microservices: server + client interceptors, JWKS fetch from S3, JWT verifier, token manager.
