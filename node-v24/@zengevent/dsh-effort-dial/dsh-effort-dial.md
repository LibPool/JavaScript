# @zengevent/dsh-effort-dial

> 标签: deepseek-harness, dsh, dsh-plugin

## 简介

DSH Web UI plugin: a rheostat-style reasoning-effort slider in the composer — drag through the model's advertised thinking levels, snap on release, writes through the official model directory.
