# @es3d/es3d

> 标签: 3d, converter, file-format, gltf, instancing, obj, procedural, step, stl, svg, webgl2, webgpu

## 简介

ES3D (Extensible Scalable 3D): a declarative, SVG-inspired 3D scene format with a WebGPU/WebGL2 reference renderer, editor and converter.
