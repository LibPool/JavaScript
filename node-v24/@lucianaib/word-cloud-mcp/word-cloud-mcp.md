# @lucianaib/word-cloud-mcp

> 标签: chinese-segmentation, document-processing, image-generation, mcp, model-context-protocol, pdf, png, spiral-layout, svg-generation, text-analysis, text-extraction, visualization, word, word-cloud, wordcloud

## 简介

一个专注于从文档内容制作词云图的 MCP 工具，支持 PDF、Word、TXT、MD 等多种格式的智能文字提取，具备优化的螺旋布局算法和多种输出格式
