# @kenkaiiii/ink

> 标签: cli, colors, command-line, components, jsx, preact, print, react, redux, render, stdout, text

## 简介

Ink 6.8.0 with gg-framework rendering patches (atomic scrollback inserts, bottom-anchored frames, in-place repaints). Installed as an npm alias for the ink specifier in @kenkaiiii/ggcoder.
