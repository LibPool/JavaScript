# @kenkaiiii/gg-editor-premiere-panel

> 标签: JavaScript

## 简介

Adobe Premiere Pro extension that lets gg-editor drive Premiere. Ships both a UXP plugin (Premiere 25.6+) and a legacy CEP panel (sunset Sept 2026).
