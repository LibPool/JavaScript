# @kenkaiiii/cfm-mcp

> 标签: ai-agents, claude, code-search, cursor, grep, llm, mcp, model-context-protocol, ripgrep, sourcegraph

## 简介

Self-hosted code search MCP server — your own grep.app for AI agents. No rate limits, no shared infra. Searches 2M+ public repos via Sourcegraph or any local checkout via ripgrep.
