# @hamzaabili/opencode-telegram-notify

> 标签: bot, inline-buttons, notifications, opencode, opencode-plugin, permissions, telegram

## 简介

OpenCode plugin (v1 and v2): Telegram notifications for permissions, questions, idle and errors, with tap-only inline buttons (never auto-approve).
