# @threahq/remote-session

> 标签: agent, bot, connector, runtime, sdk, threa

## 简介

SDK for connecting an interactive agent runtime to a Threa scratchpad: session linking, claiming work, presence and claim renewal, /steer and /stop, attachments, and interim or final replies. A connector implements deliverTurn; the SDK runs the loop.
