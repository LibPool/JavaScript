# @hasdata/booking-mcp

> 标签: booking, booking-com, booking-mcp, hasdata, hotels, mcp, model-context-protocol, scraper, travel

## 简介

MCP server for Booking.com through HasData's hosted API: search stays by destination and dates, and read a single property in full. 1,000 free credits every month.
