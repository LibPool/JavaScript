# @hasdata/shopify-mcp

> 标签: ecommerce, hasdata, mcp, model-context-protocol, price-monitoring, product-data, scraper, shopify, shopify-mcp

## 简介

MCP server for Shopify storefronts through HasData's hosted API: pull the public product catalogue and collections from any store by URL, with variants, SKUs and prices. No app, no merchant token. 1,000 free credits every month.
