# @hasdata/web-scraping-mcp

> 标签: hasdata, headless-browser, html-to-markdown, mcp, model-context-protocol, proxy, scraper, web-scraping

## 简介

MCP server for HasData's Web Scraping API: fetch any public URL through managed proxies with optional JS rendering, geo targeting, wait conditions and extraction rules. 1,000 free credits every month.
