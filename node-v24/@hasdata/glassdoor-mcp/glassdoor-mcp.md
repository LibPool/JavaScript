# @hasdata/glassdoor-mcp

> 标签: glassdoor, glassdoor-mcp, hasdata, job-search, jobs, mcp, model-context-protocol, recruiting, scraper

## 简介

MCP server for Glassdoor through HasData's hosted API: search job listings by keyword and location, and read one posting in full with the company rating and salary estimate. No Glassdoor partner account. 1,000 free credits every month.
