# @hasdata/google-maps-mcp

> 标签: google-maps, google-maps-mcp, hasdata, maps, mcp, model-context-protocol, places, reviews, scraper

## 简介

MCP server for Google Maps through HasData's hosted API: place search, place details, reviews, photos, posts and contributor history. No Google Cloud project. 1,000 free credits every month.
