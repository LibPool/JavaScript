# @royashbrook/waterbear

> 标签: agent, claude, claude-code, keepalive, launchd, persistence, remote-control, session, tmux

## 简介

Keep a CLI agent session alive through crashes, patches, quits, and reboots, and resume the same conversation when it comes back. macOS/launchd + tmux.
