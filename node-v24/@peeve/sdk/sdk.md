# @peeve/sdk

> 标签: agent, in-product, peeve, sdk, support

## 简介

The Peeve SDK — one vanilla-JS package that works with any frontend (React, Vue, Angular, Svelte, plain JS) and a /server entry for the backend. Zero third-party deps.
