# @usesalama/ntx-apps-buyer

> 标签: JavaScript

## 简介

Customer-facing API: the self-serve companion to WhatsApp (see `docs/TRD.md` §8). Currently a bare boilerplate — no domain entities yet. Intended to grow into: current cycle/quote view, payment history, address management, and referral status.
