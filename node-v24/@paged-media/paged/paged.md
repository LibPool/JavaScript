# @paged-media/paged

> 标签: JavaScript

## 简介

The paged engine: the editing canvas (wire types, document model, WebGPU rendering), its introspection (./introspect) and the document repository (./repo) as wasm for the browser and Node, and the `paged` command line over it, with `paged mcp` for agents.
