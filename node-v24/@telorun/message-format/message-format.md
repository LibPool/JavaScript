# @telorun/message-format

> 标签: cldr, i18n, messageformat, plural, telo

## 简介

Telo's message core: a closed profile of Unicode MessageFormat 2 — placeholders, plural selection, CLDR plural rules and decimal formatting from pinned CLDR data, and RFC 4647 language lookup. No Intl, no dependencies; one answer in Node, Rust and every b
