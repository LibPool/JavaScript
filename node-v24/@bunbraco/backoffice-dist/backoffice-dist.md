# @bunbraco/backoffice-dist

> 标签: JavaScript

## 简介

The Umbraco backoffice, built to run in a browser. Major and minor track the @umbraco-cms/backoffice release vendored here; the patch is ours. Regenerate with `bun run vendor:backoffice`.
