# @gizmo564/lobby-ui

> 标签: JavaScript

## 简介

Small UI parts every game reuses: 21 avatars, QR, fullscreen, Modal, Stepper, Toggle, Choice, ColorPicker, TeamPicker, TeamChip, TurnTimer, toasts, CodePanel, PlayerList (host controls, bots), ProfileEditor, fitGrid.
