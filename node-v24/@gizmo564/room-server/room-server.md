# @gizmo564/room-server

> 标签: JavaScript

## 简介

Generic multi-device room: BaseRoom (members, rejoin, host, screens, settings, start/again, timers, per-viewer views), GameRoomDO (hibernation, idle close, nap freeze, stats), and the Worker routes. Also ships a tiny toy GameLogic for other packages' test
