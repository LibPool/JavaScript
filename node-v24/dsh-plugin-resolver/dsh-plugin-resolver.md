# dsh-plugin-resolver

> 标签: catalog, deepseek, dsh, dsh-plugin, harness, plugin-installer, plugin-manager, resolver

## 简介

Agent-facing DSH plugin resolver: search the catalog, pick a version the running DSH accepts, install (registry or GitHub-source build), and verify - no trial and error.
