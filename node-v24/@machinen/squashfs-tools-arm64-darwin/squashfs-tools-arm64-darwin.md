# @machinen/squashfs-tools-arm64-darwin

> 标签: JavaScript

## 简介

Bundled mksquashfs (squashfs-tools) for arm64 darwin. Lets @machinen/runtime build the read-only squashfs lower for `--mount` overlays without a host install.
