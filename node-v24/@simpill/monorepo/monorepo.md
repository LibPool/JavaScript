# @simpill/monorepo

> 标签: monorepo, simpill, typescript, utils

## 简介

Root package for @simpill: all utils are installed from npm (@simpill/<name>.utils). Run 'npm install' at repo root. Use 'npm run use:local' to point at local utils/ for development.
