# @sebastienrousseau/crypto-sdk

> 标签: client, cryptography, encryption, fetch, ml-dsa, ml-kem, post-quantum, pqc, rest-api, sdk, typescript

## 简介

Typed TypeScript client for the crypto-server REST API: post-quantum, encryption, signing and hashing calls. Zero dependencies, built on fetch.
