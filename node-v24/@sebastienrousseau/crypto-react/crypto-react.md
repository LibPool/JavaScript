# @sebastienrousseau/crypto-react

> 标签: cryptography, encryption, hashing, hooks, keygen, post-quantum, react, react-hooks, signing, webcrypto

## 简介

React hooks for client-side cryptography: key generation, encryption, signing, hashing and post-quantum hybrid streaming encryption (ML-KEM-768).
