# @everymatrix/hostpilot-core

> 标签: JavaScript

## 简介

Target validation and temporary hosts-file mappings for HostPilot. This is an ES module library with TypeScript declarations. Use `@everymatrix/hostpilot-cli` for the complete `hpl` command.
