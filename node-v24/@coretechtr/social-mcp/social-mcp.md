# @coretechtr/social-mcp

> 标签: claude, instagram, mcp, model-context-protocol, social-media

## 简介

MCP server that connects Claude to a self-hosted social publishing dashboard: pick up queued scenarios, refine copy, request and review generated images, submit posts for approval.
