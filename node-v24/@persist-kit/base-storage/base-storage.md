# @persist-kit/base-storage

> 标签: encryption, event-emitter, pluggable, ssr, storage, typescript

## 简介

A tiny, zero-dependency, fully pluggable base class for encrypted key/value storage with typed events. No storage, environment, or runtime assumptions.
