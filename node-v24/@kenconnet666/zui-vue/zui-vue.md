# @kenconnet666/zui-vue

> 标签: components, css-in-js, design-system, emotion, i18n, timezone, type-safe, vue, vue3

## 简介

Vue 3 components & helpers built on @kenconnet666/zui-core. ZBox for nested theme / componentTokens / locale / timezone, plus headless composables.
