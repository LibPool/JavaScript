# @yonastewabe/nestjs-redis-cache

> 标签: cache, ioredis, nestjs, redis, typeorm

## 简介

Generic, zero-app-specific Redis cache module for NestJS, built on ioredis, with an HTTP interceptor and TypeORM auto-invalidation
