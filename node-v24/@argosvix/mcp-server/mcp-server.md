Observability MCP server for AI agents: 89 tools (2 usable with no API key) to query and operate LLM cost, errors, latency, alerts, budgets, evals, prompts, approvals, and safety checks from Claude Desktop, Cursor, or any MCP client. stdio + HTTP transpor
