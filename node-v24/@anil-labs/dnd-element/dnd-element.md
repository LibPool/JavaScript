> 标签: custom-element, dnd, drag-and-drop, draggable, list, reorder, sortable, web-component

## 简介

Web Component (<dnd-list>) for @anil-labs/dnd-core — sortable lists, cross-list groups, multi-drag and keyboard a11y in any framework or plain HTML via a script tag.
