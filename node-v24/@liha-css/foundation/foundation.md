# @liha-css/foundation

> 标签: JavaScript

## 简介

`@liha-css/foundation` は **Void Reset 後の“最低限の足場”** を配布します。 タイポグラフィ（h1/h2…）や見た目のルールは提供せず、**「読める・操作できる」だけを保証**します。
