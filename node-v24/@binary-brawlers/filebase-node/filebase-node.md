# @binary-brawlers/filebase-node

> 标签: JavaScript

## 简介

Server-side admin SDK for [FileBase](https://github.com/binary-brawlers/filebase). Use it from any Node.js (or Bun / Deno with `fetch`) backend to mint signed upload sessions, upload files directly from your server, and manage files.
