# prestron-media-encoder

> 标签: anime, batch-encode, cli, ffmpeg, h265, hevc, interactive, media-encoder, mkv, video

## 简介

Interactive TUI batch video encoder built on Node 22 and FFmpeg. Auto-classifies movies, series, and anime with strict output verification.
