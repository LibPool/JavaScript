# vox-trust-mcp

> 标签: audio, authenticity, deepfake, mcp, model-context-protocol, provenance, voice, voice-cloning

## 简介

MCP server for the Vox Trust protocol: verify sealed voice recordings (WAV) from any AI assistant, with the seconds that changed. Verify-only, no secrets. Pre-1.0, not audited.
