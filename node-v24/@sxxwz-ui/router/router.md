# @sxxwz-ui/router

> 标签: JavaScript

## 简介

本包是根据 ea-router https://toscode.gitee.com/zexzy/ea-router 修改，由于原组件中只提供了vue 2.x + vue-router 3.x 相关方法，未支持 typescript 特此进行代码改造 目标适用于vue3 + Ts，本依赖库目前只支持vue3 +ts项目
