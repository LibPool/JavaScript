# @skinhub/viewer

> 标签: counter-strike, cs2, csgo, embed, iframe, inspect-link, react, skin, viewer

## 简介

React wrapper for the SkinHub CS2 skin viewer embed — props in, postMessage out. No three.js, no renderer, no asset bundle; React is the only peer.
