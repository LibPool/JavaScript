# @aplopes/notedeck-sdk

> 标签: aplopes, notedeck, plaud, sdk, transcription, webhook

## 简介

Server-side SDK for connecting a third-party app to a NoteDeck user's recordings (sessions, transcripts, AI, audio) over a signed OAuth-style handshake.
