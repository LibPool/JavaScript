# @iyowei/create-esm

> 标签: cli, create, esm, generator, infrastructure, iyowei, scoffold, template

## 简介

这是一个命令行工具，给到 ESM 源码文件路径后，自动创建一个项目、打包、发布，确保一个指令即可在项目中安装使用，进而支持跨项目使用。
