# dru-date-picker

> 标签: datepicker, datetime, ios, next, nextjs, nuxt, react, timepicker, vue, web-component, wheel

## 简介

iOS-style wheel date/time picker for Vue, React, Next.js, Nuxt, and vanilla JavaScript. Colors, button text, and date type are customizable per instance.
