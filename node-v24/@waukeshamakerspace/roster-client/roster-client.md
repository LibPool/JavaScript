# @waukeshamakerspace/roster-client

> 标签: http-client, people, roles, roster, waukesha-makerspace

## 简介

One HTTP client for Roster, the Waukesha Makerspace person system of record: people, roles, lookup, search and login-time resolve, with the wire quirks (API key header, HTML-at-200 origin, envelope, camel/snake asymmetry) handled once
