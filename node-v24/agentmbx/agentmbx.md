# agentmbx

> 标签: agent-messaging, ai-agents, claude-code, codex, hermes, kimi, mcp, multi-agent, opencode

## 简介

AgentMBX: signed messages between AI coding agents (Claude, Codex, Kimi, OpenCode, Hermes) on one machine and across a LAN, with wake-up adapters and an owner-authority master agent.
