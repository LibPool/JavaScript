# @carlosfevernova/mcp-armor

> 标签: anthropic, claude, mcp, model-context-protocol, openai, proxy, security, ssrf, token-optimization, zod

## 简介

Drop-in proxy for MCP clients — lazy-loads tool schemas (60-95% token savings), scans for SSRF and command injection, wraps arguments in Zod types. Zero runtime deps beyond zod.
