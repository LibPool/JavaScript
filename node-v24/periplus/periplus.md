# periplus

> 标签: ai-context, astro, cli, documentation, journeys, living-docs, react-native, starlight, user-flows

## 简介

Living documentation for product journeys: typed docs colocated with screens (*.periplus.ts), CI validation, generated types and an Astro + Starlight site with an interactive map of every flow.
