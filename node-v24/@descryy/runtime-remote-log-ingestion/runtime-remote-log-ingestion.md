# @descryy/runtime-remote-log-ingestion

> 标签: JavaScript

## 简介

Remote-environment log ingestion (DEC-271): for staging/preview/production, where Descry cannot inject a proxy into infra it doesn't own, ingest whatever the target already has -- logs, and trace ids if a field is declared -- and correlate best-effort aga
