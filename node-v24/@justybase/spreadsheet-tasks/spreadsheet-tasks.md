# @justybase/spreadsheet-tasks

> 标签: binary, excel, performance, reader, spreadsheet, typescript, workbook, writer, xlsb, xlsx

## 简介

High-performance TypeScript library for reading and writing Excel files in XLSB and XLSX formats. XLSB is 3.3x faster to write and 2.3x faster to read than XLSX.
