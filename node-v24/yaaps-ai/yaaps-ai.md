# yaaps-ai

> 标签: JavaScript

## 简介

Command-line client for YAAPS (yaaps.net): publish agent-made HTML reports as temporary shareable links.

## 官网

- 官网：https://yaaps.net
- 源码仓库：git+https://github.com/ShlomiPorush/yaaps.git
- npm 页面：https://www.npmjs.com/package/yaaps-ai
