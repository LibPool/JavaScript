# @vue-mcp-apps/server

> 标签: mcp, mcp-apps, mcp-ui, model-context-protocol, nuxt-ui, vue

## 简介

Register Vue cards as MCP Apps templates on any MCP server (SDK v1 or v2) and shape tool results for them.
