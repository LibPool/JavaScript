# @candid-core/schema

> 标签: JavaScript

## 简介

Zod-style schema runtime for Candid: builders with static inference, structural validation, a TypeScript-native binary codec, typed actors over a transport-only agent, and form metadata — all driven by candid-core's canonical Contract model.
