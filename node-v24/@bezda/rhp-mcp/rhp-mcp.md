# @bezda/rhp-mcp

> 标签: agent, ai, charts, checker, data-visualization, mcp, mcp-server, model-context-protocol, rhp, solidjs

## 简介

Make charts with rhp from any AI agent: an MCP server with rhp's guide, references and recipes, and a checker that renders a chart in a browser and reports what is wrong, with screenshots
