# @suneyde/web-tokens

> 标签: css, css-variables, custom-properties, design-system, design-tokens, dtcg, spacing, style-dictionary, theming, tokens, typography

## 简介

Design tokens for the web: CSS custom properties, typography classes, and typed JS values generated from W3C DTCG sources with Style Dictionary.
