# @zhuyichuan/canvas-agent

> 标签: JavaScript

## 简介

Infinite Canvas 本地伴生服务与 MCP 连接器。为 **WorkBuddy** 及其他兼容 MCP（Model Context Protocol）协议的 AI 客户端提供与 Infinite Canvas 网页画布的实时协同与操作能力。
