# @maroonedsoftware/serverfeed

> 标签: backend, pubsub, realtime, serverfeed, serverkit, typescript

## 简介

Framework-agnostic, transport-free in-process feed of realtime server activity (pub/sub, replay buffer, snapshot) for ServerKit.
