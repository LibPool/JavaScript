# @maroonedsoftware/permissions

> 标签: authorization, backend, permissions, rbac, rebac, serverkit, typescript, zanzibar

## 简介

A Zanzibar-style relationship-based access control library — an authorization model DSL, a relation-tuple repository contract, and a Check evaluator with per-request metrics.
