# @maroonedsoftware/saml

> 标签: backend, identity, saml, saml2, serverkit, sso, typescript

## 简介

SAML 2.0 service-provider toolkit for ServerKit: per-provider configuration from a pluggable source, IdP metadata parsing, SP metadata generation, and SP-initiated sign-in as an authentication factor on @node-saml/node-saml.
