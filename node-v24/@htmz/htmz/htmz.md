# @htmz/htmz

> 标签: ajax, api, dashboard, declarative, dom, frontend, html, htmx-like, json, performance, reactive, rest-api, spa, templates, web-components, zero-javascript

## 简介

Transform any JSON API into dynamic HTML with zero JavaScript coding. Declarative attributes for AJAX, templating, and DOM updates.
