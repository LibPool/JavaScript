# @valyd/sdk

> 标签: credential, face-match, identity-verification, kyc, license-verification, liveness, login-with-valyd, oauth2, sso, valyd, verify, webhooks

## 简介

The unified Valyd SDK — Login with Valyd (OAuth2 SSO), identity verification (hosted + standalone), consent-gated attributes, and signed webhooks. One host, one credential.
