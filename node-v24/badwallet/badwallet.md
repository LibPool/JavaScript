# badwallet

> 标签: fixtures, mdl, mdoc, openid4vp, sd-jwt, testing, verifiable-credentials

## 简介

Test fixture emitter for OpenID4VP credential verifiers. Generates valid and deliberately broken SD-JWT VC and ISO 18013-5 mdoc presentations.
