# @dockndevai/mcp-teams

> 标签: ai, chat, collaboration, llm, mcp, microsoft-365, microsoft-graph, microsoft-teams, model-context-protocol, office365, teams

## 简介

Model Context Protocol server for Microsoft Teams (Microsoft Graph) — read teams, channels, chats and messages, and post/reply/send, with browser sign-in and safe-by-default access modes and guards.
