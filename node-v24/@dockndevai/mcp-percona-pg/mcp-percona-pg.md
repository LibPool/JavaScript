# @dockndevai/mcp-percona-pg

> 标签: ai, database, devops, kubernetes, llm, mcp, model-context-protocol, percona, pgbouncer, postgres, postgresql

## 简介

Model Context Protocol server for the Percona Operator for PostgreSQL — manage PostgreSQL + PgBouncer clusters, pooling, backups/PITR, and DR with security modes and access-control flags.
