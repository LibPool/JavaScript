# @geoql/doctor-language-server

> 标签: audit, doctor, geoql, language-server, lint, lsp, nuxt, vue, vue3

## 简介

LSP server that runs the @geoql/doctor audit engine over Vue 3 + Nuxt 4 files and publishes diagnostics to any LSP-capable editor. TypeScript, ESM, stdio.
