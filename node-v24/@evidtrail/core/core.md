# @evidtrail/core

> 标签: ai, ai-attribution, ai-coding, claude-code, cursor, devex, engineering-metrics, git, github-copilot, provenance, schema

## 简介

Git collection, two-axis AI attribution (mode × evidence), and versioned schemas for evidtrail. An auditable ledger of AI provenance and change signals for your git repositories — honest about what git can and cannot prove.
