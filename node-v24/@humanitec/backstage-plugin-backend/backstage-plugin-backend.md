# @humanitec/backstage-plugin-backend

> 标签: JavaScript

## 简介

`@humanitec/backstage-plugin-backend` is a plugin for the Backstage backend app. It provides a route that `@humanitec/backstage-plugin` will use to connect to Humanitec API.
