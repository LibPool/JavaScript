# @gcwioro/vite-plugin-vue-i18n-typescript

> 标签: autocomplete, compile-time-validation, hmr, hot-reload, i18n, intellisense, internationalization, localization, translation-keys, type-generation, type-safe, types, typescript, vite, vite-plugin, vue, vue-i18n, vue3

## 简介

Type-safe Vue i18n translations. Auto-generates TypeScript types from JSON locale files. Catch translation errors at compile time with full IDE autocomplete.
