# @wecity/mp-fe-gateway

> 标签: mp-fe-gateway

## 简介

小程序前端网关，提供给微信小程序的前端限流 SDK，通过限流配置对 wx.request/wx.cloud.callContainer 进行前置拦截，从而对后端网关进行特殊时期的保护。
