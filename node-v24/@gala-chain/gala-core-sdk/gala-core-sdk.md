# @gala-chain/gala-core-sdk

> 标签: eip712, gala, galachain, sdk, signing

## 简介

The GalaChain core SDK: signing (native, personal-sign, EIP-712), the gateway transport, the gateway token reads (balances, token classes, NFT collections) and writes (transfer, burn, lock, unlock) and the shared error model, for every product SDK and app
