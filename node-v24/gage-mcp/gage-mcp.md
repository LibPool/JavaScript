# gage-mcp

> 标签: agents, gage, mcp, model-context-protocol, robinhood-chain, wallet

## 简介

gage's MCP server for agents with their own wallet: `npx -y gage-mcp init`, then borrow and earn on gage. Robinhood Chain under spend limits, and its testnet.
