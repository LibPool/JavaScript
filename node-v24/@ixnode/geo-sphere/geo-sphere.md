# @ixnode/geo-sphere

> 标签: GIS, clickable countries, component, data visualization, geo-sphere, geography, geospatial, interactive map, map rendering, mapping, mercator projection, multi-language, nodejs, react, touch support, typescript, world map, zoomable map

## 简介

A Node.js package for rendering interactive world maps with Mercator projection, customizable languages, and advanced interactivity features such as zoom, pan, and click events.
