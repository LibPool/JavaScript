# @sechak.agency/moromap

> 标签: carte, choropleth, d3, dataviz, geojson, map, maroc, morocco, prefectures, provinces, react, regions, svg, topojson

## 简介

Zero-dependency-fetch interactive Morocco map for JS/TS — regions & provinces/prefectures, labels, data markers, choropleths, themes, search, export (SVG/PNG). Ships with bundled geo-data and an optional React wrapper.
