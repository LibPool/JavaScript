# @theokit/tui

> 标签: agent, ai, chat, cli, ink, llm, react, streaming, terminal, tui

## 简介

AI-native TUI primitives for agent CLIs — streaming chat, tool cards, diffs, agent timeline and metrics, built on Ink (React for the terminal)
