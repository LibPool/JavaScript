# @systemfsoftware/effect-schema-recursion-budget

> 标签: arbitrary, effect, effect-ts, fast-check, property-testing, recursion, schema, typescript

## 简介

The recursionBudget annotation pipeline for Effect Schema unions: the Vite transform that materializes a declared generation budget into the arbitrary-derivation hook, and the injected runtime that builds it.
