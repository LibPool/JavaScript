# @systemfsoftware/effect-daemon-process

> 标签: child-process, daemon, effect, effect-ts, process, supervision, supervisor

## 简介

The effect-daemon-spec medium over operating-system child processes — a command spec spawned through ChildProcessSpawner, its exit code and terminating signal reported as observed, and its shutdown mapped to SIGTERM and SIGKILL.
