# @systemfsoftware/oxlint-plugin-cell-taxonomy

> 标签: architecture, lint, lint-rules, linter, naming-convention, oxc, oxlint, oxlint-plugin, screaming-architecture, typescript

## 简介

Oxlint rule requiring every source file under src/ to name the cell it is: <name>.<cell>.ts, with a configurable set of cells and exempt entrypoint names.
