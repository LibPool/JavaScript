# @systemfsoftware/oxlint-plugin-effect-entrypoint

> 标签: composition-root, effect, effect-ts, entrypoint, lint, lint-rules, linter, oxc, oxlint, oxlint-plugin, runmain, typescript

## 简介

Oxlint rules enforcing main.ts as a real interpretation edge - interprets exactly once, exports nothing, is imported by nothing, never wraps a foreign promise runtime, and builds the process runtime once, lazily, at module scope.
