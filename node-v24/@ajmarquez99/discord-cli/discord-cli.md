# @ajmarquez99/discord-cli

> 标签: agentic, allowlist, bot, cli, discord, mcp

## 简介

Discord CLI for coding agents — post, read, react, reply, and manage threads via the Discord REST API, with a fail-closed channel allowlist. Ships an MCP server too.
