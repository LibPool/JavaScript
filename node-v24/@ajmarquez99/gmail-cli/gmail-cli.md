# @ajmarquez99/gmail-cli

> 标签: agentic, allowlist, cli, email, gmail, nodemailer, send, smtp

## 简介

Gmail CLI with a fail-closed recipient allowlist — send (markdown, attachments, dry-run, threading, send log) plus IMAP read, label, and mark.
