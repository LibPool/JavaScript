# @lucidui-dev/bridge

> 标签: ai-agents, builder, claude-code, cursor, lucid-ui, mcp, model-context-protocol

## 简介

Connect your coding agent to Lucid Builder: the agent renders Lucid UI apps in your browser and gets errors and diagnostics back. An MCP server with zero dependencies.
