# @fsegurai/marked-extended-code

> 标签: code, code-blocks, extensions, javascript, library, line-numbers, markdown, marked-extended-code, markedjs, parser, prism, shiki, syntax, syntax-highlighting, typescript, vitepress

## 简介

Extension for Marked.js that adds VitePress-style code blocks: titles, line numbers, line highlights, diff/focus/warning/error markers and [!code …] magic comments, rendered as sanitizer-safe class tokens that survive strict sanitizers such as Angular's.
