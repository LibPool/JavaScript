# @agentfromzero/agentpassport-sdk

> 标签: ai-agents, eip-3009, envio, erc-8004, escrow, monad, nansen, reputation, usdc, viem, x402

## 简介

TypeScript SDK for AgentPassport: escrow-backed ERC-8004 reputation for AI agents on Monad. Read passports, check hiring policies, hire/deliver/release through USDC escrow, gasless EIP-3009 opens.
