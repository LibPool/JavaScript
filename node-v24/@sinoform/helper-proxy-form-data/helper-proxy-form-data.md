# @sinoform/helper-proxy-form-data

> 标签: JavaScript

## 简介

在很多情况下，需要通过表单项的标题（中文名称）获取表单项的值，例如打印输出和路由控制。 `helper-proxy-form-data`模块是用来帮助通过表单项标题获取表单项的值。
