# @danwo/mobile

> 标签: JavaScript

## 简介

Mobile apps for danwo tests: builds an Expo, Xcode, Gradle or Flutter app to trust danwo's proxy, and runs it on an iOS Simulator or Android emulator bound to that proxy, driven through agent-device.

- 源码仓库：git+https://github.com/carbonmeai/danwo.git
- npm 页面：https://www.npmjs.com/package/@danwo/mobile
