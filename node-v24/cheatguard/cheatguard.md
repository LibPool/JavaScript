# cheatguard

> 标签: agents, ai, claude-code, code-quality, guardrails, linter

## 简介

Catch the shortcuts AI coding agents take: weakened tests, type suppressions, config tampering, stubs, phantom imports. Diff-aware, deterministic, built for agent hooks.
