# @luwiostack/country

> 标签: continent, country, currency, hooks, i18n, intl, iso-3166, locale, luwio, react

## 简介

Typed ISO 3166 country data for React — countries, borders, dialing codes, currencies and spoken languages, with a `<Country>` provider and `useCountry` hook.
