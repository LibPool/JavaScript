# @alert-whatif/ui

> 标签: alert-rules, alerting, grafana, react, visualization

## 简介

Shared React components for alert-whatif (chart, compute trace, parameter controls). Pure presentational layer — no Grafana SDK, no datasource concerns. Consumed by @alert-whatif/demo and @alert-whatif/plugin.
