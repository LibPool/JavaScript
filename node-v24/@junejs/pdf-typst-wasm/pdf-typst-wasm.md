# @junejs/pdf-typst-wasm

> 标签: agent, cloudflare-workers, june, pdf, typst, wasm

## 简介

June — a PdfRenderer on a Typst to PDF engine compiled to WebAssembly: no browser, no native binary, and it runs on Cloudflare Workers.
