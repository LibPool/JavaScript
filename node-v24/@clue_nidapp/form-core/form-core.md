# @clue_nidapp/form-core

> 标签: JavaScript

## 简介

线索通表单 SDK 为线索通表单组件核心逻辑SDK，包含表单从初始化到最终销毁全生命周期数据流转，仅作为核心逻辑的封装不侵入UI交互。目前该 SDK 支持 h5，lynx，字节小程序环境。使用该 SDK，开发者可以不依靠橙子建站，搭建自己的表单落地页。
