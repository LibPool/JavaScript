# @nats-trail/server

> 标签: JavaScript

## 简介

API bridge for [NATS Trail](https://github.com/solsolettidev/nats-trail): Express + WebSocket. Owns NATS connections (pooled per context), protects credentials, enforces limits and serves the built UI.
