# @human-kit/markdown

> 标签: markdown, mdsvex, preprocessor, rehype, remark, svelte, unified

## 简介

A markdown preprocessor for Svelte built on unified — components in markdown, frontmatter metadata, runes-compatible blueprints, and pluggable async syntax highlighting.
