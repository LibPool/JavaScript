# @human-kit/ui

> 标签: a11y, accessible, component-library, components, design-system, headless, human-kit, svelte, svelte5, tailwind, ui, ui-kit

## 简介

Accessible, typed UI components for Svelte 5 — shipped as native ESM with per-component subpath exports so bundlers only include what you import.
