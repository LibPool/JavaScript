# @worldscore/mcp

> 标签: ai-agents, claude, country-data, mcp, model-context-protocol, worldscore

## 简介

MCP server for WorldScore — read-only, provenance-carrying access to sourced 0–100 country scores for AI agents and MCP clients. Thin client over the public API; ships no data.
