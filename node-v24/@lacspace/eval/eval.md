# @lacspace/eval

> 标签: ai, assertions, cosine-similarity, eval, evaluation, grading, isomorphic, json-schema, jsonpath, keyword-coverage, levenshtein, llm, llm-as-judge, llm-eval, pass-rate, prompt-engineering, regression-testing, rubric, scorer, testing, typescript, zero-dependency

## 简介

A tiny, zero-dependency, keyless toolkit for evaluating LLM outputs — deterministic scorers (contains, regex, JSON-schema, Levenshtein, cosine, keyword coverage, JSONPath) plus an optional LLM-as-judge whose model is fully injected, batch runners and pass
