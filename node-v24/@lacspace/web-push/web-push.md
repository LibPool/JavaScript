# @lacspace/web-push

> 标签: aes128gcm, browser-notifications, cloudflare-workers, edge, isomorphic, keyless, no-firebase, notifications, push, push-notifications, pwa, rfc8291, rfc8292, service-worker, typescript, vapid, vercel-edge, web-crypto, web-push, zero-dependency

## 简介

Send Web Push notifications to browsers with ZERO dependencies and NO vendor — pure Web Crypto (VAPID + RFC 8291 aes128gcm payload encryption). No Firebase, no FCM account, no keys to buy. Isomorphic: runs on Node, Deno, Bun and edge runtimes (Vercel Edge
