# @lacspace/indicators

> 标签: adx, atr, bollinger-bands, candle, candlestick, cci, chaikin-money-flow, dema, donchian-channels, ema, ichimoku, keltner-channels, macd, mfi, obv, ohlc, parabolic-sar, pattern-detection, roc, rsi, stochastic, stochrsi, stock-market, streaming, supertrend, technical-indicators, tema, trading, typescript, vwap, williams-r

## 简介

Streaming technical indicators (RSI, MACD, EMA, Bollinger, ATR, Supertrend, ADX, VWAP) with O(1) incremental updates for live price feeds. Zero-dependency.
