# @lacspace/oauth

> 标签: arctic, auth, github-login, id-token, isomorphic, jwks, next-auth, oauth, oauth2, oidc, openid-connect, pkce, sign-in-with-apple, sign-in-with-google, social-login, typescript, zero-dependency

## 简介

OAuth 2.1 / OpenID Connect client for social login — Google, GitHub, Microsoft, Apple, GitLab, Discord, Slack, LinkedIn, Facebook, X, Spotify, Twitch, Notion, and any OIDC issuer via discovery (Auth0, Okta, Keycloak, Cognito). PKCE, state, nonce, ID-token
