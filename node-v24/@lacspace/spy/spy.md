# @lacspace/spy

> 标签: argument-matchers, assertions, call-inspection, fake, fake-timers, isomorphic, jest, matchers, mock, mocking, objectContaining, resetAll, sinon, spy, stub, test, test-double, testing, typescript, unit-testing, vitest, zero-dependency

## 简介

A tiny, zero-dependency test-doubles library — spies, stubs, mocks, argument matchers and deterministic fake timers that work in any test runner or the browser. Isomorphic and fully typed.
