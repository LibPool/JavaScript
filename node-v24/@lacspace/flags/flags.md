# @lacspace/flags

> 标签: a-b-testing, ab-testing, deterministic, experiments, feature-flag, feature-flag-overrides, feature-flags, feature-toggle, gradual-rollout, isomorphic, kill-switch, launchdarkly-alternative, multivariate, percentage-rollout, rollout, segments, self-hosted, targeting, typescript, unleash-alternative, variants

## 简介

Feature flags & A/B experiments with no SaaS and no infrastructure — deterministic bucketing (same user always gets the same result), targeting rules, percentage rollouts and weighted variants. Synchronous, zero-dependency, isomorphic.
