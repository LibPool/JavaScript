# @lacspace/virtual

> 标签: dynamic-size, horizontal-list, infinite-list, overscan, performance, pinned-rows, react, react-virtual, scroll-to-index, ssr, sticky-headers, tanstack-virtual, typescript, usevirtualizer, variable-size, virtual-list, virtualization, windowing, zero-dependency

## 简介

Headless list virtualization for React — render only the rows in view, with fixed or dynamically-measured sizes, overscan, sticky/pinned rows, horizontal lists, and scroll-to-index. useVirtualizer in ~2KB, plus a React-free math core. Zero-dependency, SSR
