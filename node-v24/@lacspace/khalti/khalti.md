# @lacspace/khalti

> 标签: amount-validation, callback, edge, epayment, esewa, fetch, idempotency, isomorphic, khalti, kpg-2, nepal, paisa, payment, payment-gateway, payment-verification, purchase-order-id, typescript, web-crypto

## 简介

Khalti KPG-2 (ePayment API v2, Nepal) client — initiate payments, look up status, typed errors and Key auth over global fetch. Zero-dependency, isomorphic (Node, edge, browser).
