# @lacspace/queue

> 标签: async-queue, concurrency, concurrency-limit, isomorphic, job-queue, p-limit-alternative, p-queue-alternative, priority-queue, promise-queue, queue, rate-control, task-queue, throttle-concurrency, typescript, zero-dependency

## 简介

A tiny in-memory async task queue with a concurrency limit for Node and the browser — run up to N tasks at once, prioritise, pause/resume, abort and await the drain. Zero-dependency, isomorphic, TypeScript-first.
