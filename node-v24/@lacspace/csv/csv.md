# @lacspace/csv

> 标签: bom, chunked, column-mapping, csv, csv-parse, csv-parser, csv-stream, csv-stringify, delimited, dialect, isomorphic, papaparse-alternative, rfc4180, streaming-csv, tsv, type-coercion, type-inference, typescript, zero-dependency

## 简介

Correct, RFC 4180 CSV parsing & stringifying — quoted fields, escaped quotes, newlines in cells, CRLF, custom delimiters, type coercion, column mapping, chunked/streaming parse and typed row objects. Zero-dependency, isomorphic.
