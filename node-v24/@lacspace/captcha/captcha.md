# @lacspace/captcha

> 标签: altcha, anti-bot, bot-protection, captcha, gdpr, hmac, isomorphic, keyless, no-recaptcha, pow, privacy, proof-of-work, spam-protection, typescript, zero-dependency

## 简介

A keyless, privacy-friendly proof-of-work CAPTCHA with zero dependencies — no Google, no Cloudflare, no account, no tracking, no puzzles to squint at. Stateless HMAC-signed challenges (ALTCHA-style) verified with a single server secret. Isomorphic core +
