# @lacspace/crypto

> 标签: aead, aes, aes-256-gcm, base64, base64url, constant-time, crypto, csprng, decrypt, encrypt, encryption, envelope-encryption, gcm, hkdf, hmac, isomorphic, key-derivation, keyring, pbkdf2, random-int, random-string, sha256, sha512, timing-safe-equal, typescript, uuid, web-crypto

## 简介

Safe, boring cryptography over Web Crypto — authenticated AES-256-GCM, PBKDF2 key derivation, SHA-256, HMAC, secure random and constant-time compare. Isomorphic (Node, edge, browser, RN).
