# env-parity-plugin

> 标签: .env, .env.example, astro, astro-integration, client-components, dotenv, env, environment-variables, lint, next, nextjs, process.env, rolldown, rollup, rollup-plugin, rspack, validation, webpack, webpack-plugin

## 简介

Fail your Webpack, Rspack, Rollup, Rolldown, Astro or Next.js build or dev server when a variable from .env.example is missing or empty, or when your code reads one the example doesn't list. Catches server secrets in Next.js client components. Built on @a
