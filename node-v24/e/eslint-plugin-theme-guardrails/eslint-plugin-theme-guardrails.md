# eslint-plugin-theme-guardrails

> 标签: eslint, eslint-plugin, eslintplugin, hardcoded-colors, mui, tailwind, theme, typescript

## 简介

ESLint rules enforcing theme compliance for MUI and Tailwind. Bans hardcoded colors, fontWeight, and fontFamily.
