# eslint-plugin-typewind-redux

> 标签: eslint, eslint-plugin, eslintplugin, tailwindcss, typewind

## 简介

ESLint rules for typewind (v3) and typewind-v4 — enforce the gray/grey spelling, suggest canonical class names, sort/dedupe/validate tw. chains
