# ember-cli-rtlcss

> 标签: JavaScript

## 简介

Ember-Cli addon that runs rtlcss as a post-build step to generate right-to-left css files (app.rtl.css etc).

- 官网：https://github.com/dbouwman/ember-cli-rtlcss#readme
