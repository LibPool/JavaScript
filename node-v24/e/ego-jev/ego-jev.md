# ego-jev

> 标签: agent, browser-automation, claude-code, ego-lite, jev, typesafe

## 简介

Let Jev (TypeSafe System One) drive multi-step flows inside ego lite, your real browser. The agent supplies goals, values and target page states; Jev picks every click.
