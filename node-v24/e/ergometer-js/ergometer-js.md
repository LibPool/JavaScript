# ergometer-js

> 标签: BLE, HID, PM3, PM4, PM5, PhoneGap, USB, WebHid, concept 2, cordova, driver, ergometer

## 简介

Java script ergometer driver for concept 2 performance monitor with BLE and USB. (The PM5) Works on all major platforms using cordova and node/electron
