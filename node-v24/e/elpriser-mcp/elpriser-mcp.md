# elpriser-mcp

> 标签: claude, denmark, dk1, dk2, electricity-prices, elpriser, energidataservice, llm, mcp, model-context-protocol, spotpris

## 简介

MCP server for Danish electricity prices (elpriser.org) — current spot price, cheapest hours, and 7-day forecast for DK1 and DK2.
