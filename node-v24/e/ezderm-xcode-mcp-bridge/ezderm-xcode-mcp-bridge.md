# ezderm-xcode-mcp-bridge

> 标签: apple, ios, macos, mcp, mcpbridge, xcode

## 简介

Shim that invokes Apple's Xcode MCP Bridge (xcrun mcpbridge) for use with MCP-compatible clients like VS Code Copilot.

- npm 页面：https://www.npmjs.com/package/ezderm-xcode-mcp-bridge
