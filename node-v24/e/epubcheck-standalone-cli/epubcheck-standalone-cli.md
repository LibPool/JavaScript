# epubcheck-standalone-cli

> 标签: accessibility, cli, command-line, ebook, epub, epub3, epubcheck, ncx, npx, opf, standalone, teavm, validation, validator, w3c

## 简介

The official EPUBCheck command line with no Java to install: same flags, console output, JSON, XML, and XMP reports, and exit codes as the official tool, byte-identical, run straight from npx.
