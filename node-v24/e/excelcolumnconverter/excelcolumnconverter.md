# excelcolumnconverter

> 标签: JavaScript

## 简介

**Excel Column Converter** is a simple npm package that helps convert numbers to Excel-style column names  (e.g., `1 → A`, `28 → AB`) and Excel column names back to numbers (e.g., `A → 1`, `AB → 28`).
