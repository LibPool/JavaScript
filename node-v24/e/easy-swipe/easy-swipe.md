# easy-swipe

> 标签: vue, vue-swipe

## 简介

一个简单的轮播图插件 # 运行 * npm install * npm run serve # slideList * type:Array * 轮播图片list # activeIndex * type:Number * 开始播放第一张图片的索引，默认0 # duration * type:Number * 轮播间隔，默认3000 即 3s # arrow * type:String * 切换箭头的显示时机 * nerver 不显示 * always 一直显示 * h
