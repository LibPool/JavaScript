# envmetrics

> 标签: cgroup, container, cpu, docker, kubernetes, memory, metrics, monitoring, observability, resource

## 简介

A lightweight, cgroup-aware Node.js library that returns current resource usage as a fraction of actual usable limits — correctly across bare metal, Docker, and Kubernetes.
