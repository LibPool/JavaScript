# ego-lite-bridge

> 标签: ai-agent, browser-automation, cdp, chrome-devtools-protocol, claude-code, codex, ego-browser, ego-lite, puppeteer, windows

## 简介

Windows-compatible replacement for the ego lite browser runtime. Bridges ego-browser CLI to standard Chrome via CDP.
