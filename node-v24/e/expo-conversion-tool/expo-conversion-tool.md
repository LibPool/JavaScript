# expo-conversion-tool

> 标签: JavaScript

## 简介

This is the React Native to Expo CLI tool to check if React Native packages can be converted to Expo packages.

## 官网

- npm 页面：https://www.npmjs.com/package/expo-conversion-tool

## 历史版本号

- 0.1.0

## 获取地址

- npm 安装：`npm install expo-conversion-tool`
- npm registry：https://registry.npmjs.org/expo-conversion-tool
- Node 要求：>=16.7.0
