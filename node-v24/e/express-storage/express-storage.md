# express-storage

> 标签: aws-s3, azure, azure-blob-storage, cloud-storage, express, express-middleware, file-upload, file-upload-middleware, file-validation, gcs, google-cloud-storage, multer, multer-alternative, multi-cloud, multipart-upload, nodejs, object-storage, presigned-url, s3, s3-upload, secure-upload, storage, streaming-upload, typescript, upload

## 简介

Express.js file upload middleware for AWS S3, Google Cloud Storage, Azure Blob & local disk. Unified API with presigned URLs, file validation, streaming uploads, TypeScript support, and zero-config provider switching.
