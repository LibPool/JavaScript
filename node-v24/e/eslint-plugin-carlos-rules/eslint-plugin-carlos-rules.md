# eslint-plugin-carlos-rules

> 标签: ast, eslint, eslint-plugin, guide, static-analysis, tutorial, typescript

## 简介

ESLint 插件：通过限制函数参数数量并推荐使用对象参数模式来提高代码质量。包含了自定义规则 max-params-plus，支持函数声明、箭头函数、类方法等多种场景的检查。
