# easy-date

> 标签: Easy Date, EasyDate, Format, Javascript Date, Javascript date format, Rails Date, Rails like javascript date, date format, ruby date

## 简介

EasyDate is a Javascript extension for easy dates manipulations which is heavily inspired by Rails ActiveSupport::Duration class.
