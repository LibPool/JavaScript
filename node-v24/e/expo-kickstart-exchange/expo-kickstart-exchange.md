# expo-kickstart-exchange

> 标签: ads, config-plugin, cross-promotion, expo, expo-module, ios, kickstart, kickstart-exchange, react-native, swiftui

## 简介

Kickstart Exchange banner adverts for Expo apps - an Expo module wrapping KickstartSDK's SwiftUI advert view, plus a config plugin for the iOS deployment target.
