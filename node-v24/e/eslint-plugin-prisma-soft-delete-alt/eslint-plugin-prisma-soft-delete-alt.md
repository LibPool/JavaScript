# eslint-plugin-prisma-soft-delete-alt

> 标签: custom-eslint-rule, eslint, prisma, prisma-soft-delete, soft-delete, typescript, typescript-eslint

## 简介

This eslint plugin is used to force developers to use `{ deleted: null }` or `{ deletedAt: null }` filter in where query.
