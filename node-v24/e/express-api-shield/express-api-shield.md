# express-api-shield

> 标签: api, api-key, cors, express, helmet, middleware, rate-limit, sanitize, security, shield

## 简介

A single, composable Express middleware combining API key auth, security headers, rate limiting, IP filtering, injection detection, request IDs, and more.
