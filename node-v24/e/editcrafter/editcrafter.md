# editcrafter

> 标签: code-block, collaborative, custom-editor, drag-and-drop, editor, file-handler, image-upload, markdown, markdown-editor, placeholder, react, react-components, react-editor, react-ui, rich-text, tailwindcss, text-editor, text-styling, tiptap, typescript, wysiwyg

## 简介

A powerful, customizable rich text editor built with Tiptap for React applications. Features image management with bubble menus, table support, and extensive formatting options.
