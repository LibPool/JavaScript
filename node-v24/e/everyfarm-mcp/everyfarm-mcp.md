# everyfarm-mcp

> 标签: agriculture, crops, every.farm, farm, geospatial, mcp, model-context-protocol, robotics, satellite

## 简介

MCP server for Every.Farm: farm data, datasets, satellite analyses, robot missions and the public Crop Picker API as agent tools. A thin wrapper over https://api.every.farm/v1 — auth, farm scoping, rate limits and the human-publish rule for missions all s
