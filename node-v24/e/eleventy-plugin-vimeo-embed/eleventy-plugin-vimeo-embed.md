# eleventy-plugin-vimeo-embed

> 标签: 11ty, eleventy, eleventy-plugin, vimeo

## 简介

An Eleventy plugin to automatically embed Vimeo videos, using just their URLs.

- 官网：https://gfscott.com/embed-everything/
- 源码仓库：git+https://github.com/gfscott/eleventy-plugin-embed-everything.git
