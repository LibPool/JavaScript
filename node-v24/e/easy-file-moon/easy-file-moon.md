# easy-file-moon

> 标签: JavaScript

## 简介

file('name').write('content')와 같이 직관적이고 인간 중심적인 문법으로 파일 읽기, 쓰기, 삭제를 간편하게 처리할 수 있는 파일 시스템 도구입니다.
