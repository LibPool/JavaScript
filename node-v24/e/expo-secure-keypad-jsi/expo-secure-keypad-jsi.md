# expo-secure-keypad-jsi

> 标签: SecureKeypadJsi, expo, expo-secure-keypad-jsi, react-native

## 简介

Secure PIN / password keypad for Expo (New Architecture). Natively rendered shuffled keys, the entered value never enters the JS runtime, mlock'd C++ buffer, OpenSSL RSA-OAEP ciphertext only. Screen-capture blocking and device integrity are the host app's
