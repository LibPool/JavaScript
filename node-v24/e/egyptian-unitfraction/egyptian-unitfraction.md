# egyptian-unitfraction

> 标签: egyptian fractions, egyptian fractions algorithm, fraction

## 简介

Egyptian Unit Fraction is a small Node library for finding unit fractions in an Egyptian way. In the Egyptian fraction approach, we can present any positive rational fraction in a sum of distinct unit fractions.  For example:  3/11 can be presented in Egy
