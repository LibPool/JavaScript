# epx-frame

> 标签: JavaScript

## 简介

EPX Frame 是一个基于 Vue 2.7 的低代码开发平台，通过代码和页面组件配置相结合的方式，实现快速构建企业级应用。平台采用配置驱动的架构，开发者可以通过可视化配置页面和组件，无需编写大量重复代码即可构建完整的业务系统。
