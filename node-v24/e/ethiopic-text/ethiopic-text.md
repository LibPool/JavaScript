# ethiopic-text

> 标签: amharic, ethiopic, fold, ge-ez, geez, i18n, normalization, search, tigrinya, typescript, unicode

## 简介

Search, matching, and normalization for Ethiopic script (Amharic, Tigrinya, Ge'ez). Fixes homophone folding — "ሠላም" matching "ሰላም". Zero dependencies.
