# easy-bdd-tool-jest

> 标签: assertion, bdd, jest, tdd, test, testing

## 简介

Easy BDD Tool, for Jest. Create your BDD tests directly in code, and get readable error messages. Exports to Gherkin/Cucumber feature files.
