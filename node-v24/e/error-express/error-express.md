# error-express

> 标签: catch-express-error, error-express, error-handler, error-middleware, express, express-async-errors, express-error, express-error-handler, global-error, global-error-express, sa3akash, throw-express-error

## 简介

A lightweight, zero-dependency package to handle global errors in Express.js applications. It catches unhandled errors and provides a simple, yet powerful way to manage them.
