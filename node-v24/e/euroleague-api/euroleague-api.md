# euroleague-api

> 标签: api-client, basketball, basketball-data, boxscore, eurocup, euroleague, play-by-play, sdk, sports-data, statistics, typescript

## 简介

Unofficial TypeScript SDK for EuroLeague and EuroCup public APIs — browser and Node 20+, Zod-validated, live demo at aimon7.github.io/euroleague-api-demo/docs.
