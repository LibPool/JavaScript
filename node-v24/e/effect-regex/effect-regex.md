# effect-regex

> 标签: ast, backreferences, builder, capture-groups, effect, fluent-api, lookahead, lookbehind, mcp, model-context-protocol, pattern, pcre, re2, regex, regexp, security, type-safe, typescript, validation

## 简介

Type-safe, composable regex builder for TypeScript using Effect. Build patterns with a fluent API that compiles to multiple dialects (JS, RE2, PCRE).
