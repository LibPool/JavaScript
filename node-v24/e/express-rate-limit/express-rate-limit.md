# express-rate-limit

> 标签: attack, auth, authorization, brute, brute-force, bruteforce, express, express-rate-limit, force, ip, limit, middleware, rate, rate-limit, ratelimit, security

## 简介

Basic IP rate-limiting middleware for Express. Use to limit repeated requests to public APIs and/or endpoints such as password reset.
