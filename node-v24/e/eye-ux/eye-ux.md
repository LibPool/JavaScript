# eye-ux

> 标签: JavaScript

## 简介

EyeUX enables hands-free scrolling in your React web applications through real-time eye tracking powered by WebGazer.js. It offers seamless integration via a simple React provider and hook system, allowing you to bring gaze-based interaction into your app
