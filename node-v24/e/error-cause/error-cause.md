# error-cause

> 标签: aggregateerror, ecmascript, error, evalerror, javascript, polyfill, rangeerror, referenceerror, shim, syntaxerror, typeerror, urierror

## 简介

An ES-spec-compliant shim/polyfill/replacement for the `.cause` property on all Error types that works as far down as ES3
