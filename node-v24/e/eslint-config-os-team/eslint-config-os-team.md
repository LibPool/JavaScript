# eslint-config-os-team

> 标签: JavaScript

## 简介

ESLint rules, including TypeScript (without React). Extends `eslint-config-airbnb-base` and `eslint-config-os-team-base`. If you need React, see [eslint-config-os-team-react](https://www.npmjs.com/package/eslint-config-os-team-react).
