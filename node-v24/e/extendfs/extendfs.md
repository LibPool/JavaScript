# extendfs

> 标签: copy, delete, directory, file, file system, fs, util, utility

## 简介

ExtendFS is a module to extend Node's default File System (fs) module to recursively copy/delete directories with callbacks to notify the caller upon each successful copy/delete of a file or directory and upon completion of the whole process.
