# expo-runtime-app-icon

> 标签: ExpoDynamicAppIcon, alternate-icon, app-icon, expo, expo-plugin, expo-runtime-app-icon, react-native

## 简介

Change your Expo app's icon at runtime, on iOS and Android, with an Expo config plugin and native module. Compatible with Expo SDK 53 through 57.
