# ember-i18n-fetch-translations

> 标签: ember-addon, ember-i18n

## 简介

Fetch translations for ember-i18n from the server instead of embedding them.

## 官网

- 源码仓库：https://github.com/ecraft/ember-i18n-fetch-translations
- npm 页面：https://www.npmjs.com/package/ember-i18n-fetch-translations

## 获取地址

- npm 安装：`npm install ember-i18n-fetch-translations`
- npm registry：https://registry.npmjs.org/ember-i18n-fetch-translations
- Node 要求：^4.5 || 6.* || >= 7.*
