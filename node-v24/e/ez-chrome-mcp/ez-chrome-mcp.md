# ez-chrome-mcp

> 标签: browser-automation, cdp, chrome, chromium, cursor, debugging, devtools, mcp, model-context-protocol, playwright

## 简介

MCP server for debugging live Chrome tabs — list targets, read console logs, evaluate JavaScript, and capture screenshots over CDP.
