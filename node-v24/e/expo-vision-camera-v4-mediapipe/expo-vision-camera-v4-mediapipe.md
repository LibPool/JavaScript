# expo-vision-camera-v4-mediapipe

> 标签: ai, android, computer-vision, config-plugin, edge-computing, expo, expo-plugin, face-landmarker, frame-processor, gesture-recognition, hand-landmarker, hand-tracking, holistic, machine-learning, mediapipe, pose-landmarker, react-native, sign-language, vision-camera

## 简介

Expo Config Plugin to integrate Google MediaPipe Hand, Pose & Face Landmarker with React Native Vision Camera v4. Real-time, on-device holistic landmark detection (hands, body and face) via native Kotlin Frame Processor Plugin.
