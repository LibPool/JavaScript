# expo-dev-mcp

> 标签: ai, claude, debugging, devtools, expo, mcp, model-context-protocol, react-native, sqlite

## 简介

MCP server for debugging Expo apps — query databases, execute JS, capture network, navigate routes. Works on simulators and physical devices.
