# expressjs-field-validator

> 标签: api-docs, api-documentation, api-validation, body-validation, express, express-js, express-middleware, expressjs, field-validation, header-validation, input-validation, json-validation, middleware, nodejs, params-validation, query-validation, request-body, request-validation, rest-api, sanitization, schema-validation, swagger-alternative, type-checking, validate, validation, validator

## 简介

A powerful, lightweight Express.js middleware for validating request fields (body, query, params, headers) with a fluent, chainable API. Zero dependencies, TypeScript support, and auto API docs generation.
