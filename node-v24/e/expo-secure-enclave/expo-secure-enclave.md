# expo-secure-enclave

> 标签: android, android-keystore, biometric, challenge-response, cryptography, device-binding, ecdsa, expo, expo-module, face-id, hardware-backed, ios, p-256, passwordless, react-native, secure-enclave, signing, strongbox, tee, touch-id

## 简介

Hardware-backed ECDSA P-256 signing for Expo and React Native using the iOS Secure Enclave and Android Keystore/StrongBox, gated by Face ID, Touch ID or fingerprint.
