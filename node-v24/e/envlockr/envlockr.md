# envlockr

> 标签: cli, dotenv, encryption, env, environment-variables, local-first, secrets, secrets-management, security

## 简介

Local-first encrypted secrets CLI — OS-keychain key storage, run-with-secrets injection, and API key liveness checks. Node wrapper for the Python CLI.
