# expo-vitest

> 标签: accessibility, expo, react-native, react-native-web, react-native-windows, testing, vitest

## 简介

Vitest for Expo code on every platform it runs on: one project each for iOS, Android, web and Windows, picked by a test file's name, and a harness that drives the running app and reads its accessibility tree.
