# einvoice-kit-mcp

> 标签: agent, e-invoice, en16931, factur-x, invoice, mcp, model-context-protocol, validation, xrechnung, zugferd

## 简介

MCP server that lets AI agents read and validate EU e-invoices (EN 16931, XRechnung, Factur-X/ZUGFeRD, UBL, CII, Peppol) locally — no uploads, no Java.
