# env-config-jsonc

> 标签: config, configuration, env, jsonc, loader

## 简介

env-config-jsonc 是一个轻量级 Node.js 环境配置加载工具，支持 JSONC（JSON with Comments） 格式的配置文件解析。它允许开发者通过简单的 API 加载和合并多层级配置，并自动挂载到 Node.js 的 process.envconfig 上，方便全局访问
