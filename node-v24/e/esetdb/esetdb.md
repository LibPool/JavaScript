# esetdb

> 标签: db, eset, quick

## 简介

this is esetdb,
const db = require('esetdb');
`name`.db()
`name`.db(`a.add`,`d`)
`name`.db(`a.set`,`d`)
`name`.db(`a.a.del`,`d`)
`name`.db(`a.del`)
`name`.db(`a.a`)
