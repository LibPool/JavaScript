# ebizu-sdk

> 标签: cordova-android, ebizu, ecosystem:cordova

## 简介

We provide a simple way to integrate Ebizu platform services into your Android apps. For both Android, the SDK is provided as a ZIP archive and contains pre-compiled binaries for each architecture

- npm 页面：https://www.npmjs.com/package/ebizu-sdk
