# eslint-plugin-operability

> 标签: ai-assistant, code-quality, data-minimization, debug-code, eslint, eslint-plugin, eslintplugin, interlace-quality, linting, llm-optimized, log-quality, logging, observability, operability, production-ready, sre, static-analysis, typescript

## 简介

ESLint plugin for production operability — bans debug code and console logging in production, verbose error messages, and process.exit calls.
