# evatr-api

> 标签: bzst, evatr, germany, rechtlogisch, vat-id, wrapper

## 简介

Checks a VAT-ID using the eVatR REST-API of the German Federal Central Tax Office (Bundeszentralamt für Steuern, BZSt)
