# eva-plugin-hitarea-dyeing

> 标签: eva.js, plugin

## 简介

在 EvaJs 中，给 Event 设置了 HitArea，如果需要调整点击区域的宽高，位置，形状等参数，本插件可以提供可视化的染色能力
