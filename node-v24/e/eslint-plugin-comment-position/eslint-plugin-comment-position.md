# eslint-plugin-comment-position

> 标签: autofix, code-style, comment-style, comments, eslint, eslint-plugin, eslintplugin, formatting, lint

## 简介

ESLint plugin that enforces a consistent position for line and block comments (above or beside the code they describe), with autofix.
