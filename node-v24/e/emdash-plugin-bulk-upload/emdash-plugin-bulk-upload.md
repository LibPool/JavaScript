# emdash-plugin-bulk-upload

> 标签: admin, bulk-upload, cms, emdash, media, plugin

## 简介

Bulk upload admin page for Emdash CMS: a drag-and-drop queue that creates a reviewed draft entry (with optional linked translation) for every uploaded file
