# elves-components

> 标签: JavaScript

## 简介

* 新增分数（不需要排行） addScore * 获取分数（不需要排行） getScore * 减少分数（不需要排行） minusScore * 新增分数（需要排行） addRankScore * 获取分数（需要排行） getRankScore * 减少分数（需要排行） minusRankScore * 获取排行 getRank * md5加密 md5
