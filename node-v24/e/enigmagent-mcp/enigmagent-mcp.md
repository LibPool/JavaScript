> 标签: aes-256-gcm, ai-agents, argon2id, claude-desktop, credentials, cursor, encryption, enigmagent, llm, mcp, mcp-server, model-context-protocol, openclaw, p2pclaw, secrets, secrets-management, security, vault

## 简介

Local encrypted vault MCP server. AES-256-GCM + Argon2id. Resolves {{PLACEHOLDER}} secrets at runtime so LLMs never see real API keys. Works with Claude Desktop, Cursor, Continue.dev, Cline, Open WebUI.
