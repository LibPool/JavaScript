# email-local-mcp

> 标签: claude, email, gmail, imap, macos, mcp, model-context-protocol, smtp

## 简介

Email Local MCP — a local macOS MCP server that connects multiple email accounts to your AI agent: Gmail, iCloud, Fastmail, or any IMAP host (full CRUD over IMAP/SMTP, App Passwords in the Keychain).
