# express-dedupe

> 标签: api-optimization, cache, concurrent-requests, dedup, dedupe, deduplication, express, express-middleware, http-middleware, in-flight-requests, middleware, node, nodejs, performance, prevent-duplicate-requests, rate-limiting, request-cache, request-coalescing, request-deduplication, request-merging, thundering-herd, thundering-herd-protection, trie, typescript, url-pattern

## 简介

Express middleware to deduplicate concurrent identical HTTP requests — prevents thundering herd, merges in-flight requests, boosts Node.js API performance with TypeScript support
