# ephor

> 标签: agents, ai, constitutional, governance, postgres

## 简介

Ephor — a governed agent organization: a technology company where every operational role is an AI agent, run under a human board and enforced by infrastructure, not prompts. This package reserves the name; the project lives on GitHub.
