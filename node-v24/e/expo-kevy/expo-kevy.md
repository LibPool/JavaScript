# expo-kevy

> 标签: JavaScript

## 简介

kevy embedded in React Native via Expo Modules — the real native engine, synchronous JSI calls, one cmd() entry to all verbs. The MMKV shape (sync scalar get/set) plus everything MMKV doesn't have: TTL, structures, pub/sub, persistence you can read.
