# exlo

> 标签: apg, aws, dynamodb, invoke, lambda, local, node, nodejs, python, ruby, s3, secrets-manager, serverless, sns, sqs, stream

## 简介

A modular toolkit to emulate cloud services locally using high-quality built-in plugins and custom extensions. Includes support for Lambda, S3, SNS, SQS, Secrets Manager, DynamoDB, REST API Gateway and more.
