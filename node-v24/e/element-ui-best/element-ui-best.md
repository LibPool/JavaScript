# element-ui-best

> 标签: components, element-ui, element-ui-best, 二次封装, 组件库, 统一UI, 统一交互

## 简介

element-ui-best 组件库基于 element-ui 二次开发，实现了符合倍施特中后台管理系统的统一视觉风格与交互，并结合业务新增了一些通用组件和指令。从而达到视觉与交互一致性，提升用户体验，提高研发效率。
