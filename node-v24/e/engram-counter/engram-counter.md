# engram-counter

> 标签: ai, audit, engramx, finops, jcs, llm, rfc8785, savings, sigstore, tamper-evident, tokens

## 简介

Open-source AI token savings audit primitive. Apache 2.0. Tamper-evident JCS-canonicalized SHA-256 attestations over paired-run logs. Zero runtime dependencies.
