# eslint-plugin-express-security

> 标签: ai-assistant, api-security, appsec, code-quality, cookies, cors, csrf, cwe, cwe-352, eslint, eslint-plugin, eslintplugin, express, expressjs, graphql, helmet, interlace-security, linting, llm-optimized, node, nodejs, open-redirect, owasp, rate-limiting, redos, sast, security, security-headers, static-analysis, typescript, vulnerability, web-security

## 简介

ESLint plugin for Express.js security — detects permissive CORS, missing CSRF protection, missing helmet headers, insecure cookies, and GraphQL introspection in production.
