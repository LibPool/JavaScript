# eslint-plugin-i18n-toolbox

> 标签: eslint, eslint-plugin, eslintplugin, i18n, i18n-toolbox

## 简介

A powerful ESLint plugin streamlining i18n migration and maintenance. Automates extraction of Chinese strings into structured locale JSON files, enforces wrapping with custom i18n methods via fixable rules, and validates key consistency across codebase.
