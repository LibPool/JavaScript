# excel-to-prisma

> 标签: excel, excel-converter, excel-to-prisma, excel-to-prisma-convert, excel-to-prisma-converter, prisma, prisma-converter

## 简介

excel-to-prisma is a package that parses Excel data and converts it into a data object that can be used in Prisma ORM
