# esnpm

> 标签: JavaScript

## 简介

Converts npm packages to native ES6 modules which can be imported directly from browsers without bundlers and transpilers.

## 官网

- 源码仓库：https://github.com/sgtpep/esnpm.git
- npm 页面：https://www.npmjs.com/package/esnpm
