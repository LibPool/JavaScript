# edge-cart-mcp

> 标签: ai, cart-drawer, claude, edge-cart, mcp, model-context-protocol, shopify, shopify-app

## 简介

Connect an AI assistant to your Edge Cart cart drawer on Shopify. Read drawer setup, upsells, reward tiers and performance, and prepare changes as drafts for review.
