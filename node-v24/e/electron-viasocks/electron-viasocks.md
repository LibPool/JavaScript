# electron-viasocks

> 标签: bridge, electron, electron-session, proxy, proxy-auth, socks, socks5

## 简介

Bridge a SOCKS4/5 proxy with username/password authentication into a local HTTP proxy that Electron's session.setProxy() can consume.
