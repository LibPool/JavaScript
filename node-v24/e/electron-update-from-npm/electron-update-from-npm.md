# electron-update-from-npm

> 标签: auto-update, desktop-shortcut, electron, electron-updater, github, macos, npm, npx, private-repo, self-update, start-menu, windows

## 简介

Self-update and launcher shortcuts for Electron apps installed from npm or GitHub, private repos too (npm i -g / npx) — no installers, no code signing
