# eslint-plugin-unicode-comments

> 标签: eslint, eslint-plugin, homograph-attack, security, trojan-source, unicode

## 简介

ESLint plugin flagging dangerous Unicode characters (Trojan Source, homograph attacks) and typographic tells of unedited AI-generated code (em dashes, curly quotes, ellipsis, non-breaking spaces)
