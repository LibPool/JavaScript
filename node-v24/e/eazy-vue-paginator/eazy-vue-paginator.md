# eazy-vue-paginator

> 标签: eazy pagination, eazy to use pagination, fast pagination, pagination, simple pagination, vuejs, vuejs pagination

## 简介

A Vue.js eazy to use paginator plugin. It works well for paginating a collection of data of any length.
