# emil

> 标签: Bootstrap, Jade, Less, SMACSS, webvariants

## 简介

EMIL is a collection of extended Mixins written in Less and Jade based on the most popular HTML, CSS, and JS framework for developing responsive, mobile first projects on the web, Bootstrap.
