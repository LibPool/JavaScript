# express-greenborn-mercado-pago

> 标签: express, greenborn, instore, mercado-pago, mercadopago, node, payment, payments, qr, webhook

## 简介

Integración centralizada con Mercado Pago para backends Express/Node.js: API client (axios) sobre api.mercadopago.com y webhook receptor con deduplicación, con inyección de dependencias (knex, logger) y agnóstico del esquema de base de datos. Diseñado par
