# easymem

> 标签: agent-memory, ai, bm25, claude-code, codex, full-text-search, knowledge-base, knowledge-graph, llm-wiki, mcp, mcp-server, memory, opencode, wiki, 知识库, 维基

## 简介

An LLM wiki your coding agent writes — agent memory you can open and read. The agent does the writing; easymem does the storage, full-text search and knowledge graph. No embedding model, no vector database.
