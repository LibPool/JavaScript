# effectable

> 标签: bootstrap, command-bus, component, connect, effectable, event-bus, graph-runtime, lifecycle, nodejs, reactive, redux, runtime, rxjs, store, typescript

## 简介

Declarative reactive runtime for Node.js: bootstrap, Redux-style RxJS store, Component lifecycle, class-based connect, and GraphRuntime.
