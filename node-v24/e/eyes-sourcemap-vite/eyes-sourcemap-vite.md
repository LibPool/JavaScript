# eyes-sourcemap-vite

> 标签: source-map-plugin, sourcemap, sourcemap-upload, vite-plugin, vite-source-map

## 简介

A Vite plugin for uploading source maps to monitoring services. Simplify source map management and error tracking in production builds.
