# express-structure

> 标签: JavaScript

## 简介

. ├── node_modules 第三方包存储目录(使用npm装包默认生成) ├── controller 控制器 ├── database 数据库配置 ├── models 模型 ├── public 静态资源（图片、样式、客户端js...） ├── views 视图(存储HTML视图文件) ├── app.js 应用程序启动入口（加载Express，启动HTTP服务。。。） ├── config 应用配置文件（把经常需要改动的数据放到配置文件中，修改方便） ├── utils 存
