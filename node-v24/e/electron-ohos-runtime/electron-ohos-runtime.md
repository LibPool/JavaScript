# electron-ohos-runtime

> 标签: aarch64, arm64, electron, harmonyos, ohos, openharmony, runtime

## 简介

Prebuilt Electron runtime shared libraries for OpenHarmony (ARM aarch64), auto-extracted to a configured directory on install.
