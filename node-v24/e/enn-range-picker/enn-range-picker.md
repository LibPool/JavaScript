# enn-range-picker

> 标签: @vue/compat, ant-design-vue, date-picker, moment, range-picker, standalone, vue3

## 简介

Vue 3 (@vue/compat) standalone RangePicker wrapper that auto-loads ant-design-vue@2 + moment from CDN (no extra host deps).
