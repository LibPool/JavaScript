# elizaos-plugin-crewpay

> 标签: ai-agent, crewpay, elizaos, fee-share, kol, pump.fun, solana

## 简介

ElizaOS plugin for CrewPay — Solana Pump.fun KOL Autohire + fee-shares (60/15/25; 60/15/5/20 with referralCode). Buyback cron not live. Dry-run returns dryRunId + approvalUrl before launch.
