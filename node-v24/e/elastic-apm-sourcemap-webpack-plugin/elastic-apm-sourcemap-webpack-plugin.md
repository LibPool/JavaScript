# elastic-apm-sourcemap-webpack-plugin

> 标签: apm, elastic, elasticapm, sourcemap, webpack

## 简介

ElasticAPMSourceMapPlugin is a Webpack plugin that uploads sourcemaps generated by Webpack to a Elastic APM server.
