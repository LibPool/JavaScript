# expo-variant-checker

> 标签: app-variants, ci, doctor, eas, eas-build, eas-update, expo, lint

## 简介

Catches silent drift between Expo/EAS app variants before it ships: colliding deep link schemes, mismatched EAS Update channel/environment pairs, stale local native projects, and duplicate bundle identifiers. Read-only — safe for CI.
