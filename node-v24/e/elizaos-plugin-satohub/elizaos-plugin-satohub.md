# elizaos-plugin-satohub

> 标签: crypto, elizaos, elizaos-plugin, mcp, onchain-agents, plugin, satohub, web3

## 简介

elizaOS plugin for Sato Hub: search the scored onchain-agent index, run a Preflight check before installing or trading, get a swap-venue recommendation with the fee disclosed, and turn a goal into a build plan of real listings. Read-only and non-custodial
