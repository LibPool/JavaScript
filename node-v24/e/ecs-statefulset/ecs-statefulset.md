# ecs-statefulset

> 标签: JavaScript

## 简介

A reusable AWS CDK construct for deploying **stateful services** (like Zookeeper, Apache Pinot, etc.)  on **ECS Fargate** with persistent storage using EBS Volumes and Snapshots with internal service discovery.
