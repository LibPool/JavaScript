# eruda-plus

> 标签: console, debug, devtools, eruda, har, i18n, inspect, mobile, mobile-debug, mock, network, network-panel, proxy, throttling

## 简介

Enhanced mobile web console: eruda with Chrome DevTools experience (bilingual UI, DevTools-style Network panel, block/rewrite/mock/throttle, HAR, Live Expressions and more)
