# expo-ios-mov-to-mp4-picker

> 标签: ExpoIosMovToMp4Picker, expo, expo-ios-mov-to-mp4-picker, react-native

## 简介

Pick ios .mov file from photos app. Returns a compressed audio and video version of that .mov file. Best used for backend uploads, ai server uploads
