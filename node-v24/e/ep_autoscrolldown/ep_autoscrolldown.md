# ep_autoscrolldown

> 标签: deaf, etherpad, lecture, scrolling, student

## 简介

This Etherpad module auto-scroll down the pad when the content is modified.

This module was part of an academic project for courses accessibility from Paris 8 University/THIM Lab.
