# el-table-vue

> 标签: antd-table, columns, el-table, element-ui, table, vue, vue2

## 简介

对 Element-UI 的 el-table 进行二次封装，提供类似 antd Design Table 的 columns 配置方式，支持 JSX 和 scoped slots 自定义渲染
