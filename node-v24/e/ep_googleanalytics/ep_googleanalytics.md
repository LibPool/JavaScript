# ep_googleanalytics

> 标签: JavaScript

## 简介

Add Google Analytics to Etherpad Lite -- IMPORTANT: Add the following to your settings.json file -- "ep_googleanalytics":{"trackingCode":"UA-2387498"} (for the up-to-date analytics.js) or "ep_googleanalytics":{"gaCode":"UA-2387498"} (for the legacy ga.js)
