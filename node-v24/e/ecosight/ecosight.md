# ecosight

> 标签: ci-monitoring, dashboard, devops, ecosight, github-actions, npu, open-source-community

## 简介

EcoSight (ES) — open-source community governance platform. GitHub Actions CI NPU card-hours / queue-time / duration monitoring dashboard. Single binary, zero runtime dependencies.
