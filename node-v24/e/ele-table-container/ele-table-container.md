# ele-table-container

> 标签: el-table, json, table

## 简介

- element-ui@2.15.11 / vue@2.7.14 封装 Table 组件 - 基于 100%原生 API - 实现 JSON 动态驱动表单 - 为实现自定义表格 / 嵌套表头等需求仅新增 [**slotName**](guide/eleTable?id=自定义列模板) / [**children**](guide/eleTable?id=多级表头) 两个字段 - [文档地址(demo)]()
