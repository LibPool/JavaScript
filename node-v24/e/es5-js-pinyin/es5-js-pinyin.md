# es5-js-pinyin

> 标签: JavaScript

## 简介

把汉字转化为拼音字母，由[chinalu/JSPinyin](https://github.com/chinalu/JSPinyin)改写，使用新语法并去掉mootools的依赖

- npm 页面：https://www.npmjs.com/package/es5-js-pinyin
