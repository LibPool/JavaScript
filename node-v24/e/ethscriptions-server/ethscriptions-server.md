# ethscriptions-server

> 标签: JavaScript

## 简介

Enhanced Ethscriptions API server. Caches, validates inputs and outputs with Zod, and unifies Ethscriptions API's responses, according to ESIP-9. Includes support for resolving ENS on-chain / off-chain names, and Ethscriptions names.
