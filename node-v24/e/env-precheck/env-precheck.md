# env-precheck

> 标签: ci, cli, configuration, deployment, dotenv, env-example, env-validation, environment-variables, secrets, typescript

## 简介

Validate .env files and CI environment variables against annotated .env.example contracts. Catch missing variables and invalid types without logging secret values.
