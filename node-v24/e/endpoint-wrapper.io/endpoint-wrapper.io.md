# endpoint-wrapper.io

> 标签: endpoint.io, socket.io, websocket, websockets

## 简介

endpoint.io is [express](https://expressjs.com) middleware that wraps around [socket.io](socket.io), which manages the socket object as a singleton, and exposes it
