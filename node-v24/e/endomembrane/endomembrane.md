# endomembrane

> 标签: JavaScript

## 简介

Endomembrane is a tiny controller (as in MVC) wrapper around the immutable.js library used to completely separate the model from the view. It features a very simple API (only 5 functions!) that encourages to keep this separation throughout your project.
