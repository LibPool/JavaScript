# eslint-plugin-pragmatic-deprecate

> 标签: eslint, eslint-plugin, eslintplugin

## 简介

let's you decprecate and refactor code step by step: 1. deprecate functions, constants, class etc 2. disable the use for these deprecated functions in future 3. refactor sensibly
