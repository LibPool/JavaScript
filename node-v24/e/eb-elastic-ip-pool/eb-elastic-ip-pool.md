# eb-elastic-ip-pool

> 标签: aws, eb, ec2, elastic-ip, node.js

## 简介

This package allows you to configure an Elastic IP pool for your node.js app. If the machine this packge runs on in an AWS EC2 instance, it will ensure that some elastic IP from that pool is associated to this instance.
