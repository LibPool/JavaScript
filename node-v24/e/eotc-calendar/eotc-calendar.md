# eotc-calendar

> 标签: calendar, church, easter, eotc, ethiopian, feasts, orthodox, tewahedo

## 简介

Javascript (written in Typescript) library to calculate movable feasts in the Ethiopian Orthodox Tewahedo Church calendar
