# eslint-plugin-innerurl

> 标签: eslint, eslint-plugin, eslintplugin

## 简介

检测img标签中的src属性是否为内网地址（以https://mdn.alipayobjects.com开头）

## 官网

- npm 页面：https://www.npmjs.com/package/eslint-plugin-innerurl

## 历史版本号

- 0.0.0
- 0.1.0

## 获取地址

- npm 安装：`npm install eslint-plugin-innerurl`
- npm registry：https://registry.npmjs.org/eslint-plugin-innerurl
- Node 要求：^14.17.0 || ^16.0.0 || >= 18.0.0
