# efterscript

> 标签: distillation, interpreter, pdf, postscript, wasm

## 简介

A memory-safe, embeddable interpreter compatible with the PostScript language, written in Rust, whose primary output is PDF. This package is a placeholder for the forthcoming WebAssembly build; the engine is published as Rust crates today.
