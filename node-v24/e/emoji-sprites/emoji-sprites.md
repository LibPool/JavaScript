# emoji-sprites

> 标签: emoji, fluentui-emoji, noto-emoji, sprites, spritesheet, twemoji

## 简介

Pre-rendered emoji sprite sheets for Twemoji, Fluent UI Emoji, and Noto Emoji, with typed data and lookup helpers.
