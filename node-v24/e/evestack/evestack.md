# evestack

> 标签: agent, cli, diagnostics, eve, graphile-worker, postgres, queue, scaffold, self-hosted, workflow

## 简介

Run AI agents on your own machine. `evestack create` sets up an agent and a dashboard, `evestack attach` adds them to a project you already have, and `evestack doctor` explains why a job stopped moving.
