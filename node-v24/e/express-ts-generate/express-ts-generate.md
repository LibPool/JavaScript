# express-ts-generate

> 标签: express, express-generator, generator, ts, typescript

## 简介

This is a simple package which utilizes the official express-generator package as a base, and then converts the generated project into a TypeScript equivalent. The project generated will have the same structure as what you get by using express-generator.
