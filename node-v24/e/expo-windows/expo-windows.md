# expo-windows

> 标签: expo, expo-modules-core, metro, react-native-windows, windows, winui

## 简介

Windows for Expo apps on react-native-windows: the Metro config for the platform, an Expo Modules Core over the JavaScript registry, the modules the Expo packages call with a C++ library behind them, and the app scaffold.
