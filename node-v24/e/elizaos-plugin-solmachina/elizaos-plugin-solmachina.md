# elizaos-plugin-solmachina

> 标签: agent, ai-agents, base, decision, defi, eliza, elizaos, elizaos-plugin, financial-firewall, plugin, risk, solana, solmachina, trading, usdc, x402

## 简介

SolMachina financial firewall for ElizaOS agents — EXECUTE/REVIEW/REJECT + a signed, time-boxed authorization before a trade, paid per call in USDC over x402 (Solana + Base).
