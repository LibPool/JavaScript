# entz-editor

> 标签: collaborative, crdt, editor, entz, loro, rich-text, spacetimedb, wasm, webgpu

## 简介

The entz rich text editor for the web: the <entz-editor> element on one Rust engine in a worker, Loro documents synced through SpacetimeDB, a bridge protocol and a React component
