# epochcalc-mcp

> 标签: cron, dst, epoch, mcp, model-context-protocol, time, timezone, unix-timestamp

## 简介

MCP server for time and date math: Unix timestamps, DST-aware time zone conversion, durations, cron schedules, countdowns. Zero-dependency stdio bridge to the hosted epochcalc.com server.

## 官网

- 官网：https://epochcalc.com/api
- 源码仓库：git+https://github.com/cmunkres/epochcalc-mcp.git
- npm 页面：https://www.npmjs.com/package/epochcalc-mcp
