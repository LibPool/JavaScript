# ekolite

> 标签: fastify, framework, mongodb, pubsub, realtime, rpc, typescript, websocket

## 简介

A lightweight, real-time backend framework for data-driven apps. Fastify + MongoDB + WebSocket with typed pub/sub, RPC methods, and file uploads.
