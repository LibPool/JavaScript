# esp-ble-sdk

> 标签: arduino, ble, bluetooth, esp32, iot, web-bluetooth

## 简介

A typed TypeScript SDK for talking to ESP32 devices over Web Bluetooth, with a matching Arduino/ESP-IDF firmware library and npm library.
