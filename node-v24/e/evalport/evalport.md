# evalport

> 标签: ci, eval, evaluation, llm, local-first, prompt, regression, snapshot, testing

## 简介

Local-first regression testing for LLM/prompt outputs: define cases with deterministic assertions, snapshot results, fail CI when a prompt regresses.
