# expo-telegram-auth

> 标签: expo, expo-telegram-auth, oauth, oidc, react-native, telegram, telegram-login

## 简介

Native Telegram Login for Expo apps — wraps Telegram's official Android and iOS Login SDKs for a browser-free, app-to-app OAuth flow that returns an OIDC id_token
