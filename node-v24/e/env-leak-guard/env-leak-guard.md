# env-leak-guard

> 标签: api-keys, ci-cd, devops, env, leak-detector, pre-commit, secret-scanner, secrets, security

## 简介

Blazing fast zero-dependency scanner to detect leaked API keys, tokens, credentials, and database secrets in source code, build outputs, and git staging.
