# empty-h

> 标签: JavaScript

## 简介

`empty.h` 是一个 C++ 第三方头文件，提供了一套简洁的语法糖来获取各种数据类型的默认值。通过统一的 `empty` 接口，可以安全、清晰地初始化变量，特别适用于模板编程和现代 C++ 开发。
