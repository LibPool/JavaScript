# ecogo-runtime

> 标签: client, ecogo, ecohub, json, runtime, sse

## 简介

EcoHub 调用 runtime（Node/浏览器）：受控连接池、无损 JSON codec、SSE/1 流式消费（单消费者 AsyncIterable）、摘要元数据核对。
