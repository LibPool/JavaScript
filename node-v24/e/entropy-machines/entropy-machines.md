# entropy-machines

> 标签: agents, claude-code, git-worktree, orchestration, workflow

## 简介

Vendors the entropy-machines agent-orchestration harness into your git repository as plain tracked files. A delivery mechanism, not a runtime — the harness is POSIX shell and Python 3 and needs no Node once the files have landed.
