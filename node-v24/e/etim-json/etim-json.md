# etim-json

> 标签: b2b, classification, etim, etim-classification, json, mcp, mcp-server, model-context-protocol, pim, product-data, typescript

## 简介

The ETIM classification model as clean JSON — convert, validate, generate TypeScript types, search, and serve to AI agents over MCP. Ships no ETIM data; converts the model you are licensed to download.
