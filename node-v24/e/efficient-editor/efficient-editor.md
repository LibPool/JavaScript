# efficient-editor

> 标签: editor, leaf, menu, next, rail, react, rsc, toolbar, ui-shell

## 简介

The EFFICIENT editors' shared engine and chrome: the saved document as pure functions, the published renderer, and the editor frame, panels, Layers tree, text grammar and type-in-place box. Published as editor-shell up to 0.66.0.
