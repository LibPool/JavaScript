# eslint-plugin-no-penetrating-import

> 标签: eslint, eslint-plugin, eslintplugin

## 简介

Forbid importing from subpaths of another package in monorepos.

## 官网

- npm 页面：https://www.npmjs.com/package/eslint-plugin-no-penetrating-import

- npm 安装：`npm install eslint-plugin-no-penetrating-import`
- npm registry：https://registry.npmjs.org/eslint-plugin-no-penetrating-import
- Node 要求：^14.17.0 || ^16.0.0 || >= 18.0.0
