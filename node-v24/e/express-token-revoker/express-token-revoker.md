# express-token-revoker

> 标签: blacklist, bloom-filter, express, grpc, jwt, middleware, revocation, security, token

## 简介

High-performance, crash-safe token revocation middleware for Express — Bloom filters with automatic rotation, WAL-based crash recovery, and optional gRPC admin.
