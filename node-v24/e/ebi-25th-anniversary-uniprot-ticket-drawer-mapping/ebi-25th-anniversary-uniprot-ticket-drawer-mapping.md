# ebi-25th-anniversary-uniprot-ticket-drawer-mapping

> 标签: JavaScript

## 简介

Creates consistent (ie on any machine) mappings: drawer --> ticket and ticket --> drawer to be used in UniProt's game at the EBI 25th anniversary celebration.
