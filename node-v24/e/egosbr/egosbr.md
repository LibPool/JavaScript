# egosbr

> 标签: a2a, diagnostico, egos, ia, mcp, model-context-protocol, pt-br

## 简介

EGOS na linha de comando: as portas para usar o EGOS de qualquer IA, o diagnóstico 'cabe IA?' e uma ponte stdio para o conector MCP público (sem senha).

## 官网

- 官网：https://egos.ia.br/portas/
- 源码仓库：git+https://github.com/enioxt/egos-plugins.git
- npm 页面：https://www.npmjs.com/package/egosbr
