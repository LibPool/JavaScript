# egis-map

> 标签: JavaScript

## 简介

基于 [MapboxGL] 二次研发扩展的二三维地图 SDK。在 [MapboxGL] 的基础上优化 SDK 的响应速度和加载速度、支持 4490地图加载以及三维扩展和本地部署等等，并且支持 [MapboxGL] 的其他组件扩展
