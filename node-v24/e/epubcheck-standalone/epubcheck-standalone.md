# epubcheck-standalone

> 标签: accessibility, browser, ebook, epub, epub3, epubcheck, ncx, opf, opfs, standalone, teavm, validation, validator, w3c, worker

## 简介

EPUBCheck, the official W3C EPUB validator, compiled to plain JavaScript with TeaVM: an embeddable library that validates EPUBs in Node.js and the browser with byte-identical output to the Java tool, no Java to install.
