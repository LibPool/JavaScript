# es-arraybuffer-base64

> 标签: API, ArrayBuffer, Uint8Array, base64, ecmascript, es-shim, javascript

## 简介

An ES-spec-compliant shim/polyfill/replacement for ArrayBuffer base64 methods that works as far down as ES3
