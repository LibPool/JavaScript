# eleventy-rosetta

> 标签: 11ty, blog, eleventy, eleventy-plugin, eleventy-starter, eleventy-theme, i18n, multilingual, nunjucks, pagefind

## 简介

A multilingual Eleventy blog theme: translated routes, translated tags, a language switcher that lands on the right page, Pagefind search, light/dark design tokens — no CSS framework.
