# express-typed-rpc

> 标签: RPC, api, backend, browser-client, client-server, code-generation, express, express-api, express.js, fully-typed, http, http-api, json, json-api, middleware, node.js, react, tRPC, type, type-safe, typed-api, typescript, unit-testing, web-api, web-development

## 简介

Easily create a fully-typed Express JSON RPC API over HTTP. No code generation step required. Inspired by tRPC, but much simpler.
