# easy-review-mcp

> 标签: code-review, easy-review, github, mcp, model-context-protocol, pull-request

## 简介

npx launcher for the Easy Review MCP server (er-mcp). Installs the prebuilt binary via platform-specific optional dependencies; falls back to GitHub Releases.
