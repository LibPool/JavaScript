> 标签: ai-agents, ai-coding-agents, code-review, coverage, deepseek-harness, dsh-plugin, git, security-audit, skill

## 简介

Deterministic fact producers for security auditing: which deleted code came from a security fix, and which changed symbols no test ever executed.
