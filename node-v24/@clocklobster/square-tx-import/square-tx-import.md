# @clocklobster/square-tx-import

> 标签: bookkeeping, orders, payments, payouts, sales, square, typescript, webhooks

## 简介

Import Square sales records for bookkeeping: Orders + Payments + Payouts adaption, webhook freshness signals, and Events-API missed-delivery backfill. No Invoices API, no Reporting API, no MCP runtime.
