# @minecms/core

> 标签: cms, headless-cms, minecms, schemas-as-code, typescript, zod

## 简介

Ядро MineCMS — defineSchema, defineField, defineConfig, type-level вывод и Zod-валидация. Schemas-as-code основа для headless CMS на TypeScript.
