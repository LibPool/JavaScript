# @withicons/loaders

> 标签: activity-indicator, ai-agents, animated-svg, css-animation, icons, loader, loaders, loading, loading-indicator, morph, progress, react, reduced-motion, skeleton, spinner, spinners, svg-animation, vue, web-components, with-icons, withicons

## 简介

50 animated loaders (common, creative, festival) + icon morph sequences in all 34 with icons styles. One self-contained SVG each: works as <img>, inline, <with-loader>, React or Vue. Pure CSS animation, zero dependencies.
