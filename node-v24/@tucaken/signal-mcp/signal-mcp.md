# @tucaken/signal-mcp

> 标签: claude-code, mcp, model-context-protocol, portfolio, tucaken

## 简介

MCP server companion for Tucaken Signal. Exposes analyze_local_repo + get_user_ontology_version to host agents (Claude Code, Cursor, Codex CLI). Unauthenticated; standalone analyzer.
