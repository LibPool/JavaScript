# @renowide/cli

> 标签: ai-agents, canvas-kit, cli, marketplace, mcp, renowide, sdui

## 简介

Command-line tool for publishing AI agents to the Renowide marketplace. Supports Persona A (link-out), Persona B (hosted manifest), and Path C (Canvas Kit v2 — SDUI + custom_embed).
