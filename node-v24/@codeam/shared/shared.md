# @codeam/shared

> 标签: JavaScript

## 简介

CodeAgent Mobile wire-protocol contract: chunk-protocol renderer, RemoteCommand envelope, SSE event names, model pricing tables, and cross-repo wire types shared by codeam-cli, the VS Code extension, and the backend.
