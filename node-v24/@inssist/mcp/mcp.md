# @inssist/mcp

> 标签: ai-agent, browser-automation, claude, claude-code, codex, content-scheduling, cursor, inssist, instagram, instagram-analytics, instagram-automation, instagram-dm, instagram-mcp, mcp, mcp-server, model-context-protocol, post-scheduler, social-media

## 简介

MCP server that drives a real logged-in Instagram session through the INSSIST Chrome extension: read profiles, posts and DMs, publish and schedule content, pull analytics, download media.
