# @atak-reactive/sdk

> 标签: android, android-team-awareness-kit, atak, atak-plugin, cot, cursor-on-target, geospatial, react, react-hooks, tak, typescript, webview-bridge

## 简介

TypeScript SDK and React hooks for building ATAK (Android Team Awareness Kit) plugin UIs with a typed WebView bridge to the ATAK map engine.
