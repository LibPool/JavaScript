# @starstack/strapi-plugin-auto-save

> 标签: auto-save, autosave, content-manager, draft, productivity, strapi, strapi-plugin, strapi5

## 简介

Automatically saves Strapi v5 content entries as you type. Debounced background saves, live status indicator, and zero configuration required.
