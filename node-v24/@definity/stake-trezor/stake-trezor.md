# @definity/stake-trezor

> 标签: definSOL, definity, hardware-wallet, solana, staking, trezor

## 简介

Trezor hardware-wallet support for @definity/stake — carries the pinned @trezor/connect stack so the base CLI stays minimal. Install alongside @definity/stake to enable --trezor.
