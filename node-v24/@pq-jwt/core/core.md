# @pq-jwt/core

> 标签: authentication, cryptography, dilithium, fips-204, jwt, ml-dsa, nist, post-quantum, pqc, slh-dsa, sphincs, token

## 简介

Post-quantum JWT library using NIST-standardized ML-DSA and SLH-DSA. Drop-in successor to RS256/ES256.
