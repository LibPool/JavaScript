# @suverselabs/x402-client

> 标签: buyer, client, cosmos, evm, http-402, multi-chain, payment-required, solana, stablecoin, suverse-pay, tron, usdc, wallet, x402

## 简介

Unified buyer SDK for the x402 payment protocol. One client, one config — pays any seller across 18 EVM mainnets, Cosmos Noble, TRON, Solana, and the testnets behind them. Wraps the suverse-pay facilitator by default.
