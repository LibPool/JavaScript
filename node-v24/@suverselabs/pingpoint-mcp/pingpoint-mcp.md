# @suverselabs/pingpoint-mcp

> 标签: ai-agents, arc, carbon-footprint, claude, crypto-payments, driver-location, eld, freight, freight-tracking, freight-visibility, gps, load-tracking, logistics, mcp, mcp-server, model-context-protocol, telematics, trucking, typescript, usdc, x402

## 简介

MCP server for freight tracking: your AI agent creates a load, the driver joins from an SMS link, then the agent reads live truck GPS, stop timeline, ETA and post-trip stats, or cancels it. API key or pay per call in USDC on Arc, Base or Solana (x402).
