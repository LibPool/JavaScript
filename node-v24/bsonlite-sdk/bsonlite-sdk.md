# bsonlite-sdk

> 标签: bson, bsonlite, bsonlite-console, cli, database, desktop, encrypted-storage, nodejs, offline, windows

## 简介

A portable database SDK for Node.js and Windows apps, with encryption and automatic BsonLite Console and CLI connections.
