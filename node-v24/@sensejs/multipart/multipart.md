# @sensejs/multipart

> 标签: JavaScript

## 简介

This package, `@sensejs/multipart`, provides a high-level multipart body parser based on `@fastify/busboy` that supports custom storage provider and back pressure. It does not depend on any other part of SenseJS, and can be used standalone with any other
