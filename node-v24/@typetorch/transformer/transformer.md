# @typetorch/transformer

> 标签: dependency-injection, guards, macros, rbxts, roblox-ts, transformer, typetorch

## 简介

roblox-ts transformer for TypeTorch: user macros (generated t guards, stable type ids) and DI class metadata. A stripped-down fork of rbxts-transformer-flamework.
