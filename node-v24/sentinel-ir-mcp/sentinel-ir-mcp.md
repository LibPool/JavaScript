# sentinel-ir-mcp

> 标签: ai-agent, claude, code-analysis, cursor, javascript, llm, mcp, mcp-server, model-context-protocol, sentinel-ir, static-analysis, tree-sitter, typescript, windsurf

## 简介

MCP server for sentinel-ir: lets AI agents (Claude Desktop, Cursor, Windsurf, ...) read a compact structural IR of JavaScript and TypeScript files instead of the raw source. Read-only, sandboxed to allowed folders.
