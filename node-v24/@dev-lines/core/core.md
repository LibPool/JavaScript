# @dev-lines/core

> 标签: css, debug, devtools, grid, guides, layout, outline, overlay, react, ruler

## 简介

Framework-agnostic layout debug overlay: center/width/padding guides + depth-colored section outlines, labels, and distances. Zero dependencies.
