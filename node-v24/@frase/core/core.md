# @frase/core

> 标签: aeo, agent, ai-visibility, api-client, content, frase, geo, seo

## 简介

Frase Core — Shared API client, types, and utilities for building on the Frase content platform. Powers the Frase CLI and MCP Server. Build custom integrations for SEO, GEO, AI search visibility, content hosting, and automation.
