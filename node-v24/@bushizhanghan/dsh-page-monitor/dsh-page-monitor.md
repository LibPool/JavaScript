# @bushizhanghan/dsh-page-monitor

> 标签: change-detection, cordis, cordis-plugin, deepseek-harness, dsh, dsh-plugin, monitor, notify, page-watch, watchlist, web

## 简介

Webpage watch agent for DeepSeek Harness: track a watchlist of URLs, take snapshots, detect important changes, and notify. 网页监控：盯一批网页，变化自动发现并通知。
