# @easylabs/browser

> 标签: browser, easy-labs, payments, sdk, vanilla-js

## 简介

Easy Labs SDK for the browser — framework-agnostic vanilla JavaScript client. Use with Vue, Angular, Svelte, HTMX, vanilla, or any other web framework. For React, use @easylabs/react.
