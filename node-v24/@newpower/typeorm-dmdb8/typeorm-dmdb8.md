# @newpower/typeorm-dmdb8

> 标签: JavaScript

## 简介

Data-Mapper ORM for TypeScript and ES2021+. Supports DmDB, MySQL/MariaDB, PostgreSQL, MS SQL Server, Oracle, SAP HANA, SQLite, MongoDB databases.
