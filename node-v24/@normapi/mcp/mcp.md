# @normapi/mcp

> 标签: e-invoice, e-rechnung, en16931, factur-x, kosit, mcp, model-context-protocol, xrechnung, zugferd

## 简介

MCP server for German e-invoices: validate, generate and read XRechnung and ZUGFeRD against the official KoSIT rules, with a plain-language explanation for every business-rule finding.
