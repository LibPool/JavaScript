# @nexod/twist

> 标签: JavaScript

## 简介

Cross-product Twist client. Wraps `@doist/twist-sdk` with a Nexod-flavored factory (`createTwistClient`) and OAuth helpers (`buildAuthorizationUrl`, `exchangeAuthorizationCode`).
