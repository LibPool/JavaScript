# figma-code-builder

> 标签: accessibility, agent, angular, code-generation, copilot, design-system, figma, figma-mcp, material, mcp, react, vue, vuetify

## 简介

AI agent kit that turns Figma designs into Angular, React or Vue code using your design system. Installs agents and skills into .github/ for GitHub Copilot / VS Code.
