# elizaos-plugin-aether

> 标签: aether, agent-payments, ai-agents, elizaos, elizaos-plugin, post-quantum, usdc, wallet, x402

## 简介

ElizaOS plugin for Aether: an agent wallet with spending limits that pays for APIs (x402), sends AETH and USDC, and finds paid services in the on-chain directory.
