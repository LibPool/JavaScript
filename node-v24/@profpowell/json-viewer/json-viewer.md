# @profpowell/json-viewer

> 标签: custom-elements, json-viewer, profpowell-web-components, tree-view, vanilla-breeze, vanilla-js, web-components

## 简介

A standalone JSON viewer web component with collapsible tree, path/glob API, source-data search, and no runtime dependencies.
