# @profpowell/browser-console

> 标签: browser, console, custom-elements, debug, developer-tools, devtools, logging, profpowell-web-components, vanilla-js, web-components

## 简介

A zero-dependency vanilla JavaScript web component that captures and displays browser console output with syntax highlighting and type-aware formatting
