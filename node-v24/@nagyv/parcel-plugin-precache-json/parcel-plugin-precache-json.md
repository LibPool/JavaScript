# @nagyv/parcel-plugin-precache-json

> 标签: JavaScript

## 简介

Parcel plugin that generates a precache manifest json of the bundle to be injected into [Workbox'](https://developers.google.com/web/tools/workbox) `precacheAndRoute`.
