# @awacloud/tool-fw-codegen

> 标签: JavaScript

## 简介

Code-generation tools for @awacloud/fw-shaped packages: generates the module-name to factory instance-type registry, injects the deps companion field on modules, and produces a read-only audit report of factory return-type annotations.
