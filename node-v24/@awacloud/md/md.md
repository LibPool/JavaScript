# @awacloud/md

> 标签: ast, browser, commonmark, gfm, markdown, parser, sanitize, serializer, worker-safe

## 简介

Browser-safe Markdown parser and serializer — CommonMark 0.31 and GitHub Flavored Markdown, core plus opt-in extras. Zero runtime dependency beyond @awacloud/fw.
