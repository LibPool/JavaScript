# @awacloud/ooxml

> 标签: browser, docx, drawingml, ecma-376, office, ooxml, opc, pptx, presentationml, spreadsheetml, wordprocessingml, xlsx

## 简介

Browser-safe OOXML (ECMA-376) reader/writer for .docx, .xlsx and .pptx — typed core, opt-in extras covering the rest of the schema. Zero runtime dependency beyond @awacloud/fw.
