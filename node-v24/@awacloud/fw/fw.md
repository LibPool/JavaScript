# @awacloud/fw

> 标签: awa, browser, crypto, dependency-injection, esm, framework, import-maps, lockdown, post-quantum, rendering, service-worker, wasm, web-worker, webcrypto, zero-dependencies

## 简介

Zero-dependency browser framework: a DI module runtime with 200+ ESM modules — codecs, compression, crypto (WebCrypto + WASM tiers, post-quantum), DOM rendering and query, workers, security lockdown — usable without a bundler via import maps.
