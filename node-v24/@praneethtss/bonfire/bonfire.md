# @praneethtss/bonfire

> 标签: ai, cli, coding-assistant, ink, llama.cpp, local-first, mcp, ollama, terminal, tui

## 简介

A local-first terminal coding assistant. Streams tokens, previews diffs, and runs against any local model via Ollama or llama.cpp.
