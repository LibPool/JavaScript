# @aravindhasamy/apihandler

> 标签: API Request, Accept header, Authorization, Authorization header (Bearer token), Buffer handling, Cache-control, Content-Type header, Custom header, Error handling, Fetch API, Fetch request, File handling (images, PDF), Flexible API utility, HTTP methods (GET, POST, PATCH, DELETE), Network errors, No-cache, Query parameters, Request Body (POST, PATCH), Structured error messages

## 简介

The apiRequest function is a flexible utility designed to handle HTTP requests of various types, including GET, POST, PATCH, and DELETE. It supports making API calls to external services, handling different response types, and customizing request headers
