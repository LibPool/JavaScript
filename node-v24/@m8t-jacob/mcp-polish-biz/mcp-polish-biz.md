> 标签: ai-tools, anthropic, claude, mcp, mcp-server, model-context-protocol, nbp, nip, poland, polish, vat, vies

## 简介

MCP (Model Context Protocol) server exposing Polish business data tools to AI agents: NIP/PESEL/REGON/IBAN/KRS validation, VAT whitelist, EU VIES lookup, and NBP exchange rates.
