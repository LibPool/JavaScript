# @he0119/dsh-tailnet-admin

> 标签: deepseek-harness, dsh, dsh-plugin, loopback, remote-admin, reverse-proxy, tailnet, tailscale

## 简介

把 Tailnet / 反向代理页面当作「本机」来用：启用 host 持久化设置，并按需关闭浏览器会话校验（Host/Origin 栅栏保持不动）。
