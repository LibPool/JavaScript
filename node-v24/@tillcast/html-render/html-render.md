# @tillcast/html-render

> 标签: html, point-of-sale, preview, receipt, receiptline, tillcast, wasm, webassembly

## 简介

The Tillcast HTML renderer for JavaScript: the same Rust that the Tillcast print service uses to draw receipts, compiled to WebAssembly. It renders blocks and ReceiptLine text to HTML for a screen, HTML for a mail, or text, for the layout of a printer pro
