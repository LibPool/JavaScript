# @jsx-contracts/core

> 标签: composition, contracts, design-system, eslint, jsx, slots

## 简介

The shared contract-format kernel for JSX composition contracts — the row schema, its JSON schema, the runtime validator and the condition prose the @jsx-contracts/eslint-plugin enforces and @jsx-contracts/authoring compiles to.
