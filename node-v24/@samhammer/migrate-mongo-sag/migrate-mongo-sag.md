# @samhammer/migrate-mongo-sag

> 标签: migration, mongodb

## 简介

migrate-mongo-sag is a database migration tool for MongoDB running in Node.js<br> it provides some additional functionality to the original migrate-mongo https://github.com/seppevs/migrate-mongo
