# @ngruychev/json-schema-to-ts

> 标签: json, schema, ts, type, typescript

## 简介

Infer TypeScript types from your JSON schemas — @ngruychev fork adding the draft-07 ignoreRefSiblings option for $ref-sibling / recursive schemas.
