# @stickergalaxy/arcade-ui

> 标签: arcade, css, design-system, miniapp, sticker-galaxy, telegram, ui, vanilla-ts

## 简介

Engine-agnostic CSS + vanilla-TS UI kit for Sticker Galaxy Arcade games. Parchment surfaces, Hollow Knight effects, leaderboard, result screen, settings modal, onboarding, and title screen.
