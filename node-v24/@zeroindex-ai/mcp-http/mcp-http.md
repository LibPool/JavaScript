# @zeroindex-ai/mcp-http

> 标签: http, http-client, mcp, model-context-protocol, rate-limit, retry

## 简介

Small HTTP client shared by @zeroindex-ai/mcp-* servers — auth (bearer/body/none), 30s timeout, 429 + x-ratelimit-remaining retry, structured HttpError.
