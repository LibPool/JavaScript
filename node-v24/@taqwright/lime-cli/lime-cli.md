# @taqwright/lime-cli

> 标签: appium, cli, e2e, lime, mobile-testing, qa, taqwright, test-automation

## 简介

Thin CLI client for the LIME server — fire a natural-language QA Agent goal against a connected device and write back a taqwright spec.
