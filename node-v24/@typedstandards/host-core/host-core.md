# @typedstandards/host-core

> 标签: commitment-view, provenance, record-package, static-host, trust-registry, typed-standards, verification

## 简介

Serve signed Typed Standards records from a static host: build the bundles, the key registry and a versioned index from what the CLI's sign and withdraw print, check and verify what is served, print verifier links, and apply a display policy. Holds no key
