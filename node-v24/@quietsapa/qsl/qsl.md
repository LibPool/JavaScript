# @quietsapa/qsl

> 标签: feature-flags, lazy-loading, orchestration, performance, script-loader, tag-manager, third-party-scripts

## 简介

A modern orchestrator for the third-party code that has to live in the browser. Scripts, styles, pixels and custom elements, with dependencies, triggers, conditions and timeouts.
