# @tapestry-ui/combobox

> 标签: a11y, autocomplete, combobox, headless, preact, select, tapestry-ui, typeahead, wcag

## 简介

A WCAG 2.1 AA combobox for Preact — type to filter or open the whole list, APG keyboard, match highlighting, headless behavior, skin via CSS. The polished replacement for a native select.
