# @tapestry-ui/ask

> 标签: a11y, assistant, chat, headless, panel, preact, tapestry-ui, wcag

## 简介

A WCAG 2.1 AA ask panel for Preact — a floating conversation that takes a question, shows the answer, and leaves the page behind it live. Headless behavior, skin via CSS; you supply the answering.
