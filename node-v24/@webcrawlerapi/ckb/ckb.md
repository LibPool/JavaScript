# @webcrawlerapi/ckb

> 标签: JavaScript

## 简介

A command-line tool for building a searchable knowledge base. Documents are stored in Cloudflare R2 and indexed for keyword, hybrid, and semantic retrieval via Cloudflare AI Search (AutoRAG).
