# blueprintjs-react-table

> 标签: blueprint, blueprintjs, datagrid, react, table, tanstack-table, typescript, virtualized

## 简介

A Blueprint.js-styled data table for React, built on TanStack Table v9 with row virtualization, quadrant layout, and Blueprint-style focus & selection.
