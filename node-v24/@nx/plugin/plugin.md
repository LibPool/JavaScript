# @nx/plugin

> 标签: CLI, Monorepo, Nx

## 简介

This plugin is used to create Nx plugins! It contains generators for generating common plugin features like generators, executors, migrations and more.

- 官网：https://nx.dev
- 源码仓库：https://github.com/nrwl/nx.git
