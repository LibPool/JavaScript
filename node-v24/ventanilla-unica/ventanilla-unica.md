# ventanilla-unica

> 标签: aeat, certificado-digital, clave, dehu, hacienda, sede-electronica, seguridad-social, spain, tgss

## 简介

Command-line client for the Spanish public administration portals (AEAT, TGSS, SEPE, DEHU, OARGT, CIRBE) with the holder's own certificate: reads by default, local PAdES and XAdES signing, confirmed writes.
