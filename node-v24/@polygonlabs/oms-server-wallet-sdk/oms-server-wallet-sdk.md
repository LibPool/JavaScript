# @polygonlabs/oms-server-wallet-sdk

> 标签: oidc, oms, polygon, typescript, waas, wallet

## 简介

Standalone TypeScript SDK for attested OMS server wallets, sponsored transfers, and durable Trails swaps and recovery.
