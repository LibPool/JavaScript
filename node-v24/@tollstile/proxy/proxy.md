> 标签: agent-payments, api-gateway, api-monetization, fastapi, fastmcp, gateway, http-402, mcp, mcp-payments, mpp, pay-per-call, proxy, python, reverse-proxy, x402

## 简介

Put a paid gateway in front of any HTTP API or MCP server — FastAPI, FastMCP, Rails, Go — and charge per route or per tool with x402, MPP, credits, and subscriptions. No code changes in the upstream service.
