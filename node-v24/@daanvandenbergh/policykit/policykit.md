# @daanvandenbergh/policykit

> 标签: JavaScript

## 简介

Versioned legal policies as MDX for Next.js App Router: a directory per revision, a file per locale, and a Policy class that answers which revision binds now, what notice is owed, and renders any revision in any locale - plus Claude Code rules and a skill
