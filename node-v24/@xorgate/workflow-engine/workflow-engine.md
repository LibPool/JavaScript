# @xorgate/workflow-engine

> 标签: computer-vision, edge, engine, iot, onnx, telemetry, video, workflow, xorgate

## 简介

The xorgate workflow engine as a library and the xwe command: run workflow templates over video and telemetry files with a 28-node catalog, including code function nodes, no platform account required.
