# @xorgate/react

> 标签: hooks, iot, react, replay, telemetry, video, webrtc, xorgate

## 简介

Headless React SDK for the xorgate platform: data hooks, live telemetry over MQTT, live video over WebRTC, and the recorded-media replay player.

- 源码仓库：git+https://github.com/epyelabs/xorgate-react.git
