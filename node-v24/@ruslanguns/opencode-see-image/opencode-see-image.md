# @ruslanguns/opencode-see-image

> 标签: glm, image, minimax, opencode, opencode-plugin, screenshot, vision

## 简介

Give non-vision opencode models the ability to see images/screenshots by routing them to a vision-capable model (MiniMax M3 via opencode-go by default).
