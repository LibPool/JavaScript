# @fuzo/soccer-board

> 标签: angular, canvas, component, drag-drop, export, field, football, formation, player, soccer, tactical

## 简介

A beautiful, interactive soccer field component for Angular applications. Create tactical formations, manage player positions, and export your field as PNG images.
