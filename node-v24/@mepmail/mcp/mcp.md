# @mepmail/mcp

> 标签: JavaScript

## 简介

MepMail MCP server for local clients (stdio): send and inspect transactional email, and read and answer Correio mailboxes, from Claude, Cursor and any MCP client. MepMail's API is compatible with the Resend wire protocol.
