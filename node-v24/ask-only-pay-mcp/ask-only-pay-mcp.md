# ask-only-pay-mcp

> 标签: ai-agents, approval, claude, human-in-the-loop, mcp, mcp-server, model-context-protocol, mtls, payments

## 简介

MCP server that lets an AI agent ask for a payment or an account signup, but never do it. A separate approver shows a person its own recap over mTLS; the agent only sees an id and a state.
