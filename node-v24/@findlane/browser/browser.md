# @findlane/browser

> 标签: autocomplete, browser, ecommerce search, findlane, full-text search, instant search, react, search, typo tolerance

## 简介

Findlane browser SDK: fast, typo-tolerant public search from the browser with an index's public ID, plus React hooks and components.
