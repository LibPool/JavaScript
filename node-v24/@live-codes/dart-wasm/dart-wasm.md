# @live-codes/dart-wasm

> 标签: compiler, dart, flutter, livecodes, playground, wasm, webassembly

## 简介

Run Dart and Flutter entirely in the browser, with no compilation server. The DartPad SDK — DDC, the analyzer and a subset of pub — behind a small promise-based API.
