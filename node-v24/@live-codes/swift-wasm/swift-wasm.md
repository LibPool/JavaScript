# @live-codes/swift-wasm

> 标签: compiler, livecodes, playground, swift, wasi, wasm, webassembly

## 简介

Client-side Swift for LiveCodes: compile and run Swift in the browser with no server, using the wasm-hosted Swift toolchain (swift-frontend + wasm-ld).
