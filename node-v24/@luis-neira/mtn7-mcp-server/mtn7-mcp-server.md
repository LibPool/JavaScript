# @luis-neira/mtn7-mcp-server

> 标签: documentation, mantine, mcp, modelcontextprotocol

## 简介

An MCP (modelcontextprotocol.io) server that serves a local, offline snapshot of the Mantine v7 documentation over stdio. Built on the official @modelcontextprotocol/sdk; reads its data from bundled local files instead of fetching from mantine.dev.
