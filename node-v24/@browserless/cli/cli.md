# @browserless/cli

> 标签: automation, browserless, chrome, cli, command-line, headless, pdf, puppeteer, screenshot, terminal, tool, web-scraping

## 简介

Command-line interface for headless browser automation. Take screenshots, generate PDFs, and extract content from websites.

- 源码仓库：git+https://github.com/microlinkhq/browserless.git#master
