# @browserless/lighthouse

> 标签: accessibility, audit, browserless, chrome, headless, lighthouse, metrics, performance, puppeteer, pwa, seo, web-vitals

## 简介

Run Google Lighthouse audits on websites using headless Chrome. Get performance, accessibility, and SEO metrics.

- 源码仓库：git+https://github.com/microlinkhq/browserless.git#master
