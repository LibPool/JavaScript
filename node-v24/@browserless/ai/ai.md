# @browserless/ai

> 标签: ai, browserless, chrome, gemini-nano, headless, language-detector, prompt, puppeteer, summarizer, translator

## 简介

Run Chrome Built-in AI APIs (Prompt, Summarizer, Translator, Language Detector) from Node.js using browserless.
