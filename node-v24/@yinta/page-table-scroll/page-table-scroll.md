# @yinta/page-table-scroll

> 标签: JavaScript

## 简介

> 基于element-ui 的el-table、el-pagination组件，通过监听页面滚动以及页面内容宽高变化，修改el-table、el-pagination样式，实现表格头部的固定在页面顶部以及分页器固定显示在页面底部
