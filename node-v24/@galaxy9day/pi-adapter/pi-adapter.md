> 标签: ai-agent, anthropic, channel-audit, claude-code, codex, codex-cli, executor, mcp, model-context-protocol, pi, pi-coder, trellis

## 简介

Dual-executor MCP (Codex CLI for GPT implementation, Pi CLI for cross-model review) for Trellis-aware and standalone use. Reads Trellis task artifacts, runs the executor in an isolated subprocess/worktree, and can optionally emit non-invasive Trellis chan
