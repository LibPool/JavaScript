# @mohamadjavadx/piechart

> 标签: a11y, accessibility, animation, chart, custom element, donut chart, pie chart, react, svg, typescript, web component

## 简介

An animated, accessible pie / donut chart for the web (SVG, no dependencies): a web component, a React component and a plain class. The same look and features as the Android PieChart library.
