# @albymbiju/express-pretty-logger

> 标签: ansi, debug, express, http, jwt, logger, logging, mask-sensitive, middleware, pretty-logger, sanitizer, security, terminal

## 简介

A clean, beautiful, and secure terminal logger middleware for Express.js with automatic sensitive data masking, response interception, and ANSI styling.
