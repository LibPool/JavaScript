# @synadia-ai/nats-claude-code-headless

> 标签: agent-protocol, agents, anthropic, claude, claude-code, nats, synadia-agents

## 简介

Headless NATS agent host that spawns, prompts, and stops Claude Code sessions as first-class Synadia Agent Protocol for NATS v0.3 instances. Each session registers as agents.prompt.cc-headless.<owner>.<session_id>; a small controller service adds verb-fir
