# @hytaleone/query

> 标签: game-server, hytale, hytale-server, motd, nodejs, ping, player-list, query, server-list, server-query, server-status, status, typescript, udp

## 简介

TypeScript/JavaScript client for querying Hytale servers. Get server status, player count, player list, and plugin information via UDP protocol.
