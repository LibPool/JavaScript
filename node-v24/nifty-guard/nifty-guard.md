# nifty-guard

> 标签: ai, claude-code, cursor, hooks, npm, pypi, security, slopsquatting, supply-chain, typosquatting

## 简介

Catch made-up (AI-hallucinated), lookalike and brand-new npm and PyPI packages before they're installed. A CLI and hooks for Claude Code and Cursor.
