# @coinranking/supplies

> 标签: altcoin, bitcoin, blockchain, circulating supply, coin, coinranking, crypto, cryptocurrencies, cryptocurrency, ethereum, max supply, supplies, total supply

## 简介

Cryptocurrency supply data library in JavaScript (open source) for getting total, circulating and max supplies from block explorers.

- 源码仓库：git+https://github.com/coinranking/supplies.git
- npm 页面：https://www.npmjs.com/package/@coinranking/supplies
