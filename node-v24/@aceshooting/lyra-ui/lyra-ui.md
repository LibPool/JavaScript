> 标签: accessible-components, agent-ui, charts, chat-ui, component-library, custom-elements, dashboard, data-table, data-visualization, design-system, internationalization, lit, lit-element, rtl, shoelace-alternative, storybook, ui-library, web-awesome, web-awesome-alternative, web-components

## 简介

Free, independent Lit web components: an open-source alternative to Shoelace and Web Awesome with accessible forms, dashboards, charts, and agent UI.
