# @geonosis/walk

> 标签: accessibility, audit, ci, contrast, gate, playwright, probe

## 简介

The customer walk as a gate: fourteen probes over a list of URLs, thirteen computed-DOM readings and axe’s accessibility rules, one JSON report, and an exit code that tells a could-not-run from a clean page.
