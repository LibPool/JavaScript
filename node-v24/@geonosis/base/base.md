# @geonosis/base

> 标签: bin-harness, helpers, package-root, zero-dependency

## 简介

The bottom of the method: the helpers every package would otherwise copy — value guards and error text that run anywhere, a package's own root and version, and the harness that runs a package's bin in its tests. No dependency, and nothing above it.
