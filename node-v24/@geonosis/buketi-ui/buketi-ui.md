# @geonosis/buketi-ui

> 标签: commerce, components, react, storefront, themekit, ui

## 简介

A commerce storefront's UI as a kit: the atoms and molecules of the six-tier ladder, themed through @geonosis/themekit, knowing nothing about Next, next-intl, Medusa or the app's stores.
