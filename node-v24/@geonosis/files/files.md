# @geonosis/files

> 标签: files, multi-tenant, object-storage, paths, upload

## 简介

Where a file lives and where its bytes live: one shape for a folder and a name that can never climb out, an object key with the tenant in it, a size a person can read, an icon per content type as the consumer's table.
