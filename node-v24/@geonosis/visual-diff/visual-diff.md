# @geonosis/visual-diff

> 标签: baseline, pixel-diff, pixelmatch, png, screenshot-diff, visual-regression

## 简介

Pixel comparison, reporting and baseline management for visual regression — the union of a Medusa storefront's and a Workers + D1 app's forks. Capture stays with the consumer; nothing here launches a browser.
