# @constructive-db/machine-runner

> 标签: pty, remote-control, terminal, websocket

## 简介

The machine runner: a Node daemon installed on a user's own machine that dials out to a machine relay over WebSocket, spawns policy-checked processes in a pty, and streams their bytes back. No inbound port, ever.
