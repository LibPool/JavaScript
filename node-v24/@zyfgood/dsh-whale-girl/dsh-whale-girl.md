# @zyfgood/dsh-whale-girl

> 标签: cordis, deepseek-harness, desktop-pet, dsh, dsh-plugin, web-ui

## 简介

DeepSeek Harness 插件：鲸鱼女孩桌宠。住在 Web GUI 角落的小鲸鱼——Agent 干活时游泳、调工具时吐泡泡、等审批时敲玻璃、完成时空翻庆祝；支持摸摸喂食等互动与好感度成长，好感星级解锁亲昵徽章、换装挂饰与更丰富的表情动作，并提供 whale_say 工具让 Agent 借她说话。纯程序化 SVG/CSS 动画，零素材依赖。
