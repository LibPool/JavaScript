# dsh-derive-watcher

> 标签: deepseek-harness, dsh, dsh-plugin, journey, semantic-watcher

## 简介

语义监视者（L3）：会话语义旅程账本、flash 总结、新颖性判定、里程碑折叠、上下文注入、三级语义停滞响应，以及右侧栏干预时间线（timeline）。v0.3.2 fixes npm pack files 配置（排除 replay/transcripts 与 replay/replay-ledger 的真实会话录音、test/ 目录）。
