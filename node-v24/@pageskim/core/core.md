# @pageskim/core

> 标签: agents, ai, llm, llms-txt, markdown, pageskim, seo, tokens

## 简介

Pure, isomorphic conversion library for the PageSkim format: parse HTML → extract → emit .llm.md/.llm.json. Single source of truth used by the CLI, browser SDK, and playground.
