# tofu-box

> 标签: deepseek-harness, dsh, dsh-plugin, pack, tofu-box

## 简介

TOFU BOX 伞包：一条命令装齐 tofu-zyc 的全套 dsh 插件（model-tuning、read-image-preview、shell-selector、computer-use、mcp-ui、billing-card）。本包不含代码，只做两件事：以 dependencies 拉入六个子包，以 patch 层注册它们的插件行——即 dsh-base 同款 bundle 模式。装本包或单装子包，二选一，不要混装。
