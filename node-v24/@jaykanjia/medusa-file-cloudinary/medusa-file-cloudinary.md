# @jaykanjia/medusa-file-cloudinary

> 标签: cloud-storage, cloudinary, cloudinary-storage, cloudinary-upload, file-cloudinary, file-provider, file-upload, image-upload, media-storage, media-upload, medusa, medusa-file, medusa-file-cloudinary, medusa-plugin, medusa-plugin-cloudinary, medusa-plugin-file, medusa-plugin-other, medusa-storage, medusa-v2, plugin

## 简介

A Medusa plugin to use Cloudinary as a file storage provider. Seamlessly upload, retrieve, and manage media files in your Medusa store using Cloudinary.
