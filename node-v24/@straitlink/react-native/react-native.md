# @straitlink/react-native

> 标签: app-links, attribution, deep-linking, deferred-deep-linking, dynamic-links, react-native, universal-links

## 简介

Deep linking for React Native: direct links (App Links, Universal Links, custom schemes), deferred links that survive the install (Play Install Referrer, iPhone device matching or paste handoff, the workspace's choice) and link-open analytics.
