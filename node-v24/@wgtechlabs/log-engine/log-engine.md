> 标签: bot, cjs, compliance, data-redaction, discord, esm, express, fastify, gdpr, javascript, json-logging, koa, log, logger, logging, mit-license, nestjs, nodejs, opensource, pii-protection, privacy, redaction, security, structured-logging, telegram, typescript, winston-alternative, zero-dependencies

## 简介

A lightweight, security-first logging utility with automatic data redaction for Node.js applications - the first logging library with built-in PII protection.
