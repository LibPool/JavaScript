# @jfa/arangoose

> 标签: JavaScript

## 简介

Simple ORM for ArangoDB, based on [Mongoose](https://github.com/Automattic/mongoose) and [ORMjs](https://github.com/uMaxmaxmaximus/ui-js/tree/master/server/core/orm)
