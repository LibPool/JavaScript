# @myagentmail/react

> 标签: anjal, auth, linkedin, myagentmail, outreach, react, widget

## 简介

React widgets + headless SDK for Anjal (formerly MyAgentMail). Drop-in <LinkedInConnect> for connecting accounts and <CadenceBuilder> for editing server-side outreach sequences. Pairs with linkedInProxyHandler / mamProxyHandler in @myagentmail/react/serve
