# dsh-whale-browser

> 标签: automation, browser-automation, browser-use, cdp, chrome-devtools-protocol, computer-use, deepseek-harness, dsh, dsh-plugin, plugin

## 简介

给小鲸鱼一双手：零依赖 CDP 直驱一个专用 Chromium，让 agent 像人一样读网页、点按钮、填表单、滚动、截图；每次操作先经用户授权，密码由用户自己输入。
