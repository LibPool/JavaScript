# @deffector/agent

> 标签: debugger, devtools, effector, nextjs, react, react-native, solid, ssr, state-management, time-travel, vue

## 简介

DevTools for effector: every user action as one transaction, time travel, state injection, effect overrides and replayable traces. The agent that runs in your app.
