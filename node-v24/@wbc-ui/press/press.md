# @wbc-ui/press

> 标签: content-graph, dark-mode, documentation, dynamic-routes, mini-framework, navigation, rss, search, sitemap, ssg, wbc, wbc-ui2

## 简介

wb-press — a content-graph mini-framework: feed it one navigation.js and it renders the whole site (menu, sidebar, routes, content) through WBC. Built on @wbc-ui/core's link/route engine.
