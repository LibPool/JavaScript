# @matatbread/matbot-tool-json-validation

> 标签: agent, ai, llm, matbot, matbot-plugin

## 简介

Validates tool-call inputs against each tool's JSON Schema, registered as core's ToolCallValidator so EVERY invocation door (the runner, HTTP tool routes, invokeTool) is checked at the executor rather than only the model's path.
