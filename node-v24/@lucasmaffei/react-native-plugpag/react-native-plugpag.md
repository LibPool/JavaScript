# @lucasmaffei/react-native-plugpag

> 标签: android, ios, react-native

## 简介

React Native library for PagBank/PagSeguro PlugPag SmartPOS: payments, refund, NFC and thermal printing (text, image, QR). New Architecture, TypeScript, Kotlin.
