# @dumpling_memory/elpis

> 标签: JavaScript

## 简介

Elpis 是一个以 Koa 作为 BFF 层、以 Vue3 + Element Plus 作为前端运行时的企业级领域模型建站框架。它的核心目标是：用一份领域模型配置描述系统、菜单、页面、字段和接口契约，让框架自动生成后台网站的通用页面，把开发者从重复的列表、搜索、表单、详情、删除等 CRUD 工作中释放出来。
