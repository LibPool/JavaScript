# n8n-sunset

> 标签: anthropic, ci, claude, cli, deprecation, gemini, migration, n8n, n8n-3, openai, workflow

## 简介

Scan n8n workflow exports for OpenAI, Anthropic and Google Gemini model shutdowns, OpenAI endpoint shutdowns (Assistants API, Videos API, prompt objects, ...), and nodes removed or changed in n8n 3.0.
