# @moribashi/auth

> 标签: JavaScript

## 简介

Authentication as a standard moribashi plugin: bearer-token validation against one or more OIDC issuers, a typed `Principal` in the request DI scope, a small enforcement API (`SecurityService`), and optional workload identity for services on Kubernetes.
