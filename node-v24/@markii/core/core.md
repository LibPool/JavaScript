# @markii/core

> 标签: directive, hast, mark, markdown, mdast, mk.md, parser, unified

## 简介

Framework-agnostic reference parser for Mark (.mk.md): CommonMark + directives to mdast, and mdast to a sanitized hast tree. Zero React dependency.
