# @markii/ansi

> 标签: ansi, cli, directive, markdown, markii, mk.md, renderer, terminal

## 简介

A framework-free terminal renderer for Markii (.mk.md): a registry-driven hast-to-ANSI-text engine. Zero React; for a terminal, a pipe, or any host that wants a plain string with optional color.
