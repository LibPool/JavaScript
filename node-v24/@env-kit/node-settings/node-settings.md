# @env-kit/node-settings

> 标签: 12factor, build-once-deploy-many, config, configmap, configuration, dotenv, env, kubernetes, schema, secret, settings, validation, zod

## 简介

Schema-first settings for Node apps: cascading config across env files, per-env config files, and packages (monorepo extends). Zod validation, .env.example / Markdown docs / Kubernetes manifest generation, CLI for CI/CD.
