# @googlarz/agents-sync

> 标签: agents, agents-sync, agentsmd, ai, claude, cline, codegen, context, cursor, cursorrules, gemini, mcp, windsurf

## 简介

Make Claude Code (and 10 other AI tools) read your AGENTS.md automatically. One canonical context file, auto-loaded in every session, auto-synced to .cursorrules, GEMINI.md, copilot-instructions.md, and more.
