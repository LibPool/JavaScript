# @adpushup/ap-mediation-sdk

> 标签: android, ios, react-native

## 简介

Ap Mediation SDK is a React Native Plugin for Ap Mediation SDK AdMob Adapter. Currently supports Android only. It allows you to integrate AdPushup's Ads into your React Native apps as a Mediation Demand.
