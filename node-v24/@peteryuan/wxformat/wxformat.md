# @peteryuan/wxformat

> 标签: cli, formatter, markdown, publish, wechat, 公众号

## 简介

公众号文章排版 CLI：草稿一键转纯净 Markdown + 公众号 HTML（全内联样式），支持浏览器预览、排版面板一键复制、剪贴板自动复制、JSON 输出，可被脚本、CI 与大模型直接调用。
