# @qbtc/crypto

> 标签: JavaScript

## 简介

Cryptographic core for wallets on the QBitcoin protocol — hashing, encoding, addresses, HD derivation (secp256k1 + Falcon-512), signing. Ships no chain constants: each chain injects its parameters via a ChainProfile.
