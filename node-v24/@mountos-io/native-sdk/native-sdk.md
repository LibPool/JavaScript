# @mountos-io/native-sdk

> 标签: azure-blob, file-api, filesystem, fuse, gcs, mountos, native-api, object-storage, posix, s3, sdk, unix-socket

## 简介

Node.js client for the mountOS native filesystem API. Talk to a mounted mountOS volume (a POSIX filesystem over S3, Azure Blob or Google Cloud Storage) over a local Unix socket, without FUSE.
