# @proofcodec/geoip

> 标签: cloudflare-workers, compression, db-ip, edge-computing, geoip, geoip-lite, geolocation, ip-geolocation, wasm

## 简介

GeoIP lookup in 167 KB — continent-level IP geolocation from DB-IP Lite, compressed via proof-carrying decision trees. Zero dependencies, works in Node.js, browsers, and edge runtimes.
