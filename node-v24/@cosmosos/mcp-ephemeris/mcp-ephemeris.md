# @cosmosos/mcp-ephemeris

> 标签: astrology, astronomy, claude, ephemeris, llm, mcp, model-context-protocol, natal-chart, swiss-ephemeris, transits

## 简介

MCP server exposing server-computed planetary positions (Swiss Ephemeris), validated against JPL Horizons (NASA). Plug any LLM/agent into the real sky: 19 astrology tools, never hallucinated.
