# @nktznl/ink

> 标签: ansi, chalk-alternative, cli, colorize, colors, console, logging, terminal, text-styling, typescript

## 简介

A lightweight, powerful TypeScript library for creating beautiful colorized console output with ANSI escape codes. Features chaining, themes, styles, and advanced effects.
