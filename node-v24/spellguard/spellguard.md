# spellguard

> 标签: cli, consistency, linter, markdown, spell, spell-checker, spellcheck, spellchecker, symspell, terminology, typo

## 简介

Deterministic spell checker for code and docs: repo-native vocabulary, SymSpell suggestions, terminology-consistency lint, agent-friendly output. Fully local, one dependency.
