# @sigx/zero-kit

> 标签: SignalX, codegen, css, design-system, design-tokens, recipes, sigx

## 简介

Design-system authoring kit for SignalX Zero — typed tokens and recipes compiled to plain CSS, plus the `sigx` CLI plugin closing the AI-generate → validate → iterate loop.
