# @sigx/ai-agent-node

> 标签: agent, ai, mcp, node, process, signalx, sigx, spawn

## 简介

Node building blocks for @sigx/ai-agent adapters — cross-platform process supervisor, executable resolution (PATH, PATHEXT, npm .cmd shims), child environment allowlist, loopback MCP listener
