# @sigx/lynx-richtext

> 标签: editor, input, lynx, rich-text, signalx, sigx, wysiwyg

## 简介

Native rich-text input element for Lynx (<sigx-richtext>): attributed editing (UITextView / EditText) with a span-based document model, selection events, and formatting commands. Powers @sigx/lynx-markdown's MarkdownEditor.
