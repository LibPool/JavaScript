# @sigx/json-ui

> 标签: generative-ui, json, json-ui, lynx, server-driven-ui, signalx, sigx, streaming, ui

## 简介

UI from JSON for SignalX — a streamable JSON UI spec, a catalog that describes and validates it, safe expressions, reactive state, pluggable async actions, and a platform-neutral renderer on @sigx/runtime-core
