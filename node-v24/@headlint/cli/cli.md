# @headlint/cli

> 标签: ci, head, lint, meta tags, open graph, seo, twitter card, validator

## 简介

Lint everything your <head> declares — CLI for headlint.com. Audits meta tags, social preview tags, canonical, robots, hreflang and JSON-LD for a URL.
