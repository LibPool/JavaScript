# @nuvin/computer-use

> 标签: accessibility, agent, automation, cgevent, computer-use, desktop-automation, macos, screencapturekit, screenshot, ui-automation

## 简介

Drive the macOS desktop from a CLI — accessibility-tree actions (snapshot → press/set-value) and pixel actions (screenshot → click/move/drag). Foreground automation for agents.
