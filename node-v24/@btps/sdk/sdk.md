# @btps/sdk

> 标签: billing, btps, dns, e-invoicing, encryption, invoice, protocol, signature, trust

## 简介

The reference implementation of BTPS, the Billing Trust Protocol Secure: signed, encrypted, trust-first delivery of invoices and documents between organisations.
