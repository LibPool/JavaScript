# @ssk_dev/pi-docs-slim

> 标签: pi, pi-extension, pi-package, prompt, token-efficient

## 简介

Keep Pi's built-in documentation guidance out of the system prompt unless you ask for it with /pi. Fork of pi-slim, updated for Pi 0.87.1+ (tested on 1.0).
