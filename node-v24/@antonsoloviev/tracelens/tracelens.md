# @antonsoloviev/tracelens

> 标签: agent-tracing, genai-semconv, llm-agents, llm-observability, openinference, opentelemetry, otlp, trace-viewer

## 简介

A zero-install viewer for LLM agent traces: drop an OpenTelemetry export, see every model call, tool call, token and dollar on a timeline.
