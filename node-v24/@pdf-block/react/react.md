# @pdf-block/react

> 标签: builder, document, drag-and-drop, editor, pdf, react, wysiwyg

## 简介

A visual, drag-and-drop PDF document builder for React. Renders a full WYSIWYG editor with inline styles, ready for server-side PDF generation.
