# @thehighestbit/node-red-contrib-ipc-cfx

> 标签: .NET, CFX, SDK, ipc-cfx, node-red

## 简介

A node red node for communicating with AMQP brokers using the IPC-CFX protocol. Uses the official .NET SDK.
