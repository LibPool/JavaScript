# insightics-sdk

> 标签: analytics, charts, dashboard, insightics, llm, postgres, react, text-to-sql

## 简介

Prompt-driven, real-time analytics for a Node app, in one install. Each part is its own import path: insightics-sdk/server, insightics-sdk/react, insightics-sdk/core and the rest. There is deliberately no root import, so browser code cannot pull in server
