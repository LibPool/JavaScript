# @agentdance/node-webrtc-sctp

> 标签: datachannel, dcep, node, rfc4960, sctp, typescript, webrtc

## 简介

RFC 4960/8832 SCTP + DCEP — fragmentation, congestion control, fast retransmit, ordered/unordered delivery, pre-negotiated channels. Part of the @agentdance/node-webrtc stack.
