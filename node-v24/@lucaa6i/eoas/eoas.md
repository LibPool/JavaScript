# @lucaa6i/eoas

> 标签: cli, eas, expo, expo-open-ota

## 简介

A CLI tool to manage publishing and OTA updates for expo-open-OTA self-hosted server. This is not an official tool from Expo but an open-source project (https://github.com/axelmarciano/expo-open-ota)
