# @tassyir/storefront-blocks

> 标签: liquid, sanitizer, storefront, tassyir, tassyir-app, template

## 简介

The language of Tassyir's declarative storefront blocks: a Liquid subset with a validator (coded errors with line, column and fix), a step-counted renderer and an allowlist HTML gate. The same bytes in Node and in browsers.
