# @responsibleai/agent-hooks-linux-x64-gnu

> 标签: JavaScript

## 简介

Framework-neutral agent control contract (AGENT-HOOKS-0.1). TypeScript wrapper over the canonical Rust core. Cooperative contract, not a security boundary: the host is fully trusted (see SECURITY.md).
