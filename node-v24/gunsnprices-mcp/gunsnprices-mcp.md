# gunsnprices-mcp

> 标签: ammo, ammunition, caliber, firearms, guns, gunsnprices, mcp, mcp-server, model-context-protocol, price-comparison

## 简介

MCP server for gun and ammo shopping: parse product titles, identify firearm models and calibers, cost per round, and GunsNPrices price comparison links.
