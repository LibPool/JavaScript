# @breachlens/cli

> 标签: breachlens, ci, devsecops, iac, pipeline, sarif, sast, sca, secrets, security-gate, shift-left

## 简介

Trigger a BreachLens scan from any terminal or CI pipeline and gate the build on severity — a thin, headless client for the self-hosted BreachLens API.
