# @ticatec/logger-wrapper

> 标签: commonjs, context-logger, esm, logger, logger-wrapper, logging, pino, ticatec, typescript

## 简介

A lightweight Pino logger wrapper supporting application-level Pino logger injection and child logger context binding.
