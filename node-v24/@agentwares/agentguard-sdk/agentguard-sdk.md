# @agentwares/agentguard-sdk

> 标签: agentguard, ai-agents, guardrails, kill-switch, langchain, middleware, okgate, openai-agents, spend-limit

## 简介

okgate (formerly agentguard) for tool calls that bypass MCP: wrap OpenAI Agents SDK, LangChain or plain function tools with the same policy engine (spend caps, approvals, kill switch, dry-run, loop breaker, audit log) and cap LLM spend with a guarded fetc
