# @kabbi/ble-mesh

> 标签: JavaScript

## 简介

This is **VERY EXPERIMENTAL**, **WORK IN PROGRESS** implementation of BLE Mesh v1.0 specification on top of `noble` library, allowing it to work on PCs, Macs and Raspberry PIs.
