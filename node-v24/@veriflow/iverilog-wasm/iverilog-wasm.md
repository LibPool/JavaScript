# @veriflow/iverilog-wasm

> 标签: JavaScript

## 简介

Run Icarus Verilog compilation and VVP simulation from Node.js without installing native `iverilog` or `vvp` executables. Each request runs the `ivlpp`, `ivl`, and `vvp` WebAssembly stages in an isolated worker with an in-memory filesystem.
