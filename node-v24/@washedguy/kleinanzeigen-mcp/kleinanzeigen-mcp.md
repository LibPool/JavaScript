# @washedguy/kleinanzeigen-mcp

> 标签: automation, kleinanzeigen, mcp, model-context-protocol, patchright, scraper

## 简介

Unofficial, read-only community MCP server for public kleinanzeigen.de listings: search and read listings through a local browser session. No login, no messaging.
