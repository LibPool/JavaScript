# @paircode/tool-model

> 标签: paircode

## 简介

3D/CAD 创作域插件（★ 工具 + UI 同包，2026-09-17 合并）：工具面（纯 goja 零依赖）参数化 CAD 工程（表达式驱动，改参数全模型重算）→ 三角网格内核 + BSP 实体布尔（union/subtract/intersect）→ 导出公开格式（glTF 2.0 自包含 / GLB / binary+ASCII STL / OBJ / 自包含 WebGL 预览 HTML）→ 9 项判据（M1 工程契约、M2 参数与表达式、M3 网格完整性、M4 水密性（0.1.1 起布尔输出经
