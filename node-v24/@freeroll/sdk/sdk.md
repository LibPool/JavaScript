# @freeroll/sdk

> 标签: casino, gamefi, house-banked, hyperevm, onchain-games, provably-fair, variance-vault, viem

## 简介

Build provably-fair, house-banked games on the Variance Vault protocol (HyperEVM). Define a game as an on-chain value tree, register it permissionlessly, play, and verify — the chain guarantees the game can't cheat the pool or the player.
