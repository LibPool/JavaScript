# @kinna/wx-mini

> 标签: JavaScript

## 简介

@kinna/wx-mini为简易版微信小程序快速构建脚手架，可实现以下功能： - 快速创建微信小程序项目 - 快速创建页面目录以及子文件，并添加对应的分包配置 - 快速删除文件目录，并删除对应的分包配置 - 快速创建组件以及子文件 - 监测文件变化实时变更小程序代码 - 快速分环境打包不同AppID下的项目程序
