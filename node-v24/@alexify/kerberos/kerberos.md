# @alexify/kerberos

> 标签: abac, access control, auth, authorization, cerbos, derived-roles, fine-grained-authorization, framework, kerberos, openfga, opentelemetry, permissions, policy, policy-as-code, rbac, rebac, schema, security, spicedb, web, zanzibar

## 简介

Fast, zero-dependency in-process authorization engine for Node.js and browsers — ABAC, RBAC and ReBAC (Zanzibar-style relations) with Cerbos-like policies, caveats, OpenTelemetry and pluggable validation/caching
