# @bumail/auth

> 标签: JavaScript

## 简介

Message authentication for a mail server: DKIM signing and verifying (RFC 6376) with rsa-sha256 and ed25519-sha256 through Web Crypto, SPF checking (RFC 7208), DMARC (RFC 7489) and the Authentication-Results header (RFC 8601)
