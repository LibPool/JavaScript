# @hmydgz/pb-gen-type

> 标签: JavaScript

## 简介

通过 [protobufjs](https://www.npmjs.com/package/protobufjs) 解析 pb ，生成自用的 type 的工具库； 通过包名的顶级域拆分生成的文件，方便区分给哪个微服务用 pb 暂时只支持相对路径 import
