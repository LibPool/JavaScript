# @hmemcpy/pi-escalate

> 标签: glm, model-routing, pi, pi-extension, pi-goal-x, pi-package, zai

## 简介

Smart model escalation for pi: a fast everyday model for the grind, automatic escalation to a stronger model for planning, hard debugging, and goal work — with a capability-floor guard for pi-goal-x auditor and blocker-oracle roles.
