# @retenka/storefront-events-polyfill

> 标签: cart, polyfill, shopify, shopify-theme, standard-events, storefront

## 简介

Drop-in polyfill that dispatches Shopify's official Standard Storefront Events on themes that don't yet emit them natively. Intercepts /cart/{add,change,update,clear}.js, dispatches shopify:cart:lines-update / note-update / discount-update / error via the
