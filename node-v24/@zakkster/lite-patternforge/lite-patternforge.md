# @zakkster/lite-patternforge

> 标签: brick, canvas, halfdrop, imagedata, kaleidoscope, mirror, pattern, rgba, scatter, seamless-repeat, surface-design, textile, tile, uint32, zakkster, zero-allocation, zero-gc

## 简介

Zero-GC seamless-repeat pattern kernel. Grid, halfdrop, brick, mirror, and deterministic scatter layouts + motif seam-blend + audit. Composes with lite-hueforge, lite-color-engine/remap, lite-gradient-studio.
