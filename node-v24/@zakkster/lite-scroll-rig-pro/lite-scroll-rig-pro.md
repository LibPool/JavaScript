# @zakkster/lite-scroll-rig-pro

> 标签: gsap-alternative, lenis-alternative, matrix3d, parallax, performance, raf, scroll, scroll-animation, scroll-rig, scrollytelling, smooth-scroll, spring, transform, twitch-extension, virtual-scroll, zero-allocation, zero-gc

## 简介

Zero-GC scroll-driven transform rig. Spring-smoothed virtual scroll, pre-measured intersection bounds, keyframed matrix3d batched to the DOM. Built for 16ms frame budgets and long-running sessions.
