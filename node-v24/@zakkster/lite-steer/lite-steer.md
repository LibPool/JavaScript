# @zakkster/lite-steer

> 标签: ai, autonomous-agent, boids, flee, flocking, pathfinding, seek, steering, wander, zero-gc

## 简介

Zero-GC steering behaviors for autonomous agents. Boids, seek, flee, wander, path following, curl noise. Built on lite-vec.
