# @zakkster/lite-project

> 标签: cache, commit, esm, lens, lite-query, lite-signal, optimistic-ui, overlay, projection, query, reactive, signals, tanstack-query, zero-gc

## 简介

Zero-GC projections for @zakkster/lite-signal: granular, derived, non-mutating reactive overlays with commit / revert / reconcile, and draft adapters for lite-store and lite-room.
