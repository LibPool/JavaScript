# @umbra-privacy/solana-indexer-client

> 标签: JavaScript

## 简介

The Solana indexer's data API read as the wallet store's rows: one page of a pool's notes, spends, registrations or records feed, parsed and checked, with fetch injected by the caller. Pre-release (0.x): every API, type and behaviour is subject to change
