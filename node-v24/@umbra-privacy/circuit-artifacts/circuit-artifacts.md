# @umbra-privacy/circuit-artifacts

> 标签: JavaScript

## 简介

Resolve a circuit's proving key, witness calculator and verifying key onto a device: three wire encodings, the caller's choice of store, and a verifying key derived from the bytes so the chain can be the integrity anchor. Pre-release (0.x): every API, typ
