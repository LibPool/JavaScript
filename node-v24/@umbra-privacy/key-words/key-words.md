# @umbra-privacy/key-words

> 标签: JavaScript

## 简介

Typed word encodings for BN254 field elements and 64-byte secrets: the BIP-39 English list at lengths no wallet accepts, with a checksum bound to what the secret is and where it belongs. Loads nothing at run time. Pre-release (0.x): every API, type and be
