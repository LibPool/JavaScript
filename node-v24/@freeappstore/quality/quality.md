# @freeappstore/quality

> 标签: audit, freeappstore, freegamestore, quality, viewport

## 简介

Quality reporter — apps post viewport metrics to a parent dashboard via postMessage so /quality can audit fit / scroll / clipping at every reference viewport without driving a headless browser per app.
