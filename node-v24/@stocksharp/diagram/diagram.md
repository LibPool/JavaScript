# @stocksharp/diagram

> 标签: algorithmic-trading, canvas, diagram, node-editor, stocksharp, strategy, trading, typescript, visual-programming, workflow

## 简介

Browser strategy-diagram editor for StockSharp with typed ports, palette, canvas rendering, persistence, and a TypeScript API.
