# @heiweilu/dsh-quota-capsule

> 标签: deepseek, deepseek-harness, dsh, glm, kimi, minimax, quota, usage

## 简介

Provider quota capsule for the DSH Web UI: shows the current model provider's plan usage (GLM Coding 5h/weekly, Kimi Coding, MiniMax Token Plan) or balance (DeepSeek) as a floating capsule.
