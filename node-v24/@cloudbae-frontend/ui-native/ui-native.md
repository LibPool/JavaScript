# @cloudbae-frontend/ui-native

> 标签: angular components, angular ui, component, framework, native, theme, ui

## 简介

`@cloudbae-frontend/ui-native` 是基于 angular 开发的移动端开发框架，支持常见的如路由转场动画、触摸手势、上拉加载、下拉刷新等功能。文档地址：[https://statictest.cloudbae.cn:37364/cloudbae-ui/doc/native](https://statictest.cloudbae.cn:37364/cloudbae-ui/doc/native)。
