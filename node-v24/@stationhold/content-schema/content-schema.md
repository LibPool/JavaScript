# @stationhold/content-schema

> 标签: JavaScript

## 简介

Zod schemas for [Stationhold](https://stationhold.com) content: the frontmatter of modules, failure notes, worksites, journal entries and video tutorials, the portable exercise manifest, the extension manifest, and the extension index that the site serves
