# @exla/rudder

> 标签: ai-agents, claude-code, cli, codex, coding-agents, jujutsu, opencode, terminal, tui

## 简介

A TUI for managing coding agents: run Claude Code, Codex and opencode side by side, each in its own isolated jj workspace.
