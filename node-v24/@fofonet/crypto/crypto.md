# @fofonet/crypto

> 标签: browser, crypto, cryptography, crystal, decrypt, easy, encrypt, encryption, krystal, kyber, post-quantum, pqc, quantum, typescript, web3

## 简介

An easy PQC (Post Quantum Computing) library for encrypting/decrypting data and sharing keys using the Kyber algorithm and AES-256.
