# @termhub/agent

> 标签: JavaScript

## 简介

Agente do termhub: conecta esta máquina ao servidor por WebSocket de saída (sem SSH) e expõe os terminais tmux no navegador.

## 官网

- 官网：https://termhub.dev
- 源码仓库：git+https://github.com/engenhariainversa/termhub.git
- npm 页面：https://www.npmjs.com/package/@termhub/agent
