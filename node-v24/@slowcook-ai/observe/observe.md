# @slowcook-ai/observe

> 标签: asynclocalstorage, debugging, observability, pino, request-id, slowcook, tracing

## 简介

Observability + live-debugging substrate for slowcook backends — request-scoped tracing (AsyncLocalStorage), structured pino logs, safe background tasks, breadcrumb+trace bundles for agent diagnosis. Framework-agnostic; ships a Hono adapter.
