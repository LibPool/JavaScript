# @adea-ai/harness-adapters

> 标签: agents, claude-code, codex, cursor, harness, marketplace, plugins

## 简介

Harness materialization for AI agent plugin marketplaces: translate catalog plugins into per-harness installation plans for Codex, Claude Code, Cursor, Pi, Hermes, and OpenCode.
