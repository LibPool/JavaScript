# @nestio/cruella-native

> 标签: JavaScript

## 简介

React Native components for Rocko, styled with NativeWind (Tailwind syntax) on @nestio/cruella-headless and @nestio/cruella-tokens. Shipped as source - the consuming app's own Metro/Babel config compiles it, same as any other RN app code.
