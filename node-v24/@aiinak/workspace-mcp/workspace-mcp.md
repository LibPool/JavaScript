# @aiinak/workspace-mcp

> 标签: agents, aiinak, drive, mcp, model-context-protocol, storage

## 简介

MCP server for the aiinak workspace — give your AI agent a drive, spreadsheets, and documents: search, read, upload, share files, edit sheets cell-by-cell, and create Word docs from markdown.
