# @anlyonhq/mcp-server

> 标签: actions, ai-agents, anlyon, approvals, claude, claude-code, cursor, human-in-the-loop, mcp, mcp-server, model-context-protocol, tools

## 简介

MCP server for Anlyon. Lets an AI agent invoke named production actions and request human approval, without holding a credential.
