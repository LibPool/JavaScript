# niyusha

> 标签: agent, ai, ai-agent, cli, coding-agent, developer-tools, llm, mcp, nodejs, openai, terminal, tui

## 简介

AI coding agent for the terminal: staged file edits with diff review, permissioned shell, web search, autonomous mode, sessions, and an MCP client. Zero runtime dependencies.
