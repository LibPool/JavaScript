# dsh-sandbox-mxc

> 标签: deepseek-harness, dsh, dsh-plugin, mxc, processcontainer, sandbox, windows

## 简介

DeepSeek Harness sandbox provider backed by MXC (Microsoft eXecution Containers): wraps ctx.sandbox.confine() argv as `wxc-exec --config-base64 <policy> -- <command>` on the BaseContainer backend. One runtime dependency (@microsoft/mxc-sdk, for the wxc-ex
