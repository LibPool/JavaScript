# dsh-quick-launcher

> 标签: command-palette, deepseek-harness, dsh, dsh-plugin, launcher, spotlight

## 简介

Ctrl+Space command palette over the Harness Web UI: one box to find sessions, invoke skills, open panels and switch appearance.
