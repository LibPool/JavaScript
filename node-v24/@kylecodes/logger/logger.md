# @kylecodes/logger

> 标签: AsyncLocalStorage, context, json, logger, logging, structured, traceId, typescript

## 简介

Structured logger with implicit per-request context via AsyncLocalStorage, isomorphic Node/browser behavior, and env-driven level/format.
