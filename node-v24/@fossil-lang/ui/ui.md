# @fossil-lang/ui

> 标签: JavaScript

## 简介

Radix UI primitives + Fossil design tokens for the @fossil-lang/* React component family. CSS-variable driven; no Tailwind/shadcn peer dependencies. Per ADR-0033 + ADR-0034.
