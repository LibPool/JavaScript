# @tour-kit/testing-library

> 标签: floating-ui, jsdom, react-testing-library, testing, tour-kit, vitest

## 简介

React Testing Library helpers for Tour Kit — virtual-element Floating UI pattern + act() flush wrapped once, so consumer tests don't repeat the boilerplate.
