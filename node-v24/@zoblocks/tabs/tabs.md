# @zoblocks/tabs

> 标签: accessibility, ant-design, antd, aria, healthcare, radiogroup, react, rtl, segmented-control, tablist, tabs, wcag

## 简介

Tabs that know what they are. Four semantic modes — view switch, navigation, form value, wizard — across eleven skins, with the WAI-ARIA keyboard model, priority-plus overflow and WCAG 2.2 AA states.
