# @zoblocks/clinical-note-core

> 标签: clinical-note, documentation, ehr, emr, fhir, healthcare, loinc, prosemirror, provenance

## 简介

The engine behind ZoBlocks's ClinicalNote. Coded sections, per-range provenance, a composable sign gate, and deterministic FHIR/text serialization — no React, no DOM.
