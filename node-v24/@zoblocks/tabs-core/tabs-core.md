# @zoblocks/tabs-core

> 标签: accessibility, aria, headless, healthcare, keyboard-navigation, radiogroup, segmented-control, tablist, tabs, wcag

## 简介

The selection engine behind ZoBlocks's tab system. Semantic modes, the WAI-ARIA keyboard model, priority-plus overflow and indicator geometry — no React, no DOM, no dependencies.
