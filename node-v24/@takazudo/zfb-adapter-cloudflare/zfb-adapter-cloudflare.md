# @takazudo/zfb-adapter-cloudflare

> 标签: adapter, cloudflare, cloudflare-pages, cloudflare-workers, ssg, static-site-generator, workers-static-assets, zfb, zfb-adapter

## 简介

Content-site engine on the web's Request/Response model — prerender to static HTML, serve on Cloudflare Workers, or run as a local content server inside your app. One Rust binary. Cloudflare adapter: Workers Static Assets (Pages-compatible).
