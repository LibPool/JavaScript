# @maref-org/mcp-governance

> 标签: MAREF, MCP, agent, ai-safety, governance, guardrails, model-context-protocol

## 简介

MCP Governance Server — wraps any MCP server with MAREF governance guardrails. Intercepts file writes and command execution to enforce policies via MAREF sidecar.
