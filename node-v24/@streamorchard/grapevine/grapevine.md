# @streamorchard/grapevine

> 标签: desktop, electron, ipc, json-rpc, local, named-pipe, pairing, unix-socket

## 简介

Lets desktop apps on the same computer find each other and talk, privately: local sockets, JSON-RPC, pairing and versioned capabilities.
