# @zylem/runtime

> 标签: ecs, physics, rapier3d, rust, shipyard, simulation, wasm, zylem

## 简介

Rust + wasm simulation runtime for Zylem (prebuilt zylem_runtime.wasm + thin TS loader and typed FFI exports).
