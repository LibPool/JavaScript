# @visulima/redact

> 标签: anolilab, anonymize, censor, conseal, credentials, filter, gdpr, hide, mask, maskdata, masked, masker, masking, redact, secret, security, sensitive data, serialize, stringify, visulima

## 简介

A library for redacting and masking sensitive data from objects and strings, with support for GDPR compliance, custom rules, and deep object traversal.
