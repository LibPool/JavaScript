# @visulima/yaml

> 标签: config, data, dump, js-yaml, load, parse, parser, serializer, stringify, typescript, visulima, yaml, yaml-parser, yaml1.2, yml

## 简介

A fast, zero-dependency YAML 1.2 parser and serializer with a drop-in API for both `yaml` and `js-yaml`.
