# @atomichub/atomicmarket

> 标签: antelope, atomicassets, atomichub, atomicmarket, blockchain, eosio, nft, sdk, wax

## 简介

JavaScript/TypeScript SDK for the AtomicMarket NFT marketplace contract on Antelope chains: read sales, auctions, and royalties, and build sale, auction, buyoffer, template-buyoffer, RAM-payment, and v2 royalty actions
