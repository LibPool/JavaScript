# @edgeproc/privacy-core

> 标签: browser, client-side, data-masking, egress-control, gdpr, iban, llm, llm-security, luhn, pii, pii-detection, pii-redaction, privacy, prompt-privacy, typescript

## 简介

A browser-side structured-identifier redaction boundary for LLM calls: detects cards, IBANs, SSNs, emails, US phones and labeled account/routing numbers on-device, sends only placeholders, rehydrates locally — enforced by a type-checked Egress Guard. Name
