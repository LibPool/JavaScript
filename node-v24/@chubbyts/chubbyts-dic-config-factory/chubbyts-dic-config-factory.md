# @chubbyts/chubbyts-dic-config-factory

> 标签: abstract-factory, chubbyts, config, container, dependency-injection, dependency-injection-container, dic, factory, psr-11, service-factory

## 简介

An abstract service factory for the dependency injection container, usable with chubbyts-dic-config, inspired by chubbyphp-laminas-config-factory.
