# @banzhe/dsh-file-link-open

> 标签: JavaScript

## 简介

Right-click context menu over file links in session messages: open the file in a detected editor/IDE, open its containing folder in the platform file manager, or copy its relative/absolute path. App resolution reuses the official open-in-app catalog resol
