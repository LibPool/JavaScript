## 简介

TaskFlow MCP server for AI coding agents (Claude Code, Codex, Gemini CLI, Cursor, opencode) — multi-agent task board, realtime chat, reviews, terminal streaming, activity logging, plus Claude Code hooks and a taskflow init setup walkthrough.
