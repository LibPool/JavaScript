> 标签: audit-chain, did, ed25519, merkle, prmaat, verification

## 简介

Reference verifier CLI for PrMaat Verification Spec v0.1. Verifies a signed-event bundle (signature + Merkle inclusion proof + custody check) and exits 0 on conformance, non-zero on failure with a specific failure code from spec §10. Zero runtime dependen
