# @jiangdaoli/dsh-memory

> 标签: JavaScript

## 简介

DSH long-term memory: distil durable facts/decisions/how-tos from each session, remember live user facts, recall relevant memory in new sessions, maintain the store, and configure it from Settings. Works on web and desktop.
