# @bpdm/ng-scheduler

> 标签: accessible, angular, calendar, design-system, events, responsive, scheduler, typescript

## 简介

Angular scheduler/calendar for the bpdm design system — day, week and month views over one shared headless core. Typed, themeable, accessible, responsive.
