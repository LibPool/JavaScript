> 标签: claude-code, dexter, mcp, opendexter, skills, x402, x402gle

## 简介

Compose Claude Code skill bundles from x402gle host manifests. Generates Anthropic-spec plugin bundles (plugin.json, marketplace.json, SKILL.md, references) from any host's synthesized manifest.
