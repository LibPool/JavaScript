# @salesforce/ui-bundle-template-base-vue-app

> 标签: JavaScript

## 简介

Base Vue app template — a Vue UI Bundle with Vite, TypeScript, Tailwind/shadcn-vue, and Salesforce UI Bundle SDK. Used as the foundation for feature apps when applying patches.
