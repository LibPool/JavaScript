> 标签: agentforce, ai, android, chatbot, employee-agent, ios, react-native, salesforce, service-agent

## 简介

Agentforce React Native bridge: JS API and native module for Service Agent and Employee Agent (auth bridge included; host app adds Mobile SDK).
