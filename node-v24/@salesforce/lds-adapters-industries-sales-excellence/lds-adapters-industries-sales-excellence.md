# @salesforce/lds-adapters-industries-sales-excellence

> 标签: JavaScript

## 简介

The wire adapters are used for Sales Excellence Connect API to fetch Actionable List members. these APIs also support update for the Assignee and Priority fields of Action List and Actionable List Member entities respectively
