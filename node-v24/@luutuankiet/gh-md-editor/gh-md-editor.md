# @luutuankiet/gh-md-editor

> 标签: codemirror, editor, git, markdown, preview, terminal, web-editor

## 简介

Lightweight browser editor served from any folder: markdown cockpit (editor + live preview + outline), code tabs with syntax highlight, git source control, integrated terminal, ripgrep search.
