# diagram-axi

> 标签: ai-agents, axi, cli, d2, diagram, diagrams, excalidraw, import-graph, mermaid, toon

## 简介

Token-efficient AXI CLI: turn a compact boxes-and-arrows text DSL into an editable diagram file (Excalidraw today) plus PNG/SVG renders, offline.
