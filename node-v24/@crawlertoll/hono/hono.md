# @crawlertoll/hono

> 标签: ai-crawler, bot-detection, bun, claudebot, cloudflare-workers, crawler-toll, deno, gptbot, hono, hono-middleware, http-402, pay-per-crawl, rsl, rsl-1.0, vercel-edge, web-bot-auth, x402

## 简介

Hono middleware for the AI-crawler economy. One line wires bot detection, Web Bot Auth verification, RSL 1.0 policy, and HTTP 402 issuance into any Hono app. Runs on Cloudflare Workers, Bun, Deno, Vercel Edge, Node, and the browser — unmodified.
