# @css-bookends/font-size-adjust

> 标签: JavaScript

## 简介

Typed font-size-adjust builder (a constrained non-negative number plus the 'none' and 'from-font' keywords, throw or clamp) for CSS-Bookends. A book stamped from self-publish.
