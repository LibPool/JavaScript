# @css-bookends/gilding

> 标签: autoprefixer, bookends, css, fallback, lightningcss, postcss

## 简介

Gilding: the CSS-Bookends finisher. A build-time pass that wraps a CSS post-processor (default: Lightning CSS) to complete browser compatibility (older-browser color fallbacks and vendor prefixes) over the plain CSS books emit.
