# @wanderleedev/pixel-pet

> 标签: chatbot, css-animation, lit, pixel-art, rag, sprite, steps, typescript, web-component

## 简介

Web component (Lit + TypeScript) que anima mascotas pixel art con CSS steps() a partir de una hoja de sprites y un manifiesto. Pensado para asistentes y chats.
