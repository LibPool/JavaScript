# @neuroui/components

> 标签: COGA, WCAG, a11y, accessibility, adhd, autism, cognitive-accessibility, component-library, components, design-system, dyslexia, inclusive-design, neurodiversity, react, sensory, tailwindcss, ui

## 简介

Beautiful React UI components with built-in cognitive accessibility. Every component automatically adapts to users' sensory preferences — motion sensitivity, information density, focus needs, and reading comfort.
