# @cross-virtual-list/mp-wx

> 标签: big-data, mp-virtual-list, virtual-list, 小程序, 小程序虚拟列表, 虚拟列表

## 简介

适用于微信小程序的虚拟列表组件，支持横向/竖向滚动，支持列表项尺寸可变/不变等功能。
