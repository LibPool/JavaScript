# dsh-dotenv-toolkit

> 标签: config, diff, dotenv, dsh, env, environment, mask, plugin

## 简介

dotenv toolkit for DeepSeek Harness: parse_env (parse .env into key-value pairs), diff_env (compare .env vs .env.example for missing/extra keys), mask_env (mask sensitive values for safe display). Zero runtime dependencies, read-only.
