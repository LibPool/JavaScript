# @zengcool/pi-peers

> 标签: extension, ipc, messaging, multi-agent, oh-my-pi, peers, pi

## 简介

Cross-session messaging between pi-compatible coding agent instances on one machine (registry + named pipe/UDS + token auth + receipts). Works as an extension on pi and oh-my-pi.
