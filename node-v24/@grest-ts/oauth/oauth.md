# @grest-ts/oauth

> 标签: api, auth, contract, framework, mcp, microservices, oauth, oauth2, oidc, pkce, testing, typescript

## 简介

OAuth 2.1 authorization server (panva oidc-provider on GGHttpServer) issuing @grest-ts/auth tokens, plus a browser code+PKCE client for GGAuthSession
