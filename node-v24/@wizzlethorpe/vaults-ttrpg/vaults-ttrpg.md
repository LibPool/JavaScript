# @wizzlethorpe/vaults-ttrpg

> 标签: dnd5e, foundry-vtt, obsidian, ttrpg, vault

## 简介

TTRPG add-on for the vaults CLI: statblocks, dice, battlemaps, and a grafts.json a reader imports into Foundry VTT.
