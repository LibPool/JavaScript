# @feugene/unocss-preset-granular

> 标签: granular, tree-shakeable, typescript, unocss, unocss-preset

## 简介

Universal UnoCSS preset that aggregates component styles, themes and safelist from any number of GranularProvider packages. Framework-agnostic, tree-shake friendly.
