# @kerusiweb/angular

> 标签: airline, angular, booking, cinema, kerusi, seat-map, seat-picker, seat-selection, seatmap, svg, ticketing, venue

## 简介

An Angular seat-map component that renders Kerusi Seat Map & Availability Format documents as interactive, accessible inline SVG.
