# @gravadigital/jiku

> 标签: client, grava, jiku, nats, request-reply, zitadel

## 简介

Client for Jiku's API, which is served over NATS rather than HTTP: 23 read endpoints and 20 write endpoints, request/reply, no REST anywhere.
