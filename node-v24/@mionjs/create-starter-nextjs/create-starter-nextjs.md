# @mionjs/create-starter-nextjs

> 标签: api, create, mion, mionjs, nextjs, react, rpc, starter, template, typescript

## 简介

Starter template for building full-stack apps with mion + Next.js. Run `npm create @mionjs/starter-nextjs <project-name>` to scaffold.
