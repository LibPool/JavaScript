# @jiesou/dsh-webui-fix-subagent-panel

> 标签: JavaScript

## 简介

Keep the DSH Web UI subagent catalog panel on-screen and tap-toggleable on mobile/touch: clamp the title-bar session tree to the viewport and toggle it on click (client-only plugin).
