# @nicolaudiegroup/nicolaudie-remote-protocol

> 标签: dasnet, dina, nicolaudie, protocol, remote, scene, siudi, stick, trigger

## 简介

Node JS based implementation of the Nicolaudie Remote Protocol, allowing you to connect to various devices manufactured by Nicolaudie Group that have networking capabilities.
