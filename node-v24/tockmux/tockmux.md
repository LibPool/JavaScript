# tockmux

> 标签: animation, claude, elevenlabs, ffmpeg, headless-chrome, html-to-mp4, html-to-video, mcp, model-context-protocol, playwright, tmx, video-as-code, voiceover

## 简介

Turn any self-playing HTML animation into a frame-perfect MP4, GIF or WebM. Deterministic virtual clock, voice-over sync, drag-and-drop Studio and an MCP server for AI agents.
