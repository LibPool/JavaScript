# @talosjs/markdown

> 标签: browser, bun, commonmark, front-matter, gfm, markdown, md, parser, talos, typescript

## 简介

Dependency-free Markdown toolkit for the browser and Bun — a CommonMark + GFM parser and HTML renderer with front matter, sanitizing, and extraction of headings, links, images, tasks, and code blocks
