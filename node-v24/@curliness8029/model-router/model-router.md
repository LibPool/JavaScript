# @curliness8029/model-router

> 标签: agent, anthropic, bun, cache, claude, cost-optimization, gpt, llm, openai, proxy, router

## 简介

Harness-blind LLM proxy for Bun: routes every request to the cheapest capable model (Anthropic + OpenAI), caches responses, auto-updates pricing, tracks savings on a live dashboard, and runs a request/response plugin pipeline
