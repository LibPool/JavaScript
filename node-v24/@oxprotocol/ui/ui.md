# @oxprotocol/ui

> 标签: JavaScript

## 简介

Frozen V1 component vocabulary for OXP extensions. Authors compose Box/Stack/Text/Button/VirtualList/CodeBlock trees; hosts render natively (Piye) or via the DOM backend (VS Code webview).
