# build-preset

> 标签: biome, browser-testing, build-config, capacitor, game-development, playwright, tsconfig, tsup, vite, vitest

## 简介

Shared build conventions for browser games: Vite 8 and Vitest configs with headed, muted browser testing, a Capacitor config, a tsup library build, and TypeScript and Biome base configs.
