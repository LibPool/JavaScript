# @lily-ui/css

> 标签: accessibility, css, dark-mode, design-system, design-tokens, scss, utility-classes, wcag

## 简介

Lily UI — the framework-agnostic CSS design library: design tokens, themes (light/dark/custom), utility classes, and component styles. Usable on its own or with @lily-ui/react.
