# @scarlett-player/whep

> 标签: live, low-latency, player, scarlett, video, webrtc, whep

## 简介

WHEP (WebRTC-HTTP Egress Protocol) provider plugin for Scarlett Player: sub-second live monitoring of a Tmesis preview or any WHEP server that answers offers
