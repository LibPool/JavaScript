# @sbroenne/excelcli

> 标签: automation, cli, excel, windows

## 简介

Excel automation for coding agents through terminal commands: the same features as the Excel MCP Server, usually with fewer AI tokens. Requires Windows and desktop Excel.

- 官网：https://excelmcpserver.dev/
- 源码仓库：git+https://github.com/sbroenne/mcp-server-excel.git
