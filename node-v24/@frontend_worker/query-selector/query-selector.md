# @frontend_worker/query-selector

> 标签: query-selector, remote-selector, selector

## 简介

《远程搜索+单选》组件区别于element-ui或iview组件库的select远程搜索， ①将头部显示的值和下拉选项显示的值独立开来， ②避免远程加载时头部默认值显示异常， ③支持插槽自定义
