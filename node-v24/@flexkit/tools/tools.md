# @flexkit/tools

> 标签: agent, flexkit, skills, tools

## 简介

Define, serve and run Flexkit custom tools and code skills from your own server: defineTool, defineSkill, defineTools, createToolsHandler and the local runtime behind `flexkit dev`.
