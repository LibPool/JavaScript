# dsh-pet-lan

> 标签: bongo-cat, deepseek-harness, desktop-pet, dsh, dsh-plugin, lan, multiplayer

## 简介

LAN co-op for the dsh-pet desktop pet: see peers on the same network, wave, and drag their desktop windows. Requires dsh-pet 0.3.7. An optional included patch enables live animation, bubble and meme sync.
