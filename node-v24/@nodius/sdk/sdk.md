# @nodius/sdk

> 标签: baas, database, document-store, grpc, nodius, sdk, sql, vector-search

## 简介

Thin gRPC client for the Nodius BaaS — managed relational, document and vector datastores behind one secure gateway. The .proto contract is the single source of truth.
