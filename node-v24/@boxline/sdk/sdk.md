# @boxline/sdk

> 标签: ai-agents, automation, boxline, browser, cdp, chrome, headless, playwright, puppeteer, sandbox

## 简介

Node and TypeScript SDK for Boxline: cloud browsers and shell sandboxes for AI agents, with retries, cursor pages and typed errors.

- 源码仓库：git+https://github.com/Boxline-dev/sdk-node.git
