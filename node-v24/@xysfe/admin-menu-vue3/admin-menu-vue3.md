## 简介

## vue3老版本 1.0.0以上的版本都是 适用element-plus beta版的版本，并且icon库适用@element-plus/icons的 因为element-plus 后续正式版中有组件的名称和icon库的变化，所以区分开来 如若使用的是正式新版的element-plus，请安装^2.0.0的版本
