# @powersync-bridge/drizzle

> 标签: drizzle, local-first, offline-first, orm, powersync, sqlite, sync

## 简介

Drizzle adapter for powersync-bridge: executes builders through the ORM so rows arrive decoded, derives watched tables, and hands the SDK a compilable query.
