# @arraypress/filter-toolbar-astro

> 标签: astro, astro-component, ecommerce, filter, grid-list-toggle, infinite-scroll, load-more, pagination, sort, withastro

## 简介

Astro listing toolbar — sort + grid/list view toggle + results count, with a client-side filter/search/sort/paginate runtime (live or staged apply; paged, load-more, infinite).
