# @arraypress/seo-astro

> 标签: astro, astro-component, astro-integration, csp, json-ld, llms-txt, meta-tags, og-image, open-graph, security-headers, seo, twitter-cards, withastro

## 简介

SEO for Astro in one integration: seo() feeds the <SEO> component, renders an Open Graph card for every page at build, writes llms.txt and a _headers file with a hash-based CSP, and audits the built site. Title, canonical, Open Graph, Twitter, robots, hre
