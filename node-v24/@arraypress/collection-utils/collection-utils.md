# @arraypress/collection-utils

> 标签: aggregate, astro, collection, facet, group-by, tag-cloud, taxonomy

## 简介

Aggregate + group collections by scalar or list taxonomy fields — primitives for taxonomy archive pages (tags, genres, artists, authors) — plus the report arithmetic: sumBy, countBy, rankBy, ratio, percentChange — and chunk.
