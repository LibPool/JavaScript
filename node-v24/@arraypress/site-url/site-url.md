# @arraypress/site-url

> 标签: absolute-url, astro, base-url, canonical, origin, seo, ssr, url

## 简介

Build absolute and canonical URLs from a base — for SSR/SSG canonical links, OG image URLs, JSON-LD and sitemaps. Zero dependencies.
