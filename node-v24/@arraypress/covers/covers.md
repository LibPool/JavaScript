# @arraypress/covers

> 标签: astro, build-time, cover-image, featured-image, generative, grain, harfbuzz, mesh-gradient, og-image, sharp, svg, webp

## 简介

Build-time cover images for posts and pages: soft mesh gradients, grain, grids, stripes, shapes, icons and type from one seed, as SVG or WebP/PNG/AVIF/JPEG. Recipes for the editorial looks, every layer customisable, an Astro endpoint helper. No network, n
