# @wecko-ai/modelfit

> 标签: apple-silicon, cli, gpu, hardware, llm, local-ai, modelfit, ollama, recommendation

## 简介

Detect your machine and get THE best local LLM (Ollama) it can run — from the ModelFit hardware database. Embeddable library + CLI. Offline, zero-dependency.
