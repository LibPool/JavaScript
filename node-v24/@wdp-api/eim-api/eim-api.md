# @wdp-api/eim-api

> 标签: 51AES, 51Cloud, 51WDP, 51WORLD, EimApi

## 简介

51WORLD eim-api is a JavaScript plugin designed for WdpApi, offering a comprehensive set of APIs that empower developers to seamlessly integrate eim-api into their applications.
