# @wdp-api/gis-api

> 标签: 51AES, 51Cloud, 51WDP, 51WORLD, GisApi

## 简介

51WORLD gis-api is a JavaScript plugin designed for WdpApi, offering a comprehensive set of APIs that empower developers to seamlessly integrate gis-api into their applications.
