# @effect-libs/cloudflare-playwright

> 标签: browser-automation, cdp, cloudflare, effect-libs, fork, playwright

## 简介

Patched fork of @cloudflare/playwright@1.3.5 with external CDP support, lazy cloudflare:workers import, ESM type resolution, and graceful orphaned-session handling. Vendored from upstream Cloudflare, maintained inside the @effect-libs/browser monorepo.
