# @usulpro/mentat

> 标签: agent-skills, claude-code, codex, curriculum, learning, spaced-repetition, tutoring

## 简介

A domain-agnostic tutoring system: turns a directory into a course with a competency ledger, and installs into an agent CLI as three role-skills.
