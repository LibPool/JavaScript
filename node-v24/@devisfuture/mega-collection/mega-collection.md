# @devisfuture/mega-collection

> 标签: array, array-fields, array-filter, array-search, array-sort, client-side, collection, fast-filter, fast-search, filter, high-performance, in-memory, indexed-search, inverted-index, javascript, large-arrays, large-dataset, multi-field-sort, multi-filter, nested-filter, nested-search, performance, search, sort, substring-search, text-search, tree-shakeable, typescript, zero-dependencies

## 简介

Fast indexed search, filtering, and sorting for arrays of objects in JavaScript and TypeScript. Supports nested fields, array fields, and large client-side collections.
