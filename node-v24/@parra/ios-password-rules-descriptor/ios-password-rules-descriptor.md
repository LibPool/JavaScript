# @parra/ios-password-rules-descriptor

> 标签: JavaScript

## 简介

A simple utility for generating the `descriptor` to initialize a `UITextInputPasswordRules` object per Apple's [Customizing Password AutoFill rules](https://developer.apple.com/documentation/security/password_autofill/customizing_password_autofill_rules)
