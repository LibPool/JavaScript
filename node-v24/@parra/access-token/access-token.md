# @parra/access-token

> 标签: JavaScript

## 简介

A utility class for signing Parra Access Token with node.js.  For more information on Parra Access Tokens, please visit our [docs](https://docs.parra.io/topics/access-tokens) or check out our [Node.js integration guide](https://docs.parra.io/guides/node)
