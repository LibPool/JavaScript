# @grip-labs/payclaw-mcp

> 标签: agent-payments, base, claude, cline, cursor, mcp, model-context-protocol, payclaw, stablecoin, usdc

## 简介

PayClaw as an MCP server. Adds pay/balance/history tools to Claude Desktop, Cursor, Cline, and any MCP-compatible client. v0.2: true gasless via Circle Paymaster + Kernel smart accounts on Base — agents never need ETH. Wraps @grip-labs/payclaw.
