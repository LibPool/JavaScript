# @mdevst/webstorage

> 标签: async storage, browser database, client-side storage, data persistence, database, idb, indexeddb, indexeddb wrapper, key-value store, local storage, offline storage, put/delete api, schema validation, server-side sync, storage abstraction, sync storage, typescript, value-based query, webstorage

## 简介

webstorage is a modern TypeScript wrapper around IndexedDB, offering schema-based storage, server-compatible operations, and offline-first support — all with a clean and flexible API.
