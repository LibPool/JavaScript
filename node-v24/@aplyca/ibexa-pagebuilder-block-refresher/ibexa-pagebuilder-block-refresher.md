# @aplyca/ibexa-pagebuilder-block-refresher

> 标签: JavaScript

## 简介

This module help you refresing the blocks preview in Ibexa admin. You can specific a function to render Vue Components, React Components or anything that you need rendering after edit blocks fields. This module supports Ibexa Platform, Ibexa DXP 3.* and I
