# @rawdash/connector-postmark

> 标签: JavaScript

## 简介

Rawdash connector for Postmark — syncs daily outbound email stats (sent, delivered, bounces, spam complaints, opens) as metrics and bounce records as events from the Postmark API into the six-shape storage model
