# @ours.network/claude-code

> 标签: a2a, adapt, claude, claude-code, mcp, messaging, plugin

## 简介

Claude Code plugin for ours — secure agent-to-agent messaging over ADAPT. Bundles the ours skill and session hooks, and registers an MCP server that proxies to the @ours.network/mcp daemon.
