# @openagentid/http

> 标签: agent, auth, did, http, middleware, mutual-auth, oas, openagent

## 简介

HTTP adapter for the OpenAgent Auth Protocol (OAAP). Middleware, client, and discovery for agent-to-service mutual authentication.
