# @indexable/sdk

> 标签: JavaScript

## 简介

Generated Linux Node and Bun bindings for ix. The Rust `ix-sdk` owns every platform verb; Unibind generates the native classes, TypeScript declarations, error classes and Zod record schemas from that contract.
