# @txpass/agent

> 标签: ai-agents, api-keys, cli, delegation, mcp, txpass

## 简介

Local, non-custodial Txpass agent signer + MCP server: the agent key lives on your machine, a human delegates to it, the agent calls paid APIs with short-lived session JWTs it never exposes.
