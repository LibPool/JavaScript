# @sonicium/sdk

> 标签: drbg, entropy, ml-dsa, ml-kem, post-quantum, qrng, quantum, random

## 简介

Official client for the Sonicium Entropy API: quantum-seeded random bytes, attested reseed material and post-quantum keypairs, with offline attestation verification.
