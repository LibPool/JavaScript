# dsh-dialogue-cleanup

> 标签: cleaner, cleanup, deepseek, delete, dsh, harness, plugin, session

## 简介

Delete DeepSeek Harness sessions from the running Web runtime: detach the live store entry, drop workspace records, and remove the on-disk artifacts. Host half plus a web client half in one package.
