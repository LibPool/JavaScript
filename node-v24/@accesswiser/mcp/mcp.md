# @accesswiser/mcp

> 标签: a11y, accessibility, mcp, model-context-protocol, wcag

## 简介

Stdio MCP server that lets AI coding tools start an AccessWiser accessibility scan of one deployed page and read the findings. It never writes to a site or a repository.
