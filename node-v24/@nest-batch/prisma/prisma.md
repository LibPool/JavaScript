# @nest-batch/prisma

> 标签: batch, job-repository, nestjs, persistence, prisma

## 简介

Prisma adapter SLOT for @nest-batch/core — JobRepository and TransactionManager interface shape, paired with @nest-batch/postgresql (Postgres driver) or @nest-batch/mysql (MySQL driver).
