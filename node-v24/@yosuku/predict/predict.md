# @yosuku/predict

> 标签: deepbook, defi, options, predict, prediction-market, sui, svi

## 简介

The first TypeScript SDK for DeepBook Predict — Sui's vol-surface prediction-market protocol. PTB builders, the SVI/N(d2) pricing engine, and a typed indexer client.
