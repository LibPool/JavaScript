# @lotics/ui

> 标签: JavaScript

## 简介

React DOM UI primitives with no Lotics domain coupling — no i18n, analytics, or domain types. Consumed by `frontend` and custom-code apps. Lotics-specific compositions live in `frontend` or `@lotics/ui-internal`, not here.
