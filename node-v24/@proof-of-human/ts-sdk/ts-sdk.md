# @proof-of-human/ts-sdk

> 标签: ai-disclosure, music, proof-of-human, provenance, verification

## 简介

TypeScript SDK for the Proof of Human API — verify credentialed audio, inspect structured evidence, and run partner review workflows. Generated from the PoH TypeSpec model.
