# thirdparty-pulse

> 标签: core-web-vitals, github-action, javascript, lighthouse, performance, performance-budget, sarif, static-site, third-party, web-performance

## 简介

Third-party script weight and load-cost report for static sites: estimated bytes, requests and main-thread time per page and per vendor, with budgets, plus sync-script, duplicate and preconnect checks. SARIF, Action. Zero deps.
