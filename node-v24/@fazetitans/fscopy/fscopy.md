# @fazetitans/fscopy

> 标签: backup, bun, cli, copy, database, firebase, firestore, google-cloud, migration, nosql, sync, transfer

## 简介

Fast CLI tool to copy Firestore collections between Firebase projects with filtering, parallel transfers, and subcollection support
