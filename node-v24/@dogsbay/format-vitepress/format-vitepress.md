# @dogsbay/format-vitepress

> 标签: JavaScript

## 简介

VitePress format plugin for Dogsbay — imports VitePress docs projects into TreeNode[] by translating VitePress containers, code-fence conventions, snippets and includes to Dogsbay-MD.
