# @dogsbay/adapter-camunda

> 标签: JavaScript

## 简介

Camunda 8 docs site adapter for @dogsbay/format-docusaurus — regenerates OpenAPI reference pages from their frontmatter spec blob and maps Camunda-specific MDX components.
