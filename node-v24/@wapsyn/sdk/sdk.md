# @wapsyn/sdk

> 标签: messaging, sdk, sms, typescript, wapsyn, webhooks, whatsapp, whatsapp-api

## 简介

Official Node.js/TypeScript SDK for the Wapsyn API — send WhatsApp messages and verify webhooks. Built to grow into SMS, email and more.
