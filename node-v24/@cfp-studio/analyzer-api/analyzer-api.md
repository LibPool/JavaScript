# @cfp-studio/analyzer-api

> 标签: JavaScript

## 简介

核心分析 API，用于组件/Story/TS 类型的静态分析、可预览 ID 生成与解析、分析器工厂等。为 CFP Studio 设计器和相关工具提供统一的类型分析与组件元数据抽象。
