# @cfp-studio/vfs

> 标签: JavaScript

## 简介

`@cfp-studio/vfs` 提供统一的虚拟文件系统（Virtual File System, VFS）抽象，支持内存、磁盘、堆叠多源读写、监听与快照，适用于低代码、测试、沙箱等多场景。
