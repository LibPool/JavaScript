# @macorb/cli

> 标签: JavaScript

## 简介

Give Amp a Mac: sign in to MacOrb and start, list and stop the macOS machines your Amp threads run on.

## 官网

- npm 页面：https://www.npmjs.com/package/@macorb/cli
