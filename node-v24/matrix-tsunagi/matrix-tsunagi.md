# matrix-tsunagi

> 标签: bmw, bootloader, csl, dme, e46, ecu, eeprom, kombi, m3, m35080, mcp, mss54hp, odometer, s54, smg, smg-ii, smg2, tcu, testo, tsunagi-matrix, tunerpro, tuning, ve-table, xdf

## 简介

TSUNAGI///Matrix — the BMW E46 M3 tools' calculations as a library, a CLI and MCP servers. MSS54HP DME: VE and rf_korr corrections from Testo logs. SMG II: decode and compare the gearbox calibration. DME backups and cluster M35080 EEPROMs: read and verify
