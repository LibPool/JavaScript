# @helmdeck/mcp-bridge

> 标签: agent, bridge, claude, gemini, helmdeck, mcp, model-context-protocol

## 简介

Stdio MCP bridge that connects Claude Code, Claude Desktop, OpenClaw, and Gemini CLI to a helmdeck control plane.
