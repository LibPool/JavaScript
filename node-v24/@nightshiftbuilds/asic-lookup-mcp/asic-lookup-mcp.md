# @nightshiftbuilds/asic-lookup-mcp

> 标签: abn, acn, asic, australia, business-registry, company-lookup, mcp, modelcontextprotocol, x402

## 简介

MCP server for the Australian company register: look up any ASIC-registered company by ABN, ACN or name. Paid per call in USDC on Base over x402, from your own wallet.
