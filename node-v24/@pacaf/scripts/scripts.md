# @pacaf/scripts

> 标签: code-apps, dataverse, pacaf, power-apps, power-platform

## 简介

Helper scripts for Power Apps Code App projects: prototype seeding, auth setup, deployment safety, and migration tooling. Dataverse schema, data, solution, and export operations are owned by the Dataverse-skills plugin.
