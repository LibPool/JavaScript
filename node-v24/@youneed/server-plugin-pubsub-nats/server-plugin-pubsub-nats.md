# @youneed/server-plugin-pubsub-nats

> 标签: JavaScript

## 简介

NATS adapter for @youneed/server-plugin-pubsub: NatsPubSub over subjects, via the official `nats` (nats.js). Pub/sub only (pair with a KV adapter for state).
