# @filelayer/core

> 标签: access-control, agent-skills, audit-log, authorization, cli, file-storage, mcp, mcp-server, model-context-protocol, multi-tenant, postgres, r2, rbac, revocation, s3, share-links, signed-urls

## 简介

Multi-tenant file authorization middleware and lifecycle for Postgres: a single decision point for public and private files, revocable URLs, delegated share links and a hash-chained audit trail.
