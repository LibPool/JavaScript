# @qiulei/toolboxjs

> 标签: javascript, toolbox, utility, vue

## 简介

该项目提供了一系列 JavaScript 开发的工具函数，以及一个 Vue 插件，用于自动注册指定目录下的 Vue 组件。工具函数涵盖数据处理、距离计算和字符串操作等多种功能。
