# @inframaps/fonts

> 标签: cartography, font-face, fonts, fontstack, glyphs, inframaps, maplibre, maplibre-gl, maplibre-native, maps, multilingual, noto, noto-fonts, openlayers, pbf, sdf, unicode, vector-tiles, webfonts, woff2

## 简介

Free Noto fonts for MapLibre and OpenLayers maps: glyph PBFs, WOFF2 faces and font-face CSS for every Noto script except CJK.
