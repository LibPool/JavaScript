# @kordar-lib/crud

> 标签: JavaScript

## 简介

CRUD 相关的基础类型定义库，统一描述查询条件、排序、编辑指令以及常用的请求体结构（SearchBody/FormBody/EditorBody/RemoveBody），用于在各模板与组件库中保持接口一致。
