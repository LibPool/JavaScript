# @onetype/stack-api-kit

> 标签: api, drizzle, hono, kernel, multi-tenant, plugins, sqlite, typescript

## 简介

A kernel that holds plugins apart: contracts, routes, events, hooks, permissions and scope, refused at startup rather than in review.
