# @orpc-ws/oidc-react

> 标签: JavaScript

## 简介

The library's React bindings: hooks (useConnectionState, useAuthState, useUser, useOidcCallback) and an optional react-router OidcCallback component on the ./react-router sub-path. Does not re-export the cores.
