# @mogiyoon/react-stable-timeline

> 标签: chronology, drag-and-drop, events, hangul, headless, korean, react, react-component, react-timeline, ssr, timeline, typescript, virtualization, virtualized, vis-timeline, visualization

## 简介

A React timeline with stable row packing — items never jump rows when you pan or zoom. Label-aware (Canvas2D) packing handles Hangul/Latin/mixed text correctly.
