# @suqo/sdk

> 标签: api, nepal, payments, sdk, subscription, suqo, typescript

## 简介

A TypeScript SDK for SUQO would be a small code library that lets other businesses (SUQO's platform sellers) easily connect their own apps or websites to SUQO — without writing raw API calls themselves.
