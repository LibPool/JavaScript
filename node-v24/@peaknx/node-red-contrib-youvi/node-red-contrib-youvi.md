# @peaknx/node-red-contrib-youvi

> 标签: node-red, youvi

## 简介

By using these nodes you can send commands to several smart home devices to control their functions. These nodes are created for the software package "YOUVI" starting with version 4.4 and uses the YOUVI Connect 3rd Party Service.
