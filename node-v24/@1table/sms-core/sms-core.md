# @1table/sms-core

> 标签: 1table, aliyun, btom, chatbot, embedded, sdk, sms

## 简介

可嵌入的短信核心库：不依赖 HTTP 微服务，在进程内按租户配置直接调用阿里云/Btom/Chatbot/Mock 网关发送短信
