# @genelab/gassan

> 标签: a11y, accessibility, bottom-sheet, dialog, headless, modal, nextjs, react, starting-style, top-layer

## 简介

Native <dialog> based modal shell for React. Layer 1 is delegated to the browser; the library focuses on information structure, activation gates and accessibility.
