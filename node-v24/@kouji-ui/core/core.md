# @kouji-ui/core

> 标签: a11y, angular, directives, headless, signals, ui, wcag

## 简介

Headless Angular UI primitives — signal-driven directives with WCAG 2.1 AAA semantics, no CDK, and a handful of opt-in global stylesheets.
