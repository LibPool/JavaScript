# @pdsjs/git-ci

> 标签: JavaScript

## 简介

Continuous integration for git repositories hosted in an atproto account by [`@pdsjs/git`](../git). A daemon watches the PDS firehose, runs a workflow for every push, and publishes the result as a record in its own repo.
