# @tryonit/core

> 标签: ar, augmented-reality, ecommerce, face-tracking, glasses, hand-tracking, makeup, mediapipe, react-native, try-on, typescript, virtual-try-on, zero-dependency

## 简介

Platform-agnostic core of TryOnIt, the open-source virtual try-on SDK: asset manifest validation, state store, face/hand/body anchor math and smoothing filters. Zero dependencies, no DOM.
