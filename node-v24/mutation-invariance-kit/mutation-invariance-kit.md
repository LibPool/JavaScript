# mutation-invariance-kit

> 标签: counterfactual-testing, deep-equal, fairness-testing, honesty-kits, invariance, metamorphic-testing, ranking, regression-testing, testing, typescript

## 简介

Check whether a decision, score, or ranking function's output changes when you mutate an input it should ignore, such as a name, zip code, or price.
