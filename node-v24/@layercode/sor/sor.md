# @layercode/sor

> 标签: cli, cloudflare, database, durable-objects, sqlite

## 简介

SOR provides SQLite databases via a simple CLI.

Commands:
  sor db list                    List all databases
  sor db create <name>           Create a new database
  sor db create <name> -d "desc" Create database with description
  sor db delete <name>
