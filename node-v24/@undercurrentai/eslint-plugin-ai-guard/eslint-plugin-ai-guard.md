# @undercurrentai/eslint-plugin-ai-guard

> 标签: ai, auth, authorization, claude, code-quality, copilot, cursor, eslint, eslint-plugin, express, fastify, framework, hono, llm, nestjs, nextjs, security, webhook

## 简介

Framework-aware security lint for JS/TS routes and webhooks (Express, Fastify, Hono, NestJS, Next.js). Missing-auth / missing-authz / unverified-webhook detection where typescript-eslint and eslint-plugin-security don't reach. Especially useful on AI-gene
