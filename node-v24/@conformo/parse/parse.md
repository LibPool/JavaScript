# @conformo/parse

> 标签: en16931, factur-x, invoice, parser, pdf, ubl, xrechnung, zugferd

## 简介

Reads a Factur-X/ZUGFeRD PDF or CII/UBL/XRechnung XML back into an EN 16931 Invoice, checking a PDF's visible totals against its embedded XML.
