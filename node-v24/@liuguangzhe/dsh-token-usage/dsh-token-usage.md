# @liuguangzhe/dsh-token-usage

> 标签: cordis, deepseek-harness, dsh, dsh-plugin, plugin, statistics, token, token-usage, tokens, usage

## 简介

统计本机全部 DSH 会话的历史 token 总消耗，按 message.id 去重，支持按天/模型/Provider/项目分组。Global token-usage totals across all DSH conversations.
