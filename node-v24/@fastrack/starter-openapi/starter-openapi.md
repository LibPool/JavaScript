# @fastrack/starter-openapi

> 标签: JavaScript

## 简介

Generate OpenAPI from TypeBox schemas, expose Swagger UI at `/docs`. Swagger disabled or gated in prod by default.

- npm 页面：https://www.npmjs.com/package/@fastrack/starter-openapi
