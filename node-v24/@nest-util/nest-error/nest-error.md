# @nest-util/nest-error

> 标签: JavaScript

## 简介

Standardized, localized, **generic** error system for NestJS services in the `nest-util` ecosystem (`nest-crud`, `nest-auth`, `nest-notify`, `nest-payment`, `nest-file`).
