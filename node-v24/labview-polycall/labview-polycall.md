# labview-polycall

> 标签: call-library-function-node, clfn, dll, ffi, labview, libpolycall, polycall

## 简介

LabVIEW Call Library Function Node binding for Polycall (binding ABI v1): a C wrapper DLL over the real core plus the node settings for every function
