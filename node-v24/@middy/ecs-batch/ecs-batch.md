# @middy/ecs-batch

> 标签: AWS, AWS Lambda, ActiveMQ, Batch, DynamoDB Streams, ECS, Fargate, Framework, Kafka, Kinesis, Lambda, MSK, Middleware, Middy, RabbitMQ, SQS, Serverless

## 简介

ECS/Fargate batch event runtime for the middy framework — polls SQS, Kinesis, DynamoDB Streams, Kafka, ActiveMQ, RabbitMQ and dispatches to a Lambda-shaped handler
