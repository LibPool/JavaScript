# @ved_patel/react-datagrid

> 标签: csv-export, data-grid, datagrid, editable-table, grouping, mantine, pagination, react, react-table, table, tanstack, typescript, virtualized

## 简介

A powerful, fully client-side React data grid built on TanStack Table + Mantine: multi-sort, fuzzy search, per-column filters, grouping/aggregation, banded headers, inline batch editing, row virtualization, column pinning/reorder/resize, and multi-format
