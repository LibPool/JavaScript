# @eloquentjs/codegen

> 标签: codegen, eloquent, graphql, openapi, orm, typescript

## 简介

Shared code generation engine for EloquentJS — introspect models, render stubs, emit GraphQL SDL, TypeScript types, OpenAPI specs
