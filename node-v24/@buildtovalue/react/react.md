# @buildtovalue/react

> 标签: bpmn, diagram, editor, react, svg

## 简介

React layer for bpmn-react: native SVG canvas, shapes, gestures, palette, inspector, minimap and diff view. Zero runtime dependencies (react/react-dom as peers).
