# @buildtovalue/registry

> 标签: audit, bpmn, changelog, governance, rollout, versioning

## 简介

Headless version governance for bpmn-react: a queryable registry of diagram versions with temporal validity, publication channels/environments, dual changelog and execution pinning (run-binding). Zero runtime dependencies.
