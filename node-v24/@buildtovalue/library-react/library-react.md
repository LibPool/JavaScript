# @buildtovalue/library-react

> 标签: artifact, catalog, gallery, governance, react

## 简介

React UI for the generic BuildToValue library (Handoff 6 S-3): gallery with status/type filter chips, search, artifact cards and the detail drawer — all generic, driven exclusively by the ArtifactAdapter contract. Zero runtime dependencies beyond @buildto
