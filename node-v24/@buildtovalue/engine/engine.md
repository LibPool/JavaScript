# @buildtovalue/engine

> 标签: bpmn, deterministic, engine, state-machine, workflow

## 简介

Deterministic BPMN execution kernel for the BuildToValue platform: pure advance(state, event) -> {state, effects}. Extracted from @buildtovalue/simulation (ADR-0001). v1 semantic subset: sequence flow, XOR with S-FEEL conditions, AND fork/join, user task,
