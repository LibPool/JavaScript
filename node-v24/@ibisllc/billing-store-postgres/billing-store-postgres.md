# @ibisllc/billing-store-postgres

> 标签: metering, pg, pglite, postgres, postgresql, quota, usage

## 简介

PostgreSQL MeterStore for @ibisllc/billing-metering, on pg, PGlite or any client with a query(text, values) method. Every operation is one statement.
