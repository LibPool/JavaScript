# vasm-jsi

> 标签: VasmJsi, expo, react-native, vasm-jsi

## 简介

A WebAssembly engine for Expo/React Native: Wasmtime's Pulley interpreter via JSI/JNI on iOS and Android, the browser's WebAssembly on web
