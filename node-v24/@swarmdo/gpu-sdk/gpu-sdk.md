# @swarmdo/gpu-sdk

> 标签: a100, ai, api-client, cloud-gpu, cuda, deep-learning, gpu, gpu-cloud, gpu-rental, h100, inference, l40s, llm, llm-inference, machine-learning, ml, nvidia, openai-compatible, rent-gpu, rtx4090, sdk, serverless, serverless-gpu, serverless-inference, swarmdo, typescript, vllm

## 简介

TypeScript SDK for renting cloud GPUs (H100, A100, L40S, RTX 4090) and running serverless GPU inference with an OpenAI-compatible API. Typed, zero-dependency, Node and browser.
