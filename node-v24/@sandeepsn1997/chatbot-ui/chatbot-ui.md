# @sandeepsn1997/chatbot-ui

> 标签: JavaScript

## 简介

A customizable **Chatbot UI** for embedding a chatbot into your website or web application. This package provides a ready-to-use chatbot interface that can be added to your project via npm or by using a CDN.
