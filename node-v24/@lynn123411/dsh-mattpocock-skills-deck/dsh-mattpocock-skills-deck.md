# @lynn123411/dsh-mattpocock-skills-deck

> 标签: deck, deepseek-harness, dsh, grilling, handoff, issue-tracker, mattpocock, plugin, skills, triage, wayfinder

## 简介

DeepSeek Harness 插件：Matt Pocock 技能套件（mattpocock/skills）的 DSH 控制面板（Deck）——将 wayfinder 地图/票务/进度、triage / grilling / handoff 动作注入带进 DSH。技能经本合集 agent-preset 分发（presets/matt-*/skills/），判装按「会话当前生效 preset」门控。安装：dsh plugin --profile <name> add @lynn123411/dsh-mat
