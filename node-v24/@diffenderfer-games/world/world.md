# @diffenderfer-games/world

> 标签: JavaScript

## 简介

diffenderfer.games worlds: the tile map model (dg-world@1) and its validation, a seeded procedural generator with pluggable world types, autotiling, collision, A* pathfinding and interaction zones. Pure TypeScript, no DOM; the hub renders it.
