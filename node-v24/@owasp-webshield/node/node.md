# @owasp-webshield/node

> 标签: authentication, authorization, csrf, input-validation, nodejs, owasp, owasp-top10, rbac, secure-coding, security, security-headers, server, ssrf, webshield

## 简介

Framework-neutral server layer for OWL (OWASP Webshield Library): per-request auth, access control, CSRF, validation, security headers, SSRF checks and error mapping on top of @owasp-webshield/core
