# @twind/cdn

> 标签: tailwind, tailwind-in-js, tailwindcss, tw-in-js, twind

## 简介

Twind CDN is a drop-in replacement for Tailwind CSS Play CDN that is 6 times smaller (104kb vs 17kB) without any build step right in the browser

## 官网

- 官网：https://twind.style
- 源码仓库：git+https://github.com/tw-in-js/twind.git
- npm 页面：https://www.npmjs.com/package/@twind/cdn
