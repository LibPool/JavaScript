# @kattebak/graphql-sdk-emitter

> 标签: appsync, codegen, cognito, graphql, sdk, sigv4, typescript

## 简介

Generate a typed TypeScript SDK from a GraphQL SDL with pluggable auth (SigV4, Cognito bearer, API key)
