# @sdevs/screen-sizr

> 标签: @sdevs/screen-sizr, frontend, nodejs, screen, screen size, screen size detector, screen-sizr, sdevs, sizr

## 简介

This package is a simple screen size detector for NodeJS. You can get the screensize on your Frontend app with ease. We dont guarantee that this package will work in the Backend.
