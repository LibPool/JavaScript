# @quilla-fe-kit/api-client

> 标签: client, etag, fetch, framework-agnostic, http, if-match, occ, token-refresh, typescript

## 简介

Framework-agnostic HTTP API client for consuming @quilla-kit BEs: layered fetch wrapper, single-flight token refresh, pluggable error parser, OCC via If-Match/ETag, configurable query-string serializer. Browser + Node + edge safe.
