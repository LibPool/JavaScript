# @quilla-fe-kit/auth

> 标签: auth, authentication, cookie, frontend, localStorage, token-storage, typescript

## 简介

Auth primitives for FE projects: pluggable TokenStorage interface plus three default adapters — memory (SSR-safe), localStorage (browser), and cookie (Secure / SameSite). Zero runtime dependencies.
