# @quilla-fe-kit/api-client-react-query

> 标签: client, http, occ, react, react-query, tanstack-query, typescript

## 简介

React Query adapter for @quilla-fe-kit/api-client: QueryClient factory, useQueryBase, mutation base hooks, query meta module augmentation, callback-shaped notification hooks.
