# @bufinance/kyc-ui

> 标签: JavaScript

## 简介

Shared, self-contained KYC/KYB identity-verification UI for BUFI apps. Drives Persona's embedded SDK in-app (no redirect) and renders the staged flow (intro -> processing -> approved/rejected/error). Fully prop-driven so fx, desk-v1, and b-in-bufi share O
