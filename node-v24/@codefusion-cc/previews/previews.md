# @codefusion-cc/previews

> 标签: ci, cloudflare-workers, d1, previews, pull-request, wrangler

## 简介

A Worker Preview per pull request with its own D1 database: names from the branch, the database created and deleted with it, and the Wrangler configs that point the Preview at it, from CI
