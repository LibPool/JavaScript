# @codefusion-cc/workers-http

> 标签: cloudflare-workers, cookies, csrf, http, json, rate-limit, spa, static-assets

## 简介

The HTTP plumbing of a Cloudflare Worker's API: errors thrown as answers, an API's routes, JSON responses, bounded JSON and body reading, the client's address and network, a same-origin check, rate limits over a RateLimit binding, cookies, SHA-256 and a s
