# @codefusion-cc/console

> 标签: JavaScript

## 简介

Connect a Cloudflare Workers app to CodeFusion Console: admin screens from a JSON manifest, staff, visit statistics, browser failures, diagnostics and its deployed version; and the codefusion-console command line
