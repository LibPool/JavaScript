# settled-x402

> 标签: agent-skills, agentkit, agents, ai-agents, base, claude-code, coinbase-agentkit, mcp, micropayments, payer-record, payments, preflight, spend-controls, trust, usdc, verifiable-credentials, x401, x402, x402-client, x402-discovery

## 简介

Don't let your agent pay an x402 endpoint that doesn't deliver. Checks each quote against Settled's independent evidence (paid test purchases, payTo, payee, buyer reports) before it is signed. Works with @x402/fetch, x402-fetch, any x402Client and Coinbas
