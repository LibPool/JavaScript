# @danxbot/plugin-sdk

> 标签: JavaScript

## 简介

SDK for building 50 Arms card-type plugins (DX-5170): the card kit's type declarations, a Vite preset that builds a plugin against the app's shared runtime and writes its manifest, and the danx-plugin CLI.
