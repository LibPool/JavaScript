# @dynamicagents/core

> 标签: a2a, agent2agent, agents-sdk, ai-agents, cloudflare-workers, durable-objects, eddsa, jwks, think, zero-trust

## 简介

Shared, mandatory foundation for Dynamic Agents on Cloudflare Workers: zero-trust A2A, a durable task host, task workflows, and step agents on @cloudflare/think.
