# @gatedpath/frontend-kit

> 标签: JavaScript

## 简介

React components and one hook for the five eligibility states every Redbelly dApp has: not connected, connected but not verified on the network, verified but ineligible for this action, eligible, credential expiring soon; plus explainError, the plain word
