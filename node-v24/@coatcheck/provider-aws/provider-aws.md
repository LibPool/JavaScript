# @coatcheck/provider-aws

> 标签: ai-agents, assume-role, aws, coatcheck, parameter-store, secrets, secrets-manager, ssm, sts

## 简介

coatcheck secret provider: AWS SSM Parameter Store (per-agent) and Secrets Manager (shared), with optional STS AssumeRole.
