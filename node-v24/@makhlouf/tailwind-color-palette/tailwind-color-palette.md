# @makhlouf/tailwind-color-palette

> 标签: color, colors, css, react, react-native, tailwind, tailwind-css

## 简介

Tailwind colors come with tailwind install, but there are cases where you can't install tailwind directly such as in react native apps. This package copies all the tailwind colors and wraps them for you to call them easily with the custom values of tailwi
