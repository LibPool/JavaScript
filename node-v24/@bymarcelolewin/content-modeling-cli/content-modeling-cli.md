# @bymarcelolewin/content-modeling-cli

> 标签: anthropic, cli, content-modeling, contentful, contentful-cli, contentmodeling, headless-cms, mcp, model-context-protocol

## 简介

An MCP Server and CLI tool for building, templating, and managing content models for Contentful using simple JSON files. It can also run as an MCP server for use with Anthropic's Claude and other MCP clients.
