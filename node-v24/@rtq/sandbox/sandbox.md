# @rtq/sandbox

> 标签: bubblewrap, bwrap, fail-closed, isolation, linux, macos, os-enforcement, rtq, sandbox, seatbelt

## 简介

RTQ OS sandbox runtime: Seatbelt (macOS), bubblewrap (Linux), AppContainer+Job Object (Windows), fail-closed, with explicit enforcement reporting.
