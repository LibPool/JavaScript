# qemu-img-ts

> 标签: disk-image, qcow2, qemu, qemu-img, raw, typescript, virtualization

## 简介

A TypeScript wrapper for the qemu-img command-line utility, enabling programmatic disk image creation, conversion, inspection, and management.
