# dsh-blender-mcp-bridge

> 标签: 3d-modeling, blender, deepseek-harness, dsh, mcp, model-context-protocol, plugin

## 简介

此项目是对 Deepseek Harness 开发的插件，旨在包装与桥接 Blender MCP Add-on，使 DSH 上的模型可便捷对接接入当前用户工作中的 Blender 以辅助创作，且满足基础安全需要。
