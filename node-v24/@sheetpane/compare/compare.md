# @sheetpane/compare

> 标签: JavaScript

## 简介

What changed between two versions of a workbook, for sheetpane — a headless diffWorkbooks (sheets, rows by key or alignment, cells by value, text and formula) and a grid plugin that tints the changes, sums them up and steps through them.
