# @sheetpane/import

> 标签: JavaScript

## 简介

Read an .xlsx or .csv file into the plain JavaScript Workbook object @sheetpane/export writes — raw values, display text, merges, and everything the plugins read. No runtime dependency but @sheetpane/export.
