# @midvash/emdash-plugin-bible

> 标签: bible, cms, emdash, emdash-plugin, midvash, tooltip, verses

## 简介

EmDash plugin: auto-detect Bible references in content and render verse tooltips on hover. Powered by the public Midvash API (https://api.midvash.com).
