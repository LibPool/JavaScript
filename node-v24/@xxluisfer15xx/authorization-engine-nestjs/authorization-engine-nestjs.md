# @xxluisfer15xx/authorization-engine-nestjs

> 标签: JavaScript

## 简介

Application-agnostic authorization engine for NestJS: evaluates RBAC + ABAC decisions over already-resolved permissions and policies, with no database or HTTP access of its own.
