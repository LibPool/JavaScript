# @variance-authority/vantage

> 标签: agent, e2e, flaky-tests, instrumentation, mcp, observability, testing, variance-authority

## 简介

Hold what a running test suite is saying in a process an agent can ask, so a test in flight is something to look at rather than something to wait for.
