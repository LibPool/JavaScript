# @kpstreams/core

> 标签: certhash, key-pinning, kps, no-ca, p2p, quic, secure-transport, webrtc

## 简介

Transport-neutral core for KPS: addresses, certhash, error model, and the Connection/Stream contract (plus the WebRTC wire protocol under ./webrtc). Zero runtime deps.
