# @imenam/mcp-design

> 标签: agent, ai, canvas, design, mcp, mockup, model-context-protocol, ui

## 简介

MCP server providing a simple design canvas: the agent creates shapes and text, the user refines them in a GUI, and the agent picks the edits back up.
