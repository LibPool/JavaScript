# @dshtrading/connector-finnhub

> 标签: JavaScript

## 简介

Finnhub 商业数据源美股连接器（BYOK）：tradingUsMarketData / tradingUsTrade 双服务 + us_get_ticker / us_get_klines / us_get_news 三个行情工具，服务缝三态下单闸门；凭证只存 ref 名 FINNHUB_API_KEY，不内置密钥。
