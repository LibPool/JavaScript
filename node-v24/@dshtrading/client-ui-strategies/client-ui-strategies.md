# @dshtrading/client-ui-strategies

> 标签: JavaScript

## 简介

Strategy stage view plugin for dsh-trading (issue #34 / P5): registers the 中栏「策略」tab via the tradingStageViews service — horizon segmented control, strategy cards, backtest runner with equity curve and trade log. Engine comes from the @dshtrading/strategi
