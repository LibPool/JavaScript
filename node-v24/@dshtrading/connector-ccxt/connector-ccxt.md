# @dshtrading/connector-ccxt

> 标签: JavaScript

## 简介

沿用 CCXT 所名词汇的加密现货多所行情连接器（自写 binance/okx/bybit 三条直连分支，不依赖 ccxt 库）：ticker 与 K 线 + 保留三态闸门的交易占位服务；现货限定，账户读面未实现。
