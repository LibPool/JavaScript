# @conciv/core

> 标签: ai, conciv, engine, hono, server

## 简介

Internal to @conciv/it (installed automatically, do not install directly). The conciv engine: a framework-free hono + @hono/node-server server exposing the /__pw HTTP surface, with a harness registry seam.
