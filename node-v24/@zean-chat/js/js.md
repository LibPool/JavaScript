> 标签: chat, chat-bubble, chat-widget, crisp-alternative, customer-service, customer-support, help-desk, helpdesk, in-app-chat, intercom-alternative, javascript, live-chat, messaging, sdk, support-chat, tawk-to-alternative, typescript, vanilla-js, website-chat, zean, zendesk-alternative

## 简介

Live chat widget for any website: add a free customer support chat in one line. Vanilla JS, TypeScript, no framework needed. Intercom and Crisp alternative.
