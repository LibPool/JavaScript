# @banbolee/dsh-codegraph-mcp

> 标签: bundle, codegraph, dsh, mcp, plugin

## 简介

CodeGraph MCP bridge bundle for DeepSeek Harness: connects CodeGraph to any DSH profile through the official @deepseek-ai/dsh-mcp-client bridge (codegraph serve --mcp).
