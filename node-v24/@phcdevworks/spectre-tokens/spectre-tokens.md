# @phcdevworks/spectre-tokens

> 标签: css-custom-properties, css-variables, design-tokens, javascript, phcdevworks, spectre, spectre-tokens, theming, tokens, typescript, ui-design

## 简介

@phcdevworks/spectre-tokens is the design-token foundation of the Spectre system. It provides the shared visual values and semantic contracts used across Spectre packages and PHCDevworks applications.
