# @nimconnect/profile-client

> 标签: handle, identity, nimconnect, nimfeed, nimiq, profile

## 简介

Read and claim @handles and public profiles on the shared NimFeed/NimConnect identity registry — works with any Nimiq mini app, on-chain or via NimConnect's API.
