# @vibedgames/playtest

> 标签: agent, diagnostics, gamedev, playtest, qa, testing, vibedgames

## 简介

Make a browser game playtestable: publish diagnostics, test hooks and a control manifest so `vg playtest` — and the model behind `vg playtest run` — can play it
