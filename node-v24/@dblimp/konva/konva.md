# @dblimp/konva

> 标签: JavaScript

## 简介

Integración de lienzo 2D interactivo con **`Konva`** y **`react-konva`**, permitiendo renderizar gráficos, formas vectoriales y figuras geométricas declarativamente mediante esquemas JSON en el framework DBLimp.
