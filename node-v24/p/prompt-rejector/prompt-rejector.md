> 标签: agent-security, ai-agent, ai-safety, anthropic, canary-token, claude, cve, cybersecurity, gemini, huggingface, jailbreak, kev, lethal-trifecta, llm, llm-security, mcp, mcp-tool-poisoning, mitre-atlas, model-context-protocol, prompt-injection, security, sql-injection, xss

## 简介

Security gateway for LLM agents: detects prompt injections, jailbreaks, lethal-trifecta agent configurations, Hugging Face model risks, MCP tool poisoning, and classic web vulnerabilities. Ships an MCP server (11 tools) and a REST API.
