# paper-remote-mcp

> 标签: ai-agent, claude, cursor, design, figma-alternative, mcp, model-context-protocol, paper, paper.design, playwright

## 简介

Run the Paper Design MCP without the desktop app. Sign in with your Paper account, host the editor headlessly, and drive Paper's own MCP tools from Claude Code, Cursor, Codex, or any MCP client.
