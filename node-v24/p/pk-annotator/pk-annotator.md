# pk-annotator

> 标签: annotation, claude-code, codex, devtools, mcp, react, vite, vite-plugin

## 简介

Dev-only browser annotation overlay for Vite apps that sends picked elements, captures, and prompts to Claude Code and Codex through an MCP server.
