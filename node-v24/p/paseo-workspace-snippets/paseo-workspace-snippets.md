# paseo-workspace-snippets

> 标签: package.json, paseo, paseo-plugin, scripts, snippets, terminal

## 简介

Run saved command snippets and package.json scripts in Paseo workspace terminals, from a per-workspace panel, a sidebar screen, or /snippet.
