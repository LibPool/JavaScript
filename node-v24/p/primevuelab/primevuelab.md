> 标签: bootstrap, component library, fluent, material, passthrough, primevuelab, tailwind, ui library, unstyled, vue, vue.js, vue2, vue3

## 简介

primevuelab is an open source UI library for Vue featuring a rich set of 80+ components, a theme designer, various theme alternatives such as Material, Bootstrap, Tailwind, premium templates and professional support. In addition, it integrates with PrimeB
