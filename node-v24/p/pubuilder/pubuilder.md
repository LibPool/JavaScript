# pubuilder

> 标签: dev-tools, information-architecture, inspector, minimap, nextjs, publishing, react, sitemap

## 简介

In-app IA minimap & block inspector for React — cached page snapshots with a live iframe inspector, plus a Next.js route scanner (dev-only)
