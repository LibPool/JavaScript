# pypeline

> 标签: force, salesforce, salesforcedx, sf, sf-plugin, sfdx, sfdx-plugin

## 简介

Complete pipeline devops, for build a project based on git repo, generation of package xml, validate on producction enviroment and a quick deploy structure.
