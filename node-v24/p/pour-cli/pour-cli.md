# pour-cli

> 标签: a11y, accessibility, agents, audit, ci, cli, lint, mcp, sarif, testing, wcag, wcag22

## 简介

Audit any URL against WCAG 2.2 from the terminal with the pour engine. Headless Chrome, structured findings, CI-friendly exit codes, a static check over HTML and template files with SARIF and GitHub annotations, a site-wide report runner, and an MCP serve
