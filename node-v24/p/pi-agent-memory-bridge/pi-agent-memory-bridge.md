# pi-agent-memory-bridge

> 标签: claude-mem, cross-engine, cross-session, memory, persistent-memory, pi-coding-agent, pi-extension, pi-package, pi-skill

## 简介

Self-maintained pi-coding-agent memory extension: a thin client for the local claude-mem worker HTTP API. Records tool activity, injects relevant past context, and registers a memory_recall search tool.
