# pokemon-tcg-mcp

> 标签: cards, mcp, pokemon, tcg, tcgdex, trading-cards

## 简介

Use this MCP server to the Pokémon TCG, search cards, sets, rarities via TCGdex. Tools include search cards, get card, list sets
