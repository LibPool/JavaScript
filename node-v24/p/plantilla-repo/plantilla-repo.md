# plantilla-repo

> 标签: directorio, folder, plantilla, repo, repositorio, repository, template

## 简介

Dado un repositorio remoto y un directorio dentro de ese repositorio, pueda clonar el directorio y usarlo como plantilla para un nuevo proyecto.
