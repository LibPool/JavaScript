# plex-episode-renamer

> 标签: JavaScript

## 简介

A simple CLI tool to rename your Plex episodes. Call the script and point it to a folder containing your TV show files. It will find all the images in the folder that match existing episodes. If it finds an episode, it will rename the file to match the ep
