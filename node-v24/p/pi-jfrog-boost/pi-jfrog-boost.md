# pi-jfrog-boost

> 标签: agent, boost, hooks, jfrog, pi, pi-package, token-optimization

## 简介

JFrog Boost integration for the pi coding agent — compacts noisy tool output to save tokens and context. Community project, not affiliated with JFrog.
