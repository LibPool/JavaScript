# pi-hang-guard

> 标签: bash, command-timeout, extension, hang, hung, pi, pi-package, silence, stuck, timeout, watchdog

## 简介

Watchdog for the pi coding agent: detects bash commands that produce no output (hung builds, silently stuck dev servers) and warns you instead of waiting forever.
