# paceproof-cli

> 标签: ai-governance, attestation-verification, audit-trail, cli, compute-attestation, compute-governance, cryptographic-verification, ed25519, mcp, model-context-protocol

## 简介

CLI + MCP server that verifies Ed25519-signed compute-attestation records from any provider and reports what compute was actually run, by whom, and whether every signature checks out. Read-only reporting layer -- does not sign or generate attestations.
