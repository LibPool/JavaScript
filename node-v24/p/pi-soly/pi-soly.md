# pi-soly

> 标签: ai-coding, intent-docs, mcp, model-context-protocol, multi-question, pi, pi-extension, pi-package, planning, project-management, rules-engine, session-recovery, workflow-engine

## 简介

Workflow + project management for pi-coding-agent. Plans, state, MANDATORY rules, self-review, multi-question picker. One npm install, zero config. LLM drives the workflow inline via the soly_workflow tool — no external subagent plugin.
