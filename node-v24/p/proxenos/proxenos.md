# proxenos

> 标签: agent, claude-code, delegation, mcp, model-context-protocol, orchestration, subagent

## 简介

MCP server that lets Claude Code delegate tasks to Codex CLI workers (ChatGPT subscription or API-key auth) running in isolated git worktrees
