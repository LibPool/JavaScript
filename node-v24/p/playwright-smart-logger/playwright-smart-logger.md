# playwright-smart-logger

> 标签: automation, buffer, console, debugging, e2e-testing, fixture, logging, playwright, playwright-fixture, qa, smart-logging, test-automation, test-framework, testing, typescript

## 简介

Smart logging fixture for Playwright tests that buffers console output and flushes only on test failures, with advanced features like console groups, timing, and browser console capture
