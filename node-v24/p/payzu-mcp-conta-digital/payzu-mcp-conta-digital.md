# payzu-mcp-conta-digital

> 标签: ai-tools, brl, claude, conta-digital, cursor, fintech, mcp, model-context-protocol, payzu, pix, ted

## 简介

MCP server for PayZu Conta Digital API. 14 tools: Pix in/out, TED, transferência interna, saldo, perfil, extrato. Works with Claude Desktop, Cursor, Continue.
