# pulumi-openfga

> 标签: access-control, authorization, authorization-model, devops, fine-grained-authorization, infrastructure, openfga, permissions, provider, pulumi, rebac, relationship-tuples, terraform, zanzibar

## 简介

A Pulumi provider for managing OpenFGA fine-grained authorization (ReBAC) with support for stores, authorization models, and relationship tuples, dynamically bridged from the Terraform OpenFGA provider.
