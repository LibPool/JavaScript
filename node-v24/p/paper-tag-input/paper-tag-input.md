# paper-tag-input

> 标签: accessible, chip-input, chips, form, paper-tags, stamp, tag-input, tags, vanilla-js

## 简介

A tag field where typed words become paper tags or ink stamps; paste splits on commas and newlines, Backspace pulls the last tag back to edit.
