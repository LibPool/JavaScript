# print-escpos-parser

> 标签: escpos, gbk, parser, pos, printer, receipt, thermal, utf8

## 简介

一个基于Node.js的ESC/POS打印机指令全解析工具，可以将ESC/POS格式的二进制数据或十六进制字符串解析为可读的格式
