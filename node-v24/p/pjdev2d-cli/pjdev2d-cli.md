# pjdev2d-cli

> 标签: JavaScript

## 简介

CLI to copy React UI components, overlays, layouts, utilities, and project scaffolds into your app. Templates live in this package; `add` copies them into your project, rewrites `@/pjdev2d-cli` imports to relative paths, installs missing peer dependencies
