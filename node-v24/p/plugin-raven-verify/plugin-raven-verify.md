# plugin-raven-verify

> 标签: attestation, elizaos, elizaos-plugins, plugin, raven, signed-receipt, solana, token, verification

## 简介

ElizaOS plugin: fetch a signed Raven receipt (receipt-v1) for a Solana mint and verify it LOCALLY against caller-pinned trusted keys before reporting facts, scope, and coverage gaps. Evidence, not a safe/unsafe verdict.
