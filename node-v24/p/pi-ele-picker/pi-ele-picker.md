# pi-ele-picker

> 标签: ai, devtools, element-picker, inspector, pi, pi-package, vite, vite-plugin

## 简介

Pick an element in your running page, describe the change, and send it to a pi session. Ships a Vite dev plugin (browser picker + discovery endpoint) and the matching pi bridge extension.
