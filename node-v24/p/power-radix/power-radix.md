# power-radix

> 标签: arithmetic, base, base conversion, base convert, base10, base58, base58 decode, base58 encode, base64, base64 decode, base64 encode, conversion, convert, decode, encode, hex, math, power, radix, radix conversion, radix convert

## 简介

Library for converting numbers from one radix representation (encoding) to another, with optional custom defined encodings. Inspired by rubyworks/radix.
