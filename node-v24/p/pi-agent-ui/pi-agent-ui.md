# pi-agent-ui

> 标签: agent-ui, chat, coding-agent, dashboard, developer-tools, pi, pi-coding-agent, pi-package, web-console, web-ui, webui

## 简介

Unofficial web interface for the pi coding agent — desktop workspace + mobile chat. Every session spawns an isolated pi process (RPC direct-drive).
