# pg-hybrid-rrf

> 标签: full-text-search, hybrid-search, pgvector, postgres, rag, ranking, reciprocal-rank-fusion, retrieval, rrf, tsvector, vector-search

## 简介

Hybrid search on Postgres (pgvector + full-text) fused by Reciprocal Rank Fusion, because adding a bounded cosine score to an unbounded ts_rank_cd does not do what the weights say.
