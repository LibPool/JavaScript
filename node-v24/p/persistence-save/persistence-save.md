# persistence-save

> 标签: autosave, capacitor, game-dev, jeep-sqlite, migrations, persistence, save-game, sql.js, sqlcipher, sqlite

## 简介

Save-game persistence for Capacitor games: a SQLite save/load facade (jeep-sqlite/sql.js on the web, native SQLite with SQLCipher on device), chained snapshot migrations, corrupt-save isolation, an autosave scheduler and a Preferences key-value bridge.
