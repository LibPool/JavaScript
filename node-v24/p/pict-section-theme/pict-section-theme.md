# pict-section-theme

> 标签: dark-mode, pict, retold, theme, theme-picker

## 简介

Pict section that bundles every Retold-ecosystem theme (pict-default, retold-mono, twilight, cyberpunk, daylight, neo-tokyo, …) and exposes three reusable views — a theme picker dropdown, a light/dark/system mode toggle, and an embeddable SVG topbar butto
