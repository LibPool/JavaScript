# purple-spec

> 标签: ai, audit, blue-team, bun, cli, deno, hardening, node, purple-team, red-team, sdd, security, spec, threat-model, typescript

## 简介

👾 Purple Spec is a toolkit for Security-Driven Development, a workflow that combines offensive pentest and defensive hardening so your AI agent can detect what a system does, attack it like an adversary, and harden the defenses that matter.
