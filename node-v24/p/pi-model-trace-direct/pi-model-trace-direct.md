# pi-model-trace-direct

> 标签: fingerprint, model-attribution, modeltrace, pi-coding-agent, pi-extension, pi-package

## 简介

Raw-API model attribution for the Pi coding agent: probe a provider with numeric fingerprint challenges and score the answers against a bundled ModelTrace bank, with an optional second run that keeps Pi's own system prompt so the two can be compared.
