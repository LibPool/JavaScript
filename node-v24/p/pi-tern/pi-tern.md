# pi-tern

> 标签: developer-tools, extension, mermaid, pi, pi-coding-agent, pi-package, stencil, terminal, tern, tsp

## 简介

Tern integration for the pi coding agent: TSP handshake, native Mermaid diagrams, WKWebView browser automation, pane capture and a session mirror.
