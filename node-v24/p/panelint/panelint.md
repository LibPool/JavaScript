# panelint

> 标签: csp, linter, mcp, mcp-apps, prompt-injection, sarif, security, sep-1865, static-analysis

## 简介

Static analyzer for MCP Apps (SEP-1865) UI resources. Reports properties of a content hash at a point in time.
