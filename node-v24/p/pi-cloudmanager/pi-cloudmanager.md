# pi-cloudmanager

> 标签: cloud-storage, onedrive, pi-extension, pi-package, rclone

## 简介

rclone integration for the pi coding agent — browse, read, copy, sync, move and delete files across any rclone remote (OneDrive, S3, SFTP, Google Drive, ...).
