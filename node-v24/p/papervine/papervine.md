# papervine

> 标签: api-documentation, cli, docs, docs-as-code, docs.json, documentation, documentation-generator, gitbook-alternative, mdx, mintlify, mintlify-alternative, openapi, papervine, readme-alternative

## 简介

Serve a docs site of MDX + docs.json — locally or in production. Mintlify-compatible, and an open-source alternative to GitBook and ReadMe.
