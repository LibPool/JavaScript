# prompt-judger

> 标签: JavaScript

## 简介

- GPT-Prompt 加工厂是一个用于`处理GPT模型提示词`的npm包。它提供了三个核心方法，分别针对前端、Java以及进阶的提示词加工需求。通过这个包，用户可以方便地生成或优化用于GPT模型的提示词，从而提高模型的输出质量和效率。
