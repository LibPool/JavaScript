# postcss-tailwind-opacity-fallback

> 标签: color-mix, css, fallback, opacity, postcss, safari, tailwind, tailwindcss

## 简介

PostCSS plugin to add Safari-safe rgba() fallbacks for Tailwind v4 */NN opacity utilities (bg/text/border/outline/fill/stroke).
