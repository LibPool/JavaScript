# permission-core

> 标签: access-control, authorization, data-permissions, nodejs, permissions, rbac, role-inheritance, route-permissions, typescript, wildcard-matching

## 简介

Fine-grained RBAC and resource permission core for Node.js, with route permissions, data scopes, role inheritance, and wildcard matching.
