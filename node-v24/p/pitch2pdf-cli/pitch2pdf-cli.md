# pitch2pdf-cli

> 标签: canva, cli, converter, docsend, google-slides, pdf, pitch, presentations, presentations-ai, prezi

## 简介

Command-line tool to convert Pitch, DocSend, Google Slides, Google Drive, Google Docs, Canva, Prezi, and Presentations.AI decks to PDF.

- 官网：https://www.pitch2pdf.com
- npm 页面：https://www.npmjs.com/package/pitch2pdf-cli

- npm registry：https://registry.npmjs.org/pitch2pdf-cli
