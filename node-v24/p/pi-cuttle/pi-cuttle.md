# pi-cuttle

> 标签: classifier, cost-optimization, cuttle, decision-model, extension, hybrid, jev, llama-cpp, llm-router, lm-studio, local-first, local-llm, memory-governor, model-router, model-routing, ollama, openai-compatible, pi, pi-coding-agent, pi-package, subagents, system-one, vllm, vram

## 简介

Local-first model routing for pi — a local classifier picks the right model per turn, with a cross-process memory governor so subagent fanout cannot exhaust local VRAM. The pi extension for Cuttle.
