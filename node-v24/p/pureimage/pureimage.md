# pureimage

> 标签: JavaScript

## 简介

Pure JS image drawing API based on Canvas. Export to PNG, JPG, and streams.

- 官网：https://github.com/joshmarinacci/node-pureimage#readme
- 源码仓库：git+https://github.com/joshmarinacci/node-pureimage.git
