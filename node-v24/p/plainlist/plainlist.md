# plainlist

> 标签: cli, plaintext, productivity, task, taskpaper, todo

## 简介

Local CLI for Plainlist's plain-text .todo files — list, add, search, and complete tasks, add habits and goals, plus focus/plan/done date views. Natural-language dates (tomorrow, mon, +3). Without --file, targets the same file selected in the Plainlist ap
