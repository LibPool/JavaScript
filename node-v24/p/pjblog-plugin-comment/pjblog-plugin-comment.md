# pjblog-plugin-comment

> 标签: pjblog, plugin

## 简介

PJBlog插件之评论系统；发表评论、删除评论、评论列表、热门评论、对文章HOOK，功能比较齐全。此插件为官方插件，创作者款可以自行开发评论系统。
