# pdffr

> 标签: browser, cli, client-side, document-parsing, latex, layout-analysis, markdown, ocr, pdf, pdf-to-markdown, pdf-to-text, pdfjs, privacy, tesseract

## 简介

PDF → Markdown decompiler for the browser and Node: native glyph geometry in milliseconds, render-diff-guided on-device OCR only where the text layer can't explain the ink.
