# pressa-mcp

> 标签: latex, latex-to-pdf, mcp, mcp-server, pdf, pressa

## 简介

Alias for @pressa/mcp, the Pressa MCP server: compile LaTeX to PDF without installing TeX Live. No API key needed to start.

## 官网

- 官网：https://pressa.dev/docs/mcp
- 源码仓库：git+https://github.com/pressa-dev/mcp.git
- npm 页面：https://www.npmjs.com/package/pressa-mcp

## 历史版本号

- 当前版本：1.0.0

- 1.0.0

## 获取地址

- npm 安装：`npm install pressa-mcp`
- npm registry：https://registry.npmjs.org/pressa-mcp
- Node 要求：>=18
