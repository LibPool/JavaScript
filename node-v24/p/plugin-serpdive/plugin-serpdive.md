# plugin-serpdive

> 标签: ai-agents, elizaos, elizaos-plugin, rag, search, serpdive, tavily-alternative, web-search

## 简介

Web search for elizaOS agents that returns extracted, answer-ready page content instead of links. A Tavily alternative: same speed, 20.2% fewer tokens, 60.7% of decided quality duels won on a public benchmark.
