# pi-feishu-notify

> 标签: bridge, extension, feishu, lark, notification, notify, pi, pi-package, remote, webhook

## 简介

Bidirectional bridge between pi main conversations and Feishu (Lark): sends a Feishu notification when a pi task finishes, and lets you reply to the notification in Feishu to remotely command that pi session to continue. No lark-cli dependency, built on t
