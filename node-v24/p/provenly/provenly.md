# provenly

> 标签: agent, claude, claude-code, guardrails, hooks, llm, verification

## 简介

Mechanical evidence, gates, guards, agents and a supervised task loop for Claude Code: an activity ledger, a claim checker that blocks unsupported 'tests pass', and a repair loop that escalates on stuck failures rather than on retries.
