> 标签: agent, agentic-commerce, base, building-permits, crypto-price, mcp, micropayments, model-context-protocol, oracle, prediction-market, settlement, usdc, x402

## 简介

MCP server for the Permit Verdict settlement oracle and permit intelligence API. Pays per call in USDC on Base via x402 — no API key, no account, no signup.
