# pipeline-runner-streams

> 标签: abort-signal, async, async-await, backend, backpressure, batch-processing, batch-transform, concurrency, data-pipeline, dead-letter, developer-tools, error-handling, etl, exponential-backoff, file-processing, metrics, node, nodejs, observability, parallel-processing, pipeline, readable-stream, retry, stream, stream-pipeline, stream-processing, streams, timeout, transform-stream, writable-stream

## 简介

Promise-based Node.js stream pipeline runner: retries with backoff, parallel transforms (ordered or not), batching, progress and lifecycle metrics, timeout/abort, and continue-on-error with dead-letter support.
