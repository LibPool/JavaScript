# pointmoon-mcp

> 标签: environment, field-truth, grounding, mcp, model-context-protocol, pointmoon, weather

## 简介

MCP stdio server for Pointmoon — sourced, current physical and environmental field-truth for a geographic coordinate. Each fact carries source, observedAt, ttlMinutes, and confidence, or explicit silence. Never guesses.
