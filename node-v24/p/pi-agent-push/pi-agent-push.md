# pi-agent-push

> 标签: bark, dingtalk, feishu, notify, ntfy, pi, pi-coding-agent, pi-extension, pi-package, webhook, wecom

## 简介

Pi extension: push agent idle / interrupted / need-input events to Bark, Feishu, WeCom, DingTalk, ntfy, or a generic webhook.
