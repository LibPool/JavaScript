# pi-ultrawork

> 标签: ai-agent, autonomous, coding-agent, extension, multi-agent, orchestration, pi, pi-coding-agent, pi-extension, pi-package, pi.dev, tui, ultrawork

## 简介

Persistent, goal-driven UltraWork mode for pi.dev — auto-continues across turns and fans sub-tasks out to child pi processes.
