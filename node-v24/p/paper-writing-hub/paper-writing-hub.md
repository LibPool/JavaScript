# paper-writing-hub

> 标签: academic-writing, agent-skills, chinese, claude-code, codex, literature-review, paper-writing, peer-review, rebuttal, research, skills

## 简介

One command installs 8 open-source academic paper-writing skill collections and exposes selected skills natively to Claude Code & Codex (writing, polishing, peer review, rebuttal, literature review, citation verification, thesis PPT, scientific computing)
