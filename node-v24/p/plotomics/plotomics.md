# plotomics

> 标签: bioinformatics, canvas, genomics, heatmap, oncoprint, single-cell, visualization, volcano-plot, webgl

## 简介

High-performance bioinformatics visualization components: headless factories for volcano plots, heatmaps, embeddings, oncoprints, genome browsers and more, backed by a shared TypeScript core.
