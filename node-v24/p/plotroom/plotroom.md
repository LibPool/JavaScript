# plotroom

> 标签: cd, ci, dashboard, devops, embeddable, github-actions, merge-readiness, pipeline, pull-request, react

## 简介

Embeddable CI/CD + pull-request operations dashboard — watch GitHub Actions pipeline health, runner timing and critical path, and PR merge-readiness, with one-click ready-to-merge / draft levers. Ships a React component (./embed) and a mountable Express b
