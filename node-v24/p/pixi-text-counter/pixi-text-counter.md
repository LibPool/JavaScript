# pixi-text-counter

> 标签: animation, casino, counter, digit-roll, pixi, pixi.js, pixijs, reel, slot, tween

## 简介

Animated numeric counter as a PixiJS 8 Container. Mechanical-reel digit roll with low-variance filler frames, built for slot game balance and win displays.
