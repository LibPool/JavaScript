# pure-ts-lint

> 标签: eslint, fp, functional, functional-programming, immutable, lint, pure, type-safe, typesafe, typescript

## 简介

TypeScript linter to prioritise pure functions and type safety (beyond TS strict: true). Inspired by eslint-plugin-react-hooks react-hooks/immutability rule. Powered by oxc-parser.
