# present-agent-mcp

> 标签: ai, claude, codex, gift-recommendations, gifts, mcp, model-context-protocol, present-agent

## 简介

Public MCP server for Present Agent — find 5 explainable, personalized gift recommendations from any MCP client (Claude Code, Codex, and more). Hosted: no local catalog, Shopify, or model keys required.
