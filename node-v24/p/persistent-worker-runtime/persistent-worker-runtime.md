# persistent-worker-runtime

> 标签: background-jobs, concurrency, cpu-bound, event-loop, nodejs, outbox-pattern, pool, runtime, stateful-workers, worker_threads

## 简介

A persistent worker execution runtime for Node.js to offload CPU-bound tasks and preserve Event Loop responsiveness with stateful workers.
