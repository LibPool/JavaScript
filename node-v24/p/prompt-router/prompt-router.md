# prompt-router

> 标签: ai, claude, claude-code, cli, llm, lm-studio, openrouter, prompt, router

## 简介

Route your prompts to the right AI: coding tasks to Claude Code, simple questions to your local model, deep questions to OpenRouter — with prompt optimization built in.
