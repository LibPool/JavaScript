# pi-long-task

> 标签: agentic-coding, ai-automation, ai-coding-agent, ai-coding-assistant, autonomous-coding, background-agent, coding-agent, developer-tools, llm-agent, long-running-tasks, long-task, pi, pi-coding-agent, pi-extension, pi-package, subagent, task-orchestration, task-runner, todo-planner, worker-sessions

## 简介

Pi coding agent extension that breaks large coding requests into tracked TODOs and runs them in bounded, adaptively reused AI worker sessions. A long-running task runner and subagent orchestrator for Pi, with a live TUI progress sidebar, retries, goal loo
