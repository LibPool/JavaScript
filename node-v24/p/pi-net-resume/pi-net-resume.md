# pi-net-resume

> 标签: hotspot, network, offline, pi, pi-coding-agent, pi-extension, pi-package, reconnect, resume, wifi

## 简介

Auto-continue a pi session after a network outage: arm on a connectivity error, wait for the link, then resume the same session with full context.
