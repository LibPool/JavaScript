# pinback-mcp

> 标签: annotations, chrome-extension, claude-code, codex, coding-agent, feedback, mcp, model-context-protocol

## 简介

Local MCP server that lets your coding agent read visual-feedback comments pinned to web pages with the Pinback Chrome extension.
