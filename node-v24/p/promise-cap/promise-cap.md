# promise-cap

> 标签: abort, async, concurrency, limit, priority, promise, queue, rate-limit, throttle, timeout

## 简介

Run async functions with limited concurrency — priority queuing, AbortSignal, timeouts, pause/resume, deadlock detection. Zero dependencies.
