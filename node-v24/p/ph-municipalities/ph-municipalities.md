# ph-municipalities

> 标签: pagasa, pagasa 10-day forecast, pagasa-parser, philippines, philippines json, philippines municipalities, philippines provinces, philippines regions, sheetjs, xlsx

## 简介

Lists and writes Philippine municipalities by province or region into JSON files using PAGASA 10-Day weather forecast Excel files as a data source
