# pdf-it-mcp

> 标签: ai-agents, anthropic, anthropic-skill, claude, claude-code, claude-desktop, cursor, markdown, markdown-to-pdf, mcp, mcp-server, model-context-protocol, modelcontextprotocol, pdf, pdf-generation, pdf-generator, react-pdf, report, research, skill

## 简介

MCP server and Claude Code skill that turns markdown into designed PDFs. Cover page, table of contents, code blocks that hold across page breaks, page-numbered footer. Fonts embedded, nothing else to install.
