# panda-plugin-qwik

> 标签: css-in-js, jsx, panda-plugin, pandacss, patterns, qwik

## 简介

Panda CSS v2 plugin that generates Qwik JSX pattern components (Box, Stack, VStack, HStack, …) with full style-prop support.
