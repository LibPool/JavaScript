# prisma-class-generator

> 标签: class-transformer, class-validator, codegen, dto, generator, graphql, nestjs, openapi, orm, prisma, prisma-generator, prisma-schema, swagger, typegraphql, typescript, validation

## 简介

Prisma generator that emits TypeScript classes decorated for @nestjs/swagger, class-validator, and TypeGraphQL — DTO/entity classes generated straight from schema.prisma.
