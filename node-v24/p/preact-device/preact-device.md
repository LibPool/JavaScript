# preact-device

> 标签: device-detect, is-android, is-ios, is-mobile, mobile-detection, preact, react, responsive, ssr, ua, user-agent

## 简介

Modern, minimal device detection for Preact (and React via preact/compat). ~563B brotli, SSR-safe, tree-shakeable.
