# py-cli-react

> 标签: JavaScript

## 简介

-   vite + react + ts 的项目框架 -   已安装的依赖有：antd，windicss，react-router-dom 等 -   已添加：eslint，prettier 作为代码基础检查和美化 -   已配置：前端代理解决跨域问题 -   已经配置路由表，在 RouterConfig 中 -   已经基于 fetch 封装数据请求方法 request
