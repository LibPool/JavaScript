# praxis-memory

> 标签: agent-accountability, agents, ai, claude, claude-code, cli, codex, context, mcp, memory, provenance, receipts, verification

## 简介

Your AI says "done." PRAXIS proves it. Signed, tamper-evident receipts of what your coding agent actually did — plus durable project memory. Local-first: no server, no account, your code never leaves your machine.
