# prisma-tenant-guard

> 标签: asynclocalstorage, multi-tenancy, multi-tenant, multitenant, nestjs, postgres, prisma, prisma-client-extension, prisma-extension, prisma-multi-tenant, rls, row-level-security, saas, tenant, tenant-isolation, typescript

## 简介

Row-level multi-tenancy for Prisma: an AsyncLocalStorage tenant context, a client extension that filters reads and stamps writes, and a test kit that proves no model escaped isolation.
