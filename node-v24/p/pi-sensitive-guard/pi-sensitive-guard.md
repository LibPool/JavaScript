# pi-sensitive-guard

> 标签: coding-agent, git-protection, pi, pi-coding-agent, pi-extension, pi-package, pi-tui, redaction, secret-scanning, security, sensitive-files

## 简介

Pi extension that protects sensitive files, blocks secret writes, and optionally redacts protected read output.
