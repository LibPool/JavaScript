# polydeukes

> 标签: agent, ai, covenant, dev-tool, discipline, guard, harness, ledger, verification

## 简介

A development discipline framework for building alongside an AI coding partner — deterministic covenants, a verifiable work ledger, local memory, and adversarial verification. Beta.
