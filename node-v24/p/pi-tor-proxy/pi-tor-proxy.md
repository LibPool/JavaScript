# pi-tor-proxy

> 标签: anonymous, coding-agent, extension, pi, pi-package, privacy, proxy, tor

## 简介

Pi extension that routes pi agent requests through Tor. It downloads and manages its own Tor binary, so nothing needs to be installed on the system.
