# pardis-jalali-datepicker

> 标签: calendar, date, datepicker, farsi, iran, jalaali, jalali, persian, rtl, shamsi, vanilla-js, zero-dependency

## 简介

A modern, zero-dependency Persian (Jalali/Shamsi) datepicker — multi-instance, inline mode, range selection, input masking, and three built-in themes.
