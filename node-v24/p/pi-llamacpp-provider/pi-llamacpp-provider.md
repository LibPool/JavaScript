# pi-llamacpp-provider

> 标签: gguf, llama-server, llama.cpp, llamacpp, local-llm, openai-compatible, pi, pi-coding-agent, pi-extension, pi-package, provider

## 简介

pi extension that registers your llama.cpp server as a provider and auto-discovers every model it exposes at /v1/models — context size, vision and thinking support included
