# pwainit

> 标签: init-pwa, pwa, pwa-init, pwainit, webapps, website-to-pwa

## 简介

Turn your existing website to Progressive Web App or Initiate PWA project using just one command. 'npm i -g pwainit' to install pwainit and get started.
