# pymations

> 标签: animation, education, explainer, katex, latex, manim, math, maths, pyodide, python

## 简介

Maths animations from Python on any web page: the browser half of Pymations, with its animation engine. Runs Manim Community scripts. Python runs in the browser with Pyodide.
