# pandect

> 标签: agent, ai-coding, claude, claude-code, codex, cursor, pandect, rulebook, scaffold, stack

## 简介

Stop setting up, start shipping. 33 opinionated stack rulebooks for AI coding agents (Claude Code, Codex, Cursor). One markdown file per stack — every decision pre-made, every version cited. npx pandect <stack>.
