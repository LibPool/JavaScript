# pptx-exporter

> 标签: aippt, converter, export, headless, online-ppt, powerpoint, pptist, pptx, presentation, slides

## 简介

A powerful PPTX export utility for converting slide data to PowerPoint presentations. Based on PPTist project, providing headless export functionality for PPTist online presentation application.
