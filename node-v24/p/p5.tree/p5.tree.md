# p5.tree

> 标签: addon, camera, geometry, gizmo, graphics, keyframes, manipulator, p5, p5.js, quaternion, shader, spaces, tree, webgl

## 简介

Render pipeline for p5.js v2 — pose and camera interpolation, space transforms, frustum visibility, HUD, post-processing pipe, picking, interactive 3D handles, 6-DOF helms, and declarative control panels.
