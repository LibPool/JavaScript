# paperclip-plugin-tickler

> 标签: agent-ops, ai-agents, approvals, dashboard, hud, paperclip, paperclip-plugin, paperclipai, triage

## 简介

Every org, one page: a cross-org HUD for Paperclip that shows what needs you and lets you answer approvals and agent questions inline.
