# phantomx-file-client

> 标签: ai, coder, file-server, file-system, git, lsp, socket.io, websocket

## 简介

A Socket.IO-based file-system client for Phantom coding agent, Exposes file operations, git workflows, LSP diagnostics and real-time file watching over WebSockets.
