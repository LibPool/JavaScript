# parse-string-to-argv

> 标签: argv, cli, parser, shell-words, string-argv, tokenizer, wasm

## 简介

Safely split a command string into an argv array using the Rust shell-words crate compiled to ~4 KB of WebAssembly. POSIX shell tokenization semantics, no expansion, no execution, throws on malformed input.
