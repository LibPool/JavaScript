# pagebolt-mcp

> 标签: ai-tools, browser-automation, claude, cline, cursor, demo-video, devtools, mcp, mcp-server, model-context-protocol, og-image, open-graph, page-inspection, pagebolt, pdf, pdf-generation, puppeteer, screenshot, screenshot-api, social-card, video-recording, web-capture, windsurf

## 简介

MCP server for PageBolt — take screenshots, generate PDFs, create OG images, inspect pages, record demo videos with Audio Guide narration, from AI coding assistants like Claude, Cursor, and Windsurf.
