# postman-openapi-schema-validator

> 标签: API, CLI, OpenAPI, Postman, schema, testing, validation, validator

## 简介

A Node.js utility for validating and integrating OpenAPI schema validations into Postman collections. Supports OpenAPI versions 2.0, 3.0.x. Works as a CLI tool and a library.
