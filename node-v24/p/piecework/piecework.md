# piecework

> 标签: bencode, bittorrent, cli, file-sharing, p2p, peer-to-peer, protocol, tcp, torrent

## 简介

Share a file with anyone in one command. A real peer-to-peer file-sharing protocol, implemented from scratch: bencoding, SHA-1 piece verification, a tracker, and the actual BitTorrent peer wire protocol (BEP 3).
