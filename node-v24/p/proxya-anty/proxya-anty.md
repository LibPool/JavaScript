# proxya-anty

> 标签: anti-detect, antidetect, automation, browser, cdp, fingerprint, playwright, proxy, puppeteer, scraping

## 简介

Drive the Proxya Anty anti-detect browser from Node. Fingerprints are applied inside a patched Chromium, and the DevTools Runtime agent is not left switched on — so a script-driven session is not read as automated.
