# polarmemory_openclaw

> 标签: memory, openclaw, plugin, polardb, polarmemory

## 简介

PolarDB-PG long-term memory plugin for OpenClaw. Provides auto-recall, auto-capture, and memory tools backed by a polarmemory server deployment.
