# pi-llm-wiki

> 标签: knowledge-base, llm, obsidian, pi, pi-package, pkm, research, wiki

## 简介

A Pi package for persistent markdown wikis with source capture, generated metadata, linting, and an LLM wiki-maintainer skill.
