# pi-neon-editor

> 标签: animation, editor, neon, pi-extension, pi-package, truecolor, tui

## 简介

Animated flowing neon border for the pi input editor: truecolor gradient presets, render modes, reactive typing/send/done/working effects, and user-defined presets.
