# pi-everos-memory

> 标签: everos, extension, memory, pi, pi-extension, pi-package

## 简介

EverOS-backed long-term memory for pi. Model-callable user-memory tools (search/add/profile/episodes/foresight/delete) and agent-memory tools (skills/cases/record).
