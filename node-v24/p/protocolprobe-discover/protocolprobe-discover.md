# protocolprobe-discover

> 标签: inventory, mcp, model-context-protocol, security, shadow-it

## 简介

Lists the MCP servers configured on this machine and, offline, which are in the official MCP registry. Reads config files only; sends nothing anywhere; never prints secrets.

## 官网

- 官网：https://protocolprobe.com/docs/discover
