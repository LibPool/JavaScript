# placa-fipe-api

> 标签: automovel, carro, fipe, placa, placa-api, veiculo

## 简介

Está biblioteca é para buscar dados de veículos a partir da placa, para isso é utilizado os dados fornecidos do site Tabela Fipe Brasil. Ela também verifica se o valor pesquisada realmente é uma placa válida.
