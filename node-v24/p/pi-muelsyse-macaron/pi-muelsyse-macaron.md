# pi-muelsyse-macaron

> 标签: macaron, muelsyse, pi-extension, pi-package, pi-theme, tui

## 简介

Lightweight Muelsyse Macaron visual pack for Pi: theme, ANSI art header, macaron Zentui chrome, Claude-style shimmer, optional matrix rain.
