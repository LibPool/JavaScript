# paste-audio-mcp

> 标签: claude, mcp, modelcontextprotocol, speech-to-text, transcription, voice-memo, whisper

## 简介

MCP server for paste.audio — hand Claude a voice memo or recording, get a clean transcript back. No account, no API key.

## 官网

- 官网：https://paste.audio
- npm 页面：https://www.npmjs.com/package/paste-audio-mcp

- 1.0.0

- npm registry：https://registry.npmjs.org/paste-audio-mcp
- Node 要求：>=20
