# pi-sarvam-provider

> 标签: ai, llm, openai-compatible, pi, pi-coding-agent, pi-package, provider, sarvam

## 简介

Pi coding-agent extension that registers Sarvam AI as a model provider and adds the compatibility shims its OpenAI-compatible endpoint needs (role/content fixes, tool-argument remapping, 403 retry, and a 256KB request-size guard).
