# preflight-x402

> 标签: 402, agentic-commerce, agentic-payments, ai-agents, base, mcp, payment-safety, preflight, usdc, x402

## 简介

Gate an x402 / HTTP 402 agent payment on an independent CLEAR/HOLD/ABORT verdict from whatagentsbuy.com, backed by real payment history to the seller (not a probe-only check). Abort before you sign.
