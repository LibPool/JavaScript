# pi-workflows-claude

> 标签: agents, orchestration, pi-extension, pi-package, subagents, workflow

## 简介

Claude-Code-style workflow engine for pi: a Workflow tool that runs deterministic JavaScript orchestration scripts (agent/parallel/pipeline/phase) with resume, journaling, phases, permissions and a live web UI.
