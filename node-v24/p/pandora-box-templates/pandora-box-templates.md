# pandora-box-templates

> 标签: components, low-code, page-builder, pandora-box, react, templates

## 简介

Self-contained page-template components (WhatsNew, MediaCarousel, HeroOverview, …) + their generated manifest, for rendering pandora-box documents in host apps. Built from @lce/layout — the same components the builder canvas renders.
