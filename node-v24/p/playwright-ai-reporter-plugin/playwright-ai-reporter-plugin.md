# playwright-ai-reporter-plugin

> 标签: ai, claude, e2e, failure-analysis, llm, mcp, ollama, openai, playwright, plugin, reporter, testing

## 简介

Playwright reporter that attaches AI-generated hypotheses about why a test failed, ranked by likelihood, each justified and with a suggested fix
