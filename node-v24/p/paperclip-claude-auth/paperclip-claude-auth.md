# paperclip-claude-auth

> 标签: auth, claude, oauth, paperclip, plugin

## 简介

Sign in to Claude from the Paperclip UI. Drives `claude setup-token` on a pseudo-terminal and stores the resulting 1-year token where the claude_local adapter reads it. Works on local environments.
