# pathname-to-regexp

> 标签: compiler, match, matcher, named-parameters, optional-groups, parameters, parse, parser, path, path-to-regexp, pathname, regex, regexp, regular-expression, route, router, routing, url, wildcard

## 简介

A robust JavaScript pathname parser, compiler, and matcher. Supports named parameters, wildcards, optional groups, custom delimiters, and generates optimized regular expressions.
