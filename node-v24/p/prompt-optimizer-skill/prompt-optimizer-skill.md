# prompt-optimizer-skill

> 标签: agent-skill, ai, clarity-framework, npx, prompt, prompt-engineering, prompt-optimizer, skill

## 简介

A professional agent skill that transforms simple instructions into production-ready prompts. Based on the CLARITY framework, supports 61 prompt frameworks, and provides quality validation with multi-version output.
