# playwright-flow-recorder

> 标签: ai, cdp, claude, codegen, cucumber, e2e, gherkin, playwright, qa, recorder, selectors, test-automation

## 简介

Record a browser walkthrough as a semantic event stream (JSONL) — multiple candidate selectors, recorded assertions, and intent notes — then let an AI agent convert it into tests that reuse your existing step library.
