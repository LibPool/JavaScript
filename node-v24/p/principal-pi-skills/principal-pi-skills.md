# principal-pi-skills

> 标签: agent-skills, pi-package, skills

## 简介

Skill framework for principal-level software engineering: seven dual-use skills (decide, architect, plan, build, review, debug, git-ops), a pi bootstrap, and two approval-gated workflows.
