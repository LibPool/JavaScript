# pwa-station

> 标签: composable, indexeddb, pwa, sqlite, storage, vue, wa-sqlite

## 简介

PWA Station SDK — browser SDK for PWA Station platform with SQLite, file storage, notifications, and scheduler. Includes debug mode via wa-sqlite + IndexedDB.
