# pi-copy-on-select

> 标签: clipboard, coding-agent, copy-on-select, pi, pi-extension, pi-package, selection, terminal, tui

## 简介

Copy-on-select for the pi coding agent: mouse selections land on the clipboard, a bottom-right toast confirms it, and the highlight clears itself
