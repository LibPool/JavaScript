# pi-hledit

> 标签: agent-tool, ai-agent, coding-agents, context-safe, extension, file-editing, hash-anchored, hashline, hashline-edit, hledit, local-first, pi, pi-coding-agent, pi-package, stale-edit, stale-write

## 简介

Pi wrapper for hledit hash-anchored file edits. Rejects stale writes before they happen for AI coding agents.
