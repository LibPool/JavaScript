# payload-workflows

> 标签: automation, jobs, no-code, payload, payload-plugin, payloadcms, queue, react-flow, workflows

## 简介

Visual workflows for Payload CMS 3: see every job run as a graph, and build workflows in the admin panel by dragging tasks onto a canvas. Runs on Payload's own jobs queue.
