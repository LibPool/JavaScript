# pi-paste-image-to-model

> 标签: clipboard, coding-agent, image, image-attachment, image-describe, pi, pi-coding-agent, pi-extension, pi-package, pi-tui, vision, vl-model

## 简介

Paste an image in Pi TUI; relay it with recent chat context and your prompt to a vision model, and inject the analysis into the main model's context
