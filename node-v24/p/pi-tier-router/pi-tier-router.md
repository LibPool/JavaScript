# pi-tier-router

> 标签: llm-cost, model-routing, model-tiering, pi-extension, pi-package, virtual-model

## 简介

Pi extension that routes each session between a cheap flash model and a strong pro model based on issue difficulty - Claude Code style haiku/sonnet/opus tiering, config-driven for any model family.
