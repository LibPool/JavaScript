# pi-ninfer-video

> 标签: local, ninfer, openai-compatible, pi, pi-extension, pi-package, video, vision

## 简介

pi extension: read a local video via a video-capable model, inheriting pi's current provider's endpoint and API key (e.g. a local ninfer). Zero dependencies.
