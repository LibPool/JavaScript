# pi-xfer

> 标签: agent-to-agent, coding-agent, context-transfer, handoff, mesh, pi, pi-extension, pi-package

## 简介

Cross-context handoff extension for pi coding agents: structured markdown handoffs over local sockets, cross-machine mesh transport, async board, and web picker.
