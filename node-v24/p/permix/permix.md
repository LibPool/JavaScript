# permix

> 标签: access-control, acl, authorization, frontend, javascript, nestjs, nextjs, permissions, permissions-management, rbac, react, security, solid, svelte, type-safe, typescript, vue

## 简介

Permix is a lightweight, framework-agnostic, type-safe permissions management library for JavaScript applications on the client and server sides.
