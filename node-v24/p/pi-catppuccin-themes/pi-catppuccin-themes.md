# pi-catppuccin-themes

> 标签: catppuccin, pi, pi-coding-agent, pi-package, theme, themes

## 简介

Pi themes. The four Catppuccin flavors (latte, frappe, macchiato, mocha) vendored in-house so no third-party install is needed.
