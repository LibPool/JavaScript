# pi-glm-usage

> 标签: pi-package

## 简介

A pi extension that displays z.ai (GLM Coding Plan) subscription quota usage in the status bar. Shows 5-hour and weekly quota percentages, plan level, and reset times. Updates every 60 seconds during agent runs.
