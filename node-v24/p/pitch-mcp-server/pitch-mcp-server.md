# pitch-mcp-server

> 标签: capital-thought, claude, mcp, model-context-protocol, pitch, startups, texas

## 简介

MCP server for Pitch — a startup directory and profile management platform for the Texas startup ecosystem. Exposes 24 tools for managing companies, people, pipelines, tags, cities, and reviews from MCP-aware clients like Claude Code and Cursor.
