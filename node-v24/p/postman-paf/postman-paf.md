# postman-paf

> 标签: JavaScript

## 简介

Unofficial JavaScript library to apply Royal Mail Rules & Exceptions to PAF (Postcode Address File) addresses when converting to a printable format.

## 官网

- npm 页面：https://www.npmjs.com/package/postman-paf
