# pdf3json

> 标签: JSON, PDF binary to text, PDF canvas, commandline utility to parse pdf to json, convert pdf to json, javascript, pdf, pdf parser, pdf.js fork, port pdf.js to node.js, server side PDF parser

## 简介

A PDF file parser that converts PDF binaries to text based JSON, powered by porting a fork of PDF.JS to Node.js
