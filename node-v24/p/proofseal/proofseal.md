# proofseal

> 标签: ai-agents, claims, drift-detection, harness, mcp, provenance, regression, verification

## 简介

Regression memory for coding agents — seal how your repo behaves, then check over MCP (or in CI) that an edit didn't regress it: pass/drift/regressed/missing.
