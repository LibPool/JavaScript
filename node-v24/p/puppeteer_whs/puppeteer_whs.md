# puppeteer_whs

> 标签: JavaScript

## 简介

1.  报工命令 `auto_whs`      + 如果第一次需要配置下列信息         - `whsUser`  whs系统的用户名         - `whsPwd`   whs系统的密码         - `project`  报工项目编号, 即项目列表中项目所在的索引值 从0开始         - `task`     任务科目编号, 即任务目列表中项目所在的索引值 从0开始         - `projectPath`  报工项目所在的本地完整路径
