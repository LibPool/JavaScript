# projectkeeper

> 标签: ai-agents, claude-code, codex, coding-agents, context-engineering, decision-records, developer-tools, local-first, project-context, project-graph, project-management

## 简介

A resident agent that reads a software project as it is — documents, git history, code and agent sessions — and keeps a browsable picture of what was planned, decided and done. Local-first; bring your own model key.
