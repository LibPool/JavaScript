# permitstack-mcp

> 标签: ai, api, building-permits, claude, construction, mcp, model-context-protocol, permit-data, permitstack, real-estate

## 简介

MCP server for the PermitStack building permit API — search 102M+ US building permits across 10,000+ cities in 48 states and DC from Claude and other AI agents.
