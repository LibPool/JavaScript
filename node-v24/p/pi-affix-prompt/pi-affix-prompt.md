# pi-affix-prompt

> 标签: affix, pi, pi-extension, pi-package, prompt, sticky, tui

## 简介

Affix-pin the active user prompt at the top of the transcript (antd-style Affix) with unified maxRows truncation — fullscreen TUI mode / 用户输入消息吸顶（类似 antd Affix），统一 maxRows 缩略模型
