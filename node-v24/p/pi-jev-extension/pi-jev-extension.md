# pi-jev-extension

> 标签: agent-tool, decision, guardrails, jev, pi-extension, pi-package, typesafe

## 简介

Pi extension providing jev_decide: typed choices, scores and yes/no probabilities from TypeSafe's Jev System One model, with automatic session-model fallback.
