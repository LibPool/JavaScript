# passglyph

> 标签: accessibility, chroma-hash, confirm-password, egyptian-hieroglyphs, forms, hashmask, hieroglyphs, hmac, password, password-confirmation, password-mask, react, typo, visual-hash, vue, web-component, webcrypto

## 简介

Egyptian hieroglyphs instead of password dots: matching passwords show the same glyphs, typos show where they happen, nothing is revealed. Per-instance non-extractable HMAC key over each prefix (no per-character mapping), 4-6 bits/glyph, canvas sprite, in
