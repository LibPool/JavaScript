# pennypost-mcp

> 标签: agents, email, email-api, mcp, model-context-protocol, pennypost, transactional-email

## 简介

Local stdio bridge to the hosted PennyPost MCP server. Lets any MCP client send email and manage a PennyPost account with your API key.
