# pion-mcp

> 标签: ai-agents, blockchain, horizon, mcp, model-context-protocol, pi-network, stellar

## 简介

Pion — Model Context Protocol (MCP) server for Pi Network. Read-only chain queries against Pi Mainnet and Testnet; payments are testnet-only.
