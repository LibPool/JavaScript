# pi-reactor

> 标签: ai-agent, autonomous-agents, coding-agent, cron, job-queue, pi, pi-coding-agent, pi-extension, pi-package, self-hosted, telegram, webhook

## 简介

Self-hosted agent event loop for the pi coding agent: cron and webhook triggers, a durable queue with spend caps, and outbound notifications to Telegram/Slack.
