# pi-nebula

> 标签: nebula, pi, pi-extension, pi-package, pi-theme, status-bar, theme, tui

## 简介

One chrome extension + one theme for pi: persistent startup panel, status bar, metrics bar, editor shell, tool rows — base16 nebula palette.
