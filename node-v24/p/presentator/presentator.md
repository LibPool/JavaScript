# presentator

> 标签: deck, editorial, html, katex, markdown, mermaid, presentation, slides, swiss-design, zero-dependency

## 简介

Zero-dependency Swiss/editorial HTML presentation generator. 12 layouts, 8 animations, canvas waves, cursor FX, KaTeX, Mermaid. JSON or Markdown input, single index.html output.
