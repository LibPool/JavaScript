# pi-p2p-sync

> 标签: backup, cli, config, dotfiles, mirror, peer-to-peer, pi, pi-coding-agent, pi-package, ssh, sync

## 简介

Standalone CLI that pulls a Pi agent config from one reachable machine onto another over SSH.
