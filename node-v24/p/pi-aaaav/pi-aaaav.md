# pi-aaaav

> 标签: aaaav, agent-workflow, pi, pi-coding-agent, pi-package, playbooks, skills

## 简介

Agent workflow skills for pi: one entry skill per task type, each with playbooks, over a shared Align → Anchor → Act → Verify loop, plus loop extensions (anchor gate, decision trail tool, Jev second thought, skill validator, stream rules).
