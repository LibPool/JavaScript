# pacwich

> 标签: api, bun, cli, devops, monorepo, npm, orchestration, package, package.json, pnpm, scripts, typescript, workspace, workspaces

## 简介

Monorepo tooling that works with Bun, pnpm, and npm workspaces and orchestrates package.json scripts, with a CLI and TypeScript library API
