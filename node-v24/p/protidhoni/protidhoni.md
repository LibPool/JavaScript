# protidhoni

> 标签: cache, caching, invalidation, ioredis, memoize, redis

## 简介

Redis-backed caching and invalidation higher-order functions for Node.js — wrap an async function with read-through caching, TTLs, prefix-based invalidation, and optional worker-queue-deferred invalidation.
