# paperclip-openrouter

> 标签: adapter, ai-agent, anthropic, llm, openrouter, orchestration, paperclip, paperclip-adapter, prompt-caching

## 简介

Paperclip external adapter for OpenRouter — run any of OpenRouter's 300+ models as a tool-loop agent. No local CLI. Live model catalog, per-run cost, credit-balance reporting, and Anthropic/Gemini prompt caching.
