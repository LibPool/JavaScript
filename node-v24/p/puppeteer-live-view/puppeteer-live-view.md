# puppeteer-live-view

> 标签: browser-streaming, cdp, live-view, puppeteer, puppeteer-extra, remote-browser, screencast, web-component

## 简介

Low-latency live browser rendering for Puppeteer: a web component, a puppeteer-extra plugin, and a backend session manager.
