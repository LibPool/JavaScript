## 简介

MemoryCore (TencentDB Agent Memory) long-term memory extension for pi coding agent: L0 conversations, L1 atomic memory, L2 scenes, L3 persona, team skills and knowledge base (LLM wiki) with auto-capture/recall hooks. Supports direct-connect and Gateway au
