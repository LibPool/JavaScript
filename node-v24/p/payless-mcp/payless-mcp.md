# payless-mcp

> 标签: agent-wallet, ai-agents, mcp, micropayments, model-context-protocol, robinhood-chain, usdg, x402

## 简介

MCP server that lets an agent pay for APIs over x402 on Robinhood Chain — with a spending cap it cannot exceed.
