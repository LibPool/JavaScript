# pre-commit-readme-enforcer

> 标签: documentation, git, hook, husky, pre-commit, readme, readme-links

## 简介

Pre-commit hook: stage nearest companion docs with code changes; optional custom doc patterns, warn-only mode, and root README reachability over relative Markdown links
