# pi-wake

> 标签: agent-automation, daemon, event-subscription, pi-coding-agent, pi-extension, pi-package, scheduler

## 简介

Programmable event subscriptions for the Pi coding agent: one-shot timers, remote container watches, batch barriers (watch_container_group) and completion-file conditions that wake the same agent session — in-session or via a headless-resume daemon.
