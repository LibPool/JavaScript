# publisher-subscriber-react-hoc

> 标签: HOC, addEventListener, addListener, browser, callbacks, consumer, eventEmitter, events, higher order component, javascript, provider, pub-sub, publish, publisher, publisher-subscriber, react, removeEventListener, removeListener, subscribe, subscriber, typescript, unit tests, unsubscribe, window

## 简介

React Higher-Order Component, which provides 'subscribe', 'unsubscribeAll', 'eventSubscribersCount', 'subscribersCount' methods. Can be used with various eventEmitters, including browser's 'window' object.
