# puku-agent-sdk

> 标签: agent, ai, coding-assistant, puku, puku-cli, sdk

## 简介

TypeScript SDK for building agents on top of puku-cli. Spawns the puku-cli binary as a subprocess and streams NDJSON over stdio.
