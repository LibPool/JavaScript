# pi-context-diet

> 标签: cache, compaction, context, cost, pi-extension, pi-package, tokens

## 简介

Pi extension that cuts token spend on long sessions: elides stale tool results from the context, but only when the prompt cache has already gone cold, so it costs nothing. Zero prompt tokens.
