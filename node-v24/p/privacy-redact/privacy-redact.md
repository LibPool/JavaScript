# privacy-redact

> 标签: anonymize, blur, exif, face-blur, gps, local-first, metadata, ocr, offline, pdf, pii, privacy, redact, redaction, screenshot

## 简介

Library for detecting private content, redacting it, and handling document metadata. Browser components cover OCR, faces, barcodes, and PDF pages.
