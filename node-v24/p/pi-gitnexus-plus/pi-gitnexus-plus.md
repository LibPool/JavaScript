# pi-gitnexus-plus

> 标签: agent, call-graph, code-intelligence, gitnexus, knowledge-graph, pi, pi-extension, pi-package

## 简介

GitNexus knowledge graph integration for pi — enriches searches with call chains, execution flows, and blast radius. Supports stdio and HTTP transports.
