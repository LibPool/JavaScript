# puppeteer-monitor

> 标签: browser, console, debugging, dom, llm, monitoring, puppeteer, screenshot, wsl

## 简介

Browser console, network, DOM monitoring for debugging. Captures console, network, cookies, screenshot, DOM. HTTP API for LLM/scripts. WSL+Windows, Linux, Open/Join modes.
