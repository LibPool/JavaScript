# pollster-server

> 标签: cron, polling, sharing, social, tracking

## 简介

Pollster polls for arbitrary metadata about URLs at regular intervals and puts it in a database. It's particularly good at tracking news articles' social share counts over time. Tailored to an AWS stack.
