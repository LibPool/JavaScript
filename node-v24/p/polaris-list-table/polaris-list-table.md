# polaris-list-table

> 标签: data-table, filtering, hooks, index-table, list-table, mongoose-url-query, pagination, polaris, react, shopify, sorting

## 简介

A complete data table component for Shopify Polaris with filtering, sorting, pagination and URL sync. Integrates with mongoose-url-query.
