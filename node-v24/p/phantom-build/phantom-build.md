# phantom-build

> 标签: build-plugin, code-splitting, event-handlers, lazy-loading, performance, react, rspack, suspense, unplugin, vite, webpack

## 简介

Build-time code-splitting for React (event-handler extraction + React.lazy/Suspense wrapping), plus a read-only RSC migration-readiness analyzer (phantom rsc)
