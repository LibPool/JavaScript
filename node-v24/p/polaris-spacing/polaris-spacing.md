# polaris-spacing

> 标签: CSS, Framework, HTML, JavaScript, Sass, TypeScript, Web, front-end, responsive-design, webpack

## 简介

Polaris Spacing Plugin for Polaris Framework. A set of responsive classes for controlling 'padding', and 'margin' of HTML elements.
