# powerplatform-mcp-server

> 标签: ai, automation, claude, mcp, microsoft, model-context-protocol, power-automate

## 简介

MCP server for Microsoft Power Platform with Azure CLI authentication - 283 tools for AI-assisted flow and app authoring, debugging, data, and administration. No app registration required.
