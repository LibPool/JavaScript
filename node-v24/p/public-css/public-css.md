# public-css

> 标签: JavaScript

## 简介

> 基于 [basscss](http://basscss.com/#getting-started) > 扩展   ```css   .h-50p,.h50 /*50%高度*/   .h-100p,.h100 /*100%高度*/   .w-50p,.w50 /*50%宽度*/   .w-100p,.w100 /*100%高度*/   .pos-fit /*top,right,bottom,left 均为0*/   .pointer /*鼠标手指样式*/   .abs-fit /*填充父容器*/   .
