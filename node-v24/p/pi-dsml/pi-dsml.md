# pi-dsml

> 标签: deepseek, dsml, extension, pi, pi-agent, pi-coding-agent, pi-package, tool-calls

## 简介

Pi package: recovers DeepSeek DSML tool calls that arrive as plain assistant text and executes them as real tool calls.
