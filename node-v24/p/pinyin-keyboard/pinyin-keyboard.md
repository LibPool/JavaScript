# pinyin-keyboard

> 标签: keyboard, pinyin-keyboard, vue3键盘, 手机虚拟键盘, 拼音输入法, 网页版键盘, 虚拟键盘, 键盘

## 简介

🚀 在你不方便使用系统自带的输入法键盘的时候，你可以试试这个拼音输入法键盘，工具如其名，只提供简单的拼音打字，英文（大小写）、数字。键盘还提供两个插槽供你自定义功能，分别是工具栏和工具栏内容，详细可以看下面的介绍。
