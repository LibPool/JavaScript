# pict-section-tabbar

> 标签: JavaScript

## 简介

Host-agnostic tab-bar UI helper: compact underline tabs with icons, submenu groups, pin zones, and menu/wrap/scroll overflow strategies -- a pure string-builder + layout pass with no framework dependency.
