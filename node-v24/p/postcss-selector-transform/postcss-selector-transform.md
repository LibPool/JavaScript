# postcss-selector-transform

> 标签: alias, css, extend, postcss, postcss-plugin, selectors

## 简介

Selector-level plugin surface for PostCSS: one parse, any number of selector transforms — plus styleAliases, build-time “style B like A” via :is() and :where()
