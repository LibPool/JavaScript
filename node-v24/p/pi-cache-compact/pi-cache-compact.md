# pi-cache-compact

> 标签: compaction, llama.cpp, pi, pi-extension, pi-package, prompt-cache

## 简介

Cache-friendly context compaction for Pi: write the handoff summary as a cache-hit continuation instead of a cold, re-serialized prompt.
