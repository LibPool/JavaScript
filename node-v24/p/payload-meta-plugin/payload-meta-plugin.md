# payload-meta-plugin

> 标签: cms, facebook, instagram, meta, payload, payloadcms, plugin, whatsapp

## 简介

Payload CMS plugin for connecting multi-tenant sites to Meta's network (Facebook Pixel + Conversions API, Facebook/Instagram Commerce Catalog, WhatsApp Business Cloud API). Modular per-channel, per-site — nothing hardcoded to one product line.
