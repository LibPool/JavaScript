# pv_diffcam

> 标签: cammera, differential, imagemagick, linux, pi, pvcloud, raspberry, raspistill, streamer, ubuntu

## 简介

This is a pvcloud demo that manipulates a camera in linux to capture data about consecutive images, their difference and sends the data to pvcloud. It will send pictures to the cloud when a big difference is detected. Configuration and behavior of the cam
