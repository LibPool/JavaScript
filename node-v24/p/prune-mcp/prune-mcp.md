# prune-mcp

> 标签: ai, claude, code-search, context, cursor, mcp, model-context-protocol, nextjs, repository, typescript, vscode, windsurf

## 简介

Context-selection engine for AI coding assistants — finds the most relevant files in a codebase for a change request. No LLM, no embeddings, pure graph + text scoring.
