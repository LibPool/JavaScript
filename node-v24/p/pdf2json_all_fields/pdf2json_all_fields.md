# pdf2json_all_fields

> 标签: JSON, PDF binary to text, PDF canvas, commandline utility to parse pdf to json, convert pdf to json, javascript, pdf get form fields, pdf parser, pdf.js fork, port pdf.js to node.js, server side PDF parser

## 简介

A PDF file parser that converts PDF binaries to text based JSON, powered by porting a fork of PDF.JS to Node.js (fork, form fields added)
