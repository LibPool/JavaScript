# pi-agent-tree

> 标签: JavaScript

## 简介

Multiplexer-free async subagent trees for pi, with session takeover and a live agent-tree cost report — based on davis7dotsh/my-pi-setup's subagents extension, enhanced with ideas from pi-interactive-subagents, pi-recursive, and pi-agent-teams.
