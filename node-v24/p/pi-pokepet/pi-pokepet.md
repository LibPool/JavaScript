# pi-pokepet

> 标签: ascii, codex-pets, companion, image, pet, petdex, pi, pi-extension, pi-package, statusline, tamagotchi

## 简介

A cute, colorful pet companion for the pi coding agent. Use classic ASCII pets or Petdex image pets that live below your editor and react to tools, tests, commits, PRs, reviews, subagents, model swaps and more.
