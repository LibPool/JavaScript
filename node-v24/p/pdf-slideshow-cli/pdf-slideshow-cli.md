# pdf-slideshow-cli

> 标签: cli, dark-theme, document, html, pdf, presentation, report, slideshow, tailwind, viewer

## 简介

A modern Node.js CLI tool that generates a TailwindCSS dark-theme HTML slideshow from a folder of PDF files.
