# polite-fetch

> 标签: 429, anthropic, backoff, fetch, github, openai, rate-limit, ratelimit, retry, retry-after, shopify, stripe

## 简介

Rate-limit-aware fetch wrapper that parses Retry-After, X-RateLimit-*, and provider-specific headers (OpenAI, Anthropic, GitHub, Stripe, Shopify) and waits exactly as long as the server asks — instead of dumb exponential backoff.
