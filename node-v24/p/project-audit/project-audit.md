# project-audit

> 标签: audit, claude, cli, security

## 简介

Run Claude Code audits (01–11) into audit-results/; auto-refresh SUMMARY.md + summary.json after a full run. Use `project-audit summary` without Claude to re-index. PROJECT_AUDIT_SKIP_SYNTHESIS=1 skips step 11.
