# ppp-todo

> 标签: JavaScript

## 简介

``` npm install -g ppp-todo & yarn global add ppp-todo ``` ## use ### 添加一个任务 ``` ppp add taskName ``` ### 查看所有任务 ``` ppp tasks ``` ### 清空所有任务 ``` ppp clear ``` ### 查看指令 ``` ppp & ppp help ```
