# pretty-mermaid

> 标签: diagram, diagrams-as-code, flowchart, hand-drawn, mermaid, react, renderer, sequence-diagram, sketch, svg

## 简介

Render Mermaid and Koboyo diagram code to hand-drawn SVG, in Node and in the browser, plus the React editor.

## 官网

- 官网：https://koboyo.com/mermaid-editor
- npm 页面：https://www.npmjs.com/package/pretty-mermaid

## 历史版本号

- 当前版本：0.1.0

- 0.1.0

## 获取地址

- npm 安装：`npm install pretty-mermaid`
- npm registry：https://registry.npmjs.org/pretty-mermaid
- Node 要求：>=22
