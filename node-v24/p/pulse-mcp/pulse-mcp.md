# pulse-mcp

> 标签: agents, ai, bluesky, claude, fediverse, instagram, mastodon, mcp, model-context-protocol, social-metrics, tiktok, youtube

## 简介

MCP server for Pulse — free, agent-first social-post metrics (YouTube, X, TikTok, Bluesky, Mastodon, Instagram, LinkedIn). Tools: metrics, metrics_batch, history, profile, profile_batch.
