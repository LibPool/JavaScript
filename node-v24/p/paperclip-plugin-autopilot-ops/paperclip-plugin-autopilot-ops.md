# paperclip-plugin-autopilot-ops

> 标签: automation, autopilot-care, healthcare, paperclip, plugin

## 简介

Autopilot Care · operación autónoma gobernada para instituciones de salud: workflows determinísticos, validaciones, registro de negocio, políticas (observa/propone/ejecuta/corte) y tablero del director, como plugin de Paperclip.
