# pmwallets

> 标签: ai-agent, claude-code, codex, copy-trading, mcp, pmwallets, polymarket, prediction-markets, smart-money, wallet-tracker

## 简介

Official PMWallets SDK and CLI: Polymarket smart-money leaderboard, real-time wallet fills over WebSocket with gap replay, webhooks, exports — and a CLI + MCP server so AI agents (Claude Code, Codex, Cursor, …) can follow traders and act on their fills.
