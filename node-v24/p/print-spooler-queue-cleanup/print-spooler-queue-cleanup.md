# print-spooler-queue-cleanup

> 标签: cli, no-dependencies, portable, print-queue, print-spooler, printer, printing, spooler, sysadmin, troubleshooting, win32, windows

## 简介

Fix a stuck Windows print queue: see every job, delete the one that wedges it, clear all, pause or restart the spooler - one self-contained .exe, no .NET.
