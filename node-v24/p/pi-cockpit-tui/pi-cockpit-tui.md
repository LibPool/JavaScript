# pi-cockpit-tui

> 标签: footer, git, pi, pi-extension, pi-package, statusline, tasks, tui

## 简介

Terminal UI for pi: footers with git status, task tracking, tool counters, subagent widgets and theme cycling in one hot-reloadable extension.
