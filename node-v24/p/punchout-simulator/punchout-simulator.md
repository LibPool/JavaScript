# punchout-simulator

> 标签: ariba, coupa, cxml, e-procurement, procurement, punchout, punchout-simulator, simulator, testing

## 简介

A developer tool for testing cXML PunchOut integrations by acting as a virtual counterparty (virtual buyer or virtual supplier).
