# pi-skill-deck

> 标签: pi-coding-agent, pi-extension, pi-package, productivity, skills, tui

## 简介

Two-pane categorized skill browser for Pi with bookmarks, tags, frecency tracking, source attribution, and 8 group-by modes (category, source, framework, creator, location, tag, usage, flat)
