# pi-tidy-footer

> 标签: balance, cost, currency, footer, git, live, multi-currency, pi, pi-extension, pi-package, sort, statusline, theme, tidy-footer, token, tui, wrap

## 简介

Tidy and better footer for Pi — native layout with new features: live display of multi-currency token cost and account balance with color warnings; extension sorting, wrapping, and display customization; git file status; and tool activity indicators.
