# parlo-mcp

> 标签: email, mcp, model-context-protocol, parlo, transactional-email

## 简介

MCP server for the Parlo email API — send transactional email and manage sending domains from any MCP-capable agent (Claude Code, Claude Desktop, Cursor, …).
