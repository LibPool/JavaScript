# papertype-mcp

> 标签: html-to-pdf, markdown, mcp, model-context-protocol, papertype, pdf

## 简介

MCP server for PaperType (https://papertype.dev): render Markdown, HTML or hosted templates to PDF from Claude, Cursor and other MCP clients.

## 官网

- 官网：https://papertype.dev/docs
- 源码仓库：git+https://github.com/papertype-dev/papertype-mcp.git
- npm 页面：https://www.npmjs.com/package/papertype-mcp
