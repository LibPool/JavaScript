# patchmesh

> 标签: agent, ai, claude-code, coding-agent, conflict-detection, coordination, file-claims, ledger, mcp, multi-agent, observability

## 简介

MCP server for parallel coding agents: detects file contention, coordinates claims, and prevents conflicts between agents working in the same repository.
