# payload-invoices

> 标签: credit-notes, ecommerce, invoices, payload, payload-plugin, payloadcms, pdf

## 简介

Gapless sequential invoices and credit notes for Payload ecommerce, with a frozen snapshot and PDF output, no runtime dependencies.
