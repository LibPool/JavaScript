# pi-show-cwd

> 标签: cwd, pi, pi-extension, pi-package, pwd, working-directory

## 简介

pi extension that surfaces the harness's working directory: /show-cwd prints it into the chat transcript (no LLM involved), and /change-cwd <dir> switches the harness process's cwd with '-' to jump back, tilde expansion, and filesystem-aware path completi
