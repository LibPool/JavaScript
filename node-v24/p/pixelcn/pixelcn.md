# pixelcn

> 标签: 8-bit, canvas, css, game-ui, lospec, palette, pixel, pixel-art, retro, shadcn, theme, ui

## 简介

Pixel-art UI kit for browser games and web apps: themes from Lospec palettes, stepped corners, ramp shading, CSS role classes and a canvas renderer. No framework required.
