# page-stack-vue3

> 标签: app, navigator, page, pagestack, stack, vue, vue3

## 简介

### 简介： 按照app页面栈的方式，控制路由跳转，打开新页面时保存旧页面的状态，返回时销毁页面，适合移动端H5项目
