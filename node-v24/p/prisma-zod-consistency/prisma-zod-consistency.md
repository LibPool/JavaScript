# prisma-zod-consistency

> 标签: consistency, database, lint, prisma, schema, static-analysis, zod

## 简介

CLI for prisma-zod-consistency — deterministic static analysis for Prisma + Zod + TypeScript projects. Catches drift between schema.prisma, Zod schemas, and TypeScript code.
