# pi-feishu-agent

> 标签: agent, chat-bridge, coding-agent, feishu, lark, multi-agent, pi, pi-package, remote-control, websocket, 机器人, 远程控制, 飞书

## 简介

从飞书/Lark 远程控制 Pi 编程 Agent：WebSocket 长连接、常驻 RPC Agent、移动端富文本。Control Pi coding agents from Feishu/Lark with low-latency WebSocket, persistent RPC agents, and mobile-first rich text replies.
