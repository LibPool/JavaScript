# polkadot-chat-agents

> 标签: agent, ai, bot, chatbot, claude, kimi, polkadot, statement-store

## 简介

Run AI coding agents as chat bots in the Polkadot app — Claude Code, Codex, opencode, Kimi Code, or agent frameworks (Hermes, OpenClaw) over the Statement Store. E2E-encrypted, serverless: a bot is just a process with an outbound RPC connection.
