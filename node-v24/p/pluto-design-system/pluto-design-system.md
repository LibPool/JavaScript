# pluto-design-system

> 标签: css, css-framework, dark-mode, design-system, design-tokens, julia, pluto, pluto.jl

## 简介

A general-purpose CSS framework with a Bootstrap-shaped surface, dressed in the Pluto.jl notebook aesthetic: Vollkorn headings, Alegreya Sans body, JuliaMono code, warm pastel palette.
