# @mathiascg05/smartfetch

> 标签: abortcontroller, backoff, cjs, client, esm, fetch, http, interceptors, retry, timeout, typescript, zero-dependencies

## 简介

A resilient, zero-dependency TypeScript wrapper around the native fetch API: timeouts, retries with pluggable backoff, interceptors and typed errors.
