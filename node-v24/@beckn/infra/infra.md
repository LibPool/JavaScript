# @beckn/infra

> 标签: api-gateway, aws, aws-cdk, aws-cdk-lib, aws-lambda, beckn, beckn-network, beckn-protocol, cdk-construct-library, cdk-constructs, dynamodb, http-api, iac, infrastructure-as-code, lambda, microservices, ondc, open-network-for-digital-commerce, protocol-actor, serverless, sqs, typescript

## 简介

Reusable AWS CDK constructs for deploying a Beckn Protocol actor: one Lambda per protocol action behind an HTTP API (BecknActionApi), the ACK-now/work-later queue+worker shape (AsyncBecknAction), and a single-table DynamoDB store (SingleTableStore).
