# @attesko/sdk

> 标签: JavaScript

## 简介

Attesko Edge SDK: send your product's events to Attesko Cloud with identifiers pseudonymized and sensitive fields removed on your own server.

- 官网：https://attesko.com/api
- 源码仓库：git+https://github.com/Attesko/Attesko-OS.git
- npm 页面：https://www.npmjs.com/package/@attesko/sdk
