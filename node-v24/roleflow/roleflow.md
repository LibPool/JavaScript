# roleflow

> 标签: agents, ai, glm, kimi, opencode, opencode-plugin

## 简介

Roleflow: sistema OpenCode portable con roles por responsabilidad + routing barato + ahorro de tokens. Público, instalable desde cualquier PC o server con una línea en opencode.json.
