# @yishuiliufang/dsh-relaunch

> 标签: deepseek-harness, desktop, dsh, dsh-plugin, relaunch, restart, windows

## 简介

Restart DeepSeek Harness from its sidebar. Relaunches the desktop application without a console window or a confirmation dialog, and survives application updates.
