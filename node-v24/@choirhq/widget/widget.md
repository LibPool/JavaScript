# @choirhq/widget

> 标签: chat, choir, commerce, react, sela, widget

## 简介

Embeddable Sela chat widget for Choir commerce partners — one component, ticket → chat → payment link → confirmation, and the merchant sees the whole conversation in Choir Inbox.
