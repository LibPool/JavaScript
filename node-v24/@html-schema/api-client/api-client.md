# @html-schema/api-client

> 标签: JavaScript

## 简介

跨端 API 契约与 mock client 包。当前阶段用于把 Web、移动端、桌面端未来会共享的接口形状集中到框架无关包内，并提供无后端环境下可运行的 mock client。
