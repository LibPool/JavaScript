# @klyftig/alarm-core

> 标签: alarm, alarmkit, expo, klyftig, notifee, react-native

## 简介

Klyftig shared alarm engine for Expo / React Native: reliable killed-state alarms (notifee on Android, AlarmKit + notification fallback on iOS), mission-gated dismissal model, snooze/escalation, permissions & OEM guidance, per-fire + missed-alarm telemetr
