# @five0016/dsh-model-picker

> 标签: deepseek-harness, dsh, dsh-plugin, model, picker, sidebar

## 简介

Native right-sidebar tab that lists every model the host currently advertises, grouped by provider, highlights the active one, and switches the session model on click.
