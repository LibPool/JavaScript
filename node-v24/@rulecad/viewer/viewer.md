# @rulecad/viewer

> 标签: 3d-printing, 3d-viewer, 3mf, github-pages, static-site, stl

## 简介

A model page you can host anywhere: open model links, or drop an STL to see it, check it for printing and share it. Plain static files; nothing is uploaded.
