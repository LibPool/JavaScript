# dsh-plugin-emote-chat

> 标签: deepseek-harness, dsh, dsh-plugin, emoji, reaction, sticker

## 简介

Sticker and emoji reactions for the DeepSeek Harness Web/Desktop chat: a composer sticker picker, agent stickers that render as images while the transcript keeps the pack tag, emoji reactions under the user bubble, and an emoji-rain effect.
