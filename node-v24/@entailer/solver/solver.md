# @entailer/solver

> 标签: JavaScript

## 简介

Opt-in SMT escalation for Entailer. A pure SMT-LIB emitter plus a lazily-probed Z3 backend that degrades to UNKNOWN when z3-solver is absent — an amplifier, never a gate.
