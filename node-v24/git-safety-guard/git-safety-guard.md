# git-safety-guard

> 标签: agent, backup, git, hook, pi-package, safety

## 简介

Backup-then-allow guard for discarding git commands. Auto-backs up diff + untracked + stash before checkout/restore/reset --hard/clean/stash drop, then lets the command run. pi extension + PreToolUse hook CLI.
