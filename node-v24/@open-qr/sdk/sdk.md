# @open-qr/sdk

> 标签: api-client, dynamic-qr, openqr, qr, qr-code, qrcode, sdk

## 简介

Dependency-free TypeScript client for the OpenQR REST API: generate QR codes and manage dynamic (editable) codes with scan analytics.

## 官网

- 官网：https://openqr.uk/api
- 源码仓库：git+https://github.com/open-qr/openqr.git
- npm 页面：https://www.npmjs.com/package/@open-qr/sdk
