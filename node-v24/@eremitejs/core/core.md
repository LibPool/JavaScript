# @eremitejs/core

> 标签: indexeddb, local-first, offline, offline-first, optimistic-updates, outbox, state-management, sync

## 简介

Offline-first data layer for apps talking to any REST backend: persistent outbox, optimistic rebase, and first-class handling of server-assigned IDs.
