# @cxxl/dsh-terminal

> 标签: deepseek-harness, dsh-plugin, powershell, pty, terminal

## 简介

DSH Web 内置交互式终端：底部工具窗口打开真实 PowerShell（PTY），像 IDEA 一样在浏览器里敲命令。
