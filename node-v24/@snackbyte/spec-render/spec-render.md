# @snackbyte/spec-render

> 标签: cli, documentation, html, markdown, renderer, spec-kit, speckit

## 简介

Render Spec Kit Markdown artifacts to interactive HTML — sticky auto-TOC, collapsible sections, anchored headings, syntax highlighting, task timelines, spec dashboards, plan views, cross-artifact nav, and lazy Mermaid.
