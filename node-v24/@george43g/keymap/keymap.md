# @george43g/keymap

> 标签: cheatsheet, hotkeys, ink, keybindings, keymap, tui, vim

## 简介

Framework-agnostic vim-style keymaps: one logical-key notation, declarable bindings with overridable defaults and conflict diagnostics, a pure sequence/count matcher with Ink and DOM adapters, and legend/hint/cheatsheet/--keys generators. Zero runtime dep
