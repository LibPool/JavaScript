# @george43g/cli-kit

> 标签: cli, commander, mcp, repl, terminal, tty

## 简介

Commander helpers + TTY/color/output utilities + env↔flag binder + interactive REPL. Building blocks for the `example-repo-cli` bin in any tool cloned from the starter.
