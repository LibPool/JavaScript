# @infinitedusky/telemetry-binaries-darwin-x64

> 标签: JavaScript

## 简介

Jaeger + OTel Collector (k8s distribution) native binaries for darwin-x64, bundled for @infinitedusky/indusk-mcp's local-telemetry extension. Upstream Apache 2.0 redistributed with attribution.
