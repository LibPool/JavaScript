# @share-kit/svelte

> 标签: a11y, daisyui, drawer, modal, rtl, share, svelte, svelte5, tailwindcss

## 简介

A primitive, headless-friendly share component for Svelte 5 — clipboard copy, native Web Share, file download, and custom providers, with a zero-dependency built-in icon set.
