# @heiwa4126/cdk2env

> 标签: aws-cdk, bash, cdk, cli, commonjs, environment-variables, esm, export, outputs, shell, typescript

## 简介

Convert AWS CDK outputs.json to shell-sourceable export file. CLI tool and library with dual ESM/CJS support.
