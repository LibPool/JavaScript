# 2dai-mcp-server

> 标签: 2dai, agents, ai, ai-agent, claude, claude-desktop, cline, cursor, image-generation, mcp, mcp-server, modelcontextprotocol, text-to-image, video-generation, windsurf

## 简介

MCP server for 2DAI — let Claude, Cursor, Cline and Windsurf generate images and video, upload references and organise your cloud drive on your own 2DAI account.
