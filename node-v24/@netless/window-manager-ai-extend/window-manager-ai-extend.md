# @netless/window-manager-ai-extend

> 标签: JavaScript

## 简介

一个为 Netless Window Manager 提供的 AI 对话扩展插件，基于 OpenRouter API 实现，支持多模态输入、流式响应、截图功能和思维导图导出。
