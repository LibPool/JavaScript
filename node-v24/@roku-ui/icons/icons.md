# @roku-ui/icons

> 标签: JavaScript

## 简介

这是一个 React 使用的图标库。利用了 [iconify]( https://iconify.design/) 的图标数据。你可以在 [icones](https://icones.js.org/) 浏览所有可用的图标。感谢这些库的作者的收集，让图标选择变得自由。
