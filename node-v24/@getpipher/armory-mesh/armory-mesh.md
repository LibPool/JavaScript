# @getpipher/armory-mesh

> 标签: awareness, bug-bounty, comms, cross-session, fleet, mesh, peer-to-peer, pi-extension, pi-package

## 简介

Hardened peer-to-peer mesh for pi agents — live presence, work claims, cross-session duplicate checks, and a durable fleet memory for N parallel sessions. Signed + secured by default.
