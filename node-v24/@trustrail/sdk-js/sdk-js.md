# @trustrail/sdk-js

> 标签: ai-agents, authorization, governance, policy, trustrail

## 简介

Needs a TrustRail control plane: its URL and an agent credential (`tr_agent_…` or a `trb1_` bundle) from that workspace's console. Source-available under BUSL-1.1; the licence is in the package.
