# @olegas.murasko/chaos-lambda

> 标签: aws, chaos, monkey, reliability

## 简介

Chaos Lambda is a small tool for testing resiliency and recoverability of AWS-based architectures. It's a serverless implementation of Netflix Chaos Monkey.
