# @setheum.js/setters

> 标签: JavaScript

## 简介

setters.js SDK implements a web3 provider to allow existing Ethereum dApp to be able to interact with [Setheum EVM](https://github.com/Setheum-Labs/Setheum/tree/master/lib-serml/evm).
