# @emotion-machine/claw-messenger-mcp

> 标签: ai-agents, imessage, imessage-api, mcp, modelcontextprotocol, no-mac, rcs, send-imessage, sms, text-message

## 简介

MCP server that lets an AI agent send an iMessage, text a phone number, or send SMS/RCS to a contact through Claw Messenger. Two-way messaging with no Mac required: works from Linux, Docker, Windows, or any cloud.
