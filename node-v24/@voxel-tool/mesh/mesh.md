# @voxel-tool/mesh

> 标签: magicavoxel, mesh, three, vox, voxel, voxel-tool

## 简介

Shared voxel mesh construction (face culling + vertex colors + greedy meshing + instance transform), used by @voxel-tool/viewer and @voxel-tool/exporter
