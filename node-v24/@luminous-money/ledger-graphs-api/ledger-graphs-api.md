# @luminous-money/ledger-graphs-api

> 标签: accounting, beancount, budget, cash-flow, double-entry, hledger, ledger, net-worth, reports

## 简介

Reports from any double-entry ledger's postings: spending against a simulated month, cash flow, breakdowns, largest transactions, net worth, and typical periods. Plain JSON datasets, no dependencies.
