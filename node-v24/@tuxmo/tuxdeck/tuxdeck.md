# @tuxmo/tuxdeck

> 标签: JavaScript

## 简介

Slide deck navigation logic for React (and beyond). Router-agnostic utilities for building presentation apps — keyboard navigation, touch swipe, jump-to-slide search, and multi-tab presenter sync.
