# @hubro-platform/hubro-connect

> 标签: JavaScript

## 简介

Hubro Connect is a multiplatform library enabling connection to Hubro services with support for Android, iOS, and JS (Web/NodeJS) platforms. This package provides the JavaScript/TypeScript/WASM implementation for web and Node.js environments.
