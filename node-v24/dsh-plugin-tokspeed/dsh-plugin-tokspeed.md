# dsh-plugin-tokspeed

> 标签: chart, deepseek-harness, dsh-plugin, llm, telemetry, throughput, tokens-per-second

## 简介

Record per-step model decode throughput (tokens/second) in the DeepSeek Harness and chart it in the Web UI: scatter, histogram with normal fit, per-model IQR box plot, hour-of-day medians, and a stats table.
