# @marg-adk/cli

> 标签: agent-framework, agents, cli, llm, mcp, typescript

## 简介

The marg command (npm i -D @marg-adk/cli): web (the gateway and the playground), new (a domain from the templates), evals (every suite against a writes-off gateway), verdict (a typed decision from the shell), check (the project's gate).
