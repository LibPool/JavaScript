# @limccn/longstone-wallet

> 标签: aes-gcm, argon2id, base-sepolia, bip39, memory, vault, wallet

## 简介

Host-neutral wallet.v1 core for MemoryOverEth: Argon2id + AES-256-GCM vault, BIP-39/BIP-32 accounts and password policy. Key management and addresses only; no signing, no host storage, no network.
