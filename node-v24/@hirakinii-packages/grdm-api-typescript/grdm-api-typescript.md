# @hirakinii-packages/grdm-api-typescript

> 标签: api, client, gakunin-rdm, grdm, json-api, typescript

## 简介

GakuNin RDM API TypeScript client library built on top of osf-api-v2-typescript. Provides access to all 22 OSF API v2 resources plus GRDM-specific metadata endpoints for project and file metadata management.
