# @x-otto/plugin-feedback

> 标签: JavaScript

## 简介

Feedback business contract plugin (RFC-209 + RFC-430 + RFC-440) — pulse survey recording + GitHub/Coding issue submission + dual-platform feedback panel + TUI /feedback slash command, consumed by both TUI and web-ui through the FeedbackRegistry.
