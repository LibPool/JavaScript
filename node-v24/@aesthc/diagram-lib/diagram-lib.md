# @aesthc/diagram-lib

> 标签: diagram, er, flowchart, sequence, state-machine, svg, swimlane, timeline

## 简介

Reusable SVG diagram library — band, flowchart, sequence, state-machine, ER, timeline and swimlane layouts with a cohesive visual language (dot grid, hairline cards, cobalt/branch edges, glass tooltips).
