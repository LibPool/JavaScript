# @quarktex/mcp

> 标签: agents, ai-agents, claude, cursor, mcp, model-context-protocol, quarktex

## 简介

Official Model Context Protocol server for QuarkTex — exposes the full platform (agents, files, sessions, webhook helpers) to Claude Desktop, Claude Code, Cursor, Windsurf, and any other MCP-aware coding agent.
