# @ihux/appstore-connect-mcp

> 标签: app-store-connect, apple, claude, cursor, ios, mcp, model-context-protocol, testflight, xcode-cloud

## 简介

MCP server for the entire App Store Connect API (1,300+ operations) in Claude Code, Claude Desktop and Cursor, with a local settings page for your API key and access mode. By iHux.
