# dsh-local-file-share

> 标签: agent, browser-files, cordis, deepseek, deepseek-harness, dsh, dsh-plugin, file-system-access, local-file-share, local-files, plugin, remote-development, websocket

## 简介

Local File Share / 本地文件共享 — let the dsh agent list, read and write files on the machine that runs your browser, through a private WebSocket relay and the File System Access API. Zero data copied onto the dsh host.
