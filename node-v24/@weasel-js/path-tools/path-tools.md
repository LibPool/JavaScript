# @weasel-js/path-tools

> 标签: JavaScript

## 简介

Path-editing tools for a weasel canvas, as presets an app opts into: brushes, bridge, trim and extend, curvature and handle balance, path constraints, corner shape, path effects, warps, and the Girth and Shape Builder tools.
