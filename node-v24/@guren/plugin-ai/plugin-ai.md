# @guren/plugin-ai

> 标签: ai, ai-agents, ai-sdk, bun, framework, fullstack, guren, llm, typescript

## 简介

In-process AI agents for Guren applications: model calls on the Vercel AI SDK that reach the app through its own gated agent tools (RFC 0029).
