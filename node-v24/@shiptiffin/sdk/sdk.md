# @shiptiffin/sdk

> 标签: analytics, auth, background-jobs, better-auth, bun, email, kv, nextjs, queue, react-email, redis, s3, self-hosted, shiptiffin, storage, tiffin, valkey, web-vitals, workflow

## 简介

The SDK for apps on a Tiffin box: config, KV (Valkey), file storage, queues, durable workflows, sign-in, email, analytics and Next.js helpers, with nothing to set up.
