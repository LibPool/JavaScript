# scriptc

> 标签: JavaScript

## 简介

Compile ordinary TypeScript and JavaScript to small, fast native executables — no Node, no V8, no JavaScript engine in the binary

## 官网

- 官网：https://scriptc.dev
- 源码仓库：git+https://github.com/vercel-labs/scriptc.git
- npm 页面：https://www.npmjs.com/package/scriptc
