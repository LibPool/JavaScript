# @burdenoff/cli-sdk

> 标签: burdenoff, cli, cli-sdk, commander, graphql, modular

## 简介

Modular CLI SDK shared across all Burdenoff product CLIs (vibecontrols, botlit, fluidgrids, bigconsole, healthybowl, devportal, workspaces). Each module exports CliModule contract; product CLIs become thin shells that pick which modules to mount.
