# @krdn/llm-gateway

> 标签: ai, claude, deepseek, gateway, gemini, json-repair, llm, multi-provider, ollama, openai, structured-output, vercel-ai-sdk

## 简介

Multi-provider LLM gateway — unified interface for Anthropic, OpenAI, Gemini, DeepSeek, Ollama, and more. Structured output with JSON repair, retry with backoff, token normalization.
