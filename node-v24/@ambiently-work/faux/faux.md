# @ambiently-work/faux

> 标签: agent, bash, posix, sandbox, shell, virtual-filesystem, wasm

## 简介

POSIX-ish shell that runs entirely in-process — no child_process, no subshell. Virtual FS, builtins, and an optional WASM-accelerated runtime.
