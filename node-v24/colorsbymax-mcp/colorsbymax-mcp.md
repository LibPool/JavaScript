# colorsbymax-mcp

> 标签: ai-agents, colors, colorsbymax, contrast, mcp, model-context-protocol, palette, theme, wcag

## 简介

MCP server for colorsbymax: lets AI agents set up the theme switcher, find and build themes, check contrast and finish a site's colours.
