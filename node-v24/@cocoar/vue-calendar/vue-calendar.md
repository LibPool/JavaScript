# @cocoar/vue-calendar

> 标签: agenda, calendar, events, recurrence, rrule, scheduler, temporal, virtualization, vue, vue3

## 简介

Vue 3 calendar component — Temporal-only public surface, single drop pipeline, per-endpoint source-zone preservation, explicit DST policy. Built on the principles laid out in the Time in Software, Done Right article series.
