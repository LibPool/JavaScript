# meetwave-stream

> 标签: meetwave, real-time, speaker-diarization, speech-to-text, streaming, transcription, websocket

## 简介

MeetWave streaming client: live English text over WebSocket, the full transcript at stop. No runtime dependencies; Node 22+ and browsers.

## 官网

- 官网：https://developers.meetwave.io/docs/streaming-sdk
- npm 页面：https://www.npmjs.com/package/meetwave-stream
