# @jackdbd/fastify-userinfo-endpoint

> 标签: IndieAuth, OAuth 2.0, fastify, plugin

## 简介

Fastify plugin that adds a [IndieAuth Userinfo Endpoint](https://indieauth.spec.indieweb.org/#user-information) to a Fastify server.
