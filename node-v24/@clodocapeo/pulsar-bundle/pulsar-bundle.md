# @clodocapeo/pulsar-bundle

> 标签: JavaScript

## 简介

Bundles pulsar.exe + DLLs and exposes a Node spawn() API. Pairs with @clodocapeo/pulsar-client. For HTML overlays / browser sources, use @clodocapeo/pulsar-bundle-full instead.
