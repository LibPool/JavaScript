# @wynexlabs/strata-mcp

> 标签: JavaScript

## 简介

MCP (Model Context Protocol) server exposing Strata's numerical finance compute endpoints (bond pricing, BSM + American options, portfolio VaR) as stdio tools for Claude Desktop / Cursor / other MCP clients.
