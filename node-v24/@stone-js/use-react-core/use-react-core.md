# @stone-js/use-react-core

> 标签: React, Stone.js, agnostic, core, layouts, pages, rendering, view

## 简介

The platform-independent half of Stone.js's React integration: page and layout contracts, decorators, hooks, context and the render orchestration shared by the web and native renderers.
