# @act-spec/plugin-nuxt

> 标签: JavaScript

## 简介

PRD-407 Nuxt module for the ACT (Agent Content Tree) v0.1 reference implementation. Wraps the PRD-400 generator pipeline against Nuxt 3+ static export (`nuxt generate`).
