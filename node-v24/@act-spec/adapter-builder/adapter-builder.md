# @act-spec/adapter-builder

> 标签: JavaScript

## 简介

PRD-206 Builder.io adapter for the ACT (Agent Content Tree) v0.1 reference implementation. Consumes the Builder.io Content API and emits PRD-100/PRD-102 envelopes; supports two emission modes (pass-through emits a single `marketing:builder-page` block car
