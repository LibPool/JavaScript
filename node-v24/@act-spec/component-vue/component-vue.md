# @act-spec/component-vue

> 标签: JavaScript

## 简介

PRD-302 Vue 3 binding for the ACT (Agent Content Tree) v0.1 component contract (PRD-300). Implements the Vue declaration patterns (SFC default-export static field `Component.act = {…}`, `useActContract` composable, `<script setup>` `defineActContract` mac
