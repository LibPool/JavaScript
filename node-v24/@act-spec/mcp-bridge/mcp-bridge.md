# @act-spec/mcp-bridge

> 标签: JavaScript

## 简介

PRD-602 ACT-MCP bridge for the ACT (Agent Content Tree) v0.1 reference implementation. Wraps a PRD-500 ActRuntime (or a multi-mount BridgeConfig.mounts array per amendment A4) and exposes ACT nodes as MCP 1.0 resources under the canonical act:// URI schem
