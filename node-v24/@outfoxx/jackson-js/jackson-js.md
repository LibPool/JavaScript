# @outfoxx/jackson-js

> 标签: jackson, jackson-javascript, jackson-js, jackson-json, json, json-decoder, json-deserialization, json-encoder, json-parse, json-parser, json-serialization, json-stringifier, json-stringify

## 简介

JavaScript object serialization and deserialization library using decorators. It supports also advanced Object concepts such as polymorphism, Object identity and cyclic objects.
