# @open-wysiwyg-editor/solid

> 标签: a11y, accessibility, arabic, editor, rich-text-editor, rtl, solid, solid-start, solidjs, wysiwyg

## 简介

SolidJS directive for open-wysiwyg-editor: <div use:richText>. Accessible (WCAG 2.2 AA), RTL-first, CSP-safe.
