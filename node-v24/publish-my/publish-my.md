# publish-my

> 标签: ai-agent, claude, cursor, deploy, mcp, model-context-protocol, publish, static-hosting, website

## 简介

MCP server for publish.my: publish a folder as a live website from Claude Code, Cursor, Codex, VS Code or any MCP client. Free, no account needed to start.
