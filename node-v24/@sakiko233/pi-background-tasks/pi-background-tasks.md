# @sakiko233/pi-background-tasks

> 标签: background-tasks, eventbus, pi, pi-dev, pi-extension, pi-package, process-lifecycle, shell, task-manager

## 简介

Pi extension for durable background shell task lifecycle, foreground handoff, bounded logs, completion notifications, and a shared external-task EventBus service.
