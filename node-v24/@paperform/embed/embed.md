# @paperform/embed

> 标签: JavaScript

## 简介

Zero-dependency embed library for published Paperform forms: inline/popup/drawer/popover factories, a <paperform-embed> custom element with data-attribute auto-init, shadow-DOM chrome, origin+id-filtered iframe messaging, and the single-file embed.js drop
