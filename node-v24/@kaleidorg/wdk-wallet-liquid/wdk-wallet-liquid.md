# @kaleidorg/wdk-wallet-liquid

> 标签: bitcoin, elements, kaleidoswap, liquid, lwk, wallet, wdk

## 简介

WDK wallet adapter for the Liquid network — wraps an in-process LWK (Liquid Wallet Kit) wallet in the WDK account model.
