# @skaldapp/fsa

> 标签: browser-filesystem, directory-handle, file-download, file-handle, file-handling, file-operations, file-system-access, file-upload, fsa-api, local-file-system, s3-like-api, typescript, web-api, web-platform, web-storage

## 简介

A TypeScript library providing a File System Access API wrapper for web applications. Offers AWS S3-like operations (get, put, delete, head) to interact with local file systems efficiently in modern browsers.
