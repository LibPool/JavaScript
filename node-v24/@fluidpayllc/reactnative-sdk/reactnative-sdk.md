# @fluidpayllc/reactnative-sdk

> 标签: android, bluetooth, card-reader, contactless, customer-vault, emv, fluidpay, idtech, ios, msr, payment-gateway, payments, react-native, tokenization, usb, vp3350

## 简介

Fluidpay SDK for React Native: process payments and manage the Customer Vault through the Fluidpay gateway, and take card-present EMV / contactless / magstripe payments with ID TECH VP3350 mobile readers on iOS and Android.
