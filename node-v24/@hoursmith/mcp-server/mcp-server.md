# @hoursmith/mcp-server

> 标签: claude, hoursmith, invoicing, llm-tools, mcp, model-context-protocol, time-tracking

## 简介

Model Context Protocol server for Hoursmith. Chat with your time-tracking + invoicing workspace from Claude Desktop, Cursor, Zed, Odin, or any MCP-aware LLM client.
