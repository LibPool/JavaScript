# steal-this-stack

> 标签: ai-agents, cli, css-extractor, design-system, mcp, playwright, reverse-engineering, tailwind, ui-cloner

## 简介

Reverse-engineer any live website's exact computed CSS variables, typography, animations, SVGs, and interactive UI components into a ready-to-code Tailwind starter or feed directly to AI coding agents via MCP.
