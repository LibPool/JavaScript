# @liangzx-command/deploy

> 标签: JavaScript

## 简介

cscs deploy 部署本地打包 > 优点： > - 避免jenkins或其他进程等待占用时间 > - 避免重复无效的yarn之后再进打包时间，直接终端一键处理 > - 第三方部署工具不稳定情况. (Node版本不一致，锁文件没上传等) > - 打包客户环境时，可顺便部署到公司环境
