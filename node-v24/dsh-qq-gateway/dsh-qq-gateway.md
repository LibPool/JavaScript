# dsh-qq-gateway

> 标签: deepseek-harness, dsh, dsh-plugin, messaging, napcat, onebot, onebot11, qq, qqbot

## 简介

QQ 消息网关：NapCat / OneBot 11 收 QQ 消息投给 DSH 会话，助手回复自动回传 QQ；附带 qq_* 模型工具、主号管理指令、拟人延迟与禁回。
