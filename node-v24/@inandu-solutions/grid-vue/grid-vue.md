# @inandu-solutions/grid-vue

> 标签: composable, csv-export, data-grid, data-table, datagrid, excel-export, grid, grouping, headless, i18n, inline-editing, pagination, table, virtual-scroll, vue, vue-component, vue-datagrid, vue-grid, vue-table, vue3

## 简介

Standalone Vue 3 data grid: sorting, free-text and per-column filtering, grouping, pagination, CSV/Excel (.xls)/PDF export and print, i18n (5 languages) and theming, with a deliberately small dependency footprint. The Vue port of @inandu-solutions/grid-an
