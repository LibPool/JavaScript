# @autolabz/ftc-cli

> 标签: JavaScript

## 简介

FTC CLI 是一个用于管理和调用 FTC (Fast Tool Call) 资源的命令行工具。它允许你通过设备流 (Device Flow) 进行身份验证，管理全局 FTC 资源，并列出或调用可用的工具。
