## 简介

Prompt-injection scanner for AI agents: deterministic, documented rules (instruction override, jailbreaks, exfiltration URLs, tool hijack/MCP tool poisoning, hidden Unicode, encoded payloads) returning a risk score, categories and spans. Library + x402 pa
