# xentral-mcp

> 标签: ai-agent, claude, dach, erp, mcp, model-context-protocol, xentral

## 简介

Model Context Protocol server for the Xentral ERP API. Runs locally over stdio on any platform, with no cloud dependency. Read-only by default, opt-in writes.
