# x_ele_plus

> 标签: JavaScript

## 简介

`x_ele_plus` 是一个基于 Vue 3、Element Plus 和 Vite 的后台业务组件库。它在 Element Plus 基础上封装了列表、筛选、弹框、选择器、上传、导入导出等常见能力，并提供统一的请求和工具方法，适合在多个管理后台项目中复用。
