# xmcomp

> 标签: JavaScript

## 简介

一个 **Vue3** 组件库开发环境框架,采用最新的 `Vite4+TypeScript` 为技术栈,支持`按需加载`,`单元测试`,`自动打包与发布`等功能,专注于业务组件的开发。
