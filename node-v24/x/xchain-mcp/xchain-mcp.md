# xchain-mcp

> 标签: bitcoin, dogecoin, litecoin, mcp, modelcontextprotocol, xchain

## 简介

Model Context Protocol (MCP) stdio server for the XChain Platform: read chain/token/balance data on BTC, LTC and DOGE (mainnet/testnet/regtest), and optionally submit policy-gated actions, backed by the XChain SDK.
