# xuke-components

> 标签: JavaScript

## 简介

## 说明 该组件库用于旭课宝pc端微官网模块的画布预览列表及H5页面的渲染，不同于编辑画布拖拽的组件，去除了属性修改等操作，仅用于展示组件，以便于服务端渲染H5页面时代码更轻量，减少无用代码
