# xaxi

> 标签: axios, npm, post, react, react hooks, request, swr, typescript

## 简介

Xaxi is a hook library like Vercel's SWR but purpose-built for Data Mutation. It also aims to introduce a more organized approach to interacting with APIs when building scalable web apps.
