# xlsx-style-fix

> 标签: excel, ods, office, spreadsheet, xls, xlsb, xlsm, xlsx

## 简介

Excel (XLSB/XLSX/XLSM/XLS/XML) and ODS spreadsheet parser and writer (extended to enable read/write of cell formats with xlsx files)
