# x402-arc

> 标签: 402, agent-payments, arc, circle, eip-3009, usdc, x402

## 简介

Accept x402 payments on Circle's Arc L1 (chain 5042) via client-broadcast EIP-3009 — no facilitator required, because gas is USDC.
