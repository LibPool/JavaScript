# xlogs-scanner

> 标签: ai-generated-code, appsec, bolt, cursor, dast, lovable, replit, rls, sarif, scanner, secrets, security, supabase, v0, vibe-coding

## 简介

Free, read-only security scanner for AI-built web apps. Point it at a deployed URL: finds publicly readable databases, secret keys shipped to the browser, missing protections, and hands you a fix you can paste into your AI coding tool.
