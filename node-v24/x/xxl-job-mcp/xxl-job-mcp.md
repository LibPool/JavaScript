# xxl-job-mcp

> 标签: cursor, mcp, modelcontextprotocol, scheduler, xxl-job, xxljob

## 简介

MCP server for XXL-Job admin. Run `npx xxl-job-mcp init` to print an mcp.json snippet with XXL_JOB_BASE_URL, XXL_JOB_USERNAME, XXL_JOB_PASSWORD.
