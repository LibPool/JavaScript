# xmrto-lib

> 标签: Bitcoin, Monero, cryptocurrency, exchange, xmr.to

## 简介

XMR.to is a cryptocurrency exchange that offers a service allowing users to exchange Monero for Bitcoin. This module allows one to implement a basic XMR.to order creation workflow.
