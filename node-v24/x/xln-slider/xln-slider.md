# xln-slider

> 标签: JavaScript

## 简介

在项目中 import Slider from 'xln-slider' 引用<Slider/> 必选属性 img属性指定要加载的轮播图url数组 可选属性 auto 是否自动播放，布尔值，默认为true delay 图片间隔时间，数字类型，默认为3 speed 图片滑动时间，数字类型，默认为1 pause 鼠标移入移出时是否停止开始轮播，布尔类型，默认true arrow 是否有左右箭头，布尔值，默认有 dots 是否有分页标识，布尔值，默认有
