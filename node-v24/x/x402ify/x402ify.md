# x402ify

> 标签: agentic, api, base, hedera, micropayments, pay-per-use, payments, solana, x402

## 简介

Wrap any API with x402 pay-per-call. One command, no code, no key on the server. Chain-agnostic: settle on Hedera, Base, or Solana.
