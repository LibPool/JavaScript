# xgplayer-ads

> 标签: JavaScript

## 简介

The `Ads` plugin mainly used to provide users with the ability to quickly integrate advertizement. The plugin integrates SDKs such as `Google IMA` and `Google DAI`<sup>(to be developed)</sup>, and provides ad integration capability that comply with VAST,
