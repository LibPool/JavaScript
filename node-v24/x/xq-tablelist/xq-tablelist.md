# xq-tablelist

> 标签: BootStrap5, DragTable, HTML5, JavaScript, Table, TableList, TypeScript

## 简介

基于Bootstrap5的表格列表，包括管理列表页面、添加页面、编辑页面，同时包括后台管理员管理的页面。
