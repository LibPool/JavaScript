# xue_directory

> 标签: JavaScript

## 简介

"name": "xue_directory",   "main": "index.js",   "methods":   removeDir(参数为一个目标路径）实现删除目标目录下的所有文件及文件夹   copyDir(参数为一个目标路径和一个输出路径）需实现拷贝目标目录的所有文件结构   flatDir(参数为一个目标路径和一个输出路径）需要实现目标目录的扁平化展示
