# x402-video-mcp

> 标签: agent-payments, ai-video, base, http-402, mcp, micropayments, model-context-protocol, seedance, text-to-video, usdc, video-generation, x402

## 简介

MCP server for x402video.com — pay-per-call AI video generation over the x402 protocol (USDC on Base). Quote, pay, generate, poll — no accounts, no API keys.
