# xh-eplus-ui

> 标签: JavaScript

## 简介

> 由于中台采用的是微前端开发模式，导致大部分子应用都会用到的公共组件，如：分页、表格、弹窗、项目选择器等，大家都会在写一遍，不便于管理，所以才有了这个基于`element-plus`二次封装的组件库，通过将公共组件在这里进行编写，发布到`npm`上进行统一的管理。
