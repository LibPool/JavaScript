# xxtea_ts

> 标签: decrypt, encrypt, xxtea

## 简介

工具：提供了与 Cocos Creator 相同的加密、压缩的方法。可以很方便地将 js 压缩、加密回 jsc，针对 Uint8Array 类型数据进行加密的。
