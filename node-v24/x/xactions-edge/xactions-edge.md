# xactions-edge

> 标签: agent, ai, api, bun, claude, cloudflare, cursor, deno, edge, mcp, model-context-protocol, no-api-key, scraper, twitter, workers, x

## 简介

Public X/Twitter reads from any JavaScript runtime. No API key, no account, no install. Talks to the hosted XActions MCP server.
