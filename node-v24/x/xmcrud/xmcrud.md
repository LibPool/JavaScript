# xmcrud

> 标签: api, auto-crud, controller, crud, crud-generator, express, express helper, express-api, express-crud, express-crud-generator, express-helper, express-router, express-smart-helper, middleware, mongodb-crud, mongoose-crud, redis, rest, rest-api-generator, rest-crud, router, typescript, xmcrud

## 简介

A lightweight helper library for building Express.js routes, controllers, advanced query with mongoose, and Redis-enhanced middleware with optional Redis support.
