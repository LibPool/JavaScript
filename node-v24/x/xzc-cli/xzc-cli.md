# xzc-cli

> 标签: JavaScript

## 简介

* commander：命令行指令配置，来实现脚手架命令的配置； * chalk：命令行美化工具，安装 chalk 时一定要注意安装 4.x 版本，否则会因为版本过高报错； * inquirer：命令行交互工具； * ora：命令行 loading 效果； * fs-extra：更友好的文件操作，fs-extra 模块是系统 fs 模块的扩展，提供了更多便利的 API，并继承了 fs 模块的 API。比 fs 使用起来更加友好； * figlet：生成基于 ASCII 的艺术字，可将text文本转化成生成
