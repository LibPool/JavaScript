# xats-setup

> 标签: cross-agent-teams, cross-platform, installer, xats

## 简介

One-command, OS-agnostic installer for the xats cross-agent bus (daemon + service + Claude Code/Pi/OpenCode integration + bridge). Windows, macOS, Linux.
