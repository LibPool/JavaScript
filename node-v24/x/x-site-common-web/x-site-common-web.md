# x-site-common-web

> 标签: JavaScript

## 简介

###项目描述 >落地页——嵌入到各个业务线的建站入口和展示页面，此项目只是生成每个建站页面的js和css，     各业务线如果想展示建站落地页，调用js和css渲染到相应的dom上就可以了。
