# xm-minx-print-design

> 标签: element-plus, lodop, vue3, 打印设计

## 简介

一个基于Vue3、ElementPlus2.11+、Lodop的打印模板设计器。实现打印模板的设计、预览和打印功能。基于kr-print-designer改造而来。
