# xmlunidefuse

> 标签: CDATA, CLI, HTML, XML, apos, cdata, cli, defuse, encode, entities, entity, html, htmlspecialchars, unicode, univeil, xml, xmlencode, xmlentities

## 简介

Encode the predefined XML entities (amp, lt, gt, apos, quot) and some additional, easily overlooked Unicode characters. Opt-out CharRef 39 for HTML.
