# xferlang

> 标签: configuration, data-format, json, parser, serialization, xfer, xferlang

## 简介

XferLang 1.0 for JavaScript and TypeScript: a data format with no escape sequences, typed values and line-independent syntax. Parser, canonical writer, JSON mapping and command line tool.
