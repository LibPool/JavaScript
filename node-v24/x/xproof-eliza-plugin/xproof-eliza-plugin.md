# xproof-eliza-plugin

> 标签: agent-audit, agents, audit, audit-log, autonomous-agent, blockchain, certification, compliance, elizaos, elizaos-plugins, multiversx, mx-8004, proof, proof-of-existence, trust, trust-primitive

## 简介

Compliance layer for autonomous agents. Audit guard blocks critical actions without on-chain proof. Certify outputs on MultiversX via xProof. 6-second finality.
