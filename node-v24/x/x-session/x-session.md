# x-session

> 标签: XCache, XCustomEventEmitter, XDom, XSession, svelte, sveltekit, x-auth, x-session, x-session-client, x-session-cookie, x-session-data, x-session-id, x-session-ip, x-session-key, x-session-token, xcache, xdom, xsession

## 简介

XSession(x-session), XCache(xcache), XDom(xdom), and XCustomEventEmitter for browsers and Node.js modules.
It was planned to support SvelteKit SSR(Server Side Rendering) and CSR(Client Side Rendering) to communicate with x-session API Server.
