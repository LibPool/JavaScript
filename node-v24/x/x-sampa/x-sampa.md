# x-sampa

> 标签: JavaScript

## 简介

Transforms strings from [X-Sampa](https://en.wikipedia.org/wiki/X-SAMPA) to [IPA (international phonetic alphabet)](https://en.wikipedia.org/wiki/International_Phonetic_Alphabet).
