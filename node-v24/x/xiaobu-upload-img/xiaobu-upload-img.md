# xiaobu-upload-img

> 标签: JavaScript

## 简介

基于element-ui的 `el-upload` 图片上传组件开发出来的实用图片上传组件。 支持图片裁剪、压缩、预览、下载、最大上传图片数量控制、不可编辑配置等功能。
