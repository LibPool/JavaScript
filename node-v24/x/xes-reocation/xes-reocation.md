# xes-reocation

> 标签: JavaScript

## 简介

这是一个可以实现撤销功能的一个栈，有三个方法，用import {Stack, StackArr} from 'xes-reocation'来引用，Stack是操作一个栈，Stack是多栈多场景的操作，Stack中有三个方法，add添加，调用undo方法返回值是你需要撤回的数据，调用redo方法返回值是你需要反撤销的数据
