# xaip-openai

> 标签: ai-agent, function-calling, openai, reputation, telemetry, tool-calling, trust, xaip

## 简介

XAIP wrapper for OpenAI tool calling — emits signed XAIP receipts for every tool execution. Provider-agnostic trust layer, zero deps.
