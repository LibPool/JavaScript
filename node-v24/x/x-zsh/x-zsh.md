# x-zsh

> 标签: animation, asciinema-alternative, cli, console, custom-element, powerlevel10k, progress-bar, shadow-dom, shell, spinner, terminal, tutorial, walkthrough, web-component, zsh

## 简介

Drop-in animated terminal walkthroughs as a custom element. Write a session in plain text; it renders an animated p10k-style zsh, isolated in Shadow DOM. Zero config, no build, not an emulator.
