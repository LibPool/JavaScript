# xeroemoji

> 标签: emoji, emoji-font, svg, unicode, xeroemoji

## 简介

Xero Emoji lookup: 3,963 Unicode Emoji 18.0 emoji -> SVG/PNG URLs (jsDelivr), names, groups, skin tones, plus the browser replacer.
