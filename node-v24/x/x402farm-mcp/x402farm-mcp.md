# x402farm-mcp

> 标签: ai-agents, crypto, defi, honeypot, kyb, mcp, model-context-protocol, residential-proxy, rug-pull, token-security, web-scraping, x402

## 简介

MCP server exposing x402-farm's pay-per-call tools to AI agents: crypto honeypot/rug checks, residential-IP web scraping, DeFi & market data, and global company data. Pays per call in USDC on Base via x402.
