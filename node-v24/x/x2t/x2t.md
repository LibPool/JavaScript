# x2t

> 标签: excel, excel to table, excel2table, excelToTable, table, x2t, xls, xlsx, xlsx to table, xlsx2table, xlsxToTable

## 简介

`x2t` 是用于将 `.xlsx` 和 `.xls` 文件转换为 `HTML Table` 的一个工具

## 官网

- 官网：https://github.com/zlh-GitHub/xlsx2table
- npm 页面：https://www.npmjs.com/package/x2t
