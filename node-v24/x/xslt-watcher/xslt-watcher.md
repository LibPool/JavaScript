# xslt-watcher

> 标签: JavaScript

## 简介

Xslt watcher is a realtime xslt parser. When you change your xslt you can see the output direct in your browser. Provide a xml fle and a xslt file.  Open a browser and see your parsed xslt file in you browser. Example `xsltwatcher -a demo.xml -b demo.x
