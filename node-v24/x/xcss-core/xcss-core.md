# xcss-core

> 标签: css, design, framework, frontend, semantic, styles, xcss

## 简介

A powerful CSS kernel for building customized, scalable, and high-performance frontend frameworks. Seamlessly blend the raw potential of CSS with the ease of pre-made utilities, managed by a core orchestrator that optimizes HTML and JavaScript performance
