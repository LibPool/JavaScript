# xd-server

> 标签: JavaScript

## 简介

> XD-Server - это сервер приложений, созданный для хранения и управления данными. Он предназначен для использования в качестве backend для приложений как на стороне клиента, так и на стороне сервера. Основной язык программирования, используемый в XD-Serve
