# @yoos/create-app

> 标签: JavaScript

## 简介

`@yoos/create-app` 是一款轻量、灵活的工程初始化工具，旨在帮助开发者快速创建标准化的工程模板、组件模板及业务模块，减少重复配置工作，提升项目初始化效率。支持自定义模板扩展，适配多技术栈（如 React、Vue、TypeScript 等），满足不同场景下的快速启动需求。
