# @equationalapplications/schema-software-org

> 标签: ai-memory, codemeta, knowledge-graph, llm-memory, ontology, software-organization, typescript

## 简介

Custom minimal ontology manifest for an executive agent operating on behalf of a software organization: 17 node types, 40 edges, warm-agent superset. Data-only.
