# @voxfold/lang-jsx

> 标签: adapter, copywriting, jsx, react, style-linter, tsx, voxfold

## 简介

JSX/TSX adapter for Voxfold: walks @babel/parser, replicates React's own whitespace algorithm, flattens prose.
