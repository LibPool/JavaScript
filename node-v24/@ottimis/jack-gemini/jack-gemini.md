# @ottimis/jack-gemini

> 标签: JavaScript

## 简介

Gemini provider for Jack — speaks ACP (Agent Client Protocol) over stdio JSON-RPC. Implements the @ottimis/jack-provider-sdk contract; consumed by the Jack host or any other tool that drives the SDK.
