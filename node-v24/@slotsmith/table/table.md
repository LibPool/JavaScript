# @slotsmith/table

> 标签: accessible, data-table, headless, react, rtl, slots, table, tanstack, unstyled

## 简介

A headless, fully type-safe React data table built on @tanstack/react-table v9, with swappable UI slots and plain-HTML fallbacks.
