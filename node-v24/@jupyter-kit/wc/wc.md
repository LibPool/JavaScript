# @jupyter-kit/wc

> 标签: custom-elements, ipynb, jupyter, jupyter-kit, notebook, renderer, web-components

## 简介

Web Component wrapper for @jupyter-kit/core. Defines <jk-notebook> as a CustomElement, usable from any framework or plain HTML.
