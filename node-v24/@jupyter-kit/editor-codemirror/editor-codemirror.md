# @jupyter-kit/editor-codemirror

> 标签: code-editor, codemirror, editor, ipynb, jupyter, jupyter-kit, notebook, renderer

## 简介

CodeMirror 6 based inline editor plugin for @jupyter-kit/core. Lazy-loadable — not pulled in when read-only.
