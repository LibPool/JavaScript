# @yaseen-oakrev/easy-agent

> 标签: JavaScript

## 简介

A TypeScript SDK for quickly building AI agents with LLM capabilities. This project makes it easy to create, chain, and run specialized AI agents powered by models from OpenAI, Anthropic, and more.
