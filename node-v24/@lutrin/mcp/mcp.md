# @lutrin/mcp

> 标签: deck, lutrin, mcp, model-context-protocol, pptx, presentation, slides

## 简介

Model Context Protocol server for Lutrin: exposes the Markdown → PowerPoint / HTML presentation compiler as validate/build/suggest tools. Launched by the Lutrin Agent Plugin via npx.
