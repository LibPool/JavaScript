# @tjieco/library

> 标签: ITF, barcode, code-128, generator, i2of5, qr-code, reader, scanner, typescript, zxing, zxing-typescript

## 简介

TypeScript port of ZXing multi-format 1D/2D barcode image processing library, with Code128 and ITF support.
