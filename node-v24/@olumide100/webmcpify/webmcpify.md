# @olumide100/webmcpify

> 标签: agentic, ai-agents, browser-automation, hackathon, mcp, model-context-protocol, webmcp

## 简介

A CLI that audits and generates WebMCP tool registrations for a website, verified by an isolated agent driving a real browser, with human approval required before any tool goes live
