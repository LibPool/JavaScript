# enrichr-cli

> 标签: cli, color-palette, css-variables, design-tokens, font-finder, fonts, mcp, reverse-engineering, tailwind, website-analysis

## 简介

Read the design of any website from your terminal: fonts, colors, type scale, spacing and CSS variables, measured in your own browser. Optional deep analysis through Enrichr.
