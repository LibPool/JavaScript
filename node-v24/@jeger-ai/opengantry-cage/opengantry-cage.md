# @jeger-ai/opengantry-cage

> 标签: ai-agents, cage, gantry, git-hooks, guardrail, opengantry

## 简介

Zero-config cage for AI coding agents: run any command and restore CI configs, .env secrets, git hooks/config and protected paths while it runs. Slim standalone build of `gantry cage` from @jeger-ai/opengantry.
