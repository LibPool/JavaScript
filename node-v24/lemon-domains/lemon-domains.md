# lemon-domains

> 标签: ai-agents, cli, dns, domain-availability, domain-management, domain-monitoring, domain-portfolio, domains, mcp, rdap, registrar, whois

## 简介

The Lemon Domains command line: every domain you own across your registrars, plus reports, availability and transfer checks on any domain. The same operations as the Lemon Domains REST API and MCP server.
