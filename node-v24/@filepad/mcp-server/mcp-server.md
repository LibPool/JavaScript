# @filepad/mcp-server

> 标签: agent, ai, claude, cursor, filepad, mcp, model-context-protocol

## 简介

MCP server for Filepad Agent Access. Exposes Filepad workspaces as tools to Claude Desktop, Cursor, and other MCP clients.
