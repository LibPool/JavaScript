# @bpmiq/validator

> 标签: bpm, bpmn, cli, validator

## 简介

Platform-owned validator for BPM content repos — bpmiq.yml discovery + BPMN structure and BPMNDI coverage. Runs against any checkout via --root; never executes content-repo code.

- 源码仓库：git+https://github.com/Miragon/bpm-iq.git
