# @dowel-ui/mcp

> 标签: agent, ai, claude, components, cursor, design-system, dowel, mcp, model-context-protocol, react, registry, ui

## 简介

Model Context Protocol server for Dowel. Lets a coding agent search the component registry, read a component's source and conventions, and get the exact install command — instead of guessing what exists.
