# @pavelungr/seznam-webmaster-mcp

> 标签: claude, indexation, llm, mcp, model-context-protocol, seo, seznam, webmaster

## 简介

MCP server for Seznam Webmaster API — manage indexation status, documents, history, and reindex requests across multiple sites from a single place.
