# webforai-cli

> 标签: agent-skill, ai, cli, crawler, html-to-markdown, llm, llms-txt, markdown, scraper

## 简介

The webforai CLI: convert web pages and local HTML to clean, LLM-ready Markdown from the shell or an AI agent (npx webforai-cli <url>).
