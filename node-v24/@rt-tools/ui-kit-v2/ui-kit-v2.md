# @rt-tools/ui-kit-v2

> 标签: JavaScript

## 简介

Набор компонентов Angular и дизайн-система к ним: шкалы оформления, светлая и тёмная темы. Компоненты сигнальные и `OnPush`, разметка размечена BEM-директивами из `@rt-tools/core`, каждый интерактивный элемент несёт `qa-dataid`.
