# @labtoolsstudio/fetchmcp

> 标签: claude, cursor, fetch, markdown, mcp, modelcontextprotocol, readability, scraping

## 简介

Drop-in replacement for the official fetch MCP: clean, LLM-ready Markdown from any URL. No 5k truncation, JS rendering when needed, zero config.
