# @lolly-tools/core

> 标签: capability-bridge, content-generation, lolly, lolly-tools, tool-sdk

## 简介

The Lolly tool-author contract: HostV1 capability-bridge types, the tool.json manifest schema + validator, an in-memory mock host for testing, and typed authoring helpers. Depend on this to build a Lolly tool without the platform monorepo.
