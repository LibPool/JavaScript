# @oxvoinsights/agent

> 标签: agent, ai, ai-agent, analytics, cli, instrumentation, oxvo, oxvo-insights, oxvo-insights-agent, product-analytics, setup, web-analytics

## 简介

OXVO Insights Agent: add OXVO Insights product analytics to your web app with one command. Sign in to OXVO Console, register your site, and the Agent uses AI to install the SDK, instrument key events and audit your analytics.
