# @braidlabs/gateway

> 标签: composition, fragments, gateway, micro-frontends, middleware

## 简介

Braid gateway — fetch-native origin-front middleware that routes fragment traffic by exact id under the reserved /__braid/frag/ namespace, loads fragment manifests, and passes everything else through to your existing app.
