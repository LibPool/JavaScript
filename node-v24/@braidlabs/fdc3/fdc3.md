# @braidlabs/fdc3

> 标签: braid, desktop-agent, fdc3, finos, interop, micro-frontends

## 简介

An FDC3 2.2 Desktop Agent for Braid pages: every composed fragment gets a window.fdc3 bound to its own app identity, with user channels, app channels and intents across fragments, resolved against an FDC3 App Directory. Built on the FINOS reference implem
