# @braidlabs/core

> 标签: composition, fragments, micro-frontends, version-skew, web-fragments

## 简介

Braid client runtime — compose independently deployed frontend apps into one page. This build ships the compat adapter (the contained web-fragments-style emulation layer) as the default adapter.
