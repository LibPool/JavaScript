# @dever-labs/ngx-mfe-broker

> 标签: angular, broadcast-channel, cross-tab, localStorage, mfe, micro-frontends, native-federation, signals, state-management

## 简介

Angular Signals + BroadcastChannel state broker for micro-frontends. Synchronises state across MFEs and browser tabs via localStorage persistence and BroadcastChannel cross-tab sync.
