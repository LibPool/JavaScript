# @priyankasakat/shared-ui-library

> 标签: component-library, design-system, micro-frontend, react, shared-ui, typescript

## 简介

A centralized React + TypeScript shared library designed for Micro Frontend (MFE) architecture. This library will be consumed by the Host application and all Remote applications as a reusable NPM package.
