# @notiflyio/sdk

> 标签: email, in-app, inbox, notifications, notifly, push, sdk, sms

## 简介

Official Node.js / TypeScript client SDK for the Notifly notification API. Same client as @notiflyio/api, published under the @notiflyio/sdk name.
