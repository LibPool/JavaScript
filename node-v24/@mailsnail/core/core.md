# @mailsnail/core

> 标签: certified-mail, click2mail, direct-mail, failover, letters, lob, mailsnail, physical-mail, postcards, provider-agnostic, snail-mail, usps

## 简介

Provider-agnostic core for sending physical mail: one interface, swappable adapters (Click2Mail, Lob, any Mailsnail gateway), multi-provider failover. Zero dependencies.
