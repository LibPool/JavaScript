# @roybakker/index-fast

> 标签: bing, crawl, google, google-indexing-api, indexing, indexnow, search-console, seo, sitemap, url-inspection

## 简介

Reports which of your pages Google has indexed, then asks the search engines to crawl the ones it hasn't.
