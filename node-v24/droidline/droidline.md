# droidline

> 标签: accessibility, adb, android, android-automation, appium, device-farm, droidline, mcp, mobile-automation, rpa, test-automation, testing, typescript, ui-automation, uiautomator

## 简介

Android automation from Node.js: test your apps on real phones, script the tasks you repeat and run many phones at once. No ADB, no USB cable, no root.
