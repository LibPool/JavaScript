# @marketnow/uta-conformance

> 标签: a2a, agent, agent-trust-card, conformance, ed25519, mcp, security, test-vectors, trust, verification

## 简介

UTA conformance suite for agent-trust runners — 14 signed test vectors (v1.3.3) + reference scorer + card generator. Separates real verifiers from memorizers, stage-liars and over-rejectors. Zero deps.
