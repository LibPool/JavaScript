# @outcrawl/mcp

> 标签: agent, browser-automation, crawler, mcp, model-context-protocol, outcrawl, scraping, web-search

## 简介

Outcrawl Model Context Protocol server. One tool per capability, generated from the @outcrawl/core registry — the distribution channel that puts Outcrawl inside every agent runtime with nobody writing an integration.
