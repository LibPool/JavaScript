# @igorskyflyer/registry-apppaths

> 标签: applications, apppaths, igorskyflyer, packages, registry, user, windows

## 简介

🪀 A package for reading the AppPaths registry key on Windows. Useful for retrieving applications that can be launched from the command prompt. 🗃

## 官网

- 官网：https://github.com/igorskyflyer/npm-registry-apppaths
- 源码仓库：git+https://github.com/igorskyflyer/npm-registry-apppaths.git
- npm 页面：https://www.npmjs.com/package/@igorskyflyer/registry-apppaths

## 获取地址

- npm 安装：`npm install @igorskyflyer/registry-apppaths`
- npm registry：https://registry.npmjs.org/@igorskyflyer/registry-apppaths
- Node 要求：>=22.0
