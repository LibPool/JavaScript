# @blockwatch-cc/swap-ui

> 标签: JavaScript

## 简介

TzSwap is a reusable React component for swapping Tezos FA2 and FA1.2 tokens. Originally forked from [@project-serum/swap-ui](https://github.com/project-serum/swap-ui).
