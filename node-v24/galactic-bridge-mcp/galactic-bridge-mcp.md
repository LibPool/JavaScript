# galactic-bridge-mcp

> 标签: bridge, cross-chain, crypto, evm, galactic-bridge, layerzero, mcp, model-context-protocol, oft

## 简介

MCP server for Galactic Bridge — find LayerZero OFT bridge routes by token contract address and build ready-to-sign cross-chain transactions across 14 EVM networks.
