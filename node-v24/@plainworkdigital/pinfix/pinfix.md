# @plainworkdigital/pinfix

> 标签: ci, cli, commit-sha, digest, docker, dockerfile, github-actions, pin, security, sha, supply-chain

## 简介

Pin GitHub Actions to full commit SHAs and container images to sha256 digests, keeping the version as a comment. Offline check for CI, zero dependencies.
