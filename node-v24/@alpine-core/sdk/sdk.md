# @alpine-core/sdk

> 标签: JavaScript

## 简介

The TypeScript SDK (`@alpine-core/sdk`) wraps the `@alpine-core/protocol` helpers so you can orchestrate discovery, handshake, and streaming without managing CBOR or UDP helpers directly. This package is the **SDK** layer—not the primitive protocol helper
