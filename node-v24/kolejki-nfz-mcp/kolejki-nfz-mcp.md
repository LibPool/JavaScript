# kolejki-nfz-mcp

> 标签: ai-agent, claude, healthcare, kolejki, lekarz-specjalista, mcp, model-context-protocol, nfz, open-data, poland, terminy-leczenia, waiting-times

## 简介

MCP server: NFZ waiting times in Poland for AI agents – where a specialist, test or treatment paid by NFZ is available soonest near you (forecast wait, address, phone, accessibility). No API key.
