# @copylee/dsh-academic

> 标签: academic, academic-writing, ai-agent, arxiv, bibtex, citation, cordis, crossref, deepseek, deepseek-harness, dsh, dsh-plugin, literature, literature-review, openalex, paper, pubmed, research, skills, zotero

## 简介

DeepSeek Harness 学术插件：连接本机或在线的 Zotero 文库；多源论文检索（arXiv、OpenAlex、Crossref、PubMed、知网、Google Scholar 等）、阅读开放获取全文、获取引文、核验参考文献；内置文献综述、论文精读、写作润色、模拟审稿等学术技能。
