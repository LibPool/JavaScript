# @copylee/dsh-desktop-restart

> 标签: cordis, deepseek, deepseek-harness, desktop, dsh, dsh-plugin, electron, hot-restart, restart

## 简介

DeepSeek Harness 桌面版一键重启插件：在左下角官方更新按钮旁提供需重启提示胶囊与常驻重启入口，在 dsh-market 需重启横幅与标题栏内嵌立即重启按钮，支持活动任务与插件安装守卫及优雅退出恢复。
