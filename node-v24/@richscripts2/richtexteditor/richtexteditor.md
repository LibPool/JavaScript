# @richscripts2/richtexteditor

> 标签: contenteditable, editor, formatting, html-editor, i18n, image-editor, javascript, no-dependencies, pdf-export, plugins, rich-text-editor, text-editor, toolbar, vanilla-js, wysiwyg

## 简介

A full-featured JavaScript rich text editor (WYSIWYG) with toolbar, plugins, i18n support, image editing, PDF export, and zero framework dependencies.
