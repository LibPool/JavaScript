# @aahoughton/oav-express5

> 标签: api-validation, express, express-openapi, express5, middleware, oas, openapi, openapi-3.0, openapi-3.1, openapi-3.2, openapi-middleware, openapi-request-validator, openapi-validator, request-validator, swagger, validation, validator

## 简介

Express 5 middleware for OpenAPI request validation (3.0/3.1/3.2). Promise-native; checks the request against your spec and returns problem+json errors. Built on @aahoughton/oav-core.
