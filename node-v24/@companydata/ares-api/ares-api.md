# @companydata/ares-api

> 标签: ares, ares-api, b2b-data, business-register, company-data, company-search, czech, czechia, firmy, ico, obchodni-rejstrik, sdk, typescript

## 简介

ARES API wrapper: Czech company data from ARES (the Ministry of Finance business register) with full addresses, phone, email, website and firmographics, through one REST call. A thin layer over @companydata/companydata-sdk, pinned to CZ.
