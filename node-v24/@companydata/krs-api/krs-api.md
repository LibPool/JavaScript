# @companydata/krs-api

> 标签: b2b-data, business-register, ceidg, company-data, company-search, krs, krs-api, nip, poland, polish, regon, rejestr, sdk, typescript

## 简介

KRS API wrapper: Polish company data from the KRS (Krajowy Rejestr Sądowy) and CEIDG with full addresses, phone, email, website and firmographics, through one REST call. A thin layer over @companydata/companydata-sdk, pinned to PL.
