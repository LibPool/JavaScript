# @companydata/handelsregister-api

> 标签: amtsgericht, b2b-data, business-register, company-data, company-search, firmendaten, german, germany, handelsregister, handelsregister-api, hrb, sdk, typescript

## 简介

Handelsregister API wrapper: German company data from the Handelsregister with full addresses, phone, email, website and firmographics, through one REST call. A thin layer over @companydata/companydata-sdk, pinned to DE.
