# @pidanmoe/mcp-stock

> 标签: fastmcp, mcp

## 简介

这是一个基于 [FastMCP](https://github.com/fastmcp/fastmcp) 框架构建的 MCP (Model Context Protocol) 工具包，用于获取中国A股市场相关的股票数据。
