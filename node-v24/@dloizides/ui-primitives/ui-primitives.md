# @dloizides/ui-primitives

> 标签: attribution, avatar, dloizides, footer, react, react-native, ui-primitives

## 简介

Themable, brand-agnostic React UI primitives for the dloizides.com portfolio. Includes the portfolio-wide PoweredByFooter attribution component and a themed monogram Avatar.
