# @dloizides/game-rng

> 标签: deterministic, eisaipollis, fnv-1a, game, mulberry32, prng, seeded-random

## 简介

Deterministic seeded randomness for games: mulberry32 PRNG, FNV-1a string-seed hashing, range/pick helpers and daily/random seed builders. Zero deps, isomorphic. Extracted from Surge + Aurora; bit-identical to Surge/src/rng.ts.
