# @dloizides/ui-payments

> 标签: dloizides, payments, react, react-native, react-native-web, stripe, ui

## 简介

Brand-agnostic React Native (RN-web) Stripe credentials card: connection status badge, masked key, webhook URL row, secret inputs with key-shape validation, payments switch and save/test/clear callbacks. Labels come in as props. Part of the dloizides.com
