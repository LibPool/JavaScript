# @ivaisoft/bws-webauthn-mcp

> 标签: JavaScript

## 简介

MCP server for Bitwarden Secrets Manager: the agent USES secrets it never sees, and every use is gated by a fresh physical WebAuthn Approval (Touch ID / passkey).
