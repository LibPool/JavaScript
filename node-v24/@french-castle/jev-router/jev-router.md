# @french-castle/jev-router

> 标签: claude-code, codex, cost, jev, llm, model-routing, opencode, openrouter, pi, pi-package, router, switchyard, typesafe, vercel-ai-gateway

## 简介

Route each coding-agent turn to the cheapest model that can finish it. Switchyard-style execution signals, TypeSafe's jev as the judge, and honest cost accounting. Works with Claude Code, Codex, OpenCode, and Pi.
