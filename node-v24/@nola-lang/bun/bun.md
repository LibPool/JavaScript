# @nola-lang/bun

> 标签: ai, bun, bun-plugin, llm, nola

## 简介

Bun plugin for Nola (.tsi): run .tsi from source with a bunfig.toml preload, bundle and compile in one step with Bun.build, load .tsi in bun test
