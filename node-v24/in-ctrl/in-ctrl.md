# in-ctrl

> 标签: architecture, diagrams, docs, elk, living-docs, react-flow, starlight

## 简介

Docs you stay in control of: architecture, deployment and sequence diagrams from YAML (React Flow + ELK, real product icons), a docs site from your Markdown, and checks that keep them in sync.
