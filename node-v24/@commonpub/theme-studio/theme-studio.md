# @commonpub/theme-studio

> 标签: color, commonpub, design-system, design-tokens, theme, typescript

## 简介

Framework-agnostic theme generator: derive a complete, WCAG-checked CommonPub design system from a small recipe (accent, vibe, scale, shape).
