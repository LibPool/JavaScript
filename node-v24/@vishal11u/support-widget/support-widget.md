# @vishal11u/support-widget

> 标签: feedback, nextjs, react, screenshot, support, typescript, widget

## 简介

A drop-in, self-contained support/feedback widget for React 19 + Next.js apps: floating trigger, automatic page screenshot with crop/zoom, extra image uploads, and an enterprise-styled dialog form.
