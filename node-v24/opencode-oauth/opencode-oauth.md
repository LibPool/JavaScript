# opencode-oauth

> 标签: oauth, oauth2, oidc, opencode, opencode-plugin, pkce, searxng

## 简介

OpenCode plugin: sign in to an OpenAI-compatible provider with OAuth 2.0 (authorization code with PKCE, refresh tokens), and search the web through a SearXNG behind the same sign-in
