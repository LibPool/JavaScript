# @raasimpact/arduino-uno-q-bridge

> 标签: arduino, arduino-router, arduino-uno-q, bridge, iot, mcu, messagepack-rpc, msgpack, msgpack-rpc, rpc, unix-socket, uno-q

## 简介

Pure Node.js MessagePack-RPC client for the Arduino UNO Q router — read sensors, drive GPIO, and react to async MCU events from any Node.js process.
