# @xcrapcc/mcp

> 标签: ai, claude, cursor, llm, mcp, model-context-protocol, scraper, thread, tweet, twitter, unroll, x

## 简介

MCP server for XCrap — Twitter/X tools for LLM agents: read posts, unroll threads, extract profiles and timelines, list media, no API key.
