# @dlsforge/aegov-rules-core

> 标签: accessibility, aegov, design-system, design-tokens, emirates-id, government, rtl, uae, uae-pass

## 简介

Machine-readable model of the UAE Design System (AEGOV DLS): component schemas, resolved design tokens, catalogue loader, and the DLS rule engine. Community project. Not affiliated with or endorsed by TDRA.
