# @harsh-chandak/agentguard

> 标签: agent-orchestration, ai-agents, claude-code, codex, coding-agents, consistency, coordination, decision-log, multi-agent

## 简介

Agents that can't contradict each other. A decision log for hierarchical coding agents, with deterministic contradiction detection and an escalation ladder — no model call in the decision path.
