# @luizsantiago/spec-guardrails

> 标签: agent, ai, claude, cli, cursor, devops, guardrails, python, spec-driven

## 简介

Governed spec-driven development for AI coding agents: spec-first workflow, optional Python gates (Brakes), repo memory in .specs/, and an optional python-platform preset when Python features touch deploy/infra and/or AI paths.
