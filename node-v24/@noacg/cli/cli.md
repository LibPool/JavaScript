# @noacg/cli

> 标签: broadcast-graphics, casparcg, claude-code, codex, lower-third, mcp, obs, ograf, scoreboard, spx, vmix

## 简介

The NoaCG CLI: scaffold, validate, inspect, screenshot and save broadcast graphics for NoaCG Studio, from a coding agent or your own terminal. Runs as an MCP server too (noacg mcp), against any NoaCG deployment.
