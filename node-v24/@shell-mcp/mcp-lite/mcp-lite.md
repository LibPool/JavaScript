> 标签: ai, claude, claude-desktop, cursor, llm, mcp, mcp-server, persistent-session, shell, terminal, windsurf

## 简介

MCP server for persistent shell sessions — zero config, one command. Works with Claude Desktop, Cursor, Windsurf, Zed, and any MCP client.
