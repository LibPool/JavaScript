# @godcreator/gwb-node-cli

> 标签: gwb-plugin

## 简介

运行 node 写的命令行工具：插件把自己构建出来的 cli.js 登记进来，由它启动进程、收集输出、到时限结束进程；登记的命令自动转登记成总线命令。服务 gwbNodeCli；skill 1 份；命令 1 条。
