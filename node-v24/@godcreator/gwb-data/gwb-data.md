# @godcreator/gwb-data

> 标签: gwb-plugin

## 简介

插件的数据：每个插件的文档存放在 <home>/data/<条目 id>/ 下，一份文档一个 JSON 文件，原子写入。服务 gwbData；skill 0 份；命令 0 条。
