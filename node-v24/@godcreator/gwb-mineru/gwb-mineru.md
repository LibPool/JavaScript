# @godcreator/gwb-mineru

> 标签: gwb, gwb-plugin

## 简介

PDF 转 markdown 插件：提供 gwbPdf2md 服务与 pdf2md.* 命令，把 PDF 交给 MinerU 云端解析，提交后立即返回作业号，结果在后台落进调用方给的目录。
