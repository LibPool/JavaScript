# @godcreator/gwb-gitea-issues

> 标签: gwb-plugin

## 简介

gitea issue 窗格：列出设置里几个 owner 名下各仓开着的 issue、看正文与评论；后台定时查新 issue 与新评论，装着 qq-bot 就经 gwbQqBot 私聊主人
