# @godcreator/gwb-windows-backup

> 标签: gwb-plugin

## 简介

Windows 备份插件：定时把白名单目录做成 restic 快照、同步到阿里云 OSS 异地库并周期自检，没装外壳的 home 里照样备份，装了外壳多一个备份窗格。
