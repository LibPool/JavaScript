# @godcreator/gwb-commands

> 标签: gwb-plugin

## 简介

命令总线：插件把能力登记成「命令名 → 处理函数」的表，页面、agent 与其他插件经同一张表调用（agent 经 MCP 入口的 index / search / run）。服务 gwbCommands；skill 1 份；命令 0 条。
