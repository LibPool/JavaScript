# @aivec/eslint-config-ts-react

> 标签: React, TypeScript, WordPress, webpack

## 简介

Boilerplate configurations (TS, JS, React, etc.) for various WordPress plugins/projects. Includes some features from @wordpress/scripts such as automatic asset inclusion/exclusion.
