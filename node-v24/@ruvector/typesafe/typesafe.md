# @ruvector/typesafe

> 标签: calibration, choice, classification, confidence, decisions, embeddings, jev, local-first, noul, ruvector, system-one, typesafe, zero-dependency

## 简介

Local typed decisions (choice / score / noul) over sentence embeddings — a ruvector-powered, self-optimizing alternative to typesafe.ai's System One API. Native (napi-rs) with a WASM fallback; no network, no per-token cost.
