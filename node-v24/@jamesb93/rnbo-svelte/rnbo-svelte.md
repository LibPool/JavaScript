# @jamesb93/rnbo-svelte

> 标签: music, rnbo

## 简介

*rnbo-svelte* is a node package for abstracting away repetitive tasks that are needed to work with [RNBO](https://www.npmjs.com/package/@rnbo/js) in a node-based application.
