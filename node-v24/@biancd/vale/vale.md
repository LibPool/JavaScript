# @biancd/vale

> 标签: JavaScript

## 简介

基于 Element Plus 的 Vue 3 功能组件库，提供命令式表单弹窗（`useFormPopup`）、通用表格（`useAbTable`）、标签页管理（`useTabManager`）、倒计时轮询（`useCountdownPolling`）和 HTTP 请求封装（`request`）等开箱即用的 Hook 和工具函数。
