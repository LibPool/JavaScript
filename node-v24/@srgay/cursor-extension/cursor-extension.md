# @srgay/cursor-extension

> 标签: cli, cursor, cursor-ide, ime, max-mode, mcp, mcp-feedback-enhanced, workbench

## 简介

本机 Cursor workbench 增强：MAX Mode 守护、MCP Follow-up 面板、输入法回车修复、AskQuestion 自动提交（支持随 Cursor 启动持久加载，或 CDP 临时注入）。
