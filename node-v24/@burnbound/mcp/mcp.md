# @burnbound/mcp

> 标签: agent-payments, ai-agents, base, budget, claude-code, mcp, model-context-protocol, spending-limits, usdc, x402

## 简介

MCP server that lets an AI agent pay x402 and MPP (tempo.charge) APIs under a Burnbound spending policy and check its budget and history.
