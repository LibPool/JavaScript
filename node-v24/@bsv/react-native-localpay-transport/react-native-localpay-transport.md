# @bsv/react-native-localpay-transport

> 标签: awdl, bitcoin, ble, bsv, expo, local-payment, nitro-modules, p2p, react-native, wallet

## 简介

Nitro module exposing native local-payment transports (AWDL/TLS-PSK on iOS, Nearby Connections on Android, plus a BLE rung on both) for proximity BSV payments in Expo/React Native apps.
