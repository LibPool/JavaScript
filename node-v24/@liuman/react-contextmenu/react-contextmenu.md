# @liuman/react-contextmenu

> 标签: context-menu, long-press, portal, react, right-click, submenu

## 简介

A context menu that behaves: flips at viewport edges, never adds scrollbars, submenus flip too, long-press opens it on touch, Esc/outside-click closes it. No UI framework required.
