# @j20org/jsx-transform

> 标签: JavaScript

## 简介

j20 框架的 JSX 编译器 —— 一个 Babel 插件，把 JSX 编译成 j20 运行时的细粒度响应式调用（`jsx` / `jsxs` / `template` / `Fragment`）。
