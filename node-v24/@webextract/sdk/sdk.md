# @webextract/sdk

> 标签: ai-agents, extraction, llm, markdown, mcp, web-scraping, webextract, x402

## 简介

Thin client for the WebExtract API: web page to clean Markdown + fixed-schema JSON for AI agents. Prepaid key, free tier, or pay per call with x402 (USDC on Base and 6 other chains).
