# @llm-ports/adapter-codex

> 标签: adapter, agent, ai, codex, llm, llm-ports, openai, subprocess

## 简介

Subprocess-driven adapter for OpenAI Codex CLI. Runs `codex exec --json` as a subprocess, parses its JSON event stream, and emits @llm-ports contract events. Shape A: passthrough governance (operator supplies OpenAI credentials to codex directly; @llm-por
