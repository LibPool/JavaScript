# @simplex2-sdk-util/url

> 标签: simplex2-sdk-util, url

## 简介

此模块提供了一系列用于解析和操作 URL 的工具函数。这些函数可以帮助开发者轻松提取 URL 的各个部分（如查询参数、端口、主机名等），并进行相应的处理。所有函数都经过了详细的注释和示例说明，确保易于使用和理解。
