# @minimal-viz/core

> 标签: bar-chart, charts, dataviz, echarts, funnel, gauge, heatmap, line-chart, pie-chart, react, sankey, visualization

## 简介

Lightweight React chart components (39 chart types covering Apache Superset's full ECharts-based catalog plus WorldMap and CountryMap choropleths) built on ECharts. Light/dark themes, ~18 KB gzip ESM. Stable 1.x — see VERSIONING.md.
