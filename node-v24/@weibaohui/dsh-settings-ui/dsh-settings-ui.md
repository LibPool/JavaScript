# @weibaohui/dsh-settings-ui

> 标签: appearance, cordis, deepseek-harness, dsh, dsh-plugin, plugin, ui, web

## 简介

dsh 插件 · 设置界面自定义：调整原生设置窗口大小（全屏 / 预置大尺寸 / 自定义宽高）、背景透明度与背景（主题 / 自定义颜色），悬浮球即开即调，存本机浏览器
