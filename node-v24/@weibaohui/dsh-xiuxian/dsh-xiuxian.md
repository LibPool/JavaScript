# @weibaohui/dsh-xiuxian

> 标签: companion, cordis, deepseek-harness, dsh, dsh-plugin, plugin, xiuxian

## 简介

dsh 插件 · 修仙陪伴：随机唤醒《凡人修仙传》角色，MC像素风桌宠与 agent 会话实时联动。子代理启动时化身宠物现身（最多3只同屏），支持储物袋收藏、三种显示模式、右键法宝菜单、图鉴选宠，可导出 Codex 桌宠格式。
