# @weibaohui/dsh-dashboard

> 标签: analytics, cordis, dashboard, deepseek-harness, dsh, dsh-plugin, heatmap, plugin, tokens, usage

## 简介

dsh 插件 · 使用量仪表盘：离线扫描会话日志，统计每日/每周/每月 token、估算费用、模型/工具/技能/命令榜、输出速度、工作时段与质量指标；gridstack+ECharts 卡片可拖拽编排，支持自定义公式与 AI 编排（提示词往返导入）。
