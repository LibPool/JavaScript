# @gaberrb/polypus

> 标签: agent, ai, cli, coding, harness, llm, ollama, openrouter

## 简介

Agentic coding harness that makes any AI API (with or without native tool-calling) generate and apply code. OpenRouter, Ollama, and any OpenAI-compatible endpoint.
