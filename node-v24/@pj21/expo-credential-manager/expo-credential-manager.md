# @pj21/expo-credential-manager

> 标签: authentication, autofill, credential-manager, expo, login, one-tap, password, passwords, react-native

## 简介

One-tap password sign-in for Expo / React Native. Opens the native Android Credential Manager sheet or the iOS Password AutoFill sheet and returns the saved credential.
