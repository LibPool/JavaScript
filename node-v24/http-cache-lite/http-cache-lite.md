# http-cache-lite

> 标签: cache, cache-control, deduplication, etag, express, http, lru, middleware, stale-while-revalidate, ttl

## 简介

Lightweight, framework-friendly HTTP response caching for Node.js/TypeScript with TTL, LRU, tags, ETag, Cache-Control, SWR and request deduplication.
