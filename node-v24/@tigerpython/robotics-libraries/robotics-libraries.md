# @tigerpython/robotics-libraries

> 标签: calliope-mini, microbit, micropython, robotics, tigerjython, tigerpython

## 简介

TigerJython robotics modules (micro:bit, Calliope mini) with minified and raw Python sources, plus a typed JS/TS API for easy integration.
