# @renapo/curp

> 标签: JavaScript

## 简介

Validacion local y consulta en linea de CURP (Clave Unica de Registro de Poblacion). Permite validar el formato de una CURP y consultar datos en el servicio RENAPO del gobierno de Mexico.
