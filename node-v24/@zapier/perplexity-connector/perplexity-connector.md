# @zapier/perplexity-connector

> 标签: agent, ai, automation, connector, mcp, perplexity, skills, tools, zapier

## 简介

Agent-callable Perplexity tools — ask web-grounded questions with citations, run and poll deep research, list models, and search the web. Use when the user mentions Perplexity or wants a cited web answer or search, even if they don't name Perplexity.
