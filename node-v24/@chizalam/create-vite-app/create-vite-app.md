# @chizalam/create-vite-app

> 标签: express, generator, react, router, scaffold, tailwind, template, vite, vitest

## 简介

Interactive CLI template generator for lightweight minimalist Vite + React setups with options for Tailwind CSS, PWA, Safe Storage, React Router, Vitest, and Express.
