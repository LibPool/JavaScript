# @super-line/collections-cloudflare

> 标签: cloudflare, collections, durable-objects, rows, sqlite, super-line

## 简介

Durable Object SQLite CollectionStore backend for super-line — typed row collections stored in the object that is the node, with IR→SQL snapshot pushdown.
