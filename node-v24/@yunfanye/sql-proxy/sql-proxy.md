# @yunfanye/sql-proxy

> 标签: api, database, http, mysql, postgresql, proxy, snowflake, sql

## 简介

A SQL proxy server that accepts SQL queries via HTTP and executes them against configured database backends (PostgreSQL, MySQL, Snowflake)
