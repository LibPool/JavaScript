# @getnumra/nuxt

> 标签: cod, fraud, h3, morocco, nitro, numra, nuxt

## 简介

Nuxt / Nitro server handler for Numra — the backend endpoint @getnumra/react or @getnumra/vue calls. Holds your API key so the browser never does.
