# @ddmnpm/ddm-agent-publish

> 标签: JavaScript

## 简介

读取 DDM agent 成品仓中已有 manifest.json，将符合 OpenCode 规范的 agent 打包为 zip 发布包，并提交到 DDM 平台审核；只检查，不生成或重写内容。
