# ifvisible.js

> 标签: HTML5, UI, api, browser, change, cross, idle, mode, mousemove, page-lifecycle, page-visibility, reading, status, tab, typescript, visibility

## 简介

Crossbrowser & lightweight way to check if user is looking at the page or interacting with it. (wrapper around the HTML5 Page Visibility API)
