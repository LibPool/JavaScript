# img-rescue

> 标签: broken-image, fallback, image, nextjs, onerror, placeholder, react, srcset, vue

## 简介

Zero-dependency utility that automatically swaps broken images for a fallback. Handles srcset, <picture>, SSR and per-image overrides.
