# impiler

> 标签: deserialize, intermediate compiler, json, json-to-typescript, json-typescript-deserialize, json-typescript-serialize, serialize

## 简介

Impiler is an intermediate compiler (impiler) that aids in JSON serialization and deserialization, with a primary focus on converting JSON <-> Typescript.
