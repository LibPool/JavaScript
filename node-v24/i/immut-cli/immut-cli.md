# immut-cli

> 标签: ai agents, blockchain timestamp, compliance evidence, immut, proof of existence, sha256, xrpl

## 简介

Command line tool for immut, the proof layer for digital files. Hash files locally, anchor permanent proofs on the XRP Ledger, verify them from anywhere. File contents never leave your machine.
