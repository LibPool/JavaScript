# idempotency-tester

> 标签: api-testing, at-least-once, cli, concurrency, consumer, distributed-systems, duplicate, http, idempotency, idempotent, kafka, rabbitmq, race-condition, reliability, sqs, testing

## 简介

Fire the same request or event N times concurrently and verify real database state to catch idempotency violations — across HTTP, Kafka, SQS, and RabbitMQ.
