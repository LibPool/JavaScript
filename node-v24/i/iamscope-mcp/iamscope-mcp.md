# iamscope-mcp

> 标签: aws-iam, azure-actions, azure-custom-role, azure-rbac, cloud-security, custom-role, entra-id, gcp-iam, google-workspace, iam, ibm-cloud, least-privilege, mcp, model-context-protocol, rbac, segregation-of-duties, sod

## 简介

MCP server com o catalogo do IAM Scope: 4.640 roles e 30.865 permissoes de seis nuvens (Entra ID, Azure RBAC, AWS IAM, GCP IAM, Google Workspace, IBM Cloud), mais as 17.591 acoes do Azure para escrever custom roles, respondendo na sua maquina.
