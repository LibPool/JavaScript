# india-mutual-fund-info

> 标签: AMFI, Mutual Fund

## 简介

This package provides a Javascript function interface for accessing historical and current information about Indian Mutual Funds. Text data is downloaded from AMFI's portal https://www.amfiindia.com/ and returned as an object.
