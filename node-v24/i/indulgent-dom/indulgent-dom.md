# indulgent-dom

> 标签: JavaScript

## 简介

An extremely lightweight DOM binding library for [indulgent](https://frodi-karlsson.github.io/indulgent/) signals. No syntax that can't be rendered in plain HTML, no virtual DOM, no frameworks.
