# infra-ts

> 标签: cli, config-as-code, iac, infra-ts, infrastructure-as-code, neon, typescript, vercel

## 简介

infra-ts — typed, live-reconciled infrastructure & config as code (no attribute state). An infra.ts file, a thin REST provider system, and a CLI/SDK for Neon, Vercel and beyond.
