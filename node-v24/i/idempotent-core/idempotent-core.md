# idempotent-core

> 标签: async-local-storage, concurrency, express, fastify, http, idempotency, idempotent, middleware, payments, race-condition, saas, stripe, webhook, zero-dependency

## 简介

Bulletproof, zero-dependency idempotency middleware for Node.js. Eliminates race conditions on critical endpoints (payments, webhooks) for Express, Fastify, and native HTTP.
