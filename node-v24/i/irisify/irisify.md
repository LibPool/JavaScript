# irisify

> 标签: animation, border, border-beam, conic-gradient, effect, glow, iridescent, rainbow, react, ui

## 简介

Iridescent border glow for any element - a perimeter-mapped rainbow flash/lights engine with zero dependencies. Pure CSS output, framework-free core, optional React bindings.
