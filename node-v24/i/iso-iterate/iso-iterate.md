# iso-iterate

> 标签: annotations, claude, coding-agent, design-review, dev-tool, feedback, iteration, review, variants, vite-plugin

## 简介

A feedback loop between a person reviewing a running web app and the coding agent building it. A dev-only panel bottom right of the page takes notes, pins them to real elements with a click, and writes them to a JSON file in the repo with route, selector
