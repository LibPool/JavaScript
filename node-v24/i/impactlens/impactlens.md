# impactlens

> 标签: cli, code-graph, cursor, impact-analysis, laravel, php, static-analysis, vue

## 简介

Static code graph scanner and navigation CLI for AI-assisted development. Currently supports PHP and Laravel, JavaScript, TypeScript, Vue, and Nuxt.
