# insig

> 标签: JS, fast, light, reactive, super-fast, ultra-light, webcomponents

## 简介

No-junk JS component library with insignificant weight. All in one mush: Web-Components, Localization, Templates, Routing, Reactive binding, Lazy init, Observables, Debounce, Unique IDs, PSW hashing
