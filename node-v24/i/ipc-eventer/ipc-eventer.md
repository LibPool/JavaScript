# ipc-eventer

> 标签: cross-platform, developer-tools, event-driven, event-emitter, inter-process, ipc, named-pipes, nodejs, process-communication, realtime, server-client, socket, unix-domain-sockets

## 简介

Cross-platform IPC event manager using Named Pipes (Windows) and Unix Domain Sockets (Linux/macOS) built with Node.js, based on aosx socket.
