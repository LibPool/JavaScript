# iobroker.open-epaper-link

> 标签: epaper, openepaper, openepaperlink

## 简介

ioBroker integration for alternative firmware and protocol for the ZBS243-based Electronic Shelf Labels - ESL / price tags by Solum / Samsung. It can be used to setup E-Paper tags and supply them with content.
