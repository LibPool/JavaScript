# image-cropper-react

> 标签: circle crop, crop image react, crop tool, cropper component, image crop library, image crop react, image crop ui, image cropper, image cropping, image-cropper-react, react, react crop image, react cropper component, react image crop tool, react image cropper, square crop

## 简介

A lightweight and customizable React image cropper component with drag, resize,zoom and keyboard support. Export cropped images as Base64, Blob, or File — with square and circular crop box options.
