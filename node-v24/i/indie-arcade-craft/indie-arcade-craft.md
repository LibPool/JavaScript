# indie-arcade-craft

> 标签: advergame, arcade, deterministic, fixed-timestep, game, game-feel, html5, juice, testing

## 简介

Deterministic engine parts and a gate framework for small web arcade games that play like well-reviewed indie games: fixed-step loop, seeded streams, state hashing, input sampling, juice budgets, human-limit bots, and gates proven by mutants.
