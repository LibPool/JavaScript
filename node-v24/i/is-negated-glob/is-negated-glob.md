# is-negated-glob

> 标签: extglob, glob, inverse, inverted, is, is-glob, match, micromatch, negate, negated, negation, negative, pattern, test

## 简介

Returns an object with a `negated` boolean and the `!` stripped from negation patterns. Also respects extglobs.
