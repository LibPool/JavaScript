# iphone-mirroir-mcp

> 标签: iphone, macos, mcp, mcp-server, mirroir, mobile-testing, model-context-protocol

## 简介

MCP server that controls a real iPhone through macOS iPhone Mirroring. Screenshot, tap, swipe, type — from any MCP client.
