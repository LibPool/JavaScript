# iws-cli

> 标签: JavaScript

## 简介

```     // 初始化项目     iws init -n 'fileName' -t 'template'     // 添加模版支持公共资源     iws add -n 'template' -u 'git url'     // 删除已经添加的模版     iws del -n 'template' ```
