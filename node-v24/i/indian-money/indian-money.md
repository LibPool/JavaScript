# indian-money

> 标签: crore, currency, fintech, formatter, indian, inr, lakh, money, parser, rupees, typescript

## 简介

A tiny, dependency-free TypeScript library to parse Indian currency strings (₹/Rs with lakh/crore units) into numbers and to format numbers back using the Indian numbering system
