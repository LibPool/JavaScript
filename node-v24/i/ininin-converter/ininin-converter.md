# ininin-converter

> 标签: JavaScript

## 简介

字符串或数字转半角，字符串或数字转全角，解析键值对字符串为Hash对象，编码Hash对象为键值对字符串，货币格式化，过滤掉值为空字符的参数，人民币大写， 首字母大小写
