# illustration-search

> 标签: attribution, creative-commons, image-search, openverse, pexels, pixabay, stock-photos, wikimedia-commons

## 简介

Text-to-image retrieval over open-media corpora, in the browser: the TypeScript twin of the Python `illustration` package, with licence and attribution first-class on every hit.
