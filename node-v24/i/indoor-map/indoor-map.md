# indoor-map

> 标签: JavaScript

## 简介

一款基于canvas开发的web门店地图插件。 ## 特性 * 地图元素事件封装 * 事件代理 * 更易用的画笔绘图方法 * tooltip效果实现 * 动画 * 自定义画布元素
