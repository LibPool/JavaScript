# iris-flow

> 标签: ai, automation, byok, fair-code, iris, node-editor, self-hosted, workflow

## 简介

Open-source local host for the Iris workflow engine. Run `npx iris-flow` to launch a local server, build workflows in the browser, and execute them with your own AI API keys (BYOK). No server, database, GCS, or billing required.
