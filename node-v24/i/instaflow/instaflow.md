# instaflow

> 标签: anti-detection, auto-comment, auto-follow, auto-like, browser-automation, dm-bot, headless, instagram, instagram-api, instagram-automation, instagram-bot, instagram-scraper, playwright, rate-limiter, reels, reels-scraper, social-media, social-media-automation, social-media-bot, stealth, story, web-scraping

## 简介

Headless Instagram automation powered by Playwright. Persistent sessions, human-like delays, built-in rate limiter. Post, story, like, comment, follow, DM, scrape reels and more — no API key required.
