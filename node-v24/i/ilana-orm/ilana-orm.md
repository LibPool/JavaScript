# ilana-orm

> 标签: active-record, cloudflare-workers, database, edge-runtime, eloquent, factory, javascript, knex, laravel, migrations, mysql, nextjs, nodejs, orm, pgvector, postgresql, query-builder, relationships, seeder, sqlite, supabase, typescript, typescript-orm, ulid, vector-search

## 简介

A fully-featured, Laravel Eloquent-style ORM for Node.js & TypeScript. MySQL, PostgreSQL, SQLite, Supabase, edge runtimes, pgvector AI search.
