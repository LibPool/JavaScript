# iturri

> 标签: ai-agent, backtesting, crypto, equities, market-data, mcp, ohlcv, quant, trading, trading-bot, verified-data, x402

## 简介

Client + CLI for the Iturri verified market-data API — quality-flagged candles, funding, open interest, order flow and ML-ready bundles for trading bots and AI agents. MCP + x402 native.
