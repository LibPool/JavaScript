# island-press

> 标签: ssg, vite

## 简介

一个基于 Vitejs 的静态站点生成器，使用 React 框架进行渲染。使用Vitejs提供足够快的启动速度，带来良好的开发体验。内置一套默认的文档主题，可以快速搭建一个文档、博客站点，内置 MDX 支持，可以在文档中渲染自定义的 React 组件。
