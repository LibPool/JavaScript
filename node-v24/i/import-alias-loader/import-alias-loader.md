> 标签: CallExpression, ExportNamedDeclaration, ImportDeclaration, alias, ast, i18n, import, import(), js, jsx, loader, resolve, url, webpack

## 简介

A webpack loader used to resolve .js/.jsx file import alias（through AST） . Support `import()` syntax
