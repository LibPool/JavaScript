# iam-hcl-converter

> 标签: JavaScript

## 简介

This is a very simple library which converts AWS IAM JSON policies to `terraform`'s [`aws_iam_policy_document`](https://www.terraform.io/docs/providers/aws/d/iam_policy_document.html).
