# inline-css-cache

> 标签: JavaScript

## 简介

再 HTML 中使用内联样式可以提升首屏渲染速度，但是内联样式增加了 HTML 的大小，失去了缓存优势，这个库的作用就是缓存 HTML 中的内联样式。
