# ion-image-search

> 标签: bing image search, directive, flickr image search, google image search, image search, ionic, search, service, web image search, web search

## 简介

An Ionic service for searching an image from the web with an endless scroll, similar to Whatsapps `Search web` feature when defining image for group.
