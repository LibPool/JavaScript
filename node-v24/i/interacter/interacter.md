# interacter

> 标签: cli, debug, input, input_and_output, interacter, ios, iostream, output, reader, userinput

## 简介

A simple package that allows dev to interact with the CLI by accepting user input and displaying output with customizable behavour like restricting the some characters. It can live listen to user input to prevent so
