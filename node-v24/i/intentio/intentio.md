# intentio

> 标签: actions, command-palette, commands, focus, hotkeys, intents, keybindings, keyboard-shortcuts, react, shortcuts

## 简介

Focus-scoped command dispatch for React — one intent, dispatched by keyboard shortcuts, command palette, and buttons alike, resolved by where focus is. Flutter's Actions/Intents/Shortcuts, for the web.
