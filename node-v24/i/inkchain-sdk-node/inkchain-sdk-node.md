# inkchain-sdk-node

> 标签: JavaScript

## 简介

* run `(sudo) npm install -g gulp (--registry=https://registry.npm.taobao.org)` * run `(sudo) npm install ` * run `(sudo) npm install sleep` * run `npm install inkchain-client`    to invoke building inkchain-client. * run `(sudo) gulp watch` * cd test/fix
