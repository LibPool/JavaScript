> 标签: chatgpt, claude, codex, cursor, design, free-icons, gemini, icon-search, icons, infyicon, mcp, mcp-server, model-context-protocol, png, svg, windsurf

## 简介

MCP server for Infyicon — search 161,000+ free hand-drawn icons and fetch ready-to-embed SVG or PNG from Claude, ChatGPT, Cursor, VS Code and any MCP client. Hosted endpoint: https://infyicon.com/mcp (no auth).
