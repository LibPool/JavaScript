# imansi-almacenamiento-node

> 标签: almacenamiento, archivos, express, files, imansi, nodejs, postgresql, seguridad, storage

## 简介

Sistema de almacenamiento de archivos local para Node.js con PostgreSQL y permisos opcionales. Parte del ecosistema Imansi.
