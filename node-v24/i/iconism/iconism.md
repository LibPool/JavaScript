# iconism

> 标签: assets, css, eot, font, font-generator, fonts, html, icon, icon-font, icon-generator, icons, json, sass, scss, svg, svg-font, svg-icons, ttf, typescript, webfont, woff, woff2

## 简介

Modern SVG icon font generator - Create TTF, WOFF, WOFF2, EOT fonts and web assets (CSS, SCSS, HTML, JSON, sprites) from SVG files with TypeScript support.
