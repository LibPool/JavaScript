# insight-ui-cpr

> 标签: bitcore, blockchain, blockexplorer, cryptorescue, front-end, insight

## 简介

An open-source frontend for the Insight API. The Insight API provides you with a convenient, powerful and simple way to query and broadcast data on the hush network and build your own services with it.
