# ideal-postcodes

> 标签: Addressing, Mail, PAF, Royal, UK

## 简介

UK Postcode lookup API. Wrapper for Ideal-Postcodes.co.uk API uses Royal Mail's Postcode Address File (PAF).

## 官网

- 官网：https://ideal-postcodes.co.uk/
- 源码仓库：git+https://github.com/ideal-postcodes/ideal-postcodes-node.git
- npm 页面：https://www.npmjs.com/package/ideal-postcodes
