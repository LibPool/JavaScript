# i18n-swarm

> 标签: ci, codemod, github-action, i18n, internationalization, localization, next-intl, nextjs, react, react-i18next, vue, vue-i18n

## 简介

CI gate that fails a PR when it adds a hardcoded UI string with no translation key (Next.js / Vue / React), diff-scoped with a keyed-fix patch. Ships a one-time retrofit verified by a real build.
