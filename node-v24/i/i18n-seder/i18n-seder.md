# i18n-seder

> 标签: editor, i18n, i18n tool, internationalization, json translations, localization, react, seder, seder18, translate, translation, translations editor, vue

## 简介

A lightweight local JSON-based translation editor for i18n projects. Opens a local UI to manage and edit your translation files directly from your project.
