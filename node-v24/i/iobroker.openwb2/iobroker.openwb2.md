# iobroker.openwb2

> 标签: openwb,ev-charging,wallbox,simpleapi,pv

## 简介

Reads chargepoints, counters, battery, PV and consumers from an openWB 2 wallbox controller live over MQTT, and lets you control charging via its simpleAPI HTTP interface
