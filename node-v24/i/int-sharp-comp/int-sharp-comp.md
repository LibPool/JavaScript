> 标签: avif, build tool, compress, dev dependency, framework, image compression, image optimization, optimizer, sharp, webp

## 简介

Blazing-fast image compression with modern format support — auto-discovers images in frameworks, generates compress.config, tracks compress.log, and replaces originals
