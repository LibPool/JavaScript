# isfjs

> 标签: generative, glsl, interactive-shader-format, isf, shader, visuals, vj, webgl, webgl2

## 简介

An engine for ISF (Interactive Shader Format) shaders on the web: read the header, build typed inputs, and render with WebGL 2, multi-pass included.
