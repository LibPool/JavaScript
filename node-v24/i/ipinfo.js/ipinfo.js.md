# ipinfo.js

> 标签: geoip, geoip2, geoiplite, ip-info, ip-infojs, ipapi, ipapico, ipinfo, ipinfojs

## 简介

Package for retrieving GeoIP data using ipapi.co service, and checking if connection is coming from a Tor node.
