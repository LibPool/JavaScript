# inline-chat-kit

> 标签: accessible, ai, assistant, chat, chat-ui, chatbot, component-library, design-system, llm, react, streaming

## 简介

An inline AI chat experience for React. The input is the message: it morphs into the bubble, the answer streams beneath it, and the parts around it — tool calls, reasoning, questions, artifacts, dictation — come with it.
