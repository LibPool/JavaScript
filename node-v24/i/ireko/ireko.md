# ireko

> 标签: auto-layout, canvas, compound-graph, dagre-alternative, diagram-layout, edge-routing, elkjs-alternative, graph-drawing, graph-layout, group-layout, hierarchical-layout, layout-engine, nested-graph, radial-tree, react-flow, subflows, svg, tree-layout, typescript, xyflow

## 简介

Composable graph and tree layout for TypeScript. Select a layout for each container, and get boxes and routed edges for any renderer.
