# ibanforge-mcp

> 标签: agent-payments, anthropic, banking, base, bc-nummer, bic, claude, compliance, fintech, iban, mcp, model-context-protocol, payments, payouts, qr-bill, sanctions, sepa, swift, swiss, usdc, vop, x402

## 简介

MCP server for IBANforge — IBAN validation, BIC/SWIFT lookup, Swiss BC-Nummer (1,100+ SIX entries, refreshed monthly), EMI/vIBAN classification, SEPA + VoP reachability and compliance risk scoring.
