# is-discord-invite

> 标签: checker, discord, discord-invitation, discord-invite, discord-invite-link, discord-invite-url, identifier, invitation, invite, invite-link, invite-url, link, url, validation, validator, verification, verifier

## 简介

Verifies the presence of a Discord server invitation in a given string or message, with additional features for validating and confirming the authenticity and validity of the invitation link.
