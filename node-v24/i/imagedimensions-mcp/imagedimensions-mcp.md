# imagedimensions-mcp

> 标签: accessibility, core-web-vitals, image-optimization, images, lcp, mcp, model-context-protocol, web-performance

## 简介

MCP server that audits the images on any web page — natural vs rendered dimensions, oversized-image detection, and format breakdown. Powered by imagedimensions.com.
