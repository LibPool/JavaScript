# intellim-node-sdk

> 标签: apm, distributed-tracing, express, monitoring, observability, performance, tracing

## 简介

One-line auto-instrumentation for Node.js/Express apps — traces, metrics, and error logs sent to an IntelliM backend, with distributed trace propagation across services.
