# imprnt-plugin-telegram

> 标签: channels, claude-code, imprnt, imprnt-plugin, telegram

## 简介

imprnt plugin: your vault from your phone - an imp lair session bridged to Telegram via Claude Code channels. Recall-first phone replies, one start command, no daemon.
