# iban-bank-lookup

> 标签: bank, bank-code, bic, iban, iso13616, lookup, payments, sepa, swift, validation

## 简介

Validate an IBAN offline, then resolve it to the bank behind it - name, BIC/SWIFT, city and address for 60+ countries. No API key required.
