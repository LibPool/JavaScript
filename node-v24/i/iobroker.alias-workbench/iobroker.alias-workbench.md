# iobroker.alias-workbench

> 标签: alias, ioBroker, type-detector

## 简介

Creates aliases the comfortable way — devices that vis, Alexa and the device adapter understand. Templates do the work: shipped ones for HomeMatic and Tasmota, your own for everything else. Live values while you build, dry run before anything is written.
