# ictcontact-mcp

> 标签: ai-agent, claude, contact-center, ictcontact, ictdialer, mcp, model-context-protocol, predictive-dialer, telephony, voip

## 简介

Model Context Protocol server for ICTContact and ICTDialer. Lets AI assistants monitor outbound call-center campaigns and, with writes enabled, start and stop them.
