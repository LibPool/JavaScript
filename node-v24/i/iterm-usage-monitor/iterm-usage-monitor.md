# iterm-usage-monitor

> 标签: automation, claude-code, cron, iterm, iterm2, minimax, monitoring, terminal

## 简介

Monitor and control iTerm2 sessions from a local web admin, with AI auto-continue (MiniMax) that resumes rate-limited/idle sessions.
