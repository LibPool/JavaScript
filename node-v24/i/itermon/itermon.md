# itermon

> 标签: automation, claude-code, cron, iterm, iterm2, linux, mcp, model-context-protocol, monitoring, ssh, terminal, tmux

## 简介

Monitor and control terminal sessions from a CLI, a local web admin, or an MCP server -- iTerm2 on macOS, tmux everywhere else (including over SSH on Linux) -- with a cron scheduler for recurring sends.
