# instant-expert

> 标签: ai-agents, expert-network, experts, human-in-the-loop, mcp, openai-agents

## 简介

Let AI agents pay specific executives and experts for a short call or a written answer, charged only when they answer. Test mode, MCP helpers and an OpenAI Agents SDK integration.
