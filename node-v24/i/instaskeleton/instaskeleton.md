# instaskeleton

> 标签: animation, component, jsx-inference, lightweight, loading, loading-indicator, loading-state, performance, placeholder, pulse, react, react-loading, react-placeholder, react-skeleton, shimmer, shimmer-effect, skeleton, skeleton-loader, skeleton-loading, skeleton-screen, typescript, ui, zero-dom-scan

## 简介

Ultra-light React skeleton loader with zero DOM scanning. Automatic JSX inference, manual schema support, shimmer & pulse animations. Only ~1.65KB gzipped.
