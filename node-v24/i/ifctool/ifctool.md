# ifctool

> 标签: cli, csv, ifc, ifcJSON

## 简介

Command line tool for working with IFC models.  It extracts IFC elements by ID or types, and exports as JSON or CSV (via [json2csv](https://www.npmjs.com/package/json2csv)).
