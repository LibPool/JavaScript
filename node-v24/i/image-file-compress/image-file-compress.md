# image-file-compress

> 标签: browser, compress, compress image, cut down, cut image, file upload, gyroscope, iOS image upload, image, img, minifier, photo, upload image

## 简介

Minifiy and cut down image in the browser when it is so large. Then it will solve that image uploads by iOS is rotated with gyroscope.
