# ipc-event-emitter

> 标签: child-process, child_process, childprocess, event, event-emitter, eventemitter, events, fork, ipc, pin, pinned, process, processes, ready, spawn, state, stateful, states, sticky

## 简介

An EventEmitter wrapper for IPC between parent and child processes with support for states (AKA pinned events) and logging
