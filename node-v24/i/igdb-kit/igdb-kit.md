# igdb-kit

> 标签: apicalypse, games, igdb, igdb-api, twitch, typescript

## 简介

Fully typed IGDB API client for Node.js and Bun: result types inferred from selected fields, typed filters, automatic multiquery batching, shared rate limit and token renewal.
