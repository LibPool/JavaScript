# indstocks-mcp

> 标签: amfi, bse, claude, india, indmoney, indstocks, mcp, model-context-protocol, mutual-funds, nse, portfolio

## 简介

Read-only MCP server for the official INDstocks (INDmoney) trading API, plus AMFI mutual fund NAV data. No scraping, no order placement.
