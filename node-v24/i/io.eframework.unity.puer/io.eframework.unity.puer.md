# io.eframework.unity.puer

> 标签: eframework, puer, unity

## 简介

基于 PuerTS 的扩展模块，提供了易用的 PuerBehaviour 组件和完整的 TypeScript 开发工作流，优化了脚本调试和自动化打包。
