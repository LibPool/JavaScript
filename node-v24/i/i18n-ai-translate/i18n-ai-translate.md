# i18n-ai-translate

> 标签: ai, anthropic, auto-translate, chatgpt, claude, cli, gemini, gettext, github-action, google-gemini, i18n, i18n-tools, i18next, internationalization, json, l10n, llama, llm, locale, localisation, localization, machine-translation, ollama, openai, po, translate, translate-json, translation, translation-automation, typescript, yaml

## 简介

Auto-translate i18n locale files with AI. Translate i18next JSON, Gettext PO, Java .properties, iOS .strings, Rails YAML, and TS/JS catalogues using ChatGPT, Claude, Gemini, or local Ollama models. CLI, Node library, and GitHub Action.
