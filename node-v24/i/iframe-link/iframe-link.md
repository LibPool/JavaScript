# iframe-link

> 标签: cross-origin, events, handshake, iframe, iframe-rpc, minimalist, postmessage, postmessage-rpc, rpc, typescript

## 简介

Minimalist iframe communication for JavaScript and TypeScript, with Promise-based RPC and events over postMessage.
