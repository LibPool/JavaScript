# import-react-component

> 标签: convert-react, import-react, react, react-utility, utility

## 简介

Provides functions for easily integrating React components in CommonJS projects. Note that this package handles the integration of React's DOM into the project using React as a dependency, and does not convert JSX modules to JS.
