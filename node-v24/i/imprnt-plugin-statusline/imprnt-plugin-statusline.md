# imprnt-plugin-statusline

> 标签: claude-code, imprnt, imprnt-plugin, statusline

## 简介

imprnt plugin: a customizable status line for imp sessions - model, directory, context usage, session cost. Rides imp's --settings, never touches your Claude config.
