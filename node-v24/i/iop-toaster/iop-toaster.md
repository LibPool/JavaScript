# iop-toaster

> 标签: HTML&CSS, IOP-Toaster.js, JavaScript, JavaScript library, Toast

## 简介

Toaster is a small library that allows you to create HTML Toasts - special messages that pop up at the top of the page, informing the user about events happening on the site.
