# ipl-wallpaper

> 标签: cli, cricket, ipl, standings, wallpaper

## 简介

This npm-cli package sets the wallpaper of the system to the current IPL points table. A sample image available below. We fetch the data from https://www.iplt20.com/points-table/2020.
