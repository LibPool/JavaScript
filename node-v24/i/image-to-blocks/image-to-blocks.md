# image-to-blocks

> 标签: block-palette, blueprint, image-converter, image-to-blocks, map-art, material-list, minecraft, pixel-art, voxel

## 简介

Convert image pixels to a nearest-color block palette with a material list (Minecraft-style blueprints). Zero deps, browser + Node.

## 官网

- 官网：https://image2blocks.com
- 源码仓库：git+https://github.com/veronicalynn0528/image-to-blocks.git
- npm 页面：https://www.npmjs.com/package/image-to-blocks
