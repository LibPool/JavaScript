# ingenium-auth

> 标签: api-key, auth, authentication, ingenium, jwks, jwt, middleware

## 简介

JWT and API-key authentication middleware for Ingenium. JWKS verification with SSRF/key-confusion hardening and constant-time API-key checks. Extracted from core so apps that don't authenticate pay nothing for it.
