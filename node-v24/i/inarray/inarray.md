# inarray

> 标签: array, auto-curried, contain, contains, curried, in-array, in_array, inarray, include, includes, partial-application, point-free, pointfree

## 简介

Curried predicate which checks that a value exists in an array. Generally faster than `indexOf` across JS engines.
