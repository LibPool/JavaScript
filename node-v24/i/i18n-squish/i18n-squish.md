# i18n-squish

> 标签: angular-translate, angular-translate-loader-url, compile, express, i18n, internationalisation, lang, language, locale, node, node-watch, watch

## 简介

Watch and compile language files into single locales ready to be served to angular-translate using angular-translate-loader-url.
