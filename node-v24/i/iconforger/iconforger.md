# iconforger

> 标签: assets, cli, electron, icons, tray

## 简介

Node.js CLI that turns a single 1024x1024 icon into cross-platform app/tray assets.

## 官网

- 官网：https://github.com/yahoai/iconforge#readme
- 源码仓库：git+ssh://git@github.com/yahoai/iconforge.git
- npm 页面：https://www.npmjs.com/package/iconforger
