# idmp

> 标签: API request deduplication, API response caching, async function caching, auto retry on failure, cache async calls, cache concurrent requests, concurrent fetch cache, deduplicate network requests, fetch deduplication, idempotent API calls, network request caching, prevent duplicate API requests, retry failed API calls, swr alternative

## 简介

A lightweight TypeScript library for deduplicating and caching async function calls with automatic retries, designed for idempotent network requests in React and Node.js.
