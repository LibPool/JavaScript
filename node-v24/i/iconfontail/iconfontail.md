# iconfontail

> 标签: iconfont, iconfont-cn, iconfontail, tailwindcss

## 简介

iconfontail 可以用来集成 iconfont.cn 的图标到 Tailwind CSS 中，并借助 Tree Shaking 优化图标体积。
