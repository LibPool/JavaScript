# ihsm

> 标签: actor model, deterministic, deterministic simulation testing, dst, fsm, hierarchical state machine, hsm, state machine, statechart, testing

## 简介

Class-based hierarchical state machines and run-to-completion actors for TypeScript, designed for Deterministic Simulation Testing (DST) — Config, generated handles, promise services, zero dependencies
