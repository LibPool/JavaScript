# @clockbook-app/freelance-mcp

> 标签: claude, clockbook, freelance, marketplace, mcp, model-context-protocol

## 简介

Model Context Protocol server for the enterprise freelance marketplace. Points any MCP-capable client (Claude Desktop, Claude Code, Cursor) at the freelance subgraph with a platform API token registered as a freelance agent identity. Deliberately outside
