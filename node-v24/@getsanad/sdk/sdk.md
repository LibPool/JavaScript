# @getsanad/sdk

> 标签: authentication, ed25519, gateway, mcp, sanad, workload-identity

## 简介

TypeScript/Node client SDK for Sanad — enroll for a workload credential and attach passport auth headers to gateway (MCP) requests. Mirrors the `passport proxy` sidecar.
