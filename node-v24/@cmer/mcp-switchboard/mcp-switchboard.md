# @cmer/mcp-switchboard

> 标签: ai, claude, gateway, mcp, model-context-protocol, proxy, self-hosted

## 简介

Self-hosted MCP switchboard: configure MCP servers once, give each coding agent its own endpoint and its own set of tools.
