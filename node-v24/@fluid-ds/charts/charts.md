# @fluid-ds/charts

> 标签: chart.js, charts, data-visualization, design-system, fluid-ds, sparkline, web-components

## 简介

Chart web components for Fluid (expansion pack), backed by Chart.js. Bar, line, pie, doughnut, scatter, bubble, radar, polar area, and inline sparkline.
