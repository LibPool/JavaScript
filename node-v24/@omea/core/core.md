# @omea/core

> 标签: apple-silicon, docker, hvf, hypervisor, macos, microvm, oci, sandbox, snapshot, vm

## 简介

Run any OCI/Docker image as a hardware-isolated microVM. Node/Bun/Deno binding for the Omea Rust crate.
