# dsh-win-pwsh7

> 标签: deepseek-harness, dsh, dsh-plugin, powershell, pwsh, windows

## 简介

Detect, validate, and (on request) install PowerShell 7 for the Harness pwsh tool on Windows — the self-updating Microsoft Store package by default, with the connection checked first because Windows defers Store downloads on a metered connection — and pin
