# @park-sang-gwon/google-flow-mcp

> 标签: claude, google-flow, mcp, mcp-server, model-context-protocol, modelcontextprotocol, playwright, scene-builder, veo, video-generation

## 简介

Unofficial MCP server that drives Google Flow (labs.google Veo / Nano Banana) through your own Chrome session — video & image generation plus Scene Builder (extend, jump to, download)
