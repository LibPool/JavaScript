# @connexum/n8n-nodes-connexum

> 标签: ai-agents, governance, my-cc, n8n-community-node-package

## 简介

n8n community node: Connexum Govern puts any n8n workflow step under My-CC governance. Each item passes data readiness (the source's access for the agent's passport) and the runtime gate (the governance server's check-action) before the next node runs; it
