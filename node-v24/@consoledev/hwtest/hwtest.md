# @consoledev/hwtest

> 标签: cli, hardware-in-the-loop, playstation, ps1, psx, test-farm

## 简介

Command-line client for the remote hardware test farm: run PlayStation executables on real consoles and get the serial log back.

## 官网

- 官网：https://hwfarm.consoledev.net/
- npm 页面：https://www.npmjs.com/package/@consoledev/hwtest
