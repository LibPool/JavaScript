# @quilla-be-kit/security

> 标签: authentication, authorization, bearer, jwt, password, security, session, token, typescript

## 简介

Security primitives: Token/TokenService, PasswordHasher, SessionStore interfaces, and auth middlewares (Bearer-token verification + authenticated-session enrichment) that plug into @quilla-be-kit/http's Router.
