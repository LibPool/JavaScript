# dsh-usage-board

> 标签: JavaScript

## 简介

DSH 能力插件:合并 dsh-usage-stats 会话日志与 dsh-oauthpro 渠道账本的用量看板(渠道/模型/凭证/日趋势 + 自动刷新 + 周期可选)
