# @theunipay/stealth

> 标签: bitcoin, erc-5564, ethereum, payments, privacy, solana, stealth-address, unipay, wallet, web3

## 简介

UniPay stealth engine — one meta-address (UDA) derives private one-time addresses on Bitcoin, EVM, and Solana. Address-less, non-custodial, framework-agnostic (Node, browser, React Native / Expo Go).
