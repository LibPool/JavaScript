# review-seal

> 标签: ai-agents, audit, claude, claude-code, claude-code-plugin, code-review, git-hooks, github-action, pre-commit, review

## 简介

Claude Code plugin, pre-commit hook and GitHub Action. A separate Claude Code session reviews changed files against your checklist. Commits wait until the review is current.
