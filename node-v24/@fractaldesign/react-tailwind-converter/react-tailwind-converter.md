# @fractaldesign/react-tailwind-converter

> 标签: ast, cli, codemod, converter, react, sass, scss, svelte, svelte5, tailwind, tailwindcss

## 简介

AST-based CLIs: Tailwind classes → indented Sass (real Tailwind v4 engine), and React (TSX/JSX) → Svelte 5 (Babel).
