# @fractaldesign/icons-animated

> 标签: animated, animation, flowbite, heroicons, icons, ionicons, phosphor, remix, svelte, svelte5, svg, web-animations

## 简介

Animated icons for Svelte 5: over 4,000 icons from Phosphor, Remix, Flowbite, Heroicons and Ionicons, with 22 animation templates on the Web Animations API.
