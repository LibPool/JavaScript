# @revyme/plugin-sdk

> 标签: iframe, plugin, revyme, sdk

## 简介

Authoring SDK for Revyme plugins. Plugin code calls createPlugin() to handshake with the editor host and obtain a typed canvas/CMS/etc. SDK over postMessage.
