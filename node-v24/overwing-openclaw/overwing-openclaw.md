# overwing-openclaw

> 标签: agents, guardrails, moderation, openclaw, openclaw-plugin, pii, x402

## 简介

OpenClaw plugin: Overwing's send gate on every outbound message, reply and tool call. Shadow mode by default; pays per check with an API key, an x402 wallet (ClawRouter's works), or the free allowance.
