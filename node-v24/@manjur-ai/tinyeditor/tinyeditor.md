# @manjur-ai/tinyeditor

> 标签: contenteditable, dark-mode, markdown, media-embed, mobile-first, no-build, rich-text-editor, tiny-editor, tinyeditor, url-preview, wysiwyg, youtube-embed, zero-dependency

## 简介

Zero-dependency, mobile-first rich text editor with URL preview, image upload, Markdown shortcuts, and media embeds. ~45KB. No build step.
