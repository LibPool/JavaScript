# @alfred/validate

> 标签: JavaScript

## 简介

* Take either a path to a json file or an object   * If object given, JSON.stringify and format with prettier * Find the line number of the stringified object * Add helpful CLI options (provided by jest-validate)   * Showing inline examples   * Deprecated
