# @gulfofmaine/tsstac

> 标签: JavaScript

## 简介

TsSTAC is designed as a [Sans-I/O style library](https://sans-io.readthedocs.io/index.html) for loading and managing [SpatioTemporal Asset Catalogs](https://stacspec.org/).
