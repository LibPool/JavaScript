# @autorender/strapi

> 标签: autorender, cdn, dam, media-library, plugin, strapi, strapi-plugin, upload-provider

## 简介

Strapi v5 admin plugin for AutoRender — use AutoRender as your Strapi Media Library upload provider and import existing AutoRender DAM assets by reference.
