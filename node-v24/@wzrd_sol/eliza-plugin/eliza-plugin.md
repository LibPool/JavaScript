# @wzrd_sol/eliza-plugin

> 标签: eliza, elizaos, intel, merchant_card, preflight, receipt, solana, trust, v7, wzrd, x402

## 简介

WZRD Agent Intel for ElizaOS. Free preflight ReadinessCard + merchant_card (wash_flagged refuse default), paid GET /v1/intel/trust (~0.05 USDC) V7 receipt, offline verify via twzrd-receipt-verifier. Legacy earn loop is opt-in via createWzrdPlugin({ legacy
