# @greenmice/strapi-passwordless-plugin

> 标签: authentification, login, passwordless, plugin, strapi

## 简介

A plugin for Strapi Headless CMS that provides ability to sign-in/sign-up to an application by link had sent to email.

## 官网

- 官网：https://github.com/greenmice/strapi-plugin-passwordless
- npm 页面：https://www.npmjs.com/package/@greenmice/strapi-passwordless-plugin
