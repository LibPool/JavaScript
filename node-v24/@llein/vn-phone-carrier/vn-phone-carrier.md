# @llein/vn-phone-carrier

> 标签: carrier, e164, mobifone, otp, phone, react-hook, sms, telecom, typescript, use-phone, utility, vietnam, vietnamobile, viettel, vinaphone, zero-dependency

## 简介

Detect Vietnamese mobile network operators (Viettel, Vina, Mobi, Vietnamobile, Wintel, I-Telecom), landlines, 11-to-10 digit migration, and E.164 phone formatting with React Hook useVNPhone.
