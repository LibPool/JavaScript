# @yaebal/rich

> 标签: rich-message, sendRichMessage, sendRichMessageDraft, streaming, telegram, telegram-bot, yaebal

## 简介

yaebal rich — sendRichMessage / sendRichMessageDraft: a typed block builder, a 30s-ttl draft/streaming session, and full read-side coverage of telegram's rich message model.
