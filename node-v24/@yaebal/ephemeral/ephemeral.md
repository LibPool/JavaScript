# @yaebal/ephemeral

> 标签: ephemeral, telegram, telegram-bot, yaebal

## 简介

yaebal ephemeral — reply in a group so only one user sees it: ctx.replyEphemeral() with a typed edit/delete handle and a private-chat fallback.
