# @chromamark/renderer

> 标签: admonition, callout, chromamark, commonmark, gfm, markdown, markdown-it, markdown-it-plugin

## 简介

ChromaMark renderer — a markdown-it plugin adding colored blocks, colored pills, collapsible sections, fields, meters and inline diff on top of CommonMark + GFM.
