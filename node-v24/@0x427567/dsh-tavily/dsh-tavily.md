# @0x427567/dsh-tavily

> 标签: deepseek-harness, dsh, dsh-plugin, keyless, plugin, tavily, web-search

## 简介

Tavily-backed search provider for the DeepSeek Harness web seam (ctx.web): keyless-first credentials, a cooldown after the keyless tier refuses, and a user-visible notice when it falls back to the key.
