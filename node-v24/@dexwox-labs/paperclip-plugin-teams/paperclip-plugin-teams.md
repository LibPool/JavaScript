# @dexwox-labs/paperclip-plugin-teams

> 标签: adaptive-cards, microsoft-teams, notifications, paperclip, paperclip-plugin

## 简介

Microsoft Teams Chat OS for Paperclip: v1 Adaptive Card notifications via Power Automate Workflows webhooks; v2 interactive bot (approvals, commands) on the Microsoft 365 Agents SDK.
