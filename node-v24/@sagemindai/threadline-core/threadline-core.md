# @sagemindai/threadline-core

> 标签: JavaScript

## 简介

Threadline's agent-to-agent fundamentals with no framework attached: identity keys, end-to-end encrypted and signed envelopes, pairing by invite, pinned keys and the credential gate. Used by threadline-mcp and Instar.
