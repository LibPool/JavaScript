# @nuria-tech/auth-sdk

> 标签: auth, authentication, dpop, oauth2, oidc, passkey, pkce, sdk, webauthn

## 简介

Browser OAuth 2.1 (Authorization Code + PKCE) client SDK. Google login uses Google Identity Services (FedCM); federated OIDC IdPs use code+PKCE bridge exchange; magic-link (passwordless), password, 2FA, and passkey (WebAuthn) login; optional DPoP sender-c
