# @emlab/wye

> 标签: claude-code, codex, coding-agents, knowledge-graph, local-first, markdown, memory, product-definition, requirements

## 简介

Product definition and long-term memory for coding agents: requirements, rules, decisions and constraints as Markdown in Git, a graph Claude Code and Codex query before they build, and an app to review what they decide.
