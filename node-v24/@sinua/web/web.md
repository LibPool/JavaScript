# @sinua/web

> 标签: animation, canvas, custom-element, orb, react, visualizer, voice-ui, web-component

## 简介

Drop-in Web renderer for Sinua: the shared paint contract, mount(canvas, options), an optional React <SinuaView/>, and the <sinua-view> custom element
