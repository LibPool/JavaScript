# @sinua/core

> 标签: agent, animation, canvas, orb, rust, visualizer, voice-ui, wasm

## 简介

TypeScript bridge over the Sinua Rust geometry engine (wasm-bindgen; the wasm is inlined, so no bundler config is needed)
