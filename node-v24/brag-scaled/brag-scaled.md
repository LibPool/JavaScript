# brag-scaled

> 标签: agent-skills, claude-code, claude-code-plugin, codex, demo-video, gpu, launch-video, motion-graphics, opencode, render, skill, tts, video

## 简介

One-command installer for brag-scaled: agent skills that turn a project, a running site or a script into a short video that moves like a demo, drawn on the GPU in parallel browsers.
