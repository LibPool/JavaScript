# @likemiens/aura

> 标签: custom-element, dashboard, data-visualization, gauge, no-dependencies, open-meteo, tiles, weather, web-component, widgets

## 简介

Glowing data tiles as Web Components: any number, or the weather in one call. Ten gauges, states and a board people can rearrange. No dependencies.
