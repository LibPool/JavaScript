# @yarn-tool/path-parents

> 标签: dependencies, lerna, npm, package, packages, pkg, workspaces, yarn, yarn-tool

## 简介

列出從當前目錄向上搜尋至工作區根目錄的路徑列表。List paths from the current directory up to the workspace root.
