# @truxie/drizzle

> 标签: drizzle, drizzle-orm, postgres, transaction, truxie

## 简介

Drizzle ORM for truxie — a lazily-connected database, an ambient TransactionHost with savepoints and after-commit hooks, a transaction interceptor and a health indicator
