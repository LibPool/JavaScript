# @truxie/rpc

> 标签: bridge, guard, http-client, microservice, rpc, service-to-service, truxie

## 简介

Service-to-service calls for truxie — a typed HTTP bridge client with connect-retry, timeout and correlation, plus the API-key guard for the receiving side
