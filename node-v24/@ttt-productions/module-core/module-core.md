# @ttt-productions/module-core

> 标签: dynamic-import, lazy, module

## 简介

How a module is loaded lazily: lazyModule, the one memoized dynamic import every lazy load goes through, so concurrent callers share one import. Tier 0 — no dependencies, no React, server-safe.
