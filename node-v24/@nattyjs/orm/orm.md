# @nattyjs/orm

> 标签: database, dbcontext, entity-framework, mssql, mysql, natty, nattyjs, nodejs, orm, postgresql, sql, typescript

## 简介

Entity Framework-style ORM for TypeScript with DbContext, DbSet queries, stored procedures, change tracking, and SQL database support.
