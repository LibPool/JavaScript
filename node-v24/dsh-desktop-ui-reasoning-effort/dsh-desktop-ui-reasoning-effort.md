# dsh-desktop-ui-reasoning-effort

> 标签: deepseek-harness, dsh, dsh-plugin, reasoning, thinking

## 简介

DSH plugin: configure per-model reasoning effort levels for custom pi-ai providers in the Models settings page, with presets for GPT, Claude, Grok, GLM and MiMo models.
