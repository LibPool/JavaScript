# @osdlc/yaml-splice

> 标签: byte-identical, comments, edit, frontmatter, lossless, wasm, webassembly, yaml

## 简介

Edit top-level fields of a YAML mapping in place, on bytes: set, remove or rename a field, and every byte outside the edited span stays as it was, including comments, key order, quoting, a BOM and line endings. The yaml-splice Rust crate, built to WebAsse
