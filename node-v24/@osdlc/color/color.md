# @osdlc/color

> 标签: color, colour, contrast, css, luminance, srgb, typescript, wcag

## 简介

sRGB colour arithmetic: parse the CSS colour syntaxes a browser reports, mix and composite in gamma-encoded sRGB, and measure WCAG 2 relative luminance and contrast. No dependencies.
