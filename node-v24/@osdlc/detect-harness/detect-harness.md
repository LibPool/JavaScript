# @osdlc/detect-harness

> 标签: agent, claude-code, codex, cursor, detect, harness, hooks, mcp, plugin, zod

## 简介

Find the coding-agent harnesses (Claude Code, Codex, Cursor, opencode, pi, Antigravity) on a machine and in a project, and read what each has configured: plugins, skills, hooks, MCP servers, permissions, instructions and sign-in evidence. Read-only; MCP e
