# @miadi/ncp-wampum-bridge

> 标签: belt, headless, miadi, narrative, ncp, two-eyed-seeing, wampum

## 简介

The crossing between the NCP story model and the Wampum belt model: project a narrative onto a belt, read a belt back, and get a crossing report naming everything that did not carry across. The only package that knows both engines.
