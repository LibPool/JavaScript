# @miadi/songbird-ui

> 标签: miadi, midi, piano-roll, react, singing, songbird

## 简介

React surface for a Songbird take: the piano roll of a sung phrase (rows for the pitches sung, blocks coloured by intonation, ghosts where alignment moved a note, beat lines) and the take card that plays it, plays the voice, and carries the singer's note
