# @miadi/annotate-core

> 标签: annotation, headless, miadi, plannotator, review, vanilla

## 简介

Annotate a document by block or by exact words, signed, and hand the review on, without a framework: the vocabulary, the annotator's behaviour as plain functions, quote and author resolution, an HTML-string renderer, a vanilla DOM mount with the iOS-safe
