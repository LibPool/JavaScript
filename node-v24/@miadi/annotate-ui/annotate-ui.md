# @miadi/annotate-ui

> 标签: annotation, miadi, react, review

## 简介

The React host of @miadi/annotate-core: mark a document by block or by exact words, signed, see everyone's marks, and hand the review on. Core owns the vocabulary, behaviour and markup; this package owns React state and events. It holds no URL or token: a
