# @denreport/core

> 标签: denreport, intermediate-representation, invoice, ir, json-schema, parser, pdf, report, validator

## 简介

Open, versioned JSON intermediate representation (IR) for business documents (invoices, delivery notes, receipts), with a parser, a validator, and per-target compatibility matrices. No UI, no rendering.
