# @hcd-bsas/loading

> 标签: JavaScript

## 简介

Desde el archivo loading.js se exporta la clase **LoadingHCD** la cual permite mostrar o ocultar el html **/src/template.html** que contiene la animación del overlay con el Logo en SVG.
