# @meterapp/meter-sdk

> 标签: agents, fleet, mcp, meter, sdk, taxi

## 简介

Shared contracts for Meter's public AI surface: the MCP tool catalog, public DTO schemas, machine-readable field docs and a tiny MCP JSON-RPC client. Zero runtime dependencies beyond zod.
