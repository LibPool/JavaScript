# @meterapp/glossa-next

> 标签: glossa, hreflang, i18n, l10n, language-picker, language-switcher, next, next-intl, nextjs, translation

## 简介

Language picker, "Translated by Glossa" badge and machine-readable translation attribution (JSON-LD, llms.txt, meta tag, headers) for Next.js sites translated with Glossa.
