# @bearly/tribe-client

> 标签: claude-code, cli, client, ipc, json-rpc, mcp, stdio-adapter, tribe, unix-socket

## 简介

Tribe client library — Unix-socket IPC, JSON-RPC 2.0 wire protocol, parser, daemon client, auto-start, reconnection, composition primitives (pipe/Scope/Tool registry), the stdio MCP adapter that bridges Claude Code's stdio wire to the tribe daemon socket,
