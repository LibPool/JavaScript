# @gsp-lcm/lcmcomponent

> 标签: JavaScript

## 简介

包含的具体内容：     业务对象导航，    工程操作界面，    文件树，    git面板，    元数据选择，    nuget包引用等界面。 每块内容都独立的作为app，能够单独打包，部署，并且能够单独运行展示界面。
