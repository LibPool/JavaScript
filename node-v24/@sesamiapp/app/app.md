# @sesamiapp/app

> 标签: JavaScript

## 简介

Sesami embedded-app runtime for React Router: the sesamiApp() factory, HMAC/JWT/OAuth auth, the SesamiAdminApi GraphQL client, session-storage adapters, and React host-bridge providers.
