# @kaitox/relay-protocol

> 标签: draft, kaitox, markdown, protocol, relay, toolkit

## 简介

Wire contract and portable HTTP client for the Kaitox draft relay: DraftBundle types, RelayClient interface, HttpRelayClient (Node & browser), base64 helpers. Zero dependencies.
