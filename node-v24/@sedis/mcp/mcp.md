# @sedis/mcp

> 标签: bolagsanalys, fastighetsbenchmark, financial-data, llm-tools, mcp, model-context-protocol, modelcontextprotocol, partnerapi, real-estate, sedis

## 简介

MCP server for Sedis property data — bolagsanalys of listed Nordic real estate companies and fastighetsbenchmarking of your own portfolio. Cleaned quarterly financials, substansrabatt/substanspremie, and market data via the Sedis PartnerAPI.
