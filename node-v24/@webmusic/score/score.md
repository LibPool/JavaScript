# @webmusic/score

> 标签: abc-notation, midi, music, music-analysis, music-notation, musicxml, mxl, piano-roll, playback, react, score, synthesizer, web-components, webmusic

## 简介

Symbolic music for the web: immutable score model, MIDI/MusicXML/MXL/ABC I/O, playback, analysis, views, Web Components and React bindings.
