# @webmusic/bridge

> 标签: bridge, music, score, sync, typescript, web-audio, webmusic

## 简介

Bridge between the score and audio families of the WebMusic ecosystem: synchronized score+audio playback on one AudioContext clock, score-to-clip offline rendering, and TimeMap/BeatGrid conversions. The only package allowed to import both families.
