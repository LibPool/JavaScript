# @openemt/openemt

> 标签: ai-agents, circuit-simulator, electrical-engineering, electromagnetic-transient, emt, emtp, mcp, model-context-protocol, power-engineering, power-flow, power-systems, simulation

## 简介

OpenEMT: an agent-native electromagnetic transient (EMT) and power-flow simulator for AC, DC and hybrid power systems. One deterministic solver core behind three coequal frontends: a browser canvas, a CLI, and an MCP server.
