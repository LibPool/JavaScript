# wifi-speed-customlayer

> 标签: custom-layer, map, maplibre, maplibre-gl, maplibre-gl-js, wifi, wifi-speed

## 简介

A MapLibre GL JS custom layer that shows crowd-sourced Wi-Fi speed spots from wifi.pancake-trail.site, with register/delete hand-off buttons. No API key required.
