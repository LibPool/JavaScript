# @kulinda-sec/bugsecure-mcp

> 标签: bug-bounty, bugsecure, mcp, model-context-protocol, oauth, security

## 简介

Model Context Protocol server for the BugSecure bug bounty platform: browse programmes, work on your reports and triage — with OAuth 2.1, least-privilege scopes and prompt-injection-aware output.
