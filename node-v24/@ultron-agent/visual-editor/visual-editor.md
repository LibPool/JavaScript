# @ultron-agent/visual-editor

> 标签: JavaScript

## 简介

DeliverHub 可视化编辑引擎：vendor 自 Onlook（Apache-2.0）的 TSX 源码编辑内核（AST 动作全集 + oid 锚定 + 模板节点映射），三层架构 engine / vite / runtime，集成进模板项目 Vite dev 与 chat-web 工作台。
