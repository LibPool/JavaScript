# @vexify/xql

> 标签: codegen, compiler, document-database, embedded, mongodb, nosql, query, query-language, sql

## 简介

XQL — eXtend Query Language. Extends SQL over documents with the speed of hand-written JS (compiled to closures/code, no AST walking).
