# @sentinelreign/guard-proxy

> 标签: firewall, mcp, mcpgrade, model-context-protocol, proxy, scanner, security, stdio

## 简介

Stdio sidecar firewall for MCP servers, plus the free mcpgrade scanner. Sits between an IDE and the server it auto-executes.
