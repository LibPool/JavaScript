# mcp-repo-auditor

> 标签: agents-md, ai-rules, claude, code-review, compliance, copilot, cursor, cursorrules, git, kiro, lint, mcp, mcp-server, model-context-protocol

## 简介

Local MCP server that audits your git changes against the repo's own AI rules (AGENTS.md, CLAUDE.md, .cursorrules, Copilot, Kiro, skills) and returns a compliance table or an HTML report.
