# mithril-lynx-ui

> 标签: JavaScript

## 简介

A component library for mithril-lynx apps, visually identical to @lynx-js/lynx-ui (same Luna CSS tokens) — components ported/rebuilt for Mithril's component model instead of ReactLynx.
