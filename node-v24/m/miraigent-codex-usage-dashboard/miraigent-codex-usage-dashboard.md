# miraigent-codex-usage-dashboard

> 标签: codex, dashboard, openai, quota, usage

## 简介

Codexの使用量を毎回探さずに、1アカウントでも複数アカウントでも残量・5時間制限・週次上限・リセット時刻を一覧で確認できるローカルWebダッシュボード / Local dashboard for Codex usage across one or multiple accounts.
