# mdlua

> 标签: 68000, ahead-of-time, aot, emulator, fm-synth, game-development, gamedev, genesis, homebrew, lua, luacretro, m68k, mega-drive, megadrive, pico-8, pico8, retro, retrogaming, rom, sega, sgdk, vgm, wasm, webassembly, xgm2

## 简介

Write Sega Mega Drive / Genesis games in a PICO-8-flavored Lua that compiles to native 68000 via SGDK. Full SGDK API surface, XGM2 music, PCM sfx, PNG asset pipeline, bundled WASM toolchain and emulator - no devkit install.
