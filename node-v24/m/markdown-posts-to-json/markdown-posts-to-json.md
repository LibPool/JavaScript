# markdown-posts-to-json

> 标签: JSON, JavaScirpt, Markdown, Webpack

## 简介

将 Markdown 格式的文章（.md）后缀，提取元数据，并使用 Markdown-it 将文章内容转化为 Html，最后输出为 json 文件。
