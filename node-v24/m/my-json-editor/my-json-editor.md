# my-json-editor

> 标签: json-editor, json-editor-vue, json-editor-vue3, json-scheme-editor-vue, jsoneditor, vite, vue, vue3, vuejsoneditor

## 简介

基于 `jsoneditor` 开发的vue3 json editor，支持全屏编辑，有完善的事件回调，可以在失去焦点时，对编辑器内容做校验。
