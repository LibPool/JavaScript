> 标签: analytics, claude, cursor, ecommerce-events, ga4, ga4-mcp, google-analytics, google-analytics-data-api, mcp, measurement-protocol, model-context-protocol, server-side-tracking

## 简介

GA4 MCP server that reads AND writes: run reports and funnels (Data API), audit your setup (custom dimensions, key events, compatibility checks), and send events server-side (Measurement Protocol v2)
