# my-ts-component

> 标签: JavaScript

## 简介

- 这是一个 npm 组件包的创建示例 - 封装一个组件如本项目，MyButton - 执行 npm login 登录 npm 账号 - 执行打包 npm run build 生成 dist 目录 - 执行 npm publish 发布组件包到 npm 仓库 - 发布成功后，在项目中使用 npm install 组件包即可使用 - vite-plugin-dts 用于生成 d.ts 文件，方便 typescript 项目引用 - 每次执行执行 npm publish 时，需修改 package.json
