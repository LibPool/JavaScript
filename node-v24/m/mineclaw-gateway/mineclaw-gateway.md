# mineclaw-gateway

> 标签: JavaScript

## 简介

mineclaw 的本地 HTTP/WebSocket 网关，把 coding agent 的会话能力暴露为一组 REST + WebSocket API，并附带一个用于鉴权和模型管理的 CLI。
