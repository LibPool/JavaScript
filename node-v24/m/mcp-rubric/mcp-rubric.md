# mcp-rubric

> 标签: cli, developer-tools, linter, mcp, model-context-protocol, scanner

## 简介

Rubric CLI — Postman + ESLint for MCP servers. Runs the web UI and CI scans that score MCP protocol conformance, quality, and security.
