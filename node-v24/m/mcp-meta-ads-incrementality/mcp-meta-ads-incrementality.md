# mcp-meta-ads-incrementality

> 标签: advertising, agency, attribution, facebook-ads, incrementality, marketing-api, mcp, meta-ads, model-context-protocol

## 简介

MCP server for Meta Marketing API focused on incrementality reporting. Surfaces Meta's incremental conversion attribution alongside default 7d-click/1d-view and dda windows so agencies can see the gap between reported and incremental performance.
