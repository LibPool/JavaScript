# mcp-personal-suite

> 标签: byok, calendar, claude, cursor, discord, email, image-generation, local-first, mcp, mcp-server, messaging, model-context-protocol, personal-assistant, search, self-hosted, slack, telegram, whatsapp

## 简介

Local-first personal productivity MCP server for Claude, Cursor, and any MCP client. Email, Calendar, Messaging, Search, Image Generation. BYOK, no cloud, no signup.
