# map0-check

> 标签: capabilities, cli, cors, gis, map0, ogc, ogc-api-features, wfs, wms, wmts

## 简介

Can map0 show this OGC service? Probes a WMS, WMTS, WFS or OGC API Features endpoint with the requests map0 sends and prints the verdict plus the layer definition
