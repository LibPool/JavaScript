# microsoft365-mcp-server

> 标签: ai-assistant, claude, fastmcp, mcp, microsoft-365, microsoft-graph, model-context-protocol, onedrive, outlook, teams

## 简介

A Model Context Protocol (MCP) server for Microsoft 365 - manage mail, calendar, contacts, files, Teams, Planner, OneNote, To Do, and more via Microsoft Graph.
