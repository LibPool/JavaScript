# mantyl

> 标签: agentic, ai, audit, claude-code, cli, codex, coding-agent, cursor, docker, handover, passport, provenance, software-handover, verification, verify

## 简介

The handover layer for AI-built software. Local-first: scan, verify and generate a project passport, no account required.
