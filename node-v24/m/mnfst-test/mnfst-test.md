# mnfst-test

> 标签: ai, check, happy-dom, lint, manifest, mnfst, test, testing, validation, vitest

## 简介

Testing toolkit for Manifest projects — `mnfst-test` CLI for project linting (typo'd tags, dead sources, syntax errors, console errors, a11y, broken links) and `mountManifest()` library for component-level tests with Vitest + happy-dom
