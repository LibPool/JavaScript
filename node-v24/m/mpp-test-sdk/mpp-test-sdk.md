# mpp-test-sdk

> 标签: 402, devnet, machine-to-machine, mpp, mpp32, pay-per-request, payments, sdk, solana, test

## 简介

Test pay-per-request APIs on Solana devnet. Auto-creates wallets, airdrops SOL, handles 402 MPP payments - zero setup required.
