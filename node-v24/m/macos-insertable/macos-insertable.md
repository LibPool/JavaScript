# macos-insertable

> 标签: accessibility, automation, axuielement, dictation, focused-field, macos, paste, text-insertion

## 简介

Find the focused text field of any macOS application, learn whether text can be inserted there, and insert it — verified, safely, through the Accessibility API with clipboard and keystroke fallbacks.
