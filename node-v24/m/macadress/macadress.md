# macadress

> 标签: api-client, deno, ieee, mac address, mac-address, mac-vendor, macadress, oui, sdk, typescript, vendor-lookup

## 简介

Official JavaScript and TypeScript client for the macadress.com MAC address and OUI vendor lookup API. Runs on Node, Deno, Bun and browsers, with zero dependencies.

## 官网

- 官网：https://macadress.com
- 源码仓库：git+https://github.com/sapisos/macadress-js.git
- npm 页面：https://www.npmjs.com/package/macadress
