# mm_render

> 标签: content-type, html, mm_middleware, mm_mod, render, web

## 简介

这是超级美眉页面渲染中间件，用于在 web 请求管道中识别并标注页面渲染结果，使 HTML 页面以正确的 text/html 内容类型输出。
