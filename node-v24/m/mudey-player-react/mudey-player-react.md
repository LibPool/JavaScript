# mudey-player-react

> 标签: JavaScript

## 简介

MudeyPlayer est une bibliothèque React qui vous permet d'intégrer facilement un lecteur vidéo personnalisable dans votre application web. Il offre des fonctionnalités de base pour la lecture vidéo, ainsi que des options de personnalisation pour l'adapter
