# mysql-axi

> 标签: agent, axi, cli, mysql, read-only, sql, toon

## 简介

Read-only MySQL CLI for agents - schemas, sample rows, capped SELECT/SHOW/DESC/EXPLAIN queries in token-efficient TOON. Writes are refused by a client-side guard plus a read-only session; not a grant check.
