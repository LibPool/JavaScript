# modelguild

> 标签: anthropic, claude-code, code-review, codex, llm, mcp, model-context-protocol, multi-model, opencode

## 简介

An MCP server fronting opencode and native Codex workers, letting Claude Code and Codex collaborate with other LLMs (consult, panel, research, review, delegate). Ships Claude slash commands, Codex skills, and opencode agents; `npx modelguild init` wires i
