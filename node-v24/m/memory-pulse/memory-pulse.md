# memory-pulse

> 标签: agent-memory, claude-code, codex, context, mcp, memory, modelcontextprotocol, token-savings

## 简介

Corrections that outlive the session. memory-pulse surfaces a correction first in every session and blocks the edit that writes the old value back. Four MCP tools, ~900 tokens. Claude Code, Codex, Cursor, GitHub Actions.
