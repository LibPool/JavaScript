# migrate-mongostore

> 标签: migrate, migrations, mongo, node-migrate

## 简介

Node-migrate adapter that uses mongo to track migrations. Install node-migrate and this adapter

## 官网

- 源码仓库：git://github.com/sloops77/node-migrate-mongostore
- npm 页面：https://www.npmjs.com/package/migrate-mongostore

- npm registry：https://registry.npmjs.org/migrate-mongostore
- Node 要求：>= 0.4.x
