# micro-key-producer

> 标签: GPG, PGP, RFC 4880, RFC 6637, SSH, TOR, ec, ed25519, elliptic, key generation, onion, x509

## 简介

Produces secure passwords & keys for WebCrypto, SSH, PGP, SLIP10, OTP and many others
