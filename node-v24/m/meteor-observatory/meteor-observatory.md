# meteor-observatory

> 标签: Coverage, Jasmine, Meteor, React

## 简介

Observatory is a complete Meteor 1.6+ testing and coverage suite based on Velocity and meteor-coverage.  Designed for drop-in integration, it will run Jasmine tests and report in real time to the browser as code changes the pass/fail of tests and code cov
