# mcp-img-compress-oss

> 标签: aliyun, claude, compression, cursor, image, mcp, mcp-server, model-context-protocol, optimization, oss, upload

## 简介

图片无损压缩与OSS上传MCP工具，可以让AI将项目中的图片资源无损并上传至阿里云 oss 用 cdn 链接替换图片资源
