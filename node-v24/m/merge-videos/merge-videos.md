# merge-videos

> 标签: cli, combine, concat, ffmpeg, m4v, merge, mkv, mp4, video, video-concat, video-merge

## 简介

Merge all videos inside a directory (recursively) into a single video file. Supports mp4, mkv, m4v, and ts formats.
