# maishu-jueying

> 标签: JavaScript

## 简介

Jueying 是一个基于 React、TypeScript 与 Ant Design 生态的可视化页面设计与属性编辑库。仓库同时包含一个可运行的 Demo 应用，用于演示组件设计器、属性编辑器、DataList / ProTable 等页面构建能力。
