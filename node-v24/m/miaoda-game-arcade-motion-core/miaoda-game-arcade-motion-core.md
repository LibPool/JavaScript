# miaoda-game-arcade-motion-core

> 标签: arcade, car, cocos, endless-runner, handling, lane, on-rails, outrun, phaser, racing, runner, skiing, strafe

## 简介

Engine-agnostic arcade motion core for forward-advance and lateral-strafe games. Includes LaneRunner for endless runners, skiing and on-rails movement, plus RacerCar for speed-scaled steering, curve drift and off-road grip loss. Frame-rate independent wit
