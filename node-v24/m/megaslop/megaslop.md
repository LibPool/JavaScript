# megaslop

> 标签: ai-slop, detector, generator, meta-package, slop, toolchain

## 简介

The complete slop toolchain in one install: generate it (slopgen, technoslop, slopbot, slopfest, sloptown), mass-produce it (slopacalypse), and detect it (slopcore). One dependency, maximum slop.
