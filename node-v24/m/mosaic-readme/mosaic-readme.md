# mosaic-readme

> 标签: JavaScript

## 简介

所有使用 mosaic 客户端开发的 Brix 组件，不关是核心组件还是业务组件，均可使用一份同一的 README，本 NPM 模块用来处理这份 README 格式，在 mosaic 与 mosaic-daemon 中均有使用。
