# monkeysee-bridge

> 标签: browser-automation, chrome-extension, claude-code, codex, mcp, model-context-protocol, monkeysee

## 简介

MCP server that lets an MCP client (Claude Code, Codex, any MCP client) drive a real, logged-in Chrome profile. Ships the MonkeySee Chrome extension bundled.
