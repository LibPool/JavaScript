# mocxykit

> 标签: API, dependencies, express, express middleware, middleware, mock, proxy, visualization, visualization configuration, vite, vite-dev-server, vite-dev-server-mock, vite-mock, vite-proxy, webpack, webpack-dev-server, webpack-dev-server-mock, webpack-mock, webpack-proxy

## 简介

This is an express middleware that can be used with webpack and vite. Its main function is to visualize the configuration, manage proxies, and mock data.
