# maplibregl-filter-legend

> 标签: JavaScript

## 简介

A legend control for maplibre-gl that allows 1) legend entries to control multiple layers, 2) layers to be referenced by multiple layers, and 3) the hiding of features based on a legend entry's filter expression.
