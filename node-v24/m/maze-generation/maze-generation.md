# maze-generation

> 标签: backtracker, depth, depth-first, first, gen, generator, hunt-and-kill, huntandkill, maze, maze-gen, procedural, recursive, reproducible, seed

## 简介

A package to generate mazes using the depth first or hunt and kill algorithm. Mazes can be generated with seed values for reproducibility
