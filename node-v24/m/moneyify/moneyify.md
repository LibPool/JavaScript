# moneyify

> 标签: allratestoday, big.js, cashify, conversion, convert, currency, currency-conversion, currency-converter, exchange, exchange-rate, forex, fx, mid-market, money, money.js, moneyify, refinitiv, reuters, typescript

## 简介

Lightweight currency conversion library — cashify-compatible API with optional auto-fetch from the AllRatesToday API. 160+ currencies, mid-market rates, zero runtime deps.
