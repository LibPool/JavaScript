# maileva

> 标签: JavaScript

## 简介

> Client TypeScript non-officiel pour interagir avec l’ensemble des APIs Maileva à partir des spécifications OpenAPI. Basé sur [`openapi-fetch`](https://openapi-ts.dev/openapi-fetch).
