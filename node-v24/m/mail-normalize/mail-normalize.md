# mail-normalize

> 标签: aliases, email, email-clean, email-format, email-normalizer, email-sanitizer, email-validation, gmail, node, normalize, sanitize, validation

## 简介

A lightweight Node.js library to normalize and sanitize email addresses, handling Gmail aliases and formatting for consistent storage and validation.
