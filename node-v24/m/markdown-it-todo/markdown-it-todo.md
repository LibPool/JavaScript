# markdown-it-todo

> 标签: markdown, markdown-it, markdown-it-plugin, task, todo

## 简介

Markdown todo-list support tag plugin for markdown-it markdown parser, which showing as `<input class="markdown-todo" disabled="true" checked="true">`.
