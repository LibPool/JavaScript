# morphological-box

> 标签: cli, cross-consistency-assessment, llm, morphological-analysis, morphological-box, scenario-generation, scenario-planning, zwicky-box

## 简介

Morphological box (Zwicky box) library and CLI: define key factors, values and (in)consistencies, validate them, and generate consistent scenarios.
