# mcpost

> 标签: blog, claude-code, cli, codex, devlog, makeclass, presentation, slides

## 简介

把開發對話、觀點文與投影片，從任何終端機直接發到 MakeClass——不需要 clone MakeClass 主程式，只需要一支 Personal Access Token。
