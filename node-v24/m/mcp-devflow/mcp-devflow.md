# mcp-devflow

> 标签: JavaScript

## 简介

DevFlow MCP server (SDK v2): guides an IDE AI agent through a safe developer workflow - find task, plan (human-approved), implement, checks, review gate, publish, notify. Server owns state, gates, evidence; no tool writes source code.
