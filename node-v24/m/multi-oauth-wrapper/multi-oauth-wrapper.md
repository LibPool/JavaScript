# multi-oauth-wrapper

> 标签: auth, facebook, github, google, javascript, login, node, oauth, oauth2, wrapper

## 简介

A simple npm package that unifies OAuth2 login flows for multiple providers (Google, GitHub) with minimal config and built-in token refresh handling.
