# musefit-mcp

> 标签: clothing, image, mcp, model-context-protocol, musefit

## 简介

MuseFit AI 服装生图平台的本地 MCP 包装器（stdio）：转发远程 MuseFit MCP 工具，并提供本机图片上传与结果图保存
