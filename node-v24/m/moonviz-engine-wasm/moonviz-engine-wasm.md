# moonviz-engine-wasm

> 标签: design-engine, mbt, moonbit, moonviz, prototype, svg, wasm, webassembly

## 简介

WASM-GC build of the MoonViz prototype design engine. Render and validate .mbt.md visual documents in the browser or Node with zero toolchain, zero subprocess — pure WebAssembly.
