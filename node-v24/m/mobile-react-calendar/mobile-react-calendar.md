# mobile-react-calendar

> 标签: calendar, datepicker, mobile, react, 仿携程日历

## 简介

[mobile-react-calendar](https://github.com/Li-DaDa/mobile-react-calendar)基于react的移动端日期选择组件，仿携程日历，可选区间日期，也可选一天
