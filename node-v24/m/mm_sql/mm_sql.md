# mm_sql

> 标签: add, async, await, database, database-adapter, del, exec, get, mysql, orm, promise, query, run, set, sql, sql server, sqlite, 多数据库

## 简介

一个通用的SQL帮助类，支持通过切换db_type实现对不同数据库的操作，包括MySQL和SQLite等
