# mcp-trade-guard

> 标签: agentic-trading, ai-agent-security, mcp, prompt-injection, robinhood, trading-guard

## 简介

A policy gate between an AI agent and an agentic-trading MCP: scans the text the agent reads for injection, and enforces per-order and daily dollar caps as arithmetic the agent cannot argue with.
