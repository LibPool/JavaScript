# microbit-emu

> 标签: bbc-microbit, ble, bluetooth-low-energy, cortex-m4, emulator, makecode, micro-bit, microbit, micropython, nordic, nrf52, nrf52833, simulator, wasm, webassembly

## 简介

BBC micro:bit v2.2 emulator core (nRF52833 WASM) + virtual parts for Wokwi-style setups. Boot real firmware in the browser: MicroPython REPL, MakeCode builds, 5x5 LED matrix, sensors, BLE SoftDevice face.
