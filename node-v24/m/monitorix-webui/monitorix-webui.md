# monitorix-webui

> 标签: apexcharts, dashboard, interactive-charts, linux, metrics, monitoring, monitorix, observability, rrd, rrdtool, server-monitoring, sysadmin, system-monitoring, tailwindcss

## 简介

Interactive web UI for Monitorix. Reads RRD files directly via rrdtool, serves a React + Tailwind dashboard with live charts, summary cards, and auto-discovered modules.
