# morethanui

> 标签: components, css, custom-elements, dependency-free, design-system, framework-agnostic, no-build, tauri, telegram-mini-app, ui, web-components

## 简介

MoreThanUI — a dependency-free, framework-agnostic UI component library. Plain HTML + CSS custom properties + light-DOM custom elements. No build required to use; drop the files in and write markup.
