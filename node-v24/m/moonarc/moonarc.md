# moonarc

> 标签: animation, animations, astro, astro-integration, components, css, motion, ui, withastro

## 简介

The Astro integration for Moonarc's animation and motion components. Install it with npx astro add moonarc; it adds @moonarc/core and its base tokens to every page.
