# multi-model-analyzer

> 标签: architecture, call-graph, code-quality, dependency-graph, mcp, sarif, static-analysis, typescript

## 简介

Static analysis toolchain for large TypeScript/JavaScript codebases. Extracts symbols, dependency graphs, call graphs, and architectural patterns without runtime LLM calls.
