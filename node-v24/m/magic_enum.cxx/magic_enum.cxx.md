# magic_enum.cxx

> 标签: c++, enum, from_string, header-only, iteration, library, reflection, to_string

## 简介

Static reflection for enums (to string, from string, iteration) for modern C++, work with any enum type without any macro or boilerplate code; Daniil Goncharov (2019).
