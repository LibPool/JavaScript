# mcp-adonis-docs

> 标签: adonisjs, documentation, mcp

## 简介

MCP server for version-aware AdonisJS documentation (v4-v7, Lucid, Edge, VineJS, Japa). Detects the AdonisJS version from a project's package.json and searches the matching docs.
