# mcp-universal-file-converter

> 标签: archive-extraction, file-converter, image-conversion, mcp, office-to-pdf, pdf-to-jpg, typescript, video-thumbnail

## 简介

MCP Universal File Converter - 支持压缩包、图片、PDF、Office文档等转换成可上传的 JPG (≤2MB)，支持Excel工作表拆分
