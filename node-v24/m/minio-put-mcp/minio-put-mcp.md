# minio-put-mcp

> 标签: file-archive, mcp, minio, model-context-protocol, object-storage, put-only, s3-compatible, storage

## 简介

MinIO PUT MCP服务器 - 只上传、不查询、不删除，按 did/sid/fid 三级路径自动归档
