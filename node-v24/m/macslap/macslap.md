# macslap

> 标签: accelerometer, apple-silicon, gesture, hid, iokit, m1, m2, m3, m4, macbook, macos, motion, sensor, slap, tap

## 简介

Detect physical slaps/taps on Apple Silicon MacBooks via the accelerometer. Run any function on slap.
