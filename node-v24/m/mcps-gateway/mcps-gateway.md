# mcps-gateway

> 标签: agent-gateway, agent-identity, ai-gateway, apigee, cloudflare-ai-gateway, ecdsa, ietf, kong, mcp, mcps, owasp, replay-protection

## 简介

Cryptographic message-integrity layer for AI agent gateways (MCP, A2A, REST). Per-message ECDSA signing, agent identity, replay protection. Transport-agnostic. IETF draft-sharif-mcps-secure-mcp. Reference impl forthcoming.
