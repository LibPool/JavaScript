# mongoose-query-find

> 标签: aggregation, aggregation-pipeline, api-query, async-query, crud-utilities, date-filtering, document-query, dynamic-query, field-limiting, filtering, global-search, join, lookup, mongodb, mongoose, pagination, query-builder, query-helper, regex-search, sorting, timezone, typescript

## 简介

TypeScript query and aggregation-pipeline builder for Mongoose. Provides QueryFind for allowlisted filtering, global search, sorting, field selection, population, and pagination on Model.find(), and QueryAggregate for the same safety model on Model.aggreg
