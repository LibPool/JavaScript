# magpie-mcp-server

> 标签: ai-tools, api, checkout, claude, gcash, magpie, maya, mcp, model-context-protocol, paymaya, payment-links, payment-processing, payment-requests, payments, philippines, server

## 简介

Model Context Protocol server for Magpie Payment Platform APIs. Enables AI agents to process payments, create checkout sessions, manage payment requests, and handle payment links.
