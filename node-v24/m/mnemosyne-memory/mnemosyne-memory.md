# mnemosyne-memory

> 标签: agent-memory, ai-agent, bm25, cognitive-science, hermes, llm, local-first, markdown, memory, memory-engine, openclaw, privacy, retrieval, zero-dependency

## 简介

Zero-dependency cognitive memory engine for AI agents — compound-cue retrieval from 31 cognitive-science papers, true BM25 + local semantic dictionary, no LLM, no embedding API, pure Markdown storage, <50ms search.
