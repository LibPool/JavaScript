# muxed

> 标签: ai-agent, ai-coding, claude-code, cli, cursor, daemon, mcp, mcp-aggregator, mcp-cli, mcp-daemon, mcp-proxy, mcp-server, mcp-tools, model-context-protocol, tool-server, windsurf

## 简介

MCP tools don't belong in your model's context window. Offload them to a CLI – agents call tools through shell commands and scripts instead of loading schemas into context.
