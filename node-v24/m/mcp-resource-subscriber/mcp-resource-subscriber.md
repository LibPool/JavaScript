# mcp-resource-subscriber

> 标签: cli, mcp, mcp-client, model-context-protocol, notifications, probe, subscriptions-listen

## 简介

CLI probe for MCP resource subscriptions (protocol revision 2026-07-28) — open a subscriptions/listen stream, receive live update notifications, and re-read updated content.
