# multi-cloudinary-pool

> 标签: cdn, cloudinary, free-tier, image, load-balancing, multi-account, pool, round-robin, storage, upload, video

## 简介

Pool multiple Cloudinary free-tier accounts into a single unified storage engine. Automatically routes uploads across accounts and transparently retrieves/deletes files using a self-contained composite identifier — no database required.
