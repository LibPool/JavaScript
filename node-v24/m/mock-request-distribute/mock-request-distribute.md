# mock-request-distribute

> 标签: JavaScript

## 简介

> 这个仓库是我用来测试帮助项目开发效率所建立的，为的是与真实线上请求保持一致，因为我们项目上线使用的是网关分发（根据POST请求发送过去的约定数据进行请求分发）。
