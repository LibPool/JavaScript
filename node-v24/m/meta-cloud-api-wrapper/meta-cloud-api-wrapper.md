# meta-cloud-api-wrapper

> 标签: meta, parser, typescript, webhook, whatsapp, whatsapp-business, whatsapp-cloud-api

## 简介

Comprehensive, type-safe TypeScript wrapper for the Meta Cloud API. Effortlessly parse webhooks, send messages, manage flows, and build templates for WhatsApp Business.
