# md2idx

> 标签: context-window, llm, llm-agent, markdown, markdown-index, markdown-parser, markdown-splitter, markdown-toc, token-optimization

## 简介

md2idx — Markdown to indexed JSON. Slice big docs with jq, feed LLMs only what they need.
