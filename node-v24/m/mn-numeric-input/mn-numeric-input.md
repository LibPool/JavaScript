# mn-numeric-input

> 标签: comma, comma-separated, component, currancy, currency, decimal, ember input type, ember-addon, ember-number-input, ember-numeric-input, emberjs, formatted-number, input, number, number-input, number-validation, numeric, validation, widget

## 简介

Numeric input allowing comma seperator after thousand, can be used for pure integer number as well as for float. Restrict user to enter alphabets only accepts numbers and only one dot in case of float number
