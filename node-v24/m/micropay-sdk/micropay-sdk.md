# micropay-sdk

> 标签: ai-agents, api-marketplace, autonomous-agents, http-402, machine-payments, micropayments, payment-protocol, stellar, usdc, x402

## 简介

SDK for AI agents to access APIs via x402 micropayments on Stellar. Payment is authentication.
