# mega-sim16

> 标签: 8 bit, ATmega, ATmega328p, AVR, Arduino, Arduino Uno, MCU, microcontroller, simulation, simulator

## 简介

Arduino (8-bit AVR) simulator, written in JavaScript and runs in the browser / Node.js and will be used to build the simulations of more SOC boards
