# mcp-connectwise-psa

> 标签: byok, connectwise, connectwise-manage, mcp, mcp-server, model-context-protocol, msp, psa, tickets

## 简介

MCP server for ConnectWise PSA (Manage) — tickets, time entries, companies, and configurations for technicians, with per-tech API keys (BYOK) so writes are attributed to the real member
