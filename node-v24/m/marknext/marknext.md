# marknext

> 标签: ast, cli, commonmark, context-free-grammar, documentation, lexer, markdown, marknext, markup, parser, secure, xss-protection

## 简介

A minimal, unambiguous, and secure Markdown successor. Context-free grammar parser with no inline HTML.
