# migraine-cli

> 标签: automation, cli, commands, development-tools, migraine, shell, task-runner, template, workflow

## 简介

A robust CLI tool used to organize and automate complex workflows with templated commands. Users can define, store, and run sequences of shell commands efficiently, featuring variable substitution, pre-flight checks, and discrete actions.
