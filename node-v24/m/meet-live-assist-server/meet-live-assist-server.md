# meet-live-assist-server

> 标签: assistant, localhost, meet, meeting, transcript, zoom

## 简介

Local bridge server for the Meet Live Assist browser extension: transcript sink, advice channel, action-item board, snapshots, local STT and TTS. Zero dependencies, binds to 127.0.0.1 only.
