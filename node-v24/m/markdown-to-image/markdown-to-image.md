# markdown-to-image

> 标签: image, markdown, poster, react, tailwindcss, typescript, vite

## 简介

markdown-to-image component renders Markdown as visually appealing social media images. The project also includes a built-in web editor that can be used as an online Markdown-to-poster editor with a simple one-click deployment.
