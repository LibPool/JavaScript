# mdclip

> 标签: cli, clipboard, html, linear, markdown, notion, obsidian, paste, rich-text, rtf

## 简介

Copy markdown as rich text (and rich text as markdown). Fixes pasting between LLMs, terminals, Obsidian, Linear, Notion, Motion, Docs.
