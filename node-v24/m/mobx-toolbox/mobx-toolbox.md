# mobx-toolbox

> 标签: class, getter, javascript, mobx, react, setter, state, typescript

## 简介

`mobxSaiHandler` is a super simple way to handle `data`/`error` reactions from any MobX-powered API state (like MobxSai) using just 1 line of code 🙌
