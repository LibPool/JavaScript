> 标签: africa, african, api, bank codes, bank-registry, bceao, cemac, fintech, mansaapi, ngx, nigeria, sdk, stock market, swift-codes, waemu

## 简介

Official Node.js SDK for Mansa API — African market data, the 22-country licensed-bank registry (BCEAO/COBAC, verified SWIFT codes), currencies, mobile networks, holidays and identity.
