# mern-starter-cli

> 标签: authentication, boilerplate, cli, docker, express, fullstack, jwt, mern, mongodb, mongoose, nodejs, react, redux, scaffold, starter, tailwind, typescript, vitest

## 简介

CLI that scaffolds a complete MERN project: Express 5 + TypeScript layered backend, RS256 JWT auth, tests, Docker, and a React/Vite + shadcn/ui frontend
