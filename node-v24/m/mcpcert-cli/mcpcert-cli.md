# mcpcert-cli

> 标签: cimd, cli, mcp, mcpcert, model-context-protocol, oauth, oauth2, pkce

## 简介

Official mcpcert.org CLI: provision a hosted dev MCP client identity (CIMD) and run an end-to-end OAuth 2.0 + PKCE conformance check, no account required.
