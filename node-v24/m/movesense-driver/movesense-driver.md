# movesense-driver

> 标签: accelerometer, ble, bluetooth, ecg, heart-rate, imu, movesense, rr-interval, sensor, wearable, whiteboard

## 简介

Node.js driver for Movesense BLE sensors (accelerometer, gyro, magnetometer, IMU, ECG, HR/RR, temperature) via the GATT SensorData Protocol.
