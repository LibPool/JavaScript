# mcptrap-probe

> 标签: ai-agents, audit, cli, mcp, model-context-protocol, security, tool-poisoning

## 简介

Probe a local MCP server and submit its tool surface to mcptrap.lyuata.com for static analysis. Read-only, open source.

## 官网

- 官网：https://mcptrap.lyuata.com
- 源码仓库：git+https://github.com/latanasov/mcptrap-probe.git
- npm 页面：https://www.npmjs.com/package/mcptrap-probe
