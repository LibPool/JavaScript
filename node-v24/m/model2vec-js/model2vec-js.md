# model2vec-js

> 标签: browser, embeddings, faq, model2vec, semantic-search, sentence-embeddings, spelling-correction, static-embeddings

## 简介

Model2Vec static embeddings in JavaScript, with FAQ search and spelling correction. Runs in browsers and Node; no dependencies; 4.6 MB with the model.
