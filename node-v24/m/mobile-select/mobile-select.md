# mobile-select

> 标签: area-picker, cascade, cascade-picker, mobile-friendly, mobile-picker, mobile-selector, mobile-trigger, multiple-picker, number, number-picker, number-selector, picker, react-mobile-picker, selector, vanilla-js, vanilla-typescript, vanillajs, vue-mobile-picker

## 简介

A multi-function mobile phone scrolling selector, support single to multi-select, support multi-level cascade, provide custom callback function, provide update function redraw, relocation function, compatible pc drag and so on.
