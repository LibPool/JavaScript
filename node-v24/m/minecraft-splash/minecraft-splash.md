# minecraft-splash

> 标签: minecraft, minecraft-splash

## 简介

A simple and easy to use package which will randomly select a splash text which normally displays on the main menu of Minecraft.

- 官网：https://github.com/SethFromStateFarm/minecraft-splashes
- npm 页面：https://www.npmjs.com/package/minecraft-splash
