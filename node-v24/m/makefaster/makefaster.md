# makefaster

> 标签: agent, autoresearch, lcp, lighthouse, performance, skill

## 简介

AI skill that runs an autoresearch loop to make your site measurably faster. `npx makefaster` drives a free hosted model (Union Alpha via makefaster.dev) or the agent CLI you already have (Cursor, Claude Code, or Codex) through profile -> hypothesis -> me
