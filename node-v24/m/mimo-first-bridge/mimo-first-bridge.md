# mimo-first-bridge

> 标签: agent, cordis, deepseek-harness, dsh, mcp, mcp-server, mimo, mimocode, xiaomi

## 简介

Xiaomi MiMo bridge for DeepSeek Harness (DSH): dispatch to MiMoCode (`mimo` CLI) or the Xiaomi MiMo Desktop client, preselected in settings (backend = mimocode | mimo-desktop). Full DSH control on the CLI path (--dangerously-skip-permissions), Desktop loc
