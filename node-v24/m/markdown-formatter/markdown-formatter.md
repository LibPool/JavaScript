# markdown-formatter

> 标签: chinese, cjk, formatter, jupyter, markdown, remark

## 简介

面向中文写作场景的格式化工具:中英文空格、全角标点、术语统一、markdown 标记统一。支持 markdown / Jupyter notebook / 纯文本。
