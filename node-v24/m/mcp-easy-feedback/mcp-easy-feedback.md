# mcp-easy-feedback

> 标签: ai-agent, claude-code, codex, cursor, feedback, human-in-the-loop, macos, mcp, model-context-protocol, swift

## 简介

macOS 原生弹窗 MCP 工具：让 AI 在改代码前后必须弹窗问过你。5 个反馈工具（提问 / 确认 / 选择 / 展示 / 通知），Swift + WebKit 原生 UI，支持 Markdown 与图片附件。
