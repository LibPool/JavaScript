# monday-cli

> 标签: agent, ai-agent, automation, boards, claude-code, cli, codex, graphql, kanban, monday, monday.com, task-management, typescript

## 简介

Agent-first CLI for Monday.com — read boards, file backlog items, transition statuses, and post comments from the terminal. Built for AI coding agents (Claude Code, Codex) with humans as a welcome second audience.
