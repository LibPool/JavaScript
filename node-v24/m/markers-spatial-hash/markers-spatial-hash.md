# markers-spatial-hash

> 标签: hash, map, markers, performance, spatial, spatialHash

## 简介

Lightweight and efficient map visualization package that helps you manage and render large sets of markers on a 100x100 grid. By categorizing and organizing markers into a grid, this package significantly improves map performance, especially when panning
