# matsuri-astro-theme

> 标签: astro-theme, conference, event, gsap, japanese, matsuri, tailwindcss

## 简介

Matsuri is a Japanese event/conference Astro theme — deep indigo night sky, lantern amber glows, vermillion calls-to-action, GSAP countdown timer and scroll reveals.
