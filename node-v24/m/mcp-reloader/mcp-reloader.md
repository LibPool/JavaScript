# mcp-reloader

> 标签: agent, claude, hot-reload, llm, mcp, model-context-protocol, proxy, reload, stdio, supervisor

## 简介

Hot-reload supervisor for stdio MCP servers — lets an agent rebuild-and-restart a wrapped MCP server live, no host restart.
