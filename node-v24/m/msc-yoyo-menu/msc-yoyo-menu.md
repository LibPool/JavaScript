# msc-yoyo-menu

> 标签: front-end, menu, web, web component

## 简介

<msc-yoyo-menu /> is a 「Path」 menu like effect. Menu will spray out when user press trigger. Developer could collect some feature triggers or shortcuts through <msc-yoyo-menu />.
