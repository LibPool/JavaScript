# marker-tree

> 标签: cypress, data-test, data-testid, e2e, marker, playwright, selector, testing, tree

## 简介

The library for marking all needed DOM elements for e2e testing. It automatically creates selector and key from semantic MarkerTree that being used both in the project and your e2e solution.
