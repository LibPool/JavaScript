# maskbox-target

> 标签: border-radius, clip-path, concave-corner, corner-radius, css-mask, design-system, inverted-radius, mask-composite, nextjs, react, rsc, server-components, squircle

## 简介

Nest React boxes with real cutouts: a parent punches its children's shapes out of its own CSS mask, with tangent corner joints. No DOM measuring, no client JS, RSC-safe.
