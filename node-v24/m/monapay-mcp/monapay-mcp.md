# monapay-mcp

> 标签: acb, claude-code, codex, cursor, email, mcp, model-context-protocol, monapay, payment, vietnam, vietqr, webhook, zalo

## 简介

MCP server cho MONA Pay — để Claude Code / Cursor / Codex tạo QR, tra giao dịch, cấu hình webhook MONA Pay ngay trong lúc code. MONA Pay là API ngân hàng và dịch vụ xác nhận thanh toán tự động của The MONA Group.
