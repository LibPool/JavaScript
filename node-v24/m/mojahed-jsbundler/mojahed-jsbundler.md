# mojahed-jsbundler

> 标签: bundle assets, combines assets, jsbundler

## 简介

A universal Node.js bundler that combines any file type (JS, CSS, PHP, TXT, etc.) from local or remote sources into single bundles. Perfect for Laravel Vite integration.
