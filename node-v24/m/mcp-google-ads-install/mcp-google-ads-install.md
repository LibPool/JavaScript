# mcp-google-ads-install

> 标签: claude-desktop, google-ads, install, mcp

## 简介

Writes the Claude Desktop config entry for mcp-google-ads so you never hand-edit claude_desktop_config.json. Thin delegating wrapper so `npx mcp-google-ads-install` resolves as a package name.
