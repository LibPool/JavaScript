# mcpscope-engine

> 标签: agent, agent-runtime, ai-agents, embeddable, llm, lm-studio, local-first, local-llm, mcp, mcp-client, model-context-protocol, nodejs, ollama, openrouter, sqlite, tool-calling, tool-use, typescript

## 简介

Embeddable chat/session engine for MCP: agent loop, MCP tool calling, local-first LM providers, durable node:sqlite sessions, and fine-grained transparency events. Zero runtime dependencies beyond zod.
