# mcp-media-toolkit

> 标签: ai-tools, claude-code, cloudflare-r2, codex, cursor, gemini, generative-ai, image-generation, image-upload, mcp, mcp-server, model-context-protocol, nano-banana, prompt-optimization, s3

## 简介

MCP server for AI image generation (Gemini / Nano Banana) and upload to S3-compatible storage (Cloudflare R2, AWS S3, MinIO). Works with Claude Code, Cursor, Codex, and any MCP client.
