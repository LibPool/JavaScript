# muxi-tarojs-plugin-rspack

> 标签: build-optimization, cache, faster-build, miniprogram, muxi, performance, plugin, rspack, swc, taro, tarojs, weapp, wechat

## 简介

Taro.js 插件，专门优化微信小程序构建，使用 Rspack 技术提供极速的小程序构建体验。支持 SWC 编译器、智能代码分割、缓存优化等功能，显著提升小程序开发体验。
