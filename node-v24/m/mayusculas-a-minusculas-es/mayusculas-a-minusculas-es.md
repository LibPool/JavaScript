# mayusculas-a-minusculas-es

> 标签: capitalizar, case-converter, convertir-texto, espanol, mayusculas, mayusculas-a-minusculas, minusculas, text-transform

## 简介

Biblioteca JavaScript ligera para convertir texto entre mayúsculas, minúsculas, capitalizado y tipo oración en español (con soporte completo para ñ y tildes).
