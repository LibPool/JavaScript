# mcp-medium-reader

> 标签: claude, claude-code, codex, gemini, llm, markdown, mcp, medium, model-context-protocol

## 简介

Cross-platform MCP server that wraps ZMediumToMarkdown so LLMs can read or download Medium posts as Markdown.
