# microservice-pipeline

> 标签: api-gateway, backend-framework, backend-generator, boilerplate, cli, docker, express, microservice, microservices, mongoose, nodejs, scalable-architecture, typescript

## 简介

A powerful TypeScript-based CLI tool to generate scalable Node.js microservices with Express, MongoDB, API Gateway, Docker, and auto port management.
