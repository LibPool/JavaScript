# mcp-sandbox

> 标签: ai-agents, e2b, isolation, mcp, model-context-protocol, sandbox, security

## 简介

Run any MCP server inside an isolated E2B cloud sandbox instead of on your machine — one command, no code changes. Transparent stdio bridge with env allowlisting and JSONL traffic tracing.
