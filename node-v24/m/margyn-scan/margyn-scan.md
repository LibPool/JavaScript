# margyn-scan

> 标签: audit, ci, mutation-testing, static-analysis, test-suite, testing

## 简介

Audits your test suite instead of your code. Finds tests that assert nothing, files git never committed and gates nothing invokes. Every finding ships a reproduction you can run.
