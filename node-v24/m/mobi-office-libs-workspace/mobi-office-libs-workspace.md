# mobi-office-libs-workspace

> 标签: JavaScript

## 简介

Standalone Angular workspace that builds the @mobioffice/mobi-office-libs package compatible with Angular 14+ (supports v14, v15, v16, v17, v18, v19, v20 and multiple minor releases in between).
