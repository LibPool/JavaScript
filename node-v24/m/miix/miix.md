# miix

> 标签: full-stack, miix, mix

## 简介

Miix.js is a high-performance Node.js midlle-layer & back-end framework, which is frontend-friendly, powerful and easy-to-use. It supports many features such as multi-process, full-asynchronous driver, AOP, RESTful, middleware, log management. Using Miix.
