# my-starterkit

> 标签: JavaScript

## 简介

My default npm starterkit. Includes: - Sane file structure, - Sane `package.json`/`bower.json`, - ES6-to-ES5 transpiling/polyfilling (`Promise` with `bluebird`), - Common libs (`lodash-next`, `co`, `should`).
