# mcp-agentnet

> 标签: deprecated, mcp, model-context-protocol, novarail

## 简介

Renamed to mcp-novarail. This version is a compatibility shim that runs mcp-novarail, so existing 'npx -y mcp-agentnet' configs keep working. Update your config to 'npx -y mcp-novarail'.
