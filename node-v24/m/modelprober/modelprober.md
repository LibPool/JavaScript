# modelprober

> 标签: anthropic, api, cli, deepseek, free, gemini, groq, llm, models, openai, openrouter, probe

## 简介

Probe any LLM API (OpenAI-compatible, Anthropic, Gemini) with a key: find out which models actually respond, and which ones are free.
