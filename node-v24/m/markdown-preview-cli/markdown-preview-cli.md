# markdown-preview-cli

> 标签: antd, cli, documentation, markdown, mermaid, nestjs, preview, react

## 简介

Markdown preview CLI — browse a folder as a menu tree, render Markdown with multiple themes and Mermaid diagrams. React + Ant Design frontend backed by a NestJS server, packaged as a single npm command-line tool.
