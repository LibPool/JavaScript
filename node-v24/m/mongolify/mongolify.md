# mongolify

> 标签: ajv, dto, javascript, json-schema, library, mongoose, policy, query, typescript, validation

## 简介

Schema-driven DTO & validator toolkit forMongoose schemas (no DB connection). Caching, JSON Schema compiler, Ajv engine, policy hooks, query helpers. Works in JS & TS.
