# metagetplus

> 标签: favicon, favicons, fetch, html, meta, metadata, open graph, opengraph, parse, remote, tags, title

## 简介

A Node.js module to fetch HTML meta tags (including Open Graph), title and favicons from a remote URL inspired from metaget https://github.com/mrvautin/metaget
