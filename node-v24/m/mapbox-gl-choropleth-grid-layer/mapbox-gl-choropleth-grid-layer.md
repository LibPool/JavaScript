# mapbox-gl-choropleth-grid-layer

> 标签: choropleth, grid, layer, mapbox, mapbox-gl

## 简介

Custom layer for mapbox-gl that efficiently displays large sets of world space data as a grid of colors. [View demo](https://ptnoavailability.z1.web.core.windows.net)
