# missing-index

> 标签: ci, database, drizzle, explain, index, knex, mariadb, missing-index, mysql, n+1, optimization, performance, postgres, postgresql, prisma, query, seq-scan, slow-query, typeorm

## 简介

Find the missing database index. Explains slow queries at runtime and prints the CREATE INDEX that fixes them, with the line of code that ran them. PostgreSQL and MySQL.
