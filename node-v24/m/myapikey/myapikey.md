# myapikey

> 标签: ai-gateway, ai-proxy, anthropic, api-gateway, chat-completions, circuit-breaker, claude, claude-code, cli, failover, gateway, homelab, hono, llm, llm-gateway, llm-proxy, llm-router, model-router, multi-provider, openai, openai-compatible, passthrough, proxy, self-hosted, typescript, vue

## 简介

Personal LLM API gateway & proxy — one address + one API key for all your models. Forwards OpenAI & Anthropic calls to your backends with failover and a circuit breaker. Pure passthrough, no format translation. Self-hosted (CLI + web UI).
