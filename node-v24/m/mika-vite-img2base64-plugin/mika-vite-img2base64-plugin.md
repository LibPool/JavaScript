# mika-vite-img2base64-plugin

> 标签: JavaScript

## 简介

#### 插件功能 - **自动转换**：将 PNG、JPG/JPEG、WebP 格式的图片自动转换为 Base64 数据 URL - **大小限制**：默认只转换小于 100KB 的图片，超过限制的图片保持原样 - **配置灵活**：可以通过参数调整转换大小限制
