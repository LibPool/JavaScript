# mongoose-pii

> 标签: bcrypt, mongodb, mongoose, password, passwords, pii, plugin, security

## 简介

A Mongoose plugin that lets you transparently cipher stored PII and use securely-hashed passwords.  Helps with security best practices for data storage.
