# moonshine-vm

> 标签: JavaScript, Lua, Moonshine, luac, virtual machine

## 简介

A lightweight Lua virtual machine.

This module provides only the virtual machine, making it the better choice for use with front-end applications like Browserify. For the complete Moonshine toolset, use the "moonshine" module instead.
