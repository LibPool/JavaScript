# mnmnote-mcp

> 标签: claude, e2ee, markdown, mcp, mnmnote, model-context-protocol, notes

## 简介

Local MCP server for MNMNOTE — let an LLM (Claude, Cursor, Codex) search, read, and create your end-to-end-encrypted notes. Keys never leave your machine.
