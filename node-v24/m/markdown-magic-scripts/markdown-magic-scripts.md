# markdown-magic-scripts

> 标签: automation, dashboard, developer-tools, documentation-generator, json-scripts, markdown, markdown-automation, markdown-dashboard, markdown-magic, markdown-magic-scripts, npm, npm-scripts, package-scripts, project-automation, readme-generator, script-documentation, scripts

## 简介

Automatically generate a dynamic, customizable dashboard of your npm scripts in your README.md using this markdown-magic transform. Keep your project documentation in sync with your package.json.
