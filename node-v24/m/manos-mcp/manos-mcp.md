# manos-mcp

> 标签: adb, android, automation, ios, maestro, mcp, mobile, model-context-protocol, simctl, testing

## 简介

A CLI MCP server for ad-hoc UI testing of Android & iOS apps — a tight act+observe loop, device-condition control, log/crash & network capture, OCR targeting, accessibility audits, and session recording that exports a replayable flow.
