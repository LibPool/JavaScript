# mcp-openai-image-generator

> 标签: ai, claude, cursor, dall-e, gpt-image, image-editing, image-generation, images, mcp, model-context-protocol, openai

## 简介

MCP server for generating, editing, and creating variations of images using OpenAI GPT Image models. Works with Claude Code, Cursor, VS Code, Windsurf, Cline, and more.
