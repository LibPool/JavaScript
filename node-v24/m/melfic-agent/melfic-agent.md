# melfic-agent

> 标签: agent, ai, cli, coding-agent, gemini, openrouter, termux

## 简介

Melfic Agent — a real agentic coding CLI (command: ai) that scans your project, understands its architecture, edits files, runs commands, and remembers context locally. Runs great in Termux on Android.
