# mongoose-timestamp-date-unix

> 标签: createdAt, mongodb, mongoose, plugin, timestamps, unix, updatedAt

## 简介

Mongoose plugin that adds createdAt and updatedAt auto-assigned date properties (only date) with UNIX format
