# maml897

> 标签: JavaScript

## 简介

1.如果去掉webpack.config.js中关于loader的部分，则dist/main.js中的内容基本原样输入带有class，这样有的浏览器可能就不支持 2.带着loader则会main.js会被转移，大多数浏览器可能支持 3.但是不用babel转义，webpack也会处理一些es6的语法
