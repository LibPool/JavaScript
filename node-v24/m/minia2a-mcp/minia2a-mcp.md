# minia2a-mcp

> 标签: 402-payment-required, agent-economy, agent-payments, ai-agent, api-marketplace, auto-mode, base, claude-code, cli, crypto-payments, elizaos, m2m, machine-to-machine, marketplace, mcp, micropayments, minia2a, model-context-protocol, pay-per-call, sdk, trial-first, usdc, web3, x402

## 简介

MCP server for minia2a.uk — x402 micropayment marketplace for AI agents. Discover and call pay-per-call APIs with built-in USDC settlement on Base. 5 free trial calls per signed wallet (self-custody + EIP-191 signature, no registration).
