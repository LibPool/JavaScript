# mcp-continuum

> 标签: compatibility, mcp, middleware, migration, model-context-protocol

## 简介

Dual-stack compatibility middleware for MCP servers: answer both the legacy 2025-11-25 handshake and the new 2026-07-28 stateless spec at once, plus a probe that proves both work.
