# meshproject-cli

> 标签: JavaScript

## 简介

* 1.使用 npm install meshproject-cli 安装 project-cli * 2.使用 meshcli init 初始化项目 * 3.根据自己使用的语言选择对应的配置文件版本 * 4.初始化成功终端会提示初始化成功
