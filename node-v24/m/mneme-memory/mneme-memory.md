# mneme-memory

> 标签: agent, claude, codex, llm, mcp, memory, mneme, model-context-protocol, stdio

## 简介

Mneme memory tools as a stdio MCP server — cross-session memory for any MCP client (Claude Code / Cursor / Codex / Hermes / OpenCode / OpenClaw), backed by the dsh-mneme plugin's standalone API.
