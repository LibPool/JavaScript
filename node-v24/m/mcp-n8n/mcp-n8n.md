# mcp-n8n

> 标签: ai, ai-automation, automation, claude, claude-desktop, cursor, low-code, mcp, model-context-protocol, n8n, n8n-api, no-code, workflow, workflow-automation

## 简介

MCP server for n8n: full 560-node catalog with real schemas, validated workflow building, autofix, snapshots with rollback and diff, execution debugging, health reports, full-instance backup, and remote HTTP mode
