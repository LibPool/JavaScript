# masto-id-connect

> 标签: api, auth, authentication, connect, decentralised, decentralized, fediverse, identity, masto, mastodon, oauth, oauth2.0, oidc, openid

## 简介

Functions for authenticating a user against a Mastodon API; server discovery, client registration, token exchange, and user info fetching.
