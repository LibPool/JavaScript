# macos-keyboard-backlight

> 标签: apple-silicon, backlight, brightness, cli, corebrightness, darwin, kbdlight, keyboard, keyboard-backlight, mac, macbook, macos, osx

## 简介

Control the MacBook keyboard backlight from the command line or Node - get/set brightness and toggle ambient auto-brightness. No native build step.
