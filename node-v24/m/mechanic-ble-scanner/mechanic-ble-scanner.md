# mechanic-ble-scanner

> 标签: BLE, Bluetooth, Bluetooth Low Energy, Bluetooth smart, Eddystone, Estimote, Internet of Things, IoT, iBeacon

## 简介

The mechanic-ble-scanner is a Node.js module which allows you to scan BLE beacon packets and parse the packet data. This module supports iBeacon, Eddystone, and Estimote.
