# mt5-sdk

> 标签: MT5, MetaTrader 5, Node.js, SDK, Web API, trading

## 简介

A Node.js SDK for interacting with the MetaTrader 5 Web API, enabling seamless integration of MetaTrader 5 trading features into your applications.
