# mongo-query-kit

> 标签: api, backend, database, date-range, express, filter, middleware, mongodb, mongoose, multi-sort, nodejs, odm, pagination, populate, query-builder, query-params, req-query, rest-api, search, sorting

## 简介

A lightweight utility for MongoDB and Mongoose that handles filtering, searching, sorting, pagination, and date range queries for Express APIs.
