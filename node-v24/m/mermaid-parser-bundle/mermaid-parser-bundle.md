# mermaid-parser-bundle

> 标签: ast, class-diagram, er-diagram, flowchart, gantt, mermaid, mindmap, parse-only, parser, sequence-diagram, zero-dependency

## 简介

Zero-dependency ESM bundle of mermaid's parsers — all 34 diagram types, no renderer code (no d3, cytoscape, katex, roughjs, …).
