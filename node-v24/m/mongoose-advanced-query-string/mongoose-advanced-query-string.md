# mongoose-advanced-query-string

> 标签: filter, filtering, limit fields, mongoose, mongoose queries, paginating, pagination, projection, queries, query filtering, query paginating, query projecting, query sorting, query strings, sort, sorting, url queries

## 简介

A wrapper for mongoose query functions: find() and aggregate() to let users be able to do query strings dynamically with find() and aggregate(). It lets them use dynamic filtering, sorting, projecting and paginating
