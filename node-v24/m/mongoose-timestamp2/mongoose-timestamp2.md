# mongoose-timestamp2

> 标签: createdAt, mongodb, mongoose, mongoose-timestamp, mongoose-timestamp2, mongoose-timestamps, mongoose-timestamps2, plugin, timestamp-plugin, timestamps, updatedAt

## 简介

Mongoose plugin that adds createdAt and updatedAt auto-assigned date properties. Forked from mongoose-timestamp by Nicholas Penree <nick@penree.com>.
