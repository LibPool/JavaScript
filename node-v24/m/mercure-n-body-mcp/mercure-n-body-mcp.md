# mercure-n-body-mcp

> 标签: electron, mcp, model-context-protocol, n-body, particles, vite, webgpu

## 简介

Serveur MCP de mercure-n-body : un agent de code règle, fait avancer et capture le fond de particules N-corps, sur une instance sans page (dawn.node) ou dans une application en cours de développement (pont local : relais Electron, plugin Vite).
