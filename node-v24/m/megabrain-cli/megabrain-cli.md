# megabrain-cli

> 标签: ai, anthropic, cache, cli, gemini, llm, openai, proxy, router, token-savings

## 简介

Drop-in OpenAI/Anthropic-compatible proxy and CLI that cut LLM token spend with semantic caching, tier routing and a live savings dashboard. Bilingual PT/EN, dark and light.
