# mcp-recipes

> 标签: bbc-good-food, cookbook, cooking, ingredient-scaling, marmiton, mcp, mcp-server, model-context-protocol, multilingual, pequerecetas, ptitchef, recipes, supertoinette, wikibooks

## 简介

MCP server that asks six recipe sites at once, in French, English and Spanish, merges the answers, and scales quantities. No API key required.
