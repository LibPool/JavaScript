# moveezi

> 标签: agent, api, cli, llm, logistics, mcp, moveezi, moving, relocation, sdk, storage

## 简介

Client and CLI for the public Moveezi API: read moveezi.com as structured data, search it, and reach the sales team. No credentials needed.
