# middlewright

> 标签: e2e, flaky-tests, middleware, playwright, plugin, spinner, testing

## 简介

A plugin/middleware system for Playwright locator actions — spinner-aware waiting, hydration gates, UI error reporting, video highlighting, and LLM-powered recovery. A hack, but a useful one.
