# mdev-sdk

> 标签: ai, anthropic, catalog, llm, mdev-sdk, models, models.dev, openai, pricing, sdk

## 简介

Zero-dependency TypeScript SDK for the models.dev public API: providers, models, pricing, and metadata, with an offline snapshot mode and a CLI.
