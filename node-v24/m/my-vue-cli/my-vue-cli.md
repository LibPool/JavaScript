# my-vue-cli

> 标签: JavaScript

## 简介

## 描述 写这个项目的目的一方面是为了学习搭建vue脚手架的过程，来掌握各个细节的知识，另一方面把这个过程分享出来，和大家一起学习，从而获得进一步的提高。虽然vue官方提供了一个完整的脚手架，但是我觉得如果能知道搭建的过程，能进一步加深理解。如何实现此项目我都在博客中详细写明，大家可以结合博客来看这个项目。 此项目使用的主要技术栈：<br/> * Node / Npm * ES6 * VueJs * Vue-router * Vuex * Babel * Webpack * Element-UI
