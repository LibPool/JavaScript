# morpherwallet-sdk

> 标签: JavaScript

## 简介

This is an SDK for the zero-wallet to simply add it to the website. Drop-In Replacement for Fortmatic/Portis/MetaMask

- 源码仓库：git+https://github.com/Morpher-io/MorpherWallet.git
