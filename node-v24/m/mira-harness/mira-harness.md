# mira-harness

> 标签: bot-testing, cli, e2e, gramjs, mira, telegram, userbot

## 简介

A CLI + MCP dev-tool for communicating with the @mira Telegram bot — capture its full reply (buttons/links/media) and run a self-driving experiment catalog.
