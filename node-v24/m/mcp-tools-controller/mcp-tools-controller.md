# mcp-tools-controller

> 标签: aggregator, claude, claude-code, gateway, mcp, model-context-protocol, plugin-manager

## 简介

MCP plugin manager and aggregation gateway: treat every MCP server as a plugin, validate it on connect, manage it from the CLI or from the model itself, and expose all plugin tools through one hot-reloading MCP endpoint.
