# map-tool-vue

> 标签: JavaScript

## 简介

基于 Vue 3 与 `@arcgis/core` 的地图组件库：地图初始化、底图切换（含自定义矢量示例）、工具栏（缩放、复位、测距、测面、绘图、清绘）。
