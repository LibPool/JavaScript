# multi-spec-parser

> 标签: google-discovery, json-schema, openapi, parser, standard-schema, swagger, yaml

## 简介

Parse OpenAPI 3.x, Swagger 2.0, and Google Discovery documents into normalized operation-level JSON Schemas and Standard Schema adapters.
