# mpvoice-downloader

> 标签: JavaScript

## 简介

This cli tool can batch grab the audio files within the WeChat public article and download them.

## 官网

- npm 页面：https://www.npmjs.com/package/mpvoice-downloader

## 历史版本号

- 当前版本：2.0.0

- 2.0.0

## 获取地址

- npm 安装：`npm install mpvoice-downloader`
- npm registry：https://registry.npmjs.org/mpvoice-downloader
- Node 要求：^12.20.0 || ^14.13.1 || >=16.0.0
