# mocha-wrap

> 标签: after, afterEach, around, around_filter, before, beforeEach, chai, describe, it, javascript, js, mocha, mock, stub, test, wrap

## 简介

Fluent pluggable interface for easily wrapping `describe` and `it` blocks in Mocha tests.
