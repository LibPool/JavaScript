# marketplace-package

> 标签: JavaScript

## 简介

LYNC Marketplace NPM SDK allows anyone to create their own decentralized marketplace which includes Buy/Sell and Rent/Lend for ERC-721 and ERC-1155 contracts in few lines of code.
