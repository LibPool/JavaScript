# moneyflow-mcp

> 标签: finance, geldfluss, graph, mcp, model-context-protocol, moneyflow, neo4j, simulation

## 简介

MCP server for moneyflow – query money flows, simulate policy changes, compare cohorts. Connects to money-flow.org.
