# meddelare-express

> 标签: JavaScript

## 简介

Node.js Express web server middleware for in-app, self-hosted Meddelare within your current server.

## 官网

- 官网：https://meddelare.com/
- 源码仓库：git://github.com/meddelare/meddelare-node-express.git
