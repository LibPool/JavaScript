# md-embed

> 标签: cloudflare-workers, custom-element, edge, hono, htmlrewriter, markdown, md-embed, r2, shortcode

## 简介

Streaming <md-embed> shortcode renderer for Cloudflare Workers: embeds live, R2-backed Markdown into HTML via HTMLRewriter. Name reserved — under active development.
