# mcp-versionbridge

> 标签: bridge, compatibility, mcp, model-context-protocol, protocol, version-negotiation

## 简介

Bridges an MCP client stuck on the pre-2026-07-28 initialize handshake to a 2026-07-28 server that speaks per-request protocol versioning, with no changes to either side.
