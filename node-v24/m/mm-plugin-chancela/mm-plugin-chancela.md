# mm-plugin-chancela

> 标签: agent-wallet, ai-agents, authorization, chancela, erc-8004, metamask, mm-plugin, monad

## 简介

Chancela for MetaMask Agent Wallet: ask a deterministic policy engine whether an AI agent may act, before it acts. Adds `mm chancela` commands.
