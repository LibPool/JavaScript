> 标签: album-art, artwork, cross-platform, electron, linux, macos, media, media-controls, media-session, metadata, mpris, music, native, node, nodejs, now-playing, playback, smtc, system-media, windows

## 简介

A lightweight, dependency-free library for accessing system media metadata, playback state, and artwork across Windows, Linux, and soon macOS.
