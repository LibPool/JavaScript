# mcp-anything

> 标签: agents, aggregator, gateway, llm, mcp, meta-mcp, model-context-protocol, registry, tool-discovery

## 简介

One MCP server that can discover and call (almost) any MCP server in the world — a meta-MCP gateway over the official MCP registry.
