# monthly-fx

> 标签: conversion, currency, currency-converter, ecb, exchange-rates, forex, frankfurter, fx, monthly-average, typescript

## 简介

Tiny, typed, zero-dependency FX rates with monthly-average helpers — free ECB data via Frankfurter, no API key.
