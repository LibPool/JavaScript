# mcp-ssh-terminal

> 标签: ai-agent, interactive, mcp, mcp-server, network-automation, openssh, pty, remote-access, shell, ssh, terminal

## 简介

MCP server exposing persistent, interactive SSH sessions driven through the real OpenSSH client and a headless terminal emulator.
