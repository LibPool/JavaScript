# memvara

> 标签: agent-memory, agents, ai-memory, bitemporal, cli, knowledge-graph, llm, mcp, mcp-server, memory, memvara, model-context-protocol, temporal

## 简介

npx memvara — connect a stdio MCP client to memvara, bitemporal memory for AI agents. Zero config: no URL to paste, and no browser at all when you already have a key.
