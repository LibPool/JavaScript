# mimo-throughput

> 标签: latency, llm, mimo, mimocode, monitoring, performance, throughput, tps, ttft

## 简介

Real-time LLM performance monitoring plugin for MiMoCode. Tracks TTFT, TPS, latency, token usage and cost per model with a TUI sidebar display.
