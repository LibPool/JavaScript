# mcp-server-anydoc

> 标签: anydoc, claude, claude-code, cursor, document-conversion, docx, local, markdown, mcp, mcp-server, model-context-protocol, office, pdf, pptx, privacy, xlsx

## 简介

Local MCP server that converts PDF, Word, PowerPoint, Excel and more to Markdown with anydoc. No API key. Files stay on your machine.
