# mektup-mcp

> 标签: ai-agent, domain-email, email, email-hosting, imap, mcp, model-context-protocol, smtp

## 简介

MCP server for Mektup - register domains, create real mailboxes, send/read mail, manage drafts/contacts/folders/forwarding/vacation replies, all as MCP tools backed by Mektup's live REST API.
