# mvl-botcms-users-semis

> 标签: JavaScript

## 简介

Сохранение в БД базовой информации о каждом пользователе, отправляющем сообщение боту. Пакет экспортирует модель Sequelize, поэтому в проекте должно существовать подключение к БД.
