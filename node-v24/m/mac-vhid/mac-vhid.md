# mac-vhid

> 标签: hid, keyboard, mouse

## 简介

Node addon that allows you to control the mouse and keyboard on a Mac through a virtual human input device.

- 官网：https://github.com/dapuck/node-mac-vhid
- 源码仓库：https://github.com/dapuck/node-mac-vhid.git
