# mongo-collections-to-typescript

> 标签: accumulator, codegen, etl, json-schema, mongodb, pipeline, pluggable, schema-inference, typebox, typescript

## 简介

Scan MongoDB collections, infer JSON Schema from sampled documents, and emit matching TypeScript (and optionally TypeBox) types.
