# mdspec

> 标签: bash, bun, cli-testing, cram, docs-as-tests, doctest, markdown, markdown-testing, nodejs, shell, snapshot-testing, testing, trycmd

## 简介

Markdown test runner for CLI docs and shell transcripts. Cram-style console blocks, persistent shell context, pattern matching, and snapshot updates.
