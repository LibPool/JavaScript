# modern-react-json-editor

> 标签: editor, json, json-editor, json-tree, react, react-component, svelte-jsoneditor, vanilla-jsoneditor

## 简介

A high-performance React bridge for vanilla-jsoneditor. Compatible with React 16.8+. Features integrated dark mode support, JSON Schema validation, and responsive layout inheritance.
