# mcp-testrail-server

> 标签: automation, mcp, model-context-protocol, test-management, testing, testrail

## 简介

A Model Context Protocol (MCP) server for TestRail integration — manage test plans, runs, cases, results, milestones, and more. Supports create, read, update, and delete operations on test cases.
