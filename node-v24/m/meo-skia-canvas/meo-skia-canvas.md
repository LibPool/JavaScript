# meo-skia-canvas

> 标签: canvas, compositing, gpu, graphic, graphics, headless, image, images, metal, offscreen, pdf, render, rust, skia, svg, vulkan

## 简介

A multi-threaded, GPU-accelerated 2D graphics environment for Node: the HTML Canvas API on Skia, with GUI windows, animation, and export to raster and vector formats
