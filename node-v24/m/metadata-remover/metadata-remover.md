# metadata-remover

> 标签: browser, c2pa, exif, gps, icc, jpeg, lossless, metadata, png, privacy, remove, strip, webp, xmp

## 简介

Lossless EXIF/GPS/metadata stripping for JPEG, PNG and WebP — pure TypeScript over Uint8Array, zero dependencies, runs in the browser and Node.
