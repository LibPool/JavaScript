# mcp-bw-adt-api

> 标签: ADT, BW, BW4HANA, Business Warehouse, SAP, mcp, model-context-protocol

## 简介

MCP server exposing SAP BW/4HANA ADT (bw-adt-api) operations to LLM clients, with local-file buffering for large XML payloads and table data.
