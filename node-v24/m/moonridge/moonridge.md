# moonridge

> 标签: angular, aurelia, isomorphic, liveQuery, mean, meteor, model, mongo, mongoDB, mongoose, mongoosejs, orm, realtime, rpc, socket.io, universal

## 简介

Isomorphic library, which allows you to use Mongoose.js models via socket.io-rpc doing regular queries and liveQueries
