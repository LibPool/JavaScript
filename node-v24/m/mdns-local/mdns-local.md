# mdns-local

> 标签: avahi, bonjour, dns-sd, iot, local-network, mdns, multicast, multicast-dns, raspberry-pi, rfc-6762, rfc-6763, service-advertising, service-discovery, zeroconf

## 简介

Pure JavaScript mDNS/DNS-SD for Node.js - service discovery and advertising for local networks. Callback-based, dual-stack IPv4/IPv6, RFC 6762/6763 compliant. No native bindings.
