# mysql2-helper-lite

> 标签: database, helper, lightweight, mysql, mysql2, promise

## 简介

A powerful, feature-rich MySQL query builder and ORM for Node.js with advanced caching, hooks, pagination, full CRUD support, and 16 creative functions beyond mysql2!
