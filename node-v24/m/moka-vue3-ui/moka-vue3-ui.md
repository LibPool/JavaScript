# moka-vue3-ui

> 标签: JavaScript

## 简介

Moka-UI 这是一个基于 Vue3 + TypeScript 的 UI 组件库，涵盖了Button、Switch...等常见 UI 组件。 深入研究 Vue3，使用了 setup、onMounted、watchEffect、ref、computed 等 Composition API。
