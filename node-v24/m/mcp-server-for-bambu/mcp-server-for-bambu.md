# mcp-server-for-bambu

> 标签: 3d-printer, bambu, bambu-lab, claude, claude-desktop, fdm, mcp, model-context-protocol, mqtt, p1p, p1s, x1c

## 简介

Unofficial MCP server for Bambu Lab 3D printers (LAN/MQTT). Real-time status, AMS info, print control, maintenance ledger. Not affiliated with Bambu Lab.
