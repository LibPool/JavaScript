# mb-runtime

> 标签: deno, flash-app, kv-storage, langchain, mspbots, runtime

## 简介

Flash App Platform Runtime - A lightweight runtime for flash applications with KV storage, HTTP client, mspbots integration, and LangChain capabilities (Deno only)
