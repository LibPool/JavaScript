# memgrid

> 标签: agent, ai, claude-code, coding-agent, context, knowledge-graph, memory, rag, semantic-memory

## 简介

Project-level semantic memory system for AI coding agents. Replaces full-codebase context loading with a self-evolving knowledge-mesh.
