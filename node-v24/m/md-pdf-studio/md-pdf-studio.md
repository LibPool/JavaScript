# md-pdf-studio

> 标签: chrome-extension, cli, converter, docx, epub, katex, markdown, markdown-to-pdf, marked, md-pdf-studio, md2pdf, mermaid, pdf

## 简介

A powerful CLI tool and Manifest V3 Browser Extension to convert Markdown files, text, or web pages into beautifully styled PDFs with Mermaid diagrams, LaTeX math, TOC, and themes. The CLI also writes Word (.docx) and EPUB.
