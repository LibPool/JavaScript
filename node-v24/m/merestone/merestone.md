# merestone

> 标签: adr, coding-agent, context, context-window, documentation, gate, mcp, memory, model-context-protocol, provenance, records, token-economy

## 简介

Stable addresses for durable project memory, built to spend as little context as possible: records are addressed by codes that are never renamed or reused, and every reference is re-checked by a gate.
