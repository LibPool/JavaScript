# markup-mcp

> 标签: ai, annotations, claude, claude-code, cursor, markup, mcp, model-context-protocol

## 简介

MCP server that exposes MarkUp browser-extension annotations (from your local workspace folder) to AI agents like Claude Code, Claude Desktop, and Cursor.

## 官网

- 官网：https://markupextension.com
- npm 页面：https://www.npmjs.com/package/markup-mcp

## 历史版本号

- 当前版本：0.1.0

- 0.1.0

## 获取地址

- npm 安装：`npm install markup-mcp`
- npm registry：https://registry.npmjs.org/markup-mcp
- Node 要求：>=18
