# mywanip

> 标签: cli, clipboard, ip, ipify, ipv4, ipv6, network, public-ip, wan-ip

## 简介

CLI to get your public (WAN) IP using ipify or other providers, with IPv4/IPv6 support, automatic clipboard copy, and an availability ping command.
