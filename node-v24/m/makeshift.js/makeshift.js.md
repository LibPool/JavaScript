# makeshift.js

> 标签: before-after, chart, data-viz, decision-tree, gantt, heatmap, interactive, org-chart, svg, visualization, waterfall, word-diff

## 简介

A novel JavaScript visualization library with 7 unique, interactive chart types — decision trees, Gantt charts, waterfalls, org charts, heatmaps, before/after sliders, and word diff charts.
