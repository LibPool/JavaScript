# mcp-master-tester

> 标签: developer-tools, inspector, json-rpc, mcp, mcp-client, mcp-server, model-context-protocol, testing

## 简介

Local web UI to connect, inspect and test any MCP server — stdio, Streamable HTTP & SSE, with auth prompts, schema-driven tool forms, elicitation, linting and a live JSON-RPC log.
