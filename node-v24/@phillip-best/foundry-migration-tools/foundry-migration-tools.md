# @phillip-best/foundry-migration-tools

> 标签: data-model, foundry-module, foundry-vtt, foundryvtt, migration, schema

## 简介

Schema migrations for Foundry VTT module data models: a version planner, a GM-side runner that reaches invalid documents, and load-time coercion helpers.
