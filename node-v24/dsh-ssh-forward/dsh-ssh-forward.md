# dsh-ssh-forward

> 标签: deepseek-harness, dsh, dsh-plugin, port-forward, searxng, ssh, tunnel

## 简介

Keep an SSH local port forward (for example searxng on 127.0.0.1:8080) alive for DeepSeek Harness — configured entirely from a built-in Settings page, with lease-based ownership so several profiles can run at once.
