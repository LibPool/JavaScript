# @herrhelms/bulk-model-switcher

> 标签: adapter-config, agents, bulk-edit, governance, model, paperclip, paperclip-plugin, reasoning-effort

## 简介

A Paperclip plugin to bulk-reconfigure agents. Multiselect any set of a company's agents and set their model and reasoning effort in one action — every other adapter setting is preserved. Adapter type is never changed.
