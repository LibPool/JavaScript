# @powerduck/md-editor

> 标签: codemirror, editor, katex, markdown, markdown-it, markmap, math, mindmap, performance, react

## 简介

High-performance embeddable Markdown editor: KaTeX math, Markmap mindmaps, highlight.js code blocks with copy button, github-markdown-css preview, admonition blocks, rich toolbar with image/video/YouTube/table popups, keyboard shortcuts, configurable tool
