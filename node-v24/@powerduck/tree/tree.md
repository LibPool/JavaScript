# @powerduck/tree

> 标签: api-navigation, chakra-ui, documentation, openapi, powerduck, schema-explorer, tree

## 简介

Extensible tree component for API navigation, schema exploration, and documentation. Supports OpenAPI 3.2 nested tags, x-tagGroups, and custom data sources.
