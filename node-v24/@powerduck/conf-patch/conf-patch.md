# @powerduck/conf-patch

> 标签: atomic-write, comment-preserve, config, config-editor, electron, json, jsonc, rfc6902, yaml

## 简介

Two-layer configuration editor: pure core for patching JSON/JSONC/YAML strings (browser-safe), plus file layer with atomic writes and locking for Node.js/Electron. RFC 6902 JSON Patch, comment and formatting preservation, OpenAPI validation.
