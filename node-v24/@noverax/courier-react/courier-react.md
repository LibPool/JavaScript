# @noverax/courier-react

> 标签: api-client, courier, data-fetching, hooks, optimistic-updates, react, react-query, sse, suspense, tanstack-query, type-safe, typescript, websocket

## 简介

React hooks for Courier on TanStack Query: useQuery, useMutation, useSuspenseQuery and useInfiniteQuery typed from your API definition, with live SSE and WebSocket hooks and optimistic updates
