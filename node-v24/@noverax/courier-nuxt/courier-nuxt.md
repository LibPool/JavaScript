# @noverax/courier-nuxt

> 标签: api-client, bff, courier, h3, nitro, nuxt, proxy, session, ssr, type-safe, typescript, vue

## 简介

Nuxt adapter for Courier: a Nitro event handler that proxies typed calls to any backend, with the user's session in server routes and the pages Nuxt renders
