# @noverax/courier-nestjs

> 标签: api-client, bff, courier, middleware, module, nest, nestjs, nodejs, proxy, session, sse, type-safe, typescript, websocket

## 简介

NestJS integration for Courier: a module and middleware that proxy typed calls to any backend, with the user's session, CSRF protection, SSE and WebSockets
