# @noverax/courier-astro

> 标签: api-client, astro, bff, courier, proxy, session, ssr, type-safe, typescript

## 简介

Astro adapter for Courier: an API endpoint that proxies typed calls to any backend, with the user's session in pages, endpoints and actions
