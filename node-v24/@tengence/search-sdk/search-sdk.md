# @tengence/search-sdk

> 标签: dataset, full-text-search, http-client, mcp, saas, search, tengence

## 简介

Tengence Search SDK: lazy auto-registration, dataset/search-app initialization, data push and full-text search (thin HTTP client, no local business database). 通智搜索 SDK：自动注册 + 初始化 + 推送 + 搜索（薄 HTTP 客户端）
