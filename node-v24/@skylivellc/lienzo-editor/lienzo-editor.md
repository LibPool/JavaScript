# @skylivellc/lienzo-editor

> 标签: custom-element, landing-page, lienzo, page-builder, visual-editor, vue

## 简介

Visual editor for Lienzo landing pages. A Vue 3 component and a <lienzo-editor> custom element that talk to any backend over the Lienzo protocol.
