# @sengol/instrument

> 标签: JavaScript

## 简介

TypeScript MCP tool-hash producer for Sengol rug-pull detection (ADR-0105/ADR-0107) — decorates an MCP Transport, hashes tool definitions byte-identically to the Python producer, and delivers them to a Sengol server.
