# @iserter/wp-test-env

> 标签: docker, playwright, plugin-development, testing, woocommerce, wordpress, wp-cli

## 简介

Docker-based multi-version WordPress + PHP test environment for plugin and theme developers. Run WP 6.1–7.0 × PHP 8.1–8.5 in parallel, with WooCommerce and seeded e-commerce data.
