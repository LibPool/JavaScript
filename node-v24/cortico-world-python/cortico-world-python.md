# cortico-world-python

> 标签: bridge, cortico, cortico-world, plugin, python

## 简介

Cortico World 扩展：通过 stdio JSON-RPC 桥接协议，让用 Python 编写的插件也能以原生 Cortico World 协议（工具 / 事件 / store）接入 agent。
