# @dir-ai/voyager-agent

> 标签: ai-agents, cognitive-architecture, model-context-protocol, orchestration, senses, voyager

## 简介

The one universal Voyager: a thin, model-independent orchestrator that turns modular senses (net, repo, …) into CognitiveClaims, runs a live mission, links evidence into causal chains, and acts only through consent. Composition, not a monolith.
