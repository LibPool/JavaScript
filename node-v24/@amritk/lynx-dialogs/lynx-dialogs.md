# @amritk/lynx-dialogs

> 标签: action-sheet, date-picker, dialog, lynx, mjst, native-module, typescript

## 简介

Native date pickers and action sheets for Lynx: an Android and iOS native module, and a promise-shaped facade that reaches it from the main thread.
