# @publier/primitives

> 标签: JavaScript

## 简介

MDX-facing interactive primitives for Publier (Accordion, Tooltip, Tabs, CopyButton, ImageZoom, ColorSwatch, ViewAnimation). Zero-Qwik Astro components built on daisyUI + HTML natives + lazy-upgraded web components.
