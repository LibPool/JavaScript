# @indusagi/bg-process

> 标签: ai-agent, background-jobs, background-processes, cli, dev-tools, indusagi, indusagi-extension, indusagi-package, monitoring, process-management, tui

## 简介

Background process manager extension for indusagi. Run long-running commands (dev servers, builds, tests) without blocking your AI agent workflow.
