# @mailkaro/editor

> 标签: angular, beefree-alternative, drag-and-drop, drag-and-drop-email, editor, email, email-builder, email-editor, email-templates, embeddable, iframe, mjml, newsletter-builder, react, react-email-editor, unlayer-alternative, vue, white-label

## 简介

White-label, embeddable drag-and-drop email editor for React — a drop-in Unlayer alternative. Loads from a hosted iframe so the editor never ships in your bundle (and embeds in any framework via the bridge), and renders email-safe HTML + MJML from the API
