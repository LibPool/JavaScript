# @hemant_jawale/rapid-log

> 标签: async, batching, circuit-breaker, json-logger, logger, logging, performance, typescript

## 简介

A high-performance, asynchronous Node.js logger featuring circuit breakers, batching, compression, and multiple transports (Console, HTTP). Built for scale and reliability.
