# @esneiderbravo/speclaw

> 标签: ai-agents, claude-code, code-graph, cursor, mcp, mcp-server, skills, spec-driven-development

## 简介

Where specs become law. A self-contained MCP suite that turns any repo into a spec-driven, multi-agent-ready project: its own constitution (Foundation), local code graph (Compass), spec workflow (Lawbook), and multi-agent brain (Cortex). No external CLIs,
