# @socprime/logtotal-sanitizer

> 标签: anonymization, gdpr, log-analysis, logs, masking, pii, privacy, pseudonymization, redaction, sanitizer, security

## 简介

Framework-agnostic log sanitizer that detects and pseudonymizes secrets, PII and infrastructure identifiers in log data, in the browser and in Node.js.
