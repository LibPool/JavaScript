# @discourse/ember-instantsearch

> 标签: algolia, autocomplete, ember, ember-addon, instantsearch, typesense, ui

## 简介

A Ember v2 addon which acts as a wrapper for Algolia's InstantSearch library integrated with a Typesense adapter
