# @kodax-ai/kodax

> 标签: ai, anthropic, cli, coding-agent, llm, openai

## 简介

KodaX lightweight coding agent - TypeScript implementation with 16 built-in LLM provider aliases, published as a Node-free single-file CLI and SDK
