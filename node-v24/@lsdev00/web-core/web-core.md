# @lsdev00/web-core

> 标签: auth, cache, content-security-policy, csp, nextjs, rate-limit, revalidation, rls, sanitize, security, server-actions, supabase, xss

## 简介

Security foundation for Next.js projects: auth guards, an action factory, serverless-safe rate limiting, HTML sanitizing, a two-zone CSP, a consent store, and audits that find Server Actions nobody guarded, writes nobody invalidated, HTML nobody sanitized
