# @crypticsaiyan/twincli

> 标签: bisect, bug-report, cli, environment, mcp, reproduce, sandbox, solari, works-on-my-machine

## 简介

Capture a failing environment on one machine, replay it on a Solari sandbox, and find the difference that breaks it.
