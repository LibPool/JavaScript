# @pane-app/cli

> 标签: cli, component-model, extension, launcher, pane, wasm

## 简介

Pane's command-line tool for extension authors: pane-ext creates, develops, checks and packs an extension package, and builds JavaScript and TypeScript with nothing but Node.js and npm
