# freebuff-core

> 标签: codebuff, dsh, freebuff, magpie, opencode

## 简介

Freebuff protocol core: device signing, catalog, session admission, SSE tool-call parsing and message normalization. Shared by the magpie plugin and the DSH gateway — not meant to be installed directly.
