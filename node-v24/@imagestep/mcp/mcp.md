# @imagestep/mcp

> 标签: agents, image, imagestep, mcp, model-context-protocol, remove-background, upscale

## 简介

ImageStep MCP server — the image pipeline for agents: presets, assets and jobs as seven tools (generate · transform · run_preset · save_preset · job_status · search_assets · send_feedback). Runs locally over stdio (npx) or remotely over Streamable HTTP.
