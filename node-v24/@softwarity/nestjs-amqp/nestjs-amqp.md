# @softwarity/nestjs-amqp

> 标签: activemq, amqp, amqp1, amqp1.0, artemis, decorator, dlq, messaging, nestjs, pubsub, qpid, rabbitmq, rhea, rxjs

## 简介

AMQP 1.0 integration for NestJS, powered by rhea. Decorator-based publishers and consumers, RxJS-friendly, with optional DLQ browser.
