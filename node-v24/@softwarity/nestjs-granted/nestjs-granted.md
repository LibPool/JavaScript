# @softwarity/nestjs-granted

> 标签: access-control, authorization, decorator, guard, jwt, nestjs, permissions, rbac, roles, security

## 简介

RBAC security for NestJS endpoints. Decorator-based authorization with composable boolean specifications and pluggable principal providers (HTTP headers or JWT).
