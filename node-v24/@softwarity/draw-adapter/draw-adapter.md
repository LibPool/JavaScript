# @softwarity/draw-adapter

> 标签: adapter, drawing, geojson, headless, leaflet, map, maplibre, openlayers, sigmet, sigwx, softwarity, terra-draw

## 简介

Headless map adapter (grafts on MapLibre / OpenLayers / Leaflet, Terra-Draw-style) for the @softwarity drawing libs. Generic, data-driven, zero domain types.
