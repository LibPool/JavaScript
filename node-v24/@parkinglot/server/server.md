# @parkinglot/server

> 标签: agent, browser, cli, parkinglot, relay, websocket

## 简介

ParkingLot: Drive a real browser owned by the human user. Relay daemon: WebSocket server, CLI + HTTP for agents, session registry, event cache, command ledger.
