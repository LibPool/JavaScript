# @0xgasless/mcp

> 标签: 0xgasless, agent-wallet, ai-agents, erc-8004, mcp, model-context-protocol, stablecoin, usdc, x402

## 简介

Model Context Protocol server for the 0xGasless platform — give any AI agent a KMS-custodied wallet that pays via x402, plus ERC-8004 identity/reputation/validation and the Apify tool gateway. Front door only: one project API key.
