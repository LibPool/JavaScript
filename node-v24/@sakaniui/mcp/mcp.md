# @sakaniui/mcp

> 标签: ai, claude, cursor, design-system, mcp, model-context-protocol, react, sakaniui

## 简介

SakaniUI MCP server: lets AI editors look up components, props, tokens and icons, and check code, instead of guessing. Read-only, zero dependencies.
