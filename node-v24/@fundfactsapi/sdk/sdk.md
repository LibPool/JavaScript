# @fundfactsapi/sdk

> 标签: ETF, ISIN, SRRI, TER, UCITS, api, factsheet, finance, fund data, fundfacts, holdings

## 简介

Official client for FundFacts API: structured fund & ETF data from any ISIN (key facts, TER, risk, holdings, exposure, performance), plus batch, search, portfolio look-through and overlap.

- 官网：https://fundfactsapi.com
- 源码仓库：git+https://github.com/fundfactsapi/fundfactsapi-js.git
- npm 页面：https://www.npmjs.com/package/@fundfactsapi/sdk
