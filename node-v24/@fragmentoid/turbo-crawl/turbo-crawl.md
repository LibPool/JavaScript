# @fragmentoid/turbo-crawl

> 标签: claude, claude-code, cli, codex, crawler, extraction, llm, playwright, scraper, scraping, structured-data, tui, web-scraping

## 简介

Turn any web page into structured JSON. Claude Code or Codex writes a reusable extraction template once per URL pattern; every other page is scraped without calling a model.
