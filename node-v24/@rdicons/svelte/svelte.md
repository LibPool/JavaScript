# @rdicons/svelte

> 标签: animated-icons, heroicons, icons, lucide, material-icons, phosphor, rdicons, svelte, svelte-icons, svelte5, svg, tabler

## 简介

79,000+ open-source icons for Svelte 5, from 19 libraries: one Icon component plus tree-shakable icon data. Import only what you use, e.g. import { House } from '@rdicons/svelte/lucide'.
