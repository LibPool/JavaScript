# @rdicons/react-native

> 标签: expo, heroicons, icons, lucide, material-icons, phosphor, rdicons, react-native, react-native-svg, svg, tabler

## 简介

79,000+ open-source icons as React Native components, from 19 libraries, drawn with react-native-svg. Import one library at a time, e.g. import { House } from '@rdicons/react-native/lucide'.
