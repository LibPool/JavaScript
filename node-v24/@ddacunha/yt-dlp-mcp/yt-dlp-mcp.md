# @ddacunha/yt-dlp-mcp

> 标签: comments, dive, llm, mcp, youtube, yt-dlp

## 简介

An MCP server implementation that integrates with yt-dlp, providing video, audio, and comment download capabilities (e.g. YouTube, Facebook, Tiktok, etc.) for LLMs.
