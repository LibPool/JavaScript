# agentic-numerical-control

> 标签: claude, cnc, cncjs, gcode, grbl, mcp, mcp-app, toolpath

## 简介

Agentic Numerical Control: see and run CNC jobs from your AI assistant. A 3D toolpath viewer, live machine status and job control for GRBL machines, with a built-in CNCjs engine.
