> 标签: fluent-community, hyper-human-club, mcp, model-context-protocol, read-only, rest-api, typescript, wordpress, zod

## 简介

Framework-agnostic core library: GET-only HTTP client, Zod envelopes, and 13 read-only operations for the Hyper Human Club / Fluent Community REST API.
