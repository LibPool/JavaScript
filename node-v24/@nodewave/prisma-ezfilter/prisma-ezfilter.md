# @nodewave/prisma-ezfilter

> 标签: database, dynamic-queries, filter, framework-agnostic, multi-level-relations, nested-relations, orm, prisma, query, query-builder, search, typescript

## 简介

A TypeScript package for building dynamic Prisma queries with type-safe filtering, searching, ordering, and range filtering with support for multi-level nested relations
