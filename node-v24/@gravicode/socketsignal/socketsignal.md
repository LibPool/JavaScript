# @gravicode/socketsignal

> 标签: bidirectional, realtime, rpc, signalr, socket.io, socketsignal, websocket, websockets

## 简介

Node.js client for SocketSignal - bidirectional realtime RPC over raw WebSockets. Call server methods and get return values back; the server can call methods on you. No dependencies. Built by Gravicode Studios, led by Kang Fadhil.
