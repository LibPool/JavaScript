# @frontlint/stylelint

> 标签: stylelint, stylelint-config-standard-scss, stylelint-order

## 简介

[stylelint](https://stylelint.io) 是一个强大的 CSS 代码检查工具，用于强制执行一致的代码风格，避免样式错误并提高代码质量。通过自定义规则集，可以确保团队遵循统一的 CSS 编码标准
