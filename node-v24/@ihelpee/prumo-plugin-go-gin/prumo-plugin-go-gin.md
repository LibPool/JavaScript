# @ihelpee/prumo-plugin-go-gin

> 标签: JavaScript

## 简介

Go/Gin plugin for Prumo: mutation route guards (inline/Group.Use/Engine.Use), error-handling enforcement, payload binding validation, and Go-native oracle isolation.
