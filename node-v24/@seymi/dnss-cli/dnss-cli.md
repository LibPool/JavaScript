# @seymi/dnss-cli

> 标签: cli, dns, dns changer, dns switch, dns-changer, dnss, netsh, network

## 简介

DNSS (DNS Switch) - a CLI to change your DNS servers on Windows, macOS and Linux. DNS changer with built-in presets, benchmarking and easy config management.
