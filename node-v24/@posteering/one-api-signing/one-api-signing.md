# @posteering/one-api-signing

> 标签: fintech, hmac, one-api, posteering, request-signing

## 简介

Official HMAC request signer for the Posteering One API (the One-Api-Hmac-* consumer leg). Self-contained, zero-dependency, drift-guarded against the gateway verifier.
