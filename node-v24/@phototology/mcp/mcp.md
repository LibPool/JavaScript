# @phototology/mcp

> 标签: ai, analyze-once, cache-hits, delta-billing, exif, image-analysis, iptc, local-files, mcp, mcp-server, metadata, model-context-protocol, perceptual-hash, photo-intelligence, photo-metadata, photo-registry, phototology, registry, vision, visual-memory, xmp

## 简介

Persistent memory for visual intelligence. MCP server for the Phototology registry: analyze photos with composable lenses, enrich files with EXIF/IPTC/XMP metadata, and look up cached results for free. Works with local files. Analyze once. Remember foreve
