# @cazala/party

> 标签: boids, canvas-rendering, collision-detection, dual-runtime, flocking, fluid-dynamics, forces, gpu-compute, interactive, modular-architecture, oscillators, particle-physics, particles, physics-engine, real-time, simulation, spatial-grid, sph, typescript, webgpu

## 简介

High-performance TypeScript particle physics engine with dual runtime support (WebGPU compute + CPU fallback). Features modular architecture, real-time parameter oscillation, advanced physics modules, and comprehensive rendering capabilities.
