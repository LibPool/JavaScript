# @clankersupport/widget-rsc

> 标签: ai, chat-widget, customer-support, headless, nextjs, react, react-server-components, rsc

## 简介

Embed the Clanker Support AI chat widget in a React Server Components app — one component in your Next.js root layout, with headless primitives and hooks when you want to bring your own UI.
