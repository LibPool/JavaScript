# @devpossible/ton

> 标签: configuration, data-format, parser, schema, serializer, text-object-notation, ton, tonspec, validator

## 简介

JavaScript library for parsing, validating, and serializing TON (Text Object Notation) files. Full specification at https://tonspec.com. ALPHA RELEASE: Core functionality is complete but API may change before stable 1.0 release.
