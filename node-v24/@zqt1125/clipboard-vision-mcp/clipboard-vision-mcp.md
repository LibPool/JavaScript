# @zqt1125/clipboard-vision-mcp

> 标签: clipboard, mcp, ocr, openai-compatible, vision

## 简介

Clipboard-first MCP server that gives vision-less LLMs image recognition via OpenAI-compatible vision models. Enhanced: primary+backup model failover, TTL result cache, Chinese description output.
