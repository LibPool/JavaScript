# @stapel/drive-react

> 标签: JavaScript

## 简介

Phone-first Drive product over stapel-docs 0.6: starred / recents / name search / thumbnails, a share sheet over the docs pair's share axis, an upload queue with real per-file progress (XHR PUT, concurrency 2, quota-507 state), folder navigation one rung
