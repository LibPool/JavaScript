# @stapel/analytics

> 标签: JavaScript

## 简介

Stapel analytics facade implementation: consent gate, PII guard, offline queue, provider fan-out (console + Stapel collector), typed defineEvent/tracked. The type seam it implements lives in @stapel/core.
