# @xnetjs/billing

> 标签: JavaScript

## 简介

Plug-and-play, provider-agnostic billing (Stripe + Bitcoin/BTCPay) for the self-hostable hub — a PaymentProvider port, a canonical billing model, webhook verification, and an idempotent billing store. Zero runtime dependencies (node:crypto + fetch).
