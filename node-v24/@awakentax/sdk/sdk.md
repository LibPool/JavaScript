# @awakentax/sdk

> 标签: api, awaken, crypto, embedded, sdk, tax

## 简介

Official TypeScript SDK for the Awaken Embedded Tax API. Find or create a user, attach their wallets, and get a portal URL they can open.

## 官网

- 官网：https://awaken.tax/docs/embedded/overview
