# @examples-ai/puppeteer-browser-serverless

> 标签: automation, aws-lambda, browser, kit, puppeteer, serverless, typescript, vercel

## 简介

TypeScript wrapper for Puppeteer Browser to simplify browser automation tasks. It's dedicated to serverless platforms like Vercel and AWS Lambda.
