# @treygrr/nuxt-opentelemetry

> 标签: nitro, nuxt, nuxt-module, observability, opentelemetry, otel, tracing

## 简介

OpenTelemetry tracing for Nuxt servers: starts the Node SDK before Nitro and names each request span after its Nuxt route.
