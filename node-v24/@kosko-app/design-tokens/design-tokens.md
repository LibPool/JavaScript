# @kosko-app/design-tokens

> 标签: JavaScript

## 简介

Kosko's design system for every repo that draws Kosko UI: the resolved colour, scale and font tokens, every icon glyph, and the design-system check that keeps raw values out. Generated from content-vault's design/ — one source.
