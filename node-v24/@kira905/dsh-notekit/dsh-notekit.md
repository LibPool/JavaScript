# @kira905/dsh-notekit

> 标签: anchor, byte-exact, correction-note, deepseek-harness, document-editing, dsh, idempotent, markdown, rollback

## 简介

Anchor-based correction notes for production documents with byte-exact LIFO rollback: exactly-one-match anchors, idempotency guard, dry-run by default, transactional writes.
