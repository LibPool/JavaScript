# @kira905/dsh-ecosystem-panel

> 标签: deepseek-harness, diagnostics, dsh, dsh-plugin, health-check, panel, plugin, read-only

## 简介

Read-only ecosystem overview panel for a DSH instance: plugin bundles, cordis.patch inserts, patch health, skills, upgrade health and decoupling health. One tab per category. Zero runtime npm dependencies.
