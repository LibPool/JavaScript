# @rogerta/cem-plugin-isolated-mixins

> 标签: custom-elements, custom-elements-json, custom-elements-manifest, customelements, customelementsjson, customelementsmanifest, isolatedDeclarations, mixin, webcomponents

## 简介

A plugin for @custom-elements-manifest/analyzer that creates class declarations from variable declations that are classes defined as mixins of other classes.
