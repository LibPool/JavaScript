# @dynamic-labs/crypto-keys-utils

> 标签: JavaScript

## 简介

Small node-only key helpers shared across Dynamic services and SDKs: RFC 7638 JWK thumbprint, SEC1 P-256 point expansion, constant-time byte compare, and byte-native secp256k1 public-key derivation and digest signing.
