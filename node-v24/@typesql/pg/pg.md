# @typesql/pg

> 标签: introspection, no-codegen, node-postgres, pg, postgres, postgresql, raw-sql, sql, type-level, type-safe, typescript

## 简介

node-postgres (pg) adapter for TypeSQL, with `typesql introspect` to generate a schema from a live database.
