# @aravinthkumarv/easycss

> 标签: a11y, accessibility, bootstrap-alternative, css, css-framework, no-build, responsive, tailwind-alternative, utility-css, utility-first

## 简介

A simple, utility-first CSS framework built accessibility-first, with responsive breakpoints from watch screens to ultra-wide displays. One file, no build step.
