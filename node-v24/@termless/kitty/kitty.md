# @termless/kitty

> 标签: headless, kitty, terminal, terminal-emulator, terminal-testing, tui, vt-parser

## 简介

Kitty backend for termless — uses kitty's VT parser via subprocess bridge (GPL-3.0 dependency, not distributed)
