# @termless/swash-render

> 标签: headless, napi-rs, rasterizer, rust, swash, terminal, terminal-testing, tui

## 简介

Pure-native swash text rasterizer for termless — cell grid → RGBA via napi-rs, browser-grade color-emoji fidelity with no Skia
