# @apislash/storage-web

> 标签: apislash, encrypted, indexeddb, local-first, offline, storage, sync, typescript

## 简介

Browser storage adapter (localStorage/session/volatile KV + IndexedDB structured store) for the Apislash storage core. Usable in any web app; published by Apislash.
