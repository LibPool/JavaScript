# @navalone/react

> 标签: drawer, mega-menu, menu, mobile-menu, navalone, navbar, navigation, off-canvas, react, responsive

## 简介

React wrapper for Navalone — a free, open-source responsive main-menu plugin. A thin adapter over the framework-agnostic core.
