# api-recon

> 标签: api, crawler, discovery, documentation, openapi, playwright, recon, report

## 简介

Discover a website's APIs by driving a headless browser and export categorized reports (JSON, Markdown, HTML, PDF, OpenAPI, interactive dashboard).
