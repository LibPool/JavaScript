# @hot-teapot/mock-yard

> 标签: api-mocking, devtools, faker, faker-js, frontend, http, http-mocking, mock, mock-server, mock-service-worker, mocking, msw, openapi, orval, react, react-devtools, rest, scenarios, service-worker, swagger, testing

## 简介

A browser devtools panel for MSW, built for orval + Faker. Toggle mocked endpoints, switch success/empty/error/custom scenarios, tweak latency & status, and inspect traffic — without touching code.
