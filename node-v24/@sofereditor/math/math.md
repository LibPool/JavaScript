# @sofereditor/math

> 标签: editor, latex, math, mathjax, sofer, svg

## 简介

@sofereditor/math — renders LaTeX formulas as self-contained SVG using MathJax. Pure, DOM-free engine for the Sofer editor's math formula feature.
