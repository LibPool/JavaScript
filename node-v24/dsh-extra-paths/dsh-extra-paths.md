# dsh-extra-paths

> 标签: bash, cordis, deepseek, dsh, dsh-plugin, filesystem, harness, permissions, sandbox, settings, writable-roots

## 简介

配置一组额外可写根：fs 工具与受限 shell 首次尝试即可写、无需审批，带 Web 设置页与按目录结构锚定的路径模式。 · DSH plugin: configured extra writable roots for the fs tools and the sandboxed shell, with a Web settings page and structure-anchored path patterns.
