# @iredtea/oxlint-plugin-jsdoc

> 标签: jsdoc, lint, oxlint, oxlint-plugin, tsdoc

## 简介

Правила oxlint про JSDoc, которых нет в его плагине jsdoc: require-jsdoc для экспортов и check-param-names
