# @medusasec/sensitive-spans

> 标签: ai-agents, attribution, browser-agents, dlp, pii, prompt-injection, receipts, secrets, webmcp

## 简介

Dependency-free browser-side primitives from the Medusa extension: sensitive-span detection with measured precision guards, actor attribution (human vs. agent), actor-aware policy, pseudonymization, and signed receipt chains.
