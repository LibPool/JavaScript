# @imagina-build/ias

> 标签: JavaScript

## 简介

The SDK of Imagina Application Services (IAS) for Expo and React Native apps: ias.sync, the offline-first client of the v1 sync contract; ias.push, the device in push notifications and the sync notices; and the config plugin that sets the app up from ias.
