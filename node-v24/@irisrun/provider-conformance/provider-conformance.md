# @irisrun/provider-conformance

> 标签: JavaScript

## 简介

Iris model-provider conformance suite — an importable, runner-agnostic harness that certifies any model_call performer (buffered + streaming) against the vendor-neutral model port. Two providers pass the same tests; pass it and yours is a first-class Iris
