# @irisrun/channel-core

> 标签: JavaScript

## 简介

Iris channel port — the narrow, replay-safe contract every channel implements: mint the sessionId, own and rotate a single-use continuation token (rotate only on a committed turn; keep it on a non-committed one), an atomic single-use in-flight claim, norm
