# @jackchuka/bnpm

> 标签: cli, deprecate, interactive, npm, packages, pnpm, publisher, registry, tui

## 简介

Better (p)npm: the same npm or pnpm with an interactive layer. Missing arguments become prompts, and `mine` manages the packages you publish.
