# @hilma/auth

> 标签: JavaScript

## 简介

Auth is an autentication package for react.js client applications. This package works with Hilma servers, like [auth-nest](https://github.com/hilma-tech/auth-nest) or [hilma-auth-server](https://github.com/hilma-tech/hilma-auth-server) (for `Loopback` app
