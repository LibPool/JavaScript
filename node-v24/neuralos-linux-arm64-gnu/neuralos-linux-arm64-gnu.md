# neuralos-linux-arm64-gnu

> 标签: embeddings, linux-arm64-gnu, needle, neuralos, offline, on-device, tool-calling

## 简介

neuralOS engine (libneedle3) and base weights (needle3.cact) for linux-arm64-gnu — the platform payload for the neuralos package. Install neuralos instead of this package directly.
