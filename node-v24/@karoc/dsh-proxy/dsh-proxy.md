> 标签: deepseek-harness, dsh, model-provider, plugin, proxy, settings, smoothly-proxy, sp

## 简介

Smoothly Proxy (思磨力代理插件): external DeepSeek Harness plugin — a model-provider forward proxy with per-host routing and a Settings page.
