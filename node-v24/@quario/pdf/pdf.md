# @quario/pdf

> 标签: browserless, csp, pagination, pdf, quario, report

## 简介

Tiny, browserless PDF render target for quario. Pagination, embedded fonts and deterministic bytes, with no Chromium.

## 官网

- 官网：https://getquario.com
- 源码仓库：git+https://github.com/getquario/quario.git
- npm 页面：https://www.npmjs.com/package/@quario/pdf
