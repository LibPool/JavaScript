# @tuckn/wsh-packager

> 标签: CMD, JScript, VBScript, WSF, WSH, Windows, cli, compress, minify, pack

## 简介

Node.js CLI to package WSH scripts that are defined in a Windows Script File (.wsf) into one WSH file.
