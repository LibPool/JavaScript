# kinetik-ui

> 标签: ai, animation, components, expo, mcp, react-native, reanimated, registry, shadcn, skia

## 简介

Add Kinetik UI motion components to an Expo project: copies the source, installs SDK-compatible dependencies, and serves the registry to AI agents over MCP.
