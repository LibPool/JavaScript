# @tarahi/cfnsync

> 标签: aws, cfn, change-set, ci, cli, cloudformation, deploy, iac

## 简介

Sync a directory of raw CloudFormation templates to stacks (detect changes, create/diff/execute change sets, manage stacks in dependency order).
