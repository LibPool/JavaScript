# @0k/geo-map

> 标签: geojson, gpx, kml, kmz, leaflet, map, openstreetmap

## 简介

A host-fed, framework-free map widget (Leaflet 1.9) that shows KMZ / KML / GPX / GeoJSON tracks and places over free basemaps.
