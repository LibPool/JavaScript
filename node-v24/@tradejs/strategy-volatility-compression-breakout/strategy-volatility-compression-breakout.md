# @tradejs/strategy-volatility-compression-breakout

> 标签: ai, backtesting, binance, bybit, claude, codex, coinbase, crypto, plugin, strategy, tradejs, trading

## 简介

Compression-to-expansion breakout strategy using ATR and Bollinger ranks, range expansion, volume, and optional context filters for TradeJS.
