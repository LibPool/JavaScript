# @devlite/nodejs

> 标签: ai, apm, devlite, error-monitoring, error-tracking, logging, monitoring, observability

## 简介

DevLite Node.js SDK — AI-powered observability with 1-3 line integration. Automatic error grouping, source context, user impact tracking, and sensitive-data scrubbing built in.
