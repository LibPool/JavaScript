# @devtools-code/widget

> 标签: devtools, dexie, indexeddb, offline-first, outbox, pwa, shadow-dom, synchronization

## 简介

DevTools widget embebido para aplicaciones Offline-First (solo desarrollo): simulación de red, monitor de Outbox, explorador de IndexedDB, contratos y timeline.
