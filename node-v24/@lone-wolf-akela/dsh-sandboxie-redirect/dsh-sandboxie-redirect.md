# @lone-wolf-akela/dsh-sandboxie-redirect

> 标签: copy-on-write, deepseek-harness, dsh, dsh-bundle, dsh-plugin, permission-preset, sandbox, sandboxie, windows

## 简介

DSH bundle adding a copy-on-write permission preset: shell commands run inside a per-workspace Sandboxie box, so writes outside the workspace land in the box's copy while the real disk is untouched.
