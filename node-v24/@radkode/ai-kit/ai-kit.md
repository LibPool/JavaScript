# @radkode/ai-kit

> 标签: JavaScript

## 简介

Building blocks for AI agents in TypeScript apps: task definitions with wire-safe manifests, a provider-wrapped runner with schema-enforced output, two-phase token/dollar budgets, tenant-namespaced caching, metadata-only telemetry, and eval scaffolding.
