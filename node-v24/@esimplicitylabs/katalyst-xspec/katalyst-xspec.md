# @esimplicitylabs/katalyst-xspec

> 标签: api, bdd, cli, cucumber, hybrid, playwright, terminal, testing, tui, ui

## 简介

Playwright-BDD testing framework for API/UI/hybrid/TUI: fixtures, ports, adapters, step definitions, and the katalyst-xspec CLI (init, upgrade, stubs).
