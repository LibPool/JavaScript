# medusa-mcp

> 标签: analytics, claude, ecommerce, mcp, mcp-apps, medusa, medusajs, model-context-protocol, oauth

## 简介

MCP server for the Medusa v2 Admin API – orders, payments, returns, order edits, products, inventory, promotions, bulk changes, sales/customer/restock analytics with interactive MCP Apps dashboards. stdio or remote (Streamable HTTP + OAuth 2.1).
