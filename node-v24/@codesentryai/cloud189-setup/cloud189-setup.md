## 简介

Cloud189 Agent Storage one-command installer — installs CLI + MCP, runs QR login, creates /AgentStorage folders, enables Data Leak Guard, prints MCP config. Free cloud storage for AI agents powered by Tianyi Cloud 189 / 天翼云盘.
