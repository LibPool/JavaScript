# @nextblock-cms/sdk

> 标签: JavaScript

## 简介

The typed block-authoring contract of [NextBlock](https://github.com/nextblock-cms/nextblock), the open-core CMS for Next.js and Supabase. Use it to type a block's content schema, its renderer and its CMS editor.
