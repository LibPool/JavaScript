# skilllib

> 标签: agent-skills, ai-agents, claude, claude-code, cli, codex, cursor, grok, skill-md, skills, skills-manager, tui, zed

## 简介

Manage your agent skills like dependencies. One library for all your skills; each repo gets only the ones it needs, and every agent can see them. Works with Claude Code, Cursor, Codex, Zed and Grok.
