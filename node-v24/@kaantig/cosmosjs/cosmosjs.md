# @kaantig/cosmosjs

> 标签: akash, akt, atom, band, certik, cosmos, cosmosjs, cosmostation, ctk, ibc, iov, iris, javascript, kaantig, kava, protobuf, scrt, secret, stargate, starname, tendermint

## 简介

A JavasSript Open Source Library for Cosmos Network, IRISnet, Kava, Band Protocol, Starname, Secret Network, Akash, and Certik. It supports for protobuf signing
