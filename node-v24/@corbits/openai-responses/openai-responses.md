# @corbits/openai-responses

> 标签: corbits, inference, interchange, openai, responses

## 简介

Interchange ProviderAdapter for the OpenAI Responses API wire protocol with quirks-based vendor configuration, SSE and non-streaming parsing, and reasoning signature replay.
