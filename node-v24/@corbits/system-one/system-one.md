# @corbits/system-one

> 标签: corbits, evaluation, inference, interchange, system-one, typesafe

## 简介

Typed-decision evaluation client for System One (Jev-class) models: arktype question/decision schemas, endpoint configuration with gateway override, and timeout/fallback semantics.
