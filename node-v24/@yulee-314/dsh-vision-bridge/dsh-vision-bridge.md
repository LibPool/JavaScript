# @yulee-314/dsh-vision-bridge

> 标签: JavaScript

## 简介

自包含的 DeepSeek Harness 视觉系统：DeepSeek 视觉孪生路由（原生图片体验 + 视觉桥请求层拦截）+ 本地 Ollama Agentic Vision 工具（describe/OCR/结构化扫描/区域查询/元素定位/双图对比/剪贴板）+ 粘贴分流（paste-to-path）。安装即用，无本机路径依赖。
