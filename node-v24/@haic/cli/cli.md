# @haic/cli

> 标签: ai, code-generation, compiler, domain-driven-design, hexagonal-architecture, infrastructure-as-code, llm, natural-language, programming-language

## 简介

A natural-language programming language for AI to write software in. Compiles to Java, TypeScript, Python and Go, plus Docker, Kubernetes, Terraform and AWS.
