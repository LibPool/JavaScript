# @vuer-ai/dial-types

> 标签: dial, schema, types, vuer

## 简介

Shared schema contract for the Vuer dial system. Consumed by @vuer-ai/dial-cli (generator), @vuer-ai/vuer-uikit (renderer), and @vuer-ai/vuer (consumer). Types only, no runtime code.
