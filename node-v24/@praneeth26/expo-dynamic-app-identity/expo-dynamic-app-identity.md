# @praneeth26/expo-dynamic-app-identity

> 标签: activity-alias, app-icon, app-identity, app-label, dynamic-app-icon, dynamic-icon, expo, expo-plugin, react-native

## 简介

Comprehensive Expo plugin for dynamic app icon and label switching. Features: DEFAULT alias support, deep link migration, app label switching, immediate switch, toast feedback, and adaptive icon support.
