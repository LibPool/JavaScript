# @ghostystudio/widget

> 标签: ai-agents, chat, chatbot, ghosty, ghosty-studio, react, widget

## 简介

Ghosty Studio web widget for React: drop-in chat bubble (<GhostyWidget>) or headless hook (useGhostyChat) to draw your own chat.
