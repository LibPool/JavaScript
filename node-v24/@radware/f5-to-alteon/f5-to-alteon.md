# @radware/f5-to-alteon

> 标签: adc, alteon, bigip, f5, load-balancer, migration, qkview, radware, tmsh

## 简介

Migrate an F5 BIG-IP (tmsh) configuration to Radware Alteon CLI - accepts qkview/UCS archives, config folders, or bare conf files; converts virtuals (incl. tcp/udp protocol and VLAN-restricted listeners), pools, monitors, persistence, SSL, SNAT, VLANs/rou
