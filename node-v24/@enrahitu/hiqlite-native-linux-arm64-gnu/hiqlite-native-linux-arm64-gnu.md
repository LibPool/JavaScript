# @enrahitu/hiqlite-native-linux-arm64-gnu

> 标签: JavaScript

## 简介

In-process hiqlite (cache/KV + counters) as a napi-rs native addon for EnRaHiTu. Prebuilt per-platform binaries ship as optional dependencies (spec 018).
