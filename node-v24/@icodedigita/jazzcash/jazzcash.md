# @icodedigita/jazzcash

> 标签: jazzcash, nextjs, pakistan, payment-gateway, payments

## 简介

Quick JazzCash integration for custom apps: an unofficial wrapper over the JazzCash documentation (secure hash, hosted checkout, wallet, vouchers, status, refunds, IPN). Beta. By ICODEDIGITA.
