# @phalanx-engine/runtime

> 标签: deterministic, lockstep, phalanx, replay, server-simulation, snapshot

## 简介

Isomorphic match runtime for Phalanx Engine: GameDefinition, GameState snapshot contract, MatchRunner, bots as command producers and transports (client and server simulation modes)
