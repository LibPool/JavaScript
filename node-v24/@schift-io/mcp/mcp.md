# @schift-io/mcp

> 标签: claude, cursor, mcp, memory, rag, schift

## 简介

MCP server that exposes Schift memory (Gmail/Notion/Slack/Linear/GitHub/...) to Claude Code, Cursor, ChatGPT, Gemini and other LLMs.
