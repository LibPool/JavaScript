# @taein-ui/core

> 标签: accessible, animation, component-library, components, gsap, motion, react, typescript, ui, vanilla-extract

## 简介

A React UI component library where every component has its own motion — GSAP-driven, zero-runtime CSS, tree-shakable, RSC-ready, WCAG 2.2 AA.
