# publish-pilot-mcp

> 标签: automation, claude, crates, github, mcp, model-context-protocol, npm, publish, pypi, release

## 简介

MCP server that lets Claude take a project from nothing to a published GitHub repo and npm/PyPI/crates.io package: preflight, login, scaffold, checks, publish, release.
