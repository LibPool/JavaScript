# @pi-in-go/pigpen-typesafe

> 标签: evaluation, library, llm, pig-package, pigpen, typesafe

## 简介

Shared Go client for the TypeSafe AI API (a port of the official TypeScript SDK) with an own-model backend that answers the same typed questions with the model PiG is configured with. Libraries only, no extension of its own.
