# @pi-in-go/pigpen-pig-doctor

> 标签: doctor, extension, maintenance, pig-package, pigpen

## 简介

Finds and safely fixes cruft in a PiG setup: duplicate or broken extensions, unpruned caches, orphaned agent directories, legacy files. Read-only by default; every removal is backed up and restorable
