# @pi-in-go/pigpen-warden

> 标签: agent, extension, guardrails, pig-package, pigpen, safety, typesafe

## 简介

Go port of DevMortimer's pi-warden: guardrails that steer instead of interrupt. Holds irreversible tool calls, flags off-task and off-plan calls, breaks stuck loops and asks for verification of unverified done claims. Opt-in, discloses what leaves the mac
