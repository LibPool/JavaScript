# @jgbr123/prismadb

> 标签: Data, Database, I/O, Prisma, Read, Write

## 简介

PrismaDB is an extremely easy to learn and fast Database solution to Write and Read data to the disk. It caches the entire Database in the Ram, so it should only be used for small databases that don't exceed the Ram size.
