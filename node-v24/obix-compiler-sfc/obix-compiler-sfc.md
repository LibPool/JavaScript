# obix-compiler-sfc

> 标签: canonical, compiler, obix, sfc

## 简介

The canonical SFC boundary of the .obix VueTS compiler: one Vue-independent, frozen representation of template / script / script setup / style / custom blocks (lang, src, scoped, module, attributes, source locations) and a check that treats two SFCs as eq
