# @autenai/mcp

> 标签: ai-agent, android, claude-code, codex, computer-use, cursor, desktop-automation, linux, macos, mcp, mcp-server, model-context-protocol, windows

## 简介

Computer-use MCP server: give Claude Code, Codex, Cursor or any MCP client hands on a real screen: your computer (Mac/Windows/Linux) and your Android phone (beta). Clicks, types and reads the screen, even in apps with no API.
