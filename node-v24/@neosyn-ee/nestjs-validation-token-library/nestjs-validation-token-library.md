# @neosyn-ee/nestjs-validation-token-library

> 标签: cookie, jwt, nestjs

## 简介

A secure and flexible token validation library for NestJS, designed to work seamlessly with Guards. Easily integrate token verification (JWT, custom tokens, etc.) into your NestJS applications with minimal setup.
