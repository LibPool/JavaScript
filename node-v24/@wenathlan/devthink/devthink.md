# @wenathlan/devthink

> 标签: ai, cli, developer-tools, embedded-gateway, llm, provider-endpoints, streaming, terminal, web-workbench

## 简介

DevThink is the merged AI development workbench: the provider-owned gateway engine, the DevThink browser extension (the agent surface), the Antigravity engine and the workbench CLI — one product, one binary, one metadata.
