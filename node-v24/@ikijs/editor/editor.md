# @ikijs/editor

> 标签: 2d-animation, animation, auto-rig, avatar, editor, iki, live2d, puppet, rig, rigging, typescript, vtuber

## 简介

Headless editing core and auto-rigger for .iki 2D puppet models — DOM-free edit commands, undo/redo, atlas and UV math
