# @sinjoh/sdk

> 标签: ethereum, robinhood-chain, sdk, sinjoh, viem

## 简介

Core Sinjoh SDK: byte-exact configuration codecs, launch prediction, and custom-error decoding for the immutable Sinjoh protocols on Robinhood Chain.
