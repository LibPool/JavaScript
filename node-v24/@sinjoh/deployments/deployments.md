# @sinjoh/deployments

> 标签: deployments, ethereum, robinhood-chain, sinjoh, viem

## 简介

Typed Sinjoh deployment manifests for Robinhood Chain, generated from the canonical mainnet-deployments.json, with a runtime code-hash verifier.
