# @accordkit/tracer

> 标签: JavaScript

## 简介

Lightweight, vendor-agnostic tracing core for AccordKit; designed for SDKs, AI agents, and self-hosted analytics. Provides a unified Tracer interface with message, usage, and span events that can be streamed or batched to any sink.
