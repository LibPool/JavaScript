# @premon/agent-kit

> 标签: agent, ai-agent, ethereum, ethers, evm, monad, premon, security, signer, wallet

## 简介

Guard your agent / program wallet with Premon: a drop-in ethers signer + CLI that runs every transaction through Premon's pre-sign firewall and refuses to sign what your policy blocks.
