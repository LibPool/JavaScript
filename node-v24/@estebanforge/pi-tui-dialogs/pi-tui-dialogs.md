# @estebanforge/pi-tui-dialogs

> 标签: dialog, pi, settings, tui

## 简介

Framed TUI dialog kit for @estebanforge Pi extensions: bordered settings menus with label/value columns, help panel, tabs, type-to-search, and validated input dialogs. Dialog pattern adapted from pi-subagent-manager (MIT). Plain library, no Pi entrypoint:
