# @estebanforge/pi-ask-codex

> 标签: codex, delegation, gpt, openai, pi-extension, pi-package, tool

## 简介

Pi tool that delegates a self-contained sub-task to OpenAI's Codex CLI via `codex exec --json`. Streams structured events as partial output, returns the final agent message. Configurable default model + reasoning effort, with multi-turn session continuity
