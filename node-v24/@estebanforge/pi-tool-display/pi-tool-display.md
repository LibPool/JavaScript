# @estebanforge/pi-tool-display

> 标签: compact, diff, diff-visualization, output-truncation, pi-extension, pi-package, pi-tui, tool-output, tool-rendering

## 简介

Compact tool call rendering, diff visualization, and output truncation extension for Pi coding agent. Hides, collapses, and truncates verbose tool output for cleaner TUI display. (fork of MasuRii extension)
