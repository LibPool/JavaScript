# @estebanforge/pi-hostname

> 标签: footer, hostname, pi-extension, pi-package, status-bar

## 简介

Hostname indicator for Pi. Shows the machine hostname as the first item in the footer status line (bottom left), so you always know which box a session runs on across remote machines.
