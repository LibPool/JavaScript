> 标签: airbnb, anthropic, betterstr, claude, guidebook, mcp, model-context-protocol, short-term-rental, str, vacation-rental

## 简介

BetterSTR MCP server — lets Claude (Desktop, Code, etc.) edit your guidebooks, manage map pins, read reservations, send SMS, inspect WiFi, and export your WiFi marketing guest list through the BetterSTR User API.
