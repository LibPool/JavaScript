# @sub-design/mcp

> 标签: JavaScript

## 简介

A local MCP server for `@sub-design/ui` and `@sub-design/tokens` — four tools, no hosting, no auth. Answers come from whatever version of those packages is actually installed in the project the server is invoked from, not a snapshot bundled into this pack
