# quick-html-share-mcp

> 标签: agent-tool, ai-artifact, claude, claude-artifact, claude-code, codex, continue, cursor, demo-link, html, html-hosting, html-publishing, html-share, indie-saas, mcp, mcp-server, model-context-protocol, preview-link, publish-html, share-html, share-link, static-hosting, url-shortener, vibe-coder

## 简介

MCP server that lets your coding agent (Claude Desktop, Cursor, Codex CLI, Claude Code, Continue) publish HTML and get back a shareable URL with viewer analytics — in one tool call. No account, link is the secret.
