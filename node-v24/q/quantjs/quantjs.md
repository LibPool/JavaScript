# quantjs

> 标签: OpenQL, openql, quantum computing

## 简介

QuantJS is a Javascript library for quantum computing. It aims to become basic library set of quantum computer system.

- 官网：http://quantjs.org/
- 源码仓库：git+https://github.com/openql-org/quantjs.git
- npm 页面：https://www.npmjs.com/package/quantjs
