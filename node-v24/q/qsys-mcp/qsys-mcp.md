# qsys-mcp

> 标签: ai-agent, audio, audiovisual, av, claude-code, dsp, mcp, model-context-protocol, q-sys, qrc, qsc, qsys, typescript

## 简介

Control a Q-SYS audio/video system from an AI agent over QSC's QRC protocol — against a real Core or Q-SYS Designer in Emulate mode. Open-source, cross-platform, zero QSC code.
