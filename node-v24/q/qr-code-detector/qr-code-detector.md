# qr-code-detector

> 标签: barcode, base64, camera, computer-vision, decoder, detector, image-processing, native-addon, opencv, qr, qr-code, qrcode, scanner

## 简介

QR code detection and decoding with base64 image extraction. Native Node.js addon using OpenCV (WeChat CNN detector with classic fallback).
