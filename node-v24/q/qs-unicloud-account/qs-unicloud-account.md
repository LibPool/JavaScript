# qs-unicloud-account

> 标签: uni, uniCloud

## 简介

`qs-account`为`uniCloud`开发者提供了简单、统一、可扩展的账户模块云函数类插件，支持阿里云、腾讯云。

## 官网

- npm 页面：https://www.npmjs.com/package/qs-unicloud-account
