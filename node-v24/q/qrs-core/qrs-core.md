# qrs-core

> 标签: cbor, cose, digital-signature, ecdsa, ed25519, offline-first, qrcode, sdoc, tcert, verification

## 简介

SDoc Verification Protocol core: offline-first, cross-organization verification of digitally signed documents (TCert / SDoc / Statement). Minimal audited runtime dependencies (@noble/hashes, @scure/base); inversion-of-control storage and context.
