# quiz-by-kartik

> 标签: javascript, javascript-quiz, quiz

## 简介

This is a command-line interface (CLI) JavaScript quiz application that you can run in your terminal. It presents you with a series of multiple-choice questions and you can select your answer using your keyboard.
