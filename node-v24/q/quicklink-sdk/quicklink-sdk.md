# quicklink-sdk

> 标签: c2p, fintech, pago-movil, pagos, payments, quicklink, quickpay, venezuela

## 简介

SDK oficial de la QuickLink Pay API — una sola integración para cobrar y pagar sobre los rieles bancarios de Venezuela (Pago Móvil, Crédito Inmediato, Débito Inmediato/C2P). Sin dependencias.
