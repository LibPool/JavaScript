# @junjian.work/dsh-auto-permission

> 标签: JavaScript

## 简介

DSH Auto 权限预设插件：deny 规则硬拦截 + allow 规则放行 + 未命中交 AI 审批，AI 失败或低置信度且非危险时自动放行；不修改官方包。
