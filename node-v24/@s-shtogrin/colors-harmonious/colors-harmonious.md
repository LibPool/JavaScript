# @s-shtogrin/colors-harmonious

> 标签: JavaScript

## 简介

Vue 3 компонент для вибору гармонійних кольорів на HSV колі.   Побудований з використанням [Konva](https://konvajs.org/) та [chroma.js](https://gka.github.io/chroma.js/).
