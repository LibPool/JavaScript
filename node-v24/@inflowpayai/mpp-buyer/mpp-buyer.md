# @inflowpayai/mpp-buyer

> 标签: buyer, inflow, machine-payments-protocol, mpp, payments

## 简介

InFlow MPP SDK: buyer-side `inflow` method that drives the InFlow buyer endpoints (prepare → poll → cancel) and returns the server-produced credential, composed with the mppx foundation client.
