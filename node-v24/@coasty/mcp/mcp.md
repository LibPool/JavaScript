# @coasty/mcp

> 标签: agentic, ai-agent, anthropic, automation, browser-automation, claude, claude-code, claude-desktop, coasty, computer-use, cron, cursor, desktop-automation, mcp, model-context-protocol, modelcontextprotocol, scheduling, terminal, vscode, webhook, windsurf

## 简介

MCP server for Coasty — full computer use (desktop, browser, terminal, files, schedules) from Claude Desktop, Claude Code, Cursor, Windsurf, and VS Code Copilot. Sandbox VMs free, AWS/Azure for production. 26 tools, 4-mode approval, HMAC webhooks.
