# @ramstack/alpinegear-safehtml

> 标签: alpine.js, alpinejs, alpinejs-directive, alpinejs-plugin, dompurify, html-sanitizer, xss

## 简介

@ramstack/alpinegear-safehtml provides the 'x-safehtml' Alpine.js directive for rendering HTML sanitized by DOMPurify.
