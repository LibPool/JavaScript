# @tothemax/tasking

> 标签: cli, coding-agent, daemon, feishu, jira, lark, opencode, orchestration

## 简介

A TypeScript CLI daemon that orchestrates opencode coding-agent work from Jira (structured) and Feishu (unstructured) task sources.
