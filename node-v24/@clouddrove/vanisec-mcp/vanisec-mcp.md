# @clouddrove/vanisec-mcp

> 标签: claude, encryption, mcp, model-context-protocol, one-time-secret, secrets, vanisec, zero-knowledge

## 简介

MCP server for creating Vanisec one-time secrets. Encrypts locally; the server only ever receives ciphertext.
