# @tslsmart/map_adapter

> 标签: baidu, diva, esri, gaode, superapi

## 简介

an adapter for maps,基于高德JSAPI 2.0，百度JavaScript API GL,arcgis api for javascript 3.23,光辉城市及51world sdk
