# @sitegpt/mcp

> 标签: chatbot, customer-support, mcp, model-context-protocol, sitegpt

## 简介

SiteGPT MCP server launcher — run the SiteGPT Model Context Protocol server locally (npx @sitegpt/mcp) or connect to the hosted endpoint at https://sitegpt.ai/mcp.
