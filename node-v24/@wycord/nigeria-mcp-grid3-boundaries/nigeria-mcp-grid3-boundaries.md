# @wycord/nigeria-mcp-grid3-boundaries

> 标签: admin-boundaries, boundaries, geocoding, gis, grid3, lga, mcp, model-context-protocol, nigeria

## 简介

Nigeria administrative boundaries (state / LGA / ward) as MCP tools — centroid, bounding box, and reverse-geocoding a WGS84 point to its admin areas. Backed by GRID3 (CC BY 4.0), keyless. A Wycord product, built by Braynex Services Ltd.
