# @sincpro/criteria-react

> 标签: criteria, hooks, react, sincpro

## 简介

React hooks over @sincpro/criteria's Reading and Buckets, plus a query-key helper for wiring a resource into an existing cache (react-query, …). See docs/DESIGN.md at the repo root for why this is a separate package.
