# @ungic/web

> 标签: cms, mobile, pwa, react, ungic, vite

## 简介

Builds a Site's app frontends from its theme: compiles theme/screens with the ungic compiler, mounts them on the web runtime and bundles each app with Vite (buildApps / devApps).
