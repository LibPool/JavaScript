# @ortho-earth/gmaps

> 标签: globe, google-maps, maplibre, migration, ortho-earth

## 简介

Google Maps JavaScript API on MapLibre GL: a google.maps namespace (Map, Marker, AdvancedMarkerElement, InfoWindow, Polyline, Polygon, Circle, Rectangle, Data, event, geometry) that translates to any maplibregl namespace, by default @ortho-earth/globe/map
