# @ortho-earth/plugin-splat

> 标签: 3dgs, gaussian-splatting, globe, ksplat, ortho-earth, ply, sog, splat, spz, webgpu

## 简介

Gaussian splats for @ortho-earth/globe: fills the reserved map.addData kind "splat" (SplatData or .ply / .splat / .spz / .ksplat / .sog URLs), drawn as a same-frame overlay (WebGPU: spherical harmonics, GPU sort, shared device and depth; WebGL2 fallback)
