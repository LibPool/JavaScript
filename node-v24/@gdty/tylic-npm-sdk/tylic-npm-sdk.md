# @gdty/tylic-npm-sdk

> 标签: license.lic

## 简介

## 介绍 `tylic-npm-sdk` 是一个用于许可证生成与验证的软件开发工具包（SDK），主要功能包括加密、解密、签名、验签以及获取机器唯一标识等。该 SDK 适用于需要进行软件授权管理的场景，提供了一套完整的工具类接口。
