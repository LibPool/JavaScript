# moltnode-mcp

> 标签: agents, base, blockchain, chord, defi, dex, ethereum, json-rpc, mcp, model-context-protocol, monad, rpc, solana, swap

## 简介

MoltNode by Chord: MCP server to read 31 blockchains over JSON-RPC and swap through Chord. No API key. Stdio bridge to the hosted server at https://moltnode.ag/mcp.
