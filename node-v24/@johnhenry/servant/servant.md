# @johnhenry/servant

> 标签: event-listener, http, https, middleware, node, router, server, websocket

## 简介

A self-contained, batteries-included HTTP/HTTPS server with built-in routing, middleware, and WebSocket support, dispatched through a service-worker-style addEventListener('fetch', ...) API. Extracted from leserve's controls.mjs/event.mjs.
