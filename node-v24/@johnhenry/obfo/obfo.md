# @johnhenry/obfo

> 标签: dom, fill, form, formdata, forms, html, nested, object, observe, serialize, two-way

## 简介

Convert HTML forms into nested JavaScript objects and back: read a form as an object, fill a form from one, observe a form's object as it is edited, and generate a form for a JSON value.
