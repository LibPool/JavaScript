# @johnhenry/mcp-gate

> 标签: JavaScript

## 简介

A config-driven MCP security/policy proxy — authorization, DLP redaction, rate-limit, circuit breaking, and audit, fronting many upstreams as one MCP endpoint. Built on mcp-query.
