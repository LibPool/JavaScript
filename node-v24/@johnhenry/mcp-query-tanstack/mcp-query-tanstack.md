# @johnhenry/mcp-query-tanstack

> 标签: JavaScript

## 简介

TanStack Query bridge for @johnhenry/mcp-query — queryOptions/mutationOptions factories that sync mcp-query's own reactive cache into TanStack Query, including protocol push and optimistic updates, with zero extra refetches.
