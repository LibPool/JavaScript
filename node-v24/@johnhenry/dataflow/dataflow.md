# @johnhenry/dataflow

> 标签: async, async-iterator, backpressure, cancellation, control-flow, dataflow, dependency-graph, events, notebook, queue, reactive, scheduler, spreadsheet

## 简介

An async dataflow scheduler: nodes that depend on other nodes, run by your async function, with glitch-free propagation, stale-run cancellation, skip values, live nodes, sampled inputs, queued event nodes and per-node run states. Values live wherever you
