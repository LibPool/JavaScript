# @johnhenry/hostable

> 标签: gateway, http, jsx, multi-domain, reverse-proxy, router

## 简介

Declaratively describe an API gateway using JSX -- routes across multiple domains/backends by Host header, on top of @johnhenry/servable's single-app dispatcher.
