# @johnhenry/servable

> 标签: fetch, http, jsx, router, server

## 简介

Declaratively describe an HTTP server using JSX -- a small closed set of primitives, a Fetch-API dispatcher, and adapters for Node/Deno/Bun/Cloudflare.
