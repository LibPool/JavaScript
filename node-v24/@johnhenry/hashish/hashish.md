# @johnhenry/hashish

> 标签: jaccard, locality-sensitive-hashing, lsh, minhash, nearest-neighbor, similarity, text-similarity, typescript

## 简介

Locality-Sensitive Hashing (MinHash) for fast, scalable approximate nearest-neighbor / similarity search over text. TypeScript, zero native dependencies, pluggable storage (in-memory or Redis).
