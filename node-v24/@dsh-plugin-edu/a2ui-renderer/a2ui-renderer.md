# @dsh-plugin-edu/a2ui-renderer

> 标签: a2ui, deepseek, dsh, plugin, react

## 简介

A2UI browser half for dsh: renders the a2ui_render surface inline in the chat (tool/result.meta driven), with static + interactive components and <ui_action> back-channel
