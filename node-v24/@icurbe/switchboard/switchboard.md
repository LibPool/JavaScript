# @icurbe/switchboard

> 标签: agent-communication, ai-agents, claude-code, conversations, inter-agent, loops, mcp, relay, supervision

## 简介

Supervised inter-agent messaging relay for Claude Code and OpenCode (and any MCP client). Projects, environments with web consoles, focused conversations with state docs (PROGRESS.md), LangGraph review subagents, multi-provider LLM supervision, single-pan
