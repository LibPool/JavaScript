# @bvcc/agent-sdk

> 标签: ai-agent, bvcc, defi, erc-4337, ethereum, smart-wallet, viem

## 简介

TypeScript SDK for operating a BVCC Agent Wallet from an off-chain AI agent. On-chain spending limits, no private-key custody by BVCC.
