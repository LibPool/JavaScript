# @opentele2/opentele2-win32-arm64-msvc

> 标签: fingerprint, mtcute, mtproto, napi-rs, opentele2, tdata, tdesktop, telegram, telethon

## 简介

Telegram client identity toolkit on a Rust core: Telegram Desktop tdata, mtcute and Telethon sessions, official API profiles and devices, fingerprint checks, an mtcute crypto provider and browser fingerprints
