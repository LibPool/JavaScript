# mcp-tc

> 标签: claude-code, cli, cursor, mcp, mcp-client, mcp-directory, mcp-server, model-context-protocol, vscode

## 简介

Command-line tool for mcp.tc, the directory of MCP servers: search listings and add servers to your MCP clients with each vendor's own URL or package. It also helps you build an MCP server and check it the way mcp.tc reads it.
