# @packtory/bootstrap-npm-package

> 标签: bundler, bundling, modules, monorepo, npm, package, packaging, publish, publishing, versioning

## 简介

Claim a brand-new npm name so a Trusted Publisher can be configured for it (workaround for npm/cli#8544).
