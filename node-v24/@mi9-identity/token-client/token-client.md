# @mi9-identity/token-client

> 标签: identity, jwks, jwt, m2m, mi9, oauth2, rs256

## 简介

Mi9 token client — consumer-side acquireToken/forceRefresh state machine for the Mi9 Identity Service. Handles proactive refresh, 429/503 backoff, 401 revocation, and rotation pickup.
