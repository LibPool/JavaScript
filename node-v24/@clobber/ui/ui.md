# @clobber/ui

> 标签: candlestick, clobber, depth chart, market data, order book, ticker, trading, websocket

## 简介

Live market components for Clobber: order book, depth, candles, tape, venue ticker and a headless order ticket. Plain DOM, with React wrappers.
