# @lagetech/eslint-config-react

> 标签: JavaScript

## 简介

ESLint flat config for React apps, built on [`@lagetech/eslint-config`](https://github.com/lagetech-dev/tooling/tree/main/packages/eslint-config)'s base config. A separate package so Node-only projects don't install the React plugins (about 170 packages).
