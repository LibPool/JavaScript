# @cargoflow/mcp

> 标签: cargoflow, claude, mcp, model-context-protocol, trade-finance

## 简介

Model Context Protocol server for CargoFlow: read shipments, evidence and cover, verify documents, and prepare unsigned transactions for your own wallet to sign.
