# @shuji-bonji/spec-ids

> 标签: acceptance-test, agents, ci, cli, jasmine, spec, specification, traceability, vitest

## 简介

仕様 ID（SPEC-<領域>-<機能>-<3 桁>）を仕様書の見出しとテスト名で突き合わせ、CI で止める CLI。PR の種類ごとの変更範囲の検査、採番と置き場の初期化も行う。OpenSpec の置き場（openspec/）と見出し（### Requirement:）も読める
