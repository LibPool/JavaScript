# @joao.faveri/eslint-nextjs-config

> 标签: ESlint, Next.JS, Prettier, React

## 简介

This package provides a standardized ESLint configuration tailored for projects using Next.js. It aims to enforce consistent coding styles and best practices across your Next.js projects, helping to keep your codebase clean, readable, and maintainable.
