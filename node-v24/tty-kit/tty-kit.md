# tty-kit

> 标签: ansi, cli, clipboard, colors, console, filter, keypress, list, readline, terminal, tui, ui

## 简介

Terminal UI toolkit: colors, text layout, search/highlight, keypress normalization, line editing, scrolling list with selection cursor and live filter bar, prompts, clipboard, argument parsing.
