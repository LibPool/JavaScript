# @htmlbricks/hb-stylus-notebook

> 标签: JavaScript

## 简介

Notebook layout around `hb-stylus-paper`: toolbar (`part="controller"`) for modes, undo/redo, save, and file pickers; optional `load_draw` JSON restore.
