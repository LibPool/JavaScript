# @rolling-design-sync/core

> 标签: design-sync, design-to-code, diff, figma, snapshot

## 简介

Pure diff core (normalize/diff/link/markdown/contentHash) shared by the Figma plugin and the API. No Figma, browser, or Node runtime dependencies (node:crypto used when available, pure-JS sha256 otherwise).
