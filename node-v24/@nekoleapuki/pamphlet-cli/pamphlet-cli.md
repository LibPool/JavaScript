# @nekoleapuki/pamphlet-cli

> 标签: cli, commonmark, diagram, documentation, html, markdown, mermaid, self-contained, single-file, static-site

## 简介

把一份 Markdown 编译成自包含的单文件 HTML：不联网、图预渲染成静态 SVG、无 JavaScript 可降级
