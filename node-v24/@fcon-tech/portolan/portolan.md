# @fcon-tech/portolan

> 标签: JavaScript

## 简介

Portolan: an MCP server that charts codebases - Chart store, Harbor expeditions, Chart Room. Runs on Bun; requires ripgrep and ctags on PATH (wrapped, not bundled).
