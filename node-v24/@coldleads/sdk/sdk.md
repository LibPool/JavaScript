# @coldleads/sdk

> 标签: ai-agents, b2b, coldleads, crm, email-finder, email-validation, email-verification, leads, sdk

## 简介

Official Node.js SDK for the Cold Leads API and CRM: e-mail verification, e-mail finder, contact import and management, conversations, templates, campaigns, reply and follow-up queue, website capture, and AI-agent onboarding.
