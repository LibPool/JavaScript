# @velrim/scoring

> 标签: JavaScript

## 简介

Velrim scoring/matching math (per-field P/R/F1, ECE, AUROC, Brier, risk-coverage) over the 3-state golden format. Pure TS, ESM, zero runtime deps. The same code velrim-eval and the published reliability curves run.
