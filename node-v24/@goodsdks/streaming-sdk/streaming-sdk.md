# @goodsdks/streaming-sdk

> 标签: JavaScript

## 简介

TypeScript SDK for Superfluid streaming flows on Celo and Base, with GoodDollar-aware token resolution, GDA pool helpers, live CFA reads, and subgraph-backed historical queries.
