# @goodsdks/citizen-sdk

> 标签: JavaScript

## 简介

`@goodsdks/citizen-sdk` provides typed Viem clients for interacting with GoodDollar identity contracts. Use it to verify wallets, check identity expiry, generate face verification links, and manage multi-wallet linking via the IdentityV4 wallet-link flow.
