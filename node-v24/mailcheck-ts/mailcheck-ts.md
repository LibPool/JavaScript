# mailcheck-ts

> 标签: disposable, dns-over-https, email, mailcheck, mx, suggestion, typo

## 简介

Catch mistyped, disposable and undeliverable email addresses without ever refusing a real one: an offline typo suggester (a mailcheck drop-in), a disposable-domain check and a DNS-over-HTTPS MX check that refuses only on definitive DNS answers. Zero runti
