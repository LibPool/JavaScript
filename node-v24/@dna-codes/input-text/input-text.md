# @dna-codes/input-text

> 标签: anthropic, dna, input-text, llm, openai, openrouter

## 简介

Turn freeform prose describing a business system into DNA (operational, product, technical) by dispatching to an LLM provider (openai, openrouter, anthropic). Requires an API key. Zero runtime dependencies.
