# @joetjen/cooper-config

> 标签: casc, config, configuration, cooper, secrets

## 简介

Under heavy development: not for production use before 1.0.0. Loads an application's CASC configuration once, at startup, with cooper, and gives the application functions to read it -- typed literals untagged, secrets handled per block.
