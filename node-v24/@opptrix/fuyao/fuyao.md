# @opptrix/fuyao

> 标签: a-share, aicubes, api-sdk, financial-data, fund, fuyao, stock, ths

## 简介

同花顺金融数据 API (fuyao.aicubes.cn) 官方 REST 接口 TypeScript SDK，覆盖 A 股行情、财务、指数、特色数据与基金全量端点。
