# lumiose

> 标签: JavaScript

## 简介

Feels like React. Runs like vanilla JS. Lumiose is a web framework for everything from static sites and SPAs to full-stack apps: TSX with scoped CSS built in, signals, and 0 kB of JavaScript until a page needs it.
