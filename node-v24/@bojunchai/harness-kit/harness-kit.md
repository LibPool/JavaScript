# @bojunchai/harness-kit

> 标签: agents-md, ai-agents, claude-code, codex, coding-agent, developer-tools, harness-engineering, opencode, scaffolding

## 简介

A stack-agnostic scaffolding kit for AI-coding-agent harnesses. Drops a complete 5-subsystem harness (instructions / state / feedback / observability / governance) into any new or existing repo. Based on walkinglabs/learn-harness-engineering.
