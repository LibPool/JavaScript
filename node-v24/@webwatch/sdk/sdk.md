# @webwatch/sdk

> 标签: alerting, apm, error-monitoring, observability, webwatch

## 简介

Zero-config error capture SDK for WebWatch. Auto-captures uncaught errors and unhandled rejections, batches them, and sends them to your WebWatch ingest endpoint.
