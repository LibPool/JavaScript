# @sfaizi24/adb-mcp-server

> 标签: adb, agent, android, android-debug-bridge, automation, claude, hermes, llm, mcp, model-context-protocol, openclaw, remote-adb, tailscale

## 简介

Remote-network ADB MCP server. Drive Android devices over the network from any MCP-compatible agent (OpenClaw, Hermes, Claude Desktop, Claude Code, Cursor, Codex). Built for headless setups — droplets, CI, home labs, Tailscale meshes.
