# @mhf-kit/ui

> 标签: JavaScript

## 简介

mhf-kit is a convenient UI component kit that integrates MUI (Material-UI), React Hook Form, and Bootstrap-like styles. It allows you to easily and efficiently build common UI elements such as form validation and dialogs.
