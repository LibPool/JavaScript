# @hasna/secrets

> 标签: agents, ai, cli, credentials, secrets, vault

## 简介

Hosted-first secrets vault client for AI agents — CLI, MCP server and SDK against the Hasna secrets API (credentials via @hasna/contracts), with an explicit opt-in on-box encrypted vault
