# @memex-ai-ac/vitest

> 标签: acceptance-criteria, memex, memex-ai, test-tracking, vitest

## 简介

Acceptance Criteria emit helper for Vitest. Tag tests with tagAc(), emit pass/fail to a Memex workspace.
