# @memdecks/mp-runtime

> 标签: JavaScript

## 简介

Tier-2 game session engine for the memdecks platform: Socket.IO transport, match-ticket verification, room/match lifecycle, per-player views, and card provisioning. Run a single GameModule (standalone) or many (hub).
