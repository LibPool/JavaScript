# @koda-plus/medusa-plugin-tasks

> 标签: admin, ai-agents, kanban, medusa, medusa-plugin, medusa-v2, project-management, task-board, tasks, team

## 简介

Tasks by Koda Plus: a task board in the Medusa admin for the store team and the agency or developers who work with it. Board columns with drag and drop, comments, an activity log, tasks linked to orders, products and customers, secret API keys for scripts
