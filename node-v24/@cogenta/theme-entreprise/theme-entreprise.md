# @cogenta/theme-entreprise

> 标签: JavaScript

## 简介

An engineering company theme for Cogenta: Geist and Geist Mono on a twelve-column grid, full-bleed photography, hairlines instead of boxes, a designed dark mode, and zero client JavaScript.
