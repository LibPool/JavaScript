# @dzek69/telnet-client

> 标签: JavaScript

## 简介

Bad things will happen when you call `exec` while previous one is still working with [telnet-client][1] on single connection. And this is totally possible with big app with a lot of async stuff. This wrapper fixes that by queuing the calls. Original repo
