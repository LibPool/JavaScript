# @slyte/router

> 标签: JavaScript

## 简介

Routing module of the Slyte Framework providing URL-based navigation with a full route lifecycle, dynamic and wildcard URL parameters, query params, auxiliary (side-panel) routes, and a <go-to> custom element for declarative navigation.
