# vue-greenborn-markdown-viewer

> 标签: gfm, greenborn, markdown, markdown-viewer, sanitize, vue, vue3

## 简介

Visor de Markdown para Vue 3: convierte texto Markdown (GFM) en HTML formateado, sanitizado con DOMPurify, con estilos tipográficos propios y sin dependencias de UI.
