# @gaia-ai/addon-ports-frp

> 标签: JavaScript

## 简介

GAIA ports transport: a self-hosted frp (frpc) client over an operator-owned config, reconciled via its local admin API. Implements @gaia-ai/addon-ports's PortsTransport contract.
