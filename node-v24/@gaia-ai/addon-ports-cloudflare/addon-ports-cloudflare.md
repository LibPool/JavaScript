# @gaia-ai/addon-ports-cloudflare

> 标签: JavaScript

## 简介

GAIA ports transport: a named Cloudflare Tunnel, reconciled via the Cloudflare API (DNS + ingress). Implements @gaia-ai/addon-ports's PortsTransport contract.
