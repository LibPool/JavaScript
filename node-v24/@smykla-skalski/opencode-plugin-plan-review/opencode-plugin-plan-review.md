# @smykla-skalski/opencode-plugin-plan-review

> 标签: ai, code-review, coding-agent, opencode, opencode-plugin, plan-mode, planning, tui

## 简介

opencode v2 plugin for reviewable planning in the terminal: short structured plans reviewed step by step, batched questions, planning inside the build loop with checkpoints, and a what-changed digest
