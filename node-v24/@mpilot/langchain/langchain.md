# @mpilot/langchain

> 标签: JavaScript

## 简介

LangChain JS adapter for `@mpilot/tools`. Converts the framework-agnostic Concierge registry into `StructuredToolInterface[]` ready for `model.bindTools(tools)` or any LangChain agent toolset.
