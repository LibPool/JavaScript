# @mpilot/aave-v3-mantle

> 标签: JavaScript

## 简介

Aave V3 Mantle action provider for the Concierge agent. Exposes 6 `ConciergeTool` actions with Zod schemas, viem-based execution, and ERC-8004 attestation hooks.
