# @tuweizhi/dsh-translator

> 标签: cordis, deepseek-harness, deepseek-harness-plugin, dsh, dsh-plugin, free-translation-api, no-api-key, plugin, translation, word-selection, word-selection-translation, 划词翻译

## 简介

Youdao-style word-selection translation for the DSH web GUI. Select text anywhere, click the floating button, get a translation — by default through keyless public translation endpoints, with the harness's own LLM as the other engine. 有道风格划词翻译：DSH Web GUI
