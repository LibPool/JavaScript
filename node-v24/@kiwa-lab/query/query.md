# @kiwa-lab/query

> 标签: apollo-client, cache, fetch, kiwa, mock, query, swr, tanstack-query, testing, urql

## 简介

Data fetching cache mock harness for kiwa — TanStack Query / SWR / urql / Apollo Client を統一 interface で invoke する in-process mock。 fetchQuery / mutate / invalidateQuery / subscribeToQuery までを real provider と同じ signature で叩ける test infra。
