# @naktor/sentry-web

> 标签: browser-extension, error-tracking, naktor, nextjs, noise-filter, pii-scrubber, sentry

## 简介

Naktor standard Sentry init for web apps. Filters browser-extension noise, scrubs PII, and enforces shared defaults.
