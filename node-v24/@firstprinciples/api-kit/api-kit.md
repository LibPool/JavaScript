# @firstprinciples/api-kit

> 标签: api, express, fastify, hono, problem-details, rfc7807, typescript, validation

## 简介

Backend API response conventions: a typed success/error envelope, RFC 7807 problem-details formatting of core errors, schema-agnostic request validation, and Express/Fastify/Hono adapters.
