# dsh-web-discovery

> 标签: agent-tools, browser39, cordis, cordis-plugin, deepseek-harness, deepseek-harness-plugin, discovery, dsh, dsh-plugin, searxng, web-missions

## 简介

Discovery companion for dsh-web-missions: local search engines (SearXNG HTTP JSON + browser39 search CLI) behind a DiscoveryPort — the mission core only sees URLs in / URLs out.
