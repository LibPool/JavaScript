# @kryd/cli

> 标签: ai-gateway, cli, deploy, eu-sovereign, kryd, nextjs, paas, react, vite

## 简介

Kryd CLI — push a React / Vite / Next.js app to the European cloud for your AI: git push → live with SSL, one-click managed Postgres & object storage, and an EU-hosted AI gateway already wired in. Your code and your model calls stay in the EU.
