# @rareformlabs/vue-colorful

> 标签: a11y, accessible, color picker, colorpicker, hex, hsl, hsv, rgba, vue, vue3

## 简介

A tiny color picker component library for Vue 3 apps. Fast, accessible, dependency-free, and based on the react-colorful fork.
