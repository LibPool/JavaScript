# bump-semver

> 标签: bump, bump-patch, bump-version, ci, ci-cd, cli, custom-field, devVersion, github-actions, monorepo, multi-version, nightly, nightlyVersion, npm-version, package.json, patch, release, release-automation, release-channel, semantic-versioning, semver, version, version-bump, version-floor, versioning, zero-dependency

## 简介

Bump the patch version of any semver field in package.json — version, devVersion, nightlyVersion or any custom key — with a floor field to prevent version regressions across release channels. Zero-dependency CLI and API for CI/CD.
