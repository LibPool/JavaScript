# kubb

> 标签: api-client, code-generator, codegen, faker, kubb, meta-framework, msw, plugin-system, sdk-generator, typescript, zod

## 简介

The meta framework for code generation. Point Kubb at a schema and it generates types, clients, hooks, validators, mocks, and more.
