# kinc

> 标签: WeakMap, add, array, chain, collection, decrease, decrement, increase, increment, key, map, nested, number, object, set, subtract, typed array, value

## 简介

Uses one or more keys to locate and increment a value in a Map, Object, or other collection. Supports nesting, loose key matching, and more.
