# keeldocs

> 标签: agent-skills, ci, deterministic, docs, documentation, drift, living-documentation

## 简介

keeldocs - test coverage for your docs: anchors doc sections to the code they describe, deterministically flags drift with receipts, proposes reviewable patches. Any stack, any agent, no SaaS.
