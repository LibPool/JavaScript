# kanbanthing

> 标签: agent, ai-agents, cli, json, kanban, kanban-board, no-signup, project-management, task-management, terminal, todo

## 简介

Terminal client for KanbanThing boards. Create a board and list, add, move and edit cards from a shell, with --json on every command so scripts and AI agents can drive the same board a person has open in a browser.
