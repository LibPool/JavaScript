# koishi-plugin-auto-memory

> 标签: ai, context, deepseek, group-chat, impression, koishi, memory, middleware, openai, plugin, user-profile

## 简介

智能群聊记忆中间件：自动记录上下文，在@或回复时注入前情提要，支持时间窗口过滤与内容清洗，同时提供用户印象存档功能
