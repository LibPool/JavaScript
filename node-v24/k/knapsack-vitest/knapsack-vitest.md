# knapsack-vitest

> 标签: CI, automation, integration, knapsack, knapsack pro, parallelisation, runner, test, test suite parallelisation, testing, vitest

## 简介

knapsack-vitest splits Vitest tests across CI nodes and makes sure that tests will run in optimal time on each CI node.
