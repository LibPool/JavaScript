# kkrpc

> 标签: bidirectional, browser, bun, chrome-extension, cross-context, cross-runtime, deno, elysia, elysia-websocket, extension-system, http, inter-process-communication, ipc, microservices, nodejs, plugin-architecture, postmessage, remote-procedure-call, rpc, stdio, tauri, type-safe, typescript, web-worker, websocket, worker-communication

## 简介

TypeScript-first RPC library for seamless bi-directional communication between processes, workers, and contexts. Cross-runtime compatible with Node.js, Deno, Bun, and browsers.
