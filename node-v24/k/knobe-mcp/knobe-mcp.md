# knobe-mcp

> 标签: integrity, knobe, knowledge-objects, mcp, modelcontextprotocol, provenance

## 简介

MCP server for KNOBE Protocol v1: verify, read, create, and transform sealed .knobe.md knowledge objects, and evaluate what their sealed terms permit. Runs locally; no telemetry.
