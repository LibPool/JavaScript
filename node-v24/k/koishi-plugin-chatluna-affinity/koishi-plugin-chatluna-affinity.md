# koishi-plugin-chatluna-affinity

> 标签: chatbot, koishi, plugin

## 简介

ChatLuna Character 好感度系统，提供 {好感度}、{关系}、{黑名单} 变量与工具，并支持 XML 工具调用，仅支持 onebot 平台。
