# kharradp-audit-sdk

> 标签: audit, emploin, sdk, votermood

## 简介

HTTP client SDK for product audit microservices (Emploin, Votermood). Posts to /api/audit/ingest. Not the Nest audit sink itself. For Kafka domain events use @kharradp/audit-nestjs.
