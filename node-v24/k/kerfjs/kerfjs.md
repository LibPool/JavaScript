# kerfjs

> 标签: dom, fine-grained-reactivity, jsx, reactive, signals, tiny, ui-framework

## 简介

Tiny reactive UI framework — fine-grained signals + DOM morphing + JSX. Apply the smallest possible cut to update your DOM.
