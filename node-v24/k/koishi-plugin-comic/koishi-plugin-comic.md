# koishi-plugin-comic

> 标签: bika, chatbot, chatluna, comic, copymanga, jmcomic, koishi, manga, plugin

## 简介

多图源漫画搜索与下载插件，需要自部署 comic-api v2 后端（图源插件化，内置禁漫天堂/哔咔漫画/拷贝漫画等）。支持 ChatLuna 工具调用。
