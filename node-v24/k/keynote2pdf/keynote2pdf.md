# keynote2pdf

> 标签: keynote

## 简介

Conversion of zipped Keynote presentations to PDF. Runs only on Mac with Keynote installed (or just returns an error in a callback)

- 官网：https://github.com/ThibArg/node-js-keynote2pdf
- 源码仓库：git://github.com/ThibArg/node-js-keynote2pdf
- npm 页面：https://www.npmjs.com/package/keynote2pdf
