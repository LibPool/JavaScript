# kibana-bridge-mcp

> 标签: ai, chrome-extension, claude, kibana, logs, mcp, model-context-protocol, observability, opensearch, opensearch-dashboards

## 简介

MCP server that lets AI assistants search Kibana / OpenSearch Dashboards logs through your authenticated browser session, with no API keys required.
