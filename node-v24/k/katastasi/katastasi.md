# katastasi

> 标签: ai-agents, ci, confluence, documentation, jira, markdown, mcp, requirements, rtm, task-tracking, testing, traceability

## 简介

Katastasi — open-source documentation, task-tracking, and testing framework. Local-first markdown source of truth; agent-native (MCP); syncs to Jira/Confluence/issues/CI. Answers: what is the real status — is this actually done and verified?
