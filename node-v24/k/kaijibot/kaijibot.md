# kaijibot

> 标签: ai, chatbot, cognitive, feishu, glm, lark, lmstudio, ollama, proactive-ai, zhipu

## 简介

Proactive cognitive AI assistant with Feishu/WeChat integration — learns user interests, pushes cross-domain insights, evolves skills, self-corrects. 40+ LLM providers, runs on cloud/desktop/Android.
