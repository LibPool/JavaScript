# koishi-plugin-daily-sign

> 标签: checkin, daily, koishi, monetary, plugin, sign, 签到, 货币

## 简介

每日签到插件：每个用户每天可签到一次，获得随机数量货币，支持自定义货币名称与奖励上下限
