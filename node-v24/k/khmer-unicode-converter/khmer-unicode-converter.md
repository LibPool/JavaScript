# khmer-unicode-converter

> 标签: abc, cambodia, converter, khmer, khmer-unicode, legacy-fonts, limon, unicode

## 简介

Convert Khmer text between legacy font encodings (Limon, ABC, Baidok, ...) and Khmer Unicode.
