# kd-screen-guard

> 标签: anti-tamper, auto-lock, face-id, intruder-snapshot, lock-screen, pbkdf2, react-hook, screen-guard, security, touch-id, vue-composable, web-audio-siren, webauthn

## 简介

Zero-dependency, tamper-resistant, high-security lock screen overlay library with PBKDF2 salted hashing, intruder webcam snapshot review, Web Audio API siren, WebAuthn biometrics, and framework hooks.
