# koa-addpushheader

> 标签: KOA, http2, middleware, push

## 简介

KOA Parser middleware for `this.body`. Finds local URLs and adds them to the `Link` HTTP header. HTTP/2 reverse proxies like nghttpx then push these resources to the client.
