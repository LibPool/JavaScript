# kiss-rpc

> 标签: electron, high-performance, ipc, json-rpc, message-passing, microservices, remote-procedure-call, rpc, transport-agnostic, type-safe, typescript, websocket

## 简介

High-performance, type-safe RPC library for TypeScript/JavaScript. Transport-agnostic with exceptional throughput (1M+ ops/sec).
