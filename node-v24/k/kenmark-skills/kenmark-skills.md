# kenmark-skills

> 标签: ai-agent, claude-code, cli, codex, cursor, kenmark, skills, subagents, workflow

## 简介

39 universal Kenmark agent skills + 12-command CLI for Cursor, Claude Code, Codex, and other SKILL.md-compatible agents. Includes setup, init, update, adopt, cleanup, validate, doctor, inventory, mcp, selectable optional packs with repo-aware suggestions,
