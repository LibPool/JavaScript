# koa-classic-server

> 标签: apache, directory-listing, file-server, koa, middleware, secure, static, template-engine

## 简介

High-performance Koa middleware for serving static files with classic directory listing (similar, but not identical, to Apache 2), HTTP caching, template engine support, and comprehensive security fixes
