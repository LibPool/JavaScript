# kilo-cms

> 标签: admin-panel, better-auth, cms, drizzle, headless-cms, nextjs, typescript

## 简介

An installable, config-driven CMS engine for Next.js — admin panel, RBAC, a generic field-type engine, and an API, mounted into your own app. Define your content schema via config, not a hand-maintained registry.
