# kansei

> 标签: JavaScript

## 简介

Kansei is a Toy WebGPU engine built with TypeScript, inspired by old school 3D frameworks like Papervision3D, Flash API or some more modern ones like Pixi.js, Three.js or Unity compute pipeline, this library is not intended to cover a generalist use case
