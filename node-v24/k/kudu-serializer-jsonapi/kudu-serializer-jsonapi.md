# kudu-serializer-jsonapi

> 标签: JavaScript

## 简介

A [JSON API][api] serializer for [Kudu][kudu] applications. This is an unstable pre-release version intended for internal use. The API will stabilise over time and documentation added before the final 1.0.0 release.
