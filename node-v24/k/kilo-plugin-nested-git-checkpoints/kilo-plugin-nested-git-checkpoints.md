# kilo-plugin-nested-git-checkpoints

> 标签: checkpoints, embedded-repo, git, kilo, kilocode, nested-git, opencode, plugin, snapshot, submodule, undo

## 简介

Kilo/OpenCode plugin that extends checkpoints (snapshot, undo, redo) to nested git repositories — embedded repos and submodules the built-in snapshot cannot see.
