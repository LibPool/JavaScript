# kairos-lang-mcp

> 标签: business-days, calendar, holidays, kairos, mcp, model-context-protocol, schedule, scheduling

## 简介

MCP server for the Kairos schedule definition language — evaluate definitions (list/next), validate them, and look up the descriptor reference, from any MCP client
