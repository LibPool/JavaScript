# kaboom.claude

> 标签: claude, claude-code, cli, doom, doomgeneric, game, terminal, tmux, wasm

## 简介

Real DOOM in your terminal — the actual doomgeneric engine (WASM) with truecolor half-block rendering. Play full-screen, or side by side with Claude Code in a tmux split.
