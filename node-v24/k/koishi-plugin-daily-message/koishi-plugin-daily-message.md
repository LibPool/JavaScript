# koishi-plugin-daily-message

> 标签: chatbot, cron, daily, hitokoto, koishi, markdown, message, morning, plugin, schedule, 下午, 午安, 定时, 早安, 晚安, 每日消息, 白名单

## 简介

Koishi 每日定时消息插件，支持早安、午安、下午、晚安问候，定时发送到群聊和私聊，可配置 Cron 时间、白名单与模板变量
