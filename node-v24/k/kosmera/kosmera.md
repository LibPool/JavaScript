# kosmera

> 标签: cli, dotnet-tool, kosmera, locwise

## 简介

npm shim for the Kosmera CLI: bootstraps and runs the `kosmera` .NET global tool via `npx kosmera`.

## 官网

- 官网：https://kosmera.ai
- npm 页面：https://www.npmjs.com/package/kosmera

- npm registry：https://registry.npmjs.org/kosmera
- Node 要求：>=16.0.0
