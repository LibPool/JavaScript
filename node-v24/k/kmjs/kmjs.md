# kmjs

> 标签: applescript, automation, jxa, keyboard-maestro, macos, macro, typescript, virtual-actions, workflow

## 简介

A TypeScript toolkit for treating Keyboard Maestro macros as code. Enables exporting, importing, and simulating macros in-memory with both real and virtual macro workflows.
