# koishi-plugin-dev-tool

> 标签: backup, chatbot, database, elements, koishi, plugin, restore, tool

## 简介

开发辅助：支持管理、操作数据库表，快捷操作 OneBot API（查询信息、获取资源、发包等），解析消息，监听事件等实用指令
