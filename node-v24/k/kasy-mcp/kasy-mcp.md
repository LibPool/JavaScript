# kasy-mcp

> 标签: flutter, kasy, mcp, model-context-protocol

## 简介

MCP server for the Kasy kit. Lets any MCP-capable AI (Claude Desktop, Claude Code, Cursor, ...) prepare a machine, scaffold a Kasy project, and build screens that follow the kit's design system, without touching a terminal.
