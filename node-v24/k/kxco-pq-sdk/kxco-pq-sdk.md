# kxco-pq-sdk

> 标签: audit-log, compliance, digital-signature, document-signing, fips-204, hierarchical-identity, hsm, identity, kxco, kyc, ml-dsa, nist, post-quantum, pqc, revocation, vLEI, verifiable-credential, verification-modes

## 简介

Institution identity for the KXCO stack: hierarchical ML-DSA-65 credentials, HSM-backed signing, and anchoring on Armature L1 where the chain verifies the signature in consensus rather than a server doing it.
