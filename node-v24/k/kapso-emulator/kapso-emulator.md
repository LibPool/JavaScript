# kapso-emulator

> 标签: emulator, kapso, local-development, testing, webhook, whatsapp, whatsapp-business, whatsapp-cloud-api

## 简介

Local emulator for the Kapso WhatsApp platform: Meta Graph proxy, Platform API, and signed webhook loopback. Develop and test WhatsApp flows with zero real messages.
