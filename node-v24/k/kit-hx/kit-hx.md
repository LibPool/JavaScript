# kit-hx

> 标签: haxe, javascript, library

## 简介

A meta lib containing : belt : a utility library jsloka : js implenetation of th eIO loka : IO abstract control : input (keyboard/mouse/touch/gamepad...) glmat : matrix using FloatArray boot : shell and asset loading glee : opengl wrapper korrigan : sprit
