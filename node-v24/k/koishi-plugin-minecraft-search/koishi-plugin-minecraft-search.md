# koishi-plugin-minecraft-search

> 标签: chatbot, koishi, minecraft, plugin, server, status

## 简介

用于查询Minecraft服务器状态。如果服务器来自于麦块联机，那么可以查询指定服务器的详细资源使用情况，甚至还能对指定服务器进行电源开启或重启操作
