# kiro-telegram-bot

> 标签: acp, agent-client-protocol, ai-agent, ai-coding-assistant, chatops, cross-platform, daemon, devtools, grammy, kiro, kiro-cli, mobile-coding, telegram, telegram-bot

## 简介

Control Kiro CLI from Telegram over the Agent Client Protocol (ACP). Switch projects, resume and attach to live coding sessions, stream responses with diffs, queue follow-ups, and run 24/7 as a cross-platform background service.
