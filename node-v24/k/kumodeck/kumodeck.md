# kumodeck

> 标签: backend-as-a-service, cli, deploy, gamedev, hosting, html5-games, multiplayer, web-games

## 简介

KUMODeck CLI (the `kumodeck` command): log in, create projects, push config (kumo.config.json), deploy and roll back web apps and games. Zero dependencies.
