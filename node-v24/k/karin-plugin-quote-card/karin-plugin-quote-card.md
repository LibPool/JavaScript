# karin-plugin-quote-card

> 标签: karin, karin-plugin, quote, 卡片, 名言

## 简介

名言卡片生成插件：引用一条消息回复 #名言，生成精美玻璃质感卡片（从 TRSS-Yunzai quote-card 移植）

- npm 页面：https://www.npmjs.com/package/karin-plugin-quote-card
