# kakashi-doc

> 标签: JavaScript

## 简介

一款文档生成器，能把 markdown 文件转化成 HTML 网站，方便开发者编写组件的说明文档。

- 源码仓库：git+https://github.com/v-kakashi/kakashi-doc.git
