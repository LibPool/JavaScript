# kiro-mcp-gateway

> 标签: ai, claude, claude-code, claude-desktop, cowork, filesystem, gateway, llm, mcp, model-context-protocol, plugin, shell, tools

## 简介

A stateless MCP (Model Context Protocol) gateway server with plugin-based tool registration, resource exposure, and file system / shell capabilities for Claude Desktop and Claude Code.
