# keep-alive-react

> 标签: alive, cache, keepalive, react

## 简介

- 该高阶函数只是帮助组件在销毁前记录了当前所有`state`的值，然后下次进入的时候会把上次销毁前的`state`还原回去，从而实现一种类似的激活状态。
