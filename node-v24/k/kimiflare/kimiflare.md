# kimiflare

> 标签: ai, ai-gateway, cli, cloudflare, code-generation, coding-agent, image-understanding, k2.7, kimi, llm, mcp, model-context-protocol, terminal, tui, vision, workers-ai

## 简介

A terminal coding agent powered by Kimi K2.7, routed through your own Cloudflare AI Gateway — per-request logs, response caching, authoritative cost. Web search, GitHub, headless browser, LSP, MCP, local memory, 262k context.
