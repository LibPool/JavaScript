# koishi-plugin-best-cave

> 标签: cave, chatbot, koishi, plugin, 回声洞

## 简介

功能强大、高度可定制的回声洞插件。支持丰富的媒体类型、内容查重、AI分析、人工审核、用户昵称、数据迁移以及本地/S3 双重文件存储后端。
