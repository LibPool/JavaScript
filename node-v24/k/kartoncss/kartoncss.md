# kartoncss

> 标签: element, framework, karton, web-component

## 简介

A lightweight, classless CSS framework inspired by cardboard-style design and Sakura CSS.   Designed to work beautifully with the [KartonJS web component framework](https://github.com/biensurerodezee/kartoncss).
