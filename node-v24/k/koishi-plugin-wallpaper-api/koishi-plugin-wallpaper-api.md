# koishi-plugin-wallpaper-api

> 标签: api, booru, favorite-library, koishi, koishi-plugin, konachan, pixiv, plugin, tag-weight, wallpaper

## 简介

为 sunpanel 提供壁纸每日库 + HTTP API（支持标签轮询、Pixiv 推荐流兜底、横屏比例筛选、收藏与本地缓存等）。新增：Konachan图源、标签权重系统、喜欢图库、公平随机算法
