# keppet-mcp

> 标签: crypto, exchange-rates, fx, mcp, metals, model-context-protocol, open-data, yields

## 简介

MCP server for Keppet Open Data — USD-anchored FX, metals, crypto, rates, sovereign yields and economic multipliers. Zero dependencies, no API key.
