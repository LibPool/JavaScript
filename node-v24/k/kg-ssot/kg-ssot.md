# kg-ssot

> 标签: conformance, expo, json, json-schema, knowledge-graph, provenance, react-native, validator, verifiable, yaml

## 简介

JavaScript reader for the KG-SSOT verifiable knowledge graph contract (.kg.yaml and .kg.json): a precompiled validator, no eval, for Node and React Native/Expo.
