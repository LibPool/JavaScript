# koishi-plugin-elysia-api-aggregator

> 标签: ai, chatbot, elysia-api, koishi, llm, plugin

## 简介

Inspired by New-API, the Elysia-API model aggregator plugin allows automatic fetching and manual configuration of available AI models, designed to work with the orchestrator plugin.
