# k8w-pixi-layers

> 标签: JavaScript

## 简介

Pixi.js plugin, allows to change rendering order of containers without changing the scene graph.

## 官网

- 官网：http://www.pixijs.com/
- 源码仓库：git+https://github.com/pixijs/pixi-display.git
- npm 页面：https://www.npmjs.com/package/k8w-pixi-layers
