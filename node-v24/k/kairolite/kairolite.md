# kairolite

> 标签: agent, ai-agent, cli, code-assistant, coding-agent, cpu, developer-tools, gguf, kairo, kairolite, llm, local, local-ai, local-llm, offline-ai, openai-compatible, qwen, qwen-coder, terminal-agent

## 简介

Lightweight local AI coding agent CLI — an autonomous terminal agent running Qwen2.5-Coder 3B fully offline on CPU (Linux + Windows, no GPU). OpenAI-compatible, no API keys.
