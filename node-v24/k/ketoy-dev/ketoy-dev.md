# ketoy-dev

> 标签: android, cli, compose, jetpack-compose, kbc, ketoy, ketoyvm, ktx, sdui, server-driven

## 简介

Ketoy CLI — push KTX (.ktx) app bundles, manage apps, verify namespaces, and control your Ketoy Cloud SDUI pipeline from the terminal. This npm package installs the native `ketoy` Go binary for your platform.
