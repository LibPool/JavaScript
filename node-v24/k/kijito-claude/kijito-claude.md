# kijito-claude

> 标签: anthropic, claude, claude-code, cli, context-window, installer, kijito, skills

## 简介

Installer for the kijito-claude toolkit: copies the context-tracking, session catch-up, and self-clear scripts plus the Kijito skills into ~/.claude.
