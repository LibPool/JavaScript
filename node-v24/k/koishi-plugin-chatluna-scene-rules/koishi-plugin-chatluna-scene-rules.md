# koishi-plugin-chatluna-scene-rules

> 标签: alias, chatbot, chatluna, chatluna-livingmemory, koishi, livingmemory, memory, plugin

## 简介

ChatLuna livingmemory 记忆池别名器:把同一角色多个预设(私聊版/群聊版/语音版)的 presetId 映射到同一个共享记忆池,实现多预设共享 livingmemory 记忆;运行时接管服务方法,不改 chatluna-livingmemory 任何文件
