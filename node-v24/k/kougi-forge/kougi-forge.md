# kougi-forge

> 标签: JavaScript

## 简介

AI 驱动的教材生成工具。输入主题和要求，kougi-forge 通过多智能体流水线自动生成结构完整的教材，涵盖需求分析、蓝图规划、多版本撰写、专家审校、练习题生成、全书一致性检查等阶段。
