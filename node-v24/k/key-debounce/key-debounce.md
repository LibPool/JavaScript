# key-debounce

> 标签: change, debounce, device, object, optimization, proxy, state

## 简介

对象属性频繁赋值时，为字段自动增加防抖策略。通过Proxy代理整个对象；拦截属性赋值，并使用防抖策略，实现设备状态跳变优化
