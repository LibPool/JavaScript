# koishi-plugin-onebot-webqq

> 标签: bot, chatbot, console, koishi, plugin

## 简介

提供 OneBot WebQQ，为 ChatLuna 提供特殊适配，支持显示对话输入输出、思考状态、character 的 think 字段、affinity 的好感度显示、schedule的 日程显示
