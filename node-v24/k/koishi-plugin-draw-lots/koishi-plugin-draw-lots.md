# koishi-plugin-draw-lots

> 标签: chatbot, koishi, plugin

## 简介

创建一个存储多个图片路径的数组，接受命令后从随机一个路径下取一个随机图片发送（多次导入同一路径即可提高权重）。让美少女帮你抽签查看今日的运势
