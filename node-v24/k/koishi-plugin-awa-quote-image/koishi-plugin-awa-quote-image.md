# koishi-plugin-awa-quote-image

> 标签: chatbot, koishi, plugin

## 简介

对群u的消息使用aqt 🎭 一键将群u发言渲染为“名人名言”梗图。支持多种html+css模板(黑白/思源/文楷/QQ气泡), 使用 Puppeteer 出图。✨🎨
