# koishi-plugin-at-broadcast

> 标签: chatbot, koishi, plugin

## 简介

用户可以按分组订阅广播，拥有权限的人可以按分组发起广播，已订阅的用户将会被at并且看到广播内容，可选择指定群或所有群广播！
