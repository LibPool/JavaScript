# kith-mcp

> 标签: fashion, kith, mcp, sneakers, streetwear

## 简介

Query the KITH catalog (kith.com, NYC): search streetwear and sneakers, newest arrivals by type, enriched product details (sizes/colors), price stats, below-median deals, and category counts.
