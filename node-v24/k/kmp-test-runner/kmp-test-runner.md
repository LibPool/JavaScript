# kmp-test-runner

> 标签: android, coverage, gradle, kmp, kotlin, kotlin-multiplatform, parallel-tests, test-runner

## 简介

Parallel test runner for Kotlin Multiplatform and Android Gradle projects with an agent-friendly single-line JSON envelope. CLI + Gradle plugin.
