# koishi-plugin-activelink

> 标签: ai, chatbot, chatluna, koishi, koishi-plugin, onebot, openclaw, proactive, reminder, scheduled, weixin

## 简介

为 ChatLuna 添加主动对话能力的 Koishi 插件，支持 OneBot 11 和 OpenClaw Weixin 适配器，融合定时提醒、节日问候、活跃度触发、空闲触发等功能
