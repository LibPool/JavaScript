# kysely-sqlite-json

> 标签: json, kysely, plugin, sqlite

## 简介

Kysely plugin that serializes JSON values for SQLite writes and parses them back on reads.

## 官网

- npm 页面：https://www.npmjs.com/package/kysely-sqlite-json

## 历史版本号

- 0.1.0

## 获取地址

- npm 安装：`npm install kysely-sqlite-json`
- npm registry：https://registry.npmjs.org/kysely-sqlite-json
- Node 要求：>=18
