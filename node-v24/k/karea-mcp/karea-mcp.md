# karea-mcp

> 标签: claude, cursor, karea, mcp, model-context-protocol, task-management

## 简介

MCP server for Karea task management - 12 tools covering 69 actions, for Claude Code, Cursor, and other MCP clients to create, edit, close, and recap your dev tasks
