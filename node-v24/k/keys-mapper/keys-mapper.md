# keys-mapper

> 标签: deep mapping, key map, key mapper, key transformation, loop reference, member map, member transformation, object map, object transformation, property map, property transformation, reverse mapping, 对象映射, 属性映射, 循环引用, 成员映射, 成员转换, 深度映射, 返回映射, 逆向映射, 键映射

## 简介

keys-mapper 是一个通过设置属性名字映射，就可将一个对象转换成另一个对象的工具；支持循环引用、反向映射、深度映射
