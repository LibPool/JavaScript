# kepoin

> 标签: crash-reporting, debugging, developer-experience, diagnostic, dx, forensics, instrumentation, memory-dump, observability, performance-monitoring, pii-redaction, proxy, sanitization, telemetry, tracing, zero-config

## 简介

Zero-config forensic telemetry for Node.js and Node-based Mobile apps (React Native/Expo). Automatically trace execution, benchmark performance, and generate memory autopsies on crash, without changing a line of your code.
