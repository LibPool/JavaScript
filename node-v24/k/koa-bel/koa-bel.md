# koa-bel

> 标签: any, bel, body, context, ctx, data, dom, easy, engine, express, file, files, javascript, js, jstemplate, koa, koajs, locals, render, simple, state, template, tpl, view, views

## 简介

View engine for `koa` without any deps, built to be used with `bel`. Any other engines that can be written in `.js` files would work, too.
