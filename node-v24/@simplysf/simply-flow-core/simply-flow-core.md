# @simplysf/simply-flow-core

> 标签: flow, force, salesforce, salesforcedx, sf, sf-plugin, sfdx, sfdx-plugin

## 简介

Flow deactivation/deletion and obsolete Flow version pruning logic — the library layer behind @simplysf/simply-flow, published separately for direct consumption (e.g. an MCP server, CI scripts) without the CLI framework
