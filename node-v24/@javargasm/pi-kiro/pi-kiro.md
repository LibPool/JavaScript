# @javargasm/pi-kiro

> 标签: amazon-q, aws, claude, codewhisperer, extension, kiro, pi, pi-coding-agent, pi-package, provider

## 简介

Kiro provider for the pi coding agent: AWS Builder ID / IAM Identity Center login and the CodeWhisperer streaming API, exposing the Kiro Claude model family.
