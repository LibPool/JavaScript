# dsh-bridge-llm-plugin

> 标签: deepseek, deepseek-harness, dsh, dsh-bridge, dsh-plugin, llm-adapter, playwright

## 简介

DeepSeek Harness LLM adapter: use your logged-in DeepSeek web chat (deepseek.com) as a model provider through the local dsh-bridge browser bridge. Streaming is single-shot (the whole reply arrives as text deltas); the web UI exposes no structured tool cal
