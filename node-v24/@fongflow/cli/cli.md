# @fongflow/cli

> 标签: automation, browser-agent, cli, fongflow, runner, workflow

## 简介

FongFlow command-line interface — run Flow steps on your own computer (fongflow runner), give FongFlow AI a browser (fongflow computer), run and watch workflows, and capture todos from the terminal.

## 官网

- 官网：https://fongflow.com
- npm 页面：https://www.npmjs.com/package/@fongflow/cli
