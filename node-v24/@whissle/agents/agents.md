# @whissle/agents

> 标签: agent, ai, asr, conversational-ai, embed, sdk, speech-to-text, stt, transcription, voice, voice-agents, webrtc, whissle, widget

## 简介

Embed a Whissle voice or text agent into any web app. Create/configure the agent on whissle.ai, then run a live conversation with a publishable key.
