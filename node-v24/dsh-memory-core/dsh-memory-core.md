# dsh-memory-core

> 标签: deepseek-harness, dsh, dsh-plugin, isolated, memory, memory-core, preset

## 简介

遮蔽会话的隔离记忆包（默认关闭：装进 profile 不会自动作用于任何会话，需在目标 preset 里挂载后才启用）。给被 dsh-memory-shield 遮蔽的会话加一套五轨独立记忆，独立数据目录，与 dsh-memory-evolve 完全隔离。
