# @martindye/dsh-voice

> 标签: chat, deepseek-harness, dictation, dsh, dsh-plugin, plugin, speech, stt, tts, voice

## 简介

Martin's self-contained two-way voice plugin for the DSH web app: unified voice composer in, per-message speaker buttons and auto-read out (own TTS server), plus the speech-to-text wiring. Forked from @deepseek-ai/dsh-experimental-client-ui-voice-input 0.
