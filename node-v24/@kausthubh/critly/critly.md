# @kausthubh/critly

> 标签: accessibility, agents, claude, codex, contrast, cursor, design, lint, playwright, squint test, taste, ui, visual hierarchy

## 简介

Check your running app against Critly's design concepts, and run a taste pass on it. Loads the page, measures what it renders, and fails with the fix named.
