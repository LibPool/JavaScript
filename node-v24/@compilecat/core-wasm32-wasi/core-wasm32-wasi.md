# @compilecat/core-wasm32-wasi

> 标签: JavaScript

## 简介

WebAssembly (WASI) build of compilecat's Rust/oxc core — the universal fallback the loader uses on platforms without a native binary. No os/cpu filter, so it installs everywhere.
