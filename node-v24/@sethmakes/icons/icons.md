# @sethmakes/icons

> 标签: design-system, iconify, icons, lucide, phosphor, tailwind

## 简介

Brand aliases, sizing conventions, and a custom Iconify set (prefix `mk`) for the sethmakes design language. Selection happens at YOUR build via Iconify — this package is thin.
