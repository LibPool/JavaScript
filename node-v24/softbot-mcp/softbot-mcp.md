# softbot-mcp

> 标签: ai-agents, mcp, screenshot, solana, usdc, web-scraping, x402

## 简介

MCP server for Softbot Studio pay-per-call agent tools (x402, USDC on Solana; first 3 calls free per wallet): read pages, extract data, token/wallet/email/website checks, screenshots, PDFs.
