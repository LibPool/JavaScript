# @docubook/themes-colors

> 标签: colors, css-variables, docubook, flame, hex-to-hsl, theme

## 简介

Theme color presets and color utilities for DocuBook — hex-to-HSL, CSS variable generation, and 3 built-in themes (Default/Blue, Fresh Lime, Coffee).
