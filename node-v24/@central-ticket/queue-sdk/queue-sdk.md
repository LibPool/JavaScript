# @central-ticket/queue-sdk

> 标签: centralq, event-ticketing, queue-management, queue-token, react, sdk, svelte, ticketing, typescript, virtual-queue, vue, waiting-room, web-component

## 简介

SDK de cola virtual de CentralQ. Por defecto monta la UI de CentralQ (`<central-q>`) con la experiencia publicada en el dashboard, sin bloquear la admisión ni el polling.
