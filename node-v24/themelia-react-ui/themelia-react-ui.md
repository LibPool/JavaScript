# themelia-react-ui

> 标签: admin, base-ui, dashboard, design-system, react, shadcn, tailwindcss, ui

## 简介

A composable React UI library for modern admin applications, built on Base UI and Tailwind with shadcn-compatible themes, shared design tokens, reusable layouts, blocks and workflows.
