# @apicircle-lens/cli

> 标签: JavaScript

## 简介

API Circle Lens CLI and MCP server: map every endpoint of your API to the code that implements it (the Code graph), and review pull requests for drift against your OpenAPI Spec. Needs a CLI key from an API Circle plan that includes the CLI or MCP.
