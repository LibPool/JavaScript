# @devyrpauli/mddocs

> 标签: ai-agents, collaboration, crdt, editor, git, local-first, markdown, real-time, self-hosted, yjs

## 简介

Local-first, git-native collaborative Markdown: real-time multiplayer, comments and suggestions, and an HTTP API for AI agents (read, comment, suggest, rewrite, presence, and events). Self-hostable, built on proof-sdk.
