# @sovgut/datagrid

> 标签: data-grid, datagrid, filtering, headless, headless-ui, pagination, react, row-selection, sorting, table, typescript, unstyled, zustand

## 简介

Headless, unstyled state management for React data grids: pagination, sorting, per-column filters, selection and column visibility, with the markup left entirely to you.
