# @solidity-audit-llm/hardhat-plugin

> 标签: JavaScript

## 简介

Hardhat插件，用于在Hardhat项目中使用Smart Contract Auditor进行智能合约代码审查。该插件支持自动化的代码审查流程，可以生成中文审计报告。
