# @ancher-ai/agent-skills

> 标签: agent-skills, ancher, claude-code, codex, cursor, mcp, plugin

## 简介

Ancher skills + MCP setup for coding agents (Claude Code, OpenAI Codex, Cursor). One repo that is a Claude Code plugin marketplace, a Codex plugin marketplace, and a Cursor integration — plus a cross-agent installer.
