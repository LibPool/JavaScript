# @240xu/dsh-suite

> 标签: dsh-plugin

## 简介

@240xu 生态聚合包：一条 dsh plugin add 装全家。宿主半用 shell 子路径行做故障隔离，浏览器半折进本包单个 client graph entry；逐行 disable 即回滚，standalone 安装不受影响。
