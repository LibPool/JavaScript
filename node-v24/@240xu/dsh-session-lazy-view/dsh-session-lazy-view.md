# @240xu/dsh-session-lazy-view

> 标签: JavaScript

## 简介

DSH web plugin: read-only lazy session viewer. Lists ~/.dsh/sessions (stat-only) and peeks at the last N zstd frames of any session artifact without decompressing the whole file.
