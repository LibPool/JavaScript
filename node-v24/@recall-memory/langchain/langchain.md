# @recall-memory/langchain

> 标签: agents, chat-history, langchain, langchainjs, llm, memory, recall, retriever

## 简介

Recall memory for LangChain.js: a chat message history backed by Recall sessions, a retriever over what Recall remembers, and tools for agents.
