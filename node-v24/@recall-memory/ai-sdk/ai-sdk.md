# @recall-memory/ai-sdk

> 标签: agents, ai, ai-sdk, llm, memory, recall, vercel-ai-sdk

## 简介

Recall memory for the Vercel AI SDK: tools the model can call, and middleware that adds what Recall knows about the user to each request and stores every turn.
