# @threejson/react

> 标签: react, scene-viewport, three.js, threejson

## 简介

Thin React bindings over ThreeJSON's framework-agnostic host/player kits: <SceneViewport />, useScenePlayer(), useHostI18n(), usePlayerSettings(). No business shell — app UI stays in the app.
