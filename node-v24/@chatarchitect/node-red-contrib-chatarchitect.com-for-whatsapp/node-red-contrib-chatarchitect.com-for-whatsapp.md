# @chatarchitect/node-red-contrib-chatarchitect.com-for-whatsapp

> 标签: messages, node, node-red, whatsapp

## 简介

The application integrates the official WhatsApp Business API into your Node-RED. Incoming and outgoing messages, also you can initiate a conversation. The cost of WhatsApp Business API starts from €15 per month, for more details visit the website https:/
