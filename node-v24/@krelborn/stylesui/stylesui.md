# @krelborn/stylesui

> 标签: accessibility, component-library, css-custom-properties, css-modules, dark-mode, design-system, react, react-components, theming, ui-library, wcag

## 简介

Tree-shakable React 19 component library styled with CSS modules and custom properties, with themes, palettes, light and dark modes, and accessibility tests against WCAG 2.2 AA.
