# @transmitt0r/mycelium-embed

> 标签: embeddings, llm, local-inference, mcp, openai-compatible, openrouter

## 简介

Pluggable embedding + chat client for any OpenAI-compatible endpoint (OpenAI, OpenRouter, Ollama, vLLM, LM Studio, ...), with an opt-in local CPU embedding fallback.
