# @transmitt0r/mycelium-openapi-codegen

> 标签: codegen, openapi, openapi-typescript

## 简介

Fetch an OpenAPI schema and generate TypeScript types from it — fetch-to-tempfile lifecycle plus an isolated openapi-typescript run, so callers only supply their own schema-fetching logic.
