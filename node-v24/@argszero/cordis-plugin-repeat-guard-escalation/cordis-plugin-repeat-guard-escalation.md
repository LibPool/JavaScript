# @argszero/cordis-plugin-repeat-guard-escalation

> 标签: cordis, deepseek-harness, dsh, guard, loop, plugin, repeat, tool-call

## 简介

Enforcement tier for dsh's repeat-tool-reminder guard: deny an identical repeated tool call before dispatch once advice has been ignored, plus a much earlier tier for repeats that keep FAILING with the same error. Bounded (maxDenials) so a looping session
