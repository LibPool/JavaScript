# @argszero/cordis-plugin-inbox-claim-guard

> 标签: agent-loop, cordis, deepseek-harness, dsh, guard, inbox, input-loss, plugin, recovery

## 简介

Lost-input guard for dsh: a message claimed from the agent inbox is dropped if the step throws before the durable user/message append (discussion #6964, 14/154 archived sessions). This plugin observes the public agent/inbox/claimed event, proves the loss
