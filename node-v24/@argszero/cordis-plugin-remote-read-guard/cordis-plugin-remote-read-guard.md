# @argszero/cordis-plugin-remote-read-guard

> 标签: browser-half, cordis, deadline, deepseek-harness, dsh, plugin, plugin-manager, remote, timeout

## 简介

A Client Remote read that never answers must not leave the page loading forever. The dsh Web plugin manager reads `remote.pluginInventory.list()` and `remote.pluginManager.listBundles()/listPlugins()` with no failure exit and no deadline: its store wraps
