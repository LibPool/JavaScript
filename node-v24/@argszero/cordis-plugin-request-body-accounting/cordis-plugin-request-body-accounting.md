# @argszero/cordis-plugin-request-body-accounting

> 标签: 413, bytes, cordis, deepseek-harness, diagnostics, dsh, observability, payload-too-large, plugin, request-body, session-log

## 简介

Request-body byte accounting for dsh: names what a DeepSeek request body is actually made of (base messages vs each extension field, in bytes) instead of reporting only tokens. Report-only: it measures the same expression the adapter serializes and never
