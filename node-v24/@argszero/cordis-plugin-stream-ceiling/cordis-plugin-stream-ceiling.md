# @argszero/cordis-plugin-stream-ceiling

> 标签: circuit-breaker, cordis, deepseek-harness, dsh, keep-alive, llm, plugin, stream, timeout, watchdog

## 简介

Stream ceiling for dsh: an absolute bound on one model call, mounted on the llm/stream waterfall. The harness's streamIdleTimeoutMs is re-armed by every SSE keep-alive comment (comments never enter the payload stream), so it bounds keep-alive silence rath
