# @argszero/cordis-plugin-fork-inbox-guard

> 标签: cordis, deepseek-harness, dsh, inbox, plugin, session-fork, subagent

## 简介

Fork inbox guard for dsh: a created child that copies a prefix of another session's log replays that prefix's pending input into its own empty inbox, where it is addressed to the source session's next turn and runs ahead of the child's first message. Moun
