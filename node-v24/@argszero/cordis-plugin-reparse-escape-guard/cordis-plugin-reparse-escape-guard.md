# @argszero/cordis-plugin-reparse-escape-guard

> 标签: cordis, deepseek-harness, dsh, junction, path-containment, plugin, reparse-point, sandbox, symlink, tools-pre-execute, workspace-write

## 简介

Pre-dispatch guard for dsh writes whose path leaves the granted write area through a link. Every write confinement in the harness canonicalizes first and then refuses, which is the right enforcement answer and a poor diagnostic one: `<workspace>/link/out.
