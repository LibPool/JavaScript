# @argszero/dsh-tool-identity-pin-guard

> 标签: approval, cordis, deepseek-harness, dsh, guard, identity, immutability, plugin, pre-execute, security, tool-call, tools

## 简介

Pins a tool call to the identity it was approved with. The registry hands tools/pre-execute listeners the live execution object and documents name/agent/parent/callId/signal/token as readonly, while the object is a plain writable literal with only the arg
