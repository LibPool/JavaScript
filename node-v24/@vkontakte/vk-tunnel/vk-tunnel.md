# @vkontakte/vk-tunnel

> 标签: JavaScript

## 简介

С помощью **VK Tunnel** вы можете сделать локальный веб-сервер доступным в интернете. Это нужно при отладке и демонстрации веб-приложений. VK Tunnel запускается на компьютере разработчика и создаёт специальное соединение (туннель), с помощью которого лока
