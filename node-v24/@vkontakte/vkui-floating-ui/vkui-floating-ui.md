# @vkontakte/vkui-floating-ui

> 标签: JavaScript

## 简介

Библиотека [Floating UI](https://floating-ui.com/) скомпилированная в ES5 для поддержки `browserslist` VKUI. У [Floating UI](https://floating-ui.com/) версии браузеров гораздо выше ([ссылка на `browserslist` библиотеки](https://floating-ui.com/docs/misc))
