# @ohos-ports/lmdb-openharmony-arm64

> 标签: JavaScript

## 简介

Platform specific binary for lmdb on openharmony OS with arm64 architecture (compiled from kriszyp/lmdb-js v3.5.7 source with OHOS clang, MDB_USE_ROBUST=0 for OHOS musl)
