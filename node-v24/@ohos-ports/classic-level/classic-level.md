# @ohos-ports/classic-level

> 标签: classic-level, compat, harmonyos, leveldb, ohos

## 简介

HarmonyOS @ohos-ports classic-level shim: drives the real @ohos-ports/classic-level 3.x native binding but restores classic-level 8.x get()/getSync() semantics (throw NotFoundError with code LEVEL_NOT_FOUND on missing keys) required by @dxos/echo-pipeline
