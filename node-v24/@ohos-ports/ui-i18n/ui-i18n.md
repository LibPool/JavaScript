# @ohos-ports/ui-i18n

> 标签: harmonyos, i18n, ohos-ports, reltio

## 简介

HarmonyOS port of the private Reltio ui-i18n package (bitbucket:reltio-ondemand/ui-i18n, npm 404). Implements the i18n API surface used by @reltio/mdm-sdk: translation lookups with key fallback, language switching, Intl/moment-style date, time and number
