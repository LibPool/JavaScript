# @ohos-ports/nx-linter

> 标签: CLI, ESLint, Lint, Monorepo, Web

## 简介

The Linter plugin for Nx contains executors, generators and utilities used for linting JavaScript/TypeScript projects within an Nx workspace. [HarmonyOS openharmony/arm64 port of @nx/linter@19.8.4 via @ohos-ports alias closure]
