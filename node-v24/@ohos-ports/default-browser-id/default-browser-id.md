# @ohos-ports/default-browser-id

> 标签: browser, bundle, bundleid, default, id, identifier, macos, plist, uti, web

## 简介

Get the bundle identifier of the default browser (macOS / HarmonyOS). Example: com.apple.Safari, com.ohos.browser
