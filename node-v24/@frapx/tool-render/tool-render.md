# @frapx/tool-render

> 标签: cli, ffmpeg, offline-rendering, png-sequence, render, shader, webgl

## 简介

Node CLI that renders a @frapx/tool-capture page frame by frame in headless Chrome — resumable PNG sequences on disk, with optional ProRes or H.264 encoding through ffmpeg.
