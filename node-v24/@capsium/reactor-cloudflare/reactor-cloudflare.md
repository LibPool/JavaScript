# @capsium/reactor-cloudflare

> 标签: JavaScript

## 简介

Cloudflare Workers Capsium reactor: install .cap packages over HTTP (integrity + signature verified, persisted in the Cache API) and serve them per routes.json with the §7 introspection API.
