# @logtide/sdk-node

> 标签: circuit-breaker, express-middleware, fastify-plugin, log-management, logging, logs, logtide, monitoring, observability, self-hosted, tracing

## 简介

Official Node.js SDK for LogTide (logtide.dev) - Self-hosted log management with advanced features: retry logic, circuit breaker, query API, live streaming, and middleware support
