# @yoda.digital/mycelium

> 标签: agent-coordination, bun, claude-code, curve25519, e2e-encryption, ed25519, libsodium, mcp, model-context-protocol, tofu

## 简介

End-to-end encrypted messaging between Claude Code instances. Curve25519 PFS, Ed25519 TOFU, offline identity envelopes, automatic retransmission, replay protection, zero-plaintext relay.
