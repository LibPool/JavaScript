# @paperclover/markodown

> 标签: JavaScript

## 简介

This is a weird markup language that combines features of [Markdown] and [Marko]. You can think of this as an alternative universe to MDX. Since Marko components are really easy to write, it makes this a great tool for writing interactive blog posts. Mark
