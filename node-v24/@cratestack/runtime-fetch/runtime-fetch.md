# @cratestack/runtime-fetch

> 标签: cratestack, cstack, fetch, rpc, runtime

## 简介

A typeof-fetch-compatible transport for CrateStack's generated TypeScript RPC client, adding an optional per-call timeout on top of the global fetch.
