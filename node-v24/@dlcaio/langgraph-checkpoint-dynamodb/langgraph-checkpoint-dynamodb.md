# @dlcaio/langgraph-checkpoint-dynamodb

> 标签: aws, checkpoint, dynamodb, langchain, langgraph, s3, typescript

## 简介

DynamoDB checkpoints for LangGraph with versioned channel storage, compression, optional S3 offload, and explicit recovery errors.
