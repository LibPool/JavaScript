# @clamly/anchor

> 标签: a11y, accessibility, adhd, bionic-reading, css-highlight-api, dyslexia, fixation, focus, reading, typography

## 简介

Reading anchors (bionic-style fixation points) for any website: no DOM changes with the CSS Highlight API, safe with React and Vue, SSR-friendly, zero dependencies.
