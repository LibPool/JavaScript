# @pipelock/verifier-ts

> 标签: agent-security, attestation, ed25519, pipelock, receipt, verifier

## 简介

TypeScript reference verifier for Pipelock signed agent-egress receipts (Audit Packet v0, ActionReceipt v1, EvidenceReceipt v2).
