# @sukra-infotek/tevo-seatmaps-client

> 标签: Ticket Evolution, seating chart, seatmaps, tevo, tickets

## 简介

A client side JavaScript library that enables users to view interactive seating charts for tickets available via the Ticket Evolution API. Modified for Hungry Tickets web application
