# @gent8/brandkit

> 标签: asset-bundle, brand, brand-assets, brand-kit, claude, design-system, favicon, favicon-generator, ideogram, logo, mcp, model-context-protocol, og-image, palette, pwa-icons, recraft, svg

## 简介

One SVG → 14 ship-ready brand assets (favicon, og-image, PWA icons, Chrome Web Store) — all palette-locked to brand.json. CLI + MCP server with a CI gate that exits 1 on any off-palette color.
