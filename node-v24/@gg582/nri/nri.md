# @gg582/nri

> 标签: agent-harness, ai-agent, code-generation, langgraph, llm, mcp, multi-provider, refactoring

## 简介

Adaptive agentic engineering harness: triage-routed dual-path (FAST/HEAVY) agent with business-logic pre-flight validation, abstract-graph planning, coverage-driven loops and self-applying diffs. Built on LangGraph.
