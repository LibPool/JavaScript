# @mzzsfy/dsh-llm-pi-gateway

> 标签: JavaScript

## 简介

NewAPI 等 LLM 网关接入:向每个上游请求注入会话 sessionId(请求体派生标记 + 亲和头裸 sessionId),供网关做请求亲和性粘性路由,compat 全开放
