# @mzzsfy/dsh-common-tools

> 标签: JavaScript

## 简介

全家桶公共依赖库:host 半区 setupCommonTools 由消费插件在 apply 执行(推送总线 SSE + 版本接管 + 卸载合规),client 半区 toast + bus.subscribe 经占位条目进浏览器模块表;普通 npm 依赖而非 dsh 插件,插件管理不可见
