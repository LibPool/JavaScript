# @mzzsfy/dsh-turn-notify

> 标签: JavaScript

## 简介

消息通知:六类回合事件送达声音、系统弹窗、页内提示、webhook、IM 与宿主桌面通知;内置八种合成音色,自定义音效,按事件分类指定;多窗口只响一次
