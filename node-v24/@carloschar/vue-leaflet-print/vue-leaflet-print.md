# @carloschar/vue-leaflet-print

> 标签: export, leaflet, map, png, print, vue, vue-leaflet

## 简介

Control de impresión/exportación para Vue-Leaflet (Vue 3): print nativo, PNG via html-to-image y PNG via leaflet-image.
