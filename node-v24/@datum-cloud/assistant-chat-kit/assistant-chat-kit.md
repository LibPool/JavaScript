# @datum-cloud/assistant-chat-kit

> 标签: JavaScript

## 简介

Shared client logic for talking to the assistant (Patch) service from a cloud-portal plugin: conversation state, SSE turn streaming, and the list/archive/delete/send API — everything ChatDock and any other plugin's assistant surface needs, minus rendering
