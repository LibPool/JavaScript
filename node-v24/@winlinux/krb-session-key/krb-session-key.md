# @winlinux/krb-session-key

> 标签: gssapi, kerberos, napi, node-addon, session-key, smb2, winrm

## 简介

GSSAPI Kerberos initiator (N-API addon) that exposes the context session key, for SMB2 signing with Kerberos.
