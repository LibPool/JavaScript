# @ericrius1/weft

> 标签: gpu, graphics, render-graph, shaders, vite-plugin, webgpu, wgsl

## 简介

A thin WebGPU kit: a frame is an explicit, ordered list of passes over named resources, and WGSL is the single definition of the data. With a Vite plugin for typed, hot-reloading .wgsl imports.
