# @chengyixu/clitest-runner

> 标签: ci, cli, command-line, framework, snapshot, tap, test, testing, yaml

## 简介

A testing framework specifically designed for testing CLI tools. Define tests in YAML, run them with snapshots, parallel execution, and TAP output.
