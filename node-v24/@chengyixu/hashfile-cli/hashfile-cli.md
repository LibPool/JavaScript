# @chengyixu/hashfile-cli

> 标签: checksum, cli, file-hash, hash, integrity, md5, sha1, sha256, sha512, verify

## 简介

Compute and verify file hashes from the terminal. Supports md5, sha1, sha256, sha512 with verify, compare, and directory hashing.
