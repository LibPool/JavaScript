# @vue-responsive-dash/echarts

> 标签: JavaScript

## 简介

Implements vue-echarts [https://ecomfe.github.io/vue-echarts/demo/](https://ecomfe.github.io/vue-echarts/demo/). This wrapper automatically scales the charts to fit each DashItem.
