# @vue-responsive-dash/apexcharts

> 标签: JavaScript

## 简介

Wrapper for fusioncharts [https://github.com/apexcharts/vue-apexcharts](https://github.com/apexcharts/vue-apexcharts). This wrapper automatically scales the chart to fit DashItem.
