# @algosoftltd/grid

> 标签: algosoft, cline, grid, llm-gateway, open-source

## 简介

Plug the open-source Cline harness into a model your organisation pays for. Defaults to the public AlgoSoft OS login; no gateway address, key, or model list is bundled.
