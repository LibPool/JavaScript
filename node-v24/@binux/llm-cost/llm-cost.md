# @binux/llm-cost

> 标签: ai, anthropic, calculator, claude, cli, cost, gemini, gpt, llm, openai, pricing, tokens

## 简介

💰 Beautiful CLI to count tokens and estimate costs for any LLM model (Claude, GPT, Gemini, Mistral, and 300+ more). Auto-updates prices from OpenRouter.
