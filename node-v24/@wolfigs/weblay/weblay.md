# @wolfigs/weblay

> 标签: cms, in-place-editing, nextjs, react, visual-editor, vue, weblay, wolfigs

## 简介

Install the Weblay visual editor connector in any JS app — SSR-safe injector plus React and Vue bindings. Loads the connector from Weblay's CDN; adds ~0 KB of editor weight to your bundle.
