# @microboxlabs/miot-dashboard-server

> 标签: dashboard, dashboards, embeddable, jwt, multi-tenant, self-hosted

## 简介

Framework-agnostic backend services for MIOT embeddable dashboards: persistence, identity and tenancy, datasource proxying, embed tokens.
