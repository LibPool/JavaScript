# @yuntwoyuntwo/dsh-langfuse-plugin

## 简介

Langfuse telemetry sidecar bundle for DeepSeek Harness: projects session telemetry into Langfuse traces, observations, scores, and dataset items without replacing the built-in telemetry backend
