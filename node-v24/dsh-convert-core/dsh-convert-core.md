# dsh-convert-core

> 标签: JavaScript

## 简介

Standalone conversion kernel: file / url (web page, WeChat article) / video / text to knowledge-ready Markdown + local assets, with an HTTP API and a React console built on @tita-agent/ui. The local media pipeline (audio/video/image → Markdown, subtitles
