# @stacksjs/stx-vscode

> 标签: grammar, language support, stacks, stx, vscode

## 简介

stx language support for VS Code extensions to embed: the hovers, completions, diagnostics, grammar, snippets, language configuration and TypeScript server plugin behind the stx extension.
