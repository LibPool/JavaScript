# @saacms/storage-r2

> 标签: JavaScript

## 简介

Cloudflare R2 storage adapter for saacms. Implements the `StorageAdapter` interface (`{ put, get, delete, signedUrl }`) over a Workers `R2Bucket` binding, for use by Media Collections in `bucket` storage mode.
