# @shadowdara/linguist-js

> 标签: JavaScript

## 简介

A Node.js reimplementation of github/linguist with full .gitattributes support (linguist-language, linguist-vendored, linguist-documentation, linguist-generated, linguist-detectable, linguist-ignore).
