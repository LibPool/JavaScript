# @jupiterpi/node-keyring

> 标签: JavaScript

## 简介

Node native addon for accessing the system keyring using https://crates.io/crates/keyring

## 官网

- 官网：https://github.com/JupiterPi/node-keyring#readme
- 源码仓库：git+ssh://git@github.com/JupiterPi/node-keyring.git
- npm 页面：https://www.npmjs.com/package/@jupiterpi/node-keyring

## 获取地址

- npm 安装：`npm install @jupiterpi/node-keyring`
- npm registry：https://registry.npmjs.org/@jupiterpi/node-keyring
- Node 要求：>= 10.16.0 < 11 || >= 11.8.0 < 12 || >= 12.0.0
