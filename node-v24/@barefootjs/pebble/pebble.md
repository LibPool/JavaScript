# @barefootjs/pebble

> 标签: barefoot, java, jvm, pebble, spring, ssr

## 简介

Pebble adapter for BarefootJS — compiles IR to .peb templates and ships the Java BarefootJS rendering runtime; runs under any JVM web framework (Spring Boot, Ktor, etc.)
