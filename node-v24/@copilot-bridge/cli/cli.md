# @copilot-bridge/cli

> 标签: bridge, byok, copilot, copilot-cli, github-copilot, llm, localhost

## 简介

Let your app use the GitHub Copilot CLI the user is already logged into — no API keys. Core spawn helpers, a localhost HTTP bridge, a browser client, and a React status hook.
