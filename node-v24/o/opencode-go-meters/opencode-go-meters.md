# opencode-go-meters

> 标签: meters, opencode, opencode-go, opencode-plugin, plugin, quota, usage

## 简介

OpenCode plugin showing your live OpenCode Go usage meters (rolling 5h / weekly / monthly) with reset countdowns, in the sidebar and via /gousage
