# openctf-server

> 标签: capture-the-flag, ctf, flask, lab, python, security

## 简介

OpenCTF lab CTF platform server (Flask API + sandboxed target-website service), bundled as Python source with a Node launcher. Requires Python 3.10+ already installed - npm cannot install a Python runtime for you.
