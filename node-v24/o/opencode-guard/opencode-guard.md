# opencode-guard

> 标签: ai-agent, classifier, coding-agent, guardrails, opencode, opencode-plugin, permissions, safety, secret-redaction, shell

## 简介

Permission modes and a shell safety floor for opencode: static read rules, credential guards, a classifier consulted only when nobody can be asked, loop detection and secret redaction.
