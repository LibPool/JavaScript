# opencode-keycloak-auth

> 标签: auth, device-flow, keycloak, oauth2, oidc, opencode, opencode-plugin, openid-connect, pkce, sso

## 简介

OpenCode auth plugin: OAuth2/OIDC against Keycloak (Authorization Code + PKCE S256 and Device Authorization Grant) for an OpenAI-compatible provider.
