# opencode-rundev

> 标签: dev-environment, docker-compose, opencode, opencode-plugin, opencode-tui, run-and-debug, rundev

## 简介

Run & Debug for the terminal-first world: bring a repo's dev environment up and down from OpenCode — containers, dev servers, emulators — with no LLM in the loop.
