# opencode-omniroute-router

> 标签: ai-router, coding-agent, llm, multi-model, omniroute, opencode, opencode-plugin, task-routing

## 简介

Deterministic task routing plugin for OpenCode on top of a self-hosted OmniRoute gateway: classifies requests into five tiers, delegates to exactly one worker per turn, and records execution history.
