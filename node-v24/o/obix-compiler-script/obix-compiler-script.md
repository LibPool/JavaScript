# obix-compiler-script

> 标签: compiler, obix, script, vue

## 简介

The Vue script frontend of the .obix compiler: compiles the normal <script> (JavaScript or TypeScript) of a canonical SFC with the OFFICIAL Vue script compiler (@vue/compiler-sfc compileScript) into a typed frontend artifact — the compiled module, the bin
