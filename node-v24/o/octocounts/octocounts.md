# octocounts

> 标签: cloc, code-metrics, code-statistics, count-lines, github, lines-of-code, loc, repository, scc, sloc, tokei

## 简介

Count source lines of code (SLOC) for any public GitHub repository — files, lines, code, comments, blanks, per language, without cloning.
