# officehut

> 标签: admin, components, css-framework, dashboard, react, scss, ui-kit, vanilla-js

## 简介

A small, paper-flavoured UI kit for dashboards and back-office apps. Plain CSS + tiny vanilla JS, with typed React bindings.
