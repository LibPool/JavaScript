# opencode-codex-bridge

> 标签: cache, codex, new-api, opencode

## 简介

OpenCode plugin to make a custom @ai-sdk/openai provider send Codex-shaped requests through your own proxy, which fixes prompt caching for LLM proxies (e.g., new-api).
