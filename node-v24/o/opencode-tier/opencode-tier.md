# opencode-tier

> 标签: automatic, autonomous, budget, cost, credits, gemini, github-copilot, go, model, open-code, opencode, plugin, switch, tier, zen

## 简介

🤖 Autonomous model tier switcher for OpenCode. Proactively monitors your Go credits and automatically switches between premium/free model tiers based on real-time budget analysis. Cross-platform, zero-config, daemon-ready.
