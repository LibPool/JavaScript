# online-sheet-bind

> 标签: JavaScript

## 简介

OnlineSheetBind 是一个基于 Vue 3 的 Excel 模板编辑器和轻量运行时。当前分支已经切换为纯前端实现：模板导入、字段来源导入、变量模板保存和 Excel 导出都在浏览器端完成，不依赖后端服务。
