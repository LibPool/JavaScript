# otoji

> 标签: cli, otoji, pipe, speech-to-text, stdio, transcript, voice, webrtc

## 简介

otoji CLI — bridge a terminal's stdio into an otoji voice graph at otoji.org. Zero-dep launcher: `npx otoji node <room>`.

## 官网

- 官网：https://otoji.org
- 源码仓库：git+https://github.com/snomiao/otoji.git
