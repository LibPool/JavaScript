# opencode-vision-analyze

> 标签: image, multimodal, opencode, opencode-plugin, plugin, vision, vision-model

## 简介

OpenCode plugin: vision_analyze tool — describe images & image URLs with your own vision model for text-only main models; native-image fast path for multimodal models. Zero runtime dependencies.
