# openstudy

> 标签: aprendizado, csharp, deepseek, didatica, educacao, estudo, golang, local-llm, mentor, nestjs, ollama, opencode, opencode-plugin, openstudy, typescript

## 简介

OpenStudy — plugin de estudo híbrido para OpenCode. Ensina Go, C#, TypeScript e NestJS usando modelo local (DeepSeek R1 via Ollama) para gerar conteúdo didático com analogias cruzadas e modelo cloud para decidir estratégia pedagógica
