# ofumangen

> 标签: JavaScript

## 简介

**ofumangen** is a TypeScript-powered code generator for [Express.js](https://expressjs.com/). It helps developers scaffold boilerplate code for models, routes, controllers, and more — making backend development faster, cleaner, and more consistent.
