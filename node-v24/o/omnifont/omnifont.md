# omnifont

> 标签: cad, canvas, font-manager, fontface, fonts, google-fonts, headless, opentype, svg, three.js, typescript, webfont, webgl, zero-dependency

## 简介

Zero-dependency headless font manager for Canvas / SVG / WebGL. Google Fonts + custom JSON, race-safe cache, &text preview optimization.
