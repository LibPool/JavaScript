# opencode-log-plugin

> 标签: logging, observability, opencode, opencode-plugin, tracing

## 简介

Observability collector plugin for OpenCode agents. One-way outbound event shipping to opencode-log-viewer (https://github.com/Mercuron/opencode-log-viewer).
