# onepass-proxy

> 标签: anthropic, claude, claude-code, compaction, context-window, proxy

## 简介

Local HTTP proxy between Claude Code and the Anthropic API that evicts old tool results from outgoing requests, keeping long sessions clear of auto-compact.
