# ogplayer

> 标签: ads, drm, fairplay, hls, ima, player, video, web-component, widevine

## 简介

OGPlayer video player for the browser — an <og-player> web component with HLS, DRM (Widevine, PlayReady, FairPlay), Google IMA ads, playlists and themeable controls.
