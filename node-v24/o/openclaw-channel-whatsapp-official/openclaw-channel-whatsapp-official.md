# openclaw-channel-whatsapp-official

> 标签: channel, imbee, openclaw, openclaw-plugin, whatsapp

## 简介

Official WhatsApp Business API for OpenClaw — pair via QR in 2 minutes using imBee's verified number. No Meta verification or server setup required. Free tier available; dedicated numbers for enterprise.
