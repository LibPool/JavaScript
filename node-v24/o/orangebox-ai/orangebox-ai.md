# orangebox-ai

> 标签: agents, anthropic, debugging, llm, observability, openai, proxy, sqlite, tracing

## 简介

Flight data recorder for the AI agent you're building — a zero-config local proxy that records every LLM API call your own agent code makes into SQLite, and renders each run as a visual timeline you can diff and export.
