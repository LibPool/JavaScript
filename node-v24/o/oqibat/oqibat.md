# oqibat

> 标签: ai-agents, calls, chat, multiplayer, nat-traversal, p2p, peer-to-peer, realtime, relay, rooms, self-hosted, turn, video, voice, webrtc

## 简介

Rooms for chats, calls and multiplayer games: peers join with a code and talk through one API. Connects at once over an end-to-end encrypted relay and upgrades to direct WebRTC. Self-hostable, browser + Node.
