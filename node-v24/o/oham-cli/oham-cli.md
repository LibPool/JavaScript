# oham-cli

> 标签: cli, codec-free, deep-zoom, exact-decode, hadamard, oham, still-image, tsb, video

## 简介

OHAM — OrthoHolonic Accessible Memory. The `oham` command line: inspect, decode any frame/window, excerpt stills, convert wire forms, and range-serve sealed .tsb containers. Exact integer decode, entirely local — no service, no GPU, no codec.
