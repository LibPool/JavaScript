# omp-multi-harness

> 标签: agent, ai, claude-code, cli, codex, delegation, omp, omp-extension, pi-coding-agent

## 简介

OMP extension that delegates work to the Codex and Claude Code CLIs — parallel runs, /sessions, and automatic routing, using each CLI's own login
