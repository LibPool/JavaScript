# open-crossword-bank

> 标签: cc0, clues, crossword, english, german, pattern, seeded, typescript, wordbank, wordlist, words

## 简介

Open, seedable bilingual (en/de) crossword word bank — 90k words/language plus a clued subset (syllables, POS, clues), with a pattern-matching query API for grid-filling. Code MIT, data CC0.
