# octarin-cli

> 标签: agent, analytics, cli, commits, git, llm, observability, octarin

## 简介

Octarin's per-user CLI: install AI-coding capture (`octarin init` / `init-repo`), authorize a machine (`octarin login`), or self-provision a workspace for an agent (`octarin init --agent` / `claim`). Streams your Claude Code / Cursor / Codex / Antigravity
