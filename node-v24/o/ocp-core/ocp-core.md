# ocp-core

> 标签: ai-agents, context, knowledge-base, markdown, multi-tenant, ocp, organizational-context-protocol, projection, rbac, substrate

## 简介

The OCP (Organizational Context Protocol) projection library — walk a git-native markdown substrate, derive access policy, produce scoped projections, and validate conformance (npx ocp-core validate).
