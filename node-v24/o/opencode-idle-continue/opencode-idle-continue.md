# opencode-idle-continue

> 标签: automation, continue, idle, loop, opencode, opencode-plugin, productivity, subagent, task-management

## 简介

OpenCode plugin that automatically sends prompts to continue processing when idle. Supports traditional mode and subagent mode with file monitoring and hot reload.
