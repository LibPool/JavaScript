# openclaw-langfuse-plugin

> 标签: langfuse, llm, observability, openclaw, openclaw-plugin, tracing

## 简介

OpenClaw plugin for reporting AI agent execution traces to Langfuse. Supports multi-target and self-hosted Langfuse.
