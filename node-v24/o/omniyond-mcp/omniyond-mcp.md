# omniyond-mcp

> 标签: ai-agents, claude, mcp, modelcontextprotocol, omniyond, scheduler

## 简介

Stdio bridge to the Omniyond MCP server — schedule HTTP calls and use Omniyond's agent tools from any MCP client (Claude Desktop, Cursor, etc.).

- 官网：https://omniyond.com
- npm 页面：https://www.npmjs.com/package/omniyond-mcp
