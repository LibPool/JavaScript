# ofiere-openclaw-plugin

> 标签: agents, ofiere, openclaw, plugin, project-management

## 简介

OpenClaw plugin for Ofiere PM - 18 meta-tools covering tasks, agents, projects, scheduling, knowledge, workflows, notifications, memory, prompts, constellation, space file management, execution plan builder, SOP management, agent brain, talent management,
