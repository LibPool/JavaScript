# opencode-nested-skills

> 标签: agent-skills, claude-code, monorepo, opencode, opencode-plugin, skills

## 简介

Claude Code style nested skill discovery for opencode — walks down into subdirectories, registers package-local skills, and surfaces them when you touch files in their directory.
