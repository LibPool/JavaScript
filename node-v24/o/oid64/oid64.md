# oid64

> 标签: base64, base64url, bigint, decode, encode, mongodb, objectid, shorten, url-safe, uuid

## 简介

Fast, strict, URL-safe base64 for MongoDB ObjectIds, UUIDs, integers and bigints. Zero dependencies, ESM, TypeScript.
