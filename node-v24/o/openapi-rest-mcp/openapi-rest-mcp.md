# openapi-rest-mcp

> 标签: api, api-testing, claude-ai, crud, cursor, dotnet, mcp, model-context-protocol, openapi, rest-api, swagger

## 简介

MCP server for any OpenAPI/Swagger REST API: CRUD calls, endpoint & schema discovery, fuzzy search, and flexible auth (bearer/apiKey/basic/auto-login). .NET-friendly.
