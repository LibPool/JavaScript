# opensec-pi-fff

> 标签: bun, fff, fuzzy-search, grep, opensec, pi, pi-bolt, pi-extension, pi-package, search

## 简介

OpenSec FFF for Pi: fast fuzzy file and content search (find, grep, @-mentions). Bun build of pi-fff for Pi-Bolt, fast on builds with and without the JIT.
