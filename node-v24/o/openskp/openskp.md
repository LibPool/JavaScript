# openskp

> 标签: 3d, autocad, bim, cad, conversion, converter, dxf, geometry, glb, gltf, ifc, obj, parser, ply, sketchup, skp, stl, three.js, webgl, writer

## 简介

Open-source SketchUp (.skp) binary file parser, writer, and converter — extract geometry, metadata, layers, and materials; create and edit .skp files; convert to GLB, OBJ, STL, PLY, DXF, and IFC4. Works in browser and Node.js.
