# opencode-roslyn

> 标签: csharp, dotnet, opencode, opencode-plugin, opencode-tool, refactoring, references, roslyn, roslynq, symbols

## 简介

C# semantic analysis for OpenCode V2 — types, symbols, members, references, call sites, implementations and renames through the `roslynq` CLI (Roslyn + MSBuildWorkspace).
