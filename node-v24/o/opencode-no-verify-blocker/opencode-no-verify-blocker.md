# opencode-no-verify-blocker

> 标签: ai-agent, git, no-verify, opencode, opencode-plugin, plugin, pre-commit

## 简介

OpenCode plugin that blocks `git commit --no-verify` / `git commit -n` to enforce pre-commit hooks.
