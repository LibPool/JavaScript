# omni-playground

> 标签: image-to-video, multimodal, playground, realtime, text-to-image, text-to-speech, vllm, vllm-omni, websocket, webui

## 简介

A local web playground for multimodal generation — chat, text-to-image, image editing, video, realtime voice and streaming against vLLM-omni endpoints.
