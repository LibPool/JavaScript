# opencode-modex

> 标签: codes, modex, opencode, plugin, snippets, soymaycol

## 简介

Plugin de OpenCode para acceder a la colección de códigos de Modex (code.soymaycol.icu). Lista códigos, obtén snippets y úsalos en tus proyectos.
