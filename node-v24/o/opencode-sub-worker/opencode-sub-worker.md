# opencode-sub-worker

> 标签: opencode, opencode-plugin, orchestration, parallel, subagent, tasks, worktree

## 简介

Turn a markdown task checklist into a dependency- and file-conflict-aware schedule, run ready tasks in parallel as isolated child sessions in their own git worktrees, coordinate through an orchestrator-mediated mailbox, and gate every task with a verifica
