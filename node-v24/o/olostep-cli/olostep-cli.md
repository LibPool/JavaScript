# olostep-cli

> 标签: ai-agents, answers, cli, crawl, map, mcp, olostep, scrape, web-scraping

## 简介

CLI for the Olostep API — scrape, map, crawl, answers, batch, plus skills and MCP install. Pure JS, no binary download.
