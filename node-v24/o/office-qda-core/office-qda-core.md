# office-qda-core

> 标签: csvqda, easyqda, officeqda, qda, qualitative-data-analysis, refi-qda, textqda

## 简介

The core library of easyQDA (reading, consensus, reliability, all QDA formats). This release ships the machine-readable easyQDA format contracts; the library itself is in closed alpha and will be published under this name.
