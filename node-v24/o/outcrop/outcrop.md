# outcrop

> 标签: agents, ai, board, kanban, local-first, markdown, mcp, planning, tasks, workspace

## 简介

Serve a folder of markdown tasks and docs as a live kanban board, docs site, and agent API. AI-native, zero-config, files are the database.
