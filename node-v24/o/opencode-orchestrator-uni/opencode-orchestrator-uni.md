# opencode-orchestrator-uni

> 标签: agents, audit, opencode, opencode-plugin, orchestrator, subagents

## 简介

Native OpenCode V2 plugin that registers the orchestrator agent kit (root orchestrator, audit subagents, fix-runner) and exposes the kit's process documents as the audit-kit reference.
