# openquire

> 标签: accessibility, cli, mupdf, ocr, pdf, pdfa, redact, sign

## 简介

PDF tools on the command line and in Node: redact, stamp, OCR, sign, tag, convert to PDF/A, Word and Excel, and run OpenQuire workflows.
