# onprem-logger

> 标签: api-logging, enterprise, express-logging, file-logging, json-logging, log, log-rotation, logger, logging, nodejs, on-premise, performance-logging, server-logging

## 简介

A powerful, flexible logging utility for on-premise Node.js servers with automatic file rotation, module-specific logs, colored console output, and JSON formatting.
