# oliverdb-tenant-mcp

> 标签: analytics, mcp, model-context-protocol, olap, oliverdb, sql

## 简介

MCP server for an OliverDB instance — SQL and batch queries (row functions, anomaly and similarity slots, transforms), schema, stats, whoami, and the agent onboarding manifest, over the instance's HTTPS endpoint with a scoped key.
