# openlaunch-sdk

> 标签: celestrak, launch, launch-library, mars, mission, nasa, orbital-mechanics, rocket, sdk, space, spaceflight, typescript

## 简介

A zero-runtime-dependency TypeScript spaceflight and mission-engineering SDK: Launch Library 2, NASA, CelesTrak, orbital mechanics, rockets, navigation, communications, thermal, EDL and mission utilities.
