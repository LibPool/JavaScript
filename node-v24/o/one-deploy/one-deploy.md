# one-deploy

> 标签: JavaScript

## 简介

This is a CLI tool that allows you to publish your web apps using the ONE Framework. Parameters: - WebApp name - the name of your web app - WebApp path - the url path your app will reside at - ONE instance - the url to your ONE Framework instance - B
