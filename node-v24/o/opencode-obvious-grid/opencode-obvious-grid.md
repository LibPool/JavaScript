# opencode-obvious-grid

> 标签: dashboard, monitoring, opencode, plugin, status

## 简介

Aggregate status web page for all running opencode instances: per-session cards with state, tokens, cost, speed graphs, git branch, web-session links, and notify toggles (ntfy push + platform alarm sound).
