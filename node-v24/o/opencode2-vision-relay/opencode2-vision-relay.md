# opencode2-vision-relay

> 标签: gemini, groq, multimodal, ollama, openai, opencode, opencode2, plugin, text-only, vision

## 简介

Native OpenCode V2 plugin that gives text-only models vision: relays image parts to Gemini or any OpenAI-compatible provider (OpenAI, Groq, OpenRouter, Ollama...) and replaces them with detailed text analyses before the model dispatch — works with any mod
