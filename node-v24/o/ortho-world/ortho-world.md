# ortho-world

> 标签: browser, component, countries, country, flags, geospatial, gis, i18n, iso-3166, nation, picker, selector

## 简介

A country selector you can drop into a <div>. 262 countries and territories — flags, capitals, ISO/IOC codes, UN membership, area, population, GDP, HDI — in 26 languages. Pairs with your map through signals: ISO 3166-1 is the shared vocabulary. No API key
