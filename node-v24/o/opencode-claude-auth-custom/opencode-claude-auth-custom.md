# opencode-claude-auth-custom

> 标签: anthropic, auth, claude, litellm, opencode, plugin

## 简介

OpenCode plugin that routes Claude Code OAuth credentials through a custom base URL (e.g. LiteLLM) using ANTHROPIC_BASE_URL and ANTHROPIC_CUSTOM_HEADERS.
