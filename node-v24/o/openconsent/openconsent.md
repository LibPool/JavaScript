# openconsent

> 标签: cmp, consent, consent-management-platform, consent-mode-v2, cookie-banner, cookie-consent, cookiebot-alternative, european-accessibility-act, gdpr, google-consent-mode, google-tag-manager, gtm, iubenda-alternative, onetrust-alternative, privacy, vanilla-javascript, zero-dependencies

## 简介

Lightweight, dependency-free GDPR Consent Management Platform (CMP) with native Google Consent Mode v2 support. Drop-in cookie banner, script blocking, no monthly fees.
