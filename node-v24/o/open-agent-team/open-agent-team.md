# open-agent-team

> 标签: agent, agent-orchestration, agent-team, ai, ai-agent, cli, coding-agent, declarative, git-worktree, llm, multi-agent, oat, open-agent-team, orchestration, orchestrator, pi-coding-agent, workspace

## 简介

Declarative multi-agent orchestration powered by pi-coding-agent: Admin → Leader → Worker hierarchy, team.json config, isolated workspaces (git worktree), and the oat CLI.
