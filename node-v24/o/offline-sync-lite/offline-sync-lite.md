# offline-sync-lite

> 标签: browser, conflict-resolution, dead-letter-queue, encryption, indexeddb, multi-tab, nextjs, offline, offline-first, pwa, react, schema-migrations, sdk, sync, web-crypto

## 简介

Lightweight offline-first sync SDK for browser clients using IndexedDB with encryption, multi-tab coordination, schema migrations, and conflict resolution.
