# ops-agents

> 标签: agents, agents-md, knowledge-base, markdown, obsidian, ops

## 简介

The canonical home of the ops-* format: a way of running an operational repository (a Markdown knowledge base of agreed facts, correspondence and decision history) that works in Obsidian, on GitHub and with AI agents.
