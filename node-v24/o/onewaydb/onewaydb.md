# onewaydb

> 标签: ai-agent, database, mcp, mysql, oracle, postgresql, read-only, sqlite

## 简介

Read-only database access gateway for AI coding agents: MySQL, PostgreSQL, Oracle and SQLite behind logical aliases, with credentials kept out of the MCP surface.
