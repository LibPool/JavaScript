# opencode-token-norm

> 标签: budget, context, cost, handoff, opencode, opencode-plugin, session, tokens

## 简介

OpenCode plugin for token-budget guardrails: counts budgeted tool calls, injects reminders at thresholds, audits usage automatically, and makes session handoff a single tool call
