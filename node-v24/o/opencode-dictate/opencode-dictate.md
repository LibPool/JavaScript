# opencode-dictate

> 标签: conversation-mode, dictation, hands-free, opencode, opencode-plugin, speech-to-text, stt, voice, whisper

## 简介

Hands-free voice conversation mode for opencode: dictate prompts, answer questions/permissions by voice, with an animated status indicator.
