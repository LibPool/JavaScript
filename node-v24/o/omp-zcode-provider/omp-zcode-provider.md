# omp-zcode-provider

> 标签: agent, omp-extension, omp-package, opencode, zcode

## 简介

Use the ZCode agent (zcodex app-server) as an omp model provider: omp is the chat frontend, ZCode runs the model and its own tools (bash, edits, session memory). Fork of zcode-provider.
