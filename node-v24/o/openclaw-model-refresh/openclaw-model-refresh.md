# openclaw-model-refresh

> 标签: llm, model-catalog, model-discovery, openclaw, openclaw-plugin, plugin, refresh

## 简介

OpenClaw plugin that keeps configured OpenAI-compatible model catalogs fresh: live discovery, /models-refresh command, and auto-refreshed model lists.
