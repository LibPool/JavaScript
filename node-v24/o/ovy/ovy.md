# ovy

> 标签: AOP, Aspect Oriented Programming, JavaScript OOP, JavaScript Object Oriented Programming, OOP, Ovy, class, define, extend, inheritance, object-oriented, ovy

## 简介

A fast, elegant, powerful, and cross platform JavaScript OOP library. Support singleton, super call, private, mixins and more.
