# oh-my-dshtoken

> 标签: dashboard, deepseek-harness, dsh, dsh-plugin, plugin, statistics, token, usage, web

## 简介

Oh My DSH Token — 纯本地的 AI Token 消耗统计面板：扫描 ~/.dsh/sessions 下全部历史会话日志，按 项目/会话/模型 三个维度聚合输入/输出/缓存读取 Token 消耗，图表+文本双形式可视化；入口常驻 dsh web 右下角，弹出独立统计面板，支持在线检测升级。Pure-local AI token usage statistics for DSH with project/session/model dimensions.
