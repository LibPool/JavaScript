# overdrive-db

> 标签: acid, database, document, embedded, encryption, json, key-value, mvcc, nosql, overdrive, sqlite-alternative, time-series, transactions, vector-search, wal

## 简介

OverDrive-DB — Embedded document database with ACID transactions, AES-256 encryption, WAL durability and 6 storage engines. The SQLite alternative for Node.js.
