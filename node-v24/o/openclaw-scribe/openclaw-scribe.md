# openclaw-scribe

> 标签: conversation, journal, logging, markdown, openclaw, plugin

## 简介

Turn-by-turn conversation logger for OpenClaw. Appends every agent exchange to daily markdown files across all surfaces — Discord, TUI, webchat, cron — regardless of model.
