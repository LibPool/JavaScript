# offline-kit-tauri

> 标签: cache, connectivity, desktop, offline, offline-first, tauri, tauri-plugin-store, typescript

## 简介

Offline support for Tauri desktop apps: typed request errors, connectivity monitoring, a scoped TTL response cache persisted through tauri-plugin-store (or localStorage), and an offline-aware cached-GET flow
