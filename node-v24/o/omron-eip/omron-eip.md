# omron-eip

> 标签: cip, ethernet-ip, ethernetip, industrial, nj, node-red, nx, omron, plc, sysmac

## 简介

Node.js EtherNet/IP client for Omron NX/NJ Sysmac controllers (symbolic tag access). Port of aphyt.
