# openwave

> 标签: agent-memory, ai-memory, fsrs, knowledge-graph, openclaw, openclaw-plugin, sharpwave, spaced-repetition

## 简介

Autonomic long-term memory for OpenClaw agents: injects the right memories into every turn automatically, runs the sleep system (consolidation, replay, extraction) in-process. Same engine as the sharpwave MCP server.
