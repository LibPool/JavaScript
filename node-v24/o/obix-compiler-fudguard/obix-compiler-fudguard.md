# obix-compiler-fudguard

> 标签: obix

## 简介

Render-time accessibility enforcement for OBIX: checks the HTML a component renders against the state that produced it, every time (touch targets, focus, labels, ARIA state, reduced motion, loading), plus the small html/escape helpers it needs.
