# @myndpm/stylus2scss

> 标签: converter, scss, stylus

## 简介

CLI utility to convert `styl` files to `scss`.   It also updates Angular Components metadata.

## 官网

- 官网：https://mynd.dev/
- 源码仓库：git+ssh://git@github.com/myndpm/open-source.git
- npm 页面：https://www.npmjs.com/package/@myndpm/stylus2scss
