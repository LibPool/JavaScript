# dsh-workspace-mcp

> 标签: cordis, deepseek-harness, dsh, mcp, model-context-protocol, plugin

## 简介

Project-level MCP servers for DeepSeek Harness: read .dsh/mcp.json (or .mcp.json) from the session workspace and mount its servers into each agent.
