# @klars/x402-mock

> 标签: 402, agentic-commerce, agents, ai, eip-3009, facilitator, mock, payment-required, sandbox, testing, usdc, x402

## 简介

Test mode for agent payments. A local, protocol-accurate x402 merchant and facilitator, so you can test paid-API flows in CI without a wallet, a chain, or a cent.
