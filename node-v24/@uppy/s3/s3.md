# @uppy/s3

> 标签: dam, file uploader, object storage, provider, r2, s3, uppy, uppy-plugin

## 简介

Browse and import files from S3-compatible object storage (AWS S3, Cloudflare R2, MinIO, Transloadit Storage) into Uppy.
