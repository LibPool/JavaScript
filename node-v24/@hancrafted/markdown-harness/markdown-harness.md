# @hancrafted/markdown-harness

> 标签: agents, cli, frontmatter, governance, knowledge-base, llm-wiki, markdown, okf

## 简介

Governance for a markdown knowledge base that agents help maintain — one config declares what each path must carry, and a steering query answers what governs a path before the file exists.
