# @openmobilehub/attesto-storefront

> 标签: agent, agentic-commerce, mcp, shopping, storefront

## 简介

The agentic storefront core — the cart/pricing/order model for an MCP shopping app, catalog-injected (own-the-code). Pairs with @openmobilehub/attesto-gate.
