# @teatak/mcp-server-browser

> 标签: agent, browser, llm, mcp, model-context-protocol, tools, websocket

## 简介

MCP (Model Context Protocol) server that runs in the browser. Register tools and prompts on the page; expose them to a local MCP client (e.g. an agent) over WebSocket.
