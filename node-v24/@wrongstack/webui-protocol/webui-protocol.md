# @wrongstack/webui-protocol

> 标签: protocol, websocket, webui, wrongstack

## 简介

Wire-protocol contracts shared between the @wrongstack/webui + @wrongstack/simpleui frontends and the @wrongstack/webui-server backend. Browser-safe: depends only on @wrongstack/core types (no ws, no node-only APIs). Extracted in 2026-08 to remove the web
