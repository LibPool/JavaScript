# @wrongstack/client

> 标签: agent, client, sdk, websocket, wrongstack

## 简介

Typed client for a running WrongStack WebUI server: open sessions, send prompts, stream the run and answer tool confirmations over the WebSocket protocol, and read live sessions over the HTTP API. No runtime dependencies; works in Node 22+ and the browser
