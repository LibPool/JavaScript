# webnav-ts-mcp

> 标签: ai-agents, code-navigation, css, html, javascript, lsp, mcp, model-context-protocol, typescript

## 简介

MCP server exposing JS/TS/HTML/CSS language-server features plus a workspace-wide CSS custom-property/selector index as MCP tools. TypeScript port of the Python webnav-mcp.
