# @codecai/web

> 标签: ai, binary, codec, detokenizer, llm, msgpack, protobuf, streaming, tokenizer

## 简介

Isomorphic edge tokenizer + lazy detokenizer for the Codec binary transport protocol. Works in browsers, Node 18+, and edge runtimes.
