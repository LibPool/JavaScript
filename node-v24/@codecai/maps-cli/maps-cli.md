# @codecai/maps-cli

> 标签: cli, codec, dialect, huggingface, llm, schema, tokenizer

## 简介

Generate Codec tokenizer dialect maps from HuggingFace tokenizer.json files. The 'tsc --declaration' for LLM token vocabularies.
