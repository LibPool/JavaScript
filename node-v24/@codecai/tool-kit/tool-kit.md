# @codecai/tool-kit

> 标签: agent, bolt-on, codec, llm, mcp, tokenizer, tool, tools-as-tokens

## 简介

Build Codec-native tools as independently-hosted bolt-ons. Pre-cache the tokenizer at build time so the gateway stays a pure token router. Companion to @codecai/mcp-leaf — leaf wraps existing MCP servers; tool-kit is the SDK for authoring net-new Codec-na
