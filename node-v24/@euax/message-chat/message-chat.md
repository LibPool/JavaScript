# @euax/message-chat

> 标签: JavaScript

## 简介

Um componente React.JS construído com Chakra-UI, que permite consumir salas e mensagens providas pelo microservice de [mensagens](https://github.com/Artia/euax-microservices/wiki/Microservice-message).

## 官网

- 源码仓库：git@github.com:Artia/mesageuax-ui.git
- npm 页面：https://www.npmjs.com/package/@euax/message-chat
