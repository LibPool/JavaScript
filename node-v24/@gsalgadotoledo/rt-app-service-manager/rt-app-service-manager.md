# @gsalgadotoledo/rt-app-service-manager

> 标签: JavaScript

## 简介

Global services → Add tools installs PostgreSQL, MongoDB, Redis or a JSON HTTP server into the manager's private directory. Installed versions are pinned; removing an entry preserves its database and binaries. PostgreSQL uses loopback-only trust authentic
