# @opengsd/gsd-browser

> 标签: accessibility, automation, browser, cdp, chrome, cli, devtools, screenshot, testing

## 简介

Browser automation CLI powered by Chrome DevTools Protocol — 92 commands for navigation, interaction, live viewing, annotations, recording bundles, screenshots, accessibility, network mocking, visual diffing, and more.
