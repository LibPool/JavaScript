# @rozie/runtime-vue

> 标签: JavaScript

## 简介

Tree-shakable Vue runtime helpers for Rozie.js-compiled components: the r-keynav composable, event-modifier wrappers (debounce/throttle/outside-click/key filters), a dynamic-listener normalizer, and a proxy-safe deep clone for the $clone sigil.
