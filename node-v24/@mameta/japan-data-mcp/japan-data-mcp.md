# @mameta/japan-data-mcp

> 标签: ai-agents, japan, japanese-data, mcp, model-context-protocol, x402

## 简介

MCP server exposing the agentic-jp.com suite of x402-paid Japan data APIs (address, furigana, transit, Diet, holiday, weather, corporate-number) as tools for AI agents. Payments are settled automatically over x402 using the operator's own wallet.
