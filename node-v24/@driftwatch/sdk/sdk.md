# @driftwatch/sdk

> 标签: ai-agent, ai-sdk, drift-detection, llm, observability, opentelemetry, otel, telemetry, vercel-ai-sdk

## 简介

Self-observing AI agent SDK: OpenTelemetry instrumentation for AI SDK agents plus an LLM-over-traces behavioral drift detector. Bring your own model client — no provider SDKs bundled.
