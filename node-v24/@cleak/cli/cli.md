# @cleak/cli

> 标签: agent, asan, c, cli, cpp, llm, lsan, mcp, memory-leak, static-analysis, tui, valgrind

## 简介

Agentic terminal investigator for C/C++ memory leaks — MCP-driven static + dynamic (Valgrind/ASan/LSan) analysis with an LLM judge.
