# @syncbooks/addon-sdk

> 标签: accounting, addon, erp, extension, marketplace, plugin, sdk, syncbooks

## 简介

Official SDK for building SyncBooks add-ons. Provides API client, React hooks, UI components, and postMessage bridge.
