# @proxyherd/fingerprint

> 标签: JavaScript

## 简介

ProxyHerd fingerprint service: tells a proxy manager whether a proxy is online and where it is (IP, network, location) from a local GeoIP database. Self-hosted; nothing leaves your infrastructure.
