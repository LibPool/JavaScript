# @jamjet/mcp-shim

> 标签: agent-safety, ai-agents, ai-governance, claude-desktop, cursor, mcp, model-context-protocol

## 简介

JamJet policy + audit + approval as an MCP stdio interceptor. Drop-in between any MCP client and any MCP server. Or run --serve-self as a standalone MCP server exposing policy_evaluate, policy_list_rules, policy_load_info to any agent.
