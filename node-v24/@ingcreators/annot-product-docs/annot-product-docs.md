# @ingcreators/annot-product-docs

> 标签: annotation, aria-snapshot, docs, documentation, drift, mdx, playwright, screen-spec, screen-specifications, screenshot

## 简介

Living product docs core — parse `.mdx` files with `annot:` frontmatter, resolve `<Overlay match>` keys against live Playwright `aria-snapshot` trees, run drift detection against the rendered UI, and ship a Playwright `screen` fixture that re-captures + r
