> 标签: ai-agent, annotation, claude, mcp, model-context-protocol, playwright, png, screenshot, svg

## 简介

Model Context Protocol server exposing the Annot headless annotator as agent-callable tools. Drop into Claude Desktop / Claude Code / Cursor and let an AI agent compose Annot with @playwright/mcp + GitHub MCP for one-turn bug-report autopilot, visual-diff
