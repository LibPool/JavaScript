# @tinyactors/scxmljs

> 标签: custom-elements, harel, interpreter, quickjs, sandbox, scxml, state-machine, statechart, statecharts, w3c

## 简介

A correctness-first SCXML 1.0 interpreter (ECMAScript data model) for the browser and Node, with custom elements for interactive statechart diagrams.
