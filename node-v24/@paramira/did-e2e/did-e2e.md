# @paramira/did-e2e

> 标签: did, ecdh, ed25519, end-to-end-encryption, paramira, x25519

## 简介

Pairwise end-to-end encryption between two did:iwacu: identities — Ed25519-to-X25519 conversion, ECDH, HKDF, XChaCha20-Poly1305. A relay carrying the result sees only an opaque blob.
