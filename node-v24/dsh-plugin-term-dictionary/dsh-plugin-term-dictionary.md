# dsh-plugin-term-dictionary

> 标签: deepseek, deepseek-harness, dictionary, dsh, dsh-plugin, glossary, terminology, 术语, 词典

## 简介

术语词典：自动识别对话中的生僻术语并建立词条，左侧插件区提供词典面板。已收录的词在回复中被划出，鼠标靠近显示简短解释，点击进入词典对应词条；选中词句可一键添加词条。
