# @bundle-lens/core

> 标签: brotli, bundle-analysis, bundle-lens, chunks, cli, encryption, manifest, mcp, sqlite, webpack

## 简介

BundleLens core: build-manifest types, the per-app encrypted SQLite store (schema, ingest, dedup, query, DB<->manifest extract/merge), the .blz codec (Brotli + AES-256-GCM), plus the CLI and MCP server. Uses the built-in node:sqlite; no webpack or native
