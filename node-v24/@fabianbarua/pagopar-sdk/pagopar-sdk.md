# @fabianbarua/pagopar-sdk

> 标签: pagopar, pagos, paraguay, pasarela, payments, sdk, typescript

## 简介

SDK no oficial de Pagopar para Node.js / TypeScript. Cliente tipado para iniciar transacciones, consultar pedidos y manejar webhooks.
