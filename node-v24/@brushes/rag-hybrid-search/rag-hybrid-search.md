# @brushes/rag-hybrid-search

> 标签: RAG, pi-package, 向量检索, 搜索, 文档, 查找, 检索, 混合检索, 知识库, 语义检索

## 简介

从知识库文档（PDF、报告、日报、Markdown 等）里精准检索相关段落：融合关键词（词法）
  与向量（语义）两路召回，再用 MMR 去重重排。当用户要在知识库中查找资料、检索或搜索
  文档内容时使用，触发词：检索、知识库、文档、搜索、查找、查资料、找资料、找文档、
  搜文档、知识库检索、检索知识库、混合检索、向量检索、语义检索、RAG。也用于「搜一下知识库」
  「查一下XX文档」「知识库里有没有关于XX的内容」「帮我找XX相关的文档」等短语。
  不用于：通用网页搜索（WebSearch）、飞
