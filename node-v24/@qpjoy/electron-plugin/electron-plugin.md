# @qpjoy/electron-plugin

> 标签: electron, marketplace, plugin, plugin-host, qpjoy

## 简介

Plugin host runtime + marketplace admin panel for QPJoy electron apps. Install, sandbox, and update plugins from a local SPA on 127.0.0.1:23455.
