> 标签: api, arabic, breakout-rooms, deewan, e2ee, polls, recording, sdk, video, video-meetings, webhooks, webinars, webrtc

## 简介

Official Deewan server SDK for Node.js, Bun, Deno and edge runtimes: rooms, join links, media tokens, participants, meetings, webinars, polls, breakout rooms, recordings and signed webhooks.
