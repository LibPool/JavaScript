# @acc1143/dsh-vision-bridge

> 标签: deepseek-harness, dsh, dsh-plugin, image-analysis, llm, multimodal, vision

## 简介

DSH 双模型路由插件：主对话留在 DeepSeek，图片任务自动分发到显式配置的视觉模型，再把分析结果交回 DeepSeek 继续。
