# @apparelhub/mcp-server

> 标签: agentic-commerce, ai-agents, apparelhub, ecommerce, mcp, model-context-protocol, print-on-demand

## 简介

ApparelHub MCP server: workflow-level tools that let an AI agent design apparel, build products, and sync them to sales channels through the ApparelHub platform.
