# @mcpip/sdk

> 标签: agent, authorization, gateway, mcp, mcpip, zero-trust

## 简介

Zero-dependency TypeScript/ESM client for the MCPIP authorization gateway: authorize, PIN step-up ceremony, MCP edge, catalog, audit, and the operator admin surface. Opaque, fail-closed, never retries an authorize.
