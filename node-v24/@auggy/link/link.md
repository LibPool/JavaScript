# @auggy/link

> 标签: JavaScript

## 简介

Link — the v1 entry point to the Mesh. Peer-to-peer agent ↔ agent over A2A v0.2 (JSON-RPC), mutual bearer auth, durable task store, no central service. See ADR-022.
