# @rxweave/server

> 标签: effect, event-sourcing, rpc, rxweave, server

## 简介

Local HTTP event-stream server for RxWeave — hosts @rxweave/protocol RpcGroup over NDJSON. Embed in apps or run standalone via `rxweave serve`.
