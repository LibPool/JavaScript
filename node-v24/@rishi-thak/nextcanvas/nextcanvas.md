# @rishi-thak/nextcanvas

> 标签: app-router, ast, codemod, developer-tools, devtools, dx, inline-editing, live-editing, next, nextjs, react, swc, swc-plugin, ts-morph, visual-editor, wysiwyg

## 简介

Turn a locally-running Next.js app into an editable canvas. Double-click text in the browser, edit it, and the source file is rewritten.
