# @tnventures/modelgenerator-reactnative-runtime

> 标签: code-generation, expo, mobx, modelgenerator, react-native, runtime

## 简介

React Native runtime for ModelGenerator — Mg* form field components, a native dialog manager, and the view-model bases consumed by generated .g.ts / .g.tsx code. Companion to @tnventures/modelgenerator-react-runtime, from which it re-exports every platfor
