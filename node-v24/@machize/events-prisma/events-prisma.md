# @machize/events-prisma

> 标签: events, machize, outbox, postgresql, prisma, store, typescript

## 简介

Prisma-backed implementation of the @machize/events OutboxStore (transactional outbox) — the production reference backend (PostgreSQL/MySQL). Bring your own PrismaClient; ships a reference schema.
