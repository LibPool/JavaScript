# @machize/subscriptions

> 标签: billing, machize, saas, stripe, subscriptions, typescript

## 简介

Billing for Machize, Cashier/Soulbscription-style: declarative plans, subscriptions with trials, feature flags, usage limits, gateway drivers and idempotent webhooks.
