# @machize/events-sqlite

> 标签: events, machize, outbox, sqlite, store, typescript

## 简介

Durable, SQLite-backed implementation of the @machize/events OutboxStore (transactional outbox), on Node's built-in node:sqlite. Zero external dependencies.
