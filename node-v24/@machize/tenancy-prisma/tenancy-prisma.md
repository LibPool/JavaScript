# @machize/tenancy-prisma

> 标签: machize, multi-tenant, postgresql, prisma, store, tenancy, typescript

## 简介

Prisma-backed implementation of the @machize/tenancy TenantSource — the production reference backend (PostgreSQL/MySQL). Bring your own PrismaClient; ships a reference schema.
