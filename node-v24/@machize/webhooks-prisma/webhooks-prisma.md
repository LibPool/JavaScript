# @machize/webhooks-prisma

> 标签: machize, postgresql, prisma, store, typescript, webhooks

## 简介

Prisma-backed implementation of the @machize/webhooks WebhookStore (endpoint subscriptions) — the production reference backend (PostgreSQL/MySQL). Bring your own PrismaClient; ships a reference schema.
