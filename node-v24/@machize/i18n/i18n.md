# @machize/i18n

> 标签: i18n, internationalization, intl, machize, saas, typescript

## 简介

Internationalization for Machize: context-resolved locale (per user/tenant), typed message catalogs with interpolation and plurals, and Intl-based formatting. Zero dependencies.
