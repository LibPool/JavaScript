# @dailies-studio/text

> 标签: JavaScript

## 简介

First-party text animation preset library (F3-D): split chars/words/lines + stagger, presets as pure (visibility, params) -> unit styles (identical in editor preview, both export tiers, and the player), the canonical per-frame state resolver every surface
