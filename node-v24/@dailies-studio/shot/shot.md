# @dailies-studio/shot

> 标签: JavaScript

## 简介

Shot lane data plane: the Doc3D schema (scenes of free-transform 3D layers with a per-scene camera and cinematic post), the block animation resolver, validation, migration, the Canvas2D layer rasterizer, deterministic codegen, and the three.js ShotRuntime
