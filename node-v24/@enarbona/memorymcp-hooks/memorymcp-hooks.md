# @enarbona/memorymcp-hooks

> 标签: claude-code, copilot-cli, hooks, mcp, memory

## 简介

Installer + hooks for a remote MemoryMcp server: registers the MCP server in Claude Code, Copilot CLI, Gemini CLI, VS Code and Visual Studio.
