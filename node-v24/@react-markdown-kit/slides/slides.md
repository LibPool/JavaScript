# @react-markdown-kit/slides

> 标签: deck, markdown, markdown-presentation, markdown-slides, marp-alternative, plugin, presentation, react, slides, speaker-notes

## 简介

Slides from Markdown for React Markdown Kit, as a plugin: slides() reads a deck (slides split on ---, speaker notes after ???, fragments after --, <!-- key: value --> directives) and renders it as static sections; /present adds keyboard-driven present mod
