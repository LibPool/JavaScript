# @nx-devkit/openspec

> 标签: monorepo, nx, nx-plugin, openspec, spec-driven, specs, validation, zero-config

## 简介

Nx plugin: openspec/config.yaml infers a cached spec-validate target plus per-change spec-validate:<id> targets — no project.json needed.
