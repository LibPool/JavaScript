# @llmsproxy/mcp-server

> 标签: claude, cline, cursor, llm, mcp, model-context-protocol, openai, proxy

## 简介

ProxiedLLMs MCP server — JSON-RPC 2.0 bridge to the ProxiedLLMs gateway over stdio. Configures Claude Desktop, Cursor, Cline, Zed and other MCP clients.
