# @textforagents/default-watch-pinning

> 标签: agents, mcp, model-context-protocol

## 简介

Default-watch and pinning service for agents: watches the defaults your agents depend on and pins the previous behavior in place when an upstream default moves. Watch $5/mo, Fleet $9/mo + $0.01/delta.
