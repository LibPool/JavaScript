# @ariaskit/optipix

> 标签: avif, cli, compress, convert, image, images, jpeg, optimize, optimizer, png, resize, sharp, webp

## 简介

A fast, colorful CLI that scans a folder and optimizes every image with sharp — pick the output format, dimensions and quality.
