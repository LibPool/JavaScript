# @weavo/client

> 标签: browser, collaborative-editing, crdt, real-time, sync, text-editing, textarea, weavo, websocket

## 简介

Real-time collaborative text editing for the browser — bind a textarea, connect to a WebSocket room, edits sync automatically.
