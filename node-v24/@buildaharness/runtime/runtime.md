# @buildaharness/runtime

> 标签: agent-harness, ai-agent, buildaharness, flowspec, indexeddb, llm

## 简介

Framework-agnostic client-side FlowSpec executor for Build A Harness — storage adapters (in-memory, IndexedDB/Dexie), experience store, and LLM clients (proxy, Anthropic, OpenAI-compatible).
