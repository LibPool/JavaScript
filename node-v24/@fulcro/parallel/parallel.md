# @fulcro/parallel

> 标签: cancellation, parallel, pool, structured-concurrency, typescript, web-worker, worker, worker-threads

## 简介

Structured tasks with cancellation for work that waits, and a worker pool for CPU-bound work, on the browser and on Node.
