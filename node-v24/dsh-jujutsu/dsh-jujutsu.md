# dsh-jujutsu

> 标签: cordis, deepseek-harness, dsh, dsh-bundle, dsh-plugin, jj, jj-hunk, jujutsu

## 简介

Refuses Git inside a Jujutsu workspace and hands the model the jj command instead. Eleven jj tools, prompt teaching, and a jj-hunk bridge for the DeepSeek Harness.
