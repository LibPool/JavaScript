# @angular-health-check/cli

> 标签: analyzer, angular, audit, change-detection, cli, code-quality, dashboard, diagnostics, health-check, linter, onpush, performance, rxjs, score, signals, static-analysis, technical-debt, trackby

## 简介

Angular code quality analyzer — detects missing OnPush, ngFor trackBy, RxJS leaks, and Signals adoption. Scores 0-100 normalized by project size.
