# @qubit-ltd/jsdoc-theme

> 标签: constructor detection, customizable jsdoc theme, javascript documentation, jsdoc, jsdoc-template, properties table, qubit, template

## 简介

A customized JSDoc theme based on clean-jsdoc-theme, enhanced with properties table and constructor detection features for Qubit projects.
