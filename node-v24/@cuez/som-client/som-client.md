# @cuez/som-client

> 标签: broadcast, ibc, kafka, newsroom, smart-stories, som, story-object-model

## 简介

Ergonomic, typed EventEmitter client for the Story Object Model (SOM) v0.3 bus: connect, authenticate, listen for stories and skill messages by type, and publish fail-closed.
