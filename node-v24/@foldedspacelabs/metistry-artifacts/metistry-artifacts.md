# @foldedspacelabs/metistry-artifacts

> 标签: JavaScript

## 简介

Publish-and-review for agent output, backed by a versioned vault: compare-and-swap publish (idempotent, attributed), comment threads on exact versions, and review dispatch that rides a shared task list — with the agent-to-agent autonomy boundary enforced
