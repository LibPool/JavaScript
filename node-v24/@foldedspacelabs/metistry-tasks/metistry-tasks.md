# @foldedspacelabs/metistry-tasks

> 标签: JavaScript

## 简介

A shared task list for heterogeneous agents: atomic claims, leases with heartbeat, dependency gating, idempotent create, append-only history. One TypeScript service over any pg-shaped client; adapters (HTTP, MCP, CLI) add nothing.
