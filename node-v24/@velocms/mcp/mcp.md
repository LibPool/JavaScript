# @velocms/mcp

> 标签: blog, claude, cms, mcp, mcp-server, publishing, seo, velocms

## 简介

MCP server for VeloCMS — draft, publish, and manage your blog (posts, media, comments, members) from Claude Code, Claude Desktop, Cursor, or any MCP client.
