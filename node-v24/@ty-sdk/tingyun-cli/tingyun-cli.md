# @ty-sdk/tingyun-cli

> 标签: JavaScript

## 简介

```bash npm install @ty-sdk/tingyun-cli -g  全局安装 tingyun-cli -v   查看版本 tingyun-cli create <appName>  创建指定名称的应用脚手架 tingyun-cli create <appName> -apiRoot <apiRoot> 创建指定名称的应用脚手架、指定项目中资源请求的baseUrl ```
