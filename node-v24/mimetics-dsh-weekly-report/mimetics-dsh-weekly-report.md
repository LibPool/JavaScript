# mimetics-dsh-weekly-report

> 标签: automation, deepseek-harness, dsh-plugin, report, weekly-report

## 简介

Harness (dsh) 工具插件：generate_weekly_report —— 在对话框里说一句「帮我生成本周周报」，即生成固定四模块的 Markdown 周报；内置流水线，装上即用。
