# @vectros-ai/mcp-server

> 标签: claude-desktop, hybrid-search, mcp, model-context-protocol, rag, vectros

## 简介

MCP server exposing Vectros hybrid search, structured records, and in-perimeter RAG/document-ask to MCP-aware desktop agents (Claude Desktop, Cursor, Code, Cline, Continue, VS Code).
