# @bernierllc/string-similarity

> 标签: bernierllc, fuzzy, jaro-winkler, levenshtein, similarity, string, unicode

## 简介

Pure Unicode-aware string similarity primitives: Jaro-Winkler, Levenshtein, name/email/phone/date comparators with diacritic folding and pluggable nickname tables.
