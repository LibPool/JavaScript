# @klappay/types

> 标签: 0xsplits, blockchain, crypto-payments, klap, non-custodial, payments, types, typescript, usdc, usdt, web3, zod

## 简介

TypeScript types and Zod schemas for the Klappay Core API — the request/response contracts, published separately so integrators get them without needing access to the (closed-source) API implementation.
