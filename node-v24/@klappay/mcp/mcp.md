# @klappay/mcp

> 标签: crypto, klap, klappay, mcp, model-context-protocol, payments, web3

## 简介

Local stdio MCP server for the Klap Core API — lets an AI assistant read charges, webhooks, networks and metrics, and (in test mode) create charges and simulate sandbox events, using the key `klap login` already stored on your machine.
