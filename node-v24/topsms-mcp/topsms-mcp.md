# topsms-mcp

> 标签: ai-agent, claude, czech, mcp, model-context-protocol, slovakia, sms, sms-gateway, topsms

## 简介

MCP server for TopSMS, a Czech SMS gateway: send and schedule SMS, bulk SMS, OTP verification codes, delivery status and credit from Claude, ChatGPT, Cursor and other AI assistants.
