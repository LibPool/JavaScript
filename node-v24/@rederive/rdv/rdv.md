# @rederive/rdv

> 标签: held-out-oracle, quorum, rederive, supply-chain, verified, verifier

## 简介

The rdv verdict core, re-derived as verified units. The trust-critical decision logic (eq / grade / quorum / hashOk) with adversarial held-out oracles — the verifier, in its own catalog. Verify it or re-derive it with rdv.
