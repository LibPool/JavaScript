# armory-mcp

> 标签: agent, ai, armory, claude, mcp, model-context-protocol, registry

## 简介

The Armory MCP server: search, get, and submit agent-harness components from the Armory registry over stdio. (This is Armory's OWN harness, not one of the cataloged components.)

- npm registry：https://registry.npmjs.org/armory-mcp
- Node 要求：>=18
