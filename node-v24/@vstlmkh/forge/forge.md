# @vstlmkh/forge

> 标签: agent, ai-agents, claude, claude-code, developer-tools, harness, knowledge-base, scaffolding, tracker

## 简介

A reusable agent harness for any repository: test-first ticket cycle, Markdown tracker, typed knowledge base, role agents and the hooks that keep them honest.
