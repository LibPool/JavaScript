# @ruvnet/ruview-kernel

> 标签: channel-state-information, csi, metaharness, napi-rs, ruview, vital-signs, wasm, webassembly, wifi-sensing

## 简介

RuView portable compute kernel for Node and browsers: the ADR-021 vitals pipeline in Rust, shipped as zero-import WebAssembly with an optional napi-rs native backend and a byte-identical JSON ABI.
