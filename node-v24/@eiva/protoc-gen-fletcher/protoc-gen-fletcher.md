# @eiva/protoc-gen-fletcher

> 标签: code-generation, fletcher, protobuf, protoc, typescript

## 简介

protoc plugin that generates typed TypeScript schema descriptors for Fletcher's positional wire format. Downloads the platform-matching native plugin binary from GitHub Releases on first invocation.
