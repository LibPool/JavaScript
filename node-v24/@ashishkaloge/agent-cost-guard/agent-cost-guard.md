# @ashishkaloge/agent-cost-guard

> 标签: agent, claude-code, cli, codex, cost, cursor, github-copilot, guardrail, hooks, policy

## 简介

Local, deterministic policy gate that inspects proposed agent commands and tool calls for cost-bearing actions and returns allow, approval-required, or block.
