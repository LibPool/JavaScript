# @trustflow/vercel-plugin

> 标签: did, did:web, llms.txt, next, trustflow, vercel

## 简介

Trustflow Vercel build hook. Signs did:web and llms.txt from environment secrets during deploy, with no interactive CLI. Scaffold with npx @trustflow/cli@latest init.
