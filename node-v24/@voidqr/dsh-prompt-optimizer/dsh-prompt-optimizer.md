# @voidqr/dsh-prompt-optimizer

> 标签: composer, deepseek, deepseek-harness, dsh, dsh-plugin, prompt, prompt-optimizer, rewrite

## 简介

DSH prompt optimizer: a ✨ button in the composer tool row (immediately left of the model selector) that rewrites the draft into a structured, unambiguous prompt and fills it back without sending — host-side isolated one-shot LLM call on the session's own
