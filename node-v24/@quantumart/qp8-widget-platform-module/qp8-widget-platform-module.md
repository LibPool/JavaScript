# @quantumart/qp8-widget-platform-module

> 标签: QP, QP8, npm, package, react

## 简介

Данный проект является частью системы QP8.WidgetPlatform и содержит в себе шаблон для построения модулей, содержащих один или более компонентов (страниц и виджетов)
