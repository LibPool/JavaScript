# @titon-network/automaton

> 标签: automation, automaton, blockchain, forgeton, kronos, phoebe, restaking, shared-security, themis, titon, ton

## 简介

Production-ready off-chain automaton node for the Titon protocol suite (Kronos automation, Fortuna VRF, Themis sealed-bid threshold-decryption, Phoebe price oracle). Stake once with ForgeTON, earn across every admitted consumer product. Built on TSA-audit
