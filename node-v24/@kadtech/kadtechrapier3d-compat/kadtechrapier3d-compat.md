# @kadtech/kadtechrapier3d-compat

> 标签: dynamics, joints, physics, real-time, rigid

## 简介

3-dimensional physics engine in Rust - kadtech's interpretation of the JS bindings. Compatibility package with inlined webassembly as base64.
