# @heaventreeuk/passcrunch-mcp

> 标签: generator, mcp, model-context-protocol, passphrase, password, security

## 简介

PassCrunch MCP server: lets AI agents generate cryptographically secure passwords, passphrases and random strings, and check strength, entirely locally.
