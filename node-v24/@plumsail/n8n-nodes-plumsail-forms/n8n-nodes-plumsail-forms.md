# @plumsail/n8n-nodes-plumsail-forms

> 标签: forms, n8n-community-node-package, plumsail

## 简介

Plumsail Forms allows you to create public web forms, share them with your users, and automate submission processing. This node package integrates Plumsail Forms with n8n, allowing you to process form submissions in your workflows.
