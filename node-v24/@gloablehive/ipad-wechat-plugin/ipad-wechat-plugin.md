# @gloablehive/ipad-wechat-plugin

> 标签: channel, ipad, juhebot, messaging, openclaw, plugin, wechat

## 简介

OpenClaw channel plugin for iPad WeChat protocol - enables sending/receiving WeChat messages through JuHeBot API
