# @open-kingdom/crm-backend-data-access-opportunities

> 标签: JavaScript

## 简介

A NestJS module providing persistence and REST endpoints for the two CRM pipeline entities — **leads** (top-of-funnel inquiries) and **opportunities** (qualified deals in motion). Leads are intentionally lightweight and exist only until they are converted
