# @tightknitai/storybook-addon-slack-block-kit

> 标签: block-kit, design-system, preview, react, slack, slack-block-kit, storybook, storybook-addon, storybook-addons

## 简介

Storybook 10 addon that renders Slack Block Kit JSON the way Slack would — decorator + panel + toolbar globals (surface/theme) + MDX doc block.
