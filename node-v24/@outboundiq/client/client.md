# @outboundiq/client

> 标签: ani, caller-id, contact-center, dialer, nrm, outboundani, outboundiq, sdk

## 简介

Official TypeScript SDK for the outboundIQ platform: ANI assignment, dial ingestion, custom dialer integration, NRM, live feed, and webhook verification.
