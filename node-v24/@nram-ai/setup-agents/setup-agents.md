> 标签: agent, ai, claude-code, codex, copilot, cursor, mcp, memory, model-context-protocol, neural-ram, nram, onboarding, opencode, setup

## 简介

Connects AI coding agents (Claude Code, Codex, Cursor, VS Code, and more) to a Neural Ram (nram) memory server: MCP registration plus agent memory instructions, in one command
