# @razein97/tauri-plugin-rusqlite2

> 标签: database, rusqlite, sql, sqlite, tauri, tauri-plugin

## 简介

A fork of tauri-plugin-sqlite by @bspeckco using rusqlite, supporting only SQLite with added transaction capabilities.
