# @mp-consulting/homebridge-ai-core

> 标签: ai, anthropic, claude, gemini, homebridge, homekit, llm, openai, smart-home

## 简介

Slim AI core for Homebridge plugins — provider adapters (Anthropic, OpenAI, Gemini, OpenAI-compatible), secret redaction, prompts, Assistant features and the plugin settings UI routes. No MCP dependencies.
