# @pax-training/prisma-extension-binary-uuid

> 标签: aurora, binary(16), binary-uuid, index-performance, mariadb, mysql, prisma, prisma-client-extension, prisma-extension, storage-optimization, uuid

## 简介

Transparent BINARY(16) UUID storage for Prisma + MySQL / MariaDB. Keeps string IDs in your application code while cutting storage and index size in half at the database layer.
