# @j20041426/wxml-to-canvas

> 标签: JavaScript

## 简介

该版本优化了部分细节，使得该组件更易使用。 1. 增加font-weight属性，支持`normal`和`bold`参数。 2. border-radius增加对4个圆角分别控制的写法，例如`'0 0 10 10'`。 3. 解决iOS系统报错的问题，iOS系统下画布的高度限制在4096以内。
