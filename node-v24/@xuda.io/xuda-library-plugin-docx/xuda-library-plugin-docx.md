# @xuda.io/xuda-library-plugin-docx

> 标签: ai, document, docx, office, plugin, report, word, xuda

## 简介

Create and edit Word documents (.docx) from a prompt or a structured document spec, with AI generated pictures embedded, and read existing documents back as an outline
