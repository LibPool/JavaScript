# @lafllamme/personal-page-shared

> 标签: access, categories, cms, collections, media, monorepo, pages, payload, personal-page, posts, shared, types, users, utils

## 简介

Shared types, utilities, and Payload CMS collections for the personal-page monorepo. Includes types, access utils, and Payload collection configs for Posts, Pages, Media, Users, and Categories.
