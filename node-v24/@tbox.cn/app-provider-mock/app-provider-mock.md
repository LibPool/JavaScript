# @tbox.cn/app-provider-mock

> 标签: JavaScript

## 简介

商圈 Mock Provider 包（极简零配置）：18 槽 local 供给开箱即用（含 auth.alipay-login 标签供给——登录换码路由仍走 member.account 绑定）；免传输/凭据/实例配置/集成配置；config 消费与配置验证面见 @tbox.cn/app-provider-mocktest。
