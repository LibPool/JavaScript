# @tbox.cn/app-agent-sdk-client

> 标签: JavaScript

## 简介

tbox agent 应用框架 client 轴：chat-store 状态域、WS、卡片运行时、能力适配器（asr/tts/upload/feedback）、历史/深链自动发送。通用底座（runtime/http/logger/bridge/卡片渲染基元）在 @tbox.cn/app-sdk-client。
