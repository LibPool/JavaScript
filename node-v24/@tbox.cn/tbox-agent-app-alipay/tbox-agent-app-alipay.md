# @tbox.cn/tbox-agent-app-alipay

> 标签: JavaScript

## 简介

tbox-agent-app 的支付宝小程序壳：用 web-view 加载部署后的首页（根 /），并把 H5 的 JSAPI 桥请求代理到小程序原生能力（选图/录音/定位/换码登录等）。可作为参考项目或直接二开使用。
