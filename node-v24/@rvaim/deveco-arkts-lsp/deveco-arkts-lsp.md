# @rvaim/deveco-arkts-lsp

> 标签: arkts, code-intelligence, deveco, harmonyos, language-server, lsp, mcp, mcp-server, openharmony

## 简介

MCP server that bridges ArkTS/HarmonyOS Language Server Protocol to Model Context Protocol, providing code intelligence tools (find references, go to definition, hover, symbols, call hierarchy).
