# @binarynoir/vitepress-html-escape

> 标签: docs, documentation, escape, html, markdown-it, markdown-it-plugin, vitepress, vitepress-plugin, vue

## 简介

Stop stray angle brackets and {{ }} in VitePress 2 Markdown from breaking the build: unbalanced tags like Array<string> render as text, real HTML and components are left alone.
