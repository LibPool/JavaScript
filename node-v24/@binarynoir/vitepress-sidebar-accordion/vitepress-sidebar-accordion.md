# @binarynoir/vitepress-sidebar-accordion

> 标签: accordion, collapsible, docs, documentation, sidebar, vitepress, vitepress-plugin, vitepress-theme, vuepress

## 简介

Make the VitePress sidebar an accordion: one open group per level, and only the current page's branch left open after navigating, as the VuePress sidebar behaved.
