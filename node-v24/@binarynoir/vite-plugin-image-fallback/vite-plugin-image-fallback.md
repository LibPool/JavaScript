# @binarynoir/vite-plugin-image-fallback

> 标签: build, fallback, images, placeholder, vite, vite-plugin

## 简介

A Vite plugin that swaps a broken relative/root-relative image import for a placeholder SVG at build time, instead of failing the whole build.
