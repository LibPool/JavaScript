# @binarynoir/vitepress-auto-sidebar

> 标签: docs, documentation, sidebar, vitepress, vitepress-plugin

## 简介

Automatically generate a VitePress 2 multi-sidebar config from your docs folder structure, with per-directory ordering, titles, hiding, and exclusion files.
