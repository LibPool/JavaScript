# @affiant/adapter-ai-sdk

> 标签: affiant, affidavit, agent-tools, ai-agents, ai-sdk, approval-workflow, guardrails, human-in-the-loop, tool-calling, vercel-ai-sdk

## 简介

Wires Affiant tool definitions into the AI SDK: every write an agent proposes runs through the gate and is filed as an Affidavit instead of executing.
