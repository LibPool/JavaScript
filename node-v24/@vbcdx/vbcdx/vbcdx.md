# @vbcdx/vbcdx

> 标签: agent-pack, agents, claude-code, codex, hermes, installer, mcp, opencode, vbcdx

## 简介

One installer for agent packs, skills and MCP tool packages: vbcdx install agent|skill|tool --harness=<claude|codex|opencode|hermes>. Renders the roles of installed agent packs (vbcdx-pack.json) and registers installed tool packages from their vbcdx.json
