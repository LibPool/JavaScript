# @gaborwnuk/axs-core

> 标签: axs, bicycle, ble, bluetooth, bluetooth-low-energy, cycling, derailleur, drivetrain, eagle, gatt, react-native, sram, transmission

## 简介

Read live state — including current gear — from SRAM AXS components over Bluetooth Low Energy. Zero runtime dependencies; runs under Node, Hermes and the browser.
