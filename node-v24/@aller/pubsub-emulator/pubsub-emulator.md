# @aller/pubsub-emulator

> 标签: emulator, fake, google cloud pubsub, grpc, mock, pubsub

## 简介

In-process Google Cloud Pub/Sub emulator for tests, runs the real @google-cloud/pubsub client against a local gRPC server
