# @kne/super-select

> 标签: antd, dropdown, form, i18n, multiselect, picker, react, searchable, select, table-select, tree-select

## 简介

React 复杂信息选择组件库，提供列表、表格、树形等多种选择模式，支持单选/多选、搜索、全选等功能
