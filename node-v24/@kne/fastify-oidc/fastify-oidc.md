# @kne/fastify-oidc

> 标签: authentication, dpop, fastify, jwt, kne, multi-tenant, oauth2, oidc, oidc-provider, pkce, sso, token-exchange

## 简介

基于 oidc-provider 的 Fastify OIDC 认证插件，支持 standalone / central 多项目单点登录、租户与跨项目令牌
