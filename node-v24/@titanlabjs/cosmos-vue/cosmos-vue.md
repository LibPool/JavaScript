# @titanlabjs/cosmos-vue

> 标签: blockchain, cosmjs, cosmos, transaction, wallet

## 简介

@titanlabjs/cosmos-vue is a JavaScript library providing vue hooks for interacting with Cosmos SDK based blockchains.
