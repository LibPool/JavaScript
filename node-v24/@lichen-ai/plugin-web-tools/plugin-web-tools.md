# @lichen-ai/plugin-web-tools

> 标签: JavaScript

## 简介

`@lichen-ai/plugin-web-tools` adds web fetching and internet search capabilities to [Xpert AI](https://github.com/xpert-ai/xpert) agents. The middleware provides two LangChain tools — `web_fetch` for retrieving web page content and `web_search` for search
