# @forge-cms/agent

> 标签: agent, cms, experimental, mcp, skills, typescript

## 简介

EXPERIMENTAL development-time tooling for ForgeCMS: a one-command installer (`forge-cms-agent init`), a read-only local MCP server and an official skill pack for AI coding agents.
