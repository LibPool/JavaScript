# @didrod2539/i18nlint

> 标签: cldr, gettext, i18n, i18n-linter, i18next, icu, internationalization, l10n, locale, localization, missing-keys, pluralization, react-intl, translation, translation-checker

## 简介

Lint i18n/l10n translation files locally: missing keys, placeholder mismatches, CLDR-aware incomplete plural forms, HTML tag drift and untranslated leftovers. Deterministic CLI, JSON/Markdown reports, no API key, no server.
