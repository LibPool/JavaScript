# @sanvika/cloudinary

> 标签: cdn, cloudinary, ecosystem, image-upload, media-management, sanvika

## 简介

Centralized Cloudinary SDK for the Sanvika ecosystem — proxy gateway mode (zero credentials). Legacy direct mode requires consumer to install 'cloudinary' npm package (not recommended).
