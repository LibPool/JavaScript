# @rohankumar4179/agentmarket-mcp

> 标签: JavaScript

## 简介

Stdio MCP server that bridges Claude Desktop, Cursor, Windsurf, and other local MCP clients to AgentMarket's remote Streamable HTTP MCP endpoint (/mcp) — install with npx, no local API required.
