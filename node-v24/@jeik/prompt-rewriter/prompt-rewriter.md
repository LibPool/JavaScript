# @jeik/prompt-rewriter

> 标签: JavaScript

## 简介

按 YAML 模板，在**消息进 AI 之前**和**回复发出之前**做结构化包裹，并可让 AI 给回复**打标记**，配合钉钉连接器精准认定最终答案。
