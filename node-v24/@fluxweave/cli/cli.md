# @fluxweave/cli

> 标签: cli, fluxweave, graphql, mcp, mcp-server, weave

## 简介

Fluxweave platform CLI — ships an MCP server (fluxweave) exposing dispatch/ticket, tracker, and layout operations against api.weave.io.
