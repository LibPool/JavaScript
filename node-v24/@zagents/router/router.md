# @zagents/router

> 标签: agent-gemini, cost-optimal, draco, embeddings, knn, llm-routing, model-routing, zagents

## 简介

Cost-optimal model router for AI agent harnesses — route each query to the cheapest model that's good enough (k-NN over labelled embeddings). The productized DRACO Phase-2 finding.
