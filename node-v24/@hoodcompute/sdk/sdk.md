# @hoodcompute/sdk

> 标签: ai, decentralized, hoodcompute, inference, llm, on-chain, openai-compatible, robinhood-chain, streaming, web3

## 简介

Typed TypeScript SDK for the HoodCompute decentralized AI inference network. OpenAI-compatible chat completions with on-chain settlement receipts on Robinhood Chain.
