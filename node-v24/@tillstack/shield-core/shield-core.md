# @tillstack/shield-core

> 标签: edge, firewall, rate-limit, security, tilldev, tillshield, waf

## 简介

TillShield inline edge-decisioning engine — request matching, rate limiting, config sync and decision reporting. Runtime-agnostic core shared by @tillstack/shield-node and @tillstack/shield-cloudflare.
