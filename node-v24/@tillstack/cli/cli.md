# @tillstack/cli

> 标签: cli, observability, source-maps, tilldev, tillgate, tillpulse, tillshield

## 简介

TillDev command-line interface — manage TillPulse observability, TillShield edge WAF, TillGate and TillAuth from your terminal (source-map uploads, rules-as-code, and more).
