# @tillstack/tillgate-core

> 标签: bot, captcha, human-check, proof-of-work, tilldev, tillgate

## 简介

TillGate server core — proof-of-work primitives, HMAC challenge/token blobs, adaptive risk engine, ASN datacenter detection, test keys and the reputation bloom filter. Runtime-agnostic (Node + Cloudflare Workers nodejs_compat); shared by the tillgate-edge
