# @tillstack/cache-node

> 标签: cache, ioredis, kv, node, pubsub, queue, redis, tillcache, tilldev

## 简介

TillCache client for Node.js — managed KV, durable queues and pub/sub over one HTTPS endpoint, with a drop-in ioredis-compatible surface.
