# @nanocollective/sentinel

> 标签: audit, code-review, github-actions, local-first, nanocoder, sast, security, typescript

## 简介

An installable, Nanocoder-driven workflow that runs continuous, configurable security and code audits across a GitHub organisation's repositories and files findings as issues.
