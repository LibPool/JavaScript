# @nicwn/tencentdb-agent-memory-proxy

> 标签: pi-package

## 简介

Pi client for TencentDB Agent Memory v2 — routes Pi through the TDAI Memory Proxy for team memory (L3 persona, L2 scene index, L0 capture, on-demand L0/L1/L2 search).
