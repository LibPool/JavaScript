# @nickmeriano/agent-client

> 标签: agent, browser, chat, claude, claude-code, local-first

## 简介

Browser client for @nickmeriano/agent-host: pair a page with the visitor's local Claude Code, open a session with the page's own tools, stream a turn. Framework-free ESM, no dependencies.
