# @aip-tech/braid-plugin-ui

> 标签: braid, braid-plugin, dashboard, process-manager

## 简介

A web dashboard for braid: live process status/CPU/memory, stop/restart/start buttons, and per-process live log tailing with scroll-back history, served straight off braid's own control server.
