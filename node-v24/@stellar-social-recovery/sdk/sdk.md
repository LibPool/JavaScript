# @stellar-social-recovery/sdk

> 标签: account-recovery, smart-contract, social-recovery, soroban, stellar, wallet-recovery

## 简介

Guardian-approved, time-locked wallet recovery for Stellar. Intent-based TypeScript SDK for the social recovery smart account — works with a raw Keypair or any browser wallet extension.
