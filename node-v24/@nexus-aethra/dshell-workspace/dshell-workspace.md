# @nexus-aethra/dshell-workspace

> 标签: JavaScript

## 简介

dshell workspace removal (design 4.7): same-key stub providers for workspaceRegistry / workspaces / uiWorkspace so the stock web-app workspace rows can be disabled, plus a flat session list for the sidebar.
