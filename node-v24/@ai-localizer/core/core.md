# @ai-localizer/core

> 标签: ai-agent, claude, extract, i18n, internationalization, laravel, localization, next-intl, pipeline, react, translation, vue, vue-i18n

## 简介

Pure-Node i18n pipeline — extract, replace, sync, cleanup, translate-queue — for Vue 3, React/Next, and Laravel projects. Designed for AI agent orchestration with minimal token spend.
