# @ever-works/agentmemory-plugin

> 标签: JavaScript

## 简介

Persistent agent-memory plugin — talks to a local or hosted `agentmemory` server (REST :3111). Default backend for the agent-memory capability shared by Claude Code / Codex / OpenCode / MCP clients.
