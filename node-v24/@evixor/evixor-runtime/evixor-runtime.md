# @evixor/evixor-runtime

> 标签: JavaScript

## 简介

**Evixor Runtime** is a lightweight, embeddable workflow engine for orchestrating multi-step pipelines with retries, parallel execution, subpipelines, and human-in-the-loop interactions.
