# pi-htmldoc

> 标签: artifacts, hosting, html, htmldoc, markdown, pi, pi-extension, pi-package, pi-skill, publish, share, share-link

## 简介

Free artifact publishing for Pi: share any HTML or Markdown file your agent writes as a link anyone can open. One tool call, no deploy, no hosting.
