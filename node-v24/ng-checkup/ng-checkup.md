# ng-checkup

> 标签: angular, audit, cli, health-check, migration, modernization, signals, zoneless

## 简介

A one-minute modernization report for any Angular codebase: version gap, deprecated APIs, zoneless readiness, signals adoption, test runner, type safety and circular dependencies.
