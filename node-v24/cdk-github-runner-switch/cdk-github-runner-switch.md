# cdk-github-runner-switch

> 标签: arm64, aws-cdk, cdk, ci, construct, cost-optimization, ec2-spot, github-actions, github-runner, graviton, self-hosted-runner

## 简介

AWS CDK construct: GitHub Actions runners that switch from GitHub-hosted free minutes to disposable EC2 Spot (Graviton) machines when the monthly minutes run out — and back when the month resets.
