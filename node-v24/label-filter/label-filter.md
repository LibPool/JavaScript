# label-filter

> 标签: case-insensitive, character-set, code-evolve, filter, glob, label, labelfilter, match, pattern, search, wildcard

## 简介

A small glob-like pattern language for filtering lists of objects by their labels. Parsed to an IR, never compiled to a regex.
