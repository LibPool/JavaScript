# @sj-distributor/react-native-iconfont-cli

> 标签: icon, iconfont, iconfont.cn, icons, react-native, react-native-iconfont

## 简介

用纯 JS 把 iconfont.cn 的图标转换成 RN 组件，不依赖字体，支持多色彩，支持热更新
