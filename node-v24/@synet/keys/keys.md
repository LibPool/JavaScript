# @synet/keys

> 标签: cryptography, ed25519, key-generation, keys, secp256k1, security, synet, wireguard, x25519, zero-dependency

## 简介

Zero-dependency, secure key generation library. Supports ed25519, x25519, secp256k1, RSA, and WireGuard keys.
