# @hermis/wallet-standard-base

> 标签: framework-agnostic, solana, standard, wallet

## 简介

The framework agnostic wallet standard implementation. This package is completely framework-agnostic, allowing you to integrate Solana wallets with any UI framework or vanilla JavaScript.
