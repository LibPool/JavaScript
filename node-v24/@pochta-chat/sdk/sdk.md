# @pochta-chat/sdk

> 标签: chat, e2e, ed25519, pochta, sdk, webrtc, x25519

## 简介

Framework-agnostic client SDK for Pochta — self-owned identity, end-to-end sign-then-seal crypto, relay transport, message ops, calls, and media. Ships no storage engine and no UI; you inject those.
