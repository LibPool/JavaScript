# @telic/core

> 标签: abandonment, ai-agents, analytics, breadcrumbs, frontend, funnel, intent, islands, micro-frontends, observability, saga, session-memory, state, typescript, user-intent

## 简介

A recorded intent + memory layer for frontends: record typed user-intent lifecycles (begun → fulfilled/rejected/abandoned) beside any state management, query them as in-page session memory, and optionally mediate cross-domain invocation (handle/dispatch,
