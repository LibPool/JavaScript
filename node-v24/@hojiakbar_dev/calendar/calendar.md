# @hojiakbar_dev/calendar

> 标签: agenda, calendar, day-view, drag-and-drop, event-calendar, month-view, react, scheduler, server-side, week-view

## 简介

Server-driven React calendar: day, week, month, year and agenda views; drag to create, move and resize; range-based loading with optimistic edits.
