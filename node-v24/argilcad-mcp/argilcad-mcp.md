# argilcad-mcp

> 标签: 3d, argilcad, build123d, cad, mcp

## 简介

Connect your own AI assistant (Claude, Cursor, VS Code…) to ArgilCAD over MCP. Requires an ArgilCAD Starter or Pro subscription.
