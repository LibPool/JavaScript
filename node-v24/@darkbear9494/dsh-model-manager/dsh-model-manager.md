# @darkbear9494/dsh-model-manager

> 标签: auto-delegation, cordis, deepseek-harness, dsh, dsh-plugin, model-routing, subagent, update-check

## 简介

Role-based model manager for DeepSeek Harness: assign models to planning, execution, vision and main roles, route subagent work by role, report which model every subagent used, prompt the top-level agent to delegate, and check npm for updates.
