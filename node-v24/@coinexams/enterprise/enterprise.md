# @coinexams/enterprise

> 标签: CoinExams, CoinExams Enterprise, binance api, browser sdk, bsc, ccxt, coin sets, crypto assets management, crypto backtesting, crypto portfolio, crypto portfolio builder, crypto portfolio sdk, cryptocurrency portfolio management, evm payments, hmac api, kucoin api, nodejs, on-chain payments, portfolio automation, portfolio rebalancing, typescript sdk, web3

## 简介

TypeScript SDK for building and automating cryptocurrency portfolios: manage portfolios, connect Binance and KuCoin exchange APIs, backtest coin sets, and process on-chain subscription payments from Node.js and the browser.
