# @bradenream/interfacekit-adapter-voiceflow

> 标签: adapter, interfacekit, voiceflow

## 简介

Reference Voiceflow adapter — the thin-forwarder that wraps Voiceflow general-runtime and normalizes its traces into the InterfaceKit vocabulary. The deepest integration, never a core dependency.
