# @boceto/lint

> 标签: autofix, boceto, lint, linter, markdown, markdown-it, remark, wireframe

## 简介

Linter + auto-fixer for the Boceto DSL. Catches missing label slots, invented element types, fractional coords, slot-nesting traps, and more. Usable from the playground, CI, or an MCP server.
