# @cdk-cloudformation/awscommunity-s3-deletebucketcontents

> 标签: aws-cdk, awscdk, awscommunity, cdk, cfn, cfn-resources, cloudformation, cloudformation-registry, constructs, deletebucketcontents, extensions, l1, s3

## 简介

An experimental extension that deletes all contents of the referenced bucket when the stack is deleted. Use with caution!
