# @tsdoctor/seo

> 标签: documentation, effect, json-ld, open-graph, schema.org, seo

## 简介

Framework-neutral head metadata for static TypeScript API documentation: schema.org JSON-LD, Open Graph and Twitter card vocabulary, canonical URLs, and package attribution derived from an api.json model plus its manifest.
