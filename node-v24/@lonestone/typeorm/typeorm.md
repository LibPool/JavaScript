# @lonestone/typeorm

> 标签: JavaScript

## 简介

A fork of Typeorm. Data-Mapper ORM for TypeScript, ES7, ES6, ES5. Supports MySQL, PostgreSQL, MariaDB, SQLite, MS SQL Server, Oracle, MongoDB databases.
