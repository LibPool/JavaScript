# @qaping/rig

> 标签: frame-time, game-qa, gamepad, playtest, presentmon, qaping, regression, replay, vigem, windows, xinput

## 简介

Record one controller session, replay it against every build: a virtual XInput gamepad, screen capture, PresentMon frame times and a run receipt. Windows.
