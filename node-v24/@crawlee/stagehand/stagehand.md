# @crawlee/stagehand

> 标签: ai, apify, automation, browserbase, crawlee, crawler, playwright, scraper, stagehand

## 简介

AI-powered web crawling with Stagehand integration for Crawlee - enables natural language browser automation with act(), extract(), and observe() methods.
