# @kaze-no-ryuu/argus

> 标签: ai-agent, astro, cli, diff, nextjs, odiff, pixel-diff, playwright, responsive, screenshot, screenshot-comparison, visual-regression, visual-testing, vite

## 简介

Argus: visual diff of your local site against a live site or design images. Auto-detects framework and dev server, desktop/tablet/mobile, pinpoints changed elements, HTML report + JSON for CI and AI agents.
