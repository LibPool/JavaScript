# @logictan/dsh-browser-agent

> 标签: browser-agent, cdp, deepseek-harness, dsh, dsh-plugin, playwright, typesafe

## 简介

DSH browser agent: a dynamic operation+target decision loop. TypeSafe picks the action, this plugin executes it over CDP against the user's own Chrome. DSH 浏览器 Agent 子插件。
