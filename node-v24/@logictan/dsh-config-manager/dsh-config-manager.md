# @logictan/dsh-config-manager

> 标签: backup, config-manager, configuration, cordis, deepseek-harness, dsh, dsh-plugin, export, import, mcp, migrate, migration, plugin, restore, skills, sync, webdav

## 简介

Sync your DeepSeek Harness (DSH) configuration between machines over a private git or WebDAV channel: settings, plugins, MCP servers, skills, agent presets, workspaces and provider credentials. DSH 配置远程同步插件（私有通道，明文自用）。
