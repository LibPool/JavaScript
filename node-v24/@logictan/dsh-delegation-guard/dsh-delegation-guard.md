# @logictan/dsh-delegation-guard

> 标签: deepseek-harness, delegation, dsh, guard, plugin, session, subagent

## 简介

DSH plugin that refuses one-shot subagent delegations and arms a self-waking checkpoint so a seat that dies silently cannot leave the delegating session waiting forever. DSH 派单守护子插件。
