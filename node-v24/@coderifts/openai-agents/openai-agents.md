# @coderifts/openai-agents

> 标签: api-governance, coderifts, guardrail, openai-agents

## 简介

CodeRifts contract governance for the OpenAI Agents SDK — a tool-input guardrail that gates contract mutations before a tool runs, plus REQUEST_APPROVAL mapped to the SDK's native approval surface.
