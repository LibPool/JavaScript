# @coderifts/agent-guard

> 标签: agent, ai-agent, coderifts, fail-closed, governance, guard, preflight, tool-safety

## 简介

Fail-closed guard for AI agent tool calls — preflight contract changes before they execute. Security core frozen (agent-guard-api v1.0); v1.1 adds client-side enforcement: receipt→envelope binding, decision↔action reconciliation, safe_for_agent + degraded
