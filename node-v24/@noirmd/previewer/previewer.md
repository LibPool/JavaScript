# @noirmd/previewer

> 标签: admonitions, cards, directives, editor, markdown, preview, react, renderer, tailwind, vue

## 简介

Framework-agnostic markdown renderer: one vanilla DOM engine with thin React/Vue wrappers, directives, cards, modals, and pure CSS styling
