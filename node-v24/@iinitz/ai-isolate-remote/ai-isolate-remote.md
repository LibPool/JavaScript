# @iinitz/ai-isolate-remote

> 标签: ai, ai-sdk, code-execution, code-mode, isolate, isolated-vm, remote, sandbox, tanstack, typescript

## 简介

Remote isolate driver for TanStack AI Code Mode — runs LLM-generated code in an isolated-vm sandbox on a remote executor server.
