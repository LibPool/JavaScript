# @rex0220/print-craft-authoring-tools

> 标签: JavaScript

## 简介

rex0220 印刷屋プラグイン（kintone）の設定 JSON を AI で作る・確かめるための tools（fields / record / pull / normalize / preview / diff / buttons / version）。共通の中核（@rex0220/print-craft-authoring-tools/core。print-craft MCP が使う）も含む。計算式エンジンと印刷屋のコードは利用者の印刷屋プラグインの zip から読む
