# familyancestry

> 标签: ancestry, cli, family tree, gedcom, genealogy, mcp, moshpit, pwa, tui

## 简介

family.ancestry: private family trees for your family. GEDCOM import/export, pedigree and descendant charts, photos, sources, invites, plus a private family-and-friends network with an inbox. Web app (PWA), API, CLI, TUI, MCP server and desktop app.
