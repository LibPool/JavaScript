# @renge-ui/tailwind

> 标签: css-variables, design-system, golden-ratio, preset, tailwind, tailwindcss

## 简介

Tailwind CSS preset and plugin for the Renge design system — maps --renge-* CSS custom properties to utility classes with Tailwind v4 plugin support.
