# @anointedautomation/sso-react-native

> 标签: anointed-automation, expo, oidc, react-native, sign-in, sso

## 简介

Sign in with Anointed Automation for React Native and Expo: an accessible brand-styled sign-in button and a useAnointedSignIn hook that open your server's start route in a system auth session and read the deep-link callback. No secrets in the app.
