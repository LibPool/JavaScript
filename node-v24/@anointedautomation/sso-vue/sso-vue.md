# @anointedautomation/sso-vue

> 标签: anointed-automation, nuxt, oidc, sign-in, sso, vite, vue

## 简介

Sign in with Anointed Automation for Vue 3: an accessible brand-styled sign-in button and a useAnointedSignIn composable that send the browser to your server's start route. No secrets client side.
