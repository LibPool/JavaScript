# @ashbuk/spark-slider

> 标签: a11y, accessible, animation, aria, autoplay, carousel, drag, framer-motion, framework-agnostic, gatsby, image-carousel, image-slider, keyboard-navigation, lazy-loading, lightweight, mobile, nextjs, npm-package, performance, react, react-carousel, react-component, remix, responsive, slider, swipe, touch, typescript, vite, web-application

## 简介

Lightweight, fast, and accessible React carousel slider component powered by Framer Motion. Framework-agnostic with full TypeScript support, drag gestures, keyboard navigation, and auto-play. Works with Next.js, Vite, Remix, and any React framework.
