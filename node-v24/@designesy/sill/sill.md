# @designesy/sill

> 标签: a11y, accessibility, css, design-system, lighting, physically-based, pointer, shadows, signed-distance-field, ui, webgl, webgl2

## 简介

Real-time light for interfaces: the pointer is the light, and cards, controls and type cast physically projected shadows, catch highlights and edge light. Zero dependencies, accessible by construction.
