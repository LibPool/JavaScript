# @execuro-sw-ecosystem/sw-tender-discovery-tool

> 标签: cli, rfp, shopware, tender, xlsx

## 简介

Tender Discovery Tool - local zero-dependency runtime that renders a tender analysis sidecar (specs/rfp-NNNN-slug-analysis.md) as a live page, writes ticks / answers / proposed assumptions back into it and relays batches to the running sw-discover-tender
