# @miinded/nuxt-oauth

> 标签: auth, discord, google, jwt, nuxt, nuxt-auth-utils, nuxt-module, oauth, session

## 简介

Nuxt module for JWT sessions against the Miinded backend: token renewal, authenticated API composables, logout and Google/Discord OAuth.
