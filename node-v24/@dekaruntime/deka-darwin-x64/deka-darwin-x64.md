# @dekaruntime/deka-darwin-x64

> 标签: JavaScript

## 简介

deka prebuilt binary for darwin-x64. Ships both the deka and dsc binaries as siblings (deka's runtime dsc lookup is sibling-only). Downloaded from the deka release by CI and never built in this repo.

- 源码仓库：git+https://github.com/dekaruntime/create-deka-app.git
