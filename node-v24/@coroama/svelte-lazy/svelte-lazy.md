# @coroama/svelte-lazy

> 标签: async-component, await, chunk, code-split, code-splitting, component-loader, defer, dynamic-import, lazy, lazy-component, lazy-load, lazy-loading, prefetch, reactive, runes, suspense, svelte, svelte5, sveltekit, typescript

## 简介

Lazy-loaded component slots for Svelte 5. Wraps dynamic import() in a reactive cell with prefetch, retry, and a {#await}-friendly wrapper component.
