# @xmesh/chat

> 标签: chat, custom-element, streaming, vue, web-component, xmesh

## 简介

XMesh chat shell for Vue 3, and the <xmesh-chat> web component for any host framework. Speaks the @xmesh/chat-protocol through @xmesh/sdk.
