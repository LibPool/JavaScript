# llm-gpu-memory

> 标签: calculator, cli, gpu, inference, kv-cache, llm, vllm, vram

## 简介

How much GPU memory an open LLM needs to serve: weights and KV cache, how many of each GPU hold it, and the most tokens a second their memory allows.
