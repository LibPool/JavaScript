# cortico-world-cortidrive

> 标签: cortico, cortico-world

## 简介

Cortico World for Teach my little sister how to drive, with the bot in the driver seat: a BepInEx plugin replaces the sister model with the bot's drive tool and turns game calls into events. 此乃直播测试验证之后的world，和其他 Persona / 非直播场景的兼容性有待测试。
