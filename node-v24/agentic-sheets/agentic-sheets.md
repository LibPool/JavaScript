# agentic-sheets

> 标签: Google Sheets, Node.js, TypeScript, Zod, cli, dry-run, google-sheets-api, in-memory, json, mcp, oauth, rows, spreadsheet

## 简介

Google Sheets values API wrapper for JSON rows with a TypeScript SDK, CLI, MCP server, dry-run previews, and an in-memory adapter.
