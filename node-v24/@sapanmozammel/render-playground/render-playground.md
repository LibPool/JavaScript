# @sapanmozammel/render-playground

> 标签: debug, devtools, diagnostics, hooks, memoization, performance, playground, re-render, react, visual

## 简介

Visual render observatory — wraps any React component with a real-time diagnostics panel showing health score, render timeline, prop changes, memo effectiveness, and recommendations
