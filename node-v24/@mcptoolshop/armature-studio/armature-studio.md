# @mcptoolshop/armature-studio

> 标签: animation, blender, character, comfyui, controlnet, glb, previz, sprite, turnaround, video-diffusion

## 简介

You block the shot; the model shoots it — GLB-authored previz, control sequences and gates for video-diffusion generation. Node launcher for the armature-studio Python toolkit.
