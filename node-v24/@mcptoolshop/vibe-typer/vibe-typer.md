# @mcptoolshop/vibe-typer

> 标签: agent, arcade, coding, game, mcp, model-context-protocol, ollama, typing, typing-game

## 简介

A typing arcade game where you are a coding agent. Your user has an idea, you type the code, and the thing gets built while you both watch.
