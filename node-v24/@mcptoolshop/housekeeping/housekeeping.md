# @mcptoolshop/housekeeping

> 标签: audit, ci, cli, github, github-actions, mcp, organization, sqlite

## 简介

Operational-health warehouse for a GitHub organization: CI, issues, PRs, releases, Actions cost and repo hygiene, collected into SQLite and audited against written rules.
