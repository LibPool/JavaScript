# dsh-plugin-deep-scan

> 标签: competitive-analysis, cordis, deepseek-harness, discovery, dsh, dsh-plugin, github, niche, plugin, search

## 简介

dsh plugin: iterative GitHub deep search — multi-query × 4-channel search (phrase / loose / README full-text / topic sweep), mine new query terms from hit topics, iterate rounds with a diminishing-returns stop rule, and rank by channel precision + stars.
