# @timonics/auth-guard

> 标签: auth, guard, jwks, jwt, nestjs, oauth2, resource-server, timonics

## 简介

NestJS resource-server auth for timonics services: JWKS JWT verification, global auth/scope guards, and a matching exception filter. Verifies RS256 access tokens issued by cerberus.
