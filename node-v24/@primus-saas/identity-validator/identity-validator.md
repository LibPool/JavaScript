# @primus-saas/identity-validator

> 标签: authentication, azure-ad, express, identity, jwt, multi-tenant, nestjs, oidc, validator

## 简介

Multi-issuer JWT/OIDC token validator for Node.js. Supports Azure AD, custom JWT issuers, and any OIDC-compliant identity provider. Works with Express and NestJS.
