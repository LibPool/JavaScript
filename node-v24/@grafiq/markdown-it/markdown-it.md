# @grafiq/markdown-it

> 标签: dsl, grafiq, hydrate, markdown-it, markdown-it-plugin, mockup, wireframe

## 简介

markdown-it plugin that renders Grafiq mockups from fenced code blocks, with client-side hydration and a built-in lightbox.
