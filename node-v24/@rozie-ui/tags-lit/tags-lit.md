# @rozie-ui/tags-lit

> 标签: accessibility, aria, chips, component, headless, lit, multiselect, rozie, rozie-ui, tag-input, tags, token-input

## 简介

Idiomatic Lit headless WAI-ARIA tags / token input (chips with removable controls, type-to-add with configurable delimiters, paste-to-bulk-add, dedup, validation, max cap) — one accessible Rozie source compiled to a Lit custom element.
