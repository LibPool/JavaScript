# @rozie-ui/data-table-vue

> 标签: JavaScript

## 简介

Idiomatic Vue headless WAI-ARIA data table (sorting, filtering, pagination, selection, column visibility/resize/reorder/pinning) on @tanstack/table-core — one accessible Rozie source compiled to Vue.
