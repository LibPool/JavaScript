# @rozie-ui/toast-vue

> 标签: accessibility, aria, component, headless, notification, rozie, rozie-ui, snackbar, toast, toaster, vue

## 简介

Idiomatic Vue headless, accessible toast / notification host (queue, auto-dismiss, hover-pause, positioning, imperative show/dismiss/clear handle) — one accessible Rozie source compiled to Vue.
