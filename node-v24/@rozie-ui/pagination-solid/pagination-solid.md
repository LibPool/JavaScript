# @rozie-ui/pagination-solid

> 标签: accessibility, aria, component, headless, nav, page-navigation, pager, pagination, rozie, rozie-ui, solid

## 简介

Idiomatic Solid headless WAI-ARIA pagination control (page-item model with ellipses, sibling/boundary windowing, prev/next, roving keyboard nav) — one accessible Rozie source compiled to Solid.
