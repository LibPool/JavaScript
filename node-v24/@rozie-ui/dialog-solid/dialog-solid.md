# @rozie-ui/dialog-solid

> 标签: accessibility, aria, component, dialog, headless, modal, overlay, popup, rozie, rozie-ui, solid

## 简介

Idiomatic Solid headless WAI-ARIA modal dialog on the native <dialog> element (top-layer, ::backdrop scrim, focus trap, Esc-to-dismiss, scroll-lock) — one accessible Rozie source compiled to Solid.
