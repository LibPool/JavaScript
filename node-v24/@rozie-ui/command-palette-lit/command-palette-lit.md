# @rozie-ui/command-palette-lit

> 标签: accessibility, aria, cmdk, command-k, command-menu, command-palette, component, headless, lit, palette, rozie, rozie-ui, spotlight

## 简介

Idiomatic Lit headless WAI-ARIA cmdk-style command palette (portal overlay, search filter, keyboard navigation) — one accessible Rozie source compiled to a Lit custom element.
