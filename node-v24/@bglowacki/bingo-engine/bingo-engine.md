# @bglowacki/bingo-engine

> 标签: appel-jacobson, board-generator, engine, english, isomorphic, literaki, polish, scrabble, solver, typescript, validator

## 简介

Isomorphic, dictionary-injected, multi-language Scrabble engine: validator, scorer, solver, board generator. Zero runtime deps, ESM+CJS, TypeScript.
