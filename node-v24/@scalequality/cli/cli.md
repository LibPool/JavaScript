# @scalequality/cli

> 标签: ai-workspace, cli, code-quality, coding-agent, scalequality

## 简介

ScaleQuality CLI. Connect your computer to the ScaleQuality AI Workspace (`scalequality login`), run its coding engine in any folder of your computer, and import your Claude Code and Codex conversations.
