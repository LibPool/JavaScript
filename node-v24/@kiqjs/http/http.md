# @kiqjs/http

> 标签: api, controller, decorator, http, koa, rest, rest-api, spring-boot, typescript

## 简介

HTTP integration for kiqjs. Provides @RestController and route decorators (@GetMapping, @PostMapping, @PutMapping, @DeleteMapping) to map controllers and methods into HTTP endpoints automatically. Spring Boot-inspired decorators for Node.js/TypeScript.
