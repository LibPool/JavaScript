# @quadmanswe/plugin-azure-devops-backend

> 标签: JavaScript

## 简介

Simple plugin that proxies requests to the [Azure DevOps](https://docs.microsoft.com/en-us/rest/api/azure/devops/?view=azure-devops-rest-6.1) API.
