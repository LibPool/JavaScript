# @zhushanwen/z-subagent-workflow

> 标签: background-agents, headless, orchestration, subagent, workflow, zcode

## 简介

Subagent orchestration + deterministic multi-phase workflows for zcode via the zsw CLI (pure local one-shot processes since 2.0.0 — no resident daemon): subagent lifecycle with worktree isolation, schema outputs, model routing, core-unified agent .md disc
