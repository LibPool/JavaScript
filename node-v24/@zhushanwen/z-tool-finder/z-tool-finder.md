# @zhushanwen/z-tool-finder

> 标签: lazy-loading, mcp, progressive-disclosure, proxy, tool-search, zcode

## 简介

Progressive loading for MCP tools in zcode: per-server proxy wrappers (get_tool_details/call_tool), SessionStart auto-takeover + available-custom-tools manifest injection, global tool search. Reversible via tf restore.
