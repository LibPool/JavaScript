# @zhushanwen/pi-llm-shared

> 标签: config, llm, model-resolution, pi, pi-package, shared

## 简介

Shared LLM invocation library for Pi extensions — model resolution (ref exact only), LLM calling (completeSimple), and config read/write with mtime+size caching. Shared library, not a Pi extension.
