# @durabl/cli

> 标签: JavaScript

## 简介

Auth and download for Durabl. The public command is `npx -y @durabl/install`, which installs this package into a temporary directory on every run.

## 官网

- npm 页面：https://www.npmjs.com/package/@durabl/cli
