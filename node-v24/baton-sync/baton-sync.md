# baton-sync

> 标签: baton, claude-code, codex, cursor, gemini-cli, handoff, mcp

## 简介

Connect this laptop to Baton: wires the baton MCP server into Claude Code, Codex, Cursor and Gemini CLI, and runs the Claude Code hooks.
