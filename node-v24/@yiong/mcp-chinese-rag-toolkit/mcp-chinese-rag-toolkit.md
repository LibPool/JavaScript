# @yiong/mcp-chinese-rag-toolkit

> 标签: chinese, factory, mcp, model-context-protocol, rag, toolkit

## 简介

Reusable MCP server + Chinese RAG pipeline toolkit (factory + Tool builder + error envelope + eval framework) for building internal and third-party MCP servers in TypeScript.
