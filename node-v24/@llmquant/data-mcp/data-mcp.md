# @llmquant/data-mcp

> 标签: JavaScript

## 简介

LLMQuant Data MCP server — financial data for AI agents: wiki & research papers, crypto & equity prices, ETF, macro indicators, SEC filings (10-K/10-Q/8-K) & 13F holdings, prediction markets, company news, and personal portfolio context.
