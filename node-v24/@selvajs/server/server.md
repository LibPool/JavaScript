# @selvajs/server

> 标签: grasshopper, rate-limiting, rhino-compute, selva, ssrf

## 简介

Transport-agnostic server building blocks for apps built on the Selva engine (limits, rate limiting, SSRF guard, remote-definition fetch, definition service + render loader); the solve core lives in @selvajs/solve/server

- 源码仓库：git+https://github.com/VektorNode/selva.git
