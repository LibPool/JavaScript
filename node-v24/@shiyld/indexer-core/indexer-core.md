# @shiyld/indexer-core

> 标签: JavaScript

## 简介

Shared indexer logic for the Shiyld privacy protocol — multi-network event ingestion, Merkle proof serving, and a versioned read API. Used by apps/indexer and embeddable directly into a third-party service.
