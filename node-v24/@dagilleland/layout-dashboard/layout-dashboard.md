# @dagilleland/layout-dashboard

> 标签: astro, astro-component, dashboard, layout, starlight, starlight-layouts, widgets

## 简介

Full-width Starlight layout for a widget grid, plus reusable DashboardGrid/Widget stat-tile components usable in any Starlight page. One of four layout packages from Starlight Layouts.
