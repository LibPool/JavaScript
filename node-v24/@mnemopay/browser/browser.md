# @mnemopay/browser

> 标签: JavaScript

## 简介

Thin trust + state layer for agent browser sessions. Wraps Browserbase / Stagehand / Playwright; binds every session to a MnemoPay DID, FiscalGate budget, Article 12 audit chain, and per-session billing meter.
