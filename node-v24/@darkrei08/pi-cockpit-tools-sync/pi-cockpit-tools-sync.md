# @darkrei08/pi-cockpit-tools-sync

> 标签: ai-proxy, antigravity, cockpit-tools, multi-account, pi, pi-agent, pi-extension, rotator

## 简介

Pi extension that reads desktop cockpit-tools accounts/quotas, syncs Pi auth, and provisions a multi-account rotator (commands: /cockpit-sync, /cockpit-provision, /cockpit-proxy).
