# @asylia/hw-ledger

> 标签: @ledgerhq/ledger-bitcoin, asylia, bip48, bitcoin, ble, hardware-wallet, ledger, multisig, p2wsh, psbt, psbt-signing, self-custody, typescript, wallet-policy, web-bluetooth, webhid, xpub

## 简介

Auditable Ledger hardware-wallet TypeScript adapter for WebHID/Web Bluetooth environment checks, xpub export, wallet-policy registration, address display, and P2WSH multisig PSBT signing.
