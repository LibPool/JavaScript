> 标签: date-picker, haptic, infinite-scroll, ios-picker, momentum-scroll, react, scroll-picker, time-picker, typescript, wheel-picker

## 简介

An iOS-style 3D infinite-scroll wheel picker for React with momentum physics, snap looseness control, haptic vibration feedback, and full TypeScript support.
