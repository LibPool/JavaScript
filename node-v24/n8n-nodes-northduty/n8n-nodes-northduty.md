# n8n-nodes-northduty

> 标签: alerts, monitoring, n8n-community-node-package, northduty, ssl, synthetic-monitoring, uptime, user-journey, woocommerce, wordpress

## 简介

n8n community node for NorthDuty: user journey monitoring (checkout, signup, login, forms) plus uptime, SSL, domain and site health checks, with alerts the moment something breaks
