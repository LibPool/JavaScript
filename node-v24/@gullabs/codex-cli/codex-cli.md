# @gullabs/codex-cli

> 标签: cli, codex, dev-only, llm, openai, testing, typescript

## 简介

Dev-only OpenAI Codex CLI provider adapter for any-llm — routes calls through a locally-authenticated `codex` CLI session for $0 API spend during workflow iteration. NOT for production use.
