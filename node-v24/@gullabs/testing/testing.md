# @gullabs/testing

> 标签: ai, cost, gemini, google-genai, llm, observability, tokens, typescript, usage

## 简介

Test fakes for any-llm: FakeClock (clock and scheduler), FakeClient, FakeAdapter, error factories, recording sink, telemetry and logger, fake Gemini and xAI SDK clients, fake stores and CLI runner. No network in tests.
