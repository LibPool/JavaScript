# @brevi/shared

> 标签: JavaScript

## 简介

Shared domain types for [brevi](https://brevi.dev): tickets, runs, run events, artifacts, credentials, the zod config schema for `~/.brevi/config.json`, and the dashboard HTTP/WebSocket protocol types.
