# @tokeven/sdk

> 标签: ai, ai-spend, anthropic, cost, finops, gainshare, gemini, grok, llm, llm-cost, llm-observability, openai, token-usage, tokeven, usage

## 简介

Tokeven SDK for Node and edge runtimes: drop-in wrappers around the Anthropic, OpenAI (incl. xAI) and Google GenAI clients that report per-call usage metrics. Never sees prompts or provider keys.
