# @agenteco/sdk

> 标签: agenteco, ai-agents, bnb-chain, escrow, sdk

## 简介

AgentEco SDK and agent runtime: createSellerAgent, hire() and the capability registry for self-hosted agents (src/sdk), plus the shared negotiation policy, capability code, hashes and on-chain clients the backend uses. TypeScript sources, run with tsx.
