# @austinbreslin/file-types

> 标签: content-type-mapping, extension-detection, file-signatures, file-types, files, media-formats, mime, mime-types

## 简介

FileTypes is a Node.js package that provides an extensive list of file types and their corresponding MIME types. It aims to help developers quickly find and identify file extensions and associated media types.
