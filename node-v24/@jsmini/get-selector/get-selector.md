# @jsmini/get-selector

> 标签: JavaScript

## 简介

获取 DOM 元素的 CSS 选择器，类似 Chrome 浏览器的 copy selector 功能，但支持获取更短的 CSS 选择器

- 源码仓库：git://github.com/jsmini/get-selector.git
