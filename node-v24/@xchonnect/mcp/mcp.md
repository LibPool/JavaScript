# @xchonnect/mcp

> 标签: agent, chia, claude, mcp, wallet, xchonnect

## 简介

Xchonnect MCP plugin: lets an AI agent (Claude Code first) pair with your Chia wallet and ask it to trade. Keys and rules stay in the wallet.
