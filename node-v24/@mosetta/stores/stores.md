# @mosetta/stores

> 标签: JavaScript

## 简介

mosetta stores: store kinds, the operation contract, web/s3/capability connectors and StoreConnectors, which picks a store connector by store + required operations; tile hosts. Web-API clean, zero deps — usable from the browser, factory lines and node.
