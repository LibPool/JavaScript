# @aphrody/eslint-plugin-m3

> 标签: eslint, eslintplugin, lint, m3, material-design, material-web, oxlint

## 简介

Lint rules for sites consuming material-web (@aphrody/m3-react + Material Symbols) — runs under the native bun lint (jsPlugins).
