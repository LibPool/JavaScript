# @openhermit/channel-signal

> 标签: channel, chatbot, openhermit, signal, signal-cli

## 简介

OpenHermit channel plugin for Signal via signal-cli-rest-api (json-rpc receive WS + QR-link setup wizard) with text, media, and voice transcription.
