# @ericdisero/aurora-shared

> 标签: ai-music, aurora, claude, mcp, model-context-protocol, music-generation, mvsep, stem-separation, suno

## 简介

Shared operations layer for the Aurora MCP server and CLI: storage, Suno/MVSEP provider clients, background jobs, and the single tool surface both consume. Most users want @ericdisero/aurora-mcp-server or @ericdisero/aurora-cli instead.
