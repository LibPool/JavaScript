# @streamline-pulse/creeba-ws

> 标签: creeba, p2p, transport, websocket

## 简介

Creeba WebSocket transport: client transport + server bridge so a well-known node (e.g. a cloud peer) is reachable over plain WebSocket — same frames, certs and convergence as any other transport. Identity is proven by an ed25519 challenge handshake; cryp
