# @iyulab/u-scene

> 标签: diagram, engineering, lit, scene, svg, visualization, web-components

## 简介

Declarative engineering scenes for the web: parametric diagrams from plain data, rendered to static SVG or a <u-scene> element, with handles that set an input from the drawing.
