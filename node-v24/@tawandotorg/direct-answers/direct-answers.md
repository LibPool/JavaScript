# @tawandotorg/direct-answers

> 标签: adr, answer-quality, claude, claude-code, code-review, plugin, prompt

## 简介

Claude Code plugin for verdict-first answers: position before reasoning, labeled facts vs assumptions, and an audit trail for assumptions inherited from project context.
