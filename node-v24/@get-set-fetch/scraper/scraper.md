# @get-set-fetch/scraper

> 标签: cloud, node, nodejs, scraper, scraping, web

## 简介

Plugin based node.js web scraper. It scrapes, stores and exports data. Supports multiple storage options: SQLite, MySQL, PostgreSQL. Supports multiple browser or dom-like clients: Puppeteer, Playwright, Cheerio, Jsdom.
