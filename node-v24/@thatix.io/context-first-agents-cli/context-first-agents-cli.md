# @thatix.io/context-first-agents-cli

> 标签: ai-agents, ai-assisted, cli, context-first, dynamic-agents, ephemeral-agents, methodology, orchestrator, spec-driven, worktree

## 简介

Evolution of context-first-cli: manage the Context-First methodology across any project AND orchestrate dynamic, ephemeral AI agents from specs. All agent orchestration lives in .md command templates; the Node layer only scaffolds and manages.
