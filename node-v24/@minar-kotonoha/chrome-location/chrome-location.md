# @minar-kotonoha/chrome-location

> 标签: JavaScript

## 简介

本npm包主要解决了其他包在取process.env.PROGRAMFILES时，没有同时取process.env.ProgramFiles的问题，因为在进程中，process.env.xxx是不区分大小写的，但是在线程中会区分，所以需要多取一次。并且添加了通过chrome命令行取位置的逻辑。
