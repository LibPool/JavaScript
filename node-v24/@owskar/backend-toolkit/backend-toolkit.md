# @owskar/backend-toolkit

> 标签: backend, bcrypt, express, jwt, logger, pagination, response, toolkit, utils, validation

## 简介

A collection of small, dependency-light utilities for Node.js backend developers: response helpers, async error handling, JWT, password hashing, dates, pagination, validation, logging and env loading.
