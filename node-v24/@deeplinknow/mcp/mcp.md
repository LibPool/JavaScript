> 标签: app-links, apple-app-site-association, assetlinks, deep linking, deferred deep linking, expo, firebase-dynamic-links, flutter, mcp, mcp-server, model-context-protocol, react-native, universal-links

## 简介

DeepLinkNow MCP server: lets coding agents (Claude Code, Cursor, Windsurf, VS Code) set up deferred deep linking, check Universal Link and App Link domains, and manage DeepLinkNow links.
