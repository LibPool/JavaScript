# threejam

> 标签: 2d-game-engine, agent-skills, ai-agents, cli, deterministic, game-engine, game-testing, mcp, threejs, typescript, vibe-coding, webgl

## 简介

A 2D game engine on Three.js where coding agents prove what their games do: exact, repeatable runs, state from sim, frames from shot, as a CLI and MCP tools
