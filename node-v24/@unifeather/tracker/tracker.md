# @unifeather/tracker

> 标签: analytics, browser, lightweight, privacy, tracker, tracking, web-analytics

## 简介

Tiny (~1KB) privacy-friendly client-side tracker. Minimal by default; cookie id, session id and custom properties are opt-in.
