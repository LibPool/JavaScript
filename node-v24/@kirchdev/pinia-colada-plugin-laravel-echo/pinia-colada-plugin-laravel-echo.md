# @kirchdev/pinia-colada-plugin-laravel-echo

> 标签: echo, kirchdev, laravel, pinia-colada, pinia-colada-plugin, realtime, reverb, vue, websockets

## 简介

Pinia Colada plugin that keeps a query's cache current from Laravel Echo events — and invalidates it when the websocket drops and comes back.
