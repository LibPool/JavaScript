# @pgmi-builds/omp-webui

> 标签: JavaScript

## 简介

OMP provider for DeepSeek Harness (dsh): registers an AgentFactory on ctx.agents that spawns `omp --mode rpc` and bridges OMP's RPC stream into Dash Agent/Session contracts.
