# @morehao/dsh-skills-console

> 标签: deepseek-harness, dsh, dsh-plugin, skills

## 简介

DSH 技能控制台：技能真身只由 skills CLI 写，本插件只管可见性、接入与生命周期——装 / 更新 / 删除 / 启停、四态软链、回收站、订阅。
