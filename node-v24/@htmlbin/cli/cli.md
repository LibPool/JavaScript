# @htmlbin/cli

> 标签: agent, cli, cloudflare-pages, github-pages, html, htmlbin, pastebin

## 简介

CLI for htmlbin. Publish HTML, get a URL. Cloud by default, pluggable backends for org-internal hosting (GitHub Pages, Cloudflare Pages + Access).
