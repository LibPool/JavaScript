# @ratel-ai/cloud-sdk

> 标签: ai-agents, context-engineering, llm, opentelemetry, otlp, ratel, skill-catalog, skills, telemetry

## 简介

Management & supervised self-improvement client for Ratel Cloud — catalog writes, intent analysis, and skill-suggestion review over the cloud API, plus the OpenTelemetry destination on /otel. Dependency-free at the root; pure HTTP, no native addon.
