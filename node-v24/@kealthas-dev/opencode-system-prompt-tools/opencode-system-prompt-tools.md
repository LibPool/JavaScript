# @kealthas-dev/opencode-system-prompt-tools

> 标签: JavaScript

## 简介

system-prompt-tools.ts opencode plugin (dumps the fully-assembled system prompt actually sent to the model, on every request, to ~/.local/share/opencode/last-system-prompt.txt), published to npm so opencode's own npm-plugin loader can install it directly
