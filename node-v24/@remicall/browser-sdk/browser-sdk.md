# @remicall/browser-sdk

> 标签: agents, browser, realtime, remicall, sdk, voice, webrtc

## 简介

Drop-in browser SDK for Remicall realtime voice agents — one call hides the entire WebRTC handshake (ICE, SDP, data channel)
