# @nitro-mlkit/document-scanner

> 标签: document-scanner, expo, machine-learning, mlkit, nitro, on-device, pdf, react-native, scanner

## 简介

On-device document scanner for React Native — Google ML Kit + Nitro. Launch ML Kit's full-screen scanner (edge detection, perspective correction, multi-page) and get JPEG/PDF pages back.
