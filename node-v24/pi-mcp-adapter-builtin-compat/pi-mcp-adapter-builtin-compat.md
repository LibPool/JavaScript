# pi-mcp-adapter-builtin-compat

> 标签: compat, mcp, pi, pi-mcp-adapter, pi-package

## 简介

Stops pi-mcp-adapter from printing a false "no longer reads mcp.json" migration warning on Pi 0.99+ (builtin:mcp vs <inline:mcp>).
