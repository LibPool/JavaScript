## 简介

Static Quebec Bill 96 / OQLF French-language web compliance scanner. Detects sites that serve Quebec but offer no adequate French version: missing hreflang fr-CA, no French toggle, English-only content and locale. MCP server + CLI for Cursor and Claude De
