# @tapizlabs/telemetry

> 标签: error-monitoring, error-tracking, sdk, tapiz, telemetry

## 简介

Framework-agnostic error & event capture SDK for Tapiz products. Captures uncaught errors, batches and ships them to a Tapiz ingest endpoint.
