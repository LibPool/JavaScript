# @cynthiaweb/cynthiaweb-mini

> 标签: JavaScript

## 简介

A lightweight website engine emphasising simplicity and ease of use. Optimised for small to medium-sized websites requiring both static and dynamic capabilities. Create entire sites out of just a few djot/markdown/html/plaintext files and their json metad
