# @carbon/agentic-renderer

> 标签: a2ui, carbon, carbon-design-system, charts, genui, ibm, renderer, web-components

## 简介

Catalog-driven renderer for the Carbon Design System. Renders A2UI SurfaceModel and GenUI RendererView instances into the DOM using cds-* web components and @carbon/charts.
