# @crawlconsole/mcp

> 标签: Backlink Data for AI, Common Crawl MCP, claude, codex, crawlconsole, mcp

## 简介

CrawlConsole gives AI agents backlink intelligence through MCP: deep backlink analysis for any domain, Domain Authority, Harmonic Centrality scores, link gaps, and page-level and anchor-level backlinks.
