# @bezier-sdf/core

> 标签: bezier, gpu, logo, sdf, shader, signed-distance-field, svg, vector-graphics, webgl, webgpu

## 简介

Framework-agnostic GPU signed-distance-field rendering of cubic Bezier curves. WebGPU + WebGL renderers, Canvas 2D helpers, and geometry utilities.
