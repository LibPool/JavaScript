# @mergesafe-io/connect

> 标签: installer, mcp, mergesafe, model-context-protocol

## 简介

One command connects every AI client on your machine to MergeSafe MCP — Claude Code, Claude Desktop, Cursor, Windsurf, VS Code and more, globally.
