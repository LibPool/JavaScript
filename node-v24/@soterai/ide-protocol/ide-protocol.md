# @soterai/ide-protocol

> 标签: cross-ide, ide-guard, local-first, protocol, soterai

## 简介

Shared cross-IDE contract for SoterAI IDE Guard: command names, feature flags, Local AI Broker HTTP contract, and event/policy schemas. No detector logic.
