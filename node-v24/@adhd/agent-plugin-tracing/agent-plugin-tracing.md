# @adhd/agent-plugin-tracing

> 标签: agent, observability, plugin, telemetry, tracing, typescript

## 简介

Tracing plugin for @adhd/agent-mcp — emits durable spans and derived metrics for every agent operation (session, task, model call, tool call, permission decision, HITL suspend/resume) into @adhd/sox-telemetry
