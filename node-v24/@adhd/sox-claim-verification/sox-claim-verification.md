# @adhd/sox-claim-verification

> 标签: claims, embedding, nli, typescript, verification

## 简介

NLI-based (Natural Language Inference) claim grounding engine. Cross-encoder NLI via worker thread, embedding pre-filter, configurable truncation strategy, LRU result cache. Worker-thread isolated from better-sqlite3 (BL-11).
