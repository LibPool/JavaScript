# @adhd/sox-graph-store

> 标签: bi-temporal, database, graph, sqlite, store, typescript

## 简介

Bi-temporal graph store — nodes + edges over SQLite with t_valid/t_invalid correctness, tExpires TTL, content-hash dedup, FTS5 sync, namespace isolation, and supersession chains. Schema migration via Drizzle ORM (ADR-0008). GraphBackendCapabilities flags
