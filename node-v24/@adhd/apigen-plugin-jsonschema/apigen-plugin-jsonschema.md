# @adhd/apigen-plugin-jsonschema

> 标签: JavaScript

## 简介

apigen target plugin (`--type jsonschema`) — emits the **JSON Schema** for each export's input/output to disk. A **generate-only** plugin (no `run` mode); useful for validation, docs, client generation, or as the IR other tools consume.
