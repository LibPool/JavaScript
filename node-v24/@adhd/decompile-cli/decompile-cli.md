# @adhd/decompile-cli

> 标签: JavaScript

## 简介

Reverse is a tool for reverse engineering code bundled with source maps. Reverse accepts **(remote) urls:** html, js, css, map, json **(local) files:** html, js, ts, jsx..., css, etc
