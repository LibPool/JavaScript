# @adhd/sox-service-proxy

> 标签: mcp, proxy, stdio, typescript, uds

## 简介

Front-shim service-proxy (spec §9.5, Slice 1.5): stdio↔UDS MCP proxy enabling zero-downtime backend upgrades without client reconnects. Dependency-free leaf (node builtins only).
