# @richkitjs/editors

> 标签: controlled-component, form, notion-like, react, react-component, rich-text-editor, richkit, wysiwyg

## 简介

Ready-made React editors for RichKit — minimal, simple, HTML, Markdown, mentions, comment box and find & replace — each a form input with value/onChange.
