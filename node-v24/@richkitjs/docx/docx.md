# @richkitjs/docx

> 标签: document-conversion, docx, editor, microsoft-word, office, prosemirror, rich-text, rich-text-editor, richkit, text-editor, word, word-export, word-import, wysiwyg

## 简介

Microsoft Word (.docx) import and export for RichKit, entirely in the browser: headings, lists, tables, links and formatting, with no conversion server.
