# @qrcodesdk/cli

> 标签: cli, code, esm, modules, png, qr, qr-code, qrcode, svg, terminal, typescript

## 简介

@qrcodesdk/cli provides the qrc command for generating QR codes as terminal text, SVG files, or PNG files.
