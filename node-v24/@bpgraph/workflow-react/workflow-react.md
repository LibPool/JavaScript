# @bpgraph/workflow-react

> 标签: automation, editor, flow, graph, node-based, orchestration, pipeline, react, ui, visual-programming, workflow

## 简介

**@bpgraph/workflow-react** is a lightweight React wrapper built on top of **@bpgraph/workflow-core**.   It provides convenient components and context utilities to simplify graph rendering and management within React applications.
