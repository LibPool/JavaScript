# claude-cost-for-claude-code

> 标签: anthropic, claude, claude-code, cli, cost-tracking, dashboard, html, jira, token-usage

## 简介

Build a self-contained HTML dashboard of Claude Code token usage, cost, and efficiency - by ticket, by model, and by day/week - from your local session logs. Zero dependencies.
