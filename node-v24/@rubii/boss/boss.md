# @rubii/boss

> 标签: JavaScript

## 简介

rubii-boss-cli — every BOSS MCP tool as a shell command (aws, db, mongo, elastic, redis, jira, cron, …), plus a stdio MCP server that proxies the BOSS MCP with the saved API key
