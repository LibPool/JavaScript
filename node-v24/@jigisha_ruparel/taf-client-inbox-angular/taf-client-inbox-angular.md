# @jigisha_ruparel/taf-client-inbox-angular

> 标签: JavaScript

## 简介

TAF client SDK — Angular <taf-inbox>: a themeable 'my work' inbox list (title / due / status + per-item actions), host-themed via taf-inbox__* hooks. Ships no theme.
