# @jigisha_ruparel/taf-client-comments

> 标签: JavaScript

## 简介

TAF client SDK — comments slice: the platform's own comment trail on any record (TABD_Comments keyed by the record's RecordInfo id), plus the @mention markup the platform turns into inbox items and e-mails.
