# @claude-worker/client

> 标签: agent, anthropic, browser, claude, claude-code, client, websocket

## 简介

Typed claude-worker protocol client for browsers and Node: REST session management plus a WebSocket attach with auto-reconnect and replay-from-last-seq. Uses the platform's fetch and WebSocket; zero runtime deps.
