# @hd-lib/hybrid-engine

> 标签: JavaScript

## 简介

HybridEngine 是为好多素教提供的，适配不同容器的 native 调用js垫片，统一了各端各容器(Weex、小程序、Nebula)的调用过程。并且未来会集成统一的基础环境变量、util方法、网络调用等能力。
