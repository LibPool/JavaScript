# @blackforestsentinel/seed-web-auth

> 标签: browser-extension, entra-id, msal, react, sentinel-seed

## 简介

Anmeldung per MSAL für Frontends in Sentinel-Seed-Projekten: Login mit stiller Erneuerung, Access-Tokens für die Function-API und Capabilities der angemeldeten Person für das UI; dazu ein Einstieg für Browser-Erweiterungen.
