# @feimacode/open-design-agent-kit

> 标签: ai-agent, claude-code, cli, codex, init, open-design

## 简介

npx @feimacode/open-design-agent-kit init — sets up Open Design's Claude Code and/or Codex integration directly in your own project, no marketplace or manual copying required. Also `export` (artifact → upload-ready PNG/JPEG) and `render-video` (HyperFrame
