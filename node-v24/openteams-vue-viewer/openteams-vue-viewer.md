# openteams-vue-viewer

> 标签: chat, collaboration, openteams, team-workspace, vue, webrtc, yjs

## 简介

Vue 3 component and composable for OpenTeams, the open-source bring-your-own-server team workspace. Self-contained: includes the <teams-app> UI.
