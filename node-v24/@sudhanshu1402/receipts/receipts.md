# @sudhanshu1402/receipts

> 标签: agent-verification, claude-code, claude-code-plugin, hooks, observability, transcript, zero-token

## 简介

Checks what an AI coding agent said it did against what it actually did, and prints the difference. Reads the Claude Code session transcript, costs no context tokens.
