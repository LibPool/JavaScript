# @acosmi/sdk-ts

> 标签: acosmi, anthropic, claude, compliance, crabclaw, crabcode, esignature, evidence, llm, openai, sdk, timestamp

## 简介

Acosmi TypeScript SDK：模型网关、Agent Run Gateway 与 Compliance（电子证据、时间章、报告、签署 envelope）统一客户端，支持浏览器 / Node ≥18 / Deno / Bun。
