# @nuxvel/nuxt

> 标签: backend, better-auth, drizzle, nuxt, nuxt-module, nuxvel, postgres, trpc, zod

## 简介

Nuxt module that gives a Nuxt app a production-ready backend: Postgres with Drizzle, a typed tRPC API, Zod validation, Better Auth, queues, mail, storage and realtime.
