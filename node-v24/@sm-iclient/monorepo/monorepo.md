# @sm-iclient/monorepo

> 标签: JavaScript

## 简介

sm-iclient is a small subset of SuperMap iClient which is written in typescript, ESM module by default, and uses ky-universal as the HTTP request. By using ky-universal, it can be run on **node** and **browser**
