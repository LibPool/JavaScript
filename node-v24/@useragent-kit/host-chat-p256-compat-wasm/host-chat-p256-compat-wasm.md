# @useragent-kit/host-chat-p256-compat-wasm

> 标签: JavaScript

## 简介

WASM/JS binding for the REMOVABLE P-256 chat compatibility shim (see useragent-chat-p256-compat). Exposes P256ChatHandle so hosts still on P-256 chat run core wasm 0.6.x + this shim. Delete on RFC-0004 X25519 migration.
