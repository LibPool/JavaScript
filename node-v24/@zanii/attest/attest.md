# @zanii/attest

> 标签: JavaScript

## 简介

Bind which code was running to a receipt: an Attestation claim + attestation_hash provenance field, with quote verification delegated to an injected platform verifier (SGX/Nitro/TPM). Honest by default — no verifier means quote NOT verified.
