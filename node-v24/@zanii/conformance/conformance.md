# @zanii/conformance

> 标签: JavaScript

## 简介

Conformance vectors for the Zanii protocol: canonical encoding, payload commitments, keys, delegation, receipts, Merkle proofs, signed tree heads and audit bundles, each with must-accept AND must-reject cases. Language-neutral JSON plus a runner.
