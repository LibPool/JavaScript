# @howarddierking/mermaid-event-model

> 标签: cqrs, d3, diagram, dsl, event-model, event-modeling, mermaid, mermaid-diagram

## 简介

Event Modeling DSL and SVG renderer as a Mermaid external diagram. Draws a strict horizontal timeline with actor/aggregate swimlanes, collapsible data sections, and vertical-slice bounding boxes.
