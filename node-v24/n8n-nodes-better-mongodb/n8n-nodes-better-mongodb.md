# n8n-nodes-better-mongodb

> 标签: aggregation, bson, change-stream, mongodb, n8n-community-node-package, objectid

## 简介

n8n MongoDB nodes: full CRUD, aggregation, bulk writes, transactions, indexes, Atlas/vector search, GridFS, BSON types (ObjectId, Date, Decimal128, ...) and a change stream trigger
