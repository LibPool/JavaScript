# @nimblestudio/session-replay

> 标签: JavaScript

## 简介

Browser SDK that keeps a rolling recording of the last minutes of a session and sends it to Nova as a bug report.

- 源码仓库：git+https://github.com/bothrs/bug-reporter-sdk.git
