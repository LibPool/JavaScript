# @riaskov/nevo-messaging

> 标签: circuit-breaker, dlq, kafka, messagepack, messaging, microservices, msgpack, nats, nestjs, nevo, opentelemetry, outbox, retry, saga

## 简介

Microservices messaging framework for NestJS with NATS/Kafka/SocketIO/HTTP transport, MessagePack, retry/circuit-breaker, OTel, schema validation, DLQ, idempotency, saga, outbox, metrics, health, DevTools
