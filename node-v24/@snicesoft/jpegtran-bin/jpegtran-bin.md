# @snicesoft/jpegtran-bin

> 标签: compress, image, imagemin, img, jpeg, jpegtran, jpg, minify, optimize

## 简介

jpegtran (part of libjpeg-turbo) bin-wrapper that makes it seamlessly available as a local dependency

## 官网

- 源码仓库：https://gitee.com/imagemin-cn/jpegtran-bin
- npm 页面：https://www.npmjs.com/package/@snicesoft/jpegtran-bin

- npm registry：https://registry.npmjs.org/@snicesoft/jpegtran-bin
- Node 要求：>=6
