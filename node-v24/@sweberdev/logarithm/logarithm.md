# @sweberdev/logarithm

> 标签: activity-log, audit, audit-log, compliance, gdpr, mariadb, multi-tenant, mysql, postgres, saas, soc2, sqlite

## 简介

Self-hosted audit log for SaaS apps: who changed what and when. Diffs with redaction, tenant-scoped queries and counts, typed action catalogs, Postgres, MySQL/MariaDB and SQLite stores, and a Fetch API handler for the React viewer.
