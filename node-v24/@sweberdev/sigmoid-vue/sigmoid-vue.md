# @sweberdev/sigmoid-vue

> 标签: animation, parallax, reduced-motion, reveal, scroll, scroll-driven-animations, spring, vue, vue3

## 简介

Vue 3 directives and composables for Sigmoid: v-reveal, v-parallax, useScrollProgress and useStory on native CSS scroll timelines.
