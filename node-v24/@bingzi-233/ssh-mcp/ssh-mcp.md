# @bingzi-233/ssh-mcp

> 标签: cli, file-transfer, mcp, model-context-protocol, remote, sftp, ssh

## 简介

纯命令行 SSH/SFTP 工具：在多台远程服务器上执行命令、传输大文件（断点续传）。支持 CLI 模式和 MCP stdio 模式。
