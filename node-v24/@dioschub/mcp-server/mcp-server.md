# @dioschub/mcp-server

> 标签: byoa, credential-blind, dioschub, mcp, model-context-protocol

## 简介

A TypeScript framework for building DioscHub-compatible MCP servers with Bring-Your-Own-Auth (BYOA) credential-blind pass-through.
