# @pnwatt/loess

> 标签: fitting, graph, plot, regression, smoothing, statistic, utility

## 简介

Fork of JavaScript implementation of the Locally-Weighted Regression package originally written in C by Cleveland, Grosse and Shyu (1992). This fork updates dependencies to fix security issues.
