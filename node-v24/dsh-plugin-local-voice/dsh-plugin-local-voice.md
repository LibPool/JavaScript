# dsh-plugin-local-voice

> 标签: asr, deepseek-harness, dsh, dsh-plugin, mlx, offline, qwen3, speech-to-text, voice

## 简介

Local real-time speech-to-text for DeepSeek Harness: a floating transcription panel plus a Qwen3-ASR recognizer provider (Apple Silicon). Fully offline.
