# @elizaos/plugin-waifu-imagegen-app

> 标签: JavaScript

## 简介

Native **image-generation AppView** for waifu agents. Renders inside an agent's ElizaOS web UI canvas (the apps overlay / desktop tab) and invokes the waifu.fun image-gen mini-app endpoint directly, settled in Eliza Cloud credits.
