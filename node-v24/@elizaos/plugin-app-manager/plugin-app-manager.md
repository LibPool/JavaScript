# @elizaos/plugin-app-manager

> 标签: app-lifecycle, app-manager, elizaos, hosted-apps, plugin

## 简介

App lifecycle plugin for elizaOS: hosted-app launch / list / close, run-state store, and the /api/apps/* route surface. Extracted from @elizaos/agent (Phase 4G).
