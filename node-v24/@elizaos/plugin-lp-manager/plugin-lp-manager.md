# @elizaos/plugin-lp-manager

> 标签: JavaScript

## 简介

A unified plugin for managing liquidity positions on Solana DEXs (Raydium, Orca, Meteora) and EVM DEXs (Uniswap, PancakeSwap, Aerodrome).
