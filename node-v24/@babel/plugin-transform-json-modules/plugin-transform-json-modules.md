# @babel/plugin-transform-json-modules

> 标签: WebAssembly, assertions, babel-plugin, import, phase, proposal, source, stage-3, wasm

## 简介

Transform json modules imports (`import '...' with { type: 'json' }`) to work in browsers and Node.js.
