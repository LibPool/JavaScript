# @onyxsoft/nv-custom-fields

> 标签: JavaScript

## 简介

Campos personalizados: se crean/editan en un panel de gestión y se renderizan como inputs funcionales reales (texto, número, fecha, combo, sí/no) en la vista principal. Standalone, OnPush, signals, sin lógica de negocio.
