# @dataverse-to-code/test

> 标签: dataverse, model-driven, playwright, power-platform, testing

## 简介

Run DataverseToCode project tests (.test.yaml) with Playwright: the offline form simulator in Chromium, a form fixture, and yamlTests(). Works with Microsoft Dataverse; not a Microsoft product.
