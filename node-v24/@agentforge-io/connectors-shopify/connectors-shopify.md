# @agentforge-io/connectors-shopify

> 标签: JavaScript

## 简介

Shopify Admin API connector for AgentForge — products, orders, customers, inventory. Public OAuth app with per-shop authorize URL (resolveEndpoints) and X-Shopify-Access-Token header.
