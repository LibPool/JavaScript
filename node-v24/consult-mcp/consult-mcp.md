# consult-mcp

> 标签: ai-agents, claude-code, code-review, codex, grok, mcp, mcp-server, model-context-protocol, second-opinion

## 简介

Get a second opinion on your code from every coding agent you have. Claude Code, Codex and Grok review each other's diffs and answer each other's questions, even inside a session that's already running. Uses the CLIs you're signed in to, no API keys.
