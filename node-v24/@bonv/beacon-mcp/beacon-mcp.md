# @bonv/beacon-mcp

> 标签: adobe-analytics, ai-agents, mcp, model-context-protocol, tag-qa

## 简介

MCP server that lets AI agents decode, explain, diff and validate Adobe Analytics hits (AppMeasurement + Web SDK) locally, over stdio.
