# @prosemark/latex

> 标签: codemirror, katex, latex, markdown, math, mathjax

## 简介

LaTeX-style math for ProseMark’s Markdown editor: `$...$` and `$$...$$`, rendered with [MathJax](https://www.mathjax.org/) loaded at **runtime** from your chosen package root (default: **jsDelivr**, pinned to the same MathJax version this package is teste
