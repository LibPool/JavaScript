> 标签: data-table, drizzle, kysely, pagination, postgrest, prisma, react-table, server-side, standard-schema, supabase, tanstack, tanstack-table

## 简介

Turn TanStack Table v9 state (sorting, column filters, global filter, pagination) into safe server-side queries for Drizzle, Prisma, Kysely and Supabase.
