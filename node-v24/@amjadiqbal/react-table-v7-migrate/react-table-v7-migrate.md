# @amjadiqbal/react-table-v7-migrate

> 标签: codemod, datagrid, migration, react-19, react-table, react-table-v7, recast, refactor, table, tanstack, tanstack-table, upgrade

## 简介

Codemod and compat helpers to migrate react-table v7 apps to TanStack Table v9 (and React 19): useTable, useSortBy, useFilters, useGlobalFilter, usePagination, useRowSelect, useExpanded.
