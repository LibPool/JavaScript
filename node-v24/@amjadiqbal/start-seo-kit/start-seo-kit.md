# @amjadiqbal/start-seo-kit

> 标签: ecommerce, hreflang, json-ld, meta-tags, og-image, open-graph, product-schema, rich-results, robots-txt, seo, sitemap, sitemap-index, structured-data, tanstack, tanstack-router, tanstack-start, twitter-card

## 简介

SEO kit for TanStack Start: typed head() meta tags (title templates, canonical, Open Graph, Twitter cards, robots, hreflang), dynamic sitemap and robots.txt server routes, JSON-LD helpers, e-commerce Product schema and an optional Open Graph image route.
