> 标签: agent-to-agent, ai-agents, assentra, cli, escrow, gateway, mcp, metering, settlement, sla

## 简介

Pactline command line: validate pact contracts, meter agent calls, run a metered gateway and a self-hosted Studio with a bilateral, hash-chained clearinghouse ledger.
