# @pactline/core

> 标签: a2a, agent-to-agent, ai-agents, assentra, ecdsa, escrow, mcp, metering, settlement, sla, web-crypto

## 简介

Framework-free agent-to-agent engine: authority verification, deterministic escrow and SLA metering, auto-negotiation, bilateral ECDSA-signed settlements and a hash-chained clearinghouse ledger. Node 20+, edge runtimes and browsers.
