# @playground-sessions/mpm-pitch-worklet

> 标签: audio, pitch, web-audio

## 简介

McLeod Pitch Method running inside an AudioWorkletNode with a ring buffer to the UI thread. Emits { frequency, confidence } events and a simple rolling contour for quick visual sanity checks.
