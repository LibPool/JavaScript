# @konneal/client

> 标签: JavaScript

## 简介

The Konneal publisher-site contract: engine API types, the SSE ask client, and the answer-contract renderers (citation chips, typed unit blocks, formulas, the in-context document pane) Ships the konneal CLI (ask, search, keys) for humans and operators.
