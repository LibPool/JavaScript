# @droponair/sdk-js

> 标签: chat-api, chat-sdk, droponair, e2ee, encrypted-chat, end-to-end-encryption, group-chat, messaging, messaging-sdk, push-notifications, realtime, sdk, video-calling, video-calls, voice-calls, webrtc, websocket

## 简介

End-to-end encrypted messaging, voice and video calling SDK. The relay never sees your keys or message content.
