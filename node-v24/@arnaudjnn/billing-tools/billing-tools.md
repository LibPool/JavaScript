# @arnaudjnn/billing-tools

> 标签: agentic-commerce, ai-agents, api-keys, auth, auth.md, billing, mcp, mpp, payments, saas, stripe, subscriptions, usage-based-billing, workos

## 简介

The get-paid engine for Stripe + WorkOS apps, for humans and AI agents. Drop-in API-key auth, credit + subscription billing, auth.md agent registration, and MPP machine payments, as MCP tools, a REST API, and a CLI. Framework-agnostic, storage-pluggable.
