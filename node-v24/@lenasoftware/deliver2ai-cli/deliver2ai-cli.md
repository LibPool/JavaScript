# @lenasoftware/deliver2ai-cli

> 标签: JavaScript

## 简介

deliver2.ai CLI — installs telemetry hooks into AI coding agents (Claude Code, Codex, OpenCode, VS Code Copilot) and forwards session events to the deliver2.ai ingestion API.
