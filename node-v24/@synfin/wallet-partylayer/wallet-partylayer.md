# @synfin/wallet-partylayer

> 标签: canton, cip-0103, partylayer, synfin, wallet, walletadapter

## 简介

The reference Synfin WalletAdapter for PartyLayer-connected Canton wallets. Drop it into @synfin/client's executePlan so a swap executes in about five lines, non-custodially, from the user's own wallet.
