# @edithree/editor-ui

> 标签: animation, blendspace, dockview, edithree, editor, react-three-fiber, state-machine, xyflow

## 简介

The edithree visual editor — host-agnostic React panels: live R3F viewport, scene outliner, properties inspector, 2D blend-space grid editor and a state-machine node graph. Runs standalone or inside the VSCode extension webview.
