# @kungal/editor-nuxt

> 标签: editor, kun-editor, kungal, milkdown, nuxt, nuxt-layer

## 简介

KunEditor Nuxt Layer — wraps @kungal/editor-vue and auto-imports <KunEditor> so an existing Nuxt app keeps its exact DX (no import needed).
