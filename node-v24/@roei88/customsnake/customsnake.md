# @roei88/customsnake

> 标签: browser-game, canvas, css, customizable, game, game-template, gamedev, html5, javascript, mini-game, retro, single-file, snake, snake-game, template, vanilla-js, zero-dependency

## 简介

A customizable retro snake game template - drop in your own head and monster images, run one build, ship a single self-contained index.html. Zero dependencies, vanilla JS + canvas.
