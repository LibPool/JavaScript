# @jawnty/agent-preflight

> 标签: agent, agents, autonomous, claude-code, cli, codex, copilot, cursor, decision, github, issue, linear, prd, preflight, readiness, scoring, spec, ticket

## 简介

Local-first deterministic CLI that scores whether an issue, spec, or decision artifact is ready for autonomous agent work. No LLM calls, no hosted backend.
