# cursorcam

> 标签: ai agent, auto zoom, browser recording, claude code, cli, click demo, demo video, mcp, mcp server, mp4, product demo, screen recording, walkthrough

## 简介

Ask your AI agent for a demo video. CursorCam clicks through your web app and renders a polished MP4 that zooms in on each click, from any MCP agent, Claude Code or the CLI.
