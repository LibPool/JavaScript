# @meszmate/agentd

> 标签: ai-agent, claude-code, codex, coding-agent, daemon, orchestrator, remote-development, tailscale

## 简介

Remote coding-agent orchestrator. One process serves the daemon, web UI, WebSocket bus, and CLI for driving claude-code / codex agents across devices.
