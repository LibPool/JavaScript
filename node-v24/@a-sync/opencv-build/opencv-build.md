# @a-sync/opencv-build

> 标签: build, opencv, opencv4nodejs

## 简介

A simple script to auto build recent OpenCV + contrib version via npm. (This fork defaults to disabled auto build, and checks for OPENCV4NODEJS_ENABLE_AUTOBUILD)
