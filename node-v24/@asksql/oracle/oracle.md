# @asksql/oracle

> 标签: ai, ask-database, database, database-chat, llm, natural-language, nl2sql, oracle, oracle-database, oracledb, sql, sql-generation, text-to-sql, text2sql

## 简介

Oracle Database connector for AskSQL. Data-dictionary schema introspection (tables, views, columns, primary/foreign keys, comments) + read-only transaction enforcement. Uses the oracledb driver in pure-JS Thin mode (no Instant Client).
