# @authup/specs

> 标签: auth, jwk, jwt, oauth2, openid-connect, rfc6749, rfc7517, rfc7519, specifications, types

## 简介

Constants, types and error classes for OAuth 2.0, OpenID Connect, JWT and JWK, as Authup uses them.
