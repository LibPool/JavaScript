# @polyskill/yusufkaraaslan.skill-seekers

> 标签: JavaScript

## 简介

Skill Seekers is a Python tool that converts documentation websites, GitHub repositories, and PDFs into LLM skills. It supports 4 platforms: Claude AI, Google Gemini, OpenAI ChatGPT, and Generic Markd
