# @polyskill/bitget-wallet-ai-lab.bitget-wallet

> 标签: JavaScript

## 简介

Interact with Bitget Wallet API for crypto market data, token info, swap quotes, and security audits. Use when the user asks about token prices, market data, swap/trading quotes, token security checks, K-line charts, or token rankings on supported chains
