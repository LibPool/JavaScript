# opencode-ds-peak

> 标签: cost, countdown, deepseek, discount, i18n, off-peak, opencode, opencode-plugin, peak, plugin, pricing, sidebar, tui

## 简介

Minimal opencode TUI sidebar dot showing whether DeepSeek is in peak or off-peak pricing, with a countdown to the next switch. Five languages.
