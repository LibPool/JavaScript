# @kkkey/dsh-pet-assets

> 标签: JavaScript

## 简介

Codex-style pet asset catalog: scans the pets directories (default $DSH_HOME/pets and $CODEX_HOME/pets, merged), validates manifests against the spritesheet contract, and serves catalog JSON plus spritesheet bytes over webserver routes
