# @scrapa/sdk

> 标签: browser, cdp, headless-chrome, markdown, playwright, proxy, puppeteer, scraper, scraping, screenshot, sdk, search, serp, web-scraping

## 简介

Official TypeScript client for scrapa.app — scrape any web page as markdown, HTML, text, links, a screenshot or a PDF, search the web, and drive a real browser over CDP.
