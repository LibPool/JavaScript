# @fairway-kit/agent

> 标签: adapter, agent, llm, local-first, runner, streaming, tool-use

## 简介

Agent integration toolkit for fairway: the Runner contract, a normalized event pump, and adapters (Claude, ...) that turn any agent into durable protocol events
