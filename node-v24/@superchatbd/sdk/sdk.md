# @superchatbd/sdk

> 标签: bangladesh, bdt, checkout, hmac, payments, sdk, superchat, superchatbd, webhooks

## 简介

Official TypeScript / Node.js SDK for the Superchat BD Developer Platform: hosted checkout payments, refunds, account data and webhook signature verification.
