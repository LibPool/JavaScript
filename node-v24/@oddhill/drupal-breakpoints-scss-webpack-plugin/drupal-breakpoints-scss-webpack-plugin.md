# @oddhill/drupal-breakpoints-scss-webpack-plugin

> 标签: breakpoints, drupal, plugin, sass, scss, webpack

## 简介

A plugin that will create a scss file with breakpoints from a Drupal theme breakpoints YAML file.

- npm registry：https://registry.npmjs.org/@oddhill/drupal-breakpoints-scss-webpack-plugin
