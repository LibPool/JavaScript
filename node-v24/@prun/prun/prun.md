# @prun/prun

> 标签: framework, hexagonal architecture, prun, pure js

## 简介

`prun` is a least opinionated modular ecosystem of modules for hexagonal architecture. This package is the shell entrypoint for prun prorgrams. It acts as the thin minimal basis for the core services
