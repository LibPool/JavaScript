# @retrofit-ui/builder-zod

> 标签: builder, fluent-builder, retrofit-ui, sdui, server-driven-ui, zod, zod-schema

## 简介

Fluent builders for retrofit-ui specs — compose tables, forms, pages, timelines, trees, and calendars in typed code instead of hand-writing JSON
