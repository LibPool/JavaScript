# @wulechuan/project-skeleton-for-libs

> 标签: JavaScript

## 简介

本项目是一个工具，用于方便地发布（复制）一个完整的Javascript库项目框架，其中包含必要的gulp配置、webpack配置、mocha+should测试框架，以及常用的npm脚本等，还包括一个空的范例骨架。
