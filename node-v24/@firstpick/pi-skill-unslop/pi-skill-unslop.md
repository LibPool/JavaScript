# @firstpick/pi-skill-unslop

> 标签: agent-skill, editing, pi, pi-coding-agent, pi-package, skill, unslop, writing

## 简介

Agents should invoke this skill whenever they write or edit prose for people, including READMEs, docs, commit messages, PR descriptions, changelogs, release notes, comments, and chat replies, to cut AI tells and restore human voice.
