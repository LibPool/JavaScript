# reel-schema

> 标签: authoring, format, json-schema, reel, schema, slideshow

## 简介

JSON Schema (draft 2020-12) for Reel 1.0 (reel/1) documents, the specification of the .zip reel package, an authoring guide and example documents. Language-neutral: generate validators in Go, Python, Rust …
