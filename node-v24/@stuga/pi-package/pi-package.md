# @stuga/pi-package

> 标签: mcp, pi, pi-package, stuga

## 简介

Connect Pi to Stuga: its MCP tools through pi-mcp-adapter, with OAuth sign-in or an agent key, the workspace's conventions in the system prompt, and playbook skills for reviewed edits.
