# @ontomorph/dtp-sdk

> 标签: JavaScript

## 简介

Official TypeScript SDK for the DTP digital-twin platform: connect twins via grant tokens, query systems, list and stream events, flag findings, manage API keys, and reach the HOLON clinical-knowledge API.
