# @ava-pay/agent

> 标签: agent-payments, ai-agent, ap2, ed25519, google-agent-payments-protocol, http-message-signatures, jws, rfc-9421, visa-trusted-agent-protocol, web-bot-auth

## 简介

Developer preview. Agent SDK for AVA Pay. Sign Visa Trusted Agent Protocol (RFC 9421), Google Agent Payments Protocol (AP2), and IETF Web Bot Auth requests. Plus the parsing primitives for building your own verifier. Pre 1.0: API may change.
