# @amirandap/llm-file-pipeline

> 标签: anthropic, batch-api, etl, llm, openai, prompt-versioning, structured-outputs

## 简介

Reusable core for LLM-based file/message extraction pipelines: prompt versioning, classification, provider dispatch (OpenAI Chat Completions + Responses, Anthropic), the OpenAI Batch API, multi-document PDF splitting, generic sinks and file storage. Canon
