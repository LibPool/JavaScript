# @rh-nestjs-shopify/auth

> 标签: JavaScript

## 简介

An OAuth setup for NestJS using Shopify's [@shopify/shopify-node-api](https://github.com/Shopify/shopify-node-api) package. Allows for online and offline auth using this module.
