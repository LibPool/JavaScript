# @data-heaving/common-azure

> 标签: JavaScript

## 简介

This folder contains source code for `@data-heaving/common-azure` NPM package. The exported entities include: - Helper methods for using Azure Authentication, and - Helper methods to read or write data to Azure BLOB storage.
