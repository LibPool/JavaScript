# @bitmonk8/pi-theta

> 标签: agent, dsl, extension, loop-engineering, pi, pi-coding-agent, pi-extension, pi-package, prompt-engineering, scripting-language, subagent, theta

## 简介

A scripting language for Pi agents: write the predictable parts of an agent task as code and leave only the fuzzy parts to the model.
