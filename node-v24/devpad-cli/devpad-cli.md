# devpad-cli

> 标签: agent, claude-code, dev-server, developer-tools, django, docker-compose, fastapi, iterm, metro, react-native, terminal

## 简介

Open a visible terminal per service and start your dev stack there — React Native / Metro, Python backends and docker compose, with the logs on your screen instead of an agent's buffer.
