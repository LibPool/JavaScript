# @pyxis-labs/web3-sources

> 标签: api-client, binance, coingecko, crypto, defi, defillama, dexscreener, etherscan, solscan, typescript, web3

## 简介

Typed TypeScript clients for 13 free crypto data APIs (CoinGecko, DefiLlama, DexScreener, Etherscan, and more). Every response carries source + freshness metadata. Zero runtime dependencies.
