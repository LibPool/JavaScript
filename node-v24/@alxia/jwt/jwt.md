# @alxia/jwt

> 标签: JavaScript

## 简介

JSON Web Tokens for alxia, on Web Crypto: HS256, ES256, RS256, EdDSA, an identity provider's JWKS (Keycloak, Auth0, Ory), and a typed bearer guard
