# @simplycms/plugin-faq

> 标签: JavaScript

## 简介

Reference FAQ plugin for SimplyCMS built with simplycms/plugin-sdk: plg_faq_items table (migration in-package), /admin/faq CRUD routes, product-detail slot, Zod settings, uk/en i18n catalog.
