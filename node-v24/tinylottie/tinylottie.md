# tinylottie

> 标签: after-effects, bodymovin, cli, compress, dotlottie, lottie, minify, optimize, webp

## 简介

Compress Lottie JSON & dotLottie files from the command line or CI: strip editor metadata, round precision, convert embedded images to WebP, convert JSON <-> .lottie. Runs locally, no uploads.
