# @ismarzdev/aispaceflow-mcp

> 标签: aispaceflow, claude, cursor, diagram, flowchart, local-first, mcp, mermaid, model-context-protocol, windsurf

## 简介

Local-first Model Context Protocol server for AISpaceFlow — deterministic diagramming tools (validate DSL, templates, icons, viewer links) for Claude Desktop, Cursor, Windsurf, and other MCP clients. No API key, no cloud round-trip.
