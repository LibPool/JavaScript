# @dmemo/opencode-plugin

> 标签: 0g, dmemo, mem0, memory, opencode, opencode-plugin

## 简介

dMemo OpenCode plugin (T3.2) — in-process mem0-oss memory via @dmemo/core, every-turn injection, deterministic capture, native compaction-hook integration. Forked from mem0's opencode-mem0.ts (D18); mem0-Platform-only surfaces stripped.
