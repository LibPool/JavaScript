# @ziqni-tech/gamification-ux-package

> 标签: JavaScript

## 简介

Our Gamification UX package enables you to quickly roll out your gamification experience. The package allows you to implement tournament leaderboards, achievements, missions, rewards and a message inbox in a most modular way.
