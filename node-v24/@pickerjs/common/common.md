# @pickerjs/common

> 标签: JavaScript

## 简介

这个包含有一组通用的实用函数和 TypeScript 类型，供多个 Picker 包使用。这个包不建议由最终用户的项目直接依赖，可能会有很多破坏性更新。

## 官网

- npm 页面：https://www.npmjs.com/package/@pickerjs/common
