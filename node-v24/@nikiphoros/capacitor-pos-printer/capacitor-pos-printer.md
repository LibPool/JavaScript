# @nikiphoros/capacitor-pos-printer

> 标签: capacitor, native, plugin

## 简介

A custom Capacitor plugin that integrates the Cashino CSN Thermal Printer Android SDK (CSNPrinterSDK.jar) into Ionic/Angular applications.
