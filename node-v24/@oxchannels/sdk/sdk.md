# @oxchannels/sdk

> 标签: openapi, openapi-fetch, oxchannels, publishing, sdk, social-media, typescript

## 简介

Closed beta. Typed TypeScript client for the OxChannels REST API, generated from the sealed OpenAPI contracts (public, dashboard, partner and agent-bootstrap surfaces); requires an API key issued by OxChannels.
