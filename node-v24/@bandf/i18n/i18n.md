# @bandf/i18n

> 标签: bergamot, custom-elements, i18n, local-first, marian, on-device, translation, web-components, webassembly

## 简介

Automatic, on-device internationalization for plain JavaScript and native Web Components, powered by the Bergamot translation engine compiled to WebAssembly.
