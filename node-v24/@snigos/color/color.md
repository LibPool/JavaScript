# @snigos/color

> 标签: cielab, ciexyz, color, colour, contrast, css4, css5, display-p3, gradient, lab, lerp, mix, p3-color, parser, srgb, xyz

## 简介

Greatly missing color functions and types for JavaScript. Supports three color spaces: *sRGB*, *CIELab* and *CIEXYZ* with precise conversion between them. Zero dependencies. Parser doesn’t rely on browser to parse color strings and could be used in any en
