# @hqleo/jslibs

> 标签: JavaScript

## 简介

+ 由于编写的语言越来越来，经常使用A语言时，会把B语言的常用的库，规则，语法忘记了，所以每个语言都会建立语法类似的库，以API的形式进行调用； + 第一版是一个比较简单的库先发布；
