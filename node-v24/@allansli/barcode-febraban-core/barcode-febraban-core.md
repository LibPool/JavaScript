# @allansli/barcode-febraban-core

> 标签: barcode, boleto, brazil, brazilian, codigo-de-barras, febraban, font-encoder, interleaved 2 of 5, interleaved-2-of-5, itf, linha-digitavel, pure-js, vanilla-core

## 简介

Vanilla JS encoder for Brazilian boleto ITF barcodes (Interleaved 2 of 5 / Febraban). Maps an even-length digit string to the BarcodeInterleaved2of5 font. Not EAN, UPC, Code 128, or a linha digitável converter.
