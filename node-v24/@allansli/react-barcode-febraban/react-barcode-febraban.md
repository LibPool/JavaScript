# @allansli/react-barcode-febraban

> 标签: barcode, boleto, brazil, brazilian, codigo-de-barras, febraban, font-encoder, interleaved 2 of 5, interleaved-2-of-5, itf, linha-digitavel, react

## 简介

React component for Brazilian boleto ITF barcodes (Interleaved 2 of 5 / Febraban). Encodes an even-length digit string for BarcodeInterleaved2of5. Not EAN, UPC, Code 128, or a linha digitável converter.
