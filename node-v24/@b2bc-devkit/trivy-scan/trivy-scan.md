# @b2bc-devkit/trivy-scan

> 标签: cli, container, cve, devsecops, docker, npx, sbom, scanner, security, trivy, vulnerability

## 简介

Run Aqua Security's Trivy scanner via npx on Linux, macOS and Windows. Downloads the official binary on first use, verifies its SHA-256 checksum, caches it locally and forwards all arguments 1:1 - no Docker, no manual install.
