# @addai/entity-desktop-mcp

> 标签: addai, computer-use, desktop, entity-studio, mcp

## 简介

MCP server that lets a +Ai entity see and use its own desktop: screenshot, click, type, scroll and run commands inside its isolated Linux environment.
