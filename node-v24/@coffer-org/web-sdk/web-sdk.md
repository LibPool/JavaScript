# @coffer-org/web-sdk

> 标签: JavaScript

## 简介

The UI contract for Coffer plugin **web bundles**. A plugin's `dist/web.js` is loaded at runtime by the host's federation loader; this package defines what that bundle declares (`PluginUIBundle`) and the field-renderer registry it plugs into.
