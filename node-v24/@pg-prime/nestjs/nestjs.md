# @pg-prime/nestjs

> 标签: nest, nestjs, pg-prime, postgres, postgresql, transactional

## 简介

NestJS module for pg-prime: the configured Db, ambient transactions, @Transactional(), request settings and rollback-per-test. Pre-alpha — the API will change.
