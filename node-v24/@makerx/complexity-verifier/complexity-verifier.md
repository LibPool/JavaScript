# @makerx/complexity-verifier

> 标签: cli, code-quality, complexity, cyclomatic-complexity, halstead, maintainability, maintainability-index, typescript

## 简介

Maintainability-index checker for TypeScript: computes cyclomatic complexity, Halstead volume, SLOC and a maintainability index, and fails files below a threshold.
