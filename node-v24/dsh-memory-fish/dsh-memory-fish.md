# dsh-memory-fish

> 标签: deepseek-harness, dsh, dsh-plugin, local-first, memory, sleep-consolidation, spaced-repetition, token-budget

## 简介

Context-budgeted local memory for DeepSeek Harness: fixed 600-token injection, three-stage sleep consolidation, spaced repetition, temporal validity. Zero dependencies, zero server.
