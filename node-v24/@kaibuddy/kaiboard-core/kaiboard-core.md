# @kaibuddy/kaiboard-core

> 标签: ai-agent, excalidraw, kaiboard, local-first, mcp, model-context-protocol, whiteboard

## 简介

Storage-agnostic command core for KaiBoard agent co-drawing: 11 commands driven through a pluggable storage adapter.
