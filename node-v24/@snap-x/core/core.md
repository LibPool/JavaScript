# @snap-x/core

> 标签: claude-skill, mcp, og-images, satori, snap-x, social-cards

## 简介

Engine for snap-x: renders self-contained Satori .mjs design files to PNG (renderer, fonts, emoji, platform formats + placement guides, checker). Use @snap-x/cli for the command.
