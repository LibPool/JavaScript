# @yanqd0/dsh-mint

> 标签: dsh, dsh-plugin, issue, mint, plugin, tracker

## 简介

DSH plugin: mint issue tracking integration — session context injection, event reminders, plan binding, a zero-approval `mint` tool, and a session tab.
