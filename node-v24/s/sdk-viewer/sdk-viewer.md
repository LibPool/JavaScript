# sdk-viewer

> 标签: Angular, JSON, SDK, array, clipboard, copy, soo-doh-kohd, soodohkohd, text, viewer

## 简介

Simple to use (Angular) component for viewing text, such as JSON and arrays, with a 'copy to clipboard' option.
