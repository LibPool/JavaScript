# sbox-sdk

> 标签: agent, ai, cloudflare-sandbox, code-interpreter, daytona, e2b, sandbox, vercel-sandbox

## 简介

One unified SDK for agent sandbox providers (E2B, Vercel, Cloudflare, Daytona, Modal, and more) — swap the adapter import, keep your code.
