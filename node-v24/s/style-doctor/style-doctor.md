# style-doctor

> 标签: ai, cliche, editor, lint, linter, llm, prose, slop, style, writing

## 简介

Diagnose prose health the way react-doctor diagnoses a React codebase: grouped findings, a 0-100 score, CI-ready exit codes, JSON for agents.
