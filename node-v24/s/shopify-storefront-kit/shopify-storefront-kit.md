# shopify-storefront-kit

> 标签: cart, ecommerce, headless-commerce, nestjs, nextjs, shopify, storefront-api, typescript, webhooks

## 简介

Framework-agnostic TypeScript toolkit for headless Shopify storefronts: typed data models, a zero-dependency Storefront API client, cart logic, webhook verification, and a catalog sync script. Works in Next.js, NestJS, or plain Node.
