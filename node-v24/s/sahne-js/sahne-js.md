# sahne-js

> 标签: Puppeteer, debugging, interception, interceptor, mocking, testing

## 简介

SahneJs is a CLI tool designed for mocking, testing, and debugging by intercepting and manipulating requests. It leverages Puppeteer's interceptor to capture and manipulate specific requests. You can direct these requests to an internal development server
