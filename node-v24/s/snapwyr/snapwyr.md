# snapwyr

> 标签: api, axios, dashboard, debug, debugging, dev-tools, express, fastify, fetch, hono, http, interceptor, koa, logger, logging, middleware, monitoring, nestjs, nextjs, real-time, request, websocket

## 简介

Zero-config HTTP request logger for Node.js. Automatically intercepts and logs fetch and axios requests. Perfect for debugging API calls in development.
