# sentinel-oracle

> 标签: air-gapped-authorization, devsecops, github, merge-authorization, qr-auth, security, supply-chain-security, webauthn

## 简介

Sentinel Oracle — Secure Merge Authorization Server. Physically separated merge authority that prevents workstation-compromise attacks from reaching the main branch.
