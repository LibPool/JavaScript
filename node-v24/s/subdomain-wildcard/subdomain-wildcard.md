# subdomain-wildcard

> 标签: JavaScript

## 简介

Urbanhire wildcard subdomain. Handle dynamic/wildcard subdomains in Express.js. This is modified from package https://www.npmjs.com/package/wildcard-subdomains. We custome to handle when main domain is subdomain. Ex: co.id, or.id
