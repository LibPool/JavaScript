# sawkit-node

> 标签: $ws, realtime, sawKit, sawKit-client, sawKit-node, socket, socket.io, socketIO, websocket, ws

## 简介

A back-end Facade over the popular 'ws' module for Node, allowing for event emissions and custom event reception.
