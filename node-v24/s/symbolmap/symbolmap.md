# symbolmap

> 标签: ai-agents, circular-dependency, cli, code-map, dead-code, dependency-graph, imports, refactoring, static-analysis

## 简介

A map of your code so tools and agents navigate instead of grepping. Where is this defined, who imports it, who uses it, what breaks if I change it. Zero dependencies.
