# svmmon-mcp

> 标签: claude, mcp, model-context-protocol, slideshow, svmmon, tiktok

## 简介

Public MCP server for Svmmon — generate TikTok slideshows from Claude and other MCP clients. Thin wrapper over the Svmmon /api/v1 REST API.
