# snaphost

> 标签: claude-code, cursor, mcp, model-context-protocol, publish, share, snaphost

## 简介

Connect your AI agent to SnapHost in one command: configures Claude Code, Cursor, VS Code, Windsurf, Codex CLI, and Gemini CLI for the hosted SnapHost MCP server.
