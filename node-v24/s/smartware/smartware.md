# smartware

> 标签: agent-memory, claims, knowledge-graph, local-first, mcp, memory, model-context-protocol, provenance, semantic-search, temporal-memory

## 简介

An open, user-owned memory protocol for every app and agent, with provenance, bitemporal truth, policy-first retrieval, and safe fallback.
