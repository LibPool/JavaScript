# soapnoteapi-mcp

> 标签: ai-scribe, billing-codes, clinical-documentation, cpt, ehr, emr, healthcare, icd-10, mcp, mcp-server, medical, medical-scribe, model-context-protocol, modelcontextprotocol, soap-notes, soapnoteapi

## 简介

Model Context Protocol (MCP) server for SOAPNoteAPI — turn clinical transcripts or audio into structured SOAP notes, ICD-10/CPT billing-code suggestions, patient summaries, and visit summaries.
