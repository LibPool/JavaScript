# smartipedia-mcp

> 标签: ai-agents, claude, encyclopedia, knowledge-base, mcp, model-context-protocol, smartipedia, wikipedia

## 简介

MCP server for Smartipedia — the AI-native encyclopedia. Read, search, write and edit encyclopedia articles. No API key, no signup.
