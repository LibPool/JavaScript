# supabase-worker-previews

> 标签: branch-preview, branching, ci, cli, cloudflare, cloudflare-workers, database, github-actions, postgres, preview, preview-deployments, supabase, supabase-branching, workers, wrangler

## 简介

Branch previews for Cloudflare Workers on Supabase branching: every git branch gets a Worker Preview, and every PR that changes the schema gets its own Supabase database.
