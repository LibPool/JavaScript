# skautis-api

> 标签: JavaScript

## 简介

Tato knihovna poskytuje jednoduché rozhraní pro připojení k Skautis API pomocí TypeScript. Zahrnuje metody pro vytváření požadavků HTTP na koncové body API, zpracování autentizace a analýzu odpovědí.
