# sqlglot

> 标签: JavaScript

## 简介

A no-dependency SQL parser, transpiler, and AST toolkit for TypeScript -- a faithful port of the Python [sqlglot](https://github.com/tobymao/sqlglot) library that runs in the browser and Node.js.
