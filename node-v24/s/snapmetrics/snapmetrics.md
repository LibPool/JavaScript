# snapmetrics

> 标签: analytics, averages, data-processing, esm, in-memory, javascript, lightweight, metric-tracking, metrics, monitoring, nodejs, performance-monitoring, real-time, response-time, time-windows

## 简介

Lightweight library for tracking real-time metrics and events with rolling statistics over configurable time windows.
