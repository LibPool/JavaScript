# style-component-compiler

> 标签: style-component, style-component-compiler, style-components, style-lib, style-library, style-unit-compiler

## 简介

样式组件编译器，一行命令生成样式组件库，包含通用样式与原子样式。从此写前端不再需要写样式了。
