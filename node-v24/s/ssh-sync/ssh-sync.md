# ssh-sync

> 标签: JavaScript

## 简介

Sync a local directory with a remote directory via ssh. Requires that rsync be installed: https://rsync.samba.org/download.html

## 官网

- npm 页面：https://www.npmjs.com/package/ssh-sync
