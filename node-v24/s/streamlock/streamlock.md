# streamlock

> 标签: aes-128, aws, cloud-run, cloudflare, dynamodb, entitlement, firestore, gate, gcs, google-cloud, hls, lambda-edge, m3u8, media, paywall, r2, s3, subscription, workers

## 简介

Runtime-agnostic subscription gating for HLS media. Rewrites AES-128 m3u8 key URIs, mints short-lived session tokens, and enforces per-episode entitlements on Cloudflare Workers, AWS Lambda@Edge, Google Cloud, or any Node 18+ runtime.
