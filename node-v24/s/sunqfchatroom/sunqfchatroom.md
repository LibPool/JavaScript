# sunqfchatroom

> 标签: JavaScript

## 简介

- 搭建临时聊天室 - 搭建 web 服务器 提供页面访问功能 - 依赖第三方 ws 模块 - 搭建 WebSocket 服务器 提供持续连接功能   - WebSocket 是种长连接的通信方式 连接成功后可以一直发送消息 - 可以实现临时连接并进行通讯 - 添加消息气泡显示 -
