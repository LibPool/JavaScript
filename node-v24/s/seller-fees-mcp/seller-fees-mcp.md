# seller-fees-mcp

> 标签: calculator, etsy, fees, gumroad, mcp, model-context-protocol, paypal, stripe

## 简介

MCP server for Gumroad, Stripe, PayPal and Etsy seller fees, payouts and break-even prices. Runs locally, no API key, no network.
