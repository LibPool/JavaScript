# signalk-ollama

> 标签: ai, container, llm, ollama, signalk-category-utility, signalk-node-server-plugin, signalk-plugin-configurator, signalk-webapp

## 简介

Ollama as a managed container for Signal K — a local LLM server other plugins and containerized services (signalk-voice-llm, signalk-ai-bridge) can call.
