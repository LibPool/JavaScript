# starbucks-jp-drink

> 标签: JavaScript

## 简介

検索オプションを指定することで、日本のStarbucksのドリンクの検索ができるmoduleです。利用した場合のサンプルとして、現在の季節のおすすめドリンクを表示するCLIが同梱されています。
