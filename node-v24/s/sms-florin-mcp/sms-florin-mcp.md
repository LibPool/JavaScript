# sms-florin-mcp

> 标签: ai-agent, ai-coding-agent, claude, claude-code, cursor, disposable-phone-number, mcp, mcp-server, model-context-protocol, otp, otp-testing, phone-verification, qa-testing, receive-sms, sms, sms-verification, temporary-phone-number, test-automation, virtual-number, windsurf

## 简介

MCP server for sms-florin — lets AI coding agents (Claude, Cursor, Codex, Windsurf...) rent a real UK phone number and receive SMS/OTP verification codes during automated testing.
