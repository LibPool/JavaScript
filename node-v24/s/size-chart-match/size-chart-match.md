# size-chart-match

> 标签: apparel, body-measurements, clothing-size, ecommerce, fashion, fit, size-chart, size-finder, size-recommendation, virtual-try-on

## 简介

Pick a clothing size from body measurements and any store's size chart. Parses copied charts, handles cm and inches, zero dependencies.
