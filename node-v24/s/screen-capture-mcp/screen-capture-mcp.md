# screen-capture-mcp

> 标签: ai-tools, anthropic, claude, claude-code, mcp, mcp-server, model-context-protocol, screen-capture, screenshot, windows

## 简介

MCP server that gives Claude Code the ability to take screenshots. Capture full screen or specific windows by title. Windows only.
