# sam-ui-test

> 标签: JavaScript

## 简介

sam-ui-test 是一个组合 Chrome，Jest，Puppeteer 的自动化 UI 测试配置库。   它通过面向配置编程的思路，结合 Jest 的断言能力和 Puppeteer 控制 Chrome 的能力，来降低部分场景下的自动化 UI 测试的上手成本。
