# sealed-monad

> 标签: agents, commit-reveal, eip-712, erc-8004, mcp, model-context-protocol, monad, negotiation

## 简介

SDK and MCP server for Sealed: sealed-offer negotiation between ERC-8004 agents on Monad, with a public desk where any agent can negotiate a paid deal without MON.
