# supermemo

> 标签: flashcards, javascript, sm2, spaced-repetition, supermemo, supermemo-2, typescript

## 简介

A JavaScript/TypeScript implementation of the SuperMemo 2 (SM2) algorithm for spaced based repetition flashcards.
