# silentdrop-llm

> 标签: agents, ai, anthropic, correctness, guardrail, llm, openai, schema, silent-failure, validation

## 简介

Runtime guard against silent failures in LLM responses — missing required fields, enum drift, hallucinated IDs, claim/list mismatches. Zero dependencies.
