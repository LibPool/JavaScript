# smooth-tabs

> 标签: a11y, accessible, category-nav, horizontal-scroll, keyboard-navigation, react, react-component, react-smooth-tabs, react-tabs, rtl, scroll-spy, scrollable-tabs, scrollspy, sticky-nav, tab-bar, tablist, tabs, typescript, wai-aria

## 简介

Accessible, scrollable React tabs with an animated indicator, overflow-aware arrows, keyboard navigation and built-in scroll-spy for section navigation. Zero dependencies.
