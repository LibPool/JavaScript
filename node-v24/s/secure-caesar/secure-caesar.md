# secure-caesar

> 标签: algorithm, caesar, cipher, cryptography, curve, data, decryption, ecc, ecdh, elliptic, encryption, expander, key, padding, password, protection, scrypt, secret, security, symetric, unicode

## 简介

secure-caesar cipher, is a symetric key cipher, based on caesar shift cipher. Enhanced with unicode support, custom padding, Scrypt key expander, elliptic curve support & power usage selection.
