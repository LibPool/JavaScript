# stokado

> 标签: browser, browser-storage, disposable, expires, localForage, localStorage, localStorage-wrapper, once, proxy, proxy-storage, serializer, sessionStorage, storage, storage-expiration, storage-proxy, storage-reactivity, storage-serialization, subscribe, web-storage

## 简介

Feature-rich proxy wrapper for browser storage with serialization, reactivity, expiration, and one-time values. Works with localStorage, sessionStorage, and async storages like localForage.
