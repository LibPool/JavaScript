# select2_pinyin

> 标签: autocomplete, dropdown, multiselect, select, tag, tagging, typeahead

## 简介

支持拼音检索 && Select2 is a jQuery based replacement for select boxes. It supports searching, remote data sets, and infinite scrolling of results.
