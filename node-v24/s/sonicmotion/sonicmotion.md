# sonicmotion

> 标签: DOM audio animation, Web Audio API stems, animación web con música, audio-driven DOM effects, audio-reactive web motion, frontend reactive audio, javascript audio stems, librería para detectar sonido, music synced UI, music visualization library JS, sonicmotion, sound frequency visualizer, visualizador de música web

## 简介

Lightweight audio-reactive DOM animation library. Sincroniza movimientos web con música usando Stems y Web Audio API. Zero dependencies.
