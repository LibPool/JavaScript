# svg-sprite-gen

> 标签: cli, react, sprite, svg, svg-sprite, svgo

## 简介

Given a folder of SVGs, it optimizes, inlines, and bundles them into a single SVG-sprite (with <symbol> tags), plus a React hook for easy lookup.
