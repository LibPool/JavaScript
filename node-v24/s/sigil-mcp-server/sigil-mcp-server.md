# sigil-mcp-server

> 标签: agent, claude, commerce, group-buy, mcp, model-context-protocol, shopping, sigil

## 简介

MCP server for Sigil — AI-first commerce marketplace. Exposes product search, live group-buy deals, personalized recommendations, and one-click checkout prep to Claude, Cursor, ChatGPT, and any MCP client.
