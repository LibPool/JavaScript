# sass-export

> 标签: Node Sass, Sass, Sass Annotations, Sass Utilities, Sass to JS, Sass to Json, Scss, Scss Json, sass variables exporting

## 简介

Exports Sass files to Json format, able to manage sections with annotations in comments.
