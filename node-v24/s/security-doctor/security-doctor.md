# security-doctor

> 标签: ai-coding-agent, cli, sast, security, sql-injection, static-analysis, taint-tracking, vulnerability-scanner, xss

## 简介

Security-focused CLI tool for JS/TS codebases — catches the vulnerabilities AI coding agents actually introduce, and installs its rules as guidance for your coding agent.
