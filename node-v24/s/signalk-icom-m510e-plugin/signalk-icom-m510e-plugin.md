# signalk-icom-m510e-plugin

> 标签: signalk-category-hardware, signalk-category-instruments, signalk-node-server-plugin

## 简介

Send and receive NMEA0183 data to and from Icom M510E. Including AIS data to enable AIS functionalily on a non-AIS model.
