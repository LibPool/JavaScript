# sahajlipi

> 标签: browser, devanagari, devnagari, ime, input-method, javascript, keyboard, nepali, nepali-input, nepali-keyboard, nepali-transliteration, nepali-typing, nepali-unicode, phonetic-typing, roman-nepali, textarea, transliteration, typescript, unicode

## 简介

Dependency-free Nepali phonetic typing and Roman Nepali to Devanagari Unicode transliteration for JavaScript, with browser input adapters and TypeScript types.
