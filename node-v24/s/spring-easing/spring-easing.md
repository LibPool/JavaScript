> 标签: @okikio/animate, animation, css-spring-easing, custom-easing, easing, framer-motion, linear-easing, motion-one, spring, spring-easing, typescript, waapi, web-animation-api

## 简介

Quick and easy spring animations. Works with other animation libraries (animejs, framer motion, motion one, @okikio/animate, etc...) or the Web Animation API (WAAPI).
