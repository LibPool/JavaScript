# sqlite3-compat

> 标签: compat, database, knex, no-native, node-sqlite3, node:sqlite, prebuild, sequelize, sqlite, sqlite3, typeorm

## 简介

The node-sqlite3 (sqlite3) callback API on Node's built-in node:sqlite. No native addon, no prebuilt binaries: same Database, Statement, Backup, serialize/parallelize, events and error codes.
