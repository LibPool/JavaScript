# substitution-ciphers

> 标签: cipher, encryption, griffinere, obfuscation, obfuscator, substitution, typescript

## 简介

The Griffinere cipher is a custom encryption algorithm in Typescript designed for reversible, base64-normalized encryption using a repeating key. Inspired by the Vigenère cipher, it adds configurable alphabet support, input validation, and padding-based e
