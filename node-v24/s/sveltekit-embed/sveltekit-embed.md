# sveltekit-embed

> 标签: codepen, components, deezer, embed, gist, github, iframe, intersection-observer, lazy-loading, mastodon, performance, responsive, soundcloud, spotify, svelte, sveltekit, twitter, typescript, ui-components, vimeo, youtube

## 简介

A collection of embed components for SvelteKit. Easily embed content from YouTube, Spotify, Vimeo, CodePen, and many more with performant, lazy-loaded components.
