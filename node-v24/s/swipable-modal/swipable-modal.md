# swipable-modal

> 标签: JavaScript

## 简介

v0.0.3 Vue plugin to create a simple modal with swipable behavior on mobile devices. ## Installation ``` npm i vue-swipable-modal ``` or ``` yarn add vue-swipable-modal ```
