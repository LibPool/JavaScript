# sasacode-plugin-agent-hygiene

> 标签: sasacode, sasacode-plugin

## 简介

Keeps agent work notes clean: STATE.md holds only current and next work, history goes to .agents/log.jsonl through an agent_log tool, with /kickoff and /handoff routines
