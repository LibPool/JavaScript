> 标签: carousal, carousel, carousel-component, carousel-plugin, carousel-slider, component, delay, loop, loopback, looping, pan, panning, react, relay, scroll, scrolling, slide, slider, slideshow, timing, vertical

## 简介

A lightweight, easy to use and highly customizable React component that achieves a &#x27;Carousel&#x27; or &#x27;Slideshow&#x27; effect. Allows for relay, panning and scrolling effects.
