# svg-core

> 标签: expo, geometry, hit-testing, parser, react-native, scene-graph, svg, typescript

## 简介

Dependency-free SVG parser, normalizer, scene graph, render planner and geometry engine in TypeScript. Runs on React Native, web and Node.
