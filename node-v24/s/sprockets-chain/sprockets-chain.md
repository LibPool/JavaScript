# sprockets-chain

> 标签: JavaScript

## 简介

`SprocketsChain` is a small node.js utility that parses Sprockets require directives and returns the dependency chain for a JavaScript bundle, which is a list of the file paths that make the bundle, ordered so that each file is preceded by all its depende
