# signalk-voice-llm

> 标签: assistant, llm, lm-studio, ollama, signalk-category-utility, signalk-node-server-plugin, voice, wyoming

## 简介

Answer boat voice commands with a local or remote LLM: subscribes to voice.command (from signalk-wyoming), asks an OpenAI-compatible LLM (LM Studio, Ollama, etc.), and speaks the reply back via say().
