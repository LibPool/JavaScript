# synapse-code-mcp

> 标签: ai, claude, code-assistant, code-context, context, developer-tools, mcp, model-context-protocol, semantic

## 简介

MCP server for code intelligence — semantic context, dependency graphs, and compressed symbol indexes for TypeScript/JavaScript, plus git-aware diffs and fast search. Zero external dependencies: no vector database, no embedding API, fully local.
