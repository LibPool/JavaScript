# signalk-multiplexer

> 标签: multiplexer, signalk

## 简介

A multiplexer for Signal K that merges any incoming Signal K (either full or delta) into an in-memory Signal K tree, tracks changes and emits events when appropiate. Optionally takes a settings object with vessel information and/or filters.
