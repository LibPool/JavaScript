# starlight-theme-large-print

> 标签: a11y, accessibility, chinese, cjk, font-size, large-print, starlight, starlight-plugin, starlight-theme

## 简介

Elder-friendly reading theme for Astro Starlight: larger serif body text, reader font-size control, warm dark mode, optional self-hosted CJK serif fonts.
