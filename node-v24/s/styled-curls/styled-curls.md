# styled-curls

> 标签: JavaScript

## 简介

A lightweight ([~32kB gzipped](https://bundlephobia.com/result?p=styled-curls@0.1.28)), modular CSS-in-JS component framework for React backed by [Emotion](https://github.com/emotion-js/emotion).
