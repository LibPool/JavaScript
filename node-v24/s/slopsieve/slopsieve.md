# slopsieve

> 标签: ai-agents, ai-slop, ci, code-quality, code-review, diff, lint, pull-request, review, vibe-coding

## 简介

Score a diff or PR for AI-slop review signals: test weakening, debug leftovers, trivial deps, dead code, narration comments. A linter for unreviewed generation.
