# sunoapi-sdk

> 标签: ai music, lyrics, music generation, sdk, suno, suno api, sunoapi, sunoupai, typescript, voice cloning

## 简介

Complete, ergonomic Node.js / TypeScript SDK for SunoAPI.org — music, lyrics, sounds, voice, upload, WAV, MIDI, stems, video, mashup, persona, cover and more. Zero runtime dependencies.
