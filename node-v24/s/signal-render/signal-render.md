# signal-render

> 标签: dom, esm, fine-grained, framework, html, micro-framework, no-build, reactive, rendering, signal-polyfill, signals, tc39, template, ui

## 简介

A 4 KB reactive UI micro-framework built on the TC39 Signals polyfill. Fine-grained DOM updates, no Virtual DOM, no build step required.
