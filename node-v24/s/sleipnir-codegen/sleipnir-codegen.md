# sleipnir-codegen

> 标签: client, codegen, discovery, javascript, rpc, sleipnir, stub-generator, typescript

## 简介

Typed client stub generator for the Sleipnir RPC framework — turns /api/sleipnir/discovery into typed TS/JS/C#/Python clients (REST / SSE / WS). CLI: sleipnir-gen.
