# stylelint-config-rational-order-fix

> 标签: css declaration order, css property order, declaration-order, order, order-css, properties-order, rational-css, stylelint, stylelint-config, stylelint-config-rational-order, stylelint-config-rational-order-fix, stylelint-order, stylelint-plugin

## 简介

Stylelint config that sorts related property declarations by grouping together following the order: Positioning, Box Model, Typography, Visual, Animation, Other.
