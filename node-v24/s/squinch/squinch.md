> 标签: agent-skill, agents, ai, architecture, architecture-diagrams, aws, azure, c4, claude-code, codex, diagrams, diagrams-as-code, gcp, google cloud, kubernetes, llm, svg, system-design

## 简介

Architecture diagrams as code for coding agents: install the skill, then check, render, diff and watch .squinch projects — clean, zoomable diagrams with real cloud icons, as deterministic SVG, PNG or interactive HTML.
