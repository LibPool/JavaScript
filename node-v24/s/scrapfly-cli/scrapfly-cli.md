# scrapfly-cli

> 标签: agentic, anti-bot, headless-browser, llm-agent, mcp, scraper, scrapfly, scraping, stealth-browser, web-scraping

## 简介

Scrapfly CLI: agentic scraping, screenshots, AI extraction, crawling, and a cloud browser over CDP. This package downloads the right platform binary on install.
