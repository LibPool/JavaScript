# sveltechatkit

> 标签: ai, chat, chatbot, dify, llm, ollama, openai, streaming, svelte, sveltekit, ui-kit

## 简介

A universal, provider-agnostic AI chat UI kit for SvelteKit — streaming responses, markdown rendering, and a clean provider abstraction for OpenAI-compatible APIs, Ollama, Dify, n8n, and custom backends.
