# svgforge

> 标签: css, generator, html, icon, icons, inline, mustache, png, retina, rwd, sprite, spritesheet, stack, stylesheet, svg, vector

## 简介

SVG sprites & stacks galore — A low-level Node.js module that takes a bunch of SVG files, optimizes them and bakes them into SVG sprites of several types along with suitable stylesheet resources (e.g. CSS, Sass, etc.)
