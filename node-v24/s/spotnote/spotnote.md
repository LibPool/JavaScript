# spotnote

> 标签: ai, astro, claude-code, coding-agent, devtools, mcp, react, solid, svelte, vite, vite-plugin, vue

## 简介

Click a UI element in your Vite dev server, write a note, and copy an AI-agent-ready prompt with the exact source location.
