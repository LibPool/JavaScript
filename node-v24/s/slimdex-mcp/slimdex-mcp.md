# slimdex-mcp

> 标签: claude, code-intelligence, coding-agent, llm, mcp, model-context-protocol, tokens

## 简介

A local MCP server for narrow code retrieval: outlines, symbol context, a dependency graph, and persistent memory instead of whole-file reads.
