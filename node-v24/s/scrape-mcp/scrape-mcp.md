# scrape-mcp

> 标签: cheerio, claude, llm, markdown, mcp, model-context-protocol, playwright, scraping, web-scraper

## 简介

Open-source MCP server for web scraping. Hybrid engine: lightweight (fetch+Cheerio) with automatic Playwright fallback. Zero config, no API keys needed.
