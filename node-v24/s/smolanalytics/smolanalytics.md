# smolanalytics

> 标签: agentic-testing, ai-testing, browser-testing, ci, claude, cursor, e2e-testing, end-to-end-testing, github-actions, mcp, no-code-testing, playwright, pull-request, qa, regression-testing, test-automation, testing, vibe-coding

## 简介

End-to-end tests without test code. Write one sentence, an agent drives a real browser and returns a verdict, and a passing run is recorded so the next one calls no model. Runs on any URL with no account.
