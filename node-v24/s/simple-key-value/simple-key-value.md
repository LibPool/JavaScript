# simple-key-value

> 标签: cache, esm, key-value, kv, nextjs, persistence, redis, storage, ttl, typescript

## 简介

Librería estilo Redis (get/set con TTL) para Node.js, escrita en TypeScript, con adapters de persistencia intercambiables (memoria, filesystem, sqlite, mysql, redis). ESM, compatible con Next.js.
