# shellmail-mcp

> 标签: agents, ai, claude, email, mcp, model-context-protocol, shellmail

## 简介

MCP server for ShellMail — full email client for AI agents: read inbox, extract OTPs, search, send/reply, and permanently delete messages (destructive tools are annotated and require confirmation)
