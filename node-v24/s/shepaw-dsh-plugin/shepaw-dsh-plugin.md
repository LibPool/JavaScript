# shepaw-dsh-plugin

> 标签: acp, cordis, deepseek-harness, dsh, shepaw

## 简介

Shepaw bridge as a DeepSeek Harness (DSH) cordis plugin: mount a Shepaw ACP v2.1 server inside DSH and route chats into DSH Agents
