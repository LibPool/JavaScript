# slim-xlsx

> 标签: JavaScript

## 简介

Features: * Read template xlsx, insert, edit & save (perfect for making invoice-like documents) * No any library used for xlsx * Styles & formats are correctly preserving * Insert new rows with merged cells * Rows cloning
