# signalk-kshana-trust

> 标签: gnss, kshana, signalk-category-utility, signalk-node-server-plugin

## 简介

Signal K server plugin: publishes the Kshana receiver-trust score, band and reasons and raises a notification when trust collapses. Advisory software, not type-approved equipment.
