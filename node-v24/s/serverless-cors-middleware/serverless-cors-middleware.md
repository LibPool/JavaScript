# serverless-cors-middleware

> 标签: JavaScript

## 简介

Serverless comes with a basic CORS implementation. With credentialed requests, the documentation [suggests the application handle the response](https://serverless.com/blog/cors-api-gateway-survival-guide/#cors-with-cookie-credentials).
