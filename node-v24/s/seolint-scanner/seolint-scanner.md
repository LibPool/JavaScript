# seolint-scanner

> 标签: audit, lint, linter, scanner, seo, seolint

## 简介

The open-source SEO scanner behind seolint.dev. Pure function: URL or HTML → structured issues. Zero-key, fully local, no network calls beyond fetching the target page.
