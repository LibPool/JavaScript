# sql-sanitizer

> 标签: express, fastify, koa, middleware, nestjs, security, sql, sql-injection, waf

## 简介

SQL injection request filter for Express/Fastify/Koa/Nest with presets, stats, CLI scanner, and parameterized sql helpers.
