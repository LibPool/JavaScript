# syllabus

> 标签: LUA scripts, RESP, cache, command mix-ins, redis, redis commands, redis protocol encoder, redis reply formatter, script cache, syllabus, Σ

## 简介

Σ Syllabus, a collection of helpers mix-ins to encode Redis commands and to decode Redis replies, builded upon Sermone.
