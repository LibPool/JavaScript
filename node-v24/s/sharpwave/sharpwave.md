# sharpwave

> 标签: agent-memory, ai-memory, claude, claude-code, cursor, fsrs, knowledge-graph, llm, long-term-memory, mcp, memory, model-context-protocol, multi-agent, openclaw, spaced-repetition, sqlite, vector-search

## 简介

Long-term memory for AI agents. An MCP server that remembers across sessions, forgets what stops mattering, and consolidates the rest — modeled on how the hippocampus actually works. Works with OpenClaw, Claude Code, Cursor, and any MCP client.
