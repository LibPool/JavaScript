# simple-message-toast

> 标签: JavaScript

## 简介

在开发小型项目时， 有时会需要用到消息提示，去安装UI库按需加载又有点麻烦，此时可以使用 simple-message-toast， 支持 vue2, vue3, react, HTML, 简单易用
