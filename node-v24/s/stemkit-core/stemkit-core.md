# stemkit-core

> 标签: client-side, computational-chemistry, curve-fitting, gromacs, lammps, molecular-dynamics, open-science, plumed, privacy, slurm, statistics, xvg

## 简介

Dependency-injected computational core for STEMKit: GROMACS, PLUMED and LAMMPS input writing and checking, trajectory parsing, statistics, molecular structure geometry, curve fitting, unit conversion, and HPC script generation.
