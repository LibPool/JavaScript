# snap-records

> 标签: accessible, component, data-grid, datatable, dynatable, filtering, grid, interactive, jquery-dynatable, library, pagination, sorting, table, typescript, vanilla-js

## 简介

A powerful and flexible TypeScript data grid component for modern web applications. Features server-side data handling, multiple rendering modes, extensive customization, and full accessibility support.
