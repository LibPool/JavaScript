# scramjet

> 标签: apache, apex, async, await, es6, es7, filter, flink, functional, highland, livedata, log, map, merge, multithreaded, mux, parser, realtime, spark, stream, threads, transform, transmux, ts, typescript

## 简介

Lightweight and real-time data functional stream programming framework like event-stream, written in ES6 using async await with multi-threading and typescript support
