# script-hop

> 标签: bun, cli, deno, fuzzy, npm, pnpm, scripts, task-runner, yarn

## 简介

Fuzzy, frecency-ranked picker for your project's scripts and tasks. Works with npm, pnpm, yarn, bun and deno.
