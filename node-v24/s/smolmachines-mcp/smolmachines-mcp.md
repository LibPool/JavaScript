# smolmachines-mcp

> 标签: agents, branch, checkpoint, mcp, microvm, model-context-protocol, sandbox, smolmachines, smolvm

## 简介

MCP server that gives any agent its own branchable microVM: create a machine of your environment, run commands, branch before risky steps, keep or discard, checkpoint and restore. Local by default, same tools on smol cloud.
