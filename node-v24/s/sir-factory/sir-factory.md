# sir-factory

> 标签: decompile, oracle, rederive, sir, supply-chain, verified-recompose

## 简介

SIR verified-recompose build orchestrator — a mechanical CLI (install → stamp → grade → pack) driven by the sir-factory-runner agent. No API key, no claude -p. Targets SIR Schema v0.2.
