# sass-transfer

> 标签: JavaScript

## 简介

vue-to-wx可以将vue模板转义成微信小程序格式 ## 为什么不是uni-app? vue-to-wx与uniapp有本质的区别,前者只是将.vue文件转义为微信支持的格式语法,并不向文件内添加runtime.可以使用vue的语法但是需要遵循小程序的api,文件可以单独抽离使用.后者直接向文件内添加自定义的运行时文件不可以单独抽离文件.
