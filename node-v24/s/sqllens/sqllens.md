# sqllens

> 标签: analyzer, antlr, ast, bigquery, column-lineage, databricks, dbt, duckdb, lineage, mariadb, mysql, name-resolution, parser, postgres, redshift, snowflake, sql, sql-analyzer, sql-parser, sqlite, static-analysis, tokenizer, trino, tsql, type-inference

## 简介

A TypeScript SQL parser and static analyzer: parse, resolve names, infer types, and trace column lineage across many SQL dialects (Databricks, T-SQL, Snowflake, BigQuery, Redshift, PostgreSQL, DuckDB, Trino, SQLite, MySQL).
