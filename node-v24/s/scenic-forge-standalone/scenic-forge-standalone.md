# scenic-forge-standalone

> 标签: csg, export, generative-art, html, path-tracing, sdf, single-file, standalone, webgpu, wgsl

## 简介

Turn a scenic-forge scene into one self-contained HTML file or React component: the compiled WGSL, a minimal WebGPU render loop, and nothing else.
