# solidvents-mcp

> 标签: dxf, mcp, perforation, solidvents, step, svg, vent

## 简介

Local MCP server for SolidVents: generate and export perforation / vent / texture patterns (SVG, DXF, STEP) from Claude, Cursor or any MCP client.

## 官网

- 官网：https://solidvents.com
- npm 页面：https://www.npmjs.com/package/solidvents-mcp
