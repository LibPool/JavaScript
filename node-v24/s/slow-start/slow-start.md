# slow-start

> 标签: backpressure, cold-start, express, fastify, guava, koa, leaky-bucket, middleware, nodejs, rate-limiter, rate-limiting, ratelimit, slow-start, smoothwarmingup, throttle, throttling, token-bucket, typescript, warm-up, warmup

## 简介

Warm-up rate limiter for Node.js and TypeScript: ramps up gradually after idle periods so cold caches and pools are not hit at full throughput. Guava SmoothWarmingUp, zero dependencies.
