# sei-logs-wrapper

> 标签: blockchain, eth_getLogs, ethereum, evm, logs, sei

## 简介

Extends the eth_getLogs function by batching calls and merging the responses. Handles unlimited block ranges and log counts through automatic pagination. Supports both Ethereum and Sei network log fetching methods.
