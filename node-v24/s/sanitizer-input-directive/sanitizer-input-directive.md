# sanitizer-input-directive

> 标签: JavaScript

## 简介

An easy-to-use Angular directive to sanitize user input based on customizable formats such as Alpha, Integer, Float, and even special character filters. Prevents unwanted characters from being typed, pasted, or auto-filled into input fields.
