# shikishi-astro-theme

> 标签: astro-theme, creative, editorial, gsap, portfolio, shikishi, tailwindcss

## 简介

Shikishi is an editorial Astro portfolio theme with mounted-paper layouts, Tailwind v4 styling, and GSAP motion.
