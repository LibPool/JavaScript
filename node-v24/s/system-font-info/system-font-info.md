# system-font-info

> 标签: coretext, directwrite, electron, font, font-enumeration, font-list, font-manager, font-metadata, fontconfig, fonts, installed-fonts, localized-names, napi, native-addon, node-addon, opentype, prebuilt, system-fonts, variable-fonts

## 简介

List installed system fonts with full metadata (localized names, supported languages, variable axes and named instances) through CoreText, DirectWrite and fontconfig. Prebuilt Node-API addon, no install-time compilation.
