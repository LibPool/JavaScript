# snk-data-grid

> 标签: JavaScript

## 简介

`snk-data-grid` es un componente de grid (tabla de datos) potente, reactivo y altamente personalizable para aplicaciones Angular. Ofrece funcionalidades avanzadas como filtrado tipo checklist (incluso en columnas agrupadas), ordenamiento, agrupación por a
