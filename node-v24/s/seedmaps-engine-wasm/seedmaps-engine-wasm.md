# seedmaps-engine-wasm

> 标签: biomes, cubiomes, minecraft, seed-finder, seed-map, structures, wasm, webassembly

## 简介

Minecraft Java-generation engine compiled to WebAssembly: Cubiomes-driven biomes, structures, spawn and the seed_engine.wasm bindings (single default context + thread-safe handle API).
