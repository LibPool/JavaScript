# shipworthy

> 标签: aws, claude-code, deploy, scanner, secrets, security, skill, vibe-coding

## 简介

Read-only security scanner for vibe-coded JS/TS apps, with a dry-run AWS deploy plan. Scans for the most common AI-generated-app security issues before deployment.
