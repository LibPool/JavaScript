# soundcheck-cli

> 标签: agent, deepgram, eval, regression, stt, testing, tts, voice, voice-agent

## 简介

Voice-agent test & tuning harness — Playwright + an LLM judge + a synthetic caller, for speech. Runs on a single Deepgram key.
