# sotai-engine

> 标签: anthropometry, avatar, gltf, human, procedural, skeleton, vrm

## 简介

Deterministic anthropometric base-body (素体) generator — dials → statistically correlated human skeleton, measurements and mesh → original VRM avatars. Realism first, stylization as a later dial.
