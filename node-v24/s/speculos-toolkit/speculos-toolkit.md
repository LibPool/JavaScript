# speculos-toolkit

> 标签: agent, ai, claude, codex, connectors, cursor, daytona, deploy, speculos, toolkit

## 简介

The Speculos toolkit for coding agents — deploy any frontend/backend to a live URL and build against your linked data connectors (BigQuery, Postgres, Snowflake, Salesforce, …). Built for Claude Code, Codex, Cursor, and friends.
