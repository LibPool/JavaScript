## 简介

See what the machine sees. Finds and decodes the text hiding in a file: invisible Unicode, ASCII smuggling, Trojan Source, homoglyphs, styled-out prompt injection, and per-recipient watermarks. Browser, CLI and CI. Zero dependencies.
