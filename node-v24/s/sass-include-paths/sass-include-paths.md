# sass-include-paths

> 标签: bower, bundle, bundler, components, gem, gems, import, include, load, nodejs, npm, package, path, paths, ruby, sass, scss

## 简介

Generates include paths for node-sass for packages from popular package managers like npm, bower, ruby gem, ruby bundler.
