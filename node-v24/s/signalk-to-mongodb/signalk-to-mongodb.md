# signalk-to-mongodb

> 标签: boating, cloud-storage, data-storage, marine, mongodb, nmea-2000, plugin, sailing, signalk, signalk-category-cloud, signalk-category-nmea-2000, signalk-category-utility, signalk-node-server-plugin, yachting

## 简介

SignalK plugin to store data to cloud hosted MongoDB URI. It provides an easy integration of SignalK server with MongoDB to log and store boat data in real-time.
