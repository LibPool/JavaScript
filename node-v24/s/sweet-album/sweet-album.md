# sweet-album

> 标签: gallery, image-viewer, justified-layout, lightbox, masonry, photo-album, photos, react, virtual-scroll, vue

## 简介

A framework-agnostic web photo album: justified layout, virtual scrolling, year/month/day drill-down, selection, favorites and a full-screen viewer. Works with vanilla JS, React and Vue.
