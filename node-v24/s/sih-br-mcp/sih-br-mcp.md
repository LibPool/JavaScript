# sih-br-mcp

> 标签: aih, ambulatory-care-sensitive-conditions, brasil, brazil, cid-10, csap, datasus, epidemiologia, hospital-admissions, icd-10, icsap, internacoes-hospitalares, mcp, mcp-server, saude-publica, sih, sih-sus, sus

## 简介

Servidor MCP do DATASUS SIH/SUS: internações hospitalares do Brasil (AIH, 1992–2025) — causas CID-10 e CID-9, séries mensais, ICSAP e taxas por UF e município, sem baixar .dbc nem usar TabNet. Brazilian hospital admissions (SIH/SUS) MCP server.
