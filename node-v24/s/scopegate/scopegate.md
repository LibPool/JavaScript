# scopegate

> 标签: audit-trail, claude-code, coding-agents, credentials, cursor, kimi-code, mcp, model-context-protocol, oauth, opencode, policy-engine, secrets-management, security

## 简介

Ephemeral credentials & persistent connections gateway for coding agents (Claude Code, Kimi Code, Cursor, OpenCode). The agent never holds secrets — it holds short-lived, minimum-scope capabilities.
