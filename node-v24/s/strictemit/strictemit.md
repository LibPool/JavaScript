# strictemit

> 标签: abortsignal, async-iterator, emitter, event-emitter, eventemitter, events, pubsub, tiny, typed, typescript

## 简介

Tiny, fully typed event emitter. Typed events and arguments, once, wildcard listeners, AbortSignal, waitFor() promises and async iteration. Zero dependencies, works everywhere.
