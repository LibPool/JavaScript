# signal-radar

> 标签: claude-code-plugin, email-triage, grok, influencers, jev, pi-package, tiktok, twitter, typesafe

## 简介

Read-only radar for X, TikTok, creators and email: TypeSafe Jev scores every item in ~0.5s, headless Grok explains only the top few, you get a digest. CLI, pi package and Claude Code plugin.
