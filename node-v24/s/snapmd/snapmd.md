# snapmd

> 标签: ai, cli, github, hackernews, html-to-markdown, llm, markdown, mcp, mcp-server, notion, obsidian, rag, reddit, stackoverflow, web-clipper, youtube-transcript

## 简介

Clip any webpage as clean, LLM-ready Markdown from your terminal. Supports YouTube, GitHub, Reddit, HN, StackOverflow. Includes MCP server for AI tool use.
