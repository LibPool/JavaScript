# semantic-state

> 标签: embeddings, hooks, on-device, react, semantic-search, state-management, transformers-js, web-worker

## 简介

Experimental React library: rank state by meaning, on-device. useSemantic() hooks, Web Worker embeddings, and a commit policy that keeps lists still while you use them.
