# sponsored-code

> 标签: ads, claude-code, developer-earnings, mcp, polygon, usdc

## 简介

An ad rides your Claude Code terminal. You get paid in USDC. Run `npx sponsored-code` — installs and runs the Sponsored Code CLI (@sponsored-code/cli).
