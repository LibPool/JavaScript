# slopstopper-mcp

> 标签: claude, code-review, mcp, model-context-protocol, production-readiness, security-scanner

## 简介

MCP server exposing SlopStopper's production-readiness scanner (security, reliability, observability, functional, accessibility gaps) as tools for Claude Desktop, Cursor, or any MCP-compatible AI tool.
