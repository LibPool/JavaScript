> 标签: antigravity, claude, convert pdf to markdown, document conversion, docx to markdown, epub to markdown, excel to markdown, markdown, mcp, modelcontextprotocol, ocr, pdf to markdown, powerpoint to markdown

## 简介

Convert PDF, Word, Excel, PowerPoint, OpenDocument, EPUB, images and audio to clean Markdown, locally. An MCP server for Claude, VS Code and Antigravity.
