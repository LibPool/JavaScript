# scd4x-node

> 标签: co2, i2c, scd40, scd41, sensirion, sensor

## 简介

Node.js library for [Sensirion SCD40 and SCD41](https://www.sensirion.com/search/products?q=SCD4x), the CO2, temperature, and humidity sensors.
