# ssh-persona

> 标签: accounts, cli, gh, git, github, gitlab, identity, includeif, macos, ssh

## 简介

Route SSH keys and gh accounts per repository on macOS — the right identity per project, chosen by git itself, with nothing global to switch. Installs the `sshid` command.
