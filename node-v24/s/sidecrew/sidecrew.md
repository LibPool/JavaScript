# sidecrew

> 标签: apple-silicon, claude-code, developer-tools, local-llm, mcp, mcp-server, mlx, mutation-testing, unit-tests

## 简介

Ask for a change to your source and get it — made by local MLX models on your Mac, checked by a gate a machine can run before Claude sees it. Unit tests too. MCP server + CLI.
