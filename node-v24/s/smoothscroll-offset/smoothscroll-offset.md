# smoothscroll-offset

> 标签: JavaScript

## 简介

A smooth scroll package almost entirely based off of the package found https://github.com/alicelieutier/smoothScroll but with the option to specify an offset pixel amount in case you want to have an absolutely positioned header or nav-bar or some other HT
