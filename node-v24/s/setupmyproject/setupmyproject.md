# setupmyproject

> 标签: boilerplate, cli, express, fullstack, react, scaffold, starter, tailwind, template, vite

## 简介

Interactive CLI to quickly scaffold Vite + React + Tailwind projects with optional Express backend. Supports frontend-only, backend-only, or full-stack setup.
