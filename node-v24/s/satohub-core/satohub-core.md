# satohub-core

> 标签: crypto, ed25519, mcp, onchain-agents, preflight, satohub

## 简介

Thin, zero-dependency client for the public Sato Hub surfaces — the scored onchain-agent index, Preflight, Sato Route and the Sato Bot build plan — with the Ed25519 response-signature verifier included.
