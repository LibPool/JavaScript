> 标签: africa, africastalking, messaging, otp, sdk, sendafrica, sms, tanzania, typescript

## 简介

Official TypeScript/JavaScript SDK for the SendAfrica Tanzania SMS API — send SMS, check credits, and top up with full type safety.
