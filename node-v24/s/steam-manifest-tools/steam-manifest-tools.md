# steam-manifest-tools

> 标签: JavaScript

## 简介

Tools to interact with Steam depots and manifests. - `mango download-chunks <depot id> <manifest id> [--lancache]` (basically the same as prefilling a LAN cache, optionally downloads from a LAN cache) - `mango populate-chunks <depot id> <manifest id> <i
