# smooth-stream-text

> 标签: ai-chat-ui, ai-ui, animation, headless, llm, llm-ui, react, smooth-streaming, stream-text, streaming-markdown, streaming-text, svelte, text-reveal, token-streaming, typewriter, vue, web-component

## 简介

Smooth out bursty LLM text streams and reveal them as a left-to-right wave. Headless core with zero dependencies, plus React, Vue, Svelte and Web Component wrappers.
