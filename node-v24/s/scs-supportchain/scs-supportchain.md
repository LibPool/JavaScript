# scs-supportchain

> 标签: api, automation, cli, npx, scs, skill, supply-chain, supportchain, 供应链

## 简介

SCS 供应链系统 CLI + Agent Skill 一体化包：npx scs-supportchain install 自动安装命令行与 AI Skill；内置登录、盘点、造数、审批、下单、体检等业务流程
