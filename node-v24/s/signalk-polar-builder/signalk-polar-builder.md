# signalk-polar-builder

> 标签: polar, sailing, signalk-category-navigation, signalk-node-server-plugin, signalk-webapp, vpp

## 简介

Self-expanding polar diagram builder for Signal K. Passively observes wind/speed data, detects steady-state sailing conditions, and accumulates a boat-speed-vs-TWS/TWA polar table over time.
