# singular-skill

> 标签: agent-skills, claude, claude-code, discovery, hooks, plugin, routing, skills, skills.sh

## 简介

Singular: a Claude Code plugin for per-prompt skill routing, stack detection, and gated, pinned, ephemeral discovery of third-party skills. `npm install -g singular-skill && singular install`, then type /singular in Claude Code.
