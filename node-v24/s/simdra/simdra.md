# simdra

> 标签: 2d, canvas, cloudflare-workers, edge, graphics, image, image-processing, sharp, simd, wasm, zig

## 简介

SIMD-accelerated 2D canvas and image manipulation, in a Worker. HTML5 Canvas API + sharp-shaped fluent surface. Cloudflare Workers, browsers, edge.
