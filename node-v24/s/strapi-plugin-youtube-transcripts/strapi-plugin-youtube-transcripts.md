# strapi-plugin-youtube-transcripts

> 标签: ai, captions, mcp, strapi, strapi-plugin, subtitles, transcript, transcripts, video, youtube

## 简介

Fetch, store, search and read YouTube transcripts in Strapi. Works on its own, and exposes AI tools when strapi-plugin-ai-sdk is installed.
