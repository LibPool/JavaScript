# svg-to-tsx-react-native-cli

> 标签: component, react, react-native, svg

## 简介

Based on svg-to-tsx-react-cli-cli. A command line utility that takes a svg image file and outputs a fully formatted stateless functional React Native component with `height` and `width` for props. With flags to toggle formatting and remove style attribute
