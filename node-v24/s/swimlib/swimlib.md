# swimlib

> 标签: cl2, ev3, hy-tek, hy3, hytek, meet manager, records, sd3, sdif, swimming, team manager, time standards

## 简介

Read and write common swimming data formats: SDIF (SD3/CL2), Hy-Tek HY3, EV3 event files, REC record files, and STD/ST2 time standards.
