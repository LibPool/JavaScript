# stl-oracle

> 标签: 3d-printing, cad, geometry, isomorphic, manifold, mesh, slicing, stl, surface-area, volume, watertight

## 简介

Parse, analyze, and compute geometric metrics for STL files (volume, surface area, bounding box, watertightness, and more). Works in Node and the browser.
