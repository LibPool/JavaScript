# session-prefix

> 标签: deepseek-harness, dsh, dsh-plugin, emoji, prefix, session, session-prefix, status, title, 会话状态, 标题前缀

## 简介

Visual session state badges for DeepSeek Harness: mark a session's project state by prefixing its title with customizable emoji or text badges (default wip 🚧, blocked ⏸️, review 👀, done ✅, plan 💡, bug 🐛), with configurable default state for new sessio
