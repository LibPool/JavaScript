# sso-frappe

> 标签: auth, frappe, login, next-auth, nuxt, oauth, oidc, react, spa, sso, vue

## 简介

Reusable OAuth2/OIDC client for adding 'Login with Frappe' to any Next.js, React, Vue, Nuxt, or Node.js project.
