# scp-cf-destination

> 标签: JavaScript

## 简介

A package to be used as express middleware to make a connection to the connectivity service of the Cloud Foundry SAP Cloud Platform (SCP) with the on-premise SAP backend system. The destination service is being used to retrieve the virtual host<br> Axios
