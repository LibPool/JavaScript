# super-image-cropper

> 标签: angular, animated-gif, animation, browser, canvas, crop, cropper, cropperjs, frontend, gif, gif-cropper, image, image-cropping, image-editor, image-manipulation, image-processing, javascript, jpeg, jpg, photo-editor, png, react, typescript, vue, web, web-components

## 简介

A powerful JavaScript image cropping library that supports GIF animations, PNG, JPG and other formats with CropperJS integration. Perfect for web developers who need to crop animated GIFs while preserving animation quality.
