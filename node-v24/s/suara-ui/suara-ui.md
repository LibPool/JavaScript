# suara-ui

> 标签: JavaScript

## 简介

Shared, presentational React UI components (Header, Footer, FAQ accordion) used across Suara's HubSpot CMS React projects. Framework-agnostic beyond React + Tailwind naming conventions — not tied to HubSpot.
