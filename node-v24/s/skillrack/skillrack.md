# skillrack

> 标签: agent, ai, claude-code, cli, codebuddy, cursor, prompt, scaffold, skill, skills

## 简介

Agent skill rack — 交互式选择 77 个 agent，一条命令把 Markdown 技能装进 CodeBuddy / Claude Code / Codex / Cursor 等宿主。Zero dependency, Node 18+.
