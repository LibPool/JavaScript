# shipstatic-cli

> 标签: cli, deploy, sdk, shipstatic, static-hosting

## 简介

CLI and SDK for ShipStatic. Deploy static websites, landing pages, and prototypes instantly from the terminal or code. The unscoped name for @shipstatic/ship.
