# skill-image

> 标签: ai, architecture, claude-code, claude-skill, design, diagram, explode, fmode, image, presentation, product, scene

## 简介

Claude Code skill + CLI: AI 图像生成器。7 种模式（--app/--arch/--explode/--product/--scene/--detail/--slide），零依赖纯 ESM，自动读 API Key，白底 PNG 可直接拖入 PPT。
