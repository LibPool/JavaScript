# sm-polyfill

> 标签: chinese, cryptography, gm, nodejs16, openssl, polyfill, sm2, sm3, sm4, 国密

## 简介

SM2/SM3/SM4 polyfill for Node.js 16 and earlier. Provides SM2 signing/verification using sm-crypto when native OpenSSL support is unavailable.
