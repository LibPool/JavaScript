# sagedesk

> 标签: ai, chat, chatbot, customer-support, embeddings, faq, floating-chat, help-widget, knowledge-base, local-ai, nextjs, nlp, no-api-key, offline, privacy, rag, react, semantic-search, support, support-widget, transformers, vanilla-js, vector-search, wasm, web-component, webassembly, widget

## 简介

RAG-powered support widget for any website. Local mode: in-browser search with no API key. LLM mode: synthesized answers via your own backend.
