# solution-remove

> 标签: JavaScript

## 简介

Tool to remove solution-marked codesnippets from all `*.js`, `*.jsx`, `*.java`, `*.html`, `*.rest`, `*.htm` and `*.md` files in a folder (including subfolders, ignoring `node_modules`). These are the default settings.
