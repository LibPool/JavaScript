# scrutari

> 标签: cli, cli tool, crawler, javascript library, link gatherer, scrape, scraping, sitemap, url gatherer, web crawler, website crawler

## 简介

A website crawler gathers URLs with the same origin on a site. Available as both a CLI tool and a JavaScript library.
