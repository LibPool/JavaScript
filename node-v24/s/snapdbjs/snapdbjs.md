# snapdbjs

> 标签: cache, database, ephemeral, fast, feature-flag, in-memory, lightweight, middleware, nodejs, nosql, npm-package, otp, plugin, rate-limiting, redis, session, token, ttl, typescript

## 简介

A fast, lightweight, Redis-like in-memory database for Node.js with plugin and middleware support. Perfect for ephemeral data, rate limiting, OTPs, tokens, and more.
