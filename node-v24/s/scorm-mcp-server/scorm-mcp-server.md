# scorm-mcp-server

> 标签: claude, e-learning, lms, mcp, mcp-server, offline, scorm, scorm-2004

## 简介

MCP server: turn self-contained HTML, a Claude Design (.dc) bundle or a mobile-learning platform content export into a SCORM 2004/1.2 package any LMS can import — offline assets, milestone/score tracking, bundled ADL schemas.
