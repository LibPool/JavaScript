# synthcore-mcp

> 标签: agent-tools, deterministic, mcp, model-context-protocol, program-synthesis, synthcore

## 简介

MCP server for Synthcore — gives any agent (Claude, Cursor, …) a deterministic, verified, $0 tool to synthesize small data-transform functions from input→output examples.
