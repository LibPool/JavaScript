# secret-sniff

> 标签: api-key, credentials, redact, scanner, secrets, security

## 简介

Scan text for credentials and API keys (AWS, GitHub, Stripe, OpenAI, Anthropic, JWT, PEM, ...). Zero dependencies. Format-anchored — not entropy-guessing.
