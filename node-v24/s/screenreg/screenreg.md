# screenreg

> 标签: authorship, bitcoin, c2pa, copyright, cryptography, merkle, opentimestamps, provenance, registration, screenplay, screenwriting, timestamp

## 简介

Reference implementation of The Screenplay Registry — a free, open, cryptographically verifiable timestamp for screenplays anchored to Bitcoin via OpenTimestamps.

- 源码仓库：git+https://github.com/screenplay-registry/screenreg.git
