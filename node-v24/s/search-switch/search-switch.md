# search-switch

> 标签: aggregations, analytics, elasticsearch, meilisearch, opensearch, search, typescript

## 简介

Backend-agnostic search & analytics data layer — one generic API over OpenSearch today, Elasticsearch / Meilisearch / others later. Switching backends is a config change, not a rewrite.
