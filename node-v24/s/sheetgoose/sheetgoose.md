# sheetgoose

> 标签: browser, database, database-client, google, google-sheets, mongoose, nodejs, nosql, orm, sheets, spreadsheet, typescript

## 简介

Use Google Sheets as a database with Mongoose-like syntax. Works in both browser and Node.js.
