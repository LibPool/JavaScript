# strictdb

> 标签: ai, database, elasticsearch, mcp, mongodb, mssql, mysql, orm-alternative, postgresql, sqlite, unified

## 简介

One unified API for MongoDB, PostgreSQL, MySQL, MSSQL, SQLite, and Elasticsearch. AI-first database driver with guardrails, self-correcting errors, and schema discovery.
