> 标签: api-key, bucket, cli, cloudflare-r2, express, fastify, file-upload, filesystem, hono, image-resize, metadata-index, minio, mongodb, multipart-upload, object-storage, postgres, presigned-url, r2, rest-api, s3, sharp, sqlite, storage, thumbnails, upload

## 简介

Unified, driver-agnostic object storage for Node.js. One API for S3, R2, MinIO, the local filesystem and memory, with a queryable catalog, image transforms and a REST server.
