# splithub-ab-testing

> 标签: a/b-testing, ab-testing, analytics, client-side, conversion-optimization, cro, experiment, google-analytics, redirect, split-testing, splithub, variant

## 简介

A lightweight A/B testing library for client-side split testing. Supports redirect and DOM-edit test types with page-specific triggering, persistent variant assignment, and Google Analytics integration.
