# statless-telemetry

> 标签: analytics, cli, cookie-free, developer-tools, do-not-track, eprivacy, gdpr, instrumentation, node, npm, opt-out, privacy, privacy-first, self-hosted, statless, telemetry, usage-analytics

## 简介

Zero-dependency, cookie-free usage telemetry for developer CLIs and npm packages. Opt-out aware, pseudonymous rotating hashes, works standalone or self-hosted.
