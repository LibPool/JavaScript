# supcpu

> 标签: cli, gpt, mcp, nanogpt, onnx, onnxruntime, small-language-model

## 简介

sup — run sup computer's tiny GPTs in your terminal, or serve them to an agent over MCP. Downloads a release's public artifacts and runs it on onnxruntime-node.
