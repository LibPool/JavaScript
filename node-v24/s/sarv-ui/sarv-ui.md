# sarv-ui

> 标签: components, design-system, sarv-ui, tailwind-plugin, tailwindcss, theme, tokens, ui-library

## 简介

Sarv UI – A minimal, theme-aware UI component library for Tailwind CSS v4. Includes design tokens, ready-to-use components, and theme support.
