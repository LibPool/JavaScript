# spatial-plugin-grid

> 标签: JavaScript

## 简介

A React 18/19 plugin-agnostic viewport layout library. Every plugin declares named states, footprints, transitions and an anchor alignment; the host chooses compatible placement. Expansion overlays neighbors without reflow. The default is an empty three-r
