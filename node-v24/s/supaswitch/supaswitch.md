# supaswitch

> 标签: account, cli, keychain, multi-account, profiles, supabase, supabase-cli, switcher

## 简介

Per-repo Supabase account switching for humans and coding agents — named tokens in the macOS Keychain plus a transparent supabase shim, so parallel repos use different accounts without supabase login
