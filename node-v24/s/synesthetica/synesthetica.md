# synesthetica

> 标签: claude, cli, mcp, mcp-server, music-visualisation, synesthetica

## 简介

Real-time music visualiser + MCP server. Listens to MIDI or audio, draws it in a Western-music-theory visual language, and exposes the whole thing to Claude Desktop for natural-language control.
