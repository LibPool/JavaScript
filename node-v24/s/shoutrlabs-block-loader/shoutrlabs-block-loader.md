# shoutrlabs-block-loader

> 标签: JavaScript

## 简介

This script is used by the `Webclient` and some `Blocks`-Packages to load the actual Vue-Components of the `Blocks`.

- npm 页面：https://www.npmjs.com/package/shoutrlabs-block-loader

- npm registry：https://registry.npmjs.org/shoutrlabs-block-loader
- Node 要求：>=10
