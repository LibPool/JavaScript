# sentvia-mcp

> 标签: agent-tools, ai-agents, claude, email, email-api, inbox, mcp, mcp-server, model-context-protocol, openclaw, sentvia, smtp, transactional-email

## 简介

MCP server for SentVia — email infrastructure for AI agents. Create inboxes, send and reply, search, manage threads, webhooks and allow/block rules as native agent tools.
