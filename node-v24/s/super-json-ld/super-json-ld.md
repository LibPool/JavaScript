# super-json-ld

> 标签: json-ld, jsonld, nextjs, react, rich-results, schema-dts, schema.org, seo, structured-data

## 简介

Tiny, configurable JSON-LD (schema.org) builders for the web, with an optional React component. Framework-agnostic core, typed with schema-dts.
