> 标签: sanity, sanity-plugin

## 简介

The Shared Notes Notepad Plugin is a lightweight, non-intrusive addition to Sanity Studio that provides a convenient shared notepad functionality for team collaboration. Features: Seamless Integration: Adds a collapsible notepad interface to your Sanity S
