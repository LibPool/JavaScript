# simple-ng-loader

> 标签: 9, Interceptor, Scss, angular-loader, angular9.0, http, http-loader, httpLoader, loader, simple-ng-loader, spinner

## 简介

This package intercept your http request and shows the loader for you on each request and is in beta version. This project was generated with [Angular CLI](https://github.com/angular/angular-cli) version 9.0.0.
