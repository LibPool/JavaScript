# svgttf

> 标签: convert, design, font, svg, ttf

## 简介

NodeJS library to extract SVG outline pathdata from OpenType fonts and to convert SVG drawings to fonts

## 官网

- 官网：https://github.com/loveencounterflow/svgttf
- 源码仓库：https://github.com/loveencounterflow/svgttf.git
- npm 页面：https://www.npmjs.com/package/svgttf
