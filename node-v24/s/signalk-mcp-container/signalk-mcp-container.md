# signalk-mcp-container

> 标签: mcp, model-context-protocol, signalk-category-ai, signalk-node-server-plugin, signalk-plugin-configurator

## 简介

SignalK plugin that runs signalk-mcp-server as a managed container, exposing marine data to MCP clients (e.g. Claude) over the network.
