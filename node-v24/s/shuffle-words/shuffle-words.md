# shuffle-words

> 标签: algorithm, benchmarking, combinatorics, efficient, equally, finite, fisher, fixtures, knuth, letters, permutation, random, randomize, randomizer, randomly, replacement, samples, set, shuffle, shuffled, shuffling, string, terms, test, unbiased, word, words, yates

## 简介

Shuffle the words in a string and optionally the letters in each word using the Fisher-Yates algorithm. Useful for creating test fixtures, benchmarking samples, etc.
