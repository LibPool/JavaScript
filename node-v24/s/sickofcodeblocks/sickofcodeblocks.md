# sickofcodeblocks

> 标签: ansi, cli, clipboard, email, nerd-fonts, plain-text, redact, sanitize, slack, strip-ansi, terminal, tty

## 简介

Convert raw terminal/CLI output into clean plain text for pasting into email, Slack, and docs — no screenshots, no code blocks.
