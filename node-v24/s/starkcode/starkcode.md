# starkcode

> 标签: agent, json-schema, pipeline, protocol, starkcode, starkgate, validation, verification

## 简介

StarkCode protocol — versioned JSON Schema contracts + gates for agent pipelines (DAG, classification, diff, mutation, arbitration). No LLM, no generation, no agent hosting. Product of the StarkCore platform.
