# spectre.db

> 标签: cache, database, discord, discord-bot, file-based, json, key-value, lightweight, lru, no-dependencies, nodejs, storage, wal

## 简介

A lightweight, production-grade file-based JSON database for Node.js. Zero dependencies, WAL-based persistence, LRU cache, atomic writes, and optional AES-256 encryption.
