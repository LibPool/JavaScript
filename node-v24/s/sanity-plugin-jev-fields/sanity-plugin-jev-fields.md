# sanity-plugin-jev-fields

> 标签: ai, ai-gateway, jev, sanity, sanity-plugin, typesafe

## 简介

Jev questions for Sanity Studio: AI-evaluated yes/no, score and choice answers attached to a field, from TypeSafe's Jev model through Vercel AI Gateway
