# stm32f4-emu

> 标签: arm, cortex-m4, embedded, emulator, firmware, stm32, stm32f407, wasm

## 简介

STM32F407 emulator: Rust CPU + peripheral model (WASM). Runs real Cortex-M4 firmware in Node or the browser.
