# socketio-kit

> 标签: express, express-middleware, react, react-hooks, realtime, sdk, socket.io, socket.io-client, socket.io-server, typescript, websocket

## 简介

Developer-friendly Socket.IO SDK wrapper for Client & Express Server with type-safety, room helpers, React hooks, and automatic cleanup.
