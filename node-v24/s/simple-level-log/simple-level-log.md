> 标签: auto, based, console, debug, easy, error, info, lambda, level, logging, on, serverless, simple, stringify, trace, verbose, warn

## 简介

Simple easy to use level logger based on standard JavaScript Console logging methods. Developers can control log output based on current log level as well as individual control flags. Super useful for local as well as cloud applications. Automatically str
