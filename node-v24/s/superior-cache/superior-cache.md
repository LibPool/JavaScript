# superior-cache

> 标签: cache, cluster, deduplication, distributed, invalidation, lru, multi-layer, pubsub, redis, stampede, typescript

## 简介

Production-grade distributed caching system for Node.js with multi-layer cache, request deduplication, stampede protection, tag-based invalidation, background refresh, clustering support, and observability.
