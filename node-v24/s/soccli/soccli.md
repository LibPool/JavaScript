# soccli

> 标签: cli, graphql, json-rpc, mqtt, pusher, reverb, signalr, socket.io, stomp, subscriptions, wamp, websocket

## 简介

Terminal-first real-time protocol CLI for WebSocket, Pusher/Reverb, Socket.IO, GraphQL, JSON-RPC, STOMP, SignalR, MQTT, and WAMP.
