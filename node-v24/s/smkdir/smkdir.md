# smkdir

> 标签: JavaScript

## 简介

快速在指定目录下创建指定数量的文件夹; 新加入命名功能，见语法 ##语法     var mk = require("smkdir")     mk("e:",3)//随机数名     或：     var mk = require("smkdir")     mk("e:",5,["we","are","fighting"])//最后两个以随机数命名
