# signalk-rpi-stats

> 标签: cpu, monitoring, raspberry-pi, signalk-category-hardware, signalk-category-utility, signalk-node-server-plugin, temperature

## 简介

Signal K plugin publishing Raspberry Pi system stats: CPU temperature/utilisation/frequency, core voltage, memory, storage, uptime, load average, and throttling/under-voltage detection
