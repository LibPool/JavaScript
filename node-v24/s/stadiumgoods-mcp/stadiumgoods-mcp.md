# stadiumgoods-mcp

> 标签: mcp, resale, sneakers, stadium-goods, streetwear

## 简介

Query the Stadium Goods catalog (stadiumgoods.com, NYC): search sneakers and streetwear, newest arrivals, enriched product details (sizes), price stats, below-median deals, and category counts.
