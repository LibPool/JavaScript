# screenshots-pagepixels

> 标签: API, Multi-Step, Scheduled, Screenshot, Screenshots

## 简介

Take immediate screenshots, create scheduled screenshots, take multi-step screenshots (click links, complete forms, login to websites), and get change notifications using the PagePixels Screenshot API python wrapper.
