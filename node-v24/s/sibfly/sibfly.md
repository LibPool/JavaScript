# sibfly

> 标签: geospatial, ground-motion, insar, nasa, opera, sentinel-1, sibfly, subsidence

## 简介

Zero-dependency client for the SibFly ground-motion API — satellite-measured land subsidence/uplift (mm/yr) for any US address
