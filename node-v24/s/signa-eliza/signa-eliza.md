# signa-eliza

> 标签: agent, ai-agent, ai16z, base, decentralized, eliza, elizaos, ethereum, signa, wallet-signed

## 简介

ElizaOS plugin for SIGNA — give any Eliza agent a wallet-signed inbox on Base. Cross-platform DMs, hold-to-chat ERC-20 gated rooms, federated identity.
