# splitted-url

> 标签: domain, domain name extract, external url, external url checker, external-url, host, hostname, is external url, maindomain, split-url, subdomain, sud domain extractor, url-spit

## 简介

Use to identify (extract) main domain and hostname from a url. We can also use it as external url checking by comparing domain variable in the result.
