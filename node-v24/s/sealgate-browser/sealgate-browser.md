# sealgate-browser

> 标签: conditional-ui, fido2, passkey, sealgate, webauthn

## 简介

Browser SDK for SealGate. Runs passkey (WebAuthn) registration and login in the browser and relays them to the SealGate API through your server

## 官网

- 官网：https://sealgate.jp/docs#sdk
