# structdoc-mcp

> 标签: document, invoice, layout, markdown, mcp, modelcontextprotocol, ocr, pdf, rag, receipt, x402

## 简介

MCP server for StructDoc — turn any document (PDF/image) into structured data for AI agents: OCR, layout-to-Markdown, tables, invoice/receipt fields. Pays per call via x402 (USDC on Base/Solana) — no API keys.
