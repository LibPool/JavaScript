# stemem

> 标签: agent, emotion, identity, local-first, mcp, memory, persona, soulspec, tone

## 简介

Stemem — local-first identity-layer runtime for AI agents (MCP server). JOJO&Adam group product. Lets any MCP host give an agent a personality that grows across sessions and survives context compaction.
