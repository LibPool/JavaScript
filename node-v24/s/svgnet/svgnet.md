# svgnet

> 标签: customizable, d3-alternative, dark-theme, force-directed, graph, interactive, light-theme, mobile-first, modular, network, network-graph, node-link-diagram, physics, responsive, svg, theming, touch-gestures, typescript, visualization, zero-dependencies

## 简介

Modern SVG graph visualization library with advanced theming, mobile-first design, and customizable physics simulation. Features dynamic node/edge styling, touch optimization, and zero dependencies.
