# stabilize-orm

> 标签: bun, cache, cursor-pagination, database, hooks, knex, migration, mysql, optimistic-locking, orm, pagination, postgres, postgresql, prisma, query-builder, redis, seeding, soft-delete, sqlite, transactions, type-safe, typeorm, typescript

## 简介

A modern, type-safe ORM for Bun and Node.js with support for SQLite, MySQL, PostgreSQL, SQL Server and MongoDB, Redis caching, optimistic locking, cursor pagination, and a full-featured query builder.
