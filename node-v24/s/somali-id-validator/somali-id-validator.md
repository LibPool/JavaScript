# somali-id-validator

> 标签: NIRA, arabic, cli, id, kaarka aqoonsiga, national-id, privacy, somalia, trilingual, validation, validator

## 简介

Validate Somali National ID fields with enhanced date formats, trilingual support (English/Somali/Arabic), interactive CLI, batch processing, and privacy helpers. Performance optimized with comprehensive error handling.
