# s3-release

> 标签: JavaScript

## 简介

A tool for packaging npm modules and uploading them to S3. Useful for deploying closed-source npm modules.

## 官网

- 源码仓库：git://github.com/ccare/s3-release.git
- npm 页面：https://www.npmjs.com/package/s3-release
