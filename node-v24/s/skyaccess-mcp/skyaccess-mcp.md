# skyaccess-mcp

> 标签: charter, claude, cursor, empty-legs, mcp, modelcontextprotocol, private-jet, skyaccess

## 简介

Hosted SkyAccess MCP server for private jet empty legs: installer for Claude, Cursor and other MCP clients, plus a stdio bridge.

- 官网：https://skyaccess.com
- 源码仓库：git+https://github.com/sky-access/skyaccess-mcp.git
- npm 页面：https://www.npmjs.com/package/skyaccess-mcp
