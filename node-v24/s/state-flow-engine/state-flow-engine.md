# state-flow-engine

> 标签: finite-state-machine, fsm, immutable, lifecycle-hooks, state-machine, state-management, type-inference, typescript, workflow, zero-dependency

## 简介

A TypeScript-native, zero-dependency Finite State Machine with declarative schemas, advanced type-inference, lifecycle hooks, and immutable state for eliminating state explosion in complex workflows.
