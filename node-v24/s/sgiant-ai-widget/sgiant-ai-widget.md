# sgiant-ai-widget

> 标签: ai, assistant, chat, chatbot, embeddable, llm, no-framework, streaming, vanilla, widget

## 简介

Framework-agnostic embeddable AI chat widget. One call mounts a streaming chat bubble into any page — no React, no framework, themeable.
