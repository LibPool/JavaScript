# signalk-meshcore

> 标签: ais, freeboard-sk, lora, mesh, meshcore, meshtastic, signalk-category-instruments, signalk-node-server-plugin, telemetry

## 简介

SignalK plugin for MeshCore LoRa mesh radio — connects via TCP/WiFi or USB serial, decodes #TEL: telemetry, and publishes nodes as AIS-style vessel targets with tracks in freeboard-sk.
