# softke-js

> 标签: softke, softke-js

## 简介

- isNonnegativeNumber 非负数 - bindDataByObject 把源对象值绑定到目标对象 - formatCurrencyNo 逗号分隔返回保留两位小数 - numberToCurrencyNo 数字转换空返回 0 - decimalToCurrencyNo 数字转换 空返回 0.00
