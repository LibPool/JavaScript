# semctx

> 标签: blast-radius, bun, change-impact, ci-gate, claude-code, contracts, git-diff, invariants, mcp, typescript, verify

## 简介

Deterministic, local-first repository change-impact analyzer: computes the semantic blast radius of a git diff and enforces contracts and invariants (PASS/WARN/BLOCK). Not a code-search replacement (ADR 0005).
