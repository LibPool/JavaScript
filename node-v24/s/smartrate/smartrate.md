# smartrate

> 标签: distributed-rate-limiter, fixed-window, middleware, nodejs, rate-limit, rate-limiter, rate-limiting, redis, sliding-window, throttle, token-bucket

## 简介

A Node.js rate limiter with fixed window, token bucket, sliding window algorithms, in-memory storage, and Redis-backed distributed rate limiting.
