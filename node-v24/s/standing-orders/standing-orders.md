# standing-orders

> 标签: agent-orchestration, agents, ai-agents, autonomous-agents, claude-code, cli, codex, control-plane, git-worktree, llm, openrouter, orchestration, task-queue, telegram, unattended

## 简介

A control plane for unattended coding agents — queue tasks, walk away, come back to pull requests. Agents build in leased worktrees, never touch your default branch, and interrupt you only for decisions that need a human.
