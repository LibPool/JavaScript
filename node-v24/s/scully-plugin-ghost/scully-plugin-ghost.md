# scully-plugin-ghost

> 标签: JavaScript

## 简介

> **scully-plugin-ghost** is a small small router plugin for [scully](https://scully.io/) to retrieve **posts** content from your [Ghost](https://github.com/TryGhost/Ghost) headless CMS.
