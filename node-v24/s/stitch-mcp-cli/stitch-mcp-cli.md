# stitch-mcp-cli

> 标签: ai-coding, antigravity, claude-code, cli, codex, cursor, design-to-code, google-stitch, mcp, model-context-protocol, opencode, scaffolding, stitch, ui-design, vscode, zed

## 简介

Google Stitch MCP server + CLI: export UI designs to React, Vue, Svelte, Next.js and 5+ frameworks, with auto-config for Cursor, Claude Code, OpenCode, Antigravity, Zed and VS Code.
