# serbitone-design-system-installer

> 标签: JavaScript

## 简介

🚀 **Serbitone Design System Installer** is a CLI tool that helps you quickly set up the Serbitone Design System in your project. You can choose between the **Default Theme** (bundled CSS) or a **Custom Theme** (CSS excluded, fully customizable).
