# scrapeloop-mcp

> 标签: b2b, cold-email, email-verification, leads, mcp, model-context-protocol, scrapeloop

## 简介

Scrapeloop MCP server  -  set up and run Scrapeloop end-to-end (integrations, scraping, lead database, verification, cleaners, enrichment, strategies, Instantly campaigns) from any MCP client (Claude Desktop, Cursor, ChatGPT, …).
