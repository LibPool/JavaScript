# stackscope

> 标签: analytics, automatic-capture, browser-sdk, cloudflare-workers, console-logs, core-web-vitals, error-tracking, logging, monitoring, network-requests, observability, performance-metrics, real-time, telemetry, typescript, user-interactions, zero-config

## 简介

📊 Zero-config browser SDK for automatic log capture - console, network requests, user interactions, performance metrics, Core Web Vitals. Sends to your own Cloudflare Worker. Full TypeScript support.
