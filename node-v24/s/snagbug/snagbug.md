# snagbug

> 标签: bug-report, feedback, github-issues, in-app, screenshot, widget

## 简介

In-app bug & idea capture widget — a keyboard shortcut opens a small overlay that grabs a screenshot, the current view and console errors, and lets you point at a DOM element or drag a region, then files it as a GitHub issue. Framework-agnostic and shadow
