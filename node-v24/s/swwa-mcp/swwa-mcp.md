# swwa-mcp

> 标签: a11y, accessibility, korean, kwcag, mcp, model-context-protocol, wcag

## 简介

KWCAG 2.2(한국형 웹 콘텐츠 접근성 지침)·웹 접근성 품질인증 기준으로 웹 콘텐츠의 접근성을 검사·리뷰·인증 준비하도록 돕는 MCP 서버. 오프라인 결정적 도구(정적 jsdom+axe-core, 선택적 브라우저 감사)를 제공한다.
