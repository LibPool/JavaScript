# serverasmcp

> 标签: ai-agents, claude, cloudflare, codex, cursor, deploy, deployment, devops, dns, linux, mcp, mcp-server, model-context-protocol, production, remote-execution, root-access, self-healing, server-management, serverasmcp, ssh, systemd

## 简介

MCP server that gives AI agents unrestricted root SSH access to unlimited Linux servers. Execute any command, deploy files, configure Cloudflare DNS, and self-heal deployments until production is live.
