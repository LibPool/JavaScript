# sheetq

> 标签: google-sheets, googleapis, gviz, orm, query, service-account, sheets, spreadsheet, typescript

## 简介

Typed, server-side query layer for Google Sheets — model a sheet like a tiny ORM: gviz-powered search, type-safe read & write.
