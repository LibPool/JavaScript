# sesame-kit

> 标签: ble, candy-house, cli, json-rpc, sesame, smart-home, smart-lock

## 简介

Control your SESAME smart lock from your own code — even directly over Bluetooth, offline. BLE + cloud, CLI, Node library, and a JSON-RPC server for any language. Hub3 IR, device management. Unofficial.
