# strata-payments-kit

> 标签: JavaScript

## 简介

Verified Stripe payment pipeline: webhook signature verification, canonical event normalization, purchase-confirmation email, background receipt generation. Thin wrappers over stripe, nodemailer, bullmq and pdfkit.
