# strapi-plugin-cron-lock

> 标签: cron, distributed-lock, horizontal-scaling, kubernetes, lock, redis, scheduler, strapi, strapi-plugin

## 简介

Distributed lock for Strapi 5 cron jobs. Prevents duplicate execution when running multiple instances.
