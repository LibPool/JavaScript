> 标签: animation, custom-elements, dom, frontend, history, javascript, lifecycle, lightweight, navigation, stackview, transitions, typescript, ui, view-management, web, web-components, zero-dependencies

## 简介

A lightweight TypeScript library for managing DOM history with smooth transitions and view chaining. Pure JavaScript implementation without external dependencies.
