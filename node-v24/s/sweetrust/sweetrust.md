# sweetrust

> 标签: agent-orchestration, ai-agents, audit-log, capability-security, ed25519, evidence, hash-chain, information-flow-control, mandate, prompt-injection, provenance, receipts, taint-tracking, trust-tiers, verification

## 简介

Trust rails for AI agents: issue authority, enforce it, prove what happened. Ed25519-signed mandates, provenance-tiered values with fail-closed sinks, and receipt chains a stranger can verify. Zero runtime dependencies.
