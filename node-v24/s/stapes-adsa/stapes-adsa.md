# stapes-adsa

> 标签: adsa, ai-agent, ast, cli, fast-path, git-hooks, linter, logging, npx, observability, pre-commit, slow-path, stapes, static-analysis, ts-morph, typescript, zero-config

## 简介

AST-based ADSA (Adaptive Dual-System Architecture) linter for TypeScript. Flags slow paths without logging, fast paths doing I/O, decision points without routing, async boundaries missing the adsa_path log line, and invalid {adsa_path, adsa_area} shapes.
