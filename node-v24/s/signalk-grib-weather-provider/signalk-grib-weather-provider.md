# signalk-grib-weather-provider

> 标签: forecast, gfs, grib, grib2, marine, signalk, signalk-category-weather, signalk-node-server-plugin, weather

## 简介

Signal K Weather API provider serving local GRIB2 files (GFS, Arpège, Arome, ICON) — each source becomes a selectable weather provider
