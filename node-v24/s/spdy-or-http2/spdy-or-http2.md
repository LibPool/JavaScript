# spdy-or-http2

> 标签: http, http2, https, polyfill, ponyfill, spdy

## 简介

Node.js ponyfill for HTTP/2 support (uses native http2 module or falls back to spdy if Node version is < v10.10.0; when http2 is marked as no longer experimental)
