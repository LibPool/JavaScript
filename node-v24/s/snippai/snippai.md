# snippai

> 标签: ai, groq, monid, nvidia, openrouter, screen-capture, snipping-tool, tinyfish, vision

## 简介

SnipAI — AI Screen Assistant for Windows. Press hotkey, drag to select any screen region, get instant AI analysis. Free search via TinyFish (Monid).
