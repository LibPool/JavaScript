# syntropylog-native

> 标签: logging, masking, napi-rs, native-addon, observability, pii-masking, rust, sanitization, serialization, syntropylog

## 简介

Native Rust engine for SyntropyLog (napi-rs): serialize + PII mask (declarative MaskSpec) + sanitize in a single pass. Optional — SyntropyLog transparently falls back to a parity-tested pure-JS engine when no prebuilt binary is available.
