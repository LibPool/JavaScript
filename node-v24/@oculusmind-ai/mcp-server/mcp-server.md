# @oculusmind-ai/mcp-server

> 标签: a2a, agents, claude-code, mcp, model-context-protocol, oculusmind

## 简介

MCP server exposing OculusMind.AI agents (Uno, Vera, Maximus) as tools for Claude Code and other MCP hosts, over the A2A protocol.
