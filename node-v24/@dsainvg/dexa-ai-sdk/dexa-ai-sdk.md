# @dsainvg/dexa-ai-sdk

> 标签: decide, dexa-ai-sdk, extract, fern, llm, openapi, sdk, typescript

## 简介

Dexa is the TypeScript client for the Decide + Extract API. Run decide and extract tasks against one context in a single request.
