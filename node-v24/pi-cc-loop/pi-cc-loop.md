# pi-cc-loop

> 标签: claude-code, cron, extension, loop, pi-package, scheduler

## 简介

Claude Code compatible /loop for the Pi coding agent: cron-scheduled fixed intervals, self-paced chains, and the same dispatch semantics as Claude Code.
