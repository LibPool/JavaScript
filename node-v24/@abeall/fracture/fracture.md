# @abeall/fracture

> 标签: animation, bookmarklet, break, dom, easter-egg, effect, fracture, glass, react, shards, shatter, three, webgl

## 简介

Shatter DOM elements into slow-motion 3D shards with depth-of-field blur. Pure fracture algorithm, element API, React hooks, an easter egg, and a fracture-any-page extension.
