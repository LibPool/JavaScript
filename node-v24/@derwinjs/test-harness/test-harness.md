# @derwinjs/test-harness

> 标签: JavaScript

## 简介

End-to-end lifecycle test harness for the Derwin platform — bootstraps a real Postgres + real runners + replayed Anthropic + the broken-fixture, runs the full DETECT → INVESTIGATE → TICKET → CLASSIFY → AUTHOR → VERIFY-PRE → DISPATCH → VERIFY-POST → ARCHIV
