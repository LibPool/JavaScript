# @doubao-apps/taro-runtime

> 标签: JavaScript

## 简介

`@doubao-apps/taro-runtime` 提供 Doubao Apps 场景下的 Taro 运行时适配层。 通常由 `@doubao-apps/taro-plugin` 在构建时自动接入，你也可以在需要时手动引用对应导出。
