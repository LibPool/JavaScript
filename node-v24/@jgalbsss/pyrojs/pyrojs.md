# @jgalbsss/pyrojs

> 标签: animation, canvas, celebration, confetti, effect-ts, fireworks, particle-system, particles, react, react-confetti

## 简介

A fireworks engine for the web — like react-confetti, but fireworks. 68 firework types, image/SVG/text fireworkify, a one-line React overlay, and an Effect-TS choreography DSL. Tiny, fast, and tree-shakeable.
