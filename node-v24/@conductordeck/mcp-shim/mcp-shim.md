# @conductordeck/mcp-shim

> 标签: ai, automation, claude, conductor-deck, elgato, mcp, model-context-protocol, stream-deck

## 简介

stdio→HTTP proxy that lets Claude Desktop, ChatGPT, Cursor, and Zed connect to the Conductor Deck MCP server running on localhost:47823.
