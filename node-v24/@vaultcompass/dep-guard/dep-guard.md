# @vaultcompass/dep-guard

> 标签: cli, dependency-security, npm-audit, package-hallucination, supply-chain-security, typosquatting

## 简介

Command-line gate that blocks risky dependency changes -- typosquats, tampered lockfile entries, newly acquired install scripts, and hallucinated package names -- before install, before commit, before CI.
