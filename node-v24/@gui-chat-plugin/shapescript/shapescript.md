# @gui-chat-plugin/shapescript

> 标签: 3d, gui-chat, gui-chat-protocol, plugin, shapescript, three

## 简介

presentShapeScript — interactive 3D models authored in the ShapeScript language (parser + Three.js renderer), with USDZ / GLB / STL export, for GUI Chat Protocol hosts. Core (tool definition + execute) on `.`, Vue View/Preview on `./vue`, server-only rast
