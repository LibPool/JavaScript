# @seggwat/react-native

> 标签: expo, feedback, nps, ratings, react-native, seggwat

## 简介

SeggWat feedback SDK for React Native and Expo — feedback form, helpful/star/NPS rating prompts, and a headless API client. Pure TypeScript, no native code.
