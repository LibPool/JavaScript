# @libeilong/model-manager

> 标签: JavaScript

## 简介

一个高性能、内存安全且类型友好的 TypeScript 领域模型管理库。专为复杂的前端应用设计，支持 **自动内存管理 (WeakRef)**、**响应式框架集成 (Vue/MobX)**、**关系自动 hydrate**、**模型家族多态分发** 以及 **精细化的数据合并策略**。
