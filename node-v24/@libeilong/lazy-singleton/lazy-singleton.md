# @libeilong/lazy-singleton

> 标签: JavaScript

## 简介

一个零依赖、仅 ~500 字节的微型工具库，用于创建延迟初始化的单例。它可以从根本上解决 JavaScript/TypeScript 项目中的循环依赖问题，并提供一流的开发体验，包括对 Vite 和 Webpack 的状态保留热重载（HMR）支持。
