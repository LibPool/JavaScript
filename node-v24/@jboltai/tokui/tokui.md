# @jboltai/tokui

> 标签: ai, component, dsl, framework-agnostic, react, render, server-sent-events, sse, streaming-ui, svelte, tokui, ui-framework, vue, web-components

## 简介

TokUI — Zero-dependency streaming UI description & rendering framework for AI chat. Describe UI with a tiny DSL, stream over SSE, render to real DOM incrementally.
