# @out-box/cli

> 标签: agents, ai, claude, cli, cloudflare-workers, html, out-box.dev, outbox, personal-library, publish

## 简介

Outbox CLI — publish HTMLs to your personal space (out-box.dev). Agents-first publishing platform with folder-scoped keys, server-side templates, atomic rotation, versioning, and tenant isolation by default.
