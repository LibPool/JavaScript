# @reddb-io/toon-rpc-acp

> 标签: acp, legacy, toon, toon-rpc

## 简介

Client for this repository's own legacy, terminal ACP-style REST contract. Not IBM/BeeAI ACP, not Zed's Agent Client Protocol, not interoperable with either.
