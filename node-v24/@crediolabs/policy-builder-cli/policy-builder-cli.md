# @crediolabs/policy-builder-cli

> 标签: authorization, openzeppelin, policy, smart-account, soroban, stellar

## 简介

Command line for the OZ Policy Builder: `policy-builder <tool>` runs any of the eight policy-synth tools and prints its JSON envelope.
