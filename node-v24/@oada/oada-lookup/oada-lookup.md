# @oada/oada-lookup

> 标签: OADA, client discovery, client registration, oada-configuration, openid-configuration

## 简介

JavaScript utility library to lookup OADA documents such as Well-Known (RFC 5785) resource, e.g., oada-configuration, openid-configuration, etc, and public OADA client registrations

- 官网：https://github.com/OADA/oada-lookup-js
- 源码仓库：git+https://github.com/OADA/oada-lookup-js.git
