# @pi-harness/plugin-vision-toolkit

> 标签: cordis, pi-harness, pi-harness-plugin, plugin

## 简介

Catalog signature-verified PNG, JPEG, GIF, and WebP metadata with bounded header reads, cancellable workspace traversal, explicit partial results, and a local-only normalized panel.
