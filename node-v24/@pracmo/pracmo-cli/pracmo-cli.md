# @pracmo/pracmo-cli

> 标签: JavaScript

## 简介

练成（Pracmo）App 的 AI 练习助手命令行：把对话、资料或目标整理成私人练习题，加入已有甲程与练习册。任何 AI Agent 都可直接调用；不绑定任何特定 Agent 平台。
