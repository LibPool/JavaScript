# pagerecast-mcp

> 标签: ai-agents, capture, design-tokens, figma, mcp, model-context-protocol

## 简介

MCP server for PageRecast: AI agents capture web pages as .recast files, extract their design tokens and hand captures to the Figma plugin. Free, open source and local-only.
