# @rabia_youcef/better-regex

> 标签: backtracking, from-scratch, parser, regex, regular-expression, zero-dependency

## 简介

A regex engine built from scratch — parser + backtracking matcher, no native RegExp. Supports literals, ., *, +, ?, and | alternation.
