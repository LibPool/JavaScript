# @hzblj/expo-native-icons

> 标签: android, asset-catalog, config-plugin, expo, expo-module, icons, ios, react-native, svg, vector-drawable

## 简介

Your SVG icons as native assets for Expo: a config plugin that turns them into iOS asset catalog images and Android vector drawables, typed names, and a native view that draws them tinted.
