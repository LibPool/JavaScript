# @hzblj/expo-rich-haptics

> 标签: android, core-haptics, expo, expo-module, feedback, haptic, haptics, ios, react-native, taptic, vibration

## 简介

Haptics for Expo that feel like the platform: UIKit feedback and Core Haptics patterns on iOS, the system's haptic feedback and rich primitives on Android, never a vibrator buzz.
