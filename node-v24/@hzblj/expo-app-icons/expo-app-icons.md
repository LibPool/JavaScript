# @hzblj/expo-app-icons

> 标签: alternate-icons, android, app-icon, config-plugin, expo, expo-module, icon, ios, launcher-icon, react-native

## 简介

Alternate app icons for Expo: a config plugin that generates them and a native module that switches them at runtime on iOS and Android.
