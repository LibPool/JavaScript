# @hzblj/kara-expo-plugin

> 标签: config-plugin, expo, kara-ui

## 简介

The Expo config plugin and tooling of @hzblj/kara-ui: the app's SVG icons as native assets on iOS and Android, and UIKit semantic colour overrides.
