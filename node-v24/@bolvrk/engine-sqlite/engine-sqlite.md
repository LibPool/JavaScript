# @bolvrk/engine-sqlite

> 标签: ddl, lint, migrations, sql, sqlite

## 简介

Bolvrk SQLite migration danger rules (SL###) over a real SQLite grammar. BETA: static rules only, behind --engine=sqlite in the CLI.
