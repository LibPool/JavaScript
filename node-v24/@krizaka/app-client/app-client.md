# @krizaka/app-client

> 标签: api-client, expo, krizaka, react-native, service-discovery, session

## 简介

What every Krizaka Expo app shares: the bearer session over a secure-storage port, the discovery client of the signed services manifest, the API client (bearer, timeout, 401 handling) and, in ./react, the auth context every app's screens read. Ports in, n
