# @krizaka/push

> 标签: apns, expo, expo-push, fcm, krizaka, push, push-notifications, react-native

## 简介

Mobile push without an SDK: the Expo Push Service relays to FCM (Android) and APNs (iOS) from one HTTP call. Pure and dependency-free: batches by 100, never throws, reports the dead tokens to forget.
