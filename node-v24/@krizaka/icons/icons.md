# @krizaka/icons

> 标签: design-system, icons, krizaka, react, react-native, react-native-svg, svg, tree-shakable

## 简介

The Krizaka signature icons: one drawing language (24 grid, cut corners, a node at the core) for every Krizaka product — React (tree-shakable, server-safe) and React Native (react-native-svg).

- 源码仓库：git+https://github.com/krizaka/krizaka-ui.git
