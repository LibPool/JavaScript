# @krizaka/db

> 标签: database, krizaka, migrations, modules, postgresql, transactions

## 简介

The database foundation of every Krizaka module: shared Query, Connection and Clock types, transactions, versioned and frozen module schemas embedded in the product's own migration sequence, a runner for products without one, and a test database helper. N
