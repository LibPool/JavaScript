# @xihe-lab/tapd-markdown

> 标签: JavaScript

## 简介

TAPD rich text (TinyMCE HTML dialect) ↔ Markdown bidirectional lossless converter: semantic primitives for @mentions/attachment anchors, GFM mapping, inline-HTML passthrough
