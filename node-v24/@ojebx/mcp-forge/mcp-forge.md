# @ojebx/mcp-forge

> 标签: ai, anthropic, claude, codegen, cursor, mcp, model-context-protocol, openapi, postman, swagger, tools

## 简介

Compile any OpenAPI or Swagger spec into a working Model Context Protocol (MCP) server in one command.
