# @windypro-rourou/dsh-auto-continue

> 标签: auto-continue, deepseek-harness, dsh, dsh-plugin, failover, nvidia

## 简介

DSH 自动续跑插件：监视（多个）模型提供商，回合失败自动发「继续」续跑；连续失败后按列表切换回退模型（思考强度直接选定）；附 Web 配置台与运行事件日志。
