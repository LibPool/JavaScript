# @zennolux/vite-plugin-wasm

> 标签: es-modules, modules, plugin, vite, wasm, wasm-pack, webassembly

## 简介

Add WebAssembly ESM integration (aka. Webpack's `asyncWebAssembly`) to Vite and support `wasm-pack` generated modules.
