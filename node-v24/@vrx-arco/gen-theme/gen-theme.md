# @vrx-arco/gen-theme

> 标签: JavaScript

## 简介

使[Arco Design Lab](https://arco.design/themes)生成的包 @arco-themes/vue-[lib] 可以混合 @arco-design/web-vue 的样式文件，独立生成为一个静态的主题包

## 官网

- 源码仓库：https://gitee.com/vrx/arco-gen-theme
- npm 页面：https://www.npmjs.com/package/@vrx-arco/gen-theme
