# @fenixsoftware/plugin-instagram-creator

> 标签: JavaScript

## 简介

Paperclip plugin: generate Instagram-ready post images via OpenRouter (gpt-5.4-image-2 base + gemini-2.5-flash-image / nano-banana for logo overlay).
