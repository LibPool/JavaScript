# @tonyweckstrom/llm-cassette

> 标签: cassette, fetch, litellm, llm, openai, record, replay, testing, vcr

## 简介

Tallenna LLM-kutsujen vastaukset kerran ja toista ne testeissä: nopeat, ilmaiset ja vakaat testit ilman verkkoa. Record/replay for fetch-based LLM clients.
