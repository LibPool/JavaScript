## 简介

Comprehensive pre-install evaluation for DeepSeek Harness plugins: security scan, footprint benchmark, community review aggregation and version compatibility check, scored like npm audit + Lighthouse. 安装前综合评估：安全扫描 / 性能基准 / 社区评价聚合 / 版本兼容验证。
