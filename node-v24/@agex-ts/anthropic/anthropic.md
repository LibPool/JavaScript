# @agex-ts/anthropic

> 标签: agent, agex, agex-ts, anthropic, claude, llm, provider

## 简介

Anthropic Messages API provider for agex-ts. Lowers NeutralTurn[] to Anthropic content blocks; streams via SSE; no SDK dependency.
