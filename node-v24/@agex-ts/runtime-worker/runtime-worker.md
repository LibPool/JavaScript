# @agex-ts/runtime-worker

> 标签: agent, agex, agex-ts, browser, isolation, runtime, sandbox, typescript, web-worker

## 简介

Worker-isolated RuntimeAdapter for agex-ts. Browser-first (Web Worker); ts-blank-space transpile by default with a transform hook for embedders that need fuller TS coverage (e.g. esbuild-wasm).
