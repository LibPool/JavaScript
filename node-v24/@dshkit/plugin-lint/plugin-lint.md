# @dshkit/plugin-lint

> 标签: deepseek-harness, dsh, dshkit, lint, plugin

## 简介

Read a packed dsh plugin and report what the carrier's own reader would refuse in it, before anyone installs it. Static, single-package, two layers of four — it prints what it did not look at.
