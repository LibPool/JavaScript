# @dotprotocol/piperchat

> 标签: JavaScript

## 简介

P2P chat with E2E sealed bodies (X25519+AES-256-GCM), Ed25519-signed identities, optional zstd-with-shared-dict wire compression, signed-when-present threading + reactions + read-acks, SQLite storage, SSE relay
