# davy-jones-locker

> 标签: data-pipeline, duckdb, duckdb-wasm, flowgraph, framework, vue, vue3

## 简介

An app framework for flowgraphs on SEAMONSTER: the browser shell (engine client, DuckDB-wasm, storage). Its Python engine is davy-jones-locker on PyPI.
