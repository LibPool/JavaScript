# @carverauto/create-dashboard

> 标签: JavaScript

## 简介

npm-create scaffolder for ServiceRadar dashboards. `npm create @carverauto/dashboard <name>` forwards to `serviceradar-cli dashboard init`.

- 官网：https://github.com/carverauto/serviceradar#readme
- 源码仓库：git+ssh://git@github.com/carverauto/serviceradar.git
