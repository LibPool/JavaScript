# @wizsolucoes/wiz-pagination

> 标签: JavaScript

## 简介

Pagination é o nosso componente de comunicação numérica de elementos ( páginas, comentários, artigos, imagens…) com o objetivo de carregamento dentro de um determinado contexto. Seu foco é mostrar ao usuário onde ele está e permitir que tenha acesso diret
