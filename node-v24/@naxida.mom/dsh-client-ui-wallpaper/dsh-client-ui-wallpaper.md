# @naxida.mom/dsh-client-ui-wallpaper

> 标签: JavaScript

## 简介

Wallpaper plugin: set a comic cover from y-comic as the DSH background, with panel/dialog/bubble/input opacity sliders, position controls, URL upload and a local file upload
