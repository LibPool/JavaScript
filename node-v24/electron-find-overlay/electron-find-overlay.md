# electron-find-overlay

> 标签: browser-search, chromium, ctrl-f, electron, find, find-bar, find-in-page, findbar, findinpage, native-search, overlay, search, search-bar, webcontentsview

## 简介

A modern find bar for Electron apps, using the browser's native search. It floats over the page, so it never finds its own search text
