# @ulu/pandoc-adapter

> 标签: adapter, cli wrapper, conversion, convert, converter, document conversion, docx, markdown, pandoc, stream

## 简介

A Node.js package that provides utilities for converting documents using Pandoc, with a focus on processing multiple files and managing extracted assets.
