# agentflowctl

> 标签: agent, ai, claude-code, cli, code-review, codex, gemini, tdd

## 简介

讓 Claude Code、Codex、Gemini CLI 等 agent 分工整理需求、規劃、寫測試與程式並交叉審查，最後建立 PR；由程式推進流程，以測試與檢查結果把關
