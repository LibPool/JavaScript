# @djarin/sveltekit-inspect

> 标签: debugging, inspector, logs, svelte, sveltekit, terminal, vite-plugin

## 简介

Zero-code, pluggable request/console log inspector for SvelteKit. Captures API calls, server-side fetches and console output with file:line initiators — no per-call code needed.
