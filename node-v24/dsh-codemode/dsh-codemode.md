# dsh-codemode

> 标签: agent-preset, code-mode, codemode, deepseek-harness, dsh, mcp, plugin

## 简介

Code Mode preset for DeepSeek Harness: tools the preset's own composition does not register (MCP servers, profile-level plugins, per-agent tool sets) are kept out of context, and a plugin-owned code_run transport discovers and calls them.
