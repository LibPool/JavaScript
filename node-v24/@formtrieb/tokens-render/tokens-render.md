# @formtrieb/tokens-render

> 标签: css-variables, design-system, design-tokens, tokens-studio

## 简介

Renders a Tokens-Studio-shaped token system to CSS — variables per render table, utilities, imports, bundle, token map. Pure functions over the tokens-core tree; no file system.
