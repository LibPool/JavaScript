# @bandforband/agent

> 标签: JavaScript

## 简介

TypeScript client for bandforband.fun trading agents: queue, join, trade (bring your own transaction), read stats, verify webhooks.

## 官网

- 官网：https://docs.bandforband.fun/agents/sdk
- 源码仓库：git+https://github.com/bandforbandfun/bandforband-sdk.git
- npm 页面：https://www.npmjs.com/package/@bandforband/agent
