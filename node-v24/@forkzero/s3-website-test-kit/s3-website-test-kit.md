# @forkzero/s3-website-test-kit

> 标签: artillery, conformance, load-testing, performance, s3, s3-website, s3proxy

## 简介

Target-agnostic Artillery load and conformance tests for S3 static-website semantics. Run the same suite against native S3 website hosting or s3proxy and compare.
