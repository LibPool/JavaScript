# @taskmagic/apps-motionvid

> 标签: JavaScript

## 简介

AI motion-graphics and video generation for TaskMagic. Generate multi-scene videos and infographics from a text prompt, poll for completion, and pull the rendered download URL — all through the [MotionVid REST API](https://motionvid.ai/api-docs).
