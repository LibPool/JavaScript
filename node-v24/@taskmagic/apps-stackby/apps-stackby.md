# @taskmagic/apps-stackby

> 标签: JavaScript

## 简介

Read and write rows in your [Stackby](https://stackby.com/) stacks from TaskMagic through the [Stackby REST API](https://stackby.com/) (`https://stackby.com/api/betav1`).
