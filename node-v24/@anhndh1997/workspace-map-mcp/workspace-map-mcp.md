# @anhndh1997/workspace-map-mcp

> 标签: ai-agent, code-navigation, codemap, copilot, mcp, model-context-protocol, tree-sitter, workspace

## 简介

MCP server that maps a workspace: markdown folder/file tree + code relation maps (types, inheritance, imports, calls) for AI-assisted navigation.
