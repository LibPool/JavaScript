# @pound79/specproof

> 标签: JavaScript

## 简介

Scaffolder CLI for specproof — keeps AI-written E2E tests honest. `specproof init` drops a config-driven behavior-test scaffold (Playwright / Flutter) plus a PR drift-check workflow into your repo.
