# @nifrajs/authjs

> 标签: auth, authjs, bun, nifra, oauth, oidc, session, typescript

## 简介

Official Auth.js integration for nifra - mount Auth.js (OAuth, OIDC, credentials, WebAuthn-ready) into a nifra app, read sessions in handlers and loaders, guard routes, and drive it all from any frontend.
