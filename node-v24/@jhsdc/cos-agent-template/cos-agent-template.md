# @jhsdc/cos-agent-template

> 标签: JavaScript

## 简介

A reusable [eve](https://eve.dev) agent template: Slack integration via Vercel Connect, a Neon Postgres logging/idempotency layer, a centralized `withWebhookHandler()` wrapper, a generic Slack/Teams notifier, and a Skynest (Context Nest) MCP knowledge-vau
