# @ashdev/codex-plugin-release-tsundoku

> 标签: codex, manga, plugin, release-source, tsundoku

## 简介

Tsundoku release-source plugin for Codex - announces new volume/chapter coverage for tracked series via the Tsundoku incremental series feed, matched by exact external IDs
