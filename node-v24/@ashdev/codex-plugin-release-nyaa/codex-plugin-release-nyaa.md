# @ashdev/codex-plugin-release-nyaa

> 标签: codex, manga, nyaa, plugin, release-source, torrent

## 简介

Nyaa.si uploader-feed release-source plugin for Codex - announces torrent releases for tracked series, filtered by an admin allowlist of trusted uploaders
