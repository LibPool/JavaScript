# @blksword/dsh-flowus

> 标签: bundle, deepseek-harness, dsh, flowus, mcp, oauth, plugin, settings-page

## 简介

FlowUs for DeepSeek Harness: browser OAuth sign-in against the official FlowUs MCP server, its tools registered as native agent tools, a /flowus command, and a Settings -> FlowUs page.
