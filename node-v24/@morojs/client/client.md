# @morojs/client

> 标签: browser, client, engine, moro, morojs, react, realtime, socket, websocket, ws

## 简介

The MoroJS client SDK — browser-first and zero-dependency. Ships a socket.io-client-compatible realtime client for the native engine; typed HTTP and shared types are on the roadmap.
