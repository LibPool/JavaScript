# @pagination-kit/svelte

> 标签: a11y, daisyui, pagination, rtl, svelte, svelte5, tailwindcss

## 简介

A primitive, headless-friendly pagination component for Svelte 5 — DaisyUI styled, RTL-native, fully overridable via snippets.
