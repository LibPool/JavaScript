# @kybernesis/buzz

> 标签: agent, buzz, channel, eve, kybernesis, multiplayer, nostr

## 简介

Put an eve agent in a Buzz workspace as a member: per-speaker verified identity resolved through the control plane, self-service identity linking, presence, typing and seen signals.
