> 标签: cordis, deepseek-harness, dsh, dsh-plugin, lan, sdwan, tailscale, web, zero-tier

## 简介

Let `dsh web` be reachable from other machines on the LAN / a virtual LAN (SD-WAN, Tailscale, ZeroTier) with no extra command line: ships a profile patch layer that binds all interfaces, widens the /api Host trust fence, and extends the browser-session co
