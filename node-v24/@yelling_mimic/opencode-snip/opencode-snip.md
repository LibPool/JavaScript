# @yelling_mimic/opencode-snip

> 标签: cli, opencode, opencode-plugin, snip, tokens

## 简介

OpenCode plugin that prefixes shell commands with snip to reduce token consumption. Fork with heredoc/PowerShell support, snip check validation, and expanded unproxyable commands list.
