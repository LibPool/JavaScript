# @camplus360/agent-memory-bridge-dsh

> 标签: agent-memory-bridge, ai-agent, claude-mem, coding-agent, cross-engine, cross-session, deepseek-harness, dsh, dsh-plugin, memory, memory-bridge, persistent-memory

## 简介

DeepSeek Harness memory plugin: captures conversation/tool observations to the local claude-mem worker, giving DeepSeek Harness cross-session shared memory. Summarization/embedding/search stay in claude-mem.
