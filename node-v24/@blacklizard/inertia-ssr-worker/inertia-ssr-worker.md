# @blacklizard/inertia-ssr-worker

> 标签: adapter, cache, express, inertia, inertia-js, inertiajs, load-balancer, redis, self-healing, spa, ssr, worker

## 简介

Production SSR worker for Inertia.js v3 — wraps your render function with health/readiness endpoints, request/uptime/RSS-based recycling, and graceful drain.
