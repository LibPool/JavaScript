# @developertown/oidc-provider

> 标签: auth0, authentication, authorization, azure-ad, cognito, oauth2, oidc, oidc-client-ts, openid-connect, pkce, react, react-hooks

## 简介

React authentication provider built on oidc-client-ts, with first-class support for Auth0, Azure AD, and Amazon Cognito.
