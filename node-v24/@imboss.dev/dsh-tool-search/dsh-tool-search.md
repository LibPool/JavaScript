# @imboss.dev/dsh-tool-search

> 标签: context-window, dsh, llm-agent, mcp, tool-discovery

## 简介

On-demand tool discovery for DSH: trims resident tool descriptions, defers MCP tools until find_tools, plus checkpoint_update and a staleness nudge for dsh-checkpoint compaction.
