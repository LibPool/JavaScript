# @ojodotso/mcp-server

> 标签: agent, ai, html-to-image, image-generation, mcp, model-context-protocol, ojo, screenshot

## 简介

MCP server for oJo — let AI agents turn HTML into images. Free live previews with no account; add an oJo API key for hosted PNG URLs and templates.
