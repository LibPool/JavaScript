# @goplausible/regent-plugin-claude

> 标签: JavaScript

## 简介

Regent channel plugin for Claude Code — connects Claude Code to Regent wallet peers (e.g. Regent) over Liquid Auth (FIDO2) + WebRTC DataChannels.
