# @ganttloom/project-io

> 标签: export, gantt, import, microsoft-project, ms-project, mspdi, p6, primavera, project-management, schedule, xer, zero-dependency

## 简介

Import Microsoft Project (MSPDI XML) and Primavera P6 (XER) schedules into @ganttloom/gantt-core tasks and dependencies, and export them back to MS Project XML. Zero dependencies.
