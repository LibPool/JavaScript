# @chronista-club/creo-ui-icons-web

> 标签: creo-ui, design-system, iconify, icons, solid-js

## 简介

creo-ui — Iconify-based icon adapter for SolidJS web apps. Universal semantic registry with curated 9-set Iconify lineup (mingcute/iconoir/ph/svg-spinners/codicon/simple-icons/flagpack/noto/bi).
