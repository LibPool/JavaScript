# @jordan_magnatu/agent-mcp

> 标签: JavaScript

## 简介

Magnatu for any MCP host (Claude Desktop, Cursor, VS Code, LM Studio, a self-hosted bot): pair once, then the assistant sends, reads and checks mandates through tools, with the agent key on this machine.
