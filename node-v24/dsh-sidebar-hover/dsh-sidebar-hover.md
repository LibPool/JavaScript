# dsh-sidebar-hover

> 标签: deepseek, dsh, dsh-plugin, harness, hover, sidebar

## 简介

Claude Code-style sidebar for DeepSeek Harness: hovering the collapsed sidebar toggle peeks the sidebar over the content, selecting a session collapses it, clicking the toggle pins it; plus back/forward session history arrows (Cmd+[ / Cmd+]). Own Settings
