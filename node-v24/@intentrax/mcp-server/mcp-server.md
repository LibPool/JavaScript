# @intentrax/mcp-server

> 标签: ai-agents, claude-code, codex, cursor, execution-assurance, intentrax, kiro, mcp, model-context-protocol, proof, verification

## 简介

Read-only Model Context Protocol server for Intentrax proof verification. Gives coding agents (Claude Code, Cursor, Kiro, Codex) two safe tools: verify a public proof, and read a tenant-scoped proof. Never executes, admits, signs, or writes.
