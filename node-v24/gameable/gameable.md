# gameable

> 标签: game-engine, gaussian-splatting, multiplayer, three, webassembly, webgpu

## 简介

Gameable Engine: a browser game engine where the world is a gaussian splat, the renderer is WebGPU and all game logic is a WebAssembly component.

- 官网：https://engine.gameable.com
- 源码仓库：git+https://github.com/getgameable/gameable-engine.git
