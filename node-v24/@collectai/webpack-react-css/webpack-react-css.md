# @collectai/webpack-react-css

> 标签: JavaScript

## 简介

One of the problems when speaking about components modularity is CSS scoping. `Shadow DOM` will be the solution to this problem, but in the meantime developers have to sortout this issue. This module helps to prepare react and css files for browser bundle
