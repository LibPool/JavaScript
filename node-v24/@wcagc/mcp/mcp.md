# @wcagc/mcp

> 标签: a11y, accessibility, axe-core, en-301-549, mcp, model-context-protocol, pdf-ua, wcag

## 简介

wcagc MCP server — a thin, stateless adapter that translates MCP tool calls into wcagc-api HTTP calls. No database, no secrets beyond WCAGC_API_BASE_URL (+ WCAGC_MCP_KEY for local stdio mode). Open-source: this package holds no business logic or credentia
