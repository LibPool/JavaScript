# @bskts/sdk

> 标签: agent, basket, bskts, defi, index, non-custodial, robinhood-chain, sdk, viem

## 简介

Typed, non-custodial client for the bskts API: tokenized index baskets on Robinhood Chain. Reads, unsigned transaction builders, dry runs and guard rails for wallets and agents.
