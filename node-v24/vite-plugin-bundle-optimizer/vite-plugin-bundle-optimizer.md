# vite-plugin-bundle-optimizer

> 标签: brotli, bundle, bundle optimization, chunks, code-splitting, gzip, optimizer, rollup, vendor, vite, vite-plugin

## 简介

Vite plugin for automatic production bundle optimization via intelligent chunk splitting, vendor grouping, shared dependency extraction, and compression.
