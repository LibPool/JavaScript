# @rturv/mcp-pdf-reader

> 标签: ai-assistant, anthropic, claude, github-copilot, image-extraction, mcp, metadata-extraction, model-context-protocol, pdf, pdf-extraction, pdf-reader, pdf-search, text-extraction, tool

## 简介

A Model Context Protocol (MCP) server that enables AI assistants (Claude, GitHub Copilot) to read, extract text, search, and analyze PDF files with full metadata and image extraction support
