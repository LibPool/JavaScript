# http-server-bsv

> 标签: JavaScript

## 简介

属性|说明 ---|--- -p --port  |  端口设置，默认是 8080 -g --gzip   |  默认false -P --proxy  | 通过一个 url地址，代理不能通过本地解析的资源 -h --help   | 显示帮助 -v --version| 版本
