# hana-sql-sandbox-backend

> 标签: HANA, SAP

## 简介

Uses @sap/hana-client to run HANA Statements to HANA backend. Returns JSON meant for a Vue frontend like https://github.com/entmike/hana-sql-sandbox-frontend.
