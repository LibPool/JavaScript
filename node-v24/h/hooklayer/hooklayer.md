> 标签: ai-agents, claude, cursor, hooks, mcp, mcp-connector, mcp-server, model-context-protocol, n8n, short-form-video, tiktok, viral

## 简介

Hooklayer MCP connector — viral-content intelligence for AI agents. One-line install (npx hooklayer) that bridges any stdio MCP client to the hosted Hooklayer server: TikTok/YouTube hook scoring, virality prediction, trend pulse, viral templates, creator
