# hpp-sanitize

> 标签: express, hpp, http-parameter-pollution, middleware, nodejs, sanitization, security, validation

## 简介

middleware para remover parâmetros de requisição duplicados, prevenindo ataques de "Poluição de Parâmetros HTTP (HPP)"
