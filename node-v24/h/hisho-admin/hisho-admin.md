# hisho-admin

> 标签: JavaScript

## 简介

`hisho-admin` は Hisho の管理・データ投入用 SDK です。サーバーサイドのバッチ、管理スクリプト、社内ツールなどから、プロジェクト作成やソース追加をコードで実行できます。
