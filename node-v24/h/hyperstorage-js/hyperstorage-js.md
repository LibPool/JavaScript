# hyperstorage-js

> 标签: browser, client, commonjs, ecmascript, es, javascript, js, localStorage, module, sessionStorage, storage, ts, typescript, umd, utility

## 简介

A lightweight superjson-wrapper for localStorage/sessionStorage with efficient caching and type-preserving serialization.
