# hg-async-render

> 标签: angular, async, render, resolver, suspense

## 简介

Are you sick of the navigation blocking Angular resolver. No problem... just use the async-render component for the different parts of you app that need to be rendered  and create directive resolvers that you can attach to the inidvidual async render comp
