# harness-homies

> 标签: agent-plugins, claude-code, codex, cursor, mcp, model-context-protocol, opencode

## 简介

Read-only MCP server for inspecting Claude Code, OpenCode, Cursor, and Codex sessions on the same machine — list what's running, get topics/todos, fetch transcripts.
