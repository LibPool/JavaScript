# haibun-solid-lite

> 标签: JavaScript

## 简介

Hai Solid web routes, steppers and tests for [Haibun](https://github.com/withhaibun), built around the [Solid Lite specification](https://github.com/solid-lite/draft-spec), basically a Linked Data Platform implmentation.
