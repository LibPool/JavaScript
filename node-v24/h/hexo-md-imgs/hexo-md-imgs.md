# hexo-md-imgs

> 标签: NexT, hexo, 本地图片

## 简介

hexo中，在`source/images`里放图片，markdown引用路径为`../images/*.png`或者`/source/images/*.png`，但是这样编译出来，图片路径是不对的，这个插件修改一下，详细看这里 : https://github.com/yuhlzu/hexo-md-imgs
