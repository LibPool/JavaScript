# highlightjs-1c-bsl

> 标签: 1c, 1c-enterprise, bsl, highlight.js, hljs, onec, syntax-highlighting

## 简介

Post-processor for highlight.js that restores missing hljs-keyword class on BSL scope-marker keywords (Функция/КонецФункции/Процедура/КонецПроцедуры/Знач)
