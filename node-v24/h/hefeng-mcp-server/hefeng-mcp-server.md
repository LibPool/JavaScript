# hefeng-mcp-server

> 标签: datetime, geolocation, hefeng-weather, mcp, modelcontextprotocol, weather

## 简介

一个用于和风天气API的MCP服务器，提供天气查询、城市位置ID获取和当前日期时间查询功能。
