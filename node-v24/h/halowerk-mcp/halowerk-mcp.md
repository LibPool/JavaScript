# halowerk-mcp

> 标签: agent-tools, base, mcp, micropayment, modelcontextprotocol, pay-per-call, usdc, x402

## 简介

HALOWERK services as MCP tools, paid per call with x402 on Base. No account, no login, no subscription — a throwaway wallet with a few dollars is enough.
