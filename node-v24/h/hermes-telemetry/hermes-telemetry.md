# hermes-telemetry

> 标签: 8examples, ai-worker, hermes, hermes-agent, monitoring, telemetry

## 简介

Call-home telemetry reporter for managed Hermes Agent workers. Phones imprints (status, model, token usage from Hermes' own state.db, errors, browser health, host health) to your 8Examples telemetry endpoint every 10 minutes.
