# hprose-ts

> 标签: hprose, hprose-html5, hprose-ts

## 简介

* hprose-html5 的 阉割版 * 只支持 Hprose.HttpClient (http) 和 Hprose.Client.create (websocket) * 不支持回调，均采用 Promise
