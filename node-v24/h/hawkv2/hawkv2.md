# hawkv2

> 标签: HAWKV2, agent, ai, cli, coding-agent, fork, hawk, hawkv2, llm, opencode

## 简介

HAWKV2 — AI-powered development tool. Community fork of opencode (MCP auto-reconnect, hot reload, eval pipeline, memory consolidation, unified prompt); installs the HAWKV2 CLI as `hawk` alongside the official opencode.
