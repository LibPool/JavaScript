# hasl-tools

> 标签: JavaScript

## 简介

跨环境（APP壳/微信/企微/H5）原生能力 SDK：拍照上传、OCR 校验、人脸识别、PDF 阅读、图片裁剪、反馈等；服务地址与上传鉴权均内置，宿主仅需 setEnv 告知环境即可开箱即用。
