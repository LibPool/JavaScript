# helloruntime

> 标签: cron, deploy, drizzle, jobs, knative, nitro, paas, serverless, vite

## 简介

CLI + runtime SDK for Helloruntime — a self-hostable PaaS for Node full-stack apps. Build locally, `helloruntime deploy`; every git branch gets its own environment with Postgres (Drizzle migrations applied on deploy), S3 storage, and durable tasks/workflo
