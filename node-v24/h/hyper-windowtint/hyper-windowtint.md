# hyper-windowtint

> 标签: color, cwd, hyper, hyper-plugin, hyper.app, hyperterm, osc7, project, tabs, terminal, theme, tint

## 简介

Color every Hyper terminal window based on its active project folder, so you can tell multiple terminals apart at a glance.
