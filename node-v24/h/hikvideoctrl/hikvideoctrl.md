# hikvideoctrl

> 标签: browser, camera, cctv, dvr, esm, h264, h265, hik, hikvideo, hikvision, ip-camera, ipcamera, isapi, no-plugin, nvr, playback, player, ptz, ptz-control, rtsp, surveillance, typescript, video, video-player, websdk, websocket, 云台控制, 回放, 录像, 播放器, 无插件, 无插件开发包, 海康, 海康SDK, 海康威视, 海康播放器, 海康监控, 球机, 监控, 网络摄像头

## 简介

海康威视无插件的现代 TypeScript 封装，统一 async/await API，覆盖设备登录、实时预览、录像回放、抓拍、PTZ 云台与设备维护。
