# hoosat-sdk

> 标签: blockchain, client, cryptocurrency, grpc, hoosat, htn, node, sdk

## 简介

TypeScript SDK for Hoosat blockchain: full node integration, crypto utilities, real-time UTXO streaming, transaction building, dynamic fee estimation, and QR code generation
