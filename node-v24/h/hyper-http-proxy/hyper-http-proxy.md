# hyper-http-proxy

> 标签: JavaScript

## 简介

A simple HTTP Proxy for [HyperDHT](https://docs.pears.com/building-blocks/hyperdht) connections using [bech32 encoded connection strings](https://github.com/hzrd149/hyper-address)
