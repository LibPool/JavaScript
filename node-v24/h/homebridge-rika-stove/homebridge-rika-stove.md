# homebridge-rika-stove

> 标签: corso, firenet, homebridge, homebridge-plugin, hopper, pellets, poele, rika, stove, sumo

## 简介

Homebridge plugin for RIKA pellet stoves via the FireNet cloud service — heating control, calculated pellet level, service and fault indicators. No dependencies.
