# homebridge-mqtt-lux-tasmota

> 标签: BH1750, Sonoff-Tasmota, Wifi IoT Relay Board, electrodragon, homebridge, homebridge-plugin, homekit, itead, sonoff, tasmota

## 简介

Plugin to HomeBridge optimized for work with Itead Sonoff and Electrodragon Relay Board hardware and firmware Sonoff-Tasmota via MQTT. It acts as an Ambient Light sensors.
