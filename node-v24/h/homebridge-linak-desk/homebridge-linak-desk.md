# homebridge-linak-desk

> 标签: desk, homebridge-plugin, homekit, linak, mqtt, sit-stand, standing-desk, supports-hap

## 简介

Control the height of LINAK sit/stand desks from Apple Home, via the mqtt-linak bridge.
