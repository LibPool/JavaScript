# honeycrawlpot

> 标签: canary, crawler, deception, fake-secrets, honeypot, honeytoken, llm, prompt-injection, scanner, security

## 简介

Serve realistic decoy files (fake secrets + prompt injections) to AI/LLM-powered vulnerability scanners. Zero-dependency, framework-agnostic.
