# homebridge-rpi-rts

> 标签: homebridge-plugin, homekit, pi, raspberry, rts, somfy

## 简介

A Homebridge plugin to add HomeKit compatibility to Somfy RTS devices (rolling shutters, blinds, awnings, ...) requiring only a Raspberry Pi and a simple 433 MHz transmitter.
