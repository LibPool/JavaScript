# hive-create-app

> 标签: JavaScript

## 简介

hive-create-app 是全局安装的 npm 包，提供了终端里的 hive 命令。它可以通过 hive create <项目名称> 快速搭建一个新项目

## 官网

- npm 页面：https://www.npmjs.com/package/hive-create-app

- 1.0.1

## 获取地址

- npm 安装：`npm install hive-create-app`
- npm registry：https://registry.npmjs.org/hive-create-app
