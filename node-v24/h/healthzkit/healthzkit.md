# healthzkit

> 标签: express, health-check, healthcheck, healthz, healthzkit, hono, kubernetes, liveness, nextjs, nodejs, probe, readiness

## 简介

Framework-agnostic Kubernetes liveness and readiness probes for Node.js. Parallel checks, status rollup, HTTP mapping, and optional background scheduling.
