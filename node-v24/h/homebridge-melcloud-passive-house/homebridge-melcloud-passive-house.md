# homebridge-melcloud-passive-house

> 标签: homebridge, homebridge-plugin, homekit, influxdb, melcloud, mitsubishi, passive-house, passivhaus, predictive, shelly, thermal-learning, weather-forecast

## 简介

Homebridge plugin for passive house climate control using Mitsubishi AC via MELCloud. Features predictive temperature management, external sensors (Shelly), weather forecasting, and thermal learning.
