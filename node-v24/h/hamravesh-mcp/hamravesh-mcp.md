# hamravesh-mcp

> 标签: ai, claude, darkube, devops, hamravesh, kubernetes, mcp, model-context-protocol, modelcontextprotocol, paas

## 简介

MCP server for the Hamravesh / Darkube console API — manage apps, deploys, databases, registries and billing from any MCP client (Claude, etc.).
