# homebridge-gpio-switch-dualrelay

> 标签: garagedoor, gpio, homebridge, homebridge-plugin, pi, raspberry, relay

## 简介

For a switch that requires two GPIO pins (closing pin and opening pin), and requires them to be active for some amount of time.
