# hikvision-player

> 标签: JavaScript

## 简介

`hikvision-player` 是一个面向 React 的海康威视 H5 播放器组件封装。组件负责加载 `h5player.min.js`、创建 `JSPlugin` 实例、注册窗口事件，并可以通过 React 属性声明式地完成预览、回放、分屏、音量、全屏等常用操作。
