# html-docx-js-extends

> 标签: docx, html, html-docx-js, html-to-docx, typescript

## 简介

基于html-docx-js-typescript的扩展，支持将多段html转换为docx文档,并分段设置纵横方向，以及简单页眉和页码的设置.
