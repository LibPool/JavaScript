# hermes-desktop-ru

> 标签: hermes, hermes-desktop, i18n, localization, ru, russian, translation, локализация, мод, русский

## 简介

Полная русская локализация Hermes Desktop: i18n-каталог + хардкоды компонентов и main-процесса. Структурный реестр якорей переживает обновления Hermes (doctor + пересборка asar).
