# hindsight-run-mcp

> 标签: attestcoin, creditcoin, ethereum, mcp, model-context-protocol, underwriting

## 简介

MCP server for hindsight.run: would the desk lend to this Ethereum address, did this transaction happen, which bounties are open — read from Creditcoin, no prover, no precompile, no wallet.
