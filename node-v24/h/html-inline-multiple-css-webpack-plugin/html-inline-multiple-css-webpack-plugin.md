# html-inline-multiple-css-webpack-plugin

> 标签: css, document, embedded, inline, internal, style, stylesheet, webpack, webpack-plugin, webpack4

## 简介

☄️ A webpack plugin based on HtmlInlineCssWebpackPlugin, In order to fix the problem that cannot inline multiple css, for convert external stylesheet to embedded stylesheet, aka document stylesheet,
