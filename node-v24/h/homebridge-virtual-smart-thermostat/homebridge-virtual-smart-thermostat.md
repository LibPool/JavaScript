# homebridge-virtual-smart-thermostat

> 标签: homebridge-plugin, homekit, supports-hap, thermostat, virtual-thermostat

## 简介

Virtual HomeKit thermostats for Homebridge 1.8+ and 2.x. Control heaters and coolers from a setpoint, with HTTP sensors, webhooks, hysteresis and optional TV-heat compensation.
