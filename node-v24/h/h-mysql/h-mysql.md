# h-mysql

> 标签: h-mysql, mysql thinkphp, mysql2, node-mysql

## 简介

一直以来很喜欢Thinkphp的数据操作风格，所以在nodejs上也封装了一个MYSQL数据库的常用操作，支持链式调用，实现语义化的数据库操作。
