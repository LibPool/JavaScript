# harpoon-package

> 标签: game-protocol, harpoon

## 简介

Server runtime helpers: graceful shutdown hooks, health report JSON, and tick profiling (used by harpoon-be). Wire protocol lives in harpoon-be/src/protocol (shared with harpoon-fe via @arena/protocol).
