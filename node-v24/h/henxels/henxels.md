# henxels

> 标签: agent-harness, agents, agents-md, ai, coding-agent, contract, guardrails, harness, knowledge-base, lint, llm-wiki, okf, open-knowledge-format, pre-commit, structure

## 简介

A repo-level harness for coding agents — file-level constraints that keep every agent true to your repo's structure. No Python required: the launcher bootstraps its own engine (official uv, checksum-pinned) on first run.
