# hilla-plugin-jackson-enums-vite

> 标签: enum, hilla, jackson, json-property, typescript, vaadin, vite, vite-plugin

## 简介

Vite plugin that rewrites Hilla-generated TypeScript enum values to match Jackson @JsonProperty wire values from a sidecar JSON.
