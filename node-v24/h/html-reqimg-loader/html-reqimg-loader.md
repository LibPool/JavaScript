# html-reqimg-loader

> 标签: JavaScript

## 简介

webpack处理图片资源时（例如file-loader），在html模板中直接使用img标签src加载图片的话，因为没有被依赖，图片将不会被打包，这个loader很好的解决了这个问题。

## 官网

- npm 页面：https://www.npmjs.com/package/html-reqimg-loader
