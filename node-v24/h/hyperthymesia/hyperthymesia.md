# hyperthymesia

> 标签: JavaScript

## 简介

> 超忆症（英语：Hyperthymesia，源自古希腊语 hyper（“过度”）和thymesis（“记忆”））。又称完全记忆，指一个人拥有超常自传性记忆，可以记住自己一生中主要的个人经历和事件（无选择记忆）。
