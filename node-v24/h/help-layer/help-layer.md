# help-layer

> 标签: a11y, accessibility, annotation, contextual-help, framework-agnostic, help-layer, help-mode, shadow-dom, tooltip, zero-dependency

## 简介

Framework-agnostic, zero-dependency, drop-in help mode for existing web apps — toggleable help markers with description popups, Shadow DOM piercing, and full cleanup.
