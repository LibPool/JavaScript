# hapi-ratelimit-mongoose

> 标签: hapi, hapijs, mongoose, rate limit

## 简介

This package is a Hapi.js plugin based on MongoDB & Mongoose that give a global rate limit control on your app/API. You can also set up some specific rate limits on each route config.
