# homebridge-platform-tecomat

> 标签: blinds, homebridge-plugin, ifoxtrot, jalousie, plc, shutter, teco, tecomat, window-covering

## 简介

Homebridge dynamic platform plugin for Teco / Tecomat iFoxtrot PLCs — auto-discovers jalousie blocks and exposes them as HomeKit window coverings.
