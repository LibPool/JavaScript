# homebridge-clearlight-sauna

> 标签: clearlight, gizwits, homebridge, homebridge-plugin, homekit, infrared, jacuzzi, sanctuary, sauna, siri

## 简介

Homebridge plugin for Clearlight/Jacuzzi infrared saunas via local LAN Gizwits protocol. Auto-discovers sauna on your network. No cloud required.
