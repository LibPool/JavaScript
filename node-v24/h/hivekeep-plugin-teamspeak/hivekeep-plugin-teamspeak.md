# hivekeep-plugin-teamspeak

> 标签: channel, hivekeep, hivekeep-plugin, teamspeak, tts, voice

## 简介

Bridge Hivekeep with a TeamSpeak server via the local ts-bot WebSocket API. Channel adapter (chat + TTS) + tools (move, speak, send chat, status, per-speaker WAV recording).
