# huckleberry-js

> 标签: baby, cloudflare, firebase, firestore, huckleberry, mcp, model-context-protocol, workers

## 简介

Unofficial TypeScript client (read + write) for the Huckleberry baby-tracking app (Firebase). Runs on Cloudflare Workers, Node 20+, and browsers. Not affiliated with Huckleberry Labs.
