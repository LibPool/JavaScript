# hyperbolic-map

> 标签: canvas, escher, geometry, hyperbolic, map, non-euclidean, poincare-disk, tiling

## 简介

Interactive viewer for vector maps of the hyperbolic plane, drawn in the Poincaré disk. Zero dependencies.
