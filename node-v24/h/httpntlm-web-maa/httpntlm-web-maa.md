# httpntlm-web-maa

> 标签: JavaScript

## 简介

fork of the famous httpntlm module by SamDecrock which is a library to do HTTP NTLM authentication, added an option to enable/disable strict ntlm, and made it work on the browser

## 官网

- 官网：https://github.com/maa105/node-http-ntlm#readme
- 源码仓库：git://github.com/maa105/node-http-ntlm.git
