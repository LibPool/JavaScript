# homebridge-broadlink-window-covering

> 标签: homebridge-plugin

## 简介

Homebridge Broadlink Window Covering is a plugin for Homebridge that allows you to control Broadlink RF window coverings. It provides an interface for controlling the open, close, and stop commands of the window coverings. The plugin is written in TypeScr
