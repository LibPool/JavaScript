# homebridge-ac-http

> 标签: ac, air-conditioner, apple-homekit, climate, cooler, esp32, esp8266, fan-speed, heater, heater-cooler, home-automation, homebridge, homebridge-plugin, homekit, http, http-api, humidity, hvac, ir-blaster, ir-remote, raspberry-pi, rest, rest-api, restful, smart-home, swing, temperature, thermostat

## 简介

Homebridge plugin for any HTTP/REST-controlled air conditioner — IR blasters, ESP8266, ESP32, and any device with a REST API. Supports composed commands, templates, dual-axis swing, humidity, fan speed mapping, and custom headers.
