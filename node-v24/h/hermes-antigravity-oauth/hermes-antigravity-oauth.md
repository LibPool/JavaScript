# hermes-antigravity-oauth

> 标签: agy, antigravity, gemini, hermes, hermes-agent, hermes-plugin, oauth

## 简介

One-command Google Antigravity sign-in for Hermes Agent: installs the antigravity-oauth provider plugin and runs the official agy OAuth flow.
