# habitcore-mcp

> 标签: adherence, agent-payments, base, behavioural-analytics, consistency, habits, mcp, model-context-protocol, streaks, usdc, x402

## 简介

MCP server for Habitcore — behavioural analytics over habit and routine data. Scores adherence, consistency, streaks and lapse risk. Pays per call with x402 (USDC on Base).
