# hibi-agent

> 标签: agent, availability, date, day, fixed-offset, life-engine, schedule, time, timezone

## 简介

日々：生活引擎的第一块——固定偏移的「一天」工具（本地墙钟、本地日、日常时段窗口），并把 daycrew 的依赖波次调度统一到同一个入口。Day/time primitives for 1:1 real-time life engines.
