# hebros-mcp

> 标签: ai-agents, code-index, llm, mcp, mcp-server, tree-sitter, typescript

## 简介

Token-cheap codebase maps for AI coding agents. MCP server: tree-sitter symbols with exact line numbers, import graph, call edges. Navigate code without read/grep loops.
