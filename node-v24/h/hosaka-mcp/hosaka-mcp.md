# hosaka-mcp

> 标签: agents, b2b, company-data, enrichment, mcp, modelcontextprotocol, technographics, x402

## 简介

Company facts for AI agents, paid per call in USDC on Base: domain age, mail and DNS providers, and every third-party vendor a company can be proven to use, each with the record that proves it. No signup, no API key.
