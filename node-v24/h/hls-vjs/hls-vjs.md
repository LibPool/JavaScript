# hls-vjs

> 标签: JavaScript

## 简介

Adds HLS playback support to [video.js 5.0+](https://github.com/videojs/video.js) using [hls.js library](https://github.com/video-dev/hls.js/).

## 官网

- npm 页面：https://www.npmjs.com/package/hls-vjs

## 历史版本号

- 当前版本：1.0.5

- 1.0.5

## 获取地址

- npm 安装：`npm install hls-vjs`
- npm registry：https://registry.npmjs.org/hls-vjs
