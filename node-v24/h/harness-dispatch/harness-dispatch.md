# harness-dispatch

> 标签: ai-agents, antigravity, claude, codex, coding, cursor, dispatch, llm, mcp

## 简介

Turn locally installed coding harnesses (Claude Code, Codex, Cursor, Antigravity) and local/remote API endpoints into tools any AI can call, with async job handling for long-running agent work.
