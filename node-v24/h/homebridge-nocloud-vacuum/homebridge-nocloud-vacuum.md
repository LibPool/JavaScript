# homebridge-nocloud-vacuum

> 标签: dreame, homebridge, homebridge-plugin, mqtt, nocloud, robot, vacuum, valetudo

## 简介

Homebridge plugin for Dreame robots running NoCloud (Valetudo) firmware — auto-discovers robots via MQTT and exposes per-room fans
