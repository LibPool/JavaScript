# hookshed

> 标签: agent, debugging, github, mcp, sandbox, shopify, stripe, webhook, webhook-testing, webhooks

## 简介

A webhook endpoint in one command: open a URL, point Shopify, Stripe or GitHub at it, read what arrived.
