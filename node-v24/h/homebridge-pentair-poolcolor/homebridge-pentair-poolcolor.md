# homebridge-pentair-poolcolor

> 标签: homebridge-plugin, pentair, pool, screenlogic

## 简介

Exposes a Pentair ScreenLogic pool/spa light circuit as a HomeKit color lightbulb. Pick a color on the Home app color wheel and the plugin sends the matching fixed-color command to the pool controller.
