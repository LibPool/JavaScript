# hash-code-string

> 标签: URL-safe, base64, code, decoding, encoding, friendly, hash, hashcode, hashing, short, string, url, utility

## 简介

Convert long strings into short, url-safe, hash-like strings. Limited to 32 bits of uniqueness.
