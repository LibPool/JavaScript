# homebridge-powerview-g3

> 标签: blinds, gen3, homebridge-plugin, hunter-douglas, powerview, shades, window-covering

## 简介

Homebridge plugin for Hunter Douglas PowerView Gen 3 shades, using the gateway's local REST API (no Matter, no cloud).
