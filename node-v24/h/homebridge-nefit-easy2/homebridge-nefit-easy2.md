# homebridge-nefit-easy2

> 标签: bosch, homebridge-plugin, homekit, nefit, nefit-easy, thermostat, xmpp

## 简介

Homebridge plugin for Nefit Easy thermostat using bosch-xmpp. Replaces the deprecated homebridge-nefit-easy on Node.js 22+.
