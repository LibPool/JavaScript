# huofengshui

> 标签: Core, Frontend, Library

## 简介

core => 核心方法，比较常用的一些方法 cookie => 操作cookie md5 => md5加密 tools => 通用工具类，每个工具是独立的 url => 对url的一些操作 sxhr => 与后端通信的ajax spromise => 对不支持的promise浏览器做兼容
