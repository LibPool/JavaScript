# hyperiux-mcp-server

> 标签: effects, hyperiux, mcp, model-context-protocol, registry, ui

## 简介

MCP server for browsing and installing Hyperiux Vault effects - lets AI clients search the catalog, inspect an effect's props/dependencies/changelog, and fetch installable source.

## 官网

- 官网：https://vault.hyperiux.com
- 源码仓库：git+https://github.com/Hyperiux-Immersion-Labs/hyperiux-components.git
