# hermes-chrome-companion

> 标签: agent, browser, chrome, companion, hermes, mcp

## 简介

Thin installer for Hermes Chrome local companion (bridge + native host). Not the Chrome extension runtime — clones/downloads from GitHub and runs install.sh.
