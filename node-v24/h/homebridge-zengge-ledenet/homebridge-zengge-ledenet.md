# homebridge-zengge-ledenet

> 标签: addressable, eave-lights, flux-led, homebridge-plugin, homekit, led, ledenet, magic-home, magichome, permanent-lighting, permanent-outdoor-lighting, pixel-led, rgb, zengge, zg-bl-hongrui

## 简介

HomeKit support via Homebridge for ZENGGE / LEDENET LED controllers running newer OEM firmware (model 0x6E, ZG-BL-HONGRUI) that existing Magic Home plugins cannot talk to.
