# human-machine-swapper

> 标签: aeo, agent, ai-search, answer-engine-optimization, custom-element, geo, llm, llms.txt, llmstxt, machine-readable, switcher, toggle, web-component

## 简介

A web component that adds a Human / Machine pill to any website. Machine shows the site's llms.txt, the plain-text reading written for language models, rendered in place. One file, about 6 KB gzipped, no dependencies and no build step.
