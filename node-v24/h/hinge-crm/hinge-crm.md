# hinge-crm

> 标签: adb, android, automation, cli, hinge, openai, uiautomator

## 简介

Hinge co-pilot driven over adb: scrape a profile, draft a like-comment with an LLM, type it onto the hooked card, log it, keep going. Needs adb + an Android device with USB debugging and an OpenAI API key.
