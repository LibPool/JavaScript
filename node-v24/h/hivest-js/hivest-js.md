# hivest-js

> 标签: api, decorators, dependency-injection, design-patterns, express, fast, framework, injection, middleware, minimalist, modular, modules, nodejs, simple, typescript

## 简介

A simple, fast and minimalist framework for Node.js that allows you to create modular applications with dependency injection using decorators
