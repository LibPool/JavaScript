# http-stats

> 标签: capacity planning, graph, http, load testing, performance, server, stats

## 简介

Module for benchmarking HTTP servers with support for metrics such as response time, requests per second and CPU and memory usage. Generates friendly HTML reports and offers both a command line interface and a JavaScript API.
