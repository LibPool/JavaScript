# homebridge-bluetooth-led-lights-tg

> 标签: bluetooth, homebridge-plugin, homekit, led, lights

## 简介

A Homebridge plugin to control Bluetooth-enabled LED light strips in homekit. No password or pin required for the Bluetooth connection.
