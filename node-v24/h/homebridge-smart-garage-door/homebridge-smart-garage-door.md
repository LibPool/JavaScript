# homebridge-smart-garage-door

> 标签: garage, garage-door-opener, garagedoor, gpio, homebridge, homebridge-plugin, homekit, libgpiod, raspberry-pi

## 简介

Homebridge garage door opener accessory for Raspberry Pi GPIO (relay + 0/1/2 door sensors), using libgpiod via its Python bindings
