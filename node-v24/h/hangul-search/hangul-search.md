# hangul-search

> 标签: Hangul, Korean, Korean initial consonant, chosung, search, 초성, 초성검색, 한글

## 简介

Json객체에서 한글 검색을 수행. 한글 초성 검색을 지원. Korean search within JSON objects. Supports Korean initial consonant search.
