# homebridge-rpi-monitor

> 标签: cpu, homebridge-plugin, monitor, raspberry-pi, raspberrypi, temperature, undervoltage

## 简介

A minimal Homebridge plugin exposing Raspberry Pi CPU temperature and undervoltage status to HomeKit via a lightweight companion HTTP server — no pigpiod/rgpiod required.
