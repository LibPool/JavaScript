# hetzup

> 标签: JavaScript

## 简介

**hetzup** lets you spin up [Hetzner Cloud](https://www.hetzner.com/cloud/) servers on-demand and automatically configures a reverse proxy for SSH and web. This means that you only pay when you're actually using a server while keeping stable SSH & web acc
