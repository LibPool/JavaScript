# handova

> 标签: accounts, ai-agents, claude, claude-code, cli, codex, openai

## 简介

Got more than one Claude Code or Codex account? Switch between them without logging out, hand a conversation and its memory to another when one hits its usage limit, and keep every account's profile clean.
