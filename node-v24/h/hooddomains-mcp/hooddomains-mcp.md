# hooddomains-mcp

> 标签: domains, ens, hood, mcp, robinhood-chain, web3

## 简介

MCP server for Hood Domains — resolve, look up, and register .hood names on Robinhood Chain. All on-chain, no backend.

## 官网

- 官网：https://www.hood.domains
- 源码仓库：git+https://github.com/Hooddomains/hoodmcp.git
- npm 页面：https://www.npmjs.com/package/hooddomains-mcp

- npm 安装：`npm install hooddomains-mcp`
- npm registry：https://registry.npmjs.org/hooddomains-mcp
- Node 要求：>=18
