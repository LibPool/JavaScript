# hexo-post-webauthn-encrypt

> 标签: encrypt, encryption, fido2, hexo, hexo-plugin, passkey, password, webauthn

## 简介

A Hexo plugin that encrypts post HTML and decrypts it with WebAuthn PRF or an optional password.
