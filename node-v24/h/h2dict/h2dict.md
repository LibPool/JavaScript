# h2dict

> 标签: JavaScript

## 简介

*    常用榜。 *    模糊查询 (编辑距离、类SublimeText)，用于查找不能完全拼写出来的单词。 *    形似词，用于对比区分拼写相近易混淆的单词。 *    音似词，用于对比区分读音相近易混淆的单词。
