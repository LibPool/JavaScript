# hivelearn-mcp

> 标签: agent, anthropic, claude, community, hivelearn, lms, mcp, model-context-protocol

## 简介

Official stdio MCP server for HiveLearn — lets AI agents read and author communities, courses, events, quizzes, and certificates through the HiveLearn public API.
