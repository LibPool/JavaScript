# huge-uploader

> 标签: big file upload, chunked upload, fault tolerent, file api, file upload, huge file upload, pausable upload, resumable upload, upload

## 简介

Module to handle huge file uploads by chunking them in the browser. Resumable, fault tolerent, offline aware, mobile ready.
