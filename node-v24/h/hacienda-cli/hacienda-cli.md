# hacienda-cli

> 标签: aeat, cli, declaracion, hacienda, irpf, modelo-100, renta, spain, tax

## 简介

CLI para interactuar con la sede electrónica de la AEAT. Descarga datos fiscales, sube declaraciones XML (Modelo 100). Nunca presenta ni firma.
