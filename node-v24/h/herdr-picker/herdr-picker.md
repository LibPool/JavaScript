# herdr-picker

> 标签: ai, chrome-extension, claude-code, coding-agent, devtools, dom, element-picker, herdr, native-messaging

## 简介

Pick a DOM element on any page in Chrome and send it, with a prompt, to a coding agent running in herdr.
