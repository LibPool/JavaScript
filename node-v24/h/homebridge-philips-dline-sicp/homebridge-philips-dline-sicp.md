# homebridge-philips-dline-sicp

> 标签: d-line, homebridge-plugin, philips, sicp, signage, television

## 简介

Homebridge plugin to control Philips D-Line signage displays (e.g., 55BDL4511D) over LAN using SICP (TCP:5000). Exposes as a HomeKit Television with inputs.
