# hexo-deployer-s3-plus

> 标签: aws, deployer, hexo, s3

## 简介

A flexible Hexo deployer for AWS S3 and other S3-compatible services like Tebi.io, MinIO, and Cloudflare R2. Updated for Hexo 7.
