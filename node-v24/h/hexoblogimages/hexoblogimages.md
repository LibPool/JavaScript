# hexoblogimages

> 标签: 博客, 图片

## 简介

本仓库为个人博客的静态资源仓库，通过 GitHub 的 Actions 进行 npm publish 操作，推送到 npm 上，然后作为CDN静态资源用于个人博客上。

## 官网

- 官网：https://github.com/blhorizon/HexoBlogImages#readme
- 源码仓库：git+https://github.com/blhorizon/HexoBlogImages.git
