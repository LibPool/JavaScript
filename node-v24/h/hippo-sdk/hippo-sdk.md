# hippo-sdk

> 标签: JavaScript

## 简介

`hippo-sdk` is a WebAssembly-based npm library for cryptographic operations, including **key pair generation**, **ECDH encryption**, **ECDSA signing**, and **DID management**. It's built with Rust for high performance and compiled to WebAssembly for seaml
