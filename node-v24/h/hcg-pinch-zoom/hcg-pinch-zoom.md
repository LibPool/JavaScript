# hcg-pinch-zoom

> 标签: drag, gesture, image-viewer, image-zoom, javascript, no-dependencies, pinch, pinch-zoom, touch, ui-component, vanilla-js, wheel, zoom

## 简介

Lightweight dependency-free vanilla JavaScript library for pinch and wheel zoom with drag. Touch pinch, trackpad pinch, Ctrl+wheel, min/max scale, and focal-point zoom.
