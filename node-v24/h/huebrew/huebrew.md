# huebrew

> 标签: cli, color-palette, color-scheme, color-thief, design-tokens, dominant-color, image-colors, median-cut, oklch, palette-extractor, tailwind-colors, theme-generator, zero-dependency

## 简介

Brew a color palette & ready-to-use theme tokens from any image — dominant colors via median-cut, perceptual OKLab ramps, and CSS/SCSS/Tailwind/JSON/SVG export. CLI + library + web app. Zero dependencies, 100% local.
