# hormigasais-edge-starter

> 标签: agent-based, edge-computing, hormigasais, lbh-protocol, offline-first, sovereign-node, termux

## 简介

Starter template para desplegar un nodo soberano HormigasAIS con agentes LBH. Incluye SDK de protocolos LBH, generadores automáticos y agentes edge.
