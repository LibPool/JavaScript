# hls-ad-inserter

> 标签: JavaScript

## 简介

This project provides a tool to parse HLS m3u8 manifests and insert `EXT-X-DATERANGE` tags for ad breaks (Preroll, Midroll, Postroll). It uses the `hls-parser` library.
