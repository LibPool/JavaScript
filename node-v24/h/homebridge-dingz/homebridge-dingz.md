# homebridge-dingz

> 标签: dingz, homebridge-plugin, iot, smarthome

## 简介

Homebridge Plugin for dingz & myStrom Devices. Implements some (but not all, due to API limitations) functions of a [dingz](https://dingz.ch) Smart Home Device.
