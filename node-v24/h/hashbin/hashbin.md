# hashbin

> 标签: NestJs, argon2, bcrypt, crypto, hashbin, pbkdf2, typescript

## 简介

Hashbin is The Wrapper Module That Supports Various Hashing and Encryption Algorithms (Bcrypt, Argon2, PBKDF2) in NestJS
