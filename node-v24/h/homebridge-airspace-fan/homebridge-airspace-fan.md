# homebridge-airspace-fan

> 标签: airscape, attic-fan, cgi, fan, homebridge, homebridge-plugin, homekit, whole-house-fan

## 简介

A Homebridge plugin to control AirScape-style whole-house fans via their fanspd.cgi HTTP interface, with optional attic temperature sensor support.
