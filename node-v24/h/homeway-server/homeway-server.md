# homeway-server

> 标签: JavaScript

## 简介

Homeway server binaries (Go + patched sing-box) for linux amd64/arm64 and the host installer. Published from CI when a main commit is tagged for release (scripts/tag-release.sh); installed on hosts by install-release.sh.
