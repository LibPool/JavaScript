# halu-map

> 标签: Leaflet, OpenLayers

## 简介

由 JavaScript 语言编写的 GIS 客户端应用开发包， 基于SuperMap开源代码， 支持多源数据地图，支持多终端，跨浏览器， 可快速实现浏览器上美观、流畅的地图呈现。
