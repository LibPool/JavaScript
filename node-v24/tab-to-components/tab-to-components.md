> 标签: click-to-component, click-to-source, clipboard, component-inspector, copy-file-name, cursor, custom-editor, dev-only, devtools, dx, jsx-source, open-in-editor, open-in-ide, react, react-18, react-19, react-router, react-router-dom, react-router-v7, react-router-v8, remix, tanstack-start, trae, vite, vite-plugin, vite-plugin-react, webstorm

## 简介

Alt+click a React element in your dev server to open its JSX source in your editor or copy the file name to the clipboard. Dev-only Vite plugin with first-class React Router v6/v7/v8, TanStack Start and Remix v2 support, React 18 and 19, Vite 6-8. Choose
