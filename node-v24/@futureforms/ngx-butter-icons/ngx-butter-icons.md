# @futureforms/ngx-butter-icons

> 标签: JavaScript

## 简介

**ngx-butter-icons** is a set of icons for easy scalable vector graphics on websites and in web application created with the Angular framework, created and maintained by [Future Forms](https://futureforms.studio).
