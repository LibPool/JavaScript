# @aiblackbox/cli

> 标签: agent, ai, audit, claude, compliance, evidence, mcp, provenance, tamper-evident

## 简介

BLACKBOX — the flight recorder for AI agents. One command to enroll a device, record every Claude Code / MCP tool call into a tamper-evident hash-chained + signed log, anchor it to a public timestamp, ship to a fleet, and verify offline.
