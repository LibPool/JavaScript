> 标签: ai, caa, certificate-authority, claude, cursor, dns, domain, llm, lookup, mcp, mcp-server, model-context-protocol, nameserver, network, tls, whois

## 简介

MCP server for DNS lookups, including CAA checks, reverse DNS, and RDAP-first domain or IP registration data with WHOIS fallback; zero auth, zero config
