# @voltro/plugin-queue

> 标签: framework, typescript, voltro

## 简介

Queue interop — consume and produce against an existing Kafka: Schema-decoded consumers via defineQueueConsumer (*.consumer.ts; at-least-once, serial per partition, retry + dead-letter), batched producing via QueueService or transactionally through the ou
