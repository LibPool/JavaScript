> 标签: backend, cloud, developer-tools, durable-execution, edge, event-driven, functions, microservices, observability, queue-management, react-style, reliability, scalability, sdk, serverless, signal-handling, typescript, zero-infrastructure

## 简介

Fns is the React for backend development, making serverless functions invincible. It offers a zero-infrastructure platform with reliable execution, signal handling, all with built-in observability.
