# romdev-toolchain-decomp-gcc

> 标签: JavaScript

## 简介

The gcc toolchains N64 and PS1 matching-decompilation projects pin (KMC gcc 2.7.2 with binutils 2.6 as; EGCS 1.1.2 with binutils 2.9.5 as; gcc 2.6.3-psx cc1; gcc 14.2 for mips-linux-gnu) and the build tools they run (slinky, pigment64, crunch64), bundled
