# @apexdevtools/apex-log-parser

> 标签: apex, apex-log, apex-logs, call-tree, debug-log, debug-logs, developer-tools, dml, governor-limits, log-analysis, log-parser, parser, performance, salesforce, salesforce-apex, sfdc, soql, typescript

## 简介

Turn a Salesforce Apex debug log into a typed event tree with execution timings, governor limits and SOQL/DML counts. No dependencies.
