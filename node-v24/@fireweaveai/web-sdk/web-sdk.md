# @fireweaveai/web-sdk

> 标签: browser, control-points, feature-flags, fireweave, progressive-delivery, release-engineering, web

## 简介

Fireweave SDK for browsers: control points and target registration, in remote (fw-server) or local (in-process, no network) mode. Holds no secrets.
