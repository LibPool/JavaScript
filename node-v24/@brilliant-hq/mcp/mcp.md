# @brilliant-hq/mcp

> 标签: JavaScript

## 简介

No-config local MCP bridge for brilliant.design — a dumb stdio<->loopback router. Your coding agent drives your live web tab (or the desktop app); zero bytes touch Brilliant's servers.
