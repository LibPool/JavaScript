# multi-gmail-connector

> 标签: claude, email, gmail, local-first, mcp, model-context-protocol, multi-account

## 简介

Multi-Gmail Connector for Claude: a free, local-first, read-only MCP server that lets Claude search several Gmail accounts at once. Tokens stay in your OS keychain.
