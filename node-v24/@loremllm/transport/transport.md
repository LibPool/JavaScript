# @loremllm/transport

> 标签: agent, ai, ai-sdk, chat, chatbot, demo, eve, llm, mock, static-chat, streaming, testing, transport, ui-message, vercel-ai-sdk

## 简介

A lightweight transport implementation for the [Vercel AI SDK UI layer](https://ai-sdk.dev/docs/ai-sdk-ui/transport). It lets you describe the exact `UIMessage[]` the UI should display and streams the message back to the client without touching your netwo
