# @savvifi/meridian-launchpad

> 标签: JavaScript

## 简介

The command-palette / launchpad renderer of the meridian renderer family: renders a meridian.ui.v1 Launchpad descriptor (command_palette.proto) as a ⌘K palette, dispatching each Command's action through the meridian-web-react ComponentKit / RpcInvoker sea
