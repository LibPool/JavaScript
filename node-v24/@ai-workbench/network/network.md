# @ai-workbench/network

> 标签: deepseek-harness, dsh, dsh-plugin

## 简介

安装：在 DSH「插件 → 添加插件」填写 `@ai-workbench/network@0.4.4`，或运行 `dsh plugin --profile desktop add @ai-workbench/network@0.4.4`。
