# backlogsync

> 标签: backlog, github-action, github-issues, milestones, roadmap, zero-dependency

## 简介

BACKLOG.md as the single source of truth: a generated ROADMAP.md, a check for CI, and a one-way sync to GitHub issues and milestones. Zero dependencies.
