> 标签: ai, api-key, base, blockchain, claude, gemini, llm, micropayments, openai, openai-compatible, smart-routing, solana, usdc, x402

## 简介

TypeScript SDK for BlockRun - every frontier model behind one OpenAI-compatible client. Pay with a BlockRun API key or per-call in USDC. Smart routing picks the cheapest capable model. No rate limits.
