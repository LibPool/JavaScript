# @onrank/sdk

> 标签: bonding-curve, launchpad, onrank, ton, ton-connect, trading-bot

## 简介

ONRANK (TON launchpad) integration SDK: on-chain quotes and unsigned TON Connect messages for buying and selling coins on the curve and the pool. No keys, no network required.
