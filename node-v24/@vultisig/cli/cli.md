# @vultisig/cli

> 标签: agent-ask, ai-agent-cli, bitcoin-cli, blockchain, claude-code, cli, crypto, crypto-cli, cursor, mpc, mpc-wallet-cli, multi-chain-wallet, multi-party-computation, opencode, seedless, self-custody, thorchain-cli, threshold-signatures, tss, vsig, vultisig, wallet, wallet-cli

## 简介

The self-custody MPC wallet CLI for AI coding agents (Claude Code, Cursor, OpenCode). Natural-language agent mode, 36+ chains, DKLS23 threshold signatures. Seedless.
