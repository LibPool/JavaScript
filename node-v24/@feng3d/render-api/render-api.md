# @feng3d/render-api

> 标签: JavaScript

## 简介

提供WebGL/WebGPU统一的渲染数据结构，描述渲染所需的所有数据以及流程，用于@feng3d/webgl与@feng3d/webgpu。

## 官网

- 官网：https://feng3d.com/render-api/
- 源码仓库：git+https://github.com/feng3d-labs/render-api.git
- npm 页面：https://www.npmjs.com/package/@feng3d/render-api
