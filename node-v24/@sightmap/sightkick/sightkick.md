# @sightmap/sightkick

> 标签: agent, cli, sightkick, sightmap, webmcp, yaml

## 简介

sightkick — compile a .sightkick/ tool layer + sightmap corpus into WebMCP tool IR, and install the sightkick agent skills (native binary, no Go toolchain required)
