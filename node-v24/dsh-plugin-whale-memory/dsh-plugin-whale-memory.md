# dsh-plugin-whale-memory

> 标签: agent, dsh, long-term-memory, memory, plugin

## 简介

鲸鱼娘长期使用插件：三层长期记忆（核心 / 脑区 / 外围），带 TTL、上限、归档、文件锁、关键词/模糊召回与 180 天脑区降级，供 DSH agent 使用。
