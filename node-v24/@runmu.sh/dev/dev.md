# @runmu.sh/dev

> 标签: dev-server, extension, hot-reload, muclient, mud, runmu

## 简介

The μClient extension dev server: watch, build with esbuild, serve on localhost with CORS, push hot reloads over Server-Sent Events and a headless test host that replays .murec recordings (@runmu.sh/dev/test).
