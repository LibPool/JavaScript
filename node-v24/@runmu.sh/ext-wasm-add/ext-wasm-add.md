# @runmu.sh/ext-wasm-add

> 标签: example, muclient-extension, wasm

## 简介

The mu.wasm.load example: a panel that calls add(a, b) in a 41-byte hand-written WebAssembly module (wasm/add.wat), pinned by sha256 in muclient.wasm.
