# @runmu.sh/ext-mooedit

> 标签: codemirror, editor, lambdamoo, mcp, moo, simpleedit

## 简介

Edit MOO verbs, properties and notes in a real code editor: MOO syntax colours, a linter, snippets, a diff before you save. Handles MCP simpleedit and LambdaCore local edit.
