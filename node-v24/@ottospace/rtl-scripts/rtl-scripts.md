# @ottospace/rtl-scripts

> 标签: arabic, bidi, detection, i18n, ottospace, rtl, scripts, unicode

## 简介

Zero-dependency world-scripts table + RTL/bidi/shaping-aware detection shared by the OttoSpace RTL toolchain (miraat, lahja, kashida). Runtime-independent script detection (explicit Unicode ranges, not ICU-version-dependent \p{Script}).
