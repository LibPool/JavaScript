# @snowseo/beacon-server

> 标签: ai, ai-crawlers, analytics, bot-detection, gptbot, rfc-9421, self-hosted, web-bot-auth

## 简介

Server side of the beacon protocol: AI crawler verification (provider IP ranges, datacenter detection, reverse DNS, Web Bot Auth) plus a reference ingest server.
