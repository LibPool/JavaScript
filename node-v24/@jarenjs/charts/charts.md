# @jarenjs/charts

> 标签: bar, charts, headless, jaren, line, pie, scatter, streaming, svg, vnode

## 简介

Headless charts for the jaren suite: chart definitions compiled to a geometry-free AST and rendered as pure-vnode SVG through @jarenjs/view — SSR-able, structurally shared, themeable via host-linked tokens
