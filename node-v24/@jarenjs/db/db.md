# @jarenjs/db

> 标签: database, document-store, jaren, json, json-schema, postgres, postgresql, sqlite

## 简介

Document storage for the Jaren suite: a model document declares collections as JSON Schemas with indexes; openStore applies DDL through a dialect and gives transactional, schema-validated reads and writes over SQLite (Node, Bun, or an injected wasm handle
