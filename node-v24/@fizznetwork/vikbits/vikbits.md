# @fizznetwork/vikbits

> 标签: ai, electron, plugin-sdk, social-posting, tim-fam, vik-fam, vikbits, viki

## 简介

SDK for authoring VikBit chips - plugins for Viki, the pink-chip Tim Fam sibling. Validate manifests, scaffold new chips, import the init() contract types.
