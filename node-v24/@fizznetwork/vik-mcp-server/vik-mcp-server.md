> 标签: ai, ai-tools, big-vik-claw, chatgpt, claude, claude-desktop, cursor, fizznetwork, mcp, model-context-protocol, scheduler, social-media

## 简介

MCP (Model Context Protocol) server for Big Vik Claw — exposes Vik's tools (social posting, scheduler, brand cards, file I/O, datetime) to any MCP-compatible AI client. Self-heals when Big Vik Claw restarts via tools/list_changed notifications.
