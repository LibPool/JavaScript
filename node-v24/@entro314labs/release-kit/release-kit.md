# @entro314labs/release-kit

> 标签: changelog, cli, github-release, npm-publish, release, release-automation, semver, tag, versioning, zero-dependency

## 简介

Single-file, zero-dependency release mechanism for JS/TS/Node projects: version bump, changelog roll, commit, annotated tag, push, publish, GitHub release
