# @objectstack/connector-mcp

> 标签: ai, connector, integration, mcp, model-context-protocol, objectstack, tools

## 简介

Model Context Protocol (MCP) connector for ObjectStack — a generic adapter that turns any MCP server's tools into a connector's actions on the automation engine's connector registry (ADR-0024).
