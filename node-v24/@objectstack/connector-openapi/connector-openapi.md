# @objectstack/connector-openapi

> 标签: api, connector, integration, objectstack, openapi, swagger

## 简介

OpenAPI 3.x connector generator for ObjectStack — turns a declarative OpenAPI document into connector actions on the automation engine's registry, with a self-contained static-auth HTTP transport (ADR-0023).
