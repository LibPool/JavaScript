# @soulcode/bexio-oauth

> 标签: bexio, oauth, oidc, openid-connect, postgres, token

## 简介

Bexio OAuth token custody for Node apps: connect Bexio accounts, store tokens encrypted in Postgres, get a valid access token anywhere.
