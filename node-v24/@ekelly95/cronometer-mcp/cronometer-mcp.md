# @ekelly95/cronometer-mcp

> 标签: claude, cronometer, food-log, macros, mcp, micronutrients, model-context-protocol, nutrition

## 简介

MCP server for your Cronometer account: the full diary over Cronometer's mobile API, honest coverage-aware nutrition (missing is never zero), safe writes, and an optional OAuth remote connector.
