# @rebodocs/editor

> 标签: docx, editor, vanilla, word, word-processor, wysiwyg

## 简介

A DOCX editor for the browser: pages, caret and selection, toolbar, menu, side panel and status bar. No framework.

- 官网：https://rebodocs.com/docs/vanilla/
