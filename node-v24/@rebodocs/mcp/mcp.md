# @rebodocs/mcp

> 标签: ai, assistant, claude, docx, editor, mcp, model-context-protocol, word

## 简介

Tools for an AI assistant to read and edit DOCX documents: an MCP server for Claude Desktop and other clients, and Claude in a chat beside the editor.
