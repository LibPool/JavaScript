# @affordant/server

> 标签: affordance, hateoas, hypermedia, node, rest, server

## 简介

Server-side builder for the Affordant hypermedia envelope. Framework-agnostic: declare affordances once, gate them on state, emit _self / _actions that the affordant client consumes.
