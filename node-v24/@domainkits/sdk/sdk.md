# @domainkits/sdk

> 标签: certificate-transparency, dns, domain-api, domain-data, domain-search, domainkits, expired-domain-search, expired-domains, expired-domains-data, newly-registered-domains, newly-registered-domains-api, newly-registered-domains-list, search-expired-domains, search-newly-registered-domains, whois

## 简介

TypeScript client for the DomainKits REST API. Search expiring, newly registered, aged, active, deleted and marketplace domains, plus hostname search, WHOIS, DNS, Certificate Transparency and trends.
