# @hartewired/md-to-gdoc

> 标签: agent, automation, batchupdate, cli, docs-api, gdoc, google, google-docs, llm, markdown, oauth, stateless, zero-dependency

## 简介

Turn markdown into a nicely formatted Google Doc. A pure, zero-dependency markdown -> Docs API batchUpdate request builder (does the painful index math for you), plus an optional stateless CLI.
