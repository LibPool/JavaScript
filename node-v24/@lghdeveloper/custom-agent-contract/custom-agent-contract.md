# @lghdeveloper/custom-agent-contract

> 标签: ai-agent, api-contract, custom-agent, mcp, types, zod

## 简介

Shared, framework-agnostic API contract (zod schemas + TypeScript types) for the Custom Agent project. Consumed by both the self-hosted server and the React Native app so the two never drift.
