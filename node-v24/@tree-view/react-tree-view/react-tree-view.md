# @tree-view/react-tree-view

> 标签: checkbox, filter, performance, react, tree, treeview, virtualized

## 简介

High performance virtualized React tree with tri-state checkboxes, deep expand/collapse, filtering, wrapping labels, hover child highlight and context menus.
