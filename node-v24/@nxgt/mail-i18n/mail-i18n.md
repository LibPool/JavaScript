# @nxgt/mail-i18n

> 标签: email, i18n, icu, maizzle, messageformat, vue

## 简介

An i18n plugin for a Maizzle project: ICU catalogues checked at build time, t() in templates, one output per locale, and the manifest the renderer reads. createTranslator for use outside templates.
