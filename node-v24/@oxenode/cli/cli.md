# @oxenode/cli

> 标签: JavaScript

## 简介

Oxenode's cli lets you to create an Oxenode plugin project with all the tools required for development. You can find a documentation article on [creating your plugin](https://oxenode.io/docs/Create-a-plugin/) on the official site.
