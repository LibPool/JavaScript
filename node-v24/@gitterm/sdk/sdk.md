# @gitterm/sdk

> 标签: JavaScript

## 简介

TypeScript SDK for the [GitTerm](https://gitterm.dev) API: create sandboxed workspaces for a repository, run an agent in them, and relay the questions it asks back to a human. Used by the `gitterm` CLI, the OpenCode plugin, and integrations such as Slack
