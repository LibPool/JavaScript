# maclaya

> 标签: apple-silicon, jev, laya, local-ai, mlx, system-one, typesafe

## 简介

Run Laya typed-decision models locally on Apple Silicon behind a Jev (TypeSafe System One) compatible API, with a dashboard and playground.
