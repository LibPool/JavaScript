# @pq-jose/jose

> 标签: authentication, encryption, fips-203, fips-204, fips-205, jose, jwe, jwk, jwks, jws, jwt, ml-dsa, ml-kem, nist, nodejs, post-quantum, pq-jose, pq-jwt, pqc, signing, slh-dsa, typescript

## 简介

Part of the PQ-JWT ecosystem. Built on @pq-jwt/core for post-quantum signing; adds JWE, JWK, and JWKS (jose-compatible API). NIST FIPS 203/204/205 via @noble/post-quantum.
