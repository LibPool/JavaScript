# @bloklabs/react

> 标签: block-based, block-editor, blok, contenteditable, editor, headless, json, notion, notion-like, react, react-component, rich-text-editor, typescript, wysiwyg

## 简介

React block editor — official React bindings for Blok, the headless Notion-like rich text editor. Hooks and components that render blocks and save to JSON.
