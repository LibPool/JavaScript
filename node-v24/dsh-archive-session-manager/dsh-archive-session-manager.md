# dsh-archive-session-manager

> 标签: archive, deepseek-harness, delete, dsh, plugin, session

## 简介

归档会话管理：在会话「···」菜单中为已归档会话提供「删除会话」，并提供一个归档会话管理面板（多选、批量删除、批量取消归档）。
