# kikiui-html

> 标签: a11y, accessible, components, css, dark-mode, design-system, html, kiki, no-framework, ui, ui-kiki, vanilla, vanilla-js, wordpress

## 简介

KIKI UI HTML: the vanilla HTML, CSS and JavaScript edition of the KIKI UI design system. Tokens, CSS-only components and lightweight, accessible behaviours you can load one component at a time. No React, no Tailwind, no runtime dependencies.
