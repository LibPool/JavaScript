# dsh-plugin-weixin

> 标签: asr, bot, channel, cordis, deepseek-harness, dsh, dsh-plugin, ilink, wechat, weixin

## 简介

Weixin (personal WeChat, iLink Bot API) channel plugin for DeepSeek Harness — command a DSH agent from WeChat, with images, files and voice-note transcription.
