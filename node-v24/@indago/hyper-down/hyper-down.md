# @indago/hyper-down

> 标签: cms, fts5, full-text-search, headless-cms, markdown, mcp, mdx, nextjs, react, react-router, sqlite, ssr, static-site, tanstack, vike, vite, vite-plugin

## 简介

Markdown/MDX → SQLite (FTS5 contentless) → server-side route loaders. A drop-in SSR headless CMS for Vike, React Router, TanStack Start, and Next.js — zero backend service.
