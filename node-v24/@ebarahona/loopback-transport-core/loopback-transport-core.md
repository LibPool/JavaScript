# @ebarahona/loopback-transport-core

> 标签: event-driven, execution-context, extension, grpc, kafka, loopback, loopback4, loopback4 extension, message-handler, microservices, mqtt, nats, rabbitmq, transport

## 简介

Transport-agnostic microservice primitives for LoopBack 4 — message handlers, event patterns, execution context, and client proxies for Kafka, RabbitMQ, gRPC, MQTT, and NATS.
