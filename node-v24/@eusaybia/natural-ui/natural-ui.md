# @eusaybia/natural-ui

> 标签: JavaScript

## 简介

Natural UI — Eusaybia's component library. Ships the local-first collaborative rich text editor (Tiptap + Yjs + IndexedDB + Tiptap Cloud) with a prebuilt WKWebView artifact for native apps.
