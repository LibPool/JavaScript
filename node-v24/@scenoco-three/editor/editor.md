# @scenoco-three/editor

> 标签: editor, gamedev, gizmo, inspector, scene, scenoco, three, threejs, xml

## 简介

The standalone SceNoCo editor: a static site that opens any .scene.xml from a folder or a URL, builds the scene live, and saves back — a tree, an inspector, gizmos. `scenoco-editor` serves it locally.
