# @scenoco-three/observer

> 标签: agent, gamedev, mcp, observer, scenoco, screenshot, simulate, three, threejs

## 简介

An agent's eyes on a SceNoCo scene: an MCP server over stdio that compiles the project, runs the scene in a headless Chrome it owns, renders it from stated viewpoints, drives it frame by frame, and reads it back as text.
