# @kache/sdk

> 标签: dapp, kache, kaspa, provider, sdk, wallet

## 简介

dApp connector for the Kache wallet — Kaspa L1 via window.kache plus the Kasplex / Igra EVM L2s via window.ethereum (EIP-1193 / EIP-6963).
