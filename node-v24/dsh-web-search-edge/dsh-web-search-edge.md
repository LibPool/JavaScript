# dsh-web-search-edge

> 标签: bing, deepseek-harness, dsh, dsh-plugin, edge, free, keyless, shenma, web-search

## 简介

Keyless, zero-cost web_search for DeepSeek Harness: renders Shenma with your local Edge browser over CDP and reads Bing over HTTP. No API key, no model call, no bill.
