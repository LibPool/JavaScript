# @tarhnama/store

> 标签: docx, editor, markdown, outline, persian, prosemirror, rtl

## 简介

Persistence for an outline workspace: pluggable adapters, per-document records, debounced autosave and schema migration. IndexedDB in the browser, in-memory everywhere else.
