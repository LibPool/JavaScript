# @miracledesign/design-tokens

> 标签: design system, design tokens, miracle, miracle design tokens, style dictionary

## 简介

Miracle Design Tokens are the single source of truth for core design values, stored in a technology-agnostic JSON format to ensure consistency across Miracle products.
