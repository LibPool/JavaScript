# @contentstack/contentstack-spartacus-connector

> 标签: angular, composable-storefront, contentstack, headless-cms, sap-commerce-cloud, spartacus

## 简介

Contentstack CMS feature library for SAP Composable Storefront (Spartacus). Overrides the Spartacus CMS layer so page and component content resolve from Contentstack, while SAP OCC remains the commerce engine.
