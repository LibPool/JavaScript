# @veltdev/chat-sdk-adapter

> 标签: bot, chat-adapter, chat-sdk, collaboration, comments, velt

## 简介

Chat SDK adapter for Velt: build bots that read, reply, mention, and start threads in anchored comments across documents, editors, canvases, PDFs, and video.
