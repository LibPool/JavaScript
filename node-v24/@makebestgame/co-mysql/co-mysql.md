# @makebestgame/co-mysql

> 标签: co-mysql, mysql

## 简介

@makebestgame/co-mysql is a [mysql](https://github.com/mysqljs/mysql) wrapper to be used with [visionmedia's co](https://github.com/visionmedia/co) library which has a centralized config.
