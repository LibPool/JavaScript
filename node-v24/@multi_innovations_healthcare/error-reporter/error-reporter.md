# @multi_innovations_healthcare/error-reporter

> 标签: discord, elysia, error-tracking, react, webhook

## 简介

Lightweight error tracking that reports to a Discord webhook. Elysia plugin (server) + React helpers (client), with dedupe and rate-limiting.
