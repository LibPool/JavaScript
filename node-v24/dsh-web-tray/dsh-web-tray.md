# dsh-web-tray

> 标签: deepseek, dsh, harness, launcher, shortcut, tray, windows, wsl

## 简介

Windows tray icon and Start menu entry for `dsh web` running inside WSL — open and exit only, no watchdog (fork of dsh-wsl-tray)
