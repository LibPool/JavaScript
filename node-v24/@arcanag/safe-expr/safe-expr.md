# @arcanag/safe-expr

> 标签: calculator, evaluator, expr-eval, expression, formula, jsep, safe, sandbox

## 简介

A sandboxed expression evaluator for user-written formulas. expr-eval compatible syntax, built on jsep, with no route from an expression to JavaScript's object model.
