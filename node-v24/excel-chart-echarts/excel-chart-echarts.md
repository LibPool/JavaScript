# excel-chart-echarts

> 标签: chart, converter, drawingml, echarts, excel, ooxml, spreadsheet, xlsm, xlsx, xltm, xltx

## 简介

Convert embedded native Excel charts (DrawingML in .xlsx/.xlsm/.xltx/.xltm) into Apache ECharts options — not whole-workbook charting; TypeScript & Python, zero-dependency, with CLI
