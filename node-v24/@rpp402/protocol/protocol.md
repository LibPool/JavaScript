# @rpp402/protocol

> 标签: json schema, protocol, robinhood payments protocol, rpp402, types

## 简介

RPP402 protocol source of truth: JSON Schemas and TypeScript types for the six v1 primitives (Discovery, Quote, Commerce Session, Payment Intent, Settlement, Receipt).
