# @boarderless/mcp-server

> 标签: agentic-ui, boarderless, mcp, model-context-protocol, puppeteer, spatial-canvas

## 简介

Model Context Protocol (MCP) server for Boarderless, allowing Ai agents to read the canvas state, mutate Objects, and calculate export bounds.
