# @farview/cli

> 标签: JavaScript

## 简介

Farview 中继 CLI —— 本地零依赖 WS relay + 内嵌 viewer 单文件 + 自动 Cloudflare 隧道（发布于 @farview scope，bin 命令为 farview）
