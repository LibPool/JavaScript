# dsh-whitelist-auto-approval

> 标签: allowlist, approval, bash, bundle, deepseek-harness, dsh, plugin, sandbox, settings, web-ui, whitelist

## 简介

Per-command sandbox allow-list for the DSH bash tool, managed from Settings and the Plugins page: allow-listed CLIs run under a home-writable sandbox instead of prompting for danger-full-access.
