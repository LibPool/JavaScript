# @junpenn/xbridge-sdk

> 标签: JavaScript

## 简介

Type-safe SDK for XBridge. It exposes the same actions, execution modes, DTOs, errors, pagination, and capability metadata used by the XBridge CLI, API, and Cloudflare Worker.
