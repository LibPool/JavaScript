# @shrkcrft/api-surface-diff

> 标签: api-surface, breaking-change, code-intelligence, diff, sharkcraft

## 简介

SharkCraft API surface diff: compare two code-graph snapshots and report added / removed / changed public symbols. Catches accidental API breaks before publish.
