# dsh-project-progress

> 标签: deepseek-harness, dsh, dsh-plugin, kanban, progress, project-management, sidebar

## 简介

Project Manager — 侧边栏实时进度看板（DSH 双面插件）：项目进度树 + 百分比与未完成计数、关注/门控/交接、回滚点与审查。
