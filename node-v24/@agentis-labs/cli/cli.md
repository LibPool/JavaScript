> 标签: agent, agentis, agents, ai, ambient, antigravity, automation, brain, claude-code, cli, codex, control-panel, cursor, dashboard, gemini-cli, harness, hermes, memory, multi-harness, openclaw, orchestration, self-hosted, workflow, workflow-engine

## 简介

Multi-harness dashboard for agents you own — Claude Code, Codex, Cursor, Antigravity, Hermes, and OpenClaw, with a permanent Brain of memory that survives any harness or model swap. Install with `npm install -g @agentis-labs/cli`.
