# @berachain/wagmi

> 标签: JavaScript

## 简介

Shared wagmi v2 + Thirdweb wallet / connection layer for the dapps, plus a lighter provider variant. **Both variants still use Thirdweb.** Lightweight stubs `openConnectModal` / `DebugConnectButton`; it is not a no-Thirdweb bundle.
