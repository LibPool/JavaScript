# @customermates/n8n-nodes-crm

> 标签: automation, contacts, crm, customer-relationship-management, customermates, deals, gdpr, n8n-community-node-package, organizations, services, small-business, workflow

## 简介

n8n community node package for Customermates CRM - Modern CRM for small businesses with configurable lists (contacts, organizations, deals, services, tasks and your own), Trash, record webhooks, and messaging (email, LinkedIn, WhatsApp)
