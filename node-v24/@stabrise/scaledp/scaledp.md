# @stabrise/scaledp

> 标签: browser, document-processing, gliner, ner, ocr, onnx, onnxruntime-web, paddleocr, pdf, pii, tesseract, wasm, webgpu

## 简介

Process documents (PDF, images) in the browser using AI/ML pipelines: OCR, text detection, and NER on onnxruntime-web. A browser mirror of the ScaleDP Python library.
