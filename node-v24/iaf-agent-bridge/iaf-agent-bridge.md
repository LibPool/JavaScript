# iaf-agent-bridge

> 标签: acp, agent-client-protocol, codex, cursor, cursor-agent, iaf-agent-bridge, mcp

## 简介

MCP bridge that lets a supervisor such as Codex send work to Cursor Agent over ACP and continue the same session until the request is complete.
