# @dak-os/skills

> 标签: JavaScript

## 简介

The Dak Stack skills primitive — the loader for SKILL.md playbooks (frontmatter + Markdown + held-out evals), the bundled SKILL.md / eval-case JSON Schema (the format), and the eval/promotion contract: a skill's candidate -> active -> archived lifecycle,
