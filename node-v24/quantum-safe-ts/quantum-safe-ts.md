# quantum-safe-ts

> 标签: cnsa-2.0, dilithium, encryption, fips-203, fips-204, fips-205, hybrid, kyber, ml-dsa, ml-kem, post-quantum, pqc, quantum-safe, slh-dsa, typescript, wasm, x25519

## 简介

Hybrid post-quantum cryptography for TypeScript and JavaScript: ML-KEM, ML-DSA, SLH-DSA, hybrid envelopes and signatures. Rust core compiled to WASM, wire-compatible with quantum-safe-py.
