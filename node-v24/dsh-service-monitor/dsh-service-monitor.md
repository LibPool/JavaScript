# dsh-service-monitor

> 标签: balance, bocha, deepseek, deepseek-harness, dsh, dsh-plugin, firecrawl, quota, scraperapi, scrapingbee, searchapi, serpapi, tavily, tinyfish

## 简介

DeepSeek Harness 第三方服务余额监控插件：选择服务、录入 API Key、按 1/5/10/30 分钟定时查询剩余额度，提供主面板看板与侧边栏状态图标。收录有余额查询接口的服务（Tavily、博查、Firecrawl、SerpAPI、SearchApi、ScrapingBee、ScraperAPI、TinyFish）。Third-party service balance monitor for DeepSeek Harness: pick services, enter API keys
