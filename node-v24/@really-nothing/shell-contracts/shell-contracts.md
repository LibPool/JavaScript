# @really-nothing/shell-contracts

> 标签: contracts, micro-frontend, qiankun, shell, types, wujie

## 简介

主系统平台 主壳与子系统的协议单一事实来源：manifest、Bridge、Overlay、Feedback、事件等类型。独立发布到公共 npm，主壳与各子系统按 SemVer 版本独立安装。
