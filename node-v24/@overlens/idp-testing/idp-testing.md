# @overlens/idp-testing

> 标签: conformance, idp, jwks, jwt, mock, oauth2, oidc, overlens, rs256, testcontainers, testing

## 简介

Testing toolkit for the Overlens IDP (RFC-0005): mint valid RS256 tokens, in-process mock JWKS + mock IDP, negative-case token factories, drop-in conformance kits, the idp-doctor preflight CLI and a Testcontainers helper for the real containerized IDP. Bu
