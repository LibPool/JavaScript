# @editlayer/core

> 标签: cms, content-editing, content-management, editlayer, git-cms, github-cms, headless-cms, inline-editing, jwt, magic-link, nextjs, octokit, react, typescript, visual-editor

## 简介

Framework-independent core for EditLayer: types, validation, permissions, magic-link tokens, content merge, and GitHub publishing for in-page visual editing of Next.js marketing copy.
