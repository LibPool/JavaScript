# @decocms/vtex-cms

> 标签: cli, cms, content-platform, faststore, vtex

## 简介

CLI for VTEX Content Platform (the CMS behind FastStore v4): pull, diff and push entries as branch commits, with dry-run by default, backups, and a read-back from the data plane.
