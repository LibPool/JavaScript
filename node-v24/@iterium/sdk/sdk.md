# @iterium/sdk

> 标签: ai-agent, iterium, mcp, model-context-protocol, scrum-master, sdk

## 简介

Official TypeScript SDK for Iterium — chat with the autonomous Scrum Master agent, pull live stats, manage the Add-ons waitlist, and connect your own AI SDK agent to any MCP server.
