# @foobars/vue-select-country

> 标签: country, element-ui, flag, select, virtual-select, vue

## 简介

vue2 国家选择器，基于 element-ui 虚拟滚动组件实现，支持二位码、三位码、中英文国家名称绑定和显示国旗，可自定义显示格式和数据
