# @xrplworks/xls26

> 标签: JavaScript

## 简介

This is an implementation of the [XLS-26 Standard](https://github.com/XRPLF/XRPL-Standards/discussions/71). This package exports one single function called `parse` that converts a string of a `xrp-ledger.toml` file to a JavaScript object.
