# @bwthomas/outline-numbering

> 标签: alphanumeric, decimal, numbering, ordered-list, outline, prosemirror, prosemirror-plugin, tiptap, tiptap-extension

## 简介

Framework-agnostic ProseMirror plugin (with Tiptap wrapper) for nested ordered-list numbering with pluggable strategies: alphanumeric (Harvard / Purdue OWL I/A/1/a), decimal, legal, arabic, lower-roman, or custom.
