# @kadal/theme-swiss

> 标签: design, grid, grotesk, kadal-deck, kadal-theme, presentation, slides, swiss, theme

## 简介

Swiss, a theme for Kadal Deck (@kadal/deck). A bold International-style theme for design talks: huge grotesk headings on a strict twelve-column grid, one signal colour.
