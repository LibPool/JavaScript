# @kadal/prettier-plugin

> 标签: kadal-deck, mdx, presentation, prettier, prettier-plugin, slides

## 简介

Prettier for Kadal Deck decks (deck.mdx): separators and frontmatter normalised, YAML formatted with its comments, and every slide's Markdown formatted, with code, notes, magic-move and ::slot:: sugar left exactly as written.
