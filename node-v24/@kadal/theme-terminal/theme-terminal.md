# @kadal/theme-terminal

> 标签: code, developer, kadal-deck, kadal-theme, monospace, presentation, slides, terminal, theme

## 简介

Terminal, a theme for Kadal Deck (@kadal/deck). A developer theme for code-heavy talks: mono-forward type, superb code blocks, dark first with a good light variant, and the matching Ayu code colours.
