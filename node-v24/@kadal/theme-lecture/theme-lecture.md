# @kadal/theme-lecture

> 标签: academic, education, kadal-deck, kadal-theme, lecture, math, presentation, slides, theme

## 简介

Lecture, a theme for Kadal Deck (@kadal/deck). An academic theme for lectures and seminars: numbered sections, a course footer, theorem, definition and proof blocks, citations, and print-perfect pages.
