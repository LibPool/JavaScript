# @habemus-papadum/aiui-slides

> 标签: JavaScript

## 简介

The slides framework: a deck of viewport-sized slides moved one frame at a time as an ordinary aiui app — current slide + scene step as controls, wheel/touch quantized to one step per gesture, additive in-slide scenes, HUD grid overview with live previews
