# @smart-padel/design

> 标签: JavaScript

## 简介

Smart Padel design system — single source of truth for tokens (color, type, spacing, radii, shadow, motion) and icons (Lottie + flat SVG). Consumed by every Smart Padel front-end (web, mobile, watch).
