# @chancestv/tv-ui

> 标签: chromium-53, remote-control, spatial-navigation, tv, ui-components, vue3

## 简介

TV base UI components (E-prefixed) for Vue 3, built on @chancestv/tv-focus, tuned for legacy WebView (Chromium 53+).
