# @shopeasy/knowledge

> 标签: ai, context-builder, knowledge-base, markdown, search, shopeasy

## 简介

Gerencia a base de conhecimento (Markdown) do ShopEasy e monta o melhor contexto textual possível para enviar a uma IA sem RAG/vetores.
