# @devsnicket/plugin-discovery-create-repository

> 标签: babel, commonjs, dependencies, dependency, discovery, injection, inversion, module, modules, plugin, plugins

## 简介

A factory function that creates a repository to which functions/objects etc can be plugged into and discovered from elsewhere.
Discovery requires a Babel plug-in to add module imports @devsnicket/plugin-discovery-commonjs-babel-plugin.
