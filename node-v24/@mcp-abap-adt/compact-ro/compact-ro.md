# @mcp-abap-adt/compact-ro

> 标签: abap, adt, compact, mcp, mcp-server, read-only, sap

## 简介

The read-only compact MCP server for SAP ABAP ADT over stdio: the 17 compact tools that change nothing, one per operation with the object in the arguments, and the leftover-session list and logoff. Configured as @mcp-abap-adt/core; connects over HTTP, RFC
