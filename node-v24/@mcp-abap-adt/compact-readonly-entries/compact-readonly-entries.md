# @mcp-abap-adt/compact-readonly-entries

> 标签: abap, adt, compact, mcp, read-only, sap

## 简介

The compact ABAP ADT tools that change nothing: one tool per read operation, the object in the arguments. A tool list a consumer can hand out knowing it carries no write route.
