# @mcp-abap-adt/server-runtime

> 标签: abap, adt, mcp, mcp-server, model-context-protocol, sap

## 简介

The launch code of the MCP ABAP ADT servers: the stdio launcher and server with the destination layer (the auth broker per destination), the Streamable HTTP launcher and server, and the HTTP+SSE launcher and server. No command of its own — each server pac
