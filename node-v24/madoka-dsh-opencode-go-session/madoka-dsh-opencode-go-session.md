> 标签: cordis, deepseek-harness, dsh, dsh-plugin, missing-session-id, opencode-go, prompt-cache, session-affinity, x-opencode-session

## 简介

DeepSeek Harness plugin for OpenCode Go only: attaches a stable per-conversation x-opencode-session header (fixes 400 MissingSessionID). 仅面向 OpenCode Go：自动附加稳定的每会话请求头。
