> 标签: agents, crawler, llm, markdown, mcp, rag, scraping, screenshot, synoppy, web-data

## 简介

Official TypeScript/JavaScript SDK for the Synoppy web-data API — scrape, search, screenshot, crawl, map, extract, classify, enrich, and images on one key.
