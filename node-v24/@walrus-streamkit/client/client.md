# @walrus-streamkit/client

> 标签: hls, playback, sdk, seal, streaming, sui, video, walrus, walrus-streamkit, web3

## 简介

Frontend/viewer SDK for WalrusStreamKit — the end-user's wallet pays for access (buy_access / subscribe) and Seal-unlocks encrypted HLS playback in the browser.
