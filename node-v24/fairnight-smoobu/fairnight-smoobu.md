# fairnight-smoobu

> 标签: channel-manager, dynamic-pricing, short-term-rental, smoobu, vacation-rental

## 简介

Smoobu connector for Fairnight: read apartments and bookings, write nightly prices and minimum stays through the official API (HMAC-signed).
