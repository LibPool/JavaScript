# @caslanqa/create-playwright-ai

> 标签: ai, api-testing, automation, chatbot-testing, create, e2e, judge, llm, ollama, playwright, scaffold, starter, testing

## 简介

Scaffold a ready-to-run Playwright + TypeScript test framework: AI Judge for LLM evaluation, layered API testing, lazy session auth, and full tooling (ESLint, Prettier, husky, commitlint)
