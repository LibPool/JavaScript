# @thinletterio/vqweb

> 标签: browser, embeddings, on-device, query-encoder, qwen3, retrieval, vector-quantization, webgpu

## 简介

Vector-quantised query encoders (.vqw containers) in the browser on WebGPU: load a 105-240 MiB file, embed a query in ~100 ms, keep your document index unchanged.
