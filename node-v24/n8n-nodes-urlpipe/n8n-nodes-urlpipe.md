# n8n-nodes-urlpipe

> 标签: lighthouse, markdown, metadata, n8n, n8n-community-node-package, screenshot, urlpipe, web-scraping

## 简介

n8n node for URLpipe: turn any URL into Markdown, a screenshot, a PDF, metadata, structured data, console errors or a Lighthouse audit, rendered in real Chrome.
