# @readystack/shopify-theme-restaurant

> 标签: restaurant, shopify, theme

## 简介

Im offiziellen Shopify Theme Store werden kostenpflichtige Themes als Einmalzahlung verkauft; die dort gelisteten Preise liegen im Bereich von 140–500 USD (nachprüfbar unter themes.shopify.com).
