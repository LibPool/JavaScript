# @readystack/mysql84-upgrade-blocker-lint

> 标签: migration, mysql, mysql 8.4, mysql upgrade, rds extended support, rds mysql, replication, sql lint

## 简介

MySQL upgrade 8.0 → 8.4: finds the SQL, my.cnf and parameter-group lines that MySQL 8.4 removed, with the fix on each line
