# @16x/webphone-sdk

> 标签: JavaScript

## 简介

`@16x/webphone-sdk` 是浏览器端 WebPhone SDK。客户只需提供服务端取票接口，并在前端配置 `createTokenSessionProvider`。SDK 会在内部获取坐席账号、创建会话、登录 SIP、刷新凭证并请求坐席状态。
