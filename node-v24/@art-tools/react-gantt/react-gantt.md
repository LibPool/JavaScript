# @art-tools/react-gantt

> 标签: gantt, gantt-chart, project-management, react, scheduling, timeline, typescript, virtualized

## 简介

Composable, virtualized Gantt chart for React — dependencies, working-time calendars, undo/redo, and slot-based theming.
