# @lengmoxxl/dsh-remote-workspace

> 标签: deepseek-harness, dsh, pty, remote, ssh, terminal, worktree

## 简介

DeepSeek Harness plugin for working on other machines: manage machines over SSH, work in their repositories and worktrees, and open a terminal there.
