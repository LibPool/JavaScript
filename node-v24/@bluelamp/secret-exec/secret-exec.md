# @bluelamp/secret-exec

> 标签: bluelamp, cli, secret

## 简介

金庫の値を子プロセスの環境変数にだけ入れてコマンドを実行し（exec）、標準入力から金庫へ入れる（put）。値を画面・引数・ログに出さない口
