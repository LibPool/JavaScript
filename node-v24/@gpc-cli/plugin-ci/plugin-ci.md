# @gpc-cli/plugin-ci

> 标签: android, ci-cd, github-actions, gitlab-ci, google-play, google-play-console, play-store, plugin, release-automation

## 简介

CI/CD plugin for GPC Google Play Console CLI. GitHub Actions, GitLab CI, JSON output, exit codes, environment variable config.
