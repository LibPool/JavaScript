# toastnova

> 标签: accessibility, alerts, animations, glassmorphism, notifications, react, swipe-to-dismiss, themes, toast, toaster, typescript

## 简介

A modern, customizable React toast notification library featuring 6 built-in themes, physics-based animations, and accessible queue management.
