# context-librarian

> 标签: agents-md, claude-code, claude-md, context, documentation, llm, mcp, memory

## 简介

Keep AI instruction files (CLAUDE.md, AGENTS.md) small as a project grows: a budget-checked library of rulebook, reading desk, path-scoped shelves and partitioned books. CLI, Claude Code plugin and MCP server.
