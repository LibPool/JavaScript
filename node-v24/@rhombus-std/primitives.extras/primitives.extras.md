# @rhombus-std/primitives.extras

> 标签: compiler, primitives, transformer, typefor, typescript

## 简介

The standalone type-derivation authoring transformer: the typefor<T>() compile-time Type mechanism plus the inline primitive stage. A Go/ttsc descriptor package — the derivation runs in the shared owner binary, di-independent so any family can mint augmen
