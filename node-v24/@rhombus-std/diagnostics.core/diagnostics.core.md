# @rhombus-std/diagnostics.core

> 标签: diagnostics, ioc, metrics, telemetry, tracing, typescript

## 简介

Diagnostics abstractions: the metrics/tracing configuration surface (MetricsOptions/TracingOptions, InstrumentRule/TracingRule, MeterScope/ActivitySourceScopes, IMetricsBuilder/ITracingBuilder) plus the builder extension functions. No metrics/tracing runt
