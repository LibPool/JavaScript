# @rhombus-std/config

> 标签: config, configuration, ioc, options, typescript

## 简介

Layered configuration engine: ConfigBuilder/Root/Section, compareConfigKeys, the Memory provider, an index-navigable Section tree, and a Type-tree schema that coerces on build().
