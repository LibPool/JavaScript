# @purgeon/analyzer-jsx

> 标签: ast, clsx, cva, jsx, oxc, purge, rolldown, tree-shaking, vite

## 简介

Walks JSX AST via oxc-walker, tracks element usages and class-variant calls (cva/cn/cx/tv/clsx) for purgeon
