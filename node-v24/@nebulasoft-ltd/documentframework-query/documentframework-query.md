# @nebulasoft-ltd/documentframework-query

> 标签: documentframework, dsl, fluent, nebulasoft, pipeline, query

## 简介

TypeScript query DSL and fluent pipeline builder for NebulaSoft DocumentFramework. Builds the query DSL string for sending over the wire, with client side validation for a fast fail path.
