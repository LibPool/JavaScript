# @entourage/session-validation-client

> 标签: authentication, cookie, fail-closed, server-side, session, validation

## 简介

Framework-agnostic client plumbing for validating a cookie-backed session against a remote validator endpoint, with fail-closed security semantics. Bring your own endpoint and credentials.
