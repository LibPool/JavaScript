# @quickflo/app-sdk

> 标签: entitlement, form, onboarding, quickflo, sdk, webhook

## 简介

Framework-agnostic browser SDK for QuickFlo micro-apps: identity-aware onboarding, entitlement checks, and typed webhook + form trigger clients.
