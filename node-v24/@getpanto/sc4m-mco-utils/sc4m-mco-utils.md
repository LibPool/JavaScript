# @getpanto/sc4m-mco-utils

> 标签: JavaScript

## 简介

This software provides utility functions which (1) generate MCO contracts represented in TURTLE from Media Contractual Objects, and (2) parses MCO contracts represented in TURTLE and converts them into Media Contractual Objects.
