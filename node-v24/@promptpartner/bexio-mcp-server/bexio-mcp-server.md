# @promptpartner/bexio-mcp-server

> 标签: accounting, api, bexio, claude, invoices, mcp, model-context-protocol, swiss, typescript

## 简介

Complete Swiss accounting integration for Bexio via MCP. Works with Claude Desktop, n8n, and any MCP client. 314 tools for invoices, contacts, projects, time tracking, account balances and more.
