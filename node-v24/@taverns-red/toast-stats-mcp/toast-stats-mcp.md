# @taverns-red/toast-stats-mcp

> 标签: district-statistics, mcp, model-context-protocol, toastmasters

## 简介

Thin, local, read-only MCP server over the public Toast Stats snapshot CDN (ADR-008). Exposes the pre-computed snapshot fields as MCP tools over stdio — no computation, no analytics-core.
