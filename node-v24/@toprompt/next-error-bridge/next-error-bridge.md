# @toprompt/next-error-bridge

> 标签: error-boundary, error-bridge, iframe, nextjs, postmessage, preview, toprompt

## 简介

Error bridge for Next.js apps — forwards runtime, build, console, and React render errors from an iframe preview to the parent window via postMessage. Designed for AI coding environments like toPrompt.
