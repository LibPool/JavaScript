# @interopio/bbg-market-data

> 标签: bbg, bloomberg, desktop, glue, glue42, interop, interopio, ioconnect, market data

## 简介

A high-level API that wraps existing io.Connect Bloomberg Bridge Market Data interop methods. The API is based on the jBloomberg open source wrapper.
