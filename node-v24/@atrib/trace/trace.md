# @atrib/trace

> 标签: agent, atrib, attribution, cognitive-primitive, lineage, mcp, model-context-protocol, provenance, trace, verifiable

## 简介

Legacy home of atrib's trace read primitive. Superseded by @atrib/recall (the read verb, shape=walk with a direction); this package re-exports the same surface and forwards the atrib-trace binary.
