# @atrib/action-gate

> 标签: action-control, action-gate, agent, agent-control, approval, atrib, browser-automation, computer-use, governance, human-in-the-loop, policy, receipts, verifiable

## 简介

Host-owned action gate helpers for atrib's verifiable action layer. Signs policy decisions and outcomes before high-impact agent actions run.
