# @atrib/recall

> 标签: agent, atrib, attribution, cognitive-primitive, mcp, memory, model-context-protocol, recall, signed-records, verifiable

## 简介

MCP server for atrib's verifiable action layer. Lets agents query their own provable past from the local mirror.
