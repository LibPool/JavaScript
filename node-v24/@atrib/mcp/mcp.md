# @atrib/mcp

> 标签: agent, attribution, ed25519, mcp, merkle, model-context-protocol, receipts, transparency, verifiable

## 简介

MCP server middleware for atrib's verifiable action layer. Signs and chains successful tool calls with one-line integration.
