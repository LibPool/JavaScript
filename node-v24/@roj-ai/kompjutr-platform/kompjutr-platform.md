# @roj-ai/kompjutr-platform

> 标签: JavaScript

## 简介

Run the Roj SDK against a [Kompjutr](https://www.npmjs.com/package/@kompjutr/do) workspace. This adapter uses `@kompjutr/do` **0.1.3** from npm.
