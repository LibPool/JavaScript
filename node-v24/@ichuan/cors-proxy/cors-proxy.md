# @ichuan/cors-proxy

> 标签: JavaScript

## 简介

这是一个基于 Node.js 的轻量级 HTTP 代理服务器，旨在解决前端开发过程中的跨域资源共享 (CORS) 问题。

- npm 页面：https://www.npmjs.com/package/@ichuan/cors-proxy
