# @healthcloudai/hc-cli

> 标签: cli, health-cloud, healthcloud, mcp, model-context-protocol

## 简介

HealthCloud MCP command-line interface — one `hc mcp <audience> <command>` per MCP gateway tool, generated from the shared tool manifest.
