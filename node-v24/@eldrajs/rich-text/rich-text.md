# @eldrajs/rich-text

> 标签: eldra, html, prosemirror, renderer, rich-text, tiptap

## 简介

Framework-free rendering for Eldra CMS rich text: the document types, plain-text extraction, an escaping HTML serialiser, and embed normalisation.
