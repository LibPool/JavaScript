# vue-greenborn-map-selector

> 标签: greenborn, leaflet, location, map, map-picker, modal, vue, vue-greenborn-modal-manager, vue3

## 简介

Selector de ubicación en mapa (Leaflet) para Vue 3, integrado con vue-greenborn-modal-manager: abre un modal apilable sobre el resto de modales, devuelve lat/lng vía callback y se cierra con el gestor genérico.
