# @wildwinter/scoperegistry

> 标签: expression, registry, scope, state, wildwinter

## 简介

Scope registry / runtime state container for @wildwinter/expr: owned property scopes + foreign (host-resolved) scopes, save/load, and the scopeRegistrySpec interop format. Produces the EvalContext and ExpressionSchema that expr consumes.
