# @wildwinter/app-shell

> 标签: design-tokens, dom, electron, shell, wildwinter

## 简介

The shared shell for the editor family (Patterpad, Storylet Studio): the app-agnostic design-token grammar, the per-entity colour hash, and the vanilla-TS DOM primitive. Two palettes, one grammar - each app supplies its own palette/fonts over these tokens
