# @spyglassjs/ui

> 标签: dashboard, react, reporting, semantic-layer, spyglass, vega-lite

## 简介

JSON-expressible reporting widgets: metric, table, chart, note + a custom-component registry. Renders a ReportDoc. Pairs with the `spyglass` engine.
