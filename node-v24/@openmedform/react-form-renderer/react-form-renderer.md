# @openmedform/react-form-renderer

> 标签: JavaScript

## 简介

React renderer for OpenMedForm form definitions: JSON Forms with custom clinical controls, sharing form-core and form-design-tokens with the Angular renderer so the same FormDefinition renders equivalently in both.
