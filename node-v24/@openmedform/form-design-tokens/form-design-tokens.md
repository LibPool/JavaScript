# @openmedform/form-design-tokens

> 标签: JavaScript

## 简介

Shared visual/layout tokens (typography, spacing, borders, row heights, breakpoints) exposed as TS constants and CSS custom properties, consumed by BOTH the React and Angular renderers so the same FormDefinition renders equivalently across frameworks.
