# @bandonker/opencode-goal

> 标签: agent, automation, autonomous, goal, loop, opencode, opencode-plugin

## 简介

Set an objective for a session and keep working until it is reached: the goal is re-injected into every request, the model auto-continues when a turn ends, and the loop stops only on goal_complete/goal_blocked, a user interrupt, a stall, or the iteration/
