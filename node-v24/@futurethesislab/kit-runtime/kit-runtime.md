# @futurethesislab/kit-runtime

> 标签: artifacts, content, ftlab, runtime, venture-kit

## 简介

Cohort Venture Kit runtime assets — the reference-venture content tree and the artifacts render runtime, packaged so a consumer (e.g. the venture pipeline) can satisfy VENTURE_KIT_DIR without a kit checkout on disk.
