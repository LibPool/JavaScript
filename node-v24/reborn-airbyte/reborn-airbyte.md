> 标签: airbyte, claude, claude-code, context-store, hubspot, korean, mcp, skill, stripe

## 简介

Airbyte Agents(호스팅 MCP · Context Store)를 클로드 코드에 붙이는 공식 명령(claude mcp add --transport http airbyte-agent https://mcp.airbyte.ai/mcp)과 그 뒤 인증 단계, 붙인 뒤 막아 둘 것(쓰기 권한 · 무료 월 1,000 작업 · 토큰 절감은 「최대」 수치)을 한국어로 안내하는 클로드 코드 스킬을 깝니다. --check 는 이 PC 에 붙어 있는지 파일만 읽어
