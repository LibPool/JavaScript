# dyscalculia-embed

> 标签: dyscalculia, education, embed, iframe, number-games, number-line, numeracy, subitizing, teachers, web-component

## 简介

Free number practice games for any website: a <dyscalculia-game> web component and a React wrapper. Count the dots, which is bigger, which group has more, place the number and remember the digits, in English, German, Spanish, French, Dutch and Brazilian P
