# @albertomarturelo/cta-mcp

> 标签: banco, bank, bci, cartola, chile, claude, mcp, model-context-protocol, read-only

## 简介

MCP (stdio) server to read your own Chilean bank accounts from an AI agent. Each tool is a thin call into @albertomarturelo/cta-core tasks (ADR-003).
