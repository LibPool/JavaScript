# @albertomarturelo/nemo-mcp

> 标签: bolsa, chile, claude, corredora, mcp, model-context-protocol, nemo, vector-capital

## 简介

MCP server (stdio) for the Vector Capital portal. Each tool/resource is a thin call into @albertomarturelo/nemo-core tasks (ADR-003). Browser sign-in (auth_login, no password argument) plus the CLI's read surface (ADR mcp-browser-login).
