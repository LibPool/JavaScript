# @albertomarturelo/sii-cli

> 标签: chile, cli, dte, f22, f29, impuestos, rcv, sii, sii-cl, tax

## 简介

CLI for Chile's SII (tax authority): authenticated reads of RCV, F29, F22, boletas de honorarios, DTE-authorized and peticiones administrativas, factura borradores on the Portal MIPYME (never emission), and document downloads. Each command is a thin call
