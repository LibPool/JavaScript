# @xano/sdk

> 标签: deploy, ephemeral, infrastructure-as-code, preview-environments, sdk, typescript, xano, xanosdk

## 简介

The official TypeScript SDK for Xano, one platform to build, run and govern AI-built software. Your coding agent writes the backend in TypeScript, you run it on the Xano Engine on your machine, then deploy it to Xano.
