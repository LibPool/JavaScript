# @pooled/openclaw

> 标签: llm, local-llm, openclaw, openclaw-plugin, p2p, peer-to-peer, pooled, self-hosted, webgpu, webrtc

## 简介

Peer-to-peer inference engine for your claw: run one model across your own devices, each holding part of it on its GPU.
