# @bobjoy/vconsole

> 标签: ai-agent, console, debug, mcp, mobile, vconsole

## 简介

Fork of Tencent vConsole (dev branch, 3.16.0-alpha) with a WebSocket bridge that streams logs/network data to an MCP server for AI agents. Upstream: https://github.com/Tencent/vConsole
