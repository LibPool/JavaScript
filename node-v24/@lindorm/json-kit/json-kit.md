# @lindorm/json-kit

> 标签: JavaScript

## 简介

Loss-less JSON serialisation for JavaScript values that don't survive `JSON.stringify` — `Date`, `Buffer`, `BigInt`, `undefined`, and the `null` vs `undefined` distinction.
