# dewee-webchat

> 标签: agent, ai, astro, chat-widget, chatbot, cloudflare-workers, dewee, goclaw, nextjs, react, vue, web-component

## 简介

Embeddable chat widget for Dewee AI agents — web component, React/Vue/Astro wrappers and a secure backend handler (Workers, Next.js, Node, Bun, Deno).
