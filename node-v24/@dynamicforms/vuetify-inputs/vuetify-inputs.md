# @dynamicforms/vuetify-inputs

> 标签: components, data entry, dynamicforms, forms, inputs, material-design, typescript, velis, vue, vuetify

## 简介

Vuetify input components with guaranteed visual consistency across all form fields — unified density/variant system, globally configurable, with inline mode for table cells. Built for @dynamicforms/vue-forms.
