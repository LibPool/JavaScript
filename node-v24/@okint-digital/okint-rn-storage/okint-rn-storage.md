# @okint-digital/okint-rn-storage

> 标签: async-storage, encrypted-storage, keychain, keystore, mmkv-alternative, okint, react-native, secure-storage, storage

## 简介

Vanilla, pluggable React Native storage — one API over swappable backends: hardware Keystore/Keychain (secure), AES-encrypted blobs (encrypted), SQLite, SharedPreferences/UserDefaults (async), a synchronous fast store, or in-memory.
