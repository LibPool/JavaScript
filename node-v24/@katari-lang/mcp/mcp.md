# @katari-lang/mcp

> 标签: JavaScript

## 简介

MCP tool-listing helper for the Katari CLI: connects to an MCP server and emits its tool listing as JSON (running the OAuth authorization flow in memory when --oauth is given). Spawned by `katari mcp pull`.
