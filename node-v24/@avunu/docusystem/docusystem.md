# @avunu/docusystem

> 标签: avunu, docs, documentation, jx, markdown, static-site

## 简介

The documentation system shared by every Avunu open-source project: a CLI that builds a project's Markdown into its docs site, and the reusable GitHub Actions workflows that check and deploy it.
