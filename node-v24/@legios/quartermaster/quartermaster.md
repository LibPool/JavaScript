# @legios/quartermaster

> 标签: claude, claude-code, cli, codex, gnome, macos, opencode, quota, rate-limit, statusline, usage, windows

## 简介

Cuánta cuota te queda en TODOS los perfiles de Claude Code de la máquina, más Codex y los proveedores de opencode. Sin red y sin credenciales: el número sale del cache que Claude Code deja en disco.
