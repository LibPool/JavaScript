# @stratta/mcp

> 标签: civil-engineering, claude, eurocodes, mcp, model-context-protocol, rag, sia, stratta

## 简介

MCP server exposing the engineering norms your firm is licensed for (SIA / Eurocodes) to any MCP client, via Stratta TreeRAG.
