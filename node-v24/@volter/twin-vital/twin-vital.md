# @volter/twin-vital

> 标签: api, health, junction, lab-testing, local, mirror, mock, sdk, simulator, testing, twin, vital, webhooks

## 简介

Local Vital (Junction) health-data + lab-testing API twin — users, link tokens, lab tests/markers/labs, orders, PSC appointments, results, devices/connections, and svix-style signed webhooks. Built on @volter/world-core.
