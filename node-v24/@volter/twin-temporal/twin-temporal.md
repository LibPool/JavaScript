# @volter/twin-temporal

> 标签: JavaScript

## 简介

Local Temporal frontend twin: WorkflowService over gRPC (HTTP/2) on loopback — task queues, workflow and activity tasks, timers on the World clock, signals, queries, children, continue-as-new, visibility; unserved RPCs answer UNIMPLEMENTED. Built on @volt
