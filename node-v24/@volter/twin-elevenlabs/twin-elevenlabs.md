# @volter/twin-elevenlabs

> 标签: elevenlabs, text-to-speech, tts, twin

## 简介

ElevenLabs twin (Protocol 3): text to speech as labeled silence in the format asked for (the twin runs no model), the account's voices, API keys. Built on @volter/world-core.
