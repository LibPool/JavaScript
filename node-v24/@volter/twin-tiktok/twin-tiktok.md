# @volter/twin-tiktok

> 标签: content-posting, login-kit, tiktok, twin

## 简介

TikTok twin (Protocol 3): Login Kit's authorize page and tokens, the Content Posting API (videos by chunked upload, direct and to the inbox; photos pulled from verified URLs; post status) and the Display API (user info and stats, videos), as Postiz calls
