# @volter/localrouter

> 标签: JavaScript

## 简介

OpenRouter's interface, served by local models. An npm package and a process on a laptop, a worker in a browser tab. No daemon, no app, no account.

- npm 页面：https://www.npmjs.com/package/@volter/localrouter
