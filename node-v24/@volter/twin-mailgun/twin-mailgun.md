# @volter/twin-mailgun

> 标签: api, email, fixtures, local, localstack, mailgun, mirror, mock, sdk, simulator, testing, transactional-email, twin, webhooks

## 简介

Local Mailgun twin — a faithful, stateful local Mailgun v3/v4 API your real `mailgun.js` SDK talks to unmodified. Domain-scoped form-encoded sends, stored messages, the Events API with paging, the four suppression tables, domains/webhooks/routes/mailing-l
