# @volter/cyclotron

> 标签: blender, claude-code, code-oss, codex, game editor, mcp, react, three.js, webassembly

## 简介

A free, open-source game editor by videogame.ai using Blender 5.2 compiled to WebAssembly, Code-OSS, three.js, TypeScript and React.

- 源码仓库：git+https://github.com/volter-ai/editor.git
- npm 页面：https://www.npmjs.com/package/@volter/cyclotron
