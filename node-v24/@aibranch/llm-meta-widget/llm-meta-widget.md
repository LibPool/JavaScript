# @aibranch/llm-meta-widget

> 标签: chat-widget, custom-element, llm, mcp, model-context-protocol, tool-calling

## 简介

Embeddable browser chat widget: a custom element that discovers tools at page, origin and hub scope and dispatches each tool call to the right one. Two lines of HTML on any host, Rails or not.
