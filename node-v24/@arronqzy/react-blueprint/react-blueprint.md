# @arronqzy/react-blueprint

> 标签: JavaScript

## 简介

蓝图编辑器。基于 [React Flow](https://reactflow.dev/)：拖节点、连线、单步调试、蓝图库和执行日志。节点怎么跑由 `@arronqzy/blueprint-dsl` 决定，本包只负责画布和调试界面。
