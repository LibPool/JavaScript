# @advdominion/babel-plugin-nunjucks

> 标签: JavaScript

## 简介

Плагин для [babel-loader](https://github.com/babel/babel-loader), позволяющий использовать шаблонизатор [Nunjucks](https://mozilla.github.io/nunjucks/) внутри JS-файлов.
