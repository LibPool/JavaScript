# @trydaleel/core

> 标签: daleel, on-device, provenance, rag, retrieval

## 简介

Pure, framework-free, I/O-free core of the Daleel engine: provenance types + deterministic ranking, grade-filter, tier/attribution, and prompt-assembly logic.
