# emdash-header-footer-code

> 标签: analytics, cms, emdash, emdash-plugin, footer, header, snippets

## 简介

Add custom code snippets (analytics, verification tags, chat widgets, CSS/JS) to the head or body of EmDash pages — no theme edits.
