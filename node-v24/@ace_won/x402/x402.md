> 标签: arc, arc-network, circle, conduit, eip-3009, micropayment, middleware, nextjs, payment, usdc, web3, x402

## 简介

Drop-in x402 payment middleware for Next.js — powered by Conduit on Arc Network. Wrap any API route with one line to require USDC micropayments.
