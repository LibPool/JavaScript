# @applaudiq/embed-react-native

> 标签: applaudiq, embed, expo, react-native, recognition, sso, webview

## 简介

React Native SDK to embed the Applaud IQ recognition portal (auto + manual login, native SSO). Works with bare React Native and Expo.
