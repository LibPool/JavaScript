# @crossly/sdk

> 标签: automation, crosslister, crossly, crossposting, depop, ebay, etsy, grailed, marketplace, mercari, poshmark, reseller, sdk, shopify, typescript, vinted

## 简介

Official TypeScript SDK for the Crossly public API. Multi-marketplace crossposting + automation — list once, sell on 15+ platforms (Poshmark, eBay, Etsy, Mercari, Depop, Grailed, Vinted, Whatnot, Shopify, and more).
