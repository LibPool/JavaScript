# @amond-ai/harness-transport-cloudflare

> 标签: agent, claude-code, cloudflare, sandbox, transport, websocket, workers

## 简介

Opens the harness bridge socket from workerd — through a Cloudflare Sandbox binding or straight over `fetch` — so the adapter never reaches for `ws`
