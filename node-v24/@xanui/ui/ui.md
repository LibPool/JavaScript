# @xanui/ui

> 标签: component-library, design-system, frontend, headless-ui, nextjs, oklch, react, react-components, responsive, tailwind-alternative, theming, typescript, ui, ui-library

## 简介

A modern, fully-typed React UI component library — 60+ components, an OKLCH-based theming engine via createTheme(), responsive props, and a flexible Tag primitive system. Built on @xanui/core
