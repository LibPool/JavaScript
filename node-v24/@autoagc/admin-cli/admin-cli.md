# @autoagc/admin-cli

> 标签: JavaScript

## 简介

`@autoagc/admin-cli` 是 `autoagc-a2a-server` 的官方 CLI 包，安装后的命令为 `autoagc-admin`，用于统一访问 Agent Card、A2A JSON-RPC、管理接口，以及运维排障接口。

## 官网

- npm 页面：https://www.npmjs.com/package/@autoagc/admin-cli
