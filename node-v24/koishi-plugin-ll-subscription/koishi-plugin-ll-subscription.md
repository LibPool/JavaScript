# koishi-plugin-ll-subscription

> 标签: cdk, giftcard, koishi, plugin, qq, subscription

## 简介

按群订阅 + CDK 卡密续期：管理员批量生成 30 天卡，群内兑换后机器人正常响应，到期前提醒，过期后静默。
