# @flip-engine/core

> 标签: 3d, album, book, flipbook, headless, page-flip, viewer

## 简介

Headless, content-agnostic 3D page-flip engine. Pure TypeScript — zero DOM, zero framework. Plug in a platform binding to render it anywhere.
