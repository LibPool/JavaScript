# @stratasync/mobx

> 标签: linear, linear sync engine, linear-sync-engine, local-first, mobx, observable, offline-first, reactivity, realtime, sync, sync-engine, typescript

## 简介

@stratasync/mobx: MobX reactivity adapter for Strata Sync, an open-source implementation of Linear's sync engine.
