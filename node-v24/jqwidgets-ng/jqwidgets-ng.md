# jqwidgets-ng

> 标签: JavaScript

## 简介

jQWidgets for Angular - 82 UI components, including Grid, Scheduler, Gantt, PivotGrid, TreeGrid and Chart, as standalone Angular components with 40 themes.

- 源码仓库：git://github.com/jqwidgets/jQWidgets.git
