# @dac-software/pos-navigator-pl

> 标签: JavaScript

## 简介

This is POS Navigator PL javascript component that lists and shows on map all qarsons points of sale. this component is intended for use on QarsonPL website. Library uses react, redux, typescript, css written in SASS preprocessor.
