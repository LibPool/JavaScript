# @mqn00/file-manager-plugin-system-info

> 标签: file-manager, file-manager-plugin, system, system-info

## 简介

File Manager 系统信息插件：将内置系统信息页面抽取为独立插件，展示 OS/CPU/内存/磁盘分区/Node 信息，入口注册到文件浏览器顶栏导航
