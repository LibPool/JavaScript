# @clanker-chain/mqtt-node-client

> 标签: JavaScript

## 简介

Low-level MQTT pub/sub for clanker-chain bots. Auth-agnostic: pass `getPassword()` for CONNECT (typically SIWE from `@clanker-chain/identity-node-client`).
