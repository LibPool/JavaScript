# homebridge-olarm-platform-pgm

> 标签: alarm, garage-door, gate, homebridge-plugin, homekit, mqtt, olarm, pgm, security-system, smart-home

## 简介

Homebridge plugin for Olarm security systems using the official Olarm API, with real-time MQTT updates, zone discovery and gate control via PGM outputs.
