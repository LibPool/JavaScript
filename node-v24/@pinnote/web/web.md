# @pinnote/web

> 标签: comments, feedback, nextjs, pinnote, react, review, widget

## 简介

Add the PinNote feedback widget to a website: one function for any JavaScript app, one component for React. A small loader: the widget itself is downloaded from the PinNote server at run time.
