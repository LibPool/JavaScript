# @zicolasjac-ai/remote-readonly-ssh

> 标签: agent-skill, ai, audit, bastion, claude, cli, jumpserver, opencode, ops, readonly, security, ssh, whitelist

## 简介

只读 SSH 运维 CLI 与 Agent Skill：通过 JumpServer 堡垒机白名单强制执行只读查询；认证组支持 SSH 私钥/密码两种模式与按 IP 分组；附 SKILL.md 让 opencode / Claude Code / Cursor 等 AI 助手自动发现并正确调用。
