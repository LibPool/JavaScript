# @zicolasjac-ai/easy-keepalive-github

> 标签: connectivity, dns, github, hosts, keepalive, scheduled-task, windows

## 简介

GitHub 直连保活工具: 计划任务驱动, 自动检测 github.com 连通性, 当前 IP 不可达时自动同步切换 hosts 中所有 GitHub 相关子域名到可用候选 IP (Windows / Node.js, 零依赖, IP 池动态从 GitHub 官方 meta API + 多 DNS 查询 + 实测筛选获取, npx 一键安装自动弹 UAC, 安装后自动验证任务属性)
