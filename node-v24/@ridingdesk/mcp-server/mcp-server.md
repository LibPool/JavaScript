# @ridingdesk/mcp-server

> 标签: campaign, crm, mcp, model-context-protocol, ridingdesk

## 简介

Model Context Protocol server for RidingDesk — exposes the Customer Data API (voters, donations, volunteers, canvassing, lawn-signs, campaign) as 11 MCP tools for Claude Desktop and other MCP clients.
