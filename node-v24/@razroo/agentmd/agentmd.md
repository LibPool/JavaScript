# @razroo/agentmd

> 标签: adherence, agent, anthropic, claude, evaluation, fixtures, linter, llm, markdown, prompt

## 简介

Agent prompts as structured markdown, with a linter for structure and a harness that scores per-rule adherence — so iteration produces numbers, not vibes.
