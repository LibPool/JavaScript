# @donor360/eshop-sdk

> 标签: checkout, donations, donor360, eshop, js, sdk

## 简介

The eShop SDK JS is a lightweight library that allows you to build eShop into any website. It is based on Donor360's API and provide the ability to retrive products, latest donations from your eShop, add products to cart and checkout.
