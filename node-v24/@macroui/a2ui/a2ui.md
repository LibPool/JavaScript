# @macroui/a2ui

> 标签: a2ui, ai, component, dsl, framework-agnostic, macroui-a2ui, react, render, server-sent-events, sse, streaming-ui, svelte, ui-framework, vue, web-components

## 简介

MacroUI A2 — Zero-dependency streaming UI description & rendering framework for AI chat. Describe UI with a tiny DSL, stream over SSE, render to real DOM incrementally.
