# @kaana.ai/sdk

> 标签: JavaScript

## 简介

The TypeScript client of Kaana's public API at https://kaana.ai/v1: models, power levels, responses, chat completions, embeddings, speech, transcription, images, decisions, generation records and realtime sessions. Runs in Node, browsers and React Native.
