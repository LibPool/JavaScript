# @profoundry-us/highball

> 标签: ai, checks, ci, claude-code, code-quality, hooks

## 简介

Highball runner — local CI for AI coding agents: runs a repo's .highball/checks.yml rules, blocks the agent on failure, and optionally reports runs to PostHog.
