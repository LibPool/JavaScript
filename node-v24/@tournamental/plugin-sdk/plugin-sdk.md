# @tournamental/plugin-sdk

> 标签: apache-2.0, ingest, plugin, renderer, scoring, sdk, tournamental

## 简介

Plugin SDK for Tournamental. Types + manifest schema + test harness for authoring third-party plugins (renderers, scorers, ingest sources, identity providers, commentary, share cards, odds sources, affiliate routers).
