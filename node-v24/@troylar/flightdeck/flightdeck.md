# @troylar/flightdeck

> 标签: agent-skills, ai-assistant, checklist, offline, process, runbook, sop

## 简介

Offline team process checklists in one HTML file. Run and prove a checklist, then give your AI assistant a brief to build a skill. Track which process version each skill follows.
