# @db0-ai/ai-sdk

> 标签: ai-sdk, chat-history, context-window, llm, memory, nextjs, persistent-memory, useChat, vercel

## 简介

Persistent memory middleware for Vercel AI SDK. Add long-term memory to useChat apps — retrieves relevant facts from past sessions within a token budget. Works with any AI SDK provider.
