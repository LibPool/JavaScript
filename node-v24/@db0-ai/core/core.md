# @db0-ai/core

> 标签: agent, ai, ai-sdk, context-window, langchain, llm, memory, persistent-memory, postgresql, rag, sqlite, vector-search

## 简介

Agent-native data layer SDK. Persistent memory with scoping and superseding, execution state with branching, context assembly with token budgets. SQLite and PostgreSQL. Works with Vercel AI SDK, LangChain.js, and any TypeScript agent.
