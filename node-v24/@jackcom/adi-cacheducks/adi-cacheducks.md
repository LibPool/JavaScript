# @jackcom/adi-cacheducks

> 标签: adi-cacheducks, cacheducks, caching pubsub, indexeddb pubsub, localStorage pubsub

## 简介

A data caching interface for the front-end. It has pub-sub capabilities, and focuses on reading from/writing to localStorage or other cache implementation (e.g. IndexedDB).
