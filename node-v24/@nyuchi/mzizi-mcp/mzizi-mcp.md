# @nyuchi/mzizi-mcp

> 标签: bundu, mcp, model-context-protocol, mzizi, registry, supabase

## 简介

Mzizi MCP — Model Context Protocol server for the Mzizi component registry. Reads the document-route store, one component per JSON document.
