# @tabula-css/preset

> 标签: ai, design-system, llm, preset, tabula, tailwind, tailwind-v4, tailwindcss

## 简介

Tabula Tailwind v4 entry assembly: @import "tailwindcss" source(none) + @theme + @source inline() over the whole vocabulary. Pure library — the CLI writes the files.
