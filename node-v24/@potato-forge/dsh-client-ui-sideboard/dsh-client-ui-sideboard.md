# @potato-forge/dsh-client-ui-sideboard

> 标签: JavaScript

## 简介

Browser half of dsh-sideboard: the right-sidebar canvas page type, its block renderers (d3 charts, WCAG contrast, computed diffs, sandboxed HTML), and the lazily loaded Mermaid chunk.
