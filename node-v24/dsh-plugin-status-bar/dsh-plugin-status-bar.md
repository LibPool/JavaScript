# dsh-plugin-status-bar

> 标签: composer, cordis, deepseek, dsh, dsh-plugin, harness, slot, status-bar

## 简介

DSH 客户端插件：在输入框上方维护一条状态条（比输入卡片略窄、居中、与卡片上沿贴合），向其它客户端插件提供 inputStatusBar 段注册面。不含任何业务逻辑。
