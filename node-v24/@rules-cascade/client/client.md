# @rules-cascade/client

> 标签: browser, business-rules, decision-engine, forms, react, react-hook, rule-cascade, rules-cascade, rules-engine, validation

## 简介

Rule Cascade in the browser and in Node.js clients: fetch, cache and refresh the client manifest, and evaluate it in a React form with useRuleEvaluation.
