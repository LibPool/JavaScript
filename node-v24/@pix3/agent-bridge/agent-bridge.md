# @pix3/agent-bridge

> 标签: agent, antigravity, claude, codex, llm, openai, pix3, proxy

## 简介

Local bridge for the Pix3 editor's in-editor agent: Claude Agent SDK, Antigravity CLI, Codex CLI, and a credential-injecting proxy for OpenAI / Anthropic / OpenCode Zen / custom providers. Keys stay on your machine.
