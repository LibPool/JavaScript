# @pix3/cli

> 标签: agent, cli, game-engine, mcp, pix3

## 简介

Pix3 command line: create a project from a recipe, and link your own coding agent (Claude Code, Codex, ...) to an open Pix3 editor window over a loopback MCP channel.

- 源码仓库：git+https://github.com/pix3dev/pix3.git
