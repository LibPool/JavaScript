# dsh-plugin-read-image-preview

> 标签: deepseek-harness, dsh, dsh-plugin, image, preview, screenshot, tool-card, ui

## 简介

会话图片的全屏查看与标注：接管官方图库位置（read_image 行、消息图片）与 computer-use 等工具卡片；查看器工具常驻，标记可选中/移动/改尺寸，滚轮缩放、触控板捏合与双指平移；回车把图片（含标注、按裁剪）直接放进输入框，也可复制或存进 ~/.dsh/screenshots；输入框旁一键抓屏后直接框选；设置页管理与按期清理截图。
