# @fnioc/core

> 标签: dependency-injection, di, ioc, typescript

## 简介

The pure-types ioc abstractions substrate: the dependency-signature data format, the slot/token type surface, and the authoring type machinery a library author depends on to author registrations without the di runtime. Types only — zero runtime, zero depe
