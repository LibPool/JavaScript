# @xberg-io/langchain-xberg

> 标签: document-extraction, document-loader, langchain, langchainjs, ocr, pdf, rag, text-extraction, xberg

## 简介

LangChain.js document loader for Xberg — extract text, tables, and metadata from 107 document formats with optional OCR.
