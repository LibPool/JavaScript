# @muthuishere/jevx

> 标签: agent-skill, claude-code, cli, codex, hooks, jev, system-one

## 简介

Agent skill + CLI for fast typed judgements (yes/no, pick-one, rating) from any Jev-style System One endpoint. Installs the jevx binary from GitHub Releases.
