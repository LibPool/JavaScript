# @kikulmj/dsh-jupyter

> 标签: JavaScript

## 简介

Jupyter notebook (.ipynb) viewer, editor and runner for the dsh web GUI: a native right-sidebar tab type driven by the host filesystem service, with a stdlib-only Python kernel bridge that uses dsh's bundled Python. No native dependencies.
