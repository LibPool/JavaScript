# @sanning/anchor-langchain

> 标签: agents, ai, anchoring, arweave, audit-trail, langchain, provenance, sanning

## 简介

Anchor your LangChain.js agent's run tree as it executes: one callback handler turns every chain, LLM and tool step into a signed evidence envelope, sent to Sanning and witnessed on an interval to a permanent public record. Prompts and outputs are hashed
