# @metapages/hash-query

> 标签: base64, bookmarkable, deep-link, fragment, hash, hash-param, hash-params, hash-query, json, location-hash, no-backend, permalink, persist-state, query-params, query-string, react, react-hooks, search-params, serverless, shareable-url, state in url, state-in-url, state-management, typescript, url, url state, url-fragment, url-hash, url-state, use-hash-param, useHashParam, useHashParamJson

## 简介

Store state in the URL hash: typed get/set of hash query params (JSON, base64, boolean, number) + React hooks. Shareable, bookmarkable URL state, no server or database required.
