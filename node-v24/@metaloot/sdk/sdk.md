# @metaloot/sdk

> 标签: 2d-assets, 3d-assets, animation, auth, browser-games, game-audio, games, glb, metaloot, multiplayer

## 简介

Unified Metaloot SDK for games: hosted 2D, 3D, audio and animation assets, player auth, and multiplayer rooms.
