# @bsuite/dry-lint

> 标签: bsuite, eslint, eslint-plugin, eslintplugin, supabase

## 简介

ESLint plugin enforcing BSuite one-shot architecture (single-owner Supabase entity tables) and the OAuth callback bridge contract.
