# @stianselland/itx-mcp

> 标签: claude, crm, itx, mcp, model-context-protocol, ticketing

## 简介

Model Context Protocol server for ITX. Exposes the itx-cli surface as MCP tools so Claude can read tickets, customers, prospects, and activity history.
