# @keep-lts/html-minifier

> 标签: cli, compress, compressor, css, cve-2022-37620, cwe-1333-inefficient-regular-expression-complexity-(redos), fork, html, htmlmin, javascript, lts, min, minification, minifier, minify, optimize, optimizer, pack, packer, parse, parser, patch, security, uglifier, uglify

## 简介

Security-maintained drop-in fork of html-minifier. Patches CVE-2022-37620 (ReDoS) by bounding the leading whitespace in the custom-fragment regex, making matching linear. Original API unchanged.
