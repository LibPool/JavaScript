# @cxphoenix/vp-wasm-coding

> 标签: client-side, code-runner, codemirror, in-browser, pyodide, python, vitepress, vue, wasm

## 简介

VitePress component for a client-side Python coding playground — Pyodide in a Web Worker, AC/WA/RE/TLE verdicts, a bundled random-input generator, and a pluggable editor. No COOP/COEP required.
