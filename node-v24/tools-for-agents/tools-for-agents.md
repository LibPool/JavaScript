# tools-for-agents

> 标签: agent-tools, ai-agents, claude, claude-code, llm, mcp, mcp-server, zero-dependency

## 简介

The whole tools-for-agents kit in one install: nine zero-dependency MCP tools for coding agents — coordinate, read code, run safely, hold secrets, remember, read the web, read data, recall, see — and ghost, a self that persists across sessions.
