# @queryjs/core

> 标签: api, filter, orm, pagination, parser, query, query-parser, queryjs, rest, search, sort

## 简介

Type-safe, declarative query language for REST APIs: parse filter, sort, search, and pagination HTTP query parameters into validated ResourceQuery objects, then map them to any ORM via pluggable adapters.
