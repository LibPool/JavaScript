# @vs-org/session

> 标签: @vs-org/session, Express session manager, Mongo Db session, VS session, express session, session handler, vs session, vs-org session

## 简介

This is simple express session management middleware with Mongo DB for storing sessios. This package supports validate, destroy, create sessions.
