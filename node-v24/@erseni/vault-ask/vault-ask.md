# @erseni/vault-ask

> 标签: ai-agents, claude-code, end-to-end-encryption, mcp, secrets, zero-knowledge

## 简介

Request and send secrets for AI agents through Erseni Vault: end-to-end encrypted, bound to one command, masked in every output, never printed.
