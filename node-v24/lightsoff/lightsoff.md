# lightsoff

> 标签: JavaScript

## 简介

The Lights Off CLI validates and deploys TypeScript SDK factories, inspects runs, downloads artifacts, and manages GitHub bindings. Requires Node.js 24 or newer; Bun is not required for the installed executable.
