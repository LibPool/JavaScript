# dsh-research-panel

> 标签: deepseek-harness, dsh-plugin, panorama, research, skills

## 简介

Research tab for the DSH Web session page: a read-only panorama of installed agent skills — trigger commands (/skill) plus plain-language purpose notes, so users never have to memorize the skill corpus.
