# @uranus-workspace/auth

> 标签: JavaScript

## 简介

Uranus Technologies authentication package — generic OIDC (oidc-client-ts) with Keycloak presets, React provider, hooks, guards, pre-wired screens, API helpers and optional Next.js App Router middleware.
