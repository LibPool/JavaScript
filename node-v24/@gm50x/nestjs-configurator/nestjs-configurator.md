# @gm50x/nestjs-configurator

> 标签: JavaScript

## 简介

[nestjs-configurator](https://githuyb.com/gm50x/nestjs-configurator) is a unified way to add CORS, Compression, Helmet, Serialization and initialize Swagger on NestJS applications.
