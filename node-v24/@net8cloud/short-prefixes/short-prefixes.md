# @net8cloud/short-prefixes

> 标签: JavaScript

## 简介

This repository contains a list of prefixes for common shorter URLs, so for example, `youtube.com/watch?v=yr_HIrfr7is` just becomes `n8s.uk/~y.yr_HIrfr7is`. This might not look like much of a saving, but when sharing links in places with character limits
