# @rn-projects/react-native-canvas

> 标签: 2d, android, canvas, canvas2d, drawing, fabric, game, graphics, html5-canvas, ios, jsi, react-native, skia

## 简介

The HTML5 Canvas 2D API for React Native, GPU-rendered with Skia (C++) — paths, text, images, gradients, filters & drag events at 60fps. No WebView, no bridge. If you know ctx.fillRect, you already know it.
