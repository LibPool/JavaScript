# @sartodev/vite-plugin-tsgo-checker

> 标签: checker, overlay, oxlint, tsgo, typescript-go, vite, vite-plugin

## 简介

Vite plugin that type-checks with tsgo (TypeScript 7) and lints with Oxlint, with a browser overlay and formatted terminal output.
