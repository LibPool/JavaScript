# blockchainiq-x402-mcp

> 标签: base, crypto, market-data, mcp, model-context-protocol, usdc, x402

## 简介

MCP server for Blockchain IQ's pay-per-call crypto market data API (x402, USDC on Base). Free catalog and sample without a wallet; paid tools are paid by your own wallet.
