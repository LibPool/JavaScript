# @twist-space/twist-icons-plugins

> 标签: JavaScript

## 简介

if you use [twist-icons](https://github.com/twist-space/twist-icons) in `Vue3/2`, you can use the [unplugin-vue-components](https://github.com/unplugin/unplugin-vue-components) plugin to automatically import components without using import icon component
