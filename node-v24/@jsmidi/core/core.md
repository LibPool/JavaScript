# @jsmidi/core

> 标签: ableton, garage band, live coding, logic pro, midi, pro tools, sonic pi

## 简介

JSMidi is a library for live coding and producing music with JavaScript using a digital audio workstation like Logic Pro X, Ableton, Garage Band, etc.
