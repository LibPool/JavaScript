# @workspec/canvas

> 标签: canvas, diagram, infinite-canvas, react, ui, whiteboard, zustand

## 简介

Host-agnostic infinite-canvas engine for WorkSpec surfaces: per-instance zustand store factory with undo/redo command history, camera/pointer/keyboard hooks, fractional-index z-order, an open shape-util/tool registry seam, and a CanvasHost persistence sea
