# @eir-labs/coltrane

> 标签: agents, claude, mcp, methodology, model-context-protocol, workflow-engine

## 简介

A methodology engine — a typed substrate for defining agents, composing multi-phase standards, dispatching gigs, and sealing every output to a content-addressed ledger. Ships as an MCP server.
