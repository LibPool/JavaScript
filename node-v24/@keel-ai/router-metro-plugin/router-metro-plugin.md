# @keel-ai/router-metro-plugin

> 标签: JavaScript

## 简介

Metro bundler plugin that scans `app/` at build time and emits a virtual `@keel-ai/router/__routes__.js` module + TypeScript types. Pair with @keel-ai/router for build-time routing (V2).
