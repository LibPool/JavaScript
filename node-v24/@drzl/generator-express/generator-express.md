# @drzl/generator-express

> 标签: codegen, drizzle, drizzle-orm, express, rest, standard-schema

## 简介

Generate Express 5 routers from a Drizzle schema, one route module per table, validated by DRZL's schemas through an emitted Standard Schema middleware.
