# @drzl/generator-fast-check

> 标签: codegen, constraints, drizzle, drizzle-orm, fast-check, property-testing

## 简介

Generate fast-check arbitraries from a Drizzle schema, bounded by every CHECK the analyzer parsed, so a property test only draws rows the database would accept.
