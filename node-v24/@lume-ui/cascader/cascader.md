# @lume-ui/cascader

> 标签: cascade, cascader, component, lume-ui, picker, radix-ui, react, select, tailwind, tailwindcss, typescript, ui

## 简介

A powerful cascading selector component built with React, Radix UI, and Tailwind CSS. Supports single/multiple selection, search, and custom rendering.
