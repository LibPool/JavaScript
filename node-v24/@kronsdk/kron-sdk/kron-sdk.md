# @kronsdk/kron-sdk

> 标签: covenant, dex, kaspa, kcc20, kron, silverscript, wallet

## 简介

Build, sign, and submit transactions against KRON's native-L1 Kaspa covenants (bonding curve + AMM pool) from any JS/TS environment — browser or Node. Reference SDK for wallet and dApp integrators.
