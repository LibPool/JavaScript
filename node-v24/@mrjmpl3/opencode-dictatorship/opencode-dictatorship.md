# @mrjmpl3/opencode-dictatorship

> 标签: agents, ai, coding-agent, mcp, multi-agent, opencode, orchestration, plugin

## 简介

Agent orchestration plugin for OpenCode — a single Commander directing specialised agents (Recon, Strategist, Intelligence, Operative, Designer, Surveillance) with the Model Context Protocol.
