# @constructive-io/site-deploy

> 标签: constructive, content-addressed, deploy, preview, release, static-site

## 简介

Deploy a static build as an immutable Constructive release: hash, content-addressed upload with dedupe, one manifest commit, publish/rollback and preview refs
