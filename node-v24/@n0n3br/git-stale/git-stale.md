# @n0n3br/git-stale

> 标签: audit, cli, developer-tools, git, hygiene, repository, stale

## 简介

Scan a directory of git repos and flag dirty worktrees, unpushed/unpulled commits, stale projects, detached HEAD and dead GitHub remotes.
