# @glandjs/fastify

> 标签: adapter, architecture, event-driven, fastify, fastify-adapter, framework, gland, glandjs, http, protocol, typescript

## 简介

A Fastify adapter for Gland HTTP protocol layer, enabling high-performance HTTP handling within the Gland architecture solution.
