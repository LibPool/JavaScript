# @glandjs/node

> 标签: adapter, architecture, event-driven, framework, gland, glandjs, http, middleware, node, nodejs, protocol, router, typescript, zero-dependency

## 简介

Gland's HTTP layer on node:http, with no framework and no runtime dependencies. Also the reference implementation of the adapter contract.
