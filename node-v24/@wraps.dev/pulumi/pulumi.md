# @wraps.dev/pulumi

> 标签: aws, aws-ses, deploy, email, email-infrastructure, iac, infrastructure, pulumi, pulumi-component, ses, wraps

## 简介

Pulumi component for email infrastructure. Deploys SES, event processing, email history, HTTPS tracking, and OIDC auth as a composable component.
