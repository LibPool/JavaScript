# @soasap-com/angular-sdk

> 标签: angular, feature-flags, feature-management, remote-config, signals, soasap, sse

## 简介

Ultra-lightweight, flicker-free feature flags SDK for Angular with instant client-side evaluation. Real-time SSE updates, persistent browser cache, and reactive Signals for zero-overhead UI rendering.
