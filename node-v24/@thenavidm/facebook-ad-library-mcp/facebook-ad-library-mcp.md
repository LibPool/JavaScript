# @thenavidm/facebook-ad-library-mcp

> 标签: ad-intelligence, ad-library, ai-agents, claude, claude-code, competitive-research, facebook-ads, llm-tools, mcp, mcp-server, meta-ad-library, model-context-protocol

## 简介

MCP server for Meta's public Ad Library. Reads the real ad JSON rather than scraping rendered text, so it returns every creative, the true landing URL and the platform list. Free by default with no API key, with optional provider backends. Works with Clau
