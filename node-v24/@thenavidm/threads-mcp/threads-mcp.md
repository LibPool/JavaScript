# @thenavidm/threads-mcp

> 标签: ai-agents, claude, claude-code, llm-tools, mcp, mcp-server, meta, model-context-protocol, threads, threads-api

## 简介

MCP server for Threads. 30 tools for posting, chained threads, carousels, replies and reply approvals, insights, keyword search and profile discovery, with LLM-optimised output. One-command OAuth with automatic 60-day token refresh. Works with Claude Code
