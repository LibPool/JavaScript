# @thenavidm/telegram-mcp-cli

> 标签: ai-agents, claude, cli, mcp, model-context-protocol, mtproto, telegram

## 简介

Telegram MCP server and CLI for Claude Code and AI agents. 74 tools for chats, history, search, sending, media, contacts, groups, admin, topics, reactions, polls, folders and privacy, on your real Telegram account over MTProto.
