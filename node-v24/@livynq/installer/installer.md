# @livynq/installer

> 标签: JavaScript

## 简介

npm-free package installer used by Livynq for its plugins and Homebridge plugins: semver resolution, integrity checks, no install scripts

- 官网：https://github.com/gongbin/livynq#readme
- 源码仓库：git+https://github.com/gongbin/livynq.git
- npm 页面：https://www.npmjs.com/package/@livynq/installer
