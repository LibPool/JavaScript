# @rogeecn/pi-retry

> 标签: error-normalizer, pi, pi-coding-agent, pi-extension, pi-package, retry

## 简介

Normalize unrecognized transient provider errors (e.g. HTTP/2 PROTOCOL_ERROR from cliproxyapi) so pi's agent-level auto-retry kicks in instead of stopping.
