# @zhongcp/dsh-model-fallback

> 标签: deepseek-harness, dsh, dsh-plugin, fallback, llm, model-switch, quota, retry

## 简介

模型报错时自动切到备用模型并在同一步重试，备用模型可在设置页从模型列表里选。
