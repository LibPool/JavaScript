# @campminder/menu-tree-guard

> 标签: campminder, drift, menu, navigation

## 简介

The generic menu drift guard for the nav Domain System: compares a portal's shipped menu tree against a derived fixture of its host's canonical menu, allowing only the differences a reviewed known-deltas contract accepts. ERP-agnostic — carries no portal'
