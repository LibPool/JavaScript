# @campminder/menu-filter

> 标签: JavaScript

## 简介

The pure menu visibility filter for the nav Domain System: (tree, FilterContext) => tree over the entitlement and releaseFlag rule kinds, plus the deprecated feature, featureKey and versionBranch kinds. ERP-agnostic, no I/O.
