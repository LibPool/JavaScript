# @jimp/wasm-jpeg

> 标签: JavaScript

## 简介

A format plugin for Jimp that adds support for JPEG images using [mozjpeg](https://github.com/mozilla/mozjpeg).

- 官网：https://github.com/jimp-dev/jimp#readme
- 源码仓库：git+https://github.com/jimp-dev/jimp.git
