> 标签: bot-detection, browser-verification, express, mandate, middleware, nextjs, security, token-verification, x-mndt

## 简介

MANDATE verification for Node.js: hosted cross-referenced validation by default, plus the offline DEADMAN emergency tier and legacy local verification.
