# @topo/cross-inpage-provider-injected

> 标签: cross-inpage-provider

## 简介

当引入或升级第三方库时，可能会遇到语法兼容性检查失败的情况。这是因为我们的项目使用 `syntax-compatibility.eslint.config.cjs` 来限制使用较新的 JavaScript 语法特性，以确保更好的浏览器兼容性。
