# photocn

> 标签: exif, image-editor, lut, photo-editor, react, shadcn, webgl

## 简介

GPU photo editor engine for React: adjustments, curves, LUT filters, crop, perspective, blur, EXIF-aware export. Pairs with the photocn shadcn/ui registry.
