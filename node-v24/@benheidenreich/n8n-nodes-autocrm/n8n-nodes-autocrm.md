# @benheidenreich/n8n-nodes-autocrm

> 标签: autocrm, automotive, crm, dealership, lead-management, leads, n8n-community-node-package

## 简介

n8n community node for autocrm (IMAGO Informationstechnologie): create, search and read leads, assign them to branches, categories and employees, attach emails and notes, and check lead existence via the autocrm API3
