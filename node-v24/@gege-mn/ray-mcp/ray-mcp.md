# @gege-mn/ray-mcp

> 标签: ai-agents, discord, email, mcp, mcp-server, model-context-protocol, notifications, push-notifications, ray, slack, telegram, webhooks

## 简介

Local stdio MCP server for Ray, the notification delivery API (email, push, Slack, Discord, Telegram, webhooks). Bridges to Ray's hosted MCP endpoint.
