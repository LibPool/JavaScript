> 标签: adapter, baileys, bot, chatbot, commands, framework, igniter-js, messaging, middleware, telegram, type-safe, typescript, whatsapp, zaileys, zod

## 简介

A modern, type-safe multi-platform bot framework for the Igniter.js ecosystem (adapters, middleware, commands, rich content).
