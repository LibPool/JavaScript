# @loomweaver/mcp

> 标签: ai-tools, codegen, loomweaver, mcp, model-context-protocol, scaffolding

## 简介

LoomWeaver: open-source plugin platform for Angular workbenches. The MCP server: scaffolding and validation as tools, so an AI assistant in any product repo can build weavers without a checkout.
