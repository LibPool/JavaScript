# @pandi-coding-agent/ask

> 标签: ask, confirm, pi, pi-extension, pi-package, select, tui

## 简介

Pi extension with interactive decision tools (ask_choice, ask_confirm) the model can call to pop a TUI selector / confirm dialog and read back the choice.
