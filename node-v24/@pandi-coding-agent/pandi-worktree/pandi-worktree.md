# @pandi-coding-agent/pandi-worktree

> 标签: git, pi, pi-extension, pi-package, worktree

## 简介

Extensión de Pi para gestionar git worktrees: un comando /worktree y una tool git_worktree invocable por el modelo (list/add/open/remove/prune).
