# @hirez_io/jest-given

> 标签: Given When Then, JavasScript Unit Tests, Microtests, Testing, TypeScript Unit Tests, Unit tests, gwt, hirez.io, jest, jest-given

## 简介

A jest addon that helps you clean up your microtests by breaking them into a Given / When / Then structure.
