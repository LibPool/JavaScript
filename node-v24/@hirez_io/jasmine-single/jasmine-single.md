> 标签: Angular Tests, Given When Then, JavasScript Unit Tests, Microtests, Single Action Tests, Testing, TypeScript Unit Tests, Unit tests, gwt, hirez.io, jasmine, jasmine-single

## 简介

A Jasmine addon that helps you write 'Single-Action Tests' by breaking them into a given / when / then structure.
