# @kevinvincent/mcp-bridge

> 标签: JavaScript

## 简介

A lightweight bridge that connects [Claude Desktop](https://www.anthropic.com/index/claude-desktop) via **STDIO** to any MCP-compatible backend using **SSE (Server-Sent Events)**.
