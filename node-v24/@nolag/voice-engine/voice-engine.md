# @nolag/voice-engine

> 标签: JavaScript

## 简介

Real-time voice agent engine: turn taking, barge-in, voice activity detection and call screening, independent of any telephony or AI vendor. Pairs with @nolag/voice so the call can reach a larger orchestrator for knowledge and tools.
