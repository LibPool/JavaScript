# @activeledger/nano-gateway

> 标签: activeledger, blockchain, distributed ledger technology, dlt, ledger, nano, network

## 简介

Lightweight, permissioned SSE + read gateway for nano light-node clients - runs alongside a real Activeledger node, direct DB access like activehybrid, no Activecore dependency.
