# graph-propagate

> 标签: agents, ai, claude, codex, cursor, gemini, graph, graph-first, graphify, knowledge-graph, legacy, reverse-engineering, specifications, token-reduction

## 简介

Graph-first reverse engineering for legacy systems (Reversa fork with graphify). Codex agents query a graphify knowledge graph of the code before reading files, so analysis runs faster with far fewer tokens. graphify is installed automatically on first ru
