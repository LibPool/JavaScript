# @techholding/payload-publishing-workflows-plugin

> 标签: approval, cms, payloadcms, payloadcms 3, plugin, publishing, rbac, review, state machine, typescript, workflow

## 简介

A PayloadCMS plugin that adds multi-stage content approval workflows (draft -> review -> approved -> published) with role-based permissions, audit trail, and event-driven notification hooks.
