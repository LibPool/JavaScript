# @gnomes/scxml

> 标签: scxml, simulation, state-machine, statechart, visualization, wasm, webassembly, workflow, xml

## 简介

Browser-first WebAssembly package for parsing, validating, exporting, diffing, and simulating W3C SCXML statecharts.
