# @smithy-hono/adapter-node

> 标签: JavaScript

## 简介

Node/Redis runtime adapter for @smithy-hono/security-core. Implements the four storage interfaces (Session, RateLimit, Nonce, SecretProvider) over a narrow structural Redis port plus platform glue (forwarded-proto / client-IP resolvers, stdout JSON logger
