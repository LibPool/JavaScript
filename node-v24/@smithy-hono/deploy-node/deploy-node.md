# @smithy-hono/deploy-node

> 标签: JavaScript

## 简介

One-command Node/Docker/Kubernetes deploy for smithy-hono apps: given a domain, builds the API (and optional same-origin SPA front-door) container images, generates + syncs secrets into a k8s Secret, renders the Deployment/Service/Ingress/ConfigMap manife
