# @smithy-hono/deploy-cf

> 标签: JavaScript

## 简介

One-command Cloudflare Workers deploy for smithy-hono apps: given a domain, provisions the declared bindings (KV / Durable Objects / D1), generates + syncs secrets, renders wrangler config with a custom-domain route, builds the UI, and deploys — UI + API
