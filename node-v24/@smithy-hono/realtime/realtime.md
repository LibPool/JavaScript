# @smithy-hono/realtime

> 标签: JavaScript

## 简介

Opt-in realtime notify-hub runtime for smithy-hono @live resources. A backend-agnostic RealtimeHub port with a poll-anywhere PollingHub and an in-process MemoryHub, a notify-on-commit DataStore decorator (withLiveNotify), a hono streamSSE endpoint bridge,
