# @theholocron/holocron-plugin-infisical

> 标签: holocron, infisical, plugin, vault

## 简介

Holocron plugin for Infisical. Implements the vault capability against Infisical's REST API, plus exports verifyToken + AUTH_HINT for `holocron auth`.
