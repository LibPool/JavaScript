# @theholocron/holocron-plugin-doppler

> 标签: doppler, holocron, plugin, vault

## 简介

Holocron plugin for Doppler. Implements the vault capability against Doppler's REST API — projects, configs, secrets, plus verifyToken + AUTH_HINT for `holocron auth`.
