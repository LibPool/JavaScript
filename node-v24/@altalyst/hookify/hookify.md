# @altalyst/hookify

> 标签: data-fetching, debounce, frontend, hooks, local-storage, outside-click, react, react-hooks, state-management, toggle, typescript, utility-hooks

## 简介

A lightweight, dependency-free collection of framework-agnostic React hooks for debouncing, data fetching, toggling state, syncing state to storage, detecting outside clicks, and more.
