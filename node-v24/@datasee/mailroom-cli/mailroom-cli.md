# @datasee/mailroom-cli

> 标签: ai, claude, cli, email, email-marketing, mailroom, mcp, model-context-protocol, newsletter, self-hosted, ses

## 简介

CLI and MCP server for mailroom, the self-hosted newsletter platform. Manage address books, write newsletters in Markdown, send, and read delivery stats — or let Claude do it.
