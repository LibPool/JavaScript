# @vertexa/prisma-fetch-engine

> 标签: Prisma, binary, cache, download, engine, fetch, fork, internal, vertexa

## 简介

Fork of @prisma/fetch-engine — downloads and caches Prisma Rust engine binaries from GitHub Releases. Internal package consumed by @vertexa/prisma-engines.
