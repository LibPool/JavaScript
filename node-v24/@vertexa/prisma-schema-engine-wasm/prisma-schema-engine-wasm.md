# @vertexa/prisma-schema-engine-wasm

> 标签: PostGIS, Prisma, WASM, WebAssembly, fork, geography, geometry, internal, introspection, migration, schema-engine, vertexa

## 简介

Fork of @prisma/schema-engine-wasm — WebAssembly bindings for the Prisma Schema Engine, handling database migrations and introspections. Adds PostGIS Geometry/Geography type support. Internal package.
