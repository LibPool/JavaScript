# @viixixciv/chainid

> 标签: blockchain, chainid, cli, cli-tool, developer-tools, ethereum, evm, rpc, terminal, web3

## 简介

An elegant CLI tool to retrieve a blockchain's chainId from any RPC endpoint (supports HTTP/S and WebSocket).
