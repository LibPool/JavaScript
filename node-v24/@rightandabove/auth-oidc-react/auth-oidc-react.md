# @rightandabove/auth-oidc-react

> 标签: JavaScript

## 简介

Headless React client for auth-oidc: Redux Toolkit slice, redux-observable epics, `useAuth()`, and `bootstrapAuthOidc()`. **No UI kit** — wire it into your own store and screens.
