# @bryanberger/jmap-mcp

> 标签: caldav, calendar, email, jmap, mcp, stalwart

## 简介

Local MCP server exposing a Stalwart JMAP server (mail, calendar, contacts, files, sharing, Sieve) to an AI assistant, with a configurable write policy.
