# @braynexservices/nigeria-mcp-worldbank-macro

> 标签: economy, gdp, indicators, macroeconomics, mcp, model-context-protocol, nigeria, world-bank

## 简介

Nigerian macroeconomic indicators (GDP, inflation, population, remittances, FDI, unemployment) as MCP tools. Backed by the World Bank Indicators API, keyless.
