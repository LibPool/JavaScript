# @braynexservices/nigeria-mcp-nigsac-sanctions

> 标签: compliance, kyc, mcp, model-context-protocol, nigeria, nigsac, sanctions, sanctions-screening

## 简介

Screen a person or company name against Nigeria's official NIGSAC sanctions register as an MCP tool — a best-effort, diacritic-folded, transliteration-tolerant screening signal for human review. Live register, keyless.
