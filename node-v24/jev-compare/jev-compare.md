# jev-compare

> 标签: ai, bounding-box, design-qa, image, image-comparison, image-diff, jev, screenshot, similarity, typesafe, ui-review, visual-regression, visual-testing

## 简介

AI visual image comparison for UI review: a 1–10 similarity score, located differences with bounding boxes, and fix suggestions. Built on the TypeSafe AI (Jev) SDK.
