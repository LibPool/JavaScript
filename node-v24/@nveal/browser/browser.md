# @nveal/browser

> 标签: analytics, nveal, privacy, replay, session-recording, session-replay, user-behavior, user-session, web-analytics

## 简介

Lightweight session recording SDK for capturing and replaying user sessions. Record, replay, and analyze user behavior with privacy-first defaults.
