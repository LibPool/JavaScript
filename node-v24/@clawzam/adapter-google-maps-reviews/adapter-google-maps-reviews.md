# @clawzam/adapter-google-maps-reviews

> 标签: adapter, clawzam, google-maps-reviews, serpapi

## 简介

Fetch customer reviews for any Google Maps listing. Returns reviewer info, ratings, text, and dates. Requires a data_id (get it from google-maps-search).
