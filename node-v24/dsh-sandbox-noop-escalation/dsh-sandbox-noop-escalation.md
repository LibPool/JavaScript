# dsh-sandbox-noop-escalation

> 标签: codex, cordis, deepseek-harness, dsh, dsh-plugin, gpt, sandbox

## 简介

DeepSeek Harness plugin: drop sandbox_permissions/justification fields that cannot widen the current sandbox mode, so redundant escalations (common with GPT models) no longer fail with "not strictly wider".
