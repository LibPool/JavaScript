# @zoreal/mark-verify

> 标签: content-signing, mark, post-quantum, provenance, signature, verification, zoreal

## 简介

Verify a ZOREAL Mark: a live, chip-verified human vouched for exactly this text, here, then. The one verifier implementation, shared by the browser extensions, the verify page and the badge script.
