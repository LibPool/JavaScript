# @thecyrilcril/mcp-config-builder

> 标签: config, dotenv, laravel, leak-prevention, mcp, model-context-protocol, secrets

## 简介

Build a project's .mcp.json from a committed placeholder template, injecting secrets from .env at build time — with a built-in leak guard that refuses to process a template containing raw secrets.
