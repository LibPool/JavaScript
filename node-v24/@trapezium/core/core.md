# @trapezium/core

> 标签: data-table, datagrid, filtering, headless, pagination, sorting, table

## 简介

Framework-agnostic engine behind Trapezium tables: column model, type registry, filtering, sorting, pagination, selection and URL state. Zero dependencies.
