# @seonggukchoi/datee

> 标签: JavaScript

## 简介

[Datee](https://github.com/seonggukchoi/packages.js/tree/main/packages/datee) is a simple and lightweight date library that extends a `Date` class of native JavaScript, and provide some useful methods like [day.js](https://day.js.org/).
