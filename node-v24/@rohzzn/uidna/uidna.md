# @rohzzn/uidna

> 标签: coding-agents, design-tokens, mcp, model-context-protocol, playwright, react, reverse-engineering, ui

## 简介

Reverse-engineer any user interface into a UI DNA document, rebuild it as code you own, and prove it with a DiffReport. MCP server and CLI for coding agents.
