# @tikpay/iso8583-ts

> 标签: bcd, emv, iso8583, lllvar, llvar, payments, typescript

## 简介

ISO 8583 parser written in TypeScript with LLVAR/LLLVAR enforcement, bitmap handling and built-in field level BCD/ASCII encoding.
