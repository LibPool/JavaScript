# @vipulc/line-match

> 标签: filter-lines, find, grep, inverse-match, line, line match, lines, locate, match, pattern, regex, regular-expression, search, text-processing

## 简介

Returns lines matching a pattern in a string. Supports inverse operation as well, to exclude lines with matches.
