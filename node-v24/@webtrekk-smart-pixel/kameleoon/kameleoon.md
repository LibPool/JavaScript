# @webtrekk-smart-pixel/kameleoon

> 标签: JavaScript

## 简介

The Webtrekk Kameleoon extension makes it easier for you to analyse the displayed A/B test and variants. Using the extension, the information from Kameleoon tests are sent directly to Webtrekk.
