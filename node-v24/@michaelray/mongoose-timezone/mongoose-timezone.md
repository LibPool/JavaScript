# @michaelray/mongoose-timezone

> 标签: JavaScript

## 简介

一个mongoose插件，用于规范存储的日期时区。默认情况下，mongo日期以UTC格式存储，如果服务器存放在其它时区，则显示会有差别。该插件用于渲染服务器所在时区的时间。
