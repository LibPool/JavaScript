# @airprompter/agent-telemetry

> 标签: agent, airprompter, governance, llm, opentelemetry, prompts, spool, telemetry

## 简介

The content-free telemetry spool and its uploader for AirPrompter agents: minute windows as append-only segments (or in memory on serverless), the host budget, and direct-to-object-store upload under a grant.
