# @did-btcr2/keypair

> 标签: bip340, bip340 key pair, bitcoin, cryptosuite, decentralized identifiers, decentralized identity, did, did method, did:btcr2, dids, schnorr, schnorr signatures, secp256k1, secp256k1 key pair

## 简介

Secp256k1 key pairs with ECDSA, BIP-340 Schnorr, and BIP-341 taproot signing, multibase encoding, and constant-time operations.
