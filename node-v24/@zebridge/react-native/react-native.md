# @zebridge/react-native

> 标签: expo, expo-module, nats, offline-first, postgresql, react-native, sqlite, sync

## 简介

ZeBridge for React Native: an offline-first SQLite replica of PostgreSQL tables over NATS, as an Expo module with libzb built in (iOS and Android)
