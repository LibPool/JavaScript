# @dittos-loop/daemon

> 标签: agent, claude-code, daemon, dittos, loop

## 简介

Local agent daemon for Dittos.Loop — connects your machine's Claude Code to a Loop engine over WebSocket. Run via npx; no repo clone needed.

## 官网

- npm 页面：https://www.npmjs.com/package/@dittos-loop/daemon

- npm registry：https://registry.npmjs.org/@dittos-loop/daemon
- Node 要求：>=20
