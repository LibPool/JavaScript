# @eastdesire/jscolor

> 标签: JavaScript

## 简介

Web color picker with opacity channel (alpha channel) and custom palette. Supports CSS colors such as rgba() and hex, including #rrggbbaa.

## 官网

- 官网：https://jscolor.com
- 源码仓库：git+https://github.com/EastDesire/jscolor.git
- npm 页面：https://www.npmjs.com/package/@eastdesire/jscolor
