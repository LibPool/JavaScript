# @bellhop-marketing/mcp-install

> 标签: bellhop, claude, claude-code, claude-skills, cursor, installer, mcp, model-context-protocol

## 简介

One command to connect the Bellhop MCP server to Claude Code, Cursor, and Claude Desktop — and install the Bellhop skills into Claude Code.
