# @villji/dsh-file-manager

> 标签: agent, cordis, deepseek, dsh, dsh-web, file-manager, plugin

## 简介

A dsh-web file browser & editor plugin: a floating two-pane panel (browse, view/edit with highlight.js syntax highlighting) launched from a sidebar button.
