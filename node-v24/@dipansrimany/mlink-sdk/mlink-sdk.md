> 标签: blockchain, blockchain links for mantle, evm, mantle, mantle-network, mlink, react, transactions, ui-components, web3

## 简介

SDK for building Mantle links - shareable blockchain transaction URLs with React UI components. Supports Solana-style linked actions with parameters.
