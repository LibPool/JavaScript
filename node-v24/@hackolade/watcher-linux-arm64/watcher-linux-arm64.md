# @hackolade/watcher-linux-arm64

> 标签: JavaScript

## 简介

Re-published version to have all prebuilds defined as npm packages without platform constraints for cross building an Electron application - A native C++ Node module for querying and subscribing to filesystem events. Used by Parcel 2.
