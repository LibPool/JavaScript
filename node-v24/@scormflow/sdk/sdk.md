# @scormflow/sdk

> 标签: client, cmi5, elearning, pluggable-transport, scorm, scorm-1-2, scorm-2004, sdk, typescript, xapi

## 简介

Framework-agnostic TypeScript client for the ScormFlow runtime engine. Pluggable ScormTransport (REST, LocalStorage, Memory, bring your own).
