# @openslow/dsh-web-mobile

> 标签: JavaScript

## 简介

Mobile-adaptive DSH web UI: on narrow screens the settings dialog becomes a full-screen sheet and the details panel opens as a full-screen drawer, so every surface stays usable on phones.
