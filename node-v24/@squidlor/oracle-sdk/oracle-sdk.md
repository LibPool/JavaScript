# @squidlor/oracle-sdk

> 标签: aggregator, arbitrum, chainlink, defi, oracle, price-feed, qubetics, robinhood-chain, squidlor, viem

## 简介

Read Squidlor aggregated oracle feeds on any supported chain — on-chain via viem or off-chain via the REST API.
