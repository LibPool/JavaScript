# @hsinsekai-nanami/dsh-notifier

> 标签: approval, codex, deepseek-harness, dsh-plugin, notifications, toast

## 简介

DSH 任务提醒插件：任务结束/审批/提问/出错时网页 toast + 跨窗口系统弹窗 + 通知中心；设置页内置配置预设，可自定义弹窗位置、样式、主题、宽度与系统级提醒开关
