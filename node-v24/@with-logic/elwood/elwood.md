# @with-logic/elwood

> 标签: agent, automation, claude-code, cli, codex, hooks, llm, pty, terminal

## 简介

Control interactive agentic coding CLIs (Claude Code, Codex) through real terminal sessions: typed hooks, a unified activity stream, resumable sessions, and a headless CLI.
