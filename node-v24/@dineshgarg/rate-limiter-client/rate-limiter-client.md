# @dineshgarg/rate-limiter-client

> 标签: JavaScript

## 简介

A minimal client for the rate-limiter SaaS's enforcement endpoint, `POST /v1/rate-limit/check`. Call `check()` before handling a request to see whether it's allowed under the rule configured for that resource.
