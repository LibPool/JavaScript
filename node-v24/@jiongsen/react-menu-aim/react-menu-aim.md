# @jiongsen/react-menu-aim

> 标签: anti-flicker, direction-detection, dropdown, menu, menu-aim, react, react-component, submenu, ux

## 简介

A React implementation of jQuery-menu-aim — smart dropdown menus with aim detection to prevent flicker when moving diagonally toward submenus
