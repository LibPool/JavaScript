# @run4w4y/nx-tailwind-source-plugin

> 标签: nx, plugin, postcss, sources, tailwindcss, tailwindcss-v4, workspace

## 简介

PostCSS plugin for dynamic configuration of Tailwind CSS v4 @source directives from an Nx project graph.
