# @bunnycode/react-zoom

> 标签: ecommerce, image, magnify, product, react, zoom

## 简介

A highly customizable, React + Tailwind-powered product image zoom component.   Supports thumbnails, double-click zoom, and drag-to-pan. Perfect for e-commerce apps 🛒.
