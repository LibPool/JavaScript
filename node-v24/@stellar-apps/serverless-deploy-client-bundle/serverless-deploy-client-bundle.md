# @stellar-apps/serverless-deploy-client-bundle

> 标签: bundler, client bundle, plugin, s3, serverless, serverless-plugin, upload, webpack

## 简介

A Serverless plugin that bundles your client-side code with Webpack and uploads it to an S3 bucket. This was built to be used with React SSR lambda functions, but may have additional uses.
