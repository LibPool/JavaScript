# @wesgro/postcss-migrate-colors-to-vars

> 标签: JavaScript

## 简介

Will: * find all colors inside of a css file * compare them to a Object of css vars, and their values * replace the color with the css-var of your choosing based on the nearest delta      * based on [Delta E2000](https://en.wikipedia.org/wiki/Color_differ
