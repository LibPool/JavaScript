# @plannotator/atomic-editor

> 标签: codemirror, codemirror6, editor, live-preview, markdown, obsidian, react, wysiwyg

## 简介

CodeMirror 6 markdown editor with Obsidian-style inline live preview. Plannotator fork of atomic-editor (adds YAML frontmatter parsing).
