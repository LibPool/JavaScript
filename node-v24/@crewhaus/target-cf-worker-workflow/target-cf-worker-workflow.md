# @crewhaus/target-cf-worker-workflow

> 标签: JavaScript

## 简介

Codegen backend for the workflow target emitted as a Cloudflare Worker. Sibling of target-cf-worker-cli; reads the same IrWorkflowV0 variant, emits a self-contained Worker bundle that runs the steps sequentially.
