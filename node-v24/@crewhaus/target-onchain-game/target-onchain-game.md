# @crewhaus/target-onchain-game

> 标签: JavaScript

## 简介

Codegen for the §47 `onchain-game` perceive-act-perceive loop. Emits a daemon that reads game state, asks the model for a move, broadcasts the move, awaits confirmation, and repeats.
