# @gang-of-beads/pi-web-goals

> 标签: pi-goal, pi-package, pi-web, pi-web-plugin

## 简介

PI WEB plugin for pi-goal: a Goals tab listing the project's goals with their status and task progress, and short rows for goal events in the conversation.
