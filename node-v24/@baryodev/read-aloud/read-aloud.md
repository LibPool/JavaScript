# @baryodev/read-aloud

> 标签: accessibility, article, edge-tts, read-aloud, speech, text-to-speech, tts, web-component

## 简介

Add read-aloud to any site with Microsoft Edge's neural TTS. A tiny Node engine plus a customizable, framework-free browser reader: controller, web component, and word highlighting.
