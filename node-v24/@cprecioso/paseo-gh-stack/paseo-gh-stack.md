# @cprecioso/paseo-gh-stack

> 标签: gh-stack, paseo, paseo-plugin, stacked-prs

## 简介

Paseo workspace panel for GitHub stacked PRs: see the gh stack your branch belongs to and switch the workspace between its branches.
