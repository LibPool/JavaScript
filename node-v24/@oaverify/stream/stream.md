# @oaverify/stream

> 标签: json-schema, json-schema-2020-12, json-schema-validator, oas, openapi, openapi-3.0, openapi-3.1, openapi-3.2, openapi-validator, sax, stream, streaming, validation, validator

## 简介

Streaming OpenAPI / JSON Schema 2020-12 validator. Validates a JSON body as it streams with bounded memory for multi-GB payloads, echoing bytes through unchanged while reporting violations on a side channel. Built on @oaverify/core.
