# @passauth/express

> 标签: JavaScript

## 简介

`@passauth/express` is an Express integration for [passauth](https://www.npmjs.com/package/passauth).   It gives you a ready-to-use authentication router, optional email-based auth flows, middleware for protected routes, and an OpenAPI generator.
