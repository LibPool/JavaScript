# @dooor-ai/auth-node

> 标签: auth, dooor, express, fastify, jwks, jwt, nestjs, oidc

## 简介

Server-side verification for Dooor Auth access tokens: offline JWKS verification with kid caching, plus Express and generic guard adapters.
