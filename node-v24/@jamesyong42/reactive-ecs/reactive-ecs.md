# @jamesyong42/reactive-ecs

> 标签: ecs, entity-component-system, observable, query, react, reactive, scheduler, typescript, zero-dependencies

## 简介

A reactive, dependency-free TypeScript ECS — event-driven components, tags, resources, cached queries, and a topological system scheduler. Designed for React and other UI frameworks, not just game loops.
