# @petridhsg/medusa-plugin-product-translations

> 标签: category-translations, i18n, internationalization, medusa, medusa-plugin, medusa-v2, multilingual, product-translations, translations

## 简介

Product and category i18n translations for Medusa v2. Stores locale-aware translations for products, variants, options, option values, and categories — with ready-made admin and store API routes.
