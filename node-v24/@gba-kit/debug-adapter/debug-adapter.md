# @gba-kit/debug-adapter

> 标签: dap, debug-adapter-protocol, debugger, emulator, gameboy-advance, gba, typescript

## 简介

Debug Adapter Protocol server for GBA programs on top of gba-kit: VS Code, Neovim, Emacs, Zed and JetBrains debug a ROM with source, DWARF values, data breakpoints and exact rewind
