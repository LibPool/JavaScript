# @gba-kit/debug-ui

> 标签: debugger, emulator, gameboy-advance, gba, react, typescript

## 简介

React panels for a GBA debugger — screen with gamepad and audio, palette, tiles, tilemaps, sprites, I/O registers, trace, events, memory search, labels, save states, input recordings — over a transport an editor or a web page provides
