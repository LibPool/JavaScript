# @getciabatta/sdk

> 标签: ciabatta, realtime, speech-to-text, text-to-speech, voice-agent, voice-ai, websocket

## 简介

JavaScript SDK for the Ciabatta voice-agent API: REST client, resumable voice sessions, browser mic/speaker call, webhook verification.
