# sentrygate

> 标签: guardrail, jailbreak, laya, llm, onnx, pii, prompt-injection, redaction, security

## 简介

Local on-device guard between your app and an LLM: catch prompt injections (a 421M decision model run in-process via ONNX Runtime) and mask PII before the prompt leaves the machine. No API calls, nothing leaves your machine. Same engine as the Python pack
