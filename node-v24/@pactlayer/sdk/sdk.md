# @pactlayer/sdk

> 标签: ai-agents, escrow, ethereum, mcp, robinhood-chain, usdg, viem, web3, x402, xmtp

## 简介

TypeScript SDK for the PactLayer escrow protocol on Robinhood Chain. Create quests, lock ETH/USDG, build AI agents that earn onchain.
