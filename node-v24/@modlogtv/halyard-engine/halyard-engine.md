# @modlogtv/halyard-engine

> 标签: evaluation, feature-flags, ofrep, openfeature

## 简介

Pure, dependency-free feature flag evaluation engine used by Halyard. Evaluate a flag configuration against an evaluation context and get a value with a reason.
