# @lucidaquarian/app-version-checker

> 标签: app-store, app-update, capacitor, cordova, hybrid-app, ionic, mobile, play-store, version-check, version-compare

## 简介

A cross-platform version checker plugin for Cordova and Capacitor-based mobile applications. Compare local app versions against remote sources and prompt users to update.
