# @jugaaadi/table

> 标签: data-grid, datagrid, editable, formulas, react, spreadsheet, table, tanstack

## 简介

A world-class, spreadsheet-style data table for React built on TanStack Table v8 — editable cells, formulas, rich column types, borders/formatting, find & replace, shareable views, and a build-your-own blank sheet.
