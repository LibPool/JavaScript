# cortico-world-zcode

> 标签: cortico, cortico-world

## 简介

该插件可以集成ZCode：让Coopanion可以报告ZCode中的任务进展,并把对话中的复杂任务委派给ZCode执行

## 官网

- npm 页面：https://www.npmjs.com/package/cortico-world-zcode

## 历史版本号

- 当前版本：0.2.0

- 0.0.0-stage
- 0.1.0
- 0.2.0

## 获取地址

- npm 安装：`npm install cortico-world-zcode`
- npm registry：https://registry.npmjs.org/cortico-world-zcode
- Node 要求：>=22
