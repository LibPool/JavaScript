# @consenttheater/playbill

> 标签: adtech, browser-fingerprinting, compliance, consent, cookie-database, cookies, data-protection, gdpr, privacy, trackers, tracking-database

## 简介

An open-source, tiered knowledge base of GDPR-relevant web trackers (cookies, domains, companies) with pure-function matching helpers. Each entry is tagged with the consent burden it creates under EU/GDPR rules — no verdicts, no risk scores. Standalone li
