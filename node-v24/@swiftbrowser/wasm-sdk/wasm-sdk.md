# @swiftbrowser/wasm-sdk

> 标签: JavaScript

## 简介

The Swift SDK for WebAssembly's base, for the Swift compiler built as WebAssembly (@swiftbrowser/wasm-compiler): the WASI sysroot, clang's headers and the Swift standard library (Swift 6.4.0, wasm32-unknown-wasip1).
