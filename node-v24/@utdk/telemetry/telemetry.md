# @utdk/telemetry

> 标签: logs, metrics, otlp, spans, telemetry, utdk

## 简介

Shared telemetry-export contract for UTDK observability providers: one export operation over the OTLP/HTTP JSON encoding for spans, logs, and metrics, with aprovan.* attribution helpers and a zero-dependency SDK
