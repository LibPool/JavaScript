# dsh-plugin-usage-panel

> 标签: deepseek, dsh-plugin, harness, panel, quota, usage

## 简介

A usage panel for provider plans: shows how much of each quota window is left (GLM Coding Plan today) as a compact chip next to the model selector, with a detail popover.
