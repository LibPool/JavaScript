# @regixo/connectors

> 标签: bigquery, compliance, data-catalog, dbt, dora, gdpr, local-first, metadata, mysql, postgres, redshift, regixo, ropa, snowflake

## 简介

Per-source adapters (kinds: sql · saas · manual · dbt · script). test() + discover(), metadata only. Built-in: Postgres · MySQL · SQL Server · Redshift · Snowflake · BigQuery · Stripe · dbt · CSV, plus agent-authored (BYOC) script connectors.
