# @ultimatelemon-eu/mcp-http

> 标签: JavaScript

## 简介

Run an MCP server over stateless Streamable HTTP: /mcp, /healthz, a base path for proxies, the caller's own API key or a stateless OAuth sign-in, and errors that never leak a stack trace.
