# @hy-sde-org/dsh-tool-browser

> 标签: agent, browser, cdp, chrome, deepseek, dsh-plugin, harness

## 简介

Model-facing browser tool (open/close/run over launch, CDP-attach and relay backends, ARIA-snapshot + screenshot observations) for DeepSeek Harness — a standalone plugin with no upstream harness changes required.
