# @hy-sde-org/dsh-git

> 标签: agent, commit, deepseek, dsh-plugin, git, harness, review, worktree

## 简介

Agentic git plumbing for DeepSeek Harness: the host ctx.git service (diff capture/parsing, hunk staging, commit/push/log over the subprocess seam) plus the vcs/repo-lock/worktree/conventional layers backing the commit, review, and worktree tools in @hy-sd
