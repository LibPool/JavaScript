# @hy-sde-org/dsh-tool-subagent-report

> 标签: agent, continuable, decision, deepseek, dsh-plugin, harness, report, subagent

## 简介

The child-scoped report tool for continuable in-process subagents on DeepSeek Harness: installs `report` plus its usage guidance into every continuable child scope, so findings reach the parent before the child finishes.
