# @hy-sde-org/dsh-fs-archive

> 标签: 7z, agent, archive, arj, asar, cab, cpio, deb, deepseek, dsh-plugin, harness, iso, rar, rpm, tar, zip

## 简介

Pure-TS multi-format archive engine (zip/tar/tar.gz/rar/7z/iso/deb/rpm/cpio/cab/arj/asar + codecs), ported from @oh-my-pi/pi-utils (MIT), as a standalone npm package.
