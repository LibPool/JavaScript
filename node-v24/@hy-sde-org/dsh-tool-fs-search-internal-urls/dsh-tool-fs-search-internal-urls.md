# @hy-sde-org/dsh-tool-fs-search-internal-urls

> 标签: agent, conflict, deepseek, dsh-plugin, glob, grep, harness, internal-urls

## 简介

Agent-scope shadow of the DeepSeek Harness glob/grep discovery tools that also searches conflict://, pr://, issue:// resources through ctx.internalUrls — the search half of the internal-URL routing surface for stock harness releases.
