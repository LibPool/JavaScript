# @mrdoge/node

> 标签: betting, mrdoge, odds, realtime, sdk, sports, websocket

## 简介

Mr. Doge Node SDK — server-side WebSocket + HTTP client. Authenticate with an `sk_live_...` API key and stream live sports data.
