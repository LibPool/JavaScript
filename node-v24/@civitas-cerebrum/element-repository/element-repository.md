# @civitas-cerebrum/element-repository

> 标签: automation, clean-code, json-repository, locators, page-object-model, playwright, selectors, test-automation

## 简介

A lightweight, robust package that decouples your UI selectors from your test code. By externalizing locators into a central JSON repository, you make your test automation framework cleaner, easier to maintain, and accessible to non-developers.
