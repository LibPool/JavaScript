# @codeages/app-observe-pusher

> 标签: JavaScript

## 简介

面向浏览器的日志与指标上报 SDK。事件先进入 FIFO 内存队列，再按数量和请求体大小限制批量上报；网络故障时自动退避重试，并在页面离开时使用 keepalive 请求尽力发送。
