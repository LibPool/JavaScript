# @wuyaos/pi-tool-gate

> 标签: context, deferred-loading, pi, pi-extension, pi-package, token, tool-gate

## 简介

按需工具开关 — 把重 schema 工具默认 inactive，提供 gate_tools loader（模型自取）和 /tool-gate 命令（用户手动管），降低每轮请求 tools[] 的固定 token 占用
