# @remixify/react-query

> 标签: component, ios, mobile, react, react native, react native component, react-query

## 简介

Remixify with React Query is a library for creating React Native components with integration with [React Query](https://tanstack.com/query/latest) for data management. If you prefer not to use React Query, you can use our sister library [@remixify/native]
