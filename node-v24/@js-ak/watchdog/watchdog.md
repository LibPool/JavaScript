# @js-ak/watchdog

> 标签: blocked, event loop lag, event-loop, event-loop-lag, freeze, lag, monitoring, napi, nodejs, watchdog

## 简介

Native watchdog for Node.js that detects event loop lag and freezes with near-zero overhead.
