> 标签: archive, backpressure, decrypt, deflate, encrypted-zip, esm, extract, inflate, node, password, password-protected, pkzip, readable, stream, streaming, typescript, unzip, zip, zip-password-stream, zipcrypto

## 简介

Streaming ZipCrypto unzip and zip for Node.js: one-pass parse of a Readable, entries as streams, write without buffering payloads, zero runtime dependencies.
