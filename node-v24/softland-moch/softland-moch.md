# softland-moch

> 标签: agent, ai, assistant, hermes, mobile, self-hosted, websocket

## 简介

softland-moch — one command to install and control Moch, your AI agent at home, in your pocket. Mobile backend fork of hermes-agent (MIT, Nous Research). The command you type is `moch`.
