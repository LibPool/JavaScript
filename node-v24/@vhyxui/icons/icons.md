# @vhyxui/icons

> 标签: design-tokens, icons, react, sprite, svg, vhyxara, vhyxui, web-components

## 简介

SVG icons for VhyxUI: React components, framework-free SVG strings, a <vhyx-icon> web component and a sprite — token-driven sizes, built-in motion, zero runtime dependencies
