# @spinekit/inventory

> 标签: arc, classytic, erp, flow, inventory, spine, stock, warehouse, wms

## 简介

Arc module for WMS/inventory composition — hosts the flow engine as a module export (arc.modules.inventory) and composes the host's warehouse resource fleet (nodes, locations, lots, waves, procurement, ...) through one seam. Kernel-agnostic shell: per-res
