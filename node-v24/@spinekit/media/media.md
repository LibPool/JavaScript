# @spinekit/media

> 标签: arc, classytic, media, multipart, presigned, spine, storage, upload

## 简介

Arc module for @classytic/media-kit — two-phase direct-to-storage uploads (start-write / complete-write), content-hash dedup handshake, multipart & resumable sessions, and maintenance schedules, as ONE composable Arc resource.
