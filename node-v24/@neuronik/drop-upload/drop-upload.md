# @neuronik/drop-upload

> 标签: cli, drop, image, mcp, neuronik, screenshot, upload

## 简介

Upload a local image (or the clipboard) to drop and print a shareable URL — the local helper for drop.neuronik.io.

## 官网

- 官网：https://drop.neuronik.io
- 源码仓库：git+https://github.com/neuronik-io/drop.git
- npm 页面：https://www.npmjs.com/package/@neuronik/drop-upload
