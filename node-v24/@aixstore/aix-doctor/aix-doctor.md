# @aixstore/aix-doctor

> 标签: aix, claude, marketplace, mcp, review

## 简介

Pre-submit MCP server for AiX marketplace sellers. Run the same review checks AiX runs server-side, locally, before you submit. Consent-gated mutations — every fix shows a diff and asks before writing.
