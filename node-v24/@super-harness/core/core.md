# @super-harness/core

> 标签: agent, agents, ai, harness, language-model, llm, mastra, multi-agent, orchestration, streaming, subagent, super-line, supervisor, tool-calling, typescript

## 简介

Transport-free harness session runtime for Super Harness: createHarness hosts a tree of Mastra Agents with delegation edges, full-fidelity streaming events, HITL suspension/approval gating, per-thread modes, and thread management — no super-line.
