# @ciromaciel/auth-extension

> 标签: browser-extension, chrome-extension, oauth, oauth2.1, pkce, rfc8252, rfc8414, rfc8707

## 简介

Standard OAuth 2.1 sign-in for browser extensions: discovery (RFC 8414), PKCE S256, resource-bound tokens (RFC 8707), in the same tab or in a window, with refresh rotation.
