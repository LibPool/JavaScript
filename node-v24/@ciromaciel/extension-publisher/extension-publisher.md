# @ciromaciel/extension-publisher

> 标签: JavaScript

## 简介

Publishes a browser extension to the Chrome Web Store and Microsoft Edge Add-ons, and a VS Code extension to the VS Code Marketplace and Open VSX, from the terminal or CI: credentials, package, upload, publish, status.
