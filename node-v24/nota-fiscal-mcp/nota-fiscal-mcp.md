# nota-fiscal-mcp

> 标签: brasil, fiscal, mcp, model-context-protocol, nfe, nfse, nota-fiscal

## 简介

Servidor MCP para emissao, consulta e cancelamento de NF-e e NFS-e no Brasil. Permite que agentes de IA (Claude, etc.) operem notas fiscais via um provedor (Focus NFe).
