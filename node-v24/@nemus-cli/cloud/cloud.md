# @nemus-cli/cloud

> 标签: agent, ci, cloud, iac, nemus, opentofu, terraform

## 简介

Optional cloud/IaC runners for Nemus — run a workspace + coding agent on your own infrastructure. Vendor-neutral and provider-pluggable. Not required for local Nemus.
