# @aggbond/draggable-window

> 标签: dom, drag, draggable, float, javascript, mobile, touch, ui, vanilla-js, window, 前端组件, 悬浮窗口, 拖拽

## 简介

一个轻量级的 JavaScript 可拖拽浮动窗口插件，支持移动端触摸和 PC 端鼠标操作，具有容器内拖拽和边界约束功能
