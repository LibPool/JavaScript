# @exitanty/mcp

> 标签: ai-agent, antidetect, antidetect-browser, browser-automation, claude, cursor, exitanty, ios, iphone, mcp, model-context-protocol, modelcontextprotocol, webdriver, webkit

## 简介

MCP server for driving the ExitAnty antidetect browser on iPhone over LAN (WebKit WebDriver). Works with Claude, Cursor, VS Code and any MCP client.
