# @dmc--98/blindfold-scim

> 标签: JavaScript

## 简介

SCIM 2.0 user provisioning + compliance export for Blindfold Auth. Wraps the engine admin API as the standard /Users, /Groups, and /ServiceProviderConfig endpoints; emits NDJSON / JSON compliance exports of principals, memberships, and audit events.
