# @dmc--98/blindfold-mobile

> 标签: JavaScript

## 简介

Mobile-friendly Blindfold Auth client: PKCE S256 helpers, pluggable secure token storage, login + rotating refresh + logout, ready to drop into React Native / Swift / Kotlin via HTTP.
