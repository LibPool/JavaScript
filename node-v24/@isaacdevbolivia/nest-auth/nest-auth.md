# @isaacdevbolivia/nest-auth

> 标签: auth, jwt, nestjs, permissions, rbac, refresh-token, roles, typeorm

## 简介

Autenticación reutilizable + RBAC (roles y permisos por sistema) para NestJS. Access token con claims de autorización + refresh tokens rotativos. Modo validación sin base de datos.
