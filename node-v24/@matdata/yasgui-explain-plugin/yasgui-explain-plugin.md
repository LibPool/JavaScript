# @matdata/yasgui-explain-plugin

> 标签: blazegraph, explain, graphdb, matgui, qlever, query-plan, rdf, sparql, sparql-algebra, stardog, yasgui, yasr

## 简介

Explain view for YASGUI and MatGUI: the SPARQL algebra of a query, and the execution plan with timings from QLever, GraphDB, Stardog, Blazegraph and Neptune
