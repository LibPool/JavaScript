# @consciousclouds/canvas-runtime

> 标签: JavaScript

## 简介

Conscious Clouds Canvas renderer — maps a CanvasDefinition onto consumer-supplied React components from the approved Component Registry. Fails closed on unknown/removed/unmapped components. Product-neutral (the component map is injected).
