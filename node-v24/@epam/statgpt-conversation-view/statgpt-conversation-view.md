# @epam/statgpt-conversation-view

> 标签: JavaScript

## 简介

This is StatGpt portals library, provides reusable React components, context, and utilities for managing and displaying advanced conversation views within the StatGPT portals. It includes logic for representing conversations, chating, handling stream-mess
