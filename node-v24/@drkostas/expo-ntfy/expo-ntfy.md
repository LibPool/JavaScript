# @drkostas/expo-ntfy

> 标签: android, expo, expo-config-plugin, foreground-service, notifications, ntfy, react-native

## 简介

Phone notifications from a self-hosted ntfy server in an Expo app, without Firebase: a config plugin that adds a native Android foreground service, plus the wire logic and the notification glue
