# @moksa/emdash-shop

> 标签: JavaScript

## 简介

EmDash 網站整合套件：商店頁面、Store API、外掛之間的匯流排、金流與物流回呼、Cookie 同意與追蹤，讓沙盒商店外掛（moksa-*）在網站上運作。
