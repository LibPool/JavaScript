# @moksa/plugin-commerce-notify

> 标签: JavaScript

## 简介

訂單通知信：訂單成立、繳費資訊、付款完成、出貨、到店、完成、取消、退款、發票開立與新訂單通知，含寄信紀錄與重寄，需搭配 @moksa/emdash-shop 網站整合套件。
