# @moksa/plugin-tappay

> 标签: JavaScript

## 简介

TapPay：以 prime 收款的信用卡、Apple Pay、Google Pay、Samsung Pay 與台灣電子錢包，含驗證過的付款通知與退款，需搭配 @moksa/emdash-shop 網站整合套件。
