# @moksa/commerce-pack-core

> 标签: ecommerce, emdash, emdash-plugin, moksa, taiwan

## 简介

Moksa 商店套件（自架版）基礎包：moksa-commerce-core、moksa-commerce-notify、moksa-commerce-documents（出貨單、揀貨單）、商店後台、moksa-mail 與網站整合 @moksa/emdash-shop，以 EmDash plugins: [] 在同一個程序內執行。
