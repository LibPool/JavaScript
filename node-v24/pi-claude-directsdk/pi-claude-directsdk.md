# pi-claude-directsdk

> 标签: claude, claude-code, extension, model-provider, pi, pi-package

## 简介

Claude as a Pi model provider through the unmodified Claude Code executable. Pi owns the transcript and tools; the CLI supplies subscription authentication as a model transport.
