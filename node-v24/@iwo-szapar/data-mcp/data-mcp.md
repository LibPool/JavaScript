# @iwo-szapar/data-mcp

> 标签: claude-code, crm, knowledge-management, mcp, memory, model-context-protocol, pocketbase, second-brain, supabase

## 简介

Unified data MCP server for Second Brain — markdown, Supabase, and PocketBase backends. 21 tools: knowledge, sessions, handoffs, links, brain health, setup, plus generic record_* CRUD for goals, tasks, contacts, CRM, blog, email, content calendar. Optiona
