# @liniukesi/dsh-voice-input

> 标签: deepseek-harness, dsh, plugin, push-to-talk, speech-to-text, voice

## 简介

Hold-Space push-to-talk voice input for the DeepSeek Harness Web Client: records the microphone while the Space bar is held and fills the composer draft with the transcript on release
