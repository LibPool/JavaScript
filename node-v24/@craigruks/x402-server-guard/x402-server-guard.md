# @craigruks/x402-server-guard

> 标签: agentic-payments, hardening, middleware, payments, replay-protection, security, web3, x402

## 简介

Server-side hardening middleware for x402 payment endpoints. Mitigations for settlement races, replay, cross-resource substitution, and cache leakage. Not a security guarantee.
