# @cardananium/cardano-debug-mcp

> 标签: cardano, cbor, cddl, claude, debugger, decompiler, mcp, model-context-protocol, plutus, uplc

## 简介

MCP server for inspecting, validating and step-debugging Cardano transactions and Plutus scripts (cquisitor-lib + de-uplc engine + dehosk decompiler).
