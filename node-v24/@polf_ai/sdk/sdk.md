# @polf_ai/sdk

> 标签: api, clipping, clips, polf, reels, sdk, shorts, tiktok, video, webhooks

## 简介

SDK TypeScript oficial da API do Polf — vídeo longo → cortes verticais (Reels/TikTok/Shorts) com legenda PT-BR. Cliente tipado + webhooks.constructEvent (Stripe-style HMAC).
