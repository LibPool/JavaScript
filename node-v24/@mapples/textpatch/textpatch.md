# @mapples/textpatch

> 标签: JavaScript

## 简介

Unified-diff hunks for Mapples Source text (RFC-0001 A13): generate, apply exactly, 3-way merge, text hash. Shared by the Creator and the mapples CLI; mirrored by the server's Python applier.
