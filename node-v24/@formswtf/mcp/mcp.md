# @formswtf/mcp

> 标签: claude, forms, forms.wtf, mcp, model-context-protocol, web3

## 简介

Model Context Protocol server for forms.wtf: build, manage, and analyze Web3 forms from any MCP client (Claude Desktop, Cursor, etc.).
