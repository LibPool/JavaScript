# @deslop/coding-standards

> 标签: JavaScript

## 简介

A strict Vite+ lint preset, and three skills for Claude Code, Codex and OpenCode: `lint-companion` (the shapes to write first so the preset passes on the first run), `delivery` and `review`. `review` judges a diff against the repository's `CODING_STANDARD
