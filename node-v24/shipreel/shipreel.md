# shipreel

> 标签: announcement, changelog, cli, conventional-changelog, devrel, ffmpeg, github-action, github-actions, github-release, instagram-reels, keep-a-changelog, linkedin, marketing, mp4, open-source, playwright, release, release-notes, semantic-release, social-media, twitter, video, video-generator, youtube-shorts

Turn release notes and CHANGELOG.md into a short branded announcement video for X, LinkedIn, Instagram and YouTube Shorts. CLI, library and GitHub Action.
