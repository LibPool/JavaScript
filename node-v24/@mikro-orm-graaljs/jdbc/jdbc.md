# @mikro-orm-graaljs/jdbc

> 标签: JavaScript

## 简介

MikroORM JDBC driver for GraalVM-JS, bridging SQL execution to host-side JDBC via a Kysely dialect.

- npm 页面：https://www.npmjs.com/package/@mikro-orm-graaljs/jdbc
