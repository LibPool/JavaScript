# @geoclear/client

> 标签: address, api-client, geoclear, geocoding, hono, typescript

## 简介

Typed TypeScript client for GeoClear — address intelligence built for the agents that call it. 198M US locations, 15+ fields per call, MCP-native, optional per-decision USDC payment via x402 on Base.
