# @rhythmjs/queue

> 标签: background-jobs, bun, jobs, queue, redis, rhythm, worker

## 简介

Typed job queues for Rhythm on Bun: a queue module on the kernel with a typed job map, named processors, repeatable schedules, and lifecycle-managed workers — an in-memory engine by default, Bun's native redis client for distribution.
