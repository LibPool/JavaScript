# @fidacy/crabtrap

> 标签: JavaScript

## 简介

Observe-mode adapter that puts a neutral, portable, signed Fidacy verdict on top of Brex CrabTrap's local audit decisions. Non-blocking; never alters the CrabTrap flow.
