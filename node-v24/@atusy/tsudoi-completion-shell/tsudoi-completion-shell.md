# @atusy/tsudoi-completion-shell

> 标签: JavaScript

## 简介

Provides native fish, zsh, and xonsh candidates through `textDocument/completion`. Each handler keeps one shell completion process alive, so ordinary completion does not pay shell startup cost on every keystroke.
