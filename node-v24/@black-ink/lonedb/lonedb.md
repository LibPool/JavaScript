# @black-ink/lonedb

> 标签: JavaScript

## 简介

This is a simple database management library that is built ontop of localStorage with similar syntax **BSON** syntax. I was motivated with the need to store database tables on localStorage and also be able to perform a couple of operations like:  - Find
