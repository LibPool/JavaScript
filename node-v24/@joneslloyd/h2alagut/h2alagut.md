# @joneslloyd/h2alagut

> 标签: adapter, alagút, fetch, http2, proxy, tunnel

## 简介

H2alagút – A fetch adapter for Node.js that performs HTTP/2 requests with optional HTTP/1 proxy tunneling via HTTP CONNECT.
