# @revkeen/react

> 标签: JavaScript

## 简介

React cart hooks and headless display components (ProductGrid, ProductCard, PriceDisplay, BuyButton, CartButton) for selling RevKeen products from Framer, Lovable, v0, Bolt or any React app. Publishable-key browser SDK only.
