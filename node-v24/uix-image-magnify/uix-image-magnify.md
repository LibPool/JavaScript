# uix-image-magnify

> 标签: e-commerce, image-gallery, image-zoom, inner-zoom, lens, magnifier, magnify, product-gallery, react, side-by-side, swiper

## 简介

Responsive React product gallery with Swiper, featuring three image magnify modes (lens, side-by-side, inner) and configurable thumbnail positions.
