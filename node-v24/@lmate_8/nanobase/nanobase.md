# @lmate_8/nanobase

> 标签: database, json, nanobase

## 简介

NanoBase is a **minimal, file-based JSON database for Node.js and TypeScript**. 💾 It stores all data in a JSON file and provides simple, yet powerful CRUD operations. Perfect for small projects, prototypes, or learning purposes. 🚀
