# @kota.tomi/aws-cdk-npm-test

> 标签: aws

## 简介

You should explore the contents of this project. It demonstrates a CDK Construct Library that includes a construct (`AwsCdkNpmTest`) which contains an Amazon SQS queue that is subscribed to an Amazon SNS topic.
