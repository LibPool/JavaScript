# dsh-plugin-refyard

> 标签: deepseek-harness, dsh-plugin, git, git-workbench, refyard

## 简介

The Refyard Git workbench as a DeepSeek Harness panel: history, changes, diffs, commits, branches and stashes for the repository the current session is working in.
