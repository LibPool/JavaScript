# weimo-ui-core

> 标签: JavaScript

## 简介

一套以玻璃拟态（glassmorphism）为设计语言的 React 基础组件库：会随背景明暗自适应的磨砂材质、shadcn/ui 兼容的语义 token、内置可达性的交互原语，帮你把应用界面做出「精致工具」的质感。
