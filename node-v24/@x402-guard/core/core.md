# @x402-guard/core

> 标签: ai-agents, budget, hedera, payments, policy, spending-limit, x402

## 简介

Pure spending-policy engine for x402 AI agents: persistent SQLite ledger, rolling-window budgets (global/origin/recipient), allowlists, quote-sanity, loop detection, rate limits. No network, no chain.
