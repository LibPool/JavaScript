# hygienex-edge

> 标签: amc, cctv, docker, edge-agent, hygienex, kitchen-hygiene

## 简介

One-command installer for the Hygienex edge agent (AMC kitchen-hygiene programme): checks Docker, writes the config, pulls the agent image and starts it on the restaurant's box.
