# @tooark/code

> 标签: code-editor, codemirror, custom-elements, design-system, javascript, json, tailwindcss, tooark, web-components, yaml

## 简介

Tooark Code — a code editor (`<ark-code-editor>`) based on CodeMirror 6 (supporting JSON, JavaScript, and YAML), featuring code completion, formatting, and token-based theming
