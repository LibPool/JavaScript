# @pome-sh/sandbox-domains

> 标签: agent-testing, digital-twin, evaluation, grading, pome, runtime

## 简介

Pome's twin domain layer — the in-process runtime a bound check reads: each digital twin's domain object, its SQLite opener, its seed parser and its declared check vocabulary. Runtime, not server: no Hono app, no routes, no MCP tool table.
