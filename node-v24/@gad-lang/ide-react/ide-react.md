# @gad-lang/ide-react

> 标签: codemirror, debugger, editor, gad, ide, react

## 简介

Reusable React IDE component for the Gad language: file tree, multi-pane editor, run/format/doc and a stepping debugger. Backend-agnostic — drive it with any IdeApi implementation (HTTP `gad ide` server, or a fully in-browser WASM + LocalStorage backend).
