# @emilia-protocol/openai-guard

> 标签: agent-safety, ai-agent, authorization, emilia-protocol, function-calling, grok, guardrails, human-in-the-loop, openai, tool-calling, xai

## 简介

Guard OpenAI-compatible tool calls (OpenAI, xAI Grok, Together, …) with EMILIA Protocol — block irreversible agent actions until a named human signs off.
