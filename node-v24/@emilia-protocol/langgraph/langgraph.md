# @emilia-protocol/langgraph

> 标签: agent-inbox, ai-agent, authorization, emilia-protocol, exact-action, human-in-the-loop, langgraph

## 简介

Bind LangGraph Agent Inbox human responses to exact, one-time EMILIA authority. Accept uses the frozen interrupt, edit requires fresh authority for the edited action, and response or ignore never authorize tool execution.
