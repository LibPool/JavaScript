# @lll9p/pi-better-compaction

> 标签: codex, compaction, openai, pi-extension, pi-package, responses

## 简介

Better compaction for pi: native /responses/compact replay for OpenAI Responses APIs, plus a configurable compaction model driving pi's native summarization everywhere else.
