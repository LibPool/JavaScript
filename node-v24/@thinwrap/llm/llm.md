# @thinwrap/llm

> 标签: ai, anthropic, bring-your-own-fetch, chat-completions, claude, embeddings, gateway, gpt, lightweight, llm, openai, stateless, zero-dependency

## 简介

Unified, zero-dependency TypeScript facade over LLM chat-completion (and embeddings) providers. Stateless, BYO fetch, no vendor SDKs.
