# @phukon/shush

> 标签: suppress, utility, warnings

## 简介

A lightweight utility for Node.js projects to selectively suppress unwanted runtime warnings originating from dependencies or older code. This is particularly useful for dealing with "punnycode is deprecated" or similar warnings that you cannot fix direct
