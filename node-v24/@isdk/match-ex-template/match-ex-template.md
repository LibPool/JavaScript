# @isdk/match-ex-template

> 标签: interpolation, isdk, match-ex, plugin, template

## 简介

Template interpolation plugin for @isdk/match-ex, backed by @isdk/template-engines. Importing it registers StringTemplate into the engine, so {{placeholder}} expectations interpolate out of the box.
