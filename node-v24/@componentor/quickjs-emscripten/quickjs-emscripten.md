# @componentor/quickjs-emscripten

> 标签: emscripten, eval, interpreter, quickjs, runtime, safe, vm, wasm

## 简介

Javascript/Typescript bindings for QuickJS, a modern Javascript interpreter, compiled to WebAssembly.
