# @agent-sh/harness-bash

> 标签: agent, ai, bash, bedrock, exec, llm, openai, sandbox, shell, tool-use

## 简介

Bash tool for AI agent harnesses — autonomous shell execution with pluggable executor, permission hook, cwd-carry, inactivity timeout, and background job support
