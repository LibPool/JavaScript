# @ahmadastic/froam

> 标签: design-tool, figma-like, froam, no-code, page-editor, react, static-site, visual-editor, vite-plugin

## 简介

A visual editor for a running site or static HTML folder. Save supported revisions as a versioned design, generated override CSS, and a small content runtime.
