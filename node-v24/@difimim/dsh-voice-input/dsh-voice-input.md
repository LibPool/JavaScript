# @difimim/dsh-voice-input

> 标签: cordis, deepseek-harness, dsh, plugin, speech-to-text, voice, webspeech

## 简介

DeepSeek Harness 语音输入插件：在输入框加入麦克风按钮，用浏览器 Web Speech API 把语音实时转成文字填入输入框。
