# @br8n/mcp

> 标签: ai-memory, br8n, knowledge-base, markdown, mcp, model-context-protocol, owned-memory, portable-memory

## 简介

br8n — owned, portable working memory. A plain-files brain template and a tiny MCP server that lets any model read it. Files, not a login.
