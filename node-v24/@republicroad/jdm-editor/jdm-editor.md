# @republicroad/jdm-editor

> 标签: JavaScript

## 简介

React components for authoring [JDM](https://gorules.io/docs) (JSON Decision Model) documents: a decision graph canvas, decision tables, expression and function editors, a simulator, and a custom-function spreadsheet — themed end-to-end with shadcn/ReUI +
