# @fractal_cloud/offer-contracts

> 标签: JavaScript

## 简介

Offer parameter contracts 2.0: evaluate component parameters against an Offer's contract, validate declarations, compute the contract digest. One semantics with the Java, Go and C# implementations, pinned by the aria-spec conformance suite.
