# @dzhechkov/cloudru-hub

> 标签: claude, claude-code, cloud-ru, cloudru, deploy, evolution, mcp, unofficial, vps

## 简介

Unofficial Cloud.ru Evolution launcher with a pinned cloud-write-blocking MCP proxy for Codex, Hermes, OpenCode and Pi, Claude Code permissions, and skill dialect compiler. Engine binary resolved at runtime, never bundled. NOT affiliated with Cloud.ru.
