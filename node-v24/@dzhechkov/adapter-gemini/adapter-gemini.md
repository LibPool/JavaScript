# @dzhechkov/adapter-gemini

> 标签: adapter, agent-skills, gemini, gemini-cli, gemini-code-assist, gemini.md, harness

## 简介

GEMINI.md platform adapter - flattens canonical skills into a single root-level GEMINI.md (plain Markdown, no frontmatter, hierarchical; read by Gemini CLI + Code Assist; intentionally lossy, merge-not-overwrite).
