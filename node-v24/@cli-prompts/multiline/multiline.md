# @cli-prompts/multiline

> 标签: ansi, bracketed-paste, chalk, cli, cli-framework, cli-input, cli-toolkit, command-line, enquirer, input, inquirer, interactive, multiline, multiline-input, nodejs, prompt, terminal, text-editor, tty

## 简介

A production-ready multiline text prompt for Node.js CLIs. Flicker-free, smooth, and supports full cursor movement with rich ANSI rendering. Built to fill the gap the other great libraries never covered.
