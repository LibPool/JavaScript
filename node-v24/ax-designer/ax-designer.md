# ax-designer

> 标签: agent-experience, agents, audit, ax, cli, mcp, model-context-protocol

## 简介

Audita la Agent Experience (AX) de un repositorio y genera el código (CLI de verbos estrechos y MCP server) para que un agente lo opere con menos tokens, menos rondas y menos errores.
