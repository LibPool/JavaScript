# @kindgi/adapter-model-bedrock

> 标签: JavaScript

## 简介

Amazon Bedrock ModelProvider for @kindgi/capabilities: Claude, Nova, Llama, Mistral and OpenAI's models on Bedrock's Converse API, by the runtime's AWS identity or a Bedrock API key.
