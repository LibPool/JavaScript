# @robotical/jumping-game

> 标签: JavaScript

## 简介

A picture-led introduction to press-event programs for children aged 4–7. The interface follows Bubble Popper, with seven discovery missions followed by the original ten-star jumping goal. See [the flow and validation notes](docs/learning-redesign.md).
