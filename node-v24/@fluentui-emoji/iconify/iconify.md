# @fluentui-emoji/iconify

> 标签: emoji, fluentui, fluentui-emoji, iconify, icons, svg

## 简介

Fluent UI Emoji as Iconify JSON collections — works with unplugin-icons, the Tailwind Iconify plugin, and every Iconify component.
