# @mnemosyne_os/agent-transcripts

> 标签: agent, antigravity, claude-code, connector, mnemosyne, observability, openclaw, transcript

## 简介

Read what coding agents already write on disk: a declarative connector format, an interpreter that never evaluates it, and the liveness rules that keep "last seen" from becoming "working".
