# homebridge-ledvance-native

> 标签: homebridge-plugin, homekit, ledvance, smartplus, supports-hap, sylvania, tuya

## 简介

Homebridge plugin for LEDVANCE SMART+ WiFi and Sylvania devices, with app login, automatic discovery and local control with cloud fallback.
