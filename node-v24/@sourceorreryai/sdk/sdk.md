# @sourceorreryai/sdk

> 标签: dotenv, keyring, napi-rs, secrets, security, vault

## 简介

Read secrets from SourceOrrery vaults, the encrypted replacement for .env files; read-only, with vaults created and secrets stored by the sourceorrery CLI
