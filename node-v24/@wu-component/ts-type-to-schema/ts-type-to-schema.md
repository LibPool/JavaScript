# @wu-component/ts-type-to-schema

> 标签: JavaScript

## 简介

基于 TypeScript AST 解析，实现 CLI 与浏览器双端兼容的 TypeScript 类型到 JSON Schema 的转换工具，支持接口、枚举、数组、基础类型等多种 TypeScript 类型结构转换。
