# capguru

> 标签: aws-waf, capguru, captcha, funcaptcha, geetest, hcaptcha, puppeteer, recaptcha, solver

## 简介

Automatic captcha solving for Puppeteer via the Cap.Guru service: reCAPTCHA v2, hCaptcha, GeeTest, FunCaptcha, TikTok, AWS WAF, Yandex SmartCaptcha
