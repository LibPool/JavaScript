# @bandura/cli

> 标签: aether, api, api-testing, bandura, ci, cli, graphql, grpc, http, openapi, postman, websocket

## 简介

Headless runner for Bandura .aether API flows - run API tests in your terminal or CI. No app, account, or backend required.
