# @fyeeme/pi-hooks

> 标签: automation, claude-code, hooks, lifecycle, pi, pi-package, serena

## 简介

Claude Code-compatible hooks runner for pi. Reads hooks config (priority: ~/.pi/agent/hook.json, then project .pi/hook.json) and maps SessionStart, PreToolUse, and Stop events to pi lifecycle events.
