# @fyeeme/pi-ask-user

> 标签: ask, ask-user, clarification, extension, interactive, oh-my-pi, pi, pi-package

## 简介

oh-my-pi's `ask` tool migrated to a pi extension — tabbed multi-question dialog with a Submit review page, inactivity countdown, RPC degradation, and headless hiding.
