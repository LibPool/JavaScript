# @fyeeme/pi-goal

> 标签: agent-loop, autonomous, budget, extension, goal, goal-mode, pi, pi-package

## 简介

Goal mode for pi — one persistent autonomous objective looped until verified success: goal tool (create/get/complete/impossible/resume/drop), token/time budget accounting with budget-limit steering, automatic continuation turns, /goal and /guided-goal com
