# @sdcorejs/nestjs

> 标签: async-local-storage, audit, context, framework, library, multi-tenancy, nestjs, permission, typeorm

## 简介

Production NestJS and TypeORM building blocks for fail-closed tenancy, trusted identity, authorization, cache, HTTP, files, audit history, jobs, validation, and i18n.
