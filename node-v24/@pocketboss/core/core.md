# @pocketboss/core

> 标签: JavaScript

## 简介

Framework-neutral TypeScript client for PocketBoss Bridge protocol v1. It provides the vanilla JavaScript entry point, typed bridge requests, browser file inputs, and the shared REST client and custom element for order comments.
