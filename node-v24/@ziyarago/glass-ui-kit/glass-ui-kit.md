> 标签: component-library, dark-mode, design-system, glassmorphism, i18n, tailwindcss, typescript, ui-kit, vue, vue3

## 简介

A modern glassmorphism-inspired Vue 3 + TypeScript component library — ~139 components across 12 groups, two palettes, dark mode and 6 locales.
