# @bsvkey/x402-paywall

> 标签: 402, ai-agents, api-monetization, bsv, micropayments, middleware, pay-per-call, paywall, reverse-proxy, x402

## 简介

Put a BSV (x402) paywall in front of any HTTP API — charge per call, no accounts. Middleware or reverse proxy. Settlement-agnostic.
