# @e-volv/openfeature-web

> 标签: e-volv, feature-flags, launch, openfeature

## 简介

OpenFeature web provider for e-volv Launch — evaluates feature flags in the browser through @e-volv/logs: evaluated values for the identified context, cached in localStorage, refreshed on focus, with exposures.
