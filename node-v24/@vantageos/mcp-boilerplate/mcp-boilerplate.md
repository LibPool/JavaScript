# @vantageos/mcp-boilerplate

> 标签: boilerplate, mcp, model-context-protocol, starter

## 简介

Clonable MCP server skeleton: dual-transport bootstrap (stdio + Streamable HTTP, stateless) on the official @modelcontextprotocol/sdk, ready to extend with protocol-kit, auth, tenant and UI layers.
