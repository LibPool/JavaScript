# @renderfy/preview

> 标签: cli, html-to-image, html-to-pdf, live-reload, preview, renderfy, tailwind, template

## 简介

Local live-preview for Renderfy templates. Edit an HTML/Tailwind file in your editor, see it render against renderfy.io in your browser on save.

## 官网

- 官网：https://renderfy.io
- 源码仓库：git+https://github.com/pintechlabs-dev/renderfy.io.git
- npm 页面：https://www.npmjs.com/package/@renderfy/preview
