# @enterpret/zendesk-mcp-server

> 标签: ai, claude, help-center, mcp, modelcontextprotocol, zendesk

## 简介

MCP server for Zendesk Support & Help Center APIs. Forked from @fruggr/zendesk-mcp-server; adds ZENDESK_OAUTH_BEARER env mode for headless broker-supplied OAuth tokens.
