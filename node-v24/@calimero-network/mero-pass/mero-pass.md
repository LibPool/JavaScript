# @calimero-network/mero-pass

> 标签: calimero, e2ee, mero, mero-pass, secrets, vault

## 简介

Mero Pass vault crypto and session logic for browsers and Node: open, read and write an end-to-end encrypted Mero Pass vault, as the app or as an agent (mero-bot).
