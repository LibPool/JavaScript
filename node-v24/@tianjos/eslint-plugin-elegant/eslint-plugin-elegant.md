# @tianjos/eslint-plugin-elegant

> 标签: code-quality, eslint, eslint-plugin, linting, nestjs, typescript

## 简介

Opinionated ESLint rules for elegant, behavior-rich TypeScript: honest types, encapsulated state, small uncoupled classes, guard-clause flow, and structured logging. Built for NestJS and DDD codebases.
