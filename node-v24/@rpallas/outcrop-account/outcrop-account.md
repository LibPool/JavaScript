# @rpallas/outcrop-account

> 标签: account, aws, baseline, cdk, oidc, platform, stacksets

## 简介

Account and organisation baseline constructs for outcrop: GitHub OIDC deploy roles, DNS and certificates, alerting, event bus, KMS, shared parameters and secrets, budgets, security services, networking and StackSet wrappers.
