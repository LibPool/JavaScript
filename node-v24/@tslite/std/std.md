# @tslite/std

> 标签: etl, functional, json, mapper, operators, ramda, std, stdlib, typescript

## 简介

TSLite std — the typed functional standard library (FP, no OO): operator signatures as native TSL types for the checker Env, plus the matching runtime for the interpreter. The typed stdlib for JSON mappers.
