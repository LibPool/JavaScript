# @tslite/json-schema

> 标签: ast, json-schema, openapi, schema, serialization, type-bridge

## 简介

TSLite json-schema — the two-way bridge between TSLite types and JSON Schema 2020-12 (and draft-07, OpenAPI 3.0): toJsonSchema / fromJsonSchema
