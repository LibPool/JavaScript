# @tslite/language-service

> 标签: codemirror, completion, diagnostics, editor, embedded-languages, language-service, lsp, monaco

## 简介

The editor contract: an LSP-shaped, offset-based language service interface plus embedded-region segmenters, position utilities and test doubles. Zero dependencies, zero language coupling.
