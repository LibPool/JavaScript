# vitest-supermock

> 标签: mock, mocking, testing, vi.mock, vite-plugin, vitest, vitest-mock-extended

## 简介

Mock a module in Vitest from a regular import: const routerMock = supermock(router). A Vite plugin hoists the vi.mock call for you.
