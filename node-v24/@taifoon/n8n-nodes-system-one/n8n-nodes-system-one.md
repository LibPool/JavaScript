# @taifoon/n8n-nodes-system-one

> 标签: classification, confidence, grading, jev, n8n, n8n-community-node-package, probability, structured-output, system-one, typesafe

## 简介

System One for n8n: ask yes/no, pick-one and score questions about any item and get every answer with its probabilities. TypeSafe hosts it by default; any host serving the System One API works.
