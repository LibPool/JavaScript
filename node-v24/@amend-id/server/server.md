# @amend-id/server

> 标签: amend, amend-id, backchannel-logout, oauth, oidc, pkce, session, sign-in

## 简介

Sign in with Amend iD, on your server — verify Amend iD's tokens against its published keys, keep people signed in with a sealed HttpOnly cookie, refresh properly, hear back-channel logout. No dependencies.
