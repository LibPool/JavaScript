# opencode-harness-kit

> 标签: agent, context-management, harness, opencode, opencode-plugin, reasoning-effort

## 简介

Harness kit for OpenCode: capability profiles, a fleet of job lanes with one free model each, role-based reasoning effort, context pruning, and measured baselines.
