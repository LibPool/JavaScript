# @ferrow/rate-limit-redis

> 标签: distributed, lua, rate-limit, redis, sliding-window, throttle, typescript

## 简介

Distributed sliding-window rate limiter over a pluggable minimal eval() client interface — works with any redis client, no dependency required. Ships an atomic Lua script plus an in-memory fallback for tests/dev.
