# @ferrow/jsonrpc-ts

> 标签: ai-agents, json-rpc, jsonrpc, llm, mcp, protocol, rpc, stdio

## 简介

Spec-correct JSON-RPC 2.0 framing — request/response/notification builders, validating parser, batch support, typed dispatch, id correlation. Transport-agnostic, MCP-relevant. Zero runtime dependencies.
