# @ferrow/json-schema-from-sample

> 标签: devtools, draft-07, json, json-schema, schema-inference, validation

## 简介

Infer a draft-07 JSON Schema subset from sample JSON data — types, nested structures, nullable/required/enum inference across multiple samples, format detection. Zero runtime dependencies.
