# @ferrow/ml-data-pipeline

> 标签: data-preprocessing, normalization, one-hot-encoding, tabular-data, train-test-split, typescript

## 简介

Lightweight tabular data prep, no tensor deps: column typing, normalize/standardize with saved fit params, one-hot encoding, seeded shuffle, train/test split, simple imputation, and a chainable Pipeline that serializes its fitted params.
