# @veilio-inc/cli

> 标签: ai, anonymizer, cli, llm, pre-commit, privacy, secret-scanning, veilio

## 简介

Anonymize identifiers and redact credentials in source code before it reaches an LLM — from the terminal, a pipe, or a pre-commit hook.
