# @allratestoday/exchange-plugins

> 标签: allratestoday, central-bank, currency, ecb, edge-rates-server, exchange-rate, exchange-rate-plugins, exchange-rates, forex, fx, rate-plugins, reference-rate

## 简介

Exchange-rate source plugins for AllRatesToday: live mid-market rates, the daily 16:00 London reference rate and official central-bank tables, behind one plugin interface with ordered fallback. Includes a drop-in provider for edge-rates-server.
