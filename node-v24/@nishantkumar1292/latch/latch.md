# @nishantkumar1292/latch

> 标签: ai, claude, code-review, coding-agents, github-actions, merge-gate, pull-request

## 简介

The independent merge gate for the agent era — a bounded review⇄fix loop that converges any pull request to mergeable, then stops. A human always merges.
