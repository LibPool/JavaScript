# @coder/ai-sdk-provider

> 标签: ai, ai-gateway, ai-sdk, aibridge, anthropic, coder, llm, openai, provider, vercel-ai-sdk

## 简介

Vercel AI SDK provider for Coder AI Gateway. Point the AI SDK at your Coder deployment with a Coder API token and use any model your deployment proxies — across AI Gateway's OpenAI- and Anthropic-compatible surfaces.
