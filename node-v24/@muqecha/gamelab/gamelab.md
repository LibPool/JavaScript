# @muqecha/gamelab

> 标签: game, godot, html5, mcp, performance, phaser, playwright, profiling, testing, threejs, unity, webgl

## 简介

Harness-agnostic test lab for HTML5/WebGL games: serve builds or proxy dev servers with an instrumented hook, drive a Playwright Chromium (device emulation, touch, gamepad, throttling, traces), run scripted scenarios and export Playwright CI tests. Expose
