# @chirag127/keyless-pollinations

> 标签: ai, chat, design-system, framework-agnostic, keyless, llm, no-key, openai-compatible, pollinations

## 简介

Keyless Pollinations text client. OpenAI-compatible, no API key. chat(messages, opts) -> string against https://text.pollinations.ai/openai. Framework-agnostic (Node + browser via global fetch).
