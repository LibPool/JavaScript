# @chirag127/data-firebase

> 标签: data-adapter, design-system, firebase, firestore, framework-agnostic, oriz, user-data

## 简介

Thin framework-agnostic Firebase Firestore adapter for small user-data. Inits from PUBLIC_FIREBASE_* env, exposes tiny getDoc/setDoc/onSnapshot wrappers. Never hardcodes secrets — config read from env or passed explicitly.
