# @chirag127/oz-file

> 标签: design-system, download, drag-drop, dropzone, file, filereader, format-bytes, framework-agnostic, print-to-pdf

## 简介

Framework-agnostic browser file helpers: FileReader promises, Blob download, drag-drop wiring, scoped print-to-PDF, byte formatting. Zero dependencies — works in Astro, Next, Vue, Svelte, or plain HTML.
