# @chirag127/oz-tokens-base

> 标签: a11y, contract, css-variables, custom-properties, design-system, design-tokens, framework-agnostic

## 简介

The --oz-* CSS custom-property CONTRACT: color roles (bg/fg/accent/muted/border/surface), space scale, radii, font-family slots, motion durations. Ships sane defaults + a11y focus ring. Each site imports this then OVERRIDES the props with its own bespoke
