# @zerogpu/worker

> 标签: docker, edge-inference, electron, inference, macos, on-device, onnx, slm, worker, zerogpu

## 简介

ZeroGPU Worker — join the ZeroGPU network from a Docker container or any Node.js host (servers, macOS desktop apps, developer laptops), and serve inference locally.
