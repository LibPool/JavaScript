# @feezal/feezal-theme-eink

> 标签: dashboard, e-ink, epaper, feezal, feezal-theme

## 简介

E-ink theme for feezal dashboards — paper-white background, pure black ink, mono type stack, no animation. Companion to the eink-* element family.
