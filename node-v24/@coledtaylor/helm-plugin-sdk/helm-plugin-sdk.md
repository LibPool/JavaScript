# @coledtaylor/helm-plugin-sdk

> 标签: claude-code, helm-plugin, plugin, sdk

## 简介

Types, the manifest schema and helpers for building Helm plugins. The runtime - the window.helm bridge, theme tokens and primitives stylesheet - comes from the running Helm.
