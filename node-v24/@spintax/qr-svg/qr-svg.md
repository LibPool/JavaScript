# @spintax/qr-svg

> 标签: csp, qr, qr-code, qr-generator, qrcode, short-links, ssr, static-site, svg, vanilla-js, zero-dependencies

## 简介

A QR code as a minimal SVG string: one rect and one path on integer coordinates, crisp at any size, safe under a strict CSP. Zero dependencies; Node and the browser.
