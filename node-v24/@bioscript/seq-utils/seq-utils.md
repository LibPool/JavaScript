# @bioscript/seq-utils

> 标签: bioinformatics, complement, debruijn-graph, dna, kmers, minimizers, reverse-complement, rna, rolling-hash, sequence, super-kmers, syncmers, utilities

## 简介

Core sequence manipulation utilities for DNA/RNA operations: conversion, complement, reverse complement, k-mer analysis, minimizers, and De Bruijn graphs.
