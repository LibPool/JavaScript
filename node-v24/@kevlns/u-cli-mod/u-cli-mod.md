# @kevlns/u-cli-mod

> 标签: cli, pipeline, unity, unity-editor, windows

## 简介

u-cli-mod: pin exact Unity Editor version routes and install the adapted com.unity.pipeline package for Unity 2022 (Windows-first). Downloads Unity assets at runtime into the user cache; the package itself contains no Unity binaries or package source. Not
