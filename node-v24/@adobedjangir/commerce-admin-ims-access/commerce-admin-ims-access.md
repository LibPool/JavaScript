# @adobedjangir/commerce-admin-ims-access

> 标签: access-control, adobe-io, aio, app-builder, commerce-admin, ims, rbac

## 简介

Email-based RBAC add-on for @adobedjangir/commerce-admin-management. Assign admin/editor/viewer roles by email via a UI (super-admins in .env), with server-side enforcement of config saves, schema edits, audit reverts, and snapshot ops.
