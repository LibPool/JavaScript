# @saga-a2ui/react-mcp-stack

> 标签: JavaScript

## 简介

The React and MCP Apps stack for SAGA A2UI: starts a view for an application's own catalog, and a FaithfulCard application from one validated definition, so an application installs one stack plus React and writes only its own decisions
