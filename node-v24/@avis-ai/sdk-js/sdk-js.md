# @avis-ai/sdk-js

> 标签: JavaScript

## 简介

Minimal, **framework-agnostic** JavaScript/TypeScript client for the **Avis AI** HTTP API. Use it anywhere you can run `fetch`: **Vue, Svelte, Angular, vanilla sites, Electron, Node 18+, Deno**, etc.
