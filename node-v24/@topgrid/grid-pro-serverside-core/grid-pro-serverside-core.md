# @topgrid/grid-pro-serverside-core

> 标签: data-table, datagrid, grid, headless, row-model, server-side, ssrm, table, tanstack-table

## 简介

Framework-neutral server-side row model core: block cache, SSRM controller, lazy-group tree cache, viewport row model, server pivot columns (no React/Vue; @tanstack/table-core type-only).
