# dsh-wechat-emoji

> 标签: dsh, dsh-plugin, emoji, emotion, vision, wechat

## 简介

让 DSH agent 识别微信/QQ 表情包与聊天截图并判断对方情绪（GLM-4V-Flash），暴露 wechat_emoji_analyze 工具。
