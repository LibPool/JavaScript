# @async/framework

> 标签: async, async-loader, cache, no-build, router, server-functions, signals, ssr, streaming, web-framework

## 简介

No-build Loader app runtime with browser and server entrypoints, signals, command events, route partials, cache split, SSR activation, and streaming boundaries.
