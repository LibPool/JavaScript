# @openatlas/sdk

> 标签: asr, hausa, igbo, llm, n-atlas, nigeria, text-to-speech, tts, yoruba

## 简介

TypeScript client for the hosted N-ATLaS models (Nigeria's sovereign LLM + Hausa/Yoruba/Igbo/Nigerian-English ASR). Non-commercial use only, per the N-ATLaS license.
