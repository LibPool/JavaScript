# @spaturzu/sdk

> 标签: Anthropic, Bedrock, Google, LLM, Mistral, OpenAI, attribution, cost, metering, monitoring

## 简介

Per-agent LLM cost attribution + budget enforcement + cross-provider fallback for Node.js. Wraps your provider client (OpenAI, Anthropic, Bedrock, Gemini, Mistral) and emits a metering row to the spaturzu gateway on every call, with frame-based agent attr
