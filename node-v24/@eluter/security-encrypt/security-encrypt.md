# @eluter/security-encrypt

> 标签: eluter, encryption, openpgp, pgp, responsible-disclosure, security, vulnerability

## 简介

CLI to encrypt vulnerability reports with PGP for security@eluter.com. Runs from anywhere via npx, no gpg required.
