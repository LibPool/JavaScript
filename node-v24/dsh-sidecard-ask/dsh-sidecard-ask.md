# dsh-sidecard-ask

> 标签: ask, deepseek-harness, dsh, dsh-plugin, selection, side-card, 侧边卡片, 划词, 选中追问

## 简介

DSH 划词追问（侧边卡片作答）：在聊天区与任务区选中文本就地追问，答案由独立子代理在侧边卡片里流式呈现，也可选择落回主对话。
