# @omnidim-ai/sdk

> 标签: omnidim, omnidimension, rest-api, sdk, typescript, voice-agent, voice-ai

## 简介

Official JavaScript and TypeScript SDK for the OmniDimension voice-AI REST API. Manage agents, dispatch calls, run bulk campaigns, knowledge bases, phone numbers, and simulations.
