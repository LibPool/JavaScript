# @svelte-safe-html/core

> 标签: html, lint, safe-html, sanitization, security, svelte, svelte3, svelte4, svelte5, xss

## 简介

A zero-dependency utility that detects unsafe HTML in Svelte components across versions 3, 4, and 5.
