# @ui-organized/pack-ui-organized

> 标签: design-system, design-tokens, dtcg, generator

## 简介

The UI Organized generator pack — brand palette, neutral preset, typescale, spacing/radius, and elevation generators that emit plain DTCG tokens. The default, optional pack for the Token Manager.
