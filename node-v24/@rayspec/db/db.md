# @rayspec/db

> 标签: JavaScript

## 简介

The tenant-scoped data layer. Request-path and run-core code only ever hold a **`TenantDb`** (obtained via `forTenant`) — the raw, unscoped database handle stays at the composition root. Postgres-backed, with tenant isolation as a construction-time guaran
