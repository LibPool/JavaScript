# @rayspec/adapter-pi

> 标签: JavaScript

## 简介

The Pi adapter. Runs the same neutral `AgentSpec` as the reference adapter onto the same neutral surface — central `dispatchTool`, real `ConvTurn`/`ConvPart` types, and a real per-step journal.
