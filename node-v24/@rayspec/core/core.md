# @rayspec/core

> 标签: JavaScript

## 简介

Kernel primitives shared by every RaySpec runtime and adapter: the **neutral `Backend` interface** that all agent-backend adapters implement, plus foundational building blocks such as bounded request bodies, the error-class hierarchy, and content hashing.
