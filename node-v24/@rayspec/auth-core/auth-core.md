# @rayspec/auth-core

> 标签: JavaScript

## 简介

HTTP-free authentication and authorization primitives: API-key HMAC, authorization checks, audit logging, and auth configuration. Unit-testable without a server; composed into the HTTP surface by `@rayspec/api-auth`.
