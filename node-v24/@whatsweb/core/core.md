# @whatsweb/core

> 标签: baileys, bot, esm, lid, multi-device, no-puppeteer, sdk, whatsapp, whatsapp-web

## 简介

A great-DX WhatsApp Web SDK for Node.js — no browser, no Puppeteer. Command router, media, groups, presence and per-user conversations, on the native Multi-Device protocol (Baileys 7).
