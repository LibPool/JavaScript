# @tomagranate/liquid-glass

> 标签: apple, displacement-map, effect, glass, liquid-glass, react, refraction, ui, webgl

## 简介

A framework-independent liquid-glass (Apple-style refraction) effect for the web, built on the SVG feDisplacementMap filter, with React bindings and a WebGL texture backend for canvas/video.
