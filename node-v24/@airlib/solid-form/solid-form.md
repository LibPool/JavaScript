# @airlib/solid-form

> 标签: airlib, anchor, form, reactive, solid, solidjs, typescript, validation, zod

## 简介

Reactive and declarative SolidJS form components built on AirLib. Typed forms, field validation, cross-field matching, and array fields with fine-grained reactivity.
