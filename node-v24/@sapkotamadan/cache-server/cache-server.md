# @sapkotamadan/cache-server

> 标签: API, automation, cache-server, content-analysis, data-mining, headless-browser, html-source, page-render, puppeteer, web-crawler, web-fetcher, web-page-extractor, web-scraping

## 简介

CacheServer is an efficient web page extractor that uses Puppeteer to launch a headless browser and fetch web page content.
