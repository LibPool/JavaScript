# @grid-is/spreadsheet-engine

> 标签: excel, google-sheets, headless, office, spreadsheet, xlsx

## 简介

The spreadsheet engine for agentic products. Load, calculate and edit Excel workbooks in Node or the browser, with Excel and Google Sheets formula compatibility.
