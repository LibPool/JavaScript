# @evanion/acl

> 标签: access-control, acl, authorization, matrix, permissions, policy, typescript

## 简介

A declarative, serializable access-control matrix authored once and evaluated locally on whatever JS runtime is running: a Node backend, a frontend SSR graph, a browser SPA, or a hybrid JS platform.
