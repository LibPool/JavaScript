# @netforge/template-racer

> 标签: ai-agents, browser-game, game-engine, game-template, gamedev, html5-game, kart-racer, mcp, multiplayer, net-forge, physics, racing, threejs, typescript

## 简介

Kart racer game template for Net Forge: harbour circuits with drift mini-turbos, boost pads, coins and laps at 60 Hz, with seat-filling bots (TORQUEBAY).
