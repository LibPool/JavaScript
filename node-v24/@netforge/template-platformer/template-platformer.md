# @netforge/template-platformer

> 标签: ai-agents, browser-game, game-engine, game-template, gamedev, html5-game, mcp, multiplayer, net-forge, physics, platformer, threejs, typescript

## 简介

Multiplayer platformer game template for Net Forge: races to the flag with coyote time, jump buffering, dashes, springs and moving platforms (SKYLEDGE).
