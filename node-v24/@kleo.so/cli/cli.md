# @kleo.so/cli

> 标签: cli, content, kleo, linkedin, mcp, model-context-protocol

## 简介

Kleo from your terminal — read your knowledge base, swipe file, templates, posts and agent memory, and delegate tasks to the Kleo agent. A thin MCP client over the Kleo MCP server.
