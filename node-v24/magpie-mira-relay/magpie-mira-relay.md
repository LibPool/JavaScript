# magpie-mira-relay

> 标签: magpie, mira, mirasim, opencode, opencode-plugin, provider, relay

## 简介

Provider plugin for Mirasim-compatible relay deployments: sign in with a base URL and an API key, and see each deployment's quota windows in magpie.
