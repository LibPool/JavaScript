# @filipebraida/eslint-config-adonis

> 标签: adonisjs, architecture, ast-grep, eslint, eslint-config, inertia, lint, react

## 简介

Lint for AdonisJS apps: architecture rules as ast-grep YAML and a UI preset (strict React, react-hooks, accessibility and design system). Every message says how to fix it.
