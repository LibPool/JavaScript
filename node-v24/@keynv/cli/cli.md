# @keynv/cli

> 标签: ai-safety, cli, keynv, mcp, secrets, secrets-management, vault

## 简介

Secrets vault CLI for teams and AI-assisted development — reference secrets by alias so the real values stay out of your code, shell history, and AI transcripts.
