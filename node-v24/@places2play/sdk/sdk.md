# @places2play/sdk

> 标签: api, graphql, maps, pickleball, places2, places2play, sdk

## 简介

Official Places2Play API client — typed, framework-agnostic access to the paid GraphQL API (server-side OAuth client-credentials + browser-safe domain-locked publishable keys), plus a thin embed-map loader.
