# @nfails/wabi-wit-gen

> 标签: bun, codegen, component-model, ffi, flutter, jni, native-abi, sdk, swift, wit

## 简介

WIT → SDKs (C#, Java/Android, Swift, Dart/Flutter, TypeScript/Bun) + core glue (Rust, Go, C#) over one stable native ABI. Runs as WebAssembly: no native install.
