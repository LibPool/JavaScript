# @iflow-mcp/namin-dafny-sketcher

> 标签: JavaScript

## 简介

This Dafny Sketcher MCP builds on the Dafny Sketcher CLI, and exposes certain CLI functionality to MCP clients such as Claude and Cursor. ChatGPT can also work through a [third-party adapter](https://github.com/SecretiveShell/MCP-actions-adapter).
