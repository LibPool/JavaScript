# @iflow-mcp/arkapravasinha-groww-mcp-server

> 标签: JavaScript

## 简介

A comprehensive Model Context Protocol (MCP) server for the Groww Trading API. This server provides tools to interact with Groww's trading platform, enabling you to place orders, manage your portfolio, access live market data, and more. [![smithery badge]
