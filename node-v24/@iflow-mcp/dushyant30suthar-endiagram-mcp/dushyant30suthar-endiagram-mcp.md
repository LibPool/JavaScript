# @iflow-mcp/dushyant30suthar-endiagram-mcp

> 标签: dependency-graph, endiagram, graph-theory, mcp, structural-analysis

## 简介

MCP server for EN Diagram — six questions about any system (structure, invariants, liveness, reachability, equivalence, composition) answered with graph theory. Plus a render tool. Pure math, no AI inside the computation.
