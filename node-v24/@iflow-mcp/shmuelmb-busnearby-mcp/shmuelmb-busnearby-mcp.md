# @iflow-mcp/shmuelmb-busnearby-mcp

> 标签: JavaScript

## 简介

A Model Context Protocol (MCP) server that provides access to the Israeli transport api.   This is the Unofficial MCP of Bus Nearby API, [You can check this API here](https://busnearby.co.il/plan)
