# @iflow-mcp/geekychris-amiga_mcp

> 标签: JavaScript

## 简介

A cross-development environment for Commodore Amiga (68k) that connects a modern host machine to an emulated (or real) Amiga via serial, providing live debugging, memory inspection, variable editing, remote execution, and full MCP integration with Claude
