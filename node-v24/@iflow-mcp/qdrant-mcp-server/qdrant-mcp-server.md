# @iflow-mcp/qdrant-mcp-server

> 标签: embeddings, mcp, qdrant, semantic-search, vector-search

## 简介

MCP server for semantic search using local Qdrant and Ollama (default) with support for OpenAI, Cohere, and Voyage AI
