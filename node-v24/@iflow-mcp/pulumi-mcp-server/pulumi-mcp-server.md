# @iflow-mcp/pulumi-mcp-server

> 标签: JavaScript

## 简介

To interact with the MCP Server, you'll need an MCP client. [Supported clients](https://modelcontextprotocol.io/clients) include Claude Desktop, VSCode, and Cline, among others. The configuration process is similar across all of them.
