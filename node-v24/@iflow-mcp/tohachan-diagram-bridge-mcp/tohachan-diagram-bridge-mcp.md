# @iflow-mcp/tohachan-diagram-bridge-mcp

> 标签: diagram, mcp

## 简介

A "bridge" MCP server with a unique Prompt+Tool design that helps LLMs seamlessly generate and render diagrams. Powered by Kroki to support dozens of formats.
