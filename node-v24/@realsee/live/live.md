# @realsee/live

> 标签: JavaScript

## 简介

如视 Live SDK：基于如视 WebSocket 长链双工通信能力的前端封装，借助此 SDK 您可以快捷地实现具备同屏连线、实时语音的 VR 带看业务能力。
