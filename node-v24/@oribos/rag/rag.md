# @oribos/rag

> 标签: agent-framework, ai-agents, embeddings, llm, memory, rag, semantic-recall, typescript

## 简介

Oribos RAG capability package — semantic recall over message history: wrap a MemoryStore to index saved messages with your embedding model and pull older relevant messages back into the recall window, no dependencies beyond the @oribos/core peer.
