# @oribos/croner

> 标签: ai-agents, cron, croner, llm, scheduling, typescript

## 简介

Oribos croner wrapper — cron expressions as a schedules.save() fragment (next + timezone), no dependencies beyond an exact-pinned croner, no core peer.
