# @oribos/observational-memory

> 标签: agent-framework, ai-agents, compaction, llm, memory, observational-memory, typescript

## 简介

Oribos observational-memory capability package — compaction over message history: wrap a MemoryStore so older messages that left the recall window are condensed inline, within the request that read them, into observation notes and reflections by your own
