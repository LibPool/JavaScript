# @kewwy-xu/midi2xml

> 标签: midi, xml

## 简介

Used to convert midi to xml. Forked from @thayes/midi2xml(https://www.npmjs.com/package/@thayes/midi2xml). 
 Compared to the original, this package exports parseMIDIToXML
