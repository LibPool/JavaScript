# @mnemora/local-embedding

> 标签: JavaScript

## 简介

EmbeddingProvider の、外部サービスへ繋がない実装。ruri v3 30m (ONNX/q8) を transformers.js でプロセス内推論する。256次元・対称 prefix（docs/architecture.md §5.5）。
