# @backlineint/gatsby-theme-drupal-markdown-post

> 标签: JavaScript

## 简介

Single purpose theme that displays Markdown post data from Drupal in Gatsby with limited  configuration. Uses the [gatsby-remark-drupal](https://www.gatsbyjs.org/packages/@weknow/gatsby-remark-drupal/) plugin for markdown and image preprocessing.
