# @z2net/opencodeignore-v2

> 标签: agentignore, opencode, opencode-plugin

## 简介

OpenCode V2 plugin that keeps .agentignore-guarded paths away from the agent: permission enforcement, result filtering, script commands, and an RPC contract.
