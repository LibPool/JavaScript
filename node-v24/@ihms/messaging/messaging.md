# @ihms/messaging

> 标签: api-client, bulk-email, bulk-sms, email, ihms, messaging, namibia, sms, typescript

## 简介

TypeScript client and centralized docs for the IHMS Email & SMS API (transactional, bulk, delivery status, records & stats). Works in Node, browsers, and React.
