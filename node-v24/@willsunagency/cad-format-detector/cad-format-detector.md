# @willsunagency/cad-format-detector

> 标签: cad, cadguide, dwg, dxf, engineering, file-type, ifc, iges, magic-bytes, step

## 简介

Zero-dependency pure JavaScript detector for CAD formats (DWG, DXF, STEP, IGES, IFC) with binary magic byte recognition.
