# @skill-wiki/mcp-server-core

> 标签: mcp, model-context-protocol, prime-lang, skill-wiki, stdio

## 简介

Generic MCP server for any compiled Prime corpus. Exposes one tool — prime_query — that browses atoms, traverses the edge graph, and returns projection-level paths for the agent to Read.
