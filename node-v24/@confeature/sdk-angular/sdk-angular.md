# @confeature/sdk-angular

> 标签: JavaScript

## 简介

Confeature Angular SDK — ConfeatureService + provideConfeature + ConfeatureModule + *cfFlag directive + cfFlag pipe on top of @confeature/sdk-browser-js. ConfigCat publishes no official Angular SDK; drop-in compatible with the configcat-js runtime surface
