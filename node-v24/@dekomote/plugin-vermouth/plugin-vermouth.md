# @dekomote/plugin-vermouth

> 标签: game-library, game-streaming, plugin, proton, punktfunk, vermouth, wine

## 简介

Punktfunk plugin: adds your Vermouth game library (Proton, Wine, native, Steam, retro) to the host's library and launches each title through Vermouth.
