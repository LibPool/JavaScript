> 标签: cli, design-tokens, dtcg, mcp, razorwind, shell-shock, shell-shock-plugin, storm-software, theme

## 简介

Razorwind + Shell Shock integration: generate a CLI theme from design tokens and expose the extracted design system through Shell Shock commands and MCP tools.
