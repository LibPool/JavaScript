# authichain-verify

> 标签: authichain, did-key, digital-product-passport, ed25519, gs1, provenance, verifiable-credentials, verifier

## 简介

Offline reference verifier for the AuthiChain Verification Specification v0.1.0. Zero dependencies, runs without contacting any AuthiChain server.
