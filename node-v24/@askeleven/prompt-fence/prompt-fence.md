# @askeleven/prompt-fence

> 标签: ai-agents, ai-security, email, guardrails, inbox, indirect-prompt-injection, llm-security, mcp, mcp-server, prompt-injection, spotlighting

## 简介

Stop prompt injection in AI inbox triage and chat agents. Scans emails, web pages and messages for instructions aimed at the AI (hidden HTML, invisible Unicode, base64, fake system markers), fences untrusted content for the prompt, and gates the tool call
