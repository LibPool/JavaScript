# @askeleven/send-guard

> 标签: ai-agents, bounce, deliverability, email, email-validation, email-verification, list-hygiene, mcp, mcp-server

## 简介

Check an email list before an agent (or a person) sends to it. Free local checks, optional mailbox verification via Analyzemail. CLI, library, and MCP server. Zero dependencies.
