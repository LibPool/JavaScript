# @allbluecn/bug-sdk

> 标签: JavaScript

## 简介

AllBlue BUG 采集 SDK（浏览器 + Node）：浏览器端封装 @grafana/faro-web-sdk 内核，Node 端自实现进程钩子，批量静默上报至 AllBlue /api/bugs/report
