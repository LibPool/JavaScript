# @sanityloop/extras

> 标签: JavaScript

## 简介

The shelf - every optional SanityLoop module as a subpath import. Only light libs (~2MB) ride as dependencies; the heavy worlds (mcp, pi-model, http-server) load lazily and declare their own needs.
