# dsh-tool-notion

> 标签: blocks, converter, deepseek-harness, dsh-plugin, export, markdown, mcp, notes, notion, rich-text, 笔记转换

## 简介

Notion block conversion for DeepSeek Harness: turn an exported block array into Notion-flavoured Markdown and back, with rich-text runs split at annotation boundaries and every lossy step reported. No API client and no external dependency.
