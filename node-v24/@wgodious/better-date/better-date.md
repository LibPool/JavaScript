# @wgodious/better-date

> 标签: better, date, datetime, deps, fluent, format, immutable, local, node, time, timestamp, timezone, utc, zero

## 简介

Tiny immutable fluent Date wrapper for Node.js & browsers (zero dependencies). Provides flexible formatting, comparison, and arithmetic on dates.
