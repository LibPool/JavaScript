# @danielng23/dsh-client-ui-x402

> 标签: JavaScript

## 简介

x402 wallet GUI, browser half: a Phantom-style wallet popup (create/import and switch wallets, QR receive, USDC send, on-chain activity) and a payment card for x402_pay calls, fed by the x402 Host remote
