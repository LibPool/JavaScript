# @mdbase-dev/connect-sync

> 标签: JavaScript

## 简介

Provider-neutral replication protocol and executable reference state machine for mdbase authorities. It models stable record identity, pinned snapshots, scoped ordered changes, conditional idempotent mutations, conflicts, cursor reset, revocation, offline
