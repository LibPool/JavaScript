# @paykernel/routing

> 标签: fallback, gateway-selection, paykernel, payment-routing, payments, routing, typescript

## 简介

Portable safe payment routing policies for @paykernel/core: deterministic select-only gateway choice, money-safe amount ranges, and structurally restricted post-attempt fallback eligibility.
