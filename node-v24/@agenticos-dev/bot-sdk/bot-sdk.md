# @agenticos-dev/bot-sdk

> 标签: JavaScript

## 简介

Dependency-free transport contract and explicit fixture transport foundation. This package does not connect to a live API, handle credentials, or grant authority. Hosts supply handlers and remain responsible for authentication and policy.
