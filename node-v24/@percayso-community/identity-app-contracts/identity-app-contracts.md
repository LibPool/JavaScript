# @percayso-community/identity-app-contracts

> 标签: JavaScript

## 简介

The Percayso ID app's wire contract: registration with an Approval key and a Channel key, the Channel proof, the request and response shapes of the app's six routes, the ES256 signed bytes, the attestation slots and the closed refusal union.
