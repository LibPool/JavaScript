# @secundus-studio/stift-persisters

> 标签: offline, persistence, stift, tanstack-intent

## 简介

Offline pack storage for @secundus-studio/stift-core: OPFS, IndexedDB (idb-keyval), and Cache Storage PersisterAdapters, plus a best-effort fallback chain.
