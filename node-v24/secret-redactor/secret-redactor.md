# secret-redactor

> 标签: ai, api-key, cli, credentials, llm, mask, privacy, prompt, redact, redaction, sanitize, secret, secrets, security, token

## 简介

Replace API keys, tokens and passwords in text with numbered placeholders before you paste it into an AI chat, then put the values back into the reply. No dependencies. Node and browsers.
