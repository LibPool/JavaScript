# @mbrundige/token-tracker

> 标签: agent-skills, ai-usage, claude-code, codex, continue, cursor, gemini-cli, statusline, token-tracking

## 简介

Local token usage tracker for Cursor, Claude Code, Gemini CLI, Codex, Continue, and Agent Skills hosts. Shared data lives in ~/.token-tracker/ with an optional Cursor CLI status line.
