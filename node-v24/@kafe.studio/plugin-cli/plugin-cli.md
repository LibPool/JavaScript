# @kafe.studio/plugin-cli

> 标签: atproto, cli, cms, fair, kafecms, plugin, plugin-cli, plugin-registry

## 简介

CLI for authoring, building, and publishing KafeCMS plugins. Covers init / build / dev / bundle / publish plus registry search and identity. Atproto OAuth, FAIR-shaped records, sandboxed-plugin-only.
