# @ttrpg/lancer-mechanics

> 标签: lancer, lcp, massif-press, mech, rpg, ttrpg

## 简介

RAW Lancer TTRPG engine. Substrate-driven combat math, action economy, NPC composition, mech building, content registry. Pure TypeScript. The open library for building Lancer tools.
