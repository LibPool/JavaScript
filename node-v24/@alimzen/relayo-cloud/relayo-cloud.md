# @alimzen/relayo-cloud

> 标签: bounces, email, failover, gateway, relayo, sms, webhooks

## 简介

Relayo Cloud driver: send email and SMS through the Relayo platform with one API key (rly_test_ to simulate, rly_live_ to deliver through your providers), and get every event through one signed webhook.
