# @grahan/core

> 标签: astronomy, ephemeris, julian-day, moon, moon-phase, sun, sunrise, sunset

## 简介

Astronomy-grade sky calculations: Julian day, ΔT, sun/moon positions, sunrise/sunset, sidereal time, moon phases. Zero dependencies.
