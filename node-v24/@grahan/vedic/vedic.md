# @grahan/vedic

> 标签: ayanamsa, hindu-calendar, nakshatra, panchang, panchanga, rahu-kaal, tithi, vedic

## 简介

Vedic layer for the grahan sky engine: ayanamsa, panchang (tithi, nakshatra, yoga, karana), Rahu Kaal. Zero dependencies.
