# @omniaid/capacitor-sunmi-pay

> 标签: android, capacitor, card-reader, emv, nfc, payment, plugin, pos, sunmi

## 简介

Capacitor plugin for Sunmi Payment SDK - provides card reading, EMV processing, PIN input, security operations, and printing capabilities for Sunmi POS devices
