# @althorlabs/a11yscan

> 标签: a11y, accessibility, axe-core, cli, github-action, playwright, wcag

## 简介

Open-source WCAG accessibility scanner CLI and GitHub Action (headless Chromium + axe-core). Scans URLs on your own machine's network, prioritized report by impact, optional LLM fix hints.
