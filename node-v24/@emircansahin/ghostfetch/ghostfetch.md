# @emircansahin/ghostfetch

> 标签: anti-bot, bot-detection, bypass, cloudflare, cookie-jar, crawler, cycletls, fetch, http-client, http2-fingerprint, ja3, ja4, proxy, proxy-rotation, residential-proxy, retry, rotating-proxy, scraping, session, tls-fingerprint, typescript, web-scraping

## 简介

Resilient HTTP client for Node.js with TLS fingerprinting (CycleTLS/JA3), proxy rotation and health checks, sticky sessions with a cookie jar, and per-site retry rules that tell a bad proxy apart from a slow server
