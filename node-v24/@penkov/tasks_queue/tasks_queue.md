# @penkov/tasks_queue

> 标签: async, backoff, cron, delayed-jobs, distributed, job-queue, nest, nodejs, periodic-tasks, postgres, postgresql, priority, queue, retry, scheduling, task, task-queue, task-runner, typescript, worker

## 简介

A lightweight PostgreSQL-backed task queue system with scheduling, retries, backoff strategies, and priority handling. Designed for efficiency and observability in modern Node.js applications.
