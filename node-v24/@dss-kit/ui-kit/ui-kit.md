# @dss-kit/ui-kit

> 标签: JavaScript

## 简介

Storybook для библиотеки React-компонентов **UI Kit** (`@dss-kit/ui-kit`) с дизайн-системой. Репозиторий хранит исходники компонентов и их Storybook, собирает контейнерный образ и разворачивает Storybook в Kubernetes.
