# dsh-lanhu

> 标签: cordis, deepseek-harness, design, design-spec, design-to-code, dsh, dsh-plugin, lanhu

## 简介

让 AI 直接「读蓝湖（Lanhu）设计稿」—— 把设计稿解析成可直抄的精确数值（色值 / 字号 / 圆角 / 间距 / 文本），替代靠截图估算。
