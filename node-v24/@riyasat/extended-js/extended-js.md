# @riyasat/extended-js

> 标签: Extended, ExtendedJavascirpt, JQuery, Javascript

## 简介

This library will extends JavaScript with JQuery Methods, You do not need to install JQuery for that. Most common methods of JQuery will be available as native methods on HTML Elements
