# @streamapp/meituan

> 标签: JavaScript

## 简介

Stream capability package: Meituan coupons / nearby group-buy search / ordering through Meituan's own official agent CLI (the one it ships for WorkBuddy), materialized from Meituan's public bucket and pinned by hash
