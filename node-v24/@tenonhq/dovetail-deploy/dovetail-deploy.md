# @tenonhq/dovetail-deploy

> 标签: JavaScript

## 简介

ClickUp-status-driven ServiceNow update-set promotion orchestrator for Dovetail — resolves the update sets for a task, preview-gates, and commits them across instances via a transport port (sawmill). Pure orchestration; transport stays in @tenonhq/dovetai
