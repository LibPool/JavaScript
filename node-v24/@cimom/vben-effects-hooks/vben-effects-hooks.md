# @cimom/vben-effects-hooks

> 标签: JavaScript

## 简介

用于多个 `app` 公用的 hook，继承了 `@cimom/vben-core-composables` 的所有能力，并扩展了更多业务场景下的钩子函数。业务上有通用 hooks 可以放在这里。
