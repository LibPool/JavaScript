# @designjs/mcp-server

> 标签: ai-agents, anthropic, claude, cursor, design-to-code, designjs, grapesjs, mcp, model-context-protocol

## 简介

stdio Model Context Protocol (MCP) server for DesignJS — lets Claude Code, Cursor, and any MCP-compatible agent read and write a live HTML/CSS design canvas.
