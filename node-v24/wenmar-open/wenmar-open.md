# wenmar-open

> 标签: automotive, nhtsa, offline, vehicle, vin, vin-decoder, vpic, webassembly

## 简介

VIN decoding and a year, make, model, trim and engine catalog: a typed client for the Wenmar Open API, and an offline mode that answers from a data file with no network. No API key.
