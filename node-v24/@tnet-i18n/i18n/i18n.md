# @tnet-i18n/i18n

> 标签: JavaScript

## 简介

> Shared **i18n package** cho hệ thống web & mobile apps của Trinity Net Technology.   > Dùng để đồng bộ key/value translations (multi-language) và cung cấp API/React hook để thao tác thuận tiện.
