# @easbot/note

> 标签: document-ingestion, easbot, embedding, entity-extraction, full-text-search, graph-database, hybrid-search, knowledge-base, llm, rag, sqlite, vector-search

## 简介

Note Knowledge Base - 非结构化记忆和文档知识库管理系统，支持混合搜索（向量+FTS+图）和 LLM 驱动的知识摄取
