# @three-ws/skill-license

> 标签: access-control, agent, anchor, license, nft, pda, skill, solana, spl, three.ws

## 简介

On-chain skill licenses for agents — each purchased skill is a 1/1 SPL NFT plus a deterministic SkillLicense PDA. Mint, verify, and read trustless skill access in one import, no database required.
