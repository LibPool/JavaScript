# @three-ws/mcp-policy

> 标签: agent-safety, mcp, model-context-protocol, solana, three.ws, tool-policy

## 简介

The three.ws MCP tool policy: every tool's group and tier, read-only by default with opt-in financial groups, named confirm flags, and preview ids that must precede every irreversible call.
