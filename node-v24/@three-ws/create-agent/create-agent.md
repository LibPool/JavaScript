# @three-ws/create-agent

> 标签: 3d, agent, avatar, create, glb, gltf, rigging, scaffold, text-to-3d, three.ws, web-component

## 简介

One command from a sentence to a rigged, animated 3D agent you can embed anywhere. npm create @three-ws/agent "a friendly cartoon astronaut"

- 官网：https://three.ws/create
- 源码仓库：git+https://github.com/nirholas/three.ws.git
