# @4xian/vue-fabric

> 标签: canvas, drawing, fabric, graphics, paint, typescript, vue

## 简介

基于 fabric.js 的二次封装绘图工具库，支持任意区域画图(直线,曲线)，矩形，文本，图片等功能，不限制框架，原生js可使用。
