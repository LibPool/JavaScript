# @tenprint/verify

> 标签: JavaScript

## 简介

Standalone verifier for TenPrint tiered and DAR attestations: ML-DSA-65 signature, Merkle fold, and the HCS anchor on a public mirror node. Makes no calls to the TenPrint API.
