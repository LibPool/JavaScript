# @nizam-os/keyset-core

> 标签: cursor, cursor-pagination, keyset, keyset-pagination, pagination, postgres, seek

## 简介

Keyset pagination for any JavaScript runtime: a typed filter AST with a per-type operator table, sort and page validation, HMAC-signed expiring cursors bound to the query, and a query plan a database adapter renders. Database-free.
