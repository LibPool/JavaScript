# @nizam-os/catalog-core

> 标签: catalog, check-constraint, pg-catalog, postgres, postgresql, schema, types

## 简介

The PostgreSQL catalog model as TypeScript types: tables, columns, constraints with the rules read from their CHECK expressions, indexes, row security policies, enums, and domains, plus the browser-safe public slice. Database-free, no dependencies.
