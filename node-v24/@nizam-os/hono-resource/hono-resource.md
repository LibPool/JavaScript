# @nizam-os/hono-resource

> 标签: api, hono, json-api, jsonapi, openapi, rest, routes

## 简介

Hono routes for a runtime of @nizam-os/resource-core declarations: every declared operation at the path its JSON:API links name, negotiated, validated, and answered by @nizam-os/hono-jsonapi, with no handler written per resource.
