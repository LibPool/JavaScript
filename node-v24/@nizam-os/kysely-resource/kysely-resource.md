# @nizam-os/kysely-resource

> 标签: json-api, kysely, multi-tenant, outbox, postgres, postgresql, rls, row-level-security

## 简介

The Kysely runtime for @nizam-os/resource-core declarations on PostgreSQL: a storage adapter that sends and reads every value as text, scoped transactions inside row security, boot checks against the catalog and the connection, and a transactional outbox.
