# dsh-todo-reminder

> 标签: deepseek-harness, dsh, notification, plugin, reminder, todo, 待办, 提醒

## 简介

DSH 全局个人待办插件：侧边栏「待办」面板 + 右侧待办条（悬停探出 / 快到点自动弹开）+ 到期提醒（自定义音效）+ 完成需确认，另给 agent 提供 todo_* 工具。与 DSH 会话无关。
