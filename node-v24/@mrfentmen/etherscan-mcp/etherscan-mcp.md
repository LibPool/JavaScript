# @mrfentmen/etherscan-mcp

> 标签: crypto, ethereum, etherscan, evm, mcp

## 简介

Query the Etherscan v2 API (free key; set ETHERSCAN_API_KEY; chainid default 1): ETH balance, transactions, ERC-20 transfers.
