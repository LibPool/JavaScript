# @paleye/mcp

> 标签: colors, mcp, model-context-protocol, palette, paleye

## 简介

Local helper for the Paleye MCP server: proxies the remote Paleye tools over stdio and lets agents search palettes with a local screenshot or image file.

- 官网：https://paleye.art/mcp
