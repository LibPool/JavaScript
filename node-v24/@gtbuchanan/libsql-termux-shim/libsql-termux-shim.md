# @gtbuchanan/libsql-termux-shim

> 标签: JavaScript

## 简介

libsql native-binding stand-in for Termux/Android, implemented on node:sqlite, so libsql-dependent tools (e.g. promptfoo) run where libsql ships no prebuilt binding
