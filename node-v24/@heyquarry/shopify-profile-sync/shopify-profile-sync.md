# @heyquarry/shopify-profile-sync

> 标签: JavaScript

## 简介

Sync Shopify shop profile (email, plan, phone) to HeyQuarry after OAuth install.

- 官网：https://heyquarry.com
- npm 页面：https://www.npmjs.com/package/@heyquarry/shopify-profile-sync

- npm registry：https://registry.npmjs.org/@heyquarry/shopify-profile-sync
- Node 要求：>=18
