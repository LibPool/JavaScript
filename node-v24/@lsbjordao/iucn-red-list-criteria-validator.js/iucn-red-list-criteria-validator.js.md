# @lsbjordao/iucn-red-list-criteria-validator.js

> 标签: biodiversity, conservation, criteria, extinction-risk, iucn, red-list, redlist, taxonomy, threatened-species, validator

## 简介

Validates, reconciles and normalizes IUCN Red List criteria declarations (A–E) against the evidence supplied, with multilingual reports.
