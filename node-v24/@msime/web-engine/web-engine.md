# @msime/web-engine

> 标签: chinese, hangul, ime, input-method, japanese, korean, pinyin, wasm, webassembly, wubi

## 简介

水杉输入法的网页引擎：在浏览器的 Web Worker 里运行的拼音、双拼、五笔、日语和韩文输入法，可部署到任意静态站点。
