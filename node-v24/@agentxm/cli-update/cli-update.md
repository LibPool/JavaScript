# @agentxm/cli-update

> 标签: JavaScript

## 简介

AXM self-update capability: install-ownership detection, release-channel and exact-version resolution, the startup update check, and the verified upgrade of the installed axm executable. Unstable and unsupported — use the axm.sh CLI.
