# @agentxm/workspace-transactions

> 标签: JavaScript

## 简介

AXM workspace transactions: the process transition lock, per-closure snapshot ledger, restoration, atomic single-file publication, and footprint observation for the axm CLI. Unstable and unsupported — use the axm.sh CLI.
