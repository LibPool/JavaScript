# @agentxm/extension-workspace

> 标签: JavaScript

## 简介

AXM extension-workspace kernel: coding-agent contracts, managed-file projection, per-type semantic vocabulary, and extension-type parity for the axm CLI. Unstable and unsupported — use the axm.sh CLI.
