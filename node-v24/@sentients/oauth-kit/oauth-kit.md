# @sentients/oauth-kit

> 标签: JavaScript

## 简介

Client OAuth/SSO côté serveur pour les backends tiers : vérifie et valide une session utilisateur auprès de sentient-api-core (appareil + session + consentement) sans exposer les données sensibles.
