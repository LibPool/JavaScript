# @erseco/mind-elixir-export-svg

> 标签: export, mind-elixir, mind-map, mindmap, svg, vector

## 简介

Render Mind Elixir mind maps as standalone SVG with native text and vector shapes, laid out as Mind Elixir does, without a browser
