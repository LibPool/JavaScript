# @sabhahq/narada

> 标签: JavaScript

## 简介

Narada — the messenger general, packaged for the Sabha marketplace. Bundles the narada MCP (dist) so it launches via node ${CLAUDE_PLUGIN_ROOT}/mcp/bin/start.mjs. Depends on sabha-core.
