# dsh-listener

> 标签: asr, dashscope, deepseek-harness, dsh-plugin, voice-input

## 简介

DeepSeek Harness 云端语音输入插件，支持快捷键录音、阿里云百炼实时识别，并将文字追加到当前会话草稿。
