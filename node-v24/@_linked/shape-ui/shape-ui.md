# @_linked/shape-ui

> 标签: interoperable, lincd, linked data, semantic web, web3

## 简介

UI driven by a shape: editors, a table over any shape's instances, a form derived from its properties, a read-only view and a relation picker — plus the read and write paths through the Linked Query DSL.
