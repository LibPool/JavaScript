# @astrolimit/opencode-mem

> 标签: ai, coding-agent, memory, multi-machine, opencode, plugin

## 简介

Thin opencode plugin for the astrolimit central memory service: memory tool (add/search/list) over HTTPS + auto-capture + offline outbox queue.
