# @astrolimit/opencode-mem-local

> 标签: ai, coding-agent, local, memory, opencode, plugin, standalone, vector-database

## 简介

Local single-machine opencode memory plugin (fork of tickernelz/opencode-mem, independently evolvable): Turso/libSQL vector search + local embeddings on-device.
