# @paramour-js/eslint-plugin

> 标签: eslint, eslint-plugin, eslintplugin, nextjs, routing, type-safe, typescript

## 简介

ESLint plugin for paramour — flags raw hrefs, raw param reads, and href() arithmetic that bypass paramour's typed routing
