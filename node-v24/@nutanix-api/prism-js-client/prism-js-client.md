# @nutanix-api/prism-js-client

> 标签: Nutanix Prism APIs, nutanix

## 简介

The Javascript client for Nutanix Prism APIs is designed for Javascript client application developers offering them simple and flexible access to APIs that manage Tasks, Category Associations and Submit Batch Operations.
