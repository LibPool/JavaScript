# @cloudflare/telescope

> 标签: browser, cloudflare, har, lighthouse, page-load, performance, playwright, testing, web-vitals

## 简介

Cross-browser performance testing agent and library, built on Playwright. Collects HAR, Web Vitals, screenshots, filmstrip, and video.
