# @tdacorp/identity-sdk

> 标签: authorization, dpop, identity, oauth2, oidc, tdacorp

## 简介

TDACorp identity SDK: OIDC relying party, service client (client_credentials and token exchange, DPoP), resource-server verifier, PEP client, sealed sessions and tdaid-lint.
