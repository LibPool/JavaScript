# metrics-mcp

> 标签: analytics, mcp, metrics, model-context-protocol, page-views, privacy, rbac, web-analytics

## 简介

MCP server for metrics, the privacy-friendly web-analytics service: read page views, visitors, pages, referrers, countries and devices per project, inspect raw events and manage projects, with role-based tool access and audit logging.
