# @olaservo/mcp-wrappers

> 标签: code-execution, codegen, mcp, model-context-protocol, wrappers

## 简介

Generate typed TypeScript wrappers for MCP tools so agents can call them as code (the "MCP as code" pattern), plus the runtime bridge and a staleness-aware lifecycle.
