# @stonedogcode/release-notes

> 标签: changelog, conventional-commits, release-notes, whats-new

## 简介

A release-notes surface for applications: releases described by their deploys, filtered to what a customer should read, grouped by day, with an optional what's-new prompt and a host-configured way to report a problem.
