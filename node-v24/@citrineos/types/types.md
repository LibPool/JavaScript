# @citrineos/types

> 标签: ocpp, ocpp_v201, types

## 简介

Shared type definitions for CitrineOS: OCPP model types, DTO shapes, Zod schemas, enums, and protocol types. This package contains no server runtime and is safe to consume from browser apps.
