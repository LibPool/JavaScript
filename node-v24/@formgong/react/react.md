## 简介

React contact form without a backend: <ContactForm>, <FormgongForm> and useFormgong(). Submissions go to email, Telegram and webhooks via Formgong. Works in Lovable, Bolt, v0, Next.js and Vite. A Formspree / Web3Forms alternative.
