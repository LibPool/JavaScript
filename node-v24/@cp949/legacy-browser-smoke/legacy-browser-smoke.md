# @cp949/legacy-browser-smoke

> 标签: JavaScript

## 简介

고정된 Chromium 75(2019년 build)를 실제로 실행해, 최신 문법으로 작성된 production 번들이 legacy 브라우저에서 로드조차 실패하는지 사전에 검증하는 smoke 실행기다. 정적 문법 검사가 아니라 실제 브라우저 실행 결과(로드 성공, console/page-error, 실패한 요청)를 판정한다.
