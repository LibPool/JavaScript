# @pouchy_ai/backend-kit

> 标签: JavaScript

## 简介

Verify signed Pouchy Data requests, collapse duplicate Action deliveries, answer reconciliation, emit Events. The runtime integration plane for a Pouchy Data backend — declarations stay in the dashboard/API.
