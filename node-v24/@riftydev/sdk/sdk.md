# @riftydev/sdk

> 标签: browser, node-compatible, rifty, runtime, sandbox, sdk, wasi, webcontainer

## 简介

rifty — a browser-based Node-compatible runtime + WASI runner. One install, all the parts, plus a framework-free createSandbox() façade.
