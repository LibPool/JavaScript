# @kiwook/modal

> 标签: modal, react, typescript

## 简介

props|type|설명 ---|---|--- message|string|모달의 메시지 입니다. closingButtonText|string|닫는 버튼의 텍스트 입니다. onClose|function|닫는 버튼의 로직이 들어갑니다. handleButtonText|string|삭제, 로그아웃 등 **어떤 특정한 일**을 하는 버튼의 텍스트입니다. onHandle|function|**어떤 특정한 일**을 수행하는 로직이 들어갑니다.
