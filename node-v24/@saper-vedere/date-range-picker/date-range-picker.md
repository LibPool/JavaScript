# @saper-vedere/date-range-picker

> 标签: calendar, component, date-picker, date-range-picker, datepicker, typescript, vue, vue3

## 简介

Vue 3 + TypeScript date range picker with two-month calendar, drag-to-adjust, optional input mode with popover, presets, theming via CSS custom properties, and full slot customisation.
