# @gaurussel/tiptap-diff-utility

> 标签: decorations, diff, document-diff, editor, prosemirror, rich-text, tiptap, version-comparison

## 简介

TipTap/ProseMirror extension that diffs two document versions and renders inserted, deleted, moved, and inline changes as visual decorations. Live and snapshot modes.
