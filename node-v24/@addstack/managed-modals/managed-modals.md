# @addstack/managed-modals

> 标签: base-ui, dialog, drawer, modal, priority, queue, radix-ui, react, scheduler, shadcn, shadcn-ui, sheet, vaul

## 简介

Priority scheduling for dialogs and drawers in React (shadcn/ui, Radix, Base UI, vaul): one modal flow on screen, a queue for the rest, preemption with resume, nested flows.
