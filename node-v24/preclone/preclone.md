# preclone

> 标签: ai-agents, bitbucket, cli, devcontainer, git, github, gitlab, malware, mcp, mcp-server, npm, security, static-analysis, supply-chain, take-home, vscode

## 简介

See everything a repo would run on your machine (on open, AI agent start, install, run and commit) before you clone, open or install it. Static analysis only: it never runs the repo's code.
