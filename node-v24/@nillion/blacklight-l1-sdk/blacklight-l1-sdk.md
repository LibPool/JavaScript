# @nillion/blacklight-l1-sdk

> 标签: blacklight, ethereum, ibe, nillion, sepolia, threshold-encryption

## 简介

TypeScript SDK and CLI for Blacklight L1 — seal a payload to a committee of nodes, post it with an on-chain release condition, and reconstruct it when the condition fires.
