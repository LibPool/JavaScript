# @w3tech.io/vrpc-viem

> 标签: attestation, ed25519, ethereum, rpc, tdx, verifiable, viem

## 简介

viem drop-in for Ankr's verifiable RPC — vrpcHttp custom transport verifies every JSON-RPC response (Ed25519) before parse, fail-closed.
