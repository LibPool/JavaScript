# @nexdoc/mcp-server

> 标签: design, mcp, model-context-protocol, nexdoc

## 简介

NexDoc Design MCP server. Remote HTTP (ChatGPT, Claude, Cursor) authenticates with OAuth 2.1 — do not ask for an API key. Local stdio uses NXD_API_KEY.
