# @fulldotdev/check

> 标签: accessibility, html-validate, links, seo, static, website

## 简介

Static checks of a built website's files: HTML and accessibility markup, links, assets and fragments, also in Markdown, feeds and web manifests, SEO tags, structured data syntax, sitemap and robots.txt, file sizes and sensitive files.
