# @sendmsg/mcp-client

> 标签: ai-agent, claude, email, mcp, model-context-protocol, sendmsg

## 简介

stdio ↔ HTTP bridge for the Sendmsg.io MCP server. Use this from Claude Desktop, Cursor, Windsurf, or any other MCP client that only speaks stdio.
