# dsh-wsl-bridge

> 标签: bash, deepseek-harness, dsh, dsh-plugin, linux, windows, workspace, wsl

## 简介

Native WSL execution for DeepSeek Harness on Windows: persistent Linux bash, Linux-path file and search tools, and a WSL session mode that asks which distribution folder to use as the workspace. No extra web server and nothing to install inside the distri
