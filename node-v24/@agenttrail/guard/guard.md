# @agenttrail/guard

> 标签: agent-safety, ai-agents, claude-code, cli, code-safety, cursor, guardrails, hooks, policy, security

## 简介

Free, local guard for Claude Code and Cursor: a hook that allows, asks, or blocks a tool call against a curated guardrail library. No account, no server. The only network call is crash reporting, which is off unless you turn it on and sends stack traces o
