# @useclickly/mcp-server

> 标签: agent, ai, claude, clickly, cursor, mcp, model-context-protocol

## 简介

Model Context Protocol stdio server that exposes Clickly annotations to AI coding agents (Claude Code, Cursor, Codex, Windsurf).
