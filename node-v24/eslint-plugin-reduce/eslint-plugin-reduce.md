# eslint-plugin-reduce

> 标签: array, eslint, eslint-plugin, eslintplugin, lint, linter, optimization, performance, quadratic, reduce, spread

## 简介

ESLint plugin that flags spread syntax inside Array.prototype.reduce callbacks, which can cause significant performance issues.
