# @bluesky-social/jwk

> 标签: atproto, json web key, jwk, jwks, jwt

## 简介

A library for working with JSON Web Keys (JWKs) in TypeScript. This is meant to be extended by environment-specific libraries like @bluesky-social/jwk-jose.
