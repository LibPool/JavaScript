# @alfacapital-tech/c4builder

> 标签: C4, C4Model, Documentation, Generator, Markdown, PlantUML, Software Architecture

## 简介

A CLI tool designed to compile a folder structure of markdowns and plant uml files into a site, single file markdown or a collection of markdowns with links
