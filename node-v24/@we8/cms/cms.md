# @we8/cms

> 标签: aeo, cloudflare-workers, cms, headless-cms, hono, self-hosted, seo, we8

## 简介

The core we8 headless CMS: content, forms, analytics, media, and SEO modules behind a single-site /api/v1 API, with a pluggable admin auth seam.
