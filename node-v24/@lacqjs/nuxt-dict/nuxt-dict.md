# @lacqjs/nuxt-dict

> 标签: @lacqjs/nuxt-dict, dict, nuxt, nuxt-dict

## 简介

Nuxt 数据字典模块，提供扁平/树形字典翻译、多语言国际化、三级缓存与 SSR 预取。
