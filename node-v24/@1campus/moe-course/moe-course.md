# @1campus/moe-course

> 标签: JavaScript

## 简介

「moe-course」程式庫提供「全國高中課程計畫」的相關功能，包含：課程規劃與課程代碼表比較、解析課程代碼欄位、對照代碼中欄位的中文說明。
