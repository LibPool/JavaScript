# @waiin/openapi-tools

> 标签: api, generator, openapi, reducers, services

## 简介

@waiin/openapi-tools is a powerful CLI and library designed to streamline API development by generating proxy services and Redux integrations for React applications based on OpenAPI specifications. It supports any JSON from Swagger, allowing seamless API
