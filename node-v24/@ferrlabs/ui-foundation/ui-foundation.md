# @ferrlabs/ui-foundation

> 标签: JavaScript

## 简介

Framework-agnostic FerrLabs design foundation: SVG icons, base CSS + fonts, Tailwind preset tokens. Consumed by @ferrlabs/ui-ng and by the Astro sites directly.
