# @loomcycle/library

> 标签: agent, ai, component, library, loomcycle, react, substrate

## 简介

Embeddable React Library component for the loomcycle agentic runtime — the Agents / Skills / MCP-Servers substrate browser (lineage, create/fork/promote/retire, Claude Code import) as a standalone, themeable package.
