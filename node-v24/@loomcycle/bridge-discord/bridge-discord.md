# @loomcycle/bridge-discord

> 标签: agent, ai, bot, bridge, discord, loomcycle

## 简介

Discord bridge for loomcycle interactive agents (RFC EQ): people talk to a loomcycle agent with slash commands, each as their own loomcycle user, with question and review cards as buttons. Interactions over HTTP; no Gateway.
