# @loomcycle/explorer

> 标签: agent, ai, component, document, explorer, loomcycle, path, react, vfs

## 简介

Embeddable React Path VFS + chunked-graph Document browser for the loomcycle agentic runtime (RFC AL / AK) — a themeable, standalone package: a dirent tree with folder/document CRUD and a chunk-tree Document viewer/editor.
