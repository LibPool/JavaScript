# @ssfbank/norwegian-id-validators

> 标签: fodselsnummer, norsk, norwway, organisasjonsnummer, ssn

## 简介

Validates norwegian ssn, orgno(both statically and API), accountno and KID. Based on npm pkg norsk-validator.
