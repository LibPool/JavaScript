# @wickermoney/plugin-sdk

> 标签: JavaScript

## 简介

The contract between [Wicker Money](https://github.com/WickerMoney/wicker-money) and its plugins. The host and every plugin build against this package: it defines the plugin manifest and validates it, and it declares the props and context a plugin's React
