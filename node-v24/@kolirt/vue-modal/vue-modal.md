# @kolirt/vue-modal

> 标签: confirm, dialog, focus-trap, headless, imperative, lightbox, modal, modal-manager, modals, nested-modals, overlay, popup, stacking, vue, vue-modal, vue-modals, vue3, vuejs

## 简介

Open modals from any function, stack them as needed, and style them however you want. No template boilerplate, no manual state — just call and await.
