# @webnori/agent-one

> 标签: agent, ai-agent, cli, coding-agent, knowledge-graph, kuzu, llm, local-llm, ollama, openai-compatible, terminal, tool-use

## 简介

A coding agent for your terminal in one native binary: reads your code, writes files, runs commands behind an approval gate, and remembers each project in a knowledge graph. Works with any OpenAI-compatible model, hosted or local (Ollama, LM Studio, vLLM)
