# @pro-laico/payload-seed

> 标签: fixtures, payload, payloadcms, plugin, seed, seeding

## 简介

Schema-aware, type-safe seeding plugin for Payload CMS: typed cross-file references with dependency tracking, robust media uploads, a POST /api/seed endpoint, and a SeedRegistry injected into payload-types.ts.
