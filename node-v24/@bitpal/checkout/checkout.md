# @bitpal/checkout

> 标签: base, bitpal, checkout, crypto, eip-3009, evm, non-custodial, pay-per-call, payments, sdk, stablecoin, usdc, x402

## 简介

BitPal Checkout SDK — non-custodial crypto checkout: create sessions, issue per-order deposit addresses, poll status, verify signed webhooks, and charge per API call with x402.
