# @madrimov/via-payment-sdk

> 标签: humo, payment, sdk, subscription, uzbekistan, uzcard, via, via.uz

## 简介

TypeScript SDK for the VIA payment platform API (api.via.uz): subscriptions, cards, transfers, merchant payments, deposits, holds, invoices, cashback, OFD receipts and monitoring. Works on Node >= 18.17 and Bun.
