# @mzimt625/datapulse-sdk-web-sender-debug

> 标签: JavaScript

## 简介

开发调试 Sender。默认只输出事件名、事件 ID、时间与属性键，不打印属性值、用户 ID 或页面正文。可用 `forward` 同时转发到真实 Sender。
