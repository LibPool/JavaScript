# @mzimt625/datapulse-sdk-web-plugin-visual-tracking

> 标签: JavaScript

## 简介

已发布可视化规则的运行时插件。它从 DataPulse 配置接口加载页面浏览与元素点击规则，并按结构化域名、路径和查询参数条件触发事件。
