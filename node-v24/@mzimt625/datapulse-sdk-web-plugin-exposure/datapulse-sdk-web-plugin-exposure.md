# @mzimt625/datapulse-sdk-web-plugin-exposure

> 标签: JavaScript

## 简介

Web 元素曝光采集插件。基于 `IntersectionObserver`，支持可见面积比例、有效停留时间、重复曝光，以及动态注册和注销。
