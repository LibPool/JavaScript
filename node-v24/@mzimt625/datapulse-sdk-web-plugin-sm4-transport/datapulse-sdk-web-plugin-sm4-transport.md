# @mzimt625/datapulse-sdk-web-plugin-sm4-transport

> 标签: JavaScript

## 简介

Web SDK 的 SM4 传输插件。事件批次使用随机 IV 的 SM4-CBC 加密，并以独立密钥执行 HMAC-SHA256 完整性校验；请求正文只包含加密 envelope。
