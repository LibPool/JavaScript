# @lsmsgpack/client

> 标签: JavaScript

## 简介

Reads application/x-lsmsgpack responses of LsMsgPack's ASP.NET formatters into complete JavaScript objects (with the cached, described schema, or the models of lsmsgpack-ts) and writes request bodies they read.
