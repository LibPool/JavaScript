# @kromatv/ui

> 标签: JavaScript

## 简介

KROMA design system: one universal component library. Authored against React Native, it renders natively on Apple TV / Android TV and through react-native-web on Tizen / webOS / desktop / browser. Design tokens live here in TypeScript and generate the CSS
