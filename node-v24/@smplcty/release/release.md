# @smplcty/release

> 标签: changelog, keep-a-changelog, prerelease, release, release-it, semver

## 简介

Laptop-driven release tooling: derive the SemVer bump from CHANGELOG.md, cut prereleases correctly, and guard against a stale local branch. Shared across the simplicity/productionnow apps.
