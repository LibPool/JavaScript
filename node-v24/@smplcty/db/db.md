# @smplcty/db

> 标签: friendly-error, pg, pool, postgres, postgresql, with-client

## 简介

Tiny TypeScript helpers for pg: env-driven Pool factory, withClient checkout-run-release wrapper, parameterized UPDATE statement generator, and friendly error messages for common pg constraint codes.
