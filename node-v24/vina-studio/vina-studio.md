# vina-studio

> 标签: claude, cursor, garment, mcp, model-context-protocol, pattern, vina

## 简介

MCP server for Vina: lets your AI agent (Claude Code, Claude Desktop, Cursor) work on the garment pattern you have open. Runs vina-mcp.
