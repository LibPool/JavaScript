# @ptner/stripe-lib

> 标签: billing, checkout, cloudflare, d1, pay-as-you-go, stripe, subscriptions, webhooks, workers

## 简介

Server-side Stripe billing for Cloudflare Workers, Node and Deno: pay-as-you-go Checkout, subscriptions, customer portal and verified webhooks. No UI, no framework.
