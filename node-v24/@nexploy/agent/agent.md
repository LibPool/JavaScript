# @nexploy/agent

> 标签: agent, deployment, docker, nexploy, tunnel

## 简介

Nexploy agent — bridges a remote Docker daemon to a Nexploy instance over an outbound tunnel, with no inbound port and no Docker socket exposed on the network.
