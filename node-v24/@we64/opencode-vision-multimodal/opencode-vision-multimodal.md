# @we64/opencode-vision-multimodal

> 标签: ai, document, image, multimodal, ocr, opencode, opencode-plugin, pdf, vision, we64

## 简介

Give opencode native image, PDF and document analysis via any OpenAI-compatible multimodal API. Files are sent as-is; the API decides what it can read. No OCR, no conversion.
