# @cexoso/git-diff-report

> 标签: JavaScript

## 简介

一个 Istanbul coverage reporter，**只展示 git diff 范围内的未覆盖代码块**，帮助你在 Code Review 时快速聚焦新增/修改代码的测试覆盖情况。
