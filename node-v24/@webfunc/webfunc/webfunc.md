# @webfunc/webfunc

> 标签: cloud, cors, functions, google, google-cloud-functions, http-handler

## 简介

Lightweight HTTP handler for Google Cloud Functions. It supports CORS and also assists in initialization of web app projects hosted on Google Cloud Functions.
