# dcursed

> 标签: agents, antigravity, claude-code, coding-agents, cursor, diagram, mcp, opencode, plan, planning

## 简介

A plan you and your coding agents share: a diagram in your repository that you edit by hand, with each step showing who has it and how that is known. For OpenCode, Claude Code, Cursor and Antigravity.
