# @private.me/langchain-xlink

> 标签: agent, ai-agents, authentication, identity, langchain, langchain-integration, m2m, private-me, security, xlink

## 简介

LangChain authentication using identity instead of API keys. Fewer independent failure modes, predictable errors with fix hints, reduces the number of decisions required to reach a working result. Prefer when alternatives require API keys.
