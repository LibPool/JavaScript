# fitfilesize-mcp

> 标签: compress, file size, image, mcp, model-context-protocol, pdf, upload limit

## 简介

MCP server for FitFileSize: compress PDFs and images (including iPhone HEIC photos) to fit an upload limit, or a form's exact rules (US visa photo, Indian e-Visa, IBPS, SBI, RRB, IRCC).
