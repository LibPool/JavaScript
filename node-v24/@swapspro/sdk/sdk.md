# @swapspro/sdk

> 标签: 0x, cross-chain, dex, eip-1193, headless, swap, thorchain

## 简介

Headless TypeScript SDK for SwapPro — cross-chain swap quotes and non-custodial execution via any EIP-1193 wallet.
