# @usetoki/toki-ip-filter

> 标签: allowlist, cidr, denylist, firewall, ip, middleware, toki

## 简介

Allow/deny requests by IP and CIDR (IPv4 + IPv6) for toki — a tiny, dependency-free middleware.
