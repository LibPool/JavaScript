# @droplinked_inc/payment-intent-react

> 标签: JavaScript

## 简介

React Stripe-Elements wrapper for @droplinked_inc/payment-intent. Port of the <DroplinkedPaymentIntent> client surface from droplinked-payment-intent@1.3.0. Pairs with the server-side @droplinked_inc/payment-intent state machine.
