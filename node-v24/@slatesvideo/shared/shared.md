# @slatesvideo/shared

> 标签: ai-video, claude, image-generation, kling, mcp, model-context-protocol, seedance, slates, veo, video-generation

## 简介

Shared operations layer for the Slates MCP server and CLI: auth, cloud/desktop clients, and the single tool surface both consume. Most users want @slatesvideo/mcp-server or @slatesvideo/cli instead.
