# @jabworks/condux

> 标签: agents, condux, opencode, opencode-plugin, skills, workflow

## 简介

OpenCode plugin for the condux workflow toolkit — bundles the condux skills and injects the specialist agents (coder, explorer, planner, researcher) plus an opt-in plan-review listener.
