# @unclecat/mcp-obsidian

> 标签: claude, markdown, mcp, model-context-protocol, notes, obsidian

## 简介

MCP server for Obsidian vaults via the filesystem. Works without Obsidian running, supports multiple vaults with per-vault readonly/readwrite mode.
