# @suluk/scalar-standalone

> 标签: JavaScript

## 简介

The suluk-forked Scalar API Reference standalone bundle (Scalar 1.59.0 + the suluk OpenAPI v4 patch-set: native requests->operations ingest, parameterSchema, multi-request-per-method, facet panels). Served via jsdelivr-npm so @suluk/scalar's native-v4 vie
