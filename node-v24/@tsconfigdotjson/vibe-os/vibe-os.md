# @tsconfigdotjson/vibe-os

> 标签: bun, dtach, multiplexer, ssh, terminal, vps, wasm, xterm

## 简介

A coding desktop in the browser, on a box you own. Git worktrees per piece of work, terminals that survive a reload, and SSH that runs in the tab.
