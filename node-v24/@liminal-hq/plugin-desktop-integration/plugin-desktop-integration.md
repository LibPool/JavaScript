# @liminal-hq/plugin-desktop-integration

> 标签: JavaScript

## 简介

Desktop activation helpers for Linux Tauri apps: native X11 window activation and a unified global-shortcut API that picks the right binding path (X11 direct grab vs. Wayland portal) automatically based on session type.
