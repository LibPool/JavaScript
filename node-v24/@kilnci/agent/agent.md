# @kilnci/agent

> 标签: JavaScript

## 简介

Kiln CI/CD build agent. Provides the `kiln-agent` binary used by `kiln agent start --host` to run builds directly on the host as bash subprocesses (for targets that need native tooling — e.g. Xcode on macOS).
