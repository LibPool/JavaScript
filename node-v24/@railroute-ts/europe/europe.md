# @railroute-ts/europe

> 标签: europe, freight, geojson, logistics, rail-network, rail-route, railroute-ts, railway, train-route

## 简介

Europe rail network data for railroute-ts — Europe-wide mainline rail (35–72N, 10W–32E) from OpenStreetMap, with gauge, electrification and train-ferry links (Messina, Rostock–Trelleborg). 12,886 stations with UIC codes.
