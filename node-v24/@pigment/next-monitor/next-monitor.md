# @pigment/next-monitor

> 标签: monitor, next, payload

## 简介

Next.js config wrapper and monitor route utilities for the Pigment crm. Each site exposes a stable public URL (often hit by [Vercel Cron](https://vercel.com/docs/cron-jobs)), verifies `CRON_SECRET` on requests, and can POST audit payloads to the any crm.
