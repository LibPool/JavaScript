# @thejoshualab/react-tiptap-editor

> 标签: ai-editor, blog-editor, dropbox, google-drive, markdown, prosemirror, rich-text, tiptap, wysiwyg

## 简介

Enterprise-grade React WYSIWYG editor powered by TipTap 2. Features an enterprise two-tier toolbar, document/classic/inline canvas modes, image resizing with presets, responsive media embeds, and built-in AI Copilot.
