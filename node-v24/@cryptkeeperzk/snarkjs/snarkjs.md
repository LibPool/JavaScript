# @cryptkeeperzk/snarkjs

> 标签: circuit, cryptography, ethereum, knowlage, zcash, zero, zksnark

## 简介

zkSNARKs implementation in JavaScript, is a forked version from the main `iden3/snarkjs` repo to make it work with CryptKeeper Browser Extension using `@cryptkeeperzk/ffjavascript` forked version.
