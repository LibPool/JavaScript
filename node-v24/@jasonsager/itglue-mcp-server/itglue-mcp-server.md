# @jasonsager/itglue-mcp-server

> 标签: ai, documentation, it-glue, itglue, llm, mcp, model-context-protocol, msp

## 简介

Unofficial MCP server for the ITGlue API — documents, sections, organizations, plus client-side name search and a local content-search index. Fork of Junto-Platforms/itglue-mcp-server.
