# @qrxcodes/mcp

> 标签: ai-art, mcp, mcp-server, model-context-protocol, qr, qr-code, qr-code-generator, qrx, stdio

## 简介

QRX MCP server for stdio clients: art QR codes that always scan. Bridges to the hosted QRX MCP server at qrx.codes/mcp.
