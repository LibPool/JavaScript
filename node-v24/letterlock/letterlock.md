# letterlock

> 标签: encryption, erc-8004, hpke, mera, monad, passkey, prf, viem, webauthn, x25519

## 简介

A passkey becomes an encryption address on Monad: resolve keyOf(address) and seal data only that passkey can open, on any device it syncs to.
