# dsh-desktop-uia

> 标签: ai-agent, computer-use, cordis-plugin, deepseek-harness, desktop-automation, desktop-control, dsh, dsh-bundle, dsh-plugin, ui-automation, uia, windows, windows-automation

## 简介

Windows desktop control for DeepSeek Harness through UI Automation: read a window's control tree, drive elements by id, approve every write, and watch it all in the settings panel.
