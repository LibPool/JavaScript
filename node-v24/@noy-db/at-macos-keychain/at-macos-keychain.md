# @noy-db/at-macos-keychain

> 标签: aes-256-gcm, at-macos-keychain, encryption, keychain, macos, managed-secret, noy-db, rubber-hose-resistant, sealing-key-provider, zero-knowledge

## 简介

macOS Keychain sealing key provider for noy-db managed-secret mode — AES-256-GCM under a 32-byte key stored in the user's login Keychain. Desktop-app provider in the at-* family; pairs with Touch ID via Keychain Access UI.
