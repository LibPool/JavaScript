# @aryanbansal-launch/observer-launch-mcp

> 标签: claude, mcp, model-context-protocol, observability, observe, observeinc, opal

## 简介

MCP server for querying Observe (OPAL) from Claude and other MCP clients -- health check, ad-hoc OPAL queries, and fast aggregated helpers for recent errors, error summaries, and log stats.
