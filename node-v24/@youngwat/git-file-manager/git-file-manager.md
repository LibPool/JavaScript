# @youngwat/git-file-manager

> 标签: branch, cherry-pick, cli, commit, git, rescue, sync

## 简介

Git 救火工具：把提交错分支的 commit 剪切到功能分支并彻底还原源分支；把指定 commit 的文件改动按原目录结构同步到另一个目录
