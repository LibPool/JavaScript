# @this-npm-test-org/storage-connection-driver

> 标签: amodal, amodal-connection-driver, file-upload, r2, s3, storage

## 简介

First-party ConnectionDriver for blob storage. Backs Cloudflare R2 (S3-compatible) or local filesystem; registers /upload + /download/:blob_ref HTTP routes and read_blob/delete_blob LLM tools. Templates that need file storage declare a `protocol: "storage
