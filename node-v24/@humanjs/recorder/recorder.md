# @humanjs/recorder

> 标签: browser-automation, demo, gif, humanize, humanjs, mp4, playwright, recorder, screen-recording, test-generation, tutorial, video, webm

## 简介

One-call session recording for HumanJS — capture a humanized Playwright session as mp4, webm, gif, or a structured JSON timeline.
