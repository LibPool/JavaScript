# @idevconn/isubscribe-entitlements

> 标签: authorization, billing, casl, entitlements, feature-flags, idevconn, isubscribe, nestjs, react, saas, subscriptions

## 简介

Runtime entitlements engine for iSubscribe: turn purchased plans into runtime feature access via a framework-agnostic core, React provider/hooks, and NestJS guards/decorators. CASL is hidden behind a business-oriented API.
