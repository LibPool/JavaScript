# dsh-prompt-deck

> 标签: deepseek-harness, dsh, dsh-plugin, prompt, prompt-manager

## 简介

dsh-prompt-deck — local prompt deck for DSH: a composer button opens a searchable prompt-card panel; clicking a card appends it to the input draft.
