# @synoi/start

> 标签: ai-tools, gateway, llm, quickstart, synoi

## 简介

SynOI Gateway bootstrap — `npx @synoi/start init` drops a docker-compose.yml + .env template into your current directory; `npx @synoi/start link` pairs a headless install with your SynOI account via RFC 8628 device flow.
