# @sawala/kontena-client

> 标签: cms, headless, kontena, sawala, sawala-cloud, sawala-tech, typescript

## 简介

TypeScript client for the Kontena public read API — Sawala Cloud's headless CMS. Framework-agnostic, runs in Node, browsers, and Cloudflare Workers.
