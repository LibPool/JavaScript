# @ukewea/dsh-taskboard

> 标签: agent, deepseek-harness, dsh, dsh-plugin, kanban, taskboard

## 简介

English-only, independently maintained DSH task board plugin with taskboard_* agent tools, scheduled execution, Git worktree isolation, and a live SSE kanban view.
