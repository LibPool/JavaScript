# @peddlum/node-sdk

> 标签: api-sdk, auth, baas, chatbot, database, multi-tenant, payments, peddlum, push-notifications, storage

## 简介

Official Node.js SDK for Peddlum — auth, data, storage, chatbot, payments, push, email, AI, and more. Works in Node 18+ and Cloudflare Workers (with nodejs_compat).
