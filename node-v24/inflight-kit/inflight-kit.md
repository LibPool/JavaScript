# inflight-kit

> 标签: abortsignal, async, cancellation, fetch, request-coalescing, request-deduplication, singleflight, thundering-herd, timeout, typescript

## 简介

Deduplicate concurrent async requests with independent AbortSignal cancellation, per-caller timeouts and shared deadlines. Zero-dependency TypeScript singleflight.
