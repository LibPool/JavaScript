# @chimok/lossless-rotate

> 标签: auto-rotate, autorotate, avif, dct, exif, imir, irot, isobmff, jpeg, jpegtran, jpg, lossless, orientation, rotate

## 简介

Make JPEGs upright: read and write the EXIF orientation tag, rotate JPEGs losslessly in the DCT domain, and handle the orientation of AVIF.
