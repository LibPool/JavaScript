# @pitchkit/core

> 标签: analytics, charting, data-visualization, dataviz, football, football-pitch, mplsoccer, opta, pitch, skillcorner, soccer, soccer-analytics, statsbomb, svg, typescript, visualisation, visualization

## 简介

Zero-dependency TypeScript core for PitchKit, the football (soccer) visualisation library: coordinate systems, transforms, scene/layer model, SVG renderer.
