# @osqd/jql

> 标签: filter, json, mongodb, predicate, query, search, typescript

## 简介

JSON Query Language — one MongoDB-style query document for every place the OSQD projects filter data, with a zero-dependency TypeScript engine that compiles each query once into a plain predicate.
