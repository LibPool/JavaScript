# @open-music-sdk/react

> 标签: apple-music, apple-music-api, hooks, musickit, react, sdk, tanstack-query, typescript

## 简介

The Apple Music API for a React app: everything in the browser package, a provider that holds the client and the listener's token, hooks for the client, Apple's sign-in and the preview player, and one query factory for TanStack Query.
