# @lasmind/website-accessibility

> 标签: a11y, accessibility, accessibility-widget, color-blind, colorblind, daltonize, font-size, high-contrast, lasmind-vision, read-aloud, text-to-speech, wcag

## 简介

LasMind Vision accessibility widget for any website: a colour blind filter, read aloud text to speech, high contrast and text size. A visitor preference menu.
