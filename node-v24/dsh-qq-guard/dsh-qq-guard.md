# dsh-qq-guard

> 标签: chatbot, deepseek-harness, dsh, onebot, plugin, qq, quota, token-usage

## 简介

QQ group guard for DeepSeek Harness: per-(bot, group) daily token accounting, regex prefix gating before the model call, optional daily cost quotas, and a read-only dashboard. Verified against dsh-onebot-qq v1.1 session ids.
