> 标签: autopilot, buyback, fair-launch, hash-based-signatures, launch-rules, launchpad, lm-ots, lms, meteora, noised, passkey, post-quantum, programmable, qsl-1, quantum, quantum-security-layer, rfc8554, solana, token-2022, token-launch, token-standard, transfer-hook, verifier

## 简介

TypeScript SDK for Noised, the quantum security layer for Solana: the QSL-1 token standard checker, launch builders, an independent on-chain verifier, post-quantum creator identities (LMS, RFC 8554), post-quantum vaults (LM-OTS) and programmable launches
