# @aiquants/authz-drizzle

> 标签: authorization, drizzle, mssql, rbac, row-level-security, typescript

## 简介

Drizzle (mssql) adapter for @aiquants/authz-core: defineAuthzSchema factory, getEffectivePermissions, and row/column scope application helpers.
