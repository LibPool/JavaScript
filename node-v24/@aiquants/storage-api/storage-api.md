# @aiquants/storage-api

> 标签: connectrpc, filesystem, google-cloud-storage, google-drive, grpc, storage, typescript

## 简介

Server-side TypeScript client for the multi-backend storage-api ConnectRPC service (local filesystem, Google Cloud Storage, Google Drive, in-memory) over a UNIX domain socket.
