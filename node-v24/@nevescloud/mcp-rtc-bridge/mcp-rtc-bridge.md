# @nevescloud/mcp-rtc-bridge

> 标签: anthropic, bridge, claude, claude-code, mcp, model-context-protocol, p2p, transport, webrtc

## 简介

Stdio MCP server that lets Claude Code (or any local MCP client) reach MCP servers hosted on the mcp-rtc mesh. Built on @nevescloud/mcp-rtc. Discovers the remote peer's tools and dynamically forwards them.
