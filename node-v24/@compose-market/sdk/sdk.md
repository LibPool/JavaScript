# @compose-market/sdk

> 标签: a2a, agentic-economy, compose, compose-market, decentralized-inference, facilitator, inference, manowar, x402, x402-v2

## 简介

Official Compose.Market SDK: Compose Keys, x402 facilitator, multi-provider model catalog, native streaming inference with typed receipts, unified tool-call events, agent + workflow runtime streams, live session events, and wallet-scoped persistence.
