# @kinarajs/kinara

> 标签: events, express, framework, grpc, hooks, kinara, microservices, mongodb, otel, rabbitmq

## 简介

Hook-first microservice framework for Node.js. HTTP, gRPC, events, permissions, cache, and Mongo — copy a module and it runs.
