# @dev_hussein/react-native-amazing-bottom-sheet

> 标签: JavaScript

## 简介

Bottom sheet modal with support for nested scroll view, dynamic height, two stops and pan gesture, built with reanimated for maximum performance, supports typescript out of the box.
