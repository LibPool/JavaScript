# @speedb/mcp

> 标签: code-review, database, mcp, model-context-protocol, performance, sql

## 简介

MCP server that scans a GitHub or GitLab repo for database queries and grounds every proposed rewrite against the source. The calling agent supplies the reasoning — no API key required.
