# @hashborn/mcp

> 标签: ai-agent, attestation, hashborn, mcp, model-context-protocol, post-quantum, pqc-rh, robinhood-chain, wots

## 简介

A Model Context Protocol server that gives any MCP-capable AI agent a Hashborn (protocol pqc-rh) post-quantum identity: register it, sign and anchor its actions on Robinhood Chain with one-time keys, and verify records offline.
