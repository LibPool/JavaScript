# @pawells/rxjs-events

> 标签: async, event-emitter, events, observables, reactive, rxjs, typescript

## 简介

RxJS-based event handling library with reactive observables and async event streams. Provides a typed EventHandler for publish/subscribe, AsyncObservable for backpressure-aware async iteration, DebounceEvents/ThrottleEvents/PipeEvents for composing handle
