# @pawells/graphql-mongoose

> 标签: builder, filter, graphql, mongodb, mongoose, query, subscription, typescript

## 简介

GraphQL-to-Mongoose filter builder — translates GraphQL filter inputs into Mongoose/MongoDB query objects and in-memory subscription filter predicates
