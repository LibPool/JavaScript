# @niravi/mcp

> 标签: ai, mcp, model-context-protocol, niravi, search, video

## 简介

Niravi Cloud API as an MCP server — tools generated from the same OpenAPI spec as the SDK, calls routed through the @niravi/sdk transport. No reinvented HTTP/auth.
