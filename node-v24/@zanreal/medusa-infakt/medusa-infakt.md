# @zanreal/medusa-infakt

> 标签: e-invoicing, infakt, invoicing, ksef, medusa, medusa-plugin, medusa-plugin-integration, medusa-plugin-other, medusa-v2, plugin, poland

## 简介

Medusa v2 plugin for Polish invoicing: issues inFakt invoices for paid orders and files them to KSeF, with a durable, crash-safe state machine and an operator surface for invoices that need review.
