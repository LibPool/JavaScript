# @zanreal/medusa-usage-tinybird

> 标签: clickhouse, medusa, medusa-plugin, medusa-plugin-integration, medusa-plugin-other, medusa-v2, metering, tinybird, usage, usage-based-billing

## 简介

Tinybird usage sink for @zanreal/medusa-usage: an append-only usage event log in a column store, deduplicated on read so a retry cannot double count.
