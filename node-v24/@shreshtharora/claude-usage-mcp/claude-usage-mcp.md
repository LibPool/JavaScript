# @shreshtharora/claude-usage-mcp

> 标签: claude, claude-code, cost, local, mcp, offline, privacy, tokens, usage

## 简介

Local-only MCP server for Claude Code usage: tokens, equivalent API cost, 5-hour blocks and context size, read from your own transcripts on disk. No API key, no network calls, nothing leaves the machine.
