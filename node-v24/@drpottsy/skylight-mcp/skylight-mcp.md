# @drpottsy/skylight-mcp

> 标签: ai, calendar, chores, claude, family, mcp, model-context-protocol, skylight

## 简介

MCP server for Skylight Calendar API - enables agentic interactions for calendar, chores, lists, and family management. Maintained fork of @rjhalvorson/skylight-mcp.
