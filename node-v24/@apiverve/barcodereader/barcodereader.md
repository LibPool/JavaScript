# @apiverve/barcodereader

> 标签: barcode reader api, barcode scanner api, decode barcode from image, ean-13 barcode reader, upc barcode scanner api

## 简介

Barcode Reader decodes 1D barcodes from an uploaded image or an image URL, including EAN-13, EAN-8, UPC-A, UPC-E, Code 128, Code 39, Code 93, ITF, Codabar and GS1 DataBar. It returns the decoded value and the symbology. Paid plans add the GTIN, the barcod
