# @apiverve/balancesheet

> 标签: assets and liabilities data api, balance sheet api, statement of financial position api, stock balance sheet api, total assets and total liabilities api

## 简介

Balance Sheet is a stock balance sheet API that returns the statement of financial position for a US public company by ticker - assets, liabilities and shareholders' equity - straight from SEC filings: current assets, cash, receivables, current liabilitie
