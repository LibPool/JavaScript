# @apiverve/weatheralerts

> 标签: national weather service api, nws alerts api, nws api, severe weather alerts api, weather alerts api

## 简介

Weather Alerts returns the severe weather warnings, watches and advisories in effect right now for any point or state in the United States, straight from the National Weather Service. Each alert names the event, how severe and urgent it is, the area cover
