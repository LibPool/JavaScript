# @apiverve/pdfpagenumbers

> 标签: add page numbers to pdf, number pdf pages api, page x of y pdf, pdf page numbers api, pdf pagination api

## 简介

PDF Page Numbers stamps a page number on every page of a PDF, uploaded or fetched from a URL, and returns a download link to the numbered file. Choose the corner or edge and the font size. Paid plans can also set a label format such as Page 3 of 12, the s
