# @apiverve/financialratios

> 标签: financial ratios api, leverage ratios api, liquidity ratios api, profitability ratios api, ratio analysis api

## 简介

Financial Ratios returns the key profitability, liquidity, leverage, efficiency and cash-flow ratios for a US public company by ticker - margins, ROE, ROA, current ratio, debt-to-equity, interest coverage, asset turnover, FCF margin and more - all compute
