# @dwast/verifactu-lib

> 标签: aeat, factura, facturacion, hash, qr, verifactu

## 简介

Librería para la gestión de Verifactu (RD 1007/2023): modelo de datos, encadenado hash, generación XML, QR y cliente AEAT.
