# opencite-mcp

> 标签: bibtex, citation-verification, citations, crossref, hallucination, mcp, model-context-protocol, open-access, openalex, pubmed, retraction, scholarly-search

## 简介

MCP server for OpenCITE — verifiable scholarly evidence for agents: verify references before citing them (retracted? fabricated? wrong DOI?), search 250M+ open-access papers plus museum, library, manuscript and Islamicate archives, and fetch any work by D
