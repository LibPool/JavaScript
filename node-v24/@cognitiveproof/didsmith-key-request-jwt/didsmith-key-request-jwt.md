# @cognitiveproof/didsmith-key-request-jwt

> 标签: did, did-web, didsmith, ed25519, jwt, verifiable-credential

## 简介

Builds and signs the compact JWT-VC "key request" DIDsmith's key-linking flow expects, from any Ed25519 signer — a raw seed, an HSM, or @cognitiveproof/webauthn-prf-identity's signBytes. Zero dependencies, works in the browser and Node.
