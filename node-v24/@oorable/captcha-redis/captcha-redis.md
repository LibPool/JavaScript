# @oorable/captcha-redis

> 标签: JavaScript

## 简介

Redis-backed challenge store and rate limiter for OORABLE CAPTCHA, for multi-instance deployments. Bring your own Redis client (ioredis, node-redis, etc.) -- none is bundled.
