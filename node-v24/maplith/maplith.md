# maplith

> 标签: ai-agents, claude-code, codex, csv, maplith, mcp, mcp-server, model-context-protocol, postgres, postgresql, read-only

## 简介

Maplith for your AI agents: set Maplith up in Claude Code or Codex with one command, and share a folder of data files with your agent over MCP, read-only and behind a token, filled from PostgreSQL under a read-only role.
