# @gautamgiri/use-status-manager

> 标签: custom-hook, hook, react, status-manager, subscription, use-status-manager

## 简介

A lightweight and flexible custom React hook for managing subscriptions and status updates in your application. It helps you subscribe to a list of candidates, fetch their statuses, and keep them updated with polling and debounce functionality.
