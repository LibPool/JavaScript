# @fiatdock/goat-plugin

> 标签: agent-payments, agents, ai-agents, base, fiatdock, goat, goat-plugin, goat-sdk, mcp-marketplace, usdc, x402

## 简介

FiatDock plugin for the GOAT SDK: token verdicts, token safety, wallet portfolios, web pages and Base chain data, paid per call in USDC over x402 from the agent's own GOAT wallet, plus a free marketplace search
