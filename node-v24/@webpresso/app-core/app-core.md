# @webpresso/app-core

> 标签: JavaScript

## 简介

Shared low-level primitives for webpresso agent packages: repo-root discovery, process-tree termination, e2e port/health + fail-closed secret-env, release-version validation, workspace-binary resolution. Pure Node, no runtime dependencies.
