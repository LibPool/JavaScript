# @namahapdf/embed

> 标签: annotate, client-side-pdf, embed, iife, no-bundler, on-device, pdf, pdf-editor, pdf-viewer, redact, script-tag, sdk, sign, standalone, wordpress

## 简介

Standalone browser build of the NamahaPDF editor — one <script> tag, then NamahaPDF.mount(). For sites with no bundler (WordPress, Rails, Django, plain HTML).
