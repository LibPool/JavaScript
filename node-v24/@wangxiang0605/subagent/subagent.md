# @wangxiang0605/subagent

> 标签: agent, pi, pi-extension, pi-package, subagent, tool

## 简介

Pi extension: Provides a `subagent` tool: each call spawns a separate pi process for an isolated context, supporting single, parallel, and chain modes. / Pi 扩展：提供 `subagent` 工具：每次调用启动独立的 pi 进程以获得隔离上下文，支持 single / parallel / chain 三种模式。
