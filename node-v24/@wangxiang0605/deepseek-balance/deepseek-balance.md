# @wangxiang0605/deepseek-balance

> 标签: balance, deepseek, pi, pi-extension, pi-package, usage

## 简介

Pi extension: Shows the DeepSeek account balance in the status bar (refreshed every 5 minutes and after each turn) and tracks token usage and cost per task. / Pi 扩展：在状态栏显示 DeepSeek 账户余额（每 5 分钟及每轮对话后刷新），并统计一次任务消耗的 token 与费用。
