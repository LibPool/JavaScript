# @elsewhereprotocol/game-sdk

> 标签: elsewhere, game-engine, game-sdk, multiplayer, race, virtual-world

## 简介

Build mini-games that run inside Elsewhere: a declarative game spec, its validator, the match engine the world runs, a local harness and a CLI.
