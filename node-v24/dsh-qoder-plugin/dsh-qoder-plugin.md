# dsh-qoder-plugin

> 标签: deepseek, deepseek-harness, dsh-plugin, model-provider, qoder

## 简介

把 Qoder 模型接入 DeepSeek Harness：用 PAT 调用与 Qoder CLI 同源的模型服务，支持国内版 / 国际版双区域、模型开关、上下文窗口与每日签到，并提供只读的额度概览。
