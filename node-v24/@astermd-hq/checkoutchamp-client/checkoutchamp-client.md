# @astermd-hq/checkoutchamp-client

> 标签: api-client, checkout-champ, checkoutchamp, crm, ecommerce, orders, payments, rest-client

## 简介

Unofficial Node.js client for the Checkout Champ API: orders, leads, upsales, campaigns, customers, transactions and lander clicks, with opt-in redacted request logging.
