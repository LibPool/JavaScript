# @d3-timeline/core

> 标签: JavaScript

## 简介

The framework-agnostic core engine for the Timeline component. Built with D3.js, this package handles the heavy lifting of SVG rendering, responsiveness (`ResizeObserver`), smart collision detection, and D3 transitions.
