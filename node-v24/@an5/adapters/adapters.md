# @an5/adapters

> 标签: adapter, an5, dotnet, go, golang, java, kotlin, orm, python, rust, swift, typescript

## 简介

Standalone language adapters for AN5 ORM - TypeScript, Python, .NET, Go, Rust, Java, Kotlin, Swift, and Google Sheets query execution.
