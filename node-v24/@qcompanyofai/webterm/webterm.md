# @qcompanyofai/webterm

> 标签: pty, shell, sysadmin, terminal, web-terminal, xterm

## 简介

A minimal web-hosted terminal: run shell commands from the browser, with a file explorer, editor, process viewer and packet capture. Python backend, no build step.
