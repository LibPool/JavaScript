# @agungabadii/opencode-auth-ag

> 标签: antigravity, auth, claude, gemini, google, oauth, opencode, plugin

## 简介

Enhanced Google Antigravity IDE OAuth auth plugin for OpenCode - featuring safe mode anti-ban protection, Oh-My-OpenCode integration, strict quota locking, and proxy support.
