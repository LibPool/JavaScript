# @sz.ws/cms

> 标签: cli, cloudflare, cms, d1, sz-ws, sz.ws, workers

## 简介

CLI for sz.ws CMS — `setup` wires the repo to your Cloudflare account, `secrets` fills in the managed Worker keys after a deploy, `add` installs code extensions, `preflight` checks settings before deploy.
