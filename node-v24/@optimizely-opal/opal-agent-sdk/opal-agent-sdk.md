# @optimizely-opal/opal-agent-sdk

> 标签: agent, ai, llm, opal, sdk, streaming, typescript

## 简介

Isomorphic TypeScript SDK for invoking Opal agents over a Personal Access Token (PAT). Works in Node and the browser.
