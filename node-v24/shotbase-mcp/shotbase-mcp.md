# shotbase-mcp

> 标签: agents, claude, mcp, model-context-protocol, playwright, screenshot, screenshot-api, self-hosted, shotbase

## 简介

MCP server for Shotbase — capture any web page plus structured data (page type, headings, CTAs, prices) in one call. Point it at your own self-hosted instance via SHOTBASE_MCP_URL, or at the hosted API.
