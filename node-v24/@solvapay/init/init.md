# @solvapay/init

> 标签: JavaScript

## 简介

Shared primitives for SolvaPay CLI tooling (browser auth, env writers, product picker, install runner). Consumed by `solvapay` and `create-solvapay`.

## 官网

- 官网：https://github.com/solvapay/solvapay-sdk#readme
- 源码仓库：git+https://github.com/solvapay/solvapay-sdk.git
- npm 页面：https://www.npmjs.com/package/@solvapay/init
