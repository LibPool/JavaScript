# @fire-shield/react

> 标签: access-control, authorization, caching, deny, fire-shield, hoc, hooks, permissions, plugin, rbac, react, wildcards

## 简介

React adapter for Fire Shield RBAC with hooks, HOCs, and components. Features: Plugin system, Advanced audit logging, Wildcards, Deny permissions, Permission caching, Lazy roles, Memory optimization, RBACAggregator support
