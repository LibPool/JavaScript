# @shadrqen/opencode-team-config

> 标签: JavaScript

## 简介

Shared OpenCode 4-agent orchestration layer (router/builder/fixer/architect) for the team. Installs additively via OPENCODE_CONFIG_DIR; never touches your existing opencode.json, opencode.jsonc, or provider secrets.
