# forecast-web

> 标签: browser, chronos, forecasting, onnx, react, tabicl, tabular, time-series, timesfm, webgpu

## 简介

Forecasting and tabular prediction models in the browser on WebGPU or WebAssembly: TimesFM 2.5, Chronos-Bolt and TabICL. Optional React hook.
