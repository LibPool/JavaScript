# @ienznotfound/smeme-canvas

> 标签: JavaScript

## 简介

Generate classic top/bottom text memes (PNG) and animated progressive text-reveal videos (GIF) directly in Node.js! Inspired by [brat-canvas](https://www.npmjs.com/package/brat-canvas).
