# @apitraffic/adonisjs

> 标签: adonis, adonisjs, apitraffic, apm, logging, monitoring, observability, waf

## 简介

AdonisJS package for ApiTraffic: request capture, the ApiTraffic firewall and the APM bridge, as a provider and two middleware.
