# @apitraffic/cli

> 标签: apitraffic, ci, cli, config, offline, resilience

## 简介

Keeps a repository's pinned ApiTraffic definitions fresh. `definitions pull` writes .apitraffic/definitions/sdk.json; `definitions check` fails CI when the committed file has drifted from the account's live config.
