# dsh-egress-gate

> 标签: allowlist, data-exfiltration, deepseek-harness, dsh-plugin, egress, security

## 简介

Deterministic network egress gate for DeepSeek Harness: web fetches and searches are checked against a destination allowlist before they run — content scanning guards what agents read, this guards where data may flow
