# @agentportal/metrics

> 标签: agent, agentportal, ai, cli

## 简介

OpenTelemetry metrics bridge for agentportal: turns diagnostics_channel runs/usage/spawn/exit/retry/breaker/rate-limit/permission signals into OTel counters and histograms (GenAI semantic conventions where they apply). @opentelemetry/api is a peer depende
