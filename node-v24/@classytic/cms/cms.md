# @classytic/cms

> 标签: JavaScript

## 简介

CMS kernel: content types, content items, assets. Block-based (Slate AST), form-based (typed), and MDX content unified in one storage model. Multi-tenant, headless, visibility-aware. Kernel Construction Standard compliant (defineCms().bind()); built on Mo
