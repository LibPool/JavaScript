# @classytic/arc-review

> 标签: arc, classytic, erp, moderation, ratings, review, spine

## 简介

Arc module for @classytic/review — ratings & reviews as one composable resource: adapter-backed reads + moderation-safe domain verbs (submit, edit, moderate, respond, vote-helpful, remove). BYO engine; eligibility (verified-purchase) is a host config hook
