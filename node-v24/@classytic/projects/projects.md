# @classytic/projects

> 标签: JavaScript

## 简介

Project delivery engine — projects, tasks, timesheets, milestones, client deliverables with approval sign-off, and Stripe-style handover journeys. MongoDB persistence via @classytic/mongokit, arc-compatible events.
