# @classytic/arc-testkit

> 标签: arc, classytic, fastify, in-memory, mongodb, test-harness, testing

## 简介

Boot a real @classytic/arc app around the module(s) under test on in-memory MongoDB — the ecosystem test harness. Thin Mongo-typed wrapper over @classytic/arc/testing (arc 2.22+). If your arc module boots green here, it composes into any arc host.
