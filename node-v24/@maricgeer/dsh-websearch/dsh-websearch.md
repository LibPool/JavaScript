# @maricgeer/dsh-websearch

> 标签: anysearch, cordis, deepseek-harness, dsh, exa, firecrawl, plugin, tavily, web-search, websearch

## 简介

Unified multi-provider WebSearch management plugin for the DeepSeek Harness (dsh) — priority chains with full HA degradation for search and fetch, plus a settings-page GUI
