# @bingyin/youtube-mcp

> 标签: captions, claude, llm, mcp, subtitles, transcript, video, youtube, yt-dlp

## 简介

A simplified MCP server for extracting subtitles from videos. Supports YouTube, Facebook, TikTok and other platforms via yt-dlp.
