# @grec0/mcp-mantis

> 标签: bugtracker, issue-tracker, mantis, mantisbt, mcp, model-context-protocol, rest

## 简介

A TypeScript MCP stdio server for the MantisBT REST API: read, resolve, comment on issues, plus local semantic search.
