# @grec0/mcp-secure-env-elicit

> 标签: claude, elicitation, env, environment-variables, mcp, model-context-protocol, proxy, secrets, wrapper

## 简介

MCP wrapper that launches other MCP servers with secret env vars collected interactively via elicitation — placeholders in config, values held AES-encrypted in memory, never on disk.
