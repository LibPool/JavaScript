# @jamolpe88/dsh-desktop-chat

> 标签: deepseek, deepseek-chat, deepseek-harness, desktop, dsh, dsh-plugin, webchat, webview

## 简介

Opens the official DeepSeek Chat web app inside DeepSeek Harness Desktop: one sidebar entry renders chat.deepseek.com in the center column through the desktop shell's native browser guest, and keeps you signed in across restarts. No chat UI, no agent tool
