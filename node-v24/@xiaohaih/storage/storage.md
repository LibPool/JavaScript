# @xiaohaih/storage

> 标签: browser storage, localStorage, sessionStorage, storage, web storage

## 简介

本项目提供了一个灵活的本地存储工具, 基于 `TypeScript` 实现, 支持 `localStorage`, `sessionStorage` 及自定义存储; 通过 `StorageCore` 类, 可以方便地进行数据的序列化, 反序列化, 存储和读取。
