# @myida/sdk

> 标签: ai-agents, decentralized-identity, delegation, did, eip-712, ibct, marketplace, reputation, soulbound, ssi, verifiable-credentials

## 简介

TypeScript SDK for the IDA decentralized identity platform — mint DIDs, provision AI agents, issue W3C Verifiable Credentials, record trust signals, and anchor ZK proofs on the ADI blockchain.
