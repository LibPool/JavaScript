# @entree_pos/xlsx

> 标签: entreepos, excel, spreadsheet, workbook, worksheet, xlsx

## 简介

A zero-dependency modern JavaScript API for lossless XLSX/XLSM editing, charts, pivot tables, and Office password encryption.
