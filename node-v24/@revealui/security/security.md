# @revealui/security

> 标签: cors, csp, encryption, gdpr, rbac, revealui, security

## 简介

Security primitives — CSP/CORS/HSTS headers, RBAC + ABAC policy engine, encryption helpers, audit logging, GDPR compliance. Ships with RevealUI.
