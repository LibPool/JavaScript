# @cratebase/schema

> 标签: JavaScript

## 简介

Schema-as-code for Cratebase: typed field builders, deterministic collection ids and defineSchema() that emits the JSON accepted by `cratebase dev`, `cratebase schema` and POST /api/schema/apply.
