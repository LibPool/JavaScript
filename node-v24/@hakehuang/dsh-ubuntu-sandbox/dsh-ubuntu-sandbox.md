# @hakehuang/dsh-ubuntu-sandbox

> 标签: cordis-plugin, deepseek-harness, dsh, dsh-plugin, remote, sandbox, ssh, tmux, ubuntu

## 简介

Remote SSH Ubuntu sandbox for DeepSeek Harness: run bash on a remote host with a persistent (tmux) session plus remote read/write/list tools, sharing the host store of @linxin666/dsh-ssh.
