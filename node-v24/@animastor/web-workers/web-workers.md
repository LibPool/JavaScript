# @animastor/web-workers

> 标签: animastor, frontend, ports-and-adapters, preact, private-worker, setup-wizard, sharing, web-ui, workers

## 简介

Private Worker Management UI for Animastor web frontend — worker CRUD, setup wizard, sharing V2, and notification adapter. Host capabilities (api, i18n, ui, auth, icons) arrive via the injected WorkerPorts contract; the package never imports host stores,
