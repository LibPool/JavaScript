# @animastor/web-settings

> 标签: ai-provider, animastor, connector, frontend, local-ai, preact, pure-functions, settings, web-ui

## 简介

Pure AI provider and Local AI Connector helpers for Animastor web frontend — provider validation, connector lifecycle, status mapping, sharing badges, and timestamp formatting. Zero host dependencies; pure functions and types only.
