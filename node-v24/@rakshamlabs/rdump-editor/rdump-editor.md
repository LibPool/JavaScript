# @rakshamlabs/rdump-editor

> 标签: editor, markdown, prosemirror, react, rich-text, tiptap, wysiwyg

## 简介

Markdown-first rich text editor: Tiptap-based writing surface with markdown/HTML/JSON round-trip, tables, tasks, math, mermaid, charts, mentions and page links — configurable per feature, lazy-loaded per flag.
