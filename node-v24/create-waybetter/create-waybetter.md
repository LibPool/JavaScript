# create-waybetter

> 标签: create, plugin, scaffold, tauri, theme, waybetter

## 简介

npm create waybetter: scaffold a wayBetter plugin (*.plugin.js, JS or TypeScript), theme (JSON with the waybetter theme schema) or a whole wayBetter app (Tauri 2 + waybetter-host + the waybetter runtime). No dependencies.
