# @jbitar/lazydev

> 标签: dev-server, local-development, localhost, on-demand, proxy, reverse-proxy

## 简介

On-demand local dev-server proxy: every project gets a permanent .localhost URL that wakes its dev server on request and sleeps it when idle.
