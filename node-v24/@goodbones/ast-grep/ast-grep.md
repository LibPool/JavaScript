# @goodbones/ast-grep

> 标签: architecture, ast-grep, campaigns, lint, monorepo

## 简介

The ast-grep syntax matcher for @goodbones/core: a campaign's `syntax` term, evaluated through @ast-grep/napi behind the core's SyntaxMatcher port.
