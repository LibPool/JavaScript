# @goodbones/oxlint

> 标签: architecture, hexagonal, import-boundaries, lint, monorepo

## 简介

The oxlint plugin for @goodbones/core: the imports, exports, members, structure and surface families as five oxlint rules, evaluated in the editor and in CI from the same manifest the CLI reads.
