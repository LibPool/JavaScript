# @superbworks/sdk

> 标签: clarity, json-schema, nlp, plain-language, reading, semantics, typed, word-sense, wordnet

## 简介

Read any text as a typed, span-anchored document: tokens, morphology, phrases, clauses, propositions, references, senses in context and what the wording leaves open. Deterministic, no key needed.
