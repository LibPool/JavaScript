# @auto-hwp/react

> 标签: chat, document, hancom, hwp, hwpx, pdf, react, svg, viewer

## 简介

React components for auto-hwp: open .hwp/.hwpx, render pages to SVG, mark cells/ranges, chat-edit via a host-supplied AI callback, and download HTML/PDF — one <HwpWorkspace/> line. No LLM, no keys, no bundled fonts.
