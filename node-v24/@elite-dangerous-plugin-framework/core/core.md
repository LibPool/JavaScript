# @elite-dangerous-plugin-framework/core

> 标签: JavaScript

## 简介

Core Plugin Library for Elite: Dangerous Plugin Framework. This provides mostly types and helpers to interact with EDPF, as well as an abstraction layer around the HTMLElement used by plugins.
