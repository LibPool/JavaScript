# @hsu-canvas/renderer

> 标签: canvas, graphics, image, offscreen, renderer, text

## 简介

Canvas 渲染工具集：富样式文本渲染（TextGraphics）、图片合成渲染（ImageGraphics）与图片/字体加载工具
