# dsh-guard-repeat-output

> 标签: cordis-plugin, deepseek-harness, dsh, guard, repetition

## 简介

Host-side degeneration guard for DSH: strips garbage code points from the stream, detects repetition collapse and discards the attempt before any of it enters history, and can retroactively decontaminate a session that was already poisoned.
