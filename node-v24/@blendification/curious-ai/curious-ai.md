# @blendification/curious-ai

> 标签: blendification, conversation, curious-ai, docx, interview, pdf, react, report, survey

## 简介

Run a Curious AI interview from any web app: the participant protocol (session, stations, turns, submission, completion reports) packaged once, with the surface-context read model the pages render from.
