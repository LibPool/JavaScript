# @rover-tools/engine

> 标签: @rover-tools, AWS, AWS-SAM

## 简介

Rover-Engine is a SAM module generating system, which generates SAM projects based on user requirements. It will have a set of predefined stacks(Auth, CRUD) which are commonly used and  a option to define our custom stacks. It is designed using typescript
