# @cssdoc/markdown

> 标签: css, cssdoc, documentation, emitter, markdown

## 简介

Render an @cssdoc/core model to markdown reference pages + a sidebar (compatible with typedoc-plugin-markdown / typedoc-vitepress-theme).
