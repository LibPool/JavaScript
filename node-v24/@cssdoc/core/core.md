# @cssdoc/core

> 标签: JavaScript

## 简介

A generic CSS documentation extractor: parse doc-comments + the CSS AST into a serializable model (TSDoc, for CSS).

- 源码仓库：git+https://github.com/thedannywahl/cssdoc.git
