# @ad-freiburg/qlever

> 标签: database, knowledge-graph, qlever, rdf, sparql, triplestore, wasm, webassembly

## 简介

QLever SPARQL engine compiled to WebAssembly. Build RDF indexes and run SPARQL queries directly in the browser or using Node.js.
