# comarkserv

> 标签: cli, comark, livereload, markdown, markserv, mdc, preview, server, srvx, static-site, twinkleplop

## 简介

Serve a directory of markdown as fast, live-reloading HTML pages, with Comark components and twinkleplop highlighting. A modern markserv.
