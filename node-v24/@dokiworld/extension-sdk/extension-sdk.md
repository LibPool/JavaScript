# @dokiworld/extension-sdk

> 标签: JavaScript

## 简介

`@dokiworld/extension-sdk` 是 DokiWorld Web UI Extension 的版本化 TypeScript 契约。UI Extension 以不受权限沙箱限制的同源浏览器代码运行。SDK 用于改善兼容性和恢复能力，不是权限沙箱。
