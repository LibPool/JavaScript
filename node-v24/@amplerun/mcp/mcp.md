# @amplerun/mcp

> 标签: ai-agents, amplerun, gpu, llm, mcp, model-context-protocol

## 简介

MCP server (stdio) that lets AI agents find and rent GPUs on AmpleRun, and register their own account with a wallet. Wraps @amplerun/sdk; read-only unless AMPLERUN_MCP_ALLOW_SPEND=1.
