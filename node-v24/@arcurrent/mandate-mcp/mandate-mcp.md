# @arcurrent/mandate-mcp

> 标签: agents, arc, escrow, mcp, model-context-protocol, usdc

## 简介

MCP server that lets any AI agent use MandateEscrow on Arc: read mandates and reputation, and (opt-in) create, prove, release and refund them.
