# @tiktok-emojis/vue

> 标签: emojis, svg, tiktok, tiktok emojis, vue

## 简介

Complete TikTok emojis collection as Vue 3 components. 46 secret TikTok emojis (smile, happy, angry, etc.) with SVG rendering. Perfect for social media apps, chat interfaces, and engaging user content. Vue 3 compatible.
