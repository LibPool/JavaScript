# @deot/docs-dever

> 标签: JavaScript

## 简介

`@deot/docs-dever` 是 `doc` CLI 的运行层，负责 development、build 和 preview 三种模式，以及开发 runtime、原始资源响应、SSE、history fallback 和静态资源复制。
