# @friendofsvelte/progress

> 标签: JavaScript

## 简介

A **super smooth and customizable** **navigation progress bar** for **Svelte 5**, powered by: - **🌀 Svelte 5 Runes** (`$state`, `$derived`) - **🌊 svelte/motion** (`Tween`) - **🎨 TailwindCSS v4** - **🔮 tailwind-variants & tailwind-merge** for ultimate
