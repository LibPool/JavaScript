# @kombifyio/sites-knowledge

> 标签: JavaScript

## 简介

KnowledgeStore implementations for kombify Sites Framework' corpus tier, one package with sub-path exports: /sqlite-vec (Node zero-infra, FTS5 + vec0 + RRF hybrid), /vectorize (Cloudflare, namespace-per-site + shard router). Root export ships the chunking
