# @freerdp-bridge/api

> 标签: JavaScript

## 简介

Shared HTTP/WebSocket session API and reference browser assets for FreeRDP Browser Bridge. The `./fastify` export mounts the bridge on an existing server. Most applications should install `@freerdp-bridge/fastify`, which re-exports this integration.
