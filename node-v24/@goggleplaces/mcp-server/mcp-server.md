# @goggleplaces/mcp-server

> 标签: ai-agent, directions, geocoding, goggle-places, great-britain, maps, mcp, model-context-protocol, places, search

## 简介

Official Model Context Protocol (MCP) server for the Goggle Places API — predictive search, nearby, directions, address lookup and route sharing as MCP tools.
