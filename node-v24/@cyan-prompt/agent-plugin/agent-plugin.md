# @cyan-prompt/agent-plugin

> 标签: agent, archrompt, claude-code, codex, cyan-prompt, gemini-cli, mcp, model-context-protocol, opencode, sdk

## 简介

Cyan Agent Plugin — SDK and MCP server bridging external AI coding agents (Claude Code, Codex, OpenCode, Gemini CLI, Continue, Cline, Roo Code, Amp, and any MCP client) to the Cyan Prompt Agent Platform (cyan.v1.* API).
