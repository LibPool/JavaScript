# @atmo-dev/contrail-community

> 标签: atproto, community, contrail

## 简介

Community module for contrail — community-owned spaces with tiered access levels (member → moderator → admin), invite tokens, DID provisioning, and the access-level reconciler that keeps spaces_members in sync.
