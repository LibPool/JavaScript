# @maroonedog/waypoint

> 标签: form, forms, react, schema, standard-schema, typescript, validation, vue, zod

## 简介

A field's address exists before the component that draws it: typed paths the compiler has already checked and runtime state already written, with a contract any validator can describe itself through, resolvers and React and Vue bindings behind one install
