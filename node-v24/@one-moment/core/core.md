# @one-moment/core

> 标签: accessibility, aphasia, assemblyai, assistive-technology, speech-to-text, turn-taking, voice-agent

## 简介

The decision layer of a voice agent that waits: evidence from two listening streams, negation checks, Dissent, the Adjudicator, forced choices and the Floor Controller. Pure, no network, no I/O.
