# @edgemodders/edgemat-mcp

> 标签: cyberpunk2077, materials, mcp, mlsetup, modding, model-context-protocol, wolvenkit

## 简介

EDGEmat for AI assistants over MCP: find, describe and recolor Cyberpunk 2077 materials, and make new ones, with the material library built from your own game.
