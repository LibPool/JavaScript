# @edgemodders/edgedeck-mcp

> 标签: claude, cyberpunk, cyberpunk2077, mcp, mod manager, modding, model context protocol

## 简介

EDGEdeck's MCP server and command line: manage Cyberpunk 2077 mods (add, turn on or off, order, deploy, undo, conflicts, loadouts) from an AI assistant or a script.
