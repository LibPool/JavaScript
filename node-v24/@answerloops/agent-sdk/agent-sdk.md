# @answerloops/agent-sdk

> 标签: agent-api, answerloops, knowledge-base, mcp, support

## 简介

Typed client for the answerLoops Agent API (knowledge base search, FAQ, tickets, grounded answers) and a CLI to self-host answerLoops or install its Claude Code skills.

- 官网：https://answerloops.com/docs/integrations/agent-api
- 源码仓库：git+https://github.com/answerLoops/answerLoops.git
