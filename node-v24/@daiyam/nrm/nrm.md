# @daiyam/nrm

> 标签: NPM, registry

## 简介

NPM registry manager can help you easy and fast switch between different npm registries, now include: cnpm, taobao, nj(nodejitsu), edunpm

## 官网

- 官网：https://github.com/daiyam/nrm
- 源码仓库：git://github.com/daiyam/nrm.git
- npm 页面：https://www.npmjs.com/package/@daiyam/nrm
