# @movk/sigma

> 标签: composables, graph, graphology, knowledge-graph, network-visualization, nuxt, nuxt-module, nuxt4, sigma, sigmajs, vite, vue, webgl

## 简介

基于 sigma v4 的知识图谱可视化 Nuxt 模块：SigmaGraph 等声明式组件与 composables，覆盖渲染、交互、布局、分析与 DOM 覆盖层，面向 1000+ 节点的大规模图谱。
