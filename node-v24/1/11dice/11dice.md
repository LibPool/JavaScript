# 11dice

> 标签: fetch, free-proxy, load-test, proxies, proxy, proxy-pool, rate-limit, rotate, rotation, scraping, undici

## 简介

fetch with automatic rotating free proxies. Scrapes public proxy lists, validates them, and routes every request through a random working proxy. Proper defaults, works out of the box.
