# @blen/react-lighthouse-viewer

> 标签: lighthouse, lighthouse-report, lighthouse-viewer, pagespeed-insights, performance, react, web-vitals

## 简介

Show Lighthouse reports in React: analyze a website, load a saved report, or pass a report object. Uses the official Lighthouse report renderer.
