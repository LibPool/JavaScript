# chunked-uploader-client

> 标签: backoff, blob, chunked, chunking, fetch, file-upload, multipart, progress, resumable, retry, typescript, upload

## 简介

Dependency-free, typed resumable chunked upload client for the resumable/chunked-uploader PHP backend. Uses Blob.slice(), the Fetch API and FormData — no runtime dependencies.
