# @dauthau/mcp-dauthau

> 标签: anthropic, claude-code, dauthau, mcp, model-context-protocol

## 简介

Node.js MCP wrapper kết nối AI tool (Claude Code, Cursor, ...) tới dịch vụ tra cứu đấu thầu DauThau. Apisecret giữ local, ký hashsecret mỗi request.
