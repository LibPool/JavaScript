# @setsquare/ui

> 标签: a11y, accessibility, components, design-system, nextjs, react, react-aria, tailwindcss, wcag

## 简介

React Aria components, design tokens, a dashboard shell and a site shell, with a switch between WCAG 2.2 AA and AAA sizing, spacing and contrast.
