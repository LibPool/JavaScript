# @setsquare/ui-agent

> 标签: a11y, a2ui, accessibility, agent, generative-ui, llm, react, wcag

## 简介

UI an agent puts together and takes away: a Setsquare renderer for A2UI, which refuses a description that fails a check and tells the agent why.
