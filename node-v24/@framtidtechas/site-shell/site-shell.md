# @framtidtechas/site-shell

> 标签: cms, framtid, frontend, shell, site

## 简介

Gjenbrukbar frontend-skall for Framtid CMS — header, footer, list/article-renderere og document-card. Distribueres som pakke slik at kunder får oppdateringer via versjons-bump.
