# @mkostka/workit-camunda

> 标签: Camunda, Typescript, Ville de Montreal, Worker, Zeebe, open-telemetry

## 简介

Worker for Node.js system with pluggable Camunda clients that works with both Zeebe and Camunda platform powered by TypeScript
