# @xt230/dsh-ppt-master

> 标签: deepseek-harness, dsh-plugin, powerpoint, ppt-master, pptx, python, skill

## 简介

Declares a PPT Master agent preset (skill + interpreter tool, scoped to that preset) and manages the Python interpreter and projects root it runs with through the plugin's own Config
