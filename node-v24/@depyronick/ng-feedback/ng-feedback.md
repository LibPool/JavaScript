# @depyronick/ng-feedback

> 标签: angular6, directive, feedback, html2canvas, rxjs

## 简介

An angular directive for sending feedback featuring Angular 8, Html2canvas, Angular Material, Rxjs, inspired by Google send feedback, based on angular-cli.
