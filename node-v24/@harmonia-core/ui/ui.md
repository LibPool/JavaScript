# @harmonia-core/ui

> 标签: accessibility, adaptive-ui, capacity-adaptive, cognitive-load, design-tokens, motion, react, ui-framework

## 简介

A capacity-adaptive UI framework that treats human cognitive, temporal, and emotional state as first-class inputs. Derives interface modes (density, motion, contrast, focus) from explicit user state — no inference, no profiling.
