# @domoarigatomrburato/primeval

> 标签: approximation, browser, cli, generative-art, geometric, image, lqip, napi, placeholder, png, primitive, rust, shapes, svg, wasm, webassembly

## 简介

Approximate images with geometric shapes (triangles, ellipses, curves, polygons) and export SVG or PNG. Native Rust engine with a Node API and CLI, and a WebAssembly build for browsers.
