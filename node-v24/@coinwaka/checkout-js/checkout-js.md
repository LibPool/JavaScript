# @coinwaka/checkout-js

> 标签: browser, checkout, coinwaka, coinwaka-pay, crypto, kenya, mpesa, payments

## 简介

Browser checkout for Coinwaka Pay. Redirect to hosted checkout and poll payment status with a publishable key (M-Pesa, card, PayPal, crypto).
