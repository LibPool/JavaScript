# @coinwaka/cli

> 标签: cli, coinwaka, coinwaka-pay, kenya, mpesa, payments, webhooks

## 简介

Coinwaka Pay command-line tools: verify keys, trigger sandbox webhooks, and forward live events to your local server for webhook testing.
