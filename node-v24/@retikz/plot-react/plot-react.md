# @retikz/plot-react

> 标签: chart, grammar-of-graphics, plot, react, tikz, visualization

## 简介

React bindings for @retikz/plot: <Plot> (thin spec wrapper + composition DSL) lowering to @retikz/core via @retikz/react.
