# @chee/patchwork-transcript

> 标签: JavaScript

## 简介

Speech-to-text toolkit for Patchwork tools: a worker-backed in-browser ASR provider (transformers.js — Moonshine/Whisper, WebGPU→WASM) and an OpenAI-compatible /audio/transcriptions provider, behind one account-doc config resolvable per DOM subtree.
