# @henryavila/blink-tui

> 标签: blink, catppuccin, cli, ink, nerd-font, react, terminal, tui

## 简介

blink — a framework for building modern, elegant TUI apps. Catppuccin-themed Ink (React for the terminal) primitives, dual-mode Nerd Font glyphs, and a strict character-cell visual contract.
