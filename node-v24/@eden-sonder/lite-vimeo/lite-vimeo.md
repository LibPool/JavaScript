# @eden-sonder/lite-vimeo

> 标签: vimeo, web components

## 简介

A web component that loads Vimeo embed iframes faster. Extends Alex Russell (@slightlyoff)'s and KJ Roelke (@choctaw-nation)'s work to allow poster images.
