## 简介

Build approval-gated AI agents with the same primitives that power AZMX AI — BYOK provider router (Anthropic / OpenAI / any OpenAI-compatible incl. local REVA & Ollama), approval gate, deny-list, hash-chained audit log. Ships a headless `azmx` CLI. Secure
