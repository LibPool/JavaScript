# @chrono-os/health-nest

> 标签: chrono-os, coolify, health-check, liveness, nestjs, readiness

## 简介

Health check para NestJS: GET /health com checks de dependência (banco, Redis, heartbeat) em paralelo, timeout por check, 200 ok ou 503 degraded, sem vazar erro interno no corpo; GET /health/live para liveness.
