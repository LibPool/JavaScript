# @chrono-os/env-schema

> 标签: chrono-os, env, validation, zod

## 简介

Helpers Zod para validação de env vars em services Chrono — optionalStr/optionalUrl (string vazia vira undefined), requireIfPresent (regra condicional de segurança), parseEnvOrExit (boot Fastify) e validateForNest (ConfigModule.forRoot).
