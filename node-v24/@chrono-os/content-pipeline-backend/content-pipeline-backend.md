# @chrono-os/content-pipeline-backend

> 标签: JavaScript

## 简介

Fastify plugin + services Prisma do pipeline de produção de conteúdo Chrono. Interfaces plugáveis: ContentImageEngine, PublisherAdapter, MetricsCollector, Validator. Inclui prisma/schema.template.prisma (6 models) e CLI 'content-pipeline'.
