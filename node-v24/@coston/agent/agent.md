# @coston/agent

> 标签: agent, ai, chat, copilot, llm, mcp, vercel-ai-sdk

## 简介

Reusable, standards-first agent-chat module — a thin wiring layer over the Vercel AI SDK and MCP for building app-scoped LLM copilots.
