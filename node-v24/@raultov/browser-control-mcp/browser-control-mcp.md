# @raultov/browser-control-mcp

> 标签: browser, command-line-utilities, debugging, development-tools::debugging, devtools, firefox, mcp, web-programming

## 简介

MCP server to control and debug Chrome and Firefox at runtime: breakpoints, call frames and stepping over CDP and WebDriver BiDi/RDP, plus navigation, DOM, input, screenshots, console and network capture.
