# @wenaixi/cfbridge

> 标签: bundle, cloudflare, cordis, deepseek-harness, dsh, dsh-bundle, mcp, skill

## 简介

Cloudflare Code Mode MCP 全局 Bundle，安装后所有 DSH 会话自动获得 docs/search/execute 三工具与 cfbridge Skill，配合项目本地 Wrangler CLI 透传。
