# @oldsuns/opencode-branch-session

> 标签: branch, git, guard, opencode, opencode-plugin, protection, safety

## 简介

Stateless branch guard for OpenCode: blocks file writes and dangerous git on protected branches (main/master), guides agents to work on feature branches, drives merges through the /finish-branch wrap-up command.
