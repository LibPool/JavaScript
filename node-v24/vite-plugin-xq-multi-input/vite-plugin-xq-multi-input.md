# vite-plugin-xq-multi-input

> 标签: JavaScript

## 简介

A vite plugin that scans html files under entry directories and auto-configures multiple html inputs.一个根据入口目录扫描 html 文件并自动配置多个 html 入口的 Vite 插件。
