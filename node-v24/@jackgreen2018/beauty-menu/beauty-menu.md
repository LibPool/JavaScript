# @jackgreen2018/beauty-menu

> 标签: JavaScript

## 简介

A lightweight, high-performance beauty service menu generator that runs entirely in the browser or Node.js via Rust/WASM. No server required, no file uploads — 100% client-side with Rust-level speed.
