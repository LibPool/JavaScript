# @openmirai/intl-runtime

> 标签: JavaScript

## 简介

Runtime primitives for loading, validating, formatting, and recovering Mirai Intl catalogs. This package is intended for advanced integrations and is used by [`@openmirai/intl-i18next`](https://www.npmjs.com/package/@openmirai/intl-i18next).
