# @mynameistito/opencode-force-input

> 标签: ctrl-enter, ctrl-return, force-submit, interrupt, keyboard-shortcuts, opencode, opencode-plugin, prompt, tui

## 简介

OpenCode TUI plugin that interrupts the active run and submits the prompt with Ctrl+Enter.
