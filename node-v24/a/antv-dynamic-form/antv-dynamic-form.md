# antv-dynamic-form

> 标签: JavaScript

## 简介

基于[antv](https://www.antdv.com) 的动态表单。 在完整支持的表单组件下，拓展支持了颜色Color、旋转角度Angle、代码编辑Monaco、富文本编辑RichText、JSON编辑器、MarkDown编辑器
