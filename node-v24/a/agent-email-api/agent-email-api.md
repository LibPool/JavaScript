# agent-email-api

> 标签: agent email api, ai agent, autonomous email, courier, email api, inbox api, otp, receive email, temporary email, verification

## 简介

Agent email API. REST API for AI agents to receive OTP codes, magic links, and verification emails. No signup. No OAuth. No Gmail API.
