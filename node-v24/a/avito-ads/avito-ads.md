# avito-ads

> 标签: api, avito, avito-ads, client, sdk, typescript, реклама

## 简介

TypeScript SDK для публичного API кабинета Авито Реклама (Avito Ads). Без рантайм-зависимостей, работает в Node.js 18+, Deno, Bun и serverless.
