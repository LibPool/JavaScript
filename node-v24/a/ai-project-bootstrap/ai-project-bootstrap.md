# ai-project-bootstrap

> 标签: ai, boilerplate, claude, cursor, developer-experience, generator, scaffolding

## 简介

Generate and maintain an AI-assisted dev environment tailored to your stack: rules for Cursor, Claude Code and 6 more AI tools, docs, prompts, cost estimates and starter templates, plus check, review, analyze, implement, doctor and upgrade commands.
