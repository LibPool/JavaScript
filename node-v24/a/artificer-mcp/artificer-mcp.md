> 标签: ai-generation, content-generation, creative-media, ffmpeg, gemini, image-generation, imagemagick, mcp, model-context-protocol, nano-banana, veo, video-generation

## 简介

Public MCP for AI-powered creative media generation and processing — image gen (Gemini/Nano Banana), video gen (Veo), image/video/audio post-processing (ImageMagick + FFmpeg), pluggable storage, and opinionated creative workflows
