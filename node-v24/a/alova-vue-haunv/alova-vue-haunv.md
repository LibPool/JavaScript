# alova-vue-haunv

> 标签: alova, api, axios-alternative, http, vite, vue-cli, vue3

## 简介

Alova HTTP client wrapper for Vue 3 — automatically binds apiGet/apiPost/apiPut/apiDelete to the global scope.
