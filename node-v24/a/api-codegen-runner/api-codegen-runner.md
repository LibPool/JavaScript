# api-codegen-runner

> 标签: api, apifox, axios, cli, codegen, ejs, fetch, generator, openapi, swagger, template, typescript, vite-plugin

## 简介

A powerful and flexible API code generator runner supporting OpenAPI, Swagger, and Apifox specifications, with customizable templates and integration for TypeScript, Axios, Fetch, EJS, and Vite.
