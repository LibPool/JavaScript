# agentstack-skills

> 标签: agentstack, ai-agents, claude-code, installer, skills

## 简介

One-line installer for the agentstack Claude Code skills. Run `npx agentstack-skills` to install all eight slash commands plus the root dispatcher to ~/.claude/skills/.
