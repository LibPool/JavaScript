# athleticstandard

> 标签: ai-agents, apple-health, athletic-standard, crossfit, file-format, hrv, hyrox, json-schema, local-first, oura, recovery, training, triathlon, wearables, whoop

## 简介

An open, local-first file format for an athlete's training and recovery data, built for AI agents to read. Device measurements and self-reported notes stay separate.
