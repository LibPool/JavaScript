# aio-terminal

> 标签: ai, claude, cli, codex, deepseek, gemini, kimi, router, terminal

## 简介

All-in-one AI terminal manager — a persistent conductor that delegates each task to the AI worker best suited for it, using the CLIs/subscriptions you already have (Claude Code, Codex CLI, Gemini CLI, Kimi Code CLI) plus cheap APIs (DeepSeek, Gemini API).
