# arcasha-router

> 标签: arcasha, bandit, belief, contextual-bandit, linucb, llm, routing

## 简介

Observation-Driven Adaptive Routing (ODAR) — belief-driven routing engine for heterogeneous LLM pools. LinUCB-Shadow with Bayesian belief features. Pure TypeScript, works in Node/WebGPU/edge.
