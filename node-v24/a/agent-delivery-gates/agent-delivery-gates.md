# agent-delivery-gates

> 标签: ai-agent, cli, code-review, csharp, delivery-gate, git-hooks, go, java, mcp-server, mutation-testing, php, prose-lint, python, ruby, rust, test-diff, tree-sitter

## 简介

Delivery gates for AI coding agents: breaks your code on purpose and reports the breaks no test noticed. Seven languages via tree-sitter, on Windows, macOS and Linux. Git hook, CI step or MCP server.
