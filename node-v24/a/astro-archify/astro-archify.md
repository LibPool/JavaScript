# astro-archify

> 标签: archify, architecture, astro, astro-integration, diagrams, markdown, sequence-diagram, system-design, utility, withastro

## 简介

An Astro integration that renders Archify system diagrams (architecture, workflow, sequence, dataflow, lifecycle) from JSON IR code blocks at build time, with Archify's renderer bundled in
