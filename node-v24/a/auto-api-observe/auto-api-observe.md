## 简介

Zero-config observability for Node.js APIs — Express, Fastify, Koa, Hono, NestJS, Next.js, Hapi, Elysia, Apollo, Lambda, tRPC, Restify. Request tracing, DB profiling, slow-request detection, and real-time metrics.
