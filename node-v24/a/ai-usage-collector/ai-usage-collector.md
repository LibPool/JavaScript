# ai-usage-collector

> 标签: JavaScript

## 简介

Totals-only usage collector for AI coding tools (Codex, Claude, Grok, OpenCode, Antigravity). Reads local session files, uploads per-day token/cost totals. Prompts and file contents never leave the PC.
