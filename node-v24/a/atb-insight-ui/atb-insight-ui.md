# atb-insight-ui

> 标签: atb-explorer, atbcoin, atbcore, blockchain, blockexplorer, front-end, insight

## 简介

An open-source frontend for the ATB Insight API. The Insight API provides you with a convenient, powerful and simple way to query and broadcast data on the atbcoin network and build your own services with it.
