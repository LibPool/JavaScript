# autostack-ai

> 标签: ai, backend, boilerplate, cli, express, generator, jwt, oauth, scaffold, websocket

## 简介

Scaffold a production-ready Node.js + Express backend (JWT auth, Google OAuth, WebSockets, Email) with one command — plus an AI-powered command to generate new backend features on demand.
