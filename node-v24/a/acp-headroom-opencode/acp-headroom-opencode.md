# acp-headroom-opencode

> 标签: ccr, context-compression, headroom, llm, opencode, opencode-plugin, tokens

## 简介

Headroom tool-output compression for OpenCode — compresses oversized tool results via a local Headroom proxy and lets the model retrieve originals back by hash.
