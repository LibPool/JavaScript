# apollo-server-plugin-landing-page-customizer

> 标签: ApolloServerPluginLandingPageLocalDefault, ApolloServerPluginLandingPageProductionDefault, apollo, graphql, landing, page, plugin

## 简介

Wraps the @apollo/server ApolloServerPluginLandingPage* plugins to enable further customization, e.g. setting the title and favicon in the rendered HTML
