# apifox-openapi-codegen

> 标签: apifox, codegen, openapi, react-query, typescript

## 简介

从 Apifox 拉取 OpenAPI 并自动生成 `types.ts`、`client.ts`、`hooks.ts` 等文件。

## 官网

- npm 页面：https://www.npmjs.com/package/apifox-openapi-codegen

## 历史版本号

- 0.1.0

## 获取地址

- npm 安装：`npm install apifox-openapi-codegen`
- npm registry：https://registry.npmjs.org/apifox-openapi-codegen
- Node 要求：>=18
