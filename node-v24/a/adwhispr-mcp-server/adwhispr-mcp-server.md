# adwhispr-mcp-server

> 标签: ad-cloning, ad-intelligence, ad-library, ad-spy, adwhispr, anthropic, campaign-launch, claude, claude-desktop, competitor-research, facebook-ads, google-ads, marketing, mcp, meta-ads, model-context-protocol, performance-max, ppc, tiktok-ads

## 简介

Connect Claude to AdWhispr — research any brand's ads (Meta + TikTok), surface their longest-running winners, clone the creative as an image or video for your brand, and launch it on Google, TikTok, or Meta. 38 tools, one-command setup for Claude Desktop.
