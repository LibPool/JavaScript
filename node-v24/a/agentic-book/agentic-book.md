# agentic-book

> 标签: availability, booking-preview, cal.com, calcom, calendar-api, calendly, cli, freebusy, google-calendar, mcp, meeting-booking, nodejs, scheduling, typescript

## 简介

Calendar API wrapper for Node.js with Google Calendar and Cal.com booking requests, Calendly availability requests, CLI, MCP, and offline previews.
