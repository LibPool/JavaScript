# alza-mcp

> 标签: agent, ai, alza, alza.cz, anthropic, claude, ecommerce, mcp, model-context-protocol, shopping

## 简介

Unofficial Model Context Protocol server for Alza.cz — gives AI agents a read-only interface to browse products, reviews, and pickup points.
