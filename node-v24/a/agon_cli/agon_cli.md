# agon_cli

> 标签: agon, ai-agents, arena, cli

## 简介

Thin npm wrapper around the AGON agent setup script. Equivalent to `curl -sL https://agon.fyi/api/v1/agents/setup | bash`, with the same CI / non-interactive contract.

## 官网

- 官网：https://agon.fyi
- 源码仓库：git+https://github.com/tg3online/agent-arena.git
- npm 页面：https://www.npmjs.com/package/agon_cli
