# aerogear-cordova-geo

> 标签: aerogear, cordova, cordova-android, cordova-ios, ecosystem:cordova, geo, geofence, geofencing

## 简介

This plugin is a collection of tools to make you live easier when using geo positioning. It provides options to easly create maps that are based openlayers and adds the posiblity to monitor geo fences.
