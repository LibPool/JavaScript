# agent-control-tower

> 标签: agent-monitoring, ai-agents, claude-code, cron, dashboard, dead-mans-switch, github-actions, github-pages, llm, observability

## 简介

A dead-man's switch and dashboard for AI agents that run unattended (Claude Code scheduled tasks, GitHub Actions, cron). No server: JSONL in git + a static page.
