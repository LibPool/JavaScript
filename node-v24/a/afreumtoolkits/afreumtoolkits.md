# afreumtoolkits

> 标签: afreum, blockchain, geo, official, sdk, stellar, tokens, toolkit

## 简介

Official Afreum developer toolkit/SDK for the Afreum Ecosystem public JSON data (tokens, geo, logos) on the Stellar chain.
