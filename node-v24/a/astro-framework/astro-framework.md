# astro-framework

> 标签: AKFW, Astro-Framework, Astro-css-Framework, lightweight-css-framework, optimized-css-framework, simple-css-framework

## 简介

Astro framework is simple, lightweight yet powerful css framework for your day-to-day projects, which includes basic rules, pre-defined classes, highly optimized and many more
