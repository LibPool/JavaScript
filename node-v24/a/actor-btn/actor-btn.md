# actor-btn

> 标签: Angular, Button Loader, Button Spinner

## 简介

This is a lightweight library developed using latest Angular 9 to show or hide loader on button or disable it when we are doing some asynchronous task.  [StackBlitz Demo](https://stackblitz.com/edit/actor-btn)
