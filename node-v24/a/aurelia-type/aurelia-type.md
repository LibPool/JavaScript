# aurelia-type

> 标签: aurelia, css, html, tailwind, tailwindcss, typography

## 简介

An **aurelia-type** plugin that automatically applies elegant, well-crafted typographic defaults to plain HTML content, making text-rich pages look polished with minimal configuration.
