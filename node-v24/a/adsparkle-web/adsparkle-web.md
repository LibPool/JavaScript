# adsparkle-web

> 标签: adsparkle, affiliate, analytics, attribution, conversion, pixel, postback, tracking

## 简介

Browser SDK for the AdSparkle affiliate attribution tracking platform. GA/Pixel-style click capture + conversion postbacks. Zero dependencies, UMD, ~10 kB.
