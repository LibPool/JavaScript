# algolia-index

> 标签: algolia, astro, cli, gatsby, index, indexing, library, markdown, mdx, nextjs, search, static-site

## 简介

A powerful Node.js CLI tool and library for indexing Markdown, MDX, and JSON files to Algolia. Perfect for static sites built with Astro, Vitepress, Gatsby, Next.js, or any static site generator.
