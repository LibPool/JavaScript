# aware-server

> 标签: JavaScript

## 简介

This AWARE Server is used for coordinating studies and storing/retriving their data into/from a MySQL database. If you have not yet setup your MySQL server setup, you should do that before following this guideline [here](/doc/mysql-ndb.md)
