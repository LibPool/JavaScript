# axe-devtools-mcp

> 标签: a11y, accessibility, axe-core, claude, claude-code, mcp, model-context-protocol, playwright, wcag

## 简介

MCP server that runs axe-core accessibility scans (via Playwright) on URLs and HTML, for use with Claude Code and other MCP clients.
