# antelope-ecc

> 标签: antelope, blockchain, cryptography, ecc, ecdsa, eosio, esm, isomorphic, javascript, keys, secp256k1, signature, typescript

## 简介

A universal JavaScript and TypeScript ECC signing and key utility library for Antelope-based blockchains.
