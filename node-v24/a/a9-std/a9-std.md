# a9-std

> 标签: adt, algebraic-data-types, deno, deserialization, discriminated-union, json, prototype, serialization, tagged-union, typescript

## 简介

Minimal TypeScript library for JSON serialization that preserves prototypes and methods using UUID-tagged discriminated unions
