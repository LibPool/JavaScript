# auto-boiler

> 标签: auto-generate, automation, boilerplate, code-generation, developer-tool, file-template, file-watcher, js, productivity, react, template, typescript

## 简介

A simple file watcher that automatically adds boilerplate code to new files. Supports multiple file types like JS, JSX, TS, TSX, and more. Just run it in the background and save time writing repetitive code!
