# appdrop-maker

> 标签: android, apk, appdrop, capacitor, ionic, react-native, release

## 简介

Le maker d'AppDrop : construit, signe, relit et publie l'APK release d'un projet Ionic/Capacitor ou React Native sur un serveur AppDrop.
