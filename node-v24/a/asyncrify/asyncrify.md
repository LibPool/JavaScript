# asyncrify

> 标签: async, await, concurrency, concurrent, limit, list, max, promise, promises, queue, retries, retry, throttle, timeout, timeouts, wait

## 简介

A simple queue for executing promises concurrently. You can set timeouts, max concurrency as well as retries
