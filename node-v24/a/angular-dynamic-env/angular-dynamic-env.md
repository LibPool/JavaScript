# angular-dynamic-env

> 标签: Angular, docker, dynamic env, dynamic environment, front-end, javascript

## 简介

This library was generated with [Angular CLI](https://github.com/angular/angular-cli) version 14.1.0. \ It provides a service to dynamically load and get `.env` file after build.
