# arabic-native-localization

> 标签: agent-skill, arabic, claude, claude-code, claude-skill, i18n, l10n, localization, next-intl, rtl, translation

## 简介

Claude skill that writes natural, native-quality Arabic UI copy (locale files, buttons, errors, empty states, RTL) instead of literal translations. Install into ~/.claude/skills via npx.
