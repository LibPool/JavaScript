# aamio-wasm

> 标签: aamio, agents, ed25519, mcp, nacl, proof-of-work, wasm, webassembly

## 简介

The aamio protocol core in WebAssembly, compiled from the Rust client: proof of work as one call, and the same keys, signing, sealing and canonical gate. No transport.
