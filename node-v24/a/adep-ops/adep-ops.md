# adep-ops

> 标签: 1panel, acme, adep, custom-domain, openresty, tls

## 简介

adep 自建部署的边缘侧运维工具：任意第三方域名/自定义 CNAME 的证书签发与 vhost 接入、与平台库对账的自动接入守护、域名校验失败现场自检、装机与体检（面向 1panel + openresty 的部署）
