# agentainer

> 标签: agentic, agents, ai, ai-agents, claude, claude-code, codex, gemini, hermes, llm, mailbox, multi-agent, orchestration, prompt-routing, python, tmux

## 简介

Zero-dependency multi-agent orchestrator with a file-based mail model for AI coding agents (Claude Code, Codex, Gemini, Hermes). Agents talk by reading and writing files; the orchestrator routes the mail.
