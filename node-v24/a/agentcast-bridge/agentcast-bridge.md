# agentcast-bridge

> 标签: acp, agent, agent-client-protocol, bridge, claude-code, codex, coding-agent, opencode, websocket

## 简介

把 stdio-only 的 ACP (Agent Client Protocol) agent 暴露成 WebSocket 服务，供 Agent Cast 鸿蒙客户端远程连接

- 官网：https://github.com/atbeta/agent-cast/tree/main/bridge
- 源码仓库：git+https://github.com/atbeta/agent-cast.git
- npm 页面：https://www.npmjs.com/package/agentcast-bridge

- npm registry：https://registry.npmjs.org/agentcast-bridge
- Node 要求：>=18
