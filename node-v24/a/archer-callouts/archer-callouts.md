# archer-callouts

> 标签: JavaScript

## 简介

The **archer-callouts.js** is a small javascript library for easily creating fancy callout elements.  Basically, designed for the use in archer graphics it is completely independent from the archer-graphics.js library and can be used by its own in any htm
