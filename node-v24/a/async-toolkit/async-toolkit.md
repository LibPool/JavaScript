# async-toolkit

> 标签: async, await, backoff, cjs, concurrency, defer, deferred, delay, esm, p-limit, p-map, promise, retry, sleep, timeout, toolkit, typescript

## 简介

Zero-dependency async toolkit for TypeScript — retry, timeout, pLimit, pMap, sleep, defer & error-as-value. Tree-shakeable, ESM + CJS.
