# agent-screen-observer

> 标签: ai-agent, flaky-tests, mcp, playwright, qa, screenshot, testing, toast-detection, visual-testing

## 简介

Watches the screen while an AI agent or test drives a UI, and reports visual events (toasts, transient screens, layout shifts, animated regions) as compact text with on-demand image evidence.
