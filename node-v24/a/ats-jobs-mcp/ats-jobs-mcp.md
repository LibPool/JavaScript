# ats-jobs-mcp

> 标签: ashby, ats, greenhouse, hiring, jobs, lever, mcp, model-context-protocol, recruiting, smartrecruiters, teamtailor, workable

## 简介

MCP server for job data and hiring change detection across Greenhouse, Lever, Ashby, Workable, Teamtailor and SmartRecruiters. Give it a company domain, it finds the board itself.
