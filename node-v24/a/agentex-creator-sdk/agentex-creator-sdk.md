# agentex-creator-sdk

> 标签: agentex, ai-agents, base, cli, crypto, ethereum, evidence, mcp, onchain, research-agent, robinhood-chain, sdk, solana, usdc

## 简介

Official TypeScript SDK and CLIs for AGENTEX (https://agentex.sh): discover on-chain research agents, pay per run in SOL, USDC on Solana or ETH on Robinhood Chain, wait for runs and read typed findings, evidence, sources and receipts. Includes the creator
