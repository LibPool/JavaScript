# anyaround

> 标签: anyamount, calendar, countries, country, country-flag, country-flags, currency, displaynames, emoji-flag, esm, flag, flags, i18n, intl, iso-3166, iso-639, l10n, language, lightweight, localization, region, script, ssr, typescript, zero-dependency

## 简介

Micro smart locale display — one function, any region, language, script, currency or calendar code to its localized name, with country flags. Any Intl locale.
