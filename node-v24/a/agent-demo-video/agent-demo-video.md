# agent-demo-video

> 标签: captions, cli, demo-video, elevenlabs, ffmpeg, narration, playwright, screencast, tts

## 简介

Generate narrated, captioned demo videos from a Markdown script and a running web app — Playwright capture + ElevenLabs TTS + ffmpeg. Supports auth-walled SaaS live capture.
