# array-xor

> 标签: complements, diff, difference, disjunction, elements, exclusive, exclusive-or, intersection, or, predicate, relative, set, sets, symmetric, union, xor

## 简介

Returns the symmetric difference (exclusive-or) of an array of elements (elements that are present in all given arrays and not in their intersections).
