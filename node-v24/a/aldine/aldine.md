# aldine

> 标签: collaboration, latex, overleaf-alternative, self-hosted

## 简介

Aldine — slim, self-hosted, open-source LaTeX collaboration (an Overleaf alternative). This package name is reserved for the Aldine project; the app itself ships as Docker images.
