# ai-handoff-mcp

> 标签: agent-handoff, ai-agents, claude-code, github-copilot, mcp, mcp-server, model-context-protocol, vscode

## 简介

Local-first MCP server that lets one AI coding agent (Claude, Copilot, Cursor, ...) continue another agent's task from its last checkpoint
