# auto-vhost-xampp

> 标签: apache, cli, vhost, virtualhost, windows, xampp

## 简介

CLI to auto-create Apache virtual hosts for XAMPP on Windows: adds a hosts entry, writes the VirtualHost block, and restarts Apache.

## 官网

- npm 页面：https://www.npmjs.com/package/auto-vhost-xampp

- npm registry：https://registry.npmjs.org/auto-vhost-xampp
- Node 要求：>=14
