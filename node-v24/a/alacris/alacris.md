# alacris

> 标签: alacris, context, custom-elements, esm, fine-grained, no-virtual-dom, reactive, signals, store, template, tiny, web-components

## 简介

Fast web components with signals and fine-grained DOM updates. 6.5 kB, ESM-only, zero dependencies, no build step.
