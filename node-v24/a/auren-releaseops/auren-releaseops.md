# auren-releaseops

> 标签: cli, deployment, devops, git, release, supabase

## 简介

Local-first release operations CLI: ZIP intake, sync, checks, git, Supabase migrations, rollback, and release-doc generation, with an explicit approval gate before anything writes or pushes.
