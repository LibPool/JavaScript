# asma-ui-core

> 标签: JavaScript

## 简介

The ASMA design system — the shared React component library that ASMA frontends build their UI from. Form controls, selects and comboboxes, dialogs, menus, tooltips, tables, date/time pickers, ~180 icons, and the colour and typography tokens behind them.
