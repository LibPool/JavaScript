# ai-chat-element

> 标签: ai, angular, anthropic, chat, chatbot, custom-element, lit, llm, openai, react, streaming, vue, web-component

## 简介

A reusable, framework-agnostic AI chat UI as a Web Component. Works in React, Angular, Vue, and vanilla JS. Pluggable transport with built-in adapters for OpenAI-compatible and Anthropic APIs.
