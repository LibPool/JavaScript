> 标签: agent-skills, agents, archflow, archflowai, claude-code, codex, copilot, cursor, gemini, opencode

## 简介

Archflow, the phase-based AI development framework: `npx archflow install` sets it up in a project for Claude Code, OpenAI Codex, GitHub Copilot CLI, Cursor, Gemini CLI, OpenCode, or any AGENTS.md + Agent Skills host.
