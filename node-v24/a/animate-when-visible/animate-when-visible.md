# animate-when-visible

> 标签: animate, animation, animation-classes, css-animations, intersection-observer, scroll, staggered-animation, viewport, visibility, visible-elements

## 简介

A tiny (2KB), no-dependency JavaScript module that adds classes to elements when they become visible, letting you control animations with CSS.
