# awsmap

> 标签: aws, buckets, cli, ec2, elb, grep, instances, list, map, multiple, s3, scan

## 简介

Quickly list EC2 instances, S3 buckets or Elastic Load Balancers created across all configured AWS accounts at once. grep friendly.
