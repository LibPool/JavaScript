# arbr-audit

> 标签: ai, anthropic, audit, cli, control-plane, cost, llm, openai

## 简介

Audit a log of past LLM requests for premium-model overuse, or wrap a coding agent live to see what a session costs, with zero server, zero database, and zero signup.
