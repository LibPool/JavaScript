# angular-fix-header-grid

> 标签: Angular, Angular 17, Angular 4, Angular 5, Angular 6, Angular 7, Grid, fix header

## 简介

It is a simple grid with all basic feature. It's header is fixed and body is scrollable. For hierarchical data (where there is a Parent-Child relationship), check out this <a href="https://github.com/debabratapatra/angular-tree-grid">Angular Tree Grid</a>
