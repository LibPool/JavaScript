# activitysmith-cli

> 标签: activitysmith, api, app-icon-badge, automation, cli, deployment, live-activities, logging, logs, monitoring, observability, publishing, push-notifications, reporting, tracking

## 简介

Command-line interface for ActivitySmith. Send Push Notifications, start, update, and end Live Activities, and set App Icon Badge Counts from your terminal.
