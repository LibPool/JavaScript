# ai-consensus-core

> 标签: ai, anthropic, consensus, cvp, debate, entropyvortex, grok, llm, mcp, multi-agent, openai, roundtable

## 简介

Dependency-light TypeScript implementation of the Consensus Validation Protocol (CVP): multi-model debate with confidence-weighted scoring, disagreement detection, and optional judge synthesis.
