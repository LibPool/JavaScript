# agent-hop

> 标签: agent-harness, agent-runtime, ai-coding, claude-code, cli, codex, coding-agents, cross-agent, developer-tools, grok, hybrid-search, local-first, opencode, pi, pty, runtime, rust, semantic-search, session-search, terminal

## 简介

Runtime for coding-agent harnesses. Run Claude Code, Codex, OpenCode, Pi, and Grok in one terminal, hop a live session between them, and search or resume any local chat.
