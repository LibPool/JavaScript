# auravms-mcp

> 标签: auravms, mcp, modelcontextprotocol, procurement, purchasing, quotes, rfq, supplier

## 简介

MCP server for AuraVMS — run RFQ/procurement cycles from any MCP-capable agent: add suppliers, create and send RFQs, pull quotes with L1/L2/L3 ranking, place orders, close out.
