# audiencescore-mcp

> 标签: audiencescore, mcp, model-context-protocol, reputation, reviews, trust, verified-reviews

## 简介

Connect any MCP client to AudienceScore — verified-review trust scores gated by cryptographic proof of purchase. Stdio bridge to the hosted read API.
