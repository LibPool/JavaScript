# agently-mcp

> 标签: a2a, agent, agently, agently-mcp, ai, discovery, mcp, model-context-protocol

## 简介

A Model Context Protocol (MCP) server providing a 'fetch_agents' tool to discover public A2A agents on the Agently platform via its public API.
