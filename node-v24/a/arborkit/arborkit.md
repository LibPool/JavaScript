# arborkit

> 标签: ag-ui, agents, artifact, blackboard, event-sourcing, json-patch, json-tree, llm, multi-agent, semantic-search, shared-state, time-travel

## 简介

A versioned, searchable JSON workspace for AI agents: scoped edits, semantic discovery, audit history, time-travel, and delta persistence.
