# axi-drag-ui

> 标签: JavaScript

## 简介

本项目是一个基于 Vue 3 + Vite 的低代码视觉设计器，专注于按钮组件的设计和样式定制。最新版本对按钮样式进行了全面改进，提供了丰富的视觉效果和交互体验。
