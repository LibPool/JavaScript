# apple-silicon-metrics

> 标签: apple-silicon, cpu, gpu, m1, m2, m3, m4, m5, macmon, macos, metrics, monitoring, napi, power, temperature

## 简介

Sudo-less Apple Silicon hardware metrics (CPU/GPU/RAM, temperature, power) for Node & TypeScript, backed by the Rust macmon crate.
