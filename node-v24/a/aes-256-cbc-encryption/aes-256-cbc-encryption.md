# aes-256-cbc-encryption

> 标签: aes, aes-256-cbc-encryption, decrypt, encrypt

## 简介

This Node.js module provides robust and secure functions for encrypting and decrypting text using the AES-256-CBC (Advanced Encryption Standard with 256-bit key size in Cipher Block Chaining mode) algorithm.
