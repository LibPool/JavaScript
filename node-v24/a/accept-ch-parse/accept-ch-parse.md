> 标签: accept-ch, client-hints, header, http, parser, responsive-images, rfc8942

## 简介

Zero-dependency parser for the HTTP Accept-CH Client Hints header (RFC 8942) for Node.js (>=18, ESM+CJS) and Python (>=3.11)
