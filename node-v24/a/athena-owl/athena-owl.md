# athena-owl

> 标签: agent, athena, indexer, language-server, llm, lsp, mcp, multi-language, semantic, sqlite, tree-sitter

## 简介

Athena-Owl (玲纳 Lingna): 希腊智慧女神雅典娜之猫头鹰 —— 多语言代码语义 MCP 服务器：语言服务器、Tree-sitter AST 与 SQLite 索引，缓存优先的符号读取与自愈的 LSP 生命周期。
