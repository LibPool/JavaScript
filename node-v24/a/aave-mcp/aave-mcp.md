> 标签: aave, aave-v3, anthropic, arbitrum, base, claude, defi, ethereum, lending, mcp, model-context-protocol, optimism, polygon, portfolio

## 简介

MCP server that monitors AAVE v3 positions on every chain where the protocol is live, via direct RPC reads. Chain list is derived dynamically from @bgd-labs/aave-address-book and updates automatically when AAVE governance approves new deployments. Read-on
