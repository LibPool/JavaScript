# atlas-tools-mcp-server

> 标签: JavaScript

## 简介

Atlas GIS MCP 工具集由 DataV 团队打造，专为大模型智能处理地理空间数据所设计，包含地理编码、路径规划、空间数据生成与处理、行政区划解析等常见 GIS 工具。
