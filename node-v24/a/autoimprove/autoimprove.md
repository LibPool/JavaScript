# autoimprove

> 标签: agent, coding-agents, deepwork, prompt-optimization, skill-optimization, skills

## 简介

Train portable markdown skills for coding agents from your workflows and sessions. An embeddable TypeScript implementation of the SkillOpt-style training loop.
