# agent-uplink

> 标签: agents, claude, claude-code, local, mcp, mcp-server, messaging, model-context-protocol, multi-agent

## 简介

Local messaging between AI coding sessions (Claude Code, Claude Desktop): role accounts, DMs, and shared channels through an MCP server and a local hub. Windows only.
