# aiand-router

> 标签: aiand, anthropic, claude, claude-code, llm-router, pi, pi-package, router

## 简介

One-command installer that points Claude Code, Codex, opencode, or pi at the Aiand Router. For pi it also ships the routing extension, loaded via pi.extensions.

- 官网：https://aiand.ai
