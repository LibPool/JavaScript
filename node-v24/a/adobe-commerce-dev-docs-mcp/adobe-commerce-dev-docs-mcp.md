## 简介

MCP server for Adobe Commerce / Magento 2 developer documentation. Gives AI assistants (Claude, Cursor, Cline, Windsurf) direct access to developer.adobe.com/commerce — PHP modules, GraphQL, REST API, PWA Studio, App Builder, extensibility, MFTF testing,
