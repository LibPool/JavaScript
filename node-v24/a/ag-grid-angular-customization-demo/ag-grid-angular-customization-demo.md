# ag-grid-angular-customization-demo

> 标签: angular-component, data, grid, js, table

## 简介

It's a 10 minute guide with examples that shows how to customize ag-Grid. I'll show you how to implement and integrate custom filtering logic, cell editor and celll renderer.
