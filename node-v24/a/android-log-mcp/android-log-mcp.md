# android-log-mcp

> 标签: adb, android, claude, codex, cursor, logcat, mcp, model-context-protocol

## 简介

MCP stdio server that gives AI agents (Claude Code, Codex, Cursor) read-only access to Android logcat: background recording, Android Studio filter syntax, crash/ANR grouping, app launch timelines.
