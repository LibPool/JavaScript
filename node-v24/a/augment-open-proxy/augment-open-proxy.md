# augment-open-proxy

> 标签: anthropic, augment, claude, claude-code, continue, cursor, llm, openai, proxy

## 简介

HTTP proxy that lets OpenAI- and Anthropic-compatible clients (Claude Code, Cursor, Continue) talk to the Augment backend via the Augment SDK.
