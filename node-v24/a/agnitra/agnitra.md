# agnitra

> 标签: agnitra, huggingface, inference, llm, optimization, pytorch

## 简介

TypeScript HTTP client for the Agnitra inference-optimization API. The optimizer itself is Python-only; this package lets browser and Node.js apps call a hosted Agnitra service.
