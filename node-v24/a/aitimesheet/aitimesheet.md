# aitimesheet

> 标签: ai-agents, claude-code, cli, local-first, observability, privacy, timesheet, tokens, usage-tracking

## 简介

Local, private timesheet for Claude Code agents: sessions run, tasks done, tokens used. Reads only from ~/.claude/projects on your own machine, nothing leaves it.
