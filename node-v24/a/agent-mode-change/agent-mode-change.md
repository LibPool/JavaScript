## 简介

Agent-mode floating window for DeepSeek Harness (dsh): switch a session's system prompt between the harness's own prompt and 13 archived coding-agent CLI prompts (Claude Code, Codex CLI, Antigravity, Grok, Kimi, MiniMax, opencode, Pi…) from a draggable We
