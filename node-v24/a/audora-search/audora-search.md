# audora-search

> 标签: audora, audora-search, fuzzy search library, fuzzy-search-js, search

## 简介

A lightweight and flexible fuzzy search library for JavaScript. Easily perform approximate string matching on arrays of strings or objects, with customizable thresholds and instant results. Perfect for search bars, autocomplete, and suggestion features.
