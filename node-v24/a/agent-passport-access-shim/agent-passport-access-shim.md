# agent-passport-access-shim

> 标签: access-receipt, agent-passport, attribution, mcp, provenance

## 简介

Adapter that emits a signed APS AccessReceipt for each governed MCP tools/call. Signing and verification are the agent-passport-system SDK's; this is proof of governed access, not a contribution or value claim.
