# axios-plus

> 标签: ajax, http, miniprogram, node, promise, xhr, 小程序

## 简介

Promise based HTTP client for the browser, wechat miniprogram and node.js  一款基于promise的多终端Http requesut 库，支持web、微信小程序和nodejs，基于axios扩展而来
