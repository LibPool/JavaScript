# allowance-kit

> 标签: agentic-payments, ai-agents, budget, mcp, micropayments, payment-channels, solana, spend-controls, stablecoin, usdc, x402

## 简介

The missing buyer-side runtime for x402: fund your AI agent once; it pays any x402 API autonomously inside hard policy rails — budgets, per-call caps, velocity circuit breakers, host allowlists, kill switch, audit ledger.
