# ailint

> 标签: JavaScript

## 简介

该项目的主要功能是分析一个软件项目的代码，找出可能存在的BUG并提出合理的改进建议。项目会读取软件的目录结构及文件内容，通过调用AI服务进行分析，并将结果输出到一个指定的文件中。
