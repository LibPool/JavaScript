# ascend-doc-mcp

> 标签: Ascend, CANN Mind系列, 应用使能, 推理, 推荐, 昇腾, 昇腾文档, 昇腾社区, 算子, 训练

## 简介

将昇腾开发技术文档（含昇腾社区和昇腾相关开源仓）包装成MCP标准只读数据源，让任何兼容 MCP 的 Agent 都能便捷地引用权威资料，减少大模型知识幻觉；它只做资料读取，不执行操作。
