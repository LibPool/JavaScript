# aitomic-o-grid3

> 标签: JavaScript

## 简介

A grid template. Include this template in module GenericList using macro `{layout '../path-to-latte-template'}` or import {latte} block using macro `{import '../path-to-latte-template'}` and declare this block as `{include #blockName}`.
