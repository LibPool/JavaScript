# anydb-sql-fork-publish

> 标签: any, db, mysql, orm, pg, postgres, postgresql, sql, sqlite

## 简介

Minimal ORM for mysql, postgresql and sqlite with complete arbitrary SQL query support (based on brianc's query builder sql)
