# alpaca-guard-mcp

> 标签: agentic-trading, ai-agent, alpaca, alpaca-markets, circuit-breaker, claude, cursor, daily-limit, guard, mcp, model-context-protocol, paper-trading, spending-cap

## 简介

MCP server that wraps the Alpaca trading API with a hard daily USD cap. Paper trading by default. Live trading blocked unless explicit opt-in.
