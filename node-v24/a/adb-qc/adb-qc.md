# adb-qc

> 标签: adb, adb wireless, adb-connection, adb-over-wifi, adb-pairing, adb-wireless, adb-wlan, android, android-devices, connect, debugging, device-discovery, devices, mDNS, pairing, pairing-code, qr-code, remote-debugging, tcp, usb-debugging, wifi, wireless, wireless debugging

## 简介

Quickly set up a wireless ADB connection for Android devices. Supports connection via pairing code or QR code, enabling remote debugging over Wi-Fi.
