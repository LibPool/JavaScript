# amethyst-compiler

> 标签: JavaScript

## 简介

This is a C-style "compiler" and linker for JavaScript. It outputs binaries with a `AMT\x00` header and should be used for compiling your Amethyst apps. ## CLI The main binary is `amtc`. To install it, run `npm i amethyst-compiler -g`.  * `out` - The b
