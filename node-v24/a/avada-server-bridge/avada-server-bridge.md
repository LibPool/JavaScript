# avada-server-bridge

> 标签: avada, bigquery, firebase-functions, koa, shopify, toolkit

## 简介

Server-side logic toolkit for Avada Shopify apps — BigQuery hub modules, TTL caching, Koa handlers and core primitives for Firebase Functions.
