# aegis-agent-guard

> 标签: agent-security, ai-agents, ai-safety, claude-code, cli, cursor, guardrails, pre-commit

## 简介

A pre-commit safety guard for AI coding agents. Blocks destructive shell commands before they run, with a tamper-evident audit log. Drop-in Claude Code hook.
