# amd-noconflictify

> 标签: amd, browserify, browserify-plugin

## 简介

Browserify plugin for avoiding that libraries register themselves as AMD modules.

- 官网：https://github.com/iadvize/amd-noconflictify
- 源码仓库：git://github.com/iadvize/amd-noconflictify.git
