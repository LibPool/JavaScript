# ai-agent-bank-mcp-server

> 标签: a2a, agent-economy, ai-agents, capability-backed-collateral, defi, lending, mcp, model-context-protocol, polygon, usdc, x402

## 简介

MCP server for AI Agent Bank — the financial layer for the agent economy. Self-custody wallets, on-chain USDC transfers, P2P swaps, collateralized lending, capability-backed credit, and dynamic interest rates on Polygon.
