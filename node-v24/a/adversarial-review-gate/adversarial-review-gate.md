# adversarial-review-gate

> 标签: adversarial-review, agent-skills, claude-code, code-review, codex, coding-agent, gemini-cli, opencode, roundtable

## 简介

The roundtable: an adversarial review where specialist seats find defects alone, attack each other's findings, and a clean-context judge rules. Runs on any coding agent (Claude Code, Codex, Gemini CLI, opencode) on Linux, Windows, and macOS.
