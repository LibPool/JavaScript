# agent-coord-waiter

> 标签: agent-coord, marketplace, mcp, secp256k1, waiter, x402

## 简介

Minimal TypeScript helpers for agent-coord v0.1 Waiters (canonical JSON, signing, ECIES, payments). No MCP — use marketplace MCP tools from your agent.
