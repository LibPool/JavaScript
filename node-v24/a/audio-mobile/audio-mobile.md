# audio-mobile

> 标签: audio, mobile

## 简介

本插件主要针对移动端audio音频播放问题，实现了自动播放，循环播放的功能。对大部分移动端播发设备做了兼容处理，对于h5游戏开发以及微信小程序开发非常适用。
