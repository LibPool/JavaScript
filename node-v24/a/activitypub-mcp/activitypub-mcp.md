# activitypub-mcp

> 标签: activitypub, activitystreams, ai, claude, decentralized, fediverse, llm, mastodon, mcp, misskey, model-context-protocol, pleroma, social-media, webfinger

## 简介

Model Context Protocol (MCP) server for the Fediverse — let Claude and other LLMs explore and post to Mastodon, Misskey, and Pleroma. Read-only by default.
