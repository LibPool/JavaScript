# agent-flywheel

> 标签: agent, continual-learning, deepseek-harness, dsh-plugin, observability, openclaw, openclaw-plugin, percepteye, reinforcement-learning

## 简介

Close the loop on your OpenClaw or DeepSeek Harness agent: record what your tools actually did — ok, failed or unknown — claim graded rollouts in training mode, and report them back. Never alters a tool result; set PERCEPTEYE_AGENT_MODE=production for a s
