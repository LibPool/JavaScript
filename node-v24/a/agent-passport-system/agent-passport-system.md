# agent-passport-system

> 标签: agent-identity, agent-protocol, agentic-commerce, ai-agent, attribution, autonomous-agent, coordination, cryptographic-identity, delegation, ed25519, governance, mcp, merkle-tree, multi-agent, social-contract, trust, typescript, values-alignment

## 简介

Enforcement and accountability layer for AI agents. Bring your own identity (did:key, did:web, SPIFFE, OAuth, did:aps). Gateway enforcement, monotonic narrowing, cascade revocation, earned reputation, wallet binding, attribution, signed receipts.
