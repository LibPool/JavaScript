# aiui-action

> 标签: aiui, dsh-plugin, iflytek, mcp, robot, speech, voice, wakeup

## 简介

讯飞语音背包（iFlytek AIUI / ZC-H358S）语音 + 机器人动作插件：19199 协议客户端、唤醒/识别/语义、官方 TTS 通道、动作序列下发 + 宇树 G1 执行桥、设备运维、USB 自动发现背包 IP。
