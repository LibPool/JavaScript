# adhdgofly-dsh-ext

> 标签: adhdgofly, deepseek, deepseek-harness, dsh, dsh-plugin, highlighting, markdown, part-of-speech, pos-tagging

## 简介

ADHDGoFly POS highlighting for DeepSeek Harness Web: nouns green, verbs red, adjectives/adverbs purple, others gray, in rendered Markdown (conversation messages, deliverables, etc.) + local word-frequency statistics (spiral word cloud, trends) + floating
