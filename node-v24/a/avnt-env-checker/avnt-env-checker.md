# avnt-env-checker

> 标签: JavaScript

## 简介

Um pacote para listar e/ou verificar se todas as variáveis de ambiente usadas em um projeto (local, git ou remoto) estão declaradas em um arquivo de configuração (.env, .json) ou em um objeto diretamente.
