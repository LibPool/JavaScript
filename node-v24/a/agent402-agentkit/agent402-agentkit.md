# agent402-agentkit

> 标签: agent-tools, agent402, agentic-finance, agentkit, ai-agents, aifi, base, cdp, coinbase, http-402, llm-tools, micropayments, mpp, proof-of-work, tool-discovery, usdc, x402

## 简介

Agent402 (500+ pay-per-call web tools over x402 or MPP; Agentic Finance) as a Coinbase AgentKit action provider for CDP, Privy, ZeroDev or viem wallets: find, call, about. Pays over x402 in USDC on Base from the agent's wallet, or free via proof-of-work.
