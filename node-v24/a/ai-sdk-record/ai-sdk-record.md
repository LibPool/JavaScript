# ai-sdk-record

> 标签: ai, ai-sdk, cassette, language-model, record, replay, streaming, testing, vcr, vercel

## 简介

Record real Vercel AI SDK calls and replay them deterministically in tests. Cassette-based, framework-agnostic, zero runtime dependencies.
