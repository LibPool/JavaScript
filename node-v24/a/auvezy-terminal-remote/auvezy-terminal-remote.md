# auvezy-terminal-remote

> 标签: claude, claude-code, lan, mobile, pty, remote, terminal, websocket, xterm

## 简介

Auvezy Terminal Remote — 局域网内通过手机/平板浏览器远程控制 PC 终端：atr <program>，多终端多实例自动出现在浏览器 tab 切换
