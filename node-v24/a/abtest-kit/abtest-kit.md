# abtest-kit

> 标签: a/b-test, ab-test, baidu-tongji, experiment, react, split-test, typescript

## 简介

Lightweight A/B testing SDK with multiple strategies (random, CRC32, custom) and optional React integration. Supports Baidu Tongji and standalone usage.
