# agent-chaos

> 标签: agent-security, ai-agent, cli, llm-security, mcp, mcp-security, prompt-injection, red-team, security, testing

## 简介

Local-first security testing CLI for AI agents. Runs controlled attack scenarios against an agent and reports whether it violated a security boundary.
