# arg-env

> 标签: .env, arguments, cli, command, compose, config, docker, dotenv, env, env-file, env_file, environment, line, loader, node, parser, variables

## 简介

Node.js package to work with `.env` files in the same way as docker and docker-compose via `--env-file` or `"env_file"` in package.json
