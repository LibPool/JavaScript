# ahoney-cli

> 标签: vant

## 简介

ahoney-cli 是一个 Vue 组件库构建工具，通过 ahoney-cli 可以快速搭建一套功能完备的 Vue 组件库。

## 官网

- npm 页面：https://www.npmjs.com/package/ahoney-cli

## 历史版本号

- 当前版本：1.0.7

- 1.0.1
- 1.0.2
- 1.0.7

## 获取地址

- npm 安装：`npm install ahoney-cli`
- npm registry：https://registry.npmjs.org/ahoney-cli
- Node 要求：>=10
