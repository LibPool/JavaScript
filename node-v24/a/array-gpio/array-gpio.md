# array-gpio

> 标签: IoT, bcm2835, embedded system, gpio, i2c, industry 4.0, iot, m2m, onoff, plc, raspberry pi, rpi, rpio, spi

## 简介

array-gpio is low-level javascript library for Raspberry Pi using direct register access.
