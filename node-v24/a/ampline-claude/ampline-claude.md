# ampline-claude

> 标签: anthropic, claude-code, cli, statusline, terminal, zero-dependency

## 简介

A color-graded, zero-dependency statusline for Claude Code — a 16-step model/effort color wheel, context and rate-limit usage, git state, and session cost, all on one line.
