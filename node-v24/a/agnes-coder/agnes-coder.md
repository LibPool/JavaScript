# agnes-coder

> 标签: agnes, agnes-ai, cli, coding-agent, mcp, plugins, skills, termux

## 简介

Agnes AI coding agent CLI —— 终端内直连 Agnes 对话，支持 run_shell/write_file/read_file/use_skill 工具、SKILL.md 与 zip 技能自动加载、流式对话及真 TUI（悬浮命令菜单 + 底部状态栏）。社区第三方客户端。
