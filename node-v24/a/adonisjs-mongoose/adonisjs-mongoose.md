# adonisjs-mongoose

> 标签: adonis, adonisjs, adonisjs-v7, database, mongodb, mongoose, odm

## 简介

Mongoose ODM integration for AdonisJS — config-driven multiple connections, container-managed manager, models, ace command, REPL bindings and health checks.
