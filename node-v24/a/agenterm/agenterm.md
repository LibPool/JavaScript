# agenterm

> 标签: agents, claude-code, cli, codex, dev-server, mcp, model-context-protocol, process-manager, terminal

## 简介

Run dev servers, watchers, and builds in terminals that you and your coding agents can watch, type into, and stop. CLI and MCP server.
