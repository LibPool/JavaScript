# agui-framework

> 标签: ag-ui, agent, ai, anthropic, fireworks, framework, llm, ollama, openai, streaming, typescript

## 简介

A TypeScript framework for building AI agent-powered applications. Integrates with multiple LLM providers (OpenAI, Anthropic, Ollama, Fireworks) and implements the AG-UI protocol for real-time frontend communication.
