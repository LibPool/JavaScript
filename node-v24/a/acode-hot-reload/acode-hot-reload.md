# acode-hot-reload

> 标签: acode, bun, hot-reload, ink, live-reload, plugin, react, typescript, websocket

## 简介

Hot-reload development server and plugin for Acode Editor. Instantly rebuild and push plugin updates with Bun, Ink, and WebSocket.
