# ascent-accessibility-mcp

> 标签: a11y, accessibility, mcp, model-context-protocol, wcag, wcag22

## 简介

MCP server exposing the WCAG 2.2 success-criteria knowledge base (catalog, remediation, manual tests, reviewer profiles, understanding, applicability) used by Ascent Accessibility.
