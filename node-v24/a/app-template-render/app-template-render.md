# app-template-render

> 标签: JavaScript

## 简介

ATR是一个基于`VUE3`和`ElementPlus`的纯前端渲染组件，也仅仅是一个前端渲染组件，可以做到通过相应的`JSON`生成简单的表单和视图，提高前端开发效率
