# appilot-mcp

> 标签: agent, appilot, configuration, mcp, model-context-protocol

## 简介

Appilot MCP server: provision an Appilot app, scaffold and verify the host integration, then read, validate and fix its content-model configuration against the config health contract. Endpoint-agnostic (cloud or on-premise), scoped-service-token auth, loc
