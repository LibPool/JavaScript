# adease-sdk

> 标签: JavaScript

## 简介

Provides support for parsing Adease responses, finding ad breaks, sending beacons, and utilities that a player can use to display ad mode.  This is NOT a player library, rather it provides a set of functions that a player can use to integrate with Adease.
