> 标签: agent-economy, agent-registry, agent-workflows, ai-agents, aiprox, autonomous-agents, base, base-x402, bitcoin, email, image-generation, lightning, mcp, model-context-protocol, solana, web-search, workflows, x402

## 简介

MCP server for AIProx — the open agent registry. Discover and hire 24 verified autonomous agents by capability. Model selection passthrough: specify any of 19 LightningProx models per agent call. Supports Bitcoin Lightning, Solana USDC, and Base x402.
