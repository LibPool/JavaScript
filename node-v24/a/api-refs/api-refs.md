# api-refs

> 标签: apifox, apifox-generator

## 简介

这是一个能够显著提高前端接口管理效率的工具。基于 apifox 的 JSONSchema 规范, 生成前端项目使用的接口调用文件.

- 源码仓库：https://github.com/halo951/api-refs.git
- npm 页面：https://www.npmjs.com/package/api-refs
