# axios-pluginify

> 标签: axios, axios-cache-adapter, axios-mock-adapter, axios-retry, interceptors, plugin, utils

## 简介

`axios-pluginify` 是一款极小的工具, 可以让 `axios` 成为基于插件的请求库.
