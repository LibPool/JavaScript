# azure-storage-backup

> 标签: JavaScript

## 简介

<img src='http://www.newhorizons.com/portals/278/Images/MSAzure.png' width="200"/> azure-storage-backup is an npm module to generate the azure storage backups. Primarily this was designed to do BLOB storage backups, but it now also supports Table storage
