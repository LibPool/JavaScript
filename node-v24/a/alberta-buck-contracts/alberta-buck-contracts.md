# alberta-buck-contracts

> 标签: abi, artifacts, ethereum, solidity, stablecoin

## 简介

Compiled ABI and bytecode for the Alberta Buck contracts (unaudited prototype): the BUCK token, BuckCredit, the BUCK_K controller, the identity registry and the baskets, built with a pinned compiler
