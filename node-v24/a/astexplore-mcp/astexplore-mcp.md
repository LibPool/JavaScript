# astexplore-mcp

> 标签: abstract-syntax-tree, acorn, ast, astexplorer, babel, code-analysis, espree, estree, javascript, jsx, mcp, mcp-server, modelcontextprotocol, parser, syntax-tree, typescript, typescript-eslint

## 简介

MCP server that parses JS/TS source into an AST using a selectable parser (babel, acorn, typescript, espree, @typescript-eslint/parser) — astexplorer.net as an MCP tool.
