# agent-shell-guard

> 标签: agent-skills, ai-agent, codex, codex-cli, openai, powershell, shell, skill, windows

## 简介

Codex Agent Skill: stop guessing, verify Windows shell state (PowerShell/cmd/Git Bash/WSL) before executing commands. Prevents path, env-var, cwd, and command-not-found failures and blocks blind retries.
