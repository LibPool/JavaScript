# aikoql-mcp

> 标签: ai-agents, aikoql, claude-code, context-compiler, knowledge-database, knowledge-graph, mcp, mcp-server

## 简介

Aikoql — The Agent-First Knowledge Database. Single binary, zero deps. MCP server for knowledge CRUD, aikoql queries, graph traversal, hybrid search, context compilation, document ingestion, and more.
