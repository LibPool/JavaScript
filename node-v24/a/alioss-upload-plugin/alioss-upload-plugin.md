# alioss-upload-plugin

> 标签: JavaScript

## 简介

webpack插件，将本地的图片自动打包上传到 oss ，并在本地创建服务，通过服务代理进行访问图片，解决小程序的背景图片无法使用本地图片的痛点

## 官网

- npm 页面：https://www.npmjs.com/package/alioss-upload-plugin
