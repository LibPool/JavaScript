# attenu-guard

> 标签: a2a, agents, ai, audit-log, authorization, delegation, langchain, langgraph, langgraphjs, least-privilege, mcp, owasp, security, sub-agents, typescript

## 简介

Attenu Guard for TypeScript: enforces per-agent permissions on every tool call and sub-agent handoff — a sub-agent never holds more than its parent — and writes a hash-chained audit log you verify offline. Same bundle format as the Python library.
