# api-placa

> 标签: api-placa, automovel, carro, placa, veiculo

## 简介

Está biblioteca é uma Api Wrapper simples para buscar dados de veículos a partir da placa, para isso é utilizado os dados fornecidos do site tabelafipebrasil.com
