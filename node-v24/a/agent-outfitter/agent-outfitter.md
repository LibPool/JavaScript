# agent-outfitter

> 标签: agent, agents, agents-md, claude, codex, lockfile, mcp, package-manager, provisioning, skills

## 简介

Library-first agent package manager. Resolve, verify, and install agent primitives (skills, MCP servers, instruction fragments) into Claude Code, Codex, or any harness, from an await-able TypeScript API.
