# auto-compact

> 标签: auto-compact, compaction, context, deepseek-harness, dsh, dsh-plugin, plugin

## 简介

会话级自动上下文压缩插件：回合中每步前 + 回合结束检测上下文用量，超过会话阈值自动 compact，摘要注入上下文后自然继续（DeepSeek Harness / DSH）
