# angular-weblineindia-message-dialog-box

> 标签: alertbox, angular-components, angular-message-dialog-box, angular-messagedialog, angular-weblineindia-message-dialog-box, custom-alert-box, custom-messagedialog, message-dialog-box, messagedialog

## 简介

AngularJS based MessageDialog component used for showing custom dialog with message. You can even change number of buttons on that. You can also hide header and cross icon.
