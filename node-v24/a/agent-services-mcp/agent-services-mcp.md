# agent-services-mcp

> 标签: accountability, agent-tools, agentic, ai-agents, audit, base, cloudflare-workers, content-provenance, ed25519, mcp, mcp-server, micropayments, model-context-protocol, provenance, quality-scoring, signed-receipts, usdc, x402

## 简介

MCP server exposing paid (x402) and free tools for AI agents — content provenance, quality scoring, and action audit — each backed by Ed25519-signed receipts on Cloudflare Workers.
