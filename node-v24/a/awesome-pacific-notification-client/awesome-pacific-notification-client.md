# awesome-pacific-notification-client

> 标签: awesome-pacific, component, nextjs, notification-system, notifications, pub-sub, react, real-time, redis, typescript, websocket, widget

## 简介

A React/Next.js notification widget for real-time notifications. Features organization verification, Redis pub/sub integration, customizable themes, and easy setup with environment variables.
