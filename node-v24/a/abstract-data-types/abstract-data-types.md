# abstract-data-types

> 标签: abstract, abstract data type, abstract-data-type, adt, binary, binary search tree, binary tree, binary-search-tree, binary-tree, data, link list, linked, list, queue, search, search tree, stack, tree, type

## 简介

This module aims to provide a full suite of abstract data types. At present it provides the abstract data type, Queue, Linked List, Stack, Binary Tree an Binary Search Tree.
