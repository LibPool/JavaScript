# amdin

> 标签: admin, cms, forms, mongodb, mongodb-admin, mongoose, mongoose-admin, vue

## 简介

A plug-and-play admin for [Mongoose](http://mongoosejs.com), written with [Koa](http://koajs.com) and [Vue](https://vuejs.org).
