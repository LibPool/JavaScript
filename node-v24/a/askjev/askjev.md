# askjev

> 标签: agents, jev, mcp, model-context-protocol, system-one, typesafe, typesafe-ai

## 简介

Unofficial MCP server for Jev, Typesafe AI's System One model. Ask free-text questions; Jev routes them to choice, score, or yes/no and answers with calibrated probabilities.
