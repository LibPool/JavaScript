# answerhatch-mcp

> 标签: ai, answerhatch, cite-or-refuse, docs, documentation, mcp, model-context-protocol, onboarding, rag, widget

## 简介

MCP server for AnswerHatch: onboard a domain to a cite-or-refuse answer widget from your agent (sign in, register a domain, verify by DNS, crawl, collect the embed snippet).
