# anonymous-browser

> 标签: anonymity, anonymous, anti-fingerprinting, browser, camoufox, disposable, fingerprint, privacy, tor

## 简介

Disposable, fingerprint-rotating browser via Tor (Camoufox-based) with optional real-time disposable email — Linux + macOS.
