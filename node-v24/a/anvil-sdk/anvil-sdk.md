# anvil-sdk

> 标签: agent, agents, ai, anvil, backend, express-alternative, file-based-routing, framework, http, llm, mcp, model-context-protocol, router, typescript

## 简介

Express for humans. Anvil for agents. Node backend framework with file-based routing, compile-time validation, and a native agentic layer (MCP, tools, tracing).
