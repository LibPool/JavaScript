# avacast

> 标签: avacast, avatar, realtime, sdk, webrtc

## 简介

Node.js / TypeScript SDK for avacast realtime avatars: create sessions and make the avatar speak from your server, and show it in the browser.

## 官网

- 官网：https://avacast.jp/docs
- 源码仓库：git+https://github.com/shannonllc/avacast-node.git
- npm 页面：https://www.npmjs.com/package/avacast
