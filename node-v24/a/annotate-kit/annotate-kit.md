# annotate-kit

> 标签: annotation, backend-agnostic, bug-report, feedback, firebase, overlay, react, rest, screenshot, self-hosted, supabase, visual-feedback

## 简介

Drop-in in-app annotation / visual-feedback overlay for React apps. Pin & draw on your live site, capture screenshots + console, export a clean prompt for your developer or any AI coding assistant. Backend-agnostic via a small storage adapter — ships zero
