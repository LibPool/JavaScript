# async-drop-late

> 标签: JavaScript

## 简介

有同学在多次ajax的时候遇到了较早的请求后到导致数据不一致的问题，最好的方案当然是数据包含版本，但这个实现就不依赖后端也能确保数据不会被迟到的ajax结果覆盖
