# audionorm

> 标签: audio, cli, ebu-r128, ffmpeg, loudness, lufs, normalization, normalize, volume

## 简介

Normalize audio files to an optimal loudness (LUFS / peak) from the command line. Bundles ffmpeg, so it just works with npx.
