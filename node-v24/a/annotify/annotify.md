# annotify

> 标签: annotations, controller, decorators, ejs, http, middleware, node, nodejs, rest, rest-api, router, routing, spring, spring-boot, static-files, templates, typescript

## 简介

Annotation-based HTTP routing for Node.js + TypeScript, inspired by Spring Boot. Zero runtime dependencies. Express-style middleware + templates.
