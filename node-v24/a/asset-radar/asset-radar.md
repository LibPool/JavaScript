# asset-radar

> 标签: assets, cli, font, image-compression, nextjs, optimization, orphan-detection, react, static-analysis, svg, vite, webp

## 简介

Zero-config static analysis & media optimization CLI tool for frontend developers. Scans codebases to detect orphan/unused assets, uncompressed images, raw Figma SVGs, and bloated font files.
