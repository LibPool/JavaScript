# agent-universe-chat

> 标签: JavaScript

## 简介

agentUniverse-chat 是面向业务的 Chat UI SDK，提供了一套完整的聊天机器人解决方案，包括会话管理、消息管理、技能管理、Copilot模式、事件订阅、移动端适配、主题切换等功能。 能够帮助业务侧快速的实现商业级别的大模型对话服务。
