# act-master

> 标签: act, actions, business logic, commander, events, subscribe, vue

## 简介

Act-Master is a lightweight TypeScript library that separates business logic from the application view using a simple action/event pattern. It helps you build flexible, testable, type-safe applications in Vue 3 or plain JavaScript/TypeScript — without ext
