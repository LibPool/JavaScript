# agent-collective

> 标签: agent-coordination, callsign, coding-agent, cross-harness, hub, irc, multi-agent, omp, omp-extension, peer-discovery, pi, pi-coding-agent, pi-extension

## 简介

Cross-instance peer awareness and steering for omp and pi: every running instance sees the others by callsign and can prompt them — natively through omp's hub tool, or via peers/peer_send tools on pi.
