# a11yhawk

> 标签: a11y, accessibility, audit, ci, lighthouse, playwright, scanner, wcag

## 简介

Open-source, self-hostable web accessibility scan engine: Playwright capture, Lighthouse audits, and BYOK LLM analysis producing structured WCAG reports.
