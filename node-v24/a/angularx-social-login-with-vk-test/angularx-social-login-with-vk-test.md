# angularx-social-login-with-vk-test

> 标签: angular, angular-social-login, angular4, facebook-authentication, google-authentication, social-authentication, social-login

## 简介

Social login and authentication module for Angular 4 / 5 / 7. Supports authentication with Google, Facebook, LinkedIn, Vkontakte. Can be extended to other providers also.
