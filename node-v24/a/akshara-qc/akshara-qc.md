# akshara-qc

> 标签: accessibility, akshara, devanagari, grapheme, i18n, indic, kannada, tamil, telugu, testing, typography

## 简介

Find broken Indic text rendering on the web — clipped ascenders, tofu, font fallback, mid-cluster truncation and line breaks inside a syllable.
