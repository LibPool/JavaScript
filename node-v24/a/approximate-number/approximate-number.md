# approximate-number

> 标签: -h, abbreviate, abbreviated, approximate, approximate-number, approximation, big, billion, closest, format, formatter, friendly, human, large, million, near, nearest, number, numbers, readable, round, short, simple, stack exchange, stack overflow, thousand, trillion

## 简介

Converts numbers into a more human-friendly format, similar to `ls`'s `--human-readable` flag (`ls -lh`) or Stack Overflow's reputation numbers. For example, 123456 becomes '123k'.
