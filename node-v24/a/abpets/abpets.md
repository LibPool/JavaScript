# abpets

> 标签: agentbro, ai-agent, ai-coding, claude, claude-code, cli, cline, codex, codex-desktop, copilot, cursor, desktop-pet, gemini-cli, github-copilot, macos, marketplace, mascot, pets, pixel-art, sprite, spritesheet, virtual-pet

## 简介

Install desktop pets for AI coding agents — Claude Code, Codex, Cursor, GitHub Copilot, Cline, Gemini. One command extracts a pet's spritesheet into ~/.codex/pets and ~/.agentbro/pets so any AgentBro-hosted agent picks it up.
