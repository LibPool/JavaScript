# angular-esbuild-visualizer

> 标签: angular, bundle, bundle-analyzer, code-splitting, esbuild, lazy-loading, metafile, stats-json, treemap, visualizer

## 简介

Visualize the import branch of an Angular (esbuild builder) production bundle, starting from index.html. Builds an interactive HTML tree of chunk-to-chunk imports (eager + dynamic routes) and per-chunk original-module contents, using the build's stats.jso
