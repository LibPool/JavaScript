# avecolor

> 标签: auto-theme, average-color, background-color, color-analysis, color-extraction, dominant-color, hex, image-color, image-processing, rgb, shadow-color

## 简介

A lightweight JavaScript utility to extract the average color from any image. Supports HEX or RGB output.
