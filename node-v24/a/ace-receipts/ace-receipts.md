# ace-receipts

> 标签: agents, ai, ci, code-review, github-actions, governance, prompt-injection, receipts, security

## 简介

AI agents can cook. Make them bring receipts. Tiny CLI + GitHub Action that scans AI-agent workflows and AI-generated diffs for proof, risk, permission, missing evidence, and closeout.
