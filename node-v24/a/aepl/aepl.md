# aepl

> 标签: aepl, backend, class, classes, dataType, framework, game-development, games, html, lightweight, minigames, nodejs

## 简介

A Node.JS multi-layered class creation package with built-in parenting systems that let you get info from classes above as well as better function and property makers for easier to read and understand development and modding support inspired by Roblox's S
