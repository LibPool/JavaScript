# agent-trajectory

> 标签: claude, claude-code, claude-code-plugin, hooks, session, telemetry, trace, trajectory

## 简介

Record every Claude Code session as a replayable trajectory timeline (prompts, tool calls, permissions, subagents, token usage) and view it in a local web UI.
