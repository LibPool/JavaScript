# adevgh

> 标签: adev, android, arm64, gh, github-cli, termux

## 简介

Unofficial installer that provides the standard `gh` command inside ADEV/Termux using the Android ARM64 build of GitHub CLI from the Termux repository. Not affiliated with or endorsed by GitHub.

## 官网

- npm 页面：https://www.npmjs.com/package/adevgh

- 1.0.0

## 获取地址

- npm 安装：`npm install adevgh`
- npm registry：https://registry.npmjs.org/adevgh
- Node 要求：>=18
