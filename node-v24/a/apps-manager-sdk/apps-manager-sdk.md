> 标签: apps-manager, ed25519, electron-license, license-manager, licensing, node-locking, offline-license, react-license, software-licensing

## 简介

Production-grade, low-code Licensing Client SDK for Desktop (Electron), Node.js, and Web applications with offline Ed25519 lease verification, server-side subscription validation, and React hooks.
