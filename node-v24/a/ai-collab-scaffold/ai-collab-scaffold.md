# ai-collab-scaffold

> 标签: agents-md, ai, copilot, documentation, frontmatter, knowledge-graph, scaffold

## 简介

与业务和框架无关的 AI 协作工具脚手架，可一键安装到任意 Node.js 项目。它通过 YAML frontmatter + ai:lint/new/report 命令 + git hooks + CI 守门，5 分钟内为项目建立 AI 友好的知识库底座。内置踩坑库（pitfalls）、架构决策记录（ADR）和受控词表，让 AI Agent 与团队成员始终基于同一事实源协作。支持 Git 和 SVN 双 VCS，并提供 Cytoscape 知识图谱仪表盘可视化文档健康度。
