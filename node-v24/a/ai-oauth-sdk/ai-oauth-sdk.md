# ai-oauth-sdk

> 标签: ai, anthropic, authentication, chatgpt, claude, cli, gemini, grok, login, oauth, oauth2, openai, pkce, sign-in-with-chatgpt

## 简介

Minimal, provider-agnostic OAuth for AI CLIs and apps. Sign in with ChatGPT, Claude, Gemini or Grok and get a token back. Works in Node, browsers, React, React Native, and via CDN.
