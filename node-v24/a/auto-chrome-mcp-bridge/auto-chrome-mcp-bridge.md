# auto-chrome-mcp-bridge

> 标签: browser, chrome, mcp

## 简介

Auto Chrome MCP — Chrome Native-Messaging host (Node). Non-interference background work mode, per-session work tabs, Force Reconnect, Playwright CDP fallback.
