## How to pass credentials :  ### Pass 'mailGun' credentials in .env file with exactly same variable names. - EMAIL_SERVICE = "Name of the service, e.g: 'mailgun'" - EMAIL_AUTH_USERNAME = "*username*" - EMAIL_AUTH_PASSWORD = "*password*"
