# aegis-auth-kit

> 标签: aes-256-gcm, argon2, auth, authentication, bcrypt, biometric, chacha20-poly1305, encryption, fido2, hashing, lockout, mfa, passcode, passkey, password, pbkdf2, policy, scrypt, security, step-up-auth, webauthn

## 简介

AegisSDK — Universal authentication orchestration SDK — configurable passcode hashing (Argon2id, scrypt, PBKDF2, bcrypt), biometric/WebAuthn, envelope encryption, policy engine with lockouts, fallback chains, and step-up auth.
