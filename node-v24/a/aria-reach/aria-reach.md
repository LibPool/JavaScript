# aria-reach

> 标签: a11y, accessibility, angular, aria, component-library, lint, screen-reader, section-508, static-analysis, wcag

## 简介

A static and runtime accessibility analyzer that detects ARIA anti-patterns in shared web component libraries and ranks them by downstream reach (Library Reach Index), so teams fix the issues affecting the most assistive-technology users first. Aids WCAG
