# aicortex-core

> 标签: ai, aicortex, chatbot, deepseek, free, gemma, llama, llm, mistral, no-api-key, ollama, open-source, qwen, streaming

## 简介

Free LLMs in the browser and Node.js. No API keys, no server setup. Powered by community Ollama servers. Supports Llama, Mistral, Gemma, DeepSeek, Qwen and more.
