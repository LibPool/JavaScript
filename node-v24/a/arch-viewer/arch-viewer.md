# arch-viewer

> 标签: ai-coding, architecture, c4, code-review, diagram, drift-detection, impact-analysis, layer-violation, mcp, mermaid, model-context-protocol, pull-request

## 简介

AI 写完代码后，自动看清架构变了什么：会话基线 → 变更图谱 → 影响面分析，IDE 状态栏 / PR 评论 / CLI 三端可用。
