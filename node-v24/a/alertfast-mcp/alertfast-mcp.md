# alertfast-mcp

> 标签: alertfast, alerts, discord, mcp, model-context-protocol, slack, telegram

## 简介

Model Context Protocol server for AlertFast — send alerts, manage destinations, API keys, and templates from any MCP client (Cursor, Claude Desktop).
