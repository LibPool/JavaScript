# arcade-agent-mcp

> 标签: agent, arc, arcade, circle, defi, dex, launchpad, mcp, modelcontextprotocol, usdc

## 简介

MCP server: let any AI agent trade and launch tokens on Arcade (USDC-native DEX + bonding-curve launchpad on Circle's Arc L1).
