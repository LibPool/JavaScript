# agentic-sdlc-mcp

> 标签: agentic, ai, claude, devops, github, mcp, model-context-protocol, sdlc

## 简介

An MCP Server acting as an Agentic SDLC Control Plane — helps AI coding agents plan, create, test, review, secure, and release software following GitHub Agentic AI best practices.
