# api2pdf

> 标签: barcodes, docx-image-preview, docx-to-pdf, headless-chrome, html-to-docx, html-to-pdf, html-to-xlsx, libreoffice, markdown-to-pdf, merge-pdfs, pdf, pdf-generation, pdf-to-html, ppt-to-pdf, qr-code, url-to-pdf, wkhtmltopdf, zip-files

## 简介

Node.js client for the Api2Pdf REST API with support for Chrome, wkhtmltopdf, LibreOffice, Markitdown, OpenDataLoader, PdfSharp, Zip, Zebra, and utility endpoints.
