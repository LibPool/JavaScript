# ascii-image-bg

> 标签: animation, ascii, ascii-art, background, canvas, generative, hero, react, react-component

## 简介

Animated ASCII-art background for React, rendered live from any image (SVG, PNG, JPEG, and more). Cursor-erase interactivity, reduced-motion aware, zero runtime dependencies.
