# agentlane

> 标签: ai-agents, android-emulator, claude-code, codex, coding-agents, cursor, dev-environment, ios-simulator, maestro, mcp, playwright, worktrees

## 简介

Gives each coding agent its own lane: a running copy of your app with its own ports, dev servers, database, and a simulator, emulator or browser to drive it.
