# audiocrate

> 标签: audio, audio-engine, audioworklet, daw, dsp, music, music-theory, scene-graph, signal-processing, synthesis, three.js, web-audio, webaudio

## 简介

A scene graph and AudioMaterial system for audio, organized like three.js. Serialisable DSP that the same interpreter runs offline and in an AudioWorklet.
