# auth0-token-vault-cli

> 标签: ai-agent, auth0, cli, gmail, oauth, token-vault

## 简介

Auth0 Token Vault CLI — Access third-party services (Gmail, Slack, etc.) on behalf of authenticated users via Auth0 Token Vault. Designed for both humans and AI agents.
