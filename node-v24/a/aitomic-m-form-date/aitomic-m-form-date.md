# aitomic-m-form-date

> 标签: JavaScript

## 简介

Default style of date field to simple and easy customization using global SASS mixin @input from package aitomic-base and javascript plugin [PickMeUp](https://github.com/nazar-pc/PickMeUp). Installation of dependencies is fully automatic.
