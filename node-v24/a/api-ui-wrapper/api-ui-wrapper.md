# api-ui-wrapper

> 标签: api-ui, api-ui-wrapper, api-wrapper, hoc, hoc-wrapper, ui-wrapper

## 简介

A Wrapper which takes two parameters (Component and API). Fills the data fetched from the passed API into the Component.
