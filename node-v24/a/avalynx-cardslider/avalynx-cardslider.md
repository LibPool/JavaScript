# avalynx-cardslider

> 标签: avalynx, bootstrap, bootstrap5, cardslider, component, grid, slider

## 简介

AvalynxCardSlider is a simple grid card slider for web applications. Based on Bootstrap >=5.3 without any framework dependencies.
