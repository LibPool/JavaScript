# agent-traffic-light

> 标签: ambient, claude, claude-code, coding-agent, hooks, macos, menu-bar, notifications, ntfy, status

## 简介

Ambient status for coding agents. A coloured light per session, a bell on the transitions that matter, and a push to your phone — so you can leave the desk and be pulled back only when a session actually needs you.
