# applan

> 标签: bonjour, cli, dev-server, lan, mdns, vite

## 简介

Give your npm/Vite/CRA/Next dev server a friendly LAN-visible name (http://appname.local:PORT) instead of hunting for an IP address. Zero privilege, zero persisted state.
