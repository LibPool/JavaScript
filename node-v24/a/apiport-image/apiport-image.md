# apiport-image

> 标签: ai, apiport, cli, gpt-image, image-generation, text-to-image, 生图

## 简介

交互式命令行生图工具：一条 npx 命令，用 apiport 中转站的「生图分组」API Key 调用 gpt-image 系列模型出图。
