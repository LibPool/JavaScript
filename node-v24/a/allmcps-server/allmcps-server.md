# allmcps-server

> 标签: ai-agent, allmcps, claude, cli, mcp, model-context-protocol

## 简介

The official MCP server and CLI for AllMCPs.com - search, browse, get install configs, and submit MCP servers directly from your AI agent or a shell script.
