# agentic-rss-parser

> 标签: agentic, agentic-ai, ai-agent, anthropic, atom, atom-parser, bluecarbons, claude, content-pipeline, deduplication, enrichment, feed-aggregator, feed-parser, feeds, llm, mcp, model-context-protocol, nodejs, ollama, open-source, openai, rss, rss-parser, rss-reader, typescript, xml-parser

## 简介

Node.js RSS and Atom feed parser with agentic analysis, LLM enrichment, heuristic deduplication, and Model Context Protocol (MCP) server tooling. Drop-in rss-parser compatible. Zero-dependency hand-rolled XML parser with SSRF protection, pluggable storage
