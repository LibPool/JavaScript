# ai-sdk-relay-protocol

> 标签: agent, ai, ai-sdk, harness, protocol, relay, websocket

## 简介

Wire protocol for an agent-session relay: provider-agnostic AgentEvent stream, session channel (client ⇄ relay ⇄ runner), replay cursors, and permission flow, all as Zod schemas.
