> 标签: alert, angular-toast, framework-agnostic, hot-toast, javascript-toast, lightweight, notification, notifications, notistack, react-alert, react-hot-toast, react-notification, react-notifications, react-toast, react-toastify, small, snackbar, sonner, svelte-toast, toast, toast-notification, toast-notifications, toastify, tostify, typescript, vanilla, vue-toast, zero-dependency

## 简介

Framework-agnostic toast notifications. Same toast.success() API for vanilla JS, React, Vue, Svelte, Angular, Astro, and CDN. No provider required. Vanilla ~5.9KB · React ~6.7KB · Vue ~6.5KB · Svelte ~6.8KB gzip JS per path + ~2.7KB CSS.
