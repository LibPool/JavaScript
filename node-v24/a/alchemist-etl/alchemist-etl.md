# alchemist-etl

> 标签: JavaScript

## 简介

Alchemist is an JavaScript ETL(**E**xtract, **T**ransform, **L**oad) engine focused on managing data coming from multiple sources, in an efficient and streamlined way, by using pipelines. ![Alchemist](./alchemist.png)
