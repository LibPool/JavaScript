# amanda-cli

> 标签: JavaScript

## 简介

1. npm init -y 2. 在新建的package.json 文件里面添加bin字段， ``` "bin": {     "init": "index.js"   }, ``` 3. 在根目录下新建index.js文件，准备编写命令 4. 执行npm link命令，关联自己写的包，不然会报命令的错
