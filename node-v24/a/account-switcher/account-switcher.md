# account-switcher

> 标签: account, account-management, antigravity, auth, auth-file, backup-restore, cli, codex, credentials, desktop-app, github, gitlab, multi-account, oauth, seamless-switching, switcher

## 简介

Lightweight CLI tool untuk switch antara multiple accounts (Codex, Antigravity, GitHub, dll) dengan mudah dan aman. Switch accounts dalam 5 detik tanpa re-login!
