# agentpay-gateway

> 标签: agent-payments, ai-agent, base, budget, mcp, model-context-protocol, payment-gateway, spend-limits, usdc, x402

## 简介

Cross-rail spend-policy gateway for AI agent payments: unified multi-currency budgets, rail routing, per-transaction limits, payee allowlists, and full audit logging across agent payment rails (x402-style, Alipay-style).
