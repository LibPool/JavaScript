# agentfdr

> 标签: agent, claude-code, codex, coding-agent, debugging, flight-recorder, llm, observability, openai, timeline, tokens

## 简介

Flight data recorder for local coding agents — dissect why Claude Code or Codex CLI looped, drifted, or burned tokens. Zero instrumentation, local-first.
