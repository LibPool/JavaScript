# appdrift-mcp

> 标签: app-store-optimization, appdrift, aso, claude, keyword-research, mcp, model-context-protocol

## 简介

App Store and Google Play lookups for MCP clients: keyword ranks, autocomplete, listing scores. Free without a key; an AppDrift key adds account tools and token-priced AI drafts.
