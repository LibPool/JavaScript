# appcrane-mcp

> 标签: appcrane, connector, deployment, mcp, model-context-protocol, self-hosted

## 简介

Standalone MCP connector for AppCrane — the self-hosted deployment platform for AI-built apps. Serves the appcrane_* tool catalog for offline introspection and proxies real tool calls to your AppCrane instance.
