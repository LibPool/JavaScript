# ai-provider-helper

> 标签: ai, foundry-vtt, llm, proxy

## 简介

Local AI helper for the AI Provider Library Foundry VTT module. Loopback proxy on 8090/8091: key vault, OAuth device flows, provider probes, chat, vision, and image calls.
