# adjuro

> 标签: adjuro, attestation, compliance, ed25519, eddsa, jose, jws, merkle-proof, receipt, rfc6962, rfc8037, tcpa, transparency-log, verifier

## 简介

Independent, offline-capable verifier for Adjuro Ed25519 receipts (JWS / RFC 8037). Verifies signatures locally — never trusts Adjuro's server for the answer.
