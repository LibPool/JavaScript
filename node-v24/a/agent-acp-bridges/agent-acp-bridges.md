# agent-acp-bridges

> 标签: acp, agent-client-protocol, ai-agents, wicked

## 简介

ACP (Agent Client Protocol) stdio bridge for headless coding CLIs without a native or ecosystem ACP adapter — currently agy (Antigravity) — plus the `wicked-pi` launcher that hands a pi seat its skills through the community pi-acp adapter. Used by wicked-
