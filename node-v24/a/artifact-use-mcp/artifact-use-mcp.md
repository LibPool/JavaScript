# artifact-use-mcp

> 标签: agents, artifact-use, artifacts, mcp, publishing

## 简介

Local stdio MCP server for Artifact Use: publish local folders and HTML as stable, gated, reviewable links with a creator token, and manage comments, access, and share links.
