# agy-cli-usage

> 标签: agy, antigravity, cli, code-assist, gemini, quota, rate-limit, usage

## 简介

Headless usage/quota monitor for the Antigravity CLI (agy) — reads Cloud Code quota directly, with a PTY fallback. No IDE required.
