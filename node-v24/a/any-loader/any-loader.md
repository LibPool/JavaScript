# any-loader

> 标签: AOP data loader, AOP load stream, LoadStream, OOP extend loader, async data loader, async/await API, data loader, data loader middleware

## 简介

Middleware of data loader. Easy to manage and wrap data API in your application. Support async/await and Promise. Compatible with future ES features.
