# ai-review-pipeline

> 标签: ai, auto-fix, cli, code-review, devtools, full-file-review, git-diff, openai, pipeline, quality, review, testing, zero-config

## 简介

Zero-config AI code quality pipeline CLI: deterministic rule checks + AI review, 4-tier team-friendly scoring, HTML report, and a built-in SiliconFlow fallback. Review, auto-fix and generate tests from a single command.
