# @malipetek/dsh-git-graph

> 标签: cordis, deepseek-harness, diff, dsh, dsh-plugin, git, source control

## 简介

Source control in the right Sidebar: the working tree with stage, unstage, discard and commit; a commit graph; branches; and fetch, pull and push — plus the files the agent changed last turn.
