# @holonograph/types-public

> 标签: evaluation, holonograph, llm, observability, schemas, types, typescript, wire-format, zod

## 简介

Public wire-format types and zod schemas for a Holonograph lens — the shared contract between the client SDK and the lens. Type your integration and validate wire payloads against the same schemas the lens uses.
