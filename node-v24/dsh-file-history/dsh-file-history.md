# dsh-file-history

> 标签: deepseek-harness, dsh, dsh-plugin, git, history, rollback, snapshot

## 简介

Per-turn file history for DeepSeek Harness: every conversation turn gets a snapshot, a change card in the chat, and one-click rollback of files, conversation, or both.
