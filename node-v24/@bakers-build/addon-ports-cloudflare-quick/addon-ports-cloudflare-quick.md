# @bakers-build/addon-ports-cloudflare-quick

> 标签: JavaScript

## 简介

bakers.build ports transport: one cloudflared Quick Tunnel process per route, with no fixed name/URL/uptime guarantee. Implements @bakers-build/addon-ports's PortsTransport contract.
