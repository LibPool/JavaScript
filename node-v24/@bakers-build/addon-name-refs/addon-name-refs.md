# @bakers-build/addon-name-refs

> 标签: JavaScript

## 简介

bakers.build connection addon: resolve entity NAMES (--label_names, --environment_names) into the relationships that reference them, on the live write, via dropsh's extendOperationSchema and alterRequest hooks.
