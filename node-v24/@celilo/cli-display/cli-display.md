# @celilo/cli-display

> 标签: celilo, cli, display, progress, terminal

## 简介

Shared terminal-UI primitives for Celilo CLI tools: a progress display that renders a flat append-only stream with a time gutter and a single status-glyph vocabulary (or emits structured [progress:start|done|fail|sub] markers for downstream parsers), plus
