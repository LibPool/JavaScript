# @realreel/photo-attest

> 标签: android-keystore, attestation, c2pa, content-authenticity, content-credentials, expo, expo-module, provenance, react-native, realreel, secure-enclave

## 简介

Expo native module for hardware-bound C2PA capture signing (iOS Secure Enclave / Android Keystore) with platform attestation (App Attest / Play Integrity). Reference implementation, best-effort support.
