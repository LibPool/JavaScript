# @avensio/async-pool

> 标签: async, avensio, concurrency, pool, promise

## 简介

A lightweight, type-safe FIFO promise pool for limiting concurrent asynchronous tasks in Node.js and browsers. Includes strict limit validation, rejection-safe scheduling, and typed ESM, CJS, and IIFE bundles.
