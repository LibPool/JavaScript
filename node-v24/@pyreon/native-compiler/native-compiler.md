# @pyreon/native-compiler

> 标签: JavaScript

## 简介

PRIVATE / EXPERIMENTAL — Pyreon Multi-Target Compiler (PMTC). Transforms Pyreon JSX source to native Swift (SwiftUI) and Kotlin (Jetpack Compose). Not published. See .claude/plans/native-platforms.md for strategic direction.
