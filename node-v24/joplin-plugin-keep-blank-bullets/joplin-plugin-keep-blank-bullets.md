# joplin-plugin-keep-blank-bullets

> 标签: joplin-plugin

## 简介

Rich Text editor, desktop and Android: an empty bullet, numbered item or checkbox stays in the note until you type in it, instead of being dropped when the note saves. Mobile support was developed and tested on Android only (untested on iOS).
