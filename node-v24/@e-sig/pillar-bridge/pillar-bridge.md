# @e-sig/pillar-bridge

> 标签: agent-to-agent, delivery-channel, e2e-encryption, esign, esignature, iaaso, mcp, pillar, uuaid

## 简介

Optional Pillar (UUAID/IAASO-3050 agent communication substrate) bridge for @e-sig/mcp — deliver signing links, lifecycle events, and identity proofs as signed, end-to-end encrypted envelopes over an agent's own inbox instead of (or alongside) email/webho
