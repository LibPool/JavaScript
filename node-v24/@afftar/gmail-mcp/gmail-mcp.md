> 标签: ai, auto-auth, claude, cli, cursor, email, gmail, google-gmail, mcp, model-context-protocol, oauth, tui

## 简介

Gmail MCP server with portable tool schemas (works with strict validators: Meta Muse, DeepSeek). CLI, TUI, console, OAuth, multi-account support
