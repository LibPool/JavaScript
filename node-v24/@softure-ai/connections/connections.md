# @softure-ai/connections

> 标签: JavaScript

## 简介

SOFTURE AI connections module: the app as an OAuth 2.0 client of third-party APIs and a store for their API keys. Providers from configuration, a connect flow for Next.js (one-time state, PKCE, a callback route) behind an admin-only page with each connect
