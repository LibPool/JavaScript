# @softure-ai/deploy

> 标签: JavaScript

## 简介

SOFTURE AI deploy CLI for a one-VPS app: renders .env.prod from CI secrets (names from the compose file), writes the release report between two tags, backs up the database, guards the migration ledger, compares row counts, verifies production against depl
