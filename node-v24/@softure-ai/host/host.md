## 简介

SOFTURE AI host CLI: provisions a shared app server on top of the softure.vps_foundation Ansible collection (Traefik edge, Cloudflare-only origin, deploy user) and onboards an app with one command (server folder, first deploy.sh, forced-command deploy key
