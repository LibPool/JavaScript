# @maxnth/gestalt

> 标签: avatar, avatar-generator, avatars, generative, generative-avatars, gradient, mesh-gradient, profile-pictures, typescript, vue, vue3

## 简介

Deterministic generative avatar components for Vue 3. Render unique avatars from any seed without stored images or network requests.
