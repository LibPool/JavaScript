# @owlmeans/web-marketing-consent

> 标签: JavaScript

## 简介

The browser half of @owlmeans/marketing-consent — the post-sign-in privacy-choices screen, a reusable settings-card body, the login step and landing hooks that wire it into @owlmeans/client-auth, and the cookie-consent bridge to @owlmeans/consent.
