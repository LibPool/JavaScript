# @owlmeans/server-oauth

> 标签: JavaScript

## 简介

The server half of @owlmeans/oauth — a standards-facing OAuth 2.1 authorization server (device authorization + authorization code with PKCE, RFC 9728/8414 metadata, Client ID Metadata Documents, Dynamic Client Registration) that mints ordinary @owlmeans/a
