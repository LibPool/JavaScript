# @owlmeans/llm-common

> 标签: JavaScript

## 简介

Serializable contracts for LLM inference and execution. Runtime-free — it holds the enums, policy shapes and record formats that both an inference runtime (`@owlmeans/llm`) and a persistence/queue consumer need to name the same things.
