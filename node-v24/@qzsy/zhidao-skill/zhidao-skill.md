# @qzsy/zhidao-skill

> 标签: claude-code, oa, skill, zhidao, 泉州五中

## 简介

至道 OA（泉州五中办公软件）操作技能。查目录用本包，调用后台时写无依赖的 Node.js fetch 脚本。缺少 Cookie 时引导账号密码和图形验证码登录。
