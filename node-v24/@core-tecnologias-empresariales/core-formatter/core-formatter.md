# @core-tecnologias-empresariales/core-formatter

> 标签: JavaScript

## 简介

Formateo e internacionalización de valores (números, moneda, fechas, teléfonos, identificadores fiscales, unidades) para el ecosistema Core Tecnología Empresarial, parametrizado por país/locale — nunca funciones fijas por país.
