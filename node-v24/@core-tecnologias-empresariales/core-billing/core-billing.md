# @core-tecnologias-empresariales/core-billing

> 标签: JavaScript

## 简介

SDK de comercio/facturación transversal — planes públicos y (a futuro) checkout Webpay — para que un landing/marketing site consuma el catálogo comercial de cualquier producto Core (CorePyme, Core Tributario, futuros) sin conocer su backend a mano.
