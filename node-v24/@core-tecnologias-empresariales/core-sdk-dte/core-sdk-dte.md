# @core-tecnologias-empresariales/core-sdk-dte

> 标签: JavaScript

## 简介

Integración con los servicios DTE del SII de Chile (autenticación con certificado, DTEUpload, QueryEstUp/QueryEstDte/QueryEstDteAv, wsDTECorreo) con protección contra doble envío: un resultado ambiguo nunca se reenvía a ciegas. Agnóstico de base de datos
