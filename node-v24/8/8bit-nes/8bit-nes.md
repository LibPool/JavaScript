# 8bit-nes

> 标签: 8bit, css, dark-theme, design-system, design-tokens, nes, nuxt, react, retro, vue, web-components

## 简介

NES 8-bit retro-modern design system. Design tokens + class-based CSS components + light-DOM web components. Cross-framework: HTML, Vue 3, Nuxt, React.
