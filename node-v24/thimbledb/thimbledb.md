# thimbledb

> 标签: aws-s3, azure-blob-storage, browser-database, cloudflare, cloudflare-r2, cloudflare-workers, container, database, database-admin, encryption, helm, indexeddb, json-database, kubernetes, object-storage, oidc, r2, serverless, typescript, vibe-coding, webcrypto

## 简介

Encrypted browser-first JSON database for small web apps, backed by object storage with in-app or separate Cloudflare and Node authorities.
