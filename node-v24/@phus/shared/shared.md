# @phus/shared

> 标签: JavaScript

## 简介

Phus shared: common TypeScript types and utilities — Brand, Result, Envelope/Outbound protocol shapes, json/promise/path/env helpers. Pure library, no runtime business logic. See documents/Proposal-Monorepo-Split.md §3.
