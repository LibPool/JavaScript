# @xdbml/parse

> 标签: ast, data-modeling, dbml, parser, schema, xdbml

## 简介

Parser for xDBML (eXtended Database Markup Language), a strict superset of DBML 3.13.6: tokenizer, parser, module resolver, and name resolver.

- 官网：https://xdbml.org
- 源码仓库：git+https://github.com/xdbml/xdbml-spec.git
