# @yiln-dsh/dsh-plugin-session-list-cache

> 标签: JavaScript

## 简介

DSH bundle plugin that collapses the repeated full-store session enumerations the Web GUI fires concurrently, by caching and coalescing sessionQuery.listSessions().
