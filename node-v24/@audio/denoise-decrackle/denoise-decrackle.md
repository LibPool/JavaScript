# @audio/denoise-decrackle

> 标签: audio, decrackle, denoise, dsp, restoration

## 简介

De-crackle: dense small impulses found as outliers of both the AR prediction error and the two-sided error, all of a window rebuilt at once by least-squares AR interpolation, looked for again until none is new, each event kept only where an impulse added
