# @audio/synth-dx7

> 标签: audio, dsp, dx7, fm, msfa, synth, sysex, yamaha

## 简介

Yamaha DX7 FM engine: a bit-exact JavaScript port of the Music Synthesizer for Android core (6 operators, 32 algorithms, DX7 envelopes, LFO, pitch EG), with DX7 sysex loading
