# dsh-agent-toolbox

> 标签: agent, claude-code, codex, cursor, deepseek, dsh, gemini, prompts, skills, toolbox, workbuddy

## 简介

DSH web plugin: a composer-side toolbox that lets you manually curate and add Skills and Prompts from WorkBuddy, Claude Code, Codex, Cursor and Gemini — no auto-injection, so your DSH context stays clean.
