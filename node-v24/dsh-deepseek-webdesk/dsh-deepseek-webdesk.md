# dsh-deepseek-webdesk

> 标签: conversation, cordis-plugin, deepseek, dsh-plugin, handoff, web-chat

## 简介

DeepSeek Web Desk for DSH: 在左侧栏拉出 DeepSeek 网页版会话列表，点一条就在主区域打开完整网页对话（复用 DSH 网页登录态、中文界面），并可接力到当前任务或新建任务。
