# @git-agentic/sentinel-action

> 标签: ci, github-actions, npm-audit, sbom, security, supply-chain

## 简介

Sentinel CI runner: self-booting dependency-tree audit for GitHub Actions (sentinel-ci) — audits a lockfile, writes a CycloneDX SBOM, and posts a PR verdict.
