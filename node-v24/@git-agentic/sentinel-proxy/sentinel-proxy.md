# @git-agentic/sentinel-proxy

> 标签: npm-audit, npm-registry, package-retraction, registry-proxy, security, supply-chain

## 简介

Sentinel registry proxy: transparently serves npm packages while intercepting and auditing each tarball, with an authoritative native publish path, verified claims, and time-locked retraction.
