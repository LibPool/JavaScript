# @c64cade/ultimate-bridge

> 标签: bridge, c64, c64cade, commodore64, ultimate64

## 简介

Local bridge server for connecting C64Cade to Ultimate 64 II and Commodore 64 Ultimate devices.

## 官网

- 官网：https://c64cade.com/ultimate-bridge
- npm 页面：https://www.npmjs.com/package/@c64cade/ultimate-bridge

## 历史版本号

- 当前版本：0.1.0

- 0.1.0

## 获取地址

- npm 安装：`npm install @c64cade/ultimate-bridge`
- npm registry：https://registry.npmjs.org/@c64cade/ultimate-bridge
- Node 要求：>=18
