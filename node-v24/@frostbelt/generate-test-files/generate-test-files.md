# @frostbelt/generate-test-files

> 标签: bandwidth-testing, cli, development-tools, file-generator, file-upload-testing, mock-files, storage-testing, test-data, test-files, testing-tools

## 简介

A powerful CLI tool for generating test files of various types and sizes. Perfect for testing file upload functionality, storage systems, and bandwidth limits. Supports text, binary, images, videos, and more.
