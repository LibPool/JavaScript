# @ait-co/polyfill

> 标签: apps-in-toss, mini-app, polyfill, toss, web-api, web-standard

## 简介

Polyfill so you can build Apps in Toss mini-apps with standard Web APIs (navigator.clipboard, navigator.geolocation, ...) that transparently route through the SDK at runtime
