# @antzsoft/filekit-server

> 标签: antz, azure, download, express, filekit, ftp, multipart, nestjs, presigned, s3, sftp, storage, thumbnails, upload

## 简介

FileKit server SDK — upload, download, fetch and signed URLs for S3, Azure Blob, local/mounted disk, remote file servers, SFTP and FTP, with multiple providers at once. Stateless: no database.
