# @ethora/chat-component

> 标签: chat, ethora, messaging, messenger, react, react-component, reactjs, web3, xmpp

## 简介

Open-source React chat and AI-agent UI SDK for Ethora: drop-in messaging, rooms, and AI bots with a self-hosted or cloud backend.
