# @justanarthur/modo-ui

> 标签: base-ui, components, design-system, fluid-functionalism, motion, react, tailwindcss, unocss

## 简介

Fluid Functionalism (Base UI flavor, MIT © 2026 Micka Touillaud) ported to UnoCSS: motion springs, fluid hover, a two-step size ladder and an eight-level elevated surface system. Documented with modo.
