# dsh-glass-ranswork

> 标签: deepseek-harness, dsh, dsh-bundle, dsh-plugin, glass, glassmorphism, theme, wallpaper

## 简介

自定义主题：给 DeepSeek Harness Web 界面加上「80% 半透明 + 背景模糊」的毛玻璃外观，并提供完整的主题设置页（透明度 / 模糊 / 饱和度 / 氛围光 / 配色 / 自定义背景图片）。
