# @maxessien/subsplease

> 标签: anime, api, client, rss, scraper, subsplease, subtitles, torrent

## 简介

A typed API client that fetches and parses subsplease.org (anime subtitles) into structured responses: schedules, show lists, episodes, and episode torrents.
