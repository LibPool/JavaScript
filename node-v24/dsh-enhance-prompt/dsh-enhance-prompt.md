# dsh-enhance-prompt

> 标签: deepseek-harness, dsh, dsh-plugin, prompt, prompt-enhancement

## 简介

DeepSeek Harness plugin: a composer button that rewrites the current draft into a clearer, more specific prompt with your own configured model, and can restore the draft it replaced.
