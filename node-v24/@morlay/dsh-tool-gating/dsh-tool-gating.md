# @morlay/dsh-tool-gating

> 标签: context-budget, dsh, dsh-plugin, preset, tools

## 简介

Gates the standard preset's model-visible tool catalog: a small always-on base group plus an enable_tools tool that unlocks further groups on request, so unused tool schemas and guidance never enter the prompt.
