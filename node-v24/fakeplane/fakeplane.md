# fakeplane

> 标签: agent-testing, ai-agents, ci, evals, fake-backend, linear, mcp, model-context-protocol, regression-testing, simulation, slack, zendesk

## 简介

Stateful fake Zendesk, Slack, Linear and HTTP backends for testing AI agents. Script scenarios, inject faults, assert on side effects, and block bad releases in CI.
