# @vdm-nexus/ai-sdk-provider

> 标签: ai-agents, ai-sdk, ai-sdk-provider, base, signed-inference, solana, usdc, vdmnexus, vercel-ai-sdk, x402

## 简介

Vercel AI SDK provider for VDM Nexus. One-line drop-in that handles the x402 USDC handshake and surfaces the SIR v2 signed-inference receipt via providerMetadata.
