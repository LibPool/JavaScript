# @vdm-nexus/mastra-provider

> 标签: ai-agents, base, mastra, signed-inference, solana, usdc, vdmnexus, x402

## 简介

Mastra provider for VDM Nexus. Drop-in nexusModel() helper that returns a Mastra-compatible LanguageModel paying via x402 and exposing the SIR v2 signed-inference receipt.
