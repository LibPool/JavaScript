# @dataoil/client

> 标签: database, dataoil, graph, ndjson, search, sql, vector

## 简介

The Data Oil client for JavaScript and TypeScript: one statement over rows, vectors, keywords and relationships, streamed as NDJSON, with the two tenancy headers, typed errors and the retry a lost race needs built in. No dependencies.
