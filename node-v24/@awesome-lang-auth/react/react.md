# @awesome-lang-auth/react

> 标签: auth, authentication, awesome-go-auth, awesome-node-auth, hooks, nextjs, react, react-native

## 简介

React bindings for the awesome-*-auth family: a typed, backend-agnostic client for the awesome-node-auth wire protocol (cookie on web, bearer on React Native).
