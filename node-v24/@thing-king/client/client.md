# @thing-king/client

> 标签: JavaScript

## 简介

`@thing-kint/client` is a simple, efficient library for interacting with the `thingking.org` platform. It allows you to manage **groups** (collections of things) and perform actions like creating, deleting, moving, and executing things within these groups
