# @tawaship/pixi-box2d

> 标签: box2dweb, pixi, pixi.js

## 简介

"pixi-box2d" is a plugin for using "[box2dweb](https://github.com/hecht-software/box2dweb)" with "[pixi.js](https://github.com/pixijs/pixi.js)".

## 官网

- 官网：https://tawaship.github.io/pixi-box2d/
- 源码仓库：git+https://github.com/tawaship/pixi-box2d.git
- npm 页面：https://www.npmjs.com/package/@tawaship/pixi-box2d
