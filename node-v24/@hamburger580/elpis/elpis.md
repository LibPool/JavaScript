# @hamburger580/elpis

> 标签: JavaScript

## 简介

Elpis 是一个企业级全栈应用框架，可以快速生成系统以及后续拓展。它将服务端（Koa）与前端工程（Webpack + Vue 3）整合为一套统一的开发范式，通过配置驱动的模型（Model）即可生成完整的 Dashboard 系统，同时提供多层级的扩展能力。
