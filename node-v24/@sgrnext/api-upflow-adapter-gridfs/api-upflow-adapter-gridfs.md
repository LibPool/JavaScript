# @sgrnext/api-upflow-adapter-gridfs

> 标签: api, backend, file, gridfs, handler, mongodb, multipart, nextjs, request, server, sugar, upload

## 简介

The @sgrnext/api-upflow-adapter-gridfs is an adapter for the @sgrnext/api-upflow plugin that stores files in GridFS
