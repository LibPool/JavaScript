# @ionicfi/js

> 标签: JavaScript

## 简介

Ionic browser payment SDK loader. Loads the Ionic SDK from https://js.ionicfi.com so card handling is never bundled into your app.

## 官网

- 官网：https://ionicfi.com
- npm 页面：https://www.npmjs.com/package/@ionicfi/js
