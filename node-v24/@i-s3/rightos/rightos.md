# @i-s3/rightos

> 标签: api, clinic, digital-ticket, ev-charging, i-s3, privacy, qr, queue, queue-management, rightos, verification

## 简介

TypeScript SDK for RightOS — privacy-first queue/EV/pickup QR API. No end-user PII. OpenAPI + MCP (@i-s3/rightos-mcp).
