# dsh-root-planner-preset

> 标签: agent-preset, cordis, deepseek-harness, delegation, dsh, guard, subagent, workspace-isolation

## 简介

DSH agent preset: the root agent plans and decides, subagent workers read, write and run commands inside their own _agents/ workspace, and nothing outlives its task.
