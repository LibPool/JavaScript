# @assistant-ui/metro

> 标签: assistant-ui, babel-transformer, expo, generative, metro, react-native, use generative

## 简介

Metro / Expo integration for assistant-ui: the "use generative" directive compiler that colocates a tool's schema, server execute, and client render in one file. Works with Expo and bare React Native.
