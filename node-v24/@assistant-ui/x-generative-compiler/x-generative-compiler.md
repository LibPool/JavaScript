# @assistant-ui/x-generative-compiler

> 标签: assistant-ui, compiler, generative, internal, rsc, use generative

## 简介

Internal: the framework-agnostic "use generative" compiler that splits a colocated tool (schema + server-only execute + client-only render) into per-target builds. Shared by @assistant-ui/next and @assistant-ui/vite.
