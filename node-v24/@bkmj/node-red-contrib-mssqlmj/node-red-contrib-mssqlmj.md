# @bkmj/node-red-contrib-mssqlmj

> 标签: JavaScript

## 简介

A ultra-fast, robust, and feature-rich Microsoft SQL Server node for Node-RED, built directly on top of the native `tedious` driver and powered by `tarn.js` connection pooling.
