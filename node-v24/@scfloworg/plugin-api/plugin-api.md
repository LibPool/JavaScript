# @scfloworg/plugin-api

> 标签: plugin, plugin-api, types, typescript

## 简介

TypeScript type declarations for plugins of the scaffold app framework. Types only — no runtime code. Regenerated from src/kernel by `bun run plugin-types:build`; never edit dist/ by hand.
