# @quidli/connect-mcp

> 标签: agent, agent-payments, ai, base, claude, claude-desktop, crypto, cursor, ethereum, farcaster, identity, identity-resolution, mcp, mcp-server, model-context-protocol, multiplayer-agents, onchain-reputation, payments, reputation, solana, usdc, wallet, wallet-lookup, web3-agent, x402

## 简介

MCP server for agent identity and reputation: resolve social handles to wallet addresses, score onchain reputation, and send USDC from any MCP client.
