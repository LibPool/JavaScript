# @coldsmirk/inkstone-codemirror

> 标签: codemirror, codemirror6, controlled, editor, host

## 简介

Framework-agnostic CodeMirror 6 plumbing: a controlled editor host (create-once, external-value reconcile, in-place theme swap), the standard document extension bundle, and the editors' catppuccin theming.
