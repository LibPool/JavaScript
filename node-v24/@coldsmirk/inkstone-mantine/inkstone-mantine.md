# @coldsmirk/inkstone-mantine

> 标签: catppuccin, code-highlight, mantine, shiki, syntax-highlighting

## 简介

Mantine adapter for the inkstone Shiki highlighter: a CodeHighlight adapter that renders through the shared singleton with its catppuccin pair — the same palette the inkstone editors use.
