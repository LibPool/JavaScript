# @coldsmirk/abacus-mantine

> 标签: codemirror, editor, expression, form, input, mantine, react, zen

## 简介

Mantine adapter for abacus: a Mantine-native <ExpressionField> that wraps the ZEN <ExpressionInput> in Input.Wrapper chrome, theme-bridged to Mantine's CSS variables.
