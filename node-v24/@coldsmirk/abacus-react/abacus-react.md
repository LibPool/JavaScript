# @coldsmirk/abacus-react

> 标签: autocomplete, codemirror, editor, expression, gorules, react, zen

## 简介

React <ExpressionInput> for editing ZEN expressions — type-aware completion, hover, and lint — with CSS-variable theming and no UI-framework dependency.
