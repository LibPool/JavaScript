# @coldsmirk/inkstone-react

> 标签: code-editor, codemirror, editor, monaco, react, shiki

## 简介

Drop-in React code editors: a preconfigured Monaco <MonacoEditor> (offline workers, Shiki catppuccin themes, dark switching, opt-in zh-CN UI) and a controlled CodeMirror 6 <CodeMirrorEditor> (catppuccin themes, dark switching, sizing).
