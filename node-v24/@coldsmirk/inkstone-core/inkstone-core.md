# @coldsmirk/inkstone-core

> 标签: catppuccin, editor, highlighter, shiki, syntax-highlighting

## 简介

Shared Shiki highlighter service for the inkstone editor toolkit: one fine-grained singleton (catppuccin themes, the JS regex engine by default or Oniguruma on request) reused by Monaco, static rendering, and markdown surfaces.
