# @vemonet/typodown

> 标签: editor, gfm, markdown, typora, wysiwyg

## 简介

A Typora-like WYSIWYG markdown editor for the web. Renders GitHub Flavored Markdown inline and reveals the raw markdown syntax on the block under the cursor.
