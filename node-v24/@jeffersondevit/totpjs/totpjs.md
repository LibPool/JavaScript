# @jeffersondevit/totpjs

> 标签: 2fa, crypto, hotp, mfa, native, otp, rfc-4226, rfc-6238, speakeasy, totp, two-factor, zero-dependency

## 简介

Zero-dependency, native TOTP (RFC 6238) implementation for Node.js. Drop-in replacement for speakeasy.
