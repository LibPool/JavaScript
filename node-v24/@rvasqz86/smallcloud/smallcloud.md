# @rvasqz86/smallcloud

> 标签: ai-agents, deploy, docker, magic-link, mcp, paas, sandbox, self-hosted

## 简介

Self-hosted cloud for small software: deploy static sites and Node.js apps to private, sandboxed, magic-link-protected HTTPS URLs in seconds. Agent-native (MCP), scale-to-zero, persistent storage, share-by-link.
