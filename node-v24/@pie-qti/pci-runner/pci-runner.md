# @pie-qti/pci-runner

> 标签: assessment, iframe, pci, portable-custom-interaction, qti, qti3, sandbox

## 简介

Deployable QTI 3.0 PCI sandbox runner: a static page that executes Portable Custom Interaction modules in a sandboxed cross-origin frame and bridges the spec contract over postMessage
