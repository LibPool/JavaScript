# @babelqueue/kafka

> 标签: apache-kafka, babelqueue, kafka, kafkajs, messaging, polyglot, queue

## 简介

Apache Kafka adapter for BabelQueue — canonical-envelope publisher and a URN-routed, process-then-commit consumer (SDK-owned retry topics + DLQ).
