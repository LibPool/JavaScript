# @adaptabletools/aql

> 标签: adaptable, adaptable query language, adaptabletools, aql, custom query language, data query, datagrid, query language

## 简介

Adaptable Query Language (AQL) is a powerful and flexible query language that allows users to query and filter data in a way that is both intuitive and powerful.
