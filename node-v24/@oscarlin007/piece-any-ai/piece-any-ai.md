# @oscarlin007/piece-any-ai

> 标签: activepieces, ai, byok, composio, llm, mcp, openai-compatible, openrouter

## 简介

Use your own LLM API key (OpenRouter, OpenAI, Groq, Ollama, or any OpenAI-compatible endpoint) inside Activepieces without spending AI credits. Includes TinyFish, MCP servers and Composio apps.
