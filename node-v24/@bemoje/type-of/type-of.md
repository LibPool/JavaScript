# @bemoje/type-of

> 标签: constructor's, evaluate, infinite, infinity', nan', null, property, representing, returns, string, typeof, undefined', value's, values

## 简介

Returns a string representing a value's constructor's name property, except for 'NaN', infinite values, 'Infinity', 'Null' and 'Undefined'.
