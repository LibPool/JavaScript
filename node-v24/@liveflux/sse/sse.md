# @liveflux/sse

> 标签: adapter, eventsource, liveflux, realtime, reconnect, server-sent-events, sse, typescript

## 简介

Server-Sent Events (SSE) adapter for Liveflux — an EventSource stream with reconnect and cursor resume, for any backend in any language.
