# @tipe/nuxt-apollo-module

> 标签: JavaScript

## 简介

> Nuxt.js module to use [vue-apollo](https://github.com/Akryum/vue-apollo) (integrates graphql-tag loader to parse `.gql` & `.graphql` files)
