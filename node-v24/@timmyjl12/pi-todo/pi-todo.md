# @timmyjl12/pi-todo

> 标签: agent, pi, pi-coding-agent, pi-extension, pi-package, task-tracking, tasks, todo

## 简介

Persistent, visible todo tracking for the pi coding agent — Claude Code-style task tools (TaskCreate/TaskGet/TaskList/TaskUpdate) with dependency edges, an above-editor widget, a statusline pill, and a /todo menu overlay.
