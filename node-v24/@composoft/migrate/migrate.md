# @composoft/migrate

> 标签: composoft, migration, next.js, react, static-analysis

## 简介

Static analyzer + interactive walkthrough that scopes a composoft migration from an existing React/Next.js codebase. v0 of the migration story; future iterations add the block extractor and embeddable runtime.
