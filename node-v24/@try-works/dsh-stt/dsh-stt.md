# @try-works/dsh-stt

> 标签: cactus, deepseek-harness, dictation, dsh, dsh-bundle, dsh-plugin, local-inference, on-device, speech-recognition, speech-to-text, transcription, voice-input, voz, whistle

## 简介

Multi-model local speech-to-text for the DSH Web composer: Whistle and Voz, user-selectable, with lazy per-model download. Ships as a DSH bundle.
