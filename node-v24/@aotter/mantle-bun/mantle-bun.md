# @aotter/mantle-bun

> 标签: JavaScript

## 简介

Embedded Bun adapter for Mantle Core with caller-owned bun:sqlite storage and Web-standard HTTP transport.

- 源码仓库：git+https://github.com/aotter/mantle.git
