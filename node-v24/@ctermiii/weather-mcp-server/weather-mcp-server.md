# @ctermiii/weather-mcp-server

> 标签: air-quality, chinese, claude, forecast, llm, mcp, model-context-protocol, open-meteo, pm2.5, precipitation, temperature, uv-index, weather

## 简介

MCP server for fetching weather data from Open-Meteo API with support for Chinese city names, 1-16 days forecast, temperature, wind, comfort index, precipitation, UV index, and PM2.5/PM10 air quality
