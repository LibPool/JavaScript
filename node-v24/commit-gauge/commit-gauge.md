# commit-gauge

> 标签: cli, commit-message, commit-msg, commitlint, conventional-commits, git, git-hooks, github-action, lint, sarif

## 简介

Lightweight Conventional Commits linter for git hooks and CI: lints a message, a file, stdin or a commit range, explains every problem and suggests a corrected header. Configurable types/scopes, sign-off and issue rules, hook installer. Text/JSON/SARIF/Ma
