# toto-stack

> 标签: authentication, csrf, express, framework, full-stack, mfa, prisma, rate-limiting, rbac, react, session, totp

## 简介

Secure full-stack web app foundation: Express 5 + Prisma sessions, auth (password + TOTP MFA), RBAC, CSRF, rate limiting, user management, background jobs and extensible services.
