# @genexus/vite-plugin-kasstor

> 标签: lit, lit decorators, vite, web components

## 简介

Vite plugin that wires @genexus/kasstor-build and @genexus/kasstor-insights into a single entry point and adds HMR for components built with @genexus/kasstor-core.
