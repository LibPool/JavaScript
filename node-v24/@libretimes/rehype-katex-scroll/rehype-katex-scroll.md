# @libretimes/rehype-katex-scroll

> 标签: academic, display-math, katex, math, overflow, rehype, rehype-plugin, scroll

## 简介

Rehype plugin that wraps KaTeX display math in a horizontally scrollable, edge-faded container so long formulae do not clip or break the page layout
