# @tandio/expctl-mcp

> 标签: ab-testing, expctl, experiment, mcp, tandio

## 简介

Tandio 实验平台 expctl 的 MCP server（stdio）——npx 一键启动，包装与 npm 版本同号的官方 expctl 二进制，不含任何重新实现的业务逻辑
