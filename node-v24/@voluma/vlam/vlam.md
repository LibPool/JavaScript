# @voluma/vlam

> 标签: 3dgs, 3dgs-lod, 3dgs-stream, gaussian-splatting, three-js, viewer, webgpu

## 简介

VLAM! - A lightweight WebGPU Gaussian splat viewer for three.js, built for high performance, streaming LOD, and fully customizable rendering through an open shader pipeline.
