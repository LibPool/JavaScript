# @vinyasa/patterns

> 标签: JavaScript

## 简介

8 composite page-and-workspace patterns built on top of the rest of `@vinyasa/*`: AppShell, SplitView, InspectorPanel, MultiPanelLayout, DashboardLayout, SettingsLayout, AnalyticsWorkspace, AIWorkspace.
