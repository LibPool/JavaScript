# @vinyasa/feedback

> 标签: JavaScript

## 简介

11 feedback primitives: Spinner, ProgressBar, CircularProgress, Alert, Banner, InlineMessage, Skeleton, LoadingOverlay, EmptyState, ErrorBoundary, Toaster (+ the `toast` imperative API).
