# @learnwy/presentation

> 标签: JavaScript

## 简介

Framework-free presentation helpers of the lwy apps (learnwy's personal tools): design tokens, preferences, sanitized Markdown, time, number, and text formatting, country data. Built for lwy; 0.x, any release may break.
