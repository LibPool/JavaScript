# saudi-cloud-cost-estimator-cli

> 标签: aws, azure, cli, cloud, cost, estimator, finops, gcp, gpu, ksa, oci, oracle, sar, saudi, vat

## 简介

Estimate and compare cloud costs for Saudi Arabia regions — in SAR, with 15% Saudi VAT. Covers Oracle Cloud (Riyadh/Jeddah), AWS (Bahrain), Azure (UAE) and Google Cloud (Dammam): compute (general/memory/compute-optimized + GPU profiles, or any custom SKU)
