# @takk/bayesdecide

> 标签: ab-testing, bandit, bayesian, best-arm, beta-bernoulli, conjugate-prior, contextual-bandit, edge, experimentation, llm, mcp, multi-armed-bandit, prompt-engineering, prompt-experimentation, sequential-testing, thompson-sampling, typescript, zero-dependency

## 简介

BayesDecide: Bayesian multi-armed bandits for continuous prompt experimentation. Thompson sampling routes more traffic to the prompt variant that looks best while staying calibrated, and a stopping rule promotes a winner without waiting for a fixed-N A/B
