# @takk/coryphaeus

> 标签: agent-graph, ai-agents, budget, edge, llm-orchestration, local-first, mcp, model-routing, multi-agent, nodejs, observability, openai-compatible, orchestration, orchestrator, provider-agnostic, typescript, vercel-ai-sdk, zero-dependency

## 简介

Open, local-first, provider-agnostic multi-agent orchestrator: compose frontier models as a coordinated team with Thinker/Worker/Verifier roles, cost budgets, and an auditable agent graph. Zero dependencies, node-free core, TypeScript-first.
