# @takk/keymesh

> 标签: ai-infrastructure, anthropic, api-keys, circuit-breaker, failover, gemini, key-rotation, llm, load-balancing, openai, proxy, rate-limit, resilience, retry, rotation

## 简介

Universal, zero-runtime-dependency NPM library and CLI for intelligent API key rotation, failover, load balancing, circuit breaking, and rate-limit recovery. Drop-in adapters for OpenAI, Anthropic, Gemini, and any HTTP endpoint.
