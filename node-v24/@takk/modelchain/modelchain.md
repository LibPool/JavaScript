## 简介

Universal, drop-in, measurable LLM router with native streaming and tool calling. Routes prompts across OpenAI, Anthropic, Gemini and any OpenAI-compatible HTTP endpoint by cost, latency and observed quality. Includes a Vercel AI SDK adapter. Zero runtime
