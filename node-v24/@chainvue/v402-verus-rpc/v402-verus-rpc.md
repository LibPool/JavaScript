# @chainvue/v402-verus-rpc

> 标签: JavaScript

## 简介

Minimal, v402-scoped Verus daemon JSON-RPC client: only the RPC methods the v402 payment stack needs, wrapped in a 500ms-timeout + circuit-breaker policy. Includes a mock implementation for tests. Deliberately not a general-purpose Verus client.
