# @chainvue/peculium-wallet

> 标签: agent-payments, ai-agent, mcp, model-context-protocol, v402, verus, verusid, vrsc, wallet

## 简介

Peculium — the safe Verus wallet for AI agents. MCP server + CLI: local offline signing, public nodes, human-configured policy the agent cannot change.
