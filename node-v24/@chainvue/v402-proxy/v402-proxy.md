# @chainvue/v402-proxy

> 标签: JavaScript

## 简介

v402 reverse proxy: a standalone payment guard in front of ANY origin (static site, WordPress, arbitrary API). Matches route rules, challenges with 402, verifies/reserves via a v402 facilitator (HTTP mode), streams paid requests through to the upstream —
