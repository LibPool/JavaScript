# @anyfu/dict-vue

> 标签: dict, dictionary

## 简介

`@anyfu/dict-vue`是使用`@anyfu/dict-core`中`createDictManager`封装的 Vue Hooks, 并且提供完整的字典数据管理功能以及相应的工具函数。

## 官网

- 官网：https://dict-manager.vercel.app
- 源码仓库：git+https://github.com/sufangyu/anyfu-dict.git
- npm 页面：https://www.npmjs.com/package/@anyfu/dict-vue
