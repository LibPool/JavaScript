# pi-context-decisions

> 标签: classifiers, context, decisions, pi, pi-extension, pi-package, skills

## 简介

Pi extension that uses decision/classifier models (Pi, TypeSafe JEV, OpenAI, OpenRouter) to filter which skills are advertised and, opt-in, which external tools and MCP servers are available for each prompt
