# @pinarkive/pinarkive-sdk-ts

> 标签: api, cluster, ipfs, pinarkive, pinning, sdk, timelock, typescript, v3

## 简介

TypeScript SDK for the Pinarkive API v3 - fetch-based, Bearer auth, clusterId (cl) and timelock support. Replaces secureFetch/publicFetch in apps.
