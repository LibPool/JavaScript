# use-sync-external-store

> 标签: JavaScript

## 简介

Backwards compatible shim for React's useSyncExternalStore. Works with any React that supports hooks.

## 官网

- 官网：https://github.com/react/react#readme
- 源码仓库：git+https://github.com/react/react.git
- npm 页面：https://www.npmjs.com/package/use-sync-external-store
