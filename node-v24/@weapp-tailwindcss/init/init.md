# @weapp-tailwindcss/init

> 标签: JavaScript

## 简介

Project initializer for cross-platform Tailwind CSS with weapp-tailwindcss. 用于初始化跨端 Tailwind CSS 项目的 weapp-tailwindcss 工具。

## 官网

- 官网：https://tw.weapp.dev/docs/quick-start/install
- 源码仓库：git+https://github.com/sonofmagic/weapp-tailwindcss.git
- npm 页面：https://www.npmjs.com/package/@weapp-tailwindcss/init
