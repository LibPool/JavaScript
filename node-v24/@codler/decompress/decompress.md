# @codler/decompress

> 标签: buffer, bz2, bzip2, decompress, extract, gzip, readableStream, streams, tar, tar.bz, tar.gz, unzip, web streams, zip

## 简介

Decompress is a Node.js module for decompressing files and archives. It supports various formats and provides an easy-to-use API for extracting files from compressed archives.
