# @basaltkit/audit-prisma

> 标签: audit, basalt, postgresql, prisma, store, typescript

## 简介

Prisma-backed implementation of the @basaltkit/audit AuditStore (append-only trail) — the production reference backend (PostgreSQL/MySQL). Bring your own PrismaClient; ships a reference schema.
