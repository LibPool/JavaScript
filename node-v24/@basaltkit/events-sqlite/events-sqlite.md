# @basaltkit/events-sqlite

> 标签: basalt, events, outbox, sqlite, store, typescript

## 简介

Durable, SQLite-backed implementation of the @basaltkit/events OutboxStore (transactional outbox), on Node's built-in node:sqlite. Zero external dependencies.
