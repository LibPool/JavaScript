# @basaltkit/subscriptions

> 标签: basalt, billing, saas, stripe, subscriptions, typescript

## 简介

Billing for Basalt, Cashier/Soulbscription-style: declarative plans, subscriptions with trials, feature flags, usage limits, gateway drivers and idempotent webhooks.
