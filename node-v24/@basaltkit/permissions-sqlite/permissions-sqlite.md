# @basaltkit/permissions-sqlite

> 标签: basalt, permissions, rbac, sqlite, store, typescript

## 简介

Durable, SQLite-backed implementation of the @basaltkit/permissions AccessStore, on Node's built-in node:sqlite. Zero external dependencies.
