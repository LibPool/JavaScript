# @basaltkit/events-prisma

> 标签: basalt, events, outbox, postgresql, prisma, store, typescript

## 简介

Prisma-backed implementation of the @basaltkit/events OutboxStore (transactional outbox) — the production reference backend (PostgreSQL/MySQL). Bring your own PrismaClient; ships a reference schema.
