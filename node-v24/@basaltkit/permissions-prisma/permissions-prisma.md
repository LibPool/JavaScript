# @basaltkit/permissions-prisma

> 标签: basalt, permissions, postgresql, prisma, rbac, store, typescript

## 简介

Prisma-backed implementation of the @basaltkit/permissions AccessStore — the production reference backend (PostgreSQL/MySQL). Bring your own PrismaClient; ships a reference schema.
