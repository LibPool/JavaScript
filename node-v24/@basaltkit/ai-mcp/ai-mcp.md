# @basaltkit/ai-mcp

> 标签: ai, basalt, claude, developer-experience, mcp, model-context-protocol, stdio

## 简介

Dev-only MCP bridge that exposes Basalt's AI developer workflows (analyze, doctor — plan/make/review to follow) to MCP clients (Claude Desktop/Code) over stdio. Never a runtime dependency of an app: it only uses the framework's official public APIs.
