# @basaltkit/search-elasticsearch

> 标签: basalt, elasticsearch, full-text, opensearch, search, typescript

## 简介

Elasticsearch / OpenSearch driver for @basaltkit/search — multi_match relevance, tenant-scoped, talking to the REST API directly with an injectable fetch (no SDK).
