# @basaltkit/exports-xlsx

> 标签: basalt, excel, export, typescript, xlsx

## 简介

XLSX formatter for @basaltkit/exports — writes a valid single-sheet .xlsx (Office Open XML) with a built-in ZIP writer. Zero dependencies.
