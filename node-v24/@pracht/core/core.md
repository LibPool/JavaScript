# @pracht/core

> 标签: api-routes, framework, full-stack, isg, loaders, pracht, preact, routing, ssg, ssr

## 简介

Core runtime for Pracht, a full-stack Preact framework with per-route SSR, SSG, ISG, SPA, loaders, and API routes.
