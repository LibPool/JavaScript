# @khulnasoft/gatsby-plugin-khulnasoft-builder

> 标签: JavaScript

## 简介

This plugin generates [Vercel Build Output API v3](https://khulnasoft.com/docs/build-output-api/v3) for Gatsby v4+ projects.
