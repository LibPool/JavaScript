# @notnotype/nb-agent-ui

> 标签: JavaScript

## 简介

Agent 对话视图：核心（视图类型、分轮与摘要、发送规则、harness 适配器）是纯 TS；Vue 渲染层建在 nb-ui 之上，Markdown 与提示词编辑器由宿主注入。
