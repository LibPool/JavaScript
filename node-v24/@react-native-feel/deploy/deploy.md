# @react-native-feel/deploy

> 标签: android, eas, expo, github-actions, ios, react-native, testflight

## 简介

React Native Deploy: the eas build/submit commands and your eas.json, with builds running on GitHub Actions runners and store delivery handled by the asc CLI.
