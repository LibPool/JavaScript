# @pressline/render

> 标签: image, png, pressline, print-on-demand, printfile, render, sharp, wasm

## 简介

Render helper for Pressline Engines: fit, pad and stamp an image into a print-ready PNG for a Printfile Spec, on Node (sharp) or in a Worker (WASM)
