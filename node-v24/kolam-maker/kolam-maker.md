# kolam-maker

> 标签: dot-grid, esoterica, generator, javascript, kolam, kolam-generator, mirror-curves, one-line-drawing, pulli-kolam, pwa, rangoli, sacred-geometry, sikku-kolam, south-india, svg

## 简介

Kolam Maker: generate South Indian sikku kolams, dot-grid designs where a single unbroken line loops around every dot. Watch it being drawn, edit it, and download it as SVG or PNG.
