# @teamsofie/base-components

> 标签: buttons, components, css, dark-mode, design-system, forms, react, sofie, teamsofie, ui

## 简介

Sofie UI — de officiële CSS component library van Team Sofie. Bevat buttons, formulieren, modals, navigatie, tabellen, badges en meer. Volledig token-based met light en dark theme support.
