# @telaro/llm

> 标签: ai-agents, autogen, crewai, eliza, langchain, llamaindex, openai, telaro

## 简介

Telaro LLM-framework adapters bundle. Wrap autogen, crewai, eliza, langchain, llamaindex, or openai-agents runtimes so every tx-emitting action auto-records on Telaro. One install, one import per framework.
