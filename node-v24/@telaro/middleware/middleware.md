# @telaro/middleware

> 标签: ai-agents, middleware, reputation, solana, telaro, trust-gate

## 简介

Generic Telaro trust-gate middleware. Wraps any TypeScript SDK to enforce on-chain bond + score policy before tx-emitting methods.
