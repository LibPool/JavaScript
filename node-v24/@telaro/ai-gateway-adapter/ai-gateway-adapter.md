# @telaro/ai-gateway-adapter

> 标签: agents, ai-gateway, cloudflare-ai-gateway, mcp, openrouter, telaro, trust

## 简介

Wrap the Telaro MCP toolset as a single tool callable from AI gateways (OpenRouter, Cloudflare AI Gateway). One adapter import gives any model served through the gateway access to bonded-agent trust lookups, marketplace search, and dispute reads.
