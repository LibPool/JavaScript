# @telaro/sacp-mcp

> 标签: JavaScript

## 简介

Expose a sACP-registered Offering as a Model Context Protocol (MCP) agent. Buyers discover via /.well-known/agent-card.json, drive work via /mcp/invoke, settlement via sACP.
