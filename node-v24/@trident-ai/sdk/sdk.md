# @trident-ai/sdk

> 标签: anthropic, langchain, llm-security, observability, openai, openllmetry, prompt-injection, tracing, trident

## 简介

Trident SDK for TypeScript/Node. One init() call auto-instruments OpenAI, Anthropic, LangChain, Bedrock, and ships OTel spans to your Trident project.
