# @neural4d/model-viewer-source-zip

> 标签: JavaScript

## 简介

The lazy ZIP Source capability for Neural4D Model Viewer. It extracts a ZIP input into a Core `AssetBundle`; model format detection and parsing remain in the format Loader packages.
