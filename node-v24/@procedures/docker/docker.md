# @procedures/docker

> 标签: automation, containers, devops, docker, docker-compose, procedures

## 简介

Docker and Docker Compose as typed procedures: ps, run, exec, logs (streaming), build, pull, push, tag, images, inspect, volumes, networks, prune, stop, rm, compose up, down, ps, logs, build and restart, run with argv and no shell injection.
