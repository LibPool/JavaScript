# @procedures/compiler

> 标签: capabilities, codegen, compiler, dsl, effects, procedures, static-analysis, workflow

## 简介

The compiler of procedure programs: it checks a JSON program before the first call (scopes, effects, schemas, capability) and writes it as a plain async function.
