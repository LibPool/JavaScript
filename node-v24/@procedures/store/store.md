# @procedures/store

> 标签: json-programs, persistence, procedures, program-store, registry, rpc

## 简介

A program store for procedure-as-data: save the programs that procedure.define makes, load them back after a restart, in memory, a JSON file, IndexedDB or a remote collection storage.
