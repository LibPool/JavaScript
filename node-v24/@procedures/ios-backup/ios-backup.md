# @procedures/ios-backup

> 标签: backup, imessage, ios, iphone, mobilesync, procedures, sms

## 简介

Read an iPhone backup (MobileSync): find the newest backup, find a file in Manifest.db, read the messages of sms.db. No native dependency.
