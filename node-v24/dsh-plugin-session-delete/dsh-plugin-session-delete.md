# dsh-plugin-session-delete

> 标签: cordis, deepseek-harness, delete, dsh, plugin, session

## 简介

Delete a DeepSeek Harness session permanently and with zero local residue: sidebar menu entry with confirmation, stops running work, refuses sessions with forked children, and clears the event log, workspace accounting, archive/pin sets, projection cache,
