# @siegesailor/terminal-sigma

> 标签: command-line-tool, ink, pomodoro, self-development, terminal-dashboard, typescript

## 简介

A long-running terminal dashboard that turns self-development into a game: a Tomato Timer, diet and workout trackers, everyday quotes, and a character that levels up with you.
