# @chonla/playwright

> 标签: api-testing, decorators, e2e, mixin, page-object-model, playwright, pom, rest, standard-schema, test.step, zod

## 简介

Readable page objects and API clients for Playwright: @step for business-readable reports, @PageWith/@ApiWith mixins, @Get/@Post endpoint decorators, and schema-validated responses.
