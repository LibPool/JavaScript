# @jaivalsaija/react-rough-notation

> 标签: annotate, react, react-component, rough, sketchy

## 简介

React wrapper for RoughNotation (https://roughnotation.com/), a small JavaScript library to create and animate annotations on a web page. Maintained fork of react-rough-notation by Link Strifer.
