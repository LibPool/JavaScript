# @surfmate.team/digital-human-storage

> 标签: JavaScript

## 简介

Shared blob-storage adapter for the digital-human suite: implements each feature's storage port (e.g. ui-config's AvatarStoragePort) against Supabase Storage using a client the app injects. Never calls createClient; holds no credentials.
