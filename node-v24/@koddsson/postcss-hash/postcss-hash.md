# @koddsson/postcss-hash

> 标签: cache, cache-buster, cache-busting, cachebuster, css, hash, manifest, md2, md4, md5, mdc2, name-changer, postcss, postcss-hash, postcss-plugin, ripemd160, sha, sha1, sha224, sha256, sha384, sha512

## 简介

PostCSS plugin to replace output file names with HASH algorithms (md5, sha256, sha512, etc) and string length of your choice - for cache busting
