# dsh-taskboard-kit

> 标签: agent, collaboration, cordis, deepseek-harness, dsh, kanban, local-first, plugin, taskboard

## 简介

dsh (DeepSeek Harness) taskboard kit: one local task board per workspace. Agents create/claim/progress tasks with model tools; humans watch and drive the same board in a kanban tab — a single JSON file in the workspace is the only source of truth, no serv
