# @cimom-ui/standard-ui

> 标签: components, element-ui, ipqc, vue, vue2, vxe-table

## 简介

标准组件库：基于 Vue 2.6 + Element UI 2.x + vxe-table 3.24.x 的通用业务组件（按钮、弹窗、筛选栏、表单、表格、树、分割条等）
