# @awryhant/pdfmath

> 标签: ai-agents, cli, compress, mcp, mcp-server, merge, model-context-protocol, offline, pdf, repl, scripting, slice, split

## 简介

PDF arithmetic from the command line and as an MCP server: merge, cut, slice (Python-style), rotate and compress PDFs, with a Python-like scripting language (.pm). Fully offline.
