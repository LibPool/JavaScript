# @paneui/mcp

> 标签: agent, human-in-the-loop, mcp, model-context-protocol, pane, relay

## 简介

Model Context Protocol (stdio) server for Pane: lets any MCP client (Claude Desktop, Cursor, …) hand a human a rich interactive UI by URL and get structured data back.
