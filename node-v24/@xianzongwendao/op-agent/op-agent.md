# @xianzongwendao/op-agent

> 标签: agent, audit, cli, devops, linux, monitoring, operations, ops, pi-coding-agent, safety, sre

## 简介

A lightweight Linux operations agent built on the pi coding agent SDK - safety-first, single-process, embedded SQLite, runs on 1c1g servers.
