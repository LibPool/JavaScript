# @veris-ai/e2b-opencode

> 标签: e2b, integration-testing, opencode, opencode-plugin, sandbox, veris

## 简介

OpenCode plugin that runs every session in an E2B sandbox whose vendor API calls are answered by a Veris twin, with a receipt of what the vendor received.
