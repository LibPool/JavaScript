# @shumkov/orchestra

> 标签: channels, claude, claude-cli, claude-code, codex, mcp, openai, polygram, session-pool, tmux, water

## 简介

Transport-agnostic session engine for Claude Code and the native Codex app-server: spawn, steer, supervise, observe turns, and recover.
