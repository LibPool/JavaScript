# @edgeros/jsre-sqlnet

> 标签: JavaScript

## 简介

SqlNet 是一个基于 SQLite3 的网络化 SQL 数据库服务，基于 EdgerOS (JSRE) 运行时环境设计。它提供了一个 TCP 服务器，通过自定义二进制协议处理 SQL 查询，支持 SQLite3 的所有功能。
