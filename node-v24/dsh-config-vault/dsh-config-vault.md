# dsh-config-vault

> 标签: backup, config, configuration, deepseek, deepseek-harness, dsh, dsh-plugin, restore, rollback, snapshot

## 简介

配置保险箱：为 DeepSeek Harness 配置创建快照、对比差异并安全回滚（设置补丁、插件清单、技能规则、工作区列表），恢复前自动安全快照，凭据默认排除。零构建、零运行时依赖。
