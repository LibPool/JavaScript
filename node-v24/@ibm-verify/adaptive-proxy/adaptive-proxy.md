# @ibm-verify/adaptive-proxy

> 标签: JavaScript

## 简介

The Proxy SDK for server-side JavaScript ([Node](https://nodejs.org)). The purpose of this library is to provide an interface for device authentication, authorization, and risk assessment using IBM Verify.
