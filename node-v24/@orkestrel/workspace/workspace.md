# @orkestrel/workspace

> 标签: edit, file, search, snapshot, typescript, workspace

## 简介

A virtual file workspace for the @orkestrel line — path-keyed immutable files, an edit and search surface, registries with an active pointer, and pluggable snapshot stores. Part of the @orkestrel line.
