# @orkestrel/workflow

> 标签: orchestration, runner, scheduler, task, typescript, workflow

## 简介

A typed workflow engine for the @orkestrel line — a serializable Workflow → Phase → Task tree run by a composed runner on a cooperative scheduler. Part of the @orkestrel line.
