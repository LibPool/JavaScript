# @orkestrel/program

> 标签: aggregate, authority, composition, decision, engine, notices, orchestration, orkestrel, program, qualification, rating, rules, typescript

## 简介

A program composition layer that orchestrates @orkestrel/qualifier and @orkestrel/rater into one execute workflow with notices, authority, status, decisions, and batch aggregation. Part of the @orkestrel line.
