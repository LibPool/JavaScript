# @richardmcquiston01/error-log-adapter-neo4j

> 标签: adapter-pattern, cypher, error-logging, graph, logger, neo4j, typescript

## 简介

Neo4j adapter for @richardmcquiston01/error-log-adapter: stores each error as an ErrorLog node merged on the entry id, so retries never duplicate.
