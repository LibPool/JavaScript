# @richardmcquiston01/monogram-font-maker

> 标签: font, font-generator, laser, monogram, opentype, otf, svg, ttf

## 简介

Framework-agnostic TypeScript library that turns a set of monogram letter SVGs into an installable OTF/TTF font, so laser-template tools don't need every letter imported as a separate image.
