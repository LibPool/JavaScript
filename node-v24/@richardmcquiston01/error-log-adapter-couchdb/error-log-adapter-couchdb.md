# @richardmcquiston01/error-log-adapter-couchdb

> 标签: adapter-pattern, couchdb, error-logging, logger, nano, typescript

## 简介

CouchDB adapter for @richardmcquiston01/error-log-adapter: stores each error as a document whose _id is the entry id, so retries never duplicate.
