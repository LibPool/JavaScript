# @richardmcquiston01/material-colors-grid

> 标签: 3d-printing, canvas, color-grid, color-palette, color-swatch, filament, filament-colors, image-generator, material-colors, png-export, product-listing, product-page, swatch-grid, typescript

## 简介

Framework-agnostic TypeScript library that renders a grid of material colors (e.g. filament colors) to a canvas and exports PNG images for product pages.
