# browser-input-method

> 标签: handwriting, input, input method, pinyin, 手写, 拼音, 汉语, 浏览器, 输入法

## 简介

浏览器输入法。支持汉语拼音全拼输入、英文输入、手写输入。内置虚拟键盘，可选全键盘、手写、整数、数字、身份证键盘布局。
