# bloxscout-mcp

> 标签: agent, analytics, claude, cursor, game-analytics, llm, mcp, mcp-server, model-context-protocol, roblox, roblox-api

## 简介

MCP server for bloxscout — live Roblox analytics for AI agents (Claude, ChatGPT, Cursor, Zed). Thin launcher that re-exports the MCP entrypoint from the bloxscout package.
