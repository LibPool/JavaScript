# babel-plugin-transform-lang-cli

> 标签: ac-lang-cn, babel-handbook, i18n-ast, react-demo-bable

## 简介

提供一个提取代码中,中文的一个bable插件,原理是通过词法分析（Lexical Analysis）,在Babel转码得到AST 来实现
