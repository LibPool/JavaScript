# babel-plugin-tsconfig-alias-to-relative

> 标签: relative-alias-to-relative, ts-alias-to-relative-path, tsconfig-path-alias-resolver

## 简介

A utility to resolve tsconfig path aliases to the relative path style while babel transpile codes
