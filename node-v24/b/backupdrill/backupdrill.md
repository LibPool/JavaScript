# backupdrill

> 标签: backblaze-b2, backup, cloudflare-r2, database-backup, disaster-recovery, pg_dump, postgres, postgresql, restore, s3, supabase, supabase-backup

## 简介

Open-source CLI to back up a Supabase project — Postgres database and Storage files — to your own S3/R2/B2 bucket, with a checksummed manifest.
