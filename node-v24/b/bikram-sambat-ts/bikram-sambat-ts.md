# bikram-sambat-ts

> 标签: ad-to-bs, bikram-sambat, bs, bs-to-ad, calendar, date, date-conversion, nepal, nepali-calendar, nepali-date

## 简介

Lightweight, dependency-free TypeScript library for converting dates between Gregorian (AD) and Bikram Sambat (BS), the calendar used in Nepal.
