# babel-plugin-transform-cjs-exports

> 标签: babel, codemod, commonjs, es6, exports, plugin, transform

## 简介

A Babel plugin that transforms CommonJS `exports.name = value` syntax into ES6 `export const name = value`.

## 官网

- npm 页面：https://www.npmjs.com/package/babel-plugin-transform-cjs-exports

- 1.0.0

- npm registry：https://registry.npmjs.org/babel-plugin-transform-cjs-exports
