# better-goal

> 标签: JavaScript

## 简介

`better-goal` is a foreground Thin Dispatcher for a single GitHub repository. It selects one queued issue, claims it, starts a persisted Codex Run, and advances only after the issue's Completion Gate is observable on GitHub.
