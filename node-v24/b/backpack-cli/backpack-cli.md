# backpack-cli

> 标签: oclif

## 简介

A quick CLI tool to help hotswap your machine by backing up your local setup.

- 官网：https://github.com/manuphatak/backpack-cli
- 源码仓库：https://github.com/manuphatak/backpack-cli.git
