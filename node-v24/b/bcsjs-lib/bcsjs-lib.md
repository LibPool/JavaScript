# bcsjs-lib

> 标签: bcschain, bcsjs, bitcoinjs, smart contract

## 简介

This is an extend lib for bitcoinjs-lib. It extends the network type of bitcoinjs-lib. It also provides an useful lib to help you building BCSChain transactions.
