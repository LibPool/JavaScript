# brewdown

> 标签: D&D, dungeons-and-dragons, homebrew, markdown, markdown-it, markdown-it-plugin, rpg

## 简介

A flavour of markdown and stylesheet specifically for D&amp;D 5th edition homebrew, implemented as a plugin for markdown-it.
