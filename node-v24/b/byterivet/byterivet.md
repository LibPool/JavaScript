# byterivet

> 标签: cli, csv, docx, dummy-file, file-generator, fixtures, pdf, png, qa, sample-files, test-files, upload-testing, xlsx, zip

## 简介

Generate valid test files of an exact byte size (1 byte to 2 GB) in 20 formats: PDF, PNG, DOCX, XLSX, CSV, JSON, ZIP, MP4, WAV and more.
