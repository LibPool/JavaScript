# base-security-scanner-mcp

> 标签: ai-agent, ai-agents, audit, autonomous-agent, base, base-chain, blockchain, bytecode, claude, claude-code, erc20, ethereum, honeypot, mcp, mcp-server, model-context-protocol, rug-pull, scanner, security, smart-contract, solidity

## 简介

MCP server for AI agents to scan and audit smart contracts on Base for security vulnerabilities. Detect honeypots, rug pulls, hidden mints, proxy risks, and generate full audit reports.
