# bullmq-groups

> 标签: bullmq, bullmq-pro, fairness, fifo, groups, nestjs, queue, redis

## 简介

Per-group FIFO and fairness for open-source BullMQ: an alternative to BullMQ Pro's groups, with the same API and a NestJS module
