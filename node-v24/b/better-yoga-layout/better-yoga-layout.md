# better-yoga-layout

> 标签: css, flexbox, layout, performance, wasm, yoga

## 简介

A performance-refactored fork of Yoga: an embeddable, performant flexbox layout engine with WASM bindings. Drop-in replacement for yoga-layout, faster on real-world UI trees.
