# babel-plugin-transform-rxscss

> 标签: JavaScript

## 简介

需要将`import styles from './styles.rxscss'` 转成`import * as styles from './styles.rxscss'`

- npm 页面：https://www.npmjs.com/package/babel-plugin-transform-rxscss
