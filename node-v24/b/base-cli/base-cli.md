# base-cli

> 标签: app, application, arg, args, base, baseplugin, cache, cli, command, command-line, config, data, extend, flag, flags, line, merge, method, methods, option, options, opts, plugin, store, terminal

## 简介

Plugin for base-methods that maps built-in methods to CLI args (also supports methods from a few plugins, like 'base-store', 'base-options' and 'base-data'.
