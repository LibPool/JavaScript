# basic-file-preview

> 标签: basic-file-preview, file-preview, json, markdown, office, txt, vue3

## 简介

这是一个基于 vue3、element-plus 封装的文件预览组件，目前仅支持预览以（pdf、docx、xlsx、pptx、txt、json、md）格式结尾的文件以及常规格式的图片，并提供水印功能
