# ble-bump

> 标签: ble, bluetooth, bump, minigame, miniprogram, wechat

## 简介

微信小程序/小游戏「碰一碰」核心能力包：BLE 外围广播 + 中心扫描 + 撮合编排。零框架依赖，通过依赖注入接入任意宿主（Cocos 小游戏 / uniapp 小程序 / 原生小程序）。
