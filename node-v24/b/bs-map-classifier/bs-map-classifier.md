# bs-map-classifier

> 标签: beat-saber, classifier, ml, onnx, pattern-detection, rhythm-game

## 简介

Classify Beat Saber maps into Tech / Speed / Accuracy / Standard / Extreme using an ONNX model trained on note-level pattern features. Works in Node.js and browser.
