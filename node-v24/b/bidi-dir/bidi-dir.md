# bidi-dir

> 标签: arabic, bidi, bidirectional, dir-auto, direction, farsi, hebrew, i18n, ltr, persian, rtl, unicode

## 简介

Resolve text direction by dominant script, not by the first character. Fixes mixed Persian/Arabic/Hebrew text that dir="auto" renders backwards.
