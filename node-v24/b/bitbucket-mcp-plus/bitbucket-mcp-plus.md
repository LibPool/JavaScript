# bitbucket-mcp-plus

> 标签: ai, bitbucket, bitbucket-cloud, bitbucket-server, llm, mcp, model-context-protocol

## 简介

Model Context Protocol (MCP) server for Bitbucket Cloud and Server API integration (fork of bitbucket-mcp with extra tooling: batch comment removal, reviewer management, local image uploads)
