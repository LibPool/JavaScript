# bridgy

> 标签: developer tools, expose local server, http tunnel, https tunnel, local to live, localhost, localtunnel, ngrok, port forwarding, public url, reverse proxy, share localhost, tunnel, webhook testing, websocket tunnel

## 简介

Lightweight tunneling tool to expose localhost to a secure public URL. Instantly share local servers, test webhooks, and access apps globally.
