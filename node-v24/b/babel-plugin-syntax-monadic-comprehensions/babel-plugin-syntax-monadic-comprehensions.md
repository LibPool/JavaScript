# babel-plugin-syntax-monadic-comprehensions

> 标签: babel, babel-plugin, comprehension, es7, for, haskell, monad, scala, syntax

## 简介

A plugin for Babel 7 that (mostly) transforms for comprehensions to flatMaps/maps.
