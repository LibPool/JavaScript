# borgo-framework

> 标签: bun, code-generation, fast-refresh, file-based-routing, framework, fullstack, go, golang, islands, nextjs-alternative, react, self-hosted, sse, ssr, typescript, websockets

## 简介

The self-hosted React framework: file-based React SSR on Bun, API routes in Go, typed end to end. Vercel DX, Go performance, no platform lock-in.
