# brex

> 标签: api, brex, expenses, fintech, openapi, payments, sdk, typescript

## 简介

Unofficial TypeScript SDK for the Brex API, generated deterministically from Brex's OpenAPI specs. Tree-shakeable, ESM-only, zero dependencies.
