# bexio-mcp

> 标签: accounting, api-client, bexio, invoicing, mcp, model-context-protocol, switzerland

## 简介

MCP server and typed TypeScript client for the bexio API (Swiss business software): contacts, quotes, orders, invoices, purchase, accounting, banking, items, projects, time tracking, files and payroll.
