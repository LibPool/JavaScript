# billion-context-opencode

> 标签: JavaScript

## 简介

ACP (Active Context Pruning) compression adapter for opencode — one package that loads on both opencode V1 (experimental.chat.* hooks) and V2 (Plugin.define). Model-driven context management via acp-kernel: bili_compress / bili_decompress / bili_search /
