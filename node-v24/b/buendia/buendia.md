# buendia

> 标签: SQLite, drizzle, expo, full-stack, javascript, libSQL, node, react, react-native, tamagui

## 简介

A full-stack JS framework uniting Expo's and Tamagui for cross-platform UI with Node.js backend, featuring built-in auth, and a blend of Drizzle and SQLite for versatile data handling.
