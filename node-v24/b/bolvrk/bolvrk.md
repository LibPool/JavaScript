# bolvrk

> 标签: credentials, database, github-action, linter, mcp, mcp-server, migrations, postgres, schema, secrets, sqlite, static-analysis

## 简介

Bolvrk CLI — the deterministic checker for code. Verifies database migrations (Postgres, SQLite in beta) and scans for committed credentials; runs as a CLI and an MCP server. Free rules run locally; the full corpus runs in the hosted service.
