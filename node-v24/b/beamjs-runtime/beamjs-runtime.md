# beamjs-runtime

> 标签: actor-model, beam, concurrent, elixir, erlang, fault-tolerant, genserver, javascript, otp, pattern-matching, pipe-operator, quickjs, runtime, supervisor, typescript

## 简介

JavaScript/TypeScript runtime built on the BEAM VM (Elixir/Erlang) with QuickJS. Erlang/OTP superpowers for JS: lightweight processes, supervision trees, GenServer, pattern matching, pipe operator.
