# bastok

> 标签: 6502, BASIC, detokenizer, homebrew, petcat, prg, retrocomputing, tokenizer, typescript

## 简介

Convert BASIC ASCII text to tokenized binaries (.prg/.bas) and back for the AC6502 BIOS's BASIC
