# bedaya-poller

> 标签: JavaScript

## 简介

- Go in the console to the app directory. - Run the build: npm run build - docker build -t badayait/bedaya-trigger . - docker push badayait/bedaya-trigger:latest - if your are not logged in: docker login --username=badayait
