# balade

> 标签: agentic-development, ai-generated-code, code-review, coding-agent, developer-tools, effect, github, pull-request, pull-request-review, walkthrough

## 简介

Human-readable walkthroughs for agent-scale pull requests. A bring-your-own-agent CLI that turns walkthrough files into interactive review apps.
