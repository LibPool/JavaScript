# botlock-sdk

> 标签: ai, bot-detection, cloudflare-workers, express, fastify, monetization, nextjs, paywall, solana, x402

## 简介

Drop-in AI bot paywall, fully wallet-based: provide your Solana wallet, receive USDC directly. No API keys. Local bot detection + stateless x402 facilitator. Works with Express, Next.js, Fastify, and Cloudflare Workers.
