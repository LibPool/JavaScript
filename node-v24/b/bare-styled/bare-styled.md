# bare-styled

> 标签: compile-time, css-in-js, fiber-free, oxc, styled-components

## 简介

styled-components without the wrapper fiber: a build-time transform (oxc or Babel) + a JSX runtime that resolves styled components to plain host elements, compiling CSS at build time where possible.
