# bazeries-cipher

> 标签: bazeries, cipher, classical-cipher, cryptography, ctf, decoder, encryption, substitution, transposition, typescript

## 简介

Tiny dependency-free TypeScript implementation of the Bazeries cipher (digit-keyed transposition + keyed substitution).
