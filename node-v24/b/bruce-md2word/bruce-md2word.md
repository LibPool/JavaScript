# bruce-md2word

> 标签: agent-skills, ai-agent, cli, deepseek-harness, docx, dsh, markdown, mermaid, plugin, word

## 简介

面向 AI Agent 的 Markdown 转 Word 工具，提供开箱即用的中文排版、Mermaid 图表转图片和可编辑数学公式，提供Skill、独立 CLI 和 DSH 插件。
