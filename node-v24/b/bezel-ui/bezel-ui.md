# bezel-ui

> 标签: animation, component-library, design-system, framer-motion, gsap, nextjs, react, tailwindcss, typescript, ui-components

## 简介

Bezel is a React component library for interface work that needs motion and craft: animated navigation, scroll reveals, cursors, loaders and editorial layout primitives, shipped as readable TypeScript source.
