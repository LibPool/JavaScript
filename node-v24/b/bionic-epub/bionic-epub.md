# bionic-epub

> 标签: bionic-reading, cli, ebook, epub, reader

## 简介

CLI для преобразования EPUB в формат "bionic reading" без потери метаданных, обложек и шрифтов.

## 官网

- npm registry：https://registry.npmjs.org/bionic-epub
- Node 要求：>=20.0.0
