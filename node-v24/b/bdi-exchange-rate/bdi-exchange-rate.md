# bdi-exchange-rate

> 标签: api, banca, bdi, central-bank, currency, d'italia, eur, exchange-rate, exchange-rates, forex, fx, italy, official-rates, typescript

## 简介

Official Banca d'Italia (Italy) daily exchange rates — 150 currencies vs EUR, history since 2016. Zero-dependency Node.js/TypeScript client.
