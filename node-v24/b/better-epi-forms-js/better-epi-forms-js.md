# better-epi-forms-js

> 标签: JavaScript

## 简介

- Works with Bootstrap 2.3.x and Bootstrap 3 - Adds support for [iCheck jQuery plugin](https://github.com/fronteed/iCheck/) (all iCheck [features](https://github.com/fronteed/iCheck/#options) are supported)
