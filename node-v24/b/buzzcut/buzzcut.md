# buzzcut

> 标签: agent-skills, ai, claude-code, codex, commit, commit-message, cursor, git, linter, pr-description, pull-request, slop

## 简介

Makes coding agents write commits and PRs a reviewer can read: what changed and why, with the names, files and test counts they cite checked against the diff and the repo. No API key needed.
