# bjj-scoreboard

> 标签: bjj, brazilian-jiu-jitsu, custom-element, grappling, ibjjf, jiu-jitsu, match-timer, scoreboard, tournament, web-component

## 简介

A free IBJJF BJJ scoreboard web component with points, advantages, penalties, automatic tiebreaks, and a match clock. One script tag, no framework, no dependencies.
