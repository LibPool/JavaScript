# beeswax-mcp

> 标签: accounting, beeswax, bookkeeping, claude, invoices, mcp, modelcontextprotocol

## 简介

Official MCP server for Beeswax (beeswaxapp.com) — query invoices, quotes, expenses, payments, journals, time entries, projects, products & services and tax returns from Claude and other MCP clients, and build quotes priced from your catalogue.
