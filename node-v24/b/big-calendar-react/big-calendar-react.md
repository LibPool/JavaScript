# big-calendar-react

> 标签: big-calendar, calendar, date-fns, react, shadcn, shadcn-ui, tailwindcss, zustand

## 简介

A fully-featured calendar component for React with 5 views, event CRUD, user filtering, and dark mode. Built with shadcn/ui and Tailwind CSS.
