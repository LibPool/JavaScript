# blockly-json-logic-block

> 标签: JavaScript

## 简介

JSONLogic Editor ============== Built complex rules authomatically by JSONLogic editor utilizing Blockly. All supported operations in JSONLogic structure are provided by Blockly blocks. Drag and drop blocks to make your own rule.
