# bun-overlay

> 标签: anti-aliasing, bun, canvas, ffi, gradient, graphics, hud, layered-window, opengl, overlay, transparent, typescript, win32, windows

## 简介

Anti-aliased, GPU-batched overlays for Bun on Windows — gradients, soft shadows, text and 3D markers on a transparent, click-through window. Pure bun:ffi, no native build.
