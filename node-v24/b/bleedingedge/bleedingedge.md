> 标签: JavaScript

## 简介

Skeleton build tool learning using: lerna monorepo, webpack2, nodejs, hot reloader 3, react router 4, preact, jsdom, enzyme, babel6 loader, async extension point bootstrap, flowtypes, eslint autofixing...
