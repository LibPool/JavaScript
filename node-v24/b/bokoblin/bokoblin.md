# bokoblin

> 标签: JavaScript

## 简介

Bokoblin is an opinionated scaffolding generator for AWS Lambda functions. It bundles together a set of tools which facilitate fast development and deployment of Lambda functions by providing: - flow - jasmine - webpack - deployment scripts
