# bun-capstone-abi

> 标签: abi, capstone, disassembler, exoproc, x86, x86_64

## 简介

Side-effect-free Capstone/x86 ABI constant tables (cs_arch, cs_err, x86_reg, x86_insn, ...) shared between bun-capstone's native binding and @exoproc/simulate's guest capstone.dll -- no bun:ffi/native loader dependency.
