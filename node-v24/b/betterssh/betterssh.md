# betterssh

> 标签: cli, devtools, git, github, gitlab, multiple-accounts, ssh, ssh-config, ssh-keys

## 简介

诊断并修复多账户 SSH 配置 —— 一条命令找出 git remote 用错账户/密钥的问题。BetterSSH 桌面应用的 CLI 伴侣。
