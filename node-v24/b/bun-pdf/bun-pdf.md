# bun-pdf

> 标签: acroform, agent, agent-skill, annotations, claude, cli, forms, markdown, pdf, pi-package

## 简介

CLI for AI agents to read, fill, and comment on PDF files — annotated-markdown read views, locator-based addressing, format fidelity via incremental saves.
