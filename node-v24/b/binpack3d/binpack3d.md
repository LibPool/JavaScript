# binpack3d

> 标签: 3d, 3d bin packing, 3d-bin-packing, bin, bin packing, bin-packing, box packing, boxing optimization, container loading, cuboid, knapsack, packer, packing, pallet

## 简介

A fast 3D bin packing library for packing boxes into containers with multiple bins. TypeScript support and zero dependencies.
