# better-sqlite3-compat

> 标签: better-sqlite3, compat, database, electron, no-native, node:sqlite, prebuild, sqlite, sqlite3, synchronous

## 简介

The better-sqlite3 API on Node's built-in node:sqlite. No native module, no rebuilds: same Database, Statement, transactions, pragma, functions, aggregates, backup and serialize contract.
