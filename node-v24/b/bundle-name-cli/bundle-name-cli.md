# bundle-name-cli

> 标签: applescript, bundle, bundleid, bundlename, cfbundleidentifier, cfbundlename, cli, cli-app, id, identifier, macos, plist, uti

## 简介

Get bundle name from a bundle identifier (macOS): `com.apple.Safari` → `Safari`
