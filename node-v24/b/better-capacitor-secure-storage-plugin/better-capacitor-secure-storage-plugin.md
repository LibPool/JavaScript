# better-capacitor-secure-storage-plugin

> 标签: capacitor, native, plugin

## 简介

Capacitor plugin for storing string values securely on iOS and Android. Skip Pay fork of capacitor-secure-storage-plugin with hardened Keychain/Keystore configuration.
