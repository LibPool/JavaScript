# bubble-msg

> 标签: JavaScript

## 简介

bubble-msg是针对通过`<iframe>`嵌套的多个窗口间进行通信的vue插件。当前端项目中存在多层`<iframe>`嵌套，为方便进行层间通信，可以使用此插件。
