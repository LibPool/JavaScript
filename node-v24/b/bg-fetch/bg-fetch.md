# bg-fetch

> 标签: background-fetch, backgroundfetch, cache-api, download, downloads, offline, progress, pwa, react-hooks, resumable, service-worker, typescript

## 简介

The browser's Background Fetch API made usable: downloads that survive a closed tab, an OS progress notification, and a service-worker helper that actually keeps the bytes.
