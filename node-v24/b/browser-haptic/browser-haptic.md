# browser-haptic

> 标签: android, browser-haptic, haptic, haptic-feedback, ios, mobile, mobile-web, pwa, safari, tactile, touch-feedback, ux, vibrate, vibration, vibration-api, zero-dependencies

## 简介

Lightweight haptic feedback for web apps. Vibration API (Android) + iOS Safari 17.4+ switch fallback. Zero dependencies.
