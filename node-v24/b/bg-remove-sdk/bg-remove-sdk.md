# bg-remove-sdk

> 标签: background-removal, browser, onnx, rmbg, segmentation, transformers.js, webgpu

## 简介

Headless in-browser background removal powered by RMBG-1.4 + transformers.js. No UI, no server — inference runs in a Web Worker via WebGPU/WASM.
