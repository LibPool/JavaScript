# babel-plugin-hoist-constant-jsx-attributes

> 标签: JavaScript

## 简介

Prevents unnecessary rerenders and GC pressure by hoisting constant objects out of JSX attributes and into the top-level scope, ex. for objects in a 'style' prop.
