# botbuilder-hipchat

> 标签: JavaScript

## 简介

Connect your bot to HipChat. This is a local connector, similar to `TextBot` not a way to use HipChat with the [BotConnecterService](http://docs.botframework.com/connector/getstarted/#navtitle)
