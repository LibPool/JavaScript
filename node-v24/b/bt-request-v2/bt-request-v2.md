# bt-request-v2

> 标签: JavaScript

## 简介

`bt-request-v2` 是一个基于 `axios` 和 `crypto-js` 的 HTTP 请求库，提供了一些实用的功能，包括自动添加时间戳、生成签名和请求拦截器。
