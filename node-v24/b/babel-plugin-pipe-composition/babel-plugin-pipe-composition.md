# babel-plugin-pipe-composition

> 标签: babel, babel-plugin, pipe, pipe backward, pipe forward, pipe operator, pipeline

## 简介

Overload the bitwise operators (`<<`) and (`>>`) to provide F# like pipe forward/backward behavior
