# bdaya-socraticode

> 标签: code-graph, codebase, embeddings, indexer, mcp, ollama, qdrant, socraticode, vector-database

## 简介

Bdaya-Dev fork of SocratiCode — MCP server for local codebase indexing, semantic search, and code dependency graphs. Adds IaC/proto/PowerShell indexing, dotfile (.gitlab-ci.yml/.github) support, ~195x faster scan, and .env-secret/.team-worktrees exclusion
