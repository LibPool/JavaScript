# blockready

> 标签: callbacks, css, css-in-js, events, javascript, js, style, template, theme, ui, ux

## 简介

BlockReady is a JavaScript UI library to quick setup styling for elements. It comes with a default theme enabled. But guess what? You can add as many themes as you want! Also, you can, change the styling, use callbacks, or make your OWN themes!
