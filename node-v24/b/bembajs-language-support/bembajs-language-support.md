# bembajs-language-support

> 标签: african, bemba, bembajs, components, framework, highlighting, jsx, language, programming, react, syntax, ui, zambia

## 简介

Provides language support for BembaJS files (.bemba) with syntax highlighting, file icons, IntelliSense, React integration, and full control flow syntax (conditionals, loops, async/await)
