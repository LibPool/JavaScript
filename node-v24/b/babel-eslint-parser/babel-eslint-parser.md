# babel-eslint-parser

> 标签: JavaScript

## 简介

ESLint parser that allows for linting of experimental syntax transformed by Babel

## 官网

- 官网：https://babel.dev/
- 源码仓库：git+https://github.com/babel/babel.git
- npm 页面：https://www.npmjs.com/package/babel-eslint-parser

- 7.13.10

## 获取地址

- npm 安装：`npm install babel-eslint-parser`
- npm registry：https://registry.npmjs.org/babel-eslint-parser
- Node 要求：^10.13.0 || ^12.13.0 || >=14.0.0
