# bb-plugin-dispatch

> 标签: agent-ide, ai-agents, bb, bb-plugin, getbb, prompt-engineering, prompt-expansion, task-routing

## 简介

A bb plugin that turns a one-liner into a scoped thread in the right project: it classifies which of your bb projects the request belongs to, expands it through a prompt enhancer, and spawns the thread.
