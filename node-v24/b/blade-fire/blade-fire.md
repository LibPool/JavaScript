# blade-fire

> 标签: annotation, annotator, canvas, diagram, drawing, svg, typescript

## 简介

SVG 标注画布库（多边形/矩形/手绘等绘制工具 + 缩放平移 + 标注双向绑定），本体为 ESM JS，附带 TypeScript 类型声明
