# babylon-scene-player

> 标签: 3d, babylon, babylonjs, datav, digital-twin, scene-player, webgl

## 简介

数字孪生场景播放器：加载「数字孪生场景编辑器」导出的场景 JSON，一行代码在任意页面里把场景跑起来（几何体 / 灯光 / 能量管道 / datav 特效 / glb 模型）
