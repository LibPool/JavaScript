# bguard

> 标签: assertions, bguard, custom-validators, data-schemas, data-validation, input-validation, runtime-validation, schema, type-checking, type-inference, type-safety, typescript, typescript-schema, validation, validators

## 简介

**bguard** is a powerful, flexible, and type-safe validation library for TypeScript. It allows developers to define validation schemas for their data structures and ensures that data conforms to the expected types and constraints.
