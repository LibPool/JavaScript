# browser-agent-server

> 标签: ai-agent, browser-automation, chrome-extension, json-rpc, mcp

## 简介

Vendor-neutral bridge that exposes the browser-agent Chrome extension as JSON-RPC + MCP tools, so any agent can drive the browser.
