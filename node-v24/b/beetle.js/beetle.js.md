# beetle.js

> 标签: Change, Client, JavaScript, OData, ORM, Side, Tracker, TypeScript, Unit, Work, of

## 简介

Beetle is a data manager for Javascript. The goal is to be able to work with data as easy as Entity Framework and LINQ.
