# backend-cloud-sdk

> 标签: baas, backend-cloud, browser-sdk, cloud-database, cloud-functions

## 简介

Backend Cloud 平台官方 SDK：三模认证（L0 appid / L1 HMAC 签名 / L2 STS 短期凭证），前端/Node 调用云函数与云数据库；附 bc CLI（bc init / bc run）本地云开发工作流
