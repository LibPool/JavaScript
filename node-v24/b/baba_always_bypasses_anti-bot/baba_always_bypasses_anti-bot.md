# baba_always_bypasses_anti-bot

> 标签: automation, browser, camofox, pi-extension, pi-package, playwright

## 简介

Pi extension over the Camoufox anti-fingerprint browser — the agent writes fixed-step web workflows down as self-healing skills it maintains and fixes itself, so each repeat costs one bash call instead of burning LLM tokens. Log in by hand once; watch it
