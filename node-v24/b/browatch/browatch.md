# browatch

> 标签: CLI monitoring tool, auto restart node files, express server, express server restart, file watcher, file-monitoring, nodemon, process restart, watch node files

## 简介

NodeWatch (browatch) is a CLI tool that monitors changes to your node app, upon change detection, restarts your node/express app itself.
