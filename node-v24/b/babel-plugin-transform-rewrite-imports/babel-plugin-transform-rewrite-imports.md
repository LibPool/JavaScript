# babel-plugin-transform-rewrite-imports

> 标签: add, append, babel, cjs, commonjs, dynamic, es, esm, export, extension, extensions, import, map, mjs, module, plugin, replace, require, rewrite, transform, typescript

## 简介

Add an extension to import specifiers that do not already have one, replace the extensions of those that do, or even rewrite specifiers entirely
