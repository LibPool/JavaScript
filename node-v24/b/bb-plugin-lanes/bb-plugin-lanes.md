# bb-plugin-lanes

> 标签: agent-ide, ai-agents, bb, bb-plugin, claude-code, codex, getbb, opencode, openrouter, rate-limits, usage-limits

## 简介

A bb plugin showing every model lane's headroom in one place. bb tracks Claude Code and Codex natively; this adds OpenCode Zen Go and OpenRouter, normalised into the same shape.
