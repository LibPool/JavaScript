# battlestack

> 标签: boilerplate, cli, drizzle, generator, nuxt, nuxt4, scaffold, scaffolding, starter, tailwind, template

## 简介

Battlestack — plugin-based scaffolding CLI for Nuxt 4. This unscoped package is the `npx battlestack` entry point; the implementation lives in @battlestack/cli.
