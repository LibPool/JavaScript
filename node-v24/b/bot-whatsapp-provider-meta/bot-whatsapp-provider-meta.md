# bot-whatsapp-provider-meta

> 标签: JavaScript

## 简介

Esto es el conector a Twilio, Meta con una ligera modificación sobre el proveedor de Meta que permite capturar la respuesta generada a partir de un botón de una plantilla. Código original: https://github.com/codigoencasa/bot-whatsapp/tree/main/packages/pr
