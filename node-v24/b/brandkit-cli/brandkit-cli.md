# brandkit-cli

> 标签: animations, brand, branding, cli, crawler, css-extraction, design-system, design-tokens, playwright, scraper, screenshot, shaders, three.js, webgl

## 简介

One headless run turns any live URL into a full brand kit: DOM, CSS, design tokens, multi-width screenshots, loader/theme/cursor capture, asset extraction, animation catalog, and WebGL/Three.js shaders.
