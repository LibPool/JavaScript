# biller-mcp-server

> 标签: biller, cfe, dgi, facturacion, mcp, model-context-protocol, uruguay

## 简介

MCP server local, read-only, para la API REST de Biller (facturación electrónica de Uruguay). Solo llamadas HTTP GET.
