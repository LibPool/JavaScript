# babilinapps.realsense.downloader

> 标签: RealSense

## 简介

Unofficial RealSense Package Downloader.
A simple package that downloads the newest RealSense Unity Package from the Official Release Page.

## Why was it created?
I have been using the Intel RealSense SDK for a lot of my projects and wanted to have a way
