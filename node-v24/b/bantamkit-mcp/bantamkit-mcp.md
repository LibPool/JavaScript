> 标签: agent, claude, claude-code, claude-desktop, copilot, cursor, json-schema, llm, mcp, mcp-server, memory, model-context-protocol, vscode

## 简介

Memory MCP server for Claude Code, Cursor, VS Code Copilot and Claude Desktop: per-person memory, JSON Schema validation, shift-work tools. Pure Node; install once with npx, run offline.
