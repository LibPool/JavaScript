# bc-nuvei-sdk

> 标签: bettercommerce, nuvei-sdk, payments

## 简介

BetterCommerce's Nuvei NodeJS SDK enables server-side integration with [Nuvei payment ](https://docs.nuvei.com/api/main/indexMain_v1_0.html?json#RESTAPIOverview) for Web SDK implementations. This SDK provides server-to-server API calls to support React/Ja
