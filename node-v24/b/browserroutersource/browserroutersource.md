# browserroutersource

> 标签: JavaScript

## 简介

根据提供的路由配置自动复制所有文件，以解决在browser模式下访问404的问题，在静态服务器上也能运行，不用配置nginx

## 官网

- npm 页面：https://www.npmjs.com/package/browserroutersource

## 历史版本号

- 当前版本：1.0.0

- 1.0.0

## 获取地址

- npm 安装：`npm install browserroutersource`
- npm registry：https://registry.npmjs.org/browserroutersource
