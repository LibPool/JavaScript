# bot-avatars

> 标签: agent, ai, animation, avatar, bot, canvas, character, face, mascot, react

## 简介

Animated bot avatars for React — eighteen glossy 3D shapes with living faces that turn, hop and flip, three states (idle, working, sleeping), 2D canvas, no WebGL
