# bsky-comments-client

> 标签: at-protocol, atproto, bluesky, comments, custom-element, privacy, static-site, web-component

## 简介

Privacy-respecting Bluesky comments as a zero-dependency web component, with an optional proxy mode that keeps reader IPs off Bluesky.
