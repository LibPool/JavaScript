# basemail

> 标签: agents, ai-agent, base, base-chain, basemail, basename, email, ethereum, siwe, viem

## 简介

Official Node.js SDK for BaseMail — email for AI agents. Wallet-based (SIWE) sign-in, free agent-to-agent mail, API keys, ATTN, webhooks.
