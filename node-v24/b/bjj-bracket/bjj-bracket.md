# bjj-bracket

> 标签: bjj, bracket, bracket-generator, brazilian-jiu-jitsu, double-elimination, grappling, ibjjf, jiu-jitsu, round-robin, tournament, web-component

## 简介

Free BJJ tournament bracket generator: single elimination, double elimination, and round robin, with teammates kept apart and an IBJJF-style podium. A dependency-free TypeScript library and a <bjj-bracket> web component.
