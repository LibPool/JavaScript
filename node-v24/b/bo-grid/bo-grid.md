# bo-grid

> 标签: candlestick, chart, datagrid, fintech, grid, market-data, order-book, price-limit, realtime, sparkline, svelte, svelte5, table, trading, trading-chart, vietnam-stock-exchange, virtual-scroll, websocket

## 简介

Tiny, fast Svelte 5 data grid: canvas sparklines, batched realtime cell updates, and virtual scrolling. A free, fintech-focused alternative to heavyweight grids.
