# big-calendar-vue3

> 标签: big-calendar, calendar, date-fns, pinia, shadcn-vue, tailwindcss, vue, vue3

## 简介

A fully-featured calendar component for Vue 3 with 5 views, event CRUD, user filtering, and dark mode. Built with shadcn-vue and Tailwind CSS.
