# brooker_f-test-cli

> 标签: JavaScript

## 简介

脚手架初始化 npm init -y  创建bin文件夹下的入口文件 index.js,并在第一行 #!/usr/bin/env node 配置package.json文件，配置脚手架指令，指向bin文件夹下的index.js入口文件 ```json "bin": {   "cli-command": "bin/index.js" } ``` 然后发布脚手架到npm + npm login 进行登录 + npm publish 进行发布
