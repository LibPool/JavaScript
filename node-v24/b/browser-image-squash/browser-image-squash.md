# browser-image-squash

> 标签: avif, browser, client-side, compress, compression, exif, image, image-compression, image-optimization, jpeg, jsquash, mozjpeg, optimize, oxipng, picture, png, react, resize, responsive, squash, srcset, typescript, wasm, web-worker, webp

## 简介

Client-side image compression & resizing in the browser — responsive AVIF + JPEG/PNG variants, off the main thread via a Web Worker pool, EXIF stripped. WASM codecs (jSquash), framework-agnostic, React optional.
