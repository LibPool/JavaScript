# bg-location-sender

> 标签: background-location, bg-location-sender, cordova-android, cordova-ios, ecosystem:cordova, firebase, firebase-location-store, gps-location, location-store

## 简介

This plug-in is used to store users geo location to a data store when an ionic app is running in the background. Data store can be a backend API, firebase or for frontend use it as a location watcher.
