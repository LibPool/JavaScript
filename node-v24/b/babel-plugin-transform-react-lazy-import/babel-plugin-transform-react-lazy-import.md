# babel-plugin-transform-react-lazy-import

> 标签: JavaScript

## 简介

该插件是为了解决在开发中，由于使用 `Suspense` 和 `lazy`，在修改文件时导致产生连锁效应，最终应用被最外层的 `Suspense` 重新渲染。
