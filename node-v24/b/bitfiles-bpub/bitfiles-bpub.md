# bitfiles-bpub

> 标签: bitcoin, bpub, inscription, p2wsh, segwit

## 简介

TypeScript port of the bpub Python library: read and write BPUB data inscriptions embedded in Bitcoin transactions. Isomorphic (Node + browser), zero runtime dependencies.
