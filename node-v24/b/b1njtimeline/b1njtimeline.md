# b1njtimeline

> 标签: JavaScript

## 简介

b1njTimeline is a jQuery plugin that makes use of Moment.js and Html5 <time> element to create a simple and clean timeline on the web page. The event will be automatically placed on the timeline based on <time> datetime attribute.
