# btn-kit

> 标签: button, buttons, click, component, contained, custom, disabled, href, outlined, progress, ripple, round, rounded, router, shape, sizes, text, theme, variation, vue, vuejs

## 简介

btn-kit is a Vue 3 component for creating buttons for web applications. Built-in features include icon support, different button types and sizes, states, effects.
