# blend-editor

> 标签: blend, editor, rich text, rich text editor, wysiwyg

## 简介

O Blend Editor é uma aplicação de edição de texto que oferece uma experiência intuitiva e flexível para formatação e criação de conteúdo. Ele foi projetado para ser uma ferramenta poderosa, mas fácil de usar, permitindo que os usuários expressem suas idei
