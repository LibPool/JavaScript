# botly-bots

> 标签: JavaScript

## 简介

**BotlyBot** is a lightweight, fully customizable, plug-and-play chatbot UI component for React applications — powered by [Botly](https://botly.ai), your platform to build, host, and manage AI chatbots using Gemini, DeepSeek, and Mistral models.
