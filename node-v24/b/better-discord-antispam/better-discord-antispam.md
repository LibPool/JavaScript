# better-discord-antispam

> 标签: antispam, better, discord, discord.js, module, mute, spam

## 简介

A simple module based on Michale Scofield's module: discord-anti-spam.js! While containing the same features(quick and simple setup), it adds new things like setting up a report channel, timed mutes(removed ban option and added mute & unmute automatically
