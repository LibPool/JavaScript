# blueprint-table-v1

> 标签: JavaScript

## 简介

Exports the latest 1.x version of https://github.com/palantir/blueprint/tree/develop/packages/table. This is useful if you need to simultaneously depend on Blueprint 1.x and 3.x for back-compat reasons.
