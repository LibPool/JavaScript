# buson

> 标签: JavaScript

## 简介

1. 什么是观察者模式/发布-订阅模式？ （1）观察者模式： 观察者模式（Observer Pattern）定义了一种一对多的关系，让多个订阅者对象同时监听某一个发布者，或者叫主题对象，这个主题对象的状态发生变化时就会通知所有订阅自己的订阅者对象，使得它们能够自动更新自己。
