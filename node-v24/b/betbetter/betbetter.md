# betbetter

> 标签: afl, api-client, betting, mlb, nba, nfl, nhl, odds, power-rankings, predictions, soccer, sports, sports-analytics

## 简介

Zero-dependency client for the free Bet Better sports model API — model score predictions, win probabilities, power rankings and publicly graded picks for 12 sports. No API key.
