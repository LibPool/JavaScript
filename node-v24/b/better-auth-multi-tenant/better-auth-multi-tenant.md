# better-auth-multi-tenant

> 标签: auth, better-auth, better-auth-plugin, multi-tenancy, multi-tenant, saas, subdomain, tenant-isolation

## 简介

Subdomain-based multi-tenancy for Better Auth: tenant resolution from the request host, tenant-bound sessions, and cross-tenant request rejection.
