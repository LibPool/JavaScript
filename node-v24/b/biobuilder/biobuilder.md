# biobuilder

> 标签: JavaScript

## 简介

* Use set DEBUG=1 in terminal to print debug logs * Use biobuilder command with following options   * --createConfig=<path to folder> where config file should be created   * --config=<path to folder> where config file is present   * --build build bio
