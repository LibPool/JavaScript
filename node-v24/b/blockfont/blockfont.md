# blockfont

> 标签: font, minecraft, opentype, pixel-art, truetype, ttc, typography, variable-fonts, woff, woff2

## 简介

Pixel-perfect Minecraft typography engine that vectorizes vanilla textures and resource packs into OpenType and Web fonts.
