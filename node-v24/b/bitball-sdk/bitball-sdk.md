# bitball-sdk

> 标签: HBInit, bitball, bot, haxball, headless, multiplayer, webrtc

## 简介

BitBall headless SDK — host public rooms/bots from Node.js (HBInit). Connect to any BitBall lobby with BITBALL_WS.
