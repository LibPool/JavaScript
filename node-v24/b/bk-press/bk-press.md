# bk-press

> 标签: Cypress, bk-press, bkpress, 端到端测试, 组件测试, 自动化测试

## 简介

一个用于 Cypress 自动化测试的 CLI 工具，提供了快速初始化测试环境、并行运行自动化测试、生成 fixture 拦截数据、生成 Cypress 测试脚本等强大功能。
