# bear.css

> 标签: atomic-css, cascade-layers, container-queries, css, css-framework, design-tokens, logical-properties, utility-css, zero-dependency

## 简介

Zero-dependency, zero-build atomic CSS utility framework built on a five-level token hierarchy. Native cascade layers, logical properties, fluid type/space scales, container queries.
