# bfs-vault

> 标签: aes-256-gcm, argon2, backup, backup-cli, backup-tool, bit-rot, cli, client-side-encryption, data-integrity, disaster-recovery, distributed, encryption, erasure-coding, fault-tolerance, ftp, offsite-backup, redundancy, reed-solomon, restore, self-hosted, sftp, ssh, versioning

## 简介

Encrypted CLI backup split across local, FTP and SSH storages with Reed-Solomon parity - any N of N+K parts restore everything
