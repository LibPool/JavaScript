# backlot

> 标签: broker, coding-agents, dev-environment, e2e, environment, harness, mcp, preview, sandbox, warm-pool

## 简介

The repo-aware environment broker: puts a working, seeded, provable instance of your web application in front of coding agents and humans — warm pools, leases, bind-by-sync. Brokers environments; never provides them.
