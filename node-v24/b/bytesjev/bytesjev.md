# bytesjev

> 标签: claude-code, jev, mcp, model-context-protocol, overengineering, planning, typesafe

## 简介

PlanningChecker: a local MCP server for Claude Code that asks Jev (TypeSafe System One) whether each item in the agent's plan is actually needed, with a live dashboard.
