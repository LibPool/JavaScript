# brixel

> 标签: cli, content-addressable, dedupe, disk-space, hardlink, node_modules, package-manager

## 简介

[beta] node_modules que quase não ocupa disco. Use brixel install no lugar do npm install: cada pacote fica guardado uma vez só no seu computador, e dez projetos com o mesmo React ocupam o espaço de um.
