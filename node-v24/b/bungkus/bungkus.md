# bungkus

> 标签: bungkus, file-upload, form-persistence, hook, indexeddb, localstorage-alternative, persist-form, react, save-form

## 简介

Bungkus: A lightweight React Hook to save form data (files & text) to IndexedDB. Prevent data loss on refresh.
