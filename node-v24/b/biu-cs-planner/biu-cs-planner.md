# biu-cs-planner

> 标签: bar-ilan, biu, course-planner, degree-planner, hebrew, scheduler, timetable, university

## 简介

A local course planner for Bar-Ilan University Computer Science students: build the weekly Timetable for an Academic Year, offline, in a folder you own. The degree Plan and Progress are not built yet.
