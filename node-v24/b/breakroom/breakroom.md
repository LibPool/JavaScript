# breakroom

> 标签: ai, cbt, diagnostic, llm, proxy, routing

## 简介

Cloudflare Worker BYOK proxy with 5-state cognitive firewall (Freeze, Panic, Rumination, Helplessness, Fawning) for AI agent loop interception. Includes CLI for setup.
