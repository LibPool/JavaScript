# babel-preset-es2015-webpack2

> 标签: JavaScript

## 简介

Babel preset for all es2015 plugins except es2015-modules-commonjs (because webpack2 supports it already!).

## 官网

- 官网：https://babeljs.io/
- 源码仓库：git+https://github.com/marcello3d/babel-preset-es2015-webpack2.git
- npm 页面：https://www.npmjs.com/package/babel-preset-es2015-webpack2
