# bani-mcp

> 标签: africa, bani, fintech, getbani, mcp, model-context-protocol, payments, payouts

## 简介

Model Context Protocol (MCP) server for the Bani API — lets AI agents and developer tools create customers, collect payments, send payouts, pay bills, convert currencies, and more on Bani.
