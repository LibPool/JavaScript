# better-dsh-session-deletetool

> 标签: archive, conversation, deepseek-harness, delete, dsh, dsh-plugin, session

## 简介

Delete a conversation from the DSH sidebar instead of only archiving it, and see the whole family it spawned — every subagent session and derived conversation, nested — before choosing which of them go with it; delete many at once from the trash icon besi
