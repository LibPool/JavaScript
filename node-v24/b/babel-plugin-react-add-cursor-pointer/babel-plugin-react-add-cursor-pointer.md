# babel-plugin-react-add-cursor-pointer

> 标签: babel, babel-plugin, clickable-element, cursor, cursor-pointer, decorate, decorator, jsx, plugin, pointer, react, style, stylize, transform

## 简介

This babel plugin styles any enabled JSX element that has an onClick prop with cursor: pointer.
