# bcp-exchange-rate

> 标签: api, banco, bcp, central, central-bank, currency, del, exchange-rate, exchange-rates, forex, fx, official-rates, paraguay, pyg, typescript

## 简介

Official Banco Central del Paraguay (Paraguay) daily exchange rates — 26 currencies vs PYG, history since 2016. Zero-dependency Node.js/TypeScript client.
