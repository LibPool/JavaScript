# blumi-printer-sdk

> 标签: ble, bluetooth-printer, dithering, escpos, pos, sii, thermal-printer, ticket, web-bluetooth

## 简介

Librería Javascript ES6 para impresión térmica ESC/POS mediante Web Bluetooth (BLE), WebUSB y Web Serial con perfiles de hardware personalizados, tramado de imágenes y constructores semánticos.
