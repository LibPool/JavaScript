# dsh-career-planner

> 标签: career, deepseek-harness, dsh, job-search, plugin, resume

## 简介

职业规划工作台 + 职业规划师预设：插件把包内预设自动同步到 DSH，界面与 AI 共用同一份职业数据（画像 / JD 池 / 投递 / 技能 / 简历）
