# @lakphy/local-router

> 标签: JavaScript

## 简介

`@lakphy/local-router` 是一个本地 AI CLI 网关工具。   安装后通过 `local-router` 命令启动服务，把 OpenAI/Anthropic 风格请求统一转发到你配置的上游 provider。
