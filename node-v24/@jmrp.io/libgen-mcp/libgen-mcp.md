# @jmrp.io/libgen-mcp

> 标签: ai, arxiv, claude, cli, crossref, doi, libgen, library-genesis, llm, mcp, model-context-protocol, open-access, stdio

## 简介

Model Context Protocol (MCP) server for federated search, citation and reading of books and papers across Library Genesis and open-access sources. Runs as a local binary over stdio or HTTP.
