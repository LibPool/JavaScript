# @thibezer/ui-components-kit

> 标签: cad, custom-elements, custom-elements-manifest, design-system, form-associated, gis, leaflet, react, shadow-dom, ui-kit, vue, web-components

## 简介

Web Components nativos (W3C Custom Elements + Shadow DOM) para interfaces densas de GIS, CAD e formulários, sem dependência de framework.
