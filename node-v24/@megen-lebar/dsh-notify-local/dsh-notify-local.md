# @megen-lebar/dsh-notify-local

> 标签: deepseek-harness, dsh, local, notifications, web-plugin

## 简介

DSH 本机通知插件：回合完成/出错/待审批时弹系统通知（Windows Toast + WinForms 对话框回退、macOS osascript、Linux notify-send），无任何第三方 webhook。
