# @nathwn12/oc-bifrost

> 标签: adapter, bridge, compatibility, opencode, opencode-plugin, v1, v2

## 简介

The rainbow bridge for OpenCode plugins — run V1-era plugin hooks on the OpenCode V2 runtime; unmapped hooks are refused loudly instead of silently dropped.
