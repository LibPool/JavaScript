# @hadron-memory/access-control

> 标签: access-control, authorization, authz, hadron, policy

## 简介

Hadron's authorization core — the pure, isomorphic access-control evaluators used by hadron-server and every Hadron client. The server is always the enforcement authority; clients use this to predict its decisions.
