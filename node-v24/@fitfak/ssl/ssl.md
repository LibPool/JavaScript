# @fitfak/ssl

> 标签: certificate-authority, crl, crypto, csr, ecdh, ecdsa, ml-dsa, ml-kem, ocsp, pki, post-quantum, rsa, tls, x25519, x509

## 简介

node:crypto (OpenSSL) tabanlı RSA/EC/AES/Hash/HMAC ilkelleri + tam özellikli X.509 PKI motoru (CSR, CRL, OCSP, sertifika zinciri doğrulama, HTTP responder sunucuları, ML-KEM/ML-DSA post-kuantum destek).
