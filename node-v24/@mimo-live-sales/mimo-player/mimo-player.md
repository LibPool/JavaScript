# @mimo-live-sales/mimo-player

> 标签: JavaScript

## 简介

Biblioteca React que abstrai a reprodução de vídeo da Mimo Live Sales. O pacote é publicado no npm e centraliza a lógica de player para que múltiplos produtos compartilhem a mesma implementação, sem duplicar código.
