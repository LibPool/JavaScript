# @betterimage/cards

> 标签: betterimage, instagram, link-preview, meta-tags, og-image, open-graph, social-card, social-media-images, twitter-card, youtube-thumbnail

## 简介

Signed betterimage.io card URLs: one template renders a social card per page at any platform size (1200x630 link preview, YouTube thumbnail, Instagram square or portrait, story, Pinterest pin).

## 官网

- 官网：https://betterimage.io/api
- 源码仓库：git+https://github.com/mfundakowski/betterimage-cards.git
- npm 页面：https://www.npmjs.com/package/@betterimage/cards
