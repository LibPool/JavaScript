# @selfcure/cli

> 标签: JavaScript

## 简介

Frontend testability maturity CLI — scores components, flags ambiguous locators, and ships data-testid fixes as a PR before Cypress, Playwright, Selenium, TestCafe, or WebdriverIO run.
