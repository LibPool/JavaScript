# @nickcao/coco

> 标签: ai, claude-code, cli, codex, coding-agent, loop-engineering, mcp, referee

## 简介

A loop-engineering referee for AI coding agents (Codex / Claude Code): plan → implement → review → verify → human-merge, gated by a git-tree-hash-bound, epoch-scoped state machine, with ChatGPT-Pro (Oracle) as the review brain.
