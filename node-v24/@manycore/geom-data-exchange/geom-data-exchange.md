# @manycore/geom-data-exchange

> 标签: JavaScript

## 简介

## 包含功能： - 定义了点，向量，矩阵，坐标系，各类曲线，曲面，裁剪曲线曲面等常用几何元素的对外暴露数据格式（数据交换接口）。 - 定义了顶点，边，面片，环，翼边，体，组件，组件实例等常用的拓扑元素的对外暴露数据格式（数据交换接口）。 - 定义了以上数据格式的序列化和反序列化标准接口。 - 提供了以上数据交换接口的实现（基本数据+序列化+反序列化，不包含任何几何造型算法）。
