# @quilltent/nextjs

> 标签: app-router, headless-cms, next, nextjs, quilltent, sdk

## 简介

Next.js (App Router) integration for QuillTent: cached content fetchers, revalidate and preview route handlers, DraftBanner, and QtImage.
