# @contensu/directus-extension-image-carousel-interface

> 标签: carousel, directus, directus-custom-interface, directus-extension, gallery, images

## 简介

A Directus interface that presents the image files linked to an item as a browsable carousel, with thumbnails, autoplay, and keyboard navigation.
