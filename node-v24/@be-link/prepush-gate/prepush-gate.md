# @be-link/prepush-gate

> 标签: JavaScript

## 简介

客户端 pre-push 质量门禁 CLI：非受保护分支本地跑 lint/typecheck + 完整单测门禁（小改动判定/单测差异/增量覆盖率），失败即拒绝推送
