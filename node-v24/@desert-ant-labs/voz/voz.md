# @desert-ant-labs/voz

> 标签: asr, isomorphic, on-device, onnxruntime, speech-recognition, subtitles, transcription, wasm, webgpu, webnn, word-timestamps

## 简介

On-device speech recognition for JavaScript: transcripts with word-level timestamps, 25 languages. Runs in the browser on WebAssembly + ONNX Runtime Web (WebGPU, with the decode step on WebNN where the browser has it), and server-side in Node from one imp
