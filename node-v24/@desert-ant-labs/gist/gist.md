# @desert-ant-labs/gist

> 标签: content-tagging, isomorphic, litert, multi-label, multilingual, nlp, on-device, taxonomy, topic-classification, wasm

## 简介

On-device content topic tagging for JavaScript: multi-label topics from a 36-topic taxonomy across 101 languages. Runs in the browser (WebAssembly + LiteRT.js) and server-side in Node (native), from one import.
