# @desert-ant-labs/moderator

> 标签: content-moderation, image-classification, isomorphic, litert, nsfw, nudity-detection, on-device, wasm

## 简介

On-device NSFW image detection for JavaScript. Runs in the browser (WebAssembly + LiteRT.js) and server-side in Node (native), from one import.
