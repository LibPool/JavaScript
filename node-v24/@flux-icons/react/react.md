# @flux-icons/react

> 标签: icon-set, icons, react, shadcn, shadcn-ui, svg, tailwind

## 简介

Icons on one 24×24 grid, as React components in four styles: stroke, two-tone, duotone and fill, each in rounded or sharp corners. Built for shadcn/ui.
