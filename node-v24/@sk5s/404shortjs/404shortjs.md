# @sk5s/404shortjs

> 标签: gh-pages, javascript, shortener, sk5s-project, static-site, vanilla-javascript

## 简介

404shortjs make a short link just in a minutes, use Javascript to redirect. Just add the Script to 404 page. 快速製作簡易短連結檔案，只要將Script加入404頁面，就可以快速完成多個短連結，使用Javascript重新導向，不用後端程式。
