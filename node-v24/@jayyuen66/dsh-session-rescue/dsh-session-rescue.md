# @jayyuen66/dsh-session-rescue

> 标签: cordis, dsh, llm-retry, plugin, session-resume

## 简介

Session rescue for dsh web: auto-resume on transient model failures, max-tokens continuation and unclosed-todo catch-up (host), plus edit-resend / retry / queue-withdraw / stop-and-reask / settings card (client).
