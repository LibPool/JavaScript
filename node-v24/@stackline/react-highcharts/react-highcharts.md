# @stackline/react-highcharts

> 标签: 3d-chart, candlestick, chart-wrapper, charts, dynamic-charts, heatmap, highcharts, highcharts-react, highcharts-wrapper, highmaps, highstock, maintained, react, react-charts, react-highcharts, react-library, realtime-charts, stock-chart, treemap, typescript, ui-component, wrapper

## 简介

A maintained React 19 wrapper for Highcharts, Highstock, and Highmaps with native options, constructor switching, module helpers, refs, and realtime update modes.
