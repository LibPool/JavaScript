# @lsdkit/di

> 标签: JavaScript

## 简介

该项目提供了一个基于 TypeScript 实现的依赖注入（DI）容器，用于管理应用程序中的对象生命周期和依赖关系。支持三种不同的服务生命周期：**瞬态（Transient）**、**单例（Singleton）** 和 **创建工厂**。
