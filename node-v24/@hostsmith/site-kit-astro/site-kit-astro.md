# @hostsmith/site-kit-astro

> 标签: astro-integration, hostsmith, webflow, withastro

## 简介

A reusable kit for building websites with Astro: typed sections in Markdown, header and footer blocks, guidelines for AI agents and example designs, with a deploy workflow for Hostsmith.
