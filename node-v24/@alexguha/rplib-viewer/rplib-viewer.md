# @alexguha/rplib-viewer

> 标签: d3, diagram, rplib, svg, viewer, visualization

## 简介

Lightweight read-only viewer UI for rplib diagrams. Same canvas + sidebar + navigation as rplib-editor, with all authoring features stripped out.
