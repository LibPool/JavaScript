# @swimly/longrise-cli

> 标签: JavaScript

## 简介

本脚手架主要用来初始化`rollup`组件打包环境，支持的模板有：`vue2`，`vue3`，`typescript`，`webcomponent`，后续还会添加更多前端组件库模板，敬请期待！
