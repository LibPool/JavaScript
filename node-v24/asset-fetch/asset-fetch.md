# asset-fetch

> 标签: 3d-assets, asset-pipeline, assets, cli, game-dev, itch.io, poly-haven, sqlite

## 简介

Typed CLI and library for finding, verifying, extracting, and curating game assets from itch.io, Poly Haven, and a local SQLite catalog.
