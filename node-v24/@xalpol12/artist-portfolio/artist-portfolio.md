# @xalpol12/artist-portfolio

> 标签: angular, artist, cms, gallery, portfolio

## 简介

Reusable Angular building blocks for artist portfolio sites: thumbnail grids, project detail pages composed from content blocks (paragraph/image/video/gallery/quote/link), Cloudinary image loading, and SEO wiring.
