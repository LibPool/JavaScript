# @concile/test

> 标签: JavaScript

## 简介

An in-process test harness for Concile apps: `createTestConcile` boots a real `EmbeddedRuntime` — the actual transactor, query engine, and reactive subscription manager — over an in-memory SQLite database, so your query/mutation/action tests exercise real
