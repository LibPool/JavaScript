# @sponsorcoin/spcoin-feeds

> 标签: JavaScript

## 简介

Real accounts/tokens/networks data feeds (fetchers, in-memory caching, mappers to spcoin-panels' UI shapes) for MeritWallet — shared between spcoin-nextjs-front-end and the Merit Wallet browser extension (spCoinExtension). Deliberately has zero dependency
