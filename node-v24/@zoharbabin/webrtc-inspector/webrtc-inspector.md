# @zoharbabin/webrtc-inspector

> 标签: chrome-extension, debugging, devtools, instrumentation, mcp, testing, webrtc

## 简介

Framework-agnostic live WebRTC inspection and fault injection: peer connections, tracks, data channels, WebSockets, fake mic/camera, and real transport/signaling fault injection for reconnect testing.
