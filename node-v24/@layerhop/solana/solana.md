# @layerhop/solana

> 标签: bridge, cross-chain, layerhop, solana, swap, wallet-adapter, wallet-standard, web3

## 简介

Execute LayerHop quotes with a Solana wallet: decode the transaction, sign and send it through @solana/wallet-adapter, Wallet Standard or an injected provider, submit-via-API and co-signed modes, then report it
