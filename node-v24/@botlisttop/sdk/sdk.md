# @botlisttop/sdk

> 标签: bot, bot list, botlist, discord, discord.js, server count, slash commands, stats

## 简介

SDK officiel de Bot List (botlist.top) : envoie automatiquement le nombre de serveurs, le statut en ligne, les commandes slash et le profil (nom, avatar, bannière) de votre bot discord.js.

- 源码仓库：git+https://github.com/botlisttop/sdk.git
- npm 页面：https://www.npmjs.com/package/@botlisttop/sdk
