# @alxwlw/oxlint-config

> 标签: JavaScript

## 简介

The alxwlw oxlint canon for oxlint 1.x + oxlint-tsgolint (type-aware): base/node/nest/react/next presets, TypeScript-7-compatible (tsgolint embeds typescript-go).
