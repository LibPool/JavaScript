# @openconsole/nacos

> 标签: adapter, config, framework-agnostic, hono, load-balancer, microservices, nacos, nestjs, nextjs, service-discovery

## 简介

Framework-agnostic Nacos client — service discovery, dynamic config, and a fetch-compatible HTTP layer with plugins. Adapters for Next.js, Hono, and NestJS.
