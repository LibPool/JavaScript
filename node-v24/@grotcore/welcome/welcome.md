# @grotcore/welcome

> 标签: JavaScript

## 简介

A Discord bot plugin that welcomes new members and sends farewell messages when they leave. Supports customizable channels, multiple message types (plain text, embeds, or ComponentsV2), and dynamic username replacement in messages.
