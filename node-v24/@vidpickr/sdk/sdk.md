# @vidpickr/sdk

> 标签: download, mp4, video, vidpickr, youtube, youtube-downloader

## 简介

Official Node.js SDK for the VidPickr API — download YouTube videos with one function call. No ffmpeg dependency.

## 官网

- 官网：https://vidpickr.com/api
- 源码仓库：git+https://github.com/vidpickr/sdk-node.git
- npm 页面：https://www.npmjs.com/package/@vidpickr/sdk
