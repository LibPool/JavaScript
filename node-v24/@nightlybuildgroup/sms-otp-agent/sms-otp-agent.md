# @nightlybuildgroup/sms-otp-agent

> 标签: 2fa, agent, e3372, hilink, huawei, modem, otp, sms, zte

## 简介

Drains SMS inboxes from USB modems (Huawei E3372 HiLink, ZTE goform) and pushes them to an sms-otp-service server.
