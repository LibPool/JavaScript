# @geohar/pi-mcp-combiner

> 标签: extension, mcp, mcp-combiner, pi, pi-extension, pi-mono, pi-package, sharedserver

## 简介

Pi extension: run the mcp-combiner MCP aggregator via sharedserver and inject its tool-discovery directive. Pairs with pi-mcp-adapter, which makes the combiner's tools reachable from Pi.
