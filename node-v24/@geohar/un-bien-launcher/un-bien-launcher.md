# @geohar/un-bien-launcher

> 标签: agent-mesh, daemon, launcher, pi, presence, remote-launch, un-bien, unbien

## 简介

unbien-launcher — the un-bien machine-presence launcher daemon. A lightweight mesh peer (not a Pi session) that lets a paired app launch a Pi session on this machine even when no Pi is running here. Part of the un-bien monorepo; wraps the presence core ex
