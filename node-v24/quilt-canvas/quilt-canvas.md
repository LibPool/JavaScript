# quilt-canvas

> 标签: ai, claude, claude-code, design-tool, html, infinite-canvas, mcp, mcp-server, prototyping, ui-design

## 简介

AI-native infinite-canvas design tool: describe an app, get multi-screen HTML designs on an infinite canvas, click through them as a prototype, and let your local coding agent read and write the canvas over MCP.
