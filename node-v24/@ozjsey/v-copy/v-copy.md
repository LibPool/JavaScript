# @ozjsey/v-copy

> 标签: a11y, clipboard, clipboard-history, clipboard-manager, copy, copy-history, copy-to-clipboard, directive, textcontent, v-copy, vue, vue3

## 简介

Vue 3 directive that copies any element — and keeps the last N copies so your users can pick one back out. Copy history with de-duplication, a copied-feedback state, slot-like reactive state, keyboard + a11y, and an automatic clipboard fallback. Zero depe
