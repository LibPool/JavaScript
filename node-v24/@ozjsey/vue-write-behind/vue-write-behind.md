# @ozjsey/vue-write-behind

> 标签: auto-save, autosave, batch-save, composable, debounce-save, dirty-tracking, local-first, offline, optimistic, outbox, retry, sync, vue, vue3, write-back, write-behind

## 简介

Write-behind cache for Vue 3 — local state stays authoritative, the server's reply is discarded on purpose, and a failed save never rolls back or drops what the user typed
