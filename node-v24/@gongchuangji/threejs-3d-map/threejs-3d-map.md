# @gongchuangji/threejs-3d-map

> 标签: 3D地图, 3d-map, chinaMap, threejs, 下钻地图, 标记, 飞线

## 简介

基于three.js d3.js 创建的3D地图，支持3级区域下钻,支持标记、飞线、圆柱体统计等
