# @82editor/core

> 标签: contenteditable, editor, hangul, html-editor, hwp, ime, korean, rich-text-editor, typescript, wysiwyg

## 简介

82editor — a free WYSIWYG HTML editor: IME-safe Korean input, Word/HWP paste cleanup, tables, images, markdown shortcuts. Zero dependencies.
