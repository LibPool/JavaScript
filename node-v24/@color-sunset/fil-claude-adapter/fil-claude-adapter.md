# @color-sunset/fil-claude-adapter

> 标签: JavaScript

## 简介

The Claude Code Adapter: constrains the Claude Code Agent Runtime to the active Fil Phase (allowedTools via a PreToolUse hook, instructions, context, skills) and installs through Claude Code's native settings channel.
