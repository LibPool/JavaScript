# @kirana-style/biome-plugin

> 标签: JavaScript

## 简介

Kirana's lint rules for Biome, as GritQL plugins: a forwarded sx that is not last, className next to styleProps(), dark mode written as prefers-color-scheme or dark:, and class-string helpers.

- 官网：https://kirana.style/docs/tooling/lint#biome
- 源码仓库：git+https://github.com/kirana-style/kirana.git
