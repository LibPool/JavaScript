# @meowshed/meow-checks

> 标签: meowpaw, pi-package

## 简介

Runs a repository's five verification stages, format, lint, check, test and build, from the commands it declares in .meowpaw/profile.toml, and reports a stage with no command as unresolved, never as passed. It keeps up to 450 characters in context on ever
