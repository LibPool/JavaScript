# @meowshed/meow-git

> 标签: meowpaw, pi-package

## 简介

Refuses a git commit on the trunk the repository declares, and checks every commit a push would publish for the declared commit convention and for a good signature, before the push runs. It keeps nothing in context on every turn. Distributed as a Pi packa
