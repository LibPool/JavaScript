# @meowshed/meow-github

> 标签: meowpaw, pi-package

## 简介

Reads a GitHub repository's issues, pull requests and comments through gh as one JSON document, projects an approved epic's tasks onto issues and writes nothing else, and asks before a Bash command's gh changes how the repository is governed. It keeps not
