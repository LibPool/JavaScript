# @flarecart/worker-http

> 标签: api, cloudflare, cookies, cors, router, turnstile, urlpattern, workers

## 简介

The HTTP layer of a Cloudflare Worker API — a URLPattern router with per-route CORS, ApiError responses, request helpers (IP and /64, country, bearer, cookies, size-capped JSON with any Zod-shaped schema), safe cookies, origin checks and Turnstile.
