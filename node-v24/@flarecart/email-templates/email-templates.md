# @flarecart/email-templates

> 标签: email, email-templates, html-email, plain-text, receipt, transactional-email

## 简介

Transactional emails that render in every client — a table-based, inline-styled layout and small blocks (heading, paragraph, button, links, details, codes, divider), rendered as HTML and plain text from one description. Every value escaped where it lands;
