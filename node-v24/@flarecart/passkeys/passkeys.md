# @flarecart/passkeys

> 标签: admin, authentication, cloudflare-workers, d1, fido2, passkeys, passwordless, webauthn

## 简介

Passkey sign-in for an admin page — server flows over a store you choose (in-memory and Cloudflare D1 included), single-use challenges, provider names, session-cookie helpers, the browser calls, and a software passkey for tests.
