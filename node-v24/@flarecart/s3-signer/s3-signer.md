# @flarecart/s3-signer

> 标签: aws-signature, cloudflare-r2, cloudflare-workers, content-disposition, cors, multipart-upload, presigned-url, r2, s3, sigv4

## 简介

AWS Signature Version 4 for S3-compatible storage (Cloudflare R2, AWS S3, Backblaze B2, Spaces, MinIO) on Web Crypto: presigned downloads that save under any filename, create-only presigned uploads, multipart, bucket CORS. No dependencies; runs in Workers
