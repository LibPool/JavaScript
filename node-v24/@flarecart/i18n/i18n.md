# @flarecart/i18n

> 标签: accept-language, cloudflare-workers, i18n, intl, l10n, localization, plural, translation, typescript

## 简介

Typed message catalogs on Intl: language negotiation (Accept-Language, regions, Traditional vs Simplified Chinese), plurals with Intl.PluralRules, placeholders, and checks that translations keep their placeholders and pages only use keys that exist. No de
