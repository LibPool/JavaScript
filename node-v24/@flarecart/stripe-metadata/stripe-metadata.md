# @flarecart/stripe-metadata

> 标签: chunking, ecommerce, limits, metadata, stripe, stripe-metadata

## 简介

Store values longer than Stripe's 500-character metadata limit across numbered keys (base, base_2 …): lists and JSON, with stale chunks cleared and Stripe's key and value rules checked.
