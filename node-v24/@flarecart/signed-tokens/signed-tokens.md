# @flarecart/signed-tokens

> 标签: api-key, cloudflare-workers, download-link, hmac, magic-link, secret-rotation, signed-url, token, web-crypto

## 简介

Tokens for links and APIs with nothing to store but a secret: signed, expiring, namespaced tokens (the same format as the PHP sugarcommerce/signed-tokens), compact signed ids, and hashed bearer tokens. Web Crypto only.
