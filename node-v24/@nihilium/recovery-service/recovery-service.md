# @nihilium/recovery-service

> 标签: JavaScript

## 简介

Node-only hosts for a recovery wallet's backend: a vault's encrypted records (spec §12), which a provider can hold without custody, and the seal-payment proxy that keeps the Nihilium API key off the client.
