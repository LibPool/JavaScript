# @versioned-store/prompt-store

> 标签: eval-gate, llm, llm-ops, prompt, prompt-management, prompt-store, prompt-versioning, versioned-config

## 简介

A batteries-included, versioned prompt store with a deterministic promote-gate (golden-render + placeholder-binding), built on @versioned-store/core. Version, eval-gate, and roll back your LLM prompts.
