# @agentpager/cli

> 标签: agent, claude-code, cli, codex, remote-control, wechat-miniprogram

## 简介

AgentPager daemon — 手机遥控你电脑上的编程 Agent(Claude Code/Codex/Gemini 等 7 家)。配对后在微信小程序里实时查看会话、续聊、语音输入、发图。
