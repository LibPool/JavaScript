# @aifinpay/wallet

> 标签: ai-agent, aifinpay, casper, derive, evm, keypair, seed, solana, wallet

## 简介

Derive an AiFinPay agent wallet (Solana + EVM + Casper) with four tiny crypto deps — no viem, no @solana/web3.js, ~4.5 MB. The light way to give an agent a wallet where the full SDK will not install.
