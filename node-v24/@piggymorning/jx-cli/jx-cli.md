# @piggymorning/jx-cli

> 标签: JavaScript

## 简介

1.main字段和bin字段的区别，一个工程中，业务逻辑的入口文件，用main来指定。除此之外工程中可能还会存在从系统层面去执行的命令，这些命令对应的执行文件，使用bin来指定 2.npm link：可以关联命令以及执行命令的文件
