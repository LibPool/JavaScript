# @easy-vite/plugin-html

> 标签: ejs, html, minify, mpa, multi-page, template, vite, vite-plugin

## 简介

A Vite plugin to minify index.html, render it with EJS templates, inject entries, and support MPA — compatible with Vite 5-8
