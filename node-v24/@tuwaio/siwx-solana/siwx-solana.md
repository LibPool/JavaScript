# @tuwaio/siwx-solana

> 标签: @solana/kit, authentication, caip-122, ed25519, sign-in-with-solana, solana, tuwa, typescript, wallet-standard, web3

## 简介

Layer 2 (L2) of the TUWA Ecosystem. Solana adapter for @tuwaio/siwx. Signs and verifies CAIP-122 messages for Solana via @solana/kit and @wallet-standard using ed25519 cryptography.
