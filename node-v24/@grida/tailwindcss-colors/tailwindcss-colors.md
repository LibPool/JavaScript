# @grida/tailwindcss-colors

> 标签: colors, data, grida, tailwind, tailwindcss

## 简介

Tailwind CSS color data package - provides color values in multiple formats (RGBA, HEX, OKLCH) for programmatic use. Not intended for direct CSS import in production.
