# kokon-mcp

> 标签: image-editing, image-generation, kokon, local, mcp, mcp-server, model-context-protocol, offline, qwen-image

## 简介

MCP server for Kokon: generate and edit images offline with Qwen-Image 2.1 on your own GPU. Requires the Kokon desktop app (Windows/macOS).
