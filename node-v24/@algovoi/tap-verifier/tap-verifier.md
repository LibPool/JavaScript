# @algovoi/tap-verifier

> 标签: audit, ed25519, jcs, receipt, rfc8785, tap, trusted-agent-protocol, verifier, visa

## 简介

Offline verifier for AlgoVoi TAP receipts (Visa Trusted Agent Protocol post-authentication audit trail). Re-derives the JCS RFC 8785 receipt_id and checks the Ed25519 signature with public libraries only. Byte-identical to algovoi-tap-verifier (PyPI). Apa
