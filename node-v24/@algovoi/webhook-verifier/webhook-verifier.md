# @algovoi/webhook-verifier

> 标签: algovoi, hmac, signature, verification, webhook

## 简介

Cryptographic verifier for AlgoVoi webhook signatures (v1 HMAC-SHA256 + v2 HKDF-SHA256/HMAC-SHA384)
