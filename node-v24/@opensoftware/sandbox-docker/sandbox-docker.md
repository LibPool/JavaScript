# @opensoftware/sandbox-docker

> 标签: JavaScript

## 简介

sandbox-docker: runs isolated, resource-limited sandboxes on Docker behind an iron-proxy egress proxy that refuses other hosts, puts in the real secrets and allows only the declared MCP tools.
