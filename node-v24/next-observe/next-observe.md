# next-observe

> 标签: apm, apm-agent, instrumentation, monitoring, next, nextjs, observability, opentelemetry, otel, tracing

## 简介

The APM agent for Next.js: OpenTelemetry for server, browser and your own code via 'use observe'. It only collects and sends; the UI and the AI agents are in the next-observer observer (npx next-observer dev).
