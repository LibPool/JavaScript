# @swarmclawai/agentbox

> 标签: agent-cli, agent-observability, ai-agents, asciinema, coding-agents, debugging, mcp, model-context-protocol, replay, terminal-recorder

## 简介

Local-first black box recorder for AI agent terminal runs: replay terminal output, file diffs, MCP calls, and risk flags.
