> 标签: abi, calldata, dao, ethereum, governance, proposal, smart-contract, staking, tokamak, ton, web3, wton

## 简介

Headless library for building DAO proposal actions with Tokamak Network support - smart contract function calls with parameter validation and calldata encoding
