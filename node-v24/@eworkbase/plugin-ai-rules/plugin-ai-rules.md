# @eworkbase/plugin-ai-rules

> 标签: JavaScript

## 简介

统一维护团队的 AI 规则、技能、命令与 MCP 配置，并生成 Codex、Claude Code 等客户端文件。支持初始化、预览生成结果、检查配置、同步规则和更新规则来源。
