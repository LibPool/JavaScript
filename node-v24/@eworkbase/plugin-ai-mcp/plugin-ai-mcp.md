# @eworkbase/plugin-ai-mcp

> 标签: JavaScript

## 简介

将当前工作区的插件命令、状态和上下文提供给 AI 工具。支持查看本地 MCP 服务状态、重启服务，并通过 AI Rules 将连接配置写入支持的 AI 客户端。
