# @mayorista-emilai/skill-catalog

> 标签: agent-skills, cursor, cursor-skills, emilai, skill-catalog, skills

## 简介

EmilAI skill catalog for the Cursor coding agent. Install as an npm dependency (no MCP server) and use the CLI to copy skills into ~/.cursor/skills/.
