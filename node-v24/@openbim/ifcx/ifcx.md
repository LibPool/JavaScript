# @openbim/ifcx

> 标签: bim, browser, gltf, ifc, ifc5, ifcx, openbim, wasm

## 简介

Read, write, validate and compose IFC5 / IFCX files, and export GLB, from JavaScript in Node and the browser (WebAssembly build of openbim-ifcx).
