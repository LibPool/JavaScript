# @puenteworks/checkyourself

> 标签: ai-agents, audit, checkyourself, claude, code-review, completion-evidence, mcp, model-context-protocol, production-readiness, stdio

## 简介

Reviewable completion-evidence workflow, bounded scoring, guided hardening, and learning-plan system for AI-built apps. Stdlib-only Python CLI plus a stdio MCP server with 11 tools; no network, no telemetry, secret values never printed.
