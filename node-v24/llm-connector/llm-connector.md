# llm-connector

> 标签: ai, anthropic, chatgpt, claude, codex, electron, llm, oauth, openai, streaming

## 简介

Conectores para LLMs numa API única: assinatura Codex/ChatGPT, Claude API e OpenAI API, com login, renovação de token, catálogo de modelos e streaming. Versão beta.
