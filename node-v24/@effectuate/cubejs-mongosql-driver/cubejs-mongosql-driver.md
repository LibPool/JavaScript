# @effectuate/cubejs-mongosql-driver

> 标签: analytics, atlas, cube, cubejs, cubejs-driver, mongodb, mongosql, olap

## 简介

Cube.js native data source driver for MongoDB via the MongoSQL translator (Rust + napi-rs). Replacement for the EOL'd BI Connector path.
