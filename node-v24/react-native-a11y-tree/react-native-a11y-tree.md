# react-native-a11y-tree

> 标签: a11y, accessibility, agent, expo, fabric, headless, hermes, layout, metro, react-native, testing

## 简介

Render a React Native component headlessly (real Metro + Fabric/Hermes) and print its accessibility and layout tree; interact with it and check a11y/design rules. For agents and CI.
