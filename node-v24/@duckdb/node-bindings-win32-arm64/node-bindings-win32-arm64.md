# @duckdb/node-bindings-win32-arm64

> 标签: JavaScript

## 简介

Binaries supporting [Node](https://nodejs.org/) bindings to the [DuckDB C API](https://duckdb.org/docs/api/c/overview) for Windows (Win32) arm64.
