# @neograce/cli

> 标签: bun, cli, code-review, grace, knowledge-graph, lint, python, semantic-markup, typescript, verification

## 简介

neo-grace CLI for .ngrace linting, transition gates, run ledger and cursor, mechanized review with deterministic finding ids, task-scoped context slices, status snapshots, module health, and verification queries, with a Bun-powered ngrace binary.
