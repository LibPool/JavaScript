# @fhirstarter/ehr

> 标签: ehr, fhir, fhirclient, oauth2, react, smart-app-launch, smart-on-fhir, vue

## 简介

Thin, plug-and-play SMART on FHIR EHR-launch library with no runtime deps. Runs native SMART App Launch in the background with live progress and turnkey Vue/React components, then hands off a flat authorized result for any FHIR library.
