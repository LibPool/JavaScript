# @resnovas/openclaw-proton-pass

> 标签: credentials, mcp, openclaw, openclaw-plugin, proton-pass, secret-provider, secrets

## 简介

Resolve OpenClaw credentials from Proton Pass at request time, so no API key is written into openclaw.json
