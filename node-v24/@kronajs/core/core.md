# @kronajs/core

> 标签: code-folding, config, configuration, diff, dotenv, folding, hcl, ini, json, json5, jsonc, properties, terraform, toml, typescript, viewer, xml, yaml

## 简介

Framework-agnostic core behind kronajs: a line-based document model for JSON, YAML, TOML and INI/.env, with folding ranges and a line diff.
