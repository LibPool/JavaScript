# @kyoofus/kyotool-userinfo

> 标签: JavaScript

## 简介

`kyotool-userinfo`는 TypeScript로 작성된 간단한 CLI 도구입니다. 사용자 ID를 입력하면 랜덤한 사용자 프로필을 생성해 JSON 형식으로 출력합니다.
