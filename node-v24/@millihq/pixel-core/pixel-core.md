# @millihq/pixel-core

> 标签: JavaScript

## 简介

This is the core package of [Pixel for Next.js](https://github.com/milliHQ/pixel). It is a small wrapper that extracts the image-optimization functionality of Next.js and makes it usable without starting the whole Next.js server.
