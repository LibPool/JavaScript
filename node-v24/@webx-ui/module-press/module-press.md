# @webx-ui/module-press

> 标签: admin, cms, media-coverage, press, vue, webx-ui

## 简介

Press for the WebX UI admin panel: the outlets that wrote about a site and their articles — a link or a PDF — ordered by hand, shown on the site by blocks.
