# @webx-ui/module-recipes

> 标签: admin, cms, recipes, vue, webx-ui

## 简介

Recipes for the WebX UI admin panel: a gallery, ingredients, method and nutrition, flat categories with pages of their own, and the nutrients a recipe is rich in.
