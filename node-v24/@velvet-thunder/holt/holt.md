# @velvet-thunder/holt

> 标签: chrome-extension, markdown, notes, qa, screen-recording, screenshot, vite-plugin

## 简介

Local server for the holt Chrome extension: writes screenshots, recordings and QA notes straight into your repo as markdown. CLI + Vite plugin, zero dependencies.
