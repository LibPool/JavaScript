# @tensorfeed/x402-base-mcp

> 标签: afta, agent-payments, base, ethereum, evm, mcp, model-context-protocol, tensorfeed, usdc, x402

## 简介

Read-only MCP server for verifying x402 USDC settlements on Base mainnet. The verify-side companion to Coinbase Base MCP, with AFTA federation helpers.
