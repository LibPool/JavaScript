# @apick/cms

> 标签: admin, apick, cms, headless-cms, themes, wordpress-alternative

## 简介

APIck CMS — a full, themable CMS on top of @apick/core: schema-driven admin UI, users & sessions, server-rendered themable frontend, plugins. WordPress-class, headless-first.
