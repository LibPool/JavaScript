# @agtnames/cli

> 标签: a2a, agent, agent-identity, agt, ai-agents, cli, manifest, mcp, metamask, naming, polygon

## 简介

Register a .agt name, publish a signed manifest, set records and verify the result from a terminal. Signs in MetaMask through a local page, or with a key from the environment or an encrypted keyfile.
