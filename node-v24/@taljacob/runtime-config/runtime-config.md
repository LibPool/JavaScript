> 标签: build-once-deploy-anywhere, config, docker, environment-variables, envsubst, nginx, runtime-config, runtime-env, spa, vite, vite-plugin

## 简介

Build a web app once, set its settings when it is deployed - and refuse to start when they are missing or wrong.
