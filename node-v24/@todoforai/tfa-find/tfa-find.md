# @todoforai/tfa-find

> 标签: cli, embeddings, multimodal, search, todoforai

## 简介

Local multimodal file index — register folders, embed images / PDF pages / audio / video with gemini-embedding-2 (swappable engine), semantic search with a stable --json contract.
