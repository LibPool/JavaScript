# @todoforai/voiceloop

> 标签: barge-in, conversational-ai, deepgram, elevenlabs, llm, piper, realtime, speech, speechmatics, stt, tts, vad, voice, voice-agent

## 简介

Fast, interruptible browser voice agent: VAD → STT → LLM → TTS with real barge-in, echo filtering, streaming first-sentence TTS and tap-to-seek. Zero runtime dependencies.
