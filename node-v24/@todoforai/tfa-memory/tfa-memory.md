# @todoforai/tfa-memory

> 标签: cli, memory, search, todoforai

## 简介

Zero-config TODOforAI memory CLI — add/search/ls/get/rm/live text memory rows addressed as source/ref, plus federated search over every message of every past TODO (read-only `todo` source), with full-text and semantic search, plus L2 working-memory re-ren
