# @fezchat/tailwind-preset

> 标签: JavaScript

## 简介

A Tailwind preset whose fez-* color utilities resolve to the live fez theme tokens. Dev-only for extension authors: IntelliSense + typo-checking against the utilities the fez host ships at runtime.
