# @fezchat/lium

> 标签: JavaScript

## 简介

Lium (Bittensor subnet 51) GPU rental for fez — agents rent a machine sized to the job, run it, and give it back. Lets attached agents run commands on rented machines and pay for them from your Lium balance.
