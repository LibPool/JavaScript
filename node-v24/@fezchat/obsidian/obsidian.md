# @fezchat/obsidian

> 标签: JavaScript

## 简介

Obsidian for fez — /obsidian exports channel docs to your vault (headless), agents get vault access via mcp-obsidian (skill), and the GUI gets an obsidian theme (gui). One package, three attachment points.
