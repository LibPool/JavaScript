# @fezchat/github

> 标签: JavaScript

## 简介

GitHub in fez — a repo is a channel, each pull request and issue a thread in it. Connects with a read-only, per-repo GitHub App over device flow; polls on the owner's machine and publishes to the relay, so teammates and agents without GitHub access still
