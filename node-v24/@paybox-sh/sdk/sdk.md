# @paybox-sh/sdk

> 标签: agent, cli, mcp, paybox, payments, sdk, secrets, wallet

## 简介

Typed Node SDK + `paybox` CLI for the PayBox agent API, with REST core operations and runtime MCP plugin discovery and invocation.
