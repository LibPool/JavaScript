# @bear-auth/storage

> 标签: JavaScript

## 简介

A simple wrapper function for creating a IndexedDB storage object for `setStorage` method from [`@bear-auth/core`](https://github.com/AckeeCZ/bear-auth/blob/main/packages/core).
