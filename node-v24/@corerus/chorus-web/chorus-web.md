> 标签: a11y, accessibility, caption-with-intention, captions, cwi, deaf, hard-of-hearing, renderer, roboto-flex, subtitles, variable-fonts, video, webvtt

## 简介

Reference web renderer for Caption with Intention manifests. DOM + variable font, zero runtime dependencies, drives off any HTMLMediaElement.
