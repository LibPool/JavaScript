# @voidly/mcp-email

> 标签: agent, ai, claude, email, inbox, llm, mcp, messaging, tool, voidmail

## 简介

MCP server for agent email: create @voidmail.ai inboxes, send to owner-approved recipients, receive, search and manage aliases. No phone or CAPTCHA.
