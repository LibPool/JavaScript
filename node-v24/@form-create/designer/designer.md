# @form-create/designer

> 标签: @form-create, AI, components, draggable, dynamic-form, element-ui, form, form-builder, form-designer, json-form, vue.js, 表单设计器

## 简介

好用的Vue低代码可视化表单设计器，可以通过拖拽的方式快速创建表单，提高开发者对表单的开发效率。
