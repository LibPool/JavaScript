# @cboxdk/id-nuxt

> 标签: authentication, cbox-id, nuxt, nuxt-module, oidc, sso

## 简介

Nuxt module for Cbox ID — drop-in sign-in / callback / sign-out routes and session handling built on @cboxdk/id-js. Add authentication to a Nuxt app with one module entry.
