# @cloudbitmaps/core

> 标签: audience, bitmap, bitset, cloud, compressed-bitmap, croaring, lambda, nodejs, object-storage, roaring, roaring-bitmap, roaring-bitmaps, scale-to-zero, segmentation, serverless, set, set-intersection, typescript

## 简介

Internal engine of CloudBitmaps, which the other @cloudbitmaps packages are built on. Its main entry is outside the stability promise; the public contract for writing a driver is @cloudbitmaps/core/driver-kit. No cloud SDK.
