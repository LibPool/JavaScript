# @astergaze/commentor-react

> 标签: annotation, bug-report, comments, feedback, react

## 简介

React binding for @astergaze/commentor-core — drop <CommentorProvider config=…> around your app and stakeholders can comment on it. Works inside focus-trapping modals (Radix/shadcn, Mantine); not inside a native <dialog>.showModal().
