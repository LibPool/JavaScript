# @hnss/psi-plugin-base

> 标签: JavaScript

## 简介

名字为 `base` 的 Mount。类型从 `@hnss/psi-compose` 导入，运行时不依赖 `@hnss/psi-core`。配置是 `{ cwd: string }`。本包不提供会话存储。
