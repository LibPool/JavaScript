# @wcmj/sill

> 标签: config, json-schema, json5, jsonc, lint, schemastore, toml, validation, yaml

## 简介

Schema validation for config files: respects $schema and falls back to the SchemaStore catalog. JSON, JSONC, JSON5, YAML, TOML.
