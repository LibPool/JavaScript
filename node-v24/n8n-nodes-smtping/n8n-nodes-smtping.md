# n8n-nodes-smtping

> 标签: disposable email, email validation, email verification, n8n-community-node-package, smtping, spamtrap

## 简介

n8n community node for SMTPing: verify email addresses, run bulk list jobs, and check spamtrap, disposable, spambot and complainer lists.
