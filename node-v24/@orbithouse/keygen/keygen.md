# @orbithouse/keygen

> 标签: ethereum, frame, keccak256, keystore, local-keygen, metamask, orbit, secp256k1, self-custody, web3-keystore-v3

## 简介

Local Ethereum keypair generator. Writes Web3 Keystore v3 (importable by MetaMask, Frame, geth). Private keys never leave the local filesystem.
