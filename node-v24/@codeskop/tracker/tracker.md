# @codeskop/tracker

> 标签: analytics, api-monitoring, apm, browser, bugsnag-alternative, codeskop, crash-reporting, error-monitoring, error-tracking, exception-tracking, frontend-monitoring, javascript-errors, logging, network-monitoring, performance-monitoring, product-analytics, real-user-monitoring, rum, sentry-alternative, typescript

## 简介

Error tracking, API monitoring and product analytics for web apps. Free plan, 2-minute setup, ~14 KB, zero dependencies. Works with any framework or a single script tag.
