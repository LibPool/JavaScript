# @codeskop/tracker-react

> 标签: analytics, apm, codeskop, crash-reporting, error-boundary, error-monitoring, error-tracking, nextjs, performance-monitoring, product-analytics, react, react-error-boundary, real-user-monitoring, sentry-alternative, typescript

## 简介

React error tracking and analytics for Codeskop: provider, error boundary and hook. Works with Next.js App Router, Vite and CRA. Free plan.
