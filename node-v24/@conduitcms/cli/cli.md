# @conduitcms/cli

> 标签: JavaScript

## 简介

Conduit — an AI-first, code-first headless CMS. This is a name reservation for @conduitcms/cli, the native Bun CLI (binary name `conduit`). Primarily the schema plane; every command supports --json for agent consumption. See scope.md.
