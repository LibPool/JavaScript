# dsh-session-titler

> 标签: client-plugin, cordis, deepseek, deepseek-harness, dsh, dsh-plugin, session, title, web

## 简介

DSH 会话标题生成器：把整个会话总结成一条新标题，确认后才写入。Session title generator for DeepSeek Harness: summarize the whole session into one title, then confirm before applying it.
