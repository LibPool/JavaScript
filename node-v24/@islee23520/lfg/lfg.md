# @islee23520/lfg

> 标签: grok-build, lazycodex, npx, setup

## 简介

OpenCode OmO / lazycodex GrokBuild port: npx @islee23520/lfg setup --run installs the lfg-owned Grok Build plugin payload under ~/.grok/plugins/lfg.
