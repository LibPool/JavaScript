# @pydantic/llm-babel

> 标签: anthropic, bedrock, gateway, gemini, llm, openai, pydantic, translate

## 简介

Translate LLM requests, responses, errors, and streams between provider wire formats (OpenAI, Anthropic, Gemini, Bedrock, Mistral, DeepSeek, Cohere) through one canonical IR. The TypeScript backend of llm-babel, transpiled from one spec and proven byte-id
