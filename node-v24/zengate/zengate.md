# zengate

> 标签: api-gateway, chat-completions, gateway, keyless, llm, openai, openai-compatible, opencode, proxy, responses-api, self-hosted, zen

## 简介

Keyless OpenAI-compatible API (Chat Completions + Responses) for OpenCode's free Zen models, served through the real OpenCode CLI.
