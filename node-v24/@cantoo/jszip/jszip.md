# @cantoo/jszip

> 标签: archive, compression, deflate, esm, fflate, inflate, jszip, typescript, unzip, zip

## 简介

Maintained fork of JSZip — create, read and edit .zip files with JavaScript. Based on @bybrave/jszip2 with fflate compression.
