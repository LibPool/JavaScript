# @foundanand/spyglass-sdk

> 标签: analytics, error-tracking, product-analytics, rrweb, self-hosted, session-replay, spyglass, telemetry

## 简介

Tiny telemetry SDK for spyglass: events, session replay, flow timing, errors, and bug reports. ~4KB gzipped core; rrweb loads lazily.
