# @fdkey/http

> 标签: ai-agent, anti-bot, captcha, express, fastify, fdkey, hono, http-402, middleware, rest, verification

## 简介

FDKEY verification middleware for plain HTTP backends — gate REST/HTTPS routes behind LLM-only puzzles. Drop-in for Express, Fastify, Hono. Includes browser widget for puzzle rendering.
