# @tangent.to/proba

> 标签: bayesian, browser, distributions, esm, gradients, logpdf, probability, statistics

## 简介

Probability distributions for JavaScript (ESM): logpdf with analytic gradients, logDensity as a differentiable expression, pdf/cdf/quantile, seedable sampling. scipy.stats-validated.
