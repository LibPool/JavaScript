# @xivdyetools/worker-kit

> 标签: cloudflare-workers, hono, logger, middleware, rate-limiting, request-id, typescript, xivdyetools

## 简介

Shared Cloudflare Worker toolkit for xivdyetools: Hono middleware (request ID, logger, rate limit) + request body guards + magic-byte image sniffing + rate limiting backends (Memory, KV, Upstash)
