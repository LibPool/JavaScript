# @moluoxixi/postcss-selector-prefix

> 标签: JavaScript

## 简介

基于 `postcss-selector-parser` 的 PostCSS 插件，用于精确替换 class 与 id 选择器的名称前缀。 插件会替换 selector AST 中的 class/id 节点、`class`/`id` 属性选择器的值， 以及 CSS 值里能表达 selector 的文本片段； 不会改写 `url(...)` 这类资源路径，也不会碰 HTML 或 JS 字符串。
