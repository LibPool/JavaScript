# @moluoxixi/config-form-designer-element-plus

> 标签: JavaScript

## 简介

ConfigForm Designer 的 Element Plus 物料适配包。它提供内置字段/布局物料、运行时组件映射、Element Plus 属性控件和选项来源诊断，并组合成可直接使用的 Designer registry。
