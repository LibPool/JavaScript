# @hasthiya_/headless-comments-react

> 标签: adapter, comment, comment-section, comments, component, composable-hooks, customizable, discussion, headless, nested-comments, optimistic-updates, react, reaction, reply, themeable, thread, tree-crud, typescript, ui

## 简介

A truly headless React comment system with generic types, tree CRUD, standalone hooks, composable per-comment hooks, and pluggable adapters. TypeScript-ready and fully themeable.
