# @web_qiang/aform

> 标签: aform, declarative, element-plus, form, table, vue3

## 简介

基于 Vue3 + Element Plus 的声明式表单/表格组件库（aform）：配置驱动渲染、字典联动、异步请求与自定义组件自动注册。
