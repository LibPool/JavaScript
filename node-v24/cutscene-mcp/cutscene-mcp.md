# cutscene-mcp

> 标签: cli, cutscene, launch-video, mcp, mcp-server, model-context-protocol, motion-design, motion-graphics, mp4, video

## 简介

Cutscene from a terminal and for an assistant: a command line and an MCP server that search the Cutscene library, assemble motion-design films, change them, check them, preview them and export MP4 files on your own machine.
