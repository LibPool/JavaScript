# @ng-native/metro

> 标签: android, angular, angular-native, aot, bundler, css, fabric, ios, metro, native, react-native

## 简介

Metro transformer and config preset for Angular Native: Angular AOT through oxc, the linker, and the build-time CSS compiler.
