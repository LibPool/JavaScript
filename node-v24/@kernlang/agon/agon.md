# @kernlang/agon

> 标签: agent, agon, ai, claude, cli, code-generation, codex, conquer, council, forge, gemini, kernlang, llm, multi-agent, orchestration, synthesis, tribunal

## 简介

The competitive multi-AI orchestration CLI. Engines compete in isolated git worktrees on the same task, the best test-passing solution is applied, and Glicko-2 ratings track each model over time. Modes: forge, brainstorm, synthesis, tribunal, council, cam
