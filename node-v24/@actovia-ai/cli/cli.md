# @actovia-ai/cli

> 标签: JavaScript

## 简介

A CLI for the Actovia ecosystem: launch the Actovia desktop app, check for CLI updates, and browse/install [Agent Skills](https://skills.sh) from the terminal — either interactively or as scriptable JSON-emitting commands.
