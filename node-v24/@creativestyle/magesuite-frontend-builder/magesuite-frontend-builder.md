# @creativestyle/magesuite-frontend-builder

> 标签: JavaScript

## 简介

A modern build system for Magento 2 / MageSuite themes built on **Webpack 5**, **TypeScript**, and **Gulp 5**. Provides webpack bundling, SCSS compilation, asset copying, image optimisation, linting, BrowserSync dev proxy, and Magento cache management — a
