# @finnsky/design-tokens-to-ui-suite

> 标签: css-variables, daisyui, design-tokens, drupal, dtcg, ui-skins, ui-suite

## 简介

Transform DTCG (W3C Design Tokens) or Tokens Studio JSON into Drupal UI Suite / UI Skins artifacts via configurable mapping presets.
