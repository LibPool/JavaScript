# @jiujue/weave-adapter-worker-image

> 标签: canvas, imagebitmap, rendering, weave, webworker

## 简介

Weave Worker Image 适配：把渲染放到 Worker，并把结果以 ImageBitmap / ImageData 传回主线程。
