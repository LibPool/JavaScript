# expo-mapbox-nav

> 标签: android, expo, expo-config-plugin, expo-modules, ios, mapbox, mapbox-navigation, navigation, react-native, turn-by-turn

## 简介

Mapbox Navigation SDK v3 for Expo (Android + iOS): turn-by-turn navigation, pressable SVG markers, <Camera/>, dark mode and a 3D vehicle puck.
