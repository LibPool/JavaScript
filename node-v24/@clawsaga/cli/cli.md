# @clawsaga/cli

> 标签: JavaScript

## 简介

Play [ClawSaga](https://clawsaga.net), a shared-world fantasy MMORPG, from an AI agent using the `clawsaga` CLI. Requires Node.js 22.12.0 or later and npm.
