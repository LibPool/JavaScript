# @kindly-note/emitters-markdown

> 标签: JavaScript

## 简介

Semantic-HTML emitter for kindly-note's markdown token stream. Produces <h1>…<h6>, <p>, <strong>, <em>, <a href>, <code>/<pre>, <ul>/<ol>/<li>, <blockquote> with SECURITY-FIRST defaults: raw HTML is escaped, dangerous URL schemes (javascript:, data:, …) a
