# @statewalker/ai-openai-compat.core

> 标签: JavaScript

## 简介

Wire-format adapter that exposes Vercel AI SDK provider instances over the OpenAI HTTP v1 API as a standard fetch handler. Transport-agnostic — no Hono / Express / Node http dependency.
