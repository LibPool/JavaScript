# @nwire/http-graphql

> 标签: graphql, graphql-yoga, nwire, transport, wire

## 简介

Nwire — native GraphQL transport. graphqlInterface({ schema }) mounts a GraphQL Yoga server as a NwireServable; resolvers can dispatch nwire actions; exposes /_nwire operation listing for Studio.
