# @msdshsk/react-er-canvas

> 标签: database, electron, elkjs, entity-relationship, er-diagram, mermaid, query-builder, react, react-flow, schema

## 简介

Render Mermaid-format ER diagrams in React/Electron with extended visual features (PK/FK icons, schema groups, FK reference highlighting, manual JOINs, drag-to-position).
