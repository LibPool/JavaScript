# @querais/sdk

> 标签: ai, arbitrum, decentralized, inference, llm, openai-compatible, querais, web3

## 简介

TypeScript client + CLI for QueraIS, the decentralized AI inference marketplace. OpenAI-shaped chat/streaming plus QueraIS extras: nodes, stats, batched-settlement sessions.
