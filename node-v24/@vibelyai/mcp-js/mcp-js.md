# @vibelyai/mcp-js

> 标签: ai-assistant, mcp, model-context-protocol, oauth, supabase, tanstack, vibely

## 简介

Turn a Vibely app into an MCP server that ChatGPT, Claude and other AI assistants can use. Declare tools with defineTool, register them with defineMcp; OAuth 2.1 resource-server auth against the app's own Supabase project.
