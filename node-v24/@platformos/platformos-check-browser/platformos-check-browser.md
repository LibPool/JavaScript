# @platformos/platformos-check-browser

> 标签: JavaScript

## 简介

This is the Browser wrapper of the runtime-agnostic [`@platformos/platformos-check-common`](https://npm.im/@platformos/platformos-check-common) package. It does not come with batteries included and assumes you know what you're doing.
