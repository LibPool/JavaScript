# @lofcz/embedpdf-plugin-shell

> 标签: JavaScript

## 简介

Document-scoped workbench surface state: named surfaces (panels, modals, overlays) with exclusivity groups, plus the open-menu stack. Pure serializable state — commands drive it, and applications can snapshot and restore it. The app owns the DOM.
