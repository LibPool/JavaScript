# @lofcz/embedpdf-core-ui

> 标签: JavaScript

## 简介

Pure chrome core: the structure-only schema vocabulary, the toolbar fit solver (measure → solve → overflow), the overflow-to-menu projection, and the shortcut parser/matcher. DOM-free, kernel-free, framework-free.
