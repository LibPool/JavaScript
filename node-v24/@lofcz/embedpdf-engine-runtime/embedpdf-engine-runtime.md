# @lofcz/embedpdf-engine-runtime

> 标签: embedpdf, native, pdf, runtime, wasm

## 简介

Low-level PDF execution runtime for EmbedPDF, backed by EmbedPDF's fork of PDFium and distributed as WASM and native platform packages.

## 官网

- 官网：https://www.embedpdf.com
- 源码仓库：git+https://github.com/lofcz/embed-pdf-viewer.git
