# postali

> 标签: api, codigo postal, colombia, colonias, cp, códigos postales, espana, geonames, mexico, postal code, sepomex, spain, zip code

## 简介

Cliente oficial de la API gratuita de códigos postales de Postali (México, Colombia, España). Sin dependencias, con tipos.
