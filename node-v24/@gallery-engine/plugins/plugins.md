# @gallery-engine/plugins

> 标签: JavaScript

## 简介

Plugins 提供可插拔的 Gallery 扩展能力：水印、下载、AI 标签和 AI 相似搜索。每个插件都可以安装到 `Gallery` 或兼容的上下文对象中。🧰
