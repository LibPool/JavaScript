# @logituit-rel/logix-ads-manager

> 标签: Ads SDK, IMA, Vega Application, Vega OS, logituit

## 简介

Logix Ads Manager uses IMA SDK for HTML5 and display Ads using a WebView in a Vega Application. This package is specifically designed for Vega OS.
