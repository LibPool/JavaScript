# @simon_he/translate

> 标签: api, async, auto-translate, batch-translation, bing-translate, cjs, cross-platform, deepl, deeplx, es6, esm, fallback, fast, free-translation, google-translate, i18n, internationalization, javascript, language, lightweight, lingva, localization, machine-translation, multilingual, multiple-providers, mymemory, nodejs, open-source-translation, promise, reliable, robust, text-translation, translate, translation, translation-api, translator, typescript

## 简介

A fast, robust, and lightweight translation library supporting 5 translation services (Google, Bing, DeepL, MyMemory, Lingva) with automatic fallback, batch processing, caching, and full TypeScript support.
