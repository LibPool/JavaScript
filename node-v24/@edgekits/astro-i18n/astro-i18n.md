# @edgekits/astro-i18n

> 标签: astro, astro-integration, cloudflare, cloudflare-workers, edge, i18n, kv

## 简介

Edge-native i18n for Astro on Cloudflare Workers: translations in Workers KV, a per-namespace edge cache invalidated by the Purge API, and typed keys.
