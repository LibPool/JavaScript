# @flashyos/dialects

> 标签: A2A, AAO, agent card, agents.txt, interoperability

## 简介

One charter, many dialects — emits the surfaces other standards define (agents.txt/agents.json, A2A Agent Card) from an organisation's AAO charter, so the same facts cannot drift between them. Refuses to emit a surface the organisation does not serve.
