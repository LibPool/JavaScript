# @capseal/wasm

> 标签: c2pa, cloudflare-workers, provenance, verification, wasm, webassembly

## 简介

The CapSeal verifier compiled to WebAssembly. Verify a proof object offline, in a browser, a Worker or Node - no server and nothing of ours in the path.
