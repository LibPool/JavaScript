# @paean-ai/harness-paean-app

> 标签: JavaScript

## 简介

Paean App plugin: hosts the Paean web app under /workspace on the harness origin, reverse-proxies the Paean API under /paean-api, and embeds the app as a frame-wide surface behind a sidebar launcher
