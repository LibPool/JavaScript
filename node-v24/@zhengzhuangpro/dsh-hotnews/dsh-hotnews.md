# @zhengzhuangpro/dsh-hotnews

> 标签: dsh, hotnews, news, plugin, trending

## 简介

DSH Web 插件：在 DeepSeek Harness 浏览器界面内查看 hotnews 聚合的热门新闻（百度/微博/抖音/虎扑/知乎/掘金/36氪/GitHub/少数派/华尔街见闻）。
