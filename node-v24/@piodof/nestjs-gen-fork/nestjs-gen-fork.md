# @piodof/nestjs-gen-fork

> 标签: JavaScript

## 简介

A command line tool to automatically generate some or all feature set files for NestJS: * \<name>.module.ts * \<name>.controller.ts * \<name>.service.ts * \<name>.repository.ts * \<name>.model.ts
