# @consensys/linea-ccip-gateway

> 标签: JavaScript

## 简介

Adapted from [EVM gateway](https://github.com/ensdomains/evmgateway) for fetching data on Linea along with Sparse Merkle Proofs and return it to the L1 callback function.
