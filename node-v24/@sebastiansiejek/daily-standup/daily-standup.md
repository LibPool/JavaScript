# @sebastiansiejek/daily-standup

> 标签: automation, daily, jira, report, standup, tasks, time, timecamp

## 简介

1. Retrieves time entries from TimeCamp 2. Matches entries with Jira issues 3. Generates a consolidated report 4. Handles weekend/Monday edge cases automatically
