# @offchain-wtf/sdk

> 标签: base, ethereum, gateway, ipfs, payment, payment-protocol, usdc, web3, x402

## 简介

Offchain.wtf is a pay-per-request IPFS gateway. This SDK provides a simple interface for interacting with the gateway.
