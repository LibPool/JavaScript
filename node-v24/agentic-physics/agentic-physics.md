# agentic-physics

> 标签: claude-code, cli, formal-verification, lean, lean4, mathlib, physics, physlib, theorem-proving

## 简介

Command-line client for Agentic Physics: formalize physics in Lean 4, prove it with a kernel-checked proof, and talk to the agent — from a terminal or from a coding agent such as Claude Code.
