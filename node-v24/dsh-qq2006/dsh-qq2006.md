# dsh-qq2006

> 标签: deepseek-harness, dsh, dsh-plugin, qq2006, retro, skin, theme, web-ui

## 简介

QQ2006 skin for the DeepSeek Harness Web UI: coral-blue palette, SimSun typography, classic controls, chat-window toolbar and a skin center with a pixel-accurate login window.
