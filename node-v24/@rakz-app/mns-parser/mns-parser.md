# @rakz-app/mns-parser

> 标签: file-format, mnemonic, mns, parser, plain-text, rakz, rkz, serializer, typescript

## 简介

Reference reader and writer for the MNS Format — the open, plain-text format for mnemonics (.mns / .rkz). MNS-format compatible (0.1).
