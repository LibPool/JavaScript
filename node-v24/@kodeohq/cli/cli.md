# @kodeohq/cli

> 标签: cli, collaborative, dashboard, git, ide, kodeo, sync, tui, vscode

## 简介

The KODEO command-line tool: a full-screen dashboard (kodeo ui), live chat, comments, notifications, KODEO Assist, the project's Git and pull requests, teammates' terminals — and two-way sync of a KODEO project with a folder (kodeo watch), KODEO as a Git
