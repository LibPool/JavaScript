# @ramper/react-native-evm

> 标签: android, blockchain, crypto, ios, ramper, ramper.xyz, react-native, terra, wallet

## 简介

Ramper's EVM React Native SDK works with Ramper's Core React Native SDK to help developer easily onboard new users onto their Ethereum DApp through account management, wallet creation, and wallet interactions.
