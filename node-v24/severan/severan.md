# severan

> 标签: dead-code-elimination, partial-evaluation, rspack, specialize, svelte, tree-shaking, vite, webpack, zero-dependency

## 简介

Zero-dependency Svelte component specializer: rewrites each component a library ships for the props an app passes it, so branches that can never render are cut from the build.
