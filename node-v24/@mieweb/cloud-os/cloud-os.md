# @mieweb/cloud-os

> 标签: JavaScript

## 简介

os.mieweb.org (self-hosted) adapters implementing the Cloudflare-shaped @mieweb/cloud contracts over durable, networked infrastructure: D1→libSQL/sqld, Vectorize→libSQL native vectors, R2→S3/MinIO, KV+Queues→Valkey/Redis. Durable Objects stay single-node
