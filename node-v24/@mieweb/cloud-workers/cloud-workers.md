# @mieweb/cloud-workers

> 标签: JavaScript

## 简介

Portable `cloudflare:workers` shim. Backs the `mieweb:workers` virtual module: re-exports the native runtime on Cloudflare (workerd) and provides a pure-JS DurableObject base everywhere else.
