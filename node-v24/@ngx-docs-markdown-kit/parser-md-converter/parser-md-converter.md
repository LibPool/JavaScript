# @ngx-docs-markdown-kit/parser-md-converter

> 标签: badges, docs, markdown, npm, nuget, readme

## 简介

Genera README.md multi-flavor (GitHub/npmjs/NuGet) a partir del manifiesto de contenido de un sitio create-ngx-docs-site -- nucleo agnostico de framework (sin dependencias de Angular): marcadores de splice, deteccion de badges, downgrade de las extensione
