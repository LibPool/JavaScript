# @ngx-docs-markdown-kit/parser-md-code-block-themes

> 标签: angular, code-block, docs, markdown, themes

## 简介

Decenas de paletas de color reales (Nord, Monokai, Atom One Dark, GitHub Dark, y ~80 mas) para @ngx-docs-markdown-kit/parser-md-code-block, generadas desde los temas oficiales de highlight.js. Opcional: solo se activa si esta instalado.
