# @ngx-docs-markdown-kit/parser-md-card

> 标签: angular, card, docs, markdown, material

## 简介

Extension de @ngx-docs-markdown-kit/parser-md que reconoce un fence "content-card" (imagen/titulo/subtitulo/contenido/acciones) y expone un componente de Angular que lo renderiza con <mat-card> real de Angular Material.
