# @ngx-docs-markdown-kit/parser-md

> 标签: docs, frontmatter, markdown, marked, parser

## 简介

Parser de Markdown extensible para sitios de documentacion -- nucleo agnostico de framework (sin dependencias de Angular), basado en marked. Define el punto de extension (.use()) que consumen los paquetes parser-md-seo y parser-md-code-block.
