# @adatechnology/game-floorplan-post-apocalyptic

> 标签: floorplan, game, house-state, post-apocalyptic, survival, zombie

## 简介

Post-apocalyptic genre pack for @adatechnology/game-floorplan: the fortified and abandoned house states as a state plugin, with their item types, flags and a configurable seed distribution.
