# @adatechnology/game-characters

> 标签: body, characters, damage, dismemberment, game, penetration

## 简介

Engine-agnostic living bodies for games: body proportions, rig, an 11-kind segment tree with 6 crowd regions, and a damage model (protection, penetration, severity, dismemberment, death, bleeding) as a DestructibleImpl. Deterministic. Knows nothing about
