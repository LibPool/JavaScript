# @adatechnology/game-props3d

> 标签: furniture, game, low-poly, procedural, props, three, threejs

## 简介

Procedural low-poly 3D props (decor, modern furniture, yard, house-state). Builders only describe primitives through an api passed by the host, so any renderer can draw them.
