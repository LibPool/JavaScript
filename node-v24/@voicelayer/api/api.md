# @voicelayer/api

> 标签: agents, api, messaging, sms, sse, voicelayer, webhooks, whatsapp

## 简介

The VoiceLayer REST API client: messages, conversations, events, webhooks and channels. Generated from the public OpenAPI document, plus webhook verification and the event stream.
