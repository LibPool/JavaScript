# @aiassesstech/budget-betty

> 标签: budget-betty, cashcanvas, fleet, openclaw

## 简介

Budget-Betty — household finance OpenClaw agent. Ships identity files, budget_betty_status, and budget_betty_upload_file. CashCanvas tools arrive via remote MCP client, not this plugin.
