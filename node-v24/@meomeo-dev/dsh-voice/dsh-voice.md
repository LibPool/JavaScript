# @meomeo-dev/dsh-voice

> 标签: JavaScript

## 简介

Conversation-tone switcher bundle for DeepSeek Harness — ships the 令 (Ling) tone, a create-voice meta-skill, and a web UI for three-level (session/workspace/user) voice switching.
