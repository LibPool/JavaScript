# @mmutils/bench

> 标签: benchmark, distribution, histogram, microbenchmark, mmutils, performance, typescript, worker

## 简介

Microbenchmarks with run time distributions: every call is timed in a fresh worker, with CPU and memory probes, and plotted side by side with @mmutils/logger.
