# @aglyn/aglyn-transfer-ui

> 标签: JavaScript

## 简介

The import and export screens every Aglyn surface uses: the export dialog, the eight-step import wizard, and the pieces they are built from. It is the UI over the import/export core in `@aglyn/aglyn/data-transfer`, which holds the header matching, value r
