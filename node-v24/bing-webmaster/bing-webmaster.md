# bing-webmaster

> 标签: bing, bing-webmaster, cli, indexing, keyword-research, seo, sitemap, webmaster-tools

## 简介

Command-line control of Bing Webmaster Tools: reports, keyword research, URL/sitemap submission, crawl settings, blocks, users — every API method, with dry-run-by-default writes.
