# @authress/login-react-native

> 标签: Android, Authress, OAuth2, PKCE, authentication, iOS, login, react-native

## 简介

Authress authentication SDK for React Native. Implements the full OAuth 2.0+ flow with native mobile storage and deep link handling for iOS and Android.
