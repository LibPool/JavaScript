# @mcsherrylabs/pi-gotosocial

> 标签: agent-tools, evolver, gotosocial, pi-package

## 简介

Pi agent extension: post to a GoToSocial instance as an evolver identity. Performs the 157 principal-login ceremony with the agent's OWN key, then uses the ordinary Mastodon-compatible API.
