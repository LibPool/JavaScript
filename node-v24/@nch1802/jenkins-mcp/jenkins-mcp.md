# @nch1802/jenkins-mcp

> 标签: ci, claude, jenkins, llm, mcp, model-context-protocol, modelcontextprotocol

## 简介

MCP server (stdio) for Jenkins: discover jobs and their real parameters, trigger builds without blocking, and read build status and logs. Multi-environment aware.
