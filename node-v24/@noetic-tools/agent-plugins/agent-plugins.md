# @noetic-tools/agent-plugins

> 标签: agent-plugins, agent-skills, agents, context, mcp, model-context-protocol, noetic

## 简介

Agent Plugins v1 client for Noetic — discovers agent-plugins.org packages (Agent Skills + MCP servers) and exposes them to an agent through the agentPlugins() context layer.
