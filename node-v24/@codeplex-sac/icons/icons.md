# @codeplex-sac/icons

> 标签: JavaScript

## 简介

El sistema de iconos semánticos de **Codeplex-SAC**, basado en **Google Material Symbols Rounded**. Este paquete proporciona una iconografía consistente, moderna y alineada con la tipografía **Poppins**.
