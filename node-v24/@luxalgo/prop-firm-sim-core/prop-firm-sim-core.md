# @luxalgo/prop-firm-sim-core

> 标签: drawdown, evaluation, expected-value, monte-carlo, prop-firm, prop-trading, risk-of-ruin, simulation, trading, trading-challenge

## 简介

Seedable, browser-safe Monte Carlo engine for prop-firm challenge simulation: pass probability, expected attempts, expected cost, EV, and optimal risk sizing from a trader profile and a firm's exact ruleset - with every assumption visible.
