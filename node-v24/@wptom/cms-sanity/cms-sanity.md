# @wptom/cms-sanity

> 标签: astro, cms, content-loader, sanity, wptom

## 简介

Sanity CMS for WPTom templates: Studio schema, Astro loader and seeding, all generated from the template's content model. No dependencies besides @wptom/content-model.
