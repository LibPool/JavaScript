# @firebase-bridge/firestore-functions

> 标签: cloud functions, emulator alternative, firebase, firebase admin, firebase functions, firestore, firestore admin, firestore emulator, firestore functions, firestore mock, firestore trigger, firestore triggers, gapic, in-memory firestore, jest, mock firestore, testing, trigger, triggers, unit testing, vitest

## 简介

Bind firebase-functions v1 & v2 Firestore triggers to an in-memory Firestore (from @firebase-bridge/firestore-admin) for fast, deterministic backend tests—no emulator required.
