# @devicechain/widgets

> 标签: dashboard, devicechain, echarts, iot, maplibre, react, widgets

## 简介

DeviceChain's built-in dashboard widgets across six channels — telemetry (time-series chart + gauge over Apache ECharts, latest card, table, and lazily loaded level, indicator and radial widgets: linear and level gauges, battery, status light, signal bars
