# @expunct/sdk

> 标签: ai, gdpr, hipaa, llm, pdf, pii, privacy, rag, redaction, typescript

## 简介

Node.js SDK for the Expunct PII redaction API — detect and redact PII from text, PDFs, images, video, and audio before it reaches your LLM.
