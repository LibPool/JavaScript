# @prustogi/buddy

> 标签: agent, buddy, claude, cli, codex, copilot, documentation, onboarding, opencode

## 简介

A friendly onboarding agent for GitHub Copilot CLI, Claude Code CLI, Codex CLI, and OpenCode. Helps newcomers understand any code repository. Stores portable, git-friendly knowledge in .buddy/.
