# @growth-labs/mcp-wrapper-scaffold

> 标签: JavaScript

## 简介

Read-only MCP-wrapper scaffolding for Cloudflare Workers: dual-accept auth (shared bearer against a Secrets Store binding OR short-lived EdDSA gateway JWTs), a per-wrapper method+origin+path allowlist enforced via a closure passed into every tool handler,
