# @growth-labs/opengraph

> 标签: JavaScript

## 简介

Generates branded Open Graph images using Cloudflare Browser Rendering (Puppeteer). Screenshots HTML templates, caches in R2, serves via on-demand route. Four sizes per page: 1200×630 (OG / Facebook / LinkedIn / Twitter), 1200×675 (Google Discover 16:9),
