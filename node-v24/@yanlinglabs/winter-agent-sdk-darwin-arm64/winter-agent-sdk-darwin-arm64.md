# @yanlinglabs/winter-agent-sdk-darwin-arm64

> 标签: JavaScript

## 简介

The compiled `winter` runtime binary for macOS on Apple Silicon (`darwin`/`arm64`). This package ships **no JavaScript API** — it is an `optionalDependency` of [`@yanlinglabs/winter-agent-sdk`](https://github.com/yanlingLabs/winter-agent-sdk/tree/main/pac
