# @soljs/sol

> 标签: JavaScript

## 简介

The `@soljs/sol` package is the browser and server runtime plus author-facing interface for Sol applications. It provides compiled components, fine-grained reactive state, document-head content, DOM refs, portals, forms, cached queries, mutations, server
