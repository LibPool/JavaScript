# @matteai/stma-server

> 标签: agent-fleet, coding-agents, devtools, mcp, model-context-protocol, self-hosted

## 简介

STMA (Speak to my Agent) server — self-hostable control plane for coding agents: MCP endpoint, environment snapshots, debug sessions, agent runs, work claims and policy. Runs on an embedded database with no setup.
