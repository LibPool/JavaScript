# @firescraper/mcp

> 标签: agent, ai, claude, crawler, cursor, firescraper, llm, mcp, model-context-protocol, modelcontextprotocol, rag, scraper, web-scraping

## 简介

Model Context Protocol (MCP) server for FireScraper. Give Claude, Cursor, Windsurf, and any MCP-compatible AI agent the ability to crawl websites and turn them into clean, LLM-ready text.
