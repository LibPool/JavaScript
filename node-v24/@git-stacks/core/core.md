# @git-stacks/core

> 标签: JavaScript

## 简介

The Node.js domain core for git-stacks. It owns schema-compatible YAML persistence, workspace lifecycle, Git/filesystem behavior, integrations, commands, files, notes, labels, priorities, and opt-in agent-hook configuration.
