# @liuheo/table-exporter

> 标签: excel, exceljs, export, file-saver, spreadsheet, table, xlsx

## 简介

Export frontend table data to Excel based on exceljs + file-saver. Supports custom columns, styles, merged cells, multi-sheet, and data-driven export.
