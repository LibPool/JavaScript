# n-atlas

> 标签: african-languages, asr, hausa, igbo, llm, n-atlas, natlas, nigeria, speech-to-text, yoruba

## 简介

Official-style developer SDK for N-ATLaS, Nigeria's sovereign multilingual LLM (Hausa, Igbo, Yoruba, Nigerian English) and its ASR models.
