# @artentus/jam1emu

> 标签: JavaScript

## 简介

This is a work-in-progress emulator for the 8 Bit Pipelined CPU by James Sharman written in Rust.   You can find the real hardware implementation of the CPU on James Sharmans YouTube channel:   https://www.youtube.com/watch?v=3iHag4k4yEg&list=PLFhc0MFC8
