# @wiremark/core

> 标签: balsamiq, dsl, markdown, mockup, mui, sketch, svg, wireframe

## 简介

Core parser, layout engine, and hand-drawn SVG renderer for the wiremark wireframe DSL. Pure JS, no host dependencies.
