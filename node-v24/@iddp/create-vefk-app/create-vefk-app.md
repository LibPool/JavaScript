# @iddp/create-vefk-app

> 标签: create, scaffolder, vefk

## 简介

Scaffolder der VEFK-Tools-Suite — erzeugt ein neues Tool aus vefk-app-template und ersetzt die Platzhalter (Toolname, Marke, Auth-Profil, 2FA/Mail).
