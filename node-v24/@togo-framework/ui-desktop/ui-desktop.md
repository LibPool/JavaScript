# @togo-framework/ui-desktop

> 标签: JavaScript

## 简介

togo UI kit — OS-like desktop shell (dock, windows, spotlight, launchpad, login screen) on top of the `os` plugin. Depends on @togo-framework/ui-core and @togo-framework/ui-auth.
