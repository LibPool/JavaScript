# @iqsteel/mcp-bridge

> 标签: bridge, claude, claude-desktop, ifc, ifc-viewer, iqsteel, mcp, model-context-protocol, websocket

## 简介

MCP server bridging Claude Desktop (or any MCP client) to a running iQSteel / ifc-viewer browser tab via WebSocket.
