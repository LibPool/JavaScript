# @envoys/sdk

> 标签: a2a, agent-identity, ai-agents, cryptography, ed25519, envoys, http-signatures, rfc9421

## 简介

Cryptographic identity for AI agents. Ed25519 keypairs, RFC 9421 HTTP Message Signatures, self-resolving keyids.
