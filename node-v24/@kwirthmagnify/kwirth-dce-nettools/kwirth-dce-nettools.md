# @kwirthmagnify/kwirth-dce-nettools

> 标签: dce, dns, kubernetes, kwirth, network

## 简介

Network primitives shared by Kwirth extensions: TCP reachability and DNS resolution in the back end, and the icon and a shared latency chart in the front end. No binary is spawned
