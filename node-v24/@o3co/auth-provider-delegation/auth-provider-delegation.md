# @o3co/auth-provider-delegation

> 标签: authorization-server, delegation, federation, identity-provider, nodejs, oauth2, oidc, openid-connect, self-hosted, typescript

## 简介

Delegated upstream access for auth-provider, a self-hosted OAuth 2.0 authorization server and OpenID Connect provider for Node.js: a confidential client acts for a user at an upstream provider, with the provider holding and refreshing the upstream tokens.
