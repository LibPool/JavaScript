# @o3co/auth-provider-identity

> 标签: authorization-server, csrf, identity-provider, login, nodejs, oauth2, oidc, openid-connect, self-hosted, session, typescript

## 简介

Clients, users, password login, CSRF protection and sessions for auth-provider, a self-hosted OAuth 2.0 authorization server and OpenID Connect provider for Node.js.
