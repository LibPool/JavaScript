# @mcpvitals/cli

> 标签: agents, ai, cli, health-check, healthcheck, mcp, mcpvitals, model-context-protocol, monitoring, uptime

## 简介

Health-check any MCP server from the command line — runs the real initialize → tools/list handshake and exits 0 (healthy) / 1 (degraded) / 2 (down). By mcpvitals.com.
