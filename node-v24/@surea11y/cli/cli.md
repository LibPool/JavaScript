# @surea11y/cli

> 标签: a11y, a11y-testing, accessibility, accessibility-testing, aria, audit, baseline, cli, command-line, contrast, jsdom, sarif, wcag, wcag21, wcag22

## 简介

Command-line WCAG 2.2 accessibility scanner for static HTML, with baseline gating and HTML/SARIF reports. Powered by @surea11y/core.
