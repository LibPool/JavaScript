# @lightningrodlabs/we-rust-utils

> 标签: holochain, lair, moss, napi, zome-call

## 简介

Native Node.js bindings for Rust utilities used by Moss: signing Holochain zome calls and inspecting/repackaging happ and webhapp bundles.
