# @neuronection/assistant-ui

> 标签: JavaScript

## 简介

Shared React component library for the Assistant family (career-, study-, health-, desktop-assistant). Family look by default, app-flavored via CSS-variable tokens.

- 源码仓库：git+https://github.com/neuronection/assistant-ui.git
