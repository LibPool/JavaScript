# @kohaku-ui/mcp-renderer

> 标签: JavaScript

## 简介

The shared MCP Apps renderer bundle: `.` loads the pre-built, dependency-free single-file HTML (`loadRendererHtml`); `./boot` builds a product-specific renderer bundle from React source (renderer-react etc. as optional peers).
