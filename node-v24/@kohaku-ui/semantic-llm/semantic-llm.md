# @kohaku-ui/semantic-llm

> 标签: JavaScript

## 简介

A default SemanticPort for kohaku: deterministic GUI normalization, LLM-backed natural-language normalization against an Intent catalog (structured output, optional catch-all fallback), and query resolution from @kohaku-ui/intents definitions.
