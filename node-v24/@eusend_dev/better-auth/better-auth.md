# @eusend_dev/better-auth

> 标签: auth, better-auth, better-auth-plugin, email, eusend, gdpr, transactional-email

## 简介

Better Auth plugin for eusend — verification, password-reset, OTP, magic-link and invitation email from the EU, plus contact sync for verified users.
