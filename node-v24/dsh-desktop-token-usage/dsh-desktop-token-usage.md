# dsh-desktop-token-usage

> 标签: dashboard, deepseek-harness, dsh, plugin, statistics, token, usage

## 简介

Local-only DSH token usage dashboard: aggregates session logs under $DSH_HOME and renders them in the sidebar. Verified on DSH Desktop 0.1.7-rc.2, 0.2.0-rc.2 and 0.2.1-rc.2.
