# @ellyseum/cordyceps

> 标签: agent, ai, aider, claude, claude-code, cli, codex, gemini, harness, json-rpc, llm, orchestration, pty, websocket

## 简介

Local-first agent harness — spawns and drives PTY-based CLI coding agents via a JSON-RPC 2.0 control plane, with a service bus and plugin architecture.
