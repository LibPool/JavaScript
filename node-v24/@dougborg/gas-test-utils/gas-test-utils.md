# @dougborg/gas-test-utils

> 标签: gas, google-apps-script, mock, testing, typescript, vitest

## 简介

Vitest mock factories for Google Apps Script globals (SpreadsheetApp, UrlFetchApp, PropertiesService, Logger, Utilities, CacheService) plus generic HTTP response builders.
