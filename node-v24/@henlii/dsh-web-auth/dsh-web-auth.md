# @henlii/dsh-web-auth

> 标签: JavaScript

## 简介

DSH plugin: password authentication + trust for dsh web LAN/Tailscale access. Non-loopback /api and WebSocket traffic requires a password login; once authenticated, the privileged settings/credentials plane works over LAN.
