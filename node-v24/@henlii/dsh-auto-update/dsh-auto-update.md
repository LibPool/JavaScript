# @henlii/dsh-auto-update

> 标签: JavaScript

## 简介

DSH plugin: one-click update for the DeepSeek Harness runtime — check npm latest/next dist-tags, upgrade to the preview build or roll back to the stable one, with a guarded background upgrade (separate process, verify-then-restart, rollback script).
