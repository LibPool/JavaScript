# @trevixal/extension-image

> 标签: drag-and-drop, editor, extension, image, rich-text, rich-text-editor, trevixal, typescript, upload, wysiwyg

## 简介

Images for the Trevixal editor: pluggable storage backends, drag-and-drop and paste upload, resize, alignment and captions.
