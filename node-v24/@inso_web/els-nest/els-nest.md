# @inso_web/els-nest

> 标签: els, error-tracking, inso, insoweb, logger, logging, nest, nest-logger, nestjs, nestjs-logger, nestjs-pino-alternative, observability, pino-nestjs-alternative, structured-logging, winston-alternative

## 简介

NestJS module and LoggerService for @inso_web/els-client. A drop-in replacement for the built-in NestJS Logger, nestjs-pino and pino-nestjs. Supports app.useLogger() and DI injection.
