# @ravian0772/jenkins-mcp

> 标签: ai-tools, ci, devops, jenkins, jenkins-ci, mcp, mcp-server, mcp-tools

## 简介

Connect AI assistants to any Jenkins CI/CD server. List jobs, trigger parameterised builds, check build status, fetch console logs, and inspect job metadata — all from natural language without leaving your editor.
