# @sloanfinger/socker-js

> 标签: JavaScript

## 简介

An easy-to-use websocket library based on Promises with built-in support for heartbeats and storing user data. Built using [ws](https://npmjs.com/package/ws) and [uuid](https://npmjs.com/package/uuid/).
