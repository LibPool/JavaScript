# @blackbelt-technology/pi-untrusted-content-guard

> 标签: pi-extension, pi-package, prompt-injection, security

## 简介

Pi extension that detects and neutralises hidden prompt-injection payloads in untrusted tool results, spotlights them, and gates sensitive tools behind confirmation after untrusted content was read.
