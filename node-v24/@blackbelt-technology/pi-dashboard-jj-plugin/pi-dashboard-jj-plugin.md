# @blackbelt-technology/pi-dashboard-jj-plugin

> 标签: JavaScript

## 简介

Jujutsu (jj) workspace plugin for pi-dashboard — adds session-card badge, action bar, sidebar workspace list, and the jj-workspace + jj-workspace-fold-back skills.
