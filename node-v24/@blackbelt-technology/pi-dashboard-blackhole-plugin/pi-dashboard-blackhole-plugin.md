# @blackbelt-technology/pi-dashboard-blackhole-plugin

> 标签: JavaScript

## 简介

Dashboard settings surface for the pi-blackhole extension — reads and writes its on-disk pi-blackhole-config.json through validated server routes, including an ordered per-worker model fallback-chain editor.
