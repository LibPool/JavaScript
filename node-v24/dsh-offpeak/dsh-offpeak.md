# dsh-offpeak

> 标签: deepseek-harness, dsh, free-run, freeze, off-peak, pause, peak, plugin, retry, session-gate, time-policy, weekend

## 简介

可配置峰谷自动会话门：config/offpeak.json 驱动 peak 时段 + 周末全天 off-peak + 单会话「畅跑」限时无视峰谷 + 高峰自动暂停/波谷自动恢复 + 按模型名的高峰拦截列表。
