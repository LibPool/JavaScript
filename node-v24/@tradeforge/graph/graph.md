# @tradeforge/graph

> 标签: algorithmic-trading, backtest, backtesting, computation-graph, cryptocurrency, dag, dataflow, directed-acyclic-graph, forex, graph, serialization, strategy, trading-bot, type-safe, typescript

## 简介

Compose tradeforge computations as a typed directed acyclic graph. Define source nodes that fetch market data and output nodes that compute derived values — then resolve the whole graph in topological order.
