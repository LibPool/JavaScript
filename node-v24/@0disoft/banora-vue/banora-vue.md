# @0disoft/banora-vue

> 标签: JavaScript

## 简介

Optional Vue 3 adapter for the Banora 0.1 SDK. Install with `npm install @0disoft/banora @0disoft/banora-vue`. Build locally with `bun run build:adapters` from the repository root.
