# @blinn-motion/canvas

> 标签: 2d, adapter, animation, blinn-motion, canvas, figma, figma-motion, motion, motiondoc, timeline

## 简介

Blinn Motion Canvas adapter — paints @blinn-motion/core's resolved render tree onto a 2D canvas. Pure JS, no DOM layout.
