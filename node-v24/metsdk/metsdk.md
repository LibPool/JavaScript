# metsdk

> 标签: a2ui, anthropic, claude, generative-ui, openapi, react, rest-api, shadcn, swagger

## 简介

Turn any REST API into a working app: users ask in plain language, MetGen designs the screen with Claude from your OpenAPI spec, and MetSDK renders it with shadcn/ui against your API.
