# @perfood/couch-auth

> 标签: Cloudant, CouchDB, Express, Facebook, Node, PouchDB, Twitter, authentication, login, oauth, passport

## 简介

Easy and secure authentication for CouchDB/Cloudant. Based on SuperLogin, updated and rewritten in Typescript.
