# @beeos-ai/acp-types

> 标签: acp, agent-client-protocol, beeos, json-rpc, types, wire-protocol

## 简介

TypeScript wire types for the BeeOS proxy ACP protocol (beeos-claw <-> web/mobile SDKs). Independent of upstream @agentclientprotocol/sdk.
