# @convex-dev/ai-budget

> 标签: ai-gateway, budget, convex, convex-component, cost, llm, rate-limit, usage

## 简介

Metered, budget-governed AI Gateway usage for Convex: cost & usage tracking, per-user/per-action/global spend/token/rate limits, request logging, re-run, and an Agent-component adapter.
