# @convex-dev/batched-replay

> 标签: collaboration, component, convex, cursors, drawing, multiplayer, presence, react, realtime, replay

## 简介

Batch fast-changing values (cursors, pen strokes, game movement) into a few writes a second and replay them smoothly, live or later.
