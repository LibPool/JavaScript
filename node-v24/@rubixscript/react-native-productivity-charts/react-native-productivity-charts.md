# @rubixscript/react-native-productivity-charts

> 标签: activity-tracker, analytics, charts, data-visualization, expo, focus-time, gifted-charts, glassmorphism, heatmap, pomodoro, productivity, progress-tracking, react, react-native, statistics

## 简介

A beautiful React Native library for productivity charts with glassmorphic design. Features heatmaps, activity charts, and customizable progress visualizations using Gifted Charts.
