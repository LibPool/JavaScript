# @extrovert.dev/mcp

> 标签: agent, email, extrovert, mailbox, mcp, model-context-protocol, otp, wait-for-email

## 简介

Extrovert MCP server - a real mailbox for your agent, in one call. Tools incl. a blocking wait_for_email with OTP/link extraction.
