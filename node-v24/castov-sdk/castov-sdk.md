# castov-sdk

> 标签: base64, castov, cron, dst, hash, jwt, nanoid, objectid, sha256, snowflake, timestamp, timezone, ulid, unix, uuid, uuidv7, zero-dependency

## 简介

Zero-dependency, zero-server developer utilities: Unix timestamps, ID detector (ObjectId, Snowflake, UUIDv7, ULID), cron explainer, IANA time zone converter with DST handling, UUID v4/v7, Base64, hashing, and JWT decoding. Works in Node.js, Deno, Bun, edg
