# @shiftbloom-studio/privacy-filter

> 标签: browser, nextjs, pii, privacy, redaction, token-classification, transformersjs, webgpu

## 简介

In-browser privacy-span detection with the openai/privacy-filter model via Transformers.js (WebGPU/WASM). No server compute; text never leaves the device.
