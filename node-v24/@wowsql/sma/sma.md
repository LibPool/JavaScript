# @wowsql/sma

> 标签: api, breaking-changes, dependabot, openapi, sdk, self-maintaining, versionly, wowsql

## 简介

Official TypeScript SDK for Versionly (Self-Maintaining APIs) — detect third-party API breaking changes and get auto-fix pull requests. Requires an active subscription and an API key.
