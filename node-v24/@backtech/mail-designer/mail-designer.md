# @backtech/mail-designer

> 标签: drag-and-drop, email, email-builder, email-editor, email-html, email-template, mcp, mjml-alternative, newsletter, outlook, react, wysiwyg

## 简介

Block-based email designer for React. Zero-dependency table-based email HTML renderer, themeable via CSS variables, with a CLI and an MCP server.
