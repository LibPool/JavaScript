# @eisgs/textarea

> 标签: JavaScript

## 简介

Ссылка на компонент `ref` пробрасывается в html textarea. `onChange` и `value` позволяют управлять содержимым. `label` и `placeholder` позволяют указать дополнительную информацию для пользователя
