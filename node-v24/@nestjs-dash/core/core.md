# @nestjs-dash/core

> 标签: JavaScript

## 简介

Panel, Resource, Table/Form/Action/Schema builders for NestJS Dash (the NestJS host module lives in @nestjs-dash/nestjs; ORM adapters in @nestjs-dash/{typeorm,mikroorm,prisma,in-memory})
