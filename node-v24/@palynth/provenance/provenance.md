# @palynth/provenance

> 标签: JavaScript

## 简介

Palynth provenance kernel: canonical JSON, SHA-256 hash chains, Merkle roots, Ed25519 writer signatures, capsule evidence references. Byte-identical with the Python kernel and the browser port.
