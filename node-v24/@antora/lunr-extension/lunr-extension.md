# @antora/lunr-extension

> 标签: antora, antora-component, antora-extension, lunr

## 简介

An Antora extension that adds offline, full-text search powered by Lunr to your Antora documentation site.

- 官网：https://antora.org
- 源码仓库：git+https://gitlab.com/antora/antora-lunr-extension.git
