# @agent-arc-status/emitter

> 标签: agent, agents, ai, arc-status, llm, observability, progress

## 简介

Batteries-included producer for the Agent Arc Status Protocol: guarantees started-first, done/blocked-on-exit, and an automatic silence backstop. Zero runtime dependencies.
