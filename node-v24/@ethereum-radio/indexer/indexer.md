# @ethereum-radio/indexer

> 标签: browser, dapp, eth_getLogs, ethereum, ethers, event-logs, evm, indexer, indexing, viem, web3

## 简介

Browser-side event-log indexing for dapps — a resumable, incremental eth_getLogs cursor with viem/ethers adapters, pluggable storage, and IPFS export/import.
