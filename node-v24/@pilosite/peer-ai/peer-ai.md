# @pilosite/peer-ai

> 标签: ai, ai-consultation, claude, claude-code, codex, codex-cli, cross-model, gemini, gemini-cli, peer-review, skills

## 简介

AI-to-AI peer consultation — install symmetric skills in Claude Code, Codex CLI, and Gemini CLI so any AI can ask any other AI for a second opinion, code review, or deep analysis.
