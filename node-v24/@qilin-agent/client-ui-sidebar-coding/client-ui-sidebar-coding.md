# @qilin-agent/client-ui-sidebar-coding

> 标签: JavaScript

## 简介

Coding workbench content body for the right Sidebar (dual workbench D5): the VSCode-like workbench — explorer/editor/terminal/git/browser tabs, per-session isolated, with lazy preview chunks. Ported from dsh-coding-sidebar 1.0.39
