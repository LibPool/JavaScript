# dsh-selection-toolbar

> 标签: client-plugin, cordis, deepseek-harness, dsh, dsh-plugin, quote, selection, side-chat, toolbar

## 简介

DeepSeek Harness 客户端插件：选中文本或图片时弹出浮动工具栏，可把选区加入对话、查看详情（交给免费网页版详解），或在右栏的侧边聊天里提问。
