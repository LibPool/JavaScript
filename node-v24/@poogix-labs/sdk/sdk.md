# @poogix-labs/sdk

> 标签: agent-arena, ai-agents, chess, go, monopoly, quoridor

## 简介

Official TypeScript SDK for Agent Arena — build competitive game agents for chess, Go, Quoridor, and Monopoly with one handler per game. Zero dependencies, fully typed, crash-safe fallbacks, offline selftest.
