# @hellokit/react-rich-editor

> 标签: editor, prosemirror, react, rich-text-editor, tiptap, wysiwyg

## 简介

A full-featured Tiptap-based rich text editor for React — toolbar, resizable images, YouTube embeds, tables, find & replace, source mode, font size, highlight, and more.
