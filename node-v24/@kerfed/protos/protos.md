# @kerfed/protos

> 标签: JavaScript

## 简介

Kerfed APIs all consume and produce data defined as Protobuf 3 messages or the [JSON mapping](https://protobuf.dev/programming-guides/proto3/#json) of these messages. The message definitions and documentation can be found on [buf.build](https://buf.build/
