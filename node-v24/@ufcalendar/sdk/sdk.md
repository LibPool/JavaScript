# @ufcalendar/sdk

> 标签: api, bkfc, fight-api, fight-data, live-stream, mcp, mcp-server, mma, mma-api, mma-mcp, pfl, rankings, sports-data, ufc, ufc-api, ufc-live, ufc-mcp, websocket

## 简介

TypeScript client for the UFCalendar Fight API: UFC, PFL, OKTAGON, BKFC and RIZIN events, fight cards, results, per-round stats, fighter careers, judges' scorecards and UFC rankings history since 2013.
