# @jinba-browserflow/agent

> 标签: agent, anthropic, authoring, browserflow, claude, playwright

## 简介

Authoring agent: RecordDriver over local Playwright + Claude. The only package allowed to depend on @anthropic-ai/sdk and playwright (both lazy-imported).
