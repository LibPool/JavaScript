# @fetcher-sh/mcp-server

> 标签: ai-tools, claude, cursor, fetcher, mcp, model-context-protocol, reddit, twitter, web-data, youtube

## 简介

Official Model Context Protocol (MCP) server for fetcher.sh — web data API for agents. Search 111 endpoints across Twitter/X, YouTube, TikTok, Instagram, Reddit, Google, and more via Claude Desktop, Cursor, or any MCP client.
