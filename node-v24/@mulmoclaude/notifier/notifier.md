# @mulmoclaude/notifier

> 标签: JavaScript

## 简介

Host-agnostic notification engine (active + history persistence, write coordinator, lifecycle validation, pub-sub + in-process fan-out) shared by MulmoClaude and MulmoTerminal. File paths, atomic writer, event sink, and logger are injected.
