# @mulmoclaude/file-change-publisher

> 标签: JavaScript

## 简介

Shared workspace file-change broadcaster for MulmoClaude and MulmoTerminal — publishFileChange(relPath) forwards a write to the host's primary channel + the plugin-scoped live-refresh channels (plugin:<scope>:file:<path>). Server-only; all host specifics
