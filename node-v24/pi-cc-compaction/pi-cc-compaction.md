# pi-cc-compaction

> 标签: claude-code, compaction, context, extension, pi-package, prompt-cache

## 简介

Claude Code's compaction for the Pi coding agent: summaries that reuse the prompt cache, Claude Code's thresholds and prompt, and idle compaction before the cache expires.
