# @onderling/attribute-charter

> 标签: JavaScript

## 简介

Requested-attributes charter — a coarse, capped, k-anon-guarded privacy mini-spec for optional background attributes on pseudonymous feedback. The first concrete instance of the personal-properties/disclosure model. Pure functions, web ≡ mobile.
