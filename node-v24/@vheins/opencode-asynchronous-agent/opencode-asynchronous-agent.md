# @vheins/opencode-asynchronous-agent

> 标签: agent, async, background, opencode, opencode-plugin, opencode-v1, opencode-v2, sidebar, statusline, subagent, tui

## 简介

OpenCode plugin (V1 + V2): runs every subagent asynchronously in the background, a TUI sidebar monitor with token stats, opt-in background-subagent control tools (children/result/cancel/send), opt-in event-driven progress reports from a child's todowrite
