# @xiazhi88/dshgo

> 标签: deepseek, deepseek-harness, dsh, dsh-plugin, lan, mobile, proxy

## 简介

把只监听 127.0.0.1 的 dsh web 暴露到局域网，并带上移动端适配 —— 一个包，手机连上就能用。
