# @xylabs/aries-datalake-xl1-adapter

> 标签: adapter, ariestools, datalake, xl1, xylabs

## 简介

Adapter that fronts the real @xyo-network/xl1-protocol-sdk RestDataLake* classes as a PayloadsClient. Kept isolated to contain XL1 SDK's transitive peer-dependency chain.
