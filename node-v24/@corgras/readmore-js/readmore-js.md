> 标签: Description, ExpandCollapse, FrontendDevelopment, JavaScriptLibrary, JavaScriptPlugin, JavaScriptTools, Javascript, MobileFriendly, OpenSource, Plugin, Plugins, Read-more, Read-more-button, ReadMoreJS, Readmore, Text, UXDesign, js

## 简介

A smooth and lightweight pure JavaScript plugin for collapsing long text blocks with "Read more" and "Close" buttons, enhancing readability and saving space, perfect for mobile devices.
