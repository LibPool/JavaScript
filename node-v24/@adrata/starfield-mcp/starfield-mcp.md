# @adrata/starfield-mcp

> 标签: adrata, agents, board, claude-code, codex, cursor, issue-tracker, kanban, mcp, model-context-protocol, starfield, windsurf

## 简介

Starfield MCP server — give Claude Code, Codex, Cursor, and other coding agents your Starfield board. Read boards and cards, create and move work, and run governed writes from the terminal.
