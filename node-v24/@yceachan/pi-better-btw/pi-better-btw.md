# @yceachan/pi-better-btw

> 标签: btw, coding-agent, overlay, pi, pi-extension, pi-package, side-chat, tui

## 简介

Fork of nicobailon/pi-side-chat (https://github.com/nicobailon/pi-side-chat) — /btw (alias /side) forks the current conversation into a non-capturing side-chat overlay: read-only lane with lane enforcement, prompt pack, shared-prefix caching, mouse select
