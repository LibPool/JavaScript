# @aperture-engine/webgpu

> 标签: aperture, ecs, game-engine, pbr, renderer, typescript, webgpu

## 简介

WebGPU rendering backend for the Aperture game engine: materials, shadows, IBL, post effects, picking, text, UI, and particles.
