# @yft-design/engine

> 标签: JavaScript

## 简介

yft-design 的 WebGL2 画布引擎：接受 fabric toObject 格式 JSON，输出 GL 画布 / 位图（任意倍率 FBO 读回）/ SVG（纯数据序列化器）
