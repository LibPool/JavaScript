# @billdaddy/channelkit

> 标签: async, buffered, channel, concurrency, go-channel, producer-consumer, select, typescript, unbuffered, zero-dependencies

## 简介

Zero-dependency TypeScript Go-style async channels: buffered/unbuffered Channel<T>, select(), close(), for-await iteration, AbortSignal cancellation. Port of Go channels / Python asyncio.Queue / C# Channel<T>.
