# @billdaddy/geohashkit

> 标签: bounding-box, geo, geohash, latitude, location, longitude, neighbors, ngeohash, proximity, spatial, typescript, zero-dependency

## 简介

Zero-dependency TypeScript geohash: encode/decode lat-lng, neighbors, bounding box, bboxes coverage, expand, distance, parent/children. Port of Python geohash2 / Go geohash.
