# @mockflow/mockflow-bridge

> 标签: ai-agent, bridge, diagram, ideaboard, mcp, mockflow

## 简介

Connects your own AI agent (Claude Code or Codex) to a live MockFlow board open in the browser. The agent is the brain, the browser tab is the hands, the bridge is the nervous system between them.
