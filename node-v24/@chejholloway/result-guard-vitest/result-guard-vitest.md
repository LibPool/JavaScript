# @chejholloway/result-guard-vitest

> 标签: matchers, neverthrow, result, testing, vitest

## 简介

Vitest matchers for asserting on neverthrow Result/ResultAsync values: toBeOk, toBeErr, toMatchOk, toMatchErr.
