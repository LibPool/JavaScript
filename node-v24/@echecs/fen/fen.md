# @echecs/fen

> 标签: chess, fen, forsyth-edwards, no-dependencies, parser, position, serializer, typescript

## 简介

Parse and stringify FEN (Forsyth–Edwards Notation) chess positions. Strict TypeScript, no-throw API.
