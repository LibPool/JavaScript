# @echecs/game

> 标签: board, checkmate, chess, chess-engine, draw-detection, game, legal-moves, minimal-dependencies, move-generation, redo, stalemate, threefold-repetition, typescript, undo

## 简介

Chess game engine with legal move generation, check/checkmate/stalemate detection, and undo/redo. Strict TypeScript.
