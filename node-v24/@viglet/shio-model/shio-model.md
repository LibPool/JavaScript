# @viglet/shio-model

> 标签: agent, ai, claude-code, cms, content-as-code, content-management-system, content-modeling, dsl, gitops, headless, headless-cms, mcp, model-context-protocol, post-types, shio, typescript, viglet

## 简介

Typed TypeScript DSL for the Shio CMS content model. Author post-types as code — `postType()`, `text()`, `comboBox()`, `relator()`, … — and compile to the canonical Shio post-type JSON that the `shio` CLI pushes. The authoring inverse of @viglet/shio-clie
