# @true402.dev/openclaw-swap-guard

> 标签: ai-agents, base, honeypot, openclaw, openclaw-plugin, rug-check, solana, swap, token-safety, trading-agent, x402

## 简介

OpenClaw plugin: before any tool call that buys a token, check it with true402 (executed buy/sell honeypot simulation) and block honeypots and rugs. Base, Ethereum, BSC, Solana. Free daily checks; pay-per-check over x402.
