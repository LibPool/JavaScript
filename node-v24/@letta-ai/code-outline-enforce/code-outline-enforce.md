# @letta-ai/code-outline-enforce

> 标签: code-outline, code-outline-dir, context-efficiency, csv, directory-outline, letta-code, letta-mod, letta-package, non-code-formats, permissions, toml, xml, yaml

## 简介

Forces agents to outline large code files before reading them. Permission overlay blocks full-file reads on large source files and auto-injects a capped structural outline. Includes code_outline_dir for directory-level structural outlines.
