# @craftos/agent-app-pi

> 标签: a2app, agent-app, agent-native, pi-package, skills

## 简介

Agent App Framework plugin for Pi (earendil-works/pi): the /agent-app launcher command, the six framework skills, and an extension that makes Pi reachable from `agent-app <dir> bridge`. Pi drives the agent-app and a2app CLIs with its own bash tool.
