# @craftos/agent-app-dsh

> 标签: JavaScript

## 简介

Agent App Framework bundle for deepseek-harness (dsh): the agent tools plus an 'Agent Apps' manager (build, embed, per-app session, lifecycle) shown in the dsh UI, driving the agent-app and a2app CLIs
