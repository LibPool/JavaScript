# @supramundane/supram

> 标签: atkinson-hyperlegible, claude-code-skill, css, design-system, grid, typography

## 简介

A design system with a leadlight grid, the Empyrean palette, and Atkinson Hyperlegible type. Plain CSS, no build step, vendored into each project.
