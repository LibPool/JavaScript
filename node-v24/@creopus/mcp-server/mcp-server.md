# @creopus/mcp-server

> 标签: claude-code, creopus, hardware-engineering, mcp, model-context-protocol

## 简介

Model Context Protocol server for Creopus.ai, run locally over stdio. Lets Claude Code, Cursor or any MCP-capable agent browse your system hierarchy, read and generate engineering artifacts, and bootstrap whole systems.
