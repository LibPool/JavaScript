# @askalf/strongroom-mcp

> 标签: agent-security, ai-agents, credentials, leases, least-privilege, mcp, model-context-protocol, own-your-stack, secrets

## 简介

An MCP server that is the strongroom control plane: its tools mint scoped, expiring, revocable leases and hand agents a lease-backed base URL — so API keys never enter agent context. Part of Own Your Stack.
