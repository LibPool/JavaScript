# @hanzo/observe-native

> 标签: analytics, autocapture, hanzo, react-native, semantic, tamagui, tauri, telemetry

## 简介

Native + desktop binding for @hanzo/observe. Instruments @hanzo/gui (Tamagui) / React Native presses and inputs, and bridges Tauri desktop, so native and desktop emit the SAME canonical Events as the web — through @hanzo/event to the ONE entry point (POST
