# @hanzo/docs-ui

> 标签: docs, gui, hanzo, next.js, react

## 简介

The user interface of @hanzo/docs — layouts, sidebar, table of contents, search, Ask AI and the MDX components — composed from @hanzo/ui and @hanzo/gui, styled by @hanzo/design.
