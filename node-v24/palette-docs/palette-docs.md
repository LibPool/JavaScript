# palette-docs

> 标签: JavaScript

## 简介

Palette Docs: lets Palette Code read HWP/HWPX/DOCX/XLSX/PPTX/PDF/ZIP and images, and create DOCX/HWPX/XLSX/PPTX (PDF and legacy formats via LibreOffice). MCP server + CLI.
