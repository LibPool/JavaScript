# @suss/cli

> 标签: api-contract, breaking-changes, contract-testing, python, ruby, static-analysis, suss, typescript

## 简介

Read TypeScript, Python and Ruby, write down what the code does on every path, from the request or message that comes in to the table or queue it touches, and check it against the clients, specs and infrastructure on the other side.
