# @suss/contract-appsync

> 标签: api-contract, api-drift, appsync, aws, cloudformation, graphql, static-analysis, suss

## 简介

Turn the AppSync API in a CloudFormation or SAM template into a suss contract and check it against the resolvers and clients on either side of it.
