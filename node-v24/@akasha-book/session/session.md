# @akasha-book/session

> 标签: JavaScript

## 简介

阿卡夏之书会话层插件 v0.4：索引 worker 化（宿主只投递 + 常驻 worker 线程串行索引）+ 自动增量索引（turn/end 去抖）+ 压缩事件行 + 每回合节奏条 + 循环观测 P0（dry 干跑——只观测不干预；核心逻辑归 akasha\session.mjs，可手动 node akasha.mjs session …）
