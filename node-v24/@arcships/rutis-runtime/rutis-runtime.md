# @arcships/rutis-runtime

> 标签: cordis, plugin, runtime, rutis

## 简介

The Node runtime of rutis: runs JavaScript and TypeScript plugins (and Cordis plugins) for a rutis host, and links Cordis applications to rutis nodes
