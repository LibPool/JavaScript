# @builder6/onlyoffice

> 标签: JavaScript

## 简介

Builder6 OnlyOffice 模块为 Builder6 平台提供 OnlyOffice 文档编辑器集成，支持在线协作编辑 Word、Excel、PowerPoint 等 Office 文档。
