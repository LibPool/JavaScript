# @fluida/core

> 标签: breakpoints, container-queries, framework-agnostic, layout, resize-observer, responsive

## 简介

Framework-agnostic engine that computes responsive layout decisions from a viewport, and container-based layout from a real measured element — no runtime dependencies, no UI framework required.
