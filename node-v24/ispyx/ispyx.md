# ispyx

> 标签: claude, computer-use, desktop-automation, keyboard, macos, mcp, model-context-protocol, mouse, screenshot, windows

## 简介

Local desktop-control MCP server: lets an AI use your keyboard, mouse and screen (windows, screenshots, clicks, typing, clipboard). stdio only, Windows and macOS.
