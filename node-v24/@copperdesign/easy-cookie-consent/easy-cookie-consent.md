# @copperdesign/easy-cookie-consent

> 标签: click-to-load, consent, cookie-consent, embed, gdpr, google-fonts, google-maps, i18n, privacy, soundcloud, vimeo, youtube

## 简介

Click-to-load consent gate for third-party embeds (YouTube, Vimeo, SoundCloud, Google Maps) plus an optional global consent modal and deferred Google Fonts / arbitrary-callback hooks. Zero dependencies, single file, multi-language.
