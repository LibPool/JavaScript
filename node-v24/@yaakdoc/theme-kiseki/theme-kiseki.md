# @yaakdoc/theme-kiseki

> 标签: shadcn, tailwindcss, theme, yaak, yaakdoc, yaakdoc-theme

## 简介

Kiseki - the default yaakdoc theme. Uses Tailwind CSS v4 + shadcn/ui, support light & dark modes.
