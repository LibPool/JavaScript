# @sveltejs/svelte-preview-install

> 标签: pnpm, preview, svelte, sveltekit

## 简介

Install Svelte/Kit packages from a GitHub PR, branch, or commit without waiting for the build in silence. Ships the `spi` (svelte preview install) CLI.

## 官网

- npm 页面：https://www.npmjs.com/package/@sveltejs/svelte-preview-install

## 历史版本号

- 当前版本：0.0.1

- 0.0.1

## 获取地址

- npm 安装：`npm install @sveltejs/svelte-preview-install`
- npm registry：https://registry.npmjs.org/@sveltejs/svelte-preview-install
- Node 要求：>=20
