# @markshawn/code-inspector-core

> 标签: inspect, inspector, plugin, vite, vscode, vue, webpack

## 简介

Enhanced code-inspector core with mode switching: Click DOM to open IDE or copy path. Press Shift+Alt+C to toggle modes.
