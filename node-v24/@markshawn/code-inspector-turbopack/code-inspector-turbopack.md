# @markshawn/code-inspector-turbopack

> 标签: copy-path, enhanced, inspect, inspector, mode-switching, nextjs, plugin, turbopack, vscode

## 简介

Enhanced code-inspector turbopack plugin with mode switching: Click DOM to open IDE or copy path. Press Shift+Alt+C to toggle modes.
