# dsh-token-report

> 标签: cli, deepseek, dsh, sqlite, statistics, token, usage

## 简介

DSH token 用量统计 CLI：读本地会话日志，输出按厂商/模型/项目/会话/时间的用量报表，支持本地页面与增量上报。支持 Node 与 Bun。
