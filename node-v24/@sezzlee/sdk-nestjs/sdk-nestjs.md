# @sezzlee/sdk-nestjs

> 标签: agents, ai, llm, mcp, model-context-protocol, nestjs, sezzlee, typescript

## 简介

Embeds an MCP layer into an existing NestJS backend: search-first tool discovery over your real endpoints, dispatched through your own guards, pipes and interceptors.
