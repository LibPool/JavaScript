# @jonathan888/canvas-agent

> 标签: JavaScript

## 简介

本地 Canvas Agent 用来连接画布网页与本机运行时。本地开发时优先连接 `http://localhost:3000`，不需要先使用线上站点。

## 官网

- npm 页面：https://www.npmjs.com/package/@jonathan888/canvas-agent

## 历史版本号

- 当前版本：0.7.0

- 0.7.0

## 获取地址

- npm 安装：`npm install @jonathan888/canvas-agent`
- npm registry：https://registry.npmjs.org/@jonathan888/canvas-agent
- Node 要求：>=18
