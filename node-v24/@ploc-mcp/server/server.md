# @ploc-mcp/server

> 标签: ai-tools, anthropic, claude, flashcards, learning, mcp, model-context-protocol, ploc, spaced-repetition

## 简介

MCP server for Ploc (plocai.com) — save conversations, fetch flashcards, and run spaced-repetition review from any MCP-compatible AI client (Claude Code, Claude Desktop, Codex, Antigravity).
