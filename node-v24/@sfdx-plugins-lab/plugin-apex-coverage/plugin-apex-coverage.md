# @sfdx-plugins-lab/plugin-apex-coverage

> 标签: sfdx-plugin

## 简介

A Salesforce CLI plugin to work with apex code coverage obtained by `sfdx force:apex:test:run -r human --codecoverage --outputdir <path>`.
