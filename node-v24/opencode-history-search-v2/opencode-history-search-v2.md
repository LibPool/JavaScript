# opencode-history-search-v2

> 标签: history, memory, opencode, opencode-plugin, plugin, search, sqlite

## 简介

OpenCode V2 plugin: search past conversation sessions by keyword, fuzzy term, multi-term AND, or file touch history. Local, read-only, no network.
