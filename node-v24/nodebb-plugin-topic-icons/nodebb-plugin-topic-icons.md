# nodebb-plugin-topic-icons

> 标签: categories, composer, covers, icons, nodebb, nodebb-plugin, plugin, thumbnails, topic, topic-icons

## 简介

Topic icons and covers for NodeBB 4: authors pick an icon from an admin-managed library in the composer; icons appear in topic lists and topic headers. Topics without a thumbnail can show the first image of their first post or a per-category default cover
