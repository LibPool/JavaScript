# @vextorium/plugin-vextorium

> 标签: ai-agents, base, crypto-data, elizaos, elizaos-plugins, funding-rate, liquidations, usdc, x402

## 简介

ElizaOS plugin: 550+ pay-per-call data services (perp funding, liquidations, market regime, prices, on-chain, DeFi) paid in USDC on Base via x402. No API keys.
