# @elham-en/drag-n-drop-engine

> 标签: drag-and-drop, gesture-handler, new-architecture, react-native, reanimated, reorder

## 简介

React Native drag-and-drop engine for reordering and moving items across lists. Built on Reanimated 4, Gesture Handler, and react-native-worklets.
