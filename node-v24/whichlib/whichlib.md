# whichlib

> 标签: claude-code, cursor, dependencies, developer-tools, github, mcp, mcp-server, model-context-protocol, recommendation

## 简介

The dependency picker for coding agents: an MCP server that recommends, compares and scores GitHub repositories, plus a daily dashboard of the most-starred new repos.
