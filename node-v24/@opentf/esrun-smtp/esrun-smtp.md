# @opentf/esrun-smtp

> 标签: email, es-runtime, esrun, mail, mime, opentf, smtp

## 简介

SMTP client for esrun: STARTTLS and implicit TLS, PLAIN/LOGIN/XOAUTH2, MIME messages, pooling.
