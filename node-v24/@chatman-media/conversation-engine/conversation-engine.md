# @chatman-media/conversation-engine

> 标签: conversation, lead-engine, multi-tenant, pipeline

## 简介

Channel-agnostic pipeline обработки inbound сообщений: contact-resolve → conversation lookup → mode routing → AI-reply / queued / human → outbound. Сердце data plane.
