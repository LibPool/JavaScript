# @bettercommunity/bmd-editor

> 标签: bettercommunity, bmd, directives, editor, markdown, react, wysiwyg

## 简介

The editor for B.MD documents: a block menu with every directive, a live preview through the real renderer, phone and desktop layouts, a link checker and an HTML export, as one React component. Separate from @bettercommunity/bmd so a site that only reads
