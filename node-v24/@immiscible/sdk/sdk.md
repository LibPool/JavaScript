Approvals, spend limits and signed receipts for AI agents: ask before a tool pays, shares data or acts, wait for a person, settle, verify. Guards for the OpenAI Agents SDK, LangChain, LangGraph and the Vercel AI SDK; x402 and wallet payments; an LLM gatew
