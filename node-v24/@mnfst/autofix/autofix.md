# @mnfst/autofix

> 标签: ai-sdk, anthropic, autofix, fetch, gemini, google, llm, openai, reliability, retry, self-healing, vercel

## 简介

Self-healing fetch() for OpenAI, Anthropic, and native Google Gemini requests. Fixes request-side failures at runtime and retries once.
