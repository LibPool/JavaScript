# @uiw/react-amap-hawk-eye-control

> 标签: amap, api-loader, bdmap, hawk-eye-control, map, react, react-amap, types, 地图, 高德, 高德地图

## 简介

鹰眼控件，用于显示缩略地图，显示于地图右下角，可以随主图的视口变化而变化，也可以配置成固定位置实现类似于南海附图的效果。
