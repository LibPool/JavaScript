# @nuvui/editor

> 标签: JavaScript

## 简介

A rich text editor for @nuvui/react, on Tiptap: a toolbar, a menu on the selection, links and a character count, with HTML as its value.

- 官网：https://nuvui.nuvraxis.com
- 源码仓库：git+https://github.com/Nuvraxis/nuvui.git
