# @adelie/use-lieflat-charts

> 标签: adelie-plugin, chart.js, charts, dataviz, echarts, html, lieflat-charts, penguin-harness, report, slides, svg

## 简介

Turn data into polished, interactive HTML charts — and, on request, into a paged HTML/PDF deck or a full-page report. Template-driven, one colour system per deliverable. Ported from the lieflat-charts skill.
