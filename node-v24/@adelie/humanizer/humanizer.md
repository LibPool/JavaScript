# @adelie/humanizer

> 标签: JavaScript

## 简介

Rewrite or edit prose in any language so it reads like edited human writing in the register of books, newspapers and encyclopedias rather than default AI output. A small drafting core — vary every pattern, build density from anchored facts in whole gramma
