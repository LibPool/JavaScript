# @zachtrice/react-lightbox

> 标签: a11y, accessible, gallery, image, lightbox, modal, react, typescript, zoom

## 简介

Tiny, accessible, dependency-free React lightbox for click-to-enlarge images: ESC + backdrop close, scroll lock, focus handling, and a portal.
