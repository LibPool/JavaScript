# @zachtrice/react-data-table

> 标签: a11y, accessible, cursor, data-table, datagrid, dynamodb, infinite-loading, pagination, react, sort, sortable, table, typescript

## 简介

Small, accessible React data table with stable blank-last sorting, client-side pagination (including All), and a cursor-paged loader that fetches every page.
