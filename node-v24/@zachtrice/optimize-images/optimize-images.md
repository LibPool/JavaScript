# @zachtrice/optimize-images

> 标签: blur, build, cli, image, next, nextjs, optimize, placeholder, sharp, webp

## 简介

Build-time image optimizer: convert PNG/JPEG to WebP and generate tiny base64 blur placeholders (great with next/image placeholder="blur"). CLI + API.
