# @awesome-cordova-plugins/zoom

> 标签: angular, cordova, ionic, mobile, native, plugin, zoom

## 简介

Zoom plugin for Cordova and Ionic. A Cordova plugin to use Zoom Video Conferencing services on Cordova applications.
