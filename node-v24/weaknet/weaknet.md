# weaknet

> 标签: JavaScript

## 简介

Android 弱网模拟器：HTTP/HTTPS 代理与网页控制台，支持多台手机、按 App 分流和 HTTPS 解密。源码中的版本号仅为占位，发布流程会按 git 标签改写。
