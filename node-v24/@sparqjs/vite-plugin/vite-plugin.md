# @sparqjs/vite-plugin

> 标签: JavaScript

## 简介

该包为 Sparq Trusted Root 提供统一的 Vite 开发和构建接入。它负责开发态 HMR、CSS 转发和生产构建描述；最终文件校验、SHA-256、`frontend/artifact.json` 与 Manifest 仍由 `sparq-tool` 负责。
