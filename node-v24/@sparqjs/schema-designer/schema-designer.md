# @sparqjs/schema-designer

> 标签: JavaScript

## 简介

`@sparqjs/schema-designer` 提供业务无关的 Schema 可视化设计器。宿主负责加载 Schema、实现设计期服务并决定保存和发布流程；Designer 只维护当前实例的草稿、画布、属性检查器和输出。
