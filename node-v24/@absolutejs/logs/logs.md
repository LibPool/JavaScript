# @absolutejs/logs

> 标签: absolutejs, logging, logs, observability, structured-logs

## 简介

Structured log primitive for the AbsoluteJS substrate. Levels, child loggers, sinks (console-JSON, console-pretty, memory, rotating file), optional secret redaction via @absolutejs/secrets, optional trace-id correlation via @absolutejs/telemetry. Metrics
