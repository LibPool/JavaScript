# @gulibs/beautify-qrcode-hooks

> 标签: JavaScript

## 简介

React Hooks，基于 [qr-code-styling](https://www.npmjs.com/package/qr-code-styling)，支持单码/批量生成、Canvas 与 SVG 双模式预览、内置背景图与文字叠加插件、PNG/JPEG/WebP/SVG 导出，以及可扩展的插件体系。
