# @neurealistic/browser-inspector

> 标签: automation, browser, cdp, e2e, inspector, mcp, model-context-protocol, playwright

## 简介

MCP server that drives a real Chromium over CDP for UI/DOM/network inspection, batched page-object steps, screenshot/video capture, and authed API calls — with an optional portable canonical profile store.
