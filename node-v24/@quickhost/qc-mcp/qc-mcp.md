# @quickhost/qc-mcp

> 标签: claude, cloud, dns, hosting, mcp, mcp-server, model-context-protocol, quickcloud, quickhost, vps

## 简介

MCP (Model Context Protocol) server for the QuickHost QuickCloud API - lets Claude Desktop, Claude Code, Cursor and other AI assistants manage your cloud with your own API key. Read-only by default.
