# @kineco-au/bacpac-importer

> 标签: azure-sql, bacpac, bun, converter, dacpac, database, mariadb, migration, mssql, mysql, postgres, postgresql, sql-server, sqlite

## 简介

Convert a SQL Server .bacpac to SQLite, Postgres or MySQL. Reads the export directly, tables and data, with no SQL Server, SqlPackage or .NET.
