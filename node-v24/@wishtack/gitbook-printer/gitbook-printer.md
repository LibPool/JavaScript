# @wishtack/gitbook-printer

> 标签: JavaScript

## 简介

This is a basic tool that will read your **New Gitbook**'s `SUMMARY.md`, crawl your course using Chrome *(puppeteer)* and produce a PDF file with all the content in `out/gitbook.pdf`.
