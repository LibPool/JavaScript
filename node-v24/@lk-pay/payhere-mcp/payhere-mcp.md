# @lk-pay/payhere-mcp

> 标签: lk-pay, mcp, model-context-protocol, payhere, payments, sri-lanka

## 简介

Model Context Protocol server for PayHere — Sri Lanka's payment gateway. Lets developers retrieve payments, issue refunds, generate checkout payloads, and compute PayHere signatures from any MCP-aware client (Claude Code, etc).
