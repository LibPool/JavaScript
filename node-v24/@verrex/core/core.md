# @verrex/core

> 标签: effect, framework, jsx, reactivity, ui, verrex, vx

## 简介

An Effect-native UI framework where Effect's <A, E, R> channels propagate from every leaf of the view tree to the root — a forgotten Layer becomes a compile-time error that names the missing service.
