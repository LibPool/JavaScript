# @bookitive/widget-js

> 标签: bookitive, embed, seatmap, tickets, widget

## 简介

Loader + TypeScript types for the embeddable Bookitive seat-map widget. Injects the CDN runtime (like @stripe/stripe-js) and returns a typed mount().
