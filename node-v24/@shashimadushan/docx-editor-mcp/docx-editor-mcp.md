# @shashimadushan/docx-editor-mcp

> 标签: agent, claude, docx, mcp, model-context-protocol

## 简介

MCP server exposing @shashimadushan/docx-editor-agent's tool registry over stdio, so Claude Desktop/Claude Code/any MCP client can read and edit .docx files directly.
