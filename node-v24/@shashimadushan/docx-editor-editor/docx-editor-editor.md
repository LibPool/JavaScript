# @shashimadushan/docx-editor-editor

> 标签: document, docx, editor, paged, prosemirror, rich-text, tiptap, word, word-processor

## 简介

A clean, extensible, framework-agnostic DOCX editor built on TipTap. Load .docx, edit, save .docx — and add your own extensions. Word/Google-Docs-style paged layout.
