# vite-plugin-mkcert-containerized

> 标签: container, devcontainer, docker, https, mkcert, ssl, vite, vite-plugin

## 简介

Drop-in replacement for vite-plugin-mkcert that eases trusting mkcert's CA on the host machine when running Vite in a container.
