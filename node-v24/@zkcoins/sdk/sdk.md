# @zkcoins/sdk

> 标签: bip-32, bip-340, bip-39, bitcoin, schnorr, sdk, wallet, zkcoins

## 简介

Pure-TypeScript wallet SDK for zkCoins — BIP-39/32 derivation, Schnorr signing, typed REST client, high-level account adapter.
