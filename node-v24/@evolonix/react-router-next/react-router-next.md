# @evolonix/react-router-next

> 标签: app-router, filesystem-routing, nextjs, react, react-router, router, typegen, vite, vite-plugin

## 简介

Next.js-style filesystem routing for React Router 7, with a Vite plugin that generates per-route typed params.
