# @canveo/mcp

> 标签: canveo, compliance, contracts, mcp, model-context-protocol, review

## 简介

Canveo Model Context Protocol server for contract review, creation, sending, and signing. Works with any MCP client (Cursor, Claude Desktop, VS Code, and others).
