# @aryrabelo/planqueue

> 标签: coding-agent, extension, notes, oh-my-pi, omp, pi, planqueue, plugin, prompt-queue

## 简介

PlanQueue: an OMP harness extension that turns a session-notes panel into a FIFO prompt queue for coding agents, persisted per repo/branch/session.
