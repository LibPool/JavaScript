# @nestm/tenant

> 标签: esm, multi-tenant, nestjs, nestjs-12, nestm, row-level-security, sequelize, typeorm

## 简介

Fail-closed multi-tenancy for NestJS 12 with typed request context, ORM adapters, Redis caching, and PostgreSQL RLS helpers.
