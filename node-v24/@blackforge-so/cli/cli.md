# @blackforge-so/cli

> 标签: blackforge, cli, crypto, market-data, microstructure, orderbook

## 简介

Terminal client for the BlackForge crypto market-data API — catalog, symbols, latest bucket, time series and usage, as table, JSON or CSV.
