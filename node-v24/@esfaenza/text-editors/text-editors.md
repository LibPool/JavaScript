# @esfaenza/text-editors

> 标签: JavaScript

## 简介

Libreria che rende disponibile `<es-editor>`, un editor rich-text basato su [tiptap](https://tiptap.dev) che produce il proprio valore in HTML, Markdown o testo semplice.
