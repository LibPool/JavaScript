# jevtester

> 标签: agent, browser, e2e, exploratory-testing, jev, playwright, testing

## 简介

Unofficial exploratory browser tester: it maps your app, a small decision model (Jev) picks the clicks, your spec supplies the typing, and code decides pass/fail.
