> 标签: ar, augmented-reality, computer-vision, face, face-analysis, face-shape, glasses, landmark, mediapipe, on-device, privacy, sdk, try-on, typescript, virtual-tryon, visutry

## 简介

Platform-agnostic core for VisuTry SDK: types, coordinate transforms, face semantic mapping, face metrics, face shape scoring, glasses pose solver, pose smoothing, quality gate.
