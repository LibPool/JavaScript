# @castpdf/sdk

> 标签: castpdf, e-invoice, factur-x, html-to-pdf, pdf, pdf-generation, sdk, xrechnung, zugferd

## 简介

Official Node.js and TypeScript client for the CastPDF API: PDFs from templates or HTML, EU e-invoices, batches and webhooks.
