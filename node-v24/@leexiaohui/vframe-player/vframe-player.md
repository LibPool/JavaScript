# @leexiaohui/vframe-player

> 标签: JavaScript

## 简介

基于 Canvas 的轻量级序列帧图片播放器。以最小 API 提供帧率控制、循环/往返播放、播放区间、预加载与事件钩子，适合产品动效、分镜浏览、3D/AR 截帧预览等场景。
