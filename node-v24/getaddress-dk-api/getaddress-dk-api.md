# getaddress-dk-api

> 标签: address, address-lookup, adgangsadresser, adresse, adresser, autocomplete, danish, danmark, dar, dawa, denmark, getaddress, postnummer

## 简介

TypeScript client for getaddress.dk, the DAWA-compatible Danish address API: autocomplete, adresser, adgangsadresser, reverse geocoding, vejnavne, postnumre, datavask, companies (CVR) and usage. DAWA's paths, parameters, field names and ids.
