# @develia/vuetify

> 标签: JavaScript

## 简介

Componentes y utilidades reutilizables para aplicaciones Vue 3 con Vuetify 3. El paquete no conoce modelos ni endpoints de dominio: los datos, las confirmaciones específicas y los efectos pertenecen al consumidor. El único transporte integrado es el ciclo
