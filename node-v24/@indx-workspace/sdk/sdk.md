# @indx-workspace/sdk

> 标签: JavaScript

## 简介

The typed, isomorphic TypeScript client for the Agent Workspace API, with agents and surfaces as code at /define, the project file and starter project at /project, and a test double and contract-valid fixtures at /testing.
