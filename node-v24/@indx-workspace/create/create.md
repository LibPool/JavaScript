# @indx-workspace/create

> 标签: JavaScript

## 简介

npm create @indx-workspace <directory>: generate an Agent Workspace project (a v2 aw dev project by default, or a deployment project with --cloud) with @indx-workspace/cli's create-agent-workspace.
