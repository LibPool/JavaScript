# @dabaihk/dimension-ui

> 标签: ai, cards, dashboard, data-visualization, design-system, metrics, ui, zero-dependency

## 简介

A rules-first card system for dense, high-stakes dashboards. One card, one question; six colours with one meaning each; five marks; four variants. Zero dependencies.
