# @polypad/mcp

> 标签: 3d, cad, claude, mcp, model-context-protocol, parametric

## 简介

MCP server that lets Claude, Cursor or another AI assistant build and inspect 3D models in your open Polypad tab (polypad.ink). Runs locally, nothing is uploaded.

## 官网

- 官网：https://polypad.ink
- npm 页面：https://www.npmjs.com/package/@polypad/mcp
