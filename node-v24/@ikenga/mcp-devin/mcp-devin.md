# @ikenga/mcp-devin

> 标签: ai, coding-agent, cognition, desktop, devin, ikenga, mcp, model-context-protocol

## 简介

Model Context Protocol (MCP) server that exposes the user's local Devin CLI to any Ikenga engine — single-turn runs, session listing/resume, and background task delegation.
