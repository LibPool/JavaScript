# @niche-works/web-font-observer

> 标签: browser, font, web-font

## 简介

`@niche-works/web-font-observer` is a niche library for checking whether web fonts are available.\ It is built on the standard CSS Font Loading API and provides functionality equivalent to [fontfaceobserver](https://github.com/bramstein/fontfaceobserver)
