# @aegisrunner/runner

> 标签: aegisrunner, localhost, playwright, scanner, self-hosted, testing

## 简介

The AegisRunner self-hosted local executor — runs `aegis scan --local` scans AND `aegis run --local` test suites on your machine (browser stays local, brain + storage in the cloud). No Docker required.
