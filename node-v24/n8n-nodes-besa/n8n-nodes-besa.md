# n8n-nodes-besa

> 标签: admission, ai-agents, besa, ed25519, n8n-community-node-package, receipt, signing, trust

## 简介

Verify signed BESA manifests, gate tool calls through BESA admission policy, and issue signed BESA execution receipts from an n8n workflow.
