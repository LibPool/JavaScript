# @nemu-ai/pdf

> 标签: charts, declarative, document, fonts, latex, mathjax, pdf, pdf-generation, pdfkit, theming, typescript, variable-fonts

## 简介

PDF generation for Node and Bun with a declarative document API and a low level element API, bundled variable fonts with real weights, LaTeX math, native charts, and theming.
