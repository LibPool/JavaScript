# @onrails/docgen

> 标签: api-reference, ast, docgen, docs, documentation, fumadocs, jsdoc, mdx, tsdoc, typescript

## 简介

Generate MDX API-reference pages from TypeScript source + JSDoc/TSDoc, and compile-check @example blocks against the real API.
