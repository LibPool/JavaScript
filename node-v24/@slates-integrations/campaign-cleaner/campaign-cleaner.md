# @slates-integrations/campaign-cleaner

> 标签: JavaScript

## 简介

Analyze, clean, and optimize HTML email campaigns to improve deliverability and avoid spam filters. Submit campaign HTML for automated processing that inlines CSS, sanitizes HTML, replaces spam-triggering characters and font colors, detects broken and bla
