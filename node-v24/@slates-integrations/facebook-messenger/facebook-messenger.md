# @slates-integrations/facebook-messenger

> 标签: JavaScript

## 简介

Send and receive messages between Facebook Pages and users through Messenger. List conversations and read recent messages. Create rich message templates including carousels, buttons, receipts, and media. Upload reusable media attachments for later sends.
