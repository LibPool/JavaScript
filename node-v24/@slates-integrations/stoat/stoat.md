# @slates-integrations/stoat

> 标签: JavaScript

## 简介

Read, send, edit, search, pin, and delete messages in Stoat, formerly Revolt. Manage servers, channels, members, bans, roles, permissions, invites, custom emoji, and channel webhooks. Discover direct message channels with a user session.
