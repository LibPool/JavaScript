# @slates-integrations/dataforseo

> 标签: JavaScript

## 简介

Retrieve practical SEO, SEM, ecommerce, business, app, content, and AI optimization data from DataForSEO API v3. This integration supports Google, Bing, Yahoo, and YouTube organic SERP live search; Google Ads keyword metrics; DataForSEO Labs keyword/domai
