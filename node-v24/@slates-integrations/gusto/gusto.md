# @slates-integrations/gusto

> 标签: JavaScript

## 简介

Connect a Gusto company through production or demo OAuth. Call `get_current_context` to discover the exact authorized company UUID, token owner and granted API scopes; each OAuth grant targets one company. Gusto assigns scopes during application approval.
