# @webcodereview/cli

> 标签: chatgpt, claude, cli, code-review, deepseek, gemini, mcp, model-context-protocol

## 简介

Send prompts to ChatGPT, Gemini, Claude, DeepSeek and Grok through your own logged-in Chrome, as a CLI and an MCP server (needs the WebCodeReview Chrome extension)
