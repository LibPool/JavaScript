# @millicast/trino-iceberg-mcp

> 标签: apache-iceberg, iceberg, keycloak, mcp, model-context-protocol, read-only, sql, trino

## 简介

Read-only Model Context Protocol (MCP) server for an Apache Iceberg data lake served by Trino, authenticating with Keycloak client credentials. Runnable via npx or Docker.
