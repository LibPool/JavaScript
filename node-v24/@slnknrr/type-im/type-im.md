> 标签: arrow-function, async-function, bitmask, brand-check, cross-realm, duck-typing, generator, internal-slot, is-array, is-map, is-plain-object, is-promise, iterator, toStringTag, type-check, typed-array, typeof, zero-allocation

## 简介

The honest typeof: type predicates that return the evidence, not a verdict. Each is* asks every witness it has — constructor name, toStringTag, duck protocol, internal-slot brand, prototype chain, same-realm constructor — and returns their answers as bits
