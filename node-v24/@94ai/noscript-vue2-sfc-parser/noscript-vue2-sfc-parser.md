# @94ai/noscript-vue2-sfc-parser

> 标签: browser runtime parser, parse typescript, parse vue2 setup script, sfc parser, vue2

## 简介

Load vue2 SFC component with inline `<noscript>` tag in browser. supports `setup script` and `ts`
