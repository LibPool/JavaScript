# dev-view

> 标签: audit, best-practices, cli, developer-tools, dotenv, git, github, gitignore, hygiene, nodejs, project-health, python, repository, secrets

## 简介

A command-line tool that checks your project for problems like committed secrets, tracked build folders and missing licenses, then explains why they matter and how to fix them. Works on local folders and public GitHub repositories.
