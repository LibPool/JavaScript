# @stealthscale/plugin-theming

> 标签: design-system, plugins, react, theme, theming

## 简介

Renders the theming pages: what a theme is, every token, style and condition it fills with the values read from the stylesheet in both color modes, the gate's pairs measured live, and how a theme is written.
