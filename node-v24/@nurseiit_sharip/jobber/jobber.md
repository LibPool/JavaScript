# @nurseiit_sharip/jobber

> 标签: claude-code, cli, job-search, mcp, telegram, vacancies

## 简介

Локальный персональный ассистент поиска работы по Telegram (provider-agnostic). CLI управления установкой, версиями и расписанием; интеллект — в Claude Code через MCP.
