# @stijnus/dsh-prompt-optimizer

> 标签: composer, deepseek-harness, dsh, dsh-plugin, prompt, prompt-engineering, prompt-optimizer

## 简介

Optimize the DeepSeek Harness composer draft into a structured prompt through the session model, reusing the Prompt Optimizer rewrite engine. Choose plain, sections, or role-task-goal output.
