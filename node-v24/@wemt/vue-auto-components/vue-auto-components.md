# @wemt/vue-auto-components

> 标签: plugin, vite, vue

## 简介

一个专为 Vue 3 + Vite 项目设计的组件自动导入插件，基于 `unplugin-vue-components` 封装，提供更简便的配置和更强大的自定义规则支持。
