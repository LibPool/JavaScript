# @wemt/html-to-uniapp

> 标签: converter, html, uniapp, vue

## 简介

一个用于将 HTML 页面转换为 UniApp Vue 页面自动化工具，支持自动处理兼容性问题、生成页面配置和索引页面。

## 官网

- npm 页面：https://www.npmjs.com/package/@wemt/html-to-uniapp

- 1.0.0

- npm registry：https://registry.npmjs.org/@wemt/html-to-uniapp
