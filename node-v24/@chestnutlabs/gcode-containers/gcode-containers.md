# @chestnutlabs/gcode-containers

> 标签: 3d-printing, 3mf, chestnutlabs, cnc, container, gcode, gcode-3mf, toolpath, zip

## 简介

Safe, bounded, in-memory container extraction for sliced G-code (.gcode.3mf) — DD-005 §4.4/§7. Never writes files, never fetches, zero dependencies.
