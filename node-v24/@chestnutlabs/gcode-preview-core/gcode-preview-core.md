# @chestnutlabs/gcode-preview-core

> 标签: 3d-printing, chestnutlabs, cnc, controller, framework-neutral, gcode, preview, toolpath, viewer

## 简介

Framework-neutral preview controller for the Chestnut Labs G-code viewer (DD-007 §4.6): the shared engine glue, state model, and TypeScript contracts beneath the Vue/React/Svelte adapters.
