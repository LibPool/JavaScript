# @bentway/core

> 标签: agent, bentway, kernel, llm, transcript, turn-loop

## 简介

Runtime-agnostic execution kernel for LLM agents: turn loop, neutral transcript, tool-call dispatch, and provider-agnostic stop/retry semantics
