# @wisp-ui/react

> 标签: accessibility, component-library, css-modules, dark-mode, design-system, design-tokens, dynamic-color, expressive, react, react-components, shape-morphing, spring-animation, theming, ui, ui-kit

## 简介

Expressive React components with plain CSS: native elements, per-component styles, dark mode and dynamic colour. Zero-runtime, tree-shakeable, no shadow DOM.
