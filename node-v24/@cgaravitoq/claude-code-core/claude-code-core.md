# @cgaravitoq/claude-code-core

> 标签: anthropic, claude, claude-code, coding-agent, llm, oauth

## 简介

Framework-agnostic core for using Claude Code's OAuth subscription as an Anthropic provider: credential read/refresh, signed billing header, beta computation, and request transforms. No Pi, no LangChain — just the native Claude Code stack.
