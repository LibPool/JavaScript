# @james.valencia/mcp-reportia

> 标签: ai, mcp, model-context-protocol, npx, reportia, stdio, typescript

## 简介

Servidor MCP (Model Context Protocol) independiente que envuelve la API HTTP real de Reportia. Pensado para ser consumido por otra aplicación de IA vía npx/stdio.
