# @office-viewer/parser

> 标签: ast, attachments, browser, document parser, docx, excel, formatting, libreoffice, metadata, ocr, odp, ods, odt, office, openoffice, parser, pdf, pdf.js, powerpoint, pptx, presentation, rtf, slides, spreadsheet, structured-data, tesseract, text extraction, typescript, word, xlsx

## 简介

A robust, strictly-typed Node.js and Browser library for parsing office files (.docx, .pptx, .xlsx, .xls, .csv, .odt, .odp, .ods, .pdf, .rtf) into structured AST with rich metadata, formatting, and attachment support.
