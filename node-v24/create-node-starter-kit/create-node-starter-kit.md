# create-node-starter-kit

> 标签: cli, create, generator, initializer, nodejs, npx, scaffold, starter-kit, template

## 简介

Scaffold highly customizable Node.js applications and packages by composing compatible features: project type, language, module system, framework, testing, linting, databases and more.
