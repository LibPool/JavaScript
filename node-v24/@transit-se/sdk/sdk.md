# @transit-se/sdk

> 标签: gtfs, gtfs-rt, kollektivtrafik, lokaltrafik, public-transport, sl, stockholm, sverige, sweden, trafiklab, transit

## 简介

TypeScript SDK for Swedish public transit APIs (Trafiklab, GTFS-RT). Departures, stop lookups, service alerts, vehicle positions, and more.
