# @helpai/elements

> 标签: ai, chat, embed, help-ai, shadow-dom, streaming, widget

## 简介

Help AI embeddable AI agent elements for the browser. Six chat layouts (floating / inline / modal / drawer / page / standalone) plus an iframe wrapper. Shadow-DOM-isolated, streaming SSE.
