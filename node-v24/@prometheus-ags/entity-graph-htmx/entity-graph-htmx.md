# @prometheus-ags/entity-graph-htmx

> 标签: entity-graph, html-fragments, htmx, idiomorph, normalized-cache, server-sent-events, sse, state-management

## 简介

Node.js SSE fragment server for HTMX — streams HTML entity fragments over Server-Sent Events with idiomorph/morph swaps, backed by the Prometheus entity graph.
