# @pubinfo-pr/module-crypto

> 标签: JavaScript

## 简介

Pubinfo 的请求加密模块。它在应用启动时向后端拉取加密开关与公钥配置，并通过 Pubinfo 的 HTTP hooks 在请求发送前加密、响应返回后解密。
