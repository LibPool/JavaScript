# @lakeql/adapters

> 标签: adapters, clickhouse, hive, iceberg, lakeql, parquet, s3, trino

## 简介

Storage adapters for LakeQL — provides high-level table management for different backends (Trino/Hive/S3, Iceberg, ClickHouse, etc.)
