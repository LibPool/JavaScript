## 简介

DSH Token 用量 / 花费 / 余额面板（社区插件，非官方；即 dsh-token-meter-panel 的短名孪生包，二者代码相同，可同时安装）：兼容 DSH 0.2.x，零外部依赖（无需 zstd/zstdcat/Homebrew）· 账户余额走 DeepSeek 账号登录或 API Key · 峰谷分档计价 · 成本构成 · 按会话明细 · 预算告警。Community token usage, cost & balance panel for DeepSeek Harness.
