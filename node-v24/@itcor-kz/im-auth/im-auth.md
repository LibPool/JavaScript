# @itcor-kz/im-auth

> 标签: JavaScript

## 简介

Модуль авторизации и регистрации пользователей для приложений на Vue 3 + Vuetify 3.   Поставляется как набор готовых страниц и стора, которые можно встроить в хост‑приложение.
