# @alphacoder-v0/pi-loops

> 标签: coding-agent, cron, hooks, inbox, loops, mcp, pi, pi-extension, pi-package, triggers

## 简介

An automation layer for pi: cron + stateful loops with a triage inbox, maker/checker verification, dynamic triggers, MCP notifications and tools, lifecycle hooks, session archives. A non-invasive pi extension.
