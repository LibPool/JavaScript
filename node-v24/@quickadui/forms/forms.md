# @quickadui/forms

> 标签: forms, quickadui, react, react-hook-form, zod

## 简介

Form field components (Input, Textarea, Select, Checkbox, Switch, RadioGroup, Label) plus a React Hook Form + Zod bindings layer (Form, FormField, FormItem, FormLabel, FormControl, FormDescription, FormMessage).
