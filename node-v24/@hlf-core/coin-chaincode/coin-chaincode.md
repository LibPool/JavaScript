# @hlf-core/coin-chaincode

> 标签: blockchain, chaincode, coin, digital-asset, fabric, hyperledger, hyperledger-fabric, smart-contracts, token, typescript

## 简介

TypeScript library for token management on the Hyperledger Fabric chaincode side: accounts, emission, transfers, hold and burning with event dispatching
