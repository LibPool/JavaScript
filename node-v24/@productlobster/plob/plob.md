# @productlobster/plob

> 标签: agent, cli, mcp, product-management, productlobster

## 简介

ProductLobster command-line tool — run PM analyses, manage workspaces, read run output, and upload documents from your terminal. A thin MCP client for the ProductLobster agentic surface.
