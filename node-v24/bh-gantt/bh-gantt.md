# bh-gantt

> 标签: gantt, gantt-chart, scheduler, timeline, virtual-scroll, vue, vue3

## 简介

High-performance virtualized Gantt chart for Vue 3: tree rows, dependency links, drag scheduling and optional portfolio view.
