# @milton-group/tailnet-mcp-launch

> 标签: JavaScript

## 简介

DNS-aware launcher for mcp-remote against Milton tailnet MCP servers. Waits for MagicDNS to register after login/wake, then spawns a pinned mcp-remote so Claude Desktop bridges don't die on a startup ENOTFOUND.
