# @breezil/hypixel-parsers

> 标签: breezil, hypixel, minecraft, parser, types, typescript

## 简介

Rich, typed parsers for Hypixel API JSON - players, guilds, SkyBlock, and every game mode turned into readonly fully-typed objects. Pure, no network.
