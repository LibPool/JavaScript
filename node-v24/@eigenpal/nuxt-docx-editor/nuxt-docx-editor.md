# @eigenpal/nuxt-docx-editor

> 标签: document, docx, editor, nuxt, nuxt-module, ssr, word

## 简介

Nuxt 3 & 4 module for the @eigenpal/docx-editor WYSIWYG DOCX editor — auto-imports an SSR-safe <DocxEditor> component.
