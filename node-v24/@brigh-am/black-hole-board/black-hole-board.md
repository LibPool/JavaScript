# @brigh-am/black-hole-board

> 标签: animation, black-hole, board-game, react, svg, visualization

## 简介

Reusable Black Hole board: pure game model + SVG illustration components (static stills, rotation/flip transposition animations, scoring visualization, themeable skins).
