# @vanmarkic/agent-verifier

> 标签: agent, ai-code-review, angular, ci, code-quality, coding-agent, coverage, guardrails, llm, process-supervisor, static-analysis, test-integrity, typescript, verification, vitest, watchdog

## 简介

Deterministic verification layer for AI-generated code changes. Detects weakened tests and lowered thresholds in a diff, supervises build and test processes with hard deadlines and process-group kill, and emits a structured PASS/FAIL report for coding age
