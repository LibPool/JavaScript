# @better-files/svelte

> 标签: better-iam, data-room, stores, svelte, sveltekit, typescript

## 简介

Svelte bindings for Better Files: typed stores for rooms, folders, capabilities and uploads (Svelte 4 and 5, no runtime dependency), plus SvelteKit hooks
