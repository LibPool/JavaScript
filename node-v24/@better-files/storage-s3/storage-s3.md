# @better-files/storage-s3

> 标签: better-iam, data-room, minio, r2, s3, storage, typescript

## 简介

S3-compatible storage adapter for Better Files (AWS S3, Cloudflare R2, MinIO, B2, Wasabi) using SigV4 over fetch, no AWS SDK.
