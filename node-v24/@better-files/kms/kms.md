# @better-files/kms

> 标签: aws-kms, better-iam, byok, data-room, encryption, kms, typescript, vault

## 简介

Bring-your-own-key providers for Better Files: AWS KMS, Google Cloud KMS, Azure Key Vault and HashiCorp Vault Transit over fetch (no SDKs), plus key migration between providers.
