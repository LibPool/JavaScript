# @better-files/adapter-drizzle

> 标签: better-iam, data-room, drizzle, orm, typescript

## 简介

Drizzle adapter for Better Files: run on the host's drizzle db (node-postgres, postgres.js, PGlite, better-sqlite3, libSQL), with a generated schema for drizzle-kit
