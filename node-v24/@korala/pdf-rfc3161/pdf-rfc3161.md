# @korala/pdf-rfc3161

> 标签: cloudflare-workers, digital-signature, edge, ltv, pades, pdf, rfc3161, timestamp, tsa

## 简介

[Korala fork of pdf-rfc3161 @ 3ff05c8] A pure JS library to add RFC 3161 trusted timestamps to PDFs. Edge-ready, works in Node.js, Cloudflare Workers, and Browsers without native dependencies.
