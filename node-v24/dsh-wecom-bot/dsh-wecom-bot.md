# dsh-wecom-bot

> 标签: cordis, deepseek-harness, dsh, dsh-plugin, plugin, wecom, 企业微信

## 简介

Bridge a WeCom (企业微信) smart bot to DeepSeek Harness: user groups own a Workspace, a model and an agent preset, members get their own Session, refused senders are told to ask an operator and wait in an authorization list on the plugin page, administrators
