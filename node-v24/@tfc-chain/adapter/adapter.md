# @tfc-chain/adapter

> 标签: JavaScript

## 简介

`@tfc-chain/adapter`包的目的为：为链下程序调用智能合约提供便利。 `@tfc-chain/adapter`包中封装了`ethers.js`API，并提供了调用`@tfc-chain/core`合约的简易API，而无需了解以太坊API。
