# @supbuddy/caddy-linux-amd64

> 标签: JavaScript

## 简介

Supbuddy's Caddy build (with the caddy-l4 layer4 module) for Linux x64. Installed automatically by the `supbuddy` CLI as a platform-specific optionalDependency.
