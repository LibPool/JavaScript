# @gatilab/emdash-core-forms

> 标签: astro, contact-form, emdash, emdash-plugin, forms, submissions, turnstile, webhook

## 简介

Core Forms for EmDash: HTML-first forms with AJAX and no-JS submission, spam protection, email and webhook actions, and a submissions inbox. Port of the Core Forms WordPress plugin.
