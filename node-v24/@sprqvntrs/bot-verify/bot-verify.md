# @sprqvntrs/bot-verify

> 标签: JavaScript

## 简介

Verify search-engine crawlers (Googlebot et al.) against their published IP ranges + reverse-DNS, and detect spoofed bots. Framework-agnostic core plus a React Router 7 middleware adapter.
