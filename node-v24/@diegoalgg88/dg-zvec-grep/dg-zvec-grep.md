# @diegoalgg88/dg-zvec-grep

> 标签: JavaScript

## 简介

Agent-friendly hybrid workspace search across code and non-code content. Fork of zvec-grep with a parametrized OpenAI-compatible remote embedding backend (adds nvidia/nemotron-3-embed-1b and the multimodal nvidia/llama-nemotron-embed-vl-1b-v2).
