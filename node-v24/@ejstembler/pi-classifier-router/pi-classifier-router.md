# @ejstembler/pi-classifier-router

> 标签: jev, laya, omp-extension, pi-extension, pi-package, router

## 简介

Classifier-driven model router for pi and Oh My Pi (omp): routes each prompt to a model using Jev (TypeSafe) or Laya typed decisions, with circuit breaking and fallback chains
