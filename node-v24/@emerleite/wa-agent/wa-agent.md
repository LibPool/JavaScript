# @emerleite/wa-agent

> 标签: agent, chatbot, cloudflare-workers, d1, hono, llm, meta, whatsapp

## 简介

Opinionated WhatsApp Cloud API agent framework for Cloudflare Workers — Drizzle-backed stores, D1-coalesced webhook queue, AI assistant integration with pluggable reply enrichment, opt-in CRM, account-link redemption, broadcast cron, sequential drip plans
