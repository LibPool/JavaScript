# @hela/preset-workspaces

> 标签: JavaScript

## 简介

A preset of functions and commands for monorepo management. Powerful, simple and fast software development and management system. Support for monorepos and non-monorepo setups. Supports multiple fixed and/or multiple independent-versioned projects in one
