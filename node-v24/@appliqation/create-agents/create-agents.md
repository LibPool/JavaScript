# @appliqation/create-agents

> 标签: JavaScript

## 简介

Interactive installer that scaffolds a local folder of Appliqation standalone agents (autotest, autopilot, scriptgen, defect-fix, heal-selector, visual-regression, explorer, pr-raise, dashboard) with a working .env and ready-to-run CLI/CI commands.
