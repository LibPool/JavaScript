# @tcd-devkit/eslint-config-a11y

> 标签: a11y, accessibility, config, eslint, eslint-config, eslintconfig, flat-config, jsx, lint, react, tcd-devkit

## 简介

ESLint Flat Configuration for JSX A11y. This package provides accessibility (a11y) rules for JSX using `eslint-plugin-jsx-a11y`, helping to create more accessible web applications.
