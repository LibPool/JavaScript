# @teamshift/permission-planner

> 标签: ai-agents, gmail-api, hubspot, human-in-the-loop, least-privilege, microsoft-graph, oauth, oauth-scopes, permissions, quickbooks, shopify-access-scopes, slack-scopes, stripe-restricted-keys

## 简介

Turn a list of intended AI-agent actions into the minimum OAuth scopes and API permissions (Google, Microsoft Graph, Slack, HubSpot, QuickBooks, Stripe, Shopify), a risk tier and a recommended human-approval policy.
