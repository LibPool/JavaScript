# @teamshift/webhook-inspect

> 标签: ai-agents, debugging, github-webhook, hmac, replay, shopify-webhook, signature-verification, slack-signing-secret, stripe-webhook, twilio-signature, webcrypto, webhook, webhooks

## 简介

Verify, explain and debug webhook signatures (Stripe, GitHub, Shopify, Slack, Twilio, generic HMAC) with a browser-safe WebCrypto core, plus a local capture server and replay CLI.
