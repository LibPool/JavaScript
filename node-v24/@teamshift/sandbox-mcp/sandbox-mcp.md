# @teamshift/sandbox-mcp

> 标签: agent evaluation, ai agents, llm evaluation, mcp, mcp server, mock crm, model context protocol, sandbox, synthetic data, testing

## 简介

Mock small-business MCP servers (CRM, inbox, calendar, invoicing, phone) backed by a realistic fictional company, for testing AI agents end-to-end without real accounts.
