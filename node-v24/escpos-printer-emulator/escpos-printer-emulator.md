# escpos-printer-emulator

> 标签: 9100, emulator, esc/pos, escpos, jetdirect, pos, receipt, thermal printer

## 简介

Network ESC/POS receipt printer emulator: listens on raw TCP (port 9100) like a real printer and renders exactly what it would print in a live web viewer.
