# @archmax-ai/harness

> 标签: agent, agents, ai, deepagents, governance, guardrails, langchain, llm, state-machine, typescript, workflow

## 简介

Agents can't reliably follow a process. archmax harness makes them: a governed layer over LangChain Deep Agents that enforces a declarative workflow state machine on every step.
