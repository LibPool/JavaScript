# @digitalvibes/mood-board

> 标签: agents, ai, canvas, design, dibe, figjam, mood-board, moodboard, style-reference

## 简介

A local, FigJam-like mood board canvas that stores its data in .dibe/ so AI coding agents can read it as a style reference.
