# @angelyeye/dsh-cost-tracker

> 标签: cordis, cost-tracking, deepseek-harness, dsh, dsh-plugin, llm, token-usage

## 简介

DeepSeek Harness (DSH) plugin: LLM token usage & cost tracking with a settings dashboard, agent tools, HTTP API, persistent storage, multi-device cloud sync, session-log history import, official price sync and a multi-vendor price catalog.
