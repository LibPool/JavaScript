# @artinstack/migrator

> 标签: content, grapesjs, migration, normalizer, smugmug, squarespace, wordpress, wxr

## 简介

MIT OSS migration framework — WordPress, SmugMug, Squarespace, Wix to portable DTOs. CLI + MigrationSink for any host; also powers import on artinstack.com
