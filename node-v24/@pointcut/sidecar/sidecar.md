# @pointcut/sidecar

> 标签: ai-agent, bridge, design-mode, devtools, esbuild, pointcut, rollup, sidecar

## 简介

Standalone Node server mounting the Pointcut Bridge for dev-server-less setups (a peer to auto-attach, not a fallback).
