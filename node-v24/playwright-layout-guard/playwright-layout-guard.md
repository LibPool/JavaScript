# playwright-layout-guard

> 标签: accessibility, cls, e2e, fixture, layout, layout-shift, playwright, testing, visual-stability, web-performance

## 简介

A Playwright fixture that fails a test when something on the page moves or changes its size. Works in Chromium, Firefox and WebKit, names the element and how far it moved.
