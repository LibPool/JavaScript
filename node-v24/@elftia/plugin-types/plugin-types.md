# @elftia/plugin-types

> 标签: agent, elftia, host-api, plugin, plugin-types, sdk

## 简介

Plugin host-API contract for Elftia plugins — the versioned AgentUiHostApi (renderer half) + AgentBackendHostApi (main half) types and HOST_API_VERSION. The only contract a plugin imports for the host surface (paired with @elftia/agent-spec). Pure TypeScr
