# @meeby/vectorglobe

> 标签: flight-routes, geojson, globe, great-circle, map, vector, visualization, webgl

## 简介

All-in-one fast vector world map rendering for websites. Self-contained 3D globe with a 2D fallback, no tiles, no runtime dependencies.
