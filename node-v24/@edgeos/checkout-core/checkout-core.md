# @edgeos/checkout-core

> 标签: checkout, commerce, ecommerce, edgeos, headless, payments, sdk, tickets

## 简介

Framework-agnostic headless checkout engine for EdgeOS — store, typed API client, server-authoritative pricing, cart, form validation and analytics. Zero UI, zero framework. Ships the building-edgeos-checkout Claude Code skill.
