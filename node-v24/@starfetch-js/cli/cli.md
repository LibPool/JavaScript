# @starfetch-js/cli

> 标签: adql, astronomy, cli, exoplanets, gaia, irsa, nasa-exoplanet-archive, simbad, star-catalog, tap, virtual-observatory, vizier

## 简介

CLI for querying Gaia, SIMBAD, VizieR, and other public astronomy TAP services with reproducible ADQL.
