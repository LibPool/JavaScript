# @cratis/ai

> 标签: ai, arc, cratis, proxy, typescript

## 简介

Generated Arc command/query proxies and TypeScript types for Cratis.AI - the backend AI concerns (providers, pools, tiers, concurrency, conversations, agents, worker/harness scheduling, usage) shared by Direct and Studio. Generated only - no components, n
