# @benzenejs/grpc

> 标签: JavaScript

## 简介

TypeScript port of the server-side slice of Benzene.Grpc — routes gRPC calls of all four shapes (unary, server-/client-/bidi-streaming) into Benzene message handlers over @grpc/grpc-js
