# @sparq-org/sparq

> 标签: linked-data, rdf, rdfjs, sparql, triplestore, wasm, webassembly

## 简介

RDF/JS interface to the sparq SPARQL engine (Rust → WebAssembly): an in-memory, dictionary-encoded RDF store with SELECT/ASK and SPARQL Update.
