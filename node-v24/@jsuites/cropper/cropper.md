# @jsuites/cropper

> 标签: javascript plugins, image cropper, javascript image cropper, javascript image editor, rotate, zoom, crop, brightness, contrast.

## 简介

JavaScript image editor and cropper plugin, with crop, zoom, rotate, brightness, contract and methods to export the results.
