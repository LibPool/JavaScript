> 标签: 2fa, auth, authentication, cloudflare, d1, forward-auth, magic-link, otp, passkey, passwordless, self-hosted, session, totp, webauthn, workers

## 简介

SQL storage adapter for @fullstacktechnyc/passwordless-core — drivers for Cloudflare D1, node:sqlite, bun:sqlite, and Postgres. Zero runtime dependencies.
