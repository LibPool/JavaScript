# @h-k-dev/angular-email-editor

> 标签: angular, email, email-editor, html-email, prosemirror, rich-text, signals, wysiwyg

## 简介

An email editor for Angular on ProseMirror — a visual composer and an HTML source editor over one schema that is the vocabulary of email HTML.
