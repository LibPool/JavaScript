## 简介

ElizaOS plugin: CHECK_TOKEN_RISK action + pre-trade TOKEN_RISK provider. Rug / honeypot / token-safety checks for Base and Solana tokens, paid per call over x402 with the agent's own wallet ($0.0009), free preview without a wallet.
