# @reactgraph-ui/core

> 标签: ast, components, developer-tools, graph, hooks, nextjs, react, typescript, visualization

## 简介

Visualize your React/Next.js project as an interactive hierarchy graph. Maps Pages -> Components -> Hooks -> APIs with props, types, and connections.
