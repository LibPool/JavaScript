# @floats/sdk

> 标签: agent, ai, canvas, flashcards, floats, mcp, mindmap, vercel-ai-sdk

## 简介

Typed client + AI-agent tools for Floats (thefloats.app): read canvases, write floats, margin-annotate, and run spaced-repetition flashcards.
