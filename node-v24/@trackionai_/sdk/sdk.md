# @trackionai_/sdk

> 标签: ai, attribution, cost-tracking, observability, trackion

## 简介

Attribution context helper for Trackion. Turns a context object into the headers the Trackion proxy reads, so AI spend can be traced back to a feature, workflow, customer, or agent.
