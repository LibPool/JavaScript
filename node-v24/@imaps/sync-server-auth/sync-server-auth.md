# @imaps/sync-server-auth

> 标签: arcgis, auth, authentication, feature-service, international-mapping, maplibre, popup, sync-server

## 简介

Framework-agnostic browser sign-in for Sync Server: popup flow, token persistence, authed fetch, MapLibre and ArcGIS helpers. Zero dependencies.
