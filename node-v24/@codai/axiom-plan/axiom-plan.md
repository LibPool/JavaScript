# @codai/axiom-plan

> 标签: agent, axiom, codegen, content-addressed, manifest

## 简介

Plan → ManifestBundle compiler for AXIOM v2: content-addressed artifacts, JCS manifest digest, inline/CAS blob transport, in-toto attestation, bundle verification and manifest diff
