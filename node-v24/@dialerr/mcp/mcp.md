# @dialerr/mcp

> 标签: dialer, dialerr, embed, mcp, modelcontextprotocol, softphone, webrtc, widget

## 简介

MCP server for Dialerr — lets AI coding assistants provision an embed key (browser-approved) and install the Dialerr softphone widget.
