# @omnibtc/dmens-sui-sdk

> 标签: JavaScript

## 简介

The typescript SDK for Dmens Protocol. >Dmens is a reduction of "Decentralize Momments", building a blockchain Twitter protocol on the Sui network, and integrating it in ComingChat in the form of a product similar to WeChat Moments.
