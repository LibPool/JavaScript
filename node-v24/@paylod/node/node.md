# @paylod/node

> 标签: daraja, kenya, m-pesa, mpesa, paylod, payments, safaricom, stk-push

## 简介

Official Node/TypeScript client for the paylod API — M-Pesa (Safaricom Daraja) STK Push, status polling, signed webhooks and offline error decoding, with zero runtime dependencies.
