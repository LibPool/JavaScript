# @lift-html/svelte

> 标签: svelte

## 简介

lift-html is a tiny library for building HTML Web Components, components that are meant to enhance existing HTML on the page instead of rendering it on the client or hydrating it. It utilizes Svelte to make attributes reactive, uses runes for state manage
