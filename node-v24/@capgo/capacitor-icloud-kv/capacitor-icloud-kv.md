# @capgo/capacitor-icloud-kv

> 标签: NSUbiquitousKeyValueStore, android, backup, capacitor, capgo, icloud, ios, key-value, plugin, sync

## 简介

Capacitor plugin to keep small app state in iCloud key-value storage on iOS and Android Backup on Android, so it survives a new phone.
