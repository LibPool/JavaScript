# @kirkelabs/oaa-agent-kit

> 标签: agent, agentic-payments, ai-agents, algorand, cli, logicsig, nodejs, oaa, open-agent-access, pera-wallet, perawallet, wallet, x402

## 简介

Create a fundable, Algorand-connected AI agent in minutes — it works on your behalf and pays for what it uses over x402, spending only within an on-chain LogicSig mandate (per-tx cap, payee allowlist, expiry). Pera Wallet-interoperable: fund and activate
