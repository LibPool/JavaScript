# @kirkelabs/walletless-kit

> 标签: algorand, audit-trail, charity, cli, custodial, gdpr, merkle, nodejs, oaa, onboarding, privacy, raffle, receipts, verifiable-draw, walletless, x402

## 简介

Walletless web architecture toolkit: low-friction onboarding (ephemeral custodial accounts), receipt-only on-chain proofs, a tamper-evident hash-chained + Merkle audit trail, segregated money ledgers, and a verifiable, recomputable draw. Charity prize-dra
