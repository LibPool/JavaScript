# @ddd-ts-kit/auth

> 标签: abac, access-control, authentication, authorization, clean-architecture, ddd, domain-driven-design, hexagonal-architecture, rbac, rebac, typescript, zanzibar

## 简介

Authentication and authorization behind ports: actors, permissions declared per use case, role, attribute and relationship (Zanzibar-style) based authorizers, deny by default.
