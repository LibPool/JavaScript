# @ddd-ts-kit/redis

> 标签: cache, clean-architecture, ddd, distributed-lock, domain-driven-design, dragonfly, hexagonal-architecture, rate-limiter, redis, redis-streams, typescript, valkey

## 简介

Adapters of the kernel ports on the Redis protocol (Redis, Dragonfly, Valkey): cache, distributed lock, rate limiter, relay wake-up signal, a background job store, and an integration event provider on Redis Streams.
