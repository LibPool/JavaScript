# @softwareseva/ui

> 标签: JavaScript

## 简介

Accessible React primitives on Tailwind v4 with the kashi design tokens (light and dark). Button, IconButton, DropdownMenu, Input, Select, RadioGroup, Checkbox, Switch, Card, Badge, Alert.
