# @echo-note/gitea-toolkit-mcp

> 标签: agent, ai, gitea, issue, mcp, model-context-protocol, pull-request

## 简介

Gitea 的 MCP 工具服务（stdio）：35 个工具覆盖仓库 / Issue / Pull Request / 通知 / Gitea Actions 的读写。独立于 VS Code 扩展，任何 MCP 客户端（Claude Desktop、Cursor、CodeBuddy…）均可接入。
