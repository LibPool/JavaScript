# @scopebond/framework

> 标签: ai-agents, langchain, langgraph, policy, scopebond, tools, vercel-ai

## 简介

Scopebond framework plugins — one import so an agent checks your policy before every tool call and records a signed receipt. Cooperative (M0) in-process guard with Vercel AI SDK and LangGraph/LangChain adapters.
