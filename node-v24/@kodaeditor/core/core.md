# @kodaeditor/core

> 标签: custom-element, docx, editor, html-editor, pdf-import, prosemirror, rich-text-editor, self-hosted, web-component, word-paste, wysiwyg, xlsx

## 简介

WYSIWYG rich-text editor as a web component. Brings tables, lists and formatting across when users paste from Word, Excel and Google Docs. Self-hosted, framework-agnostic.
