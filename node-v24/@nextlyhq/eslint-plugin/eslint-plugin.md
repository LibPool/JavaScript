# @nextlyhq/eslint-plugin

> 标签: design-tokens, eslint, eslint-plugin, eslintplugin, nextly, nextly-plugin

## 简介

ESLint rules that keep Nextly admin UI on the design-token system — for first-party packages and for plugins built by anyone else.
