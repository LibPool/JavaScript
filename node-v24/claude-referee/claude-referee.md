# claude-referee

> 标签: claude-code, claude-code-plugin, developer-tools, jev, llm-as-a-judge, typesafe

## 简介

Unofficial CLI that checks "done" claims and small judgement calls with TypeSafe Jev, and keeps local receipts. The Claude Code plugin of the same name bundles it.
