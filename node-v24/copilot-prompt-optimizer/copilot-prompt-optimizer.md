# copilot-prompt-optimizer

> 标签: copilot-hooks, github-copilot, prompt-engineering, token-counter, vscode

## 简介

Captures every prompt sent to GitHub Copilot Chat via a VS Code Agent Hook, counts tokens, and stores a token-leaner local rewrite you can reuse — suggestion only, nothing is auto-applied.
