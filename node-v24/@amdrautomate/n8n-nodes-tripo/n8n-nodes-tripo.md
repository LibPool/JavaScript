# @amdrautomate/n8n-nodes-tripo

> 标签: 3d generation, glb, image to 3d, n8n, n8n-community-node-package, retopology, rigging, text to 3d, tripo, tripo3d

## 简介

n8n community node for Tripo (Tripo3D): generate 3D models from text, images or multiview photos, texture, convert, retopologize, segment, rig and animate them, generate images and multiviews, and poll tasks with the Tripo API v3
