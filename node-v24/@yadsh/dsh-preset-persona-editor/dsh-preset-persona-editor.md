# @yadsh/dsh-preset-persona-editor

> 标签: agent-preset, agent-presets, cordis, deepseek, deepseek-harness, dsh, dsh-plugin, persona, settings-ui, system-prompt, web-ui

## 简介

Edit an agent preset's persona for the DeepSeek Harness from the settings UI: prefix, suffix, complete mode, and the runtime-context toggle, written back into the preset's own agent.cordis.yml
