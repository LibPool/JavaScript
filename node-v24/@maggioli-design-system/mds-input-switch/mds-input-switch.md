# @maggioli-design-system/mds-input-switch

> 标签: JavaScript

## 简介

mds-input-switch is a web-component from Magma Design System, built with StencilJS, TypeScript, Storybook. It's based on the web-component standard and it's designed to be agnostic from the JavaScript framework you are using.
