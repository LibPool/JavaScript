# vivid-charts

> 标签: agent-skill, ai-agents, charts, choropleth, claude, data-visualization, dataviz, infographic, png, poster, streamgraph, svg, treemap, visual-capitalist

## 简介

Poster-grade data visualization for humans and AI agents: Visual Capitalist-style infographics (photos, maps, treemaps, streamgraphs, bubble chains…) from a JSON spec, rendered to SVG/PNG without a browser. Ships with an agent skill.
