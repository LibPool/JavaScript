> 标签: ai-agent, atp, claude, live-scores, llm, mcp, mcp-server, model-context-protocol, modelcontextprotocol, sports, sports-api, sports-data, tennis, tennis-api, wta

## 简介

MCP server for the Live Tennis API — give Claude, Cursor and other LLM agents real-time tennis scores, players and fixtures for ATP, WTA, Challenger, ITF and juniors. Odds, rankings, match statistics, charting and model win-probability tools require the P
