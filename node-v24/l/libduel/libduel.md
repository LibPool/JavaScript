# libduel

> 标签: ab-testing, benchmark, cli, comparison, developer-tools, libraries, performance

## 简介

Prove which backend library is better for YOUR code and workload before you switch. A CLI that runs controlled, fair benchmarks between two library implementations and recommends a winner.
