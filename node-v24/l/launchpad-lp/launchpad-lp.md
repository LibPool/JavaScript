# launchpad-lp

> 标签: agent, cli, deploy, launchpad, mcp, sharedspace

## 简介

lp — the Launchpad CLI. Publish, inspect, and stash apps, post to SharedSpace, read the platform docs, and bridge any Launchpad server into a local AI agent over MCP.
