# llm-whisperer

> 标签: ai, browser-automation, chatgpt, claude, deepseek, llm, playwright, qwen

## 简介

Whisper to free web LLM chat UIs (Qwen, ChatGPT, Claude, DeepSeek, GLM) and expose them over one local HTTP API — no API keys needed.
