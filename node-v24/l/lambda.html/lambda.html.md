# lambda.html

> 标签: chainable, fluent-api, functional-html, html, html-builder, htmx, jsx-alternative, server-side-rendering, ssr, tailwind, type-safe, typescript, xss-protection, zero-dependencies

## 简介

Fluent, type-safe HTML builder for TypeScript. Chainable styling API, first-class HTMX support with full autocomplete, automatic XSS protection. Zero dependencies, SSR-ready.
