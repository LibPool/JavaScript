# log-probe-mcp

> 标签: agent, claude, cursor, debugging, logging, mcp, model-context-protocol

## 简介

Agent-agnostic MCP server for hypothesis-driven debugging: spins up a local log ingestion server, correlates logs to executions, and guides any MCP-compatible coding agent through forming and testing hypotheses with real runtime data.
