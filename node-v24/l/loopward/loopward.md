# loopward

> 标签: agent-harness, ai-agents, eval, loop-engineering, mcp, red-team, robustness, tool-routing, tool-selection

## 简介

Stress-test the tool-routing decision inside an agent loop: audit confusable tools, red-team routing robustness, and export failures as training data.
