# link-cache

> 标签: cache, cli, link-checker, link-checking, lychee

## 简介

Zero-dependency helper CLIs for cached Lychee link-checking around an owned JSONC cache (link-cache.jsonc) with provenance: lychee-norm-cache (run + sync caches) and link-cache (inspect/prune).
