# lucet-core

> 标签: ai, chat, components, design-system, headless, interface, llm, state-machine, streaming, ui

## 简介

Framework-free headless core for Lucet. State logic only: streaming, aborts, tool lifecycle, versioning/restore, scope resolution. Zero framework imports.
