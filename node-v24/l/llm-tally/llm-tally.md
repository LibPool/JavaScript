# llm-tally

> 标签: anthropic, calculator, claude, cli, cost, deepseek, gemini, glm, grok, kimi, llm, mistral, openai, pricing, qwen, reasoning, token-counter, tokens

## 简介

Estimate what a prompt costs on 138 LLMs from 14 providers (OpenAI, Anthropic, Google, xAI, DeepSeek, Mistral, Qwen, Kimi, GLM and more), with reasoning effort. Web calculator, CLI and zero-dependency library.
