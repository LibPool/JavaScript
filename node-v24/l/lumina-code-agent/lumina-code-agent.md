# lumina-code-agent

> 标签: ai, cli, coding-agent, git, github, lumina, multi-agent, tui

## 简介

Lumina Code — Full AI coding agent team. Clone repos, analyze codebases, edit files, push changes. Multi-agent pipeline (Planner, Coder, Reviewer, Fixer). Streaming, model selector, effort picker. Never produces generic/robotic websites.
