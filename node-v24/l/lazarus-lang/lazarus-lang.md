# lazarus-lang

> 标签: education, francais, french, games, interpreter, langage, language, lazarus, learn-to-code, programming-language

## 简介

LAZARUS — le langage de programmation créé par Ladji Doucaré. Accolades comme Java, simplicité de Python, mots-clés uniques, mode JEU temps réel + mode INTERFACE (applications). Exécutez du code LAZARUS dans n'importe quel navigateur ou application Node.j
