# luxcss

> 标签: attributes, css, css-library, design-system, frontend, html, javascript, nextjs, react, styling, ui, zero-dependency

## 简介

Attribute-first CSS & JS library. Style anything with one HTML attribute. Zero dependencies, no build step.
