# lerna-ui

> 标签: JavaScript

## 简介

yarn 的workspaces特性 可以更好的统一管理有多个项目的仓库，可以使多个项目共享一个node_modules 避免相同依赖多次安装 "workspaces": [     "packages/*" // 工作区子目录   ],
