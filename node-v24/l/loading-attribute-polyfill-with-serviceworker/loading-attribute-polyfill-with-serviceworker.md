# loading-attribute-polyfill-with-serviceworker

> 标签: front-end, html, iframe, image, img, javascript, lazy loading, native lazy loading, polyfill, service worker, web development

## 简介

Fast and lightweight dependency-free vanilla JavaScript polyfill for native lazy loading / the awesome loading='lazy'-attribute supported by a Service Worker.
