# laya-system-one

> 标签: classifier, decision-engine, guardrails, jev, laya, multilingual, onnx, system-one, triage, typesafe, wasm, webgpu

## 简介

Self-contained, ultra-fast System 1 decision engine with WebGPU/WASM acceleration, 100% wire-compatible with TypeSafe Jev (/v1/systemone). Runs offline in Node.js, Bun, and browsers.
