# localscope-mcp

> 标签: claude, code-analysis, codebase-intelligence, cursor, embeddings, impact-analysis, local-first, mcp, model-context-protocol, privacy, ripgrep

## 简介

Local-first MCP code analyst: index your repo privately (embeddings + ripgrep-style search), then ask 'where does X break if I change Y' — zero cloud, zero config.
