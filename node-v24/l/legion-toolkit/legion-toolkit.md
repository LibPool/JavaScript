# legion-toolkit

> 标签: audit, eslint, legion, nextjs, oxlint, prettier, react, tsconfig

## 简介

One install for the whole Legion toolkit: the lint plugin, the audit CLI, the Prettier config and the TypeScript configs, each exposed as a subpath.
