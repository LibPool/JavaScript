# lib-cpf

> 标签: JavaScript

## 简介

**Esta biblioteca destina-se à verificação de números de CPF, retornando true para um CPF válido, e false para um inválido.** Na versão atual a biblioteca verifica números de CPF tanto em números quanto em string. O usuário também pode inserir o número d
