# livesey-data-parser

> 标签: ES6, Node.js, automated scraping, data extraction, financial data, financial websites, parser, proxies, queue management, rotating proxies, stock market, web scraping

## 简介

A financial data parser designed for scraping and extracting key metrics and information from various financial websites. Optimized for handling large datasets and multiple requests with proxy support, rotating proxies, and task queue management.
