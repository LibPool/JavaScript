# leaflet-geosearch

> 标签: geocoding, leaflet, maps

## 简介

Adds support for address lookup (a.k.a. geocoding / geosearching) to Leaflet.

- 官网：https://leaflet-geosearch.meijer.works
- 源码仓库：git+https://github.com/smeijer/leaflet-geosearch.git
