# llm-link-provenance

> 标签: ai-safety, citation, grounding, guardrails, hallucination, llm, markdown, provenance, rag, url

## 简介

Deterministic link provenance for LLM output. Flattens Markdown links the model never grounded, keeps the ones it did. No network, no model, no dependencies.
