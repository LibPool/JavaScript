# landcheck

> 标签: coastline, dggs, geospatial, land, ocean, offline, point-in-polygon, sea

## 简介

Offline land/sea point lookup: 182 KB global dataset, microsecond answers with confidence, built on the Trifold T3 triangular DGGS
