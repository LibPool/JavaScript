# layoutpreview

> 标签: ecad, kicad, layout, pcb, viewer

## 简介

独立 KiCad PCB 布局预览应用包：加载 .kicad_pcb 渲染板子，并支持由外部布局结果静态应用新位置（按 reference/uuid 移动封装）、聚焦查看、导出图片。
