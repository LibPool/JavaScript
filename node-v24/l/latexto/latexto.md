# latexto

> 标签: agent, cli, compile, katex, latex, pdf, png, tex, texlive

## 简介

Compile LaTeX to PDF and render LaTeX to PNG from the command line, with no local TeX installation. Drives latex.to in headless Chromium.

## 官网

- 官网：https://latex.to/agents/
- 源码仓库：git+https://github.com/latexto/skills.git
- npm 页面：https://www.npmjs.com/package/latexto
