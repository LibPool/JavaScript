# localizer-ai

> 标签: AI translation, CLI tool, MistralAI integration, OpenAI integration, VitePress localization, content localization, content management, documentation translation, format preservation, markdown translation, multilingual content, parallel processing, translation tool

## 简介

A powerful CLI tool for automating content localization using OpenAI GPT-4 or MistralAI, helping to localize apps. Supports multiple file types, preserves formatting, and enables context-aware translations.
