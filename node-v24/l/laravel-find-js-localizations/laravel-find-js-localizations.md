# laravel-find-js-localizations

> 标签: JavaScript

## 简介

A tools that helps finding untranslated strings in JavaScript files in Laravel projects using rmariuzzo/Laravel-JS-Localization and andywer/laravel-js-localization

## 官网

- 源码仓库：https://github.com/clentfort/laravel-find-js-localizations
- npm 页面：https://www.npmjs.com/package/laravel-find-js-localizations

## 历史版本号

- 当前版本：1.0.0

- 1.0.0

## 获取地址

- npm 安装：`npm install laravel-find-js-localizations`
- npm registry：https://registry.npmjs.org/laravel-find-js-localizations
- Node 要求：>=7.7.1
