# l8bin-mcp

> 标签: deploy, docker, l8b, l8bin, litebin, mcp, model-context-protocol, paas, self-hosted

## 简介

l8bin (pronounced LiteBin) MCP server — deploy and operate your self-hosted projects from any MCP client. Wraps the l8b CLI, installing the platform binary on first use.
