# lzscroll

> 标签: JavaScript

## 简介

**当前版本： V1.3.0** <br> ### lz-scroll是什么 >lz-scroll是一款基于jQuery库开发的轻量级滚动条插件，方便开发者能够自定义滚动条样式。可以设置滚动速度，是否一直显示滚动条，并且能够根据内容的高度变化而自我调整。当前版本为正式版1.3.0
