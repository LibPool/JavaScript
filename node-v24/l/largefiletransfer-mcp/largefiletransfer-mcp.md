# largefiletransfer-mcp

> 标签: ai-agent, claude, file-transfer, largefiletransfer, mcp, model-context-protocol

## 简介

Send files from your computer to LargeFileTransfer from Claude Code, Claude Desktop, Cursor and other AI agents, and get a share link back.

- 官网：https://largefiletransfer.com
- npm 页面：https://www.npmjs.com/package/largefiletransfer-mcp
