# locale-simple

> 标签: esm, gettext, i18n, internationalization, l10n, locale, localization, po, po2json, polyglot, sprintf, translation

## 简介

Tiny gettext wrapper with sprintf-style helpers (l, ln, lp, ld, …) — same API as the Perl and Python siblings, so one .po file feeds all three runtimes. ESM + CJS + types, zero runtime deps.
