# lamdis-mcp

> 标签: JavaScript

## 简介

Lamdis MCP server — lets an AI agent (Claude, Codex, or any MCP client) read, evaluate, and propose updates to living contracts over the Model Context Protocol. Authority is governed by the scopes on its Lamdis API key.
