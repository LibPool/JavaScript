# laya-system

> 标签: JavaScript

## 简介

Laya System 是基于 LayaAir 框架开发的 2D 游戏管理库。 Laya System 提供了鼠标、键盘、动画事件管理，提供了摄像机、黑板功能的实现，方便开发者快速进行开发管理。
