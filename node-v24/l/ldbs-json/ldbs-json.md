# ldbs-json

> 标签: darwin, json, ldbs, ldbws, openldbsvws, openldbws

## 简介

JSON Interface for the National Rail Enquiries Darwin OpenLDBWS and OpenLDSVWS SOAP services. To access either servce will require a valid token.
