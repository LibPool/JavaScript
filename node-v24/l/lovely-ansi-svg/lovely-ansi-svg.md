# lovely-ansi-svg

> 标签: ansi, ansi-to-svg, ascii, ascii-art, svg, terminal

## 简介

Convert ANSI/ASCII terminal text into a crisp, styleable SVG character grid. Framework-agnostic, no DOM needed.
