# linear-archive

> 标签: archive, backup, cleanup, cli, export, issue-tracker, issues, linear, linear-api, linear-app, linear.app, markdown, migration, project-management, typescript, zero-dependencies

## 简介

CLI to export Linear issues to Markdown and back them up locally, then archive or delete them in Linear. Filter by state, team, project, label, creator. Zero dependencies.
