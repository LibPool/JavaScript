> 标签: anthropic, deepseek, gemini, groq, llm, llmtoken, mern-packages, merndev, nodejs, npm-pm, observability, ollama, openai, sse, stream, streaming, typescript

## 简介

Universal LLM stream parser that normalizes SSE chunks from OpenAI, Anthropic, Google, and other providers into a single token event API.
