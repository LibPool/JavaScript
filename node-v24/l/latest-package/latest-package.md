# latest-package

> 标签: latest, monorepo, npm, package, upgrade, version, yarn

## 简介

An interactive command-line tool for upgrading packages in a monorepo to their latest versions.

- 官网：https://github.com/castastrophe/latest-package
- 源码仓库：git+ssh://git@github.com/castastrophe/latest-package.git
