# llm-tool-capability

> 标签: agent, function-calling, llama.cpp, llm, lm-studio, ollama, openai, tool-calling, tools, vllm

## 简介

Drop-in OpenAI-compatible tool calling for LLMs that don't support function calling natively. Injects tools via prompt, parses tool calls from text, and runs a full agentic loop — with streaming support.
