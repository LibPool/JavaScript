# lockstep-docs

> 标签: agent, code-graph, docs, documentation, drift, falkordb, graph, mcp

## 简介

An agent that keeps your docs true to your code: it walks a FalkorDB graph of code, docs and decisions across repositories, runs the examples, and proposes the docs fix with the path behind each paragraph.
