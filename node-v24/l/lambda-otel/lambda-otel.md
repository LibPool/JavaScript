# lambda-otel

> 标签: aws, lambda, metrics, observability, opentelemetry, otel, otlp, serverless, telemetry-api, tracing

## 简介

Vendor-neutral OpenTelemetry traces + metrics for AWS Lambda. Exports OTLP; the collector decides the backend.
