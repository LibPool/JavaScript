# lithocinch

> 标签: avif, batch, cli, cmyk, image, jpeg, lambda, mozjpeg, optimise, optimize, png, resize, sharp, srgb, svg, svgo, webp

## 简介

Fast, batch image optimizer built on sharp + svgo. Caps dimensions, normalizes color to sRGB, compresses JPEG/PNG/GIF/WebP/AVIF/TIFF and SVG. Usable as a CLI, a library, or an AWS Lambda.
