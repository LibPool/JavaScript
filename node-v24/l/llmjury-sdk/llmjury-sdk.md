# llmjury-sdk

> 标签: ab-testing, analytics, evaluation, experimentation, feature-flags, llm, observability, prompt-engineering

## 简介

Official TypeScript/JavaScript SDK for LLMJury — run LLM experiments in production: deterministic variant assignment, prompt/model comparison, and non-blocking metrics tracking.
