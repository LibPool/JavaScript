# lateralus-lsp

> 标签: language-server, lateralus, lsp, ltl

## 简介

Node launcher for the Lateralus LSP server. Wraps the Python `lateralus-lsp` entrypoint shipped by `lateralus-lang` on PyPI so editor integrations can expect a stable npm package.

## 官网

- 官网：https://lateralus.dev
- 源码仓库：git+https://github.com/bad-antics/lateralus-lang.git
- npm 页面：https://www.npmjs.com/package/lateralus-lsp

- 1.0.0

## 获取地址

- npm 安装：`npm install lateralus-lsp`
- npm registry：https://registry.npmjs.org/lateralus-lsp
- Node 要求：>=14
