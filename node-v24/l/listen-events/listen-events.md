# listen-events

> 标签: EventBus, event subscription, events, js, listen, 事件, 事件侦听器, 事件分派, 侦听器, 订阅事件

## 简介

EventBus 是一个简单的 WEB 端事件侦听器，提供了一种将事件分派给订阅的事件侦听器的机制。
