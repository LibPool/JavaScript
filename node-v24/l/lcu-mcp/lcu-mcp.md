# lcu-mcp

> 标签: cdp, lcu, league-of-legends, mcp, model-context-protocol, riot-games

## 简介

MCP server for the League of Legends client: LCU REST API, live WAMP events & recording, CDP console/DOM access, and OpenAPI schema introspection
