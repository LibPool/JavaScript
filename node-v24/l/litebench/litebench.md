# litebench

> 标签: agents, ai, codex, cursor, fts5, harness, markdown, opencode, orchestration, planning, work-units

## 简介

A lightweight build harness for Codex, Cursor and OpenCode with durable project memory, optional native agents, and proof-gated work units.
