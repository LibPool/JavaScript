# live-score-watcher

> 标签: espn, events, football, live-scores, polling, scoreboard, soccer, sports, watcher, world-cup

## 简介

Poll a live sports scoreboard and get clean match events instead of raw frames: restart-safe so a crash never replays old goals, VAR-reversal debouncing, garbled-payload guards, and adaptive polling that wakes for kickoff.
