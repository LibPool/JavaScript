# level-push

> 标签: database, db, guid, json, leveldb, levelup, uuid

## 简介

Pushes JSON to your LevelDB with auto-generated UUID. Uses [level-set](https://github.com/maiah/level-set) to convert JSON to LevelDB data structure.
