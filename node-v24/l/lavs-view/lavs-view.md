# lavs-view

> 标签: agent, iframe, lavs, postmessage, ui-command, view

## 简介

LAVS view-side SDK: postMessage bridge to the LAVS host plus UI command registry (SPEC §12). Ships a prebuilt IIFE (dist/lavs-view.iife.js) for no-build bundle views.
