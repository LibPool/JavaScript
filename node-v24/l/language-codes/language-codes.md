# language-codes

> 标签: ISO 639, ISO 639-2, ISO 639-3, Strings Resource, languages codes

## 简介

Generate up-to-date dictionaries of all existing ISO language codes. Output as JSON or .String Resource File. Features two- and three-letter ISO 639-2 & 639-3 codes. Includes automated code tables updates.
