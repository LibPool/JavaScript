# liwei-cli

> 标签: JavaScript

## 简介

``` lw add <project name> <project depository url> ``` ## 二、使用脚手架创建项目 ``` lw init <template project name> <local project name> ``` ## 三、查看模板列表 ``` lw list ``` ## 四、删除模板项 ``` lw delete <template name> ```
