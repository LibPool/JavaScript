# links-extract-karina

> 标签: extract, links

## 简介

**Esta biblioteca se destina à extrair links de um arquivo Markdown e retornar o link e o nome do link.** Na versão atual é possivel extrair os links e ordená-los de acordo com a ordem que aparecem dentro de um array que contém um objeto.
