# lambda-get-s3-file

> 标签: JavaScript

## 简介

A no dependency library for getting a smallish file from AWS S3. Made for getting .env files from S3 for Lambda functions.

## 官网

- npm 页面：https://www.npmjs.com/package/lambda-get-s3-file
