# local-agent-client

> 标签: JavaScript

## 简介

A lightweight, secure, and self-hosted agent client daemon for the **AIFrame** ecosystem. It connects local developer environments and machines to the AIFrame cloud broker, allowing agents to execute tasks and interact with local AI tools securely.
