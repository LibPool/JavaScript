# lines-overlay

> 标签: JavaScript

## 简介

Esse é um componente React que desenha linhas horizontais ou verticais sobre a tela para ajudar desenvolvedores front-end a conferir alinhamentos e espaçamentos entre elementos de interface, especialmente entre textos e outros elementos. Instale com "npm
