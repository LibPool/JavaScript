# lipafy

> 标签: ai-agents, api-authentication, bearer-token, cli, curl, gateway, lipafy, mcp, payments, wallet

## 简介

Lipafy command-line companion. Wraps `curl` so any agent or script transparently uses your Lipafy account for paid HTTP calls.
