# llm-ledger

> 标签: ai, anthropic, budget, claude, cost, llm, openai, pricing, prompt-caching, tokens, tracker, usage

## 简介

Zero-dependency token usage and cost tracker for LLM APIs (Anthropic Claude, OpenAI, and any custom model). Track spend, cache savings, and budgets across requests.
