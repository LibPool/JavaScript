# lucaledger-mcp

> 标签: accounting, api, bookkeeping, lucaledger, mcp, modelcontextprotocol, tax

## 简介

Model Context Protocol server for the LucaLedger public API. Navigate and call the API from any MCP client (Claude Desktop, etc.).
