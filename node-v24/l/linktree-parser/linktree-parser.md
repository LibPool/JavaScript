# linktree-parser

> 标签: bun, deno, javascript, linktree, linktree-miner, linktree-parser, linktree-scraper, nodejs, scraper, typescript-library, web-scraping

## 简介

linktree-parser is a TypeScript library for scraping and extracting account, links, banners, and metadata from Linktree profiles.
