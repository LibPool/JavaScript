# likerpx

> 标签: rem, rem2rpx, remtorpx, rpx, rpx2rem, rpxtorem, vh, vw

## 简介

通过 likerpx ，可以在 html 项目上使用小程序的 rpx 单位，体验跟小程序的 rpx 完全一致
