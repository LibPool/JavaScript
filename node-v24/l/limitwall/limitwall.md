# limitwall

> 标签: fixed-window, gcra, hono, leaky-bucket, middleware, rate-limit, rate-limiter, redis, sliding-window, token-bucket

## 简介

Rate limiting middleware for Hono, backed by Redis. Fixed window, sliding window, token bucket, and leaky bucket (GCRA) in one package
