# leisure-core

> 标签: leisure, leisure-core, 京心数据

## 简介

leisure-core是京心数据基于vue2.x开发的一套后台管理系统桌面端组件库，封装了大量实用的UI控件模板,非常方便开发者快速搭建前端应用
