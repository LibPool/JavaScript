# loresmith

> 标签: agents, agents-md, ai, claude, claude-code, cli, codex, cursor, developer-tools, documentation, scaffold

## 简介

Give any repo a memory. One command scaffolds the markdown docs AI agents read, follow, and keep up to date — with lifecycle rules, staleness checks, and a todo→done workflow.
