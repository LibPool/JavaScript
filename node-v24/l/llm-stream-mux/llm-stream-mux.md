# llm-stream-mux

> 标签: async-iterable, composable, ensemble, failover, fallback, fan-out, llm, llm-stream, merge, race, readablestream, stream-mux, stream-orchestration, streaming, tee, typescript, web-streams, zero-dependencies

## 简介

Zero-dependency TypeScript stream orchestration for LLM pipelines — race, fallback, merge, and tee over any AsyncIterable or ReadableStream, generic over T.
