# layout-inspector

> 标签: a11y, accessibility, box-model, contrast, devtools, element-picker, inspector, layout, layout-inspector, picker, react, wcag

## 简介

DevTools-style layout inspector for React. Hover any element for tag, selector, dimensions, font, WCAG contrast, ARIA role, accessible name, and a11y state.
