# large-package-payload-creator

> 标签: aptos, blockchain, cli, large-package, move, multi-sign, payload

## 简介

A tool for splitting large Aptos Move contract packages into multiple JSON payloads for multi-signature or object deployment. Supports batch upload, upgrade mode, and custom network/RPC. Ideal for developers deploying large Move packages on Aptos.
