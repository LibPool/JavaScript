# langchain-dev

> 标签: agent, ai, claude, claude-code, langchain, langgraph, langsmith, llm, rag, skill

## 简介

Installs the LangChain 1.x / LangGraph skill (API quick-reference + selection guide for Agents, RAG, tools, structured output, memory, middleware, LangSmith) into a project's .claude/skills folder.
