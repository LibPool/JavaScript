# luckagent

> 标签: agent, bot, claude-code, deepseek, feishu, lark, self-hosted

## 简介

Luckagent — 把 Claude Code / DeepSeek 变成飞书里的常驻 AI 同事（自托管）。此包为安装引导器：luckagent init 一键完成安装，装好后透传全部 CLI 子命令。
