# lido-mcp

> 标签: ai-agent, claude, defi, ethereum, governance, lido, liquid-staking, mcp, model-context-protocol, staking, steth, stvaults, wsteth

## 简介

A MCP server that provides Claude AI and other MCP-compatible agents with real-time access to Lido liquid staking on Ethereum — stake, unstake, wrap, govern, and manage staking positions directly from a conversation.
