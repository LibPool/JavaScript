# liveline-svelte

> 标签: animation, candlestick, canvas, chart, line-chart, multi-line, multi-series, ohlc, real-time, svelte

## 简介

Independent real-time chart library for Svelte 5, with animated line, candlestick, and multi-series modes. Originally forked from Liveline.
