# letspecify

> 标签: adr, agentic, ai-agents, cli, governance, quality-gates, scaffolding, spec-driven, spec-driven-development, traceability

## 简介

Engineering governance for spec-driven projects: scaffold a governance repo, verify the model and run the quality gates. The model decides, the tool materialises.
