# lpc-forge

> 标签: 2d, character-generator, dungeon-generator, game-assets, gamedev, godot, godot-4, indie-game, liberated-pixel-cup, lpc, pixel-art, procedural-generation, rpg, sprite-compositor, spritesheet, tilemap

## 简介

Complete 2D RPG asset pipeline — character compositor, procedural map generator, and Godot 4 exporter. Built on Liberated Pixel Cup sprites.
