# libertas

> 标签: JavaScript

## 简介

1. Install git if you don't have it: `xcode-select install` (from Terminal) 1. Clone the repo: `git clone git@github.intuit.com:cyoung2/libertas-prototype.git` 1. Navigate into the folder: `cd libertas-prototype` 1. `npm install` 1. `npm start`
