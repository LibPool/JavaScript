# layerwright

> 标签: ai design to figma, auto-layout, claude code figma, claude design to figma, claude-code, cursor, design system automation, design-to-code, export claude design, figma, figma mcp, figma to code, figma to react, figma-plugin, html to figma, mcp, mcp-server, model-context-protocol

## 简介

Turn Claude Design and Claude Code designs into native, editable Figma files (HTML to Figma with Auto Layout and your Design System components), and Figma frames into code that uses your own React components. An MCP server and Figma plugin for Claude Code
