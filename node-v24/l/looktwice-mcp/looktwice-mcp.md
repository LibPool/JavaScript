# looktwice-mcp

> 标签: api, cpsc, email, iban, mcp, modelcontextprotocol, product-recalls, validation, vat

## 简介

MCP server for the LookTwice API: email, EU VAT, IBAN, and domain validation plus evidence-backed CPSC recall screening from any MCP client.
