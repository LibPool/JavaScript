## 简介

One command to point your coding agent at Layer X1: pick your tools, install what's missing, choose models from the live catalog, paste your key. Supports Claude Code, Codex, Hermes, Aider, Continue, Cline, Cursor, Windsurf, Antigravity, Kiro.
