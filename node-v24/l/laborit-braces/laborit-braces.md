# laborit-braces

> 标签: brace-expansion, braces, glob, security

## 简介

Security patch of braces 3.0.3. Rejects brace nesting deeper than 128 and cyclic ASTs before the recursive walkers run (GHSA-vfj7-8cjw-p6xm).
