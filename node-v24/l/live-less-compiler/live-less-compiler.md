# live-less-compiler

> 标签: JavaScript

## 简介

A simple tool for watching `.less` files in a directory, and compiling them to `.css` on file change (using `lessc`). Uses less-plugin-autoprefix for automatic prefix generation with `last 2 versions,> 5%,Firefox >= 20,iOS 7` settings.
