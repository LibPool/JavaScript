# llm-canvas-windows-x64

> 标签: JavaScript

## 简介

An LLM-native local workspace for substantial coding-agent output — agents write structured HTML sections into a project-scoped browser workspace instead of dumping into the chat transcript. — prebuilt binary for win32/x64.
