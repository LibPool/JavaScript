# lolm-nfet-client

> 标签: agent, ai, code-execution, interpretability, llm, lolm, memory, nfet, sandbox, sse, streaming, telemetry, uncertainty

## 简介

Client for the LOLM-NFET agent: live SSE runs with in-conversation + cross-session memory, agentic code execution with sealed code receipts, visual app builds, and plain-English narration for an agent controlled by its own latent telemetry.
