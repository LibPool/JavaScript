# lacspace-monitor

> 标签: alerts, availability, change-detection, ci, cli, cron, diff, discord, monitor, price-monitor, response-time, rss, slack, ssl-monitor, status-monitor, telegram, typescript, uptime, watcher, webhook, website-monitor

## 简介

Free, open-source change monitor — watch any web page, CSS selector, JSON API field, RSS/Atom feed, HTTP status, header, response time, SSL expiry or uptime and get told when something moves. Condition-based alerts (price drops, thresholds), Slack/Discord
