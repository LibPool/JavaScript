# leadhunt

> 标签: b2b, cli, contact-finder, crawler, email, email-finder, lead-generation, leads, outbound, playwright, prospecting, sales, scraper

## 简介

Find contact emails for any list of domains, or sweep Google Maps for local businesses. Fast HTTP crawl first, headless Chromium only for the sites that need it.
