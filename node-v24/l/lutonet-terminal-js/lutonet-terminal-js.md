# lutonet-terminal-js

> 标签: ES6, commands, div, javascript, logger, terminal, textarea

## 简介

Terminal UI which can display data for users, admin and can be also used to trigger different functions and command. I plan to add real-time support for SignalR and Socket IO or API support for server calls
