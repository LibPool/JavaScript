# lumibase

> 标签: cli, client, cms, codegen, headless-cms, lumibase, scaffold, sdk, typegen, typescript

## 简介

LumiBase in one package — the JS/TS client (re-exports @lumibase/sdk) plus the `lumibase` CLI: generate TypeScript types from a live schema, check your setup, scaffold a project.
