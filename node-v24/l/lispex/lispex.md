# lispex

> 标签: interpreter, lisp, lispex, png, r7rs, receipts, replay, scheme, source-image, verify, vouch-bridge, wasm, webassembly

## 简介

Local CLI for the Lispex reference interpreter, explicit SICP profile, exact Lispex Images, and Lispex Vouch evidence. It evaluates .lspx files, runs .scm files only through lispex sicp run, round-trips canonical source images, authenticates signed Native
