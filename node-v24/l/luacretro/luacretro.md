# luacretro

> 标签: 6502, 68000, ahead-of-time, aot, arm, c64, cc65, commodore-64, compiler, console, game-boy-advance, game-development, gamedev, gametank, gba, genesis, homebrew, lua, lua-to-c, nes, pico-8, pico8, retro, retrogaming, rom, sdk, transpiler, wasm, webassembly

## 简介

The shared Lua compiler front-end for the gtlua / gbalua / mdlua / neslua / c64lua console SDKs: a PICO-8-flavored Lua subset compiled to C for GameTank (6502), Game Boy Advance (ARM), Sega Genesis (68000), NES (6502), and Commodore 64 (6510).
