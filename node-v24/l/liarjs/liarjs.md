# liarjs

> 标签: anti-detect, antidetect, bot-detection, browser-fingerprinting, canvas-fingerprint, cdp, chrome-devtools-protocol, ci, fingerprint, fingerprint-test, headless-detection, playwright, puppeteer, stealth, web-scraping, webgl, webgpu, webscraping

## 简介

Score a browser against itself: 52 checks over 20 fingerprint probes, cross-checked against what the TLS/HTTP layer actually saw. CLI + library for Playwright, Puppeteer and any browser with a debug port.
