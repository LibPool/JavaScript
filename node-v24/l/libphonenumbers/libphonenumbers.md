# libphonenumbers

> 标签: libphonenumber, libphonenumbers, phone, phonenumber, phonenumbers, phones

## 简介

JavaScript port of Google's libphonenumber library for parsing, formatting, and validating international phone numbers in Node.js.

## 官网

- 官网：https://libphonenumbers.js.org
- 源码仓库：git+https://github.com/Bunlong/libphonenumbers.git
