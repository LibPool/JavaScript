# laserbrain

> 标签: agent, agents, alignment, drift, goal, guardrail, harness, llm, mcp

## 简介

A goal-alignment harness for AI agents — holds the goal your agent stated first, frozen where it cannot revise it, and checks every later step against it. No model, no network, no key.
