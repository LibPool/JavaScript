# lumstate

> 标签: broadcast-channel, framework-agnostic, memory, no-storage, pinia, react, redux, session, state-management, store, svelte, vanilla, vue

## 简介

Framework-agnostic in-memory state management. No localStorage, no cookies. State lives in memory, syncs across tabs, and self-destructs on logout or tab close.
