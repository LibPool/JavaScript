# log-assistant

> 标签: console, debug, formatting, logger, logging, pretty-print

## 简介

美观实用的日志管理工具，解决开发中日志太多导致代码杂乱以及控制台输出不美观的问题

## 官网

- 官网：https://github.com/XcodeFish/LogMaster
- 源码仓库：git+https://github.com/XcodeFish/LogMaster.git
- npm 页面：https://www.npmjs.com/package/log-assistant

- npm registry：https://registry.npmjs.org/log-assistant
- Node 要求：>=12
