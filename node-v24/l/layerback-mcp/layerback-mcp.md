# layerback-mcp

> 标签: converter, diagram, drawio, flowchart, mcp, modelcontextprotocol, pptx, visio, vsdx

## 简介

MCP server for LayerBack — convert diagram images (PNG/JPG/screenshots/whiteboard photos) into fully editable Visio (VSDX), PowerPoint (PPTX), draw.io, and SVG files.
