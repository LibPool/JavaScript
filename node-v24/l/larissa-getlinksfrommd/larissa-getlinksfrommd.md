# larissa-getlinksfrommd

> 标签: JavaScript

## 简介

** Esta biblioteca se destina a identificação de markdowns, para uso em aplicações web. ** Na versão atual é capaz de fazer a identificação de markdowns, retorno em um array de objetos constituidos de chaves:valor contendo o texto e a url do markdown atra
