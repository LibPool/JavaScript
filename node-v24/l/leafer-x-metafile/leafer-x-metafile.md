# leafer-x-metafile

> 标签: emf, gdi, leafer, leaferjs, metafile, vector, wmf

## 简介

WMF / EMF+ metafile replay into neutral drawing members — a zero-dependency GDI record player (WMF placeable stream, EMF+ GDI+ records, embedded DIB extraction) for LeaferJS-based renderers
