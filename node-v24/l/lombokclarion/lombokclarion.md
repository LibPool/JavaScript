# lombokclarion

> 标签: explicit, framework, lombokclarion, php, serverless

## 简介

Frontend asset tooling for LombokClarion (PHP framework). CSS/JS are vendored under resources/ and content-hashed by `php bin/lombokclarion optimize` — npm is only used to refresh the vendored dist files.
