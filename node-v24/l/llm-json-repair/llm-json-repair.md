# llm-json-repair

> 标签: ai, anthropic, claude, fix, gpt, json, json-parser, json-repair, json5, llm, llm-json, openai, parse, partial-json, repair, standard-schema, structured-output, tool-calling, truncated-json, typescript, validation, zod

## 简介

Repair and parse broken JSON from LLM output (OpenAI, Claude, …) — fixes code fences, trailing commas, and truncated streams, then validates against your schema. Type-safe, zero-dependency, Standard Schema compatible
