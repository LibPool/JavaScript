# local-version-manager

> 标签: browser, client-side, file-manager, file-system-access-api, file-versioning, filesystem, framework-agnostic, local-storage, no-backend, version-control, versioning

## 简介

A browser-based, framework-agnostic file version control library using the File System Access API. No server. No database. Just the browser.
