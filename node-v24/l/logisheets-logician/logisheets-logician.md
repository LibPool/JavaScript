# logisheets-logician

> 标签: agent, ai, excel, llm, logisheets, mcp, spreadsheet, tools, xlsx

## 简介

AI agent tools for LogiSheets — platform-agnostic LLM tool definitions, prompts, and skills for operating a real spreadsheet engine. Powers Watson (the in-app assistant) and logisheets-mcp; reusable in any agent host.
