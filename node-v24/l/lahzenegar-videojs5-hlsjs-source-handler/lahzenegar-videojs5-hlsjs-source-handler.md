# lahzenegar-videojs5-hlsjs-source-handler

> 标签: JavaScript

## 简介

Adds HLS playback support to [video.js 5.0+](https://github.com/videojs/video.js) using [Dailymotion's hls.js library](https://github.com/dailymotion/hls.js).
