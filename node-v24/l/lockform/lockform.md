# lockform

> 标签: aes-gcm, bip39, curve25519, e2e, encryption, forms, lockform, webhook, x25519

## 简介

Official Lockform SDK: REST API client plus end-to-end encryption (X25519 + AES-256-GCM) for forms, submissions, files, and webhooks.
