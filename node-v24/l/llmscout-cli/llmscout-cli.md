# llmscout-cli

> 标签: aeo, agent-native, ai-seo, ai-visibility, answer-engine-optimization, chatgpt, claude, claude-code, cli, cross-platform, generative-engine-optimization, geo, google-ai-overviews, llm, llm-optimization, llms-txt, perplexity, seo, technical-seo, typescript

## 简介

Cross-platform LLM/GEO/AEO checker CLI in TypeScript. 21 technical-SEO and generative-engine-optimization checks, two runtime dependencies (cheerio, commander), no Python interpreter or headless browser required.
