# lombokcss

> 标签: classless, components, css, dark-mode, design-system, design-tokens, framework, glassmorphism, lightweight, neo-brutalism, rtl, theming, ui, utility-classes

## 简介

Token-first component CSS framework. One markup, five design styles (Corporate Flat, Resonant Stark, Neo-Brutalism, Semantic Minimalist, Glassmorphism), dark mode + RTL. ~9.7KB gzipped.
