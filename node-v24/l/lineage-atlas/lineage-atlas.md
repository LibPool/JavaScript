# lineage-atlas

> 标签: ai-agents, claude-code, dag, data-catalog, data-engineering, data-lineage, data-pipeline, dbt, documentation, graph, metadata, observability

## 简介

Search a column, see where it comes from and everything it feeds. Local lineage docs for data pipelines: import a dbt project in one command, let an AI agent document it, review its work on a graph.
