# l10n-for-node

> 标签: Browserless, L10N, L10N.js, Languages, Localisation, Localization, Node

## 简介

A customized implementation of L10N.js which better supports browserless environments, allowing you to run the code directly inside of node without requiring access to the document, self and XMLHttpRequest objects.
