# lyhna-verify

> 标签: attestation, ed25519, lyhna, offline-verification, receipts

## 简介

Independent, offline verifier for the Lyhna receipt corpus. Trusts no one: re-implements canonicalization + Ed25519 from scratch and depends only on Node's crypto (OpenSSL) + a pinned public key.
