# label-canvas

> 标签: JavaScript

## 简介

- Stage canvas容器对象，用于初始化canvas和储存场景对象,用于支持未来多个场景对象需求 - Scene 场景对象用于储存Canvas绘图对象和监听Canvas事件，每个场景相互独立，用于支持未来图层切换需求 - Object 标注对象，用于绘制一个矩形 这个版本还将支持圆形(完成),圆环(完成)，旋转矩形(完成)，多边形(施工中)，点阵(无法手动标注)的支持
