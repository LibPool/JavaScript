# lit-fn

> 标签: JavaScript

## 简介

一个基于 Lit 的函数式组件框架，提供类似 React Hooks 的能力，让你可以在 Web Components 中轻松使用 `useState`、`useEffect`、`useMemo` 等 Hooks。
