# lingokids

> 标签: JavaScript

## 简介

Configuration package for eslint built on top of [eslint-config-react-native-community](https://github.com/facebook/react-native/tree/HEAD/packages/eslint-config-react-native-community) and modified to meet Lingokids's own standards.
