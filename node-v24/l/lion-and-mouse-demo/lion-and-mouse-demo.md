# lion-and-mouse-demo

> 标签: JavaScript

## 简介

Demo of broccoli-lion-and-mouse, an absurd little BroccoliJS filter. Builds result in two subfolders, 'LION' and 'mouse', each containing a full copy of the source directory, but with all .txt files converted to ALL UPPERCASE and all lowercase, respective
