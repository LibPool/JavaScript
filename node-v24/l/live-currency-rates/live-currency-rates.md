# live-currency-rates

> 标签: conversion, convert, converter, currencies, currency, currency-conversion, currency-converter, currency-exchange, eur, exchange-rate, exchange-rates, finance, forex, gbp, live-rates, money, rates, realtime, usd

## 简介

Convert currencies with live exchange rates. Fluent API: Convert(100).from('USD').to('EUR'). Multiple providers (free, no key by default) — Frankfurter, fawazahmed0, AllRatesToday. Zero dependencies.
