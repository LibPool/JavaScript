# leaflet-color-cache-tile

> 标签: cache, canvas, color, javascript, leaflet, leaflet-color-cache, tile, typescript

## 简介

leaflet二维瓦片获取并动态改变整体配色方案，并加入持续缓存方案来避免重复请求处理。
