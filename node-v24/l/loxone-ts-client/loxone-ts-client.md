# loxone-ts-client

> 标签: home-automation, loxone, miniserver, smarthome, typescript, websocket

## 简介

The ultimate, fully type-safe TypeScript client for communicating with Loxone Miniservers (token/JWT auth, command encryption, live state updates, control commands).
