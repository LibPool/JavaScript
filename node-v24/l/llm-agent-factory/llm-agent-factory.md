# llm-agent-factory

> 标签: agent, checkpoint, claude, claude-code, codex, durable, fsm, llm, orchestration, pipeline, state-machine

## 简介

Typed framework for durable LLM agents: pipeline builder, FSM engine, durable checkpoints, and adapters for headless CLI providers (Claude Code, Codex CLI)
