# loopback4-nats-connector

> 标签: jetstream, loopback, loopback-extension, loopback4, messaging, nats, pub-sub, request-reply

## 简介

LoopBack 4 extension that exposes NATS as an injectable component — pub/sub, request/reply, queue groups, multi-connection isolation.
