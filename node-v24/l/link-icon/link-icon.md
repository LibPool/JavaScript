# link-icon

> 标签: icon, javascript

## 简介

自动在链接前面显示该链接对应的网站 logo，目前支持 36 个站点，包括知乎、微博、豆瓣、Twitter、Facebook 等，后期会持续增加。具体支持网站见 `src/icons.json`。
