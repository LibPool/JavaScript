# @dcrays/dsh-security-plugin

> 标签: JavaScript

## 简介

DeepSeek Harness (dsh) 安全防护插件（跨平台 macOS/Linux/Windows）：危险命令分级拦截（Unix + PowerShell/cmd）| 敏感信息脱敏 | 安全问题统一话术注入 | 危险文件写入审批 | 操作审计日志。能力与 @dcrays/mobook-security-plugin 对齐。
