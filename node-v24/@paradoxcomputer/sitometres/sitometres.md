# @paradoxcomputer/sitometres

> 标签: basecamp, e2e, logos, qml, qt, ui-testing

## 简介

UI test runner for Logos Basecamp apps: drives real clicks through the QML inspector and proves from the logs that the expected backend calls fired and succeeded.
