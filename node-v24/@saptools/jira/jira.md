# @saptools/jira

> 标签: api-token, atlassian, basic-auth, cli, jira, oauth, saptools

## 简介

Jira Cloud CLI and typed API that authenticate with an Atlassian API token or the shared JiraOps OAuth token store, read and update issues, create new tickets, and attach files
