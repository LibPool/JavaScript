# @evamaps/sdk

> 标签: map, maps, openstreetmap, osm, карта, карты

## 简介

Лёгкая 2D-карта на тайлах OpenStreetMap: метки, фигуры, GeoJSON, кластеры, геокодер. Без зависимостей, с типами TypeScript.
