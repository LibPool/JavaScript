# @zyplux/util

> 标签: concurrency, json, manifest, shell, utilities, zod

## 简介

Small utilities: assertions, polling, bounded-concurrency mapping, zod-validated JSON reads, repo-URL normalization, package.json/pyproject manifest schemas, and a git/gh shell harness
