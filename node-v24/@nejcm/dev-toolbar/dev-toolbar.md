# @nejcm/dev-toolbar

> 标签: developer-toolbar, devtools, diagnostics, feature-flags, observability, performance, react

## 简介

Extensible, low-overhead in-app developer toolbar for React applications: runtime health signals, feature flags, overlays and diagnostics.
