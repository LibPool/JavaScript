# @impulsem/centrifuge

> 标签: centrifuge, centrifugo, eventsource, pub/sub, real-time, sockjs, streaming, websocket, webtransport

## 简介

JavaScript client SDK for bidirectional communication with Centrifugo and Centrifuge-based server from browser, NodeJS and React Native (fork of centrifuge-js)
