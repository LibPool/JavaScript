# @type-ddd/date

> 标签: Base Value Object, Business Logic, Clean Architecture, Complexity, DDD, DDD-Utils, Date, Domain Driving Design, Formatting, Security, Standards, Utility, Validation, Value Object

## 简介

Library that provides TypeScript type definitions for handling Dates in Domain-Driven Design contexts. It facilitates the validation and manipulation of Dates.
