# @pixeljs/core

> 标签: audioworklet, canvas, game-engine, pixel-art, retro, typescript, wasm, webassembly, webgl2

## 简介

An independent C17/WebAssembly pixel engine for JavaScript and TypeScript: indexed graphics, tilemaps, bitmap text, input and an AudioWorklet synthesizer.
