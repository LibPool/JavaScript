# @lpextend/app-core

> 标签: JavaScript

## 简介

Framework-agnostic LP data layer for Extend apps — typed per-domain resource clients over the app's own API. Pure TS, no UI framework. The seam that lets Vue/React/Angular wrappers share one transport + types layer.
