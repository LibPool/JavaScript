# @fiscalcloud/mcp

> 标签: cfdi, facturacion, fiscalcloud, mcp, model-context-protocol, sat

## 简介

Servidor MCP para la API de timbrado CFDI 4.0 de FiscalCloud (integradores). Expone timbrar/validar/cancelar/saldo/comprobantes como herramientas para agentes de IA.
