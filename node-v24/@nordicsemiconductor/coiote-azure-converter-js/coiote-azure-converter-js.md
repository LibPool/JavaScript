# @nordicsemiconductor/coiote-azure-converter-js

> 标签: coiote, lwm2m, nrf-asset-tracker

## 简介

Convert the LwM2M JSON encoding written by AVSystem's Coiote Azure integration to nRF Asset Tracker's LwM2M JSON encoding.
