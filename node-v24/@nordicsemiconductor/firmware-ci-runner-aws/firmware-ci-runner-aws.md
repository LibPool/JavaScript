# @nordicsemiconductor/firmware-ci-runner-aws

> 标签: aws, end-to-end-testing, firmware, iot, nrf-asset-tracker

## 简介

Exposes real nRF9160 hardware to be used for end-to-end tests. Runs on AWS.
