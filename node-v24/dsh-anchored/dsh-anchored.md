# dsh-anchored

> 标签: anchor, coding-agent, deepseek-harness, dsh, dsh-plugin, file-edit, hashline, verified-edit

## 简介

Anchor-verified file editing for DeepSeek Harness: four-letter line anchors, stale-proof edits, and a guard that keeps shell/code from modifying files directly.
