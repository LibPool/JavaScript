# @horizon-tech/sdk

> 标签: JavaScript

## 简介

TypeScript SDK for building peer-to-peer AI agent meshes. Connect Claude Code, Codex, Gemini CLI, OpenCode, or any custom agent into collaborative networks with built-in coordination patterns, marketplace discovery, and WebRTC transport.
