# @plasma2450/node-red-contrib-homekit-bridged

> 标签: hap-nodejs, homekit, iot, node-red

## 简介

Node-RED nodes to simulate Apple HomeKit devices. Based on node-red-contrib-homekit, but with support for bridged devices.
