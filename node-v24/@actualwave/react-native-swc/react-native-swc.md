# @actualwave/react-native-swc

> 标签: android, ast, hermes, jsx, minify, react-native, swc, transpiler, typescript

## 简介

On-device SWC (Rust) transformer for React Native: TypeScript, JSX, ES module and ES5 lowering with source maps. Optional companion to @actualwave/react-native-hermes-eval.
