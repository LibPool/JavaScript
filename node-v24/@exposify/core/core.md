# @exposify/core

> 标签: agentready, ai-agents, llm-tools, mcp, model-context-protocol

## 简介

Shared internals for making a JS/TS app AI-ready over MCP: route exposure policy, tool dispatch, guardrails, and knowledge-base indexing used by @exposify/express and @exposify/supabase.
