# @exposify/next

> 标签: ai-agents, mcp, model-context-protocol, nextjs

## 简介

Expose a Next.js app's route handlers and Server Actions to AI agents over MCP: one route file, generated route table, tool calls over HTTP so your proxy/middleware auth still applies.
