# @exposify/token-broker

> 标签: ai-agents, jwt, jwt-bearer, mcp, model-context-protocol, oauth, oauth2, token-broker

## 简介

OAuth 2 / 2.1 / JWT Bearer token broker for MCP: mints a long-lived bearer token for the agent to hold, and transparently swaps it for a live, proactively-refreshed short-lived provider access token on every tool call.
