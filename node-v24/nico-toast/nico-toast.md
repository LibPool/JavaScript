# nico-toast

> 标签: angular, framework-agnostic, nextjs, notification, nuxt, react, svelte, toast, vue

## 简介

Framework-agnostic gooey, physics-based toast notifications. Works with Angular, React, Next.js, Vue, Nuxt, Svelte and plain JS.
