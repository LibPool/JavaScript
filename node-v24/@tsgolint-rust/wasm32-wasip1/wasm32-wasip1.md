# @tsgolint-rust/wasm32-wasip1

> 标签: linter, oxlint, tsgolint, typescript, wasi, wasm

## 简介

tsgolint-rust built for wasm32-wasip1, run on Node's WASI: the type-aware linter of oxlint where no native build runs. Install it as oxlint-tsgolint.
