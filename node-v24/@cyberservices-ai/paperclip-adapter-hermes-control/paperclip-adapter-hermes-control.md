# @cyberservices-ai/paperclip-adapter-hermes-control

> 标签: hermes, hermes-agent, nous-research, paperclip, paperclip-adapter

## 简介

Hermes Control adapter for Paperclip: the agent runs only in the Hermes profile explicitly assigned to it (assignments table shared with the plugin), launched with the administered Hermes binary and a controlled environment; configuration refusals are not
