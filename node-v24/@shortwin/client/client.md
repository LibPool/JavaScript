# @shortwin/client

> 标签: anchor, client, codama, short.win, shortwin, solana, solana-kit

## 简介

TypeScript client for the short.win Solana program, built on @solana/kit: typed instruction builders, account and event decoders, PDA helpers and error codes. Generated by Codama from the program IDL.
