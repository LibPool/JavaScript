# @unqa/ucss

> 标签: container-queries, css, css-variables, framework, mobile-first

## 简介

uCss is a modern, mobile-first, pure CSS framework designed for granular control, responsiveness, and flexibility. It leverages CSS Variables and Container Queries to provide a highly adaptable styling API without the need for complex build steps or JavaS
