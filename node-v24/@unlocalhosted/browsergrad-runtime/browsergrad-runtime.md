# @unlocalhosted/browsergrad-runtime

> 标签: browser, education, pyodide, python, webassembly, worker

## 简介

Pyodide-in-Worker runtime for browser-based Python execution. Same-origin assets, AbortSignal cancellation, structured assertion/artifact protocol. Platform-agnostic primitives — bring your own UI.
