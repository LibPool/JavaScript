# @queldrex/enforce

> 标签: agent, ai, claude, enforcement, governance, mcp, prompt-injection, security, tool-use, zero-trust

## 简介

Drop-in enforcement for AI agents — authorize every tool call through the Queldrex Trust Layer (allow / require approval / deny) before it runs, in code or as an inline MCP gateway. Fail-safe, zero-dependency.
