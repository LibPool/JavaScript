# @ziven.zhou/agent-foundation

> 标签: JavaScript

## 简介

智能体规范行为基础框架。适用于 OpenClaw、Claude Code、Trae、Cursor、Copilot 等任意 AI 编程/对话智能体。为智能体建立长期记忆、用户习惯跟踪、项目上下文持久化、操作安全确认等规范行为。
