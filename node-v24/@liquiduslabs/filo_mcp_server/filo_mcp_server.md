# @liquiduslabs/filo_mcp_server

> 标签: claude, filo, mcp, model-context-protocol, photo-editor

## 简介

MCP bridge for the FILO photo editor. Lets AI assistants (Claude Desktop, Gemini CLI, and others) view and edit the open FILO document.
