# @ruas-icons/ui

> 标签: chart, combobox, command-palette, components, dashboard, datatable, equalizer, indonesia, nextjs, otp, progress, react, ruas, rupiah, sidebar, toast, ui

## 简介

Komponen dasbor bergaya Ruas untuk React/Next.js: kerangka dasbor, tabel berpaginasi (pilih baris, CSV), isian (OTP, Rupiah, cari pilihan, rentang tanggal, unggah), toast, palet perintah, KPI dan grafik.
