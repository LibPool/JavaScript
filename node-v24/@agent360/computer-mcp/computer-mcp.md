# @agent360/computer-mcp

> 标签: accessibility, agent, automation, claude, computer-use, macos, mcp, model-context-protocol, privacy

## 简介

Computer use you can actually leave running. Passwords are blacked out before the screenshot leaves your Mac, every write asks first, everything is logged. No account, no API key, MIT.
