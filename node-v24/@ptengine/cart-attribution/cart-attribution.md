# @ptengine/cart-attribution

> 标签: attribution, cart-attributes, headless, ptengine, shopify, zero-dependency

## 简介

Zero-dependency order attribution for Shopify headless storefronts — writes Ptengine __pt_* identity into cart attributes, no analytics events, no framework required
