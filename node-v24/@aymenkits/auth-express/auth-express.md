# @aymenkits/auth-express

> 标签: auth, authentication, express, jwt, oauth, otp, passwordless

## 简介

Express 4/5-compatible adapter for @aymenkits/auth-core — requireAuth/optionalAuth middleware, claim guards, standard endpoint handlers and error mapping. Envelope-agnostic, structural req/res typing.
