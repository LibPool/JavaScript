# @ds-hu/dsh-pocket

> 标签: cordis, deepseek, deepseek-harness, dsh, dsh-plugin, dsh-pocket, gitee, github, mobile, oauth2, qr-code, remote-access

## 简介

把 DeepSeek Harness 装进你的口袋：单端口 3081 + Gitee / GitHub OAuth 登录（初始化时二选一），自建隧道（固定域名）即可远程实时同屏访问电脑上的 DSH。
