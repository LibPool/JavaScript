# @erpbridge/sdk

> 标签: agent, ai, client, erpbridge, logs, mcp, metrics, model-context-protocol, prometheus

## 简介

TypeScript client library for the ERPBridge server family — MCP tool calls, REST tool invocation, log aggregation, metrics, cache, and health.
