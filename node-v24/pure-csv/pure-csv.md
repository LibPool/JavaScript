# pure-csv

> 标签: csv, csv-injection, large-files, parser, rfc4180, schema, stream, streaming, stringify, tsv, validation, writer, zero-dependency

## 简介

Zero-dependency streaming CSV parser and writer for Node.js: RFC 4180, GB-size files with flat memory, schema validation, safe type casting, formula-injection protection, encodings and precise errors.
