# @scryve-tools/ckb-wallet-auth

> 标签: authentication, bitcoin, ckb, evm, joyid, nervos, omnilock, wallet

## 简介

Multi-chain wallet authentication for CKB — supports CKB, EVM, BTC, and JoyID wallets via challenge-response nonce flow and OmniLock address derivation.
