# @chenbz/wmp-lazy-image

> 标签: JavaScript

## 简介

**wmp-lazy-image** 是一款微信小程序图片懒加载**自定义组件**，当图片过多时，只加载**可视区域**的图片，避免过多占用网络请求，使用**wmp-lazy-image** 可让您更专注于业务逻辑。
