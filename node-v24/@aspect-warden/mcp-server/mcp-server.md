# @aspect-warden/mcp-server

> 标签: JavaScript

## 简介

MCP (Model Context Protocol) server that gives AI agents policy-enforced wallet capabilities on Sepolia. Works with Claude Desktop, OpenClaw, and any MCP-compatible client.
