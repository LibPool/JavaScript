> 标签: api client, api requests, axios alternative, fetch wrapper, http client, http requests, interceptor, javascript, ky alternative, lightweight, middleware, nodejs, react, request library, retry, typescript

## 简介

Kyro is a lightweight, middleware-based HTTP client for JavaScript and TypeScript built on top of the native Fetch API. It provides a composable request pipeline that allows developers to intercept, modify, and extend HTTP requests and responses with ease
