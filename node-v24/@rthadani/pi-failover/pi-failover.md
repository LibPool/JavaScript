# @rthadani/pi-failover

> 标签: failover, fallback, llm, model, pi, pi-package, provider

## 简介

A pi provider extension that fails over across an ordered list of compatible models (grouped into capability classes) when a provider runs out of credits or errors, so agent runs never stop when one wallet empties.
