# @mesub/react

> 标签: mesub, react, sdk, solana, subscriptions, usdc, wallet, widget

## 简介

React widget for Mesub: the wallet part of subscribing, cancelling, resuming and closing, on top of the routes @mesub/node mounts on your server.
