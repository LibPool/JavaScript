# @conorbronsdon/postlint-mcp

> 标签: ai, bluesky, character-count, claude, grapheme, linkedin, mastodon, mcp, social, twitter-text

## 简介

MCP server that checks a social post against a platform's real character limit — X t.co URL weighting, Bluesky graphemes, LinkedIn, Threads, Mastodon. Pure compute, no network.
