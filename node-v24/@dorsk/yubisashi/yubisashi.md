# @dorsk/yubisashi

> 标签: coding-agent, devtools, feedback, iframe, picker, postmessage, review, svelte, svelte5, vite-plugin

## 简介

Point at elements of your running app from a review panel: an iframe picker, a Vite plugin and a `yubi dev` proxy that inject it in dev.
