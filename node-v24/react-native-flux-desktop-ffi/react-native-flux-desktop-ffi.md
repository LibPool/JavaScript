# react-native-flux-desktop-ffi

> 标签: JavaScript

## 简介

Independent FFI branch for react-native-flux-desktop: call native DLL/dylib/so exports via declarative signatures (napi-rs + libloading + libffi). Opt-in, keeps the main package lean.
