# @openaip/yaixm-to-geojson

> 标签: aixm, format, geosjon, openaip, yaixm

## 简介

Converts YAIXM to GeoJSON. YAIXM is a simplified version of the FAA/EUROCONTROL Aeronautical Information Exchange Model (AIXM) using YAML.
