# @broberg/cmdk

> 标签: broberg, cmd-k, cmdk, command-palette, fuzzy-search, headless, keyboard-navigation, quick-actions

## 简介

Headless Cmd+K command-palette core: a framework-free fuzzyFilter (ranked subsequence match), a createPaletteController state machine (open/query/results/active-index with wrap-around keyboard nav + Enter activation), and a quota-safe localStorage recents
