# @broberg/deploy-core

> 标签: broberg, cloudflare, deploy, fly, flyio, hmac, machines, sync

## 简介

Fly Live HMAC incremental content-sync and a Fly.io client (Machines REST + the GraphQL the fleet uses) — the shared deploy execution layer for the broberg.ai fleet.
