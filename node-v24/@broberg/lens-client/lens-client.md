# @broberg/lens-client

> 标签: broberg, browser-automation, client, e2e, hono, hosted, lens, proxy, screenshot, self-healing-locators

## 简介

Thin client for the HOSTED Lens (lens.cardmem.com) — createLensClient({baseUrl,token}).capture()/.runFlow() with cold-start retry + self-healing LocateSpec, and an optional mountable Hono proxy (createLensProxy) so a product frontend hits /api/lens/* same
