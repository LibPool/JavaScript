# @broberg/mail-templates

> 标签: broberg, email, email-templates, mail-templates, multi-tenant, template-override

## 简介

The engine behind a mail template: a block model (paragraph, heading, note, button, divider, html) and brand, the one correct render order with escaped placeholders, a per-tenant override over a coded default, and the content hash a host versions on. Stor
