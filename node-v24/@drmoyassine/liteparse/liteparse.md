# @drmoyassine/liteparse

> 标签: document, docx, extraction, isomorphic, ocr, pdf, pdfjs, vision, vlm, xlsx

## 简介

Isomorphic document text extraction (PDF, Office, images) with swappable raster/OCR/VLM adapters. Runs in the browser, Node, and Deno/edge.
