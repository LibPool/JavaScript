# pi-context-engine

> 标签: code-search, context-engine, memory, pi-extension, pi-package, semantic-search, token-savings, tree-sitter, vector-search

## 简介

Semantic code context for pi: tree-sitter index + hybrid vector/BM25 retrieval + cross-session memory, all local. Port of code-context-engine (MIT, elara-labs) as a native pi extension.
