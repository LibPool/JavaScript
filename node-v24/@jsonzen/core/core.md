# @jsonzen/core

> 标签: csv, diff, format, jmespath, json, json-schema, jsonpath, jwt, minify, pydantic, typescript, validate, yaml, zod

## 简介

Pure-TypeScript JSON engine: format, validate, diff, query, convert. The library behind jsonzen.dev and the jsonzen CLI.
