# @feego/react-functional-form

> 标签: controlled, field-array, form, forms, hooks, nested-forms, react, standard-schema, typescript, valibot, validation, zod

## 简介

Schema-first, fully controlled, composable forms for React — with nested forms, field arrays, async validation and Standard Schema (Zod, Valibot, ArkType) support.
