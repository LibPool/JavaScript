# @peter.naydenov/visual-controller-for-lit

> 标签: MFE, lit, lit-html, micro-frontend, visual controller, web-components

## 简介

Tool for building micro-frontends(MFE) based on Lit components - Start multiple Lit applications on the same HTML page and control them
