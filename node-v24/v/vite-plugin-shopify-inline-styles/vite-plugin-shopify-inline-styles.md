# vite-plugin-shopify-inline-styles

> 标签: critical-css, css, inline-styles, performance, shopify, shopify-theme, vite, vite-plugin, web-performance

## 简介

Vite plugin for Shopify themes: render each section/snippet's built CSS as an inline <style> tag via inline_asset_content
