# vibetrace-cli

> 标签: 0g, ai, proof-of-build, provenance, vibe-coding

## 简介

Local-first proof-of-build ledger for AI-assisted software. `npx vibetrace-cli` collects your local AI-agent build traces, hashes them, and publishes an inspectable public build story with a build score.
