# verkstaden5-vectric-database

> 标签: JavaScript

## 简介

Välkommen till den officiella verktygsdatabasen från [Verkstaden5](https://verkstaden5.com). Denna databas (`.vtdb`) är skapad för användare av Vectrics programvaror (VCarve Desktop, VCarve Pro, Cut2D och Aspire).
