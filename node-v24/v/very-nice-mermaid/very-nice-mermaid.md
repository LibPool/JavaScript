# very-nice-mermaid

> 标签: dagre, diagram, flowchart, interactive, mermaid, renderer, svg, web-component

## 简介

A framework-agnostic Mermaid flowchart renderer: parse the DSL, auto-layout with dagre, and render beautiful interactive HTML, static SVG, PNG, or ASCII — no mermaid.js runtime, no headless browser.
