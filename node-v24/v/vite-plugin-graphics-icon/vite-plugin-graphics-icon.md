# vite-plugin-graphics-icon

> 标签: color-font, colorfont, graphics, icons, image-optimization, imagemin, sharp, sprite-sheet, svg-sprite, svg-symbol, svgo, vite-plugin, webfont

## 简介

Umbrella Vite plugin composing colorfont color-webfont + bitmap sprite sheets + SVG symbol sprites + imagemin, with one shared cache dir and on-demand loading.
