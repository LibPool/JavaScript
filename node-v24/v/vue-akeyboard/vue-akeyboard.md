# vue-akeyboard

> 标签: akeyboard, keyboard, vue

## 简介

本项目是一个vue虚拟键盘项目，基于<a href="https://github.com/18510047382/A-Keyboard">akeyboard</a>改造，修改了部分样式，并支持自定义键盘。
