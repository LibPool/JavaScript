# vttool

> 标签: JavaScript

## 简介

```bash # 安装 npm i -g vttool # 打tag vttool tag <tagname> # 例子 vttool tag skytest # 打tag + 自动推送, 默认源使用origin, vttool tag skytest -a -u <upstream> #例子1 vttool tag skytest -a #例子2 vttool tag skytest -a -u origin ```
