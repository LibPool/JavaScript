# vscode-theme-jetbrains-new-ui

> 标签: JavaScript

## 简介

Introducing a vibrant and enriched theme inspired by JetBrains' new UI - Int UI. Packed with an array of vivid colors and an extensive collection of icons, it transforms and enhances your user interface.
