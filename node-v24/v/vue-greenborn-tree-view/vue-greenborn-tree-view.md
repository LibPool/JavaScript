# vue-greenborn-tree-view

> 标签: arbol, greenborn, lazy-load, lazy-loading, tree, tree-view, vue, vue3

## 简介

Vista de árbol genérica para Vue 3 con carga diferida (lazy-load): trae primero los nodos raíz y, al expandir cada nodo, pide sus hijos mediante una función `cargarNodos(nodoPadre)` que provee el consumidor. No asume ningún backend ni forma de dato en par
