# vite-plugin-airx

> 标签: JavaScript

## 简介

Vite 插件，用于将 Airx JSX 转换接入 Vite 项目。 默认使用 automatic JSX runtime（`airx/jsx-runtime`）。

- 源码仓库：git+https://github.com/airxjs/vite-plugin.git
