# vue_ku

> 标签: vue, vue ui, vue ui 框架, vue 框架, vue_ku

## 简介

vue_ku是一款ui组件库。ui界面与业务分离，可以自定义ui界面，绑定业务逻辑功能，解决ui无法还原原型ui图。
