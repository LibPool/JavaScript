# vuepress-plugin-readmore-popular-next

> 标签: openwrite, readmore, vuepress-plugin-readmore, vuepress-plugin-readmore-popular-next, vuepress2, 公众号引流, 文章隐藏, 阅读更多

## 简介

为 VuePress 博客的每一篇文章都自动添加阅读更多的效果，关注公众号后方可解锁全站文章，从而将博客流量引流到微信公众号，达到涨粉丝数的目的。
