# view-anchor

> 标签: bounds, dom, geometry, layout, overlay, react, react hook, resize observer, resizeobserver, tree-shakeable, typescript

## 简介

High-performance geometry bridge that measures a DOM element and synchronously gives application code its current bounds: deduplicated updates, optional versioned message batching, React adapter, framework-free core.
