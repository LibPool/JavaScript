# vloop-skill

> 标签: agent-skills, agentic-workflow, ai-agents, autonomous-agents, claude-code, codex, loop-engineering, opencode, ralph, skill

## 简介

Three-layer closed-loop engineering skill for AI coding agents (plan-execute / acceptance-redesign / human-review). Installs into 40+ SKILL.md-compatible hosts: claude, codex, opencode, cursor, gemini, copilot, droid, zcode, antigravity, and more.
