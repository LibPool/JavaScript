# vue-rex

> 标签: ahooks, axios, react-query, vue-hooks, vue-query, vue-request, vue-rex

## 简介

Vue Rex 是一个面向 Vue 3 的高度灵活、类型安全且插件化的请求 Hook 库，支持多后端适配、缓存、分页、插件化扩展等特性。
