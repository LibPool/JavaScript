# vibecoder-cli

> 标签: agent, ai, autonomous, cli, coding-agent, free, llm, ollama, open-source, terminal

## 简介

A free, open-source AI coding agent that runs in your terminal. Fully yours — no payments, no artificial limitations, anything is customizable. Runs on Node or Bun; works online (free-tier cloud models) or fully offline with local Ollama.
