# vinita-sdk

> 标签: vinita-sdk

## 简介

This Project is a Simple ReactJS Project which demonstrates the following 1. Creating a Component in React 2. Making HTTP calls 3. Communicating between parent and child component 4. Using Bootstrap along with React 5. Using Basic Routing in React
