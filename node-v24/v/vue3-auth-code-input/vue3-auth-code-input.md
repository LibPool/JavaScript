# vue3-auth-code-input

> 标签: code, input, vue3, vue3-auth, vue3-code, vue3-input, vue3-input-auth, vue3-input-code

## 简介

这是一个基于 Vue 3 和 TypeScript 开发的验证码输入组件，适用于需要用户输入验证码的场景。它提供了灵活的配置选项，以适应不同的需求。
