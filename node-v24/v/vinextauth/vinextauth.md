# vinextauth

> 标签: authentication, cloudflare-workers, edge-runtime, nextauth, oauth, vinext, web-crypto

## 简介

Drop-in NextAuth v4 replacement for Vinext + Cloudflare Workers. Zero Node.js dependencies, pure Web Crypto API.
