# vue-cli-plugin-nid

> 标签: vue, vue-cli

## 简介

这是[宁皓网](https://ninghao.net)内部项目使用的一个 Vue CLI 插件，在使用了 TypeScript 的 Vue 项目里，可以用命令生成应用需要的组件与 store 模块。

## 官网

- 官网：https://ninghao.net/
- 源码仓库：git+https://github.com/ninghao/vue-cli-plugin-nid.git
- npm 页面：https://www.npmjs.com/package/vue-cli-plugin-nid
