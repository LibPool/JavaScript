# vscode-claude-code-status-dot

> 标签: claude, claude-code, patch, status-indicator, vscode

## 简介

5-state status dots on every Claude Code tab (idle/running/done/pending/interrupted) + bottom 4-light aggregate + per-session token usage & $ cost + favorites sidebar (★) + completion/interruption notifications — minimal, reversible VSCode patch with auto
