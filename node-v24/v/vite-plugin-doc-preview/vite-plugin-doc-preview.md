# vite-plugin-doc-preview

> 标签: doc, markdown, marked, preview, react, vite, vue3

## 简介

基于Vite插件机制实现对markdown文件内容进行转换。核心通过marked结合hightlight.js实现代码高亮和美化。并且可让文档中带有如preview指定标识的markdown代码块替换为组件，体验预览效果。支持Vue和React框架。
