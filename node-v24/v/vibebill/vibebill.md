# vibebill

> 标签: accounting, ai, aider, claude-code, codex, cost, gemini-cli, git, tokens

## 简介

Local, zero-config, git-native cost accountant for AI-assisted repositories. Parses real agent session logs, joins token usage to git history, and answers: what did this commit cost?
