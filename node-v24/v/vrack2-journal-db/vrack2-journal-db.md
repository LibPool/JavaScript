# vrack2-journal-db

> 标签: append-only, columnar, compression, database, delta-encoding, dictionary-encoding, event-log, journal, metrics, quantile, retention, rle, scan, time-series, wal

## 简介

Append-only columnar journal DB for Node.js: gzip/zstd, dictionary/delta/RLE/numeric-codec columns, WAL with crash-safe flush, time-range queries that skip whole files via .meta sidecars, plus a metric engine: summaries, aggregate/timeline, vector scan, q
