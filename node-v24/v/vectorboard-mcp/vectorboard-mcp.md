# vectorboard-mcp

> 标签: canvas, claude, codex, cursor, gemini, mcp, model-context-protocol, vectorboard, whiteboard

## 简介

Connect VectorBoard, the infinite board for people and AI agents, to any MCP client (Claude, Cursor, VS Code, Codex, Windsurf, Gemini CLI and more).
