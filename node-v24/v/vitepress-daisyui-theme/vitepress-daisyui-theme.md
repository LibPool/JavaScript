# vitepress-daisyui-theme

> 标签: daisyui, docs-theme, documentation, tailwindcss, vitepress, vitepress-theme

## 简介

A VitePress theme skinned with DaisyUI 5 (on Tailwind CSS 4). Doc + page layouts, full DefaultTheme.Config compatibility, built-in local search, i18n, breadcrumb, team page, math.
