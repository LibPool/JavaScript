# vellum-pdf-engine

> 标签: JavaScript

## 简介

Local PDF processing engine and CLI (merge, split, watermark, PDF/A, accessibility, signatures...) — no network calls, ever. Same code as vellumpdf.ch.

## 官网

- 官网：https://vellumpdf.ch
- 源码仓库：git+https://github.com/mabebakatala-cmyk/vellum-engine.git
- npm 页面：https://www.npmjs.com/package/vellum-pdf-engine
