# vue-component-usage

> 标签: JavaScript

## 简介

#### Description 基于babel plugin的vue组件被使用情况收集整理为树形结构展示，解决了以下问题： 1.组件名在vscode全局关键字查找是和变量名同名，匹配出来太多而不明显 2.vscode在全局搜索关键字（组件名）时会有遗漏
