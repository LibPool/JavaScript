# vue-gray-plugin

> 标签: css、置灰、gray

## 简介

vue-gray-plugin 是一个用于在Vue.js应用中添加页面置灰效果的插件。它允许你轻松地配置全局页面置灰，并提供了一种非常配置化的方式来控制页面的灰度效果。
