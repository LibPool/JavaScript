# videojs-vtt-thumbnails-freetube

> 标签: videojs, videojs-plugin

## 简介

Display thumbnails on progress bar hover, driven by external VTT files. Forked from https://github.com/chrisboustead/videojs-vtt-thumbnails.git in order to be maintained for the FreeTube project (https://github.com/FreeTubeApp/FreeTube-Vue).
