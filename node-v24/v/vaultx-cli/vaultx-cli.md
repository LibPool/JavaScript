# vaultx-cli

> 标签: JavaScript

## 简介

Installer for the vaultx native CLI: detects your platform, downloads the matching prebuilt vaultx binary from GitHub Releases, verifies its SHA-256 checksum, and exposes the `vaultx` executable. Contains no secret-management logic and no telemetry.
