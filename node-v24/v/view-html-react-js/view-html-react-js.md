# view-html-react-js

> 标签: blob iframe, dynamic html react, embed html next js, html preview react, html to iframe react, react forwardref iframe, react html embed, react html inside iframe, react iframe component, react render html, render third-party widget in react, sandbox iframe react, secure html viewer react, ssr safe html viewer, typescript html viewer

## 简介

Securely embed raw HTML inside a sandboxed iframe using React and TypeScript. Ideal for visualizations, maps, and WYSIWYG content.
