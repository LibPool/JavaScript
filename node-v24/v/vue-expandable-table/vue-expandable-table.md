# vue-expandable-table

> 标签: JavaScript

## 简介

`vue-expandable-table` is a highly customizable Vue.js component designed for displaying tabular data with the added functionality of expandable rows. It supports customizable styling for borders, cell padding, header and data cell backgrounds, and expand
