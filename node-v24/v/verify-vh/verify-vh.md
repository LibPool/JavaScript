# verify-vh

> 标签: attestation, evidence, keccak, merkle, offline, provenance, tamper-evident, verify

## 简介

Standalone, read-only, OFFLINE verifier for verifyhash artifacts (evidence seals, reconciliation seals, dataset attestations, proof bundles). Near-zero-dependency: js-sha3 + a tiny vendored secp256k1 recovery — explicitly NO ethers/hardhat, so a third par
