# vue-wafer-painter

> 标签: components, ui, vite, vue, vue2, vue3, wafer, wafermap

## 简介

The Wafermap component library based on Vue 3 provides a versatile and customizable solution for visualizing wafermaps, commonly used in semiconductor manufacturing.
