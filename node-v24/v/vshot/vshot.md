# vshot

> 标签: build-metadata, build-number, bump-version, cli, git, git-release, git-tag, npm, release, release-automation, release-cli, semver, version, version-bump, versioning

## 简介

Fast release CLI for Node.js: bump semver, generate build metadata, commit, tag, push, and update your changelog in one command.
