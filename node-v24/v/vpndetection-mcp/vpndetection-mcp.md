# vpndetection-mcp

> 标签: agent, fraud-prevention, ip-intelligence, llm, mcp, model-context-protocol, proxy-detection, tor, vpn, vpn-detection

## 简介

Official MCP server for the VPNDetection API. Gives an LLM agent VPN, proxy, Tor, hosting and CDN detection for any IP address.
