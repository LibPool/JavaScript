# vp-theme-gitlab-api

> 标签: blog, documentation, generator, theme, vue, vuepress

## 简介

在 VuePress 的知识管理兼博客主题 vuepress-theme-vdoing 基础上添加调用gitlab api，实现文件管理，以满足需求。
