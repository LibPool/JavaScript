# video-action-mcp

> 标签: claude, claude-code, mcp, model-context-protocol, ocr, transcription, video, youtube

## 简介

MCP server that lets Claude watch and listen to videos (local files or YouTube links) through Video Action Agent: transcript, on-screen text, and what was observed vs. not confirmed.

## 官网

- 官网：https://videoactionagent.web.app
- npm 页面：https://www.npmjs.com/package/video-action-mcp
