# visual-regression-viewer

> 标签: CLI, image diff, report viewer, run manifest, screenshot testing, visual diff, visual regression testing

## 简介

Review a visual regression run in the browser: reads the visual-regression-manifest files of a run, builds a self-contained HTML viewer, serves it locally or writes it to disk. Themeable with CSS variables, the page template is replaceable.
