# vue-cli-plugin-local-template

> 标签: JavaScript

## 简介

用插件来执行本地插件， 有些模版是为单个仓库服务的，弄成一个仓库来维护很麻烦。这个插件用来跑仓库内的模版

## 官网

- npm 页面：https://www.npmjs.com/package/vue-cli-plugin-local-template
