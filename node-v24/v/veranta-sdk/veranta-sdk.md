# veranta-sdk

> 标签: base, defi, perpetuals, sdk, trading, veranta, viem, wagmi

## 简介

Official TypeScript SDK for Veranta v2 - perpetuals on Base. viem-based, API-first (no ABIs), gasless via the Veranta relayer, with React hooks at veranta-sdk/react and an AWS KMS signer at veranta-sdk/kms.
