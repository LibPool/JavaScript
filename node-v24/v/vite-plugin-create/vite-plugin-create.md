# vite-plugin-create

> 标签: react vite plugin, vite, vite code generator, vite plugin, vite plugin generate, vite react component generator, vite scaffold, vite template cli

## 简介

A Vite plugin and CLI tool for scaffolding React components, stores, and pages using customizable templates. Supports TypeScript and modern Vite projects.
