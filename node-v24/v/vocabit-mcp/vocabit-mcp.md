# vocabit-mcp

> 标签: claude, flashcards, language-learning, mcp, model-context-protocol, spaced-repetition, vocabit

## 简介

MCP server for Vocabit — let an AI assistant build flashcard sets inside a real language-learning app and read back how the learner actually did.
