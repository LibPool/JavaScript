# vue-alpha-player

> 标签: alpha, player, video, vue, webgl, 双通道透明视频播放, 礼物动效播放

## 简介

🎥 基于 WebGL 的双通道透明视频播放器 Vue 组件，专门用于播放包含透明通道的视频文件。该组件将视频的 RGB 数据和 Alpha 数据分别存储在视频帧的左右两部分，通过 WebGL 着色器技术实现透明视频的播放。支持 Vue 2.x 和 Vue 3.x，性能优异，易于集成。
