# vue-image-parser

> 标签: avif, decoder, heic, image, vue, vue3, wasm, web-worker, webp

## 简介

Universal image rendering engine for Vue — supports JPEG, PNG, WebP, GIF, HEIC, AVIF with WASM fallback and zero main-thread blocking
