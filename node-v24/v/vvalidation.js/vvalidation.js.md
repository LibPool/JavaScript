# vvalidation.js

> 标签: ajax, bootstrap5, form, javascript, lightweight, modal, validation, vanilla

## 简介

Light weight Vanilla Javascript Form Validation library. Validate your forms (data & files) with js and submit your data to the server with this library written in pure javascript.
