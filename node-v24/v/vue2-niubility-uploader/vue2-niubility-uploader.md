# vue2-niubility-uploader

> 标签: chunk uploader, uploader, vue uploader

## 简介

一个超好用的轻量的vue2上传组件，支持单/多文件上传、大文件分片上传、断点续传、上传队列控制、文件预览。A lightweight and easy-to-use Vue2 upload component, supporting single/multiple file uploads, large file chunking, resumable uploads, upload queue control, and file preview.
