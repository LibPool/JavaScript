# vite-plugin-prerender-spa

> 标签: lazy-import, lazy-load, modulepreload, pre-render, preload, prerender, spa, ssg, ssr, vite, vite-plugin

## 简介

Vite plugin to pre-render SPA routes into static HTML at build time while emitting accurate asset preloads for lazy imports the rendered routes actually trigger
