# vue-debug-plugin

> 标签: JavaScript

## 简介

实时监测vue实例的状态，挂载在window.$vm上，支持快速切换组件，支持微前端

- 源码仓库：git@gitee.com:zzmwzy/debug-plugin.git
- npm 页面：https://www.npmjs.com/package/vue-debug-plugin
