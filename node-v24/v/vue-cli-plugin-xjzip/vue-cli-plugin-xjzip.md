# vue-cli-plugin-xjzip

> 标签: JavaScript

## 简介

实现对 uni-app 框架构建出的 H5 代码进一步打包处理，生成可进行测试、产线环境进行部署的 `zip` 包。

- npm 页面：https://www.npmjs.com/package/vue-cli-plugin-xjzip
