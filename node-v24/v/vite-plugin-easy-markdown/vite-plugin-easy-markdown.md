# vite-plugin-easy-markdown

> 标签: frontmatter, markdown, vite, vue

## 简介

A vite project plugin to import Markdown file and automaticlly get its abbreviated info for list display. ## Setup ``` npm i -D vite-plugin-easy-markdown ``` ## Config Options I divide transform results into two categories: meta result and complete
