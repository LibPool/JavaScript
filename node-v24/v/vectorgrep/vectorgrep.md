# vectorgrep

> 标签: claude-code, code-search, embeddings, lancedb, mcp, semantic-search, vector-database

## 简介

MCP Server for vector-based semantic code search in Claude Code. Index your codebase locally with LanceDB and search code, files, and symbols using natural language.
