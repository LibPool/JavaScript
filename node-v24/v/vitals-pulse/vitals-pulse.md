# vitals-pulse

> 标签: ci, cls, core-web-vitals, github-action, inp, lcp, lighthouse, performance, sarif, web-vitals

## 简介

Fail CI on Core Web Vitals: reads Lighthouse, Lighthouse CI, PageSpeed Insights and web-vitals reports (or runs Lighthouse), takes the median per URL and gates LCP, CLS, TBT (lab INP proxy), INP, FCP and TTFB against thresholds and a baseline. SARIF, GitH
