# vinctor-mcp-pep

> 标签: ai-agents, authorization, mcp, pep, proxy, security, vinctor

## 简介

Vinctor MCP enforcement proxy (PEP): a stdio MCP proxy that authorizes every tools/call via Vinctor delegated enforcement before forwarding it to the real server.
