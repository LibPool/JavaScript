# vue3-event-calendar

> 标签: agenda, calendar, component-library, datepicker, day-view, event-calendar, events, hourly-calendar, month-view, planning, reka-ui, responsive, schedule, scheduler, tailwind-css, time-slots, typescript, vue, vue3, week-view

## 简介

Modern Vue 3 event calendar with hourly time slots, multiple views (month/week/day/agenda), and comprehensive event management. Built with TypeScript, Tailwind CSS v4, and Reka UI.
