# vite-plugin-tyro-camo

> 标签: assets, camouflage, laravel, manifest, obfuscation, vite, vite-plugin

## 简介

Stealth asset camouflage for Laravel and Vite: cloak compiled JS/CSS bundles under deterministic, inoffensive codenames while keeping manifest.json intact.
