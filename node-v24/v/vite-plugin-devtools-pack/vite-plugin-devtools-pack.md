# vite-plugin-devtools-pack

> 标签: devtools, dock, jotai, react, solid, tanstack, vite, vite-devtools, vite-plugin

## 简介

Vite 插件：把 TanStack Query / Router、Jotai、Solid Devtools 收进 Vite DevTools 的 dock 面板，按需启用，不再各占一个页面悬浮入口
