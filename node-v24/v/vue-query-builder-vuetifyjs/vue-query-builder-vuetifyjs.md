# vue-query-builder-vuetifyjs

> 标签: JavaScript

## 简介

Vue Query Builder is a user interface that makes it easy for your users to create queries of any kind. It's useful if you need an interface for generating reports, filtering data, and more. This fork move it to Vuetify.js
