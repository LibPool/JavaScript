# vue-custome-components

> 标签: components, element-plus, ts, vue3

## 简介

插件基于UI库 <strong>element-plus</strong>, <strong>@element-plus/icons-vue</strong>, 前端框架：<strong>vue3</strong> 来开发，插件主要包含一些日常常用的组件封装（table组件，动态表单组件...）.
