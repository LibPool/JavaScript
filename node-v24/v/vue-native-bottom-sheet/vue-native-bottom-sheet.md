# vue-native-bottom-sheet

> 标签: bottom-sheet, drawer, gesture, modal, nuxt, nuxt3, spring-animation, vue, vue3

## 简介

Production-ready bottom sheet for Vue 3 with native iOS/Android-like drag physics (velocity-based inertia, rubber-band, spring animations). Works standalone in any Vue 3 app and as a Nuxt 3 module.
