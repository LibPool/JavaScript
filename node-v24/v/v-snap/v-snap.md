# v-snap

> 标签: canvas, pixi, pixi.js, playwright, screenshot, snapshot, three, visual regression, visual testing, vitest

## 简介

Fast, consistent visual snapshot tests for views drawn on a canvas or in HTML, with support for Pixi and three.js: the same images on Windows, Linux and macOS, with no Docker
