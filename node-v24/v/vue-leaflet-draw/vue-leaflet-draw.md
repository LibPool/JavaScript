# vue-leaflet-draw

> 标签: leaflet, vue

## 简介

This is a plugin port to provide the [leaflet-draw-toolbar](https://github.com/justinmanley/leaflet-draw-toolbar) control on [Leaflet](https://leafletjs.com/) maps in [Vue](https://vuejs.org/) applications.
