# vexart

> 标签: cli, components, design-system, gpu, headless, jsx, kitty, pixel, rendering, solidjs, terminal, tui, ui, wgpu

## 简介

GPU-accelerated terminal UI engine. Write JSX, get browser-quality UI in your terminal. Anti-aliased corners, shadows, gradients, glow, backdrop blur — real pixels, not ASCII.
