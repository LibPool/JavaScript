# vouch-kb

> 标签: agent, claude-code, context-engine, knowledge-base, llm, mcp, memory, openclaw, wiki

## 简介

Git-native, review-gated knowledge base for coding agents. This npm package ships the OpenClaw plugin packaging (context engine + skills); the vouch engine itself is a Python package — install it from PyPI as vouch-kb.
