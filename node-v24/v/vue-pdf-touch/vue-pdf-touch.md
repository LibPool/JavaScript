# vue-pdf-touch

> 标签: pdf, touch, vue

## 简介

基于 vue-pdf 和 vue-touch 的一个实用实例。 用于PC与移动设备间预览PDF文件，可以通过链接远程加载，也可以通过接受基于Base64加密过的密文进行加载。具体详情请自行安装查看。 头部展示 上一页 与 下一页 还有 页码 信息。在移动设备上可以 左右滑动来切换页面。
