# vite-plugin-hulak-tools

> 标签: build-tools, client-side-templates, component-templates, dynamic-templates, frontend-tools, handlebars, handlebars-integration, handlebars-templates, html-imports, html-modules, html-partials, html-templates, javascript-templates, loader, partials, spa, static-templates, template-engine, template-loader, vite, vite-handlebars, vite-html, vite-plugin, vite-tooling

## 简介

Vite plugins that bridge vite-plugin-handlebars to JavaScript: import HTML templates as functions with partials, conditionals, and zero runtime dependencies.
