# vite-plugin-unirate

> 标签: currency, exchange-rates, fintech, forex, fx, money, unirate, vite, vite-plugin

## 简介

Vite plugin for UniRate — a build-time `virtual:unirate` module with baked currency rates/currencies, plus a dev-server proxy that keeps your API key server-side.
