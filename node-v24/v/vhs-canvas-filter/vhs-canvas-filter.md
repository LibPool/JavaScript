# vhs-canvas-filter

> 标签: analog, canvas, color-bleed, crt, glitch, image-effect, retro, scanlines, vhs, vhs-filter

## 简介

Apply deterministic VHS-style effects (scanlines, color bleed, noise) to RGBA pixels or a canvas. Zero deps, browser + Node.
