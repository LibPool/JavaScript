# voicegis-mcp

> 标签: cql2, geospatial, gis, mcp, model-context-protocol, ogc-api-features, voicegis

## 简介

MCP server that lets an agent query a spatial data service in plain language, grounded in the service's own catalog and bounded by permissions the operator sets
