# vercel-php-bridge

> 标签: build-utils, lambda, laravel, php, vercel, vercel-php

## 简介

Vercel build bridge for PHP. Reuses the static PHP runtime and launcher from vercel-php, but emits a lambda handler compatible with Vercel's current Node runtime.
