# vue-relative-rotation-chart

> 标签: animated-chart, chart, data-visualization, etf-rotation, financial-chart, market-rotation, portfolio-visualization, quadrant-chart, relative-momentum, relative-rotation-graph, relative-strength, rrg, rrg-chart, rs-momentum, rs-ratio, sector-rotation, stock-chart, stock-dashboard, svg, timeline-playback, typescript, vue, vue3

## 简介

Vue 3 SVG renderer for RRG-style stock, ETF, sector, index, and portfolio rotation charts with animated tails, playback controls, and PNG export.
