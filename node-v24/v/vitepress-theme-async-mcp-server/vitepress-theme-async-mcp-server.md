# vitepress-theme-async-mcp-server

> 标签: mcp-server, vitepress-theme

## 简介

使用 Vitepress-theme-async MCP Server，可以将主题配置说明信息当做数据源提供给 Cursor 等支持 AI 编程的 IDE 工具以便让 AI 能够直接根据你的需求修改配置。
