# vuepress-theme-custom

> 标签: blog, vue, vuepress

## 简介

基于z3by的[vuepress-theme-modern-blog](https://github.com/z3by/vuepress-theme-modern-blog)进行了一些自己的修改，因为并非对每个人都通用，所以没有提PR。为了使用方便，利于维护，因此单独发包。
