# visp-hyper-agent

> 标签: ai, ai-coding, claude-code, codex, coding-agent, copilot, developer-tools, evidence, git-hooks, mcp, workflow

## 简介

Runs the Visp workflow inside Codex, Claude Code, and Copilot. Prepares scoped handoffs and records checkpoint evidence. Makes no LLM calls of its own.
