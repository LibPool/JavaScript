# vue-greenborn-panels

> 标签: collapsible, drag, droppable, layout, panels, resizable, tabbar, tabs, vue, vue3

## 简介

Sistema genérico de paneles y tabs reordenables para Vue 3: registry singleton de tabs por slot, TabBar con drag & drop nativo, panel lateral colapsable con handle de resize y estado de layout (colapso/resize) sin Pinia. Sin dependencias de UI (CSS propio
