# verifyum-mcp

> 标签: mcp, model-context-protocol, notarization, proof-of-existence, provenance, solana, timestamping, verifyum

## 简介

Local MCP server for Verifyum: create and verify privacy-preserving file proofs anchored on Solana Mainnet. The file is hashed locally; only a domain-separated commitment leaves the machine.
