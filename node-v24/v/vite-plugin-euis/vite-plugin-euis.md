# vite-plugin-euis

> 标签: build-tool, cloud-ide, codesandbox, compiler, css, euis, lovable, stackblitz, vite, vite-plugin, wasm, webassembly

## 简介

Vite plugin for Euis (Euis) with Tailwind CSS compatibility - compile Euis to CSS with WebAssembly. Works in cloud environments like Lovable, StackBlitz, and CodeSandbox.
