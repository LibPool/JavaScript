# vuc3-ant-form

> 标签: JavaScript

## 简介

一个基于 [`vuc3`](https://github.com/yuexing91/vuc3) `ant-design-vue` 的可视化表单设计器，3分钟即可将自己的组件加入到 `vuc3-ant-form` 之中。

## 官网

- npm 页面：https://www.npmjs.com/package/vuc3-ant-form

- 0.1.0
