# van-gtk

> 标签: gtk, gtk4, gui, reactive, van

## 简介

A library lets you create GUI with [vanjs](https://vanjs.org) and [gjs](https://gjs.guide/guides/gtk/3/03-installing.html#installing-gjs) in a reactive way.
