> 标签: agent, ai, animation, claude, cli, components, copilot, cursor, gsap, interactive, mcp, mcp-server, model-context-protocol, motion, performance, react, react-three-fiber, requestanimationframe, shader, three, threejs, ui, webgl

## 简介

Motion runtime and WebGL/R3F component CLI for React, with an MCP server that tells your coding agent which primitive to use, how to wire it, and when not to.
