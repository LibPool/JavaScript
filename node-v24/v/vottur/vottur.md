# vottur

> 标签: ai, anthropic, azure-openai, fetch, jsonl, llm, logging, observability, ollama, openai, openrouter, tracing

## 简介

Automatic JSONL logging for LLM APIs. Drop-in wrappers for OpenAI SDK, OpenRouter SDK, or raw fetch calls.
