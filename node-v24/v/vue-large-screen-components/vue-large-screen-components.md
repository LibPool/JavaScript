# vue-large-screen-components

> 标签: JavaScript

## 简介

一个基于 **Vue 3 + TypeScript + GSAP** 的大屏可视化组件库，提供自动缩放容器、动态数字、文本、图表模板等通用组件，同时内置时间工具函数与动画插件，帮助你快速搭建炫酷的数据展示大屏。
