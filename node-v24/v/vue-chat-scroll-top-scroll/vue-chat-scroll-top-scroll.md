# vue-chat-scroll-top-scroll

> 标签: autoscroll, chat, room, scroll, top-load, vue, vue-directive

## 简介

Automatic, yet conditional, scroll-to-bottom directive for Vue.js 2.0 with emit scroll-top event when scroll to the top.
