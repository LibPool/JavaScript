# vue3-super-tree

> 标签: component, drag-drop, primevue, tailwindcss, tree, tree-view, typescript, vue, vue3

## 简介

一个功能强大、高度可定制的 Vue 3 树形组件，完全复刻 PrimeVue Tree 的功能特性，支持拖拽、多选、键盘导航等高级功能
