# var-jsx

> 标签: JavaScript

## 简介

It's jsx translator that can easily be used ```js const {jsx} = require(`jsx`); ``` it's done!\ now you can use `jsx.translate` to translate ```js jsx.translate(`const a = <div>hi!</div>`); ``` ```js const a = Var.make(`a`,[],Var.text(`hi!`));
