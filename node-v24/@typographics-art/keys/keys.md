# @typographics-art/keys

> 标签: ed25519, provenance, signatures, signing-keys, typogram, typographics-art, verification

## 简介

Verified Typographics Art issuer signing keys (Ed25519) and sealing keys (X25519). Published immutably so agents that can only reach npm or GitHub can still verify signed Typograms. No private keys.
