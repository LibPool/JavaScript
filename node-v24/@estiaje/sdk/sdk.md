# @estiaje/sdk

> 标签: alertas, datadog, estiaje, eventos, events, linaje, logs, monitoreo, monitoring, observabilidad, observability, opentelemetry, otlp, sentry, telemetria, telemetry, tracing

## 简介

Estiaje SDK — log() / event() / outcome(). Cero dependencias, fire-and-forget: jamás lanza, jamás frena a quien emite. Captura tus console.log, pino y winston con una línea, y los errores con su stack. Manda a Estiaje, a la consola, a cualquier backend OT
