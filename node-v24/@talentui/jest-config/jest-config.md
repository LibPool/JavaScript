# @talentui/jest-config

> 标签: JavaScript

## 简介

* 安装jest  enzyme ，react-addons-test-utils和@talentui/jest-config 别忘了save dev * 在package.json => scripts 添加 `jest --config jest.config.js` * 在项目根目录下创建jest.config.js， 作为jest的配置文件 * 在项目根目录下创建tests目录用来放测试用例
