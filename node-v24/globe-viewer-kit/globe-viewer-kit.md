# globe-viewer-kit

> 标签: 3d, cesium, digital-twin, earth, gis, globe, map, satellite, webgl

## 简介

开箱即用的 3D 地球视图库：一个 div 挂载，提供自动旋转、卫星影像切换、建筑白模、太阳光照、测量标记等能力（内部由 React + CesiumJS 驱动）
