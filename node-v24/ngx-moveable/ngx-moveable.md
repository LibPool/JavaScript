# ngx-moveable

> 标签: JavaScript

## 简介

An Angular Component that create Moveable, Draggable, Resizable, Scalable, Rotatable, Warpable, Pinchable, Groupable, Snappable.

- 源码仓库：git+https://github.com/daybrush/moveable.git#master
