# @kesteinbakk/my-kit-solid

> 标签: JavaScript

## 简介

The design-system kit for SolidJS apps — the complete component surface, the app-shell chrome (layout, navigation, page-header/tab system), the themes, and the Zing integration tier, built on Kobalte + Tailwind v4 against the shared --color-* theme tokens
