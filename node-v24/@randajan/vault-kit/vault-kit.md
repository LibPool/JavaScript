# @randajan/vault-kit

> 标签: cache, data, data-sync, files, javascript, js, kit, lightweight, memory, minimal, state, storage, store, sync, universal, vault, virtual

## 简介

A tiny and universal data vault that behaves like a writable file system. Store, sync, forget. Works on client and server.
