# @pascalcouturier/skill-builder-mcp

> 标签: agent-skills, claude, copilot, mcp, model-context-protocol, skill-builder

## 简介

Connect AI tools (GitHub Copilot, Claude Code, Codex, Cursor, Claude Desktop) to Skill Builder open in your browser, over MCP.
