# @antelopejs/interface-payment

> 标签: antelopejs, checkout, interface, payment, refund, webhook

## 简介

Provider-agnostic AntelopeJS payment interface: hosted checkout, direct payments with auth/capture, refunds, saved payment methods, and normalised webhook events
