# @antelopejs/dms-media

> 标签: antelopejs, assets, dms, dms-module, file-explorer, media

## 简介

Media library for the AntelopeJS DMS: uploads, folders with per-folder permissions, image sizes and light editing, with a Finder-style explorer.
