# @antelopejs/dms-saas

> 标签: antelopejs, billing, dms, dms-module, multi-tenant, saas, stripe

## 简介

SaaS module for the AntelopeJS DMS: self-service sign-up and pricing, plans that gate features, Stripe billing, workspace settings and a back office.
