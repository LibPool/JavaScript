# @unirate/qwik

> 标签: currency, currency-converter, exchange-rates, fintech, forex, fx, qwik, qwik-city, unirate, vat

## 简介

Qwik & Qwik City integration for the UniRate currency-exchange API. Server-safe client factory, routeLoader$-ready loader factories, a server$-friendly data API, a useUniRate helper, and a key-hiding proxy handler. Zero runtime deps.
