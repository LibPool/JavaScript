# @unirate/hono

> 标签: currency, currency-converter, exchange-rates, fintech, forex, fx, hono, hono-middleware, middleware, money, unirate, vat

## 简介

Hono middleware and router for the UniRate currency-exchange API. unirate() attaches a typed client to c.var.unirate; unirateRouter() mounts ready-made /rate, /convert, /currencies, /vat JSON routes with full error mapping. Zero runtime deps; runs on any
