# @frog755/dsh-prompt-vault

> 标签: deepseek-harness, dsh, plugin, prompt, prompt-vault

## 简介

Prompt Vault: 输入框上方的提示词库。📚 按钮展开面板，主题名 + 详情展开 + 一键填入输入框；支持新建/编辑/删除/搜索。数据持久化在 ~/.dsh/prompt-library.json。
