# workbuddy-skin-lite

> 标签: cdp, cli, electron, skin, theme, workbuddy

## 简介

Lightweight, zero-dependency CLI to apply custom skins (CSS + wallpaper) to WorkBuddy via the Chrome DevTools Protocol.
