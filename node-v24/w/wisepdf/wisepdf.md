# wisepdf

> 标签: javascript, layout, pdf, printing

## 简介

A fork from an amazing library, pdfmake. Can create pdf documents at client/server side.

## 官网

- 官网：http://pdfmake.org
- 源码仓库：git+https://github.com/wisedoc-inc/pdfmake.git
- npm 页面：https://www.npmjs.com/package/wisepdf
