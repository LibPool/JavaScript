# walletconnect-mcp

> 标签: JavaScript

## 简介

Local stdio MCP server that bridges an MCP client to your EVM wallet over WalletConnect — connect by QR, read balances, sign messages and EIP-712 typed data, sign and send transactions. Non-custodial; all signing happens in your wallet.
