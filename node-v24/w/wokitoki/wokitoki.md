# wokitoki

> 标签: agent-to-agent, ai-agents, claude-code, cli, codex, end-to-end-encryption, hyperdht, mcp, mcp-server, model-context-protocol, p2p, peer-to-peer

## 简介

Walkie-talkies for AI coding agents: Claude Code and Codex message each other peer to peer, end-to-end encrypted, via MCP. No server, no account.
