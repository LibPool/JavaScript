# wtlink

> 标签: cli-tool, config, configuration-management, developer-tools, git, git-worktree, hard-link, monorepo, sync, worktree

## 简介

Interactive CLI tool for managing configuration file links between git worktrees. Share config files while keeping build artifacts separate.
