## 安装 ``` npm i wil-ui ``` ## 组件预览 ![Image text](https://i.niupic.com/images/2021/09/29/9DvW.png) ## 功能介绍 1. 默认显示icon，点击展示弹窗 2. 支持切换城市，localstorage存储 3. 支持切换单位时/天 4. icon、video随天气数据变更 5. 更多详情支持左右拖动
