# web-terminal-agent

> 标签: agent, ai-tools, browser-terminal, claude-code, cli, remote-terminal, shell, terminal, web, web-terminal

## 简介

Local agent for TerminalMate - enables browser-based terminal access to your computer. Run CLI tools like Claude Code through a friendly web interface.
