# wdio-bstack-reporter

> 标签: browserstack, browserstack-test-management, reporter, test-management, test-observability, wdio, wdio-reporter, wdio-service, webdriverio

## 简介

WebdriverIO reporter and launcher service that creates a BrowserStack Test Observability build per execution batch and updates it live as tests run. Optional Test Management integration with live result streaming, scope discovery, and hook-failure handlin
