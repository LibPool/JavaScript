# weex-trading-mcp

> 标签: contract, crypto, exchange, futures, mcp, model-context-protocol, spot, trading, weex

## 简介

Model Context Protocol (MCP) server for the WEEX Exchange API (Spot V3 + Futures/Contract V3). Exposes market data and signed trading/account tools over stdio.
