# wickchart-ai

> 标签: agent, ai, chart, charting, llm, mcp, tools, trading, wickchart

## 简介

The wickchart chart as an LLM tool surface — a self-describing tool manifest, an agent system prompt, grounding context, and a validated op dispatcher. Bring your own model; the chart never touches the network.
