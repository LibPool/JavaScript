> 标签: android, chrome, edge, firefox, ie, internet-explorer, ios, javascript, javascript-library, library, multirtc, opera, p2p, peer, peer-to-peer, peer2peer, rtcmulticonnection, rtcmulticonnection.js, rtcweb, safari, webrtc, webrtc-experiment, webrtc-library

## 简介

RTCMultiConnection is a WebRTC JavaScript wrapper library runs top over RTCPeerConnection API to support all possible peer-to-peer features.
