# win-shell-mcp

> 标签: agent, ai, cli, cross-platform, mcp, mcp-server, shell, windows

## 简介

AI-native cross-platform command abstraction layer as MCP Server. Deterministic tools replacing raw shell commands, unified minimal JSON output, handles Windows path/encoding/quoting differences.
