# whisper-secrets

> 标签: aes-256-gcm, cli, dotenv, encryption, env, secret-management, secrets, zero-knowledge

## 简介

Secure, encrypted secret management CLI for teams. Zero-knowledge .env manager with client-side AES-256-GCM encryption.
