# webpack-multiple-plugin

> 标签: webpack, webpack-multiple, webpack-page, webpack-pages, webpack-pages-plugin, webpack-plugins

## 简介

> 这是一个组成多页面Webpack的插件，基于``html-webpack-plugin``，内部使用了``ejs``插件进行模板编译
