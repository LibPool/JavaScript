# waha-calls

> 标签: calls, voip, waha, wahacall, webrtc, whatsapp

## 简介

Client SDK for WhatsApp calls on WAHA (wahacall): config, browser softphone (WebRTC), events and raw PCM. WAHA-native auth, simple event-driven ergonomics.
