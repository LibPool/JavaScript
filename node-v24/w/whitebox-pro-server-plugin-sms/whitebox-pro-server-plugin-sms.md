# whitebox-pro-server-plugin-sms

> 标签: JavaScript

## 简介

SMS channel for whitebox — outbound (transactional + bulk), inbound replies with STOP/START opt-out, delivery-status (DLR) tracking, suppressions, invalid list. Pluggable provider (whitebox-pro-sms-twilio, whitebox-pro-sms-mobica, …) routed by destination
