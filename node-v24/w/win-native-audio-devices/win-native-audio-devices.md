# win-native-audio-devices

> 标签: IMMNotificationClient, audio-devices, core-audio, default-device, device-change, device-events, electron, microphone, napi, native-addon, node-addon-api, speakers, windows

## 简介

Native Windows addon for enumerating audio devices, detecting default devices, and subscribing to device change events (no audio capture).
