# whabuzz

> 标签: sdk, webhooks, whabuzz, whatsapp, whatsapp-cloud-api

## 简介

Official WhaBuzz SDK and CLI: send WhatsApp messages through the Cloud API gateway and verify signed webhooks. Zero dependencies, fetch-based.
