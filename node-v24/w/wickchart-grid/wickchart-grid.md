# wickchart-grid

> 标签: chart, charting, grid, multi-chart, sync, trading, web-component, wickchart

## 简介

Multi-chart grid + sync for wickchart — one element lays out N charts and keeps their visible ranges and crosshairs in step. Opt-in plugin, zero dependencies, zero core changes.
