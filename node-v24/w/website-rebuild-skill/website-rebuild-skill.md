# website-rebuild-skill

> 标签: agent-skill, agent-skills, claude-code, codex, forensics, reverse-engineering, web-archiving, webgl, website-clone, website-rebuild

## 简介

Agent Skill that rebuilds a website line by line from its own minified code and proves the rebuild with automated diffs — mirror-first forensics, verbatim porting, pixel-level verification gates. 复刻网站的 Agent Skill。
