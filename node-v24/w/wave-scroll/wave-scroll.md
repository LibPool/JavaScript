# wave-scroll

> 标签: custom-element, google-wave, react, scroll, scroll-driven-animations, scrollbar, vue, web-component

## 简介

The Google Wave scrollbar, rebuilt for 2026: a zero-dependency Web Component with native scrolling, a glassy overlay grabber, and CSS scroll-driven motion. React & Vue wrappers included.
