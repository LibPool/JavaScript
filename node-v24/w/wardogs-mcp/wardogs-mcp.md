# wardogs-mcp

> 标签: base-builder, mcp, model-context-protocol, playwright, wardogs

## 简介

Unofficial MCP server for the wardogs.zone base builder: an AI assistant designs and renders WARDOGS FOB layouts from a plain text brief. Built on the Wardogs Zone community hub.
