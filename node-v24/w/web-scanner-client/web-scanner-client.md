# web-scanner-client

> 标签: airscan, document-scanner, escl, react, sane, scanner, scanning, twain, vue, wia

## 简介

Framework-agnostic TypeScript client for the web-scanner-sdk local agent (WIA/TWAIN/SANE/eSCL document scanning over HTTP+WebSocket). Core + React hooks + Vue composable.
