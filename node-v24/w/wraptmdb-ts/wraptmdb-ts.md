# wraptmdb-ts

> 标签: hacktoberfest, npm-package, tmdb, tmdb-api, typescript, wrapper-api

## 简介

wrapTMDB-ts is a wrapper lib for implementing TMDB API from doc. To request Movies and TV-shows informations from TMDB.
