# wasmbridge-net

> 标签: blazor, dotnet, wasm, wasmbridge, webassembly

## 简介

CLI that builds/publishes a WasmBridge.Net-enabled .NET WebAssembly project and syncs its output (compiled app + generated TypeScript types) into a front-end project.
