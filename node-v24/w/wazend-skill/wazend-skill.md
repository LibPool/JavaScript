# wazend-skill

> 标签: agent-skills, ai, claude, codex, cursor, gemini, opencode, skill, waha, wazend, whatsapp, windsurf

## 简介

Instala el skill de Wazend API (WhatsApp) para que cualquier agente de IA (Claude Code, Cursor, opencode, Codex, Gemini CLI, Windsurf) sepa integrar la API.
