# webdial

> 标签: fallback, http3, net.conn, server-sent-events, sse, stream, transport, tunnel, websocket, webtransport

## 简介

net.Conn-style stream over HTTP for the browser and Node.js — WebSocket with SSE+POST fallback and opt-in WebTransport, zero dependencies
