# webmcp-hud

> 标签: agent-native, agents, ai-agents, command-palette, hud, lit, mcp, model-context-protocol, web-component, webmcp

## 简介

Universal WebMCP HUD — a framework-agnostic UI layer for the agent-native web. Cmd+K command palette, agent overlay, action history with undo/redo.
