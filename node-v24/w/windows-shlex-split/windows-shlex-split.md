# windows-shlex-split

> 标签: JavaScript

## 简介

A JS implementation of CmdLineToArgvW() (it's like Python's shlex.split() but for Windows, not POSIX)

## 官网

- npm 页面：https://www.npmjs.com/package/windows-shlex-split
