# we-grid-angular

> 标签: angular, angular-cdk, column-filter, column-resize, crud, csv, data-grid, datagrid, excel-export, excel-import, grid, grouping, inline-editing, pdf-export, server-side-filtering, server-side-pagination, table, themeable, xlsx

## 简介

A themeable, dependency-free Angular data grid — column resize/reorder/pin, filter row, Excel-style checklist header filter, grouping, subtotal row, master-detail, server-side pagination, inline row editing, and Excel/CSV/PDF export plus Excel/CSV import.
