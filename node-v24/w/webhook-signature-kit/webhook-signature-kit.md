# webhook-signature-kit

> 标签: github, razorpay, shopify, signature, slack, stripe, twilio, verification, webhooks

## 简介

One small, correct verifier for Stripe/Slack/GitHub/Shopify/Razorpay/Twilio/GitLab + Generic HMAC, with raw-body adapters.
