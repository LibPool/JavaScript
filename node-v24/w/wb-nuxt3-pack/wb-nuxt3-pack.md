# wb-nuxt3-pack

> 标签: eslint, installer, nuxt, prettier

## 简介

A package to setup @nuxt/image、@nuxt/eslint、@nuxt/i18n、@nuxt/seo、@vite-pwa/nuxt、@nuxtjs/tailwindcss、Pinia、pinia-plugin-persistedstate、Prettier for Nuxt projects
