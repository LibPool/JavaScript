# whitebox-pro-server-plugin-mail

> 标签: JavaScript

## 简介

Mail channel for whitebox — outbound (transactional + bulk), inbound (form + provider webhook), tracking, suppressions, invalid list. Pluggable provider (whitebox-pro-mail-mailgun, whitebox-pro-mail-postmark, …).
