# web-doctor-mcp

> 标签: ai-agent, certificate, csp, hsts, mcp, model-context-protocol, security-headers, ssl, ssl-checker, tls, website-health, x402

## 简介

Live web health & security check for any domain or URL, as an MCP tool and a pay-per-call x402 endpoint. Does a real TLS handshake to grade the SSL/TLS certificate (validity, issuer, days-to-expiry, hostname match, self-signed), the TLS version, HTTP->HTT
