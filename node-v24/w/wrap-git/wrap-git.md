# wrap-git

> 标签: git-summarizer, git-wrapper, git-wrapper-ts, github-api-wrapper, wrap-git, wrap-git-ts

## 简介

Wraps GitHub profile and provides summarized details about repos, commits, language coverages, contributions and yearly recap for a given profile.
