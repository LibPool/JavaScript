# whimsicality-db

> 标签: agent, ai, claude, context, devin, fts5, long-horizon, mcp, memory, model-context-protocol, persistent, search, sqlite

## 简介

SQLite-backed MCP server with FTS5 full-text search for truly infinite agent context. Session tracking, event logging, and paged retrieval for long-horizon tasks.
