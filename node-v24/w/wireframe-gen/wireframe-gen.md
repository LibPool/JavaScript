# wireframe-gen

> 标签: ai-agents, cli, dsl, mockup, pdf, png, requisitos, satori, svg, user-story, wireframe

## 简介

Generador headless de wireframes a partir de un DSL YAML declarativo. Exporta SVG, PNG y PDF vectorial. Pensado para ser invocado por agentes IA.
