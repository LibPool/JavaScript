# we-report-angular

> 标签: angular, banded-report, barcode, crystal-reports-alternative, devexpress-alternative, pdf, report, report-designer, report-viewer, reporting

## 简介

Free, native Angular banded report designer and viewer — drag-and-drop design, paper sizes, data binding, barcodes, PDF export. No backend required.
