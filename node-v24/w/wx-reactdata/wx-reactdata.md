# wx-reactdata

> 标签: 微信小程序

## 简介

让你的微信小程序项目拥有类似与vue的响应式数据的特性，从而让你不用在代码中显式调用setData函数。

- 官网：https://github.com/JE-lee/wxdata
- npm 页面：https://www.npmjs.com/package/wx-reactdata
