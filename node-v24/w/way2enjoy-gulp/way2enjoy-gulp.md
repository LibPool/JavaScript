# way2enjoy-gulp

> 标签: compress, gulpplugin, image, img, minifier, optimizer, photo, picture, png, way2enjoy

## 简介

Way2enjoy API wrapper for compressing JPG, PNG, GIF images as well as PDF, MP3,MP4. All video & audio files are supported
