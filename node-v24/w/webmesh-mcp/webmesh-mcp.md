# webmesh-mcp

> 标签: browser-automation, claude, crawling, llm, mcp, model-context-protocol, playwright, scraping, web-agent

## 简介

Token-economical web browsing, scraping, and crawling MCP server. Tiered fetching (static → browser), robots.txt compliance, session persistence, and BFS crawling.
