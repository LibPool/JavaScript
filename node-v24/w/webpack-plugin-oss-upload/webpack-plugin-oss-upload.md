# webpack-plugin-oss-upload

> 标签: aliyun, aliyun-oss, assets, cdn, oss, plugin, upload, webpack, webpack-plugin

## 简介

一个可以将打包好的资源文件上传到阿里云OSS并且修改代码中资源文件CDN地址的Webpack 5+插件
