# whitebox-pro-sms-mobica

> 标签: JavaScript

## 简介

Mobica (gate.mobica.bg) provider for whitebox-pro-server-plugin-sms — HTTP send with a short client-defined id, DLR delivery-status parsing. Send-only (no inbound). No SDK.
