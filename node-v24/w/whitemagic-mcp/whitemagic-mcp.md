# whitemagic-mcp

> 标签: agent-memory, ai-agents, governance, local-first, mcp, mcp-server, receipts, session-continuity, whitemagic

## 简介

WhiteMagic MCP server: local-first, governed memory and session continuity for AI coding agents. Installs and runs the wm binary; no telemetry by default; optional read-only hosted evaluation lane.
