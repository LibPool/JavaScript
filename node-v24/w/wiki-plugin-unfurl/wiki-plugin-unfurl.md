# wiki-plugin-unfurl

> 标签: federated-wiki, link-preview, outpost, plugin, unfurl, wiki

## 简介

Link-preview Outpost for federated wiki: GET /system/unfurl.json?url=… returns a normalised static card. Carries the heavy extractor libraries so other farms need not; install on one well-resourced host and point wiki-plugin-hitchhiker at it.
