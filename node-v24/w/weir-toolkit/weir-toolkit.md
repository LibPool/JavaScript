# weir-toolkit

> 标签: agent, cli, mcp, onboarding, weir

## 简介

Weir onboarding-flow toolkit: scaffold, preview, and ship agent-authored onboarding flows. Provides the `weir` CLI and an MCP server for coding-agent hosts.
