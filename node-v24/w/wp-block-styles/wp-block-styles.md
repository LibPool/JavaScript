# wp-block-styles

> 标签: blocks, css, gutenberg, headless-cms, headless-wordpress, nextjs, wordpress, wp-block, wp-rest-api

## 简介

Comprehensive CSS styles for WordPress Gutenberg block classes rendered via the headless WP REST API. Zero dependencies, framework agnostic.
