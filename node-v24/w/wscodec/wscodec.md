# wscodec

> 标签: actor_data, codec, fpropertytag, soulmask, ue4, unreal, world.db

## 简介

Pure-JS codec for Soulmask actor_data property streams (UE 4.27 FPropertyTag wire format). Zero runtime dependencies. Accepts uncompressed bytes, returns JS objects, and vice versa. Round-trip byte-identical against every actor.
