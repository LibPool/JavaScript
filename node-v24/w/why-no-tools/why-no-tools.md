# why-no-tools

> 标签: claude, claude-code, diagnostics, mcp, mcp-server, model-context-protocol, npx, timeout, troubleshooting

## 简介

Diagnose why your MCP server shows Connected but no tools appear in Claude Code. Detects npx cold-cache installs that exceed the 30s startup limit.
