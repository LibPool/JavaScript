# wiki-plugin-farm

> 标签: api, farm, federated wiki, openapi, plugin, wiki

## 简介

Federated Wiki - Farm Plugin — one server component for the whole farm: discovers what sibling plugins declare as an interface and mounts it, so a plugin can offer an API without growing a server of its own
