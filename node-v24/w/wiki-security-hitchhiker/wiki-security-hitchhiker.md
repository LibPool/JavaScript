# wiki-security-hitchhiker

> 标签: JavaScript

## 简介

Hitchhiker security module for Federated Wiki — a fork of wiki-security-friends that additionally bootstraps the wiki-plugin-hitchhiker client UX layer (wiki-ux.js) on every page. Intended to be superseded by an own-identity (trust-graph) module.
