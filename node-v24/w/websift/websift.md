# websift

> 标签: ai-agent, duckduckgo, mcp, model-context-protocol, tool-use, web-search, websift

## 简介

Web search + page fetch library and MCP server (DDGS default) with providers, SSRF-safe fetch, and CLI. No API key required for the default provider.
