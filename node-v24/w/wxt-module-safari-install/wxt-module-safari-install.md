# wxt-module-safari-install

> 标签: codesign, dmg, macos, safari, safari-web-extension, web-extension, wxt, wxt-module, xcode, xcodebuild

## 简介

WXT module that builds, signs, and installs the generated Safari extension app locally (macOS). Pairs with wxt-module-safari-xcode.
