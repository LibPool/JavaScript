# wxo-builder-mcp-server

> 标签: agents, ai, ai-agents, antigravity, claude, copilot, cursor, flows, genai, ibm, ibm-cloud, langflow, llm, mcp, model-context-protocol, python-tools, stdio, tools, vscode, watson-orchestrate, watsonx, watsonx-orchestrate, windsurf, wxo

## 简介

MCP server for IBM Watson Orchestrate (WXO): manage tools, agents, flows, Python tools from Cursor, VS Code, Claude. Deploy from URL, create from tool-spec.json.
