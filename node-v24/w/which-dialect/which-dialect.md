# which-dialect

> 标签: dialect, dictionary, language-learning, regional, translation, vietnamese, wiktionary

## 简介

Translate words between languages and dialects, meaning by meaning, starting with Vietnamese (Northern, Central, Southern) and English, with Wiktionary data loaded on demand. More languages are planned.
