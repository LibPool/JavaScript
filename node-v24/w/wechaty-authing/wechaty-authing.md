# wechaty-authing

> 标签: JavaScript

## 简介

wechaty-authing 主要用于 Wechaty 开发者将 Wechaty 的 Contact、Room 同步到 Authing 进行统一的管理。

- 源码仓库：git+https://github.com/Authing/Wechaty-Authing.git
