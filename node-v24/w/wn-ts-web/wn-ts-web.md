# wn-ts-web

> 标签: browser, demo, interlingual, language, linguistics, typescript, web, wn-ts, wordnet

## 简介

Browser/web distribution and interactive demo for wn-ts. Implements the node-to-browser strategy for WordNet access in the browser, following the approach of wordpos/wordpos-web.
