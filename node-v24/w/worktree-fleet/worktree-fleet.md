# worktree-fleet

> 标签: JavaScript

## 简介

Small CLI to spin up multiple isolated local environments for a single repo using Git worktrees. It creates branches like `agent1`, `agent2`, …; installs dependencies if missing; optionally performs a headless Convex configuration; and generates a VS Code
