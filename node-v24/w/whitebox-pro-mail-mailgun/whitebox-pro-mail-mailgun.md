# whitebox-pro-mail-mailgun

> 标签: JavaScript

## 简介

Mailgun provider for whitebox-pro-server-plugin-mail — send (nodemailer Mailgun transport), inbound + tracking webhook parsing, HMAC-SHA256 signature verification.
