# wickra-feature-store

> 标签: features, finance, indicators, rust, streaming, trading

## 简介

Data-driven feature-matrix core for trading: fold a FeatureSpec over each symbol's history with 497 streaming indicators, join labels over a forward horizon, and materialize a byte-identical feature matrix. Node bindings powered by Rust.
