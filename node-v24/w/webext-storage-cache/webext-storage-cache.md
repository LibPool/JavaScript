# webext-storage-cache

> 标签: await, background page, browser, cache, chrome, content script, expirating, extension, firefox, memoization, memoize, options page, promises, safari, self-cleaning, temporary, web-ext, webext

## 简介

Cache values in your Web Extension and clear them on expiration. Also includes a memoize-like API to cache any function results automatically.
