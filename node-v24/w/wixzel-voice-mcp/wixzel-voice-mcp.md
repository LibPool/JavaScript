# wixzel-voice-mcp

> 标签: ai-agents, ai-voice-agent, claude, claude-code, cursor, mcp, mcp-server, model-context-protocol, phone-calls, sip-trunk, telephony, voice-agents, voice-ai, wixzel

## 简介

MCP server for Wixzel Voice: lets Claude, Cursor or any MCP client build voice agents, place real phone calls over your own SIP trunk, manage leads and campaigns, and read usage over the Wixzel Voice API.
