# worktree-switcher

> 标签: ai-agents, claude-code, codex, dev-server, dotnet, git, git-worktree, mcp, model-context-protocol, orca, ports, proxy, vite, windows, worktree

## 简介

Run many git worktrees of one app on the same fixed dev ports: switch which worktree serves them (or proxy the ports to it), with a floating button and an MCP server for coding agents. Windows.
