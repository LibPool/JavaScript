# wattpc-ui

> 标签: JavaScript

## 简介

watt-framework 内的UI组件库，只为PC端适配，尽少控制包体大小，能快速适用于watt内部产品的使用。

- 源码仓库：git@gitee.com:ChuPiJiang/watt-pc-ui.git
- npm 页面：https://www.npmjs.com/package/wattpc-ui
