# wfp-ui-reactjs

> 标签: JavaScript

## 简介

## Quick primer WSS (WFP Self Service) is a mixed Django / React.JS application. Each page is served by Django and it's a container for plain React.JS components. Data binding is binding directly by React and the Django server will act as Rest API.
