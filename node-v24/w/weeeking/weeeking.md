# weeeking

> 标签: mcp, model-context-protocol, tasks, weeek, weeeking

## 简介

MCP server for Weeek with full public API coverage. Installs the native weeeking binary (Windows x64/arm64, Linux x64 gnu/musl, Linux arm64, macOS arm64/x64) and runs it.
