> 标签: agents, agents-md, claude, claude-code, claude-md, code-review, mcp, model-context-protocol, prompt-injection, security, supply-chain

## 简介

MCP server that shows what a checkout you did not write tells your agent to do — instruction files, hook commands wired to agent events, MCP servers it declares, and the skills and subagents it ships.
