# wegine-ui-plus

> 标签: JavaScript

## 简介

一个基于 Vue 3、Element Plus、VXE Table 的业务组件 SDK，封装了常用的「查询表单 + 表格 + 详情 + 弹框」组合场景，并统一导出类型定义与业务 hooks，方便在多个项目之间复用。
