# watchdog-mcp

> 标签: agents, anchor, evm, mcp, security, smart-contracts, solana, x402

## 简介

MCP server for Solana and EVM Watchdog: who can change a program or contract, dependency advisories, repo scans and watches, paid per call over x402.
