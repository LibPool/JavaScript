# waymark-engine

> 标签: ai-agent, ast, bm25, code-discovery, code-intelligence, code-search, developer-tools, fts5, llm-tools, mcp, semantic-search, symbol-search, tree-sitter

## 简介

Agentic code discovery: ask your codebase a question, get exact file + symbol + line span in milliseconds. No re-reading, no guessing, no index to build.
