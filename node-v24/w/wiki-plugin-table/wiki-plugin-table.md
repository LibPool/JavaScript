# wiki-plugin-table

> 标签: csv, data, federated wiki, json, plugin, table, wiki

## 简介

Federated Wiki - Table Plugin — tables from CSV, TSV, markdown or JSON that read well in the narrow panel, enlarge to a sortable table, expose their data to other plugins, and answer over REST and MCP. Cloned from wiki-plugin-json.
