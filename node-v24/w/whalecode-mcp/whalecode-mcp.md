# whalecode-mcp

> 标签: agent, chat, cursor, programming, whalecode, whalecode-mcp

## 简介

WhaleCode MCP 服务器，将 MCP 主机（Cursor 等）的工具调用转发到本机已打开的 WhaleCode IDE 窗口。通过 WhaleCode 扩展的 localhost bridge 通信，支持按工作区路径或 sessionId 路由会话，提供多种 Agent 模式和模型选择，同步轮询运行状态直至完成、取消、出错或超时。
