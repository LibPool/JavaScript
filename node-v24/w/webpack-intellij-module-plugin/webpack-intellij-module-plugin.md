# webpack-intellij-module-plugin

> 标签: dependency, intellij, module, plugin, resolve, webpack

## 简介

For usage with WebpackIntellijModule plugin for Idea. This Webpack plugin reads config file generated by Idea plugin and tells resolver to use NPM packages you added in Modules of your idea project. It allows you to develop your NPM package alongside with
