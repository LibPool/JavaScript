# @volcengine/imagex-monitor

> 标签: JavaScript

## 简介

[veImageX](https://www.volcengine.com/products/imagex) 图片监控 SDK 旨在监控图片元素的加载情况，通过上报图片加载数据，助力分析图片加载各阶段耗时、成功率、分辨率等数据。
