# @volcengine/white-board-manage

> 标签: Volcano Engine, Web WhiteBoard

## 简介

互动白板 VeWhiteBoard，基于 VeRTC 的实时信令网络，提供完整的多人实时白板互动服务，支持白板工具涂鸦、轨迹实时同步、文件转码、白板录制、白板与实时音视频同步等多种能力，互动白板客户端 SDK 覆盖 Android、iOS、Web 等主流平台，同时支持在服务端进行文件转码和上传文件。
