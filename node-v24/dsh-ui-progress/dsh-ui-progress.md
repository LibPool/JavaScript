# dsh-ui-progress

> 标签: dashboard, deepseek-harness, dsh, dsh-plugin, kanban, progress, session

## 简介

DeepSeek Harness 会话进度看板：侧边栏入口（三色角标）+ 全部/进行中/已完成分栏 + 工作空间筛选。Session progress board for DeepSeek Harness: sidebar badge, All/Running/Done sections, workspace filter.
