# @isubpay/sdk

> 标签: ai-agents, mandate, mcp, metered, non-custodial, pay-as-you-go, payments, pull-payment, subscriptions, sui, x402

## 简介

iSub — non-custodial recurring/metered pull-payment primitive on Sui. TS SDK for subscriptions (Fixed), pay-as-you-go (PAYG), x402 mandate scheme, and MCP agent payments.
