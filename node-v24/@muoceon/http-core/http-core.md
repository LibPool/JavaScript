# @muoceon/http-core

> 标签: adapter, axios, cross-platform, electron, fetch, http, http-client, interceptor, react-native, typescript, xhr

## 简介

Production-grade universal HTTP client with adapter pattern — interceptors, retry, timeout, FormData, progress. Works in browser, Node.js, React Native, Electron.
