# @muoceon/oauth-client

> 标签: adapter-pattern, authorization-code, browser, cross-platform, nodejs, oauth2, oidc, openid-connect, pkce, pure-logic, react-native, refresh-token, token-exchange

## 简介

Pure-logic OAuth 2.0 / OIDC client — authorization code flow with PKCE, token exchange, refresh, userinfo. Cross-platform via user-supplied storage/crypto/fetch adapters.
