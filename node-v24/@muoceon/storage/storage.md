# @muoceon/storage

> 标签: adapter, cross-platform, localStorage, persistence, session, storage, tauri, typescript

## 简介

Universal storage abstraction with adapter pattern — manage where and how data is persisted. Web Storage, Tauri Store, memory, extensible. Type-safe JSON, namespace scoping, change events.
