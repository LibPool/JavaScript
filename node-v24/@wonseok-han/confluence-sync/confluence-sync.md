# @wonseok-han/confluence-sync

> 标签: atlassian, cli, confluence, docs-as-code, markdown, obsidian, sync

## 简介

Confluence Cloud ↔ Markdown 양방향 동기화 CLI — 마크다운을 Confluence 페이지로 발행(push)하고, Confluence 페이지·폴더·스페이스를 마크다운으로 가져옵니다(pull).
