# @magnolia/ckeditor5-plugins

> 标签: ckeditor, ckeditor 5, ckeditor5, ckeditor5-dll, ckeditor5-feature, ckeditor5-package-generator, ckeditor5-plugin

## 简介

Magnolia CKEditor 5 plugins enable editors to link pages and assets from Magnolia into rich text content, as well as to embed assets.
