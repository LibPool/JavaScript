# @monlite/vector

> 标签: ai, embeddings, monlite, rag, semantic-search, sqlite-vec, vector

## 简介

Vector / semantic search for monlite — sqlite-vec on @monlite/core, native pgvector on @monlite/postgres. Adds collection.findSimilar().
