# node-red-node-pi-neopixel

> 标签: JavaScript

## 简介

A Node-RED node to output to a neopixel (ws2812) string of LEDS from a Raspberry Pi.

- 源码仓库：git+https://github.com/node-red/node-red-nodes.git
