# @ceburu/rum-web

> 标签: apm, browser, ceburu, observability, opentelemetry, real-user-monitoring, rum, web-vitals

## 简介

Ceburu Real User Monitoring (RUM) for web apps - an OpenTelemetry JS distribution that sends page loads, Web Vitals, JS errors, network calls and sessions to Ceburu, linked to backend APM traces.
