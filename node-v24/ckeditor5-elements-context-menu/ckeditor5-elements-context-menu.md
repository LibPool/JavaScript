# ckeditor5-elements-context-menu

> 标签: ckeditor, ckeditor 5, ckeditor5, ckeditor5-feature, ckeditor5-plugin

## 简介

A context menu for CKEditor 5 elements: right-click an element, or press Shift+F10, to open a menu of commands for it.
