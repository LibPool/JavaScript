# @kodespire/gzip-js

> 标签: compression, decompression, deflate, gunzip, gzip, inflate, napi, react-native, stream, wasm, zlib

## 简介

Gzip, zlib and raw deflate for Node.js, Bun, Deno, browsers, edge runtimes and React Native. Native bindings to the official madler/zlib library with a WebAssembly fallback.
