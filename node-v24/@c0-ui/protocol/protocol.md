> 标签: ai, byok, generative-ui, genui, json-repair, llm, streaming, thesys, xml-dsl

## 简介

Streaming XML-DSL parser, serializer, and JSON repair for LLM-generated rich UI (generative UI). Framework-agnostic core of c0.
