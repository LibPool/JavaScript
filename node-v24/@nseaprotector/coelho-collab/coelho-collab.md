# @nseaprotector/coelho-collab

> 标签: collaboration, collaborative-editing, comments, crdt, editor, hocuspocus, multiplayer, prosemirror, real-time, realtime, rich-text, typescript, y-prosemirror, yjs

## 简介

Real-time collaborative rich text over Yjs for ProseMirror: cursors, offline merge, per-writer undo, comment threads that survive other writers, and a validated document to store.
