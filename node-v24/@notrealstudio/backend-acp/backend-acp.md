# @notrealstudio/backend-acp

> 标签: JavaScript

## 简介

ACP (Agent Client Protocol) с двух сторон: любой ProtocolBackend как ACP-агент (stdio + WebSocket) и внешний ACP-агент (Claude Code, opencode, Gemini CLI) как ProtocolBackend
