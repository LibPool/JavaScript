# @notrealstudio/nr-md

> 标签: ast, config, frontmatter, json5, markdown, mdd, mdz, parser, serializer, structured-data

## 简介

Markdown as structured data: headings become blocks, $key: value lines become attributes. Parser and serializer for the mdd/mdz block grammar.
