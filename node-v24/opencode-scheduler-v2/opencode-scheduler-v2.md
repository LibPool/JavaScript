# opencode-scheduler-v2

> 标签: cron, opencode, opencode-plugin, opencode-v2, plugin, scheduler

## 简介

OpenCode v2 plugin adapter for opencode-scheduler (cron/launchd/systemd scheduled jobs). Runs the unchanged v1 engine on OpenCode 2.x.
