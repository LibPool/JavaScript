# @devopsnext/starterkit-config-util

> 标签: config, environment, fetch, integrations, secure-storage, starterkit

## 简介

Framework-agnostic app-config resolution plus the secure-storage, auth-fetch and third-party-integration utilities shared by the Think Talent frontends. Mechanism only — every project keeps its own env files, service paths and environment names.
