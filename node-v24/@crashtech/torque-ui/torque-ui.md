# @crashtech/torque-ui

> 标签: accessibility, cascade-layers, css, css-framework, dark-mode, design-system, no-build, popover, ui-components, zero-javascript

## 简介

Zero-JavaScript CSS framework: no build, no SCSS, no runtime. Native HTML does the interactivity, one variable re-themes everything, and every state your own script sets is already styled.
