# @miragelyu/dsh-tui

> 标签: agent, ai, claude-code, cli, deepseek-harness, dsh, terminal, tui

## 简介

The dsh terminal-surface bundle: a full-screen interactive TUI patch layer over dsh-base plus the pi-tui chat channel, keyboard dialogs, slash commands, resume, and approval/question answerers
