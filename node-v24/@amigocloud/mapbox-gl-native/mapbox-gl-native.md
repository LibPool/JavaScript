# @amigocloud/mapbox-gl-native

> 标签: gl, mapbox

## 简介

Renders map tiles with Mapbox GL. This fork aplied the fix for https://github.com/mapbox/vector-tile/issues/55. For now, it only supports Node 8 and 10.
