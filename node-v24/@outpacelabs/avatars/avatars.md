# @outpacelabs/avatars

> 标签: avatar-generator, avatars, dither, generative, generative-avatars, gradient, mesh-gradient, ordered-dither, profile-pictures, react

## 简介

React component for generative gradient avatars. Every seed renders a deterministic mesh gradient or a crisp ordered dither, with no stored images.
