# @silentfuture/inwx-mcp

> 标签: ai-agent, claude, dns, domain, domrobot, inwx, mcp, model-context-protocol, nameserver, registrar, transfer

## 简介

MCP server for the INWX domain registrar: list, check, transfer and update domains, nameservers, contacts and DNS via the official DomRobot JSON-RPC API
