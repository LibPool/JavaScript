# @oge-ui/core

> 标签: csv, data-engine, datasource, filtering, grouping, odata, sorting, typescript, virtualization

## 简介

Framework-free data engine behind the OGE UI suite: DataSource contract (array, custom, OData), filtering/sorting/grouping pipeline, virtualization math and CSV export.
