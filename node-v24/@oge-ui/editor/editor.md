# @oge-ui/editor

> 标签: angular, contenteditable, html-editor, rich-text-editor, sanitizer, signals, standalone-components, trusted-types, wysiwyg

## 简介

Signal-based Angular rich-text editor: a dependency-free contenteditable editor over its own document model (no execCommand) with headings, lists, quotes, code, links, images, colours and alignment, its own undo history, markdown shortcuts, Word / Google
