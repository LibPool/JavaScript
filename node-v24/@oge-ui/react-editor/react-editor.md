# @oge-ui/react-editor

> 标签: accessibility, contenteditable, design-system, html-editor, react, rich-text-editor, sanitizer, typescript, wysiwyg

## 简介

React rich-text editor from the OGE UI suite: a dependency-free contenteditable editor over its own document model (no execCommand) with headings, lists, quotes, code, links, images, colours and alignment, its own undo history, markdown shortcuts, Word /
