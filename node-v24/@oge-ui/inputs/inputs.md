# @oge-ui/inputs

> 标签: angular, autocomplete, calendar, checkbox, datepicker, forms, inputs, range-slider, select, signals, slider, switch, tagbox

## 简介

Signal-based Angular form editors on one shared field chrome: text/number boxes, select box, tag box, autocomplete, checkbox, switch, radio group, calendar and date editors — native Date + Intl, no date library.
