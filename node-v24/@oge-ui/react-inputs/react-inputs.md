# @oge-ui/react-inputs

> 标签: accessibility, design-system, editor, form, input, react, textbox, typescript, validation

## 简介

React form editors from the OGE UI suite: text/number editors with the full oge field chrome — label modes, prefix/suffix slots, clear button, validation subscript, grapheme-accurate counter, password reveal, copy-to-clipboard — running the same commit pi
