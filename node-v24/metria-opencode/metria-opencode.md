# metria-opencode

> 标签: claude, codex, metria, opencode, opencode-plugin, usage

## 简介

OpenCode V2 CLI plugin that shows the current AI provider usage (Claude, Codex, OpenCode Go) in the prompt footer, powered by Metria's usage logic.
