# @miragon/slidev-speaker-profiles

> 标签: miragon, presentation, slidev, slidev-addon, speaker

## 简介

Per-speaker slide selection for a Slidev deck several people present. Each speaker keeps their own profile file, nobody overwrites anybody, and main never changes. Slides are addressed by a stable id the shipped slide-ids CLI stamps into their frontmatter
