# @miragon/bpmn-modeler-i18n

> 标签: bpmn, bpmn-js, dmn, dmn-js, i18n, modeler, translations

## 简介

Shared translations for the bpmn-js / dmn-js modeler UI: a didi translate module with runtime language switching and 12 bundled languages.
