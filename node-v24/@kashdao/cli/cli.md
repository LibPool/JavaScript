# @kashdao/cli

> 标签: cli, command-line, developer-tools, erc-4337, kash, kashdao, prediction-markets, sdk, typescript, web3

## 简介

Official non-custodial command-line interface for the Kash prediction-market protocol. Wraps @kashdao/sdk (Kash-orchestrated mode) and @kashdao/protocol-sdk (self-orchestrated mode).
