# @firecrawl/anydoc-wasm

> 标签: JavaScript

## 简介

WebAssembly bindings for anydoc: convert documents (doc, docx, odt, rtf, epub, pdf, presentations, spreadsheets, csv) to GitHub-Flavored Markdown in the browser
