# @webanalyzer/cli

> 标签: accessibility, ai-readiness, audit, cli, geo, lighthouse-alternative, mcp, seo, web-quality, webanalyzer, webanalyzer.dev, website-analyzer

## 简介

Official SDK and CLI for webanalyzer.dev — score any public web page 0-100 across 8 quality dimensions (SEO, AI readiness, performance, accessibility, code quality, UI/UX, data & tracking, security) from 290+ deterministic checks. Free, keyless.
