# @nova-fe/utils

> 标签: React, Rollup, Util, Vue, 工具库

## 简介

基于 rollup 4 + typescript 封装常用的工具函数，利用 Jest 实现自动化测试；vscode 自定义工作区 保持代码风格一致；可在 react、vue 项目中使用。
