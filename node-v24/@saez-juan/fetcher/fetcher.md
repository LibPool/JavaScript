# @saez-juan/fetcher

> 标签: JavaScript

## 简介

Wrapper seguro alrededor de `fetch` (Bun/WHATWG) que devuelve `Result` en vez de lanzar excepciones. Incluye helpers para parsear JSON, texto y para reenviar respuestas con el esquema de `Result`.
