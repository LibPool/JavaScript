# @ahoo-wang/wow-client

> 标签: client, cqrs, ddd, event-sourcing, fetch, http, microservice, typescript, wow, wow-client

## 简介

TypeScript client for Wow (https://github.com/Ahoo-Wang/Wow): commands, snapshot and event-stream queries, and the query DSL, built on Fetcher.
