# @vscode/editor-view

> 标签: editor, gpu, renderer, rust, vscode, wasm, webgpu, wgpu

## 简介

A GPU-accelerated editor renderer with a Rust/WASM core (wgpu, WebGPU + WebGL2 fallback)
