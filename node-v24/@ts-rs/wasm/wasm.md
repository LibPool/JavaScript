# @ts-rs/wasm

> 标签: TypeScript, compiler, rust, tsc, typecheck, wasm, webassembly

## 简介

tsrs (a Rust port of the TypeScript 7 compiler) as a WebAssembly module: tsc for Node and browsers, single-threaded
