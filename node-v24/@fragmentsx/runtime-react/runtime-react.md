# @fragmentsx/runtime-react

> 标签: JavaScript

## 简介

React-рантайм для встраивания опубликованных фрагментов Fragments в приложение потребителя. Строится поверх `@fragmentsx/fragments-client` — берёт готовый клиент и раскладывает его в провайдеры, хуки и компоненты React.
