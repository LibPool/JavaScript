# @astrakratos/tetherd

> 标签: ai-agent, claude-code, codex, cursor, hooks, mirror, remote

## 简介

Mirror your local AI coding sessions (Claude Code, Cursor, Codex) to a web UI — watch them, answer their prompts, and steer them from anywhere. End-to-end encrypted.
