# @oklch-picker/svelte

> 标签: color, color-picker, color-space, colour, colour-picker, colour-space, display-p3, gamut, oklch, oklch-color-picker, oklch-colour-picker, oklch-picker, p3, picker, rec2020, srgb, svelte, svelte-color-picker, svelte-colour-picker, svelte-component, svelte5, wide-gamut

## 简介

An OKLCH color picker for Svelte 5. Gamut-aware sliders, wide-gamut P3 and Rec. 2020, works with bind:value.
