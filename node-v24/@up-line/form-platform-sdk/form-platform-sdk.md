# @up-line/form-platform-sdk

> 标签: captcha, form, forms, lead, recaptcha, turnstile, typescript, validation

## 简介

The form platform's SDK for a site that renders its own form: typed forms generated from the schema, validation with the platform's rules, and a client that handles the anti-spam token, CAPTCHA and retries.
