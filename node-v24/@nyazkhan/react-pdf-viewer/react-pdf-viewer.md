# @nyazkhan/react-pdf-viewer

> 标签: component-library, document-processing, document-viewer, javascript-pdf, mozilla-pdfjs, pdf, pdf-annotation, pdf-highlighting, pdf-library, pdf-reader, pdf-rendering, pdf-search, pdf-viewer, pdfjs, react, react-components, responsive-pdf, text-selection, typescript, web-components

## 简介

A comprehensive React TypeScript component library for viewing and interacting with PDF files using Mozilla PDF.js. Features include text selection, highlighting, search, sidebar, multiple view modes, and complete PDF.js web viewer functionality.
