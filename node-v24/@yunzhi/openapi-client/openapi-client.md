# @yunzhi/openapi-client

> 标签: JavaScript

## 简介

在使用pkg打包的项目中，用于替换`@alicloud/openapi-client`依赖，解决pkg项目直接使用`@alicloud/openapi-client`依赖导致的部分动态require not found的问题。
