# @lukisxyz/pi-core-skill-tool

> 标签: agent-skills, pi-extension, pi-package, skills

## 简介

Pi extension — opencode2-style skills: strips the built-in skill catalog from the system prompt and exposes skills via a single lazy `skill` tool. Agent auto-invokes, no user input, saves ~4.5K tokens/session.
