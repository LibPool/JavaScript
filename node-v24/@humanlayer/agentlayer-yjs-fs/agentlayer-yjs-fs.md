# @humanlayer/agentlayer-yjs-fs

> 标签: JavaScript

## 简介

Yjs-backed implementations of `agentlayer-core`'s filesystem tool interfaces (`read`, `write`, `edit`, `apply_patch`, `glob`, `grep`, `list`), executing against `@humanlayer/yjs-fs`'s `YjsFilesystem` — a CRDT virtual filesystem — instead of disk. Because
