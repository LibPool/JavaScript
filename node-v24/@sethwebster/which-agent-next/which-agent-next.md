# @sethwebster/which-agent-next

> 标签: agent, agents, claude, cli, codex, dispatch, grok, mcp, quota, rate-limit, skill, usage

## 简介

Inspect installed agent CLIs and their profiles, check how much usage each has left, and print the command to run the best one next.
