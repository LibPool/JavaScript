# @stephen.taipei/adorable-git-graph

> 标签: cli, git, git-graph, git-log, three.js, visualization

## 简介

Cartoon-style animated git graph for your local repositories. Run `npx @stephen.taipei/adorable-git-graph` inside any git repo.
