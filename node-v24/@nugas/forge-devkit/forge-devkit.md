# @nugas/forge-devkit

> 标签: CRUD, NGXS, NgRx, angular, code generation, scaffolding

## 简介

Angular code generation library for scaffolding features with CRUD pages, NgRx store, facade, and adapters. No scripts required—run generators directly with `npx`.
