# @getly/sdk

> 标签: api-client, commerce, digital-products, getly, headless, sdk

## 简介

Zero-dependency TypeScript client for the Getly v1 API — products, posts, coupons, checkout links, license keys, webhooks, Getly Billing subscriptions.
