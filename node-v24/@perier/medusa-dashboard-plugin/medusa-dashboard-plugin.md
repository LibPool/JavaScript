# @perier/medusa-dashboard-plugin

> 标签: medusa, medusa-plugin, medusa-v2, perier, plugin

## 简介

Backend companion plugin for @perier/medusa-dashboard. Provides the server-side routes, modules, and subscribers that power the dashboard's native workflows.
