# @upflowi/provider-r2

> 标签: cjs, cloudflare, esm, file-transfer, multipart, r2, typescript, upload

## 简介

upflowi storage provider for Cloudflare R2 multipart uploads, driven entirely by presigned URLs your own backend generates. Never receives R2/S3 credentials.
