# @snapcn/mcp

> 标签: ai, animation, mcp, model-context-protocol, motion, registry, remotion, shadcn, snapcn, video

## 简介

MCP server for the snapcn registry: search hand-tuned Remotion components, get their prop schemas, and plan a whole video from a one-line brief — so an agent composes motion instead of inventing it.
