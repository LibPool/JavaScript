# @allyhub/analysis

> 标签: JavaScript

## 简介

AllyHub's media analysis on this computer: speech recognition with word times (Parakeet), shots, onsets and tempo, on-screen text (OCR), face tracks (YuNet) and person mattes (U²-Net), contact sheets, reference ads and their comparison with a render; mode
