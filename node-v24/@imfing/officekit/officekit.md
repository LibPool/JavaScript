# @imfing/officekit

> 标签: browser, canvas, docx, excel, office, ooxml, openxml, parser, powerpoint, pptx, viewer, word, xlsx

## 简介

TypeScript toolkit for parsing and rendering Office Open XML documents (DOCX, PPTX, XLSX) to canvas in the browser.
