# @ni-c/mcp-hub

> 标签: cimd, claude, gateway, mcp, model-context-protocol, oauth, oauth2.1, proxy

## 简介

Serve multiple stdio MCP servers from one container: Claude-Code-style mcpServers config, path-based routing, hub meta-tools, and CIMD-first OAuth 2.1 + API tokens for ChatGPT, Claude and any Streamable-HTTP MCP client.
