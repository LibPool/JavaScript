# @mk-kit/mcp

> 标签: ai, angular, claude, components, copilot, cursor, mcp, mk-kit, model-context-protocol

## 简介

MCP server for @mk-kit/ui — lets AI coding assistants look up every component, directive, service and helper of the mk-kit Angular library (inputs, outputs, methods, import paths, docs links).
