# dsh-sidebar-browser-control

> 标签: agent-tool, browser, browser-automation, cordis, deepseek-harness, dsh, dsh-plugin, sidebar

## 简介

Drive DSH's own built-in browser (the right-hand Sidebar's Browser tab) from the agent: list tabs, open, navigate, read the page, run JavaScript, click, fill forms, log in, and look at pictures or the pane itself with vision. No second Chromium process.
