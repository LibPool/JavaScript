# @7niao/version-polling

> 标签: deploy, etag, frontend, hot-update, polling, update, version, web-worker

## 简介

前端部署更新检测工具：基于 HTML 文件 ETag 与 Web Worker 轮询，自动检测网页静态资源更新并提示用户刷新。
