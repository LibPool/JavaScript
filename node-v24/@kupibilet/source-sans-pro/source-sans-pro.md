# @kupibilet/source-sans-pro

> 标签: JavaScript

## 简介

Source Sans Pro is a set of OpenType fonts that have been designed to work well in user interface (UI) environments. In addition to a functional OpenType font, this open source project provides all of the source files that were used to build this OpenType
