# @vestig/express

> 标签: express, expressjs, logging, middleware, nodejs, observability, request-correlation, structured-logging, tracing, typescript, vestig

## 简介

Express.js middleware integration for vestig logging. Automatic request correlation, structured logging, and error handling.
