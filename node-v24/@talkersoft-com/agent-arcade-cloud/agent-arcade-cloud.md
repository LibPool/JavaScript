# @talkersoft-com/agent-arcade-cloud

> 标签: JavaScript

## 简介

Agent Arcade (cloud) — voice-driven control for your AI agents, driven entirely by your Talkersoft account. Requires Google sign-in; agents, workspaces and macros live in the cloud.
