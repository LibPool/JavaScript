# @tomtom-org/maps-sdk-plugin-map-effects

> 标签: JavaScript

## 简介

Practical post-processing for a TomTomMap: bloom for emphasis, tint/grade/vignette to mute the base map under data, fog and edge blur for focus, a WebGL depth of field with bokeh for a tilted 3D view — plus high-DPI capture
