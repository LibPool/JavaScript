# @tomtom-org/maps-sdk-plugin-map-theme

> 标签: JavaScript

## 简介

Theme a TomTomMap from wherever a look comes from — a brand's colours, a website's, a described mood, an artist's palette, or an image — by assigning them to the SDK's map colours
