# @markup-carve/pandoc-carve

> 标签: ast, carve, converter, latex, markup, pandoc, typst

## 简介

Carve to Pandoc bridge: convert Carve markup to Pandoc's JSON AST and reach every pandoc output format (LaTeX, Typst, DOCX, PDF, ...)
