# @spectrayan/sse-client

> 标签: eventsource, http2, real-time, reconnection, server-sent-events, sse, streaming, typescript, webstreams

## 简介

Type-safe, framework-agnostic Server-Sent Events (SSE) client for browser and Node.js with auto-reconnect, exponential backoff, jitter, and typed streams.
