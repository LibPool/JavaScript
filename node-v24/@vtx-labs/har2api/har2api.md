# @vtx-labs/har2api

> 标签: api, cli, curl, har, openapi, openapi3, postman, reverse-engineering, schema-inference, swagger, vtx-labs

## 简介

Turn a browser .har capture into an OpenAPI 3.1 spec, a Postman collection, and cURL commands — offline, zero-dependency.
