# @ccondry/hydra-express

> 标签: JavaScript

## 简介

A fork of flywheelsports/hydra-express v1.4.19 with minor fixes. Original description: A module which wraps Hydra and ExpressJS to provide an out of the box microservice which can support API routes and handlers.
