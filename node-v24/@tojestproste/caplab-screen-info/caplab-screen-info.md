# @tojestproste/caplab-screen-info

> 标签: android, capacitor, caplab, display, native, plugin, resolution, screen

## 简介

Capacitor plugin - odczyt stanu ekranu na Androidzie (rozdzielczość, gęstość, jasność, refresh rate, cutout, paski systemowe) bez uprawnień.
