# demf-datasources-list

> 标签: JavaScript

## 简介

The Datasources List microfrontend displays and manages a table list of datasources (APIs, databases, files, etc.) with search, filter, create, edit, delete, and test connection functionalities. Entry point for datasource management in the Digital Mashup
