# dsh-mail-notify

> 标签: deepseek-harness, dsh, dsh-plugin, nodemailer, notification, smtp

## 简介

DeepSeek Harness plugin: email a top-level Agent turn's final output, its terminal failures, and its mid-turn human-attention requests over SMTP, configured from the Web UI.
