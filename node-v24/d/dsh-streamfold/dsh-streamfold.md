# dsh-streamfold

> 标签: deepseek-harness, display-mode, dsh, dsh-plugin, fold, streaming, transcript, ui, web

## 简介

流式折叠：会话窗口展示增强——运行中自动展开最新思考小窗、旧过程行折成摘要，跑完把思考与工具调用折起而穿插正文保留；逐帧推进，不依赖历史加载完。 · Stream Fold: the newest thinking window opens itself while older process rows fold into one summary; a finished turn folds thinking and tool calls away and the prose stays.
