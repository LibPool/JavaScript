# dsh-acp-door

> 标签: acp, agent client protocol, deepseek, deepseek harness, dsh, dsh-plugin, vscode

## 简介

在正在运行的 DeepSeek Harness 内核上新增一个仅监听本机回环地址的 ACP 接入点，供 VS Code 面板等外部程序连接。
