# designmd-forge

> 标签: design, design-system, design-tokens, mcp

## 简介

Free, offline MCP server for browsing/searching/fetching DESIGN.md design-system specs (colors, typography, components) across web, mobile and iOS sources, with lint/diff/scaffold authoring tools.
