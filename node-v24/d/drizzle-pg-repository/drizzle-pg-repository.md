# drizzle-pg-repository

> 标签: drizzle, drizzle-orm, orm, postgres, postgresql, repository, typescript

## 简介

A small, typed repository toolkit for Drizzle ORM on PostgreSQL: constraint-scoped base repositories, typed constraint-violation errors, and test helpers.
