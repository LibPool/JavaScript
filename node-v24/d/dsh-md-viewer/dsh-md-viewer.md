# dsh-md-viewer

> 标签: deepseek-harness, dsh, dsh-better-sidebar, markdown, plugin, preview, renderer

## 简介

DSH web plugin: render Markdown (.md) files with a rich preview (tables, badges, code) inside the dsh-better-sidebar sidebar.
