# dsh-security-gate

> 标签: audit, codex-security, deepseek-harness, dsh, security

## 简介

DSH host plugin: auto-audits newly installed plugins (presets and profile packages) with the harness's own model, exposes batch audit tools, and renders an audit panel in Settings.
