# d3-coverage-dashboard

> 标签: JavaScript

## 简介

A D3.js-based interactive dashboard that visualizes test coverage data from V8 (Node.js) reports. It provides insights into feature files, test scenarios, executed and missing steps, and highlights source files that are only invoked versus actively tested
