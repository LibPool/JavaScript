# dsh-come

> 标签: companion, deepseek, desktop, dsh, harness, installer

## 简介

DSH Come 官方 npm 安装器：桌面壳二进制经 npm registry 平台分包分发（optionalDependencies 自动选平台），postinstall 本地就位，npm 升级即壳升级。

- 官网：https://github.com/qing3a/dsh-come#readme
- 源码仓库：git+https://github.com/qing3a/dsh-come.git
- npm 页面：https://www.npmjs.com/package/dsh-come
