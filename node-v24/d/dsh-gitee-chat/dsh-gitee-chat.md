# dsh-gitee-chat

> 标签: deepseek-harness, dsh, dsh-plugin, enterprise, gitee, kanban, mcp, project-management

## 简介

会话内 Gitee 企业项目管理：模型用触发型工具取数，脚本负责拉取，看板与图表由客户端插件在对话流里渲染并可直接操作。不做侧边栏、不维护本地数据库。
