# dsh-regex-lab

> 标签: dsh, plugin, regex, tool

## 简介

Regex lab plugin for DeepSeek Harness: test_regex with capture groups, replace_preview, common pattern library, and worker-based timeout guard against catastrophic backtracking. Zero runtime dependencies.
