# dsh-taskswarm2

> 标签: deepseek-harness, dsh, multi-agent, orchestration, parallel, task-runner, taskswarm

## 简介

TaskSwarm (蜂群) — multi-agent task orchestration for DeepSeek Harness. Native port of TaskPlane (github.com/HenryLach/taskplane, MIT): waves/lanes parallel execution, git worktree isolation, PROMPT.md/STATUS.md task packets, file mailbox, cross-model revie
