# dsh-oauth-remote

> 标签: auth-request, cordis, deepseek-harness, dsh, github, nginx, oauth, reverse-proxy

## 简介

GitHub OAuth gate for public remote access to the DeepSeek Harness web GUI. Provides /oauth login/callback/authz endpoints; pair with an Nginx auth_request location to protect the whole site.
