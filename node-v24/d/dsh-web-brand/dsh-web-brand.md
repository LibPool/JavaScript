# dsh-web-brand

> 标签: branding, cordis, deepseek, deepseek-harness, dsh, favicon, icon, plugin, tab, title, web

## 简介

Per-server title + favicon branding for dsh web: prefix every browser tab with a brand (Yao - DeepSeek Harness, Yao - <session> - DeepSeek Harness) and swap the favicon, so multiple dsh instances are distinguishable at a glance. Values come from --title/-
