# demf-rule-editor-control-panel

> 标签: JavaScript

## 简介

The Rule Editor-Control-Panel microfrontend is a Control Panel for rule Editor section of Rule Manager. The Rule Editor-Control-Panel works within the Rule Manger tool in which it is mounted, and help you to manage a creation of a new Rule.
