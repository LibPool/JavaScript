# dsh-everything-search

> 标签: cordis, deepseek-harness, dsh, everything, file-search, plugin, search

## 简介

Everything 文件搜索插件（DeepSeek Harness / DSH）：全盘极速搜索文件与文件夹，多选后一键加入对话上下文，设置可自定义，es.exe 随插件打包。
