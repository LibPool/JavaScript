# dsh-plugin-phone-access

> 标签: deepseek-harness, dsh, dsh-plugin, mobile, pwa, remote-access, tailscale

## 简介

Reach this Harness from your phone over a private network: a loopback-preserving gateway with one-time pairing codes, plus a portrait layout for narrow screens.
