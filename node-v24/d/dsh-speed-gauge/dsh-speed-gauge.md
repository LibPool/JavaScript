# dsh-speed-gauge

> 标签: dashboard, dsh, dsh-plugin, gauge, monitor, speed, tok/s, token

## 简介

A generation-speed gauge for DSH: a half-circle dial and a flowing trend curve, sampling tok/s 50 times a second for finer, more accurate measurement; tuck it away with a header button at any time.
