# dkg-wm-bridge

> 标签: dkg, knowledge-graph, openclaw, origintrail, provenance, v10, working-memory

## 简介

Agent-plugin that deposits workspace artifacts into DKG v10 Working Memory with structured provenance, status tags, and a promotion path to Shared and Verified Memory. Works with OpenClaw, Hermes, and any agent that produces text artifacts.
