# docvalidator-sdk

> 标签: colombia, docvalidator, ocr, sdk, validation

## 简介

Cliente TypeScript/JavaScript para DocValidator v2 — validación documental automatizada con tipos de enriquecimiento RUES, Cédula/Registraduría y AML/SARLAFT.
