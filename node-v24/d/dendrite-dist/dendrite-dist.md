# dendrite-dist

> 标签: JavaScript

## 简介

Use [dendrite](https://matrix-org.github.io/dendrite/) as an npm module for tighter integration with node apps (e.g. test fixtures). See the dendrite documentation for usage: https://matrix-org.github.io/dendrite/.
