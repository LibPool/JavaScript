# dsh-frecency

> 标签: deepseek, dsh, dsh-plugin, frecency, glob, grep, harness, search

## 简介

Resident-index + frecency file search for DeepSeek Harness — shadows the built-in grep/glob tools. · DSH 常驻索引 + frecency 文件搜索，同名覆盖内置 grep/glob。
