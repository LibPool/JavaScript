# doc-html-skill

> 标签: agent-skills, claude, claude-code, documentation, html, mermaid, wcag

## 简介

Schema-first branded HTML documentation skills for Claude Code: deterministic renderer, widget library, three layout skins, dark mode, Mermaid theming, layered validation. `npx doc-html-skill install` copies the skills into your project.
