> 标签: code-review, deepseek, dsh, dsh-plugin, github, harness, kanban, maintainer, pull-request

## 简介

Maintainer PR review queue board for DeepSeek Harness: five-state tracking (waiting on me / waiting on author / ready to merge / merged / inbox), sidebar counters, fullscreen kanban, polling, and back-to-you transition toasts. · 维护者 PR 看板：五状态跟踪（等我行动 / 等作者
