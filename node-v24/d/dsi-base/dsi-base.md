# dsi-base

> 标签: JavaScript

## 简介

Este repositorio contiene una capa de Nuxt diseñada para proporcionar una base sólida para construir aplicaciones web modernas. Incluye un conjunto de herramientas y librerías preconfiguradas para acelerar el desarrollo y asegurar un código base consisten
