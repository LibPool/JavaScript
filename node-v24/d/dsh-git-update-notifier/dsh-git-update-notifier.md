# dsh-git-update-notifier

> 标签: cordis, deepseek-harness, dsh, dsh-plugin, git, update

## 简介

每日检查 dsh 本体是否有更新（源码 checkout 走 git，npx / npm 安装走 registry），并在 Web GUI 中交由用户决定更新、延期或回退。
