# dsh-markdown-render

> 标签: commonmark, dsh, gfm, html, markdown, plugin, render, text

## 简介

Zero-dependency Markdown renderer for DeepSeek Harness: CommonMark + GFM subset to HTML (headings, fenced/indented code, nested lists & quotes, task lists, tables with alignment, inline formatting) and to aligned plain text. Uses only Node built-ins.
