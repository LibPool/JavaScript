# dsh-tui-plugin

> 标签: JavaScript

## 简介

A standalone terminal UI bundle for the DeepSeek Harness: an interactive in-process host surface over the official dsh base with session list, streaming conversation, tool cards, approvals, questions, jobs, subagents, goals, plan mode, model selection, se
