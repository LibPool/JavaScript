# dsh-huashu-pixel

> 标签: arcade, crt, deepseek-harness, dsh, dsh-plugin, pixel, pixel-art, retro, skin, theme

## 简介

花书像素主题：暖米白纸面 + 深褐墨字 + 橙色强调 + 像素字体，暗色切街机磷光；流式输出与状态变化带 CRT 动效。
