# dsh-jiuling-remote-mobile

> 标签: android, cloudflare-tunnel, deepseek-harness, dsh, dsh-plugin, dshapp-plugin, remote

## 简介

DSH 远程目录（手机端）：在选文件夹流程里多出「电脑」页签，进入电脑目录、在电脑上发起对话，并把电脑的实时消息流同步到手机本地界面（只传文本，不映射桌面）。
