# dsh-dialog-fence

> 标签: billion-context, cache, dsh, dsh-desktop, dsh-plugin, fence, guardrail, prompt, rules

## 简介

A dialogue fence stored in one JSON file: a shared rule list that applies to every conversation plus an optional per-session list, injected into the runtime-context snapshot (cache-safe, append-only, compression-durable). The file location is customizable
