# dynamodb-item-size-calculator

> 标签: 400kb, aws, calculator, capacity, capacity-units, dynamodb, item-size, rcu, size, wcu

## 简介

Calculate DynamoDB item size in bytes and consumed capacity (RCU/WCU) from native JavaScript items — AWS's documented sizing rules, the 400 KB item limit, and the 4 KB read / 1 KB write capacity rounding. Zero dependencies.
