# datavessel-cli

> 标签: cli, datavessel, ga4, google-analytics, mcp, search-console, shopify

## 简介

Command-line interface for datavessel: 200+ read/write tools (GA4, Search Console, Google/Meta Ads, Shopify, WooCommerce, Shopware). Commands and help are generated dynamically from the backend tool catalog.
