# dsh-tui-pkg

> 标签: cordis, deepseek-harness, dsh, dsh-plugin, dsh-tui, plugin-manager, tui

## 简介

In-terminal plugin manager for dsh-tui: list installed plugins and bundles, and install, remove, enable or disable them without leaving the TUI.
