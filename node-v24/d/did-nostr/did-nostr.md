# did-nostr

> 标签: decentralized-identity, did, did-resolver, did:nostr, nostr, resolver

## 简介

did:nostr resolver — offline, HTTP (.well-known) and relay resolution, with a DIF did-resolver driver. Conforms to did:nostr 0.0.12.
