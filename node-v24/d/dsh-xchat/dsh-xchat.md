# dsh-xchat

> 标签: cordis, cross-session, dsh, plugin, subagent, xchat

## 简介

跨会话知识桥（DSH 静态插件）：@ 任意位置触发会话候选（自绘菜单，跟随主题）+ 拖拽会话到聊天窗；xchat_query 工具（在目标会话名下拉起继承其记忆的 fork 子代理，跨会话询问，用完归档删除；已移除追问/start。随 dsh profile 启动自动加载。
