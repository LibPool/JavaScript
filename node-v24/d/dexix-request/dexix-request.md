# dexix-request

> 标签: api, axios-alternative, cli, fetch, http, http-client, interceptors, node, react, request, retry, typescript

## 简介

A tiny, zero-dependency HTTP client for JavaScript and TypeScript with interceptors, built-in retries, and a beautiful CLI. Built for the browser, Node.js, and React.
