# dsh-codespace-workspace

> 标签: codespace, codespaces, deepseek-harness, dsh, dsh-plugin, github, remote-workspace

## 简介

Use a GitHub Codespace directly as a DSH workspace: the agent reads, writes and runs commands inside the cloud Codespace.
