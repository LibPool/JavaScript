# docgrity

> 标签: cli, contradiction, documentation, duplicate, github-action, lint, llm, markdown

## 简介

Docgrity doc-integrity scans for CI and local use: contradictions, duplicates and open questions across repository markdown docs. Read-only CLI — generates an HTML report; never posts anything.
