# dsh-task-alerts

> 标签: deepseek-harness, dsh, notification, notify, plugin, sound, toast, ui

## 简介

DSH task notification plugin: a chime (Web Audio, no assets) plus a popup (browser Notification, or an in-page top-right toast as fallback) when a session finishes running or starts waiting for your approval / answer. Browser-side only, lightweight, zh/en
