# dartvel_cli

> 标签: cli, dart, dartvel, flutter, framework, full-stack

## 简介

Dartvel CLI — an alias for dartvel_dev, so `npm i -g dartvel_cli` installs the same CLI. The implementation lives in dartvel_dev; this package only forwards to it.
