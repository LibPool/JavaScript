# dsh-gme-workflow

> 标签: deepseek-harness, dsh, dsh-plugin, gme, test-generation, workflow

## 简介

GME Test Agent workflow tools for DeepSeek Harness: pick interfaces, run autonomous test generation and repair through a local Python backend, poll progress, and decide with consent.
