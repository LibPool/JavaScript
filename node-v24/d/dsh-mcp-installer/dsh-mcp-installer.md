# dsh-mcp-installer

> 标签: dsh, dsh-plugin, mcp, model-context-protocol

## 简介

MCP installer settings page for DeepSeek Harness: paste or import an MCP configuration, review safety risks, then write the servers into the current profile's cordis.patch.yml.
