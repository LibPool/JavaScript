# datadiff-cli

> 标签: cli, csv, diff, git, git-diff, json, kubernetes, semantic-diff, toml, xml, yaml

## 简介

Semantic diff for JSON, YAML, CSV, TOML and XML that plugs into git diff — key order is ignored, changes are reported as data paths
