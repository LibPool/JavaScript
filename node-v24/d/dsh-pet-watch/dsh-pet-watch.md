# dsh-pet-watch

> 标签: companion, deepseek-harness, desktop-pet, dsh, dsh-plugin, screen-capture, vision

## 简介

桌宠陪看：定时截屏，让视觉模型点评你正在看的画面，投喂给 dsh-pet 的气泡。Pet watch-along for DSH: screen sampling + a vision model + dsh-pet's bubble.
