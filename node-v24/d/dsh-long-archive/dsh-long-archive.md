# dsh-long-archive

> 标签: archive, cordis, deepseek-harness, dsh, plugin

## 简介

Archived-session manager for DSH Web: sidebar footer entry, grouped archive panel, restore/delete with full agent teardown (DSH 0.1.5-rc.2 适配版)
