# dsh-novelweb

> 标签: cordis, dsh, novel, novelweb, plugin, writing

## 简介

NovelWeb 写作助手 — 可通过 dsh plugin --profile web add 安装的 DSH bundle:小说写作/策划双模式、RAG 检索、伏笔与大纲管理。
