# dsh-adb

> 标签: adb, android, automotive, bench, dsh, dsh-plugin

## 简介

ADB device & bench operations for DeepSeek Harness: device discovery, structured logcat, apk install, file pull/push, performance snapshots, perf baselines, crash reports, one-click device health reports, condition waits, operation ledger w/ rollback, scr
