# dsh-better-tools

> 标签: JavaScript

## 简介

DSH web plugin scaffold: a minimal host/client dual-half plugin that mounts through dsh.bundle.patch + profile bundles. Demonstrates a host service + model tool + web route, and a client-side React widget.
