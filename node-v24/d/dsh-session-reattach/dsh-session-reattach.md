# dsh-session-reattach

> 标签: deepseek-harness, dsh, dsh-plugin, plugin, session, workspace

## 简介

会话归位：把游离（未分组）会话按 canonical cwd 重新归属到匹配的工作区，只修 workspace 归属记录，不动会话文件。
