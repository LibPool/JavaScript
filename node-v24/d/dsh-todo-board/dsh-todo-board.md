# dsh-todo-board

> 标签: cordis, deepseek, deepseek-harness, dsh, dsh-plugin, task-board, todo, todo-list, 图片附件, 定时执行, 待办, 折叠, 自动接续

## 简介

跨会话 TODO 板：右上角浮窗、按工作目录分组、可拖动排序；每条待办可选「提醒 / 自动续跑 / 自动新开会话」三档执行模式，可附图片（派发时作为真正的图片发给模型），可设定本地时间到点才执行，双勾选（AI 完成 / 用户验收）。不占地方时可整体折叠为一行（显示计数与下一条待办），面板内各区块也能单独折叠。AI 完成一项后自动查找同目录下一条未完成待办并继续执行。
