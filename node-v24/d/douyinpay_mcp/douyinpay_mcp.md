# douyinpay_mcp

> 标签: douyinpay, mcp, model context protocol

## 简介

抖音支付提供的 MCP Server，让你可以轻松将抖音支付提供的交易创建、查询、退款等能力集成到你的 LLM 应用中，并进一步创建具备支付能力的智能工具。
