# dsh-router-ext-rtk

> 标签: JavaScript

## 简介

DSH plugin: RTK (Rust Token Killer) extension for dsh-router. Registers a command-rewrite ext via the router.ext cordis service so dsh-router ships every bash tool call through `rtk rewrite`, cutting 60-90% of LLM-bound bash output.
