# dsh-codebuddy-code

> 标签: adapter, bundle, codebuddy, deepseek-harness, dsh, llm, plugin, provider

## 简介

CodeBuddy LLM provider bundle for the DeepSeek Harness web GUI: registers the `codebuddy` provider route, its Models-page card, and its model picker entries, authenticating against the machine's CodeBuddy desktop-app login, with per-model measured image i
