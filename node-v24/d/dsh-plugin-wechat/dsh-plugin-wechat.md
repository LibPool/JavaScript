# dsh-plugin-wechat

> 标签: clawbot, deepseek-harness, dsh, dsh-plugin, openclaw, wechat, weixin, 微信机器人

## 简介

DeepSeek Harness (DSH) 个人微信 ClawBot 插件：OpenClaw 负责微信通道（扫码登录/收发消息），DSH 负责大脑，两者通过 OpenAI 兼容协议桥接。
