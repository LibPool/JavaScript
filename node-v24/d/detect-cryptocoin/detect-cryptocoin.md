# detect-cryptocoin

> 标签: altcoin, base58, base58check, bitcoin, cryptocoin, detect, franko, litecoin, novacoin, ppcoin, primecoin, terracoin, worldcoin

## 简介

Detects which cryptcoin is the given cryptocoin address (starts with some coins listed in CoinWarz.com that have working block explorers)

- 源码仓库：git://github.com/pocesar/node-detect-cryptocoin.git
