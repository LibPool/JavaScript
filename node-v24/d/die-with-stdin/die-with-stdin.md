# die-with-stdin

> 标签: Elixir, Phoenix

## 简介

This is a simple script that launches its argumets as child process and ensures the process is killed when parent stdin exits. It is similar to webpack's `--watch-stdin` but should be usable with any npm script (at least in theory).
