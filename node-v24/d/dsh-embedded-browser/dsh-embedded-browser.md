# dsh-embedded-browser

> 标签: agent-tools, browser, cdp, chrome-devtools-protocol, deepseek-harness, dsh, dsh-plugin, embedded-browser, headless-browser, human-in-the-loop, lazy-tools

## 简介

A browser that lives inside the DSH host: every session gets its own tab, the AI drives it with lazily published browser_embedded_* tools, and a human watches or takes over that same tab in an on-demand right-Sidebar tab — no GUI, no external browser, log
