# dsh-better-fork

> 标签: JavaScript

## 简介

DSH plugin: shallow seeds — one server-side wrap over ctx.agents.create cuts every child-session seed at the parent's newest compaction checkpoint, so forking, better-sidebar side chats, and subagent forks on long conversations cost O(post-compaction tail
