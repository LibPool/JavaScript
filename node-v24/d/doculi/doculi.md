# doculi

> 标签: cli, document-conversion, docx, ink, odb, odf, odg, odm, odp, ods, odt, pdf, pptx, tui

## 简介

CLI and interactive Ink TUI for documents.js: every docx/pptx/odt/odp/ods/odg/odf/pdf/odm/odb/xlsx/csv/svg/markdown/rtf conversion, bridge, and editor as a scriptable command or a terminal app.
