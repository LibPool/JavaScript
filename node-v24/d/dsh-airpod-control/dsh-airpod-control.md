# dsh-airpod-control

> 标签: accessibility, airpods, approval, deepseek-harness, dsh-plugin, head-gesture, macos, voice-control

## 简介

Control DeepSeek Harness from AirPods head gestures (via HeadOrbit): nod = allow / confirm, shake = reject / next option. Ships a one-click installer for the menu-bar app.
