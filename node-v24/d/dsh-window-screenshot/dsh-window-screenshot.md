# dsh-window-screenshot

> 标签: cordis, deepseek, deepseek-harness, dsh, macos, screenshot

## 简介

Capture the frontmost macOS window with a dual-Shift shortcut and attach it to DeepSeek Harness.

## 官网

- npm 页面：https://www.npmjs.com/package/dsh-window-screenshot

## 历史版本号

- 1.1.0

## 获取地址

- npm 安装：`npm install dsh-window-screenshot`
- npm registry：https://registry.npmjs.org/dsh-window-screenshot
- Node 要求：^22.19.0 || >=24.0.0
