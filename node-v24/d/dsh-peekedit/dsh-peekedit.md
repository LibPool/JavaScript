# dsh-peekedit

> 标签: cordis, deepseek-harness, dsh, dsh-plugin, filesystem, tools

## 简介

Enhanced file tools for DeepSeek Harness: peek (windowed view), peek_edit (literal replace / insert), peek_write (create / overwrite).
