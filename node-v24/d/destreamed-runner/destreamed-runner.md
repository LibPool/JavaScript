# destreamed-runner

> 标签: JavaScript

## 简介

Headless autonomer Tuner-Runner für Destreamed — pollt Tasks, triggert wahlweise Claude Code oder Codex als LLM-Worker, mit Toolchain-Modulen (Rust/Python/Go/…), Vault-Integration und GitLab-Repo-Mirror.
