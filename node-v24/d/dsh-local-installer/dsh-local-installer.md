# dsh-local-installer

> 标签: client-plugin, deepseek, deepseek-harness, dsh, dsh-plugin, plugin-installer, plugin-manager

## 简介

Local plugin installer for DeepSeek Harness: a Settings page with a file picker — pick .tgz plugin packages and install them into the current profile without a terminal. 本地插件安装器：设置页里点按钮选择本地 .tgz 插件包直接安装。
