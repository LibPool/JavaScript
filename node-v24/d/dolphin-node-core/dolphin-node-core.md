# dolphin-node-core

> 标签: JavaScript

## 简介

`dolphin-node-core` 是一個 node.js 的套件，由向皓田開發，採用 MIT 授權。此套件包含了一些常用的 JavaScript 物件集合：型別、向量、矩陣、位元陣列。
