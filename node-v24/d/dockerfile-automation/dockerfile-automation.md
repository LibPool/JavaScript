# dockerfile-automation

> 标签: automation, docker, dockerfile, github actions, java, kubernetes, node.js, python

## 简介

**dockerfile-automation** is a powerful CLI tool designed to streamline the creation of Dockerfiles, Kubernetes Services and Deployments, and Github Actions workflows, simplifying the containerization and deployment processes for Node.js, Python, and Java
