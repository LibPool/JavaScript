# dsh-hot-search

> 标签: chinese, cjk, cordis, deepseek-harness, dsh, dsh-plugin, fff, fuzzy, grep, obsidian, search

## 简介

Resident hot search for DSH: FFF-backed fuzzy filename + indexed grep + CJK typo-tolerant content search, all in the host process (no per-query process spawn).
