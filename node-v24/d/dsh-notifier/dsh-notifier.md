# dsh-notifier

> 标签: bark, deepseek-harness, dingtalk, dsh, feishu, ilink, notification, notify, plugin, pushplus, qq-bot, qr-login, remote-approval, serverchan, telegram, webhook, weixin, wxpusher

## 简介

DSH 通知插件：一个 notify() 打通 27 个出站渠道；支持 Telegram / 飞书 / QQ / 钉钉等入站远程审批、提问与对话回传；内置本机 Web 管理台。零运行时依赖。
