# dsh-lore

> 标签: agent-skills, documentation, dsh-plugin, journal, knowledge-base, lessons, memory, notes, work-log

## 简介

Work-memory system for AI agents, in three layers: a portable Agent Skill (process journal + index ledger + lessons, stdlib-only toolbox), a cross-workspace global memory, and a DeepSeek Harness plugin bundle that injects it.
