# decisionnode

> 标签: ai, antigravity, claude, cursor, decisions, embeddings, gemini, mcp, model-context-protocol, rag, semantic-search, windsurf

## 简介

Record structured decisions once, search them from all your AI coding tools — a shared structured semantic memory store across Claude Code, Cursor, Windsurf, Antigravity, and every MCP client.
