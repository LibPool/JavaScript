# dsh-chatvoice

> 标签: deepseek-harness, dsh, free, plugin, read-aloud, speech, speech-recognition, speech-synthesis, tts, voice, voice-input, zh-CN

## 简介

ChatVoice — free voice input + AI reply read-aloud for DeepSeek Harness (dsh). Zero config, zero cost, no API key, built on the browser's native Web Speech API. 给 DSH 装上「免费、免 API key、开箱即用」的语音输入 + 回复朗读闭环（中文优先）。
