# dsh-htmlrun

> 标签: deepseek-harness, dsh-plugin, htmlrun, publish, share

## 简介

Publish local single-file HTML to shareable html.run links as a DeepSeek Harness model tool (wraps the zero-dependency htmlrun.cjs CLI).
