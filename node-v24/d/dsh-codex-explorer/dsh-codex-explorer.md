# dsh-codex-explorer

> 标签: JavaScript

## 简介

DSH web plugin: a Codex-style filesystem explorer tab for dsh-better-sidebar — browse the WHOLE disk (no workspace fence) and open/edit any file the agent drops outside the session cwd. Previews: Markdown, Word (docx-preview) / PowerPoint (@aiden0z/pptx-r
