# dumi-theme-aipmhub

> 标签: aipmhub, dumi, dumi theme

## 简介

dumi-theme-aipmhub is a documentation site theme package designed for dumi2. It provides a more beautiful and user-friendly development and reading experience based on @aipmui/ui
