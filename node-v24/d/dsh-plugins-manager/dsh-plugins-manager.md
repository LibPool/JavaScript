# dsh-plugins-manager

> 标签: deepseek-harness, dsh, manager, npm, plugin

## 简介

DeepSeek Harness plugin: a GUI + dsh_plugin_manage tool to control your custom DSH plugins — list, install, update, uninstall, enable and disable (from npm).
