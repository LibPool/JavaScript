# dsh-session-search-plus

> 标签: deepseek-harness, dsh, search, search-plus, session-search

## 简介

DSH 会话搜索框增强：自建高速内存索引（持久化增量缓存，热启动 ~90ms）+ /api/search-plus 路由，接管官方侧栏搜索框（vscode 风格 Aa/ab/.*/fz 模式开关、多命中下拉、锚点跳转高亮）
