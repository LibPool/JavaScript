# docpad-plugin-heapdumper

> 标签: analysis, docpad, docpad-plugin, heap, heapdump

## 简介

Dumps a heap snapshot for each event in docpad, viewable in chrome profiler

- 官网：http://docpad.org/plugin/heapdumper
