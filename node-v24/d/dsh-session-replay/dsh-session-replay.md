# dsh-session-replay

> 标签: deepseek-harness, dsh, replay, session, share

## 简介

DeepSeek Harness 会话链接回放：把任意对话生成可分享的动画回放链接（Manus 风格），支持倍速、工具卡片、思考过程，并可导出自包含 HTML 离线分享。
