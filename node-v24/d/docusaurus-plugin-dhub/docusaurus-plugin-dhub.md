# docusaurus-plugin-dhub

> 标签: cms, dhub, docusaurus, docusaurus-plugin, mdx, visual-editor

## 简介

Docusaurus plugin for Dhub (dhub.dev): adds "Edit in Dhub" links to docs and blog pages and emits a dhub.json route-to-source manifest.
