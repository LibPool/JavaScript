# dsh-cmtoken-oauth

> 标签: cmtoken, cordis, deepseek-harness, device-grant, dsh, maas, oauth, pkce, plugin

## 简介

DeepSeek Harness 插件：在 DSH 设置页一键完成中国移动算力豆平台（komect）扫码认证——一次扫码自动桥接密钥管理会话、创建专属 DSH API key（lx_sk_，长期有效）、发现模型（上下文/输出/图片支持由平台动态提供）并写入 llm-pi-ai provider 配置，同时展示算力豆用量余额；粘贴识图让纯文本模型直接收图，另有 cmtoken_read_image 工具与可选的 cmtoken-vision 包装路由。零第三方运行时依赖。
