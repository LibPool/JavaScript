# digio-api

> 标签: Digital Ocean, api, api v2.0, digitalocean, do, v2.0, wrapper

## 简介

digio-api is a DigitalOcean v2.0 API library that exposes all DigitalOcean v2.0 API methods in a simple and orderly fashion.
