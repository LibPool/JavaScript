# dsh-fs-encoding

> 标签: big5, bom, coding-agent, deepseek-harness, dsh, dsh-plugin, edit, encoding, gbk, iconv, read, shift-jis, utf-16, write

## 简介

Encoding-governed read/write/edit tools for DeepSeek Harness (dsh): UTF-8 BOM fidelity and byte-exact round-trips for GBK, Big5, Shift-JIS, EUC-KR, Windows-1251 and UTF-16 text files.
