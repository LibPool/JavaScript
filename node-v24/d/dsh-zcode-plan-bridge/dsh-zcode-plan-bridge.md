# dsh-zcode-plan-bridge

> 标签: deepseek-harness, dsh-plugin, glm, model-provider, zai, zcode

## 简介

Exposes the ZCode CLI's bundled agent as a DeepSeek Harness model provider: streaming, image input, per-session reuse, and a model list read from the CLI instead of hard-coded. Derived from kyle123740/dsh-zcode-cli-proxy.
