# doclens

> 标签: csv-viewer, document-viewer, docx, file-viewer, highlight, json, markdown, pdf-viewer, pptx, react, search, xlsx-viewer, xml, zoom

## 简介

Framework-agnostic universal document viewer with search, highlight, zoom, and deep customization. Supports PDF, XLSX, CSV, PPTX, DOCX, XML, JSON, HTML, Markdown, images, video, audio, and plain text.
