# dsh-telegram-multiagent

> 标签: agent, channel, deepseek-harness, dsh, dsh-plugin, telegram

## 简介

Канал Telegram для DeepSeek Harness: один модуль на машину обслуживает несколько агентов, у каждого свой бот, свой файл токена и свой список разрешённых. Метка отправителя неподделываема, память владельца и координатора слита в одну, режим доставки перекл
