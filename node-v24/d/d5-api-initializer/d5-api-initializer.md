# d5-api-initializer

> 标签: JavaScript

## 简介

Для локальної роботи з даною бібліотекою потрібно слідувати наступної інструкції - 1. Підключаємо бібліотеку через команду yarn link. 2. На проекті, до якого треба підключити дану бібліотеку, виконуємо команду yarn link "d5-api-initializer". 3. Білдимо
