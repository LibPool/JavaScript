# dsh-attest-chain

> 标签: ai-agents, attestation, chain-of-custody, deepseek-harness, dsh-plugin, in-toto

## 简介

Signed chain-of-custody for DeepSeek Harness sessions: every watched tool result appends a hash-chained, ed25519-signed record — what the agent did, provable after the fact
