# dsh-plugin-vscode-bridge

> 标签: automation, code, coding, deepseek, dsh, dsh-plugin, vscode

## 简介

DSH ↔ VS Code 自动化闭环插件：打开/跳转文件、新窗口、扩展管理、进程状态、工作区变更检测（供智能体驱动 VS Code）。
