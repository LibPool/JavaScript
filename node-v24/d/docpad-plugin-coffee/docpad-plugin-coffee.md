# docpad-plugin-coffee

> 标签: coffee, coffeecss, coffeekup, coffeescript, docpad, docpad-plugin

## 简介

Adds support for the various CoffeeScript inspired pre-processors to DocPad. Including CoffeeScript, CoffeeKup and CoffeeCSS, among others.
