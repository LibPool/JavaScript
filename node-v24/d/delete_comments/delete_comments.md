# delete_comments

> 标签: comment, delete, javascript, jsx, remove, strip, tsx, typescript

## 简介

after facing bugs with other comment removal packages like strip-comments and others I decided to build my own it simply removes comments of javascript files and files that matchs javascript comment and string pattern it also deletes jsDoc comments
