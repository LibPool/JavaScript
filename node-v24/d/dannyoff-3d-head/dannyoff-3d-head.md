# dannyoff-3d-head

> 标签: 3d-head, glb, sample, three.js

## 简介

Sample 3D head model (GLB) for the 'Danny's Clock-Out Button' 3D face hero prompt. Served via jsDelivr as the default face when the user has no head.glb yet.
