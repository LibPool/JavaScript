# dsh-plugin-diraud

> 标签: audit, cordis, deepseek, dsh, origin, plugin, plugin-list

## 简介

Audit the DeepSeek Harness plugin list by origin (official vs self-installed): a /plugin-audit command plus a Source tab in Web Settings
