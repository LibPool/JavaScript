# directus-extension-mcp

> 标签: ai, anthropic, claude, directus, directus-extension, directus-extension-endpoint, llm, mcp, model-context-protocol

## 简介

A Directus extension that provides MCP (Model Context Protocol) server functionality with HTTP streaming support, allowing any MCP client to connect to your Directus instance
