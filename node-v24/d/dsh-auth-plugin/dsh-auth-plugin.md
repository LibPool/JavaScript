# dsh-auth-plugin

> 标签: auth, deepseek-harness, dsh, ed25519, evm, login, metamask, oauth, plugin, secp256k1, solana, wallet

## 简介

DSH Web 用户授权插件 — 用户名密码 + 通用 OAuth 2.0（内置 GitHub/Google/Discord 等模板）+ Solana/EVM 钱包登录。零依赖核心，纯配置接入
