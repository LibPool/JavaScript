# dsh-notify-desktop

> 标签: deepseek-harness, desktop, dsh, notification, plugin, toast, windows

## 简介

Windows native notifications for the DSH desktop app: a session finishes, fails, or stops to ask you something and you get a toast with a per-situation sound; clicking it raises the DSH window.
