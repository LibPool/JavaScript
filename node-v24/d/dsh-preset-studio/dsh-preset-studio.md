# dsh-preset-studio

> 标签: agent-preset, dsh, dsh-plugin, preset, settings

## 简介

DSH 预设工作室：在设置里用一个整页新建 / 编辑 / 复制 / 删除本 profile 的 Agent 预设——组成树、系统提示词（含 {{变量}} 校验）、装配诊断、来源行定位、与 standard 的差异对比、快照回滚，以及导出为可分享的 bundle。0.2.1 起适配 DSH 0.2.1（官方删除 webRuntime 服务，信任校验改用 connection.requestRejection，并修复旧版退化放行的隐患）。
