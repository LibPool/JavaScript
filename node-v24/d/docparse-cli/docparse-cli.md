# docparse-cli

> 标签: ai-agent, cli, document-parsing, markdown, mineru, ocr, pdf

## 简介

Document to Markdown CLI for AI agents, built on the MinerU parsing API. Multi-account key pool with automatic load balancing; prints the path of the parsed Markdown instead of its content.
