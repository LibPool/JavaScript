# dexie-observable

> 标签: addon, browser, dexie, indexeddb

## 简介

Addon to Dexie that makes it possible to observe database changes no matter if they occur on other db instance or other window.

## 官网

- 官网：https://dexie.org
- 源码仓库：git+https://github.com/dexie/Dexie.js.git
- npm 页面：https://www.npmjs.com/package/dexie-observable
