# dft-autopilot-mcp

> 标签: computational-chemistry, dft, gaussian, hpc, materials-science, mcp, model-context-protocol, quantum-espresso, slurm, vasp

## 简介

DFT AutoPilot — an MCP server that automates DFT computational chemistry (Quantum ESPRESSO / VASP / Gaussian) on your own HPC (SCNet, Slurm, or local).
