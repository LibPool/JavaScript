# dsh-pet-live2d-miyako

> 标签: cordis, cubism, deepseek-harness, desktop-pet, dsh, live2d, miyako, pet, plugin, web

## 简介

Live2D desktop pet for the DeepSeek Harness web GUI: a real Cubism 5 model with breath, physics, blinking, gaze tracking, 81 motions and 70 expressions, plus 11 voiced lines that animate both the character and her plush, driven by session activity.
