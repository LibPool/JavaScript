## 简介

A ZCode/Claude skill that indexes Dart language features, core libraries, and tooling (analyzer/pub/devtools/FFI/JS interop) by Dart version — only Stable, never Experimental/Preview. Covers Dart 3.0 through 3.12. Install-and-use: copies itself into .clau
