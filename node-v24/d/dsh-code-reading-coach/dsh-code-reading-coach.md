# dsh-code-reading-coach

> 标签: agent-preset, code-reading, deepseek, dsh, dsh-plugin, harness, paper

## 简介

代码研读教练（Code Reading Coach）— 交互式引导研读论文对应开源代码的 Agent 预设插件。五段研读法：锚定论文主张 → 地形扫描 → 入口追踪 → 核心映射 → 闭环验证。
