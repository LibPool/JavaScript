# dsh-question-note

> 标签: ask-user-question, deepseek, deepseek-harness, dsh, dsh-plugin, interactive-question, supplement-note

## 简介

DSH ask_user_question enhancement: selecting an option reveals an optional note input right under it; the note is sent to the model alongside the selection.
