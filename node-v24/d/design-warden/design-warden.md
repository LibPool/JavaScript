# design-warden

> 标签: accessibility, ai-agents, ci, code-review, css, design-system, design-tokens, frontend, linter, react, svelte, tailwind, visual-regression, vue

## 简介

CI check for design-system drift in frontend pull requests, built for UI written by AI coding agents. Deterministic checks for React, Vue, Svelte and CSS, optional visual diffs, and an AI reviewer that can flag but never block.
