# dsh-subagent-library

> 标签: deepseek-harness, dsh, library, plugin, subagent

## 简介

Named subagent library for DeepSeek Harness: a directory-backed roster of role subagents (one YAML file per agent: model + persona + tool filter), exposed to every session through the list_subagents and delegate tools, a /subagent command, and a Settings
