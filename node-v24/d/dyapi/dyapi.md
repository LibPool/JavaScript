# dyapi

> 标签: api, backend, bun, crud, declarative, framework, koa, micro-backend, mongodb, mysql, orm, rest, snowflake-id, sqlite

## 简介

声明你的数据，得到一套生产可用的 API：一个 Model 类，五种存储后端，零胶水代码。Declare your data, get a production API — one model class, five storage backends, zero glue code.
