# dirent

> 标签: dir, directory, directory entity, dirent, entity, file, file system, file-system, fs, fs.Dirent, path, readdir, readdirsync, vfile, vfs, vinyl, virtual file

## 简介

Virtual file class. Extends the native fs.Dirent class with methods to simplify path handling. Similar to Vinyl, but lightweight.
