# dsh-project-mcp-manager

> 标签: cordis, deepseek-harness, dsh, mcp, plugin, project

## 简介

dsh-project-mcp-manager: per-project and global MCP server loading for DSH. Reads <projectRoot>/.dsh/mcp.yml or .dsh/mcp.json (plus the read-only Claude Code project file .mcp.json), mounts project rows per project and user-layer rows (~/.dsh/mcp.yml, ~/.
