# docpad-plugin-sass

> 标签: compass, css, docpad, docpad-plugin, render, rendering, sass, scss, styles, stylesheets, styling

## 简介

Adds support for the SASS and SCSS CSS pre-processors to DocPad. It also supports the Compass framework.
