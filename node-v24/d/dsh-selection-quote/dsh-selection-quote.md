# dsh-selection-quote

> 标签: add-to-chat, cordis, deepseek-harness, dsh, dsh-plugin, inline-comment, pr-review, selection-quote

## 简介

Codex + Cursor style selection quote & inline comment plugin for DeepSeek Harness (划词右键菜单「拷贝 / 添加到对话 ⌘L」+ 持续选中高亮 + 蓝色水滴序号角标与圆角胶囊评论框 + 输入框与已发送消息「💬 N 条注释」胶囊及悬浮详情卡片)
