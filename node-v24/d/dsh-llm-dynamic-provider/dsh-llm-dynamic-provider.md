# dsh-llm-dynamic-provider

> 标签: deepseek-harness, dsh, dynamic-provider, llm, model-discovery

## 简介

Runtime-discovered pi-ai provider routes: probe an endpoint at boot, register its models into the in-memory LLM registry — nothing written to settings
