# dst-standard-framework

> 标签: JavaScript

## 简介

## 快速入门 本框架提供了基础的开发流程，包含了定时任务、Redis、拦截注入日志、特定接口客户端请求转发、以及接口拦截等样例，多请求实例封装，针对不同服务配置不同公用参数和处理标准化多返回结果，能够有效的提升研发效率。 基于 midway、egg ,如需进一步了解，参见 [midway 文档][midway]。
