# dsh-model-reasoning-defaults

> 标签: cordis, deepseek, deepseek-harness, dsh, dsh-plugin, llm, reasoning, reasoning-effort

## 简介

DSH (DeepSeek Harness) 插件：为每个 LLM 模型配置默认推理等级（reasoningEffort），并在请求进入底层调用链前按路由规则自动补齐
