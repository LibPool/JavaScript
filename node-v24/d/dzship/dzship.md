# dzship

> 标签: algeria, algerie, cash-on-delivery, cod, communes, conexlog, delivery, dhd, dz, dzbuild, ecotrack, livraison, maystro, noest, procolis, shipping, wilaya, yalidine, zr-express

## 简介

Client for dzship, the free shipping API for Algeria. Create and track COD parcels with 99 couriers (Yalidine, ZR Express, Maystro, NOEST, DHD, Conexlog and every Ecotrack courier) through one request shape. Includes the wilaya and commune dataset.
