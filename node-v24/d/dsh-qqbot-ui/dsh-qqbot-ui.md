# dsh-qqbot-ui

> 标签: cordis, deepseek-harness, dsh, plugin, qq, qqbot, settings-ui

## 简介

QQ 机器人插件（基于腾讯 @tencent-connect/dsh-qqbot@0.5.0 重新打包）＋ DSH Web「设置」里的可视化配置页。一个包同时提供宿主半与 client 半，一条 `dsh plugin add dsh-qqbot-ui` 装齐。
