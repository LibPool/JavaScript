# dsh-scheduled-tasks

> 标签: automation, cron, deepseek, deepseek-harness, dsh, dsh-plugin, i18n, scheduled-tasks, scheduler, sidebar

## 简介

Scheduled-task plugin for the dsh web sidebar: create tasks that run a natural-language prompt in dsh at a set time (one-off / daily / weekly / interval), with a sidebar manager UI placed between the New Session button and the Workspace list. UI language
