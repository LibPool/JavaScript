# decision-api

> 标签: classification, cloudflare, decision, llm, openai, openrouter, typesafe, zod

## 简介

One typed client for decision models (TypeSafe Jev, Cloudflare Clef, OpenAI gpt-6-luna, OpenRouter models such as Microsoft-Decision-1) that answer questions with calibrated probabilities
