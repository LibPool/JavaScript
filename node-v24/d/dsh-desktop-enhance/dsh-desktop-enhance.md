# dsh-desktop-enhance

> 标签: dsh, dsh-desktop, plugin

## 简介

DSH Desktop 界面增强：页内查找（Cmd+F）、轮次编号、上下文压缩行常显、建议、每步耗时、折叠文件夹状态计数、会话信息（含上下文注入 C1 视图）、工具管理、Skill 管理。
