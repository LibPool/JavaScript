# dsh-duration

> 标签: deepseek-harness, dsh, dsh-plugin, duration, 时长, 格式化

## 简介

时长格式化：把毫秒/秒等时长转换为人类可读的 X 小时 Y 分钟 Z 秒，支持多种单位（Duration formatter tool for DeepSeek Harness）
