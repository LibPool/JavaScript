# dsh-hooks-plugin

> 标签: cordis, deepseek-harness, dsh, hooks, plugin

## 简介

Claude Code style hooks for DeepSeek Harness: run shell commands on agent/tool lifecycle events from .dsh/hooks.json (CC-compatible JSON shape).
