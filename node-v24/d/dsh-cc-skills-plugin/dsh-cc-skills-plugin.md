# dsh-cc-skills-plugin

> 标签: JavaScript

## 简介

Claude Code 兼容插件：设置页两个开关 —— 1) 读取并兼容 Claude Code skill 目录（~/.claude/skills 与项目 .claude/skills）；2) 对话开始时加载全局/项目 claude.md 并告知用户
