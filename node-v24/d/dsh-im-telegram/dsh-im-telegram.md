# dsh-im-telegram

> 标签: deepseek-harness, dsh, dsh-plugin, im-bridge, telegram, telegram-bot

## 简介

Telegram 渠道适配器（dsh-im 插件家族）：bot API polling 长连接，免公网；支持内联按钮审批卡片。
