# ddei-flowgraph-layout

> 标签: ddei, ddei-autograph-layout, ddei-editor, 图形框架, 在线设计器, 插件扩展, 流程图自动排版, 自动排版

## 简介

根据业务数据自动生成排版信息，支持分组和连线合并，返回排版后的分组以及任务数据。
