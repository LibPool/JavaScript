# dsh-skins

> 标签: acg, anime, cordis, deepseek-harness, dsh, font, palette, skin, theme

## 简介

ACG-style appearance pack for DSH web: token theme families with native light/dark pairs plus full CSS skins, both replacing the overall style, palette, and fonts.
