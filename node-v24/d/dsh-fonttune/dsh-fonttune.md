# dsh-fonttune

> 标签: deepseek-harness, dsh, dsh-plugin, font, font-family, font-size, font-weight, typography

## 简介

Font plugin for the DeepSeek Harness Web GUI: the conversation gets its own font, size, line height and weight, the interface font and weight follow it, code keeps its own axis with ligature control, and whole setups save as presets.
