# dsh-plugin-open-in-browser

> 标签: browser, cordis, deepseek-harness, dsh, dsh-plugin, open-in-browser, sidebar

## 简介

Open a sidebar file in the system default browser from a DSH tab's right-click menu or the unpreviewable-file empty state.
