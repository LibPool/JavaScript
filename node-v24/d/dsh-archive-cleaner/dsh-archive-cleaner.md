# dsh-archive-cleaner

> 标签: archive, cleanup, deepseek-harness, dsh, dsh-plugin, session

## 简介

DeepSeek Harness has no delete feature yet — archiving only hides a session and leaves its log on disk forever. This plugin adds the missing delete: permanently remove the archived sessions you no longer need, from the sidebar's session menu or with the /
