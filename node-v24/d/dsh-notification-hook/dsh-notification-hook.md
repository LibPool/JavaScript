# dsh-notification-hook

> 标签: deepseek, desktop-notification, discord, dsh, feishu, notification, slack, telegram, webhook, wecom

## 简介

Notification & Webhook Hook: native desktop popups and HTTP POSTs (Feishu / WeCom / Telegram / Discord / Slack) when a session finishes, fails, or starts waiting for you. Ships a live settings page in the Web UI.
