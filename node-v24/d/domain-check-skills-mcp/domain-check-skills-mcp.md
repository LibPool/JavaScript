> 标签: ai-agent, claude, cursor, domain, domain-availability, domain-search, domains, fastest, llm-tools, mcp, model-context-protocol, rdap, registrar, whois, windsurf

## 简介

The fastest domain-availability MCP server — or the second, dispute it. Checks in about half a second, ~0.1 s cached, from any LLM: Claude, Cursor, Windsurf, Continue. 6 registrars, 50+ TLDs, no API key. By DigMyName.
