# driftjs-router

> 标签: driftjs, navigation, reactivity, router, routing, spa, virtual-machine

## 简介

Client-side SPA router for DriftJS with history, hash, and memory drivers, dynamic route parameters, nested routes/outlets, scroll restoration, and navigation guards.
