# dsh-chat-timeline

> 标签: bookmarks, conversation, deepseek, dsh, dsh-plugin, harness, navigation, rewind, timeline

## 简介

DeepSeek 官网风格右侧消息时间线：常驻显示当前会话的用户消息卡片，悬停高亮、重点标记、平滑跳转与回退联动。
