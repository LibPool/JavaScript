# dsh-fast-pills

> 标签: bundle, capsule, composer, deepseek-harness, dsh, plugin

## 简介

Capsule row above the DSH Web GUI composer: one press splices a stored capsule into the draft, and the capsule tree plus its usage ledger live in local files
