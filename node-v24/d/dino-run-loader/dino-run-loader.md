# dino-run-loader

> 标签: animation, chrome-dino, custom-element, dino, loader, loading, spinner, t-rex, web-component

## 简介

A waiting/loading Web Component: the Chrome T-Rex Runner running and auto-jumping over cacti, non-playable, themeable. Drop-in, zero dependencies.
