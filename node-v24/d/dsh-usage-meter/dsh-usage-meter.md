# dsh-usage-meter

> 标签: bundle, dashboard, deepseek-harness, dsh, plugin, token, usage

## 简介

DSH（DeepSeek Harness）模型用量仪表盘插件：按服务商/模型汇总全部会话 token 用量（assistant/message 带 usage 事件），设置页「用量」板块展示，含今日/7天/30天趋势柱状图。
