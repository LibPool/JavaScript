# dsh-page-struct

> 标签: agent, browser, dsh, dsh-plugin, page-structure, shadow-dom, table

## 简介

Read-only page structure for DSH, attached to the CUA browser: table coordinates, shadow DOM fields, code blocks, and confidence labels.
