# docker-disk-reclaim

> 标签: cleanup, compact, disk-space, docker, docker-desktop, fstrim, prune, vhdx, wsl2

## 简介

Reclaim disk space from Docker Desktop on WSL2: prune unused data, TRIM the VM filesystem and compact the virtual disk that never shrinks on its own.
