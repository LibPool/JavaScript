# docker-mdns-bridge

> 标签: avahi, bonjour, dns-sd, docker, docker-desktop, homebridge, macos, mdns, zeroconf

## 简介

Relay a Docker container's Bonjour/mDNS advertisements onto your real LAN — no host networking, no macvlan.
