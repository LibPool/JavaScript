# dsh-workspace-preview

> 标签: agent, cordis, deepseek, deepseek-harness, dsh, file-explorer, file-tree, markdown, plugin, preview, workspace

## 简介

dsh-workspace-preview: dsh 工作台插件 —— 4 列布局的工作区文件浏览器（第 3 列文件预览：代码高亮 / Markdown 渲染 / 图片，第 4 列可隐藏的目录树边栏）
