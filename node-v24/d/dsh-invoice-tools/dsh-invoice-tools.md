# dsh-invoice-tools

> 标签: cordis, dsh, invoice, 发票, 报销

## 简介

DSH 原生发票解析/报销单生成工具：读取工作区发票 PDF（XML 附件优先、文本层正则兜底），结构化 JSON + 金额勾稽校验，多张汇总生成报销单（Markdown / xlsx）。
