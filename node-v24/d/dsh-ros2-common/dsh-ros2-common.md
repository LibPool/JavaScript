# dsh-ros2-common

> 标签: deepseek-harness, dsh, dsh-plugin, ros2

## 简介

Shared runtime for the dsh-ros2 plugin family: command runner, parsers, ToolDeps toolkit, and the robot-profile script (zero-copy across packages). Not a cordis bundle.
