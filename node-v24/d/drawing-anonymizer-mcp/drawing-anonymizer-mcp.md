# drawing-anonymizer-mcp

> 标签: anonymize-pdf, cnc, data-privacy, drawing-anonymizer, drawing-masking, engineering-drawing, gdpr, imnoo, manufacturing, mcp, mcp-server, model-context-protocol, nda, pdf-anonymization, pdf-redaction, redact-pdf, technical-drawing, title-block, white-out

## 简介

MCP server that anonymizes technical-drawing PDFs: finds company names, logos, people, addresses, phone numbers, emails and URLs, masks them and writes a flattened, metadata-free PDF or an expiring share link. Powers https://drawing-anonymizer.imnoo.com
