# dsh-chat-tree

> 标签: branch, conversation, deepseek-harness, dsh, dsh-plugin, session, tree

## 简介

Conversation trees for DeepSeek Harness: every branch of a conversation drawn as a clickable tree beside the chat / 把一个对话的所有分支画成一棵可点击的树
