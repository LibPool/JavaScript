# devinpipe

> 标签: acu, attachments, context-compression, devin, devin-cli, mitm, proxy, token-optimization, vision-tokens

## 简介

Token-saving HTTPS intercepting proxy for Devin CLI: renders bulky context as dense PNGs and uploads them as attachments, cutting input characters/ACU.
