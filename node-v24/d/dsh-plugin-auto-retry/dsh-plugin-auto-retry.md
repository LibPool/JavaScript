# dsh-plugin-auto-retry

> 标签: agent, auto-retry, cordis, deepseek-harness, dsh, dsh-plugin, request-error, retry

## 简介

DeepSeek Harness plugin that takes over a model-request failure the built-in retry executor declined, continuing its backoff curve, and surfaces the full failure detail the transcript discards.
