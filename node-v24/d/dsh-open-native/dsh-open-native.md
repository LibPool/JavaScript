# dsh-open-native

> 标签: deepseek-harness, deliverables, dsh, dsh-plugin, open-with-default-app

## 简介

Open delivered files with the system default app instead of DSH's built-in sidebar preview（点交付卡片直接用系统默认程序打开，不再进侧边栏预览）
