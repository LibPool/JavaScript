# dsh-api3d

> 标签: api3d, cordis, deepseek-harness, dsh-plugin, openai-compatible, relay

## 简介

把 API3D（api3d.cn）AI API 网关接成 DSH 的一条模型路由：基础地址、API Key 与出站兼容开关都在设置页。API3D (api3d.cn) as a single DeepSeek Harness model route.
