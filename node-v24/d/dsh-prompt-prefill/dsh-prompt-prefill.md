# dsh-prompt-prefill

> 标签: composer, deepseek-harness, dsh, dsh-plugin, ghost-text, next-prompt, prefill, prompt, prompt-history

## 简介

DeepSeek Harness 插件：Agent 回答结束后在输入框预填一条灰色的下一句建议，按 Tab 或 → 采纳；输入框为空时按 ↑ 填入上一次发送的内容。
