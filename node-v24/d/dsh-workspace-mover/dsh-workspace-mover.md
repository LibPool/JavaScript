# dsh-workspace-mover

> 标签: deepseek-harness, drag-and-drop, dsh, dsh-plugin, session, session-migration, workspace

## 简介

在 DSH 侧边栏安全迁移会话：真迁移原始档案，支持失联会话恢复、移动历史和一键撤回。
