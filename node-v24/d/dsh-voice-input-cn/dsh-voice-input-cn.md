# dsh-voice-input-cn

> 标签: deepseek-harness, dsh, dsh-plugin, speech, voice, 语音

## 简介

DSH 语音助手：免按键语音输入。注意：国内必须使用 Edge 浏览器（Chrome 语音识别走谷歌服务器不可达）。
