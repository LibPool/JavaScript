# dgr-tributario-libraries

> 标签: corrientes, dgr, forms, oracle, tributario

## 简介

Lógica de negocio migrada de las librerías PL/SQL legacy de Oracle Forms de la DGR Corrientes: motor de metadata de formularios, validaciones y catálogo de mensajes.
