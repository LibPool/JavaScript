# dsh-anchor-rail

> 标签: anchor, deepseek-harness, dsh, navigation, rail, session, 会话, 导航, 锚点

## 简介

DSH Web 会话锚点导轨插件：左侧导轨展示会话全部用户问题（含压缩前历史），悬浮显示全部锚点名称（与导轨对齐），点击快速跳转。Session anchor rail for DeepSeek Harness Web.
