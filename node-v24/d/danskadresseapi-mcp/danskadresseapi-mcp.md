# danskadresseapi-mcp

> 标签: address, adresse, ai, bbr, claude, dagi, danmark, dawa, denmark, mcp, model-context-protocol

## 简介

Officiel MCP-server for DanskAdresseAPI — giver AI-agenter (Claude Desktop, Claude Code, Cursor m.fl.) værktøjer til at slå danske adresser, BBR, DAGI og postnumre op.
