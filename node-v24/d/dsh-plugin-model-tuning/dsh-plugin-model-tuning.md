# dsh-plugin-model-tuning

> 标签: compat, deepseek-harness, dsh, dsh-plugin, image-generation, model, reasoning, settings

## 简介

只补官方没有的两块：①「设置 → 模型」卡片里的兼容开关与内置目录路由推理覆盖（官方 Models 页没有的 compat.supportsDeveloperRole / compat.forceAdaptiveThinking / modelOverrides.reasoningEfforts）；②「设置 → 绘图」页（绘图模型配置 + generate_image / list_image_models 工具 + 直接绘图面板）。v3 起标题生成路由交还官方 session-title 行，模型参数页
