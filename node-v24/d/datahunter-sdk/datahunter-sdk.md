# datahunter-sdk

> 标签: sdk

## 简介

- 页面PV自动上报 - 页面关闭(unload)时暂存上报数据。下次打开时自动上报页面关闭数据，随后清除。 - 增加`runtime_id`。当用户在某一浏览器中，打开同一地址多个tab页面时，`runtime_id`会不同。此字段可区分用户不同浏览进程的行为的跟踪，防止多浏览进程交叉导致行为数据混淆。
