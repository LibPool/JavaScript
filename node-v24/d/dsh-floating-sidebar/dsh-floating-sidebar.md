# dsh-floating-sidebar

> 标签: deepseek-harness, dsh, dsh-plugin, floating-sidebar, sidebar

## 简介

DSH web plugin: an icon in the collapsed sidebar rail. Hover it and the real sidebar pushes out as a floating island card over the conversation, so sessions stay navigable while the sidebar is collapsed.
