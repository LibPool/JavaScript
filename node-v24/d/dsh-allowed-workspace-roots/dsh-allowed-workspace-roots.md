# dsh-allowed-workspace-roots

> 标签: deepseek-harness, dsh, dsh-plugin, rclone, realpath, winfsp, workspace

## 简介

DSH Desktop plugin: allow selected non-NTFS roots (e.g. an rclone/WinFsp SFTP mount) as workspaces, and repair fs.realpath on such volumes.
