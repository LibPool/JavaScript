# dsh-office-reader

> 标签: JavaScript

## 简介

DSH Office read + generate: read Word/Excel/PowerPoint (docx/xlsx/pptx and legacy doc/xls/ppt) into text/tables in memory (no intermediate files, model on-demand), and generate styled Word (.docx) from Markdown (md2docx moved here). | DSH 插件：Office 读取 + 生
