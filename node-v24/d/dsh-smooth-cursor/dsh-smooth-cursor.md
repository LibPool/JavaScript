# dsh-smooth-cursor

> 标签: caret, composer, cursor, dsh, dsh-plugin

## 简介

Smooth comet-mode animated caret for the DSH chat composer — a standalone installable DSH plugin (ported from the Obsidian Animated Cursor plugin)
