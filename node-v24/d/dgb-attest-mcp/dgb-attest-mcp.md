# dgb-attest-mcp

> 标签: ai-agents, attestation, digibyte, mcp, notarization, op_return, provenance, timestamping

## 简介

On-chain attestation for the AI era: hash any content onto DigiByte via OP_RETURN — a permanent, timestamped, tamper-evident proof it existed. Verify anytime.
