# design-brief-builder

> 标签: agent, ai, claude-code, codex, cursor, design, design-brief, skill, spec-driven

## 简介

A pre-execution governance layer for AI-assisted design. Turns design requests into structured constraint files before an AI agent (Claude Code, Cursor, Codex, and beyond) starts working.
