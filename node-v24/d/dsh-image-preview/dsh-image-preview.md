# dsh-image-preview

> 标签: attachment, deepseek-harness, dsh, dsh-plugin, heic, image, lightbox, preview, read_image, svg, tiff

## 简介

Inline previews for the images an agent already produced in DeepSeek Harness: read_image attachments and local paths in any format (HEIC/TIFF/PSD/SVG/BMP/ICO/TGA/PNM/JP2 …), rendered through the official gallery and lightbox.
