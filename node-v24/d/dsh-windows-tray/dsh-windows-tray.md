# dsh-windows-tray

> 标签: deepseek, dsh, harness, notifyicon, powershell, system-tray, tray, windows

## 简介

DSH (DeepSeek Harness) Windows 系统托盘: 蓝/灰鲸鱼状态图标 + Web/TUI 一键启停控制。纯 PowerShell + WinForms, 零依赖。※ 菜单「备份」需 personal-docs 侧的备份引擎（不随本包分发，缺则显式提示未就绪）——见 README「前置依赖」。
