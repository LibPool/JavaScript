# dsh-comfyui-workbench

> 标签: audio, comfyui, comfyui-api, cordis, deepseek-harness, dsh, dsh-plugin, image-generation, img2img, inpaint, model-inspection, music, remove-background, stable-diffusion, text2img, video, workbench, workflow

## 简介

A ComfyUI workbench for DeepSeek Harness (DSH): generate images, audio and video, inspect every installed model and node schema, build and run arbitrary workflows, and reach any ComfyUI endpoint.
