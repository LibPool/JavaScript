# dsh-tray-launcher

> 标签: deepseek-harness, dsh, dsh-plugin, launcher, powershell, system-tray, windows

## 简介

DeepSeek Harness 的 Windows 桌面托盘启动器（纯 PowerShell，零安装包、零运行时）：无窗口运行 dsh web，托盘右键切换图标、开机自启、重启 Harness，并内置用量/费用仪表插件（dsh-plugin-usage-meter）的一键安装与更新。同时以 dsh 插件形式提供（dsh plugin add 后托盘随 Harness 自动启动）。
