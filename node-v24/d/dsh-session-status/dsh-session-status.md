# dsh-session-status

> 标签: cordis, deepseek-harness, dsh, label, plugin, session, session-status

## 简介

给每个 DSH 对话设置项目状态标签（进行中/已结项/搁置中 + 自定义），会话列表最小可见，对话内头部角落可切换，跨会话/跨浏览器持久化
