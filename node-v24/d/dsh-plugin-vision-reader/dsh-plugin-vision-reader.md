# dsh-plugin-vision-reader

> 标签: cordis, deepseek, dsh, harness, image, multimodal, plugin, read_image, vision

## 简介

DeepSeek Harness host+client plugin: images go straight to the main model untouched, and pasted images are persisted to local files so the same picture can be re-read at any later point. Adds a `vision` tool for an independent second opinion from DeepSeek
