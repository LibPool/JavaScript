# dsh-tui-theme

> 标签: deepseek-harness, dsh, dsh-tui, pink, plugin, terminal, theme

## 简介

Sakura-pink themes for dsh-TUI with optional cached background follow (pink-day/pink-night), a blossom status line, and a /settings section. No shortcuts, no commands.
