# dynamic-styleguide

> 标签: CSS, SCSS, component, docs, documentation, dynamic, front end, guide, hanzo, style, styleguide

## 简介

Tool to dynamically generate styleguides from UI library. Used either internaly while working on components/modules or to share documentation with clients.
