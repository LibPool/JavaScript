# demf-kpim-editor-dashboard

> 标签: JavaScript

## 简介

The KPIM Editor Dashboard microfrontend helps the user to visually define the KPI by assigning a Dashboard to it so that its values are shown on a chart. The KPIM Editor Dashboard works within the KPIM tool in which it is mounted, and is a step of the KPI
