# dsh-block-ptc

> 标签: agent, compaction, context, deepseek-harness, dsh, dsh-bundle, dsh-plugin, ptc

## 简介

Blackboard blocks for DeepSeek Harness PTC mode: tag run_code with block ids and use block_compact to organize inactive context while retaining information needed for subsequent work.
