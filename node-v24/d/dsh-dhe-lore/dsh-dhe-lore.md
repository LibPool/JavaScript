# dsh-dhe-lore

> 标签: context, cordis, cordis-plugin, deepseek, deepseek-harness, dsh, dsh-plugin, memory, plugin, project-memory, shared-memory

## 简介

DSH plugin: project-level shared memory for DeepSeek Harness — every session in a project shares one human-readable, git-committable memory store. · DSH 项目级共享记忆插件。
