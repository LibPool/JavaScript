# database-agnostic-rate-limiter

> 标签: dynamodb, express, hono, middleware, mongodb, postgres, rate-limit, rate-limiter, redis, throttle

## 简介

Rate limiting for Node with pluggable storage. One core, four algorithms, and stores for memory, Redis, Postgres, MongoDB and DynamoDB. Express and Hono middleware included.
