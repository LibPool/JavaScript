# dssoca

> 标签: components, css, design-system, svelte, svelte5, theme, ui, vanilla

## 简介

Svelte 5 design system — signal green on near-black, monospace-forward, zero border-radius; configured along two axes (color: dark/light, size: sm/md/lg). Also consumable from plain HTML via vanilla.css + vanilla.js.
