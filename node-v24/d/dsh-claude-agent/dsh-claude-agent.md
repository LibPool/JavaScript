# dsh-claude-agent

> 标签: agent, claude, cordis, deepseek-harness, dsh, entity, plugin

## 简介

Claude 长驻实体插件：通过 @anthropic-ai/claude-agent-sdk（长驻）维护会话，暴露 chat / startConversation / pull 接口（多轮会话、流式），供编排层（multi-role-debate）或直接对话调用。
