# dz-id-validator

> 标签: algeria, dz, iban, nif, nin, nis, phone, rc, registre-commerce, typescript, validation, validator

## 简介

Zero-dependency validators for Algerian identifiers: RC, NIF, NIS, national ID (NIN), +213 phone numbers and IBAN-DZ.
