# dsh-approval-alert

> 标签: alert, approval, deepseek-harness, dsh, dsh-plugin, notification

## 简介

DeepSeek Harness approval & completion alert — desktop notification + sound + tab-title flash when a session waits for an approval or a user question, and a completion alert when a task finishes, so you never leave dsh waiting while you are away. v2 adds
