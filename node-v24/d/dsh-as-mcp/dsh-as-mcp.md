# dsh-as-mcp

> 标签: bundle, cordis-plugin, deepseek-harness, dsh, dsh-plugin, mcp, model-context-protocol

## 简介

Expose this DeepSeek Harness as an MCP server so other agents can create workspaces, start sessions, write code through DSH, and run commands.
