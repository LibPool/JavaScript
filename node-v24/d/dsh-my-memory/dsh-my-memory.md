# dsh-my-memory

> 标签: JavaScript

## 简介

DSH 记忆插件：全局/项目两级记忆持久化，会话开始时注入系统提示词，设置页可视化面板（新增/修改/删除需用户确认），memory_query 只读查询工具。DSH web plugin: global/project memory with system-prompt injection, settings panel and a read-only query tool.
