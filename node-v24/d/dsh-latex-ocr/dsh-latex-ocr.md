# dsh-latex-ocr

> 标签: deepseek-harness, dsh, formula, latex, ocr, pix2tex

## 简介

公式图片 → LaTeX（pix2tex / LaTeX-OCR）：把教材/截图中的数学公式识别为 LaTeX 代码
