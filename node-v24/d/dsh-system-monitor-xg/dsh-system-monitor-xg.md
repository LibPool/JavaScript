# dsh-system-monitor-xg

> 标签: bandwidth, bottleneck, composer-dock, deepseek, deepseek-harness, dsh, gpu, plugin, system-monitor, vram

## 简介

DSH 系统负载监控插件：CPU/内存/GPU 算力与显存带宽利用率、显存、功耗、温度实时显示，自动诊断推理瓶颈（算力 vs 带宽 vs 功耗 vs 热 vs 显存容量），Web 底栏 + agent 工具 + prefill/decode 阶段对比 + 负载 JSONL 落盘。
