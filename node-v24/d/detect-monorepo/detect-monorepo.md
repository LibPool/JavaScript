# detect-monorepo

> 标签: bun, detect, monorepo, npm, pnpm, rush, workspace, workspaces, yarn

## 简介

Detect whether a directory sits inside a JS/TS monorepo workspace (pnpm, npm/yarn/bun workspaces, or rush).
