# devign-figma-mcp

> 标签: ai, claude, cursor, design, figma, gemini, graphic-design, mcp, model-context-protocol, moodboard, openai

## 简介

MCP server that lets any AI model create, read, and edit Figma designs in real time. Supports UI design, graphic design, and moodboard workflows.
