# dsh-latex-tools

> 标签: deepseek-harness, dsh, dsh-plugin, katex, latex, mathjax, svg

## 简介

Hover LaTeX formulas in the DeepSeek Harness Web UI to copy the TeX source or export the formula as a standalone SVG.
