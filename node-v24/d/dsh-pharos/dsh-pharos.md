# dsh-pharos

> 标签: alerts, background-alert, deepseek-harness, desktop-notification, dsh, dsh-plugin, needs-your-input, notify, reminder, 任务完成, 回复完成提醒, 桌面通知, 消息提醒, 需要你操作

## 简介

DSH 桌面守望提醒：模型需要你操作（审批 / 方案确认 / 提问）或后台回复完成时，弹出系统通知与提示音，点击通知直接跳转到对应会话。另含出错 / 中断 / 用量上限提醒、安静时段、子代理过滤、当轮统计（token / 缓存命中率 / TPS）、工作流进展、SSE 桥与 Webhook（企微 / 飞书 / 钉钉 / 通用）、远程触发，以及「设置 → 消息通知」图形设置页。 Desktop notifications for DeepSeek Harness (DSH): a system toast,
