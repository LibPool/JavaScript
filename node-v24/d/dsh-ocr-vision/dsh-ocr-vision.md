# dsh-ocr-vision

> 标签: deepseek-harness, dsh, dsh-plugin, image-to-text, macos, ocr, offline, vision

## 简介

Local OCR for DeepSeek Harness: read text out of images with Apple Vision on macOS — no network, no API key, nothing to install. Falls back to tesseract elsewhere.
