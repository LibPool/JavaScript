# dsh-oc-message-undo

> 标签: deepseek, deepseek-harness, dsh, dsh-plugin, fork, message, undo

## 简介

DeepSeek Harness 会话撤回按钮:在每条用户消息操作区(复制按钮旁)加「撤回」按钮,点击后截断该语句之后的上下文(引擎原生 session/truncate),并把该句文本填回输入框等待编辑,不开分支
