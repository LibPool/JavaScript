# dsh-plugin-chatgpt-crash-fix

> 标签: chatgpt, codex, crash, deepseek, diagnostics, dsh, microsoft-store, plugin, proxy, windows

## 简介

Diagnose and fix ChatGPT/Codex desktop app startup crashes on Windows: Store-updater native crash, broken Microsoft Store channel, and Clash/system-proxy interference. Ships a Cordis command, an agent Skill (SKILL.md), and runnable PowerShell diagnostic/f
