# didww-to-openai-realtime

> 标签: agent-skill, claude, claude-code, didww, openai, sip, skill, telephony, voice-ai

## 简介

Point a DIDWW phone number directly at OpenAI's Realtime API over SIP, with a generated webhook backend for call control.
