# dsh-context-compaction-optimizer

> 标签: annotation, compaction, context, deepseek-harness, dsh, dsh-plugin, summarization

## 简介

DSH plugin: mark messages as invalid so an operator annotation digest steers what a compaction checkpoint absorbs. Cache-preserving: appends after the cached prefix, never rewrites history.
