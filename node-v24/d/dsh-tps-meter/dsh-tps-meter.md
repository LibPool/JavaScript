# dsh-tps-meter

> 标签: deepseek-harness, dsh, dsh-plugin, throughput, tok/s, tokens-per-second, usage-meter, widget

## 简介

DeepSeek Harness Web 悬浮窗：实时显示会话输出吞吐（tok/s）、本步/累计 token 与首 token 延迟，支持实时/均速双口径与多会话切换。
