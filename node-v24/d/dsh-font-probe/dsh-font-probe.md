# dsh-font-probe

> 标签: cjk, cordis, deepseek-harness, dsh, dsh-plugin, font, letter-spacing, line-height, theme, typography

## 简介

DeepSeek Harness font plugin: CJK/Latin/code font families plus font weights, letter-spacing, line-height, paragraph spacing and first-line indent. Font sizes are left to the official Appearance settings.
