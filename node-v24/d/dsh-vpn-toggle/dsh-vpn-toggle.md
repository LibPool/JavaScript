# dsh-vpn-toggle

> 标签: deepseek-harness, dsh, dsh-plugin, proxy, toggle, vpn

## 简介

DSH VPN 快捷开关：把主进程所有全局 fetch（模型 API / Files API / web 抓取）在「直连」与「本地 VPN 代理」之间按请求即时切换。GUI 右下角悬浮按钮 + 可选全局热键 + 同源控制端点 + 系统通知，状态持久化在 ~/.dsh/vpn-proxy.json。
