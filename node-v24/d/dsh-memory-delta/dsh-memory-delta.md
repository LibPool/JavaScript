# dsh-memory-delta

> 标签: agent, context, cordis-plugin, deepseek-harness, dsh, memory, spec-driven

## 简介

Layered, auto-injected cross-session memory for AI coding agents: a DSH plugin plus a standalone zero-dependency CLI. Borrows the spec/change/archive discipline from OpenSpec (MIT), but pushes instead of pulls.
