# dsh-sidebar-human-browser

> 标签: automation, browser, deepseek-harness, dsh-plugin, electron, human-like, webview

## 简介

Human-shaped browser control for DeepSeek Harness: Fitts-law pointer paths, press dwell, per-key typing with corrections, inertial scrolling, and a consistent fingerprint shim — drives DSH Desktop's built-in sidebar browser with no debug port.
