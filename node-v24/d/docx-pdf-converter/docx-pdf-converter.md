# docx-pdf-converter

> 标签: convert docx to pdf nodejs, converter, docx, docx pdf automation, docx pdf conversion tool, docx to pdf, docx to pdf converter, mammoth docx to pdf, pdf, puppeteer pdf generator, word to pdf

## 简介

A Node.js tool to convert DOCX files to PDF using Mammoth for accurate Word document parsing and Puppeteer for high-quality PDF generation. Ideal for document automation and batch processing.
