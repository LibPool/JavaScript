# dsh-lantern

> 标签: anthropic-compatible, deepseek-harness, dsh-plugin, lan, llm-gateway, local-network, openai-compatible, proxy, self-hosted

## 简介

LANtern（局域网模型灯塔）：把本机 DeepSeek Harness 已注册的全部 AI 模型，以 OpenAI / Anthropic 兼容接口照亮给同一局域网。只读复用 DSH 的模型注册表，全部产物写在插件自己的 data/ 目录内。
