# defade-mcp

> 标签: defade, mcp, model context protocol, rug pull, solana, token security

## 简介

Runs the DeFade MCP stdio server. Thin alias for the `defade` package, which carries the implementation — `npx defade-mcp` and `npx -p defade defade-mcp` are equivalent.
