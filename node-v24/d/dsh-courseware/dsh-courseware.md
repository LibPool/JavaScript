# dsh-courseware

> 标签: courseware, deepseek-harness, dsh, plugin, pptx, skill, 课件

## 简介

中小学课件生成技能包：拿用户自己的 .pptx 模板 + 课程大纲，产出套用模板风格的多页课件。由 DeepSeek Harness 的 courseware 技能 + pptxgen 引擎打包而成。
