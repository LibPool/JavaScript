# dsh-autostart

> 标签: autostart, deepseek, dsh, harness, restart, supervisor, web, windows

## 简介

Autostart + hidden-window launch + crash auto-restart for the DeepSeek Harness web UI (dsh web). Windows-only; one-click setup.
