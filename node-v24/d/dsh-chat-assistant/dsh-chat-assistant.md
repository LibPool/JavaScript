# dsh-chat-assistant

> 标签: auxiliary-chat, cordis, deepseek-harness, dsh, plugin, sidebar

## 简介

Auxiliary chat for DeepSeek Harness: a docked right-sidebar conversation forked from the main session, with full history; selection hand-off stages a packaged quote attachment; fresh chats auto-attach a deletable boundary-constraint file; closing its tab
