# dsh-custom-commands

> 标签: ai, custom-commands, deepseek-harness, dsh, plugin, slash-commands

## 简介

Codex/Claude-Code-style user-defined slash commands for the DeepSeek Harness web GUI: prompt-template command files under .dsh/commands, a '/' picker in the composer, and a host Remote that discovers and serves them.
