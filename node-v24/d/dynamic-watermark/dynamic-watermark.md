# dynamic-watermark

> 标签: icon watermark, image over image, image watermark, node watermark, smart watermark, text watermark, transparent watermark, watermark, watermark position

## 简介

Dynamic Watermark is npm watermark module to add watermark over image. It can add image as well as text watermark on given positions
