# dsh-gsap-skills

> 标签: animation, deepseek-harness, dsh, greensock, gsap, plugin, skill, 动画

## 简介

DeepSeek Harness GSAP 技能插件：把官方 greensock/gsap-skills 的 8 个 GSAP 技能（core / timeline / scrolltrigger / plugins / utils / react / frameworks / performance）打包成宿主级 skill provider。装一个插件即可让 DSH 所有会话直接获得 GSAP 动画技能，无需手工复制技能目录。
