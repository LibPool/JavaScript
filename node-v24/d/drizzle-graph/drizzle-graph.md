# drizzle-graph

> 标签: cli, dag, devtools, drizzle, drizzle-kit, drizzle-orm, migration-graph, migrations, postgres

## 简介

Browse and guard a Drizzle migration graph — a git-log-style view of the migration DAG, plus a CI guard against open heads
