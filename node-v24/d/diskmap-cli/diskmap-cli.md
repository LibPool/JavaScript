# diskmap-cli

> 标签: cache, cleanup, disk, disk-usage, macos, node_modules, storage, treemap

## 简介

Map your home folder as a 3D treemap and see which folders are safe to delete. Rescan live and delete with confirmation. No runtime dependencies.
