# domain-alive

> 标签: DNS, Domain, FQDN, RDAP, Whois

## 简介

A Node.js library for checking if an FQDN (Fully Qualified Domain Name) is alive or not, uses a combination techniques of `NS` records, WHOIS/RDAP lookups, `A/AAAA` records
