# dsh-settings-subagent

> 标签: deepseek-harness, dsh, plugin, settings, subagent

## 简介

子代理可视化配置插件：在设置页提供表单，配置主对话默认模型与子代理默认模型/提供方/后台模式，自动维护用户 agent preset 与 settings.yaml。
