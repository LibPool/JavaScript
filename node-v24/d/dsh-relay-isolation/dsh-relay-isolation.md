# dsh-relay-isolation

> 标签: agentrouter, deepseek, dsh, dsh-bundle, dsh-plugin, harness, isolation, network, relay, sandbox

## 简介

Provision a separate DSH_HOME (minimal profile + launcher) for the AgentRouter relay, and give the sandboxed agent controlled network egress.
