# dsh-phone-butler

> 标签: adb, android, cleanup, deepseek-harness, device-management, dsh, dsh-plugin, phone, screenshot, storage

## 简介

Treat a real Android phone as a device the agent can inspect and tidy up over adb: storage surveys, per-app data sizes, cache clearing, screenshots. No root required.
