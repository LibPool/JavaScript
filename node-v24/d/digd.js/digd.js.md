# digd.js

> 标签: 224.0.0.251, 53, 5353, DNS, bin, binary, capture, cli, command, create, daemon, debug, debugging, dig, javascript, js, json, line, lint, mDNS, mdig, mdigd, multicast, node, node.js, pack, parse, server

## 简介

A lightweight DNS / mDNS daemon (server) for creating and capturing DNS and mDNS query and response packets to disk as binary and/or JSON. Options are similar to the Unix dig command.
