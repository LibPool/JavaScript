# devsurface

> 标签: cli, developer-dashboard, developer-onboarding, developer-productivity, developer-tools, docker-compose, environment-checker, github-action, local-development, nodejs, npm-scripts, port-checker, project-dashboard, repository-health, repository-scanner, task-runner, zero-config

## 简介

Zero-config local developer dashboard and CLI for Node.js, Python, Go, Java, and Rust repositories. Detect scripts, env files, ports, Docker services, frameworks, logs, and repo health.
