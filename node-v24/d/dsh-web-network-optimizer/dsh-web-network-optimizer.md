# dsh-web-network-optimizer

> 标签: brotli, cache, compression, deepseek, dsh, dsh-plugin, harness, network, websocket

## 简介

dsh网页端网络优化：通过缓存与压缩技术降低传输，从而大幅提升网页加载速度；同时提供网络断连指示与自动断网重连功能。非常适合追求极致性能或网络不稳定用户使用。
