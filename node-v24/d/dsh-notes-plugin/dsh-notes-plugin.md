# dsh-notes-plugin

> 标签: deepseek-harness, dsh, dsh-plugin, markdown, notes

## 简介

DeepSeek Harness 会话感知本地笔记：把会话里的决策与约定沉淀成本地 Markdown 笔记，自动注入系统提示、可派发给活跃会话，解决「聊完就丢」的上下文断层
