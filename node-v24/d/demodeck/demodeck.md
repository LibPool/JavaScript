# demodeck

> 标签: animation, custom-elements, deck, presentation, slides, terminal, web-components

## 简介

Animated engineering-demo components for the web, with a minimal deck shell included: scripted terminal demos, typing effects, tabs, window chrome, slides or one-page scroll view. Zero dependencies, no build step.
