# dsh-mcp-console

> 标签: deepseek-harness, dsh-plugin, mcp, mcp-manager, model-context-protocol

## 简介

Manage the MCP servers of a DeepSeek Harness profile: status, switch, edit, export; add from the official MCP Registry, by hand (tested first), or with AI; find local software that can be connected
