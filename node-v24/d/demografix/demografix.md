# demografix

> 标签: age, age prediction, agify, api, api client, batch, bulk, demografix, demographics, first name, gender, gender api, gender detection, gender from name, genderize, name, name prediction, nationality, nationalize

## 简介

Predict gender, age, and nationality from names. Official client for the genderize.io, agify.io, and nationalize.io APIs, with batches of up to 100 names per request.
