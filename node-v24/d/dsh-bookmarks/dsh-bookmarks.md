# dsh-bookmarks

> 标签: bookmark, deepseek-harness, dsh, dsh-plugin, web

## 简介

Bookmark assistant replies in DeepSeek Harness: per-message bookmarks with notes and tags, a cross-session bookmark center, and one-click Markdown export.
