# dsh-code-rag-index-panel

> 标签: code-rag, cordis, deepseek, dsh, harness, index, panel, plugin

## 简介

DeepSeek Harness 插件：Code RAG 索引面板（会话输入框上方的索引状态条与开始/全量重建/取消按钮，数据直连 code-rag MCP 服务器的本地 HTTP 端点）+ 设置页「插件」区诊断与配置卡片（/api/code-rag/* 环回端点），索引条显示范围可在设置中切换（默认仅 Code RAG 模式会话），界面中英双语。
