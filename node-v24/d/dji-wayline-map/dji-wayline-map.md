# dji-wayline-map

> 标签: amap, coordinate, dji, drone, gaode, gcj02, kml, kmz, uav, wayline, wgs84

## 简介

解析大疆(DJI)航线 KMZ 文件并在高德地图(AMap)上绘制航线：KML 解析 + WGS84↔GCJ02 坐标转换 + 航点倒三角标记 + SVG 航段连线 + 自动适配视野。框架无关，传入 AMap 实例即可使用。
