# dsh-flat-teams

> 标签: JavaScript

## 简介

DeepSeek Harness（DSH）扁平团队插件：让多个独立 Agent 窗口（顶层会话）组成**无队长的扁平团队**，跨窗口互派结构化任务，并由内置"记录员"服务实时记账，用户在任何成员窗口都能问出真实进展。
