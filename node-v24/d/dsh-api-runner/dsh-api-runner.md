# dsh-api-runner

> 标签: api-runner, deepseek-harness, devtools, dsh, dsh-plugin, http-client, java, log-tail, spring-boot

## 简介

DSH 插件：按配置调用后端 HTTP 接口、启停/重启本地开发服务、增量读取日志并等待日志特征，让模型能"改完自己验"。
