# directus-extension-expandable-blocks

> 标签: blocks, cms, directus, directus-custom-interface, directus-extension, item-selector, m2a, reusable-components, shared-components

## 简介

M2A interface with inline expandable editing for Directus. Provides reusable ItemSelector components for other extensions.
