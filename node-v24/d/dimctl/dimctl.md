# dimctl

> 标签: buildkit, ci, cli, dim, docker-image

## 简介

Zero-state HTTP client for the dim daemon — submit container builds, manage credentials, stream logs. dim = Docker Image Manager.

- npm 页面：https://www.npmjs.com/package/dimctl
