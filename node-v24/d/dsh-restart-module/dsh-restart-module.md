# dsh-restart-module

> 标签: JavaScript

## 简介

会话内自重启 + 重启后自动唤醒/拉起离线会话：任何会话都能排程「杀掉本机 DSH 桌面进程并自动拉回」，替代 restart-dsh-*.bat
