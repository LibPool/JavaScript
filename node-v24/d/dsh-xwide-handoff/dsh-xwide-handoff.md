# dsh-xwide-handoff

> 标签: JavaScript

## 简介

DSH 交接插件 / Handoff plugin：/handoff 生成结构化交接卡（自动序号命名 + 侧栏置顶 + 到阈值自动备好新会话）。Generates structured handoff cards with self-incrementing titles, sidebar pinning and threshold-based auto-prepare, so a near-full chat continues seamlessly in a fresh zero-context se
