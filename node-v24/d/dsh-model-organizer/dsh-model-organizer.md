# dsh-model-organizer

> 标签: deepseek-harness, drag-and-drop, dsh, dsh-plugin, model, model-selector, reasoning-effort

## 简介

DSH 模型整理插件：输入框的模型下拉改为「供应商分组 + 模型二级折叠菜单」（含推理等级），并在模型设置页提供一个可拖拽的「供应商与模型顺序」浮窗。
