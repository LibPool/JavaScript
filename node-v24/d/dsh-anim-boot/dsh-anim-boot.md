# dsh-anim-boot

> 标签: 550c, boot-animation, dsh, dsh-plugin, splash, ueg

## 简介

DSH 开机动画：550C 片头（简易 / 完整）或 UEG 授权三幕，运行在 sandbox iframe 里，宿主不注册任何路由；通用设置里可切换或关闭。
