# dsh-plugin-session-emoji

> 标签: deepseek-harness, dsh, dsh-plugin, emoji, sidebar, web-gui

## 简介

Sidebar session emoji prefixes for the dsh web GUI: an externally attached emoji in front of every session title, set via a row context menu, persisted host-side under $DSH_HOME/storages.
