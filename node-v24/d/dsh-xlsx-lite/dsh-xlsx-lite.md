# dsh-xlsx-lite

> 标签: dsh, excel, ooxml, plugin, read, sheet, spreadsheet, write, xlsx

## 简介

Zero-dependency XLSX toolkit for DeepSeek Harness: read workbook data with automatic type/date recovery, preview sheet structure, and write xlsx from JSON/CSV/JSONL/table text. Uses only Node built-ins (zip + XML parsing, CRC32, raw deflate).
