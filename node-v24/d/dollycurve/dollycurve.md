# dollycurve

> 标签: animation, bezier, blender, camera, cinematic, easing, fcurve, graph-editor, interpolation, keyframe, three.js, timeline

## 简介

Blender-style F-Curve / camera path editor for Three.js — bezier handles, easings, cycles modifier, canvas graph editor + timeline. Web port of Blender's animation engine.
