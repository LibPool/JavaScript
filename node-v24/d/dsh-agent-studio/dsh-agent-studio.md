# dsh-agent-studio

> 标签: agent-preset, cordis, deepseek-harness, dsh, dsh-plugin, system-prompt

## 简介

DSH 图形化 Agent 配置台：可视化拼装提示词、工具、技能、子代理与备用模型，按预设绑定即接管；自建预设走平台的预设注册入口，所有配置存在插件自己的数据里，卸载即恢复原状。
