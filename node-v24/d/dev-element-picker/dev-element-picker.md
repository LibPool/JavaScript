# dev-element-picker

> 标签: ai, copy-paste, css, design, dev-tools, developer-tools, element-picker, inspector, react

## 简介

A tiny React dev-tool overlay that lets you click any DOM element on your page and copy its tag, selector, computed styles, matched CSS rules and outerHTML to the clipboard. Designed to be pasted into any AI coding assistant (Claude Code, Cursor, Codex, C
