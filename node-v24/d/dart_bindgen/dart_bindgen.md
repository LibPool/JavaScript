# dart_bindgen

> 标签: bindgen, bindings, codegen, dart, dts, flutter, interop, js_facade_gen, js_interop, typescript

## 简介

A modern, type-safe code generator to create Dart JS-interop bindings from TypeScript .d.ts files.
