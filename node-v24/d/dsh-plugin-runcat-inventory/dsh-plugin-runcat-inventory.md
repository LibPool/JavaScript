# dsh-plugin-runcat-inventory

> 标签: deepseek-harness, dsh, dsh-plugin, inventory, plugin, runcat, 逃咪

## 简介

逃咪-插件总览（Runcat Plugin Overview）：更好用的 DSH 插件列表 —— 表格视图、状态过滤、启用/停用开关（热生效）、卸载、更新提醒、配置查看与复制、中英双语界面。A better DSH plugin list.
