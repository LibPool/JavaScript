# dhiya-npm

> 标签: bm25, browser rag, chatbot widget, chrome built-in ai, client-side rag, hybrid search, in-browser ai, local llm, offline rag, privacy rag, rag, rag framework, react rag, retrieval-augmented-generation, transformers.js, useRAG, vector search, wasm embeddings, webgpu embeddings

## 简介

Client-side RAG chatbot for the browser: hybrid keyword+vector search, WebGPU/WASM embeddings, IndexedDB store, local LLM answers (Chrome built-in AI or Transformers.js), streaming, React hook, and a drop-in <dhiya-chat> widget. No servers, no API keys.
