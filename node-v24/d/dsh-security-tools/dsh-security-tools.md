# dsh-security-tools

> 标签: audit, codex-security, deepseek-harness, dsh, preset, security

## 简介

DSH agent-preset plugin wrapping the @openai/codex-security CLI: security scan, findings, and scan-comparison tools, plus the bundled Codex Security workflow payload (integrity-verified).
