# dsh-tavily-resilient-search

> 标签: cordis, deepseek-harness, dsh, dsh-plugin, key-rotation, tavily, web-search

## 简介

Pesquisa web em tempo real para o DeepSeek Harness via API Tavily, com rotação atómica e resiliente de um agrupamento de chaves (rate limit 429, cota mensal 432/433, revogação 401) e contingência keyless — sem nunca interromper o agent loop.
