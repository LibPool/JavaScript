# dsh-asciinema

> 标签: asciinema, cast, deepseek-harness, dsh, terminal-recording

## 简介

DSH plugin: record terminal/tool output as asciinema v2 (.cast), replay with an offline embedded player, and export HTML.

- npm 页面：https://www.npmjs.com/package/dsh-asciinema
