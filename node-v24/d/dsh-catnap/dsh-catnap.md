# dsh-catnap

> 标签: agent-monitor, catnap, client-ui, dashboard, deepseek-harness, dsh-plugin

## 简介

DSH 终端风格状态面板插件：实时聚合 codex/cc/joycode/dsh 等多 agent 的运行状态与会话列表，展示系统负载（内存/CPU/磁盘/电池），带一只会打盹的摸鱼小猫。
