# dsh-inline-image

> 标签: cordis, deepseek-harness, dsh, image, inline-image, local-image, markdown, plugin

## 简介

DeepSeek Harness (DSH) plugin: serve whitelisted local images over a same-origin route so assistant markdown can embed them / 本地图片内联插件
