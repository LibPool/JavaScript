# dsh-theme-macintosh

> 标签: deepseek-harness, dsh, dsh-plugin, macintosh, retro, theme

## 简介

DSH Macintosh 复古主题插件：System 7 像素语汇（ChiKareGo/Fusion Pixel 字体、桌面噪点画布、Finder 侧栏、月牙深浅切换、mcfx 闪烁、Kit 检视页），零构建 loader 格式常驻 bundle
