# dsh-endnote

> 标签: bibliography, deepseek-harness, dsh, dsh-plugin, endnote, literature, mcp, open-access, pdf, reference-manager

## 简介

EndNote library integration for the DeepSeek Harness: add papers with their open-access PDFs, manage attachments and groups, de-duplicate, and refresh the search index. Registers 2 skills and 7 native tools over one shared Python implementation.
