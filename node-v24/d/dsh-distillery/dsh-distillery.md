# dsh-distillery

> 标签: deepseek-harness, distill, dsh, dsh-plugin, fine-tune, local

## 简介

dsh 插件：本地蒸馏器——扫描全部历史会话，挖出「用户纠错 → agent 改对」片段，脱敏后蒸馏成微调数据对（JSONL）、技能草稿与 AGENTS.md 规则补丁，带人工审核队列
