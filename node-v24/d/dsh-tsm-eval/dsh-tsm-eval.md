# dsh-tsm-eval

> 标签: JavaScript

## 简介

dsh-tsm-eval: the exam system for TSM/DLR. Run a scenario paper (eval/questions.jsonl) through dsh headless, score it with tsm grade, and emit a replayable report (result + process + session-log forensics).
