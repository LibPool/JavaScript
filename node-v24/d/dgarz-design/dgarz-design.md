# dgarz-design

> 标签: components, css, css-framework, dark-mode, design-system, dgarz, minimal, monochrome, ui

## 简介

A minimal, monochrome, performance-first CSS framework. Elegant serif headings, pill shapes, full light/dark theming. Zero dependencies, one file.
