# dualscreen

> 标签: broadcastchannel, cross-window, dual-monitor, dualscreen, multi-monitor, presenter, react, second-screen, state-sync, window-management

## 简介

Drive a second monitor from your web app. Click in one window, change what's shown in another — no server required.
