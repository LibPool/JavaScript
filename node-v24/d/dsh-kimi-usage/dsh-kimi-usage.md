# dsh-kimi-usage

> 标签: cordis, dsh, kimi, plugin, quota, usage

## 简介

Kimi Coding 用量仪表盘：读取 dsh 的 Kimi Coding API key，查询 5 小时与周限额，侧栏底部图标 + 弹窗计量条展示。
