# dsh-long-office

> 标签: deepseek-harness, docx, dsh, md2docx, md2pptx, md2xlsx, office, plugin, pptx, xlsx

## 简介

DSH Office read + generate: read Word/Excel/PowerPoint (docx/xlsx/pptx and legacy doc/xls) into text/tables in memory (no intermediate files, model on-demand); generate Word/Excel/PowerPoint from Markdown via md2docx / md2xlsx / md2pptx. | DSH 插件：Office 读
