# dropdown-hide-or-show-element

> 标签: dropdown, element, hide, or, show

## 简介

Package used to show or hide an element with 3 functions namely showDropDown(), hideDropDown() and toggleShowOrHideDropDown(). It is created for dropdowns but can be used on other elements too. It uses two classes named "show" and "hide" in order to show
