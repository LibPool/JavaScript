# dsh-remote-terminal

> 标签: deepseek, deepseek-harness, dsh, dsh-plugin, pty, remote, terminal, websocket, xterm

## 简介

DSH (DeepSeek Harness) 插件：在 Web GUI 会话视图栏（轨迹旁）增加完整交互式终端 tab，远程浏览器经 WebSocket 直连宿主 PTY shell
