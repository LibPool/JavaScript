# dsh-muv-table

> 标签: deepseek-harness, dsh, dsh-plugin, magvarupdate, muv, tavern, variable-table

## 简介

MUV 变量表格编辑器 —— 树形变量面板、宏测试浮窗（random/pick/roll）、骰子快捷栏、pick 缓存管理；支持直接读取 SillyTavern PNG 角色卡（含正则脚本、世界书、变量表）。dsh-muv-engine 的伴生插件
