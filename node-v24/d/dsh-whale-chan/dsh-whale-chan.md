# dsh-whale-chan

> 标签: cordis, deepseek, deepseek-harness, desktop-pet, dsh, dsh-plugin, overlay, pet, web-ui, whale

## 简介

鲸鱼娘桌宠：住进 DSH web 的鲸鱼娘。状态镜像（干活/思考/等待审批/报错/庆祝/空闲）、分区热区、拖拽、喂食、表情包气泡、Token/费用仪表板、XP/等级/称号养成、可关闭的主动陪伴。A whale-girl desktop pet for the DeepSeek Harness Web UI.
