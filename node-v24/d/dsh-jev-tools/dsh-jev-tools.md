# dsh-jev-tools

> 标签: classification, context, context-engineering, context-window, decision, deepseek, dsh, dsh-plugin, guardrails, harness, jev, prompt-injection, typesafe

## 简介

Gives DeepSeek Harness three automatic Jev judgments — prune oversized tool output, screen fetched pages for injected instructions, suggest which skill to use — plus the jev_ask and jev_gate tools, a persistent judgment ledger, and a /jev-status diagnosis
