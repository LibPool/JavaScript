# doc-trimmer

> 标签: claude, context-optimization, documentation-parser, llm, prompt-engineering, zero-dependency

## 简介

A zero-dependency CLI utility to parse, clean, and pack HTML/Markdown documentation into token-optimized prompts for LLMs.
