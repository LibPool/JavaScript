# dsh-cyberwhale

> 标签: customization, deepseek-harness, desktop-pet, dsh, dsh-plugin, macos, theme, wallpaper, whale, windows, winui

## 简介

为 DeepSeek Harness 提供 macOS 与 Windows 风格界面、主题配色、壁纸和字体设置，以及可独立开关的蓝鲸桌宠。
