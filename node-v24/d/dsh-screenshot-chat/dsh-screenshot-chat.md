# dsh-screenshot-chat

> 标签: composer, deepseek-harness, dsh, dsh-plugin, macos, screencapture, screenshot

## 简介

Screenshot capture for the DSH composer: adds a Screenshot entry to the chat input's + menu with region capture and a hide-window variant that hides the current window before the native macOS selection overlay and restores it afterwards; the capture lands
