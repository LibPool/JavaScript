# dsh-heatmap

> 标签: analytics, cordis, deepseek-harness, dsh, dsh-plugin, heatmap, plugin, telemetry

## 简介

DeepSeek Harness 页面埋点与热力图分析插件：科学埋点采集（点击/聚焦/停留/滚动/曝光）、本地热力图与统计面板、预留 CLI 与外部上传接口、上传前用户授权弹窗。
