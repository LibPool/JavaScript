# dsh-jenkins-plugin

> 标签: build-monitor, ci, deepseek, deepseek-harness, dsh, dsh-plugin, jenkins, llm-plugin

## 简介

Jenkins integration for DeepSeek Harness: a live build-progress panel in the Web GUI plus model-facing tools for triggering builds, reading stages and console logs, and browsing a build's workspace
