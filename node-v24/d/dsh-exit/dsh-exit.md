# dsh-exit

> 标签: deepseek, deepseek-harness, dsh, dsh-plugin, exit, plugin, shutdown, sidebar

## 简介

DeepSeek Harness 退出插件：侧边栏「退出」按钮一键优雅关闭服务，关闭最后一个窗口自动退出（pagehide + sendBeacon，后台标签页不再误杀）。
