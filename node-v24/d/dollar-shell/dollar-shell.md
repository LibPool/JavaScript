# dollar-shell

> 标签: abort-signal, bun, capture, command, cross-runtime, deno, dollar, esm, exec, node-streams, nodejs, pipeline, process, shell, spawn, stream, subprocess, template-tag, typescript, web-streams, zero-dependency

## 简介

Run OS and shell commands using template tag functions. Same API in Node, Deno, and Bun. Web streams, TypeScript typings, zero dependencies.
