# docalyze-mcp-server

> 标签: copilot, docalyze, documents, excel, mcp, model-context-protocol, pdf, vscode

## 简介

MCP server for reading and visually analyzing local documents (PDF, Excel, CSV, Word, PowerPoint, images). No API keys needed.
