# discord-rpc-template

> 标签: Discord, RPC

## 简介

1. Устанавливаем [node.js](https://nodejs.org/ru/) **LTS** с официального сайта. 2. Скачиваем данные файлы с GitHub. 3. Запускаем файл – «install.bat». После загрузки закрываем окно консоли (при этом после выполнения должна появиться папка node_modules).
