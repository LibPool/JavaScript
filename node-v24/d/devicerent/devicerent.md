# devicerent

> 标签: adb, android, apk, appium, cli, device-farm, devicerent, espresso, real-device

## 简介

DeviceRent from your terminal: rent a real Android phone and drive it — guided menus and plain English, or one command at a time. Install APKs, run Quick tests and Espresso, hand it to DeviceyAI.
