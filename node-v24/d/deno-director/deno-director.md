# deno-director

> 标签: binary-transfer, bridge, buffer, cross-runtime, deno, eval, host-functions, ipc, isolate, message-passing, module-loader, native-addon, neon, node, runtime-bridge, sandbox, secure-runtime, serialization, typedarray, v8, worker

## 简介

Embed isolated Deno runtimes inside a Node.js process with a native bridge, explicit runtime policy, and a full host-side control surface.
