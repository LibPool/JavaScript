# dsh-ntfy-remote

> 标签: approval, cordis, cordis-plugin, deepseek, deepseek-harness, dsh, dsh-plugin, mobile, notification, ntfy, push, remote

## 简介

把每个 DSH 会话桥接到一个 ntfy 话题：手机推送、手机回复、审批与提问中转。
