# dsh-plugin-media-wallpaper

> 标签: deepseek-harness, dsh, dsh-plugin, plugin, wallpaper

## 简介

DeepSeek Harness 壁纸插件：图片/视频背景（GIF/APNG/动图 WebP/PNG/JPEG/MP4/WebM），格式自动识别，压暗/亮度/高斯模糊，界面色调跟随，填充方式可调，侧栏/顶栏等组件透明度可控。纯客户端实现。
