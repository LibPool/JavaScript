# dsh-plugin-usage-meter

> 标签: balance, billing, budget, cost, cost-tracking, deepseek-harness, dsh, dsh-plugin, fee, plugin, token, token-usage, usage, usage-meter

## 简介

API 用量/费用/余额仪表 — DeepSeek Harness 网页插件：按钮式用量条实时报价并显示余额；面板含按模型堆叠柱状图（当日逐小时×峰谷档位、官方调价按生效区间计价）、官方账单、消耗段位与梁祖分享卡片、上下文压力预警 + 一键压缩、预算提醒与检查更新/一键更新。自动同步 DeepSeek 最新模型与定价（deepseek-flash 取代 v4-flash）。
