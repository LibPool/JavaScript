# dsh-firecrawl

> 标签: agent, deepseek-harness, dsh-plugin, firecrawl, scrape, web-search

## 简介

Firecrawl bridge for DeepSeek Harness: scrape URLs to LLM-ready Markdown and search the web via the Firecrawl Cloud API.
