# dsh-ui-flow-mapper

> 标签: cordis, deepseek-harness, diagram, dsh, dsh-plugin, flow, flowmap, plugin, prototype, ui, wireframe

## 简介

UI Flow Mapper — 在 DSH 右侧栏画出软件的界面与交互跳转，导出一份机器可读的画布 JSON 给 AI 生成前后端。A flow-map editor for the DSH right sidebar: draw screens and their jumps, export a canvas JSON an AI can implement.
