# dsh-cpa-switch

> 标签: cliproxyapi, cpa, deepseek-harness, dsh, plugin

## 简介

DeepSeek Harness 插件：在 DSH 里管理 CLIProxyAPI 的账号 —— 余额、签到、任务、切换账号，并让 CPA 随 DSH 启停。
