# dsh-google-chrome-search

> 标签: captcha, cdp, chrome, chromium, cli, deepseek-harness, dsh, google-search, mcp, model-context-protocol, puppeteer, search, web-search

## 简介

Google web search + page content extraction for AI agents: drives your local Chrome over CDP (no API key) with a human-verification (CAPTCHA) fallback. Ships as a CLI, an MCP stdio server, and a DSH skill.
