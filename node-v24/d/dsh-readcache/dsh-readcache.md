# dsh-readcache

> 标签: cache, cordis, deepseek-harness, dsh, performance, plugin, read

## 简介

为 DSH read 工具提供版本令牌校验的进程内结果缓存：未变更文件的重复读取跳过文件 I/O 与重渲染，并附带 readcache 工具查看统计与清空缓存。
