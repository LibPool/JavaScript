# dsh-plugin-store

> 标签: audit-log, cordis, deepseek, deepseek-harness, dsh, one-click-install, plugin-bundle, plugin-marketplace, plugin-store, web-ui

## 简介

Plugin Store for DeepSeek Harness (DSH): a graphical app-store inside the Harness Web UI — browse, search, and one-click install GitHub dsh-plugins, with local ratings, dependency impact graphs, audit logging, and a development scaffold
