# dsh-mobile-bridge

> 标签: cordis-plugin, deepseek-harness, dsh, mobile, noise-protocol

## 简介

DeepSeek Harness (DSH) bundle: serves the harness API to paired mobile devices over a Noise-encrypted tunnel, without opening a port.
