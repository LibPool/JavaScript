# dsh-voice-personal

> 标签: asr, chinese, cordis, deepseek-harness, dictation, dsh, plugin, speech-to-text, voice-input

## 简介

Local ASR post-processing for DeepSeek Harness: personal glossary, cross-script transliteration, learned style profile. Wraps the built-in SenseVoice provider.
