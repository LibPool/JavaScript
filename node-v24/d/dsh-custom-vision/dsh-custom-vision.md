# dsh-custom-vision

> 标签: deepseek-harness, dsh, dsh-plugin, image, image-to-text, multimodal, ocr, openai-compatible, plugin, screenshot, vision

## 简介

Use your own OpenAI-compatible vision model in DeepSeek Harness: images are described before the main model sees the request, plus an image_understand tool for reading charts, screenshots, UI and OCR.
