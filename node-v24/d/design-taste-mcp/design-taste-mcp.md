# design-taste-mcp

> 标签: accessibility, ai, axe-core, coding-agent, design, design-systems, design-taste, mcp, model-context-protocol, ui

## 简介

MCP server giving AI coding agents design taste across the UI-building workflow: rubrics, static checks, component/style registries, motion presets, render critique, and staged 3D scene guidance.
