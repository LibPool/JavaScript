# dsh-notepad

> 标签: deepseek-harness, dsh, notepad, notes, plugin, sticky

## 简介

DSH Web GUI 右侧常驻记事本：钉在页面最右边的便签面板，自动保存到 ~/.dsh/notepad/notes.md，Agent 可通过 notepad_read/notepad_write 读写。
