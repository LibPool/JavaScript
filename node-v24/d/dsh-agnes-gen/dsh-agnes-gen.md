# dsh-agnes-gen

> 标签: agnes, deepseek, deepseek-harness, dsh-plugin, gif, image-generation, text-to-image, video-generation

## 简介

Agnes AI 图像 / 视频生成插件：注册 agnes_image 与 agnes_video 工具，内置跨进程 RPM 限流、429 退避与本地 ffmpeg 转 GIF；带 Web 配置卡（API Key / RPM 预设 / ffmpeg 检测）。
