# dmk-cache

> 标签: cache, framework-agnostic, ttl, vue3, 缓存

## 简介

框架无关的数据缓存。支持 TTL、内存/会话双策略、getOrFetch 并发去重合并，Vue 已适配（dmk-cache/vue）。
