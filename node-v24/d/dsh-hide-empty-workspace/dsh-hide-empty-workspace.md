# dsh-hide-empty-workspace

> 标签: archive, deepseek, deepseek-harness, dsh, dsh-plugin, empty-workspace, hide, sidebar, workspace

## 简介

DSH Web 插件：最后一个未归档会话被归档的瞬间自动隐藏该工作区行，另在工作区行「…」菜单里追加「隐藏工作区」并配官方 Modal 恢复入口；只切 display，不归档、不删除、不改写任何工作区注册与会话数据。
