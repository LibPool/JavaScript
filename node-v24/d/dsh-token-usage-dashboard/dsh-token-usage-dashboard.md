# dsh-token-usage-dashboard

> 标签: dashboard, deepseek-harness, dsh, plugin, token, usage

## 简介

Token 用量统计看板：扫描 $DSH_HOME/sessions 下的持久化会话日志（token-meter 的同一份用量记录），聚合出 时间×模型 的输入/输出/缓存用量，生成自包含 HTML 仪表盘
