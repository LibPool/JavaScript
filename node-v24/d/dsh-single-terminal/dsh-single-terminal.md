# dsh-single-terminal

> 标签: dsh-plugin, dsh-single-terminal, pty, terminal, xterm

## 简介

Interactive terminal drawer plugin (dual-face): bottom drawer with real PTY terminals (xterm.js), multi-tab, Windows shell picker (PowerShell default / pwsh / CMD / Git Bash / WSL + custom), docked (occupies page height) or overlay mode, keep-alive sessio
