# dsh-sensenova-pool

> 标签: 429, deepseek, deepseek-harness, dsh-plugin, key-pool, key-rotation, model-provider, rate-limit, sensenova, 日日新

## 简介

商汤日日新（SenseNova）多 Key 轮换池 — 填入多把 Key 即可零配置接入 DeepSeek Harness，遇 429 限流自动切换下一把 Key。
