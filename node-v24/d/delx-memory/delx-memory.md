# delx-memory

> 标签: agent-memory, ai-agents, claude, cursor, hermes, local-first, mcp, memory, model-context-protocol, persistent-memory, sqlite

## 简介

Local-first multi-agent memory MCP. Shared SQLite + FTS5, secret-blocking, lite transport (no SDK by default), namespaces, batch + handoff tools.
