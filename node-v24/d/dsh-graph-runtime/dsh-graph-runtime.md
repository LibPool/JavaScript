# dsh-graph-runtime

> 标签: cordis, deepseek-harness, dsh-plugin, graph, langgraph, tools

## 简介

Graph runtime capabilities for the DeepSeek Harness: register LangGraph compiled graphs as DSH tools, plus a graph-driven routing agent.
