# dsa_tools

> 标签: JavaScript

## 简介

A collection of data structures and utilities for JavaScript. - Stack     - Is implemented using a Doubly-Linked List.     - Supports the following operations in O(1) Time         - push()         - pop()         - peek()         - get_length()         -
