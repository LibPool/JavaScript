# dsh-qrcode-gen

> 标签: dsh, iso-18004, plugin, png, qr, qr-code, qrcode, reed-solomon, svg

## 简介

QR code generation for DeepSeek Harness with full ISO/IEC 18004 encoding (byte mode, versions 1-10, ECC L/M/Q/H): Reed-Solomon over GF(256), block interleaving, mask evaluation. Outputs SVG / terminal ASCII / PNG (1-bit, built-in zlib + own CRC32). Zero d
