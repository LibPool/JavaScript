# dsh-mcp-master

> 标签: cordis, deepseek-harness, dsh, dsh-plugin, mcp, model-context-protocol, oauth

## 简介

MCP Master for DeepSeek Harness: global and project (.mcp.json) MCP servers, chosen per session from a picker beside the model selector — switchable at any time — with OAuth sign-in and trust review for project servers.
