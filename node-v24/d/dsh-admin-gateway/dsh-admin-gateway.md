# dsh-admin-gateway

> 标签: admin-gateway, auth, cordis, deepseek-harness, dsh, dsh-plugin, plugin, reverse-proxy

## 简介

DeepSeek Harness 管理员验证网关插件 — 自起独立 HTTP 网关，密码登录 + 反向代理 + WebSocket/SSE 透传，防止未授权访问
