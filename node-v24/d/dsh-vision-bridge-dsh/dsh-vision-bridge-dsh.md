# dsh-vision-bridge-dsh

> 标签: deepseek-harness, describe-image, dsh, gemini, groq, image, llm, multimodal, plugin, vision

## 简介

Vision bridge for text-only models (DeepSeek and any route without image input): a pluggable vision model (Gemini, Groq, or any OpenAI-compatible endpoint) describes attached images at the llm/stream seam and provides the describe_image tool.
