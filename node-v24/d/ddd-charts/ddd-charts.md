# ddd-charts

> 标签: 3d, bar-chart, charts, pie-chart, react, react-three-fiber, threejs, visualization, webgl

## 简介

Highly customizable 3D charts for React — pie and bar charts with physically-based materials, glass effects and smooth animations. Powered by three.js and @react-three/fiber.
