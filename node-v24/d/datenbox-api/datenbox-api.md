# datenbox-api

> 标签: api, data, js, microservice, nodejs, rest, sqlite

## 简介

DatenBox is a small framework for easy data handling based on node.js. Therefore DatenBox uses a REST API and multiple SQlite databases. This API package (datenbox-api) will provide API utilities for requesting a DatenBox server.
