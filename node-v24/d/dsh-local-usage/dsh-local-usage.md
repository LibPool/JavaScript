# dsh-local-usage

> 标签: cost, deepseek-harness, dsh, dsh-plugin, tokens, usage

## 简介

Usage statistics panel for DeepSeek Harness: historical token and money aggregates folded from every durable session log, drawn as a rolling-year heatmap.
