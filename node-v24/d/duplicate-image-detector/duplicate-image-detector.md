# duplicate-image-detector

> 标签: ahash, bmp, dhash, diagram, duplicate-image-detection, duplicate-images, find-duplicates, gif, image-dedupe, image-deduplication, image-fingerprint, image-hash, image-similarity, jpeg, line-art, near-duplicate, perceptual-hash, phash, png, scanned-documents, zero-dependency

## 简介

Find duplicate and near-duplicate images in Node.js with perceptual hashing (dHash, aHash, pHash). Zero dependencies, pure JavaScript, deterministic. Tuned for line art, diagrams, scanned documents and exam questions.
