# dsh-rerun-turn

> 标签: deepseek-harness, dsh, dsh-plugin, infix, regenerate, replay, rerun, surface-replace, turn

## 简介

Infix rerun for DeepSeek Harness: re-run any earlier turn in place - the reply is regenerated from the same prompt while every later turn survives, so subsequent model calls read A B C1 D E F G. Implemented with the official surface-replace contract plus
