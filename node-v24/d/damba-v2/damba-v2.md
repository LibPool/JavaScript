# damba-v2

> 标签: bullmq, crud, damba, express, framework, schema, socket.io, typeorm

## 简介

AI-friendly, schema-driven Express framework with auto-generated CRUD routes, behaviors, policies, queues, and realtime — flat, greppable conventions that LLMs and coding agents can read and generate.
