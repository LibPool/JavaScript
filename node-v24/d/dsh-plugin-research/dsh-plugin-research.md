# dsh-plugin-research

> 标签: JavaScript

## 简介

通用主题式深度调研 DSH 插件：research(topic) 唯一入口（主题进报告出，零宿主概念——子代理自分解研究线→web 检索取证→自检补漏→合成带来源完整报告交回调用方）。搜索 provider 读宿主 web seam；派单走宿主默认模型（本包 src/runner.ts 自有），账本格式归 dsh-plugin-ledger（在建）。
