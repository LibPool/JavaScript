# dsh-plugin-zoom

> 标签: accessibility, deepseek-harness, dpi, dsh-plugin, high-dpi, scale, zoom

## 简介

DeepSeek Harness Web UI plugin: manually zoom the whole interface on high-DPI displays, with Ctrl+wheel and Session-header controls.
