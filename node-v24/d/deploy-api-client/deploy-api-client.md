# deploy-api-client

> 标签: JavaScript

## 简介

## Generate new api - Replace swagger file with new version, for example from https://dev-deploy.heretto.com/v3/api-docs. - Open terminal in main catalog and execute ```npm run generate``` - Change version in package.json. - Push to npmjs.
