# dreams-amadeus

> 标签: amadeus, fake, mock, testing

## 简介

Cliente TypeScript puro com a superfície da API Amadeus usada pelos microsserviços Dreams, para simular a API em testes. Não é oficial e não tem afiliação com a Amadeus.
