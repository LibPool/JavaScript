# dallmo-fs

> 标签: JavaScript

## 简介

- compatible with both cjs and esm, by following [the advice of a post by Dan Fabulich][ref-1] - contains a few simple wrappers to deal with common fs tasks, such as :   - mkdir   - save plain text files
