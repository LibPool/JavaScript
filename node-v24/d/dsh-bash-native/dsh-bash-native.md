# dsh-bash-native

> 标签: bash, brush, deepseek-harness, dsh, dsh-plugin, sandbox, windows

## 简介

dsh-bash-native: a Windows-native POSIX bash executor for the DSH shell seam, with engine resolution and DSH's three-tier file sandbox honored.
