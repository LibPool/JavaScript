# dsh-workspace-ranswork

> 标签: cordis, deepseek-harness, dsh, dsh-bundle, dsh-plugin, overview, running-tasks, sessions, sidebar, workspace

## 简介

Workspace overview for DeepSeek Harness: a sidebar panel that switches between running tasks and all conversations, shown as one freely sortable card list, with per-card actions (pin / rename / copy id / fork / stop / archive).
