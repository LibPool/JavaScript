# dsh-updater-npm

> 标签: deepseek-harness, docs, documentation, dsh, dsh-plugin, npm-update, updater

## 简介

DSH updater + official docs sync plugin for DeepSeek Harness: one-click npm update of @deepseek-ai/dsh with real-time progress, an idle-based timeout so slow networks are not killed, a staged swap that keeps a rollback point (cleanable from the card), inc
