## 简介

Text direction for the DeepSeek Harness Web UI: an Auto / RTL / LTR control for the conversation and the whole shell, with per-block bidi detection and left-to-right code islands. پلاگین جهت متن (راست‌به‌چپ/چپ‌به‌راست) برای DeepSeek Harness.
