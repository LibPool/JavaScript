# dsh-llm-multimodal

> 标签: JavaScript

## 简介

DSH 插件：提供文本 / 图像 / 视频 / 视觉理解 / 语音 / 音乐 六个生成工具，模型从 llm-pi-ai 自动发现，含 Settings UI (llm-multimodal namespace)。
