# dsh-redteam-asset-graph

> 标签: asset-graph, cordis, deepseek-harness, dsh, plugin, redteam

## 简介

DSH 红队资产图谱插件包：把目标资产自动收集、关联、可视化，并让模型参与研判（面板 + 三个模型工具 + Jina 检索两阶段关联分析）
