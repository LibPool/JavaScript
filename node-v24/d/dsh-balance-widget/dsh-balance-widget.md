# dsh-balance-widget

> 标签: balance, cost, deepseek, deepseek-harness, dsh, plugin, token, web-ui

## 简介

Balance & cost widget for the dsh web GUI: a sidebar footer card shows the DeepSeek account balance and today's costs; clicking opens a popover with a five-tier cost breakdown (last prompt with session name / today-this-session / today-this-workspace / to
