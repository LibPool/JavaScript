# doc-file-copy

> 标签: ai, chatgpt, claude, cli, clipboard, concat, copy, llm, markdown, md, notes, prompt

## 简介

Recursively concatenate all markdown files in a folder (sorted by modification time) and copy to clipboard — turn local notes into one big AI prompt.
