# dsh-throttle

> 标签: 429, deepseek-harness, dsh, plugin, rate-limit, throttle

## 简介

DeepSeek Harness 限流插件：长程任务自动控速不再 429，支持任务复盘(begin_task/end_task)，复用 429-throttle-mcp 核心逻辑
