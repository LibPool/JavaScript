# dsh-agent-memory-bridge

> 标签: claude-mem, deepseek-harness, dsh, dsh-plugin, memory, persistent-memory

## 简介

DeepSeek Harness memory adapter: captures conversation/tool observations to the local claude-mem worker over HTTP; summarization/embedding/search stay in claude-mem.
