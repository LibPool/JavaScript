# dsh-model-tidy

> 标签: alias, deepseek, deepseek-harness, dsh, dsh-plugin, model, model-list, rename, selector, visibility

## 简介

DeepSeek Harness plugin: keep the model selector tidy. Choose which models appear and what they are called, without touching any provider configuration or running session.
