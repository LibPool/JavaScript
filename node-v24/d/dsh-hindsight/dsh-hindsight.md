# dsh-hindsight

> 标签: agent-memory, cordis, cross-session-memory, deepseek-harness, deepseek-harness-plugin, dsh-plugin, hindsight, knowledge-graph, llm-memory, long-term-memory, memory-bank, persistent-memory, vector-memory, vectorize

## 简介

Official-grade DeepSeek Harness memory plugin backed by Hindsight (vectorize-io). Add /hindsight commands and model tools that recall, remember, inspect and forget through a Hindsight memory bank.
