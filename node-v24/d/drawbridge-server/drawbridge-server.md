# drawbridge-server

> 标签: design-system, drawbridge, figma, figma-plugin, html-to-figma, mcp

## 简介

Local companion server for the Drawbridge Figma plugin: live mirror, URL fetch, code compile, browser captures, and an MCP endpoint so AI clients can push designs into Figma and read back the drift report.
