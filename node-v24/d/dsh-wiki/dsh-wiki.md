# dsh-wiki

> 标签: JavaScript

## 简介

基于 **DeepSeek Harness (DSH) + Obsidian** 的个人知识库体系（源自 [Karpathy LLM Knowledge Bases](https://community.tmpdir.org/t/llm-knowledge-bases/1685)）：LLM 负责编译与维护，人类负责选材、审核与提问。
