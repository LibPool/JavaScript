# dsh-zen-free

> 标签: dsh, dsh-plugin, dshapp-plugin, free, llm, opencode-zen, provider

## 简介

OpenCode Zen 免费池供应商：把 opencode-zen 注册进设置 → 模型的供应商列表，可增删改模型、配置图片输入与上下文；无需 API Key，请求强制直连（不走任何代理）。附带「Zen 免费池统计」设置页，按模型累计调用次数与输入/输出/缓存 token。2.1.1 修复 DSH 0.2.1 下统计接口不挂载（官方删除 webRuntime 服务，改用 connection.requestRejection）。
