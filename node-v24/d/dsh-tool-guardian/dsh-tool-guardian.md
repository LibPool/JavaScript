# dsh-tool-guardian

> 标签: context-window, deepseek-harness, dsh, dsh-bundle, dsh-plugin, local-llm, mcp, ollama, progressive-disclosure, router, tools

## 简介

Tool Guardian as a native DeepSeek Harness (DSH) bundle: keeps tool definitions out of the context window by fronting your MCP servers behind a small native router. A bridge to the Python tool-guardian, not a rewrite.
