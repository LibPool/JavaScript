# decane-node

> 标签: auth, decane, jwks, jwt, oauth, otp, signin, verify, wallet, web3

## 简介

Server-side SDK for Decane Connect Kit: sign users in (email OTP, Google, KingsChat, custom auth), verify access tokens, and resolve wallet addresses. The @privy-io/node equivalent.
