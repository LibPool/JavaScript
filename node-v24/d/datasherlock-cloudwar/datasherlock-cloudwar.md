# datasherlock-cloudwar

> 标签: JavaScript

## 简介

Cloudwar is a powerful TypeScript library that provides detailed information about machine types, regions, and availability zones for AWS and GCP. It ensures you have the most accurate and up-to-date data for your cloud infrastructure needs.
