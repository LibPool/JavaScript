# dsh-workspace-gate

> 标签: context, cordis, cordis-plugin, deepseek-harness, dsh, dsh-plugin, plugin-manager, prompt, token, workspace

## 简介

Workspace-scoped plugin gate for DeepSeek Harness: per directory, hide a plugin's tool schemas and system-prompt sections from the model, so unrelated projects stop paying their prompt prefix.
