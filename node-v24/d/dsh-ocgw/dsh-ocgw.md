# dsh-ocgw

> 标签: deepseek-harness, dsh, dsh-plugin, gateway, opencode, opencode-go, quota

## 简介

DSH 薄插件：OCGo Gateway 适配壳 — 指向网关、注入 gateway-key、注入对话标识、/ocgw 薄命令、精简自动推送、handoff。核心（gatewayClient/config/handoff）复用 shared-ocgw。
