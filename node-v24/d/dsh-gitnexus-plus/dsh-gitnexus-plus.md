# dsh-gitnexus-plus

> 标签: code-graph, code-index, coverage, dsh, dsh-plugin, gitnexus

## 简介

DSH plugin: visualize a GitNexus project index and its communities, decide whether a refresh would change anything before running it, search symbols by keyword, report what the index left out, and run incremental or FTS-repair maintenance from a sidebar p
