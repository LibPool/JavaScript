# discord-gradio

> 标签: ai-integration, cjs, discord, discord-js, discord-modals, esm, gradio, huggingface, stateless, typescript

## 简介

A stateless engine to bridge any Gradio App (Hugging Face, Shared Links) to Discord Modals with zero-config.
