# dsh-mobile-drawer

> 标签: deepseek-harness, dsh, dsh-plugin, input, mobile, sidebar

## 简介

「DSH·手机适配」：窄屏下把侧栏收起为悬浮小方块，点会话自动收起，压掉切会话时的自动聚焦，并在输入框补一排手机键盘上没有的按键。
