# date-time-combo-picker

> 标签: calendar, date-picker, date-time-picker, datetime, lit, time-picker, vaadin, web components, web-component

## 简介

A combined date & time picker web component: a single field with one popup containing a calendar. The date-time format pattern drives which time parts are shown.
