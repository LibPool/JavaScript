# dsh-agent-instructions-editor

> 标签: agents-md, deepseek-harness, dsh, instructions, plugin, settings

## 简介

Settings-page editor for DeepSeek Harness workspace instruction files: the user-global ~/.dsh/AGENTS.md, project-chain AGENTS.md/CLAUDE.md files, and AGENTS.local.md/CLAUDE.local.md overlays, with byte-budget display and new-session hints.
