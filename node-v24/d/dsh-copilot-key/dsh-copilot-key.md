# dsh-copilot-key

> 标签: automation, copilot-key, deepseek, dsh, dsh-plugin, keyboard-hook, windows

## 简介

Manage the Windows Copilot-key hook (DshCopilotKey.exe) from inside DeepSeek Harness: status, start/stop/restart, trigger, config.ini editing and logs.
