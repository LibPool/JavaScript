# dsh-luma-vision

> 标签: deepseek-harness, dsh, image, image-to-text, luma, mcp, multimodal, ocr, plugin, qwen, vision

## 简介

Vision bridge for DeepSeek Harness (dsh): image understanding for text-only models via luma-mcp, free Qwen3-VL-Flash by default. 视觉理解插件：让纯文本模型获得看图能力（截图/报错/OCR/UI 分析）。
