# dsh-plugins-cron

> 标签: JavaScript

## 简介

Persistent background scheduled agent jobs for dsh: cron_add/list/remove/run/logs with durable storage, agent-per-run execution, and a 30s dispatcher tick (Hermes cron + Kimi built-in cron pattern).
