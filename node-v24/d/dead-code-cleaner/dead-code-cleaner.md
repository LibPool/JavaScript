# dead-code-cleaner

> 标签: cleanup, dead-code, knip, nextjs, refactor, ts-morph, typescript, unused

## 简介

Find and safely remove dead code (unused variables, functions, imports, types, exports, files) and report explicit `any` in TypeScript / Next.js projects, with automatic rollback.
