# dsh-backdrop

> 标签: backdrop, background, customization, deepseek-harness, dsh, dsh-plugin, theme, wallpaper

## 简介

Wallpaper and per-section background images for the DeepSeek Harness web UI: one overall background, plus an optional image for the left sidebar, the main area and the right sidebar — each with its own opacity, display mode, alignment and effects.
