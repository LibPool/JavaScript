# dsh-decision-layer

> 标签: ai-agents, decision-layer, deepseek-harness, deepseek-harness-plugin, dsh, dsh-plugin

## 简介

A structured decision layer for the DeepSeek Harness agent loop: a danger-call gate, output self-check, tool narrowing, and loop guard backed by a pluggable adjudication model.
