# dsh-plugin-risk-rule-design

> 标签: deepseek-harness, dsh, plugin, risk-control, rule-mining, 规则挖掘, 风控

## 简介

DeepSeek Harness 第三方插件：金融风控规则挖掘。数据质检、连续变量阈值遍历、单规则挖掘、逐层遍历树并行(OR)组合搜索（F1 平衡最优）并输出自包含 HTML 分析报告。纯 JS 零依赖。
