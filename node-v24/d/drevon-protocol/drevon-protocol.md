# drevon-protocol

> 标签: drevon, enterprise, protocol, schema, zod

## 简介

The contract between the Drevon Enterprise console and the Drevon desktop app: Zod schemas, fixtures, and JSON Schema for policy, model catalog, enrollment, devices, audit, gateway errors, releases, licenses, and the catalog.
