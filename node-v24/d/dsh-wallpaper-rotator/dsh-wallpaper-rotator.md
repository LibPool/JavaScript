# dsh-wallpaper-rotator

> 标签: background, cordis, deepseek-harness, dsh, dsh-plugin, rotation, wallpaper

## 简介

DSH 壁纸轮换插件：定时轮换应用背景壁纸（交叉淡化动效），内置 SVG 壁纸集，毛玻璃/压暗/文字阴影/背景不透明度等可读性调节，设置页可配置。
