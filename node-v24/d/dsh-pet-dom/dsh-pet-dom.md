# dsh-pet-dom

> 标签: deepseek-harness, desktop-pet, dsh, dsh-plugin, mascot, pet, widget

## 简介

在 DeepSeek Harness Web 界面上跳跃的桌面宠物（Miku）：真实物理跳跃、自动识别页面可落脚区域、规划巡游与突发小动作；支持键盘控制玩法与可调控制台（高亮/合并/主题色/透明度），设置自动保存。
