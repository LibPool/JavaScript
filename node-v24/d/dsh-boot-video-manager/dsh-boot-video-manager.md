# dsh-boot-video-manager

> 标签: audio, boot-animation, cold-start, deepseek-harness, dsh, dsh-plugin, splash-screen

## 简介

DSH 开屏动画的配套插件：管理开屏视频播放列表（顺序/随机/单次），带开屏声音开关和音频自检状态条，并会自动补好旧版动画插件「开机第一次没声音」的修复。
