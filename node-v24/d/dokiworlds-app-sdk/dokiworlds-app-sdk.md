# dokiworlds-app-sdk

> 标签: JavaScript

## 简介

An App embedded in DokiWorlds can request that its host launch another App. This first release exposes only `apps.launch`; the host controls catalog lookup, permission checks, presentation, and the launched App's lifecycle.
