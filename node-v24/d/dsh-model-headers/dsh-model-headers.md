# dsh-model-headers

> 标签: deepseek-harness, dsh, dsh-plugin, headers, prompt-cache

## 简介

Per-model custom request headers: inject headers into LLM requests matched by model-name wildcard; values support fixed strings and the ${sessionId} variable. Managed from a settings-page UI.
