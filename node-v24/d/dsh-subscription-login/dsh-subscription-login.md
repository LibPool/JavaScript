# dsh-subscription-login

> 标签: claude, codex, copilot, deepseek, deepseek-harness, dsh, dsh-bundle, dsh-plugin, login, oauth, openrouter, subscription, web-ui

## 简介

Subscription sign-in console for DeepSeek Harness: sign in to ChatGPT (Codex), Claude, GitHub Copilot and OpenRouter through DSH's own authorization flows, from one page that lists every registered flow instead of one provider.
