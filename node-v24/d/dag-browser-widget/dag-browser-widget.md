# dag-browser-widget

> 标签: dag, graph, hierarchy, polyhierarchy, react, tree

## 简介

Dependency-free logic + a thin React view for browsing a DAG (polyhierarchy) as a collapsible tree, de-duplicating nodes that appear under multiple parents.
