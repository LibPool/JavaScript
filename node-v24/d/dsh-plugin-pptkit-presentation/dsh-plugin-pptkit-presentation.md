# dsh-plugin-pptkit-presentation

> 标签: JavaScript

## 简介

DeepSeek Harness plugin bundle that registers the pptkit-presentation Agent Skill (PPTKit deck authoring, preview, and PPTX export) with DSH's skill catalog.
