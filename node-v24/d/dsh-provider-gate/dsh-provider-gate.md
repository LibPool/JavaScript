# dsh-provider-gate

> 标签: deepseek-harness, dsh, dsh-plugin, model, provider, toggle

## 简介

供应商开关：一键禁用/启用任意 provider 路由（含其他插件注入的），禁用后模型选择器不再出现该供应商。
