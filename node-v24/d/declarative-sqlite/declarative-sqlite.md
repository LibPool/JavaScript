# declarative-sqlite

> 标签: capacitor, live-query, offline-first, outbox, pwa, sqlite, sync, typescript

## 简介

Offline-first sync data layer for SQLite in the browser: declarative schema, automatic migration, live queries, outbox, drafts and cursor-based sync
