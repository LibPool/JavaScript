# dsh-plugin-session-fulltext

> 标签: chinese, cjk, deepseek-harness, dsh, dsh-plugin, full-text, search, session-search

## 简介

CJK-friendly full-text content search for the DSH sidebar: literal substring search over Session history, click-to-reveal highlighting, and in-session previous/next match navigation.
