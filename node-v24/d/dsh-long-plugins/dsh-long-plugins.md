# dsh-long-plugins

> 标签: JavaScript

## 简介

Merged DSH web plugins: upload manager (drag-and-drop attach any file to the message), workspace output files, skill docs, account balance, and polished file preview (Word & PowerPoint real preview with zoom/pan, rendered Markdown). | 一个插件整合 DSH Web 的常用增强
