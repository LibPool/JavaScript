# dsh-models-router

> 标签: deepseek-harness, dsh, dsh-plugin, failover, fallback, llm, model-routing, retry, router

## 简介

Transparent cross-provider failover for DSH Agent main requests: named fallback chains, per-session chain choice, per-route retry overrides.
