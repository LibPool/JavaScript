# dsh-better-model-selector

> 标签: JavaScript

## 简介

DSH web plugin: splits the composer model selector into two independent controls — a searchable, favorite-marking model dropdown and a reasoning-effort slider — plus Ctrl+P (cycle favorite models) and Ctrl+T (cycle reasoning effort) shortcuts.
