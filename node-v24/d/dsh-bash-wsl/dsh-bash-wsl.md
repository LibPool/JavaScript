# dsh-bash-wsl

> 标签: bash, bridge, deepseek-harness, dsh, linux, windows, wsl

## 简介

Route the Windows-side DeepSeek Harness bash tool into WSL: run bash in the WSL distro with automatic workdir mapping from D:\... to /mnt/d/...
