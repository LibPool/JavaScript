# dsh-tool-folder

> 标签: bm25, cordis, deepseek-harness, dsh, dsh-plugin, firewall, obfuscation, security, semantic-search, token-optimization, tool-selection

## 简介

Fold the DSH tool surface per request + ChainGuard firewall (high-risk block + exfil-chain detection + anti-obfuscation) + BM25/bge-m3 hybrid tools_search. Shrinks schema tokens 80-90% while keeping selection accuracy. v0.2.0 adds a semantic retrieval leg
