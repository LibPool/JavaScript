# dsh-heatmap-cost

> 标签: balance, cordis, cost, deepseek-harness, dsh, heatmap, plugin, token

## 简介

Token/费用热力图插件：在 dsh Web UI 输入框下方统计条实时显示 DeepSeek 余额与本会话消耗，点击展开 GitHub 风格的热力图（近 365 天每日 token / 金额）
