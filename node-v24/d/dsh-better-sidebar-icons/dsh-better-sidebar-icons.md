# dsh-better-sidebar-icons

> 标签: JavaScript

## 简介

VSCode-style file/folder icon theme for the dsh-better-sidebar explorer and editor tabs (vscode-icons port). Applied as a pure DOM overlay: no core changes, unload-safe.
