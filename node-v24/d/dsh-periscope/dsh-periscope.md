# dsh-periscope

> 标签: asar, attachment, deepseek-harness, dsh, dsh-desktop, file, installer, patch, upload

## 简介

DSH Desktop: drop/paste any file (docx/xlsx/pdf/txt/zip…) into the conversation — the agent reads it by path. Generic file attachments are applied as core patches to the packaged app.asar via the in-place repacker (scripts/repack-inplace.mjs / install.ps1
