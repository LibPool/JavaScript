# dsh-whale-particles

> 标签: background, deepseek-harness, dsh, dsh-plugin, particles, wallpaper, whale

## 简介

Interactive whale particle background for the DSH Web UI: every dot carries its own slow force; mouse disturbs them, plus an auto screensaver mode with 360-degree waves and full-screen breathing.
