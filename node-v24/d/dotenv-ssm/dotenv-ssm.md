# dotenv-ssm

> 标签: JavaScript

## 简介

Simple utility to fetch env vars from the [AWS SSM Parameter Store](https://docs.aws.amazon.com/systems-manager/latest/userguide/systems-manager-parameter-store.html) and create a `.env` file from them.
