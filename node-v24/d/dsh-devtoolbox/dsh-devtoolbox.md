# dsh-devtoolbox

> 标签: deepseek-harness, devtools, dsh, dsh-plugin, toolbox, utils

## 简介

DSH 工具箱插件：侧边栏独立页面 + /toolbox 命令 + 配置驱动的 agent 确定性工具。52 个本地工具（文本/编码/数据/安全/提取/转换/网络/效率），数据不出机器。参考 devtoolbox.online 设计。
