# dsh-kaomoji

> 标签: deepseek-harness, dsh, dsh-plugin, emoji, kaomoji, kaomojiya, 颜文字

## 简介

Add mood-aware Japanese kaomoji to DeepSeek Harness (dsh) replies; prompt-injection plugin with a curated library from kaomojiya.org.
