# dsh-usage-panel

> 标签: agent-analytics, deepseek, deepseek-harness, dsh, dsh-plugin, token-usage, typescript, usage-statistics

## 简介

DeepSeek Harness 消耗统计插件：设置页「消耗统计」展示 Token 用量 KPI、半年活跃贡献热力图、按模型堆叠柱状图与模型环形图（Host 投影聚合 + 只读重算会话日志，永不写回）
