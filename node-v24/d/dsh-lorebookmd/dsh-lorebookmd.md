# dsh-lorebookmd

> 标签: deepseek-harness, dsh, fiction, lorebook, novel, plugin, sillytavern, tavern, world-info

## 简介

DSH lorebook-driven fiction writer plugin: import Tavern/SillyTavern character cards & world books, save local Markdown lore documents, and generate novel prose with the world settings as reference.
