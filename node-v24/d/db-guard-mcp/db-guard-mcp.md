# db-guard-mcp

> 标签: ai, database, db-guard, mcp, model-context-protocol, security, sqlite

## 简介

SQLite 数据库访问的 MCP server（最小 stdio 实现，零依赖）。只读优先、写操作强制 preview_id 绑定、自动备份+审计；支持结构化受控写入 db_audit_write（UPDATE/INSERT/DELETE）。作为 AI 助手访问 SQLite 的安全闸门。
