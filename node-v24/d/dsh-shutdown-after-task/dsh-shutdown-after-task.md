# dsh-shutdown-after-task

> 标签: auto-shutdown, deepseek-harness, dsh, dsh-plugin, power, shutdown, task-complete, 关机

## 简介

Shut down Windows after DeepSeek Harness tasks complete — draggable button, auto-dodge, cancellable countdown. 任务完成后自动关机（按钮可拖动、自动避让，倒计时可取消）。
