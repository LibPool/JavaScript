# dsh-plugin-atlas

> 标签: archive, deepseek, dsh, dsh-plugin, harness, navigation

## 简介

Archive manager (browse / unarchive / auto-rules) plus a Codex-style left tick rail for jumping between conversation turns. · 归档管理（浏览、取消归档、自动归档规则）与左侧对话刻度栏跳转。
