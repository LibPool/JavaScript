# dsh-oc-change-review

> 标签: deepseek, diff, dsh, dsh-plugin, harness, review

## 简介

DeepSeek Harness 会话修改审查：追踪会话内 write/edit 工具调用，以可自定义颜色的 diff 对比展示；会话隔离、子代理聚合、SSE 实时推送。
