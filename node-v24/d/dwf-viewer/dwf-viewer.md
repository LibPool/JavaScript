# dwf-viewer

> 标签: cad, dwf, dwf-viewer, dwfx, dwfx-viewer, frontend, hsf, line-width, lineweight, pure-frontend, threejs, viewer, w2d, w3d, wasm, webgl, xps, xps-webgl

## 简介

World's first open-source pure frontend DWF/DWFx preview component with WebGL XPS/W2D 2D rendering, W3D/HSF 3D rendering, embedded fonts, and WASM fallback.
