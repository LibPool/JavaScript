# dsh-kimi-quota

> 标签: deepseek-harness, dsh-plugin, kimi, kimi-code, quota, statusline, subscription, usage

## 简介

Kimi Code subscription quota bar for DeepSeek Harness: 5-hour/monthly usage windows and monthly equivalent spend, shown under the composer when the conversation uses a Kimi model
