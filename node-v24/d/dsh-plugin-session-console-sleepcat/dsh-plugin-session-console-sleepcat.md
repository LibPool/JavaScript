# dsh-plugin-session-console-sleepcat

> 标签: client, conversation, cordis, dsh, plugin, session

## 简介

DSH client UI plugin: a questions console for the current session (full history with jump-to-locate, per-question AI Q&A detail), and per-question collapse/expand of the model's working process.
