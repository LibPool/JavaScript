# dynamic-db-mcp-server

> 标签: acl, api-key, database, mcp, mcp-server, mysql, oracle, postgresql, sqlite, sqlserver

## 简介

Turn any relational database into a secure MCP server by configuration: API Key auth, table ACL, SQL AST validation, audit log and a web admin console.
