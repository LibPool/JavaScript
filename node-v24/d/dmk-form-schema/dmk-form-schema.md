# dmk-form-schema

> 标签: form, framework-agnostic, schema, validation, vue3, 校验, 表单

## 简介

框架无关的表单引擎。声明式 schema、校验器链、字段联动、异步校验、实时状态订阅。Vue 已适配（dmk-form-schema/vue），校验器独立导出（dmk-form-schema/validators）。
