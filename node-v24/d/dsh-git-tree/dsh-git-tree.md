# dsh-git-tree

> 标签: deepseek-harness, diff, dsh, dsh-plugin, git, source-control

## 简介

DeepSeek Harness plugin: a Sourcetree-style Git workspace — branches, diff, history, fetch/pull/push, AI-written commit messages and AI-assisted conflict resolution, with pinned and usage-ordered repositories.
