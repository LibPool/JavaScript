# @cordn/core

> 标签: bech32, codec, contextvm, cordn, mcp, mls, nostr

## 简介

Shared foundation for cordn: wire contracts (zod), leaf codecs (base64, MLS framing, group-ref bech32, group metadata + coordinator routing), and consumed-ref value types.
