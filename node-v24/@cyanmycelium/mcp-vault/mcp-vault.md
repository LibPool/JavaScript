# @cyanmycelium/mcp-vault

> 标签: cyanmycelium, end-to-end-encryption, mcp, mcp-broker, openbao, secrets, vault

## 简介

The vault.v1 contract above an mcp-broker: secrets and config files shared between slots, sealed end to end, access decided by the broker, stored in OpenBao.
