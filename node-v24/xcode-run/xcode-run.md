# xcode-run

> 标签: cli, devicectl, fzf, git-worktree, ios, mac-catalyst, simctl, simulator, xcode, xcodebuild

## 简介

Build an iOS app from the current git worktree and run it on your Mac, an iPhone, an iPad, or a simulator, with a console you can filter. No Xcode window needed.
