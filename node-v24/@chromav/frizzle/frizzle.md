# @chromav/frizzle

> 标签: ast, compiler, drizzle, filter, lexer, parser, parser-combinator, query

## 简介

A fun, type-safe query compiler with a parser-combinator grammar, pluggable code generators, and built-in validation. Filter, sort, and query your data.
