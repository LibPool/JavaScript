# @harrybin/visuals-mcp

> 标签: ai-tools, area-chart, bar-chart, charts, chat, data-visualization, github-copilot, image-preview, interactive-table, line-chart, list-view, mcp, mcp-apps, mcp-server, modelcontextprotocol, pie-chart, recharts, table, tanstack-table, tree-view, visualization, vscode

## 简介

MCP server providing interactive visualizations: tables with TanStack Table, charts with Recharts, image previews, master-detail views, tree views for hierarchical data, and customizable lists
