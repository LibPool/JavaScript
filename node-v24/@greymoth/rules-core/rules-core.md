# @greymoth/rules-core

> 标签: audit, deterministic, greymoth, no-llm, rule-engine, scoring

## 简介

Deterministic rule engine (no LLM): define rules as data, evaluate any subject into findings and a 0–100 score. The engine behind greymoth's audit tools.
