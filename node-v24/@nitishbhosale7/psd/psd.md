# @nitishbhosale7/psd

> 标签: effects, figma, layer, parser, photoshop, psb, psd

## 简介

A friendly fork of @webtoon/psd: a zero-dependency Adobe Photoshop .psd/.psb parser with a normalized, well-named API for blend modes, layer effects, text styling, visibility, and group bounds.
