# @manoelcarvalho/brazis

> 标签: JavaScript

## 简介

**Brazis** é uma linguagem de programação criada por **Manoel Carvalho** para fins didáticos. Inspirada na cultura brasileira, seu objetivo é ensinar lógica de programação para iniciantes usando uma sintaxe simples e em português.
