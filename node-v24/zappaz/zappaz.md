# zappaz

> 标签: baileys, bun, express, hono, sqlite, webhooks, whatsapp, whatsapp-api

## 简介

Embeddable WhatsApp API for Node.js and Bun: sessions, messaging, groups and webhooks on SQLite, with Express and Hono adapters.
