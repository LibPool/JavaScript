# glass-toast

> 标签: dark-mode, expo, glass, notifications, react-native, reanimated, snackbar, toast

## 简介

A lightweight toast notification library for React Native — monochrome pill toasts with action buttons, animated icons, light/dark themes and full customization (sizes, fonts, animations, layout).
