# @webextensions/live-css

> 标签: add-on, addon, apply, browser, changes, chrome, css, development, edge, editor, extension, files, firefox, google, less, live, magic, magicss, microsoft, mozilla, opera, refresh, reload, sass, server, watch, webextension

## 简介

live-css is a Node JS based development server for use with the browser extension "Live editor for CSS, Less & Sass - Magic CSS" for Chrome/Edge/Firefox/Opera
