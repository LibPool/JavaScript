# @anrakai/mcp

> 标签: anraklegal, claude, cursor, hermes, india, legal, mcp, model-context-protocol, stdio

## 简介

AnrakLegal MCP bridge — exposes the full AnrakLegal connector tool suite to any stdio MCP client (Hermes, Claude Desktop, Cursor, etc.) by forwarding to your hosted /token/{token}/mcp endpoint.
