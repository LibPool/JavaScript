# @ilovevideoeditor/sdk-node

> 标签: api-client, cloud-rendering, ilovevideoeditor, mp4, programmatic-video, render-api, sdk, typescript, video-api, video-automation, video-editing, video-generation, video-rendering, video-templates

## 简介

Official Node.js / TypeScript SDK for the iLoveVideoEditor cloud video rendering API — submit JSON scenes or templates, queue renders, download MP4/WebM.
