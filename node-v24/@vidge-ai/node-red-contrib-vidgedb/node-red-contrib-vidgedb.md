# @vidge-ai/node-red-contrib-vidgedb

> 标签: digital-twin, industrial, node-red, timeseries, vidgedb, vql

## 简介

Node-RED nodes for VidgeDB: visual connector to a VidgeDB digital-twin database over the JSON-RPC 2.0 stdin/stdout service (spawn managed as a subprocess). Query, ingest telemetry, deviation checks and event logging for real machines (OPC-UA/MQTT bridges)
