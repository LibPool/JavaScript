# maniflight

> 标签: branch-protection, ci, cli, code-review, devtools, diagnostics, github, github-actions, merge, pull-request

## 简介

Read-only GitHub pull-request diagnostics: why a PR is blocked, what evidence is missing, and who has to move next.
