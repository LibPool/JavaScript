# @dsh-plus/web-shell-sw

> 标签: JavaScript

## 简介

dsh-plus ui plugin: 外壳 Service Worker——内容寻址静态资源 cache-first、index network-first 离线兜底；绝不触碰 RPC/SSE/网关路由，token 页（no-store）永不入缓存，settings 一键注销
