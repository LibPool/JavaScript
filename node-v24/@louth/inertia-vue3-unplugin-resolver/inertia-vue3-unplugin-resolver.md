# @louth/inertia-vue3-unplugin-resolver

> 标签: inertia, resolver, unplugin, vue3

## 简介

Custom resolver for unplugin-vue-components to auto-import Inertia.js components in Vue 3 projects. Simplifies development by removing the need for manual imports, enhancing code clarity and productivity.
