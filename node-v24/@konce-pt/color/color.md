# @konce-pt/color

> 标签: apca, color, colour, contrast, design-system, gamut, koncept-ui, kpt, oklab, oklch, wcag

## 简介

Colour maths for Koncept UI — sRGB, OKLab and OKLCH conversions, hue-aware mixing, gamut mapping, WCAG and APCA contrast. Framework-free TypeScript, zero runtime dependencies.
