# @konce-pt/datetime

> 标签: calendar, date-range, datepicker, design-system, koncept-ui, kpt

## 简介

Calendar and clock core for Koncept UI date controls — day/month/year/decade grids, ranges, dial marks. Framework-free TypeScript, zero runtime dependencies.
