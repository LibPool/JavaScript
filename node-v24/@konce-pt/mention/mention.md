# @konce-pt/mention

> 标签: autocomplete, design-system, koncept-ui, kpt, mention, mentions

## 简介

Mention core for Koncept UI — parsing @mentions in text, the active query at the caret and diacritics-insensitive matching. Framework-free TypeScript, zero runtime dependencies.
