# @hashspan/faults

> 标签: anvil, chaos-testing, ethereum, evm, fault-injection, json-rpc, proxy, testing, viem

## 简介

A JSON-RPC fault proxy for tests: puts an HTTP proxy between an EVM client and a local node and makes chosen methods hang, fail, reset or answer wrong.
