# @toolars/cli

> 标签: base64, cli, cron, developer-tools, hash, jwt, local-first, mcp, mcp-server, model-context-protocol, privacy, stdio, toolars, ulid, uuid

## 简介

Local-first developer CLI and stdio MCP server for Toolars: hash, Base64, JWT decode, UUID/ULID, timestamp, cron and URL encode/decode. Zero runtime dependencies, no network access, no telemetry.
