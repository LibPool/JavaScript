# @noro-to/noro

> 标签: amazon-dsp, claude, cli, google-ads, llm, mcp, meta-ads, openrouter, paid-media, ppc, reporting

## 简介

Open-source framework that turns raw ad-platform exports into short paid-media reports where every number is traced. Code computes the numbers; your choice of model writes the words.
