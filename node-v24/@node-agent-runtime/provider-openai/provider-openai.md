# @node-agent-runtime/provider-openai

> 标签: agent, llm, node-agent-runtime, openai, provider

## 简介

C7 OpenAI-compatible chat backend of the Agent runtime: fetch-based client for OpenAI / DeepSeek / Qwen / Moonshot / Ollama etc. Injected by the caller; the core never imports it.
