# @node-agent-runtime/core

> 标签: agent, events, llm, node-agent-runtime, runtime, tool-calling

## 简介

C2 engine package of the Agent runtime: AgentRuntime run loop, agent recipe, run context, EventBus, tool/model contracts and the zero-dependency MemoryStorage/FileStorage, plus a facade re-exporting types/memory/artifact/sandbox/policy. Session & provider
