# @node-agent-runtime/memory

> 标签: agent, checkpoint, memory, node-agent-runtime, session

## 简介

C3 memory package of the Agent runtime: SessionMemory (session transcript + long-term fact layer) and the checkpoint facility (step snapshots + resume validation on a ToolSurface). ArtifactManager lives in @node-agent-runtime/artifact. Depends only on @no
