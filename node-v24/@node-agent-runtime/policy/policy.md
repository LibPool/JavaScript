# @node-agent-runtime/policy

> 标签: agent, approval, node-agent-runtime, permissions, policy

## 简介

C5 policy package of the Agent runtime: authorization decisions (allow/deny/ask) — DefaultPermissionPolicy matrix, PermissionManager approval flow with timeout and always-allowlist, composable policies. Depends on @node-agent-runtime/types and (type-only)
