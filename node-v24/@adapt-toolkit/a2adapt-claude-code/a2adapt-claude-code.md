# @adapt-toolkit/a2adapt-claude-code

> 标签: a2a, adapt, claude, claude-code, mcp, messaging, plugin

## 简介

Claude Code plugin for a2adapt — secure agent-to-agent messaging over ADAPT. Bundles the a2adapt skill and session hooks, and registers an MCP server that proxies to the @adapt-toolkit/a2adapt daemon.
