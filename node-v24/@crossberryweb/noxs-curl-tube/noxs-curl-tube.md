# @crossberryweb/noxs-curl-tube

> 标签: cloud, curl, developer tools, noxs, plugin, share, upload

## 简介

Terminal client for your file cloud: login, list, push (resumable chunked uploads with per-piece SHA-256), pull, share and delete. Noxs plugin artifact (.noxs-plugin) for the Plugin Store; manage plugins with npx @crossberryweb/nx
