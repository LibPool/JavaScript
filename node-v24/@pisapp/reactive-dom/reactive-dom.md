# @pisapp/reactive-dom

> 标签: JavaScript

## 简介

PIS v7 reactive template engine — reactiveMount wraps a render function in @vue/reactivity's effect() so cells built from a reactive ctx re-render on change. MountPoint wraps every plain-DOM render function in it (decisions D-JsReactivity / D-JsLock).
