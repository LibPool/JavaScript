# @leo108/geolite2-db

> 标签: GeoIP, GeoIP2, GeoLite, GeoLite2, Maxmind

## 简介

This repository aims to provide an easy solution to require GeoIP2 / GeoLite2 databases inside your project using npm/yarn.
