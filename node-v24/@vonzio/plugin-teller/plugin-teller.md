# @vonzio/plugin-teller

> 标签: JavaScript

## 简介

Bank data for vonzio agents via the Teller API (teller.io). Operator-provisioned mTLS client cert + 5 read-only MCP tools (enrollments, accounts, balances, transactions, account details).
