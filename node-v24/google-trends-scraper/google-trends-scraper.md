# google-trends-scraper

> 标签: google-hot-keywords, google-search-keywords, google-trends, google-trends-api, google-trends-scraper

## 简介

Unofficial Google Trends scraper and Trending Now API for Node.js and TypeScript. Fetch trending searches by country without an API key or browser.
