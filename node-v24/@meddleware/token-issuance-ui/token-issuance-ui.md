# @meddleware/token-issuance-ui

> 标签: JavaScript

## 简介

A browser front-end that lets anyone deploy their own Sui coin — a client-side equivalent of [`token-issuance-template-sui`](https://github.com/meddleware-org/token-issuance-template-sui)'s CLI. **Everything runs in the browser**: the user's wallet signs
