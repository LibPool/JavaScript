# @shinnjr/tokenguard

> 标签: access-token, claims, expiry, id-token, jwt, oauth, parse, token

## 简介

Tiny, zero-dep token utilities: parse, validate expiry, extract claims from JWT/OAuth tokens. No crypto, no network, no secrets.
