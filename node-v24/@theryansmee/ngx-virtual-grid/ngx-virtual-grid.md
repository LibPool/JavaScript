# @theryansmee/ngx-virtual-grid

> 标签: angular, angular-component, angular-grid, angular-infinite-scroll, angular-virtual-scroll, angular22, css-grid, infinite-loading, infinite-scroll, large-list, ngx, performance, responsive-grid, scroll-performance, virtual-grid, virtual-scroll, virtualization, windowing

## 简介

A responsive virtual-scrolling grid for Angular with infinite scroll. CSS Grid layout with virtual scrolling - the grid solution Angular CDK doesn't offer.
