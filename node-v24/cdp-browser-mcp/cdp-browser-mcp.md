# cdp-browser-mcp

> 标签: ai, browser, cdp, chrome-devtools-protocol, console, devtools, har, llm, mcp, modelcontextprotocol, network

## 简介

MCP server that lets an AI assistant inspect running browsers over the Chrome DevTools Protocol: enumerate browser processes, capture console logs, network traffic, DOM, performance metrics, and save everything in one shot.
