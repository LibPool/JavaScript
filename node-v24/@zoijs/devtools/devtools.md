# @zoijs/devtools

> 标签: debug, devtools, inspector, no-build, no-jsx, reactive, reactivity, signals, zoijs

## 简介

A reactive-graph inspector for Zoijs: watch one state update exactly one DOM node. Dev-only, read-only, no build step.
