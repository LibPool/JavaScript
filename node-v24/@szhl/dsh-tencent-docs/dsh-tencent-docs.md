# @szhl/dsh-tencent-docs

> 标签: cordis, deepseek-harness, documents, dsh, dsh-plugin, mcp, oauth, tencent-docs, tools

## 简介

DeepSeek Harness plugin: connect Tencent Docs end to end — a composer menu row with QR authorization and a document picker, plus the official Tencent Docs MCP server, so the model gains mcp__tencent-docs__* tools.
