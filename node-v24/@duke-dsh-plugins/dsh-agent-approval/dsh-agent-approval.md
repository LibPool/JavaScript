# @duke-dsh-plugins/dsh-agent-approval

> 标签: approval, deepseek-harness, dsh, plugin, security

## 简介

Agent-decided approvals for DeepSeek Harness: an 自动审批 permission mode where every sandbox escalation is judged automatically by an LLM (default judge: one direct LLM call with no subagent session; optional isolated judge subagent) plus an independent 自动审查
