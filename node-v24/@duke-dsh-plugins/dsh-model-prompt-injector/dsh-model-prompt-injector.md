# @duke-dsh-plugins/dsh-model-prompt-injector

> 标签: deepseek-harness, dsh, llm, model, persona, plugin, prompt, system-prompt

## 简介

为 DeepSeek Harness 中本地已配置的模型追加系统提示词：按 provider/model 精确匹配或服务商级通配（provider/*）注入到系统提示词末尾，设置面板逐模型管理，规则持久化、重启不丢。
