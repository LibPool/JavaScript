# jwt-term

> 标签: auth, cli, developer-tools, json-web-token, jwt, jwt-decoder, jwt-inspector, signature-verifier, terminal, token

## 简介

High-fidelity inline terminal JWT inspector, decoder, signature verifier, and expiry countdown timer across macOS, Linux, Windows, PowerShell, Bash, and Zsh.
