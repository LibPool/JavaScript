# @ipalpha/shared-ui

> 标签: JavaScript

## 简介

IPAlpha React component library aligned with Apple Human Interface Guidelines. Adaptive (iOS on narrow, sidebar on wide), SCSS source shipped for consumer compilation. Generic UI only, no business logic.
