# @ipalpha/shared-js

> 标签: JavaScript

## 简介

Shared helpers for IPAlpha core microservices: roles, guards, JWT/JWKS verification, revocations, system tokens, RabbitMQ wrapper, readiness, Mongo id mapping. Helpers only, no business logic.
