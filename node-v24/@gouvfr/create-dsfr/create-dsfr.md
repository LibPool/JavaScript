# @gouvfr/create-dsfr

> 标签: Systeme de Design de l'Etat, cli, create, dsfr, gouvfr

## 简介

Le module `create-dsfr` permet d'initialiser le système de design de l'État (@gouvfr/dsfr) dans un projet.
