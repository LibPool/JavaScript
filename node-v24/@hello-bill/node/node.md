# @hello-bill/node

> 标签: express, hellobill, onboarding, partner-api, sdk, utilities, webhook

## 简介

Server-side SDK for the HelloBill Partner API. Framework-agnostic core with an Express adapter; ships a webhook verifier and the spec-derived TypeScript types.
