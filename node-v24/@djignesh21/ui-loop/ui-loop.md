# @djignesh21/ui-loop

> 标签: a11y, claude-code, codex, coding-agent, context-budget, cursor, mcp, mcp-server, playwright, screenshot, ui-testing, visual-diff

## 简介

Context-budgeted visual feedback for coding agents. MCP server + CLI + Claude Code plugin that lets an agent see the UI it just changed without flooding context.
