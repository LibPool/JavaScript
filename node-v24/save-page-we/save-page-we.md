# save-page-we

> 标签: ad blocker, archive, headless chrome, html, offline, puppeteer, save page, scraper, single file, snapshot, web archive

## 简介

Save a complete web page as a single self-contained HTML file with headless Chrome - a Node.js port of the Save Page WE browser extension
