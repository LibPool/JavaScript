# @gbitx/pay-react-native

> 标签: bitcoin, checkout, crypto, gbitx, gbitxpay, payments, react-native, usdt, webview

## 简介

Accept crypto payments in your React Native app with GbitXPay. Opens the hosted GbitX checkout in a hardened WebView.
