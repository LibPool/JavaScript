# @observiz/metrics

> 标签: JavaScript

## 简介

Metrics for Node and Bun APIs via OpenTelemetry. Ships to Prometheus and visualized in Grafana. Part of the [Observiz](https://github.com/chandranilbakshi/observiz-sdk) monorepo.
