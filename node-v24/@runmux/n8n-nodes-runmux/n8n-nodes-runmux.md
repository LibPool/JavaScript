# @runmux/n8n-nodes-runmux

> 标签: ai-video, n8n, n8n-community-node-package, runmux, seedance, video-generation

## 简介

n8n community node for RunMux — generate video with Seedance 2.0 and manage the face asset library. The node polls internally via the RunMux SDK, so a video URL just comes back.
