# @huaqiu/dsh-tool-pcb-viewer

> 标签: 3d, deepseek-harness, dsh, eda, kicad, pcb, plugin, viewer

## 简介

KiCad .kicad_pcb → interactive 2D-layout + 3D board viewer DSH plugin: a pcb_preview tool, an in-conversation turn-tail card (live 3D thumbnail + actions), a big-screen split panel, and a standalone full-page route. Parses via @huaqiu/kicad-sexpr-parser t
