# @reiutsuho/pix

> 标签: cli, docker, pi-coding-agent, wrapper

## 简介

A Windows CLI launcher for @earendil-works/pi-coding-agent that runs Pi inside WSL2 and an optional Docker sandbox, sharing a single canonical runtime.
