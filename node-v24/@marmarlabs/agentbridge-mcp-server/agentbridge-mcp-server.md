# @marmarlabs/agentbridge-mcp-server

> 标签: agentbridge, ai-agents, http, mcp, model-context-protocol, stdio

## 简介

MCP server that exposes AgentBridge actions to AI agents with confirmation gates, origin pinning, and audit logging. Default stdio transport plus an opt-in Streamable HTTP transport with bearer auth.
