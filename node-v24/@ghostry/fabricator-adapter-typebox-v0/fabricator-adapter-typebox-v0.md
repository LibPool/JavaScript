# @ghostry/fabricator-adapter-typebox-v0

> 标签: factory, fixtures, mock, reproducible, schema, testing, typebox, typescript

## 简介

TypeBox v0 (@sinclair/typebox 0.34.x) adapter for @ghostry/fabricator — converts any Fabricator Schema to a TypeBox schema.
