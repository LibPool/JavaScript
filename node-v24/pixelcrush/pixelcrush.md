# pixelcrush

> 标签: canvas, color-reduction, downscale, image, median-cut, palette, pixel-art, pixelate, pixelation, quantize

## 简介

Pixelates an image to a grid and reduces it to a few colours: pure functions on RGBA pixels, and helpers for a browser image or canvas.
