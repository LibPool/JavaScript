# @deepnoid/canvas

> 标签: JavaScript

## 简介

이 프로젝트는 본부 내 프로젝트에서 사용되는 공통 CANVAS 라이브러리입니다. 주요 본부 프로젝트인 **DEEP:FENSE**와 **DEEP:SEED** 에서 사용되고 있습니다.
