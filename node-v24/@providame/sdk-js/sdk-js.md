# @providame/sdk-js

> 标签: auth, authentication, providame

## 简介

Providame auth SDK — vanilla JS, zero runtime deps, drop-in components and headless auth primitives (for plain <script> tag / non-TypeScript use; see @providame/core in sdk/core for the TypeScript SDK sdk/vue builds on)
