# @bb-studio/ocio

> 标签: ACES, OCIO, OpenColorIO, color-management, wasm, webgpu, wgsl

## 简介

OpenColorIO 2.5.2 WebAssembly bindings with CPU, GPU shader extraction, and WebGPU/WGSL support.
