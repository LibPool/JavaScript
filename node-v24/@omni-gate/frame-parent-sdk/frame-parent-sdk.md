# @omni-gate/frame-parent-sdk

> 标签: dictionary-cache, frame-bridge, jwt-management, omni-gate, parent-window, permissions, shell

## 简介

Parent-window (platform shell) SDK for Omni Gate: user/session management, permission and dictionary APIs with IndexedDB caching, JWT expiry monitoring and broadcast to all child windows. Only the shell installs this package.
