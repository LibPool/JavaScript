# @avenirs-esr/avenirs-dsav

> 标签: JavaScript

## 简介

DSAV is the deisgn system for AVENIR(s) projects and consists of a [**Vue 3**](https://v3.vuejs.org/) project in the form of a **component library**. It also provides an utility-first CSS framework for handling components styling.
