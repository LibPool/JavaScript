# @zxuqian/react-examples

> 标签: examples, javascript, react, react examples, web

## 简介

这个示例项目是由 Create-React-App 工具创建的，只导出了组件相关的部分，所以需要自己安装一下 React 相关的依赖。如果你的项目也是用 CRA 创建的，那么就不用做任何操作了~
