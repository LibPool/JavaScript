# @wzrhine/agent-core

> 标签: JavaScript

## 简介

Framework-free Agent UI contracts for WzRhineLab UI: view-model types, the three status axes, status metadata and pure helpers (dedupe, revision guards, diffs, composer tokens, formatting).
