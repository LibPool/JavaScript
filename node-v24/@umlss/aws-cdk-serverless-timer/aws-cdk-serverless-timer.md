# @umlss/aws-cdk-serverless-timer

> 标签: cdk

## 简介

The purpose of this AWS CDK Construct is to allow one to deploy a scaleable periodic timer that invokes scaleable a Lambda function.  The timer service is controlled by an API Gateway REST API.
