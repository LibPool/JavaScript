# @swal/vault

> 标签: aes-gcm, e2ee, encryption, local-first, shamir, webcrypto

## 简介

SWAL Vault Core: browser-safe end-to-end encryption for local-first apps (AES-256-GCM AEAD, Shamir 2-of-3 key shares, Ed25519-signed sealed packs, optional R2 cloud share). WebCrypto only.
