# @asinnn/stamp-js

> 标签: browser, exif, isobmff, itunes-tags, jpeg, low-memory, metadata, mov, mp4, png, streaming, xmp

## 简介

Low-memory media metadata writer: writes XMP / iTunes tags into JPEG, PNG, and MP4/MOV without re-muxing or re-encoding.
