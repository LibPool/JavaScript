# @game-hub/game-euchre

> 标签: JavaScript

## 简介

Euchre for Game Hub — the classic 24-card partnership trick-taking game with bowers, two rounds of bidding on the upcard, and going alone. Four subpath exports: ./engine (pure rules), ./module (backend GameModule seam), ./client (UI GameClient seam), ./bo
