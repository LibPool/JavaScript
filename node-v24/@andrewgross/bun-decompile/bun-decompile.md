# @andrewgross/bun-decompile

> 标签: bun, decompile, elf, extract, macho, pe, reverse-engineering, single-file-executable, unbundle

## 简介

Extracts the original transpiled sources from an executable file generated via `bun build --compile`. Supports Bun v0.6.0 through v1.4.x on macOS, Linux, and Windows.
