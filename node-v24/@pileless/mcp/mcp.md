# @pileless/mcp

> 标签: agent, approval, claude, cline, cursor, human-in-the-loop, mcp, model-context-protocol, pileless, review

## 简介

MCP stdio server for Pileless. Wraps the Pileless REST API in MCP tool calls so Claude Code, Cursor, Cline, etc. can submit Piles natively.
