# @keazon/tore-js

> 标签: ai, architecture, ast, cli, code-quality, jsx, lint, react, ts-morph, typescript

## 简介

Töre JS — AST-based architectural guardian for TypeScript/React: team-level rules that complement ESLint (design system boundaries, risky patterns from AI-assisted edits). CLI: tore check, tore init.
