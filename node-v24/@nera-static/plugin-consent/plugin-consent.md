# @nera-static/plugin-consent

> 标签: consent, cookie-banner, dsgvo, gdpr, nera, nera-plugin, privacy, static-site-generator

## 简介

A plugin for Nera static site generator that adds a consent banner and settings dialog, and keeps scripts and embeds inert until the visitor agrees, all from config/consent.yaml.
