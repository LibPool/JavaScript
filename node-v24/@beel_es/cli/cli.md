# @beel_es/cli

> 标签: api, beel, cli, invoicing, openapi, verifactu

## 简介

Agent-first CLI for the BeeL invoicing API. Commands are derived at startup from the embedded OpenAPI spec. Run with npx @beel_es/cli — no install needed.
