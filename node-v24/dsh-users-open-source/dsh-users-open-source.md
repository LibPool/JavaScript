# dsh-users-open-source

> 标签: bandwidth, deepseek-harness, dsh, dsh-plugin, loopback, network, open-folder, speedtest, workspace

## 简介

DeepSeek Harness 插件「开源用户」：本机带宽测速 —— 只在本机 127.0.0.1 回环上跑流量，不连任何外部服务器、不消耗 token；设置页提供测速器与自动上传，「云端备份」按钮打开本地工作区目录，左侧栏实时显示当前带宽。
