# @haztap/cli

> 标签: cli, haztap, storefront, truocloud, woocommerce

## 简介

CLI `haztap` del operador técnico de Haztap: sesión con passkey, workspace de la tienda, contenido (pull/push), código (dev/deploy) y estado, contra la Consola Haztap. Node ESM puro, sin dependencias.
