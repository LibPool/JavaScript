# dsh-compat-layer

> 标签: JavaScript

## 简介

Compatibility layer for DeepSeek Harness plugin session events: registers plugin-owned event types into the live vocabulary (the removed registerSessionEventType replacement, with mandatory omission classification), normalizes historical spellings, shares
