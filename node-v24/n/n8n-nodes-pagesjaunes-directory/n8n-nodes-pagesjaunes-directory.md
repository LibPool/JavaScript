# n8n-nodes-pagesjaunes-directory

> 标签: apify, n8n, n8n-community-node-package, n8n-nodes, scraping

## 简介

Scrape PagesJaunes (French Yellow Pages) by city + category. Returns business name, phone, email (website-enriched), website, full address, GPS, SIRET/SIREN, rating, opening hours + a data-quality score. The richest French B2B lead dataset on the Store. P
