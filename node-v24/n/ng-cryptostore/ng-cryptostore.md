# ng-cryptostore

> 标签: crypt, crypto-store, cryptostore, localstore, ng-crypto-store, ng-cryptostore, security, sessionstore, store

## 简介

This library was updated to [Angular CLI](https://github.com/angular/angular-cli) version 21.0.0. to store data (string, object or array of objects) in local stores or the session store with crypto-js package
