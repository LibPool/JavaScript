# narko-klient

> 标签: ai-agent, nrk, nrk-tv, playlist, psapi, streaming, tv, typescript

## 简介

Typed client for NRK TV (psapi.nrk.no) with small, validated results for AI agents that build playlists. Never throws, no dependencies.
