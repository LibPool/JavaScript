# node-red-contrib-modbus-poller

> 标签: iiot, modbus, modbus-tcp, node-red, plc, poller, registers, scada

## 简介

A Node-RED node that polls Modbus TCP devices using a user-editable, importable register table (JSON/CSV) with per-register scaling, data types, and request chunking.
