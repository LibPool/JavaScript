# ninka-authz

> 标签: abac, access-control, agent, ai, authorization, authorization-compiler, authz, compiler, deterministic, llm, opa, open-policy-agent, policy, rbac, rego, tegata, wasm

## 简介

The Authorization Compiler for AI-Driven Engineering — compiles declarative authorization policy (Tegata) into deterministic Rego/WASM. AI writes the policy, humans review it, the compiler guarantees the output.
