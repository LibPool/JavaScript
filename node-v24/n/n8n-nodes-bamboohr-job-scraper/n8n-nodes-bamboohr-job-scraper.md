# n8n-nodes-bamboohr-job-scraper

> 标签: apify, n8n, n8n-community-node-package, n8n-nodes, scraping

## 简介

Scrape job postings from any BambooHR-powered company careers page via the public JSON API. Get title, department, location, seniority, remote-type, compensation, descriptions and parse_confidence. Multi-company batch, keyword filters, zero auth, zero pro
