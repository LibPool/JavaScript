# n8n-nodes-pdf-local

> 标签: decrypt, local, n8n, n8n-community-node-package, offline, password, pdf, unlock

## 简介

Work with PDF files inside n8n on your own machine. No external API, no file leaves the host. Currently: unlock password-protected PDFs.
