# node-voronoi-map

> 标签: browser, delaunay, engine, game, generator, geometry, map, voronoi

## 简介

JavaScript port of Amit Patel's mapgen2 https://github.com/amitp/mapgen2 Map generator for games. Generates island maps with a focus on mountains, rivers, coastlines in nodejs.
