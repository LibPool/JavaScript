> 标签: clinical, ehr, electronic-health-records, epic, fhir, health-it, healthcare, hipaa, hl7, interoperability, medical, n8n, n8n-community-node-package, patient, smart-on-fhir

## 简介

A comprehensive n8n community node for Epic FHIR R4 API providing 12 healthcare resources and 40+ operations for patient records, clinical observations, medications, appointments, and healthcare automation.
