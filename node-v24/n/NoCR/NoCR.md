# NoCR

> 标签: cms, dms, documents, generator, javascript, website

## 简介

NoCR (like JCR) is content repository API, unlike JCR it's written in CoffeeScript+Node.js instead of Java, and also allows to implement a content repository in javascript or coffee. It helps you to write a good implementation as it provides a full featured test suite.
