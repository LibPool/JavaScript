# n8n-nodes-vocce

> 标签: n8n, n8n-community-node-package, speech-to-text, subtitles, transcription, vocce, whisper

## 简介

n8n community node to transcribe audio/video to text + SRT/VTT via vocce's hosted Whisper. No API key.

## 官网

- 官网：https://vocce.io
- 源码仓库：git+https://github.com/cmoonagent/vocce-agent.git
- npm 页面：https://www.npmjs.com/package/n8n-nodes-vocce
