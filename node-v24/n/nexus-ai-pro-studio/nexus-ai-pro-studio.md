# nexus-ai-pro-studio

> 标签: agents, audit-log, context-engineering, evaluation, human-in-the-loop, issue-detection, llm, llmops, nexus-ai-pro, observability, prompt-management, rbac, self-hosted, studio, team, tracing

## 简介

A studio for nexus-ai-pro: traces, threads, approvals, experiments, prompts, context bundles, issues, and proposed fixes, run locally or shared by a team with roles and an audit log, with no hosted service.
