# number-counter-animation

> 标签: animation, count-up, counter, digit-animation, effects, es6, intersection-observer, javascript, number, scroll, ui

## 简介

一个轻量级的数字滚动动画插件，当页面滚动到元素位置时，数字从0平滑滚动到目标值
