# node-hag

> 标签: Asset, CSS, Generator, HTML, Image, JS, Node, Template, Webshot

## 简介

Node HTML Asset Generator (HAG) - converts HTML and CSS templates into rendered Image assets, and can also produce Text and JSON assets.
