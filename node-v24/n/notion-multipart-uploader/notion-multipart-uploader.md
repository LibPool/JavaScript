# notion-multipart-uploader

> 标签: agent-optimized, audio, direct-upload, file_uploads, form-data, image, llm-friendly, multipart, notion, notion-api, notion-sdk, pdf, upload, zero-dependency

## 简介

Native zero-dependency multipart file uploader for Notion API. Direct upload any media type (videos, phone gallery images, audio, PDFs, and binary blobs) to Notion without external hosting.
