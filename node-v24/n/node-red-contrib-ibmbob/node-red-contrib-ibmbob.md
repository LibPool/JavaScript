# node-red-contrib-ibmbob

> 标签: agent, ai, assistant, bob, bobshell, ibm, llm, node-red

## 简介

Node-RED node to call IBM Bob Shell (bob) in headless mode and return the answer plus usage stats (cost / duration / tool calls).
