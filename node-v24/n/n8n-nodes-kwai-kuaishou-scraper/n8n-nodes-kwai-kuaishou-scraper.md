# n8n-nodes-kwai-kuaishou-scraper

> 标签: apify, n8n, n8n-community-node-package, n8n-nodes, scraping

## 简介

Search kuaishou.com (Kwai) for short videos by keyword and extract engagement data: views, likes, shares, comments, forwards, duration, captions, and creator info. CN-residential proxy, no login required.
