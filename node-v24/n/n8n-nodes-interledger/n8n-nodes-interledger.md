# n8n-nodes-interledger

> 标签: blockchain, cross-currency, fintech, ilp, interledger, n8n, n8n-community-node-package, open-payments, payment-pointer, payments, rafiki, spsp, stream-protocol, web-monetization

## 简介

A comprehensive n8n community node for Interledger Protocol providing 21 resources and 150+ operations for payments, STREAM protocol, Open Payments, SPSP, connectors, and Web Monetization. Includes Rafiki integration and cross-currency payment support.
