# nosheet

> 标签: aggregate, computation, dataframe, expression, spreadsheet, table, tabular, typescript

## 简介

Apply named, fully-typed row expressions and aggregates to tabular data. Expressions are plain arrow functions — no string formulas, no parsing, no eval.
