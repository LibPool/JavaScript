# nomo-ai

> 标签: claude-code, codex, dynamic-island, installer, ios, live-activity, opencode

## 简介

One-command installer for the Nomo plugin — mirror Claude Code, OpenAI Codex and OpenCode sessions to the Nomo iPhone app as an end-to-end-encrypted Live Activity.
