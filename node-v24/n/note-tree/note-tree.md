# note-tree

> 标签: agents-md, claude, claude-code, codex, context, cursor, kiro, mcp, memory, opencode, plugin, tokens

## 简介

Token-lean shared memory for coding agents. Saves only what matters, as leaves on a tree that grows with your project. Works with Claude Code, Codex, opencode, Kiro, Cursor, Gemini CLI and anything that reads AGENTS.md.
