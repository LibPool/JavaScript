# ngbmin

> 标签: angular, array, browserify, dependency, function, injection, ngmin, transform

## 简介

Simple AngularJS pre-minifier. Transforms all functions that end with $ng from function-injection to array injection syntax

- 源码仓库：git://github.com/spion/ngbrowserify.git
