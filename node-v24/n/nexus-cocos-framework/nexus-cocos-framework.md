# nexus-cocos-framework

> 标签: cocos-creator, game-engine, game-framework, nx-framework

## 简介

本框架采用模块化、分层设计理念，旨在提供一个高效、灵活、可扩展的Cocos Creator 3.8.7游戏开发基础架构。主要包括事件管理、网络管理、对象池、资源管理、工具类和视图管理等核心模块。
