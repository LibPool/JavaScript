# n8n-nodes-sirdas

> 标签: anonymization, document-parsing, invoice, local-first, n8n-community-node-package, ocr, pdf

## 简介

n8n node for Sırdaş: read PDFs, scans, Word, Excel, PowerPoint and email into cited fields, tables and Markdown; split batches; read forms; protect and unlock PDFs. Runs inside your n8n, nothing is uploaded.
