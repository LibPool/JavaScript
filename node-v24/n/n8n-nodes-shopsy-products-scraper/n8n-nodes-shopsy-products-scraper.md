# n8n-nodes-shopsy-products-scraper

> 标签: apify, n8n, n8n-community-node-package, n8n-nodes, scraping

## 简介

Scrape Shopsy.in (Flipkart's value marketplace) search results. Returns title, brand, price, MRP, discount, rating, reviews, key specs, availability, URL and image. Pay per product.
