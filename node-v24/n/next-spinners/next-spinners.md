# next-spinners

> 标签: loading, next, nextjs, react, registry, shadcn, spinner, ui

## 简介

React & Next.js Braille/Unicode frame spinners, no CSS. shadcn registry. Optional next-spinners/loading-ui (Tailwind, Motion).
