# nd-easing

> 标签: JavaScript

## 简介

Easing 是动画的平滑函数扩展包。由于 jQuery 自带的比较少，通过这个包可以增加更多平滑函数。

## 官网

- 官网：https://github.com/ndfront/nd-easing
- 源码仓库：git+https://github.com/ndfront/nd-easing.git
- npm 页面：https://www.npmjs.com/package/nd-easing
