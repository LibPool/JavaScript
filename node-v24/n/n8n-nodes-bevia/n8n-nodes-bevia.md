# n8n-nodes-bevia

> 标签: ai-agent, bevia, coordination, map, n8n-community-node-package, polling, territories

## 简介

Bevia community node — read the map of your thinking (territories, changes, landmarks, daily pulse), query it, export it, poll for map-change events, send content in, and file observations. A coordination wire for a person or an AI agent. Targets n8n.
