# notary-public

> 标签: attestation, busl, deployment-identity, ed25519, interchained, license, license-list, licensing, notary, offline-license, registration, spdx

## 简介

The licensing notary: distribute any SPDX license, notarize a project's LICENSE against the canonical text, and gate your own packages with offline signed registration. Deployment identity + license attestation.
