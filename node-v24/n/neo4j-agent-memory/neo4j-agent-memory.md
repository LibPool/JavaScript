# neo4j-agent-memory

> 标签: JavaScript

## 简介

A Neo4j-backed memory system for AI agents: - semantic / procedural / episodic memories - case-based reasoning (symptoms -> similar cases -> fixes) - negative memories ("do not do") - environment fingerprints for precision - hybrid retrieval returning a C
