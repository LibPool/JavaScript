# nebula-token

> 标签: authentication, nebula, oauth2, refresh-token, rfc9700, security, token-rotation

## 简介

Opaque rotating refresh tokens (RFC 9700 model): rotation, reuse detection, family revocation, sender binding. Zero dependencies.
