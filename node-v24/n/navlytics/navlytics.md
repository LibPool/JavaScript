# navlytics

> 标签: A/B, Accessibility, Analysis, Analytics, Behavior, Bot, Click, Detection, Flow, Frontend, Heatmaps, Insights, Interaction, Monitoring, Mouse, Movement, Navigation, Optimization, Session, Testing, Tracking, UX, User, Web

## 简介

Navlytics is a framework for analyzing user behavior on websites. It provides heatmaps, click statistics, and accessibility analysis to optimize the user experience.
