# npm-pages

> 标签: JavaScript

## 简介

- 集合了三个组件，包括`page-search`、`page-table`、`pagination`; - `config` 所需参数包含这三个组件内参数；（在同级下，并非包含数据） - `page-search`中；配置`searchInit`后默认有响应事件会执行查询，`notQuery=true`关闭。 - 分页组件`pagination`事件默认响应`config.query()`方法，刷新表格数据
