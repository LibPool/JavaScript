# nestjs-dynamodb-orm

> 标签: aws, decorator, dynamodb, gsi, lsi, nestjs, orm, repository, typescript

## 简介

Decorator-based DynamoDB ORM for NestJS with typed errors, lifecycle hooks, composite search keys, and GSI/LSI support.
