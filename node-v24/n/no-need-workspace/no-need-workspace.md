# no-need-workspace

> 标签: deepseek-harness, dsh, dsh-plugin, no-need-workspace, workspace

## 简介

A DeepSeek Harness bundle that adds a 'No workspace' action: the first message creates a dated folder and the sessions stay grouped under one parent.
