# noa-mcp-adapter-core

> 标签: ai-agent, governance, hash-chain, mcp, policy, provenance, receipt

## 简介

Shared, testable MCP pre-flight decision engine — extracted from examples/mcp-preflight/preflight.mjs so any MCP integration (proxy, gateway, in-process guard) can call the same preCheck() instead of re-deriving it.
