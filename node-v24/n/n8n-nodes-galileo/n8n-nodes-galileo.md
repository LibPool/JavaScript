# n8n-nodes-galileo

> 标签: ach, apple-pay, baas, banking, banking-as-a-service, card-issuing, digital-wallet, fintech, fraud-prevention, galileo, google-pay, kyc, n8n, n8n-community-node-package, payments

## 简介

A comprehensive n8n community node for Galileo Financial Technologies providing 24 resources and 200+ operations for card issuing, account management, ACH transfers, digital wallets, and BaaS functionality. Includes sandbox testing support.
