# nazbu

> 标签: cdc, crdt, database, lan, local-first, mariadb, mdns, mongodb, mysql, no-server, offline-first, p2p, peer-to-peer, postgres, postgresql, sync, sync-engine, typescript

## 简介

Local-first sync engine — keep your existing database (PostgreSQL, MySQL, MongoDB) running offline and in sync across every device, peer-to-peer, with no server. Fully typed.
