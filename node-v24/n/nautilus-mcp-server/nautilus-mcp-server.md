# nautilus-mcp-server

> 标签: claude, cursor, mcp, model-context-protocol, mongodb, mysql, postgresql, redis

## 简介

Servidor MCP (stdio) para PostgreSQL, MySQL, MongoDB e Redis com SQL somente leitura (SELECT/WITH).
