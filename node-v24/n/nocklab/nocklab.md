# nocklab

> 标签: cli, fixtures, invariants, lab, launch-evidence, nockapp, nockchain

## 简介

NockApp Lab — fixture-driven test runner for NockApp launch evidence: validate fixtures, evaluate invariants, and emit JSON/Markdown reports. Standalone CLI + TypeScript fixture-authoring types.
