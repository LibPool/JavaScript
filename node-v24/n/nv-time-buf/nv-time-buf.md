# nv-time-buf

> 标签: JavaScript

## 简介

nv-time-buf ======================= - a 16-byte buffer for test date-transfer with nvlang,  - the first-8-byte is a nan-tag (0xfff4)  - nvlang has 4 date-type:    -    0x7ffa,0x7ffb,0x7ffc ARE 8-byte inline-date but NOT compatible with JS.    -    0xfff4
