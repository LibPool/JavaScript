# n8n-nodes-sendbeam

> 标签: email, email-marketing, n8n, n8n-community-node-package, newsletter, sendbeam, transactional-email

## 简介

Use SendBeam from n8n: create and update contacts, manage lists and tags, send email, and trigger workflows from SendBeam events.
