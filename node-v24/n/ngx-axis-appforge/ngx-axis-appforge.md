# ngx-axis-appforge

> 标签: JavaScript

## 简介

基于 Angular 20 和 Ant Design 开发的 JSON 驱动动态页面生成库，完整覆盖 Ant Design 组件，并提供低代码配置组件的设计工具（本身也是动态组件之一）。本库旨在帮助开发者快速构建复杂的管理界面，通过可视化配置即可实现组件布局和属性设置。
