# ngx-sparkout-chatbot

> 标签: Angular, React, chat, chat plugin, chatbot, openai, plugin, widget

## 简介

This package provides a user interface (UI) for a chat widget that deals with organization data. It implies that users can interact with the chat widget to communicate and access specific information related to an organization.
