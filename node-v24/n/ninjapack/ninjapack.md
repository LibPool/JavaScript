# ninjapack

> 标签: assets, cli, components, design, download, export, figma, figma-api, png, ui

## 简介

A powerful command-line tool for extracting design assets from Figma files. NinjaPack allows you to quickly download UI components and assets from specific sections in your Figma designs.
