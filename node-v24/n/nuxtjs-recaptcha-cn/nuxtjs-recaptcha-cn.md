# nuxtjs-recaptcha-cn

> 标签: captcha, china, grecaptcha, nuxt, nuxtjs, recaptcha

## 简介

Simple and easy Google reCAPTCHA integration with Nuxt.js,based on @nuxtjs/recaptcha 0.6.1 and change the URL to www.recaptcha.net in order to use in China

## 官网

- 官网：https://github.com/nuxt-community/recaptcha-module#readme
- 源码仓库：git+https://github.com/nuxt-community/recaptcha-module.git
- npm 页面：https://www.npmjs.com/package/nuxtjs-recaptcha-cn
