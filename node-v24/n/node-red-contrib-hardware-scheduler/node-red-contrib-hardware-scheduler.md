# node-red-contrib-hardware-scheduler

> 标签: access-control, concurrency, gpio, hardware, i2c, lock, mutex, node-red, queue, resource, scheduler, serial

## 简介

A Node-RED node package providing a global hardware access scheduler to serialize concurrent access to shared hardware resources (serial ports, GPIO, I2C buses, etc.)
