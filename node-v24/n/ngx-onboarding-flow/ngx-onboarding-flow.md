# ngx-onboarding-flow

> 标签: angular, driver.js, event-driven, guided-tour, onboarding, product-tour, signals, tour, user-onboarding, walkthrough

## 简介

Config-driven, event-driven onboarding & product-tour engine for Angular. Define the whole tour in one typed object; the engine coordinates async transitions (business events, routing, DOM) and paints the overlay with Driver.js.
