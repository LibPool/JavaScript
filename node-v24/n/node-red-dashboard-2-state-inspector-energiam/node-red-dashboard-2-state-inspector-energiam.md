# node-red-dashboard-2-state-inspector-energiam

> 标签: context, dashboard, debug, energiam, iiot, inspector, monitoring, node-red, node-red-dashboard, node-red-dashboard-2, state, state-machine, table, widget

## 简介

Native Dashboard 2.0 widget for Node-RED — capture variable snapshots at different machine states and compare them side-by-side in a live table. Data-source agnostic, designed for IIoT state machine debugging.
