# n8n-nodes-llm-guard

> 标签: ajv, json-schema, llm, n8n-community-node-package, structured-output, validation

## 简介

LLM output guard for n8n: LLM-aware JSON extraction + real ajv JSON Schema validation + a repair-loop contract (Valid / Repair / Failed outputs) for HTTP-based LLM workflows. Never throws; every repair attempt is visible in the execution log.
