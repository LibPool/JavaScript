# n8n-nodes-metrecept

> 标签: n8n-community-node-package

## 简介

Metrecept for n8n: point any AI Agent / Chat Model workflow at a metered, caching LLM gateway that returns a signed, independently verifiable Ed25519 receipt on every cache hit, plus standalone receipt verification and a live usage/spend operation.
