# n8n-nodes-gsa-per-diem

> 标签: federal, government, gsa, lodging, n8n, n8n-community-node-package, per-diem, travel

## 简介

n8n community node for the GSA Per Diem Rates API. Look up federal per diem reimbursement rates for lodging and meals by city, state, or ZIP code.
