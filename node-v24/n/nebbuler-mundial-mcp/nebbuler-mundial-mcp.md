# nebbuler-mundial-mcp

> 标签: anthropic, claude, cursor, fifa, latam, mcp, model-context-protocol, mundial, nebbuler, soccer, windsurf, world-cup

## 简介

MCP (Model Context Protocol) server for Nebbuler Mundial 2026 open data. Gives Claude, Cursor, Windsurf and other AI agents native tools to query World Cup data, calculate creator earnings, and find LATAM sports creators.
