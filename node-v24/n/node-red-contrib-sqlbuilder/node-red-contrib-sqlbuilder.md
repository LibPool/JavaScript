# node-red-contrib-sqlbuilder

> 标签: knex, node-red, query-builder, sql

## 简介

A "batteries included" SQL query builder for CockroachDB, MariaDB, MSSQL, MySQL, PostgreSQL, SQLite3, Oracle DB, and Amazon Redshift
