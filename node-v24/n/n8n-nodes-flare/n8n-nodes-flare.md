# n8n-nodes-flare

> 标签: blockchain, cryptocurrency, defi, fassets, flare, ftso, n8n, n8n-community-node-package, oracle, songbird, state-connector, web3

## 简介

n8n community node for Flare Network blockchain. Supports FTSO price feeds, delegation, rewards claiming, State Connector attestations, FAssets, and DeFi operations across Flare, Songbird, and testnets.
