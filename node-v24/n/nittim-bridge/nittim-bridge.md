# nittim-bridge

> 标签: ai-agent, claude, code-audit, mcp, model-context-protocol, nittim, security-audit

## 简介

Local stdio MCP bridge that walks a repo on disk and posts it to nittim.com for a source audit, so an AI assistant never sees the source bytes or the API key.
