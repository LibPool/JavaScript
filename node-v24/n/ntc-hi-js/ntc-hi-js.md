# ntc-hi-js

> 标签: cmyk, color, hex, hsl, hue, i18n, lch, name, ntc, ntc.js, rgb, shade, that

## 简介

Convert hexadecimal, RGB, HSL, LCH or CMYK color to a name and a shade with i18n support.
