# node-red-contrib-telstra-messaging-api

> 标签: node-red, telstra, sms

## 简介

A Node-RED node for Telstra Messaging API - Currently supporting only sending SMS Messages. Requires pre provisioning done. Check API on https://dev.telstra.com
