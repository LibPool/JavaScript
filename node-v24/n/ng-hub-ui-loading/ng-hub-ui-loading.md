# ng-hub-ui-loading

> 标签: angular, loader, loading, ng-hub-ui, nprogress, overlay, progress-bar, spinner, standalone

## 简介

Customizable loading indicators for Angular: inline block, container overlay or fullscreen, plus a page-level progress bar for the navbar, with CSS-only variants, branding image and programmatic services. Part of the ng-hub-ui family.
