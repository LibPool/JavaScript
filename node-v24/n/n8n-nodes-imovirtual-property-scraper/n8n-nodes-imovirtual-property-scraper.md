# n8n-nodes-imovirtual-property-scraper

> 标签: apify, n8n, n8n-community-node-package, n8n-nodes, scraping

## 简介

Scrape property listings from Imovirtual.com — Portugal's leading real estate portal covering Lisbon, Porto, Faro and every district. Returns price, area, rooms, location, agency and 40+ fields per listing. Pay per property delivered.
