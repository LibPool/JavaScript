# neuralos-engine-windows-x64

> 标签: embeddings, needle, neuralos, offline, on-device, tool-calling, win32-x64

## 简介

neuralOS engine (libneedle3) and base weights (needle3.cact) for win32-x64 — the platform payload for the neuralos package. Install neuralos instead of this package directly.
