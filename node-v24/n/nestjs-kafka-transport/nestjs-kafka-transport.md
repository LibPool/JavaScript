# nestjs-kafka-transport

> 标签: event-driven, kafka, kafkajs, message-broker, microservices, nest, nestjs, platformatic, transport

## 简介

Production-grade Kafka transport for NestJS microservices built on @platformatic/kafka: drop-in replacement for the built-in kafkajs transport with request-reply, retries, dead-letter topics and batches.
