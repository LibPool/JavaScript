# ngx-bulk-uploader

> 标签: angular, bulk-upload, data-grid, excel, grid, handsontable, validation

## 简介

Schema-driven bulk Excel upload grid for Angular, built on Handsontable — define a module as a schema, get validation, dependent dropdowns, multi-select, Excel import/export and DB-uniqueness checks for free.
