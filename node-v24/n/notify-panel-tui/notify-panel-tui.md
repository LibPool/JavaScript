# notify-panel-tui

> 标签: agent, ai-agent, claude, codex, event-driven, notification, notify-panel, pty, tui

## 简介

notify-panel 的 TUI 消费端:把任意交互式 TUI agent(claude/codex/gemini-cli/…)起在 PTY 里,未读通知自动当作"用户敲的字"注入,让 agent 被外部事件唤醒
