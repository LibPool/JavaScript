# nexlide

> 标签: animation, carousel, framer-motion, image-carousel, nexlide, nextjs, react, react-carousel, react-component, react-slider, react-ui, slider, tailwindcss, ui-component

## 简介

Nexlide is a modern, lightweight, and fully customizable React carousel component built with Framer Motion for smooth animations and Tailwind CSS for flexible styling.
