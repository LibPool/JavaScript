# nvidia-glm-proxy

> 标签: glm, mcp, nim, nvidia, openai-compatible, proxy, streaming, tool-calls

## 简介

Proxy for NVIDIA NIM API that fixes GLM-5.1 tool_call streaming bugs (numeric IDs, missing function.name, ID instability)
