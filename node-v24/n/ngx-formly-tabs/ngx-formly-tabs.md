# ngx-formly-tabs

> 标签: angular, angular forms, form library, formly, forms, json forms, ng-formly, ngx-formly, tabs

## 简介

ngx-formly-tabs is an Angular module that adds Components that enable flexible tab use for @ngx-formly.
