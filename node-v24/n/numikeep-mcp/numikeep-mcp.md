# numikeep-mcp

> 标签: coins, mcp, model-context-protocol, numikeep, numismatics

## 简介

MCP server that lets an AI agent add coins to a Numikeep collection, using a connection key the owner created.

## 官网

- 官网：https://numikeep.com/developers/
- npm 页面：https://www.npmjs.com/package/numikeep-mcp
