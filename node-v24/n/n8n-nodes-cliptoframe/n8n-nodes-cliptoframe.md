# n8n-nodes-cliptoframe

> 标签: automation, cliptoframe, ffmpeg, frame-extraction, n8n, n8n-community-node-package, screenshot, thumbnail, video

## 简介

n8n community node for ClipToFrame — extract still frames and metadata from video URLs via a hosted API (no FFmpeg needed, works on n8n Cloud)
