# node-red-contrib-fanuc-focas

> 标签: cnc, fanuc, focas, focas2, iot, node-red

## 简介

Node-RED node for FANUC CNC data collection via FOCAS2 protocol (pure Node.js, no native libraries, adapted from pyfanuc)
