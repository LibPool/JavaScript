# node-red-contrib-simple-thermostat

> 标签: node-red, thermostat

## 简介

A node that compares msg.payload to a target value and returns a new msg.payload such as 'off' or 'on'.  Supports the result of InfluxDB queries such as `SELECT MEAN(value) FROM "My meaurement" WHERE time > now() - 2m`
