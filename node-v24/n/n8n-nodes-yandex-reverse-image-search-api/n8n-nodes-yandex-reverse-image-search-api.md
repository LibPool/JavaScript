# n8n-nodes-yandex-reverse-image-search-api

> 标签: ai-tool, apify, find-image-source, image-search, n8n, n8n-community-node-package, n8n-nodes, reverse-image-search, similar-images, visual-search, yandex

## 简介

Reverse image search on Yandex: find matching pages, similar images, other sizes, tags, shopping matches, and knowledge graph entries. Apify-backed n8n community node, pay-per-result, and usable as an AI agent tool.
