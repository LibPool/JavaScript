# node-prof-cli

> 标签: cpu-profile, devtools-protocol, diagnostics, heap-snapshot, inspector, memory-leak, nodejs, pm2, profiling, ssh

## 简介

Heap snapshots, CPU profiles, and allocation sampling of running Node.js processes, locally or over ssh, streamed to your machine. Includes a preparation guide and local summarize/diff analysis.
