# n8n-nodes-nukeapi

> 标签: gdpr, n8n, n8n-community-node, nukeapi, user-deletion

## 简介

n8n community node for NukeAPI — GDPR/CCPA/LGPD user-deletion API. Delete a user across 78+ SaaS tools with one call and get a signed audit trail.
