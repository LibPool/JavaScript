# noder.go

> 标签: node, noder, noder go, noder.go, noder.go npm, pool, typescript, workers

## 简介

Effortlessly execute CPU-intensive tasks in parallel with worker threads.   **noder** simplifies concurrency in Node.js by providing support for creating individual workers and worker pools with easy-to-use syntax.
