# ng2-timeline-simple

> 标签: angular, angular2, events, milestone, ng2, timeline, tracker

## 简介

An angular js library that automatically generates timeline with callback function to handle click events. Forked from ng2-timeline, by mohdrashid/ng2-timeline.
