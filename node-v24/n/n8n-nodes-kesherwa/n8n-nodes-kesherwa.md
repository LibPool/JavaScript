# n8n-nodes-kesherwa

> 标签: automation, chatbot, customer support, kesherwa, messaging, n8n-community-node-package, notifications, webhook, whatsapp, whatsapp api, whatsapp business api, whatsapp rest api

## 简介

Send and receive WhatsApp messages via KesherWA REST API. Supports text, images, videos, audio, documents, locations, and reactions with automatic media decryption.
