> 标签: 2fa, n8n, n8n-community-node-package, otp, phone-verification, sim-card, sms, telegram, verification, virtual-number, virtualsms, whatsapp

## 简介

n8n community node for VirtualSMS — real-SIM SMS verification across 145+ countries and 2,500+ services. Buy numbers, receive OTP codes via webhook or polling, manage rentals.
