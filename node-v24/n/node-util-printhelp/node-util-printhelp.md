# node-util-printhelp

> 标签: arguments, cli, generator, help, node, node-util, node:util, options, parse, parseArgs, print, printer, util, util.parseArgs, utilities, utils

## 简介

Utility to generate and print CLI help text from a Node.js `util.parseArgs` configuration, designed minimally to resemble a potential future Node.js built-in.
