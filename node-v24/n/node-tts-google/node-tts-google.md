# node-tts-google

> 标签: JavaScript

## 简介

A node library to use googles text to speech translation to play audio to the speaker directly.

- 源码仓库：https://github.com/nothingmn/node-tts-google.git
- npm 页面：https://www.npmjs.com/package/node-tts-google
