> 标签: boilerplate, cli, cli-tool, code-generator, component, component-cli, component-generator, component-scaffolding, create-component, create-react-component, create-react-component-cli, create-react-component-tool, frontend, generator, javascript, jsx, node-cli, npm, react, react-cli, react-component, react-component-boilerplate, react-component-cli-tool, react-component-creator, react-component-setup, react-component-template, react-typescript, reactjs, tsx, typescript

## 简介

A powerful CLI tool to generate React component files with CSS templates. Supports both JSX and TSX formats. Simplifies component creation for modern React projects.
