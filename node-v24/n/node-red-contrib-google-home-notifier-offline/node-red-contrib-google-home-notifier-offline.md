# node-red-contrib-google-home-notifier-offline

> 标签: google, google-home, internet of things, iot, node-red, offline, text to speech, tts, voice

## 简介

Node-Red nodes for google-home-notifier-offline library. With this node you can cast any String (up to 200 chars) to any google cast device.
