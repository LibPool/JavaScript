# neurostack

> 标签: ai, cli, fts5, knowledge-base, knowledge-graph, knowledge-management, local-first, mcp, obsidian, rag, retrieval-augmented-generation, semantic-search, sqlite

## 简介

Local retrieval layer and optimizer for your Markdown knowledge base. CLI + MCP server: ranked evidence for any AI client, stale-note detection, session harvesting.
