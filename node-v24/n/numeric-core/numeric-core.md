# numeric-core

> 标签: a1z26, arithmetic, blue-prince, blueprince, cipher, game, numeric-core, operators, puzzle, roman-numerals, solver

## 简介

Unofficial solver for the numeric core puzzle in Blue Prince. Finds the numeric core of four numbers: the smallest whole number you can make by combining them with +, -, *, and /, worked out left to right.
