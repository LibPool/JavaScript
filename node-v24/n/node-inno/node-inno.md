# node-inno

> 标签: builder, electron, exe, inno, nwjs, packager

## 简介

一个基于innosetup的 nodejs自动化打包工具，通过json配置，可灵活定制安装界面和安装流程，为nwjs、electron或者其他应用进行exe的打包。
