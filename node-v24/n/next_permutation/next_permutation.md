# next_permutation

> 标签: javascript, js, next_permutation, permutation

## 简介

`next_permutation`是一个全排列功能的函数，可以接收一个字符串s和数字n，可以返回s在全排列中的n步后的字符串（如果已到最后一个排列，则返回最后一个）
