# n8n-nodes-jianying

> 标签: n8n-community-node-package

## 简介

n8n 工作流自动化平台的扩展节点，用于集成剪映(抖音剪辑工具)的视频编辑功能，支持视频剪辑、特效添加、关键帧、导出等自动化操作
