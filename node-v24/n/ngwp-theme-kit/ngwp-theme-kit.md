# ngwp-theme-kit

> 标签: angular, github, repos, repositories, theme, typescript, wordpress

## 简介

NgWP Theme Kit is an Angular library that enables the creation of WordPress themes using Angular. It follows the principle of headless cms, using the WordPress REST APIs.
