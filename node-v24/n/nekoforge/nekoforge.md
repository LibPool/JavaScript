# nekoforge

> 标签: ai, claude, cli, code-review, codegen, codex, cursor, developer-tools, harness

## 简介

NEKOFORGE — source-aware local AI development harness: turns existing codebases into reusable context and task packets, and gates AI changes behind a tamper-evident verdict before explicit apply.
