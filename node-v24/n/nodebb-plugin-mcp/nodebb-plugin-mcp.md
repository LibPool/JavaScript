# nodebb-plugin-mcp

> 标签: agents, ai, antigravity, claude, cursor, llm, mcp, model-context-protocol, nodebb, nodebb-plugin, sse

## 简介

Model Context Protocol (MCP) server plugin for NodeBB. Expose forum search, discussions, categories, and moderation to AI agents via standard MCP protocol.
