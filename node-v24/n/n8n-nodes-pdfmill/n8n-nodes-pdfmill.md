# n8n-nodes-pdfmill

> 标签: document, generate-pdf, html-to-pdf, invoice, n8n, n8n-community-node-package, pdf, pdfmill

## 简介

n8n community node to generate branded PDF and PNG documents from a template or raw HTML via pdfmill — workflow data in, finished document out. No Chrome to host.
