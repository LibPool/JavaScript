# ngx-message-error

> 标签: angular, error, message, ng, ng2, ngx, ngx-erro, ngx-error, ngx-message, ngx-message-erro, ngx-message-error

## 简介

The component's purpose is to encapsulate the message display logic for form validations made with `ReactiveForms`.
