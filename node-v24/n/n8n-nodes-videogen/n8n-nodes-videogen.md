# n8n-nodes-videogen

> 标签: ai, n8n, n8n-community-node-package, video, videogen

## 简介

n8n community node for VideoGen. Start script, voiceover, slideshow, and prompt-to-video workflows. Node definition is generated from the VideoGen developer API OpenAPI spec.
