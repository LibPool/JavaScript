# nuxt-ui-basekit

> 标签: charts, components, data-table, nuxt, nuxt-layer, nuxt-ui, vue

## 简介

Markenfreie Basis-Komponenten für Nuxt 4 auf Nuxt UI — Tabellen, Reiter, Diagramme, Auswahl und Leerzustände als Nuxt-Layer.
