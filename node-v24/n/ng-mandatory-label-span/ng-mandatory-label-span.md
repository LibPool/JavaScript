# ng-mandatory-label-span

> 标签: angular, angular-cli, asterisk, codemod, developer-tool, form-validation, forms, label-span, mandatory, mandatory-label, reactive-forms, template-transformer

## 简介

Zero-dependency Angular CLI tool and library to automatically inject reactive form mandatory asterisk spans into labels across Angular 8 to 19+ component templates.
