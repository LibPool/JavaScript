# nexusmem

> 标签: agent, ai, context, exit-codes, local-first, mcp, memory, shell-history, sqlite

## 简介

Local-first persistent memory for AI coding agents. Indexes git history, shell commands with exit codes, project docs and (opt-in) assistant transcripts into an embedded SQLite database, then serves back a ranked, token-budgeted context slice over MCP or
