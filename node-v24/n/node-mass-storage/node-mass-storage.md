# node-mass-storage

> 标签: SCSI, mass storage, webusb

## 简介

A library that lets you work with USB mass storage devices connected via WebUSB. PLEASE DO NOT USE THIS UNLESS YOU KNOW WHAT YOU'RE DOING!!!
