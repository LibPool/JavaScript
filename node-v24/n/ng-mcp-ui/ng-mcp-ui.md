# ng-mcp-ui

> 标签: ai, angular, angular-schematics, apps-sdk, chatgpt, chatgpt-apps, claude, mcp, mcp-apps, mcp-ui, model-context-protocol, ng-add, openai, schematics, ssr, widgets

## 简介

Add an MCP server to your Angular app with one ng add. Its tools show interactive Angular widgets in Claude and ChatGPT.
