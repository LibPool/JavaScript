# noesis-mcp-connect

> 标签: assessment, mcp, model-context-protocol, noesis, personality, proxy, psychometrics, seges, stdio

## 简介

Local stdio MCP bridge to Noesis's Psychometric Scoring MCP server (https://noesis.seges.ai/mcp) -- for MCP clients that only support locally-spawned stdio servers, not remote HTTP.

## 官网

- 官网：https://noesis.seges.ai
- npm 页面：https://www.npmjs.com/package/noesis-mcp-connect

## 历史版本号

- 1.1.1

## 获取地址

- npm 安装：`npm install noesis-mcp-connect`
- npm registry：https://registry.npmjs.org/noesis-mcp-connect
- Node 要求：>=18
