# native-bucket

> 标签: binary, browser, cache, cloudflare, indexeddb, r2, workers

## 简介

native-bucket — a bridge between Cloudflare R2/Workers and browser IndexedDB for heavy binary datasets (GIS archives, ZIP, large assets): proxied Fetch with progress, R2 bucket listing/upload, persistent Cache. Browser-only. MIT.
