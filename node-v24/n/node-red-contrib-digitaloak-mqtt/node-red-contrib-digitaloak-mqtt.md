# node-red-contrib-digitaloak-mqtt

> 标签: dynamic mqtt, mqtt, mqtt dynamic subscribe, mqtt dynamic unsubscribe, node-red

## 简介

Based on core mqtt-in node, using core mqtt-broker config node. Additional features: dynamic topic subscription, unsubscribe after first msg recv option, dynamically unsubscribe specific node from specific topic, pass msgs through node.
