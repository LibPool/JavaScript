# n8n-nodes-cdp-browser

> 标签: browser-automation, cdp, chromium, n8n-community-node-package, playwright, puppeteer

## 简介

n8n community node for a self-hosted Remote Chromium CDP Automation REST API - full tab, JS, input, form, capture, cookie, storage, network, download, geolocation, emulation, dialog and permission control.
