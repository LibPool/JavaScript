# node-red-contrib-easye4-json

> 标签: easy, easye4, eaton, http, json, node-red, plc, sps, steuerung

## 简介

Node-RED nodes for the Eaton easyE4 via the JSON API of its web server (HTTP/HTTPS): read/write operands, function blocks, RUN/STOP, clock (English/Deutsch)
