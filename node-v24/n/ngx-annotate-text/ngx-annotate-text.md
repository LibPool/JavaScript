# ngx-annotate-text

> 标签: Angular, Angular component, Angular component library, NER, NLP, TypeScript library, annotate, annotate entities, annotate parts of text, annotate text, annotation documents, annotation tool, entities, highlight entities, highlight text, highlight words, highlighting, named entity recognition, part of speech tagging, pos-tagging

## 简介

This Angular component library is perfect for tasks like visualizing named entity recognition, part of speech tagging, or annotating text datasets. It allows for interactively highlighting and annotating parts of text.
