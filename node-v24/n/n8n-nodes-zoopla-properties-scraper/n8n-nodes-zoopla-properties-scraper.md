# n8n-nodes-zoopla-properties-scraper

> 标签: apify, n8n, n8n-community-node-package, n8n-nodes, scraping

## 简介

Scrape Zoopla UK property listings by location, operation (sale/rent), beds, price. Returns numeric price, price-drop info, 'Reduced' flag, agent name & phone, GPS, postcode, images, parse confidence per record. Pay per result.
