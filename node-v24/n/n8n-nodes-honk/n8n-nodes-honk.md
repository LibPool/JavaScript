# n8n-nodes-honk

> 标签: alerts, honk, honk-honk, n8n, n8n-community-node-package, notifications, push-notifications

## 简介

n8n community node for Honk! Honk! (honk-honk.app): send messages from your workflows to your phone, with idempotency keys so retries never notify twice.
