# n8n-nodes-bouncelens

> 标签: disposable email, email, email typo, email validation, email verification, mx, n8n, n8n-community-node-package

## 简介

n8n node that checks email addresses for bad format, dead domains, typos, throwaway domains and duplicates. Runs inside n8n, no API key.
