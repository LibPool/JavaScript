# nd-bitset

> 标签: JavaScript

## 简介

nd-bitset ======================= - simple wrap of std::bitset - only work in nodejs - must be 64 * Integer  (IF <= 32, directly use a JS integer is BEST) - suitable for bigsize bit-pool (suggested is 1G)
