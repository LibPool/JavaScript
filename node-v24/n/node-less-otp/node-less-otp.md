# node-less-otp

> 标签: 2fa, auth, authentication, authorization, hotp, less, less-otp, node, node-less-otp, one-time password, otp, password-less, passwordless, passwordless-auth, passwordless-authentication, passwordless-authorization, passwordless-authorization-code, security, stateless, stateless-auth, stateless-authentication, stateless-authorization, stateless-authorization-code, totp

## 简介

A super lightweight library for generating and verifying one-time passwords (OTPs) without the database interaction and additional dependencies.
