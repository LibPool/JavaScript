# node-red-contrib-nhc2-z2m-light

> 标签: light, nhc2, niko, node-red, z2m, zigbee2mqtt

## 简介

Node-RED node to convert NHC2 light payloads to Zigbee2MQTT set commands with shared rate-limit config.
