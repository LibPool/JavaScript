# next-watch

> 标签: ai-agents, bun, claude-code, codex, dev-server, git, mise, nextjs, terminal-dashboard, tmux, tui, watcher

## 简介

Terminal dashboard that watches a Next.js repo: pulls origin, restarts only the dev servers that changed, and keeps Claude Code and Codex sessions alive.
