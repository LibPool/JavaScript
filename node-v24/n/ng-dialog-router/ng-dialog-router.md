# ng-dialog-router

> 标签: @angular, @angular/material, angular, angular/router, dialog, mat-dialog, material, modal, ng, ng-dialog-router, router, routing

## 简介

A small angular library that allows you to configure instances of @angular/material's MatDialog as part of your routing configuration.
