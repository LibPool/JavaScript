# near-fastkv-encrypted

> 标签: aes-256-gcm, e2ee, encryption, fastkv, key-value, near, storage, tee

## 简介

End-to-end encrypted key-value storage for NEAR Protocol using FastKV backend. Requires NEAR account and FastKV infrastructure. Client-side AES-256-GCM encryption with TEE key wrapping via OutLayer.
