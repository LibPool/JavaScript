# n8n-nodes-raposa

> 标签: ai-agents, approval, audit-log, human-in-the-loop, n8n-community-node-package, raposa

## 简介

n8n community node for Raposa Aval: pause a workflow until an authorised human approves, with a hash-chained audit record of the decision.
