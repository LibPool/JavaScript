# n8n-nodes-crmcalls

> 标签: auto dialer, autodialer, call center, calls, crm, crmcalls, leads, n8n, n8n-community-node-package, telephony

## 简介

CRMCalls node for n8n: create and update contacts, bulk-load them into the call center or straight into an auto-dial project, read calls and download their recordings, and read scenarios, call results, projects, custom fields, tags and users
