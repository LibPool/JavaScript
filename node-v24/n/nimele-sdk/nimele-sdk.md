# nimele-sdk

> 标签: avatar, digital-human, llm, matting, nimele, noise-suppression, sdk, shadow, tts

## 简介

Browser SDK for Nimele digital avatar — actorId + avatarId, LLM/TTS, lip-sync canvas, action switch, soft person shadow, mic with DTLN noise suppression
