# nocobase-db-merge-export

> 标签: cli, database, export, mariadb, migration, mysql, nocobase

## 简介

NocoBase database configuration data export tool - exports pure configuration data to safely overwrite target databases. NocoBase 数据库配置数据导出工具，用于提取并覆盖目标数据库的纯配置数据
