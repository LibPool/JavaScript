# n8n-nodes-whatsapp-personal

> 标签: automation, baileys, diginno, n8n-community-node-package, n8n-node, whatsapp

## 简介

n8n community node to send/receive WhatsApp messages from a personal number via a self-hosted Baileys bridge — no Meta Business API required. Built by Diginno.
