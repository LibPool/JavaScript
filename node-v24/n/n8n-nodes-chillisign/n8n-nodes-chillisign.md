# n8n-nodes-chillisign

> 标签: chillisign, custom template, email, email signature, n8n-community-node-package, signature

## 简介

Node for integrating ChilliSign — a professional email signature management platform. Automate signature creation, user management, and template synchronization via ChilliSign REST API.
