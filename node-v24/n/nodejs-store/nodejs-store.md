# nodejs-store

> 标签: access-control, acl, aggregation, ai-agent, computed-columns, cross-database, data-layer, gql, group-by, json-schema, llm-tool, mongodb, mongoose-alternative, multi-database, multi-tenant, mysql, natural-language-query, node, odm, orm-alternative, postgres, postgresql, prisma-alternative, query-builder, query-validation, rbac, row-level-security, soft-delete, sqlite

## 简介

Multi-backend data layer for Node.js (MongoDB, MySQL, SQLite, PostgreSQL): pure JSON schemas, GQL tree queries compiled to a single native query, GROUP BY/HAVING aggregation, computed columns, soft-delete and role-based access control
