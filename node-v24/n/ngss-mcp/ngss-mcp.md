# ngss-mcp

> 标签: 3d-framework, education, mcp, model-context-protocol, ngss, science, standards, teachflow, token-efficient

## 简介

MCP server with 8 tools for NGSS standards: complete 3D framework filtering (SEP, CCC, DCI) and intelligent unit planning. Supports Smithery.ai deployment.
