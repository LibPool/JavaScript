# ng-string-rotate

> 标签: Angular, Angular2, Angular4, Angular6, ionic, ng, string, string rotater, string shifter

## 简介

String rotater for [Angular](http://angular.io); Rotate the string in clockwise/ anti-clockwise * john -> ohnj * john -> hnjo * jacob -> bjaco  (anti-clockwise)
