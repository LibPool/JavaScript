# nodebb-plugin-rank-badges

> 标签: badges, gamification, nodebb, nodebb-plugin, plugin, rank, ranks, reputation, user-title

## 简介

Rank badges for NodeBB 4: ranks from post count and/or reputation, group badges (Administrator, Moderator, any group), optional images and a level bar. Configured in the ACP; forum and ACP translated (en-GB, pl).
