# non-overlapping-recurring-task

> 标签: ES2020, async-task, clean-teardown, disjoint-executions, execution-overlap, graceful-shutdown, graceful-teardown, graceful-termination, mutually-exclusive, node.js, nodejs, non-overlap, non-overlapping, periodic-scheduler, periodic-task, recurring, recurring-task, scheduler, setInterval, smooth-shutdown, task-scheduler, ts, typescript

## 简介

A modern `setInterval` substitute tailored for asynchronous tasks, ensuring non-overlapping executions by skipping attempts if a previous execution is still in progress. Features execution status getters, graceful teardown, and a fixed delay between runs.
