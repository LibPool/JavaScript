# ngx-chronica

> 标签: angular, angular-calendar, calendar, chronica, component, date-picker, date-range, datetime-picker, duration-picker, forms, standalone, time-picker, typescript, ui

## 简介

Complete Angular date & time component library featuring DatePicker, DateRange, InlineCalendar, TimePicker, DateTimePicker, and DurationPicker. 8 color themes, dark mode, WCAG 2.1 AA targeted accessibility, and zero external dependencies.
