# n8n-nodes-easychat

> 标签: chat, easychat, easyhive, n8n-community-node-package, slack

## 简介

n8n community node to post messages to Easy Chat (chat.easyhive.pro) as the Easy Bot — a drop-in replacement for the Slack node.
