# next-jest-boost

> 标签: cli, jest, nextjs, testing, typescript

## 简介

A CLI tool to automatically setup Jest + Testing Library for Next.js projects, supporting JavaScript and TypeScript, and npm, yarn, pnpm package managers.

## 官网

- npm 页面：https://www.npmjs.com/package/next-jest-boost

- npm registry：https://registry.npmjs.org/next-jest-boost
- Node 要求：>=12
