# nrb-exchange-rate

> 标签: api, bank, central-bank, currency, exchange-rate, exchange-rates, forex, fx, nepal, npr, nrb, official-rates, rastra, typescript

## 简介

Official Nepal Rastra Bank (Nepal) daily exchange rates — 22 currencies vs NPR, history since 1998. Zero-dependency Node.js/TypeScript client.
