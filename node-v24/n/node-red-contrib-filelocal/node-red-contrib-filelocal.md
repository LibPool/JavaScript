# node-red-contrib-filelocal

> 标签: copy, delete, directory, file, filesystem, folder, list, mkdir, move, node-red, stat

## 简介

Node-RED nodes to work with filesystem. You can copy, move, link, delete files, create, list and remove folders and get info.

## 官网

- npm 页面：https://www.npmjs.com/package/node-red-contrib-filelocal

## 获取地址

- npm 安装：`npm install node-red-contrib-filelocal`
- npm registry：https://registry.npmjs.org/node-red-contrib-filelocal
- Node 要求：>= 12.0.0
