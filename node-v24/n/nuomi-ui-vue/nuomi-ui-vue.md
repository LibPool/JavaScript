# nuomi-ui-vue

> 标签: JavaScript

## 简介

这是一款基于 Vue3.3 和 TypeScript 的 UI 组件库，涵盖了 `Button`、`Switch`、`Tabs`、`Dialog` ... 等常见 UI 组件，并提供了官方文档，可在线查看代码示例，且支持 PC 和手机浏览。
