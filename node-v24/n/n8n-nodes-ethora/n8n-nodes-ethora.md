# n8n-nodes-ethora

> 标签: ai-agent, chat, ethora, messaging, n8n-community-node-package

## 简介

n8n community node for Ethora: broadcast chat messages, manage rooms, and get AI agent replies on a self-hosted or cloud Ethora instance.
