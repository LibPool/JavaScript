# next-advanced-sitemap

> 标签: app-router, google-images, google-news, google-video, hreflang, multilingual, nextjs, seo, sitemap, typescript

## 简介

Advanced sitemap generator for Next.js. Powerful support for Google Images, Video, News, and Hreflang (multilingual). Type-safe and built for App Router.
