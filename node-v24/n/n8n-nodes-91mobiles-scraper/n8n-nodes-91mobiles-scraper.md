# n8n-nodes-91mobiles-scraper

> 标签: apify, n8n, n8n-community-node-package, n8n-nodes, scraping

## 简介

Scrape 91mobiles.com device listings (phones, tablets, laptops). Returns name, brand, best-buy price, spec score, device URL and image. Pay per device.
