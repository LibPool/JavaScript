# now-static-build-storybook

> 标签: JavaScript

## 简介

This package provides a [builder](https://zeit.co/docs/v2/deployments/builders/overview#when-to-use-builders) for Zeit's [Now 2.0](https://zeit.co/blog/now-2) that compiles [Storybooks](https://github.com/storybooks/storybook)
