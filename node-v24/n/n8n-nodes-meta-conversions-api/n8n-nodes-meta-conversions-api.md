# n8n-nodes-meta-conversions-api

> 标签: advertising, attribution, capi, conversions-api, facebook, meta, n8n, n8n-community-node-package, pixel, server-side-tracking

## 简介

Send server-side conversion events to the Meta Conversions API from n8n, with customer information normalized and SHA-256 hashed to Meta's spec.
