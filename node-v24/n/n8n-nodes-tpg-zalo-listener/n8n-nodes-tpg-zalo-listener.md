# n8n-nodes-tpg-zalo-listener

> 标签: n8n, n8n-community-node-package, zalo, zca-js

## 简介

n8n trigger node that listens to Zalo (personal account) messages using the open-source zca-js library. Emits { message: { type, data, threadId, isSelf }, isVoiceMessage } per message.
