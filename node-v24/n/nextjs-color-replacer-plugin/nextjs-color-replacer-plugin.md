# nextjs-color-replacer-plugin

> 标签: build-time, colors, css, css-in-js, emotion, less, material-ui, mui, nextjs, plugin, react, sass, scss, styled-components, stylus, typescript, webpack

## 简介

A comprehensive Next.js plugin that replaces custom color names with configured color values during build time. Supports CSS, CSS-in-JS, MUI, and inline styles.
