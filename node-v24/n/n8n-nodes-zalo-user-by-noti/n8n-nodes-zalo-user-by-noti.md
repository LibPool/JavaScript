## 简介

n8n community node cho tài khoản Zalo cá nhân (API không chính thức qua zca-js): gửi tin nhắn, quản lý bạn bè/nhóm, đăng nhập QR, trigger sự kiện. Dùng có rủi ro khóa tài khoản.
