# node-serviceworker

> 标签: isomorphic, nodejs, serviceworker

## 简介

Environment for running serviceworkers in node.js, as 'isomorphic' request handlers for clients without SW support.

- 源码仓库：https://github.com/gwicke/node-serviceworker.git
