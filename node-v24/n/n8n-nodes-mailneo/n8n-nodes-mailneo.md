# n8n-nodes-mailneo

> 标签: email, email-marketing, mailneo, n8n, n8n-community-node-package, newsletter

## 简介

n8n community nodes for the Mailneo public API: a Mailneo node covering the v2 resources and a MailneoTrigger webhook node with HMAC signature verification.
