# next-marquee

> 标签: marquee, nextjs, performance, react, scroller, ticker, waapi, web-animations-api

## 简介

Compositor-driven React marquee built on the Web Animations API. Jank-free runtime speed changes, reverse scrolling, phase-preserving resize, reduced-motion support. SSR-safe, works with Next.js App Router and Pages Router.
