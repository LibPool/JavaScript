# nvis-fe-cms-libs

> 标签: cms, components, react, tailwindcss, ui

## 简介

Thư viện các component React được đóng gói để sử dụng trong dự án CMS Landing Page.   Thay vì viết lại code cho từng section, bạn có thể import trực tiếp các component từ thư viện này.
