> 标签: agent, cypher, dns, egress, graph, identity, ipv6, n8n, n8n-community-node-package, osint, provisioning, rdap, threat-intelligence, transparency, whisper

## 简介

n8n community node for Whisper agent identity and the whisper.security graph: register agents with routable IPv6 /128s, set DNS resolver policy, read logs, get egress config, keyless identity verification + RDAP, plus raw Cypher and 29 named graph recipes
