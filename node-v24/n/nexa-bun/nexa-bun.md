# nexa-bun

> 标签: admin, api, crud, framework, fullstack, hostinger, nexa, nexa-bun, node, nodejs, orm, rest, typescript

## 简介

Nexa — Production backend framework for Node.js. One resource → REST API, ORM, auth, queue, and admin panel. Zero native build (Hostinger / Windows friendly).
