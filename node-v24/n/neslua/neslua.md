# neslua

> 标签: 6502, 8-bit, ahead-of-time, aot, cartridge, cc65, famicom, fceumm, game-development, gamedev, homebrew, lua, mmc1, nes, nes-rom, nintendo, pico-8, pico8, retro, retrogaming, rom, sprites, wasm, webassembly

## 简介

PICO-8-flavored Lua compiled to a real NES (.nes) ROM. Zero native tools: the cc65 toolchain runs as bundled WASM. The NES member of the luacretro console SDK family.
