# node-query-filter

> 标签: api, django, django-filter, drf, express, filter, filters, ordering, postgres, postgresql, query, querystring, rest, search, sequelize, sorting, typescript

## 简介

Ready-made filtering, search and sorting for Node.js APIs using Sequelize + PostgreSQL: turn ?age__gte=18&search=rahul into validated queries. Django REST Framework–style syntax.
