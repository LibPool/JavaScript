# node-group

> 标签: custom-element, document-persistent-fragment, dom-fragment, dom-transparency, fragment-streaming, live-parent, no-dom-patching, node-group, ownership-sharing, persistent-fragment, production, transparent-group, typescript, vanilla-js, virtual-parent

## 简介

Zero-runtime vanilla JavaScript library providing transparent DOM grouping via DocumentPersistentFragment - live parent semantics without wrappers, shadow roots or DOM patching.
