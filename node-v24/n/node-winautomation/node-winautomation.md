# node-winautomation

> 标签: accessibility, automation, com-automation, desktop, excel, office-automation, outlook, powerpoint, sap-gui, testing, ui-automation, windows, word

## 简介

Complete Windows automation library with UI Automation and COM support for Office (Excel, Word, PowerPoint, Outlook, Access, OneNote, Visio), SAP GUI, and Acrobat
