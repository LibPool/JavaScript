# node-typescript-koa-rest

> 标签: api rest, boilerplate, class-validator, cors, github actions, helmet, heroku, jwt, koa, koa2, sql, typeORM, typescript, winston

## 简介

API REST using NodeJS and KOA framework, typescript. TypeORM for SQL with class-validators. Middlewares JWT, CORS, Winston Logger. Swagger API docs
