# node-lab-mcp

> 标签: ifr, mcp, model-context-protocol, node-lab, partykit

## 简介

MCP server to drive the IFR Node Lab graph from any MCP client (Claude / Codex / Gemini …) — locally or, via a PartyKit relay, against the deployed app.
