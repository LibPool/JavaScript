# nestjs-drizzle-orm

> 标签: NestJS, Nodejs, ORM, drizzle, pg, postgres

## 简介

Is a NestJS ORM module tailored for Drizzle, supporting PostgreSQL and MySQL dialects. Simplify your database interactions effortlessly.
