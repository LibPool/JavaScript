# node-red-contrib-tcpip

> 标签: broadcast, multicast, networking, node-red, session, socket, tcp, tcpip, udp

## 简介

Node-RED nodes for managing multiple simultaneous TCP/IP and UDP connections with sessionId-based routing, status updates and structured error envelopes.
