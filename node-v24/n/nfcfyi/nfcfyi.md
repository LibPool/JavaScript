# nfcfyi

> 标签: api-client, contactless, iso-14443, ndef, nfc, nfcfyi, rfid

## 简介

TypeScript API client for NFCFYI -- NFC chips, chip families, NDEF types, operating modes, and standards. Zero dependencies.
