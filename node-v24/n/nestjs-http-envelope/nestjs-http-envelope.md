# nestjs-http-envelope

> 标签: api, envelope, exception-filter, interceptor, nest, nestjs, pagination, response, rest

## 简介

A uniform response & error envelope for NestJS — success/error interceptor + all-exceptions filter, attribute-hoisting (pagination), and @SkipEnvelope, all configurable.
