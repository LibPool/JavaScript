# nativescript-telerik-ui-pro

> 标签: autocomplete, calendar, chart, dataform, gauges, listview, nativescript, sidedrawer, ui

## 简介

Progress NativeScript UI Pro is an upgrade of Progress NativeScript UI - a cross-platform UI components suite based on the native iOS and Android libraries provided by Telerik.
