# n8n-nodes-stockx-scraper

> 标签: ai-tool, apify, ecommerce, marketplace, n8n, n8n-community-node-package, n8n-nodes, resale, sneakers, stockx

## 简介

Search StockX product listings and market data (lowest ask, highest bid, last sale, per-size pricing). Apify-backed n8n community node, pay-per-event, usable as an AI agent tool.
