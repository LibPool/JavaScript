# node-dde-with-edge-js

> 标签: JavaScript

## 简介

node-dde-with-edge-js is a simplified regacy win32 Dynamic Data Exchange (DDE) wrapper for node.js using [Edge.js](https://github.com/tjanczuk/edge) and [NDde](http://ndde.codeplex.com/). The client listen to the asynchronous _advise_ on multi-threaded CL
