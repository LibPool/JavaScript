# nocodb-mcp

> 标签: ai, claude, database, mcp, model-context-protocol, no-code, nocodb

## 简介

Full-coverage MCP server for NocoDB v3 — 92 tools across 19 groups. Manage schema, records, views, webhooks, links, attachments, dashboards, scripts, NocoDocs from any AI agent. stdio + HTTP transports.
