# novel-weaver

> 标签: ai-writing, character-voice, creative-writing, genre-pack, novel, novel-writer, opencode, opencode-plugin, pacing, worldbuilding, writing

## 简介

AI-assisted novel writing system for OpenCode - genre packs, arc templates, character voice tracking, pacing analysis, and a built-in web UI. Exposes tools via OpenCode plugin and MCP server.
