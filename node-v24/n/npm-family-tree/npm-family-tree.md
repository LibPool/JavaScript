# npm-family-tree

> 标签: angular family tree, family organization, family tree, family tree in angular, npm family tree

## 简介

A family tree is a type of chart or diagram representing generations of families and how they are linked throughout the years. A family tree can include names, multiple wife,gender,alive status, marriage status and pictures.
