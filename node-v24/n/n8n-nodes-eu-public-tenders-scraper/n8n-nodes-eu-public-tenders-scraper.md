# n8n-nodes-eu-public-tenders-scraper

> 标签: n8n, n8n-community-node-package, n8n-nodes

## 简介

n8n community node: search EU public tenders from the official TED (Tenders Electronic Daily) API — relevance scoring, dedup and new-only alerts.
