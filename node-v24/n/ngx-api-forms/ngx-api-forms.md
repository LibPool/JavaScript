# ngx-api-forms

> 标签: 422, angular, angular-validation-errors, api, class-validator, django, error-handling, express, express-validator, form-errors, form-helper, forms, http-interceptor, i18n, laravel, nestjs, ng, ngx, reactive-forms, server-side-validation, ssr, validation, zod

## 简介

Bridge API validation errors to Angular Reactive Forms. Supports NestJS/class-validator, Zod, Laravel, Django REST, express-validator and custom presets.
