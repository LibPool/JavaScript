# n8n-nodes-fetchworks

> 标签: apify, captions, n8n-community-node-package, subtitles, transcript, youtube

## 简介

n8n community node for YouTube transcripts — segments, plain text, SRT, VTT from videos, channels, playlists, and search, via the Fetchworks YouTube Transcript Scraper on Apify
