# n8n-nodes-stayingapi

> 标签: accommodation, airbnb, availability, booking, cross-ota, google-hotels, hotel-api, n8n, n8n-community-node-package, price-comparison, reviews, stayingapi, travel-api, vacation-rental, vrbo

## 简介

n8n community node for StayingAPI: live accommodation data in one node with search, availability, real price quotes, cross-OTA price comparison and reviews across Airbnb, Booking.com, Vrbo and Google Hotels.
