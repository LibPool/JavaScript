# nodebb-plugin-usercleaner

> 标签: admin, bulk-delete, dormant-users, nodebb, plugin, spam, user-cleanup

## 简介

Bulk-delete dormant, abandoned and spam accounts from NodeBB with a dry-run-first admin workflow, live filter preview and background deletion jobs.
