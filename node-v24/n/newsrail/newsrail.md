# newsrail

> 标签: agent, atom, atproto, bluesky, github, hacker-news, json-feed, llm, news, rss, threads, webhook, wire, x-api

## 简介

NewsRail polls sources, filters items, writes posts, renders cards, publishes posts, and stores records. Each wire uses one config file.
