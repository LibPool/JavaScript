# nostr-wot-sdk

> 标签: data, decentralized, nip-65, nostr, outbox, react-hooks, sdk, social-graph, trust, web-of-trust, wot

## 简介

Meta-package re-exporting the @nostr-wot/* family (wot, relay, data, signers, ui, dm, wallet, auth, blossom) under subpaths. Existing imports keep working; new code should depend on the scoped packages directly.
