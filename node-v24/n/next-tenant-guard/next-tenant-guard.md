# next-tenant-guard

> 标签: edge-middleware, middleware, multi-tenant, multitenant, next.js, nextjs, rbac, role-based-access-control, saas, subdomain-routing, tenant

## 简介

Drop-in Next.js middleware for multi-tenant routing and role-based access control — resolve a tenant from subdomain/path/header and gate routes by role in one config object.
