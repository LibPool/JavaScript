# ngx-slickjs

> 标签: angular, carousel, lazy-loading, ngx, ngx-slickjs, slick, slick-carousel, slickjs

## 简介

ngx-slickjs is slick-carousel package for Angular 6+. ngx-slickjs can lazy load slick.js packages
