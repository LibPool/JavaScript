# nodeset-js

> 标签: caex, diagram-js, information-model, modeler, nodeset, nodeset2, opc-ua

## 简介

Graphical modeler for OPC UA information models: types and instances in the notation of OPC 10000-3 Annex C, stored as NodeSet2.
