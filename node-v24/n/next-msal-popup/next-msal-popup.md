# next-msal-popup

> 标签: app-router, authentication, azure-ad, entra-id, msal, msal-browser, nextjs, oauth, popup, react

## 简介

Finish an MSAL Browser v5 popup login from a Next.js redirect page. Forwards the auth response over the BroadcastChannel MSAL is listening on, then closes the popup.
