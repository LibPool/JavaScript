# n8n-nodes-reeflex

> 标签: ai-agents, governance, guardrails, human-in-the-loop, n8n-community-node-package, reeflex

## 简介

Reeflex Gate node for n8n - govern what your workflow's agents may do before it happens; route each risky step on allow/hold/deny, decided on real impact (via reeflex-core POST /v1/decide).
