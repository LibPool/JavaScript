# nuxt-i18n-inspect

> 标签: devtools, i18n, i18n-inspector, in-context-editing, localization, nuxt, nuxt-i18n, nuxt-module, translations, vue-i18n

## 简介

Edit @nuxtjs/i18n translations in the running app and write them straight to your locale files. No backend.
