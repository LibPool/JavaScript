# n8n-nodes-codex-cli

> 标签: ai, chatgpt, codex, n8n, n8n-community-node-package, openai, subscription

## 简介

n8n community node that runs OpenAI Codex through your local, subscription-authenticated Codex CLI (Sign in with ChatGPT) — no API key. Chat + Agentic modes, local exec, no Docker socket.
