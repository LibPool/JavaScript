# normalise-with-fields

> 标签: JavaScript

## 简介

This does a very similar thing to [normalizr](https://github.com/paularmstrong/normalizr): specify a schema to build functions to normalize / denormalize an object that adheres to that schema. The main difference is the ability to treat 'fields' as normal
