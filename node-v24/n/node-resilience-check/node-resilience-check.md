# node-resilience-check

> 标签: backpressure, chaos-engineering, cli, event-loop, fault-injection, graceful-shutdown, microservices, nodejs, race-condition, reliability, resilience, retry, testing, typescript

## 简介

Open-source resilience testing CLI for Node.js and TypeScript services. Detect backpressure bugs, retry storms, event-loop blocking, race conditions, graceful shutdown failures, and microservice reliability issues.
