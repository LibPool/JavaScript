# n8n-nodes-niyoos

> 标签: ai, anthropic, claude, langchain, llm, n8n, n8n-community-node-package, niyoos

## 简介

Use Niyoos-governed LLMs (Anthropic via the Niyoos proxy) as a LangChain chat model in n8n.
