# ngx-tailwindcss

> 标签: angular, angular-cli, cli, css, sass, tailwind

## 简介

A helpful cli tool for integrating tailwindcss with angular-cli projects, inspired from https://www.npmjs.com/package/ng-tailwindcss with more functionality for sass
