# n8n-nodes-nodester-probe-experimental

> 标签: experimental, jsonplaceholder, n8n, n8n-community-node-package, nodester

## 简介

EXPERIMENTAL TEST PACKAGE - not for production use. An n8n community node built entirely from a JSON definition with no TypeScript build step, wrapping the public JSONPlaceholder test API.
