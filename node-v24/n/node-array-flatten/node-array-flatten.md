# node-array-flatten

> 标签: array, array-flat, array-flatten, array-utility, collection, deep-flatten, es-next, es2019, flat, flatten, functional, immutable, javascript, list, nested, node, performance, transform, utility

## 简介

A modern, efficient, and lightweight utility for flattening nested arrays in Node.js and JavaScript. Leverages native Array.prototype.flat() for optimal performance.
