# nodebb-plugin-iframely

> 标签: embed, gfycat, giphy, iframely, imgur, nodebb, oembed, onebox, plugin, unfurl, youtube

## 简介

Iframely will give you embeds from over 1700 domains, plus previews for the rest of the web.
