# @foreseen/sdk

> 标签: bot, celo, commit-reveal, game, minipay, rock-paper-scissors, viem, web3

## 简介

TypeScript SDK for Foreseen — the on-chain Rock Paper Scissors mind-sport on Celo. Matchmake, scout opponents from their on-chain history, commit-reveal, and build bots.
