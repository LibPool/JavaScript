# @tamtunnel/si-wallet-core

> 标签: JavaScript

## 简介

Audited crypto core: Ed25519 did:key identities, compact EdDSA JWS mandates, scrypt+AES-256-GCM keystore, replay ledger, strict canonical base64url. Zero runtime dependencies.
