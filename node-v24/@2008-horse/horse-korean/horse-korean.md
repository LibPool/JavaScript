# @2008-horse/horse-korean

> 标签: g2p, hangul, korean, offline, onnx, pronunciation

## 简介

Horse Korean: converts written Korean (Hangul) into how it is pronounced. Offline ONNX model with a JavaScript SDK.

- 官网：https://2008-horse.com/
