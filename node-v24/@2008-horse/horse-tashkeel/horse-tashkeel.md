# @2008-horse/horse-tashkeel

> 标签: arabic, diacritization, harakat, offline, onnx, tashkeel

## 简介

Horse Tashkeel: restores diacritics (tashkeel) to Arabic text written without them. Offline ONNX model with a JavaScript SDK.

- 官网：https://2008-horse.com/
