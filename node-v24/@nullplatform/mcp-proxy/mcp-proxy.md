# @nullplatform/mcp-proxy

> 标签: agent, ai, cli, controlplane, mcp, nullplatform, proxy

## 简介

A CLI proxy for Model Context Protocol (MCP), allowing AI agents to communicate with backend API executors via Nullplatform's control plane.
