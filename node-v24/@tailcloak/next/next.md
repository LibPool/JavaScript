# @tailcloak/next

> 标签: next, nextjs, obfuscate, tailcloak, tailwind, tailwindcss, turbopack, webpack

## 简介

Obfuscate Tailwind CSS v4 class names in Next.js production builds. One line in next.config, Turbopack and webpack.
