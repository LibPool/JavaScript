# @alwith/module-drive

> 标签: JavaScript

## 简介

Pre-release shared Drive module. JavaScript and Rust ship in the same versioned artifact. The native engine is extracted from ALwith Desktop; `desktop-provenance.json` records the source revision and original file hashes. Desktop migration is deferred.
