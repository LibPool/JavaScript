# @automate-io/jira-mcp-server

> 标签: ai, atlassian, jira, jira-cloud, mcp, mcp-server, model-context-protocol

## 简介

MCP server for Jira Cloud. Exposes issue, project, board, sprint, search, comment, worklog, link, version, attachment and property operations as MCP tools using the Jira Cloud REST and Agile APIs.
