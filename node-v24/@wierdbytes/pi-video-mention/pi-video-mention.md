# @wierdbytes/pi-video-mention

> 标签: coding-agent, extension, multimodal, openrouter, pi, pi-package, video

## 简介

Send video files to video-capable models via @mentions — routed as video_url content parts when the active model supports video, left as plain text otherwise.
