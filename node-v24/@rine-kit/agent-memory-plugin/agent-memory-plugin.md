# @rine-kit/agent-memory-plugin

> 标签: JavaScript

## 简介

Connects the @rine-kit/agent-memory engine to an @rine-kit/plugin-sdk host (Vercel AI SDK agents): remember / correct / forget tools, a recall hook and an observe hook. Authorization is whatever the host builds from its trusted context.
