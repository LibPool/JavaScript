# @yakies/nestjs-assets

> 标签: JavaScript

## 简介

专门用于构建 公共代码（如：封装的库、工具等） 的 rollup 配置模板，当需要开发和构建公共代码时，直接克隆本项目即可，并默认在的 src 目录下开发即可；支持nestjs后端项目
