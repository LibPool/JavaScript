# @gate-forge/witness

> 标签: JavaScript

## 简介

Gateforge runner-neutral witness: the loopback HTTP witness proxy, the per-test session tagging contract, and the runner-adapter contract every test runner (Playwright, Cypress, pytest+httpx, Jest/Vitest+supertest) implements to produce the same trusted e
