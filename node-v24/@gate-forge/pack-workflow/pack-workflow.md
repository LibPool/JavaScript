# @gate-forge/pack-workflow

> 标签: JavaScript

## 简介

Workflow / state-machine discovery pack: TS-only AST detector (GPP/3), five workflow contracts (transition-allowed, transition-rejected, terminal-immutable, audit-emitted, persisted-final-state), entity-adapter schema for state-machine witnesses.
