# @tungvivas/angular-vibe-kit

> 标签: agents, ai, angular, claude, claude-code, scaffold, skills, slash-commands, subagents, vibe-coding

## 简介

Bootstrap a Vibe Coding workflow (CLAUDE.md, project docs, slash-commands, skills, agents) into any Angular project. Detects your Angular version and installs version-matched best-practice rules.
