# @alatastudio/dsh-client-modules

> 标签: JavaScript

## 简介

Client module system, dual-face: Node half discovers dsh.client bundles and composes the transport-neutral boot graph; browser half is the lazy-CJS module table used by the vendored Cordis Loader
