# @zeroclickdev/zeroboard-mcp

> 标签: kanban, mcp, model-context-protocol, supabase, zeroboard

## 简介

MCP server for ZeroBoard — manage your boards, columns, and cards from any MCP-compatible agent (Claude Code, Cursor, Zed, Windsurf).
