# @deploybaseline/salesforce

> 标签: JavaScript

## 简介

Salesforce emulator for REST API v31.0 to v68.0: describe, sObject rows by ID and by external ID with upsert, relationship traversal, SOQL `query` and `queryAll`, replication feeds, sObject Collections, composite, batch, tree, and graph requests, limits,
