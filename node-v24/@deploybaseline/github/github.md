# @deploybaseline/github

> 标签: JavaScript

## 简介

GitHub REST API emulator: users, repos, issues, PRs, comments, reviews, labels, milestones, branches, git data, orgs, teams, releases, webhooks, search, actions, checks, and rate limit, plus GraphQL, OAuth Apps, and GitHub Apps.
