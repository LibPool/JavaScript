# @deploybaseline/plaid

> 标签: JavaScript

## 简介

Plaid API emulator for Baseline: Link tokens and a hosted Link page with sandbox logins, public token exchange, items, accounts and real time balances, Auth ACH numbers, transactions sync and get over deterministic sandbox data, institutions, the sandbox
