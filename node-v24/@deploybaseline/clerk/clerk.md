# @deploybaseline/clerk

> 标签: JavaScript

## 简介

Clerk authentication and user management emulator for local development and tests: the Frontend API for clerk-js (environment, client, sign-in, sign-up, sessions, `/v1/me`, social sign-in, handshake), OIDC discovery, JWKS, OAuth authorize/token/userinfo,

- 源码仓库：git+https://github.com/deploybaseline/baseline-cli.git
