# @deploybaseline/slack

> 标签: JavaScript

## 简介

Slack API emulator for local development and tests: auth, chat, conversations, users, profiles, presence, files, pins, bookmarks, views, reactions, team, OAuth, incoming webhooks, interactivity, slash commands, Socket Mode, and an inspector.

- 源码仓库：git+https://github.com/deploybaseline/baseline-cli.git
