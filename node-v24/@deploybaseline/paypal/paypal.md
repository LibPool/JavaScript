# @deploybaseline/paypal

> 标签: JavaScript

## 简介

PayPal emulator for local development and tests: OAuth client credentials, Orders v2, Payments v2, a hosted approval page with sandbox buyers, and Webhooks v1 with SHA256withRSA signatures.
