# @deploybaseline/stripe

> 标签: JavaScript

## 简介

Stripe payments emulator for local development and tests: customers, payment methods, setup intents, customer sessions, payment intents, charges, refunds, products, prices, invoices, invoice items, subscriptions, subscription items, test clocks, checkout
