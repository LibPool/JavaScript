# @deploybaseline/sendgrid

> 标签: JavaScript

## 简介

SendGrid email API emulator for local development and tests: Mail Send v3 with SendGrid's validation, scheduling, dynamic and legacy templates with Handlebars rendering, API keys with scopes, Marketing contacts and lists, the Event Webhook with ECDSA sign
