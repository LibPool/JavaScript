# @nac3/forge-rn

> 标签: agentic, chat, nac3, react-native, voice, yujin

## 简介

Yujin NAC3 React Native primitives. Cross-target attrs (data-nac-id <-> testID), shared tokens, and the canonical 3-mode chat surface (Globito / Mini / Full).
