# mlc-markdown

> 标签: forms, markdown, marked, mlc, renderer, sop

## 简介

Rendering of Markdown with the MLC Markdown Extension (non-standard): form fields, fill hints, alerts, anchors, page breaks — the same look in MarkSafe, the MLC Sensor Monitor and the MLC Terminal. Display only; the rules live in the Go module mlcext.
