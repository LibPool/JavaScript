# jquery.steps.full

> 标签: bootstrap, bootstrap-footable, footable, footable-bootstrap, footable-tables, full-features-footable, responsive-footable, tables

## 简介

jQuery Steps is a smart UI component which allows you to easily create wizard-like interfaces. This plugin groups content into sections for a more structured and orderly page view. Furthermore, it is as simple as 1-2-3 to add plugins such as jQuery Valida
