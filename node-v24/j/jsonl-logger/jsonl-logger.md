# jsonl-logger

> 标签: bun, datadog, ecs, elastic-common-schema, esm, google-cloud-logging, json-lines, jsonl, logger, nextjs, opentelemetry, pino, structured-logging, victoria-logs

## 简介

Lightweight ESM-only JSON Lines logger with pluggable formatters for Google Cloud Logging, VictoriaLogs, Elastic Common Schema (ECS), Datadog, and Pino, with OpenTelemetry trace-context support
