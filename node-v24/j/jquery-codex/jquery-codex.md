# jquery-codex

> 标签: codex, ecosystem:jquery, jquery, jquery-plugin, sodomizer, text

## 简介

jQuery Plugin for sodomizing texts for a period of given time. It applies a temporary effect to the selected text(s). Check the demo for better undestanding.
