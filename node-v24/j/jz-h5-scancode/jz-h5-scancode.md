# jz-h5-scancode

> 标签: barcode, barcode-detector, camera-scanner, h5, h5扫码, h5扫码插件, jsqr, qrcode, scanner, uni-app, 二维码, 扫码

## 简介

H5环境下的二维码扫描插件，提供与 uni.scanCode 完全兼容的 API 接口，支持摄像头实时扫码和图片扫码。v1.1.0优化性能，修复卡死问题
