# js-profile

> 标签: javascript, js, performance, profile

## 简介

一个 js profiler 工具, 可以分析函数的运行的时间和运行次数，主要用于分析关键 js 代码的运行性能，例如分析 js 写的算法的性能。若需要分析整个项目的运行性能，请使用 chrome devtools。
