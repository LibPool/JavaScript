# jjckpt

> 标签: agent, ai, checkpoint, claude-code, jj, jujutsu, snapshot, undo

## 简介

Per-turn AI checkpoints backed by Jujutsu (jj), isolated from your git history. Engine CLI — used by agent hooks and the VS Code extension.
