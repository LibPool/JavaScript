# jev-mcp

> 标签: ai, classification, confidence, jev, mcp, model-context-protocol, system-one, typesafe

## 简介

MCP server exposing TypeSafe Jev typed judgments: classify, score, check, a batched multi-question ask, a many-item triage with server-side file reads, and model discovery.
