# jami-mcp

> 标签: cbe, claude, cursor, etb, ethiopia, jami, jamidev, mcp, model-context-protocol, mpesa, payments, telebirr

## 简介

Official MCP server for JamiDev — let Claude, Cursor and any MCP client create ETB checkouts, reconcile orders, preview and send payouts, debug webhooks and search the Jami docs.
