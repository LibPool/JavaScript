# jianfv-ui

> 标签: Vue-Ui

## 简介

加载组件库 ``` npm i --save jianfv-ui ``` 使用全局引入方法 ``` import JF form 'jianfv-ui' Vue.use(JF) ``` 在页面中使用 输出 Hello World 则引用成功 ``` <jf-demo /> ``` ### 组件api演示地址 ``` 暂无 ``` #### 版本更新记录 ``` 1.2.2 ```
