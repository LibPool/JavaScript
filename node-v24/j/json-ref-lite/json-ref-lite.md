# json-ref-lite

> 标签: $ref, circular, graph, json, json jsonschema ref json pointers jsonref remote reference lightweight, json pointers, jsonpointer, jsonref, jsonschema, ref, remote reference, resolve

## 简介

Extremely light weight way to resolve jsonschema '$ref' references & inheritance: create circular/graphs, fractals from json (browser/coffeescript/javascript).
