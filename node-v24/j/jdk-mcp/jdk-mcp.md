# jdk-mcp

> 标签: java, jdk, mcp, temurin

## 简介

MCP server to detect, install, configure and uninstall JDK on macOS and Windows (Temurin, OpenJDK, Oracle, etc.)

## 官网

- npm 页面：https://www.npmjs.com/package/jdk-mcp

## 历史版本号

- 当前版本：1.0.0

- 1.0.0

## 获取地址

- npm 安装：`npm install jdk-mcp`
- npm registry：https://registry.npmjs.org/jdk-mcp
- Node 要求：>=18
