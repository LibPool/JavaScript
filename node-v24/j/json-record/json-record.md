# json-record

> 标签: append-only, cryptography, data-integrity, digital-signature, hash-chain, json, json-security, ledger, nodejs, record, tamper-evident, typescript

## 简介

A lightweight, tamper-evident, hash-linked ledger for JSON or binary payloads, with optional WebCrypto signatures.
