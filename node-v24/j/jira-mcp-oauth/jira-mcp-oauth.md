# jira-mcp-oauth

> 标签: atlassian, cursor, jira, jira-cloud, mcp, model-context-protocol, sso

## 简介

Model Context Protocol server for Atlassian Jira: browser SSO cookies for REST (with background session keep-alive), plus optional Confluence attachment helpers—configure for your own Jira site (Cloud or Data Center).
