# jquery.geo

> 标签: API, ecosystem:jquery, geo, interactive, jquery-plugin, map, mapping, spatial, widget

## 简介

An interactive mapping widget and geo-spatial API built on open source and open data (NOT a wrapper of other APIs, such as Google Maps)

## 官网

- 官网：http://jquerygeo.com
- 源码仓库：git://github.com/jQueryGeo/geo.git
- npm 页面：https://www.npmjs.com/package/jquery.geo
