# jq-multiple-cli

> 标签: PWA, cli, jQuery, multiple page, webpack5, 自动构建

## 简介

一个使用webpack打包的jQuery 多页面构建工具。css预处理使用scss，jQuery使用CDN方式引入，并使用TS。同时支持PWA技术，开箱即用。 ## usage
