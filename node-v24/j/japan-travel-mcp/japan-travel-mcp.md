# japan-travel-mcp

> 标签: ai-agents, japan, mcp, model-context-protocol, open-data, tourism, travel

## 简介

Open Japanese tourism dataset + MCP server — 13,394 tourist spots × 18 languages, ~20,000 accommodations, 690 officially-designated cultural records. All 47 prefectures, all from public sources. Free, no API key.
