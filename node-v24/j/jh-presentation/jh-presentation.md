# jh-presentation

> 标签: ai, claude, diagram, er-diagram, html-slides, mcp, mcp-server, model-context-protocol, presentation, slides, state-machine, system-map

## 简介

An MCP server and engine for AI-built HTML presentations: single-file decks with live diagrams, ER and sequence diagrams, charts, step animations, in-place text editing and PDF export.
