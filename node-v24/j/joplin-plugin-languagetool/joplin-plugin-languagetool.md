# joplin-plugin-languagetool

> 标签: joplin-plugin

## 简介

Use the power of LanguageTool for grammar and spell checking in your notes. Currently the plugin is in an alpha state and a more complete support, please leave an issue if you encounter a bug or want a new feature.
