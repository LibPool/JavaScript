# joplin-plugin-willdo

> 标签: joplin-plugin

## 简介

Task manager for Joplin: dates, alarms, recurrence, search and linked notes. Interface in Brazilian Portuguese. Android: enable Joplin notifications. PT-BR: Tarefas no Joplin com datas, alarmes, recorrência e busca. Android: permita notificações.
