# js-chunks

> 标签: chunking, documents, docx, markdown, rag, text-splitting, wasm

## 简介

Idiomatic TypeScript/JS wrapper around a WASM-backed Rust document chunking engine for RAG — 36 file formats, images, and PDF; runs on Node, Bun, Deno, and browsers.
