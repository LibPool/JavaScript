# js-scissor

> 标签: base64, blob, browser, canvas, contain, cover, crop, image, javascript, jpeg, png, resize, thumbnail, typescript, webp

## 简介

Lightweight browser image resizer — resize from <img>, <canvas>, or URL and get Base64, Blob, or image elements.
