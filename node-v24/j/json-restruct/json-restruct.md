# json-restruct

> 标签: data-transformation, etl, excel, filter, json, json-mapper, json-restruct, mapper, mapping, schema, transform, transformer, wildcard

## 简介

A high-performance, declarative schema based system for restructuring JSON data into well-defined, API-ready JSON payloads.
