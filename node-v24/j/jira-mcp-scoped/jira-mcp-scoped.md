# jira-mcp-scoped

> 标签: atlassian, issue-tracking, jira, mcp, modelcontextprotocol

## 简介

Project-scoped MCP server for Jira — issues, comments, sprints, transitions and attachments over the Jira REST API, narrowed to a single project instead of everything the account can access
