# js2mjs

> 标签: CommonJS, ESM, cjs, js, mjs, transpile

## 简介

Patch an ESM distribution that is using .js extension so it use .mjs instead

## 官网

- 官网：https://github.com/garronej/js2mjs
- 源码仓库：git://github.com/garronej/js2mjs.git
