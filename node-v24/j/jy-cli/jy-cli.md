# jy-cli

> 标签: JavaScript

## 简介

commander 编写指令和处理命令行的 inquirer 强大的交互式命令行工具 chalk 修改控制台输出内容样式 ora 这是一个好看的加载，就是你下载的时候会有个转圈圈的那种效果 download-git-repo 用来下载远程模板的，支持 GitHub、 GitLab 和 Bitbucket 等
