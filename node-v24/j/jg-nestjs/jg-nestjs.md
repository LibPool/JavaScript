# jg-nestjs

> 标签: api, cors, exception-filter, interceptor, nestjs, validation

## 简介

NestJS for HTTP APIs: an ApiException, a filter and an interceptor for the jg-api-response envelope, schema validation, CORS, and app bootstrap.
