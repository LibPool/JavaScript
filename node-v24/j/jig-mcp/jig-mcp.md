# jig-mcp

> 标签: a11y, accessibility, agent, browser, browser-automation, claude, cursor, jig, mcp, mcp-server, modelcontextprotocol, qa, qiksy, testing

## 简介

MCP bridge to Jig — let the agent in your editor open the running page, sign in as a role, fill the form and read the console in the tester's own workbench.
