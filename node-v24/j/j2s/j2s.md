# j2s

> 标签: API, GraphQL alternative, JSON, ORM, Parse alternative, Parse relational, RESTful, SQL, Swagger alternative, access control, bookshelf.js, knex, koa, koa.js, query language, rapid development, resource oriented architecture

## 简介

JSON to SQL, build RESTful API server on the fly, which accespts JSON describing SQL query statements, support (almost) full SQL functionality, with configurable access control & pluggable middlewares
