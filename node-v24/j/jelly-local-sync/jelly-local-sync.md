# jelly-local-sync

> 标签: adb-reverse, android, annotations, cli, ios, jelly, local, mobile-testing, qa, sse

## 简介

Local-only browser viewer for Jelly QA annotations. Open in browser, paste the per-session URL into the SDK, see annotations stream in over USB / LAN. Nothing leaves the machine.
