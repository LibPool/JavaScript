# json-forgefy

> 标签: ai-agent, ai-tool, data-mapping, data-normalization, declarative-json, etl, jq-alternative, json, json-mapper, json-pipeline, json-reshape, json-transform, json-transformation, jsonata-alternative, llm-tools, mongodb-operators, projection, safe-eval, typescript, zero-dependencies

## 简介

Safe, declarative JSON transformation engine using MongoDB-style aggregation operators. Zero dependencies, 100% test coverage, and TypeScript-first. Ideal for API data mapping, ETL, and AI agents.
