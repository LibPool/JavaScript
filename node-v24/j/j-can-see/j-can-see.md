# j-can-see

> 标签: claude-code, codex, color-picker, grok, image, image-diff, inspect, locate, mcp, model-context-protocol, ocr, svg, ui-restoration, vectorize, vision

## 简介

MCP server that gives text-only AI coding agents a vision toolkit: describe/OCR images, locate elements with pixel coordinates, diff images, pick exact colors, trace SVGs — for clients whose primary model has no multimodal input.
