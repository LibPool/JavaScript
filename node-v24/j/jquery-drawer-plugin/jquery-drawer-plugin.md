# jquery-drawer-plugin

> 标签: drawer, ecosystem:jquery, jquery-drawer, jquery-plugin, jquery-slider, slideDown, slideIn, slideOut, slideUp, slider, sliders

## 简介

Drawer is a simple jQuery plugin for adding a sliding drawer functionality to any HTML element. It can be used to show/hide any element with sliding effect of a drawer. The Drawer can be anchored to any side of the page or a div. It can also be configured
