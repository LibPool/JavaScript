# json2toon-converter

> 标签: compact, converter, data-format, encoding, json, llm, serialization, token, toon, typescript

## 简介

Convert between JSON and TOON (Token-Oriented Object Notation) formats. Lossless, bidirectional, and LLM-friendly.
