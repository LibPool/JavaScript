> 标签: agent, ai, antigravity, claude, claude-code, copilot, jdi, opencode, spec-driven-development, workflow

## 简介

JDI (Just Do It) — lean workflow toolkit for Claude Code, GitHub Copilot, Antigravity, OpenCode, and JetBrains Junie. 17 slash commands (/jdi-issue autonomous intake + /jdi-next auto-router + 7 loop + ralph + adopt + meta + roadmap mutation + DoD confirm)
