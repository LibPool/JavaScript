# jm-ksef

> 标签: e-invoice, fa3, faktura, invoicing, krajowy-system-e-faktur, ksef, poland, vat, webcrypto

## 简介

Plug-and-play JS/TS client for the Polish KSeF (Krajowy System e-Faktur) API v2 — authentication, invoice sessions (online + batch), querying, export, and verification. Zero dependencies, runs on Node 20+, browsers, and Cloudflare Workers (WebCrypto only)
