# jarallax-0.1

> 标签: background, image, parallax, video, vimeo, youtube

## 简介

Fork of Jarallax Smooth parallax scrolling effect for background images, videos and inline elements. Code in pure JavaScript with NO dependencies + jQuery supported. Youtube, Vimeo and Local Videos parallax supported.
