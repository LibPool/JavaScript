# joplin-plugin-cjk-breaks

> 标签: joplin-plugin

## 简介

This plugins suppresses linebreaks between CJK characters as in markdown-it plugin: [markdown-it-cjk-breaks](https://github.com/markdown-it/markdown-it-cjk-breaks)
