# jenkinsfile-lint

> 标签: ci, declarative-pipeline, jenkins, jenkinsfile, jenkinsfile-runner, lint

## 简介

One-command offline linting for declarative Jenkinsfiles, wrapping the official jenkinsfile-runner Docker image with clear errors and no manual Jenkins setup.
