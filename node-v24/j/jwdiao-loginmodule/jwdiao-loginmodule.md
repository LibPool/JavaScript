# jwdiao-loginmodule

> 标签: JavaScript

## 简介

* username?:string   ` 用户入参名`  * password?:string   ` 密码入参名`  * captcha?:string   ` 验证码入参名`  * bgImage?:string   ` 背景图地址`  * url?:string       ` 登录请求接口地址`  * captchaUrl?:string   ` 验证码请求接口地址`  * title?:string   ` 系统名称标题`  * ref?:string   ` 可选参数`
