# joshua-wepy

> 标签: JavaScript

## 简介

- 基于微信小程序的小程序商城买家端，采用`wepy`框架开发； - 项目实现了基本的商城功能； - 目前后端数据是基于`easy-mock`的随机模拟数据，且页面只开放了少部分功能； - 目前只对接了部分接口，如果接口报错404，说明该接口还尚未配置Mock数据，后续会继续完善。 - 有需要模拟数据界面，可以提ISSUE；
