> 标签: ai-agent, browser-agent, claude, cli, codex, context-compaction, jev, skill-router

## 简介

One command to install the whole Jev-powered agent toolset (jev-compact, jev-gate, jev-qa, jev-find, jev-ultrafast, jev-skill-router, cdp-browser-launcher). Zero deps.
