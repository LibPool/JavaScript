# jev-lexer

> 标签: gpu-lexer, jev, lexer, shiki, syntax-highlighting

## 简介

Language-agnostic syntax highlighter: split like gpu-lexer, classify every part with Jev, render Shiki-compatible tokens, HTML and ANSI
