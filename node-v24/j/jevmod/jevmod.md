# jevmod

> 标签: content-moderation, jev, moderation, spam, toxicity, typesafe

## 简介

Content moderation for user text, powered by Jev (TypeSafe System One): spam, scam, harassment, adult content, off-topic, self-harm, doxxing, minors, plus your own rules in plain language.
