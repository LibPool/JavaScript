# jaegerize-xray

> 标签: aws, jaeger, opentelemetry, tracing, x-ray, xray

## 简介

Fetch AWS X-Ray traces by ID and emit Jaeger UI JSON. Accepts Jaeger-format trace IDs straight from the Jaeger UI.
