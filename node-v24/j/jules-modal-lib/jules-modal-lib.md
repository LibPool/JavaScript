# jules-modal-lib

> 标签: JavaScript

## 简介

Une simple librairie React permettant d’afficher une **fenêtre modale** réutilisable et personnalisable.   Elle gère l’ouverture/fermeture, un titre optionnel, un bouton de fermeture et le rendu de contenu enfant.
