# jira-flow-cli

> 标签: atlassian, automation, cli, ghcp, github-copilot, jira, mcp, mcp-server

## 简介

Jira workflow CLI and MCP server - read tickets, create sub-tasks, manage transitions and comments. Integrates with GitHub Copilot without Atlassian MCP overhead.
