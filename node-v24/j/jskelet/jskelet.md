# jskelet

> 标签: esbuild, express, islands, isr, jsk, seo, ssr, tailwind

## 简介

A framework that feels like no framework: Express 5 + build-time .jsk SSR (optional EJS peer), vanilla JS islands, Tailwind v4 and an in-process HTML TTL cache.
