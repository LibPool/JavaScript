# joyagent-mcp

> 标签: agent, joyagent, joyagent-mcp, mcp

## 简介

JoyAgent MCP 是调用[JoyAgent](https://joyagent.jd.com/) 智能体服务进行交互。允许用户通过 MCP 协议调用各种智能体功能，如油价查询、等智能体中的服务等。
