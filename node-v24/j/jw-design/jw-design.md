# jw-design

> 标签: JavaScript

## 简介

`jw-design` 是一个基于 Vue 3 和 Arco Design Vue 的现代化 UI 组件库，旨在提供高度可定制、易于使用的组件，适用于各种 Web 应用开发场景。所有组件支持 TypeScript、响应式设计和全局配置，满足企业级开发需求。
