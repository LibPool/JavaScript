# jun-db

> 标签: atomic-writes, binary-storage, database, db, document-store, embedded-database, jun, jun-db, lru-cache, nosql, persistence, proxy-database, sharding, v8-serialization, zero-dependency

## 简介

Transparent JavaScript object persistence using Proxies and binary storage. Features automatic sharding, atomic I/O, and LRU caching with zero dependencies.
