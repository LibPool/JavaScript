# joplin-plugin-typora-like-editor

> 标签: joplin-plugin

## 简介

为 Joplin 提供 Typora 用户喜欢的 Markdown 风格文档导出功能，支持完善的元数据处理和资源管理。我的典型使用场景是与 Typora 软件搭配使用，主要用于日常笔记文档撰写，借助其简洁界面与高效编辑功能，提升文字处理与排版效率。Joplin负责笔记整理，备份和同步。
