# jquery-xdomainajax

> 标签: JavaScript

## 简介

This small mod for jQuery enables you to make GET requests, accross domains! You can use jQuery's Ajax methods as you usually would.

## 官网

- npm 页面：https://www.npmjs.com/package/jquery-xdomainajax
