# julia-system-one

> 标签: classifier, decision-engine, guardrails, inference, jev, julia, multilingual, native, system-one, triage, typesafe, wasm

## 简介

Self-contained System 1 decision engine: multilingual INT8 transformer served by a zero-dependency native binary (or the bundled pure-Rust WASM engine). TypeSafe Jev wire-compatible (/v1/systemone). Runs offline in Node.js, Bun and browsers.
