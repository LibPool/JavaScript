# jase-tunnel

> 标签: jase-tunnel, llm, lm-studio, local-ai, mcp, ollama, tools

## 简介

Connect visitors’ local LLMs to your website with Jase Tunnel: install the manifest, broker and panel with one command. Optional MCP tools adapter.
