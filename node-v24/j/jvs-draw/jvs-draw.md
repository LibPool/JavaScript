# jvs-draw

> 标签: JavaScript

## 简介

`jvs-draw` 是一个基于 Vue 3 和 Element Plus 开发的轻量级虚拟白板（Virtual Whiteboard）组件。它可以轻松集成到您的 Vue 3 项目中，提供流程图绘制、草图绘制和自由书画等功能。
