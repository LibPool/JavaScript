# jslice

> 标签: JavaScript

## 简介

[`jslice`](https://www.npmjs.com/package/jslice) is a small `JavaScript/TypeScript` library for slicing arrays using `slice strings`. The `slice` syntax is heavily inspired by its counterpart in `python`.
