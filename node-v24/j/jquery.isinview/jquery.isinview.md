# jquery.isinview

> 标签: container, display, dom, element, hidden, hide, jquery, jquery-plugin, nested, overflow, recursive, scroll, scrollbar, show, view, viewport, visibility, visible, window

## 简介

Detects if elements are in view - inside of the viewport, an iframe, or other containers. Extremely fast.
