# jquery-common-keydown

> 标签: a11y, accessibility, ebay, ecosystem:jquery, jquery-plugin

## 简介

jQuery collection plugin that triggers events for common accessibility keys e.g. ENTER, SPACE, ESC, ARROW KEYS.
