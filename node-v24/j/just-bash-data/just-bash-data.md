# just-bash-data

> 标签: agent-shell, document-database, encryption, just-bash, jwt, llm-tools, mongodb-style, rag, rbac, vector-search

## 简介

just-bash plugin: db (MongoDB-style document store) and vec (vector similarity search) commands for in-shell agents.
