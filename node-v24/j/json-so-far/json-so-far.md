# json-so-far

> 标签: ai, anthropic, incomplete, json, json-repair, llm, openai, parser, partial, partial-json, repair, stream, streaming, structured-output, truncated

## 简介

Best-effort parser for JSON that hasn't finished arriving. Render streaming LLM output before the closing brace shows up. Zero dependencies, never throws.
