# jsonql-ws-server

> 标签: Websocket, jsonql, socket.io, ws

## 简介

Setup WebSocket server for the jsonql to run on the same host, automatic generate public / private channel using contract

## 官网

- 官网：http://jsonql.org
- 源码仓库：git+ssh://git@gitee.com:to1source/jsonql.git
- npm 页面：https://www.npmjs.com/package/jsonql-ws-server
