# jiliui

> 标签: component, components, tailwindcss, vue

## 简介

- 基于 vue + tailwind 开发的组件库。 - 提供原子类和组件类，在非vue的前端项目(默认使用了tailwindcss)下也能使用 - css 导出为 tailwind 插件，可以接入 tailwind 的代码补全
