# jcode-ui

> 标签: agent, ai, assistant-ui, chat, chatbot, components, copilot, llm, react, ui

## 简介

React AI chat UI components — styled, token-driven, backend-agnostic. Streams messages, tool calls, approvals, and ask-user interactions.
