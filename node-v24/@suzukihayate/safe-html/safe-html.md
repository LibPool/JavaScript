# @suzukihayate/safe-html

> 标签: contextual, escape, html, sanitize, security, tagged-template, template-literal, xss, zero-dependency

## 简介

文脈（HTML/属性/URL）を理解して自動エスケープする、依存ゼロのタグ付きテンプレート。フレームワーク不要でXSSを防ぐ。
