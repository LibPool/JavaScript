# @atlasauth/pca-authzen

> 标签: agent authorization, ai agents, authorization api, authzen, openid, pca, pdp, proof-carrying authority

## 简介

AuthZEN PDP for PCA: expose the PCA verifier/policy engine behind the OpenID AuthZEN Authorization API (subject/action/resource/context) with the COAZ MCP-tool and AARP approval profiles, so any AuthZEN PEP can use PCA as its decision point.
