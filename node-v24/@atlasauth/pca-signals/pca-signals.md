# @atlasauth/pca-signals

> 标签: agent authorization, ai agents, caep, pca, proof-carrying authority, rfc 8417, security event tokens, shared signals, ssf

## 简介

Shared Signals Framework (CAEP/SSF) for PCA: build + verify Security Event Tokens (RFC 8417) for grant revocation and mid-run kill-switch propagation to in-flight agents.
