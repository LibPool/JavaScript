# @atlasauth/cli-banner

> 标签: JavaScript

## 简介

The animated Atlas mark for CLIs — a real-time 3D software renderer (z-buffer, Lambert + specular, luminance ASCII ramp, truecolor) that spins the Atlas diamond-on-tile logo in the terminal. TTY-only, CI-safe, NO_COLOR-aware.
