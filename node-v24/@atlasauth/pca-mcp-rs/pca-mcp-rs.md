# @atlasauth/pca-mcp-rs

> 标签: agent authorization, ai agents, mcp, oauth, pca, proof-carrying authority, resource server, rfc 8707, rfc 9728

## 简介

MCP authorization resource-server for the 2026-07-28 spec: serve RFC 9728 PRM + Client-ID Metadata Documents, enforce RFC 8707 resource indicators + RFC 9207 issuer validation + scope accumulation, and wire PCA FROST step-up into the MCP step-up challenge
