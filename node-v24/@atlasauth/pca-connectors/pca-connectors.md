# @atlasauth/pca-connectors

> 标签: agent authorization, ai agents, connectors, manifest, oauth, pca, proof-carrying authority, saas

## 简介

Declarative outbound connector registry for PCA: provider manifests (auth URLs, scopes, refresh, token placement) for the top SaaS tools + an auto-refresh helper, so every vault connector call is a proof-carrying capability.
