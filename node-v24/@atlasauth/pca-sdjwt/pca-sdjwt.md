# @atlasauth/pca-sdjwt

> 标签: agent authorization, ai agents, jwt, pca, proof-carrying authority, sd-jwt, selective disclosure

## 简介

SD-JWT serialization of a PCActn for PCA: emit/verify a PCActn (and its capability claims) as a selectively-disclosable SD-JWT so PCA proofs drop into existing JWT/SD-JWT verifiers and align with WIMSE / AP2 mandate shape.
