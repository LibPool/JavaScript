# @atlasauth/agent-toolkit

> 标签: JavaScript

## 简介

Safe, scoped Atlas identity tools for AI agents — the Atlas peer of `@clerk/agent-toolkit`. It wraps the [`@atlasauth/backend`](../backend) management client and exposes its operations as framework-native tools for the **Vercel AI SDK** and **LangChain**.
