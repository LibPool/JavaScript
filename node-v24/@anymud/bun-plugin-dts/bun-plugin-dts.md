# @anymud/bun-plugin-dts

> 标签: automatic-dts, bun, bun-build-plugin, bun-build-system, bun-build-tool, bun-development, bun-javascript, bun-js, bun-plugins, bun-typescript, code-generation, definition-files, dts, dts-generator, js-to-ts, type-definitions, typescript, typescript-definitions, typescript-plugin, typescript-support

## 简介

This Bun.build plugin leverages `dts-bundle-generator` to automatically generate TypeScript definition files (`.d.ts`) for projects. It's designed to make your development process smoother by ensuring your project is strongly typed with TypeScript support
