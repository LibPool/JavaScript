# @bramas/simulant-core

> 标签: JavaScript

## 简介

Shared project interfaces and configuration-graph traversal for Simulant. These contracts connect the simulator interface, project adapters, graph workers and CLI. Simulation semantics and exploration are implemented in `@bramas/simulant-engine`.
