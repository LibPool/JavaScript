# @bramas/simulant-stdlib

> 标签: JavaScript

## 简介

`@bramas/simulant-stdlib` supplies the model families, components, sensors and tasks used by Simulant experiments. It is installed with the compiler and CLI. Start a standalone project with `npm create @bramas/simulant@latest my-project`.
