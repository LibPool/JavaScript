# @bramas/simulant-ui

> 标签: JavaScript

## 简介

SolidJS interface for Simulant experiments: interactive execution navigation, adversary choices, settings and presets, state inspection, algorithm source highlighting, configuration graphs, and a view of the model and generated Lean.
