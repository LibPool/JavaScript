> 标签: conference, gb28181, meeting, monitoring, mqtt, recording, screen-share, video-call, video-on-demand, vod, voice-call, web-component, webrtc

## 简介

Native Web Components for 1:1 audio/video calls, multi-window VOD/monitoring (with voice intercom) and multi-party video meeting (rooms, layouts, host controls, screen share, local recording). MQTT signaling + WebRTC. Works with Vue2/Vue3/React/vanilla.
