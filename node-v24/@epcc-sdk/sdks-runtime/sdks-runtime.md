# @epcc-sdk/sdks-runtime

> 标签: authentication, backoff, client-credentials, elastic-path, oauth, retry

## 简介

Service-agnostic runtime helpers for the Elastic Path generated SDKs: token providers, storage adapters, a caching token source, a retry wrapper with backoff, and a client factory that wires them together.
