# @meridui/tokens

> 标签: color, css-custom-properties, css-variables, dark-mode, design-system, design-tokens, dtcg, figma, merid, react, spacing, style-dictionary, theming, tokens, tokens-studio, typescript, typography, w3c-design-tokens

## 简介

Merid design tokens as W3C DTCG JSON, typed JavaScript, CSS custom properties and a Tokens Studio file for Figma, with light, dark, accent and density modes.
