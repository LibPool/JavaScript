# @addozhang/dsh-3d-model-viewer

> 标签: JavaScript

## 简介

Interactive STL/3MF viewer plugin for the DeepSeek Harness Web GUI: sidebar document preview, live session drawer, CAD navigation, orthographic dimension labels, 3MF part colors.
