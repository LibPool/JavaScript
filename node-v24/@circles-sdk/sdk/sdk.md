# @circles-sdk/sdk

> 标签: JavaScript

## 简介

The Circles SDK is a TypeScript library designed to simplify the interaction with the [Circles V1](https://github.com/circlesUBI/circles-contracts) as well as with [Circles V2](https://github.com/aboutcircles/circles-contracts-v2).
