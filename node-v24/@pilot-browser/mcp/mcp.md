# @pilot-browser/mcp

> 标签: ai-agent, browser-automation, chrome, claude, mcp, model-context-protocol, prompt-injection

## 简介

MCP server that lets AI agents drive your real, logged-in browser: visible cursor, takeover, handoff, approvals, origin allowlist.
