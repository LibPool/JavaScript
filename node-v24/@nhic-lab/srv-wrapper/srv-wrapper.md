# @nhic-lab/srv-wrapper

> 标签: ai-agent, audit-log, cli, daemon, server-management, ssh

## 简介

Local daemon + CLI that lets AI agents run commands on registered servers by an opaque server-id only, never seeing real hostnames or credentials.
