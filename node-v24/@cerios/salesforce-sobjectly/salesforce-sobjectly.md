# @cerios/salesforce-sobjectly

> 标签: api, bulk-api, cerios, codegen, composite, crm, rest, salesforce, sobject, soql, sosl, tooling-api, type-safe, typescript

## 简介

Type-safe Salesforce REST API client for TypeScript. Generated SObject types, a typed SOQL builder, CRUD, composite, sObject collections, SOSL, invocable actions/Flow, Tooling API and Bulk API 2.0.
