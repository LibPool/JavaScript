# dsh-longterm-memory

> 标签: agent-memory, deepseek-harness, dsh, dsh-plugin, long-term-memory, markdown, memory, obsidian

## 简介

DSH Memory Vault (长期记忆) — durable local long-term memory for DeepSeek Harness, stored as an Obsidian-compatible Markdown vault with a rebuildable index, an in-sidebar management page, and real per-turn recall.
