# @plyvorastream/meeting

> 标签: chat, google-meet, hand-raise, livekit, meeting, react, recording, screen-share, video-conferencing, web-component, webrtc

## 简介

Developer-first video conferencing SDK for Plyvora: Google Meet-style meetings with LiveKit WebRTC, camera/mic, screen share, chat, hand raise, recording, layout modes, React component and Web Component.
