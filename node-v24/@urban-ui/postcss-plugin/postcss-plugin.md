# @urban-ui/postcss-plugin

> 标签: JavaScript

## 简介

Automatically discovers all `@urban-ui/*` packages (including transitive dependencies) and generates include paths for PostCSS StyleX compilation.

## 官网

- npm 页面：https://www.npmjs.com/package/@urban-ui/postcss-plugin

## 历史版本号

- 当前版本：0.2.0

- 0.2.0

## 获取地址

- npm 安装：`npm install @urban-ui/postcss-plugin`
- npm registry：https://registry.npmjs.org/@urban-ui/postcss-plugin
- Node 要求：>=18
