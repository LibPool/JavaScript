# @wuyuchentr/html-sanitize-lite

> 标签: clean, html, sanitize, sanitizer, security, xss

## 简介

Lightweight HTML sanitizer to prevent XSS. Keep safe tags, strip dangerous ones. < 2 KB, 90% lighter than DOMPurify.
