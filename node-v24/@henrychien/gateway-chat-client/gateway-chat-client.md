# @henrychien/gateway-chat-client

> 标签: JavaScript

## 简介

TypeScript client for the agent-gateway chat protocol. One owner for the client side of a chat session: init and resume, stored-identity reuse, the 401 refresh rule, the one-turn request body, SSE frame parsing, mid-turn subscribe reconnect, cancel, and t
