# @sessionguard/cli

> 标签: ai-coding, audit, claude-code, cursor, observability, secrets-scan, security, windsurf

## 简介

Security audit for local AI coding agent sessions (Claude Code, Cursor, Windsurf). Scans for leaked secrets, risky commands, and unsafe edits — all local, zero upload.
