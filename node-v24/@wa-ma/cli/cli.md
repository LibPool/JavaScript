# @wa-ma/cli

> 标签: agent, chatbot, cli, developer-tools, messenger, wama, whatsapp

## 简介

Interactive developer CLI for WAMA (WhatsApp Multi-Agent) to manage instances, link accounts, poll QR codes, send messages, and query logs.
