# wsl-notify

> 标签: notification, notifications, opencode, opencode-plugin, powershell, toast, windows, wsl

## 简介

Windows toast notifications for OpenCode — permission, question, session completion and error events. Zero dependencies, one entrypoint for OpenCode V1 and V2, works from WSL (powershell.exe interop) and native Windows.
