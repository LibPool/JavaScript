# @decision-keep/mcp

> 标签: ai-act, ai-governance, audit, decision-log, explainability, forensic, mcp, model-context-protocol, verification

## 简介

Model Context Protocol (MCP) server for Decision Keep's out-of-band forensic witness. Lets AI coding assistants, agents and orchestration frameworks natively verify decision trails without pipeline latency.
