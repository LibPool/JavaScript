# @open-pioneer-community/window

> 标签: open-pioneer-trails

## 简介

This package provides windowing system for draggable, resizable and closable UI widgets in Open-Pioneer Trails. This package uses [react-rnd](https://github.com/bokuweb/react-rnd) internally.
