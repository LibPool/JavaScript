# @mistflow-ai/cli

> 标签: ai, cli, coding, mistflow

## 简介

Mistflow CLI. Local execution commands (install, build, qa, dev) that complement @mistflow-ai/mcp: MCP handles API coordination, this CLI handles long-running local operations the MCP client's 60s timeout can't survive.
