# @apitoagents/sample-shop-mcp

> 标签: ecommerce, example, mcp, mcp-server, model-context-protocol, streamable-http

## 简介

MCP server exposing a sample shop API to ChatGPT, Claude and other agents: paginated search, idempotent orders, guarded cancellation. Official TypeScript SDK.
