# @2en/icons

> 标签: central-icons, clawly, design-system, expo, icons, react, react-native, svg, ui

## 简介

Clawly's standard icon library — central-icons re-exported for both React Native and Web, plus selectively vendored @2en/openai-icons glyphs and Clawly-custom additions.
