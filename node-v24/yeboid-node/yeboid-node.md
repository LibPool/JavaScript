# yeboid-node

> 标签: authentication, express, jwt, middleware, oauth2, oidc, openid, pkce, yebo, yeboid

## 简介

YeboID OAuth2 SDK for Node.js/Express — JWKS verification + auth middleware. Pairs with yeboid-web on the frontend.
