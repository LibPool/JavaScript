# @nolebase/markdown-it-bi-directional-links

> 标签: markdown, markdown-it, markdown-it-plugin, nolebase, nolebase-integration, readabilities, vitepress, vitepress-plugin

## 简介

A markdown-it plugin that adds Obsidian compatible internal links (bi-directional links) to your markdown.
