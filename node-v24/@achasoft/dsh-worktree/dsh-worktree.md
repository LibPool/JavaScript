# @achasoft/dsh-worktree

> 标签: branch-switcher, branches, cordis, deepseek-harness, dsh, dsh-plugin, git, git-worktree, worktree

## 简介

Git worktrees and branches for the DeepSeek Harness Web Client: a branch and worktree row above the composer that shows where the session is checked out, branch and worktree switching, and worktrees adopted as harness workspaces
