# @rahul_dadhich15/auth-jwt-toolkit

> 标签: auth, authentication, base64url, claims, json-web-token, jwt, jwt-decode, jwt-decoder, jwt-expiry, jwt-inspector, jwt-validator, token, typescript, zero-dependencies

## 简介

Production-ready, dependency-free TypeScript toolkit for decoding, validating, inspecting, and checking the expiration of JSON Web Tokens (JWTs).
