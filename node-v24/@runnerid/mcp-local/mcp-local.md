# @runnerid/mcp-local

> 标签: 2fa, ai-agents, browser-agents, cdp, login, mcp, mcp-server, runnerid, totp

## 简介

runnerID MCP server that runs next to an agent's browser and types logins and codes into it over local CDP. The model never sees the password.
