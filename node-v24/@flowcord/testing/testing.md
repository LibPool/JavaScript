# @flowcord/testing

> 标签: discord, discord-bot, discord.js, e2e, flowcord, headless, integration-testing, integration-tests, menu, mocks, simulator, test-harness, testing

## 简介

Headless harness for simulating and testing discord.js component interactions (buttons, selects, and modals) built with FlowCord.
