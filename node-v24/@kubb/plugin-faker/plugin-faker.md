# @kubb/plugin-faker

> 标签: code-generation, codegen, faker, faker.js, fakerjs, fixtures, kubb, meta-framework, mock-data, mocks, typescript

## 简介

Generate Faker.js mock data factories with Kubb. Produces realistic seed data and fixtures for development and testing.
