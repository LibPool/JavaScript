# @kubb/studio

> 标签: agent, codegen, kubb, openapi, studio, typescript, websocket

## 简介

Kubb Studio client runtime. Connects a Kubb project to Kubb Studio over WebSocket and streams code generation events, shared by the `kubb studio` CLI command and the Docker agent.
