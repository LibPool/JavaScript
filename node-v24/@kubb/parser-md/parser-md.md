# @kubb/parser-md

> 标签: codegen, frontmatter, kubb, markdown, meta-framework, parser, yaml

## 简介

Markdown source file parser for Kubb. Converts the universal AST to `.md` source and renders YAML frontmatter via the `print` helper.
