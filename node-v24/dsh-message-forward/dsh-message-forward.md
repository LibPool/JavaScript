# dsh-message-forward

> 标签: deepseek, deepseek-harness, dsh, dsh-plugin, forward, session

## 简介

Cross-session message forwarding for DeepSeek Harness: extract a user message, a model reply, or a multi-selected batch from one session and deliver it into another, with silent send, draft fill, or send-and-jump delivery.
