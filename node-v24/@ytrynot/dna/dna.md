# @ytrynot/dna

> 标签: ajv-alternative, bytecode, code-generation, compiler, dna, json-schema, performance, schema, typescript, validation, validator, zod

## 简介

Schema validation that compiles to standalone JS function. Zod-like API, serializable, portable, using DNA bytecodes
