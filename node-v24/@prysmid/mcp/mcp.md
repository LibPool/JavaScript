# @prysmid/mcp

> 标签: agents, auth, mcp, model-context-protocol, oidc, prysmid, zitadel

## 简介

Official Prysmid MCP server — manage workspaces, apps OIDC, login policy, IdPs, branding, users from any MCP-compatible agent (Claude Code, Cursor, etc.)
