# @sanity/workflow-studio-plugin

> 标签: sanity, sanity-io, sanity-plugin, studio, workflow, workflows

## 简介

Sanity Studio plugin for @sanity/workflow-engine: the form strip, a Workflows document view, stage badges, and the document-action lock.
