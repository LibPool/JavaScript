# @sanity/workflow-diagram

> 标签: diagram, react, sanity, sanity-io, workflow, workflows

## 简介

React component rendering a workflow definition as a stage diagram — ELK layered layout, current-stage and visited-path highlighting, transition tooltips on line hover.
