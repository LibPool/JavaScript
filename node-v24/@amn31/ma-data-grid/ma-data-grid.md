# @amn31/ma-data-grid

> 标签: angular, conditions, datagrid, filter, multi, sequelize

## 简介

@amn31/ma-data-grid is an Angular component for presenting large and complex data. The table was designed to be flexible and light package. The features regarding filtering, sorting or paging are already available without creating additional code.
