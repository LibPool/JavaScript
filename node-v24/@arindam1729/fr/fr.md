# @arindam1729/fr

> 标签: ai, cli, code-search, codebase, developer-tools, file-search, jev, llm, semantic-search, typesafe

## 简介

Ask a question about a codebase, get the files that matter. Every file gets a fast relevant/maybe/irrelevant decision from TypeSafe's Jev, streamed live as you type.
