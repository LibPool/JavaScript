# kastorflow-mcp

> 标签: agent, claude, kastorflow, mcp, model-context-protocol, notebooklm

## 简介

Connect AI agents (Claude, Cursor and others) to KastorFlow for NotebookLM over MCP. Runs on your computer and talks only to the KastorFlow Chrome extension.

## 官网

- 官网：https://kastorflow.com
- npm 页面：https://www.npmjs.com/package/kastorflow-mcp

- 1.0.0

- npm registry：https://registry.npmjs.org/kastorflow-mcp
