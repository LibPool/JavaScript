# @vui-rs/core

> 标签: bun, ffi, renderer, rust, terminal, tui, vui-rs

## 简介

Native terminal rendering engine for vui-rs — a Rust cell buffer (truecolor, unicode, borders, taffy layout, images) driven from Bun via FFI.
