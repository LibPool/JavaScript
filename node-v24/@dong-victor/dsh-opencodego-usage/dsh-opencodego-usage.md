# @dong-victor/dsh-opencodego-usage

> 标签: balance, deepseek-harness, dsh, go, opencode, plugin, quota, usage

## 简介

opencode Go 套餐余额查看插件（DSH Web GUI）：侧边栏直接显示 rolling(5小时)/weekly(周)/monthly(余额) 三档用量进度条、百分比与重置时间，60s 自动刷新，无需点击；点击打开详情面板（倒计时、状态徽章、端点/密钥信息）；agent 工具 opencode_go_balance 可直接回答套餐用量。密钥默认取 llm-pi-ai 的 opencode-go 路由 apiKeyEnv（OPENCODE_GO_API_KEY，官方 opencode 模型专用密钥
