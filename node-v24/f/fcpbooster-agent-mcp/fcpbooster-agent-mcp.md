# fcpbooster-agent-mcp

> 标签: agent, fcpbooster, final-cut-pro, mcp, papercut-pro, subtitle-wrangler

## 简介

Local bridge for FCPBooster (Subtitle Wrangler and PaperCut Pro): stdio MCP tools plus a loopback HTTP door for shell clients (sw-call). The page connects to it directly; no browser extension is involved.
