# fluxo-ui

> 标签: accessible, calendar, data-grid, design-system, drag-and-drop, gantt-chart, kanban-board, pivot-table, react-component-library, react-ui-kit, report-builder, rich-text-editor, state-management

## 简介

A comprehensive, accessible React component library built with TypeScript. Includes 100+ production-ready UI components, a custom state management solution, dependency injection container, 12 color themes, dark mode, and full keyboard navigation.
