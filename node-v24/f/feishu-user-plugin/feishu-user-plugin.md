# feishu-user-plugin

> 标签: agent, claude-code, feishu, im, lark, mcp, messaging, model-context-protocol, plugin, protobuf

## 简介

All-in-one Feishu MCP server + CLI tool for Claude Code / Codex / Cursor / scripts — 85 tools across 3 auth layers (cookie / app / OAuth). Send as you, read groups, manage docs / bitable / wiki / drive / calendar / tasks / OKR.
