# file-concat-tool

> 标签: AI, CLI, NLP, TSX, TypeScript, automation, code analysis, code extraction, context window, developer tool, file concatenation, machine learning, prompting

## 简介

A tool for generating context windows for AI prompting by recursively searching for .ts and .tsx files and concatenating their contents into a text file.
