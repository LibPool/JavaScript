# flow-strip-migrate

> 标签: babel, babel-plugin-transform-flow-strip-types, codemod, flow, flow-to-typescript, migration, typescript

## 简介

Automated migration tool: replace babel-plugin-transform-flow-strip-types with the maintained fork, and optionally migrate Flow annotations to TypeScript.
