# figma-rust-mcp

> 标签: ai, ai-to-figma, antigravity, claude, claude-code, claude-to-figma, code-to-figma, cursor, design, design-to-code, figma, figma-automation, figma-bridge, figma-mcp, figma-plugin, mcp, model-context-protocol, plugin, ui-generation, vscode, windsurf

## 简介

Claude Code to Figma — Bidirectional MCP bridge. AI draws UI on Figma canvas, reads designs back. Works with Claude, Cursor, VS Code, Windsurf, Antigravity. No API key needed.
