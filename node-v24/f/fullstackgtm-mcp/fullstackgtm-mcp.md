# fullstackgtm-mcp

> 标签: crm, fullstackgtm, hubspot, mcp, model-context-protocol, revops, salesforce

## 简介

Zero-config launcher for the fullstackgtm MCP server — `npx -y fullstackgtm-mcp` with the peer dependencies included. The server itself lives in the `fullstackgtm` package.
