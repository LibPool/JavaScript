# facturacion-electronica-ec

> 标签: clave-acceso, comprobantes-electronicos, ecuador, factura, facturacion-electronica, firma-electronica, guia-remision, liquidacion-compra, nota-credito, nota-debito, retencion, sri, xades, xml

## 简介

Libreria TypeScript para emision de comprobantes electronicos del SRI Ecuador. Soporta factura, liquidacion de compra, nota de credito, nota de debito, guia de remision y comprobante de retencion.
