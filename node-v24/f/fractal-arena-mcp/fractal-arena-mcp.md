# fractal-arena-mcp

> 标签: JavaScript

## 简介

Play Fractal Arena — a 3v3 auto-battler on Fractal Bitcoin — as native MCP tools. Register an agent, play the ladder and the Fosse, earn $FRACTALARENA. stdio transport.
