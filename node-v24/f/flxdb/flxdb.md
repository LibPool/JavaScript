# flxdb

> 标签: backup, database, eventemitter, file-database, flxdb, json, json-db, key-value, kv, lightweight-db, localdb, namespaces, nodejs, persistent, schema-validation, storage, transactions, ttl, typescript, watch

## 简介

A lightweight, fast and persistent key-value database for Node.js with namespaces, TTL, JSON schema validation, transactions, watch/unwatch, backup/restore and EventEmitter support.
