# fast-alert

> 标签: alert, banner, browser, lightweight, message, notification, popup, snackbar, toast, typescript, vanilla, zero-dependency

## 简介

Ultra-lightweight, zero-dependency toast & alert library for the browser. Typed, accessible, stackable — one function, no CSS import.
