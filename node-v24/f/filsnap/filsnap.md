# filsnap

> 标签: dapp, fevm, filecoin, metamask, plugin, snap, wallet

## 简介

Connect to Filecoin dapps using Metamask. Manage Filecoin accounts, send FIL to Native and FEVM accounts and enable FEVM transaction insights.
