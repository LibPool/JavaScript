# forge-orchestrator

> 标签: ai-coding, git-worktree, multi-agent, opencode, orchestrator, parallel, pipeline

## 简介

opencode 并行编程编排器：一句话需求 → 契约先行 + 多 worker 隔离并行 + 完成即合并 + 闸门自愈，产出通过全部验收测试的代码。自带 Web 控制台，一键使用。
