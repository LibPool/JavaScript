# flutter-driver-mcp

> 标签: ai, flutter, integration-test, llm, mcp, model-context-protocol, testing

## 简介

An MCP server that lets AI agents drive Flutter apps — tap, type, scroll, assert, and screenshot live UIs via WebSocket.
