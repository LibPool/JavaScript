# flutter-appium-node

> 标签: appium, appium-webdrivrio, flutter appium automation, flutter appium node, flutter driver, flutter element finder, flutter-appium, flutter-finder, flutter-node-automation, npm

## 简介

This library helps to find the flutter elements present on the flutter app build, and later any action can be perfomed on that element using the webdriverIo driver.
