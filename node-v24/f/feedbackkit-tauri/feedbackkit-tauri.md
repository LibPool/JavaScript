# feedbackkit-tauri

> 标签: annotation, bug-report, feedback, feedbackkit, screenshot, tauri

## 简介

In-app feedback for Tauri apps: FeedbackKit's web SDK plus real OS/device/app details and a native menu trigger from tauri-plugin-feedbackkit.
