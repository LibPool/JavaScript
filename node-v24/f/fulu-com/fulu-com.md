# fulu-com

> 标签: JavaScript

## 简介

fulu-ui是基于react+typescript技术栈进行快速开发业务组件的演示项目(你也可以不用ts)，源于`father-build`提供的打包功能，支持 cjs、esm 和 umd 三种格式的打包，内置支持 css 和 less，支持开启 css modules等特性。此外采用dumi负责编写组件文档，支持组件预览。
