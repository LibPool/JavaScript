# fc-designer

> 标签: JavaScript

## 简介

* 新增样式文件请添加到根目录下style.js   * 打完包发布到公有仓库或者私有仓库   * 项目中引用的时候需要引入fc-designer/asset/designer.css * 组态js文件缺失需要手动添加按需添加 * 引入整个模块需要DeignerModule  引入组件需要引入DesignerMainModule
