# firebase-kit-client

> 标签: callable, client, cloud-functions, connectivity, firebase, firebase-kit, firestore, keepalive, rate-limit, testing, typescript

## 简介

Client-side Firebase toolkit: typed callable functions including fire-and-forget keepalive callables, Firestore helpers, connectivity handling, rate limiting, and test mocks.
