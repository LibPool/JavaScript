# flowproof

> 标签: ai-agents, automation, citrix, sap-gui, test-automation, testing, windows

## 简介

Test that a bot only ever does the job it was given — and never deletes, sends or approves the thing it must not. Record it doing the job once, then replay on every commit with zero LLM calls. For the agents and RPA already running real work in production
