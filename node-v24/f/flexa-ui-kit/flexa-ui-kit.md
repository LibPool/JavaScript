# flexa-ui-kit

> 标签: accessible, component-library, design-system, flexa, react, ui-kit, wcag

## 简介

Flexa UI — a React component kit built on the Flexa Design System (flexa-design-system). Token-only CSS, WCAG-gated, one component per file. Depends one-way on FDS; never imports the Flexa Builder core.
