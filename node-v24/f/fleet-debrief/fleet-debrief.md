# fleet-debrief

> 标签: agent-observability, ai-agents, claude-code, cli, cost-tracking, debugging, llm, local-first, observability, run-diff, session-replay, token-usage

## 简介

The morning debrief for your AI agent fleet: what ran, what it cost, what it touched, and a diff between any two runs. Local-only, zero-config, reads what Claude Code already writes to disk.
