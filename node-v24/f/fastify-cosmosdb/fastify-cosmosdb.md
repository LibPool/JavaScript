# fastify-cosmosdb

> 标签: azure, cosmosdb, fastify, nosql

## 简介

This Fastify plugin interogates your CosmosDb account to determine which containers are available and provides quick access through a Fastify Instance decoration. This plugin integrates with [@azure/cosmosdb](https://www.npmjs.com/package/@azure/cosmos) a
