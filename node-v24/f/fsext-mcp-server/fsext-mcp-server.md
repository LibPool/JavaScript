# fsext-mcp-server

> 标签: MCP SSE, MCP server tool, MCP stdio, MCP streamable-http, file read, file replace, file search, file write, filesystem mcp server, image OCR, image crop, image resize, image rotate

## 简介

Extended filesystem MCP toolkit with file I/O, directory operations, image processing and OCR. Supports stdio, SSE and streamable-http transports.
