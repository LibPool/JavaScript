# fluxapi-cli

> 标签: api, cli, curl, fluxapi, httpie, rest, restful

## 简介

A lightweight, cross-platform command-line interface for interacting with APIs. Built as a companion to the FluxAPI Desktop client, it allows developers and testers to send HTTP requests, inspect responses, and manage API workflows directly from the termi
