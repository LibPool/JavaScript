# ftx-ui

> 标签: JavaScript

## 简介

-   这是一个基于 Vue 3 + TypeScript 的 UI 库，涵盖了 Button、Switch、Dialog、Tabs 等常见 UI 组件。 -   深入研究 Vue 3，使用了 setup、onMounted、watchEffect、ref、computed 等 Compositioin API     模块化的源代码简洁明了，易于阅读。 -   推出[官方文档](https://fengtx.tk/ftxui-website/index.html#/)，可在线查看示例代码，并支持 PC
