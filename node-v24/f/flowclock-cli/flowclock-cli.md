# flowclock-cli

> 标签: agent-native, cli, flowtime, hud, mcp, productivity, stopwatch, terminal, time-tracking, timer

## 简介

Flowtime count-up terminal timer (HUD, not Pomodoro) with silent session logging — agent-native, like gh and vercel.
