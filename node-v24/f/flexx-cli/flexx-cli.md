# flexx-cli

> 标签: agent, audit, ethereum, foundry, llm, reentrancy, security, smart-contract, solidity, static-analysis, web3

## 简介

npx launcher for flexx: an agentic Solidity auditor that proves every finding with an executable Foundry PoC. Wraps the Python CLI (requires Python 3.11+ and Foundry).
