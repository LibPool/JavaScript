# fluxplugin

> 标签: architecture, cli, electron, extensions, plugin, plugins, react, typescript

## 简介

Plugin architecture for Electron + React + TypeScript. Build apps that others can extend: routes, menus, commands, UI slots, IPC, hooks, permissions — with a CLI.
