# feed-media-fork

> 标签: atom, blog, feed, rss, syndication, wrapper, xml

## 简介

Feed Media is a fork of the Feed npm library (a RSS, Atom and JSON feed generator for Node.js) with added support for media elements such as used by podcasts.
