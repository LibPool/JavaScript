# formulyze

> 标签: chemistry, formula, katex, latex, math, mathjax, physics, react, search, semantic-search

## 简介

Local-first, open-source name→LaTeX formula search. Type a concept, get correct LaTeX + a rendered image, instantly, offline, free. Math, physics, astrophysics, chemistry.
