# free-image-source

> 标签: attribution, creative-commons, esm, image-search, license-compliance, open-license, public-domain, typescript, wikimedia, wikimedia-commons, wikipedia, zero-dependencies

## 简介

Find a freely-licensed Wikimedia image for anything, with the attribution needed to publish it. Zero dependencies.
