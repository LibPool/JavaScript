# form-design-components

> 标签: JavaScript

## 简介

一个功能强大的基于 Vue 3、Element Plus 和 Vant 的表单设计器组件库，提供字典管理、表单管理、表单模板管理和属性配置四个核心模块，帮助开发者快速构建和管理复杂的表单系统。
