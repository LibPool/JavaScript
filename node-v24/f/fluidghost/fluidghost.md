# fluidghost

> 标签: exif, fluidghost, image, metadata, sdk, uniquify, video

## 简介

Official TypeScript/JavaScript client for the FluidGhost API. Spoof a photo, video, or carousel with your API key and get back distinct variants with device-authentic metadata — submit, poll, download.
