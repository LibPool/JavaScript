# flagrm

> 标签: agent-skills, ai-agent, angular, claude-code, cli, codex, copilot, dotnet, feature-flags, feature-toggles, flag-removal

## 简介

Guardrails for removing feature flags with AI coding agents (Claude Code, Copilot, Codex): skills, a baseline, a verify gate and a Stop hook.
