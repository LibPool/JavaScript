# facetful

> 标签: analytics, browser, cli, columnar, csv, facets, opfs, parquet, sql, wasm

## 简介

Tiny columnar SQL engine for browser faceting — Rust/wasm, ~240KB gz, zero dependencies. Open Parquet or CSV instantly, facet 1M rows in milliseconds, persist to OPFS; one install gives the library and the `facetful` command.
