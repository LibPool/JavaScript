# forma-css

> 标签: classless, css, eco-friendly, framework, light-dark, no-javascript, oklch, pico, sass, scss, semantic-html

## 简介

A low-footprint, classless SCSS microframework for semantic HTML. Zero JavaScript. Born as the successor of Pico CSS.
