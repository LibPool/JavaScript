# ficta

> 标签: browser, cli, csv-generator, data-generator, excel-generator, fake-data, faker, json-generator, mock-data, nodejs, sql-generator, test-data, test-data-generator, toml-generator, xml-generator, yaml-generator

## 简介

Universal test data generator for Node.js, browsers, and CLI. Generate realistic test data in multiple formats (CSV, JSON, XML, Excel, TSV, SQL, YAML, TOML) using Faker.js.
