# fibx

> 标签: agent, ai, base, claude-desktop, cli, defi, fibrous, hyperevm, mcp, mcp-apps, monad, skills, swap, wallet, walletconnect

## 简介

Zero-dependency CLI and MCP server for DeFi on Base, HyperEVM, and Monad — Fibrous aggregation, your own wallet over WalletConnect, a local signing policy, and the FibX app as MCP Apps UI.
