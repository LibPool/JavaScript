# fabricjs-document-engine

> 标签: autosave, canvas, canvas editor, copy paste, custom objects, custom properties, design editor, export image, export pdf, export svg, fabric, fabric js, fabric.js, fabricjs, fabricjs editor, history, image editor, import svg, indexeddb, layers, load from json, loadfromjson, nextjs, object id, pdf, react, react hooks, recovery, redo, save canvas json, serialization, svelte, text on path, tojson, typescript, undo, undo redo, vue

## 简介

Fabric.js save and load, undo and redo, and autosave for an existing canvas: stable object ids, custom objects, copy and paste, SVG import, PNG, SVG and PDF export, and recovery.
