# fileuploadtool

> 标签: JavaScript

## 简介

## 安装     npm i -g @gswl/fileuploadtool ## 使用     servepath:服务器上传地址 必传     filepath: 上传文件甲路径     cfg: 判断是否在上传文件夹中创建.gsupload配置文件，默认 {server:serverpath , ignore:[], useGitignore: true}     fileupload -s <servepath> -f [filepath] --cfg
