# fr-lightbox

> 标签: gallery, image-viewer, lightbox, swipe, typescript, vanilla-js, zoom

## 简介

A dependency-free, vanilla TypeScript lightbox with pinch-to-zoom, panning, swipe navigation, and keyboard controls.
