# feishu-agent-bridge

> 标签: agent, ai, chatbot, claude, cursor, feishu, lark, webhook, websocket, 飞书, 飞书机器人

## 简介

飞书/Lark 与任意 AI Agent 的 Node.js 桥接（WebSocket / HTTP Webhook、消息收发）；可与 Cursor Headless、Claude Code、自建服务等集成
