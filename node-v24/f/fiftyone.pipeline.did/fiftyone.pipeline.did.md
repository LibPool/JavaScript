# fiftyone.pipeline.did

> 标签: 51degrees, 51did, fodid, owid, pipeline

## 简介

Strongly typed reader for the 51Did (51Degrees Identifier) value returned by the 51Degrees Cloud service. Parses the OWID envelope and exposes the usage, licence id, match key and terms document plus the identifier type. Compare match keys, never envelope
