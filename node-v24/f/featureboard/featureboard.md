# featureboard

> 标签: canny-alternative, express, feature-request, feedback, mongodb, mongoose, product-board, roadmap, self-hosted, upvote

## 简介

Embedded, MongoDB-backed feature request board for Node.js. One-vote-per-user upvoting, comments, status triage, and two React UIs you mount inside your Express app.
