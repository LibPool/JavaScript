# friday-gmail-cli

> 标签: agent, ai-agents, claude, cli, draft, email, gmail, inbox, no-send, triage

## 简介

A zero-dependency Gmail CLI for AI agents that structurally cannot send email. It reads, labels, and drafts; a human clicks send.
