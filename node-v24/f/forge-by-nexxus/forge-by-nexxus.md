# forge-by-nexxus

> 标签: boilerplate, cli, generator, react, scaffold, spring-boot, template, typescript

## 简介

Scaffolds React, Spring Boot and Python projects that build before you touch them. Versions and structure are decided, and add-ons you decline leave nothing behind.
