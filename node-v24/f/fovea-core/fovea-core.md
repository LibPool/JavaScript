# fovea-core

> 标签: accessibility, bionic-reading, fixation, fixation-point, reading, speed-reading, text, typography

## 简介

Fixation-point text emphasis: tokenizes prose into words with leading-stem lengths, and renders them to ANSI, HTML, or Markdown.
