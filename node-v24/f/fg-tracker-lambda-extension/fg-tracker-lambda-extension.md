# fg-tracker-lambda-extension

> 标签: aws-lambda, fg-tracker, lambda-extension, observability, telemetry-api

## 简介

Extensão externa da AWS Lambda para o FG Tracker: agrega a Telemetry API (invocações, erros, timeouts, cold starts, duração, memória, concorrência) e envia para POST /v1/ingest
