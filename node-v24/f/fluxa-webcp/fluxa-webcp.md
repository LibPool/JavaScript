# fluxa-webcp

> 标签: competitive programming, compiler, cp, cpp, debugger, js, ts, typescript, web

## 简介

ts interpreter for a competitive-programming-focused C++ subset, with AST-level step execution, full state inspection, and GCC/Clang-style diagnostics.
