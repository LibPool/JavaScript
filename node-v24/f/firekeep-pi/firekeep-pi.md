# firekeep-pi

> 标签: coding-agent, firekeep, mcp, memory, pi, pi-extension, self-hosted

## 简介

Firekeep hook bridge for the Pi coding agent — briefings in context, a hard-blocking pre-edit gate, and shared working state across every agent you run.
