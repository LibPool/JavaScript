# flowzap-mcp

> 标签: ai, claude, cline, codex, cursor, diagrams, flowzap, mcp, model-context-protocol, sequence-diagram, warp, windsurf, workflow, zed

## 简介

MCP server for FlowZap - Create workflow, sequence, architecture, and mind map diagrams via AI assistants. Works with Claude Desktop, Claude Code, Cursor, Windsurf, OpenAI Codex, Warp, Zed, Cline, Roo Code, Continue.dev, and Sourcegraph Cody.
