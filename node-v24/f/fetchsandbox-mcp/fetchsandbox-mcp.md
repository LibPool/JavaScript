# fetchsandbox-mcp

> 标签: agent-verification, api-sandbox, claude, cursor, idempotency, integration-testing, mcp, model-context-protocol, openapi, paddle, stripe, verification, webhook-testing

## 简介

A deterministic verification engine for agents. Fires the edge cases your sandbox never sends, then proves a fix: the same scenario fails on the old code and passes on the new.
