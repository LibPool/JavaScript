# fever-cookies-plugin

> 标签: GDPR, cookie consent, cookiebar, cookieless, cookies, data protection, privacy

## 简介

This plugin allows you to setup a fully customizable cookie bar, so the user can control which cookies want, following the best practices of GDPR compliance.
