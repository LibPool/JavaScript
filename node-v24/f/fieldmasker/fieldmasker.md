# fieldmasker

> 标签: data-masking, fieldmasker, gdpr, log-safe, logging, mask, object, password, pii, privacy, redact, sanitize, security, sensitive, token

## 简介

Mask sensitive fields (passwords, tokens, cards, SSNs) from any object before logging or sending to analytics. Zero dependencies.
