# fileflowhq

> 标签: cli, components, compress-image, convert-image, csv-to-json, file-upload, fileflowhq, image-compression, images-to-pdf, merge-pdf, pdf-to-image, react, shadcn, split-pdf, tailwind

## 简介

Add ready-made, private file tools to your React app: compress images, convert images, merge/split PDFs, PDF to images, images to PDF, CSV/JSON. Copies the components into your project, shadcn-style.
