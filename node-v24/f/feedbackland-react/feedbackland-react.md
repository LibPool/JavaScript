# feedbackland-react

> 标签: drawer, embed, feedback, feedbackland, in-app-feedback, popover, react, saas, user-feedback, widget

## 简介

Drop-in React feedback widget. Slide-in drawer or popover; embeds a Feedbackland board via iframe (or your self-hosted instance) and submits feedback through a hosted API.
