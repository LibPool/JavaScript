# futu-sdk

> 标签: futu, futu-api, futu-open, futu-open-api, futu-opend, futunn, node-futu-api, 富途

## 简介

futu-api 的高性能精简易用版；基于*.proto静态编译，提供高性能的多层封装但层层开放的易用接口，获取最原始最完整的量化数据；相较于Python, nodejs更接近Web, 从而轻而易举搭建一个可视化交易站点，这是进行可控量化交易的不二选择。
