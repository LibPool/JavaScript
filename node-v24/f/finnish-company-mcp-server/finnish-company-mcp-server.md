# finnish-company-mcp-server

> 标签: apify, claude, company, financials, finland, kaupparekisteri, kyc, mcp, model-context-protocol, prh, y-tunnus, ytj

## 简介

Open bridge to the hosted Finnish Company Lookup & Financials (PRH/YTJ) MCP server on Apify — look up any Finnish company, parsed financial statements, and registered notices from any MCP client using your own Apify API token.
