# farsight-mcp

> 标签: ai-agent, claude, claude-code, mcp, model-context-protocol, screenshot, vision

## 简介

farsight-mcp: the MCP server exposing fetch_image, so an agent anywhere with outbound HTTPS can see an image sent via the farsight CLI.
