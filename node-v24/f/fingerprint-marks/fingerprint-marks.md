# fingerprint-marks

> 标签: biometric, component, fingerprint, hand, react, tailwind

## 简介

A highly optimized React component library for rendering left/right hand images with configurable fingerprint hotspots. Built with performance in mind and fully compatible with Tailwind CSS.
