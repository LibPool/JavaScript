# fdic-call-report-api

> 标签: bank, call, call-report, callreport, data, fdic, fdic-insured, opensource, report

## 简介

Three functions to be incorporated into an api that allow a user to access call report data for any fdic insured bank.  Pre-requisite: an fdic api username and key.
