# fontsplit

> 标签: font, googlefonts, split, subset

## 简介

フォントファイルを GoogleFonts のように 120 個程のファイルへ分割し、サブセット化します。\ サブセット化したフォントファイルを使用するための fontface 用 css ファイルも同時に生成します。
