# face-guard

> 标签: authentication, camera, capture, detection, face, face-api, face-guard, faceguard, guard, identity, login, recognition, verification, webcam

## 简介

前端轻量级人脸识别与图像采集工具，基于 face-api.js 封装，支持自动检测、用户引导和 Base64 图像输出。
