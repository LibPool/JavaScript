# foundation-ai

> 标签: ai, antigravity, claude-code, context, copilot, cursor, llm, npx, opencode, scaffold, vscode

## 简介

Set up AI context continuity in any project — works with OpenCode, Cursor, VS Code, Claude Code, Antigravity, or any AI tool. Run with npx, no global install needed.
