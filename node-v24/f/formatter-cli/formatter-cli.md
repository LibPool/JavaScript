# formatter-cli

> 标签: JavaScript

## 简介

A Node.js CLI tool for formatting CSS, HTML, JavaScript, and JSON — extracted from the Chrome DevTools frontend formatter worker.

## 官网

- 源码仓库：https://source.chromium.org/chromium/chromium/src/+/main:third_party/devtools-frontend/src/front_end/entrypoints/formatter_worker/
- npm 页面：https://www.npmjs.com/package/formatter-cli

## 历史版本号

- 当前版本：1.0.0

- 1.0.0

## 获取地址

- npm 安装：`npm install formatter-cli`
- npm registry：https://registry.npmjs.org/formatter-cli
- Node 要求：>=16
