# forge-tree

> 标签: ascii, cli, directory, firebase, generator, monorepo, nextjs, scaffold, tree, turbo

## 简介

Interactive CLI to scaffold projects from an ASCII tree. Parses hierarchies, generates files/folders, runs smart detectors (Next.js, Firebase, npm init), and emits dotfiles/formatters.
