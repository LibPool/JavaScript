# firefly-audio-video

> 标签: adobe, audio-video, cli, dgr, firefly, firefly-services, hevc, mogrt, prores, render, sdk, video

## 简介

Node/TypeScript client for Adobe Firefly Services' audio/video (DGR) API — promises that resolve with the finished asset, native preset/.epr authoring, redacted logging, and an npx CLI.
