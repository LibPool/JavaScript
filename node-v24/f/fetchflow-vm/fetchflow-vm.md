# fetchflow-vm

> 标签: api-orchestration, async, automation, emscripten, execution, fetch, flow-control, high-performance, http, javascript, pause, production-ready, quickjs, requests, resume, scalable, serialization, state, vm, workflow

## 简介

A JavaScript execution environment that automatically pauses on fetch() calls, allows external HTTP processing, and resumes with injected responses
