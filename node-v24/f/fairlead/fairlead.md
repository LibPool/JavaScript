# fairlead

> 标签: agents, ci, command-line-utilities, development-tools, guardrails, hooks, testing

## 简介

Guardrails and a guided path for coding agents: rules enforced as the agent works, tests scoped to what a change can reach, capped project memory, and KPIs.
