# feishu-raw-card-to-dsl

> 标签: card, card-dsl, feishu, im, lark

## 简介

把飞书 im.message.get 的 raw_card_content 编辑器内部 envelope 转换为公开 JSON Schema 2.0 DSL，规避 user_card_content 丢失 column.padding 等字段的问题
