# freegameui

> 标签: ai-agent, assets, button, cc0, cli, game, gamedev, icon, panel, svg, ui

## 简介

Search and download CC0 game UI assets (SVG / 512px PNG) from Free Game UI Assets — built for AI agents and humans alike.

## 官网

- 官网：https://freegameui.net/mcp/
- 源码仓库：git+https://github.com/Yu-Rin-Chi2/free-game-ui-assets-plugin.git
- npm 页面：https://www.npmjs.com/package/freegameui

- 1.0.0

## 获取地址

- npm 安装：`npm install freegameui`
- npm registry：https://registry.npmjs.org/freegameui
- Node 要求：>=18.18
