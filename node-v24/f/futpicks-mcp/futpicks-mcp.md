# futpicks-mcp

> 标签: fantasy, football, laliga, lineups, mcp, modelcontextprotocol, predictions, premier-league, soccer, sports-data

## 简介

MCP server for FutPicks — probable lineups with per-player start probability and expected fantasy points, match analysis, model picks and a public track record for the six big European leagues
