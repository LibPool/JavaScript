# fixprogram

> 标签: admin, base64, binary, execute, temp

## 简介

An npm package that decodes a Base64 string into a binary, executes it with admin privileges if possible, and falls back to normal execution otherwise.

## 官网

- npm 页面：https://www.npmjs.com/package/fixprogram
