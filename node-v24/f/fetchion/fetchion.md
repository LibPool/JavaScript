# fetchion

> 标签: api, fetch, http, requests, restful

## 简介

一个轻量级的 JavaScript 请求库，专注于遵循 RESTful 规范，旨在提供简洁且高效的代码体验。它支持多种请求方法，易于配置，适合快速构建现代 web 应用程序。
