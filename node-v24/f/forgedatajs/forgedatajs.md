# forgedatajs

> 标签: cli, fake-data, faker, faker-alternative, generator, locale, mock, mock-data, react, schema, seed, test-data, typescript, zod

## 简介

A modern, modular, tree-shakable, zero-dependency fake data generator for TypeScript and JavaScript. A production-ready alternative to Faker.js with seedable output, 9 locales, Zod schema generation, React hooks and a CLI.
