# flow-pcc

> 标签: correlation, covariance, flow, flow.io, linear correlation, multivariate, pearson product moment correlation coefficient, readable, reduce, statistics, stats, stream, transform, variance, writable

## 简介

Reduce transform stream which calculates the Pearson product-moment correlation coefficient matrix of streamed numeric data.
