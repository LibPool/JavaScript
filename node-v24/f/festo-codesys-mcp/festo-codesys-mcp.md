# festo-codesys-mcp

> 标签: automation, cia-402, codesys, cpx, ethercat, festo, iec-61131-3, mcp, plc, plcopen, structured-text

## 简介

MCP server for Festo/CODESYS PLC engineering — IEC 61131-3 ST generation, validated PLCopen XML, embedded knowledge base (27 topics, 19 manuals, BM25 search), 38-block ST library, optional CODESYS IDE driving and hardware commissioning
