# fraud-check-ts

> 标签: cloudflare-warp, country-filter, fraud-detection, fraud-prevention, hosting-detection, icloud-relay, ip-api, ip-check, ip-geolocation, ip-validation, proxy-detection, security, typescript, vpn-detection

## 简介

A powerful TypeScript library for IP address fraud detection and validation. Detect proxies, VPNs, hosting IPs, and filter by country with support for custom whitelist rules.
