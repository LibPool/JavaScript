# forgeton-sdk

> 标签: automaton, blockchain, forgeton, restaking, shared-security, tolk, ton

## 简介

TypeScript SDK for ForgeTON — the shared-security staking pool for TON. Stake automatons, slash, receive AutomatonSync pushes.
