# finnhub-mcp

> 标签: ai, claude, financial, finnhub, market-data, mcp, model-context-protocol, stocks

## 简介

Model Context Protocol (MCP) server for Finnhub financial data. Launches the native finnhub-mcp server over stdio — no .NET SDK required.
