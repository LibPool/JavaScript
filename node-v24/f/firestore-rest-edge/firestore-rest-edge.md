# firestore-rest-edge

> 标签: cloudflare-workers, deno-deploy, edge, firebase, firestore, rest, vercel-edge, zero-dependency

## 简介

Minimal Firestore client over REST for V8 isolate runtimes (Cloudflare Workers, Vercel Edge, Deno Deploy) where firebase-admin's gRPC transport doesn't work.
