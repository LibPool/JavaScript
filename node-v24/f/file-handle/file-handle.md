# file-handle

> 标签: download, file, file-handle, http-server, preview, serve, server, share, transfer, upload, web-server

## 简介

A simple local web file server with a user-friendly interface, allowing easy file upload, download, preview, and management through a browser. 
一个简易的文件服务器，方便通过浏览器来浏览、上传或管理目录和文件.
