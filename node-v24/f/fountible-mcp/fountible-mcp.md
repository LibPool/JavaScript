# fountible-mcp

> 标签: canvas, design, design-to-code, fountible, mcp, modelcontextprotocol, tailwind, ui

## 简介

Connect MCP clients (Claude Desktop, Cursor, …) to the Fountible app over stdio. Zero-dependency shim that forwards to Fountible's local AI-connectors endpoint.
