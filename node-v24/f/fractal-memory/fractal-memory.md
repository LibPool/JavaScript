# fractal-memory

> 标签: agent-memory, ai-agents, embeddings, knowledge-graph, langchain, langgraph, long-term-memory, mcp, memory, rag, vector-search

## 简介

Hierarchical-graph long-term memory for AI agents: variable-depth abstraction tree, cross-topic recall, temporal knowledge graph. Ships an MCP server, an HTTP service, and a LangGraph BaseStore.
