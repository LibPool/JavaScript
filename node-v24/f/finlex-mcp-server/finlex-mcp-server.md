# finlex-mcp-server

> 标签: apify, claude, finland, finlex, finnish-law, legal, legislation, mcp, model-context-protocol, open-data, statutes

## 简介

Open bridge to the hosted Finnish Legislation (Finlex) MCP server on Apify — search Finnish statutes and retrieve them as clean structured text from any MCP client using your own Apify API token.
