# forgespec

> 标签: ai-agents, claude, codex, contracts, gemini, multi-agent, opencode, sdd, spec-driven-development, task-board, zod

## 简介

Multi-agent SDD plugin — Zod contract validation, task board with dependency management, file reservation, and shared SQLite database. Compatible with OpenCode, Claude, Gemini, and Codex.
