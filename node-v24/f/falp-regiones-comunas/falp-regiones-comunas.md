# falp-regiones-comunas

> 标签: JavaScript

## 简介

Esta biblioteca proporciona funciones para consultar regiones y comunas desde un conjunto de datos de zonas. Las funciones están escritas en TypeScript y se basan en un archivo JSON que contiene las zonas.
