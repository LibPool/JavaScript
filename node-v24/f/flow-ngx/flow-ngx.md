# flow-ngx

> 标签: angular, bpm, diagram, execution, flowchart, process, signals, svg, visual-programming, workflow

## 简介

FlowNGX — Visual process design and execution for Angular. Diagram canvas, typed process models, validation, step-by-step execution engine, undo/redo and JSON import/export.
