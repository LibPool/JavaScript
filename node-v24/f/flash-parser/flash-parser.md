# flash-parser

> 标签: ast, brightscript, compiler, cst, dsl, parser, roku, scenegraph

## 简介

Lossless CST + typed AST parser for the flash-theater DSL (.thr/.flsh) — the flash-theater counterpart to kopytko-brightscript-parser.
