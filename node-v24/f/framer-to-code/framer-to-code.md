# framer-to-code

> 标签: claude, claude-code, export, framer, migration, skill, static-site, website

## 简介

Install the framer-to-code Claude Code skills — convert any Framer-published website into a self-contained coded static site: pixel-perfect mirror, or hard mode with the Framer runtime removed entirely.
