# forgekit-radix-mcp

> 标签: a11y, accessibility, ai, claude, cursor, design-system, mcp, model-context-protocol, radix, radix-ui

## 简介

MCP server that exposes Radix Primitives' APIs and accessibility contracts to AI coding agents, so Claude/Cursor stop hallucinating props and respect the ARIA contract.
