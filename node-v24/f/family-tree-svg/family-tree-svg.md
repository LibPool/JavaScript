# family-tree-svg

> 标签: ancestry-visualization, d3-alternative, family-diagram, family-tree, family-tree-generator, family-tree-svg, genealogy, genealogy-visualization, interactive-tree, javascript-family-tree, organic-tree, pedigree-chart, svg, svg-tree, tree-visualization, vector-family-tree

## 简介

Pure organic SVG family tree visualization for JavaScript & TypeScript — generates realistic living trees with calligraphic trunks, botanical leaves, pan/zoom, dynamic themes, and vector export from JSON data.
