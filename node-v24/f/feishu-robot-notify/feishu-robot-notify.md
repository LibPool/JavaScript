# feishu-robot-notify

> 标签: claude-code, codex, feishu, mcp, notification, opencode

## 简介

A zero-dependency MCP server and setup CLI that sends structured summary notifications to a Feishu webhook robot across Claude Code, OpenCode, and Codex.
