# flow-web

> 标签: cli, flow, flow-cli, flow-web, installer, static-site

## 简介

Early public preview (v0.1.0-beta.1): npm installer for Flow Web. Bundled manifest downloads prebuilt `flow` from GitHub Releases; override with FLOW_WEB_BINARY or FLOW_WEB_MANIFEST_URL if needed.
