# flexbiz-server-core

> 标签: core, erp, express, flexbiz, mongoose

## 简介

FlexBiz Server — nhân (core) mã nguồn mở: model/controller CRUD, kế toán/kho/công nợ, báo cáo, kết nối kênh, quản trị công ty. Chạy độc lập với đầy đủ tính năng cơ bản; tự phát hiện & nạp các gói mở rộng thương mại nếu được cài thêm.
