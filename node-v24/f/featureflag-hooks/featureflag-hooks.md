# featureflag-hooks

> 标签: context, feature flag, rbac, react, role based access control

## 简介

### Hooks  * useFlagHook * useGaurdHook * usage useGaurdHook('awesome-button') | return boolean ### update feature flags on the fly * The useFlagHook give updateContext method  ### callback after each update * the updateContext accepts callback as second
