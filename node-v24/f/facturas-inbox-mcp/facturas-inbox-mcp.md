# facturas-inbox-mcp

> 标签: document-intake, facturas, gestoria, invoices, irpf, iva, mcp, mcp-server, model-context-protocol, nif, spain

## 简介

MCP server that turns a folder of Spanish invoice PDFs into validated, structured data: classify documents, extract NIF/IVA/IRPF/totals with arithmetic checks, and summarize IVA soportado/repercutido per period. Local, read-only, no API keys.
