# fca-meta

> 标签: appstate, automation, bot, chat-api, cookies, dgw, facebook, fb-bot, fb-chat-api, fca, fca-meta, json-rpc, lightspeed, messenger, messenger-bot, meta, nodejs, realtime, websocket

## 简介

Facebook Messenger chat API client for Node.js. fb-chat-api compatible, cookie/appState login, realtime listening. Talks to a hosted fca-meta server over JSON-RPC + WebSocket.
