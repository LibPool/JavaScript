# figsnap-mcp

> 标签: agent, ai, claude, design-to-code, design-tokens, figma, figma-plugin, mcp, mcp-server, model-context-protocol

## 简介

The Figma file you have open, as MCP tools. A local daemon and a slim Figma plugin: extract a node as PNG, React, HTML and CSS, read and edit the canvas, and keep a saved set of components — no relay, no account, nothing off your machine.
