# fx-rates

> 标签: allratestoday, api, cli, currency, currency-conversion, currency-converter, exchange, exchange-rate, finance, forex, fx, fx-rates, mid-market, money, real-time, refinitiv, reuters

## 简介

Lightweight Node.js library and CLI for real-time mid-market currency exchange rates. 160+ currencies from Refinitiv (Reuters) and interbank feeds via the AllRatesToday API.
