# flash-cache-client

> 标签: cache, database, n-api, performance, rust

## 简介

**Native Node.js bindings (via [napi-rs](https://napi.rs)) for [Flash Cache](https://crates.io/crates/flash-cache-server) — a Redis-inspired, async, in-memory data store built in Rust.**
