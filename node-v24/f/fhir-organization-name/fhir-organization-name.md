# fhir-organization-name

> 标签: JavaScript

## 简介

`<fhir-organisation-name>` adds name of organisation to the page. Uses mwc-textfield and iron-ajax  In typical use, just use `<fhir-organisation-name url=""></fhir-organisation-name>`
