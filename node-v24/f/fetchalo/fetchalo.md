# fetchalo

> 标签: authorization, es-module-shims, fetch, headers, micro-frontends, module-federation, rspack, vite, vite-plugin, webpack

## 简介

Vite, webpack and Rspack plugin that loads remote JS, CSS and media through your own fetch, so every request can carry headers (e.g. Authorization) without a service worker.
