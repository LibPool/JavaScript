# forgebase-mcp

> 标签: ai-agents, baas, forgebase, forgeyn, mcp, model-context-protocol, postgres, supabase

## 简介

Forgeyn Base MCP server — lets AI agents (Claude, Cursor, ...) use a Forgeyn Base account directly: projects, SQL, tables, gateway apps. Authenticate with a scoped access token, like the Supabase MCP server.
