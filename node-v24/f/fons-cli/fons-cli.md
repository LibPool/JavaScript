# fons-cli

> 标签: agentic, calendar, cli, company, fons, founders, mcp, oauth, profile, scheduling

## 简介

Fons CLI — read and update your Fons profile, company, product, metrics and data room from the terminal, and schedule calls with other members. OAuth in the browser; no token ever pasted.
