# fulcrum-memory

> 标签: agent-memory, entity-graph, git, graph, hnsw, knowledge-graph, kuzu, memory, vault, vector-search

## 简介

Three-layer memory stack — git vault (L0), FTS5 full-text search (L1), Kuzu graph + HNSW vector search (L2) for agent memory and cross-project knowledge graphs
