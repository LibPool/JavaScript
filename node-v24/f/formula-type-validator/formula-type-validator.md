# formula-type-validator

> 标签: aggregation, ast, calculated-fields, custom-fields, expression-parser, formula, math-expression, parser, semantic-validation, sql, syntax-validation, type-checker, type-inference, type-matrix, validator

## 简介

Type-aware formula validator with configurable type matrices, aggregation functions, and arithmetic operation rules. Parses expressions into AST, validates syntax and semantics, and infers result types.
