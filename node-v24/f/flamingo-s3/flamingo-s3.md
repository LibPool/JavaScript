# flamingo-s3

> 标签: flamingo-addon

## 简介

flamingo-s3 is a https://github.com/piobyte/flamingo addon to allow reading and converting images from https://aws.amazon.com/s3/.

- 源码仓库：git+https://github.com/piobyte/flamingo-s3.git
