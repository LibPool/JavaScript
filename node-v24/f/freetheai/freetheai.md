# freetheai

> 标签: ai sdk, chat completions, fetch, free ai api, free llm api, freetheai, llm, openai compatible, streaming, tool calls, typescript, web search

## 简介

Official JavaScript and TypeScript SDK for FreeTheAI, the free OpenAI-compatible AI API: chat, streaming, tool calls, web search, image and video tasks, with built-in retries, fallback models, and rate-limit handling.
