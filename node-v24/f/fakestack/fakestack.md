# fakestack

> 标签: auto-update, database, fake-data, faker, fakestack, generator, mock, mysql, postgresql, schema, sqlite, test-data, testing

## 简介

High-performance database generator - Generate databases from JSON schemas with realistic fake data. Auto-downloads latest binary on first run.
