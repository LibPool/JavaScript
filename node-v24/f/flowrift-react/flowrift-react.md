# flowrift-react

> 标签: accessible, component-library, components, dark-mode, design-system, flowrift, nextjs, radix-ui, react, tailwind, tailwindcss, ui

## 简介

A modern, themeable React component library built with Tailwind CSS and Radix UI primitives. Includes Header, Hero, Features, Footer, Cards, Button, CTA, Pricing, Testimonials, FAQ, Stats, Contact, Team, LogoClouds, Blog, Steps, Banner, Tabs, Modal, Sideb
