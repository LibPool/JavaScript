# finprodata-sdk

> 标签: api, contacts, finance, finprodata, investors, private-equity, sdk, venture-capital

## 简介

TypeScript SDK for the finprodata API — verified, never-stale data on finance professionals (PE/VC firms, fund managers, LPs, and the people who work there).
