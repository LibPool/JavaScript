# foxtrail

> 标签: ai-agent, audit-log, cli, firefox, hmac, indexeddb, jsonl, mozilla, nodejs, redaction, sha256, tamper-evident, typescript, web-crypto

## 简介

Tamper-evident AI agent audit logs for Node.js and Firefox, with HMAC hash chains, IndexedDB and JSONL stores, secret redaction, and CLI verification.
