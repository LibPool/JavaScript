# fastify-amqp-async

> 标签: amqp, amqplib, amqplib-as-promised, async, fastify, fastify-plugin, rabbitmq

## 简介

Fastify AMQP plugin, which uses amqplib-as-promised so as to allow for Promise-based RabbitMQ operations.
