# flowchart-sequence-designer

> 标签: diagram, editor, flowchart, mermaid, plantuml, react, sequence-diagram, svg, typescript

## 简介

TypeScript library for building and editing flowcharts and sequence diagrams — programmatic API, React UI, and multi-format export (Mermaid, PlantUML, SVG, PNG, JSON).
