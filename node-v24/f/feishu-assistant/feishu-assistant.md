# feishu-assistant

> 标签: ai, assistant, bot, claude, codex, feishu, lark, mcp, tower

## 简介

飞书私人助理机器人 —— 群里 @ 它即可聊天、查知识库、把讨论建成 Tower 任务。薄适配器：接飞书轮询 → 转发给你选的 AI CLI（claude / codex / gemini / qwen / hermes …）。
