# folio-editor

> 标签: document, editor, folio, nextjs, page-break, pagination, print, prosemirror, react, tiptap

## 简介

A paginated document editor for React/Next.js — page breaks, table/paragraph splitting, editable headers/footers, print-ready output. Built on TipTap.
