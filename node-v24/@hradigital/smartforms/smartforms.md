# @hradigital/smartforms

> 标签: client-side, form, form-state, html-form, no-framework, toolbar, validation

## 简介

State-aware client-side form manager for static HTML forms. Tracks per-field state (new, unchanged, changed, invalid, empty) and toggles toolbar actions accordingly.
