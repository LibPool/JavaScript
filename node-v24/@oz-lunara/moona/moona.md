# @oz-lunara/moona

> 标签: agent, ai, audit, claude, codex, cursor, database, guardrail, mcp, postgres, security

## 简介

Moona — a local-first guardrail for AI coding agents (a Lunara product). Intercepts an agent's database/infra actions, computes the blast radius, blocks destructive ops until keychain-gated human approval, and writes a cryptographically signed audit log.
