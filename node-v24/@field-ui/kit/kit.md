# @field-ui/kit

> 标签: bundle, dom, field, field-ui, meta, reciprocal, suite

## 简介

The whole field-ui suite in one install — the engine (@field-ui/core), the DOM platform, and the web-component, React, and vanilla adapters. A meta-package: install it, then import from the specific @field-ui/* package you need.
