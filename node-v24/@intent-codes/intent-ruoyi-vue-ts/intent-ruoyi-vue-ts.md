# @intent-codes/intent-ruoyi-vue-ts

> 标签: JavaScript

## 简介

`intent-ruoyi-vue-ts` 并非只能生成 vue 或 typescript 代码，而是为 ruoyi vue 分离版，且前端使用 typescript 的项目生成所有代码，包括后端的 java 代码。
