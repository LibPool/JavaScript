# @agentic.artists/modelshortlist

> 标签: ai, artificial-analysis, llm, mcp, model-context-protocol, model-recommendation, model-selection, openrouter, zdr

## 简介

A local BYOK MCP server that helps AI assistants shortlist models using OpenRouter catalog data and Artificial Analysis benchmarks, with optional ZDR filtering.
