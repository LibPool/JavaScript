# @haybarn/ext-midi-h2-0-0

> 标签: duckdb, extension, haybarn, midi

## 简介

Read, analyze, generate, and play MIDI files with SQL. Provides table functions for parsing Standard MIDI Files, scalar functions for note/frequency conversion, and macOS playback via AudioToolbox.
