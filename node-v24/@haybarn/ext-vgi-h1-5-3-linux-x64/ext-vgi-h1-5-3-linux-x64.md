# @haybarn/ext-vgi-h1-5-3-linux-x64

> 标签: JavaScript

## 简介

Haybarn extension 'vgi' for linux/x64 (glibc). Built against haybarn 1.5.3. Installed automatically by the @haybarn/ext-vgi-h1-5-3 meta-package; use that, not this leaf, in your dependencies.
