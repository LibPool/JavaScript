# @haybarn/ext-pgvfs-h2-0-0

> 标签: duckdb, extension, haybarn, pgvfs

## 简介

DuckLake and DuckDB databases on PostgreSQL - pgvfs:// stores data files as PostgreSQL rows for many writers and readers; pgdb:// stores a DuckDB database for one writer and many readers
