# @haybarn/ext-yaml-h1-5-3-wasm-threads

> 标签: duckdb, duckdb-wasm, extension, haybarn, wasm, yaml

## 简介

WebAssembly (threads) build of the Haybarn extension 'yaml' for duckdb-wasm. Built against haybarn 1.5.3. Pick the variant (mvp/eh/threads) matching your duckdb-wasm bundle.
