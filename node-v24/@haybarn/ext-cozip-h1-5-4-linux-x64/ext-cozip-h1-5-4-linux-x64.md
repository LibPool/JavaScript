# @haybarn/ext-cozip-h1-5-4-linux-x64

> 标签: JavaScript

## 简介

Haybarn extension 'cozip' for linux/x64 (glibc). Built against haybarn 1.5.4. Installed automatically by the @haybarn/ext-cozip-h1-5-4 meta-package; use that, not this leaf, in your dependencies.
