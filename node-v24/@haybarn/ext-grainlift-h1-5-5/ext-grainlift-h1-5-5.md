# @haybarn/ext-grainlift-h1-5-5

> 标签: duckdb, extension, grainlift, haybarn

## 简介

Query any database exposed by a Grainlift gateway from Haybarn DuckDB-WASM, over HTTP(S) or Iroh, through a statically linked ADBC driver.
