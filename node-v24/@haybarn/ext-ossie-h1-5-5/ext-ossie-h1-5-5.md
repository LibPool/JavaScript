# @haybarn/ext-ossie-h1-5-5

> 标签: duckdb, extension, haybarn, ossie

## 简介

The Apache Ossie (incubating) reference implementation for DuckDB. Reads Ossie semantic model files in YAML or JSON and answers semantic queries against the tables in DuckDB, from a single binary, with no infrastructure. Also exposes the semantic layer vi
