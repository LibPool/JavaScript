# @haybarn/ext-web_search-h1-5-4-wasm-threads

> 标签: duckdb, duckdb-wasm, extension, haybarn, wasm, web_search

## 简介

WebAssembly (threads) build of the Haybarn extension 'web_search' for duckdb-wasm. Built against haybarn 1.5.4. Pick the variant (mvp/eh/threads) matching your duckdb-wasm bundle.
