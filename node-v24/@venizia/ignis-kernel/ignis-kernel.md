# @venizia/ignis-kernel

> 标签: authentication, authorization, browser, component, controller, dependency-injection, di, ignis, ioc, isomorphic, kernel, loopback, loopback4, repository-pattern, rest, typescript, venizia

## 简介

Browser-pure kernel of the IGNIS framework: dependency injection, lifecycle, REST controllers, repository and datasource abstractions, and the authentication and authorization seams. No node builtin and no server-only peer, so the same kernel serves a Bun
