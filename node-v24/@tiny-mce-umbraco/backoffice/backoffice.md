# @tiny-mce-umbraco/backoffice

> 标签: RTE, Rich Text Editor, TinyMCE, Umbraco

## 简介

This Umbraco CMS package enables access to the TinyMCE-based Rich Text Editor (RTE) in version 16 and above. It also supports the use of TinyMCE Premium plugins with a valid subscription. Additional features include streamlined configuration for RTE Data
