# @independo/inderun-web

> 标签: ai, cloud-fallback, inderun, llm, local-llm, offline, on-device, on-device-ai, onnx, onnxruntime, openai, prompt-api, routing, sdk, streaming, web

## 简介

On-device AI with automatic cloud fallback for web apps. Runs ONNX Runtime or the Chrome Prompt API in the browser and falls back to an OpenAI-compatible endpoint, with streaming and cancellation behind one API.
