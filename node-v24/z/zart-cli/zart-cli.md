# zart-cli

> 标签: zart, zart-cli

## 简介

Zart Cli 是一个 Vue 组件库构建工具，通过 Zart Cli 可以快速搭建一套功能完备的 Vue 组件库, Zart Cli 基于 Vant Cli 修改而来。
