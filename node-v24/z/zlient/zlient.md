# zlient

> 标签: api-client, arktype, fetch, http-client, rest-api, schema-validation, standard-schema, type-safe, typescript, valibot, validation, zod

## 简介

A type-safe HTTP client framework with Standard Schema support - works with Zod, Valibot, ArkType, and any validation library
