# zcode-provider

> 标签: agent, opencode, pi-extension, pi-package, zcode

## 简介

Use the ZCode agent (zcodex app-server) as a pi model provider: pi is the chat frontend, ZCode runs the model and its own tools (bash, edits, session memory).
