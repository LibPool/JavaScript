# zepto.timer-handler

> 标签: handler, timer, timer-handler, timerhandler, zepto

## 简介

Zepto timerHandler 定时器插件支持动态注册管理，支持已ms/s/m/h时间设置间隔周期时间、暂停、限制运行次数及自动销毁机制
