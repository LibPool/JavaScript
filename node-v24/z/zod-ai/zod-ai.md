# zod-ai

> 标签: JavaScript

## 简介

This package provides functionality similar to [Marvin](https://github.com/prefecthq/marvin)'s AI utilities, but based on [Zod](https://github.com/colinhacks/zod) functions and for the Typescript ecosystem.
