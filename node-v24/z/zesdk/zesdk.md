# zesdk

> 标签: app-shell, components, design-system, desktop, local-first, modal, tauri, toast, ui, vanilla-js, zesdk

## 简介

Framework-free frontend kit for Ze-family apps: design tokens, icons, app shell (sidebar, views, search, console) and components (modal, toast, menus) for Tauri 2 + vanilla JS. Zero dependencies.
