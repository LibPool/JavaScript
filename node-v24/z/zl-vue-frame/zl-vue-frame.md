# zl-vue-frame

> 标签: admin, admin-template, element-ui, management-system, vue

## 简介

为了各个开发人员开发的后台管理系统风统一，所以抽离了一个上线的项目架子去做开发，包括后期依赖版本的升级以及出现框架级别问题，也会比较好解决。
