# zx-list-ad

> 标签: JavaScript

## 简介

一个基于 uni-app、Vue3 <script setup> 语法开发的高兼容性广告列表项组件，适配 H5、小程序、App。可嵌入于 zx-list 组件中，支持多端广告展示，便于灵活插入广告内容。
