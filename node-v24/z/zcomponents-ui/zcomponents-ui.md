# zcomponents-ui

> 标签: component-library, css, customizable, dropdown, dual-thumb-slider, filter-ui, price-range, range-slider, react, react-components, react-hook-form, scss, select, typescript, ui, ui-library, yup, zcomponents, zcomponents-ui, zdrop, zdropbutton, zero-dependency, zod, zrange

## 简介

Zero-dependency React UI components library with dropdowns and a dual-thumb range slider. Written in TypeScript, styled with SCSS, fully customizable and React Hook Form ready.
