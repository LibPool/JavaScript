# zzc-react-native-cli

> 标签: JavaScript

## 简介

为了统一租租车的整个React Native的版本环境，以及使用同样的目录结构，所以开发出一个自动化创建工程目录的脚手架工具。所有新的RN项目都应该使用该脚手架来创建工程。
