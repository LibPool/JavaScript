# zenrei

> 标签: adr, ai-agents, claude, decision-records, governance, mcp, model-context-protocol

## 简介

Decision memory for AI-driven development — a local MCP server that indexes decisions/*.md and stops agents from re-proposing rejected designs.「その提案、前例があります」
