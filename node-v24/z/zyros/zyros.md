# zyros

> 标签: blog, blog-generator, cms, developer-tools, jamstack, json-driven, markdown, nextjs, react, ssg, static-site, static-site-generator, tailwindcss, typescript, website-builder

## 简介

A developer-friendly static site generator built with Next.js and Tailwind CSS. Transform a simple JSON file into a beautiful, fast static website.
