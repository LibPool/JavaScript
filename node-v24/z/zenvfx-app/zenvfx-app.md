# zenvfx-app

> 标签: JavaScript

## 简介

一个基于 TypeScript + Node.js 编写的实验性混合架构命令行工具。它使用了**常驻后台进程（Daemon）**来处理所有请求，每次在终端输入命令（Client）时，都会将指令发送给后台集中执行。
