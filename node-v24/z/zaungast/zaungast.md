# zaungast

> 标签: indexeddb, leveldb, mcp, microsoft-teams, model-context-protocol, offline, read-only

## 简介

Read-only, offline MCP server for Teams: search chats, read conversations, surface trending topics, find people, and browse meetings & calls — straight from the local on-disk cache, with no Graph API, no cloud, no credentials, and token-economical output
