# zerodep-js-vue

> 标签: JavaScript

## 简介

Vue 页面宿主。onMounted 建立独立页面，输入变更更新原实例，onBeforeUnmount 释放资源。服务器输出空容器；Vue 与 zerodep-js 作为 peer。
