# zk-x509-sdk

> 标签: ethereum, ethers, identity, kyc, verification, x509, zero-knowledge, zk-x509

## 简介

TypeScript SDK + CLI for integrating zk-X509 on-chain identity verification (prove an X.509 certificate identity with a ZK proof, then gate your dApp on it).
