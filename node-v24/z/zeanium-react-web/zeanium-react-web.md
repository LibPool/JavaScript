# zeanium-react-web

> 标签: form, framework, graph, javascript, oop, table, web component

## 简介

Web page component(form, table, pager, loading, graph, dataview, animate, layout) for react.js, it support desktop page and mobile page. You can using the same api for different platform, it's easy to develop and deploy your app using the one code on diff
