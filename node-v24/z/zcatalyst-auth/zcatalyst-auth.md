# zcatalyst-auth

> 标签: ZCatalyst-auth, catalyst, zoho

## 简介

Authentication middleware for Zoho Catalyst AppSail Node.js applications. Provides Zoho OAuth 2.0 login, session management backed by Catalyst DataStore, and route protection middleware.
