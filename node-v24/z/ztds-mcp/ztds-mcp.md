# ztds-mcp

> 标签: claude-desktop, cursor, data-sanitization, mcp, mcp-server, modelcontextprotocol, pii-redaction, zero-trust, ztds

## 简介

Open standard MCP server for Zero-Trust Data Sanitization (ZTDS RFC v1.0). In-memory PII masking.
