# zfzn-charts

> 标签: JavaScript

## 简介

- 基于 ts 搭建的用于将项目封装的插件发布 npm 的模版。 - 其内置了静态服务 测试用例 和 持续集成。 - 先进行本地开发，确认功能和测试全部通过后再发布到 npm。
