# zerodep-js

> 标签: JavaScript

## 简介

zerodep-js 的响应式、组件、DOM 与 hydration 运行时。使用标准 TSX 和 TypeScript 7，源码须经过 `zerodep-js-compiler` 或 `zerodep-js-vite` 转换。样式边界采用 CSS Tools tokenizer，CSS 类型采用 csstype 的生成数据；不依赖其他组件框架运行时。
