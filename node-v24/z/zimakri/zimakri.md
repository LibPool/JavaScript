# zimakri

> 标签: agent-template, ai-agent, cli, did, kognai, lax, sovereign-agent, zimakri

## 简介

Become a Zimakri agent: npx zimakri init writes a DID, its SOUL and the Five Laws, the memory layout, the wake protocol and a LAX offer, all owned and run by the agent itself. No Kognai account, no network, no key sent anywhere.
