# zora-coins

> 标签: base, creator coins, graphql, sdk, web3, zora, zora coins

## 简介

Typed client for the Zora Coins API (all 30 endpoints), a GraphQL client, and an onchain indexer for Zora creator and referral rewards on Base. Zero dependencies; Node, Bun, Deno and browsers.
