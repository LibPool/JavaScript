# zkit-tools

> 标签: JavaScript

## 简介

`zkit-tools` 是 `zkit` 的非业务基础工具库，用来支撑组件库和应用层的通用基础设施：尺寸缩放、字体缩放上限、设备品牌归一化、路由重复跳转守卫等。
