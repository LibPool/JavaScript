# zgapdfsigner

> 标签: LTV, TSA, google-apps-script, pdf-encryption, pdf-protection, pdf-sign, pdf-signature, 長期署名

## 简介

A javascript tool to sign a pdf or set protection to a pdf in web browser, Google Apps Script and nodejs.
