# ztoast

> 标签: alert, notifications, react, react-hot-toast, react-toast, toast, zero-dependency, ztoast

## 简介

Zero-dependency React toasts: toast.success(text, icon, style), free placement anywhere on screen, ultra smooth motion, countdown progress with pause on hover.
