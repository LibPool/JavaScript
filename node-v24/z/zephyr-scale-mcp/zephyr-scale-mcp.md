# zephyr-scale-mcp

> 标签: jira, mcp, testing, tm4j, zephyr-scale

## 简介

MCP server for Zephyr Scale on self-hosted Jira Server / Data Center: test cases, cycles, executions, plans, folders, attachments and automation via REST API v1
