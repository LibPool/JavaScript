# zeitstempel

> 标签: bitcoin, opentimestamps, ots, react, timestamp, verification

## 简介

Lightweight TypeScript library for the full OpenTimestamps lifecycle — stamp, upgrade, and verify .ots proofs — with optional React components. Works in browsers and Node.js.
