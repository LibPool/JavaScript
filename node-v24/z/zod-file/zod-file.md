# zod-file

> 标签: config, configuration, file, json, migration, persistence, schema, settings, storage, toml, type-safe, typescript, validation, yaml, zod

## 简介

Type-safe file persistence with Zod validation and schema migrations for Node.js. Supports JSON, YAML, and TOML.
