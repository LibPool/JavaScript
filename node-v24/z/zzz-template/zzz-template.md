# zzz-template

> 标签: browser, ejs-alternative, fast, handlebars-alternative, html-template, include, isomorphic, javascript-template, layout, lightweight, mustache-alternative, nodejs, partial, render, string-interpolation, template, template-engine, template-literal, template-literals, zero-dependency

## 简介

Fastest JavaScript template engine using native template literals. Zero dependencies, ~600 bytes, works in Node.js and browser. EJS/Handlebars alternative.
