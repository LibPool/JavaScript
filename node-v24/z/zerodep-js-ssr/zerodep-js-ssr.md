# zerodep-js-ssr

> 标签: JavaScript

## 简介

zerodep-js 的同步组件 SSR、文档模板组合与显式数据编码。每次 `renderToString` 使用独立请求作用域；不执行 DOM effect、ref 或浏览器事件。安装时须提供同版本的 `zerodep-js`。
