# zcode-usage-stats

> 标签: deepseek-harness, dsh, dsh-plugin, statistics, token, usage, 使用统计

## 简介

仿zcode的使用统计：在 DeepSeek Harness(DSH) 设置页渲染全量会话的 Token 用量统计——按天/按小时趋势图、模型用量仪表盘、活跃热力图，支持今天/昨天/最近7·30天/本月/上月/自定义区间。
