# @nfsfu234/tour-guide

> 标签: interactive-guide, nfsfu234, onboarding, product-tour, react, react-tour, step-by-step, tooltip, tour, tour-guide, tutorial, user-guide, walkthrough

## 简介

A plug-and-play React component for creating customizable onboarding tours with tooltips, modals, and smooth user guidance. Zero-dependency, dark mode support, and full control over step logic.
