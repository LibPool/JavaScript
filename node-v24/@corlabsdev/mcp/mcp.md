# @corlabsdev/mcp

> 标签: ai-agents, cypress, locators, mcp, playwright, selenium, test-automation, ui automation, webdriverio

## 简介

MCP server that gives AI coding agents scored, maintainable, parameterised locators from a live page, in the test framework your repo already uses, then checks and repairs them.
