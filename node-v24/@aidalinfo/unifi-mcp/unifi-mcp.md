# @aidalinfo/unifi-mcp

> 标签: mcp, mcp-server, network, site-manager, typescript, ubiquiti, unifi

## 简介

UniFi (Ubiquiti) MCP server, read-only by default — Site Manager + Network Integration API, Prometheus exporter and Prometheus/Loki history, unofficial internal API and UNAS health over SSH
