# dsh-linux-integration

> 标签: chromium, deepseek-harness, desktop, dsh, dsh-plugin, freedesktop, gnome, kde, launcher, linux, pwa, wayland, x11, xdg

## 简介

DeepSeek Harness 的 Linux 原生桌面集成：XDG 桌面入口、纯净无边框独立窗口，以及由自己启动的服务随窗口关闭而停止的生命周期管理。
