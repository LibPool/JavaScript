# @fnnm/opencode-decision-first

> 标签: agent-skill, decision-first, jev, opencode, opencode-plugin, typesafe

## 简介

Decision-first as an OpenCode plugin: registers its bundled agent skill automatically and nudges the agent when a prompt contains bounded-judgment vocabulary.
