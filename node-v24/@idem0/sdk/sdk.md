# @idem0/sdk

> 标签: anthropic, byok, claude, exactly-once, idempotency, idempotent, llm, openai, proxy, retry

## 简介

Drop-in idempotency for @anthropic-ai/sdk and openai via the idem0 proxy — a config producer, not a client.
