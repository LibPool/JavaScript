# @hualiong/dsh-qq-bot

> 标签: chatbot, deepseek-harness, dsh, dsh-bundle, dsh-plugin, im, qq, qqbot

## 简介

Minimal QQ-only IM bridge for DeepSeek Harness: bind one session to QQ, /new in a default workspace, relay only the final answer, and push from any session through the send_qq_message tool. Configured in Settings → QQ bot.
