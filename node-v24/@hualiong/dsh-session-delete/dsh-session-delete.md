# @hualiong/dsh-session-delete

> 标签: cordis, deepseek-harness, dsh-plugin, session-management

## 简介

Delete sessions of a DeepSeek Harness profile from the UI: session-row menu item with a confirm dialog; the host endpoint deletes the log, projection cache and workspace accounting, cascading through the whole subagent tree. Optionally exposes session_lis
