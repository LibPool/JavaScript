# @hope_phenom/dsh-plugin-code-quality

> 标签: code-review, cordis, deepseek-harness, diff, dsh, dsh-plugin, refactor, simplify, skill

## 简介

DeepSeek Harness plugin adding two code-quality commands as user-invocable skills: /simplify (behavior-preserving cleanups over the current diff) and /code-review (multi-angle bug hunt with an independent verifier pass), plus /review as an alias.
