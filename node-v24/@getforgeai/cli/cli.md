# @getforgeai/cli

> 标签: agents, ai, claude-code, cli, developer-tools, docker, forgeai, mcp

## 简介

ForgeAI CLI — runs AI coding agents in local Docker containers with your own AI tokens, and connects them to the ForgeAI cockpit.
