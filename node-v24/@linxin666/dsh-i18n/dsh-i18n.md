# @linxin666/dsh-i18n

> 标签: JavaScript

## 简介

DSH web GUI language pack plugin: registers the Русский language into the locale catalog and centrally carries the ru dictionaries for every family plugin namespace (missing keys fall back to English through the SDK chain).
