# @linxin666/dsh-client-ui-preset-center

> 标签: JavaScript

## 简介

Community agent-preset manager: the Workshop's Presets panel and the host library that installs, declares, disables and uninstalls presets downloaded from dsh-market.com, keeping a downloaded composition inert until the plugin declares it to the agent-pre
