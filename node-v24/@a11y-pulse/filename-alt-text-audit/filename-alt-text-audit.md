# @a11y-pulse/filename-alt-text-audit

> 标签: a11y, accessibility, alt-text, audit, non-text-content, wcag

## 简介

WCAG 1.1.1 Non-text Content audit that flags images whose alt text is their own filename, a camera file name, or placeholder text (failure F30).
