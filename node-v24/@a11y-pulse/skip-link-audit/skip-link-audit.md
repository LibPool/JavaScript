# @a11y-pulse/skip-link-audit

> 标签: a11y, accessibility, audit, bypass-blocks, skip-link, wcag

## 简介

WCAG 2.4.1 Bypass Blocks audit that finds skip-link-like in-page anchors in the first tab stops and verifies that activating them moves keyboard focus.
