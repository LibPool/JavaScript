# @a11y-pulse/orphaned-tab-roles-audit

> 标签: a11y, accessibility, aria, audit, tabs, wcag

## 简介

WCAG 1.3.1 and 4.1.2 audit that flags ARIA tabs with no tab panel and tab panels with no tab, including navigation links dressed up as tabs.
