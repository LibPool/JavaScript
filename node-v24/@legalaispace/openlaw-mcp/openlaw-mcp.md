# @legalaispace/openlaw-mcp

> 标签: ai, case-law, caselaw, eu-law, law, legal, legislation, mcp, model-context-protocol, oscola, uk-law

## 简介

Free MCP server for UK and EU open law — fetches and cites caselaw, statutes, ICO, HMRC, EUR-Lex and ECHR judgments, with link-only FCA references.
