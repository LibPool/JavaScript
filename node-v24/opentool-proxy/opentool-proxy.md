# opentool-proxy

> 标签: JavaScript

## 简介

Zero-cache local dev proxy for OpenToolLab's No Cache Browser — no-store headers, Service Worker neutralization, cache-bust rewrite, file-watch reload, real-time web vitals over WebSocket.
