# @ngbracket/a11y-devtools

> 标签: a11y, accessibility, angular, axe, axe-core, devtools, ngbracket

## 简介

Dev-only in-app accessibility auditing for Angular that maps each axe violation back to the component that rendered it — the attribution React overlay tools can't do.
