# @aibolabs/capability-runtime

> 标签: JavaScript

## 简介

Node 22+ Capability Runtime 2.0/2.1 helper。声明 `hostSdk` 的插件由宿主提供此包，开发时用 `npm install -D @aibolabs/capability-runtime` 安装为 `devDependencies`，发布时不携带 SDK；包版本等于宿主 SDK 版本，即应声明的 `hostSdk.min`。版本、公开入口和迁移见[宿主 SDK](https://github.com/chldu2000/aibo/blob/main/docs/
