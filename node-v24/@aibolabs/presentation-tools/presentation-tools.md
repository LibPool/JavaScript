# @aibolabs/presentation-tools

> 标签: JavaScript

## 简介

独立的 Presentation 目录打包工具，通过 `npm install -D @aibolabs/presentation-tools` 安装。 CLI 只依赖 Node.js 22+；类型声明依赖 `@aibolabs/plugin-protocol`。
