# @qttdev/vite-ts-lib-starter

> 标签: JavaScript

## 简介

构建在 Vite 5.x 之上，并为使用 TypeScript 编写库做好了准备。它生成一个混合包 - 同时支持 CommonJS 和 ESM 模块。
