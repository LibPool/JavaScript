# @wpelevator/wp-release

> 标签: checksums, deploy, gettext, i18n, plugin, pot, release, signing, svn, theme, wordpress, zip

## 简介

Package, checksum, sign, verify and version-check WordPress plugins and themes, extract and compile their translations, and deploy plugins to WordPress.org SVN
