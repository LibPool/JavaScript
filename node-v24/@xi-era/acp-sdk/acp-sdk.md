# @xi-era/acp-sdk

> 标签: acp, agent, ai, component, distributed, iot, mcp, protocol

## 简介

ACP (Agent-Component-Protocol) SDK & CLI — Lightweight component call protocol for AI Agent, focusing on remote service, IoT hardware and distributed business components. Bidirectional compatible with MCP & OpenAI Tool-Call.
