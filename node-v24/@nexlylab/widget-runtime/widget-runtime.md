# @nexlylab/widget-runtime

> 标签: JavaScript

## 简介

The widget itself — WidgetCore, its blocks, themes and hooks — in two roles: source for in-workspace consumers (React externalised) and a CDN payload with its own React inlined. Since ECO-15548 this is the only package a widget change moves (spec §8, D12)
