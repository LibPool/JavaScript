# @dsh-plugin/dsh-approve-for-me-client

> 标签: JavaScript

## 简介

Frontend (browser) plugin for @dsh-plugin/dsh-approve-for-me: renders a codex-style auto-review status bar (shimmer progress → verdict) in the Web GUI conversation stream, driven by a host session projection over approval/asked + approval/decided events.
