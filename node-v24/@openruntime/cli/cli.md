# @openruntime/cli

> 标签: JavaScript

## 简介

OpenRuntime CLI is the main entry point for coding agents using OpenRuntime as a web development debugging tool. It preserves login state and browser sessions, operates real pages, collects debugging evidence, loads team Extensions, and reads Runtime Core
