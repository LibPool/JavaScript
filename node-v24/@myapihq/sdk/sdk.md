# @myapihq/sdk

> 标签: ai-agent, api-client, domains, mcp, model-context-protocol, myapi, payments, sdk

## 简介

TypeScript client for MyAPI. Use it from code you deploy — edge functions and containers that call back into the platform. Agents building things should use the MyAPI MCP server: https://api.myapihq.com/mcp
