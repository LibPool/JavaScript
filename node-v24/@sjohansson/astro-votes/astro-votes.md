# @sjohansson/astro-votes

> 标签: astro, astro-component, astro-integration, likes, static-site, umami, votes, web-components

## 简介

Like and dislike buttons for static Astro sites. Votes go to your analytics tool as events, a CI job writes the totals to a JSON file, and the site shows them at build time. No database.
