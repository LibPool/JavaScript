# @openiap/nodered

> 标签: JavaScript

## 简介

Simple wrapper around NodeRed, RabbitMQ and MongoDB to support a more scaleable NodeRed implementation. Also the "backend" for [OpenRPA](https://github.com/skadefro/OpenRPA)

## 官网

- 官网：https://github.com/open-rpa/openflow
- 源码仓库：git+https://github.com/open-rpa/openflow.git
- npm 页面：https://www.npmjs.com/package/@openiap/nodered
