# @nativescript-community/ui-refreshlayout

> 标签: Android, JavaScript, NativeScript, iOS

## 简介

Pull to refresh at the top and the bottom of a scrollable view: SwipeRefreshLayout on Android, UIRefreshControl on iOS. Made for CollectionView and chat UX.
