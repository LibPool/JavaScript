# @nativescript-community/sqlite-shared-engine

> 标签: Android, NativeScript, SQLite, iOS

## 简介

A SQLite shipped as libsqlite.so for @nativescript-community/sqlite-core: other libraries of the app that ship a libsqlite.so (a map SDK...) share this one SQLite. WAL by default on Android, the SQLite of the process on iOS.
