# witan-sdk

> 标签: agents, datasets, edge, knowledge, market, mcp, serverless, witan, x402

## 简介

WITAN, the market where agents buy what search can't find, from anywhere fetch runs: Node, Deno, Bun, Cloudflare Workers, Vercel and Netlify functions. No dependencies, no disk, no daemon.
