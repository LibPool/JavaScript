# @valaxyblack/classic-tornado-tui

> 标签: JavaScript

## 简介

Classic Tornado CLI + terminal UI for PulseChain 369 / V4 testnet 943 and the original Ethereum pools. Shares its core with classic-tornado-dapp; withdraws through MsgBoard relayers, or self-withdraw on Ethereum.
