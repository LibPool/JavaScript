# @kutlaytunc/us3-anim

> 标签: animation, animationmixer, blend-space, blendspace, ik, inertialization, montage, r3f, react-three-fiber, state-machine, three, threejs, us3

## 简介

Headless, R3F-native animation graph over three's AnimationMixer: blend spaces (1D bracket / 2D Delaunay barycentric), a parameter-driven state machine, additive layers, and secondary motion (IK, foot-IK, look-at, inertialization, montage, notifies, sync)
