# @r0hitsharma/http-client-core

> 标签: JavaScript

## 简介

Typed HTTP client utilities built on OpenAPI and Zod: an `openapi-fetch` client factory, the OpenAPI helper types the rest of the toolkit shares, and helpers that turn a document's component schemas into zod validators.
