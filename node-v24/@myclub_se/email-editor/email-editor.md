# @myclub_se/email-editor

> 标签: custom-element, email, email-template, html-email, lit, mosaico, newsletter, web-component

## 简介

Framework-agnostic <myclub-email-editor> Web Component. Modern block-library email editor for newsletters — drops into Angular, Ionic, WordPress, Django, or any HTML page. Ships a pure renderer subpath (./render) for server-side HTML production.
