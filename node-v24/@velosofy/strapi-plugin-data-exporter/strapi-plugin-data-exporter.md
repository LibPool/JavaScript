# @velosofy/strapi-plugin-data-exporter

> 标签: content-type, csv, data-export, excel, export, json, strapi, strapi-plugin, strapi5, xlsx

## 简介

A Strapi v5 plugin to export any content type data to CSV, JSON, or XLSX, with column selection support.
