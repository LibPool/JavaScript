# @goshops/gs-sdk-vue

> 标签: JavaScript

## 简介

@goshops/gs-sdk-vue is a Vue.js wrapper for the @goshops/gs-sdk JavaScript SDK. It allows you to easily integrate the GS SDK into your Vue.js applications.
