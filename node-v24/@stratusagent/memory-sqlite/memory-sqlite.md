# @stratusagent/memory-sqlite

> 标签: agent, ai, llm, memory, sqlite, stratus, stratus-plugin

## 简介

A SQLite-backed agent memory store for Stratus Agent, as a plugin: one owner-only database file, the kernel's memory contract, no FTS index
