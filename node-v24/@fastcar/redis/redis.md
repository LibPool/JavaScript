# @fastcar/redis

> 标签: @fastcar/core, @fastcar/redis, crud, redis

## 简介

`@fastcar/redis` 是 `@fastcar/core` 框架下的 Redis 组件，基于 `redis@5`，提供多数据源、常用缓存操作、Redis 数据结构操作以及 pipeline、transaction、pub/sub、Lua 等高级能力。
