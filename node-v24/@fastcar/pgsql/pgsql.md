# @fastcar/pgsql

> 标签: @fastcar/core, @fastcar/pgsql, ORM, pg, pgsql

## 简介

FastCar 的 PostgreSQL 组件，提供连接池、ORM 映射、事务管理、多数据源、原生 SQL 执行，以及基于 `pgvector` 的向量检索能力。
