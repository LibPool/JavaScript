# @getvda/evaluator-sdk

> 标签: JavaScript

## 简介

The ACP evaluator SDK — the fleet-reuse artifact. Any agent embeds it to fetch → verify → cache → evaluate → seal a governance bundle LOCALLY. Framework-agnostic. Fail-static.
