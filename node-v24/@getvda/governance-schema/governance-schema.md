# @getvda/governance-schema

> 标签: JavaScript

## 简介

The shared governance-file schema contract (C2MD ⇄ ACP). VDA-MD governance files: taxonomy, MUST/MUST NOT/MAY clause grammar, clause-level citations, RACI. Versioned first-class artifact.
