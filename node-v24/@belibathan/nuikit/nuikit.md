# @belibathan/nuikit

> 标签: cfx, conformance, design-tokens, esx, fivem, lint, nui, qbcore, qbox, shadcn

## 简介

The nuikit command line: `nuikit check` audits a FiveM resource against the nuikit protocol's conformance levels (themed, well-behaved, native), `nuikit tokens` lists the theme tokens.
