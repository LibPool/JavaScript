# @watermarker/react-native

> 标签: android, copyright, image, ios, photo, react-native, turbomodule, watermark, watermarking

## 简介

Fast image watermarking for React Native: logos, text and timestamps, positioned or tiled, powered by Rust. Paths in, paths out, so photos never cross the bridge.
