# @meeto/embed-core

> 标签: embed, free, meeto, screen sharing, video call, video chat, video conferencing, webrtc, widget

## 简介

Free video call widget for any website. Embed Meeto video chat — lobby, screen sharing, chat, reactions — with one snippet or a floating call button. Zero dependencies.
