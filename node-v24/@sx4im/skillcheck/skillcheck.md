> 标签: ab-testing, agent-skills, ai-agent, ai-agents, benchmark, cli, evals, evaluation, llm, llm-eval, nodejs, prompt-engineering, prompt-testing, skill-testing, testing, typescript

## 简介

Controlled A/B tests for agent SKILL.md files: blind grading, bootstrap confidence intervals, HELPS/PLACEBO/HARMS - effect size, not schema validation.
