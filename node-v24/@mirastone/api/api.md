# @mirastone/api

> 标签: JavaScript

## 简介

Biblioteca oficial para interagir com a API do Mirastone, que é sincronizada com o banco de dados do bot. Permite acessar dados de usuários, transações e outras funcionalidades do Mirastone de forma fácil, segura e atualizada.
