# @xjmz/base-layout

> 标签: JavaScript

## 简介

`BaseLayout` 可以提供一个标准的中后台布局方案，支持 `top`、`sider`、`top-sider` 布局形态； 可以使用 BaseLayout 来减少布局成本。
