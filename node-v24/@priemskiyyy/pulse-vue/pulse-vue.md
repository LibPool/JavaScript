# @priemskiyyy/pulse-vue

> 标签: app-state, background, composables, foreground, lifecycle, page-visibility, pulse, vue, vue3

## 简介

Vue bindings for Pulse: a provider, and composables for the Pulse and its lifecycle state that observe without starting or disposing anything.
