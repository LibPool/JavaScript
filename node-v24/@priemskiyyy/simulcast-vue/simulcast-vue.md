# @priemskiyyy/simulcast-vue

> 标签: composables, pubsub, real-time, realtime, simulcast, ssr, subscriptions, typed-events, typescript, vue, websocket

## 简介

Vue bindings for simulcast: a provider component that owns the realtime session and composables for shared channel subscriptions, typed events, channel status, and connection state.
