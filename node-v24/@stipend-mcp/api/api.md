# @stipend-mcp/api

> 标签: agent-payments, fastify, mcp, payments-api, stipend, stripe-webhook

## 简介

Cold-path HTTP API for Stipend (Fastify). Host-facing endpoints, Stripe webhook receiver, outbound webhook delivery worker.
