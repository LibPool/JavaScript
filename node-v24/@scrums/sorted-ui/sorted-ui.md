# @scrums/sorted-ui

> 标签: JavaScript

## 简介

Sorted UI — the Scrums.com design system. Shared Console/Field-Ops React component library for Scrums.com app surfaces (catalog, mission-control, external consoles). Implements the brand contracts; reads design tokens. Documented at /company/sorted-ui.
