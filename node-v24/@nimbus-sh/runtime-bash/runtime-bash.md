# @nimbus-sh/runtime-bash

> 标签: bash, nimbus, runtime, wasi, wasm

## 简介

GNU bash 5.2.37 and BusyBox 1.37.0, cross-compiled to wasm32-wasi, as a Nimbus runtime package.
