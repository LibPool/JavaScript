# @freereportjs/testing

> 标签: @freereportjs/core, cypress, playwright, report, testing

## 简介

Test helpers for FreeReport: read what the report viewer shows, fill parameters, page and search, and drive the designer, in jsdom, happy-dom or a real browser (Playwright, Cypress).
