# @zpos/capacitor-tcp-printer

> 标签: capacitor, escpos, network-printer, printer, tcp, thermal-printer

## 简介

Capacitor plugin for raw TCP printing to network thermal printers (port 9100 / ESC/POS over Ethernet). Base64 payload preserves null bytes that cut commands depend on.
