# @zpos/capacitor-smart-till-printer

> 标签: capacitor, escpos, printer, smart-till, thermal-printer

## 简介

Capacitor plugin for Smart Till thermal printer — binds to com.prints.printerservice.IPrinterService AIDL for raw ESC/POS output (including null-byte cut commands).
