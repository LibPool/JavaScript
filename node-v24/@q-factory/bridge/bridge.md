# @q-factory/bridge

> 标签: agent, bridge, claude-code, cli, codex, daemon, mcp

## 简介

Bridge — run agent tasks on your own machine through your own CLI (Claude Code / Codex / Cursor / Gemini). MCP server + `qf` CLI.
