# @hitl-kit/ai-sdk

> 标签: agents, ai, hitl, human-in-the-loop, vercel-ai-sdk

## 简介

Vercel AI SDK adapter for HITL Kit. Typed tool() wrappers that return schema-conformant HITL events so <HitlEventRenderer /> can dispatch them client-side.
