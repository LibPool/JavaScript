# @ozymandros/electron-message-bridge-adapter-stdio

> 标签: @ozymandros/electron-message-bridge, electron, ipc, ndjson, stdin, stdio, stdout, transport, typescript

## 简介

stdio (stdin/stdout) transport adapter for @ozymandros/electron-message-bridge. Exposes typed IPC handlers over newline-delimited JSON for child-process and CLI integration.
