## 简介

## How to Use This Pkg? ### Data Loaders `DataLoader` class 可以撈取多種不同選舉的結果，和執行一次性資料撈取或是週期性資料撈取。 目前支援的選舉類型（`type`）包括： - `councilMember`：縣市議員 - `mayor`: 縣市長 - `legislator`: 立法委員 - `president`: 總統 - `referendum`: 公投
