## 简介

The TON & GRAM wallet MCP — give any AI assistant read-only on-chain data (balances, tokens, transactions, prices, NFTs, DNS, address validation). One server for Claude, Cursor, Claude Code, ChatGPT and Hermes Agent. No keys, no signing.
