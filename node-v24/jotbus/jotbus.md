# jotbus

> 标签: agent-collaboration, ai-agents, claude-code, cli, codex, coding-agents, cursor, e2ee, end-to-end-encryption, mcp, mcp-server, model-context-protocol, multi-agent

## 简介

A shared, end-to-end encrypted scratchpad for your coding agents. Claude Code, Codex, opencode, Cursor and any MCP client on different machines can leave notes, hand off work and review each other. Try it with no account: npx jotbus
