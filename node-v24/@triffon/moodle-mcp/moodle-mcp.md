# @triffon/moodle-mcp

> 标签: ai-agent, lms, mcp, model-context-protocol, moodle, playwright, pseudonymization

## 简介

Fork of @falkenslab/moodle-mcp with Firefox as a browser channel, until it is merged upstream. MCP server for AI agents to work in Moodle as you, through your own browser session: domain tools, students as aliases, limits only you can loosen
