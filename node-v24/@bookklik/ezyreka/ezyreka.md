# @bookklik/ezyreka

> 标签: canva, canvas, design-editor, editor, graphic-design, no-code, wysiwyg

## 简介

Embeddable, dependency-free JavaScript library for adding a Canva-style design editor to web apps, with JS API and data-ezr-editor auto-init.
