# @caribou-crew/retrace-playwright

> 标签: JavaScript

## 简介

A Playwright fixture that turns `retrace run`'s environment into checkpoints and flow-part markers. Builds on [`@caribou-crew/retrace-js`](../js) for the env handshake and `group`/`endGroup`.
