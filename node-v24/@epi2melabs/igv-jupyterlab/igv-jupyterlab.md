# @epi2melabs/igv-jupyterlab

> 标签: jupyter, jupyterlab, jupyterlab-extension, widgets

## 简介

igv-jupyterlab is an extension for Jupyter Lab and traditional Jupyter Notebooks which wraps igv.js.
