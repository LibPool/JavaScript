# @sqwig/vue

> 标签: contenteditable, rich-text-editor, spellcheck, vue, vue-component, vue3, wysiwyg

## 简介

Vue 3 component for Sqwig — the text box with spellcheck built in. Client-side dictionary spellcheck; text never leaves the browser.
