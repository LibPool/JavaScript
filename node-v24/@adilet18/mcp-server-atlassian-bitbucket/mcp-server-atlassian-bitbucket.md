# @adilet18/mcp-server-atlassian-bitbucket

> 标签: ai, ai-connector, ai-integration, anthropic, atlassian, bitbucket, claude, cli, external-tools, llm, mcp, mcp-inspector, mcp-server, model-context-protocol, pull-request, repository, resources, server, tooling, tools, typescript, version-control

## 简介

Node.js/TypeScript MCP server for Atlassian Bitbucket. Enables AI systems (LLMs) to interact with workspaces, repositories, and pull requests via tools (list, get, comment, search). Connects AI directly to version control workflows through the standard MC
