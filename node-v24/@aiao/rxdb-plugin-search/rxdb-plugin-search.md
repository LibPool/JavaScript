# @aiao/rxdb-plugin-search

> 标签: aiao, fts5, full-text-search, postgresql, rxdb, search, sqlite, tsvector

## 简介

Reactive full-text search plugin for Aiao RxDB, backed by SQLite FTS5 or PostgreSQL tsvector.
