# @ozaco/db

> 标签: JavaScript

## 简介

A reactive, adapter-agnostic database module. You declare tables with a column DSL; every read is a lazily-built query you can also **watch**; every write announces a change that watchers — and other nodes — see. The backend is a plugin: the same code run
