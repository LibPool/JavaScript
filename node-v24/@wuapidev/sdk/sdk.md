# @wuapidev/sdk

> 标签: messaging, sdk, webhooks, whatsapp, whatsapp-api

## 简介

TypeScript SDK for wuapi, a WhatsApp API for developers. Link numbers by QR or pairing code, send and receive messages, manage chats, contacts, groups and channels, split them into projects and verify webhooks.

## 官网

- 官网：https://wuapi.dev/docs
- 源码仓库：git+https://github.com/wuapidev/wuapi-typescript.git
