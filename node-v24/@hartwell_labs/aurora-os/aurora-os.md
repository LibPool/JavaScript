# @hartwell_labs/aurora-os

> 标签: browser, desktop, os, terminal, typescript, virtual-filesystem, webos, window-manager

## 简介

Aurora — a complete operating system in the browser. Window manager, virtual file system, terminal with 35+ commands, 8 applications, themes, wallpapers and procedural audio. TypeScript, zero runtime dependencies.
