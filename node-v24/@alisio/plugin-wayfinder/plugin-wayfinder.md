# @alisio/plugin-wayfinder

> 标签: alisio-plugin, specification-driven-development, workflow

## 简介

Coordinates a resumable specification-driven development workflow by delegating bounded phases to fresh Alisio child sessions and persisting validated artifacts in the workspace.
