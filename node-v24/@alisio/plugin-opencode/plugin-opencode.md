# @alisio/plugin-opencode

> 标签: alisio-plugin, model-provider, opencode

## 简介

OpenCode Console (Zen) model provider for Alisio: fail-closed Responses, Chat Completions and Anthropic Messages routing over the unauthenticated OpenCode catalog.
