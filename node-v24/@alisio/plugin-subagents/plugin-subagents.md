# @alisio/plugin-subagents

> 标签: agent-harness, ai, alisio-plugin, coding-agent, llm, multi-agent, openai-compatible, plugins, subagents

## 简介

Subagents for Alisio: delegate tasks to specialized agents in separate child sessions with narrowed permissions, parallel execution, git worktree isolation and a live agent tree. Built-in, disableable plugin.
