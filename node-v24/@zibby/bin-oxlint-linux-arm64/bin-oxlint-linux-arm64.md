# @zibby/bin-oxlint-linux-arm64

> 标签: JavaScript

## 简介

Vendored oxlint 1.73.0 binary for linux/arm64. Redistribution of the oxc project's oxlint (https://github.com/oxc-project/oxc) fetched from the official GitHub release and sha256-pinned by Zibby at publish time. Installed only on matching os/cpu.
