# @awbx/cronix-sdk

> 标签: cron, cronix, hmac, manifest, scheduler, typescript

## 简介

App-side SDK for cronix: declare cron jobs in code, build the manifest, verify signed triggers. Framework-agnostic — works with anything that exposes a Web Request (Hono, Bun, Workers, Vercel) or via a sister adapter package for Express / Fastify / Koa /
