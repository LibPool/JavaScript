# @lucky-office/excel

> 标签: excel, excel-preview, lucky-office, ole-attachment, vue, vue-office, vue3, xls, xlsx

## 简介

基于 vue-office 二次开发的 Vue Excel 预览组件，支持 .xlsx/.xls 渲染、OLE 附件预览/下载/拖拽、单元格选择等能力。
