# @clawnify/routes

> 标签: JavaScript

## 简介

One-line, reliable API discovery for Clawnify apps — serves /api/openapi.json (the contract) + a lean /llms.txt index, generated from your live Hono routes, and makes /api/* 404s self-describing.
