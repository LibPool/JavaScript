# @normalized-db/denormalizer

> 标签: Denormalizer, IndexedDB, JavaScript, NoSQL, Normalization, Normalizer, ObjectDB, Reverse references, TypeScript

## 简介

Denormalize `JavaScript` objects from a normalized data structure based on a simple schema (implemented with `TypeScript`).
