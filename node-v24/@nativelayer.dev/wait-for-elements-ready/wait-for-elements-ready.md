# @nativelayer.dev/wait-for-elements-ready

> 标签: DOM, HTMLElement, MutationObserver, custom-elements, fouc, html, lifecycle, orchestration, promise, ready, web-components

## 简介

Reveal your page only when all Web Components are ready and functional. No timers, no polling, no FOUC.
