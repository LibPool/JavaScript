# @spendthebits/mcp-giftcards

> 标签: ai-agents, base, gift-cards, mcp, model-context-protocol, stablecoin, usdc, x402

## 简介

MCP server that lets an AI agent search, price and buy SpendTheBits gift cards over x402, with the owner's limits and the card code kept out of the model's context.
