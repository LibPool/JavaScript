# @inaya-network/bridge-sdk

> 标签: JavaScript

## 简介

Cross-chain $INAYA transfer + cross-chain staking SDK for the Inaya Network (SOW-1). Separate from @inaya-network/custody-sdk (file custody) so upload-only consumers don't pay for this surface.
