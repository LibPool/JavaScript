# @samerecord/core

> 标签: deduplication, drizzle, entity-resolution, fuzzy-matching, pgvector, record-linkage, samerecord, typescript

## 简介

Type-safe entity-resolution DSL. Declare entities, fields, scopes, and scoring channels in a TypeScript config; the matcher (@samerecord/server) runs the queries against PostgreSQL + pgvector. Cross-references between scoring channels and declared fields/
