# @ccgf/flow-field

> 标签: ccgf-shared, cocos, flow-field, pathfinding

## 简介

流场寻路：多单位共用一张方向场，复用 @ccgf/pathfinding 的网格。纯计算、零运行时依赖、不依赖引擎与框架
