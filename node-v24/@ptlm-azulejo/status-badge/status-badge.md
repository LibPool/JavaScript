# @ptlm-azulejo/status-badge

> 标签: JavaScript

## 简介

The `StatusBadge` component displays the current status of an item by combining a colored status indicator with a descriptive label. It provides a clear, compact way to communicate states such as information, success, warning, error, or neutral in lists,
