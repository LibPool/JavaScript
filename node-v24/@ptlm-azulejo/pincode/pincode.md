# @ptlm-azulejo/pincode

> 标签: JavaScript

## 简介

A pincode input is a specialized field for short numeric codes — verification codes, security PINs, or authentication tokens. Each digit sits in its own cell to keep entry readable and fast. Pair it with `AzField` when you need a label, help text, or vali
