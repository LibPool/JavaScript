# @omnis-x/watcher

> 标签: edge, middleware, nextjs, omnis-x, runtime-monitoring, security, threat-detection, waf

## 简介

Edge-safe, fire-and-forget beacon that feeds OMNIS-X Runtime monitoring from inside your app. One line in Next.js middleware. Signatures match locally — we never receive your users' raw request data.
