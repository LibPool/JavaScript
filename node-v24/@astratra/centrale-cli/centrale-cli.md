# @astratra/centrale-cli

> 标签: astratra, centrale, cli, debug-id, source-maps

## 简介

Outil en ligne de commande pour un tableau de bord de surveillance auto-hébergé : identifiants de débogage dans les builds, envoi des cartes de code, déclaration des déploiements.
