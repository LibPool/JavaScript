> 标签: astratra, biometric, cache, expo, expo-updates, mobile, netinfo, offline, push, react-native, session

## 简介

Mobile plumbing without the mobile runtime: secure token session with an injected keystore, a biometric gate, native push registration and foreground watching, a checkout round-trip that survives a missing native module, network state that only calls a mi
