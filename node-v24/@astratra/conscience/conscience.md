# @astratra/conscience

> 标签: agent, ai, astratra, audit, decisions, governance, memory, postgres

## 简介

Documented memory of an AI agent's decisions (outcomes, corrections, lessons with evidence, self-model, lineage, erasure) under a deterministic governor with no language model: constitution, permissions, budgets, isolation, kill switch, human approval.
