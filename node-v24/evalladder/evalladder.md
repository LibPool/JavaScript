# evalladder

> 标签: ai, anthropic, bedrock, eval, evals, gemini, llm, llm-as-judge, ollama, openai, promptfoo, release-gate, testing

## 简介

Test any AI model the same way. One plugin per vendor (Bedrock, OpenAI, Anthropic, Gemini, Ollama), code assertions by default, optional cheap-first LLM judge, per-model cost, and a CI release gate.
