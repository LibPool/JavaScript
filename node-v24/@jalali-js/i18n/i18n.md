# @jalali-js/i18n

> 标签: calendar, date, farsi, i18n, jalali, locale, pashto, persian, rtl, shamsi

## 简介

Locale data and display formatting for jalali-js: English, Farsi, and Pashto, relative time, format templates, strict parsing, numerals, and RTL.
