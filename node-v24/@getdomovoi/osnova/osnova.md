# @getdomovoi/osnova

> 标签: ai-agent, call-graph, claude-code, code-context, code-graph, code-index, code-intelligence, codex, coding-agent, cursor, kilo, mcp, mcp-server, opencode, pi, repo-map, static-analysis, tree-sitter

## 简介

Deterministic code map for AI coding agents: a tree-sitter symbol and call graph served over MCP and a CLI, with no embeddings, network or telemetry.
