# @codejoo/counter

> 标签: JavaScript

## 简介

浏览器端的轻量高性能计数引擎。单个共享的 `requestAnimationFrame` 心跳驱动所有 **count-up** （数字滚动）与 **count-down**（倒计时），渲染方式可插拔——默认纯文本，也可用富 SVG/DOM 渲染插件 （翻牌、里程表、圆环）。
