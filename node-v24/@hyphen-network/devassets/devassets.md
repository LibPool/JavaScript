# @hyphen-network/devassets

> 标签: api-key-manager, claude-code, cli, credential-management, developer-secrets, developer-tools, devtools, dotenv, env, env-manager, environment-variables, indie-dev, local-secrets, mcp, multi-project, secrets, secrets-manager, supabase, vault, vercel

## 简介

Local-first developer secrets manager — store encrypted env vars, manage API keys across projects, resolve provider identities, and inject secrets into commands. CLI + MCP server. No cloud, no account.
