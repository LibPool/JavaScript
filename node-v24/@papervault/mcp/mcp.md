# @papervault/mcp

> 标签: agent-safety, ai-agent, anthropic, claude, cryptography, disaster-recovery, mcp, model-context-protocol, papervault, secret-management, shamir-secret-sharing

## 简介

MCP server for PaperVault. Lets AI agents trigger paper-based secret backups as a safety step before sensitive operations — agents never see secret values.
