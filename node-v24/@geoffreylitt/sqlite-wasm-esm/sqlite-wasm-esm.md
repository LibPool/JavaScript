# @geoffreylitt/sqlite-wasm-esm

> 标签: JavaScript

## 简介

The new [SQLite WASM build](https://github.com/sqlite/sqlite/tree/master/ext/wasm/) is rather hard to use in modern JS apps, so this wrapper package tries to make this easier.
