# @localize-infra/schemas

> 标签: JavaScript

## 简介

Zod contracts shared between the `localize-infra` CLI, its API and its web surfaces. Publishing them separately is what lets the open-source CLI and a self-hosted API agree on request and response shapes without either depending on the other's internals.
