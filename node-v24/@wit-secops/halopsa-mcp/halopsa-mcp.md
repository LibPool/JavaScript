# @wit-secops/halopsa-mcp

> 标签: ai, halo, halopsa, helpdesk, llm, mcp, model-context-protocol, msp, psa

## 简介

MCP server for the HaloPSA API — tickets, ticket actions, cross-ticket action history, clients, sites, users, assets, projects, calendars, and lookups, with guarded ticket write tools. Read-only by default.
