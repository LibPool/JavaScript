# @wit-secops/crowdstrike-mcp

> 标签: ai, crowdstrike, edr, falcon, flight-control, llm, mcp, model-context-protocol, mssp

## 简介

MCP server for CrowdStrike Falcon built for Flight Control (MSSP) parents: every tool takes a tenant, and read tools can sweep all child tenants. Read-only by default.
