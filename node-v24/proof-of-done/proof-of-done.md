# proof-of-done

> 标签: ai-agents, claude-code, cli, coding-agents, cursor, reward-hacking, test-integrity, testing, verification

## 简介

Catch AI coding agents faking "done": detects deleted tests, skipped tests and removed assertions by diffing before vs. after.
