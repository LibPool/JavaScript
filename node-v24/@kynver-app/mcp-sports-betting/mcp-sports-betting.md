# @kynver-app/mcp-sports-betting

> 标签: JavaScript

## 简介

Kynver Sports Betting MCP server — recommend-only paper handicapping across six engines (NFL/NBA/MLB/NHL/NCAA plus horse racing): per-sport adjustable parameters, one-call game and race analysis (research → number → edge), day-board slate, paper ledger. N
