# @ucl-vr/ubiq

> 标签: ar, messaging, multiplayer, networking, ubiq, vr, xr

## 简介

Core messaging and networking library for the Ubiq platform. Provides connection management, message passing, and network scene abstractions over TCP and WebSocket.
