# @ucl-vr/ubiq-server

> 标签: multiplayer, networking, server, ubiq, vr, webrtc, websocket, xr

## 简介

Ubiq room server for multi-user XR applications. Provides room management, rendezvous, peer-to-peer signalling, and ICE server coordination.
