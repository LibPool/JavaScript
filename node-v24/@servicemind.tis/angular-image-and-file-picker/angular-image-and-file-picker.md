# @servicemind.tis/angular-image-and-file-picker

> 标签: angular, angular-material, camera-capture, drag-and-drop, file-upload, file-viewer, image-compression, image-upload, pdf-viewer

## 简介

Angular image and file upload component with drag-and-drop, pre-signed URL uploads, client-side compression, camera capture, and built-in preview for images, PDFs, video, and Excel.
