# @frontmcp/plugin-skilled-openapi

> 标签: agent-skills, agentfront, frontmcp, mcp, model-context-protocol, openapi, plugin, skills

## 简介

FrontMCP plugin that serves a REST API to the model as skills from an OpenAPI-based bundle, behind three tools: search_skill, load_skill and run_workflow

## 官网

- 官网：https://frontmcp.dev/reference/plugins/skilled-openapi
- 源码仓库：git+https://github.com/agentfront/frontmcp.git
