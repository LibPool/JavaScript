# @frontmcp/plugin-approval

> 标签: agentfront, approval, authorization, frontmcp, human-in-the-loop, mcp, model-context-protocol, plugin, tool-approval

## 简介

Approval plugin for FrontMCP: refuses to run marked tools until an approval is recorded for the caller
