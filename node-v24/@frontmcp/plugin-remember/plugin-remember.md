# @frontmcp/plugin-remember

> 标签: agentfront, encryption, frontmcp, mcp, memory, model-context-protocol, plugin, redis, remember, session, vercel-kv

## 简介

Remember plugin for FrontMCP: encrypted key-value memory for tools (this.remember) in session, user, tool and global scopes, stored in memory, Redis or Vercel KV

- 官网：https://frontmcp.dev/reference/plugins/remember
- 源码仓库：git+https://github.com/agentfront/frontmcp.git
