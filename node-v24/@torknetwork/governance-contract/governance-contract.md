# @torknetwork/governance-contract

> 标签: JavaScript

## 简介

Tork governance contract v3.1: full receipts, assessment digest, Genie tool types, feedback, golden-set tests, per-tenant Tower link, and optional providers/caching. One build, embedded in every Tork product.
