# @zooid/budd-runtime-docker

> 标签: JavaScript

## 简介

Docker runtime for budd. Spawns the agent CLI inside a container with a workspace mount and an env allowlist.

- npm 页面：https://www.npmjs.com/package/@zooid/budd-runtime-docker
