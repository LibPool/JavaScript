# @michi-vz/vue

> 标签: a11y, accessibility, ai, canvas, charting, charting-library, charts, d3, data-visualization, dataviz, framework-agnostic, graph, llm, llm-ready, mcp, michi-vz, responsive, svg, typescript, visualization, vue, vue-charts, vue3, vuejs, webgpu

## 简介

Vue 3 charts - SVG, canvas & WebGPU rendering, accessible by default, with an LLM-ready data context. Thin wrapper over the framework-agnostic @michi-vz engine.
