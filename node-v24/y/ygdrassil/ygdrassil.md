# ygdrassil

> 标签: fsm, hash, react, router, state-machine, url, vanilla, web-components

## 简介

Lightweight state machine that syncs state with the URL hash for bookmarkable app states. React components/hooks plus a zero-dependency vanilla JS twin with Web Components.
