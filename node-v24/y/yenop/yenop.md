# yenop

> 标签: ai-agents, authorization, cedar, claude-code, mcp, policy, security

## 简介

The local-first execution authorization layer for AI coding agents: ALLOW / ASK / DENY on every action, one set of rules across Claude Code, Cursor, Codex, Gemini and MCP.
