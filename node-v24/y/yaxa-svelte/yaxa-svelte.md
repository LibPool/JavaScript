# yaxa-svelte

> 标签: nuxt-ui, opengraph, robots, seo, sitemap, svelte, svelte5, sveltekit, tailwind, tailwindcss-v4, ui-components

## 简介

The Intuitive Svelte UI Library — Nuxt UI v4 equivalent for SvelteKit 2.7+ & Svelte 5 with automated SEO, dynamic OpenGraph cards, sitemaps, robots.txt, and Tailwind CSS v4.
