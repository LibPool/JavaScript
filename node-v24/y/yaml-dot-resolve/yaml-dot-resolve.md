# yaml-dot-resolve

> 标签: ci, config, configuration, environment, interpolation, jsonpath, placeholder, serverless, stage, substitution, template, typescript, yaml

## 简介

Recursive ${...} YAML placeholder substitution: stage-aware config, dotted paths, nested placeholders, and optional defaults (:-).
