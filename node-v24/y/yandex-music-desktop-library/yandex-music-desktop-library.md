# yandex-music-desktop-library

> 标签: audio, controller, desktop, media, music, typescript, volume, windows, yandex

## 简介

TypeScript library for controlling Yandex Music desktop application on Windows. Provides event-based and promise-based APIs for media control and multi-device volume management.
