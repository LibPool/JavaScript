# ytdl-core-enhanced

> 标签: 2025, android-client, audio, authentication, download, downloader, enhanced, fast, hls, innertube, m3u8, mp3, mp4, multithreading, production-ready, reliable, signature-decoding, stable, stream, video, youtube, ytdl, ytdl-core

## 简介

Stable YouTube downloader using Android InnerTube client with automatic signature decoding. Features reliable format extraction, restricted video support with cookies, multi-threading, and production-ready 2025 compatibility.
