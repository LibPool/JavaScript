# yzkx-skills

> 标签: JavaScript

## 简介

yzkx-cli AI Skills 交互式安装器——由用户勾选要安装到哪些 Agent 工具（含 Hermes 原生四段式 skills 与 WorkBuddy 直拷，跳过 PromptScript 全局安装报错）
