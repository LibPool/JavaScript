# yz-module-user

> 标签: JavaScript

## 简介

* server: 服务地址,   * loginLevel: 登陆级别,   * port: Port 各系统端口,   * path: 第三方登陆重定向地址path   * systemKey   * systemSecret   * resultPropertyKey: axios 返回数据取哪个字段   * axios: 系统axios   * encryMode: 密码加密方式      userModule.encryMode = {       none: 0,
