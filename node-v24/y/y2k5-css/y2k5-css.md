# y2k5-css

> 标签: 2005, aesthetic, css, framework, geocities, nostalgia, retro, web-2000s, windows-xp, y2k

## 简介

A CSS framework that brings back the look and feel of the 2005 web: XP blue gradients, solid borders, 11px Verdana, tables for layout, and pure y2k5 nostalgia.
