# yt-transcript-gemini-mcp

> 标签: ai-sdk, captions, claude, gemini, llm-tools, mcp, model-context-protocol, subtitles, transcript, youtube, youtube-search

## 简介

YouTube search and transcripts as an MCP tool. Combinable filters on views, date, duration and subscriber count. Free captions first, Gemini when they are missing, yt-dlp last.
