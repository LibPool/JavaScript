# yudada-map3d

> 标签: JavaScript

## 简介

**yudada-map3d** 是一个基于 **Vue 3 + Three.js** 的 3D 省份地图组件库，用于在网页中快速渲染可配置的 3D 省级地图（默认示例为湖南省，也支持传入任意省份/地区的 GeoJSON）。
