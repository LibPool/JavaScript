# your-cto-jev

> 标签: ai-agents, claude-code, codex, cursor, gemini-cli, git-hooks, guardrails, jev, pre-commit, secrets

## 简介

A sharp-tongued CTO gatekeeper for AI coding agents: blocks leaked secrets in git commits and destructive shell commands in Claude Code, Cursor, Gemini CLI and Codex, using TypeSafe Jev.
