# yash-auth-flow

> 标签: access-token, auth, auth-forge, auth-library, authentication, backend, express, jwt, login-logic, multi-account, node, otp, prisma, rbac, refresh-token, rest-api, secure-auth, security, session-management, signup-logic, user-management

## 简介

Production-ready multi-account authentication library (Auth Forge) for Node.js, Express, Prisma, and PostgreSQL. Secure JWT auth, OTP, and dynamic email verification flow.
