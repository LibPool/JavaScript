# yql-weather-location

> 标签: geolocation, location, promise, weather, yahoo, yidea, yql

## 简介

A NPM util for easier YQL(Yahoo Query Language) with Q Promise in nodejs, also provides helper for getting location and weather.

## 官网

- 官网：https://github.com/yidea/yql-weather-location
- 源码仓库：https://github.com/yidea/yql-weather-location
- npm 页面：https://www.npmjs.com/package/yql-weather-location

## 获取地址

- npm 安装：`npm install yql-weather-location`
- npm registry：https://registry.npmjs.org/yql-weather-location
- Node 要求：node >= 0.8.0
