# yim-wxmini-sdk

> 标签: JavaScript

## 简介

yim-wxmin-sdk(yideb im wechat miniprogram sdk)是IM消息针对微信小程序的js开发工具包，基于websocket与im服务器连接，用于im消息相关功能。

- npm 页面：https://www.npmjs.com/package/yim-wxmini-sdk
