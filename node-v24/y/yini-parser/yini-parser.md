# yini-parser

> 标签: config, config-file, configuration, data-format, files, ini, ini-parser, json-alternative, parse, parser, read, settings, yaml-alternative, yini, yini-parser

## 简介

Official Node.js (TypeScript) parser for YINI, an INI-inspired, indentation-insensitive configuration format with clear nested sections and explicit structure.
