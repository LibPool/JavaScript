# yangmengke

> 标签: JavaScript

## 简介

- 安装命令 'npm i nrm -g' - nrm ls 列出所有镜像源地址列表 - nrm use <列表名称> ### 发包 - 1.注册npm账号 - 2.切换镜像源至Inpm官方镜像源nrm use npm - 3.初始化要发布的包文件和目新点包管理文件package. json - 4.命令行登陆npm官网 - 5.查看登录账号是否正确 - 6.发布自己编写完成的包 - 7.查看包是否发布成功 - 8.如果此包不经常使用就进行删除，近免污染npn镜像源
