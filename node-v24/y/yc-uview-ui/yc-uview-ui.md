# yc-uview-ui

> 标签: uniapp, uview, vue3.0, yc-uview-ui

## 简介

同时支持 Vue3.0 和 Vue2.0，你没看错，现在 uView 支持 Vue3.0 了！（不支持nvue，此版本为uView1.0的分支）-- 核心基于 uView1.8.3
