# yoyo-pi

> 标签: coding-agent, pi-extension, pi-package, terminal, tui, vim

## 简介

Polished pi extension pack: Vim prompt editing, choice pickers, themes, status bars, file/todo sidebars, context snapshots, and plan mode.
