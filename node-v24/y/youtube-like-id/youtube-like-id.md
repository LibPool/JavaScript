# youtube-like-id

> 标签: alphanumeric, base62, encoder, id, obfuscation, short-id, url-shortener, youtube

## 简介

Generate YouTube-style short IDs from numbers. Lightweight, fast, and reversible base62 encoder with optional obfuscation.
