# yyt

> 标签: nightwatch, yyt

## 简介

* 基于 `nightwatch` ui 测试框架出来的 开箱即用 一键安装 0 配置，test 框架 yyt * 配合 `docker-yyt` 可应用用 gitlab-ci 的定时任务实现 线上定时回归测试 * 已引入 `nightwatch-helpers` * 支持 `nightwatch --env xxx` 写法
