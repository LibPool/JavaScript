# ys-http-server

> 标签: JavaScript

## 简介

静态 http 文件服务器(对照 http-server)的一套实现方案，包含了文件夹内模板渲染，响应体压缩，http 缓存等一系列的实现。

## 官网

- npm 页面：https://www.npmjs.com/package/ys-http-server
