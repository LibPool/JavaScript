# youtube-videos-api-v2

> 标签: live-videos, search, youtube, youtube-api, youtube-data-api, youtube-videos-api

## 简介

Lightweight Node.js wrapper around the YouTube Data API v3 for fetching live videos, all channel videos, and query-based search results.
