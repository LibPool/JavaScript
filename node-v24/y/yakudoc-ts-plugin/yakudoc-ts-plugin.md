# yakudoc-ts-plugin

> 标签: japanese, jsdoc, language-service-plugin, translation, tsserver, typescript, vscode

## 简介

tsserver Language Service Plugin that swaps JSDoc documentation shown in the editor (hover / completion / signature help) with translations in your language
