# @codexview/cli

> 标签: agent, ai, claude-code, cli, codex, markdown, transcript

## 简介

CLI that renders AI coding agent transcript logs (Codex exec JSONL and rollouts, codex-team, Claude Code, OpenCode, GitHub Copilot) as compact plaintext markdown. Wraps @codexview/adapters.
