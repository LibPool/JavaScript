# pandascrow

> 标签: api, escrow, fintech, nigeria, pandascrow, payments, sdk, typescript, webhooks

## 简介

Official Node.js / JavaScript SDK for the Pandascrow v3 API: escrow, wallets, payouts, bank transfers, virtual accounts, invoices, payment links, KYC and webhooks.
