# koishi-plugin-dcqq-bridge

> 标签: bridge, chatbot, discord, forward, koishi, onebot, plugin, qq, relay

## 简介

Discord 频道与 QQ 群（OneBot）之间的消息转发：完整渲染 embed、换算时间码、@全体、防 ping、失败降级、可选的机器翻译与 EVE 术语表
