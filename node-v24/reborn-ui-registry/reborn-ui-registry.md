# reborn-ui-registry

> 标签: JavaScript

## 简介

Reborn-UI 组件 registry 数据分发包（纯 JSON，无代码）；在 components.json 中设置 registry: "reborn-ui-registry" 即可让 CLI 与数据独立升级
