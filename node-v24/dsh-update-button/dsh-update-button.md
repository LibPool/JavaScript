# dsh-update-button

> 标签: JavaScript

## 简介

在 DeepSeek Harness 界面内部提供一个实体「更新」按钮：点击后可检查并安装 DSH 最新版本。

## 官网

- npm 页面：https://www.npmjs.com/package/dsh-update-button

## 历史版本号

- 当前版本：0.1.0

- 0.0.0-stage
- 0.1.0

## 获取地址

- npm 安装：`npm install dsh-update-button`
- npm registry：https://registry.npmjs.org/dsh-update-button
- Node 要求：^22.19.0 || >=24.0.0
