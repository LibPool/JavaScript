# community-cordova-plugin-diagnostic

> 标签: bluetooth, camera, cordova-android, cordova-ios, diagnostic, ecosystem:cordova, location, nfc, notifications, permissions, runtime-permissions, settings, wifi

## 简介

Check and request device permissions and the state of Location/WiFi/Camera/Bluetooth/NFC/notifications settings, compiling only the modules an app uses. Community fork of cordova.plugins.diagnostic.
