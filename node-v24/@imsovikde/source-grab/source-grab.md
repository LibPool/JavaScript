# @imsovikde/source-grab

> 标签: asset-downloader, cdp, chrome-extension, devtools-protocol, media-grabber, mv3, network-interceptor, resource-sniffer, sidepanel

## 简介

Chrome extension that captures every file your browser loads in real-time using Chrome DevTools Protocol. Filter, search, and download individually or as ZIP.
