# @cdr-kit/react-ui

> 标签: JavaScript

## 简介

Styled component variants for @cdr-kit/react — ConditionBadge, AccessStepper, SubscribeButton, VaultCard + DX primitives. CSS-variable themed; no Tailwind, no lucide, no framer-motion hard deps.
