# @cdr-kit/story

> 标签: JavaScript

## 简介

Thin TypeScript wrappers over @story-protocol/core-sdk: register IP, mint license tokens, attach PIL terms, register derivatives, wrap IP. The agent-as-publisher surface for cdr-kit.
