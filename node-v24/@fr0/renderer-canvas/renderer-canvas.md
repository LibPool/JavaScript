# @fr0/renderer-canvas

> 标签: JavaScript

## 简介

Isomorphic Canvas 2D renderer for fr0. Targets the standard CanvasRenderingContext2D interface so the same code runs in browsers, OffscreenCanvas, and node-side Skia (@napi-rs/canvas).
