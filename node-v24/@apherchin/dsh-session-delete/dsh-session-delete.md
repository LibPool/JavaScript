# @apherchin/dsh-session-delete

> 标签: cordis, deepseek-harness, delete, dsh, dsh-plugin, plugin, session, sidebar

## 简介

DSH session-row menu "Delete conversation": permanently deletes a session's on-disk data, cascades into subagent sessions, and refuses live sessions (host + client plugin).
