# @miraiclip/localize

> 标签: captions, i18n, localization, miraiclip, translation

## 简介

Translate a Miraiclip project into other languages: text, captions, html block text, markers and the narration script, through any translator (a chat model, DeepL, or your own), as one variant document per language.
