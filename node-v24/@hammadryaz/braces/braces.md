# @hammadryaz/braces

> 标签: curly-brace, filters, interpolation, lightweight, mustache, render, ssr, streaming, string, template, template-engine, typescript, xss-safe, zero-dependency

## 简介

A tiny, fast, dependency-free template engine for universal {curly-brace} interpolation. TypeScript-first, XSS-safe, filter pipes, streaming SSR.
