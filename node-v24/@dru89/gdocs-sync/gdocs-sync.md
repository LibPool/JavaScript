# @dru89/gdocs-sync

> 标签: cli, drive, google-docs, markdown, sync

## 简介

Markdown <-> Google Docs sync engine and CLI: incremental push, high-fidelity fetch, comments-safe updates, tabs, images, callouts. Built against the dru89/doc-tools scenario catalog.
