# @missionsquad/mcp-etherscan

> 标签: ai, blockchain, crypto, ethereum, etherscan, evm, explorer, llm, mcp

## 简介

Read-only MCP server for Etherscan V2 and compatible EVM explorers, with configurable base URL, chain ID, and context-bounded responses.
