# @ac-kit/app-report

> 标签: events, logging, pipeline, reporting, sink

## 简介

Shared event-pipeline contracts for logging, reporting and process output: one ReportEvent shape, one ISink interface, one ScopeTracker, fed to pluggable sinks and formatters.
