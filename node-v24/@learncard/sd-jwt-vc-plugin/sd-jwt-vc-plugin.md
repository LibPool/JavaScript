# @learncard/sd-jwt-vc-plugin

> 标签: JavaScript

## 简介

SD-JWT-VC holder + verifier support for LearnCard. Implements RFC 9901 (SD-JWT) and draft-ietf-oauth-sd-jwt-vc.
