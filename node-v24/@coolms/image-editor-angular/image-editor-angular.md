# @coolms/image-editor-angular

> 标签: canvas, coolms, fabric, image-editor

## 简介

The CoolMS image editor for Angular: a fabric.js v6 engine behind a framework-agnostic adapter, with transform, filter and insert tools, a layers panel, and a save flow wired to the Media Library and VFS.
