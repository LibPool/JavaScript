# @coolms/sheet-editor-angular

> 标签: angular, coolms, editor, sheet, spreadsheet, xlsx

## 简介

The CoolMS spreadsheet editor for Angular: a grid over an immutable sheet-document model, with cell formats, merges, column and row sizing, and multi-sheet editing.
