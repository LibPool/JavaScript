# @braedonsaunders/appkit-egress-proxy

> 标签: agents, appkit, application-framework, egress, proxy, sni, ssrf, typescript

## 简介

Fail-closed egress chokepoint for agent sandboxes — explicit HTTP and CONNECT proxying plus transparent DNAT interception with SNI and Host sniffing, policy and audit ports, and no TLS interception.
