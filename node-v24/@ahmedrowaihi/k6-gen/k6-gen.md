# @ahmedrowaihi/k6-gen

> 标签: codegen, k6, load-testing, openapi, typescript

## 简介

Programmatic generator: OpenAPI spec → typed k6 client (one function per operation), TS types, and faker-backed data builders. No hey-api plugin required.
