# @moshcoder/moshpit-dns

> 标签: alt-root, dns, moshpit, namespace, resolver

## 简介

Resolve Moshpit names on this machine. A tiny DNS bridge for .whatever endings, routed per-suffix so the rest of the internet is untouched.
