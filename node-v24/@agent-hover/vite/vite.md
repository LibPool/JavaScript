# @agent-hover/vite

> 标签: agent-hover, ai-agent, devtools, mcp, react, vite-plugin

## 简介

Point at your UI, your agent understands it. Dev-only Vite plugin for React: click any element and send precise context to Claude Code, Cursor, Codex or any MCP agent.
