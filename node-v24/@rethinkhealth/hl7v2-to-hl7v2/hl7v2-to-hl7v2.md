# @rethinkhealth/hl7v2-to-hl7v2

> 标签: health, healthcare, hl7, hl7v2, nodejs, typescript

## 简介

hl7v2 plugin to transform hl7v2 messages to a hl7v2. Useful for sanitizing messages.

## 官网

- 官网：https://www.rethinkhealth.io/hl7v2/docs
- 源码仓库：git+https://github.com/rethinkhealth/hl7v2.git
- npm 页面：https://www.npmjs.com/package/@rethinkhealth/hl7v2-to-hl7v2
