# @actcore/web-runtime

> 标签: act, agent, agent-component-tools, ai, browser, component-model, jspi, mcp, tools, wasip3, wasm, webassembly, webmcp

## 简介

Web runtime for ACT (Agent Component Tools) — loads and runs signed wasm agent tools in the browser, and exposes them to browser agents via WebMCP
