# @fdnpm/fd-module-cli

> 标签: freedom, middleware

## 简介

@fdnpm/fd-module-cli是前端模块开发的脚手架，统一规范前端模块开发，并且为前端模块开发提供统一的开发环境，构建环境。此脚手架开发的模块可为可视化页面搭建系统提供页面组装模块
