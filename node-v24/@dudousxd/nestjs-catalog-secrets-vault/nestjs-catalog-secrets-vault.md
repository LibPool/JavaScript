# @dudousxd/nestjs-catalog-secrets-vault

> 标签: catalog, encryption, hashicorp, nestjs, secrets, transit, vault

## 简介

HashiCorp Vault Transit secret vault for @dudousxd/nestjs-catalog: connection credentials encrypted by Vault, so the key never reaches the application and rotation never reaches the database.
