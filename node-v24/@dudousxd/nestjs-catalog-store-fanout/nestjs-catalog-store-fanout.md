# @dudousxd/nestjs-catalog-store-fanout

> 标签: catalog, dual-write, migration, nestjs, snapshots, warehouse

## 简介

Fan-out store for @dudousxd/nestjs-catalog: one primary that decides, N followers kept in step, with a durable failure journal, snapshot replay and a comparison tool for migrating between engines without a big-bang cutover.
