# @dudousxd/nestjs-diagnostics-telescope

> 标签: diagnostics, diagnostics-channel, extension, nestjs, observability, tanstack-intent, telescope, watcher

## 简介

nestjs-telescope extension for @dudousxd/nestjs-diagnostics — one generic watcher records every aviary:<lib>:<event> diagnostic event in the Telescope dashboard.
