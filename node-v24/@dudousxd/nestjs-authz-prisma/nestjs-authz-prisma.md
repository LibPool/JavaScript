# @dudousxd/nestjs-authz-prisma

> 标签: authorization, authz, nestjs, permissions, prisma, rbac, roles

## 简介

Prisma RBAC persistence for @dudousxd/nestjs-authz — roles, permissions, and a Gate seam (zero connection ownership, structural client).
