# @dudousxd/nestjs-catalog-store-duckdb

> 标签: catalog, duckdb, nestjs, parquet, snapshots, warehouse

## 简介

DuckDB + Parquet warehouse store for @dudousxd/nestjs-catalog: one Parquet object per snapshot batch, read back through read_parquet.
