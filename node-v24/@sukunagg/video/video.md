# @sukunagg/video

> 标签: a11y, accessible, captions, chapters, hls, media-player, react, rsc, ssr, sukuna-ui, video, video-player

## 简介

Standalone, SSR-safe React video player from sukuna-ui — chapters, thumbnails, captions, playlists, HLS — themeable with --vp-* CSS variables, no Tailwind or sukuna-ui required.
