# @sukunagg/fx

> 标签: accessible, animation, canvas, effects, particles, react, react-server-components, reduced-motion, rsc, ssr, sukuna-ui, tailwind-v4, webgl

## 简介

Canvas, WebGL and SVG effects for sukuna-ui: client islands over a server-rendered CSS poster, on one shared frame loop that pauses off-screen and holds a still frame under reduced motion.
