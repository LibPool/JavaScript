# @unicode/unicode-1.1.5

> 标签: bidi, case-folding, characters, code points, data, regex, regexp, symbols, unicode, unicode-data

## 简介

JavaScript-compatible Unicode data. Arrays of code points, arrays of symbols, and regular expressions for Unicode v1.1.5’s categories, scripts, blocks, bidi, and other properties.
