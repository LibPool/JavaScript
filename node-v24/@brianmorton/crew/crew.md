# @brianmorton/crew

> 标签: agent, agents, ai, automation, claude, cli, coding-agent, jira, linear

## 简介

Autonomous agent team: role-specialized coding agents that propose typed work into Linear or Jira, gate material changes behind human-approved PRDs, and drain approved work into PRs — running on your machine against your Claude subscription.
