# @pdrittenhouse/vite-plugin-virtual-glob

> 标签: dynamic-import, glob, import, storybook, virtual-module, vite, vite-plugin

## 简介

Vite plugin that creates virtual modules from filesystem globs — solves the static-path limitation of import.meta.glob() when source paths are determined at runtime.
