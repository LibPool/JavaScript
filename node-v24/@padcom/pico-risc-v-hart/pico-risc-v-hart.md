# @padcom/pico-risc-v-hart

> 标签: bare-metal, emulator, jit, risc-v, riscv, rv64, webassembly

## 简介

A RISC-V (RV64GC) computer for bare-metal programs, in Node.js and browsers: compile C, run it, talk to its UART. The core of Pico RISC-V.
