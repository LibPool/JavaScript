# @tandem/synthetic-browser

> 标签: JavaScript

## 简介

This library contains a *browser VM* that is intented for debugging, designing, and editing web applications. It comes with *loads* of features that enables you perform certain tasks against your application that you couldn't otherwise do in a normal web
