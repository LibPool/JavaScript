# modelbrain-mcp

> 标签: ai-memory, local-first, mcp, memory, model-context-protocol, modelbrain

## 简介

Thin MCP stdio client for ModelBrain, the private memory layer for AI assistants. Connects to the ModelBrain desktop app already running on your computer; does not bundle ModelBrain itself.
