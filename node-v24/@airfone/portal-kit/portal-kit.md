# @airfone/portal-kit

> 标签: JavaScript

## 简介

The shared building blocks of the AirFone web portals: an API client with cookie or bearer sessions, the console UI kit (theme, shell, tables, dialogs), step-up and Google sign-in, passkeys and money formatting.
