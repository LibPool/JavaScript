# @iwantfyi/conformance-kit

> 标签: agentic-commerce, conformance, demand-protocol, iwant.fyi, mcp, spec

## 简介

Conformance test kit for the iwant.fyi demand-side protocol (v1.1). Points at any MCP server URL and verifies spec section 15 compliance, including the v1.1 additions (signed webhooks, error taxonomy, idempotency, capabilities, transparency).
