# @guardbee/mcp-agent-graph-auditor

> 标签: ai-security, autogen, crewai, devtools, excessive-agency, guardbee, langgraph, mcp, multi-agent, security

## 简介

MCP server that builds a reachability graph across multi-agent orchestration configs (LangGraph, CrewAI, AutoGen/ag2) to find transitive excessive agency — an agent with no dangerous tool of its own that can still reach one through delegation or group mem
