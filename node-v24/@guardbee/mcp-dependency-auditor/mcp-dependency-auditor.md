# @guardbee/mcp-dependency-auditor

> 标签: cve, dependency-audit, devtools, guardbee, mcp, npm-audit, osv, sca, security, supply-chain, vulnerability-scanner

## 简介

Dependency vulnerability scanner (OSV) for npm and pip manifests, with single-package lookups for PyPI, crates.io, Maven, Go and RubyGems; CLI and MCP server
