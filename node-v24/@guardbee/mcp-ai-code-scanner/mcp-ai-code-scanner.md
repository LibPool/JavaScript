# @guardbee/mcp-ai-code-scanner

> 标签: ai-security, devtools, guardbee, llm-security, mcp, owasp-llm-top-10, security

## 简介

MCP server that scans code for insecure LLM/AI integration patterns — client-exposed API keys, unsafe handling of model output, excessive agent tool permissions, and PII sent to third-party LLMs
