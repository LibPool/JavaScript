# @guardbee/mcp-security-proxy

> 标签: ai-gateway, anthropic, audit, claude, data-masking, dlp, firewall, guardbee, guardrails, llm, llm-firewall, llm-gateway, mcp, mcp-gateway, model-context-protocol, openai, pii, pii-masking, prompt-injection, proxy, security

## 简介

MCP security gateway and LLM firewall: masks PII and secrets, blocks prompt injection and toxic flows (lethal trifecta), approves risky calls and keeps a hash-chained audit log, for MCP servers and LLM APIs
