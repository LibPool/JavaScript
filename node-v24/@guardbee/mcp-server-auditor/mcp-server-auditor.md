# @guardbee/mcp-server-auditor

> 标签: ai-security, devtools, guardbee, mcp, mcp-security, sast, security

## 简介

MCP server that audits other MCP servers' tool definitions for insecure patterns — excessive-agency tool names, shell/eval/SQL/SSRF sinks fed by raw tool input, overly permissive schemas, hardcoded secrets, and wildcard CORS
