# @playcanvas/inspector

> 标签: debug, devtools, inspector, playcanvas, webgl, webgpu

## 简介

A debug panel for PlayCanvas apps: the entity hierarchy, assets, frame graph, render targets, textures, meshes, materials, scripts, cameras, memory, shaders and physics of a running app
