# @newblock/iautopay-mcp

> 标签: autonomous-payment, blockchain, eip-3009, mcp, model-context-protocol, payment, usdc

## 简介

iAutoPay is an MCP service that enables AI agents to automatically pay for purchases. It currently runs on Base chain (operated by Coinbase) and supports USDC payments.
