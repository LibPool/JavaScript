# @diveinto/obs

> 标签: jsonl, logging, nextjs, node, observability, opentelemetry, otel, structured-logging, trace-context, tracing

## 简介

Structured logging, tracing and metrics for Next.js and Node services: one record shape, rotating files, W3C trace context, optional OpenTelemetry export
