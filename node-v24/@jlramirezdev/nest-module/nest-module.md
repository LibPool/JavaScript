# @jlramirezdev/nest-module

> 标签: cli, module, nestjs, typeorm

## 简介

> CLI generator para **NestJS + TypeORM** que crea un módulo completo (Entity, DTOs, Repository, Service, Controller y módulo) con convenciones de naming y soporte para plurales irregulares.
