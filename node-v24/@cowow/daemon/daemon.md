# @cowow/daemon

> 标签: acp, agent-client-protocol, claude, cowow, mcp, rag

## 简介

ACP bridge daemon: dials cowow-acp-proxy, hosts a ClaudeAcpAgent per ACP connection, injects cowow's MCP server into every session/new
