# @pioneret/tracker-football

> 标签: ball-tracking, football, gsap, live-tracker, match-tracker, react, react19, soccer, sports, ui-components

## 简介

A React library for real-time football match UI, featuring live ball position tracking, event display, and components for an interactive match experience.
