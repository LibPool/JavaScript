# @getintel/agent

> 标签: ai, analytics, chatgpt, claude, crawlers, getintel, perplexity

## 简介

Report AI bot visits (ChatGPT, Perplexity, Claude, Gemini) from your server to GetIntel — Analytics → AI crawlers.
