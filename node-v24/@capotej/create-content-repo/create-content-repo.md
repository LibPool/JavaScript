# @capotej/create-content-repo

> 标签: agent, cli, content, scaffold, ssg, typst

## 简介

Scaffold a content-repo: .typ sources + agent skills + stdlib-Python build orchestrator. Run via npx @capotej/create-content-repo <name>.
