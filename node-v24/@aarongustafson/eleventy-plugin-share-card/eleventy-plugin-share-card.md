# @aarongustafson/eleventy-plugin-share-card

> 标签: 11ty, eleventy, eleventy-plugin, og-image, open-graph, share-card, sharp, social-image

## 简介

Build-time social share-card (OG image) generator for Eleventy. Composites text over a base image using sharp + SVG — no external services required.
