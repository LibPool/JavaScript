# @monte3l/groundwork

> 标签: bootstrap, claude-code, claude-code-plugin, cli, developer-tools, scaffolding, typescript

## 简介

CLI that bootstraps a TypeScript project with a strict toolchain and Claude Code setup, or read-only surveys an existing one, plus a /customize plugin that tailors it to current guidance.
