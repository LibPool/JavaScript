# @gmfe/keyboard

> 标签: JavaScript

## 简介

`@gmfe/keyboard` 是 gmfe 组件库的键盘导航扩展包，为 `@gmfe/table` 和 `@gmfe/table-x` 提供键盘操作能力。支持在表格单元格之间通过方向键、Tab 键和 Enter 键导航，并提供多种键盘单元格组件（输入框、选择器、日期选择器等）。
