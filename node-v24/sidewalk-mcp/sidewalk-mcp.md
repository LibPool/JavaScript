# sidewalk-mcp

> 标签: agent, claude, mcp, mcp-server, qa, sidewalk, walkthrough

## 简介

The MCP server that lets an AI agent write a sidewalk walkthrough a person walks in a Chrome side panel; starts the walkd daemon if none is answering
