# @paladini/lattes-parser

> 标签: brasil, cnpq, curriculo, curriculum, extrator, lattes, lattes-parser, parser, pesquisa, typescript, xml

## 简介

Independent toolkit to edit Plataforma Lattes curriculum XML locally (CLI/TypeScript) with automatic backups. Export/import on the platform stay manual. Not affiliated with CNPq.
