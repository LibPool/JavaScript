# @tomradex/ipc

> 标签: tomrade, tomrade-plugin, types

## 简介

ctx.ipc — the typed channel contract between the main process and the renderer. Channels are contributed by plugins; the shell supplies the transport. — declarations for full-mode plugins; Tomrade provides the code at run time
