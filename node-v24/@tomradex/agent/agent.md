# @tomradex/agent

> 标签: tomrade, tomrade-plugin, types

## 简介

ctx.agent — the platform every engine runs on: threads, runs, the ledger, blocks, suspended workflows, run-scoped undo, and the engine/workflow/playbook/policy registries — declarations for full-mode plugins; Tomrade provides the code at run time
