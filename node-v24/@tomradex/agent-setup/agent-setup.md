# @tomradex/agent-setup

> 标签: tomrade, tomrade-plugin, types

## 简介

One-click agent setup: Tomrade installs a chosen agent's CLI in the background and watches its sign-in, no terminal needed — declarations for full-mode plugins; Tomrade provides the code at run time
