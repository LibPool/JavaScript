# @tomradex/engine-terminal

> 标签: tomrade, tomrade-plugin, types

## 简介

Gemini CLI as an in-app agent over ACP that can also take a ticket in a terminal, and Antigravity CLI (agy) for a terminal only — declarations for full-mode plugins; Tomrade provides the code at run time
