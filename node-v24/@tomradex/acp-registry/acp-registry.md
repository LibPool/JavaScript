# @tomradex/acp-registry

> 标签: tomrade, tomrade-plugin, types

## 简介

Agents from the ACP registry: the person adds one in Settings and Tomrade runs it over ACP through npx, set up like any plugin agent — declarations for full-mode plugins; Tomrade provides the code at run time
