# @tomradex/herdr

> 标签: tomrade, tomrade-plugin, types

## 简介

ctx.herdr — herdr (the terminal workspace manager for coding agents) on this machine: its socket, whether it runs, and the panes it holds. Optional; nothing changes without it. — declarations for full-mode plugins; Tomrade provides the code at run time
