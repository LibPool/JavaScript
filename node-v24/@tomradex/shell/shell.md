# @tomradex/shell

> 标签: tomrade, tomrade-plugin, types

## 简介

A bash tool for in-process agents: run in the thread's workstream checkout or the project's Files folder, asked before each command, never served over MCP — declarations for full-mode plugins; Tomrade provides the code at run time
