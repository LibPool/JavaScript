# @fraios/inbox-client

> 标签: analytics, fraios, ingestion, jitsu-compatible, semantic-events

## 简介

First-party JavaScript / TypeScript client for the fraios ingestion service. Sends analytics envelopes to the canonical /inbox/{source} path for server-side Semantic Event normalization. Preserves the core @jitsu/js call surface while using fraios routing
