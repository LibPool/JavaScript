# @fgiova/mini-dynamo-mapper

> 标签: aws, dynamo-mapper, dynamodb, orm

## 简介

A type-safe DynamoDB mapper for Node.js built on top of [@fgiova/mini-dynamo-client](https://github.com/fgiova/mini-dynamo-client).
