# @map-library/supermap

> 标签: JavaScript

## 简介

SuperMap 适配器是基于 Leaflet 和 SuperMap iClient 的地图组件，它为统一地图库提供了兼容 SuperMap 的功能实现。该适配器封装了复杂的底层接口，提供简单易用的 API，支持标记管理、图层控制和点聚合等高级功能。
