# dsh-github-status

> 标签: auth, deepseek-harness, dsh-plugin, gh, github, status, ui

## 简介

GitHub connection status for DeepSeek Harness: a pill in the conversation header shows a red or green dot, one click starts the GitHub device login, and the dot turns green with your account name once authorized. 在对话顶部显示 GitHub 连接状态：红/绿灯 + 一点登录，授权后自动变绿并显示
