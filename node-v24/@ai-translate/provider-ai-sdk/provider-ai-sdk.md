# @ai-translate/provider-ai-sdk

> 标签: ai, ai-sdk, anthropic, i18n, internationalization, l10n, llm, localization, openai, translation, vercel

## 简介

Run ai-translate against any AI SDK provider — OpenAI, Anthropic, Google, Bedrock, or a gateway — with one interchangeable translation and semantic-audit provider.
