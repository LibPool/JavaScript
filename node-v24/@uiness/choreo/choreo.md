# @uiness/choreo

> 标签: animation, intersection-observer, react, reveal, scroll-animation, uiness, web-animations

## 简介

Animates a whole site from what is already on the page: inspects the DOM, works out what each element is, and choreographs entrances, staggers, counters and hover touches. Zero dependencies.
