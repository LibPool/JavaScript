# @uiness/map

> 标签: google-maps, map, mapkit, marker, openstreetmap, osm, react, slippy-map, tiles, uiness

## 简介

React maps with zero dependencies: OpenStreetMap or any XYZ tiles, markers and popups, and the same API on Google Maps or Apple Maps.
