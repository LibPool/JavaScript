# @claprox/insight-ui

> 标签: bitcore-cadex, blockchain, blockexplorer, cadex, cadexcoin, front-end, insight

## 简介

An open-source frontend for the Insight API. The Insight API provides you with a convenient, powerful and simple way to query and broadcast data on the Cadex network and build your own services with it.
