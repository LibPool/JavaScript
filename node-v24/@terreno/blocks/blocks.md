# @terreno/blocks

> 标签: agents, ai, generative-ui, terreno, zod

## 简介

Shared contracts for agent-driven UI: ask schemas, simple cards, and whole-reply block documents — part of Terreno, the batteries-included TypeScript framework for universal apps.
