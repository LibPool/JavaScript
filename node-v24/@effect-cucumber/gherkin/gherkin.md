# @effect-cucumber/gherkin

> 标签: bdd, cucumber, feature-file, gherkin, parser

## 简介

Gherkin feature-file parsing for effect-cucumber. Effect-native; effect is a peer dependency only (ADR-EC-021), never bundled. Uses core effect's FileSystem service interface; depends on no concrete platform implementation.
