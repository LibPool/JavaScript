# @ninna-ui/cli

> 标签: cli, nextjs, ninna-ui, project-generator, react, react-router, scaffolding, starter-template, tailwindcss, tailwindcss-v4, vite

## 简介

CLI tool for scaffolding Ninna UI projects - Vite + React, Next.js 15, React Router v7 templates with 5 theme presets. Tailwind CSS v4.
