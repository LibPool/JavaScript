# @oreefy/datetime

> 标签: date, datetime, duration, ecosystem, edge, format, oreefy, timeago

## 简介

A lightweight, zero-dependency TypeScript date-time library for flexible pattern formatting, input binding, duration calculation, and relative time (ago).
