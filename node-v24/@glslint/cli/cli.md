# @glslint/cli

> 标签: deck.gl, glsl, linter, lsp, luma.gl, maplibre, shader, shadertoy, webgl

## 简介

A GLSL checker and language server for WebGL shader toolkits (luma.gl/deck.gl, maplibre, ShaderToy) and any project
