# @zukhruf/docker

> 标签: container, docker, docker-context, docker-engine, engine-api, unix-socket

## 简介

A client for the Docker Engine API on Node.js. It selects the engine that the Docker CLI selects, and it sends HTTP requests to that engine through a Unix socket, a Windows named pipe or SSH, with no Docker CLI and no third-party dependencies.
