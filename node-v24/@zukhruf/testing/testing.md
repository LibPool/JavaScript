# @zukhruf/testing

> 标签: disposable, docker, fixtures, integration-tests, mariadb, mysql, postgres, sql-server, testing

## 简介

Disposable fixtures for integration tests: Docker containers and database servers, SQLite and DuckDB databases, HTTP servers and streams. Node's global setup and global teardown remove what a killed test run left behind.
