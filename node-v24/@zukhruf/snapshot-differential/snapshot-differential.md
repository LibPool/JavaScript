# @zukhruf/snapshot-differential

> 标签: cdc, change-data-capture, diff, elt, etl, incremental, snapshot, snapshot-differential

## 简介

Change data capture for an upstream with no change log: compare each scan with the last snapshot, get the new and changed records, and let a deletion policy judge each key that the scan no longer lists.
