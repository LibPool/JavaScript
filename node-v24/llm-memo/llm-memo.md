# llm-memo

> 标签: anthropic, cache, claude, fixtures, gemini, llm, memoize, openai, record, replay, testing, vcr

## 简介

Cache LLM API calls by request hash, on disk or in memory, so tests and dev loops stop paying for repeat calls. Works with the OpenAI, Anthropic and Gemini SDKs, including streams. Zero dependencies.
