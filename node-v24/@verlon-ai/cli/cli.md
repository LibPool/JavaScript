# @verlon-ai/cli

> 标签: agent-integration, agents, ai, cli, gateway, llm, management, verlon

## 简介

Command-line interface for Verlon AI — script gates, API keys, experiments, and analytics from the terminal. The dashboard's agent-operable twin: every operation an agent can do, you can do from a shell. Agent integration protocol: https://verlon.ai/AGENT
