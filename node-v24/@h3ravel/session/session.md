# @h3ravel/session

> 标签: H3, framework, h3ravel, laravel, modern, nodejs, persist, session, typescript, web

## 简介

Provides a unified session management layer for h3ravel, with secure encryption, consistent API design, and optional adapters (memory, file, redis, db).
