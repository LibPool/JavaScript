# @massing/geometry-math

> 标签: aec, autocad, bim, cad, geometry, osnap, polar-tracking, snapping

## 简介

Pure CAD geometry for the browser: object snapping, polar tracking, dynamic input, drawing inference, placement validation, and an AutoCAD-style command grammar. No DOM, no three.js, no network.
