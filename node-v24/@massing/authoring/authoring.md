# @massing/authoring

> 标签: aec, authoring, cad, command-loop, snapping

## 简介

The authoring session — armed tool, half-collected arguments, and cursor-to-point resolution. Snapping happens before the reducer, and hover and pick resolve through one function so the crosshair cannot lie.
