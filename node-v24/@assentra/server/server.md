# @assentra/server

> 标签: ai-agents, approvals, audit-log, ecdsa, human-in-the-loop, mcp, policy-as-code, rbac, web-crypto, workflow

## 简介

Deterministic approval-workflow compiler, RBAC policy engine and ECDSA-signed action seals. Framework-free; runs in Node 20+, edge runtimes and browsers.
