# firebase-edge

> 标签: cloudflare-workers, edge, firebase, firestore, identity-toolkit, rest

## 简介

Zero-dependency Firebase Auth + Firestore admin utilities over REST. Runs on Cloudflare Workers, Vercel Edge, Deno, Bun and Node 20+.
