# @centralkg/map-react-native

> 标签: central.kg, cluster, kyrgyzstan, map, maplibre, marker, polyline, react-native

## 简介

Map of Kyrgyzstan (central.kg) for React Native — <CentralMap>, <Marker>, <Polyline>, clustering and a REST client over map.central.kg, authenticated with a per-service API key. Wraps @maplibre/maplibre-react-native.
