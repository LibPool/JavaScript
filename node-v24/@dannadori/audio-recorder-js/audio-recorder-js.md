# @dannadori/audio-recorder-js

> 标签: JavaScript

## 简介

`@dannadori/audio-recorder-js`は、Web Audio API を活用した高性能なオーディオ録音・処理ライブラリです。AudioWorklet を使用したリアルタイム処理により、低遅延で高品質なオーディオ処理を実現します。
