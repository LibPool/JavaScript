# @10p.io/browser-serve

> 标签: JavaScript

## 简介

headless Chrome の画面を配る `browser` child。`planx server` が optional child として spawn する (bundle は `browser.main.mjs`)。配信の中身は `@10p.io/computer-serve` と同じ pipeline (SourceHost / SourceRuntime / ScreenHost / ScreenView) で、Chrome は `Screen` 実装 1 個 (`CdpScreen`)
