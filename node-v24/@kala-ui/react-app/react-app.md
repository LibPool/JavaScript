# @kala-ui/react-app

> 标签: app-shell, charts, components, dashboard, data-table, design-system, react, typescript, ui

## 简介

App-level composite components for Kala UI — AppShell, Sidebar, Header, DataTable, ApexCharts wrappers, drag-and-drop and dashboard widgets — built on @kala-ui/react primitives.
