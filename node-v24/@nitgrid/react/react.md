# @nitgrid/react

> 标签: data-grid, data-table, datagrid, grid, nitgrid, react, spreadsheet, table, virtual-scroll, virtualization

## 简介

NitGrid — lightweight, high-performance data grid for React. Virtual scrolling to millions of rows, sorting, filtering, selection, pagination, pinning, inline editing and CSS-variable theming.
