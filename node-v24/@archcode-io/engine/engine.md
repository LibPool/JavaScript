# @archcode-io/engine

> 标签: archcode, architecture, c4, diagram, dsl, elk, notation

## 简介

ArchCode — an open notation for software architecture. The reference engine: parser with byte-exact round trip, model, semantic checks, lenses, layout and SVG.
