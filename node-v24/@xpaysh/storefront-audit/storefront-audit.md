# @xpaysh/storefront-audit

> 标签: agentic-commerce, ai-readiness, audit, cli, conformance, lint, llms-txt, robots-txt, schema-org, ucp

## 简介

Conformance + readiness auditor for agentic-commerce storefronts. Checks /llms.txt, /.well-known/ucp, schema.org JSON-LD on PDPs, robots.txt AI-crawler allowlist, A2A agent-card, RFC 9728 OAuth resource metadata, and rejects fictitious well-known URIs. Li
