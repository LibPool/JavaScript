# @xpaysh/acp-session-store

> 标签: acp, agentic-commerce, checkout-session, dynamodb, session-store

## 简介

Storage backend for ACP checkout sessions, used by the agentic-commerce-for-* plugin family. Ships an InMemorySessionStore (default; suitable for single-instance dev) and a DynamoDBSessionStore (production; reads/writes the xpay-acp-sessions table with TT
