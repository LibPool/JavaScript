# @v-office/site-manifest

> 标签: JavaScript

## 简介

Derives a site's manifest at build time — the installed platform package versions and the platform surfaces the build reaches — and writes it to dist/site-manifest.json for the build worker to report. A Vite plugin for Vite sites (guest, owner) and an Ast
