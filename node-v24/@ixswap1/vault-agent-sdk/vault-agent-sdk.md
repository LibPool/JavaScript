# @ixswap1/vault-agent-sdk

> 标签: agent, avalanche, erc-4626, erc-7540, investax, ixs, rwa, vault

## 简介

Read IXS ERC-7540 vault state, build unsigned vault transactions, and wire an LLM agent to propose them. No wallet, no keys, no hosted service.
