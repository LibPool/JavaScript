# @ixook/request

> 标签: JavaScript

## 简介

Axios 请求客户端。默认按「HTTP 200 + `{ code, data, message }` 信封」解包；token、未授权之后的行为和 Toast 由调用方注入。不提供单例，不放业务 API。
