# @maplesnow/icon

> 标签: cli, dashboard-icons, favicon, hd-icons, icon, lobehub, logo

## 简介

Icon acquisition pipeline: brand-correct, standardized (512x512 RGBA PNG) icon files or URLs from a merged LobeHub + HD-Icons + dashboard-icons index. Single-file Python 3 stdlib wrapped for npx.
