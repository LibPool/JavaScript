# @salesforcedevs/dx-css-variables

> 标签: JavaScript

## 简介

This repository is a collection of variables for the DX projects (Salesforce Developers, API Hub), with a collection of SDS and C360 defined colours, spacing, typography, etc, and unique valules specific to individual properties.
