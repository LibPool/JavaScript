# @goonerlabs/idempotency

> 标签: deduplication, exactly-once, fintech, idempotency, idempotent, payments, retry, safety, web3

## 简介

Exactly-once processing for money-moving operations — run an operation once per key, replay the stored result on retries, and dedupe concurrent callers. Zero dependencies, pluggable async store.
