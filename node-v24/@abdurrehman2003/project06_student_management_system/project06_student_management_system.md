# @abdurrehman2003/project06_student_management_system

> 标签: JavaScript

## 简介

This Student Management System allows users to enroll in courses, pay tuition fees, and view their enrollment status. It prompts for the student’s name, course selection, payment method, and confirms enrollment with status details.
