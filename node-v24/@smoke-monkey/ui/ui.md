## 简介

Drop-in React chat UI for AI agents and LLMs. Streaming markdown, tool-call cards, charts, mermaid diagrams, syntax highlighting and inline ask-user prompts, with a headless runtime and a normalized event contract. Works with OpenAI, Anthropic, Gemini, La
