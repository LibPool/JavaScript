# @textifyme/mcp

> 标签: claude, cursor, markdown, mcp, model-context-protocol, ocr, speech-to-text, textify, transcription, youtube-transcript

## 简介

Local (stdio) shim for the hosted Textify MCP server — transcribe audio/video, OCR images, and convert files & web pages to text from Claude, Cursor, and any MCP client.
