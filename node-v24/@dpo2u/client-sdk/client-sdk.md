# @dpo2u/client-sdk

> 标签: adgm, aes-gcm, anchor, compliance, consent-manager, dpdp, dpo, encryption, gdpr, groth16, lgpd, mcp, micar, model-context-protocol, pdpa, privacy, rest-api, shadow-drive, solana, sp1, zk-proof

## 简介

TypeScript client for dpo2u-solana — on-chain compliance primitives (LGPD/GDPR/DPDP), AES-GCM encrypted storage, MCP REST client for audit/docs toolkit, and OAuth login via `dpo2u-cli login`. Build on Solana.
