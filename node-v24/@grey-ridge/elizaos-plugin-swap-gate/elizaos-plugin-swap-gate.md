# @grey-ridge/elizaos-plugin-swap-gate

> 标签: base, defi, elizaos, honeypot, plugin, pre-trade, token-safety, trading-agent, x402

## 简介

Pre-trade token-safety gate for Base trading agents (ElizaOS): honeypot, sellability, admin-control and liquidity-vs-size checks via Grey Ridge /gate/swap, paid inline with x402 USDC ($0.008/call). Call before every swap.
