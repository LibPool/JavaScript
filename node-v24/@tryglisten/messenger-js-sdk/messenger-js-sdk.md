# @tryglisten/messenger-js-sdk

> 标签: ai, chat, customer-support, glisten, messenger, react, widget

## 简介

Official Glisten messenger SDK — a tiny, typed, SSR-safe wrapper that loads the Glisten chat widget in any JS/React app. The <script> embed is the no-code alternative; this renders the identical widget.
