# @fullstackunicorn/thumbnails

> 标签: blurhash, filesystem, fullstackunicorn, image-processing, image-resize, metadata, nodejs, responsive-images, sharp, thumbnails, utilities

## 简介

A Node.js utility for generating responsive image thumbnails and metadata (size, ratio, blurhash) using Sharp and Blurhash.
