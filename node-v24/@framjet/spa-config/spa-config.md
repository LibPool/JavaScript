# @framjet/spa-config

> 标签: JavaScript

## 简介

Universal configuration loader for SPAs that works seamlessly across Node.js, browsers, Vite, Webpack, Deno, and Bun. Automatically detects runtime environments and loads config from appropriate sources with type-safe getters and smart fallbacks.
