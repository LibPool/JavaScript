# @laikacms/decap-ai

> 标签: ai, decap-cms, headless-cms, vercel-ai-sdk

## 简介

AI chat integration for Decap CMS: server adapter, React widget, model providers, all bundled with their own ai SDK runtime so consumers stay decoupled.
