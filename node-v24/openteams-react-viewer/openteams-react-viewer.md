# openteams-react-viewer

> 标签: chat, collaboration, openteams, react, team-workspace, webrtc, yjs

## 简介

React component and hooks for OpenTeams, the open-source bring-your-own-server team workspace. Self-contained: includes the <teams-app> UI.
