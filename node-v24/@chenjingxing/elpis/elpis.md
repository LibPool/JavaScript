# @chenjingxing/elpis

> 标签: dashboard, element-plus, elpis, enterprise, fullstack, koa, koa2, scaffold, vue, vue3, webpack

## 简介

基于 **Koa** 的后台与 **Vue 3 + Element Plus** 前端的工程化脚手架：服务端按目录自动加载 Controller / Service / Router / 中间件等；前端通过 **model 配置** 驱动 Dashboard 菜单与 Schema 列表页。
