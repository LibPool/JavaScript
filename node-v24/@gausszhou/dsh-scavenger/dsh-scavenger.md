# @gausszhou/dsh-scavenger

> 标签: JavaScript

## 简介

Scavenge a DeepSeek Harness profile: pre-flight static checks (composition, resolution, contract) that identify which plugins cause boot errors, and clean them up (plan → apply, backup/rollback included).
