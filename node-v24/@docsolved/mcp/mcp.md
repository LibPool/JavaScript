# @docsolved/mcp

> 标签: document-ai, document-extraction, mcp, model-context-protocol, ocr

## 简介

DocSolved MCP server and installer: lets MCP-compatible coding agents (Codex, Claude Code, Gemini CLI) discover DocSolved capabilities, fetch integration guidance, and extract structured data from local documents through the DocSolved API.
