# synseq-ng

> 标签: angular, audio, music, piano, sequencer, soundboard, synseq, synth, webaudio

## 简介

Angular 22 standalone library wrapping a synth keyboard, sequencer, presets and editable sequence cache (localStorage). Zero configuration: no styling setup, no providers.
