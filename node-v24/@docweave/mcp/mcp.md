# @docweave/mcp

> 标签: ai-agents, chromium, claude, cursor, extract-text, generate-pdf, html-to-pdf, invoice, mcp, mcp-server, model-context-protocol, pdf, pdf-generation, pdf-to-markdown, pdf-to-text, read-pdf, receipt

## 简介

MCP server for AI agents to generate AND read PDFs: generate_pdf (HTML, a URL, or a template + JSON → PDF) and read_pdf (a PDF → text/markdown). Works with Claude, Cursor, and any MCP client.
