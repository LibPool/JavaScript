# @runwisp/js

> 标签: astro, background-jobs, cron, cron-history, dashboard, job, nestjs, nextjs, node-cron, nuxt, runwisp, scheduler, sveltekit

## 简介

node-cron compatible scheduler backed by RunWisp: every run is recorded with its output, exit code and duration, and shown in a web UI.
