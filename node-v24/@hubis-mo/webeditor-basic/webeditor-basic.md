# @hubis-mo/webeditor-basic

> 标签: JavaScript

## 简介

A lightweight, modern, zero-external-icon-dependency Rich Text Editor component for **Vue 3** and **Nuxt 3/4**, built on top of [TipTap](https://tiptap.dev/).
