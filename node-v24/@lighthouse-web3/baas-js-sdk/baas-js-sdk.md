# @lighthouse-web3/baas-js-sdk

> 标签: api-key, backup, content-addressed, deduplication, encryption, fastcdc, lighthouse, restore, sdk, snapshot

## 简介

Lighthouse Backup SDK for JavaScript/TypeScript: workspace-scoped incremental, content-addressed backup and restore with API-key bearer authentication and optional client-side encryption.
