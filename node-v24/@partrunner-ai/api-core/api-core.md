# @partrunner-ai/api-core

> 标签: JavaScript

## 简介

Framework-agnostic Node backend primitives shared by PartRunner apps: Nexus DB access, structured logging, audit trail, feature flags, maintenance mode and pagination. Vercel HTTP adapters live under the ./vercel subpath.
