# @ngxviewbuilder/runtime

> 标签: angular, dashboard, drag-and-drop, form-builder, json-forms, low-code, view-builder

## 简介

Native Angular runtime for NGX View Builder: renders forms, dashboards, data tables and guided flows defined as JSON.
