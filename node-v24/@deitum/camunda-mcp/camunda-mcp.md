# @deitum/camunda-mcp

> 标签: ai, bpmn, camunda, camunda7, dmn, llm, mcp, model-context-protocol, workflow

## 简介

MCP server for Camunda 7 — BPMN/DMN definitions, process instances, incidents, user tasks, history and DMN evaluation over the engine REST API.
