# @akshay2642005/fingerprint-sdk

> 标签: bot-detection, browser-fingerprinting, fingerprint, fraud-prevention, signal-collection

## 简介

Browser signal collection SDK — gathers browser signals, packages them into a versioned SignalPackage, and ships them to the fingerprint ingress. No fingerprint computation in the browser.
