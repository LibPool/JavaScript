# rarefaction-lsp-mcp

> 标签: ai-agent, call-graph, call-hierarchy, claude-code, claude-code-plugin, code-intelligence, code-navigation, codex, codex-plugin, coding-agent, context-engineering, impact-analysis, language-server, language-server-protocol, lsp, mcp, mcp-server, model-context-protocol, static-analysis, token-usage

## 简介

MCP server that gives AI coding agents an LSP call graph for one symbol: callers, callees, implementations, tests and impacted files in one call, instead of reading whole files.
