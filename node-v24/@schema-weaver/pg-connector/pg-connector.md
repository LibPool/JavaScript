# @schema-weaver/pg-connector

> 标签: agent, bridge, database, ddl, devtools, ide, migration, postgres, postgresql, schema, schema-weaver, tunnel

## 简介

Bridge between the Schema Weaver browser IDE and your PostgreSQL databases. Runs near the DB, never exposes credentials, executes queries and migrations on demand.
