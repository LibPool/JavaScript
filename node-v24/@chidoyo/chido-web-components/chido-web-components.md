# @chidoyo/chido-web-components

> 标签: custom-elements, form-controls, localization, react, shadow-dom, theming, typescript, web-components

## 简介

Framework-independent Web Components for forms and user interfaces, with TypeScript definitions, customizable themes, English and Spanish validation, and optional React wrappers.
