# @web3r/flowerkit

> 标签: browser, browser-utilities, cjs, click-outside, debounce, deep-clone, deep-merge, dom, dom-events, esm, event-listener, fetch, formdata, frontend, javascript, local-storage, ssr, ssr-safe, throttle, tree-shaking, typescript, url-search-params, utilities

## 简介

Typed, tree-shakable utilities for browser APIs, DOM events and SSR: debounce, throttle, fetch, FormData, arrays, objects and strings. ESM/CJS.
