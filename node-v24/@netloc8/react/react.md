# @netloc8/react

> 标签: GeoGate, cookie-consent, country-detection, eu-detection, gdpr, geo-blocking, geoip, geolocation, ip-geolocation, location-detection, netloc8, react, react-context, react-hook, timezone, useGeo

## 简介

React geolocation components. Provider, useGeo() hook, and GeoGate for conditional rendering by country, region, city, and EU membership.
