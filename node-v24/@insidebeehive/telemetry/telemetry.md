# @insidebeehive/telemetry

> 标签: fly.io, http-logging, observability, opentelemetry, tracing, zero-code

## 简介

Zero-code telemetry for Node services on Fly.io: OpenTelemetry traces (parent-based, sampled) + 100% HTTP access/payload logging as JSON lines on stdout. Activate with NODE_OPTIONS="--import @insidebeehive/telemetry/register" — no app code.
