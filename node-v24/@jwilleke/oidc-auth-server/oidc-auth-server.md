# @jwilleke/oidc-auth-server

> 标签: authorization-server, device-flow, node-oidc-provider, oauth2, oidc, pkce, rfc8628, smart-on-fhir

## 简介

OpenID Connect authorization server for Node apps: a thin, hardened wrapper around node-oidc-provider with device authorization (RFC 8628), UserInfo, refresh rotation and PKCE, where the host app keeps sign-in.
