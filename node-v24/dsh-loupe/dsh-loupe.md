# dsh-loupe

> 标签: deepseek-harness, dsh, dsh-plugin, explain, loupe, selection

## 简介

Select text in a DSH conversation and explain it in a floating window: independent channel, no session pollution, pinnable to a real session. / 划词解释浮窗：选中即弹、独立通道、不污染主会话、可固定成正式会话。
