# @webmaxru/cookieless-insights

> 标签: analytics, application-insights, azure, azure-monitor, beacon, cookieless, gdpr, no-cookie-banner, privacy, real-user-monitoring, rum, spa, static-site, telemetry

## 简介

Cookieless, consent-banner-free Real User Monitoring for static sites — sends page views and events to your own Azure Application Insights (free tier). Tiny beacon by default (~1–2 KB), optional Application Insights SDK adapter.
