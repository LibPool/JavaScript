# @ghub/glockdown-sdk

> 标签: JavaScript

## 简介

GLockdown for apps: the stage this app's GLockdown agent has set, read from the file the agent writes, and the call that raises this app one rung over pinned TLS. Hand-written on node: built-ins, no dependencies.
