# @ghub/gmint-sdk

> 标签: JavaScript

## 简介

The client for GMint, the broker that holds GitHub App keys: get a short-lived, narrowly scoped installation token over TLS 1.3 + mTLS with signed, channel-bound requests and sealed responses. No third-party dependencies.
