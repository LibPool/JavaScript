# @liquefy/cascade.reactive

> 标签: cascade, observable, proxy, reactive, signals, state management, temporal signals

## 简介

Temporal signals: reactive programming with ES6 proxies, where readers and writers of the same data are ordered in time. The reactive engine of Cascade.
