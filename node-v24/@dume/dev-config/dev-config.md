# @dume/dev-config

> 标签: a11y, axe-core, eslint, husky, lint-staged, oxlint, prettier, stylelint

## 简介

The configuration shared by my projects: Prettier, oxlint, ESLint and Stylelint configurations, a pre-commit hook with husky and lint-staged, accessibility checks with axe-core and Playwright, and Claude Code settings
