# @tinloof/tanstack-wsr

> 标签: offline, pwa, service-worker, ssr, tanstack, tanstack-router, tanstack-start, vite, vite-plugin, wsr

## 简介

Worker-Side Rendering (WSR) for TanStack Start: render selected routes inside a service worker — instant, offline, zero-flash document loads.
