# bun-app-window

> 标签: bun, desktop, ffi, frameless, ipc, titlebar, webview, webview2, window

## 简介

Native WebView2 window shell for Bun — frameless or system-decorated windows, DPI-aware geometry, typed IPC, system-accurate title bar
