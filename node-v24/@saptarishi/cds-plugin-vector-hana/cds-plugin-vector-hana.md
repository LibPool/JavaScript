# @saptarishi/cds-plugin-vector-hana

> 标签: ai, cap, cds, embeddings, hana, hana-cloud, joule, llm, rag, sap, semantic-search, vector-search, vector-store

## 简介

Vector store for SAP CAP with HANA Cloud's native REAL_VECTOR + COSINE_SIMILARITY. Includes a SQLite fallback for local development so you can build semantic-search features without paying for HANA. Composes with @saptarishi/cds-plugin-llm for embeddings.
