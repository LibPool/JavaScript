# @diceforge-sdk/renderer-web

> 标签: 3d, dice, renderer, tabletop, threejs, webgl

## 简介

Browser presenter for DiceForge: Three.js 3D dice with outcome-first animation, DOM fallback, reduced-motion support, and accessible announcements.
