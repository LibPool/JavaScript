# @theguysapp/books-host-sdk

> 标签: accounting, inventory, sdk, theguybooks

## 简介

The TypeScript client for the TheGuyBooks host API: create your clients' books and bring their owners in, sync inventory — typed calls, typed refusals, safe retries and a one-command conformance check.
