# @seoable/install

> 标签: claude, cursor, installer, mcp, model-context-protocol, seo, seoable, vscode, windsurf

## 简介

One-command installer for the Seoable MCP server across every MCP-aware client (Claude Desktop, Claude Code, Cursor, VS Code, Windsurf, Cline, Zed, Continue, Gemini CLI).

- 官网：https://seoable.dev/docs/mcp
- 源码仓库：git+https://github.com/seoable/installer.git
- npm 页面：https://www.npmjs.com/package/@seoable/install
