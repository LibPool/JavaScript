# @theyahia/orange-money-mcp

> 标签: africa-api, ai, claude, francophone-africa, ivory-coast-api, mcp, mcp-server, mobile-money, model-context-protocol, orange-money, payments, senegal-api

## 简介

MCP server for Orange Money WebPay (Senegal + 10 Francophone West/Central African countries) — 8 tools for web payments, status, cashin, cashout. OAuth2 Client Credentials with Basic auth header.
