# @mjasnikovs/pi-task

> 标签: JavaScript

## 简介

Deterministic task planning and spec-orchestration for local models — crash-safe /task pipelines with verify/enforce gates, a real-time remote web view, and web/docs/fetch/worker subagent tools.
