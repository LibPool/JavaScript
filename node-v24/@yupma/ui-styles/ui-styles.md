# @yupma/ui-styles

> 标签: Design styles, Tokens, UI kit, Web Design, YupMa

## 简介

@yupma/ui-styles is a comprehensive style library for the YupMa design system. It provides a suite of CSS and SCSS files with tokens and classes that can easily be modified according to need.
