# @openbrowse/mcp-server

> 标签: ai-agent, broker, browser-automation, mcp, model-context-protocol, oauth, openbrowse

## 简介

OpenBrowse MCP broker — an OAuth 2.1 + WebSocket bridge that lets external MCP hosts (Cursor, Claude Desktop, OpenCode, etc.) drive the OpenBrowse browser extension. Runs locally on 127.0.0.1.
