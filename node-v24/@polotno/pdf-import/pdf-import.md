# @polotno/pdf-import

> 标签: design editor, javascript, pdf, pdf import, pdf to canvas, pdf to editable design, pdf to json, polotno

## 简介

Convert PDFs into editable Polotno JSON designs with text, images, tables, and vector graphics in browsers and Node.js
