# @polotno/psd-import

> 标签: design editor, javascript, layered design, photoshop, polotno, psd, psd import, psd to editable design, psd to json

## 简介

Convert Photoshop PSD files into editable Polotno JSON designs while preserving text, vector, and raster layers
