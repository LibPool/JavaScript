# @next2d/builder

> 标签: JavaScript for Android, JavaScript for Linux, JavaScript for MacOS, JavaScript for Steam, JavaScript for Windows, JavaScript for Xbox, JavaScript for iOS, Multi-platform builder, Next2D

## 简介

Multi-platform builder for Next2d Framework, supporting export to various platforms such as macOS, Windows, iOS, Android and Web(HTML)
