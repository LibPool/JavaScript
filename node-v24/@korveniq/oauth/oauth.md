# @korveniq/oauth

> 标签: authentication, commonjs, esm, korveniq, login-with-korveniq, nodejs, oauth, oidc, openid-connect, pkce, typescript

## 简介

Official SDK for Login with Korveniq (OIDC Authorization Code + PKCE). Works in Node.js (CJS/ESM) and browsers (JS/TS).
