# @usetheo/orm

> 标签: decorators, dependency-injection, drizzle, orm, repository, theokit, transactional, typescript, usetheo

## 简介

Repository pattern + @InjectRepository decorator + agent-aware columns + @Transactional + schema export polyglot over drizzle-orm, consuming @usetheo/di for inversion of control. NestJS TypeORM-equivalent DX for the theokit ecosystem.
