# @usetheo/acp

> 标签: JavaScript

## 简介

Agent Client Protocol (ACP) server adapter for @usetheo/sdk. Exposes an SDKAgent over stdio JSON-RPC so Zed/Cursor/Claude Desktop can drive it. ADRs D349-D360.
