# @xd-cell/worker-sdk

> 标签: JavaScript

## 简介

`@xd-cell/worker-sdk` 是 XD Cell 面向业务自定义 Worker 的 runtime SDK。它的目标是在 Worker 运行时提供一层足够薄、接近 Cloudflare API 心智的资源抽象，而不是把底层 KV、D1、R2、service binding、内部 gateway path 或 capability 格式直接暴露给业务。
