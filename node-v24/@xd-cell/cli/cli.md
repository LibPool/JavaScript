# @xd-cell/cli

> 标签: JavaScript

## 简介

`@xd-cell/cli` 是 XD Cell 的命令行入口，用于登录、发布和管理站点。用户、CI 和 AI agent 都应通过 CLI 操作，不要直接拼接 pages-api HTTP 请求。

## 官网

- npm 页面：https://www.npmjs.com/package/@xd-cell/cli
