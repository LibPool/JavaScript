# @mnaoumov/obsidian-dev-toolkit

> 标签: obsidian, obsidian-plugin, tooling

## 简介

Tooling for Obsidian plugin development: the plugin builder for esbuild, vite, rollup, webpack and parcel, shared ESLint/Vitest configs, demo vaults and the release script.
