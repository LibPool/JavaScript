# @agent-sessions/dsh-comms

> 标签: JavaScript

## 简介

`@agent-sessions/dsh-comms` publishes each live top-level DeepSeek Harness session to the Agent Sessions presence socket. It adds `peers.list` and `message.send`, and delivers inbound messages through DSH's native `Agent.steer` path.
