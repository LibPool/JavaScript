# @agentxin-ai/plugin-tool-call-limit

> 标签: JavaScript

## 简介

`@agentxin-ai/plugin-tool-call-limit` enforces tool call quotas for [AgentXin AI](https://github.com/agentxin-ai/agentxin) agents. It tracks tool usage per thread and per run, blocking or ending execution once limits are exceeded while surfacing clear fee
