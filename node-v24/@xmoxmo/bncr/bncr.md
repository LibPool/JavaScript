# @xmoxmo/bncr

> 标签: JavaScript

## 简介

OpenClaw 的 Bncr 频道插件，用于将 Bncr / 无界客户端接入 OpenClaw，实现消息收发、媒体传输和会话管理。

- 源码仓库：git+https://github.com/xmoxmo/openclaw-bncr-channel.git
- npm 页面：https://www.npmjs.com/package/@xmoxmo/bncr
