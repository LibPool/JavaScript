# @policyforge/mcp

> 标签: ccpa, compliance, gdpr, legal, mcp, model-context-protocol, policyforge, privacy-policy, terms-of-service

## 简介

Model Context Protocol server for PolicyForge — generate privacy policies, terms of service, cookie policies and more directly from AI coding tools (Claude Code, Cursor, Windsurf).
