# @jean.gnc/harness-kit

> 标签: agent, claude, claude-code, codex, harness, markdown, marketplace, multi-agent, plugin, skills, typescript

## 简介

Build your own multi-agent harness: typed toolkit for authoring plugins (skills, agents, commands, hooks) and shipping them to Claude Code and Codex from a single source tree.
