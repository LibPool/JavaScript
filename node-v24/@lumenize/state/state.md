# @lumenize/state

> 标签: lumenize, path-based, reactive, state, store

## 简介

Path-based reactive store for Lumenize — getState/setState/subscribe with hierarchical notification, middleware, and computed derivations. Works in Cloudflare Workers, Node.js, Bun, and browsers.
