# @openexpert/opencore

> 标签: agents, ai, local-first, mit, opencore, openexpert, oss

## 简介

OpenCore — open-source engine of OpenExpert (MIT). Config, model provider selector (Google / Ollama / OpenAI-compatible), storage and secrets interfaces, tool catalog, and CLI.
