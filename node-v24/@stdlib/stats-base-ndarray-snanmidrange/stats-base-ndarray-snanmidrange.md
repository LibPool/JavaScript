# @stdlib/stats-base-ndarray-snanmidrange

> 标签: math, mathematics, max, midrange, min, ndarray, range, statistics, stats, stdlib, stdmath

## 简介

Compute the mid-range of a one-dimensional single-precision floating-point ndarray, ignoring `NaN` values.
