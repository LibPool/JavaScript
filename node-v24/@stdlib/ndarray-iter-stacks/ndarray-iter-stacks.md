# @stdlib/ndarray-iter-stacks

> 标签: iter, iterate, iteration, iterator, matrix, multidimensional, ndarray, stack, stdlib, stdtypes, subarray, tensor, util, utilities, utility, utils

## 简介

Create an iterator which iterates over each subarray in a stack of subarrays according to a list of specified stack dimensions.
