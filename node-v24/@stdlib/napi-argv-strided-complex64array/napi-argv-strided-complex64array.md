# @stdlib/napi-argv-strided-complex64array

> 标签: addon, array, cmplx, complex, complex64, float, macros, napi, native, ndarray, stdlib, strided, utilities, utils

## 简介

Convert a Node-API value representing a strided array to a single-precision complex floating-point array.
