# @stdlib/stats-base-ndarray-nanmskrange

> 标签: mask, masked, math, mathematics, nan, ndarray, range, statistics, stats, stdlib, stdmath

## 简介

Calculate the range of a one-dimensional ndarray according to a mask, ignoring NaN values.
