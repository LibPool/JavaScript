# @stdlib/stats-base-nanvariancech

> 标签: array, deviation, dispersion, math, mathematics, sample variance, standard deviation, statistics, stats, std, stdev, stdlib, stdmath, strided, strided array, typed, unbiased, var, variance

## 简介

Calculate the variance of a strided array ignoring NaN values and using a one-pass trial mean algorithm.
