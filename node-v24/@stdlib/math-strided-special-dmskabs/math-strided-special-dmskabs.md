# @stdlib/math-strided-special-dmskabs

> 标签: abs, absolute, array, dbl, double, double-precision, element-wise, float64, float64array, magnitude, mask, masked, math, mathematics, missing, missing values, na, ndarray, stdlib, stdmath, strided, value, vector

## 简介

Compute the absolute value for each element in a double-precision floating-point strided array according to a strided mask array.
