# @stdlib/blas-ext-base-scusumkbn2

> 标签: accumulate, array, blas, compensated, cumulative, extended, float, float32, float32array, kahan, kbn, math, mathematics, single, statistics, stats, stdlib, stdmath, strided, strided array, sum, summation, total, typed

## 简介

Calculate the cumulative sum of single-precision floating-point strided array elements using a second-order iterative Kahan–Babuška algorithm.
