# @stdlib/stats-base-dsemch

> 标签: array, double, estimate, estimation, float64, float64array, math, mathematics, mean, standard deviation, standard error, standard error of the mean, statistics, stats, std, stdev, stdlib, stdmath, strided, strided array, typed

## 简介

Calculate the standard error of the mean for a double-precision floating-point strided array using a one-pass trial mean algorithm.
