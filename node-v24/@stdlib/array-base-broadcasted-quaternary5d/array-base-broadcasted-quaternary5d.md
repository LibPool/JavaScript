# @stdlib/array-base-broadcasted-quaternary5d

> 标签: 5d, apply, array, base, broadcast, foreach, map, matrix, multidimensional, ndarray, quaternary, stdlib, transform

## 简介

Apply a quaternary callback to elements in four broadcasted input arrays and assign results to elements in a five-dimensional nested output array.
