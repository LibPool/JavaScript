# @stdlib/ndarray-base-to-reversed

> 标签: base, data, flip, matrix, ndarray, numpy.flip, reverse, slice, stdlib, stdtypes, structure, to-reversed, types, vector, view

## 简介

Return a new ndarray where the order of elements of an input ndarray is reversed along each dimension.
