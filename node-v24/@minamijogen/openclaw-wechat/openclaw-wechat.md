# @minamijogen/openclaw-wechat

> 标签: openclaw, plugin, qclaw, wechat

## 简介

Reuse QClaw's private WeChat gateway in OpenClaw with QR pairing. 在 OpenClaw 中复用 QClaw 私有微信通路，并支持扫码配对。
