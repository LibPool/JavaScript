# @vipengele/ts-core-observability

> 标签: error-reporting, error-tracking, exceptions, logger, logging, observability, opentelemetry, otlp, structured-logging, typescript, vipengele

## 简介

Structured logging and error reporting for the browser and Node — category-scoped loggers, pluggable sinks, and an error reporter with scopes, breadcrumbs and console, HTTP and OTLP transports.
