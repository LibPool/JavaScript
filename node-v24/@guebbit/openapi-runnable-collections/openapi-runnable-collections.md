# @guebbit/openapi-runnable-collections

> 标签: api-client, bruno, collection, contract, deterministic, fixtures, insomnia, mock-server, mockoon, openapi, postman, seed, swagger

## 简介

Generate API client collections (Bruno, Insomnia, Mockoon, Postman) from an OpenAPI document, filled with values from your seed dataset so every request actually runs.
