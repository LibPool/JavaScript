# @noresign/airemote

> 标签: claude-code, coding-agent, daemon, headless, mobile, remote-control, sse

## 简介

Remote-control your local coding agent from your phone: headless Claude Code, streaming events over HTTP/SSE, session resume, remote tool-call approval.
