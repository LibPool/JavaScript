# @openlayer-utils/timeline-canvas-player

> 标签: JavaScript

## 简介

`TimelineCanvasPlayer` 是一个基于 Canvas 2D 的纯渲染时间轴组件，无外部 UI 框架依赖。它以 Unix 秒为时间单位，在画布上绘制刻度尺 + 业务区间色条，支持滚轮缩放、鼠标悬浮辅助游标、双击回调。
