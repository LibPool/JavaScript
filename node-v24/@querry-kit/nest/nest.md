# @querry-kit/nest

> 标签: casl, decorators, fields, nestjs, openapi, pagination, pipes, prisma, projection, query-kit, query-service, swagger, typescript

## 简介

Consolidated NestJS helpers for Query Kit fields, Prisma-style query services, CASL policies, decorators, pipes, and response projection.
