# @agentxpay/sdk

> 标签: agentxpay, ai-agent, blockchain, escrow, ethereum, monad, payment, service-discovery, subscription, web3, x402

## 简介

TypeScript SDK for AgentXPay - AI Agent Payment Infrastructure on Monad blockchain. Supports x402 protocol, service discovery, payments, subscriptions, escrow, and agent wallet management.
