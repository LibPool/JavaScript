> 标签: chatgpt, codex, deepseek-harness, dsh, dsh-plugin, oauth

## 简介

Codex 订阅授权管理 for the dsh web surface: a dedicated settings page (authorization status, validity/expiry, one-click browser OAuth) plus an expired-credential modal when a GPT model is selected. Host half runs the full OpenAI OAuth flow (PKCE S256, localhost
