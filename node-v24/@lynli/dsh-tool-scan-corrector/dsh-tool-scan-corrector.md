# @lynli/dsh-tool-scan-corrector

> 标签: audit, deepseek-harness, document, dsh-plugin, ocr, orientation, pdf, rotation, scan-corrector, scanner, tesseract

## 简介

DSH (DeepSeek Harness) 工具插件 — 扫描件智能纠偏：6 种方法融合决策，自动检测并修正 PDF 页面方向（0/90/180/270），纯本地处理，生成可解释的 JSON 修正报告。
