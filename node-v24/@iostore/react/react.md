# @iostore/react

> 标签: JavaScript

## 简介

`@iostore/react` 是 io 查询与状态系统在 React 18/19 下的官方适配层。它的设计目标和 TanStack Query 类似：把「请求状态管理、缓存、重试、失效、观察者订阅」封装成声明式 API；同时保留 io 的细粒度响应式能力，使你可以在同一个组件内同时管理本地状态单元（`io` / `unit`）与远程数据（`query` / `mutation`）。
