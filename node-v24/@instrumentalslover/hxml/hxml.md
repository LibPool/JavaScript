# @instrumentalslover/hxml

> 标签: compiler, custom-elements, html, hxml, markup, namespace, parser, superset, xml

## 简介

HTML + XML superset. Unprefixed elements follow HTML rules, namespaced elements follow XML rules. Freely mixed in the same document.
