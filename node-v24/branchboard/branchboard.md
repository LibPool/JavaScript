# branchboard

> 标签: ai, ai-canvas, branching, canvas, chat, claude, claude-code, codex, infinite-canvas, llm, local-first, opencode, research, whiteboard

## 简介

A whiteboard for AI chats: run chats side by side on a canvas, branch any answer and connect the answers you want to build on. Free, open source and local, with your claude, codex or opencode command or an API key.
