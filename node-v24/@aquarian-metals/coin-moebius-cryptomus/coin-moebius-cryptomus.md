# @aquarian-metals/coin-moebius-cryptomus

> 标签: bitcoin, coin-moebius, crypto, cryptomus, monero, payments, webhook

## 简介

Cryptomus payment provider for Coin Moebius. Routes any Cryptomus-supported coin (Monero, btc, USDT, and many more) through the same SDK callback shape.
