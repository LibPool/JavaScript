# @small-tech/jsdb

> 标签: ECMAScript Modules, ESM, JSDB, JSDF, JSQL, append-only, database, es6 modules, in-memory, in-process, javascript, js, metaprogramming, proxy, small tech, small web, streaming, transaction log, transparent, zero dependency

## 简介

A zero-dependency, transparent, in-memory, streaming write-on-update JavaScript database for Small Web applications that persists to a JavaScript transaction log.
