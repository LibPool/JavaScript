# @singi-labs/academicpages-renderer

> 标签: academic-cv, academicpages, atproto, personal-site, renderer, sifa

## 简介

Pure HTML renderer for academicpages-style personal sites driven by Sifa profile data. No framework, no filesystem -- import and call.
