# @hyzyn/dsh-plugin-kit

> 标签: JavaScript

## 简介

通用 DSH 插件库（pnpm monorepo）：模板插件、插件开发工具包、一键聚合安装包。根包同时是全家桶 bundle（dsh.bundle.patch），DSH 与插件市场可直接识别安装。
