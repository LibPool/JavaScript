# dsh-reboot

> 标签: agent, deepseek-harness, dsh-plugin, restart

## 简介

DeepSeek Harness 一键重启插件：restart_host 工具 + 设置页「重启」入口；CLI 宿主看门狗按原命令行原端口重启（页面自动恢复），桌面端自动重启整个客户端（TypeScript + vitest）
