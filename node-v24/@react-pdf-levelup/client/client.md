# @react-pdf-levelup/client

> 标签: javascript, pdf, react pdf, react pdf levelup

## 简介

Utilidad de frontend para decodificar un PDF en base64 generados con @react-pdf-levelup/core y descargarlo/abrirlo en el navegador.
