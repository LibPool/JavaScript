# @sekmet/gatsby-transformer-wpcontent

> 标签: gatsby, gatsby-plugin, gatsby-transformer-plugin, html, prismjs, responsive images

## 简介

A Gatsby transformer plugin for authoring content in HTML. Supports ToC generation, responsive images, section anchors and Prism.JS code highlighting.
