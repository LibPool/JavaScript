# makebounty

> 标签: 3d-printing, agent, bounty, cli, cnc, diy, marketplace, mcp

## 简介

Command-line client for MakeBounty: search, post and claim DIY bounties. Same API and same API key as the MCP server.

## 官网

- 官网：https://makebounty.com/docs/agents
- 源码仓库：git+https://github.com/HeronNetworks/diy-bounty.git
- npm 页面：https://www.npmjs.com/package/makebounty
