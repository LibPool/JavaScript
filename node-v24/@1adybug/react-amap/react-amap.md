# @1adybug/react-amap

> 标签: JavaScript

## 简介

`@1adybug/react-amap` 是基于高德地图 JSAPI v2.0 的 React 19 声明式封装。它负责加载 JSAPI、创建地图实例，并把点标记、矢量图形、图层、控件、工具、服务等高德对象映射为 React 组件或 Hook。
