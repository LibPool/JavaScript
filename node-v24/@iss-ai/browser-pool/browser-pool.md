# @iss-ai/browser-pool

> 标签: cjs, esm, jest, rollup, typescript, umd, utils

## 简介

`BrowserPool` 是一个用于管理和调度无头浏览器（Headless Browser）资源的高效任务池，基于 [Playwright](https://playwright.dev/) 实现。它专门为高并发爬虫、自动化测试、AI 会话调度等场景设计，支持多工作节点（Worker）复用、超时控制、状态隔离、持久化用户状态以及动态适配不同的浏览器内核（如 Chromium, Camoufox 等）。
