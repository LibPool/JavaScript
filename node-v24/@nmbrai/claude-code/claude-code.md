# @nmbrai/claude-code

> 标签: agent, channel, claude-code, claude-code-plugin, mcp, mcp-server, nmbr

## 简介

nmbr for Claude Code — a channel plugin (text your Claude Code session from your phone, approve permissions on nmbr cards) that is also a plain MCP server for any MCP host.
