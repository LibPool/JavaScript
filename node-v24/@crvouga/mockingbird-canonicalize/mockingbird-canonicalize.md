# @crvouga/mockingbird-canonicalize

> 标签: canonicalize, mockingbird, parity

## 简介

Strict, provider-neutral canonicalisation of HTTP exchanges for differential comparison: symbolic id replacement, declared volatile fields, parity headers, structural diff.
