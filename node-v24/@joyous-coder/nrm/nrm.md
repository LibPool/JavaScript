# @joyous-coder/nrm

> 标签: fork, npm, npmrc, nrm, patch, registry

## 简介

npm registry manager — Pana/nrm fork that fixes the npmrc _auth leak: switching registries no longer writes `_auth`, `always-auth`, `email`, `repository`, or `home` to the top level of ~/.npmrc
