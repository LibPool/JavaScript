# @cookwala/mcp

> 标签: cooking, cookwala, food-safety, mcp, model-context-protocol, recipes, robots

## 简介

Cookwala MCP server: search and read recipes, dry-run them against a device, check safe bands, mandates and humanitarian SMS. Read-only; reads the static catalog on cookwala.ai; never starts cooking.
