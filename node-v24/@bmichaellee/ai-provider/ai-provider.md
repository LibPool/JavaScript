# @bmichaellee/ai-provider

> 标签: ai, anthropic, claude, claude-code, llm, provider, tool-use

## 简介

LLM client with interchangeable backends behind one provider-agnostic interface. Ships two Claude backends: the Anthropic API, or a local Claude Code install for keyless development and testing.
