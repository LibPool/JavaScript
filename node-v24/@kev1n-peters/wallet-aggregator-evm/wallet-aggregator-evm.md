# @kev1n-peters/wallet-aggregator-evm

> 标签: JavaScript

## 简介

Implements the base abstractions for EVM-compatible blockchains, using [wagmi](https://github.com/wagmi-dev/wagmi) under the hood to handle connection implementations.
