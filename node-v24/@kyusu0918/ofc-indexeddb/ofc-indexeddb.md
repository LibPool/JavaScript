# @kyusu0918/ofc-indexeddb

> 标签: crud, indexeddb, localdatabase, logical delete, offline-storage, store factory, typescript, wrapper

## 简介

A type-safe IndexedDB wrapper for TypeScript that provides typed store factories, simple CRUD methods and built-in logical delete support.
