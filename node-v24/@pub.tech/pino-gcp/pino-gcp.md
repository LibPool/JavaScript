# @pub.tech/pino-gcp

> 标签: cloud-logging, gcp, google-cloud, http-request, logging, pino, pino-transport, stackdriver, structured-logging, trace

## 简介

Pino transport that reformats log records into Google Cloud Logging structured format, with trace/span correlation, HTTP request fields, and error stack extraction
