# lingxi-mcp

> 标签: agent, claude, codex, cursor, desktop-pet, lingxi, mcp, mcp-server, model-context-protocol, 灵犀

## 简介

灵犀 Lingxi desktop cat for coding agents: an MCP server and a shell client that let Codex, Cursor, WorkBuddy, Claude or any MCP host drive the cat - and install the macOS app from GitHub when it is missing.
