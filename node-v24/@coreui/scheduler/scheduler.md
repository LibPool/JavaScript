# @coreui/scheduler

> 标签: calendar, coreui, event-calendar, scheduler, scheduling

## 简介

Vanilla JavaScript resource/time scheduler for CoreUI — day, week, and resource views with drag & drop, RFC 5545 recurrence, and full keyboard support
