# @atom-circuit/embed-sdk

> 标签: atom, cosmos, cosmostation, cosmwasm, defi, embed, iframe, keplr, leap, react-component, referral, skip, staking, swap, validator, widget

## 简介

Embed the Atom Circuit swap widget on any website with one line. Carries a referralId so swap fees route to the host validator.
