# @angangii/frontendpractice

> 标签: JavaScript

## 简介

1. 临时安装可执行依赖包，不用全局安装，不用担心长期的污染。 2. 可以执行依赖包中的命令，安装完成自动运行。 3. 自动加载node_modules中依赖包，不用指定$PATH。 4. 可以指定node版本、命令的版本，解决了不同项目使用不同版本的命令的问题。
