# @trackunit/react-map-draw

> 标签: JavaScript

## 简介

Provider-agnostic **polygon drawing engine** for the `@trackunit/react-map` family (ADR 0030). It implements the `DrawPort` contract from `@trackunit/react-map-adapter-shared` on top of [Terra Draw](https://terradraw.io), so the Google Maps and Mapbox GL
