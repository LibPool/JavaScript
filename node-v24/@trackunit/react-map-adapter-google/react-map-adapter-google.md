# @trackunit/react-map-adapter-google

> 标签: JavaScript

## 简介

**Google Maps** adapter for `@trackunit/react-map`: implements the shared adapter contract from `@trackunit/react-map-adapter-shared` using [`@vis.gl/react-google-maps`](https://github.com/visgl/react-google-maps) and the Google Maps JavaScript API.
