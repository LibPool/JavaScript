# @cmgmyr/hive

> 标签: agents, claude-code, codex, coordination, mcp, multi-agent, sqlite, tmux

## 简介

Run a crew of Claude Code and Codex workers from one lead session: visible tmux panes, exact state from hooks, one local SQLite store.
