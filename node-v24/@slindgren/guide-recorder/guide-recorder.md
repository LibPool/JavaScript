# @slindgren/guide-recorder

> 标签: documentation, help, playwright, screen-recording, tts, tutorial, video

## 简介

Record narrated how-to videos and screenshots of any web app from JSON scripts (Playwright + optional Azure/Google TTS + ffmpeg).
