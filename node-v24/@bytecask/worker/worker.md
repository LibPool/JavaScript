# @bytecask/worker

> 标签: blob-storage, browser-storage, bytecask, comlink, file-system-access, offline-first, opfs, origin-private-file-system, streaming, typescript, web-worker, worker

## 简介

OPFS blob-I/O Web Worker for bytecask — sync-access-handle reads/writes behind a Comlink surface, spawnable from a factory, a URL, or an inlined blob (two-stage inline build).
