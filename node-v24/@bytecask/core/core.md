# @bytecask/core

> 标签: binary-data, blake3, blob-storage, blob-store, browser-storage, bytecask, cas, content-addressable-storage, content-addressed-storage, deduplication, file-storage, indexeddb, offline-first, opfs, typescript, web-storage

## 简介

Browser-native content-addressed binary blob store — BLAKE3 addressing, tiered storage adapters (OPFS via worker, IndexedDB, memory), dedup, refcount, GC.
