# @zeroxcyril/chase

> 标签: dynamic-analysis, mcp, move, security, smart-contracts, sui

## 简介

Chase — dynamic analysis for Sui Move transactions. Invariant checks over real execution traces, deterministic triage, and a budget-bounded scout agent. CLI, library and MCP server.
