# @danadresse/mcp-server

> 标签: address, ai-agent, claude, cursor, danadresse, danish, dawa, denmark, geocoding, mcp, model-context-protocol

## 简介

Model Context Protocol server for Danadresse — Danish address API. Gives Claude Desktop / Claude Code / Cursor / Continue direct access to autocomplete, validation, reverse geocoding, DAGI, BBR and address-quality scoring across all 2.4M Danish addresses.
