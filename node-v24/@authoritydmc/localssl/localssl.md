# @authoritydmc/localssl

> 标签: certificates, fastapi, https, local-ssl, mobile-testing, nextjs, reverse-proxy, spring-boot, ssl, sslip, vite

## 简介

Zero-config multi-device local HTTPS proxy and certificate engine with sslip.io, Java PKCS12 / Python PEM generation, and mobile QR code pairing.
