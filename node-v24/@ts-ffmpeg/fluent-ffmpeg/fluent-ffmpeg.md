# @ts-ffmpeg/fluent-ffmpeg

> 标签: ffmpeg

## 简介

A fluent API to FFMPEG (http://www.ffmpeg.org) with types from @types/fluent-ffmpeg (https://github.com/DefinitelyTyped/DefinitelyTyped/tree/master/types/fluent-ffmpeg)
