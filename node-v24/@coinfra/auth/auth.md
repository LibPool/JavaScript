# @coinfra/auth

> 标签: JavaScript

## 简介

The sign-in wheel: Better Auth extended with domestic-China connectors (WeChat, WeCom, SMS OTP) and a coinfra house preset. Embedded library — each app runs it in-process, no standalone identity server.
