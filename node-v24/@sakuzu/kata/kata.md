# @sakuzu/kata

> 标签: components, css, custom-properties, design-system, golden-ratio, spacing, svelte, tokens, typography

## 简介

The design system of sakuzu: a numeric scale derived from the golden ratio, CSS tokens, base CSS and Svelte components for drawing applications.
