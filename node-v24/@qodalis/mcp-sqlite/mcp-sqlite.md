# @qodalis/mcp-sqlite

> 标签: ai, claude, cursor, database, mcp, model-context-protocol, sqlite, sqlite3

## 简介

Model Context Protocol (MCP) server for SQLite files using the Node.js built-in driver — read-only guard, token-efficient results, no native dependencies.
