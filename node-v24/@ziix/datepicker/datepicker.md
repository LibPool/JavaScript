# @ziix/datepicker

> 标签: booking, calendar, datepicker, datetime, resource, scheduling, timepicker

## 简介

Framework-agnostic date / time / datetime picker with configurable minute steps and resource-aware selection — fetch bookable resources from a URL, show free time per resource and pick the one a task lands on.
