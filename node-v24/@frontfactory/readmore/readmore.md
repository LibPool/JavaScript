# @frontfactory/readmore

> 标签: a11y, clamp, collapse, ellipsis, expand, line-clamp, read-more, readmore, show-more, text-truncate, truncate, typescript, vanilla-js

## 简介

Zero-dependency plugin to truncate text to N lines or a fixed height, with an ellipsis and an accessible read more / read less toggle.
