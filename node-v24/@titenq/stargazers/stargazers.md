# @titenq/stargazers

> 标签: automation, cli, documentation, git, github, github-api, project-documentation, readme, repository, stargazers, stars

## 简介

CLI to automatically add a GitHub stargazers section to your project's README. Fetches and displays stargazers' avatars from your repository in an elegant and organized way.
