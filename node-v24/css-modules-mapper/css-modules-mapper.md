# css-modules-mapper

> 标签: content-mapper, css, css-modules, typed-css-modules, types, typescript, typescript-7, vite, webpack

## 简介

TypeScript 7.1 content mapper that type-checks CSS module imports against the CSS itself, with no generated .d.ts files
