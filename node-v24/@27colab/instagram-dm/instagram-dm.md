# @27colab/instagram-dm

> 标签: chatbot, graph-api, instagram, messaging, meta, typescript, webhook

## 简介

Typed building blocks for Instagram DM bots: webhook verification, event parsing, Business Login OAuth, a Send API client with 24-hour window rules, and a fake Graph API for tests.
