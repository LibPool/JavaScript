# @api.global/typedserver

> 标签: HTTP server, SSL, TypeScript, compression, compression (gzip, deflate, brotli), cors, feeds, live reload, proxy, robots.txt, sitemap, static file serving, typed requests

## 简介

A TypeScript-based project for easy serving of static files with support for live reloading, compression, and typed requests.
