# @wefly/vue-audio

> 标签: audio, manage, vue, vue 3.0

## 简介

A simple and easy to use Audio library that relies on the VUE 3.0 framework. It supports multiple audio switches on the same page, and only one audio player exists at the same time. It supports dragging, clicking and jumping to play anywhere.
