# @amarjit_gts/universal-ai-orchestrator

> 标签: JavaScript

## 简介

Domain-agnostic, optional Orchestrator (v1, tool-only planning): plan -> validate -> execute -> replan (Planned engine), plus a simpler native-tool-calling loop (Reactive engine). No concept of "agent" yet — see ADR-006.
