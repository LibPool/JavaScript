# @vertaaux/mcp-server

> 标签: a11y, accessibility, audit, mcp, ux, vertaa

## 简介

MCP server with an autonomous audit, fix, and verify loop. 38 tools for UX and accessibility audits, framework-aware patches (React/Vue/Angular/Svelte), atomic GitHub PRs, and policy-as-code CI gates.
