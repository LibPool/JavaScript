# @sunkimkk/pinterest-mcp

> 标签: claude-code, codex, design-inspiration, mcp, mcp-server, model-context-protocol, moodboard, pinterest

## 简介

Let your AI agent browse Pinterest: search pins, see images, related pins, boards and downloads for Claude Code, Codex and any MCP client. No login, no API key, no browser.
