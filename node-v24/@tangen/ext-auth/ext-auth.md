# @tangen/ext-auth

> 标签: JavaScript

## 简介

Site users for a Tangen site: email and password, one-time codes by email or SMS, SSO (Google, GitHub, any OpenID Connect provider), anonymous sessions, profile fields, and the admin to manage them
