# @q1travel/design-system

> 标签: JavaScript

## 简介

q1travel 产品家族的设计权威上游仓，三件事集于一处：`@q1travel/design-system` npm 包、设计契约（`contracts/`）与公开文档站。下游各仓只读消费已发布的包，并用包内 `q1-design` CLI 同步、校验契约缓存。推荐公开域名：`design.q1lx.com`。
