# @voidbase-cloud/sdk

> 标签: javascript-sdk, js-sdk, pocketbase, pocketbase-js, pocketbase-sdk, voidbase, voidbase-sdk

## 简介

voidbase JavaScript SDK: the PocketBase JS SDK, kept in step with upstream, plus a typed client, a plugin surface, an offline queue, PWA helpers, in-place editing, a chat helper, a payments helper, an SEO helper and an interface strings runtime
