# @voidbase-cloud/plugin-polar

> 标签: cloudflare-workers, payments, polar, voidbase, voidbase-plugin

## 简介

The polar plugin of voidbase. Taking money through Polar: provides payments@1 with Polar's REST API, its Standard Webhooks and the shared payment rows
