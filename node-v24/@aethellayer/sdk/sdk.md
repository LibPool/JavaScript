# @aethellayer/sdk

> 标签: aethellayer, cli, cursor, developer-experience, mcp, observability, sdk

## 简介

AethelLayer CLI probe and MCP server. Catch Docker OOM / API dropouts, log them locally, draft GitHub tickets, and expose get_recent_errors to Cursor and Claude.
