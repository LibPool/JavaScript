# @luckrya/eslint-config-cli

> 标签: @luckrya/eslint-config, cli, eslint, eslint-config, eslint-config-cli, eslintconfig

## 简介

A tool to quickly integrate code specifications for your project. It mainly uses the official configuration of @luckrya/eslint-config-*, allowing developers to focus more on business development.
