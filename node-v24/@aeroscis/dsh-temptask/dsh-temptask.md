# @aeroscis/dsh-temptask

> 标签: deepseek-harness, dsh, dsh-plugin, sandbox, scratch, session, temporary-workspace

## 简介

DSH 临时任务模式：为 DSH 增加「任务」分组——不绑定任何长期工作空间，自动在任务根目录下创建隔离的临时工作目录并开启会话，即开即用、用完即弃；喜欢的任务可以「转正」：改名、搬到正式目录、连对话一起带过去。Temporary task mode for DeepSeek Harness.
