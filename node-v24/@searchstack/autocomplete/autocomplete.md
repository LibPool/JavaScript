## 简介

Drop-in autocomplete, typeahead and "ask this site" answer UI for any text input — anchored dropdown on desktop, full-screen on mobile, and a Cmd-K overlay that streams a cited answer. Framework-agnostic, with search history, custom templates and CSS vari
