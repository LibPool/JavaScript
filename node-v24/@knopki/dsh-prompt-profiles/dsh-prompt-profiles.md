# @knopki/dsh-prompt-profiles

> 标签: deepseek-harness, dsh, dsh-plugin

## 简介

DSH bundle adding a per-session prompt-profile axis: named system-prompt sections grouped into profiles with per-section order and scope, sealed into the session prompt.
