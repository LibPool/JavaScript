# @azarai/pi-math

> 标签: formula, kitty, latex, math, pi, pi-coding-agent, pi-package, terminal

## 简介

Render LaTeX math as inline images in the pi chat transcript. Lightweight (python3 + matplotlib), theme-adaptive colors.
