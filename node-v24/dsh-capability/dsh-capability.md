> 标签: capability, cordis, deepseek-harness, dsh, dsh-plugin, isolation, permissions, security

## 简介

Capability model for DeepSeek Harness: A capability model for DeepSeek Harness plugins: declare fs/shell/net/env access, enforce it at load time, report violations. Name reserved; first release in development.
