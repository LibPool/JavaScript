# postext-epub

> 标签: ebook, epub, epub3, fixed-layout, postext, reflowable, typesetting, typography

## 简介

Browser-native EPUB 3 writer for Postext documents: fixed-layout (pre-paginated) books that reproduce every printed page with real text, and reflowable books in semantic XHTML styled from the same configuration.
