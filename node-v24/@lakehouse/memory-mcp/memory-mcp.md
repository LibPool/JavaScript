# @lakehouse/memory-mcp

> 标签: ai, assistant, claude, lakehouse42, lh42, mcp, memory

## 简介

Persistent memory for AI assistants via MCP. Works with Claude Code, Cursor, Windsurf, and any MCP-compatible client.
