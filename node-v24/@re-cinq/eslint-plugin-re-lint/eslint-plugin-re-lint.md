# @re-cinq/eslint-plugin-re-lint

> 标签: clean-code, eslint, eslint-plugin, eslintplugin, jscpd

## 简介

re:cinq house ESLint rules: complexity, naming, functions, comments, tests, layering, spec traceability, and jscpd-backed duplicate detection. Flat config, plugin key re-lint.
