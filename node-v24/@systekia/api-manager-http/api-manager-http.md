# @systekia/api-manager-http

> 标签: JavaScript

## 简介

`@systekia/api-manager-http` es una librería HTTP extensible y modular para proyectos frontend (Next.js, React, Vue, Svelte, Nuxt.js), escrita en TypeScript y usable desde JavaScript.
