# @aby-jo/dropdown-package

> 标签: ["dropdown"]

## 简介

A simple and customizable JavaScript package for creating dropdown menus that can be toggled by either a click or hover event. This lightweight and reusable solution works with multiple dropdowns on the same page, offering flexibility in user interaction.
