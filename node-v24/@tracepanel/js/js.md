# @tracepanel/js

> 标签: bun, express, n+1, nestjs, nextjs, nuxt, opentelemetry, pino, sql, tracing, winston

## 简介

Traces and logs for Node.js and Bun apps (Express, NestJS, Next.js, Nuxt, Bun.serve): every request with its SQL, logs and errors, N+1 queries found
