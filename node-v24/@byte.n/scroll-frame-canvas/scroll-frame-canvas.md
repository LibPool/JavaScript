# @byte.n/scroll-frame-canvas

> 标签: animation, canvas, frame, image-sequence, offscreen-canvas, progressive-loading, scroll, scroll-driven, sequence

## 简介

基于滚动条驱动的 Canvas 帧序列渲染器，支持渐进式大序列加载、OffscreenCanvas 预渲染与事件回调。
