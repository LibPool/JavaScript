# @steempro/sds-api

> 标签: api, blockchain, client, rest, sdk, sds, steem, steemworld, typescript

## 简介

Typed JavaScript / TypeScript client for the Steem Blockchain Data Services (SDS) REST API — every module and method of sds0.steemworld.org, promise + callback support, custom SDS instances, retries and structured error handling.
