# @egen-civitas/esm-tenant

> 标签: JavaScript

## 简介

Tenant capture system for EGEN SPA — resolves the active tenant from the URL (subdomain/path/query/JWT) and exposes it globally (store + window). No local tenant registry, no frontend validation — see src/types.ts.
