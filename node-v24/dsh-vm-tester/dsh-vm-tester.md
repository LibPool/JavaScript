# dsh-vm-tester

> 标签: black-box, deepseek-harness, dsh, gui-automation, plugin, testing, virtualbox

## 简介

Black-box GUI testing for DeepSeek Harness: the agent sees only screenshots and drives only mouse/keyboard inside a VirtualBox guest.
