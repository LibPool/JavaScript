# @defuse-protocol/nearintents-mpp-sdk

> 标签: cross-chain, http-402, machine-payments, mpp, near, near-intents, payments, typescript

## 简介

Reference implementation of the `nearintents` payment method for MPP (Machine Payments Protocol) — cross-chain HTTP 402 payments settled by NEAR Intents. Extends mppx.
