# @nexora-ui/menu

> 标签: JavaScript

## 简介

Headless, accessible menu for Angular. Composes `@nexora-ui/listbox` (role=menu, action mode) and `@nexora-ui/dropdown` for overlay lifecycle. Directive-based API with trigger, panel, items, and groups. No value binding — on item activation the component
