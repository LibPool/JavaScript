# @alexstack/universal-mean-api

> 标签: JavaScript

## 简介

NodeJs-Express-MongoDB-Universal-CRUD-API(MEAN API) for dynamic MongoDB tables, no need to repeat the CRUD API code for every table. Focus on run it in a serverless environment.
