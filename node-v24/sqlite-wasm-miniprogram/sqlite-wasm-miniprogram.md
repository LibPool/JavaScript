# sqlite-wasm-miniprogram

> 标签: miniprogram, sqlite, sqlite-wasm, wasm, wechat, wxwebassembly

## 简介

The official @sqlite.org/sqlite-wasm, built to run in WeChat mini programs (WXWebAssembly): injected shims, cross-realm fixes and prebuilt callback stubs.
