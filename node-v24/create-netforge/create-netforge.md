# create-netforge

> 标签: create, game, net-forge, netnet, starter, template, three.js

## 简介

Start a game with Net Forge, the open-source multiplayer browser game engine built for AI coding agents: npm create netforge@latest my-game. Ten templates, play money, AGENTS.md and MCP config included.
