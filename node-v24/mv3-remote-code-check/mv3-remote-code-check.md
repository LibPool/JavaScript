# mv3-remote-code-check

> 标签: browser-extension, chrome-extension, chrome-web-store, github-action, manifest-v3, mv3, remote-code, vite-plugin

## 简介

Reads a built browser extension the way the Chrome Web Store review does and fails on remotely hosted code (Manifest V3), as a CLI, a GitHub Action and a Vite plugin.
