# @crawlready/edge-contract

> 标签: cache-key, crawlready, edge, hmac, webcrypto

## 简介

Frozen wire contract between the CrawlReady SDK, the edge worker, and the control plane. Zero dependencies, WebCrypto only — runs identically on Node 18+, the Next.js Edge runtime, and Cloudflare workerd.
