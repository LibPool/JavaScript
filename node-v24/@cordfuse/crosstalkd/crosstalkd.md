# @cordfuse/crosstalkd

> 标签: agents, ai, cordfuse, crosstalk, git, messaging

## 简介

Crosstalk daemon — the engine that runs inside the crosstalk-server container. Operators interact via @cordfuse/crosstalk on the host.
