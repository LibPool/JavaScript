# @sruim/mesh-flow

> 标签: 3d, 3mf, assimp, convert, fbx, glb, gltf, mesh, model, obj, ply, stl, usdz, vox, wasm

## 简介

浏览器端 3D 模型格式转换 SDK（Assimp WASM 封装），支持 OBJ/FBX/USDZ/STL/GLB/3MF/PLY/VOX/GLTF 输入与 GLB/OBJ/STL/PLY/USDZ/FBX 导出
