# @cyrus-ai/cursor-runner

> 标签: agent, cli, cursor, cursor-sdk, jsonl, streaming

## 简介

Cursor SDK runner — spawned by Cyrus's agent-runtime as a process boundary around @cursor/sdk, emitting SDKMessage events as JSONL on stdout so consumers get typed events with no schema drift.
