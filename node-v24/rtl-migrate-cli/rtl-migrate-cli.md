# rtl-migrate-cli

> 标签: cli, codemod, css, css-in-js, i18n, logical-properties, ltr, rtl

## 简介

CLI + codemod that migrates physical LTR CSS / CSS-in-JS properties to RTL-ready logical properties (marginLeft -> marginInlineStart, etc.)
