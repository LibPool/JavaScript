# @blackcube/pacifica-sdk

> 标签: dex, ed25519, exchange, pacifica, perp, perpetuals, sdk, solana, trading, websocket

## 简介

TypeScript SDK for the Pacifica exchange (perpetuals DEX on Solana): REST, WebSocket, Ed25519 signing and on-chain deposits
