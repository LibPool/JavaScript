# @browserid-ng/mcp-auth

> 标签: agent, authorization, browserid, mcp, oauth, rfc7521, warrant

## 简介

Warrant-gated MCP tools over MCP's own OAuth 2.1: a BrowserID 7521 assertion-grant AS + fail-closed per-call revocation checks. Every tool call attributable to 'agent X on behalf of human Y', revocable in one click.
