# @omgqa/playwright-reporter

> 标签: omgqa, playwright, playwright-reporter, qa, test-reporting

## 简介

Playwright reporter that turns a run into an OMGQA test run and auto-creates/dedups findings from failures (E20).

## 官网

- npm 页面：https://www.npmjs.com/package/@omgqa/playwright-reporter

## 获取地址

- npm registry：https://registry.npmjs.org/@omgqa/playwright-reporter
- Node 要求：>=18
