# @cyd-prc/dsh-entropy-guard

> 标签: audit-chain, autonomy, dsh, dsh-plugin, entropy-runtime, entropy-sdk, gear-ladder, guard, safety

## 简介

Gear-based autonomy governor for the DeepSeek Harness agent: the entropy-sdk EntropyRuntime core (gear ladder G0-G4, utility gate, slow-up/fast-down policy, tamper-evident audit chain) bound to the Harness tool registry, with a live Web UI and paper-ready
