# @caohaoyangcn/dsh-ui-scale

> 标签: accessibility, deepseek-harness, dsh, dsh-plugin, font-size, plugin, scale, ui, zoom

## 简介

Global UI scale and per-surface font-size control for the DeepSeek Harness web GUI: a scale ratio that enlarges the whole application shell instead of only conversation text, plus independent font sizes for the sidebar, conversation, right sidebar, and bo
