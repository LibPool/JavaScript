# @ordervschaos/babel-plugin-react-component-tagger

> 标签: babel-plugin, component, debugging, development, file-path, jsx, react, tagging, vite, webpack

## 简介

A Babel plugin that tags the topmost JSX element in React components with the component's file path for easier debugging and development
