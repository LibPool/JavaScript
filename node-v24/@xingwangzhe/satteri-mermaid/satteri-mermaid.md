# @xingwangzhe/satteri-mermaid

> 标签: astro-component, astro-integration, diagram, markdown, mdast, mermaid, plugin, renderer, satteri

## 简介

Sätteri MDAST+HAST plugin: render Mermaid diagrams as static SVG at build time via mermaid-rs (napi-rs). 23 diagram types, zero client JS.
