# @mercurjs/magento2-connector-plugin

> 标签: magento2, marketplace, medusa-plugin, medusa-v2, mercur

## 简介

Mercur plugin that lets a Magento 2 storefront sell marketplace offers: outbound webhooks, an external payment provider, and external refund recording.
