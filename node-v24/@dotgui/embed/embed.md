# @dotgui/embed

> 标签: cdn, dotgui, embed, gui, renderer, web-component

## 简介

Drop-in browser layer that renders .gui files anywhere. A thin wrapper over @dotgui/kit's renderer — one CDN script, zero dependencies for the consumer.
