# @eclipsefdn/vite-plugin-asciidoctor

> 标签: asciidoc, asciidoctor, vite, vite-plugin

## 简介

This vite plugin allows you to use Asciidoctor.js to convert AsciiDoc files into HTML, making it easy to integrate AsciiDoc content into your Vite projects.
