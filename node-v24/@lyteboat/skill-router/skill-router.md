# @lyteboat/skill-router

> 标签: JavaScript

## 简介

lyteboat's skill router over the dsh skill registry: full / dynamic load modes, LLM routing per user input (the reference LLMSkillRouter), the lyteboatActiveSkill projection, and required-tool activation through @lyteboat/tool-policy
