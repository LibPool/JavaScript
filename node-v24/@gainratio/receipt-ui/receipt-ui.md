# @gainratio/receipt-ui

> 标签: audit-ui, avow, ed25519, fail-closed, provenance, react, react-components, signature-verification, signed-receipt, tamper-evident, trust-badge, typescript

## 简介

React components that render and verify an Avow SignedReceipt — a composable badge and panel with a fail-closed, three-state verdict (verified / tampered / untrusted signer).
