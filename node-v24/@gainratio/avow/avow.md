# @gainratio/avow

> 标签: audit-log, browser, canonical-json, cryptography, digital-signature, ed25519, jcs, offline-verification, provenance, rfc8785, signed-receipt, tamper-evident, typescript

## 简介

Avow signs a JSON record into a receipt, a file anyone can check offline to confirm the record is unchanged and who signed it.
