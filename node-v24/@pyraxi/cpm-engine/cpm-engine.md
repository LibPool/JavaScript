# @pyraxi/cpm-engine

> 标签: cpm, critical-path, gantt, mspdi, nzs-3910, project, scheduler, scheduling-engine

## 简介

Pyraxi CPM Engine — headless construction scheduling engine: forward/backward critical-path pass, 8 MS Project constraint types, negative slack, working-time calendars, baselines, MSPDI interop. Pure TypeScript, framework-agnostic.
