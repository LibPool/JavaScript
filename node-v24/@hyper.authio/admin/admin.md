# @hyper.authio/admin

> 标签: admin, authio, oauth, oidc, openapi

## 简介

Authio Admin API client for Node.js and edge runtimes: every operation generated from the server's OpenAPI document, grouped by area and typed by path, with account credentials, envelopes, errors, paging and Retry-After.
