# @better-iam/ldap

> 标签: access-control, authentication, authorization, directory, iam, ldap, ldaps, multi-tenant, rfc4511, typescript

## 简介

A read-only LDAPv3 directory gateway over Better IAM: people, groups and password binds for applications that only speak LDAP.
