# @better-iam/nestjs

> 标签: abac, access-control, authentication, authorization, decorators, guards, iam, multi-tenant, nest, nestjs, rbac, typescript

## 简介

NestJS module for Better IAM: an authentication guard, authorization decorators, a request-scoped service, the IAM HTTP API, and audit event handlers.
