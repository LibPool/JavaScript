# @ouispec/agent-realtime

> 标签: JavaScript

## 简介

Realtime server for agent turns and UI actions — declared client events, room tokens, the UI action result store, the approval store, declared product events and their job settlements, Redis fan-out; the product supplies auth, room policy and keys
