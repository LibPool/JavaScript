# @ai-gui/plugin-dashboard

> 标签: ai, aigui, bi, dashboard, echarts, llm, plugin, provenance, resultset

## 简介

BI dashboard plugin for AIGUI — a grid of panels, each a table + ECharts chart + provenance, with per-panel refusals. The host writes every number; the model only proposes the layout.
