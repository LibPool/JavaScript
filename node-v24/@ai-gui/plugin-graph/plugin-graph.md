# @ai-gui/plugin-graph

> 标签: 3d, ai, aigui, graph, knowledge-graph, llm, ontology, plugin, rdfs, three

## 简介

Knowledge graphs and ontologies for AIGUI — entities, typed relations, classes with domain/range checks, drawn as 2D SVG or a three.js model.
