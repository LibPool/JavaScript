# @nanobpm/nano-ide-trigger-mqtt

> 标签: home-automation, iot, mqtt, nano-ide-ext, nano-ide-trigger, nanobpm

## 简介

MQTT trigger source pack for the Nano/Urban RAD console: subscribe to broker topics and drive process instances from messages (ADR 0025).
