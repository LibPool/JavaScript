# @nanobpm/nano-ide-app-embedded-nano

> 标签: embedded, nano-ide-app, nano-ide-ext, nanobpm

## 简介

Embedded μ-nano app pack for the Nano RAD IDE: compile a self-contained Deno binary with the Nano BPMN engine running in-process (ADR 0005), no gateway required.
