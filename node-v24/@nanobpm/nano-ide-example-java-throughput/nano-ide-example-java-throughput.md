# @nanobpm/nano-ide-example-java-throughput

> 标签: camunda, falcon, java, nano-ide-example, nano-ide-ext, nanobpm, throughput

## 简介

Distributable example app for the Nano RAD IDE: a Java + Maven throughput demo that runs one code path against Camunda 8 (REST/gRPC) or Nano (Falcon) — pick the transport by swapping one dependency.
