# @flipperdotfamily/react

> 标签: coin flip, flipper, nextjs, react, robinhood chain, viem, wagmi, web3, widget

## 简介

React components and hooks for flipper.family: the drop-in <FlipperWidget /> (SSR-safe, bring your own wallet) and a headless useFlipperClient hook.
