# @flipperdotfamily/widget

> 标签: coin flip, custom element, eip-1193, embed, ethereum, flipper, lit, robinhood chain, uniswap, web component, web3, widget

## 简介

Drop-in coin-flip widget for flipper.family: a framework-agnostic <flipper-widget> web component. Bring your own wallet (any EIP-1193 provider or viem WalletClient), theme it, white-label it.
