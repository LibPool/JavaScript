# @fdls/file-viewer

> 标签: document-viewer, file-preview, image, pdf, preview, react, react-pdf, viewer

## 简介

React components for in-app file preview: shell (FileViewer), PDF viewer, and image pan/zoom. No Radix UI or icon library peer dependencies.
