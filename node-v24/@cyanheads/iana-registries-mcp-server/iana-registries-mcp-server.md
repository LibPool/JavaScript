# @cyanheads/iana-registries-mcp-server

> 标签: bcp47, datatracker, http-fields, http-status-codes, iana, ietf, language-tags, mcp, mcp-server, media-types, mime-types, model-context-protocol, oid, port-numbers, private-enterprise-numbers, protocol-registries, rfc, rfc-editor, stdio, streamable-http, typescript, uri-schemes

## 简介

Look up IANA ports, media types, HTTP status codes and fields, URI schemes, enterprise numbers, and BCP 47 language tags; check RFC status; search and read any IANA registry via MCP. STDIO or Streamable HTTP.
