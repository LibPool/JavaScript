# @cyanheads/pubmed-mcp-server

> 标签: JavaScript

## 简介

Search PubMed/Europe PMC, fetch articles and full text (PMC/EPMC/Unpaywall), citations, MeSH terms via MCP. STDIO or Streamable HTTP.
