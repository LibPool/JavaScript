# visimark-mcp

> 标签: agent, ai, document-integrity, llm, markdown, mcp, modelcontextprotocol, visimark

## 简介

A stdio MCP server exposing the VisiMark engine to agents: every command except simulate as a tool, the authoring discipline as resources, read-only unless an operator opens the write gate.
