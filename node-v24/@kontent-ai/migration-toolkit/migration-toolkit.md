# @kontent-ai/migration-toolkit

> 标签: Kontent.ai, Kontent.ai data migrations, Kontent.ai import, Kontent.ai import toolkit, Kontent.ai migration tool, Kontent.ai migrations

## 简介

This program can be used to import content related data into Kontent.ai from various sources. The included functionality enables the content & asset export/import from Kontent.ai environments.
