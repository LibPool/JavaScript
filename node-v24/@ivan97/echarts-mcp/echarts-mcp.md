# @ivan97/echarts-mcp

> 标签: ai, chart, charts, data-visualization, echarts, llm, mcp, model-context-protocol, svg, visualization

## 简介

Apache ECharts MCP server. 18 chart types, stdio + Streamable HTTP, SVG/PNG/option/HTML output. Zero native dependencies by default.
