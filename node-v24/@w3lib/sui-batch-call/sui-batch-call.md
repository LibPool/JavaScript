# @w3lib/sui-batch-call

> 标签: batch, coin, dex, grpc, grpc-web, nft, sui, swap

## 简介

Batched Sui reads and writes over gRPC-web: balances, coin metadata, objects, NFTs (Display); batch transfers, sponsored collection, batch transactions; LP positions and add / remove liquidity on Sui CLMM, DLMM, AMM and multi-coin (Aftermath) DEXes; swaps
