# @w3lib/wallet

> 标签: connect, connect-modal, eip-6963, react, solana, sui, ton, tron, vue, wallet, wallet-standard, walletconnect

## 简介

Framework-agnostic browser wallet connection for EVM (EIP-6963, WalletConnect), Solana and Sui (Wallet Standard), Tron and TON. Multi-chain connections, auto-reconnect, events, chain switching, chain presets, Vue/React hooks and an optional built-in conne
