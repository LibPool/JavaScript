# @ariada-org/core-engine

> 标签: JavaScript

## 简介

Pure-runtime ariada scanner engine — analyzer fan-out, ScanEvent emission, scoring, fingerprinting, registry, cross-domain detection. No Node, browser, or Playwright deps.
