# @momentstream/file-client

> 标签: JavaScript

## 简介

File Service 的 TypeScript 客户端。HTTP 调用来自 `contracts/openapi.yaml`；独立的 Job 提示 decoder 来自 `contracts/proto/momentstream/file/events/v1/transfer_job_terminal_hint.proto`。本目录由生成器整体写入，请勿手工修改。
