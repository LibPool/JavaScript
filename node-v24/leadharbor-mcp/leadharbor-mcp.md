# leadharbor-mcp

> 标签: email-verification, lead-generation, linkedin-jobs, mcp, rapidapi, youtube

## 简介

MCP server for the LeadHarbor APIs on RapidAPI: email verify (MX), website contact extractor, LinkedIn jobs search, YouTube data. Bring your own RapidAPI key.
