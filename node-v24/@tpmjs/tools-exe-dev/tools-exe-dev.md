# @tpmjs/tools-exe-dev

> 标签: ai, cloud, exe.dev, ssh, tpmjs, virtual-machine, vm

## 简介

Manage exe.dev virtual machines. Create, list, delete, restart VMs, manage sharing, and execute commands via SSH.
