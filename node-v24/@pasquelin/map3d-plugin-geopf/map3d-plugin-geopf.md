# @pasquelin/map3d-plugin-geopf

> 标签: JavaScript

## 简介

Plugin map3D — enrichit les bâtiments 3D au clic avec les attributs BDTOPO de la Géoplateforme IGN (WFS), via useBuildingEnrichment().
