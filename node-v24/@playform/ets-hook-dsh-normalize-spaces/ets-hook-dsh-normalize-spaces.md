# @playform/ets-hook-dsh-normalize-spaces

> 标签: JavaScript

## 简介

The spaces hook: a DeepSeek Harness plugin that hooks the llm/stream waterfall — the interceptable wrapper around EVERY streaming model call — and normalizes the unicode space family (U+00A0 no-break space, U+1680 ogham space mark, U+2000–U+200A the en/em
