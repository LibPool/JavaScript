# @pify/ask-question

> 标签: ask, interactive, pi, pi-extension, pi-package, pify, question

## 简介

Let the model ask instead of guessing: CC AskUserQuestion-shaped tool on built-in dialogs - 1-4 questions, multi-select, Other free-text, works in TUI and RPC
