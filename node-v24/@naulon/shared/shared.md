# @naulon/shared

> 标签: ai-crawler, micropayments, naulon, paywall, settlement, stablecoin, usdc, x402

## 简介

The naulon contract layer: env config, credits + license types, settlement and attribution wire types, event/observation sinks, and the money primitives (network constants, EIP-3009). Builds on @naulon/sdk and re-exports it, so downstream packages get one
