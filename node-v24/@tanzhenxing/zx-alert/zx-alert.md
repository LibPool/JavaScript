# @tanzhenxing/zx-alert

> 标签: alert, 信息, 提示, 提示信息, 提示框, 提示框组件, 警告, 错误

## 简介

`zx-alert` 是一个用于页面中展示重要提示信息的组件。它不属于浮层元素，不会自动消失或关闭。
