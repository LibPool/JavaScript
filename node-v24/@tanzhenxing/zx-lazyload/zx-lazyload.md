# @tanzhenxing/zx-lazyload

> 标签: lazyload, 图片懒加载组件

## 简介

`zx-lazyload` 是一个为 UniApp 设计的图片懒加载组件，旨在优化图片加载体验，提升页面性能。它支持 H5、小程序和 App 端（Vue3 版本）。
