# @soniar4i/ng-image-slider

> 标签: JavaScript

## 简介

Based on ng-image-slider. Angular 12 Image slider with lightbox. An Angular responsive image slider with lightbox popup. Also support youtube url, image base64 string and mp4 video urls and base64 string.
