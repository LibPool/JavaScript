# @nahtanpng/pokedex-cli

> 标签: ansi-art, cli, gaming, pokeapi, pokedex, pokemon, pokemon-games, terminal

## 简介

Terminal Pokédex for quick mid-run lookups: weaknesses, evolution, where to find it and the sprite, all for the game you're actually playing.
