# @oh-hai/mcp

> 标签: JavaScript

## 简介

OH HAI MCP server — the Hub agent surface (oh_hai_notify / oh_hai_ask / oh_hai_task / oh_hai_inbox / oh_hai_list) as native MCP tools. `oh-hai-mcp` runs locally over stdio; the same tools are hosted at https://mcp.ohhai.app.
