# pretendata

> 标签: aadhaar, anonymization, benchmark, data-classification, dlp, dspm, masking, pci, phi, pii, privacy, secret-scanning, synthetic-data, test-data

## 简介

Synthetic test data with a known answer key, for testing DLP, DSPM, data classification, secret scanning and masking tools. Checksum-valid identifiers, deliberate near-misses, and scoring.
