# @open-secure-viewer/ocr

> 标签: image, ocr, open-secure-viewer, pdf, tesseract

## 简介

Optional OCR layer for Open Secure Viewer (powered by tesseract.js). Lazy-loads the Tesseract worker only when ocrPage() is called.
