# @event-kit/bus

> 标签: broadcastchannel, cross-tab, event-bus, localstorage, pubsub, typed-events, typescript

## 简介

Zero-dependency, type-safe, cross-tab event bus with pluggable transports (BroadcastChannel, LocalStorage, WebSocket, ...).
