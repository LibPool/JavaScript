# @ai-matrx/code-runtime

> 标签: ai-matrx, allowlist, applets, babel, compile, sandbox, scope

## 简介

The AI Matrx in-frame code runtime: compiles stored multi-file TSX (Applets, kind components, tool and emit renderers, code blocks) against one documented import scope, with named stand-ins for anything unresolved, the one source-gate list, and a compile
