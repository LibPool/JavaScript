# @lingxiao-office/web-api

> 标签: agent, ai, api, fastify, http, lingxiao, llm, sse, websocket

## 简介

凌霄剑域 Web API：基于 @lingxiao-office/sdk 的 HTTP/ACP/SSE/WebSocket 服务层，供各产品线通过 Web 协议消费后端引擎。
