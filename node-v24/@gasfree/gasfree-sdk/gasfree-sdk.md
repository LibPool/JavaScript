# @gasfree/gasfree-sdk

> 标签: TRON, gasFree

## 简介

gasfree-sdk-js is a toolkit developed based on the GasFree API specification. It facilitates the integration of the non-gas TRC20 token transfer service for the web & browser extension platform.
