# @ceicei/test

> 标签: ceicei, test

## 简介

1. 注册npm账号 2. 本机控制台登录npm账号，输入用户名密码邮箱，弹出网页进行登录。 3. 确保npm源正确。查看本机npm源 npm config get registry，设置为官方源npm config set registry https://registry.npmjs.org， 4. 编写包内的package.json文件，name和version字段必填，内容格式必须是json格式。 5. 控制台执行npm publish --access public， 发布为公共包。
