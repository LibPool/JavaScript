# @api-common/governance-pipeline-auditor

> 标签: api-commons, api-governance, audit, ci, github-actions, linting, maturity, pipeline, spectral

## 简介

Lint your linting: audit a repo's API-governance CI setup against an 8-point maturity rubric and get a prioritized punch-list of fixes. The sequel to spectral-reporter. An API Commons tool.
