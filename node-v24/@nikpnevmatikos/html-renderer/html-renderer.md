# @nikpnevmatikos/html-renderer

> 标签: JavaScript

## 简介

React Native HTML renderer in TypeScript — zero native modules, Fabric/Expo compatible. Supports tagsStyles, stylesheet with CSS selectors, custom renderers, and more.
