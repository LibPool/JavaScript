# @tegis/server

> 标签: anti-piracy, content-protection, drm, ed25519, eddsa, entitlement, jws, tegis, video

## 简介

Tegis backend SDK — mint short-lived, EdDSA-signed entitlement grants. The tenant signing key never leaves your server.
