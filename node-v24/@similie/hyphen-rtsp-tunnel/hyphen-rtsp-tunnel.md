# @similie/hyphen-rtsp-tunnel

> 标签: api, command center, hyphen, monitoring, rtsp, streaming, tunnel, video

## 简介

API plugin module for Hyphen Command Center. Provides TCP and WebSocket interfaces for managing RTSP streams and related services using HyphenOS.
