# @keboola/eslint-plugin-design

> 标签: brand-safety, design-system, eslint, keboola, oxlint

## 简介

This repo's custom oxlint rules: @keboola/design composition + brand-safety conventions (documented in packages/design/AGENTS.md), plus conventions no core oxlint rule can express. Enabled per consumer config; the package exports no preset.
