# @keboola/validate-ui-mcp

> 标签: agent, cli, keboola, mcp, model-context-protocol, validate

## 简介

Local stdio MCP server — the UI-authoring counterpart to the hosted keboola/mcp-server — exposing discover (discover_design), scaffold (scaffold_app), validate (validate_ui) and score (score_ui, serve_and_score) tools for a discover → scaffold → generate
