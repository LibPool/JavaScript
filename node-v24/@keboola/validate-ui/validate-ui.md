# @keboola/validate-ui

> 标签: accessibility, agent, cli, keboola, playwright, validate, visual-regression

## 简介

Closed-loop validation for agent-generated Keboola UI — boots a module headless, drives it, and returns a machine-readable verdict (runtime health, accessibility, visual/brand, brief-conformance)
