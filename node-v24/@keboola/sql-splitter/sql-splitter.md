# @keboola/sql-splitter

> 标签: bigquery, codemirror, keboola, snowflake, sql, statement-splitter

## 简介

Splits a SQL script into statements using the CodeMirror SQL grammar, so quotes, dollar-quotes and comments follow the dialect rather than a hand-written scan.
