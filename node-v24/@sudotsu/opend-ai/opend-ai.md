# @sudotsu/opend-ai

> 标签: ai-agent, cli, coding-assistant, llm, ollama, openai-compatible, uncensored-llm, venice-ai

## 简介

An uncensored, local-first CLI coding agent — streams live reasoning, edits files, runs commands. Provider-agnostic, runs on any OpenAI-compatible uncensored LLM.
