# @kb-skills/adapter-git-log

> 标签: adapter, change-frequency, git, git-log, history, hot-files, kb-skills

## 简介

Git history adapter for kb-skills. Extracts commit frequency, hot files, recent changes and contributor stats to give AI a historical dimension for change-impact analysis.
