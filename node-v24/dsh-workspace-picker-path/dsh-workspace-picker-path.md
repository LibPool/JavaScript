# dsh-workspace-picker-path

> 标签: deepseek-harness, directory-picker, dsh, dsh-plugin, workspace

## 简介

Controls the directory the workspace picker opens at: a fixed custom path (typed, pasted, or chosen visually), or the last directory you successfully picked. Quoted paths and CJK are accepted; a This PC level reaches other drives.
