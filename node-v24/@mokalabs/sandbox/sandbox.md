# @mokalabs/sandbox

> 标签: a2a, a2ui, ag-ui, ai-agents, anthropic, azure, debugging, gemini, generative-ui, inspector, json-rpc, langgraph, llm, mcp, mcp-apps, mcp-client, mcp-inspector, model-context-protocol, ollama, openai, playground, sandbox, skills

## 简介

See every MCP message: chat with any LLM and MCP server, compare models, call tools, and see what your AI editor sends to your MCP servers. 100% local. One command: npx @mokalabs/sandbox
