# @awais0198/evalgate

> 标签: ai-agents, claude-code, code-review, evaluation-harness, llm-as-judge, llm-evaluation

## 简介

An open evaluation and audit layer for AI coding agents — scores tool-call diffs, calibrates against human overrides, and gives non-engineers a way to review flagged changes.
