# @lsby/ts-hkt

> 标签: JavaScript

## 简介

这是一个 TypeScript 库，用于模拟高阶类型（Higher-Kinded Types）。由于 TypeScript 的类型系统不支持“一等”类型的构造器（First-class Type Constructors），本库通过接口和类型运算来实现类似的功能。
