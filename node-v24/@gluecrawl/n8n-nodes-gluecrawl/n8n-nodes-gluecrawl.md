# @gluecrawl/n8n-nodes-gluecrawl

> 标签: crawler, data-extraction, gluecrawl, n8n, n8n-community-node-package, scraping, web-scraping

## 简介

n8n community nodes for Gluecrawl — agentic web scraping. Create jobs from a plain-English goal, start runs, pull structured rows, and trigger workflows on run completion.
