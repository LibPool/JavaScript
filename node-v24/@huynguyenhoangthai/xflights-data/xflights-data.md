# @huynguyenhoangthai/xflights-data

> 标签: JavaScript

## 简介

This is a pre-built integration package to access master data like Airlines, Airports, and Flights, served by the [xflights](https://github.com/capire/xflights) microservice. For example, it is used in the [xtravels](https://github.com/capire/xtravels) ap
