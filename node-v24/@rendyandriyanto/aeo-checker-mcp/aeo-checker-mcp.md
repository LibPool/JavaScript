# @rendyandriyanto/aeo-checker-mcp

> 标签: aeo, ai-readiness, answer-engine-optimization, claude, llm, mcp, model-context-protocol, seo

## 简介

MCP server that scans a URL or a whole site for AEO / AI-readiness and hands the extracted content plus structural answer signals to the host LLM to judge answer-ability.
