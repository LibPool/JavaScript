# @honeypathkar/react-native-live-update

> 标签: activitykit, android, dynamic-island, ios, live-activity, live-update, notification, now-bar, react-native

## 简介

Live Activities on iOS (Lock Screen + Dynamic Island) and Live Updates on Android 16 (status-bar chip, and the OEM surfaces built on it such as Samsung's Now Bar) behind one API.
