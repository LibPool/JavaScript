# @vitibase/ssr

> 标签: auth, cookies, nextjs, postgres, remix, ssr, vitibase

## 简介

Server-side rendering helpers for Vitibase — cookie-based sessions for Next.js, Remix, SvelteKit and other frameworks that render on the server.
