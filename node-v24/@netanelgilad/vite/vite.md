# @netanelgilad/vite

> 标签: build-tool, dev-server, framework, frontend, hmr, vite

## 简介

Vite 8 repinned onto @netanelgilad/rolldown (single-threaded WASM Rolldown) to run inside workerd / Cloudflare Worker-Loader child isolates. Self-contained: bundles a single-threaded esbuild-wasm shim as esbuild; workerd code-generation rewrites pre-baked
