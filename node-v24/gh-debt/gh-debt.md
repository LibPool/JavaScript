# gh-debt

> 标签: gh-extension, github-cli, issue-tracking, pr-review, stale, technical-debt

## 简介

GitHub CLI extension for tracking and managing technical debt — PRs awaiting review, assigned issues, and stale items across all your repositories, prioritized by date
