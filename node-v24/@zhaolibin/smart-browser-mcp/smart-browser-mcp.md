# @zhaolibin/smart-browser-mcp

> 标签: ai-agents, api-testing, automation, browser, browser-automation, cdp, claude, claude-code, e2e, mcp, mcp-server, model-context-protocol, playwright

## 简介

Browser automation and API testing MCP server built on Playwright + CDP. Numbered element refs and Set-of-Mark screenshots let AI agents target the right node; flow record/replay, element memory, captcha handoff and an HTTP API test suite.
