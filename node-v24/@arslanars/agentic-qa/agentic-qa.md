# @arslanars/agentic-qa

> 标签: ai-testing, allure, automation, claude, claude-code, cucumber, e2e, gherkin, page-object-model, playwright, playwright-bdd, qa, test-generator, test-runner

## 简介

Local Playwright + BDD framework with a visual test runner UI. Turns user stories into executable browser tests, auto-heals failures, tracks flakiness, and maps git diff to affected features. No paid API required.
