# dsh-onebot-qq

> 标签: bridge, chatbot, deepseek, deepseek-harness, dsh, go-cqhttp, harness, lagrange, llonebot, napcat, onebot, onebot11, qq, qq-bot, qqbot

## 简介

给 dsh（DeepSeek Harness）加 QQ 机器人通道：OneBot 11 协议，兼容 NapCat，支持私聊群聊、图片语音、t2i 卡片与设置页配置。QQ bot channel plugin for deepseek harness via OneBot 11.
