# angpackage-grid

> 标签: angular, batch-editing, crud, data-grid, datagrid, excel-filter, grid, row-selection, table, tooltips, virtual-scroll, virtualization

## 简介

High-performance Angular data grid: row + column virtualization (50k–1M rows), Excel-style filtering and a filter row, multi-sort, row selection, add/update/delete with batch editing and undo, tooltips, summaries, templates and a full grid API.
