# @gjsify/gi-runtime-android

> 标签: android, gjsify, glib, gobject-introspection, nativescript

## 简介

NativeScript plugin that puts the GObject-Introspection runtime into an Android APK — libnode_gi.so plus the GLib/GObject/Gio closure and their typelibs, for arm64-v8a and x86_64. Add it as a dependency and @gjsify/node-gi's `requireGi` works on the devic
