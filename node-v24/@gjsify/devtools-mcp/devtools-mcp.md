# @gjsify/devtools-mcp

> 标签: dbus, debug, devtools, gjs, gtk, mcp

## 简介

MCP↔devtools bridge for GJS apps — exposes a running app's org.gjsify.Devtools control plane (DBus) to an AI agent as MCP tools
