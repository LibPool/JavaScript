# @gjsify/gamepad-native

> 标签: controller, darwin, gamepad, gjs, linux, macos, sdl3, windows

## 简介

SDL3's gamepad subsystem, statically linked and trimmed, behind a GObject API that speaks the W3C standard layout — the backend of @gjsify/gamepad (ADR 0075). Contains no JavaScript; the prebuilt library and typelib arrive through per-target optionalDepen
