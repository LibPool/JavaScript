# @gjsify/workspace

> 标签: gjs, install, monorepo, node, workspace, yarn

## 简介

Yarn-workspaces-compatible discovery + resolution for gjsify install/foreach. Reads package.json `workspaces` (string array or { packages, nohoist } shape), expands globs, resolves `workspace:^` to local versions, builds the dependency graph + topological
