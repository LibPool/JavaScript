# @gjsify/webgl-linux-ppc64

> 标签: JavaScript

## 简介

linux-ppc64 prebuilt native library + GObject-Introspection typelib for @gjsify/webgl. Installed automatically on linux/ppc64 as an optionalDependency of that package (ADR 0017) and skipped everywhere else. Contains no JavaScript.
