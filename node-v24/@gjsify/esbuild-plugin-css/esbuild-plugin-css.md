# @gjsify/esbuild-plugin-css

> 标签: css, esbuild, gjs, gnome, gtk, plugin

## 简介

esbuild plugin that bundles CSS (resolving @import from node_modules) and returns the result as a string for GTK CssProvider.load_from_string()
