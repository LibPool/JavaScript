# @gjsify/sab-native-linux-x64-musl

> 标签: JavaScript

## 简介

linux-x64-musl prebuilt native library + GObject-Introspection typelib for @gjsify/sab-native. Installed automatically on linux/x64/musl as an optionalDependency of that package (ADR 0017) and skipped everywhere else. Contains no JavaScript.
