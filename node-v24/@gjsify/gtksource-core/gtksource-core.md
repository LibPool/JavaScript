# @gjsify/gtksource-core

> 标签: gjs, gtk, gtksourceview, headless, highlighting, language, style-scheme, syntax

## 简介

Headless GtkSourceView language/style parsing (renderer-free) — parse .lang and style scheme XML into typed data with JS regex translation, strict unsupported reporting
