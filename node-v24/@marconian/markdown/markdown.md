# @marconian/markdown

> 标签: admonitions, emoji, footnotes, katex, marconian, markdown, markdown-parser, markdown-renderer, mermaid, react, syntax-highlighting, tables, typescript

## 简介

React Markdown renderer with extended syntax support for admonitions, math equations (KaTeX), Mermaid charts, spoilers, definition lists, tables, code highlighting, footnotes, and emoji.
