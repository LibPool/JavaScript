# @spine-benchmark/metrics-model

> 标签: JavaScript

## 简介

Fit a linear feature -> milliseconds cost model (ridge regression) from measured device runs, overall and per GPU family, with cross-validation. Replaces the hand-tuned RI/CI weights with data-fitted coefficients.
