# @glyphcss/fonts

> 标签: 3d, ascii, extrude, font, glyphcss, mesh, opentype, text, truetype, ttf

## 简介

Turn fonts + text into extruded 3D polygon meshes for glyphcss. Framework-agnostic — returns Polygon[].
