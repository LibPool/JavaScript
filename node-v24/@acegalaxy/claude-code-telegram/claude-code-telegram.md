# @acegalaxy/claude-code-telegram

> 标签: ai-bot, ai-cli, anthropic, claude, claude-code, cli-bridge, codex, coding-agent, deepseek, gemini, openai, telegram, telegram-bot, voice, whisper

## 简介

Use Claude Code (and Codex / DeepSeek / Gemini) from Telegram. Tiny bridge: text + voice in, real-time stream out, full .claude/ harness per project. Switch CLI mid-chat with /cli, switch project with /project. One npm install.
