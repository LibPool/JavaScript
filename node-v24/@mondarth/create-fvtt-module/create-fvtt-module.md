# @mondarth/create-fvtt-module

> 标签: create, foundry-vtt, foundryvtt, fvtt, module, scaffold, template

## 简介

Scaffolds a Foundry VTT v14+ module project (TypeScript or JavaScript, Vite, Svelte or Lit, Vitest, Playwright, semantic-release, Sphinx).
