# @fireflydb/expo-driver

> 标签: crdt, expo, expo-module, fireflydb, sqlite

## 简介

Expo native module + drivers for FireflyDB. Bundles libfirefly and wires it through expo-sqlite, expo-secure-store, and React Native WebSocket.
