# @neewe/neewton-agent

> 标签: agent, ai, cli, daemon, device-code, local-runner, neewe, neewton, pipeline

## 简介

NEEWE Local Agent — CLI/daemon que executa jobs do Pipeline Dev na máquina do usuário (modo Local). Pareamento por device-code, servidor loopback e sincronização .neewe plug-and-play.
