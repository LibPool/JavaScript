# @quantajs/astro

> 标签: astro, astro-integration, islands, quantajs, ssr, state-management, store, typescript, withastro

## 简介

Astro integration for QuantaJS: one store shared by React, Vue and Svelte islands, a container per request, and server state that reaches the islands.
