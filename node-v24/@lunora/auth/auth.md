# @lunora/auth

> 标签: auth, better-auth, cloudflare, durable-objects, lunora, oauth, session, workers

## 简介

Cookie-session auth for Lunora: PBKDF2 email/password plus OAuth (PKCE), D1-backed, sessions in SessionDO
