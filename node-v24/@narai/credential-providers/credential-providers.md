# @narai/credential-providers

> 标签: aws-secrets-manager, azure-key-vault, credentials, env, gcp-secret-manager, keychain, secrets

## 简介

Pluggable secret-resolution for Node: env vars, JSON files, macOS/Linux keychain, Windows Credential Manager, and AWS / GCP / Azure cloud secret managers. Zero runtime dependencies; cloud + Windows SDKs loaded on demand.
