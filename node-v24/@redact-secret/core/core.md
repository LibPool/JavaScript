# @redact-secret/core

> 标签: browser, node, redaction, secret-detection, security

## 简介

Deterministic secret detection and redaction for runtime data and AI context: scans text locally before it reaches logs, storage, telemetry, tools, or model context. One API for Node.js and browsers.
