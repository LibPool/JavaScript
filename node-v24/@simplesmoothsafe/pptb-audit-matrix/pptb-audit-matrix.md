> 标签: audit, auditing, compliance, dataverse, metadata, powerplatform, pptb, security, toolbox

## 简介

Org, table and column audit flags on one screen: cross-environment diff against a second connection or a snapshot, bulk set with preview and confirm, CSV and snapshot export.
