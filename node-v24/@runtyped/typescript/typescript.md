# @runtyped/typescript

> 标签: compiler, runtime-type-reflection, runtyped, tsc, typescript

## 简介

The runtyped TypeScript compiler: tsc with always-on runtime type reflection. Native Go binary (fork of microsoft/TypeScript's native compiler); compiling with this tsc is the opt-in.
