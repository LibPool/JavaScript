# broken-roasts

> 标签: bot, burn, discord, funny, generator, random, roast, roast-api, roasts, savage, whatsapp, zero-dependency

## 简介

Zero-dependency roast generator. Five flavours (savage, light, general, burn, funny) plus personalised roasts. No API keys, works offline.
