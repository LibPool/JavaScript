# @flagtide/angular

> 标签: angular, feature-flags, signals, ssr, websocket, zoneless

## 简介

Signals-first Angular SDK for flagtide: injectFlag, a structural directive, a canMatch guard, a connection status signal and a dev overrides panel. Zoneless and SSR ready.
