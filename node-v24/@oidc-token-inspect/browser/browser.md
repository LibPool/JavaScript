# @oidc-token-inspect/browser

> 标签: auth, browser, devtools, drop-in, jwt, oauth, oidc, pkce, token

## 简介

Drop-in browser plugin for Token Inspect. Self-mounts a DevTools-style panel in a closed Shadow DOM. Includes ClientObserver (fetch and XHR pass-through wrap), PKCE flow reconstruction, traceparent correlation (same-origin allowlist).
