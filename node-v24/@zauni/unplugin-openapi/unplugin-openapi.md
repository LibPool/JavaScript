# @zauni/unplugin-openapi

> 标签: astro, esbuild, openapi, plugin, rolldown, rollup, rspack, swagger, unplugin, vite, webpack, yaml

## 简介

A bundler agnostic plugin which converts OpenAPI 3.0, 3.1 and Swagger files to ESM modules.
