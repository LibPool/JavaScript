# @pipeworx/mcp-511-sf-bay

> 标签: 511-sf-bay, mcp, mcp-server, model-context-protocol, pipeworx

## 简介

511 SF Bay Transit MCP — live departures, vehicle positions and service alerts for every transit operator in the San Francisco Bay Area, from the regional 511.org open-data API run by the Metropolitan Transportation Commission.
