# @briefcase-ai/native

> 标签: JavaScript

## 简介

Native cost engine for briefcase-ai: model pricing and id normalization backed by the Rust core. Ships binaries for Linux x64/arm64 (gnu), macOS x64/arm64, and Windows x64 in one package.
