> 标签: adapter, ai-agents, chat-sdk, dial, imessage, mms, phone-number, sms, telephony, voice

## 简介

Wire a Dial phone number into a Chat SDK bot — the same handler answers SMS, MMS, iMessage, and inbound voice.
