# @amazon-devices/keplerscript-audio-lib

> 标签: JavaScript

## 简介

**KeplerScript-Audio** is set of libraries providing Audio APIs for KeplerScript applications. - Audio Focus - Volume Management - Audio Playback - Audio Record
