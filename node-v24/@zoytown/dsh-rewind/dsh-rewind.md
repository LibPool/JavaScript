# @zoytown/dsh-rewind

> 标签: agent-safety, ai-agent, checkpoint, coding-agent, cordis, deepseek, deepseek-harness, dsh, dsh-plugin, file-history, git, llm, plugin, restore, revert, rewind, rollback, shadow-git, snapshot, snapshots, time-machine, undo, undo-changes, version-history, workspace-backup

## 简介

DeepSeek Harness (dsh) plugin that snapshots your workspace at every turn into a shadow git repository, so you can restore the files to any earlier turn. Your own .git is never touched, and plain directories work too.
