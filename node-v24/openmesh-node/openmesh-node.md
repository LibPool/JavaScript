# openmesh-node

> 标签: backpressure, circuit-breaker, database, distributed-systems, framework, http, load-balancing, microservices, mtls, nodejs, opentelemetry, orm, redis, service-discovery, service-mesh, spiffe, streaming, traffic-management, typescript, workload-identity

## 简介

A TypeScript-first Node.js backend runtime for typed APIs and application-native microservices with database lifecycle, service discovery, traffic policy, backpressure, and streaming.
