# @appmonster/mcp-delivery

> 标签: cj대한통운, delivery, korea, mcp, model-context-protocol, parcel, tracking, 배송조회, 우체국, 택배

## 简介

MCP server for parcel tracking in Korea and abroad (CJ대한통운, 우체국, 한진, 롯데, 로젠, 쿠팡, 일본 야마토/사가와, DHL, UPS…) via Delivery Tracker — status, events, delivered-or-not, batch tracking. 택배 조회 MCP.
