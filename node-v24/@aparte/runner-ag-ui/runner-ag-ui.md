# @aparte/runner-ag-ui

> 标签: ag-ui, agent, agno, ai, chat, langgraph, mastra, runner, tanstack-ai

## 简介

Render an AG-UI agent in aparté — Agno, LangGraph, Mastra, CrewAI, Pydantic AI, TanStack AI: the agent runs on its server, aparté draws the chat, its tool calls and its approvals.
