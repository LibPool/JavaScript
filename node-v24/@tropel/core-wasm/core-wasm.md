# @tropel/core-wasm

> 标签: api-client, dynamic-variables, postman, variables, wasm, webassembly

## 简介

Tropel core tier for browser embedders (KnockPort): the dynamic-variable catalog (and later auth signing / import parse) compiled to wasm32-unknown-unknown. No QuickJS — see API_CLIENT_WEB_PAYLOAD.md §2.3 two-tier split.
