# mongoose-typed-aggregation

> 标签: aggregate, aggregation, group, inference, lookup, mongodb, mongoose, pipeline, type-safe, types, typescript, unwind

## 简介

Fluent, fully type-inferred aggregation pipelines for Mongoose. The compiler infers the output of .match().unwind().group().addFields().sort() — zero runtime cost.
