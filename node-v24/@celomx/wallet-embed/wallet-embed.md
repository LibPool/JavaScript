# @celomx/wallet-embed

> 标签: celo, embedded-wallet, human.tech, minipay, privy, react, thirdweb, waap, wallet

## 简介

Vendor-agnostic embedded wallet SDK. Mount Privy, thirdweb, or human.tech WaaP — one at a time — behind a single React API. MiniPay auto-detects.
