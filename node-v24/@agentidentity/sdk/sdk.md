# @agentidentity/sdk

> 标签: a2a, agent, agent2agent, ai-agent, email, events, identity, mcp, sdk, webhooks

## 简介

TypeScript client for Agent Identity — give an agent its own email address, durable event stream, agent-to-agent tasks, and encrypted secret vault.
