# @hodeinavarro/odoo-rpc-ts

> 标签: api-client, effect, effect-ts, erp, json-rpc, odoo, rpc, typescript

## 简介

Effect-native, strongly-typed Odoo RPC client for TypeScript — JSON-RPC, JSON-2, and cookie-session transports for Odoo 16–19 with a tagged-error taxonomy.
