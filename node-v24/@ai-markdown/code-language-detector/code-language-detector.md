# @ai-markdown/code-language-detector

> 标签: code-block, code-language, detect-language, highlight.js, language-detection, llm, markdown, shiki, streaming, syntax-highlighting, typescript

## 简介

Zero-dependency heuristic language detection for unlabelled code blocks, built for streamed LLM output: abstains instead of guessing, never flips between language families mid-stream, and maps fence language names to Shiki and highlight.js names.
