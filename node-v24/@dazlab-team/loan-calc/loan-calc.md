# @dazlab-team/loan-calc

> 标签: arm, calculator, formulas, interest, loan, mortgage, principal, repayments

## 简介

Loan calculator written in TypeScript. OO interface. ARM (Adjustable Rate Mortgage) options. Interest only repayments. Extra monthly payments option. Adjustable repayment frequency.
