# @enablo/flip-auth

> 标签: authentication, flip, getflip, hono, keycloak, oidc, openid-connect, pkce

## 简介

Sign in with Flip (Keycloak OIDC, authorisation code + PKCE) for Node and edge apps, with optional Hono routes. Unofficial; not made by Flip.
