# @webdesignhot/design-md-mcp

> 标签: ai-agents, claude, claude-code, codex, cursor, design-system, design.md, mcp, model-context-protocol

## 简介

MCP server exposing the webdesignhot.com DESIGN.md catalog (400+ real-brand design systems) to Claude Code, Claude Desktop, Cursor, Codex, Cline, and any other MCP-aware AI agent. Tools: list, get, search, diff, export, component resolution, and safe toke
