# @file-viewer/renderer-design

> 标签: abr, aco, animate, ase, asl, csh, document-preview, eps, file-viewer, fla, grd, icml, idml, idms, illustrator, indd, inx, offline, pat, pdd, photoshop, postscript, psb, psd, psdt, renderer, wasm, worker, xd, xfl

## 简介

Offline-first Adobe design renderer for Photoshop, native PGF and PDF-compatible Illustrator, InDesign, XD, modern XFL-based Animate FLA, and bounded design-resource previews.
