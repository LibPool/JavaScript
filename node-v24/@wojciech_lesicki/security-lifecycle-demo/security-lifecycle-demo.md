# @wojciech_lesicki/security-lifecycle-demo

> 标签: demo, educational, lifecycle-scripts, npm, postinstall, preinstall

## 简介

Educational demo of npm preinstall/postinstall lifecycle scripts - each hook fetches a package's registry metadata and logs the response, and reports how npm >=12's allowScripts blocking affects it.
