# @i-scope/com-protocol-types

> 标签: com-automation, constants, dispid, i-scope, iscope, iscope-debugger, oscilloscope, protocol

## 简介

TypeScript constants mirror of the iScope COM protocol — IDispatch DISPIDs (SDBGMID, SACID), event ids (DBGEID, OSCEID), step actions (STEPACT), break reasons (BRKREASON), VLST runtime ids (RTID). The authoritative C++ definitions live in @i-scope/iscope-
