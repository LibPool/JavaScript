# @exsa/exsa

> 标签: a11y, accessibility, bem, classless, css, css-framework, css-layers, custom-properties, design-system, design-tokens, lightweight, theming, zero-build

## 简介

A 5-layer CSS framework built on tokens, not tools. 24 KB core (~5.6 KB gzipped). 50 components. 20 themes. Zero build step.
