# @rabbx/kv

> 标签: JavaScript

## 简介

A cross-platform, type-safe Key-Value store abstraction. It provides a unified, modern async API that works identically across Node.js, Bun, Cloudflare Workers, Vercel KV, and the Browser. Stop rewriting your storage logic every time you switch runtimes o
