# @sahan-sac/blog-kit

> 标签: ai, blog, llm, markdown, seo

## 简介

Headless AI blog toolkit on @sahan-sac/ai-core: full-post generation with a JSON schema and repair pass, SEO suggestions, draft and cover helpers, AI image generation through an ImageSink port, plus pure blog utilities (slugs, Markdown and HTML conversion
