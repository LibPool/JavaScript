# @sahan-sac/media-kit

> 标签: cloudinary, images, media, r2, s3, upload

## 简介

Headless media layer for Cloudinary, AWS S3 and Cloudflare R2: multi-account registry with ordered failover, upload/format validation, HMAC and SigV4 signing, delivery URL transforms, a browser upload client, and a typed CloudinaryClient. Framework-agnost
