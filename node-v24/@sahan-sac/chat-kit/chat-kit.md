# @sahan-sac/chat-kit

> 标签: ai, chat, chatbot, prompt

## 简介

Headless chatbot core for the portfolio site: guarded prompt building, prompt-injection and output-link guards, an anonymous-visitor rate-limit cookie, a knowledge-base builder that tolerates a failing source, and runChat, the pure request/response path b
