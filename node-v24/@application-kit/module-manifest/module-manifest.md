# @application-kit/module-manifest

> 标签: manifest, modules, nestjs, vite-plugin

## 简介

Манифест модуля продукта: контракты web-, CLI-, консьюмер- и грант-манифестов, сборщики модулей процесса с проверкой дублей, SSR-реестр клиентских модулей для NestJS и Vite-плагин клиентских entry по раскладке
