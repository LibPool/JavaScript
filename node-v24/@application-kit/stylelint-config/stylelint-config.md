# @application-kit/stylelint-config

> 标签: stylelint, stylelint-config, vue

## 简介

Пресет stylelint приложения на пакетах @application-kit: стили .vue, .scss и .css — порядок свойств recess, стилистика @stylistic, Vue SFC через postcss-html
