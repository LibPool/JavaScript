# @application-kit/mailer

> 标签: email, mailer, nestjs, nodemailer

## 简介

Отправка писем по шаблонам для NestJS: SMTP или дамп в лог, идемпотентность по журналу отправленного, гейт подписок; шаблоны и тексты приносит приложение
