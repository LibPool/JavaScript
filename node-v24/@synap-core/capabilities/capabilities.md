# @synap-core/capabilities

> 标签: capabilities, manifest, synap, views, widgets

## 简介

React-free capability layer (families, interchange, manifest, registration meta) over the renderables catalog in @synap-core/types/renderables, which it re-exports. Safe to import from backend, AI agents and build scripts.
