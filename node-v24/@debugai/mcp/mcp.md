# @debugai/mcp

> 标签: ai, claude, debugai, debugging, error-analysis, mcp, model-context-protocol, stack-trace

## 简介

DebugAI MCP server. One command sets it up in Claude Desktop, Claude Code, Cursor, Zed, Windsurf, Cline, Gemini CLI or any MCP client: browser sign-in, no key pasting, no config editing.
