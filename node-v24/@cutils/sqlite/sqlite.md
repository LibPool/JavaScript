# @cutils/sqlite

> 标签: database, elf, native, scriptc, sqlite, standard-schema

## 简介

Embedded SQLite for chttp/scriptc apps — vendored amalgamation, FFI shim, Standard-Schema row seam. Compiles to a single static ELF.
