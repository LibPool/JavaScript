# @cutils/mongo

> 标签: bson, database, elf, mongo, mongodb, native, scriptc, standard-schema

## 简介

Async, hand-rolled MongoDB wire-protocol driver (OP_MSG + BSON) for chttp/scriptc apps — node:net/tls/crypto only, no FFI. Compiles to a single static ELF.
