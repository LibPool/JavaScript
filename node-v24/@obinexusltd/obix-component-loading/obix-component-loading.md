# @obinexusltd/obix-component-loading

> 标签: accessibility, busy, component, dop, feedback, loading, obix, spinner

## 简介

OBIX ObixLoading — a role="status" spinner with an accessible label and an optional full-area overlay; starts hidden. Data-Oriented, zero dependencies.
