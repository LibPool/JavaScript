# @obinexusltd/obix-component-radiogroup

> 标签: accessibility, component, dop, form, obix, radio, radiogroup, roving-tabindex

## 简介

OBIX ObixRadioGroup — a role="radiogroup" fieldset with roving tabindex, arrow-key navigation, and aria-checked per option. Data-Oriented, zero dependencies.
