# @obinexusltd/obix-component-toast

> 标签: accessibility, component, dop, feedback, notification, obix, snackbar, toast

## 简介

OBIX ObixToast — a transient notification with role="status", six screen positions, an auto-dismiss duration, and pause-on-hover. Data-Oriented, zero dependencies.
