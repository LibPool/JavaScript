# @deemwario/agent-proxy

> 标签: agentproxy, claude, codex, copilot, masking, mitm, proxy, secrets, security

## 简介

A local proxy that masks secrets in your AI coding agents' traffic before they leave your machine. Installs the AgentProxy CLI + per-agent wrappers.
