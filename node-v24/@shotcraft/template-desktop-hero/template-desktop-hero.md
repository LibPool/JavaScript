# @shotcraft/template-desktop-hero

> 标签: desktop, hero, landing, readme, shotcraft, shotcraft-template

## 简介

Shotcraft template — Desktop hero composite. 1920×1080 landscape, browser-chrome framed, dark + light variants. Good for README heroes, landing pages, blog posts, OG images.
