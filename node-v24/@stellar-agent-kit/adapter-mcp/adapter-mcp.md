# @stellar-agent-kit/adapter-mcp

> 标签: JavaScript

## 简介

Expose StellarAgentKit as a Model Context Protocol (MCP) server. Each agent action becomes one MCP tool consumable by Claude Code, Cursor, and other MCP clients.
