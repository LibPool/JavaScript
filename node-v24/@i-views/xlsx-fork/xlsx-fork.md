# @i-views/xlsx-fork

> 标签: csv, dbf, dif, excel, ods, office, spreadsheet, sylk, xls, xlsb, xlsm, xlsx

## 简介

Fork of `xlsx` with disabled date parsing: Excel (XLSB/XLSX/XLS/XML) ODS and other spreadsheet format (CSV/DIF/DBF/SYLK) parser and writer

## 官网

- 官网：http://sheetjs.com/opensource
- 源码仓库：git://github.com/SheetJS/js-xlsx.git
- npm 页面：https://www.npmjs.com/package/@i-views/xlsx-fork

- npm registry：https://registry.npmjs.org/@i-views/xlsx-fork
