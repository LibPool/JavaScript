# @react-router-modules/runtime

> 标签: JavaScript

## 简介

Application assembly layer for modular-react (React Router integration). Takes modules and configuration, produces a running app — either with the library-owned router (`resolve()`) or wrapped around `@react-router/dev/vite` framework mode (`resolveManife
