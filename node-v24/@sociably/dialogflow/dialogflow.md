# @sociably/dialogflow

> 标签: JavaScript

## 简介

This module implement the [`IntentRecognizer`](https://sociably.js.org/api/modules/core_base_intentrecognizer.html) interface with [DialogFlow ES](https://cloud.google.com/dialogflow/es/docs) API.
