# @mailsenpai/nestjs

> 标签: email, mailer, mailsenpai, nest, nestjs, nestjs-module, smtp-senpai, transactional-email

## 简介

NestJS module for SMTP Senpai by MailSenpai: inject the SMTP Senpai email API client (send, events, suppressions, webhooks) with forRoot/forRootAsync.
