# @ihc/terminal-cloud-client

> 标签: JavaScript

## 简介

Vanilla TypeScript client for Terminal Cloud. Same client targets either the cloud REST API (set baseUrl to *.convex.site) or an on-LAN proxy (set baseUrl to http://192.168.x.x:8900) — the proxy transparently forwards online and handles offline-supported
