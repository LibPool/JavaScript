# @rio-cloud/rio-order-chat-component

> 标签: JavaScript

## 简介

This library provides the Order Communication Chat-Menu React component that can be embedded in the ApplicationHeader. The actual content of the order chat -- are embedded via an iFrame that references https://order-communication-chat.tour-tracking.rio.cl
