# supply-chain-sentinel

> 标签: cli, cyclonedx, dependencies, devsecops, github-action, github-actions, license, lockfile, npm, osv, sarif, sbom, security, supply-chain, supply-chain-security

## 简介

One supply-chain gate for npm projects: runs package-tripwire (risky dependency changes), license-sentinel (license policy), sbom-diff-sentinel (new vulnerabilities and SBOM drift) and workflow-sentinel (GitHub Actions hardening) with one config, one comb
