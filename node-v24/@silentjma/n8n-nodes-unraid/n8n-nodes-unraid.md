# @silentjma/n8n-nodes-unraid

> 标签: docker, graphql, homelab, n8n, n8n-community-node-package, unraid

## 简介

Unofficial n8n community nodes for the Unraid GraphQL API: Docker, array, VMs, logs, notifications and a polling trigger for log/alert watching.
