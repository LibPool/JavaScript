> 标签: edge, feature-flag-sdk, feature-flags, feature-toggles, nextjs, react, sdk, serverless, switchflag

## 简介

Lightweight feature flag SDK for Node.js and edge runtimes. Evaluate flags locally with zero runtime dependencies.
