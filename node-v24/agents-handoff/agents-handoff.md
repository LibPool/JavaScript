# agents-handoff

> 标签: agent, ai, claude-code, codex, continuation, cross-harness, handoff, installer, npx, provenance, session, skill

## 简介

Write, verify, and hand off complete AI working sessions across any harness (Claude Code, Codex, DeepSeek Harness, plain JSONL or text logs). Cross-harness session capture with sha256 provenance and verified continuation.
