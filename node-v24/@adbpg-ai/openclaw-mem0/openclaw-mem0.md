# @adbpg-ai/openclaw-mem0

> 标签: adbpg, alibaba-cloud, analyticdb, long-term-memory, mem0-compatible, memory, openclaw, plugin

## 简介

OpenClaw memory plugin for AnalyticDB for PostgreSQL Long-Term Memory service. Apache-2.0 fork of @mem0/openclaw-mem0 with self-hosted endpoint compatibility.
