# mates-css

> 标签: JavaScript

## 简介

CSS library for all frameworks like React, Vue, Mates, Angular, Solid, Svelte, Lit. Even plain JS. It even comes with a design system. A compact pure-CSS no-JS library with design tokens, automatic dark mode, flex & grid utilities, and CSS-only charts.
