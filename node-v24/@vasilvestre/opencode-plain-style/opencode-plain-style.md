# @vasilvestre/opencode-plain-style

> 标签: opencode, opencode-plugin, plain-language, style-guide, writing

## 简介

Plain-language writing rules for opencode agents, injected into every system prompt. Enforces ISO 24495-1 principles on commits, comments, docs, and chat prose.
