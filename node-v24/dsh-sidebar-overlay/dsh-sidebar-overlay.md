# dsh-sidebar-overlay

> 标签: deepseek-harness, dsh, dsh-plugin, floating-sidebar, overlay, sidebar, ui

## 简介

Floating sidebar overlay for DSH: an independently rendered workspace/session browser mounted in the official shell.overlay seat, without touching the official sidebar or grid. 独立渲染的 DSH 浮动侧边栏：不碰官方侧边栏与 grid。
