# @mind-elixir/export-html

> 标签: JavaScript

## 简介

`@mind-elixir/export-html` is a plugin of [mind-elixir-core](https://github.com/ssshooter/mind-elixir-core). You can use `@mind-elixir/export-html` to export a `.html` file.
