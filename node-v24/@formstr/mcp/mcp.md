# @formstr/mcp

> 标签: ai-tools, forms, formstr, mcp, model-context-protocol, nostr

## 简介

Model Context Protocol server for the Formstr super-app — drive Nostr forms (and more) from any MCP host, with secure keychain/NIP-46 login.
