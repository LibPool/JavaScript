# @fonderie/react-config-admin

> 标签: admin, config, feature-flags, fonderiejs, hooks, react, secrets, typescript

## 简介

React hooks for the Fonderie config admin API (feature flags/remote config + secrets) — thin bindings over @fonderie/client's ConfigAdminClient.
