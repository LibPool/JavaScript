# @fonderie/react-admin

> 标签: admin, fonderiejs, hooks, management, operations, react, typescript

## 简介

React hooks over @fonderie/admin — the operator's surface. One hook per page: attention, manifest, doctor, config, routes, tokens, admin log. Admin-token authenticated; the shell in @fonderie/react-admin-screens composes these with the config and courier
