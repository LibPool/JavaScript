# @uiseal/cli

> 标签: accessibility, angular, cli, css, design-system, design-tokens, drift, linter, sarif, scss, svelte, tailwind, tailwindcss, tokens, vue

## 简介

CLI and interactive TUI for uiseal — design-system enforcement for AI-generated code. Checks CSS, JSX, Vue, Angular, Svelte, and backend templates against your design tokens.
