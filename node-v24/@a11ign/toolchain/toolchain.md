# @a11ign/toolchain

> 标签: node:test, rslib, rstest, toolchain, tsconfig

## 简介

The one test and build toolchain every a11ign repository shares: the rstest config (node:test shim, run record, verdict line), the Rslib presets, and the TypeScript base.
