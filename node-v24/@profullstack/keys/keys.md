# @profullstack/keys

> 标签: api-key, ed25519, edge, license-key, middleware, power-key, profullstack, token, web-crypto

## 简介

One key for every Profullstack service. Ed25519-signed Power Keys minted at profullstack.com/shop and verified offline, over Web Crypto, in Node, Bun and at the edge.
