# @profullstack/myna-plugin-agenticjobs

> 标签: agenticjobs, hiring, jobs, myna, myna-plugin

## 简介

Post jobs to an agenticjobs board from myna. A job posting is a publication, not a status update, so it is never part of a fan-out.
