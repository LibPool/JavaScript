# @profullstack/wx93

> 标签: agents, cli, hqtui, mcp, qr-code, short-links, tui, url-shortener

## 简介

wx93.me from the terminal: shorten links, see their stats, print QR codes, all in an hqtui TUI too, plus a stdio MCP server for agents.
