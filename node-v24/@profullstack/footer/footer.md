# @profullstack/footer

> 标签: copyright, footer, hono, nextjs, openwebring, react, ssr, webring

## 简介

One footer for every Profullstack site: links, copyright and the << Profullstack >> webring nav with Random. Sites render the @latest template from the CDN at runtime, so a release updates every site without a redeploy.
