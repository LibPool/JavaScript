# @profullstack/media2markdown-core

> 标签: ffmpeg, llm, markdown, ocr, rag, transcription, whisper

## 简介

Deterministic media-to-Markdown pipeline: ffmpeg, whisper.cpp, OCR and PDF parsers. No LLM in the loop.
