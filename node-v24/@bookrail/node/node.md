# @bookrail/node

> 标签: api-client, availability, booking, bookings, bookrail, reservations, scheduling, sdk, typescript

## 简介

Bookrail SDK for TypeScript. Types generated from the OpenAPI specification, one hand-written idiomatic layer on top. ESM only.
