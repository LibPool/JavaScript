# @minimalcorp/meshi

> 标签: calorie, developer-tools, health, local-first, meshi, nutrition, self-hosted, tracker

## 简介

摂取カロリーを記録し、目標に対する進捗を可視化するローカルツール。npx 一発で web + server を起動する。
