> 标签: api-client, api-testing, cli, contract-testing, developer-tools, fetch, http, middleware, rest, sdk, test-runner, type-safe, typescript, validation, zod, zod-contracts

## 简介

A strongly typed TypeScript HTTP client powered by Zod contracts, middleware, retries, mock data, contract testing, CLI tooling, and report generation.
