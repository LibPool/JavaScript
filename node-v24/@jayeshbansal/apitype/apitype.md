# @jayeshbansal/apitype

> 标签: api, cli, code-generation, codegen, developer-tools, json, json-schema, mcp, model-context-protocol, openapi, schema, type-generation, typebox, types, typescript, vite-plugin, zod

## 简介

Generate TypeScript types, Zod schemas, TypeBox, and JSON Schema from any API endpoint or JSON — instantly. Works as a CLI, MCP server, Vite plugin, and GitHub Action.
