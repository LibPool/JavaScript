# @tzam-org/providers

> 标签: JavaScript

## 简介

Provedores de login agnósticos e multi-org: herança global → org → app, drivers (senha, e-mail, magic link, OTP, GitHub, Google, Microsoft Entra ID), cliente OIDC do Entra (PKCE, nonce, state no servidor), segredos cifrados presos à org, logout front-chan
