# @ontemper/as2

> 标签: JavaScript

## 简介

AS2 (RFC 4130) client for Temper workflows: receive, send (pack -> deliver -> confirm), MDN handling. All S/MIME crypto executes on the platform engine - the SDK implements no cryptography itself.
