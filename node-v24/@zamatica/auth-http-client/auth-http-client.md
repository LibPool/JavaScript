# @zamatica/auth-http-client

> 标签: JavaScript

## 简介

Auth-aware fetch wrapper for the zamatica fleet-env cert auth scheme. signedFetch() signs the request via @zamatica/auth-core, attaches MTZ-* headers, and discovers the daemon's instance-id from /health.
