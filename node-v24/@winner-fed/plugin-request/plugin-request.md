# @winner-fed/plugin-request

> 标签: axios, composition-api, http, interceptor, plugin, request, typescript, useRequest, vue-hooks-plus, vue2, vue3, winjs, winjs-dev, winner-fed

## 简介

WinJS 框架的 HTTP 请求插件，基于 axios 和 vue-hooks-plus，提供了强大的请求处理能力和 Vue 3 Composition API 支持。
