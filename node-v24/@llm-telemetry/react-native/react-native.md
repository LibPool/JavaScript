# @llm-telemetry/react-native

> 标签: ai, anthropic, evaluation, gpt, grafana, llm, loki, observability, opentelemetry, rag, react-native, tempo, tracing

## 简介

Production-ready, provider-agnostic LLM observability SDK for React Native. Auto-instruments any AI chat or search feature with OpenTelemetry traces, RAG quality metrics, and automated evaluation scores.
