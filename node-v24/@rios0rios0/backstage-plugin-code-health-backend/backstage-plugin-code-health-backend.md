# @rios0rios0/backstage-plugin-code-health-backend

> 标签: azure-devops, backstage, backstage-plugin, ci, code-health, confluence, github, jira, wakatime

## 简介

Backstage backend plugin that ingests repository history from the catalog's GitHub and Azure DevOps repositories into the Backstage database, and serves it to the Code Health dashboard
