# @inxep/probuilder

> 标签: xengine

## 简介

Minimal Unity-ProBuilder-style procedural geometry for XEngine: parametric shapes (grid plane / cube / stairs / ramp) as engine meshes with automatic MeshRenderer + static MeshCollider wiring. zonezero M5 arena.
