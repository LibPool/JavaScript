# @inxep/xts

> 标签: hot-update, quickjs, scripting, typescript, xengine

## 简介

Official optional TypeScript game scripting and hot-update for XEngine: authors gameplay as TypeScript, packs it with the editor toolchain, and runs it on QuickJS behind a versioned native ABI on Windows and HarmonyOS players. Installs the script runtime,
