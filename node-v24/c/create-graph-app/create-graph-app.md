# create-graph-app

> 标签: cli, create-app, express, generator, nextjs, postgres, scaffolding, template

## 简介

Interactive full-stack project initializer — a composable template registry (Next.js, Zustand, shadcn/ui, Express, Neon Postgres, AWS S3) consumable by this CLI today and by an AI orchestration engine later.
