# cf-wfp-simulator

> 标签: cloudflare, dispatch-namespace, local-development, miniflare, saas, simulator, wfp, workers, workers-for-platforms, wrangler

## 简介

Local simulator for Cloudflare Workers for Platforms. Import the wrap function in your dispatcher; flip one URL env var to switch between localhost and CF.
