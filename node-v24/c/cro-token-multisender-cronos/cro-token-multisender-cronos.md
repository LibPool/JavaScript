# cro-token-multisender-cronos

> 标签: Multisender

## 简介

Script ini adalah alat sederhana yang memungkinkan Anda untuk mengirim CRO (Chrono) ke beberapa alamat tujuan sekaligus di jaringan Cronos menggunakan beberapa private key yang telah Anda siapkan. Ini berguna jika Anda perlu mendistribusikan CRO ke bebera
