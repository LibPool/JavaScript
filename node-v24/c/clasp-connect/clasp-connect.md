# clasp-connect

> 标签: connector, passkey, rainbowkit, wagmi, wallet, xrpl, xrpl-evm

## 简介

Dapp SDK for the Clasp wallet — XRPL popup signing and an XRPL EVM wagmi connector. Zero runtime dependencies.
