# cross-window-state

> 标签: broadcast-channel, cross-tab, cross-window, electron, electron-state, ipc, multi-window, shared-state, state-management, vue

## 简介

One state, many windows, always in sync — shared reactive state for Electron multi-window apps and cross-tab web apps, with built-in persistence and versioned migration.
