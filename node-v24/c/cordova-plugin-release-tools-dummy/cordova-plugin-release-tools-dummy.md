# cordova-plugin-release-tools-dummy

> 标签: JavaScript

## 简介

This is a dummy Cordova plugin for testing [Cordova Release Tools](https://github.com/janpio/cordova-release-tools). It does absolutely nothing when added to a Cordova plugin, but I can use it to use the `cort` commands and see if they still work.
