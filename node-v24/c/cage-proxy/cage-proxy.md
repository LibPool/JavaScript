# cage-proxy

> 标签: agent-sdk, anthropic, cage, claude, gemini, openrouter

## 简介

Drop-in wrapper for @anthropic-ai/claude-agent-sdk that routes via the Cage Worker to Anthropic, OpenRouter, or Google Gemini models.
