> 标签: ai, anthropic, claude, claude-code, cli, developer-tools, productivity, reliability, session-analysis, streaks

## 简介

How long can Claude Code go without an error? Median 12 successful tool calls between errors. Longest streak: 829. Bash breaks 52% of streaks.
