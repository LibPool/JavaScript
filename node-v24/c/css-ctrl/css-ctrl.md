# css-ctrl

> 标签: JavaScript

## 简介

**CSS-CTRL** is a `CSS-in-JS` library that combines ideas from **Tailwind**-like shorthands and dynamic style injection (similar to **styled-components**). It provides features such as theme/palette management, breakpoints, container queries, pseudo-class
