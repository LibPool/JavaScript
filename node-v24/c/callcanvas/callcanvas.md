# callcanvas

> 标签: api, api-report, api-testing, callcanvas, html-report, playwright, playwright-test, qa, redact, report, reporter, request, response, sanitize, testing

## 简介

CallCanvas — visual API reporting for Playwright. Every API call. One clear view: sanitized request/response pages inside the native Playwright report, one self-contained page per test.
