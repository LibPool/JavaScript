# chillchart

> 标签: bar-chart, chart, charts, dark-mode, framework-agnostic, graph, line-chart, pie-chart, vanilla-js, visualization, zero-dependency

## 简介

Zero-dependency chart library with line, bar, pie, and doughnut charts. Framework-agnostic with dark/light mode support.
