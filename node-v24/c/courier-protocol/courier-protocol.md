# courier-protocol

> 标签: agent identity, agent infrastructure, agent-operations, ai agent email, autonomous email, autonomous-agents, durable email identity, email for agents, email recovery, governed outbound, magic link receiver, mcp, modelcontextprotocol, otp extraction, persistent inbox, scoped credentials, verification code, x402

## 简介

Durable email identities for autonomous AI agents — persistent inboxes, scoped credentials, recovery after memory loss, OTP and magic link handling, and governed outbound communication without Gmail OAuth.
