# claude-agents-doctor

> 标签: agents, ai-agents, anthropic, claude, claude-code, linter, mcp, orchestration, subagents

## 简介

Static linter for Claude Code subagent hierarchies (.claude/agents). Catches broken auto-delegation, read-only permission mismatches, and orchestration anti-patterns. Zero dependencies.
