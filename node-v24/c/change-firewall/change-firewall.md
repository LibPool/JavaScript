# change-firewall

> 标签: agentic-coding, ai-agent-verification, ai-coding-agents, ast-diff, blast-radius, claude-code, code-review, crash-proof, cursor, cursor-agent, developer-tools, git-diff, mcp, mcp-server, merge-gate, model-context-protocol, pre-commit, static-analysis, symbolic-execution, trust-layer, typescript, windsurf

## 简介

The deterministic trust layer for autonomous AI coding agents. Compiler-grounded verification of what an agent actually did vs. what it claimed, blast radius mapping, and persistent contract memory.
