# cldz-cli

> 标签: anthropic, api-key, bedrock, claude, claude-code, cli, launcher, oauth, vertex

## 简介

One-command launcher for Claude Code — pick an auth method (API key / OAuth / gateway / Bedrock / Vertex) once and just run `cldz`.
