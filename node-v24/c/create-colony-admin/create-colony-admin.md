# create-colony-admin

> 标签: admin, admin-template, ant-design, antd, create-app, dashboard, react, scaffold, typescript, vite

## 简介

Scaffold Colony — a free, bilingual React admin dashboard on Ant Design v6, Vite 8 and TypeScript. No meta-framework, no prerelease dependencies.
