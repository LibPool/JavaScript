# closingset

> 标签: cleanup, graceful, lifecycle, shutdown, sigint, sigterm

## 简介

Every process deserves a proper closing set. Tiny graceful-shutdown manager: register cleanup handlers, run them LIFO on SIGINT/SIGTERM with a hard timeout.
