# cc-grass

> 标签: claude-code, contribution, github, grass, profile, readme, stats, svg

## 简介

GitHub-style contribution grass SVG generator for Claude Code usage. Reads ~/.claude/projects/**/*.jsonl (and ~/.codex/sessions if present) and renders an orange grass graph for your README.
