# chunkjson

> 标签: ai, edge, json, json-lines, jsonl, llm, ndjson, partial-json, sse, stream, streaming-json, streams, transformstream, typescript, web-streams

## 简介

Streaming JSON for Web Streams: line splitting, NDJSON/JSON Lines, incremental array streaming, and partial JSON for LLM output. Zero dependencies, runs on every runtime.
