# cidr-deny-allow-transformer

> 标签: allow, aws, aws-cdk, aws-sdk, cdk, cidr, deny, ingress, ip, network, sdk, securitygroup

## 简介

This is a NPM library that allows you to transform a subset of denied CIDRs within a larger CIDR into a list of allowed CIDRs.
