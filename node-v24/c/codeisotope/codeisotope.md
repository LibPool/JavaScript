# codeisotope

> 标签: ai, claude-code, codebase, cursor, dependencies, github, golang, opencode, oss, python, rust, supply-chain

## 简介

Finds the mature, battle-tested libraries your AI-written codebase reinvented by hand, grades the dependencies it already has, and reports what is missing. JavaScript, Python, Rust and Go.
