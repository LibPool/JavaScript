# cryptbridge

> 标签: aes, bun, cross-language, cryptography, encryption, hmac, laravel, php, polyglot, security, typescript

## 简介

The AES-256-CBC bridge for Laravel ⇄ Bun. CryptBridge lets your polyglot stack services in Bun read and write encrypted blobs compatible with Laravel's Crypt::encryptString()
