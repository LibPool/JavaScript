# cortico-world-browser

> 标签: bilibili, browser, cortico, cortico-world, danmaku, puppeteer, search, video, web

## 简介

Cortico World: 浏览器 —— 她能搜索、开页、读页、点击、填表、上传、截图，也能陪看 B 站视频（画面拼图、字幕与弹幕），共用浏览器与登录态。★ 非即插即用：装完包还不能用，要先装上游 web-access，填 worlds.browser.skillDir、选浏览器并打开远程调试，否则 World 起不来。要求 Cortico 0.2.0 及以上。 ★ 支持 Coopanion(Coo):0.2.5 上实测通过。有问题请提 GitHub issue,或到 QQ 群 @筆離嘢。
