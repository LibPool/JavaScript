# comark-tiptap

> 标签: comark, editor, markdown, prosemirror, react, tiptap, vue

## 简介

A Comark-aware Tiptap kit — edit markdown, Comark AST, or ProseMirror JSON with lossless round-trips, plus optional framework bindings.
