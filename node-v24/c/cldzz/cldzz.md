# cldzz

> 标签: anthropic, api-key, bedrock, chatgpt, claude, claude-code, cli, codex, launcher, oauth, openai, subscription, vertex

## 简介

One-command launcher for Claude Code and Codex — pick a provider + agent, and cldz runs it (auto-proxying cross-provider via Switchyard).
