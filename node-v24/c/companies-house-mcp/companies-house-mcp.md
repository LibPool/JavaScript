# companies-house-mcp

> 标签: api, claude, companies-house, company-search, due-diligence, mcp, mcp-server, model-context-protocol, uk

## 简介

MCP server for the UK Companies House public register — connects Claude, Codex, Cursor, Zed and other MCP clients to live company data. Bring your own free API key.
