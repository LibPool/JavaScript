# clenzer

> 标签: antigravity, ast, claude-code, cleaner, code-cleanup, code-quality, complexity, cursor, dead-code, javascript, linter, mcp, mcp-server, model-context-protocol, refactor, static-analysis, ts-morph, typescript, unused-imports, unused-variables

## 简介

MCP server that scans for dead code and unnecessary complexity in TypeScript/JavaScript projects, then safely cleanses it. Works with Claude Code, Cursor, Antigravity, and any MCP-compatible CLI agent.
