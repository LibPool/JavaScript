# crates-io-mcp

> 标签: cargo, crates, mcp, packages, rust

## 简介

Look up Rust crates, versions, and downloads from crates.io. No key required.

- 官网：https://github.com/mrfentmen/crates-io-mcp#readme
- 源码仓库：git+https://github.com/mrfentmen/crates-io-mcp.git
- npm 页面：https://www.npmjs.com/package/crates-io-mcp

## 获取地址

- npm 安装：`npm install crates-io-mcp`
- npm registry：https://registry.npmjs.org/crates-io-mcp
- Node 要求：>=20
