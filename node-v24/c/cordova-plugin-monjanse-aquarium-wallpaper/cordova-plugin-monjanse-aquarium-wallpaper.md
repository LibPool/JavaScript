# cordova-plugin-monjanse-aquarium-wallpaper

> 标签: aquarium, cordova-android, ecosystem:cordova, gdevelop, live-wallpaper, wallpaperservice, webgl

## 简介

Interactive GDevelop/WebGL Android live wallpaper. Version 1.0.3 renders the virtual display into ImageReader frames and copies them to the WallpaperService surface, fixing devices that only showed the fallback background.
