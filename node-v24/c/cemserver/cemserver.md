# cemserver

> 标签: ExpressJS 4.0 With OAuth2, HTTP Server, JSON Cache, NodeJS Clusterable, sqlite3

## 简介

Clusterable ExpressJS Server with OAuth2
A very simple and hopefully powerful NodeJS OAuth2 server, as well as a simple sqlite3 based JSON Cache.
