# claude-math

> 标签: claude, claude-code, claude-code-plugin, codex, codex-cli, codex-skills, katex, latex, math, skill, terminal, unicode

## 简介

Render math legibly in Claude Code and OpenAI Codex CLI. Emits Unicode glyphs instead of unrenderable LaTeX in the terminal. A stopgap until hosts render math natively.
