# caelario-mcp

> 标签: caelario, claude, codex, facebook, instagram, mcp, model-context-protocol, social-data, tiktok, twitter, youtube

## 简介

MCP server for social media data from Instagram, TikTok, YouTube, X and Facebook. Run extractions, batches, schedules, saved results and usage workflows through Caelario.
