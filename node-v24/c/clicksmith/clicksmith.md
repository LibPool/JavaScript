# clicksmith

> 标签: accessibility, aria, browser-automation, chrome, chrome-extension, claude, design-qa, figma, mcp, model-context-protocol, qa, testing

## 简介

MCP server + Chrome extension that lets Claude drive your real Chrome browser for QA, testing, and design comparison. ARIA-first, batch execution, Figma-ready.
