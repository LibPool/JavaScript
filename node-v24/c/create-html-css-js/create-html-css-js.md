# create-html-css-js

> 标签: JS, Javascript, create html, css and javascript, css, css3, html, html5

## 简介

A handy tool to generate basic HTML, CSS, and JS files with a responsive header, body, and footer. Perfect for starting new projects with ease. Get your HTML, CSS, and JS foundations in place quickly!
