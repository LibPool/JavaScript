# chrome-bulk-screenshot

> 标签: batch, bulk, chrome, headless, screengrab, screenshot, snapshot

## 简介

This package will EFFICIENTLY take pdf snapshots of rendered web pages in bulk using Puppeteer (aka headless Chromium).
