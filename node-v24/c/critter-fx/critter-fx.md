# critter-fx

> 标签: animation, background, bats, birds, boids, butterflies, canvas, critters, effect, flocking, halloween, no-dependencies

## 简介

Canvas critters for the browser: bats, birds, bugs and anything else that moves on its own, with flocking, roosting and pointer scatter. No dependencies.
