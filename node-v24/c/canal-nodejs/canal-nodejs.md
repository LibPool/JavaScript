# canal-nodejs

> 标签: canal, client

## 简介

> 此应用是 node js 版本的 [Canal](https://github.com/alibaba/canal) 客户端。 >  > 它可以让你在 node js 环境中对 MySQL 数据库中的数据进行增量订阅 & 消费。更多信息请看 [Canal wiki]( https://github.com/alibaba/canal/wiki)
