# ct-gantt-vue

> 标签: JavaScript

## 简介

基于 Vue 3.5+ 的甘特图组件，支持计划条、实际条、阶段汇总、任务依赖、里程碑、虚拟滚动、拖拽编辑、图片导出和原生实例接入。
