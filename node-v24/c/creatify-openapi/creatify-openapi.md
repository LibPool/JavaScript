# creatify-openapi

> 标签: autocrudify, creatify, creatify-openapi, eventify, generator, json-ject, migratify, openapi, permissify, persistify, scaffold, serveify, tsify

## 简介

Generate a serveify-openapi server project from an openapi.json (json-ject) spec: migratify DB import, openapi-blocks prefabs, tsify types, eventify events, autocrudify + persistify + permissify wiring
