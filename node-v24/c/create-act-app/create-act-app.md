# create-act-app

> 标签: JavaScript

## 简介

Bootstrap an ACT-emitting site from an example template. Unscoped per npm-create convention (npm create act-app@latest).

## 官网

- 官网：https://act-spec.org
- 源码仓库：git+https://github.com/act-spec/act.git
- npm 页面：https://www.npmjs.com/package/create-act-app
