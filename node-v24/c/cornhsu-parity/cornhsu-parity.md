# cornhsu-parity

> 标签: ci, css-inspector, design-qa, design-tokens, figma, pixel-perfect, playwright, property-level-design-qa, ui-testing, visual-regression

## 简介

Property-Level Design QA that can gate your CI. Compares real numeric values from your Figma file against the rendered UI and fails the PR when the implementation drifts from the design.
