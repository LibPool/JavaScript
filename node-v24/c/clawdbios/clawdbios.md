# clawdbios

> 标签: agent, ai, base, claude, clawdbios, clawdos, cli, fal, firmware

## 简介

ClawdBIOS — the firmware layer for autonomous agents, in your terminal. Create agents, load a character, and chat with them. Boot. Verify. Execute.
