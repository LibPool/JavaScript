# create-cesiumjs

> 标签: 3d-map, cesium, cesiumjs, geospatial, react18, scaffold, vite, vue3

## 简介

A scaffolding tool to quickly create CesiumJS geospatial visualization projects, supporting HTML, Vue3 + Vite, and React18 + Vite templates
