# clonify

> 标签: clone, clonify, cloning, copy, cyclic, data, deep, deep-clone, deepclone, javascript, object, structures, utility

## 简介

A feature-rich, cyclic-safe deep clone utility for JavaScript. Handles POJOs, custom classes, Maps, Sets, Symbols, Dates, RegExps, and more — all with prototype preservation.
