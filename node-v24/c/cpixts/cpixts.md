# cpixts

> 标签: content-protection, cpix, dash, dash-if, drm, hls, playready, pssh, speke, widevine

## 简介

Isomorphic TypeScript library for CPIX (DASH-IF Content Protection Information Exchange) documents, with Widevine/PlayReady DRM and AWS SPEKE v2 support
