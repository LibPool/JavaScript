# create-roxyon-app

> 标签: create, lumenjs, roxyon, scaffold, starter

## 简介

Scaffold a Roxyon project — LumenJS SPA or a Node app — wired for `roxyon deploy`, with AGENTS.md / llms.txt / editor rules so any AI assistant gets it right.
