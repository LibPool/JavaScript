# cloudflare-range-cache

> 标签: 206, bandwidth, cache, cdn, cloudflare, cloudflare-workers, edge-cache, mp4, partial-content, range, range-requests, streaming, video, worker

## 简介

Cache HTTP Range (206 Partial Content) responses at the Cloudflare edge without Enterprise — a dependency-free Worker that chunk-caches large media and reassembles correct 206 responses.
