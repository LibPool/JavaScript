# claude-accounts-usage

> 标签: anthropic, chatgpt, claude, codex, multi-account, openai, opencode, opencode-plugin, quota, tui, usage

## 简介

OpenCode TUI plugin to view multi-account Claude and ChatGPT subscription usage and switch the active account. Coexists with @ex-machina/opencode-anthropic-auth and OpenCode built-in codex auth.
