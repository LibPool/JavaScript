# cdc-monitor

> 标签: cassandra, cdc, change-data-capture, dashboard, debezium, kafka, logical-replication, monitoring, observability, postgres

## 简介

Database-agnostic change data capture monitoring: point it at PostgreSQL, Cassandra or any Debezium/Kafka stream and get a unified event model, metrics, anomaly detection, backlog predictions and a dashboard.
