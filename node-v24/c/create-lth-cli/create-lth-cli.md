# create-lth-cli

> 标签: JavaScript

## 简介

1. **commander:** 参数解析  --help其实就借助了他 2. **inquirer:** 命令行交互,可以实现vue脚手架那种选择模块的功能 3. **chalk:** 命令行样式，帮助我们输出各种颜色 4. **fs-extra:** 文件操作 5. **download-git-repo:** 下载git仓库 6. **ini:** 配置文件ini格式解析器何序列号器 7. **ora:** 实现命令行loading 8. **nodemon:** 监控文件变化自动执
