# cache-panda

> 标签: async-cache, cache, cache-manager, cache-wrapper, conditional-cache, decorator, execution-time-cache, lazy-cache, method-cache, nestjs, nestjs-cache, panda, performance-cache, prefix-cache, smart-cache, ttl, typescript

## 简介

🐼 A flexible, decorator-based smart cache module for NestJS with TTL, key prefixing, and conditional caching based on method execution time.
