# create-file-manager-app

> 标签: Express, File Manager, JWT, MongoDB, Node, React, Template

## 简介

​ ## Description Create File Manager apps with no build configuration. This is the installer tool for the [file-manager-auth-mern](https://github.com/ashkiani/file-manager-auth-mern) template which is a boilerplate for Password Protected File Manager Apps
