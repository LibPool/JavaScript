# cursor-composer-in-claude

> 标签: anthropic, api, chat-completions, claude, cursor, llm, openai, proxy, streaming

## 简介

OpenAI- and Anthropic-compatible proxy for the Cursor agent CLI. Use Cursor models from any LLM client, with multi-account rotation, streaming, and an auto-starting SDK.
