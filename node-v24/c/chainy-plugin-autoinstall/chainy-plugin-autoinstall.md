# chainy-plugin-autoinstall

> 标签: chainy, chainy-addon, chainy-custom, chainy-plugin

## 简介

Chainy plugin that automatically installs missing plugins on node versions 0.11 and above

## 官网

- 官网：https://github.com/chainy-plugins/autoinstall
- 源码仓库：http://github.com/chainy-plugins/autoinstall.git
- npm 页面：https://www.npmjs.com/package/chainy-plugin-autoinstall

## 历史版本号

- 当前版本：1.0.0

- 1.0.0

## 获取地址

- npm 安装：`npm install chainy-plugin-autoinstall`
- npm registry：https://registry.npmjs.org/chainy-plugin-autoinstall
- Node 要求：>=0.4
