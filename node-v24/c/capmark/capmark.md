# capmark

> 标签: agent, agent-skills, ai-agent, capabilities, deepseek-harness, dsh, manifest, mcp, permissions, plugin, sandbox, security, supply-chain

## 简介

Declare what an AI agent plugin may do, in Markdown, and check it. Drafts the manifest for you from what the plugin already declares.
