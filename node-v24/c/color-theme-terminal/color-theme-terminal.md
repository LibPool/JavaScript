# color-theme-terminal

> 标签: JavaScript

## 简介

¿Quieres añadir un toque de estilo a tu terminal?   Este paquete te permite mostrar un mensaje con diferentes temas de color en la consola de Windows (o cualquier consola que soporte ANSI), ideal para darle personalidad a tus proyectos desde el primer co
