# crehq-mcp-server

> 标签: brand-affiliation, claude, crehq, entity-resolution, fdd, franchise, location-data, mcp, model-context-protocol, retail

## 简介

Model Context Protocol server for CREHQ entity affiliation and location intelligence (brands, operators, parent companies, storefronts, franchise data, credit signals, site history, whitespace and co-tenancy).
