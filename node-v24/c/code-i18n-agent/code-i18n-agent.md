# code-i18n-agent

> 标签: agent, ast, code, i18n, internationalization, mcp

## 简介

智能体：自动将代码项目国际化的扫描-分类-提取-翻译-替换-验证管线（不限于 ERP，适配 Vue/React/TS/JS/HTML）
