# create-auric

> 标签: multi-tenant, nestjs, postgresql, row-level-security, saas, scaffold, starter

## 简介

Scaffold a developer-owned AURIC Core foundation — identity, organizations, RBAC, files, messaging, multi-tenant PostgreSQL with row-level security — into your own project.
