# commit-log-daily

> 标签: agent, ai, cli, commit, daily, git, langchain, log

## 简介

从多个 Git 仓库聚合提交记录，生成日报/周报/月报。采用自然语言驱动的 Agent 交互方式，配置好 API 后直接对话即可。
