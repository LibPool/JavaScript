# com.hidano.realtimeavatarcontroller

> 标签: avatar, mocap, realtime, vmc, vtuber

## 简介

Runtime avatar controller for VTuber use cases. Provides slot-based MoCap source management, avatar provider abstraction, and motion pipeline for Unity.
