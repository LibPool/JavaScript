# citeguard-mcp-server

> 标签: academic, ai-agent, bibliography, citation-checker, citations, crossref, doi, expression-of-concern, literature-review, mcp, mcp-server, model-context-protocol, modelcontextprotocol, open-science, peer-review, reproducibility, research-integrity, retracted, retraction, retraction-watch, scholarly

## 简介

MCP server that checks whether a cited paper has been retracted, corrected, or flagged with an expression of concern -- via Crossref, including Retraction Watch records. No API key.
