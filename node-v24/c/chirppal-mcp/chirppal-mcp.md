# chirppal-mcp

> 标签: ai, anthropic, deprecation, gemini, llm, mcp, model-context-protocol, openai

## 简介

MCP server for the ChirpPal Model Deprecation Radar — ask an AI assistant whether an LLM model is deprecated and what to migrate to.
