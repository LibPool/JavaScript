# cokpit

> 标签: cokpit, installer, windows

## 简介

Installs Cokpit for Windows: downloads the latest signed installer from cokpit.dev, checks its SHA-256 and runs it.

- 源码仓库：https://cokpit.dev
- npm 页面：https://www.npmjs.com/package/cokpit

- npm registry：https://registry.npmjs.org/cokpit
