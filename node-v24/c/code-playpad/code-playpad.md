# code-playpad

> 标签: code-editor, codemirror, custom-element, education, javascript, playground, pyodide, python, repl, run-code-in-browser, sandbox, typescript, wasm, web-component

## 简介

Embeddable browser code playground: a CodeMirror editor that runs Python, JavaScript and TypeScript in the browser. No backend. One shared worker per page, blocking input(), multi-file projects, lazy per-language loading.
