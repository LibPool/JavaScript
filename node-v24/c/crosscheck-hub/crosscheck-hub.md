# crosscheck-hub

> 标签: acp, agent-client-protocol, claude-code, coding-agents, cursor, developer-tools, hooks, mcp, pglite, team-coordination

## 简介

Team coordination for local coding agents: a self-hosted hub with embedded PGlite plus connectors for Claude Code, Cursor and any ACP agent — presence, claims, diagnosis trees.
