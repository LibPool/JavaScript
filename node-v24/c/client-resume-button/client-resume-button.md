# client-resume-button

> 标签: composer, continue, cordis, deepseek-harness, dsh, dsh-plugin, interrupted, resume

## 简介

Adds a Continue button to the DeepSeek Harness composer: when the previous turn was interrupted (by the user, a crash, or an error), one click asks the model to pick that turn back up.
