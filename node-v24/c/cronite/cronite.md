# cronite

> 标签: background-jobs, cron, cronite, persistent-cron, scheduler, sqlite-cron, task-scheduler

## 简介

Simple persistent cron job manager for Node.js – SQLite storage, failure handling, user ownership, dynamic add/start/stop
