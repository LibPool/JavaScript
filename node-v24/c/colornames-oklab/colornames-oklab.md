# colornames-oklab

> 标签: blue-noise, color, color-names, colors, display-p3, oklab, oklch, palette, rec2020, wide-gamut

## 简介

4444 color names blue-noise sampled over the Rec2020 gamut in OKLab — evenly spread perceptually, tiered by gamut (sRGB / Display P3 / Rec2020), named by Claude Fable 5.
