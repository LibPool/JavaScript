# chakram-cucumber

> 标签: API, BDD, HTTP, JSON, REST, chai, test

## 简介

chakram-cucumber is an fork of chakram package. It was modified to work with cucumber runner. Chakram is API testing framework designed to test JSON REST endpoints. The library offers a BDD testing style and fully exploits javascript promises
