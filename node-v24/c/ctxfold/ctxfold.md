# ctxfold

> 标签: anthropic, cli, compression, context-window, csv, json, llm, logs, lossless, openai, prompt, prompt-engineering, tokenizer, tokens, tsv

## 简介

Lossless, structure-aware re-encoding of bulky text (logs, JSON, CSV) to cut LLM prompt tokens. Lossless or no-op — never lossy.
