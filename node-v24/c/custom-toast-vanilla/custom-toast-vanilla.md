# custom-toast-vanilla

> 标签: alpine.js, custom, frontend, javascript, laravel, notification, toast, vanilla

## 简介

A lightweight and customizable toast notification library for JavaScript applications, designed for seamless integration with Laravel, Alpine.js, and vanilla projects. Enhance your user interface with elegant, responsive notifications.
