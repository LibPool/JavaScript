# crypto-pay-js

> 标签: cli, crypto, freelance, npx, trc20, usdt, zero-dependencies

## 简介

Check USDT (TRC20) payments to a wallet and generate a QR code for receiving one. Zero dependencies, no API key, runs via npx straight from GitHub.
