# create-designjs

> 标签: claude, cursor, design-to-code, designjs, mcp, model-context-protocol, scaffolder

## 简介

Project scaffolder for DesignJS — creates a fresh directory wired up to the DesignJS MCP server so an AI agent can design in it.
