# cloudy-cli

> 标签: ai, chat, cli, cloudy, coding-agent, terminal, tui

## 简介

Cloudy in your terminal — chat, one-shot asks, and the coding agent that runs in the folder you are standing in. Same account, models and quota as the web app.
