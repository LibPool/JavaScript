# complex-md

> 标签: AGENTS.md, claude-code, code-churn, coding-agents, cursor, git, hotspots, mcp

## 简介

COMPLEX.md: a computed map of where edits are risky and where bugs get fixed, for coding agents. Signals from git, hooks that gate hotspot edits, an MCP server agents query mid-task.
