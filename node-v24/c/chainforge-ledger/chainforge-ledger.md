# chainforge-ledger

> 标签: blockchain, consensus, cryptocurrency, cryptography, dao, defi, dex, layer1, ledger, pos, pow, sharding, smart-contracts, staking, tokenomics, wallet, web3

## 简介

A modular JavaScript blockchain framework for building custom Layer 1 networks with PoW/PoS, smart contracts, DeFi, governance, tokenomics, and sharding support.
