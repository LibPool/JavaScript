# cordova-plugin-ios-finite-task

> 标签: background, cordova, cordova-ios, ecosystem:cordova, suspend, task

## 简介

Cordova/PhoneGap Plugin for running finite duration tasks (will also run for up to 3 minutes after the app is suspended).
