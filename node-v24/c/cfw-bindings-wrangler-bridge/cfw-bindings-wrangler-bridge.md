# cfw-bindings-wrangler-bridge

> 标签: bindings, cloudflare, d1, kv, r2, workers, wrangler

## 简介

This bridge makes it possible to interact with **remote** Cloudflare Workers bindings(like KV, D1, etc...) **from anywhere** you want.
