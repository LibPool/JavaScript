# chapi-ai

> 标签: ai, anthropic, chatbot, groq, llm, openai, rag, vercel-ai-sdk, vue, web-component

## 简介

Chatbot de IA con RAG: multi-proveedor (Anthropic/OpenAI/Google/Groq), grounding no configurable, adaptadores de backend (Express/Next.js/Convex/serverless) y widget de UI en Vue.
