# clujo

> 标签: async-jobs, cluster-safe, concurrent-tasks, cron, dependency-management, distributed-locking, javascript, job-automation, node, parallel-execution, redis, single-execution, sync-jobs, task-dependencies, task-scheduler, topological-sort, typescript, workflow-orchestration

## 简介

Schedule interdependent tasks on a cron-like schedule with parallel task execution. Built in distributed locking to prevent overlapping executions in a clustered environment.
