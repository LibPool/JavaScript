# code-agent-orchestrator-protocol

> 标签: cao, code-agent-orchestrator, contract, protocol, types

## 简介

The wire contract shared by the code-agent-orchestrator CLI and CAO Desktop: run-directory layout, workflow/run/event types, transcript entries and planning, and the registry, request, interaction and presence file schemas. Zero runtime dependencies, no N
