# compact_model

> 标签: Compact, Model, Proxy

## 简介

Compact Model est un `Model Proxy` qui vous permet d'avoir une codebase refactorisée lorsqu'il s'agit de définir vos endpoints et le flux réseau en encapsulant le client `axios`.
