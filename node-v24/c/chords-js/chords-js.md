# chords-js

> 标签: abc, chord-progression, chords, harmony, music, music-education, notation, roman-numeral, transpose

## 简介

A reference library for the .chords harmony format — parse, transpose, Roman-numeral analysis, chord-chart rendering, and an ABC bridge to abcjs (the abcjs-analogue for chord progressions).
