# claude-review-tool

> 标签: annotate, claude, claude-code, devtools, feedback, nextjs, overlay, proxy, review, vite-plugin

## 简介

Claude Review Tool (CRT): annotate your local site in the browser, talk to Claude in-page, get a self-contained task file in your repo.
