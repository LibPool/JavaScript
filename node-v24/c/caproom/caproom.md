# caproom

> 标签: ai-agent, cgroup, idle-memory, macos, memory, oom, park, process-limit, watchdog

## 简介

Memory-cap any command (AI coding agents, builds, background jobs) on macOS, Linux, and Windows — real enforcement via Docker cgroups, Windows Job Objects, or a polling watchdog, plus park/wake to reclaim idle process memory without killing.
