# concurrent-thread-js

> 标签: async, concurrent, es6, javascript, promise

## 简介

为单线程的JavaScript实现多线程并发的功能，语意上参考Java实现，提供getState/sleep/join等API，并提供线程间通信的功能，依赖ES6语法，基于Promise和Async函数实现，故需要Babel编译才能运行
