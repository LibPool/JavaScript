# catalog-converter

> 标签: JavaScript

## 简介

A library with utility functions and a CLI for converting a TerriaJS v7 catalog to a TerriaJS v8 catalog.

- 源码仓库：git+https://github.com/TerriaJS/catalog-converter.git
