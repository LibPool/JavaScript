# chooper-grid

> 标签: JavaScript

## 简介

基于VUE3实现的虚拟表格,功能有： * 理论无限的大数据垂直滚动（数据过多后滚动无法精准定位） * 虚拟水平滚动 * 列锁定 * 列拖动改变顺序 * 排序
