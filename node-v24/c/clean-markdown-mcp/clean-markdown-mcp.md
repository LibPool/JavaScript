# clean-markdown-mcp

> 标签: ai-agent, apify, claude, html-to-markdown, llm, markdown, mcp, mcp-server, model-context-protocol, rag, readability, scraper, web-scraping

## 简介

MCP server that turns any URL into clean, LLM-ready Markdown. Strips ads, nav, and boilerplate using Mozilla Readability. Built for RAG pipelines and AI agents.
