# catalyst-scaffold

> 标签: JavaScript

## 简介

Interactively scaffolds a Turborepo monorepo: Express API gateway + gRPC microservices + React web app, with optional MongoDB/PostgreSQL, Redis + BullMQ, Socket.IO, file uploads, and Prometheus + Grafana.
