# csv-types

> 标签: CSV, csv, flexible, parser, reader, table, types

## 简介

CSV Types (csv-types-js) is a JavaScript library to parse CSV strings (comma separated values and text files with fields delimited by a character) and produce a JavaScript AST (abstract syntax tree) with the data. It also supports *types specs*: multiple
