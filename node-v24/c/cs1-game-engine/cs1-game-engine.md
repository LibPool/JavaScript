# cs1-game-engine

> 标签: JavaScript, WebGL, game engine

## 简介

The CS1 Game Engine is a 3D Multiplayer VR-ready Game Engine designed for Computer Science Education and application prototyping. The v1.0.0 release will be polished and ready for commercial applications.
