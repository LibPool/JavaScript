# capacitor-maplibre-native

> 标签: android, capacitor, capacitor-plugin, compass, gps, map, maplibre, maplibre-native, native, navigation, ride-sharing

## 简介

Native MapLibre GL map plugin for Capacitor 8. GPU-accelerated real native MapView — not a WebView map. Built for ride-sharing and navigation apps.
