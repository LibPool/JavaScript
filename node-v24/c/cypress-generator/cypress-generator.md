# cypress-generator

> 标签: automation, cypress, data-cy, e2e, flask, python, qa, scraper, test-generator, testing

## 简介

Generate real-world Cypress E2E specs from scraped pages — data-cy-first selectors, login support, and optional Flask web UI.
