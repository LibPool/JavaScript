# cgparse

> 标签: CGView, EMBL, GenBank, bioinformatics, parser

## 简介

Converts sequence files (GenBank, EMBL, FASTA) and feature files (GFF3, GTF, BED, CSV) to JSON and CGView JSON

- 官网：https://parse.cgview.ca
- 源码仓库：git+https://github.com/sciguy/cgview-parse.git
