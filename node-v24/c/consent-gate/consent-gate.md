# consent-gate

> 标签: analytics, cmp, consent, cookie-consent, cookieconsent, eprivacy, gdpr, nextjs, react, tracker

## 简介

Structural cookie-consent gating. Declare trackers with a category; the library owns injection and refuses to load anything before that category is granted. Vanilla core + optional React wrapper, built on CookieConsent v3.
