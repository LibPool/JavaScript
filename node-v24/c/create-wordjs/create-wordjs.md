# create-wordjs

> 标签: bootstrap, cms, create, nextjs, no-php, plugin-permissions, sandbox, sandboxed-plugins, scaffold, self-hosted, sqlite, ssr, typescript, wordjs, wordpress-alternative

## 简介

Create a WordJS site with one command — the self-hosted CMS where third-party plugins run in an OS-isolated process with per-capability permission grants. SSR/SEO out of the box, SQLite by default, no PHP.
