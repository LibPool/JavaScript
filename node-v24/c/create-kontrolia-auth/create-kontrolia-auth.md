# create-kontrolia-auth

> 标签: auth, cli, iam, installer, kontrolia, supabase

## 简介

Turnkey installer for KontrolIA Auth. `npx create-kontrolia-auth mi-app` checks requirements, downloads the repo, installs deps, and runs a wizard: (1) connect to an existing Supabase project or create a new self-hosted one via Docker; (2) where to deploy
