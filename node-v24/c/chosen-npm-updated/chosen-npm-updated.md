# chosen-npm-updated

> 标签: JavaScript

## 简介

An npm friendly fork of Chosen which is a JavaScript plugin that makes select boxes user-friendly. It is currently available in both jQuery and Prototype flavors.

- 官网：https://github.com/harvesthq/chosen#readme
- 源码仓库：git+https://github.com/harvesthq/chosen.git
- npm 页面：https://www.npmjs.com/package/chosen-npm-updated
