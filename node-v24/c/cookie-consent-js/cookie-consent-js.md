# cookie-consent-js

> 标签: cookie, cookie consent, dsgvo, eu, gdpr, javascript, js, law

## 简介

A simple dialog and framework to handle the EU law (as written by EuGH, 1.10.2019 – C-673/17) about cookies in a website.
