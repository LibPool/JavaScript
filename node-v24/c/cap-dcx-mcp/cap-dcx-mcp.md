# cap-dcx-mcp

> 标签: aggregator, claude, figma, gateway, github, jira, mcp, model-context-protocol, omnistudio, salesforce

## 简介

DCX MCP gateway: a single MCP server that aggregates GitHub, Salesforce, OmniStudio, Figma, and Jira MCP tools. Add it once to an MCP client (e.g. Claude Code) over stdio/npx and use all underlying tools.
