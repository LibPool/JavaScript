# claude-code-win32

> 标签: bash, claude, claude-code, claude-code-plugin, claude-plugin, cross-platform, developer-tools, git-bash, hook, msys, powershell, pwsh, transpile, transpiler, typescript, win32, windows

## 简介

Claude Code Plugin: hybrid bash→PowerShell transpiler for Windows. POSIX pass-through, targeted rewrites, MSYS path translation, per-command deny hints.
