# clean-special-chars

> 标签: accented, accentuation, clean string

## 简介

Converts accented letters to its cleaned form like 'Ã' to 'A', 'ç' to 'c', '&!*' to '', etc. All spaces will be converted to '-' and the text is returned in Lower Case
