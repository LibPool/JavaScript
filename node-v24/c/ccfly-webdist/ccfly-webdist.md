# ccfly-webdist

> 标签: ccfly, claude-code, spa, tmux, web-ui

## 简介

Prebuilt ccfly web UI (ttyd-ui SPA). The ccfly binary embeds a fallback copy and fetches newer versions of this package at runtime, so UI updates ship via npm without rebuilding/republishing the platform binaries.
