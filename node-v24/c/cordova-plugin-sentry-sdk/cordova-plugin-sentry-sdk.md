# cordova-plugin-sentry-sdk

> 标签: cordova-android, cordova-ios, ecosystem:cordova, sentry

## 简介

Starts the native Sentry SDKs (sentry-cocoa, sentry-android) through their public API and keeps the user, tags and contexts your JavaScript SDK sets in sync, so a native crash is reported with the context of the session it happened in
