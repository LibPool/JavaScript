# cordova-plugin-screen-blocker

> 标签: capacitor, cordova-android, cordova-ios, ecosystem:cordova, flag-secure, ionic, privacy, screen-recording, screenshot

## 简介

Cordova/Ionic plugin to block screenshots and screen recording on Android and iOS, with capture/recording event callbacks.
