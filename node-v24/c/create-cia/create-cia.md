# create-cia

> 标签: create-cia, css-is-awesome, design-system, installer, scss, wizard

## 简介

npm create cia — guided installer for css-is-awesome (cia). Detects your framework and package manager, installs cia, wires the two-import SCSS model, picks a theme, and optionally connects the MCP server for AI agents. Existing projects only — no scaffol
