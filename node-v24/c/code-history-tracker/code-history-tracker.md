# code-history-tracker

> 标签: blame, code history, code history tracker, code-archaeology, commit, function history, git, history, history tracker, line history, tracking, version-control

## 简介

Track code changes history - see all commits that modified a function or line with hover and right-click. A VS Code extension that lets you track the complete history of any line of code or function without manually searching through git history.
