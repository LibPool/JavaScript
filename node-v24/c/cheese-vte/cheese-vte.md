# cheese-vte

> 标签: JavaScript

## 简介

**cheese-vte** vte表示的是基于vue开发的table组件包含了Excel的简略功能;   **cheese-vte** 是一个多表头可编辑的组件，采用了Excel的合并方式，进行多级表头的设置，是一个可视化编辑的表格;   **cheese-vte** 的发展路线是将Excel常用简单功能代入到table表格中;
