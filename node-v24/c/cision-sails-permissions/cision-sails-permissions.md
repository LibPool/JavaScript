# cision-sails-permissions

> 标签: access, acl, audit, enterprise, entitlements, grant, passport, permissions, privileges, rbac, restriction, roles, sails, sails.js, security, tracking, trail

## 简介

Cision Fork. Comprehensive user permissions and entitlements system for sails.js and Waterline. Supports user authentication with passport.js, role-based permissioning, object ownership, and row-level security.
