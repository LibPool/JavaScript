# cordova-plugin-media-extended

> 标签: Phonegap Android media, cordova, cordova-amazon-fireos, cordova-android, cordova-blackberry10, cordova-ios, cordova-tizen, cordova-ubuntu, cordova-windows, cordova-windows8, cordova-wp7, cordova-wp8, ecosystem:cordova, media

## 简介

Cordova plugin Media, exdended to change setMediaStreamType constant on Android. Can play sound as System sound, as Ring, as Music etc.
