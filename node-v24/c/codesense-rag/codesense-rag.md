# codesense-rag

> 标签: cli, code-search, embeddings, rag, semantic-search, vector-search

## 简介

A CLI tool for semantic codebase search using embeddings, vector similarity, and RAG — ask plain-English questions about your code instead of grepping for exact keywords.
