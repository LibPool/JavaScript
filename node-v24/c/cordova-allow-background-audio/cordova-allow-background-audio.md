# cordova-allow-background-audio

> 标签: audio, background, background-audio, cordova, cordova-ios, ecosystem:cordova, ios, media, phonegap

## 简介

Allow background Audio for iOS

		When included within a cordova/phonegap build then the application will allow background audio to continue to play for iOS
		out of the box. No further action is necessary.

		This negates having to use location/other
