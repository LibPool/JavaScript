# card-dispenser

> 标签: 3d, card, carousel, css-3d, dispenser, picker, random-pick, rolodex, roulette, scroll-driven, vanilla, zero-dependency

## 简介

A rotating card dispenser: cards stand edge-on around a drum, the one that reaches the front rises to face you. Scroll-scrub, drag, keyboard, and a spin-to-pick that lands on one item. Zero dependencies, CSS 3D.
