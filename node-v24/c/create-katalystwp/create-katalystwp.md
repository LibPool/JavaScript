# create-katalystwp

> 标签: agents, ai, claude, create, cursor, docker, mcp, scaffold, wordpress, wp-cli

## 简介

Scaffold a local WordPress + AI-agent dev environment (Docker Compose) with WP-CLI, Claude Code, and the Cursor CLI in an isolated workspace container.
