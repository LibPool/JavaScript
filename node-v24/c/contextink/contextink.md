# contextink

> 标签: acp, agent, ai-agents, ascii-art, clarification, context, discord, gemini-cli, intent, meme, zed

## 简介

Contextink - acquires context from minimal info so you do not have to explain it. Scans the repo, detects gaps, asks only the minimal high-information-gain questions.
