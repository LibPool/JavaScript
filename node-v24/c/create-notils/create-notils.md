# create-notils

> 标签: base-ui, cli, create, monorepo, nextjs, shadcn, starter, tailwind, turborepo

## 简介

Scaffold a production-ready Next.js project (Turborepo + Bun + Tailwind v4 + shadcn/ui on Base UI + Biome) as a monorepo or a standalone app, in one command.
