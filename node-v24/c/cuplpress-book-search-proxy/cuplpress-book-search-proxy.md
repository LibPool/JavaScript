# cuplpress-book-search-proxy

> 标签: JavaScript

## 简介

中国政法大学出版社图书检索 MCP stdio 代理：把本地 stdio 透明转发到远端 Streamable HTTP MCP（ai.cuplpress.com/mcp）。供只支持本地 command/stdio 的 MCP 客户端（如豆包等）接入。

## 官网

- npm 页面：https://www.npmjs.com/package/cuplpress-book-search-proxy

- 1.0.0
