# context-engine-ai

> 标签: agents, ai, ai-agents, context, context-engine, embeddings, events, llm, mcp, model-context-protocol, pgvector, rag, semantic-search, sqlite, temporal-decay, tfidf, vector-search

## 简介

A lightweight context engine for AI agents. Ingest events, build semantic context, query with natural language. Zero config default with SQLite + local TF-IDF embeddings.
