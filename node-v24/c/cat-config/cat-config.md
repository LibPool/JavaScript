# cat-config

> 标签: NODE_ENV, argv, cli, config, config-loader, configuration, docker, dotenv, env, json, merge, node-config, settings, toml, typescript, yaml

## 简介

Node.js config loader: load and merge from JSON, YAML, .env, TOML, CLI argv, and env vars. NODE_ENV-aware, TypeScript-ready, Docker-friendly.
