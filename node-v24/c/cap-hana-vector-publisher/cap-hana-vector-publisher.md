# cap-hana-vector-publisher

> 标签: cap, cds, cds-plugin, chunking, embedding, hana, hana-cloud, pdf, rag, sap, vector

## 简介

Plug-and-play SAP CAP plugin and library that extracts text from PDF/TXT/MD uploads, chunks it with overlap, stores the chunks with native SAP HANA Cloud vector embeddings (VECTOR_EMBEDDING) and serves upload and similarity search.
