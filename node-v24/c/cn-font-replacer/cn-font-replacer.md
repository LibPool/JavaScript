# cn-font-replacer

> 标签: cdn, cjk-font, cn-font, font

## 简介

font-replacer 是中文网字计划用于动态加载、动态更换字体所使用的库。你也可以自定义字体源来加载自己的字体，默认使用了字图 CDN的庞大字体库来源！
