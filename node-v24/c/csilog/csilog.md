# csilog

> 标签: csijs / felog / tntlog / log / frontendlog

## 简介

csijs是一个前端日志系统，它将错误信息记录于本地localStorage中。无任何依赖、无入侵性。

- 源码仓库：git+ssh://git@github.com/tnfe/csijs.git
