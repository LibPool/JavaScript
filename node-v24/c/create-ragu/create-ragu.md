# create-ragu

> 标签: claude-code, create, knowledge-base, mcp, rag, ragu, scaffold, starlight

## 简介

Scaffold a Ragu knowledge base: markdown docs validated by schema, published with Starlight, searchable by agents over MCP, kept in sync with your code by a Claude Code plugin.
