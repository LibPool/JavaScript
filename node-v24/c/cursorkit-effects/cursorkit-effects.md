# cursorkit-effects

> 标签: animation, canvas, cursor, cursor-effect, custom-element, effects, mouse, vanilla-js, web-component, zero-dependency

## 简介

25 套鼠标光标动效，封装为零依赖 Web Component。原生 Canvas 绘制，一行 import 接入，Vue / React / Next.js 与纯 HTML 通吃。
