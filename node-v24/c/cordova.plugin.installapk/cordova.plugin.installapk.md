# cordova.plugin.installapk

> 标签: android api26, install permission

## 简介

android API26及以上版本安装apk需要获取应用安装权限。 两个作用：一是检查当前应用是否具有应用安装权限，二是获取应用安装权限。

## 官网

- npm 页面：https://www.npmjs.com/package/cordova.plugin.installapk
