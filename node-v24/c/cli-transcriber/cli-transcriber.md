# cli-transcriber

> 标签: agent-skills, claude-code, cli, codex, markdown, partials, skills, subagents, templates, yaml

## 简介

Write agent skills and subagents once, as YAML with shared partials, and get Markdown for Claude Code, Codex and plugins. Every partial, skill, agent and tool a source uses must exist and be declared; the build checks it all and says where.
