# cron-kit-vue

> 标签: cron, cron-expression, crontab, form, quartz, scheduler, vue, vue-component, vue3

## 简介

Vue 3 版 Cron 表达式可视化组件：支持 v-model 与表单校验，可在弹窗中配置并回传表达式，零运行时依赖。
