# create-lumi-cms

> 标签: cms, create, lumi, scaffold, starter

## 简介

Scaffold a new Lumi CMS project. Thin wrapper that delegates to @murumets-ee/create so `npm create lumi-cms` and `pnpm create lumi-cms` resolve to the real scaffolder.
