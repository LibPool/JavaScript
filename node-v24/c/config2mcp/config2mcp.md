# config2mcp

> 标签: agent, claude, cli, cli2mcp, config, cursor, developer-tools, mcp, mcp-server, model-context-protocol, stdio, windsurf, wrapper, yaml

## 简介

Turn any CLI tool into an MCP server from one YAML config. Zero code, no shell injection, bounded execution. Runs bare (auto-discovers config) or with an explicit file.
