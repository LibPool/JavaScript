# cordova-plugin-keychain-touch-id-eg

> 标签: Biometric, Fingerprint, KeyChain, Scanner, Touch ID, TouchID, cordova-ios, ecosystem:cordova

## 简介

Scan the fingerprint of your user with the TouchID sensor (iPhone 5S, iPhone 6(S), ..) and control a key in the Keychain
