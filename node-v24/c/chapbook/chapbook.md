# chapbook

> 标签: accessibility, classless, css, dark-mode, design-system, monospace, no-dependencies, print-stylesheet, typography, wcag

## 简介

A small CSS system for documents that want to read like documents. Monospace carries structure, a second face carries language, and separation comes from rules and space rather than from cards. Nine rules, no dependencies, no build step.
