# caelus-birth

> 标签: astrology, birth-time, iana, natal-chart, timezone, tzdb

## 简介

Local birth time + place -> UT, correctly. IANA timezone resolution for caelus charts: DST, half-hour zones, ambiguous and nonexistent times.
