> 标签: ai, ai-client, ai-sdk, anthropic, chat-completion, chatgpt, claude, eio, function-calling, gpt, grok, json-schema, llm, llm-sdk, local-llm, melange, ocaml, openai, openrouter, streaming, structured-output, text-generation, typesafe, typescript, xai, zero-dependency

## 简介

OCaml-first SDK for LLM providers with a zero-dependency Melange-generated JavaScript package, streaming, structured outputs, and tool calling.
