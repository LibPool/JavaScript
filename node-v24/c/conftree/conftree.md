# conftree

> 标签: config, feature-flags, hierarchy, multi-tenant, settings

## 简介

Generic hierarchical configuration engine with arbitrary scopes, inheritance, caching, and audit. Zero required dependencies: works standalone or with any storage/pub-sub backend via simple ports.
