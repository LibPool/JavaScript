# chokugaki

> 标签: chokugaki, claude, codex, cursor, feedback, mcp, model-context-protocol, stdio

## 简介

chokugaki 用 stdio 型 MCP サーバー。AI コーディングエージェント(Cursor / Codex 等)からフィードバック管理 API を直接操作できる薄い HTTP クライアント。
