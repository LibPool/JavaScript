# concord-engine

> 标签: agent-orchestration, ai-agents, claude-code, codex, coding-agents, consistency, coordination, decision-log, multi-agent

## 简介

Scale parallelism. Preserve alignment. A fleet of coding agents builds one task in parallel against a spec contract, and a decision that contradicts one already in force is refused — deterministically, with no model in the decision path.
