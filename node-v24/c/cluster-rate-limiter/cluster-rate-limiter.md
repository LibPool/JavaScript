# cluster-rate-limiter

> 标签: api, cluster, concurrency, ipc, multiprocess, rate-limit, rate-limiter, rate-limiting, semaphore, sliding-window, throttle, worker

## 简介

A zero-dependency, ultra-fast Node.js cluster rate limiter utilizing IPC and a zero-allocation Float64Array ring buffer for high-throughput semaphore and sliding window limits.
