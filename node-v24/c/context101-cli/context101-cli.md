# context101-cli

> 标签: bedrock, cli, context101, knowledge-base, mcp, self-host

## 简介

Thin self-host CLI for Context101 (Amazon Bedrock Knowledge Bases). Bin: context101. Use `npx context101-cli` — unscoped `npx context101` is Context7's MCP.
