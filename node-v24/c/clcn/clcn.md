# clcn

> 标签: ansi, chalk, cli, colors, commonjs, esm, gradient, rainbow, terminal, truecolor

## 简介

A lightweight CLI coloring utility with support for ANSI, HEX, gradients, rainbow, and dual ESM/CJS support.
