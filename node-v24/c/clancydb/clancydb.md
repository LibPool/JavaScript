> 标签: aggregation, async-lock, database, embedded-database, file-based-db, fs-extra, joi, json-database, lightweight-db, local-db, lodash, mongodb-like, nodejs-database, nosql, schema-validation

## 简介

ClancyDB is a lightweight, file-based NoSQL database inspired by MongoDB. It provides an easy-to-use API for storing, querying, and managing JSON-based data.
