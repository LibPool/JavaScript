# consentloop

> 标签: ccpa, cmp, consent, consent-management, consent-management-platform, consent-mode-v2, consentloop, cookie-banner, cookie-consent, cookie-consent-banner, cookie-law, cookie-notice, cookies, dsgvo, gdpr, google-consent-mode, privacy, script-gating

## 简介

The fastest cookie consent banner for the web — a source-available CMP. Zero dependencies, zero layout shift, ~1.5 KB loader. Google Consent Mode v2, GDPR & CCPA presets, script & embed gating, per-service consent, 58 languages, headless mode.
