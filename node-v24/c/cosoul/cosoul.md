# cosoul

> 标签: JavaScript

## 简介

The MCP server that turns the TSX your own Claude or Codex writes into a live, data-backed internal app — validated, persisted, and rendered on real team records. Ground any app in a design system extracted from a URL. cosoul runs no LLM of its own.
