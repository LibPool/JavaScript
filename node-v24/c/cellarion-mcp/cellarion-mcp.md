# cellarion-mcp

> 标签: cellar, cellarion, claude, mcp, model-context-protocol, wine

## 简介

Connect your AI (Claude Desktop, Cursor, …) to your Cellarion wine cellar — a stdio MCP bridge to a Cellarion server.
