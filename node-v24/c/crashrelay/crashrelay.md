# crashrelay

> 标签: cli, crash-reporting, error-tracking, github-issues, jira, monitoring, ticketing

## 简介

Catch backend crashes, HTTP 5xx responses, and error-log lines (plus frontend JS errors via crashrelay-browser) and auto-file tickets in Jira or GitHub Issues.
