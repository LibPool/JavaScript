# cxhn-assets-cache

> 标签: assets, cache, cache-api, offline, prefetch, preload, pwa, service-worker

## 简介

前端静态资源预加载与缓存工具包：基于 Service Worker + Cache API 透明拦截，支持预加载进度、超时跳过、成功/失败计数与缓存清理策略。
