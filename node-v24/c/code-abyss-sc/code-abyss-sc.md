# code-abyss-sc

> 标签: ai, assistant, claude, claude-code, cli, codex, configuration

## 简介

为 Claude Code / Codex CLI / Gemini CLI / OpenClaw 注入可切换人格、主动执行导向、6种输出风格与30个工程技能（含自我进化炼炉）。代码图谱由独立的 abyss Rust CLI 提供（github.com/telagod/abyss）
