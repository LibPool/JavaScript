# chronoverify-mcp

> 标签: c2pa, exif, forensics, image, mcp, model-context-protocol, modelcontextprotocol, osint, provenance, verification

## 简介

MCP server for ChronoVerify: verify a photo's capture time and provenance (C2PA, EXIF, pixel forensics) and fetch a signed, RFC 3161 timestamped audit report, from any MCP-compatible AI agent.
