# compose-healthcheck-lint

> 标签: ci, devops, docker, docker-compose, healthcheck, lint

## 简介

CLI that scans a docker-compose file and reports which services have no healthcheck, and which depends_on entries don't actually wait for health.

## 官网

- npm 页面：https://www.npmjs.com/package/compose-healthcheck-lint

- 1.0.0

## 获取地址

- npm 安装：`npm install compose-healthcheck-lint`
- npm registry：https://registry.npmjs.org/compose-healthcheck-lint
- Node 要求：>=14
