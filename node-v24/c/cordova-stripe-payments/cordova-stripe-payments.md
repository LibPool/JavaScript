# cordova-stripe-payments

> 标签: ach, apple pay, cards, checkout, cordova, cordova-android, cordova-ios, credit cards, ecosystem:cordova, google pay, payments, stripe

## 简介

Cordova plugin for Stripe payments using the native Android/iOS SDKs. Supports Apple Pay and card payments.
