# clark-platform-client-js

> 标签: clark, clark-platform, openai-compatible, sse, streaming

## 简介

Zero-build-step, plain-JavaScript client for the Clark Platform API (OpenAI-compatible-ish, with extras). Native ESM, no compile step required to consume.
