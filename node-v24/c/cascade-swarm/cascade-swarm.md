# cascade-swarm

> 标签: agents, cascade, claude-code, codex, coding-agents, coordination, git-worktree, parallel, swarm

## 简介

Point a swarm of your own coding agents (Claude Code or Codex CLI) at a goal. Workers in separate git worktrees, coordinated through Cascade, stopping when your check passes.
