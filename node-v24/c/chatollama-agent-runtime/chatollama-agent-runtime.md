# chatollama-agent-runtime

> 标签: JavaScript

## 简介

`chatollama-agent-runtime` is the standalone Runtime package for ChatOllama. It uses Vercel AI SDK internally and exposes ChatOllama-owned messages, snapshots, and process-local events.
