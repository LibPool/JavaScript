# crossframejs

> 标签: communication, cross-window, crossframejs, iframe, messaging, plugin-system, postmessage, secure, typescript

## 简介

A lightweight, type-safe, extensible library for secure iframe communication using postMessage — with channels, plugins, and handshake support.
