# connections-mcp

> 标签: JavaScript

## 简介

Connections Local MCP - a thin SELF-UPDATING loader that fetches its implementation from AWS at launch (push fixes to AWS, never re-publish). Local-execution companion (shell/git/files/ssh/browser) + browser sign-in for the remote Connections (Studio) MCP
