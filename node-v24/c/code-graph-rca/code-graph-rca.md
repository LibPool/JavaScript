# code-graph-rca

> 标签: ai-agent, call-graph, claude-code, code-graph, cursor, knowledge-graph, mcp, model-context-protocol, python, rca, root-cause-analysis, static-analysis, tree-sitter, typescript

## 简介

RCA infrastructure for AI-built code. Code knowledge graph + opinionated RCA engine, exposed via MCP (Cursor / Claude Code / Cody / Cline / Continue / Windsurf / Zed) plus CLI and library. RCA is the wedge; the same engine covers code review, refactor bla
