# catjs-irt

> 标签: 4pl, adaptive-testing, cat, catr, computerized-adaptive-testing, irt, item-response-theory, psychology, psychometrics

## 简介

Computerized adaptive testing in JavaScript — a faithful port of the R catR package: 4PL item response function, MFI/bOpt item selection, and EAP/BM/ML/WL ability estimation with standard errors.
