# cordova-plugin-app-privacy

> 标签: android, cordova, cordova-android, cordova-ios, ecosystem:cordova, ios, plugin, privacy, screenshots

## 简介

Cordova plugin to enable/disable privacy mode (block screenshots, hide content when minimized) on Android and iOS.
