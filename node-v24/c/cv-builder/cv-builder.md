# cv-builder

> 标签: cv, cv-builder, pdf, print, puppeteer

## 简介

Narzędzie do generowania profesjonalnych CV w formacie PDF. Personalizuj treść, dodaj zdjęcie i generuj interaktywne dokumenty PDF z aktywnymi linkami.
