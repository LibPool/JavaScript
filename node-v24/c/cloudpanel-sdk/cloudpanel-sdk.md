# cloudpanel-sdk

> 标签: cloudpanel, cloudpanel-cli, clpctl, hosting, nodejs-sdk, server-management, ssh, vps

## 简介

Node.js SDK for managing CloudPanel via SSH — wraps all clpctl CLI commands into a clean, promise-based API.
