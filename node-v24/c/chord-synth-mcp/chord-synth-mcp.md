# chord-synth-mcp

> 标签: ai-tools, audio, chord, mcp, model-context-protocol, music, synthesizer, wav

## 简介

Generate chord progression WAV files via MCP. 28 presets, 22 arp patterns, 7 instruments, slash chords, transposition.
