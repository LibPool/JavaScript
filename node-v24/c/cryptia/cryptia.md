# cryptia

> 标签: cipher, cryptiaJS, cryptography, data-encryption, data-security, decryption, encryption, javascript-encryption, npm-package, open-source, secure, secure-data, secure-text, string-decryption, string-encryption, substitution-cipher, text-decryption, text-encryption

## 简介

Cryptia is a simple JavaScript library for encrypting and decrypting text using a basic substitution cipher. It provides an easy-to-use interface for securing text data in client-side applications..
