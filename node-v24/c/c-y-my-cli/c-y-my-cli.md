# c-y-my-cli

> 标签: JavaScript

## 简介

1、使用到的第三方库 - 命令行参数获取：commander - 命令行接口配置：inquirer - 加载动画：ora - git仓库项目下载：download-git-repo 2、开发步骤 - 获取版本号 - 创建create命令 - 配置命令行接口 - 从git仓库或本地获取代码模版 - 在package.json中配置bin可执行文件 - 通过npm link 创建bin命令的软链接，挂载到全局 -
