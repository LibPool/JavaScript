# chunk-lite

> 标签: chunking, embeddings, llm, rag, text-chunking, tokenizer, typescript

## 简介

Token-aware text chunking for RAG pipelines — configurable overlap, sentence/paragraph-boundary awareness, and a pluggable tokenizer.
