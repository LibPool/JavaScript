# calamine

> 标签: calamine, excel, ods, spreadsheet, wasm, xls, xlsb, xlsx

## 简介

Fast xlsx/xls/xlsb/ods reader — calamine compiled to WebAssembly. One artifact for Node, Bun, Deno, browsers and edge workers.
