# cordova-mms-plugin

> 标签: cordova, cordova-android, cordova-ios, cordova-windows, cordova-wp8, ecosystem:cordova, phonegap, sms

## 简介

Cross-platform plugin for Cordova / PhoneGap to to easily send MMS. Available for Android and iOS.
