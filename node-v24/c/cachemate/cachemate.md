# cachemate

> 标签: cache, cache-invalidation, caching, listen-notify, pg-listen, postgres, postgresql, query-cache, redis, typescript

## 简介

Redis-backed caching for Postgres: join/flat/row caching with automatic invalidation via LISTEN/NOTIFY.
