# common-player

> 标签: flv, h264, h265, http-flv, jessibuca, video, video-player, vue, ws-flv, 播放器, 流媒体

## 简介

基于 Jessibuca 的 Vue2 视频播放组件，支持 H265/H264 编码的 WebSocket-FLV、HTTP-FLV 等流媒体播放。安装即用，无需额外配置。
