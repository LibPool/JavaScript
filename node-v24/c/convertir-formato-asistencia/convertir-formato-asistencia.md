# convertir-formato-asistencia

> 标签: asistencia, conversión, excel, herramienta, nodejs, reporte, xls, xlsx

## 简介

Herramienta Node.js para convertir registros de asistencia (XLS/XLSX) a un reporte de Excel legible, agrupando por usuario y marcando ausencias.
