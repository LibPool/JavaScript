# cna-template-material-tailwindcss-reduxtoolkit

> 标签: cna-template, create-next-app, eslint, next, prettier, react-redux, redux-toolkit, template

## 简介

A quick start Create Next App template with material-ui, tailwindcss, redux-toolkit, eslint-configuration, prettiter-configuration, hoc for protected route, axios configuration, context api for user authentication, react-testing-library
