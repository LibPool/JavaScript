# cordova-plugin-ml-barcode-scanner

> 标签: android, barcode, cordova, cordova-android, cordova-ios, ean, ecosystem:cordova, image, ios, qrcode

## 简介

An Cordova plugin for iOS and Android that allows to open a barcode scanner. For the detection the plugin uses Googles MLKit.
