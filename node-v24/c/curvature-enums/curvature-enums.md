# curvature-enums

> 标签: JavaScript

## 简介

1. 按照模块分类 2. 统一通过src/index.js 对外提供 3. 更新代码后，需要到gitlab上添加一个新的唯一的tag，如1.2.1 4. 使用时需要带上tag标记，注意：只更新代码，不更新tag会导致代码不能被正确安装
