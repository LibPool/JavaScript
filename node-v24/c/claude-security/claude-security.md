# claude-security

> 标签: agent, anthropic, claude, code-review, sarif, sast, security, static-analysis, vulnerability

## 简介

Claude-powered security scanning: CLI and TypeScript SDK that drives the Claude Agent SDK through bundled scan skills and seals results into a verifiable scan contract (JSON, SARIF, Markdown).
