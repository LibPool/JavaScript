# chatarea

> 标签: @功能, @提及, React, Vue, ai, ai输入框, chat, mention, mentions, sender, 聊天框

## 简介

纯JS封装的聊天框，交互功能对标豆包、钉钉、微信聊天框，适用于JQuery/React/Vue等各大框架，兼容PC与H5的使用
