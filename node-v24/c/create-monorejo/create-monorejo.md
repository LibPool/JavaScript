# create-monorejo

> 标签: drizzle, monorepo, nestjs, nextjs, pnpm, supabase, turborepo

## 简介

A CLI tool to scaffold a TypeScript monorepo with Turborepo, Supabase, Drizzle, Next.js, and NestJS.
