# create-indiepub

> 标签: astro, create, indiepub, indieweb

## 简介

Scaffold a new [IndiePub](https://indiepub.dev) site in seconds. Clones an official theme from Codeberg, wires up your config, and gets you ready to deploy on Cloudflare.
