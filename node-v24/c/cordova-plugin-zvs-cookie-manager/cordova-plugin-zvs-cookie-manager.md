# cordova-plugin-zvs-cookie-manager

> 标签: cordova-android, ecosystem:cordova

## 简介

This plugin exposes the CookieManager object (android) to cordova applications - specifically enabling one to allow third-party cookies within your app. This is in response to android API 21+ changes to cookie management
