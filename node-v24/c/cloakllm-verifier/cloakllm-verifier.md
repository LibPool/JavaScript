# cloakllm-verifier

> 标签: audit, cloakllm, compliance, eu-ai-act, rfc3161, verification

## 简介

Independently verify CloakLLM audit artifacts (hash chain, RFC 3161 timestamps, KeyManifest provenance, compliance reports) without the PII-detection stack or trusting CloakLLM's code.
