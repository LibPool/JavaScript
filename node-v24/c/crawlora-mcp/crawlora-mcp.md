# crawlora-mcp

> 标签: crawlora, data-extraction, mcp, model-context-protocol, serp, web-scraping

## 简介

Local MCP server for Crawlora — 2221 structured public web-data tools across 260 platform groups (search, maps, commerce, social, finance) wrapping the Crawlora REST API.
