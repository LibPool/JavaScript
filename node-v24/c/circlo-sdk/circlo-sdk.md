# circlo-sdk

> 标签: celo, circlo, defi, ethereum, prediction-market, sdk, viem, web3

## 简介

High-level TypeScript SDK for Circlo — a social prediction game on Celo Mainnet. Wraps viem with ergonomic helpers for creating circles, staking on goals, and listening to onchain events.
