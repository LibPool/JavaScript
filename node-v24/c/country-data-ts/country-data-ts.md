# country-data-ts

> 标签: address, administrative-divisions, calling-code, countries, country, e164, geonames, iso-3166, phone, postal-code, telephone, typescript

## 简介

Zero-dependency, tree-shakeable worldwide country, address and phone reference data for TypeScript (ISO 3166 countries, administrative divisions, postal-code patterns, calling codes and phone masks)
