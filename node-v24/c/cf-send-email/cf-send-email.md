# cf-send-email

> 标签: cf-send-email, cloudflare, cloudflare-email, cloudflare-email-service, cloudflare-workers, edge, email, email-sending, email-template, email-verification, hono, html-email, inline-css, magic-link, otp, password-reset, plain-text-email, send-email, send_email, serverless, transactional-email, typescript, verification-code, workers, wrangler, zero-dependency

## 简介

Send transactional emails from Cloudflare Workers via the send_email binding (Cloudflare Email Service), with a zero-dependency renderer for email-client-safe inline-styled HTML and plain-text bodies (password reset, OTP, verification, invites).
