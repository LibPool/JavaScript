# clipradar-mcp

> 标签: claude, clipping, clipradar, creator-economy, mcp, model-context-protocol, modelcontextprotocol

## 简介

MCP server for ClipRadar — live pay-per-view clipping campaigns (payout rates, budgets, categories, viral scores) as tools for Claude, Cursor and any MCP client.
