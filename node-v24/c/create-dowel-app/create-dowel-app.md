# create-dowel-app

> 标签: ai, components, create, design-system, dowel, next, nextjs, react, saas, scaffold, starter, tailwind, template, ui

## 简介

Creates a Next.js application wired to Dowel: design tokens, path aliases and the blocks for the kind of product you are building, installed as source you own.
