# cls-mcp-usage-proxy

> 标签: audit, cls, cursor, mcp, proxy, tencent

## 简介

CLS MCP 使用情况审计代理：透传官方 cls-mcp-server，旁路记录每次 tools/call 的入参、返回、耗时，落盘本地 NDJSON 供使用情况统计。
