# cam-fe-code-generator

> 标签: api management, cam, codegen, typescript

## 简介

`cam-fe-code-generator` 是 CAM 的 npm CLI。它从 CAM 后端拉取指定 Service 的 API 定义与参数结构，生成 TypeScript 类型、可注入请求实现的 Service Class，以及 axios/fetch 使用示例。
