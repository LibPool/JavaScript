# celtic-knot-maker

> 标签: book-of-kells, celtic-art, celtic-knot, celtic-knot-maker, esoterica, generator, george-bain, interlace, javascript, knotwork, mirror-curves, pwa, sacred-geometry, svg

## 简介

Celtic Knot Maker: draw breaks on a grid and the Celtic knotwork weaves itself, over and under, using George Bain's method. Color the strands and download the knot as SVG or PNG.
