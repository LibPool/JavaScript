# clawlego

> 标签: JavaScript

## 简介

ClawLego AgentOS master — declarative lifecycle management for digital-employee agent instances (K8s-style: apiserver + controllers + clawdash in one binary). Postinstall pulls the platform binary from download.clawlego.com and verifies its sha256.
