# card-bin-db

> 标签: amex, bank-card, bank-identification-number, bin, card-brand, card-info, card-lookup, credit-card, debit-card, discover, issuer, mastercard, payment-card, visa

## 简介

A fast and lightweight library for querying bank card information (issuer, brand, type, country) based on BIN (Bank Identification Number).
