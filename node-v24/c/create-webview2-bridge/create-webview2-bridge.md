# create-webview2-bridge

> 标签: create, react, scaffold, vb.net, vite, webview2, winforms

## 简介

Scaffold a WinForms (VB.NET / .NET Framework 4.8) + WebView2 + Vite/React app wired with webview2-bridge: `pnpm create webview2-bridge my-app`
