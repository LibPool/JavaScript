# cancancan-ts

> 标签: ability, access-control, access-control-list, acl, authorization, cancancan, permissions, policy, rbac, role-based-access-control, rules-engine, security, typescript

## 简介

Lightweight and extensible authorization engine for TypeScript inspired by CanCanCan. Define flexible permissions using actions, subjects, and conditions.
