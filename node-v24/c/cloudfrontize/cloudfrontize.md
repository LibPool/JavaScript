# cloudfrontize

> 标签: aws, brotli, cloudfront, compression, emulator, lambda-at-edge, local-development, static-server

## 简介

High-performance, high-fidelity local emulator for AWS Lambda@Edge and CloudFront Functions. Validate edge logic, catch illegal header mutations, and execute production-grade runtimes on a specialized local static server.
