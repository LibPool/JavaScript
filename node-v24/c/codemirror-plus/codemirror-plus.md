# codemirror-plus

> 标签: CodeMirror, Editor, Javascript, addon

## 简介

A collection of add-ons for CodeMirror that can be used individually. Furthermore, addon/builder helps to build feature-rich pre-packaged CodeMirror instance that use many of the addons here and from official distribution. See demo/builder_with_requirejs.
