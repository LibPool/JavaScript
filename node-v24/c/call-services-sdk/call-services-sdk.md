# call-services-sdk

> 标签: JavaScript

## 简介

Call Services là một thư viện javascript cho trình duyệt, có nhiệm vụ thực hiện cuộc gọi video hoặc audio qua mạng ngang hàng p2p. Sử dụng công nghệ WebRTC
