# cypress-debugger

> 标签: currents, cypress, cypress-debugger, cypress-replay, cypress-traces, e2e, replay, sorry-cypress, time-travel

## 简介

Capture and replay Cypress Tests. Debug your failed and flaky CI cypress tests by replaying execution traces.
