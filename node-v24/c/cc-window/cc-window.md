# cc-window

> 标签: anthropic, claude, claude-code, cli, dashboard, monitoring, sessions, terminal, tmux, xterm

## 简介

Local web dashboard for Claude Code: monitor every session, spawn new ones, and drive each interactive terminal — all in one page (127.0.0.1 only).
