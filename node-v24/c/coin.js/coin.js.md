# coin.js

> 标签: commerce, crypto, ethereum, hanzo, payments, stablecoin, usdc, viem, wallet, web3

## 简介

Drop-in crypto payments for Hanzo — accept stablecoins and native coins, composing commerce.js (api.hanzo.ai) for deposits/credits and viem for the wallet.
