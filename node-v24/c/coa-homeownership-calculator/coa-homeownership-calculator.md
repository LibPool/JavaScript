# coa-homeownership-calculator

> 标签: JavaScript

## 简介

A homeownership calculator built to integrate with the City of Asheville website (local government). Written in React, it assumes Bootstrap 4 CSS exists in the host site.

- 官网：https://github.com/cityofasheville/housing-calculator#readme
