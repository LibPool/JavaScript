# candid-to-zod

> 标签: ast, candid, dfinity, did, icp, internet computer, motoko, schema, typescript, validation, zod

## 简介

Convert Internet Computer Candid files (.did.js, .did.ts) into runtime-safe TypeScript Zod validation schemas.
