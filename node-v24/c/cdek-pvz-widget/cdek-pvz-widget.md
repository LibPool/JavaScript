# cdek-pvz-widget

> 标签: cdek, checkout, delivery, pickup-point, pvz, widget, yandex-maps, пвз, сдэк

## 简介

Lightweight CDEK pickup-point (PVZ) picker with server-side city filtering. Loads offices for a single city (~1MB) instead of the whole world (~19MB). Drop-in compatible with @cdek-it/widget (window.CDEKWidget).
