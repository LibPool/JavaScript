# cordova-plugin-pvt-uniquedeviceid

> 标签: Windows, android, cordova, device, id, ios, phone, phonegap, unique, uuid, wp

## 简介

PhoneGap / Cordova unique device id (UUID) plugin for Android, iOS and Windows Phone 8. Remains the same after app uninstall.

- npm 页面：https://www.npmjs.com/package/cordova-plugin-pvt-uniquedeviceid

- npm registry：https://registry.npmjs.org/cordova-plugin-pvt-uniquedeviceid
