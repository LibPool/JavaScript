# cyf-improt-excal

> 标签: JavaScript

## 简介

```vue import Excal from 'cyf-improt-excal' const excal = new Excal() excal.importCsv(tableData, tit, 'key','文件名称')//第一个参数为表格数据 第二个数据为表头 第三个数据为表头的key 如果表头就是一个数组则不需要key 则按照顺序渲染 excal.importXml('#id','导出')//第一个参数为导出的dom名字 第二个为导出文件名 目前这个有点问题主要是导出后没有表格线！！
