# chat-source

> 标签: chat, chatbot, eventsub, irc, kick, live-chat, overlay, pusher, stream, streamer, streaming, twitch, typescript, webhook, youtube

## 简介

One typed event stream over Twitch, Kick and YouTube live chat: anonymous public reading and authenticated broadcaster reading, with reconnection, channel verification and a replay test kit.
