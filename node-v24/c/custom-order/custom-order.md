# custom-order

> 标签: JavaScript

## 简介

自定义指令  tap tap点击事件  focus 聚焦  swipe swiper滑动事件  swiperleft swiper左滑事件  swiperright swiper右滑事件  swiperdown swiper下滑事件  swiperup swiper上滑事件  longtap 长按事件  drap 拖拽事件（h5）  pdrag 拖拽事件（pc）
