# clawprint

> 标签: agent-security, ai-agents, capability-manifest, claude-code, diff, manifest, mcp, skills, supply-chain

## 简介

The capability manifest for your agent config (.claude/, .cursor/, AGENTS.md, .mcp.json ...). Know exactly what your agent setup can do, and catch every change in PR review. Deterministic, zero-dependency, no AI, no verdicts.
