# code-measure

> 标签: cargo-mutants, cobertura, complexity, coverage, duplication, hotspots, infection, jacoco, junit, lcov, mutation-testing, pitest, refactoring, stryker

## 简介

Measure a codebase in any language before and after a refactoring: duplication, complexity, hotspots, test results, line and branch coverage, and mutation score, as one JSON summary.
