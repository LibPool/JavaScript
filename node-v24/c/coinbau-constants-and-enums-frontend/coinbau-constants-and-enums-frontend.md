# coinbau-constants-and-enums-frontend

> 标签: JavaScript

## 简介

1. run npm install 2. add new file, same like contract.js and     write typescript enums in it 3. npm run build 4. npm publish 5. for usage in projects: import { nameOfSpecificEnum }    from 'coinbau-constants-and-enums-frontend/dist/fileName.js'
