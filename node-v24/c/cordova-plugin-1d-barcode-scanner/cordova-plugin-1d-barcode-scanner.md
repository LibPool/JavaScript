# cordova-plugin-1d-barcode-scanner

> 标签: avfoundation, barcode, barcode-scanner, codabar, code128, code39, cordova, cordova-android, cordova-ios, ean, ean13, ecosystem:cordova, itf, mlkit, scanner, upc

## 简介

Cordova plugin to scan 1D linear barcodes (EAN, UPC, Code 128, Code 39, Code 93, ITF, Codabar) on iOS and Android. QR codes and other 2D codes are intentionally NOT scanned.
