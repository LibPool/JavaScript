# claude-code-auth

> 标签: anthropic, auth, claude, claude-code, oauth, opencode, provider, subscription

## 简介

Claude Code subscription auth provider for OpenCode and Claude Code, multiple Claude accounts via OAuth, with subscription rate limits exposed to OpenCode.
