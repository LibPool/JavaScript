# crashbox

> 标签: black box, breadcrumbs, crash recovery, crash reporting, error recovery, ios, local-first, oom, out-of-memory, safari, tab crash, wasm, webassembly, webgpu

## 简介

Local-first crash black box for the browser: survives hard tab kills (WebGPU, WASM, OOM) and surfaces the recovered state on next load.
