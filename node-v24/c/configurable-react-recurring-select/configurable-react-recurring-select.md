# configurable-react-recurring-select

> 标签: boilerplate, edit, hmr, hot, live, react, reactjs, reload, webpack

## 简介

React component which makes creating ice_cube recurrence schedules easy.  This fork of the original allows more control over every element and every i18n translation.  It supports react 16.14 but moment must be a global variable in your project.
