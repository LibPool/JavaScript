# china-optipng-bin

> 标签: compress, image, imagemin, img, minify, optimize, optipng, png

## 简介

OptiPNG wrapper that makes it seamlessly available as a local dependency, 同步官方代码，解决国内下载jpegtran-bin,optipng-bin依赖的源码慢的问题
