# console-for-proxy

> 标签: console, proxy, vue

## 简介

Vue3.0 之后，生命的 ref 对象、数组都是经过代理的，那如果使用 console.log 输出的为代理后的对象，不利于在控制台查看。所以本仓库修改原始
