# common-list

> 标签: tablelist, vue3

## 简介

用于快速搭建CRUD的前端应用, 目前已实现网络的增删改查的请求封装，实现表格数据的筛选，查找，分页等常用功能，使用该组件可以快速开发出业务系统的常用功能界面。
