# claude-bridge-mcp

> 标签: chrome-extension, claude, claude-code, devtools, mcp, model-context-protocol, react

## 简介

MCP server that connects the Claude Bridge Chrome extension to Claude Code — click any UI element and get its React component, source file, props, and styles as context
