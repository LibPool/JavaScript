# chokidar-webextensions

> 标签: file, fs, fsevents, watch, watchFile, watcher, watching

## 简介

Chokidar - A neat wrapper around node.js fs.watch / fs.watchFile / fsevents. This fork of Chokidar library has some changes related to awaitWriteFinish.
