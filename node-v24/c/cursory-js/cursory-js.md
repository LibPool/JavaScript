# cursory-js

> 标签: anti-bot, bezier, browser-automation, cursor, cursory, human-like, mouse, mouse-movement, playwright, puppeteer, scraping, trajectory

## 简介

Mouse Trajectory Factory. Generate 100% human-realistic mouse trajectories with timings. A TypeScript port of Vinyzu's cursory.
