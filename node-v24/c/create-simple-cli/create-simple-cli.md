# create-simple-cli

> 标签: JavaScript

## 简介

脚手架使用 webpack5 构建,不支持 node10 以下版本，内置typescript, antd ui 库和 axios，不带数据管理三方插件，可根据需要自己安装

## 官网

- npm 页面：https://www.npmjs.com/package/create-simple-cli
