# contextwall

> 标签: ai-safety, api-keys, langchain, llm, openai, pii, prompt, redaction, sanitizer, secrets, vercel-ai

## 简介

Local-only sanitizer for LLM prompts. Detects API keys, PII, secrets, and credentials and replaces them with safe placeholders, semantic fakes, or reversible tokens.
