# cmd-git-copilot-tools

> 标签: agents, ai, automation, cli, command-line, copilot, developer-tools, github, github-copilot, instructions, prompts, skills, workflows

## 简介

Browse and download agents, cookbook, hooks, instructions, plugins, prompts, skills, and workflows from GitHub repositories with Copilot custom tools. Command-line tool port of the original VS Code extension.
