# cmux-claude-queue

> 标签: claude, claude-code, cli, cmux, developer-tools, macos, prompt-queue, queue, terminal

## 简介

Queue your next prompt for Claude Code with one keypress, delivered as a fresh turn only after the current one actually ends. macOS + cmux.
