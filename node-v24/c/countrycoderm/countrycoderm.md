# countrycoderm

> 标签: ISO 3166, RM, code, country, country code, country lookup, dialing code, international, iso, mobile code, phone code, telephone, world

## 简介

CountryCodeRM is a versatile npm package that allows users to retrieve country names from country codes and vice versa. Whether you're looking to convert India -> +91 or +91 -> India, this package provides a simple and efficient way to handle country code
