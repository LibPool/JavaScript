# codepass

> 标签: ai, aider, amp, claude-code, cli, codex, coding-agent, cursor, cursor-agent, factory-droid, github-copilot, goose, grok, grok-build, harness, pty, terminal, xai

## 简介

Interactive terminal harness that switches between coding agents (Claude Code, Codex, Antigravity, opencode, Grok Build, Cursor Agent, Aider, Goose, Amp, Factory Droid, GitHub Copilot CLI, Cline) and carries a shared handoff file so you never lose context
