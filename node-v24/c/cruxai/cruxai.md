# cruxai

> 标签: ai, analytics, claude, cli, codex, crux, harness, opencode, productivity

## 简介

Analyze your AI coding assistant usage across Claude, Codex, OpenCode, and more — a local-first CLI that turns your session logs into an offline dashboard and terminal reports. Read-only, zero telemetry.
