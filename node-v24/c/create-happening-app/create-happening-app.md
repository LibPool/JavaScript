# create-happening-app

> 标签: claude-code, create-app, jotai, nextjs, react-query, starter, template

## 简介

Scaffold a new frontend project on Happening's standard Next.js architecture — layered folders, a typed fetch client, React Query + Jotai wiring, and a CLAUDE.md so AI agents follow the same rules as the team.
