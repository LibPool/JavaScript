# chtty-cli

> 标签: JavaScript

## 简介

- 第三方库   inquirer ：交互式命令行工具，有他就可以实现命令行的选择功能   download-git-repo ：在 git 中下载模板   chalk ：粉笔帮我们在控制台中画出各种各样的颜色   metalsmith ：读取所有文件,实现模板渲染   consolidate ：统一模板引擎
