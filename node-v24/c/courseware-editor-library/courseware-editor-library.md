# courseware-editor-library

> 标签: JavaScript

## 简介

交互游戏编辑器通用组件库。适用于交互游戏编辑器的通用组件，包括 Button 、Input、Cropper（图片裁剪）、FormHeader（表头）、FormItem（表格）、UploadAudio（音频上传）、UploadImg（图片上传）。
