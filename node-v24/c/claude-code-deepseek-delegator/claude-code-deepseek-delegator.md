# claude-code-deepseek-delegator

> 标签: ai-agent, anthropic, claude, claude-code, cli, cost-savings, deepseek, delegation, glm, grok, groq, kimi, llm, llm-router, mcp, mcp-server, model-agnostic, model-context-protocol, moonshot, ollama, openai-compatible, openrouter, orchestration, providers, qwen, subagent, token-optimization, token-savings, zhipu

## 简介

MCP server that lets Claude Code delegate heavy-token tasks to DeepSeek, Kimi, GLM, Qwen, Grok, or any OpenAI-compatible model. Claude orchestrates; the delegate does the heavy lifting. Zero dependencies.
