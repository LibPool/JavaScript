# castela-collector

> 标签: activity, claude, claude-code, events, gamification, websocket

## 简介

Open-source collector that turns your Claude Code activity into a live event stream any game can build on. Watches your local sessions, broadcasts neutral activity events over localhost. Never sends prompts, file paths, or code anywhere.
