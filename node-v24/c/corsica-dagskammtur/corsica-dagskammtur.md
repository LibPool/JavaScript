# corsica-dagskammtur

> 标签: JavaScript

## 简介

A [corsica](https://github.com/mozilla/corsica) plugin to display current weeks menu items in corsica. Utilizes [node-dagskammtur](https://github.com/stebbib/node-dagskammtur) to get the data to display.
