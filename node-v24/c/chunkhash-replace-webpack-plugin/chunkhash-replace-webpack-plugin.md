# chunkhash-replace-webpack-plugin

> 标签: chunkhash, webpack chunkhash, webpack chunkhash replace, webpack replace script reference

## 简介

Webpack plugin for transforming js bundle references in your html files with cache friendly filenames using chunkhashes.
