# chronos-bridge

> 标签: calendar, conversion, hebrew, islamic, jdn, persian

## 简介

A high-precision calendar conversion engine using Julian Day Number (JDN) as a universal bridge for Gregorian, Hebrew, Islamic, and Persian systems.
