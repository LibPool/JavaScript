# create2app

> 标签: JavaScript

## 简介

- 初版（仅学习用）     - 本脚本是根据matriks2重写的一个快速生成脚手架的小工具     - 本工具在matriks2的基础上加了：         - 持久化本地的remote仓库         - 新增theme选择         - 支持本目录生成脚手架
