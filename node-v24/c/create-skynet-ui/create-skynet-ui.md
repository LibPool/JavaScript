# create-skynet-ui

> 标签: create, css, llm, no-build, scaffold, skynet-ui, ui

## 简介

Scaffold a Skynet UI page in seconds: npm create skynet-ui — landing, dashboard, chat, or auth template in any of 9 themes, zero build steps.
