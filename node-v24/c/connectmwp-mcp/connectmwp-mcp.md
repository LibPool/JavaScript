# connectmwp-mcp

> 标签: ai, claude, claude-desktop, connectmwp, cursor, ed25519, mcp, model-context-protocol, wordpress

## 简介

Local MCP client for connectMWP — connects AI clients (Claude Desktop, Claude Code, Cursor) directly to self-hosted WordPress sites using session-less Ed25519 signature auth.
