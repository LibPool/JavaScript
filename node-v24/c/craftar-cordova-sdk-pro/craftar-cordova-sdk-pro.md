# craftar-cordova-sdk-pro

> 标签: cordova, cordova-android, cordova-ios

## 简介

This plugin is a wrapper for using the CraftAR Pro SDK in the CraftAR cordova plugin. This project is not intended to be used directly. Visit http://catchoom.com/documentation/cordova
