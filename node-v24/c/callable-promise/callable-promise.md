# callable-promise

> 标签: async, async-utils, await, callable, callable-promise, defer, deferred, promise, promise-utils, resolvable, resolve, ts, typescript, utility

## 简介

A tiny TypeScript utility for creating promises that can be resolved by calling them like a function.
