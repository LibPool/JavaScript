# chunkwise

> 标签: browser, chunked, file-upload, minio, multipart, presigned, r2, resumable, s3, upload, uploader, zero-dependency

## 简介

Resumable multipart uploads for S3-compatible storage. Parallel parts, server-truth resume, integrity-checked. Zero dependencies, browser and Node.
