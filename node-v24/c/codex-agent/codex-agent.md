# codex-agent

> 标签: JavaScript

## 简介

> Codex Agent 是对 OpenAI Codex CLI 的“守护与编排层”，补齐持续任务调度、异常自愈与多渠道通知能力，让 `codex exec --json` 可以安全地长时间运行并在断连后自动恢复。
