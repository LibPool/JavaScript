# contractinstance

> 标签: "blockchain", "contract-api", "dapp", "ethers", "proxy", "smart-contract", "solidity", "web3"

## 简介

A lightweight JavaScript library that allows seamless interaction with smart contract APIs using a dynamic proxy. Supports easy contract function calls with automatic wallet authentication.
