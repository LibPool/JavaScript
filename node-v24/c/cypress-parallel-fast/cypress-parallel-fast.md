# cypress-parallel-fast

> 标签: ci, cypress, cypress-parallel, grep, parallel, speed, test-splitting

## 简介

Parallelize Cypress test cases within and across spec files using a dynamic task queue — faster than file-level splitting because individual it() blocks are distributed across workers.
