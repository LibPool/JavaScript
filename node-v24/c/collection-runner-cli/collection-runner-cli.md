# collection-runner-cli

> 标签: api-testing, automation, cli, collection-runner, enterprise, html-reports, newman, notifications, postman, report-generator, secure, telegram, testing

## 简介

CLI tool to run Postman collections with Newman, generate beautiful HTML reports with interactive charts, and send Telegram/Slack/Discord notifications. Zero unsafe native dependencies. Interactive first-run setup wizard included.
