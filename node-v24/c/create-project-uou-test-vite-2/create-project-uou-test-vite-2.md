# create-project-uou-test-vite-2

> 标签: JavaScript

## 简介

KickstartJS é uma ferramenta de linha de comando simples, projetada para agilizar a criação de novos projetos usando Vite ou Next.js. Esta ferramenta automatiza o processo de configuração criando um novo projeto com os comandos oficiais do Vite e do Next.
