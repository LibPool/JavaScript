# c64rdy

> 标签: c64, commodore, d64, datasette, emulator, tap, tape

## 简介

Command-line tool for Commodore 64 tapes and disks — turn cassette recordings into .tap files, list what a tape or disk holds, mend damage, build disk images, and boot programs headless
