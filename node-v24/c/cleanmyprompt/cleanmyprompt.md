> 标签: ai firewall, ai safety, api key scanner, ci, copilot, copilot security, credential scanner, data protection, gdpr, git hooks, github actions, hipaa, llm, openai, pii, pre-commit, prompt security, redact, sarif, secret scanner, secrets, security, token compression, token reduction

## 简介

Scan, redact, and squeeze code before it reaches an LLM. Blocks API keys, secrets, and PII in real time. Cuts token costs 30–70% with smart compression. Git hooks, CI/CD, SARIF, watch mode. Free for personal use — commercial license for teams.
