# capacitor-auth-manager

> 标签: angular, authentication, capacitor, capacitor-plugin, google-sign-in, id-token, oauth, react, vue

## 简介

Capacitor + web authentication. Firebase-agnostic native & web Google sign-in (idToken/accessToken) for React, Vue, Angular and vanilla JS — a drop-in alternative to @codetrix-studio/capacitor-google-auth. More providers shipping one at a time.
