# context1000

> 标签: adr, ai, ai-tools, architecture-decision-records, chromadb, claude, cli, code-review, developer-tools, document-processing, documentation, documentation-format, documentation-tools, knowledge-base, mcp, model-context-protocol, rag, retrieval-augmented-generation, rfc, vector-search

## 简介

**context1000** is a documentation format for software systems, designed for integration with artificial intelligence tools. The key artifacts are ADRs and RFCs, enriched with formalized links between documents.
