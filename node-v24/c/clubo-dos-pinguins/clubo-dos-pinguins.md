# clubo-dos-pinguins

> 标签: ai-agents, claude-code, hooks, pixel-art, visualization

## 简介

Uma praça de pinguins no navegador onde cada agente de IA (Claude Code) vira um pinguim: trabalha na mesa, pensa lendo num banco.
