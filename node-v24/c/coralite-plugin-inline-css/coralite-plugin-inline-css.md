# coralite-plugin-inline-css

> 标签: CSS inlining, CSS minification, HTML optimization, SSG plugin, coralite, inline css, performance improvement, server-side rendering, static site generator, stylesheet optimization, web performance

## 简介

Coralite plugin for inlining CSS.  Eliminate HTTP requests and improve performance by converting `<link>` tag CSS to `<style>` tags.
