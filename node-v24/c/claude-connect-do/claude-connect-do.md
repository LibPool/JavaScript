# claude-connect-do

> 标签: ai, anthropic, claude, claude-code, cli, digitalocean, gradient-ai, litellm, llm, openai, proxy

## 简介

Run Claude Code against DigitalOcean Gradient AI — spins up a local LiteLLM proxy to bridge Claude Code's Anthropic API format to DO's OpenAI-compatible endpoint.
