# cctl

> 标签: command tool, component, create component

## 简介

``` cctl -h   查看帮助 cctl -d   指定目录 cctl page 同时创建一个组件和路由映射,如果组件已经存在,也可以单独创建路由映射 cctl cpn  创建一个组件(如果懒得用代码块的话) ```
