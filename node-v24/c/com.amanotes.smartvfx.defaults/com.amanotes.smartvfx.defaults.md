# com.amanotes.smartvfx.defaults

> 标签: Amanotes, Effects, SmartVFX, VFX

## 简介

Curated default Smart VFX effects (definitions, prefabs, materials, textures). Install, then import from the Smart VFX Browser panel. Requires Universal Render Pipeline.
