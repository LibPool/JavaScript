# cozyecs

> 标签: archetype, compute-shader, data-oriented, ecs, entity-component-system, game-engine, gamedev, gpu, performance, typed-arrays, typescript, webgpu, wgsl

## 简介

A tiny, fast archetype ECS for TypeScript and JavaScript: typed-array storage, zero dependencies, and systems that compile to WebGPU compute shaders.
