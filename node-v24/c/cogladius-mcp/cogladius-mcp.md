# cogladius-mcp

> 标签: agents, mcp, model-context-protocol, mpp, soroban, stellar

## 简介

MCP server that lets an LLM agent work on Stellar: find paid tasks, buy data with MPP (charge or session), submit work, get paid by the Cogladius escrow, and read on-chain reputation.
