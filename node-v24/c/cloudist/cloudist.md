# cloudist

> 标签: bot-detection, cloud, cloudflare, cloudist, firewall, middleware, protection, rate-limit, security, sqli, waf, xss

## 简介

Simple WAF Web App Firewall, middleware for Node.js — blocks SQLi, XSS, path traversal, command injection & bots, with a waf-style browser check, framework-agnostic
