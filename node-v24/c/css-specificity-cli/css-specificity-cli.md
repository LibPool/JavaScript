# css-specificity-cli

> 标签: budget, cli, css, css-quality, heatmap, lint, refactor, selectors, specificity, stylesheet

## 简介

Print a specificity heat map for any CSS file, directory, or live URL — spot the over-specific selectors before they become a refactor.
