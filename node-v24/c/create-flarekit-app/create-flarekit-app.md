# create-flarekit-app

> 标签: coston2, create, fassets, flare, ftso, scaffold, starter, web3

## 简介

Start a Flare project — a headless script, a React app, an AI agent, or an MCP server, wired to a real network and pinned to the kit version it was generated against.
