# chainfetch-mcp-server

> 标签: addresses, ai, api, blockchain, chainfetch, crypto, defi, ethereum, mcp, model-context-protocol, semantic-search, smart-contracts, transactions, vector-database, web3

## 简介

A Model Context Protocol (MCP) server that provides access to ChainFETCH API for AI-powered Ethereum blockchain intelligence with advanced semantic search capabilities. Supports both stdio and HTTP transport modes.
