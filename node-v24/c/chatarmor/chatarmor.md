# chatarmor

> 标签: ai, ai-safety, angular, chat-widget, chatbot, gemini, llm, nestjs, openai, prompt-injection, rate-limit, spend-limit

## 简介

Production-ready AI chat endpoint for NestJS over Gemini/OpenAI, with the protections indie devs forget: API key never on the frontend, timeout + total fallback (never crashes), anti-prompt-injection, and a hard spend cap via llm-budget-cap.
