# clarity-aui-atlas

> 标签: architecture, code-map, codebase, dependency-graph, impact-analysis, static-analysis, treemap, visualization

## 简介

See any codebase as a map in seconds — Atlas (Map + Ring) and Lineage Trace. Deterministic and offline by default; optional BYO-key district descriptions. `npx clarity-aui-atlas`.
