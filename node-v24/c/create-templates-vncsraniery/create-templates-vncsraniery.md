# create-templates-vncsraniery

> 标签: boilerplate, landing-page, nextjs, react, tailwind, template, typescript

## 简介

Ferramenta para inicializar projetos Next.js com templates personalizados do VncsRaniery. Suporte a comandos diretos (add, list, help), múltiplos templates, instalação otimizada e download direto na pasta atual.

- 源码仓库：git+https://github.com/VncsRaniery/templates.git
