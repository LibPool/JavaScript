# contrast-score

> 标签: blur-score, contrast, contrast-score, exposure-score, glare-score, image-quality, kyc-document, michelson-contrast, ocr-preprocessing, rms-contrast, sharp

## 简介

Quantifies image and document contrast quality using Michelson contrast, RMS contrast, and luminance histogram distribution via Sharp. Optimized for pre-OCR document scanning and KYC verification.
