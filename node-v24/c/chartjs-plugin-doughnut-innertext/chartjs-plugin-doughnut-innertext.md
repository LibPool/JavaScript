# chartjs-plugin-doughnut-innertext

> 标签: chartjs, chartjs-plugin, doughnut chart inner text plugin, react-chartjs, react-chartjs-2

## 简介

A ChartJS doughnut plugin. It add inner text to the center of doughnut chart.
