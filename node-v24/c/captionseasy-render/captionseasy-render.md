# captionseasy-render

> 标签: captions, captionseasy, remotion, render, transparent-video, video

## 简介

Rendering add-on for captionseasy: burns CaptionsEasy captions into a video (MP4) or exports a transparent overlay (.mov ProRes 4444 / .webm VP9) with Remotion, locally.
