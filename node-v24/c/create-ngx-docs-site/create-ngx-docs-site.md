# create-ngx-docs-site

> 标签: angular, cli, create-app, docs, markdown, scaffold

## 简介

[Beta] Scaffolding: crea un sitio de documentacion en Angular basado en Markdown, listo para usar, con los paquetes de @ngx-docs-markdown-kit ya conectados. No gastes tokens de IA reconstruyendo la misma infraestructura (navegacion, SEO, README) en cada p
