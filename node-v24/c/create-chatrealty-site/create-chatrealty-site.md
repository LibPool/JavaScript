# create-chatrealty-site

> 标签: chatrealty, create-app, idx, mls, next, real-estate, scaffold, starter

## 简介

Scaffold a real-estate website backed by the ChatRealty API — listings search, map, favorites + lead capture, and neighborhood pages. One command, then customize.
