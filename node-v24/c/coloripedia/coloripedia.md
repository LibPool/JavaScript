# coloripedia

> 标签: a11y, accessibility, cmyk, color-names, color-palette, color-theory, colors, colours, contrast, contrast-ratio, dataset, design, design-tokens, hex, hsl, rgb, wcag

## 简介

Named colors with WCAG 2.2 contrast already computed — AA/AAA verdicts, the text color that works, plus hex, RGB, HSL, CMYK and relations.
