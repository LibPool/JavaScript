# codex-grok-bridge

> 标签: agent-harness, codex, grok, model-provider, responses-api, xai

## 简介

Run Grok 4.6 as the model inside Codex, with Codex still owning tools, permissions, history and MCP. Uses the grok login session, not an API key.
