# create-orchestrator-legion

> 标签: agent, claude, claude-code, github, orchestrator, project-template, scaffolding, worktree

## 简介

Orchestrator-Legion: an interactive initializer for a Claude Code agent team: an orchestrating main session, a roster with exclusive directory ownership, and a sync command for existing projects.
