# cups-config-reader

> 标签: CUPS, config, configuration, defaults, parser, reader, settings

## 简介

Util to read CUPS configuration (/etc/cups/cupsd.conf) merged with the defaults settings and CUPS files config (/etc/cups/cups-files.conf) and parses the directives in them
