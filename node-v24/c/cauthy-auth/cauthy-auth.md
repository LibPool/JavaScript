# cauthy-auth

> 标签: auth, authentication, cauthy, express, fastify, hono, nextjs, nuxt, oauth, oidc, session, sso, svelte, sveltekit, vue

## 简介

Sign in with Cauthy: one route to mount, getSession on the server, useSession in the browser. No database, no screens to build.
