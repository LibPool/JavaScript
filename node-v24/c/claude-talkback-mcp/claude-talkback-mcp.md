# claude-talkback-mcp

> 标签: claude, claude-code, elevenlabs, mcp, sapi, text-to-speech, tts, voice, wsl

## 简介

MCP server that gives Claude Code a conversational voice — speaks short, peer-style summaries aloud, ducking your music so it's audible. Two engines (Windows SAPI + ElevenLabs), works from WSL and native Windows.
