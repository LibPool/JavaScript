# cochrane-mcp

> 标签: claude, cochrane, evidence-based-medicine, healthcare, mcp, medical, model-context-protocol, research, systematic-review

## 简介

MCP server for searching the Cochrane Library — systematic reviews, trials (CENTRAL), clinical answers — and fetching structured review/trial details.
