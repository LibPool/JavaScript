# canvasimo

> 标签: api, canvas, canvasimo, chain, fluent, html5, interface, sensible, simple

## 简介

An HTML5 canvas drawing library, with 150+ useful methods, jQuery-like fluent interface, and cross-browser compatibility enhancements.
