# canvaslayer

> 标签: Canvas, android, drag, ios, layer, mobile, npm, rotate, touch, zoom

## 简介

Canvas添加多个图层操作，支持单个图层的拖动、缩放、转转.Canvas adds multiple layers,Support single layer drag, zoom, rotation,Support android version 4.4+ and ios.
