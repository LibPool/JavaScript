# cookie-jwt-crypto-sveltekit

> 标签: JavaScript

## 简介

fonction de creation d'un jwt + d'un cookie (affectation httponly) + authorization graphcms dans le header, le tout fonctionnant dans le hooks de sveltekit + crypto pour les hash de mot de passe
