# cakefetch

> 标签: cakefetch, fetch, http, request, response, rest-api, restful-api, typescript

## 简介

Cakefetch is a lightweight library for making HTTP requests based on fetch, facilitating the consumption of REST APIs with a simple and intuitive wrapper.
