# claude-translator

> 标签: anthropic, astro, claude, gemini, hreflang, i18n, l10n, localization, multilingual, ollama, openai, seo, static-site, translation

## 简介

Translate a static website into dozens of languages as real static pages, by substituting into built HTML instead of re-rendering.
