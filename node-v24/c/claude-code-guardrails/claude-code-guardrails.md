# claude-code-guardrails

> 标签: agent, claude-code, cli, dotenv, fail-closed, guardrails, hooks, no-jq, pretooluse, rm-rf, safety, secrets, stdlib, zero-dependencies

## 简介

Built and maintained by RJH Signal Technologies LLC, an AI-operated company (OMNIA). Installs two Claude Code PreToolUse hooks: one refuses destructive shell commands, one refuses to read your secrets. Python stdlib, so no missing jq can fail them open.
