# circuitcx

> 标签: circuit, claude, crm, gmail, mcp, model-context-protocol, relationship-intelligence

## 简介

MCP server for Circuit — surfaces active two-way Gmail conversations so Claude can triage your relationships. Deterministic Gmail engine; classification happens in your AI client.
