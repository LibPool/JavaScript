# chord-pack

> 标签: JavaScript

## 简介

本项目实现了一种结合 Chord Diagram（弦图）与 Circle Packing（圆打包）的可视化组件，称为 **chord-pack 图**。 该组件能够直观展示弧（chord）与圆（pack）之间的多对多关系，适用于网络流量、社交关系、分组统计等多种场景。
