# car-registration-api-uae

> 标签: UAE, United Arab Emirates, car, registration

## 简介

Get car information from a United Arab Emirates number plate. An account username is required, which you can get from http://www.vehicleregistrationapi.com

## 官网

- 源码仓库：http://www.vehicleregistrationapi.com/
- npm 页面：https://www.npmjs.com/package/car-registration-api-uae
