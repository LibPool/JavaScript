# card-precheck

> 标签: card precheck, card validator, credit card, credit card validation, javascript, luhn, luhn check, node, npm package, payment, payment validation, saas

## 简介

**card-precheck** is a lightweight JavaScript utility for validating credit and debit card numbers **before** sending them to a payment gateway.
