# cordova-plugin-local-notification-iphm-proto

> 标签: appplant, cordova-android, cordova-ios, cordova-windows, ecosystem:cordova, local notification, notification

## 简介

Temporary Fork of Cordova Local-Notification Plugin to hot-fix PGB build problem for IPHM prototype application. The plugin supports scheduling local notifications in various ways with a single interface. It also allows you to update, clear or cancel them
