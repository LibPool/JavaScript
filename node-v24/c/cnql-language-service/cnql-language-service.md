# cnql-language-service

> 标签: cnql, completion, dotnet, language-service, monaco, monaco-editor, wasm

## 简介

CNQL editor language service: completion, hover, diagnostics, semantic tokens and references, compiled to WebAssembly, with Monaco integration modules.
