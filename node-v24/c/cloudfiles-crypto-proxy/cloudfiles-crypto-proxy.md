# cloudfiles-crypto-proxy

> 标签: api, cloud computing, cloudfiles, rackspace, rackspace cloud, rackspace cloudfiles

## 简介

An HTTP proxy between Rackspace Cloudfiles that encrypts on upload and decrypts on download
