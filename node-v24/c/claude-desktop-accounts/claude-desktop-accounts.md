# claude-desktop-accounts

> 标签: account-switcher, anthropic, claude, claude-ai, claude-code, claude-desktop, mac, macos, menu-bar, menubar, multiple-accounts, quota, rate-limits, session-sync, switch-accounts, usage-limits

## 简介

Use several accounts in Claude Desktop on macOS: keep Code sessions visible under every account, and switch accounts in one click from the menu bar with live 5-hour and weekly usage. Unofficial.
