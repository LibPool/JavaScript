# cordova-plugin-cross-origin-isolated-headers

> 标签: cordova, cordova-android, ecosystem:cordova, file

## 简介

Cordova plugin to mock headers so that Android webview will reflect crossOriginIsolated as true, which will allow features such as SharedArrayBuffer.
