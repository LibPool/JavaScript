# caldom

> 标签: Alternative, Browser, Components, DOM, Frontend, JavaScript, Library, Lightweight, Minimalist, Performant, React, Reactive, Small, Tiny, UI, Vue, jQuery

## 简介

An agnostic, reactive & minimalist (3kb) JavaScript UI library with direct access to native DOM.
