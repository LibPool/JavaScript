# cordova-plugin-printer-usb

> 标签: JavaScript

## 简介

A Cordova/Phonegap plugin which one can print a message on the selected usb printer for Android.

## 官网

- npm 页面：https://www.npmjs.com/package/cordova-plugin-printer-usb

## 历史版本号

- 1.0.0

## 获取地址
