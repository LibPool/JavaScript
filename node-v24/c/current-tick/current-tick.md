# current-tick

> 标签: JavaScript

## 简介

A tiny modern no-nosence "current-tick" implementation that equeues your function to be executed later __within the current event loop cycle__, exactly what unfortunately named [`process.nextTick`](https://nodejs.org/api/process.html#process_process_nextt
