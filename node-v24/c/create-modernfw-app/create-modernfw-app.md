# create-modernfw-app

> 标签: Boilerplate, CLI, Code Generator, Development Workflow, Docker, ESLint, Front-end Development, Import Alias, JavaScript, Lint-staged, Modern Web Development, Next.js, Open Source, React, Tailwind CSS, TypeScript, Web Development

## 简介

Create Modernfw App is a command-line interface (CLI) tool that generates a modern Next.js/React application with TypeScript, and provides additional options such as Tailwind CSS, ESLint, Docker, Lint-staged, and Commit Lint
