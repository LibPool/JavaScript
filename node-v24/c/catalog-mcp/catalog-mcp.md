# catalog-mcp

> 标签: agent-tools, catalog, inventory, json, mcp, model-context-protocol

## 简介

MCP server that turns any JSON catalog into query tools for AI agents. Point it at a catalog URL or file; agents get filtering, grouping, ranking, and schema discovery.
