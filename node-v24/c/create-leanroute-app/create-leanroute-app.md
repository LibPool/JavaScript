# create-leanroute-app

> 标签: anthropic, leanroute, llm-gateway, next.js, openai, scaffold, starter, template

## 简介

Scaffold a new Leanroute-powered app. `npx create-leanroute-app my-app` gets you a running Next.js chat app (streaming, model picker, cost display) or a bare Node.js CLI starter pre-wired to Leanroute's OpenAI-compatible endpoint.
