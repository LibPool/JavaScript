# create-agentproto-app

> 标签: agentproto, create, open-standard, scaffold, tanstack, vite

## 简介

create-agentproto-app — scaffold an agentproto agent app: the .agentproto/ shell (APP.md, an agent, a workflow) plus a Vite + TanStack Router + TanStack Query ui/ project that builds to static files in .agentproto/ui/. Run with `pnpm create agentproto-app
