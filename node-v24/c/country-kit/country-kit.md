# country-kit

> 标签: calling-code, cctld, countries, country, country-codes, country-flags, country-list, currency, dial-code, e164, flag-emoji, iso-3166, iso-3166-1, iso-4217, locale, phone, svg-flags, typescript, un-m49

## 简介

ISO 3166-1 country data for TypeScript: alpha-2/3 codes, names, ITU-T E.164 calling codes, UN M49 regions, IANA ccTLDs, ISO 4217 currencies, flag emoji, and SVG flags.
