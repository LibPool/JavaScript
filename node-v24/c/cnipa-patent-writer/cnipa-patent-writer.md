# cnipa-patent-writer

> 标签: agent-skill, claude, claude-code, cnipa, docx, patent, skill, 专利, 发明专利

## 简介

A Claude Code Agent Skill for drafting Chinese invention patents (CNIPA) — borrows only a template's formatting, generates all content from your own materials. Installs via npx into your agent's skills folder.
