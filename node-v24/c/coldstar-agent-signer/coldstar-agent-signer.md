# coldstar-agent-signer

> 标签: agent-wallet, ai-agent, air-gap, cold-storage, coldstar, policy, signer, solana, solana-agent-kit, wallet

## 简介

Agent-safe signing for Coldstar — policy-gated auto-sign / air-gapped escalation / reject. The agent never holds the root key.
