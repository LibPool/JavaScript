# cypress-live-reporter

> 标签: cypress, cypress-plugin, dashboard, e2e, live, observability, postgres, self-hosted, test-reporter, testing

## 简介

Self-hosted live Cypress test reporting — streams run/spec/test events and failure evidence (screenshots, DOM, console, commands) to Postgres or a webhook.
