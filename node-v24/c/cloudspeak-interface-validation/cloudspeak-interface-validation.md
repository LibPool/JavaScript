# cloudspeak-interface-validation

> 标签: cloudspeak, ts, typescript, validate, validation

## 简介

Work-in-progress library for creating Typescript interface validators.  The code generated by `cloudspeak-interface-generation` uses this library, so the generated validators rely on this library at runtime.
