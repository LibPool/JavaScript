# crypterjs

> 标签: aes, aes-256, aes-256-ctr, aes-256-gcm, aes256, cipher, crypter, crypterjs, crypto, cryptography, data-security, decrypt, decryption, encrypt, encryption, hashr, jwt, library, node, npm, open-source, pbkdf2, secure, symmetric-encryption, token-encryption

## 简介

A simple and secure library for encrypting and decrypting data using AES-256-GCM with PBKDF2 key derivation. Ideal for securing JWT tokens and sensitive information.
