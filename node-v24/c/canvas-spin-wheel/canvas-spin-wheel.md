# canvas-spin-wheel

> 标签: canvas, decision wheel, picker wheel, prize wheel, raffle, random picker, spin wheel, wheel of names, widget

## 简介

A tiny, dependency-free, canvas-based spin wheel widget for the browser. Weighted entries, realistic spin physics, TypeScript types included.
