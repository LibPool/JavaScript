# cross-build-git-info-plugin

> 标签: build-info, git, plugin, rollup, version, vite, webpack

## 简介

一个跨平台的 Webpack 和 Vite 插件，用于在项目打包后，在输出目录中生成一个详细的 `git.info` 文件。
