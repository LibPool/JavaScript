# cloudsynth

> 标签: aws, cdk, cdk-nag, ci, cloudformation, compliance, devsecops, iac, infrastructure-as-code, intent, policy, policy-as-code, verification

## 简介

Check a synthesized AWS CDK app against cloudsynth.intent.yml. Exemptions, coverage accounting, shareable rule packs, and an editor schema. Runs entirely in your own pipeline: no account, no API key, no network calls.
