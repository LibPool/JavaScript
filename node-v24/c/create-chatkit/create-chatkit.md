# create-chatkit

> 标签: JavaScript

## 简介

npx create-chatkit my-chat-app — scaffolds a bare Vite+Svelte app wired to @chatkit-svelte/svelte + @chatkit-svelte/ui with chosen plugins/theme. SvelteKit scaffolding is not yet supported.
