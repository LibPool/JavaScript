# cmdpeek

> 标签: argparse, autocomplete, bash, cheatsheet, cli, command-builder, explainshell, fish, flags, fzf, help, interactive, man, shell, terminal, tldr, tui, zsh

## 简介

Interactive flag explorer & command builder for any CLI — parsed live from the command's own --help. Local-first, no curated database.
