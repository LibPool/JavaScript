# canon-ds

> 标签: coding-agents, css, design-system, design-tokens, mcp, react, studio, vibe-coding

## 简介

A design system for apps built with coding agents: shared tokens, components, layouts, CSS and React exports, focused instructions, lint and MCP tools.
