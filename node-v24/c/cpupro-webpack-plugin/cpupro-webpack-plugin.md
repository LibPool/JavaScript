# cpupro-webpack-plugin

> 标签: JavaScript

## 简介

Webpack provides a really detailed `webpack.debug.ProfilingPlugin`, but it only does CPU Profiling. Further, it doesn't seem to work with config arrays. We can do much better. We can leverage the work of @lahmatiy - the excellent cpupro: https://github.co
