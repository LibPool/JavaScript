# capacitor-pq-secure-storage

> 标签: android, biometric, capacitor, cryptography, dilithium, fips-203, fips-204, ios, kyber, ml-dsa, ml-kem, plugin, post-quantum, pqc, secure-storage

## 简介

Hardware-backed post-quantum crypto (ML-DSA, ML-KEM, AES-256) and biometric secure storage for Capacitor on iOS and Android, with a software fallback for the web.
