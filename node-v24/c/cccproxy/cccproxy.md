# cccproxy

> 标签: JavaScript

## 简介

A minimal proxy server that allows [Claude Code](https://docs.anthropic.com/en/docs/claude-code) to use GitHub Copilot as its backend. This enables Claude Code users with GitHub Copilot subscriptions to leverage their existing subscription for Claude Code
