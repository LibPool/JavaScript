# chat2blend

> 标签: 3d, agent, ai, blender, bpy, bridge, cdp, chatgpt, cli, llm, modeling, modelling, procedural-generation

## 简介

Use your LLM subscription as the 3D brain. Let Blender execute. Local-first bridge that drives the ChatGPT desktop app over CDP and streams bpy chunks straight into Blender - no API key, loopback only, zero runtime dependencies.
