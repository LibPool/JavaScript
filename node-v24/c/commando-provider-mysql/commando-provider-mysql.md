# commando-provider-mysql

> 标签: bot, discord, discord-bot, discord.js, discord.js-commando, discordjs-commando, mariadb, mysql

## 简介

Uses a MySQL or MariaDB (recommended) database to store guild settings. It requires the mysql2 npm package.
