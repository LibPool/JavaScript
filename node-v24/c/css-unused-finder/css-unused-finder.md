# css-unused-finder

> 标签: cli, css, css-quality, dead-classes, fragility, lint, refactor, specificity, stylesheet, unused-css

## 简介

Score a stylesheet's fragility (A–F) and surface !important, ID selectors, deep nesting, and dead classes — one CLI command, no config.
