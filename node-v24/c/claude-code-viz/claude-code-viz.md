# claude-code-viz

> 标签: analytics, claude, claude-code, cli, dashboard, usage, visualizer

## 简介

Local web dashboard for your Claude Code data (~/.claude) — usage & cost analytics, session replay, activity heatmap. 100% local & read-only.
