# capcode

> 标签: anti-ocr, captcha, captcha generator, captcha npm, captcha-canvas alternative, express captcha, hmac, javascript captcha, jpeg, node captcha, nodejs captcha, otp, png, security, svg, svg-captcha alternative, ttl, verification

## 简介

Zero-dependency Node.js CAPTCHA generator - PNG/SVG/JPEG image with HMAC-SHA256 signed token & TTL. Stateless pure TypeScript alternative to svg-captcha and captcha-canvas.
