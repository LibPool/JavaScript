# calllint

> 标签: agent, ai, cli, mcp, model-context-protocol, sarif, scanner, security, static-analysis, supply-chain

## 简介

Evidence-backed security verdicts for MCP servers and agent tools. Lint agent tool-call risk before tools run — SAFE / REVIEW / BLOCK / UNKNOWN, with evidence. Never executes the server it judges.
