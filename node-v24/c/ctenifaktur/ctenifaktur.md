# ctenifaktur

> 标签: accounting, bank-statement, camt053, cli, ctenifaktur, czech, faktura, gpc, invoice, invoice-ocr, isdoc, money-s3, pohoda

## 简介

Command-line client for Čtení Faktur: upload Czech invoices, receipts and bank statements, download ISDOC, Pohoda, Money S3, GPC and SEPA XML exports.
