# codebase-doc-generator

> 标签: ai, api-docs, code-analysis, codebase, dependency-graph, developer-tools, documentation, llm, mcp, mermaid, model-context-protocol, readme

## 简介

MCP server that auto-generates documentation from any codebase. Scans architecture, maps dependencies, extracts APIs, generates README — all local, zero external APIs. Reduces LLM context window usage by 70%.
