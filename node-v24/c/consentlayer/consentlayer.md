# consentlayer

> 标签: analytics, angular, astro, consent, conversions-api, cookie-consent, ga4, gdpr, meta-pixel, nextjs, nuxt, posthog, react, sentry, solid, solidstart, svelte, sveltekit, tanstack-start, vue

## 简介

Consent-first analytics for the browser and server: one API in front of GA4, Meta, PostHog, Sentry and more, gated by the visitor's consent.
