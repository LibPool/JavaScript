# create-daloy

> 标签: api, cli, create, daloy, daloyjs, init, openapi, rest, scaffold, starter, template

## 简介

Scaffold a new DaloyJS project. Run with `pnpm create daloy`, `npm create daloy@latest`, `yarn create daloy`, or `bun create daloy`.
