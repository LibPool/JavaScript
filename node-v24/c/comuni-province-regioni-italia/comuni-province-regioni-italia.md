# comuni-province-regioni-italia

> 标签: api, comuni, continenti, italia, lingue, nazioni, node, province, regioni, server, stati

## 简介

Piccolo server in Node.JS che espone API da cui ricavare i comuni, province, regioni italiane. Inoltre è possibile avere anche gli nazioni, continenti e lingue del mondo. Utile per popolare elenchi e liste drop-down
