# computerworld

> 标签: agents, computer-use, deterministic, environment, reinforcement-learning, simulator, wasm

## 简介

An ultra computer world simulator written in Rust: five OS shells, real applications, a synthetic internet and byte-identical replay, as WebAssembly for Node and the browser.
