# ccusage-report

> 标签: analytics, claude-code, cli, usage-report, visualization

## 简介

Claude Code 使用报告工具 — 从 JSONL 日志和 Git 仓库提取 AI 贡献度、效率与使用指标，支持 Web 可视化和命令行两种模式
