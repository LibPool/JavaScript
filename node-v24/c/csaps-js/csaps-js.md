# csaps-js

> 标签: approximation, browser, csaps, cubic-spline, curve-fitting, interpolation, ndgrid, numerical, smoothing, smoothing-spline, spline, typescript

## 简介

Cubic spline approximation (smoothing) for Node.js and the browser. A dependency-free TypeScript port of the Python csaps library — univariate, multivariate and N-D gridded data smoothing.
