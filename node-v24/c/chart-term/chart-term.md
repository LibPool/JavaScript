# chart-term

> 标签: ascii-chart, bar-chart, braille, chart, cli, data-visualization, histogram, line-chart, sparkline, terminal, truecolor, unicode

## 简介

High-fidelity inline terminal charts, sparklines, line plots, and bar graphs with Unicode Braille, box-drawing axes, and 24-bit Truecolor gradients across macOS, Linux, Windows, PowerShell, Bash, and Zsh.
