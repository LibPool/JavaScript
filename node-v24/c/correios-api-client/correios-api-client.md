# correios-api-client

> 标签: api, calculo, calulo preço, cep, correios, prazo, preço, rastreamento

## 简介

A lightweight client for interfacing with the Correios API. Facilitates seamless integration of Brazil's postal services into JavaScript applications, including features for tracking, delivery estimates, pricing, and address lookup (CEP).
