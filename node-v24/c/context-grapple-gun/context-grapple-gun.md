# context-grapple-gun

> 标签: agents, autonomy, claude-code, cogpr, governance, plugin

## 简介

Portable, harness-agnostic governance lifecycle for the Ubiquity substrate: cognitive PRs, scoped promotion, and cross-session lesson compounding. cgg-runtime is the Claude Code adapter today; cogpr carries the conventions for any platform.
