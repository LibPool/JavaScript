# cf-ddns-cli

> 标签: API, CLI, Cloudflare, DDNS, DNS, TypeScript

## 简介

A simple CLI tool that updates Cloudflare DNS records dynamically (DDNS) with your current IP address (IPv6 supported), compatible with Cloudflare API v4.
