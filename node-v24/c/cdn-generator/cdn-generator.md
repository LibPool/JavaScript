# cdn-generator

> 标签: cdn, cli, esm.sh, githack, github, jsdelivr, jsdmirror, local-ip, nip.io, sslip.io, statically, traefik.me, wildcard-dns

## 简介

Generate CDN links for any GitHub repo (jsDelivr, esm.sh, GitHack, Statically, jsDelivr mirrors) and wildcard DNS hostnames for any IP (nip.io, sslip.io, traefik.me, backname.io, anyip.dev, local-ip.sh).
