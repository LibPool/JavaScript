# camerashy

> 标签: blur, camerashy, framework-agnostic, nextjs, print-protection, privacy, protection, react, screen-capture, screenshot, security, sensitive-data, server-components, shield, vanilla-js

## 简介

Lightweight screenshot detection and visual shielding for sensitive UI content. Framework-agnostic core with a React wrapper. Supports blur, color overlay, and content replacement modes.
