# cordova-plugin-networkinterfaces

> 标签: cordova-android, cordova-browser, cordova-ios, cordova-windows, ecosystem:cordova, ip, local, network, proxy, wifi

## 简介

This plugin allows your application to retrieve the local wifi ip address, carrier ip address and http proxy information.
