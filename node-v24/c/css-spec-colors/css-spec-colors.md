# css-spec-colors

> 标签: colors, css, keywords, names, svg

## 简介

A JSON with all CSS color keywords and their corresponding values in hex, RGB and HSL. Color list generated from W3C spec (https://www.w3.org/TR/css-color-4/#named-colors).
