# canvas-mark-board

> 标签: board, canvas, canvas-mark, drawing, img-mark, line, mark, mark-board, mark-tool, polygon, react, rect, typescript, vue, vue-mark

## 简介

`canvas-mark-board` 基于原生canvas封装的图像标注工具，在 vue / react / 原生js 应用中都可以实现标注功能。提供了一系列事件和方法，用于管理标注对象、绘制标注形状、导入标注数据等操作。
