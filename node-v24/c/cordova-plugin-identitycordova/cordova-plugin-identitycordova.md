# cordova-plugin-identitycordova

> 标签: cordova-android, cordova-ios, ecosystem:cordova

## 简介

Identity platform plugin for Cordova. This plugin supports liveliness detection, ocr, touchless fingerprint, document scanning and mobile voice biometric
