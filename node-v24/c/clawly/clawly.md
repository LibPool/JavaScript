# clawly

> 标签: JavaScript

## 简介

Clawly — OpenClaw plugin for self-hosted (BYOI) instances. Registers the gateway methods, tools, and hooks that the Clawly mobile/desktop client needs, without any dependency on the managed Clawly backend.
