# claude-skill-architecture-diagram

> 标签: architecture, claude, claude-code, claude-skill, diagram, svg

## 简介

AI agent skill for generating dark-themed architecture diagrams as self-contained HTML files. Works with Claude Code, Cursor, Windsurf, and any LLM agent.
