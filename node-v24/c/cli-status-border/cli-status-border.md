# cli-status-border

> 标签: ansi, border, cli, progress, spinner, status, terminal, tui

## 简介

A reusable animated status border for CLI tools — a colored bar pinned to the top of the terminal that pulses while a task runs, and resolves to a success/error color when it's done. Any color you want, not just green.
