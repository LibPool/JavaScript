# canship

> 标签: ai-generated-code, api-key, audit, cli, nextjs, secrets, security, static-analysis, supabase, vibe-coding

## 简介

Static scanner for exposed credentials and open access rules in JS/TS front-end projects. Scans local files without executing project code or making network requests.
