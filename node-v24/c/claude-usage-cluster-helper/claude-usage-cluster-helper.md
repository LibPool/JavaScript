# claude-usage-cluster-helper

> 标签: claude, claude-code, cli, dashboard, instrument-cluster, localhost, rate-limit, usage

## 简介

Local helper for the Claude usage cluster: reads your OAuth token from the OS credential store, polls the zero-token usage endpoint, and serves a credential-free usage subset on http://127.0.0.1:41527 for the browser page to read. No dependencies, nothing
