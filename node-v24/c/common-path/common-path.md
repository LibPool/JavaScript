# common-path

> 标签: absolute, array, common, cross-platform, deepest, dir, directory, file, files, find, folder, longest, max, parent, path, paths, posix, prefix, relative, root, same, shared, unc, windows

## 简介

Finds the longest common parent directory path in an array of file path strings or custom objects. Also returns sub and base parts for each path.
