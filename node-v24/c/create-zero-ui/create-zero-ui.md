# create-zero-ui

> 标签: css driven state, data attributes, fastest ui updates, global state, high performance react, instant ui updates, no context, no prop drilling, postcss plugin, react, react optimization, react state, scoped state, ssr safe, state management, tailwind, tailwind variants, ui state, zero render, zero rerenders

## 简介

Zero-UI project scaffolder for React. Instantly sets up zero-runtime UI state, Tailwind variants, PostCSS, and SSR-safe config in Vite or Next.js apps.
