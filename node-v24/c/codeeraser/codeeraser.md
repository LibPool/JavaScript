# codeeraser

> 标签: clone-detection, code-quality, codeeraser, dead-code, deduplication, entropy

## 简介

CodeEraser — erase LLM-induced code & document entropy. This package is a name-reservation pointer: the tool ships as prebuilt binaries on GitHub Releases, `cargo install codeeraser`, and a Claude Code plugin.
