# leafthrough

> 标签: flipbook, magazine, page-flip, page-turn, react, svelte, three, vue, web-component, webgl

## 简介

A 3D magazine you can flip through, with paper that bends, rolls and casts shadows. Built on three.js, with React, Vue, Svelte and Web Component bindings.
