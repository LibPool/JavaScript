# @cs4-seltra/crud-pattern

> 标签: JavaScript

## 简介

Crud pattern allows to have a standard structure for the behavior of typeorm CRUDs, both from the configuration of resolvers at GraphQl level, as well as at controller level with Swagger decorators.
