# ondocs

> 标签: ai, ai-sdk, ai-search, ask-ai, astro, astro-integration, bm25, docs-search, docusaurus, docusaurus-plugin, embeddings, fumadocs, llms-txt, mcp, mcp-server, nextra, rag, react, retrieval, starlight, starlight-plugin, vitepress, vitepress-plugin, withastro

## 简介

Open-source Ask AI for your docs, with an MCP server for agents: cited answers on your own model key, from one static index built with your site. No vendor, no vector database. Starlight, Docusaurus and VitePress plugins, Next.js, or one script tag.
