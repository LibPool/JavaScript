# @perxel/spotlight

> 标签: ai, ai-sdk, chat, cmdk, command palette, headless, mcp, react, search, spotlight

## 简介

Search or ask, like Spotlight: a ⌘K box that searches a site as you type and hands a question to an AI chat on Enter. Headless React parts, an optional liquid glass skin, and a Web-standard server helper.
