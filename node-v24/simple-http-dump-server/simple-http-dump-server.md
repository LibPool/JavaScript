# simple-http-dump-server

> 标签: dump, dumper, http, log, logger, mock, requests, server, webhook

## 简介

Tiny HTTP server that answers every request with 200 and dumps it to stdout and, optionally, a JSON Lines file. A fake upstream for webhooks and client testing.
