# agentic-usage-analysis

> 标签: agent, audit, claude-code, codex, opencode, session-logs, skill, zcode

## 简介

Skill + toolkit that reconstructs how AI coding agents (Codex, Claude Code, ZCode, OpenCode, OMP, ...) worked on a repository, from their local session logs. Installs itself into your agent's skills directory.
