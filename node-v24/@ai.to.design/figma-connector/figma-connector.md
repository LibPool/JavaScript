# @ai.to.design/figma-connector

> 标签: ai, claude, claude-code, cursor, design-tokens, figma, figma-plugin, html-to-figma, mcp, mcp-server, model-context-protocol

## 简介

Local MCP server for ai.to.design — render AI-generated HTML/CSS as native, editable Figma designs from Claude, Cursor, Codex or any MCP client.
