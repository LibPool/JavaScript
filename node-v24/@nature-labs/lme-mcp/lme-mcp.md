# @nature-labs/lme-mcp

> 标签: agent-memory, claude, claude-code, cursor, llm, long-term-memory, mcp, memory, model-context-protocol

## 简介

Living Memory MCP — a persistent memory store for coding agents, over stdio. Facts survive across sessions and processes; retrieval is semantic (MMR), not string matching. Pre-alpha.
