# @dgteam/validator

> 标签: dgteam, dgteam.cn

## 简介

1、支持在 rule 中设置自定义验证规则（先不支持异步）   2、支持接受 return Error 对象   3、一些特殊字段比如 int 在基础判断和辅助判断中错误提示不够精确的问题
