# @valiify/val-core

> 标签: agents, claude-code, design-system, figma, val, valiify

## 简介

Val — the shared agent pipeline for Valiify component libraries: Figma extraction, component mapping, build, QA and visual accuracy. Templates + tools + methodology; each library supplies a val/config.json.
