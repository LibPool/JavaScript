# @triiiceratops/plugin-av

> 标签: JavaScript

## 简介

Audiovisual plugin for the triiiceratops IIIF viewer, authored on @triiiceratops/plugin-sdk. Claims time-based-media canvases and renders their media over the canvas rect.
