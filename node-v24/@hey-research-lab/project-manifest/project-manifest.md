> 标签: cli, evm, hey-research, json-schema, manifest, robinhood-chain, typescript, well-known

## 简介

A machine-readable declaration format (/.well-known/hey-project.json) for Robinhood Chain projects: JSON Schema, TypeScript types, validator and CLI. Declared, not verified.
