# @listen-fire/image-providers

> 标签: JavaScript

## 简介

Image generation behind the model map (OpenAI, Gemini). The vendor SDKs are optional peers loaded on first use; the environment and the host answers (usage recording, token counting) are passed in as @listen-fire/model-providers' ModelHost.
