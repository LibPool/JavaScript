# @listen-fire/wake-cloud-tasks

> 标签: JavaScript

## 简介

The wake slot's module on Google Cloud Tasks (`@lf/wake-cloud-tasks`): a host saying work is due now or at an instant becomes a Cloud Tasks task, named for its coalescing window, that starts a Cloud Run drain job. Served as a process lf starts (kind: core
