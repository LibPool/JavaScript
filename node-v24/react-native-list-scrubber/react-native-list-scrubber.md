# react-native-list-scrubber

> 标签: accessibility, collapsing-header, contacts, fast-scroll, flashlist, flatlist, gesture-handler, legend-list, react-native, reanimated, scrollbar, scrubber, section-index, sectionlist

## 简介

Fast scrolling for long React Native lists: a draggable thumb with section labels (A–Z, dates…), on the UI thread with Reanimated 4 (New Architecture), and an adjustable screen-reader control.
