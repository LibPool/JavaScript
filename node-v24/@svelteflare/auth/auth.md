# @svelteflare/auth

> 标签: JavaScript

## 简介

A lightweight, Edge-native, DB-agnostic authentication library built for **Svelte 5** and **SvelteKit** that integrates seamlessly with **@svelteflare/sync** for real-time WebSocket session verification.
