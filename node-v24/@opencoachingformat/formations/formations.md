# @opencoachingformat/formations

> 标签: JavaScript

## 简介

Standard basketball formation registry for Open Coaching Format (OCF) — offense and zone defense starting positions, resolvable to OCF entities.

## 官网

- 官网：https://opencoachingformat.org
- 源码仓库：git+https://github.com/opencoachingformat/formations.git
- npm 页面：https://www.npmjs.com/package/@opencoachingformat/formations
