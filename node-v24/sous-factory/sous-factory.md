# sous-factory

> 标签: agents, claude, codex, software-factory, workflow

## 简介

A software factory for coding agents, on your machine. sous runs your software development flow with coding agents: implement, review, fix, merge, or any step you write. The flow is a deterministic graph in YAML, like a GitHub Actions workflow, so the age
