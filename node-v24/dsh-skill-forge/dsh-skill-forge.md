# dsh-skill-forge

> 标签: agent, deepseek-harness, dsh, dsh-plugin, memory, plugin, prompt, skill, skills

## 简介

Skill Forge for DeepSeek Harness: distill a conversation or pasted context into a reusable SKILL.md, so a similar question later hits a skill instead of re-deriving the answer. Includes 4 model tools and a Web GUI panel.
