# @budhash/confix

> 标签: config, configuration, confix, editor, ini, properties, sed, yaml

## 简介

Faithful JavaScript port of the confix config-file editor core — update, add, comment, uncomment and delete keys in properties/YAML/INI-style files. Pure text-to-text, zero dependencies.
