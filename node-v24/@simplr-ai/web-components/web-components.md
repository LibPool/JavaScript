# @simplr-ai/web-components

> 标签: ai-delegation, angular, astro, behavioral-biometrics, custom-elements, device-fingerprinting, feature-flags, framework-agnostic, fraud-detection, rum, simplr, svelte, vue, web-components

## 简介

Framework-agnostic Web Components for the Simplr platform. Standard Custom Elements + a small imperative controller that expose the full @simplr-ai/js browser core (device fingerprint, behavioral biometrics, fraud/order checks, feature flags, RUM, profile
