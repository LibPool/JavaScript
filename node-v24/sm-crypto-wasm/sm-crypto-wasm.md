# sm-crypto-wasm

> 标签: assemblyscript, chinese-cryptography, cms, cryptography, encryption, gm, gmssl, sm-crypto, sm2, sm3, sm4, sm9, typescript, wasm, webassembly, webcrypto, x509, zuc, 商密, 国密

## 简介

SM2/SM3/SM4/SM9/ZUC (Chinese cryptography) implemented in AssemblyScript → WebAssembly. Node.js 18+ and modern browsers, with per-algorithm lazy loading.
