# @hashi-mcp/server

> 标签: anthropic, claude, desktop, hashi, mcp, model-context-protocol

## 简介

MCP server for Hashi bridges. Wraps @modelcontextprotocol/sdk and exposes one or more bridges as a single MCP server (stdio).
