# @bringuplabs/bringup-mcp-server

> 标签: bringup, fleet, mcp, model-context-protocol, robotics

## 简介

Connect AI coding agents (Claude Code, Codex, Claude Desktop) to the Bringup desktop app over MCP — a zero-config stdio bridge to the app's local endpoint.
