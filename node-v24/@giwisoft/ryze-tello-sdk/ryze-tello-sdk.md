# @giwisoft/ryze-tello-sdk

> 标签: JavaScript

## 简介

Node.js SDK for the [Ryze Tello Drone](https://www.ryzerobotics.com/tello).   Provides a fluent Promise-based API for drone commands, live telemetry, and video streaming.
