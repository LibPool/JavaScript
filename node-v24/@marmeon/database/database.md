# @marmeon/database

> 标签: database, kysely, marmeon, migrations, postgres, sqlite

## 简介

Data access on Kysely for Marmeon apps: connections, migrations per module, generated table types, repositories, relations derived from foreign keys (with), tryInsert/tryUpdate returning a Result, transactions that roll back on err, and pagination.
