# @atomicloud/diene.config

> 标签: atomicloud, bun, cjs, config, configuration, esm, yaml, zod

## 简介

The config-loading engine for the AtomiCloud TypeScript family — 4-tier merge (base YAML → landscape overlay → build-time injection → runtime env), zod validation, and $schema generation.
