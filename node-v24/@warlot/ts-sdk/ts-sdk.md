# @warlot/ts-sdk

> 标签: api, sdk, tutorial, typescript, warlot

## 简介

A TypeScript SDK for interacting with the Warlot decentralized backend platform. This SDK is designed to simplify the process of building applications that leverage Warlot's decentralized storage and compute capabilities.
