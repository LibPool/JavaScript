# @deepwhale-cn/dsh-shell-canvas

> 标签: canvas, deepwhale, dsh, dsh插件, text-to-video, video, whale, 深鲸画布

## 简介

把一段文字变成能发的视频。贴一段稿子、选几张素材，点一下出横竖双版成片；稿子、素材、成片都在你自己的电脑上，不上传、不联网。免费版即可用，授权后去水印。
