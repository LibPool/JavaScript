# @mice-game/core-mod

> 标签: JavaScript

## 简介

The mandatory UI shell for Mice Game. It owns the Svelte application, theme controls, and runtime mod manager. The engine uses Svelte's runtime reactivity, while this project owns the Svelte components and SvelteKit application.
