# @onchaindiligence/auto-evidence-proxy

> 标签: agent-payments, evidence, mcp, onchaindiligence, receipts, reconciliation, x402

## 简介

Local Auto-Evidence for explicitly supported payment paths: durable, stable-attempt, no-blind-retry OnChainDiligence evidence for x402 v2 Base-USDC workflows, plus a stdio MCP guard proxy. Not a wallet, gateway or custodian.
