# @angular-libs/web

> 标签: angular, battery, bluetooth, click-outside, clipboard, device-orientation, directives, file-drop, file-system-access, geolocation, hardware, idle-detection, network, nfc, resize-observer, signals, web-api

## 简介

Reactive Angular Signal wrappers and directives for modern Browser and Hardware Web APIs (Geolocation, Battery, Bluetooth, NFC, File System, ResizeObserver, ClickOutside, FileDrop, and more).
