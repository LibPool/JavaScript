# @fulate/vue

> 标签: JavaScript

## 简介

Vue adapter 把 Vue renderer 接到一个 Fulate `Root`。它不复制 Core 场景状态，也不创建第二个 Root frame runtime；每个挂载的应用只拥有自己的 content/overlay Layer 和 Vue 生命周期。
