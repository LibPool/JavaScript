# @pipedog/espeak-ng

> 标签: conversational-ai, espeak-ng, g2p, phonemizer, pipecat, pipedog, realtime, tts, voice-ai, wasm

## 简介

eSpeak NG phonemization for pipedog's local TTS models (Kokoro, Piper): espeak-ng compiled to WebAssembly, loaded lazily as an optional peer dependency.
