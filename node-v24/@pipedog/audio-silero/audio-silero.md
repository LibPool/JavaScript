# @pipedog/audio-silero

> 标签: conversational-ai, onnx, pipecat, pipedog, realtime, silero, vad, voice-activity-detection, voice-ai

## 简介

Silero VAD (SileroVADAnalyzer) for pipedog, with the upstream silero_vad.onnx model included. Runs on onnxruntime-node or onnxruntime-web via @pipedog/onnx.
