# @pipedog/transport-whatsapp

> 标签: conversational-ai, pipecat, pipedog, realtime, transport, voice-ai, webrtc, whatsapp, whatsapp-calling

## 简介

WhatsApp Business calling for pipedog: a port of Pipecat's WhatsAppClient and WhatsAppApi (Meta Cloud API calling webhooks, HMAC signature checks, SDP accept/reject/terminate) on the SmallWebRTC transport.
