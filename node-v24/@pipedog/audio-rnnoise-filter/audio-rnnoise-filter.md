# @pipedog/audio-rnnoise-filter

> 标签: audio-filter, conversational-ai, noise-suppression, pipecat, pipedog, realtime, rnnoise, voice-ai, wasm

## 简介

RNNoise noise suppression for pipedog: a port of Pipecat's RNNoiseFilter, with RNNoise compiled to WebAssembly, so it runs on Bun, Node, Deno and Cloudflare Workers.
