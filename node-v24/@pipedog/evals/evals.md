# @pipedog/evals

> 标签: conversational-ai, evals, llm-judge, pipecat, pipedog, testing, voice-ai

## 简介

Pipecat's evals (pipecat.evals) for pipedog: test a bot end to end with scripted or LLM-simulated users, TTS for the user's audio, matchers and an LLM judge, results, suites, and the pipedog-eval CLI.
