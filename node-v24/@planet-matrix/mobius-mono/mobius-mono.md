# @planet-matrix/mobius-mono

> 标签: library, mobius, mono, monorepo

## 简介

Mobius Mono Project 是一个面向项目开发的一致性项目，由 Mobius Mono Specification 和 Mobius Mono Toolkit 组成，为项目提供可复用的设计依据、工程规范和开发工具。
