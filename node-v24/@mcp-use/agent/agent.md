# @mcp-use/agent

> 标签: agent, ai, langchain, mcp, model-context-protocol, typescript

## 简介

Native cross-platform MCP agent. Inspector → MCPAgent → loop → fetch + @mcp-use/client. LangChain bridge at @mcp-use/agent/langchain.
