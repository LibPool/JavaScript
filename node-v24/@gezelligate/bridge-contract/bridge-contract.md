# @gezelligate/bridge-contract

> 标签: bridge, contract, gezelligate, manifest

## 简介

Shared bridge-manifest contract for Gezelligate: one zod schema consumed by the engine (producer) and the bridge launcher (consumer), so the two can never drift apart silently.
