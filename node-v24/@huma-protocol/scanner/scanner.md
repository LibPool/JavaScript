## 简介

HUMA wallet-graph scanner — signed sybil-risk scoring for any wallet list. Ethereum, Base, Arbitrum, Optimism, Polygon, Avalanche and Solana via free-tier Helius + Alchemy RPCs. Ed25519-signed JSON + Markdown + HTML reports.
