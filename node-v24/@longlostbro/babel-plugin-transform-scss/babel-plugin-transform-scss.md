# @longlostbro/babel-plugin-transform-scss

> 标签: babel, css, plugin, sass, sass-loader, scss, transform, transpile, webpack

## 简介

Forked from https://github.com/altgifted/babel-plugin-transform-scss. Babel plugin for transpile scss or sass imports to css and embedding them in the head of the document
