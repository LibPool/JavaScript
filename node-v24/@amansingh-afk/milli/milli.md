# @amansingh-afk/milli

> 标签: animation, ansi, ascii, image, terminal, tui, video

## 简介

Pixel-perfect animated ASCII art engine. Images, GIFs, video → terminal, browser, or embedded (Go/Lua/JSON). CLI + web playground.
