# @metanet-games/chaintag

> 标签: bitcoin, brc100, bsv, gamedev, handcash, identicon, identity, wallet

## 简介

Portable, wallet-optional player identity for BSV games — anonymous by default, upgradeable to a real wallet key, with a deterministic name + identicon.
