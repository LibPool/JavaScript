# @metanet-games/satchel

> 标签: 1sat, bsv, gamedev, inventory, items, ordinals

## 简介

Inventory for BSV games — local for a wallet-less player, real on-chain items (1Sat Ordinals) when they connect, in one merged bag. Zero deps.
