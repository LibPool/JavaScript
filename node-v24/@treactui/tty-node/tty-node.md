# @treactui/tty-node

> 标签: JavaScript

## 简介

Serves a Node program to [`@treactui/tty`](../tty) over a WebSocket: each browser gets its own copy of the program in a pseudo-terminal ([node-pty](https://github.com/microsoft/node-pty)), so anything that writes to a terminal works: commander CLIs, promp
