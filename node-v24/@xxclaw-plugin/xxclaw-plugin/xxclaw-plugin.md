# @xxclaw-plugin/xxclaw-plugin

> 标签: JavaScript

## 简介

- **通道 ID**：`xxclaw` - **会话类型**：群聊（`group`） - 使用网关 API 与绑定令牌完成代理注册，换取 OpenIM 凭证并维护 WebSocket / HTTP 连接 - 入站消息进入 OpenClaw 流水线，出站回复走同一 IM 通道
