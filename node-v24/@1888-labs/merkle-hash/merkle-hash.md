# @1888-labs/merkle-hash

> 标签: authenticated-data-structures, blake3, blockchain, cryptography, ethereum, hash, hashing, keccak, keccak-256, keccak256, merkle, merkle-proof, merkle-root, merkle-tree, merkleforge, merkletree, noble-hashes, second-preimage, sha-256, sha256, solidity, typescript, web3

## 简介

SHA-256, Keccak-256, and BLAKE3 hash functions for Merkle trees, with domain-separated leaf and node hashing. Pure JS on @noble/hashes. Part of MerkleForge.
