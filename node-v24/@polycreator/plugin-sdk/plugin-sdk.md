# @polycreator/plugin-sdk

> 标签: agents, canvas, plugin, polycreator, sdk

## 简介

Plugin SDK for PolyCreator — types + PolycreatorPlugin base class for building third-party renderer plugins (toolbar, agents, canvas events, providers).
