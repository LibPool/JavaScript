# @wanimjs/wanim

> 标签: animation, browser, canvas, manim, math, python, rapydscript, visualization

## 简介

Manim-compatible animation library in TypeScript with a real-time Canvas2D backend, a Python-to-JS compiler bridge and prebuilt browser bundles — one package with subpath exports.
