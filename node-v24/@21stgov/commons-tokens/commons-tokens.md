# @21stgov/commons-tokens

> 标签: accessibility, css-variables, design-system, design-tokens, dtcg, government, wcag

## 简介

Design tokens for Commons, the accessibility-first design system for U.S. local governments. DTCG JSON sources compiled to CSS custom properties with a mathematically guaranteed color-contrast contract.
