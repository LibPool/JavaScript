# procmand

> 标签: cli, cluster, daemon, log-rotation, monitoring, process-manager, process-supervisor, supervisor, zero-dependencies

## 简介

Minimal process manager: long-lived daemon + short-lived CLI talking over a unix socket. Zero runtime dependencies.
