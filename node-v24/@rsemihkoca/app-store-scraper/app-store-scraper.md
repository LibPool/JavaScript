# @rsemihkoca/app-store-scraper

> 标签: app-data, app-store, apple, ios, ipad, itunes, mac, ratings, reviews, scraper, typescript

## 简介

Modern TypeScript library to scrape application data from the iTunes/Mac App Store. Fork with additional features: voteSum, voteCount fields and slice(1) fix.
