# @omniforge/mission-control

> 标签: JavaScript

## 简介

Mission Control is a local-first control panel for running AI coding agents against your own repositories. It turns a request into a scoped ticket, routes that ticket through a workflow, keeps local project memory, and can hand completed work to PR or MR
