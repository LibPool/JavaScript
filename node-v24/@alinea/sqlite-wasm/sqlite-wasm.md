# @alinea/sqlite-wasm

> 标签: JavaScript

## 简介

SQLite compiled to WebAssembly for browsers, workers, edge runtimes, Node.js, and Bun. The package exposes a small `sql.js`-compatible database API and ships both a deflate-compressed Base64 build and a separate Wasm build.
