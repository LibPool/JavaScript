# @cortadel/deepagents

> 标签: agents, ai, cortadel, deepagents, knowledge-graph, langchain, langgraph, llm, memory

## 简介

Cortadel long-term memory for DeepAgents — an AgentMiddleware that recalls before the turn and persists after it, plus search_memory / add_memories tools.
