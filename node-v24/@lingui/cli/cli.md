# @lingui/cli

> 标签: catalog, cli, compile, extract, gettext, i18n, lingui, linguijs, localization, translation

## 简介

Lingui CLI: extracts i18n messages from source code into catalogs and compiles the translated catalogs for the runtime

- 源码仓库：git+https://github.com/lingui/js-lingui.git
