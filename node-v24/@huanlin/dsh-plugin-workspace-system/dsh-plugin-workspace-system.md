# @huanlin/dsh-plugin-workspace-system

> 标签: dsh-plugin

## 简介

按 workspace 注入一段用户编辑的 system 提示词段落（sidebar 面板编辑，同一 workspace 下所有会话共享，保存后下一轮请求生效）。 | Injects a user-edited system-prompt section per workspace (edited from a sidebar panel, shared by every session in that workspace, effective on the next request after save
