# @funny-booth/playwright-profile-mcp

> 标签: JavaScript

## 简介

FUNNY BOOTH playwright-profile MCP: @playwright/mcp を内包proxyし、Chromeプロファイル/ログイン状態(storage-state)管理の4ツール(setup_profile/save_login/list_profiles/switch_profile)を追加。並列 wizard のブラウザ分離用
