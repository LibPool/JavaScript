# cli-kanban

> 标签: agents, claude-code, cli, codex, kanban, markdown, mcp, mcp-server, tickets

## 简介

A kanban board of Markdown files in your repository, for you and your AI coding agents: CLI, MCP server, and a plugin for Claude Code and Codex. No dependencies.
