# @blixis-io/security

> 标签: cors, middleware, rate-limit, security-headers, typescript

## 简介

An optional production baseline for @blixis-io/http: CORS with explicit origins, security headers, rate limiting with a pluggable shared store, and a proxy-aware client address. Plain middleware, nothing on by default.
