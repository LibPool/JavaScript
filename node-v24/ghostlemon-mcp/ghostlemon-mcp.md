# ghostlemon-mcp

> 标签: automation, claude, ghostlemon, linkedin, mcp, model-context-protocol

## 简介

MCP server for the Ghostlemon API: schedule LinkedIn posts, manage automations, and read leads from any MCP client (Claude, Cursor, ...).
