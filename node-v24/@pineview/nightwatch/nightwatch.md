# @pineview/nightwatch

> 标签: JavaScript

## 简介

Easy to use Node.js based End-to-End testing solution for browser based apps and websites, using the W3C WebDriver API.

- 源码仓库：git+ssh://git@github.com/nightwatchjs/nightwatch.git
