# ptp-transplant

> 标签: agent-skill, ai-coding-agent, frontend, migration, prototype, skill, transplant

## 简介

Prototype to Production Transplant: a skill for AI coding agents that connects an approved interactive prototype to an existing production backend, keeping prototype layout authority separate from real data and commands.
