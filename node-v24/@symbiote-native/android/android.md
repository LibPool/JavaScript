# @symbiote-native/android

> 标签: android, host-shim, keyboard, native-module, react-native, settings, symbiote-native

## 简介

SymbioteNative's Android host-shim native modules — re-provide RN host signals (keyboard events, ...) that SymbioteNative's own Fabric surface bypasses. iOS needs none of this; its equivalents are global native observers RN already ships.
