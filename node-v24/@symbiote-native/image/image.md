# @symbiote-native/image

> 标签: angular, expo-image, image, react, react-native, solid, svelte, symbiote-native, vue

## 简介

expo-image wrapped for SymbioteNative — one framework-agnostic core, built once and reachable from the React, Vue, Svelte, Solid, and Angular adapters. The image view with caching, placeholders and SF Symbols, plus the image cache and hash functions.
