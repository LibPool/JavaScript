# @symbiote-native/sensors

> 标签: accelerometer, angular, expo-sensors, gyroscope, pedometer, react, react-native, solid, svelte, symbiote-native, vue

## 简介

expo-sensors wrapped for SymbioteNative — one framework-agnostic core, built once and reachable from the React, Vue, Svelte, Solid, and Angular adapters. Accelerometer, Barometer, DeviceMotion, Gyroscope, LightSensor, Magnetometer, MagnetometerUncalibrate
