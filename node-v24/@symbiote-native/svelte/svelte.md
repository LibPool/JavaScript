# @symbiote-native/svelte

> 标签: android, cross-platform, fabric, ios, react-native, renderer, svelte, symbiote-native

## 简介

SymbioteNative's Svelte adapter — a DOM shim over stock compiled Svelte output driving real native iOS/Android views through the same engine as every other adapter.
