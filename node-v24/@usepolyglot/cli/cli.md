# @usepolyglot/cli

> 标签: agent, ai, cli, coding-agent, llm, local-llm, mcp, ollama

## 简介

A coding-agent CLI that works the same way whether the model is Claude, GPT, or an open-weight model like Qwen, DeepSeek, GLM, or Llama running locally.
