# hardhat-kms

> 标签: aws-kms, azure-key-vault, cloud-kms, ethereum, ethers, foundry, google-cloud-kms, hardhat, hardhat-ignition, hardhat-plugin, hardhat3, hsm, kms, remote-signer, secp256k1, signer, smart-contracts, turnkey, viem

## 简介

Hardhat 3 plugin signing transactions, messages and typed data with keys in AWS KMS, Google Cloud KMS, Azure Key Vault or Turnkey; works with viem, ethers, Ignition and a Foundry-style --kms option.
