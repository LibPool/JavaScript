# @mcpflow.io/mcp-canvas-mcp-server

> 标签: canvas lms, mcp, mcpflow, modelcontextprotocol, server

## 简介

一个用于与Canvas API交互的模型上下文协议（MCP）服务器。该服务器允许您在Canvas内管理课程、作业、注册和成绩。
