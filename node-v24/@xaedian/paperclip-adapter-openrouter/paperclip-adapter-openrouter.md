# @xaedian/paperclip-adapter-openrouter

> 标签: adapter, ai-agent, openrouter, orchestration, paperclip

## 简介

OpenRouter adapter for Paperclip - 300+ AI models (free & paid) via a single API key. External adapter plugin, no Paperclip source patches required.
