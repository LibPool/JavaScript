# @phoenix-plugin-registry/brackets-highlight-multibyte-symbols

> 标签: highlight, multibyte

## 简介

Highlight multibyte symbols and alphabets.(including Show Whitespace by DennisKehrig) NOTE:Please disable Show Whitespace before installation.
