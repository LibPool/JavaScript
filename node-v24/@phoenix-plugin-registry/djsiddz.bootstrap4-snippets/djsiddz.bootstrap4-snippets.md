# @phoenix-plugin-registry/djsiddz.bootstrap4-snippets

> 标签: Bootstrap, Bootstrap 3, Bootstrap 4, Bootstrap Snippets, HTML, HTML Document, Snippets, device, html, screen

## 简介

Add Bootstrap v4.0.0-alpha2 HTML5 Snippets to your page by hitting Ctrl-Shift keys with designated snippets eg. N for navbar etc.
