# @phoenix-plugin-registry/nicolo-ribaudo.brackets-jslint-errors

> 标签: error, explanation, help, info, jshint, jslint, jslinterrors, jslinterrors.com, linting

## 简介

This extension helps you to understand the sometimes cryptic error messages produced by JSLint, JSHint and ESLint, using data from jslinterrors.com.
