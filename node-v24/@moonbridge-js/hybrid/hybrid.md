# @moonbridge-js/hybrid

> 标签: Android, PC, bridge, flutter, hybrid, iOS, js-native, macOS, mobile, windows

## 简介

`moonbridge.js` 是一个服务于 js-native 通信的，使用 JavaScript 语言编写的桥接库，支持与 native 侧进行消息交互。
