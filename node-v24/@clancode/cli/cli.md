# @clancode/cli

> 标签: agent-harness, ai-coding, clancode, cli, coding-agent, developer-tools, local-first, trueforge

## 简介

Local-first TrueForge-supervised AI coding harness — pair with the ClanCode web control plane, run agents in isolated Git worktrees, enforce approvals, validate, and open PRs from your machine.
