# @dakaio/object-storage

> 标签: aws4fetch, cloudflare-r2, exif, minio, object-storage, presigned-url, r2, s3, sharp, upload, webp

## 简介

Objects in Cloudflare R2 or any S3 API through aws4fetch, or in a local folder while developing, behind one small interface: put, get, delete, a whole folder at once, links that expire. Plus a sharp helper that re-encodes an upload without its EXIF.
