# @dakaio/domainscout-mcp

> 标签: bulk, domain, domain-availability, domain-search, mcp, model-context-protocol, naming, rdap, whois

## 简介

Domain research for AI agents: an MCP server that checks hundreds of domain names in one call (DNS, RDAP, WHOIS) and shows prices and where to buy.
