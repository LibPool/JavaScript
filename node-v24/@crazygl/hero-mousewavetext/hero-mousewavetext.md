# @crazygl/hero-mousewavetext

> 标签: animation, canvas, component, crazygl, cursor, frontend, hero, hero-section, interactive, landing-page, mousewavetext, react, three, typography, ui, wave, webgl

## 简介

Mouse Wave Text — A wave travels along the heading following the cursor — each letter pops up as the wave passes, then settles back. Switch to auto mode for a hands-off demo. A customizable CrazyGL animated hero section — WebGL, React, drop-in.
