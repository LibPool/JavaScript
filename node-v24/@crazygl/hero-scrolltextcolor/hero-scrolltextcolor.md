# @crazygl/hero-scrolltextcolor

> 标签: animation, canvas, color, component, crazygl, frontend, hero, hero-section, interactive, landing-page, react, scroll, scrolltextcolor, three, typography, ui, webgl

## 简介

Scroll Text Color — A heading whose colour sweeps from start to end as the user scrolls — uses background-clip:text for crisp gradient handover. A customizable CrazyGL animated hero section — WebGL, React, drop-in.
