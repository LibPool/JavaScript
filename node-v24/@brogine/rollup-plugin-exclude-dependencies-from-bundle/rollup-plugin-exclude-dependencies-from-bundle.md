# @brogine/rollup-plugin-exclude-dependencies-from-bundle

> 标签: bundle, dependencies, exclude, plugin, rollup, rollup-plugin

## 简介

Rollup plugin to automatically add a library's peerDependencies and Dependencies to its bundle's external config.
