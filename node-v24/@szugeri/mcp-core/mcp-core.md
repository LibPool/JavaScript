# @szugeri/mcp-core

> 标签: mcp, model-context-protocol

## 简介

Shared runtime discipline for MCP servers: response envelope, closed error taxonomy, secret-masking stderr logger, stdio guard, fail-closed env config, OAuth 2.0 refresh-token client.
