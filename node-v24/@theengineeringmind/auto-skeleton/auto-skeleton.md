# @theengineeringmind/auto-skeleton

> 标签: a11y, accessibility, content-loader, fallback, loading, loading-placeholder, loading-skeleton, nextjs, placeholder, react, react-component, react-loading-skeleton, react-skeleton, server-components, shimmer, skeleton, skeleton-loader, skeleton-loading, skeleton-screen, ssr, suspense, typescript, ui

## 简介

Automatic skeleton loading screens measured from your real UI. React skeleton component and vanilla JS core with shimmer, SSR and Next.js support. No hand-written skeleton components.
