# @jrc03c/get-audio-file-metadata

> 标签: audio, ffmpeg, flac, m4a, metadata, mp3, node, ogg, wav

## 简介

This utility gets basic audio file metadata in Node. Note that it requires `ffprobe`, which is part of the `ffmpeg` package.
