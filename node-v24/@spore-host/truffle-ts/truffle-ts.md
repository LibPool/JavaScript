# @spore-host/truffle-ts

> 标签: aws, browser, ec2, gpu, instance-selection, instance-types, spore-host, truffle, typescript

## 简介

Browser-native EC2 instance discovery — parse a natural-language query, resolve to instance types, filter, offline. A TypeScript port of the spore.host truffle tool.
