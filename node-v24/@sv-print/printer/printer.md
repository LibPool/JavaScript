# @sv-print/printer

> 标签: airprint, core-printing, cups, custom-paper, electron, ffi, koffi, media, paper, paper-size, print, printer, printing, sv-print, winspool

## 简介

Cross-platform printer and custom paper-size capability bridge for Electron, built on Koffi and a thin native C ABI (Winspool / Core Printing / CUPS). Ships prebuilt binaries per platform and CPU architecture.
