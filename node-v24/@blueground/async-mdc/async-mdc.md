# @blueground/async-mdc

> 标签: async, asynclocalstorage, logger, logging, logs, mapped diagnostic context, mdc

## 简介

Async hooks based Mapped Diagnostic Context, inspired by SLF4J's MDC. Typically used with logging libraries for log enrichment.
