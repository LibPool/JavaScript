# @aimata-dsl/core

> 标签: ai, aimata, ast, code-generation, compiler, dsl, html, jsx, mcp, tailwind, token-compression, ui

## 简介

Token-optimized micro-DSL compiler for AI-assisted UI generation. Compress JSX/HTML/Tailwind into dense DSL and expand back deterministically.
