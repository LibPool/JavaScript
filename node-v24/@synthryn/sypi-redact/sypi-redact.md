# @synthryn/sypi-redact

> 标签: extension, redact, sypi

## 简介

Mask likely secrets in model-visible tool results before they enter the conversation. Use it when command output may contain API keys, tokens, passwords, or other credentials. Primary capability: an automatic result-redaction hook with no separate command
