# @jb7/ngx-virtualscroll

> 标签: angular, ngx, scroll, virtual scroll

## 简介

A lightWeight Angular2+ Virtual Scroll component which reduces the load on DOM by dispalying only those items which are visible in the viewport and loads them dynamically on scroll
