# @memnox/interceptors

> 标签: ai-agents, claude-code, hooks, seam, security

## 简介

The local seams — a PreToolUse hook, a shell wrapper, a git credential helper, an egress proxy and a Docker socket gate — that route what an agent does through Memnox before it happens.
