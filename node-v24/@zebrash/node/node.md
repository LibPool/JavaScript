# @zebrash/node

> 标签: barcode, bun, label, label-printer, node, parser, png, renderer, svg, typescript, zebra, zebra-printer, zebrash, zpl, zpl-ii

## 简介

Render ZPL labels to PNG or SVG on Node.js and Bun. Pure TypeScript port of ingridhq/zebrash.
