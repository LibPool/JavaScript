# @cloud-ru/ds-code-editor

> 标签: JavaScript

## 简介

Обёртка над monaco-editor с темизацией на токенах дизайн-системы, шапкой с языком и кнопкой копирования, async/lazy-загрузкой и JSON/YAML-валидацией по schema.
