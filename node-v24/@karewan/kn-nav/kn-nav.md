# @karewan/kn-nav

> 标签: ajax, history, legacy, navigation, pjax, typescript, vanilla

## 简介

Ajax navigation library (pjax like) for vanilla JS and legacy server-rendered projects that do not use a modern framework like Vue or React, based on KnHttpJs, written in TypeScript
