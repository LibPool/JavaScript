# @tallyrow/safesignal

> 标签: browser, federated, frontend, logging, module-federation, observability, redaction, safesignal, sanitization, secure-by-default, structured-logging, transport

## 简介

SafeSignal — secure structured logging facade and safety boundary for browser applications and federated frontend modules. Browser-first, vendor-neutral, secure-by-default sanitization, redaction, and pluggable transports.
