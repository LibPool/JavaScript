> 标签: 1c, 1c-enterprise, ai, ai-agent, bsl, claude, claude-code, code-index, code-search, cursor, mcp, model-context-protocol, rust, tree-sitter

## 简介

Rust code index MCP server (BSL/1C-aware). Static binary auto-downloaded for your OS. Tree-sitter AST, federation, sub-ms search.
