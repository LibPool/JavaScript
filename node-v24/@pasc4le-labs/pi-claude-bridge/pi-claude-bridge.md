# @pasc4le-labs/pi-claude-bridge

> 标签: claude-agent-sdk, claude-code, extension, pi, pi-package

## 简介

Pi extension that uses Claude Code (via Agent SDK) as a model provider, adds an AskClaude tool, and runs each session as the Claude Code account its directory names (fork of elidickinson/pi-claude-bridge)
