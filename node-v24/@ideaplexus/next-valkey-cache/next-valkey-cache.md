# @ideaplexus/next-valkey-cache

> 标签: cache, cache-handler, isr, next, nextjs, platformatic, redis, valkey, watt

## 简介

A Next.js cache handler on Valkey that keeps serving when Valkey does not answer: a deadline on every call, reconnects, retried invalidations, and Next's file cache when no Valkey is configured.
