# fancy-ui-vue

> 标签: animated-components, animations, component-library, components, motion, tailwind, tailwindcss, ui, ui-library, vue, vue-components, vue3

## 简介

Animated UI components for Vue — the Vue counterpart of fancy-ui-svelte. WebGL, GSAP and CSS motion, styled with Tailwind CSS v4.
