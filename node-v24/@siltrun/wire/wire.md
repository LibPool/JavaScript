# @siltrun/wire

> 标签: binary, codec, game-server, multiplayer, quic, realtime, serialization, silt, webtransport, wire-protocol

## 简介

Silt binary wire codec: a declarative field-type combinator that encodes and decodes from one schema on both sides, for the wire:"binary" tier. Zero-dep, realm-safe.
