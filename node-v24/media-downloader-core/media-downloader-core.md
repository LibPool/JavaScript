# media-downloader-core

> 标签: electron, ffmpeg, integrity-check, media-backup, playlist-archiver, typescript, video-archiver

## 简介

Download engine for heavy workloads (many videos, huge playlists): yt-dlp + ffmpeg on a CPUs/2 worker pool, O(1) hot paths, codec-guaranteed formats and full integrity validation.
