> 标签: bun, cli, cognitive-complexity, complexity, cyclomatic-complexity, lint, typescript

## 简介

Cognitive and cyclomatic complexity checks for TypeScript (and more), configured with an ESLint-style flat config and powered by the cccc Rust engine through bun:ffi
