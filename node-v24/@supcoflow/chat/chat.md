# @supcoflow/chat

> 标签: bug-report, chat, intake, preact, react, supcoflow, widget

## 简介

El chat de intake de Supcoflow, embebible en cualquier sitio: orienta sobre el producto y abre el reporte cuando el problema es un bug.
