# @tracepass/dpp-types

> 标签: circular-economy, digital-product-passport, dpp, espr, eu-regulation, types

## 简介

TypeScript types for EU Digital Product Passports (ESPR) — templates, passports, parties, and traceability events. Types only, zero runtime, zero dependencies.
