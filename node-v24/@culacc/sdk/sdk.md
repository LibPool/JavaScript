# @culacc/sdk

> 标签: audio-editor, cdn, culacc, document-editor, eu, gdpr, image-editor, images, pdf-editor, spreadsheet, storage, uploads, video-trimmer

## 简介

Client for the Culacc API: store files, publish them to the web, serve resized images from EU-hosted storage, and let your visitors edit photos, videos, documents, spreadsheets, slides, PDFs, drawings and audio.
