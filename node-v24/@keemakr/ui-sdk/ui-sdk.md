# @keemakr/ui-sdk

> 标签: JavaScript

## 简介

Product screens for keemakr marketplace modules: a versioned, server-driven UI tree schema plus defineScreen() handlers. Module code never ships to the browser — keemakr-core validates the tree and renders it with platform components.
