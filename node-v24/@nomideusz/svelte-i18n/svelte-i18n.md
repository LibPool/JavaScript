# @nomideusz/svelte-i18n

> 标签: hreflang, i18n, internationalization, locale, routing, runes, ssr, svelte, svelte5, translations

## 简介

Lightweight i18n for Svelte 5 — runes-based locale state, flat JSON messages, {variable} interpolation, URL-locale routing.
