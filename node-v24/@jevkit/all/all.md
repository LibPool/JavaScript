# @jevkit/all

> 标签: calibration, evaluation, jev, llm, system-one, typesafe

## 简介

Tooling for building on TypeSafe's Jev, the first System One model. Installs the whole jevkit ring: record format, linter, drift, benchmark, calibration, and the vitest integration.
