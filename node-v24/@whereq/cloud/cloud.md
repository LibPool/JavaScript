# @whereq/cloud

> 标签: api, autos, cost-of-living, data, finance, fuel-prices, gas-prices, prices, sdk, trending, whereq

## 简介

Official JavaScript/TypeScript SDK for the WhereQ data cloud (api.whereq.cloud) — North-America fuel & gas-station prices, cost-of-living prices, autos, lottery, trending, finance & more.
