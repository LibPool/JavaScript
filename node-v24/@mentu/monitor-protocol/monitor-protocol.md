# @mentu/monitor-protocol

> 标签: agents, claude, cloudevents, epistemic, evidence, mcp, mcp-server, mentu, model-context-protocol, monitor, monitors, observability, provenance, pub-sub

## 简介

An epistemic layer over pub/sub: monitors as enduring daemons that emit evidence with provenance, keep a computed state, and are subscribed to with a durable cursor. CloudEvents envelope, MCP extension door, Nostr-shaped filters, Kafka-shaped delivery.
