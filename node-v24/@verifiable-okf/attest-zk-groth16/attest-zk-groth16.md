# @verifiable-okf/attest-zk-groth16

> 标签: JavaScript

## 简介

Verifiable OKF attestation verifier for the zk-groth16 scheme (Groth16/BN254 via snarkjs). Offline proof verification; bundles the contains_no_pii demo verification key.
