# @wanderwares/medusa-commerce-bundle

> 标签: commerce-bundle, gorgo, integration, medusa, medusa-v2, wanderwares

## 简介

Versioned manifest and configuration helpers for the Wanderwares Medusa integration bundle. Pre-installs released integrations as dormant-by-default, Gorgo-managed plugins.
