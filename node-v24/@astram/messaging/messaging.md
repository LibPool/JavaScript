# @astram/messaging

> 标签: JavaScript

## 简介

Astram framework — email delivery adapters (SMTP over nodemailer; Brevo, SendGrid and Mailgun over plain fetch) behind the @astram/core EmailProvider port. Bounded sends, one jittered retry on transient failures, sanitised errors that never carry a creden
