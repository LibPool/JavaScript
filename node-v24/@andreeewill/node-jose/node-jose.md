# @andreeewill/node-jose

> 标签: crypto, jose, jwa, jwe, jwk, jws

## 简介

A JavaScript implementation of the JSON Object Signing and Encryption (JOSE) for current web browsers and node.js-based servers. Fork of node-jose by Cisco Systems, Inc.
