# @tastic/split-screen

> 标签: couch-multiplayer, expo, layout, local-multiplayer, orientation, react-native, split-screen, two-player

## 简介

Two-player split-screen layout engine for React Native games: device-orientation-aware zone splitting (face-to-face rotate-and-stack vs side-by-side row), which physical side each player lands on, and the fade transition between them
