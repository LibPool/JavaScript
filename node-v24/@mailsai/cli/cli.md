# @mailsai/cli

> 标签: agent, agent-email, ai, cli, email, inbox, mails.ai, mcp, transactional-email, webhooks

## 简介

The mails.ai command line: give AI agents real inboxes, send and receive email, follow events live, forward webhooks to localhost, and add the mails.ai MCP server to Claude, Cursor, Codex or VS Code. Clean JSON when piped, a machine-readable command tree,
