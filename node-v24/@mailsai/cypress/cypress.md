# @mailsai/cypress

> 标签: cypress, cypress-plugin, e2e, email, email-testing, magic-link, mails.ai, otp, verification-code

## 简介

Cypress commands for mails.ai: give each test run its own email address, then wait for the sign-up code or link sent to it.
