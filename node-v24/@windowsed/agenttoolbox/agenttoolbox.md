# @windowsed/agenttoolbox

> 标签: JavaScript

## 简介

Install coding agents and set up Windowsed AI Gateway connections for Claude Code, Codex, Grok Build, OpenCode, OpenClaw, Hermes, Pi Agent Harness, Continue, Aider, Zed, Cline, Roo Code, and Cursor. Linux, macOS, and Windows.
