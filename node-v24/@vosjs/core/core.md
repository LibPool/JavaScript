# @vosjs/core

> 标签: animation, compiler, creative-coding, declarative, deterministic, generative, gsap, motion-graphics, programmatic-video, three, threejs, video, video-engine, video-generation, video-rendering, vos, webgl

## 简介

Programmatic video engine for the web — compile a declarative config into deterministic, resolution-independent motion graphics and video (Three.js, GSAP, 2D, HTML, video). The open engine behind vos.so.
