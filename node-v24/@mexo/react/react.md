# @mexo/react

> 标签: angular, framework, microfrontends, microservices, react, routing, single-page-application

## 简介

Mexo Project is a fork of the [Microzord](https://github.com/taiga-family/microzord) project. The main goal of the fork is to make the project more stable and to add new features. Mexo Project license is Apache 2.0, the same as the original project.
