# @blcrosbie/yadash

> 标签: agent, analytics, bi, claude, dashboard, dashboard-as-code, echarts, embed, skill, static-site, yaml

## 简介

Dashboards as YAML. Validate it, compile it to a static page, host it anywhere - and let an agent maintain the config instead of your JSX.
