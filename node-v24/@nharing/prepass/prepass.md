# @nharing/prepass

> 标签: bm25, claude, claude-code, cli, code-search, codex, coding-agent, context, developer-tools, hook, mcp-alternative, retrieval

## 简介

Stops your coding agent searching from zero. Ranks your repo against the prompt and hands the agent a shortlist of file paths, in ~110ms. No API key, no network call, no index. Works with Claude Code, Codex, and any agent that can run a command.
