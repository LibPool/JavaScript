# @tansr/serve

> 标签: JavaScript

## 简介

tansr Agent 会话引擎 (tansr Agent Session Engine): the bare /v2 agent-session protocol engine (REST + SSE) you embed in your own Node service. Session auth is fully yours via the authenticate seam. This package is not a gateway — auth policy, rate limiting, q
