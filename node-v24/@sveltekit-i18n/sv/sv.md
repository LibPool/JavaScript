# @sveltekit-i18n/sv

> 标签: i18n, sv-add, svelte, sveltekit

## 简介

Svelte CLI add-on that sets sveltekit-i18n up in a SvelteKit project: npx sv add @sveltekit-i18n

- 官网：https://sveltekit-i18n.github.io
- 源码仓库：git+https://github.com/sveltekit-i18n/sv.git
