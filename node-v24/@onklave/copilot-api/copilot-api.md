# @onklave/copilot-api

> 标签: anthropic-compatible, claude-code, ghe, github-copilot, github-enterprise, onklave, openai-compatible, proxy

## 简介

Expose a GitHub Copilot account (github.com or *.ghe.com) as an OpenAI/Anthropic-compatible API server. Connect Claude Code to GitHub Enterprise Cloud Copilot.
