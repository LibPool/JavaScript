# @jungherz-de/notionkit-elements

> 标签: custom-elements, dark-mode, design-system, notion, notionkit, shadow-dom, ui-components, vanilla-js, web-components

## 简介

Vanilla JavaScript Web Components wrapping the NotionKit CSS foundation – <nk-*> custom elements with Shadow DOM, automatic theme sync and native form participation.
