# @kiberon-labs/behave-graph-nodes-ai

> 标签: JavaScript

## 简介

AI nodes for behave-graph: define agents backed by a pluggable LLM provider, drive a back-and-forth conversation, push messages into the chat from the graph, and (next) attach tools the model can call.
