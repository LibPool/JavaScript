# @samyx/repl-openapi

> 标签: api-client, cli, codegen, command-line, fetch, openapi, repl, swagger, tui, typescript

## 简介

Generate @samyx/repl-builder commands (REPL/CLI/TUI) from an OpenAPI schema — a codegen emitter plus a runtime CLI, with pluggable auth
