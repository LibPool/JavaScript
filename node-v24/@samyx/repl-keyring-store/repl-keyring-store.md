# @samyx/repl-keyring-store

> 标签: credentials, keychain, keyring, napi-rs, secrets, token-storage

## 简介

Tiny secret store backed by the OS keychain (@napi-rs/keyring), with a transparent in-memory fallback when the native module is unavailable
