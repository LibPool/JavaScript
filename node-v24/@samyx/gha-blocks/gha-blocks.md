# @samyx/gha-blocks

> 标签: JavaScript

## 简介

Composable, self-describing trigger blocks for @samyx/gha-core: author a rule's trigger as a typed flow (event/debounce/timer/waitFor/first/join) that both executes and draws its own diagram.
