# @samyx/gha-ui

> 标签: JavaScript

## 简介

Bundled Vue dashboard for @samyx/gha-core: configs, filterable event/handler logs (TanStack Table), and a rules -> handlers flow (dagre). Served via Hono as one self-contained page.
