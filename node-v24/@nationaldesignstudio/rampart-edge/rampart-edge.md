# @nationaldesignstudio/rampart-edge

> 标签: browser, classifier, llm, onnx, onnxruntime-web, pii, privacy

## 简介

Rampart Edge — client-side PII gate for AI assistants: deterministic validators + one 1.45 MB ONNX model (onnxruntime-web) that decides BLOCK or ALLOW before a message leaves the browser and marks the PII spans to redact.
