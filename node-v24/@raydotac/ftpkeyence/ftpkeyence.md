# @raydotac/ftpkeyence

> 标签: automation, camera, ftp, industrial, keyence, typescript, vision, vs-series

## 简介

FTP client for Keyence VS series vision cameras. Supports list, download, upload, remove — file and folder — with TypeScript types.
