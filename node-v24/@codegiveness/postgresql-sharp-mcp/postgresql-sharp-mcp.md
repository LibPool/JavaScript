# @codegiveness/postgresql-sharp-mcp

> 标签: database, mcp, mcp-server, postgresql

## 简介

Database-agnostic PostgreSQL MCP server with live discovery and bounded per-call selection. Installs one platform package with the .NET runtime bundled; no .NET installation or runtime downloads required.
