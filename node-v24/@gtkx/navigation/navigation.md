# @gtkx/navigation

> 标签: adwaita, desktop, gtk, gtk4, gtkx, linux, navigation, react, react-navigation

## 简介

React Navigation for GTKX: stack, tab, drawer and master/detail navigators rendered with libadwaita's navigation view, view stack and split views
