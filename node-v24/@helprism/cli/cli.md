# @helprism/cli

> 标签: ci, cli, docs, github-actions, help-center, helprism, knowledge-base, sync

## 简介

Helprism CLI (beta): report shipped changes from CI so the help center gets update suggestions for human review (Helprism sync). Sends file paths and commit messages only, never code.
