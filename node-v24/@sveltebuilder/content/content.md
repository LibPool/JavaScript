# @sveltebuilder/content

> 标签: articles, blog, cms, drizzle, json-ld, news, publishing, rss, sitemap, svelte, svelte5, sveltebuilder, sveltekit

## 简介

Publisher/news domain module for SvelteBuilder — articles, sections, taxonomy, live coverage, newsletters, comments, RSS, sitemaps, and JSON-LD, with a Drizzle schema and i18n built in.
