# @vsirotin/log4ts

> 标签: angular, console, debugging, javascript, log4ts, logging, typescript

## 简介

This library makes it easy and more convenient than console.log etc. to output data about the operation of your TypeScript (e.g. Angular) application to the browser console, dynamically managing this output in real time.
