# @aplus-frontend/axios-core

> 标签: @aplus-frontend/axios-core

## 简介

Based on axios, ts type support is enhanced, and vue3 or react presets are provided by default. Provides a plug-in mechanism that is pluggable and supports expansion of plug-ins that suit your business
