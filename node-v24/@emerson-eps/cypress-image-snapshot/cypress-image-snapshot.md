# @emerson-eps/cypress-image-snapshot

> 标签: JavaScript

## 简介

Cypress Image Snapshot binds [jest-image-snapshot](https://github.com/americanexpress/jest-image-snapshot)'s image diffing logic to [Cypress.io](https://cypress.io) commands.
