# @dmayman/pm-agent

> 标签: agent, claude-code, claude-plugin, github, github-issues, pm, project-management

## 简介

A Claude Code plugin that makes GitHub Issues your source of truth: a PM agent and /pm:* commands that scope ideas into issues, sequence work, and keep coding sessions from colliding.
