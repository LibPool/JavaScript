# @flipzitcg/mcp

> 标签: flipzi, mcp, model-context-protocol, pokemon, prices, tcg, trading-cards

## 简介

MCP server for the Flipzi Data API: TCG card search, prices, sold comps, history and movers for Claude, Cursor and other AI tools. Bring your own Flipzi API key; free tier available.
