# @scdo/plugin-scdo

> 标签: base, eliza-plugin, elizaos, elizaos-plugin, elizaos-plugins, ledger, plugin, scdo, usdc, wallet, x402

## 简介

SCDO x402 for ElizaOS: a per-agent wallet (USDC on Base via x402), signed heartbeats and booked income on the SCDO Agent Ledger, a bookkeeping ledger service.
