# dsh-token-total

> 标签: deepseek-harness, dsh, heatmap, plugin, statistics, token, usage

## 简介

DSH web plugin: token 用量统计看板 + 单会话（主智能体 + 子智能体）用量统计。提供今日/近3天/近7天/近1月/近3月/自定义筛选、六个汇总卡片、活跃热力图、缓存命中率折线与分模型柱状图、按模型/按供应商 Top5 列表。
