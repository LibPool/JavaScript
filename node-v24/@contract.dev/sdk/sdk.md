# @contract.dev/sdk

> 标签: JavaScript

## 简介

A TypeScript/JavaScript SDK for interacting with [contract.dev](https://contract.dev) blockchain stagenets. This SDK provides a simple interface to link contracts, manage deployments, trace transactions, and interact with the contract.dev testing environm
