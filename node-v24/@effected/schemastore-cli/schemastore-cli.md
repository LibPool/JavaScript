# @effected/schemastore-cli

> 标签: cli, draft-07, effect, effected, json-schema, schemastore

## 简介

The schemastore command: build and check SchemaStore-shaped JSON Schema documents from a schemastore.config.ts, with a per-schema published flag and a drift policy.
