# @ciphermarket/sdk

> 标签: JavaScript

## 简介

Framework-agnostic TypeScript SDK for CipherMarket, a privacy-preserving prediction market protocol with CoFHE-encrypted positions, FPMM pricing, oracle resolution, redemption, and Reineira dispute escrow.
