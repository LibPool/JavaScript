# @txco/react-router

> 标签: react-router, react-router-preset, remix, spa, thanks-computer, txco, web-abi

## 简介

React Router preset for Thanks, Computer (txco): after `react-router build`, writes a Web ABI build — build/client as public/, a route-aware SPA fallback as ops/, and txco-web.json — for `txco apply` to install.
