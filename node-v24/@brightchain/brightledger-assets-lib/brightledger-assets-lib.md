# @brightchain/brightledger-assets-lib

> 标签: assets, brightchain, brightledger, browser-safe, ledger, programmable

## 简介

BrightLedger programmable asset layer — browser-safe domain library: typed payloads, canonical serializer, Asset_Id derivation, and SDK constructors.
