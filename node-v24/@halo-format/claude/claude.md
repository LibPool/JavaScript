# @halo-format/claude

> 标签: ai-agents, claude, claude-agent-sdk, halo, mcp, messages-api, tool-results

## 简介

Halo adapter for Claude on two runtimes: the Agent SDK (installHalo — a PostToolUse encode hook + a single in-process halo_fetch MCP tool) and the raw Messages API (@halo-format/claude/raw — createRawHalo, no Agent SDK needed). Tool results become a shape
