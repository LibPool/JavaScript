# @halo-format/langgraph

> 标签: ai-agents, halo, langchain, langgraph, middleware, tool-results

## 简介

Halo host adapter for LangChain agents and LangGraph graphs: a wrapToolCall encode middleware (results become a shape map, out of context) plus a single halo_fetch navigation tool. installHalo() wires it in one call.
