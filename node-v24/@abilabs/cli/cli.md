> 标签: abi, agents, ai-agents, cli, pay-per-call, robinhood-chain, scaffold, usdg, x402

## 简介

The abi command line: scaffold an AI agent that sells a skill per call in USDG (abi init), launch it on Robinhood Chain, check its status, get test USDG.
