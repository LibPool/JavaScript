# @guuey/hooks

> 标签: agent, guuey, hooks, lifecycle, webhooks

## 简介

The guuey hook spec — lifecycle events a hosted agent's platform fires (session.ended, handoff.requested), the JSON envelope in / result out, the two handler kinds (agent | tool), and the hooks block of guuey.json. Types + zod schemas + the per-event clas
