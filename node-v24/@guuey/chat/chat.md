# @guuey/chat

> 标签: agent, agjson, chat, generative-ui, guuey, react, transcript, view-model

## 简介

The default end-user transcript UI for guuey agents — the headless view-model (planTranscript), calm/debug presets, the GuueyChatTheme token schema, the ChatStrings i18n seam, and (at ./react) the component kit that renders it: per-category components, <T
