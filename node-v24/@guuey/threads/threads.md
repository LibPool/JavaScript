# @guuey/threads

> 标签: agent, agjson, guuey, persistence, rehydration, sessions, threads

## 简介

Universal session/thread persistence for AgJSON agents — the ThreadStore contract (append-fold, history, snapshots), the fold↔row mapping, and an in-memory binding. Guuey's hosted runtime is one binding; implement the port against your own store and run t
