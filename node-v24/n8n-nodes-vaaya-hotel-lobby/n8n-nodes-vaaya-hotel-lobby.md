# n8n-nodes-vaaya-hotel-lobby

> 标签: fal, hotel-lobby, minimax, n8n, n8n-community-node-package, vaaya, video-generation

## 简介

n8n community node for the Vaaya Hotel Lobby recipe: put yourself (or you and a friend) into the viral Hotel Lobby performance video, generated with MiniMax H3 on fal.ai using your own fal API key.
