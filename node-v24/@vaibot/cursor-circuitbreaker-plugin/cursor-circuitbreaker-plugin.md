# @vaibot/cursor-circuitbreaker-plugin

> 标签: agent-safety, ai-agents, audit, circuit-breaker, cursor, governance, guardrails, hooks, plugin, provenance, vaibot

## 简介

VAIBot governance plugin for Cursor — intercepts tool calls via Cursor hooks, classifies risk, enforces policy (allow / ask / deny), and creates tamper-evident audit receipts with on-chain provenance anchoring.
