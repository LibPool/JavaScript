# @gavinc-cn/sandbox-path-allowlist

> 标签: cordis, deepseek-harness, dsh, plugin, sandbox

## 简介

沙箱路径白名单: 对配置目录内的 write/edit 沙箱升权请求自动放行, 在 Web 弹框 answerer 之前短路 approval/request 瀑布, 用户不再收到弹框。
