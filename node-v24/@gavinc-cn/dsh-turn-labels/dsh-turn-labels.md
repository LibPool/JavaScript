# @gavinc-cn/dsh-turn-labels

> 标签: JavaScript

## 简介

把 Web GUI 右侧的轮次刻度轨换成常驻文字: 每轮一行显示该轮用户提问, 当前轮高亮, hover 显示提问+回答预览, 点击跳转该轮; 每个 ask_user_question 条目直接显示**用户回答**(一行一个回答, 品牌蓝 accent + 缩进到提问文字的起点, 与提问行区分, hover 出完整问答预览, 点击跳到该提问的位置), 读不到回答(未作答/整题跳过/用户折叠了那一行)时退回原版小横杠。列宽跟着正文栏宽度自适应(无下限, 文字超宽截断), 正文拉宽后不压正文。
