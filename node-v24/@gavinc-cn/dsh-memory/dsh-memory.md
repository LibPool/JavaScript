# @gavinc-cn/dsh-memory

> 标签: JavaScript

## 简介

跨会话记忆插件: 会话首次提交 prompt 时注入两级记忆索引 (agent/pre-step 追加消息), 回合结束按限流提示模型回顾并写入 (agent/turn-stopping + agent.steer); 记忆根 ~/.agents/memory, 与 kimi code / DSH desktop 共用一份。
