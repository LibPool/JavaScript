# @oceanalt/langchain

> 标签: agent-payments, aml, langchain, langchainjs, pre-payment, tool, x402

## 简介

LangChain.js tools and a payment-tool guard: ask OceanAlt about a payee (allow / review / decline) before an agent pays. Fails closed. No keys, no custody. Not affiliated with LangChain.
