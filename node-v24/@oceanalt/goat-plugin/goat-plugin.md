# @oceanalt/goat-plugin

> 标签: agent-payments, aml, eip-3009, goat, goat-sdk, plugin, pre-signing, x402

## 简介

GOAT SDK plugin: check payments, x402 signatures and approvals with OceanAlt before an agent signs them. Two tools, plus an optional wallet-client guard that blocks or asks a human. No keys, no custody. Not affiliated with GOAT.
