# @shoplix-ai/block-kit

> 标签: JavaScript

## 简介

The renderer contract every Block Type renderer is written against: what a renderer receives, how a Block Type is registered with its owner, the closed capability set, and the small helpers renderers share. Contract only, no renderers.
