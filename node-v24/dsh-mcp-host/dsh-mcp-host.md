# dsh-mcp-host

> 标签: browser, deepseek, dsh-plugin, harness, mcp, playwright

## 简介

Expose a stdio MCP server (Playwright, Chrome DevTools, any MCP) as native DeepSeek Harness tools. Host-only, no client bundle.
