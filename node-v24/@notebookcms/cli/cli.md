# @notebookcms/cli

> 标签: JavaScript

## 简介

のーとぶっくCMS の導入の CLI。Next.js のサイトに SDK を組み込み（init）、コードの <T> の文言を取り込みファイルに読み取り（extract）、取り込みファイルで初期データを CMS に取り込み（import）、導入と取り込みの Claude Code のスキルを書き出す（skill）
