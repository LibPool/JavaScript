# @financica/stripe-tax-invoices

> 标签: accounting, fees, invoice, pdf, reverse-charge, stripe, tax-invoice, typescript, vat

## 简介

Parser for the Stripe tax invoice PDF — the monthly invoice for Stripe's own fees, which the Dashboard is the only place to get.
