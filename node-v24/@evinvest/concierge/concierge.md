# @evinvest/concierge

> 标签: JavaScript

## 简介

Host wrappers for the concierge microfrontends: the sign-in dialog, the account page, the account chip and the re-authentication dialog, the sign-in-required and reauth-required hooks, and the session shape. A thin layer over @evinvest/mfe.
