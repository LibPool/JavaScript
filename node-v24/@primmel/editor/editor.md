# @primmel/editor

> 标签: editor, metrology, modelling, oiml, primmel, recommendation, smart

## 简介

The Primmel Studio editor — the model canvas, inspectors, mapper, and review surface for the Primmel v3 kernel. Program layers (OIML SMART first) plug in via the registry; the editor stays program-agnostic.
