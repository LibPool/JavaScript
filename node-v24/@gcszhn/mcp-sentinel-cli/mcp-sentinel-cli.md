# @gcszhn/mcp-sentinel-cli

> 标签: JavaScript

## 简介

Harness-agnostic MCP stdio CLI that acts as a sentinel between any agent and MCP servers — polling long-running tasks on the agent's behalf so that token-costly status loops never enter the LLM inference path
