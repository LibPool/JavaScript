# @jengo/broadcasting

> 标签: broadcasting, codeigniter4, events, jengo, pusher, realtime, soketi, sse, websocket

## 简介

Universal real-time event broadcasting client for Jengo and CodeIgniter 4 supporting Server-Sent Events (SSE) and WebSockets.
