# dsh-ws-deflate

> 标签: compression, deepseek-harness, dsh, dsh-plugin, permessage-deflate, websocket

## 简介

Enable permessage-deflate on DSH's WebSocket transport (/api/remote.mux) without modifying the DSH install tree. Host-only plugin; measured 70.9% fewer wire bytes for a session transcript on one Windows box.
