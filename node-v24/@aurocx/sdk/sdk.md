# @aurocx/sdk

> 标签: JavaScript

## 简介

The AuroCX SDK package enables AuroCX products to be added your applications. An AuroCX product is exported as a wrapped classes that is responsible for initializing shared cross-product functionalities and using specific AuroCX products.
