# @aurigma/color-picker

> 标签: cmyk, color picker, customer's canvas, eye-dropper tool, rgb, web-to-print

## 简介

Color picker component used in Customer's Canvas and other Aurigma's editor. It supports both CMYK and RGB, and eye-dropper tool.

## 官网

- 官网：https://customerscanvas.com
- npm 页面：https://www.npmjs.com/package/@aurigma/color-picker
