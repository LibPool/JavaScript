# @keyring-dev/sdk

> 标签: JavaScript

## 简介

The Keyring SDK runtime: the framework-agnostic request decision, the three onUnavailable modes, per-env resource injection, runInEnv, on-demand policy fill and the telemetry ring buffer. Framework adapters are thin wrappers over this.
