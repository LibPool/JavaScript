# @jsamuel1/cmux-mcp

> 标签: ai-agent, automation, claude, claude-code, claude-desktop, cmux, ghostty, macos, mcp, mcp-server, model-context-protocol, terminal

## 简介

Hardened fork of cmux-mcp: a Model Context Protocol server for controlling the cmux terminal. Adds shell-injection-safe execFile arg passing, read-only/write/dangerous tool annotations, and an updated MCP SDK.
