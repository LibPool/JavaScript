# dsh-logo-color

> 标签: branding, deepseek-harness, dsh, dsh-plugin, theme

## 简介

Recolors the DeepSeek logo across the Web UI - sidebar brand mark, new-session mark, and browser tab icon - from a settings page in this bundle's Plugin Center entry.
