# @wattleaddr/js

> 标签: address, address-autocomplete, address-validation, address-verification, australia, autocomplete, g-naf, geocoding, gnaf, sdk, wattleaddr

## 简介

JavaScript/TypeScript SDK for the WattleAddr address API — Australian address autocomplete & verification, served from Australia. Headless client + drop-in autocomplete widget, zero dependencies.
