# @xzzpig/pi-sentinel

> 标签: audit, guardrail, llm-as-judge, pi, pi-coding-agent, pi-extension, pi-package, sentinel

## 简介

Declarative natural-language sentinel rules for the pi coding agent: side-loop LLM audits on tool calls, tool results, turn/agent boundaries and context thresholds, with blocking gates and background finding injection.
