# @mosaicjs/core

> 标签: JavaScript

## 简介

The Mosaic core: the mosaic-jsx compiler, IR types, validate, resolve, the bounded expr evaluator, the modular block vocabulary (defineBlockSchema, createRegistry, macros), and the Host Manifest.
