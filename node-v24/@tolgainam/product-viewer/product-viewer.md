# @tolgainam/product-viewer

> 标签: 3d, apple, component, ecommerce, framer-motion, gltf, product-page, product-viewer, react, react-component, threejs

## 简介

Apple-style product viewer React component with expandable feature cards, colour variants and media galleries. Renders from a JSON content file. No UI framework dependency.
