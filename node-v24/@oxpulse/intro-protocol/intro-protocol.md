# @oxpulse/intro-protocol

> 标签: chat, contact, crypto, cwe-208, e2ee, introduction, oxpulse, safety-number, timing-safe

## 简介

L2 introduction protocol — Briar-faithful intro crypto (X25519+HKDF+AEAD), JSON+Zod wire codec, and Signal-style safety numbers. Fixes CWE-208 timing oracle in sessionId redundancy check. EXPERIMENTAL (0.1.0).
