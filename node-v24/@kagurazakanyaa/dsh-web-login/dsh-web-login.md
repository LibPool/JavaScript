# @kagurazakanyaa/dsh-web-login

> 标签: deepseek-harness, dsh, dsh-plugin, lan, login, password, systemd

## 简介

Username/password login for the DeepSeek Harness Web UI, so it can be exposed to a LAN without depending on the per-boot launch token.
