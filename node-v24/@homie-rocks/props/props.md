# @homie-rocks/props

> 标签: JavaScript

## 简介

Procedural scenery geometry for three.js: houses, boats, trackside furniture, landforms, rocks, vegetation, trusses and industrial fittings. Each generator takes numbers and an RNG and returns a BufferGeometry.
