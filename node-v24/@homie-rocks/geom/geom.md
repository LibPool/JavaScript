# @homie-rocks/geom

> 标签: JavaScript

## 简介

Procedural geometry for three.js games: chamfered primitives, walls with cut openings, lofts, sweeps, merge and instancing accumulators, route and racing-line maths. It builds triangles; it owns no game content.
