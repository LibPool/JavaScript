> 标签: arabic, ayah, bismillah, comark, editor, hadith, islamic, ligature, markdown, quran, react, waqf

## 简介

A lightweight, beautiful React markdown editor featuring natural Arabic Islamic typography (Ayah brackets, Hadith quotes, and styled ligatures like Bismillah, Jalla Jalaluh, Rub el Hizb, etc.). Built for the Waqf tech ecosystem.
