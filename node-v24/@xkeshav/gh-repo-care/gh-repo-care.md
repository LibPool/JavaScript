# @xkeshav/gh-repo-care

> 标签: GitHub Community Files, community, community health files, discussion templates, gh-repo-care, health files, issues templates, npm cli, npx, open source, repo health check

## 简介

This is a npm CLI tool which help your GitHub repository to make it community supportive by adding necessary health files such as security,support,contribution and custom template for PR,issues and discussions.
