# @flytrap-qa/mcp

> 标签: android, flytrap, ios, mcp, mobile, model-context-protocol, qa, testing

## 简介

MCP server that lets your coding agent read FlyTrap crawl results: bugs with evidence, screen graphs, network hosts, SDKs and build diffs for your own apps.
