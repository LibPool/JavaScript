# @mapled/nuxt

> 标签: cms, headless-cms, mapled, nitro, nuxt, nuxt-module

## 简介

Read published Mapled content in a Nuxt site — a server-side client with a tag cache, the publish webhook (purge the Nitro cache or call a deploy hook), preview, live updates and a Nuxt module that mounts it all.
