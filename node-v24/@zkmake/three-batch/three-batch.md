# @zkmake/three-batch

> 标签: batchedmesh, draw-calls, instancing, lod, meshoptimizer, performance, r3f, react-three-fiber, three, threejs

## 简介

Fewer draw calls and triangles for three.js: culling cells, static bakes, batches that follow moving objects, instance pools, far copies with meshoptimizer. Vanilla three and React Three Fiber.
