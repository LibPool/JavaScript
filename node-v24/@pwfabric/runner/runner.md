# @pwfabric/runner

> 标签: JavaScript

## 简介

pwapp runner — browser ES module that runs a pwpack source envelope at RUNTIME (hash/path router, navigation assembly, PKCE auth bridge) on top of the @pwfabric/embed fat-mode renderer
