# @fronik/envman

> 标签: cli, devtools, dotenv, dotenv-manager, encryption, env, env-management, environment, environment-variables, nodejs, secret-scanner, secrets, security

## 简介

A security-first CLI for environment variable management with AES-256 encryption, secret scanning, health diagnostics, auto-backups, and safe sync.
