# @xauth/react-lock

> 标签: JavaScript

## 简介

xauth 是一个企业级身份认证提供商，其集成了 OAuth、LDAP、OIDC 等多种身份认证和授权解决方案。此仓库包含了 xauth 提供的 React 认证/授权 UI 组件。
