# @handy-common-utils/media-utils

> 标签: aac, asf, audio, ebml, extract, flac, info, matroska, media, mkv, moov, mov, mp3, mp4, mpeg, mpeg transport stream, mpeg-ts, ogg, parse, pcm, stream, video, wav, webm, wmv

## 简介

A pure-JavaScript media info parser and audio extractor for browsers and Node.js that works without FFmpeg, WASM, or external binaries.
