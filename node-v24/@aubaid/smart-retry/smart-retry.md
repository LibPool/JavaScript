# @aubaid/smart-retry

> 标签: api-retry, async-await, axios-retry, backoff-strategy, error-handling, exponential-backoff, failure-logging, fault-tolerance, fetch-retry, http-retry, linear-backoff, network-retry, promise, request-retry, resilience, retry, transient-errors, typescript

## 简介

TypeScript retry library for HTTP requests with exponential/linear backoff, Axios and Fetch integrations, and automatic failure logging for later replay
