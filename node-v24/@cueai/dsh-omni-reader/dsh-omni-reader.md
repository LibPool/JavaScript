# @cueai/dsh-omni-reader

> 标签: cue, deepseek-harness, dsh, dsh-plugin, mcp, omni-reader

## 简介

DSH bundle: registers the audited Cue Omni Reader MCP server so its tools surface as mcp__omni__* in any DeepSeek Harness profile.
