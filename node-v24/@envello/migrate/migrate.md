# @envello/migrate

> 标签: JavaScript

## 简介

Codemod that rewrites Resend SDK usage to the Envello SDK (import statements and client instantiation; method calls like .emails.send()/.emails.batch() are left as-is since Envello's SDK mirrors Resend's shapes).
