# @keystoneui/react

> 标签: JavaScript

## 简介

Accessible React 19 component library built on Base UI and Tailwind CSS v4, distributed as an npm package and a shadcn-compatible registry.

## 官网

- 官网：https://keystoneui.io
- 源码仓库：git+https://github.com/keystone-ui/react.git
- npm 页面：https://www.npmjs.com/package/@keystoneui/react
