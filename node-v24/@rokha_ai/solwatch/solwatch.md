# @rokha_ai/solwatch

> 标签: honeypot, memecoin, rokha, rug-check, solana, token-2022, token-audit, web3

## 简介

Real-data Solana memecoin auditor — freeze/mint authority, Token-2022 honeypots, launch bundles, holders, liquidity. Sister tool to Hoodwatch. Ships a prebuilt Rust binary — no toolchain needed.
