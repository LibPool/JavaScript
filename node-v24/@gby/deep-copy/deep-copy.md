# @gby/deep-copy

> 标签: RegExp copy, clone, copy, deep, deep clone, deep copy, depth, depth copy, duplicate, function copy, loop reference, recursive, recursive clone, recursive copy, 函数拷贝, 引用关系, 循环引用, 拷贝类型, 深克隆, 深复制, 深度克隆, 深度复制, 深度拷贝, 深拷贝

## 简介

deep-copy 深拷贝，可对任意数据进行深度拷贝，包括 函数 function、正则 RegExp、Map、Set、Date、Array、URL 等等；支持含循环引用对象的拷贝，并且不会丢失成员的引用关系 和 类型信息，支持扩展，可根据数据类型定制拷贝逻辑，也可指定拷贝深度；所以，通过它可实现对任意类型的数据进行任意想要的拷贝
