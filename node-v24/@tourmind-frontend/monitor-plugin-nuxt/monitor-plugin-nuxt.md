# @tourmind-frontend/monitor-plugin-nuxt

> 标签: error-tracking, frontend-monitor, nuxt, nuxt-module, nuxt2, sourcemap

## 简介

Nuxt 2 module that captures runtime errors and uploads sourcemaps to a frontend-monitor server.
