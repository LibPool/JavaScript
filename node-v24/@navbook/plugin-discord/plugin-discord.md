# @navbook/plugin-discord

> 标签: bot, chat, discord, git, issues, navbook-plugin, tracker

## 简介

A Discord bridge for the tracker: a thread per pull request and per issue you choose, updates and mentions in it, and commands that comment, review, assign and close as the person who typed them
