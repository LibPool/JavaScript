# @querylens/engine

> 标签: b-tree, buffer-pool, database-internals, education, query-planner, sql

## 简介

QueryLens's toy database engine: a SQL parser, planner, optimizer, buffer pool, B+Tree and lock manager that emits a trace of every step. Pure and deterministic; no DOM, no React.
