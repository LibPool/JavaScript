# @archform/mcp

> 标签: architecture, c4, d2, diagrams-as-code, graphviz, mcp, mermaid, model-context-protocol, plantuml

## 简介

MCP server that renders and validates diagrams as code: Mermaid, PlantUML, C4, Graphviz, D2, Structurizr, BPMN and Excalidraw.
