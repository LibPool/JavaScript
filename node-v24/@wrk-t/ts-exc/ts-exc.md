# @wrk-t/ts-exc

> 标签: dto, error-handling, exception, http, nestjs, openapi, status-codes, swagger

## 简介

Type-safe HTTP exception DTOs for NestJS. 50+ status-code DTOs with Swagger decorators, middleware support, and a built-in generator.
