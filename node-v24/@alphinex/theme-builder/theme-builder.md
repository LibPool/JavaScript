# @alphinex/theme-builder

> 标签: JavaScript

## 简介

Embeddable, no-code editor for @alphinex/theme's semantic tokens — live preview against real ui components, export as CSS custom properties or a ThemeDefinition JSON. See documentation/PRODUCT-RESEARCH-MASTER-PLAN.md §10.1 (Sprint 21).
