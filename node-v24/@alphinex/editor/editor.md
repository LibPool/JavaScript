# @alphinex/editor

> 标签: JavaScript

## 简介

Theme-aware rich text editor (adapter around Tiptap/ProseMirror) + a DOMPurify-sanitized read-only renderer. See ADR-0012 and documentation/PRODUCT-RESEARCH-MASTER-PLAN.md §10 (Sprint 19).
