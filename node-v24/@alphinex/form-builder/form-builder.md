# @alphinex/form-builder

> 标签: JavaScript

## 简介

Embeddable, no-code editor over @alphinex/forms' buildFormFromSchema() — add/reorder/configure fields, live-preview the generated form, export the FieldDefinition[] JSON schema. See documentation/PRODUCT-RESEARCH-MASTER-PLAN.md §10.1 (Sprint 23).
