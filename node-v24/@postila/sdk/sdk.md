# @postila/sdk

> 标签: byob, direct-upload, drag-and-drop, file-upload, image-editor, image-transform, multipart-upload, picker, postila, r2, react, s3, signed-url, upload

## 简介

Postila file uploads: a drop-in React picker, a headless upload client with direct-to-bucket and multipart uploads, an in-browser image editor, image transform URLs, and server helpers for signed tokens and signed delivery URLs.
