# @dialog-fn/react

> 标签: async, await, confirm, confirmation, dialog, drawer, headless, imperative, modal, popup, promise, prompt, react, react-dialog, react-modal, toast, unstyled

## 简介

Promise-based dialogs for React — open a dialog and await the result. Headless, unstyled, ~1 KB, zero dependencies, no providers.
