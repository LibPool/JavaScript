# @customyai/core

> 标签: customy, http, idempotency, retry, sdk

## 简介

Customy SDK core: fetch transport, typed errors, retries with Retry-After, idempotency, pagination, platform discovery and machine tokens. Runs on Node, edge runtimes and browsers.
