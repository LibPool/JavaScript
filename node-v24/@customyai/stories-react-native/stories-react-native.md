# @customyai/stories-react-native

> 标签: customy, react-native, reanimated, stories

## 简介

Customy Stories for React Native: story bar, full-screen viewer, banners, provider and hooks (plus headless mode) on the pure core of @customyai/stories-render. Reanimated + Gesture Handler as peers; video, media cache, storage and Lottie are injectable.
