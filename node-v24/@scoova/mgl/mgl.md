# @scoova/mgl

> 标签: JavaScript

## 简介

Scoova's WebGL map renderer — a fork of MapLibre GL JS v4.7.1 (BSD-3-Clause) with an RTL marker/popup positioning fix applied.

- 源码仓库：git://github.com/Scoova/scoova-mgl.git
- npm 页面：https://www.npmjs.com/package/@scoova/mgl
