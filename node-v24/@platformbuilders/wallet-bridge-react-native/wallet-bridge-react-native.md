# @platformbuilders/wallet-bridge-react-native

> 标签: android, ios, react-native

## 简介

Este repositório contém um pacote React Native para integração com carteiras digitais. Ele atua como uma ponte (bridge) que se conecta aos SDKs nativos de cada carteira, abstraindo a complexidade dos fluxos de provisionamento (Push e App2App). Inicialment
