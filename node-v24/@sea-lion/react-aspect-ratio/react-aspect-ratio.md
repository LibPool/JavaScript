# @sea-lion/react-aspect-ratio

> 标签: JavaScript

## 简介

AspectRatio 是宽高比容器组件，用于保持内容的宽高比显示。无论容器宽度如何变化，内容始终维持指定的宽高比，适用于图片、视频等媒体内容的等比展示。
