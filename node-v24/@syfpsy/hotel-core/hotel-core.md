# @syfpsy/hotel-core

> 标签: astro, design-tokens, geo, hotel, schema-org, seo

## 简介

Design-free core for agency hotel sites: the design-token system, SEO/GEO JSON-LD + meta generators, the hotel config schema, and i18n machinery. Consumed by per-hotel Astro apps; ships raw .ts/.astro (Astro needs no build step).
