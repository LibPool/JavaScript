# pi-keepawake

> 标签: caffeinate, keep-awake, pi-extension, pi-package, prevent-sleep, setthreadexecutionstate, systemd-inhibit, wake-lock

## 简介

Keep the host from idle sleeping while a pi process is running. Blocks system sleep only — display sleep and the lock screen still work.
