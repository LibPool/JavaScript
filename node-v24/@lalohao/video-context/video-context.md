# @lalohao/video-context

> 标签: agents, claude, ffmpeg, mcp, mlx, transcript, video, whisper

## 简介

Turn a video into context an AI agent can use: a local timestamped transcript (whisper.cpp or mlx-whisper), key frames (ffmpeg) and an MCP server to search and read them.
