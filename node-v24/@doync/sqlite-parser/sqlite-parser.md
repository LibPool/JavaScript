# @doync/sqlite-parser

> 标签: ast, parser, sql, sqlite, typescript

## 简介

Native TypeScript SQLite SQL parser: a typed, visitable AST with JSON serialization, SQL unparsing, and tolerant parsing. Zero dependencies.
