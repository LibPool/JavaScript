# dsh-intellij-mcp

> 标签: deepseek-harness, dsh, dsh-plugin, ide, intellij, jetbrains, mcp

## 简介

IntelliJ IDEA MCP bridge for DeepSeek Harness: connects to the IDE's built-in MCP server over stdio (idea stdioMcpServer) and registers its tools as mcp__intellij__*, with a settings page for the connection
