# @gamerelay/sdk

> 标签: ai, browser-games, entity-sync, game-server, gamedev, host-migration, html5-game, kaplay, llm, lobby, matchmaking, multiplayer, netcode, phaser, pixi, realtime, relay, threejs, websocket

## 简介

Multiplayer for browser games without a server: rooms, entity sync with smoothing, host migration, chat and leaderboards. Zero dependencies.
