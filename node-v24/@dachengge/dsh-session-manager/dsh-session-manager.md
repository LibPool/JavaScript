# @dachengge/dsh-session-manager

> 标签: dsh, dsh-plugin, dshm, harness, session

## 简介

DSH 会话管理插件（dshm）：设置页「会话管理」面板 + 3082 端口上的完整 dshm 界面（会话列表/全文搜索/每步 token 趋势/导出/归档）。
