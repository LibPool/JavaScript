# @macroforge/typescript-plugin

> 标签: derive, language-service, macros, plugin, tsserver, typescript

## 简介

TypeScript language service plugin that augments classes decorated with @derive to include macro-generated methods.

- 官网：https://macroforge.dev
- 源码仓库：git+https://gitlab.com/macroforge-ts/macroforge-ts.git
