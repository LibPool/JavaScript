# @4quays/mcp

> 标签: 4quays, crypto, mcp, model-context-protocol, post-quantum, signing

## 简介

4Quays MCP server — gives an agent sign, verify, encrypt-for, and decrypt as native tools. The agent API key lives in the server env, never in the conversation.
