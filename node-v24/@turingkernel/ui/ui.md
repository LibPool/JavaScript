# @turingkernel/ui

> 标签: accessibility, components, design-system, radix-ui, react, shadcn, tailwindcss, wordpress

## 简介

Accessible React components for Tailwind CSS 4, built on Radix: typed, documented, tested in Vite, Next.js and the WordPress admin, with a theme, a strings provider and a contrast check.
