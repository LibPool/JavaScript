# @tvuikit/fps-react

> 标签: dom, fps, hud, react, tv, tvkit

## 简介

DOM-based React FPS HUD overlay. Works in any render path (DOM, Pixi, mixed); pairs with @tvuikit/fps for the underlying measurement.
