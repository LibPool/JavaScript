# @youcraft/recall-structured

> 标签: ai, crud, data-extraction, intent-detection, llm, memory, recall, schema, sql, sqlite, structured-data, typescript, zod

## 简介

Schema-based structured memory for AI applications. Define Zod schemas, let the LLM handle intent detection, data extraction, and CRUD operations with precise SQL queries.
