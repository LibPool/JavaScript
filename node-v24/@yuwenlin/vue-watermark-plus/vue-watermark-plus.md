# @yuwenlin/vue-watermark-plus

> 标签: canvas, directive, vue, vue2, vue3, watermark, 指令, 水印

## 简介

Vue2 / Vue3 通用水印指令，支持多行文本、高清适配、防误删、自适应重排、全页水印、工厂函数与命令式 API
