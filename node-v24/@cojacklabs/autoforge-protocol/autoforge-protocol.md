# @cojacklabs/autoforge-protocol

> 标签: JavaScript

## 简介

`@cojacklabs/autoforge-protocol` contains the versioned, model-independent contracts exchanged between AutoForge Core, agents, SDKs, and hosted clients. It performs no filesystem, Git, network, credential, or provider I/O.
