# @cojacklabs/autoforge-core

> 标签: JavaScript

## 简介

`@cojacklabs/autoforge-core` contains deterministic, model-independent project intelligence and orchestration policy. External effects are supplied through the interfaces exported from `@cojacklabs/autoforge-core/ports`.
