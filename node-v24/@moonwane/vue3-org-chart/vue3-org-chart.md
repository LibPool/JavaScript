# @moonwane/vue3-org-chart

> 标签: hierarchy, org chart, tree, vue

## 简介

Forked from n1crack/vue3-org-chart. Vue3 Org Chart is a tree diagram that visualizes the structure of an organization and the relationships and relatives. It is a Vue 3 component.
