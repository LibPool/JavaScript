# @vcp-test/site-edit-engine

> 标签: JavaScript

## 简介

VCP 的源码级 site edit 引擎。它读取 snapshot 或项目文件，构建 render document / object detail，并把高层编辑操作规划为 patch plan 或直接执行到预览工作区。
