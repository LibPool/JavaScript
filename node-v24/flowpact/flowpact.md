# flowpact

> 标签: ci, composite-actions, contracts, github-actions, linter, matrix, reusable-workflows, sarif, secrets, semver, static-analysis, workflow-call

## 简介

Data-flow linter for GitHub Actions: grades releases of shared workflows and actions against their callers, checks calls into other repositories, and finds values that arrive empty.
