# @zerossr/skill-keeper

> 标签: ai-agent, claude, claude-code, codex, cursor, skill, skill-manager, skm

## 简介

skm — 通用 AI skill 库管理器。一个命令管住所有引擎的 skill：init/list/sync/doctor/engines/create/remove/info/validate，跨引擎同步（Claude Code / Cursor / Qoder / Antigravity / Codex / Cline / Windsurf / Copilot / Aider）。
