# @jacob-ebey/react-server-dom-vite

> 标签: react

## 简介

React Server Components bindings for DOM using Vite. This is intended to be integrated into meta-frameworks. It is not intended to be imported directly.

- 源码仓库：git+https://github.com/facebook/react.git
