# @mukundakatta/agentvet

> 标签: agent, ai, anthropic, llm, mcp, openai, schema, tool-args, tool-use, validation, zod

## 简介

Validate LLM-generated tool args before execution. Wrap your tools with a schema; throws ToolArgError with an LLM-friendly retry hint when the model hallucinates wrong types. Zero deps.
