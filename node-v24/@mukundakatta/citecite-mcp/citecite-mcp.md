# @mukundakatta/citecite-mcp

> 标签: citations, llm, markers, mcp, rag

## 简介

MCP server for RAG citation marker [1] [2] injection, parsing, and stripping. Helps LLMs round-trip citations in retrieval-augmented outputs.
