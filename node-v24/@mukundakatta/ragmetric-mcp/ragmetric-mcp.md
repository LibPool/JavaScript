# @mukundakatta/ragmetric-mcp

> 标签: evaluation, ir, mcp, metrics, mrr, ndcg, rag

## 简介

MCP server for RAG retrieval evaluation metrics: Recall@k, Hit@k, MRR, NDCG@k. Helps LLMs score retrieval quality.
