# @writavo/mcp-server

> 标签: blogging, cms, content-api, headless-cms, mcp, model-context-protocol, writavo

## 简介

MCP server for the Writavo Content API. Sign in from the browser, import an existing blog, and draft, edit, organise, schedule and publish a Site's content from any AI assistant, with tools generated from the published OpenAPI specification.
