# @thelacanians/tuimark

> 标签: agents, ai-agents, bun, cli, css, declarative, layout, markup, terminal, tui, tuimark, typescript, ui

## 简介

Tuimark for npm: the `tuimark` command (validate, dump, play, run terminal UIs written as .tui markup) and a TypeScript client to drive a view from Bun over `tuimark host`.
