# @1587causalai/configurable-personal-fs-server

> 标签: ai, configurable-server, filesystem, mcp, model-context-protocol, personal-documents

## 简介

一个高度可配置的个人文件系统MCP服务器，具有上下文感知AI交互能力。允许通过命令行参数动态配置根目录，或默认为当前工作目录。
