# @idsh/mobile

> 标签: bundle, client, cordis, deepseek-harness, dsh, mobile, touch

## 简介

The touch-device half of a dsh Web profile: coarse-pointer CSS, Enter inserting a line break instead of sending, and an iOS home-screen icon — the things the self-hosted image carried as build-time patches
