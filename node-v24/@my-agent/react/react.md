# @my-agent/react

> 标签: JavaScript

## 简介

`@my-agent/react` 是 React SDK 的运行时包，负责客户端、上下文、主题容器、钩子与绑定运行时的 Agent 组合层组件。纯展示原语由 `@my-agent/ui` 提供。
