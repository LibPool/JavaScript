# @usenarrator/plugin-sql

> 标签: JavaScript

## 简介

TS plugin: SQL embedded in TS/JS (postgres.js, Bun.sql, pg, better-sqlite3, bun:sqlite, Prisma raw, kysely/slonik/Neon templates).
