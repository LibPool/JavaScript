# @andares/pi-toolkits

> 标签: approval, ask-mode, autostart, boundary, code-review, compact-model, compaction, model-favorites, permission, pi, pi-coding-agent, pi-extension, pi-package, prompt-stash, readonly, toolkit

## 简介

Integrated toolkit extension for pi — ask mode (read-only Q&A), session-scoped permission checks, model favorites, prompt stash, third-party code review, session autostart, and a dedicated compaction model
