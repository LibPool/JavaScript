# dsh-collapse-paste

> 标签: collapse, composer, deepseek-harness, dsh, dsh-plugin, paste, transcript

## 简介

Fold multiline pastes in the DSH composer into an inline chip, and long sent messages into a collapsible transcript row; the full text is always sent to the model unchanged.
