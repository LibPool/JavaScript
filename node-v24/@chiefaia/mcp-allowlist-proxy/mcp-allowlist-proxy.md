# @chiefaia/mcp-allowlist-proxy

> 标签: JavaScript

## 简介

Deterministic command-allowlist proxy in front of an MCP server. Pins the upstream commit SHA, wraps spawn in macOS sandbox-exec, and rejects any tool call not on the policy allowlist before forwarding.
