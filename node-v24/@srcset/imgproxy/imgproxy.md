# @srcset/imgproxy

> 标签: image, imgproxy, responsive, srcset

## 简介

Adapter for imgproxy: srcset variant urls for content images, e.g. from an API or a CMS.

## 官网

- 官网：https://srcset.js.org/proxies/imgproxy/
- 源码仓库：https://github.com/TrigenSoftware/srcset.git
- npm 页面：https://www.npmjs.com/package/@srcset/imgproxy
