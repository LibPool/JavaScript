# react-native-mapsforge-vtm-ext-grib

> 标签: android, grib, maps, mapsforge, offline, react-native, vtm, weather

## 简介

Weather GRIB overlay extension for react-native-mapsforge-vtm. Renders gridded weather data (wind, temperature, pressure, etc.) as colored overlays on offline vector maps. Android only.
