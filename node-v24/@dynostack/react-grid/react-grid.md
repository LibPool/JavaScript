# @dynostack/react-grid

> 标签: ag-grid, data-grid, data-table, dynostack, dynostack-grid, editable, export, filters, radix, react, react-grid, shadcn, tailwind, tanstack-table

## 简介

Dynostack React Grid: an open-source React data table built on TanStack Table, Radix UI and Tailwind CSS, with advanced filters, inline editing, column controls, CSV/Excel export, themes and i18n.
