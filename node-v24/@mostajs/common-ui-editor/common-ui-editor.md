# @mostajs/common-ui-editor

> 标签: crud, editor, html, mostajs, theme, ui, ui-html-stack

## 简介

Éditeur CRUD de thèmes (HTML-string, zéro dépendance) : grille presets/personnalisés + création/configuration (color pickers) + aperçu live + export JSON. Produit des thèmes lus par @mostajs/common-ui. Compose @mostajs/common-ui + @mostajs/app-shell-ui. M
