# @mostajs/doc-driver-pandoc

> 标签: doc-export, driver, mostajs, no-build, pandoc, powerpoint, pptx, slides

## 简介

Driver PPTX (diaporama PowerPoint) pour @mostajs/doc-export via pandoc — pandoc consomme le Markdown source (--slide-level=2), reprise de la voie md2View. `run` injectable (testable sans pandoc) ; gabarit PPTX optionnel (--reference-doc). Aucune dépendanc
