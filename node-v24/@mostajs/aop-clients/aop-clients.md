# @mostajs/aop-clients

> 标签: JavaScript

## 简介

Clients de l'agence + Veilles spécifiques (ORM-first). La Veille est compatible avec l'orchestrateur aop-scheduler (active/run/markRun). Réutilise aop-alerts (matching).
