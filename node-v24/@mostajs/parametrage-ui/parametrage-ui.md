# @mostajs/parametrage-ui

> 标签: admin, html, mostajs, no-react, parametrage, schema-form, server-side, settings-ui

## 简介

Écrans HTML du paramétrage d'une instance (@mostajs/parametrage), sans React ni script : formulaire d'une section par groupes (@mostajs/schema-form), secrets en écriture seule avec empreinte, provenance des valeurs (départ, données, saisie, locataire, .en
