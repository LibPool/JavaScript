# @mostajs/file-export

> 标签: csv, dialect, docx, excel, export, file, html, mostajs, ods, openoffice, pdf, xlsx

## 简介

Export de données structurées (titre + items + champs + liens) vers des fichiers — un DIALECTE par format (façon dialects @mostajs/orm) : html, csv, pdf, docx, ods (OpenOffice/Calc), xlsx (Excel). html/csv sans dépendance ; pdf/docx/tableurs via drivers o
