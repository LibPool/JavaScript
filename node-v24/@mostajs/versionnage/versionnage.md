# @mostajs/versionnage

> 标签: audit, chaine-empreintes, date-effet, historique, immuable, mostajs, versioning, versionnage

## 简介

Versions datées, immuables et chaînées d'un objet JSON quelconque (grille de tarifs, identité, réglage, barème) : publier, version courante, version en vigueur un jour donné, versions à venir, restaurer, écarts entre versions, preuve d'intégrité par chaîn
