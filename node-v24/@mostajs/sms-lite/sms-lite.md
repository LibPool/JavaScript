# @mostajs/sms-lite

> 标签: broadcast, gateway, lite, mostajs, notifications, sms, transport, zero-dependency

## 简介

Transport SMS minimal ZÉRO-DÉPENDANCE (drivers façon dialectes : console + passerelle HTTP via fetch). Pendant SMS de @mostajs/smtp-lite. S'enregistre comme canal de @mostajs/broadcast (smsBroadcastChannel).
