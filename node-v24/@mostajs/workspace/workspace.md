# @mostajs/workspace

> 标签: apache2, cli, dev, mostajs, multi-env, nextjs, pm2, prod, scaffold, test, workspace

## 简介

Scaffold multi-env workspace (dev/test/prod) pour les apps de l'écosystème @mostajs. CLI init + promote + status, templates Apache2 + pm2 + Next.js basePath, bootstrap chaîné des modules mostajs.
