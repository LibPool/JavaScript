> 标签: css-variables, dark-mode, design-system, design-tokens, dtcg, figma, tailwind, tailwind-v4, tailwindcss, theming, tokens-studio, usva, w3c-design-tokens

## 简介

The token layer for usva: semantic role tokens, three themes, a Tailwind v4 theme.css, and W3C DTCG plus Tokens Studio exports for Figma.
