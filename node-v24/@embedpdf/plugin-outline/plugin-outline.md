# @embedpdf/plugin-outline

> 标签: JavaScript

## 简介

Document-scoped outline (bookmarks): the document's outline mirrored from the engine with this session's pending edits shown, which items are expanded and selected, the item for the reading position, activation, and create, update, move and delete as undo
