# @smuit/text-field

> 标签: form, input, material, material-design, mui, svelte, svelte5, text-field

## 简介

Material Design 3–style single-line text field for Svelte 5 — filled · outlined, floating label, prefix/suffix + icons, and a character counter, on smuit design tokens.
