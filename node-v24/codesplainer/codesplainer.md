# codesplainer

> 标签: acp, ai, architecture, claude-code, codebase, codex, diagrams, kiro

## 简介

Understand any codebase through small, expandable diagrams generated by your local AI coding agents (Kiro CLI, Claude Code, Codex, any ACP agent).
