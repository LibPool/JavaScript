# @manzhixing/web-storage-adapter

> 标签: LocalStorage, SessionStorage, storage

## 简介

用于适配 Web 存储的适配器, 将 LocalStorage 和 SessionStorage 的接口转换为统一的接口, 以便于使用和管理
