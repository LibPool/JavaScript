# @sproutboat/cli

> 标签: cli, deploy, edge, porffor, serverless, sproutboat, wrangler

## 简介

Wrangler-shaped CLI for Sproutboat — works against any control plane (self-hosted or cloud) via --api-url / SPROUTBOAT_API_URL.
