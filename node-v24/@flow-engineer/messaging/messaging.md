# @flow-engineer/messaging

> 标签: agents, ai-agent, chatbot, flow-messaging, imessage, llm, mcp, messaging, telegram, webhooks, whatsapp

## 简介

Flow Messaging SDK: let an AI agent talk with people on WhatsApp, Telegram and iMessage through one API. Typed client, live event stream, webhook verification, LLM stream to message bubbles, and a CLI with an MCP bridge.
