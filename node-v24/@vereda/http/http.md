# @vereda/http

> 标签: backoff, bulkhead, bun, circuit-breaker, cloudflare-workers, fault-tolerance, fetch, http, http-client, opentelemetry, queue, rate-limit, rate-limiting, resilience, retry, retry-budget, timeout, typescript

## 简介

Resilient fetch for Node.js, Bun and Cloudflare Workers: retries, backoff, timeouts, per-host bulkheads, circuit breakers, retry budgets and rate limits, with typed results. Zero dependencies.
