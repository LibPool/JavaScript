# @lemonadejs/babel-plugin-jsx-lemonadejs

> 标签: babel, babel-plugin, jsx, lemonadejs, template-literal, transform

## 简介

A Babel plugin to transform JSX syntax into a tagged template literal syntax for use with LemonadeJS.
