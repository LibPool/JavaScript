# @portbay/swc-plugin-loc

> 标签: devtools, jsx, nextjs, portbay, source-location, swc-plugin, tsx, turbopack, visual-editor

## 简介

Dev-time SWC plugin that stamps each JSX host element with its authored source location (data-pb-loc) for PortBay's visual editor. SWC/Turbopack parity with @portbay/babel-plugin-loc — covers Next.js App Router.
