# n8n-nodes-mci-db-backup

> 标签: backup, dump, mariadb, mysql, n8n, n8n-community-node-package, zip

## 简介

n8n community node: dump a MySQL/MariaDB database to a .sql file (mysqldump-style, pure SQL) and zip it. Replicates the MCI DB backup workflow.
