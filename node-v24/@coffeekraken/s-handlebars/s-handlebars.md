# @coffeekraken/s-handlebars

> 标签: JavaScript

## 简介

Handlebars utility package that export a "registerHelpers" function which will register helpers on your handlebars instance like "length", "replace", "sort", and a lot more...

## 官网

- 官网：https://coffeekraken.io
- npm 页面：https://www.npmjs.com/package/@coffeekraken/s-handlebars
