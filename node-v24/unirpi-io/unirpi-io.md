# unirpi-io

> 标签: gpio, mock, raspberry-pi, rpi, rpi-io, unirpi-io

## 简介

A mock implementation of RPI-IO (by gdorbes) to use a fake instance of Raspberry Pi GPIO's on any platform for Node.js
