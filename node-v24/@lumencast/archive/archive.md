# @lumencast/archive

> 标签: archive, lsml, lsmlz, lumencast

## 简介

LSMLZ/1 archive packer + unpacker. Read and write the single-file ZIP container that carries an LSML scene bundle plus its content-addressed assets. Includes a conformance runner against the LSMLZ/1 case suite.
