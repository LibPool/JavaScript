# @mcp-lens/presets

> 标签: lens-presets, mcp, mcp-lens

## 简介

Reference library of moment-shaped lens presets for MCP Lens. Compiled at build time from ../../presets/<domain>/*.md. Authored as markdown; consumed as typed TypeScript exports per domain.
