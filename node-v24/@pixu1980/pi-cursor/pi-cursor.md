# @pixu1980/pi-cursor

> 标签: api-key, cursor, cursor-sdk, extension, pi, pi-coding-agent, pi-package, provider

## 简介

Cursor API key provider for pi.dev - run Cursor local agents from pi using your own Cursor API key, stored only on your machine, with an audited egress surface (Cursor endpoints only)
