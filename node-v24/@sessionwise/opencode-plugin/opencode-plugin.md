# @sessionwise/opencode-plugin

> 标签: ai-coding, opencode, opencode-plugin, session-tracking, sessionwise

## 简介

SessionWise plugin for opencode — captures tool usage and chat messages into the SessionWise knowledge base via the local sessionwise CLI.
