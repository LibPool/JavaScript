# grokbot-cli-mcp

> 标签: claude-code, cli, coding-agent, grok, mcp, model-context-protocol, pi, xai

## 简介

Grok coding agent for your terminal (built on pi) and an MCP server so Claude Code can use Grok: X/web search, vision, image/video generation and full agent delegation.
