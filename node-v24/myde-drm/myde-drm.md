# myde-drm

> 标签: dma-buf, drm, egl, electron, gpu, pixel-format, rgba, wayland

## 简介

Convert DRM dma-buf pixel formats (XRGB, XBGR, RGBX, BGRX, ...) for Electron on GPU or CPU
