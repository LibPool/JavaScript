# pladar-agent-linux-x64

> 标签: ai-agent, air-gapped, hermes-agent, offline-install, pladar-agent, unofficial

## 简介

Self-contained Linux x64 runtime for pladar-agent: unofficial packaging of Hermes Agent 0.22.2 (MIT, (c) Nous Research). Payload ships as small npm chunk packages (for networks that abort large downloads); assembles, verifies (SHA-256) and unpacks on firs
