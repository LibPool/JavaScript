# @strongkeep/core

> 标签: JavaScript

## 简介

Shared trust-boundary primitives for the StrongKeep AI Security feed: entry schema, closed ConstrainedAction enum, Ed25519 sign/verify, unsigned-index builder, and consumer-side verified-feed serving. Imported by both the private forge (produces + signs)
