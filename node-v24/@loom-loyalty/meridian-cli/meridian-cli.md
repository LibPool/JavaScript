# @loom-loyalty/meridian-cli

> 标签: JavaScript

## 简介

Developer CLI for the Meridian protocol. Scaffolds Cloudflare adopter projects, mints admin tokens, runs diagnostics, and talks to the admin surface exposed by @loom-loyalty/meridian-runtime-cloudflare.
