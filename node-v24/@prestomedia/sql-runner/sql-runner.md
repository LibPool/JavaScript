# @prestomedia/sql-runner

> 标签: database, lexical-scoping, mysql, mysql2, mysql2-promise, scope-masking, sql, transaction, transaction-management, typescript, wrapper

## 简介

A lightweight transaction-masking wrapper around mysql2/promise that safely handles inline database expressions.
