# computer-use-turbo

> 标签: accessibility, ai-agents, claude-code, codex, computer-use, desktop-automation, mcp, model-context-protocol

## 简介

MCP server that lets any AI agent operate the desktop apps on macOS, Windows and Linux, in the background and safely. Needs the Computer Use Turbo helper app.
