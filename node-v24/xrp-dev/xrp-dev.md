# xrp-dev

> 标签: cloudflare-workers, codec, ed25519, edge, effect, ripple, secp256k1, workerd, xrp, xrpl

## 简介

XRPL SDK for workerd, Bun, browsers and Node. The main entry holds no keys; wallets are xrp-dev/wallet and the MCP server is xrp-dev/mcp.
