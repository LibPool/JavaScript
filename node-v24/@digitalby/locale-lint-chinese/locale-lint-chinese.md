# @digitalby/locale-lint-chinese

> 标签: chinese, ios, locale-lint-plugin, localization, opencc, simplified, traditional, xcode

## 简介

Chinese (Simplified vs Traditional) script-contamination plugin for @digitalby/locale-lint. OpenCC-backed character-exclusivity detection across zh-Hans / zh-Hant / zh-HK / zh-TW / zh-MO / zh-CN / zh-SG locales.
