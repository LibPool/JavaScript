# @ryuz/utevo

> 标签: bun, html, json, llm, markdown, parser, sanitize, typescript

## 简介

Utevo is a simple TypeScript library for parsing HTML to Markdown and JSON, sanitizing and preserving only semantic structure tags. Ideal for preprocessing HTML for LLMs.
