# @waysnx/ui-kit-coverage

> 标签: adoption, ast, cli, coverage, react, static-analysis, ui-kit, waysnx

## 简介

Deterministic, read-only analyzer that reports how much of a React/TypeScript application uses the WaysNX UI Kit — adoption, utilization, native/custom UI, and replacement candidates. No AI, no network.
