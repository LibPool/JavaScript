# @research-ag/duel-game-core

> 标签: canister, dfinity, game, icp, internet-computer, motoko, multiplayer, turn-based, two-player

## 简介

Rules-agnostic client for a duel-game-core game: session identity, polling transport, a headless client, and default lobby/staging/rematch/debrief screens any of which a game can replace.
