# @hookraft/use-key-cursor

> 标签: animation, cursor, hooks, keyboard, modal, nextjs, react, typescript, ux

## 简介

Animate a circle cursor to a target element when a keyboard key is pressed. Perfect for closing modals, confirming forms, and keyboard-driven UX that feels alive.
