# @mavis-pet/broker

> 标签: agent-companion, desktop-pet, mavis, petdex

## 简介

Mavis Pet broker — receives mavis hook events over HTTP, maintains per-session state machine, pushes aggregated pet animation state to floater clients via WebSocket.
