# @s2script/eslint-plugin

> 标签: JavaScript

## 简介

s2script residual safety rules — the small, local checks the type system cannot carry (no-ctx-escape, no-floating-promise-in-factory, no-bigint-in-interface-payloads, no-await-in-raw-view). Pinned by @s2script/sdk so the SAME engine+rules run in the edito
