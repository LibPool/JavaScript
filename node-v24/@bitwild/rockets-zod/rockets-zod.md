# @bitwild/rockets-zod

> 标签: JavaScript

## 简介

Zod-first resource layer for Rockets — compiles a zod schema into nestjs-zod DTOs + a defineResource() call. Database-agnostic: entity generation is delegated to a SchemaEntityCompiler adapter.
