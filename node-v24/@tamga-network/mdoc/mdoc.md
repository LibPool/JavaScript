# @tamga-network/mdoc

> 标签: JavaScript

## 简介

ISO/IEC 18013-5 mdoc (mobile document) minimal profili: deterministik CBOR, COSE_Sign1, MobileSecurityObject ihracı ve doğrulaması, cihaz imzası, OpenID4VP/DC API oturum dökümü (18013-7) ve yakın alan sunumu (cihaz tanıtımı, oturum şifrelemesi, BLE ileti
