# @sbugallo/opencode-vpet

> 标签: opencode, plugin, tui, virtual-pet, vpet

## 简介

An OpenCode virtual-pet plugin with /vpet-spawn, /vpet-freeze, /vpet-unfreeze, /vpet-set, /vpet-dex, and /vpet-history commands.
