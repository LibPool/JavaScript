# @lynniemagoo/adafruit-st7735-library

> 标签: adafruit, display, i2c, node, pi, raspberry, raspi, rpi, spi, st7735, st7789, tft

## 简介

NodeJS Promise-based port of C/C++ Adafruit-ST7735-Library from Github - Library for Family of ST77XX TFT displays including ST7735, ST7789.
