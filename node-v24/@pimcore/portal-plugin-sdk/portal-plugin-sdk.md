# @pimcore/portal-plugin-sdk

> 标签: JavaScript

## 简介

Types for the portal plugin contract. A plugin imports this package name and gets the RUNTIME over Module Federation -- the host exposes it, and a plugin names this package as its remote key. The package itself ships types only. Deliberately ships no Java
