# @enconvert/node-sdk

> 标签: anything-to-markdown, anything-to-pdf, api, compress-image, conversion, document-convert, docx-to-pdf, enconvert, heic-to-webp, html-to-pdf, image-compression, image-convert, markdown, pdf, rag, screenshot, sdk, svg-to-png, url-to-markdown, url-to-pdf, url-to-screenshot

## 简介

JavaScript / TypeScript SDK for EnConvert: read any page or file into agent-ready Markdown, JSON, or screenshots (scored 0.0-1.0), compress images, and convert documents. V2 perception + MCP.
