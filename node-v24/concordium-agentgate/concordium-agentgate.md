# concordium-agentgate

> 标签: a2a, agent-identity, agent-registry, agent-verification, ai-agents, cis-8004, concordium, erc-8004, mcp, mcp-server, middleware, model-context-protocol, trust, verification, x402

## 简介

AI agent identity verification for MCP and x402: check whether an AI agent is registered, Active and Verified in the Concordium Agent Registry (CIS-8004, ERC-8004 compatible). Library, Express middleware, MCP server and hosted pay-per-call API.
