# @idl3/claude-control

> 标签: agent, claude, claude-code, dashboard, tmux

## 简介

Local web UI to watch and drive your Claude Code sessions running in tmux — live transcripts, reply, answer AskUserQuestion, attach files, from a browser or phone.
