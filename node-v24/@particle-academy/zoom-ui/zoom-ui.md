# @particle-academy/zoom-ui

> 标签: connector, fancy-flow, fancy-ui, messaging, particle-academy, zoom

## 简介

Zoom's authoring surface for fancy-flow — the node kinds, their config schemas and their declared output shapes. React on every host; carries no executor.
