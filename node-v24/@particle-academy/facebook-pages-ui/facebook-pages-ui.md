# @particle-academy/facebook-pages-ui

> 标签: connector, facebook_pages, fancy-flow, fancy-ui, marketing, particle-academy

## 简介

Facebook Pages's authoring surface for fancy-flow — the node kinds, their config schemas and their declared output shapes. React on every host; carries no executor.
