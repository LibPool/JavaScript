# @particle-academy/fancy-walkthrough

> 标签: fancy, human-plus, intro.js-alternative, onboarding, particle-academy, product-tour, react, spotlight, walkthrough

## 简介

First-party guided walkthroughs for React: self-registering targets, a spotlight that survives scroll, resize and overflow, JSON steps an agent can author, and activation events built in. Replaces intro.js-style tours.
