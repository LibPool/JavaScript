# @particle-academy/docs-mcp

> 标签: agents, ai, claude, cursor, docs, fancy, mcp, model-context-protocol, particle-academy

## 简介

Dev-only MCP server (stdio) that exposes docs from every installed @particle-academy/* package. Configure once in your editor (Claude Code / Cursor / Claude Desktop) and any agent can list, read, and search the docs shipped with your installed fancy-* pac
