> 标签: api, connector, crm, fancy-ui, hubspot, particle-academy

## 简介

HubSpot for Node — the service descriptor, its faker, its webhook verification, and one function per operation. Plain HTTP on @particle-academy/fancy-connector-core; no vendor SDK.
