# @topstats/discord

> 标签: JavaScript

## 简介

Official TopStats Analytics integration for discord.js bots. Automatic event tracking plus a track() for your own events.

## 官网

- 官网：https://docs.topstats.gg/docs/analytics
- 源码仓库：git+https://github.com/top-stats/analytics-discord-integration.git
- npm 页面：https://www.npmjs.com/package/@topstats/discord
