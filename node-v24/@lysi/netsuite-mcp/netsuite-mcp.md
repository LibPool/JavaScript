# @lysi/netsuite-mcp

> 标签: ai, anthropic, claude, erp, mcp, model-context-protocol, netsuite, suiteql, suitetalk

## 简介

MCP server for NetSuite — exposes SuiteQL, REST record CRUD, transforms, metadata discovery, datasets and RESTlets as MCP tools over stdio or HTTP.
