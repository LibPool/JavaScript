# @markdown-it-enhancer/plugin-implicit-figures

> 标签: figure, image, img, implicit_figures, markdown-it, markdown-it-enhancer, markdown-it-plugin

## 简介

Render images occurring by itself in a paragraph as `<figure><img ...></figure>`, similar to pandoc's implicit_figures
