# @suntion/dsh-tool-gate

> 标签: dsh-plugin

## 简介

Per-session, per-plugin tool gating for DeepSeek Harness: at session start, choose which enabled plugins may contribute tools; disabled plugins' tools are never injected into that session's prompt.
