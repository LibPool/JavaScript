# @traceten/cli

> 标签: ai-traffic, analytics, attribution, chatgpt, claude, cli, perplexity, traceten

## 简介

The Traceten command line. Browse your AI-traffic numbers in an interactive terminal view, script every API report, and manage sites, goals, funnels and keys. Sign in through your browser, or use an API key in CI.
