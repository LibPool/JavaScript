# @schwaizer/ocp-companion

> 标签: JavaScript

## 简介

OCP Companion client — headless pairing (claim → approval → token), device-key PoP connect, heartbeats, silent token refresh, turns, and resume. Crypto and transports are injected so it runs in React Native (Hermes) and node alike.
