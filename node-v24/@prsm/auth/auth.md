# @prsm/auth

> 标签: auth, authentication, express, oauth, postgres, session, totp, two-factor

## 简介

PostgreSQL-backed authentication for Express: sessions, remember-me, password reset, email confirmation, OAuth, roles, two-factor, and audited impersonation
