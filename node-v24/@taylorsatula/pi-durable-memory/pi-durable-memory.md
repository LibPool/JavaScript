# @taylorsatula/pi-durable-memory

> 标签: embeddings, encryption, memory, pi-extension, pi-package, sqlite

## 简介

Proper long-term memory for Pi. These are not crude MEMORY.md files. Each memory is stored individually and the agent curates them. Memories are injected into the context window for just-in-time recall. Local SQLite, embedding search.
