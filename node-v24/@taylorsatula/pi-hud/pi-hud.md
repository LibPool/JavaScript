# @taylorsatula/pi-hud

> 标签: pi-package

## 简介

Ambient HUD injected into the model's context on every LLM call. Live briefing notes (time, context budget, git, cwd) that refresh as assistant messages complete — kept off the transcript and out of the user's view.
