# dsh-niuma

> 标签: counter, deepseek, deepseek-harness, dsh, dsh-plugin, income, overtime, panel, payday, salary, ticker, wage, worktime, 工资, 牛马, 计数器, 面板

## 简介

牛马加速器 — DSH 工资换算实时计数器：按实收月薪、上下班时间、午休（可设是否算工时）、法定节假日自动折算秒/分/时/日/周/月工资，工资每秒滚动增长。Community salary ticker plugin for DeepSeek Harness.
