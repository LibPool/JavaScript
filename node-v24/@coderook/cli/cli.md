# @coderook/cli

> 标签: backup, cbx, coderook, gamedev, large-files, project-hosting, snapshots, vcs, version-control, versioning

## 简介

The command line for CodeRook (coderook.com): version control and project hosting for projects of any size. Every save is a compressed snapshot, private or public, never used to train AI.
