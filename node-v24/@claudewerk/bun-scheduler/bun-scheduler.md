# @claudewerk/bun-scheduler

> 标签: alarm, bun, cron, durable-objects, fake-clock, scheduler, timers

## 简介

One injectable Clock/Scheduler for every timer in the substrate stack: host timers, a deterministic FakeClock, Durable Object alarms, and cron expressions on any clock. Zero required runtime deps.
