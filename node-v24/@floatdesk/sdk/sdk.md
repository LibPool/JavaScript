# @floatdesk/sdk

> 标签: discord, express, helpdesk, sdk, slack, support, telegram, tickets, widget

## 简介

Multi-provider support ticket SDK — Express server factory with plug-in storage adapters, Slack/Telegram/Discord channel integrations, and AWS S3 media uploads
