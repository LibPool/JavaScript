# @nibgate/wallet

> 标签: appkit, arc, nibgate, paywall, react, siwe, usdc, wagmi, wallet, x402

## 简介

Single Nibgate wallet standard: chain guard, error mapping, SIWE sign-in, and a shared Reown AppKit (AppKit + wagmi) React provider, connect, and unlock.
