# @plotdb/esh

> 标签: bash, browser-shell, embeddable, interpreter, opfs, posix, shell, virtual-fs, zenfs

## 简介

esh — embeddable shell runtime for JavaScript. Shell syntax + virtual fs, runs in browser (OPFS persistence), Node, and workers.
