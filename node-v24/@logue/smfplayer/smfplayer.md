# @logue/smfplayer

> 标签: Maple Story 2, Music Macro Language, WebMidiLink, mabinogi, midi, midi player, mml, ms2mml, sequencer, smf, webaudio, wml

## 简介

smfplayer.js is JavaScript based Standard Midi Player for WebMidiLink based synthesizer.
