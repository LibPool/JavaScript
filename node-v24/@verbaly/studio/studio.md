# @verbaly/studio

> 标签: editor, i18n, localhost, translations, verbaly

## 简介

Local review server for Verbaly: read, edit and approve translations over the JSON files already in your repo. No account, no database.

- 官网：https://verbaly-web.vercel.app/docs/guide/studio
- 源码仓库：git+https://github.com/AronSoto/verbaly.git
