# @pnpancholi/pi-review-panel

> 标签: code-review, diff, pi-extension, pi-package, pi-review-panel, review, tui

## 简介

A git-based, session-aware review panel for the pi coding agent. Tracks every file the agent changes during a session and presents an interactive, keyboard-navigable diff view so you can review changes before committing.
