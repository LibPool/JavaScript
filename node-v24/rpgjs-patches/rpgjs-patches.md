# rpgjs-patches

> 标签: canvasengine, game-dev, patch, pixi, pixi-viewport, rpgjs, workaround

## 简介

Narrow runtime patches for the CanvasEngine defects every RPGJS 5 game meets: the viewport clamp, teardown before mount, and late sprite work.
