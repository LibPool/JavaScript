# @gardner-nick/cdk-blog-backend

> 标签: aws-cdk, blog, cdk, construct, serverless

## 简介

A reusable AWS CDK construct for a serverless blog backend (API Gateway HTTP API + Lambda + DynamoDB, optional S3 assets).
