# @asun-labs/dsh-plugin-computer-user

> 标签: automation, computer-use, deepseek-harness, dsh-plugin, screenshot, virtual-desktop

## 简介

Virtual-desktop computer use for DeepSeek Harness: the agent sees a live snapshot in the right sidebar and its mouse acts on a virtual pointer overlay, so your real desktop and cursor stay yours.
