# @ia-qa/self-healing

> 标签: accessibility, broken-selectors, codemod, cypress, e2e, e2e-testing, flaky, flaky-tests, locators, mcp, model-context-protocol, playwright, qa, selector-drift, selectors, selenium, self-healing, test-automation, test-maintenance, testing

## 简介

Your Playwright, Cypress or Selenium tests break when a selector moves — this finds the element again and rewrites the test. Deterministic: no LLM decides whether your build passes. Runs entirely on your machine, with a local MCP server for agents.
