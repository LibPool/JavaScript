# @nuwax-ai/file-server-proxy

> 标签: electron, file-server, file-server-proxy, nuwax, rust, sidecar

## 简介

Native file-server-proxy (Rust) as the single entry on :60000 — embeds the Rust file-server, routes between Rust and the TypeScript nuwax-file-server, and manages nuwax-file-server (installed as a pinned dependency); prebuilt binary from Alibaba Cloud OSS
