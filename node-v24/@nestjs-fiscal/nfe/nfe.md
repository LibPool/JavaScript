# @nestjs-fiscal/nfe

> 标签: JavaScript

## 简介

O pacote `nfe` contém toda a lógica específica para a emissão, validação, cancelamento e inutilização de Notas Fiscais Eletrônicas (NFe v4.00) dentro da arquitetura do NestJS Fiscal BR.
