# @doxinger/smart-fingerprint

> 标签: browser-fingerprint, browser-id, device-fingerprint, fingerprint, visitor-id

## 简介

Lightweight browser fingerprint library with stable, full and session fingerprints, similarity scoring, caching and ESM/UMD support.
