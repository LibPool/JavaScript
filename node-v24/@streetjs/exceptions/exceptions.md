# @streetjs/exceptions

> 标签: errors, esm, exceptions, http-errors, status-codes, street-framework, streetjs, typescript, zero-dependencies

## 简介

StreetJS HTTP exceptions foundation: a typed exception hierarchy (400/401/403/404/409/422/500/501/503) with status codes, JSON serialization, and a type guard. Zero runtime dependencies.
