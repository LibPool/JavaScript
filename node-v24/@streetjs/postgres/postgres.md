# @streetjs/postgres

> 标签: database, esm, failover, high-availability, postgres, postgresql, scram-sha-256, street-framework, streetjs, typescript, wire-protocol, zero-dependencies

## 简介

StreetJS PostgreSQL driver: a dependency-free PostgreSQL wire-protocol client (SCRAM-SHA-256 auth, extended query protocol, streaming results) plus a high-availability client (primary discovery, role-targeted routing, failover). Zero runtime dependencies.
