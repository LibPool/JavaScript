# @streetjs/webhooks

> 标签: delivery, esm, hmac, replay-protection, signature, signing, street-framework, streetjs, typescript, verification, webhook, webhooks, zero-dependencies

## 简介

StreetJS webhooks foundation: generic outbound webhook signing and delivery (HMAC-SHA256, timestamped signatures, retries) plus constant-time incoming signature verification with replay protection. Zero runtime dependencies.
