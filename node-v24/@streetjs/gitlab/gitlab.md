# @streetjs/gitlab

> 标签: connector, esm, gitlab, integration, merge-request, pipeline, street-framework, streetjs, typescript, webhook

## 简介

StreetJS GitLab connector: a typed GitLab REST API v4 client (projects, issues, notes, merge requests, pipeline triggers) built on @streetjs/integrations, plus X-Gitlab-Token webhook verification.
