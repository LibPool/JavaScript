# @streetjs/testing

> 标签: deferred, esm, fake-clock, fetch-mock, mock, spy, street-framework, streetjs, test-utilities, testing, typescript, wait-for, zero-dependencies

## 简介

StreetJS testing foundation: framework-agnostic test utilities — spies, a controllable fake clock, deferreds, waitFor/delay async helpers, and a scripted fetch mock. Zero runtime dependencies.
