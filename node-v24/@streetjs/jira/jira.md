# @streetjs/jira

> 标签: atlassian, connector, esm, integration, issue-tracker, jira, street-framework, streetjs, typescript

## 简介

StreetJS Jira connector: a typed Jira Cloud REST API v3 client (issues, comments, transitions, assignment, JQL search) built on @streetjs/integrations, with Basic email+token auth and an HMAC webhook verifier.
