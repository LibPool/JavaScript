# @streetjs/cluster

> 标签: auto-restart, cluster, esm, heartbeat, ipc, multiprocess, street-framework, streetjs, typescript, workers, zero-dependencies

## 简介

StreetJS clustering foundation: a primary-process cluster coordinator that spawns workers across CPUs with IPC heartbeat monitoring and auto-restart, plus worker-side heartbeat/ready helpers. Zero runtime dependencies.
