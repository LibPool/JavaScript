# @signalto/bridge-node

> 标签: express, fastify, geo, koa, llms-txt, middleware, nextjs, redirects, robots-txt, seo, signalto, structured-data

## 简介

SignalTo content-bridge connector for Node.js apps — serves managed robots.txt, root files, redirects, response headers and page heads from inside your app, paired to the SignalTo engine.
