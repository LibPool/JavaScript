# @gritdigital/grit-build

> 标签: esbuild, eslint, grit, grit-build, prettier, tailwind

## 简介

A thin wrapper around [esbuild](https://esbuild.github.io/) and [LightningCSS](https://lightningcss.dev/) to make building for the web fast and simple.
