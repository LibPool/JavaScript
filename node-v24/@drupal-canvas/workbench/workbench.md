# @drupal-canvas/workbench

> 标签: JavaScript

## 简介

Canvas Workbench is a local preview and development app for Drupal Canvas Code Components, inspired by Storybook. It scans your project, lists discovered components, pages, content templates, and page templates, and renders previews in an isolated frame.
