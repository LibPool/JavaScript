# dsh-for-agi-splash

> 标签: agi, boot-animation, deepseek-harness, dsh, dsh-plugin, splash, splash-screen, startup-animation, 启动动画, 开屏动画, 开机动画

## 简介

DSH-for-AGI 开屏动画：9.9 秒精简版 + 30 秒剧场版。剧场版走完冷启动 → 自检 → 认知网络 → 工具桥接 → 上下文装配 → AGI 就位 → 交棒，装完或升级后播一次，之后自动回精简版；中文旁白 + 全片音效，点击或 Esc 随时跳过。
