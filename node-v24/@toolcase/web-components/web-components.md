# @toolcase/web-components

> 标签: bootstrap-compatible, custom-elements, framework-free, html5, toolcase, typescript, web-components

## 简介

Framework-free HTML5 Web Components (tc-*) with their own from-scratch toolcase styling and a Bootstrap-compatible class/grid API — drop into any stack without React, Vue, or Angular.
