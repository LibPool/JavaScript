# @zohocrm/zdk-cli

> 标签: CLI, ZDK, ZOHO

## 简介

ZDK CLI (Zoho Development Kit CLI) is a set of CLI tools that you can use to interact with and manage your CRM org metadata in a developer-friendly way.
