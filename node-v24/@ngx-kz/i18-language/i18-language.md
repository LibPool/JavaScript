# @ngx-kz/i18-language

> 标签: JavaScript

## 简介

- Вставить перевод или исправления для всех четырех языков `en.ts`, `kk.ts`, `qq.ts`, `ru.ts` - Поднять версию либы в `projects/ngx-kz/i18-language/package.json` - Запустить run `ng build @ngx-kz/i18-language && cd dist/ngx-kz/i18-language && npm publish`
