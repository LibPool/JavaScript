# @shieldfont/react

> 标签: anti-scraping, react, server-component, shieldfont

## 简介

ShieldFont React component. Encodes in Node, so your original text never ships in plain form. Screen readers get the real text: every protected block carries a visible notice with a button that shows it, on by default, tested with NVDA and VoiceOver. A v0
