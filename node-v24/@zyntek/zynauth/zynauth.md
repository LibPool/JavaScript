# @zyntek/zynauth

> 标签: auth, login, mfa, oidc, sso, zynauth, zyntek

## 简介

SDK oficial de ZynAuth — el proveedor de identidad de Zyntek. Login embebido con MFA para tus apps, como Amplify lo es para Cognito.
