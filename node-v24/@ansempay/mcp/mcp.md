# @ansempay/mcp

> 标签: ai-agents, ansem, mastercard, mcp, mcp-server, payments, solana, usdc, virtual-card

## 简介

Ansem Pay MCP server — lets AI agents (Claude, ChatGPT, any MCP client) mint single-use virtual Mastercards funded with USDC or $ANSEM on Solana. Wraps @ansempay/sdk with local claim-token custody and daily budget caps.
