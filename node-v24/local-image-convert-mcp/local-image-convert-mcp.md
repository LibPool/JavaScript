# local-image-convert-mcp

> 标签: avif, converter, heic, image, mcp, model-context-protocol, offline, privacy, webp

## 简介

Local stdio MCP server that converts images (HEIC, JPEG, PNG, WebP, AVIF) on your own machine. No network, no telemetry.
