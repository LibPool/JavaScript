# @devrecated/autodevelop

> 标签: agentic-coding, autodevelop, claude-code, cli, cursor, mcp, opencode

## 简介

Autodevelop CLI — downloads the kit from the Autodevelop host after login, installs the organization policy pack, and connects MCP (binary wrapper).
