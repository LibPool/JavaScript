# dsh-conversation-recycle-bin

> 标签: audit, conversation, deepseek-harness, delete, dsh, dsh-plugin, memory, recycle-bin, session

## 简介

DSH conversation deletion with an optional, previewed cascade into conversation-associated memory: soft delete + recycle bin, audit trail, batch rate limits and per-session rollback. 删除对话（可选一并删除关联记忆）：软删除与回收站、审计留痕、批量限流、失败回滚。
