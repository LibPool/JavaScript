# @ticora/cli

> 标签: JavaScript

## 简介

ticora — vendor CLI for the Workspace Engine. `contracts diff` gates breaking contract changes against saved workspaces; `contracts lint` checks contract quality. All IO lives here; validation reuses @ticora/core's validateSpec unchanged.
