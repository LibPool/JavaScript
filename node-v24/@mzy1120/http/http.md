# @mzy1120/http

> 标签: BatchProcessor, DataLoaderService, MultiApiTask, axios, fetch, http, mzy1120, orchestrator, request, restful

## 简介

@mzy1120 专属请求库:基于 axios 的统一封装(业务信封解包 / 防重复 / 并发熔断 / 全局反馈适配器,RESTful 语义化方法)+ 多接口编排(MultiApiTask / BatchProcessor / DataLoaderService,细粒度进度 / 整体取消 / 单接口重试),零 UI 依赖,可注入 antd/ElementPlus 等
