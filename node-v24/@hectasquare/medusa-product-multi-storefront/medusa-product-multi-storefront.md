# @hectasquare/medusa-product-multi-storefront

> 标签: ecommerce, medusa, medusa-plugin, medusa-v2, medusajs, multi-brand, multi-storefront, product-overrides, sales-channels, storefront-presentation

## 简介

Medusa v2 plugin adding universal multi-storefront and multi-brand support with decoupled presentation (titles, descriptions, handles, badges), isolated image galleries, auto-transform response middleware, and an integrated top-level Admin UI badge switch
