# @webviewjs/webview-win32-ia32-msvc

> 标签: cross-platform, gui, node, rust, webview

## 简介

Robust cross-platform webview library for Node.js written in Rust. It also works with deno and bun.

## 官网

- 官网：https://github.com/webviewjs/webview#readme
- 源码仓库：git+ssh://git@github.com/webviewjs/webview.git
- npm 页面：https://www.npmjs.com/package/@webviewjs/webview-win32-ia32-msvc
