# @premium-cms/plugin-premiumcms-projects

> 标签: JavaScript

## 简介

PremiumCMS control-plane plugin (trusted, in-process): provisions isolated instances on Cloudflare, themes-as-repos, plugins-as-repos, custom domains, credits
