# @clientsdemo/license-client

> 标签: clientsdemo, ehr, ehs, isms, ksdb, license, license-server, license-validation, partnerhub, shoprewards

## 简介

TypeScript client SDK for the ClientsDemo License Server. Validate licenses, manage seats, renew, activate/deactivate machines, send heartbeats, run a continuous enforcement watchdog, and verify offline.
