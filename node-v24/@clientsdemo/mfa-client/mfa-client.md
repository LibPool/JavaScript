# @clientsdemo/mfa-client

> 标签: 2fa, mfa, number-matching, push-authentication

## 简介

Server-side client for the clientsdemo MFA push-authentication service — create enrollments, dispatch sign-in requests, verify number matching, and consume webhooks.
