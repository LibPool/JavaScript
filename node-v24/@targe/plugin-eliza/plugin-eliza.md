# @targe/plugin-eliza

> 标签: anthropic, base, elizaos, google, llm, micropayments, openai, targe, usdc, x402

## 简介

Targe LLM token sharing marketplace — call Claude, GPT, and Gemini via pooled keys with USDC micropayments. No API key required. Share your idle key and earn USDC.
