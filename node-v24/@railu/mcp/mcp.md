# @railu/mcp

> 标签: advertising, agentic, clearing, mcp, model-context-protocol, railu, tools

## 简介

Mount a @railu/agent as MCP tools — the Railu execution layer appears as tools your LLM orchestrator already knows how to call. Framework-agnostic: tool definitions + a dispatcher + a JSON-RPC handler.
