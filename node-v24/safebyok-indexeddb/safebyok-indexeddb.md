# safebyok-indexeddb

> 标签: e2ee, indexeddb, safebyok, vault

## 简介

IndexedDB storage for safebyok: a VaultDB that keeps vault bundles and lockboxes as ciphertext in this browser, each verb one IndexedDB transaction, and the template for a key-value backend of your own.
