# @rixtay/mail-mcp

> 标签: claude, email, hotmail, mcp, microsoft-graph, model-context-protocol, outlook, unsubscribe

## 简介

MCP server for a personal Outlook.com / Hotmail mailbox: read, search, file, delete and unsubscribe from newsletters via Microsoft Graph.
