# @mdht/plugin-jazz-schema

> 标签: codegen, crdt, jazz-tools, local-first, zenstack, zmodel

## 简介

ZenStack v3 CLI plugin: generate a Jazz CoValue schema (co.map/co.list) from your ZModel schema.
