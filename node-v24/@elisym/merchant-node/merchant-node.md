# @elisym/merchant-node

> 标签: checkout, commerce, elisym, nostr, payments, solana, usdc

## 简介

Pay Core merchant node: the self-hosted store behind elisym's stablecoin checkout - takes orders over Nostr, verifies payments, completes orders.
