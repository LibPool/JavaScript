# @nestjs-transactions/prisma

> 标签: async-local-storage, cls, nestjs, nestjs-cls, nestjs-transactions, prisma, prisma-transactional, propagation, savepoint, transaction, transactional

## 简介

Declarative @Transactional() for NestJS + Prisma: inject one transaction-aware Prisma client, drop the $transaction boilerplate. No monkey-patching.
