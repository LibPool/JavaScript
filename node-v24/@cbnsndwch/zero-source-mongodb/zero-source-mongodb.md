# @cbnsndwch/zero-source-mongodb

> 标签: JavaScript

## 简介

Production-ready MongoDB change source for Rocicorp Zero with NestJS integration. Features MongoDB change streams, discriminated union support, WebSocket streaming, dynamic schema loading, and comprehensive metadata APIs for real-time data synchronization
