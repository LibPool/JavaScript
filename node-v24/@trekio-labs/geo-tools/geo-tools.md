# @trekio-labs/geo-tools

> 标签: bearing, bounding-box, douglas-peucker, geo, geodesy, gps, great-circle, haversine, polyline, simplify

## 简介

Dependency-free geodesic helpers: haversine distance, bearing, destination, point-to-path distance, bounding boxes and Douglas-Peucker simplification.
