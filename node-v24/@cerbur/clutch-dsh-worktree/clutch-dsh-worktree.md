# @cerbur/clutch-dsh-worktree

> 标签: deepseek-harness, dsh, dsh-plugin, git, worktree

## 简介

Adds a Worktree view to DSH Web UI that groups Sessions by Git worktree while keeping DSH as the source of truth.
