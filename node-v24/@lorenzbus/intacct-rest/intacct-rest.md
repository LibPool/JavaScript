# @lorenzbus/intacct-rest

> 标签: api, client, intacct, openapi, rest, sage, sage-intacct, typescript

## 简介

Typed, host-agnostic TypeScript client for the Sage Intacct REST API, generated from Sage's OpenAPI specification.
