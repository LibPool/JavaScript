# @easydev-org/easybus-sdk

> 标签: JavaScript

## 简介

easybus protocol SDK (TypeScript) — the multi-tenant extension bus. Wire contract: proto/easybus/v1/protocol.proto (the single source of truth, shared with easybus-sdk Go/Python/Rust).
