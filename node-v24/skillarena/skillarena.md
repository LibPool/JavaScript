# skillarena

> 标签: agent-skills, agents, agents-md, ai, ai-evaluation, benchmark, claude, claude-code, claude-md, claude-skills, codex, coding-agent, evals, llm, mcp, ollama, opencode, openrouter, plugins, skills

## 简介

Benchmark AI coding agent skills, plugins and CLAUDE.md files: run Claude Code, Codex or OpenCode with and without them and measure pass rate, cost, false "done" claims and test tampering. Works with any LLM.
