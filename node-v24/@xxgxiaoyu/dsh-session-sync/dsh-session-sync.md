# @xxgxiaoyu/dsh-session-sync

> 标签: deepseek, deepseek-harness, dsh, dsh-plugin, lan, p2p, session, session-sync

## 简介

DSH LAN session sync: auto-discover devices running this plugin, browse/pull/push sessions over HTTP, verify them with SHA-256, and keep a local-only nickname per device.
