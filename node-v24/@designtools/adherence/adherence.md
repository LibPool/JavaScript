# @designtools/adherence

> 标签: adherence, adoption, cli, design-system, design-tokens, deterministic, eslint, react, react-scanner, report, tailwind

## 简介

A warn-only report on how closely a React product follows its design system: system components against the raw elements they replace, classes that bypass the tokens, and classNames that override a component. Reads the @designtools/manifest JSON; markdown
