# bundle-pulse

> 标签: brotli, budget, bundle-size, ci, github-action, gzip, performance, sarif, vite, webpack

## 简介

CI gate for JS/CSS bundle size: per-entry budgets on raw, gzip and brotli sizes, total JS/CSS budgets, growth vs a base-branch snapshot with content-hash-insensitive names, unminified and duplicate files. SARIF, Markdown, GitHub Action. Zero deps.
