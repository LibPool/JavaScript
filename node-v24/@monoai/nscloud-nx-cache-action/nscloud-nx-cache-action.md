# @monoai/nscloud-nx-cache-action

> 标签: cache, cli, github-actions, namespace, nx

## 简介

CLI tools for Nx HTTP caching across local development, Namespace runners and hosted builds, with local archives, shared Artifact Storage and short-lived build credentials.
