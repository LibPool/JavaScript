# @pafcore/cli

> 标签: ci, core-web-vitals, lighthouse, page-speed, performance, regression

## 简介

Measures the Lighthouse performance score, how much it moves between runs on the same page, and whether a change you made moved it by more than that. Says INCONCLUSIVE when it cannot tell.
