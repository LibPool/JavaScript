# @mark1russell7/client-shell

> 标签: child-process, exec, procedures, shell, spawn, streaming

## 简介

Safe command execution for TypeScript: shell.run with argv and no shell, shell.stream line streaming with backpressure, process-tree kill, timeouts and output caps.
