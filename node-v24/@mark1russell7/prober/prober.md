# @mark1russell7/prober

> 标签: bpf, co-re, ebpf, keepalive, libbpf, linux, observability, retransmission, tcp

## 简介

An eBPF prober for TCP: a CO-RE kernel program and its Rust collector, which record what the kernel did to each socket, with the record contract in TypeScript.
