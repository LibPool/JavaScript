# @mark1russell7/docker-sqlite

> 标签: database, docker, docker-compose, embedded-database, migrations, node, query, schema-migrations, sql.js, sqlite, sqlite-web, sqlite3, typescript, wasm, webassembly

## 简介

SQLite for Node.js with no native build: sql.js (SQLite in WebAssembly) with safe file access (one call at a time per file, atomic saves, no write on read), queries, migrations and an optional Docker Compose web UI.
