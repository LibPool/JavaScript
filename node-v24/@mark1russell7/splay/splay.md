# @mark1russell7/splay

> 标签: data-renderer, dispatch, framework-agnostic, json-viewer, layout, react, recursive, registry, renderer, solid, svelte, type-dispatch, typescript, ui, visualization, vue, zero-dependency

## 简介

Type-driven recursive renderer for any data: register a viewer per type and dispatch renders nested values with React, Vue, Solid, Svelte or plain strings. Framework-agnostic core, zero dependencies.
