# dsh-fulltext-index

> 标签: bigram, cjk, dsh, fulltext, inverted-index, plugin, relevance, search, tf-idf, tokenize

## 简介

In-memory full-text search plugin for DeepSeek Harness: inverted index with deterministic tokenization (ASCII words lowercased, CJK runs as character bigrams with singleton unigram fallback), TF-IDF ranked search with title field boosting (2x), match cove
