# react-native-floating-glass-tabbar

> 标签: android, animated, blur, bottom-navigation, bottom-tabs, custom-tab-bar, expo, expo-blur, expo-router, floating, glass, glassmorphism, ios, liquid-glass, navigation, pill, react-native, react-native-tab-bar, react-navigation, tab-bar, tabbar, typescript

## 简介

Floating frosted-glass pill tab bar for React Native: a custom tabBar for React Navigation bottom tabs and expo-router, with a spring-animated indicator, label modes, badges, RTL and collapse-on-scroll.
