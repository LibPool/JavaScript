# @autopilot-harness/port-devin

> 标签: agent, ai, autopilot, checklist, code-review, devin, devin-cli, harness

## 简介

Autopilot harness host port for Devin CLI hooks (subprocess; Stop decision:block+reason; anchored PostToolUse matcher; independent --platform devin fingerprint). CLI only — not Desktop, cloud, or Cascade.
