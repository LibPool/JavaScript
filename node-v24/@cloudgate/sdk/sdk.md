# @cloudgate/sdk

> 标签: api, cloud, cloudgate, cloudstack, multi-cloud, sdk, typescript

## 简介

Official TypeScript/JavaScript client for the CloudGate public API (v1): subscriptions, resources, billing, reports, support and organization administration.
