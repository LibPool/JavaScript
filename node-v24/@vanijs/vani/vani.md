# @vanijs/vani

> 标签: dom, explicit-rendering, fine-grained, framework, frontend, hydration, js-first, jsx-runtime, no-compiler, no-virtual-dom, signals, ssg, ssr, typescript, ui, vanilla, vanilla-js, web-standards, zero-dependencies

## 简介

Web-standards-first UI runtime with explicit updates, fine-grained DOM ownership, and zero dependencies. JS-first, transpiler-free, with an optional JSX adapter. Built for SPA, SSR, and SSG.
