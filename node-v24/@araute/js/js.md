# @araute/js

> 标签: JavaScript

## 简介

SDK de navegador do Araute: monta o campo de cartão do checkout transparente (SmartForm da Lyra) com o client_secret do PaymentIntent.

## 官网

- 官网：https://docs.araute.com
- 源码仓库：git+https://github.com/arautehq/araute-js.git
- npm 页面：https://www.npmjs.com/package/@araute/js
