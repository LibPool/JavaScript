# @btravstack/observability

> 标签: dependency-injection, logger, logging, observability, opentelemetry, structured-logging, typescript, unthrown

## 简介

Observability for @btravstack/core: a strict Logger port correlated with the kernel's units, a dependency-free JSON sink, and the lifecycle events as log lines
