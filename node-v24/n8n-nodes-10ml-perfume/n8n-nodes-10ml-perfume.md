> 标签: fragrance, fragrance-api, fragrance-notes, mcp, n8n, n8n-community-node-package, perfume, perfume-api, perfume-recommendation, similar-perfumes

## 简介

n8n community node for the free 10ML Perfume Finder: search perfumes, note pyramids, accords, similar scents, alternatives, notes and houses from the 10ML Fragrance Index. No API key.
