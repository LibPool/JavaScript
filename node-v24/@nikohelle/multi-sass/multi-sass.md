# @nikohelle/multi-sass

> 标签: css, dynamic, export, mixin, multi, multi-purpose, partial, sass, scss, styles, stylesheet

## 简介

Library for publishing stylesheets in multi-purpose environments with support for outputting only named partials of a SASS mixin. Selector renaming and customisation is also supported with middleware.
