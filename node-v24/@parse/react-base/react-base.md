# @parse/react-base

> 标签: next.js, parse, react, react native, ssr

## 简介

An experimental base implementation to support the specialized packages for React, React Native, and React with SSR (e.g. Next.js) applications. These packages provide you easy, real-time, offline-first interaction with the powerful Parse Server backend.
