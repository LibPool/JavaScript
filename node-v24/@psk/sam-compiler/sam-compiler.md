# @psk/sam-compiler

> 标签: JavaScript

## 简介

1. Install [Node.js](https://nodejs.org/en/download/). 2. `npm login` ('npm login' in Bitwarden). 3. `npm install -g @psk/sam-compiler`. 4. Verify installation by running `samc`.
