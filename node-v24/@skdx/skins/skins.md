# @skdx/skins

> 标签: JavaScript

## 简介

The default SkandaDX component skin — framework-neutral CSS that styles the core components from @skdx/react, @skdx/vue, @skdx/svelte, @skdx/angular and @skdx/web-components against @skdx/tokens
