# @yangtianlong/dsh-sound

> 标签: deepseek-harness, dsh, notification, plugin, sound

## 简介

DSH Web GUI 提示音插件：消息完成与需要用户确认时播放提示音。完成音、确认音各自可在 设置→通用 里通过下拉框选择音效（默认合成音 + 自定义上传），上传的音效、开关与选择状态持久化到 $DSH_HOME/dsh-sound/，重启后保留。
