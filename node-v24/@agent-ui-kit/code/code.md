> 标签: agent-ui, code-editor, codemirror, custom-elements, design-system, markdown, syntax-highlighting, web-components

## 简介

The code + prose family for agent-ui: a zero-dependency highlighter core, seven hand-rolled tokenizers, a sanitized markdown renderer, and an editable-first source editor (the editor pack lazy-loads CodeMirror 6 per mount — no CodeMirror in your bundle ot
