# @spekoai/mcp-calls

> 标签: agentvoice, calls, claude-code, mcp, mcp-framework, model-context-protocol, phone, speko, voice-ai

## 简介

Place real, disclosed phone calls to businesses, or call your verified owner when an agent needs input. Single self-contained package: `npx @spekoai/mcp-calls init`.
