# @circuit-llm/node

> 标签: JavaScript

## 简介

Circuit SDK node — join/manage a mesh node from code: the inference-mesh control plane (register/ready/heartbeat) + the public node registry (announce/ping). The heavy GPU serving stays in the node image.
