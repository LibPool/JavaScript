# @julong/mono-rele2-exchange

> 标签: JavaScript

## 简介

Use this skill to fetch the latest KRW exchange rates for China, Japan, and the Euro area from Naver, Google, and Daum via the mono-rele2-exchange CLI. Scrapes each portal with Playwright and returns JSON, using null for any rate it cannot read.
