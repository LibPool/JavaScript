# @atlaskit/drag-and-drop-hitbox

> 标签: JavaScript

## 简介

An addon for `@atlaskit/drag-and-drop` with helpers for attaching interaction information to a drop target when it is being dragged over

- 官网：https://atlassian.design/components/drag-and-drop/
