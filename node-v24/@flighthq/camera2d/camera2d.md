# @flighthq/camera2d

> 标签: JavaScript

## 简介

2D game camera — world<->screen view matrix, target follow with deadzone + frame-rate-independent smoothing + world-bounds clamp, zoom-about-a-point, parallax offsets, and a visible-bounds cull query over a plain-data camera
