# @flighthq/scene-resources

> 标签: JavaScript

## 简介

Caller-driven resolution of scene-format texture resource references into live ImageResources — discovery walk, resolution policy, cancellation, and an opt-in availability signal over @flighthq/loader + @flighthq/image
