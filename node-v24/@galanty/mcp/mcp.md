# @galanty/mcp

> 标签: JavaScript

## 简介

Connect your agent (Claude Code, Codex, Gemini CLI, ...) to the Galanty app on this Mac over MCP (stdio bridge to the app's local endpoint, with file upload and download).

- npm 页面：https://www.npmjs.com/package/@galanty/mcp
