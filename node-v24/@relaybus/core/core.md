# @relaybus/core

> 标签: dead-letter, event-bus, events, inbox, nestjs, outbox, retry, transactional-outbox

## 简介

Reliable, storage-agnostic event bus: transactional outbox, per-handler deliveries, retries with jitter, dead letters and ordering keys.
