# @relaybus/postgres

> 标签: event-bus, outbox, pg, postgres, postgresql, relaybus, skip-locked

## 简介

PostgreSQL event store for relaybus: transactional outbox with SKIP LOCKED leasing, for pg, Prisma, TypeORM, Knex, Kysely and Drizzle.
