# @cosyte/hl7

> 标签: adt, builder, healthcare, hl7, hl7-v2, hl7v2, interoperability, mllp, oru, parser, serializer, toolkit, typescript

## 简介

Developer-focused HL7 v2 toolkit for Node.js and TypeScript, message parsing and building, mutation and serialization, and one-line helpers.
