# @cosyte/ncpdp

> 标签: claims, e-prescribing, healthcare, interoperability, ncpdp, parser, pharmacy, script, serializer, telecom, typescript

## 简介

NCPDP parser, serializer, and builder for Node.js and TypeScript: SCRIPT ePrescribing and Telecom pharmacy claims, lenient on parse, spec-clean on emit.
