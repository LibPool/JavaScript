# @cosyte/transform

> 标签: adt, fhir, fhir-r4, healthcare, hl7, hl7v2, interoperability, mapping, oru, transform, typescript, v2-to-fhir

## 简介

HL7 v2 → FHIR R4 transformation library for Node.js and TypeScript: IG-grounded, fail-safe, value-free diagnostics; never a confident wrong FHIR value.
