# @boostkit-dsh/skill-arm64-arch-reference

> 标签: JavaScript

## 简介

查阅 ARM A-profile（AArch64/A64）架构特性与指令的权威速查表。每当涉及 ARM64/AArch64/A64 的架构特性（FEAT_*，如 FEAT_SVE/FEAT_LSE/FEAT_MTE/FEAT_BF16）、某特性的引入版本或可选/强制状态、 指令的助记符/汇编模板/编码（Encoding）、或某指令受哪个特性门控时，都应使用本 skill。 尤其在做 ARM64 编译器/代码生成（codegen）优化、判断目标指令在哪个架构版本可用、为某指令选择 feature gate、
