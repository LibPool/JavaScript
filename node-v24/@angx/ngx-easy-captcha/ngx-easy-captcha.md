# @angx/ngx-easy-captcha

> 标签: angular, angular captcha, cloudflare turnstile, google recaptcha, ngx cloudflare turnstile, ngx easy captcha, ngx google recaptcha, recaptcha v3

## 简介

One Angular service for both Google reCAPTCHA v3 and Cloudflare Turnstile, loading each script on demand and cleaning up after itself.
