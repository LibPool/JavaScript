# @andan/semantic-release-gitlab-dryrun

> 标签: automation, gitlab, npm, publish, release, semantic-release

## 简介

Automatically generate a release, along with a corresponding git tag, for GitLab-hosted source code.  Supports a dry-run flag before creating release
