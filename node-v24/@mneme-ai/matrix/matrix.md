# @mneme-ai/matrix

> 标签: JavaScript

## 简介

THE MATRIX RAIL — the local-first gRPC wire server for Mneme. Any AI agent (any language) connects over HTTP/2 + Protobuf to reach every Mneme function through one typed, signed, streaming pipe. Invoke (unary, proof-carrying) + Pipe (bidi, chunked → any-s
