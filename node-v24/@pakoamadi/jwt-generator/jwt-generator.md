# @pakoamadi/jwt-generator

> 标签: JavaScript

## 简介

A lightweight, ultra-fast, and secure HMAC-SHA256 JWT (JSON Web Token) generator and validator for Node.js. Built with **pure JavaScript** and zero external dependencies, making it perfect for V8-optimized environments and high-load microservices.
