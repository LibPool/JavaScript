# @uptimizr/db-mssql

> 标签: analytics, azure-sql, events, mssql, query, sql-server, storage, uptimizr

## 简介

Optional single-tenant Microsoft SQL Server store for Uptimizr — composes the @uptimizr/db dialect-agnostic query layer and CollectorStore contract for self-hosters standardized on SQL Server / Azure SQL who want a multi-writer relational backend.
