# @uptimizr/metrics

> 标签: 3d, analytics, mcp, metrics, openapi, registry, uptimizr, zod

## 简介

The Uptimizr semantic metric registry — one machine-readable definition per analytics metric (row schema, units, filters, endpoint, limits, interpretation). Dependency-free and browser-safe.
