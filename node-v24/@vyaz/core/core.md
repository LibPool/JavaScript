# @vyaz/core

> 标签: canvas-text, font-metrics, rich-text, svg, table-layout, text-layout, typography

## 简介

Rich-text layout engine — TypeScript, isomorphic (browser + Bun/Node.js), pixel-perfect typography. TextFrame/paragraph layout plus a TableFrame grid layout (colSpan/rowSpan, borders, nested tables).
