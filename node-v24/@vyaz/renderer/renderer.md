# @vyaz/renderer

> 标签: renderer, svg, table-layout, text-layout, typography

## 简介

SVG renderer for @vyaz/core layout output — text lines and TableFrame grids, four presets (flat/browser/preserve/glyph), plus registerFont() for keeping engine metrics and document.fonts in sync.
