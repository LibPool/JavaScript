# @maryland-gov/mdwds

> 标签: JavaScript

## 简介

A shared foundation for Maryland government websites. Built by the Maryland Digital Service, this mdwds includes UI components, measurement tools, accessibility helpers, and best practices for modern, user-centered digital services.
