# @magic-translate/js

> 标签: html, i18n, javascript, magic-translate, multilanguage, translations

## 简介

Plain JavaScript client for Magic Translate (https://magictranslate.io): translate any website with a script tag

- 源码仓库：git+https://github.com/magic-translate/magic-translate.git
