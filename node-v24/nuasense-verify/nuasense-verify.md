# nuasense-verify

> 标签: base, ed25519, jcs, merkle, nuasense, opentimestamps, provenance, rfc3161, rfc6962, rfc8785

## 简介

Independent, dependency-free verifier for NuaSense nsp-2 provenance proofs: RFC 8785 canonical JSON, RFC 6962 Merkle audit paths bound to committed counts, Ed25519 origin signatures against pinned keys, and OpenTimestamps / RFC 3161 / pinned Base registry
