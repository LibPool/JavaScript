# dsh-workspace-recollection

> 标签: cordis, cross-session, deepseek-harness, dsh, dsh-plugin, embeddings, long-term-memory, memory, rag, semantic-search

## 简介

给 DeepSeek Harness 的跨会话记忆：按工作区隔离、跨会话共享的长期记忆。常驻 prompt 的只有浅层要点，长文用段级引索定位到段、只取那一段，深层原文（当时的思考、命令、结论）留在本地向量库里按需取回。检索自带噪音过滤与时间通道，零联网（本地嵌入模型），不改动官方内核。
