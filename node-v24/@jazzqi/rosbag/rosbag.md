# @jazzqi/rosbag

> 标签: JavaScript

## 简介

`rosbag` is a node.js & browser compatible module for reading [rosbag](http://wiki.ros.org/rosbag) binary data files.

## 官网

- 官网：https://github.com/jazzqi/rosbag.js#readme
- 源码仓库：git+https://github.com/jazzqi/rosbag.js.git
- npm 页面：https://www.npmjs.com/package/@jazzqi/rosbag

- 2.6.4

- npm 安装：`npm install @jazzqi/rosbag`
- npm registry：https://registry.npmjs.org/@jazzqi/rosbag
- Node 要求：>=8.0.0
