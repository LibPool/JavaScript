# @agora-sdk/social-core

> 标签: agora, community, constellation, neighborhood, react, social-graph, typescript, weather

## 简介

Platform-agnostic client for the Agora social graph (Weather, Constellation, Neighborhood lenses): typed REST transport, provider + feature-gated hooks. Pure data — no crypto.
