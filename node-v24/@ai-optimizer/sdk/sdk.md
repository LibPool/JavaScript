# @ai-optimizer/sdk

> 标签: JavaScript

## 简介

Public SDK for authoring community framework packs for ai-optimizer. Use this to publish your own pack to npm — name it `ai-optimizer-pack-<framework>` and ai-optimizer will load it via the `plugins` config field.
