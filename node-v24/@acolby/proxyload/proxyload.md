# @acolby/proxyload

> 标签: A/B testing, TypeScript, architecture, contract, experimentation, filesystem convention, interface, modular, tooling, versioning

## 简介

A structural standard and toolkit for organizing, typing, loading, and versioning modular TypeScript code at scale. Arbiter enforces a strict filesystem convention for clarity, repeatability, and experimentation in large projects.
