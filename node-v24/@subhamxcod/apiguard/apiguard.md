> 标签: api, api-breaking-change, api-diff, breaking-change, cd, ci, developer-tools, openapi, openapi-diff, openapi3, openapi31, typescript

## 简介

Detect breaking changes between OpenAPI specifications (3.0 & 3.1) so API contracts never silently break downstream consumers.
