# @github-tools/sdk

> 标签: agent, ai, ai-sdk, durable, github, tanstack-ai, tools, workflow

## 简介

A typed tool layer for GitHub AI agents, with presets, human approval, and durable execution. Works with eve, the AI SDK, TanStack AI, Vercel Workflow, and Chat SDK
