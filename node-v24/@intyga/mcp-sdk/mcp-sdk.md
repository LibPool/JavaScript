# @intyga/mcp-sdk

> 标签: ai-agents, authorization, human-approval, mcp, model-context-protocol, webauthn

## 简介

Wrap an MCP server so every tool call is gated behind a cryptographically-signed human approval (local policy + INTYGA gateway step-up).
