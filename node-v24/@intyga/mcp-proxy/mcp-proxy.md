# @intyga/mcp-proxy

> 标签: ai-agents, authorization, human-approval, mcp, model-context-protocol, proxy

## 简介

Stdio proxy that gates a third-party MCP server's tool calls behind a signed human approval — no code changes to the wrapped server.
