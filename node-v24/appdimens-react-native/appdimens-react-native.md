# appdimens-react-native

> 标签: appdimens, appdimens-dynamic, dimensions, dp, expo, foldable, react-native, responsive, scaling, sdp, sp, ssp, tablet

## 简介

AppDimens Dynamic for React Native — responsive dp/sp scaling (sdp, hdp, wdp, ssp…) with 12 strategies, resize and physical units. Same API names as the Android library, pure JS, O(1) per call.
