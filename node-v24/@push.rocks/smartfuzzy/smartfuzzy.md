# @push.rocks/smartfuzzy

> 标签: article search, data filtering, dictionary matching, fuzzy matching, keyword matching, object sorting, search, string matching, text analysis, text similarity

## 简介

A library for fuzzy matching strings against word dictionaries or arrays, with support for object and article searching.
