# @push.rocks/smartsea

> 标签: assets, cache, extraction, native addons, node.js, node:sea, process.dlopen, sea, sidecar, single executable application, typescript

## 简介

The in-executable runtime for Node.js single executable applications: SEA detection, atomic extraction of embedded asset trees into a cache keyed by content hash, and a native addon loader.
