# @push.rocks/smartai

> 标签: AI integration, AI models, AI toolkit, API, Anthropic, OpenAI, TypeScript, asynchronous chat, audio generation, chatbot, content analysis, document classification, document processing, image description, multi-model, multiple providers, provider switching, real-time interaction, streaming chat, synchronous chat, text-to-speech, vision processing

## 简介

Provider registry and capability utilities for ai-sdk (Vercel AI SDK). Core export returns LanguageModel; subpath exports provide vision, audio, image, document, OCR and research capabilities.
