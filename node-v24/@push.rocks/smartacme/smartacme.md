# @push.rocks/smartacme

> 标签: ACME, ACME server, DNS challenges, LetsEncrypt, MongoDB, PKI, RFC 8555, SSL/TLS, TypeScript, automation, certificate authority, certificate management, certificate renewal, crypto, dns-01 challenge, domain validation, http-01 challenge, secure communication, token-based challenges, wildcard certificates

## 简介

A TypeScript-based ACME client and server for certificate management with built-in CA, supporting LetsEncrypt and custom ACME authorities.
