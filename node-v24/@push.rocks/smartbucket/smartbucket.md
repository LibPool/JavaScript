# @push.rocks/smartbucket

> 标签: S3, TypeScript, access control, bucket management, bucket policies, buffer handling, cloud agnostic, data management, data streaming, directory management, environment configuration, file locking, file operations, file transfer, metadata management, multi-cloud, object storage, streaming, trash management, unified storage

## 简介

A TypeScript library providing a cloud-agnostic interface for managing object storage with functionalities like bucket management, file and directory operations, and advanced features such as metadata handling and file locking.
