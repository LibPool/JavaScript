# pen-find

> 标签: ai-agents, claude-code, claude-code-plugin, design, jev, mcp, pen, pen.dev, pencil, search, skill, typesafe

## 简介

Find frames, screens and components in Pen (pen.dev) design files by describing them. Jev ranks every node by meaning; your AI agent only reads the top matches.
