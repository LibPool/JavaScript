# @abtnode/passport

> 标签: JavaScript

## 简介

ABT Node Daemon 提供给 Blocklet 的页面通行证中间件，方便在打开 Blocklet 内的敏感页面时要求管理员身份，比如 `admin_url` 和 `config_url`
