# @kvncrw/bws-mcp-server

> 标签: bitwarden, bitwarden-secrets-manager, bws, claude, mcp, model-context-protocol, secrets

## 简介

MCP server for Bitwarden Secrets Manager. Wraps the official bws CLI so Claude and other MCP clients can manage infrastructure secrets.
