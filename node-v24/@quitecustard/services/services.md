# @quitecustard/services

> 标签: api-client, discord, ocr, start.gg, steam, twitch, typescript

## 简介

Thin serverless-shaped API clients for Discord, Steam, start.gg and Twitch, plus Claude-vision OCR that reads an image into whatever shape the caller declares
