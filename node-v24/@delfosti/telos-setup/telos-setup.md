# @delfosti/telos-setup

> 标签: claude-code, delfosti, gadm, setup, telos

## 简介

Telos setup-in-1-command — installs the GADM kit (skills, security hooks, agents, CLAUDE.md template) into a project, driven by the telos-kit manifest.
