# @nslookup-io/mcp-server

> 标签: ai-tools, claude, dns, dns-health, dns-lookup, dnssec, mcp, model-context-protocol, nslookup, propagation

## 简介

MCP server for DNS lookups (53 record types), DNS health reports (39 checks), global propagation checks, RDAP registration data, hosting reports, DNS change review, SSL/TLS certificates, BIMI/VMC, security scans, GEO (AI readiness) scoring, multi-location
