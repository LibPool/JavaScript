# @snack-uikit/hot-spot

> 标签: JavaScript

## 简介

- Компонент **HotSpot** добавляет к любому контенту (или отображает отдельно) интерактивную точку‑индикатор с настраиваемым внешним видом и анимацией пульсации. - Позволяет гибко управлять положением точки относительно дочернего контента через предустанов
