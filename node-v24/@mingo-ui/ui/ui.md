# @mingo-ui/ui

> 标签: JavaScript

## 简介

面向移动网页的 Web Components 组件库，提供默认 UI、TypeScript 类型、主题定制和按组件导入入口。基于浏览器原生 Custom Elements 与 Shadow DOM，不依赖特定前端框架。
