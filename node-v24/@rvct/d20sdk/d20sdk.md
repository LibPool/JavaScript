# @rvct/d20sdk

> 标签: iframe, penpal, phoenix, postmessage, runtime, sdk

## 简介

`@rvct/d20sdk` is a TypeScript adapter for connecting sandboxed d20-compatible iframe modules to a shell application. It wraps the cross-window bootstrap exchange and returns separate Shell connection and Phoenix session stores for embedded modules.
