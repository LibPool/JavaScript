# @vibecontrols/vibe-plugin-security-onboard

> 标签: bun, onboard, profile-detector, repo-profile, security, vibe, vibe-plugin, vibecontrols

## 简介

Repo profile detector for the repo.onboard lifecycle stage. Detects whether the repo is frontend / backend / cli / mcp / chrome-extension / vscode-extension / mobile / iac / etc. and seeds default security policy.
