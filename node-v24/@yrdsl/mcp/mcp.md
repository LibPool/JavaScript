# @yrdsl/mcp

> 标签: ai, anthropic, claude, mcp, mcp-server, model-context-protocol, yard-sale, yrdsl

## 简介

MCP server for yrdsl.app. Talks to either the hosted API (api.yrdsl.app) or a local self-hosted repo. Lets Claude add, edit, and reserve items on a digital yard sale.
