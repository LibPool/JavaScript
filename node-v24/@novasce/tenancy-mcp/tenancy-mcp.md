# @novasce/tenancy-mcp

> 标签: JavaScript

## 简介

Conector do Novasce Tenancy para a sua IA (Claude Code, Codex, Antigravity, Claude Desktop e Cursor). A chave de IA de cada pessoa fica na configuração da ferramenta, nunca no pacote.
