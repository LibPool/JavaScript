# @syncfusion/ej2-react-a2ui

> 标签: a2ui, agent, ai, ej2, grid, react, syncfusion

## 简介

Syncfusion EJ2 React adapter for the A2UI agent-to-UI protocol (v0.9). Provides a catalog of 55+ production-grade EJ2 components (Grid, Chart, Scheduler, Diagram, Spreadsheet, RichTextEditor, Toast, plus the basic A2UI primitives) exposed as a Zod-validat
