# @syncfusion/ej2-lists

> 标签: Syncfusion, check list, checkbox, data list, dynamic list, ej2, es6 list, group list, infinite list, list component, list gestures, list widget, listview template, listview with checkbox, material list, mobile list, nested view, remote listview, sort, todo, ui listview, virtualization, web components

## 简介

The listview control allows you to select an item or multiple items from a list-like interface and represents the data in interactive hierarchical structure across different layouts or views.
