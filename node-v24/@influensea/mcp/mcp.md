# @influensea/mcp

> 标签: influensea, linkedin, mcp, model-context-protocol, scheduler, social-media

## 简介

Influensea MCP server: let Claude, Cursor or any MCP client write in your voice, save drafts for you to approve, and publish or schedule posts to LinkedIn, X, Threads, Instagram and Facebook.
