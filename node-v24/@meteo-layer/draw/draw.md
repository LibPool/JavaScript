# @meteo-layer/draw

> 标签: annotation, cesium, drawing, geojson, maplibre, measure, meteorology

## 简介

@meteo-layer 绘图工具包（可独立分发）：模式画/选/编辑/测量/GeoJSON 持久化 + 渲染器无关内核 + Cesium/MapLibre 双端适配器 + Vue 工具栏
