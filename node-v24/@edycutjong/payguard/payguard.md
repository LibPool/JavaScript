# @edycutjong/payguard

> 标签: agent-security, ai-agent, eip-3009, guardrail, mcp, payments, pharos, x402

## 简介

GuardianRail — the safety layer x402 lacks: deterministic spend caps, asset-spoof protection, payee allowlist, and eth_call pre-flight simulation before an agent signs. Ships as a library and an MCP server.
