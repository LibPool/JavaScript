# @hxmc/text

> 标签: JavaScript

## 简介

Text for hxmc, in pure Haxe: TrueType fonts (parsing, outlines, an anti-aliased rasterizer), shaping by cmap and kerning with fallback fonts, line layout and a glyph atlas; the system's fonts found on Linux, Windows and macOS
