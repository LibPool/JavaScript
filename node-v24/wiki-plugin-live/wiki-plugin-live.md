# wiki-plugin-live

> 标签: audio, federated wiki, ffmpeg, live capture, plugin, recorder, wiki, workshop

## 简介

Federated Wiki - Live Plugin: the farm records a workshop continuously in one-minute segments into a page's assets, and the item marks each contribution — Begin, Finish, End — on the recorder's clock
