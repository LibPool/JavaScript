# @aecworks/pdfviewer4obv.js

> 标签: JavaScript

## 简介

OBVDoc 采用的了pdf.js 来展示 doc 类型的文件。基于 pdf.js 官方的viewer进行小范围修改。 该仓库fork了github上的官方仓库：[pdf.js@github](https://github.com/mozilla/pdf.js)。 需要定期的对官方的修改进行整合，解决重大的bug和功能的升级。
