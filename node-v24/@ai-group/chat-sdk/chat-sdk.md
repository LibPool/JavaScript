# @ai-group/chat-sdk

> 标签: JavaScript

## 简介

面向 AI 中台平台的前端集成 SDK，支持 OAuth2 安全认证、聊天机器人、智能编辑器、多模态对话，适配 SaaS / 私有化双场景。
