# @open-panel/profile-engine

> 标签: macropad, openpanel, profiles, sqlite, stream-deck

## 简介

Profile/page/button CRUD, zod validation, SQLite persistence (via Node's built-in node:sqlite) and schema-version migrations for OpenPanel.
