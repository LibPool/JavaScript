# @sprigr/apps-datasets

> 标签: JavaScript

## 简介

Write keyed datasets through env.SPRIGR.datasets.append (decisions 0079, 0115): objectID to row_key rows, 5xx-only retry, batches of at most 1,000 rows, and a test helper that checks rows against the manifest's datasets contract.
