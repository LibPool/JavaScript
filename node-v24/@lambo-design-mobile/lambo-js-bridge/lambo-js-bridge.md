# @lambo-design-mobile/lambo-js-bridge

> 标签: JavaScript

## 简介

LamboJsBridge 是一个js 适配sdk 用于处理H5应用和运行时环境的能力调用。支持微信、钉钉等环境。目前已适配微信（WechatAdapter）和企业微信（WeComAdapter）
