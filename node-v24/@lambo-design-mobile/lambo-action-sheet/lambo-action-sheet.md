# @lambo-design-mobile/lambo-action-sheet

> 标签: JavaScript

## 简介

LamboActionSheet 是一个基于vant拓展的动作面板展示组件，在van-action-sheet组件基础上集成了lambo-button-group组件，动作面板底部的按钮组更符合用户使用习惯。
