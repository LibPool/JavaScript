# @greenek/grunt-svg-symbols

> 标签: gruntplugin, icon, icons, map, sprite, sprites, svg, symbols

## 简介

Generate an SVG icon system (based on `<symbol>`) of a specified folder. Lightweight fork of the [Lorti/grunt-svg-symbols](https://github.com/Lorti/grunt-svg-symbols).
