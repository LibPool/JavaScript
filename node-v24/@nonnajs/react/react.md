# @nonnajs/react

> 标签: dependency-injection, di, hooks, ioc, nonna, react, zero-reflection

## 简介

React bindings for @nonnajs/di - a <NonnaProvider> context component plus useInjection()/useOptionalInjection()/useAllInjections()/useInjector() hooks for zero-reflection dependency injection in React apps.
