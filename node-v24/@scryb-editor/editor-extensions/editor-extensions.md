# @scryb-editor/editor-extensions

> 标签: editor, image-resize, markdown, prosemirror, rich-text-editor, table, tiptap, tiptap-extension, typescript, wysiwyg

## 简介

Tiptap extensions for rich text editing: font size and family, line height, indentation, resizable images, tables, drag handle, paste cleanup and an accessibility checker
