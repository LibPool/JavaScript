# @postamico/mdforge

> 标签: ai, chart, charts, document-generation, docx, llm, markdown, markdown-to-docx, markdown-to-pdf, no-chromium, no-puppeteer, pdf, pdfkit, report, word

## 简介

Forge markdown into polished PDF & DOCX. Pure Node, no headless browser. Supports JSON charts and tables. By PostAmico.
