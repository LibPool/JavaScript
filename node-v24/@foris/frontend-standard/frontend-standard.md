# @foris/frontend-standard

> 标签: JavaScript

## 简介

`@foris/frontend-standard` provides the automated enforcement of the Foris frontend standard: the checks that run on every pull request and the CLI that executes them. Frontend work at Foris is done by a full-stack team, so compliance cannot depend on rev
