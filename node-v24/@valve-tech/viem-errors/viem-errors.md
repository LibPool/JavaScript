# @valve-tech/viem-errors

> 标签: custom-error, eip-1193, errors, ethereum, evm, user-rejection, viem, wagmi, wallet

## 简介

Cause-chain-aware error utilities for viem-based dapps. Detect EIP-1193 user rejections (4001 / class name / message regex), extract decoded custom Solidity error names from anywhere in viem's nested cause chain, map raw RPC/wallet/contract errors to shor
