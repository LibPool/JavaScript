# @onenomad/paperclip-plugin-przm-memory

> 标签: mcp, memory, paperclip, paperclip-plugin, przm

## 简介

Give Paperclip agents long-term memory with przm Memory: search and save memories as agent tools, see related memories on issues, and save outcomes of finished issues automatically.
