# @onenomad/paperclip-plugin-github

> 标签: github, paperclip, paperclip-plugin

## 简介

GitHub branch and pull request flow for Paperclip issues: PR status, checks and reviews on the issue, branch and PR creation, and CI alerts to the assignee.
