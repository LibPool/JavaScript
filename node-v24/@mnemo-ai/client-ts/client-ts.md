# @mnemo-ai/client-ts

> 标签: ai, client, memory, mnemosyne, rag, sdk, typescript, vector

## 简介

Typed TypeScript SDK for the Mnemosyne cognitive memory HTTP API. Drop-in alternative to direct library import when consumers prefer RPC over coupling.
