# @wlahsib/mcp-onepiece

> 标签: anime, claude, cursor, fandom, manga, mcp, mcp-server, model-context-protocol, one-piece, onepiece, wiki

## 简介

MCP server for the One Piece Wiki: articles, infoboxes, chapters, episodes, story arcs and a spoiler limit. Works with any MCP client.
