# dsh-session-url

> 标签: deep-link, deepseek-harness, dsh, plugin, session

## 简介

DSH Web GUI plugin: one conversation, one link — mirrors the main-view session into the URL fragment (and opens the linked conversation on load). Browser half only, no dependencies, no telemetry.
