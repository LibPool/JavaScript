# @allowkit/agent-wallet

> 标签: ai-agents, base, payments, react-native, solana, usdc, wallet, x402

## 简介

Self-custodial agent wallet layer for x402: multichain signer bridge over the official @x402 packages (EVM + Solana), Nitro-bridged native custody interfaces (Secure Enclave / StrongBox), and wallet adapters.
