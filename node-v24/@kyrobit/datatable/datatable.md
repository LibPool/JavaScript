# @kyrobit/datatable

> 标签: data-table, grid, grouping, headless, mui, pagination, react, table

## 简介

Headless data-table state (pagination, sorting, search, server-side grouping) fully decoupled from rendering. Bring your own UI, or use the built-in MUI renderer.
