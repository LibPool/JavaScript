# @kyrobit/kyroguard

> 标签: access-control, authorization, drizzle, express, fastify, mongoose, multi-tenant, policies, rbac

## 简介

Policy-based access control with domains, tenants and scopes. A scope is a condition you write against your own tables; kyroguard adds it to every query for that resource. Framework-agnostic core with Fastify, Express, Drizzle (PostgreSQL/MySQL/SQLite), P
