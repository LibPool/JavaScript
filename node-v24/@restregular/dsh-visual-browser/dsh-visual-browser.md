# @restregular/dsh-visual-browser

> 标签: browser, browser-automation, cdp, chrome-devtools-protocol, deepseek, deepseek-harness, dsh-plugin, screenshot, visualization

## 简介

Visual browser for DeepSeek Harness: the Agent drives a real Chrome through a token-light numbered view of interactive elements (never the raw DOM), while the Web UI streams the live page frame, the click point of every action, and a replayable operation
