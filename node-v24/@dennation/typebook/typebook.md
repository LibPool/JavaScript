# @dennation/typebook

> 标签: ai-agents, components, documentation, llms-txt, react, typescript, unplugin

## 简介

A toolkit for documenting React components from their TypeScript types — one bundler-plugin scan, plugins turn it into artifacts (AI-agent docs and more)
