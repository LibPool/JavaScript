# @membership-card-protocol/wallet-sdk

> 标签: JavaScript

## 简介

Wallet SDK for the Card Protocol — wallet-side, key-custody holder functionality: wallet setup, keyring, backup/recovery, sub-card authorization, and card offer review/countersign/acceptance. Depends on @membership-card-protocol/app-sdk.
