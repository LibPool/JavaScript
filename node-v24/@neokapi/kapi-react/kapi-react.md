# @neokapi/kapi-react

> 标签: i18n, internationalization, l10n, localization, nextjs, react, translation, vite, webpack

## 简介

Zero-config i18n for React. Transforms vanilla JSX at build time using W3C HTML5 translatability rules. Supports build-time inlining (zero runtime) and OTA dynamic loading. Extracts translatable content as Kapi Localization Format (KLF).
