> 标签: ai-agents, call-graph, claude-code, code-review, impact-analysis, kotlin, mcp, nestjs, spring, static-analysis

## 简介

See which endpoints a change reaches — static call-flow impact for Spring and Node services, as a CLI, a local web canvas, and an MCP server.
