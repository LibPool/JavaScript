# @kazant/flexgraph

> 标签: diagram, erd, flowchart, graph, layout, orthogonal-routing, sugiyama

## 简介

Flexible relationship graph for the browser: layered layout with strong crossing minimization, ports, orthogonal edge routing with obstacle avoidance, groups and constraints. Plain HTML, CSS & JS.
