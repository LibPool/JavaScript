# @charles_zmw/wechat-automator

> 标签: JavaScript

## 简介

这是一个基于 **Model Context Protocol (MCP)** 的微信小程序自动化服务器。它允许 AI 助手（如 Gemini CLI）直接操作微信开发者工具、获取模拟器状态、执行自动化测试或进行辅助调试。
