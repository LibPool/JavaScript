# @gkoreli/ghostty-vt-js

> 标签: ghostty, libghostty-vt, terminal, typescript, wasm, webassembly

## 简介

Direct JavaScript bindings to Ghostty's canonical libghostty-vt C ABI, with browser, headless, session, server, React, and WASM surfaces.
