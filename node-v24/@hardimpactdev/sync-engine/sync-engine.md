# @hardimpactdev/sync-engine

> 标签: laravel, local-first, offline, react, sqlite, sync

## 简介

TypeScript client for Sync Engine: a local-first SQLite store with an outbox, a sync client and a scheduler, with optional React hooks. Pairs with the Laravel server, hardimpactdev/sync-engine.
