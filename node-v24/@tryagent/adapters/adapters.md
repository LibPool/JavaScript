# @tryagent/adapters

> 标签: guardrails, human-in-the-loop, langgraph, openai-agents, tryagent, vercel-ai-sdk

## 简介

Framework adapters that wire TryAgent human-in-the-loop guardrails into LangGraph, the Vercel AI SDK, and the OpenAI Agents SDK.
