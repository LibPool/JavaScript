## 简介

MCP server + CLI for Altronis — private, on-prem AI in Singapore. Ask the Lyra consultant, estimate AI cost (cloud vs own box vs hybrid, SGD), and pull curated SG AI events, news, and business-formation data. Wraps the public altronis.sg endpoints; read-o
