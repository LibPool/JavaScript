# @oksigenia/ghost-md-publisher

> 标签: admin-api, ghost, ghost-blog, ghost-cms, markdown, publisher, static-publishing

## 简介

Publish articles to Ghost from a Markdown file with YAML front-matter: processes images (resize + format + EXIF), supports native Ghost cards (Product Card, video embeds, bookmarks, callouts, image captions) and creates or updates the post via the Admin A
