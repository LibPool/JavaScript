# prism-code

> 标签: canonicalization, code-hash, content-addressing, deterministic, prism-code, sha256, source-code, stable-hash

## 简介

Deterministic canonicalization and content addressing for source code — stable hashes that ignore line endings, BOMs, trailing whitespace and blank-line drift.
