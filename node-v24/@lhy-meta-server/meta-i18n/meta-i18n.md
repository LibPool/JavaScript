# @lhy-meta-server/meta-i18n

> 标签: bun, i18n, internationalization, interpolation, localization, nodejs, typescript

## 简介

面向 Bun 设计、兼容 Node.js 的服务端国际化（i18n）插件，支持深层属性插值、复数、上下文、格式化与插件扩展
