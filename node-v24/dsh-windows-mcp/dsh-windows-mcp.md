# dsh-windows-mcp

> 标签: automation, computer-use, deepseek-harness, dsh, dsh-plugin, mcp, model-context-protocol, screenshot, ui-automation, windows, windows-mcp

## 简介

Windows desktop automation for DeepSeek Harness — plugs CursorTouch/Windows-MCP (screenshot, UI automation, input, clipboard, processes, registry) into DSH through the official MCP client bridge.
