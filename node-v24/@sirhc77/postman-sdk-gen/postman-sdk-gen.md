# @sirhc77/postman-sdk-gen

> 标签: api-client, api-codegen, api-wrapper, axios, client-generator, codegen, developer-tools, fetch, http-client, openapi-alternative, postman, postman-collection, postman-sdk, rest-client, sdk, typescript, typescript-sdk

## 简介

Generate a fully-typed TypeScript SDK from a Postman collection, with support for Axios or Fetch, folder-based namespacing, and auto-inferred types.
