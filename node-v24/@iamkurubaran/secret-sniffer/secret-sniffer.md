# @iamkurubaran/secret-sniffer

> 标签: api-key, credentials, detect-secrets, entropy, git-hook, gitleaks, leak, pre-commit, scanner, secrets, security, token

## 简介

Scan files, directories, and git staged changes for leaked API keys, tokens, and credentials using entropy and pattern-based detection.
