# @stefanprobst/remark-lint-no-auto-links

> 标签: JavaScript

## 简介

Remark plugin to lint markdown for autolinks. Autolinks are URLs enclosed in `<` (less than) and `>` (greater than) characters, e.g. `<https://example.com>`. Autolinks are invalid in mdx v2.
