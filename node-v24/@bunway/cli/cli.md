# @bunway/cli

> 标签: bun, bunway, cli, drizzle, elysia, framework, scaffolding, sveltekit

## 简介

Rails-inspired Bunway CLI for creating, generating, migrating, and running Bun, Elysia, Drizzle, and SvelteKit applications.
