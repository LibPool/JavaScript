# @dornick/parsers

> 标签: JavaScript

## 简介

File parser registry for Dornick. Lazy VFS sub-mounts under /user/files/<id>/parsed/*. Built-in CSV/JSON/text; companion packages add PDF, DOCX, XLSX, OCR, ML, audio.
