# @dornick/webmcp

> 标签: agent, browser, mcp, model-context, modelContext, polyfill, tools, typescript, w3c, webmcp

## 简介

Zero-dependency, spec-conformant polyfill and TypeScript types for the W3C WebMCP API (document.modelContext). Standalone — no Dornick required.
