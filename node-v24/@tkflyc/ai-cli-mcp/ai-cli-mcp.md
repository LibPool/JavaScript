# @tkflyc/ai-cli-mcp

> 标签: ai-agent, background-jobs, circuit-breaker, claude, claude-code, cli, codex, mcp, model-context-protocol, openai-compatible

## 简介

Run Claude, Codex, Antigravity (agy), and any third-party OpenAI-compatible API through MCP with background jobs. Self-maintained, registry-based architecture.
