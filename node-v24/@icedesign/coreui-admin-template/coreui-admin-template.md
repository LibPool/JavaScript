# @icedesign/coreui-admin-template

> 标签: ice-scaffold

## 简介

该模板基于社区的 CoreUI 改造而成，使用 react-scripts 构建，支持 CoreUI 的所有功能，同时也支持飞冰基础组件和区块的使用， 支持 Iceworks 一键创建项目和完整的 GUI 操作
