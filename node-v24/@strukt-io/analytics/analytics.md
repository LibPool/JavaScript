# @strukt-io/analytics

> 标签: analytics, hook, hooks, react, strukt, tracker, tracking

## 简介

Fork of the use-ackee library, this combined the react hook with the tracker library. In addition to the original features, it allows for more flexibility in how data is sent to the backend.
