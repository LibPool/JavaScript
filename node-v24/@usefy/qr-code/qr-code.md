# @usefy/qr-code

> 标签: barcode, canvas, generator, headless, qr, qr-code, qrcode, react, reed-solomon, rsc, svg

## 简介

QR code generator for React — hand-written ISO/IEC 18004 encoder with Reed–Solomon error correction, SVG/canvas/PNG output, module & eye shapes, gradients, logo embedding with scannability validation, and a zero-dependency RSC-safe headless core
