# @emdzej/nfsx-fsc

> 标签: JavaScript

## 简介

FSC + cert + identity host orchestrator for nfsx. Wraps @emdzej/nfsx-runtime with high-level FscManager operations (checkFsc / getFsc / getVin / getFsStatus / …) over the 00swt*.ipo CABI surface. The TypeScript equivalent of winkfpt's coapiKf* C functions
