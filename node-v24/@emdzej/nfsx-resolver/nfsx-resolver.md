# @emdzej/nfsx-resolver

> 标签: JavaScript

## 简介

Lookup-chain resolver for BMW NFS / WinKFP SP-Daten. Loads HWNR.DA2 + KFCONF10.DA2 + kmm_SIT.txt and exposes part-number → flash-context queries. The C-side equivalent of winkfpt's `coapiKfReadKfConf*` + planner machinery. Anchor: ../../docs/architecture.
