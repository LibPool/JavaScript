# @emdzej/nfsx-flash

> 标签: JavaScript

## 简介

Flash-programming orchestrator for nfsx. Wraps nfsx-runtime + nfsx-fsc + nfsx-flash-data with the 7-stage pipeline (RESOLVE → PRECHECK → AUTHENTICATE → SESSION → TRANSFER → AIF_WRITE → POSTCHECK), dry-run default, per-stage confirmation gates, and a strat
