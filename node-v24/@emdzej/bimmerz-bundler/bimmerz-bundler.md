# @emdzej/bimmerz-bundler

> 标签: JavaScript

## 简介

Curate a BMW software install (INPA / EDIABAS / NCS) into a small zip web tools (inpax-web, future ediabasx-web, future ncsx) can import into OPFS. Uses gitignore-style exclude patterns.
