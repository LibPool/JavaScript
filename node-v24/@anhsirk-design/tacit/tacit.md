# @anhsirk-design/tacit

> 标签: agents, ai, context, local-first, opencode, retrieval

## 简介

Local-first context engine for AI coding agents: three persistent graphs (code, project memory, trial-and-error knowledge), deterministic retrieval, native OpenCode plugin. No LLM, no embeddings, no network.
