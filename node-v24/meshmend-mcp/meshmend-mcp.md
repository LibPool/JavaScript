# meshmend-mcp

> 标签: 3d-printing, 3mf, manifold, mcp, mesh-repair, model-context-protocol, stl, watertight

## 简介

Check and repair STL and 3MF meshes on your own computer from any MCP client: holes, flipped faces, inside-out shells, non-manifold edges.
