## 简介

DSH 插件社区：把 GitHub Discussions 变成插件的讨论区、把 Issues 变成 bug 汇报入口、把 Stars 变成评分。插件详情页里就能看到社区在说什么。/ A community layer for DSH plugins: GitHub Discussions as the discussion board, Issues as the bug inbox, stars as the rating — visible right inside the plugin detai
