# @lettrove/embed

> 标签: drag-and-drop, email-builder, email-editor, embeddable, html-email, landing-page, page-builder, popup, sdk, white-label

## 简介

The embeddable drag-and-drop email editor and page builder for web apps: put Lettrove in your product in a few lines, white-labeled, with AI built in. The editor loads from lettrove-embed.com; this package is a 5 KB loader.
