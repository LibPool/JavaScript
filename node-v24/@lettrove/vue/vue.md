# @lettrove/vue

> 标签: drag-and-drop, email-builder, email-editor, embeddable, page-builder, vue, vue-component, vue3, white-label

## 简介

<LettroveEditor />: the embeddable drag-and-drop email editor and page builder as a Vue 3 component. White-labeled, AI built in, HTML that renders in every inbox.
