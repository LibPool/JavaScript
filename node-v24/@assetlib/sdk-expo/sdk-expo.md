# @assetlib/sdk-expo

> 标签: JavaScript

## 简介

Expo SDK 54 to 57 (React Native 0.81 to 0.86) image delivery adapter for `@assetlib/sdk-core`. One integration targets iOS, Android, and Expo web. This is a preview SDK, not separate Swift or Kotlin SDKs.
