# @experttoolkit/sdk

> 标签: calculator, convert-units, experttoolkit, mcp, measurement, nist, si-units, unit-conversion, unit-converter

## 简介

Typed client for the ExpertToolkit computation APIs — unit conversion across 1,800+ units and 100+ dimensions with step-by-step audit trails, batch conversion, unit registry search, retry and caching built in. NIST/BIPM-aligned factors.
