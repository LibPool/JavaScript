# @bitbysoft/document-kit-invoice

> 标签: JavaScript

## 简介

Invoice domain plugin for BitBySoft DocumentKit — maps generic AI extraction output into a typed invoice structure via a replaceable InvoiceProvider. Reuses ai-extraction and ocr; duplicates no OCR or AI logic. Depends on the ai-extraction plugin at regis
