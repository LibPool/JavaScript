# @kernloop/kernel

> 标签: JavaScript

## 简介

Kernloop Layer 0 — the kernel (spec §3). P0 scope: the AuditChain only — an append-only, hash-chained, SIEM-compatible JSONL event log with tamper-evident verification (spec §3.1, §3.3, §10 item 1). Registry, router, ladder, bus, and adapters arrive in P1
