# @mmj-map/palette

> 标签: color, map-style, maplibre, mcp, mcp-server, mmj, no-api-key, palette, self-hosted

## 简介

MCP server that derives a full map palette from four anchor colours and builds a ready MapLibre style. Self-hosted maps, no API key.
