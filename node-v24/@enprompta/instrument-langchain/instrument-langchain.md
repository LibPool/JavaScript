# @enprompta/instrument-langchain

> 标签: enprompta, instrumentation, langchain, observability, opentelemetry, tracing

## 简介

Enprompta framework instrumentation for LangChain — emits typed, nested OpenTelemetry spans that Enprompta ingests as first-class Retrieval/Tool/Agent spans.
