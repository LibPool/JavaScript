# @caisson-sh/artifact-render

> 标签: JavaScript

## 简介

Shared render primitive for public-facing compliance artifacts: a readiness-language claim filter, allowlist-based field redaction, and citation-row rendering — the seam the ISO 27001 SoA generator and the trust-page generator both render through.
