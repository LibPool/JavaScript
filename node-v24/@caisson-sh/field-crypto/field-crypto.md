# @caisson-sh/field-crypto

> 标签: JavaScript

## 简介

Per-tenant authenticated field encryption: HKDF key derivation, AES-256-GCM, a versioned envelope, a Drizzle column type, and a pluggable FieldKeyProvider with a KMS seam.
