# @caisson-sh/audit-worm

> 标签: JavaScript

## 简介

Write-once (WORM) artifact store with an S3 Object-Lock backend, a SHA-256 append-only audit chain with a trusted WORM anchor, and an append-only locked-version database with a derived current version.
