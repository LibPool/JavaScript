# @caisson-sh/guardrails

> 标签: JavaScript

## 简介

Content-safety layer: swappable Moderator port (local | provider | custom) + TS-native PII engine (mask / hash / reversible-tokenize via field-crypto) behind a fail-closed input/output guard.
