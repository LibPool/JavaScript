# @qdkj/redis-mcp-server

> 标签: cache, key-value, mcp, model-context-protocol, redis

## 简介

Redis 数据库操作 MCP 服务端，提供键查询、字符串/Hash/List/Set 操作、键信息、原始命令执行能力；通过 MCP 协议与 Cursor/Claude Desktop/CodeBuddy 等 AI 客户端通信。
