# @knowvah/dot-react

> 标签: @knowvah/dot-engine, diagram, dot, graphviz, react, react-component, svg

## 简介

A React <DotDiagram> component that renders Graphviz DOT to SVG in the browser — powered by the pure-TypeScript @knowvah/dot-engine.
