> 标签: connect, context, eagle eye, hoc, hooks, observable, observable context, react, react context, react hooks, react observable conttext, react state, state, state management, state manager, useContext

## 简介

Observable react context - Update-friendly context. Prevents automatic total component tree tear-down and re-rendering during context updates.
