# @asheeui/puck

> 标签: component-library, design-system, expo, nativewind, page-builder, puck, react, react-native, tailwindcss, typescript, visual-editor

## 简介

The AsheeUI Puck integration: one block registry behind one import, routed by the bundler so an editor composes a page on the web and a device renders the stored page with the native components.
