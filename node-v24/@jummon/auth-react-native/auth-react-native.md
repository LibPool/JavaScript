# @jummon/auth-react-native

> 标签: auth, authentication, expo, jummon, oidc, passkey, pkce, react-native

## 简介

React Native / Expo adapters for @jummon/auth's agnostic core: AsyncStorage+SecureStore storage, expo-crypto PKCE, Linking-based social-login navigation, and react-native-passkey WebAuthn. Headless-only (mode: "headless") — no hosted-redirect mode on RN.
