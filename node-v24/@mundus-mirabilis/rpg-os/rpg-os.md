# @mundus-mirabilis/rpg-os

> 标签: brp, dnd, dungeons-and-dragons, game-engine, rpg, rpg-os, rules-engine, the-dark-eye, wasm, webassembly

## 简介

Universal RPG rule engine (C++23 compiled to WebAssembly). Loads ANY ruleset JSON at runtime and resolves stats, checks, and combat in Node.js and the browser.
