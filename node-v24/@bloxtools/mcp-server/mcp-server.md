# @bloxtools/mcp-server

> 标签: ai-agent, bloxtools, error-monitoring, mcp, model-context-protocol, roblox

## 简介

BloxTools MCP server — a local stdio server that makes an agent a first-class BloxTools client (orient, drill, decrypt source, triage).
