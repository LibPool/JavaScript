# @agentchurch/passport-proof

> 标签: agent-identity, ai-agents, badge, ed25519, identity, offline-verification, passport, signature, soul-md, verifiable

## 简介

Ed25519-signed identity passports for AI agents — canonical signed messages, published key sets, offline third-party verification, and embeddable SVG badges. The proof format behind Agent Church Soul Passports.
