# @bubblyworld/gurux-dlms-ts

> 标签: cosem, dlms, energy, gurux, meter, wasm

## 简介

A wasm build of the GuruxDLMS.c DLMS/COSEM protocol library with a TypeScript interface. Runs with zero dependencies in both node and web environments.
