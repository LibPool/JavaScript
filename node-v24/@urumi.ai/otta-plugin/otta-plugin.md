# @urumi.ai/otta-plugin

> 标签: JavaScript

## 简介

Otta EmDash plugin — sandbox-clean (workerd, Block Kit, ctx.http + allowedHosts only). Runs commerce in-process on the host-injected ctx.storage; no React, no DB driver.
