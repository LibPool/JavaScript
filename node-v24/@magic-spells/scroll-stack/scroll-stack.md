# @magic-spells/scroll-stack

> 标签: custom-elements, fade, list, scroll, scroll-animation, scroll-stack, stack, sticky, web-components

## 简介

Natively scrolling list web component whose items animate at the scrollport edges instead of clipping — sticky stack handoff, vertical/horizontal, pure CSS effects driven by a progress custom property, no dependencies
