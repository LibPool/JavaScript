# @magic-spells/puzzle-win32-x64

> 标签: JavaScript

## 简介

The Windows x64 binary for the Puzzle framework CLI. Also installed on Windows ARM64, which runs it under the OS's x64 emulation — hence the two-entry "cpu" field.
