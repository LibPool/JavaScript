# dsh-pr-watch

> 标签: ci, cordis, deepseek-harness, dsh, dsh-plugin, gh, github, pull-request, status

## 简介

PR status window for the DeepSeek Harness Web GUI — floating pull-request chips with CI check tallies, review/mergeability badges, auto-discovery of your open PRs, and per-session branch scoping. Uses your existing gh CLI auth.
