> 标签: alerts, backup, claude-code, dell-emc, email, mcp, networker, pagerduty, ppdm, sla, slack, teams, webhook

## 简介

Backup alerting for Dell EMC PPDM and NetWorker — webhook events and proactive SLA and storage checks, sent to Slack, Teams, PagerDuty and email, with an MCP server for Claude Code
