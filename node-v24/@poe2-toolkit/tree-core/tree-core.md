# @poe2-toolkit/tree-core

> 标签: geometry, passive-tree, path-of-exile, poe2, skill-tree

## 简介

Headless, framework-agnostic geometry engine for the Path of Exile 2 passive tree. Data in, game-accurate scene out. Positions and sizes derived from the source data, never hand-tuned.
