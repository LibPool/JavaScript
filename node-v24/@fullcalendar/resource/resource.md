# @fullcalendar/resource

> 标签: calendar, event, full-sized, fullcalendar, resource, scheduler

## 简介

FullCalendar v6 only (in v7, this is built into each framework's scheduler package, e.g. @fullcalendar/react-scheduler). Base support for resources, required by resource views
