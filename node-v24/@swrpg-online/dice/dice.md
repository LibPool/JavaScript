# @swrpg-online/dice

> 标签: cli, dice, dice-roller, edge-studio, fantasy-flight-games, ffg, genesys, narrative-dice, roleplaying, rpg, star wars, star-wars, swrpg, tabletop, typescript

## 简介

A TypeScript library that creates dice rolls using the narrative dice system for the Star Wars Roleplaying Game by Fantasy Flight Games and Edge Studio.
