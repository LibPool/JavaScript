# @catidegla/driftline

> 标签: anthropic, canary, ci, drift, evals, gemini, llm, model-drift, monitoring, observability, openai, regression-testing, statistics

## 简介

Detect when your LLM provider changes the model under a name that did not change. Statistical drift detection over committed probes, provider identity capture, zero dependencies, no service.
