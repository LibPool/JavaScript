# @edgehero/pi-dispatch

> 标签: ai-agent, autonomous-agents, azure-devops, bullmq, cli, coding-agent, cron, docker, forgejo, gitea, github, gitlab, job-queue, pi, pi-coding-agent, podman, self-hosted

## 简介

The pi-dispatch worker and CLI: runs the pi coding agent as a self-hosted service, one locked down Docker or Podman container per job, with spend caps checked before anything is spent, plus init, up, doctor and service install.
