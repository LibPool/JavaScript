# @weftsh/sandbox

> 标签: ai-agents, aws, code-interpreter, e2b, firecracker, microvm, sandbox, self-hosted

## 简介

Weft Sandboxes SDK helpers and admin CLI. Use the unmodified E2B SDK for sandboxes; use this package to configure it and to manage teams, keys, egress policies and templates.
