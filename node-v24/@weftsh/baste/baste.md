# @weftsh/baste

> 标签: ci, cli, continuous-integration, firecracker, git-hooks, github-actions, local-ci, pre-push, tart

## 简介

Run your GitHub Actions workflows locally in a fresh VM on every git push, and post the result to GitHub as a check you can require.
