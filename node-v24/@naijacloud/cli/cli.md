# @naijacloud/cli

> 标签: cli, deployment, devops, hosting, mcp, model-context-protocol, naijacloud

## 简介

Command-line interface for NaijaCloud hosting: authenticate, and manage projects, services, deployments, domains and environment variables. Also serves those operations to AI agents over MCP via `naijacloud mcp`.
