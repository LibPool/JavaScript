# @lodz/sdk

> 标签: attribution, basis-points, bitcoin, btcfi, solana, yield

## 简介

Typed client for the LODZ BTC yield layer on Solana. Reports yield as sustainable, emissions and counterparty, and identifies BTC assets by mint.
