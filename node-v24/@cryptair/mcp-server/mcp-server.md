# @cryptair/mcp-server

> 标签: agent-tools, ai-agents, anthropic, attestation, claude, cryptair, hedera, mcp, model-context-protocol

## 简介

MCP server for Cryptair — cryptographic attestation for AI agents on Hedera Hashgraph. Lets agents prove agreements, certify documents, and verify counterparty claims with on-chain receipts.
