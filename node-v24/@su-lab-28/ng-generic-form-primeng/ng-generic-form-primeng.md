# @su-lab-28/ng-generic-form-primeng

> 标签: angular, bootstrap, component library, primeng, tailwind, ui library

## 简介

This Angular library was developed to accelerate form creation. The core idea is to build forms based on a JSON object structure, with all components being generated using [PrimeNG](https://primeng.org/).
