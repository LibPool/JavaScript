# @rivia-labs/oban-ts

> 标签: background-jobs, cron, drizzle, job-queue, knex, oban, outbox, postgres, postgresql, prisma, transactional-outbox, typeorm, worker

## 简介

Robust job processing and transactional outbox for TypeScript, backed by PostgreSQL. A port of Elixir's Oban with pluggable ORM adapters (TypeORM, Knex, Drizzle, Prisma, pg).
