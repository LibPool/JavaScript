# @smwb/onreel-git-mcp

> 标签: git, github, gitlab, gitverse, issue-tracker, jira, mcp, onreel, sourcecraft, typescript, worktree

## 简介

Библиотека модулей, выделенных из onreel: git-операции и безопасные пути, список файлов worktree, жизненный цикл worktree против порта WorktreeStore, адаптеры трекеров GitHub/GitLab/Jira/SourceCraft/GitVerse/локального, MCP-сервер на stdio и готовый MCP-с
