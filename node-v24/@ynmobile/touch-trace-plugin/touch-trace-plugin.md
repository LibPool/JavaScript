# @ynmobile/touch-trace-plugin

> 标签: axios, fetch, plugin, spanid, trace, traceid, tracing, vue, vue2, xhr

## 简介

全链路日志追踪能力独立插件包:Vue2 工程一行 Vue.use 接入,自动为所有后端请求注入 X-Trace-Id / X-Span-Id / X-Menu-Id。
