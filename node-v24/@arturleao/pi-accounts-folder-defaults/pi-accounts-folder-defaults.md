# @arturleao/pi-accounts-folder-defaults

> 标签: accounts, anthropic, codex, copilot, oauth, pi-accounts, pi-coding-agent, pi-extension, pi-package

## 简介

Per-folder default OAuth accounts for @narumitw/pi-accounts. Pin a named account to a directory tree; every new Pi session under it uses that account.
