# @alternatefutures/ac-auth-react

> 标签: JavaScript

## 简介

React components and hooks for Sign in with Alternate Clouds: AuthProvider, SignIn, SignInButton, UserButton, SignedIn, SignedOut, useUser, useSession, useOrganization. The same shadcn primitives, palette and typography as the Alternate Clouds web app.
