# @neutree-ai/sse-consumer

> 标签: JavaScript

## 简介

Reads the Neutree Agent Platform's SSE turn streams: a neutral SSE line reader (readSSE) and a turn runner (runTurn) with plugins, idle timeout and one reconnect.
