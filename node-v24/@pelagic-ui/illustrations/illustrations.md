## 简介

Pelagic UI illustrations — 24 original, themeable SVG empty-state scenes (no data, no results, offline, 404, …) that follow every Pelagic theme through CSS variables. Zero dependencies; React, Vue, Svelte, Angular, Astro, web component and React Native en
