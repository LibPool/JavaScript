# @openpets/stripe

> 标签: api-keys, opencode, payments, plugin, restricted-keys, stripe

## 简介

Generate Stripe Dashboard URLs to create restricted API keys with specific permissions. Supports presets for common use cases like MRR tracking, billing, and payments.
