# @openpets/gitlab

> 标签: ci, devops, git, gitlab, opencode, plugin

## 简介

GitLab integration plugin for OpenCode - manage projects, issues, merge requests, CI/CD pipelines, and more. Includes a GitLabClient class for programmatic access.
