# @openpets/remove-bg

> 标签: background-removal, image-processing, opencode, openpets, plugin, remove-bg, removebg

## 简介

OpenPets plugin for the remove.bg API. Remove image backgrounds from URLs, local files, or base64 images, save processed results, check account credits, and submit difficult examples to the improvement program.

## 官网

- 官网：https://www.remove.bg/api
- 源码仓库：https://github.com/raggle-ai/pets/pets/remove-bg
- npm 页面：https://www.npmjs.com/package/@openpets/remove-bg
