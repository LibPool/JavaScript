# @openpets/hypothes

> 标签: annotations, highlights, hypothesis, opencode, openpets, plugin, web-annotations

## 简介

Search, create, and manage web annotations using the Hypothesis API. Annotate any web page, search highlights by URL or topic, and organize with tags and groups.
