# @cresva/acp-mcp

> 标签: acp, agent-commerce-protocol, ai-agents, claude, cresva, ecommerce, mcp, model-context-protocol, storefront

## 简介

MCP server for Cresva. scan_store reports whether AI agents can find, understand and buy from any public store, with no key required. Seven further tools wrap the Cresva ACP storefront API.
