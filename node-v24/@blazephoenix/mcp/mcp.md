# @blazephoenix/mcp

> 标签: ai-agents, base, blazephoenix, byo-rpc, defi, dex, dex-aggregator, ethereum, llms-txt, mcp, model-context-protocol, on-chain-quoter, swap

## 简介

Local MCP server for BlazePhoenix: quotes, unsigned calldata, simulation and solvency, all read through your own RPC. It never signs and never holds keys.
