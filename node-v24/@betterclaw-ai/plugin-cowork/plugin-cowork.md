# @betterclaw-ai/plugin-cowork

> 标签: ai-agents, approval-gate, claude-desktop, cowork, workflow-enforcement

## 简介

BetterClaw plugin for Anthropic Cowork (in Claude Desktop). Enforces workflow graphs over Cowork's verified connectors via shell-command hooks.
