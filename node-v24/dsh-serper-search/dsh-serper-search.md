# dsh-serper-search

> 标签: deepseek-harness, deepseek-search-api, dsh-plugin, serper, web-search

## 简介

Merged, cached, health-aware web search for the DeepSeek Harness: DeepSeek Search API (primary) + serper.dev Google results (secondary), interleaved by a fixed ratio and registered as one provider on the ctx.web seam so the built-in web_search tool serves
