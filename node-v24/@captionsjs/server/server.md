# @captionsjs/server

> 标签: animated-captions, burn-in, captions, cli, ffmpeg, skia-canvas, subtitles, video

## 简介

Burn captions.js animated word-level captions into video with FFmpeg — same renderer as the browser preview, no headless browser.
