# @rmdes/indiekit-endpoint-conversations

> 标签: activitypub, bluesky, conversations, indiekit, indiekit-plugin, indieweb, mastodon, textcasting, webmention

## 简介

Conversation aggregation endpoint for Indiekit. Backend enrichment service that polls Mastodon/Bluesky notifications and serves JF2-compatible data for the interactions page.
