# @ind.ie/acme-v2

> 标签: ACME, fork, v2

## 简介

Fork of acme-v2.js for use in the ACME TLS fork of Greenlock.js that removes the telemetry and the artificial and privacy-eroding email address requirement for Let’s Encrypt certificates.
