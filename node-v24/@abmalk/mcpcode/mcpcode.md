# @abmalk/mcpcode

> 标签: cli, code-generation, codegen, mcp, mcp-server, mcp-tools, model-context-protocol, type-safe, typescript

## 简介

Generate type-safe TypeScript wrappers for Model Context Protocol (MCP) tools. Connects to MCP servers via STDIO, discovers tools automatically, and generates clean, type-safe code.
