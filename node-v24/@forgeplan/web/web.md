# @forgeplan/web

> 标签: decisions, forgeplan, graph, sveltekit, visualization

## 简介

Interactive realtime web map for a Forgeplan workspace. Ships a pre-built SvelteKit app and a tiny init/start CLI — no npm install at user side.
