# @velajs/cloudflare-access

> 标签: access, cloudflare, jwks, jwt, oidc, vela, zero-trust

## 简介

Zero Trust / OIDC identity for Vela: RS256-pinned JWKS verification, fail-closed resolveIdentity + composeResolvers, an issuer-preset generic JWKS adapter, and a Vela guard/module bridge into @velajs/authz
