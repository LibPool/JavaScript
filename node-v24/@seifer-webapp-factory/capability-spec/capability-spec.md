# @seifer-webapp-factory/capability-spec

> 标签: JavaScript

## 简介

capability-spec — de gedeelde spec van de capability-module-tier: de enige bron van het CapabilityModuleManifest-interface en zijn validator. Modules importeren hiervandaan i.p.v. het type + de validator lokaal te her-declareren, zodat er geen drift tusse
