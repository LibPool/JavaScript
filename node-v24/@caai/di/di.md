# @caai/di

> 标签: auto inject, caai, caai-di, clean architecture, constructor injection, dependency injection, di, function injection, inversion of control, ioc, lightweight, minimalist, nodejs, service locator, ts di, typescript, zero dependencies

## 简介

`@caai/di` is a minimalist TypeScript dependency injection library for Node.js that automatically resolves and injects dependencies into constructors and functions. Designed with zero external dependencies, it powers the Caai framework.
