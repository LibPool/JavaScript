# @hoodstack/agent-kit

> 标签: agent, ai-agents, ethereum, hoodstack, mcp, model-context-protocol, robinhood-chain, tools, web3

## 简介

Give AI agents safe, typed access to Robinhood Chain through HoodStack: read chain state, inspect tokens, and simulate transactions. Ships framework-agnostic tools and an MCP server.
