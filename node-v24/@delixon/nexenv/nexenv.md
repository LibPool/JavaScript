# @delixon/nexenv

> 标签: cli, developer-tools, devtools, environment-manager, local-first, nexenv, per-project-environment, rust, stack-detection, tauri

## 简介

Per-project development environment manager. Detects stack, isolates variables, opens projects ready to work. Desktop + CLI. Source-available (FSL-1.1-ALv2).
