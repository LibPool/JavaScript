# @uwmd/module-data-center

> 标签: colocation, commercial-real-estate, data-center, module, pue, underwriting, uwmd

## 简介

Compatibility shell for the retired official data-center module (RFC 0039). Since RFC 0080 data_center is a builtin class in @uwmd/core; this package declares no class, section, calculation or rule, and exists so existing installs and org.uwmd.datacenters
