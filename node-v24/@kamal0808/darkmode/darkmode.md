# @kamal0808/darkmode

> 标签: JavaScript

## 简介

DarkMode.js is a lightweight JavaScript library that dynamically enables a dark mode on any website. It intelligently analyzes the colors of your page and creates a dark mode with perfectly contrasting colors.
