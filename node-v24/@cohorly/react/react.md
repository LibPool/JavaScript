# @cohorly/react

> 标签: analytics, cohorly, mixpanel, product-analytics, react, tracking

## 简介

React bindings for Cohorly, hosted product analytics (Mixpanel-style). <CohorlyProvider> and useCohorly() on top of @cohorly/web.
