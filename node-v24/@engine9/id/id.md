# @engine9/id

> 标签: JavaScript

## 简介

Browser client for engine9 identity: add the Delegate Login widget (log in, switch email, change role, log out in one dialog) and Level-based content gates to any website with one script tag, verify Identity Tokens, and optionally talk to @engine9/core.
