# @ljwei-stak/dsh-fixed-port-bridge

> 标签: bundle, coopanion, deepseek-harness, dsh, dsh-plugin, port, tcp-forward, websocket

## 简介

给 DSH 一个固定的本地端口：在宿主进程内监听你指定的端口，转发到 DSH 每次启动都会变的随机 web 端口。
