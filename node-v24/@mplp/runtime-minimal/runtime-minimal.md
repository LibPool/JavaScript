# @mplp/runtime-minimal

> 标签: ai-agent-lifecycle, lifecycle, mplp, multi-agent, protocol

## 简介

Public minimal runtime helper package for MPLP v1.0.0. Exposes runtime-level AEL/VSL/orchestrator artifacts, not protocol SSOT objects.
