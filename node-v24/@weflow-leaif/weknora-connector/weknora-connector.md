# @weflow-leaif/weknora-connector

> 标签: console, extension, knowledge-base, weflow, weknora

## 简介

WeKnora Connector settings UI for the Weflow Console. Loads through the platform ExtensionHost to configure WeKnora knowledge-base integration (base URL, API key, knowledge-base whitelist, timeout).
