# @statedelta/react

> 标签: hooks, inspector, launcher, observability, react, statedelta, typescript, useSyncExternalStore

## 简介

React bindings for the StateDelta launcher — hooks, context and devtools to observe a LaunchRequest's full lifecycle (phases, chain, timeline, logs, domain events) in the frontend
