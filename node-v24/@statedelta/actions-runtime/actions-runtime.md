# @statedelta/actions-runtime

> 标签: JavaScript

## 简介

Substrato de execução do actions: frame (scope chain léxica), portas interna/externa + gates (entry/exclusive), registry O(1), signal/result, watchers e execution-report. Invoca um executor OPACO — cego a interp/jit. Consome o IR do actions-core.
