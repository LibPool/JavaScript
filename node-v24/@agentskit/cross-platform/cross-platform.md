# @agentskit/cross-platform

> 标签: agentskit, ai-agents, bun, child-process, cross-platform, deno, node, portability, spawn, windows

## 简介

One place for OS and runtime portability in the AgentsKit ecosystem: spawn, paths, line endings and filesystem that behave the same on Windows, macOS and Linux under Node, Bun and Deno.
