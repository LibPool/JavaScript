# @hatchkit/dev-plugin-next

> 标签: JavaScript

## 简介

Next.js plugin for hatchkit's local-dev integration. Writes the project's Caddy fragment on `next dev` startup and prints a Tailscale-URL banner alongside Next's own startup output.
