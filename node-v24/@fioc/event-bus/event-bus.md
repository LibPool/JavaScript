# @fioc/event-bus

> 标签: command-pattern, cqrs, ddd, dependency injection, di container, domain-driven-design, domain-events, event-bus, event-driven, event-handlers, event-sourcing, fluent api, interceptors, ioc, javascript, mediator-pattern, microservices, middleware, modular di, query-pattern, tree-shakeable, type-safe, typescript

## 简介

Type-safe event bus with CQRS support for FIoC. Build event-driven architectures with commands, queries, notifications, and middleware - fully integrated with dependency injection.
