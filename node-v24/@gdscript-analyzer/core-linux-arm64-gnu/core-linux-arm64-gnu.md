# @gdscript-analyzer/core-linux-arm64-gnu

> 标签: analyzer, completion, diagnostics, gdscript, godot, godot-4, language-server, lsp, napi, static-analysis, type-inference

## 简介

Headless GDScript (Godot 4.x) static analysis for Node — diagnostics, type-aware hover, completion, symbols, and navigation. The native binding of gdscript-analyzer (Roslyn for Godot).
