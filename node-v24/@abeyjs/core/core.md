# @abeyjs/core

> 标签: JavaScript

## 简介

This package is AbeyJs stripped to the spine: **one channel**, **typed events**, **intents**, and the naming rules everything else hangs on. No screens, no network stack, no flow engine, no agents—those imports **this**.
