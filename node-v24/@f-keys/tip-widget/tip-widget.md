# @f-keys/tip-widget

> 标签: bip21, bitcoin, cashapp, client-side, creator, crypto, custom-element, dogecoin, donate, donation, embeddable, ethereum, f-keys, kofi, no-fee, obs, obs-overlay, paypal, qr, qr-code, streamer, tip, tip-jar, tipping, tips, tipstreams, twitch, venmo, web-component, widget, zero-dependency

## 简介

Embeddable multi-method tip QR web component for streamers and creators. One <script> tag, zero dependencies, nothing leaves the browser. Deep-links to crypto (BIP-21) + PayPal, Cash App, Venmo, Ko-fi. No account, no custody, no fees.
