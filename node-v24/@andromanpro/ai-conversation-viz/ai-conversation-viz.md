# @andromanpro/ai-conversation-viz

> 标签: ai, canvas, chatgpt, claude, conversation, d3-force, force-directed, graph, jsonl, llm, threejs, visualization

## 简介

Force-directed visualization of human↔AI conversation sessions with multi-agent orchestration support (Task tool, sub-agents). Parses Claude Code JSONL, ChatGPT exports, Anthropic API messages. Zero deps, Canvas 2D + WebGL + Three.js 3D.
