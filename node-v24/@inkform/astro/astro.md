# @inkform/astro

> 标签: api-reference, astro, astro-integration, docs, documentation, llms-txt, mdx, openapi, pagefind, withastro

## 简介

Astro integration for @inkform/framework: serve a folder of MDX docs, a native OpenAPI reference, llms.txt and Pagefind search from any Astro 7 site.
