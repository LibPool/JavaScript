# @boardherald/mcp-bridge

> 标签: agent, boardherald, bridge, chatgpt, claude, claude-desktop, mcp, model-context-protocol

## 简介

stdio ↔ HTTPS bridge for connecting any MCP client (Claude Desktop, ChatGPT, custom) to a BoardHerald tenant.
