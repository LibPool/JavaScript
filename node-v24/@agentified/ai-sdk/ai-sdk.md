# @agentified/ai-sdk

> 标签: JavaScript

## 简介

Vercel AI SDK adapter for [Agentified](../../../README.md) — wraps SDK classes with AI SDK-typed shells via composition. Tools are exposed as AI SDK `tool()` objects for direct use with `generateText`/`streamText`.
