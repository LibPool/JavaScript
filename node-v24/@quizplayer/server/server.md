# @quizplayer/server

> 标签: bun, e-learning, express, hono, interactive-video, lms, nextjs, quiz

## 简介

Node.js backend for QuizPlayer: server-side answer validation and storage for Express, node:http and Fetch-API runtimes (Next.js, Hono, Bun, Deno).
