# @shizhanyu13/dsh-waom

> 标签: auto-ops, autonomous, cordis, deepseek, deepseek-harness, dsh-plugin, monitor, plugin, self-healing, subagent, waom

## 简介

Ironbound WAOM autonomous-ops service plugin for the DeepSeek Harness (DSH). Monitors a target, decides a fix, drives a DSH subagent to implement it (no claude -p subprocess), and evaluates the result independently (GAN-style). Ported from scripts/waom/wa
