# @vibe-oss/kvy

> 标签: agent, ai, claude-code, cli, codex

## 简介

kvy — CLI wrapper for Claude Code / Codex agent sessions. Hand-rolled arg parsing (no framework), full flag passthrough to the underlying provider CLI, file-only logging (stdout/stderr are reserved for the real provider TUI once local-mode spawning lands)
