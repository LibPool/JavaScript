# @evarentha/linearpress-oidc-sso

> 标签: evarentha, linearpress, oidc-sso, plugin

## 简介

OIDC / OAuth2 单点登录：可自定义添加任意 OAuth2 或 OIDC 认证平台（含 Discovery 自动填充），回调地址可配置（默认 /sso-callback），支持未注册用户自动注册（重名用户名追加 _openid 后四位，可关闭），已登录用户可在个人资料（colorful-profiles）或仪表盘绑定/解绑平台账号。
