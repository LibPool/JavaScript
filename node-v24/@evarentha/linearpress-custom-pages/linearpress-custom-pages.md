# @evarentha/linearpress-custom-pages

> 标签: custom-pages, evarentha, linearpress, plugin

## 简介

创建可自定义路由的页面（内置/可视化编辑器），并支持上传带数据片段替换的静态 HTML 页面。路由遵循先注册原则：系统保留路由与后续插件路由自动覆盖，列表页实时提示冲突。
