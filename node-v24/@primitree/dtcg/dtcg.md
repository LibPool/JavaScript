# @primitree/dtcg

> 标签: design tokens, dtcg, figma, figma variables, resolver, style-dictionary, terrazzo, w3c design tokens

## 简介

Read Primitree's supported DTCG 2025.10 value subset into Core and convert Figma variables to DTCG, Resolver contexts, CSS, Tailwind CSS, and TypeScript.
