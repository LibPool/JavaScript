# @sensei-studio/typegen

> 标签: JavaScript

## 简介

Sensei Studio content-model type generator — turns a tenant's content types into TypeScript interfaces for the REST delivery/preview payload shape (FR-19.2). Build-time tool: no runtime, no network, zero dependencies. Field keys are emitted as the api_id
