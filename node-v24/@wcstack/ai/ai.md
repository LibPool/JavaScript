# @wcstack/ai

> 标签: ai, anthropic, azure-openai, custom-elements, declarative, framework-agnostic, llm, openai, streaming, wc-bindable, web-components, zero-dependencies

## 简介

Declarative AI inference component for Web Components. Streaming-first, multi-provider (OpenAI, Anthropic, Azure OpenAI) via wc-bindable-protocol.
