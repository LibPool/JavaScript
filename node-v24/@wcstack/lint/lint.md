# @wcstack/lint

> 标签: cli, custom-elements, data-wcs, lint, static-analysis, validator, wcstack, web-components, zero-dependencies

## 简介

Static-contract validator CLI (wcs-validate) for wcstack data-wcs bindings and wcstack.manifest.json sidecars. Thin npm wrapper around the wcstack-intellisense validator core.
