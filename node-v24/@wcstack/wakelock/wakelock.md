# @wcstack/wakelock

> 标签: custom-elements, declarative, framework-agnostic, keep-awake, screen-wake-lock, wake-lock, wc-bindable, web-components, zero-dependencies

## 简介

Declarative Screen Wake Lock component for Web Components. Framework-agnostic, holds the screen awake while a bound state is true via wc-bindable-protocol.
