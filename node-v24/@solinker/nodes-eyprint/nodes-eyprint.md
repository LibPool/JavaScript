# @solinker/nodes-eyprint

> 标签: n8n-community-node-package, 工具软件, 易云打印

## 简介

易云打印可使普通打印机具有远程打印,共享打印,自助打印,订单打印,电商平台云打印等联网功能,使用易云打印平台的用户可实时通过网络在线向各种类型的打印机发送打印任务。
