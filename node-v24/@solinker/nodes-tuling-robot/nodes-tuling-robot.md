# @solinker/nodes-tuling-robot

> 标签: AI人工智能, n8n-community-node-package, 图灵机器人

## 简介

图灵机器人平台，基于自然语言处理、语料库和云计算等技术，为广大开发者、合作伙伴提供的一系列智能语义处理能力（包括语义理解、智能问答、语料库对接等）的服务平台。可以让所有专业和非专业的IT人员快速开发出智能机器人、聊天机器人，实现企业客服系统的自动回复。
