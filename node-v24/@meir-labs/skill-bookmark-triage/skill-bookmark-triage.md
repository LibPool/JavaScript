## 简介

The meirlabs bookmark-triage skill — turn saved X/Twitter bookmarks into Linear tickets automatically: a daily agent loop that reads new bookmarks via the shiori.sh CLI, classifies each against your idea taxonomy, auto-files the actionable ones, and tags
