# @meir-labs/skill-verify-frontend-change

> 标签: browser, claude, claude-code, frontend, meirlabs, skill, skills, ui, verify

## 简介

Verify any UI change end-to-end before declaring it done — drive it in a real browser, check console and mobile, screenshot before/after. A Claude Code skill; npx installs it into .claude/skills.
