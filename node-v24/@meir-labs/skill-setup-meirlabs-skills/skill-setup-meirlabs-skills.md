# @meir-labs/skill-setup-meirlabs-skills

> 标签: claude, claude-code, config, meirlabs, setup, skill, skills, wizard

## 简介

Per-repo setup wizard for the meirlabs skills: interviews you once (issue tracker, design context, deploy posture, analytics) and writes an "## Agent skills" config block the other skills read. npx installs it into .claude/skills.
