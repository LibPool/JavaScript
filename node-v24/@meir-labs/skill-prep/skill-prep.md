# @meir-labs/skill-prep

> 标签: claude, claude-code, codex, linear, meirlabs, planning, skill, skills, tickets

## 简介

Prep a ticket: the agent reads it, works out the fix, and writes the plan, risk, effort and priority back onto the ticket without building anything. npx installs it into .claude/skills.
