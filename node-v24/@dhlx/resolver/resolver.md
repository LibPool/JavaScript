# @dhlx/resolver

> 标签: error, promise, reject, resolve

## 简介

resolver 是一个强大的 TypeScript 工具函数，用于处理异步函数的执行结果，统一进行错误处理和结果包装，让您的异步代码更加简洁和可靠。
