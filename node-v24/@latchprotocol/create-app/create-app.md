# @latchprotocol/create-app

> 标签: amm, create, dex, hooks, latch, latchprotocol, launchpad, react, scaffold, template, vite, white-label

## 简介

The Latch app template: scaffold a DEX, a Launchpad or both on LatchProtocol's shared core. npm create @latchprotocol/app. MIT, one config file, no core deployment.
