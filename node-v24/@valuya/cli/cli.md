# @valuya/cli

> 标签: JavaScript

## 简介

A small CLI to **purchase access** (create checkout session → pay on-chain if needed → submit signed proof → verify → mint mandate), plus a couple of **admin helpers** (e.g. wallet allowlisting, product creation).
