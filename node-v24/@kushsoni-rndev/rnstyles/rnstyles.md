# @kushsoni-rndev/rnstyles

> 标签: @kushsoni-rndev/rnstyles, dark-mode, expo, light-mode, react, react-native, responsive-styles, style-library, tailwind, typescript, utility-first

## 简介

A lightweight Tailwind-style utility-based styling library for React Native, React, Next.js, Expo, and Electron. Supports full class names, shorthand (Tailwind-style), responsive styles, custom fonts, and dark/light modes.
