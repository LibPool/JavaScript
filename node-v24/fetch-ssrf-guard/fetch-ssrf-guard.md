# fetch-ssrf-guard

> 标签: dns-rebinding, fetch, private-ip, security, ssrf, undici, url-preview, webhook

## 简介

SSRF-safe fetch for Node.js: blocks private, loopback and cloud-metadata addresses, checked at connect time so DNS rebinding can't get around it.
