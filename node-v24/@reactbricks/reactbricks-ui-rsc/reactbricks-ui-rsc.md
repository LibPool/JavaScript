# @reactbricks/reactbricks-ui-rsc

> 标签: JavaScript

## 简介

React Bricks UI theme for Next.js App Router starter. It provides ready-made marketing bricks (hero units, feature grids, pricing, blog, testimonials, forms, headers/footers) styled with Tailwind CSS v4.
