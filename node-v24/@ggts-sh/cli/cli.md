# @ggts-sh/cli

> 标签: agents, charts, cli, dataviz, ggplot2, grammar-of-graphics, headless, plot, svg, validation, visualization

## 简介

ggts: validate and render plot specs (JSON) to SVG from the command line — the feedback loop for agents that author charts in sandboxes.
