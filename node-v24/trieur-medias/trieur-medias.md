# trieur-medias

> 标签: comfyui, gtk, local, media, photos, python, sorter, trash, trieur

## 简介

Local media sorter: scroll, tick, move to a folder, trash — a ComfyUI .json sidecar follows its image. Python stdlib + plain HTML, nothing to install. (Trieur de médias : page locale pour trier photos et fichiers.)
