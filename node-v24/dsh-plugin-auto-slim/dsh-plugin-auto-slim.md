# dsh-plugin-auto-slim

> 标签: context, dedupe, deepseek-harness, dsh, dsh-plugin, tokens

## 简介

Cuts token spend on repeated tool calls: identical read-only calls reuse their earlier result, superseded results collapse to a placeholder. No session rewrite, no effect on side-effecting commands.
