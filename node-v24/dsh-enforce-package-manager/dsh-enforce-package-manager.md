# dsh-enforce-package-manager

> 标签: agent, bun, deepseek, deepseek-harness, dsh, dsh-plugin, guard, npm, package-manager, pip, pnpm, poetry, uv, yarn

## 简介

DeepSeek Harness plugin that catches the wrong package manager for the repo (npm install in a pnpm repo, pip install in a uv/poetry project, and so on) and gives the model the exact right command.
