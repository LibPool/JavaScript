# @acunsoft/datatable-vue

> 标签: a11y, accessible, data-table, datatable, table, vue, vue3

## 简介

Vue 3 components and composables for @acunsoft/datatable-core: an accessible table, pagination, search, column menu and bulk actions with slots for custom cells.
