# takeback

> 标签: ai-agents, checkpoint, claude-code, claude-code-plugin, cli, codex, coding-agent, cursor, gemini-cli, opencode, rewind, safety, undo, vibe-coding

## 简介

Ctrl+Z for AI coding agents. One command undoes the last turn of Claude Code, Codex or any agent, including files changed through Bash.
