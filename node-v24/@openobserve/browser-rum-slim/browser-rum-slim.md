# @openobserve/browser-rum-slim

> 标签: JavaScript

## 简介

This package is equivalent to the [RUM package][1], but without support for Session Replay recording and the `compressIntakeRequests` initialization parameter. Use it when you do not need session replay and want a smaller bundle.
