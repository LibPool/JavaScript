# dsh-doc-review

> 标签: annotation, comment, deepseek-harness, document, dsh, dsh-plugin, review

## 简介

把模型的长回复当成稿子来审：原地批注（评论/认可/反对）后一次发回；或以文档模式阅读，高亮、评论线程、让 Agent 直接改正文，读完带回主会话。A DeepSeek Harness plugin.
