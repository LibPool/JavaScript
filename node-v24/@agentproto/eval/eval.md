# @agentproto/eval

> 标签: agentic, agentproto, aip-14, aip-30, deterministic, eval, open-standard, score, scorer

## 简介

Deterministic reference scorers as AIP-14 TOOL contracts + one builtin AIP-30 PROVIDER. A scorer IS a tool whose outputSchema is the shared `Score` shape — no new scorer port. Ships exact-match, regex-match, json-schema-valid, and latency-budget. No LLM/m
