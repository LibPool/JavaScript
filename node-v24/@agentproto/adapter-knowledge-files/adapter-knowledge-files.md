# @agentproto/adapter-knowledge-files

> 标签: adapter, agentic, agentproto, bm25, files, knowledge, knowledge-engine, open-standard, provider-kit, rag, retrieval

## 简介

Pure, zero-runtime knowledge adapter: implements @agentproto/knowledge-engine's IKnowledgeProvider over local files with an in-process BM25 index (no embeddings, no network, no API key). Registers as a provider-kit family and ships a node:fs FsPort so it
