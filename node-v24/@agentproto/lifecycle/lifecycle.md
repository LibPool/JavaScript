# @agentproto/lifecycle

> 标签: agentic, agentproto, aip-37, events, lifecycle, open-standard, vocabulary

## 简介

@agentproto/lifecycle — AIP-37 LIFECYCLE.md reference implementation. A vocabulary AIP defining the standard lifecycle event names that hosts fire and that policy blocks (storage sync, sandbox lifecycle, etc.) reference. Not a runtime — just a shared lang
