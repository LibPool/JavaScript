# @agentproto/sandbox

> 标签: agentic, agentproto, aip-36, defineSandbox, open-standard, sandbox

## 简介

@agentproto/sandbox — AIP-36 SANDBOX.md reference implementation. A composable schema block defining the `sandbox` field — provider, config, command env, network egress, resource limits — for any manifest that names a compute environment for agent-issued
