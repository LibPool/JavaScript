# @agentproto/review

> 标签: agentic, agentproto, aip-62, attestation, defineReview, open-standard, review, verdict, workflow

## 简介

@agentproto/review — the review primitive. A REVIEW.md manifest (checks + named bindings) compiled into an ordinary AIP-15 workflow (prepare → freeze range → parallel lanes → fan-in verdict), plus the verdict contract (pass | block | incomplete, per-lane
