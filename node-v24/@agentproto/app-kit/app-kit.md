# @agentproto/app-kit

> 标签: agent, agentproto, aip-15, aip-53, defineApp, open-standard, workflow

## 简介

@agentproto/app-kit — declare an agent (with its system prompt) and its workflows in one TypeScript module and import them anywhere. A thin umbrella over AIP-42 defineAgent + AIP-15 defineWorkflow: defineApp cross-links the two (every workflow agent-step
