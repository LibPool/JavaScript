# @agentproto/driver-http

> 标签: JavaScript

## 简介

agentproto/http-runtime — AIP-31 HTTP provider specialisation. Sugar over @agentproto/driver's defineDriver({ kind: 'http' }) plus body templating, JSONPath-lite response extraction, and SSE streaming.
