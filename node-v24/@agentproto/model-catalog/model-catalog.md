# @agentproto/model-catalog

> 标签: agentproto, llm, model-catalog, model-picker, pricing

## 简介

Unified, dependency-light model catalog: LLM, image, video, audio entries + cost dispatcher + picker. Zod-only; the OSS core that @agstudio/model-catalog layers billing/access/BYOK on top of.
