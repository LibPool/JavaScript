# @agentproto/cli-exec

> 标签: agent, agentproto, child-process, cli, headless, spawn, stdin

## 简介

Minimal one-shot CLI execution helper — spawn a command, feed a prompt over stdin, capture stdout, with timeout + AbortSignal. Plus a tolerant parser for agent CLIs that emit a `--output-format json` result envelope. Shared by anything that drives a headl
