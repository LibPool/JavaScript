# @agentproto/computer-api

> 标签: agentproto, aip-36, computer, contract, microvm, open-standard, sandbox

## 简介

@agentproto/computer-api — versioned public contract for the computer controller HTTP API: zod schemas and inferred types for create/get/exec/suspend/resume/rm of computers, published ports, status and the error envelope.
