# @agentproto/design

> 标签: agentic, agentproto, aip-4, defineDesign, design, open-standard

## 简介

@agentproto/design — AIP-4 DESIGN.md reference implementation. A markdown + frontmatter format for portable design tokens, and the registry conventions used by designkit.sh to share community kits.
