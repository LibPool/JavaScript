# @routier/pglite-plugin

> 标签: data access layer, database, entities, offline, opfs, orm, pglite, postgres, postgresql, routier, typescript, wasm

## 简介

PGlite plugin for Routier: real PostgreSQL in WebAssembly, persisted to OPFS in the browser and to disk or memory in Node.
