# @mckit/core-nestjs

> 标签: core-nestjs

## 简介

Biblioteca de utilidades y servicios core para aplicaciones NestJS / Node.js. Proporciona herramientas robustas y fuertemente tipadas para la manipulación segura de objetos dinámicos, interpolación de textos, acceso anidado por notación de puntos/arreglos
