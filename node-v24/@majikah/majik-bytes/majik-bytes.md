# @majikah/majik-bytes

> 标签: arraybuffer, binary-serialization, canvas-safe, data-integrity, file-to-png, lossless-encoding, majik-bytes, majikah, metadata-preservation, pixel-packing, png-data-storage, sha3-512, steganography, tamper-evident, typescript

## 简介

MajikBytes is a TypeScript utility for lossless byte conversion and portable data encoding. It preserves source types and encodes strings, JSON, binary data, Files, numbers, BigInts, and booleans as PNG, TXT, or JSON.
