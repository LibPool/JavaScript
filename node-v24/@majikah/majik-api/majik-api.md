# @majikah/majik-api

> 标签: api-key, api-management, cloudflare, domain-validation, ip-filtering, key-rotation, majikah, rate-limiting, redis, security, sha256, supabase, typescript, whitelisting

## 简介

A TypeScript API key management library for secure credential hashing, lifecycle management, rotation, rate limits, quotas, IP/domain whitelisting, and access controls.
