# @brijeshp/pinflow

> 标签: annotation, claude, comments, cursor, feedback, markdown, pin, prototype, review, vibe-coding

## 简介

Add a comment layer to any web page, then hand the export to your coding agent. One script tag, 17 kB, and reviewers don't install anything.
