# rampa-mcp

> 标签: algorand, argentina, brazil, exchange-rates, fx, latam, mcp, mexico, model-context-protocol, off-ramp, stablecoin, usdc, venezuela, x402

## 简介

MCP server for Rampa — LATAM stablecoin cash-out, FX, spreads, yields and withdrawal fees. Free comparison tools out of the box; paid endpoints via x402 on Algorand when you configure a wallet.
