# requestport

> 标签: JavaScript

## 简介

RequestPort on your own machine. `requestport start` initialises an instance and serves it from one Node.js process: the REST API, MCP, the web application and the background worker, on PGlite or on PostgreSQL. Agents reach it through `requestport login`,
