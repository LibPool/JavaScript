## 简介

Agent Reach(클로드 코드 같은 에이전트가 트위터·레딧·유튜브·깃허브 등을 읽게 해 주는 오픈소스 CLI)를 깔기 전·후에 걸리는 자리를 먼저 말해 주는 클로드 코드 안내 스킬입니다. 기본 설치는 검사만 한다는 점(--system 을 줘야 설치), doctor 로 무엇이 되는지 보는 법, 쿠키로 로그인하는 채널은 전용 부계정을 쓰라는 저장소 경고, 「요금 내는 API 없음」이 정확히 어디까지인지를 알려 줍니다. Agent Reach 는 Panni
