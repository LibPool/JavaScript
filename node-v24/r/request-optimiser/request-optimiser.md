# request-optimiser

> 标签: faster, http, link, optimiser, optimized, request, simple, speed, util, utility

## 简介

This module was speed optimised. It´s based on request and is 50% faster than the original by using multiple different techniques like compressing, minify and rewriting a lot of interal source code from the original module with newer methods.
