# rahman-resources-mcp

> 标签: claude, mcp, model-context-protocol, rahman, scaffolder, templates

## 简介

Model Context Protocol server for the Rahman Resources registry — stdio + HTTP transports. Exposes templates, slices, features, recipes, Claude skills, and CRUD workflows as MCP tools/resources.
