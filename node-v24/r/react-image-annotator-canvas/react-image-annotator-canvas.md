# react-image-annotator-canvas

> 标签: annotation, annotator, bounding-box, canvas, computer-vision, image, image-labeling, label, labeling, object-detection, react, react-component, touch, typescript, visual-diff

## 简介

A generic React canvas component for drawing, selecting, moving, resizing, and labeling rectangular annotations on images. Bring your own categories — use it for ML labeling, visual-diff QA, manuscript markup, or any image-annotation workflow.
