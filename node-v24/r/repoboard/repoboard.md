# repoboard

> 标签: agents, board, claude-code, cli, dashboard, git, kanban, local-first, markdown, mcp

## 简介

Local-first repo dashboard and agent-driven Kanban board. Cards are markdown files in .repoboard/, git is the history; one bin serves the CLI, the HTTP/WebSocket dashboard, and an MCP server.
