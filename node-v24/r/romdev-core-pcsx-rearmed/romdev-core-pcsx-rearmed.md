# romdev-core-pcsx-rearmed

> 标签: JavaScript

## 简介

PCSX-ReARMed libretro core (Sony PlayStation, HLE BIOS) for romdev, bundled as WASM with romdev's CPU + SPU + GPU-VRAM debug exports.
