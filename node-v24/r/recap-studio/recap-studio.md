# recap-studio

> 标签: accessibility, ai-agents, claude-code, claude-code-plugin, education, explainer, mcp, mobile-first, nextjs, validation

## 简介

Generate beautiful, calm, mobile-first one-page explainers in under 5 minutes. Claude Code plugin with 13 specialist agents, 7-dimension validation board, static Next.js output. This package redirects to the canonical install path.
