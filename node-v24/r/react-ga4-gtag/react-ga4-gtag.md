# react-ga4-gtag

> 标签: JavaScript

## 简介

This is a library to allow simple lightweight integration in GA4 or Google Analytics 4 in a React app. A minimal package, bundled its around 0.5kb, just using the context wrapper will give your aplication basic ga4 data and a provided hook gives you acces
