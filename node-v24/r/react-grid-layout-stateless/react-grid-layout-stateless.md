# react-grid-layout-stateless

> 标签: drag, draggable, fluid, grid, react, resizable, resize, responsive

## 简介

A draggable and resizable grid layout with responsive breakpoints, for React, with isStateless prop added to store layout not in state, but in external source of trooth
