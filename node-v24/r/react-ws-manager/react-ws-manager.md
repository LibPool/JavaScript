> 标签: event driven, event subscription, hooks, multi endpoint wesocket, multi websocket, pubsub, react, react websocket, react ws, realtime, realtime websocket, reconnect, typescript, websocket, websocket hook, websocket manager, ws, ws client

## 简介

Type-safe WebSocket manager for real-time applications. Framework-agnostic core with first-class React support. Supports multi-endpoint connections, auto-reconnect, and subscription-based messaging.
