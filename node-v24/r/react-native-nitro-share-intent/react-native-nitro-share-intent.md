# react-native-nitro-share-intent

> 标签: android, app-integration, content-sharing, cross-platform, deep-linking, document-sharing, file-handling, file-sharing, image-sharing, intent, ios, media-sharing, native, nitro, nitro-modules, react-native, share, share-intent, sharing, text-sharing, typescript, url-scheme, video-sharing

## 简介

A powerful React Native library for handling native share intents on iOS and Android. Built with Nitro Modules for optimal performance. Handle text sharing, file sharing, and multiple file sharing from other apps.
