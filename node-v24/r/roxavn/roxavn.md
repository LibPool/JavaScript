# roxavn

> 标签: JavaScript

## 简介

RoxaVN is a full stack web framework, designed in a modularized architecture. Each module can be used independently as a separate service, or run multiple modules at the same time as monolithic architecture. RoxaVN is designed according to the KISS princi
