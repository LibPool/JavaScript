# reborn-freetier

> 标签: bandwidth, claude, claude-code, cloudflare, cloudflare-pages, deployment, free-tier, hosting, korean, limits, vercel

## 简介

무료 배포 플랜에서 내 프로젝트가 어디서 먼저 걸리는지 재 주는 클로드 코드 스킬입니다. --check 가 지금 폴더의 빌드 크기·파일 수·가장 큰 파일을 실제로 재서 Vercel Hobby 와 Cloudflare Free 의 한도에 맞대 봅니다. 가장 많이 헷갈리는 자리는 「넘으면 어떻게 되나」입니다 — Vercel Hobby 는 자동 과금되지 않고 30일 멈춥니다. 한도값은 각 사 공식 문서 2026-09-12 기준이며 저희는 두 회사와 제휴 관계가
