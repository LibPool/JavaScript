# react-native-nitro-input

> 标签: amount-input, animated-input, currency-input, nitro, nitro-modules, react-native, text-input, text-morph, torph

## 简介

Native text and amount input for React Native with Torph-style text morphing: characters slide, fade and reflow as you type, currency formatting applied natively, no JS round trip. Built with Nitro.
