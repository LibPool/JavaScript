# react-native-apple-key-commands

> 标签: expo, hotkey, ios, ipad, key-command, keyboard, macos, react-native, shortcuts, uikeycommand

## 简介

Dynamic hardware-keyboard shortcuts (UIKeyCommand) for React Native and Expo. Register key commands from JS and get an event back when one fires. Works on iPad and on iPad apps running on Mac. iOS only. Built with the Expo Modules API.
