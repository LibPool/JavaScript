# rubick-chatgpt

> 标签: JavaScript

## 简介

无限创建Ai好友，支持chatgpt、claude、gemini等中转API接入，支持Ai语音对话、Ai绘画、Ai音乐、支持openai最新的GPT系列模型、支持谷歌gemini系列模型以及完美适配第三方中转api
