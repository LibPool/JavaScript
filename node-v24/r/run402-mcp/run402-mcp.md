# run402-mcp

> 标签: agent, ai, backend-as-a-service, database, mcp, model-context-protocol, postgres, run402, supabase-alternative, x402

## 简介

MCP server for Run402 — full-stack backend infrastructure for AI agents: Postgres, auth, storage, serverless functions and atomic deploys. Paid with x402/MPP. Includes $0.03 image generation.
