# react-pkce-coustome

> 标签: JavaScript

## 简介

This zero-dependency package enables [React](https://reactjs.org/) applications to use an OAuth2 provider for authentication. The OAuth2 provider must support the [PKCE Spec](https://tools.ietf.org/html/rfc7636).
