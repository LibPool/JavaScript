# reflect-metadata-miniprogram

> 标签: JavaScript

## 简介

如果在小程序中直接使用 npm 中的 reflect-metadata, 小程序会做一些打包处理.  这样就导致 reflect-metadata 失效, Reflect 中的方法并不会被写入到全局名称空间. 这个 reflect-metadata 版本就是针对小程序环境做修改.
