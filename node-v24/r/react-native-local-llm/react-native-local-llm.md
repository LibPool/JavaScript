> 标签: apple-intelligence, cactus, edge-ai, executorch, expo, foundation-models, gemma, llm, local-llm, offline-ai, on-device, qwen, react-native, streaming

## 简介

One interface for every on-device LLM runtime in React Native — Apple Foundation Models, ExecuTorch, and llama.cpp-based Cactus — with device-aware model selection and unified token streaming.
