# requirejs-plugins

> 标签: JavaScript

## 简介

Small set of plugins for [RequireJS](http://requirejs.org). Some plugins may also work on other AMD loaders (never tested it).

- 官网：https://github.com/jstrimpel/requirejs-plugins
- 源码仓库：git://github.com/jstrimpel/requirejs-plugins.git
