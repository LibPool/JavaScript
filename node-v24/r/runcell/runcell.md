# runcell

> 标签: agent, agent-runtime, ai, ai-agents, code-execution, llm, sandbox, sandboxed-agents, standard-schema, structured-output, typescript, zod

## 简介

TypeScript runtime for running agents in sandboxes with structured results, file outputs, and persistent threads.
