# react-linear-feedback

> 标签: bug-report, bug-reporting, embed, feedback, linear, marker, react, screenshot, script-tag, widget

## 简介

Drop-in feedback widget for React apps or any site via a script tag: draw a box, write a note, and it captures a screenshot and opens a Linear issue. Self-contained styles, zero design-system dependencies.
