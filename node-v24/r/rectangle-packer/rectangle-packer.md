# rectangle-packer

> 标签: 2d-layout, 2d-packing, algorithm, area-optimization, atlas-generation, bin-packing, guillotine-packing, layout-algorithm, optimization, packing-algorithm, rectangle-packer, rectangle-packing, rectangular-packing, space-optimization, space-utilization, sprite-packing, texture-packing, typescript

## 简介

A high-performance TypeScript library for 2D rectangle packing algorithms. Implements area-based packing and Guillotine bin packing with multiple heuristics for optimal space utilization.
