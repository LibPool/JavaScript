# react-doctor-rewritten

> 标签: accessibility, diagnostics, knip, linter, nextjs, oxlint, performance, react, react-compiler, react-native, security, tanstack, typescript

## 简介

Diagnose and fix React codebases for security, performance, correctness, accessibility, bundle-size, and architecture issues (fork of millionco/react-doctor with --hide-branding HTML report for CI).
