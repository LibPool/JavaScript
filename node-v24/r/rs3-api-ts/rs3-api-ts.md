# rs3-api-ts

> 标签: cli, lua, plugin, rs3, runescape, tstl, typescript-to-lua

## 简介

rs3-plugin: scaffold, build and check RuneScape 3 plugins written in TypeScript. Emits readable Lua and validates plugin.json against the client's rules.
