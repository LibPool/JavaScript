# readme-gauge

> 标签: badges, cli, docs, documentation, github-action, lint, linter, markdown, readme, sarif

## 简介

Lint READMEs for missing sections, broken and stale badges, stale install commands, missing usage examples, broken relative links and anchors, placeholders and license mismatches. Checks JS code examples and imports, and the table of contents (--fix-toc).
