# react-tab-layout

> 标签: layout, react, swipe, tab, tabs

## 简介

A react tab layout library that looks like the Android tab layout component (http://w3z.in/27ef). This library is heavily inspired from react-swipe-views (http://w3z.in/845) but it does not support the swipe feature and supports dynamically changing child
