# react-native-web-serial-api

> 标签: android, cdc-acm, ch340, cp210x, ftdi, navigator.serial, pl2303, react-native, serial, turbomodule, usb, usb-serial, web serial api, web-serial

## 简介

W3C Web Serial API (navigator.serial) for React Native on Android, backed by a USB-serial TurboModule (built on mik3y/usb-serial-for-android).
