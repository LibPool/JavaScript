# remote-editable-pager

> 标签: cross-page-editing, editable-table, framework-agnostic, large-list, pagination, react, remote-pagination, vue

## 简介

框架无关的可编辑远程分页器：分页加载 + 跨页编辑 + 增删行 + 保存时自动汇总全量数据
