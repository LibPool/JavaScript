# rosemary-js

> 标签: context, csv, fuzzy-search, graph, knowledge-graph, llm, markdown, notes, second-brain, tags

## 简介

A graph-shaped knowledge store for Node: leaves, tags, typed connections, fuzzy search, optional LLM context layer.
