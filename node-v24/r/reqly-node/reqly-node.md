# reqly-node

> 标签: apm, express, fastify, hono, koa, latency, monitoring, nestjs, observability, reqly

## 简介

Reqly SDK for Node.js: per-route latency, errors, consumers and LLM cost for Express, Fastify, Hono, Koa, NestJS and plain node:http, sent to a self-hosted Reqly collector.

- 源码仓库：git+https://github.com/tanisheesh/reqly.git
