# rns-audiomix

> 标签: audio, dev-client, expo, mix, react-native

## 简介

Native audio processing module for **Expo React Native** (iOS & Android).   Powered by **FFmpegKit** (iOS) and **JavaCV/FFmpeg** (Android).
