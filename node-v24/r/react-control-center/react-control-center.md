# react-control-center

> 标签: react, react control center, react-control-center, replace redux, state broadcast, state dispatch, state management, state sync, work with redux

## 简介

control your react component state in a funny way, every react instance of different class if they were registered in react-control-center own the ability of knowing and syncing each other's state, just have a try and discover more^_^
