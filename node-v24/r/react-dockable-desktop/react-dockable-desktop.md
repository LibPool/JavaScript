# react-dockable-desktop

> 标签: dockable, docking, ide, layout, panels, react, vue-dockable-desktop, window-manager, workspace

## 简介

A premium, state-of-the-art window manager and dockable layout engine for React. Supports fluid grid splits, tabbed groups, floating resizable windows, zero-unmount state preservation, context menus, and internationalization.
