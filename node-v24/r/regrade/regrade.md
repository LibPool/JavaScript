> 标签: agent-evaluation, ai-agents, ai-testing, anthropic, ci, claude, cli, evals, evaluation, github-actions, gpt, llm, llm-as-a-judge, llm-evals, llm-evaluation, llm-judge, llm-testing, ollama, openai, prompt-engineering, prompt-testing, rag, rag-evaluation, regression-testing, testing, tool-calling, tracing, typescript

## 简介

Regression testing for LLM apps, AI agents and RAG pipelines: run test cases through your pipeline, score answers (exact match, LLM-as-a-judge, latency, cost, tool calls), and fail CI when a prompt or model change makes results worse. Statistically honest
