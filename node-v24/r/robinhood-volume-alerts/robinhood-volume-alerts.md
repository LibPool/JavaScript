# robinhood-volume-alerts

> 标签: blockchain-monitoring, cli, crypto-alerts, defi, dex, evm, memecoin, onchain-data, robinhood, robinhood chain, robinhood-chain, rug-detection, telegram, telegram-bot, trading-alerts, uniswap-v3, volume-alerts, volume-spike, wallet-tracker, whale-alerts, whale-tracker

## 简介

Real-time Telegram alerts for Robinhood Chain (chain id 4663): volume spikes, whale trades, price moves, rug warnings, launches, graduations, wallet tracking, and a scorecard that follows how every call performed. One process, one SQLite file, no API keys
