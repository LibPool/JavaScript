# react-image-inspector

> 标签: document-viewer, gallery, image, inspector, lightweight, magnifier, magnifying-glass, media, react, typescript, video, viewer, zoom

## 简介

A lightweight React media viewer for images and videos with zoom, rotation, flipping, thumbnails, theming, and a magnifying lens for images.
