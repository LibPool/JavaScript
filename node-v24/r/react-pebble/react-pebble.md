# react-pebble

> 标签: alloy, compiler, jsx, moddable, pebble, piu, preact, smartwatch, vite-plugin, watchface

## 简介

Write Pebble watchfaces and apps in JSX — compiles to piu, Rocky.js, or native C that runs on the watch.
