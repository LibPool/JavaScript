# react-native-font-scale

> 标签: auto-scaling, flexible, react-components, react-native, text

## 简介

Flexible, autoscale, sizetofit <Text/> component without any native module.It can be adjusted to fullfil the usage of wrap_content in android and minimumScale in iOS
