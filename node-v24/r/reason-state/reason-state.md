# reason-state

> 标签: agent-memory, agentic-workflow, agi, ai-agents, anthropic, assumptions, deterministic-reasoning, grok, langchain, langgraph, llm-memory, long-context, long-term-memory, memory-compression, multi-agent, openai, reasoning-engine, self-healing, state-management, token-optimization

## 简介

Governed long-term memory for agents. **Token-budgeted context** + **drift control when facts change** (explicit `retract()` + `heal()`), with deterministic replay/audit. Works **keyless** in retrieve-only mode.
