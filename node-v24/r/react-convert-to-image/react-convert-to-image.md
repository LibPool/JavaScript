# react-convert-to-image

> 标签: convert any component to image, download image, download screenshot, image, jpeg, jpg, react, react component snapshot, react-convert-to-image, react.js, reactjs, screenshot, svg

## 简介

Plugin to allow the download of any React component in project (whether currently rendered or not) as a image.
