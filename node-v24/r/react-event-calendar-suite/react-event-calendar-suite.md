## 简介

React Event Calendar Suite - Production-ready React event calendar & scheduler with month/week/day/list/year views, drag-and-drop, RRULE recurrence, ICS import/export, i18n, and timezone support. Style-isolated Ant Design UI for safe embedding in any host
