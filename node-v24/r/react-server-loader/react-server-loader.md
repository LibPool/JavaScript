# react-server-loader

> 标签: directives, esm, loader, react, react-server-components, react-server-dom-esm, react-server-dom-webpack, rsc, server-components, transformer

## 简介

Loader-side tooling for React Server Components in ESM environments — directive detection, transformer primitives, and Node ESM loader scaffolding. Transport-agnostic.
