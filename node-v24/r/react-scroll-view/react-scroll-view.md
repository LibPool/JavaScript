# react-scroll-view

> 标签: JavaScript

## 简介

A more sane way to work with scrolling inside React. The basis idea is to wrap elements which should be able to scroll inside a `createScrollContainer` function and then wrap elements which should interact with the scroll container inside a `withScrollApi
