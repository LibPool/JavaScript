# react-use-anywhere

> 标签: authentication, business-logic, dependency-injection, hook-agnostic, hook-injection, hooks, modular, navigation, nextjs, production-ready, react, react-router, router-agnostic, service-layer, state-management, tanstack-router, typescript, use-anywhere, utility

## 简介

Use React hooks anywhere in your codebase - in services, utilities, and business logic. Router-agnostic, hook-agnostic, and works with any React hooks (auth, navigation, state, custom hooks, etc.).
