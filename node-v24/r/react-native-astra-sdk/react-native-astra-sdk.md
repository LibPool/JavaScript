# react-native-astra-sdk

> 标签: android, ios, react-native

## 简介

react-native-astra-sdk is a plug-and-play KYC flow for React Native apps: wrap your app in KycProvider, call startKyc, and the SDK handles Astra server initialization plus the full modal experience for terms, guidance, face capture, document capture, veri
