# rtsp-streamer

> 标签: angular, camera, h264, ip-camera, live-video, player, react, rtp, rtsp, streaming, video, webcodecs, websocket, zero-dependency

## 简介

Zero-dependency RTSP-to-browser streaming over WebSocket, with a WebCodecs <rtsp-player> element and React/Angular bindings — no ffmpeg, no native addons, no media server.
