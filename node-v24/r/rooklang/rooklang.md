# rooklang

> 标签: channels, compiler, concurrency, go, goroutines, javascript, programming-language, rooklang, static-typing, vite-plugin, web-components, web-workers

## 简介

A language with JavaScript semantics, Go-style syntax, goroutines on real threads and static types that compiles to readable JavaScript
