# react-fhir-forms

> 标签: ehr, fhir, fhir-r4, forms, headless, healthcare, questionnaire, questionnaire-response, radix-ui, react, shadcn, shadcn-ui, tailwind

## 简介

Render FHIR R4 Questionnaires as React forms. ~3.7 KB headless core + opt-in Tailwind and shadcn/ui recipes. Bring your own UI or use the recipes — same Questionnaire in, same QuestionnaireResponse out.
