# react-native-nitro-qrcode

> 标签: android, expo, expo-qr-code, expo-qrcode, fast-qrcode, ios, jsi, native-module, nitro, nitro-modules, no-svg, performance, png, qr-code, qr-code-generator, qrcode, react-native, react-native-qr-code, react-native-qrcode, react-native-qrcode-svg, react-native-web, web

## 简介

Fast QR code generator for React Native and Expo with Nitro, native C++, PNG export, gradients, and no react-native-svg or Skia.
