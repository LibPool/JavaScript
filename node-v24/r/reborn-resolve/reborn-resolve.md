> 标签: claude, claude-code, davinci-resolve, korean, mcp, resolve, skills, video-editing

## 简介

DaVinci Resolve 를 클로드 코드에 붙이는 한국어 스킬을 스킬 폴더에 놓고, 이 컴퓨터의 Resolve 판(Studio/무료)·버전을 재서 붙는 길을 하나로 정해 줍니다. 공식 MCP(21.1 Studio · File > Setup AI Assistants)와 커뮤니티 MCP(samuelgursky/davinci-resolve-mcp · MIT)를 가려 안내하고, 무료판 21.1 은 붙지 않는다고 그대로 말합니다.
