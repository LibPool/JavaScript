# reverse-geocoders

> 标签: geo, geocoder, geocoding, gis, mapquest, nominatim, openstreetmap

## 简介

Unified interface for multiple reverse-geocoding services. Currently supports Google, MapQuest Open, and MapQuest Nominatim.
