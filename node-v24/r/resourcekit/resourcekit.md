# resourcekit

> 标签: cache, drizzle, local-first, offline, optimistic-updates, react, sync, typescript

## 简介

A full-stack data runtime for TypeScript apps: typed resources, instant local reads, optimistic writes with offline replay, and one sync endpoint - on top of your existing backend.
