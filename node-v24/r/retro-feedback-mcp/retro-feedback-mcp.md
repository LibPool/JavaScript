# retro-feedback-mcp

> 标签: bug-reports, changelog, feature-requests, mcp, model-context-protocol, rbac, retro, roadmap, user-feedback

## 简介

MCP server for retro, the user-feedback service: triage bug reports, feedback and feature requests, manage public roadmaps and changelogs, with role-based tool access and audit logging.
