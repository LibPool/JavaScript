# react-native-scaninput

> 标签: react-native

## 简介

> 此插件封装原生安卓的输入框组件(EditText),并且禁用了系统软键盘，为的是适用PDA手持项目需求（有硬键盘的安卓手机）。个人原因由于安卓方面不是特别懂，可能会存在一些bug。欢迎各位提issues！
