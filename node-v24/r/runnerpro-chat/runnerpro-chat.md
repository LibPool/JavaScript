# runnerpro-chat

> 标签: JavaScript

## 简介

runnerpro-chat es un paquete utilizado por RunnerPro para implementar el chat en sus aplicaciones. Se decidió crear un nuevo paquete para reutilizar el código ya que las lógicas del chat son parecidas.
