# resilient-pubsub

> 标签: backoff, dead-letter, envelope, fault-tolerance, google-cloud-pubsub, jitter, message-queue, nodejs, pubsub, resilience, retry, typescript

## 简介

A transparent, framework-agnostic resilience layer around @google-cloud/pubsub: structured envelopes, retries with backoff/jitter, native dead-letter support.
