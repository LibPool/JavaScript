## 简介

- **Smart Toolbar Mode:** Toggle show/hide formatting toolbar using a dedicated button or keyboard shortcut (`Ctrl+Shift+F`), keeping the height stable (no layout jumps) and formatting shortcuts active always. - **Production ready:** All major bugs fixed
