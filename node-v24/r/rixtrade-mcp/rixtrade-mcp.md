# rixtrade-mcp

> 标签: agent, brokerage, llm, market-data, mcp, model-context-protocol, options, rixtrade, trading

## 简介

MCP server for the RixTrade trader API — lets an agent read accounts, positions and orders, and (opt-in) place them.

## 官网

- 官网：https://rixtrade.com/api/sdk/
- npm 页面：https://www.npmjs.com/package/rixtrade-mcp
