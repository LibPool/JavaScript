# restorm-cli

> 标签: api, client, graphql, grpc, local-first, mock, rest, testing, websocket

## 简介

Restorm — local-first API testing environment (REST, GraphQL, gRPC, WebSocket, MQTT, Redis, AMQP…). Runs Restorm from a terminal or from CI: your installation if you have one, otherwise the official build, downloaded once, checksum-verified and cached.
