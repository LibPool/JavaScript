# resvg-napi

> 标签: fontdb, napi-rs, png, rasterize, render, resvg, svg, text-measurement, tiny-skia, usvg, wasm

## 简介

Render SVG to PNG in Node — and read back the resolved tree, text metrics and fonts. Powered by resvg.
