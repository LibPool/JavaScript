# redhop-win-x64

> 标签: context, embeddings, llm, napi-rs, native-binary, nlp, rag, retrieval, windows

## 简介

Windows x64 (MSVC) native binary for redhop — a reasoning-preserving context runtime for RAG. Installed automatically by the `redhop` package on Windows x64; not intended to be installed directly.
