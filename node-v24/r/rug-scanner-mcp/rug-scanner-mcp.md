# rug-scanner-mcp

> 标签: base, crypto, defi, ethereum, mcp, mcp-server, rug-pull, security, token-scanner, x402

## 简介

MCP server for on-chain token rug pull risk analysis. 7 parallel checks, deterministic scoring. $0.05 USDC per scan via x402 on Base.
