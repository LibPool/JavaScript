# rdtsc

> 标签: benchmark, cross-platform, duration, high-resolution, native, performance, process-priority, processor-cycles, rdtsc, stopwatch, thread-priority, tick, timing

## 简介

The most high resolution cross platform timing in NodeJs that use processor command RDTSC. Calculate performance with accuracy +/- 4 processor cycles.
