# read-pdf2llm

> 标签: llm, native-addon, nodejs, ocr, pdf, pdfium, tesseract, text-extraction

## 简介

High-performance PDF text extractor (with OCR fallback) for Node.js, optimized for LLM pipelines. Uses PDFium, Tesseract, and C++ addon.
