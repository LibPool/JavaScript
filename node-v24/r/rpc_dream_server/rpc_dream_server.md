# rpc_dream_server

> 标签: bridge, rpc, socket, tcp, typescript, websocket

## 简介

implementation of rpc_dream packages transport layer and rpc server with tcp socket, it is can be use on node.js<->node.js via tcp socket and web<->node.js via web socket.
