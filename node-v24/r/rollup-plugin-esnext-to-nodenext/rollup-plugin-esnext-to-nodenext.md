# rollup-plugin-esnext-to-nodenext

> 标签: bundler, esm, esmodules, file-extension, import-extension, javascript, js-extension, module, module-resolution, node-esm, node-modules, nodenext, rollup, rollup-plugin, strict-esm, typescript, typescript-transform

## 简介

A Rollup plugin that transforms ESM imports to Node.js-compatible NodeNext format by adding explicit file extensions
