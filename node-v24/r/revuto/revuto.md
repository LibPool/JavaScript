# revuto

> 标签: agent, ai, cli, code-review, llm, obsidian, openai-compatible, pr-review, surrealdb

## 简介

Local, supplier-agnostic, repo-agnostic autonomous PR reviewer. Stands up a learning reviewer for any repo: clone + onboard + PR-history backfill → curated skill, then poll-review + learn loop with skills graduated into an external (Obsidian) vault.
