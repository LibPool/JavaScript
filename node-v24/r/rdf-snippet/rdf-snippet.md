# rdf-snippet

> 标签: JavaScript

## 简介

- indexOf 重写 indexOf（兼容 IE8） - getSpecifiedObjectValue 查找指定位置的健值 - handleError 一个错误处理函数和测试案例的代码 - isHostMethod 浏览器能力检测 - recursiveAdd 递归加法 - equalDiffSeries 等差数列 - bigNum 大数阶乘 - getLines 单词折行算法（canvas） - showTime 显示当前时间 - countDownBySecond 秒数倒计时
