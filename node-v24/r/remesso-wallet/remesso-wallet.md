# remesso-wallet

> 标签: agent-wallet, celo, codex, cursor, mcp, remittances, stablecoins, x402

## 简介

An agent wallet on Celo whose spending is capped on-chain by its human. MCP server for Codex, Cursor, Claude and any MCP host: pay people and agents in USD₮, USDC or USA₮, pay x402 APIs, ask to be paid on a schedule.
