# recursion-data

> 标签: recursion-data, recursion-data-component, vue, vue-component

## 简介

无限级树形递归组件，默认数据源 Vue.$store.state，用于 vue 项目 vuex state 数据展示。也可传入其他多层级数据。组件样式仿照 Vue Devtools 数据面板。
