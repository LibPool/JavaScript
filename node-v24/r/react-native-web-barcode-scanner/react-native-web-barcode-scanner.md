# react-native-web-barcode-scanner

> 标签: code, expo, expo-barcode-scanner, expo-web, native, official, react, react-native, react-native-barcode-scanner, react-native-web

## 简介

A React component that renders a viewfinder for the device's either front or back camera viewfinder and will scan bar codes that show up in the frame.
