# rapidads

> 标签: ai-agent, facebook-ads, mcp, meta-ads, rapid-ads

## 简介

Upload ad media and ad copy CSVs to a Rapid Ads agent batch from the command line (used by AI agents via the Rapid Ads MCP connector).

## 官网

- 官网：https://rapid-ads.com/dashboard/connect-agent
- npm 页面：https://www.npmjs.com/package/rapidads

- npm registry：https://registry.npmjs.org/rapidads
- Node 要求：>=18.17
