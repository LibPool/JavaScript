# react-perf-recorder

> 标签: claude, devtools, mcp, memory-leak, performance, profiler, re-render, react, react-query, redux, renders, vite, vite-plugin, zustand

## 简介

Record React re-renders in the browser: cascade roots, hook-level reasons, store causes and user actions, saved as sessions an agent reads over MCP
