# rubyhash-mcp

> 标签: debugging, diff, hash, mcp, minitest, modelcontextprotocol, rails, rspec, ruby, testing

## 简介

MCP server for RubyHash (rubyhash.dev): diff two Ruby hashes from failing Minitest/RSpec output and convert Ruby hash literals to sorted JSON. Runs entirely locally, nothing is uploaded.

## 官网

- 官网：https://rubyhash.dev/agents
- npm 页面：https://www.npmjs.com/package/rubyhash-mcp
