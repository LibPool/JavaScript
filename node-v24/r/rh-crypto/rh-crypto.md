# rh-crypto

> 标签: api-client, crypto, ed25519, request-signing, robinhood, robinhood-api, robinhood-crypto, trading

## 简介

Zero-dependency Ed25519-signed HTTP client for the Robinhood Crypto Trading API. Byte-exact request signing, keypair generation, and a thin authenticated client for any v1/v2 endpoint.
