# replace-hardcoded-domain

> 标签: angular, angular-cli, angular17, angular18, angular19, angular8, codemod, domain, localstorage, migration, refactor, schematics, site-service

## 简介

Angular migration tool to replace hardcoded localStorage domain lookups with SiteService injection. Compatible across Angular 8 to 19+ with zero runtime dependencies.
