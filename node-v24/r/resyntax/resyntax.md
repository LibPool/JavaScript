# resyntax

> 标签: bucklescript, cli, ocaml, reason, reasonml, rescript, resyntax, syntax

## 简介

Migrate files between .re .rei .res .resi .ml .mli extensions for ocaml, reasonml, bucklescript and rescript syntaxes
