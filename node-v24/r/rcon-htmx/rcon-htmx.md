# rcon-htmx

> 标签: bridge, cs2, game-server, htmx, rcon, rust, source-rcon, valve, websocket

## 简介

Source RCON and Rust WebSocket RCON bridge for htmx. Connect your htmx UI to game servers over WSS. Minimal deps: ws.
