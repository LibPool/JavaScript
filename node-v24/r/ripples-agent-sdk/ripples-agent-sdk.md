# ripples-agent-sdk

> 标签: agent, erc20, launchpad, nft, ripples, robinhood-chain, uniswap-v4

## 简介

Launch an agent on Ripples and run it: one call to create the market, the collection and the treasury that holds the agent's money under limits nobody can raise.
