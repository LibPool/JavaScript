# react-static-example-typescript

> 标签: JavaScript

## 简介

This example includes: - TypeScript & Loader Configuration (full support) - Source-Maps for everything (in dev) - TypeScript paths alias mapping as a standard `webpack.config.js` used within react-static's build system (see tsconfig.json` paths & src/path
