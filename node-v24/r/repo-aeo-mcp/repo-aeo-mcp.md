# repo-aeo-mcp

> 标签: developer-tools, discoverability, github-topics, llms-txt, mcp, mcp-server, model-context-protocol, monitoring, npm-search-score

## 简介

MCP server for continuous repository discoverability monitoring: npm search score, GitHub visibility signals, llms.txt freshness and site checks. Read-only by default.
