# ratchet-verify

> 标签: automation, bisect, breaking-changes, changelog, ci-cd, cli, code-quality, continuous-integration, dependencies, dependency-management, developer-tools, devtools, github-actions, javascript, lockfile, nodejs, npm, package-management, semver, static-analysis, supply-chain-security, testing, typescript, upgrade

## 简介

Verify a dependency bump before you merge it: real tests, changelog breaking changes vs. actual usage, bisection to the breaking version.
