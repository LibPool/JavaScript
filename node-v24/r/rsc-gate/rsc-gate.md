# rsc-gate

> 标签: app-router, ci, lint, nextjs, react, react-server-components, rsc, serialization, server-only, use-client

## 简介

Catch React Server Component boundary bugs before next build — non-serializable props, server-only leaks, and accidental client bundling — in CI and your editor.
