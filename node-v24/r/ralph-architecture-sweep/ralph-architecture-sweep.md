# ralph-architecture-sweep

> 标签: agent, architecture, claude-code, codebase, deepening, npx, ralph, refactoring, skill

## 简介

Installer for the ralph-architecture-sweep Claude Code skill — drive the ralph loop to sweep a codebase for architecture-deepening opportunities and file them as vertical-slice issues, over a whole repo or a chosen part.
