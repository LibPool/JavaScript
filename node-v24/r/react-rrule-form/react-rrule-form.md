# react-rrule-form

> 标签: component, form, icalendar, react, recurrence, recurring, rfc5545, rrule, schedule, tailwind

## 简介

A recurrence-rule (RFC 5545 RRULE) form component for React. Tailwind-styled by default, restylable down to every element, zero runtime dependencies.
