# react-native-webrtc-playback

> 标签: android, ant-media, audio, compressor, expo, expo-plugin, ios, jitter-buffer, leveller, limiter, live-streaming, nitro-module, playback, playout, react-native, react-native-nitro-modules, react-native-webrtc, webrtc, whep

## 简介

Makes react-native-webrtc playback sound like media, not a phone call: a play-only audio path, a voice leveller behind a limiter, and a playout buffer that rides out poor networks. iOS, Android, Expo.
