# react-native-tabbar-navigator

> 标签: ios, navigator, react, react-native, tabbar

## 简介

Yet another TabBar + Navigator component in React Native iOS, mainly focus on simplify the construction of TabBar + Navigator, and solving the problem of lacking `hidesBottomBarWhenPushed` feature in React Native iOS.
