# rn-snappy-toast

> 标签: android, ios, react-native

## 简介

rn-snappy-toast is a lightweight, fast, and fully customizable toast notification library for React Native.It’s designed to help you deliver instant, non-intrusive, and delightful feedback to your users — with minimal setup and maximum flexibility.
