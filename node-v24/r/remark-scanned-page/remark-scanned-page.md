# remark-scanned-page

> 标签: accessibility, directive, handwriting, highlight, mark, markdown, remark, remark-plugin, scanned, transcription

## 简介

Publish a scanned page with a synchronised transcription and an accessible fallback. Colour highlights live inside the markdown as directives.
