# repro-agent

> 标签: agents-md, ai-agent, bug-report, claude-code, diagnostics, issue-triage, open-source-maintainers, prompt-injection, repro, reproduction, support, troubleshooting

## 简介

No repro, no issue. An agent that runs on the user's machine: diagnoses the problem, fixes what is safely fixable, and otherwise produces a bug report with real reproduction evidence.
