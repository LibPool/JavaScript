# remons-render-markdown

> 标签: gfm, markdown, mermaid, react, render

## 简介

一个基于 React 的 Markdown 渲染组件，支持 GFM（GitHub Flavored Markdown）、代码高亮、Mermaid 图表、Tabs 渲染等功能。
