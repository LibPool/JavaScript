# rating-charts.js

> 标签: JavaScript

## 简介

This is a strongly typed JavaScript package for visualizing rating systems like Elo. It can be used in educational or gamified dashboards as well as in pure gaming applications. The package is based on D3, so all charts are rendered as SVG.
