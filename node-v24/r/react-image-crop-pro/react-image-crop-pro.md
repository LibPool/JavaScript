# react-image-crop-pro

> 标签: a11y, accessible, avatar, crop, cropper, drag-and-drop, dropzone, gesture, image, image-editor, mobile, photo-editor, pinch-zoom, profile-picture, react, react-component, resize, rotate, touch, typescript, upload, zoom

## 简介

A modern React image cropping component with drag-and-drop upload, touch gestures (pinch-zoom & rotation), and TypeScript support. Perfect for avatars, profile pictures, and image editing with built-in accessibility.
