# ros-mobile-bridge

> 标签: cdr, foxglove, mobile, react-native, robotics, ros, ros2, rosbridge, websocket

## 简介

Protocol adapters for connecting JavaScript and TypeScript runtimes to ROS 2 robots. Foxglove WebSocket and rosbridge over a single IProtocolClient interface; runs in React Native, browsers, Node.js, and Electron from the same build.
