# robowallet-sdk

> 标签: depin, iot, machine-to-machine, robowallet, session-keys, solana, web3

## 简介

TypeScript helpers for the RoboWallet on-chain program — session-key vaults with on-chain spending limits for machine-to-machine payments on Solana.
