# rgbcct-color-handler

> 标签: LED, LED strip, RGB, RGBCCT, RGBCW, RGBW, RGBWW, color, convert, hex

## 简介

Color parser and format converter for colors with up to 5 channels, such as those used by various LED and LED strip types like RGB, RGBW, and RGBCCT
