# romdev-rabbitizer

> 标签: JavaScript

## 简介

rabbitizer (MIPS instruction decoder) built from its C library to WASM, with a synchronous JS binding that mirrors the Python rabbitizer module API. Ships rabbitizer 1.16.2, 1.14.3 and 1.13.0.
