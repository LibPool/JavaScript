# reni-reactjs-sdk

> 标签: context, email-api, react, react-hooks, reni, reni-payments, renimail, sdk

## 简介

React hooks and context provider for the Reni SDK. Provides useReni, useSendEmail, useSendCampaign, and useGetBankList hooks.
