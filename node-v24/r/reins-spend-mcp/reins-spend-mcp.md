# reins-spend-mcp

> 标签: agent-payments, ai-agent, mcp, model-context-protocol, solana, spend-control

## 简介

Reins — let an LLM pay APIs only inside an on-chain spend policy (budget, payee allowlist, expiry, revoke) on Solana. MCP server + CLI.
