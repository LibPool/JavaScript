# react-path-picker

> 标签: ai-coding-agent, claude-code, codex, css-selector, cursor, dev-tool, devtools, inspector, picker, react, react-fiber, xpath

## 简介

One click saves a thousand tokens. Stop describing UI elements to your AI agent — click any element to copy its XPath, CSS selector, route, and React component info, then paste straight into Cursor / Claude Code / Codex.
