# rn-find

> 标签: agent, automation, cdp, cli, e2e, expo, hermes, idb, metro, react-native, simulator, tap

## 简介

Find and tap React Native elements by text through Metro's Hermes inspector. No testIDs, no in-app SDK, no MCP server — one CLI.
