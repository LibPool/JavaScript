> 标签: breadcrumb, cascading, category-selector, dependent-dropdown, dropdown, dynamic-dropdown, filter, hierarchical, keyboard-navigation, menu, multiselect, navigation, nested-dropdown, react, react-component, react-dropdown, search, select, tree-select, ui-component

## 简介

A powerful React cascading dropdown component with multi-selection, search functionality, and hierarchical navigation. Perfect for building category selectors, dependent dropdowns, and nested menu systems with TypeScript support.
