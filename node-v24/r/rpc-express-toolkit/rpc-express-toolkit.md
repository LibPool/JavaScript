> 标签: ajv, authentication, batch, bigint, browser, client, cors, date, express, fetch, json-rpc, json-rpc-2.0, jsonrpc, logging, middleware, node, nodejs, rate-limit, rpc, schema, secure, self-signed, server, ssl, toolkit, typescript, validation

## 简介

JSON-RPC 2.0 toolkit for Express.js with simplified APIs, structured logging, middleware, schema validation, batch support, and optional Safe Mode.
