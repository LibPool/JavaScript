# repeat-request-minder

> 标签: minder, repeat, request

## 简介

一个可以帮助你检查项目中是否存在重复请求的工具。使用后会自动监听请求，当发现1秒内有发出多次相同的请求时，会toast提示并在控制台上打印请求信息。
