# reciplan-ui

> 标签: recipe, stencil, svelte, sveltekit, ui-library, web-components

## 简介

Reusable Stencil web component library for the Recipe Finder & Meal Planner app (recipe cards, star rating, meal slots, badges, search bar, buttons).
