# react-nature-toggle

> 标签: a11y, accessible, dark-mode, day-night, light-mode, nature, nextjs, react, react-component, switch, theme-toggle, toggle, typescript

## 简介

Accessible nature-themed light/dark mode toggle for React with framer-motion springs: day landscape, night sky, animated knob. Full TypeScript.
