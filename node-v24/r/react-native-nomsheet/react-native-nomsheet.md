# react-native-nomsheet

> 标签: bottom-sheet, expo, fabric, gesture-handler, keyboard, modal, new-architecture, react-native, reanimated

## 简介

A fully-customizable, gesture-driven bottom sheet & modal for React Native + Expo, built natively on Reanimated v4 with best-in-class keyboard handling.
