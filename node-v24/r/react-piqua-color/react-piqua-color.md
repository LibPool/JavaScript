# react-piqua-color

> 标签: cmyk, color, color-picker, controlled, hex, hsl, hue, react, rgb

## 简介

A portable, fully controlled React color picker: SV square, hue bar, and hex/rgb/hsl/cmyk sliders. Self-contained styling via CSS custom properties, no CSS framework required.
