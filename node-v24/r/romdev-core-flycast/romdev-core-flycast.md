# romdev-core-flycast

> 标签: JavaScript

## 简介

Flycast libretro core (Sega Dreamcast, reios HLE BIOS) for romdev, bundled as WASM — single-threaded build with the WASM SH-4 recompiler; boots homebrew ELFs and commercial GD-ROM images.
