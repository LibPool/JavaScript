# rn-av-binder

> 标签: audio, avfoundation, expo, mediacodec, mp4, react-native, video

## 简介

On-device image + audio → MP4 composition for React Native. AVFoundation (iOS) and MediaCodec/MediaMuxer (Android). New Architecture compatible.
