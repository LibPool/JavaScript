# react-rrule-generator-ts

> 标签: JavaScript

## 简介

This is ReactJS project based on Create React Library and using Bootstrap styling. It's built with the help of a great rrule.js library.
 It also uses: 
 -lodash 
 -date-fns 
- @material-ui/pickers
