# react-upload-modal

> 标签: drag-and-drop, file-upload, modal, progress, react, s3, upload

## 简介

GoKwik media picker modal for React — content library browse with search + infinite scroll, drag & drop uploads (multipart + presigned S3 video), progress, validation. Configure baseUrl + merchantId, get back S3/CDN URLs.
