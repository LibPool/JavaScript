# react-native-get-app-list

> 标签: android, android-apps, app-integration, app-list, application-info, application-manager, cross-platform, get-installed-apps, installed-apps, mobile-apps, mobile-development, react-native, react-native-android, react-native-library, version-code

## 简介

A comprehensive library to retrieve the list of all installed applications on Android devices, including detailed information such as package names, app name and version codes.
