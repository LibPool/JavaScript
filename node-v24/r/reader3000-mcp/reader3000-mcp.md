# reader3000-mcp

> 标签: annotations, markdown, mcp, modelcontextprotocol, reader.iiik, reader3000, review

## 简介

MCP server for READER.IIIK (reader3000.com): share Markdown documents with people, read their inline notes back, leave your own as Mr. Robot. Talks only to the reader3000 gateway over HTTPS; keeps a local ledger of the documents it created so they stay yo
