# redis-tiered-cache

> 标签: cache, cache-stampede, distributed-cache, invalidation, ioredis, lru, multi-level-cache, redis, stale-while-revalidate, tiered-cache, typescript

## 简介

Distributed caching framework for Node.js — L1 memory + L2 Redis, cache stampede protection, tag invalidation, multi-cluster routing, and a plugin system.
