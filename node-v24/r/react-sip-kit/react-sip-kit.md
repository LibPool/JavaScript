# react-sip-kit

> 标签: communication, design, frontend, javascript, jssip, library, npm, react, react-hooks, react-sip, react-sip-provider, real-time, responsive, session-initiation-protocol, sip, sip.js, sipjs, state-management, telephony, typescript, utility, voip, webRTC, zustand

## 简介

A modern **React SIP.js toolkit** for building web softphones and SIP clients.   Supports **audio/video calls**, **call recording**, **screen sharing**, and **device management**, all with a clean, extensible, TypeScript-first architecture.
