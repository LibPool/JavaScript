# roulette-lite

> 标签: generative, generative-art, hero-background, illustration, line-art, palette, procedural, roulette, roulette-wheel, ssr, static-site, svg, vanilla-js, zero-dependencies

## 简介

Procedural roulette-wheel illustrations as an SVG string. Seeded geometry, brand-aware auto-palette, line or flat, top or tilted, optional CSS spin. Zero dependencies; runs in Node at build time and in the browser.
