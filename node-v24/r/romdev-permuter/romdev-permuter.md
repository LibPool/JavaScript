# romdev-permuter

> 标签: JavaScript

## 简介

Plain-JS port of decomp-permuter: PERM macros, randomization passes, the objdump-diff scorer and the compile.sh contract, with candidate evaluation in node worker threads and disassembly through WASM binutils.
