# renkei-client

> 标签: liff, line, line-login, oidc, openid-connect, renkei

## 简介

Tiny zero-dependency SDK for apps that talk to a renkei server: build the LINE login URL, exchange LIFF tokens, read the session, decode the typed line:* claims. Browsers, Node, Workers.
