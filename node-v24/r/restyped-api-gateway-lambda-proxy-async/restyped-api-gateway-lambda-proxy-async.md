# restyped-api-gateway-lambda-proxy-async

> 标签: JavaScript

## 简介

API Gateway Lambda Proxy route wrappers for declaring type-safe APIs with [RESTyped](https://github.com/rawrmaan/restyped). Also supports `async` route functions.
