# react-native-ehyc-sdk

> 标签: JavaScript

## 简介

It's built on top of `react-native-vision-camera`,  `react-native-image-resizer` and `react-native-fs` it takes an image component and upon click, you get the image picker prompt, get the base64 string of the image and the image source changes to whatever
