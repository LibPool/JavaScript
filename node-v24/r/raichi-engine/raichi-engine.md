# raichi-engine

> 标签: JavaScript

## 简介

**raichi-engine** is a lightweight 2D game engine written in TypeScript, built from scratch for educational and experimental purposes.   Inspired by classic game engines like Cocos and Love2D, with a strong focus on clarity, modularity, and full control.
