# redux-capi

> 标签: JavaScript

## 简介

Redux-capi is alternative to react-redux.  It allows you to package  actions, selectors and thunks as an API to be consumed by React components.  It uses a declarative specification for the API that eliminates the need to write reducers for state mutation
