# rwa-feeds

> 标签: bls, cap-rate, fred, market-data, oracle, real-estate, real-world-assets, rwa, valuation

## 简介

Live market data for real-world-asset valuation — commercial property price growth, cap-rate anchors, vacancy, construction cost and metro labour data, from FRED and the BLS. No API key required.
