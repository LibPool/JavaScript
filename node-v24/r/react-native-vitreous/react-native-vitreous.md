# react-native-vitreous

> 标签: appkit, glass, liquid-glass, macos, nsglasseffectview, react-native, react-native-macos

## 简介

Native macOS Liquid Glass for React Native, mirroring the expo-glass-effect API on AppKit's NSGlassEffectView.
