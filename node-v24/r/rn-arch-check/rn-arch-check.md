# rn-arch-check

> 标签: android, audit, bridgeless, ci, cli, compatibility, compatibility-checker, dependency-audit, dependency-checker, devtools, expo, expo-sdk, fabric, ios, jsi, migration, native-modules, new-arch, new-architecture, newarch, newarchenabled, react-native, react-native-directory, react-native-upgrade, turbomodule, turbomodules, upgrade

## 简介

Check which React Native dependencies support the New Architecture (Fabric, TurboModules, JSI) before you migrate. Zero-config CLI, Expo and bare RN, CI-ready.
