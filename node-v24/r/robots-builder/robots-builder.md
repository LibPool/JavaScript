# robots-builder

> 标签: crawl-delay, crawler, robots, robots.txt, seo, sitemap, user-agent

## 简介

Programmatically build robots.txt files from a JS/TS config. Per-bot rules, crawl-delay, sitemaps, host — with validation and parsing.
