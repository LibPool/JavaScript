# react-ppt-json-viewer

> 标签: deck, json, json-to-ppt, powerpoint, ppt, pptx, presentation, presentation-viewer, react, react-component, slide-viewer, slides, slideshow, viewer

## 简介

A React component to render PowerPoint-like presentations from JSON data. Supports text, images, navigation, and custom styling inside the browser.
