# router-helper_yh

> 标签: vue-router@4, vue3, 路由栈自管理

## 简介

基于vue-router@4通过「对Vue Router的go、push、replace等方法的拦截」以及「路由守卫中对 首次进入页面、页面前进、页面回退 的拦截处理」来维护自管理路由栈，实现任意页面回退至目标路由的功能
