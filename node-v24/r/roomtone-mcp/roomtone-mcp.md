# roomtone-mcp

> 标签: ai, claude, mcp, meeting notes, meeting recorder, model-context-protocol, roomtone

## 简介

MCP server that lets AI agents work with your Roomtone meeting notes: list recordings, read write-ups, add a source, chat with what was said, and get the transcript.
