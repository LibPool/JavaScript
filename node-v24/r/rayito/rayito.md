# rayito

> 标签: agent-deployment, agentcore, agents, aws, aws-cdk, bedrock, cdk, code-interpreter, e2b, lambda, microvm, sandbox

## 简介

SDK TypeScript de Rayito: sandboxes de ejecución para agentes de IA sobre AWS Lambda MicroVMs, dentro de tu propia cuenta, y despliegue de agentes en MicroVMs o en Amazon Bedrock AgentCore, con la CLI o con CDK.
