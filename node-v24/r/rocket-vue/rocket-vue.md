# rocket-vue

> 标签: JavaScript

## 简介

- rocket-vue是基于Vue开发的程序内核，整合了诸如模块加载、路由渲染、权限验证、请求发送、数据存储等核心能力，帮助开发者快速完成管理系统开发。
