# react-native-font-sim

> 标签: KaiTi, SimHei, SimSun, font, react-native

## 简介

Font `SimSun(宋体)`, `SimHei(黑体)` and `KaiTi(楷体)`, can work with `<Text/>` or `<GCanvasView/>` or react-native-font-picker
