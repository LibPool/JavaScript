# rmz-storefront-sdk

> 标签: angular, api, client-side, dokan, dokansa, ecommerce, framework-agnostic, hmac, react, rmz, rmz-gg, sdk, security, server-side, storefront, svelte, typescript, universal, vanilla-js, vue

## 简介

Secure, framework-agnostic SDK for RMZ Storefront API. Works with React, Vue, Angular, Svelte, and Vanilla JS. Supports both client-side and server-side environments. (Platform As A Backend)
