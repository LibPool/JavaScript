# retry-kit-js

> 标签: api, backoff, circuit-breaker, database, exponential-backoff, fault-tolerance, http, resilience, retry, typescript, zero-dependency

## 简介

Framework-agnostic retry with exponential backoff + jitter, and a circuit breaker, for API/DB calls. Zero dependencies, fully typed, production-ready.
