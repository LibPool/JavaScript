# rocketchat-commandwords

> 标签: JavaScript

## 简介

Parses messages for [[messageText]] or [[messageText@online_recipient]] and turns each into a clickable link that will paste <messageText> into the current room in the first case, or DM <messageText> to <online_recipient> in the second case.
