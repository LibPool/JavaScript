# react-ai-drawer

> 标签: ai, markdown, mdx, react, renderer, streaming

## 简介

一个专为 AI 应用程序设计的 React 渲染器，基于react-ai-renderer修改，支持了自定义markdown包裹快自定义渲染，支持流式 Markdown 和 MDX 内容渲染，提供 AI 推理展示、代码高亮和可选的 Mermaid 图表渲染功能。
