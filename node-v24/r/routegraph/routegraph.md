# routegraph

> 标签: astar, dijkstra, dsl, graph, navigation, pathfinding, react-native, tutorial, typescript, ui-automation

## 简介

Typed navigation graphs for apps: a compact .navgraph format, pathfinding, and JSON instruction generation with extension hooks. Works in React Native, browsers and Node.
