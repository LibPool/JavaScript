# retry-primitives

> 标签: backoff, breaker, circuit-breaker, cloudflare-workers, decorrelated-jitter, deno, durable-objects, edge, exponential-backoff, fault-tolerance, fibonacci-backoff, idempotency, jitter, lambda, pure-functions, queue, resilience, retries, retry, retry-after, serializable, stateless, typescript, zero-dependencies

## 简介

Retry and circuit breaker as pure functions — exponential, decorrelated jitter, fibonacci backoff, consecutive and rolling-window breakers. JSON-serializable state, no clock reads, no I/O, no dependencies. Survives a process restart, so it works in Cloudf
