# robot-heads-vue

> 标签: 3d, agent, ai, animation, avatar, bot, canvas, led, llm, mascot, robot, status, vue

## 简介

Animated 3D robot heads for Vue: glossy TV-headed bots with LED-matrix faces that show what an agent is doing (thinking, searching, listening, speaking and more). 2D canvas, no WebGL, no runtime dependencies. A Vue port of robot-heads.
