# r3f-aeroperf

> 标签: aeroperf, monitor, performance, r3f, react, react-three-fiber, stats, three, threejs, webgl, webgpu

## 简介

A modern performance HUD for React Three Fiber, built on top of r3f-webgpu-perf, featuring a redesigned UI and enhanced visualizations for WebGL and WebGPU.
