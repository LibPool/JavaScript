# ris-ktx2

> 标签: basis-universal, ktx, ktx2, libktx, texture, typescript, vulkan, wasm, webassembly

## 简介

Browser TypeScript library for loading, creating, and transcoding KTX2 textures, including the interfaces, enumerations, and texture-format helpers.
