# rn-sql-connect

> 标签: android, data-connect, firebase, graphql, ios, postgres, react-native, sql-connect, turbomodule

## 简介

React Native native SDK for Firebase SQL Connect (Data Connect). Wraps the Android and Apple native SDKs instead of running the JS web SDK inside React Native.
