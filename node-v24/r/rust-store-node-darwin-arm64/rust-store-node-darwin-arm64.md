# rust-store-node-darwin-arm64

> 标签: ai-agent, binding, data-layer, gql, mongodb, multi-backend, mysql, napi, napi-rs, orm-alternative, postgresql, query-planner, query-validation, rust, rust-store, sql-dialect, sqlite

## 简介

Node.js binding (napi-rs) for the rust-store multi-backend data engine: GQL parsing, permissions, computed columns and SQL dialect translation for MongoDB, MySQL, SQLite and PostgreSQL
