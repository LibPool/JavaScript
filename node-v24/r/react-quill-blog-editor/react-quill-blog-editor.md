# react-quill-blog-editor

> 标签: blog, quill, react, rich-text-editor, wysiwyg

## 简介

A React wrapper around Quill 2 preconfigured for blog content: fonts, tables, colors, alignment, line spacing, light/dark theming, non-base64 image uploads, and a read-only viewer for displaying saved posts.
