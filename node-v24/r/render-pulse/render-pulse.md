# render-pulse

> 标签: async, core-web-vitals, critical-css, defer, fcp, github-action, lcp, performance, render-blocking, static-site

## 简介

Find render-blocking resources in a built static site: head scripts without defer/async, heavy blocking CSS, @import chains, third-party blocking resources without preconnect, document.write, parser-blocking body scripts, print CSS without media, missing
