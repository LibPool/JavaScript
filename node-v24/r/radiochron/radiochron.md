# radiochron

> 标签: apple-silicon, ble, bluetooth, diagnostics, iot, linux, linux-arm64, macos, nodejs, raspberry-pi, rust, wifi, windows

## 简介

Cross-platform Node.js API and streams for RadioChron Wi-Fi flight recording, incident diagnosis, and portable BLE history/risk analysis.
