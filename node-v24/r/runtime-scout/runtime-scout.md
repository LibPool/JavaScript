# runtime-scout

> 标签: cli, environment, language-detector, nvm, pyenv, rbenv, runtime, runtime-scout, rustup, version-manager

## 简介

Detect programming languages/runtimes installed on the local machine, including versions managed by nvm, pyenv, rbenv, rustup, and more.
