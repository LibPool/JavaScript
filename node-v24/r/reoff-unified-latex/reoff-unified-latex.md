# reoff-unified-latex

> 标签: ast, converter, docx, latex, ooxast, reoff, unified, unified-latex

## 简介

Plugin for `reoff` that takes an `ooxast` tree and turns it into a `unified-latex` tree, allowing for .docx to .tex conversion
