# remote-harness-mcp

> 标签: ai, automation, computer-use, gemini, google-gemini, mcp, model-context-protocol, spark

## 简介

Turn your PC, Laptop, Server or Android phone into an autonomous execution node for Google Gemini via native MCP: 26 tools, write/edit/search, background jobs, public file and page sharing, secure reverse tunnel, self-update, and a device branch (battery,
