# react-native-live-list

> 标签: auction, countdown, expo, flashlist, flatlist, live-updates, react-native, realtime, sse, ticker, timer, viewability, websocket

## 简介

Keep the on-screen rows of a React Native list live: one shared ticker, drift-free countdowns, and viewport-scoped realtime subscriptions.
