# react-native-page-scrollview

> 标签: Broadcasting, Image, RN, ScrollView, carousel, native, page, page-ScrollView, page-scrollView, photo, picture, react, react-native, rn, scrollView, viewpager

## 简介

对ScrollView的封装,可以很方便的实现水平,垂直分页轮播效果.而且可以自定义分页宽高,和侧边View的旋转,透明度,大小等.
