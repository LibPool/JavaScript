# @ruminaider/slack-cli

> 标签: agent, cli, mcp, pi-package, slack

## 简介

Slack CLI that authenticates as you using your existing Slack desktop session. Read channels, send messages, search, and manage reactions, files, pins, and canvases from the terminal. No app, no OAuth, no admin approval.
