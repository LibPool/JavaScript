# @sternelee/rlottie

> 标签: pako, rlottie, webworker

## 简介

使用 `rlottie` + `pako` + `webworker` 在前端实现 `lottie` 的动画效果, 如 telegram 官网动画的效果, 或本地演示 `npm run dev` 优势: 体积更小，只需要 835kb 库文件 + 10Kb 左右的素材
