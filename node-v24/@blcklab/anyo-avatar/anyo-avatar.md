# @blcklab/anyo-avatar

> 标签: 3d, anyo, avatar, glb, gltf, humanoid, sekai64, spatial-web, vrm

## 简介

Optional complete humanoid Avatar system for Anyo, including renderer-neutral runtime contracts, VRM 0.x/1.0 support, and explicit Sekai64 integrations.
