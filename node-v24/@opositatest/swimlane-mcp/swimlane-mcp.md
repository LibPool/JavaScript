# @opositatest/swimlane-mcp

> 标签: claude, kanban, kanbanflow, mcp, model-context-protocol, swimlane, tanstack-ai

## 简介

Unofficial read-only MCP server for KanbanFlow: list a person's tasks across all your boards from any MCP client. Not affiliated with KanbanFlow.
