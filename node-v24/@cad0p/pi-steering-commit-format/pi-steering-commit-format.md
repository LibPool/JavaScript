# @cad0p/pi-steering-commit-format

> 标签: commit, conventional-commits, guardrails, jira, pi-package, pi-steering-package, safety

## 简介

Commit-message format validation predicates for pi-steering. Bundled formats: Conventional Commits 1.0.0 (Angular preset type allowlist), bracketed JIRA-style ticket references. Extensible via `commitFormatFactory`.
