# @mailwoman/nuts-lookup

> 标签: JavaScript

## 简介

EU coordinate → NUTS statistical-region codes (levels 1–3). Point-in-polygon over Eurostat GISCO NUTS boundaries in node:sqlite. An @mailwoman/annotations Annotator.
