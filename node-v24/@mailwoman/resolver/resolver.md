# @mailwoman/resolver

> 标签: JavaScript

## 简介

The address resolver: walk an AddressTree, decorate nodes with gazetteer-supplied coordinates + attribution. Backend-agnostic (any ResolverBackend), with the span-rescore + postcode-consistency changes. Lifted out of @mailwoman/core so it can depend on @m
