# @mailwoman/fastify

> 标签: JavaScript

## 简介

Fastify plugin for mailwoman — register geocoding, parsing, and POI search routes plus a fastify.mailwoman decorator over the local pipeline. 0.0.1 is a name-reservation placeholder; the first functional release ships with the next mailwoman minor.
