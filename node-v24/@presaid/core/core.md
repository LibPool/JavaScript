# @presaid/core

> 标签: canonical-json, commitment, merkle, presaid, proof, rfc6962, sha256, verification

## 简介

Presaid verification primitives: strict canonical JSON, SHA-256 commitments, RFC-6962 Merkle proofs, payload schemas. Verify a certificate with the exact code Presaid uses.
