# @coveops/expanding-result-actions-menu

> 标签: JavaScript

## 简介

A companion component that adds expanding capabilities to the ResultActionsMenu component. This component is used to control whether the hovering ResultActionsMenu is always visible and if so, which components are hidden until the user hovers over the res
