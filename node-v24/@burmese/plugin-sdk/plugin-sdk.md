# @burmese/plugin-sdk

> 标签: burmese, desktop-pet, plugin, sdk, types

## 简介

Type definitions and testing harness for building Burmese desktop pet plugins (SDK v3). The Burmese runtime injects the SDK implementation at load time; the ./testing entry point runs plugins without the app.
