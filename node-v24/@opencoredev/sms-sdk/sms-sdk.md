# @opencoredev/sms-sdk

> 标签: bandwidth, plivo, sinch, sms, sms-sdk, telnyx, twilio, typescript, vonage, webhooks

## 简介

One TypeScript SDK for SMS providers: Twilio, Telnyx, Plivo, Vonage, Bandwidth, and Sinch behind one typed send API with safe fallback and verified webhooks.
