# google-graphql-functions

> 标签: cloud, functions, google, graphiql, graphql

## 简介

Run graphql queries on Google Cloud Functions (beta). This package can also serve a GraphiQL UI out-of-the-box. This project is mainly a modification of the excellent express-graphiql maintained by Facebook. This project is published using a BSD-style lic
