# g-guest-mcp

> 标签: booking, g-guest, local-business, mcp, modelcontextprotocol, reservations, restaurants, salons

## 简介

Local stdio MCP server for G-Guest: book a table, appointment or class place at a real local business. Proxies to the hosted G-Guest endpoint. No account, no API key.
