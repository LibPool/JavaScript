> 标签: agents, ai, ai-sdk, breakpoints, debugger, devtools, langgraph, llm, local-first, mcp, observability, openinference, opentelemetry, tracing, vercel-ai-sdk

## 简介

GraphMind — local server + CLI for the GraphMind live agent debugger. Instrumented apps stream execution events in; the viewer watches live, replays history, and sends control commands.
