# ghiraldi-base-admin

> 标签: JavaScript

## 简介

Part of the Ghiraldi framework set of base plugins, this plugin is used as the basis for administrative interfaces in a ghiraldi app.  By itself, it doesn't do much, but serves as a base for other administrative interfaces.
