# generate-8

> 标签: generate passwords, generate sceret key, generate-8, otp generator, random data generator

## 简介

Gen8 (generate-8) is an Open Source Nodejs Library for generating random data like sceret keys, passwords, OTP numbers, etc using cryptography.
