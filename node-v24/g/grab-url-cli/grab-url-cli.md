# grab-url-cli

> 标签: aria2, cli, download, downloader, file-downloader, grab-url, magnet, resume, sftp, torrent, web-archiving, yt-dlp

## 简介

The grab-url transfer CLI: resumable HTTP/SFTP downloads, torrents and magnets via aria2c, 700+ media sites via yt-dlp, and whole-page archiving. Ships as its own package so importing grab-url stays a 5kB library.
