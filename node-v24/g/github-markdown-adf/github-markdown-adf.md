# github-markdown-adf

> 标签: adf, atlassian, atlassian-document-format, bidirectional, converter, gfm, github-flavored-markdown, jira, markdown, parser

## 简介

Bidirectional GitHub Flavored Markdown (GFM) to/from Atlassian Document Format (ADF) converter for Node.js, browsers, and TypeScript.
