# gulp-webdriver

> 标签: bdd, gulp, gulpplugin, mocha, runner, saucelabs, selenium, tdd, test, testing, webdriver, webdriverio

## 简介

gulp-webdriver is a gulp plugin to run e2e tests with the WebdriverIO testrunner
