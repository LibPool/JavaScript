# geoip-country-lite

> 标签: country, geo, geoip, geolite, geolookup, ip, ipv4, ipv6, maxmind

## 简介

A fork of GeoIP-lite, a light-weight, native JavaScript implementation of GeoIP API from MaxMind that only supports country data.

## 官网

- 官网：https://github.com/carlosrymer/geoip-country-lite
- 源码仓库：git://github.com/carlosrymer/geoip-country-lite.git
- npm 页面：https://www.npmjs.com/package/geoip-country-lite
