# grunt-styledoc

> 标签: css, cssdoc, docblock, documentor, generator, gruntplugin, less, presentation, sass, scss, showcase, styledoc, stylus

## 简介

Grunt wrapper for styledoc: parser and showcase generator for JavaDoc-like comments in CSS, LESS, SASS etc.
