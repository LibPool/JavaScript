# grok-loop-kit

> 标签: agent, agent-loop, context-compaction, grok, grok-4.5, langchain, langgraph, llm, responses-api, xai

## 简介

Auto-apply Grok 4.5 context compaction to xAI Responses API agent loops. Drop-in client that compacts every N turns or when a token budget is exceeded.
