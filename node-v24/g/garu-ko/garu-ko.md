# garu-ko

> 标签: browser, hangul, korean, korean-nlp, korean-tokenizer, lightweight, morphological-analysis, nlp, offline, pos-tagging, tokenizer, wasm, webassembly, 한국어, 형태소-분석, 형태소-분석기

## 简介

Ultra-lightweight Korean morphological analyzer for the web (1.2MB model, WASM, F1 96.0% gold testset)
