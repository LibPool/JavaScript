# gitle-cli

> 标签: agents, ai, claude, cli, github, mcp, prd, project-management, spec-driven, task-graph

## 简介

Gitle CLI — describe what you want to build, get a dependency graph of GitHub issues, and dispatch AI agents (or teammates) to ship it. Companion CLI for gitle.app.
