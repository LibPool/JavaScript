# gtfs-one-mcp

> 标签: ai, bus, claude, gtfs, gtfs-realtime, mcp, model-context-protocol, public-transit, transit, wordpress

## 简介

Model Context Protocol server for any GTFS One transit site. Lets AI assistants query bus stops, schedules, routes, live vehicle positions, and service alerts from an agency's live GTFS data. Runs locally (stdio) or as a hosted remote connector (Streamabl
