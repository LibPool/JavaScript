# gulp-runner-tdp-plugin-build-css

> 标签: compress, concatenate, css, glob, gulp, gulp-runner-tdp, minify, plugin

## 简介

A plugin for gulp-runner-tdp (or standalone gulp-task) which (configurably) performs various build tasks on CSS files via glob-able path patterns
