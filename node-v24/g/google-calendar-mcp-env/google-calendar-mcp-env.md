# google-calendar-mcp-env

> 标签: calendar, google-calendar, mcp, model-context-protocol, oauth, stateless

## 简介

Stateless Model Context Protocol (MCP) server for Google Calendar. Authenticates purely via environment variables (OAuth refresh token) — no on-disk credential files, no runtime browser flow. Built for headless/containerized agents.
