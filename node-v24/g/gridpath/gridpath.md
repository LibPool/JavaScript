# gridpath

> 标签: ai-agent, claude-code, codex, cursor, embed, embeddable, excel, grid, ironcalc, mcp, model-context-protocol, react, spreadsheet, webassembly, xlsx

## 简介

Real Excel files in your web app and in your agent: an embeddable spreadsheet with a Rust/WebAssembly engine, in-place .xlsx saves and AI tools, plus an MCP server for coding agents.
