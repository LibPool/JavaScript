# gomerch-pg

> 标签: gobiz, gofood, gomerch, gopay, gopay-merchant, indonesia, indonesian-payment, merchant, nodejs, payment, payment-gateway, qris, qris-dynamic, typescript

## 简介

GoPay Merchant Payment Gateway - Library payment gateway tidak resmi untuk GoPay Merchant / GoBiz Indonesia. Mengubah QRIS statis menjadi QRIS dinamis per pesanan dan mendeteksi settlement melalui polling API transaksi GoBiz.
