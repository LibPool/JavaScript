# globalrules-mcp

> 标签: ai-agents, country-data, holidays, mcp, model-context-protocol, vat, x402

## 简介

MCP server for GlobalRules: verified country facts (VAT, public holidays, tipping, visas, ~55 topics x 120+ countries). Free tools work with zero setup (no wallet, no signup); paid tools return structured JSON with sources via automatic x402 micropayments
