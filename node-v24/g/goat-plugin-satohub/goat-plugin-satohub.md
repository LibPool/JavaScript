# goat-plugin-satohub

> 标签: agents, ai, goat, goat-plugin, goat-sdk, onchain-agents, preflight, satohub, web3

## 简介

GOAT SDK plugin for Sato Hub: run a Preflight check on a repo, package, MCP endpoint or token before your agent installs, connects to or trades it, and search the scored onchain-agent index. Keyless, read-only, never signs or moves funds.
