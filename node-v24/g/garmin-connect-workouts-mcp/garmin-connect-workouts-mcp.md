# garmin-connect-workouts-mcp

> 标签: claude, fitness, garmin, garmin-connect, mcp, training, workout

## 简介

MCP server that turns natural-language workout descriptions into structured Garmin Connect workouts, with pace/heart-rate/power/cadence targets and real repeat blocks.
