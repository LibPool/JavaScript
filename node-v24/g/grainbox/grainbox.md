# grainbox

> 标签: api-first, fine-grained, fp, framework, front-end, frp, functional, functional-reactive-programming, grain, grainstack, minimal, reactive, small, state management, vanilla

## 简介

A minimal reactivity solution sans compiling or bundling, allowing SPAs to be built without compilers, bundlers or even NPM.
