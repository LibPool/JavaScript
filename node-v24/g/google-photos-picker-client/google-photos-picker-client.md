# google-photos-picker-client

> 标签: google-photos, google-photos-picker, import, oauth, picker, react, svelte

## 简介

Framework-agnostic client for the google-photos-picker import flow (state machine, popup-safe OAuth, polling) with optional React and Svelte adapters.
