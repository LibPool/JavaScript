# gmfarcaster-shoutout-mcp

> 标签: farcaster, gm-farcaster, mcp, model-context-protocol, mpp, shoutout, sponsor, tempo, x402

## 简介

MCP server for the On-Air Shoutout API — pay to have a sponsor message read live on the GM Farcaster show, from any MCP client. Pay-per-call via x402 (USDC on Base) or MPP (USDC on Tempo); no API keys.
