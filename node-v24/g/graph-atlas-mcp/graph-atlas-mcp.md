> 标签: changelog, entra, graph, identity, mcp, mcp-app, microsoft, schema, visualization

## 简介

MCP server tracking undocumented and documented Microsoft Graph API schema changes across Entra ID, Entra ID Governance, Identity & Access Management, Entra Agent ID, and Information Protection — with an interactive MCP Apps schema visualiser.
