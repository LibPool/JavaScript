# gulp-h5epacker

> 标签: gulp, html5, 页面资源打包进html页面

## 简介

移动H5页面打包工具，可以根据描述将资源打包进html，替换资源为全局资源包CDN地址，减少请求数量

## 官网

- npm 页面：https://www.npmjs.com/package/gulp-h5epacker
