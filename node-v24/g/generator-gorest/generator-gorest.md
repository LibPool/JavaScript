# generator-gorest

> 标签: api, go, golang, microservice, rest, webservice, yeoman-generator

## 简介

yeoman generator for creating a ready rest api. gorilla mux for routing, logrus for logging , negroni for middleware. Comes with options for mongodb and stomp for messaging. Has ready dockerfile and docker compose config
