# green-tomato

> 标签: api, backup, cache, hoxy, javascript, mock, mock-server, node, nodejs, proxy, reverse, sandbox, test

## 简介

A sandbox and mock server that automatically records mocks by a reverse proxy. It can be used as a API cache
