# google-trends-js

> 标签: google-trends, google-trends-api, google-trends-js, javascript, keyword-research, seo, trendsapi, typescript

## 简介

Google Trends client for JS/TS. Interest over time, growth, and live trending searches via the Trends API. Zero-scrape alternative to the abandoned google-trends-api package.
