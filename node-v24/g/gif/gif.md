# gif

> 标签: gif, image, picture, rgb, rgba

## 简介

A C++ module for node-js that converts RGB and RGBA buffers to a GIF images (in memory).

## 官网

- 源码仓库：https://github.com/pkrumins/node-gif.git
- npm 页面：https://www.npmjs.com/package/gif
