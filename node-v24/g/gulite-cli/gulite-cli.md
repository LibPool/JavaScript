# gulite-cli

> 标签: JavaScript

## 简介

* launch下的sync.json引入的bin文件放到项目根目录（编译时会自动拷贝） * 运行代码和执行代码存放在同个根目录（运行代码guliteos_demo和编译代码guliteos_build） * 编译文件和运行文件引入目录使用相对路径
