# gulp-gapps-rename

> 标签: gulpplugin

## 简介

Gulp Plugin to rename files to Google Apps Script compatible names. To be used before uploading files to GApps

- 官网：https://github.com/rodyhaddad/gulp-gapps-rename#readme
- 源码仓库：git+https://github.com/rodyhaddad/gulp-gapps-rename.git
- npm 页面：https://www.npmjs.com/package/gulp-gapps-rename
