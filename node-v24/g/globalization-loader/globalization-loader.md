# globalization-loader

> 标签: JavaScript

## 简介

国际化 编译打包，直接中文开发，不用考虑国际化的任何方案 打包 自动提取 中文段落，你只需在谷歌翻译上翻译对应的中文然后保存文件即可。重新打包就ok了
