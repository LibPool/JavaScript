# genesis-assurance

> 标签: ai-agents, assurance, audit, ci, ledger, reward-hacking, rlvr, verifier

## 简介

Universal evaluation and assurance platform for AI-native software: declarative evaluations (claim → dataset → subject → evaluator → metrics → evidence → verdict) plus adversarial verifier assurance with tamper-evident ledger.
