# gatsby-plugin-gtag

> 标签: gatsby, gatsby-plugin, google-analytics, gtag, outbound-link

## 简介

Gatsby plugin to add Google Analytics gtag.js (replacement for analytics.js) to a site. Includes Outbound Links.
