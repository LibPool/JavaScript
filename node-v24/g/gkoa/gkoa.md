# gkoa

> 标签: koa, koa-route, node, template

## 简介

1. 基于 koa 封装，通过装饰器简化路由、自定义中间件等写法。 2. 全局错误捕获机制，写入 logs 目录，便于排查问题。 3. 抽离数据库配置文件，通过插件简化 sql 语句。 4. 增加 pm2 部署方式，简便快捷！
