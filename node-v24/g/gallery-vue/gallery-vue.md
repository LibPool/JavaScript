# gallery-vue

> 标签: carousel, gallery, gallery-vue, gallery-vuejs, images, mobile, pictures, slider, touch, vue, vue-carousel, vue-component, vue-gallery, vue-plugin, vue-slide, vue-vimeo, vue-youtube, vuejs, vuejs-gallery, vuejs-vimeo, vuejs-youtube

## 简介

VueJS responsive and customizable image and video gallery, carousel and lightbox, optimized for both mobile and desktop web browsers. Support Youtube and Vimeo.
