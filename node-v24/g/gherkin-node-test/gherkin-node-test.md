# gherkin-node-test

> 标签: acceptance-testing, agent, bdd, bun, bun-test, cucumber, deno, deno-test, gherkin, gherkin-lint, linter, node-test, vibe-coding, zero-dependency

## 简介

The smallest honest Gherkin runner and feature-file linter — zero dependencies, native on node:test, bun:test, and Deno, with a vitest adapter, built for agent-driven BDD.
