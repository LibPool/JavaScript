# git-pandit

> 标签: ai, automation, cli, commit, conventional-commits, developer-tools, git, ollama, openai

## 简介

An AI-powered CLI tool that automatically generates meaningful, well-structured git commit messages from your staged changes. Supports free offline mode via Ollama, mood personalities, git personality scoring, and team leaderboards.
