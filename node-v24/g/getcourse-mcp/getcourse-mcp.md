# getcourse-mcp

> 标签: ai, automation, cdp, claude, elearning, getcourse, lms, mcp, mcp-server, model-context-protocol, playwright, typescript

## 简介

MCP server that automates a GetCourse account (grant lesson/training access, manage users & groups) through a logged-in browser over CDP.
