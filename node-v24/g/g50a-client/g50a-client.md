# g50a-client

> 标签: air-conditioner, g-50a, gb-50a, hvac, m-net, melans, mitsubishi

## 简介

Framework-free Node.js client for Mitsubishi Electric G-50A / GB-50A centralized AC controllers (M-NET / MELANS XML over HTTP).
