# gutcheck

> 标签: ai-generated-code, claude-code, hollow-tests, mutation-testing, pseudo-tested, test-quality, testing

## 简介

Diff-scoped mutation probe for AI-written tests: guts each changed function and reruns only its own tests, reporting proven, hollow, one-sided, unverifiable, or no binding test — each with a replayable receipt.
