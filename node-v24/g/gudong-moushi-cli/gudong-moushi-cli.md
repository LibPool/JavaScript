# gudong-moushi-cli

> 标签: agent, ai, cli, local-first, moushi, s3, todo, webdav

## 简介

CLI tool that lets AI agents read and manage your Moushi (谋事) todo tasks from S3/WebDAV. No MCP needed, just a command.
