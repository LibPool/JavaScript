# gwe-engine

> 标签: chinese-novel, fiction, nlp, quality-check, web-novel, writing, writing-assistant, 小说写作, 网文, 质量检测, 连贯性检查

## 简介

GWE - Generic Web-novel Engine: 网文追读力检测引擎。7维雷达评分 + 26项质量规则 + 身体锚点检测 + 全书连贯性分析，帮你写出不被划走的网文。
