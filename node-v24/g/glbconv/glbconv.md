# glbconv

> 标签: 3d-tiles, converter, glb, gltf, obj, ply, stl, usdz, zero-dependency

## 简介

GLB（glTF バイナリ）を他の 3D 形式へ変換する小さな道具。依存ゼロ・ブラウザと Node の両方で動く。Draco は注入口（decodeDraco）で受ける。
