> 标签: ai, automation, bridge, claude, claude-code, genudo, http, mcp, model-context-protocol, stdio, streamable-http

## 简介

Connect Claude to Genudo — the platform to build AI agents for any communication or sequence-based channel. Create and manage pipeline-aware agents with integrations and company-knowledge access, from one platform, one inbox, and one analytics dashboard.
