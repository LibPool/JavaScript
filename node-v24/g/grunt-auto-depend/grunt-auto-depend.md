# grunt-auto-depend

> 标签: auto, dependencies, gruntplugin, install

## 简介

Auto install grunt dependencies from grunt.loadNpmTasks as you program so that you can be even lazier.

- 官网：https://github.com/norcalli/grunt-auto-install
- 源码仓库：git://github.com/norcalli/grunt-auto-depend.git
