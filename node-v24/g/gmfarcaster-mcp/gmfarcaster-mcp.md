# gmfarcaster-mcp

> 标签: farcaster, gm-farcaster, knowledge-api, mcp, model-context-protocol, mpp, tempo, warpee, x402

## 简介

MCP server for the Warpee Knowledge API — query the GM Farcaster podcast archive from any MCP client. Pay-per-call via x402 (USDC on Base) or MPP (USDC on Tempo); no API keys.
