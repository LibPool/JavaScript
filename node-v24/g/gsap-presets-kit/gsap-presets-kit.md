# gsap-presets-kit

> 标签: animation, greensock, gsap, marquee, presets, scroll, scrolltrigger, splittext, timeline, typewriter

## 简介

Un set pequeño, tipado y validado en runtime de helpers para GSAP: animateFrom, animateTo y animateFromTo, más presets de SplitText, Typewriter y Marquee, con soporte de ScrollTrigger y timelines.
