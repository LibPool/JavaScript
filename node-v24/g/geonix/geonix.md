# geonix

> 标签: JavaScript

## 简介

A Node.js microservices framework built on [NATS](https://nats.io/). Write self-announcing services as plain JavaScript classes with HTTP endpoints defined as specially-named methods. A gateway component automatically discovers services and routes HTTP/We
