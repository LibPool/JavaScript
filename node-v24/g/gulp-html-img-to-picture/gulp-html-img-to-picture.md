# gulp-html-img-to-picture

> 标签: avif, avifhtml, gulp, gulp avif, gulp webp, gulp-avif-html, gulp-webp, gulp-webp-html, gulpplugin, html-tag-picture, img-to-picture, picture, source, type-avif, type-webp, webp, webphtml

## 简介

Gulp plugin to wrap tag <img> with <picture> adding <source> including .avif and .webp and sort sources inside <picture> by size
