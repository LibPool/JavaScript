# gitbook-plugin-mermaid-svg

> 标签: chart, documentation, gitbook, graph, honkit, mermaid, svg

## 简介

Mermaid SVG 渲染插件（GitBook 3 版，与 honkit-plugin-mermaid-svg 同代码）。构建时自动将 ```mermaid 代码块渲染为矢量图（website 输出 SVG / EPUB+PDF 输出 PNG）。
