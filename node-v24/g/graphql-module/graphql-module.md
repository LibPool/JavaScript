# graphql-module

> 标签: cli, graphql, prisma, typescript

## 简介

this package allows to create a a generic GraphQL module (with GraphQL types and prisma schema).  it uses :  -  prisma : (version ```>=15.5```) -  GraphQL  -  Postgres : or any other database
