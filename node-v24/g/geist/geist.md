# geist

> 标签: geist, geist mono, geist pixel, geist sans, vercel font

## 简介

Geist is a new font family for Vercel, created by Vercel in collaboration with Basement Studio.

- 官网：https://vercel.com/font
- 源码仓库：git+https://github.com/vercel/geist-font.git
