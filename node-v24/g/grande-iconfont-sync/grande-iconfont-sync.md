# grande-iconfont-sync

> 标签: alibaba, automation, cli, font, icon, iconfont, iconfont同步, mcp, model-context-protocol, sync, 自动同步, 阿里图标库

## 简介

CLI tool and MCP server for automatically synchronizing Alibaba iconfont project files to local, supporting file difference comparison (ignoring timestamps) and automatic updates.
