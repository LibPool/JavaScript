# gitfork

> 标签: JavaScript

## 简介

Fork a Github repo with node.js (programmatically) with just `user/repo` pattern or through [gitfork-cli][gitfork-cli] package for CLI usage.

- 官网：https://github.com/tunnckoCore/gitfork
- 源码仓库：git://github.com/tunnckoCore/gitfork.git
- npm 页面：https://www.npmjs.com/package/gitfork
