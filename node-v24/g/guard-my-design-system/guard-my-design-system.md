# guard-my-design-system

> 标签: ai-agents, ci, code-quality, code-review, css, design-drift, design-ops, design-system, design-tokens, developer-tools, github-action, lint, linter, pull-request, style-guide, tailwind

## 简介

Your design system dies one pull request at a time. This makes sure it doesn't. A guard that judges only the lines a change adds, against the system the repo already has, and names the on-system value the author probably meant.
