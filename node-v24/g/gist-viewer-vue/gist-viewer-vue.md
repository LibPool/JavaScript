# gist-viewer-vue

> 标签: code-block, component, embed, gist, github, github-gist, nuxt, syntax-highlighting, vitepress, vue, vue3

## 简介

A Vue 3 component for embedding GitHub Gists with syntax highlighting, line numbers, and a copy button.
