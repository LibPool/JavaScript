# generator-create-native-di

> 标签: create react native, di, native, npm, react, react native cli, yeoman-generator

## 简介

cli สำหรับ react native ที่มีตัวอย่างโครงสร้างพื้นฐานพร้อมใช้งานประกอบไปด้วย package หลักๆ เช่น mobx,moment,lodash และรองรับภาษา javascript es6 และมี di สำหรับสลับ Store ที่จะติดต่อ api กับ fake mockup ที่สร้างขึ้นเอง ^^ สามารถ install project ด้วย คำสั่ง
