# gulp-ccr-watch

> 标签: browser-sync, cascading, configurable, configurable-gulp-recipe, configurable-gulp-recipes, configuration, configurations, cook, cookbook, gulp, gulp 4.0, gulp recipe, gulp recipes, gulp task, gulp tasks, gulp-ccr, gulp-chef, gulp-cookery, plugin, plugins, recipe, recipes, reload, task, tasks, watch

## 简介

Watch source files of specific tasks and their descendants and run corresponding task when a file changes. A cascading configurable gulp recipe for gulp-chef.
