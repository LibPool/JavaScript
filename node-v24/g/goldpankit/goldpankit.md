# goldpankit

> 标签: build framework, cli, cli platform, code generate, goldpankit, kit, 代码生成, 脚手架平台

## 简介

GoldPanKit是一款极速研发套件，可在套件中快速构建各类技术框架和项目。开源作者可发布自己的项目，并为其设定金额，实现开源项目的盈利。
