# geovouch-store

> 标签: JavaScript

## 简介

GeoVouch storage layer — the Drizzle table defs, D1 read/write, and the rolling-window query for a Cloudflare Workers + D1 consumer. Batteries-included: import this and get tables + migration + windowed metrics, no re-declaration. Depends on drizzle-orm;
