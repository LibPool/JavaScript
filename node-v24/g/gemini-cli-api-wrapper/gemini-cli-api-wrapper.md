# gemini-cli-api-wrapper

> 标签: ai, api, cli, gemini, gemini-cli, genai, google, langchain, llm, openai, proxy, rest, wrapper

## 简介

Local REST API server wrapping @google/gemini-cli-core with OpenAI-compatible endpoints. Use Gemini models with any OpenAI client — no API key needed.
