# greenlit-books

> 标签: agents, ai, books, catalog, claude, cli, definitions, glossary, greenlit-books, kindle, llms-txt, mcp, search

## 简介

Official thin CLI for the Greenlit Books public catalog API: search, browse, fetch, and define the terms the books coin. JSON-first, built for agents and humans.
