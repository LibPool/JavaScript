# github-user-profile

> 标签: api, github

## 简介

Muestra la información de un usuario de Github haciendo uso de la librería de la API. La librería está desarrollada en Angular.

- 源码仓库：git+https://github.com/Heber-739/angular-libs.git
- npm 页面：https://www.npmjs.com/package/github-user-profile
