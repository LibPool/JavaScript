# gdrive-publish

> 标签: cli, google-docs, google-drive, google-sheets, markdown, pi-package, publish

## 简介

Publish markdown, CSV and Excel files to Google Drive as native Google Docs and Sheets, rewriting relative links to real Doc URLs with stable sharing links
