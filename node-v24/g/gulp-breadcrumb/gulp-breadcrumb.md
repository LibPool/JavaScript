# gulp-breadcrumb

> 标签: HTML5, accessible, bootstrap, breadcrumb, breadcrumbs, gulp

## 简介

A gulp plugin that creates accessible HTML5 breadcrumbs (with bootstrap classes) based on the page directory structure.
