# grunt-asciidoctor-assemble

> 标签: asciidoc, asciidoctor, assemble, grunt

## 简介

Uses AsciiDoc or Markdown files to produce a static website. This is a combination of grunt-asciidoctor and assemble. Thanks @anthonny_q for grunt-asciidoctor.
