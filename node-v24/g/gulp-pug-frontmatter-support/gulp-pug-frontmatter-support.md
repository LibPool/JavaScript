# gulp-pug-frontmatter-support

> 标签: compile, frontmatter, gulpplugin, jade, pug, stream

## 简介

A fork of Gulp-Pug that adds frontmatter support. Was intended for use with the Jekyll-Bliss project but will work for any use.
