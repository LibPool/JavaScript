> 标签: allow-flag, api-keys, cli, code-quality, console-log, debugger, developer-tools, focused-test, git, git-hooks, hook, pre-commit, pre-push, safe-push, secret-detection, security

## 简介

A lightweight CLI tool that scans staged Git files before push and prevents dangerous code from being pushed accidentally.
