# gsm.ino

> 标签: arduino, avr, gcc, ino, leo, make, uno, yun

## 简介

With this library you can use the Arduino GSM shield to connect on GSM and GPRS networks Packaged for the leo build system.

- 官网：http://arduino.cc/en/Reference/GSM
