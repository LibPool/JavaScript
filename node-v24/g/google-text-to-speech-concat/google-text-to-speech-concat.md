# google-text-to-speech-concat

> 标签: cloud, concat, concatenation, google, google cloud, split, ssml, text to speech, text to speech api, text-to-speech, text-to-speech api

## 简介

Automatically split large text into parts Google's Text To Speech API can consume, and concatenated the audio into one single audiofile.
