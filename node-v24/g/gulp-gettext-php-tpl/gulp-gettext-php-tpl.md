# gulp-gettext-php-tpl

> 标签: gettext, gulp, gulpplugin, msgfmt, msgmerge, php, smarty, tpl, xgettext

## 简介

Gulp plugin to parse .php and .tpl (Smarty) files, detect GNU Gettext usages in it and compile a .POT file. It can then merge .PO/.MO files with the newly generated template
