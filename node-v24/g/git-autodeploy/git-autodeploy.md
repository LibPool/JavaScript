# git-autodeploy

> 标签: JavaScript

## 简介

AutoDeploys an application   [![NPM](https://nodei.co/npm/git-autodeploy.png)](https://nodei.co/npm/git-autodeploy/)   ## Commands   add - adds an app         syntax: git-autodeploy add --remote <repoPathShort> --name <appName> --script <startScript>
