# geokdbush-tk

> 标签: JavaScript

## 简介

**Note 1:** This fork works with `kdbush 4.x`, which doesn't store the whole objects, but only ids, so you have to keep the id-to-object lookup by yourself, and the `.around` method returns just ids.
