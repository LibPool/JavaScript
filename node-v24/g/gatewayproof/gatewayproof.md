# gatewayproof

> 标签: conformance, cost-tracking, gateway, litellm, llm, openai-compatible, proxy, streaming, testing

## 简介

A conformance test suite for OpenAI-compatible LLM gateways -- catches streaming-fidelity, usage-accuracy, cost-accuracy, concurrency, and error-propagation bugs against a deterministic mock upstream.
