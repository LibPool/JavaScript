# gemma-webgpu

> 标签: ai, browser, gemma, gguf, inference, llm, ml, q8, quantized, transformer, webgpu

## 简介

Run Gemma 3 locally in the browser via WebGPU. Q8_0 quantized, streaming generation, multi-turn chat with KV cache reuse.
