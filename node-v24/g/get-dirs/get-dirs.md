# get-dirs

> 标签: dir, directories, dirs, folders, list, recursive, recursively, subdirectories, subdirs, subfolders

## 简介

Recursively get all directories and subdirectories of a path via a readable Stream. Allows for exclusions (eg 'node_modules')
