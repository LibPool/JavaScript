# gulp-chrome-manifest-iconify

> 标签: chrome, chrome extension, extension, gulp, gulpplugin, icon, manifest

## 简介

A gulp plugin that takes a master icon and automatically generates icon set for your Chrome extension or app by parsing the v2 manifest
