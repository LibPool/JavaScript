# glyphrow

> 标签: accessibility, auto-fit, css, font, font-feature-settings, font-tester, font-variation-settings, fonts, framework-agnostic, glyphrow, google-fonts, opentype, react, type-proofing, type-specimen, type-tester, typescript, typography, vanilla-js, variable-fonts, web-typography, zero-dependencies

## 简介

Accessible, dependency-free type tester for the web — a vanilla JS core with an optional React wrapper. Composable OpenType features, variable-font axes, and auto-fit sizing.
