# gstinapi-mcp

> 标签: claude, gst, gst-verification, gstin, hsn, india, mcp, model-context-protocol

## 简介

MCP server for gstinapi.in — GSTIN verification, GST return/compliance/filing-preference history, and HSN/SAC code lookup, for use from Claude and other MCP clients.
