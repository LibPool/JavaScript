# gtfs-sqljs

> 标签: better-sqlite3, browser, expo-sqlite, gtfs, nodejs, op-sqlite, react-native, sql.js, sqlite, transit

## 简介

Load GTFS data into a SQLite database (sql.js / better-sqlite3 / op-sqlite / expo-sqlite) via a pluggable adapter
