# gatsby-remark-component-images

> 标签: component, gatsby, gatsby-plugin, image, markdown, rehype, remark, responsive images

## 简介

A Gatsby remark plugin applying gatsby-plugin-sharp processing to images defined in html-style markdown rehyped components.
