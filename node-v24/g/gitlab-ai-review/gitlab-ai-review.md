# gitlab-ai-review

> 标签: ai, automation, ci-cd, code-review, gitlab, impact-analysis, merge-request, review, sdk, static-analysis

## 简介

GitLab AI Review SDK with TypeScript Call Chain Analysis - 支持 TypeScript 增量调用链分析、影响分析、删除符号检测、注释代码识别、文件内部冲突检查、智能文件过滤的智能代码审查工具
