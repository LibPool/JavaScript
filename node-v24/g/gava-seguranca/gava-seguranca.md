# gava-seguranca

> 标签: agents-md, ai-coding, cnpj, cpf, lgpd, pii, privacy, security-audit

## 简介

Auditoria de conformidade LGPD para pipelines de dados fiscais (CPF/CNPJ) em qualquer IDE — instala um AGENTS.md de auditoria, referências de tokenização/criptografia e um scanner de PII no seu projeto.
