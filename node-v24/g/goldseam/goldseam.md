# goldseam

> 标签: ai, cypress, cypress-plugin, e2e, self-healing, test-maintenance, testing

## 简介

Self-healing for the Cypress suites you already have: failures become rich captures, your model (local or API) proposes a minimal selector fix, the suite verifies it, and it arrives as a pull request.
