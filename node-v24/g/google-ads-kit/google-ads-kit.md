# google-ads-kit

> 标签: adwords, edge, fullrun, google-ads, google-ads-api, google-ads-sdk, rest-api, serverless, typescript

## 简介

REST-first TypeScript SDK for the Google Ads API by Fullrun. No gRPC, no native bindings — works everywhere.
