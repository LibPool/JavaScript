# george-sdk

> 标签: JavaScript

## 简介

Simple wrapper around [The One API](https://the-one-api.dev) with typed methods. You will need to provide your own token, link to create one [here](https://the-one-api.dev/sign-up). Methods available are: ```typescript getMovie(string) getMovies() ```
