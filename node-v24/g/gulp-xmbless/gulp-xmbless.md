# gulp-xmbless

> 标签: bless, css, gulpplugin, internet explorer, postprocessor, preprocessor, split

## 简介

CSS post-processor which splits CSS files suitably for Internet Explorer < 10. Bless + Gulp + gulp-bless = gulp-xmbless
