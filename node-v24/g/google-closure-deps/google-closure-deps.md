# google-closure-deps

> 标签: closure, dependencies, goog, javascript, library

## 简介

Library to parse dependencies for Closure Library. Also includes a CLI to generate deps.js files for Closure Library's debug loader.

## 官网

- 官网：https://developers.google.com/closure/library/
- 源码仓库：git+https://github.com/google/closure-library.git
- npm 页面：https://www.npmjs.com/package/google-closure-deps
