# google-crawl-simulator

> 标签: JavaScript

## 简介

Simulates how Googlebot crawls and indexes a page: robots.txt rules, raw HTML crawl (wave 1), JS-rendered crawl (wave 2, like Google's Web Rendering Service), and SEO signal extraction (title/meta/canonical/hreflang/structured data/alt text/links/status c
