> 标签: agents, ai, bm25, claude-code, cli, context, cursor, llm, mcp, mcp-server, memory, rag, resolver, retrieval, search

## 简介

Resolver for AI agents: a question resolves to where its answer is written, read again every time. No keys, no packages. CLI, MCP server and library.
