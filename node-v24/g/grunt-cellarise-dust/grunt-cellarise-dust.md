# grunt-cellarise-dust

> 标签: gruntplugin

## 简介

This package has been forked from vtsvang/grunt-dust, and updates the amd wrapper to make it pass standard jshint lint tests and adds a new option 'cwd' to provide your own current working directory for relative dynamic_mappings task. Grunt.js plugin to c
