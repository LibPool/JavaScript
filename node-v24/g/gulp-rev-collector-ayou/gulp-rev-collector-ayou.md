# gulp-rev-collector-ayou

> 标签: asset, assets, collect, collector, gulp, gulpplugin, rev, revision, static, version, versioning

## 简介

Static asset revisioning by appending content hash to filenames `unicorn.css` → `unicorn.css?v=d41d8cd98f`
