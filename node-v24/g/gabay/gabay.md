# gabay

> 标签: filipino, gabay, guided-tour, onboarding, react, tooltip, tutorial, user-onboarding

## 简介

A lightweight React library for creating beautiful user onboarding experiences. Gabay means 'guide' or 'tutor' in Filipino.
