# gitscout-cli

> 标签: audit, cli, github, lockfile, malware, npm-audit, scanner, security, static-analysis, supply-chain, trojan-source, typosquatting

## 简介

Pre-clone static security scanner for GitHub repositories and local codebases. Detects malicious lifecycle scripts, credential theft, obfuscated payloads, trojan source, typosquatting, data exfiltration, and lockfile integrity issues.
