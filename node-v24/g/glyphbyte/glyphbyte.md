# glyphbyte

> 标签: glyph, handwriting, napplet, nip-19, nostr, ocr, prefix

## 简介

One drawn glyph is one byte. Read hand-drawn glyph rows from photos on the device, render rows to draw from, and resolve the bytes on nostr as event id and pubkey prefixes.
