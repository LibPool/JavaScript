# gio-webjs-sdk-cdp

> 标签: autoracker, gio, javascript, sdk, web

## 简介

GrowngIO官方 WebJS SDK，具备自动采集基本的用户行为事件，比如访问和行为数据等。目前支持代码埋点、无埋点、可视化圈选、热图等功能。
