# gatsby-plugin-dts-css-modules

> 标签: JavaScript

## 简介

GatsbyJS V4 plugin, which automatically Creates TypeScript *.d.ts files for your CSS Modules, no matter which CSS preprocessor (Sass, LESS, Stylus etc.) you are using.
