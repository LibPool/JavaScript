# guardagent

> 标签: agent, guard-core, guard-core-ts, middleware, monitoring, security, telemetry

## 简介

Telemetry & Monitoring Agent for Guard-Core TS and its thin adapters. Buffers security events and metrics, flushes them to the guard-core-app ingestion API with retry, backoff, payload-size split, and optional Redis crash recovery.
