# gitlab-ops-mcp

> 标签: ci-cd, devops, gitlab, mcp, webhooks

## 简介

Supplementary MCP server for GitLab operational tools — webhooks, CI/CD variables, protected branches, project settings, groups, access tokens, and pipeline triggers
