# gitlab-badge-proxy

> 标签: badge, coverage, gitlab, hono, pipeline, proxy, shields.io, svg

## 简介

Server-side proxy that turns private GitLab pipeline/coverage status into public SVG badges, without ever exposing the GitLab instance's URL to clients.
