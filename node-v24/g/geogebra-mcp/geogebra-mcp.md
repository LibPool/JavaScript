# geogebra-mcp

> 标签: claude, geogebra, geometry, mcp, playwright

## 简介

MCP server that lets an AI draw and edit geometry directly on GeoGebra® Calculator (geogebra.org/calculator) through Playwright. Unofficial; not affiliated with GeoGebra.
