# glanceless

> 标签: accessibility, ci, contrast, copywriting, design-review, fail-closed, gate, layout, lint, playwright, visual-regression, wcag

## 简介

Page-level design rules measured in a real browser and failed closed: contrast, dead columns, page chrome, full-column figures, a figure over a tracked label, table shape, and copy noise.
