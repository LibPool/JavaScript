# griffincss

> 标签: components, css, flexbox, grid, griffincss, layout, sass, scss, ui, utilities

## 简介

Griffincss — модульная SCSS-библиотека: ядро раскладок на CSS Grid и Flexbox, утилиты и компоненты интерфейса. Мета-пакет: ставит griffincss-core, griffincss-utils и griffincss-ui
