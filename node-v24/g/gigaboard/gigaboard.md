# gigaboard

> 标签: accessibility, chess, chess-engine, chess-ui, chessboard, gigaboard, gigachess, react, react-chessboard, ssr, typescript, wai-aria

## 简介

Ultra-fast React chessboard with owned state, byte-scoped subscriptions, refs-only drag, polished default theme and pieces, sounds, arrows, premoves, and SSR static rendering.
