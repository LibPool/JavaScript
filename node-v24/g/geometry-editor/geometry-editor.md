# geometry-editor

> 标签: canvas, compass, drawing-tool, educational-software, euclidean-geometry, geometry, geometry-construction, geometry-editor, interactive-geometry, math, math-editor, protractor, react-component, react-geometry, ruler, svg, teaching-tool, typescript

## 简介

React geometry editor component with ruler, protractor, compass, and geometry tools. Draw lines, angles, arcs, and circles. Export SVG/PNG/JSON with step-by-step playback for education.
