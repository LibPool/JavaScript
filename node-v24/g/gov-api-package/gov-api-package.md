# gov-api-package

> 标签: JavaScript

## 简介

政务能力扩展库(gov-api-package)是对外提供api能力的扩展库，方便外部小程序快速接入内部能力，前端提供的npm包对内部接口做一层封装，主要提供api能力，没有样式
