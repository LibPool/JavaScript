# glitchless-mcp

> 标签: ai-agents, claude-code, codex, coding-agent, cursor, dashboard, game-analytics, game-development, game-observability, gamedev, godot, mcp, mcp-server, model-context-protocol, observability, performance, playtesting, threejs

## 简介

Game observability MCP server: lets coding agents (Claude Code, Codex, Cursor and others) read your game's player telemetry and ranked findings, design its own dashboard, and run playtest bots.
