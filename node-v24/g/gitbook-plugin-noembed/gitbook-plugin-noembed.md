# gitbook-plugin-noembed

> 标签: facebook, gitbook, gitbook-plugin, iframe, instagram, noembed, oembed, videos, vimeo, youtube

## 简介

Get any video or iframe card supported by https://noembed.com/#supported-sites. (Vimeo, YouTube, Facebook, Twitter, Instagram, etc)
