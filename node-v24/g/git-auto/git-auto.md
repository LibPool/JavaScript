# git-auto

> 标签: JavaScript

## 简介

<h1  align="center">git-auto</h1> <div>     git-auto 优势     1.git提交推送操作更快捷 一个命令即可做到     2.提交复杂信息前缀可以直接存在本地，设置后提交自动携带     3.遇到冲突时可以自动合并代码 避免了输入git stash等操作     4.合并分支，可以不用切换分支来回操作     5.相同与系统下备份git和还原git项目 </div>
