# galacticconnection

> 标签: agent, ai, cli, galactic, galacticconnection, mcp, mcp-bridge, mcp-server, model-context-protocol, serverless, stdio, tool-discovery

## 简介

Galactic — local stdio MCP bridge + CLI. Connect any computer-access agent (Claude Code, Claude Desktop, Cursor) to the Galactic platform, with local filesystem tools, plus build/deploy/manage Agents from your shell.
