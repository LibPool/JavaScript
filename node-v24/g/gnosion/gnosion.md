# gnosion

> 标签: agent-memory, ai, brain, coding-agent, embeddings, machine-learning, mcp, memory, portable-model, self-learning, vibe-coding

## 简介

A portable, self-improving cognitive engine + universal coding-agent memory (MCP). Pluggable cognition heads (vision/text/design/tabular/memory) that learn from every input, exportable as one .gnosion file, importable anywhere.
