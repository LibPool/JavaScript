# gatsby-source-strapi-plugin-menus

> 标签: gatsby, gatsby-plugin, gatsby-source, menu, menus, strapi, strapi-plugin, strapi-plugin-menus

## 简介

Gatsby source plugin to fetch and expose the UI Menu as GraphQL nodes in Gatsby from Strapi using the strapi-plugin-menus API.
