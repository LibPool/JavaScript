# gridla

> 标签: dashboard, drag, grid, layout, nested-layout, page-builder, react, resize, responsive, typescript

## 简介

Pixel-based grid and nested-layout engine with move, resize, place, and transfer solving. Framework-neutral core with an optional React adapter.
