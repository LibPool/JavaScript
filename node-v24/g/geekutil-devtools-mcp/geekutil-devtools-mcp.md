# geekutil-devtools-mcp

> 标签: base64, developer-tools, hash, json, jwt, local-only, mcp, model-context-protocol, offline, privacy, stdio

## 简介

Local-only developer toolbox as an MCP server. JWT verify/sign, JSON, Base64, hashing, key generation, cron, timestamps, regex and URL encoding. Runs entirely on your machine with zero network calls.
