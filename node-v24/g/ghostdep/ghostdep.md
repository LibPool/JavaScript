# ghostdep

> 标签: cli, dependency-drift, dependency-health, duplicate-dependencies, esm, ghost-dependencies, npm, typescript, zombie-dependencies

## 简介

A production-ready CLI and library to detect ghost, zombie, duplicate, and drifted dependencies in Node.js and TypeScript projects.
