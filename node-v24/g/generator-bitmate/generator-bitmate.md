# generator-bitmate

> 标签: bitmate, generator, gulp, yeoman, yeoman-generator

## 简介

Generate Apps in the Cloud. Supports Angular, React and Express, packaged with Bower or Webpack and using tools such as Gulp, Browsersync, Eslint, Karma & Mocha.
