# gtm-goat-cli

> 标签: agent, cli, gtm, mcp, sales-automation

## 简介

gtm — command-line client for the GTM Automation platform. Speaks MCP over HTTP to /api/mcp/[key]; any agent (Claude Code, Codex, …) can drive it via the shell.
