# glide-editor

> 标签: angular, cli, component, dev-server, devtools, live-edit, overlay, proxy, react, tailwind, visual-editor, vue

## 简介

Visual editor for web dev servers — select, edit text, move elements, reorder, duplicate, and apply changes directly to source. Works with React, Vue, and Angular.
