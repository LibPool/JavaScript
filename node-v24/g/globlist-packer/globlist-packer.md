# globlist-packer

> 标签: archiver, distributable, gitignore archive, glob packer, globlist, globlist archive, globlist zip, ignore, ignorelist

## 简介

CLI and NodeJS utility for packing files into an archive based on ignore glob pattern lists, such as .gitignore files.
