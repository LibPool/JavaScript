# goei-sync

> 标签: anthropic, ccusage, claude-code, claude-code-cost, claude-max, cost-dashboard, cost-tracking, dashboard, goei, multi-machine, spend-by-branch, team, usage-tracking, wrapped

## 简介

Track your Claude Code spend by git branch in one command, no account. Print a shareable Claude Code Wrapped card, or sync daily rollups to Goei, the hosted team cost dashboard. Zero API keys, nothing in your request path.
