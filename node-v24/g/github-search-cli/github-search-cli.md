> 标签: cli, cli-tool, commandline, developer-experience, developer-tools, gh, github, github-api, github-search, npm-search, octokit, opentui, search, terminal, trending, trending-repositories, tui

## 简介

Search GitHub from your terminal — repo search, trending repos, npm package search, bookmarks, deep-dive, compare, export. Keyboard-driven TUI + pipeable CLI.
