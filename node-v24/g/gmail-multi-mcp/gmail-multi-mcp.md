# gmail-multi-mcp

> 标签: claude, email, gmail, llm-tools, mcp, model-context-protocol, multi-account

## 简介

MCP server for multiple Gmail accounts. Per-account permission tiers, two-phase confirmation on every send, and prompt-injection defenses on untrusted mail content.
