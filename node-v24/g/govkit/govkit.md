# govkit

> 标签: adr, cli, docs-as-code, eval, governance, quality-gate, rfc, sdlc

## 简介

Deterministic, cross-platform docs-as-code SDLC governance engine: a structural verify gate + a graded quality eval. Run with npx; no API key required.
