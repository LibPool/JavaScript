# glitchless-deck

> 标签: coding-agent, deploy, devkit, game-development, game-observability, gamedev, godot, mcp, performance, steam-deck, steamdeck, steamos, unity, unreal

## 简介

Send a game build from any computer (macOS, Windows or Linux) to a Steam Deck on your network, put it in the Deck's library, launch it and measure it with Glitchless. Godot, Unity, Unreal and web games; made for coding agents too.
