# graphweft

> 标签: ai agents, code graph, code search, copilot chat, dependency graph, embeddings, impact analysis, local-first, mcp, mcp-server, model context protocol, rag, retrieval, semantic code search, token savings, tree-sitter

## 简介

Local-first code graph: index a repo into an import/symbol graph and retrieve the relevant slice instead of whole files. Ships as a CLI, an MCP server for AI agents, a TypeScript API, and a VS Code chat participant.
