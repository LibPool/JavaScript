# garmin-connect-sdk

> 标签: fitness, garmin, garmin-connect, health, nodejs, sdk, typescript

## 简介

Unofficial Node 24+ TypeScript SDK for a user's own Garmin Connect data. Uses private Garmin Connect endpoints.
