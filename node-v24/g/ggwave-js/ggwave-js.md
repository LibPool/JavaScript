# ggwave-js

> 标签: acoustic-modem, audio, data-over-sound, demodulation, fft, fsk, ggwave, mfsk, modulation, reed-solomon, sound, ultrasound, web-audio, webaudio

## 简介

Pure JavaScript port of ggwave - data-over-sound library. 100% compatible with the original C/C++ implementation by Georgi Gerganov.
