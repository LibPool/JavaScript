# goldenprofile

> 标签: deduplication, edge, entity-resolution, goldengraph, goldenprofile, record-linkage, virtual-fingerprint, wasm

## 简介

GoldenProfile Virtual Fingerprint engine — cross-document entity resolution. Edge-safe TypeScript surface over the same pyo3-free Rust kernel as the Python/C bindings, via opt-in WebAssembly.
