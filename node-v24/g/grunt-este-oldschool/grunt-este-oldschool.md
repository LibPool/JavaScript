# grunt-este-oldschool

> 标签: Closure, CoffeeScript, Compiler, Este, Google, Mocha, Soy, gruntplugin

## 简介

This is a package for old school Este framework (version 5). Everything you need for Google Closure. Precise configuration, Soy templates, localization, TDD stack, and even CoffeeScript support. File watcher included.
