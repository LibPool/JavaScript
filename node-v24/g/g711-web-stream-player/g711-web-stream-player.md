# g711-web-stream-player

> 标签: audio-streaming, flv, g711, pcma, pcmu, react, typescript, vue, web-audio

## 简介

G.711 PCMA/PCMU streaming audio playback for browsers with FLV extraction, jitter buffering and noise reduction.
