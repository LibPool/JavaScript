# gemini-reliability-proxy

> 标签: denial-of-wallet, fallback, gemini, llm, proxy, rate-limit, reliability, retry, serverless, vercel

## 简介

Treat an unreliable LLM like infrastructure: a zero-dependency Gemini proxy core with model fallback chains, 429-vs-5xx-aware retry, chain-wide time budgets, and denial-of-wallet limits.
