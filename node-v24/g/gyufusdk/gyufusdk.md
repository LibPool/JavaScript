# gyufusdk

> 标签: JavaScript

## 简介

玉符SDK ====== 玉符SDK集成了签署和验证JWT令牌的功能，使得身份提供者（IDP）和服务提供者（SP） 只需要用很少的代码就可以轻松将玉符提供的单点登录和其他功能集成到现有的服务之中。
