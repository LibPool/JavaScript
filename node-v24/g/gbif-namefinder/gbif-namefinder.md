# gbif-namefinder

> 标签: darwin core, darwincore, gbif, global names, name finder, ocr, parser, parsing, scientific name, scientificname, silverbiology

## 简介

Node Library for interacting with GBIF's Name Finder API to detect scientific names in OCR. http://tools.gbif.org/namefinder/
