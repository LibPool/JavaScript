# gnosem-install

> 标签: ai-memory, chatgpt, claude, cursor, gnosem, installer, mcp, model-context-protocol, windsurf, zed

## 简介

One-command installer for Gnosem — cross-vendor AI memory over MCP. Detects and configures Claude Desktop, Claude Code, Cursor, Windsurf, and Zed.
