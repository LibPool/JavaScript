# github-repo-scout-mcp

> 标签: ai-agent, claude, github, github-search, mcp, model-context-protocol, repo-health, repository, topics

## 简介

Read-only MCP server for discovering and evaluating GitHub repositories: multi-topic search, topic discovery, repo health scores, comparisons and similar-repo search. Works without a token.
