# gifshot-watermarks

> 标签: WebRTC, animated gif, getUserMedia, gif

## 简介

JavaScript library that can create animated gifs from video streams (e.g. webcam), existing videos (e.g. mp4), or existing images

## 官网

- 源码仓库：https://github.com/yahoo/gifshot.git
- npm 页面：https://www.npmjs.com/package/gifshot-watermarks
