# gcp-simple-secrets

> 标签: JavaScript

## 简介

This is a library that takes in the location of a GCP secret from Google's Secret Manager and a name of an environment variable. If `process.env.NODE_ENV === 'production'` then `getSecret()` attempts to retrieve the secret from the Secret Manager service,
