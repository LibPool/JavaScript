# gimme-sats

> 标签: JavaScript

## 简介

A set of React components and utilities to make accepting Lightning payments in React apps dead simple. The core library consists of a `GimmeSatsProvider`, which wraps the application, and a `GimmeSats` button which can then be rendered throughout the app
