# gravix-rtc

> 标签: audio, conferencing, gravix, gravix-cloud, react, realtime, rtc, sfu, video, webrtc

## 简介

Real-time WebRTC client SDK for Gravix Cloud: voice, video and live rooms in the browser, with optional React bindings.
