# aitizer.sdk

> 标签: airtable, aitizer, database, no-code, postgrest, rest, sdk, supabase

## 简介

AITIZER data client with a supabase-js style API: tables, filters, ordering, counts, embedded relations, SQL and app auth. Zero dependencies.
