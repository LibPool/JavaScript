# @denkopsai/sdk

> 标签: bun, denkops, key-value, kv, persist, sdk, sqlite

## 简介

DenkOps SDK — env-aware SQLite key-value store for Bun apps deployed on DenkOps. One line: denkops.store.set/get on the durable /persist volume.
