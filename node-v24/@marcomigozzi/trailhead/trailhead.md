# @marcomigozzi/trailhead

> 标签: agent-skill, claude-code, github-issues, planning, trailhead

## 简介

Start and drive large projects as a map of tickets on GitHub Issues. Map-based onboarding + a discuss→plan→execute→verify engine, all on the Issues. Installs the trailhead skill, commands, and hooks into your agent's config dir.
