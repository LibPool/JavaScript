# @nubjs/runner

> 标签: esm, jsx, loader, nodejs, register, runner, runtime, transpiler, ts-node, tsx, typescript

## 简介

Run TypeScript on Node.js — TypeScript, JSX, tsconfig paths, and data-format imports through a native transform, as the `nubr` runner for files, scripts and installed bins, or as a preload the way tsx and ts-node are registered
