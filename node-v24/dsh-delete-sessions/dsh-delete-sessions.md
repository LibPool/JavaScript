# dsh-delete-sessions

> 标签: deepseek-harness, delete, dsh-plugin, session, 删除会话

## 简介

给 DeepSeek Harness 增加真正的「删除会话」：从侧栏会话菜单永久删除一个会话（停活动、清工作区记账/归档/置顶、删除投影缓存与日志文件），而不是只能归档。
