# @makat/i18ntool

> 标签: JavaScript

## 简介

项目中国际化配置可能分散在不同 js 或 ts 文件中，且不便于产品核对翻译是否准确。 此工具可将项目下命名中含有 i18n 的文件中的翻译对提取到 excel 中。
