# liendeadline-mcp

> 标签: ai-agents, chatgpt, claude, construction, construction-law, cursor, deadlines, lien, lien-deadlines, material-supplier, mcp, mcp-server, mechanics-lien, model-context-protocol, notice-to-owner, preliminary-notice, supplier

## 简介

MCP server for US mechanics lien and preliminary notice deadlines. Turns supplier delivery dates into statute-cited deadlines, flags what needs review instead of guessing, and serves lien guides for all 50 states and DC.
