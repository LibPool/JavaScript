# @plumbox/dev

> 标签: app-platform, cli, code-signing, ed25519, plu, plum, plum-box, plumbox, self-hosted

## 简介

Developer CLI for Plum Box apps: create a publisher key, pair your own box, package and sign a .plu, push it, follow its logs, and run a panel locally.
