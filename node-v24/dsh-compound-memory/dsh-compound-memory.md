# dsh-compound-memory

> 标签: deepseek-harness, dsh-plugin, mcp, memory

## 简介

DeepSeek Harness bundle that launches the compound-memory stdio MCP server, mounts the bundled compound-memory skill, and injects a short once-per-session usage reminder.
