# @ux-builder/design

> 标签: JavaScript

## 简介

The guided design loop (FEAT-018, CONTRACT-008): the ux-builder-design skill, the new artifact types' templates and prompts, the design state and the ux-builder-design command. CLI first, MCP optional; it makes no network request and calls no model.
