# @bridgeuidev/cms-client

> 标签: cms, firebase, firestore, headless-cms, newt, newt-client-js

## 简介

Newt (newt-client-js) API-compatible read-only client SDK for the BridgeUI CMS, backed by Firestore REST API v1. Zero dependencies.
