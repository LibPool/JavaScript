# @sixthsummit/ship-rich-text

> 标签: JavaScript

## 简介

Rich content fields for Ship applications: a versioned, kernel-owned document allowlist with server-side HTML rendering, plain-text projection, named extensions and embedded managed attachments whose purge follows the owning record
