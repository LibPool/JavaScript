# @aivo-x402/solana

> 标签: JavaScript

## 简介

AIVO Solana layer on top of the official x402 v2 protocol — auto-DID wallet + self-hosted facilitator with x402.org fallback. Re-exports @x402/* (core, svm, hono, fetch, extensions).
