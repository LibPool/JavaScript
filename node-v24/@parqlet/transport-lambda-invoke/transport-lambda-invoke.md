# @parqlet/transport-lambda-invoke

> 标签: JavaScript

## 简介

Direct AWS Lambda Invoke ClientTransport. SigV4-signed POSTs to the AWS Lambda Invoke API; no Function URL required, no @aws-sdk/* dep.
