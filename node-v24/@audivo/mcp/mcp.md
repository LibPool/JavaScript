# @audivo/mcp

> 标签: audivo, chatgpt, claude, codex, cursor, mcp, model-context-protocol, podcast, transcripts, youtube, yt-dlp

## 简介

Official Audivo MCP server: one call from an episode link to its transcript. Podcast search, episode discovery, transcripts, and on the local server YouTube audio, for Claude, ChatGPT, Codex, Cursor, and any other MCP client.
