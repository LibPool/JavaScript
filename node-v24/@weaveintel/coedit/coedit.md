# @weaveintel/coedit

> 标签: JavaScript

## 简介

**CRDT co-editing for AI apps** — a tiny, zero-dependency toolkit so a human and an AI agent can edit ONE document at the same time and always converge, with awareness cursors and offline reconcile (Collaboration Phase 7).
