# @xiaopb/dsh-roboto-mono

> 标签: deepseek-harness, dsh, dsh-plugin, font, nerd-font, oh-my-posh, plugin, roboto-mono, terminal, xterm

## 简介

Roboto Mono for DeepSeek Harness: embeds Roboto Mono, DejaVu Sans Mono and a Nerd Font icon subset so code blocks and the dsh-hardssh terminal render box-drawing symbols and Oh My Posh icons.
