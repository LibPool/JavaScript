# @jb9k62/good2go

> 标签: agent-memory, agent-skill, claude-code, cli, documentation, good2go, mcp-free, okf, open-knowledge-format

## 简介

Node tooling for OKF (Open Knowledge Format) bundles and agent memory: validator, graph viewer, Mermaid gates, ranked search, and the edukai memory bundle, plus skills and hooks for Claude Code and pi.
