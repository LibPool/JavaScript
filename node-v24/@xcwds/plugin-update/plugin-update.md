# @xcwds/plugin-update

> 标签: offline-first, pwa, service-worker, updates, xcwds, xcwds-plugin

## 简介

Updates that wait for the user in @xcwds apps: a new version waits until the user taps Update, postponed while something a reload would interrupt is running.
