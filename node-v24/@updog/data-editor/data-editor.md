# @updog/data-editor

> 标签: client-side, column-mapping, csv, csv-import, csv-importer, data-editor, data-import, data-import-sdk, dromo-alternative, excel, flatfile-alternative, grid, importer, react, react-csv, react-csv-importer, spreadsheet, spreadsheet-editor, table, usecsv-alternative, validation, xlsx

## 简介

Client-side CSV and Excel importer and spreadsheet editor for React. Import CSV, Excel, JSON, TSV, and XML, match columns, validate, and edit 1M+ rows entirely in the browser.
