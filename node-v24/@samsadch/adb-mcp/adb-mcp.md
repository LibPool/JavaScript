# @samsadch/adb-mcp

> 标签: adb, agent, ai, ai-agent, android, android-debug-bridge, antigravity, claude, claude-mcp, cursor, device-control, emulator, logcat, mcp, mcp-server, mobile-testing, model-context-protocol, modelcontextprotocol, screenshot, sharedpreferences, sqlite, windsurf

## 简介

Model Context Protocol (MCP) server for Android ADB: inspect databases, capture screenshots, manage apps, edit SharedPreferences, and control devices with AI agents in Antigravity, Claude, Cursor, and Windsurf.
