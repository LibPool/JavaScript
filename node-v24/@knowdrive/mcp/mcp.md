# @knowdrive/mcp

> 标签: claude, knowdrive, mcp, memory, model-context-protocol

## 简介

1-click MCP server for KnowDrive — run `npx -y @knowdrive/mcp` to give any MCP client (Claude Desktop, Claude Code, Cursor) memory backed by your KnowDrive KnowDB.
