# @andrewlabs/openclaw-messageguard

> 标签: message-filter, messageguard, openclaw, openclaw-plugin, secret-detection, security

## 简介

OpenClaw plugin: filters outgoing messages for API keys, credentials, PII, and other sensitive data using MessageGuard.
