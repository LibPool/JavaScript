# @kunolu/dsh-sbtd

> 标签: deepseek, dsh, dsh-plugin, sbtd, workflow

## 简介

DSH 宿主上的 SBTD workflow 适配器。当前为 T5：注册短中文 sbtd section、进程内会话状态、`sbtd_plan`、`sbtd_review`、`tools/pre-execute` / `agent/pre-step` hooks 门禁，以及从 640-skills 只读同步的 `manuals/`。
