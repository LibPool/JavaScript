# opencode-fetch-proxy

> 标签: corporate, http-proxy, opencode, opencode-plugin, proxy, vpn

## 简介

Route one OpenCode provider through an HTTP proxy — for a LAN model server reachable only via a corporate proxy — without touching the system proxy.
