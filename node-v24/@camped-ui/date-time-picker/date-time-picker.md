# @camped-ui/date-time-picker

> 标签: camped, camped-ui, components, date-time-picker, next.js

## 简介

A date-time picker component enables users to easily select both date and time through an interactive calendar and time input. It simplifies scheduling tasks by providing a consistent and user-friendly interface for entering date-time values.
