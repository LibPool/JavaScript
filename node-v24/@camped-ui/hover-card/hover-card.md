# @camped-ui/hover-card

> 标签: camped, camped-ui, components, hover-card, next.js

## 简介

Hover Card component is designed for sighted users, providing a visually appealing and interactive way to preview content available behind a link. It enhances the user experience by allowing users to hover over a link or trigger element, revealing a card
