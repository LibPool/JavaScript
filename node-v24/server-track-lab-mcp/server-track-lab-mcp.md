# server-track-lab-mcp

> 标签: ai-agents, conversions-api, mcp, meta-capi, model-context-protocol, server-side-tracking

## 简介

MCP server for server-track-lab: let AI agents send server-side conversion events (Meta CAPI live; Google validate-only preview; LinkedIn dry-run) with your own server-track-lab API key.
