# @polyfillhq/capacitor-plugin-safe-area

> 标签: capacitor, native, plugin, safe-area

## 简介

A Capacitor V3/V4 plugin to get Statusbar Height on Android and get SafeArea info on iOS. Forked to fix breaking bugs.
