# @deepblend/dsh-blender-bundle

> 标签: 3d, agent, blender, deepseek-harness, dsh-plugin, product-visualization, rendering

## 简介

Create Blender product scenes in DSH with editable recipes, model imports, previews and PNG/MP4 delivery; includes workbench and agent configuration.
