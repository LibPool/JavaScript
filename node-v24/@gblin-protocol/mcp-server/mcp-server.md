# @gblin-protocol/mcp-server

> 标签: agent-payments, agent-treasury, ai-agents, attestation, base, base-mainnet, chainlink, coinbase-agentkit, defi, eas, eliza, gblin, idle-usdc, jit-swap, market-risk, mcp, model-context-protocol, onchain-index, proof-of-diligence, risk-attestation, risk-off, risk-regime, uniswap, x402

## 简介

Market risk regime (calm/elevated/crash) and treasury tools for AI agents on Base. Free risk-regime reads, signed EIP-712 risk attestations as portable proof-of-diligence, and JIT swaps to USDC for x402 invoices.
