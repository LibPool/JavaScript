# @facet-llc/protocol

> 标签: JavaScript

## 简介

TypeScript types and reference parser for the Facet agent-commerce protocol: agents.txt v1.2, FacetPaymentRailAdapter interface, origination verifiers, and per-primitive request/response types. Zero runtime deps. Apache-2.0.
