# @camstack/addon-auth

> 标签: addon, auth, camstack, camstack-addon, magic-link, oidc, passkey, sso, webauthn

## 简介

Authentication bundle — magic-link, OIDC, and WebAuthn/passkey. Multi-entry npm package shipping 3 addons under a single bundle; each addon keeps its own id, capabilities, and runner.
