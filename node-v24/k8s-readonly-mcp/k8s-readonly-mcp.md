# k8s-readonly-mcp

> 标签: ai-agent, claude-code, devops, k8s, kubernetes, mcp, model-context-protocol, rbac, readonly, sre

## 简介

Read-only Kubernetes MCP server for AI agents (Claude Code, Cursor, Gemini CLI, Codex CLI, VS Code Copilot). It has no write tools, and Kubernetes RBAC enforces read-only access as a second wall.
