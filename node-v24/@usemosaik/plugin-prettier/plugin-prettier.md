# @usemosaik/plugin-prettier

> 标签: JavaScript

## 简介

The Prettier Plugin implementation: adds Prettier to a generated react-ts/react-js project. If ESLint was also selected (resolveInstallationOrder guarantees ESLint runs first), wires in eslint-config-prettier to avoid rule conflicts.
