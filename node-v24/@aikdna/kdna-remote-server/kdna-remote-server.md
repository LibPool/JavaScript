# @aikdna/kdna-remote-server

> 标签: judgement-asset, kdna, kdna-remote-server, projection, remote-mode, self-hosted, task-projection

## 简介

Self-hostable KDNA projection service that returns task-scoped judgment projections without sending the full .kdna payload.
