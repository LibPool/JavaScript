# @lyln/lpm2

> 标签: EPERM, daemon, named-pipe, pm2, process-manager, production, rpc.sock, supervisor, windows

## 简介

PM2 without the Windows named-pipe collision: per-instance IPC namespaces, no unhandled-EPERM crash, zero dependencies.
