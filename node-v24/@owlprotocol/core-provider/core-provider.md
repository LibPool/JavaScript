# @owlprotocol/core-provider

> 标签: react-query, solidity, trpc, web3

## 简介

Core Owl Protocol EIP1193 provider and viem wrappers for the following types of RPC calls. * Public Client * Wallet Client * ERC4337 Bundler Client * ERC4337 Paymaster Client
