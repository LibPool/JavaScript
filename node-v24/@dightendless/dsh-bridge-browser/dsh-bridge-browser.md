# @dightendless/dsh-bridge-browser

> 标签: ai-agent, browser-automation, chrome-extension, cordis, deepseek-harness, dsh, dsh-plugin, edge-extension

## 简介

Operate the Chrome or Edge tab you are already in, through the unpacked extension: hover, coordinate clicks, drag, batched actions, whole-page screenshots, file upload, image addresses and switching between connected browsers — with approval-gated actions
