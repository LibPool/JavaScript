# @xiahan/slidex

> 标签: dsl, editor, export, pptx, presentation, slides, xml

## 简介

SlideX — an XML-based slide language and WYSIWYG editor/viewer for AI-friendly deck authoring, with pixel-true export to PPTX / PNG / PDF.
