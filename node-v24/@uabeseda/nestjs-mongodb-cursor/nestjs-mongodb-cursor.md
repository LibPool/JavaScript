# @uabeseda/nestjs-mongodb-cursor

> 标签: cursor, mongodb, mongoose, nestjs, nodejs

## 简介

NestJS library that provides a decorator and an interceptor to stream MongoDB or Mongoose cursors directly to the HTTP response. This allows for efficient data transfer, especially when dealing with large datasets
