# @bimetal/picker-svelte-components

> 标签: autocomplete, combobox, components, multi-select, picker, svelte

## 简介

Default Svelte 5 picker / combobox — canonical .bm-picker* render layer over the headless controller: single/multi select, type-to-filter, chips, keyboard (owned controller OR options/config).
