# @bimetal/dom

> 标签: builder, dom, framework-agnostic, reconciliation, vanilla

## 简介

Framework-free DOM builder primitives for the BIMETAL vanilla render layers: el() (a tiny createElement wrapper with class + rich content) and syncChildren() (keyed child reconciliation that reuses node instances, preserving focus/caret). No framework — c
