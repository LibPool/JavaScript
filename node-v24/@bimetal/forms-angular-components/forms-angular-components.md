# @bimetal/forms-angular-components

> 标签: angular, components, form-builder, forms, validation

## 简介

Default Angular form builder + renderer — <bm-form-builder> edits the schema (add/reorder/edit fields, undo), <bm-form-renderer> fills it live (validation, submit) and composes <bm-picker> per select field. Thin standalone-component bindings over the cano
