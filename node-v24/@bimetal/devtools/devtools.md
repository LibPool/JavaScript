# @bimetal/devtools

> 标签: audit, debugger, devtools, diagnostics, event-sourcing, headless

## 简介

Event-Debugger primitives (v0.14). Framework-agnostic registry + diagnostics-source for auditing event-sourced systems. Zero hard dependencies on @bimetal/broker or any domain package — structural interfaces only.
