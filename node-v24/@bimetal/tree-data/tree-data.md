# @bimetal/tree-data

> 标签: cqrs, event-sourcing, headless, hierarchy, outline, tree, undo

## 简介

Tree-domain event-sourcing: Tree-as-Aggregate (a hierarchy of nodes is ONE aggregate with hard invariants — structural consistency, acyclic move/reparent, a prototype-safe node pool). Commands/events, treeAggregate, treeProjection, createTreeStore. Built
