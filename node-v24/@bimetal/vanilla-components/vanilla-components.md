# @bimetal/vanilla-components

> 标签: JavaScript

## 简介

Generic zero-framework bindings for the BIMETAL component family: one mount<Component>() per component, plain-DOM renderers driving the canonical controllers. No calendar specifics — calendar mount lives in @bimetal/calendar-vanilla-components.
