# @bimetal/toast-themes

> 标签: css, design-tokens, notification, themes, toast

## 简介

Framework-agnostic CSS theme + design tokens for the BIMETAL toast (light/dark, WCAG-AA variants). Styles the canonical .bm-toast* contract the toast-{fw}-components render.
