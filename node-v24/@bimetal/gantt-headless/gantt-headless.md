# @bimetal/gantt-headless

> 标签: controller, dependencies, framework-agnostic, gantt, headless, scheduling, undo

## 简介

Canonical, framework-agnostic gantt controller (createGanttController) on @bimetal/headless-core. Owns all timeline-interaction semantics — bar move/resize, task dialog, dependency linking (the family's first cross-entity relationship), FS-block-as-state,
