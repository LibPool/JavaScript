# @bimetal/toast-headless

> 标签: a11y, controller, feedback, framework-agnostic, headless, notification, snackbar, toast

## 简介

Canonical, framework-agnostic toast controller (createToastController) on @bimetal/headless-core. The family's first LIGHTWEIGHT / FEEDBACK component — controller-only (no store, no aggregate, no undo). Owns the presentation lifecycle: queue, per-toast li
