# @paragon-ux/codedb-core

> 标签: call-graph, cli, code-intelligence, code-search, deterministic, symbol-index, zig

## 简介

Deterministic structural code intelligence — lexical-only fork of codedb: outline, symbol, call graph, and trigram search. No embeddings, no telemetry, no cloud, no daemon.
