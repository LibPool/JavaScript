# @monkeytestai/monkeytest-core

> 标签: agent, ai-testing, anthropic, browser-automation, bug-detection, claude, e2e, exploratory-testing, gemini, groq, llm, mistral, monkeytest, ollama, openai, openrouter, playwright, qa, test-automation, typescript

## 简介

Open-source AI exploratory testing engine. Crawls a real browser with Playwright, plans flows with an LLM, executes with screenshots, and reports deduplicated bugs. Works with OpenAI, Gemini, Anthropic, Mistral, Groq, or any OpenAI-compatible endpoint.
