# @polyus-studio/vera-cmp

> 标签: ccpa, cmp, consent-mode, cookie-consent, gdpr, gpc, nextjs, nuxt, privacy, react, vanilla-cookieconsent, vue

## 简介

Centralized cookie consent management (CMP) for 30+ sites — a typed wrapper around vanilla-cookieconsent v3 with Vue/Vite, Nuxt, React and Next.js adapters, tracker loaders, Google Consent Mode and GPC.
