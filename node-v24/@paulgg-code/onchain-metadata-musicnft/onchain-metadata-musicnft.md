# @paulgg-code/onchain-metadata-musicnft

> 标签: metadata, music, nft, onchain

## 简介

NFT music metadata. Stored on-chain as Base64 encoded string. Works with OpenSea, Zora, Catalog, and all other music NFT Protocols.
