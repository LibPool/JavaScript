# opencode-smart-ui

> 标签: charts, opencode, opencode-plugin, smart-ui, tui

## 简介

ChatGPT-style smart chat UI for opencode: the model can render charts, dashboards, tables, progress, callouts, menus, quizzes and next-prompt suggestions directly in the conversation.
