# @nayaone/design-system-mcp

> 标签: ai, claude-code, cursor, design-system, icons, mcp, model-context-protocol, nayaone, tokens

## 简介

MCP server for the NayaOne Design System. Plugs into Cursor / Claude Code / VSCode / Cowork so your AI assistant writes on-system code — semantic tokens, real icon names, no hex literals.
