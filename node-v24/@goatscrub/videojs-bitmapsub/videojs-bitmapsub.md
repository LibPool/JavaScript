# @goatscrub/videojs-bitmapsub

> 标签: bitmap, pgssub, subtitle, videojs, videojs-plugin, vobsub

## 简介

A video.js plugin helps you displaying bitmap subtitle type as image, like vobsub (DVD) or pgssub (Bluray).
