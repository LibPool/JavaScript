# dsh-apk-vm

> 标签: agent, android, android-emulator, apk, deepseek-harness, dsh, dsh-plugin, rooted-android, scrcpy, ui-automation, webcodecs

## 简介

Local AOSP Android VM for DeepSeek Harness: preview rooted APKs at up to 60 fps, automate UIAutomator flows, and give each Agent an isolated VM.
