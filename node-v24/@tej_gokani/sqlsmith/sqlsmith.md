# @tej_gokani/sqlsmith

> 标签: cli, database, db, migration, migrations, node, postgres, postgresql, rls, row-level-security, schema, schema-generator, sql, sqlsmith, supabase

## 简介

SQLSmith converts JavaScript object schemas into clean, safe, Supabase-ready Postgres SQL migration files with schema diffing, CLI tools, and type overrides.
