# @react-pixel-ui/react

> 标签: clip-path, css, hooks, pixel, pixel-art, pixelated, react, retro, ui

## 简介

Wrap any element with <Pixel> and your CSS becomes pixel art. Tailwind, inline styles, CSS modules — all supported. No Canvas, SSR compatible.
