# @stabgan/openrouter-mcp-multimodal

> 标签: ai, audio, image-analysis, llm, mcp, openrouter, text-to-speech, transcription, vision

## 简介

MCP server for OpenRouter — chat with 300+ LLMs, analyze images/audio/video, generate images (dedicated API), TTS/STT, video generation (Veo 3.1 / Seedance / Wan), async completions, response caching
