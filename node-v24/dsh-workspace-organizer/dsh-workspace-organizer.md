# dsh-workspace-organizer

> 标签: archive, conversation-organizer, deepseek, deepseek-harness, dsh, dsh-plugin, organizer, session, session-archive, session-management, session-manager, session-organizer, session-tags, sessions, tags, unarchive, workspace

## 简介

DeepSeek Harness (DSH) Web session organizer: group sessions by custom tags, archive/restore in one click, browse archived sessions. 会话整理插件：标签分类、归档/恢复、已归档浏览。
