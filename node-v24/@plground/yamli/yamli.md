# @plground/yamli

> 标签: arabic, arabizi, ime, input-method, rtl, transliteration, yamli

## 简介

Modern Arabic transliteration engine — type Arabic with Latin letters. Dual Node.js + browser (CDN) library rebuilt from Yamli 5523. (npm: yamli-js — GitHub: abdou-da0wew/yamli)
