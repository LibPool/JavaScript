# @shoplyjs/create

> 标签: JavaScript

## 简介

A CLI tool for rapidly scaffolding a new Vendure server application. Heavily inspired by [create-react-app](https://github.com/facebook/create-react-app).

## 官网

- npm 页面：https://www.npmjs.com/package/@shoplyjs/create
