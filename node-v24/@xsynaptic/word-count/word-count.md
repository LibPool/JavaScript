# @xsynaptic/word-count

> 标签: cjk, i18n, multilingual, text, word-count, wordcount

## 简介

A fast, dependency-free multilingual word counter with support for CJK, Thai, Lao, Burmese, Khmer, Javanese, and Vai scripts
