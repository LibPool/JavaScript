# @backthread/extractor

> 标签: architecture, ast, code-graph, dart, elixir, flutter, kotlin, louvain, php, python, ruby, static-analysis, swift, typescript

## 简介

Deterministic, install-free structural extraction for TypeScript, Python, Ruby, Elixir, PHP, Kotlin, Dart/Flutter, and Swift codebases — AST → communities → god-nodes → framework & infra adapters, zero LLM/DB/network.
