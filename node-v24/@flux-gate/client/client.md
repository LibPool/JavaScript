# @flux-gate/client

> 标签: client, edge, rate-limiter, rate-limiting, service

## 简介

Client for the FluxGate rate-limit service: one HTTP call per decision, from any app or edge runtime. Plugs into every @flux-gate/http adapter. No runtime dependencies besides @flux-gate/core types.
