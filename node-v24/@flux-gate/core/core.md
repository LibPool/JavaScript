# @flux-gate/core

> 标签: gcra, rate-limiter, rate-limiting, sliding-window, throttle, token-bucket

## 简介

Five rate-limiting algorithms (fixed window, sliding log, sliding counter, token bucket, GCRA) with zero dependencies and a deterministic clock.
