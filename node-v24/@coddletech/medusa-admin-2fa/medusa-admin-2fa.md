# @coddletech/medusa-admin-2fa

> 标签: medusa, qrcode, speakeasy, two-factor authentication

## 简介

A Two-Factor Authentication (2FA) plugin for Medusa.js v2.8+ Admin, powered by TOTP with QR code support.
