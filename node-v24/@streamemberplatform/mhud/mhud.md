# @streamemberplatform/mhud

> 标签: ai-friendly, css, game-ui, gta5, hud, nui, obs, overlay, rdr2, stream, tiktok, ui-kit

## 简介

Themed, dependency-free HUD & UI kit for game mods and live-stream overlays (NUI, OBS, HTML5): vitals, location, economy, equipment, vehicle, kill feed, gifts, broadcast crop, 4 themes.
