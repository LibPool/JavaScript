# @loutrejs/node

> 标签: JavaScript

## 简介

Loutre ApplicationをNode.jsのHTTP serverへ接続するRuntime Adapterです。Web StandardのRequest / ResponseをLoutre HTTP Applicationへbridgeし、server lifecycleをNode.js上で管理します。
