# @switchyardhq/switchyard

> 标签: ai-agents, claude-code, cli, codex, cursor, developer-tools, git, worktree

## 简介

Manage multiple AI coding agents working on the same git repository: isolated worktrees per agent, collision detection before merge, safe cleanup.
