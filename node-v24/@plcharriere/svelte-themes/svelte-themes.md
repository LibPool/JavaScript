# @plcharriere/svelte-themes

> 标签: dark-mode, prefers-color-scheme, ssr, svelte, sveltekit, theme, themes, theming, typescript

## 简介

SSR-safe theme switching for SvelteKit 2 + Svelte 5. Plain CSS themes, cookie-persisted, prefers-color-scheme aware, with live cross-tab sync.
