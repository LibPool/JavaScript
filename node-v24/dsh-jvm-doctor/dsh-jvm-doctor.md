# dsh-jvm-doctor

> 标签: application-yml, cordis, deadlock, deepseek, deepseek-harness, dependency-conflict, deterministic, diagnostics, dsh, dsh-plugin, dsh-plugins, exception-chain, garbage-collection, gc-log, gc-pause, gradle, java, jdk, jstack, jvm, local-first, maven, no-network, offline, plugin, production-diagnostics, read-only, spring, spring-boot, sre, stack-trace, thread-dump, troubleshooting

## 简介

DSH plugin: offline JVM production-report diagnostics — thread dumps with Java-level deadlock cycles, GC-log pause percentiles, Maven/Gradle dependency conflicts, exception chains and Spring config diffs. Never touches a running process: no jcmd, no jstac
