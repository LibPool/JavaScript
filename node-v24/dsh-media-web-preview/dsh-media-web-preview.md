# dsh-media-web-preview

> 标签: audio, deepseek-harness, dsh, dsh-plugin, media, player, preview, range, streaming, video

## 简介

In-browser audio and video previews in the DSH right Sidebar, backed by an authenticated byte-range media route so a remote browser can play and seek large files without opening a native app on the Host.
