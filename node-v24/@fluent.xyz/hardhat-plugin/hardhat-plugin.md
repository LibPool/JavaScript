> 标签: compile, ethereum, fluent, hardhat, hardhat-plugin, smart-contracts, wasm, webassembly

## 简介

Hardhat toolbox for developing smart contracts in the Fluent blockchain ecosystem. Provides seamless WASM compilation and integrated testing for Rust and Solidity contracts.
