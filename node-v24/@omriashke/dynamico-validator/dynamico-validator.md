# @omriashke/dynamico-validator

> 标签: dynamico, push-gate, react-native, validator

## 简介

Server-side validator for Dynamico components. Automatically renders each pushed component with default props and book.config.json previews (with providers) in a worker thread; rejects pushes that throw or miss scope bindings.
