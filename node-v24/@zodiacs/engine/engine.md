# @zodiacs/engine

> 标签: astrology, ephemeris, natal-chart, synastry, transits, typescript, zodiac

## 简介

Browser-first astrology calculations used by Zodiacs.org: tropical charts; one calculation API with bounds and receipts in ./calc; birth-time windows in ./window; returns, relationship charts, the void-of-course Moon, patterns and dignities in ./technique
