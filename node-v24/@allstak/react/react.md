# @allstak/react

> 标签: allstak, apm, error-tracking, observability, react

## 简介

AllStak React SDK — standalone error tracking, breadcrumbs, ErrorBoundary, useAllStak hook, and withAllStakProfiler HOC. No @allstak/* runtime dependencies.
