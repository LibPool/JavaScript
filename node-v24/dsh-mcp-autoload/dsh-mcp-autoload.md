# dsh-mcp-autoload

> 标签: cordis, deepseek-harness, dsh, dsh-plugin, mcp, plugin

## 简介

Auto-discovers project-level MCP servers declared in .agents/mcp.json, mounts them per agent session, and shows a session MCP inventory panel in the Web UI.
