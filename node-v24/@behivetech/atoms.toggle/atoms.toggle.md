# @behivetech/atoms.toggle

> 标签: JavaScript

## 简介

A bare toggle/switch control (built on Radix's `Switch`) — the Radix switch button is this component's own root element. It has no built-in label/hint/error; wrap it in `FormField` for that chrome.
