# @hawkeyexl/manni

> 标签: ci, cli, frontmatter, json-schema, markdown, metadata, okf, validation

## 简介

One command line for documentation that is meant to be checked. `manni meta` validates the presence and format of document metadata (Markdown frontmatter and more) against JSON Schema, built for CI. Formerly docmeta.
