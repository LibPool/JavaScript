# @manmohan-khandelwal/swagger2ts

> 标签: api-client, cli, codegen, openapi, swagger, typescript

## 简介

Generate typed TypeScript API clients (request/response types + a typed URL map) from a Swagger/OpenAPI 3.x document. Usable as a CLI (via npx) or as a library.
