# @bettip/fair-draw

> 标签: drand, draw, giveaway, lottery, picker, provably-fair, raffle, random, team-generator, verifiable

## 简介

Verifiable random draws for giveaways, raffles, teams and number picks, bound to the drand public randomness beacon. Nobody can rig the draw, and anyone can re-check it.
