# tamilscript

> 标签: compiler, javascript, language-tools, lexer, nodejs, npm, tamil, tamil-numerals, tamilscript, transformer, transpiler

## 简介

TamilScript: a Tamil-friendly JavaScript source transformer for Node.js, with Tamil numeric literals and Tamil identifiers.
