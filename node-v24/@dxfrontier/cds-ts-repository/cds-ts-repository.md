# @dxfrontier/cds-ts-repository

> 标签: CDS-TS-Dispatcher, CDS-TS-Repository, Controller-Service-Repository, SAP CAP BaseRepository, SAP CAP Decorators, SAP CAP TypeScript

## 简介

The goal of SAP CAP CDS-QL BaseRepository is to significantly reduce the boilerplate code required to implement data access layers for persistance entities by providing out of the box actions on the database like .create(), .createMany(), .getAll(), .upda
