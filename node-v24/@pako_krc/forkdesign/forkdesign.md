# @pako_krc/forkdesign

> 标签: ai, claude, comments, design, feedback, git, iteration, local-first, playground, prototype, react, variants, vite

## 简介

Local-first AI design iteration for Vite + React — comment on a component, get source-backed variants, and keep the whole history in your repo. Every change is a git diff.
