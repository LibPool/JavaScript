# @octaviaflow/oflow-templating

> 标签: JavaScript

## 简介

Flow ↔ .oflow mapping: export a workflow to a portable .oflow (credentials split into the encrypted secrets) and import one back (ids remapped, secrets re-installed). App-agnostic.
