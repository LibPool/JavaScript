# @any-nav/core

> 标签: agent, context, markdown, navigation

## 简介

Any-Nav SDK: read-only core that scans Markdown folders into navigation, decides exposure within a context budget, renders injection fragments, and answers list/search/read. Adapters own all writes, processes, and protocols.
