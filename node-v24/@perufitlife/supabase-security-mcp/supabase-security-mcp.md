# @perufitlife/supabase-security-mcp

> 标签: audit, claude, cursor, mcp, remediation, rls, security, supabase

## 简介

MCP server for Supabase security: audit (with active anon-key probe that proves leaks live), dry-run fixes, and apply remediations with rollback. The only auditor that closes the loop in your AI agent.
