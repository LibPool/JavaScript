# @ambionframework/just-bash

> 标签: agents, ambion, filesystem, git, just-bash, just-git, sandbox, workspace

## 简介

The just-bash backends for an Ambion workspace: a virtual Unix filesystem and shell, in memory or over a directory, and a git backend in the process.
