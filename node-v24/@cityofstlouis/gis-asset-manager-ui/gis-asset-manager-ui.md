# @cityofstlouis/gis-asset-manager-ui

> 标签: ArcGIS, ArcGIS Maps SDK for JavaScript, City of St. Louis, City of St. Louis Web Team, GIS, JavaScript, Missouri, St. Louis, asset manager, assets, city, map, web components

## 简介

GIS Asset Manager UI utilizes the ArcGIS Maps SDK for JavaScript to create an interactive map for asset selection and/or asset creation, along with a user interface for managing assets. It is intended for use within a parent application.
