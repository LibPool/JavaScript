# @roasted/cli

> 标签: apply-kit, ats, cli, cover-letter, cv, job-search, mcp, resume, roasted, roasted.cv

## 简介

Terminal CLI for the roasted.cv job-hunt workflow: tailored apply kits (CV + cover letter), one-page PDF render, application tracker. Pairs with the hosted MCP server at mcp.roasted.cv.
