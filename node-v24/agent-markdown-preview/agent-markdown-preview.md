# agent-markdown-preview

> 标签: claude-code, cli, codex, coding-agent, latex, markdown, mermaid, opencode, pandoc, pi, preview

## 简介

Browser preview of coding-agent responses (Claude Code, Codex, Pi, OpenCode) and local Markdown, LaTeX, code and diff files, with math, syntax highlighting and Mermaid.
