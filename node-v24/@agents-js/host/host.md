# @agents-js/host

> 标签: a2a, ag-ui, agent, gateway, host, websocket

## 简介

Host orchestration for the agents-js A2A gateway: ACP-backed A2A executor, AG-UI fetch handler, WebSocket bridge, and surface broadcaster.
