# @godai_dev/llm

> 标签: JavaScript

## 简介

GDI 共通 LLM 基盤（gdi-llm-proxy）クライアント SDK。gdi-auth auth_token を Bearer で転送し、Gemini 応答（stream/非stream）を数行で呼び出す
