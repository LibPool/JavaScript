# zig-wasm-git

> 标签: blob-store, cloudflare-workers, edge, git, kv, serverless, smart-http, wasm, webassembly, zig

## 简介

git remote as a versioned blob store — no fs, no git CLI. Pure-Zig git protocol engine in a ~60KB wasm, with a small async JS API. Runs in Node, browsers and Cloudflare Workers.
