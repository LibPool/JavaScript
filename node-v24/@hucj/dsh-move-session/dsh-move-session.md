# @hucj/dsh-move-session

> 标签: deepseek-harness, dsh, move-session, plugin, session-migration, workspace

## 简介

Cross-workspace session migration for the dsh web GUI: a Move Session header action plus dialog (target workspace picker, keep-or-archive the original), idle-session only, full context preserved. Hot-pluggable — mounted via ~/.dsh/cordis.patch.yml + a pro
