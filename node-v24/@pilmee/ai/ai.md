# @pilmee/ai

> 标签: built-in-ai, chrome-ai, gemini-nano, on-device-ai, prompt-api, typescript, web-context, webgpu, webllm, webmcp

## 简介

A friendly TypeScript orchestrator for Chrome's built-in AI APIs (Prompt API, Summarizer, Writer, Rewriter, Translator, Language Detector, Proofreader) with site-scoped context, WebMCP tool support, and an optional WebGPU fallback for browsers without Gem
