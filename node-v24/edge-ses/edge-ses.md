# edge-ses

> 标签: amazon-ses, bun, cloudflare-workers, deno, edge, email, ses, sigv4, workers

## 简介

Send email with Amazon SES from Cloudflare Workers and other edge runtimes. Zero dependencies, Web Crypto SigV4, simple/raw/template email.
