# @c15t/dev-tools

> 标签: c15t, cmp, consent, cookie-consent, debugging, developer-tools, devtools, gdpr, privacy

## 简介

Developer tools for debugging cookie consent in c15t apps. Inspect consent state, resolved policy, location, IAB TCF state and kernel events.
