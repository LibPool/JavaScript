# @chainstarter/solidity-verify

> 标签: JavaScript

## 简介

Compile contract and generate metadata to verify contracts in scan. ### Supported scan: * etherscan * bscscan * ...scan ## Install ``` npm install -g @chainstarter/solidity-verify ```
