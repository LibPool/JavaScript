# @crown-dev-studios/simple-auth-server-ts

> 标签: JavaScript

## 简介

Framework-agnostic server primitives for auth flows in TypeScript. This package gives you Redis-backed OTP and session services plus a Google OAuth auth-code exchange helper, without forcing a web framework or database model.
