# @aramir/react-native-barcode

> 标签: barcode, generator, react-native

## 简介

Uses [jsbarcode](https://github.com/lindell/JsBarcode) to generate barcode binary data with native svg rendering via [react-native-svg](https://github.com/software-mansion/react-native-svg).
