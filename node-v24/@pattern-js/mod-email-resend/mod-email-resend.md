# @pattern-js/mod-email-resend

> 标签: driver, email, mod, pattern, resend

## 简介

Resend driver for @pattern-js/mod-email — dependency-free (the Resend API is one fetch). Install it, create an account in admin → System → Email, and email.send delivers through Resend.
