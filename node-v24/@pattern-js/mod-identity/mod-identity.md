# @pattern-js/mod-identity

> 标签: auth, identity, mod, pattern, sessions, users

## 简介

Users, sessions, roles and pluggable login methods for Pattern — the optional identity brick. Opaque revocable cookie sessions (CAS-backed, sqlite or in-memory), a single-use token kernel (login/invite/bootstrap), a login page, and admin screens.
