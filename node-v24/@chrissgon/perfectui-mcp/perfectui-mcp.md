# @chrissgon/perfectui-mcp

> 标签: agents, css, mcp, mcp-server, model-context-protocol, perfectui

## 简介

A read-only MCP server that answers questions about Perfect UI 1.0.0 from its own documentation and stylesheet, as a stdio bin and as a library for other transports.
