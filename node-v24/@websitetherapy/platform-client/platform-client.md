# @websitetherapy/platform-client

> 标签: next, visitor-agent, websitetherapy, widget

## 简介

Thin in-build surface for WebsiteTherapy client sites: the visitor-agent widget mount + a next.config helper. Everything else (the agent runtime, plugins) is delivered as external platform services, so the owner build stays freeform with a near-zero platf
