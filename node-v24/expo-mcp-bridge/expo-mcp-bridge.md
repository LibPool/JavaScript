# expo-mcp-bridge

> 标签: agent, ai, ai-agent, android, antigravity, automation, claude, claude-code, cursor, e2e-testing, expo, expo-go, ios, mcp, mcp-server, mobile-testing, model-context-protocol, react-native, react-native-testing, testing

## 简介

Let AI agents (Claude Code, Cursor, Antigravity) see and drive your Expo / React Native app on a real phone: snapshot, tap, type, scroll, screenshots, logs and network over MCP.
