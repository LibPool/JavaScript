# @clickstreamhq/react

> 标签: analytics, clickstream, hooks, react, signals

## 简介

React hooks + provider for ClickStream. Wraps @clickstreamhq/signals (visitor context) and @clickstreamhq/sdk (event tracking) behind idiomatic React APIs.

## 官网

- 官网：https://docs.clickstream.com/signals
