# @ts-core/crypto-gost

> 标签: cryptography, digital-signature, encryption, gost, gost-r-34.10, gost-r-34.11, russian-crypto, ts-core, typescript

## 简介

TypeScript library for Russian GOST cryptographic standards (GOST R 34.10, GOST R 34.11) - key generation, signing, verification, encryption and decryption
