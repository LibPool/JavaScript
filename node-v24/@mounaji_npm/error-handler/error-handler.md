# @mounaji_npm/error-handler

> 标签: error-handling, errors, events, express, logging, mounaji, nextjs, structured-logs

## 简介

Robust, framework-agnostic error handling — typed error taxonomy, structured logging, secret redaction, and event shooting. Adapters for Express, Next.js route handlers, and Node process hooks.
