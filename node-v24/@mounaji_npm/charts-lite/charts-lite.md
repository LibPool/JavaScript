# @mounaji_npm/charts-lite

> 标签: charts, dashboard, mounaji, react, saas, svg

## 简介

Zero-dependency SVG charts (Bar, Line, Donut, StatCard) for SaaS dashboards. Fully token-driven (--mn-*) so charts inherit the host app theme, with accessible SVG labels.
