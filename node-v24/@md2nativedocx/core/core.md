# @md2nativedocx/core

> 标签: JavaScript

## 简介

Mermaid engine of md2nativedocx (Markdown to native Word, Mermaid diagrams included). Pure TypeScript: Mermaid text (all 29 diagram types) -> AST -> layout -> native, editable OOXML/DrawingML shapes for Word. No Pandoc, VS Code, or Office.js knowledge.
