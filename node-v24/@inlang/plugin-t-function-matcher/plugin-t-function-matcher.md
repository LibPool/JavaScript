# @inlang/plugin-t-function-matcher

> 标签: JavaScript

## 简介

This plugin enables [Sherlock](https://inlang.com/m/r7kp499g/app-inlang-ideExtension) (VS Code extension) to recognize `t("key")` function calls used by most i18n libraries.
