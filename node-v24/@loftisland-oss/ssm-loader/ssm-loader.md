# @loftisland-oss/ssm-loader

> 标签: aws, config, dotenv, env, parameter-store, ssm, systems-manager

## 简介

Load AWS Systems Manager Parameter Store values into process.env — by path prefix or by explicit parameter names. Works from both JS and TS, CJS and ESM.
