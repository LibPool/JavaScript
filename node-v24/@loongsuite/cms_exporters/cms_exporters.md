# @loongsuite/cms_exporters

> 标签: JavaScript

## 简介

CMS Exporters 提供多种数据导出器，用于将追踪数据发送到不同的后端系统。支持控制台输出、OTLP 协议导出等多种方式，满足开发调试和生产环境的不同需求。
