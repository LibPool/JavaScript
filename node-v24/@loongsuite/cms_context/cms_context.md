# @loongsuite/cms_context

> 标签: JavaScript

## 简介

CMS Context 提供基于 Node.js AsyncLocalStorage 和 async_hooks 的上下文管理器实现，用于在异步调用链中传递和保持上下文信息。这是实现分布式追踪上下文传播的关键组件。
