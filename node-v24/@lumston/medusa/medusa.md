# @lumston/medusa

> 标签: JavaScript

## 简介

This Angular Schematic Library, named **Medusa**, provides a set of powerful schematics to streamline and automate common tasks when developing Angular applications. With Medusa, you can quickly generate modules and submodules for template **Medusa**
