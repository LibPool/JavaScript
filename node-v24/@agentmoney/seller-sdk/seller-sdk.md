# @agentmoney/seller-sdk

> 标签: agent-payments, ai-agents, hono, http-402, paywall, x402

## 简介

Seller SDK for the money agent-payment network: a Hono paywall middleware plus a signed client for challenges, receipt redemption, and refunds.
