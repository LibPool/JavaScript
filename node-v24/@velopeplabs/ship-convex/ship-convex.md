# @velopeplabs/ship-convex

> 标签: batches, component, convex, fedex, labels, shipping, tracking, ups, usps

## 简介

Convex component for VeloShip: quote, buy, batch and track FedEx, USPS and UPS labels from Convex functions, with reactive mirror tables and a signed webhook receiver.
