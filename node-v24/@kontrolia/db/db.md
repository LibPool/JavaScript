# @kontrolia/db

> 标签: auth, kontrolia, migrations, postgres, rbac, supabase

## 简介

KontrolIA Auth database layer: SQL migrations for the `kontrolia` schema (organizations, RBAC, Custom Access Token Hook) and a connection-string-agnostic migration runner.
