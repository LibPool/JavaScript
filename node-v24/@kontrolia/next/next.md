# @kontrolia/next

> 标签: auth, authentication, authorization, kontrolia, middleware, next.js, nextjs, sdk

## 简介

Next.js integration for KontrolIA Auth: reusable route-protection middleware with automatic session refresh, and verifyRequest() for API routes acting as a resource server.
