# @standardserver/node

> 标签: adapter, http, http2, node, nodejs, request, response, server, sse, standardserver, streaming, typescript

## 简介

Node.js HTTP and HTTP/2 adapter for Standard Server: transport-agnostic requests, responses, and streaming on top of IncomingMessage and ServerResponse
