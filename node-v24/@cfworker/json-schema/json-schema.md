# @cfworker/json-schema

> 标签: cloudflare, json, json-schema, jsonschema, schema, service-worker, worker, workers

## 简介

A JSON schema validator that will run on Cloudflare workers. Supports drafts 4, 7, 2019-09, and 2020-12.
