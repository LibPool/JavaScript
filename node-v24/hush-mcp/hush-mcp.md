# hush-mcp

> 标签: ai-agents, claude, mcp, model-context-protocol, payments, privacy, solana, x402

## 简介

MCP server for HUSH: let Claude, Cursor or any MCP agent buy from the HUSH Agent Shop over private x402 on Solana, inside a leashed agent wallet.
