# @doichain/bcur-code-scanner-svelte

> 标签: JavaScript

## 简介

QR Code scanner in a Svelte Component with [BC-UR Encoding](https://github.com/ngraveio/bc-ur) support. It is also known as "animated" QR-Codes.
