# hermes-ui-plus-bridge

> 标签: bridge, hermes, hermes-agent, qr-pairing, setup, tailscale

## 简介

Optional UI Bridge for the Hermes Interactive UI+ app (unofficial community client for Hermes Agent): presentation router, uploads, voice, QR pairing and SSE pass-through in front of the Hermes Agent API.
