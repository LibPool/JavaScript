# @motong/dsh-voice

> 标签: deepseek-harness, dsh, dsh-plugin, edge-tts, speech-to-text, text-to-speech, voice, 快捷键, 朗读, 语音输入

## 简介

给 DeepSeek Harness（DSH / DeepSeek Hermes）加语音能力的社区插件：输入框语音输入（可配快捷键）+ 回答朗读（微软 Edge 神经网络音色，可换音色、可试听），无需 API Key。
