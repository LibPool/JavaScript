# @codebygarv/express-lens

> 标签: alerts, apm, curl-generator, dashboard, express, express-logging, express-middleware, grafana, har-export, http-debugger, http-inspector, logger, logging, memory-monitoring, metrics, monitor, monitoring, morgan, morgan-alternative, observability, p95, p99, percentile-latency, performance, pino-alternative, prometheus, prometheus-exporter, realtime-analytics, request-replay, route-metrics, slow-requests, threshold-alerts

## 简介

Zero-dependency HTTP monitoring, APM metrics, percentile latencies (p50/p90/p95/p99), threshold alert callbacks, Prometheus format exporter, slow request profiler, and real-time embedded web dashboard for Express.js.
