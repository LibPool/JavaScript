# @vrwarp/brother-ql-webusb

> 标签: P-touch, QL-800, QL-820NWB, brother, brother-ql, label-printer, raster, thermal-printer, webusb

## 简介

Print to Brother QL and P-touch label printers directly from the browser via WebUSB. TypeScript port of the brother_ql raster protocol.
