# open-sso-node

> 标签: JavaScript

## 简介

Generic OAuth-style "Login via SSO" client for Node apps: builds the login redirect URL and handles the callback token exchange against any provider that speaks this simple protocol (GET /login?callback=...&client_id=... followed by a POST /oauth/token ex
