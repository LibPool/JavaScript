# @reventlessdev/trait-notification

> 标签: JavaScript

## 简介

Notification domain trait: rules, host contract, conformance suite and emitter for a per-recipient contact directory, a kind x channel subscription matrix, and the decision to send, suppress or record a message as undeliverable
