# pi-nano-gpt-provider

> 标签: nano-gpt, pi, pi-coding-agent, pi-extension, pi-package, provider

## 简介

nanoGPT custom provider extension for the Pi coding agent — lazy discovery of the detailed model catalog (context windows, vision/reasoning, at-cost pricing), cached offline, no startup blocking.
