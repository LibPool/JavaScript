# @chronolanejs/react

> 标签: calendar, date-fns, event-calendar, react, react-calendar, resource-calendar, scheduler, time-grid, timezone, typescript

## 简介

An open-source React and TypeScript calendar and scheduler with accessible views, resources, event interactions, and timezone support.
