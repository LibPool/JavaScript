# sub2api-mcp

> 标签: admin, agent, ai-gateway, claude, llm-gateway, mcp, model-context-protocol, openai-compatible, sub2api

## 简介

MCP server for Sub2API — manage users, balances, upstream accounts, groups, API keys, usage and account probing. Works with any MCP-capable agent (DSH, Claude Desktop, Claude Code, Cursor, ...).
