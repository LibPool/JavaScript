# zusantara

> 标签: ai, claude, drizzle, file-based-routing, framework, indonesia, typescript, web

## 简介

Framework web TypeScript AI-driven asal Nusantara: routing berbasis file, auth, database, dan AI yang membangun aplikasi dari bahasa sehari-hari.
