# @stylewx/validator

> 标签: html, lint, validator, wechat, wechat-article

## 简介

stylewx validator: WeChat compatibility checker (CSS whitelist, HTML structure, content limits). Outputs a structured report. Isomorphic (no DOM / no Node-only APIs).
