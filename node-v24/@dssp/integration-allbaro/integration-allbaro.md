# @dssp/integration-allbaro

> 标签: JavaScript

## 简介

올바로(Allbaro) 폐기물적법처리시스템 연계용 Things-Factory 통합 태스크. headless-connector 위에서 올바로 사이트에 로그인하여 건설폐기물 발생량 등을 조회한다.
