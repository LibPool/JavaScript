# @firemedia/skyfire-core

> 标签: ac-3, dvb, mpeg-ts, player, wasm, webcodecs

## 简介

In-browser DVB player bridge: MPEG-TS demux + WASM AC-3/E-AC-3 decode + audio-master A/V sync + DVB-subtitle compositing. Host wires WebCodecs/WebAudio.
