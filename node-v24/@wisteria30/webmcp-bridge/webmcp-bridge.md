# @wisteria30/webmcp-bridge

> 标签: agent, cdp, chrome, claude-code, mcp, model-context-protocol, modelcontext, webmcp

## 简介

Expose WebMCP (document.modelContext) tools from a live Chrome page as a stdio MCP server for CLI agents like Claude Code.
