# @archestack/ship-check

> 标签: agents-md, bolt, cli, cursor, firebase, lovable, nextjs, rls, scanner, secrets, security, supabase, v0, vibe-coding

## 简介

Find ship blockers in vibe-coded apps before launch: committed secrets, Supabase RLS gaps, open Firebase rules, API routes with no auth check. Runs offline.
