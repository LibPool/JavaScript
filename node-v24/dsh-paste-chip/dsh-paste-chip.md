# dsh-paste-chip

> 标签: clipboard, composer, deepseek-harness, dsh, dsh-plugin, paste, ux

## 简介

DSH 插件：长文本粘贴自动折叠成可展开的胶囊，悬停看正文与上下文，发送时按原位展开；也接管其他插件写入的长文本。
