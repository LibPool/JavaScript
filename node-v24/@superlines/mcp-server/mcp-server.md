# @superlines/mcp-server

> 标签: ai-search, ai-visibility, analytics, claude, cursor, llm, mcp, model-context-protocol, seo, superlines

## 简介

Model Context Protocol (MCP) server for Superlines AI visibility analytics. Connect Claude Desktop, Cursor, or any MCP-compatible client to your Superlines data.
