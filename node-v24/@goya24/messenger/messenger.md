# @goya24/messenger

> 标签: ai-agent, chat-widget, customer-support, goya24, live-chat, messenger, persian, rtl

## 简介

Load and control the goya24 support messenger from any JavaScript page: open it, identify the signed-in customer, listen for unread replies.
