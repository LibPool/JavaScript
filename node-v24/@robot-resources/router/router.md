# @robot-resources/router

> 标签: ai, anthropic, cost-optimization, llm, model-selection, openclaw, plugin, robot-resources, router

## 简介

Robot Resources Router — in-process LLM routing for OpenClaw. Smart-selects the cheapest Anthropic model capable of each prompt. No daemon, no Python, runs inside the OC plugin process.
