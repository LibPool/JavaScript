# @bondedhq/sdk

> 标签: agentkit, ai-agents, bonded, elizaos, langchain, langgraph, mandate-vault, mcp, solana-agent-kit, vercel-ai-sdk, viem

## 简介

Trade through a Bonded Mandate Vault and get rated by the Bonded Arena from any TypeScript agent: a typed vault client with dry runs, Sentinel checks and a mandate builder; the Arena episode's tools for LangChain, the Vercel AI SDK, ElizaOS and Coinbase A
