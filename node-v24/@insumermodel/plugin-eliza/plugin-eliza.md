# @insumermodel/plugin-eliza

> 标签: ai-agent, attestation, blockchain, condition-based-access, eliza, elizaos, insumer, plugin, trust, verification, wallet, web3

## 简介

ElizaOS plugin for InsumerAPI: condition-based access for autonomous agents. 10 actions: buy API key, create merchant, configure conditions, add credits, verify wallets, trust profiles (up to 50 checks across 28 chains incl. Solana, XRPL, Bitcoin, Tron, S
