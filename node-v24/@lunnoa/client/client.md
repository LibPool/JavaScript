# @lunnoa/client

> 标签: agents, ai-agents, api-client, automation, lunnoa, lunnoa-automate, lunnoa-client, openapi, sdk, sse, streaming, typescript, workflow

## 简介

TypeScript SDK for building applications on top of Lunnoa Automate — typed client for the Public API (agents, workflows, executions, entities, knowledge, queues), SSE agent chat streaming, and deployment-specific codegen
