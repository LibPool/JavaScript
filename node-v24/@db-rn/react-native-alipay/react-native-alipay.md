# @db-rn/react-native-alipay

> 标签: alipay, authorization, native-module, payment, react-native, turbomodule, 支付, 支付宝

## 简介

React Native 支付宝 SDK 原生模块，支持支付、授权登录，兼容新架构 (TurboModule) 和旧架构 (Bridge)
