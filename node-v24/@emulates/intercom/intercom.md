# @emulates/intercom

> 标签: emulates, intercom, messaging, service, webhooks

## 简介

Stateful emulator of the Intercom REST API 2.11: contacts (search, create with 409 on duplicates, update, get), conversations (create with Idempotency-Key, reply as JSON or multipart, close/open, get, cursor search), admins, and X-Hub-Signature-signed adm
