# @seyond-perception/pcv-replay

> 标签: JavaScript

## 简介

`@seyond-perception/pcv-replay` 是基于 Three.js 的 PS32 2.0 点云回播组件。组件负责创建 Three.js 场景、连接点云 WebSocket 和控制 WebSocket、解析动态点云与 box 数据，并提供播放、暂停、上一帧、下一帧、跳转和雷达切换能力。
