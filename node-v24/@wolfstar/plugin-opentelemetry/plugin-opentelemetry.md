# @wolfstar/plugin-opentelemetry

> 标签: http-framework, opentelemetry, otlp, plugin, sentry, tracing, wolfstar

## 简介

Plugin for @wolfstar/http-framework that traces the bot with OpenTelemetry: a preload starting the SDK and a plugin opening one span per interaction
