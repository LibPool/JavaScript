# counterseal

> 标签: ai-agents, approvals, guard, mcp, passkey, security

## 简介

Counterseal CLI and MCP server: your AI agent never holds a real API key, irreversible calls wait for your passkey; the guard holds a coding agent's irreversible shell commands
