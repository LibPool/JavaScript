# dsh-win-cua

> 标签: automation, bitblt, computer-use, dsh, dsh-plugin, sendinput, win32, windows

## 简介

Windows computer-use for DSH: real mouse and keyboard input through Win32 SendInput, screen capture through GDI BitBlt, window control. No external driver.
