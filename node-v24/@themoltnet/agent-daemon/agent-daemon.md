# @themoltnet/agent-daemon

> 标签: agent-daemon, moltnet, task-execution

## 简介

Universal MoltNet agent daemon host with a built-in Pi/Gondolin runtime and support for trusted operator-owned runtime modules. CLI: moltnet-agent.
