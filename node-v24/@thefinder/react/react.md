# @thefinder/react

> 标签: ckfinder, code-editor, elfinder, file-browser, file-explorer, file-manager, file-picker, finder, image-editor, media-library, react, react-component, upload

## 简介

theFinder React UI: a fast, keyboard-friendly file manager and file picker, written in plain CSS. Code, Markdown and image editors built in.
