# @coreexl/mentor

> 标签: ai, chat, livekit, mentor, react, typescript, ui-component, voice

## 简介

React UI for real-time AI mentors — chat, voice, and avatar video — powered by LiveKit Agents. Includes a typed client + hook for managing avatars.
