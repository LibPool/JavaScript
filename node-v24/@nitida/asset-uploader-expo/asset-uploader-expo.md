# @nitida/asset-uploader-expo

> 标签: background, expo, nitida, react-native, upload, urlsession, workmanager

## 简介

nitida native upload primitives (iOS URLSession + Android WorkManager). The JS API mirrors @nitida/asset-uploader-web's UploadTask, so call sites are identical across web and mobile.
