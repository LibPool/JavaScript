# @jeyabbalas/quac

> 标签: cli, csv, data-cleaning, data-quality, data-validation, duckdb, excel, json-schema, parquet, qc

## 简介

Data quality control for tabular data — validate a dataset against a JSON Schema and QC rules, and get a styled five-sheet Excel report. Runs entirely in the browser, or headless on Node.
