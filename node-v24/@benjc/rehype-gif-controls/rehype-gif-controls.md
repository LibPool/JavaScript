# @benjc/rehype-gif-controls

> 标签: bem, canvas, controls, gif, html, interactive, markdown, mdx, plugin, rehype, responsive, self-contained, web-component

## 简介

A rehype plugin that automatically adds interactive controls to GIF images with responsive canvas rendering, auto-play limits, and click-to-replay functionality
