# @nlpjs-neo/request

> 标签: fetch, file system, http, http client, nlp, nlp.js, nlpjs-neo, nlu

## 简介

HTTP client for NLP.js Neo, plus a file system plugin that loads corpora, configuration and models from a path or a URL
