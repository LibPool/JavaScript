# @nlpjs-neo/xtables

> 标签: excel, nlp, nlp.js, nlpjs-neo, nlu, spreadsheet, tables, xlsx

## 简介

Reads the named tables out of an Excel sheet and returns each one as a list of objects keyed by column name
