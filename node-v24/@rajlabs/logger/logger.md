# @rajlabs/logger

> 标签: async-local-storage, child-logger, cli, console, express, json, log, logger, logging, middleware, namespace, pretty, redaction, request-context, structured-logging, terminal, transports

## 简介

A developer-first Node.js logger with beautiful local output, structured JSON for production, automatic AsyncLocalStorage request context, safe redaction, and extensible transports — dependency-free at the core.
