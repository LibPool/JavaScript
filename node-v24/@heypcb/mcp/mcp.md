# @heypcb/mcp

> 标签: claude, codex, cursor, heypcb, kicad, mcp, model-context-protocol, pcb

## 简介

HeyPCB for AI agents: a local MCP server (stdio) that proxies to HeyPCB's remote MCP server and adds local KiCad upload and export-to-disk tools.
