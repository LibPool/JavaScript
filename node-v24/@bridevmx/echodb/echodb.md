# @bridevmx/echodb

> 标签: append-only, cms, document-database, echo-entries, echodb, headless-cms, json-database, mataroa, nosql, ram-first, supabase, wal, zero-dependency

## 简介

RAM-first document database backed by Mataroa and Echo Entries with PocketBase parity. Zero-dependency, append-only, atomic transactions, auto-compaction.
