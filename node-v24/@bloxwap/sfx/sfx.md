# @bloxwap/sfx

> 标签: click, hover, interaction-feedback, interface-sounds, sfx, sound, sound-effects, synthesis, ui-sounds, web-audio

## 简介

Interface sound effects for the web, synthesized live with Web Audio. No audio files, zero runtime dependencies.
