# @superdata/micro-index-tools

> 标签: JavaScript

## 简介

首页工厂化组件库<br /> 用于首页展示<br /> 提供页头通知栏，快捷入口，我的关注，常用下载，外部链接，工作流指令/通知/线索相关，布控告警/预警订阅，日历日程，系统反馈，订阅推送，我的待办，重要警情等板块<br /> 组件支持布局自适应<br /> 该服务仅支持UI布局，不支持外部接口数据<br />
