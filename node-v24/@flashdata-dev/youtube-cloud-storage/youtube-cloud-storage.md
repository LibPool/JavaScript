# @flashdata-dev/youtube-cloud-storage

> 标签: cli, flashdata, mcp, model-context-protocol, youtube-download, youtube-to-s3

## 简介

Deliver YouTube video, audio or clips to your own S3 or other supported cloud storage. Track asynchronous delivery and its output manifest. CLI and MCP via the paid FlashData API.
