# @mambalabsdev/mcp-open-tender-rfp-finder

> 标签: apify, clay, contracts-finder, government-contracts, lead-generation, mcp, model-context-protocol, public-procurement, rfp, ted, tenders

## 简介

MCP server for Open Tender and RFP Finder. Find open public tenders and RFPs by keyword, CPV code, and country from UK Contracts Finder, UK Find a Tender, EU TED, and CanadaBuys: one row per notice with buyer, deadline, value, codes, and link. Runs on Api
