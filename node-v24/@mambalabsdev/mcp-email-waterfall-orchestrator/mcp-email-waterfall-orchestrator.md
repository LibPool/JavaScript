# @mambalabsdev/mcp-email-waterfall-orchestrator

> 标签: apify, byok, clay, email-finder, email-verification, enrichment, lead-generation, mcp, model-context-protocol, waterfall

## 简介

MCP server for the Mamba Labs Work Email Waterfall actor on Apify. Give it contacts and your own provider API keys and it finds a work email for each, verifies it, and returns real per-provider spend attribution as flat Clay-ready JSON.
