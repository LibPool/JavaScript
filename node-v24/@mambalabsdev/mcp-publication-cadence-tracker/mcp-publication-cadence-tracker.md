# @mambalabsdev/mcp-publication-cadence-tracker

> 标签: apify, blog, clay, competitive-intelligence, content-cadence, content-marketing, editorial, mcp, model-context-protocol, publishing

## 简介

MCP server for the Mamba Labs Publication Cadence Tracker actor on Apify. Give it a company domain and it returns how much long-form work that company publishes per month and whether the rate is rising or falling, as flat Clay-ready JSON.
