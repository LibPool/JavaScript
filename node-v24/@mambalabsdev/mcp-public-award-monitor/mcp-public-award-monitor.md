# @mambalabsdev/mcp-public-award-monitor

> 标签: apify, award-signals, clay, govcon, mcp, model-context-protocol

## 简介

MCP server for the Mamba Labs Government Contract Award Monitor actor on Apify. Pick a public award register and a time window, get back the companies that won public work in it.
