# @mambalabsdev/mcp-creator-change-monitor

> 标签: apify, change-detection, clay, influencer-marketing, mcp, model-context-protocol, monitoring

## 简介

MCP server for the Mamba Labs Influencer Change Monitor actor on Apify. A named list of creator handles in, one row per change since the previous run out.
