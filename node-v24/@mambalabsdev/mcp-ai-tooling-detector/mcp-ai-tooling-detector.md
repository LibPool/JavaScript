# @mambalabsdev/mcp-ai-tooling-detector

> 标签: ai-adoption, ai-detection, ai-maturity, apify, chat-widget, clay, llms-txt, mcp, model-context-protocol, tech-stack

## 简介

MCP server for the Mamba Labs AI Tooling Detector actor on Apify. Give it a company domain and it returns whether the company only talks about AI, actually deploys AI tooling on its site, or charges for AI, with the evidence, as Clay-ready JSON.
