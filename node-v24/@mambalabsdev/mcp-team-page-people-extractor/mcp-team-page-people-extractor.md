# @mambalabsdev/mcp-team-page-people-extractor

> 标签: apify, clay, contact-discovery, mcp, model-context-protocol, team-page

## 简介

MCP server for the Mamba Labs Team Page People Extractor actor on Apify. Returns the people a company publishes on its own team, leadership or about page, with names, titles and the source page.
