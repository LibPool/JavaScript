# @happyseeds/devtools

> 标签: devtools, inspector, preview, vite, vite-plugin

## 简介

Preview-environment devtools for Vite apps: a zero-dependency browser runtime that reports errors, routes and element picks over postMessage, plus the Vite plugin and React overlay that make element picking work
