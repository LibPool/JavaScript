# @yunuseon/kayra

> 标签: ansible, docker-compose, hetzner, opentofu, paas, platform, self-hosted, traefik

## 简介

A self-hosted app platform and the CLI that runs it: Traefik, Authelia, a registry, rootless BuildKit and a small deployer per server, set up with OpenTofu and Ansible.
