# @tracestrack/node-mapnik

> 标签: canvas, carto, graphics, map, mapnik, tile

## 简介

Node.js bindings for Mapnik (maintained by Tracestrack) - prebuilt, self-contained linux-x64 build including a fix for mapnik/mapnik#4580 (default marker SVG dimension inference)

## 官网

- 官网：http://mapnik.org
- 源码仓库：git://github.com/tracestrack/node-mapnik.git
- npm 页面：https://www.npmjs.com/package/@tracestrack/node-mapnik
