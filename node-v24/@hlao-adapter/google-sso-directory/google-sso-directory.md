# @hlao-adapter/google-sso-directory

> 标签: JavaScript

## 简介

Google Workspace Directory API lookup via service account with domain-wide delegation. Reference implementation of an HLAO verifyActor source for deployments that verify actors by checking membership in a Workspace directory.
