# @ctrlback/crypta

> 标签: aead, aes-256-gcm, blind-index, crypta, crypto, encryption, encryption-at-rest, esm, field-encryption, key-rotation, keyring, typescript

## 简介

Field-level encryption at rest for structured data: a self-describing AEAD envelope, a versioned keyring, a keyed blind index, and a typed per-field seal/open factory. Zero runtime dependencies.
