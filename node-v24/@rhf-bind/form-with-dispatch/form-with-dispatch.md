# @rhf-bind/form-with-dispatch

> 标签: form, hooks, react, react-hook-form

## 简介

This library provides a set of utilities, types, and components to simplify form handling in React applications, extending the react-hook-form library with custom dispatching mechanisms and additional contextual support.
