# @syntronic/ngx-highlight

> 标签: angular, css-highlight-api, directive, highlight, search

## 简介

Angular directives for highlighting search matches using the native CSS Custom Highlight API — no DOM mutation, works across nested text nodes, supports multiple independent named searches within one group.
