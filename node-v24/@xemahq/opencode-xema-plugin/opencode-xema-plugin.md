# @xemahq/opencode-xema-plugin

> 标签: JavaScript

## 简介

Opencode plugin providing the Xema dynamic system-prompt overlay hook, the per-turn session.idle auto-commit, and the sub-agent fan-out ceiling. Contributes no tools.
