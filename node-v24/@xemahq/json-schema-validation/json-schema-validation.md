# @xemahq/json-schema-validation

> 标签: JavaScript

## 简介

Layer-1 JSON Schema (draft 2020-12) validation on Ajv: one configured validator with two strictness modes (annotated for author schemas carrying x-* / ui:* annotations, strict for platform-declared schemas), a bounded compiled-schema cache that never leak
