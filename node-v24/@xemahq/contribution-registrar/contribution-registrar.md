# @xemahq/contribution-registrar

> 标签: biome-host, contribution, nestjs, sync, xema, xema-platform

## 简介

Pusher-side SDK for Xema OS contribution sync. biome-host uses ContributionRegistrarService to push a biome's resolved contributions to each owning registry's PUT /contributions/sync at lifecycle time, ordered by the kind routing table, authenticated with
