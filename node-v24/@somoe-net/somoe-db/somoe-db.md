# @somoe-net/somoe-db

> 标签: embedded, embedded-database, embedded-db, file-based, jsonl, local-database, node:sqlite, object-storage, single-file, somoe, somoe-db, sqlite, typescript

## 简介

单文件 JSONL + SQLite 混合嵌入式数据库（使用 Node.js node:sqlite 原生模块）。零依赖、可嵌入式本地数据库。
