# @yimeng.ch/verdaccio-minio

> 标签: minio, s3, storage, verdaccio, verdaccio-plugin

## 简介

Verdaccio 6 storage plugin for MinIO / S3 (fork of barolab/verdaccio-minio@0.2.5, upgraded from the v4 to the v6 plugin API, zero @verdaccio/* runtime deps)
