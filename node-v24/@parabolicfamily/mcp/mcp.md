# @parabolicfamily/mcp

> 标签: agent, arc, bonding-curve, circle, defi, erc-8004, launchpad, mcp, model-context-protocol, uniswap-v4, usdc, web3

## 简介

MCP server for Parabolic, a bonding-curve token launchpad: discover coins, quote curve trades and build unsigned transactions. Never holds keys.
