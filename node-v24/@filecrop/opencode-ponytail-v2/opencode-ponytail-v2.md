# @filecrop/opencode-ponytail-v2

> 标签: ai-agent, opencode, opencode-plugin, ponytail, skills, yagni

## 简介

Ponytail for OpenCode V2: a self-contained adapter that ports the plugin surface to the native V2 API, with upstream's ruleset, skills, and commands vendored verbatim. Not a fork; no runtime deps.
