# @msqd/lydia

> 标签: api, component-library, http, observability, react, storybook, tailwindcss, typescript, ui

## 简介

React component library for observing and interacting with HTTP APIs: badges, data tables, charts, forms and transaction pages, built with TypeScript and Tailwind CSS 4.
