# @iappx/drizzle-active-record

> 标签: active-record, decorators, drizzle, drizzle-orm, entity, model, orm, postgres, postgresql, query-builder, relations, soft-delete, typescript

## 简介

A decorator-driven Active Record layer over Drizzle ORM for PostgreSQL: declare entities with decorators, get a chainable query builder, relations, soft delete and hydration on top of the generated Drizzle schema.
