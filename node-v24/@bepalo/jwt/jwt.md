# @bepalo/jwt

> 标签: ES256, HMAC, JWT decoding, JWT signing, JWT validation, RS256, access control, access-token, auth, authorization, bearer, claims, identity, json web token, jwk, jws, jwt, middleware, payload, secure tokens, token-verification

## 简介

A secure and tested json-web-token class-based utility library for generating keys, signing, verifying, and decoding JWT payloads for use with your high-security demanding projects.
