# ecw-js

> 标签: ecw, erdas, ermapper, gis, opfs, orthophoto, raster, wavelet

## 简介

Zero-dependency JavaScript reader for ERDAS ECW (Enhanced Compression Wavelet) raster files, for the browser and Node.
