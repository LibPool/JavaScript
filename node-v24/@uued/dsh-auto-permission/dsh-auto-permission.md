# @uued/dsh-auto-permission

> 标签: JavaScript

## 简介

Auto permission mode: a host-plane approval answerer between Workspace Write and Full Access — allow rules auto-approve out-of-workspace escalations once, deny rules auto-block them with a notice, everything else asks
