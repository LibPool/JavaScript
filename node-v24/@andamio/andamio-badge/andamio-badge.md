# @andamio/andamio-badge

> 标签: andamio, cardano, credential-badge, custom-element, open-badges, verifiable-credentials, web-component

## 简介

The <andamio-badge> web component: embed an Andamio credential badge on any site with a script tag and one element. Renders the badge card, shows honest baked-aware verified state, and links back to the credential's display page.
