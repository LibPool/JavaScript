# @openagentsinc/agent-harness-contract

> 标签: JavaScript

## 简介

The Effect-native **agent harness contract**. One versioned adapter contract drives a third-party coding-agent runtime (Codex, Claude Code, an ACP peer, a managed sandbox) behind a uniform surface with durable, cursor-exact turn suspend and continue.
