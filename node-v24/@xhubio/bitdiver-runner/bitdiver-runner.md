# @xhubio/bitdiver-runner

> 标签: JavaScript

## 简介

Test-Execution-Framework fuer automatisierte End-to-End Tests. Fuehrt Tests als Suites mit Steps aus, vergleicht Ergebnisse und liefert strukturiertes Reporting.
