# opencode-citecheck

> 标签: academic, arxiv, bibliography, bibtex, citations, crossref, doi, latex, opencode, opencode-plugin, retraction

## 简介

Verify \cite keys and DOIs inside the OpenCode agent loop — catch fabricated, unresolved and retracted references before they ship.
