# @entitlehub/sdk

> 标签: entitlehub, entitlements, in-app-purchase, play-billing, storekit, stripe, subscriptions

## 简介

EntitleHub SDK: one entitlement API across App Store, Google Play, Stripe, and web. Works in browsers, React Native, Expo, and Node.
