# @sentropic/geo-core

> 标签: JavaScript

## 简介

Modèle de domaine & standards géographiques : hiérarchie administrative (ISO 3166), GeoJSON (RFC 7946), CRS, Source Manifest + licences. Zéro dépendance runtime.
