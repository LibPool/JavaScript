# @sentropic/build-cli

> 标签: JavaScript

## 简介

The `stp app` processes of the Sentropic umbrella CLI: a deterministic, dependency-light scaffolding substrate (token substitution + scaffold manifest + generator core) that materialises a runnable chat-app whose backend mounts the published @sentropic/ch
