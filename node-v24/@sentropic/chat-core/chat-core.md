# @sentropic/chat-core

> 标签: JavaScript

## 简介

Chat orchestration core for @sentropic/* — port interfaces (CheckpointStore, MessageStore, SessionStore, StreamBuffer, LiveDocumentStore, ToolRegistry, EventSink, JobQueue, AgentRuntime). Adapters live in persistence-* / flow.
