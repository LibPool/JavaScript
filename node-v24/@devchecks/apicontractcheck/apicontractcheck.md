# @devchecks/apicontractcheck

> 标签: api, breaking-changes, contract-testing, har, openapi, swagger

## 简介

Check APIs against their OpenAPI contract: validate real responses (live, HAR files or a fetch wrapper) and detect breaking changes between spec versions.
