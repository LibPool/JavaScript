# @morfact/core

> 标签: composable, dag, dsl, lease, orchestration, outbox, plugin, storage-agnostic, task, workflow, yaml

## 简介

Composable, storage-agnostic workflow orchestration runtime — define DAGs, spawn child runs, route by condition, and execute hooks with built-in retry/lease/outbox.
