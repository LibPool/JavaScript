# @shinyaigeek/lumen

> 标签: bun, canvas, claude-code, coding-agent, mcp, openui, ui

## 简介

A local web canvas that lets a coding agent describe rich UI (OpenUI Lang) and see it rendered live on localhost. Ships an MCP server + CLI.
