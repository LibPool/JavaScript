# @exortek/apikey

> 标签: api-key, apikey, auth, backend, hmac, node-crypto, prefixed-token, scopes, security, server-only, stripe

## 简介

Stripe-style prefixed API keys for Node.js — 3-segment tokens (prefix_id_secret), HMAC-SHA256 storage hash with pepper rotation, scope allowlists with wildcard match, opt-in lastUsedAt tracking, memory + Redis stores, Express + Fastify middleware. Server-
