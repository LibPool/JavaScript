# @swoojeff/n8n-nodes-ytdlp-audio

> 标签: audio, download, n8n, n8n-community-node-package, youtube, yt-dlp

## 简介

n8n community node to download YouTube audio (optionally full video) via yt-dlp, returned as binary data.
