# @imcmurray/cloakroom

> 标签: claude-code, data-protection, llm, pii, pre-commit, privacy, redaction, sanitize, secrets

## 简介

Check your secrets at the door: swap PII/secrets for reserved-range decoys before any LLM sees them, restore them in the reply. CLI (`cloak`), wrap-any-command mode, pre-commit gate, Claude Code hooks.
