# dsh-csdn-theme

> 标签: csdn, deepseek-harness, dsh-plugin, markdown, theme

## 简介

CSDN 风格的 DSH Web 主题：CSDN 品牌色与博文正文排版（加粗/下划线/引用/表格/代码等）双层接入，浅色与深色各一套。
