# @hugpy/agents-ui

> 标签: JavaScript

## 简介

Agent fleet console — a loosely-coupled arm of the hugpy ecosystem, built standalone (Vite + Tailwind v4) and served at /fleet. The agent side of the fleet: portable runtime, node roster, dispatch. Dials the same-origin current-hugpy API (/api).
