# @hugpy/media-intelligence-ui

> 标签: JavaScript

## 简介

Media-intelligence console — a loosely-coupled arm of the hugpy ecosystem, built standalone (Vite + Tailwind v4) and served at /media. Dials the same-origin current-hugpy API (/api).
