# @apify/storage-local

> 标签: api, apify, sqlite

## 简介

Drop in replacement of Apify API with a local SQLite and filesystem implementation. Not all API features are supported.

## 官网

- 官网：https://sdk.apify.com/
- 源码仓库：git+https://github.com/apify/apify-storage-local-js.git
- npm 页面：https://www.npmjs.com/package/@apify/storage-local
