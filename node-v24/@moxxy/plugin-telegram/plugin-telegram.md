# @moxxy/plugin-telegram

> 标签: agent, bot, channel, moxxy, telegram

## 简介

Telegram channel for moxxy via grammy. Treats Telegram chats as a bidirectional channel: prompts in, assistant + tool prompts out, inline-keyboard permission flow, QR deep-link chat pairing.
