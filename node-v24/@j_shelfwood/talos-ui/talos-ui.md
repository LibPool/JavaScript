# @j_shelfwood/talos-ui

> 标签: astro, chamfer, css, design-system, hud, monochrome, ui, web-components

## 简介

Dark-monochrome HUD design system — chamfered panels, Oxanium type, ambient grid, and composable notched-panel web components. Framework-agnostic CSS + opt-in web components + Astro wrappers.
