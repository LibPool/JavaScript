# @reckit/calcom-mcp

> 标签: booking, cal.com, cal.eu, calendar, claude, mcp, model-context-protocol, scheduling, stdio

## 简介

Local stdio MCP server giving an AI agent full access to the Cal.com / Cal.eu v2 API. Defaults to the EU host (api.cal.eu); US and self-hosted users set CALCOM_BASE_URL.
