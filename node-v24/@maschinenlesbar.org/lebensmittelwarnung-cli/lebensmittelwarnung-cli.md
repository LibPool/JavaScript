# @maschinenlesbar.org/lebensmittelwarnung-cli

> 标签: api-client, bvl, cli, germany, lebensmittel, lebensmittelwarnung, recall, rss, rueckruf, verbraucherschutz

## 简介

TypeScript API client and CLI for the official lebensmittelwarnung.de product-warning feeds — food, cosmetics and consumer-product recalls (Rückrufe), filterable by federal state and product type
