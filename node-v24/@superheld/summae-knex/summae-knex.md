# @superheld/summae-knex

> 标签: accounting, knex, persistence, rechnungswesen, sqlite, summae

## 简介

Database adapter (Node) for @superheld/summae-core — persists into the shared summae_* schema via Knex (query/schema builder) + better-sqlite3 / pg
