# @shopimind/integration-kit-js

> 标签: JavaScript

## 简介

Foundation for building ShopiMind integrations: a runtime plus typed, once-tested primitives (HMAC webhook signatures, encryption, log redaction, a safe cursor-based sync engine, pagination/concurrency, pluggable persistence with official SQLite and Postg
