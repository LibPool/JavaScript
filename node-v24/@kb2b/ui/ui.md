# @kb2b/ui

> 标签: base-ui, design-system, kb2b, react, shadcn, tailwind-v4, tailwindcss, tokens

## 简介

Shared UI primitives + design tokens for kb2b-web and kb2b-desktop. CSS-only consumers (Cloudflare Pages, no bundler) import tokens.css/theme.css directly. Tailwind v4 + React consumers import components from the package root.
