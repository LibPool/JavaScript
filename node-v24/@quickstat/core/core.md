# @quickstat/core

> 标签: analytics, core, dashboard, grafana, metrics, monitor, monitoring, node.js, prometheus, statistics, stats, track, tracking

## 简介

QuickStat simplifies tracking for different libraries or even manual entries. Visualize data in Grafana, store in databases, or scrape via Prometheus.
