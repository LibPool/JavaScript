# @pxlhut/brand-core

> 标签: accessibility, apca, color, design-tokens, multi-tenant, oklch, shadcn, theming, wcag, white-label

## 简介

Generate a complete, gamut-mapped, APCA-validated design token tree from one brand colour. Pure, browser-safe, framework-agnostic.
