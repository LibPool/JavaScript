# @imbear/summarycard

> 标签: card, mcp, summary, visualization

## 简介

这是一个基于 Model Context Protocol (MCP) 的工具服务，专为大语言模型 (LLM) 设计。它能够将结构化的文本数据转化为精美的可视化总结卡片，并以图片形式返回。
