# @ykurilov/agent-chat-mcp

> 标签: JavaScript

## 简介

Серверы MCP, которые подключает админ приложения: вставил адрес сервиса (документация библиотек, задачи, CRM, поиск по коду), включил нужные инструменты — агент ими пользуется. Только удалённые серверы (Streamable HTTP или SSE), запуска программ на сервер
