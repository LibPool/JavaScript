# @ykurilov/agent-chat-limits

> 标签: JavaScript

## 简介

Лимиты расходов для чата с агентом: бюджет в долларах на человека, на чат и на весь сервис — в любых окнах (сутки, неделя, месяц, N часов от первого запроса). Отдельное расширение: приложению без лимитов пакет не нужен. Ядро записывает в журнал расхода то
