# @ykurilov/agent-chat-voice-dialog

> 标签: JavaScript

## 简介

Голосовой режим чата с агентом: человек говорит, агент отвечает голосом, человека можно перебить. Распознавание — Soniox (через пакет `@ykurilov/agent-chat-voice`), озвучка — ElevenLabs. Ключи хранятся только на сервере: в браузер не уходит ни главный, ни
