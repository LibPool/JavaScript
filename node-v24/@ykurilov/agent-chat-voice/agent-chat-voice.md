# @ykurilov/agent-chat-voice

> 标签: JavaScript

## 简介

Голосовой ввод для чата с агентом через Soniox: человек нажимает микрофон в поле ввода, слова появляются в поле по ходу речи, он правит и отправляет сам. Отдельное расширение: приложению без голоса пакет не нужен, а чат без него кнопки микрофона не рисует
