# @ykurilov/agent-chat-sandbox

> 标签: JavaScript

## 简介

Песочница агента для админа приложения: чат с боевым агентом, журнал каждого обращения к модели и вызова инструмента, правка любого сообщения с веткой, своя модель и своя системная инструкция на чат. Отдельное расширение: приложению без песочницы пакет не
