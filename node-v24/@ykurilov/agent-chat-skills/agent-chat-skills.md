# @ykurilov/agent-chat-skills

> 标签: JavaScript

## 简介

Навыки агента: готовые указания для отдельных задач («разработка игр», «оформление договора»), которые админ пишет на экране приложения, а агент загружает сам, когда задача подходит. Инструкция агента не растёт, кэш модели не ломается.
