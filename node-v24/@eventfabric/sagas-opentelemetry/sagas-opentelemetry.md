# @eventfabric/sagas-opentelemetry

> 标签: eventfabric, metrics, observability, opentelemetry, otel, process-manager, saga, tracing, typescript

## 简介

OpenTelemetry adapter for @eventfabric/sagas: traces + counters + histograms per saga reaction / command dispatch / timer fire, plus observable gauges for queue lag and overdue timers.
