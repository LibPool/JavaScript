# @eventfabric/core

> 标签: aggregate, cqrs, ddd, domain-driven-design, event, event-driven, event-sourcing, event-store, events, eventsourcing, eventstore, multi-tenancy, multi-tenant, outbox, outbox-pattern, projection, snapshot, typescript, upcaster

## 简介

Event sourcing core for TypeScript: aggregates, event store + outbox interfaces, inline / catch-up / async projections, snapshots, multi-tenancy, upcasters. Backend-agnostic — pair with @eventfabric/postgres.
