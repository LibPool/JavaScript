# dsh-teleagent

> 标签: agent, deepseek-harness, dsh, dsh-plugin, llm, openai-compatible, teleagent

## 简介

TeleAgent 档位模型接入 DSH：工具调用、可配置上下文（含 1M）、插件内官方登录。TeleAgent tier models for DeepSeek Harness with tool calling and in-panel sign-in.
