# @rudof/rudof

> 标签: knowledge-graphs, linked-data, rdf, semantic-web, shacl, shex, sparql, validation, webassembly

## 简介

Validate RDF data with ShEx and SHACL, and query it with SPARQL, in the browser and in Node.js
