# @cruglobal/flags

> 标签: cru, etag, feature-flags, feature-toggles, flags, polling

## 简介

Official Node.js client for Cru's pipeline feature flag service. Zero dependencies, synchronous flag reads, fail-static polling with ETag revalidation.
