# @danielsoren/secrets-loader

> 标签: aws, config, env, esm, secrets, secrets-manager, typescript, zod

## 简介

Load one JSON secret from a provider (AWS today; pluggable in the future), merge local overrides, validate with Zod, and return typed config.
