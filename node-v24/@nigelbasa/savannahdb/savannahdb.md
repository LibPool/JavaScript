# @nigelbasa/savannahdb

> 标签: bson, database, document-database, embedded-database, mongodb-compatible, mql, n-api, native, nosql

## 简介

Independent custom document database with embedded (N-API) and REST APIs. MongoDB-compatible MQL surface, no MongoDB runtime needed.
