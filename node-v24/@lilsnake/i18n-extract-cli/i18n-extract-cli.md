# @lilsnake/i18n-extract-cli

> 标签: auto-translate, extract, i18n, i18n-cli, i18n-translate, intl, intl-cli, react-i18n, translate, vue-i18n

## 简介

这是一款能够自动将代码里的中文转成i18n国际化标记的命令行工具。适用于vue2、vue3和react
