> 标签: ai-code-review, ai-diff-verification, ai-safety, claude-code, code-safety, codex, cursor, deterministic-rules, human-gate, local-first, mcp, pr-review, second-opinion, secret-scanner, verification-gate

## 简介

Local verification gate for AI-written code diffs. Deterministic rules decide the verdict, never the LLM. No auto-commit, push, or deploy — you decide at the Human Gate.
