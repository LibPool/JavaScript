# unplugin-sourcemaps

> 标签: esbuild, rollup, source-map, sourceMappingURL, sourcemap, vite, webpack

## 简介

Universal plugin for loading existing source maps from imported modules. Works with Vite, Rollup, webpack, and esbuild.
