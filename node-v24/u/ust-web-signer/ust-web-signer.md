# ust-web-signer

> 标签: browser, ed25519, signing, trust-infrastructure, ust, webcrypto

## 简介

WebCrypto Ed25519 signer + producer for UST (Universal State Transcript) 1.0 — the browser-side piece that ust-protocol deliberately omits (a private key never enters the verifier). Byte-compatible; produces documents that verify VALID under ust-protocol.
