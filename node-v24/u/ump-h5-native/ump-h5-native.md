# ump-h5-native

> 标签: JavaScript

## 简介

Browser peer of [`ump-native`](https://npmjs.com/package/ump-native) for [UMP](https://git.n.xiaomi.com/zhoujianlin/ump). Mirrors the same component surface so `import { View, Text, ... } from 'ump-h5-native'` works on the web.
