# umi-plugin-cool-docker

> 标签: JavaScript

## 简介

支持将项目打包为 docker。并且可以通过 umirc 配置环境变量。环境变量兼容本地开发。独立部署和 docker 部署。

- npm 页面：https://www.npmjs.com/package/umi-plugin-cool-docker
