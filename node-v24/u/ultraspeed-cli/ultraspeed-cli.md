# ultraspeed-cli

> 标签: ai-agents, blitz, cli, core-web-vitals, lighthouse, mcp, pagespeed, performance, web-performance, website-speed-test

## 简介

One-click website speed test in your terminal or AI tool: score, named causes with evidence, and an apply-able fix plan. Includes the Ultraspeed MCP server (report, plan, apply, remeasure) for Claude Code, Cursor, Codex, and Gemini CLI.
