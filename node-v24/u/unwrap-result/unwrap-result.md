# unwrap-result

> 标签: JavaScript

## 简介

Um método que executa uma função ou Promise de forma segura, retornando um array com dois valores: o primeiro é um possível erro (ou null se não houver erro), e o segundo é o resultado da operação. Isso permite lidar com erros e resultados de forma consis
