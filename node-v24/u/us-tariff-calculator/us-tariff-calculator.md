# us-tariff-calculator

> 标签: 2026, ai-agent, api, customs, customs duty, duty, duty rate, ecommerce, hmf, importer, landed-cost, mcp, mpf, section 301, tariff, tariff calculator, tariffs 2026, trade, us import tariff, us tariff calculator, us-tariff, usa

## 简介

Calculate the current total 2026 US import tariff on any product in one call. Stacked duty layers (MFN, Section 301/232), MPF/HMF, no HTS code required. Works without an API key.
