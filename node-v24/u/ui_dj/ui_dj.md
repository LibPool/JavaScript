# ui_dj

> 标签: JavaScript

## 简介

`ui_dj` 是一个基于 **Vue 3 + Vite 8 + UnoCSS + sass-embedded** 构建的业务组件库。当前仓库主要包含基础 UI 组件和 PDF 编辑/生成能力。
