# ultrabrowse

> 标签: agent, automation, browser, claude-code, codex, jev, mcp, typesafe

## 简介

Ultra-fast browsing for Claude Code, Codex and any MCP client: hand off a goal, a Jev-driven Chrome does the clicking at ~300 ms per decision.
