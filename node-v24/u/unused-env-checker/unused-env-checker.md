# unused-env-checker

> 标签: cjs, cleanup, cli, code-quality, custom-ignore, developer-tools, dotenv, env, environment, environment-variables, ignore-patterns, mjs

## 简介

A CLI tool that scans your codebase and compares used environment variables with the variables defined in your .env file.
