# unfazed

> 标签: agents, bun, code-mode, deploy, deployment, graphql, mcp, sdk, unfazed

## 简介

Official TypeScript SDK for unfazed. The code-mode companion to the unfazed MCP server: deploy, wait, tail logs and roll back from one script.
