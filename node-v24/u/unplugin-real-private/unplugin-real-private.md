# unplugin-real-private

> 标签: class, esbuild, javascript, members, plugin, private, rollup, rspack, typescript, unplugin, vite, webpack

## 简介

Turn TypeScript private class members into real ECMAScript #private members, for Vite, Rollup, Webpack, Rspack, esbuild and more.
