# unified-trial-mcp

> 标签: chictr, chinadrugtrials, clinical-trials, clinicaltrials.gov, ictrp, mcp, model-context-protocol, trial-search, 临床试验, 小胰宝

## 简介

统一临床试验检索 MCP 服务：一个 MCP 入口覆盖 ICTRP、ClinicalTrials.gov、ChiCTR 与中国药物临床试验登记平台（含研究者信息）。
