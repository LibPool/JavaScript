# util-fine

> 标签: JavaScript

## 简介

addBigNum(a,b)可以计算得到两个20位数(a,b)的和，需要传入字符串类型的值;randomClass(total,num)可以自动随机分班，需要传入两个参数.total是总人数，num是班级个数
