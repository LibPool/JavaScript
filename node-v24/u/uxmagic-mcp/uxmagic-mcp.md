# uxmagic-mcp

> 标签: ai, design, design-to-code, frames, mcp, ui, uxmagic

## 简介

MCP bridge for UX Magic — connect your IDE to the full UX Magic design toolset (generate & edit designs, themes, projects, frames) over MCP with API-key auth.
