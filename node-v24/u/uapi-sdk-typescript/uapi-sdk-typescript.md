> 标签: agent, axios, client, free-api, mcp, nodejs, openapi, public-api, rest, rest-api, sdk, typescript, uapi, uapis, uapis.cn

## 简介

Official TypeScript / Node.js SDK for UAPI / uapis.cn — a strongly-typed wrapper around 100+ free public-API endpoints (network, text, image, social, translation, search). Generated from the live OpenAPI 3.1 spec.
