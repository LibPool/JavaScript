# usedevice-mcp

> 标签: ai-agents, android, device-cloud, emulator, ios, mcp, mobile, model-context-protocol, real-devices, simulator, usedevice

## 简介

MCP server for usedevice: mobile devices for AI agents (iOS Simulators, Android Emulators, real iPhones, Pixels and Galaxies). Early access: list devices, ask the site, reserve a slot.
