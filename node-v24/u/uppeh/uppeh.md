# uppeh

> 标签: drag-drop, dropbox, file uploader, google drive, preview, progress, resumable uploads, s3, tus, webcam, xhr

## 简介

Extensible file upload widget with support for drag&drop, resumable uploads, previews, restrictions, file processing/encoding, remote providers like Dropbox and Google Drive, S3 and more :dog:
