# unstemizer

> 标签: JavaScript

## 简介

`unstemizer` allows you to access each part of a [Stems](http://www.stems-music.com/) file. A Stems file is a music format that contains four ‘stems’: Drums, Bassline, Melody, and Vocal stems. This format allows DJs to control each track independently.
