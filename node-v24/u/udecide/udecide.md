# udecide

> 标签: browser, classifier, embedding, intent, local-first, onnx, pii, sentiment, similarity, spam, text-classification, toxicity, transformers, wasm

## 简介

Six small text classifiers and a train() primitive that run in the browser or in Node and return calibrated probabilities.
