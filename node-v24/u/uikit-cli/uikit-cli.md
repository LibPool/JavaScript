# uikit-cli

> 标签: cli, design-system, react, scaffold, shadcn, tailwind, ui-kit, uikit, vue

## 简介

The uikit CLI — scaffold, validate, and add UI kits from the uikit.studio gallery. Includes the kit contract and the uikit-standard generator.
