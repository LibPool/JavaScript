# uni-js-bridge

> 标签: JavaScript

## 简介

适用于uni-app框架中webview组件和H5通信的js小工具。此JS是放在H5项目中的；还需要配合uni-app另外封装的webview组件；uni-app的webview组件会放在另一个项目中；
