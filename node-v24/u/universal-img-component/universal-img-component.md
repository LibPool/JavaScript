# universal-img-component

> 标签: base64, cdn, cloudinary, image, nextjs, react, text-image

## 简介

🌟 A versatile React component for handling images with ease! 📸 Supports multiple modes: convert images to Base64 🔄, optimize with CDN 🌐, create text-based images 📝, and use Next.js optimization 🚀. Perfect for any project needing dynamic image manage
