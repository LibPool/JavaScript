# useskl

> 标签: agent-skills, claude, claude-code, cli, codex, copilot, cursor, skill-manager, skills, skl

## 简介

The Agent Skills manager — save, install, and version Agent Skills across Claude Code, Codex, Cursor, Copilot, Gemini & more, as easy as using npm. Installs the `skl` command.
