# useclaudeproxy

> 标签: CLIProxyAPI, claude, claudecode, useclaudeproxy

## 简介

useclaudeproxy — OAuth device-flow CLI that authenticates the Hermes CLI and runs CLIProxyAPI as a local OpenAI/Claude/Gemini/Codex proxy.
