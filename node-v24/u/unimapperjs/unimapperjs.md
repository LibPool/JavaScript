# unimapperjs

> 标签: database, domain, entities, linq, mapper, mongodb, mssql, mysql, object, odm, orm, postgre, universal

## 简介

Universal node.js (native ES6/ES7) LINQ-like object mapper (ORM/ODM) for all types of databases (SQL, NoSQL).
