# usefluxui

> 标签: animation, color, css, easing, hook, interpolation, keyframes, lerp, motion, physics, react, scroll, spring, stagger, transform, transition, tween

## 简介

Real-time CSS interpolation engine. 200+ easings, spring physics, scroll-linked animations, stagger, color/transform/unit interpolation. One hook. Zero dependencies.
