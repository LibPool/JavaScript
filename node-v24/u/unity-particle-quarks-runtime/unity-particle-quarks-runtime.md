# unity-particle-quarks-runtime

> 标签: JavaScript

## 简介

Generic Three.js/Quarks runtime for Unity ParticleSystem JSON exported by the Unity ParticleSystem to Quarks exporter. It uses `three.quarks` and `quarks.core` `0.17.1`.
