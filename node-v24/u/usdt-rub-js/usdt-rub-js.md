# usdt-rub-js

> 标签: cli, crypto, freelance, npx, rub, usdt, zero-dependencies

## 简介

Estimate how many rubles you actually get for USDT via P2P, an exchanger, or your own spread. Zero dependencies, runs via npx straight from GitHub.
