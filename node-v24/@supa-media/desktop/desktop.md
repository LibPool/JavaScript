# @supa-media/desktop

> 标签: desktop, electron, menu-bar, offline, outbox, supa, tray

## 简介

Electron shell for Supa apps — menu-bar tray, panel windows, preload bridge, settings store, offline outbox, and an Electron-free core that tests under plain node
