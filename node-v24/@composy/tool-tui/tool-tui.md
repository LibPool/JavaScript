# @composy/tool-tui

> 标签: cli, interactive, ldesign, terminal, tool-ui, tui, vue-tui

## 简介

LDesign 终端 UI 基础层：基于 vue-tui 的终端组件、design token 与 runTui 运行时封装，供 tools/* CLI 统一引用。
