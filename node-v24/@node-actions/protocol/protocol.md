# @node-actions/protocol

> 标签: actions, api-contract, contract, introspection, node-actions, protocol, runtime, typescript

## 简介

O CONTRATO de actions — o padrão que qualquer implementação cumpre, independente de como resolve o corpo (diretivas, TS, outra coisa). Invocação (2 portas), envelope de resultado, modelo de erro, introspecção (params/result em JSON Schema, disponibilidade
