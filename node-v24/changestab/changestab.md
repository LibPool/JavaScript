# changestab

> 标签: changes, cordis, deepseek-harness, diff, dsh, git, jj, plugin

## 简介

Read-only changes view for the dsh (DeepSeek Harness) web GUI — its own Changes tab in the right column, alongside the built-in file browser: a jj/git change tree, each change's changed files, and side-by-side or unified diffs, with click-to-ref and Open-
