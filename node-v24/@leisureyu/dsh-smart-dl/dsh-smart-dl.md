## 简介

Multi-threaded downloader plugin for DeepSeek Harness: bundles aria2, probes file size and picks aria2 multi-connection or curl fallback automatically (Windows x64/arm64, Linux x64/arm64; any platform with aria2c on PATH). Verifies downloads against MD5 /
