# glitchless-sourcemaps

> 标签: error-tracking, game-development, game-observability, gamedev, phaser, source-maps, sourcemaps, threejs, vite, vite-plugin, web-games

## 简介

Upload a web game's source maps to Glitchless, so errors from the minified build show the original function, file and line, and group the same in every build. A CLI for CI and a Vite plugin.
