# @agenticprimitives/browser-identity

> 标签: adapter, agent-authority, agentic, agentic-primitives, agentic-trust, agenticprimitives, ai-agents, browser-identity, fedcm, federation, sign-in

## 简介

Browser sign-in adapter seam: feature-detect FedCM and choose the browser-native path vs the guaranteed fallback. FedCM-first, not FedCM-only (ADR-0031).
