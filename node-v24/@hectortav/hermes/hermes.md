# @hectortav/hermes

> 标签: persistent, queue, queues, redis, reload, restart, runner, schedule, scheduler, task, tasker, timeout, timer

## 简介

Hermes is a minimal Node.js job scheduler. Uses Redis to ensure reliability and job persistence between reloads and restarts. Hermes uses Typescript by default.
