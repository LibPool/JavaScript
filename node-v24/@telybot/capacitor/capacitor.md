# @telybot/capacitor

> 标签: capacitor, chat, chatbot, cordova, ionic, support, telybot, widget

## 简介

Open your Telybot bot in an Ionic/Capacitor app: the plain widget script tag, or the hosted chat page as a full-screen surface.
