# @tracepoint/mcp-doctor

> 标签: ai-agents, audit, cli, llm, mcp, model-context-protocol, prompt-injection, security, security-scanner, tool-poisoning

## 简介

Security auditor for MCP servers. Finds tool descriptions carrying hidden instructions, annotations that contradict their own schema, over-shared credentials, and pairs of tools that together form a path off your machine. Runs entirely offline.
