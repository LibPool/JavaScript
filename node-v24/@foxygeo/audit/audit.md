# @foxygeo/audit

> 标签: ai-search, ci, claudebot, geo, github-actions, gptbot, llms.txt, schema

## 简介

Lint llms.txt, GPTBot/ClaudeBot access, and schema in CI. Comments AI Readiness on the PR and publishes a public FoxyGEO report.
