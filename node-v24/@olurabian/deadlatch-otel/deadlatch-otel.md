# @olurabian/deadlatch-otel

> 标签: agent-governance, ai-agents, deadlatch, grafana, observability, opentelemetry, otel, purse, tracing

## 简介

Emit Deadlatch control events (Purse enforce, blackbox prove, Tripwire watch) as OpenTelemetry spans. Flows into Grafana, agento11y, or any OTel backend.
