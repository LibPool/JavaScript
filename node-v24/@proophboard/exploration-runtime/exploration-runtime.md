# @proophboard/exploration-runtime

> 标签: event-modeling, exploration-mode, play-function, prooph-board, runtime, scenario

## 简介

Pure, environment-independent Exploration Mode runtime for prooph board: fold play functions, run scenarios as tests, and build the TypeScript .d.ts surfaces used to typecheck play functions. Runs in Node and the browser.
