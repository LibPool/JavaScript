# @bbb-mobile/sdk-host

> 标签: JavaScript

## 简介

Host bridge of the BigBlueButton meeting SDK: JS<->native events (joined/leave/error, host commands), the Android meeting foreground service, and the LiveKit setup lifecycle listener
