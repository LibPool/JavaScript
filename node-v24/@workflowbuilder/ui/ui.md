# @workflowbuilder/ui

> 标签: accessible, base-ui, component-library, components, design-system, react, typescript, ui, workflow-builder

## 简介

Workflow Builder's component library: accessible, themeable React UI primitives (button, input, select, modal, menu, date picker, switch, tooltip, and more) built on Base UI, plus diagram building blocks for node/edge UIs.
