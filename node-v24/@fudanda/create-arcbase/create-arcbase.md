# @fudanda/create-arcbase

> 标签: JavaScript

## 简介

从已交付包创建独立项目，使用 `ArcBaseAdmin` 和 React Router。当前生成器源码及新交付归档默认使用 Ant Design，可用 `--ui semi` 选择 Semi；已发布旧版本的行为由对应版本决定。Node 仅参与生成/开发/构建，生产直接运行宿主 Go 二进制。
