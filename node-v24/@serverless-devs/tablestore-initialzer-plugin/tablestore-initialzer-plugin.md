# @serverless-devs/tablestore-initialzer-plugin

> 标签: JavaScript

## 简介

`@serverless-devs/tablestore-initialzer-plugin` 插件是基于 [Aliyun TableStore SDK](https://github.com/aliyun/aliyun-tablestore-nodejs-sdk)开发，使用该插件需要在环境变量里设置 `tablestore_endpoint` 和 `tablestore_instanceName` 两个参数, 然后你可以在 `baseHandler` 里 通过 `request.internal` 里拿
