# @patrickdk77/file-defuse

> 标签: attachments, cdr, defang, defuse, detect, disarm, image, inspect, nested, office, pdf, sanitise, sanitize, scanner, scrub, security, upload

## 简介

Sanitize uploads with the defuse family. Sniffs the content, hands the file to the package that reads it, routes every file found inside back through the same router, and limits the whole tree: size, depth, file count, decoded bytes and time.
