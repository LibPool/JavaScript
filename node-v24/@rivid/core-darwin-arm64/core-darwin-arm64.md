# @rivid/core-darwin-arm64

> 标签: base32, bulk, crockford, fast, id, identifier, monotonic, napi, performance, rust, sortable, ulid, uuid, uuidv7

## 简介

High-performance, spec-compatible ULID generation for Node.js and Bun, powered by a Rust core via NAPI-RS. Includes monotonic ULIDs, bulk generation, binary APIs, alternative encodings and UUIDv7.
