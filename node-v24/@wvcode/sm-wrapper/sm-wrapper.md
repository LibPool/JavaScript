# @wvcode/sm-wrapper

> 标签: JavaScript

## 简介

Este cliente de API serve para facilitar o processo de buscar os resultados das pesquisas feitas na plataforma Survey Monkey para que possam ser processadas e utilizadas de maneira livre.
