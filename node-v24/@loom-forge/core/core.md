# @loom-forge/core

> 标签: composition, dsl, headless, json, nocode, react, ui

## 简介

loom · o kernel HEADLESS: DefNode → ResolvedNode via bind → resolve → plan. Zero React, zero ambiente, zero dependências. Os ports (bind/validação/ações/endereço/tipos) são os seams de DI.
