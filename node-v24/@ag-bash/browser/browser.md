# @ag-bash/browser

> 标签: ag-bash, agentic, browser, cdp, mcp

## 简介

Optional ag_browser_* MCP tool suite for Ag-Bash — scripted, deterministic Chrome DevTools Protocol automation (navigate, click, type, screenshot, evaluate JS, raw CDP) backed by browser-harness-mcp. Not an autonomous browser-use.Agent integration.
