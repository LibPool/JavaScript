# @captchasonic/mcp-server

> 标签: ai-agent, captcha, captchasonic, claude, geetest, hcaptcha, mcp, model-context-protocol, recaptcha, turnstile

## 简介

CaptchaSonic MCP server: lets Claude and any MCP client solve CAPTCHAs. Hosted at https://mcp.captchasonic.com, or run locally over stdio.

- 官网：https://captchasonic.com/en/docs/mcp/get-started
