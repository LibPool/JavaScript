# @apnex/cognitive-layer

> 标签: JavaScript

## 简介

Sovereign cognitive-middleware layer for OIS agents — pluggable chain-of-responsibility augments for tool-call interception, caching, dedup, description enrichment, error normalization, and telemetry. Consumed by @apnex/network-adapter via opt-in config.
