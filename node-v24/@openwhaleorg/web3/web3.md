# @openwhaleorg/web3

> 标签: JavaScript

## 简介

Chain access for OpenWhale: the `web3/chain` kind (an EVM read/sign session), the `EVM Wallet` account view, and the `web3/evm` wallet-key and `web3/rpc` endpoint credential types. On-chain venue plugins (Pendle, …) depend on it for the wallet key family
