# @iwotech/deploy-cli

> 标签: JavaScript

## 简介

- 执行 yarn deploy 后，将自动上传 dist 目录下的文件到指定仓库指定分支，并发起 webhook 请求 - 发布可指定单个或多个环境，执行 yarn deploy test prod ...，不指定则发布全部环境
