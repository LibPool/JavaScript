# @apisurf/ngnui

> 标签: cron, dashboard, ngn, scheduler, sqlite, tasks, viewer

## 简介

ngnui — browse an ngn run database in a local web UI: tasks, runs, logs, timings, stored keys, versions, plus a live task editor.
