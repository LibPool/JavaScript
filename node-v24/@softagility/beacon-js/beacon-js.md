# @softagility/beacon-js

> 标签: analytics, beacon, sdk, softagility, telemetry, tracking, usage

## 简介

SoftAgility Beacon JavaScript/TypeScript SDK — track usage events, manage sessions, capture exceptions, and queue events offline. Browser + Node.
