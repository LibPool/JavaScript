# @jfrevert/smoldot

> 标签: JavaScript

## 简介

Smoldot light client fork with the Midnight Cargo feature enabled — provides the bridge host-function stubs needed to host a Midnight runtime in-browser. Tracks upstream smoldot 2.0.40.
