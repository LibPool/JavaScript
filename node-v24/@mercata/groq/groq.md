# @mercata/groq

> 标签: ai

## 简介

The **[Groq provider](https://ai-sdk.dev/providers/ai-sdk-providers/groq)** for the [AI SDK](https://ai-sdk.dev/docs) contains language model support for the Groq chat and completion APIs and embedding model support for the Groq embeddings API.
