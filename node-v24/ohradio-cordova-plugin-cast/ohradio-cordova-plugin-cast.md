# ohradio-cordova-plugin-cast

> 标签: cast, chromecast, cordova, cordova-android, ecosystem:cordova, hls, streaming

## 简介

Botón de Cast para transmisiones en vivo HLS en apps Cordova. Usa el Default Media Receiver de Google: no requiere registrar ninguna aplicación ni pagar la cuota de desarrollador de Cast.
