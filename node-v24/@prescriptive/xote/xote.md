# @prescriptive/xote

> 标签: accessibility, components, design-system, prescriptive, rescript, ui, xote

## 简介

Accessible UI components for Xote/ReScript that implement the Prescriptive contracts. Styled against @prescriptive/tokens; prop types are generated from the spec API contracts, so the implementation can't drift from the spec.
