# @duckalization/bundler-plugin

> 标签: duckalization, esbuild, i18n, localization, rollup, translation, unplugin, vite, webpack

## 简介

Build-time ID injection for duckalization: pre-bakes content-derived IDs into __() calls so no hashing ships to the client.
