# @refore-ai/html-to-jsdesign-mcp

> 标签: JavaScript

## 简介

Agent 按你的要求打开很多页面 / 浏览模块，比如一个操作流程 / 所有子模块，挨个通过这个 MCP 导入到 JSDesign(即时设计) 的设计稿里。
