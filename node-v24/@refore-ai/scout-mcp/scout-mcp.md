> 标签: JavaScript

## 简介

Local MCP server for [Refore Scout](https://refore.ai/scout) — lets AI agents (Claude Code, Codex, Cursor, …) read the Watch / Discover data collected by the Refore Scout browser extension, **read-only and fully local**: the extension in your browser conn
