# @oleksiimazurenko/fit-text

> 标签: clamp, container-queries, cqi, css, fit-text, responsive, typography, zero-js

## 简介

Fit text to its container with pure CSS — zero JS. The framework-agnostic stylesheet core: container-query font sizing (cqi + clamp) with language-aware hyphenation.
