# @tfn-design/design-tokens

> 标签: JavaScript

## 简介

The single source of truth for every design value on web and mobile. Both apps `@import "@tfn-design/design-tokens/theme.css"` in their global CSS — Tailwind v4 and NativeWind v5 parse it identically.
