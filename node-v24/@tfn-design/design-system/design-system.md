# @tfn-design/design-system

> 标签: JavaScript

## 简介

The shared component set for web (React DOM) and native (React Native with NativeWind). Components are styled with Tailwind 4 classes that resolve against the tokens in `@tfn-design/design-tokens`, which installs with this package as a dependency.
