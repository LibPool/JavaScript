# @m1z23r/ngx-dnd

> 标签: angular, angular21, dnd, drag, drag-and-drop, drop, kanban, reorder, signals, sortable, standalone

## 简介

A signals-first Angular drag and drop library - sortable lists, connected and nested drop lists, drop zones, copy sources, auto-scroll and custom previews. No rxjs, no CDK.
