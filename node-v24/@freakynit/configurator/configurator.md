# @freakynit/configurator

> 标签: app-config, config, config-cache, config-file, config-loader, config-manager, config-overrides, config-parser, configuration, deep-merge, dotenv, env, environment, environment-variables, nodejs, nunjucks, settings, templating, type-safe, typed-config, typescript, yaml, yml

## 简介

Type-safe YAML configuration loader for Node.js with environment variable templating via Nunjucks. Supports local overrides, deep merging, caching, and customizable environment handling for clean and flexible configuration management.
