# @ai-setting/roy-task-plugin

> 标签: JavaScript

## 简介

OpenCode plugin for business-semantic task management. Ships the plugin entry (dist/index.js) plus the `roy-task` CLI (dist/cli.js) that bridges Feishu events to the roy agent — the CLI runs on plain Node.js, no bun required.
