# hypra

> 标签: accessibility, html, hypra, llm, markdown, seo, templates, webmcp

## 简介

The Hypra compiler and the runtime for its JavaScript pages: accessible HTML for browsers, Markdown for LLMs and WebMCP tools for AI agents, from one file.
