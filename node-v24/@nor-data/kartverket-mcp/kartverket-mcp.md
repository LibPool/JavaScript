# @nor-data/kartverket-mcp

> 标签: address, adresser, cadastre, geocoding, geonorge, kartverket, matrikkel, mcp, model-context-protocol, norway, stedsnavn

## 简介

MCP server for Norwegian map and cadastre data from Kartverket (Geonorge): address search/geocoding, place names, properties (matrikkel), buildings, municipalities, statistical zones and terrain elevation. No API key required.
