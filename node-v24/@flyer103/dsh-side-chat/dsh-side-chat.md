# @flyer103/dsh-side-chat

> 标签: context-isolation, deepseek-harness, dsh, dsh-plugin, side-chat, side-conversation

## 简介

DSH side chat: fork the current session into an ephemeral side conversation that can really edit files, without polluting the main transcript.
