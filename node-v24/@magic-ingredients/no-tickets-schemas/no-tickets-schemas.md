# @magic-ingredients/no-tickets-schemas

> 标签: JavaScript

## 简介

Zod source-of-truth schemas for no-tickets event types. Consumed in-workspace by the no-tickets-service runtime validator and on npm by client SDKs (TS CLI, MCP) for local validation before publish.
