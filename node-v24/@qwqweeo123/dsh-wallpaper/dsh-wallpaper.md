# @qwqweeo123/dsh-wallpaper

> 标签: background, dsh, dsh-plugin, theme, wallhaven, wallpaper

## 简介

Apply a global wallpaper to the whole interface — every surface is re-composited so the image shows through consistently, from the wallhaven.cc marketplace or a local upload.
