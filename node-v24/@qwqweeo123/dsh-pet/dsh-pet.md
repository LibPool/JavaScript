# @qwqweeo123/dsh-pet

> 标签: codex-pets, desktop-pet, dsh, dsh-plugin, overlay, pet, sprite

## 简介

A draggable pet that lives in its own transparent, always-on-top window: move it anywhere on screen, watch it react to agent state (running / awaiting approval / error), and browse the codex-pets.net marketplace.
