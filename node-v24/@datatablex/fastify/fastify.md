# @datatablex/fastify

> 标签: data-table, datatable, export, fastify, filter, kysely, pagination, postgresql, server-side

## 简介

Fastify and Kysely query engine for DataTableX: an allowlisted field config, a ready-made route, query to SQL translation and streaming export.
