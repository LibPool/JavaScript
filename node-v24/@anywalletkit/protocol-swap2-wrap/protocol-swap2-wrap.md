# @anywalletkit/protocol-swap2-wrap

> 标签: permissionless, weth, wrap

## 简介

Wrap and unwrap the native coin (ETH↔WETH, BNB↔WBNB, POL↔WPOL…) on 13 EVM chains as a swap2 venue: 1:1, no pool, wrapped tokens verified on-chain.
