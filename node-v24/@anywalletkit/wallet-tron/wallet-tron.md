# @anywalletkit/wallet-tron

> 标签: bip32, secp256k1, trc20, tron, wallet

## 简介

Tron wallet for Any Wallet Kit: BIP-32 m/44'/195'/0'/0/i accounts, TRX and TRC-20 transfers against a full-node HTTP API, no tronweb.
