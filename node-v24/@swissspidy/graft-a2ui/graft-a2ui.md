# @swissspidy/graft-a2ui

> 标签: a2ui, generative-ui, graft

## 简介

A2UI v0.9 surfaces as a Graft build's UI: the Graft catalog, snapshots for the verifier, static validation, refs and migrations. Built on @a2ui/web_core; no rendering.
