# term-highlight

> 标签: css-highlight, custom-highlight-api, dom, find, highlight, highlighter, mark, regex, search, text, typescript

## 简介

Highlight words, phrases, and regex patterns inside a DOM subtree using the CSS Custom Highlight API or DOM-span wrapping. Zero runtime dependencies, TypeScript, ESM + CJS.
