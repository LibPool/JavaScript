# trilean-sql

> 标签: postgres, predicate, predicate-pushdown, query-builder, rules-engine, sql, sqlite, three-valued-logic, trilean

## 简介

Compiles a trilean predicate tree into a parameterised SQL WHERE fragment, pushing three-valued logic down onto the database's own NULL propagation instead of evaluating it in process.
