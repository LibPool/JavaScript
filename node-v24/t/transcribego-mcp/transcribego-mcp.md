# transcribego-mcp

> 标签: audio, mcp, model-context-protocol, transcribego, transcription

## 简介

Local MCP (stdio) proxy for TranscribeGo: forwards tools to the remote TranscribeGo MCP and adds local audio file uploads via direct-to-Blob transfer.
