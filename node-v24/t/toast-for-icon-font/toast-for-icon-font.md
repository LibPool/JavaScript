# toast-for-icon-font

> 标签: toast-for-icon-font

## 简介

官方toast组件只支持显示`success`，`loading`两种icon，因此需要一个更加个性化的toast组件。 npm一些组件包只支持图片又不支持iconFont的形式 此组件依赖于[wepyjs](https://github.com/wepyjs/wepy)，如果没有使用`wepyjs`将无法使用 ## 使用
