# templator-generator

> 标签: code generator, generate, generate generator, generate template, generator, generator generator, project templater, project templator, template, template generator, templator

## 简介

This is a project that templates projects (creates generator for them), and generates projects from the generated template generators. It aids and facilitates the creation of dynamic/configurable/smart code templates
