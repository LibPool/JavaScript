# terum-skills-report

> 标签: claude-code, skills, terum

## 简介

Offline collector for Terum's free Claude Code skills report. Writes your skills, the scripts they reference and locally derived usage counts to one folder you review, zip and send yourself. No network, no install, nothing left behind.
