# ts-ioc-container

> 标签: awilix-alternative, clean-api, container, decorators, dependency-injection, dependency-injection-container, di, hook, inject, inversify-alternative, inversion-of-control, ioc, ioc-container, lazy-injection, lifecycle-hooks, no-global-container, scope, scoped-dependencies, service-container, tsyringe-alternative, typescript, typescript-di, typescript-ioc

## 简介

Fast, lightweight TypeScript dependency injection container with a clean API, scoped lifecycles, decorators, tokens, hooks, lazy injection, customizable providers, and no global container objects.
