# timetopost-mcp

> 标签: ai-agent, claude, instagram, mcp, mcp-server, model-context-protocol, scheduler, social-media, tiktok, timetopost, twitter

## 简介

Official MCP server for TimeToPost — let AI agents (Claude, Cursor, any MCP client) schedule and publish social media posts to Instagram, TikTok and X, and read engagement analytics.
