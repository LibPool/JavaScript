# tiertwo

> 标签: agents, claude-code, cursor, governance, mcp, tiertwo

## 简介

One command that connects this machine's AI agents to Tier Two: registers the hosted MCP endpoint in every host, finds the systems your agents already use, and (reversibly) routes their calls through Tier Two.
