# trance-richtext-editor

> 标签: content-editable, editor, html, lexical, plug-and-play, react, renderer, rich-text-editor, trance, wysiwyg

## 简介

A plug-and-play rich text editor for React, powered by Lexical. Drop-in editor with HTML output and a beautiful renderer component.
