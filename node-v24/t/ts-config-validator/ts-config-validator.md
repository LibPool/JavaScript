# ts-config-validator

> 标签: config, jest, jsdoc, json, schema, typescript, validation, yaml

## 简介

Validate YAML/JSON config files against TypeScript interfaces with JSDoc constraints. No code generation — constraints live in JSDoc comments, validation runs at test time via the TS compiler API.
