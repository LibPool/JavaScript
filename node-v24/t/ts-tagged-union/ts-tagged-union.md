# ts-tagged-union

> 标签: Algebraic-Data-Types, coproduct, discriminated-union, exhaustive, functional, functional-programming, narrowing, pattern-matching, tagged-union, type-guard, type-predicate

## 简介

A modern TypeScript library designed to reduce boilerplate for tagged unions, also known as discriminated unions. This library is also an implementation of algebraic data types
