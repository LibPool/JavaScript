# tubeship

> 标签: captions, cli, creator, playlist, publish, schedule, subtitles, upload, youtube, youtube-api

## 简介

A publishing CLI for YouTube: one JSON manifest per video (captions, thumbnail, playlists, schedule), batch uploads that resume, sync for videos already up, safe by default (plan + confirm, --dry-run). Uses the YouTube Data API v3.
