# thaiqr-cli

> 标签: cli, emv, emvco, payment, promptpay, qr, qrcode, thai, thailand

## 简介

A small CLI for working with Thai QR (TLV) data. The npm package name is `thaiqr-cli`, but the installed command is `thaiqr`. Implemented in TypeScript and designed to run with Bun (also works with Node.js when using Bun-compatible commands).
