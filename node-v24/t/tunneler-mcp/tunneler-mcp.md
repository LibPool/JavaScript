# tunneler-mcp

> 标签: agent, claude, email, mcp, reddit, tunneler

## 简介

MCP server for Tunneler — let an agent manage governed social/email identities (post, reply, DM, vote, inbox, email) through guardrails, approvals, and an arm switch.
