# thegoldbarometer-mcp

> 标签: finance, gold, mcp, model-context-protocol, open-data

## 简介

MCP server for The Gold Barometer: today's gold buying-conditions score, the published history, and what followed similar readings since 1971.

- 官网：https://thegoldbarometer.com/data/
