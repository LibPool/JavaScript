# tglider

> 标签: code-analysis, javascript, llm, mcp, refactoring, semantic-navigation, typescript

## 简介

Compiler-backed TypeScript and JavaScript code intelligence for coding agents through MCP. Navigate symbols and calls, inspect diagnostics and dependencies, and preview edits and refactors.
