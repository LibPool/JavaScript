# tsyringe-react

> 标签: dependency, dependency injection, hooks, injection, javascript, react, typescript

## 简介

A way to implement tsyringe together with react hooks, use it if you need dependency injection without interfaces or with a small container.

- 源码仓库：git+https://github.com/ramon-sg/tsyringe-react.git
