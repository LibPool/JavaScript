# tracegrab

> 标签: ai, behavioral-testing, debugger, mcp, runtime, verification

## 简介

Prove AI-changed code still behaves correctly at runtime. Drive handlers with sequenced API calls, trace the real data flow, diff behavior against a baseline, and gate the change on it.
