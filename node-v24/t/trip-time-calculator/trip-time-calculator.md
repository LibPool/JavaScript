# trip-time-calculator

> 标签: JavaScript

## 简介

**出発地・到着地・出発日時・フライト時間から、到着日時と時差を計算できる CLI アプリケーションです。**   [Luxon](https://moment.github.io/luxon/) と [Enquirer](https://www.npmjs.com/package/enquirer) を使用して、タイムゾーンも考慮した正確な時間計算を行います。
