# temporal_rs

> 标签: JavaScript

## 简介

Native Node.js and WASM bindings for [temporal_rs](https://github.com/boa-dev/temporal) — the Rust implementation of the [TC39 Temporal proposal](https://tc39.es/proposal-temporal/).
