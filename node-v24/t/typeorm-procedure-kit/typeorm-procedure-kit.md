# typeorm-procedure-kit

> 标签: continuous-query-notification, data-source, database-notifications, entity-metadata, listen-notify, nestjs, oracle, oracle-cqn, oracledb, orm, pg, plsql, postgres, postgresql, procedure-call, query-runner, raw-sql, refcursor, serializers, sql-transactions, stored-procedures, type-safe, typeorm, typeorm-0.3, typeorm-fork, typescript

## 简介

Enterprise TypeORM toolkit for Oracle and PostgreSQL with strongly-typed repositories, stored procedures, multi-database entity inheritance, raw SQL orchestration, notifications, and an enhanced bundled TypeORM runtime
