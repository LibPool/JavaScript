# tokenez

> 标签: ai, claude, claude-code, copilot, cursor, dashboard, local-first, tokens, tracker, usage

## 简介

Tokenez — local, private AI usage tracker. Captures real token/quota usage from Claude Code, GitHub Copilot, Cursor, Antigravity, Windsurf and browser AI sites, and powers your live dashboard at tokenez.tech/app. All data stays on your machine.
