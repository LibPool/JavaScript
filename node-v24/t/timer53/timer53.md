# timer53

> 标签: JavaScript

## 简介

Timer53 is an extension of `setTimeout/setinterval` method, and provides with following functionalities: - Can change config on the go! - Timer will ony start once callback and interval is provided. - Can define interval in milliseconds(ms), seconds(s)
