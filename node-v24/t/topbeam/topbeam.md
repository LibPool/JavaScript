# topbeam

> 标签: ai-coding, audit, claude, claude-code, cli, evidence, git, local-first, offline, progress-tracker, project-status, provenance, topbeam, transcript, verification, vibe-coding

## 简介

Honest project board for Claude Code. Reads your transcripts and git deterministically — no LLM — and labels every claim by evidence: file, test, human approval, or not verified. Local-first.
