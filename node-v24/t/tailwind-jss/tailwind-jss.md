# tailwind-jss

> 标签: JavaScript

## 简介

An experimental babel plugin that allows tailwind classes to be described as an object.

## 官网

- npm 页面：https://www.npmjs.com/package/tailwind-jss

## 历史版本号

## 获取地址

- npm 安装：`npm install tailwind-jss`
- npm registry：https://registry.npmjs.org/tailwind-jss
- Node 要求：>=10
