# tosch-hl7

> 标签: component, field, health-informatics, healthcare, hl7, interoperability, javascript, medical, message, parser, segment, typescript

## 简介

A TypeScript/JavaScript library to work with HL7 messages in a simple and intuitive way. Features optimized internal structure, consistent 1-based indexing, field modification, and minimal optional chaining.
