# tanstack-aspnet-data

> 标签: asp.net, aspnet, devextreme, ef-core, efcore, tanstack, tanstack-table

## 简介

Server-side data adapter: TanStack Table state to DevExtreme.AspNet.Data wire format (ASP.NET Core + EF Core). No DevExtreme UI required.
