# tool-call-validator

> 标签: function-calling, json, json-schema, llm, repair, tool-call

## 简介

Parse and validate LLM tool-call JSON payloads. Loose JSON parsing (repairs common LLM mistakes) + JSON-Schema-subset validation. Zero dependencies.
