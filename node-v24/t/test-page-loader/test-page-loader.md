# test-page-loader

> 标签: fixture, html, iframe, jasmine, load, loader, page, qunit, test, window

## 简介

Simple helper for unit testing with JavaScript Testing Frameworks (e.g. Jasmine, QUnit, etc.), to load HTML pages as fixtures.
