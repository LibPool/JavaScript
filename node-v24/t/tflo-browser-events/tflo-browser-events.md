# tflo-browser-events

> 标签: analytics, browser, cep, event-pattern-matching, first-party, privacy, rust, tflo, wasm

## 简介

Capture browser events, transform them into typed domain signals with tflo-cep (Rust/WASM), and ship them to GA4 / a first-party collector / any HTTP sink.
