# tapalcatl

> 标签: JavaScript

## 简介

This serves as a reference implementation of [Tapalcatl 2](https://medium.com/@mojodna/tapalcatl-cloud-optimized-tile-archives-1db8d4577d92) for JavaScript. It includes support for block-aligned reads (and subsequent caching) of remote Tapalcatl archives.
