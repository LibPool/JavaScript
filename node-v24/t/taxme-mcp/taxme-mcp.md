# taxme-mcp

> 标签: JavaScript

## 简介

MCP server for the Canton of Bern tax portal TaxMe / BE-Login — read AND fill tax returns (open, navigate, set fields, results, gated submit) via SwissID/AGOV browser automation, with cached sessions (storageState) that survive restarts
