# tympan

> 标签: ai, chromium, converter, deck, deterministic, generated, html, pdf, playwright, proposal, sections

## 简介

Deterministic, secure, fast HTML→PDF converter: one semantic section per page, runtime print-CSS defeated, self-verifying output. Zero config.
