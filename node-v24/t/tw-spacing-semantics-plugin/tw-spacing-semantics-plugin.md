# tw-spacing-semantics-plugin

> 标签: css-custom-properties, design-system, design-tokens, gap, margin, padding, refactoring-ui, semantic-spacing, spacing, tailwind-css-v4, tailwind-v4, tailwindcss, tailwindcss-plugin

## 简介

Semantic spacing utilities for Tailwind CSS v4 — isolated p-*, m-*, and gap-* classes built on --space-* custom properties. Fully independent from Tailwind's native spacing scale.
