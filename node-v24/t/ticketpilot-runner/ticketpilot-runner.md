# ticketpilot-runner

> 标签: ai-agent, automation, claude, devops, jira, self-hosted

## 简介

TicketPilot runner — the customer-side agent host. Polls your Jira, runs jailed AI agents in your local checkouts, opens PRs, executes approved deploys and audits. All credentials and code stay on this machine; the runner only dials out.
