# token-damage

> 标签: ai, claude-code, cli, codex, gemini-cli, llm, opencode, receipt, statusline, tokens, usage

## 简介

The receipt your AI agent never gave you. Reads the local logs of Claude Code, Codex, Gemini CLI and OpenCode and prints an itemized receipt, or watches today live. Uploads nothing.
