# tokemitsu

> 标签: analytics, claude-code, cost, gitnexus, hooks, mcp, rtk, tokens

## 简介

Claude Code only: one-command setup for rtk and GitNexus, a cheap-model delegation pattern, and a local dashboard showing tokens/dollars spent vs saved.
