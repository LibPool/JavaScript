# twill-engine

> 标签: JavaScript

## 简介

The [Twill.js](https://raw.githubusercontent.com/rostber/twill/master/dist/twill.js) is an ultra small (2k gzip) JS templating engine. Uses a part of dom to compile a dynamic html.
