# tm-vue-auth-modified

> 标签: auth, authentication, json, jwt, plugin, token, vue, vue.js, web

## 简介

Vue.js token based authentication plugin. Supports simple token based and Json Web Tokens (JWT) authentication. (Forked for fixed google scopes). Please go to official repository.
