# translate-kit

> 标签: ai, ai-translation, ast, build-time, codegen, i18n, internationalization, jsx, localization, next-intl, nextjs, translate, translation, vercel-ai-sdk

## 简介

AI-powered i18n pipeline for build time. Scan, transform, and translate JSX/TSX with any AI model. Zero runtime cost. Compatible with next-intl.
