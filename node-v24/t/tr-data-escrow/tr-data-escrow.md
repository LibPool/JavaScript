# tr-data-escrow

> 标签: archive, crypto, encryption, escrow, gdpr, jwe, jwk, vault

## 简介

Cryptographic escrow of JSON data and files into a filesystem vault. Data and file keys are encrypted to a public escrow key (RSA-OAEP or ECDH-ES) as JWE; files are streamed AES-256-GCM. Each escrow is a self-contained, atomically placed directory.
