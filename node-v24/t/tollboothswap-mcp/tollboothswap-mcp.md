# tollboothswap-mcp

> 标签: 0x, ai-agents, base, defi, honeypot, jupiter, mcp, mcp-server, micropayments, modelcontextprotocol, rug-pull, solana, token-swap, usdc, x402

## 简介

MCP server for Tollbooth: non-custodial token swaps and honeypot/rug-pull checks for AI agents on 8 chains (Solana, Base, Ethereum, Arbitrum, Polygon, Optimism, BSC, Avalanche), paid per-call in USDC via x402
