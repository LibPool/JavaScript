# talrtc-openclaw-plugin

> 标签: channel, openclaw, openclaw-plugin, talrtc

## 简介

OpenClaw 插件，通过 WebSocket 连接 TalRTC 实时通信服务，为 OpenClaw 提供 RTC 流接入能力。
