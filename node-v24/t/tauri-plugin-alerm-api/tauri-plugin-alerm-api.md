# tauri-plugin-alerm-api

> 标签: JavaScript

## 简介

Android のネイティブ [`AlarmManager`](https://developer.android.com/reference/android/app/AlarmManager) API を Tauri アプリから利用するプラグインです。指定した時刻にアラームを設定し、発火時にシステム通知を表示します。
