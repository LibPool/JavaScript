# tailwind-typescript-plugin

> 标签: class-names, class-variance-authority, className, css-in-js, cva, developer-tools, ide, jsx, language-service, linter, react, tailwind, tailwind-css, tailwind-variants, tailwindcss, tsx, typescript, typescript-plugin, validation, vscode

## 简介

TypeScript Language Service plugin that validates Tailwind CSS class names in JSX/TSX files. Catches typos and invalid classes in real-time with support for tailwind-variants and class-variance-authority.
