# tl2api

> 标签: json, mcp, mcp-server, model-context-protocol, no-api, playwright, scraper, timeline, twitter, x

## 简介

Local API + MCP server that returns your X (Twitter) home timeline as JSON by driving a real logged-in browser — no X API key.
