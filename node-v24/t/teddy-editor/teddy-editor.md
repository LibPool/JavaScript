# teddy-editor

> 标签: component, editor, lightweight, react, reactjs, rich-text, simple, tailwind, teddy-editor, text-editor, typescript

## 简介

A lightweight WYSIWYG editor built with React and Tailwind CSS. Fully customizable, TypeScript-ready, and easy to integrate into any modern React application.
