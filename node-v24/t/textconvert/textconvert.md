# textconvert

> 标签: camelcase, clear-text, cli, convention, conventions, convert, dash, data-privacy, email-validation, kebabcase, language-detection, log-sanitization, mask, naming, numbers-to-words, pascalcase, phone-number, phone-validation, pii, pii-redaction, privacy, redact, redaction, sanitize, snakecase, text, typescript, underscore, url-validation, validation

## 简介

Lightweight, dependency-free text utilities for TypeScript -- redact PII (emails, phone numbers) from free-form text, plus case conversion, validation, and analysis.
