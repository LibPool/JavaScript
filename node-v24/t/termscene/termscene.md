# termscene

> 标签: animation, asciinema, demo, deterministic, gif, mock, mp4, puppeteer, readme-gif, screencast, terminal, terminal-gif, vhs, video, webm

## 简介

Author a mock terminal you fully control and render it to a deterministic mp4/gif/webm. Script the commands and output in a small scene file — no recording, no real shell. Built for a coding agent to drive.
