# tinybase-mergeable-history

> 标签: checkpoints, crdt, history, local-first, mergeable, mergeablestore, redo, sync, tinybase, undo, undo-redo

## 简介

Persistent, syncable, CRDT-aware undo/redo history for TinyBase MergeableStore. Unlike built-in Checkpoints, history is stored as data inside the store, so it survives reloads and merges across clients.
