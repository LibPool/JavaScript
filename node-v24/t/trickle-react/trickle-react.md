# trickle-react

> 标签: ai, anthropic, hooks, llm, openai, partial-json, react, streaming, structured-output, trickle-json, typescript, useobject, zod

## 简介

React hooks for streaming structured output from LLMs — useStreamingObject(schema, startStream) gives you a typed, progressively-filling object with per-field loading status. Built on trickle-json.
