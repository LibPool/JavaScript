# tc-roman-number

> 标签: algoritmo-arabico, algoritmo-romano, arabic, arabico, conversor, conversor-de-algoritmo-romano, converter, converter-numeral-roman, number, number-arabic, number-roman, numeral, numeral-arabic, numeral-roman, numero, numero-arabico, numero-romano, roman, romano

## 简介

**Esta biblioteca tem como finalidade converter algarismos romanos em arábicos, fazendo também o caminho inverso, em aplicação web.** Ela possui duas funções, uma que recebe uma string de algarismos romanos e outra que faz o caminho inverso.
