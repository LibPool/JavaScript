# terminal-bridge

> 标签: ai-chat, claude, remote-access, tailscale, terminal, tmux, web-terminal, websocket, xterm

## 简介

Access a full web terminal and AI chat interface from anywhere. Built with xterm.js, tmux, and the Claude Agent SDK for macOS and Linux.
