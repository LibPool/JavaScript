# turath-mcp

> 标签: ai, arabic, author, books, claude, islamic, mcp, mcp-server, search, turath, turath.io

## 简介

An MCP server that gives AI clients accurate access to the turath.io library — authors, books, pages, and search — over stdio and Streamable HTTP.
