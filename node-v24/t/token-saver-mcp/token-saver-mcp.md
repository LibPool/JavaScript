# token-saver-mcp

> 标签: alerts, anthropic, claude, claude-code, cost-reduction, developer-tools, llm, mcp, token-optimization, token-saver, warnings

## 简介

MCP plugin that fires warnings, errors, and alerts when AI token usage is wasteful. Works with any MCP client. Auto-suppresses logs and ignored history to keep context lean.
