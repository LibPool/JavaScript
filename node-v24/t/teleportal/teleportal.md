# teleportal

> 标签: e2ee, protocol, provider, runtime, server, storage, subdocs, transport, yjs

## 简介

A storage, transport & runtime agnostic Y.js server/provider. Built on web primitives, supports subdocs, and handles everything without in-memory storage. Perfect for collaborative apps! 🚀
