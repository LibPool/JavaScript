# today_auto_cli

> 标签: cicd, clone, create

## 简介

npm install today_auto_cli -g #创建VUE项目 today_auto_cli create <project-name> #克隆git仓库项目 today_auto_cli clone <git-repo-url> #查看帮助 today_auto_cli --help #查看版本 today_auto_cli --version #删除项目 today_auto_cli delete <project-name>
