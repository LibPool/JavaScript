# tile-maker

> 标签: Geojson, Shapefile, Simplification, Topojson

## 简介

Node web services and example front end to convert a collection of ESRI shapefiles into a complete administrative geography; e.g USA, states, counties, census tracts, census block groups into TopoJSON tiles optimised for a series to map zoomlevels. Typica
