# tsai-cli

> 标签: agents, ai, classification, claude-code, cli, jev, system-one

## 简介

Unofficial, unaffiliated CLI for the TypeSafe AI System One API, built for testing and prototyping. Typed judgments (noul, choice, score) for shells, CI, and coding agents.
