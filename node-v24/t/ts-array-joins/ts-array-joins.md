# ts-array-joins

> 标签: aggregation, array, array-operations, commonjs, composite-keys, data-manipulation, data-processing, data-transformation, database, esm, functional, group-by, grouping, immutable, inner-join, join, json, left-join, lodash-alternative, multi-key, one-to-many, one-to-one, orm, prisma, ramda-alternative, sql-join, strongly-typed, type-safe, typescript, zero-dependencies

## 简介

Strongly-typed TypeScript utilities for array grouping, SQL-like joins, and data aggregation. Zero dependencies, full type inference, O(n+m) performance.
