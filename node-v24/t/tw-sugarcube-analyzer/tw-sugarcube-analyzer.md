# tw-sugarcube-analyzer

> 标签: sugarcube, twee, twine, typescript

## 简介

Shared analysis core for SugarCube's author-populated containers: recovers the types of setup / State.variables / State.temporary / settings members from their assignments, and projects .twee passages to TypeScript.
