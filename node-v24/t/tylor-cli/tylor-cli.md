# tylor-cli

> 标签: academic, agent, claude, claude-code, cli, mcp, pdf, skill, tylor, typst

## 简介

CLI for Tylor — operate on your Typst projects from the terminal or AI agents (list/create, pull/push, compile, public links, version history). Self-installing Claude Code skill.
