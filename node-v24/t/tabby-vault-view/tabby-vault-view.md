# tabby-vault-view

> 标签: profiles, ssh, ssh-config, tabby, tabby-plugin, terminal

## 简介

Connection vault for Tabby: a responsive grid of SSH hosts and other profiles with two-way editing of Tabby profiles and ~/.ssh/config
