# thelounge-plugin-exec

> 标签: exec, irc, thelounge

## 简介

Recreates irssi's `/exec` command for [thelounge](https://thelounge.chat), which allows you to run arbitrary commands on your host and send the output to IRC. Useful for playing ASCII art, cowsay, etc. Thank you to MiniDigger's shortcuts [plugin](https://
