# torchic

> 标签: autograd, browser, deep-learning, machine-learning, neural-network, sharedarraybuffer, simd, tensor, typescript, wasm, webassembly, webgpu

## 简介

In-browser neural network library with reverse-mode autograd and three interchangeable compute backends: JS Web Workers, SIMD Rust/WebAssembly, and WebGPU.
