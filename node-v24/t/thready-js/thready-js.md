# thready-js

> 标签: async, concurrent, multithreading, parallel, performance, thread-pool, threads, typescript, web-worker, worker, worker-pool

## 简介

A lightweight, type-safe thread pool manager for JavaScript and TypeScript. Bring your own worker - we handle the pooling.
