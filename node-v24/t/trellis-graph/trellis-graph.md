# trellis-graph

> 标签: cli, code-intelligence, coding-agents, context-graph, mcp, tree-sitter, trellis

## 简介

Trellis — an open-source context graph engine for large codebases. Persistent, local-first architectural maps for coding agents, with an embedded MCP server.
