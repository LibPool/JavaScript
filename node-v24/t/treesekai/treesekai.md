> 标签: hatsune, hatsune miku, miku, miku hatsune, vocaloid, vocaloid hatsune miku, vocaloid miku

## 简介

This is a cli tool based on Hatsune Miku from Project Sekai. 
Currently, it has greetings for all of the different miku versions and descriptions for the sekai's that each of those mikus reside in.
