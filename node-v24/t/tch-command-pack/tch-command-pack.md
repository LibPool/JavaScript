# tch-command-pack

> 标签: tch

## 简介

* 增加代码的压缩功能,如果是线上则压缩,测试服务器不压缩. #### 0.3.0   * 增加了一个tch pack -t 09284-09295,可以根据两个里程碑打包之间的改动代码 #### 0.1.6   * 增加了一个tch pack -n 功能,只打包非构建的代码,加快打包速度
