# teamlayer-mcp

> 标签: mcp, model-context-protocol, tasks, teamlayer

## 简介

MCP server for TeamLayer: create, search and edit tasks, comments and attachments from Claude, Cursor or any MCP client.

- npm registry：https://registry.npmjs.org/teamlayer-mcp
