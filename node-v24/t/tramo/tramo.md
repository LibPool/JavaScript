# tramo

> 标签: agent, ai, automation, embeddable, node-editor, react, workflow

## 简介

Embeddable workflow editor + runtime. Umbrella meta-package re-exporting @tramo/editor, @tramo/spec, @tramo/runtime, and every first-party brand integration pack from one install.
