# txt-csv-to-json

> 标签: convert ralational data to json, convert text data file to json, csv to json, text to json, txt to json

## 简介

A node module to read relational data from any ASCII text data file, mainly in (.txt) or (.csv) extension, and to convert the data in to JSON format.
