# tracklution-mcp

> 标签: ai-agent, claude-code, conversion-tracking, cursor, mcp, mcp-server, model-context-protocol, server-side-tracking, stdio, streamable-http, tracklution, windsurf

## 简介

Discovery wedge for the Tracklution MCP server at https://mcp.tracklution.com/mcp. Today this is an alias of the `tracklution` package and prints the agent install protocol. Future versions will offer a local stdio<->Streamable-HTTP MCP proxy for clients
