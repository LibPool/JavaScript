# timeline-format

> 标签: date, formatTime, timeline

## 简介

该模块调用函数回后返回类似于“刚刚，几分钟前，几小时前，几天前等”     传入一个日期参数,格式为"YY/MM/DD HH:MM:SS" 例："2019/07/15 15:26:46"
