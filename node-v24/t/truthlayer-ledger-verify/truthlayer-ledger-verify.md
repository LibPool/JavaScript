# truthlayer-ledger-verify

> 标签: audit, cli, ed25519, ledger, merkle-proof, offline-verifier, opentimestamps, truthlayer, verification

## 简介

Standalone Node CLI — verifies a tenant's daily seals from public artifacts alone (public tenant registry, public seals, OTS proofs). No Cloudflare dependency: this is what a verifier runs to check TruthLayer's claims without touching TruthLayer's infrast
