# tracepad

> 标签: agents, evals, evaluation, llm, llm-observability, observability, opentelemetry, otlp, prompts, self-hosted, tracing

## 简介

Tracing, prompts, scores and evals for Node LLM apps, on OpenTelemetry — the client for Tracepad, the single-binary self-hosted LLM observability server
