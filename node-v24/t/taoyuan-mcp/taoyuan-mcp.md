# taoyuan-mcp

> 标签: ai-music, chatgpt, claude, mcp, mcp-server, model-context-protocol, music, music-generation, song, songwriting, taoyuan

## 简介

Taoyuan MCP server: write an original song for one person — lyrics, two full versions and cover art in about a minute. stdio proxy for https://api.musicsforyou.com/mcp
