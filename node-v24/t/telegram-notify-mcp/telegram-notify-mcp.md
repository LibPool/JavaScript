# telegram-notify-mcp

> 标签: botfather, mcp, model-context-protocol, notifications, telegram

## 简介

MCP connector/server that sends Telegram notifications via your own BotFather bot (BYOB), with Phase 2 inbound reply routing and inline approval buttons.
