# ticatec-log4bs

> 标签: JavaScript

## 简介

新的logger注册在window对象中，所以只需要在系统启动的时候引入即可。不需要在每个模块单独引入。   logger有四个级别，分别是 ``` logger.debug = console.debug logger.info = console.info logger.warn = console.warn logger.error = console.error ```
