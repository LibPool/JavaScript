# table-diff

> 标签: ci, cli, compare, comparison, csv, data, dataset, diff, json, jsonl, keyed, markdown, primary-key, reconcile, reconciliation, rows, table, tabular, tsv

## 简介

Diff two tables (CSV, TSV, JSON, JSONL) by key from the command line — added, removed, and field-level changes. Colored terminal output, Markdown for PR comments, or JSON. Powered by rowset-diff.
