# tokenwise-tracker

> 标签: ai, analytics, cost-tracking, database, firebase, firebase-integration, firestore, langchain, llm, logging, metrics, mongodb, mongodb-atlas, monitoring, openai, plug-and-play, sqlite, token-usage, zero-config

## 简介

A lightweight, plug-and-play package to monitor OpenAI API costs, token usage, and performance with SQLite, Firebase, and MongoDB support. Zero configuration Firebase integration.
