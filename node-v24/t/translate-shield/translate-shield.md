# translate-shield

> 标签: accessibility, browser-translation, dom, google-translate, i18n, mutationobserver, nextjs, notfounderror, react, removechild

## 简介

Keeps React and Next.js apps correct when a browser translator rewrites the DOM: no crash, no frozen values, and no flash of the original language.
