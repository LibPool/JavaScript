# trama-connectors

> 标签: connector, ecommerce, headless, platform-agnostic, shopify, trama, webflow, wix

## 简介

Open-source platform connectors that map Wix, Shopify, and Webflow APIs to a single canonical schema (TramaProduct, TramaCart, TramaCollection). The connector layer behind Trama — public so you can audit it, extend it, or self-host it.
