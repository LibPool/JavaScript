# tusk-mcp

> 标签: agent, ai, database, mcp, model-context-protocol, postgres, postgresql, read-only, schema, sql

## 简介

PostgreSQL MCP server for AI agents. Schema introspection, SELECT-only query execution, and opt-in write access per target.
