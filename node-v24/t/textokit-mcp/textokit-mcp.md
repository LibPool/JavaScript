# textokit-mcp

> 标签: agents, api, argentina, base, fx-rates, mcp, model-context-protocol, usdc, web-reader, x402

## 简介

MCP server for tienda.textokit.store: 17 pay-per-call x402 tools on Base (web reader, FX and crypto rates, Argentine data, Rioplatense Spanish text) plus free catalog and samples. Pays with the buyer's own wallet.
