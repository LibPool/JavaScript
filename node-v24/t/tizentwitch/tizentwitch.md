# tizentwitch

> 标签: JavaScript

## 简介

TizenTwitch 3.0.0 - Massive update: enhanced ad blocking with MutationObserver, playback controls (play/pause/seek/volume/mute/fullscreen/quality), stream info overlay, settings panel with toggle switches, Twitch theme, chat overlay with positioning, CORS
