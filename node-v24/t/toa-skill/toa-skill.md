# toa-skill

> 标签: agent-skills, claude-code, codex, cursor, donate, open-source, skills

## 简介

Donate your unused AI plan usage to curated open source projects: installs the TOA agent skill for Claude Code, Codex, Cursor, Gemini CLI and more, and spends leftover usage before your weekly reset.
