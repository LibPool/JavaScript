# tiles2bitsy

> 标签: JavaScript

## 简介

A simple nodejs client tool to generate bitsy graphics from an image. It generates a file called gamedata.txt. You can import the file text content to the gamedata textarea from the Bitsy Editor. Or share the file with others.
