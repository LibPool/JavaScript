# text-transition-animator

> 标签: animate, animation, dom, frontend, smooth, text, text-animation, text-effect, text-transition, transition, ui-effect, web-animation

## 简介

A lightweight utility for smoothly animating the transition between any two texts on web pages. You provide the texts, the library handles the animation.
