# torny

> 标签: greasemonkey, tampermonkey, torn, torn.com, tornpda, typescript, userscript, violentmonkey

## 简介

Framework and build toolkit for Torn.com userscripts that run on desktop userscript managers and TornPDA from one TypeScript codebase.
