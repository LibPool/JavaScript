## 简介

Tariff Exposure Monitor — live US import tariff calculator MCP server. Looks up any HTS code, returns an estimated stacked rate (MFN + Section 301 + Section 232) and flags the November 10, 2026 Section 301 exclusion expiry. 19,856 HTS codes. Free, no sign
