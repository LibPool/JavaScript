# tunasync-unity-mcp

> 标签: claude, codex, mcp, unity, vrchat

## 简介

MCP server for driving the Unity Editor (VRChat-aware): C# eval, scene queries, NDMF bakes, VRChat uploads, logs and a built-in recipe library. Pairs with the UnityMCP editor plugin over TCP.
