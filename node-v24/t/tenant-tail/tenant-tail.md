# tenant-tail

> 标签: attestation, certificate, cli, governance, provenance, rust, tenant, verification

## 简介

The tenant-tail CLI: a verify-only toolkit that re-checks a factory's run-side paperwork (governance certificate, provenance) with no trust in the producer. Ships the prebuilt binary; no Rust toolchain required.
