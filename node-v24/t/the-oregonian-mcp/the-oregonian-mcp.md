# the-oregonian-mcp

> 标签: ai, claude, mcp, model-context-protocol, news, newspaper, oregonian, oregonlive, rss

## 简介

MCP server for OregonLive.com / The Oregonian newspaper — provides tools for fetching news, sports, weather, and more via RSS feeds, plus ad support.
