# toomux

> 标签: ai-agents, anthropic, claude, claude-code, terminal, tmux, tui

## 简介

Claude Code, minus the babysitting: every session on one screen in tmux, handover to a fresh session before context gets slow and expensive, and recovery from restarts and usage limits.
