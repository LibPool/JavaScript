# tokenoscopy

> 标签: ai-agents, anthropic, claude, claude-code, codex, flight-recorder, observability, openai-codex, session-replay, spend-control, stop-limit

## 简介

Flight recorder & spend control for AI agents and the apps that call Claude. Records Claude Code and Codex CLI sessions, enforces budgets, and puts stop-limits on production Anthropic API spend.
