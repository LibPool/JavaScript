# ts-communication

> 标签: delta, fins, ge-srtp, industrial-automation, inovance, invt, melsec, modbus, modbus-rtu, modbus-tcp, nodejs, omron, plc, s7, siemens, typescript, xinje

## 简介

工业 PLC 通讯库，支持 Siemens S7、Melsec MC、Omron FINS、Inovance、Invt、Delta、GE SRTP、XinJE 和 Modbus。
