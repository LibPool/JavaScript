# tldkit

> 标签: domain, esm, hostname, psl, public-suffix, public-suffix-list, subdomain, tld, tldts, tree-shakeable, zero-dependency

## 简介

A zero-dependency, ESM-first drop-in replacement for tldts and psl. Same API, same Public Suffix List, a fraction of the install size.
