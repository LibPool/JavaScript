# tailwindnext

> 标签: nextjs, prettier, reactjs, tailwind, tailwindcss

## 简介

This is a [Next.js](https://nextjs.org/) project bootstrapped with [`create-next-app`](https://github.com/vercel/next.js/tree/canary/packages/create-next-app). This project uses TailwindCSS with Tailwind Prettier Sort plugin.
