# tsubu-js

> 标签: bunsetsu, furigana, japanese, karaoke, language-learning, read-along, ruby, subtitles

## 简介

Renders one pre-segmented Japanese sentence for read-along: furigana that never move a character, and a highlight that is a pure function of time.
