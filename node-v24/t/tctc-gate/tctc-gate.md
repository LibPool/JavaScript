# tctc-gate

> 标签: ai-agents, authorization, erc-7303, ethereum, mcp, model-context-protocol, token-gating

## 简介

Token-gate any existing MCP server with ERC-7303 roles: grant is a mint, revoke is a burn — no server modification.
