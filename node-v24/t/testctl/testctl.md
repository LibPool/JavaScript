# testctl

> 标签: ci, claude-code, cli, e2e, electron, flutter, frappe, integration-test, jest, mcp, model-context-protocol, nextjs, playwright, plugin, react, supabase, test-runner, testing, vitest, vue, web

## 简介

Run Frappe, Flutter, Electron, Next.js (Vercel), Supabase, Web (React/Vue via Vitest/Jest), and E2E (Playwright / Flutter integration_test) tests with one command and a unified report. Ships as a Claude Code plugin.
