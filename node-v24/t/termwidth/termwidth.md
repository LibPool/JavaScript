# termwidth

> 标签: cli, cli-truncate, cpr, emoji, string-width, terminal, tui, unicode, wcwidth, width, wrap-ansi

## 简介

Measure terminal cell width from ground truth — probe the terminal itself, cache, then it's pure arithmetic. Drop-in for string-width / wrap-ansi / cli-truncate.
