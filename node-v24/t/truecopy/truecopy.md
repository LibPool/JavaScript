# truecopy

> 标签: bank-statement, browser, data-extraction, document-parsing, extract-tables, invoice, pdf, pdf-parser, pdf-parsing, pdf-table, schema, table-extraction, typescript, validation

## 简介

Extract tables from a PDF, a Word document, a paste or a CSV in TypeScript, and know when the extraction cannot be trusted. Learns each document's own shape, so a new issuer needs no new configuration.
