# throttle-frequency

> 标签: debounce, debounce-function, debouncing, frequency, load-balancing, throttle, throttle-frequency, throttle-function, throttling

## 简介

Tool to throttle execution frequency of any given function - time in milliseconds, no initial delay, optional scope declaration.
