# tauri-plugin-torchlight-api

> 标签: android, flashlight, ios, mobile, tauri, tauri-plugin, torch

## 简介

JavaScript/TypeScript bindings for tauri-plugin-torchlight: control the smartphone torch (on/off, brightness, availability, state and change events) from Tauri v2 apps on Android and iOS.
