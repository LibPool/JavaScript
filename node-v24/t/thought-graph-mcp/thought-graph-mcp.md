# thought-graph-mcp

> 标签: decomposition, llm, mcp, model-context-protocol, reasoning, thought-graph

## 简介

An MCP server that guides an LLM to decompose complex problems into a graph of reasoning steps, logs the process to Markdown, renders an interactive HTML graph, and lets you pinpoint and regenerate any step.
