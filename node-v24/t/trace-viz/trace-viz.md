# trace-viz

> 标签: 3d, blast-radius, canvas, dependency-graph, distributed-systems, grammar-of-graphics, latency, observability, particles, service-map, service-mesh, throughput, topology, trace-viz, visualization

## 简介

Visualize service topologies as living, re-projectable pictures. Every dimension is a knob: choose what a box is, bind any dimension to any visual channel, and drop into a 3D world where fail-closed dependencies carry blast radius.
