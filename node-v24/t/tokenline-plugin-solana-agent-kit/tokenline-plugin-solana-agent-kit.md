# tokenline-plugin-solana-agent-kit

> 标签: credit, solana, solana-agent-kit, tokenline, usepod, x402

## 简介

Tokenline plugin for Solana Agent Kit: credit scores for Solana agents from on-chain creator fees, pay-later AI compute on UsePod, repay and lock $ANSEM from the agent wallet.
