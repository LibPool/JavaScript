# t-stack-manager

> 标签: better-t-stack, claude-code, cli, cursor, scaffold, skill, template, typescript

## 简介

Remember your project setups: scaffold from saved better-t-stack templates and reapply the libraries, post-scaffold modifications, and agent skills you always add. A Claude Code skill backed by a TypeScript CLI.
