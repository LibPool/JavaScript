# terms-acceptance

> 标签: acceptance, audit, better-auth, clerk, compliance, consent, firebase, gdpr, legal, nestjs, re-acceptance, terms, terms-of-service, tos, typeorm

## 简介

Versioned, provable terms-of-service acceptance records. Storage-agnostic core plus adapters for TypeORM/NestJS, Better Auth, Clerk and Firebase Auth, and an optional React checkbox and re-accept modal.
