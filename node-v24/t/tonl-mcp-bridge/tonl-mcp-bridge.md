# tonl-mcp-bridge

> 标签: ai, anthropic, claude-4, cli, compression, cost-optimization, data-format, gemini, google-ai, gpt-5, json, llm, mcp, mcp-server, model-context-protocol, openai, rag, token-counter, token-optimization, tonl, typescript, yaml

## 简介

Reduce LLM token costs by 30-60% with TONL format. TypeScript library & CLI with MCP Server for bidirectional JSON/YAML ↔ TONL conversion.
