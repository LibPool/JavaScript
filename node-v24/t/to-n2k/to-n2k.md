# to-n2k

> 标签: JavaScript

## 简介

A JavaScript library to produce NMEA 2000 messages, based on messages data in [canboat](https://github.com/canboat/canboat/tree/master/analyzer).

## 官网

- npm 页面：https://www.npmjs.com/package/to-n2k

- 1.0.0
