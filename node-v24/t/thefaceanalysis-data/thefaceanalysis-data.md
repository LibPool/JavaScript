# thefaceanalysis-data

> 标签: dataset, face-analysis, face-shape, facial-measurements, fwhr, statistics

## 简介

Face measurement statistics from 102 faces (fWHR, midface ratio, symmetry, canthal tilt, pupillary distance), face/eye/lip/nose types and method thresholds, as JSON and CSV. Data CC BY 4.0, code MIT.
