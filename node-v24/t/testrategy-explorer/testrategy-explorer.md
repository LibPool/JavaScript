# testrategy-explorer

> 标签: ai, exploratory-testing, playwright, testrategy

## 简介

Testrategy の AI 探索的テスト実行ランナー。Testrategy で作成した実行を、あなたの PC または CI 上で Playwright + AI で動かします。

- npm 页面：https://www.npmjs.com/package/testrategy-explorer
