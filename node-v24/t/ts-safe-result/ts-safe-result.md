# ts-safe-result

> 标签: async, discriminated-union, either, err, error-handling, functional, monad, neverthrow, ok, promise, result, result-async, try-catch, type-safe, typescript

## 简介

A tiny, type-safe Result type for TypeScript with chainable async support. Handle errors as values, not exceptions.
