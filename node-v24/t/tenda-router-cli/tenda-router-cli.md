# tenda-router-cli

> 标签: change, communicate, control, dynamic, ip, reboot, router, tenda

## 简介

This package can be used to communicate with tenda router using nodejs at your will. It can be useful to change your IP Address (if your ISP allots dynamic IP Address to you), etc.
