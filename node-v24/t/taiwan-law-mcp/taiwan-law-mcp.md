# taiwan-law-mcp

> 标签: judgments, law, legal, mcp, mcp-server, model-context-protocol, regulations, taiwan

## 简介

Self-hosted MCP server for Taiwanese legal research: statutes (MOJ), court judgments (Judicial Yuan), constitutional interpretations, and legislative history. 14 tools, every result with official source URLs. Free, no API key.
