# ts-toasty.js

> 标签: alerts, customizable, display, javascript, messages, minimal, plugin, simple, toast, way

## 简介

A minimal JavaScript notification plugin that provides a simple way to display customizable toast messages on the web page with CSS3 transition effects. Refactor to Typescript.
