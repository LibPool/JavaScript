# tablecrafter

> 标签: csv, data-table, datatable, editable-table, filtering, inline-editing, sorting, table, vanilla-js, zero-dependency

## 简介

Zero-dependency JavaScript data table with inline editing, advanced filtering, and mobile card view. Companion library to the TableCrafter WordPress plugin.
