# ts-plugin-jest-to-uvu

> 标签: JavaScript

## 简介

This is a plugin that works with ttypescript to convert existing test code for jest written in TS into code that works with hedrall/ts-uvu. (TSで書かれた既存のjest用のテストコードを、hedrall/ts-uvuで動作するコードに変換する、ttypescriptで動作するプラグインです。)
