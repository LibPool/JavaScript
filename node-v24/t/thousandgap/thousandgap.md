# thousandgap

> 标签: customizable spacing, digit grouping, format numbers, number formatting, number readability, numeric formatting, space separator, styled separator, thousand separator, thousands gap

## 简介

A library for formatting numbers with customizable thousand separators, allowing control over the spacing via styles to enhance number readability.
