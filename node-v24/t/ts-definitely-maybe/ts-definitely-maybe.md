# ts-definitely-maybe

> 标签: adt, fp, maybe, result, typescript

## 简介

Exposes minimal set of helpers to work with `Maybe`, `Result` union types + a `pipe` function. Based on [ts-union](https://github.com/twop/ts-union) library.
