# tpl-stencil

> 标签: JavaScript

## 简介

This is a node command-line tool that automatically creates files from templates ## Start install ``` npm install -g tpl-stencil ``` Register the github user name, repos name, and branch name where your templates are stored ``` tpl config ``` Enter the us
