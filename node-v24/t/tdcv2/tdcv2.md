> 标签: cli, coherent-data, csv, data-generation, data-generator, deterministic, dsl, dummy-data, fake-data, fake-data-generator, faker, faker-alternative, fixtures, i18n, json, locale, mock-data, parquet, reproducible, sample-data, seeded, sql, synthetic-data, synthetic-data-generator, test-data, test-data-generator, testing

## 简介

Deterministic test-data generator: coherent records, exact proportions, and any text format you describe. Same seed, same bytes. Also usable as a faker — one call, one value — from the same data packs.
