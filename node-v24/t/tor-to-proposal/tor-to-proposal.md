# tor-to-proposal

> 标签: agent-skills, bid, consultant, cover-letter, cv, financial-proposal, mcp, proposal, rfp, tender, tor, un, undp, ungm

## 简介

The bid tool that refuses to lie. ToR + CV in -> verified bid pack out: cover letter, tailored CV, technical response, financial proposal, submission checklist. Deterministic CLI + agent skill for UN / NGO / government consultants.
