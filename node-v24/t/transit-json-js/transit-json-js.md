# transit-json-js

> 标签: gtfs, mongodb, parser, postgresql, sqlite, transit, transit-json, validator

## 简介

Lightweight, modern library to parse, validate, and load TransitJSON schemas into SQLite, PostgreSQL, and MongoDB with zero mandatory dependencies.
