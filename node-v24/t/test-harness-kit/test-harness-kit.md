# test-harness-kit

> 标签: agent-skills, ai-agents, e2e, interchange-format, playwright, test-automation, testing, trif

## 简介

Reference kit for TRIF (Test Recipe Interchange Format): portable, self-maintaining test recipes any AI agent, engine, or human can execute. NL <-> Recipe <-> Script.
