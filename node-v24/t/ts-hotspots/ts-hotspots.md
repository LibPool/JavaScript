# ts-hotspots

> 标签: ai-agent, architecture, cli, clone-detection, co-change, code-metrics, complexity, dependency-graph, duplication, hotspots, refactoring, static-analysis, typescript

## 简介

Static analysis CLI that points AI coding agents at TypeScript hotspots: per-function complexity, Type-3 duplication, architectural pressure, and git co-change.
