# token-estimate

> 标签: agent, budget, context-window, estimate, llm, openai, tiktoken, token-count, tokens, truncate

## 简介

Estimate LLM token counts without shipping a 30 MB tokenizer, including the base64, hashes, non-Latin text and indentation that character-ratio estimates get badly wrong.
