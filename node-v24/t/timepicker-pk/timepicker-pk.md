# timepicker-pk

> 标签: google calendar, picker, time, timepicker, ui

## 简介

A jQuery timepicker plugin inspired by Google Calendar. It supports both mouse and keyboard navigation.

- 官网：http://jonthornton.github.com/jquery-timepicker/
- 源码仓库：git+https://github.com/jonthornton/jquery-timepicker.git
