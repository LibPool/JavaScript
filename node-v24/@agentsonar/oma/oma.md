# @agentsonar/oma

> 标签: agentsonar, coordination, multi-agent, observability, open-multi-agent

## 简介

AgentSonar integration for Open Multi-Agent (OMA) and any Node multi-agent bus: bridges agent-to-agent events to the AgentSonar coordination engine.
