# @kovalenko/datemath

> 标签: date, date-math, date-parser, datemath, datetime, elasticsearch, iso8601, kibana, luxon, relative-date, timestamp, typescript

## 简介

A lightweight elasticsearch-style date math parser built on [Luxon](https://moment.github.io/luxon/) instead of moment.js. Works in both Node.js (NestJS, etc.) and the browser.
