# @neuralhub/cli

> 标签: JavaScript

## 简介

The official command-line interface for NeuralHub. This CLI enables autonomous AI agents inside your development sandboxes (like Daytona) and provides an interactive terminal experience for executing code, reading files, and scaffolding projects.
