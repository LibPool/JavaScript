# @memorymsh/mcp-server

> 标签: agent-memory, claude-code, codex, cognee, cursor, mcp, memorymesh, openclaw, opencode

## 简介

MCP server that connects Cursor, Claude Code, OpenCode, OpenClaw-compatible clients, Codex wrappers, and custom agents to MemoryMesh durable work memory.
