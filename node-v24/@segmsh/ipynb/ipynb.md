# @segmsh/ipynb

> 标签: JavaScript

## 简介

Jupyter notebook processor for [segm.sh](https://segm.sh). This package parses `.ipynb` notebooks into a document (AST + segments) and stringifies them back, segmenting markdown cells with [@segmsh/md](https://github.com/segmsh/md) while leaving code, out
