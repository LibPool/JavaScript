# @deduva/adp

> 标签: adp, agent, evidence, forge, github, provenance, sbom, sdlc

## 简介

The ADP CLI — intents, proposals, gates, evidence and undo against an ADP instance, plus `adp init` and `adp connect` for a repository that already exists.
