# @noiseport/mcp

> 标签: JavaScript

## 简介

Local **stdio Model Context Protocol** server to operate a running Noiseport instance in plain language from any MCP client (Claude Desktop, Cursor, Claude Code). It wraps the same scoped `npt_` admin token and context as [`@noiseport/cli`](../cli).
