# @figtools/core

> 标签: design-tokens, figma, figma-api, playwright, scraper

## 简介

Fetches the data of a Figma node or file (position, size, styles, hierarchy) without the limitations of a free account: no official REST API rate limits, no Dev Mode plan required.
