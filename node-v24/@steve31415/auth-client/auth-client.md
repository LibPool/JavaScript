# @steve31415/auth-client

> 标签: auth, cloudflare, hono, workers

## 简介

Cached client for the Plasticine auth service — Hono middleware, Durable Object boundary helpers (gateWebSocketUpgrade, resolveUserFromRequest), and a lower-level whoami()
