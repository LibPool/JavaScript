> 标签: ad-creative, ads-optimiser, claude, device-flow, grok, image-generation, mcp, modelcontextprotocol, tiktok, tiktok-ads, video-generation

## 简介

MCP server for Ads Optimiser: generate TikTok ad images and videos from Claude, with local file upload and download. Device-flow sign-in, no API keys.
