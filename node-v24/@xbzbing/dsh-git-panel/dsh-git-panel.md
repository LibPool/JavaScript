# @xbzbing/dsh-git-panel

> 标签: commit, deepseek-harness, diff, dsh, git, plugin, web-ui

## 简介

DeepSeek Harness (dsh) plugin: an IDE-style Git panel in the Web GUI — branch/history overview, uncommitted changes with commit & amend, diff stats, and a zsh-style branch marker in the input bar.
