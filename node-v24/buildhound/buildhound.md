# buildhound

> 标签: ci, coding-agent, github-actions, linux, mac-mini, macos, mcp, runners, self-hosted-runner

## 简介

Run GitHub Actions on the Macs and Linux machines you already have, in a clean VM per job, set up by your coding agent. Agent-first CLI.
