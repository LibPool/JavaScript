# @pimia/sdk

> 标签: facturacion, oauth, pimia, sdk, verifactu

## 简介

Cliente TypeScript de la API de Pimia para apps de partner: OAuth con PKCE, rotación de refresh persistida, reintentos de rate limit y tipos generados del OpenAPI.
