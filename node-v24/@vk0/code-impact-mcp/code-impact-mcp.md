> 标签: ai-agent, anthropic, blast-radius, claude, claude-code, code-analysis, dependency-graph, developer-tools, impact-analysis, javascript, local-first, mcp, mcp-server, model-context-protocol, refactoring, static-analysis, typescript

## 简介

Lightweight pre-commit safety gate for AI agents. Answers 'is this change safe?' with PASS/WARN/BLOCK verdict in seconds. Zero setup, no database.
