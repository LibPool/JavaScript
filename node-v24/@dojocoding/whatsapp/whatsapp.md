# @dojocoding/whatsapp

> 标签: agent, graph-api, llm, mcp, meta, multi-tenant, opentelemetry, sdk, typescript, webhooks, whatsapp, whatsapp-cloud-api

## 简介

Typed TypeScript SDK for Meta's WhatsApp Cloud API, opinionated for agentic use cases (LLM orchestrators, multi-turn bots, multi-tenant deployments, transactional pipelines).
