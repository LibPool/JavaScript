# @depup/workbox-webpack-plugin

> 标签: caching, depup, fetch requests, file manifest, latest, offline, patched, security, service worker, updated-dependencies, webpack, workbox, workbox-webpack-plugin, workboxjs

## 简介

A plugin for your Webpack build process, helping you generate a manifest of local files that workbox-sw should precache. (with updated dependencies)
