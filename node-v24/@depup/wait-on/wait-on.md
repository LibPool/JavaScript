# @depup/wait-on

> 标签: available, cli, cross-platform, delay, depup, exist, files, http, latest, linux, osx, patched, portable, ports, ready, security, sockets, tcp, unix, updated-dependencies, wait, wait-on, win32, windows

## 简介

wait-on is a cross platform command line utility and Node.js API which will wait for files, ports, sockets, and http(s) resources to become available (with updated dependencies)
