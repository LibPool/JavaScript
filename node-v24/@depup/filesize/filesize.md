# @depup/filesize

> 标签: bytes, depup, diff, file, file system, filesize, latest, patched, readable, security, size, updated-dependencies

## 简介

Lightweight, zero-dependency JavaScript utility to convert bytes to human-readable strings with localization support (with updated dependencies)
