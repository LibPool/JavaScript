# @depup/graphql-upload

> 标签: apollo, depup, esm, express, file, graphql, graphql-upload, koa, latest, middleware, mjs, multipart, patched, request, security, server, updated-dependencies, upload

## 简介

Middleware and a scalar Upload to add support for GraphQL multipart requests (file uploads via queries and mutations) to various Node.js GraphQL servers. (with updated dependencies)
