> 标签: data-mapper, ddd, depup, entity, identity-map, javascript, js, latest, mariadb, mikro-orm, mongo, mongodb, mysql, orm, patched, postgresql, security, sqlite, sqlite3, ts, typescript, unit-of-work, updated-dependencies

## 简介

TypeScript ORM for Node.js based on Data Mapper, Unit of Work and Identity Map patterns. Supports MongoDB, MySQL, PostgreSQL and SQLite databases as well as usage with vanilla JavaScript. (with updated dependencies)
