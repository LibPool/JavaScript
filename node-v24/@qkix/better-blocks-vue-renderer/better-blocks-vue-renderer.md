> 标签: background-color, better-blocks, blocks, blocks-renderer, cms, color, diagram, headless-cms, highlight, katex, latex, math, mermaid, nuxt, renderer, rich-text, strapi, strapi-v5, text-color, vue, vue3

## 简介

Vue 3 renderer for Strapi v5 Blocks content with full Better Blocks plugin support - colors, tables, to-do lists, media embeds, alignment, and more. Server-rendered in Nuxt, and just as happy in a plain Vue app.
