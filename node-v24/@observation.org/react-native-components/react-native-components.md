# @observation.org/react-native-components

> 标签: JavaScript

## 简介

React Native component library for components used by React Native applications of Observation.org. There are 2 kinds of components: UI components: - `Accordion` - `BackButton` - `BackgroundImage` - `BottomSheet` - `Checkbox` - `Chip` - `ContentImage` - `
