# @snapeos/homebridge-samsung-soundbar-local

> 标签: homebridge-plugin, homekit, samsung, soundbar

## 简介

Local HomeKit control of Samsung D/F-series soundbars via the IP Control JSON-RPC interface. No cloud, no SmartThings.
