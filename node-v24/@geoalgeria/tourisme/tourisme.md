# @geoalgeria/tourisme

> 标签: algeria, algerie, attractions, dz, geoalgeria, geojson, historic, hotels, national-parks, open-data, thermal-springs, tourism, tourisme

## 简介

Tourism infrastructure across Algeria's 69 wilayas: 4,300+ geocoded hotels, attractions, historic sites, thermal springs and protected areas. JSON, CSV, GeoJSON, TypeScript.
