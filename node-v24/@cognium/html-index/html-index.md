# @cognium/html-index

> 标签: accessible-name, aria, cognium, html, static-analysis

## 简介

Static index of built HTML: elements with roles, accessible names, visible labels, inherited language and matching CSS declarations, the IDREF graph, parse errors, stylesheets, media, frames and shadow trees, plus a file index and a cross-page route index
