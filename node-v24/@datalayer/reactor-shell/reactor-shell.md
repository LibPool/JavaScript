# @datalayer/reactor-shell

> 标签: datalayer, plugins, reactor, shell, views

## 简介

The shell plugin of a Datalayer Reactor platform — a generic view point, a segmented selector that shows nothing until plugins contribute, a choice store, and a cycle command.
