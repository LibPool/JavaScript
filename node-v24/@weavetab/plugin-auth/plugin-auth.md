# @weavetab/plugin-auth

> 标签: auth, cookies, mcp, session, vault, weavetab, weavetab-official, weavetab-plugin, zero-leak

## 简介

Zero-Leak Enterprise Session & Cookie Vault for Weavetab. Capture and inject authenticated sessions over CDP without exposing credentials to agent prompt context.
