# i18n-le

> 标签: audit, cli, i18n, i18n-le, i18next, l10n, letools, next-intl, nolindnaidoo, translations

## 简介

Audit a set of translation catalogues against one of them: missing keys, broken placeholders, empty and untranslated values. Never quotes a translation.
