# @shivesh-3003/apps-sdk

> 标签: finance, light, light.inc, lovable, sdk

## 简介

Build an app that reads Light and runs inside it: a typed client for Light's public API, the OAuth and API key flows, the embed protocol, and Light's design tokens.
