> 标签: cli, documentation, latex, markdown, markdown-reader, markdown-viewer, mermaid, reader, themes, viewer

## 简介

Portable web-based Markdown viewer with file tree navigation, themes, LaTeX, Mermaid diagrams, and a native folder picker.
