# @inneranimalmedia/agentsam-sections

> 标签: agentsam, glb, layout, media, scroll-animation, sections

## 简介

Reusable mxs-* page kit: global header/footer, scroll-driven split sections, and a media slot for image, gif, video, glb and sandboxed app previews.
