# @inneranimalmedia/client-cms-editor

> 标签: JavaScript

## 简介

Reusable full-stack website + CMS kit with multi-page public sites, a protected authoring dashboard, local SQLite, starter/theme import, and pluggable auth, storage, and deployment adapters.
