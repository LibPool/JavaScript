# @inneranimalmedia/agentsam-browser-surface

> 标签: agentsam, browse-mode, browser, build-mode, generative-browser, provider

## 简介

AgentSamBrowserSurface: a portable Browse/Build browser capability with a provider registry so the lightweight Local Studio browser and the AgentSam Browser Shell can be swapped behind one stable host composition.
