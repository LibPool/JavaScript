# @mailflat/ai-sdk

> 标签: ai-agents, ai-sdk, email, email-api, mailflat, otp, tools, vercel-ai-sdk

## 简介

MailFlat tools for the Vercel AI SDK. Give any model a real email inbox it can create, read, and pull one-time codes from.
