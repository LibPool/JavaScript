# @nickkupriyanov/slotline-react

> 标签: appointment, booking, calendar, dark-theme, headless, meeting, react, scheduler, scheduling, timeslots, widget

## 简介

Themable, accessible React booking widget: month calendar → time slots → details → confirmation. CSS-variable theming, dark theme by default, soft animations, bring-your-own backend.
