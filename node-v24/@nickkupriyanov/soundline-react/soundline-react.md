# @nickkupriyanov/soundline-react

> 标签: audio, dark-theme, headless, media, music, player, playlist, react, widget

## 简介

Themable, accessible React audio player: single track and playlist, CSS-variable theming, dark theme by default, soft animations, bring-your-own track source.
