# @sharick/cli

> 标签: JavaScript

## 简介

Connect coding agents (Claude Code, Codex) to Sharick from any machine — installs the sharick-connect skill, session hooks, and the sharick-todo MCP server without Sharick Desktop.

## 官网

- npm 页面：https://www.npmjs.com/package/@sharick/cli
