# @joeybaker/chokidar

> 标签: file, fs, fsevents, watch, watchFile, watcher, watching

## 简介

A neat wrapper around node.js fs.watch / fs.watchFile / fsevents. This fork only replaces fs with graceful-fs to prevent EMFILE errors.
