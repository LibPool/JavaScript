# @hemit99123/ccrouter

> 标签: anthropic, claude, claude-code, cli, llm, model-router, proxy

## 简介

Per-prompt model router for Claude Code — a zero-dependency localhost proxy that classifies each prompt and routes it to the best-suited Claude model (Haiku/Sonnet/Opus).
