# @peroxider/dsh-python-bridge-runtime

> 标签: JavaScript

## 简介

TypeScript runtime that lets a Python module expose itself as a Cordis Service / Event listener / capability Provider over newline-delimited JSON-RPC. Spawns `python -u -m dsh_bridge.runtime` and forwards decorated methods.
