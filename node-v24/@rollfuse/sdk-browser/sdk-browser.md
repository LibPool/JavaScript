# @rollfuse/sdk-browser

> 标签: JavaScript

## 简介

Browser SDK that evaluates rollfuse feature flags directly in client-side JavaScript using a Public Credential (never a regular Service Credential), reusing @rollfuse/evaluation-core's deterministic bucketing/evaluation algorithm.
