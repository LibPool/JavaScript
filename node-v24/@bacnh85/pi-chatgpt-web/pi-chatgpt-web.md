# @bacnh85/pi-chatgpt-web

> 标签: JavaScript

## 简介

Pi extension that turns a self-hosted ChatGPT-web bridge (OpenAI-compatible, e.g. basketikun/chatgpt2api) into a Pi provider for free web-tier models.
