# @groundtruth-now/plugin-groundtruth

> 标签: elizaos, elizaos-plugin, groundtruth, memecoin, plugin, robinhood-chain, rug, solana, x402

## 简介

ElizaOS plugin for GROUNDTRUTH: memecoin coin records, creator track records and venue figures (Solana, Robinhood Chain), from the live API.
