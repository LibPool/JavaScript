# @voltkit-rtc/react

> 标签: hooks, live-streaming, nextjs, react, rtc, video-call, voltkit, webrtc

## 简介

React hooks and components for VoltKit RTC rooms: a provider, connection state, participants, local media, remote tracks, network quality and wallet notices, on top of @voltkit-rtc/client.
