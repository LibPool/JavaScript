# @qlens/jest-reporter

> 标签: ci, jest, qualitypilot, reporter, test-health

## 简介

Jest reporter that posts run summaries and case-level results to QualityPilot (qlens.dev) CI ingest.

## 官网

- 官网：https://qlens.dev/docs/ci-ingest
- 源码仓库：git+https://github.com/i-kosheliev/qualitypilot.git
- npm 页面：https://www.npmjs.com/package/@qlens/jest-reporter
