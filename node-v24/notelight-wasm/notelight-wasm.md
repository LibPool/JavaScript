# notelight-wasm

> 标签: bm25, embeddings, hybrid-search, notes, rag, rust, search, semantic-search, vector-search, wasm, webassembly

## 简介

notelight's Rust retrieval core as WebAssembly: open a notelight index and run BM25 or hybrid (BM25 + quantized vector) search, or build an index, in the browser or Node.
