# @uxland/etc-hes-plugins-sandbox

> 标签: JavaScript

## 简介

Sandbox per desenvolupar plugins de Harmonix (React, Lit o Angular) i provar-los al costat dels plugins del plugin store de PRE, dins del mateix shell que fa servir l'aplicació.
