# @blyp/core

> 标签: bun, elysia, farmjs, logger, logging, pino, standalone, typescript

## 简介

A high-performance, modular logger with Bun-first runtime detection and TypeScript support. Built on Pino and supports Elysia, Hono, Express, Fastify, NestJS, Next.js App Router, Farm.js, React Router, Astro, Nitro, Nuxt, TanStack Start, SolidStart, and S
