# @next-model/core

> 标签: active-record, database, esm, migrations, model, next-model, orm, query-builder, typescript, validation

## 简介

A typed, promise-based ORM for TypeScript. Declare models with a factory, chain immutable query scopes, manage associations, and plug in any storage via the Connector interface — with validators, callbacks, soft deletes, and a built-in in-memory connector
