# @coremarine/sbf-parser

> 标签: binary, core-marine, coremarine, gnss, gps, protocol, sbf, septentrio

## 简介

It is a library to parse SBF data. SBF is a private binary protocol of Septentrio trademark which uses in its GNSS devices
