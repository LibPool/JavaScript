# @restatedev/byoc-artifacts

> 标签: JavaScript

## 简介

Pre-built Lambda artifacts (restatectl wrapper, retirement watcher, CloudWatch custom widget) used by @restatedev/byoc. Distributed via npm so the construct does not need to fetch them from a public S3 bucket at deploy time.
