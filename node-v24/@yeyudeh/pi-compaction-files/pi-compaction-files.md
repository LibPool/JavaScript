# @yeyudeh/pi-compaction-files

> 标签: compaction, context, context-window, pi, pi-extension, pi-package, tokens

## 简介

Caps Pi's compaction file lists (<read-files>/<modified-files>): drops dead, duplicate and temp paths, hides sensitive ones, strips blocks the summarizer re-seeds into the narrative, and keeps the cost per turn constant.
