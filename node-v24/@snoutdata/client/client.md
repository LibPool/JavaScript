# @snoutdata/client

> 标签: auth, postgres, postgrest, realtime, snoutdata, storage

## 简介

The JavaScript client for SnoutData Cloud: the data API, auth, storage, realtime and Snout Functions of one project, from one URL and one key. No dependencies.

## 官网

- 官网：https://docs.snoutdata.com/cloud/api
- npm 页面：https://www.npmjs.com/package/@snoutdata/client
