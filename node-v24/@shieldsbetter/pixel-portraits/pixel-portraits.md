# @shieldsbetter/pixel-portraits

> 标签: avatar, generator, pixel-art, portrait, procedural

## 简介

Random pixel-art character portraits, drawn from Viktor Hahn's sprite set (CC BY 4.0). Zero dependencies, browser or server.
