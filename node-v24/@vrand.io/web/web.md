# @vrand.io/web

> 标签: gaming, provably-fair, random, randomness, rng, solana, verifiable-randomness, vrf, wallet, web3

## 简介

Verifiable randomness (VRF) for Solana in one line: const r = await vrand.random(). Proofs verified in the browser before you ever see the number. Sessions: sign once, then unlimited prompt-free requests — perfect for on-chain games. Provably fair dice, s
