# @eonic.ai/absurd-sql

> 标签: absurd-sql, backend, database, eonic-ai, indexeddb, sqlite, web, worker

## 简介

This is a modified fork of [absurd-sql](https://github.com/jlongster/absurd-sql), for Eonic.ai, a no-code AI system, and is used as an internal package for Eonic.ai Studio. The package allows users to store their data locally as part of the studio in Eoni
