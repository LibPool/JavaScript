# @doitrix/headless

> 标签: accessibility, design-system, dialog, headless, menu, select, vue, vue3, wai-aria

## 简介

Unstyled, accessible Vue 3 behaviour for the Doitrix design system — dialog, popover, tooltip, menu, select, tabs, form controls and data-table state. Zero dependencies, tree-shakable.
