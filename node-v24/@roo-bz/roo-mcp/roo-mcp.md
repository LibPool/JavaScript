# @roo-bz/roo-mcp

> 标签: claude, mcp, model-context-protocol, modelcontextprotocol, qr, roo, roo.bz, shortener, shortlinks, webhook

## 简介

MCP server for the Roo (roo.bz) smart-shortlink API — create, manage, and configure add-ons (scheduled/click-count redirects, webhooks, preview links, QR codes) on Roo shortlinks from any MCP-capable AI client.
