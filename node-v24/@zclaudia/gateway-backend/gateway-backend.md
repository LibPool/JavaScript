# @zclaudia/gateway-backend

> 标签: backend, gateway, reverse-tunnel, websocket, zclaudia

## 简介

Backend SDK for the zclaudia gateway: registration, heartbeats, channel serving (dial-is-accept), topic publishing, HTTP-over-channel.
