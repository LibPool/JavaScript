# @charkylabs/signal-cli

> 标签: bug-report, cli, env, setup, signal, support

## 简介

Set up Signal in a project without copying keys: sign in through the browser, and put a product's keys into your env files and Vercel. `npx @charkylabs/signal-cli init`.
