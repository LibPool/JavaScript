# @run402/nwc

> 标签: lightning, nip-44, nip-47, nostr, nwc, run402

## 简介

Nostr Wallet Connect (NIP-47) client: pairing URIs, NIP-44 v2 encryption, signed request events, and a standing relay connection that says which side went quiet.
