# @coswic/sdk

> 标签: JavaScript

## 简介

Coswic TypeScript SDK — Sign in with Coswic（OAuth PKCE）＋ AI chat（計量扣款、串流、重放）client。零依賴，Node 20+ 與現代瀏覽器皆可用。
