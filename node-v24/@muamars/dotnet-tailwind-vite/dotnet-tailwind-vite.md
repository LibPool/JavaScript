# @muamars/dotnet-tailwind-vite

> 标签: JavaScript

## 简介

⚡ **dotnet-tailwind-vite** adalah sebuah CLI tool sederhana untuk mengintegrasikan **Vite v8** dan **Tailwind CSS v4** secara instan ke dalam proyek **ASP.NET Core** (MVC / Razor Pages).
