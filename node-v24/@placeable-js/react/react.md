# @placeable-js/react

> 标签: design-editor, drag, gesture, headless, react, resize, rotate, transform

## 简介

Thin, SSR-safe React adapter for @placeable-js/core: useTransformController + <TransformChrome /> for drag/resize/rotate chrome.
