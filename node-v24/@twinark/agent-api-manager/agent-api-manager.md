# @twinark/agent-api-manager

> 标签: JavaScript

## 简介

Manages the Digital Twin API, providing access to data, assets, and scenes in the digital twin environment. Handles API requests from other agents and external clients, and interacts with the digital twin to retrieve and manipulate information as needed.
