# @khorsheed/dsh-capture

> 标签: capture, chrome, cordis, dsh, dsh-plugin, headless, puppeteer, render, scraping

## 简介

Rendered fetch (capture) host service: one Remote verb renders a URL in a managed headless Chrome and returns the serialized rendered page with CSSOM styles inlined, so static extractors can read JS-heavy pages
