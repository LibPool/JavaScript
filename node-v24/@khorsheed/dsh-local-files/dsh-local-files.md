# @khorsheed/dsh-local-files

> 标签: browser, cordis, dsh, dsh-plugin, local-files, workspace

## 简介

Git-agnostic local file browser in the right sidebar: a lazy file tree with structured HTML/Markdown/JSON/CSV/image previews over its own Typert Remote, defaulting to the session's workspace but not limited to it
