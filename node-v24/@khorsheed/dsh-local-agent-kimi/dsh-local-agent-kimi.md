# @khorsheed/dsh-local-agent-kimi

> 标签: cordis, dsh, dsh-plugin, kimi, local-agent

## 简介

Kimi Code harness for dsh-local-agent: scoped KIMI_CODE_HOME, one-shot kimi -p delegation visible in the 子代理 surface, session records and preset wiring; the session-granted `subagent_kimi` delegation tool ships as the package's `./tool` composition entry
