# @dark-mode-pro/moonsender-push

> 标签: moonsender, push-notifications, service-worker, vapid, web-push

## 简介

Web push SDK for self-hosted Moonsender servers — one durable token per browser installation, Firebase-style ergonomics, zero runtime dependencies.
