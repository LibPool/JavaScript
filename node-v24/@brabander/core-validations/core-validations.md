# @brabander/core-validations

> 标签: JavaScript

## 简介

`@brabander/core-validations` bevat framework-agnostische validatiefuncties (bijvoorbeeld `isValidEmail`, `isValidPassword`) voor gebruik door domain-modellen en andere packages.
