# @brabander/nswag

> 标签: JavaScript

## 简介

`@brabander/nswag` (`type:adapter`, `scope:shared`) bevat de initiële NSwag-opzet voor het genereren van een TypeScript API-client uit een OpenAPI/Swagger-specificatie.
