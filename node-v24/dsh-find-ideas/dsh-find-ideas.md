# dsh-find-ideas

> 标签: architecture, code-search, deepseek-harness, dsh, dsh-plugin, github, prior-art

## 简介

Prior-art search for a development idea: search GitHub for similar projects, rank them by relevance weighted with stars, then read the repositories you pick and report what their code actually says.
