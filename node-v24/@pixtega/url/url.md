# @pixtega/url

> 标签: avif, image, picture, pixtega, resize, srcset, url, webp

## 简介

URL builders for Pixtega, the on-demand image derivation service. Re-exports the pixtega package: pixtegaUrl, pixtegaSrcSet, pixtegaPicture.

## 官网

- 官网：https://pixtega.com
- 源码仓库：git+https://github.com/kroofy/Pixtega.git
- npm 页面：https://www.npmjs.com/package/@pixtega/url
