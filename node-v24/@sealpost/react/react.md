# @sealpost/react

> 标签: dkim, email, email-editor, react, sealpost, smtp, visual-editor

## 简介

React components for building and sending email: a visual email editor, a deliverability gate, a domain and mailbox vault and an SMTP transcript inspector. Ships a precompiled, scoped stylesheet.
