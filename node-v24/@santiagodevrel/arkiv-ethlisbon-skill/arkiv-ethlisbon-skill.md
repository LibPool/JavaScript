# @santiagodevrel/arkiv-ethlisbon-skill

> 标签: agent-skill, arkiv, blockchain, claude-code, ethlisbon, skill, web3

## 简介

Claude Code skill that makes you Arkiv-fluent for ETHLisbon. Pairs with the official arkiv-best-practices skill, adds gap-fill gotchas, ETHLisbon starter templates, and Claude Code prompting patterns. One npx command installs both.
