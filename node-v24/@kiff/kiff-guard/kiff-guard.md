# @kiff/kiff-guard

> 标签: agents, audit, governance, guardrails, kiff, openclaw, tool-calls

## 简介

Drop-in guard that puts KIFF clearance in front of any agent's tool calls — observe to audit, enforce to govern. TypeScript SDK.
