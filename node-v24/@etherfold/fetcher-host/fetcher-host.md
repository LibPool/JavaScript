# @etherfold/fetcher-host

> 标签: JavaScript

## 简介

The host-side half of the log-fetcher: configuration, what a cycle's outcome means, how long to wait before the next one, and the two shapes a host schedules in (a loop, one bounded run). Names no runtime.
