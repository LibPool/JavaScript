# @realitycollective/native-environment

> 标签: audio, conformance, environment, fog, lighting, native, occlusion, openxr, realitycollective, scene-management, scenes, skybox, typescript, visionos, webxr, world-sensing, xr

## 简介

Native host adapter for the Reality Collective WebXR Environment Extensions - reads the environment, audio, sensing and scenes slices of globalThis.__rcHost that a native app (OpenXR, visionOS) installs, forwards the engine-free @realitycollective/webxr-e
