# @observer-protocol/fireblocks-op-authorize

> 标签: JavaScript

## 简介

Observer Protocol as the authorization gate at the Fireblocks API Co-Signer callback boundary. Fireblocks holds the key; OP holds none; an OP deny means no signature exists.
