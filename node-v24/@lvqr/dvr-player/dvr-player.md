# @lvqr/dvr-player

> 标签: dvr, hls, lvqr, player, streaming, video, web-component

## 简介

LVQR DVR scrub Web Component - drop-in HLS DVR player with custom seek bar, LIVE indicator, client-side hover thumbnails, and SCTE-35 ad-break markers
