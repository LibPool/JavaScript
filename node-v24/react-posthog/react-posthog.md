# react-posthog

> 标签: block, blocker, disable-scroll, events, freeze, lock-screen, overlay, scroll-lock

## 简介

Block the whole page with one call: locks vertical and horizontal scroll and covers the site with an overlay that swallows every event (clicks, scroll, keyboard, touch, ...).
