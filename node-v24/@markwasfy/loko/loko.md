# @markwasfy/loko

> 标签: background-sync, conflict-resolution, indexeddb, local-first, multi-tab, offline, offline-first, sync, typescript

## 简介

Add offline support to any TypeScript app in 5 minutes. Bring your own backend. Offline storage + sync for SaaS CRUD apps. Framework agnostic. Backend agnostic. Zero dependencies.
