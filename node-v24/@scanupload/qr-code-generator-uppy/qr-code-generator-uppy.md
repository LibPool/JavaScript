# @scanupload/qr-code-generator-uppy

> 标签: file-upload, qr-code, scanupload, signalr, uppy, uppy-plugin

## 简介

Official Uppy plugin for the ScanUpload QR Code Generator — receive files uploaded from a phone via QR code and hand them straight to an Uppy instance.
