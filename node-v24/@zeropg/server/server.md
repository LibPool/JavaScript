# @zeropg/server

> 标签: pglite, postgres, postgrest, scale-to-zero, serverless, wire-protocol

## 简介

Early experiment in the cheapest possible scale-to-zero Postgres. Standalone dedicated-Postgres server for zeropg: one scale-to-zero container holding the lease + PGlite + ObjectStoreFS, exposing the real Postgres wire protocol (pglite-socket) on a local
