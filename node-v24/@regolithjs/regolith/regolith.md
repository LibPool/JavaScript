# @regolithjs/regolith

> 标签: javascript, linear-time, napi, pattern-matching, performance, redos, regex, regexp, rust, safe-regex, security, typescript

## 简介

A TypeScript and JavaScript library immune to Regular Expression Denial of Service (ReDoS) attacks by using Rust and linear RegEx under the hood. Regolith has a linear worst case time complexity, compared to the default RegExp found in TypeScript and Java
