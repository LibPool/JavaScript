# @zlnap/astrolabe

> 标签: ai-coding, claude-code, code-intelligence, code-navigation, code-search, codex, coding-agent, cursor, lsp, mcp, mcp-server, model-context-protocol, tree-sitter

## 简介

Local MCP server for code search and navigation (search_code, find_symbol, find_references, goto_definition) for AI coding agents. Node shim for the native Astrolabe AI binary.
