# @janodetzel/app-commands

> 标签: ai-agents, apollo, cli, commands, devtools, expo, expo-router, mcp, model-context-protocol, react-native, testing, zustand

## 简介

Run typed commands against a running app from a CLI, an MCP server, or the Metro dev tools, and keep the app's features reachable with lint and dependency-cruiser rules. Knows no UI framework.
