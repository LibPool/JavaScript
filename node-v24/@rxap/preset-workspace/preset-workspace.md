# @rxap/preset-workspace

> 标签: nx, nx-plugin, packages, plugin, preset, preset-workspace, rxap

## 简介

This package provides generators for initializing a workspace with pre-configured settings. It includes a preset generator to set up a new workspace and an init generator to coerce peer dependencies. The preset generator leverages `@rxap/plugin-workspace`
