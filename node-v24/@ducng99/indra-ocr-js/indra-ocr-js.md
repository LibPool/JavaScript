# @ducng99/indra-ocr-js

> 标签: indra-ocr, ocr, onnx

## 简介

indra-ocr ONNX models in JavaScript — browser (onnxruntime-web, wasm) and Node (onnxruntime-node): line detection, recognition (Latin + CJK), reading order, orientation
