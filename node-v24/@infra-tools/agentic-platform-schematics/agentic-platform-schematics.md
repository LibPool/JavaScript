# @infra-tools/agentic-platform-schematics

> 标签: agentic, angular, monorepo, scaffold, schematics

## 简介

Angular schematics that scaffold the Agentic Experience Platform monorepo (projects/, platform/, docs/) into a new workspace — example apps ship separately in @infra-tools/agentic-examples-schematics; security-sensitive scripts excluded.
