# @ahmetilhn/hanui

> 标签: a11y, accessible, bottom-sheet, combobox, component-library, css-modules, dark-mode, data-table, design-system, design-tokens, headless, modal, react, scss, theming, typescript, ui, wcag

## 简介

Accessible, theme-driven React component library built on SCSS Modules. Bootstrap Icons for shell iconography, two built-in themes and a fully overridable design-token contract.
