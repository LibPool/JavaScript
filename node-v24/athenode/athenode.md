# athenode

> 标签: ai-agents, athenode, claude-code, cli, codex, cursor, mcp, mcp-server, spec-driven-development, specifications

## 简介

Spec-driven development for AI coding tools: a local daemon with a web UI for specifications, ToDo cards and plugins, and the athenode CLI that generates skills, agents, rules and MCP servers for Claude Code, Codex, Cursor and 27 more tools.
