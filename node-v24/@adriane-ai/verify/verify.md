# @adriane-ai/verify

> 标签: JavaScript

## 简介

Offline, independent verifier for an Adriane Certificate of Execution — re-checks the Ed25519 signature, walks the attestation chain, AND re-derives the run from the capsule alone. `npx @adriane-ai/verify capsule.json`.
