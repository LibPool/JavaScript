# @owsp/js

> 标签: ajv, json-schema, openwinspec, typescript, validation, windows, wom

## 简介

Runtime SDK for OpenWinSpec: AJV validation with x-allowedClasses/x-uniqueBy, x-partial projections and hashing, x-order canonical ordering, unit conversions, construction business validation, TypeScript types.
