# @robinmesh/sdk

> 标签: ai, decentralized, inference, llm, on-chain, openai-compatible, robinhood-chain, robinmesh, streaming, web3

## 简介

TypeScript client for RobinMesh, the decentralized AI inference network on Robinhood Chain. Chat completions in the OpenAI shape, token streaming, and a verifiable on-chain settlement receipt for every job.
