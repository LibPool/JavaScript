# @kalads/tokens

> 标签: css-variables, dark-mode, design-system, design-tokens, kalads, react-native

## 简介

KalaDS design tokens: CSS custom properties, typed CSS variable references for React, JS, JSON and React Native values, in a light and a dark theme.
