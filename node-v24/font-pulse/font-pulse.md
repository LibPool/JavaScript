# font-pulse

> 标签: cls, core-web-vitals, font-display, fonts, github-action, performance, sarif, static-site, web-fonts, woff2

## 简介

Audit web font loading in a built static site: font-display, preload with crossorigin, unused preloads, WOFF2, heavy or unsubset fonts, unicode-range, unused faces and weights, per-page font payload, Google Fonts display=swap and preconnect. SARIF, GitHub
