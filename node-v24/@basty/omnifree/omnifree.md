# @basty/omnifree

> 标签: bash, chat, claude-code, compression, free, multi-provider, plugin, router, slash-command

## 简介

One slash, zero setup — /use. Routes every request through 8 verified free-tier providers (chat, code, image) with level-2 token compression. Bash vs chat intent inferred from one quoted string.
