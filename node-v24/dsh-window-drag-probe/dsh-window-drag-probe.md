# dsh-window-drag-probe

> 标签: app-region, deepseek-harness, diagnostics, dsh, dsh-plugin, electron, macos, plugin, window-drag

## 简介

窗口拖动：窗口一加载就在顶部自动装好一条可拖拽带（本机 macOS 拖不动窗口的解法），并从插件页提供按钮打开面板读取 computed app-region、recall 标记与窗口位移（deepseek-harness discussion #9112）。
