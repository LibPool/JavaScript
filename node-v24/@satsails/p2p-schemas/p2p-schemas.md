# @satsails/p2p-schemas

> 标签: bitcoin, escrow, non-custodial, p2p, sails, sdk

## 简介

Sails P2P Trading domain schemas — Offer, Trade, Dispute contracts shared by every wallet/SDK integration (the 'contrato social' layer between Sails Core and any P2P trading interface)
