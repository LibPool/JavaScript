# @cvparse/core

> 标签: ai-sdk, ats, cv, json-resume, llm, ollama, parser, recruiting, resume, spanish

## 简介

Turn CVs and resumes into typed, JSON Resume-compatible JSON using LLMs via the Vercel AI SDK. Multi-provider, Ollama/local-first, best-in-class Spanish CV support.
