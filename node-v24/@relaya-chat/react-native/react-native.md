# @relaya-chat/react-native

> 标签: chat, community-chat, expo, headless, hooks, live, moderation, radio, react-native, real-time, realtime, ugc, websocket

## 简介

Real-time community chat hooks for React Native and Expo — OTP auth, WebSocket messaging, moderation. Connects to the Relaya™ SaaS at api.relaya.chat. Headless: bring your own UI.
