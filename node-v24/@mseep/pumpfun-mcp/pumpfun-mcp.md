# @mseep/pumpfun-mcp

> 标签: mcp-server, mseep

## 简介

A Model Context Protocol (MCP) server for interacting with the [Pump.fun](https://pump.fun) platform on Solana. This server enables AI assistants to create, buy, and sell tokens on the Pump.fun platform.
