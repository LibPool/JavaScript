# @mseep/ebay-mcp

> 标签: ai, ai-tools, api, backend, documentation, ebay, ebay-api, llm, mcp, mcp-server, model-context-protocol, mseep, server

## 简介

Model Context Protocol (MCP) server that exposes 100% of eBay's Sell APIs (322 tools across 270 endpoints) to AI assistants like Claude, Cursor, and Cline, covering inventory, order fulfillment, marketing, analytics, and developer tools with OAuth authent
