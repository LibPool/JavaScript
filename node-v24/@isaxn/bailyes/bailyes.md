# @isaxn/bailyes

> 标签: baileys, bot, framework, pairing-code, store, whatsapp, whatsapp-bot

## 简介

WhatsApp Bot Framework built on Baileys, with QR and pairing code login, a built-in contact/chat/message store, and a modular interactive message builder (Button, ButtonV2, Carousel, AIRich).
