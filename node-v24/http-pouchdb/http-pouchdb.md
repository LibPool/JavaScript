# http-pouchdb

> 标签: JavaScript

## 简介

Access remote CouchDB databases like you would access your local PouchDB ones.

- 官网：https://github.com/pouchdb/pouchdb-server#readme
- 源码仓库：git+https://github.com/pouchdb/pouchdb-server.git
