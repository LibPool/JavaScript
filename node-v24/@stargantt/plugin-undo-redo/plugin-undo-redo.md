# @stargantt/plugin-undo-redo

> 标签: gantt, gantt-chart, plugin-architecture, project-management, scheduling, timeline, typescript, zero-dependencies

## 简介

Official StarGantt plugin: records every applied transaction and replays it in reverse on undo, forward again on redo.
