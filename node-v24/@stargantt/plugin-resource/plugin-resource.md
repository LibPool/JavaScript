# @stargantt/plugin-resource

> 标签: gantt, gantt-chart, plugin-architecture, project-management, scheduling, timeline, typescript, zero-dependencies

## 简介

Official StarGantt plugin (opt-in): resource ledger, assignment column and editor, resource-axis panel, over-allocation analysis, and a load chart with reports.
