# @stargantt/plugin-data-sync

> 标签: gantt, gantt-chart, plugin-architecture, project-management, scheduling, timeline, typescript, zero-dependencies

## 简介

Official StarGantt plugin (opt-in): REST/GraphQL snapshots with delta sync and optimistic write-back, lazy paged loading, IndexedDB offline snapshots, and realtime transport application.
