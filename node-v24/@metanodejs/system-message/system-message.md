# @metanodejs/system-message

> 标签: JavaScript

## 简介

`@metanodejs/system-message` là package JS/ESM dùng để **gửi/nhận message chuẩn hóa** giữa các môi trường khác nhau. Hỗ trợ message lớn, debug chi tiết, và transport linh hoạt.
