# warproxy

> 标签: bittorrent, cloudflare, http-proxy, proxy, sing-box, socks5, udp, vpn, warp, wireguard

## 简介

Local HTTP + SOCKS5 proxy (TCP and UDP: BitTorrent, DHT, DNS...) that routes everything through Cloudflare WARP. One command, no admin rights, Windows / Linux / macOS.
