# @molecule/api-scheduler-postgresql

> 标签: advisory lock, cron, molecule, multi-instance, postgresql, scheduler

## 简介

PostgreSQL-coordinated scheduler provider for @molecule/api-scheduler: in-process timers that take a per-task advisory lock so a scheduled task runs ONCE across every API instance.
