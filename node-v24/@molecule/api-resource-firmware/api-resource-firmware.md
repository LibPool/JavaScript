# @molecule/api-resource-firmware

> 标签: firmware, iot, molecule, ota, resource, rollout

## 简介

Owner-scoped firmware versions + OTA rollouts: draft/publish/deprecate, per-device update tasks, realtime command dispatch, device-token-authenticated status reporting. Extracted from iot-device-manager flagship.
