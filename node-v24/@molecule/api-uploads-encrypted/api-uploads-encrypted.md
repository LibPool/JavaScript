# @molecule/api-uploads-encrypted

> 标签: aes-256-gcm, encryption, encryption-at-rest, files, molecule, uploads

## 简介

Encrypting upload provider for molecule.dev — encrypts every file before another upload provider stores it, decrypts on read.
