# @molecule/api-model-hosting

> 标签: gpu, inference, model-hosting, molecule, scale-to-zero, serverless

## 简介

Model hosting for molecule.dev — run a model server container on rented GPUs or CPUs (Cloud Run, Modal, RunPod, Koyeb) or your own Docker host, and get an HTTPS URL plus auth headers, behind swappable bonds
