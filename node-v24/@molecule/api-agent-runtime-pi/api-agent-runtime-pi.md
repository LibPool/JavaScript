# @molecule/api-agent-runtime-pi

> 标签: agent, molecule, pi, runtime, sandbox

## 简介

Pi coding-agent runtime — unattended runs on any Pi-supported model provider in ephemeral cloud sandboxes; artifacts-only return, per-run credentials, deny-by-default egress
