# @molecule/api-ai-embeddings-local

> 标签: ai, embeddings, local, molecule, offline, onnx, transformers

## 简介

Local (offline) ai-embeddings provider for molecule.dev — runs a small sentence-embedding model in-process via Transformers.js (onnxruntime); no API key and no network at query time
