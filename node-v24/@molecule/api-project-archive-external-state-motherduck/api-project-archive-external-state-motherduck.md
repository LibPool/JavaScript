# @molecule/api-project-archive-external-state-motherduck

> 标签: archive, backup, duckdb, molecule, motherduck, project

## 简介

MotherDuck external-state capture for project archives — exports a project's configured MotherDuck databases (DuckDB EXPORT DATABASE, parquet) into the archive and imports them back on restore.
