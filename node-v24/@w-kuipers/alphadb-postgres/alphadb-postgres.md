# @w-kuipers/alphadb-postgres

> 标签: SQL database management, SQL version management, database, database migration tool, database version management, extension, rust

## 简介

AlphaDB is a versatile tool for managing MySQL database versions, using JSON to define structures and simplify migrations across environments.
