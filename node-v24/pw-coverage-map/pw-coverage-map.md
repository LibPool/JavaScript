# pw-coverage-map

> 标签: api-testing, coverage-report, e2e, openapi, playwright, qa, test-automation, test-coverage, test-report

## 简介

See what your Playwright tests cover without running them: suite → test → steps HTML report, API endpoint coverage from OpenAPI, over-coverage and no-assertion detection, diff for PR comments.
