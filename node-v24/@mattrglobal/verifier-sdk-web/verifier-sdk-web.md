# @mattrglobal/verifier-sdk-web

> 标签: JavaScript

## 简介

This package is a browser SDK for online mDoc verification against a MATTR VII verifier tenant. It supports same-device and cross-device OID4VP presentation flows, plus the W3C Digital Credentials API as a tech preview.
