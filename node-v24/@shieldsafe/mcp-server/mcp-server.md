# @shieldsafe/mcp-server

> 标签: claude, mcp, model-context-protocol, security, shieldsafe, vulnerabilities

## 简介

ShieldSafe MCP server — read project findings and report code-security findings to the ShieldSafe cloud from MCP-compatible clients (Claude Code, Cursor, Windsurf, Cline, etc.) over stdio.
