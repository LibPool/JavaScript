# @jream/lmdbq

> 标签: bun, fifo, job-queue, libmdbx, lmdb, mdbxmou, message-queue, node, pubsub, queue

## 简介

A persistent message queue, durable pub/sub, and job queue toolkit for Bun and Node.js, built on LMDB/libmdbx.
