# @quarks.studio/config

> 标签: JavaScript

## 简介

Configuration management for the Quark CLI. The domain models the configuration values (`AppConfig`), the repository persists them in `~/.config/quark/config.ini` (INI) and migrates legacy tokens to the session storage.
