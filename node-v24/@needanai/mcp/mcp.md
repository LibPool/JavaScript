# @needanai/mcp

> 标签: ai-tools, mcp, model-context-protocol, needanai

## 简介

MCP server for the NeedAnAI catalogue: search 15,000+ AI tools by pricing, category or task, compare them, find alternatives and check whether they are still live. stdio shim for hosts that cannot speak HTTP.
