# @santi-dev/blindpay-sdk

> 标签: api, blindpay, sdk, typescript

## 简介

A TypeScript SDK for integrating with the BlindPay payment processing API. This SDK provides a comprehensive interface for managing payments, quotes, receivers, and blockchain transactions across multiple networks.
