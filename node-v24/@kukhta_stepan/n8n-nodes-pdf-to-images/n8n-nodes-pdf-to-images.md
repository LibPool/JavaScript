> 标签: convert, docx, image, n8n, n8n-community-node-package, n8n-node, pdf, pdfjs, rtf

## 简介

n8n community node: PDF binary → JPEG/PNG per page (Mozilla PDF.js + @napi-rs/canvas, no MuPDF/Poppler)
