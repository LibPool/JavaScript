# @gemmein/sdk

> 标签: ai, auth, authentication, baas, backend, passwordless, payments, storage, stripe, vibe-coding

## 简介

Gemmein SDK — passwordless auth, safe storage, and Stripe-driven record flips for AI-built apps. Small enough that one prompt teaches the whole API.
