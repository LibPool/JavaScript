# @webrizen/sso

> 标签: authentication, nextjs, oauth2, oidc, openid-connect, sso, webhooks, webrizen

## 简介

Add “Sign in with Webrizen” (OpenID Connect SSO), organization roles, the Directory API and signed webhooks to any app.
