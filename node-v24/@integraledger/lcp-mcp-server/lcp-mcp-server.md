# @integraledger/lcp-mcp-server

> 标签: agentic-commerce, ai-agent, lcp, legal-context-protocol, mcp, model-context-protocol, tools, verify-before-pay

## 简介

Read-only Model Context Protocol server exposing Legal Context Protocol tools to an AI agent — verify before pay, compute an atrHash, extract and place references across the nine commerce protocols that have one. Works against any seller.
