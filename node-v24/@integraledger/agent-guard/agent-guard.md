# @integraledger/agent-guard

> 标签: acp, agent-guard, agentic-commerce, ai-agent, ap2, buyer-protection, lcp, legal-context-protocol, verify-before-pay, x402

## 简介

Integra Agent Guard — the buyer-side verify-before-sign guard for agentic purchases. Fetches the terms a seller advertised, recomputes the fingerprint, and halts before any signing key is invoked if they disagree. Works against any seller.
