## 简介

Post-quantum-only cryptographically secure random number generator. A reseedable SP 800-90A-style DRBG built on the SHAKE256 XOF (FIPS-202) — the same Keccak sponge that underpins ML-KEM/ML-DSA — with an optional ML-KEM (FIPS-203) lattice entropy-conditio
