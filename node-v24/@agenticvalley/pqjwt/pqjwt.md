# @agenticvalley/pqjwt

> 标签: akp, authentication, dilithium, fips-204, jose, jwk, jws, jwt, ml-dsa, post-quantum, pqc, quantum-resistant, rfc9964, signature, token

## 简介

Post-quantum signed JSON Web Tokens (JWT/JWS) with NIST ML-DSA (FIPS-204). No classical crypto, no hybrids — a pure post-quantum drop-in for the JWT you already know.
