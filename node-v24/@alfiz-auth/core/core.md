# @alfiz-auth/core

> 标签: access-control, authorization, permissions, rbac

## 简介

The Alfiz Client: permission grammar, catalog, closure evaluation, check shapes, caching, and the provider contract. Pure functions over provider-supplied data — no storage, no I/O.
