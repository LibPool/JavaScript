# @esnerda/cz-rental-management-mcp

> 标签: claude, czech, mcp, model-context-protocol, rental, vyuctovani

## 简介

MCP server for the Czech rental-management app — exposes property/contract/payment/cost-statement/reconciliation tools over stdio. Speaks to a rental-management REST backend.
