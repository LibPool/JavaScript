# @intentic/claude-plugin

> 标签: agent, claude-code, claude-code-plugin, context, token-savings

## 简介

The intentic Claude Code plugin: trimmed Bash output, a project map and field notes at session start, iq search and fileq teaching, and a /intentic:stats report of what each saved
