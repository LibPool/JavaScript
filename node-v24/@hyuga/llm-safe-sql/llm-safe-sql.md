# @hyuga/llm-safe-sql

> 标签: ai-safety, database, dry-run, human-in-the-loop, llm, mcp, mysql, postgresql, rollback, sql, sqlite

## 简介

Let an LLM propose UPDATE/DELETE, then actually run it, measure the real before/after diff, and always roll back — so the human approves measured facts, not the model's claim.
