# @hyuga/nenpi

> 标签: agent, ai, cache-read, claude, claude-code, context, cost, hooks, llm, observability, token-usage, tokens, zero-dependency

## 简介

Where a Claude Code session actually burns its tokens. Attributes cache_read spend to the tool output that caused it (residency cost), measures whether your hooks changed anything, and nudges in-session. Zero-dependency, reads only local transcripts.
