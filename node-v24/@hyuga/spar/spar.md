# @hyuga/spar

> 标签: agent, ai, claude-code, coding-agent, developer-tools, hooks

## 简介

The frame agent tools bolt onto: one mode (converge or diverge), one phase set, one finding shape, one ledger per repo, and one rule for who may stop what. Zero dependencies, no daemon, no LLM.
