# @neetru/product-feedback

> 标签: JavaScript

## 简介

Fluxo de feedback pos-suporte (report -> resolvido -> satisfacao -> contestacao) reutilizavel para produtos SaaS Neetru — deteccao client-side via listMyTickets(), throttle por-usuario configuravel, maquina de estados de 4 estados. Extraido do InterPay v2
