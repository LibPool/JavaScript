# @waylis/sqlite-db

> 标签: JavaScript

## 简介

Node.js Sqlite implementation of a Database interface for [Waylis](https://github.com/waylis/core). Build using [better-sqlite3](https://github.com/WiseLibs/better-sqlite3).
