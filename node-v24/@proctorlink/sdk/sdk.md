# @proctorlink/sdk

> 标签: JavaScript

## 简介

Platform-agnostic browser SDK for ProctorLink. Mounts a cross-origin enclave iframe that captures camera keyframes and proctoring events, and streams them to the host application (e.g. an Angular quiz portal).
