# @ijfw/memory-server

> 标签: ai-efficiency, claude-code, codex, cursor, gemini, ijfw, mcp, memory

## 简介

Cross-platform persistent memory server for IJFW. 14 MCP tools (memory + admin/update + brain). Works with 15 platforms: 14 via MCP (Claude Code, Codex, Gemini CLI, Cursor, Windsurf, Copilot, Hermes, Wayland, OpenCode, QwenCode, Cline, KimiCode, OpenClaw,
