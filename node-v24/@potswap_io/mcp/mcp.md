# @potswap_io/mcp

> 标签: ai-agent, jupiter, mcp, model-context-protocol, potswap, solana, swap

## 简介

Potswap MCP server: best-route Solana swaps, wallet, transfers, staking, DCA / rebalance / take-profit / limit strategies and POT rewards for AI agents. Non-custodial; built on @potswap_io/sdk.
