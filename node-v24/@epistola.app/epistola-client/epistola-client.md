# @epistola.app/epistola-client

> 标签: api, client, document-generation, epistola, fetch, openapi

## 简介

Node.js client for the Epistola document generation API, on the platform's own fetch. Generated from the Epistola OpenAPI contract, with identity headers, RFC 9457 problem-detail error handling, API-key and self-signed JWT auth, NDJSON result collection,
