# @bunny.net/astro-adapter

> 标签: astro, astro-adapter, astro-component, bunny, bunny.net, bunnycdn, edge, edge-scripting, ssr, withastro

## 简介

Astro adapter for bunny.net Edge Scripting. Renders Astro on the edge and serves the build assets from Bunny Storage.
