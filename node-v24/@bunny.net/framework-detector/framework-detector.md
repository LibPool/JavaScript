# @bunny.net/framework-detector

> 标签: bunny, bunny-sites, bunny.net, framework-detection, github-actions, static-site, typescript

## 简介

Detect a project's web framework and package manager, with build presets and a GitHub Actions workflow for bunny.net Sites. Dependency-free: runs on disk, against a GitHub repository, or in the browser.
