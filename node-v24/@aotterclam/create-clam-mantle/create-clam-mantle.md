# @aotterclam/create-clam-mantle

> 标签: JavaScript

## 简介

npx scaffolder for clam-mantle consumer projects. Fetches the starters-monorepo tarball at a runtime-resolved sources.json, merges _common/ + <archetype>/ + (optional) themes/<theme>/ into the user's directory, fills {{PLACEHOLDER}} macros, and prints RUN
