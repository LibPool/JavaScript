# @aotterclam/clam-cms-admin-ui

> 标签: JavaScript

## 简介

Admin SPA for clam-cms — React 19 + Vite + Tailwind v4 + shadcn. Platform-agnostic: ships a single self-contained HTML string consumed by clam-cms-cloudflare / clam-cms-netlify mount layers.
