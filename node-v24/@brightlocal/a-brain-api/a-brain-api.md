# @brightlocal/a-brain-api

> 标签: api, brightlocal, local-seo, sdk, typescript

## 简介

Typed SDK for the public BrightLocal APIs. Call the APIs documented at developer.brightlocal.com from TypeScript or JavaScript with generated types, zod-validated inputs, and a browser-safe client.

## 官网

- 官网：https://developer.brightlocal.com
- 源码仓库：git+https://github.com/BrightLocal/acquisition-brain.git
- npm 页面：https://www.npmjs.com/package/@brightlocal/a-brain-api
