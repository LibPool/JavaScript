# @getmasv/masv-mcp-server

> 标签: ai, file, llm, massive, masv, mcp, transfer

## 简介

MCP server for MASV. Provides tools to use MASV API. MASV is an easy-to-use, secure, and ultra-reliable cloud-based and on-prem managed file transfer service for large file workflows.
