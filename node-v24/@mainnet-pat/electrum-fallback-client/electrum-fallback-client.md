# @mainnet-pat/electrum-fallback-client

> 标签: bitcoin, bitcoin cash, electrum

## 简介

@mainnet-pat/electrum-fallback-client is a lightweight JavaScript library that lets you connect with one or more Electrum servers with fallback and ranking strategies.
