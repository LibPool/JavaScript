> 标签: blockchain, defi, dex, dusa, limit-order, massa, mcp, mcp-server, model-context-protocol, swap, trading

## 简介

MCP server exposing the DusaCLI programmatic API — trade on the DUSA V2 protocol (Massa) from any MCP client (Claude Desktop, Vibe, Cursor): swaps, liquidity, limit orders, balances, order books
