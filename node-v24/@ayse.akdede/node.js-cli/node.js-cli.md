# @ayse.akdede/node.js-cli

> 标签: JavaScript

## 简介

Tool written in NODE.JS to list the holidays by the choosen year and country.   ## Install  $ npm install @ayse.akdede/node.js-CLI   $ npm link   ## Execute   npm @ayse.akdede/node.js-CLI [COUNTRY] [YEAR]. The year is optionnal, the defeult value is the c
