# @dahawa/hawa-hands

> 标签: JavaScript

## 简介

MCP server for Hawa Code providing file & shell tools (Read, Write, Edit, Glob, Grep, Bash, PowerShell). Designed to separate Agent reasoning from tool execution so tools can later be sandboxed.
