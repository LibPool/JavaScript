# @monosmith/plugin-sdk

> 标签: json-rpc, monosmith, plugin, sdk, smith

## 简介

The TypeScript SDK for writing smith plugins: the protocol's types, the serve loop, a test host, the conformance checks, templating and key-order-keeping JSON editing. No runtime dependencies.
