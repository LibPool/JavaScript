# @deanpress/big-integer

> 标签: arbitrary, arithmetic, big, bigint, biginteger, bignum, integer, math, precision

## 简介

A fork of Peter Olson's BigInter library that always assumes native BigInt is not supported.

## 官网

- 源码仓库：git@github.com:peterolson/BigInteger.js.git
- npm 页面：https://www.npmjs.com/package/@deanpress/big-integer
