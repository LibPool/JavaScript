# @farmost/social-agent

> 标签: ai, anthropic, claude-code, claude-code-skill, cli, llm, openai, social, social-relationship, wechat

## 简介

社交关系AI管家 - 独立 CLI 工具。自动追踪社交关系，帮你拟消息、记待办、维护人脉。v3.0 起支持多 LLM provider（Claude/OpenAI/MiniMax）。
