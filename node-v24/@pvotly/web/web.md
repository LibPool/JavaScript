# @pvotly/web

> 标签: data-grid, drag-and-drop, olap, pivot, pivot-grid, pivot-table

## 简介

Framework-agnostic pivot table UI: drag-and-drop field list, grid renderer, filters, conditional formatting, export and themes. Built on @pvotly/core.
