# @lnsy/data-table

> 标签: custom-elements, data-table, formulas, grid, spreadsheet, vanilla-js, web-component

## 简介

A dependency-free <data-table> web component: spreadsheet, table and list modes with formulas, endpoint lookups, wikilinks and file I/O.
