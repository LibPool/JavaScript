# @marinoscar/platform-ai-providers

> 标签: JavaScript

## 简介

Framework-free AI provider adapters (OpenAI, OpenAI-compatible, Azure OpenAI, Anthropic, Gemini) and their core types. Runs in a plain Node process: no Nest, no database, no OpenTelemetry SDK.
