# @loomfsm/dashboard

> 标签: agents, ai-agents, audit-trail, dashboard, durable-execution, human-in-the-loop, llm, orchestration, react, state-machine, web-ui

## 简介

loom's web control plane — a React SPA over the @loomfsm/server HTTP API. A PEER client of the same resolver the CLI drives: edit config/secrets/models, browse projects, submit tasks, answer gates. Ships as PREBUILT static assets the server serves at / —
