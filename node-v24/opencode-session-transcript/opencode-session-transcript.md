# opencode-session-transcript

> 标签: export, markdown, opencode, opencode-plugin, session, transcript

## 简介

OpenCode plugin that exports a session as readable Markdown. A correct /export: unlike the built-in it reads the whole session from SQLite, not just the loaded portion.
