# @donotlb/pi-node-docker

> 标签: bundle, distroless, docker, dotenvx, esbuild, healthcheck, node

## 简介

Build-time CLI for Node.js apps on minimal Docker runtimes: a validated single-file ESM bundle, a dotenvx preload, and a Node-based health check.
