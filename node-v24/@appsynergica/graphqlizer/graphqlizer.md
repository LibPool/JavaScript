> 标签: add class validator decorators, add class validator to typeorm entities, add decorators, add nestjs decorators, add nestjs graphql decorators, add nestjs graphql decorators to typeorm entities, remove decorators from TypeORM Entities

## 简介

A Command Line App for adding “code first” nestjs graphql decorators and or class validator decorators to TypeORM entities.
