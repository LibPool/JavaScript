# @cpp.js/package-jpegturbo-wasm

> 标签: cpp.js-package, jpegturbo, libjpeg-turbo, react-native, webassembly

## 简介

This package provides a libjpegturbo library compiled with Cpp.js, enabling seamless usage of JPEG functionalities in JavaScript, WebAssembly and React Native projects.
