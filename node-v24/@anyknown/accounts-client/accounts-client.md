# @anyknown/accounts-client

> 标签: JavaScript

## 简介

Server-side helpers for products that sign users in with Anyknown Accounts (`https://accounts.anyknown.com`). It gives a Hono app the three browser sign-in routes (`/api/auth/start`, `/api/auth/callback`, `/api/auth/logout`), a product session cookie, API
