# dsh-eval-guard

> 标签: bubblewrap, deepseek-harness, dsh, dsh-plugin, evaluation, sandbox, seccomp

## 简介

Evaluation guard for DSH: workspace-only filesystem, no network/subagents, wall-clock limits, and task installation for meow-ai-arena and benchmark tasks.
