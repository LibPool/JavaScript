# @leadconnector/vite-tanstack-config

> 标签: JavaScript

## 简介

Shared Vite configuration for LeadConnector TanStack Start previews. Requires Vite 7 or 8, matching the supported `@tanstack/react-start` peer. The standalone tagger, HMR gate, and dev-server bridge packages continue to support Vite 5 through 8.
