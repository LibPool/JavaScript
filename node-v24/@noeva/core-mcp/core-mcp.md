# @noeva/core-mcp

> 标签: JavaScript

## 简介

MCP server for the Noeva core APIs (workspaces, files, folders) — protocol adapter over the noeva-server-api REST API. Ships an HTTP service (central deploy) and a stdio package (client-distributable).
