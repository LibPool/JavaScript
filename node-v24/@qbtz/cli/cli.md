# @qbtz/cli

> 标签: cli, orchestrator, pennylane, qbtz, qiskit, quantum, venv

## 简介

The Elite Quantum Computing Environment Orchestrator — scaffold a real Python quantum venv (Qiskit + PennyLane), add starter circuits, run them, and check the env. `npx @qbtz/cli init`.
