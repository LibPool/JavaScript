# @kervan/transport

> 标签: ai-agents, mcp, mcp-server, model-context-protocol, stdio, streamable-http, typescript

## 简介

stdio and stateless Streamable HTTP transports for Kervan MCP servers: a Node.js server, a standard fetch handler and an in-memory test client.
