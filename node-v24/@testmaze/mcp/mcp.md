# @testmaze/mcp

> 标签: claude-code, cline, code-quality, cursor, exploratory-testing, mcp, model-context-protocol, playwright, test-management, testmaze, verifier

## 简介

Stdio bridge to the Test Maze MCP verifier for Claude Code, Cursor, Cline and other MCP agents: deterministic test verdicts, code-smell and architecture checks, and exploratory testing with your own browser. Token stays in a gitignored .env.testmaze.
