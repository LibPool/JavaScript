# @eatmedicine/ibrain-nmc-mcp

> 标签: JavaScript

## 简介

WorkBuddy connector runtime for Sundray NMC controllers (IBrainNMC AI Assistant): online users, access points, switches, network events, plus a documented passthrough for any open-API endpoint.
