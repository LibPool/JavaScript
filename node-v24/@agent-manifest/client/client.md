# @agent-manifest/client

> 标签: agent-declaration, agent-manifest, agent-manifest-spec, canonicalization, json-schema, rfc8785, structural-validation

## 简介

Reading client for Agent Manifest v1.0 declarations. Parses, canonicalises, fingerprints, compares and structurally validates manifests. It reports where a document came from and what cannot be concluded from it; it does not score, rank, certify or enforc
