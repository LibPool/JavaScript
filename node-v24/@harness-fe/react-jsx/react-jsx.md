# @harness-fe/react-jsx

> 标签: agent, data-morphix, harness-fe, jsx, jsxImportSource, source-aware

## 简介

Drop-in JSX runtime that adds data-morphix-loc to every rendered element in dev mode. Set tsconfig.jsxImportSource = '@harness-fe/react-jsx' and the Harness-FE agent can map any DOM node back to file:line:col with zero bundler config.
