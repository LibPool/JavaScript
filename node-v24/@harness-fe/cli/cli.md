# @harness-fe/cli

> 标签: JavaScript

## 简介

Harness-FE CLI — launches the gateway with an in-process core. `harness` (solo: stdio MCP + loopback /ws, zero-config), `harness serve` (shared headless HTTP gateway), or `harness --governed` (team: tokens + RBAC + audit over HTTP).
