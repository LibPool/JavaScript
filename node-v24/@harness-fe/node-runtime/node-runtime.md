# @harness-fe/node-runtime

> 标签: agent, harness-fe, mcp, next.js, node, server, tracing

## 简介

Node.js server-side SDK for Harness-FE. Captures server errors, console output, and Route Handler traces — links them to the browser session via a shared sessionId.
