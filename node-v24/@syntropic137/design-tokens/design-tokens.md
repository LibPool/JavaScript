# @syntropic137/design-tokens

> 标签: css-custom-properties, design-system, design-tokens, theming

## 简介

Design tokens for the Syntropic137 cross-framework design system: layered --ds-* CSS custom properties, a JSON snapshot and a typed token name list. Zero runtime dependencies.
