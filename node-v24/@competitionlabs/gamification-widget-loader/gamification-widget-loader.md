# @competitionlabs/gamification-widget-loader

> 标签: JavaScript

## 简介

Browser-side loader for the CompetitionLabs gamification widget. It retrieves the active widget configuration from the CompetitionLabs gateway, loads the JavaScript and CSS assets declared by that configuration, and mounts the widget in the containers sup
