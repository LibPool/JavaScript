# bash-wp-cli-update

> 标签: backup, bash, cli, fleet, maintenance, sysadmin, updates, wordpress, wp-cli, wp-cli-update

## 简介

Fleet maintenance for WordPress sites through WP-CLI: core, plugin and theme updates, database repair and optimisation, a database dump before anything changes, a restore path, JSON reports and a lock that stops two runs from overlapping.
