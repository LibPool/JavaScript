# hush-x402

> 标签: ai-agents, mcp, middleware, payments, privacy, solana, stealth-address, x402

## 简介

Private x402 middleware for Solana: sell any endpoint per call in SOL or USDC, every call paid to a one-time stealth address. Web Request/Response, works in Next.js, Hono, Workers, Bun.
