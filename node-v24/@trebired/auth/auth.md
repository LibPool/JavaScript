# @trebired/auth

> 标签: auth, authentication, bun, permissions, sessions, totp

## 简介

Authentication and permissions for Trebired apps: password credentials, session tokens and cookies, login sessions, TOTP two-factor, backup and activation codes, and a role-based permission engine, wired through .trebired/auth/config.ts.
