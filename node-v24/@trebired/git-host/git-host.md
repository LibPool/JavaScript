# @trebired/git-host

> 标签: actions, automation, backend, bun, git, git-forge, git-host, hosting

## 简介

Embeddable Git host and forge for Bun apps with real Git CLI execution, smart HTTP and SSH transports, repository automation, and backend APIs.
