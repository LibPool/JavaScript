# @reylosql/sqlite

> 标签: JavaScript

## 简介

Reylo's analysis engine for SQLite: the WebAssembly artifact reylo loads to type .sql files against a SQLite database. Install it beside reylo, at reylo's version.

## 官网

- 源码仓库：git+https://github.com/colinhacks/reylo.git
