# @shaftware/componecat-mcp

> 标签: componecat, developer-tools, mcp, mcp-server, modelcontextprotocol, software-catalog

## 简介

Stdio bridge for the Componecat MCP server — connect stdio-only MCP clients to your organization's software component catalog at app.componecat.ai.
