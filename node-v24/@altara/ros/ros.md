# @altara/ros

> 标签: altara, battery-state, dashboard, imu, monitoring, navsatfix, react, react-ros, real-time, robot-dashboard, robot-monitoring, robotics, ros, ros-bridge, ros-react, ros2, rosbridge, rosbridge-suite, sensor-msgs, telemetry, websocket

## 简介

ROS2 rosbridge adapter for React — pipe live sensor_msgs/* topics (IMU, GPS, battery, range, temperature) into real-time Altara dashboards. Typed factories, auto-reconnect, ROS timestamp normalization.
