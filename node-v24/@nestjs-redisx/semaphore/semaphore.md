# @nestjs-redisx/semaphore

> 标签: bulkhead, concurrency, distributed, nestjs, permits, redis, semaphore, throttle

## 简介

Distributed counting semaphore plugin for NestJS RedisX — bound concurrency across instances with permit leases, auto-renewal, and @WithSemaphore
