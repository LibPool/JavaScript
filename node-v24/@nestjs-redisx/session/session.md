# @nestjs-redisx/session

> 标签: express-session, fastify-session, nestjs, redis, revocation, session, session-management, session-store, spring-session

## 简介

Redis session management plugin for NestJS RedisX — express-session/@fastify/session store with per-user introspection, revocation, seat limits, and absolute lifetime caps
