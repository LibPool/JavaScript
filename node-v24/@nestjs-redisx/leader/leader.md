# @nestjs-redisx/leader

> 标签: cron, distributed, failover, leader, leader-election, nestjs, redis, scheduler, singleton

## 简介

Leader election plugin for NestJS RedisX — run cron jobs, migrations, and cleanup on exactly one instance, with heartbeat leases and automatic failover
