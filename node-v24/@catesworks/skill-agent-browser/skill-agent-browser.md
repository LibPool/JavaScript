# @catesworks/skill-agent-browser

> 标签: JavaScript

## 简介

Provides a fast CLI for browser automation over Chrome/Chromium via CDP, using accessibility-tree snapshots and compact element references to navigate pages, click, fill forms, take screenshots, and…
