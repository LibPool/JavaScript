# @tom-schorn/n8n-nodes-imap-enhanced

> 标签: ai, ai-tool, email, imap, n8n-community-node-package

## 简介

Enhanced IMAP node for n8n — fetch, search, move, flag and manage emails, usable as an AI Agent tool. Custom labels, limit parameters and structured email fields.
