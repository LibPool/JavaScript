# @anna-ai/app-runtime

> 标签: anna, anna-app, iframe, runtime, sdk

## 简介

Anna App browser runtime SDK. Loaded by every Anna App iframe; provides typed proxy over the postMessage RPC bridge to the host (Anna dashboard / `anna-app dev` harness).
