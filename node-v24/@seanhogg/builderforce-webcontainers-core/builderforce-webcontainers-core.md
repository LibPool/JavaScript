# @seanhogg/builderforce-webcontainers-core

> 标签: builderforce, dev-server, esbuild, in-browser, preview, sandbox, vite, webcontainer

## 简介

BuilderForce WebContainers — core. A runtime-agnostic in-browser dev server: virtual file system, module resolution, import rewriting to a package CDN, CSS/JSON/asset modules and project detection. No COOP/COEP required.
