# @seanhogg/builderforce-webcontainers

> 标签: builderforce, dev-server, esbuild-wasm, in-browser, preview, service-worker, webcontainer

## 简介

BuilderForce WebContainers — browser runtime. Boots an in-browser dev server for a project held in memory and serves it to an iframe through a service worker. Open source, no COOP/COEP, no session caps.
