# @pogly/spacetimedb-authz

> 标签: authorization, permissions, rbac, roles, spacetimedb, submodule

## 简介

Roles, scopes and grants for SpacetimeDB, as a submodule: wildcard permissions, inheritance, scope trees, expiring grants, invites, no privilege escalation, audit log and RLS helpers. Same schema as authz.rs / Authz.cs.
