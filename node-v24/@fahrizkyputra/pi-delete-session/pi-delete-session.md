# @fahrizkyputra/pi-delete-session

> 标签: cleanup, delete-session, pi, pi-extension, pi-package, session, trash

## 简介

Delete the active Pi session (and start a fresh one), or multi-select saved sessions to clean up. Confirmation first, extra confirmation for favorites, trash-safe deletion.
