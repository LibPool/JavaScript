> 标签: api, fake-data, mock, msw, openapi, postman, prism, swagger, typescript

## 简介

The Loutre engine: OpenAPI 3.x, Swagger 2.0, TypeScript types or Postman collections turned into a typed route table and realistic, coherent mock data.
