# @auditcore/ui-react

> 标签: JavaScript

## 简介

Native React-Komponenten (React 18 und 19) der FlowAudit-Oberflächen (Basis, Tabelle, Synopse, VVT, DSFA, Risiko-Merkmale, Screening, Stichprobe, Benford, Dokumentvergleiche, Geo-Karte, Kanban) auf Basis von @auditcore/ui-core und @auditcore/kanban-core,
