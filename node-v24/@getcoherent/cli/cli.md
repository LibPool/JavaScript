# @getcoherent/cli

> 标签: ai, ai-agents, claude-code, cli, code-generation, coherent, design-system, frontend, governance, mcp, nextjs, react, visual-regression

## 简介

Open-source platform that governs AI-built frontends: your coding agent designs and builds the UI; Coherent scopes every edit, verifies it in a real browser and rolls back what fails.
