# @snowbros/tokens

> 标签: css-variables, design-tokens, dtcg, motion-tokens, snowbros

## 简介

Motion, typography, spacing and color tokens (W3C DTCG format) with a functional vs expressive motion scale, exported as CSS custom properties and TypeScript.
