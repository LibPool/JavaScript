# @cf-commerce/mcp

> 标签: ai-agent, cli, cloudflare, commerce, ecommerce, mcp, model-context-protocol

## 简介

MCP (Model Context Protocol) stdio client for the Commerce Native platform — proxies tool calls to the remote MCP endpoint at /ucp/v1/mcp, handling session lifecycle and OAuth device-code authentication.
