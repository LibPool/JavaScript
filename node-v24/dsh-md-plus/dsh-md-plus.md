# dsh-md-plus

> 标签: code-block, deepseek-harness, dsh, dsh-plugin, markdown, mermaid, shiki, syntax-highlighting

## 简介

Markdown display enhancements for DeepSeek Harness Web: code block restyle, syntax highlighting for languages DSH does not ship, and built-in mermaid diagrams.
