# @mlmcps/sdd-mcp

> 标签: claude, mcp, spec-driven-development

## 简介

Read-only MCP server for spec-driven development: estate contract lookup, knowledge-layer checks, and spec inventory over a local repo, plus the toolkit's spec-driven commands served as MCP prompts.
