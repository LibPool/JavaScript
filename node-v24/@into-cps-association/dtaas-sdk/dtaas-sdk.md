# @into-cps-association/dtaas-sdk

> 标签: digital twins, dtaas, extensions, sdk, visualisation

## 简介

Contract for DTaaS web client extensions: extension and host-service types, visualisation schemas, validation helpers, a test harness and a shareable ESLint config.
