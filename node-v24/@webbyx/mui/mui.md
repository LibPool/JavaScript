# @webbyx/mui

> 标签: components, emotion, layout, material-ui, mui, next, nextjs, react, theme, ui

## 简介

Batteries-included MUI extension for Next.js: opinionated theme overrides, layout primitives (vertical / horizontal / blank), and higher-level components wired to a runtime settings store.
