# maplibre-polygon-editor

> 标签: editor, geojson, maplibre, polygon, snapping, territory, topology, vue

## 简介

Precise, topology-aware polygon editor for MapLibre GL, with a Vue 3 component. Shared borders stay shared; snapping helps but is never required.
