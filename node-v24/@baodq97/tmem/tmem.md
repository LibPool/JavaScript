# @baodq97/tmem

> 标签: agent, ai, claude, cli, llm, memory, rag, recall

## 简介

tmem — local long-term memory CLI for AI coding agents: L0→L3 memory tiers, hybrid FTS+vector recall, two-clock persona, health doctor, and a read-only visualiser.
