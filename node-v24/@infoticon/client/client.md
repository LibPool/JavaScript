# @infoticon/client

> 标签: api-client, ean, gtin, gus, infoticon, nip, openapi, sdk, vat

## 简介

Typed TypeScript client for the Infoticon API v2 (company, IP, email domain, product, country, exchange rate and card BIN lookups)
