# @cap2ui5/samples

> 标签: abap2ui5, cap, cap2ui5, cds, samples, sap, sapui5, ui5

## 简介

abap2UI5's samples as cap2UI5 apps: add the package to a CAP project and they run beside its own apps. Every sample a plain JavaScript class, translated from its ABAP original line for line.
