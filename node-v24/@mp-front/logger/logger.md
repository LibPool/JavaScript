# @mp-front/logger

> 标签: JavaScript

## 简介

Biblioteca de logging ligera para aplicaciones del ecosistema `@mp-front`. Provee logs con niveles, colores y filtrado configurable.

- npm registry：https://registry.npmjs.org/@mp-front/logger
- Node 要求：>=20.0.0
