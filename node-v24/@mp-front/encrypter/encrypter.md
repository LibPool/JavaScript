# @mp-front/encrypter

> 标签: JavaScript

## 简介

Biblioteca de encriptación/desencriptación basada en JWE (JSON Web Encryption) para el ecosistema `@mp-front`. Usa el algoritmo A256KW + A256GCM para proteger datos sensibles y SHA-256 para generar hashes.
