# @chaos-overlords/client

> 标签: chaos-overlords, client, game-server, multiplayer, rest, sdk, server-sent-events, sse, turn-based, typescript

## 简介

TypeScript client for the multiplayer server: typed REST calls and a resumable SSE event iterator. The reference for the game's C# client.
