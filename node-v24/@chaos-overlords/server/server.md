# @chaos-overlords/server

> 标签: chaos-overlords, game-server, hono, http-api, multiplayer, rest, server-sent-events, sse, turn-based

## 简介

The Hono application both runtimes serve: REST intents, the SSE event stream, auth and the error envelope. Takes its ports through a container.
