# leadsradar-dsh-plugin

> 标签: JavaScript

## 简介

探栗（LeadsRadar）AI 获客 · DeepSeek Harness 插件——再小的生意，也有自己的AI获客团队。宿主内置 dsh-mcp-client 以 stdio 拉起探栗适配器，带来 leadsradar_* MCP 工具与五大数字员工技能（情报栗现采现报/洞察栗拆解研究/创作栗存题下素材/成交栗评论挖客/管家栗调度应答）。
