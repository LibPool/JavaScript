# @lenso/web-ingress-workers

> 标签: JavaScript

## 简介

`@lenso/web-ingress-workers` connects a backend-authorized Lenso WebSocket session to Cloudflare's `WebSocketPair`. Use `createWebSocketTransport()` as the `upgradeWebSocket` option of Runtime's `createStreamingHttpHandler`.
