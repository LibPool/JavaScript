# @overworld-engine/adapters-savefile

> 标签: game, overworld, rpg, savegame, tauri

## 简介

Tauri adapter for Overworld: a hardened atomic-file-with-backups primitive (temp write, fsync, rotating backups, atomic rename) for desktop game saves
