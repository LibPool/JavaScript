# @mikeargento/bitgraph-sdk

> 标签: ai-audit, bitgraph, causal-order, proof, provenance, sdk

## 简介

Make and check BitGraphs from any stack: files are hashed locally, each SHA-256 is bound in one atomic action in the enclave, and the proof is saved beside the file.
