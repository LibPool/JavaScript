# @genmotion/cli

> 标签: ai-agents, animation, hyperframes-alternative, mcp, motion-graphics, mp4, remotion-alternative, render, threejs, video

## 简介

Make videos with code and coding agents. Three.js scenes, a live studio, headless MP4 rendering, and an MCP server — one CLI.
