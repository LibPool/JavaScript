# @igold/fe-bootstrap-vue

> 标签: bootstrap-vue, fe-bootstrap-vue

## 简介

使用 Bootstrap-Vue 框架開發的 UI Library，簡化了許多的 data 設定和 template 的壓縮，免去一些邏輯的設計，快速開發你的網站。
