# @rowsncolumns/pivot

> 标签: JavaScript

## 简介

AG Grid-style pivoting library for spreadsheets using DuckDB, adapted from [ag-grid-duckdb-datasource](https://github.com/arontsang/ag-grid-duckdb-datasource).
