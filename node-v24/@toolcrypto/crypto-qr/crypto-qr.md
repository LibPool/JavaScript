# @toolcrypto/crypto-qr

> 标签: address-validation, bip21, bitcoin, crypto, cryptocurrency, eip681, ethereum, payment, qr, qrcode, solana, solana-pay, tron, usdc, usdt

## 简介

Payment QR codes for crypto: checks the address, writes the payment link in the chain's own standard, draws the code as SVG or PNG.
