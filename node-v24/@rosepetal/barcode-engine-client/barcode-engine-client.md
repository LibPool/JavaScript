# @rosepetal/barcode-engine-client

> 标签: JavaScript

## 简介

Node client of rp-barcode serve, the persistent decode and verify service of rosepetal-barcode-sdk: one shared engine process per Node-RED runtime, framed requests over stdio, timeouts, bounded queue, restart with backoff
