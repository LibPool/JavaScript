# @db-state/server-mongo

> 标签: audit-log, db-state, event-sourcing, mongodb, permissions, rbac, realtime, rpc, sync, websocket

## 简介

MongoDB-backed server for db-state: CRUD, append-only log, sync, WebSocket RPC, group-based access objects with row filters and field-level rules, file-based custom methods.
