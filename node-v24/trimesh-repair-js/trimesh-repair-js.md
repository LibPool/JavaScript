> 标签: hole-filling, manifold, mesh, mesh-repair, mining, triangulation, trimesh

## 简介

Repair functions for the trimesh family of JavaScript meshing libraries: open loops, patching, closing, welding, orientation and mesh checks. Placeholder release - the code arrives in 0.1.0.
