# dsh-muse-code

> 标签: dsh, dsh-plugin, muse, muse-code, sidebar

## 简介

Muse Code inside DeepSeek Harness: a composer switch that opens a live Muse Code panel in the right sidebar, with the same session readable and controllable from chat tools.
