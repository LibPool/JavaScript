# @joaquimserafim/fetchx

> 标签: abort, abortcontroller, browser, client, fetch, http, isomorphic, json, node, signal, timeout, typescript

## 简介

Tiny, dependency-free fetch wrapper for Node and browsers: timeouts, signal merging, typed JSON helper, and a client factory.
