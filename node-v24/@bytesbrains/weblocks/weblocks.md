# @bytesbrains/weblocks

> 标签: ai, blocks, components, function-calling, lego, llm, manifest, site-generator, static-site, structured-output, web-builder

## 简介

Block engine for AI-composable web apps — the AI composes a SiteManifest from a fixed block catalog; the engine validates and renders it to static HTML. Snap-together "Lego" web building blocks, shareable across repos.
