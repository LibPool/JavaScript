# @genclass/mcp

> 标签: claude-code, coding-agent, debugging, double-submit, flaky, genclass, mcp, mcp-server, model-context-protocol, playwright, race-condition, stale-response

## 简介

GenClass for coding agents: an MCP server that sees what happens inside your app's pages (clicks, requests, the order responses arrived, state writes, errors), re-runs them with the network answering in different orders to find race conditions, and replay
