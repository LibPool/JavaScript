# @yangdongzhen590/dsh-code-smell

> 标签: JavaScript

## 简介

代码气味雷达（Code Smell Radar）：静态扫描仓库的 TODO/FIXME 债务、超长行、大文件、重复代码块与未实现桩，按严重度输出修复建议。全程只读，不执行测试/构建。（fork from lucky8197/dsh-code-smell）
