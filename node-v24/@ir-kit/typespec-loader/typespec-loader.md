# @ir-kit/typespec-loader

> 标签: codegen, ir-kit, loader, openapi, typespec

## 简介

Compile a TypeSpec file to an OpenAPI 3.x document in memory. Thin wrapper over @typespec/compiler + @typespec/openapi3 — plugs into any @ir-kit OpenAPI generator at the spec-loading boundary.
