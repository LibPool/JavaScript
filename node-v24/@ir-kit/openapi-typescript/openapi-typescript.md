# @ir-kit/openapi-typescript

> 标签: client, codegen, hey-api, openapi, sdk, typescript

## 简介

Thin programmatic wrapper around @hey-api/openapi-ts that ships a `generate()` matching the shape of @ir-kit/openapi-{go,kotlin,swift}, so the same sdk-regen workflow can target TypeScript clients (types + sdk + schemas + transformers + validators + ...)
