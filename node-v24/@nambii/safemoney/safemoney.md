# @nambii/safemoney

> 标签: bigint, currency, decimal, finance, foreign-exchange, fx, iso-4217, money, rounding, typescript

## 简介

Money-safe TypeScript primitives: currency-safe arithmetic with no floating-point errors, typed ISO 4217 currency codes, rounding policies, FX metadata, formatting and minor-unit conversion.
