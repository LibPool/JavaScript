# @houserules/plugin-github

> 标签: backlog, claude-code, github, github-projects, houserules, houserules-plugin, ledger

## 简介

houserules plugin: GitHub integrations. Ships a projects module that syncs the backlog and decision ledgers to GitHub Projects.
