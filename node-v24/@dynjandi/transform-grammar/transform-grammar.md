# @dynjandi/transform-grammar

> 标签: JavaScript

## 简介

The URL grammar for [Dynjandi](https://dynjandi.dev)'s image CDN: the one place a variant path such as `/<file-id>/-/resize/800x/-/format/webp/` is parsed, normalised, serialised and hashed.
