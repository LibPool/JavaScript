# @nestlingjs/logging

> 标签: esm, logger, logging, nestling, typescript

## 简介

Интерфейс логгера Nestling и штатная реализация: четыре уровня, три формы вызова, дочерний логгер с привязками, вывод в stderr текстом или JSON
