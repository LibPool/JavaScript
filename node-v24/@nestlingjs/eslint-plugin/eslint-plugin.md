# @nestlingjs/eslint-plugin

> 标签: eslint, eslintplugin, esm, lint, nestling, typescript

## 简介

Правила ESLint для кода на Nestling: граница модуля по баррель-файлу, форма условной примеси в объектный литерал, запрет глобалей процесса, подсказка про слой в декларации endpoint'а и список зависимостей класса против параметров конструктора
