# @nestlingjs/client

> 标签: contracts, esm, http-client, nestling, typed-client, typescript

## 简介

Типизированный HTTP-клиент из деклараций операций: вызов метода API устроен так же, как вызов порта, а зависимостей у пакета нет, кроме @nestlingjs/operations
