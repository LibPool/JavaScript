# @forma-ai/forma-mcp

> 标签: accessibility, axe-core, browser-automation, forma, lighthouse, mcp, model-context-protocol, playwright, ui-ux, website-audit

## 简介

Portable Playwright MCP server for UI/UX audits: inspect pages, capture screenshots, measure accessibility, performance, color, motion, and responsive layouts with user-controlled browser actions.
