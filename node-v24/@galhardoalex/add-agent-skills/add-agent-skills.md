# @galhardoalex/add-agent-skills

> 标签: agent-skills, ai, claude, claude-code, cli, codex, copilot, cursor, skill-md, skills

## 简介

Interactive CLI that installs curated, open source agent skills (SKILL.md) into .claude/skills, .agents/skills, .cursor/skills and .github/skills, always fetching the latest version from each skill's official GitHub repository.
