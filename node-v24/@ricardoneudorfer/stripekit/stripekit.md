# @ricardoneudorfer/stripekit

> 标签: billing, checkout, elements, invoices, payments, stripe, subscriptions, typescript

## 简介

A complete, production-ready Stripe integration toolkit for Node.js and TypeScript. Handles customers, payment methods, payments, checkout, subscriptions, invoices, coupons, webhooks and Stripe Elements with built-in timezone handling.
