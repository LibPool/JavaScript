# @sendai/monquery

> 标签: cursor, filter, keyset, mongodb, mongoose, odata, pagination, query, typegoose, url

## 简介

Readable URL filter grammar (OData-style) with schema-driven validation, MongoDB compilation and keyset pagination. One package, browser-safe core, opt-in server entry points.
