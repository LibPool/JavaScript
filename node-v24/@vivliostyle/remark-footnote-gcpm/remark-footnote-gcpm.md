# @vivliostyle/remark-footnote-gcpm

> 标签: JavaScript

## 简介

GCPM-style inline footnote plugin used by VFM. Emits `<span class="footnote">` elements at the call site, with duplicate references rendered as `<a class="footnote-duplicated-call">`.
