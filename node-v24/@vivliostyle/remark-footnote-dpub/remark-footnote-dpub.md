# @vivliostyle/remark-footnote-dpub

> 标签: JavaScript

## 简介

DPUB-ARIA inline footnote plugin used by VFM. Emits `<a role="doc-noteref">` calls with `<aside role="doc-footnote">` bodies placed after the containing block element.
