# @hypen-space/ios-streamer

> 标签: hypen, idb, ios, mjpeg, simctl, simulator, streaming, xcrun

## 简介

Stream and control iOS Simulators over HTTP/WebSocket. MJPEG video, tap/swipe/text input via xcrun simctl + idb.
