# @videoedit-mcp/bridge

> 标签: ai-agent, claude, cursor, mcp, model-context-protocol, videoedit

## 简介

Stdio MCP bridge for the VideoEdit-MCP desktop app — pure-Node HTTP/SSE client with -32001 session-expiry auto-recovery.
