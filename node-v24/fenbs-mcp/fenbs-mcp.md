# fenbs-mcp

> 标签: ai-agent, ai-agents, claude, claude-code, codex, cursor, fenbs, kanban, mcp, mcp-server, model-context-protocol, project-management, stdio, task-board, windsurf

## 简介

Connect any MCP client to your fenbs board over stdio. A tiny bridge to https://fenbs.ai/api/mcp for clients that cannot open a browser or speak remote MCP.

## 官网

- 官网：https://fenbs.ai/integrations
- npm 页面：https://www.npmjs.com/package/fenbs-mcp
