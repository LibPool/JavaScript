# @firemoot/stream-compat

> 标签: chat, compatibility, firemoot, migration, sdk, stream-chat, typescript

## 简介

A drop-in adapter exposing the getstream.io `stream-chat` API surface over @firemoot/client, so a Stream app can switch to Firemoot by changing configuration only.
