# @stwrd-auth/core

> 标签: authentication, cloudflare-workers, management-api, node, oauth2, oidc, sessions, stwrd, webhooks

## 简介

Runtime-neutral core of the stwrd JavaScript SDKs: configuration, OIDC relying-party client, sessions, signed cookies, webhook verification and the Management API transport.
