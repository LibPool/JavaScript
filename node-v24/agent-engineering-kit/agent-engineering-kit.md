# agent-engineering-kit

> 标签: agents-md, ai-agents, claude-code, codex, coding-agent, cursor, developer-tools, gemini-cli, github-copilot, skills, subagents

## 简介

Make AI coding agents (Claude Code, Codex, Cursor, Copilot, Gemini CLI and more) ship clean, maintainable code. A safe GUI/terminal installer for rules, agents, skills and hooks, for any project.
