# @vericto/sdk

> 标签: ai-agents, better-sqlite3, firewall, langchain, security, snowflake, sql, sqlite, vericto

## 简介

Official Vericto SDK for Node.js: check every SQL statement with Vericto before it runs. Wrappers for snowflake-sdk and better-sqlite3, LangChain.js SQL agents, and a client for the Vericto Runtime API.
