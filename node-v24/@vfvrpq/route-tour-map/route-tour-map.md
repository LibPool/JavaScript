# @vfvrpq/route-tour-map

> 标签: bilibili, globe, html-generator, map, maplibre, route, timeline, video, visualization

## 简介

Generate a cinematic dark route-map web page from episode/trip data: globe projection, great-circle arcs, timeline auto-tour, click-to-open detail cards. Zero build, single HTML output.
