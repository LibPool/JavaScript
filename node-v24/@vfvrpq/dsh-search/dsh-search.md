# @vfvrpq/dsh-search

> 标签: deepseek, deepseek-harness, dsh, dsh-plugin, fetch, rag, search, web-search

## 简介

DeepSeek first-party Search/Fetch API for DeepSeek Harness: three tools (deepseek_search / deepseek_fetch / deepseek_research) that return structured, reranked web results with search operators, page-to-Markdown fetching, and cost-aware defaults.
