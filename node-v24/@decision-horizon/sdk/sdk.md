# @decision-horizon/sdk

> 标签: JavaScript

## 简介

In-process hook for Node agents: signed, hash-chained Agent Decision Records (adr/0.2) that the Python `dh verify` accepts, and a `dhjs` command line (keygen, verify, push, watch). Automatic upload to the hosted store and offline Ostiary risk scoring, com
