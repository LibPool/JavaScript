# @projectura/mcp

> 标签: mcp, mcp-remote, projectura, stdio

## 简介

Shim stdio→HTTP do conector MCP do Projectura. Ponte DIRETA (sem dependências, sem subprocesso) para clientes MCP que só falam stdio (ex.: Claude Desktop).
