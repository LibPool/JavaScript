# broken-translate

> 标签: detect-language, fetch, i18n, l10n, language, mymemory, translate, translation, translator, zero-dependency

## 简介

Zero-dependency translation for Node. Auto-detect, batch, and long-text support using the built-in fetch. No axios, no SDK, nothing to install.
