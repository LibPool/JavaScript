# @letar/forms-query

> 标签: combobox, forms, react, react-query, select, tanstack-query, typescript, zenstack

## 简介

TanStack Query adapters for @letar/forms — option sources for Select and Combobox (search, selected record, invalidation), works with both the Chakra and the shadcn skin. ZenStack helpers in a separate entry point.
