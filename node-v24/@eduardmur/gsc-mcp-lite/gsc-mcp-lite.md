# @eduardmur/gsc-mcp-lite

> 标签: claude, google-search-console, gsc, mcp, mcp-server, model-context-protocol, search-console, seo

## 简介

The Google Search Console Performance report over MCP: clicks, impressions, CTR and position by query, page, country, device and date. Read-only, one credentials file, no analysis layer.
