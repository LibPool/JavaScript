# @godspeedai/cognate-provider-openai-oauth

> 标签: JavaScript

## 简介

Sign in with ChatGPT (SIWC) OAuth/OIDC credential adapter: dynamic client registration, PKCE sign-in, validated tokens, rotating refresh, and governed subscription inference.
