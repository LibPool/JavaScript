# @uxndigital/eslint-config-base

> 标签: JavaScript

## 简介

A shared flat ESLint configuration for JavaScript and TypeScript projects at UXN Digital. It includes ESLint recommended rules, TypeScript support, import sorting, unused-import detection, and Prettier integration.
