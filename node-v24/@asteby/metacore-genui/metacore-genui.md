# @asteby/metacore-genui

> 标签: JavaScript

## 简介

Metacore generative UI - validates and renders the agent's declarative genui/v1 specs (cards, KPIs, tables, links, timelines, charts, confirmation forms) from a closed whitelist, with no HTML or scripts.
