# @skyhighmedia/byok-vault

> 标签: api-keys, byok, encryption, secrets, supabase, vault

## 简介

BYOK provider-key vault — encrypted at rest in Supabase Vault, decrypted only server-side at point of use. The actual module SkyHighMedia apps run.
