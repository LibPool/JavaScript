# @kasava/prompt-builder

> 标签: ai, anthropic, ast, builder, claude, fluent, llm, openai, orm, prompt, prompt-engineering, prompt-orm, typescript

## 简介

A prompt ORM for TypeScript. Typed variables, a composable template tag, an inspectable AST, and pluggable output dialects.
