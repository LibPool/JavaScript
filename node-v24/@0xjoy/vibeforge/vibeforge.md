# @0xjoy/vibeforge

> 标签: JavaScript

## 简介

CLI for [VibeForge](https://vibeforgescanner.vercel.app) - scans local codebases for security issues, AI slop, code smells, and performance problems. Outputs a scored, graded report directly in your terminal.
