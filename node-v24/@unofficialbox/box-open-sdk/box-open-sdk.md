# @unofficialbox/box-open-sdk

> 标签: api-client, box, box-api, sdk, typescript, unofficial

## 简介

Box API client for TypeScript (open source, community, punk rock) — typed models, async managers, and a fetch runtime with retry, backoff, and token refresh.
