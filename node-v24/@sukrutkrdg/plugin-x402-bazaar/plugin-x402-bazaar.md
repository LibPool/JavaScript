# @sukrutkrdg/plugin-x402-bazaar

> 标签: ai-agents, base, eliza, elizaos, near, plugin, swap, token-safety, x402

## 简介

Check, then act — x402 Bazaar plugin for ElizaOS: pre-trade GO/HOLD/STOP on Base and NEAR, best-price swaps on Base (0x) executed from the agent's wallet, cross-chain swaps through NEAR Intents, and 150+ pay-per-call agent APIs.
