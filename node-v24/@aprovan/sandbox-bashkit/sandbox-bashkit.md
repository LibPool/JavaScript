# @aprovan/sandbox-bashkit

> 标签: aprovan, bashkit, sandbox, utdk, wasm

## 简介

Run Aprovan sandboxes in-process on WASM: the @utdk/sandbox driver backed by bashkit's bash interpreter and virtual filesystem — no container, no credential, works in Node and the browser
