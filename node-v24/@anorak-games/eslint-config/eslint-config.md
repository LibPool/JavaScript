# @anorak-games/eslint-config

> 标签: anorak, eslint, eslint-config, eslintconfig

## 简介

Shared ESLint flat-config for Anorak projects — one frontend factory (Expo client + Vite admin) and one backend config, so the convention rules live in a single place.
