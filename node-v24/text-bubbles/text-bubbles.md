# text-bubbles

> 标签: animation, astro, bubbles, canvas, custom-element, hero, interactive, particles, react, text, typography, web-component

## 简介

Text drawn as interactive particles that scatter around the pointer. Tiny, dependency-free canvas core with React and custom element adapters.
