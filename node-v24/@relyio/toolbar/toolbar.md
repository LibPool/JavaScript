# @relyio/toolbar

> 标签: preview, relyio, toolbar

## 简介

The RelyIO preview toolbar: a development-only, shadow-DOM panel showing the dataset, branch, key and sandbox a page is reading from, and badging each bound field published or draft with a Studio link, over @relyio/sdk.
