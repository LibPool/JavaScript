# @battlestack/cli

> 标签: boilerplate, cli, drizzle, generator, nuxt, nuxt4, scaffold, scaffolding, starter, tailwind, template

## 简介

Battlestack CLI engine — open-source scaffolding tool. Loads extra capabilities from installed battlestack plugins. Install/run via the unscoped `battlestack` wrapper (`npx battlestack`).
