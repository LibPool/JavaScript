# evernode-mcp

> 标签: blockchain, determinism, evernode, hotpocket, linter, mcp, model-context-protocol, smart-contracts, xahau

## 简介

Model Context Protocol (stdio) server for Evernode/HotPocket dApps: contract templates, a heuristic non-determinism linter, contract-API checks, EVR lease math, live host lookup via OnLedger, and deploy/settlement command generation. Advisory only: holds
