# @delphi-labs/shuttle

> 标签: blockchain, cosmos, cosmos-sdk, dapp, react, typescript, wallets

## 简介

Shuttle is open-source npm package designed to turn wallet connections into a plug-and-play Lego brick for Cosmos Dapps.
