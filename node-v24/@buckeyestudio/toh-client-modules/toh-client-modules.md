# @buckeyestudio/toh-client-modules

> 标签: JavaScript

## 简介

Client module system, dual-face: node half composes the __TOH_BOOT__ entry graph (incremental toh.client scan, bundle route, index tap, webPlugins service); browser half is the lazy-CJS module table the vendored cordis Loader consumes as its internal seam
