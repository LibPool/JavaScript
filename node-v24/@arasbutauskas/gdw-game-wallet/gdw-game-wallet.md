# @arasbutauskas/gdw-game-wallet

> 标签: age-assurance, eudi, game, gdw, sd-jwt, verifiable-credentials

## 简介

Game Digital Wallet (GDW) reference framework - SD-JWT-style credentials for game engines and services. Byte-for-byte compatible with the C++, C#, GDScript, Rust, Python and Lua ports.
