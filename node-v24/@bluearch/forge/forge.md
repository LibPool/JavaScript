# @bluearch/forge

> 标签: agents, ai, claude, claude-code, developer-tools, gitflow, harness, task-management

## 简介

A portable, self-managing development harness for Claude Code projects: goal decomposition, bite-sized tested tasks, GitFlow gates, security review, and per-project adoption. 13 agents, /forge:* commands, git hooks.
