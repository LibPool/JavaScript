# @forjio/catentio-saas-node

> 标签: agent-platform, catentio, forjio, operator

## 简介

Official Node.js SDK for Catentio. `PublicClient` speaks the public API (https://catent.io/v1 — API-key auth: agents, templates, runs, projects, webhooks). `CatentioSaasClient` speaks the internal control plane (session-cookie auth via @forjio/sdk).
