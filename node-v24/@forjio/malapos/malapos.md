# @forjio/malapos

> 标签: forjio, malapos, point-of-sale, pos, sdk

## 简介

Malapos SDK — typed JS/TS client for the malapos.com point-of-sale REST API: every route of the API as client.api.<area><Action>(). Sister to the Python + Go SDKs.
