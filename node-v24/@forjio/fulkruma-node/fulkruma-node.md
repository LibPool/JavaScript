# @forjio/fulkruma-node

> 标签: biteship, forjio, fulfillment, fulkruma, indonesia, shipping

## 简介

Official Node.js SDK for Fulkruma — stock, warehouses, shipping (Biteship), licenses, deliveries, API keys, audit log, billing, integrations status, stats, webhooks. Platform-partner mode for Storlaunch.
