# @forjio/huudis-node

> 标签: auth, forjio, huudis, iam, jwt, oidc, openid-connect

## 简介

Official Node.js SDK for Huudis — email/social/MFA, fine-grained authorization, webhook signature verification, and full admin API (IAM, workspaces, end-users, billing, webhook subscriptions). Powered by @forjio/sdk's device-flow auth + http-client.
