# @forjio/ripllo-cli

> 标签: JavaScript

## 简介

CLI for Ripllo — HMAC-authenticated wrapper over @forjio/ripllo-node covering 28 typed command groups: the six named marketing domains (discount, referral, abandoned-cart, pixel, feed, blog) plus auth, billing, campaigns, marketing-campaigns, programs, co
