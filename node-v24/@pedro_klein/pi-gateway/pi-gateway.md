# @pedro_klein/pi-gateway

> 标签: coding-agent, fallback, gateway, pi, pi-package

## 简介

Gateway extension for Pi — virtual provider exposing tier aliases (heavy/medium/light) that route to registered backends with automatic failover on cap hits
