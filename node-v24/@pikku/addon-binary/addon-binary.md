# @pikku/addon-binary

> 标签: JavaScript

## 简介

Convert between binary file data (base64) and JSON, without any heavy parser dependencies. For format-specific parsing use `@pikku/addon-read-pdf`, `@pikku/addon-spreadsheet`, or `@pikku/addon-xml`.
