# @pikku/addon-typesafe

> 标签: JavaScript

## 简介

[TypeSafe System One](https://console.typesafe.ai) as a Pikku addon. It returns typed judgments and calibrated probabilities, not generated text, which makes it useful for the small decisions a program has to make about its own work.
