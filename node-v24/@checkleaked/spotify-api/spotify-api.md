> 标签: api-client, charts, concerts, lyrics, music, rapidapi, sdk, spotify, spotify-api, spotify-data, spotify81, typescript

## 简介

Zero-dependency TypeScript SDK for the Spotify Data API (checkleaked). RapidAPI spotify81-compatible. Fully typed coverage of every endpoint.
