# @cosmstack/repoeject

> 标签: cleanup, cli, command-line, developer-tools, github, github-api, github-cleanup, github-profile, github-repositories, inactive-repos, interactive-cli, repo-deletion, repository, repository-cleanup, repository-management

## 简介

Interactive CLI tool to safely find and delete old or inactive GitHub repositories. Clean up your GitHub profile by removing abandoned projects, old experiments, and unused forks.
