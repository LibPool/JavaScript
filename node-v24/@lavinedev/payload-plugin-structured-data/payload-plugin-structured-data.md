# @lavinedev/payload-plugin-structured-data

> 标签: json-ld, payload, payload-plugin, payloadcms, rich-results, schema.org, seo, structured-data

## 简介

Schema.org structured data (JSON-LD) for Payload CMS: Organization, WebSite, Article, BlogPosting, Service, WebPage, FAQPage and BreadcrumbList, editable in the admin.
