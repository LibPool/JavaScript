# @buddysh/buddy

> 标签: ai, ai-code-review, bot, buddy, bun, code-review, coderabbit, dependabot, dependency-management, dependency-updates, javascript, pull-request-review, renovate, typescript

## 简介

AI code review and dependency updates in one bot. Reviews pull requests and local changes, answers @buddy comments, gates merges, repairs failing CI, and keeps dependencies current across npm, Composer, Docker, GitHub Actions and more.
