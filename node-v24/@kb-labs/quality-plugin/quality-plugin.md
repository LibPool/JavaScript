# @kb-labs/quality-plugin

> 标签: JavaScript

## 简介

KB Labs Quality Plugin provides monorepo health checks, dependency analysis, and automated fixes. Ensures code quality through comprehensive diagnostics, type safety validation, and intelligent dependency management across packages.
