# @ap3x/solana-webhooks

> 标签: JavaScript

## 简介

Webhook ingestion as a peer transport to Geyser for the AP3X Solana substrate. Receiver, outbox-first persistence, HMAC verify, backpressure, gap catchup. Helius is the first driver.
