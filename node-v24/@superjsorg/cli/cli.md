# @superjsorg/cli

> 标签: cli, compiler, javascript, null-safety, pattern-matching, sum-types, superjs, typescript

## 简介

The Super.js command-line compiler — build, check, and explain .sjs files. A null-safe, sum-typed superset of JavaScript.
