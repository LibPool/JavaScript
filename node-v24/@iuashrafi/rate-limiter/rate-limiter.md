# @iuashrafi/rate-limiter

> 标签: distributed-systems, express, middleware, rate-limiter, rate-limiting, redis, sliding-window, throttle, token-bucket

## 简介

A production-grade, distributed rate limiting library for Node.js with pluggable algorithms (fixed window, sliding window log, sliding window counter, token bucket, leaky bucket) and pluggable storage (in-memory, Redis).
