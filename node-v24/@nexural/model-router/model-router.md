# @nexural/model-router

> 标签: JavaScript

## 简介

Family→ID resolver for LLM provider models. Stable family references (e.g. anthropic:opus) resolved to volatile concrete model IDs with deprecation + price-ceiling awareness. Per ADRs 0007, 0010.
