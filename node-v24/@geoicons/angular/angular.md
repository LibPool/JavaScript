# @geoicons/angular

> 标签: JavaScript

## 简介

799 geographic map SVG icons (255 countries & territories + 167 world areas + 377 subdivisions) as tree-shakable Angular standalone components — control weight and fill, dual-licensed GPLv3 + Commercial.
