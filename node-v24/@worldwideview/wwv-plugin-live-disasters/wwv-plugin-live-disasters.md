# @worldwideview/wwv-plugin-live-disasters

> 标签: JavaScript

## 简介

Dynamic WorldWideView data-layer plugin surfacing global natural-disaster alerts from the Global Disaster Alert and Coordination System (GDACS) 24-hour RSS feed: earthquakes, tropical cyclones, floods, droughts, volcanoes and other hazards.
