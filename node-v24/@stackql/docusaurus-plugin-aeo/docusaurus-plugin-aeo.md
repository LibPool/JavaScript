# @stackql/docusaurus-plugin-aeo

> 标签: aeo, ai, answer-engine-optimization, docusaurus, llms.txt, plugin, seo

## 简介

AEO (Answer Engine Optimization) helpers for Docusaurus: .md companion files, llms.txt / llms-full.txt, an Ask AI dropdown, and /ai/* route conventions.
