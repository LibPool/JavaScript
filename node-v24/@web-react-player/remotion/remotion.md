# @web-react-player/remotion

> 标签: audio-mixer, browser, canvas-export, motion-graphics, player, react, remotion, tree-shaking, tsx-compiler, video-editor, video-player, webcodecs

## 简介

Remotion integration suite for Web React Player: in-browser TSX compiler, WebCodecs MP4/WebM exporter, dynamic audio mixer, scenario adapters and widget runtime.
