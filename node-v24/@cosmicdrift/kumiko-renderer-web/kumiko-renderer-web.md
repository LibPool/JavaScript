# @cosmicdrift/kumiko-renderer-web

> 标签: JavaScript

## 简介

Web-platform bindings for @cosmicdrift/kumiko-renderer. HTML default-primitives, browser history-based navigation, EventSource-backed live events, and a one-call createKumikoApp that mounts the whole stack via react-dom.
