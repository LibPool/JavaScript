# @inkefe/create-decorator

> 标签: create-decorator, decorator, es6 decorator, high order function decorator

## 简介

支持在高阶函数基础上直接创造一个es6装饰器, 并可以兼容箭头函数、静态函数、普通prototype函数, 可以说是万能装饰器
