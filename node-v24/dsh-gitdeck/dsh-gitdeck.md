# dsh-gitdeck

> 标签: cordis, deepseek-harness, device-flow, dsh, github, github-api, oauth, pat, plugin

## 简介

Git 操作台：在 DSH 里连接你的 GitHub 账号，让 AI 以你的身份建仓库、传文件、读 PR、查 Actions。OAuth 设备流与 Token 两种接法，只读模式与调用留痕开箱可用。
