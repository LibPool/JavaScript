# @hardhat-kms/aws

> 标签: aws, aws-kms, cloudtrail, ethereum, ethers, hardhat, hardhat-ignition, hardhat-kms, hardhat-plugin, hardhat3, hsm, kms, signer, smart-contracts, viem

## 简介

AWS KMS signer for Hardhat 3 (hardhat-kms provider): secp256k1 keys never leave KMS; signing history from CloudTrail.
