# @tarekeldeeb/quran-madina-react

> 标签: arabic, madina, mushaf, quran, quran-madina-html, react

## 简介

React wrapper for the quran-madina-html custom element — render Madina-style Quran pages (no images) in React on web and mobile (via a Capacitor WebView).
