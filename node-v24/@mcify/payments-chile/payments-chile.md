# @mcify/payments-chile

> 标签: JavaScript

## 简介

Vendor-agnostic types and helpers for Chilean payment-link APIs (Khipu, Mercado Pago, Webpay, Smart Checkout). Used by mcify connectors to expose a portable shape across vendors.
