# @yellow-org/sdk

> 标签: chain abstraction, chain agnostic, ethereum, high-speed, layer 2, layer 3, nitro, nitrolite, scaling, state channels, statechannels, yellow, yellow-org

## 简介

The Yellow SDK empowers developers to build high-performance, scalable web3 applications using state channels. It's designed to provide near-instant transactions and significantly improved user experiences by minimizing direct blockchain interactions.
