# @boxy-design/behaviors

> 标签: JavaScript

## 简介

Framework-free behaviours for Boxy components: menus, tooltips, toasts, combobox, calendar, slider, kanban, panes, data grid, colour picker, inbox and charts. Works on the markup every @boxy-design package renders.
