# @durely/garmin-insights-mcp

> 标签: claude, fitness, garmin, garmin-connect, mcp, model-context-protocol

## 简介

durely insights: an MCP server for your own Garmin data, via Garmin's official Personal API. Full history kept locally, analysed down to the second. Unofficial.
