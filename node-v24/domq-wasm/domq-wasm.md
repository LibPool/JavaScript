# domq-wasm

> 标签: cloudflare-workers, css-selector, dom, html, html-to-markdown, html-to-text, markdown, parser, scraper, wasm

## 简介

Tiny, forgiving HTML parser for JavaScript (WebAssembly): CSS selectors, readable text, Markdown and JSON from messy HTML. Zero JS dependencies.
