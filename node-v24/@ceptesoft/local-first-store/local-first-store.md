# @ceptesoft/local-first-store

> 标签: debounce, local-first, offline-first, persist, storage, zustand

## 简介

Offline-first persistence plumbing: debounced and version-stamped storage decorators (zustand-persist compatible) plus keyed-collection upsert/remove helpers. Zero dependencies.
