# @kidlab/dsh-kid-security

> 标签: dsh, dsh-plugin, kid, security

## 简介

给小朋友的「电脑安全 / 城堡守卫」启蒙插件：防火墙、磁盘加密、锁屏、远程端口、登录记录五个模型工具，外加一张常驻输入条上方的 🐕 卡片（DeepSeek Harness / Cordis bundle）。
