# @aliksir/neko-harness-doctor

> 标签: anti-pattern, audit, claude, claude-code, cli, diagnostic, harness, kv-cache, prompt-caching

## 简介

Diagnose Claude Code harness (CLAUDE.md, settings.json, .mcp.json, hooks, skills, memory, MCP, workflow) against 33 anti-pattern indicators. Outputs S-E grade and prioritized Quick Wins with interactive fix proposals.
