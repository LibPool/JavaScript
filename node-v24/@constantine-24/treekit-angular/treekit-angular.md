# @constantine-24/treekit-angular

> 标签: accessibility, angular, dnd, drag-and-drop, keyboard, tree, tree-view, treeview, virtual-scroll, virtualized

## 简介

Angular component over @constantine-24/treekit-core: virtualized tree with native HTML5 drag-and-drop, keyboard-accessible DnD, filtering, and lazy loading. No Material or CDK dependency.
