# @vobiz/mcp

> 标签: ai-agents, claude, ivr, mcp, mcp-server, model-context-protocol, rcs, sip-trunking, sms, telephony, vobiz, voice-api

## 简介

Official Vobiz MCP server: voice calls, in-call control, VobizXML IVRs, call records, recordings, phone numbers, SIP trunks, SMS/MMS/RCS and the Vobiz Agent Skills for Claude and any MCP client.
