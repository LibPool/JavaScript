# @mr-huang/node-cli-utils

> 标签: JavaScript

## 简介

```bash cau git [path] [deep] # 批量提交文件  场景解决无法大批量提交的场景 cau rename [dir] [format] [filter]  #批量重命名文件， dir父级文件夹 format 命名格式[number]代表数字[prefix|p]前缀[suffix|s]后缀eg:{prefix:test}测试文件{number}{suffix:end} filter过滤需要操作的文件 ```
