> 标签: blake3, cavs, content-addressed, dedup, deduplication, fastcdc, object-storage, s3, sdk

## 简介

Official TypeScript SDK for the CAVS Deduplication Service — content-defined chunking, tenant-scoped deduplication and versioned objects over your own object storage.
