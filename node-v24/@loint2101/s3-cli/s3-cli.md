# @loint2101/s3-cli

> 标签: aspnet, build, cli, deploy, dotnet, msbuild, publish, zip

## 简介

CLI tool for building and publishing .NET projects with MSBuild. Supports multiple project profiles, auto-zip, and customizable clean rules.
