# cdpfleet-mcp

> 标签: agents, browser, cdpfleet, claude, cursor, mcp, model-context-protocol, playwright

## 简介

MCP server for cdpfleet: let Claude, Cursor or any MCP client drive real remote browsers — Chrome, Edge, Firefox, Camoufox and more — with residential proxies and live-view handoff.
