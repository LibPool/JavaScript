# winsechunter

> 标签: abuse-report, dfir, event-log, forensics, incident-response, powershell, security, stix, windows

## 简介

Incident-response toolkit for Windows security events: collect by IP, analyze, report, preserve evidence. Thin CLI launcher for the WinSecHunter PowerShell module.
