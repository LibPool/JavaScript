# @ohtokaah-sys/dsh-memory-host

> 标签: deepseek-harness, dsh, dsh-plugin, memory, storage-domain

## 简介

记忆 domain host 插件：用 storageDomain 开一次 'memory' domain（画像表 + 记忆表），供 preset 侧 dsh-memory 用 get() 取。
