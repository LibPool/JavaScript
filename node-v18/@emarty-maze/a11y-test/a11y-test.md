# @emarty-maze/a11y-test

> 标签: a11y, accessibility, accessibility-testing, automation, axe, axe-core, compliance, playwright, testing, wcag, wcag21, wcag2a, wcag2aa, web-accessibility

## 简介

Standalone accessibility testing tool for any website using axe-core and Playwright. Test WCAG 2.0/2.1 compliance with configurable scenarios, password protection support, and multiple output formats (HTML, JSON, Markdown).
