# @soltein-net/solt-odoo-rpc

> 标签: JavaScript

## 简介

Generic, domain-agnostic Odoo XML-RPC client, auth, and typed errors. No knowledge of any specific Odoo model/domain (helpdesk, project, ...) and no MCP dependency by design.
