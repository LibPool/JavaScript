# @voqalize/client-transport

> 标签: getusermedia, mediamanager, pipecat, screenshare, smallwebrtctransport, voice-ai, webrtc

## 简介

An open implementation of pipecat's MediaManager protocol for SmallWebRTCTransport. Owns the microphone, camera and screen share in the browser using navigator.mediaDevices alone.
