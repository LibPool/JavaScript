# @cinefiller/mcp-server

> 标签: cinefiller, mcp, model-context-protocol, video-generation

## 简介

Cinefiller MCP server — a stdio bridge to the hosted Cinefiller API (www.cinefiller.com/mcp). Same API key, same credits, same projects as the REST API.
