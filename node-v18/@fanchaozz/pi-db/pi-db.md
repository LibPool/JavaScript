# @fanchaozz/pi-db

> 标签: agent-tools, database, db-tools, extension, mysql, mysql2, pi, pi-agent, pi-extension, pi-package, sql-server, sqlcmd, sqlserver

## 简介

Unified database extension for pi coding agent: one db_* toolset across SQL Server 2008 (sqlcmd backend) and MySQL 8 (mysql2 pool), with an extensible dialect registry for future databases.
