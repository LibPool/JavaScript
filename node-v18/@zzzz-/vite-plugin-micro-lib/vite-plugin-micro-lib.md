# @zzzz-/vite-plugin-micro-lib

> 标签: JavaScript

## 简介

`vite-plugin-micro-lib` 是一个用于构建微型库的 Vite 插件。它可以帮助你将多个外部依赖打包成独立的模块，并生成相应的导入映射。
