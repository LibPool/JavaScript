# @minders/amplitude-wrapper

> 标签: ampli, amplitude, amplitude-analytics, analytics, minders, react-native, tracking, typescript, wrapper

## 简介

Wrapper de Minders sobre el SDK de Amplitude para TypeScript Web y React Native, con CLI integrado para sincronizar la definición de eventos vía ampli pull.
