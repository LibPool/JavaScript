> 标签: ai-friendly, audio, cloudflare-stream, data-channel, meshcast, p2p, peer-to-peer, streaming, twitch, vdo.ninja, video, webrtc, webrtc-http, whep, whip

## 简介

AI-friendly P2P communication SDK for audio, video, and data. Includes WHIP/WHEP clients for publishing to Twitch, Meshcast, Cloudflare Stream
