# @crossbind/port-tiff-wasm

> 标签: crossbind, crossbind-package, image, libtiff, tiff, wasm, webassembly

## 简介

WebAssembly build of the precompiled TIFF (libtiff) image library, built with crossbind. Use it together with the main package @crossbind/port-tiff.
