# @crossbind/port-lerc-ios

> 标签: crossbind, crossbind-package, ios, lerc, libLerc, raster-compression, react-native

## 简介

iOS build of the precompiled LERC (Limited Error Raster Compression) library, built with crossbind. Use it together with the main package @crossbind/port-lerc.
