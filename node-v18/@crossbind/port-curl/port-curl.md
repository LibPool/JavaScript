# @crossbind/port-curl

> 标签: android, crossbind, crossbind-package, curl, http, ios, libcurl, networking, react-native, wasm, webassembly

## 简介

This package provides a CURL library compiled with crossbind, enabling seamless usage of CURL functionalities in JavaScript, WebAssembly and React Native projects. Client-side URL transfers for web and mobile applications.
