# @crossbind/port-gdal-bin-wasi

> 标签: crossbind, crossbind-package, gdal, gdal-cli, geospatial, gis, raster, vector, wasi, wasmtime, webassembly

## 简介

The upstream `gdal` command-line interface prebuilt as a single WASI (wasm32-wasip3) command component. Install, point wasmtime at the shipped .wasm and data folder, and run - no compiler involved.
