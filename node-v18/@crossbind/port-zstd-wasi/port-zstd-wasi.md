# @crossbind/port-zstd-wasi

> 标签: compression, crossbind, crossbind-package, libzstd, wasi, webassembly, zstandard, zstd

## 简介

WASI build of the precompiled Zstandard (zstd) library, built with crossbind. Use it together with the main package @crossbind/port-zstd.
