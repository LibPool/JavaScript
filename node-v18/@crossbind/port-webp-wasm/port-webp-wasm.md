# @crossbind/port-webp-wasm

> 标签: crossbind, crossbind-package, image, libwebp, wasm, webassembly, webp

## 简介

WebAssembly build of the precompiled WebP image library, built with crossbind. Use it together with the main package @crossbind/port-webp.
