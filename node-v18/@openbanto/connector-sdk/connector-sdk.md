# @openbanto/connector-sdk

> 标签: chatops, connector, openbanto, plugin, sdk

## 简介

Connector plugin contract for OpenBanto — implement this to add a chat/messaging connector (Slack, Discord, LINE WORKS, ...) as an external plugin, without editing the OpenBanto core.
