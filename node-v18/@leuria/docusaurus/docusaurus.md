# @leuria/docusaurus

> 标签: ai, ask-ai, docusaurus, docusaurus-plugin, search, webmcp

## 简介

Ask AI for any Docusaurus site, on the reader's own AI: no API keys, nothing to pay per question. Plus the Connect button and WebMCP tools for the browser's agents.
