# @live-i18n/client

> 标签: angular, dev-server, developer-tools, i18n, in-context-editor, internationalization, live-edit, ngx-translate, standalone, translation, transloco

## 简介

Zero-config, in-context translation editor for Angular. Hover any translated text during ng serve, click, edit, and the matching key in your *.json files is rewritten on disk. Pairs with @live-i18n/plugin.
