# @kne/prompts-remote-components

> 标签: frontend, prompts, react

## 简介

前端组件库开发辅助提示词集合，包含 BizUnit 业务模块生成、RemoteLoader 远程加载、FormInfo 表单组件、国际化、文档生成、示例编写等任务的 AI 提示词模板
