# @spcsn/taro-vite-runner

> 标签: JavaScript

## 简介

`@spcsn/taro-vite-runner` 是 `@spcsn/taro-cli` 在小程序端使用的 Vite/Rolldown 构建执行器。它负责把 Taro 页面、组件、模板、样式和静态资源组织成微信小程序可运行的产物。
