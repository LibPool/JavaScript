# @authfu/mcp

> 标签: agent, authentication, authfu, mcp, model-context-protocol, oauth

## 简介

Protect an MCP server with Authfu: JWT verification against Authfu's JWKS, spec-correct OAuth challenges, and the identity of both the person and their agent on every request.
