# skilltotal

> 标签: agent-skills, claude-code, mcp, mcp-server, scanner, security, static-analysis, supply-chain

## 简介

Static security scanner for MCP servers, agent skills and npm/PyPI packages. Runs the skilltotal Python engine through uvx, pipx or an installed Python.
