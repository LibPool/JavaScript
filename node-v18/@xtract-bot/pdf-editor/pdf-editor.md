# @xtract-bot/pdf-editor

> 标签: annotations, forms, mupdf, pdf, pdf-editor, react, redaction, wasm, webassembly

## 简介

A complete PDF editor as a single React component. Annotations, forms, redaction, signing, OCR and page ops — MuPDF WebAssembly, entirely client-side, nothing uploaded.
