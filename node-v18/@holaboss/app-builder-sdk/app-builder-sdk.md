# @holaboss/app-builder-sdk

> 标签: agents, app-builder, holaboss, mcp, sdk

## 简介

SDK for building Holaboss app modules — 5 orthogonal primitives (connection / resource / action / sync / start), declarative state machines, typed bridge, pluggable state backend.
