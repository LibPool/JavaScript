# @sartel/browser-mcp

> 标签: ai-agent, browser, browser-automation, chrome, chrome-extension, human-in-the-loop, mcp, mcp-server, model-context-protocol, sartel, web-automation

## 简介

Sartel Browser MCP — a local stdio MCP server that lets a Sartel agent drive the user's real, logged-in Chrome through the Sartel browser extension. Fork of Agent360dk/browser-mcp (MIT).
