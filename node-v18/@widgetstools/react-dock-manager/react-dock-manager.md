# @widgetstools/react-dock-manager

> 标签: dock, dock-manager, docking, drag-and-drop, floating-panels, layout, react, split-pane, tabs

## 简介

A powerful, extensible dock manager for React with drag-and-drop, floating panels, split views, tabs, and auto-hide pinnable panels.
