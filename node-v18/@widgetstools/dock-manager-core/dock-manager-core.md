# @widgetstools/dock-manager-core

> 标签: auto-hide, dock-manager, docking, drag-and-drop, floating-panels, layout, split-pane, tabs, zero-dependencies

## 简介

Zero-dependency layout manager supporting tabs, splits, floating windows, and auto-hide panels. Framework-agnostic core.
