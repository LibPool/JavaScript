# @revealui/knowledge-graph

> 标签: graphiti, knowledge-graph, pgvector, revealui, temporal

## 简介

Fleet knowledge graph — bi-temporal, content-addressed graph (ontology, deterministic IDs, deterministic ingestion, hybrid search) over Neon + pgvector. GAP-340.
