# @fstubner/nvx

> 标签: agent, bun, node, npm, sandbox, security, supply-chain, version-manager

## 简介

Contain what your agent installs. Installs from npm, yarn, pnpm and bun, and npx and bunx tools, run in an OS sandbox. Also a Node.js and Bun version manager.
