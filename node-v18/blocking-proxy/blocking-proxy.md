# blocking-proxy

> 标签: JavaScript

## 简介

WebDriver Proxy for testing rich clients. It block certain calls until Angular is done updating the page under test.

- 官网：https://github.com/angular/blocking-proxy
- 源码仓库：git://github.com/angular/jasminewd.git
