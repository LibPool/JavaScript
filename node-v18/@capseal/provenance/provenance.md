# @capseal/provenance

> 标签: ai-detection, c2pa, content-credentials, deepfake, exif, image-forensics, jumbf, metadata, provenance, xmp

## 简介

Read what a file says about its own origin: C2PA manifests, EXIF, XMP and container structure, with verdicts graded by how they were reached.
