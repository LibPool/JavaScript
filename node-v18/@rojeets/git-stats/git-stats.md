# @rojeets/git-stats

> 标签: contributions, github, gitlab, heatmap, stats, streak

## 简介

Fetch public GitHub and GitLab contribution data and compute activity statistics (totals, streaks, best day). Includes presentational React UI components (heatmap, stats summary).
