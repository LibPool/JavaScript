# @napster-corp/edge-mcp

> 标签: agent, ai-agent, document.modelContext, in-browser, mcp, model-context, polyfill, tools, webmcp

## 简介

Napster Edge MCP — polyfills the WebMCP standard (document.modelContext) cross-browser and adds live state on top. Write standard registerTool calls with standard annotations; any compatible agent (including Napster's) can operate your app.
