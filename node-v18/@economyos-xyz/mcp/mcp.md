# @economyos-xyz/mcp

> 标签: JavaScript

## 简介

Model Context Protocol server (stdio + Streamable HTTP) exposing EconomyOS — coins, prediction markets, bounties, identity, invoices, streams — as MCP tools, built on @economyos-xyz/sdk.
