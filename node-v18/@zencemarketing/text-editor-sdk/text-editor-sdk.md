# @zencemarketing/text-editor-sdk

> 标签: code-blocks, customizable, editor, emoji, lexical, lexical-react, mentions, react, rich-text-editor, tags, typescript, wysiwyg, zencemarketing

## 简介

A highly customizable rich text editor React component built with Lexical - Features include mentions, tags, emoji picker, code blocks, image uploads, paste formatting, character limits, markdown shortcuts, and fully configurable toolbars
