# @lemma.id/proof-verifier

> 标签: ed25519, human-verification, identity, lemma, passkey, ppid, privacy, proof-verifier, verifier

## 简介

Local-first Lemma proof verifier. Verifies signed presentations, stamps, and site-bound session proofs on your backend with no per-request calls to lemma.id.
