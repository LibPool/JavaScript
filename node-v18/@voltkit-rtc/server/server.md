# @voltkit-rtc/server

> 标签: broadcast, chat, live-streaming, rtc, server-sdk, voltkit, webhooks, webrtc

## 简介

Server SDK for VoltKit RTC: rooms, tokens, chat, broadcast streams, usage, billing balance and rates, and verified webhooks. No dependencies.
