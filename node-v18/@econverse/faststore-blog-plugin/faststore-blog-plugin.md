# @econverse/faststore-blog-plugin

> 标签: blog, faststore, plugin, vtex, wordpress

## 简介

Rotas /blog e /blog/[slug] para lojas FastStore, com listagem e post individual alimentados pela REST API do WordPress (SEO via Yoast).
