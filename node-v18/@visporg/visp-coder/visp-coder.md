# @visporg/visp-coder

> 标签: actor-critic, ai, claude-code, cli, code-review, codex, coding-agent, harness, mcp, model-context-protocol

## 简介

Harness for AI coding agents: an actor-critic loop with executed checks, bounded file scope, an independent reviewer and independent acceptance tests. CLI and MCP server.
