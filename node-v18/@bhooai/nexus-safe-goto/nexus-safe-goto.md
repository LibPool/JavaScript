# @bhooai/nexus-safe-goto

> 标签: JavaScript

## 简介

Safe external link navigation for the BhooAI Nexus admin panel — intercepts external URLs, shows a confirmation dialog, and opens with noopener/noreferrer to prevent tab-nabbing and phishing.
