# @sirv/react

> 标签: 360, cdn, gallery, image, react, responsive, sirv, spin, srcset, video

## 简介

Companion React renderer for Sirv assets: responsive images (srcset + lazy), videos, 360 spins, Sirv views, and combined media-viewer galleries. Renders content picked with the Sirv CMS plugins.
