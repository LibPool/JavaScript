# @vanilla-bean/oxject

> 标签: eventtarget, framework-agnostic, observable, proxy, reactive, state, zero-dependency

## 简介

Reactive state container built on the platform's own EventTarget. Property access and assignment look like a plain object; the reactivity is invisible.
