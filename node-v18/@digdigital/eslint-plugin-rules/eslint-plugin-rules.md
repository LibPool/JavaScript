# @digdigital/eslint-plugin-rules

> 标签: JavaScript

## 简介

Plugin interno do ESLint com regras específicas para os projetos da Dig. A primeira regra disponível evita que o objeto inteiro `process.env` seja exposto acidentalmente no código.
