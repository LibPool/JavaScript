# @nivaro/mcp

> 标签: claude, cms, cursor, headless-cms, mcp, model-context-protocol, nivaro, typescript

## 简介

Model Context Protocol server for Nivaro CMS — lets Claude Code, Claude Desktop and Cursor read and write an instance through the typed SDK under an API key.
