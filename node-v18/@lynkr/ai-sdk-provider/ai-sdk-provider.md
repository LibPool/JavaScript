# @lynkr/ai-sdk-provider

> 标签: ai, ai-sdk, llm, llm-gateway, llm-router, lynkr, openai-compatible, self-hosted, vercel-ai-sdk

## 简介

Vercel AI SDK provider for Lynkr, a self-hosted LLM gateway and tier-routing proxy. Route AI SDK apps across Ollama, AWS Bedrock, OpenRouter, Databricks, Azure OpenAI, llama.cpp, and LM Studio.
