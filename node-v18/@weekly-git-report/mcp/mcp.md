# @weekly-git-report/mcp

> 标签: JavaScript

## 简介

Weekly Git Report 的 MCP stdio server。它让外部 Agent 使用统一 ReportRun 准备 Git 事实、生成 Markdown、保存报告正文，并在用户明确要求时推送飞书。
