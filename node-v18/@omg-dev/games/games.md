# @omg-dev/games

> 标签: JavaScript

## 简介

The save kit for omg games. A game saves its state, progress and best scores with one API. Inside the omg games store (games.omg.dev) the store keeps the data: on the phone for a guest, and in the player's account after sign-in. Anywhere else the kit keep
