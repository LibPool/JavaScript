# @miro016/pocketbase-localfirst

> 标签: angular, local-first, offline, pocketbase, realtime, signaldb, signals, sync

## 简介

Local-first, signal-reactive layer for PocketBase: cached collections, offline writes, live sync, PocketBase-compatible filters/sort/expand, typed via pocketbase-typegen.
