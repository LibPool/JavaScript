# @mduml/runtime-mermaid

> 标签: JavaScript

## 简介

浏览器运行期 Mermaid 渲染工具：把 `<div class="mermaid">...</div>`（以及 `data-uml-flow-mermaid-config`）渲染为 SVG，并尽量保持“横平竖直（正交）”连线风格。
