# @revizahoshii/hoshino-wam

> 标签: JavaScript

## 简介

WhatsApp Web WAM (analytics/telemetry) plugin for @revizahoshii/hoshino — emits the client-side metrics batches WA Web sends, for wire parity and anti-fingerprinting
