# @netsi/table

> 标签: csv, custom-element, datatable, filtering, markdown, pagination, sorting, table, web-component

## 简介

Dependency-free Web Component that adds sorting, fuzzy filtering, pagination, sums, hover and CSV/Markdown copy to semantic HTML tables.
