# polyfill-pseudoclass-has

> 标签: JavaScript

## 简介

A polyfill that adds support for the CSS pseudo-class :has() to the DOM Selectors API (by extending .querySelector(), .querySelectorAll(), .matches(), .closest() or called directly)
