# thefaceanalysis-embed

> 标签: canthal-tilt, embed, eye-shape, face-analysis, face-shape, fwhr, golden-ratio, iframe, pupillary-distance, react, web-component, widget

## 简介

Add free face measurement widgets to any website: 11 tools (face shape, eye shape, canthal tilt, nose and lip proportions, thirds, fWHR, midface ratio, symmetry, golden ratio, pupillary distance) as a <face-analysis-widget> web component and a React compo
