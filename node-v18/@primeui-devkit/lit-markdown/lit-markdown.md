# @primeui-devkit/lit-markdown

> 标签: JavaScript

## 简介

Lit renderer for the PrimeUI DevKit markdown AST with built-in prose behaviors: heading anchors, code copy button and table scroll wrapper. Renders into light DOM so shared prose styles apply.
