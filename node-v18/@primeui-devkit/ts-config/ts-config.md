# @primeui-devkit/ts-config

> 标签: JavaScript

## 简介

Shared TypeScript configurations, one per kind of package, consumed with extends. They ship as JSON and are never built.

## 官网

- 源码仓库：git+https://github.com/primefaces/primeui-devkit.git
- npm 页面：https://www.npmjs.com/package/@primeui-devkit/ts-config
