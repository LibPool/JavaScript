# @vng-api/taken

> 标签: api, openapi, taken, vng

## 简介

OpenAPI-specificatie voor MijnTaken API — De MijnTaken API standaardiseert hoe portalen klantgerelateerde gegevens tonen en acties uitvoeren namens hun gebruikers. Het doel: een eindgebruiker kan informatie en taken raadplegen op elk aangesloten port
