# @rozie/runtime-svelte

> 标签: JavaScript

## 简介

Tree-shakable Svelte 5 runtime helpers for Rozie.js-compiled components: the listener, keynav and portal actions, the Snippet-to-Component portal hosts, and crash-safe interpolation, class and style helpers. Ships source; your build shakes it.
