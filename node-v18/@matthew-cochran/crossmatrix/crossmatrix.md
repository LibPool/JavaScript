# @matthew-cochran/crossmatrix

> 标签: crossmatrix, crossmatrix-mcp, house-of-quality, mcp, model-context-protocol, qfd

## 简介

npx launcher for the crossmatrix MCP server (multidimensional House of Quality): downloads the verified release binary for your platform, runs it over stdio, and ships the crossmatrix agent skills.
