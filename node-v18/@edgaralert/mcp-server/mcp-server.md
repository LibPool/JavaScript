# @edgaralert/mcp-server

> 标签: JavaScript

## 简介

Official Model Context Protocol (MCP) server for EDGAR Alert. Thin, read-only wrapper around the public EDGAR Alert v1 API.

- 官网：https://www.edgaralert.com
