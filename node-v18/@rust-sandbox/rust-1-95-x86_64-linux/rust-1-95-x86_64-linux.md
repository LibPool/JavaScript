# @rust-sandbox/rust-1-95-x86_64-linux

> 标签: cargo, rust, rustc, sandbox, toolchain

## 简介

Pinned Rust 1.95.0 toolchain (rustc + cargo + rust-std) for x86_64-unknown-linux-gnu, installed via npm postinstall. Intended for restricted sandboxes where static.rust-lang.org is not reachable but the npm registry is.

## 官网

- npm 页面：https://www.npmjs.com/package/@rust-sandbox/rust-1-95-x86_64-linux

## 历史版本号

- 当前版本：1.95.0

- 1.95.0

## 获取地址

- npm 安装：`npm install @rust-sandbox/rust-1-95-x86_64-linux`
- npm registry：https://registry.npmjs.org/@rust-sandbox/rust-1-95-x86_64-linux
- Node 要求：>=14
