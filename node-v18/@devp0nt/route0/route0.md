# @devp0nt/route0

> 标签: path, query-string, route, router, routing, search-params, standard-schema, type-safe, typescript, url

## 简介

A strongly-typed URL router for TypeScript — define routes once, build paths and parse URLs with full type inference, search params, and Standard Schema validation.
