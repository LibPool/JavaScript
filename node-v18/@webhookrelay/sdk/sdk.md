# @webhookrelay/sdk

> 标签: api, api-client, relay, sdk, tunnel, typescript, webhook, webhook-forwarding, webhook-relay, webhook-transformation, webhookrelay, webhooks, websocket

## 简介

Official TypeScript/JavaScript SDK for the Webhook Relay API — manage buckets, inputs, outputs, service connections and JavaScript transformation functions, poll webhooks and subscribe to them in real time over WebSocket.
