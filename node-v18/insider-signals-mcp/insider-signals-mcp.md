# insider-signals-mcp

> 标签: edgar, finance, form-4, insider-trading, mcp, mcp-server, sec, stdio

## 简介

Local stdio MCP proxy for the TradeStar Insider server — filing-verified SEC EDGAR data with no sign-in: insider buying (Form 4), activist stakes (13D), hedge fund changes (13F), 8-K events, federal awards, plus verify/fact-check tools. No API key.
