# @maestrofrontier/frontier

> 标签: agents, claude-code, codex, frontier, fusion-engine, gemini, model-panel, multi-cli-fusion, orchestration

## 简介

Maestro Frontier is an opt-in, zero-dependency local multi-CLI fusion engine for AI coding agents. Compose an Opus 5 and Codex model panel, set provider-supported effort, judge its one-shot read-only responses, and synthesize one grounded answer. Optional
