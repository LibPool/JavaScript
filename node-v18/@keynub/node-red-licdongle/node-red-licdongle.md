# @keynub/node-red-licdongle

> 标签: copy-protection, dongle, hardware, keynub, license, licensing, node-red, usb

## 简介

Node-RED nodes for the KeyNub USB license dongle: prove it genuine, read and write licence records, counters, and data only a dongle can decrypt
