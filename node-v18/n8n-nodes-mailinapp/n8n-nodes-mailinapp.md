# n8n-nodes-mailinapp

> 标签: email, interactive email, mailinapp, n8n-community-node-package, webhooks

## 简介

MailInApp nodes for n8n: contacts, deals, journeys, A/B experiment results and transactional email, plus a trigger for MailInApp webhook events.
