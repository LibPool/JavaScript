# @aotter/mantle

> 标签: agent-native, backend, bun, cloudflare-d1, cloudflare-workers, code-generation, mantle, mcp, model-context-protocol, postgresql, sdk, sql, sqlite, typescript, yaml

## 简介

Agent-native app SDK and backend compiler: YAML manifests to native SQL (SQLite, Cloudflare D1, PostgreSQL) and typed TypeScript; optional REST and MCP.
