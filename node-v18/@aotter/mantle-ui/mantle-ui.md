# @aotter/mantle-ui

> 标签: design-tokens, mantle, radix-ui, react, react-components, shadcn, tailwindcss, typescript, ui-kit

## 简介

Framework-free interaction controller, React 19 components, shadcn-style UI kit and Tailwind design tokens behind Mantle Admin. No SDK dependency.
