# @aksparadise/aks-backend

> 标签: backend, boilerplate, cli, express, generator, jwt, node, opentelemetry, paseto, scaffold

## 简介

Premium interactive scaffolding CLI to instantly spin up modern, secure, and production-ready Express.js backends with JWT/PASETO, MongoDB/PostgreSQL, and built-in OpenTelemetry observability.
