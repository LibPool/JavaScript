# unesco

> 标签: JavaScript

## 简介

Unesco is an approach and framework for Progressive Web Apps thought, designed, built and maintained in function of Lowest Possible Times to First Meaningful Paint and Minimum Interactivity Regardless of Entry Point and developer happiness.
