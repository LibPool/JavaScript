> 标签: analytics, big-data, c++, csv, csv-parser, data-engineering, data-processing, etl, excel-parser, fast-csv, high-performance, large-files, log-processing, machine-learning, napi, native-addon, nodejs, non-blocking, streaming, xlsx, xlsx-parser

## 简介

Ultra-fast streaming CSV and XLSX parser for Node.js with native C++ backend, non-blocking threads, and low memory usage for huge files
