# uni-chained-select-field

> 标签: web

## 简介

<uni-chained-select-field /> is an encapsulated Web Component built upon the foundation of the uniopen design language. It brings hierarchical, multi-level cascader selection into native form workflows, enabling developers to structure multi-tiered choice
