# use-konva-snapping

> 标签: UI-UX, alignment, canvas-snapping, drag-and-drop, graphics, guidelines, konva, konva-drag, konva-guidelines, konva-helpers, konva-resize, konva-snap, konva-snapping, react, react-konva, snap-to-grid

## 简介

A lightweight React hook for adding snapping functionality to Konva.js elements. It allows objects to snap to stage borders, center, and other shapes, with customizable guidelines and snapping sensitivity.
