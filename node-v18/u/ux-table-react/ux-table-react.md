# ux-table-react

> 标签: component, datagrid, editable, fixed-columns, high-performance, react, table, typescript, ui, unocss, virtual-scroll

## 简介

一个高性能的 React 表格组件，支持虚拟滚动、单元格编辑、列排序和固定列等高级特性，基于 UnoCSS 打造。
