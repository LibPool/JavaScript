# unloop-database-dynamo

> 标签: database, dynamodb, unloop, wrapper

## 简介

dynamo database wrapper used by unloop. Provides basic table operations (get, getAll, create, update, delete, query, batch). Query functionality is dependent on unloop-query, Batch is dependent on unloop-database-wrap
