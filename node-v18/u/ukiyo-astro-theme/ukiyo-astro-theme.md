# ukiyo-astro-theme

> 标签: astro-theme, gallery, gsap, japanese, lightbox, photography, portfolio, tailwindcss, ukiyo

## 简介

Ukiyo is a photography and gallery portfolio Astro theme inspired by ukiyo-e woodblock prints — dark-first, full-bleed, with FLIP lightbox animation and GSAP motion.
