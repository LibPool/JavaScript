# utilise.emitterify

> 标签: JavaScript

## 简介

* Enhance any object into an event stream * Consistent paradigm across callbacks, promises and observables * Supports unique listener per namespace and wildcard event (`*`) * Tiny (~700b min+gzip no dependencies) * Small and intuitive API: `.on`, `.on
