# unfold-graph

> 标签: 3d, dataviz, graph, graph-visualization, particles, r3f, react, react-three-fiber, three, three.js, tree, visualization, webgl

## 简介

Interactive 3D graph/tree visualization for React — nodes and edges rendered as a glowing particle field with React Three Fiber and custom GLSL shaders.
