# unapi-mcp

> 标签: api-security, chrome-devtools-protocol, claude-code, cursor, har, mcp, mock-server, model-context-protocol, openapi, opencode, sdk-generator, shadow-api

## 简介

Unwrap any website's hidden Shadow APIs into a typed Python/TypeScript SDK, OpenAPI 3.1 spec, Auth Dependency Chain, Security Audit, and Mock/MCP server.
