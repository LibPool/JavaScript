# univi.db

> 标签: JavaScript

## 简介

Hafif, dosya tabanlı JSON veritabanı. Dot notation, TTL, event emitter, otomatik yedekleme ve daha fazlasını destekler. Tüm metodlar hem **Türkçe** hem **İngilizce** kullanılabilir.
