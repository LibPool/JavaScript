# ustart

> 标签: graphql, graphql framework, mariadb, mongodb, mongoose, mssql, mysql, postgres, sequelize, sqlite

## 简介

uStart is a NodeJS framework for building GraphQL backends using Apollo, Sequelize, Mongoose and other great tools.
