# username-mapper-slack-bot

> 标签: JavaScript

## 简介

슬랙에서 Azure Devops 관련 서비스를 이용하는 경우, `block` 에서 `@username` 을 사용하면 해당 유저의 `@username` 이 아닌 `@displayname` 으로 표시되는 문제가 있음 이 경우 해당 메시지의 쓰레드에 `@username` 으로 표시되도록 매핑해주는 봇
