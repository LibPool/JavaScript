> 标签: agent-skill, ai-agents, anthropic, claude, claude-code, cli, codex, deploy, deployment, devops, docker, dockerfile, hosting, kubernetes, openai, paas, postgres, self-hosted, uncloud

## 简介

Deploy any directory to your own cloud and get a URL. Guided deploys that catch what breaks before it breaks, plus Postgres, domains and scaling — driven from your terminal, or by Claude Code and OpenAI Codex through the bundled agent skill.
