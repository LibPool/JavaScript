# ui5-ultima

> 标签: generator, sapui5, typescript

## 简介

UI5 Ultima is a CLI tool to generate free-style SAPUI5 applications and artifacts with TypeScript. The UI5 Ultima comes with some useful built-in SAPUI5 classes.
