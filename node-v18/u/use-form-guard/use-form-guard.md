# use-form-guard

> 标签: app-router, beforeunload, dirty, form, formik, guard, hook, navigation, nextjs, react, react-hook-form, unsaved

## 简介

Framework-agnostic React hook to prevent accidental navigation when a form has unsaved changes. Works with React Hook Form, Formik, or any boolean dirty state.
