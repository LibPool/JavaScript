# use-scroll-timeline

> 标签: animation-timeline, hooks, intersection-observer, nextjs, parallax, react, scroll, scroll-animation, scroll-driven-animations, scroll-timeline, view-timeline, waapi

## 简介

Scroll-driven animation hooks for React, built on the native CSS ScrollTimeline API. Runs off the main thread, falls back to IntersectionObserver, ~2 kB.
