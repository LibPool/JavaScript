# unstable-parser

> 标签: JavaScript

## 简介

一个 Javascript 解析器，可以将js代码解析为AST(抽象语法树)   该解析器目前处于实验阶段，请勿在生产环境中使用   目前该解析器已经可以解析大多数JS语法，只有极少数语法不支持   解析出的AST已经基本符合 [ESTree规范](https://github.com/estree/estree)
