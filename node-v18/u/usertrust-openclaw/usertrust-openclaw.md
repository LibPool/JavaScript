# usertrust-openclaw

> 标签: ai, audit, budget, governance, llm, openclaw, plugin, usertrust

## 简介

usertrust governance plugin for OpenClaw. Budget, policy, and audit for streamed LLM calls whose provider id matches this plugin's id or aliases (defaults: anthropic, openai, google).
