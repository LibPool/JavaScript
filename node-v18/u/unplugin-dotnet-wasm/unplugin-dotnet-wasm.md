# unplugin-dotnet-wasm

> 标签: bun, dotnet, esbuild, farm, rolldown, rollup, rsbuild, rspack, staticwebassets, unplugin, vite, wasm, webassembly, webpack

## 简介

Mount .NET WebAssembly output as virtual modules for Vite, Webpack, Rollup, esbuild, Rspack, Rsbuild, Rolldown, Farm, and Bun.
