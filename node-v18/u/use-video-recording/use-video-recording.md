# use-video-recording

> 标签: audio-recording, camera, hook, media, mediarecorder, multimedia, react, recording, screen-recording, streaming, typescript, video, webcam, webrtc

## 简介

A professional, feature-rich React hook for video recording with MediaRecorder API. Supports pause/resume, error handling, duration tracking, and download functionality.
