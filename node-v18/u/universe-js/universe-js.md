# universe-js

> 标签: JavaScript

## 简介

Interacting with Sparkart's [Universe API](http://docs.services.sparkart.net), using [SolidusClient](https://github.com/solidusjs/solidus-client)! The Universe module inherits from the SolidusClient module.
