# utimes-electron

> 标签: access time, atime, birth time, btime, created time, fs, modified time, mtime, utimes

## 简介

Native addon to change the btime, mtime, and atime of a file on Windows, macOS, and Linux.

- 官网：https://github.com/yejimeiming/electron-utimes
- 源码仓库：git+https://github.com/yejimeiming/electron-utimes.git
- npm 页面：https://www.npmjs.com/package/utimes-electron
