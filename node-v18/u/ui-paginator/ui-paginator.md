# ui-paginator

> 标签: JavaScript

## 简介

ui-paginator is a lightweight and flexible JavaScript utility designed to simplify pagination in web applications. It provides a getPages function to generate paginated page structures, including support for ellipsis ("...") for large page ranges. Perfect
