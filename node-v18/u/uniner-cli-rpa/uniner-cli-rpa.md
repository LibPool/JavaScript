# uniner-cli-rpa

> 标签: ai-agent, automation, claude-code, cloud-flow, excel, ocr, playwright, rpa, uniner, uniner-cloud

## 简介

uniner-cli-rpa — RPA automation CLI with cloud flow publish: browser automation (Playwright/CDP), Excel, OCR, desktop/SAP, crypto/HTTP/email tools. Includes uniner-cloud-flow skill for publishing flows to Uniner Cloud.
