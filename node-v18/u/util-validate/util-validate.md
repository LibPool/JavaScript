# util-validate

> 标签: pdf, util, validate, zip

## 简介

公用的工具集合，可以解析字符串，url等，校验指定内容的格式，生成随机图片验证码，全屏事件监听，压缩文件，事件优化等工具，提升程序员的开发效率。
