# ugx-face-liveness

> 标签: JavaScript

## 简介

Client-side Angular face-liveness capture using MediaPipe Face Landmarker. The guided flow requires one face to align, complete a randomized challenge (head turns and a smile), hold still, and then captures a JPEG snapshot plus a short WebM recording.
