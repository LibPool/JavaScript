# url-embed

> 标签: Daily Motion, Facebook, Facebook Posts, Facebook Video, Flickr, Imgur, Instagram, Soundcloud, Spotify, Tumblr, Twitter, Videopress, Vimeo, Youtube, embed, oembed

## 简介

Flexible oembed module written in ES6. Supports many existing providers. Can be easily extended to support new providers. Can resolve multiple oembeds asynchronously.
