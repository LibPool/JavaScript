# url-normalize

> 标签: canonical, clean, domain, extract, humanize, idn, idna, link, normalization, normalize, parse, parser, punycode, query, querystring, sanitize, typescript, unicode, uri, url, validate, validation, validator

## 简介

Normalize, validate, and canonicalize URLs — returns HTTPS canonical form or null for invalid input. Domain extraction, URL humanization, Punycode/Unicode/IDN support, 12 config options. TypeScript, CJS + ESM.
