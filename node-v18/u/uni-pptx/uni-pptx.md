# uni-pptx

> 标签: PPTX 文件导入导出, konva, pptx editor, web pptx, web pptx editor, web pptx editor component, web pptx editor library

## 简介

基于 Konva 实现的 Web PPTX 编辑器，支持图形（文字、图片、多媒体资源、形状、折线、统计图、表格、公式等常见元素类型）插入、编辑、预览、导入导出、协同等功能
