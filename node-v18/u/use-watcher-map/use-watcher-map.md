# use-watcher-map

> 标签: fine-grained, hook, hooks, nested-state, path, performance, re-render, react, state, state-management, store, subscription, typescript, watcher

## 简介

Control re-renders in React with ease. use-watcher-map uses path subscriptions to ensure components re-render only when relevant data changes.
