# unionpay-mcp-server

> 标签: mcp, modelcontextprotocol, payment, unionpay

## 简介

unionpay-mcp-server是银联基于MCP协议为AI智能体提供的支付工具（MCP Server），各类支持MCP协议的智能体应用均可安全、便捷地接入银联支付能力
