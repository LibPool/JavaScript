# updatein

> 标签: JavaScript

## 简介

模仿`immutablejs`中的`updateIn`函数，抛弃`immutablejs`其他不需要（嫌弃`immutablejs`压缩过后体积庞大，也用不到其他方法的情况下）的东西，不再需要`fromJS` to `toString`，使用`updateIn`可以一步到位的更新对象属性。 `updateIn`在更新属性的同时不改变旧对象，每次操作都会返回新对象，未修改的属性会继续使用旧对象的引用。
