# ui-picker

> 标签: accessibility, coding-agents, color-theory, design-system, design-tokens, mcp, model-context-protocol, oklch, ui, ux

## 简介

Local-first UI design system server for coding agents — style packs, a color-theory engine, checkable UX/UI guidelines, and a human-in-the-loop picker, served over MCP.
