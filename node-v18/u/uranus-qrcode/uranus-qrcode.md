# uranus-qrcode

> 标签: JavaScript

## 简介

This is a WebAssembly module written in Rust and compiled via wasm-pack (rust-wasm-bindgen). It can take an URL, width, and height and turn it into a SVG QRcode. You can then inject the svgString as innerHTML into your DOM or use it as the src in an img t
