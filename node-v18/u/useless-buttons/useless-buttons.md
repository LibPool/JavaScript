# useless-buttons

> 标签: boids, button, canvas, cellular-automaton, custom-elements, mandelbrot, rust, wasm, web-components, webassembly

## 简介

A collection of needlessly elaborate buttons — Web Components buttons with a Rust/wasm simulation (boids, falling sand, Conway's Life, Mandelbrot, bouncing pixels, a first-person maze crawl) painted on their canvas background.
