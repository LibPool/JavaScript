# umi-plugin-typed-route

> 标签: JavaScript

## 简介

在webapp中跳转路由时，还在使用下面的方式拼接路由吗？是否在路由过多时感到难以维护？ ```ts history.push(`/app/welcome`); history.push(`/app/${projectId}`); history.push(`/app/${projectId}/${userId}`); ``` `umi-plugin-typed-route`为你提供类型安全的路由跳转！
