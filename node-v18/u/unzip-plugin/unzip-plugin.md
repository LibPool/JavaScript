# unzip-plugin

> 标签: extract, password, typescript, uncompress, unzip, vue, vue3, zip, zip-plugin

## 简介

开箱即用的 ZIP 解压插件。内置 @zip.js/zip.js，支持超大文件、密码解密、流式解压、进度反馈、暂停/恢复/取消与内存管理。可用于浏览器直解 ESModule / UMD，亦提供 Vue3 Composition API 封装。
