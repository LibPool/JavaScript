# usa-dam-data

> 标签: dam, damapi, dams, hydrology, lake, lakelevels, lakes, reservoir, sdk, us-dams, usgs, water-data, water-levels

## 简介

A modern, developer-first Node.js SDK for accessing United States dam, lake, reservoir, and water level data for free.
