# use-courier

> 标签: cancel-upload, chunked-upload, file-upload, hooks, large-file-upload, progress, react, react-hook, resumable-upload, retry, typescript, upload, upload-progress, xhr, xmlhttprequest

## 简介

A headless React hook for file uploads with progress tracking, retries, cancellation, and chunked uploads for large files.
