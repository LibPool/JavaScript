# use-latest-batch

> 标签: batch, fintech, hook, react, real-time, throttle, typescript, websocket

## 简介

React hook that buffers high-frequency WebSocket items and flushes the latest value per key at a controlled FPS — the missing middle layer between a WebSocket hook and your render.
