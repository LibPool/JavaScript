# uvcc

> 标签: camera, configuration, controls, libusb, libuvc, usb, usb video class, uvc, uvc-control, webcam, webcamera

## 简介

USB Video Class (UVC) device configurator for the command line (CLI). Used for webcams, camcorders, etcetera.
