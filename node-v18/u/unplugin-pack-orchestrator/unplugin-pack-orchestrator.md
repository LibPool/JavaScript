# unplugin-pack-orchestrator

> 标签: 7z, archive, esbuild, pack, plugin, rollup, tar, unplugin, vite, webpack, zip

## 简介

Universal plugin for auto-archiving dist folder to ZIP/TAR/7Z after build, with checksums and auto-rename support - powered by unplugin
