## 简介

Read-only UX audit skill for AI coding agents: audit a product's UX, user journeys, processes, and workflows end to end and write a scored uxaudit.md. Installs as a skill or /uxauditor command across Claude Code, Codex, Gemini, Cursor, opencode, Windsurf,
