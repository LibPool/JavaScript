# uryang-svg-animate

> 标签: JavaScript

## 简介

React + GSAP 기반 SVG 애니메이션 컴포넌트 라이브러리입니다.   간단한 SVG 컴포넌트를 `점프`, `회전`, `뒤집기` 등 다양한 방식으로 애니메이션 처리할 수 있습니다.
