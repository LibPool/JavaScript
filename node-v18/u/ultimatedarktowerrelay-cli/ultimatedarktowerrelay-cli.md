# ultimatedarktowerrelay-cli

> 标签: JavaScript

## 简介

UltimateDarkTowerRelay CLI — headless relay daemon (BLE tower emulator + WebSocket relay) for servers, Raspberry Pi, Docker, or an always-on host.
