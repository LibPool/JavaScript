# ust-protocol

> 标签: attestation, canonical, ed25519, jcs, merkle, notarization, provenance, trust-infrastructure, ust, verification

## 简介

Universal State Transcript (UST) — the stateless reference base: canonical hashing (JCS), Ed25519 signing, three-tier verification (LIGHT/HIGH/TOP), privacy commitments, chains, and anchoring. Trust infrastructure for machine-readable state.
