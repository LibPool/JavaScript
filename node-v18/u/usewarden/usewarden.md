# usewarden

> 标签: agent-drift, agent-guardrails, ai-agent-safety, ai-code-review, claude-code, claude-code-hooks, cli, codex-cli, context-rot, cursor, developer-tools, devsecops, dotenv-protection, gemini-cli, github-copilot-cli, llm-guardrails, prevent-rm-rf, prompt-injection, secret-scanning, security

## 简介

Free, local guardrail for AI coding agents: Claude Code, Cursor, Gemini CLI and more. Blocks out-of-scope writes, .env reads, rm -rf and force pushes. No API key, no account, no telemetry by default.
