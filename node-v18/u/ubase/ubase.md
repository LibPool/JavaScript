# ubase

> 标签: JavaScript

## 简介

框架对vue、vuex及国际化进行了封装和抽象，自动生成app入口文件，vuex和国际化等自动配置，内置vue开发中常用loader的配置(less, sass, css, js及图片等)，构建工具使用gulp。
