# uxml-preview

> 标签: css-to-uss, editor-tooling, flexbox, game-ui, preview, renderer, typescript, ui-toolkit, uielements, uitk, unity, unity-editor, unity3d, uss, uxml, webassembly, yoga, yoga-layout

## 简介

Preview Unity UI Toolkit UXML/USS in a browser without the Unity Editor. Uses Yoga (WebAssembly), the same layout engine UI Toolkit uses: 660 of 676 element coordinates identical to Unity 6. Parses and writes files back byte-for-byte.
