# ui5-cap-ai-features

> 标签: ai, cap, cap-plugin, cds, cds-plugin, openui5, orchestration, plugin, sap, sap-ai-core, sapui5, ui5, ui5-library

## 简介

AI text-processing features for CAP + UI5 apps in one package: a CDS plugin serving an AI service backed by SAP AI Core, and the be.wl.ai UI5 control library (AI Polish Button, AI Translate Button, AI Autocomplete, ...) that consumes it
