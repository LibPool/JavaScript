# use-numeric-separator

> 标签: eslint, eslint-plugin, eslintplugin, numeric-separator, readability, typescript-eslint, underscore

## 简介

A typescript-eslint rule that enforces underscore numeric separators on long number literals (decimal, hex, binary, octal) with per-base configuration.
