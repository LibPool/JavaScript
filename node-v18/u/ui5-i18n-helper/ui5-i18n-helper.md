# ui5-i18n-helper

> 标签: fiori, helper, i18n, internationalisation, internationalization, openui5, ui5

## 简介

Command line tool that helps i18n process in openui5 projects. It shows inconsistencies between i18n propery files and view xml files by creating a .help.propery file for each .property file.
