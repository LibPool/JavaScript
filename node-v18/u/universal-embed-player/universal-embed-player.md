# universal-embed-player

> 标签: dash, dropbox, embed, hls, player, video, vimeo, youtube

## 简介

Framework-agnostic, dependency-free video embed resolver: one URL from any host (YouTube, Vimeo, Dropbox, HLS, DASH...) in, one unified player out.
