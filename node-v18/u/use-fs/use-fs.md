> 标签: browser, directory watcher, directory-access, file system, file system api, file watcher, file-access, file-monitoring, file-system-api, files, filesystem, hooks, react, react-hooks, use, watcher, web

## 简介

A React hook for integrating with the File System Access API. Enables web applications to seamlessly work with files on a user's local system.
