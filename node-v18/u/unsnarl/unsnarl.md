# unsnarl

> 标签: analyzer, ast, cli, ecmascript, ir, mermaid, scope, scope-manager, static-analysis, typescript

## 简介

Single-file ECMAScript / TypeScript scope and reference analyzer that emits a Mermaid flowchart and a deterministic IR (JSON).
