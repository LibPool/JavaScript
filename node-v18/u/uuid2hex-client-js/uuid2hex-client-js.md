# uuid2hex-client-js

> 标签: JavaScript

## 简介

This package is the javascript client for the [UUID2Hex service](https://github.com/angelxmoreno/uuid2hex-service). It uses axios to make calls to the API and takes an optional `CacheableInterface` to avoid unnecessary calls.
