# uapi-browser-sdk

> 标签: agent, browser, client, fetch, free-api, llm, openapi, public-api, sdk, typescript, uapi, uapis, uapis.cn, vanilla-js

## 简介

Official browser / vanilla-JS SDK for UAPI / uapis.cn — dependency-free `fetch`-based wrapper around 100+ free public-API endpoints. Works in browsers, Cloudflare Workers, and any modern JS runtime.
