# unplugin-vue-i18n-dts-generation

> 标签: autocomplete, code-generation, compile-time-validation, dts, flat-structure, i18n, internationalization, localization, translation-keys, type-safe, typescript, unplugin-vue-i18n-alternative, vite, vite-plugin, vue, vue-i18n, vue3

## 简介

Alternative to @intlify/unplugin-vue-i18n - Catch unknown i18n key errors at compile time with TypeScript. Supports flat file structures. High-performance standalone Vite plugin.
