# uk-land-registry-price-mcp

> 标签: ai, apify, land-registry, mcp, model-context-protocol, property, real-estate, scraper, sold-prices

## 简介

MCP server for UK HM Land Registry sold house prices (Price Paid Data) — uncapped, by postcode/town/county/year. Tool for AI agents.
