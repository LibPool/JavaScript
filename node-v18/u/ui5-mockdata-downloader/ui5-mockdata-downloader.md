# ui5-mockdata-downloader

> 标签: JavaScript

## 简介

Ui5-mockdata-downloader downloads all metadata.xml files from all OData services listed under the dataSources part of manifest.json. Each metadata.xml is parsed and used to download all entity type sets including all links to navigation properties as JSON
