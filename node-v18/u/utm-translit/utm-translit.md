# utm-translit

> 标签: analytics, campaign-url, cyrillic, ga4, marketing, translit, transliteration, url-builder, utm, utm-builder, utm-generator, yandex-metrica

## 简介

Build clean UTM-tagged URLs with automatic Cyrillic transliteration and value normalization. Zero dependencies, works in Node.js and the browser.
