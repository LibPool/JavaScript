# uglymug

> 标签: avatar, face, generator, procedural, random, seeded, svg, ugly, vue

## 简介

The uglymug generator as a framework-agnostic library: seeded faces as SVG strings, base64 data URLs or PNGs, with an optional Vue 3 composable.
