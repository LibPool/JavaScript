# union-tools

> 标签: EraserBrushTool, brush, cornerstone, cornerstone-tools, eraser, segmentaion

## 简介

该库是基于cornerstone-tool 的一个扩展工具，包括EraserBrushTool,PseudocolorTool,mprTool工具。 ### 作用： EraserBrushTool:用于擦除brush工具的mask PseudocolorTool:基于vtk伪彩原理实现的伪彩工具
