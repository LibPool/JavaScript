# unmerged-approaches-mcp

> 标签: ai-agents, claude, disagreement, llm, llm-panel, mcp, mcp-server, model-context-protocol, multi-model, no-synthesis, openrouter, second-opinion, unmerged

## 简介

MCP server that sends one identical brief to several LLMs in parallel and returns every answer unmerged, unranked and unsynthesized, so the calling agent can see agreement and disagreement instead of an averaged blur.
