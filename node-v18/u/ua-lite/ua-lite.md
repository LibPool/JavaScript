# ua-lite

> 标签: ai-crawler, bot-detection, browser, browser-detection, client-hints, crawler-detection, device-detection, gptbot, mobile-detection, os-detection, parser, sec-ch-ua, typescript, ua-parser, user-agent, user-agent-parser, useragent, useragent-parser

## 简介

Fast, dependency-free JavaScript user agent parser — browser, engine, OS, CPU, and device detection, plus built-in bot, AI-crawler, and in-app-browser classification and Client Hints support.
