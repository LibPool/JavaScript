# uicons.js

> 标签: asset-management, assets, audio, esm, icons, pogo, pokemon, pokemon-go, pokemongo, template-literal-types, type-safe, typescript, uicons

## 简介

Type-safe UICONS client for Pokémon GO — resolves icon & audio URLs to exact template-literal types, with no runtime dependencies.
