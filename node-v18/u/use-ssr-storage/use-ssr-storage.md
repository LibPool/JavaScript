# use-ssr-storage

> 标签: hooks, hydration, localstorage, nextjs, react, remix, sessionstorage, ssr, useSyncExternalStore

## 简介

SSR-safe localStorage/sessionStorage React hook built on useSyncExternalStore — no hydration mismatches, cross-tab sync, and typed error handling.
