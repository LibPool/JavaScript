> 标签: ai-agent, anthropic, automation, browser-automation, claude, claude-code, codex, computer-use, computer-vision, cursor, desktop-automation, image-recognition, lm-studio, mcp, mcp-server, model-context-protocol, ocr, rpa, ui.vision, uivision, visual-automation, vscode, web-automation, windsurf

## 简介

Ui.Vision MCP: MCP server for browser and desktop automation (RPA) with OCR, image recognition and real mouse/keyboard input. Works with Claude Code, Claude Desktop, Codex, Cursor, Windsurf, VS Code, LM Studio and any other MCP client.
