# uppercase-core

> 标签: JavaScript

## 简介

UPPERCASE-CORE는 [UPPERCASE](https://uppercase.io)의 가장 근간을 되는 기능들을 담고 있는 모듈입니다. UPPERCASE의 모든 기능들은 이를 기반으로 합니다. 이 모듈만으로도 기본적인 웹 애플리케이션을 충분히 구현할 수 있습니다.
