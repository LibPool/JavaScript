# ugly-app

> 标签: JavaScript

## 简介

A full-stack TypeScript framework for shipping production web apps: Node + React + Postgres, type-safe RPC over WebSocket and HTTP, real-time doc subscriptions, built-in auth, AI generation, storage, cron / workers, and a CLI for every workflow.
