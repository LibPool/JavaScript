# unicloud-expressjs

> 标签: JavaScript

## 简介

代码借鉴了serverless Express，uniCloud目前虽然支持服务器单路由模式，但扩展功能都需要自己造轮子，引入ExpressJs后可以围绕其生态做出更有意思的东西
