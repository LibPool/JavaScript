# unslop-core

> 标签: anti-slop, audit, lint, mcp, model-context-protocol

## 简介

Shared engine for the *-unslop-mcp servers: comment-aware regex/structural audits, suppressions, git-change discovery, toolchain checks, CLI mode and skill installer.
