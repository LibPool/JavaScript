# ui-component-dev-test

> 标签: JavaScript

## 简介

**ui-component-dev** est une bibliothèque de composants Web modernes, élégants et personnalisables, basée sur [Lit](https://lit.dev). Elle est conçue pour fonctionner avec tous les frameworks JavaScript (React, Angular, Vue, Svelte) ou sans framework.
