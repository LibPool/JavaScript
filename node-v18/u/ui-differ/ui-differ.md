# ui-differ

> 标签: canvas, compare, design, design-qa, design-to-code, frontend, mockup, overlay, pixel-perfect, ui

## 简介

零依赖的浏览器端设计稿叠加对比工具：上传设计稿、调透明度/缩放、拖拽对齐、裁剪挖空逐块对比、辅助线对齐，IndexedDB 持久化刷新不丢。
