# ulink-cli

> 标签: JavaScript

## 简介

```shell npm i ulink-cli -g ``` # 本地初始化项目 > 通过git地址clone项目之后直接cd进入项目目录的mini文件夹后执行 ```shell ulink init [模版名称] ``` > 目前只有小程序模版 ```shell ulink init mini ```
