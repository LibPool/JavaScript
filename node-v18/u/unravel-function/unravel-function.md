# unravel-function

> 标签: argument, builder, builder pattern, chain, chaining, design, design pattern, design patterns, explode, function, functional, functional programming, parameter, pattern, patterns, readability, readable, unpack, unravel, unwrap

## 简介

Takes a function and spreads its arguments across a chain of functions to be lazily evaluated, a la the Builder Pattern.
