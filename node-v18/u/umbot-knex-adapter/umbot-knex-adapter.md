# umbot-knex-adapter

> 标签: bot-framework, database, db-adapter, knex, knexjs, mssql, mysql, orm, postgres, postgresql, sql, sqlite, telegram-bot, typescript, umbot, universal-bot

## 简介

A robust Knex.js database adapter for the umbot TypeScript framework. Supports PostgreSQL, MySQL, SQLite, and MSSQL for building scalable Telegram and web bots.
