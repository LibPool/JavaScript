# ux-cesium

> 标签: cesium, marker, measure, plot, provider

## 简介

基于 Cesium 的地图标绘、测量与点位管理库，支持 Primitive 聚合、动态 Label、弹窗、Plot 标绘、多边形分割合并、地图量算/体工具与键盘漫游。
