# ual-anchor-demo

> 标签: JavaScript

## 简介

This example implements a basic react app that utilizes [The UAL React Renderer](https://github.com/EOSIO/ual-reactjs-renderer) and the [UAL Anchor](https://github.com/greymass/ual-anchor) authenticator.
