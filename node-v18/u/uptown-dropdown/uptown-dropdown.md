# uptown-dropdown

> 标签: dropdown, expander, jared boice, react dropdown, react expander, uptown dropdown, uptown-dropdown

## 简介

a fully customizable react dropdown/expander implementation that accepts a header component or a placeholder, an optional icon, and a single component for the body which decouples the dropdown from a list
