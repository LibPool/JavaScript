# ultipa-mcp

> 标签: claude, cursor, gql, gqldb, graph-database, mcp, model-context-protocol, ultipa

## 简介

Model Context Protocol server for Ultipa Cloud and any self-managed Ultipa GQLDB instance. Operate instances, run GQL, manage backups from any MCP client (Claude Desktop, Cursor, etc.).
