# url-param-nav

> 标签: Jump, clear extra url parameter, extra, navigation, parameter, query, replace, url, url parameter navigation, url参数导航, 多余, 导航, 替换, 清除多余的url参数, 跳转

## 简介

url-param-nav 是用于执行在url参数中传递的跳转位置的工具，它解决了单面应用中用url参数传递跳转位置带来的重复跳转等问题
