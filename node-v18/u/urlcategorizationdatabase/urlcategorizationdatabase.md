# urlcategorizationdatabase

> 标签: buyer personas, content categories, content filtering, contextual targeting, domain categorization, domain intelligence, iab taxonomy, machine learning, url categorization, url categorization database, url classification, url database, website classification

## 简介

Node.js client for the URL Categorization Database: classify any domain or URL into IAB content taxonomy categories (tier 1 and tier 2) from a database of 120M+ categorized domains, with language detection and buyer personas.
