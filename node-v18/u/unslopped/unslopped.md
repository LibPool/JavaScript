# unslopped

> 标签: agents, ai, ci, claude-code, code-review, codex, coding-assistant, copilot, cursor, delivery, devops, dora, gates, sdlc

## 简介

unslopped keeps AI coding assistants from shipping slop: one prompt in, verified software out. Eight gated phases, code review that flags exploitable lines, tracker and PR integration, a code map, memory and delivery metrics.
