# unicodefyi

> 标签: character, codepoint, encoding, html-entity, unicode, unicode-lookup, utf-16, utf-8

## 简介

Unicode character lookup and encoding toolkit -- 17 formats (UTF-8, UTF-16, HTML, CSS, JS, Python, Java, Go, Ruby, Rust, C++), character info, name search. Zero dependencies.
