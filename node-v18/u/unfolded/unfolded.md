# unfolded

> 标签: css, design, development, framework, html, user-interface, web

## 简介

An easy-to-use SCSS frontend framework, that aims to develop the design for you. Fully responsive with a simple grid system, a few classes for powerful tweaking and a beautiful clean look and feel. The perfect framework to startup your next web app.
