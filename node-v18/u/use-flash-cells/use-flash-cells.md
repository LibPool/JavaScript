# use-flash-cells

> 标签: cell-flash, composable, datagrid, fintech, flash, headless, hook, mui, mui-datagrid, price-flash, react, react-table, real-time, stock, table, tanstack-table, ticker, trading, typescript

## 简介

Headless React hook that tracks per-cell value changes in fintech data tables and exposes up/down/null flash direction — composable with MUI DataGrid, TanStack Table, react-data-grid, or any renderer. Zero runtime dependencies. Never write a DIY price-fla
