# url-object-converter

> 标签: arrays, deserialize, esm, nested-objects, object-to-url, parse, query-parameters, query-params, query-string, serialize, stringify, typescript, url, url-builder, url-decoder, url-encoder, url-to-object, zero-dependencies

## 简介

A lightweight, zero-dependency package that converts JavaScript objects into URL-friendly query parameters and vice versa. Supports nested objects, arrays, Date, BigInt, and custom serializers.
