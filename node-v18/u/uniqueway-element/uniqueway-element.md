# uniqueway-element

> 标签: affix, element-ui, table, upload, vue, 组件化

## 简介

基于 element-ui 库的二次封装，该组件库主要针对现有列表页的 table 表格及 form 表单中的 rules 校验等场景，旨在减少重复的操作，让开发变得更简单。
