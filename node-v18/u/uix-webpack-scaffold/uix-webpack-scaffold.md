# uix-webpack-scaffold

> 标签: scaffold, uix, webpack

## 简介

Simple demo for scaffold of webpack 4 + react + babel. Supports batch processing of HTML templates, SASS, and JavaScript module files.  (https://github.com/xizon/uix-webpack-scaffold)
