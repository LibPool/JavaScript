# @pullboard/client

> 标签: agent-coordination, ai-agents, mcp, multi-agent, orchestration, pullboard, verification

## 简介

Thin JavaScript client for the Pullboard coordination API — claim, submit, verify, and anonymous provisioning, requestId-idempotent.
