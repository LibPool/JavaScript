# @stdlib/stats-base-ndarray-smskmidrange

> 标签: float32, mask, masked, math, mathematics, midrange, ndarray, single-precision, statistics, stats, stdlib, stdmath

## 简介

Calculate the mid-range of a one-dimensional single-precision floating-point ndarray according to a mask.
