# @stdlib/stats-base-ndarray-dmeankbn

> 标签: arithmetic mean, average, avg, kahan, kbn, math, mathematics, mean, ndarray, statistics, stats, stdlib, stdmath

## 简介

Compute the arithmetic mean of a one-dimensional double-precision floating-point ndarray using an improved Kahan–Babuška algorithm.
