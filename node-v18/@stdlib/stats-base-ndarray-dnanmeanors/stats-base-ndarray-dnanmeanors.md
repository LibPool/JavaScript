# @stdlib/stats-base-ndarray-dnanmeanors

> 标签: arithmetic mean, average, avg, central tendency, math, mathematics, mean, nan, ndarray, ordinary recursive summation, recursive summation, statistics, stats, stdlib, stdmath

## 简介

Compute the arithmetic mean of a one-dimensional double-precision floating-point ndarray, ignoring `NaN` values and using ordinary recursive summation.
