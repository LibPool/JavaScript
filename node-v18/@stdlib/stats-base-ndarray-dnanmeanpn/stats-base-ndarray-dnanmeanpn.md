# @stdlib/stats-base-ndarray-dnanmeanpn

> 标签: arithmetic mean, average, avg, central tendency, ignore nan, math, mathematics, mean, nan, ndarray, statistics, stats, stdlib, stdmath, two-pass

## 简介

Compute the arithmetic mean of a one-dimensional double-precision floating-point ndarray, ignoring `NaN` values and using a two-pass error correction algorithm.
