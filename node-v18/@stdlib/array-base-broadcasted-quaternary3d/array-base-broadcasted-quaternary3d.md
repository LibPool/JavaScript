# @stdlib/array-base-broadcasted-quaternary3d

> 标签: 3d, apply, array, base, broadcast, foreach, map, matrix, multidimensional, ndarray, quaternary, stdlib, transform

## 简介

Apply a quaternary callback to elements in four broadcasted input arrays and assign results to elements in a three-dimensional nested output array.
