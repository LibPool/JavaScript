# @stdlib/math-strided-special-dmskramp

> 标签: array, dbl, digital signal processing, double, double-precision, dsp, element-wise, float64, float64array, heaviside, mask, masked, max, maximum, missing, missing values, na, ndarray, nonnegative, ramp, stdlib, strided, vector

## 简介

Evaluate the ramp function for each element in a double-precision floating-point strided array according to a strided mask array.
