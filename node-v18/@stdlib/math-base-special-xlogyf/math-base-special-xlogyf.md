# @stdlib/math-base-special-xlogyf

> 标签: ln, log, logarithm, math, mathematics, natural, special, stdlib, stdmath

## 简介

Compute `x * ln(y)` so that the result is `0` if `x = 0` for single-precision floating-point numbers `x` and `y`.
