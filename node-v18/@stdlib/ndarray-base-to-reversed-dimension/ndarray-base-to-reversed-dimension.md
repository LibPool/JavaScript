# @stdlib/ndarray-base-to-reversed-dimension

> 标签: base, data, dimensions, flip, matrix, ndarray, numpy.flip, reverse, stdlib, stdtypes, structure, types, vector

## 简介

Return a new ndarray where the order of elements of an input ndarray along a specified dimension is reversed.
