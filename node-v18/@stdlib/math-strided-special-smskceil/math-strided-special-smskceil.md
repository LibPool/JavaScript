# @stdlib/math-strided-special-smskceil

> 标签: array, ceil, element-wise, float, float32, float32array, flt, integer, mask, masked, math, math.ceil, mathematics, missing, missing values, na, ndarray, nearest, round, single-precision, stdlib, stdmath, strided, vector

## 简介

Round each element in a single-precision floating-point strided array toward positive infinity according to a strided mask array.
