# @stdlib/number-float32-base-to-word

> 标签: 32-bit, base, binary, bits, convert, float, float32, floating-point, ieee754, integer, literal, number, single, stdlib, stdtypes, to, type, types, uint32, unsigned, util, utilities, utility, utils, word

## 简介

Return an unsigned 32-bit integer corresponding to the IEEE 754 binary representation of a single-precision floating-point number.
