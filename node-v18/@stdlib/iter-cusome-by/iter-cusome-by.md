> 标签: all, any, cumulative, cusome, every, iter, iterate, iterator, predicate, some, stdlib, stdutil, stdutils, test, transform, util, utilities, utility, utils, validate

## 简介

Create an iterator which cumulatively tests whether at least `n` iterated values pass a test implemented by a predicate function.
