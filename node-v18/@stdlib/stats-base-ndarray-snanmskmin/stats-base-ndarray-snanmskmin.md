# @stdlib/stats-base-ndarray-snanmskmin

> 标签: float32, mask, masked, math, mathematics, min, minimum, nan, ndarray, single, statistics, stats, stdlib, stdmath

## 简介

Calculate the minimum value of a one-dimensional single-precision floating-point ndarray according to a mask, ignoring NaN values.
