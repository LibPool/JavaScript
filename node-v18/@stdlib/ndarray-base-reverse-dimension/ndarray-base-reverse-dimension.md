# @stdlib/ndarray-base-reverse-dimension

> 标签: base, data, flip, matrix, ndarray, numpy.flip, reverse, slice, stdlib, stdtypes, structure, types, vector, view

## 简介

Return a view of an input ndarray in which the order of elements along a specified dimension is reversed.
