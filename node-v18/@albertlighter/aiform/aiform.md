# @albertlighter/aiform

> 标签: ai, ai-assistant, automation, browser-extension, chrome-extension, deepseek, firefox-extension, form, form-filling, form-history, form-management, javascript, openai, openrouter, typescript, web-automation

## 简介

一个基于AI的智能表单填写工具，支持自动提取表单数据、AI重写优化、表单历史记录以及智能填充。同时支持npm包和浏览器插件使用。
