# @omdsh-plugins/omdsh-document

> 标签: JavaScript

## 简介

Document attachments for the DeepSeek Harness web GUI: a Document row under an Attachments heading in the composer's plus menu, whole-window drag-and-drop and paste that turn Word, PowerPoint, Excel, PDF, Markdown and plain text into text the agent reads
