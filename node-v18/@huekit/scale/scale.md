# @huekit/scale

> 标签: color, color-palette, color-scale, css, design-system, huekit, lightness-scale, oklab, oklch, palette, tailwind

## 简介

Generate a perceptual lightness scale from one OKLCH color. Part of huekit, the OKLCH toolkit for designers.
