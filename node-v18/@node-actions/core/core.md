# @node-actions/core

> 标签: actions, ast, builders, node-actions, orchestration, pipeline, serializable, typescript

## 简介

O MODELO da linguagem de actions: a árvore (Action → Statements), os builders, a declaração de slots (a fronteira action↔TSL) e o codec. O AST é a verdade — este package o define, deixa construí-lo e sabe escrevê-lo. Não parseia, não elabora, não avalia,
