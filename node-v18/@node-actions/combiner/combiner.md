# @node-actions/combiner

> 标签: artifacts, combiner, drag-and-drop, many-to-many, rules, tslite

## 简介

COMBINER — motor de combinação many:many entre artefatos tipados, dirigido por REGRAS. O motor descobre as operações possíveis; quem executa é o consumidor. Core puro e zero-dep; a persistência (manifest) e a compatibilidade de tipos (compat) entram por s
