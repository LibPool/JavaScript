# @node-actions/editor

> 标签: document, dsl, editor, edits, node-actions

## 简介

A camada de EDIÇÃO do documento DSL de actions: as operações — inserir, remover, mover, copiar e desativar — como DADO, e a porta que as aplica. Pura: entra um documento e uma edição, sai outro documento. Sem canvas, sem React, sem DOM.
