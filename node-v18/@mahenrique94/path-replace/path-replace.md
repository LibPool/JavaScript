# @mahenrique94/path-replace

> 标签: path-replace, paths, replace, replace-path, tsconfig, typescript

## 简介

A lib for replace symbolic paths from tsconfig to phisic path. This way it's possible use paths attribute inside your tsconfig with NodeJS app.
