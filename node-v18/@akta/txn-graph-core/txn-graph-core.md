# @akta/txn-graph-core

> 标签: algorand, dagre, transaction-graph, visualizer

## 简介

Platform-neutral core for the Akita txn-graph visualizer: graph building, drill-down scopes, layout, theme tokens, data provider, and the useTxnGraph controller — shared by @akta/txn-graph-web and @akta/txn-graph-rn.
