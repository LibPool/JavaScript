# @adlc/build-gate

> 标签: adlc, agentic, ai, build-gate, cli, gate, llm

## 简介

Machine-checkable fitness-to-build gate — denies starting a high-risk P4 build in a degraded (context-rot) session unless an audited override is recorded (C13).
