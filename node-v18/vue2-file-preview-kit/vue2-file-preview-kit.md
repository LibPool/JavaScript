# vue2-file-preview-kit

> 标签: docx-preview, file-preview, file-viewer, image-preview, markdown-preview, office, online-preview, pdf-viewer, pptx-preview, vue, vue-plugin, vue2, xlsx-preview

## 简介

Vue 2 在线文件预览组件，开箱即用，支持图片、PDF、Word(doc/docx)、Excel(xls/xlsx/csv)、PPT(ppt/pptx)、Markdown、代码/文本、音视频等多种文件类型
