# @dualkit/format

> 标签: aed, arabic, bahrain, emirates-id, gulf, hijri, i18n, iban, kuwait, oman, qatar, rtl, sar, saudi, uae

## 简介

Gulf formats for bilingual products: AED, SAR, QAR, KWD, BHD and OMR, Hijri dates, Arabic numerals, phones and IBANs for all six GCC countries, Emirates ID, Saudi VAT number, Gulf weekends.
