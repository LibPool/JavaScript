# @ttrpg/probability

> 标签: dice, expected-value, probability, rpg, statistics, ttrpg

## 简介

Probability analysis for dice expressions. Distribution, mean, percentiles, chance-of-N+. Built on @ttrpg/dice notation. Monte Carlo + exact-for-simple-cases.
