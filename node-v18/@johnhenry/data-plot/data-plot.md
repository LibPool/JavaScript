# @johnhenry/data-plot

> 标签: charts, chernoff-faces, custom-elements, data-visualization, datalist, no-build, plots, tables, web-components

## 简介

Plots written as HTML: data from a <table> or <datalist>, marks from a <template>, placed with CSS. Custom elements shipped as source, no build step, no dependencies.
