# @johnhenry/inspectable

> 标签: custom-element, devtools, inspect, inspector, notebook, preview, repl, serialize, structured-clone, worker

## 简介

Preview any JavaScript value -- functions, cycles, Maps, errors, proxies -- as a small structured-clone-safe tree, so a value living in a Worker or iframe can be shown elsewhere; plus a <value-inspector> element with lazy expansion.
