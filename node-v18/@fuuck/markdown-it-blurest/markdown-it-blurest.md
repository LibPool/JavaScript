# @fuuck/markdown-it-blurest

> 标签: JavaScript

## 简介

A markdown-it plugin that enhances image rendering with blurhash support and custom web components. This plugin automatically generates blurhash placeholders for images and renders them using the `<ax-blurest>` custom element with progressive loading capa
