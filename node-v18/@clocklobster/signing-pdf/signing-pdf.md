# @clocklobster/signing-pdf

> 标签: certificate, document, e-sign, electronic-signature, esign, overlay, pdf, pdf-lib, signature

## 简介

Pure pdf-lib primitives for electronic-signature PDF overlay: field values, signature images, certificate pages, and finalization.
