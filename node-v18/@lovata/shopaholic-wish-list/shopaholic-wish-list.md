# @lovata/shopaholic-wish-list

> 标签: octobercms, shopaholic, wish list

## 简介

Package adds helper methods for integration with [Wish list for Shopaholic](https://octobercms.com/plugin/lovata-wishlistshopaholic) and [Shopaholic](https://octobercms.com/plugin/lovata-shopaholic) plugins.
