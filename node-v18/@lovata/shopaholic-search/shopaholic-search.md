# @lovata/shopaholic-search

> 标签: octobercms, search, shopaholic

## 简介

Package adds helper methods for integration with [Search for Shopaholic](https://octobercms.com/plugin/lovata-searchshopaholic) and [Shopaholic](https://octobercms.com/plugin/lovata-shopaholic) plugins.
