# @theyahia/payme-mcp

> 标签: ai, claude, mcp, mcp-server, model-context-protocol, payme, payment, sum, uzbekistan, uzs

## 简介

MCP server for Payme Subscribe API — payments, cards, receipts for Uzbekistan. 10 tools. JSON-RPC 2.0 with X-Auth header.
