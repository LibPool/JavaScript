# @zestty/language-server

> 标签: JavaScript

## 简介

LSP for ZesTTY (zts): serves compiled TypeScript twins to tsserver's LanguageService and remaps diagnostics, hover, and definitions through the sourcemaps back to the .zts source (Civet's approach).
