# @benvargas/bb-plugin-xai-voice

> 标签: JavaScript

## 简介

Voice transcription (speech-to-text) for bb, served by xAI's Grok STT (`https://api.x.ai/v1/stt`). Registers the `xai-voice` AI service so bb's prompt-box dictation can run on xAI instead of Codex.
