# @causentrix/rum-sdk

> 标签: causentrix, observability, opentelemetry, real-user-monitoring, rum, tracing

## 简介

Browser RUM SDK for causentrix-platform: OpenTelemetry traces (page load, fetch/XHR, click/submit), exceptions, and error logs from real user sessions.
