# @znora/chart-mcp

> 标签: JavaScript

## 简介

ZNORA chart MCP server — wraps the chart's action surface as Claude-callable tools so an LLM can drive the chart in real time. Customer-agnostic; per-customer wiring via the ChartAgenticAdapter contract in @znora/chart.
