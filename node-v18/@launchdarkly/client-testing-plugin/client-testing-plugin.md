# @launchdarkly/client-testing-plugin

> 标签: feature-flags, launchdarkly, mock, test, testing

## 简介

Testing plugin for LaunchDarkly client-side JavaScript SDKs. Uses the experimental plugin debug-override mechanism to inject flag values for unit tests and local development.
