# @sequio/skill

> 标签: agent-skill, ai, claude, llms-txt, pixijs, sequio, video-editor

## 简介

An installable AI Agent Skill (SKILL.md) + llms.txt that teach an AI assistant how to use sequio — build a Track/Clip/Effect object graph, preview, and export/render video.
