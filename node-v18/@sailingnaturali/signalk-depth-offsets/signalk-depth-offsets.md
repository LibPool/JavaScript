# @sailingnaturali/signalk-depth-offsets

> 标签: depth, marine, signalk-category-utility, signalk-node-server-plugin

## 简介

Derive environment.depth.belowKeel and belowSurface from belowTransducer using measured transducer offsets. For DBT-only feeds that carry no offset field.
