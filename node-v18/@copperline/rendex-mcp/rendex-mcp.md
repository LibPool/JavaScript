# @copperline/rendex-mcp

> 标签: ai-agent, claude, content-extraction, copperline, html-to-image, html-to-pdf, markdown-to-image, mcp, model-context-protocol, pdf, rendering, rendex, screenshot

## 简介

MCP server for Rendex: render HTML, Markdown, or URLs to images or PDF, apply Mustache data templating, and extract clean reader-mode content, all from AI agents
