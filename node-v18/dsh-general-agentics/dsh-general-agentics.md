# dsh-general-agentics

> 标签: cordis, cordis-plugin, deepseek-harness, dsh, dsh-bundle, dsh-plugin, white-label

## 简介

General Agentics distribution bundle for DeepSeek Harness (DSH): one install brings the General Agentics white-label brand, curated plugins, bundled skills, and MCP pre-configuration. Built on DeepSeek Harness (DSH).
