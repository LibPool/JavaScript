# @triargos/live-collection

> 标签: JavaScript

## 简介

Frontend live-sync engine: collection registry + scoping, persistence factory (TanStack DB), SSE/catchup client, sync broker, and bootstrap orchestration. Hero type: LiveCollection<T>.
