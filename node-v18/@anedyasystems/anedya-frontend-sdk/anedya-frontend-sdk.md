# @anedyasystems/anedya-frontend-sdk

> 标签: API, Anedya, IoT, JavaScript, SDK, TypeScript, browser, cloud, commands, data-access, device-management

## 简介

Official Anedya Frontend SDK for JavaScript and TypeScript. This SDK provides a comprehensive set of tools and functionalities to interact with Anedya's IoT platform, enabling developers to easily manage devices, access data, and execute commands in a sea
