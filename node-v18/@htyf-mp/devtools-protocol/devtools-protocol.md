# @htyf-mp/devtools-protocol

> 标签: JavaScript

## 简介

HTYF DevTools 的共享 TypeScript 协议类型。该包不依赖 Node、Electron 或 React Native；三个运行时模块必须使用同一个 `PROTOCOL_VERSION`。
