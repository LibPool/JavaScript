# @booboo-brain/cli

> 标签: booboo, cli, knowledge-graph, mcp

## 简介

Booboo CLI — one `booboo` command: build | serve | mcp | view | panel. Lazy-loads each subcommand so a build-only run never pulls the server or viewer.
