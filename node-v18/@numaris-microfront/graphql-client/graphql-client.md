# @numaris-microfront/graphql-client

> 标签: appsync, graphql, micro-frontends, numaris

## 简介

Cliente AppSync (query/mutate/subscribe realtime, sin Amplify) para la API GraphQL de la plataforma Numaris, con el schema real incluido.
