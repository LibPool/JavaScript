# @backlex/cli

> 标签: baas, backend-as-a-service, backlex, cli, command-line, devtools

## 简介

The backlex CLI — auth/profiles, collection + item CRUD, backups, users/roles, feature flags, functions/flows/webhooks/jobs, advisor, scaffolding, and type/OpenAPI generation against any backlex instance.
