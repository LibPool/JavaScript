# @isaiahiroko/fourward-ngx-apps-gamification

> 标签: JavaScript

## 简介

Badge shelf + household-scoped leaderboard, mounted as its own peer route (`/gamification`) alongside `/student`/`/admin`/`/payments`/`/id`. Linked to from the student dashboard rather than deeply embedded in it — `ngx-apps` projects don't cross-import ea
