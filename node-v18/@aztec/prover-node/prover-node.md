# @aztec/prover-node

> 标签: JavaScript

## 简介

The prover node turns sequenced checkpoints into epoch proofs that get submitted to the L1 rollup contract.  It runs alongside an Aztec validator/full-node and consumes the canonical chain view those nodes emit, proving epochs **optimistically** — sub-tre
