# @obinexusltd/obix-component-alert

> 标签: accessibility, alert, banner, component, dop, feedback, notification, obix

## 简介

OBIX ObixAlert — an inline message that switches between role="alert" (error / warning) and role="status" (info / success), with an optional dismiss button. Data-Oriented, zero dependencies.
