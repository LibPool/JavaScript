# @obinexusltd/obix-component-textarea

> 标签: accessibility, character-count, component, dop, form, multiline, obix, textarea

## 简介

OBIX ObixTextarea — a multi-line field with maxLength + a live "characters remaining" counter, configurable resize, and aria-multiline. Data-Oriented, zero dependencies.
