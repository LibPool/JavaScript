# @obinexusltd/obix-component-form

> 标签: accessibility, component, dop, error-summary, form, obix, validation

## 简介

OBIX ObixForm — a novalidate form wrapper that tracks a fields map, computes valid, and renders an role="alert" error summary linked via aria-describedby on submit. Data-Oriented, zero dependencies.
