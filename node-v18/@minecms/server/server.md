# @minecms/server

> 标签: cms, drizzle, fastify, headless-cms, minecms, server, trpc

## 简介

MineCMS backend — Fastify v5 + tRPC v11 + Drizzle (MySQL/PostgreSQL) + signed-cookie сессии. Запускает headless API поверх схем, описанных через @minecms/core.
