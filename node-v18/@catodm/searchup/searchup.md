# @catodm/searchup

> 标签: ai, c++, cli, code-search, find, full-text-search, grep, json, regex, search, trae-skill, web-search

## 简介

High-performance C++ search utility for AI agents — full-text, regex, filename, and web page search with JSON output. Includes Trae IDE skill definition.
