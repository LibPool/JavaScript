# @conformyze/lynta-ruleset-migrator

> 标签: JavaScript

## 简介

This project serves as a converter between the legacy ruleset format and a new one. It's used internally, albeit it can be used externally too, also in browsers.

- 官网：https://github.com/conformyze/lynta
- 源码仓库：git+https://github.com/conformyze/lynta.git
- npm 页面：https://www.npmjs.com/package/@conformyze/lynta-ruleset-migrator
