# @depup/is-odd

> 标签: array, count, depup, even, filter, integer, is, is-odd, latest, math, numeric, odd, patched, security, string, updated-dependencies

## 简介

Returns true if the given number is odd, and is an integer that does not exceed the JavaScript MAXIMUM_SAFE_INTEGER. (with updated dependencies)
