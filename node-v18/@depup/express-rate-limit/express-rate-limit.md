> 标签: attack, auth, authorization, brute, brute-force, bruteforce, depup, express, express-rate-limit, force, ip, latest, limit, middleware, patched, rate, rate-limit, ratelimit, security, updated-dependencies

## 简介

Basic IP rate-limiting middleware for Express. Use to limit repeated requests to public APIs and/or endpoints such as password reset. (with updated dependencies)
