> 标签: depup, latest, mock, mockgoose, mongodb, mongodb-memory-server, mongodb-prebuilt, mongomem, mongoose, patched, security, stub, updated-dependencies

## 简介

MongoDB Server for testing (auto-download latest version). The server will allow you to connect your favourite ODM or client library to the MongoDB Server and run parallel integration tests isolated from each other. (with updated dependencies)
