# @depup/openpgp

> 标签: crypto, dependency-bumped, depup, gpg, openpgp, pgp, updated-deps

## 简介

[DepUp] OpenPGP.js is a Javascript implementation of the OpenPGP protocol. This is defined in RFC 4880.
