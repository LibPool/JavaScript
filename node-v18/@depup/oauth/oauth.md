# @depup/oauth

> 标签: dependency-bumped, depup, oauth, updated-deps

## 简介

[DepUp] Library for interacting with OAuth 1.0, 1.0A, 2 and Echo.  Provides simplified client access and allows for construction of more complex apis and OAuth providers.
