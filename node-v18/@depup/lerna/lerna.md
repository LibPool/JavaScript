# @depup/lerna

> 标签: depup, latest, lerna, monorepo, multi-package, patched, security, updated-dependencies

## 简介

Lerna is a fast, modern build system for managing and publishing multiple JavaScript/TypeScript packages from the same repository (with updated dependencies)
