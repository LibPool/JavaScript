# @ardinsys/contour

> 标签: candlestick, canvas, charting, charts, financial, ohlc, stock, timeseries, trading

## 简介

Contour is a canvas-based charting engine for financial time series — candlestick, bar, line, area, and HLC controllers, indicators, drawings, and plugins. Framework agnostic, zero runtime dependencies.
