# @wycto/dsh-token-usage

> 标签: deepseek-harness, dsh, plugin, statistics, token, usage

## 简介

Token 用量记录与统计面板：记录 DSH 所有 LLM API 调用，支持秒级时间范围查询、多维度筛选、分组统计与 CSV 导出
