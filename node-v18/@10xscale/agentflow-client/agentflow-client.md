> 标签: 10xgraph, 10xscale, agent, agentflow, ai, api-client, chatbot, conversation, function-calling, llm, memory, streaming, threads, tools, typescript

## 简介

Final release under this name: the project continues as 10xGraph (https://10xgraph.com). TypeScript client for the 10xScale Agentflow API server: invoke and stream agent graphs, manage threads, memory and files, run client-side tools, and realtime audio.
