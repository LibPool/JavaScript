# @andreasnicolaou/js-natural-sort

> 标签: alphanumeric, array, case-insensitive, comparator, date, datetime, desc, javascript, natural-sort, natural-sorting, numeric, sort, sorter, sorting, typescript

## 简介

Natural sort comparator for JavaScript and TypeScript: numbers, dates, IP addresses and hex values, with case-insensitive, descending and key-based sorting.
