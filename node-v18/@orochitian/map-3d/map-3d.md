# @orochitian/map-3d

> 标签: 3d-map, dashboard, geojson, map, three, threejs, visualization

## 简介

基于 Three.js 的 3D 立体行政区划地图，传入 GeoJSON 与少量配置即可生成一张可交互的科技风立体地图
