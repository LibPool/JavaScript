# @isaacchacko/graph

> 标签: canvas, force-directed, graph, graph-view, network, react, visualization, web-component

## 简介

Pretty, living force-directed graphs from a few lines of text. Obsidian-style graph view as a dependency-free canvas renderer, a React component and a <graph-view> HTML tag.
