# @rtcn/light-engine

> 标签: irradiance, light-probe, lighting, per-room, spherical-harmonics, three-js, threejs, webgl, websocket

## 简介

分房间 SH 球谐光照引擎：WebSocket 推送 + per-material 探针注入 + 分档渲染管线（three.js per-material SH probe injection, per-room lighting, tiered pipeline）
