# @diagrammo/dgmo-mcp

> 标签: ai, charts, claude, dgmo, diagrammo, diagrams, flowchart, mcp, mcp-server, sequence-diagram, svg

## 简介

MCP server for rendering DGMO diagrams — SVG/PNG output, browser preview, HTML reports, and 50+ chart types. Works with Claude Desktop, Claude Code, and any MCP client.
