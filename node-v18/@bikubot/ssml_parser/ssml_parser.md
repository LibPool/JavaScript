# @bikubot/ssml_parser

> 标签: bikubot, shorthand, ssml

## 简介

**v2** \ With shorthand V2 the system moves from using one character to represent an effect to using two, this is to make the letter combination make more sense and open up more "slots" for future effects. This v2 only work in streams that uses Bikubot
