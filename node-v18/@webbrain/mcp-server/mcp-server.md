# @webbrain/mcp-server

> 标签: browser-agent, browser-automation, claude-code, codex, cursor, mcp, model-context-protocol, webbrain

## 简介

Model Context Protocol server that lets any MCP client (Claude Code, Codex, Cursor, OpenClaw) delegate browser tasks to a running WebBrain extension — in the user's real, already-authenticated browser session.
