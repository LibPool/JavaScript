# @kid7st/voicenote

> 标签: bun, cli, diarization, meeting-notes, philips, transcription, voice, voicenote

## 简介

Voice recordings → diarized transcripts → integrated semantic Markdown notes. Currently optimized for the PHILIPS VTR6500 recorder, but the workflow is generic.
