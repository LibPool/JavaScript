# @atisiothings/laniakea-lib-metrics

> 标签: JavaScript

## 简介

Library for collecting, aggregating, and analyzing app performance metrics. It supports counters, gauges, histograms, and timers, providing real-time insights. Compatible with Prometheus and OpenTelemetry, it integrates seamlessly into monitoring systems,
