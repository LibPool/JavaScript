# @g-bits/ui-kit-make

> 标签: JavaScript

## 简介

`@dam/ui-kit-make` 是面向 Figma Make 的可发布设计系统包骨架。它的目标不是替代仓库内部的 `@dam/ui-kit`，而是提供一套更稳定、更容易发布、对宿主环境依赖更少的最小组件集合，作为 Figma Make kit 的代码事实源。
