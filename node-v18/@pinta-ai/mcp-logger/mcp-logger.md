# @pinta-ai/mcp-logger

> 标签: aware, cli, logging, mcp, observability, observer, opentelemetry, tracing, wrapper

## 简介

Generic MCP-to-OTLP forwarder. Wraps any MCP server and emits OTel traces to OTEL_EXPORTER_OTLP_ENDPOINT.
