# @pyreon/native-runtime-kotlin

> 标签: JavaScript

## 简介

PRIVATE / EXPERIMENTAL — Kotlin runtime that compiler-emitted Compose code links against on Android. Parallel to @pyreon/native-runtime-swift. Phase 0+ scaffold; first real module is PyreonStorage (Compose + file-backed persistent state).
