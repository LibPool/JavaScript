# @realitycollective/webxr-input

> 标签: contracts, input, openxr, realitycollective, typescript, webxr, xr

## 简介

Shared, engine-free input contracts for the Reality Collective WebXR extension families: normalised input sources (rays, pinches, pokes, grips, hand joints, gaze, 2D pointers), capability negotiation, a pull-based provider interface, and pointer streams -
