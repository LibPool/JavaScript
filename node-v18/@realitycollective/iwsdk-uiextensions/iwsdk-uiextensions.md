# @realitycollective/iwsdk-uiextensions

> 标签: iwsdk, realitycollective, spatial-ui, typescript, ui, uikitml, vr, webxr, windowing, xr

## 简介

Meta IWSDK adapter for the Reality Collective UI Extensions - windowing, docking, layout regions and extra controls, binding the engine-free @realitycollective/webxr-uiextensions core onto IWSDK's ECS, UIKitML and interaction systems.
