# @saganta/stellar-appkit-react-native

> 标签: JavaScript

## 简介

React Native connector + modal UI for Stellar AppKit — WalletConnect deep linking, Albedo WebView bridge, AsyncStorage persistence, full modal parity with the web SDK.
