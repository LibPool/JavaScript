# @pipedog/piper

> 标签: conversational-ai, local, onnx, pipecat, pipedog, piper, realtime, text-to-speech, tts, voice-ai

## 简介

Piper text-to-speech for pipedog: a port of Pipecat's PiperTTSService (Piper ONNX voices run locally through @pipedog/onnx, espeak-ng phonemization) and PiperHttpTTSService (a Piper HTTP server, over fetch).
