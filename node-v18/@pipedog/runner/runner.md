# @pipedog/runner

> 标签: conversational-ai, dev-server, exotel, pipecat, pipedog, plivo, realtime, runner, telephony, telnyx, twilio, voice-ai, webrtc, whatsapp

## 简介

Pipecat's development runner for pipedog: createTransport() from runner arguments, and a dev server (main()) with the prebuilt WebRTC client, SmallWebRTC signalling, telephony webhooks and WebSockets for Twilio, Telnyx, Plivo and Exotel. A fetch handler y
