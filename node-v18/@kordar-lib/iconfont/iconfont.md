# @kordar-lib/iconfont

> 标签: JavaScript

## 简介

内置 IconFont 资源打包：包含 iconfont.css/woff/ttf/js 等文件，构建时提取为 dist/index.min.css，便于在任意项目中直接引入统一图标集。
