# @kordar-lib/menus

> 标签: JavaScript

## 简介

菜单与树结构工具库：提供通用侧边栏节点类型、菜单生成服务、二叉树索引、选择树等能力，便于在不同 UI 框架中复用菜单与 Tab 数据结构。
