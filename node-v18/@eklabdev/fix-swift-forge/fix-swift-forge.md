# @eklabdev/fix-swift-forge

> 标签: financial, fix, fix-protocol, iso15022, iso20022, mt, mx, parser, swift, typescript, xml, zod

## 简介

A type-safe FIX, SWIFT MT (ISO 15022), and MX (ISO 20022) toolkit for TypeScript. Supports FIX 4.0–5.0 SP2, all MT categories 1–9, all ISO 20022 business areas, parsing, validation, building, conversion, and masking.
