# @aemonge-dev/pi-openspec-gate

> 标签: accounting, ladder, openspec, pi-extension, pi-package

## 简介

Ladder gate for Pi: accounting at the tool-call boundary — every mutation is exempt-recorded, attributed to a focused change, declared by the human, or blocked with remedies. Never permission; never a renderer.
