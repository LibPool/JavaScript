# @pwngh/economy-edge

> 标签: anti-corruption-layer, meta, payments, payouts, receipt-verification, reconciliation, steam, tilia, webhooks

## 简介

The boundary between external payment providers and the ledger: a stateless, bidirectional codec from each provider's money-movement dialect to one canonical vocabulary.
