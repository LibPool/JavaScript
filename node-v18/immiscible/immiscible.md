## 简介

Approvals, spend limits and a kill switch for AI agents, set up in one command: npx immiscible init. See it first, offline and with no account: npx immiscible try. Installs a fail-closed Claude Code hook, prints MCP setup for Claude Code, Cursor and VS Co
