# @olzhas-adiyatov/slidev-addon-asciinema

> 标签: slidev, slidev-addon, vuejs

## 简介

A fork of the slidev addon to embed asciinema casts to presentations. In this fork we use original css file from asciinema-player. You can find the original addon here https://github.com/murilo-cunha/slidev-addon-asciinema
