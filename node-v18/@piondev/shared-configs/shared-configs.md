# @piondev/shared-configs

> 标签: JavaScript

## 简介

`@piondev/shared-configs`는 JavaScript/TypeScript 프로젝트의 ESLint, Prettier, Biome 설정을 공유하는 목적으로 제작되었습니다. 이를 통해 보다 일관성 있는 코드 스타일을 유지하고 잠재적으로 발생하는 programmatic error를 줄이고자 합니다.
