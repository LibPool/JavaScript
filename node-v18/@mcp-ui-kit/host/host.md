# @mcp-ui-kit/host

> 标签: generative-ui, host, mcp, mcp-apps, model-context-protocol, sandbox

## 简介

Thin MCP Apps host for any chat UI: mounts ui:// views of MCP tool results in a sandboxed iframe over the official AppBridge. React component and <mcp-app-view> web component included.
