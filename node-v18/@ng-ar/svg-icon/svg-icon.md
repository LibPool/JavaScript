# @ng-ar/svg-icon

> 标签: Angular, Angular13, angular_svg_icon, svg_icon

## 简介

The `@ng-ar/svg-icon` is an Angular 13 service and component that provides a means to inline SVG files to allow for them to be easily styled by CSS and code.
