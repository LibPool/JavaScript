# webcrypto-token

> 标签: browser, bun, cloudflare-workers, cross-subdomain-auth, deno, edge, edge-runtime, expiring-token, hmac, hmac-sha256, isomorphic, jose-alternative, jwt, jwt-alternative, jwt-like, magic-link, short-lived-token, signed-token, signed-url, stateless-auth, subtle-crypto, timing-safe, token, typescript, web-crypto, webcrypto, websocket-auth, workerd, zero-dependency

## 简介

Tiny zero-dependency signed token (JWT alternative) using only Web Crypto HMAC-SHA256 — short-lived expiring claims for Cloudflare Workers, edge, browsers, Deno, Bun and Node
