# @kreuzberg/kreuzberg-cli

> 标签: JavaScript

## 简介

CLI proxy for kreuzberg — downloads and runs the native kreuzberg binary from GitHub releases.

- 官网：https://github.com/kreuzberg-dev/kreuzberg#readme

- npm 安装：`npm install @kreuzberg/kreuzberg-cli`
- npm registry：https://registry.npmjs.org/@kreuzberg/kreuzberg-cli
- Node 要求：>=18
