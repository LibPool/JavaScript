# @digabi/ui-result-list

> 标签: JavaScript

## 简介

1. run `npm run compile` 2. copy folder `lib` into `registry` repository into `node_modules/@digabi/ui-result-list` overwriting the old `lib` folder 3. run `make restart` in `registry` repository
