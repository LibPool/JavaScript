# react-anydoc-viewer

> 标签: document, docx, ooxml, pdf, powerpoint, pptx, presentation, react, slides, typescript, viewer, word

## 简介

Free, open-source, watermark-free React component that renders PowerPoint (.pptx), Word (.docx) and PDF files in the browser. No paid APIs, no external services.
