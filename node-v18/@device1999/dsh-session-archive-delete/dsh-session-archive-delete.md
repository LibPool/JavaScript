# @device1999/dsh-session-archive-delete

> 标签: archive, backup, cleanup, deepseek-harness, delete, dsh, dsh-plugin, session

## 简介

给 DeepSeek Harness 的会话列表加一个安全的删除入口：先完整备份到本地、校验通过后再删除，支持子代理会话级联处理与自定义备份位置。
