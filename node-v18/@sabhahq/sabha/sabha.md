# @sabhahq/sabha

> 标签: JavaScript

## 简介

The Sabha umbrella plugin. Installing it pulls the shared sabha-core runtime and every general (Argus, Narada) in one step; each general still contributes its own MCP server. Install this for the whole assembly, or install a single general directly.
