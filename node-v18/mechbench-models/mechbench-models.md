# mechbench-models

> 标签: JavaScript

## 简介

Shared TypeScript types for mechbench platform objects (User, Org, Project, Workspace, ApiKey, etc.). Consumed by mechbench-ui and mechbench-api. Distinct from mechbench-schema, which covers wire-format data records.
