# @devlas/capacitor-usb-serial

> 标签: android, capacitor, capacitor-plugin, ch340, cp210x, ftdi, otg, pl2303, rs232, serial, usb

## 简介

Puerto serial USB para Capacitor en Android (adaptadores FTDI, CH340, CP210x, PL2303 y dispositivos CDC-ACM): abre el puerto, escribe y lee bytes crudos. Sin conocer ningun protocolo.
