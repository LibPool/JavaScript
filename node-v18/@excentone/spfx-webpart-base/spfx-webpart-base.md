# @excentone/spfx-webpart-base

> 标签: excent-one, internal, sharepoint, spfx, webpart

## 简介

Extends the capabilities of @microsoft/sp-webpart-base's BaseClientSideWebPart. This package is based on v1.11.0 of SharePoint Framework.
