# @thebcms/medusa-plugin

> 标签: bcms, cms, headless-cms, medusa, medusa-plugin, medusa-plugin-cms, medusa-plugin-integration, medusa-v2, plugin, thebcms

## 简介

BCMS (https://thebcms.com) integration for Medusa v2 - link CMS entries to products and serve them through Medusa's admin and storefront APIs.
