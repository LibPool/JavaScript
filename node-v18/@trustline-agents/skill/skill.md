# @trustline-agents/skill

> 标签: agent, claude-code, sdk, skill, stellar, trustline

## 简介

One-command installer for the TrustLine Agent SDK Claude Code skill. Run `npx @trustline-agents/skill` to add it to ~/.claude/skills.
