# service-monitor-backend

> 标签: fastify, logs, monitoring, pino, sqlite

## 简介

One SQLite store for what every process of a service logs, by topic and level, and how each process and the machine are doing; a pino destination, a heartbeat, and a Fastify plugin that reads it.
