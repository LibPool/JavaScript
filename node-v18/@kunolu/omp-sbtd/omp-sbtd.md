# @kunolu/omp-sbtd

> 标签: JavaScript

## 简介

OMP-hosted SBTD workflow plugin for KPi. It provides `/sbtd` commands and a fixed, read-only SBTD Kit snapshot; it does not silently install global tools or modify a project during plugin installation.
