# @adatechnology/game-contracts

> 标签: animation, contracts, destruction, fluids, game, modules, types, weapons

## 简介

The contracts every game module depends on, and nothing else: destruction (parts, hits, events, DestructibleImpl), weapons (shots), fluids (containers, item uses), item animations and the TestableModule a module hands the test room. Types plus tiny checke
