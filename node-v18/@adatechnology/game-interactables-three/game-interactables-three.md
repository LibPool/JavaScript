# @adatechnology/game-interactables-three

> 标签: furniture, game, interaction, mirror, particles, procedural, three, threejs

## 简介

three.js adapter for @adatechnology/game-interactables: merged-by-material mesh api with animated parts, pose sync, cloth sway with matching shadows, pooled effects, screens, mirrors and cords.
