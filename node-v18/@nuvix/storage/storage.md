# @nuvix/storage

> 标签: baas, bun, cloud-storage, file-upload, minio, nuvix, s3, storage, typescript, wasabi

## 简介

S3-compatible storage library for the Nuvix BaaS platform, built on Bun's native APIs. Supports AWS S3, Wasabi, MinIO, and local storage.
