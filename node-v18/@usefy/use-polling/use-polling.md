# @usefy/use-polling

> 标签: abort-controller, async, backoff, hooks, interval, pause, poll, polling, react, resume, usePolling

## 简介

A React hook to poll an async function on an interval — non-overlapping self-scheduling ticks, pause/resume, an enabled gate, and exponential backoff
