# @nippysky/datetime-picker

> 标签: bottom-sheet, calendar, date-picker, datepicker, expo, react-native

## 简介

A lightweight, dependency-free (besides date-fns) bottom-sheet date picker for React Native and Expo apps. No native modules, no icon libraries, no custom fonts required.
