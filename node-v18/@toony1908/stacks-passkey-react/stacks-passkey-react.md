# @toony1908/stacks-passkey-react

> 标签: bip39, hot-wallet, passkey, prf, react, sdk, stacks, wallet, webauthn

## 简介

Reusable React SDK for a WebAuthn passkey (PRF)-derived Stacks hot wallet: connect, send STX, sign transactions, and recover, with per-operation FaceID/fingerprint auth.
