# @pandi-coding-agent/pandi-typescript-lsp

> 标签: diagnostics, pi, pi-extension, pi-package, tsc, typescript

## 简介

Extensión de Pi para feedback de diagnósticos de TypeScript: ejecuta `tsc --noEmit` en el borde coherente (`agent_end`) sobre archivos tocados, más la herramienta `typescript_diagnostics` y el comando `/tsc`. No es un LSP completo (sin hover/go-to-def).
