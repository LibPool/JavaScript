# @gmfe/table

> 标签: JavaScript

## 简介

`@gmfe/table` 是基于 [react-table-v6](https://github.com/tannerlinsley/react-table/tree/v6/) 封装的高级表格组件包，提供丰富的表格功能扩展。包含基础表格、可编辑表格以及多个 HOC（高阶组件），支持选择、展开、固定列、排序、子表格、自定义列等功能。
