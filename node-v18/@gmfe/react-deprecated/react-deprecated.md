# @gmfe/react-deprecated

> 标签: JavaScript

## 简介

`@gmfe/react-deprecated` 包含已废弃的 React 组件，这些组件在新项目中不建议使用，但为了向后兼容仍保留在此包中。建议使用 `@gmfe/react` 中的替代组件。
