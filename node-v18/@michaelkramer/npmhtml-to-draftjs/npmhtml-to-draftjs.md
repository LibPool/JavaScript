# @michaelkramer/npmhtml-to-draftjs

> 标签: JavaScript

## 简介

A library for converting plain HTML to DraftJS Editor content. Build for use with **[react-draft-wysiwyg](https://github.com/jpuri/react-draft-wysiwyg)**.
