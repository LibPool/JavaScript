# @solankivishal/face-liveness-web

> 标签: anti-spoofing, camera, face-detection, face-liveness, liveness, liveness-detection, ncnn, react, wasm, webassembly

## 简介

On-device face liveness (anti-spoofing) detection in the browser: tells real faces from photos, screens and masks. WebAssembly + Web Worker, with a React component.
