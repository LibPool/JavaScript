# @iswesolutions/plugin-ipam-backend

> 标签: JavaScript

## 简介

Backend for [`@iswesolutions/plugin-ipam`](../ipam): a permission-checked gateway to the phpIPAM API, static-address allocation for new containers, DNS checks, usage history, a search collator and Backstage notifications for new IPAM issues.
