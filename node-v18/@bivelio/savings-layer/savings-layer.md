# @bivelio/savings-layer

> 标签: bivelio, cost-optimization, llm, llm-costs, observability, token-accounting

## 简介

The savings layer for your LLM bill: a library inside your code that lets through only what has to be paid for and returns a SavingsReport per call, measured with your provider's own meter and kept apart from estimates. Commercial license, paid per seat,
