# @jaingxyz/personal-gmail-mcp

> 标签: anthropic, claude, gmail, google-api, google-calendar, mcp, model-context-protocol

## 简介

Model Context Protocol server for a personal Gmail (consumer Google account) inbox and calendar, via the Gmail and Google Calendar APIs. Stdio transport, loopback OAuth, OS-keyring token cache.
