# @zakkster/lite-text-layout

> 标签: bitmap-font, bmfont, canvas, canvas2d, ellipsis, game-text, hud, kerning, line-break, text-layout, text-wrap, truncate, typed-array, word-wrap, wrap, zero-alloc, zero-gc

## 简介

Zero-GC bitmap font word wrapper. Computes line breaks, kerning-aware widths, and truncation/ellipsis flags into a Float32Array that feeds @zakkster/lite-bmfont's drawWrapped directly. Supports bmfont 1.x and 2.x.
