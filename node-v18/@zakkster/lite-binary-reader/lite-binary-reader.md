# @zakkster/lite-binary-reader

> 标签: arraybuffer, binary, dataview, endianness, garbage-collection, gc, parser, performance, reader, soa, struct, wire-format, zero-dependency, zero-gc

## 简介

Tiny, zero-dependency, zero-GC reader for raw or foreign binary buffers: point it at an ArrayBuffer + an offsets/type table and read fields with no allocation, any byte offset, explicit endianness.
