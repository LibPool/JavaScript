# @lpdfio/lpdf

> 标签: document, lpdf, pdf, wasm, xml

## 简介

Node.js SDK for Lpdf — PDF as Code on every platform. You describe a document as code or XML. Lpdf renders a compact, pixel-perfect PDF — identical across platforms.
