# @lazy-node/readlines

> 标签: buffer, create-by-tsdx, create-by-yarn-tool, file-reader, filesystem, fs, large-file, lazy-node, line, line-by-line, line-reader, linebyline, linereader, memory-efficient, read, reader, readfile, readline, readlines, stream-alternative, sync, synchronous, text-file

## 简介

逐行讀取檔案，無需將整個檔案載入記憶體 (Read file line by line without buffering the whole file in memory)
