# @piadina/fetch-jsonl

> 标签: api, async-generator, data-streaming, fetch, http, json, json-lines, jsonl, line-by-line, ndjson, newline-delimited, parser, streaming, typescript

## 简介

Stream and parse (**JSON Lines**)[https://jsonlines.org/] directly with fetch. Yields parsed JSON objects one line at a time.
