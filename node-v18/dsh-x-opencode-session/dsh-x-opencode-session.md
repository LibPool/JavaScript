# dsh-x-opencode-session

> 标签: deepseek, deepseek-harness, dsh, dsh-plugin, opencode, x-opencode-session

## 简介

DeepSeek Harness 插件：模型请求 URL 含 opencode.ai 时附加 x-opencode-session 请求头，值复用请求自带的会话 id（同一对话固定、重启/断网不变、不同对话不同）。
