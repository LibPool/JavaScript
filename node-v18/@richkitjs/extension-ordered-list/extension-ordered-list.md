# @richkitjs/extension-ordered-list

> 标签: editor, list, numbered-list, ordered-list, prosemirror, rich-text, rich-text-editor, richkit, richkit-extension, text-editor, wysiwyg

## 简介

Ordered list node for RichKit: toggleOrderedList, decimal, alphabetic and roman numbering, and Mod-Shift-7 shortcut.
