# @richkitjs/extension-drag-handle

> 标签: block-editor, drag-and-drop, drag-handle, editor, notion, prosemirror, reorder, rich-text, rich-text-editor, richkit, richkit-extension, text-editor, wysiwyg

## 简介

Block drag handle for RichKit: drag to reorder blocks, plus block actions such as duplicate (Mod-D) and delete.
