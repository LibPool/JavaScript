# @richkitjs/extension-slash-commands

> 标签: command-menu, editor, notion, prosemirror, rich-text, rich-text-editor, richkit, richkit-extension, slash-commands, slash-menu, text-editor, wysiwyg

## 简介

Notion-style "/" command menu for RichKit: tracks the slash query and keyboard navigation so you can search and insert blocks. Headless, bring your own menu UI.
