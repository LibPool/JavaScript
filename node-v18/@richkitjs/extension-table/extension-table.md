> 标签: column-resize, editor, merge-cells, prosemirror, rich-text, rich-text-editor, richkit, richkit-extension, spreadsheet, table, tables, text-editor, wysiwyg

## 简介

Tables for RichKit: insert, add and delete rows and columns, merge and split cells, header rows and columns, column resizing and Tab navigation.
