# @richkitjs/extension-track-changes

> 标签: editor, prosemirror, review, revisions, rich-text, rich-text-editor, richkit, richkit-extension, suggestion-mode, suggestions, text-editor, track-changes, wysiwyg

## 简介

Track changes for RichKit: record insertions and deletions as suggestions, then accept or reject them one by one or all at once.
