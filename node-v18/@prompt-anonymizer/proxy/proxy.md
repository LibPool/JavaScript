# @prompt-anonymizer/proxy

> 标签: anonymization, llm, openai, pii, privacy, proxy

## 简介

A buddy check for PII before it reaches an LLM - consistent, reversible labels. OpenAI-compatible local proxy (prompt-anonymizer-proxy) built on @prompt-anonymizer/core, with a localhost admin GUI.
