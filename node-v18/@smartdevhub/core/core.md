# @smartdevhub/core

> 标签: africa, kyc, orange-money, payments, smartdev, sms, wave, xof

## 简介

SDK TypeScript officiel de Smartdev Core — paiements (Wave, Orange Money), SMS/WhatsApp, vérification d'identité et campagnes pour l'Afrique de l'Ouest. Généré depuis le contrat TypeSpec.
