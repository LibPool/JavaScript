# @jbrowse/render-core

> 标签: jbrowse, jbrowse2, rendering, webgl, webgpu

## 简介

GPU/Canvas2D rendering primitives for JBrowse displays: the HAL, the draw-lifecycle mixin, per-region/global backend bases, and the React backend hooks
