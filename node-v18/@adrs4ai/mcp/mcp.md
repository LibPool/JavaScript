# @adrs4ai/mcp

> 标签: JavaScript

## 简介

The MCP mouth over @adrs4ai/docket-core: a thin stdio server (server key `adrs4ai`, per Mint №105) exposing the Secretariat's handler set — lookup, list_open_questions, answer_question, apply_batch and the rest — to any MCP client. One handler set, N adap
