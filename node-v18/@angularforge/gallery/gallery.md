# @angularforge/gallery

> 标签: angular, angular-library, angularforge, gallery, image-gallery, lightbox, signals, standalone

## 简介

A feature-rich, accessible Angular image gallery library with lightbox, full-gallery, and share support. Built with Angular signals and OnPush change detection.
