# @codady/stax

> 标签: components, css3, es6, html5, javascript, mvvm, vnode

## 简介

STAX is a lightweight, data-driven UI framework built with TypeScript. It leverages the power of Web Components for data initialization and provides a simple, easy-to-learn syntax with no dependencies.
