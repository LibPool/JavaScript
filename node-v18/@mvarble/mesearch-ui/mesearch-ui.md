# @mvarble/mesearch-ui

> 标签: JavaScript

## 简介

The Svelte components and styles mesearch sites are made of: the map, the index, search, the rail, contents, sequences, and a textbook look. Data and URLs come in as props, so any SvelteKit site can use them.
