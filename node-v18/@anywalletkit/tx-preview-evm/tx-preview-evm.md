# @anywalletkit/tx-preview-evm

> 标签: anywalletkit, approvals, eth_simulateV1, evm, preview, security, simulation, transaction

## 简介

What an EVM transaction (or an approve → call sequence) will do before it is signed: decoded calls, approvals, transfers, simulated balance changes (eth_simulateV1 with transfer tracing, eth_call fallback) and a verdict of named checks for a review screen
