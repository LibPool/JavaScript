# @anywalletkit/protocol-staking-lido-evm

> 标签: anywalletkit, ethereum, lido, protocol, staking, staking-protocol, steth, wsteth

## 简介

A simple package that lets @anywalletkit/wallet-evm wallet accounts stake through the Lido protocol: stake, two-phase queue withdrawals (permit-first), wrap/unwrap, rewards.
