# @anywalletkit/protocol-swap2-jupiter

> 标签: aggregator, anywalletkit, dex, jupiter, solana, swap, swap2

## 简介

Jupiter same-chain Solana swaps for the swap2 engine through Swap API V2's Router path (GET /swap/v2/build): Metis routing, no Jupiter swap fee, keyless or with an API key. The transaction is assembled locally from raw instructions after every instruction
