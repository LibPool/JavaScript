# rasso-plugin-image-compressor

> 标签: JavaScript

## 简介

本地离线图片压缩工作台：拖动滑块实时调节质量与缩放、批量压缩多张图片、导出 PNG/WebP 或写入剪贴板，同时提供 Base64 编码与格式互转，图片全程不上云
