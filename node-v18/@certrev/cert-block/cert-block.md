# @certrev/cert-block

> 标签: certification, certrev, ed25519, hydrogen, json-ld, react, schema-org, server-components, shopify, ssr, web-component

## 简介

Headless render edge for the CertREV CertDeliveryEnvelope: SSR-safe React cert components, a framework-agnostic <certrev-badge> Web Component, a schema.org JSON-LD projector, and a fail-closed verify layer over the shared VerdictKernel.
