# @cartamd/plugin-code

> 标签: carta, editor, emoji, katex, markdown, markdown editor, remark, slash, syntax highlighting, text editor, unified

## 简介

This plugin adds support for code blocks **syntax highlighting**. It uses the same highlighter from the core package(Shiki).
