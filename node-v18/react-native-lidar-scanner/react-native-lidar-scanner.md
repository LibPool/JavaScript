# react-native-lidar-scanner

> 标签: 3d, arkit, expo, floor-plan, ios, lidar, measure, react-native, room-scan, roomplan

## 简介

Scan rooms with the iPhone LiDAR (Apple RoomPlan), view them in 3D and measure walls, doors, windows and furniture.
