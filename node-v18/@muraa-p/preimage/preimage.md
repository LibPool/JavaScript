# @muraa-p/preimage

> 标签: ai-agent, checkpoint, claude-code, codex, data-loss, journal, local-first, mcp, opencode, rollback, sqlite, undo, write-ahead-log

## 简介

The undo layer for AI agents. A write-ahead journal for file and database changes, so an agent's bad edit is a rollback instead of an apology.
