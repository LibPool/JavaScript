# @opennodes/cli

> 标签: ai, claude-desktop, cursor, gateway, inference, mcp, mcp-server, onp, openai-compatible, opennodes, router

## 简介

OpenNodes (ONP) client: search verified AI nodes, pre-price chains, invoke with signed receipts; OpenAI-compatible gateway with onp/auto routing; stdio MCP server for Cursor, VS Code, and Claude Desktop
