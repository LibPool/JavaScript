# @upstash/mcp-toolkit

> 标签: agent, ai, durable, events, long-running, mcp, model-context-protocol, qstash, redis, tasks, upstash, webhooks

## 简介

Durable building blocks for MCP servers on the official TypeScript SDK: long-running tools (tasks) and webhook events, with Upstash Redis, QStash and Workflow backends.
