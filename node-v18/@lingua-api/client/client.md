# @lingua-api/client

> 标签: JavaScript

## 简介

Zero-dependency Node (≥ 22) client for the [Lingua API](https://api.lingua-api.com): `translate`, `translateBatch`, `languages`, with retries and rate-limit-aware scheduling.
