# @coworkkit/react

> 标签: agent, ai, copilot, coworkkit, multimodal, nextjs, react, sdk, voice, voice-agent

## 简介

Coworkkit React SDK — put an AI co-worker in your web app: it talks to your users, sees what's on screen, and operates the app as the signed-in user. Provider + hooks (useAction, useSurface, useElement).
