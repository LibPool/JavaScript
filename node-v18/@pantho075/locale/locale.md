# @pantho075/locale

> 标签: i18n, localization, nextjs, pantho, react, svelte, translation, vue

## 简介

Tiny framework-agnostic i18n core. Translation data lives in TS, no JSON files, no provider. Works in React, Next.js, Vue, Svelte, and Node.
