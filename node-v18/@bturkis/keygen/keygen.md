# @bturkis/keygen

> 标签: crypto, cryptography, hash, hex-key, key-generator, keygen, password-generator, random-string, secret-key, security, token, uuid, web-crypto-api

## 简介

Cryptographically secure key generators — hex keys, UUIDs, passwords, random strings, and text-to-key hashing. Uses Web Crypto API.
