# @joycostudio/trazo

> 标签: deterministic, diagram, flowchart, git-graph, layout, ssr, sugiyama, svg

## 简介

Deterministic code-to-diagram layout engine (flowcharts + git graphs). Pure TS core + optional React SVG renderers.
