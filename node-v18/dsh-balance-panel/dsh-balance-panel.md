# dsh-balance-panel

> 标签: balance, deepseek-harness, dsh, dsh-plugin, opencode, quota, usage

## 简介

Provider quota/balance widget for the dsh web surface: an inline sidebar card above the Settings row (collapsed glanceable row expanding into a Harness-native card with a settings panel), fed by a loopback Connection RPC channel whose host half proxies ea
