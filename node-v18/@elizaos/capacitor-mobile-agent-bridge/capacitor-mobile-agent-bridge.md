# @elizaos/capacitor-mobile-agent-bridge

> 标签: agent, android, ios, mobile, relay, tunnel

## 简介

Outbound tunnel from a phone-hosted Eliza agent so a remote Mac client can reach it. See docs/reverse-direction-tunneling.md.
