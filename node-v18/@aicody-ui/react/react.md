# @aicody-ui/react

> 标签: JavaScript

## 简介

`@aicody-ui/react`는 Aicody UI의 React 컴포넌트 라이브러리입니다. Tailwind CSS를 기반으로 스타일링된 다양한 UI 컴포넌트를 제공하며, 접근성과 유연성을 중점으로 설계되었습니다.
