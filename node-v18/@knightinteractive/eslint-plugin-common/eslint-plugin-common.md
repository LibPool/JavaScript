# @knightinteractive/eslint-plugin-common

> 标签: JavaScript

## 简介

This package contains custom plugins for ESLint. This plugin can be used directly in a project, or (preferably) as a dependency for our main ESLint configuration [package](https://bitbucket.org/knightinteractive/eslint-config/src/master/).
