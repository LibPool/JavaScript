# @youneed/server-plugin-pubsub-sqs

> 标签: JavaScript

## 简介

AWS SQS adapter for @youneed/server-plugin-pubsub: SqsPubSub over SQS queues (channel = queue), pure fetch + SigV4 (no aws-sdk). Long-poll consumer.
