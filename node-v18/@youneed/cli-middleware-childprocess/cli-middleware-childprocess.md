# @youneed/cli-middleware-childprocess

> 标签: JavaScript

## 简介

Child-process middleware for @youneed/cli: this.childprocess.spawn / .exec wrap node:child_process in a task — reactive (pending/output/exit), killed on shutdown or teardown.
