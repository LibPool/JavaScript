# @valaxyblack/vault

> 标签: JavaScript

## 简介

Classic Tornado vault: versioned data + export format, DEK key hierarchy (password + EIP-712 signature wraps, rotation), sealed settings and a Vault class with browser and Node/Bun storage. WebCrypto only.
