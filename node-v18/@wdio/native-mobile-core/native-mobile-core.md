# @wdio/native-mobile-core

> 标签: appium, internal, mobile, wdio, webdriverio

## 简介

Shared Appium-mobile launcher, device pool, capability prep, contexts, deeplink, and device-log capture for WebdriverIO native mobile services (React Native, Flutter)
