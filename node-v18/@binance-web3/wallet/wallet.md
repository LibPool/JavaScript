# @binance-web3/wallet

> 标签: API, Binance, Connector, REST, Trading, Wallet, Web3

## 简介

Official Binance Web3 Wallet Connector - A lightweight library that provides a convenient interface to Binance's Web3 Wallet REST API and WebSocket Streams.
