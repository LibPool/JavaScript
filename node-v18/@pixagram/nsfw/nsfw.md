# @pixagram/nsfw

> 标签: browser, client-side, content-moderation, efficientnet, image-classification, nsfw, onnx, onnxruntime-web, web-worker

## 简介

On-device NSFW image classification for the browser (EfficientNet via onnxruntime-web). Off-main-thread Web Worker with an automatic main-thread fallback. Model bundled in the package.
