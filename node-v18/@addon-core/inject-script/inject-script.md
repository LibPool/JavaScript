# @addon-core/inject-script

> 标签: addon, api, browser, chrome, edge, extension, firefox, google, opera, safari, script

## 简介

A lightweight, TypeScript-ready library for injecting JavaScript functions or external scripts into browser extension tabs and frames (Manifest V2 & V3).
