# @atlasauth/better-auth-migrate

> 标签: atlas, atlasauth, auth, better-auth, export, migration

## 简介

Export a Better Auth app (users, passwords, social accounts, two-factor, passkeys, API keys, organizations, SSO, OAuth apps, subscriptions, sessions) into an encrypted bundle for import into Atlas. Runs inside your app, through your own Better Auth databa
