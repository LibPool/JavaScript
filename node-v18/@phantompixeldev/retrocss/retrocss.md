# @phantompixeldev/retrocss

> 标签: 90s, accessibility, components, css, css-framework, dark-mode, design-system, desktop-ui, framework, retro, rtl, sass, scss, typescript, ui, vaporwave, wcag, win95, win98, win9x

## 简介

Win9x-style UI framework for the modern web: the mid-90s desktop look, WCAG AA in light and dark, keyboard-operable components, RTL support, and TypeScript types — with no runtime dependencies.
