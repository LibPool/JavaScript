# @kl13nt/strapi-plugin-website-builder

> 标签: build website, plugin, publishing, strapi, strapi plugin, strapi-plugin, website builder, website-builder

## 简介

A plugin for Strapi Headless CMS that provides the ability to trigger website builds manually, periodically or through model events.
