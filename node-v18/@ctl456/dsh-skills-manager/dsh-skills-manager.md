# @ctl456/dsh-skills-manager

> 标签: agent-skills, deepseek-harness, dsh-plugin, skills

## 简介

Unofficial DeepSeek Harness plugin: add, edit, remove, enable and disable agent skills from the Web settings page or from chat, so the harness loads them with its own skill tool
