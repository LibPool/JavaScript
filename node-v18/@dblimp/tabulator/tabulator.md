# @dblimp/tabulator

> 标签: JavaScript

## 简介

Integración con **`Tabulator`** (`tabulator-tables`) para tablas interactivas con procesamiento de datos a gran escala, filtrado en vivo, paginación remota y edición en celda para DBLimp.
