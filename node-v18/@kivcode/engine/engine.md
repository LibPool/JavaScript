# @kivcode/engine

> 标签: headless-cms, json-schema, kiv, page-builder, visual-editor

## 简介

Headless, JSON-driven document engine for the Kiv visual page-builder — document model, registry, field schema, history, and plugin system. No UI framework dependency.
