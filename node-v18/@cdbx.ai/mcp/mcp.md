# @cdbx.ai/mcp

> 标签: cdbx, claude-desktop, mcp, model-context-protocol, stdio-bridge

## 简介

Local stdio bridge to the cdbx MCP server — lets Claude Desktop (and any other stdio-only MCP client) connect to cdbx.
