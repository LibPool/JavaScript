# @tslite/format

> 标签: ast, eject, emitter, formatter, prettier, pretty-print, tslite, tsx, typescript

## 简介

TSLite source emitter and formatter — AST (emit) or text (format) to readable TypeScript/TSX in one pass: Doc algebra, 80-col wrapping, types preserved, comments printed. The runtime codegen is @tslite/codegen.
