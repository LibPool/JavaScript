# @tslite/explain

> 标签: developer-experience, diagnostics, error-messages, functional-programming, quickfix, typescript

## 简介

TSLite explain — enriches type-check diagnostics with 'why it is NOT a language bug' help for JS/OO habits (proto members, new, class), with operator suggestions and auto-fixes
