# @tslite/graph

> 标签: cycle-detection, dataflow, fixpoint, graph, lattice, strongly-connected-components, tarjan, tslite, worklist

## 简介

Monotone fixpoint propagation over graphs with cycles (worklist), strongly connected components and cycle detection, edge inversion. Zero dependencies, zero language coupling.
