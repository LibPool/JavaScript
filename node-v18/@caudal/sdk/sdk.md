# @caudal/sdk

> 标签: caudal, datadog, eventos, events, linaje, logs, observabilidad, observability, opentelemetry, otlp, sentry, telemetria, telemetry, tracing

## 简介

Caudal SDK — log() / event() / outcome(). Cero dependencias, fire-and-forget: jamás lanza, jamás frena a quien emite. Manda a Caudal, a la consola, a cualquier backend OTLP (Sentry, Datadog, Grafana) o a los tres a la vez.
