# @authbase/auth-api-nextjs

> 标签: api, auth, authbase, authbase.ai, authentication, login, nextjs, oauth, sdk

## 简介

A reusable authentication API SDK for AuthBase.AI platform that provides password sign-in, email verification code sign-in, password reset, sign-out, third-party authentication, and other features.
