# n8n-nodes-compasslab-qr-barcode

> 标签: barcode, barcode reader, compasslab, ean13, n8n, n8n-community-node-package, qr code, qr code generator

## 简介

n8n node for QR Code and Barcode Generator and Reader (CompassLab): Generate QR codes and EAN-13, UPC-A, Code 128, Code 39 barcodes (PNG or SVG), and read them from images.
