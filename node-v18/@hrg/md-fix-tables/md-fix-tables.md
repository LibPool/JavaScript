# @hrg/md-fix-tables

> 标签: align, aligner, cli, fix, formatter, gfm, markdown, pipes, readme, table, tables

## 简介

Fix and align the pipe tables in a Markdown file: pad every cell to a single grid, rebuild the separator row, keep the alignment markers, close rows that never ended.
