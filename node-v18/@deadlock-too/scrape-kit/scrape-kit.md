# @deadlock-too/scrape-kit

> 标签: api, scraper, typescript

## 简介

TypeScript toolkit for building resilient website-scraper clients: a retrying fetch client with backoff and User-Agent rotation, fuzzy title matching, a typed result/error model, and a base service to extend.
