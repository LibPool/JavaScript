# @digo-labs/docs

> 标签: JavaScript

## 简介

`defineDocs` — the MDX documentation engine behind design.digo-labs.com: styled MDX rendering, section/category navigation, sidebar, table of contents, ⌘K search, and live component/page/effect previews, wired from one config call.
