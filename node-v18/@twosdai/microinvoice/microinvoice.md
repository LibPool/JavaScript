# @twosdai/microinvoice

> 标签: JavaScript

## 简介

Fast & elegant PDF invoice generator for Node using PDFKit. No Puppeteer. Based on node-microinvoice by @baptistejamin.

## 官网

- 官网：https://github.com/twosdai/node-microinvoice
- 源码仓库：git://github.com/paigo-tech/node-microinvoice.git
- npm 页面：https://www.npmjs.com/package/@twosdai/microinvoice
