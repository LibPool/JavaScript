# @iflow-ai/search-mcp

> 标签: claude-code, claude-desktop, hermes, iflow, iflow-search, image-search, mcp, model-context-protocol, web-fetch, web-search

## 简介

MCP (Model Context Protocol) server for the iFlow Search API. Exposes web search, image search, and web fetch to any MCP client (Claude Code, Claude Desktop, Hermes Agent, …). Built on @iflow-ai/search-core.
