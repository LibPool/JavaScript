# @jaydeepgadhiya/guarddog

> 标签: audit, cli, express, guarddog, nodejs, sast, scanner, security, vulnerability

## 简介

Static analysis for Node.js & Express apps. Parses your code and reports injection, auth, async and schema bugs with a security score and an HTML report.
