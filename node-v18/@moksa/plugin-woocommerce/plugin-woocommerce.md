# @moksa/plugin-woocommerce

> 标签: JavaScript

## 简介

WooCommerce 搬家：匯入商品 CSV、商品圖片、顧客、優惠券與歷史訂單，需搭配 @moksa/emdash-shop 網站整合套件。

## 官网

- 官网：https://moksaweb.com
- npm 页面：https://www.npmjs.com/package/@moksa/plugin-woocommerce
