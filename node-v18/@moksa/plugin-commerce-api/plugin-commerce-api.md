# @moksa/plugin-commerce-api

> 标签: JavaScript

## 简介

整合 API：給 ERP、POS、倉儲讀取商品、庫存、訂單、顧客與優惠券的 REST API 金鑰，以及訂單、庫存、商品變動的 Webhook（Standard Webhooks 簽章、重試、自動停用），需搭配 @moksa/emdash-shop 網站整合套件。
