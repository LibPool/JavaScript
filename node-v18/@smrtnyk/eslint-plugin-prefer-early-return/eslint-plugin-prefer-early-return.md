# @smrtnyk/eslint-plugin-prefer-early-return

> 标签: code-style, early-return, eslint, eslint-plugin, eslint9, eslintplugin, flat-config, prefer-early-return

## 简介

ESLint plugin that enforces early returns over full-body conditional wrapping. Compatible with ESLint 9+ flat config.
