# @dekimuhq/trace-otel

> 标签: agtr, anchored-agent-trace-receipts, opentelemetry, otel, span-exporter, trace

## 简介

Convert OpenTelemetry spans to signed ar.trace.v2 (AgTR) receipts. OTel is an optional peer dependency; the core anchors verifier stays OTel-free.
