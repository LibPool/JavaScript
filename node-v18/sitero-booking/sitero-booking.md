# sitero-booking

> 标签: JavaScript

## 简介

`BookingPage` 與 `BookingManagementPage` 僅提供頁面內容，不含品牌 header 或網站外框。Consumer 請於 `app/booking/layout.tsx` 統一加入外框與樣式，讓 `/booking` 和 `/booking/manage` 共用 logo、名稱、背景與內容寬度。
