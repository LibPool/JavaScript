# @agent-unit/runtime

> 标签: agents, ai, ai-sdk, durable, langgraph, mastra, runtime

## 简介

agent-unit's optional run engine: journaled runs, pauses, the /runs API and adapters for AI SDK, Mastra, OpenAI Agents and LangGraph.
