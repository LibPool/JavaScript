# @nxgt/mongo-kit

> 标签: collections, configuration, gridfs, mongodb, transactions, typescript

## 简介

An application's MongoDB wiring in one object: a validated config, the clients it opens from it, and every collection typed on the database it lives in, and its GridFS files beside them in the same transactions
