# @nxgt/msw-graphql

> 标签: e2e, graphql, mock, mocking, msw, playwright, testing

## 简介

Mock a GraphQL API with msw by executing the real operations against your schema: one executor for the browser worker and the Node server, a control channel to reset, fail or reseed it from an e2e test, and a dual Vite/Node SDL loader
