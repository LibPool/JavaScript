# @nxgt/telemetry

> 标签: logging, observability, opentelemetry, otlp, telemetry, traceparent, tracing, typescript

## 简介

Logs and traces for a TypeScript service, with no OpenTelemetry SDK: spans over AsyncLocalStorage, W3C traceparent propagation, declared events, and a pipeline that never blocks the caller
