# @nxgt/telemetry-mongo

> 标签: logging, mongodb, mongoose, observability, opentelemetry, telemetry, tracing, typescript

## 简介

MongoDB for @nxgt/telemetry: an exporter that writes signals to a capped-by-TTL collection, and client spans from the driver's command monitoring
