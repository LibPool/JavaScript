# @scalebrowser/sdk

> 标签: agent-browser, ai-agents, browser, browser-automation, cdp, chrome-devtools-protocol, mcp, scalebrowser, sdk

## 简介

Official Node/TypeScript SDK for the Scalebrowser daemon: typed REST client plus a direct-CDP driver plane (nodriver-style, not Playwright).

- 官网：https://scalebrowser.net
- 源码仓库：git+https://github.com/blackdiamond-labs/scalebrowser.git
