# @c15t/core

> 标签: banner, ccpa, cmp, consent, consent-banner, consent-management, consent-management-platform, consent-manager, consent-mode-v2, cookie, cookie-banner, cookie-consent, cookies, eu-cookie-law, gdpr, global-privacy-control, google-consent-mode, headless, iab, iab-tcf, javascript, lgpd, preference-center, privacy, script-blocking, self-hosted-cmp, server-side-rendering, ssr, tcf, tracking-consent, typescript

## 简介

Headless JavaScript cookie consent engine and consent management platform (CMP). Stores GDPR consent, decides who sees a cookie banner, and gates configured scripts on each visitor's consent policy.
