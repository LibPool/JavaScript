# @wral/form

> 标签: JavaScript

## 简介

Lit web component for standalone form pages on WRAL sites: renders an api-forms document as a plain accessible form, submits it anonymously (e-mail only, no My WRAL account), and shows the confirmation. First page: Brain Game Registration.
