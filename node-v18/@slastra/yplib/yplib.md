# @slastra/yplib

> 标签: bluetooth-printer, flashtoy, knaon, label-printer, raster, reverse-engineering, thermal-printer, web-bluetooth, y50p, ypl

## 简介

YPL thermal label printer protocol: framing, CRC, 1-bit raster, and a Web Bluetooth transport. Reverse-engineered and verified against hardware captures.
