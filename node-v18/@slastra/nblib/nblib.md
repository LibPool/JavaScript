# @slastra/nblib

> 标签: b1, bluetooth-printer, label-printer, niimbot, niimbot-b1, raster, thermal-printer, web-bluetooth

## 简介

NIIMBOT B1 label printer protocol: packet framing, 1-bit raster encoding, print-job orchestration, and a Web Bluetooth transport. Browser-first, dependency-free ESM, ported from MultiMote's niimbluelib.
