# @emilia-protocol/langchain

> 标签: agent-safety, ai-agent, authorization, emilia-protocol, guardrails, human-in-the-loop, langchain, langchainjs

## 简介

Guard LangChain.js tools with EMILIA Protocol — require an offline-verifiable authorization receipt (EP-RECEIPT-v1) before an irreversible tool runs: missing -> refused, valid -> runs, replay -> refused, forged -> refused (RR-1). The approval becomes port
