# @emilia-protocol/attest

> 标签: agent, attestation, ed25519, emilia-protocol, identity, offline-verification, receipts, sha256

## 简介

Bind relying-party-pinned identity bytes and subject to a work-product hash in a signed EP receipt; no identity, authority, or execution overclaim.
