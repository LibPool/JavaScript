# @emilia-protocol/require-receipt

> 标签: 402, 428, a2a, agent-accountability, agent-authorization, agent-commerce, ai-agent, emilia-protocol, receipt-required, trust-receipt, verifiable-credential

## 简介

Demand a verifiable EMILIA authorization receipt for any irreversible agent action. Emits Receipt Required challenges (428, with legacy 402 compatibility) and tells the agent exactly what to bring.
