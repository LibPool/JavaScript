# @swins/vault-knowledge-mcp

> 标签: knowledge-graph, mcp, model-context-protocol, obsidian, reasoning-edges, semantic-search, vault

## 简介

Query a typed knowledge graph over an Obsidian vault: semantic concept search, contradiction surfacing across reasoning edges, and article retrieval. Read-only, local-first, stdio.
