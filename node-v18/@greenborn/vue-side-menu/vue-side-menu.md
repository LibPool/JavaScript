# @greenborn/vue-side-menu

> 标签: menu, navigation, responsive, side-menu, sidebar, vue, vue3

## 简介

Menú lateral genérico y autocontenido para Vue 3: configurable por props, responsive con overlay en móvil, filtrado opcional por permisos vía provide/inject y soporte opcional de vue-router. Sin dependencias de UI (CSS propio).
