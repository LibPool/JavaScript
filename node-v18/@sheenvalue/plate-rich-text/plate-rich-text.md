# @sheenvalue/plate-rich-text

> 标签: editor, plate, platejs, react-hook-form, rich-text, slate, tailwind

## 简介

Custom Plate-based rich text editor for React Hook Form — HTML-string contract, toolbar, tables, images, emoji, RTL, resize & expand.
