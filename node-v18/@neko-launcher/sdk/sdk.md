# @neko-launcher/sdk

> 标签: minecraft, neko-launcher, sdk, webhook, whitelist

## 简介

Official SDK for the Neko Launcher Server API and webhooks: whitelist sync and management from a server plugin or your own tools, and webhook signature verification.
