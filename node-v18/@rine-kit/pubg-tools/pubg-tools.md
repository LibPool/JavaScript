# @rine-kit/pubg-tools

> 标签: JavaScript

## 简介

The PUBG tool catalogue shared by every host: names, descriptions, validated inputs (zod) and the call into PubgDomainService. Hosts add only identity resolution and result delivery. Extracted from Lab's plugins/pubg.
