# @rine-kit/agent-core

> 标签: JavaScript

## 简介

The reasoning loop of an AI participant: chat model over an OpenAI-compatible endpoint, plugin tools, one turn service for text and voice. No dependency on RINE's API, LiveKit or desktop.
