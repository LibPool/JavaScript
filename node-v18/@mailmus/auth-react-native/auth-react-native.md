# @mailmus/auth-react-native

> 标签: JavaScript

## 简介

React Native SDK for Mailmus Auth end-users — sign-up, sign-in, MFA, OAuth (system browser + deep link), sessions, organizations. Wraps @mailmus/auth with a secure-storage token store and a native OAuth flow.
