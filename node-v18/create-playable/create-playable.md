# create-playable

> 标签: generator, mraid, pixi, pixijs, playable, playable-ad, template, threejs, vite

## 简介

Generator for playable-ad projects: TS + Vite + Pixi (+ optional Three.js), per-network adapters (generic/meta/google/applovin), single-file builds with size gates.
