# @kolkrabbi/kol-deck

> 标签: deck, design-system, kol, kolkrabbi, pptx, presentation, slides

## 简介

KOL presentations — slides as data (a 1920×1080 stage of text, image and rule layers), the renderer, the editor, present mode, and PNG · PDF · PPTX · deck-file export. Data and starting layouts are consumer-injected. Sits above @kolkrabbi/kol-{theme,compo
