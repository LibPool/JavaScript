# @andygo.dev/docs-harness

> 标签: ai, claude, claude-code, docs, documentation, mcp, search, typescript

## 简介

Local AI development harness for a project's own documentation: SQLite/FTS5 (optionally hybrid) search over your docs, served to coding agents through an MCP server.
