# @slipsheet/hugerte

> 标签: embed, hugerte, hugerte-plugin, pdf, slipsheet, tinymce-6

## 简介

HugeRTE editor plugin that adds a PDF upload button. Inserts standardized .slipsheet markup; pairs with @slipsheet/viewer for rendering. API-compatible with TinyMCE 6 (the last MIT-licensed TinyMCE).
