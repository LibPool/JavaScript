# @quarry-systems/agora-orchestrator

> 标签: JavaScript

## 简介

Orchestrator-engine (codename agora-offload) — named queues, depends_on resolution, resource locks, a fire-and-reconcile tick loop, and SQLite run-state behind pluggable Executor/Trigger seams.
