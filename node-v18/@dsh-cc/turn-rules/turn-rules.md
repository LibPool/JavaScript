# @dsh-cc/turn-rules

> 标签: JavaScript

## 简介

Turn rules: a non-interrupting rule engine that matches trigger-bearing cursor-plugin rules against completed tool calls/results and user prompts, injecting the rule body as an advisory reminder at that seam (additionalContexts / attributed inject)
