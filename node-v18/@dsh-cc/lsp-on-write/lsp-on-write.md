# @dsh-cc/lsp-on-write

> 标签: JavaScript

## 简介

LSP diagnostics-on-write: after a successful edit/write/NotebookEdit, pull the touched file's diagnostics from the running serena language servers via the mcpConnections registry and append them into the same tool result; settings-gated, dark by default
