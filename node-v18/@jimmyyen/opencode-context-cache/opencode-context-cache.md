# @jimmyyen/opencode-context-cache

> 标签: ai, context-cache, opencode, plugin, prompt-cache, session

## 简介

OpenCode plugin for stable, privacy-preserving prompt cache key and sticky session management. Concept from JackDrogon/opencode-context-cache, reimplemented with auto-update and Magic Context compatibility.
