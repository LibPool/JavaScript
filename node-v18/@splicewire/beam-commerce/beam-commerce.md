# @splicewire/beam-commerce

> 标签: JavaScript

## 简介

The commerce-domain beam surfaces, authored pre-packaged and DTO-first (rehome-ui, ADR-0116). Mirrors the PHP splicewire/laravel-beam-commerce package by domain. Ships the prepaid-credit auto-reload config + activity surface as a portable, tenancy-agnosti
