# @splicewire/beam-mainframe

> 标签: JavaScript

## 简介

The app-level frame that hosts schemastud Frames: the missing site-shell for a beam site. Ships the frozen slot contract (as types), an SSR-safe named-slot registry, a Mainframe registry (register a mode-layout by name), the host→Mainframe delegation seam
