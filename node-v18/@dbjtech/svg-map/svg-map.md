# @dbjtech/svg-map

> 标签: JavaScript

## 简介

- 车位id命名规则 `carport_车位号`  - 停车位绘制尺寸 ` width="50" height="70"`(车位图层必须包含这两个属性) - 车位状态图标请见`./images`文件夹 - 车位的底色建议不要使用灰色，容易和未开放状态的图标相混合。 - 引导屏命名规则 `screen_引导屏编号`
