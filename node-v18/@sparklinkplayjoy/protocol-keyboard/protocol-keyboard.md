# @sparklinkplayjoy/protocol-keyboard

> 标签: JavaScript

## 简介

- index.js 入口文件 - byte 字节相关文件 例如 Head：0x5c - message 消息系统,统一处理消息的收发 - pack 协议参数计算相关 - tools 数据处理公共方法
