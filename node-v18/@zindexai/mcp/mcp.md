# @zindexai/mcp

> 标签: ai-agents, architecture-diagram, claude, claude-code, cursor, diagram-as-code, diagrams, er-diagram, flowchart, mcp, mcp-server, mermaid, model-context-protocol, svg, version-history, zindex

## 简介

Immutable agent diagrams for Claude Code, Cursor, Claude Desktop and any MCP host. Your agent saves architecture, ER and flow diagrams (Mermaid or JSON), changes them later and opens any version by date. Teams share diagrams across people and agents.
