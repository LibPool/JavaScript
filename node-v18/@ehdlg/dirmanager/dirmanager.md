# @ehdlg/dirmanager

> 标签: cli, npmtool

## 简介

**CLI Directory Manager** is a command-line tool built with Commander.js that allows you to easily manage directories and files. With this tool, you can create directories, list the contents of directories, and create files directly from the command line.
