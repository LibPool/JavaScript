# @ghalex/kvbox-server

> 标签: firecracker, microvm, sandbox, server, vm

## 简介

kvbox host daemon: owns Firecracker microVMs on a Linux host and serves the kvbox API. Managed with the @ghalex/kvbox CLI.

## 官网

- 官网：https://kvbox.sh
- 源码仓库：git+https://github.com/ghalex/kvbox.git
