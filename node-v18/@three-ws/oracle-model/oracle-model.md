# @three-ws/oracle-model

> 标签: explainable-ai, logistic-regression, memecoin, offline-inference, oracle, prediction, pump.fun, rug-detection, solana, three.ws

## 简介

The three.ws Oracle conviction model, running locally. Download the real bucket weights once, then score any pump.fun launch offline with no API key: probability it runs, probability it rugs, and the probability it runs and hands it straight back.
