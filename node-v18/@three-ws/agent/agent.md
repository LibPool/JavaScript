# @three-ws/agent

> 标签: agent, ai-agent, cli, cron, mcp, model-context-protocol, openai-compatible, solana, subagents, telegram, terminal, three.ws, tui

## 简介

Run a three.ws agent on your own machine or VPS: a terminal UI with slash commands, streaming tool output, local file and shell tools in a resource-limited sandbox, the three.ws MCP tools and agent wallet, SQLite sessions with full-text search, parallel s
