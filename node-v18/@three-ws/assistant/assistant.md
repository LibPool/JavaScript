# @three-ws/assistant

> 标签: 3d, ai-agent, assistant, avatar, chatbot, embed, text-to-speech, three.ws, tts, widget

## 简介

A 3D avatar assistant for any website in one script tag. A floating launcher opens a real animated avatar with a chatbot mode (free models or the visitor's own Groq/OpenRouter key) and a speak mode that says whatever you type, out loud, in a speech bubble
