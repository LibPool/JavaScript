# @three-ws/x402-modal

> 标签: 402, agent-payments, base, checkout, eip-3009, eip3009, evm, metamask, micropayments, pay-per-call, payments, paywall, phantom, siwx, solana, stablecoin, usdc, web3, x402

## 简介

A drop-in, dependency-free payment modal for any x402 paid endpoint. One script tag turns a 402 challenge into a polished checkout: wallet connect (Phantom on Solana, MetaMask/EVM via EIP-3009), the 402 → sign → settle flow, SIWX re-entry, spending caps,
