# @priemskiyyy/flare-crashlytics

> 标签: adapter, crash-reporting, crashlytics, error-reporting, firebase, flare, react-native, typescript

## 简介

Firebase Crashlytics destination for flare on React Native: non-fatal errors through recordError, with an honest capability surface and an opt-in ambient integration for keys, user and logs.
