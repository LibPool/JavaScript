# @priemskiyyy/flare-devtools

> 标签: devtools, diagnostics, error-reporting, flare, inspector, react, solid, svelte, typescript, vue

## 简介

Devtools for flare: a framework-independent inspector for destination statuses, buffers, pending receipts and a payload-free timeline, with React, Vue, Solid and Svelte wrappers.
