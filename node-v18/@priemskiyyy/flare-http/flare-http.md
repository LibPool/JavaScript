# @priemskiyyy/flare-http

> 标签: adapter, backend, error-reporting, fetch, flare, http, idempotency, typescript

## 简介

HTTP destination for flare: sends each sanitized error report through your own client, with backend acknowledgement as evidence and reports that never cross accounts.
