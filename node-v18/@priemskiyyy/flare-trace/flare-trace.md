# @priemskiyyy/flare-trace

> 标签: analytics, breadcrumbs, bridge, error-reporting, flare, trace, typescript

## 简介

Bridge from Trace to flare: selected analytics events become error-relevant breadcrumbs, with only the properties you map, the time they occurred, and no history replayed.
