# @shieldlabs-ai/js

> 标签: device-intelligence, fingerprinting, fraud-detection, identification, risk-score, shieldlabs, visitor-identification

## 简介

Browser loader for ShieldLabs device intelligence: loads the hosted agent from the ShieldLabs CDN and returns a request ID for every identification.
