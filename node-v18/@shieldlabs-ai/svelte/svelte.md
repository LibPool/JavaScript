# @shieldlabs-ai/svelte

> 标签: device-intelligence, fraud-detection, identification, shieldlabs, svelte, sveltekit

## 简介

Svelte 5 and SvelteKit bindings for ShieldLabs device intelligence: load the agent once, track its state and get a request ID for every identification.
