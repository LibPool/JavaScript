# @nera-static/plugin-images

> 标签: avif, images, nera, nera-plugin, responsive-images, sharp, srcset, static-site-generator, webp

## 简介

A plugin for Nera static site generator to generate responsive, modern-format images (AVIF/WebP, srcset, width/height, lazy loading) at build time.
