# @koumatsumoto/gh-auth-bridge-client

> 标签: JavaScript

## 简介

gh-auth-bridge Worker と連携する SPA 向けクライアント SDK。 GitHub OAuth の popup login、token refresh、GitHub API 呼び出しを共通化する。
