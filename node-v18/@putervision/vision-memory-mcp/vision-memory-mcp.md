> 标签: ai-agents, ai-assistant, claude-code, clip, cursor, cursor-rules, developer-tools, lancedb, mcp, mcp-server, model-context-protocol, model-context-protocol-server, perceptual-diff, perceptual-hash, trajectory-export, ui-testing, vector-search, vision-memory, visual-cache, visual-sdd, visual-spec, windsurf

## 简介

Persistent visual cache for LLM-driven software development. Caches screenshots using perceptual hashing, vector search, and AX trees to prevent token overhead and visual hallucination loops.
