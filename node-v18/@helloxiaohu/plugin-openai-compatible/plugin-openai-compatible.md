# @helloxiaohu/plugin-openai-compatible

> 标签: JavaScript

## 简介

`@xpert-ai/plugin-openai-compatible` bridges the [XpertAI](https://github.com/xpert-ai/xpert) agent platform with any model provider that exposes an OpenAI-compatible REST API. It centralises authentication, base URL management, and capability declaration
