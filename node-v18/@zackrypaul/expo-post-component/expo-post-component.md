# @zackrypaul/expo-post-component

> 标签: component, expo, feed, link-preview, media, mentions, moti, post, react-native, react-query, reanimated, social, typescript, video

## 简介

Reusable React Native social post component for Expo apps. Renders feed posts with text parsing, mentions, link previews, responsive image/video media grids, polls, stats, interactions, and tags.
