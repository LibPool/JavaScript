# @open-neko/plugin-resend

> 标签: JavaScript

## 简介

Operational email for OpenNeko through Resend. The agent sends an email from a Resend template, from Markdown in a house layout, or from HTML, and checks delivery status. Rules match the real recipient domains. Network egress limited to api.resend.com.
