# @sabeesoft/insightql

> 标签: ast, cloudwatch, dsl, filter, logs, logs-insights, parser, query-language

## 简介

A tiny, dependency-free query language in the spirit of CloudWatch Logs Insights — parse a query string into an AST and evaluate it against plain JavaScript records.
