# @jdsalasc/solvejs-objects

> 标签: deep merge objects, get nested value, has own property, javascript object utilities, omit object keys, pick object keys, set nested value, solvejs, typescript object utilities, zero dependency

## 简介

Safe TypeScript object utilities for pick/omit, own-property checks, nested get/set, and prototype-hardened deep merges for config and state.
