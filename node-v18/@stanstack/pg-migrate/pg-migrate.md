# @stanstack/pg-migrate

> 标签: migrate, migrations, postgres, postgresql, schema

## 简介

A simple, scriptable PostgreSQL migration and schema management toolkit for Node.js/TypeScript projects. This package provides CLI tools to initialize your database directory, manage migrations, and generate type-safe database code using [apgdiff](https:/
