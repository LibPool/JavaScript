# @integration-tools/piece-shopify

> 标签: JavaScript

## 简介

Shopify piece that authenticates with a custom app's **Client ID + Client Secret** (client credentials grant) instead of a static Admin API access token. The access token is fetched and refreshed automatically on every request, so nothing expires.
