# @hypemova/retryable

> 标签: JavaScript

## 简介

This library provides a decorator-based retry mechanism inspired by Spring's @Retryable. It allows you to automatically retry a function or method upon encountering specific errors or exceptions. You can configure the maximum number of retries, the delay
