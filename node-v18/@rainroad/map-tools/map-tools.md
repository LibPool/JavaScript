# @rainroad/map-tools

> 标签: JavaScript

## 简介

当打包完成后，应将 `src/types` 下的类型文件同步拷贝进 `lib/types` 目录下。并在 `mapTool.d.ts` 和 `useMap` 的文件顶部添加 `/// <reference path="minemap.d.ts" />`，以使类型提示生效。
