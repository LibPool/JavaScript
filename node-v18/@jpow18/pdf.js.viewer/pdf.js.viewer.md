# @jpow18/pdf.js.viewer

> 标签: Mozilla, pdf, pdf.js

## 简介

A wrapper around PDF.js, providing a simplified interface for viewing and interacting with PDF documents within web applications. This wrapper is primarily focused on rendering interactive forms without all the overhead that comes with the PDF.js viewer.
