# @afta8/signalsmith-stretch

> 标签: audio, loop, pitch, time, web-audio

## 简介

JS/WASM release of the Signalsmith Stretch library, extended with native loop topologies (forward/reverse/ping-pong loopMode), tape-style mirror reverse, natural-end notifications, duration-preserving equal-power loop crossfade, and shared sample-buffer s
