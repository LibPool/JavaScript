# @arcaelas/dynamite

> 标签: arcaelas, arcaelas insiders, arcaelas-insiders, aws, decorators, dynamodb, dynamodb-orm, orm, typescript

## 简介

Modern decorator-first ORM for AWS DynamoDB with TypeScript support. Type-safe models, relationships, validations, and transactions.
