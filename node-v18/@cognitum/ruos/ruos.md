# @cognitum/ruos

> 标签: claude-code, claude-code-mod, claude-code-plugin, cli, cloud-desktop, codex, cursor, mcp, model-context-protocol, ruos

## 简介

ruOS from your terminal: browser sign-in, desktops, a stdio MCP bridge for Codex/Cursor, doctor, and a Claude Code mod (/ruos overview drawn like the ruOS console, an interactive live desktop view you click and type into, guard, audit, status line).
