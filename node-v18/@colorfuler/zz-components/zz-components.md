# @colorfuler/zz-components

> 标签: Vue3, components, ui

## 简介

开源的组件库开发起始模板，帮助以最轻松的方式搭建功能完善的Vue3组件库，让使用者只需关注到组件的开发，无需关注繁琐的搭建配置。
