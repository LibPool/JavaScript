# @dojocode/sql-test-helpers

> 标签: dojocode, pglite, postgresql, sql, sqlite, sqlite-wasm, test-helper, vitest

## 简介

Shared Vitest test helpers for in-process PGlite (PostgreSQL WASM) and sqlite-wasm. Auto-loads every non-test .sql file alongside the calling test and exposes a typed query/exec API.
