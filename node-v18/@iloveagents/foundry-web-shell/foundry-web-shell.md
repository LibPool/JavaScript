# @iloveagents/foundry-web-shell

> 标签: JavaScript

## 简介

Browser bootstrap and layout shell for Foundry UI — bootstrapShell({ modules, pages, theme, authProvider }) mounts the SPA around foundry-web-ui. Module-agnostic.
