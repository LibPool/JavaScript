# @cdeust/codex-claude-bridge

> 标签: JavaScript

## 简介

Symmetric composition root: an MCP stdio server mountable in either host (Codex or Claude Code), exposing the bridge_delegate tool that hands work to the peer. Published standalone so both hosts can reach it via `npx`, without checking out this repository
