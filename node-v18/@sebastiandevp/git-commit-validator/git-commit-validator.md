# @sebastiandevp/git-commit-validator

> 标签: cli, commit, commit-format, commit-message, conventional-commits, git, git-hooks, git-validation, hooks, team-workflow, validator

## 简介

Sistema de validación automática de commits con formato personalizado y CLI interactivo. Valida commits con patrón Tipo|IdTarea|YYYYMMDD|Descripción
