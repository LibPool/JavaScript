# @x12i/youtube-video-uploader-cli

> 标签: cli, oauth2, playlist, uploader, video-upload, youtube, youtube-data-api

## 简介

CLI tool to batch upload MP4 videos to YouTube via YouTube Data API v3 with OAuth2, metadata.json config, playlist assignment, swap, and sync-playlist alignment.
