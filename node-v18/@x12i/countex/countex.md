# @x12i/countex

> 标签: aggregation, analytics, counters, events, metrics, mongo, redis, sparse-matrix, timeseries

## 简介

Generic sparse counter matrices for JSON events. Dynamic counting, aggregation, and retrieval from mapped JSON inputs.
