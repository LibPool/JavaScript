# @xstate-devtools/mcp

> 标签: ai, mcp, model-context-protocol, statechart, xstate

## 简介

Model Context Protocol server for XState: list machines, describe structure, Mermaid diagrams, test paths, validation, find references, find implementation, setup() coverage, events, and state detail — over any workspace, no VS Code required.
