# @icodedigita/n8n-nodes-jazzcash

> 标签: automation, jazzcash, n8n, n8n-community-node-package, pakistan, payments

## 简介

n8n community nodes for JazzCash payments (create checkout, mobile account, vouchers, status, refunds, IPN trigger). An unofficial wrapper over the JazzCash documentation. Beta. By ICODEDIGITA.
