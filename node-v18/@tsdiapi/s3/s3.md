# @tsdiapi/s3

> 标签: aws, file-management, file-upload, presigned-url, private-bucket, public-bucket, s3, storage, tsdiapi, typescript

## 简介

A TSDIAPI plugin for seamless AWS S3 integration, enabling file uploads, downloads, and presigned URL generation.
