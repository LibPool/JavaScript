# wp-alchemist

> 标签: cli, composer, generator, scaffold, tailwind, vite, vue, wordpress, wordpress-plugin

## 简介

Create WordPress plugins with Composer, namespace prefixing, REST routes, migrations, Vite, Vue and Tailwind, then generate modules, migrations, controllers and repositories inside them.
