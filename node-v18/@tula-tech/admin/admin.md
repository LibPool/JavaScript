# @tula-tech/admin

> 标签: admin, api-client, auth, authentication, tula, user-management, webhooks

## 简介

Tula's typed admin API client for servers and tooling: every /v1/admin operation, generated from the OpenAPI contract. Takes a secret key; never for a browser.
