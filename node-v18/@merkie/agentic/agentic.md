# @merkie/agentic

> 标签: agent, agents, ai, ai-sdk, compaction, cost-tracking, durable, llm, observability, openrouter, resilience, retry, streaming, usage-tracking, vercel-ai-sdk, workflow

## 简介

A resilience, storage, and observability harness for LLM agents on the Vercel AI SDK + OpenRouter — durable resumable sessions, guaranteed-outcome tasks, smart retries, token-based compaction, and BYOK-aware cost tracking.
