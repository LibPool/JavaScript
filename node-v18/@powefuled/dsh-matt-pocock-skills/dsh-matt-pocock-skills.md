# @powefuled/dsh-matt-pocock-skills

> 标签: agent-skills, deepseek, deepseek-harness, dsh, dsh-plugin, matt-pocock, mattpocock, skills

## 简介

DeepSeek Harness plugin that mirrors Matt Pocock's agent skills (github.com/mattpocock/skills) into DSH as mp-* skills, with background sync, per-skill toggles and manual sync/management tools.
