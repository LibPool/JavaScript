# @pro-max-max/bridge-protocol

> 标签: bridge, capabilities, cesium, cesiumjs, iframe, permissions, postMessage, protocol, typescript

## 简介

Capability-based postMessage protocol for Cesium viewer host ↔ iframe guest communication. Defines the bridge envelope, 37 typed capabilities, error codes and handshake payloads.
