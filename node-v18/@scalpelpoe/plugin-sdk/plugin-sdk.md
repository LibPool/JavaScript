# @scalpelpoe/plugin-sdk

> 标签: electron, path-of-exile, plugin-sdk, poe, scalpel

## 简介

TypeScript SDK for building Scalpel plugins. Types only; the runtime is served by Scalpel at scalpel-internal://sdk.js via importmap.
