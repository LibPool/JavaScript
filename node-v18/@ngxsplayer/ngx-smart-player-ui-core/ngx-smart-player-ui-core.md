# @ngxsplayer/ngx-smart-player-ui-core

> 标签: a11y, accessibility, angular, headless, media, player, ui

## 简介

Headless, accessible UI primitives (play button, time slider, volume control) for ngx-smart-player. Source-profile aware, theme via CSS tokens.
