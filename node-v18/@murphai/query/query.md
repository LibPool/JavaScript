# @murphai/query

> 标签: JavaScript

## 简介

Owns read helpers, filters, derived retrieval state, and export-pack generation over canonical vault state. Query code must not mutate canonical vault data. It may rebuild local `.runtime/` artifacts such as the optional SQLite search index at `.runtime/s
