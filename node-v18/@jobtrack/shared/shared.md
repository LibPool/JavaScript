# @jobtrack/shared

> 标签: JavaScript

## 简介

Internal shared types and Zod schemas for [JobTrack](https://github.com/CuplexUser/JobTrack) — a personal job-application tracker. Consumed by `@jobtrack/api` and the `jobtrack` CLI.
