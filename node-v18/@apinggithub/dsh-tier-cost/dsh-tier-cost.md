# @apinggithub/dsh-tier-cost

> 标签: billing, cost, deepseek-harness, dsh, dsh-plugin, model-router, usage

## 简介

Per-level (L0–L3) spend for the DSH auto model router: folds session logs into token usage per routing level and joins the billing plugin's per-turn cost.
