# @cordini/elpis

> 标签: JavaScript

## 简介

企业级全栈应用框架。后端基于 Koa 约定式加载，前端基于 Vue 3 + Element Plus + Webpack 多页构建；业务项目通过依赖本包扩展 `app/`、`model/` 即可快速落地中后台。
