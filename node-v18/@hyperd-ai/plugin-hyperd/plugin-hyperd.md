> 标签: base, defi, dex-quote, elizaos, elizaos-plugin, hyperd, liquidation, plugin, pnl, token-security, usdc, wallet-risk, x402, x402-buyer

## 简介

ElizaOS plugin for hyperD — on-demand DeFi intelligence (wallet risk, token security, liquidation alerts, P&L, DEX quotes, synthesis-tier composed verdicts) paid per-call in USDC on Base via the x402 protocol. No API key, no signup.
