# grid-lanes-polyfill

> 标签: css, grid, grid-lanes, masonry, polyfill, waterfall

## 简介

A polyfill for CSS Grid Lanes (display: grid-lanes), the masonry/waterfall layout from CSS Grid Layout Module Level 3.
