# @unionkeyhq/hd-web-sdk

> 标签: JavaScript

## 简介

`@unionkeyhq/hd-web-sdk` is a browser implementation of hardware-sdk that creates an iframe and communicates with transport through the iframe to avoid cross-domain issues.
