# github-actions-annotations-reporter

> 标签: annotations, check-runs, cli, github-actions, issues, reporter, wont-fix, workflow

## 简介

Scans the latest GitHub Actions workflow runs for annotations and files dedup-aware GitHub Issues, with severity filters, won't-fix history-aware suppression, and auto-close when annotations vanish.
