# gasp-aicf-mcp

> 标签: aicf, compliance, eu-ai-act, gasp, gdpr, iso27001, mcp, model-context-protocol, nist, security, soc2

## 简介

MCP server for GASP AICF, an AI control library for organisations that build or deploy AI systems, scoped by named profiles. Mapped across 12 source frameworks, 2 crosswalks and 4 overlays, queryable from Claude Code, Claude Desktop or any MCP-compatible
