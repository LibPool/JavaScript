> 标签: ai-coding, analytics, astro, claude, cookieless, cursor, gizmo, install, mcp, model-context-protocol, nextjs, nuxt, onboarding, remix, sveltekit, web-analytics

## 简介

Cookieless web analytics for AI coding agents. Cursor / Claude / any MCP-aware tool installs the tracker in one prompt (framework-aware: Next, Remix, SvelteKit, Nuxt, Astro, Vite, React, HTML), verifies it's tracking, then reads your traffic. OAuth onboar
