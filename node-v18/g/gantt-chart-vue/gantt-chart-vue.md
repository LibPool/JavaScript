# gantt-chart-vue

> 标签: Gantt, Gantt chart, element-ui, gantt vue, vue, vue gantt, vue2.x, vue3.x, 甘特图

## 简介

vue2写的甘特图，支持高度自适应、tag拖拽、显示标记线、tag支持右键菜单、任务列支持显示右键菜单、支持只读模式、支持加减n天任务持续时间效果、支持tag避让效果【需结合后端数据刷新整个甘特图】
