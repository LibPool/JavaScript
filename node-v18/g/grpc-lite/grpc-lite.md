# grpc-lite

> 标签: api, grpc, light, lightweight, lite, protobuf

## 简介

this zero-dependency package will download and install the grpc-v1.0.1 prebuilt-binary from https://storage.googleapis.com/grpc-precompiled-binaries/node/grpc
