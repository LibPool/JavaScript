# gumlet-js-sdk

> 标签: gumlet, image api, video analytics, video api, video security

## 简介

Use Gumlet SDK to upload videos to Gumlet, manage channel & playlist, create image source, and get analytics

## 官网

- 官网：https://gumlet.com
- 源码仓库：git+https://github.com/akbansa/gumlet-js-sdk.git
- npm 页面：https://www.npmjs.com/package/gumlet-js-sdk
