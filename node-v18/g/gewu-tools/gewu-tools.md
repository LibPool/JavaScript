# gewu-tools

> 标签: JavaScript

## 简介

格物审视面插件：gewu_prep（HTML 逐页截图 + subagent_vision 简报契约生成，宿主直起 Chrome）+ gewu_locate（真值核验：文字定位到页码/行号）。让无视觉能力的主脑经 subagent_vision 完成视觉检验。
