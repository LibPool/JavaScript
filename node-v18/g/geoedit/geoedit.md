# geoedit

> 标签: editor, geojson, geopbf, gis, map, ortho-earth, sphere, topology

## 简介

GeoPBF topological editor as a map gadget: initEditor(map, opts). Edits on the sphere (great-circle edges, rotations, small circles), @style annotations shared with the viewer (geopbf/edit/draw), large-file mode on GintBUF — the editor half of the geopbf
