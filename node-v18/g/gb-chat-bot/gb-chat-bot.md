# gb-chat-bot

> 标签: JavaScript

## 简介

A lightweight, pluggable chatbot interface built with JavaScript and powered by **OpenAI’s ChatGPT** API. Perfect for integrating smart conversation assistants into your web applications, CRMs, customer support flows, or educational portals.
