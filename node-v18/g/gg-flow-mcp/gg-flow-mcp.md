# gg-flow-mcp

> 标签: chrome-extension, claude, google-flow, image-to-video, mcp, model-context-protocol, veo

## 简介

MCP server + Chrome extension that drives Google Flow: local image (+ optional end frame) and a prompt in, downloaded mp4 out.
