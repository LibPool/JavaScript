# gewu-i18n

> 标签: JavaScript

## 简介

- 约定大于配置 - 利用翻译接口自动翻译多语言 - 后端无须进行多语言配置，后端只需返回错误原始 key，前端进行多语言 - 支持 typescript, 支持将翻译后的对象映射到声明对象的类型中，方便调整
