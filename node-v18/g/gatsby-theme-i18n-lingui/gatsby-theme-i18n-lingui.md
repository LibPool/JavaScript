# gatsby-theme-i18n-lingui

> 标签: gatsby, gatsby-plugin, gatsby-theme, i18n, lingui

## 简介

A Gatsby theme for providing localization support via Lingui. This theme sets up Lingui's context provider so that you can access your translations on every page. Works best together with gatsby-theme-i18n.
