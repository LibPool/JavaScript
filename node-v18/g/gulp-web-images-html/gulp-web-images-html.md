# gulp-web-images-html

> 标签: gulp, html, webp

## 简介

Replaces the <img> tag with <picture> <source> <img> in HTML files. No SVG, GIF format and data- support. The mode is possible only for local links. Fork on the plugin gulp-webp-html-nosvg.
