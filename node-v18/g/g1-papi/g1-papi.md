# g1-papi

> 标签: JavaScript

## 简介

A library for interacting with the [G1 duniter](https://duniter.org) API.\ Use [polkadot-api](https://papi.how) (papi) to interact with the Polkadot blockchain.\ Not ~~polkadot.js~~.
