# gemup

> 标签: artsy, gemini, gemup, s3, upload

## 简介

Lightweight Javascript utility for using Artsy's Gemini service to upload directly to S3.

- 官网：https://github.com/artsy/gemup#readme
- 源码仓库：git+ssh://git@github.com/artsy/gemup.git
- npm 页面：https://www.npmjs.com/package/gemup
