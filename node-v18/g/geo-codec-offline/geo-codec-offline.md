# geo-codec-offline

> 标签: geocode, geocoding, geolocation, geonames, india, kd-tree, latitude, longitude, maps, offline, reverse-geocode, spatial, trie

## 简介

Zero-dependency offline geocoding library for India — forward geocode, reverse geocode, fuzzy search, and bounding-box queries. No internet required.
