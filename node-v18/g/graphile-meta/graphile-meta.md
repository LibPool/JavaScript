# graphile-meta

> 标签: codegen, constructive, dynamic-queries, graphile, graphql, introspection, meta, metadata, plugin, postgraphile, postgres

## 简介

PostGraphile v5 _meta introspection plugin — exposes a single _meta root query describing tables, fields, indexes, constraints, relations, inflection names, and smart-tag-derived metadata for dynamic query building and code generation
