# groupcache-js

> 标签: arc, cache, caching, consistent-hashing, distributed, distributed-cache, embedded-cache, groupcache, grpc, http2, kubernetes, lfu, lru, peer-to-peer, singleflight, typescript

## 简介

Distributed caching and cache-filling library for Node.js/TypeScript. No Redis required - your app instances become the cache.
