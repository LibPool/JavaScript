# gapt-mcp

> 标签: claude, devops, gapt, mcp, modelcontextprotocol, sandbox

## 简介

MCP server for GAPT (geny-adapted-project-toolkit) — drive projects, sandboxed workspaces, git, services, agent sessions and deploys from any MCP client
