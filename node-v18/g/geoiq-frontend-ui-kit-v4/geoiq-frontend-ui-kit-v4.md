# geoiq-frontend-ui-kit-v4

> 标签: geoiq, nextjs, react, shadcn, tailwindcss, typescript, ui-kit

## 简介

GeoIQ's shadcn-based component library — React 19 / Tailwind 4 / @base-ui/react. Real shadcn registry components, pulled verbatim via `npx shadcn add` and re-exported as-is, themed through one CSS file (dist/styles.css) a consumer can use as-is or overrid
