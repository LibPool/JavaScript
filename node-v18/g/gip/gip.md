# gip

> 标签: address, cli, dependency-free, dns, echo, external, external-address, external-ip, http, https, internet-protocol, iot, ip, ipv4, ipv6, network, public-ip, utility

## 简介

Zero-dependency, TypeScript-friendly module and CLI tool that uses node:http/https to retrieve your real public IPv4 or IPv6 address.
