# get-regions

> 标签: aws, aws-cli, cli, gcloud-cli, gcp-cli, google, google-cloud, regions

## 简介

NPX script that lists/searches the code names for all the AWS and GCP (Google Cloud Platform) regions and copy the selected one to the clipboard.
