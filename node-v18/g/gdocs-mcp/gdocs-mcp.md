# gdocs-mcp

> 标签: ai-tools, claude, document-automation, google-docs, google-sheets, google-workspace, mcp, model-context-protocol

## 简介

Open-source MCP server for Google Docs and Sheets. Self-hosted, local OAuth, no third-party token storage.
