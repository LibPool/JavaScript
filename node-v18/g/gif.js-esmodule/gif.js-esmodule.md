# gif.js-esmodule

> 标签: JavaScript

## 简介

基于 gif.js [官方链接：http://jnordberg.github.io/gif.js/] 封装的符合 esmodule 规范的 gif 插件 使用方法和 gif.js 一致，只是在其基础上增加了 npm 方式引入

## 官网

- npm 页面：https://www.npmjs.com/package/gif.js-esmodule

## 历史版本号

- 当前版本：1.0.0

- 1.0.0

## 获取地址

- npm 安装：`npm install gif.js-esmodule`
- npm registry：https://registry.npmjs.org/gif.js-esmodule
