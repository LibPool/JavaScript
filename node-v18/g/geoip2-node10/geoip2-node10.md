# geoip2-node10

> 标签: geoip, geoip2, geolocation, ip, maxmind, maxminddb, mmdb

## 简介

Maxmind GeoIP2 database reader for geolocating ip addresses.  Fast native implementation by wrapping libmaxminddb.
