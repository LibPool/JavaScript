# gpu-tex-enc

> 标签: EtcTool, GPUTexEncoder, astc, astcenc, basis, bc1, bc2, bc3, bc4, bc5, bc7, bc7enc, compression, dxt1, dxt3, dxt5, etc1, etc1s, etc2, etc2comp, image-compression, uastc

## 简介

API and CLI for compressing images using the ASTC, ETC, ETC2, BCn (DXTn) and BASIS texture compression standard.
