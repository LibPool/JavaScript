# go-nextwp-plate

> 标签: blog, boilerplate, create, docker, headless, i18n, nextjs, polylang, wordpress, wpgraphql

## 简介

Generate a headless WordPress (Docker + WPGraphQL) + Next.js (App Router) project in one command — optional Polylang i18n, advanced blog and contact form.
