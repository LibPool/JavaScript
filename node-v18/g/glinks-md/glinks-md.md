# glinks-md

> 标签: JavaScript

## 简介

Módulo de Node.js que recibe un string (en formato Markdown) y extrae todos los links encontrados y los devuelve en arreglo de objetos.

- 官网：https://github.com/LoreVazquez/extract-links-from-md#readme
- 源码仓库：git+https://github.com/LoreVazquez/extract-links-from-md.git
- npm 页面：https://www.npmjs.com/package/glinks-md
