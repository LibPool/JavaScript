# ga-toasts

> 标签: a11y, accessible, alert, confirm, customizable, dark-mode, ga-toasts, javascript toast, notification, notifications, promise, rtl, snackbar, swipe, theme, themeable, toast, toast notification library, toast notifications, toastify alternative, toasts, typescript, ui, vanilla-js, zero-dependency

## 简介

Modern, accessible, dependency-free toast notifications for the web. Fully themeable (createToaster + design tokens), stacked animations, 7 types, 9 positions, dark mode, swipe-to-dismiss, and first-class TypeScript support.
