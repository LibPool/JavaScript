# gittyignore

> 标签: JavaScript

## 简介

This is an interactive command line to generate `.gitignore` file templates across different tools, framework, languages e.t.c. We use the list from the [GitHub repo](https://github.com/github/gitignore) to populate the `.gitignore` template.
