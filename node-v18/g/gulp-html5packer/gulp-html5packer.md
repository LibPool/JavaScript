# gulp-html5packer

> 标签: gulp, gulp-h5packer, gulpplugin, html5, packer

## 简介

移动H5页面打包工具，可以根据描述将资源打包进html，替换资源为全局资源包CDN地址，减少请求数量

## 官网

- npm 页面：https://www.npmjs.com/package/gulp-html5packer

- 0.1.0

## 获取地址

- npm 安装：`npm install gulp-html5packer`
- npm registry：https://registry.npmjs.org/gulp-html5packer
