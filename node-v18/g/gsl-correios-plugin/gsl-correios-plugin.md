# gsl-correios-plugin

> 标签: JavaScript

## 简介

Este é um plugin para o [framework de e-commerce Vendure](https://www.vendure.io/)  Para integração com os Correios, Ele  lida com cálculos relacionados a envio de produtos, como cálculo de cubagem e peso, consulta de serviços disponíveis, cálculo de pra
