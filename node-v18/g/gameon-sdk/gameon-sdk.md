# gameon-sdk

> 标签: api-client, connect4, gameon, roulette, sdk, typescript

## 简介

One SDK for every GameOn game: GameClient (game frontends) and GameOnPlatform (game servers). Contracts: specs/gameon.yaml, specs/platform.yaml
