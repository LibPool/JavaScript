# gosce-postgres-redis-compose-generator

> 标签: a2a, ai-agent, getvda, mcp, postgres-redis-compose-generator

## 简介

Generate a production-ready docker-compose.yml for a Postgres + Redis (database + cache) stack — health checks, named volumes, PgBouncer pooling, Redis maxmemory/persistence policy, bridge networking
