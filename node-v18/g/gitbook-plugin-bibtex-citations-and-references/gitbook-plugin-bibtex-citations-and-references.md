# gitbook-plugin-bibtex-citations-and-references

> 标签: bibtex, citations, gitbook, references

## 简介

Beta quality, still some bugs. Plugin for Gitbook that handles citations and references. Expects bibtex references in 'literature.bib'. Uses Citation Style Language stylesheets to generate references. NOTE: this WILL NOT WORK on Gitbook's cloud servers si
