# graph-powers

> 标签: agent-skills, agents, claude-code, claude-code-plugin, codex, codex-cli, guardrails, harness, hooks, skills

## 简介

A shared harness for Claude Code and Codex CLI: agents, skills, commands and git/execution guardrails that work in any repository. The project declares its stack in one config file and the plugin adapts.
