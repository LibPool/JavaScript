# generator-devpress

> 标签: wordpress-generator, yeoman-generator, yeoman-wordpress-generator

## 简介

A Yeoman generator for Wordpress including automatic database setup, the download and install of advanced custom fields, the download and install of Yoast SEO, install option for third party themes, and grunt script for minimising CSS/JS and compressing i
