# grecha-susha

> 标签: framework, frontend, grecha, html, js

## 简介

Dead-Simple Front-End JavaScript Framework. Originally designed for emoteJAM. Derived into a more complete framework by Spectcow. The name basically means buckwheat and land in russian.
