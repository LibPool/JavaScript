# gowm

> 标签: auto-detection, bridge, cli, composables, cross-platform, events, github, go, golang, hooks, javascript, loader, manager, memory-management, nodejs, react, typescript, vue, wasm, webassembly

## 简介

Go Wasm Manager - Loader system for Go WebAssembly modules with GitHub repository support. Features auto-detection, event system, CLI, React hooks, Vue composables and TypeScript type generation.
