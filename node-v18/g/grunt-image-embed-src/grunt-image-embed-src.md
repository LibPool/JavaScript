# grunt-image-embed-src

> 标签: base64, css, data URI, gruntplugin, image, src

## 简介

Grunt task for embedding images as base64 data URIs inside your stylesheets or as src values in other files.

- 源码仓库：git://github.com/tango42/grunt-image-embed-src.git
- npm 页面：https://www.npmjs.com/package/grunt-image-embed-src
