## 简介

GoCreative — keyless compliance & regulated-data tools for AI agents: OFAC/sanctions/PEP + KYB screening, SEC, FRED, FDA recalls, federal awards. Pay-per-call USDC, no API key. One-line MCP server for Claude Code, Cursor, Cline & any MCP client.
