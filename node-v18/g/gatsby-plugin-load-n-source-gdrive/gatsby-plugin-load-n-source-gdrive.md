# gatsby-plugin-load-n-source-gdrive

> 标签: JavaScript

## 简介

This plugin takes the following params and uses them (a) to copy assets from google drive to your local file system  and (b) expose their meta-data properties from google drive under the `gDrive` namespace in graphql.
