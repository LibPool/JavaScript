# graphstream-algo

> 标签: dynamic, graph, graphstream

## 简介

GraphStream is a library for the modeling and analysis of dynamic graphs. You can generate, import, export, measure, layout and visualize them. This is the algo package contains some algorithms that you can use with GraphStream.
