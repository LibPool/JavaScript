# gulp-config-tool

> 标签: JavaScript

## 简介

gulp-config-tool 是一个基于gulp封装的npm包，它内部集成好了gulpfile.js等配置文件，我们只需要直接使用该工具提供的命令，即可实现打包，本地调试等功能
