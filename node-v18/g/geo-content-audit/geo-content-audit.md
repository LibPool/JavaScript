# geo-content-audit

> 标签: ai-seo, claude, content-audit, geo, llm-seo

## 简介

CLI for the geo-content-audit Claude Skill — fetches pages, extracts visible text, runs deterministic prechecks, and asks an LLM (Claude Code CLI or Anthropic API) to audit content against SKILL.md's GEO judgment criteria.
