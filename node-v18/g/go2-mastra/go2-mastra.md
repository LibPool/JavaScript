# go2-mastra

> 标签: agent-attribution, agent-native, ai-agents, go2, mastra, mcp, short-links, url-shortener

## 简介

Mastra tools for Go2 — short links your AI agent can call. Mint tracked URLs, set expiry, query per-run agent attribution. Drops into any Mastra Agent in 5 lines.
