# gecko-mcp

> 标签: automation, browser, claude, firefox, floorp, gecko, librewolf, marionette, mcp, model-context-protocol, waterfox, webdriver, zen-browser

## 简介

An MCP server that lets AI assistants (Claude Code, Claude Desktop, Cursor…) read, screenshot and manage tabs in Firefox-based browsers — Floorp, LibreWolf, Waterfox, Zen, Mullvad, Firefox — via Floorp's automation API or Marionette.
