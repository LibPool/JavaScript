# gjirafaapi

> 标签: autobus, gjirafa, kadriu, shqip, toti

## 简介

gjirafa.com offers a very useful service to check bus schedule in Kosovo. They do not, however, offer an API or module which developers can use and present the information in their applications. As such, I have created this node module to help developers
