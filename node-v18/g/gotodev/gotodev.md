# gotodev

> 标签: angular, boilerplate, cli, create-app, fast, generator, react, rust, scaffold, starter, svelte, template, typescript, vite, vue

## 简介

🚀 Create React + TypeScript + Tailwind apps in 2.3s instead of 45s. 100x faster than Vite. Built with Rust + Oxc + Rolldown. Single-pass compilation. Security audit passed (0 vulnerabilities).
