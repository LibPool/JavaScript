# gulu-duck

> 标签: JavaScript

## 简介

这是一个基于 Vue3 + TypeScript 的 UI 组件库，涵盖了Button、Switch、Dialog、Tabs...等常见UI组件。 深入研究 Vue 3，使用了 setup、onMounted、ref、computed 等 Compositioin API，模块化的源代码简洁明了，易于阅读。 我还推出了官方文档，地址为：https://duckzzzzzz.github.io/gulu-duck-ui/#/，可在线查看示例代码，并支持PC 和手机浏览。
