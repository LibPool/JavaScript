# github-pr-review-mcp

> 标签: ai, automation, cli, code-analysis, code-review, fastmcp, github, github-api, mcp, pr, pull-request, review, typescript

## 简介

MCP server for GitHub PR reviews and code analysis using FastMCP. Provides AI-powered code review comments, security analysis, and automated feedback for pull requests.
