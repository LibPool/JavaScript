# greenlock-challenge-test

> 标签: ACME, Let's Encrypt, challenge, dns-01, http-01, module, plugin, strategy

## 简介

The base set of tests for all ACME challenge strategies. Any `acme-http-01-`, `acme-dns-01-`, `acme-challenge-`, or greenlock plugin should be able to pass these tests.
