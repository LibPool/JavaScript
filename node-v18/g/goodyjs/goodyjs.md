# goodyjs

> 标签: framework, full-stack, goody, goodyjs, http-server, reactive, router, signals, ssr, zero-dependency

## 简介

A lightweight, zero-dependency full-stack JavaScript framework uniting reactive UI, native HTTP server, composable middleware, SSR, and zero-config tooling.
