# git-branch-cleanup

> 标签: JavaScript

## 简介

A Node.js CLI tool to help clean up your local Git branches that have no active upstream branch or whose upstream branch is gone.

## 官网

- npm 页面：https://www.npmjs.com/package/git-branch-cleanup

## 历史版本号

- 当前版本：1.0.4

- 1.0.4

## 获取地址

- npm 安装：`npm install git-branch-cleanup`
- npm registry：https://registry.npmjs.org/git-branch-cleanup
- Node 要求：>= 6.0.0
