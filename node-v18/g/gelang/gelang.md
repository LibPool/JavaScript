# gelang

> 标签: compiler, cpp, csharp, flutter, ge, gelang, golang, kotlin, polyglot, python, react, rust, transpiler, typescript, zig

## 简介

One typed source language, compiled to Rust, C++, C#, Zig, Go, or Kotlin — chosen per function. Generates Flutter and React UIs from one DSL.
