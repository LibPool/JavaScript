# getaxon

> 标签: JavaScript

## 简介

Multi-tenant, multi-agent business-automation platform. Next.js (App Router, Turbopack) + Prisma/Postgres + the Vercel AI SDK (Anthropic Claude, with an optional local Ollama fallback in dev).
