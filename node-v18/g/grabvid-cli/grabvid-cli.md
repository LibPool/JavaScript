# grabvid-cli

> 标签: JavaScript

## 简介

Terminal app to download videos from YouTube, X, Instagram, and more. Paste a URL, pick a format, grab it.

## 官网

- npm 页面：https://www.npmjs.com/package/grabvid-cli

## 获取地址

- npm 安装：`npm install grabvid-cli`
- npm registry：https://registry.npmjs.org/grabvid-cli
- Node 要求：>=18
