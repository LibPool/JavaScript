# gaido

> 标签: agents, ai, claude-code, codex, creative-coding, generative-art, node-graph, pixi, playwright, video

## 简介

A lab notebook for creative-coding agents — a coder agent writes a visual scene, a renderer captures deterministic video, a critic reviews it; every attempt is a forkable node on a graph.
