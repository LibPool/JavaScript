# gatsby-theme-glossary

> 标签: gatsby, gatsby-plugin, gatsby-theme

## 简介

A minimalist [Gatsby Theme](https://gatsbyjs.org/docs/themes) for a glossary built with [MDX](https://mdxjs.com) and [Theme UI](https://theme-ui.com).
