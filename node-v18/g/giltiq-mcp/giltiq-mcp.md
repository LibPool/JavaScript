# giltiq-mcp

> 标签: 18e, bzst, eu, germany, mcp, model-context-protocol, qualified-confirmation, tax, ustg, validation, vat, vies

## 简介

MCP server for EU VAT validation — VIES + BZSt failover, §18e qualified confirmations, cached fallback. Works when VIES is down.
