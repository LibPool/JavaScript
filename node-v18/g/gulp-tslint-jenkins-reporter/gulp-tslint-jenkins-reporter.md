# gulp-tslint-jenkins-reporter

> 标签: checkstyle, gulp, hudson, jenkins, report, reporter, tslint, xml

## 简介

gulp-tslint checkstyle reporter, to be used by Jenkins (Hudson). Writes output to an xml file.
