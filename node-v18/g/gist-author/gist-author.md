# gist-author

> 标签: JavaScript

## 简介

Gist Author provides user experiences over Gist-backed content. This system is aimed at the strange subset up authors who want to publish content (sometimes on an ad-hoc bases) AND who are already invested in Gist-based [tools](https://github.com/defunkt/
