# generator-litelement-cli

> 标签: cli, lit, litelement, polymer, scaffolding, wc, web components, webcomponents, yeoman-generator

## 简介

A simple LitElement CLI to generate a complete modern web component scaffolding. Includes Webpack, Babel, Karma, Documentation and IE11 support. Router is an option :)
