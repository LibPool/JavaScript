# gitbook-plugin-double-edit-link

> 标签: edit-with, gitbook, github, plugin

## 简介

GitBook Plugin to add "Edit this page" link on every page. Link target will be that page's source file on Github or Gitlab or any repo, the other target link can be a online editor
