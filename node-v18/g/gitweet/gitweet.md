# gitweet

> 标签: cli, developer-tools, github, github-action, launch, open-source, release, share, social, tweet, twitter, x

## 简介

Generate a pre-filled tweet link for your GitHub project in one command. No API, no tokens — just a link that opens X with your release text ready to post.
