# gatehouse-mcp

> 标签: agent-tools, claude, gatehouse, mcp, model-context-protocol, registry

## 简介

The Gatehouse registry as an MCP server: ask an agent-tooling question (is X safe, what's out there, give me the audit) and get Gatehouse's vetted verdict, live. Read-only, no telemetry.
