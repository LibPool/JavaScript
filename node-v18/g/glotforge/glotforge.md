# glotforge

> 标签: ai, i18n, icu, internationalization, keyless, localization, nextjs, react, translation, typescript

## 简介

Keyless i18n for TypeScript & React — write copy in your own language, ship every language. Content-hash catalogs, a build-time loader, and AI translation with glossary and context steering.
