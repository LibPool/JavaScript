# geto-goals

> 标签: agent, autonomous, geto, goals, loop, pi-package

## 简介

Durable autonomous goal loop for pi (Codex /goal style). /goal set|show|edit|pause|resume|clear plus a goal_report tool and an agent_settled continuation loop. Goal state lives in .pi/goals/goal.json and is re-injected every turn, so it survives compactio
