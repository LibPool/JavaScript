# greed.js

> 标签: ai, browser, deep-learning, gpu-acceleration, machine-learning, neural-networks, numpy, python, pytorch, tensor, webassembly, webgpu

## 简介

Lightweight, private alternative to Colab. Run PyTorch & NumPy in browser with GPU acceleration (8.8x speedup). Fast, secure, runs locally.
