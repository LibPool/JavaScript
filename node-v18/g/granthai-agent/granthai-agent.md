# granthai-agent

> 标签: api, documentation, generator, go, java, mcp, model-context-protocol, openapi, openapi-3.1, php, proxy, python, reverse-proxy, swagger

## 简介

Language-agnostic GranthAi agent: a reverse proxy that generates OpenAPI 3.1 docs, Swagger UI and an MCP server from the live traffic of any HTTP API
