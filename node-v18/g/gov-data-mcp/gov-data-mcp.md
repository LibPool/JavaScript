# gov-data-mcp

> 标签: apify, compliance, due-diligence, environmental, epa, faa, fdic, fema, government-data, mcp, mcp-server, modelcontextprotocol, noaa, open-data, phase-i-esa, real-estate, usgs

## 简介

MCP server exposing published US government open-data tools (EPA, FEMA, USGS, NOAA, FAA, USACE, FDIC, HUD, state licensing boards) as agent-callable tools, backed by Apify Actors.
