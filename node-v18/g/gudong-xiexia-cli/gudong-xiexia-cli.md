# gudong-xiexia-cli

> 标签: agent, ai, cli, diary, local-first, s3, webdav, xiexia

## 简介

CLI tool that lets AI agents read and write your Xiexia (写下) diary from S3/WebDAV. No MCP needed, just a command.

- npm 页面：https://www.npmjs.com/package/gudong-xiexia-cli
