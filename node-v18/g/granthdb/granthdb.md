# granthdb

> 标签: browser-database, client-side-database, database, dexie, dexie-alternative, granthdb, indexeddb, local-first, offline, opfs, origin-private-file-system, orm, sqlite, sqlite-wasm, wasm, web-worker

## 简介

SQLite in the browser with a Dexie-compatible API. OPFS-backed, runs in a Web Worker, safe across tabs, with an IndexedDB fallback.
