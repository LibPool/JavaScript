# google-analytics-api

> 标签: JavaScript

## 简介

"This module takes an OAuth 2.0 token returned by Google, verifies it, gets temporary authentication and refresh tokens, requests new authorization tokens with refresh tokens, and gets Google Analytics data using the analytics query provided."
