# gridcarbon

> 标签: api-client, carbon, carbon-intensity, co2, eia, electricity, energy, entsoe, gco2eq, green-software, grid, neso, sdk, sustainability

## 简介

Tiny zero-dependency client for the gridcarbon.dev grid carbon intensity API (45 zones across Europe, the US and Great Britain).
