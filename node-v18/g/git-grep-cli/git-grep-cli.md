# git-grep-cli

> 标签: cli, command line, commit message, file content, git, git hash, git tools, git-grep, grep, lost-found, regret, regret medicine, search

## 简介

A simple command line tool to search for commit-message or file-content in a git repository to retrieve the corresponding git hash.
