# global-timezones

> 标签: geography, javascript, timezones, typescript

## 简介

global-timezones is a robust npm package that provides comprehensive information about time zones, including detailed Daylight Saving Time (DST) data. This package is designed to help developers easily access accurate and up-to-date time zone information
