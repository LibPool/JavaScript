# gatsby-theme-deck-n-blog

> 标签: gatsby, gatsby-plugin, gatsby-theme

## 简介

You write the MDX for your [mdx-deck](https://github.com/jxnblk/mdx-deck)s, and this Gatsby theme creates the deck and the blog post for you.
