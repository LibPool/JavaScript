# get-user-media-promise

> 标签: MediaDevices, get, getUserMedia, helper, light, media, mozGetUserMedia, navigator.msGetUserMedia, pollyfill, polyfill, ponyfill, promise, shim, small, tiny, user, webkitGetUserMedia, wrapper

## 简介

Light-weight wrapper for the newer Promise-based MediaDevices.getUserMedia API with a fallback to navigator.getUserMedia (and it's prefixed variants)
