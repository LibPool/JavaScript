# geo-finance

> 标签: JavaScript

## 简介

**geo-finance** — TypeScript-библиотека для работы с финансовыми данными по регионам России с возможностью географической визуализации и анализа. Идеально подходит для исследования региональных финансовых потоков, построения индексов и сравнения регионов.
