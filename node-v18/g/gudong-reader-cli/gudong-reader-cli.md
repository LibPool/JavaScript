# gudong-reader-cli

> 标签: agent, ai, cli, epub, local-first, reader, reading, s3, webdav

## 简介

CLI tool that lets AI agents read your ShuDongDong (书咚咚) reading data from S3/WebDAV. No MCP needed, just a command.
