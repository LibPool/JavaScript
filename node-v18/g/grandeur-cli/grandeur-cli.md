# grandeur-cli

> 标签: JavaScript

## 简介

Universal code compiler and package manager for microcontrollers. Based on Arduino. Currently supports ESP8266 and ESP32 family.

- npm 页面：https://www.npmjs.com/package/grandeur-cli
