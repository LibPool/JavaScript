# gsl-asset

> 标签: JavaScript

## 简介

Este é um serviço para o [framework de e-commerce Vendure](https://www.vendure.io/) projetado para adicionar/remover a associação do asset ao usuário. Funcionalidade atribuída ao projeto [Gseller](https://gseller.com.br/).
