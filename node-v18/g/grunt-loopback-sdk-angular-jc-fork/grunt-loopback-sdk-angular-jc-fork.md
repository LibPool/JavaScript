# grunt-loopback-sdk-angular-jc-fork

> 标签: angular, gruntplugin, loopback

## 简介

Grunt plugin for auto-generating Angular $resource services for LoopBack using loopback-sdk-angular-jc-fork which enables multiple instance creation by implemeting the createMany feature
