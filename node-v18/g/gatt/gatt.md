# gatt

> 标签: all, bootstrap, builder, generate, generator, scaffold, scaffolding, template, the, things, utility

## 简介

Generate All The Things (GATT) using this library. It provides an extremely flexible workflow that should cover most use cases to scaffold some variables and template into an output directory.
