# gfm.macro

> 标签: babel-plugin-macros, cmark, cmark-gfm, commonmark, gfm, github flavored markdown, github-flavored-markdown, jsx, markdown, react

## 简介

GitHub Flavored Markdown Babel macro converts Markdown to JSX at compile time using the cmark-gfm C library.
