# garn-mcp

> 标签: ai, components, design-system, garn, mcp, model-context-protocol, radix, react, tailwind

## 简介

garn MCP query server — ask the garn design system about its components (search, view, examples, recipes, relations, audit). Ships a bundled metadata snapshot; runs over stdio via `npx garn-mcp`.
