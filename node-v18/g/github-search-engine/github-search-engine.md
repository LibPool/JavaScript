# github-search-engine

> 标签: JavaScript

## 简介

Very simple and reusable `React.js` debounced autocomplete component which searches through [GitHub v3](https://developer.github.com/v3/) REST API for repositories or usernames matching provided string. Styled with [material-ui](https://material-ui.com/),
