# gdharness

> 标签: ai, ai-integration, ai-tools, auto-reload, claude, cline, cursor, dap, debug-adapter-protocol, developer-tools, game-development, game-engine, gamedev, gdharness, gdscript, godot, godot-engine, godot4, input-injection, language-server, lsp, mcp, mcp-server, model-context-protocol, opencode, screenshot, typescript

## 简介

A harness for driving a Godot 4 project from an agent: editor addons, a runtime bridge into the running game, an MCP server in front of them, and a CLI that installs and diagnoses the Godot side.
