# grunt-cellarise-mongoimport

> 标签: grunt, gruntplugin, import, mongo, mongodb

## 简介

This package has been forked from andrewkeig/grunt-mongoimport, and updates the task to remove newlines from source json files before importing data into mongodb.  Grunt task for importing data into mongodb.
