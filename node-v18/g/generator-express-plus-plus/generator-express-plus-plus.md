# generator-express-plus-plus

> 标签: babel, es6, eslint, express, node, yeoman, yeoman-generator

## 简介

Basic generator for express using npm as a build tool and babel jade eslint mocha chai with a basic file structure. Ideal boilerplate for small projects.
