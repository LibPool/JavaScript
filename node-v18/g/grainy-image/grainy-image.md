# grainy-image

> 标签: canvas, css, custom-element, film-grain, filter, grain, grainy, image-effect, noise, shadow-dom, svg, texture, turbulence, vanilla-js, web-component, web-components

## 简介

A Web Component for creating grainy/noisy image effects with 4 powerful methods: Canvas, CSS Gradient Mask, CSS Background Layers, and SVG feTurbulence
