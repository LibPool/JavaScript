# godot-ai-mcp

> 标签: ai, claude, copilot, cursor, editor, game-development, gdscript, godot, godot4, mcp, model-context-protocol

## 简介

MCP server that gives AI agents full control over the Godot 4.7+ editor — scene tree, node manipulation, GDScript execution, viewport capture, and ClassDB reflection.
