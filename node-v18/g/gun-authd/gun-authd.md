# gun-authd

> 标签: argon2, authentication, decentralized, deterministic, gun, gundb, hkdf, offline, p2p

## 简介

Deterministic authentication for GunDB using Argon2id + HKDF. Supports optional PIN, rate limiting, and enhanced security. Offline-first, censorship-resistant login.
