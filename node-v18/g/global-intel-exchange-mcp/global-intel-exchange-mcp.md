# global-intel-exchange-mcp

> 标签: agent, claude, compliance, cve, mcp, model-context-protocol, sanctions, x402

## 简介

MCP server exposing the Global Intelligence Exchange x402 API (US sanctions screening, NVD CVE lookups, SEC/Companies House company checks) as tools for Claude and other MCP hosts. Pays per query with your own wallet via x402/USDC on Base.
