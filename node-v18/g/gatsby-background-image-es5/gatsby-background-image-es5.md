# gatsby-background-image-es5

> 标签: ES5, background, background-image, backgroundImage, gastby-component, gatsby, gatsby-image, image, react-component

## 简介

Lazy-loading React background-image component with optional support for the blur-up effect. Transpiled to ES5.
