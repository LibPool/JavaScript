# gulp-iconfont-css-and-template

> 标签: iconfont, iconfont-css, iconfont-template

## 简介

基于gulp-iconfont和gulp-iconfont-css源码修改的组件，用于生成iconfont及字体图标及查看模板。解决生成的字体图标不方便查看的问题
