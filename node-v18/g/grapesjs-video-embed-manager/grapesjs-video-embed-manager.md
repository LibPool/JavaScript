# grapesjs-video-embed-manager

> 标签: embed, grapesjs, manager, plugin, video, videos, vimeo, youtube

## 简介

A wrapper that turns the grapesjs video component into a dynamic experience, opening a modal similar to the GrapesJS Asset Manager. This plugin has been optimized to work with Youtube, Vimeo, and a local video server.
