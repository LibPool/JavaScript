# gen-erd-cli

> 标签: cli, database, diagram, erd, mysql, postgresql, schema, sql-server, sqlite

## 简介

A CLI tool that generates beautiful ERD diagrams using database connection configs. Supports PostgreSQL, MySQL, SQL Server, and SQLite.
