# genshin-engine

> 标签: anime, cel-shading, game-engine, open-world, procedural, three, threejs, toon, tsl, typescript, webgpu

## 简介

An anime-style open-world engine for the browser on three.js WebGPU — toon materials, outlines, post-processing, streamed terrain, parametric world kits and a Web Audio synthesizer, as plain TypeScript and TSL modules.
