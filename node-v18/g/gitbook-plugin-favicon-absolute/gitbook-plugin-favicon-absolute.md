# gitbook-plugin-favicon-absolute

> 标签: absolute, apple-touch-icon, bookmark, favicon, gitbook-plugin-favicon-absolute, icon, shortcut

## 简介

favicon-absolute 插件采用绝对路径设置网站 favicon 图标,相对于相对路径来说更加简单方便.
