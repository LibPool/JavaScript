# grunt-vows-runner

> 标签: asynchronous, bdd, concurrent, grunt, gruntplugin, parallel, runner, task, test, testing, vows

## 简介

An alternative test-runner for vows using grunt.  Adds new capabilities such as running test suites concurrently.
