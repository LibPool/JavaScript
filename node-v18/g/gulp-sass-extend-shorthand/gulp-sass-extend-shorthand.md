# gulp-sass-extend-shorthand

> 标签: extend, gulp, gulp-replace, gulp-sass, gulpplugin, sass, shorthand

## 简介

A gulp-replace wrapper to add a shorthand syntax for writing @extend rules in Sass stylesheets.
