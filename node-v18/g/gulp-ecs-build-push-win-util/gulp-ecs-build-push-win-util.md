# gulp-ecs-build-push-win-util

> 标签: amazon, deploy, ecs, git, gulp, windows

## 简介

Gulp utility tasks to facilitate container deployment to Amazon Elastic Container Service. Also contains tasks for bumping package version, tagging and committing to git.
