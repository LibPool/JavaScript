# governance-idl-sdk

> 标签: JavaScript

## 简介

The **Governance SDK** is a TypeScript-based library enabling developers to create, manage, and interact with the SPL Governance program on the Solana blockchain. It simplifies building governance applications by abstracting low-level blockchain operation
