# gatsby-transformer-prismic

> 标签: gatsby, gatsby-plugin, gatsby-transformer-plugin, html, prismic, prismjs, responsive images

## 简介

A Gatsby transformer plugin for Prismic Rich Text fields. Supports ToC generation, responsive images, section anchors and Prism.JS code highlighting.
