# gatsby-remark-remove-root-p-tag

> 标签: gatsby, gatsby-plugin, remark

## 简介

Removes the wrapping HTML `<p>` tag that `gatsby-transformer-remark` automatically adds during its markdown transformation process. The root `<p>` tag or root line break `
` is preserved if it exists in the user-provided markdown.
