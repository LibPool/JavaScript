# glidercli

> 标签: automation, autonomous, browser, cdp, chrome, cli, devtools, loop, ralph-wiggum, websocket

## 简介

Browser automation CLI. Control a configured Chromium browser through an extension CDP relay, run YAML tasks, and execute bounded autonomous loops.
