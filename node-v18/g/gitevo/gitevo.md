# gitevo

> 标签: branching, checkpoint, claude-code, claude-code-plugin, evolution, git, lessons-learned, mcp

## 简介

Evolutionary git branching for LLM agents — checkpoint, spawn, learn, abandon, adopt, finish. Ported from Python GitEvoMCP to TypeScript.
