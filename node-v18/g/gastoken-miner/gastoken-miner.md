# gastoken-miner

> 标签: blockchain, cryptocurrency, erc20, erc223, etc, eth, ethereum, gas, gastoken, saturn, token

## 简介

GasToken is an ERC20 token on Ethereum and Ethereum Classic blockchains. This package is the miner for this token.
