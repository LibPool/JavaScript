# gitbook-plugin-copyright

> 标签: copyright, gitbook-plugin, gitbook-plugin-copyright, website, wechat

## 简介

基于Gitbook实现的版权保护插件,用于复制内容时追加版本信息以及文章末尾添加版权小尾巴
