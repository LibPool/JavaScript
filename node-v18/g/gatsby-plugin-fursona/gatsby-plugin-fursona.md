# gatsby-plugin-fursona

> 标签: furry, fursona, gatsby, gatsby-plugin, gatsby-plugin-fursona

## 简介

Easily generate and manage well-known fursona schema files and images for your static sites with this Gatsby plugin. Ideal for creating standardized, accessible fursona landing pages using modern frontend frameworks.
