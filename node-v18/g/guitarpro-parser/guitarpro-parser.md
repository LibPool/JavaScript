# guitarpro-parser

> 标签: gp3, gp5, gp7, gpx, guitar, guitar-pro, music, parser, tab, tablature

## 简介

Pure JavaScript parser for Guitar Pro files (.gp, .gpx, .gp5, .gp3). Zero native dependencies, works in browser and Node.js.
