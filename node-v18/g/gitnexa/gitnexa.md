# gitnexa

> 标签: ai, cli, commit, conventional-commits, gemini, git, gitnexa, openrouter

## 简介

AI-powered Git CLI assistant that analyzes staged changes, generates Conventional Commit messages, validates and scores them, and creates commits with your confirmation.
