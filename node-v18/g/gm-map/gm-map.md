# gm-map

> 标签: gm-map, react-component

## 简介

gm-map组件是基于饿了么开发的react-amap组件的再封装，使用高德地图的API，具体功能有 1. 搜索栏输入相关关键字出现tips列表，点击某一项确定位置 2. 拖动地图确定位置，在搜索栏出现相应的地址信息
