# gerdur

> 标签: cli, deezer, deezer-downloader, flac, id3, isrc, lrc, lyrics, metadata, mp3, music-downloader, spotify, tidal

## 简介

Command-line music downloader for Deezer (Spotify/Tidal links resolved via ISRC matching) with automatic MP3/FLAC tagging, synced lyrics and a side-effect-free programmatic API.
