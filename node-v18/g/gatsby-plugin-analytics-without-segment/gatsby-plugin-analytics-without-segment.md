# gatsby-plugin-analytics-without-segment

> 标签: analytics, analytics.js, analyticsjs, free, gatsby, gatsby-plugin, segment, standalone, without

## 简介

A Gatsby plugin to use Segments open-source analytics library (analytics.js) WITHOUT using the paid Segment service (segment.com)
