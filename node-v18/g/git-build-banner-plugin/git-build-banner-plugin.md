# git-build-banner-plugin

> 标签: banner, build-info, console, debug, git, plugin, version, vite, webpack

## 简介

自动在打包产物中注入项目名、Git 分支、提交哈希、打包时间，浏览器控制台一键查看 — 支持 Webpack & Vite
