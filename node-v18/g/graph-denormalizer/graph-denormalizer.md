# graph-denormalizer

> 标签: denormalize, graph, habtm, has_and_belongs_to_many

## 简介

denormalize a graph (handles has_and_belongs_to_many relationships, which normalizr/denormalizr (https://github.com/paularmstrong/normalizr) doesn't)
