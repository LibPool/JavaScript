# @graficos/nuxt-comments

> 标签: better-auth, cloudflare, comments, d1, nuxt, nuxt-module

## 简介

Embeddable, unstyled comments system for Nuxt 4, backed by Cloudflare D1 and authenticated via @nuxtjs/better-auth.
