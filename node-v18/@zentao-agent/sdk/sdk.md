# @zentao-agent/sdk

> 标签: api-client, sdk, zentao, 禅道

## 简介

TypeScript SDK for ZenTao 20.x — HTTP client with token auto-refresh, composite operations, plus credentials/keychain helpers shared by @zentao-agent/cli.
