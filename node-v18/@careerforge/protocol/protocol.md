# @careerforge/protocol

> 标签: capabilities, careerforge, json-rpc, plugin, protocol

## 简介

CareerForge plugin protocol types — JSON-RPC over stdio, capability manifests, evidence drafts. Zero dependencies, published for plugin authors in any language. UNSTABLE until 1.0: this package will change without a major version bump.
