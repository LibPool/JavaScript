# @zephora/tailwind-preset

> 标签: design-tokens, preset, tailwind, zephora

## 简介

Tailwind CSS preset generated from Zephora UI design tokens (zephoraPreset) — colors, spacing, radius, typography, shadows, motion and z-index.
