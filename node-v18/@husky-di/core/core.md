# @husky-di/core

> 标签: JavaScript

## 简介

`@husky-di/core` is the foundation of husky-di. It handles the core runtime responsibilities: registering services, resolving services, managing lifecycles, and keeping the whole resolution flow predictable, testable, and inspectable.
