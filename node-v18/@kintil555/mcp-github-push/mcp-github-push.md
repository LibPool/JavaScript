# @kintil555/mcp-github-push

> 标签: claude, cli, git, github, mcp, model-context-protocol, push

## 简介

MCP server yang menyimpan GitHub PAT secara lokal dan melakukan git clone/commit/push sungguhan di komputer kamu — Claude cukup kirim diff/patch lewat tool call, bukan isi file utuh, dan token tidak pernah lewat chat.
