# @lumjs/typdef

> 标签: JavaScript

## 简介

TypDef is a cousin to the Enum system from [@lumjs/core]. It can do pretty much everything that Enum can, but TypDef items can contain properties, methods, and generally are just a lot more flexible than Enum values.
