# @to-skills/mcp

> 标签: agent-skills, ai, mcp, model-context-protocol, skill-generation, skill-md, to-skills, typescript

## 简介

Extract and bundle MCP servers as Agent Skills — introspects live MCP servers (stdio or HTTP) and produces SKILL.md consumable by MCP-native agents (via mcp: frontmatter) or non-MCP agents (via CLI-as-proxy adapters)
