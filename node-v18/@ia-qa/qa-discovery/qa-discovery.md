# @ia-qa/qa-discovery

> 标签: crawler, mcp, model-context-protocol, playwright, qa, test-discovery, testing

## 简介

Deterministic surface reconnaissance for an unknown web app — crawl, capture, diff. No LLM, no hosting: runs entirely on your machine, with a local MCP server for agents.
