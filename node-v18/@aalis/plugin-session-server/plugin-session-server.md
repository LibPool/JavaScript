# @aalis/plugin-session-server

> 标签: aalis, aalis-plugin

## 简介

会话服务：会话协议的服务端（会话列表与增量、会话的增删改与配置、已读、订阅与条目、历史、回合控制）与审批服务（在场、排队、应答核验、结算、审计）
