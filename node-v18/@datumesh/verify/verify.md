# @datumesh/verify

> 标签: canonical-json, datumesh, ed25519, jcs, receipt, rfc8785, verify

## 简介

Verifier for Datumesh receipts: strict canonical JSON (RFC 8785), cell URIs, units, blobs, response envelopes, key documents and Ed25519 signatures.
