# @brutesoftware/loocat

> 标签: apm, error-monitoring, logging, loocat, observability, sdk, telemetry, tracing

## 简介

The Loocat SDK — captures every error (and soon logs & traces) and ties each event to a tenant/account, so failures can be crossed with revenue.
