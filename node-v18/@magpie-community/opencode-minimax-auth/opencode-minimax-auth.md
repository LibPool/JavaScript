# @magpie-community/opencode-minimax-auth

> 标签: mcode, minimax, minimax-code, opencode, opencode-plugin

## 简介

OpenCode provider plugins for MiniMax Code accounts: their credits and M Plan, China (minimax-code) and international (minimax-code-global), with MiniMax Code's own device sign-in
