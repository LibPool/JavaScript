# @tabdotbar/agent-sdk

> 标签: agents, ai, eip-7702, erc-8004, gasless, mcp, model-context-protocol, payments, smart-pay, stablecoin, tab, x402

## 简介

Tab payment rail for autonomous agents. Smart Pay (one $X call, any asset/chain, EVM + Solana), unified Bridge (any asset to any asset across chains), Solana Smart Pay via Subscriptions Delegation Program, gasless tipping (EIP-7702 + Solana fee-payer), x4
