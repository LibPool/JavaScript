# repairworth-mcp

> 标签: auto-repair, car-maintenance, car-repair, claude, consumer-law, mcp, model-context-protocol, open-data, repair-estimate, repair-quote, towing

## 简介

MCP server that checks the arithmetic of a US auto repair quote (total against itemized lines, two quotes side by side, towing, maintenance reserve) and looks up state auto repair estimate laws. It holds no market price.
