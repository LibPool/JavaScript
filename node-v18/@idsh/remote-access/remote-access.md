# @idsh/remote-access

> 标签: bundle, cordis, deepseek-harness, dsh, heartbeat, lan, remote, websocket

## 简介

Reach a dsh Web profile from another machine: bind every interface and keep the UI's Remote-mux WebSocket alive across a flaky or proxied link
