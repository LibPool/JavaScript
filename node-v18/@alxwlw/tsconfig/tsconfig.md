# @alxwlw/tsconfig

> 标签: JavaScript

## 简介

TypeScript 7 `tsconfig` presets for the canon. Each preset is a plain `.json` file — extend it by package specifier (published consumers) or by path (this repo, which extends its own presets directly from `packages/tsconfig/`).
