# @machinat/dialogflow

> 标签: JavaScript

## 简介

This module implement the [`IntentRecognizer`](https://machinat.com/api/modules/core_base_intentrecognizer.html) interface with [DialogFlow ES](https://cloud.google.com/dialogflow/es/docs) API.
