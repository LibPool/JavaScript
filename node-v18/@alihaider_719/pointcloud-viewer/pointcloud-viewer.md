# @alihaider_719/pointcloud-viewer

> 标签: 3d, las, laz, lidar, point-cloud, potree, viewer, webgl, webgpu

## 简介

Standalone, embeddable 3D point cloud viewer built on Potree 2.x. WebGPU + WebGL fallback, zero external dependencies, configurable API, theming via CSS variables.
