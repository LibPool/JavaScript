# @orpc-ws/cookie-bff-nestjs

> 标签: JavaScript

## 简介

NestJS adapter for @orpc-ws/cookie-bff. Wires the cookie verifier into OrpcWsModule internally (the consumer configures cookie-BFF once) and hosts the /auth/* controller.
