# @spintax/slots-lite

> 标签: casino, generative, generative-art, hero-background, illustration, line-art, palette, procedural, reels, slot-machine, slots, ssr, static-site, svg, vanilla-js, zero-dependencies

## 简介

A procedural slot machine as an SVG string. Seeded reels and cabinet, brand-aware classic palette, line or flat, classic and procedural symbols, an optional CSS spin. Zero dependencies; runs in Node at build time and in the browser.
