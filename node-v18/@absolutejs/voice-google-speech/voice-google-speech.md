# @absolutejs/voice-google-speech

> 标签: JavaScript

## 简介

Google Cloud Speech-to-Text adapter for @absolutejs/voice — buffered-batch (REST) + real-time streaming (gRPC-Web over HTTP/2, no @grpc/grpc-js dep)
