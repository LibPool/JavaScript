# @wix/site-service-site-info

> 标签: JavaScript

## 简介

Information about the site that is being rendered: its display name, its revision and its site ID. The host (Thunderbolt) supplies the values and updates them when the editor renames the site, the site gets a new revision, or an unsaved site gets its site
