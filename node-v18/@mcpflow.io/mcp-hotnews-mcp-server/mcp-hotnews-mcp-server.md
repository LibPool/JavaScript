# @mcpflow.io/mcp-hotnews-mcp-server

> 标签: bilibili, chinese-social-media, hot-news, mcp, mcpflow, trending, weibo, zhihu

## 简介

HotNews MCP Server是一个基于 Model Context Protocol (MCP) 的实时热点话题聚合服务，可以为 AI 助手提供来自中国主要社交平台和新闻网站的热点话题。支持知乎热榜、36氪热榜、百度热点、B站热榜、微博热搜、抖音热点、虎扑热榜、豆瓣热榜、IT新闻等9个主要中文平台的热点话题，提供带热度指数的可点击链接，方便 AI 模型获取最新热点资讯。
