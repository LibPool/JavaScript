# @mcpflow.io/mcp--notepad-server-mcp-server

> 标签: mcp, mcpflow

## 简介

基于 TypeScript 实现的 MCP 协议笔记服务器，提供添加、删除和更新笔记的功能，并支持与 Claude Desktop 的集成。
