# @hyperfixi/realtime

> 标签: _hyperscript, eventsource, hyperfixi, hyperscript, plugin, realtime, sse, websocket, worker

## 简介

Realtime features for hyperfixi — adds `socket`, `eventsource`, and `worker` top-level features (upstream _hyperscript 0.9.93 extensions; worker is an async main-thread shim).
