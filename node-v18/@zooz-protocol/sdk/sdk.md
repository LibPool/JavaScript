# @zooz-protocol/sdk

> 标签: coalichain, nft, polkadot, proof-of-trust, substrate, tokens, voting, zooz

## 简介

TypeScript SDK for Coalichain (ZOOZ Protocol): read votes, trusts and decisions, verify vote proofs, create tokens and NFTs, connect browser wallets.
