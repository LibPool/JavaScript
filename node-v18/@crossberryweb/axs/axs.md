# @crossberryweb/axs

> 标签: agent, axs, cli, localhost, noxs, plugin-manager, react, web-ui

## 简介

AXS - Noxs Agent web UI. Run npx @crossberryweb/axs and a React control center with /pkg npm dashboard for the Noxs agent opens at localhost (Noxs floating browser on device, system browser elsewhere). Any OS shell: Windows, macOS, Linux.
