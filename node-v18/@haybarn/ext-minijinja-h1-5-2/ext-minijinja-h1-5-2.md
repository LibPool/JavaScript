# @haybarn/ext-minijinja-h1-5-2

> 标签: duckdb, extension, haybarn, minijinja

## 简介

Adds templating to DuckDB, enabling dynamic generation of text, HTML, and reports directly within SQL queries using the MiniJinja engine.
