# @haybarn/ext-laterite_ags4-h1-5-6

> 标签: duckdb, extension, haybarn, laterite_ags4

## 简介

Read AGS4 geotechnical data files as typed, UUID-keyed tables directly from SQL — born-typed columns, deterministic content-addressed keys that join across groups by construction, and an embedded AGS dictionary. A read-only SQL surface. Local, http(s)://
