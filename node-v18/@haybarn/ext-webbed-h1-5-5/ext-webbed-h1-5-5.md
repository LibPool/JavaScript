# @haybarn/ext-webbed-h1-5-5

> 标签: duckdb, extension, haybarn, webbed

## 简介

Comprehensive processing extension for web markup languages (XML and HTML) with SAX streaming for large files, intelligent schema inference, XPath-based data extraction, and HTML table parsing.
