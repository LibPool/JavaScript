# @haybarn/ext-read_lines-h1-5-5

> 标签: duckdb, extension, haybarn, read_lines

## 简介

Read line-based text files with line numbers and efficient subset extraction. Supports glob patterns, line selection with context, and GitHub-style '#L12-24' fragments so a line range can be attached to any path, including URIs served by other extensions.
