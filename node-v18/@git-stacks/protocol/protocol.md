# @git-stacks/protocol

> 标签: JavaScript

## 简介

Transport-neutral schemas and wire types for git-stacks clients and services, including the versioned `git-stacks/2` binary frame, canonical control encoding, scopes, handshake contracts, sequence fields, and allocation limits. This package has no Node.js
