# @islamz/site-engine

> 标签: JavaScript

## 简介

Headless site engine — SSR backend (SQLite + auth + content API + uploads) and a schema-driven admin dashboard, as a Nuxt layer. Consumers extend it and provide their own front-end + content schemas.
