# @vdatacloud/cms-components

> 标签: JavaScript

## 简介

Embeddable web components for drafting and sharing escrow agreements (daml-escrow-cms, PLAN.md 81.4 T10): light-DOM custom elements styled by @vdatacloud/cx-commons tokens, in the page's language (en/fr), talking only to the CMS API (/api/v1/cms).
