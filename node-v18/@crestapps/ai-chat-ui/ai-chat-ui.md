# @crestapps/ai-chat-ui

> 标签: ai, chart.js, chat, chat-ui, chatbot, crestapps, css, signalr, streaming, vue

## 简介

Browser-ready JavaScript widgets and CSS for CrestApps AI chat sessions and chat interactions. Supports streaming responses, image generation, Chart.js interactive charts, document uploads, copy-to-clipboard, and feedback buttons.
