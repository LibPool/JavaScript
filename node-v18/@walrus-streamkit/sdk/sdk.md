# @walrus-streamkit/sdk

> 标签: blob-storage, hls, mysten, sdk, seal, streaming, sui, video, vod, walrus, web3

## 简介

Backend SDK for non-custodial video infrastructure on Walrus (blob storage) and Sui (ownership, payments, access). Upload, encrypt, publish, and resolve playback for VOD and pseudo-live. Built-in multi-URL relayer failover, signed webhook verification, on
