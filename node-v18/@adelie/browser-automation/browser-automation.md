# @adelie/browser-automation

> 标签: JavaScript

## 简介

Drive the Adelie desktop app's built-in browser with penguin browser — read pages as simplified HTML or text, act with JavaScript and trusted clicks and typing, extract structured data, and import sign-ins from the system browser.
