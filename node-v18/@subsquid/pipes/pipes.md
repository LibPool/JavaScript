# @subsquid/pipes

> 标签: bigquery, bitcoin, blockchain, blockchain-indexer, clickhouse, data-pipeline, ethereum, etl, evm, google-cloud, hyperliquid, indexer, parquet, postgresql, pubsub, realtime, solana, streaming, subsquid, tron, typescript, web3

## 简介

TypeScript SDK for streaming blockchain data: tap SQD Portal sources, decode EVM/Solana/Bitcoin/Tron/Hyperliquid onchain data, handle reorgs, write to Postgres, ClickHouse, BigQuery, Parquet, or Google PubSub.
