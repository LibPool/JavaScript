# @falcongames/game-client-sdk

> 标签: ads, bridge, falcon, game, iap, webview

## 简介

Falcon Game Client SDK: shell-app bridge, ads, IAP/shop logic, remove-ads, lives, review, analytics, user data for Falcon web games. Plain JS, no dependencies. Logic only: no UI is included.
