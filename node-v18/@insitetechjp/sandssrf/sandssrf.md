# @insitetechjp/sandssrf

> 标签: dns-rebinding, network-namespace, sandbox, security, ssrf

## 简介

SSRF containment for Node.js: user-supplied URLs run against a simulated internal network in a Linux namespace, while public traffic is unaffected.
