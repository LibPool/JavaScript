# @mikefreno/pi-image-paths

> 标签: drag-and-drop, images, pi-extension, pi-package, screenshot, tui

## 简介

Image file paths in pi's chat input become attached images — the path collapses to a marker as you type, and the picture is drawn below the sent message.
