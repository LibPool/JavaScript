# im-connector

> 标签: agent, connector, dingtalk, discord, dws, feishu, im, mcp, mcp-server, modelcontextprotocol, wecom, wecom-cli

## 简介

MCP server that lets agents drive DingTalk (dws) and WeCom (wecom-cli) CLIs: send messages, write reports, create todos, query calendars and approvals. Extensible provider registry for more IM platforms.
