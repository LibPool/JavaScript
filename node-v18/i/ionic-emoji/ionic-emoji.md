# ionic-emoji

> 标签: JavaScript

## 简介

ionic-emoji es una librería que permite mostrar emojis en aplicaciones  creadas con el framework Ionic/Angular. Aunque puede ser utilizada en aplicaciones móviles, tiene mas sentido hacerlo en aplicaciones web, donde el selector de emojis no es tan accesi
