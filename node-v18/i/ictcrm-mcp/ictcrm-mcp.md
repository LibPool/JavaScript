# ictcrm-mcp

> 标签: ai-agent, claude, contacts, crm, ictcontact, ictcrm, mcp, model-context-protocol, telephony

## 简介

Model Context Protocol server for ICTCRM (ICTContact backend). Read contact groups and, with writes enabled, create and delete contacts and add them to campaigns.
