# import-atlas

> 标签: architecture, circular-dependencies, cli, dead-code, dependency-graph, dependency-tree, import-graph, javascript, static-analysis, typescript, visualization

## 简介

Scan a JS/TS project's local import graph from one or more entry files and render it as an interactive dependency tree or graph.
