# insight-lux-ui

> 标签: blockchain, blockexplorer, front-end, insight, luxcoin, luxcore

## 简介

An open-source frontend for the Insight API. The Insight API provides you with a convenient, powerful and simple way to query and broadcast data on the luxcoin network and build your own services with it.
