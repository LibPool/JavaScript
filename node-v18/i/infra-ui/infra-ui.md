# infra-ui

> 标签: JavaScript

## 简介

- 此仓库会将有关联的包放到一起管理，优势如下   1. 不用额外启动别的仓库，   2. 统一管理，这里暂时统一版本   3. 但是仓库体积会很大，目前只会放基础组件，业务组件和cli三个子仓库 - lerna 基本操作   lerna add
