# iana-registry-data-lib

> 标签: conformance, iana, iana dataset, iana registries, iana registry, iana-registry, ietf, internet assigned numbers authority, jose, jwt, machine-readable, metadata, oauth, registry, rfc, security tokens, spec registry, standards

## 简介

Machine-readable snapshots of IANA registries (JOSE, OAuth, JWT, etc.) refreshed by the iana-registry-data-importer for specs, security tooling, and compliance pipelines.
