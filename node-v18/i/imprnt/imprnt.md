# imprnt

> 标签: agent-context, cli, deterministic, knowledge-base, markdown, second-brain

## 简介

Deterministic-first, plain-markdown knowledge vault. Code does the bulk transform. The LLM only touches the irreducibly-semantic 20%. Native grep plus BM25 retrieval, zero MCP on the vault.
