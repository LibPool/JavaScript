# io.extendreality.tilia.locomotors.teleporttargets.unity

> 标签: area, destination, location, locomotion, locomotor, point, teleport, teleporting

## 简介

A collection of prefabs that provide a specific point or area location to specify a valid teleport location for the Unity software.
