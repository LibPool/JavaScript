# inkfold

> 标签: agent, ai, chat, components, design-tokens, react, tailwind, ui

## 简介

Crafted React primitives for AI-native interfaces — chat, thinking states, approvals, tables — plus the app shell components to go with them. Built on the beautifului.dev design tokens.
