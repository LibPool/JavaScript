# iso3166-lookup

> 标签: ISO 3166, ISO 3166-1, alpha-2, alpha-3, country code lookup, country codes, country numeric codes, num-3

## 简介

ISO 3166-1:2020 country and codes lookup. The supported country code types are alpha-2, alpha-3 and num-3.
