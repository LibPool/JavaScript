# i2c-eeproms

> 标签: AT24C01, AT24C02, AT24C04, AT24C08, AT24C128, AT24C128C, AT24C16, AT24C256, AT24C256C, AT24C32, AT24C512, AT24C512C, AT24C64, K24C256C, eeprom, i2c, raspberry pi
