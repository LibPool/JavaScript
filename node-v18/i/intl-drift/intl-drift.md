# intl-drift

> 标签: DateTimeFormat, NumberFormat, ci, cldr, drift, formatting, golden-file, i18n, icu, internationalization, intl, locale, snapshot, snapshot-testing

## 简介

Golden-file drift detection for Intl/ICU/CLDR output. Catch silent formatting changes across Node upgrades and between your server and your users' browsers.
