# ipfs-pay-to-pin-client

> 标签: ai-agent, algorand, base, ethereum, ipfs, micropayments, multi-chain, pay-to-pin, pinata, solana, usdc, x402

## 简介

TypeScript client library for pinning files to IPFS via x402 microUSDC micropayments across Base L2, Solana, Algorand, and Ethereum L1.
