# indexador-checkout

> 标签: checkout, google-tag-manager, hotmart, kiwify, sck, xcod

## 简介

Script do modelo de tag web do GTM "Indexador de Checkout": leva o identificador de indexação do visitante ao parâmetro de cada plataforma de checkout (Hotmart xcod, Kiwify sck) e registra o redirect na camada de dados.
