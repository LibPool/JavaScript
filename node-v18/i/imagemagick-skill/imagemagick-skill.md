# imagemagick-skill

> 标签: agent, agent-skill, claude-code, codex, cursor, image, image-processing, imagemagick, skill

## 简介

Agent Skill that gives coding agents (Claude Code, Cursor, Codex) a local ImageMagick image editor that never overwrites originals: probe, convert, resize, thumbnail, EXIF/GPS strip, trim, check. Formerly image-skill.
