# imk-cli-currency-converter

> 标签: JavaScript

## 简介

A simple CLI based currency converter Project made with Typescript, Node.js and Inquirer. This project is developed by Imad Ul Islam. Run This Command on Your CMD For Testing this project 'npx imk-cli-currency-converter'
