# intl-helper-cli

> 标签: JavaScript

## 简介

## 介绍 国际化多语言支持的时候，我们需要不断重复的复制粘贴替换代码，需要较大的体力成本。此工具协助开发者来减少这部分体力消耗（目前只支持 react umi 项目）。
