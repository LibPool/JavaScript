> 标签: img-limit, img-size, preview, uploadimg

## 简介

## 介绍 该模块主要针对加载图片功能，同时支持上传图片大小的判断 ## Project setup ``` npm install img-load-size --save-dev ``` ## 引用 ``` import ImgLoadSize from 'img-load-size' <ImgLoadSize /> ```
