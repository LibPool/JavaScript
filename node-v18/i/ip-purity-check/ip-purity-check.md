# ip-purity-check

> 标签: blacklist, cli, dnsbl, ip, ip-check, ip-cleanliness, ip-purity, ip-reputation, network, proxy, ptr, rbl, rdns, residential-proxy, security, spamhaus, zero-dependencies

## 简介

Score an IP's cleanliness from the command line: ~25 DNSBL blocklists plus reverse DNS, turned into a 0-100 purity score. Zero dependencies, no API key, no third-party HTTP service.
