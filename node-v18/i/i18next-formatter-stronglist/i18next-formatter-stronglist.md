# i18next-formatter-stronglist

> 标签: JavaScript

## 简介

formatter for i18next to wrap list items in <strong> tags. Usage: `{{list, stronglist}}` in template - call template with `<Trans
            t={t}
            i18nKey="keyname"
            values={{
              list: list,
            }}
          />`
