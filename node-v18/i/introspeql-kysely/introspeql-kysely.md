# introspeql-kysely

> 标签: IntrospeQL, Kysely, PostgreSQL, Postgres, TypeScript

## 简介

Powered by IntrospeQL, IntrospeQL-Kysely reads types from your Postgres database and generates a type definitions file that is compatible with Kysely
