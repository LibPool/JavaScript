# inflate-object-spread

> 标签: deep, elm, hyperapp, hyperscript, hyperx, jsx, object, react, spread, vdom, virtual dom

## 简介

Inflate objects that are written with keys as string paths: `{ 'foo.bar': 'baz' }` into `{ foo: { bar: 'baz' } }`
