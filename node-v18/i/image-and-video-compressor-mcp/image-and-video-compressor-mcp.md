# image-and-video-compressor-mcp

> 标签: ai-agent, claude, ffmpeg, image-compression, llm, mcp, mcp-server, model-context-protocol, sharp, video-compression

## 简介

MCP server for image-and-video-compressor — lets coding agents compress images and videos, probe media, and discover what the local ffmpeg and sharp builds actually support.
