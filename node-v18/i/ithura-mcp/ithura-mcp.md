# ithura-mcp

> 标签: agile, ai-agent, claude, cursor, issue-tracker, ithura, llm-tools, mcp, model-context-protocol, modelcontextprotocol, project-management, sprints, task-management

## 简介

Model Context Protocol server for Ithura, the quiet project management workspace. Gives Claude, Cursor, and other MCP clients read and write access to tasks, sprints, projects, modules, wiki pages, and intake.
