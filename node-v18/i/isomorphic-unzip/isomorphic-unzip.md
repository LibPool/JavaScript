# isomorphic-unzip

> 标签: .apk, .ipa, Browserify, Javascript, NodeJS, WebPack, manifest, parser

## 简介

Unzipping files, simple wrap for zip.js(for browser) and yauzl(for nodejs), make the apis consistent for NodeJS/Webpack/Browserify.
