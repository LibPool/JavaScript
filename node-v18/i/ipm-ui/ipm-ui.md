# ipm-ui

> 标签: ibp-intent, qrcode, skeleton, 二维码, 骨架屏

## 简介

`src/` 是本地演示应用，执行 `npm run dev` 启动。演示入口会自动加载 `components/**/*.scss`，新增组件样式无需再改 `src/main.ts`。发布到 npm 的组件源码在 `components/`，执行 `npm run build` 打包。
