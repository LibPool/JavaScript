# iop-bpmn-react

> 标签: bpmn, bpmn-js, flowable, modeler, process, react, viewer, workflow

## 简介

基于 bpmn.js 封装的 React 组件库，提供 BpmnViewer 和 BpmnModeler，支持 Flowable 扩展属性、自动布局、规则校验
