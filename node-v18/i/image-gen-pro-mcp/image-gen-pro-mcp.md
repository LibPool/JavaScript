# image-gen-pro-mcp

> 标签: ai-sdk, claude, gemini, gpt-image, image-generation, llm-tools, mcp, model-context-protocol, nano-banana, seedream, vercel-ai-gateway

## 简介

Image generation as an MCP tool. GPT Image 2, Gemini 3 Pro Image, or Seedream 4.5 behind one call; reference images and context supported; returns file paths, not megabytes of base64.
