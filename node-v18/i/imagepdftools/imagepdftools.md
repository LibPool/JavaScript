# imagepdftools

> 标签: browser, client-side, compress, compression, image, imagepdf, jpeg, libwebp, mozjpeg, png, svg, wasm, webp

## 简介

Browser-side image compression (JPEG, WebP, PNG, SVG) powered by MozJPEG, libwebp, UPNG.js. All processing runs client-side, no uploads. Extracted from imagepdf.tools.

## 官网

- 官网：https://imagepdf.tools
- 源码仓库：git+https://github.com/imagepdftools/imagepdftools.git
- npm 页面：https://www.npmjs.com/package/imagepdftools
