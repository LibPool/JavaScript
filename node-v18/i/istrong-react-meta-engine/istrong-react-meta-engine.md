# istrong-react-meta-engine

> 标签: antd, flux, immutable, istrong, istrong-js, react, react-redux, reactjs, redux

## 简介

元数据化引擎，在istrong-react-app-loader实现的应用隔离基础上，实现可以用json元数据描述界面模型，并提供了action、reducer的基础函数和monkeyKing组件.
