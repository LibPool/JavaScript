> 标签: 3-way-merge, ai-agents, ast, code-generation, conflict-resolution, diff3, git-merge-driver, merge, multi-agent, rename-detection, semantic-merge, structural-merge

## 简介

ICR — Intent-aware Code Replication: a 3-way merge that understands code structure and author intent. Structural merging, rename detection across call sites, semantic-conflict detection, parse-guaranteed output. Drop-in git merge driver. Built for AI-agen
