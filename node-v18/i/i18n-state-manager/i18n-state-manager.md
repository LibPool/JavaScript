# i18n-state-manager

> 标签: angular, git-native, i18n, internationalization, l10n, localization, react, stale-detection, state-management, translation, translations, typescript, vue

## 简介

Git-native translation management with intelligent stale detection. Hash-based state tracking ensures your translations stay synchronized with your code.
