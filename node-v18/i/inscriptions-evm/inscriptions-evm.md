# inscriptions-evm

> 标签: JavaScript

## 简介

本脚本批量生成钱包、批量打印地址以及批量打印私钥的规则与metamask完全相同，你可以将助记词导入到metamask并创建多个账户，顺序与脚本生成的完全一致。
