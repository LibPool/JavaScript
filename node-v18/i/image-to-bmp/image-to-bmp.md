# image-to-bmp

> 标签: JavaScript

## 简介

Convert image to 1 bit depth BMP. File formats `.jpg`, `.png`, `.bmp`, `.tiff`, and `.gif`. Thanks to the [Jimp](https://www.npmjs.com/package/jimp) library.
