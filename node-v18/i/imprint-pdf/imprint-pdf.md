# imprint-pdf

> 标签: chinese, document, latex, markdown, pdf, print, publisher, typography, weasyprint

## 简介

AI-native, print-grade Chinese PDF generator. Markdown in, publisher-quality PDF out, with a 0-100 print-quality report. One command: npx imprint-pdf.
