# insomnia-plugin-aws-profile-creds

> 标签: aws, creds, iam, insomnia, profile

## 简介

It can be a pain to copy paste AWS credentials in the Insomnia app if you're using more than one profile. This plugin tries to make the process easier. This plugin reads your credentials present in the `~/.aws/credentials` file and returns them back to In
