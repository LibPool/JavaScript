# input-promptify

> 标签: ES6, PromptGrouping, character-hider, clie, javascript, nodejs, prompt, selection, selection-prompt, utility

## 简介

A simple Non blocking Node.js input prompting utility for accepting user input with a Basic text input and selection(list) based format's.
