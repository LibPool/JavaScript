# intempt-nodejs-source

> 标签: Analytics, Intempt, SDK, Tracker, Tracking, intempt, nodejs

## 简介

Node JS SDK is stateless and will only send the data that you populate, whereas our mobile SDKs will automatically collect app and device information, session events, install events, and maintain persistence
