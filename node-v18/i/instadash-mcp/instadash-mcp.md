# instadash-mcp

> 标签: adapter, agents, data, grid, instadash, mcp

## 简介

Stdio adapter for the hosted Instadash MCP server at https://mcp.instadash.io/. Use this only if your MCP client doesn't support remote OAuth servers.

## 官网

- 官网：https://instadash.io
- 源码仓库：git+https://github.com/instadashio/instadash.git
- npm 页面：https://www.npmjs.com/package/instadash-mcp
