# insight-ui-alarmx

> 标签: alarmx, alarmxcore, bitcore-alarmx, blockchain, blockexplorer, front-end, insight

## 简介

An open-source frontend for the Insight API. The Insight API provides you with a convenient, powerful and simple way to query and broadcast data on the Alarmx network and build your own services with it.
