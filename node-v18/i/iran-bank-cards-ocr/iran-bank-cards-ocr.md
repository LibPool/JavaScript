# iran-bank-cards-ocr

> 标签: bank, bank-detection, card, iran, luhn, ocr, tesseract, typescript, validation

## 简介

A TypeScript library to detect Iranian bank names, logos, and validate card numbers using OCR and Luhn algorithm.
