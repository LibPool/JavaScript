# ifc-sharepoint

> 标签: aec, bim, cde, ifc, iso-19650, microsoft-365, openbim, sharepoint

## 简介

Work with IFC building models stored in Microsoft SharePoint: read IFC files and BIM metadata from SharePoint document libraries. Part of the Flinker OpenBIM toolchain.
