# image-optimalisator

> 标签: JavaScript

## 简介

ImageOptimalisator is een npm package die afbeeldingen optimaliseert voor betere laadtijden en prestaties op uw website. Het ondersteunt nu .jpg, .png, .gif en .svg bestanden.

## 官网

- npm 页面：https://www.npmjs.com/package/image-optimalisator

## 历史版本号

- 当前版本：1.0.0

- 1.0.0

## 获取地址

- npm 安装：`npm install image-optimalisator`
- npm registry：https://registry.npmjs.org/image-optimalisator
