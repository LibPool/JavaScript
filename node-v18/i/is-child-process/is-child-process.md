# is-child-process

> 标签: check, child, child-process, cp, emitter, event, events, exec, node, nodejs, process, spawn, stream, util, utility, utils, validate

## 简介

Checks whether a value is child process result, which in case is more specific Node.js EventEmitter. Browserify-ready.
