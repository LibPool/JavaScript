# insight-ui-iop-testnet

> 标签: Internet of People, IoP, blockchain, blockexplorer, front-end, insight, iopcore

## 简介

An open-source frontend for the Insight API. The Insight API provides you with a convenient, powerful and simple way to query and broadcast data on the IoP network and build your own services with it.
