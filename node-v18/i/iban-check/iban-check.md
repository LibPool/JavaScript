# iban-check

> 标签: banking, bban, finance, iban, iban checker, iban checksum, iban parser, iban validation, iban validator, iso 13616, javascript, mod97, typescript

## 简介

Validate and parse IBANs in JavaScript and TypeScript. Checks the MOD-97 checksum, country length and BBAN structure using the SWIFT IBAN Registry. No dependencies; works offline in Node.js and browsers.
