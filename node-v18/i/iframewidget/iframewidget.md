# iframewidget

> 标签: Telegrambot, bot, fronted, iframewidget, nextjs, react, support bot, telechatbot, widget, widgets

## 简介

A npm widget package to create a widget in react and nextjs app. 
 By using this package you implement a Telegram connected chat bot and you create your own bot and show in widget.
