# is-absolute

> 标签: absolute, built, built-in, check, core, detect, dir, file, filepath, is, is-absolute, isabsolute, normalize, path, path-absolute, path-is-absolute, paths, polyfill, relative, resolve, shim, slash, slashes, uri, url, util, utils

## 简介

Returns true if a file path is absolute. Does not rely on the path module and can be used as a polyfill for node.js native `path.isAbolute`.
