# il2cppdump-mermaid

> 标签: diagram, il2cpp, mermaid, reverse-engineering

## 简介

A small script to generate mermaid code from [Il2CppInspector](https://github.com/djkaty/Il2CppInspector) generated code that help you understand the relations
