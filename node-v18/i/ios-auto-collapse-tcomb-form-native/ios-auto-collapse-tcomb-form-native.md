# ios-auto-collapse-tcomb-form-native

> 标签: form, forms, react, react-component, react-native, tcomb

## 简介

This lib is based on tcomb-form-native(https://github.com/gcanti/tcomb-form-native). But it has a few differences - auto-collapsing for ios selects and ability to pass extraData
