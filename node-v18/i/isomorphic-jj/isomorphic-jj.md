# isomorphic-jj

> 标签: browser, change-tracking, git, isomorphic, jj, jujutsu, nodejs, revsets, undo, version-control

## 简介

Jujutsu (jj) version control semantics in pure JavaScript — stable change IDs, fearless undo, no staging area — for Node.js and browsers
