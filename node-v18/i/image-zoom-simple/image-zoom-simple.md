# image-zoom-simple

> 标签: component, image, image zoom, svelte, zoom, zoom image

## 简介

The Svelte Image Zoom Plugin is a lightweight and customizable plugin that provides zoom functionality for images in Svelte applications. It allows users to hover over an image and view a zoomed-in version in a separate box, enhancing the user experience
