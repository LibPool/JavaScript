# iota-ts-fetch

> 标签: JavaScript

## 简介

一个基于 **axios** 的二次封装请求库，提供统一的 `get/post/delete/put/patch` 调用方式，并内置**请求队列**能力（可按 key 中断单个请求或中断全部请求）。支持自定义 axios 默认配置、请求/响应拦截器，以及可选的 loading 显示/隐藏钩子。
