# inclusive-ui

> 标签: JavaScript

## 简介

InclusiveUI — это библиотека инклюзивных и доступных React-компонентов, созданная с упором на качество, производительность и соблюдение лучших практик веб-разработки. Компоненты разработаны с учетом принципов доступности, обеспечивая поддержку ARIA-меток,
