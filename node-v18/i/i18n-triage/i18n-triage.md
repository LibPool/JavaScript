# i18n-triage

> 标签: ast, chinese, hardcoded-strings, i18n, localization, sarif, typescript, vue

## 简介

Find the hard-coded Chinese UI strings in a Vue / TypeScript codebase that actually need translating. AST-based triage into UI text / debug logs / dictionaries / internal keys, with text, JSON and SARIF output.
