# isard

> 标签: 3d-tiles, accessibility, flood, geoplateforme, map, network, openstreetmap, vector-tiles, webassembly, webgl2

## 简介

A WebGL2 map engine for large, interactive data layers, labels and 3D Tiles over raster or vector basemaps (Rust core in WebAssembly)
