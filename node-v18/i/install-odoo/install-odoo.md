# install-odoo

> 标签: CLI, install-odoo, odoo

## 简介

A simple and powerful CLI tool to automate the installation of Odoo. Supports multiple Odoo versions, and customizable configurations. Designed for developers, testers, and system integrators to get Odoo up and running in minutes.
