# @hmans/r3f-create-loader

> 标签: JavaScript

## 简介

`createLoader` creates a loader hook for a resource served through HTTP, and will automatically queue it for preloading. This allows you to create bundles of assets that are preloaded in one go, at the time of import, rather than at the time of first use,
