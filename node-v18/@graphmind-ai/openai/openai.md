# @graphmind-ai/openai

> 标签: agents, breakpoints, debugger, graphmind, observability, openai, tracing

## 简介

OpenAI Node SDK adapter for the GraphMind live agent debugger: wrap your OpenAI client and tools to stream execution events and honour pause / step / inject / retry / abort gates.
