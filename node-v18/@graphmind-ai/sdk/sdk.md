# @graphmind-ai/sdk

> 标签: JavaScript

## 简介

Vercel AI SDK adapter for the GraphMind live agent debugger: wrap models and tools to stream execution events and honour pause / step / inject / retry / abort gates.

- 源码仓库：git+https://github.com/Hegazy360/GraphMind.git
