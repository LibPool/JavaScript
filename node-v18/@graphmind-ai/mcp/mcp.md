# @graphmind-ai/mcp

> 标签: agents, ai, breakpoints, debugger, devtools, local-first, mcp, model-context-protocol, observability

## 简介

In-process MCP server adapter for the GraphMind live agent debugger: wrap your McpServer to stream tool / resource / prompt / sampling events and honour pause / step / inject / retry / abort gates.
