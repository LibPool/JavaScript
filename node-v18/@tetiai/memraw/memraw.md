# @tetiai/memraw

> 标签: agents, context, llm, mcp, mem0-alternative, memory, no-vectors

## 简介

Vector-free memory for AI agents. A memory is one attention-aligned context document that is always fully in the prompt — no embeddings, no retrieval. Facts are distilled, importance-scored, and evicted by importance when the budget fills.
