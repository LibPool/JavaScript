# @nickkupriyanov/slotline-core

> 标签: appointment, booking, calendar, dom, headless, meeting, scheduler, scheduling, state-machine, timeslots

## 简介

Framework-free core of the Slotline booking widget: the controller, the derived view model, the flow reducer, date and time-zone helpers, copy, class names and the booking adapter contract.
