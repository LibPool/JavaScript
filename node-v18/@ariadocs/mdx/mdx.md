# @ariadocs/mdx

> 标签: ariadocs, docs, documentation, markdown, mdx, nextjs, react

## 简介

MDX content layer for Ariadocs: parse and render MDX from files or strings, build navigation from _meta.json, extract frontmatter and table of contents. Works with React Server Components and client rendering.
