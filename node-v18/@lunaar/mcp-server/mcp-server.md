# @lunaar/mcp-server

> 标签: ai, claude, cursor, image-generation, lunaar, mcp, model-context-protocol, virtual-try-on

## 简介

Model Context Protocol server for the Lunaar Public API — exposes AI rendering, virtual try-on, 3D generation, and more as MCP tools usable from Claude Desktop, Cursor, Windsurf, and any MCP-compatible host.
