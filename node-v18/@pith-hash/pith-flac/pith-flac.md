# @pith-hash/pith-flac

> 标签: audio, decoder, flac, hashing, pcm

## 简介

FLAC decoding SDK: STREAMINFO, constant/verbatim/fixed subframes and both Rice methods via the pith-flac Rust cdylib (koffi, prebuilt)
