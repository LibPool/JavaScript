# @elvora/svelte

> 标签: accessibility, components, design-system, elvora, headless, svelte, sveltekit, ui

## 简介

Elvora UI components for Svelte 4 / Svelte 5 — same headless API as the React adapter, idiomatic Svelte stores, WCAG 2.1 AA.
