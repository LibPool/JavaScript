# @zenmux/ai-sdk-provider

> 标签: ai, llm, openai, provider, sdk, zenmux

## 简介

The **[ZenMux provider](https://zenmux.ai)** for the [AI SDK](https://ai-sdk.dev/docs) contains language model support for the ZenMux chat API.
