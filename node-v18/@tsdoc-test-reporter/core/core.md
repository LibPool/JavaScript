# @tsdoc-test-reporter/core

> 标签: JavaScript

## 简介

@tsdoc-test-reporter/core contains the main logic for parsing comment tags from a TypeScript file. It requires a TypeScript `SourceFile` and the `TSDocParser` from `@microsoft/tsdoc`.
