# @mendable/firecrawl-js

> 标签: JavaScript

## 简介

JavaScript SDK for the Firecrawl API: web scraping, crawling, web search, and scientific literature search over a research paper index of PubMed, bioRxiv, medRxiv and arXiv abstracts
