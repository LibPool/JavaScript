# @repodeckhz/web

> 标签: card, custom-element, embed, github, markdown, portfolio, repodeckhz, showcase, web-component, web-components

## 简介

GitHub repos as embeddable web cards. A Custom Element that reads a config-repodeck/ folder from any repo and renders a card with an expandable modal. Works in any stack, no framework lock-in.
