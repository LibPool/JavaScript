# @sammacbeth/libdwebify

> 标签: JavaScript

## 简介

This is a [Browserify](https://github.com/browserify/browserify) transform, which replaces some node libraries with [libdweb](https://github.com/mozilla/libdweb) polyfills. This makes your node networking stack run in Firefox!
