# @super-harness/shared

> 标签: JavaScript

## 简介

Isomorphic wire layer for Super Harness: super-line contract, the harness tree types, and the client-side Store view (subscribeTree + diffTree). No Mastra, no server deps — safe in the browser, Bun, and Node.
