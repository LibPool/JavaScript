# dsh-malleable-memory

> 标签: ai-companion, context-budget, deepseek-harness, dsh, dsh-bundle, dsh-plugin, long-term-memory, memory, mood, persona

## 简介

可塑性记忆（Malleable Memory）— DeepSeek-Harness 的三层记忆与人格插件：永久层/加强层每轮全文注入，卸载层只给目录、正文按需取回；记忆随对话演化，人格与心情随经历改变。
