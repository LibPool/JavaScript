# @egchq/egc

> 标签: agent-memory, agent-orchestration, ai-agent, aider, claude-code, codex, context-sharing, cursor, developer-tools, egc, extended-global-context, hooks, local-first, mcp, mcp-server, model-context-protocol, persistent-memory, token-optimizer, windsurf

## 简介

EGC is a local-first MCP runtime that gives every AI agent the same brain: persistent shared memory, security guardrails, and up to 90% token savings across 20 AI coding tools.
