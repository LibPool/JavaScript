# @ccos/dmu-cli

> 标签: cli, dynamic module

## 简介

动态模块产物打包工具，用于从动态模块中提取libapp.so以及资源文件并重新打包。

## 官网

- 源码仓库：http://gitlab.skysri.com/flutter/node-pkg-cli.git
- npm 页面：https://www.npmjs.com/package/@ccos/dmu-cli
