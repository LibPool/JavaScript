# @andatoshiki/yrm

> 标签: NPM, andatoshiki, cnpm, manager, pnpm, registry, yarn, yrm

## 简介

❤️ Toshiki's own NPM registry manager can help you easy and fast switch between different npm registries, now include: cnpm, taobao, nj(nodejitsu), rednpm, edunpm
