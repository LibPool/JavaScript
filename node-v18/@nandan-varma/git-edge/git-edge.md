# @nandan-varma/git-edge

> 标签: cache, edge, git, isomorphic-git, merge, serverless, three-way-merge

## 简介

High-level edge-compatible git operations — parsed-object cache, object-level three-way merge, and repo management utilities. Composes with @nandan-varma/git-fs-s3.
