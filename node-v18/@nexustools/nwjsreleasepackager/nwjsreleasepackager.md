# @nexustools/nwjsreleasepackager

> 标签: cross-platform, deb, dmg, flatpak, installer, msi, nexustools, node-webkit, nwjs, packager, zip

## 简介

Pure Node.js cross-platform NW.js release packager generating Windows (.zip, .msi), macOS (.dmg with drag-to-Applications .app), and Linux (.deb, .flatpak, .zip) releases with zero external tool dependencies
