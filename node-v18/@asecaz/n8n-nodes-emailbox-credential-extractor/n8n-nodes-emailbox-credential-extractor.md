# @asecaz/n8n-nodes-emailbox-credential-extractor

> 标签: credential, emailbox, extractor, imap, mail, n8n, n8n-community-node, pop, smtp

## 简介

Custom n8n node for extracting mailbox credentials from Custom Auth credentials. Protocol-agnostic, supports IMAP, SMTP, POP.
