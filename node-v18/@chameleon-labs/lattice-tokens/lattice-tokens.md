# @chameleon-labs/lattice-tokens

> 标签: accessibility, color, design-system, design-tokens, oklch, typography, wcag

## 简介

The token layer of Lattice, an accessibility-first design system. Colour, typography, and layout values are generated from reviewed config; contrast is measured and reported at build time, not gated.
