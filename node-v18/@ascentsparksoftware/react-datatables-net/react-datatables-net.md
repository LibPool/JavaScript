> 标签: cell-editor, data-grid, datagrid, datatables, datatables-react, datatables.net, edit-in-place, editable, grid, inline-edit, nextjs, react, react-19, react-data-grid, react-datatables, react-grid, react-table, table

## 简介

Modern React wrapper for DataTables (datatables.net) using its non-jQuery API. Typed cells, free edit-in-place, styling adapters. Next.js and React Compiler friendly.
