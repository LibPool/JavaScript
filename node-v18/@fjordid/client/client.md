# @fjordid/client

> 标签: auth, authentication, eu, fjordid, gdpr, identity, keycloak, oauth2, oidc

## 简介

Lightweight JavaScript/TypeScript client for FjordID authentication. Wraps Keycloak OIDC with a simple, developer-friendly API.
