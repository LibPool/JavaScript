# @tingyun-common/cli

> 标签: JavaScript

## 简介

Tingyun CLI是用来上传Web、小程序sourcemap文件以及HarmonyOS NEXT符号表文件的CLI工具，支持Windows, Mac, Linux操作系统。

## 官网

- 源码仓库：git@git.tingyun.com:eui-browser/tingyun-cli.git
- npm 页面：https://www.npmjs.com/package/@tingyun-common/cli
