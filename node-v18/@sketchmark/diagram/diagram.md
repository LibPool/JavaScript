# @sketchmark/diagram

> 标签: ai, animation, diagram, dsl, hand-drawn, llm, rough.js, svg, visualization

## 简介

A plain-text DSL for hand-drawn diagrams. Write boxes, edges, and groups as code — renders sketchy SVG/Canvas via rough.js with a built-in step-by-step animation system.
