# @publink-ai/cli

> 标签: cli, publink-ai, shb, shb-cli, shb-task

## 简介

售后宝 通用命令行工具，面向人类用户与 AI Agent —— 覆盖 工单、事件、客户、合同、服务商、产品、项目、标签、组织架构、备件、云仓（仓储/物料/BOM/物料替换/入库/出库）、PaaS 应用、系统日志等核心业务域，提供 270+ 命令与 20+ 个 Agent Skills
