# @dealops/doxy

> 标签: cloudflare-workers, docx, office, openxml, template, templating, word

## 简介

Fill .docx templates: replace {{tags}}, repeat table rows and paragraphs, insert images. Includes a Google Docs API compatible adapter (documents.get / batchUpdate) that edits .docx files. Runs in Node, browsers, and Cloudflare Workers.
