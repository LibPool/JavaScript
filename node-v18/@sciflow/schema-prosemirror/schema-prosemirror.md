# @sciflow/schema-prosemirror

> 标签: JavaScript

## 简介

The canonical manuscript ProseMirror schema for the [SciFlow](https://docs.sciflow.org) editor, plus the generators that derive other formats from it: JSON Schema, the snapshot schema, and a JATS 1.4 `<body>`.
