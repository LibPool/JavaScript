# @wf-financing/ui-sdk

> 标签: JavaScript

## 简介

Wayflyer provides a `@wf-financing/ui-sdk` - a client-side UI SDK to interact with the Embedded Finance API. Its primary method mounts the CTA banner and embedded application in the partner UI.
