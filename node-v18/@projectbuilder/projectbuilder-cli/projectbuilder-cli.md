# @projectbuilder/projectbuilder-cli

> 标签: JavaScript

## 简介

This is CLI application created as part of the Project Builder suite. With this application, you will be able to quickly launch and configure and API server. It will install any needed plugin dependencies. It also generates a `.env` file for your password
