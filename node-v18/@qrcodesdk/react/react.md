# @qrcodesdk/react

> 标签: code, esm, jsx, module, modules, qr, qr-code, qrcode, react, tsx, types, typescript

## 简介

@qrcodesdk/react provides React components for rendering QR codes as SVG, PNG-backed image elements, and canvas elements.
