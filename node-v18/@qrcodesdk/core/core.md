# @qrcodesdk/core

> 标签: browser, bun, code, deno, esm, module, modules, node, qr, qr-code, qrcode, types, typescript

## 简介

Runtime-neutral QR code generation for any JavaScript runtime with native ESM, ES2020, and TextEncoder. Build matrices, SVG, terminal text, or custom output.
