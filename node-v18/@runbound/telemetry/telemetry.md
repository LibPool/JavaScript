# @runbound/telemetry

> 标签: logging, metrics, nodejs, observability, opentelemetry, runbound, telemetry, tracing

## 简介

Runbound Telemetry for Node.js and the browser: metrics, application logs, operations and traces sent to the exporters you choose, with Pino, Winston, console, React and OpenTelemetry bridges.
