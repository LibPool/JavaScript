# @mdht/plugin-ts-rest-contract

> 标签: codegen, effect, standard-schema, ts-rest, zenstack, zmodel

## 简介

ZenStack v3 CLI plugin: generate a ts-rest CRUD contract (Effect Schema, via Standard Schema) from your ZModel schema.
