# @grassroot/ui-core

> 标签: JavaScript

## 简介

Framework-neutral contracts and state transitions shared by every Grassroot adapter (React, Vue, Angular). This package owns **pure logic only** — no DOM, no framework runtime, no JSX. Anything here must be importable from a plain Node script without pull
