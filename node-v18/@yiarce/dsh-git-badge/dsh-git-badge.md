# @yiarce/dsh-git-badge

> 标签: JavaScript

## 简介

DSH web 插件：左侧工作区的 Git 状态徽章。工作区和状态变化通过同源事件流推送，点击徽章直接向桌面基座发送带工作区载荷的 Wails 事件；DOM 按工作区 ID 调和挂载。
