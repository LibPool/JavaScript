# @surgesim/engine

> 标签: autoscaling, capacity-planning, discrete-event, lambda, queueing, simulation, sqs

## 简介

Surgesim engine: a discrete event simulator for cloud and distributed systems (queues, worker pools, retries, autoscaling). No DOM or Node APIs, no runtime dependencies.
