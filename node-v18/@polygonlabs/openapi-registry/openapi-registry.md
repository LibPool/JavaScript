# @polygonlabs/openapi-registry

> 标签: JavaScript

## 简介

Type-accumulating drop-in for @asteasolutions/zod-to-openapi's OpenAPIRegistry. Schemas packages compose with TypedRegistry; downstream consumers (Express, codegen, gateway aggregation) read the accumulated Ops via inferred return types.
