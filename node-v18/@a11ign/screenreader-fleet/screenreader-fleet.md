# @a11ign/screenreader-fleet

> 标签: a11y, accessibility, nvda, screen-reader, utm, vm, windows

## 简介

Host-side lifecycle, health and capacity for a fleet of Windows NVDA capture workers: lease one, judge whether it is degrading, and know how many the host can afford.
