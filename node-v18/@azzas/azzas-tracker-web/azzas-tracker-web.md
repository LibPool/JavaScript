# @azzas/azzas-tracker-web

> 标签: JavaScript

## 简介

Camada única de **data tracking** das lojas web. A loja chama `trackWebEvent`, a lib resolve os parâmetros a partir dos dados brutos da plataforma (produto, orderForm, SLAs...) e faz o push no `dataLayer` no formato esperado pelo GTM/GA4.
