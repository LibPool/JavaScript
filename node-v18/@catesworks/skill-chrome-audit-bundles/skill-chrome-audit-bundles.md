# @catesworks/skill-chrome-audit-bundles

> 标签: JavaScript

## 简介

Uses Chrome DevTools MCP to collect and sort resource timing data for a page, identifying oversized JavaScript/CSS bundles, missing cache headers, and protocol inefficiencies.
