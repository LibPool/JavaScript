# @strangecyan/iroh-darwin-arm64

> 标签: applications, distributed, iroh, network, networking, p2p, peer-to-peer, protocol

## 简介

A toolkit for building distributed applications. A fork of @number0/iroh whose incoming connections can be accepted without NAT traversal (Incoming.acceptWithoutNatTraversal).
