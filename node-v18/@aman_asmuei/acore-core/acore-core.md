# @aman_asmuei/acore-core

> 标签: acore, ai-companion, aman, ecosystem, identity, multi-tenant

## 简介

The identity layer for the aman ecosystem — multi-tenant Identity records over MarkdownFileStorage (dev) and DatabaseStorage (server), built on @aman_asmuei/aman-core.
