# @getvda/distribution

> 标签: JavaScript

## 简介

Pull-based, infrastructure-agnostic bundle distribution. Publish + activate a signed bundle (activation sealed to Witness, referencing the commit hash); agents fetch over HTTPS. Rollback = activate the previous version.
