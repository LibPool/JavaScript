# @askchannelai/telegram

> 标签: askchannel, bot, grammy, inline-mode, telegram, transcripts, youtube

## 简介

Telegram glue for AskChannel bots — parse commands, build inline-picker dropdowns, and render ready-to-send HTML for the ask + import flows. Dependency-free; built on @askchannelai/sdk.
