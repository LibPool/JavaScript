# @gege-mn/mongol-bichig

> 标签: fvs, hudum, mongol-bichig, mongolian, mvs, romanization, suffixes, unicode

## 简介

Canonical data and primitives for traditional Mongolian script (Mongol bichig) — the Hudum suffix registry, Classical romanization, and Unicode character classes. Shared by @gege-mn/gege-linter and @gege-mn/gege-converter.
