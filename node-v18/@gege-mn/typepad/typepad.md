# @gege-mn/typepad

> 标签: editor, keyboard, lint, mongol-bichig, mongolian, prosemirror, unicode, vertical-text

## 简介

Keyboard layouts, an editing model, lint helpers and editor integrations for traditional Mongolian script (Mongol bichig) — the toolkit behind the gege.mn type pad.
