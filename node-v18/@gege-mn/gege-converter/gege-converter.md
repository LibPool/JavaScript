# @gege-mn/gege-converter

> 标签: classical-mongolian, converter, cyrillic, mongol-bichig, mongolian, transliteration, unicode

## 简介

Mongolian Cyrillic → traditional Mongolian script (Mongol bichig) converter. Dictionary-and-rules engine, no third-party runtime dependencies, Unicode-correct output.
