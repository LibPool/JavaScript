# @csstokens/bridge

> 标签: JavaScript

## 简介

A capability "tokens" da cooperação csstokens, sobre o conduito — createBridge (app) / createEditorBridge (editor). Modelo de tokens + apply de tema; o transporte (handshake/RPC) é @conduito/*.
