# @sedgemark/contract

> 标签: api-contract, cms, headless-cms, sedgemark

## 简介

The public contract of a Sedgemark Content workspace — the rich_text sanitization allowlist, form field types and bounds, API key scopes, and the /api/v1 runtime contract. Consumed by the dashboard and by the docs site, which live in different repositorie
