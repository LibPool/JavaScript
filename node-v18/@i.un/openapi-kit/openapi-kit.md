# @i.un/openapi-kit

> 标签: api, client, fetch, openapi, openapi-typescript, type-safe, types, typescript

## 简介

Framework-agnostic, zero-runtime type toolkit that binds an openapi-typescript `paths` definition to typed API client signatures.
