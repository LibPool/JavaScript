# @fastyshop/ui

> 标签: JavaScript

## 简介

`@fastyshop/ui` contains the shared FastyShop product tokens, React components, and public hooks. The package ships ESM, TypeScript declarations, Tailwind CSS v4 integration, the Inter variable font, the FastyShop Empty and Field patterns, ButtonLink comp
