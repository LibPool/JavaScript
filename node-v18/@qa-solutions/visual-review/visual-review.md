# @qa-solutions/visual-review

> 标签: cypress, pixelmatch, playwright, screenshot, snapshot-testing, visual-regression

## 简介

Framework-agnostic visual regression testing: screenshot comparison with tolerance thresholds, record-don't-fail CI mode, and a one-click review/accept workflow. Adapters for Playwright and Cypress.
