# @taskora/board

> 标签: admin, board, dag, dashboard, dlq, hono, jobs, monitoring, observability, queue, react, scheduler, sse, taskora, ui, workflow

## 简介

Admin dashboard for taskora — pre-built React SPA served by a Hono backend. Workflow DAG, schedules, DLQ, migrations, throughput, all with SSE live updates.
