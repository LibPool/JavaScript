# @loopstack/github-examples

> 标签: agent, example, github, loopstack, oauth, workflow

## 简介

GitHub integration workflow examples for Loopstack — a scripted repo overview across the GitHub read tools, and an interactive Claude agent with 25 GitHub tools. Both sign in through the OAuth sub-workflow on demand.
