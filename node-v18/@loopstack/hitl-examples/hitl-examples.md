> 标签: agent, ask-user, confirm, example, form, hitl, human-in-the-loop, loopstack, prompt-input, workflow

## 简介

Workflow examples for Human-in-the-Loop patterns in Loopstack — custom Document with widget, AskUserWorkflow / ConfirmUserWorkflow sub-workflow shortcuts, LLM agent loops with ask_clarification / ask_for_approval, and a meeting-notes review flow.
