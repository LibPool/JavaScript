# @loopstack/web-module

> 标签: fetch, html, http, loopstack, markdown, tool, webfetch

## 简介

Fetch and process web content. Converts HTML to Markdown, optionally summarizes against a prompt via Claude, with URL validation, same-origin redirect handling, LRU caching, and a preapproved-host allowlist.
