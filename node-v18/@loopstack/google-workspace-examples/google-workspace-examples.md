# @loopstack/google-workspace-examples

> 标签: calendar, drive, example, gmail, google, google-workspace, loopstack, oauth, workflow

## 简介

Google Workspace integration workflow examples for Loopstack — a scripted Google Calendar summary, and an interactive Claude agent with Calendar, Gmail and Drive tools. Both sign in through the OAuth sub-workflow on demand.
