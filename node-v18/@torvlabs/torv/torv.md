# @torvlabs/torv

> 标签: ai-agents, dependency, malware, mcp, npm, pre-commit, pypi, slopsquatting, supply-chain-security, typosquatting

## 简介

Stop AI coding agents from installing hallucinated or malicious packages. Verifies a dependency's provenance and reputation before it gets installed — built to catch slopsquatting.
