# @rift-finance/react

> 标签: auth, embedded-wallet, oauth, react, rift, rift-finance, wallet

## 简介

React bindings for the Rift sign-in widget. Drop in <RiftProvider>, render <RiftAuth>, and read auth state with useRift().
