# @wrongstack/requirement-intake

> 标签: JavaScript

## 简介

WrongStack Requirements Intake — collect, preserve, validate, normalize, and submit unstructured software development requests as structured intake records. Upstream of spec-driven development: it never plans, specifies, or implements.
