# @huiliyi37/dsh-intent-bridge

> 标签: JavaScript

## 简介

Intent bridge — a new session's first message is handled by a low-cost alignment model (multi-round clarification), then handed off as a structured task card to a fresh main session that naturally enters the zen phase
