# @shipispec/tsfix

> 标签: ai-codegen, ai-sdk, anthropic, auto-fix, code-fix, code-repair, error-recovery, language-service, linter, llm, tsc, typescript, validator

## 简介

TypeScript error-recovery for LLM-generated code. Layer 0/1 deterministic auto-fix via the TS Language Service + Layer 2 LLM mend (Vercel AI SDK + Anthropic) in one package.
