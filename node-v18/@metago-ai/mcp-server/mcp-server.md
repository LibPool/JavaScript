# @metago-ai/mcp-server

> 标签: ai-agent, ai-governance, claude, critical-analysis, cursor, decision-lock, lifeform, mcp, meta-evolution, metago, model-context-protocol, trae

## 简介

MetaGO Agent Harness（智能体运行时控制层套件 · 驭智层）MCP Server — 55 tools (22 思维工具 + 32 核心技能 + 1 事件上报) + 8 prompts。Engine V2.1.1 硬驱动：KMWI 四层记忆 + 元进化五阶段 + 技能智能生成调用真实代码 + 927 算法驱动（via @metago-ai/algorithms）。任何 MCP 协议客户端（Claude Desktop/Cursor/Trae/ZCode 等）即开即用。基于 Model C
