# @superduperbundle/mcp-server

> 标签: game keys, game prices, mcp, model context protocol, price comparison, steam, superduperbundle

## 简介

MCP server for live PC game key prices: lets AI assistants look up the lowest listed price across official stores and key stores (SuperDuperBundle Game Price API).
