> 标签: ai-agent, anthropic, claude, claude-code, cursor, google-search-console, gsc, mcp, mcp-server, search-console, seo

## 简介

Model Context Protocol (MCP) server for Google Search Console (GSC) inspection, search performance, and sitemaps via NPX. Spawns the Python package through uvx with full stdio passthrough.
