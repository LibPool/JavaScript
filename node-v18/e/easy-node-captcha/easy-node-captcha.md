# easy-node-captcha

> 标签: captcha, complexity, custom-font, encrypted, express, math-captcha, nextjs, node-captcha, security, svg-captcha, token, typescript, validation

## 简介

A simple, secure Node.js CAPTCHA library with encrypted token validation. Supports text and math CAPTCHAs with customizable options.
