# euiexport

> 标签: cli, eggitor, eggy, eggy-party, eui, map, messagepack, zstd, 蛋仔派对

## 简介

蛋仔派对 EUI 工具箱: eui export(把本地数据包翻译成人类可读 UI 数据包) + eui edit(用来修改字段数据的玩意)；单一 CLI,参数解析基于 commander,支持 FS(帧同步)与 SE(世界版)地图
