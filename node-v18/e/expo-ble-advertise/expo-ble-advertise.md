# expo-ble-advertise

> 标签: ExpoBleAdvertise, expo, expo-ble-advertise, react-native

## 简介

A simple React Native module for broadcasting custom BLE (Bluetooth Low Energy) advertising data in Expo apps. This module allows you to easily advertise custom data such as UUIDs or user IDs to nearby devices, enabling proximity-based interactions and Io
