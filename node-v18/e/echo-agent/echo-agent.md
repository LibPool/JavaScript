# echo-agent

> 标签: agent, ai-agent, bun, cli, llm, llm-agent, tui

## 简介

Echo's general agent: the official CLI and interactive TUI. The same agent runs interactively and through a Unix pipe. Assembly lives in @echo-agent/base, the terminal shell in @echo-agent/tui. Requires Bun.
