# ember-live-compiler

> 标签: compiler, documentation, ember, ember-source, emberjs, gjs, glimmer, gts, live-preview, template-tag

## 简介

Bundler-agnostic engine for compiling and rendering .gjs/.gts Ember components — the core that powers live Ember demos in VitePress, Docusaurus, Storybook, Backstage TechDocs, kolay, and more.
