# elm-ssr

> 标签: bun, cloudflare-workers, edge, elm, file-based-routing, framework, islands, migrations, server-side-rendering, ssr

## 简介

Elm-first SSR library and framework for Cloudflare Workers (and Bun): file-based routes/islands, backend-neutral effect adapters (KV/D1/Redis/Postgres), background tasks (waitUntil/Queues), SQL-file migrations, CLI scaffold + build.
