# eslint-config-webcube

> 标签: eslint, eslint-config, nodecube, prettier, webcube

## 简介

A sharable ESLint presets which integrates Prettier and explicitly configures all-available rules (guaranteed by scripts) from ESLint core and commonly used plugins.
