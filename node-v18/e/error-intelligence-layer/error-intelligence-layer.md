# error-intelligence-layer

> 标签: debugging, error, error-analysis, error-enrichment, error-handling, error-intelligence, error-normalization, express, fastify, logging, middleware, monitoring, nextjs, nodejs, observability, root-cause, severity, stack-parser, stack-trace, typescript

## 简介

Transform any thrown value into a structured error object with severity, root-cause chain, fix suggestions, stack parsing, request sanitisation, and framework adapters. Zero dependencies.
