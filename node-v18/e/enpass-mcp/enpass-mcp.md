# enpass-mcp

> 标签: claude, enpass, mcp, model-context-protocol, password-manager, sqlcipher, stdio, vault

## 简介

Model Context Protocol (MCP) server for Enpass vaults: unlock, list vaults, list and read entries, create entries. Master passwords are kept in the OS keychain and never pass through the model.
