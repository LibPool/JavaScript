# embeddable-live-code-widget-amineee

> 标签: JavaScript

## 简介

A framework-agnostic, embeddable **live code playground widget** (HTML/CSS/JS editor + live preview + console) designed to be dropped into any website — blogs, docs sites, LMS platforms, or plain HTML pages.
