# envscan-cli

> 标签: audit, ci, cli, developer-tools, dotenv, env, environment-variables, nodejs, secrets, security

## 简介

Audit your .env variables against your codebase. Catch missing, undocumented and unused vars — with auto-fix, watch mode, JSON/CI output, secret-leak detection, format validation, env comparison, a health score, an interactive setup wizard, HTML reports,
