# ember-local-storage-fork

> 标签: ember-addon, local-storage, local-storage adapter, local-storage array, local-storage object, localStorage, localStorage adapter, session-storage, session-storage array, session-storage object, sessionStorage

## 简介

The addon provides an ember-data adapter and a storageFor computed property that persists the changes to localStorage or sessionStorage.
