# esbuild-plugin-package-json

> 标签: backend, build, build plugin, build process, build tool, dependency management, developer tools, esbuild, esbuild copy, esbuild copy package json, esbuild dependency, esbuild plugin, esbuild tool, frontend, optimize package json, package config plugin, package json plugin, package.json, packages, plugin, validate package json

## 简介

Prepares the package.json by removing all unnecessary fields and copying it to the out folder of esbuild, so the built package can be published directly.
