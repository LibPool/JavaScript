# envnest-cli

> 标签: JavaScript

## 简介

EnvNest is a secure, GitHub-integrated `.env` file manager for developers and teams.   It helps you manage, encrypt, version, and sync environment configuration files across projects — with GitHub login, PostgreSQL backend, and custom encryption.
