# enhx-memory

> 标签: ai-agent, ai-coding-agent, fts, fts5, lightweight, mcp, memory, memory-server, minimal, model-context-protocol, sqlite, sqlite-fts5

## 简介

Lightweight SQLite-based persistent memory MCP server for AI coding agents. A minimal TypeScript implementation — not as heavy as enhanced-mcp-memory (which uses transformers, embeddings, etc).
