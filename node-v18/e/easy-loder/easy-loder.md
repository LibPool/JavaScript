# easy-loder

> 标签: JavaScript

## 简介

1、背景 首先我们来看一下为什么需要loader，以及他能干什么? webpack 只能理解 JavaScript 和 JSON 文件。loader 让 webpack 能够去处理其他类型的文件，并将它们转换为有效模块，以供应用程序使用，以及被添加到依赖图中。
