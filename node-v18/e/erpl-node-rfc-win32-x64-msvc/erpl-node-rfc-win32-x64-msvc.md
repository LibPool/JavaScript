# erpl-node-rfc-win32-x64-msvc

> 标签: abap, bapi, erpl, netweaver, node-rfc, nwrfc, rfc, s4hana, sap, sapnwrfc, saprfc, sdk-free

## 简介

SDK-free SAP RFC client for Node.js and TypeScript — a drop-in replacement for SAP's archived node-rfc. No SAP NW RFC SDK, no ICU, no node-gyp. Part of ERPL, alongside erpl-pyrfc (Python) and erpl-gorfc (Go).
