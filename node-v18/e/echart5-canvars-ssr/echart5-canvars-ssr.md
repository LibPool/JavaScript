# echart5-canvars-ssr

> 标签: canvas, echarts, image, node, node.js, nodejs, server side render, ssr

## 简介

Echarts server side render by node canvas, generate chart image by Echarts5, support http access. 使用NodeJs服务器端渲染echarts 5图表，生成图片格式,支持网络访问
