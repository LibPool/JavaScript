# ensure-dir-tiny

> 标签: dir-exists, directory-exists, ensure, ensure-dir, ensure-dir-tiny, ensure-directory, fs, mkdir

## 简介

📁 Checks if a folder exists; if not, it creates it. This prevents "File Not Found" errors when saving data.
