# eslint-plugin-knex-security

> 标签: ai-assistant, appsec, code-quality, cwe, cwe-89, database, database-security, eslint, eslint-plugin, eslintplugin, interlace-security, knex, linting, llm-optimized, mysql, owasp, postgres, raw-query, sast, security, sql, sql-injection, sqlite, static-analysis, typescript, vulnerability

## 简介

ESLint plugin for knex — detects SQL injection in raw queries built with string concatenation or template literals, connection configuration that disables TLS or certificate validation, and hardcoded database credentials.
