# express-cdn

> 标签: amazon, assets, cdn, cloudfront, express, express-cdn, gzip, jpegtran, mangle, minify, obfuscate, optimize, optipng, s3, uglify, zlib

## 简介

Node.js module for delivering optimized, minified, mangled, gzipped, and CDN-hosted assets in Express using S3 and CloudFront.
