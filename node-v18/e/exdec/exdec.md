# exdec

> 标签: exdec, exdec server, express decorator, express server decorator, express typescript decorator, server decorator, typescript express decorator

## 简介

ExDec Server - A TypeScript decorator library for modular and scalable Express applications, offering clean routing, middleware management, and enhanced type safety, with an architectural approach inspired by NestJS.
