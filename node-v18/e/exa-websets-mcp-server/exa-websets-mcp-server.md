# exa-websets-mcp-server

> 标签: ai, claude, collections, content management, exa, mcp, model context protocol, websearch, websets

## 简介

A Model Context Protocol server for Exa Websets management. Provides comprehensive websets collection management, real-time web searching, and helpful guidance through a simplified interface.
