# eiam-scan-resource-controls

> 标签: EIAM, angular, angular integration, authorization, auto register permissions, checkRole, cli, eiam scan resource controls, permission scanner, permissions, role permissions, scan permissions, stencil, stenciljs, web components

## 简介

Registers every checkRole permission code in the database automatically: a CLI that scans the source at build time, a runtime scan on route changes, and an optional per-control element that also replaces checkRole.
