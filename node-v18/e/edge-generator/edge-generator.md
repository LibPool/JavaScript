# edge-generator

> 标签: .net, c#, callback, clr, code, csharp, edge, edge-reference, generator, integration, managed, mono, net, proxy, reference

## 简介

Generates JavaScript proxies of .NET code that allow references to be passed between node.js and .NET libraries.
