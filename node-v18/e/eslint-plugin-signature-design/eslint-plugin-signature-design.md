# eslint-plugin-signature-design

> 标签: code-quality, duplicate-parameter-types, eslint, eslint-plugin, eslintplugin, function-signature, lint, parameters-types, primitive-obsession, signature-design, typescript, typescript-eslint

## 简介

ESLint rule to make function signatures better. Currently has only one rule: prevent functions from having too many arguments with the same type.
