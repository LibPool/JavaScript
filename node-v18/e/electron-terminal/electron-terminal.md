# electron-terminal

> 标签: JavaScript

## 简介

This is a minimal example of getting a terminal running in Electron using [nebula-pty](https://github.com/Rayan-Walnut/nebula-pty) and [xterm.js](https://github.com/sourcelair/xterm.js).
