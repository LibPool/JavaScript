# export-svg-chart

> 标签: JavaScript

## 简介

Converts SVG+CSS charts built with front-end technologies like D3 into SVG/PNG Node buffers for server-side use.

## 官网

- npm 页面：https://www.npmjs.com/package/export-svg-chart
