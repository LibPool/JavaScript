# expo-cutout

> 标签: apple-vision, background-removal, background-remover, expo, expo-module, image-cutout, on-device, react-native, remove-background, subject-segmentation, transparent-background, transparent-png

## 简介

On-device background removal for Expo. Apple Vision on iOS 17+ turns a local photo into a transparent PNG. No server, no API key. Dev Client required.
