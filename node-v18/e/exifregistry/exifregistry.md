# exifregistry

> 标签: cli, exif, exiftool, gps, metadata, photography

## 简介

A friendly command-line toolkit for photographers to inspect and edit photo/video metadata (EXIF, GPS, dates).

- 源码仓库：git+https://github.com/daviarndt/exifregistry.git
