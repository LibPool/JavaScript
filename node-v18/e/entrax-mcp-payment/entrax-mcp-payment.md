# entrax-mcp-payment

> 标签: entrax, hmac, mcp, model-context-protocol, payment-api, payments, qr, sbp

## 简介

MCP server for the EntraX Payment API (HMAC-SHA256). Exposes create/status/refund/rates as AI tools.
