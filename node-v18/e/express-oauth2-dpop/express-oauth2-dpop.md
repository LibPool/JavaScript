# express-oauth2-dpop

> 标签: access token, api, auth, auth0, authentication, authorization, authz, bearer, dpop, express, javascript, jwks, jwt, oauth, oauth2, openid, resource server, sdk, typescript

## 简介

Protect your Express API (resource server) routes with OAuth 2.0 JWT Bearer and DPoP-bound access tokens issued by an authorization server.
