# env-native

> 标签: .env, cli, config, dotenv, dotenv-replacement, dotenvx, env, env cli, env-loader, environment, environment-variables, fast, lightweight, minimal, native, nodejs, secure, settings, util.parseEnv, variables, zero-dependency

## 简介

Minimalistic, dependency-free .env loader using Node.js's native util.parseEnv. Much faster than dotenv, with CLI support.
