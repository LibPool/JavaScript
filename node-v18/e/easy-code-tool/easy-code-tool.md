# easy-code-tool

> 标签: JavaScript

## 简介

> 主要特性如下 > * 自动生成 `RESTful`风格的api，实现基本的`CURD` > * 自动生成管理界面，每一个模型有对应的管理视图 > * 自带权限系统，开箱即用 > * 支持图片上传 > * 支持excel导出 > * 扩展了用户端接口 jwt实现 > * 支持多语言如 `JAVA`、`PHP`、`Node.js` > * 支持多种数据库如 `MySQL`、`Mongodb` > * 灵活的表单项配置 > * 支持多种主题
