# envtrue

> 标签: arktype, bun, coercion, config, configuration, dotenv, dotenv-replacement, env, env-validation, environment, environment-variables, hono, nextjs, node, standard-schema, twelve-factor, type-safe, typescript, valibot, validation, vite, zod

## 简介

Type-safe environment variables. Loads .env files, validates with Zod/Valibot/ArkType, auto-coerces types. Drop-in dotenv replacement.
