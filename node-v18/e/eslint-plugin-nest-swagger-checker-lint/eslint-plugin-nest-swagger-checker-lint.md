# eslint-plugin-nest-swagger-checker-lint

> 标签: JavaScript

## 简介

nest-swagger-checker-linter is linter version of [nest-swagger-checker](https://github.com/ozkersemih/nest-swagger-checker) package to use it as ESLint rule.
