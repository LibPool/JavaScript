# eleventy-plugin-embed-tiktok

> 标签: 11ty, eleventy, eleventy-plugin, tiktok

## 简介

An Eleventy plugin to automatically embed TikTok videos, using just their URLs.

- 官网：https://gfscott.com/embed-everything/
- 源码仓库：git+https://github.com/gfscott/eleventy-plugin-embed-everything.git
