# excel-json-sheet

> 标签: excel, json, sheet

## 简介

<!--  * @Author: fog  * @Description: excel解析组件  --> # excel-json-sheet excel-json-sheet组件基于sheet.js, 在其基础功能上做了二次封装, 目前支持功能如下： - excel解析成json数据或二维数组 - excel文件解析过程的规则校验, 如限制行,列数, 限制模版头部, 校验规则可扩展 - excel解析支持异步配置 - json数组数据, 转excel文件下载 -
