# eleventy-plugin-csv-table

> 标签: 11ty, csv, eleventy, eleventy-plugin, table

## 简介

Eleventy plugin that renders sortable, filterable, paginated HTML tables from CSV files, with an optional dynamic (client-fetched) mode.
