# easy-starter

> 标签: ai-friendly, boilerplate, cli, cursorrules, easy-analytics, easy-db, easy-user-auth, fullstack-boilerplate, local-database, pm2-deployment, quickstart, react-starter, server-side-rendering, ssh-deployment, ssr, starter-kit, typescript-boilerplate, user-authentication, user-login, vite-template, vps-deploy, zero-config

## 简介

A lightweight, production-ready fullstack React boilerplate generator with Vite v8, TypeScript 7, server-side rendering (SSR), local analytics, SSH deploy script, PM2, and secure user authentication.
