# emp-code

> 标签: ai, cli, coding-agent, no-avx, nvidia-nim, opencode-zen, windows

## 简介

EMP CLI - coding agent with full-screen TUI (ink, clickable tool output, mouse, plan mode, markdown, vision) and 18 providers. Runs great on any light PC / weak CPU / old motherboard. Sessions, context, effort, web search, background tasks, revert.
