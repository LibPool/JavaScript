# enni-analytics

> 标签: analytics, cookieless, counters, dynamodb, first-party, nextjs, privacy

## 简介

First-party, counter-only web analytics: a ~1KB collector, one API route handler, and a password-protected admin dashboard, storing only anonymous counters in DynamoDB.
