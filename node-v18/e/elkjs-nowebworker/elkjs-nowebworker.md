# elkjs-nowebworker

> 标签: dataflow, graph, layered, layout, ports

## 简介

Forked from elkjs and remove the dependency on webworker-threads. elkjs is a automatic graph layout based on Sugiyama's algorithm. Specialized for data flow diagrams and ports.
