# essenta-mcp-server

> 标签: anthropic, claude, essenta, mcp

## 简介

MCP server for the Essenta exec-search platform. One tool: ask_chat — wraps the /api/chat endpoint so Claude Desktop / Code / Cursor / any MCP client can query Essenta's data with a partner's Bearer token.
