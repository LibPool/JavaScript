# ecardwidget-mcp

> 标签: agent, ai, ecards, ecardwidget, mcp, model-context-protocol

## 简介

Official Model Context Protocol (MCP) server for eCardWidget — let an AI agent run your account (campaigns, widgets, automations, directory, eCards) with a scoped API key.
