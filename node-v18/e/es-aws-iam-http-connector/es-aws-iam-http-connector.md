# es-aws-iam-http-connector

> 标签: AWS, Elasticsearch, IAM, IAMv4, Lambda

## 简介

Plugin for Elasticsearch client to sign requests with AWS IAMv4 so that the client can talk to AWS ES domains secured via IAM policies
