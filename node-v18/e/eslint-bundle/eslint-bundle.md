# eslint-bundle

> 标签: JavaScript

## 简介

The shortcut for installing tons of packages. Instead of: ```bash npm i -D eslint@3 eslint-config-airbnb@15 eslint-plugin-jsx-a11y@5 eslint-plugin-react@7 babel-eslint@7 eslint-plugin-import@2 ``` Just: ```bash npm i eslint-bundle -D ```
