# eventemitter3-timer

> 标签: event, eventemitter3, pixi, schedule, time, timeline, timer, timermanager

## 简介

`EventEmitter3-Timer` is a plugin extend [EventEmitter3](https://github.com/primus/eventemitter3) to create time events easily.
