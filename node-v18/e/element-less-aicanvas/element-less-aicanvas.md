# element-less-aicanvas

> 标签: ai, canvas, element-less, infinite-canvas, vue-flow, vue3

## 简介

Vue 3 AI 无限画布编辑器组件，开箱即用 —— 传入 projectId 与 adapter 即可加载完整画布（含 3D 导演台）
