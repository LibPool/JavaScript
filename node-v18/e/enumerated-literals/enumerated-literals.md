> 标签: constants, enum, enums, literals, string literal, string literals, string-literal, string-literals, template literals, template-string-literals, type-safe-enum-pattern, type-safety, typescript

## 简介

The `enumerated-literals` package provides a strongly-typed, type-safe and convenient pattern for defining and manage constant strings in an application.
