# extojs

> 标签: JavaScript

## 简介

`extojs` 是一个实用的 Node.js 命令行工具，旨在将包含多语言翻译的 Excel 文件 (`.xlsx`, `.xls`) 快速且便捷地转换为 JavaScript i18n 语言包文件。
