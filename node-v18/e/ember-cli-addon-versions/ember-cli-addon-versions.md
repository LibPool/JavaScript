# ember-cli-addon-versions

> 标签: ember-addon

## 简介

Report which Ember addons (at which versions) are installed in your application.

## 官网

- 源码仓库：https://github.com/dfreeman/ember-cli-addon-versions.git
- npm 页面：https://www.npmjs.com/package/ember-cli-addon-versions

## 历史版本号

- 当前版本：1.0.1

- 1.0.0
- 1.0.1

## 获取地址

- npm 安装：`npm install ember-cli-addon-versions`
- npm registry：https://registry.npmjs.org/ember-cli-addon-versions
- Node 要求：^4.5 || 6.* || >= 7.*
