# express-greenborn-sso-back

> 标签: auth, authentication, express, google, greenborn, middleware, node, oauth, sso

## 简介

Autenticación SSO para backends Express/Node que se integra con el servidor de autenticación Greenborn (auth.greenborn.com.ar). Middlewares (authMiddleware/authMiddlewareOptional) y router Express (/me, /sso-profile, /register) reutilizables, con inyecció
