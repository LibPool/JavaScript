# eatp

> 标签: JavaScript

## 简介

安装模块 npm i zxp-strfilter 导入模块 const str = require('zxp-strfilter'); 使用: 有三个参数,第一个为字符串, 第二个为需要过滤的字符,第三个为过滤后替换的新字符 str.getStr('abc', 'a', 'ee');// 把字符串abc中的a,替换成了ee
