# eoyo-react-redux

> 标签: model base, react immutable, redux immutable, selector template, typed immutable

## 简介

在平时的项目开发中, 使用 react 结合 redux 很容易出现性能问题. 运行时的性能问题主要就是多做了无关的 diff 计算, 因此我们考虑使用 immutable 来优化数据结构, 从数据源头减少 diff 的计算.
