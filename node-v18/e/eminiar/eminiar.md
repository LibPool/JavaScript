# eminiar

> 标签: claude-code, claude-code-plugin, context-window, fts5, knowledge-graph, mcp, sandbox, sqlite-vec, tree-sitter

## 简介

Local-first context, memory and knowledge-graph plugin for Claude Code. Sandboxed execution, FTS5 + vector search, session continuity, and a code graph — nothing leaves your machine.
