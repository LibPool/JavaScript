# el-form-react-hooks

> 标签: autoform, field-validation, form, form-builder, form-management, form-state, forms, hooks, react, react-forms, react-hook-form, schema-first, schema-validation, type-safe, typescript, typescript-forms, useform, valibot, validation, yup, zod

## 简介

React Hook Form alternative - TypeScript-first useForm hook with enterprise-grade state management. Schema-agnostic validation (Zod, Yup, Valibot), minimal re-renders, advanced form controls.
