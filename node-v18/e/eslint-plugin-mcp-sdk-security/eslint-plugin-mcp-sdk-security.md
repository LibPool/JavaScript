# eslint-plugin-mcp-sdk-security

> 标签: agentic, ai-security, appsec, code-quality, cwe, eslint, eslint-plugin, eslintplugin, interlace-security, linting, llm, llm-security, mcp, mcp-security, mcp-server, model-context-protocol, modelcontextprotocol, owasp, sast, security, static-analysis, tool-calling, tool-poisoning, typescript, vulnerability

## 简介

ESLint plugin for Model Context Protocol (MCP) SDK security — catches tools registered without an input schema, handlers reading arguments the schema never declared, model-visible descriptions built from dynamic text, and tool arguments reaching a shell.
