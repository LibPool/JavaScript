# endereco-facil

> 标签: JavaScript

## 简介

Uma biblioteca Node.js leve, moderna e fortemente tipada para busca de **endereços com fuzzy search, CEPs e cálculo de distâncias/rotas** integrando múltiplos provedores (ViaCEP, Nominatim, CepAberto, OpenRouteService, etc.).
