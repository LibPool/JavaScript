# excel-clipboard-paste

> 标签: clipboard, csv, excel, google-sheets, matrix, onpaste, parser, paste, spreadsheet, table, tsv

## 简介

Parse clipboard data pasted from Excel or Google Sheets into a clean matrix. Zero dependencies, TypeScript, ESM + CJS.
