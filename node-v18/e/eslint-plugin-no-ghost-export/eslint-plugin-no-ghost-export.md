# eslint-plugin-no-ghost-export

> 标签: eslint, eslint-plugin, eslintplugin, export, ghost-export, import, re-export

## 简介

ESLint rule that disallows importing bindings only to re-export them (ghost exports).

## 官网

- npm 页面：https://www.npmjs.com/package/eslint-plugin-no-ghost-export

- npm registry：https://registry.npmjs.org/eslint-plugin-no-ghost-export
