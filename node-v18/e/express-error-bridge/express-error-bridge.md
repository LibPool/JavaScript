# express-error-bridge

> 标签: app-error, error-handling, error-middleware, error-reporting, error-tracking, express, http-errors, logging, middleware, node

## 简介

Shared AppError class, error normalizer, and Express error-handling middleware that reports errors to a central error-tracking endpoint.
