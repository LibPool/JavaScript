# expo-navigation-mode

> 标签: android, edge-to-edge, expo, gesture-navigation, insets, navigation-bar, navigation-mode, react-native, safe-area, three-button

## 简介

Detect the Android system navigation mode (3-button / 2-button / gesture) from JS. Handy for edge-to-edge layouts on Android 15+.
