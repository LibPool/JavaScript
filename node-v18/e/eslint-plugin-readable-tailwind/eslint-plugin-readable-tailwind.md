# eslint-plugin-readable-tailwind

> 标签: break, eslint, eslint-plugin, horizontal, html, jsx, line, linebreak, literal, multi, multiline, newline, qwik, react, readable, scrolling, solid, svelte, tailwind, tailwind-classes, tailwind-css, tailwindcss, template, template-literal, template-literals, vue, wrap

## 简介

auto-wraps tailwind classes after a certain print width or class count into multiple lines to improve readability.
