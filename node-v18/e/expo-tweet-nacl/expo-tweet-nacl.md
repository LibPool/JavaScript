# expo-tweet-nacl

> 标签: expo, getRandomBytesAsync, nacl, native, random, react, tweet

## 简介

Tweet NaCl for React Native Expo which uses expo-random to get random bytes (getRandomBytesAsync - equivalent to Node.js crypt.randomBytes),
