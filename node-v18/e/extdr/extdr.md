# extdr

> 标签: JavaScript

## 简介

Готовый фронт и Node.js-сервер для чтения архитектурных решений из Markdown. Требуются Node.js 24.21.0 и npm 11.19.0.

## 官网

- npm 页面：https://www.npmjs.com/package/extdr

## 历史版本号

- 当前版本：0.1.0

- 0.0.0-stage
- 0.1.0

## 获取地址

- npm 安装：`npm install extdr`
- npm registry：https://registry.npmjs.org/extdr
- Node 要求：24.21.0
