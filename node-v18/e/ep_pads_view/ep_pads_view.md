# ep_pads_view

> 标签: dashboard, ep, ep_plugin, etherpad, html, padlist, pads, plugin

## 简介

A ready-made HTML page listing all pads with their creator and last-edited date. A thin UI on top of ep_pads_api — install both and open the page, no frontend coding required.
