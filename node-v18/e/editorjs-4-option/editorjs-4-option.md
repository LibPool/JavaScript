# editorjs-4-option

> 标签: JavaScript

## 简介

Provide block tool for MCQ's (multiple choise questions). You can write question as usual using EditorJS, for options you can use this plugin. It have four inputs for , 4 options a,b,c,d respectavily. Paste any kind of data inclusive image url, simple tex
