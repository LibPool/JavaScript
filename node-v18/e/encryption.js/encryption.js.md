# encryption.js

> 标签: aes, encrypt, encryption, nextjs, node, nuxtjs, server, token, web

## 简介

Lightweight encryption utility for node or browser (as of v2.0.0) apps, allows setting app secret & set purpose of encryption, inspired from adonis encryption feature
