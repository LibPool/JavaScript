# examurai

> 标签: ai, automation, cli, deepseek, exam, playwright, quiz, test-solver

## 简介

Открытый CLI-инструмент, связывающий браузер и LLM для работы с веб-тестами. Не готовый бот — конструктор: читает страницу, передаёт в нейросеть и выполняет ответ. Bring your own API key.
