# enclawed

> 标签: ai, audit-log, classified, enclave, fips, gateway, hardened

## 简介

Hardened single-user AI gateway for classified-enclave deployment. Hard fork of Enclawed with cloud channels, cloud LLM providers, and external search/web extensions removed; classification-policy framework always on.
