# element-readonly-form-item

> 标签: ElementUI, Form, Readonly, Vue

## 简介

基于 ElementUI 的表单只读态控件，完美适配所有表单组件。主要用于新建页与详情页动态切换。支持 npm 与 cdn 方式的引入。
