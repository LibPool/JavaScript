# eslint-plugin-n8n-runtime

> 标签: eslint, eslint-plugin, eslintplugin, n8n, n8n-community-node-package, n8n-node

## 简介

Runtime-safety lint rules for n8n community nodes: error contract, item lineage, request handling and credential flow. Sits beside @n8n/node-cli's official config.
