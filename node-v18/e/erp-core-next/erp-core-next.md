# erp-core-next

> 标签: angular, auth, erp, http, signals, stores

## 简介

Núcleo standalone, sin NgModules y basado en signals para apps Angular: stores reactivos, capa HTTP funcional, guards y dos modos de arranque (gestor/consumer).
