# excel-template-helper

> 标签: excel, node, typescript

## 简介

A simple Node.js package to fill a rectangular area in an Excel file and returns the file.   This package is powered by [openpyxl](https://openpyxl.readthedocs.io/) to handle Excel file manipulation.
