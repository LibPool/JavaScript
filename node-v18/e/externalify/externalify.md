# externalify

> 标签: browserify, browserify-transform, global, require, transform, window

## 简介

Browserify transform that lets you require external modules from any function that follows the require API.

- 官网：https://github.com/meteor/externalify
- 源码仓库：git://github.com/meteor/externalify.git
