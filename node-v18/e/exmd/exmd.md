# exmd

> 标签: JavaScript

## 简介

```exmd```的核心代码, 包含的功能有： 1. ```startProject``` 启动项目 2. ```BaseModel``` model基类 3. ```migrate``` 数据库表转model 4. ```asyncdb``` model转数据库表 5. ```renderRequestType``` controller方法的请求配置    - 配置请求   - 配置swagger及swagger中的参数和返回参数描述 6. ```handleClientAdapter``` 持久层
