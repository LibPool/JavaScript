# excel-before-upload-validation-helper

> 标签: csv, data-import, excel, react, upload, validation, xlsx

## 简介

Headless React toolkit for validating and shaping Excel data before it gets uploaded — configurable field types, Excel-to-JSON parsing, an editable confirm grid, and optional AI-assisted field generation.
