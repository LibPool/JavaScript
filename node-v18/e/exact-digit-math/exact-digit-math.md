# exact-digit-math

> 标签: add, arbitrary-precision, arithmetic, bignumber, compact-number, decimal, number-format, subtract

## 简介

Arbitrary-length, precision-safe decimal arithmetic (add/subtract) using school-method digit arithmetic, plus compact number formatting (1K, 1M, 1B, etc). No Number or BigInt used internally, so results are never affected by floating-point or 2^53 precisi
