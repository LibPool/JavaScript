# expo-call-keep

> 标签: android, callkit, calls, expo, ios, new-architecture, phone, react-native, turbomodule, voip

## 简介

An Expo-compatible React Native module for handling VoIP calls with CallKit (iOS) and ConnectionService (Android) support. Built with Kotlin and Swift, compatible with New Architecture.
