# exact-math

> 标签: 754, IEEE, add, addition, arithmetic, big, calculation, ceil, ceiling, divide, division, floating, floor, flooring, formula, integer, math, multiplication, multiply, parentheses, point, power, precision, problem, result, round, rounding, safe, subtract, subtraction

## 简介

The exact-math is a set of methods for addition, subtraction, multiplication, division, rounding, ceiling, flooring and powering calculations. It can be used with big number as it handles the floating point problem.
