# express-session-mysql2

> 标签: connect, express, express-mysql-session, express-session, mariadb, mysql, mysql2, session, session-store, store

## 简介

MySQL and MariaDB session store for express-session, built on mysql2 with up-to-date, security-patched dependencies. Drop-in replacement for express-mysql-session.
