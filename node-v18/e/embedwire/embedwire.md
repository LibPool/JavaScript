# embedwire

> 标签: embed, iframe, interactive-transcript, nocookie, postmessage, seek, sync, transcript, youtube

## 简介

Control a YouTube embed over the postMessage wire its own widget uses — no iframe_api script, works with youtube-nocookie. Method and event names follow the IFrame Player API (playVideo, seekTo, getDuration, stateChange); ships a transcript-follow example
