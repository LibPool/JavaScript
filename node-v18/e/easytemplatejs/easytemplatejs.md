# easytemplatejs

> 标签: ET, easy, easyproject, easytemplate, easytemplatejs, engine, etj, express, html, javascript, koa, koajs, library, node, node.js, plugin, template, template engine

## 简介

High-performance, small, pure, JavaScript template engine. Support:`CommonJS`, `AMD`, `CMD`, `Node.js`, `Express`, `koa`, `<etj-script>`, `<etj-style>`.
