# el-form-core

> 标签: form, form-library, form-validation, framework-agnostic, schema-based-validation, schema-first, schema-validation, type-safe, typescript, typescript-validation, valibot, validation, validation-engine, validator, yup, zod

## 简介

Framework-agnostic form validation engine - schema-first validation core for TypeScript applications. Supports Zod, Yup, Valibot and custom validators.
