# express-ip-filter

> 标签: array, blacklist, custom, express, expressjs, filter, function, glob, id, ip, ip-filter, ips, limit, limiter, match, matcher, micromatch, middleware, minimatch, options, pattern, regex, regexp, string, support, whitelist

## 简介

Middleware for [express][] that filters IPs against glob patterns, RegExp, string or array of globs. Support custom `403 Forbidden` message, blacklists, whitelists and custom ID.
