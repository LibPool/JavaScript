# elaine-cli

> 标签: JavaScript

## 简介

基于vue-cli的前端脚手架工具，该脚手架包含了pc端和移动端脚手架，以及pc端常用的页面模板和UI组件，并基于该脚手架模板以邑体预约后台管理系统为实例实现了前后端开发。
