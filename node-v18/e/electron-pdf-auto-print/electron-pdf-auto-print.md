# electron-pdf-auto-print

> 标签: JavaScript

## 简介

一个electron的自动预览打印插件,基于electron-pdf-window 进行二次拓展，实现打开pdf后0.5秒自动打印。

## 官网

- npm 页面：https://www.npmjs.com/package/electron-pdf-auto-print

## 历史版本号

- 当前版本：1.0.0

- 1.0.0

## 获取地址

- npm 安装：`npm install electron-pdf-auto-print`
