# ezamowienia-tenders-mcp-server

> 标签: apify, bzp, claude, e-zamowienia, mcp, model-context-protocol, open-data, poland, public-procurement, public-tenders, tenders

## 简介

Open bridge to the hosted Polish Public Tenders (e-Zamówienia/BZP) MCP server on Apify — find, analyze, and score Polish public tenders from any MCP client using your own Apify API token.
