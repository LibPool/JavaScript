# exchangerate-dev-mcp

> 标签: api, claude, currency, cursor, exchange-rate, exchangerate, forex, fx, mcp, model-context-protocol

## 简介

Stdio bridge for the exchangerate.dev Model Context Protocol server. Drops Claude Desktop, Cursor, or any MCP client into live FX rates in 30 seconds.
