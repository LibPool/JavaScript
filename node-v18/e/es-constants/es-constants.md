# es-constants

> 标签: E, EPSILON, LN10, LN2, LOG10E, LOG2E, MAX_SAFE_INTEGER, MAX_VALUE, MIN_SAFE_INTEGER, MIN_VALUE, Math, NEGATIVE_INFINITY, Number, PI, POSITIVE_INFINITY, SQRT1_2, SQRT2, constants, ecmascript, es-shim API, integer, javascript, max, min, polyfill, safe, shim

## 简介

An ES-spec-compliant shim/polyfill/replacement for JS language Math and Number constant values that works as far down as ES3
