# eslint-plugin-angular-typed-routes

> 标签: angular, eslint, eslint-plugin, linting, route-resolver, static-analysis, type-safety, typescript

## 简介

ESLint plugin that enforces explicit return types on Angular route resolvers, catching type mismatches at lint time.
