# electron-driver

> 标签: agent-tools, ai-agent, automation, claude, claude-code, desktop-automation, e2e, electron, mcp, model-context-protocol, playwright, testing, visual-testing

## 简介

MCP server that lets AI agents drive Electron apps — click, type, drag, screenshot, eval JS in the renderer or main process, capture console logs, handle multi-window apps, and more.
