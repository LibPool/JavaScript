# easy-sharing

> 标签: android, cli sharing, directory serving, directory sharing, file serving, file sharing, ios, mobile, mobile file sharing, receive file, send file, share clipboard

## 简介

Sharing is a command-line tool to share directories and files from the CLI to iOS and Android devices without the need of an extra client app
