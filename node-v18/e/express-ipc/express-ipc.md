# express-ipc

> 标签: IPC, TCP, axios, express, express-ipc, jayson, node-ipc, pubsub, socket.io, unix domain socket, websocket, windows named pipe

## 简介

A simple IPC server with express-like request and route handling that also supports broadcasting to multiple channels.
