# eleventy-plugin-embed-mastodon

> 标签: 11ty, eleventy, eleventy-plugin, mastodon

## 简介

An Eleventy plugin to automatically embed Mastodon posts, using just their URLs.

## 官网

- 官网：https://gfscott.com/embed-everything/
- 源码仓库：git+https://github.com/gfscott/eleventy-plugin-embed-everything.git
- npm 页面：https://www.npmjs.com/package/eleventy-plugin-embed-mastodon
