# eslint-plugin-supabase-security

> 标签: appsec, baas, code-quality, cwe, eslint, eslint-plugin, eslintplugin, interlace-security, linting, owasp, postgres, postgrest, rls, row-level-security, sast, security, service-role, static-analysis, supabase, supabase-security, typescript, vulnerability

## 简介

ESLint plugin for Supabase security — catches the service_role key reaching client code, RPC called with a computed function name, auth results whose error is discarded, and storage buckets created public.
