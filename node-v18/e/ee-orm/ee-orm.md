# ee-orm

> 标签: cluster, connection pooling, eager loading, mysql, object relational mapper, orm, postgres

## 简介

ORM for postgres and mysql. Loads and saves referenced entites, executes complex queries, supports joins, transactions, complex database clusters, connection pooling and much more. No conventions. MIT Licence
