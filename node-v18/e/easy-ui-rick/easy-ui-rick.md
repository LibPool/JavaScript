# easy-ui-rick

> 标签: JavaScript

## 简介

Easy UI是一款基于Vue3 和 Typescript 的UI组件库   这款组件库是我从Vue2过渡到Vue3的练习作品，为了熟悉Vue3，这款UI库全程手写，尽量做到熟悉Vue3写法和相比于Vue2的变化    所以强烈不建议将此库用于生产环境，但可以相互学习交流，源代码在https://github.com/rick-yao/easy-ui
