# eslint-config-lapikit

> 标签: configuration, eslint, lapikit, svelte

## 简介

Official ESLint configuration for [Lapikit](https://lapikit.dev) — prevents false positives caused by Lapikit's `<kit:*>` syntax and preprocessor.

## 官网

- 官网：https://lapikit.dev
- 源码仓库：git+https://github.com/lapikit/eslint-config-lapikit.git
- npm 页面：https://www.npmjs.com/package/eslint-config-lapikit
