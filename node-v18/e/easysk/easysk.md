# easysk

> 标签: agent-skills, ai, claude-code, mcp, skill-md, skills, typescript

## 简介

Keep every AI agent skill in your project in one shape: create, audit, fix, improve and rebuild skills. Works as a skill, a CLI and an MCP server. Pure TypeScript, zero runtime dependencies.
