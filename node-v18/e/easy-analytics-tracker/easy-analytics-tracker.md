# easy-analytics-tracker

> 标签: analytics, browser, events, first-party, react, sendbeacon, telemetry, tracking

## 简介

Lightweight, dependency-free browser client for first-party behavioural analytics. Batches events in memory and delivers them to your own HTTP endpoint via sendBeacon or fetch.
