# env-runtime-guard

> 标签: JavaScript

## 简介

EnvRuntimeGuard is a lightweight runtime environment variable validator for Node.js and frontend applications. It ensures required environment variables are set, validates types, enforces allowed values, and masks sensitive data in logs.
