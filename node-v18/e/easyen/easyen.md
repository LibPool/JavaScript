# easyen

> 标签: ai, english, plain-english, readability, sentence-length, typescript, vocabulary, 可读性, 英语, 词汇

## 简介

Check how easy an English text is to read — vocabulary level and sentence length. Helps keep AI output simple. Pure TypeScript, zero runtime dependencies.
