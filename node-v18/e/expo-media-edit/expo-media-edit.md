# expo-media-edit

> 标签: avfoundation, composer, editing, expo, expo-module, media3, overlay, preview, trim, video

## 简介

Native video composer for Expo — Project document, native preview (AVFoundation + media3), single-source-of-truth render. No FFmpeg.
