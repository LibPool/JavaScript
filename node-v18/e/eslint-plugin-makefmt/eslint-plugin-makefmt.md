# eslint-plugin-makefmt

> 标签: eslint, eslint-plugin, eslintplugin, fmt, format, formatter, gnu make, just, justfile, make, makefile, makefmt

## 简介

ESLint plugin that formats Makefiles and justfiles with makefmt. Aligns assignments and line continuations, indents conditionals, and formats recipes as shell.
