# expo-accessibility-plus

> 标签: a11y, accessibility, content-size-category, darker-system-colors, differentiate-without-color, dynamic-type, expo, ios, react-native, uiaccessibility

## 简介

Extended accessibility settings for React Native / Expo. Read and subscribe to system flags that stock AccessibilityInfo doesn't expose — differentiate without color, darker system colors, content size category, button shapes, and more.
