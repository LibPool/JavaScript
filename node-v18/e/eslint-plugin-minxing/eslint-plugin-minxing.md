# eslint-plugin-minxing

> 标签: JavaScript

## 简介

A group of ESLint plugin and presets for the minxing company. # Setup 1. Global tools     1. `npm install -g yo`     1. `npm install -g generator-eslint` 1. Generate the eslint-plugin skeleton     1. `yo eslint:plugin` 1. Generate the eslint-rules
