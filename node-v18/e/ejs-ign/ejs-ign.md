# ejs-ign

> 标签: IGN, Institut Geographique National, ejs, electron, gpao, ihm, interface, json

## 简介

module to build an html interface from a json, used for the specific needs of the French National Geographic Institute (IGN). Further development may result in a wider potential use of the module.
