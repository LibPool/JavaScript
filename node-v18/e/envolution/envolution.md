# envolution

> 标签: aws, config, configuration, dotenv, env, environment, environment-variables, hot-reload, lambda, nodejs, runtime-validation, schema-validation, serverless, singleton, startup-validation, template-generation, type-safe, typescript, validation, zod

## 简介

TypeScript-first environment configuration with Zod validation, .env support, hot reloading, and startup validation. Zero-config setup - just install and use! Perfect for Node.js, AWS Lambda, and modern TypeScript applications.
