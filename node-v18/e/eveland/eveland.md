# eveland

> 标签: JavaScript

## 简介

The public Eveland SDK provides Eve channel authentication for Eveland's short-lived, project-bound Caller Tokens, and a storage backend for Eve's `fileMemory()` ([`eveland/memory`](#evelandmemory), below).
