# eslint-plugin-intlayer

> 标签: eslint, eslint-plugin, eslintplugin, i18n, internationalization, intlayer, lint, oxlint

## 简介

ESLint (and oxlint) plugin for Intlayer. Catches untranslated strings and the dynamic call shapes the Intlayer compiler cannot optimize.

## 官网

- 官网：https://intlayer.org
- 源码仓库：git+https://github.com/aymericzip/intlayer.git
- npm 页面：https://www.npmjs.com/package/eslint-plugin-intlayer
