# easy-mrz-parser

> 标签: ID, MRZ, TD1, TD2, TD3, machine-readable-zone, parser, passport

## 简介

A JavaScript module for parsing Machine Readable Zone (MRZ) data from ID documents such as passports, ID cards. Supports TD1, TD2, and TD3 formats.
