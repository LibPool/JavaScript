# @modwrench/cli

> 标签: ai-tools, crash-analysis, load-order, mcp, mcp-server, modding, model-context-protocol, modio, nexus-mods, skyrim, steam-deck, thunderstore

## 简介

ModWrench — one MCP entry, every mod platform. Bundles all installed @modwrench/* platform packages into a single combined MCP server.
