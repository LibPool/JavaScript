# @powerduck/openapi-codegen

> 标签: api, browser, cjs, codegen, esm, generator, http-client, openapi, rest, swagger, typescript

## 简介

Generate runnable HTTP request examples from OpenAPI documents. 21 languages, 41 clients, browser-compatible, zero runtime dependencies.
