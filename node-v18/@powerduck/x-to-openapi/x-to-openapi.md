# @powerduck/x-to-openapi

> 标签: api, cjs, converter, curl, esm, openapi, postman, rest, swagger, typescript

## 简介

Extensible production-grade X-to-OpenAPI 3.2 conversion framework. Convert curl commands and Postman collections to OpenAPI 3.2 documents.
