# @forthink/sx-tool

> 标签: vue

## 简介

SX Tool是一个vue模板快速创建工具。 ###安装 `npm install @forthink/sx-tool` ###使用 使用`sx add <name>`创建页面文件或组件，按照提示步骤选择要创建的模板。 #####Options 使用`-f` `--force` 后缀覆盖原文件
