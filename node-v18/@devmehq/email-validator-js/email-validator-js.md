# @devmehq/email-validator-js

> 标签: batch-validation, cache, disposable-emails, email-checker, email-regex, email-typos, email-validation, email-validator, email-verification, free-emails, mx-records, rfc5321, smtp-verification, typescript

## 简介

Advanced email validation with MX records, SMTP verification, disposable email detection, batch processing, and caching. Production-ready with TypeScript support.
