# @zoblocks/copilot-react

> 标签: accessibility, ai, clinical-decision-support, headless, healthcare, react, wcag

## 简介

Headless React for ZoBlocks Copilot. Hooks and unstyled primitives that own state, keyboard, focus and ARIA — no design system, no styles.
