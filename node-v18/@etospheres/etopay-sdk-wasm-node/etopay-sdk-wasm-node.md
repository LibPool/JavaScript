# @etospheres/etopay-sdk-wasm-node

> 标签: blockchain, crypto, erc20, etopay, etospheres, evm, kyc, payments, wallet, web3

## 简介

This package provides ***WebAssembly (WASM)*** bindings for the ETOPay SDK, enabling seamless integration with both _Web_ applications and _NodeJS_ environments. It generates TypeScript type definitions for all relevant data objects, ensuring type safety
