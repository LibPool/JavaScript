# @openlinkos/vitepress-theme

> 标签: openlinkos, vitepress, vitepress-theme

## 简介

The shared VitePress theme of OpenLinkOS and LinkOS sites: brand, bilingual interface, language detection, metadata and a bilingual coverage check.
