# @ddd-ts-kit/s3

> 标签: clean-architecture, cloudflare-r2, ddd, domain-driven-design, file-storage, hexagonal-architecture, minio, object-storage, s3, typescript

## 简介

Adapter of the kernel FileStorage port on the S3 protocol (AWS S3, MinIO, OVHcloud, Scaleway, Cloudflare R2): streamed uploads, signed links, copy, move, listing.
