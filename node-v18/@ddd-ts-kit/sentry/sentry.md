# @ddd-ts-kit/sentry

> 标签: clean-architecture, ddd, domain-driven-design, error-reporting, error-tracking, glitchtip, hexagonal-architecture, sentry, typescript

## 简介

Error reporting to Sentry or GlitchTip behind the kernel ErrorReporter port: unexpected failures only, correlated with traces, scrubbed before sending.
