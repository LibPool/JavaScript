# @vitral/nuxt

> 标签: components, nuxt, nuxt-module, ssr, vitral, vue

## 简介

The Nuxt module for Vitral: the plugin from nuxt.config, auto-imported components and composables, the theme rendered on the server and the colour scheme in a cookie.
