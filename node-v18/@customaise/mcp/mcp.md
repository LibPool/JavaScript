> 标签: agentscripts, ai-tools, antigravity, browser-automation, chrome-extension, claude, claude-desktop, cli, codex, command-line, cursor, customaise, hitl, human-in-the-loop, kiro, mcp, mcpb, model-context-protocol, userscripts, webmcp

## 简介

MCP server and CLI bridging AI coding agents (Cursor, Claude Code, Codex, Kiro, Antigravity, Claude Desktop) to the Customaise Chrome extension. 19 tools: UserScripts, AgentScripts, WebMCP calls with HITL consent, visual DOM targeting, tab control. Drive
