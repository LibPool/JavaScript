# @larose-ui/enterprise-core

> 标签: enterprise, framework-agnostic, larose, larose-internal

## 简介

[Internal] Framework-agnostic audit store and UI schema helpers. Prefer @larose-ui/react, @larose-ui/vue, @larose-ui/svelte, or @larose-ui/runtime-* in apps.
