# @remit/logger-lambda

> 标签: JavaScript

## 简介

The logging seam every Remit service writes through. One JSON object per line on stdout, via [pino](https://getpino.io/). The exported `Logger` interface is what consuming code imports; the writer behind it is an implementation detail.
