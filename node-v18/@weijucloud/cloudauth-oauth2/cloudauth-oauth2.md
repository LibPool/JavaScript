# @weijucloud/cloudauth-oauth2

> 标签: authentication, cloudauth, cross-app, login, oauth2, profile-sync, realtime, register, sso, supabase

## 简介

CloudAuth OAuth2 SDK — 一行代码接入跨应用云端统一登录。支持注册、登录、修改资料、跨应用实时信息同步。
