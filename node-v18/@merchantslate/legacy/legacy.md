# @merchantslate/legacy

> 标签: arbitrum, avalanche, bsc, celo, crypto checkout, crypto payment, crypto payment gateway, crypto payment sdk, erc-20 payments, ethers, evm payments, merchant sdk, multi-chain, onchain crypto payment, onchain products, optimism, payment database, polygon, stablecoin payments, token rate, typescript, web3 payments

## 简介

Onchain crypto payment database SDK for EVM chains: accept crypto payments, manage products, register merchants, run staking and fetch live token rates in TypeScript for Node.js and the browser.
