# @sumologic/opentelemetry-rum

> 标签: opentelemetry, ot, rum, sumo, sumologic, tracing

## 简介

Adds OpenTelemetry tracing auto-instrumentation in the browser. Collects spans on network events and sends them to Sumo Logic.
