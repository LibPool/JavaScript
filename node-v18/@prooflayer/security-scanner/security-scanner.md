> 标签: agent-security, ai-safety, claude-code, cline, code-analysis, cursor, hallucination-detection, lightweight, llm-security, mcp, mcp-server, model-context-protocol, package-verification, prompt-injection, prooflayer, regex, sast, scanner, secrets-detection, security, sql-injection, vulnerability, windsurf, xss, zero-python

## 简介

Lightweight, zero-Python security scanner MCP server for AI coding agents. Fast install (~5s), 1700+ vulnerability rules with pure JavaScript regex engine, 4.3M+ package hallucination detection. For Claude Code, Cursor, Windsurf, Cline.
