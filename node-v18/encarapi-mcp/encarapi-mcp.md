# encarapi-mcp

> 标签: car export, che168, china car api, chinacarapi, claude, cursor, dongchedi, encar, encar api, kbchacha, kcar, korean car api, mcp, mcp server, model context protocol, used cars

## 简介

MCP server for EnCarAPI and ChinaCarAPI: live Korean (Encar, KB Chachacha, K Car) and Chinese (Dongchedi, Che168) used car listings for Claude, Cursor and other AI assistants.
