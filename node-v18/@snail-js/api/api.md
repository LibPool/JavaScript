# @snail-js/api

> 标签: api, axios, decorators, http, react, request, sse, typescript, vue, websocket

## 简介

Decorator-driven, plugin-first HTTP client built on axios. Nest.js-style decorators, an everything-is-a-plugin core and alova-style request strategies.
