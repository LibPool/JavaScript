# @linyun-host/cc-react

> 标签: cc-tweaked, cli, compiler, computercraft, gpu, jsx, lua, react, toms-peripherals

## 简介

React-style UI framework for CC: Tweaked + Tom's Peripherals GPU. The cc-react CLI compiles a .tsx app into a single Lua module whose start(side) runs as a simpleParallel task.
