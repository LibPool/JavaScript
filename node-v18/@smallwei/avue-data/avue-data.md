# @smallwei/avue-data

> 标签: JavaScript

## 简介

Avue-Data数据大屏(Vue全家桶+ElementUi+Echart+dataV)开发，丰富的交互控件和图表组件，提供智能图形推荐，报表图形任意切换，且不受维度,度量的限制。
