# @pipeworx/mcp-puerto-rico-code

> 标签: mcp, mcp-server, model-context-protocol, pipeworx, puerto-rico-code

## 简介

Puerto Rico statutes — 'leyes' (acts) of the Puerto Rico Legislature, section/article lookup and search, including the '33 LPRA 5001'-style citation to Leyes de Puerto Rico Anotadas (LPRA).
