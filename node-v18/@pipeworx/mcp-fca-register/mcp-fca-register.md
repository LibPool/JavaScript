# @pipeworx/mcp-fca-register

> 标签: fca-register, mcp, mcp-server, model-context-protocol, pipeworx

## 简介

FCA Financial Services Register MCP — the UK Financial Conduct Authority's public register of every FCA-regulated firm and individual (register.fca.org.uk): firm search, firm details by FRN, appointed representatives, and single-individual lookup by IRN.
