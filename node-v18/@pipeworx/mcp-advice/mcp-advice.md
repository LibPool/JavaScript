# @pipeworx/mcp-advice

> 标签: advice, mcp, mcp-server, model-context-protocol, pipeworx

## 简介

MCP server for the [Advice Slip API](https://api.adviceslip.com) — get random advice, search advice slips, and look up by ID. Free, no auth required.
