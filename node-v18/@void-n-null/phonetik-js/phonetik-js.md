# @void-n-null/phonetik-js

> 标签: linguistics, nlp, phonetics, prosody, rhyme, wasm

## 简介

Phonetic analysis engine for English. Rhyme detection, scansion, syllable counting. 126K-word embedded dictionary compiled to WASM.
