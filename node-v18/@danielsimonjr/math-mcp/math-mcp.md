# @danielsimonjr/math-mcp

> 标签: calculator, calculus, linear-algebra, mathematics, mathjs, matrix, mcp, model-context-protocol, performance, statistics

## 简介

MCP server for mathematical computations powered by MathTS (a mathjs-compatible TypeScript engine), with comprehensive input validation, security features, rate limiting, and expression caching
