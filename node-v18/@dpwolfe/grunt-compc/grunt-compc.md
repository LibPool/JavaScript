# @dpwolfe/grunt-compc

> 标签: actionscript, adobe, apache, compc, compiler, flash, flex, flex sdk, gruntplugin, open source

## 简介

A Grunt task plugin to compile Flash SWC files with the `compc` component compiler from the Apache/Adobe Flex SDK.
