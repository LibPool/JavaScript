# @engagifii/enhanced-data-table

> 标签: components, data-table, engagifii, react, shadcn, table, tailwind, typescript, ui

## 简介

A comprehensive, feature-rich data table component with advanced filtering, sorting, pagination, grouping, frozen columns, bulk actions, and custom cell rendering. Includes comprehensive demo showcasing all enterprise-grade features.
