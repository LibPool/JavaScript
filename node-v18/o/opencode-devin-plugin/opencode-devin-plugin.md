# opencode-devin-plugin

> 标签: ai, cognition, devin, opencode, opencode-plugin

## 简介

OpenCode plugin to drive cloud Devin sessions and use Cognition LLM models (SWE-1.7, Claude, GPT-5.6, etc.) from the OpenCode agent.
