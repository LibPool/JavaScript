# opencode-claude-code-acpbridge

> 标签: acp, agent-client-protocol, ai-sdk, anthropic, claude, claude-code, language-model, opencode, opencode-plugin, provider

## 简介

Use Claude Code inside OpenCode. An OpenCode plugin + model provider that bridges Claude Code over ACP (Agent Client Protocol): run it on your Claude subscription while OpenCode orchestrates the tools, permissions and TUI.
