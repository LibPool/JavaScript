# opencode-roadmap-plugin

> 标签: ai-agents, ai-tools, claude, minimax, opencode, opencode-plugin, product-roadmap, roadmap

## 简介

Generate product roadmaps and improvement ideas in opencode. /roadmap and /ideation slash commands print full output in chat (not just JSON files) so the data is in conversation context for follow-up questions.
