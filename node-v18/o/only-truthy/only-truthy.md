# only-truthy

> 标签: falsy, filter, object, truthy

## 简介

Returns a new object with ALL object properties with [falsy values](https://developer.mozilla.org/en-US/docs/Glossary/Falsy) removed. ## Install ```sh npm install only-truthy ```
