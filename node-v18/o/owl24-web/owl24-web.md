# owl24-web

> 标签: apm, observability, owl24, real-user-monitoring, rum, web-vitals

## 简介

Browser Real User Monitoring (RUM) SDK for owl24 — Core Web Vitals, page-load timing, and uncaught JS errors, sent to your owl24 dashboard.
