# omp-game-studio-extension

> 标签: agents, extension, game-development, game-studio, oh-my-pi, omp, opencode-game-studios, skills

## 简介

OpenCode Game Studios (OCGS) framework as an OMP (oh-my-pi) extension package: 52 game-studio agents, 77 skills, 77 slash commands, 11 path-scoped rules, plus runtime tools (question, ocgs_task, consult), audit logging, validation, drift detection, path-g
