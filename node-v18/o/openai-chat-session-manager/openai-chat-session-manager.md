# openai-chat-session-manager

> 标签: AWS, Chat Session Manager, DynamoDB, History, OpenAI, TypeScript, management

## 简介

OpenAI Chat Session Manager is a TypeScript module designed to manage chat sessions with an AI model (default : GPT-3.5 Turbo) through the OpenAI API.
