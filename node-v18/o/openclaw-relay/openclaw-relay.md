# openclaw-relay

> 标签: deskclaw, lan, local, openclaw, relay

## 简介

Local relay for DeskClaw — pairs your Mac with a remote OpenClaw host over LAN, no internet required.

- npm 页面：https://www.npmjs.com/package/openclaw-relay

## 获取地址

- npm registry：https://registry.npmjs.org/openclaw-relay
- Node 要求：>=14
