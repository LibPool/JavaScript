# openai-compatible_opencode-fix

> 标签: JavaScript

## 简介

OpenCode bundles an outdated @ai-sdk/openai-compatible that only supports image/* file parts. This package re-exports the latest version with support for PDF, audio, and text attachments. Use it as a drop-in replacement in your opencode.json config to byp
