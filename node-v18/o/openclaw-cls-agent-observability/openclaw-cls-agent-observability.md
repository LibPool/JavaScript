# openclaw-cls-agent-observability

> 标签: JavaScript

## 简介

[English](README_EN.md) OpenClaw 插件：把 Agent 执行过程导出为腾讯云 CLS Agent Trace。安装即用，不改 OpenClaw 任何配置与代码——调用链、Token 用量、工具调用、错误自动出现在 CLS 控制台的 Agent 可观测视图里。
