# og-preview

> 标签: og, og meta data, og preview, og-data, og-meta-data, open graph, open graph meta data, open graph preview, social media preview

## 简介

Generates a preview of all avaiable open graph meta data. Simply execute a CLI command and preview in the browser how all the links of your website will appear on social media platforms.
