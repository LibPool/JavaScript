# opencode-cc-hooks

> 标签: ai, claude, claude-code, hooks, opencode, opencode-plugin, plugin

## 简介

Minimal OpenCode plugin that bridges Claude Code hooks (PreToolUse, PostToolUse, UserPromptSubmit, Stop, PreCompact) to OpenCode's event system
