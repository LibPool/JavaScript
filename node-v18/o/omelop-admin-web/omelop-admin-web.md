# omelop-admin-web

> 标签: JavaScript

## 简介

omelop-admin-web is a web console for [omelop](https://gitee.com/fw-assets/omelop). it is based on [omelop-admin](https://gitee.com/fw-assets/omelop-admin). it is just an web console example, you can implement your style like web console.
