# otp-message-extractor

> 标签: 2fa, alphanumeric-otp, arabic, arabic-otp, authentication, email-otp, javascript, mfa, nodejs, one-time-password, otp, otp-detector, otp-extractor, otp-parser, passcode, receive-sms, sms-otp, sms-parser, temporary-number, typescript, verification-code, verification-code-extractor, virtual-number

## 简介

Dependency-free JavaScript OTP and verification code extractor for Arabic/English SMS text. Parses 4-8 digit and alphanumeric codes.
