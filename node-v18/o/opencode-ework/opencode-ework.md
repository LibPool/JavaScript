# opencode-ework

> 标签: agent-tools, ai-agent, gitea, issue-tracker, opencode, opencode-plugin

## 简介

Backend-agnostic issue-tracker plugin for OpenCode agents — tools: issue, comments, floor, reply, search. Speaks Gitea REST; works against real Gitea or any Gitea-compatible shim (e.g. ework-web).
