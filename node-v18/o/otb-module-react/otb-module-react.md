# otb-module-react

> 标签: TypeScript, antd, otb-module-react, react, react18, vite

## 简介

otb-module-react是基于现有的antd库进行的二次封装，简化组件的各自用法，将所有基础组件归纳于一个表单中， 集成表单组件，另还有预览图片/PDF的preview组件、上传文件的upload组件等等。 引入组件后以数据驱动组件从而加载Dom，让开发变得更简单，让代码更易维护。
