# opencode-session-keepalive

> 标签: anthropic, claude, cost-optimization, keepalive, opencode, opencode-plugin, plugin, prompt-cache

## 简介

opencode plugin that keeps idle sessions' prompt caches warm with minimal pings, and stops when it stops paying
