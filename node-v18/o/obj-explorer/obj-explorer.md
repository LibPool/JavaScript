# obj-explorer

> 标签: JavaScript

## 简介

这是用来递归搜索大对象的工具包, 可用来(不限于)在vuex,redux的大对象中，递归地按键名或按键值搜索.

## 官网

- 官网：https://github.com/ivuex/obj-explorer
- npm 页面：https://www.npmjs.com/package/obj-explorer
