# oasis-client-dep

> 标签: JavaScript

## 简介

即时通讯客户端, 部署在其它项目需要安装本项目所需要的loader 2.webpack alias @指向node_modules本项目 3.让相应loader可以处理本项目include配置额外数组指向本项目
