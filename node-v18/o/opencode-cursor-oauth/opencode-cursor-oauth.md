# opencode-cursor-oauth

> 标签: cursor, oauth, openai-compatible, opencode, opencode-plugin

## 简介

OpenCode plugin that connects Cursor's API to OpenCode via OAuth, model discovery, and a local OpenAI-compatible proxy.
