# openclaw-mpp

> 标签: agent-payments, ai-agents, http-402, machine-payments, mpp, openclaw, pay-per-use, stablecoin, tempo

## 简介

Let OpenClaw call pay-per-use APIs using MPP with automatic HTTP 402 payments and a capped Tempo Wallet access key.
