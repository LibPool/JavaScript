# openscad-customizer-web

> 标签: 3d-printing, cad, customizer, openscad, stl, three.js, wasm

## 简介

Auto-generated, in-browser 3D preview + STL export for OpenSCAD models — reads the official Customizer comment syntax so no per-project form code is needed.
