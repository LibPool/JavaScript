# opus-accumulator

> 标签: audio, concatenate, mediarecorder, ogg, opus, webm

## 简介

Append Opus audio chunks from any browser into a growing, always-valid, never-rewritten .opus file in pure JavaScript. Without FFmpeg, WASM, or re-encoding
