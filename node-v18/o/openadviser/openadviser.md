# openadviser

> 标签: adviser, advisor, ai-agent, browser-automation, chatgpt, chrome-extension, grok, openadviser, xiaohongshu

## 简介

Open-source adviser bridge that lets local AI agents consult ChatGPT, Grok, and other web AI providers through a Chrome extension.
