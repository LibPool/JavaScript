# oversea-login

> 标签: JavaScript

## 简介

efox-login是由Efox前端组开发的适用于web、pc接入UDB登录系统的工具类，包含手机验证码登录、用户名+密码登录、手机号注册、找密、第三方登录等方式 ## 接入准备 - appid申请：申请UDB业务标识 - 第三方平台应用申请和配置（按需）
