# oxlint-plugin-vue-sfc

> 标签: eslint-plugin-vue, linter, nuxt, oxc, oxlint, sfc, vue, vue3

## 简介

Vue SFC template rules for oxlint, as a JS plugin. Ports of eslint-plugin-vue rules oxlint has no native equivalent for.
