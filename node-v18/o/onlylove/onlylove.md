# onlylove

> 标签: JavaScript

## 简介

- webpack还可以用来打包JS库 - 要实现数学运算的功能 + - * / - 打包成压缩版和非压缩版 - 支持CJS/ESM方式导入   > commonjs require('zhufengmath');   > esm import e from 'es'
