# onvo-client

> 标签: api, client, nodejs, onvo, onvopay, pagos, typescript

## 简介

Onvo Client es un cliente de HTTP orientado a objetos para Node.js escrito en Typescript para interactuar de forma fácil con la API de Onvo.
