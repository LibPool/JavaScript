# opencode-vibeguard

> 标签: opencode, opencode-plugin, pii, privacy, redaction, secrets, vibeguard

## 简介

OpenCode 插件：参考 VibeGuard 的占位符格式（__VG_...__）在发送给 LLM 前脱敏、在响应完成后自动还原、在工具执行前还原参数
