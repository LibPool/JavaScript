# osf-export-templates

> 标签: JavaScript

## 简介

[Handlebars](http://handlebarsjs.com/)-templates for various osf export formats. They all accept a special format of shownotes which is documented below. There are handlebar-libs available for many languages, including [php](https://github.com/mardix/Hand
