# opencode-session-monitor

> 标签: monitor, opencode, opencode-go, opencode-plugin, session, sessions

## 简介

opencode 插件：TUI 侧边栏实时显示所有 session 的运行状态（busy/idle/error），支持鼠标 hover 高亮与点击切换，另附外部监控面板
