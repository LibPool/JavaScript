# ocmm

> 标签: codex-plugin, model-routing, multi-model, opencode, opencode-plugin

## 简介

OpenCode Multi-Model Auto-Router plugin (ocmm). Per-agent model selection, variant -> param translation, intent-keyword mode injection.
