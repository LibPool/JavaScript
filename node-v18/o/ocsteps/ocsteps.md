# ocsteps

> 标签: JavaScript

## 简介

ocSteps 是一个JavaScript异步执行辅助工具，主要用于支持 Node.js 中的大量异步API以及操作，以及前端浏览器里的异步任务（例如Ajax）。

- 源码仓库：git@github.com:OpenComb/ocSteps.git
- npm 页面：https://www.npmjs.com/package/ocsteps
