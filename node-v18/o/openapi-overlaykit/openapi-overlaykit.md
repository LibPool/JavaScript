# openapi-overlaykit

> 标签: jsonpath, oas, openapi, openapi-overlay, overlay, rfc9535, swagger, typescript

## 简介

Apply OpenAPI Overlay 1.0.0 documents using a strict, RFC 9535-compliant JSONPath engine (no eval).
