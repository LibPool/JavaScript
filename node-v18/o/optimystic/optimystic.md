# optimystic

> 标签: hooks, mutation, optimistic-ui, optimistic-update, react, react19, retry, rollback, server-actions, useActionState, useOptimistic

## 简介

Optimistic UI for React 19 Actions: rollback on error, retry with backoff, and a queue for concurrent mutations. ~2kB, no cache, no data layer.
