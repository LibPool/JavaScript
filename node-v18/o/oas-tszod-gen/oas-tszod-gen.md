# oas-tszod-gen

> 标签: oas to ts, oas to zod, oas-tszod-gen, oas3, oas3 code generator, open api, swagger code generator, zod generator

## 简介

A code generator to convert OpenApi version 3 (OAS3) specifications into endpoint caller functions for TS and Zod.
