# openvisor

> 标签: agentic, agents, anvos, openvisor, reserved

## 简介

Defensive name reservation held by the Anvos project (a desktop agentic operating layer). "OpenVisor" was a naming runner-up; the product ships as Anvos. This holds the npm name. Not a product. See the repository.
