# oxlint-plugin-react-prefer-use-effect-event

> 标签: eslint, eslint-plugin, eslintplugin, oxlint, oxlint-plugin, oxlintplugin, react

## 简介

An Oxlint / ESLint plugin that suggests wrapping calls to event handlers of your choice inside `useEffect` with `useEffectEvent`.
