# open-code-review-pi

> 标签: ai, code-review, ocr, open-code-review, pi, pi-coding-agent, pi-extension, pi-package

## 简介

pi coding agent extension for OpenCodeReview (ocr): /ocr-review commands and ocr_review / ocr_delegate tools for AI-powered code review of Git changes.
