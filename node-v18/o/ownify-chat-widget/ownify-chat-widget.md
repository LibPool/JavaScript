# ownify-chat-widget

> 标签: agent, agent-web, chat-widget, embeddable, ownify, vanilla-js

## 简介

Drop-in chat widget for embedding ownify agents on any website. Two lines of HTML or one npm import. Vanilla JS, no deps, MIT.
