# ouisys-dcb-widget

> 标签: carrier-billing, click2sms, dcb, mo, mobile-payments, one-click, ouisys, pin, subscription, ussd, widget

## 简介

Standalone carrier-billing subscription-flow widget (PIN, MO, MO-redirect, one-click, click-to-SMS, USSD). Ships as a self-contained UMD library that exposes OuisysSubscribe.
