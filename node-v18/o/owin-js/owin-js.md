# owin-js

> 标签: JavaScript

## 简介

Open Web Interface for Node.js (OWIN-JS). A lightweight REST framework for Node.js. Open-source, standards-based, drop-in replacement for Connect, Express, and Koa, with built-in seamless bridging to HTTP, COAP and OWIN servers
