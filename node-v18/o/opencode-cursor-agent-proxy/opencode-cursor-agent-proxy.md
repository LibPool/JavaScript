# opencode-cursor-agent-proxy

> 标签: cursor, cursor-agent, openai-compatible, opencode, plugin, proxy

## 简介

OpenCode plugin: transparent Cursor agent proxy with OpenAI-compatible API. Starts a local HTTP server that translates OpenAI chat completions into cursor-agent CLI calls, and injects cursor-acp provider config into OpenCode.
