# obsidian-cli-mcp

> 标签: JavaScript

## 简介

A [Model Context Protocol](https://modelcontextprotocol.io) server that wraps the [Obsidian CLI](https://help.obsidian.md/cli), allowing AI assistants like Claude to execute Obsidian CLI commands.
