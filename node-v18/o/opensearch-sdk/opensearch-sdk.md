# opensearch-sdk

> 标签: JavaScript

## 简介

阿里云OpenSearch api的sdk，基于@alicloud/opensearch-sdk 1.0的改进。 由于官方sdk存在一些小问题，且维护不活跃，所以才有此package。

## 官网

- 官网：https://github.com/imbooo/alibabacloud-opensearch-sdk
- npm 页面：https://www.npmjs.com/package/opensearch-sdk
