# opencode-kimi-code-statusline

> 标签: kimi, kimi-code, kimi-for-coding, moonshot, opencode, opencode-plugin, quota, statusline, usage

## 简介

OpenCode TUI plugin: display Kimi For Coding (Kimi Code) subscription quota (rolling 5h / weekly) in the footer statusline. V2-native, zero-config, no cookies.
