# osticket-nodejs-api-wrapper

> 标签: nodejs, osticket

## 简介

osTicket API wrapper for nodeJS. Simple and easy to use. This package will allow your application to make an API request for creating new support tickets using the open source ticketing system osTicket (https://github.com/osTicket/osTicket).
