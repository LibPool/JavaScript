# omnipr

> 标签: bitbucket, git, github, gitlab, pr, pull request

## 简介

OmniPR creates pull requests across Git providers like GitHub, GitLab, Bitbucket, etc. It’s modular, provider-agnostic, and works in Node.js/browser.
