# opencode-gen-ui

> 标签: ai, generative-ui, genui, mcp, opencode, opencode-plugin, solidjs, visualization

## 简介

Generative UI toolkit for OpenCode AI agents — reactive Solid.js widgets (charts, tables, maps, diagrams, 3D), sandboxed iframe rendering, and OpenCode tool/plugin integration.
