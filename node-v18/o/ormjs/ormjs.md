# ormjs

> 标签: arango, arangodb, database, document, mongo, mongodb, nosql, odm, orm, ormjs

## 简介

ORMjs this is javascript OOP interface to Database. Its use ArangoDB, but later I will add drivers for other databases (such as mongodb).
