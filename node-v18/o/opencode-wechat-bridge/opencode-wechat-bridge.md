# opencode-wechat-bridge

> 标签: agent-bridge, ilink, opencode, opencode-plugin, wechat, wechat-bridge, weixin

## 简介

OpenCode plugin that bridges Tencent OpenClaw personal WeChat to OpenCode: inbound DMs become prompts, agent replies are pushed to WeChat, and the agent gets a wechat_notify tool.
