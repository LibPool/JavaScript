# openui-forge

> 标签: agent-skill, claude-code, generative-ui, openui, pi-package, pi-skill, skill

## 简介

Cross-IDE, multi-stack agent skill for OpenUI (the Open Standard for Generative UI). Core skill plus stack variants for OpenAI, Anthropic, LangChain, Vercel, Python, Go, Rust, C#, Java, Ruby, PHP, Elixir.
