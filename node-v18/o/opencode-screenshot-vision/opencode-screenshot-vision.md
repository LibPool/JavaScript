# opencode-screenshot-vision

> 标签: accessibility, browser, mcp, ollama, opencode, opencode-plugin, playwright, screenshot, testing, vision

## 简介

OpenCode plugin: let a text-only LLM read browser screenshots via local Ollama with OpenCode Zen fallback.
