# opencode-forgecode

> 标签: ai-agent, forge, forgecode, graph, harness, iterative-loops, opencode, plugin

## 简介

opencode-forgecode — forge loops, graph indexing, sandbox, plan storage, plus the forgecode harness (system prompts, summary-frame compaction, truncation, doom-loop, pending-todos, undo snapshots) and forge/sage/muse agents.
