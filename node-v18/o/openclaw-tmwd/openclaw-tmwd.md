# openclaw-tmwd

> 标签: automation, browser, cdp-free, openclaw, tampermonkey

## 简介

Tampermonkey WebDriver for OpenClaw — control user's real Chrome browser via injected userscript. Reuses login state, doesn't steal mouse cursor.
