# opencode-taskflow

> 标签: mcp, opencode, orchestration, subagents, taskflow, workflow

## 简介

Run taskflow on OpenCode: an OpenCode subagent runner plus an MCP server (and an opencode.json config scaffold) that exposes the taskflow_* tools to OpenCode users.
