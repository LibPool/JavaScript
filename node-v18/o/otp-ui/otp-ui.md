# otp-ui

> 标签: angular-otp, ng-otp, ng-otp-input, ng-otp-ui, one time password, otp verification, otp-UI, otp-angular, otp-verify, verifyotp

## 简介

A fully customizable, one-time password input component with Angular.    Values of every input parameter in otp object can be changed as per user requirement. If not, default values will be considered.
