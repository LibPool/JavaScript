# opencode-idle-poke

> 标签: assistant, idle, opencode, opencode-plugin, proactive, reminder

## 简介

An OpenCode plugin that proactively sends you a message when you have been silent for a while, with a configurable interval, per-session on/off markers, and an optional adaptive interval. Not usable in one-shot CLI mode.
