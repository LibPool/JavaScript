# orchid-sdk

> 标签: capture, debugging, llm, observability, orchid, proxy, replay

## 简介

Thin TypeScript SDK for Orchid — the Orchestration Interactive Debugger. Routes outbound LLM requests through the local Orchid Proxy for capture, replay, and interactive debugging.
