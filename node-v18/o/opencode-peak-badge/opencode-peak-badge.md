# opencode-peak-badge

> 标签: deepseek, opencode, opencode-plugin, peak-hours, tui

## 简介

OpenCode TUI plugin: live [PEAK]/[OFF-PEAK] badge for any model with configured peak hours. Provider-agnostic; ships with DeepSeek defaults.
