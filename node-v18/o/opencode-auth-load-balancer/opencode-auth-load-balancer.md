# opencode-auth-load-balancer

> 标签: anthropic, claude, codex, kimi, kimi-code, load-balancer, oauth, openai, opencode, opencode-plugin

## 简介

Load-balance opencode requests across multiple Anthropic (Claude) and OpenAI (Codex) OAuth accounts and Kimi Code subscriptions, weighted primarily by weekly usage with drain-before-reset scheduling.
