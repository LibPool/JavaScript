# opencode-triage

> 标签: ai-coding-agent, opencode, opencode-plugin, router, skill-discovery, skills, token-optimization, triage

## 简介

Deterministic skill router for OpenCode — saves ~90% tokens by hiding skills from the system prompt and routing via keyword matching
