# oiii

> 标签: JavaScript

## 简介

1、全局安装 ``` > npm i oiii -g ``` 2、初始化项目（项目目录） ``` > bot init > bot init 1 # 覆盖已有文件 ``` 3、开启图像界面服务 ``` > bot open ui ``` 4、关闭图像界面服务 ``` > bot close ui ``` 默认访问端口： 请求代理端口为：80 对应静态资源访问路径为：localhost/admin 相应服务请求端口：8080 请求代理修改文件：./proxy.mjs
