# openapitest

> 标签: integration test, operapi, swagger

## 简介

The purpose of this openapitest framework is to simplify authoring, organizing, executing, and reporting result of API tests using API specification. It runs on node.js and distributed via npm. Add this module to your node.js project as a development depe
