# ok-lib

> 标签: betalen, ok, okbetalen, okit

## 简介

OK provides a powerful JavaScript API for allowing a better interaction between your custom applications and the OK services. This API is known as OK LIB. It gives easy access to OK services such as OK OPEN and OK CASH.
