# ordinales-js

> 标签: apocope, cardinal-to-ordinal, español, números-ordinales, ordinal, ordinal-es, ordinal-numbers, ordinales, spanish, spanish-numbers, spanish-ordinal

## 简介

Librería para convertir números cardinales a ordinales en español. Spanish ordinal numbers library with gender and apocope support.
