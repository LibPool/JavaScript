# octet

> 标签: absurd, abusrdjs, browser, browserify, cdn, engine, ie, javascript, js, jsdelivr, micro, microjs, node, nodejs, template, tpl

## 简介

1kb template engine for the browser and nodejs. Support helpers, partials and more. Used in AbsurdJS.
