> 标签: atproto, bluesky, brave, duckduckgo, google-news, ietf, mdn, opencode, opencode-plugin, plugin, rfc, search, specifications, w3c, web-search, whatwg, wikipedia

## 简介

OpenCode plugin that provides web search tools using DuckDuckGo, Brave, Google News, Wikipedia, Bluesky, MDN Web Docs, and the IETF, W3C and WHATWG specifications.
