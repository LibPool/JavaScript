# ordermendpoints-scanner

> 标签: api, axios, endpoints, express, joi, openapi, registry, scanner, swr, yup, zod

## 简介

AST-based API endpoint scanner for Express + SWR/axios/fetch codebases. Infers request shapes from Joi, Zod, and Yup schemas. Optionally enriches the registry with Claude-generated descriptions and gap-fills. Emits a unified JSON registry for the Ordermen
