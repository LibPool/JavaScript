# oyeboss

> 标签: Agentic, framework, humanetech

## 简介

BOSS (Build Out Solid Stuff) — Claude Code skills, agents and a conscience for founders: sets a project up with only the structure it has earned, grows it through modes (Quickstart → MVP → V1 → Scale), and says one thing when you drift. Make it real.
