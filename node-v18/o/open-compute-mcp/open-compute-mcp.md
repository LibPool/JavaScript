# open-compute-mcp

> 标签: ai-tools, automation, claude, claude-desktop, computer-use, computer-use-mcp, desktop-automation, glama, gui-automation, mcp, mcp-server, mcp-stdio, model-context-protocol, screenshot, uia, windows

## 简介

npm launcher for the open-compute MCP server: model-agnostic computer-use tools (screenshot capture, canonical safety-gated actions, Windows UIA element targeting) over MCP stdio. Spawns the Python open-compute server (from GitHub).
