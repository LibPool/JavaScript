# opticore-social-auth-provider

> 标签: opticore-social-auth-provider

## 简介

opticore auth provider implements the OAuth 2.0 Authorization Code + PKCE flow for user registration via a Google, Facebook or X (Twitter) account, without depending on Passport or the official JavaScript SDKs of the platforms.
