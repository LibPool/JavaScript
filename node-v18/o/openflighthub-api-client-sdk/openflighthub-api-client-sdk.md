# openflighthub-api-client-sdk

> 标签: dji, drone, flight, hub

## 简介

This is a typescript sdk made to talk to the [OpenFlightHub Api](https://hub.openflighthub.org/api). **It must be run in the browser!**

## 官网

- 官网：https://openflighthub.org
- 源码仓库：git+https://github.com/openflighthub/api-client-sdk-typescript.git
- npm 页面：https://www.npmjs.com/package/openflighthub-api-client-sdk
