# optin-token

> 标签: cloudflare-workers, confirmation-token, double-opt-in, edge, email, email-confirmation, hmac, list-unsubscribe, magic-link, newsletter, one-click-unsubscribe, opt-in, rfc-8058, rfc8058, serverless, signed-token, unsubscribe, web-crypto, webcrypto, workers, zero-dependencies

## 简介

Dependency-free double-opt-in confirmation tokens + one-click (RFC 8058) unsubscribe headers. Web Crypto only — runs on Cloudflare Workers with no nodejs_compat, plus Deno, Bun, browsers, and Node 20+.
