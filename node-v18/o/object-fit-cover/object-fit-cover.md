# object-fit-cover

> 标签: background-size: cover, cover, image, object-fit, picture, picturefill, polyfill, respimg, responsive images, srcset

## 简介

A polyfill for the background-image cover effect combined with responsive image behaviour with the `<img>` or `<picture>` element.
