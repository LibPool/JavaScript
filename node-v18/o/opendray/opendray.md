# opendray

> 标签: ai-coding-agent, antigravity, claude-code, cli, codex, gateway, opendray, self-hosted, slack, telegram

## 简介

Self-hosted gateway that runs Claude Code / Codex / Antigravity / shell sessions on your own infrastructure. CLI installer wrapper around the official Go release binary.
