# opacus-sdk

> 标签: 0g, agent, did, escrow, h3, infrastructure, nitro, opacus, routing, web3

## 简介

API control plane for agent infrastructure: identity (DID), low-latency routing (Nitro), geo-policy (H3), storage (0G), and settlement (Pay/Escrow).
