# olvue-ui

> 标签: JavaScript

## 简介

- 初始化vue项目: vue create demo - 安装组件库: npm install olvue-ui - 由于该组件库是使用sass编写的，因此还需要安装:npm install sass sass-loader - 导入方式有两种选择：   1. 全局导入：在main.js写下以下内容： ``` import Vue from 'vue' import OlUI from 'olvue-ui' Vue.use(OlUI) ``` 以上代码已经完成了olvue-ui的导入。   2. 组件按
