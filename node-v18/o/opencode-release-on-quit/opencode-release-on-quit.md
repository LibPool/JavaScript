# opencode-release-on-quit

> 标签: mcp, memory, opencode, opencode-plugin, opencode-tui

## 简介

OpenCode TUI plugin that releases a project's cached MCP/LSP services when you quit, and sweeps every loaded location once the last OpenCode client exits.
