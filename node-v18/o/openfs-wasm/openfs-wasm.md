# openfs-wasm

> 标签: ai-agent, fts5, grep, in-browser, just-bash, llm, openfs, sandbox, sqlite, virtual-filesystem, wasm

## 简介

Sandboxed virtual filesystem for AI agents. One import, one call — runs in Browser, Node.js, Bun, Deno. No native code.
