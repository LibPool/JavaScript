# openarch

> 标签: ai-agent, automation, bun, cli, docker, llm, openrouter, sandbox

## 简介

CLI agent that containerizes GitHub repos on the fly, runs them in isolated Docker sandboxes, and exposes their CLIs as dynamic LLM tools.
