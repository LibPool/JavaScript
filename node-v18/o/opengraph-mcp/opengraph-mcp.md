# opengraph-mcp

> 标签: mcp, meta-tags, og, open-graph, opengraph, seo, social-media, twitter-card

## 简介

MCP server to inspect and analyze Open Graph meta tags from any URL. Get scores, issues, and suggested meta tags.

- 源码仓库：git+https://github.com/midudev/opengraph.to.git
