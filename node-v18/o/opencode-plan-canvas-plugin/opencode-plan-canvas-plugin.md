# opencode-plan-canvas-plugin

> 标签: canvas, live-reload, opencode, opencode-plugin, plan, plugin, watch

## 简介

Optional opencode plugin that auto-spawns (or nudges) an opencode-plan-canvas watch server when a plan or boulder file changes
