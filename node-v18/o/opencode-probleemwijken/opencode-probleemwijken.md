# opencode-probleemwijken

> 标签: derkolk, gen-z, harrykoster, notifications, opencode, opencode-2, opencode-plugin, probleemwijken, random, sound, soundboard

## 简介

OpenCode plugin that plays random Probleemwijken/Derkolk sounds and sends push notifications when a session completes. Supports OpenCode 2 and OpenCode 1.
