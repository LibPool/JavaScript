# opencode-speak-tts

> 标签: edge-tts, opencode, opencode-plugin, opencode-tui, read-aloud, speech, text-to-speech, tts, voice

## 简介

Speak OpenCode answers aloud on Windows. Microsoft Edge neural voices (free, no API key), en-US and tr-TR, with optional LLM summarisation through OpenCode's own model.
