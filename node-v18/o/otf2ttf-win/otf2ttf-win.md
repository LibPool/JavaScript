# otf2ttf-win

> 标签: otf, ttf, win10

## 简介

* 集成了python3.8,如果python3.8被河蟹请自行添加环境变量python-win-3_8 * windows版本仅在win 10测试过,欢迎issue * 暂时没有可调试机器,所以没有添加 mac / linux 版本 * otf转ttf,开箱可用
