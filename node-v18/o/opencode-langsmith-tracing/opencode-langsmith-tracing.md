> 标签: agent, agentic, ai, claude-code, cost-tracking, langchain, langsmith, langsmith-tracing, llm, llm-observability, llm-tracing, observability, opencode, opencode-plugin, runtree, telemetry, trace, tracing, typescript

## 简介

LangSmith tracing plugin for opencode — traces sessions, LLM calls, tool calls, reasoning, and context compaction. Trace taxonomy compatible with the official langsmith-claude-code-plugins.
