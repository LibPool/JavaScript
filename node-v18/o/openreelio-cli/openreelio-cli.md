# openreelio-cli

> 标签: agent, ai-agent, captions, cli, ffmpeg, ffmpeg-alternative, headless, mcp, mcp-server, nle, render, timeline, transcription, video, video-editing

## 简介

Headless, agent-native video editing CLI and MCP server. Cut, trim, caption, analyze and render real timelines from natural language or scripts instead of hand-writing ffmpeg filtergraphs.
