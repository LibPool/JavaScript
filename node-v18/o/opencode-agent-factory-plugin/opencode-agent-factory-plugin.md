# opencode-agent-factory-plugin

> 标签: agent-factory, consensus, dag, dynamic-agents, multi-agent, opencode, opencode-plugin, orchestration, parallel-agents

## 简介

Dynamic multi-agent orchestration for OpenCode. Analyzes prompts, generates specialized agents at runtime, executes in parallel with consensus strategies.
