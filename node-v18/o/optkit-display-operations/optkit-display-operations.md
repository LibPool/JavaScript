# optkit-display-operations

> 标签: automotive, custom-element, framework-agnostic, operations, repair, shadow-dom, vanilla-js, web-component

## 简介

Framework-agnostic Web Component suite for displaying automotive repair operations details. Pure vanilla JS, Shadow DOM isolated, no runtime dependencies. Bundles OptKitRepairMethods and its shared OptKitWebCore theme/i18n module.
