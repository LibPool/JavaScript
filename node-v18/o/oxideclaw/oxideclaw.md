# oxideclaw

> 标签: ai, claude, cli, coding-agent, ollama, rust

## 简介

Single-binary coding agent: zero-setup codebase index, cost-aware model routing, worktree agents, auto-fix loop, voice cloning, autonomous browser, ACP for editors. Claude, Ollama, OpenAI-compatible.
