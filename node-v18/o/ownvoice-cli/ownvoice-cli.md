# ownvoice-cli

> 标签: agent-native, cli, fine-tuning, local-first, lora, peft, pocket-tts, pytorch, text-to-speech, tts, voice-cloning

## 简介

Train a LoRA voice adapter for pocket-tts and keep the result on your own disk, not an API subscription. npx-installable wrapper around the ownvoice Python CLI for agent and Node-first environments.
