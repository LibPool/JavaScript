# one-timer

> 标签: JavaScript

## 简介

思考如下问题: 当我们需要延迟执行代码，这种情况一多，我们就需要同时创建很多个定时器。当我们的页面同时持有很多定时器的时候，这会耗费很多不必要的计算机资源。 ```javascript setTimeout(() => {}, 100) setTimeout(() => {}, 200) setTimeout(() => {}, 300) setTimeout(() => {}, 400) setTimeout(() => {}, 500) ... ```
