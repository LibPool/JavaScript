# origin-snapshot

> 标签: backup, export, import, indexeddb, localstorage, migration, opfs, origin, sessionstorage, snapshot

## 简介

Export and restore a browser origin's localStorage, sessionStorage, IndexedDB, and OPFS as a single gzip-compressed snapshot file.
