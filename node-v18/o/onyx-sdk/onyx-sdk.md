# onyx-sdk

> 标签: agent, ai, custody, dwallet, encrypt, fhe, ika, keyless, mpc, privacy, qvac, sdk, solana, umbra

## 简介

The developer SDK for building secure, private, AI-powered financial applications on Solana. Keyless custody (Ika), financial privacy (Umbra), encrypted computation (Encrypt), and local AI (QVAC) — one package.
