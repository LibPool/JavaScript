# opencode-see

> 标签: cerebras, gemini, groq, opencode, opencode-plugin, vision

## 简介

OpenCode plugin: describe images using free Gemini, Groq, and Cerebras vision models with configurable fallback order. Compatible with OpenCode V1 and V2.
