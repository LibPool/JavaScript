# ol-react-acceptjs

> 标签: accept.js, authorize.net, credit-card, payment, react

## 简介

A lightweight, modern React implementation of Authorize.net's Accept.JS library for easily submitting credit card information to the Authorize.net platform. Fork of react-acceptjs.
