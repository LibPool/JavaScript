# opencode-session-spawn

> 标签: opencode, orchestration, plugin, session, spawn, unattended

## 简介

opencode 会话生成原语：创建新顶层会话并注入起始语句，用于无人值守长任务编排（工具 spawn_session + 命令 @spawn）。
