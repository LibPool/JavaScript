# oxzof-nosql

> 标签: JavaScript

## 简介

A lightweight NoSQL-style database built on SQLite. Stores JSON data with auto-increment _id and supports MongoDB-like operations (insertOne, find, findOne). Ideal for simple, file-based NoSQL solutions.
