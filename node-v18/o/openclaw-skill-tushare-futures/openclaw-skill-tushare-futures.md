# openclaw-skill-tushare-futures

> 标签: futures, openclaw, quant, skill, tushare, 期货, 量化

## 简介

Tushare 期货数据接口集合 - 提供行情、基础信息、仓单、结算、持仓排名、指数等14个明确的数据接口。⚠️ 此技能需要 Python 3.12+ 及 tushare、pandas 库，请手动安装依赖。
