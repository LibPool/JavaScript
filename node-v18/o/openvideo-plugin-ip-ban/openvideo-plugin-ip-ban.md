# openvideo-plugin-ip-ban

> 标签: auto-ban, geo, ip-ban, openvideo, plugin, rate, region, security, traffic

## 简介

OpenVideoAPI 自动封禁插件：按 IP 请求数 / 流量超限自动封禁（阈值可调），安全中心白名单 IP 除外，支持按 IP 地区屏蔽（ip2region）
