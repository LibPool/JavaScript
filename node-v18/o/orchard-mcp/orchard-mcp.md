# orchard-mcp

> 标签: diarization, mcp, modelcontextprotocol, portuguese, spanish, speech-to-text, transcription, whisper

## 简介

MCP server for the Orchard speech-to-text API: transcription, speaker diarization and usage for Spanish/Portuguese-first audio.
