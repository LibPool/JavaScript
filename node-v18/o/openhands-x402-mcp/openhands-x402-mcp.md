# openhands-x402-mcp

> 标签: cross-border, elizaos, iso20022, mcp, openhands, settlement, x402, xrpl

## 简介

OpenHands MCP server for the mcp-402-gateway — pay-per-call cross-border settlement via x402 + ISO 20022 (XRPL TESTNET/altnet). Exposes the gateway's whole tool surface over stdio MCP and pays the HTTP-402 rail per call.
