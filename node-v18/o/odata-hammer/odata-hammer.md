# odata-hammer

> 标签: JavaScript

## 简介

##OData Hammer is app designed to provide the following feature to users: - Download a OData ServiceUrl Metadata and all Collections - Generate OData Metadata and Collection JSON file from an Excel Spreadsheet - Convert a Excel file to a ODATA collection
