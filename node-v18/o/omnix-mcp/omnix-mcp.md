# omnix-mcp

> 标签: claude, cursor, mcp, model-context-protocol, omnix, twitter, twitter-api, x, x-api

## 简介

Official OmniX MCP server — use the X (Twitter) API (search, users, tweets, posting, DMs, articles) inside Claude, Cursor, and any MCP client.
