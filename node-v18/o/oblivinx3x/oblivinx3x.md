# oblivinx3x

> 标签: b-plus-tree, database, document, embedded, key-value, lsm, mongodb, mvcc, neon, nosql, rust, sqlite, storage-engine, typescript

## 简介

Oblivinx3x — High-Performance Embedded Document Database. Hybrid B+/LSM engine with MVCC, ACID transactions, and MongoDB-compatible query language. Zero configuration, single-file, in-process.
