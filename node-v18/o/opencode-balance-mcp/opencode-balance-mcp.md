# opencode-balance-mcp

> 标签: balance, mcp, model-context-protocol, opencode, opencode-go, opencode-zen, quota, usage

## 简介

MCP server for querying OpenCode subscription data: Go quota (rolling/weekly/monthly usage) and Zen prepaid balance. Zero dependencies.
