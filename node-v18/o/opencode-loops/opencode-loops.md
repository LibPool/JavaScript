# opencode-loops

> 标签: JavaScript

## 简介

Structured, repeatable workflow loops for OpenCode — Build, Feature, Refactor, Performance, Bug, and Security — driven to verified completion by an independent goal-verifier. Zero-config install: registers itself with OpenCode on install.
