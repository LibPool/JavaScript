# okjike-cli

> 标签: ai-agent-tools, cli, command-line, command-line-app, jike, jike-cli, jike-sdk, mcp-tools, okjike, terminal, 即刻

## 简介

即刻 (Jike) 非官方命令行工具，基于 jike-sdk，调用即刻移动端 App API (api.ruguoapp.com)，实现在终端中登录与发动态等 即刻App 的功能。
