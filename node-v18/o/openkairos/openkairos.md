# openkairos

> 标签: ai, anthropic, cli, coding-agent, gemini, openai, security, tui

## 简介

Kairos — a secure, provider-agnostic terminal coding agent with a beautiful TUI. 50+ providers, bring your own key, zero telemetry, zero runtime dependencies.
