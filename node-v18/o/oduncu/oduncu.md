# oduncu

> 标签: agent-skill, agents-md, antigravity, claude-code, codex, cursor, gemini-cli, silent, skill, terse

## 简介

Silent-executor mode for coding agents. Give it a task, it says "yaparım...", works, says "tamam." Nothing in between.
