# omp-headroom

> 标签: compression, context, cuda, headroom, llm, omp, proxy, rocm, token

## 简介

Headroom context-compression integration for OMP: proxy lifecycle, tool-output compression, session archive compaction with CCR retrieval, adaptive thresholds, and a live savings widget.
