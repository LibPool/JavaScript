# onvaou-itineraires-mcp

> 标签: bicycle, cycling, europe, geocoder, geocoding, mcp, motorcycle, openstreetmap, routing, scooter, wheelchair

## 简介

MCP server for the « On va où ? » Routing API: address geocoding, and bike, e-bike, kick scooter, motorcycle, wheelchair and walking routes across Europe, with safety indicators.
