# odin-print-farm-mcp

> 标签: JavaScript

## 简介

MCP server for 3D print farm operations — live tools for queue, jobs, printers, inventory, alerts, maintenance (v2); plus v1 reference tools for cost calculation, printer recommendations, farm capacity planning. Powered by O.D.I.N.
