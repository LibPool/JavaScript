# omp-ntfy

> 标签: alerts, notifications, ntfy, oh-my-pi, omp, pi, pi-coding-agent, pi-extension, pi-package, push-notifications

## 简介

Zero-friction, 100% free phone push notifications for oh-my-pi and pi via ntfy.sh: one-shot arming (/ntfy once), task completion summaries, and input waiting alerts.
