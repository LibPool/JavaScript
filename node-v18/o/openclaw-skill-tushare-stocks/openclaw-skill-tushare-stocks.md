# openclaw-skill-tushare-stocks

> 标签: a-shares, openclaw, quant, skill, stocks, tushare

## 简介

Tushare 股票数据接口集合 - 提供行情、基础信息、基本面、特色数据等23个明确的A股数据接口。作为 OpenClaw 技能提供,⚠️ 此技能需要 Python 3.12+ 及 tushare、pandas 库，请手动安装依赖。
