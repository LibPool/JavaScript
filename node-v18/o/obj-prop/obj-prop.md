# obj-prop

> 标签: JavaScript

## 简介

A clear and simple way to validate and manipulate properties of an object. All the methods are:  * `hasNoProperties` * `hasProperties` * `hasTheseProperties` * `deleteProperties` * `nullProperties` and  * `clearProperties`
