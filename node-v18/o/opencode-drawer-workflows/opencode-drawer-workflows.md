# opencode-drawer-workflows

> 标签: agents, opencode, opencode-plugin, tui, workflows

## 简介

Deterministic multi-agent workflows for OpenCode — script agent/pipeline/parallel/phase with journaled replay, plus a native /workflows-style TUI viewer.
