# orz-mdhtml-browser

> 标签: browser, cdn, markdown, orz-markdown, orz-mdhtml

## 简介

Prebuilt in-browser renderer for orz-mdhtml .md.html files (exposes window.orzmd.render). Served via CDN (jsDelivr).

## 官网

- 官网：https://markdown.orz.how/family.html#mdhtml
- 源码仓库：git+https://github.com/wangyu16/orz-mdhtml.git
