# ol-map3

> 标签: openlayers, plot, typescript, vue3

## 简介

Vue 3 + TypeScript + Vite + openlayers 实现2D地图，提供打点、搜索、卷帘分析、热力图、克尔金等值面分析、缓冲区渲染分析、测绘、标绘、逆地理编码、距离测量、面积测量、添加标记点线面等功能。
