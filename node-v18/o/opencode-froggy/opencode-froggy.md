# opencode-froggy

> 标签: ai-agent, automation, cli, code-review, code-simplification, developer-tools, hooks, llm, opencode, opencode-plugin, plugin

## 简介

OpenCode plugin with a hook layer (tool.before.*, session.idle...), agents (code-reviewer, doc-writer), and commands (/review-pr, /commit)
