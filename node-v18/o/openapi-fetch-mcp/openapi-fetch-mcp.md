# openapi-fetch-mcp

> 标签: mcp, openapi

## 简介

OpenAPIエンドポイントをModel Context Protocol（MCP）ツールとして登録するCLIツールです。CursorなどのMCPクライアントを通じてAPIリクエストを実行できます。
