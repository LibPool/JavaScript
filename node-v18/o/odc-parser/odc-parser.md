# odc-parser

> 标签: parser, sql

## 简介

ODC-Parser-JS provides a JavaScript version of SQL Parser along with a Out-of-the-box Monaco Plugin. It currently supports OceanBase MySQL and OceanBase Oracle SQL dialect.  ![Demo](docs/images/demo.png) ## Features
