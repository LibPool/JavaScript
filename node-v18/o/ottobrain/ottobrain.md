# ottobrain

> 标签: anthropic, claude-code, codex, context-window, cursor, llm, openai, proxy, token-compression

## 简介

Local proxy that compresses LLM tool results before they reach the API. Saves 80-95% of context tokens. Works with Claude Code, Cursor, Codex CLI, and any OpenAI-compatible tool.
