# obscura-node

> 标签: ai-agent, anti-detection, browser-automation, cdp, chrome-devtools-protocol, crawler, headless-browser, headless-chrome-alternative, lightweight-browser, obscura, playwright, puppeteer, rust-browser, stealth-browser, v8, web-automation, web-scraping

## 简介

Node.js wrapper for Obscura — the Rust-powered headless browser for AI agents and web scraping. Drop-in replacement for headless Chrome with Puppeteer and Playwright. Ultra-lightweight (~30 MB), instant startup, built-in stealth mode.
