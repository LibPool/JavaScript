# orca-playwright-bridge

> 标签: browser-automation, cdp, chrome-devtools-protocol, orca, playwright

## 简介

Drive the Orca app's embedded Chromium browser with Playwright (or raw CDP) by bridging its internal Chrome DevTools Protocol proxy.
