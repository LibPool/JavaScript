# omp-session-store

> 标签: history, oh-my-pi, omp, omp-extension, omp-plugin, pi, pi-agent, pi-extension, pi-package, search, session, session-store

## 简介

Offline session search tool for oh-my-pi (OMP) and pi-agent — search completed/archived sessions by keyword, content, or time range. Returns structured JSON. No TUI required.
