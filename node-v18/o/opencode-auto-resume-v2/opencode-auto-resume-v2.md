# opencode-auto-resume-v2

> 标签: auto-resume, llm, opencode, opencode-plugin, opencode-v2, plugin, stall-detection

## 简介

OpenCode v2 plugin adapter for opencode-auto-resume (stall detection + auto-continue). Runs the unchanged v1 recovery engine on OpenCode 2.x.
