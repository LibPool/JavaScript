# orizn

> 标签: api, country-data, immigration, multilingual, orizn, passport, sdk, travel, travel-api, visa, visa-requirements

## 简介

Official SDK for the Orizn Visa API — 40,027 passport-destination pairs in 15 languages (all plans), 30+ data points per visa: fees, processing times, photo specs, transit, embassies, overstay penalties, safety
