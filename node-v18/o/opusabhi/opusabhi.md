# opusabhi

> 标签: abhibots, ai, anthropic, antigravity, claude, claude-code, cline, cursor, ide, n8n, openclaw, opus, roo-code, vscode

## 简介

One-command Opus Proxy setup — run npx opusabhi, press y, paste your key. Sets up Claude Code, VS Code, Cursor, Antigravity, Cline, Roo Code, OpenClaw and your terminal.
