# obscura-aleo-cli

> 标签: aleo, auction, cli, obscura, privacy, zero-knowledge

## 简介

Command-line interface for Obscura — private sealed-bid auction protocol on Aleo. Read auctions, compute Dutch prices, prepare bid payloads from your terminal.
