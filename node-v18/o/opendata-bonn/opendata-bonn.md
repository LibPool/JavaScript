# opendata-bonn

> 标签: bonn, framework, opendata

## 简介

This is a Node.js framework to retrieve (parts of) OpenData provided by Bundesstadt Bonn - https://opendata.bonn.de/

## 官网

- 官网：https://gitlab.com/goern/opendata-bonn/blob/master/README.md
- 源码仓库：git+https://gitlab.com/goern/opendata-bonn.git
- npm 页面：https://www.npmjs.com/package/opendata-bonn

## 历史版本号

- 当前版本：0.2.0

- 0.1.0
- 0.2.0

## 获取地址

- npm 安装：`npm install opendata-bonn`
- npm registry：https://registry.npmjs.org/opendata-bonn
- Node 要求：>= 0.10.0
