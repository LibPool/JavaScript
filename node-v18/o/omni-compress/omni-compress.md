# omni-compress

> 标签: archive, archiving, audio, audio-compressor, avif, batch, before-upload, browser, client-side-compression, compress-image, compression, convert, deflate, encoder, fflate, ffmpeg, flac, image, image-compression, image-optimizer, image-resize, isomorphic, media, media-optimizer, mp3, node, offscreencanvas, opus, video, video-compression, wasm, web-worker, webassembly, webcodecs, webp, zero-copy, zip

## 简介

Image, audio, and video compression for browser and Node.js. OffscreenCanvas fast path, FFmpeg Wasm fallback, Web Worker threading. Compress JPEG, PNG, WebP, AVIF, MP3, Opus, FLAC, MP4, WebM.
