# opencode-mobile-use

> 标签: adb, android, computer-use, mobile, opencode, opencode-plugin, tui

## 简介

Control an Android phone from OpenCode: live phone screen in the TUI sidebar, agent tools for taps/typing/swipes/UI dumps, app-specific skills, and a built-in phone-vision subagent. Works over USB, wireless, or Tailscale.
