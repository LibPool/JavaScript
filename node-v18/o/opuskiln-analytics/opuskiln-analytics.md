# opuskiln-analytics

> 标签: analytics, cookieless, dpdp, error-tracking, first-party, pageview, spa, supabase, web-analytics

## 简介

Minimal first-party web analytics for SPAs (no cookies, DPDP-friendly). Pageviews, custom events, and JS/API error capture.
