# openvideo-plugin-embed-subtitle

> 标签: embed, ffmpeg, ffprobe, linux, muxed, openvideo, plugin, subtitle

## 简介

OpenVideoAPI 内封字幕采集插件：ffprobe 检测视频内嵌字幕轨道（多轨/多语言），ffmpeg 提取到字幕库（跨平台：内置 ffmpeg/ffprobe 二进制，Linux/Windows/macOS 开箱即用）
