# orcpin-ledger

> 标签: accounting, agents, base, ledger, reconciliation, usdc, x402

## 简介

The books an agent wallet doesn't keep: meter every x402 call your agent pays for, reconcile it against the chain, buy and verify a signed statement of account. A library for any Node x402 client, and a CLI.
