# octocode-mcp-vscode

> 标签: agentic, ai, ai-assistant, antigravity, claude, cline, code-analysis, code-research, code-search, copilot, cursor, gemini, github, mcp, model-context-protocol, octocode, pull-request, repository-explorer, roo-code, trae, windsurf

## 简介

Management extension for Octocode MCP Server. Enables AI assistants to search, analyze, and understand codebases across GitHub. Supports Cursor, Windsurf, Antigravity, Cline, Roo Code, Trae, and more.
