# omnichatkit

> 标签: a2ui, ai-chat, chat-components, chatbot, conversational-ui, generative-ui, llm-ui, nextjs, omnichatkit, react, rsc

## 简介

A modular React component library for building AG-UI based AI chat interfaces with native Generative UI(A2UI) and Shadcn styling.
