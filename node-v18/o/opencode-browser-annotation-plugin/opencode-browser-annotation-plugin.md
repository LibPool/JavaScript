# opencode-browser-annotation-plugin

> 标签: annotation, browser, chrome-extension, opencode, opencode-plugin

## 简介

Select an element in your browser, type an instruction, and send it to your OpenCode agent over a loopback + SSH tunnel. Text and element metadata only (no screenshots).
