# open-secure-viewer

> 标签: document, drm, pdf, pdfium, secure, viewer, wasm, watermark

## 简介

Zero-cost secure document viewer — PDFium WASM + Express security gateway. Drop-in replacement for Apryse/PDFTron WebViewer with no license fees.
