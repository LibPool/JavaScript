# opencode-llm-review-gate

> 标签: JavaScript

## 简介

llm-review-gate.ts opencode plugin (gates bash tool calls behind an LLM safety review before they run), published to npm so opencode's own npm-plugin loader can install it directly from a bare package name in opencode.json's plugin array - see CLAUDE.md.
