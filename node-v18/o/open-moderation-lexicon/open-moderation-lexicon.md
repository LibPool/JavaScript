# open-moderation-lexicon

> 标签: aho-corasick, chinese, content-filter, fastify, lexicon, moderation, sensitive-words, typescript

## 简介

Multilingual keyword-based moderation toolkit (TypeScript SDK, REST API, CLI) built on an open sensitive-word lexicon with Aho-Corasick matching.
