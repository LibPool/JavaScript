# ooxml-excel-editor

> 标签: canvas, edit, editor, excel, exceljs, ooxml, preview, react, spreadsheet, viewer, vue, vue2, vue3, xlsx

## 简介

High-fidelity OOXML (.xlsx) preview & editor — canvas renderer, framework-agnostic core with Vue 3, Vue 2 and React shells (1:1 UI across all shells). Read-only by default; opt-in editing with undo/redo, formula recalc, and export back to .xlsx/JSON/CSV.
