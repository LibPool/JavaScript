# orbit-controls-mousemove

> 标签: JavaScript

## 简介

ThreeJS OrbitControls as an npm package with mousemove functionality (instead of requiring mousedown). The package uses [this](https://www.npmjs.com/package/three-orbit-controls) as it's base.
