# octoloader

> 标签: a11y, accessibility, animation, css-animation, custom-element, dark-mode, loader, loading, loading-indicator, loading-spinner, mascot, octopus, pixel-art, prefers-reduced-motion, progress, progressbar, react, react-component, skeleton, spinner, sprite, svg, typescript, web-component, zero-dependency

## 简介

A pixel-art octopus that swims while you wait. Dependency-free loading indicator for React or plain HTML — colour and monochrome, determinate and indeterminate.
