# overleaf-forge

> 标签: ai, anthropic, bibtex, claude, git, latex, latexmk, mcp, model-context-protocol, overleaf

## 简介

MCP server to read, edit, compile, and verify Overleaf/LaTeX projects over git: conflict-safe edits, figure upload, clean-build verification, citation and voice linting.
