# obj-and-arr-methods

> 标签: ARRAY, METHODS, OBJECT

## 简介

This package includes array methods like reduce, map, filter, forEach, take, skip, some, every, max, min, chain. It also includes object methods: keys, values, pairs, fromPairs.
