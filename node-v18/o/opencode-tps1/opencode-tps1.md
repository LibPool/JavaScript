# opencode-tps1

> 标签: opencode, opencode-plugin, plugin, tokens-per-second, tps, ttft, tui

## 简介

Displays live TPS (tokens per second), average TPS, and TTFT (time to first token) in the OpenCode 1.x TUI session prompt.
