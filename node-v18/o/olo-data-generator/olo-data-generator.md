# olo-data-generator

> 标签: JavaScript

## 简介

For mock and demonstration purposes we have created a data generation module, which uses [Chance.js](https://chancejs.com) under the hood. This module allows a consumer to input a value, a count, and a seed for regeneration purposes, and output the value
