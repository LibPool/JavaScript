# ofs-dxf-ts

> 标签: angular, autocad, browser, cad, dxf, ezdxf, geometry, gis, typescript

## 简介

Pure, API-agnostic, browser-first TypeScript library for generating DXF files from plain coordinates, labels and options — optionally on top of a DXF template.
