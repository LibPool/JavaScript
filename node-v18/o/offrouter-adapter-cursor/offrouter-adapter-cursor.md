# offrouter-adapter-cursor

> 标签: JavaScript

## 简介

Cursor adapter for OffRouter. Installs the OffRouter MCP server into Cursor's global MCP config (`~/.cursor/mcp.json`) so `offrouter install cursor` works, with rollback.
