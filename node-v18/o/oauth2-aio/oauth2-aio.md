# oauth2-aio

> 标签: JavaScript

## 简介

本项目参考了 Java 项目 JustAuth 的设计，将所有的第三方登录都整合到一个项目中，方便使用。 因为 JustAuth 项目是 Java 项目，Node 项目中没有类似的项目，所以本项目就诞生了。 原项目地址：[JustAuth](https://github.com/justauth/JustAuth)
