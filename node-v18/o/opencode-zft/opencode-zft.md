# opencode-zft

> 标签: contract-first, gate, multiagent, opencode, opencode-plugin, traceability, traceagent, zft

## 简介

opencode gates for zft — the contract-first traceability framework. A dispatch gate that requires a contract binding before implementation work, and an L0 lint gate that fires on every .zft/ edit.
