# openaudio-suite

> 标签: ambient, audio, audio-engine, audio-player, autoplay, background-tab-detection, browser, game-audio, html5-audio, no-dependencies, pause-resume, playlist, randomized, scheduler, sequential, sound, ui-sounds, vanilla-js, web-audio, zero-dependencies

## 简介

Zero-dependency audio utilities for web browsers. Three libraries: OpenAudio_r.js (randomized scheduler), OpenAudio_s.js (sequential player), OpenAudio.js (single-clip player with background tab detection). Pure HTML5 Audio API. Apache-2.0.
