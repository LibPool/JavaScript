# opencode-ipynb

> 标签: effect, ipynb, jupyter, notebook, opencode, plugin, typescript

## 简介

OpenCode community plugin that adds robust .ipynb (Jupyter Notebook) support: inspect, read, edit, run, outputs, clean, export, reproducibility reports, and warm kernels.
