# opensubs-cli

> 标签: node, opensubs, opensubtitles, opensubtitles.com, srt, subs, subtitle, subtitle-download, subtitles

## 简介

A full featured, easy to use, CLI app to download subtitles from OpenSubtitles.com. Based on subs-cli by Alexandru Cancescu.
