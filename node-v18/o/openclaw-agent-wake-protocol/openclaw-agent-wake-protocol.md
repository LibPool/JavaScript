# openclaw-agent-wake-protocol

> 标签: agent-persistence, genesis, life, life-gateway, mcp, multi-agent, openclaw, openclaw-plugin, soul-coherence, wake-protocol

## 简介

OpenClaw extension: general-purpose LIFE gateway lifecycle manager for multi-agent systems. Handles agent registration, Genesis interview, wake protocol, and soul coherence checks for any agent configuration.
