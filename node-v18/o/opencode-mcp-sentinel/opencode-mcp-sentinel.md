# opencode-mcp-sentinel

> 标签: ai, coding-agent, mcp, opencode, plugin, poll, sentinel

## 简介

OpenCode plugin that acts as a sentinel between the AI agent and MCP servers — polling long-running tasks on the agent's behalf so that token-costly status loops never enter the LLM inference path
