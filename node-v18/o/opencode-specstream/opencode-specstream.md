# opencode-specstream

> 标签: agent-skills, lead-lists, mcp, opencode, opencode-plugin, specstream, web-data, web-search

## 简介

SpecStream plugin for OpenCode: adds the SpecStream MCP server and four agent skills, so your agent can ask for a list in plain words and get every matching row with its source.
