# opencode-opencron

> 标签: agent, opencode, opencron, plugin, queue, scheduler, task

## 简介

Headless task scheduler for OpenCode agents — schedule, retry, manage batch jobs, and receive notifications via Telegram, Discord, Slack, Email, and Webhook.
