# officecrypto-tool

> 标签: cfb, crypto, decrypt, doc, docx, encrypt, office, ole, ppt, pptx, wps, xls, xlsx

## 简介

officeCrypto is a library for node.js that can be used to decrypt and encrypt excel files.
