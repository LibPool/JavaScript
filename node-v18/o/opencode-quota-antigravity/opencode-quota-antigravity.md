# opencode-quota-antigravity

> 标签: antigravity, claude, gemini, opencode, plugin, quota, usage

## 简介

OpenCode plugin that aggregates Antigravity Manager account-pool quota (Gemini/Claude 5h & weekly windows) and serves it locally for quota display tools
