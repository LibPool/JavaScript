# openclaw-pass-manager

> 标签: gpg, openclaw, openclaw-plugin, otp, pass, password-manager, password-store, totp

## 简介

OpenClaw plugin for the standard Unix password manager (pass). Provides agent tools to list, get, save, search passwords and generate OTP codes.
