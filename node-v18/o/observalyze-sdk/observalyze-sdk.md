# observalyze-sdk

> 标签: events, node, observalyze, platform, saas, sdk, web

## 简介

This is the client SDK for sending events to [Observalyze](https://www.observalyze.com) from your web application. It can be used in both web and server environments. The logged events are used to give insight into the usage of your platform or applicatio
