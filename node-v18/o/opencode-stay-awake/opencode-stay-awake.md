# opencode-stay-awake

> 标签: caffeinate, keep-awake, linux, macos, opencode, opencode-plugin, prevent-sleep, sleep, systemd-inhibit

## 简介

OpenCode v2 plugin that keeps your computer awake and blocks system sleep while any session is generating (macOS caffeinate, Linux systemd-inhibit)
