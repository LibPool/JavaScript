# orca-agent-cli

> 标签: ai-agent, containerization, devtools, docker, docker-compose, hackathon, self-healing

## 简介

An AI agent CLI that clones a messy student/hackathon repo, detects its stack, generates Docker + docker-compose configs, shows a service-graph diagram for human approval before running anything, then builds/runs the containers with a self-healing retry l
