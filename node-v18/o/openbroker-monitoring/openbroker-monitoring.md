# openbroker-monitoring

> 标签: audit, dashboard, hyperliquid, metrics, monitoring, openbroker

## 简介

Optional dashboard/metrics forwarder for the openbroker CLI. Auto-loaded by `openbroker auto run` when installed alongside it.
