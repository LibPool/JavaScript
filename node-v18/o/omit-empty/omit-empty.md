# omit-empty

> 标签: clear, delete, empty, find, has, hasown, javascript, js, key, keys, node, node-js, object, omit, properties, property, remove, util, utilities, utility, value

## 简介

Recursively omit empty properties from an object. Omits empty objects, arrays, strings or zero.
