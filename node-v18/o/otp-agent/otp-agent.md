> 标签: 2fa, authentication, generator, hotp, javascript-security, mfa, multi-factor-authentication, node-otp, nodejs-security, one-time-password, otp, otp agent, otp-agent, otp-creator, otp-generator, otp-js, password-generator, recovery-codes, recovery-codes-generator, secure-authentication, security, time-based otp, token-generation, totp, two-factor-authentication

## 简介

A JavaScript package for generating one-time passwords (OTPs), including custom OTPs, TOTP, HOTP, and recovery codes. Ideal for secure authentication.
