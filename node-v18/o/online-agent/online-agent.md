# online-agent

> 标签: agent-connector, agent-tool, ai-agent, cli, cross-platform, json-rpc, local-server, mcp, online-agent, remote-shell, termux, tui, websocket

## 简介

Cross-platform Terminal CLI + TUI that hosts a local server so AI agents can connect via a pairing code and respond directly in your terminal. Works on Windows, Linux, macOS, and Android (Termux).
