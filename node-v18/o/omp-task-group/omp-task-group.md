# omp-task-group

> 标签: fanout, join, oh-my-pi, omp, omp-extension, omp-plugin, swarm, task-group

## 简介

Atomic multi-agent coordination layer for oh-my-pi (OMP): fan-out N independent subagents, join, and return exactly one logical result to the parent. Not a workflow engine.
