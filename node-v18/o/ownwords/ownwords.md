# ownwords

> 标签: ai-assisted, cms, content-management, conversion, dual-publishing, editorial, local-first, markdown, own-your-content, static-site, wordpress

## 简介

Own your words. Bi-directional WordPress sync, local Markdown editing, batch AI-assisted editorial operations, and dual publishing to both WordPress and static sites.
