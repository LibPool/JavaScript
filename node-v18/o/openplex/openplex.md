# openplex

> 标签: ai, anthropic, byok, chat, chatbot, llm, ollama, openai, openrouter, perplexity, web-search

## 简介

Your keys, every model — a Perplexity-style multi-thread AI chat with web search, memory, an on-device coding agent, and cross-device sync. Bring your own API keys.
