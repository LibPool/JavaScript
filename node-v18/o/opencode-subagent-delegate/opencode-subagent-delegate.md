# opencode-subagent-delegate

> 标签: delegate, delegation, llm, model-router, multi-model, opencode, plugin, subagent

## 简介

Plug-and-play OpenCode plugin: delegate(model, task) + discover_models(query) — on-demand model discovery, explicit provider/model subagent execution, no pricing heuristics, registry never injected into context.
