# opencode-go-statusline

> 标签: opencode, opencode-go, opencode-plugin, quota, statusline, usage

## 简介

OpenCode TUI plugin: display OpenCode Go subscription quota (rolling 5h / weekly / monthly) in the footer statusline. V2-native, zero-config, no cookies.
