# openlayers-quick-tools

> 标签: animation, coordinate-transform, geospatial, gis, map, move-controller, openlayers, quick-tools

## 简介

一个便捷实现 OpenLayers 基础功能的工具包，支持地图初始化、添加图层、点线面等操作，并提供强大的动画和坐标系处理工具。
