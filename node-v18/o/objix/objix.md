# objix

> 标签: assign, async, bind, chain, class, clone, delete, diff, equals, eval, extend, find, flatMap, iterator, json, keyBy, log, map, memoize, new, object, observe, pick, promise, prototype, proxy, sugar, trap

## 简介

A powerfull, high performance, lightweight library to inject many usefull methods into the Object prototype to simplify and sugar many common use cses.
