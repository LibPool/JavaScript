# openclaw-bridge

> 标签: bridge, communication, gateway, handoff, multi-agent, openclaw, openclaw-plugin

## 简介

OpenClaw plugin for cross-gateway communication — agent discovery, file transfer, real-time messaging, session handoff, and local process management. Install as plugin: openclaw plugins install openclaw-bridge
