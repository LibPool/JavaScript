# octrimmer

> 标签: agent, compaction, context, context-window, llm, opencode, opencode-plugin, plugin, prompt-cache, summary, tokens, trim

## 简介

OpenCode plugin that lets the model trim its own context: a summary replaces finished work and keeps what matters verbatim by reference, never re-generated.
