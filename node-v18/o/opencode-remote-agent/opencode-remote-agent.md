# opencode-remote-agent

> 标签: ai, aws, coding-agent, ecs, fargate, headless, opencode, opencode-cli, opencode-plugin, remote-agent

## 简介

OpenCode plugin to run OpenCode agent tasks remotely on AWS ECS Fargate. Offload long-running coding tasks to the cloud.
