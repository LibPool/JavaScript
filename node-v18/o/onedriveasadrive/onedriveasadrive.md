# onedriveasadrive

> 标签: dfs, drive, drive-letter, file-explorer, file-share, gpo, graph, intune, map-network-drive, mapped-drive, mount, network-drive, onedrive, sharepoint, webdav, windows

## 简介

Mount OneDrive and SharePoint document libraries as Windows drive letters. No-code installer/configurator for the OneDriveAsADrive WebDAV bridge.
