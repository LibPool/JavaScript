# orz-slides-browser

> 标签: JavaScript

## 简介

Prebuilt in-browser presentation engine for orz-slides .slides.html files (reveal.js + orz-markdown + the slide parser/layout/assembler)

## 官网

- 官网：https://markdown.orz.how/family.html#slides
- 源码仓库：git+https://github.com/wangyu16/orz-slides.git
