# overlock

> 标签: agent, ai, claude-code, code-review, codex, coding-agent, copilot, cursor, diff, git, guardrails, hooks, lint, reward-hacking, test-integrity

## 简介

Deterministic, zero-dependency gate on test integrity in a git patch: reports skipped tests, removed or weakened assertions, and lowered coverage thresholds.
