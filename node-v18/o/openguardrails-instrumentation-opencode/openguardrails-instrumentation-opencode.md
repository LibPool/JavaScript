# openguardrails-instrumentation-opencode

> 标签: agent, ai, guardrails, ogr, opencode, openguardrails, plugin, security

## 简介

Guard an opencode agent's tool calls through the OpenGuardrails (OGR) protocol — agent-configurable text/regex guardrails, or use your own model as the judge. No core changes.
