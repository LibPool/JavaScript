# omnilane

> 标签: agentic, claude, cli, codex, dispatch, gemini, grok, llm, multi-model, orchestration, routing

## 简介

One routing table, every harness — classify subtasks into lanes and delegate each lane through a compatible caller-owned native agent or vendor CLI.
