# onboardbasekit

> 标签: environments, envs, onboardbase, secops, secrets

## 简介

**Onboardbase Kit** (onboardbasekit) is a CLI tool for generating boilerplates with onboardbase preconfigured in them as a SecretOps infrastucture.
