# orefinder-estimate

> 标签: bedrock, diamond, java, minecraft, mining, nether, ore, orefinder, seed, y-level

## 简介

Fast offline Minecraft ore estimator: best mining Y and the areas where ores are most likely to concentrate for Java and Bedrock. Pairs with orefinder.io for seed-exact coordinates.

- 官网：https://orefinder.io
- 源码仓库：git+https://github.com/nazzal5448/ore-finder-pkgs.git
- npm 页面：https://www.npmjs.com/package/orefinder-estimate
