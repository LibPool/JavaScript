# opencode-v2-kiro-auth

> 标签: amazon-q, aws-sso, codewhisperer, kiro, kiro-cli, opencode, opencode-plugin, opencode-v2

## 简介

Use Kiro models (Claude Fable 5.1, Claude Opus 5.5, GPT 5.6 Sol) in opencode v2 with AWS Builder ID, IAM Identity Center, or Kiro API-key authentication, with effort variants and Kiro-backed web search.
