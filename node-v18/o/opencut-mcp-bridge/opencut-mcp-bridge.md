# opencut-mcp-bridge

> 标签: mcp, model-context-protocol, opencut, video-editor

## 简介

Stdio-to-HTTPS MCP bridge for O Morato Video Editor (OpenCut) — lets external MCP clients like Claude Desktop or Codex drive the editor over the same bearer-token API Hanna uses internally.
