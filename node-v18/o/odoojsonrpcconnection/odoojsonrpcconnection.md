# odoojsonrpcconnection

> 标签: Odoo, axios, erp, json-rpc

## 简介

The library is designed to facilitate communication with an Odoo server, which is an open-source ERP (Enterprise Resource Planning) system. The communication is established using the JSON-RPC (Remote Procedure Call) protocol.
