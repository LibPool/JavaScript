# opencode-git-span

> 标签: audit, coupling, dependencies, documentation, drift, git, opencode, plugin, semantic, span

## 简介

In-session git-span for OpenCode: silent span-drift healing behind shell/read/edit/write/patch calls, a hold-once git commit/push advisor, and an installer for the git-span skills and expert agent.
