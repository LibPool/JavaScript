# oxialink

> 标签: bitcoin, crypto, gateway, oxialink, payment, ton, usdt

## 简介

Official Node.js SDK for the Oxialink crypto payment gateway: create invoices, verify webhooks, send withdrawals.

## 官网

- 官网：https://oxialink.com
- 源码仓库：git+https://github.com/oxialink/node-sdk.git
- npm 页面：https://www.npmjs.com/package/oxialink

## 历史版本号

- 当前版本：1.0.0

- 1.0.0

## 获取地址

- npm 安装：`npm install oxialink`
- npm registry：https://registry.npmjs.org/oxialink
- Node 要求：>=18
