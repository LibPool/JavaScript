# openly-raml-parser

> 标签: JavaScript

## 简介

A RAML parser based on PyYAML written in CoffeScript and available for use as NodeJs module or in-browser.

## 官网

- 源码仓库：git@github.com:raml-org/raml-js-parser.git
- npm 页面：https://www.npmjs.com/package/openly-raml-parser
