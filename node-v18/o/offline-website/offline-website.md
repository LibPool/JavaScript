# offline-website

> 标签: archive, backup, cli, commander, html, json, mhtml, offline, pdf, playwright, png, print, screenshot, singlefile, txt, website, websiteprint, zip

## 简介

Save offline website as an single archive (ZIP, JSON, HTML, TXT, PDF, PNG, MHTML).
Website title will be the folder/archive name.
Nothing special, it just works, just does its job right. Enjoy!
