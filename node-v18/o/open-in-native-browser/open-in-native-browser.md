# open-in-native-browser

> 标签: android, breakout, deep-link, escape, external-browser, facebook, in-app-browser, instagram, ios, meta, webview

## 简介

Detect Instagram/Facebook in-app browsers and help users escape to their native browser, with a dismissible fallback banner and manual escape link. Works with any framework or plain HTML.
