# openclaw-security-dashboard

> 标签: audit, bulwarkai, clawhavoc, dashboard, hardening, ioc, malware, openclaw, scanner, security, supply-chain, vulnerability

## 简介

Security scanner for OpenClaw deployments. Checks gateway exposure, skill supply chain (1,184+ IOCs), config hardening, identity integrity, persistence, and sessions. Zero dependencies. 100% local.
