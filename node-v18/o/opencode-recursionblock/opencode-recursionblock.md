# opencode-recursionblock

> 标签: JavaScript

## 简介

A lightweight plugin for Opencode designed to prevent infinite loops caused by subagents continuously calling each other or themselves indefinitely. It tracks tool call execution stacks and automatically halts agent chains that exceed a configured maximum
