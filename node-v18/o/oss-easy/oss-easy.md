# oss-easy

> 标签: aliyun, oss, 阿里云

## 简介

An aliyun oss service client for NodeJS, provides batch processing, exposes api more like nodejs.fs. 阿里云 OSS 服务的SDK，提供简单好用的API接口，支持批量操作处理
