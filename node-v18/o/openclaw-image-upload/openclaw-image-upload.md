# openclaw-image-upload

> 标签: image, openclaw, plugin, upload

## 简介

OpenClaw 图片上传插件：当用户有上传图片意图时，将图片 base64 上传到指定接口并返回图片地址

## 官网

- npm 页面：https://www.npmjs.com/package/openclaw-image-upload

## 历史版本号

- 当前版本：1.0.0

- 1.0.0

## 获取地址

- npm 安装：`npm install openclaw-image-upload`
- npm registry：https://registry.npmjs.org/openclaw-image-upload
