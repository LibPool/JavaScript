# outgrid

> 标签: breakout, css, full-bleed, grid, layout, subgrid, tailwindcss

## 简介

A CSS layout grid with full-bleed breakouts and a global setup through custom properties. Plain CSS, with an optional Tailwind CSS v4 entry.
