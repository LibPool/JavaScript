# opencolor-cli

> 标签: cli, color, css, design-system, design-tokens, oklch, tailwind, wcag

## 简介

AI-powered design token generator — generate OKLCH-based color tokens for CSS, JSON, and Tailwind from a natural-language prompt or hex colors.
