# object-identity

> 标签: cache-key, canonical, canonicalize, dedupe, deterministic, equality, fingerprint, hash, identity, memoize, normalize, object, stable, structural

## 简介

Canonicalize any value into a tiny, stable identity string. Structural fingerprints for cache keys, deduping, and memoization.
