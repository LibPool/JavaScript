# occ-symbol

> 标签: derivatives, finance, occ, option-parser, option-symbol, options, options-trading, osi, trading

## 简介

Parse, validate, and build OCC option symbols — SPY260825C00500000 ⇄ { underlying, expiration, right, strike }. Zero runtime deps, TypeScript.
