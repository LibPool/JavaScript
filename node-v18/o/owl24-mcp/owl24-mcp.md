# owl24-mcp

> 标签: ai-agent, claude-code, coding-agent, cursor, mcp, model-context-protocol, observability, opentelemetry, owl24

## 简介

MCP server for owl24 — gives Claude Code, Cursor, or any MCP client direct access to your error queue: list what's broken, claim it, read the trace, and resolve it, without leaving your editor.
