# open-accessibility-widget

> 标签: a11y, accessibility, angular, contrast, react, rtl, svelte, text-size, user-preferences, vanilla-js, vue, wcag, widget

## 简介

Framework-agnostic accessibility preferences widget for any website: plain JS, React, Next.js, Vue, Angular, Svelte. Profiles, text/color/navigation adjustments, themable, RTL-ready, TypeScript types included.
