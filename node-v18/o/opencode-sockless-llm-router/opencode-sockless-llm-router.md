# opencode-sockless-llm-router

> 标签: llama.cpp, llm-router, opencode, opencode-plugin, provider

## 简介

OpenCode provider plugin for Sockless LLM Router — point it at the router's API endpoint and every model is discovered automatically, with context size, tool-calling, vision and reasoning support carried over.
