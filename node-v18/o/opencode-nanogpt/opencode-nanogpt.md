# opencode-nanogpt

> 标签: JavaScript

## 简介

Automated setup scripts for configuring [OpenCode](https://opencode.ai) with [NanoGPT](https://nano-gpt.com) integration, featuring automatic model updates, reasoning model support, and built-in MCP server.
