# opticquiz-cvd

> 标签: a11y, accessibility, ciede2000, color-blindness, color-vision-deficiency, colorblind, contrast, cvd, deuteranopia, ishihara, palette, protanopia, tritanopia, wcag

## 简介

Color accessibility engine. Checks palettes for colorblind-safety (protan/deutan/tritan, Machado 2009, scored with CIEDE2000), fixes failing palettes, and checks WCAG contrast. Zero dependencies.
