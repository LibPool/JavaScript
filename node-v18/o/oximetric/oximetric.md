# oximetric

> 标签: analytics, cookieless, events, first-party, gdpr, lightweight, metrics, oximetric, pageviews, privacy, self-hosted, telemetry, tracker, tracking, visitors

## 简介

Lightweight, privacy-friendly visitor analytics for any website. Works with the self-hosted Oximetric server. Zero runtime dependencies, works in every browser, drop-in script tag or ESM import.
