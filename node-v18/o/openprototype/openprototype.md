# openprototype

> 标签: agent, ai-prototyping, html-prototype, local-first, opencode, prd, product-management, product-manager, prototype, scaffold

## 简介

本地原型工作台：左侧树形导航 + 中间原型预览 + 右侧 AI Agent（OpenCode）。PRD 与 HTML/JS 原型协作，含自动化检查。
