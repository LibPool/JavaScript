# outright

> 标签: JavaScript

## 简介

Outright is a local-first POC for organizing coding-agent chats around Git worktrees. It scans configured project roots, reads `git worktree list --porcelain`, and presents projects, worktrees, chat threads, repository changes, and run context in one desk
