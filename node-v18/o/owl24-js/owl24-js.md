# owl24-js

> 标签: ai-agent, apm, coding-agent, error-tracking, logging, monitoring, observability, opentelemetry, owl24, tracing

## 简介

Node.js SDK for owl24 — one line of code to send logs, traces, and metrics to your owl24 dashboard, built on OpenTelemetry, with errors queued straight to your own coding agent to fix and PR.
