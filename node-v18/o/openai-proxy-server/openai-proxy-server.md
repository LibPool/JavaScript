> 标签: api-keys, billing, llm, openai, openai-compatible, openrouter, proxy, reseller, speech-to-text, sqlite, sse, stt, subscriptions, text-to-speech, tts

## 简介

OpenAI-compatible LLM/TTS/STT proxy with self-service API keys, reseller billing, subscriptions, per-key limits and live dashboards on SQLite.
