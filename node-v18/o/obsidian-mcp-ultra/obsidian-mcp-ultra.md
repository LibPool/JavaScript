# obsidian-mcp-ultra

> 标签: knowledge-graph, markdown, mcp, model-context-protocol, obsidian

## 简介

obsidian-mcp-ultra is a high-performance MCP (Model Context Protocol) bridge for Obsidian, exposing your vault as a structured, queryable knowledge graph for agentic workflows. It enables semantic retrieval, context injection, and bidirectional edits—turn
