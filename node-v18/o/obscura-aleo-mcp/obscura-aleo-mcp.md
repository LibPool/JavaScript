# obscura-aleo-mcp

> 标签: ai-agent, aleo, auction, claude-desktop, mcp, model-context-protocol, obscura, privacy, zero-knowledge

## 简介

Model Context Protocol server for Obscura — lets AI agents (Claude Desktop, ChatGPT, etc.) create, bid on, and settle private auctions on Aleo. First auction protocol with native AI-agent integration.
