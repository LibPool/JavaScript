# open-ocr-cli

> 标签: agent-first, agentic-ocr, batch-ocr, cli, cloudflare-ai-gateway, coding-agent, command-line-tool, document-extraction, gemini, json-schema, kimi, mcp-server, multimodal-ocr, muse, ocr, openai-compatible, openrouter, pdf, structured-output

## 简介

Agent-first, provider-neutral multimodal OCR CLI for images, PDFs, URLs, JSON schemas, and agentic extraction with Gemini, Kimi, Muse, and OpenRouter.
