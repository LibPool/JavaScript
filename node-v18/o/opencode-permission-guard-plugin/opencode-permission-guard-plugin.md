# opencode-permission-guard-plugin

> 标签: access-control, guard, opencode, permission, plugin, security

## 简介

Host directory access control plugin for opencode: two-layer (global+project) hot-reloadable rules with allow/deny/ask, ask-mode auto-reject, headless downgrade, /permission TUI panel (en/zh), Windows support. Zero dependencies.
