# opencode-actualyze

> 标签: actualyze, auto-discovery, context-window, inference-server, koboldcpp, llama-cpp, llamacpp, llm, lm-studio, lmstudio, local-ai, local-llm, localai, model-discovery, model-server, ollama, omlx, openai-compatible, opencode, opencode-plugin, plugin, sglang, tgi, vllm

## 简介

opencode plugin that auto-discovers models from OpenAI-compatible providers and enriches them with context window sizes, capability flags, and model metadata. Supports Actualyze, Ollama, oMLX, vLLM, TGI, SGLang, LM Studio, KoboldCpp, llama.cpp, and LocalA
