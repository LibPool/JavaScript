# ocr-llm-sdk

> 标签: JavaScript

## 简介

- `OcrLlmSDK` 是一个基于轮询机制的 OCR + LLM 异步任务管理 SDK，提供任务创建、结果获取、状态监听等功能，支持 **图片 URL**、**Base64**、**二进制文件** 方式发起任务，并可自动轮询更新任务状态与结果。
