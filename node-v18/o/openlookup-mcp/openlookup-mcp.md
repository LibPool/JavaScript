# openlookup-mcp

> 标签: domain-validation, email-validation, email-verification, fraud-detection, ip-reputation, mcp, model-context-protocol, openlookup, phone-validation

## 简介

MCP server for OpenLookup.io: lets coding agents (Claude, Cursor, etc.) score email, phone, IP, and domain risk and wire up the OpenLookup API directly.
