# opencode-discord-notifier

> 标签: cli, discord, discord-bot, notifications, opencode, opencode-plugin

## 简介

OpenCode plugin that sends Discord notifications for pending permissions, questions, and idle sessions, with buttons to answer permissions directly from Discord.
