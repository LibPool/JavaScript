# opencode-lmstudio-warm

> 标签: bun, llm, lm-studio, lmstudio, local-llm, model-loading, opencode, opencode-plugin, prewarm, warm

## 简介

Deterministic LM Studio model pre-warm gate for opencode — loads and keeps the target model resident before every request, healing cold starts and mid-session TTL evictions.
