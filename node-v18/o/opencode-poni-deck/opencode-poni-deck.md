# opencode-poni-deck

> 标签: agent, deck, monitor, opencode, plugin, poni, poni-deck, status

## 简介

Opencode plugin that reports agent status to Poni Deck by writing status JSON files to %APPDATA%\poni-deck\agents\{pid}.json

## 官网

- npm 页面：https://www.npmjs.com/package/opencode-poni-deck

## 历史版本号

- 当前版本：0.1.0

- 0.1.0

## 获取地址

- npm 安装：`npm install opencode-poni-deck`
- npm registry：https://registry.npmjs.org/opencode-poni-deck
- Node 要求：>=18
