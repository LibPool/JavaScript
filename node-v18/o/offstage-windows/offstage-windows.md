# offstage-windows

> 标签: ai-agents, claude-code, e2e, electron, focus-stealing, gui-testing, headless, hidden-desktop, playwright, testing, windows, xvfb

## 简介

Run automated GUI test sessions on Windows (Electron + Playwright e2e, CDP screenshot scripts, packaged-app smoke tests) on a hidden desktop: no windows on your screen, no stolen focus, and test runs that can go side by side.
