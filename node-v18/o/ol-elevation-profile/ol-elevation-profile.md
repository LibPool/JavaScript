# ol-elevation-profile

> 标签: altitude, cycling, d3, elevation, geojson, gpx, hiking, mtb, ol, openlayers, profile

## 简介

Synchronized elevation profile control for OpenLayers, rendered with d3. Reads elevation from 3D GPX/GeoJSON, or fills it from a terrain model: AWS tiles, IGN RGE ALTI, XYZ, WMS, GeoTIFF, GeoServer, or your own source.
