# ol-tsig

> 标签: openlayers

## 简介

Librería Para extender las clases de Openlayers, permitiendo su configuración a partir de un fichero JSON. Dicha configuración tiene la misma estructura que una definición de mapa tipica de OL pero sin la creación de Objetos.
