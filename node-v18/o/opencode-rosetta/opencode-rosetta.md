# opencode-rosetta

> 标签: claude-code, copilot, mcp, opencode, opencode-plugin

## 简介

opencode plugin that translates Claude Code and GitHub Copilot artifacts (agents, commands, MCP servers, instructions, skills) into opencode config in memory, via the plugin config hook.
