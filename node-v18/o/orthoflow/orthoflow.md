# orthoflow

> 标签: diagram, graph, layout, orthogonal, wasm, webassembly

## 简介

Orthogonal graph layout engine (WebAssembly): an unofficial, bit-exact port of the TALA layout engine from D2. Not affiliated with Terrastruct.
