# offprint-mcp

> 标签: ai-agent, claude, cursor, markdown-extractor, mcp, mcp-server, model-context-protocol, web-reader

## 简介

Official Model Context Protocol (MCP) server for Offprint: sub-100ms clean Markdown extraction, 1200 DPI vector SVGs, and multi-modal capsules for Claude Desktop and Cursor.
