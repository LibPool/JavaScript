# ok2ride

> 标签: captcha, custom-element, micromobility, ok2ride, psychomotor-vigilance, pvt, web-component

## 简介

OK2Ride: cognitive capability assessment web component (randomised reaction, steering, go/no-go, trail, memory, Stroop, time-estimation and visual-search tests) for gating micromobility vehicle unlocks.
