# omp-lilac-provider

> 标签: ai, gemma, glm, idle-gpu, kimi, lilac, llm, omp, plugin, provider

## 简介

Lilac provider plugin for OMP — Access Kimi K2.6, GLM 5.1, Gemma 4, and MiniMax M2.7 models through Lilac's OpenAI-compatible API on idle GPUs
