# opencode-agy

> 标签: agy, antigravity, delegation, gemini, headless, opencode, plugin, sub-agent

## 简介

OpenCode plugin for delegating scoped work to the Antigravity CLI (agy / Gemini) in headless mode. Thin wrapper with qualified safety and environment caveats.
