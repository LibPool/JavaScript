# opfsql

> 标签: browser, database, in-browser, indexeddb, opfs, sql, sqlite, typescript, worker

## 简介

Lightweight SQL engine in TypeScript. ~40 KB gzipped, zero native deps. Runs in browser workers via OPFS.
