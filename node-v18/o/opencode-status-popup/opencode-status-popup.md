# opencode-status-popup

> 标签: always-on-top, opencode, opencode-plugin, status, tray, windows

## 简介

Always-on-top status pill (or tray icon) for OpenCode: types the word out while the agent works, amber on provider retries, red on failures, violet when a permission is waiting for you.
