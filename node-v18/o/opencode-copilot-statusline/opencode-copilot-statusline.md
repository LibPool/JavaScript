# opencode-copilot-statusline

> 标签: copilot, github-copilot, opencode, opencode-plugin, quota, statusline, usage

## 简介

OpenCode TUI plugin: display GitHub Copilot quota (premium requests, with a chat fallback for Copilot Free) in the footer statusline. V2-native, zero-config, no cookies.
