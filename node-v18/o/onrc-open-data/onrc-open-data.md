# onrc-open-data

> 标签: companies, csv, data.gov.ro, onrc, open-data, romania

## 简介

Find and stream-parse Romania's ONRC company-registry export (OD_FIRME.csv) from data.gov.ro. No dependencies, runs anywhere with fetch.
