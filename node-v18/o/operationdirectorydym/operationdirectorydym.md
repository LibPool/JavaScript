# operationdirectorydym

> 标签: JavaScript

## 简介

共有三个方法,方法removeDir用于删除目标目录下的所有文件及文件夹,需要传入一个目标路径,方法copyDir用于拷贝目标目录的所有文件结构,需要传入一个目标路径及一个输出路径,flatDir用于实现目标目录的扁平化,需要传入一个目标路径及一个输出路径
