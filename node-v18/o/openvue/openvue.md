# openvue

> 标签: bootstrap, component library, fluent, material, openvue, passthrough, primevue, tailwind, ui library, unstyled, vue, vue.js, vue2, vue3

## 简介

OpenVue is an open source, MIT-licensed UI library for Vue featuring a rich set of 80+ components, a theme designer, and various theme alternatives such as Material, Bootstrap and Tailwind. It is a community-maintained continuation of PrimeVue.
