# oc_ms_dialog

> 标签: JavaScript

## 简介

This React library facilitates the opening of modal windows, empowering users to trigger modal pop-ups. You can tailor modal content, such as redirection buttons and informative messages, with certain parameters being optional for flexibility in usage.
