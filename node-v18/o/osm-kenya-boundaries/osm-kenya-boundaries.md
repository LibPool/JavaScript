# osm-kenya-boundaries

> 标签: administrative, administrative-divisions, africa, boundaries, constituencies, counties, east-africa, geocoding, geography, geospatial, gis, javascript, kenya, kenya-data, location, mapping, open-data, openstreetmap, osm, sub-counties, subcounties, typescript, wards

## 简介

Complete Kenya administrative boundaries data (47 Counties, 290+ Constituencies, 300+ Sub-Counties, 1,450+ Wards) with TypeScript support. Zero dependencies, tree-shakeable, and fully typed.
