# opencode-memorysync

> 标签: agent-memory, ai, long-term-memory, mcp, memory, memorysync, opencode, opencode-plugin, personalization

## 简介

Automatic long-term memory for OpenCode: recalled context injected per session, every exchange captured, the MemorySync MCP servers and slash commands registered — one plugin line, session-safe by contract.
