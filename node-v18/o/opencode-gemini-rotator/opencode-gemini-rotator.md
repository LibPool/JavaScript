# opencode-gemini-rotator

> 标签: ai-tools, api-key, api-key-rotation, developer-tools, fallback, fetch, gemini, gemini-api, gemini-pro, generative-ai, google-ai, google-gemini, interceptor, key-rotation, llm, opencode, opencode-ai, opencode-plugin, quota, rate-limit, rate-limiting, retry, rotator, tui

## 简介

OpenCode plugin that rotates multiple Google Gemini API keys to bypass per-key rate limits (HTTP 429) and quota exhaustion (HTTP 403/503 RESOURCE_EXHAUSTED) — drop-in, transparent fetch interceptor with cooldown and TUI sidebar.
