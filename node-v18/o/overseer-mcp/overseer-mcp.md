# overseer-mcp

> 标签: agents, code-review, llm, mcp, model-context-protocol, multi-agent, orchestration

## 简介

MCP server that lets a cheap executor agent consult a capable expert at three gates: planning, mid-implementation decisions, and final review. Expert receives executor summaries and real evidence, never reads the repo directly.
