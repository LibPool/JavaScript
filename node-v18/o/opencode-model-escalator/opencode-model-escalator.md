# opencode-model-escalator

> 标签: coding-agent, cost-optimization, llm, model-escalation, model-fallback, model-router, opencode, opencode-plugin, plugin, rate-limit

## 简介

OpenCode plugin that escalates a coding agent through a cheap-to-strong model chain when it is logically stuck (the same test keeps failing across repair cycles) or the current model is rate-limited or unavailable.
