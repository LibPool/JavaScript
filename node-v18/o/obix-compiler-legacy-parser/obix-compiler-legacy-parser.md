# obix-compiler-legacy-parser

> 标签: obix

## 简介

LEGACY compatibility track (D-46): the Level-0 OBIX section scanner + strict OBIX template/script parser, frozen. Produces an AST that must pass obix-spec.validateObixAST(). Depends only on obix-spec. The Vue SFC parser of the new pipeline is obix-compile
