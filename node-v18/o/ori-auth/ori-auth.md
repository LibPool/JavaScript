# ori-auth

> 标签: authentication, firebase, firebase auth, firebase authentication, firebase user, password reset, user authentication, user creation, user login, user management

## 简介

Ori-Auth is a simple Javascript npm package designed to handle Firebase authentication. It offers a set of easy-to-use functions for creating users, retrieving user data, logging in, resetting passwords, and logging out.
