# opencode-glm-usage

> 标签: bigmodel, glm, opencode, opencode-plugin, opencode-tui-plugin, quota, sidebar, usage, z.ai, zhipu, zhipuai

## 简介

OpenCode TUI plugin that shows Zhipu (智谱/GLM/Z.ai/BigModel) quota usage — 5h token limit, monthly MCP limit, 24h token total, per-model and per-tool breakdown — in the sidebar.
