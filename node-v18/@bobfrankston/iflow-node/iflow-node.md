# @bobfrankston/iflow-node

> 标签: imap, node, tcp, tls, transport

## 简介

Back-compat shim — re-exports NodeTcpTransport from @bobfrankston/node-tcp-transport as NodeTransport. New code should use node-tcp-transport directly.
