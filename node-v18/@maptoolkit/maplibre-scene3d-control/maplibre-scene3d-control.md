# @maptoolkit/maplibre-scene3d-control

> 标签: 3d, buildings, control, gltf, map, maplibre, maplibre-gl, plugin

## 简介

A MapLibre GL JS control plugin that adds the 3D scene of a Maptoolkit style: 3D buildings and glTF vegetation.
