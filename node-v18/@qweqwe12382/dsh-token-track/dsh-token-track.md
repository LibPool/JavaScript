# @qweqwe12382/dsh-token-track

> 标签: JavaScript

## 简介

每日 token 用量追踪器：按本地自然日统计输入/输出/缓存/思考 token，会话头部提供 Codex/Claude 桌面风格的用量卡片（今日总量大数字 + 近 7 天柱状图），数据来自 host 侧 session/event 聚合，免重启注入即用
