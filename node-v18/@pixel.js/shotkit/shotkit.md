# @pixel.js/shotkit

> 标签: cross-platform, headless, headless-browser, html, html-to-image, html-to-png, html-to-webp, image, image-generation, og-image, playwright-alternative, png, prebuilt, puppeteer-alternative, renderer, screenshot, screenshot-api, server-side-rendering, thumbnail, webcore, webkit, webp

## 简介

Turn HTML or a URL into PNG/WebP screenshots without a browser — WebKit rendering, no page JavaScript, prebuilt binaries for Windows, Linux and macOS
