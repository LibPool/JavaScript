# @spinejit/pi-compact-tree

> 标签: compact, pi, pi-coding-agent, pi-extension, pi-package, theme, tui, ui

## 简介

Compact process tree for Pi's terminal UI: tool calls fold into one-line summaries and thinking into titles, with a borderless input and a one-line footer.
