# @mellena1/opencode-go-usage

> 标签: go, opencode, opencode-plugin, plugin, quota, sidebar, tui, usage

## 简介

OpenCode v2 TUI plugin that shows your OpenCode Go subscription usage (5h / weekly / monthly windows) in the sidebar, fetched from the official /zen/go/v1/usage API.
