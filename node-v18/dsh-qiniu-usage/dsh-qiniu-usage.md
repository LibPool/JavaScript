# dsh-qiniu-usage

> 标签: dsh, dsh-plugin, qiniu, usage

## 简介

七牛云用量面板插件：在 DSH Web GUI 设置页展示指定 API Key 当天的各模型 Token 用量，以及账号资源包的利用情况
