# @ratel-ai/vercel-ai-sdk

> 标签: ai-agents, ai-sdk, context-engineering, framework-adapter, ratel, tool-calling, vercel-ai-sdk

## 简介

Vercel AI SDK adapter for Ratel — adapts the context-engineering core to the AI SDK's (ai@5-7) tool and message shapes, with per-turn recall helpers.
