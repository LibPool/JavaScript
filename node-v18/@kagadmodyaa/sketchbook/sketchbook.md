# @kagadmodyaa/sketchbook

> 标签: book, flipbook, page-flip, portfolio, react, sketchbook

## 简介

A page-turning sketchbook component for React, built from DOM + CSS 3D transforms, no WebGL, no dependencies beyond react/react-dom.
