# @loomweaver/plugin-sdk

> 标签: angular, extensibility, loomweaver, plugin, plugin-contract, plugin-platform, sdk

## 简介

LoomWeaver: open-source plugin platform for Angular workbenches. The plugin contract: the types a weaver depends on, ProductIdentity, Command, PluginContext and the host UI vocabulary.
