# @loomweaver/devkit

> 标签: angular, generator, loomweaver, nx, nx-plugin, plugin-platform, scaffolding

## 简介

LoomWeaver: open-source plugin platform for Angular workbenches. The Nx generators: weavers, distributions, frame plugins and the integration seams, plus the manifest and i18n validators.
