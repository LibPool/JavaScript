# @loomweaver/cli

> 标签: cli, codegen, generator, loomweaver, scaffolding

## 简介

LoomWeaver: open-source plugin platform for Angular workbenches. The scaffolding CLI: generates weavers, distributions and integrations into any project, with no Nx workspace and no checkout required.
