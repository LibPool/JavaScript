# @kungal/ui-nuxt

> 标签: components, kun-ui, kungal, nuxt, nuxt-layer, nuxt-module, ui, vue

## 简介

KunUI Nuxt Layer — wraps @kungal/ui-vue, auto-imports the components, and injects NuxtLink + @nuxt/icon so existing Nuxt apps keep their exact DX.
