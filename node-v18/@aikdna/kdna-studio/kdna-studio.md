# @aikdna/kdna-studio

> 标签: authoring, compile, domain-judgment, human-lock, judgment-cards, kdna, validate

## 简介

Open-source authoring kernel for creating KDNA domains — JS/npm package. KDNA Studio lets any app create valid, testable, packageable KDNA domains.
