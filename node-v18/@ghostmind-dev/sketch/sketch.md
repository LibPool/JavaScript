# @ghostmind-dev/sketch

> 标签: animation, annotation, blackboard, diagram, education, explainer, handwriting, math, svg, whiteboard

## 简介

Hand-written explainer boards for the browser: one scene renders as a stroke-by-stroke animation (optional pencil and writing sound) or a static board.
