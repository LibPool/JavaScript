# @davidcjw/agentwatch

> 标签: agents, ai, claude, claude-code, cli, cost, dashboard, developer-tools, live, monitor, observability, tokens, tui

## 简介

A live perch over your Claude Code agents. A zero-dependency terminal dashboard showing every active session in real time — what it's doing right now, its tokens, cost, and whether it needs you. The runtime sibling to agentmeter.
