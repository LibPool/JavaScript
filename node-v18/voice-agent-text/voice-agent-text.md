# voice-agent-text

> 标签: backchannel, barge-in, llm, markdown, sentence-splitting, streaming, text-to-speech, tts, voice-agent, voice-ai, wake-word

## 简介

Text handling for voice agents: speak the prose of a streamed LLM reply and withhold its lists, tables and code, cut it into chunks a TTS engine can start on early, and tell a real interruption from a listener's "mhm".
