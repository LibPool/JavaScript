# casesheet

> 标签: codegen, csv, data-driven, e2e, excel, keyword-driven, markdown, playwright, playwright-python, pytest, qa, test-cases, xlsx, 测试用例, 自动化测试

## 简介

Turn the test-case tables QA already writes (Markdown, CSV, Excel) into runnable Playwright specs (TypeScript, JavaScript or pytest), run them, and write the results back into the sheet. Chinese and English steps, no LLM, zero dependencies.
