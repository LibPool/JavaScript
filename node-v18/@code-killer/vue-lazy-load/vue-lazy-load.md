# @code-killer/vue-lazy-load

> 标签: blob-cache, directive, image, indexeddb, intersection-observer, lazy-load, lru-cache, v-lazy, vue, vue3

## 简介

Vue 3 图片懒加载指令插件，基于 IntersectionObserver + 两级缓存（LRU 内存 + IndexedDB 持久化）
