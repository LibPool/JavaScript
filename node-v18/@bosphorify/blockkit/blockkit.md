# @bosphorify/blockkit

> 标签: block-editor, blocknote, content, markdown, mdx-alternative, react, renderer, rich-text, wysiwyg

## 简介

Curated block editor + renderer on top of BlockNote: one registry, an allowlist renderer (block JSON → React), one-way agent markdown, and an opt-in executable block.
