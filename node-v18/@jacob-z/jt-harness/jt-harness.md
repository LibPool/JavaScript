# @jacob-z/jt-harness

> 标签: JavaScript

## 简介

`jth` 是本地 TypeScript CLI，提供长任务流程控制与长期记忆。`jth flow` 用短 Skill 配合 Codex 原生 Goal、任务列表、会话恢复和项目测试；`jth memo` 接收主会话末尾的短记忆声明，只将新记忆正文发送给 Embedding API，记忆和来源保存在 PostgreSQL + pgvector。
