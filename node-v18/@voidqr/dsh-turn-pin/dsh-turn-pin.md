# @voidqr/dsh-turn-pin

> 标签: deepseek-harness, dsh, dsh-plugin, sticky, turn-status

## 简介

DSH Web UI turn-pin: while a turn is running, pin its 'deep diving' header button to the top of the conversation viewport with CSS position:sticky, so the streaming status stays visible instead of being scrolled out of sight
