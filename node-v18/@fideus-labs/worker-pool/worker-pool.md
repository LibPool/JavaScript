# @fideus-labs/worker-pool

> 标签: chunk-queue, concurrency, itk-wasm, node, web-worker, worker-pool, worker-threads, zarrita

## 简介

A worker pool with bounded concurrency, for Web Workers and node:worker_threads. ChunkQueue-compatible add/onIdle and batch runTasks/cancel interfaces.
