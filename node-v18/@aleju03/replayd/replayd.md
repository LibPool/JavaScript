# @aleju03/replayd

> 标签: event-log, eventsource, last-event-id, libsql, resumable, server-sent-events, sqlite, sse

## 简介

Resumable Server-Sent Events on SQLite: a durable event log, Last-Event-ID replay on reconnect, explicit gap signalling, and per-topic client tracking.
