# @allratestoday/central-bank-mcp

> 标签: allratestoday, central-bank, claude, currency, currency-api, currency-conversion, currency-exchange, currency-exchange-rates, currency-rates, cursor, ecb, exchange rate, exchange rates, exchange-rate, exchangerate, forex, forex-api, mcp, model-context-protocol, official-rates, tax

## 简介

MCP server for official central-bank and tax-authority exchange rates — let AI tools (Claude Code, Cursor, Claude Desktop) fetch published rates from 120+ institutions (ECB, Fed, HMRC, BOJ, ...) via the AllRatesToday API.
