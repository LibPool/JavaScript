# @allratestoday/moneyify

> 标签: allratestoday, big.js, cashify, conversion, convert, currency, currency-api, currency-conversion, currency-converter, currency-exchange, currency-exchange-rates, currency-rates, exchange, exchange rate, exchange rates, exchange-rate, exchangerate, forex, forex-api, fx, mid-market, money, money.js, moneyify, typescript

## 简介

Lightweight currency conversion library — cashify-compatible API with optional auto-fetch from the AllRatesToday API. 160+ currencies, mid-market rates, zero runtime deps.
