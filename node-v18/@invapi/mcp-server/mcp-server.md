# @invapi/mcp-server

> 标签: automation, cii, conversion, digitalisierung, digitization, e-invoice, e-invoicing, en16931, extraction, factur-x, invapi, invoice, invoicing, mcp, mcp-server, model-context-protocol, ocr, pdf, peppol, rechnungen, ubl, validation, xlsx, xml, xrechnung, zugferd

## 简介

Invoice MCP server — extract structured data from PDF & image invoices, create e-invoices (UBL, CII, ZUGFeRD/Factur-X), convert between formats including Excel, and validate against EN 16931.
