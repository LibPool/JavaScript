# @asheghi/dsh-self-improved

> 标签: deepseek-harness, dsh, long-term-memory, memory, plugin, self-improvement

## 简介

Long-term memory and session continuity for DeepSeek Harness 0.2.1+: captures conversations, extracts reviewed memories, recalls them before each reply, and offers to continue unfinished work. Local storage; model calls are opt-in.
