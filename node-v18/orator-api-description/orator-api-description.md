# orator-api-description

> 标签: api, description, meadow, openapi, orator, reference, retold

## 简介

A self-describing JSON API reference for Orator/Meadow servers: routes, schemas, example payloads and curl snippets, auto-derived from the compiled Meadow model and the live route table, so an agent or a developer UI can learn the API.
