# @tracescout/nuxt

> 标签: debug-id, nuxt, source-maps, symbolication, tracescout, vite

## 简介

TraceScout Nuxt integration — browser-chunk debug-ID injection and private source-map upload for stack-trace symbolication (Nuxt 3/4 Vite builds via module; Nuxt 2 via post-build bin).
