# @tracescout/browser

> 标签: analytics, monitoring, performance, session-recording, tracescout, web-vitals

## 简介

Browser SDK for TraceScout: session replay, error & console capture, Web Vitals, and automatic fetch/XHR network capture — with W3C trace-context correlation to your backend logs. **Beta.**
