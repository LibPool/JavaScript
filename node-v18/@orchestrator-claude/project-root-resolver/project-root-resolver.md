# @orchestrator-claude/project-root-resolver

> 标签: anthropic, claude-code, multi-project, orchestrator

## 简介

Zero-dependency shared primitive that walks up from a cwd to find the nearest ancestor holding a project sentinel directory (RFC-040 C1)
