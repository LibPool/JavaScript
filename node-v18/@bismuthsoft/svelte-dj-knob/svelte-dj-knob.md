# @bismuthsoft/svelte-dj-knob

> 标签: JavaScript

## 简介

This is a svelte component which provides a knob like those seen in popular DJ software. Setting a value on the knob is not based on click position, rather dragging up increases the value, and dragging down decreases the value. Single clicking on the knob
