# @onveloz/pulse

> 标签: create, offline-first, postgres, pulse, reactive, scaffold

## 简介

Create and run Pulse apps. `npx @onveloz/pulse new <name>` scaffolds a fully-configured, reactive offline-first app on Postgres.
