# @lowcoai/api

> 标签: document-ai, gst, invoice, lowco, ocr, pdf, qr, sdk, upi

## 简介

Official Node/TypeScript client for the Lowco API: PDF, render, OCR, Document AI, QR and barcodes, with jobs, file inputs, webhooks and typed errors.
