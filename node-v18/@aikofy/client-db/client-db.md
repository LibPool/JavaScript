# @aikofy/client-db

> 标签: consumer-client, crdt, hlc, indexeddb, offline-first, p2p, rpc, sync, webrtc

## 简介

Offline-first, peer-to-peer IndexedDB sync (HLC, CRDT conflict resolution, WebRTC gossip) with a Consumer Client RPC layer for thin clients that call functions instead of replicating
