# @packpath/digital-link

> 标签: application-identifier, barcode, digital-link, element-string, gs1, gtin, qr-code, sunrise-2027

## 简介

Parse, build and validate GS1 Digital Link URIs and GS1 element strings. Zero dependencies; runs in browsers, Node.js and Cloudflare Workers.
