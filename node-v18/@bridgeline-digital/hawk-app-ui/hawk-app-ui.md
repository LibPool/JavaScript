# @bridgeline-digital/hawk-app-ui

> 标签: embedded-apps, hawksearch, mui, react, spark, web-components

## 简介

For Bridgeline developers: the Spark look for Hawk Apps: for React + MUI, the theme (following the host's colors and mode), the app provider and shared components; for any app (vanilla, Preact, React, Next), a stylesheet and custom elements.
