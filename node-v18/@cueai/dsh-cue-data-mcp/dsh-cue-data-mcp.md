# @cueai/dsh-cue-data-mcp

> 标签: cue, data, deepseek-harness, dsh, dsh-plugin, finance, mcp

## 简介

DSH bundle: exposes Cue's public data MCP services (regulatory, macro, disclosures, market data, statute, holdings, entity, academic, IPO, ESOP, buyback, footnote, fact index) as native mcp__cue_<domain>__* tools.
