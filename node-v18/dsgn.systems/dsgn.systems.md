# dsgn.systems

> 标签: accessibility, css, dark-mode, design-system, design-tokens, figma, oklch

## 简介

dsgn — token-driven CSS design system: OKLCH colours with guaranteed contrast, density S/M/L, four corner styles, light and dark. Mirrored 1:1 in Figma.
