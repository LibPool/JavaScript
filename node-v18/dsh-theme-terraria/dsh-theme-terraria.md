# dsh-theme-terraria

> 标签: deepseek-harness, desktop, dsh-plugin, pixel-art, terraria, theme, web-ui

## 简介

Terraria pixel theme for DeepSeek Harness (Desktop + Web): a self-contained themed frontend served by the Host plus an index-injected pixel skin and Desktop takeover layer that cannot break the official UI.
