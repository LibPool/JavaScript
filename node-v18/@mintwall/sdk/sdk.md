# @mintwall/sdk

> 标签: agent, ai-agent, crypto, decision-logging, eliza, elizaos, logging, mintwall, on-chain, plugin, solana

## 简介

Log every agent decision to a permanent, verifiable on-chain profile. Includes an ElizaOS plugin adapter and CLI for session-token auth.
