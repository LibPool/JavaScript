# @tanstack/ai-sandbox-docker

> 标签: agent, ai, docker, harness, isolation, sandbox, sbx, tanstack

## 简介

Docker sandbox providers for TanStack AI — dockerSandbox() runs a container; sbxSandbox() runs a Docker Sandboxes microVM.
