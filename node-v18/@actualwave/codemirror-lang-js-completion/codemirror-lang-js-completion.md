# @actualwave/codemirror-lang-js-completion

> 标签: autocomplete, codemirror, codemirror6, completion, javascript

## 简介

Lightweight JavaScript completion for CodeMirror 6: globals and type-inferred member suggestions (strings, arrays, Map/Set/Date/Promise, object literals, classes) with no TypeScript compiler or worker
