# @hoardodile/7z-bin

> 标签: 7-zip, 7z, 7zip, binary, ffmpeg-static

## 简介

7-Zip 26.02 full binaries (7z.exe+7z.dll / 7zz, RAR-capable) for the archive runtime, downloaded from GitHub Releases at install time (ffmpeg-static style).
