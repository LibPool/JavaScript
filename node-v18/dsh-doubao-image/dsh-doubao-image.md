# dsh-doubao-image

> 标签: agent-tool, cordis, deepseek-harness, doubao, dsh, dsh-plugin, image-generation, tabbit

## 简介

Doubao Web AI Image Generation Agent Tool plugin for DeepSeek Harness (豆包网页版 AI 生图 Agent 工具插件：向 Agent 注册 doubao_generate_image 与 doubao_image_status 原生工具，通过 Tabbit 浏览器自动化操控 doubao.com 文生图、自动优选 wm0 无水印 2.7K 超清原图落盘并作为多模态图像附件返回)
