# @myapihq/cli

> 标签: ai-agent, cli, domains, landing-page, mcp, model-context-protocol, myapi, transactional-email

## 简介

Command-line interface for MyAPI — websites on your own domain, business email, payments, a customer list. Agents should use the MyAPI MCP server instead: https://api.myapihq.com/mcp
