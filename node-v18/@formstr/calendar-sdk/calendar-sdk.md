# @formstr/calendar-sdk

> 标签: JavaScript

## 简介

Headless TypeScript SDK for the Formstr calendar protocol — private and public events, calendar lists, gift-wrapped invitations, RSVPs and busy lists, byte-compatible with calendar.formstr.app
