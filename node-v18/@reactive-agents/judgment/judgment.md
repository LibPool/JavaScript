# @reactive-agents/judgment

> 标签: agents, ai, ai-agents, classification, decision-models, effect-ts, jev, judgment, llm, ollama, systemone, typesafe, typescript

## 简介

Calibrated typed judgment primitive (Choice/Score/Noul) for Reactive Agents, provider-abstracted over TypeSafe/Jev, an LLM-emulation fallback, and a local Ollama System One backend
