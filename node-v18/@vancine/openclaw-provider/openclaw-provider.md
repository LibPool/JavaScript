# @vancine/openclaw-provider

> 标签: ai, chat-completions, openclaw, openclaw-plugin, provider, vancine

## 简介

Third-party OpenClaw provider plugin for Vancine Chat Completions. Reads model inventory from the public /api/pi/catalog and intersects it with /v1/models. Not affiliated with OpenClaw.
