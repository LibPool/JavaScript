# @wbc-ui/js

> 标签: JavaScript

## 简介

WBJS framework loader (WBGC) for Vue 2 — part of the @wbc-ui2 ecosystem. Standalone loader that drives @wbc-ui/core (WBC) plus the dataviewer surface.
