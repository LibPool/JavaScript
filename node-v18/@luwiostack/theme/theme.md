# @luwiostack/theme

> 标签: css-variables, custom-properties, design-tokens, hooks, luwio, oklch, react, theme, theming

## 简介

Headless theming for React — a JSON token config compiled to scoped CSS variables, with a `<Theme>` component, `scope()` markers, and `tokenRef` / `readToken`. Nearest-step and OKLCH-generated colour scales.
