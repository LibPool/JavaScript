# @luwiostack/bootstrap

> 标签: bootstrap, config, etag, hooks, luwio, react, stale-while-revalidate, startup-config

## 简介

Bootstrap (startup) config for apps — fetch the one config document before mount, with ETag caching + stale-while-revalidate, then build your app from it. Runtime/reactive state belongs in your data layer (e.g. TanStack Query), not here. React-free core +
