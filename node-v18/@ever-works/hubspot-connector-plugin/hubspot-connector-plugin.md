# @ever-works/hubspot-connector-plugin

> 标签: JavaScript

## 简介

HubSpot CRM connector plugin for Ever Works platform (outbound notes + record creation via the official @hubspot/api-client, and event-source pull of contact/company/deal changes into the event-ingest pipeline, with opt-in historical backfill)
