# @wxyzh/dsh-auth-proxy

> 标签: JavaScript

## 简介

Token-auth reverse proxy for dsh web: listen on 0.0.0.0, verify a static token via a built-in login page, then forward HTTP + WebSocket to the loopback webserver. No dsh source changes.
