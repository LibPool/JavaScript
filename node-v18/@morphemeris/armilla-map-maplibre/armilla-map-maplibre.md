# @morphemeris/armilla-map-maplibre

> 标签: astrocartography, astrology, map, maplibre, overlay, visualization

## 简介

MapLibre GL JS adapter for armilla's astrocartography line model (spec §12.2): draws predicate-honoring ACG lines, labels, and the place marker over a tiled basemap.
