# @invana/canvas-ui

> 标签: canvas, components, design-kit, editor, graph, react, ui

## 简介

Schema-driven, engine-agnostic React UI components (style editors, panels, controls) for Invana graph tools — built on the @invana/forms design-kit form-generator.
