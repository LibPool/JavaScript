# @meowshed/meow-prose-gate

> 标签: meowpaw, pi-package

## 简介

Stops Claude Code from publishing a commit message, pull request, issue, comment or release note that carries a writing defect any reader can point to. A program blocks a stock idiom from a fixed list, a line of bold text in place of a heading and text hi
