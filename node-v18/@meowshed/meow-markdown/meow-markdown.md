# @meowshed/meow-markdown

> 标签: meowpaw, pi-package

## 简介

Detects a Markdown corpus from what git tracks, lists the tools a repository configured for it, and prints a stages table bound from that configuration, reports a missing render target, markdownlint settings the lint stage lacks, ignores or never applies
