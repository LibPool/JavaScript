# @meowshed/meow-lua

> 标签: meowpaw, pi-package

## 简介

Detects Lua and Neovim plugins from what git tracks, names the runtime or the editor that evaluates the code before it binds anything, prints a stages table bound from the formatter, linter, test runner and rockspec the repository configured, reports a pl
