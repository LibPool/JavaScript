# @xemahq/peer-analysis

> 标签: JavaScript

## 简介

Build-time analyzer that reads a package's typed peer seams (service-registry lookups, configured peer clients, SDK facilities) from its TypeScript source and reports each peer edge, or a finding when a target cannot be determined.
