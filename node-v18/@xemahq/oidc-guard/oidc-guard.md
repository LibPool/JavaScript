# @xemahq/oidc-guard

> 标签: JavaScript

## 简介

Framework-agnostic OIDC / JWT verification and multi-tenancy primitives — JWKS fetching, issuer-metadata resolution, signature validation, tenant-claim projection and tenant fencing.
