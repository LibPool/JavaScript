# @xemahq/agent-session-nexus-contract

> 标签: JavaScript

## 简介

The Nexus contract of the agent-session service (agent-session@v1): launch an organization-owned agent session, run one turn on it with the result pushed back when the turn ends, and erase it with a per-surface receipt. Imported by callers into their work
