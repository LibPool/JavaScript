# @xemahq/backend-slot-registry-adapters

> 标签: JavaScript

## 简介

Adapter wrappers that project existing in-process per-service registries (MountSourceKindRegistry, InquiryKindSchemaRegistry, …) into a BackendSlotRegistry under their ContributionKind. Honours the 'adapt, not rewrite' policy: pre-existing registries keep
