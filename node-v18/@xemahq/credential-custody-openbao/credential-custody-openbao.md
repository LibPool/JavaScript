# @xemahq/credential-custody-openbao

> 标签: JavaScript

## 简介

OpenBao KV-v2 provider for the Xema credential custody contract (@xemahq/credential-custody). Vault-wire-compatible; a thin fetch shim with no vendor SDK. Exports the provider definition the credential broker composes, selected by deployment configuration
