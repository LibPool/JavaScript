# @xemahq/storage-driver

> 标签: JavaScript

## 简介

Every Xema StorageDriver adapter in one package — Kubernetes CSI (Longhorn, NFS, EFS, Filestore, Azure Files), Docker local, Docker Swarm CSI and host-path — plus the per-backing native-semantics table and the conformance suite a new driver is held to.
