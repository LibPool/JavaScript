# @xemahq/biome-sdk

> 标签: JavaScript

## 简介

Consolidated biome-authoring SDK for Xema. One package, per-surface subpath exports. `./builder` (defineBiome, content schemas) and `./host` (framework-agnostic host primitives) are NestJS-free, so a content-only biome installs this package plus @xemahq/c
