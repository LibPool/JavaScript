# @ekwo-ai/vat-consignment

> 标签: belgium, declaration-tva, intervat, spf-finances, tva, vat, vat-return, vatconsignment, xml

## 简介

The Belgian periodic VAT return for Intervat (VATConsignment XML, schema NewTVA-in v0.9) in TypeScript, from the figures a declaration was filed with. Zero dependencies.
