# @ekwo-ai/vd

> 标签: ec-sales-list, emta, estonia, intra-community, uhendusesisese-kaibe-aruanne, vat, vd, xml

## 简介

The Estonian form VD — uhendusesisese kaibe aruanne — in TypeScript: the XML the e-MTA loads, from plain statement rows. Zero dependencies.
