# @masterdeepak15/teamhub-client

> 标签: claude, claude-code, cli, client, mcp, model-context-protocol, multi-agent, team

## 简介

TeamHub Client — connect to a remote TeamHub server and run Team Lead/Developer/Tester Claude Code sessions (interactive or headless) from any machine. No server code, no native dependencies — just point it at a server's IP:port.
