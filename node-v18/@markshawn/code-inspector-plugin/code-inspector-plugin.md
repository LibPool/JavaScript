# @markshawn/code-inspector-plugin

> 标签: copy-path, enhanced, inspect, inspector, mode-switching, plugin, vite, vscode, vue, webpack

## 简介

Enhanced code-inspector with mode switching: Click DOM to open IDE or copy path. Press Shift+Alt+C to toggle modes.
