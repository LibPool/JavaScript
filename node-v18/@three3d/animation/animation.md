# @three3d/animation

> 标签: 3D, ThreeJS, animation, bone, path animation, 蒙皮动画, 路径动画, 骨骼动画

## 简介

@three3d/animation 提供了关于 ThreeJS 的一些动画相关的工具和方法，如：路径动画、骨骼动画 等
