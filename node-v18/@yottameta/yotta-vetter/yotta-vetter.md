> 标签: agent-skills, security, skill-vetting, supply-chain, yotta-vetter, yottaskills

## 简介

Yuanshen (元审) — the security review protocol before installing any skill: a four-phase checklist (source → code → permissions → risk) + a lightweight checker, with deep-scan handoff to yotta-security-audit. Triggers before installing/evaluating any skill
