# @promo-operations-platform/tenant-sdk

> 标签: JavaScript

## 简介

Brand/organization-agnostic client SDK for tenant casino sites to report player attributes to a Promo Operations Platform (POP) instance's marketing event ingestion API. Not specific to any single brand or organization — see docs/113_TENANT_CLIENT_SDK_ARC
