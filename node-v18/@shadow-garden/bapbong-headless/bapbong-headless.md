# @shadow-garden/bapbong-headless

> 标签: JavaScript

## 简介

bapbong — headless backend façade: one install re-exporting contracts + model + docx + commands (isomorphic, no DOM). Import .docx → edit via commands on an EditorState → export .docx, server-side.
