# @angineer/smartree

> 标签: JavaScript

## 简介

通用树组件库（Vue 3 + ant-design-vue）：SmartTree——搜索高亮、拖拽排序、文件拖入上传、状态标签、虚拟滚动，外加一套零依赖的树工具函数。
