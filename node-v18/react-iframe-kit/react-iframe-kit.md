# react-iframe-kit

> 标签: embed, hooks, iframe, iframe-resizer, micro-frontends, portal, postmessage, react, resize, rpc, widget

## 简介

Hooks-first React toolkit for iframes: portal rendering, auto-resize and a typed RPC bridge in one package.
