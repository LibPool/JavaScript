# @gnldev/queue

> 标签: agent, ai, ai-sdk, background-jobs, durable, exactly-once, jobs, llm, typescript, worker

## 简介

Durable background-task queue + worker on @gnldev/durable. Jobs run as durable runs → crash mid-job resumes exactly-once.
