# deepseek-chan-sleep-shutdown

> 标签: deepseek-harness, dsh, dsh-plugin, mascot, moon, shutdown, 关机

## 简介

Night & moon themed shutdown plugin for DeepSeek Harness — a sleepy DeepSeek-chan whale mascot button. 深夜月亮主题：鲸鱼娘睡觉形象按钮，任务完成后自动关机（可拖动、自动避让、倒计时可取消）。
