# @ekeelstudiokoikoi/iris

> 标签: JavaScript

## 简介

Iris is an Immediate-Mode GUI Library for Roblox, based on Dear ImGui, plus ImPlot widgets from LinusKat/ImPlot (forked by ekeelstudiokoikoi)
