# @sanidesk/site-kit

> 标签: JavaScript

## 简介

Headless Vue 3 primitives for SaniDesk tenant public sites. Asset helper + components (MenuPreview, ReservationForm, AddressBlock, HoursBlock, ContactForm, ...) — markup and styles owned by the consuming template.
