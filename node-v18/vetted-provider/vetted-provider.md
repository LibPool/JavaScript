# vetted-provider

> 标签: chainlist, ethereum, ethers, evm, getLogs, json-rpc, load-balancing, performance, provider, rpc, websockets, ws

## 简介

Ethers provider that rates every public RPC for an EVM chain (getLogs limits, revert data, gas cap, rate limits, latency, WebSocket health) and pick the best one for the job.
