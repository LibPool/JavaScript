# @react-native-ohos/react-native-secure-key-store

> 标签: Device Security, HUKS, KeyChain service, KeyStore service, android, harmonyos, ios, openharmony, react-native

## 简介

React Native Library for securely storing keys to iOS, Android and HarmonyOS devices in KeyChain, KeyStore and HUKS respectively.
