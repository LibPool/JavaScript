# @guardbee/mcp-audit-gap-auditor

> 标签: ai-security, audit, devtools, guardbee, mcp, mcp-security, mcp08, owasp, security, telemetry

## 简介

MCP server that audits MCP server source for OWASP MCP08:2025 (Lack of Audit and Telemetry) — missing tool-call logging, raw args/results in logs, disabled audit sinks, and tool errors swallowed without a record
