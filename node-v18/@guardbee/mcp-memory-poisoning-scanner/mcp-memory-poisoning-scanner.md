# @guardbee/mcp-memory-poisoning-scanner

> 标签: agent-security, ai-security, devtools, guardbee, mcp, memory-poisoning, prompt-injection, rag, security

## 简介

MCP server that scans agent code for memory-poisoning risks — untrusted input written into persistent, cross-session memory (MemGPT-style archival/core memory, or a vector store used as a long-term knowledge base) that later gets recalled and trusted as c
