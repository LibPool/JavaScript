# @guardbee/ner

> 标签: berturk, guardbee, kvkk, mcp, ner, onnx, person-name, pii, security, turkish

## 简介

Optional NER backend for GuardBee: finds Turkish person names with a local BERTurk model (ONNX, offline), in-process or as a sidecar HTTP service
