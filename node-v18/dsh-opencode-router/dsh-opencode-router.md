# dsh-opencode-router

> 标签: ai-models, cordis, deepseek-harness, dsh, dsh-external, dsh-plugin, dsh-plugins, free-llm, free-models, ip-pool, llm, llm-adapter, llm-provider, nodejs, opencode, opencode-zen, plugin, proxy-pool

## 简介

OpenCode Zen free models for DeepSeek Harness: a native dsh-llm adapter that needs no API key, with a proxy exit pool that rotates, probes and scales to hundreds of exits.
