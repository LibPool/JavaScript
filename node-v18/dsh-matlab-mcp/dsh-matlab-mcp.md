# dsh-matlab-mcp

> 标签: agentic-toolkit, deepseek-harness, dsh, dsh-plugin, mathworks, matlab, mcp, plugin, simulink

## 简介

DeepSeek Harness (DSH) plugin — connects DSH to MATLAB and Simulink through the official MathWorks MATLAB MCP Server, injects MATLAB/Simulink Agentic Toolkit skills, and provisions everything with one click.
