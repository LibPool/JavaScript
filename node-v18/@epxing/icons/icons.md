# @epxing/icons

> 标签: JavaScript

## 简介

图标构建工具 + 运行时（源码分发：在消费方的构建里跑，无需预构建）。构建期按需生成 Remix 图标与项目彩色图标的 CSS 规则；运行时按需补齐数据库里配的、构建期看不见的图标。渲染底座在 @epxing/theme 的 icons/base.scss。
