# @bvksound/homebridge-lg-thinq

> 标签: homebridge-plugin, homekit, lg, lg-thinq

## 简介

A Homebridge plugin for controlling/monitoring LG ThinQ devices via LG ThinQ platform. Fork of homebridge-lg-thinq with the LG preLogin 403 (axios User-Agent) fix applied — see nVuln/homebridge-lg-thinq#400 / #402.
