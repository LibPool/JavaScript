# @httpanimations/sji

> 标签: JavaScript

## 简介

SJI (Simple JavaScript Imports) is a lightweight utility for dynamically importing single JavaScript modules or all modules from a directory in Node.js. It simplifies the process of managing and loading your application’s code.
