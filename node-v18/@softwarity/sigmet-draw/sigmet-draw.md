# @softwarity/sigmet-draw

> 标签: JavaScript

## 简介

Draw SIGMET/AIRMET geometries on any map (grafts onto MapLibre, OpenLayers or Leaflet, Terra-Draw-style) and (de)serialize them to/from ICAO TAC.
