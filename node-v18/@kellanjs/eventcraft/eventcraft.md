# @kellanjs/eventcraft

> 标签: dx, event-emitter, events, hooks, pub-sub, react, subscribers, type-inference, type-safety, typescript

## 简介

A tiny, type-safe event library with inferred payloads, selective subscriptions, and optional React hooks.
