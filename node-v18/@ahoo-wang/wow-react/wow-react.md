# @ahoo-wang/wow-react

> 标签: cqrs, event-sourcing, hooks, query, react, typescript, wow, wow-react

## 简介

React hooks for Wow (https://github.com/Ahoo-Wang/Wow) queries: single, list, paged, count and list-stream. Requires React 19.3 or later.
