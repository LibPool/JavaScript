# @cson-sec/vn-llm-guard

> 标签: ai-security, guard, llm, pii, prompt-injection, sanitizer, validator, vietnamese

## 简介

Input/output validation and sanitization guard for Vietnamese LLM applications. Detects prompt injection, PII leakage, and toxic content in Vietnamese text.
