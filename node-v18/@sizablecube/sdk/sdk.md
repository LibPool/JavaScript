# @sizablecube/sdk

> 标签: api-client, axios, journal, react-query, sdk, typescript

## 简介

Shared TypeScript SDK (typed API client + React Query hooks) for the Journal app's backends. No universal gateway — each backend keeps its own proxy; see configureSdk().
