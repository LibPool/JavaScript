# @agent-relay/opencode-plugin

> 标签: agent-relay, agentrelay, multi-agent, opencode, opencode-plugin

## 简介

Agent Relay for OpenCode: lets the Agent Relay desktop deliver relay messages from other agents into an open OpenCode session and read the answer back, over a private Unix socket.
