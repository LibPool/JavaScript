# @briefi/mcp-server

> 标签: ai, briefi, claude, crm, cursor, mcp, meetings, model-context-protocol

## 简介

Model Context Protocol server for Briefi - lets Claude / Cursor / any MCP-aware client read meetings, generate briefs, triage email, and push to your CRM via the Briefi v1 REST API.
