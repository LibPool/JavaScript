# @gestaltrun/dsh-client-ui-preset-center

> 标签: JavaScript

## 简介

Community agent-preset manager: the Workshop's Presets panel and the host library that installs, enables, disables and uninstalls presets downloaded from dsh-market.com, keeping disabled presets out of every discovery root.
