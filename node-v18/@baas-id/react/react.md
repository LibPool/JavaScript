# @baas-id/react

> 标签: baas, document capture, face match, identity verification, idv, kyc, liveness, onboarding, react

## 简介

BaaS identity verification for React: guided ID and face capture with on-device quality gating, server-side verdicts, phone handoff. Requires a BaaS account.
