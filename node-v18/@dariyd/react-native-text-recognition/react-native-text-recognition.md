# @dariyd/react-native-text-recognition

> 标签: android, fabric, image-to-text, ios, ml-kit, multi-language, new-architecture, ocr, pdf, react-native, text-detection, text-recognition, turbomodules, vision, vision-api

## 简介

Advanced OCR text recognition for React Native with Vision API (iOS) and ML Kit (Android). Supports multi-language recognition, PDF files, and both old and new React Native architectures.
