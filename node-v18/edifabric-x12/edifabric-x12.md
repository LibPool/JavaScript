# edifabric-x12

> 标签: edi, edifabric, ffi, hipaa, json, x12

## 简介

Node.js bindings for ediFabric Native X12: convert X12 EDI to JSON and back, validate, and generate acknowledgments.

## 官网

- 官网：https://www.edifabric.com/edifabric-native.html
- 源码仓库：git+https://github.com/EdiFabric/edifabric-nodejs-bindings.git
- npm 页面：https://www.npmjs.com/package/edifabric-x12

- 1.1.1

## 获取地址

- npm registry：https://registry.npmjs.org/edifabric-x12
