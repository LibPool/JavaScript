# @noctcore/eslint-plugin-async-safety

> 标签: abortsignal, async, concurrency, eslint, eslint-plugin, eslintplugin, fetch, noctcore

## 简介

ESLint rules for async correctness: fetch timeouts, AbortSignal forwarding, and shared-state / concurrency races.
