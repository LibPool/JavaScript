# @netanelgilad/rolldown

> 标签: bundler, cloudflare, rolldown, rollup, single-threaded, wasm, workerd

## 简介

Single-threaded WASM Rolldown fork that runs inside workerd / Cloudflare Worker-Loader child isolates (no native .node binding, no worker threads). Drop-in for `rolldown`. Self-contained: ships the single-threaded rolldown.wasm + the patched emnapi/@tybys
