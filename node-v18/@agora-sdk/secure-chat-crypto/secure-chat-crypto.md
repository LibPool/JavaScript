# @agora-sdk/secure-chat-crypto

> 标签: agora, crypto, e2ee, mls, rfc9420, secure-chat, typescript

## 简介

The SecureChatCrypto seam for Agora end-to-end-encrypted chat (MLS / RFC 9420): the client crypto interface + a deterministic mock (./testing) + the real ts-mls core (./ts-mls, ESM-only). The bare entry and ./testing are dependency-free.
