# @agora-sdk/social-react-native

> 标签: agora, community, react-native, social-graph, typescript

## 简介

Bare React Native components for the Agora social graph: CommunityWeather, Constellation (d3-force + react-native-svg), Neighborhood, SocialTransparency. Re-exports @agora-sdk/social-core.
