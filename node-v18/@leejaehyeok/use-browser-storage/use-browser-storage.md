# @leejaehyeok/use-browser-storage

> 标签: browser-storage, cross-tab-sync, hooks, localStorage, react, serialization, sessionStorage, state-persistence, ttl

## 简介

A React hook for managing browser storage (localStorage and sessionStorage) with TTL support, custom serialization, and cross-tab synchronization.
