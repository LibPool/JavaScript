# @haruspex-guru/mcp-server

> 标签: anthropic, claude, finance, haruspex, mcp, model-context-protocol, stocks

## 简介

MCP server exposing the Haruspex public API as tools for stock analysis. For use with Claude Code, Claude.ai, Claude Desktop, Cursor, Windsurf, and any other MCP-compatible client.
