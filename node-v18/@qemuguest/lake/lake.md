# @qemuguest/lake

> 标签: analytics, analytics-engine, cloudflare, dashboard, data-lake, grafana, privacy, r2, react, session-recording, workers

## 简介

A first-party analytics data lake for Cloudflare Workers: event + session-recording ingest, a structured query engine over Analytics Engine and R2, and a Grafana-style React dashboard.
