# @luxwallet/tx

> 标签: JavaScript

## 简介

Per-VM unsigned-tx builders. EVM/Solana/XRP/TON/Bitcoin/Polkadot/Cardano + Lux-native X/P/Q/Z (UTXO/platform/PQ-EVM/ZK). Builds the canonical unsigned encoding + bytes-to-sign; never signs. Zero copyleft.
