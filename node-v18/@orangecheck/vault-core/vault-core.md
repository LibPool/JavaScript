# @orangecheck/vault-core

> 标签: bitcoin, end-to-end-encryption, oc-vault, orangecheck, password-manager, secrets, zero-knowledge

## 简介

The conformance-pinned crypto, entry model, ocv:// secret-reference resolver, and transport-agnostic API client for OC Vault (vault.ochk.io). Zero-knowledge by construction — the vault key is derived client-side and never leaves the process.
