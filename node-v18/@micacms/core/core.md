# @micacms/core

> 标签: cms, content-model, markdoc, mica, schema, zod

## 简介

The Mica core: content model DSL, authoring format, and the port contracts every adapter implements. Single source of truth for types, validation, editor forms, the on-disk format and Astro collection schemas.
