# joplin-plugin-webhook-button

> 标签: joplin-plugin

## 简介

Webhook Button turns a fenced block in a Joplin note into a button. Clicking the rendered button sends an HTTP `POST` webhook and shows the result in the note. This makes a note a lightweight, explicit trigger for an automation without leaving Joplin.
