# json-diff-ts

> 标签: array-diff, changeset, compare, data-sync, deep-diff, delta, diff, difference, esm, javascript, json, json-diff, json-patch, jsonpath, merge, modern, object-compare, object-diff, patch, performance, state-management, typescript, zero-dependencies

## 简介

Modern TypeScript JSON diff library - Zero dependencies, high performance, ESM + CommonJS support. Calculate and apply differences between JSON objects with advanced features like key-based array diffing, JSONPath support, and atomic changesets.
