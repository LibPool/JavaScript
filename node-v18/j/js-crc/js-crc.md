# js-crc

> 标签: crc, crc-16, crc-24, crc-32, crc-64, crc-8

## 简介

Simple CRC checksum functions for JavaScript. Supports many predefined models such as CRC-8, CRC-16, CRC-24, CRC-32, and CRC-64. It also supports custom CRC models.
