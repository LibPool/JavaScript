# jupyterlab_camunda_modeller_extension

> 标签: jupyter, jupyterlab, jupyterlab-extension

## 简介

Jupyterlab extension to allow modelling bpmn diagrams (and opening camunda bpmn diagrams) directly in jupyterlab
