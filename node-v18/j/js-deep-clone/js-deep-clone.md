# js-deep-clone

> 标签: array, arraybuffer, circular, clone, date, deep, error, map, object, prototype, regexp, set, typedarray

## 简介

A TypeScript module for deep cloning objects and arrays, with support for Date, RegExp, Set, Map, ArrayBuffer, TypedArrays, Error, and other built-in types, while handling circular references and preserving prototypes.
