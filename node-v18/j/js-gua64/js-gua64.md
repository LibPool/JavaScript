# js-gua64

> 标签: base64, gua64, 六十四卦編碼, 六十四卦编码

## 简介

六十四卦編碼，js實現 
如：“hello，世界”會編碼為“䷯䷬䷿䷶䷸䷬䷀䷌䷌䷎䷼䷲䷰䷳䷸䷘䷔䷭䷒〇”
