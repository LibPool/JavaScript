# jquery-fusioncharts

> 标签: fusioncharts, jquery, plugin

## 简介

jquery-fusioncharts wrapper allows you to render and manipulate FusionCharts using familiar jQuery syntax. It provides a thin integration layer between FusionCharts and jQuery for easy chart creation, updates, and event handling across browsers and device
