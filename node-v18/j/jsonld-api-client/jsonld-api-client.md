# jsonld-api-client

> 标签: api-platform, client, hydra, json-ld, jsonld, mercure, openapi-fetch, typescript

## 简介

Typed client for JSON-LD / Hydra APIs: openapi-fetch with auth and scope headers, an IRI cache, and Mercure subscriptions.
