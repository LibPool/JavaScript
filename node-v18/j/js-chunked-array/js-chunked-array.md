# js-chunked-array

> 标签: JavaScript

## 简介

This creates an iterable wrapper for an Array or Array-like object.   The Chunks are not generated on initialisation, but are available through the iterator.   Usage: ```javascript const chunked = new ChunkedArray(originalArray, sizeOfChunks); chunked.nex
