# jest-feature-reporter

> 标签: JavaScript

## 简介

- ✅ Describe blocks appear as headings. Nested describe blocks are nested headings   - ✅ Tests appear as list items representing features. Each feature is visually marked as Passing ✅, Failing ❌ or Skipped 🚧   - ✅ Tests can be prefixed with [test-type].
