# json-i18n-auto-translate

> 标签: batch, chatgpt, cli, gpt, i18n, json, localization, openai, translate, translation

## 简介

Batch-translate JSON key/value strings into multiple locales via the OpenAI chat API, preserving ICU-style placeholders.
