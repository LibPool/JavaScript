# jrpc2

> 标签: batch, client, express, http, https, json, json-rpc, json-rpc2, jsonrpc, jsonrpc2, koa, middleware, named, notifications, parameters, rpc, rpc2, server, socket.io, tcp, websocket, zeromq, zmq

## 简介

JSON-RPC 2.0 library with support of batches and named parameters. Features: Express, Koa, Socket.IO middlewares + HTTP, TCP, ZeroMQ transports
