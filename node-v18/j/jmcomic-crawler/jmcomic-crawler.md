# jmcomic-crawler

> 标签: comic, crawler, download, jmcomic, manga, 禁漫

## 简介

JMComic 禁漫天堂 API 的 TypeScript 实现，支持同步/异步下载本子、章节、图片，支持搜索、分类、收藏、评论等功能
