# jev-gateway

> 标签: anthropic, claude-code, codex, gateway, gemini, jev, llm, openai, opencode, proxy, tool-calling, typesafe

## 简介

Local LLM gateway that lets TypeSafe's Jev model pick the tool for coding agents. Launchers for Codex, Claude Code, OpenCode and Gemini, with a monitoring dashboard.
