# janux

> 标签: agentic-ui, agentic-web, ai-agents, bun, copilot, framework, fullstack, janux, mcp, resumability, vite, webmcp

## 简介

Core of Janux, the fullstack framework for the Agentic Web. One component, two faces: a view for humans, typed MCP tools & resources for AI agents.
