# joplin-plugin-whereabouts

> 标签: breadcrumb, folder, joplin, joplin-plugin, location, notebook, path, reveal

## 简介

Whereabouts: always shows the current notebook next to the note title, with click to filter, double-click to reveal, right-click to move.
