# js-polyfill-fjn

> 标签: JavaScript

## 简介

myReduce用于数组求和，接受两个参数，第一个是在每一项上调用的函数，可以接受四个参数，第一个参数是前一项，第二个参数是当前项，第三个参数是下标，第四个参数是数组；myBind用来改变函数的this指向，返回的是新的函数
