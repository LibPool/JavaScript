# jwt-js-decode

> 标签: browser, decode, decodeJwt, hmac, jsonwebtoken, jwt, jwtDecode, jwtResign, jwtSign, jwtSplit, jwtVerify, node, resign, resignJwt, rsa, sign, signJwt, split, splitJwt, token, ts, typescript, verify, verifyJwt

## 简介

Decode, sign/resign or verify JSON Web Tokens (JWT). Works in majority of modern browsers, Node.js and other JavaScript runtimes.
