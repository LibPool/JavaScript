# jar-string-editor

> 标签: bytecode, editor, jar, java, npm, string, tool, utility

## 简介

O `jar-string-editor` expoe duas classes principais: `StringSearcher` p a localizaçao de strings e `StringWriter` p a persistencia de modificaçoes
