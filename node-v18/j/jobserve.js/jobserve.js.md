# jobserve.js

> 标签: changes, css, event, events, handler, javascript, object, observable, observe, observe.js, trigger, triggers, typescript, watch, watcher

## 简介

A lightweight JavaScript library that allows developers to keep track of changes to JavaScript objects and/or DOM elements.
