# json2xlsx.cli

> 标签: i18n, vue-i18n, xlsx

## 简介

Editing vue-i18n locale files in XLSX, a useful program for editing an XLSX file instead of using local JSON files.

- 官网：https://github.com/emako/json2xlsx
