# jlink-wx-sdk-z

> 标签: JavaScript

## 简介

jlink-wx-sdk 是一套二次开发微信小程序的接口，用户调用相关接口，传入相关参数，返回相关数据，用户可以参考小峰管家微信小程序demo，进行二次开发
