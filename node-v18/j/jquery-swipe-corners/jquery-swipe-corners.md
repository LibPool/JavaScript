# jquery-swipe-corners

> 标签: ecosystem:jquery, jquery, jquery-plugin, swipe

## 简介

Allow to implement 6 diferent non jQuery native supported swipe events (up, down, topLeft, topRight, bottomLeft, bottomRight)
