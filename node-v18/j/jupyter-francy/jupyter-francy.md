# jupyter-francy

> 标签: extension, francy, gap, jupyter, jupyterlab, jupyterlab-extension

## 简介

Francy - An Interactive Discrete Mathematics Framework for GAP. Renders 'application/vnd.francy+json' MIME Type on Jupyter Environments
