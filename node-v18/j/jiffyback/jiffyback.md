# jiffyback

> 标签: backend, database, designers, framework, http, middleware, nodejs, rest-api, router, server, sqlite, template-engine, validation, websocket, zero-dependency

## 简介

Ultra-simple, flexible Node.js backend framework for web designers - build your entire backend in plain JavaScript, no PHP (or any dependency) required.
