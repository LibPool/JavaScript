# js-hyperscript

> 标签: JavaScript

## 简介

*js-hyperscript* provides a helper function to simplfy the creation of virtual UI trees nodes.<br> It's a pure JavaScript alterative to JSX.<br> Many thanks to the teams of "hyperscript", "react-hyperscript", "hiccup" and "reagent" for the inspiration.
