# jfactory-promise

> 标签: abort, abortable, aborted, aborting, async, asynchronous, await, awaitable, cancel, cancelable, canceled, canceling, cancellable, cancellation, chain, onabort, promise, task

## 简介

Promise where the whole tree can be awaited, canceled and expired. Provides synchronous status, explorable chain map, shared data, debug data and trace.
