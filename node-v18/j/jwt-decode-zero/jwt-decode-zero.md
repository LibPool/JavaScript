# jwt-decode-zero

> 标签: base64url, browser, claims, client-side, decode, json-web-token, jwt, no-server, privacy, zero-dependency

## 简介

Zero-dependency JWT decoder — pure client-side Base64URL decode, expiry check, claims table rendering. No network, no server, no key verification (that's intentional). Extracted from jslet.com.
