# j-bidi

> 标签: JavaScript

## 简介

Bidirectional messaging library supporting request-response, subscriptions, and push notifications. Works with both binary and plain JSON encoding. Ships with browser WebSocket and Node.js `ws` backends, or bring your own transport.
