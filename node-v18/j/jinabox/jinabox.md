# jinabox

> 标签: audio search, autocomplete, image search, jina, jina-box, jinabox, neural search, omnibox, search box, semantic search, video search

## 简介

A lightweight, customizable omnibox. Useful for searching text, images, videos, audios or all other kinds data with a Jina backend.
