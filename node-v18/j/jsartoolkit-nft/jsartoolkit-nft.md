# jsartoolkit-nft

> 标签: AR, ARToolKit, Augmented Reality, JavaScript, NFT, WebAR, jsartoolkit, jsartoolkit5, jsartoolkitNFT, markerless

## 简介

Emscripten port of ARToolKit5 to JavaScript. It is a lighter version of Jsartoolkit5 with only NFT markerless support
