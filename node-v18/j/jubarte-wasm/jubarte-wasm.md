# jubarte-wasm

> 标签: compare, diff, docx, docx-to-pdf, ooxml, pdf, redline, revisions, track-changes, tracked-changes, wasm, webassembly, word

## 简介

Word-mode DOCX redline engine (jubarte-redlines) compiled to WebAssembly: compare two DOCX files into a tracked-changes redline, accept/reject revisions, list revisions, render DOCX to PDF. Node and browser builds included, plus compare-only slim builds w
