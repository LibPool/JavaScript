# jxy-aichat-plugin

> 标签: JavaScript

## 简介

这是一款集智能对话、场景化AI助手与艺术创作为一体的全能型AI插件。通过先进的自然语言处理技术，它既能进行深度多轮对话解答各类问题，又能调用定制化GPTs角色模型满足教育咨询、编程辅助、商业策划等专业需求。独创的AI绘画引擎可将文字描述实时转化为精美画作，支持多种艺术风格切换，让您的创意想法即刻跃然眼前。无论是工作提效、学习探索还是艺术创作，这款三合一智能工具都将为您开启人机协作的全新体验。
