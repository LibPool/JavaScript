# json-stream-lite

> 标签: async, browser, incremental, json, json-parser, json-stream, large-files, lightweight, low-memory, memory-efficient, nodejs, parse, parser, stream, streaming, streaming-json, stringify, typescript, zero-dependencies

## 简介

A lightweight, memory-efficient, zero-dependency streaming JSON parser and stringifier for JavaScript and TypeScript. It works in both Node.js and browser environments.
