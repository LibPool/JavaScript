# jaygoo

> 标签: JavaScript

## 简介

- Node.js：整个脚手架的运行环境。本脚手架的 Node.js 。 - es6： JavaScript 的新语法。 - commander：TJ大神开发的工具，能够更好地组织和处理命令行的输入。本脚手架的 commander 版本： 2.15.1 。 - co：异步流程控制工具。本脚手架的 co 版本： 4.6.0 。 - co-prompt：分步接收用户的输入。本脚手架的 co-prompt 版本： 1.0.0 。 - chalk：色彩丰富的终端工具。本脚手架的 chalk 版本： 2.
