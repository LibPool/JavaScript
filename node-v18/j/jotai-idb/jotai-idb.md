# jotai-idb

> 标签: database, indexeddb, jotai, react, reactive, state-management, storage, typescript

## 简介

A typed, reactive IndexedDB state manager powered by Jotai. Persist and sync your application state with minimal boilerplate, full type safety, and Jotai's atom-based architecture.
