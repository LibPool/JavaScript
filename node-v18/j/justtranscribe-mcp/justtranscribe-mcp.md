# justtranscribe-mcp

> 标签: ai, claude, instagram, mcp, mcp-server, model-context-protocol, speech-to-text, tiktok, transcript, transcription, whisper, youtube

## 简介

MCP server for JustTranscribe — transcribe public videos and audio into timestamped text from Claude, ChatGPT, Cursor or any MCP client.
