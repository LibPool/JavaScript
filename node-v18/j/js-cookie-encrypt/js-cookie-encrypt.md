# js-cookie-encrypt

> 标签: aes, aes-gcm, browser, client-side, cookie, cookie-encrypt, cookie-manager, cookie-storage, cookies, encrypt, encrypted-cookie, encryption, js-cookie, js-cookie-encrypt, key-rotation, nextjs, nuxt, privacy, secure-cookie, ssr, subtle-crypto, typescript, webcrypto, zero-dependency

## 简介

The only actively maintained client-side encrypted cookie library. AES-GCM 256-bit encryption via native SubtleCrypto, zero dependencies, TypeScript generics, key rotation, deep path API, and SSR support (Next.js/Nuxt/Remix).
