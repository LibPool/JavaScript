# js-xlsx-extended

> 标签: csv, dbf, dif, excel, ods, office, spreadsheet, sylk, xls, xlsb, xlsm, xlsx

## 简介

fork了js-xlsx的功能，支持在用模板表格来生成自定义表格的时候可以保留样式
