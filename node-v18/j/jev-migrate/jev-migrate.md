# jev-migrate

> 标签: ai-tools, anthropic, classification, claude, cli, code-scanner, cohere, cost-reduction, gemini, gpt-4, groq, latency, llm, llm-cost-optimization, llmops, migration, mistral, ollama, openai, prompt-engineering, static-analysis, structured-output

## 简介

Scan your TS/JS/Python codebase for LLM calls that are secretly routing, classification, scoring, or boolean decisions - and see what converting them to TypeSafe Jev would save (benchmarked: up to 3000x faster, ~100% cheaper).
