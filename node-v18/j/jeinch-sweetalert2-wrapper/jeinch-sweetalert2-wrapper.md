# jeinch-sweetalert2-wrapper

> 标签: jeinch, sweetalert, sweetalert2

## 简介

Jeinch Sweetalert Wrapper, is a lightweight wrapper for SweetAlert2, providing five modular functions swalSuccess, swalWarning, swalError, swalInfo, swalConfirm
