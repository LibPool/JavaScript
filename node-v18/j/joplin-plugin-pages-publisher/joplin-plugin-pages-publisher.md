# joplin-plugin-pages-publisher

> 标签: github pages, joplin-plugin, site generator

## 简介

This plugin helps you generate a static website from your picked Joplin notes, and publish it as [Github Pages](https://pages.github.com/) which are accessible on Web, **with a few mouse clicks, even if you know nothing about website building & publishing
