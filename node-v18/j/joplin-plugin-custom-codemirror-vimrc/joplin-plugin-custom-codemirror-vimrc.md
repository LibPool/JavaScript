# joplin-plugin-custom-codemirror-vimrc

> 标签: joplin-plugin

## 简介

Pressing `ctrl+Shift+P` and typing `vimrc` allows editing a very-limited `.vimrc`-like configuration file for CodeMirror's ViM mode.
