# jbrowse-plugin-tview

> 标签: jbrowse, jbrowse2

## 简介

Loads BAM/CRAM read pileups into [react-msaview](https://github.com/GMOD/react-msaview) for a `samtools tview` style interface inside JBrowse 2.
