# jpyc-tipjar-widget

> 标签: jpyc, metamask, polygon, react, rescript, tipjar, web3

## 简介

Embeddable JPYC tip jar widget (Polygon, MetaMask) for React — built with ReScript. Supports rich and simple layout variants.
