# jodit-plugin-code

> 标签: code, code-block, editor, highlight.js, jodit, jodit-plugin, syntax-highlighting, wysiwyg

## 简介

Jodit editor plugin that inserts code blocks with syntax highlighting: language choice, live preview, line numbers, inline styles with CSS variables, and a copy button runtime for the site
