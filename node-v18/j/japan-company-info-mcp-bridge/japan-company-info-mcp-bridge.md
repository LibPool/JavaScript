# japan-company-info-mcp-bridge

> 标签: corporate-data, due-diligence, edinet, financial-data, gbizinfo, ifrs, japan, kyb, mcp, model-context-protocol, national-tax-agency, us-gaap

## 简介

MCP stdio server for verified Japanese corporate data (EDINET XBRL financials, National Tax Agency corporate numbers, gBizINFO) — Free edition, 192 blue-chip listed companies. Bridges the bundled mcporb-runtime.
