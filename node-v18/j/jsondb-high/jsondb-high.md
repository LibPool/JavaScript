# jsondb-high

> 标签: acid, database, durable, encryption, fast, group-commit, in-memory, json, multi-process, n-api, nosql, performance, rust, safety, storage, typescript, wal

## 简介

Blazing fast, Rust-powered JSON database for Node.js with native query engine. Features Smart Memory Management, Striped Write Locks, Group Commit WAL, and O(1) indexing. ~2.5M/s reads, ~545k/s writes.
