# jay-email-mcp

> 标签: JavaScript

## 简介

Email MCP 是一个基于 Node.js 的邮件服务模块，提供 IMAP、SMTP 协议的邮件查询和发送功能，支持通过 JSON-RPC 接口进行调用。
