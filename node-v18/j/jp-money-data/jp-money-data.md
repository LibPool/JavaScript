# jp-money-data

> 标签: dataset, japan, japanese, json, open-data, social-insurance, tax

## 简介

日本の生活マネー制度データ（自賠責・軽自動車税・標準報酬月額・雇用保険など）を出典・改定履歴つきの JSON + TypeScript 型で提供する OSS。Japanese money/social-insurance/tax parameters as machine-readable data with sources and revision history.
