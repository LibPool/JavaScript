# @needle-tools/usd

> 标签: needle, openusd, threejs, usd, webgl

## 简介

OpenUSD WebAssembly runtime and three.js Hydra render delegate — render real, composed USD stages (`.usd`, `.usda`, `.usdc`, `.usdz`) with MaterialX directly in the browser. The same technology powers the [Needle USD Viewer](https://usd-viewer.needle.tool
