# @elixcee/xlsx

> 标签: JavaScript

## 简介

Drop-in-compatible reimplementation of xlsx (SheetJS) with bounded XLSX/XLSM read-write, formula calculation, and opaque VBA-project preservation. See README.md for exact scope.
