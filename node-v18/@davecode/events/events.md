# @davecode/events

> 标签: events

## 简介

Another stupid event emitter library. This one has built-in types as well as a little bit of dom-compatibility by supporting short `.on` and `.off` methods, but also `.addEventListener` and `.removeEventListener` methods. Add functions return a "Cleanup"
