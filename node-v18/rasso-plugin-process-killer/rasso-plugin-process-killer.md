# rasso-plugin-process-killer

> 标签: JavaScript

## 简介

本地高危僵尸进程查杀与端口占用秒杀器：按端口号（如 :3000）或进程名实时模糊过滤、展示内存占用与监听端口、一键强制终止卡死进程并释放端口
