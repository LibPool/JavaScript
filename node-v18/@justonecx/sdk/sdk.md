# @justonecx/sdk

> 标签: announcements, changelog, customer-experience, feedback-board, in-app-messaging, justonecx, live-chat, nps, onboarding, product-tours, roadmap, surveys

## 简介

Embeddable customer-experience SDK for JustOneCX: product tours, announcements, surveys, live chat, and an embeddable public roadmap, feedback board and changelog. Framework-agnostic — works with React, Vue, Angular, Svelte or plain HTML.
