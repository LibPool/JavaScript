# @ortho-earth/japan

> 标签: 3d, geospatial, gis, globe, gsi, japan, map, plateau, serverless, vector-tiles, webgl, webgpu

## 简介

Serverless, dependency-free 3D globe of Japan for any web page — GSI vector tiles and MLIT PLATEAU buildings drawn on a true sphere with WebGPU/WebGL2. No API keys, no billing, no servers.
