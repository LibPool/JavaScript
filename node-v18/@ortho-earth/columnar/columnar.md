# @ortho-earth/columnar

> 标签: columnar, geoparquet, geopbf, globe, ortho-earth, parquet, webgl

## 简介

Column-chunk layer for @ortho-earth/globe: draws GeoPBF and GeoParquet without the Gint topology pass — spatial chunks (row groups) go worker → GPU as flat arrays, the first frame waits only for read + pack. Pluggable readers (GeoParquet with Range reads,
