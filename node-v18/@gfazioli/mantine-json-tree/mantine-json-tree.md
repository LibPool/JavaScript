# @gfazioli/mantine-json-tree

> 标签: collapsible-tree, component, developer-tools, editable, extension, json, json-editor, json-tree, json-view, json-viewer, mantine, mantine-ui, mantine-v9, react, react-component, syntax-highlighting, treeview, typescript

## 简介

A Mantine extension component that renders interactive JSON trees with syntax highlighting, collapsible nodes, in-place editing of values and structure, copy-to-clipboard, and configurable expansion depth.
