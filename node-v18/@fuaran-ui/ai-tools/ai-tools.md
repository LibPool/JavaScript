# @fuaran-ui/ai-tools

> 标签: ai, devtools, fuaran, introspection, ui

## 简介

Runtime tree-introspection surface for the Fuaran UI typed Node tree — getNodeState / findNodes / inspectTree over the typed shape, plus a React context provider + useFuaranIntrospection hook. The TypeScript port of the read-only introspection subset of F
