# @fuaran-ui/telemetry

> 标签: audit, fuaran, telemetry, ui

## 简介

Telemetry record contract for Fuaran hosts — the structured records a sink receives (starting with the deny record) plus the fire-and-forget sink interface. The TypeScript mirror of the F# Fuaran.UI.Telemetry.Abstractions package.
