# @meituan-nocode/nocode-linter

> 标签: JavaScript

## 简介

`@meituan-nocode/nocode-linter` 是一个基于 ESLint 的命令行代码检查工具，支持 TypeScript 和 JavaScript 项目。它可自动扫描指定目录下的代码，输出 Markdown 格式的规范性报告，帮助开发者快速定位和修复常见的代码问题。
