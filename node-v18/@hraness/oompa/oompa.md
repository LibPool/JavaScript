> 标签: bun, chatgpt, claude, claude-code, cli, codex, multi-account

## 简介

Bun CLI and local daemon for isolated Codex and Claude Code profiles, durable sessions, and optional encrypted sync. Local CLI v0.8.4 is a release candidate; daemon and hosted command-writer rollout remains blocked on capacity.
