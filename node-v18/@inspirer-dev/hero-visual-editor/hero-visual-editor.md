# @inspirer-dev/hero-visual-editor

> 标签: canvas, custom-field, figma-like, hero, plugin, strapi, visual-editor, widget

## 简介

A mini-Figma visual editor plugin for Strapi v5 that provides a canvas-based interface for creating Hero widgets with layers, overlays, and elements
