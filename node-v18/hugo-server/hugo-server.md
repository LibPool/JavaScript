# hugo-server

> 标签: api, cli, crud, documentation, express, mongoose, openapi, scaffold

## 简介

Express modules that document themselves: drop a folder to mount an API, one-line CRUD, generated docs and OpenAPI, endpoint types for hugo-api, and a test runner that finds its own tests
