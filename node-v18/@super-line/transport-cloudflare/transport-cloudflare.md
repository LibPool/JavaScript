# @super-line/transport-cloudflare

> 标签: cloudflare, durable-objects, hibernation, realtime, super-line, transport, websocket

## 简介

Cloudflare Durable Object transport for super-line: one Durable Object is one node, with hibernatable WebSockets that resume transparently on wake.
