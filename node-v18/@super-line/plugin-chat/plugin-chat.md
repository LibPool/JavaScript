# @super-line/plugin-chat

> 标签: channels, chat, membership, messages, plugin, super-line

## 简介

Chat backbone for super-line — channels, membership control, and messages backed by typed collections, with hookable server-authoritative requests. A paired plugin (contract · server). Requires @super-line/plugin-auth.
