# @lindorm/enigma

> 标签: JavaScript

## 简介

Argon2id password hashing for Node.js, plus a layered `Enigma` helper that combines HMAC signing, Argon2 hashing, and AES encryption into a single `hash` / `verify` / `assert` interface.
