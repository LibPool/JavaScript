# dsh-cron-toolkit

> 标签: cron, dsh, expression, plugin, schedule

## 简介

Cron toolkit plugin for DeepSeek Harness: explain cron expressions in Chinese, compute next run times, and validate expressions. Supports 5/6-field, macros and timezone offsets. Zero runtime dependencies.
