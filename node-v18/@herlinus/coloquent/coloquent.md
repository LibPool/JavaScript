# @herlinus/coloquent

> 标签: api, api client, coloquent, eloquent, json, json-api, json-api client, json-api-client, model, mvc, orm

## 简介

Library for retrieving model objects from a JSON-API, with a fluent syntax inspired by Laravel Eloquent.
