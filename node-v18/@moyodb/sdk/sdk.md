# @moyodb/sdk

> 标签: browser, database, key-value, local-first, moyodb, opfs, rust, storage-engine, transactions, typescript, wal, wasm, web-worker, webassembly

## 简介

Experimental Rust/WASM transactional key-value storage engine SDK for browser apps, backed by OPFS.
