# @ipare/koa

> 标签: ipare, koa, middleware

## 简介

让 Koa 成为 Ipare 的中间件，或 Ipare 成为 Koa 的中间件，并打通二者中间件管道

## 官网

- 官网：https://ipare.org
- 源码仓库：git+https://github.com/ipare/ipare.git
- npm 页面：https://www.npmjs.com/package/@ipare/koa
