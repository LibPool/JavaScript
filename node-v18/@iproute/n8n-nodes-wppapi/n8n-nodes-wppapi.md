# @iproute/n8n-nodes-wppapi

> 标签: automacao, chatbot, n8n-community-node-package, whatsapp, whatsapp-api, wppapi

## 简介

n8n community node para a WPPAPI — envie WhatsApp (texto, imagem, arquivo) e valide números em fluxos n8n. API gerenciada, trial grátis em wpp-api.com
