# rebornstudio-gitview

> 标签: claude, claude-code, gitdiagram, github, gitingest, korean, skill

## 简介

처음 보는 GitHub 저장소를 구조 그림(GitDiagram)과 AI 용 텍스트(Gitingest)로 바꾸는 법을 공식 방법 그대로 한국어 안내 스킬로 넣어 줍니다. 두 도구의 본체는 각 제작자의 것이며 싣거나 대신 설치하지 않습니다.
