# @workstudio-inc/sdk

> 标签: automation, connectors, integrations, sdk, workflow, workstudio

## 简介

Official JavaScript/TypeScript SDK for Workstudio. Headless and framework-agnostic. Covers the embeddable integration marketplace today; the surface will grow to the rest of the API.
