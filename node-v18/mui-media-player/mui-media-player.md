# mui-media-player

> 标签: audio, audio-player, material-ui, media, media-bar, media-center, mui, player, playlist, react, typescript, video, video-player

## 简介

A production-grade, highly customizable media player library for React and MUI with VideoPlayer, AudioPlayer, MediaPlayer, MediaBar, MediaCenter, and comprehensive playlist support.
