# @effuse/query

> 标签: caching, data-fetching, effect-ts, effuse, effuse-query, fine-grained, invalidate-queries, query-client, reactive, refetch, server-state, signals, structured-concurrency, type-safe, typescript, useInfiniteQuery, useMutation, useQuery

## 简介

Effuse Query handles loading, caching, and synchronizing server state. It provides reactive hooks for data fetching with built-in reliability.
