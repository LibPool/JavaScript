# @react-barcode-scanner/components

> 标签: JavaScript

## 简介

A component (and perhaps later multiple components) which use the [@react-barcode-scanner/hooks](https://github.com/react-barcode-scanner/hooks) hooks to drive a webcam  barcode scanner component.
