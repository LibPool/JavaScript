# @kody-ade/cms

> 标签: JavaScript

## 简介

Kody CMS layer — collection config, storage adapters (backend + MongoDB), service, MCP surface, API route handlers, chat tools. Depends only on @kody-ade/base; consumed as TS source by both hosts.
