# @lvdx/markdown-diff

> 标签: JavaScript

## 简介

基于 Vue 3 + mdast 的 Markdown 双栏差异对比组件，支持块级 LCS 对齐、行内/字符级 diff、表格列映射，以及接受/拒绝单个变更块。
