# @growgroup/visual-editor

> 标签: figma, html-editor, page-builder, react, slide-editor, tailwindcss, visual-editor, wysiwyg

## 简介

HTMLをブラウザ上で直接編集するビジュアルエディタ。スライド(固定サイズ)とWebページ(可変高さ)の両方に使え、保存先はアダプタで差し替えられます。
