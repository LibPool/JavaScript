# @net-advantage/jo-ui-date-picker

> 标签: JavaScript

## 简介

Optional, clearable date field. A typed `yyyy-mm-dd` value stays in sync with a calendar popover. The value is an ISO date string, or `null` when the field is cleared. An empty string is accepted and treated as cleared.
