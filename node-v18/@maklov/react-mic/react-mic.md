> 标签: MediaRecorder, audio recording, getUserMedia, html5 canvas, language, microphone, react, react-component, record audio, speech recognition, voice activation, voice recognition, volume meter, web audio api

## 简介

Record audio from your microphone and display as a sound oscillation. This is fixed version of react-mic created by @hackingbeauty. It supports newest version of react
