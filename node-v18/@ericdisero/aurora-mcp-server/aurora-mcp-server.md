# @ericdisero/aurora-mcp-server

> 标签: ai-music, aurora, claude, claude-desktop, cursor, mcp, mcp-server, model-context-protocol, music-generation, mvsep, stem-separation, suno

## 简介

MCP server for Aurora, the AI audio workbench. Your AI agent (Claude, Cursor, or any MCP client) drives music generation, covers, sample manufacturing, 7-stem separation, and DAW-ready stem organization. Files land on disk.
