# @brand_zd/vue-treeselect

> 标签: component, control, dropdown, form, input, multiselect, select, tree, treeselect, treeview, ui, vue

## 简介

基于@riophae/vue-treeselect的vue treeselect组件开发，支持设置默认打开的选项，支持打开面板自动滚动到指定选项。
