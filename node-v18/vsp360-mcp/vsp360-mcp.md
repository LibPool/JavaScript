# vsp360-mcp

> 标签: hitachi, mcp, mcp-server, model-context-protocol, storage, vsp360

## 简介

Community MCP server for Hitachi VSP 360: the VSP 360 1.4 REST API for Claude and other MCP clients. Not an official Hitachi Vantara product.
