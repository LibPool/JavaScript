# @hjdd14/dsh-toolong-warning

> 标签: compaction, context-window, deepseek-harness, dsh, dsh-plugin, plugin, token-usage, web-ui

## 简介

DSH plugin: counts completed compactions per session and raises a floating reminder — with bilingual UI — only after repeated compactions plus heavy extra token spend.
