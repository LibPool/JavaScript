# @villianwen/villianjs

> 标签: JavaScript

## 简介

Villianjs 是使用 Naive UI 和 Typescript 封装的组件库。集成了表单组件，CURD 组件，登录组件等。可以快速的进行后台开发系统的开发，减少了 CURD 的表格和表单的代码。
