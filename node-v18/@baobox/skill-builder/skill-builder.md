# @baobox/skill-builder

> 标签: baobox, custom-element, micro-frontend, preact, skill-studio, web-component

## 简介

Framework-agnostic <baobox-skill-builder> Web Component for the BaoBox Skill Studio. Reads from a configurable api-base (the tenant BFF) via @baobox/skill-builder-contract.
