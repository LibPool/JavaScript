# @mulmoclaude/shapescript-plugin

> 标签: JavaScript

## 简介

presentShapeScript — interactive 3D visualizations authored in the ShapeScript language (parser + Three.js renderer). Core (tool definition + execute) on `.`, Vue View/Preview on `./vue`.
