# @mulmoclaude/collection-watchers

> 标签: JavaScript

## 简介

Collection-completion bell subsystem (fs.watch plumbing + convergent reconciler) shared by MulmoClaude and MulmoTerminal. Depends on the @mulmoclaude/notifier singleton + @mulmoclaude/collection-plugin; the host injects its notification taxonomy + in-app
