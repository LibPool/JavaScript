# @fiesta-js/ui

> 标签: components, library, typescript, ui

## 简介

A lightweight CLI and UI toolkit delivering accessible, themeable, zero-JavaScript HTML/CSS components, scaffolding, and build tooling for fast, maintainable front-end interfaces.
