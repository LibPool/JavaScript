# @hexmillionaire/agent-lanes

> 标签: agentic-coding, ai-agents, claude-code, cli, codex, coding-agent, git, github-action, guardrails, handoff, pull-request, scope, task-scope

## 简介

Offline CLI and GitHub Action that audit an AI coding agent's Git changes against a declared file scope, then print a handoff for the next agent.
