# @fluxpointstudios/orynq-sdk-anchors-midnight

> 标签: anchor, compact, midnight, orynq, zero-knowledge

## 简介

Orynq anchors on Midnight: the immutable orynq-anchor-registry contract, its exact deploy state, the registry generations it is pinned to, and a verifier that checks an anchor from its own bytes to a GRANDPA-final block
