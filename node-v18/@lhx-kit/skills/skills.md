# @lhx-kit/skills

> 标签: ai-agent, ai-coding, claude-code, codebuddy, cursor-rules, knowledge-base, lhx-kit, prompt-engineering, skills

## 简介

Agent-agnostic skill pack for lhx-kit projects. Ships curated Markdown knowledge modules (add page / configure CDN / mobile adaptation / offline packaging / renderer schema / troubleshooting) that can be installed into any AI coding assistant via adapters
