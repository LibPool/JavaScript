# @rxova/react-file-input

> 标签: a11y, accessible, drag-and-drop, drop-zone, dropzone, file, file-field, file-input, file-picker, file-upload, headless, image-preview, multipart, react, upload, zero-dependency

## 简介

A file picker and drop zone that validates, deduplicates and revokes its own preview URLs — and never uploads anything. Headless, zero-dependency.
