# submitly

> 标签: crud, form-submission, forms, headless, nextjs, react, react-hook-form, server-actions, standard-schema, valibot, validation, zod

## 简介

Headless form submission for React and Next.js: Standard Schema validation, typed actions, server errors mapped to fields, pending/dialog locks and post-mutation refresh. Works with any UI.
