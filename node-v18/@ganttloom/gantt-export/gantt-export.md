# @ganttloom/gantt-export

> 标签: excel, export, gantt, gantt-excel, gantt-export, gantt-pdf, pdf, pdf-export, powerpoint, pptx, pptx-export, xlsx

## 简介

Export a @ganttloom/gantt-core chart to native PDF, PPTX, and XLSX files, generated from scratch with zero external PDF/OOXML libraries.
