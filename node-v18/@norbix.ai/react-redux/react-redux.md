# @norbix.ai/react-redux

> 标签: baas, hooks, norbix, react, redux, redux-toolkit, rtk-query, sdk

## 简介

Official Norbix bindings for React + Redux Toolkit. RTK Query helpers (cache, dedup, refetch, invalidation) over the typed Norbix SDK.
