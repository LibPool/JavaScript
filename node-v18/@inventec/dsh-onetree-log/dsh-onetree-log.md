# @inventec/dsh-onetree-log

> 标签: ami, bmc, deepseek-harness, dreport, dsh, dsh-plugin, ffdc, log-analysis, megarac, onetree, openbmc, settings-section

## 简介

AMI MegaRAC OneTree 一键日志（OpenBMC dreport dump）上传与分析框架：设置面板「OneTree 日志」上传压缩包或登记服务器本地路径，安全解包、自动探测 dump 根、文件清单分类，为第二阶段逐域解析提供内核。
