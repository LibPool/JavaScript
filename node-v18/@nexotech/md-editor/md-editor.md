# @nexotech/md-editor

> 标签: JavaScript

## 简介

A compact, Markdown-first React editor for blog posts, plus a lightweight chat composer. The package keeps application services such as uploads and AI behind small adapter props, so it can be reused without coupling consumers to a vendor.
