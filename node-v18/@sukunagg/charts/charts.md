# @sukunagg/charts

> 标签: a11y, accessible, area-chart, bar-chart, charts, data-visualization, line-chart, react, react-server-components, rsc, ssr, sukuna-ui, tailwind-v4

## 简介

Server-rendered, accessible React charts for sukuna-ui — BarChart, LineChart, AreaChart, DataBar — sized by CSS (no client measuring), with hover and keyboard tooltips from a small client island.
