# @trqsh-uz/trqsh

> 标签: http3, localhost, ngrok-alternative, quic, reverse-proxy, trqsh, tunnel, webhook

## 简介

Expose localhost to the internet — fast QUIC tunnels with a desktop app. This package installs the trqsh CLI binary for your platform.
