# @synet/did

> 标签: authentication, cryptography, decentralized-identifier, decentralized-identity, did, identity, production, security, self-sovereign-identity, ssi, verification, web3

## 简介

Secure, minimal, standards-compliant DID library for production environments. Supports did:key and did:web methods with strict validation and cryptographic security.
