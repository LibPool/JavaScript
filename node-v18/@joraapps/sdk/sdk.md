# @joraapps/sdk

> 标签: bridge, joraapps, mini-app, sdk, webview

## 简介

Client-side SDK for mini-apps running inside the Jora Apps platform. Provides safe UI dialogs, user-data/connection requests, navigation, and haptics — all mediated through the Jora Apps host via postMessage.
