# n8n-nodes-privatus-analytics

> 标签: analytics, cookieless, n8n-community-node-package, privacy, privatus analytics, web analytics

## 简介

n8n community nodes for Privatus Analytics, the cookieless web analytics service: a regular node for stats, goals, uptime, experiments and testimonials, and a trigger node for 25 signed webhook events.
