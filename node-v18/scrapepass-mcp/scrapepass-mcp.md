# scrapepass-mcp

> 标签: ai-agent, chrome-extension, mcp, model-context-protocol, scrapepass, web-scraper

## 简介

MCP server that connects AI apps on your computer (Claude Desktop, Claude Code, Cursor …) to the ScrapePass browser extension: extract lists and pages, magic fields, bulk downloads, screenshots, browser action flows, recipes, templates and saved data.
