# astrarch

> 标签: astrarch, claude-code, codex, coding-agents, doctor, orchestrator

## 简介

Astrarch: an orchestrator Agent that runs and governs a fleet of coding agents on your own subscriptions. This version provides `astrarch doctor`, a machine readiness check.
