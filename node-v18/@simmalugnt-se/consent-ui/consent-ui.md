# @simmalugnt-se/consent-ui

> 标签: JavaScript

## 简介

`@simmalugnt-se/consent-ui` ger webbplatser samma gränssnitt och grundinställningar för c15t i offline-läge. Paketet innehåller banner, inställningsdialog, svenska och engelska standardtexter samt gemensam CSS.
