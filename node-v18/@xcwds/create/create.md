# @xcwds/create

> 标签: create, offline-first, pwa, starter, xcwds

## 简介

npm create @xcwds: a new installable, offline-first PWA on @xcwds in one command, and `xcwds add <plugin>` to add plugins later.

## 官网

- 源码仓库：git+https://github.com/xcwds/xcwds.git
- npm 页面：https://www.npmjs.com/package/@xcwds/create
