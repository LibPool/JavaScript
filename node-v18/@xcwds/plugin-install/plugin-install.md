# @xcwds/plugin-install

> 标签: add-to-home-screen, install, offline-first, pwa, xcwds, xcwds-plugin

## 简介

Install support for @xcwds apps: an Install button where the browser offers one, Add to Home Screen steps on iPhone and iPad, hidden once installed.

## 官网

- 源码仓库：git+https://github.com/xcwds/xcwds.git
- npm 页面：https://www.npmjs.com/package/@xcwds/plugin-install
