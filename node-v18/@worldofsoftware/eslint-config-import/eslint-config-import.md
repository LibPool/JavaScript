# @worldofsoftware/eslint-config-import

> 标签: JavaScript

## 简介

This project contains an ESLint configuration file, preconfigured to run on JavaScript files only. It provides rule configurations found on [eslint-plugin-import](https://www.npmjs.com/package/eslint-plugin-import). This project is managed by WorldOfSoftw
