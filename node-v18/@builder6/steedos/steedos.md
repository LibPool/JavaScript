# @builder6/steedos

> 标签: JavaScript

## 简介

Builder6 Steedos 模块为 Builder6 平台提供直接的 MongoDB 数据库访问 API，允许管理员用户通过 RESTful 端点对自定义对象及其记录执行完整的 CRUD 操作。
