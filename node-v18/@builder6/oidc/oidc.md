# @builder6/oidc

> 标签: JavaScript

## 简介

Builder6 OIDC 客户端模块为 Builder6 平台提供 OpenID Connect (OIDC) 身份认证集成功能，支持通过外部身份提供者（IdP）进行单点登录（SSO）和用户认证。
