# @dbp-toolkit/tooltip

> 标签: JavaScript

## 简介

The tooltip component provides an icon as an anker for a tooltip. There is a generic tooltip `<dbp-tooltip>` which supports any icon the app has bundled. Another info tooltip `<dbp-info-tooltip>` shows an embedded info icon (small letter i inside a circle
