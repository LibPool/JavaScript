# @aitne-sh/aitne

> 标签: agent, ai, claude, claude-code, cli, codex, daemon, gemini, local-first, obsidian, personal-assistant

## 简介

Aitne — a local-first, proactive personal AI agent. A long-running TypeScript daemon is the nervous system; Claude Code (or Codex / Gemini CLI) is the brain. All persistent memory lives in local Markdown files.
