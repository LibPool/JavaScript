# @lblod/ember-rdfa-editor-scoped-bestuursorgaan-plugin

> 标签: ember-addon

## 简介

Ember RDFa editor Plugin to insert bestuursorgaan, bestuurseenheden linked to the profile of the user within the context of a zitting.
