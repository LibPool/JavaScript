# @hx2ryu/crashwatch-provider-firebase

> 标签: bigquery, crashlytics, crashwatch, firebase

## 简介

Firebase Crashlytics provider for crashwatch. Reads the Crashlytics BigQuery export — the only officially supported machine-readable source.
