# @mark1russell7/coeval

> 标签: coinductive, declarative, dsl, interpreter, json, language-workbench, typescript

## 简介

coeval: the kernel of declarative languages. Documents in envelopes, a ladder that finds the evaluator, kind contracts, compiled plans, a static kit, a formula kit and a run side with capabilities.
