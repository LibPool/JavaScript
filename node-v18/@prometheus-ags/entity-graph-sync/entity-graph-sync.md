# @prometheus-ags/entity-graph-sync

> 标签: collaboration, crdt, entity-graph, loro, peer-sync, sync, webrtc, websocket, yjs

## 简介

Pluggable peer-sync providers for the entity graph — ships Yjs (WebSocket + WebRTC) and Loro CRDT providers that bridge the core entity graph with collaborative editing engines.
