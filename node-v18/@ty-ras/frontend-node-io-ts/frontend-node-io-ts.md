# @ty-ras/frontend-node-io-ts

> 标签: client, data, frontend, http, io-ts, node, runtime, validation

## 简介

Bundle of TyRAS libraries suitable to use in frontends/clients which use Node runtime to send HTTP requests, and `io-ts` as data validation library.
