# @arkin-dev/easy-chatbox-ui

> 标签: JavaScript

## 简介

一个基于 React 的轻量级 AI 聊天框架，支持 React 组件方式和 iframe 嵌入两种集成方式，便于快速接入各种已有 Web 系统，实现与后端大模型服务的实时通信。
