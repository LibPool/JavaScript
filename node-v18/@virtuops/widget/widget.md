# @virtuops/widget

> 标签: ai, chat, chatbot, live-chat, support, virtuops, web-component, widget

## 简介

Embeddable AI chat widget for VirtuOps. Framework-agnostic web component with branding, real-time operator handoff, and zero runtime dependencies for the host page.
