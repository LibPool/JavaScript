# @serafort/core

> 标签: auth, authentication, jwks, jwt, m2m, rbac, sdk, serafort, sso

## 简介

Isomorphic TypeScript core SDK for Serafort authentication, Machine Identity (M2M) resilient token caching, and local B2B JWKS token validation.
