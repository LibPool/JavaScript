# @schedra/mcp

> 标签: ai-agent, claude, mcp, model-context-protocol, schedra, scheduling, social-media

## 简介

Model Context Protocol server for Schedra — schedule social posts, manage brands and connected accounts, and generate images and video from Claude, Codex, Cursor or any MCP client.
