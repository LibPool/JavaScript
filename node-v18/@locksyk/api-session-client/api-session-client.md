# @locksyk/api-session-client

> 标签: api-session-bundle, authentication, bearer-token, fetch, session

## 简介

Browser client contract for locksyk/api-session-bundle: bearer session tokens captured from X-Session-Token, presented on every request, and discarded when the server says invalid_token. No cookies anywhere.
