# @marceloazvedo1/brl-daily-quotation

> 标签: BRL, Branco, Brasil, Brazillian, Currency, Daily, Quotation, Real, SOAP, do

## 简介

This package is responsible for listing the daily quotation of foreign currencies against the Brazillian Real (BRL), all based on SOAP services provided by Banco do Brasil for free, which you can see here: https://www3.bcb. gov.br/sgspub/JSP/sgsgeral/Fach
