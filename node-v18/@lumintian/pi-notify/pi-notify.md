# @lumintian/pi-notify

> 标签: desktop-notifications, notifications, ntfy, osc777, pi-extension, pi-package, tmux, webhook

## 简介

One-way attention notifications for Pi via terminal OSC 777, optional tmux bell, and configurable JSON webhooks.
