# @grean/react-native-fade

> 标签: fade, react-native, reanimated

## 简介

Fade is a wrapper component that allows you apply a fade[in|out] effect on its render prop child<br/> It's a full typescript component using reanimated2. You can render any component you want and any items of your choice.<br/> The work is still in progres
