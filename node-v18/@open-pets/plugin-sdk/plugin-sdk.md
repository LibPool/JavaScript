# @open-pets/plugin-sdk

> 标签: desktop-pet, openpets, plugin, sdk, types

## 简介

Type definitions and testing harness for building OpenPets desktop pet plugins (SDK v3). The OpenPets runtime injects the SDK implementation at load time; the ./testing entry point runs plugins without the app.
