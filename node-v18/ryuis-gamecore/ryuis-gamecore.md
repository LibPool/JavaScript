# ryuis-gamecore

> 标签: behavior-tree, deterministic, ecs, entity-component-system, fsm, gacha, game-engine, gamecore, headless, multiplayer-sync, roguelike, rpg, spatial-hash, state-machine, typescript, zero-dependency

## 简介

Headless universal game state & simulation core engine. Zero-dependency pure TypeScript. ECS, EventBus, deterministic PRNG, stat pipeline, pluggable combat, spatial hash, dialogue, FOV, behavior tree, gacha, hierarchy & delta-sync.
