# @raj-sadan/ai-senses

> 标签: agent, ai, infrastructure, mcp, mobile, perception, senses, whatsapp

## 简介

Infrastructure-perception layer for AI agents — polls WhatsApp/cron/mobile, diagnoses services, emits sense events. Mockable defaults so it runs without any external service.
