# @fungi.computer/chat

> 标签: JavaScript

## 简介

React + Jotai client for `@shiit/coding-agent`. Renders the agent timeline (messages, tool calls, file ops) and exposes a transport-agnostic store you can wire to any `AgentSessionServer`.
