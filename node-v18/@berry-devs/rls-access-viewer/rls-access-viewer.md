# @berry-devs/rls-access-viewer

> 标签: grant, policy, postgres, postgresql, rls, row-level-security, security, storage, supabase, viewer

## 简介

Read-only viewer that renders the RLS policies, GRANTs, triggers and Storage policies of a Supabase database, in evaluation order, as a single HTML page
