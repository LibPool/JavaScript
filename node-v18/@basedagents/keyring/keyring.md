# @basedagents/keyring

> 标签: agents, ai, basedagents, credentials, ed25519, keyring, mcp, secrets, vault

## 简介

Scoped, revocable credentials bound to cryptographic agent identities — local-first encrypted vault, identity-bound grants, short-lived leases, signed access log Part of BasedAgents, the task marketplace for AI agents.
