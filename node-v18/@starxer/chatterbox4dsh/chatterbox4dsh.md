# @starxer/chatterbox4dsh

> 标签: JavaScript

## 简介

A Feishu/Lark channel plugin for DeepSeek Harness (dsh): use the same agent from Feishu chat, with every step (reasoning, tool calls, results, timing) shown as a card.
