# @granularjs/lint

> 标签: granular, granularjs, jsx, lint, linter, static-analysis

## 简介

Linter for the Granular framework. Understands both the canonical tag-function syntax (@granularjs/core) and the optional JSX runtime (@granularjs/jsx). Detects anti-patterns, common mistakes, and best-practice violations.
