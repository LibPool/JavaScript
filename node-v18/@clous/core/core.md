# @clous/core

> 标签: baas, clous, codegen, compiler, openapi, orm, postgresql, rls, schema, sdk-generator, type-safe, typescript

## 简介

Type-safe, compiler-driven schema builder for BaaS platforms. Generates PostgreSQL DDL (with RLS), TypeScript types, and OpenAPI 3.0 specs from a single declarative schema.
