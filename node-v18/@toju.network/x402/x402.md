# @toju.network/x402

> 标签: agent, ai-agent, autonomous-payments, base, decentralized-storage, eip-3009, ipfs, storacha, usdc, x402

## 简介

Agent-friendly client for storing files on IPFS via toju, paying autonomously with USDC on Base using the x402 protocol.
