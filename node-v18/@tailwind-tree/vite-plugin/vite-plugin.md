# @tailwind-tree/vite-plugin

> 标签: css, design, plugin, responsive, style, tailwind, tailwind-merge, tailwindcss, utility-first, vite

## 简介

Vite plugin for tailwind-tree. Fully compatible with Tailwind v4 and supports dynamic twTree class generation with zero setup. See: https://www.npmjs.com/package/tailwind-tree
