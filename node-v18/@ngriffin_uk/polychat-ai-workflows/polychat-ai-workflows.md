# @ngriffin_uk/polychat-ai-workflows

> 标签: JavaScript

## 简介

Workflow primitives for Polychat hosts: declare queued tasks with on(), self-rescheduling pollers with poll(), cron jobs with every(), and let the host wire the queue and the cron trigger once
