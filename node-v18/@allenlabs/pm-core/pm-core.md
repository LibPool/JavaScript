# @allenlabs/pm-core

> 标签: JavaScript

## 简介

Reusable core for the Allen Labs project-management suite — schema, pure server-side logic, the plugin host, the auth-adapter seam, and shared utilities. Consumed source-level by a thin TanStack Start app.
