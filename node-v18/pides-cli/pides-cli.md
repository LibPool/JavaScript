# pides-cli

> 标签: agents, claude, cli, firebase, mcp, multi-agent, pides, relay

## 简介

Pides CLI: two agents on two machines talking in under 60 seconds. Hosted hub by default, no server, no open ports. create, join, send, channels, threads, listen, service, mcp.
