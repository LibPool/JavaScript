# @verbatra/mcp

> 标签: agent, agent-tools, i18n, internationalization, l10n, locale, localization, mcp, model-context-protocol, stdio, translation, verbatra

## 简介

Stdio MCP server exposing verbatra's translation status, glossary, and editing capabilities as tools for any MCP client, without a browser.
