# @ilmek/a2a

> 标签: a2a, agent, agent2agent, ilmek, llm, tools

## 简介

A2A for ilmek — call Agent2Agent agents from a graph, replay-safe, with human-in-the-loop pauses surfaced as input-required tasks, and drop them into a graph as data.
