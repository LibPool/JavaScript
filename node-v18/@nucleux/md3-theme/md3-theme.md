# @nucleux/md3-theme

> 标签: agentic, ai, components, material-design-3, md3, nucleux, react, tailwind, theme, ui

## 简介

Material Design 3 theme — remaps Nucleux --nx-* tokens to the MD3 tonal palette so any component renders in a Material UI 3 look — Nucleux agentic UI for React.
