# @athenaflow/plugin-e2e-test-builder

> 标签: JavaScript

## 简介

Full-pipeline Playwright E2E test generation — explores your live site via browser, detects existing test conventions, plans coverage gaps, produces reviewed test specs, writes production-grade test code with quality gates, and stabilizes flaky tests
