# @nex-ai/nex

> 标签: agent-memory, ai-agent, ai-memory, claude, context, copilot, cursor, integrations, knowledge-graph, mcp, mcp-server, model-context-protocol, nex, organizational-memory

## 简介

Nex CLI provides organizational context & memory to AI agents. Connect email, CRM, Slack, meetings, and 100+ tools into one knowledge graph. Delegates to the nex-cli binary.
