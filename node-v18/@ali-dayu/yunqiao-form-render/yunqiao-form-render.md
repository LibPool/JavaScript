# @ali-dayu/yunqiao-form-render

> 标签: JavaScript

## 简介

这是云巧表单组件的一个轻量化使用方式，组件提供了**多种场景化的表单能力**和**丰富的表单控件**，你可以像使用一个 Antd 组件那样简单快速地使用它搭建出表单。
