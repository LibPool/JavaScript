# @chainitservices/hosted-ui

> 标签: auth, authentication, face-liveness, hosted-auth, identity, kyc, oidc, onboarding, otp, sdk, white-label

## 简介

Framework-agnostic SDK for ChainIT Hosted Auth. Provides branded onboarding flows with OTP, face liveness, and ID verification for React, Vue, Angular, and vanilla JavaScript applications.
