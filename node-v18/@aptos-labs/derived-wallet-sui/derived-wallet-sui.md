# @aptos-labs/derived-wallet-sui

> 标签: JavaScript

## 简介

A light-weight add-on package to the [@aptos-labs/wallet-adapter-react](../wallet-adapter-react/) that enables the functionality to use a Sui wallet as a Native Aptos Wallet
