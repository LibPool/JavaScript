# @dingchenhui/dsh-doudizhu

> 标签: card-game, deepseek-harness, doudizhu, dsh, dsh-plugin, lan, landlord

## 简介

Three-player LAN Doudizhu (斗地主) for DeepSeek Harness: one authority host plus two followers, each playing from the plugin's floating window, with four levels of computer player filling any empty seat.
