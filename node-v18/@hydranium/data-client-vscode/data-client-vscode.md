# @hydranium/data-client-vscode

> 标签: hydranium, langium, language-server, lsp, vscode, vscode-extension, webview

## 简介

VS Code client primitives for the hydranium data-server protocol head; companion of @hydranium/data-server. The extension host relays the data-server's socket to a webview over a vscode-messenger hop, and the webview's data port reads it, so DataConnectio
