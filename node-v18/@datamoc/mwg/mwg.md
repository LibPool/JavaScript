# @datamoc/mwg

> 标签: 2d-game-engine, babylonjs, capacitor, dialogue-system, dungeon-crawler, game-engine, game-framework, html5-games, local-file, no-server, offline-first, pixijs, roguelike, rpg, tile-map, top-down, turn-based, typescript

## 简介

A local-file game framework: renderer-free game logic, drawn through PixiJS in 2D or Babylon.js in 3D, with mobile and desktop packaging.
