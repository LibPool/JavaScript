# @nx-devkit/skill

> 标签: agent-skills, agentskills, ai-agent, claude-skills, llm, nx, nx-plugin, skill

## 简介

Nx plugin for agent skills: any SKILL.md becomes a project with build, lint, validate, os-check, and size-check targets — no project.json required.
