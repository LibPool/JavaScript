# @nx-devkit/release

> 标签: automation, ci, npm-publish, nx, nx-plugin, oidc, provenance, release

## 简介

Zero-config Nx plugin for automated npm releases via CI — version bump, OIDC publish, git tag, and GitHub Release, fully idempotent.
