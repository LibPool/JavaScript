# @nx-devkit/oxlint

> 标签: lint, linter, monorepo, nx, nx-plugin, oxc, oxlint, typescript, zero-config

## 简介

Standalone Nx plugin: infers a cached lint target from .oxlintrc config files — no project.json required.
