# @nx-devkit/playwright

> 标签: browser-tests, e2e, monorepo, nx, nx-plugin, playwright, zero-config

## 简介

Nx plugin: playwright.config files infer a cached e2e target (plus e2e:ui and e2e:update-snapshots) — Playwright without project.json.
