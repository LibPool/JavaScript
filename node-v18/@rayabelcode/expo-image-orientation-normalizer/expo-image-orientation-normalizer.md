# @rayabelcode/expo-image-orientation-normalizer

> 标签: android, exif, exifinterface, expo, expo-modules, heic, image-picker, imageio, ios, jpeg, orientation, photokit, react-native

## 简介

Native ingress normalization for gallery-picked images on React Native / Expo. Decodes via PhotoKit and ImageIO on iOS, BitmapFactory + ExifInterface + Matrix on Android; writes display-oriented JPEG with EXIF Orientation=1.
