# @reventlessdev/reventless-domain-protocol

> 标签: JavaScript

## 简介

Shared NDJSON contract (StreamEvent) between the reventless-gwt CLI (--format=vscode) and the reventless-vscode extension — a single sury @schema both emit and decode.
