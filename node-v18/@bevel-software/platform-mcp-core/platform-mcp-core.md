# @bevel-software/platform-mcp-core

> 标签: JavaScript

## 简介

The transport-agnostic half of Bevel's MCP surface: UTCP manual registration, tool discovery, MCP listing/dispatch and the code-mode meta-tools. Shared by the hosted proxy and the local stdio server.
