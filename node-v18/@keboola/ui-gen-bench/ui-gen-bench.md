# @keboola/ui-gen-bench

> 标签: agent, benchmark, cli, keboola, scoring, validate

## 简介

Scoring model and reproducible benchmark for agent-generated Keboola UI — turns @keboola/validate-ui verdicts into a tunable 0-100 BenchScore and runs a fixed fixture target set to record a committed baseline
