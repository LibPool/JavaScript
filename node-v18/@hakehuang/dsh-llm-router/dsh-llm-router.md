# @hakehuang/dsh-llm-router

> 标签: cordis, cordis-plugin, deepseek-harness, dsh, dsh-plugin, lead-worker, llm, model-router, routing

## 简介

Cordis-native Lead/Worker model routing for DeepSeek Harness: a replaceable `ctx.llm` provider route plus an observable, interceptable routing service.
