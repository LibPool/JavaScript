# @holmrenser/nj

> 标签: bioinformatics, neighbor-joining, newick, phylogenetics, wasm

## 简介

Neighbor-Joining phylogenetic tree inference. Auto-detects DNA/protein, supports multiple substitution models and bootstrap.
