# dsh-first-prompt-bar

> 标签: clipboard, deepseek-harness, dsh-plugin, prompt, 首条提问

## 简介

Persistent bar above the conversation showing the session's first prompt, with copy, a panel of every prompt sent, and ten switchable looks (four light) · 会话首条提问常驻条：复制 + 全部提问面板 + 十套可切换外观（含四套亮色）
