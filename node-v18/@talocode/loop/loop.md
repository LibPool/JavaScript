# @talocode/loop

> 标签: agents, cli, mcp, memory, sdk, search, talocode, trace, verify

## 简介

The Talocode loop for agents: search a source, verify a claim against it, trace the run, and remember the receipt. One package for the CLI, MCP server, SDK, and local API.
