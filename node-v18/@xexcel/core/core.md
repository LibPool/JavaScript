# @xexcel/core

> 标签: csv, excel, formula, headless, spreadsheet, transaction, typescript, xlsx

## 简介

Headless spreadsheet engine: immutable workbook, transactions, plugins, formula evaluator, xlsx/CSV I/O. Zero DOM.
