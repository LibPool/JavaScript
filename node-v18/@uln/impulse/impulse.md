# @uln/impulse

> 标签: audio, audio-analysis, beat-detection, bpm, dsp, fft, music, onset-detection, real-time, spectral-analysis, visualization, wasm, web-audio, webassembly

## 简介

Real-time audio feature extraction for the browser using WebAssembly. Extract BPM, beats, frequency bands, and spectral features from audio streams.
