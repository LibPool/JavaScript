# @identizen/sdk

> 标签: identizen, login, mfa, oidc, passwordless, sdk

## 简介

Identizen SDK: browser login (paired browser, Web Bluetooth, QR, deep link) and server helpers (OIDC, Verification API, webhooks). Standard OIDC on the outside.
