# @identizen/protocol

> 标签: ed25519, identity, identizen, mfa, oidc, passwordless

## 简介

Identizen protocol: keys, canonical encoding (JCS), challenge/assertion signing and verification, rotating BLE identifiers. The single implementation every Identizen component imports.
