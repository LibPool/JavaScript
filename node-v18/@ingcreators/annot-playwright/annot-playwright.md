# @ingcreators/annot-playwright

> 标签: annotation, ci, fixture, headless, playwright, png, screenshot, svg, testing

## 简介

Playwright fixture for annotated screenshots — emit annotated PNGs from failing tests without leaving the test file. Pairs `test.extend({ annotator })` with the headless renderer from @ingcreators/annot-annotator.
