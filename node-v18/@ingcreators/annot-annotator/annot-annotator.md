# @ingcreators/annot-annotator

> 标签: annotation, ci, headless, node, playwright, png, resvg, screenshot, svg, testing

## 简介

Headless annotator — render annotated screenshots from Node without a browser. Built on @resvg/resvg-js. Pairs with @ingcreators/annot-playwright for fail-on-test annotated reports.
