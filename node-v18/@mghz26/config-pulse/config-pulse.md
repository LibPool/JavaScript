# @mghz26/config-pulse

> 标签: config, configuration, dynamic-config, feature-flags, hot-reload, mongodb, push-config, runtime-config

## 简介

TEMPORARY scoped copy of config-pulse 1.1.0-beta.0 for testing. Push-based runtime config client backed by a single MongoDB document. Pushes runtime/business config into running services without restarts.
