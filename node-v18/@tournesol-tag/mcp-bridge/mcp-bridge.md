# @tournesol-tag/mcp-bridge

> 标签: bridge, cli, mcp, model-context-protocol, tag

## 简介

TAG MCP bridge — runs your local MCP server and proxies stdio ↔ TAG relay WebSocket so hosted TAG / engine can call your tools (J1, ADR-033).
