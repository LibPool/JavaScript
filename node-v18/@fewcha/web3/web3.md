# @fewcha/web3

> 标签: Aptos, Aptos Wallet, Blockchain, Dapp, Dapps, Fewcha Wallet, Wallet, Web3

## 简介

The `@fewcha/web3` library aims to be an all-in-one toolkit to enable developers interact with Aptos Blockchain and its ecosystem.
