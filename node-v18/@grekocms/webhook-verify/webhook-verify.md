# @grekocms/webhook-verify

> 标签: grekocms, hmac, signature, verification, verify, webhook, webhooks

## 简介

Receiver-side verification helper for GrekoCMS webhooks (HMAC-SHA256 v1 base-string scheme, header-bound replay protection).

- npm 页面：https://www.npmjs.com/package/@grekocms/webhook-verify
