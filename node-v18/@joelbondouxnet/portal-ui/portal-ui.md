# @joelbondouxnet/portal-ui

> 标签: JavaScript

## 简介

The shared joelbondoux.net portal design system: theme (light/dark with a cross-subdomain cookie) and the animated line background. One standard version consumed by every tool (login, prospector, AppDeck, …).
