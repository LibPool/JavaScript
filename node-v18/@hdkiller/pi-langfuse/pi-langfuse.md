# @hdkiller/pi-langfuse

> 标签: extension, langfuse, monitoring, observability, pi-coding-agent, pi-package, tracing

## 简介

Production-grade Langfuse observability for Pi. Tracks prompts, turns, tools, and streaming assistant responses with native trace hierarchies, token usage, and cost monitoring.
