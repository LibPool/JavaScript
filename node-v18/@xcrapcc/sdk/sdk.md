# @xcrapcc/sdk

> 标签: api, llm, markdown, scraper, sdk, twitter, x, xcrap

## 简介

Official Node client for XCrap — X/Twitter posts, threads, profiles, timelines and media as JSON or LLM-ready markdown. No API key.
