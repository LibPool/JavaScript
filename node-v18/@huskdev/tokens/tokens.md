# @huskdev/tokens

> 标签: css, design-tokens, husk, oklch, tailwind

## 简介

Husk design tokens — the single source of truth for brand color (OKLCH), type, spacing, radius and motion, plus the Tailwind v4 @theme mapping. Pure CSS.
