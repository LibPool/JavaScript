# @dudousxd/nestjs-agent-rag

> 标签: agent, nestjs, rag

## 简介

Retrieval-Augmented Generation for nestjs-agent — chunking, ingestion, an embedding-backed Retriever, and in-memory, pgvector and Redis (RediSearch) vector stores with lexical/hybrid search, plus PageIndex-style tree navigation retrieval for long document
