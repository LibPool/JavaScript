# @dudousxd/nestjs-agent-channels

> 标签: agent, chatbot, nestjs, telegram, whatsapp

## 简介

nestjs-agent on text channels — WhatsApp (Evolution API, Whatsmiau, Cloud API) and Telegram webhooks: verified, deduplicated, answered durably and in order, with proposals, questions, media, files and hooks
