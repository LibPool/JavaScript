# @hlao/mcp-sdk-adapter

> 标签: JavaScript

## 简介

Reference adapter from the official @modelcontextprotocol/sdk Client to the @hlao/mcp-gateway McpClient port. Peer-dep on the SDK so downstream apps pin their own version.
