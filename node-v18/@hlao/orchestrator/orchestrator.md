# @hlao/orchestrator

> 标签: JavaScript

## 简介

HLAO orchestrator: reads a workspace convention (numbered stages, CONTEXT.md, review-gate markers) and runs stages in order. Requires verifyPassport (ADR-0021) and verifyActor (ADR-0020) deps.
