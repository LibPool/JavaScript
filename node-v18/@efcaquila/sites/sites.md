# @efcaquila/sites

> 标签: aquila, attribution, efc, leads

## 简介

Aquila's runtime for a bundled school website (Vite or any bundler): lead posting to the Aquila Edge, first-touch attribution, trial sessions, sign-up packages and hosted hand-off URLs.
