> 标签: agent-loop, autoresearch, goal, long-running, pi, pi-extension, pi-package, sisyphus

## 简介

Goal mode extension for pi: persistent long-running objectives, /goal-set drafting, Sisyphus prompt style, autoContinue, and an above-editor status overlay. Fork with merged PR fixes for runtime init error and checkpoint delegation.
