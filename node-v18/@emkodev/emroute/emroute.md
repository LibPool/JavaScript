# @emkodev/emroute

> 标签: bun, deno, file-based, framework, markdown, node, router, routing, spa, ssr, typescript

## 简介

File-based (but storage-agnostic) router with triple rendering (SPA, SSR HTML, SSR Markdown). Zero dependencies.
