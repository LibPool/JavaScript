# @rightkit/outdated

> 标签: JavaScript

## 简介

Per-repo dependency updater: check, apply, gate and land for cargo, pnpm, swiftpm and external-tool pins, plus a scheduled run (launchd, Task Scheduler).

- 源码仓库：git+https://github.com/Orthic-Labs/rightkit.git
- npm 页面：https://www.npmjs.com/package/@rightkit/outdated
