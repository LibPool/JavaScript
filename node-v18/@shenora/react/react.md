# @shenora/react

> 标签: android, desktop, dotnet, hybrid, ios, ipc, maui, react, shenora, webview2, winforms

## 简介

React client for Shenora hosts on Windows, Android and iOS: correlated invoke/send/subscribe over the desktop postMessage bridge or the MAUI HybridWebView transport, typed module services, host-backed stores, and hooks for request tracking and media playb
