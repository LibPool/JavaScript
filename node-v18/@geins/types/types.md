# @geins/types

> 标签: JavaScript

## 简介

Shared TypeScript type definitions for the Geins SDK. Contains all interfaces, enums, and type aliases used across `@geins/core`, `@geins/crm`, `@geins/cms`, and `@geins/oms`.
