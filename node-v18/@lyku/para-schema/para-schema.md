# @lyku/para-schema

> 标签: branded-types, json-schema, para, parabun, schema, validation

## 简介

Para schema type system + portable runtime — JSON Schema 2020-12 with 1:1 brand-type parity. `fromSchema` validates off ParaBun (browsers, Cloudflare Workers, Node), where ParaBun's own fallback is the identity function. Ships two type variants: extended
