# dsh-pet-plugin

> 标签: companion, desktop-pet, dsh, dsh-plugin, pet, tts

## 简介

DSH 桌宠插件：四只超写实立绘（表情 + 动作序列）、主动说话与神经音色、小输入框单聊（一次性模型调用，不进会话）。
