# @basaltkit/subscriptions-proxypay

> 标签: angola, basalt, emis, multicaixa, payments, proxypay, subscriptions, typescript

## 简介

ProxyPay payment gateway driver for @basaltkit/subscriptions — reference-based Multicaixa/EMIS payments for Angola (AOA), implementing the PaymentGateway contract.
