# @basaltkit/exports

> 标签: basalt, csv, export, reporting, saas, typescript

## 简介

Data exports for Basalt: render typed export definitions to CSV/TSV/JSON/NDJSON (native, zero-dep) through a pluggable formatter seam, designed to run async via @basaltkit/queue; reads CSV back with strict locale parsing and per-line errors.
