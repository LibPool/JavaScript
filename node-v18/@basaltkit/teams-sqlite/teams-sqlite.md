# @basaltkit/teams-sqlite

> 标签: basalt, sqlite, store, teams, typescript

## 简介

Durable, SQLite-backed implementations of the @basaltkit/teams stores (memberships, invitations) built on Node's built-in node:sqlite. Zero external dependencies.
