# @basaltkit/webhooks-sqlite

> 标签: basalt, sqlite, store, typescript, webhooks

## 简介

Durable, SQLite-backed implementation of the @basaltkit/webhooks WebhookStore (endpoint subscriptions), on Node's built-in node:sqlite. Zero external dependencies.
