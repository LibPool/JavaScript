# @basaltkit/mcp-core

> 标签: ai, basalt, json-rpc, mcp, model-context-protocol, stdio

## 简介

Zero-dependency Model Context Protocol core for Basalt: the JSON-RPC 2.0 + MCP wire types, a transport-neutral server/dispatcher over function-shaped tools/resources/prompts (with progress + cancellation plumbing), and a stdio transport. Shared by the run
