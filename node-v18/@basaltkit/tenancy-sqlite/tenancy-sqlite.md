# @basaltkit/tenancy-sqlite

> 标签: basalt, multi-tenant, sqlite, store, tenancy, typescript

## 简介

Durable, SQLite-backed implementation of the @basaltkit/tenancy TenantSource, on Node's built-in node:sqlite. Zero external dependencies.
