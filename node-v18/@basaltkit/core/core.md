# @basaltkit/core

> 标签: asynclocalstorage, backend, basalt, dependency-injection, plugins, typescript

## 简介

Foundation of the Basalt ecosystem: token-based DI container, plugin system, lifecycle, hooks and context via AsyncLocalStorage.
