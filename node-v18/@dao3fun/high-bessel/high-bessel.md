# @dao3fun/high-bessel

> 标签: JavaScript

## 简介

负责管理游戏中的模型高贝塞尔曲线动画，它使用贝塞尔曲线来平滑地移动相机实体，并支持不同的缓动函数来控制动画速度，同时也支持生成曲面
