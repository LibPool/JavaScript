# @agentxin-ai/plugin-openai-compatible

> 标签: JavaScript

## 简介

`@agentxin-ai/plugin-openai-compatible` bridges the [AgentXinAI](https://github.com/agentxin-ai/agentxin) agent platform with any model provider that exposes an OpenAI-compatible REST API. It centralises authentication, base URL management, and capability
