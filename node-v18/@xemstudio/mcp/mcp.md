# @xemstudio/mcp

> 标签: 3d, cad, dimensions, fasteners, geometry, hardware, mcp, model-context-protocol, raspberry-pi, step, stl, tri-clamp

## 简介

MCP server for Xem Studio: measured geometry of real objects (dimension sheets, free STEP/STL hardware, license-aware CAD index) for AI agents.
