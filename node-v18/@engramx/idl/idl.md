# @engramx/idl

> 标签: candid, engram, icp, idl, internet-computer

## 简介

The Candid interfaces of the EngramX canisters (engram, registry, market) — the .did files and the JS/TS IDL factories generated from them, published with every release so code that calls them pins the interface by version.
