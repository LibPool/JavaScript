# @frontmcp/sdk

> 标签: agentfront, decorators, dependency-injection, frontmcp, mcp, mcp-framework, mcp-server, model-context-protocol, sdk, typescript

## 简介

The TypeScript framework for MCP servers: typed tools with Zod, dependency injection, auth, testing, agents and jobs, and builds for Node, Vercel, AWS Lambda and Cloudflare Workers.
