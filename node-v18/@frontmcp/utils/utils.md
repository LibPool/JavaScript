# @frontmcp/utils

> 标签: crypto, frontmcp, mcp, pkce, redis, storage, typescript, uri-template, utils

## 简介

Shared helpers for FrontMCP: URI templates, naming, cross-platform crypto and PKCE, key-value storage, file system and environment detection
