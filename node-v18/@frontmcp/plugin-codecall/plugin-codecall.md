# @frontmcp/plugin-codecall

> 标签: agentfront, agentscript, codecall, frontmcp, mcp, meta-tools, model-context-protocol, plugin, sandbox, tool-search

## 简介

CodeCall plugin for FrontMCP: puts many tools behind search, describe, invoke and execute meta-tools, and runs scripts that call them in a sandbox

## 官网

- 官网：https://frontmcp.dev/reference/plugins/codecall
- 源码仓库：git+https://github.com/agentfront/frontmcp.git
