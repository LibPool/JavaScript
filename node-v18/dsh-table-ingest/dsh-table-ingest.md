# dsh-table-ingest

> 标签: cordis, csv, deepseek-harness, docx, dsh, dsh-plugin, ingest, table, xlsx

## 简介

把 docx/xlsx/csv 转成规则检查器能吃的表格 JSON，带候选表、表头识别、预览与置信度。
