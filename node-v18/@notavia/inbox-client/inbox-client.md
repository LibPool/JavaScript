# @notavia/inbox-client

> 标签: in-app, inbox, notavia, saasinfrastructure, signalr

## 简介

Headless TypeScript client for the Notavia in-app inbox. Owns SignalR connection, REST, token refresh, optimistic mark-read, and a typed event bus.
