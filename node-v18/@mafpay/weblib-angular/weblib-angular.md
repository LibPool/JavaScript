# @mafpay/weblib-angular

> 标签: JavaScript

## 简介

This package is built using Angular 11 and is not compatible with Angular 9 due to TypeScript version differences. Please use [@mafpay/weblog-angular9](https://www.npmjs.com/package/@mafpay/weblib-angular9) to use it with Angular 9.
