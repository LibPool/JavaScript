# @sentre/senswap

> 标签: amm, balancer, dex, senswap, sentre, solana

## 简介

SenSwap is a Balancer-like AMM on Solana. The AMM implementation is heavily relying on [Balancer's Whitepaper](https://balancer.fi/whitepaper.pdf).
