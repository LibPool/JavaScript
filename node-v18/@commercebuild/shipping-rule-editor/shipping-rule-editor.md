# @commercebuild/shipping-rule-editor

> 标签: commercebuild, drools, rule-editor, shipping, visual-editor

## 简介

Drool-rule visual editor for shipping rules (carrier, carrier service, global). Headless core + framework-neutral UI layer (bring your own UI primitives: MUI, shadcn, Mantine, plain HTML) + optional Monaco code editor.
