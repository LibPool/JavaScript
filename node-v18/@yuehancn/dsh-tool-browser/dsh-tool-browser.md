# @yuehancn/dsh-tool-browser

> 标签: browser, deepseek-harness, dsh-plugin, extract, mcp, playwright, readability, scraping, screenshot, wait-strategy, 网页抓取

## 简介

Browser tools for DeepSeek Harness: open a page, wait for it the way it actually needs, pull out the readable article, and take a screenshot. Uses Playwright when it is installed and falls back to a static fetch that says so, so an unrendered page is neve
