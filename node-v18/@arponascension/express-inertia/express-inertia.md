> 标签: ejs, express, express-inertia, express-middleware, hmr, inertia, inertiajs, middleware, node, nodejs, react, server-side-rendering, single-page-application, spa, ssr, svelte, typescript, vite, vite-plugin, vue

## 简介

Inertia.js adapter and middleware for Express.js — build SPAs with Vue 3, React, or Svelte using classic server-side routing, EJS templates, Vite, and server-side rendering (SSR).
