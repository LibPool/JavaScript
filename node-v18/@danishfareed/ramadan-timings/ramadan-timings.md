# @danishfareed/ramadan-timings

> 标签: astronomy, fajr, fasting, islamic, maghrib, prayer-times, ramadan, sunrise, sunset, zero-dependency

## 简介

Zero-dependency library that calculates all 5 daily prayer times (Fajr, Dhuhr, Asr, Maghrib, Isha) and Ramadan fasting times worldwide using built-in solar math.
