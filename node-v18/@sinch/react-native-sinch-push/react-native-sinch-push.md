# @sinch/react-native-sinch-push

> 标签: android, apns, fcm, ios, notifications, push, react-native, sinch, turbomodule

## 简介

React Native SDK for Sinch Push — identity registration and push receive handling, with native APNs (iOS) and Firebase Cloud Messaging (Android) device token capture. Supports both the old and new (TurboModule) architectures.
