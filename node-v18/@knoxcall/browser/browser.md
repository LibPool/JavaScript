# @knoxcall/browser

> 标签: ecies, encryption, knoxcall, tokenization, webcrypto

## 简介

KnoxCall in the browser, dependency-free: hosted fields that exchange a sensitive value for a vault token (the value never enters your page JavaScript), single-use-token reveal, and client-side kc: encryption. No API key in the page.
