# koishi-plugin-chatluna-image-desc-bridge

> 标签: cache, character, chatbot, chatluna, chatluna-plugin, debug, image, koishi, multimodal, plugin, transformer, vision, 主插件, 伪装插件, 图像描述, 多模态, 拦截器, 角色扮演, 识图, 调试模式

## 简介

Koishi 图像描述转发插件，把 koishi-plugin-chatluna-multimodal-service 生成的图像描述从 messageTransformer 结果转发进 ChatLuna 伪装插件的消息正文，关闭 toolCalling 且模型非多模态时也能识图
