# @findusproptech/node-argocd

> 标签: JavaScript

## 简介

This is a simple node.js client for the ArgoCD API. It it is a wrapper around the ArgoCD REST API you can find here: https://cd.apps.argoproj.io/swagger-ui This is work in progress.
