# @md-sc/sdk

> 标签: JavaScript

## 简介

Core engine bindings for the md-sc markdown editor (vanilla TypeScript, framework-agnostic). Internal monorepo package — not published to npm; consumed by @md-sc/react, @md-sc/vue via the workspace.
