# @phestus/express-api

> 标签: api, api-provider, backend, express, express-5, framework, http, middleware, modular, phestus, typescript

## 简介

The Express API provider for Phestus, integrating Express 5 with the Phestus API and middleware modules to handle HTTP requests and route registration.
