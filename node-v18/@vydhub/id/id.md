# @vydhub/id

> 标签: auth, identity, react, sso, supabase, vyd

## 简介

SDK oficial de autenticação do ecossistema VYD — login corporativo único (SSO) via id.vydhub.com. Provider, guard, switcher e client Supabase federado.
