# @faraday-academy/three

> 标签: JavaScript

## 简介

Faraday Academy 3D addon — R3F/three.js block (Scene3D, Body, Model, world packs) that 3D lessons pin. R3F is a peer the lesson provides; optional @react-three/rapier unlocks the physics pack.
