# @groundbrick/svelte-ui

> 标签: bootstrap, components, design-system, svelte, svelte5, ui

## 简介

Reusable Svelte 5 UI components (design system): buttons, cards, alerts, badges, form fields, dropdowns, modals, empty states and more. Themeable via CSS variables.
