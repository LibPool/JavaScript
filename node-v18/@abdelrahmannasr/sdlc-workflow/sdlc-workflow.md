# @abdelrahmannasr/sdlc-workflow

> 标签: bmad, cli, sdlc, spec-driven-development, workflow

## 简介

Gated, team, multi-repo SDLC workflow: author → review → build with a PR-driven review gate and a zero-dependency CLI (setup, gate, commit, open-pr, repo). A BMAD module + 17 skills.
