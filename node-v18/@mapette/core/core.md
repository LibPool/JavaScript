# @mapette/core

> 标签: bottom-sheet, cluster, map, maplibre, maplibre-gl, photo, pilgrimage, popover

## 简介

Framework-agnostic map UI on MapLibre for place-and-photo sites: Apple Maps–like basemap, cluster bubbles, photo pins, popovers, a side panel / bottom sheet, theme and locale helpers.
