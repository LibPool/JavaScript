# @openanime/hcl-unmarshal

> 标签: browser, configuration, hcl, hcl-unmarshal, hcl2json, javascript, json, nodejs, parser, pure-js, react-native, terraform, typescript, zero-dependency

## 简介

A lightweight, zero-dependency TypeScript library that converts HashiCorp Configuration Language (HCL) into plain JSON objects. Seamlessly runs in Node.js, modern web browsers, and React Native environments.
