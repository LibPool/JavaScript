# @lucabeapps/react-network-map

> 标签: bbox, conectagd, geojson, gis, map, maplibre, maplibre-gl, openstreetmap, osm, power-grid, react, rede-eletrica

## 简介

Componente React para exibir redes elétricas (postes, rede BT/MT, transformadores...) sobre OpenStreetMap com MapLibre GL. Busca dados por bounding box e é totalmente customizável.
