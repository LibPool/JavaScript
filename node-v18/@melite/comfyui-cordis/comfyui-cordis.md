# @melite/comfyui-cordis

> 标签: JavaScript

## 简介

The comfyui engine's Cordis compose plane + models registry — one package, two services (ctx.models + ctx.comfyui). Runtime is node --experimental-strip-types (erasable-syntax TS); no build step. Cards are one-folder units (card-folder-shape design record
