# @dudko.dev/pdf-to-md-core

> 标签: markdown, pdf, pdf-parser, pdf-to-markdown, wasm, webassembly

## 简介

PDF → Markdown (Rust/WASM parsing core with a typed TypeScript API). Works in browsers, Node and Cloudflare Workers.
