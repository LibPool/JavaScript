# @agenticprimitives/mcp-oauth

> 标签: agent-authority, agentic, agentic-primitives, agentic-trust, agenticprimitives, ai-agents, grant-bundle, mcp, oauth, primitives

## 简介

MCP OAuth compatibility adapter (spec 277 §6-§8,§15): protected-resource metadata, scopes, WWW-Authenticate, bearer-token claim validation, and the Agentic Grant Bundle bridge. OAuth is ingress-compat only, not the vault authority.
