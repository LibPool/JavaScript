# @agenticprimitives/intent-engagement

> 标签: agent-authority, agentic, agentic-primitives, agentic-trust, agenticprimitives, ai-agents, engagement, intent, mandate, offer, primitives

## 简介

Intent engagement protocol core (spec 336 §8): probe → response → offer → acceptance → mandate requirement → execute → receipt as pure documents, JCS digests, and two deterministic reducers. Transport-free; grants nothing.
