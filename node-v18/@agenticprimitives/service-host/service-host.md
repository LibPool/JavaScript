# @agenticprimitives/service-host

> 标签: agent-authority, agentic, agentic-primitives, agentic-trust, agenticprimitives, ai-agents, harness, primitives, service-agent, service-host

## 简介

The Service Host (spec 433): the harness run pipeline a service agent embeds — run store, progress, routes, tools, provenance sink — so a service built as an app runs the same harness the runtime hosts. W1 step 1: the run store behind a port.
