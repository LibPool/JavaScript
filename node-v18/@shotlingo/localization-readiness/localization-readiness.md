# @shotlingo/localization-readiness

> 标签: app-store, app-store-connect, app-store-optimization, aso, character-limits, i18n, ios, l10n, localization, rtl, text-expansion

## 简介

Per-locale text expansion, script family, and RTL/overflow risk for all 41 App Store Connect languages — check whether your app name still fits after translation. Zero dependencies, no network calls.
