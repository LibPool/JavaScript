# lotusai

> 标签: api key, api-key, codex, codex-cli, coding-agent, gpt-6, gpt-6.1-sol, lotusai, setup

## 简介

LotusAI setup for Codex: adds the LotusAI provider to ~/.codex/config.toml, saves your API key and checks it. GPT-6.1 Sol, GPT-6 Astra and more on one key.
