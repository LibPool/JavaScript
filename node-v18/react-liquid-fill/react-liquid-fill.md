# react-liquid-fill

> 标签: animation, clip-path, fill, hook, hover, icon, liquid, nextjs, react, scroll

## 简介

Pour colour into icons, buttons and text. A tiny React component and hook that reveals content with an animated liquid edge on hover, focus or scroll.
