# @devladpopov/agent-audit

> 标签: acp, agentic-commerce, ai-agents, ap2, audit, ecommerce, readiness, schema.org, ucp

## 简介

Open-source readiness checker for agentic commerce: scores a storefront on UCP/ACP/AP2, structured product data, feeds, agent access, checkout and trust signals, with fixes linked to the specs.
