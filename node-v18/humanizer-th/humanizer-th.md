# humanizer-th

> 标签: agent-skills, claude-code, codex, humanizer, localization, subtitles, thai, translation

## 简介

Thai-language Agent Skills: translate subtitles, games, apps and websites into natural Thai, write dialogue and voice scripts for AI short dramas, and edit AI-written Thai. One command installs them into Claude Code, Codex, Gemini CLI and Copilot.
