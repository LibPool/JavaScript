# @eremyjay/web-server

> 标签: authentication, c2, feathers, https, mongoose, redis, server, spdy, web

## 简介

A web server based on feathers with multiple features including mongoose integration, redis support, choice of web server, built in user authentication, built in services management and heartbeat.
