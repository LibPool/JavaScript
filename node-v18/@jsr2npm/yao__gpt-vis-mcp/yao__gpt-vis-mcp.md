# @jsr2npm/yao__gpt-vis-mcp

> 标签: JavaScript

## 简介

A **local/private-favored wrapper** for [antvis/mcp-server-chart](https://github.com/antvis/mcp-server-chart) that generates charts locally without external server dependencies.
