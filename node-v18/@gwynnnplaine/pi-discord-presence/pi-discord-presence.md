# @gwynnnplaine/pi-discord-presence

> 标签: discord, discord-rpc, extension, pi, pi-agent, pi-package, rich-presence

## 简介

Discord Rich Presence for Pi — shows live agent activity (editing, reading, running commands) in your Discord status, with project, model, and a session timer.
