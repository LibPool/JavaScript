# @dynamic-labs-sdk/wagmi

> 标签: JavaScript

## 简介

Official [wagmi](https://wagmi.sh) support for the Dynamic JS SDK. Expose a Dynamic-managed EVM wallet account (embedded/OTP or external) as a wagmi connector so `useAccount`, `useSendTransaction`, `useReadContract`, and the rest of the wagmi/viem hook ec
