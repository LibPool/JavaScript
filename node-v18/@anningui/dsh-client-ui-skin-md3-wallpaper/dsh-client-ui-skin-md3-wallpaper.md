# @anningui/dsh-client-ui-skin-md3-wallpaper

> 标签: JavaScript

## 简介

Standalone Material You (MD3) dynamic-color skin for the dsh web GUI: upload any wallpaper, Monet extracts the palette with @material/material-color-utilities, and every UI token, SVG and surface follows
