# @apislash/ip

> 标签: address, apislash, cidr, ip, ipv4, ipv6, subnet, typescript

## 简介

Dependency-free IPv4/IPv6 address utilities for any TypeScript project — parse, validate, compare, range/CIDR, subnet, bytes. Exact BigInt-backed v6, strict parsing (no SSRF mis-classification). Published by Apislash.
