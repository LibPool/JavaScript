# @mengyu1026/deps-manager

> 标签: dependencies, dependency-management, deps, gui, install, monorepo, multi-project, npm, npm-gui, package, package-manager, update, visual, 依赖管理, 可视化, 可视化界面, 热重载

## 简介

一个可视化的npm依赖管理工具,让依赖管理更简单。支持多项目检测、自动热重载、依赖搜索安装卸载更新。
