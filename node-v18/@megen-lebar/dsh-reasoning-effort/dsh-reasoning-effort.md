# @megen-lebar/dsh-reasoning-effort

> 标签: deepseek-harness, dsh, reasoning-effort, web-plugin

## 简介

DSH Web GUI 思考强度配置器：侧边栏新增「思考强度」入口，可视化管理第三方 API 各模型的 reasoning effort（自动带出官方档位、保留 off、自定义线上拼写），一键写回 settings 的 llm-pi-ai 命名空间，无需手写 YAML。
