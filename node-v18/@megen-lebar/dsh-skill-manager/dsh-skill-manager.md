# @megen-lebar/dsh-skill-manager

> 标签: deepseek-harness, dsh, github, skills, web-plugin

## 简介

DSH Web GUI 技能管理器：在设置中查看本地技能，并从公开 GitHub 仓库预览、安装、更新和删除技能。
