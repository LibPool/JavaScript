# @pired/sap-fiori-mcp-server

> 标签: ai, btp, cap, cds, destinations, fiori, fiori-elements, llm, mcp, model-context-protocol, odata, sap, sap-btp, scaffolding, ui5

## 简介

Unified Model Context Protocol (MCP) server for SAP Fiori development: Fiori Elements app generation (5 floorplans), UI5 metadata & tooling, CAP/CDS model introspection and SAP BTP destinations connectivity (OData V2/V4 queries). Inspired by @sap-ux/fiori
