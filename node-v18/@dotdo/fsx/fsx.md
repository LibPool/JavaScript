# @dotdo/fsx

> 标签: ai-agents, backend, edge, filesystem, find, fs, glob, grep, posix, self-hostable, storage, typescript, virtual-fs, workers, zero-dependencies

## 简介

Pure POSIX filesystem implementation in TypeScript. Zero dependencies. Self-hostable. FsBackend interface for pluggable storage.
