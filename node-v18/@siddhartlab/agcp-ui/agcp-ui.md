# @siddhartlab/agcp-ui

> 标签: JavaScript

## 简介

This UI Components Library is bootstrapped with React, TailwindCSS, Storybook, and Material-UI. We take MUI components and wrap them into AG custom theme which is designed and developed by the Design team and can be found on here: https://design.arisglob
