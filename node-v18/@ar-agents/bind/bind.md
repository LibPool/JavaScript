# @ar-agents/bind

> 标签: agent, ai-sdk, apibank, ar-agents, argentina, baas, banco-industrial, banking, bind, cbu, cvu, debin, echeq, sociedades-ia, transferencias, vercel-ai

## 简介

BIND APIBANK (Banco Industrial BaaS) tools: transfers, DEBIN, echeq, account movements, CBU/CVU ownership. Adapter pattern: real JWT HTTP client behind a pluggable adapter, structured unconfigured default so unit tests never call the network.
