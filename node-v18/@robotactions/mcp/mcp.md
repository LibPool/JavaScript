# @robotactions/mcp

> 标签: android, claude-desktop, cursor, device-control, ios, mcp, model-context-protocol, robot-actions, test-automation

## 简介

One-command installer for Robot Actions MCP. Connects Claude Desktop / Cursor / VS Code Copilot / Windsurf / Goose / Cline / Continue to your Robot Actions account.
