# @inadigital-ui/react-chart

> 标签: JavaScript

## 简介

Wrapper sederhana untuk ApexCharts di React. Package ini sudah termasuk `react-apexcharts` dan `apexcharts`, sehingga Anda tidak perlu menginstall dependencies tersebut secara terpisah.
