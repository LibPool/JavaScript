# @elasticfunnels/cli

> 标签: cli, cms, elasticfunnels, landing-pages, sync

## 简介

ElasticFunnels command-line tool. Folder-scoped auth and full sync, designed to be used by humans, scripts, Claude Code, and any other automation.
