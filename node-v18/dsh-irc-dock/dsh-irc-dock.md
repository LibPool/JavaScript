# dsh-irc-dock

> 标签: chat, deepseek-harness, dsh, dsh-bundle, dsh-plugin, irc, libera, sidebar

## 简介

DSH 右侧栏的 IRC 客户端：宿主用 node tls/net 直连 IRC（也可选走本机代理的 HTTP CONNECT 隧道），右侧栏收发消息，Agent 也能读和发（irc_panel 工具）。
