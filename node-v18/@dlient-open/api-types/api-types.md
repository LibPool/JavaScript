# @dlient-open/api-types

> 标签: JavaScript

## 简介

目的：把 host-api 的**方法签名 + 参数/返回类型 + 英文说明**收敛为单一来源，worker（`@dlient-open/plugin-sdk`）与 UI（`@dlient-open/api-bridge`）两端引用同一套类型，避免双份漂移。
