# @botscape/plugin-skills-bridge

> 标签: JavaScript

## 简介

BotScape skills bridge plugin: syncs an IDBots-style SKILL.md directory tree into the DSH skills registry (botscapeSkills service), with kebab-case name normalization and persisted sync state in the botscape_skills_bridge storage domain.
