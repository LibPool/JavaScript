# @botscape/plugin-private-chat

> 标签: JavaScript

## 简介

BotScape private-chat daemon plugin: watches MetaWeb private messages per Bot, answers with the bot persona (memory injected) through the llm runtime, and sends ECDH-encrypted replies on-chain as /protocols/simplemsg PINs, including the MetaSwarm ping/pon
