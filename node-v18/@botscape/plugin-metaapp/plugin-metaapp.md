# @botscape/plugin-metaapp

> 标签: JavaScript

## 简介

BotScape MetaApp plugin: search on-chain MetaApps (so.metaid.io aggregation API), install them locally (metafile zip download + safe extraction), serve them on 127.0.0.1 with SPA fallback, and publish a local directory as a MetaApp (zip -> metafile upload
