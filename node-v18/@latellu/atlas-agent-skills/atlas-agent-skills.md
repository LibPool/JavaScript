# @latellu/atlas-agent-skills

> 标签: agent, atlas, claude-code, cms, headless-cms, mcp, skill

## 简介

Agent skill + MCP configuration for Atlas CMS. Works as a Claude Code plugin and as plain markdown guidance for any AI coding agent (Cursor, Codex, opencode, Gemini CLI, ...).
