# @svgfx/postprocessing

> 标签: bloom, design, duotone, effects, filter, glitch, halftone, post-processing, postprocessing, scanlines, svg

## 简介

Post-processing effects for any SVG. Scanlines, bloom, glitch, halftone and more — in, out, still an SVG.
