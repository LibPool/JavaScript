# carousel-pdf-cli

> 标签: carousel-generator, cli, content-repurposing, developer-tools, linkedin-carousel, pdf-generator, social-media, text-to-carousel

## 简介

Deterministic text-to-carousel PDF generator for LinkedIn and X. Converts markdown and articles into high-resolution multi-page slide decks. Zero browser overhead.
