# @joolt/platform-mcp

> 标签: claude, crm, joolt, leads, mcp, model-context-protocol, sophia

## 简介

MCP (Model Context Protocol) server for the JOOLT platform. Wraps the JOOLT REST API so Claude Desktop, Cursor, and any other MCP-aware client can push leads, book appointments, and update contacts using natural-language tool calls.
