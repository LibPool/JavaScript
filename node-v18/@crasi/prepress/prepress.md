# @crasi/prepress

> 标签: barcode, cmyk, ean13, label, nextjs, packaging, pdf, preflight, prepress, print, react

## 简介

React components for print-ready labels and packaging artwork: millimetres, inks and regulations instead of pixels, hex codes and viewports, with a preflight engine and PDF export.
