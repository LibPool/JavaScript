# @rosavera/tdd-dsl

> 标签: cli, dsl, tdd, testing, vitest

## 简介

LLM-friendly TDD DSL CLI — one contract for behavior implemented in more than one place (backend + frontend, MCP server + clients); emit each side's tests without a local Python install.
