# @matt.kantor/silk

> 标签: JavaScript

## 简介

Silk is an embedded DSL for authoring HTML from TypeScript. You write simple typed [JSX][jsx] and Silk generates [`ReadableStream`s][readable-stream] of [`HTMLToken`s][html-tokens].
