# @metaworkers/openclaw-governed-memory

> 标签: agent-security, governed-memory, memory-governance, openclaw, openclaw-plugin, privilege-gate, prompt-injection, trust-governance

## 简介

Governed Memory plugin for OpenClaw — injection-scores memory on write, governs retrieval, and blocks agent actions backed by untrusted/poisoned memory.
