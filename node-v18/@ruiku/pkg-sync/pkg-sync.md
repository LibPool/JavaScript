# @ruiku/pkg-sync

> 标签: JavaScript

## 简介

因为现在webpack打包的东西基本上都是生成了新的文件，而同步到服务器要么用svn，要么用什么git工具，感觉不是特别方便，所以做了这个，其原理就是对比了服务端的文件夹信息版本和本地的是否一致，如果不一致就删除服务端的，上传本地的
