# @nestjs-agentic/openai

> 标签: chat-completions, groq, model-adapter, nestjs, nestjs-agentic, ollama, openai, openrouter, tool-calling, vllm

## 简介

OpenAI-compatible ModelAdapter for nestjs-agentic. Works with OpenAI and any Chat Completions compatible endpoint such as Azure OpenAI, Ollama, vLLM, Groq, Together, OpenRouter, and LM Studio.
