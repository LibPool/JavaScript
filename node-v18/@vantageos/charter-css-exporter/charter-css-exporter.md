# @vantageos/charter-css-exporter

> 标签: JavaScript

## 简介

Turns a DTCG charter (charter-dtcg v1 contract) into CSS custom properties in @vantageos/mosaic-tokens shape. Consumes the mosaic naming convention as a pinned contract; never writes to the mosaic repo.
