# @adeildo/pi-ask-questions

> 标签: ask-user-question, pi, pi-coding-agent, pi-extension, pi-package, questionnaire

## 简介

Lets the model ask you instead of guessing: options with a preview of each, a note on any of them, and your own answer, in a dialog that scrolls with the chat.
