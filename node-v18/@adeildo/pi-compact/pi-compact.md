# @adeildo/pi-compact

> 标签: compaction, context, pi, pi-coding-agent, pi-extension, pi-package, prompt-caching

## 简介

Keeps a long pi session's context small: hides old tool output, keeping each call so the agent can run it again, and writes pi's compaction summary from the session's tasks.
