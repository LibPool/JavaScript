# @nitro-mlkit/face-detection

> 标签: expo, expo-plugin, face-detection, machine-learning, mlkit, nitro, on-device, react-native

## 简介

High-performance on-device face detection for React Native — Google ML Kit + Nitro Modules (JSI). Native batch processing, face cropping, zero bridge overhead.
