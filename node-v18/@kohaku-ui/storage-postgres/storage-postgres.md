# @kohaku-ui/storage-postgres

> 标签: JavaScript

## 简介

PostgreSQL-backed StoragePort for kohaku (Spec cache, lineage, promotion state, fixation) — a reference adapter with an idempotent schema; the contract stays @kohaku-ui/spec-core's ports.ts.
