# @misakaikato/simulacra

> 标签: agent-based-modeling, audit, bun, llm, mcp, multi-agent, robustness, social-simulation, typescript

## 简介

Typed, event-sourced kernel for LLM-driven social simulation with a built-in robustness-audit harness. CLI, HTTP API, MCP server and GUI.
