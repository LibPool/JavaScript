# @web3-onboard/keystone

> 标签: Blocknative, Coinbase, Connect Wallet, EVM, Ethereum, Ethereum Hooks, Hardware Wallet, Injected Wallet, Ledger, Mempool, MetaMask, Multichain, Next, Notifications, Nuxt, Provider, React, Svelte, Transaction, Trezor, Vue, Wallet, WalletConnect, Web3, confirmed, dapp, pending

## 简介

Keystone hardware wallet module for connecting to Web3-Onboard. Web3-Onboard makes it simple to connect Ethereum hardware and software wallets to your dapp. Features standardised spec compliant web3 providers for all supported wallets, framework agnostic
