# @imrocchan/dsh-drawio

> 标签: deepseek-harness, diagram, diagrams.net, drawio, dsh, dsh-plugin, mxgraph

## 简介

DSH drawio 插件：agent 画图工具（drawio_template / drawio_edit / drawio_validate / drawio_render）+ 官方右侧栏的「Drawio 画板」标签页——mxfile XML 实时渲染为 SVG、导出 PNG、写入工作区。核心翻译器为纯 TS 零依赖，宿主与浏览器共用。
