# @kyntocg/bloomx-cli

> 标签: admin, bloomx, cli, mail

## 简介

Command-line client for the BloomX administration API: control a BloomX instance (users, quotas, audit, security, branding, spam, extensions, import/export) from your terminal over HTTPS.
