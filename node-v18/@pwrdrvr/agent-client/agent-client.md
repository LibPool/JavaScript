# @pwrdrvr/agent-client

> 标签: adapter, agent, app-server, chat, client, codex

## 简介

Codex App Server adapter for agent-kit: long-lived multi-turn thread client, one-shot structured-output client, and a surface-agnostic chat controller, all normalizing into the agent-core neutral schema.
