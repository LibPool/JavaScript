# @pdsjs/npm

> 标签: JavaScript

## 简介

Host npm packages natively in an atproto account. Dist-tags, version manifests and tarballs live in the account's PDS as a `dev.pdsjs.npm.package` record plus blob storage, so a package rides along in CAR backups, migrates with the account, and needs no s
