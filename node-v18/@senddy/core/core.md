# @senddy/core

> 标签: base, cryptography, noir, privacy, senddy, stablecoin, usdc, zero-knowledge, zk

## 简介

Core cryptographic library for the Senddy private stablecoin protocol. ZK circuits, key derivation, note management, Merkle tree cache, and attestor client.
