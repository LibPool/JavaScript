# @thisisayande/openscrim-react

> 标签: code-recording, interactive-tutorial, monaco, monaco-editor, playback, react, screencast, scrim, scrimba, sdk

## 简介

React SDK for OpenScrim — drop-in <ScrimRecorder> / <ScrimPlayer> components and headless hooks to record and replay interactive, forkable code screencasts. Bring your own storage.
