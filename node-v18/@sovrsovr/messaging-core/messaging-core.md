# @sovrsovr/messaging-core

> 标签: JavaScript

## 简介

Canonical SOVR wire protocol — Double Ratchet, v3 envelope, topics. Pure isomorphic TypeScript: no Node builtins, no DOM. Consumed by apps/web and packages/agent-core.
