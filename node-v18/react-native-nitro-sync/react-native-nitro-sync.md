# react-native-nitro-sync

> 标签: expo, local-first, offline-first, react-native, react-native-nitro-modules, sqlite, sync

## 简介

Local-first e offline-first synchronization engine for React Native with synchronous Nitro Modules, SQLite persistence, optimistic mutations, and backend-agnostic transport.
