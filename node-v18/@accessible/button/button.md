# @accessible/button

> 标签: a11y, a11y button, a11y button hook, accessible button, aria, aria button, button, react, react a11y button, react accessible button, react aria button, react button, react button component, react component, use-a11y-button, usea11ybutton

## 简介

An accessible button component for React that provides interop between real <button> elements and fake ones, e.g. <div role='button'>
