# @openemail/cli

> 标签: cli, command line, email, email api, email templates, inbox, mailbox, mcp, openemail, send email, temp mail, terminal, webhooks

## 简介

The official OpenEmail command line. Sign in once, then send and read mail, manage domains, addresses, keys, webhooks, templates, contacts, audiences and every other OpenEmail resource, use the AI tools and connect MCP clients from your terminal.
