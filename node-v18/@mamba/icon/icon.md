# @mamba/icon

> 标签: JavaScript

## 简介

O módulo Icon possui dois componentes: `Icon` e `RoundIcon`. Ambos facilitam a criação de ícones com imagens padrões já disponíveis em nossa SDK. Além das imagens, também é possível customizar o estilo do ícone e utilizar uma imagem própria.
