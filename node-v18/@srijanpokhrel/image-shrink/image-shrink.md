# @srijanpokhrel/image-shrink

> 标签: avif, compression, image, jpeg, png, sharp, webp

## 简介

Compress AVIF, WebP, JPEG, and PNG images from the CLI or Node.js API — powered by [sharp](https://sharp.pixelplumbing.com/) (libvips).
