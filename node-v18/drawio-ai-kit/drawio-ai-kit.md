# drawio-ai-kit

> 标签: agent-skill, ai, architecture-diagram, aws, azure, bpmn, claude, diagram, draw.io, drawio, gcp

## 简介

Helps an AI draw correct, beautiful draw.io diagrams: ground-truth AWS/Azure/GCP/OSS icon catalogs, a declarative layout engine, a validator, and one agent skill. drawio-ai CLI with no runtime dependencies (bundled).
