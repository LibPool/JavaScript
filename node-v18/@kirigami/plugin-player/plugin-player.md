# @kirigami/plugin-player

> 标签: audio, kirigami, kirigami-plugin, mp3, player, playlist, plugin, waveform

## 简介

<player> / <playlist> audio players for Kirigami — SoundCloud-style waveform baked at build time with audiowaveform-wasm, cached in src/_data/player.
