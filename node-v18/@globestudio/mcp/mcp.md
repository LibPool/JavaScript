# @globestudio/mcp

> 标签: ai-tool, claude, dotted-map, globe, globestudio, map, mcp, model-context-protocol

## 简介

MCP server for Globestudio. It lets an AI assistant (Claude, Cursor, Codex and others) make dotted globes, build share links and get embed code.
