# @globestudio/react

> 标签: data-viz, dotted-globe, embed, globe, globestudio, iframe, map, nextjs, react

## 简介

React component that embeds a Globestudio dotted globe. Works in React, Next.js, Remix, Astro and anywhere JSX renders.
