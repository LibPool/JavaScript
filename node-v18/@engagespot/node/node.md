# @engagespot/node

> 标签: JavaScript

## 简介

node.js library for communicating with Engagespot REST API. Send multi-channel notifications from your node app.

## 官网

- 官网：https://github.com/Engagespot/engagespot-node
- 源码仓库：git+ssh://git@github.com/Engagespot/engagespot-node.git
