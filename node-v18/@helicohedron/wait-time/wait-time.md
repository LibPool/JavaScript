# @helicohedron/wait-time

> 标签: JavaScript

## 简介

Function that calculates the total wait time for a set of customers in a queue to all pass through. It takes in an array of customers and a certain number of counters/ gates. Customers are represented by a number indicating the length of time (seconds) it
