# @apteva/web-sdk

> 标签: agents, apteva, auth, browser, mcp, sdk

## 简介

Browser SDK for apteva-server. Handles session cookies, API keys, and opaque application-user access tokens; wraps app HTTP, MCP, agents, chat, telemetry, and authenticated SSE. Framework-agnostic.
