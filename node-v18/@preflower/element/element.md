# @preflower/element

> 标签: JavaScript

## 简介

`easy-element` 是基于 `Element-UI` 再封装的 JSON 化组件库，用来解决 `Element-UI` 部分组件经常性的重复劳动问题

- 源码仓库：git+https://github.com/preflower/easy-element.git
