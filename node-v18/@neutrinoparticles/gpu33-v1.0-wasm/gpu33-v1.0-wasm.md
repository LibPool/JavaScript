# @neutrinoparticles/gpu33-v1.0-wasm

> 标签: effectico, gamedev, gpu, neutrinoparticles, particles

## 简介

WASM build of the low-level [NeutrinoParticles](https://neutrinoparticles.com/) GPU33 runtime. Particle simulation and rendering run entirely on the GPU (WebGL2).
