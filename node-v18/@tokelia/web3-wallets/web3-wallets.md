# @tokelia/web3-wallets

> 标签: blockchain, crypto, wallets, web3

## 简介

One-Stop-Shop JavaScript library to integrate various web3 crypto wallets and multiple blockchains at once with a single interface.

- 官网：https://github.com/tokelia/web3-wallets
- 源码仓库：git+ssh://git@github.com/tokelia/web3-wallets.git
