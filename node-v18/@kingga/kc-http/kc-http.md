# @kingga/kc-http

> 标签: Axios, Fetch, HTTP, JavaScript, Kings Collection, TypeScript

## 简介

An HTTP strategy which allows you to switch between multiple HTTP libraries such as Axios, Fetch, etc. without changing any code.
