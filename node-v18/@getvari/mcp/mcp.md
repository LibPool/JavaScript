# @getvari/mcp

> 标签: calculators, claude, cursor, health, hydration, mcp, model-context-protocol, wellness

## 简介

Stdio bridge that connects MCP clients (Claude Desktop, Cursor, Continue.dev) to the public Vari Hydration Tools MCP server at https://getvari.app/api/mcp/v1.

## 官网

- 官网：https://getvari.app
- 源码仓库：git+https://github.com/getvari/vari-mcp.git
- npm 页面：https://www.npmjs.com/package/@getvari/mcp
