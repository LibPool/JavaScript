# onelobby

> 标签: browser-game, game, gamedev, lobby, lockstep, multiplayer, netcode, onelobby, p2p, peer-to-peer, voice-chat, webrtc

## 简介

Multiplayer for browser games: host/join lobbies by short code, peer-to-peer WebRTC, lockstep sync, text and voice chat. Zero runtime dependencies; works from a plain <script> tag.
