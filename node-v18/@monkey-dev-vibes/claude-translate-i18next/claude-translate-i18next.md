# @monkey-dev-vibes/claude-translate-i18next

> 标签: ai, anthropic, claude, cldr, i18n, i18next, json, l10n, localization, plurals, react-i18next, translation

## 简介

Two-pass Claude translation pipeline for i18next-style JSON locale files. Frozen-keys manifest, diff-mode, CLDR plural expansion, interpolation preservation, checkpoint resumability.
