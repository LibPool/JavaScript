# @m8tes/sdk

> 标签: agent, agents, ai, m8tes, sdk, streaming, typescript

## 简介

TypeScript SDK for the m8tes API — create agents, schedule tasks, stream runs, and verify webhooks from Node, Deno, or Bun.
