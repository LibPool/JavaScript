# @kubohiroya/turbowarp-3d-scene-runtime

> 标签: 3d, aframe, ar, extension, scene-graph, scratch, turbowarp, yaml

## 简介

A TurboWarp extension that applies a 3D/AR scene description by dispatching its call plan to turbowarp-aframe and turbowarp-ar.
