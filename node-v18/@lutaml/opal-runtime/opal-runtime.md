# @lutaml/opal-runtime

> 标签: javascript, lutaml, opal, ruby, runtime

## 简介

Pure Opal runtime for browser and Node.js. Shared by @unitsml/unitsml and other Opal-compiled gems so they don't each ship their own Opal runtime.
