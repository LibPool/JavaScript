# @unfoldingcx/inter.js

> 标签: banco-inter, bolepix, boleto, brazil, fintech, inter, mtls, open-banking, pix, pix-automatico, sdk, typescript

## 简介

TypeScript SDK for the Banco Inter partner APIs: Cobrança (Boleto com Pix), Banking, Pix and Pix Automático. mTLS, OAuth scopes, retries, rate limiting and typed webhooks included.
