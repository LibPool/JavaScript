# @concordium/wdk-wallet-concordium

> 标签: ccd, concordium, multi-chain, tether, wallet, wdk

## 简介

WDK wallet module for the Concordium blockchain: account derivation, native CCD, PLT + CIS-2 tokens, sponsored transactions, and single-identity account recovery.
