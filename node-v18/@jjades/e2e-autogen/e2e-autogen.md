# @jjades/e2e-autogen

> 标签: cli, e2e, playwright, test-generation

## 简介

Google 스프레드시트 기반 시나리오를 Playwright 테스트 스텁 코드로 자동 생성하고, 테스트 실행 결과를 다시 시트에 업데이트하는 CLI 도구
