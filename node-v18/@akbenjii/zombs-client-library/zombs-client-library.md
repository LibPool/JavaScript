# @akbenjii/zombs-client-library

> 标签: api, client, game, nodejs, zombs.io

## 简介

A comprehensive Node.js library for interacting with the zombs.io game server. It provides a high-level API for easily connecting to the server, managing game sessions, and performing various actions in the game.
