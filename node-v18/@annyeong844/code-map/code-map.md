# @annyeong844/code-map

> 标签: ast, claude, code-map, code-navigation, codex, llm, mcp, python, retrieval, symbol-index, typescript

## 简介

A code map that routes to coordinates, not meaning. Guides an LLM to the crate; the LLM interprets the raw from there.
