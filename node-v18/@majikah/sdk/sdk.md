# @majikah/sdk

> 标签: blockchain-anchor, cryptography, digital-signatures, identity-verification, majik-signature, majikah, muid, notarization, notary, sdk, security, slink, timestamping, tsa, typescript

## 简介

Official TypeScript client SDK for the Majikah ecosystem, providing unified access to Majik Universal ID (MUID) identity verification, Time Stamping Authority (TSA) issuing, cryptographically signed link claims (SLink), and on-chain document notarization
