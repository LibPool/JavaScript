# @majikah/majik-file

> 标签: aes-gcm, compression, cryptography, encrypted-files, file-encryption, file-security, hybrid-encryption, key-encapsulation, majik-file, majikah, mjkb, ml-kem, multi-recipient-encryption, post-quantum, post-quantum-cryptography, secure-file-format, secure-files, secure-storage, wasm-crypto, zstd

## 简介

Majik File is the core cryptographic engine for secure file handling in the Majikah ecosystem. It provides a post-quantum secure "MJKB" format designed for file encryption, multi-recipient key encapsulation, and transparent compression using NIST-standard
