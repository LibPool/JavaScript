# @ra11y/core

> 标签: a11y, accessibility, bun, certification, compliance, css, en-301-549, html, jsx, linter, scanner, section-508, tailwind, tsx, typescript, vpat, wcag, wcag-2.1, wcag-2.2, zero-dependencies

## 简介

Multi-standard accessibility scanner. Zero runtime dependencies. WCAG 2.2 / 2.1, Section 508, EN 301 549, and a plugin API for custom standards.
