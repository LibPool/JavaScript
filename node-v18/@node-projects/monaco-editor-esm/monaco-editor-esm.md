# @node-projects/monaco-editor-esm

> 标签: esm, monaco

## 简介

A real ESM (EcmaScript Module) build of the Monaco Editor, suitable for modern build tools and direct browser usage. This package provides the Monaco Editor as native JavaScript modules in the /esm directory, and all required CSS in /min.
