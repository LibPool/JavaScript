# @mieditor/nextjs

> 标签: JavaScript

## 简介

`@mieditor/nextjs` 为 Next.js 项目提供 UI Editor 开发期集成。它包含 Next 配置包装器、客户端桥接组件和 App Router API route 处理器，用于注入元素标识、加载编辑面板并回写源码样式。
