# @mieditor/nuxt

> 标签: JavaScript

## 简介

`@mieditor/nuxt` 为 Nuxt 项目提供 UI Editor 开发期集成。模块会在开发模式下自动注册客户端桥接插件，并把 `@mieditor/vue` 加入 Nuxt 的 Vite 插件列表。
