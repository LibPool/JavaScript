# @mieditor/svelte

> 标签: JavaScript

## 简介

`@mieditor/svelte` 为 Svelte + Vite 项目提供 UI Editor 开发期集成。插件会处理 `.svelte` 文件，注入 `data-mi-editor-id`，并提供编辑面板需要的元数据查询和样式回写接口。
