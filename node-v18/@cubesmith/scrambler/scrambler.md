# @cubesmith/scrambler

> 标签: cube, rubiks-cube, scramble, speedcubing, typescript, wca

## 简介

Dependency-free WCA scramble generation. Pure computation only — no Web Workers, no DOM, no browser-only APIs — so it runs identically in Node, Bun, Vite, and both Next.js server and client contexts.
