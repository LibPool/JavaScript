# @amicaldo/strapi-plugin-relation-flow

> 标签: relation-flow, strapi, strapi-plugin, strapi-plugin-relation-flow

## 简介

A plugin for Strapi - Open source Node.js Headless CMS to make your life easier when you want to create new content and instantly link it to your relation field.
