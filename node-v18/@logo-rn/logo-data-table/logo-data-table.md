# @logo-rn/logo-data-table

> 标签: Elements, LEDS, Logo, Logo Elements, component, data-table, polymer, web, web compoonent, web-component, web-components

## 简介

<LogoDataTable /> returns list object. Each item of the list must have a unique id, title, boolean checked value. Icon in not required.
