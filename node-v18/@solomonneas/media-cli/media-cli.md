# @solomonneas/media-cli

> 标签: arr, bazarr, cli, jellyfin, jellyseerr, media-management, media-server, plex, prowlarr, qbittorrent, radarr, sonarr, tdarr, torrent, usenet

## 简介

Single-file bash CLI for the self-hosted media stack: Sonarr, Radarr, Readarr, Lidarr, Prowlarr, Mylar3, qBittorrent, Bazarr, Jellyseerr, Tdarr, Autobrr, cross-seed, Unpackerr, Recyclarr. Works locally or over SSH.
