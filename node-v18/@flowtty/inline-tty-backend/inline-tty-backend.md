# @flowtty/inline-tty-backend

> 标签: cli, flowtty, inline, log, static, terminal, terminal-ui, tty, tui

## 简介

Inline TTY backend for flowtty: redrawable live region with append-only log lines above (the Ink <Static> pattern).
