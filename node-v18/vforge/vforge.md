# vforge

> 标签: ai, bun, generator, nextjs, opencode, plugin, react-router, shadcn, tanstack-start, v0, vite

## 简介

OpenCode plugin to generate React apps (Next.js, Vite, React Router, TanStack Start) from a prompt, with a living workspace inside each generated project.
