# @simplifyingcalculation/irs-sec-179-calculator

> 标签: JavaScript

## 简介

Section 179 Depreciation Software calculates Depreciation Expense that can be claimed under IRS Section 179. Updated for 2025 IRS guidelines. The software also calculates depreciation under Section 168 / Bonus Depreciation in addition to Sec179. Additiona
