# @lesser-auth/hono

> 标签: auth, authentication, hono, oauth2, oidc, otp, session

## 简介

Hono bindings for @lesser-auth/core: session middleware, a route guard, prebuilt auth routes, and cookie helpers for OTP and OIDC login flows.
