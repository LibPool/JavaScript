# @daanvandenbergh/i18nkit

> 标签: i18n, internationalization, localization, react, translations, type-safe, typescript

## 简介

Type-safe i18n for TypeScript - miss a translation and it's a compile error. Framework-agnostic core, optional React layer, and a Claude Code skill that sweeps for untranslated strings.
