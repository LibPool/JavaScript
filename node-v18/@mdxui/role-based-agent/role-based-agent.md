# @mdxui/role-based-agent

> 标签: ai, components, landing-page, marketing, mdxui, react, role-based-agent, templates

## 简介

Role-Based Agent site template — landing components for AI hires that own a role (e.g., AI CFO, AI VP of Sales). Composes @mdxui/neo blocks with role-badge + capabilities pattern.
