# @flowcastle/grammy

> 标签: analytics, bot, broadcast, crm, flowcastle, grammy, grammy-plugin, live-chat, middleware, telegram, telegram-bot

## 简介

FlowCastle grammY plugin — observe a Telegram bot and ship batched analytics/contact/goal events to FlowCastle. Zero runtime dependencies; architecturally incapable of breaking the host bot.
