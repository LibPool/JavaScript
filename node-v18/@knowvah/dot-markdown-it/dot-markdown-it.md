# @knowvah/dot-markdown-it

> 标签: @knowvah/dot-engine, dot, graphviz, markdown-it, markdown-it-plugin, svg

## 简介

markdown-it plugin: render Graphviz DOT fenced code blocks to inline SVG (build time) or a client component — shared by the VitePress and Eleventy DOT plugins. Powered by the pure-TypeScript @knowvah/dot-engine.
