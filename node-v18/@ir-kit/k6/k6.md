# @ir-kit/k6

> 标签: dsl, framework, k6, load-testing, performance

## 简介

Framework for authoring k6 load tests in TypeScript: defineLoadTest, flow().step() chaining, pace presets, budgets, auth middleware. Compiles to standard k6.
