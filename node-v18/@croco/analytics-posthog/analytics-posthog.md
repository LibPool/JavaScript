# @croco/analytics-posthog

> 标签: JavaScript

## 简介

PostHog 기반 분석 이벤트 추적 구현체입니다. `@croco/analytics-core`의 `AnalyticsManager` 추상 클래스를 구현하여 사용자 행동, 사용자 식별, 그룹 연결을 PostHog에 전송합니다.
