# @redchili/storage-ts

> 标签: JavaScript

## 简介

一个类型安全、可扩展的 Storage 抽象库，支持多种运行环境如 Web、 React-Native。定义不同的存储引擎（如 LocalStorage, SessionStorage, Memory、MMKV 等），并提供统一的类型推导与键管理机制。
