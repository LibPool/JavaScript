# @opensuperlab/coderelay

> 标签: agentic-workflow, ai-agents, ai-safety, cli, copilot, copilot-agents, cost-tracking, custom-agents, github-copilot, guardrails, long-running, multi-agent, orchestrator, premium-requests, risk-analysis, session-memory, subagents, vscode

## 简介

Install it and GitHub Copilot works as an orchestrator: every request becomes goal → plan → your approval → specialist agents implement → tests verify (auto-retry up to 5x). Long-running session memory plus cost and risk reports. No MCP, no config.
