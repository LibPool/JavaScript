# @tootix/grapesjs-vue

> 标签: JavaScript

## 简介

Vue 3 包装组件与组合式 API，用于围绕 [GrapesJS](https://grapesjs.com/) 构建自定义编辑器界面。本库负责画布外围的 UI 控制，不会在画布内部渲染 Vue 组件。
