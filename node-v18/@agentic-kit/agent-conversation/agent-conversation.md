# @agentic-kit/agent-conversation

> 标签: agentic-kit, coding-agent, constructive, pi, run-log

## 简介

The agent module's conversation as a library: thread load/create, an inbox over new messages, transcript append, ToolPart state machine and agent_task rows — over an injected GraphQL client.
