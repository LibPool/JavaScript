# @statewalker/ai-local-models.browser

> 标签: JavaScript

## 简介

The browser-platform implementation of in-browser, on-device model engines. It registers two local-model factories on an `@statewalker/ai-agent` `ModelManager` — **transformers.js** (ONNX models via `@browser-ai/transformers-js`) and **WebLLM** (MLC/WebGP
