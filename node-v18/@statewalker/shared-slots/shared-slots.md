# @statewalker/shared-slots

> 标签: JavaScript

## 简介

Framework-agnostic typed pub/sub slots for cross-fragment extension points. Declarations via `defineSlot(key)` / `defineKeyedSlot(key)`; bus methods on `Slots` take the declaration.
