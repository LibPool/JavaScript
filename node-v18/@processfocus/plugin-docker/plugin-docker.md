# @processfocus/plugin-docker

> 标签: JavaScript

## 简介

`@processfocus/plugin-docker` provides the `DockerStep` authoring API. Import the provider-neutral `ExecutorHost` and `FileResolutionHost` contracts from `@processfocus/runtime` when implementing a runtime adapter.
