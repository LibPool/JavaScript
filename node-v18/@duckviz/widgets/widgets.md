# @duckviz/widgets

> 标签: JavaScript

## 简介

Pre-built D3 chart registry and a standalone `<WidgetRenderer>` that runs a DuckDB query and renders one chart. Shared between @duckviz/dashboard, @duckviz/explorer, and host apps.
