# @mezzanine-stack/captcha-turnstile

> 标签: JavaScript

## 简介

[Cloudflare Turnstile](https://developers.cloudflare.com/turnstile/) を使う `CaptchaAdapter` の実装。`@mezzanine-stack/contact-core` の `CaptchaAdapter` contract を満たします。
