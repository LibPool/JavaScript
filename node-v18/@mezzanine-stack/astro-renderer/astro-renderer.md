# @mezzanine-stack/astro-renderer

> 标签: JavaScript

## 简介

Mezzanine Platform の Astro 描画層 headless component 群。 `@mezzanine-stack/content-schema` の `MezzFolderCollection` / `MezzField` を props として受け取り、コンテンツを描画する。
