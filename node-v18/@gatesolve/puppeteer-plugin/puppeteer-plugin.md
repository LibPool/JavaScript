# @gatesolve/puppeteer-plugin

> 标签: ai-agent, anti-captcha, automation, bot-detection, browser-automation, captcha, captcha-bypass, captcha-solver, cloudflare, cloudflare-turnstile, gatesolve, hcaptcha, hcaptcha-solver, mcp, model-context-protocol, puppeteer, puppeteer-extra, puppeteer-extra-plugin, recaptcha, recaptcha-solver, turnstile, web-scraping

## 简介

Automatic CAPTCHA solving for Puppeteer and puppeteer-extra. Detects and solves Cloudflare Turnstile, reCAPTCHA v2/v3, and hCaptcha via GateSolve API. Free tier included.
