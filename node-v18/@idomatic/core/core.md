# @idomatic/core

> 标签: cli, cypress, data-testid, e2e, html, idomatic, ids, parser, playwright, precommit, qa, react, selectors, test-automation, test-id, testid, testing-library, vue

## 简介

CLI that injects stable, human-readable id attributes into React/HTML/Vue/Angular elements so Playwright, Cypress and Testing Library tests stop breaking.
