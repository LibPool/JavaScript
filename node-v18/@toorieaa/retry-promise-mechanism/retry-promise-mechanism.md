# @toorieaa/retry-promise-mechanism

> 标签: async, async task repeater with callback, attempt promise repeatedly, attemptAgain, await, database pooling, failed to connect to mongo db on first connect, lightweight retry library, mongo database pooling, mongodb connection manager, node express mongodb fetch database pool, promise, retry, retry promise, retryAll, set up mongo db database pool async

## 简介

Allows you to retry a promise a number of times with a delay and various options. Useful for some mongo applications where you need to create a connection pool but you can't guarantee the database will be up when the express service starts.
