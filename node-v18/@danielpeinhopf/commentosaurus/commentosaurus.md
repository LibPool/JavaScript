# @danielpeinhopf/commentosaurus

> 标签: JavaScript

## 简介

The CommentosaurusSection React component and API client for Commentosaurus (https://github.com/sevensolutions/commentosaurus). Consumers wire it into their Docusaurus site themselves, e.g. via theme swizzling -- see example-site.
