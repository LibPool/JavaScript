# @irman/nativescript-screen-orientation

> 标签: force-orientation, lock-orientation, nativescript, orientation-change

## 简介

A plugin to force change the orientation of a page programmatically in NativeScript. Supports both Android and iOS. Forked of /nativescript-screen-orientation
