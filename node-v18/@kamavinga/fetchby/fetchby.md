# @kamavinga/fetchby

> 标签: axios-alternative, edge, fetch, http-client, middleware, retry, typescript, zod

## 简介

A modern, ultra-lightweight Fetch API wrapper with Zod schema validation, automatic retries, middlewares, and a result-tuple pattern.
