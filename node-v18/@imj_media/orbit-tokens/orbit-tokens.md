# @imj_media/orbit-tokens

> 标签: css-variables, design-system, design-tokens, orbit, tailwind

## 简介

Design tokens for the Orbit Design System — colors, spacing, typography, radius, shadows, strokes, sizes, z-index. Single source of truth exported as CSS variables, JSON, and Tailwind preset.
