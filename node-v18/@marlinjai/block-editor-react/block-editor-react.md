# @marlinjai/block-editor-react

> 标签: block-editor, dnd-kit, inspector, outline, react, undo

## 简介

Generic parts of a block editor for React: a snapshot undo history, inspector field primitives and a sortable, keyboard-operable outline. No document model and no state library.
