# @conciv/solid-streamdown

> 标签: conciv, markdown, solid-js, streaming

## 简介

Internal to @conciv/it (installed automatically, do not install directly). A SolidJS streaming-markdown renderer: a port of Vercel's streamdown (block memoization, incomplete-markdown handling, token fade-in) onto Solid + the unified pipeline. Encapsulate
