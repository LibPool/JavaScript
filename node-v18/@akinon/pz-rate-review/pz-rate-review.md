# @akinon/pz-rate-review

> 标签: JavaScript

## 简介

Shared rate & review plugin for Project Zero Next storefronts. It talks to the Akinon Rate & Review extension from the server only: the extension base url and Basic auth credentials never reach the browser, the customer identity comes from the storefront
