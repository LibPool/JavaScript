# @faulander/md2adf

> 标签: adf, atlassian, confluence, converter, emoji, jira, markdown, mention, smart-links, typescript

## 简介

Bidirectional converter between Markdown and Atlassian Document Format (ADF) with support for mentions, emojis, and smart links.
