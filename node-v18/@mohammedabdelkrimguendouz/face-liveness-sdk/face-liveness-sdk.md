# @mohammedabdelkrimguendouz/face-liveness-sdk

> 标签: anti-spoofing, biometrics, face, liveness, react, verification

## 简介

Browser SDK for passive face liveness verification. Captures a facial frame sequence and streams it to a liveness backend over WebSocket.
