# payload-plugin-dictionary

> 标签: dictionary, i18n, i18next, localization, next-intl, payload, payloadcms, plugin, translations

## 简介

A Payload CMS v3 plugin that moves static frontend translation keys into the database, enabling content editors to manage UI translations with full localization support.
