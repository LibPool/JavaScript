# keel-dotnet

> 标签: agents, aspnetcore, codegen, dotnet, dsl, keel

## 简介

Generador .NET para diseños Keel: valida el diseño agnóstico y genera services/<servicio>-dotnet/ con el scaffolding transversal al stack. Equivalente a keel-spring y keel-nest: el mismo diseño produce servidores con el mismo contrato observable.
