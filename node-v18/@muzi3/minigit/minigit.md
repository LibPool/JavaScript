# @muzi3/minigit

> 标签: checkpoint, git, pi, pi-extension, pi-package, rollback, version-control, worktree

## 简介

pi 专属扩展：为无 git 项目临时提供 git 版本控制（temp-init），为有 git 项目提供隔离 worktree 版本控制（worktree），每 turn 自动 commit，finish 弹窗收尾。

- npm 页面：https://www.npmjs.com/package/@muzi3/minigit
