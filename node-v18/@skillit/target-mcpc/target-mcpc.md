# @skillit/target-mcpc

> 标签: agent-skills, ai, mcp, mcpc, model-context-protocol, skillit

## 简介

mcpc CLI-as-proxy invocation-target adapter for @skillit/mcp — emits shell-command skills consumable by any agent with a shell tool, via Apify's mcpc CLI
