# @sejatordev/ws-client

> 标签: JavaScript

## 简介

WebSocket client ringan dengan konsep **channel-based** (mirip Pusher), mendukung **auto reconnect**, **manual reconnect**, **heartbeat**, dan **pong timeout**.
