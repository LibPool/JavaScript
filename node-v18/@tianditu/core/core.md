# @tianditu/core

> 标签: core, framework-agnostic, gis, headless, lbs, map, overlay, sdk-loader, tianditu, typescript

## 简介

Headless core for tianditu — idempotent SDK loader, map session, and lifecycle orchestration shared by every framework adapter, with a component definition layer for Vue, React, and Web Components
