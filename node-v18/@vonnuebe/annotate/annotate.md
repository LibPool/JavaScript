# @vonnuebe/annotate

> 标签: JavaScript

## 简介

Click-to-annotate live-preview tooling for harness-scaffolded React apps: compile-time JSX source stamping + a dev-only overlay that turns a click into a source-targeted (file:line) instruction for the coding agent.
