# @curless/agentbank-merchant-sdk

> 标签: agent, agentbank, curless, merchant, payments, webhook, x402

## 简介

Merchant-side SDK for agentbank — accept agent payments: open a merchant-quoted card (ACP / UCP) or stablecoin (x402: USDC on EVM / RLUSD on the XRP Ledger) checkout you price, list/summarize orders, PaymentIntents, edge-safe webhook verification, and x40
