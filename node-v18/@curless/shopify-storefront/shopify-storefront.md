# @curless/shopify-storefront

> 标签: agent-commerce, agentbank, curless, mcp, model-context-protocol, shopify, storefront

## 简介

One Shopify storefront MCP connector, driven by a config file. Identity, tool names, vocabulary and shop wiring come from a StorefrontConfig, so a second merchant is a JSON file rather than a fork of 3,400 lines.
