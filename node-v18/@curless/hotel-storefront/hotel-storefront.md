# @curless/hotel-storefront

> 标签: agent-commerce, booking, curless, hotel, mcp, model-context-protocol, travel

## 简介

One hotel-booking MCP connector, driven by a config file. Brand, tool names, vocabulary and where the rooms come from live in a HotelConfig, so the second hotel group is a JSON file rather than a fork.
