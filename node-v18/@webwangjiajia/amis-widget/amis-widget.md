# @webwangjiajia/amis-widget

> 标签: JavaScript

## 简介

> 开发amis自定义组件的工具集（支持react、vue2.0和jQuery技术栈） - 提供注册amis组件和amis-editor插件的方法； - 目前支持的技术栈：jQuery、vue2、react，vue3.0技术栈在vue3-amis-widget中支持； - 支持的amis渲染器类型：renderer（amis普通渲染器）、formitem（amis表单渲染器）、options（amis表单控件渲染器）。
