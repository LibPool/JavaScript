# @orkestrel/queue

> 标签: async, concurrency, fifo, job-queue, queue, retry, typescript

## 简介

A typed, persistent-capable FIFO job queue — bounded concurrency, retries, per-attempt timeout/abort, and an optional durable store for resuming outstanding work after a restart. Part of the @orkestrel line.
