# @orkestrel/contract

> 标签: contract, json-schema, parsers, type-guards, typescript, validation, zero-dependency

## 简介

Zero-dependency contract toolkit — type guards, combinators, parsers, and a shape DSL that compiles one contract shape into schema, is, parse, audit, explain, and generate. The foundation package of the @orkestrel line.
