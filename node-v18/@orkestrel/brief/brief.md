# @orkestrel/brief

> 标签: agent, brief, contract, deterministic, orkestrel, prompt, specification, typescript

## 简介

A synchronous, deterministic specification compiler: a rough request becomes a closed, content-hashed execution contract another agent can run, gated by a traceable reasoner and projected into every downstream artifact.
