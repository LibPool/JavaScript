# @agentproto/redaction

> 标签: agentic, agentproto, egress, open-standard, pii, privacy, redaction

## 简介

agentproto/redaction — vendor-neutral Redactor port + built-in redactors (none, deny-list, truncate, chain) and a catalog/resolver so any egress boundary can scrub outbound payloads before they leave the process.
