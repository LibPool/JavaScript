# @agentproto/processor

> 标签: agentic, agentproto, aip-51, egress, open-standard, pii, privacy, processor, redaction

## 简介

@agentproto/processor - AIP-51 vendor-neutral Processor/Redactor port + built-in redactors (none, deny-list, truncate, chain) and a catalog/resolver so any egress boundary can scrub outbound payloads before they leave the process.
