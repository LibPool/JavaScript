# @agentproto/driver-sdk

> 标签: agentproto, aip-33, in-process, provider, sdk

## 简介

agentproto/sdk-runtime — AIP-33 SDK provider specialisation. Sugar over @agentproto/driver for in-process npm/pip/cargo packages: module loading, function ref resolution, args templating.
