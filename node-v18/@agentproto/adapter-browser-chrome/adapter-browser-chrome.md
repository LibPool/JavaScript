# @agentproto/adapter-browser-chrome

> 标签: agentproto, browser, cdp, chrome, provider

## 简介

System Chrome providers for agentproto: `chrome` launches the installed Chrome on a fresh dedicated profile dir, attaches over CDP and injects granted cookies (never the default profile); `chrome-live` launches (or reuses, hot) a dedicated headful Chrome
