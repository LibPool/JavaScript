# @agentproto/identity

> 标签: agentic, agentproto, aip-23, defineIdentity, identity, open-standard

## 简介

@agentproto/identity — AIP-23 IDENTITY.md reference implementation. A workspace AIP that defines layered, composable agent identity — typed layers as AIP-18 collections, confidence-scored items, optional temporal entries, and compression-artifact tiers —
