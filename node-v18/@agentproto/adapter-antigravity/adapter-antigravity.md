# @agentproto/adapter-antigravity

> 标签: adapter, agent-cli, agentproto, agy, aip-45, antigravity, google, print

## 简介

@agentproto/adapter-antigravity — AIP-45 AGENT-CLI adapter for Google Antigravity's headless CLI (`agy`). Spawns `agy -p --output-format stream-json`; Antigravity has no ACP mode yet (feature request google-antigravity/antigravity-cli#31).
