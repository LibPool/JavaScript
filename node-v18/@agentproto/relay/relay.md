# @agentproto/relay

> 标签: agentproto, daemon, inbound, relay, webhook

## 简介

@agentproto/relay — a standalone companion service that lets one external HTTP webhook wake up exactly one pre-configured agentproto session. Generic inbound-only primitive: fixed target session baked into startup config, mandatory bearer token, basic rat
