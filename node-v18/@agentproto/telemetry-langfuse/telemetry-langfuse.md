# @agentproto/telemetry-langfuse

> 标签: agentic, agentproto, eval, langfuse, observability, open-standard, telemetry

## 简介

Langfuse ingestion REST API sink for @agentproto/telemetry. Dependency-free: maps EvalEvent batches to Langfuse trace-create and score-create objects over fetch.
