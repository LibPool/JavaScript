# @agentproto/workflow-runtime

> 标签: agentic, agentproto, aip-15, open-standard, orchestration, runtime, step-walker, workflow

## 简介

Reference step-walker for AIP-15 WORKFLOW composition: executes a typed step graph (tool / map / branch / loop / transform) over @agentproto/driver runTool, threading each step's output into a run-scoped binding bag (the AIP-16 IO seam, expressed as typed
