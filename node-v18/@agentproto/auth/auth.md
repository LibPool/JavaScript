# @agentproto/auth

> 标签: agentic, agentproto, aip-50, auth, defineAuthProvider, open-standard

## 简介

@agentproto/auth — AIP-50 AUTH.md reference implementation. Auth-provider doctype: how CLI tools and agents authenticate to API servers via a standardized discovery chain and pluggable flow engines, aligned to the WorkOS auth.md open standard.
