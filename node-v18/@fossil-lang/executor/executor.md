# @fossil-lang/executor

> 标签: JavaScript

## 简介

JS/TS wrapper around the fossil-df-wasm wasm-bindgen artifacts (--target web). The DataFusion executor that runs fossil mappings in the browser — lazy-loaded, separate from the LSP @fossil-lang/wasm.
