# @fossil-lang/corpus

> 标签: JavaScript

## 简介

Open a fossil corpus and read it. `open` is the door: it runs the fossil-graph verb surface as verb→SQL in WASM (fossil-graph-wasm) and delegates execution to a host-provided DuckDB-WASM query callback (e.g. keasy's Mosaic coordinator) — the larger-than-R
