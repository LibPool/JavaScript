# @fossil-lang/graph

> 标签: JavaScript

## 简介

In-process TS binding for the fossil-graph verb surface. Runs verb→SQL in WASM (fossil-graph-wasm) and delegates execution to a host-provided DuckDB-WASM query callback (e.g. keasy's Mosaic coordinator). The larger-than-RAM query layer for @fossil-lang/vi
