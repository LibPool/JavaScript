# dsh-tool-mining

> 标签: analytics, bus-factor, contributors, deepseek-harness, dsh-plugin, github, metrics, mining, repository, velocity, 仓库分析

## 简介

Repository mining for DeepSeek Harness: contributor spread, median pull-request merge time with a weekly trend, bus factor with single-author files, and issue backlog age. Uses the GitHub REST API.
