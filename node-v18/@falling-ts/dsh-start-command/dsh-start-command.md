# @falling-ts/dsh-start-command

> 标签: agent, client, cordis, dsh, pre-step, settings, shell, start-command

## 简介

DSH Cordis plugin: runs one configured shell command in the session's working directory before the first model request of a turn, but only when the user submits a prompt while no other agent is running. The Host half awaits the command through the mounted
