# @boomin/components

> 标签: admin, boomin, components, console, embed, payments, stripe-connect

## 简介

Components by Boomin — runtime-delivered UI you mount inside your own product. `@boomin/components/console` is the org-admin Brand Settings console (Payments, Stripe, members, API keys).
