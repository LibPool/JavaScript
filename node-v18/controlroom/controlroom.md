# controlroom

> 标签: cli, fullscreen, ink, keyboard, layout, non-tty, panes, screen, tabs, terminal, tui, zero-dependency

## 简介

Keyboard-driven terminal screens, inline or full-screen, with a static projection for pipes, CI and --json. No dependency outside the burgee family; react and react-reconciler are optional peers, loaded only by controlroom/ink. Drop-in path for ink.
