# @myrialabs/chatkit

> 标签: baileys, bot, bun, chat, conversation, discord, gateway, messaging, slack, telegram, typescript, unified-api, webhook, whatsapp

## 简介

One unified, typed API to receive and send messages across Telegram, WhatsApp (Baileys & Cloud API), Discord and Slack — a universal message envelope, capability descriptors and a built-in WhatsApp safety layer, for Node and Bun.
