# @zd~/iconfont-cli

> 标签: cli, iconfont, iconfont-cli, mini-program, react, tarojs, uni-app, vue

## 简介

一个基于 Iconfont 自动生成 React/Vue 组件的 CLI 工具，免除字体依赖，提供多种实现方式，支持 TaroJS 和 UniApp。
