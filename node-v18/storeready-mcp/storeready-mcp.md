# storeready-mcp

> 标签: app-builders, app-store, expo, ios, mcp, modelcontextprotocol, storeready

## 简介

StoreReady MCP server from Compound Labs. Reports whether the app each AI mobile-app builder produces can pass Apple App Store review, with sources. No key and no signup.
