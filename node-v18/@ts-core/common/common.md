# @ts-core/common

> 标签: command, crypto, dto, event, filter, logger, observable, pagination, reactive, rxjs, transport, typescript, utils, validation

## 简介

Foundation TypeScript library for backend and frontend applications: reactive collections, filterable DTOs, command/event transport, logging, validation and cryptography
