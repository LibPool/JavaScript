# @pagamericantech/data-mcp

> 标签: analytics, mcp, model-context-protocol, pagamerican

## 简介

MCP server exposing PagAmerican sales data (purchases, orders, refunds, checkouts, products, offers) as tools for Claude Desktop, Claude Code, Cursor and other MCP clients. Authenticates with a PagAmerican API key.
