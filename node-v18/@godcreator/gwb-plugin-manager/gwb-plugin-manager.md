# @godcreator/gwb-plugin-manager

> 标签: gwb-plugin

## 简介

插件管理：安装、卸载、升级 home 里的插件与内核，增删启停 cordis.yml 条目，包改名后把旧包名的设置与数据改归新包名，在配好的 npm 源上搜索插件
