# @godcreator/gwb-mcp

> 标签: gwb-plugin

## 简介

MCP 入口：工具只有 index / search / run 三个，无状态 streamableHTTP、凭据由每个 home 独立保管，default 固定用 2870 端口。支持不回显的临时凭据签发、到期检查与撤销，客户端接线写在随包的 onboard skill 里；自带零依赖命令行客户端，--home 读取对应入口与凭据。服务无；skill 2 份；命令 6 条。
