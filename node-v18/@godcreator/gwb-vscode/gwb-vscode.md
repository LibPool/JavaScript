# @godcreator/gwb-vscode

> 标签: gwb-plugin

## 简介

VS Code 桥：经配套的 VS Code 扩展，在开着的 VS Code 窗口里执行任意 VS Code 命令、列出命令 ID、在内置浏览器里打开网页；另直接读写 .code-workspace 文件的文件夹列表。命令 7 条；skill 1 份。
