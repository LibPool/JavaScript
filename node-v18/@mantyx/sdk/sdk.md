# @mantyx/sdk

> 标签: agent, agentic, ai, llm, mantyx, sdk, tool-use

## 简介

MANTYX as a hosted agent runtime: define ephemeral agents, mix server-side MANTYX tools with locally-executed tools, run them remotely.
