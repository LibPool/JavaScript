# @codejoo/axp

> 标签: abort, adapter, auth, axios, axios-plugin, axios-plugins, cache, cancel, dedupe, http, http-client, interceptor, loading, mock, openapi, plugin, request-dedup, retry, share, token-refresh, type-safe, typescript

## 简介

Typed, plugin-based HTTP client built on axios — cache, retry, request dedup/share, auth token-refresh, cancel, loading, mock, path-var substitution, and more, with end-to-end OpenAPI type inference.
