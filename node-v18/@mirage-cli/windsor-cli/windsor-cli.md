# @mirage-cli/windsor-cli

> 标签: cli, facebook-ads, ga4, google-ads, marketing-data, mirage, windsor, windsor.ai

## 简介

Windsor.ai CLI: explore connectors, accounts and fields, and query or download rows from any of Windsor's 350+ connectors with SQL-like filters. Read-only. Mirage / Cloudflare-Worker compatible.
