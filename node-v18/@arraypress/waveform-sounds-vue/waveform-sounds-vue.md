# @arraypress/waveform-sounds-vue

> 标签: audio, filter, player, presets, preview, sample-pack, samples, search, sound-browser, vue, vue-component, vue3, waveform

## 简介

Vue 3 component wrapper for @arraypress/waveform-sounds — a searchable, filterable sound list with typed props for every option, lifecycle emits, an exposed imperative API, and server-rendered markup the runtime adopts.
