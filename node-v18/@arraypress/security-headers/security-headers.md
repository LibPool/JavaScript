# @arraypress/security-headers

> 标签: _headers, clickjacking, cloudflare-pages, content-security-policy, csp, csp-hash, headers, hsts, netlify, security, static-site

## 简介

Security response headers for static hosts — CSP, HSTS, X-Frame-Options, Referrer-Policy, Permissions-Policy. Generates a Cloudflare/Netlify _headers file, with a strict, hash-based CSP derived from the finished build. Zero dependencies, no framework.
