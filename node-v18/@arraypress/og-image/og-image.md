# @arraypress/og-image

> 标签: astro, build-time, og-image, open-graph, resvg, satori, social-card

## 简介

Build-time Open Graph image renderer. One Satori + resvg template — eyebrow, title, subtitle, keyword chips, optional artwork tile, wordmark footer — brand-configurable, framework-agnostic, with Inter bundled so it renders with no setup.
