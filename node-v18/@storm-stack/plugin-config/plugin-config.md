# @storm-stack/plugin-config

> 标签: storm-software, storm-stack, storm-stack-plugin

## 简介

A package containing a Storm Stack plugin for injecting static .env configuration values to the code so that they're accessible at runtime.

- 源码仓库：git+https://github.com/storm-software/storm-stack.git
