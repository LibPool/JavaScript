# homebridge-nanoleaf-scene-bridge

> 标签: effects, homebridge, homebridge-plugin, homekit, matter, nanoleaf, scenes, wifi

## 简介

Exposes the scenes of Wi-Fi Nanoleaf devices to HomeKit as switches that track the active scene, ready to be used in Home app scenes.
