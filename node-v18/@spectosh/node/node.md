# @spectosh/node

> 标签: opentelemetry, otlp, session-replay, specto, tracing

## 简介

Backend spans for Specto session replay — continues the browser's trace on your Node server and exports it over OTLP/HTTP. No dependencies.

## 官网

- 官网：https://specto.sh/docs/traces
- 源码仓库：git+https://github.com/evigasoft/specto.sh.git
- npm 页面：https://www.npmjs.com/package/@spectosh/node
