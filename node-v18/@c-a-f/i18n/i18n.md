# @c-a-f/i18n

> 标签: caf, clean-architecture, clean-architecture-frontend, i18n, i18next, internationalization, next-intl, ngx-translate, react-intl, translation, vue-i18n

## 简介

Framework-agnostic internationalization interfaces and adapters for CAF. Works with i18next, vue-i18n, ngx-translate, react-intl, next-intl, or any i18n library.
