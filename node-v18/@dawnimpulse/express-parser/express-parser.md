# @dawnimpulse/express-parser

> 标签: body-parser, express-json, express-json-parse, express-nested-json, express-parse, express-parser, json-parse, url-encoded-json, urlencoded-json

## 简介

This is an expressjs middleware which is used in conjuction with body-parser & used to parse the nested json in urlencoded body params.
