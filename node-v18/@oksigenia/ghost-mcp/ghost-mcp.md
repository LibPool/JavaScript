# @oksigenia/ghost-mcp

> 标签: admin-api, ai, ghost, markdown, mcp, model-context-protocol, xpresiva

## 简介

Model Context Protocol server for Ghost, aware of the Xpresiva theme. Operate your Ghost content by talking to an AI — locally, no telemetry. Wraps the ghost-md-publisher toolkit.
