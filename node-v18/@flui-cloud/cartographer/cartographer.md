# @flui-cloud/cartographer

> 标签: framework-detection, repository-detection, static-analysis

## 简介

Reads a repository and reports what it actually says about itself: language, deployable units, how each is built and reached, and the services it declares. Every fact cites its file; what it cannot find, it says so.
