# @process-cart/mcp

> 标签: checklist, mcp, model-context-protocol, process-cart, processcart, workflow

## 简介

Model Context Protocol server for Process Cart: lets Claude, Cursor and other MCP clients find workflows, start runs, set fields, complete tasks and read activity with your API key.
