# @stryker-mutator/jasmine-runner

> 标签: @stryker-mutator/test-runner-plugin, jasmine, stryker

## 简介

A plugin to use the Jasmine (NodeJS) test runner in Stryker, the mutation testing framework for JavaScript and friends
