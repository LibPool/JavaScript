# @erikhuang/coderecall

> 标签: agent, ai, claude, claude-code, compaction, context, cursor, llm, mcp, memory, zero-dependency

## 简介

Zero-dependency decision-persistence layer for AI coding agents — your decision log (why + dead-ends), kept across context compaction. No vector DB, no API keys, no cloud.
