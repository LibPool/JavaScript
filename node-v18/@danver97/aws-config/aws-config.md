# @danver97/aws-config

> 标签: JavaScript

## 简介

This module provides a easy management of the AWS infrastructure by the microservices. The module is composed of five submodules: - `dynamodb` - `iam` (deprecated) - `lambda` (deprecated) - `sns` - `sqs`
