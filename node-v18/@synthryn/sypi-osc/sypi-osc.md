# @synthryn/sypi-osc

> 标签: extension, osc, sypi

## 简介

Add terminal hyperlinks, shell marks, and taskbar progress when the terminal supports OSC. Use it when terminal navigation and long-running progress benefit from native escape-sequence affordances. Primary capability: automatic terminal OSC integration; u
