# @abeyjs/view

> 标签: JavaScript

## 简介

AbeyJs **view layer**: native **DOM** bindings, routed **shells**, **`@AbeyComponent`** web components wired to **`OmegaRuntime`**, data-driven **list/form** mounting (form controls live in **`@abeyjs/uikit`**), declarative hero pages, **lazy** route fact
