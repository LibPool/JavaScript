# @abeyjs/flows

> 标签: JavaScript

## 简介

Long-lived **orchestration** for AbeyJs: flows sit on the same `OmegaChannel` as everything else, but they own **state machines**, **intent reactions**, and **UI hints** that never needed to be raw bus traffic.
