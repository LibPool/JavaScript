# @num-kit/core

> 标签: currency, format, formatting, i18n, intl, money, number, parse, round, typescript

## 简介

Lightweight, framework-agnostic TypeScript toolkit for number formatting, parsing, currency conversion, rounding, and human-readable output, with injectable i18n providers. Zero dependencies.
