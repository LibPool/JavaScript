# @bascik/bascik

> 标签: bascik, build tool, html components, no framework, scoped css, scoped javascript, ssg, static site generator, templating, vanilla html, web components, zero runtime

## 简介

Bascik is a build tool for HTML components with automatically scoped CSS and JS. Zero runtime.
