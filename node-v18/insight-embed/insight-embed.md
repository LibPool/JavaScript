# insight-embed

> 标签: analytics, angular, charts, dashboard, embed, embedding, insight, react, svelte, vue

## 简介

Embed Insight dashboards in any web app (React, Angular, Vue, Svelte, plain JS) without an iframe, with signed embed tokens.
