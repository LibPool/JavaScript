# @vextlabs/stoa-mcp

> 标签: ai-safety, gate, guardrails, mcp, model-context-protocol, open-source, receipt, stoa, vext-labs

## 简介

MCP server for STOA. Gives any MCP client (Claude Desktop, IDEs, agents) the tools to prove-or-permit an AI action before it commits and verify its receipt — against the open STOA API. From Vext Labs.
