# @plannotator/agent-bridge

> 标签: agent, artifact-server, bridge, mcp, plannotator

## 简介

Host-agnostic bridge client for the Plannotator agent dispatch protocol: registration, claim loop, bundle rendering and sanitization, comment operations, and the activity beacon.
