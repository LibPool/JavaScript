# depheal

> 标签: audit, dependencies, fix, npm, osv, security, supply-chain, vulnerabilities

## 简介

Finds vulnerable, malicious, risky and unused dependencies, fixes them, and keeps a fix only if your tests and build still pass. Works with npm, yarn, pnpm, bun, Python, Go, Rust, Ruby, PHP, Dart, Elixir, .NET, Maven, Gradle, Swift, Perl, Conan, vcpkg, R
