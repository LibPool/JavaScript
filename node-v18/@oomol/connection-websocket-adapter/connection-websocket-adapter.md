# @oomol/connection-websocket-adapter

> 标签: JavaScript

## 简介

使用 websocket 实现 @oomol-connection 连接，让浏览器（`websocket-adapter/client`）和 nodejs 环境（`websocket-adapter/server`）下可以互相通信。
