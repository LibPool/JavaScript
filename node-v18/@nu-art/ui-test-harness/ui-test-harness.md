# @nu-art/ui-test-harness

> 标签: TacB0sS, devtools, fiber, infra, nu-art, react, render-audit, testing, thunderstorm, typescript

## 简介

Fiber-driven React render-audit engine — installs the React DevTools global hook, walks the committed fiber tree, and runs generic layout invariants and per-component contracts. Zero React dependency in the shipped artifact.
