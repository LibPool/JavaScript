# @caesarloo/dsh-deepseek-account-vision

> 标签: deepseek, deepseek-account, deepseek-flash, deepseek-harness, dsh, dsh-plugin, image, image-understanding, multimodal, ocr, plugin, vision

## 简介

Give any main model DeepSeek-account vision in DeepSeek Harness: recognize images with DeepSeek-V4.1-Flash (deepseek-flash, 1017) through a deepseek_vision tool, and auto-transcribe attached images for any provider route. No API key.
