# @agfpd/iapeer

> 标签: ai-agents, background-agents, claude-code, codex, codex-cli, launchd, macos, mcp, multi-agent, peer-to-peer, shared-memory, telegram

## 简介

Run Claude Code and Codex CLI as local background agents that message each other, wake on demand, and share one memory.
