# @bravo68web/dev-utils

> 标签: JavaScript

## 简介

Dev Utils is a local toolbox for the request, document, or diagram in front of you. It runs as one Node process on your machine. There are no accounts and no server database. Your drafts, documents, and captured requests stay in this browser.
