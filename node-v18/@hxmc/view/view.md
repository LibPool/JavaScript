# @hxmc/view

> 标签: JavaScript

## 简介

Signals and JSX-like markup for Haxe on every target: fine-grained reactivity (signals, memos, effects, ownership, contexts, control flow), markup literals compiled to direct calls on a renderer chosen at compile time, no virtual DOM
