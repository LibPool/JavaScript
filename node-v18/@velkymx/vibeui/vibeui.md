# @velkymx/vibeui

> 标签: bootstrap, bootstrap5, component-library, typescript, ui-components, vibeui, vue, vue3

## 简介

A lightweight Vue 3 component library for Bootstrap 5.3 with dual-mode support (shorthand props and composable slots)
