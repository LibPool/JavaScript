# @motion-mcp/generation-engine

> 标签: JavaScript

## 简介

Generation engine: deterministic natural-language motion intent parsing and temperament-driven procedural clip synthesis (overshoot, squash/stretch, secondary motion) into schema-valid SceneDocs.
