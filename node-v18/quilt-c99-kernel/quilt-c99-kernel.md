# quilt-c99-kernel

> 标签: c99, cellular, provenance, quilt, receipts, reproducibility, verifiable

## 简介

The Quilt cell-fabric runtime in C99 — BIND/LINK/EFFECT/VIEW/TICK — with a one-command verifier that runs 1,285 assertions and emits a sha256 receipt.
