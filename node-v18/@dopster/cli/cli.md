# @dopster/cli

> 标签: JavaScript

## 简介

A **Dopster CLI** foi criada para **acelerar o início de novos projetos** e garantir que **todos os repositórios da empresa sigam os mesmos padrões** de arquitetura, configuração e qualidade de código (linting e formatting).
