# verdaccio-plugin-delay-filter

> 标签: security,verdaccio,plugin,filter,verdaccio-plugin,node

## 简介

Plugin for filtering packages in verdaccio, returning only the versions that were published N days ago. It reduces risk of being infected with 0-day or 1-day attacks with package updates which are not vetted by community.
