# videorouter-live

> 标签: decart, happy-oyster, live-video, odyssey, real-time, sdk, video, videorouter, world-model

## 简介

JavaScript/TypeScript SDK for videorouter.sh: live video & world models (open, keep alive, settle a real-time session), model wrappers for Happy Oyster / Decart Lucy / Odyssey, and the /v1/videos generation API. Node 18+ and browsers, zero dependencies.

- 官网：https://videorouter.sh/docs/live-video
- npm 页面：https://www.npmjs.com/package/videorouter-live
