# verdix-mcp

> 标签: address, agents, base, mcp, model-context-protocol, risk, scam, security, usdc, wallet, x402

## 简介

MCP server for Verdix: check an EVM address on Base before sending it funds (safe/caution/danger). Pays per call via x402 from your own wallet, with a max-price cap.

## 官网

- 官网：https://api.verdixapi.com
- 源码仓库：git+https://github.com/verdixapi/verdix-mcp.git
