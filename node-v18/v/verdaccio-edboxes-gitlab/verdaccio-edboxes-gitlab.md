# verdaccio-edboxes-gitlab

> 标签: JavaScript

## 简介

`verdaccio-edboxes-gitlab` is the [Verdaccio] authentication plugin that powers the auth scheme for Edboxes's NPM registry, where purchasing clients can access [TaskBotJS] Pro and Enterprise. Users log in by passing, as their NPM password, a GitLab Person
