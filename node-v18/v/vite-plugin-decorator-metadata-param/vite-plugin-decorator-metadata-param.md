# vite-plugin-decorator-metadata-param

> 标签: decorator, esbuild, metadata, plugin, reflect-metadata, typescript, vite

## 简介

A Vite plugin that automatically injects TypeScript decorator metadata to solve esbuild's lack of emitDecoratorMetadata support
