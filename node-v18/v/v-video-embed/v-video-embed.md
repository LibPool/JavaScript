# v-video-embed

> 标签: vue coub embed, vue dailymotion embed, vue embed, vue video embed, vue vimeo embed, vue youku embed, vue youtube embed

## 简介

This is a component for Vue.js to utilize YouTube, Vimeo, DailyMotion, Coub iframe embed API easily.
