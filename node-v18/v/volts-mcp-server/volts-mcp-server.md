# volts-mcp-server

> 标签: ai, asset-generation, game-dev, godot, mcp, model-context-protocol, pixel-art, sprites, spritesheets, tilesets, volts

## 简介

Generate game assets from your IDE — sprites, tilesets, characters, audio, lore, full Godot MVPs. MCP server for Claude Code, Cursor, Antigravity, and any MCP client.
