# v-resize-demo

> 标签: JavaScript

## 简介

1、先编写插件，在src目录里     index.ts 2、编写完成后，配置一下vite.config.ts里的输入输出配置     vite.config.ts 3、配置package.json里build 4、npm run build进行打包，打包后显示dist目录
