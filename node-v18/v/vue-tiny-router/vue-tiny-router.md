# vue-tiny-router

> 标签: bundle-size, component, history-api, lightweight, minimal, navigation, router, routing, single-page-app, spa, tiny, vue, vue3

## 简介

A lightweight Vue 3 router (~2.2 kB Brotli) with params, query, guards, nested layouts, lazy loading, and redirects
