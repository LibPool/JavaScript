# vue-oop

> 标签: collections, commonjs, container, es6, graphql, ioc, loader, model, oop, repository, rest, umd, universal, vue, webpack

## 简介

A library based on Model-Repository patterns for Vue components. Usable for GraphQL and REST APIs.
