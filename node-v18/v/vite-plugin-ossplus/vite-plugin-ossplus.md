# vite-plugin-ossplus

> 标签: alioss, cos, vite, vite plugin

## 简介

vite OSS上传插件, 可在 vite 打包结束后将来 vite 生成的文件自动上传到 OSS 中，目前支持阿里云、腾讯云、七牛云服务提供商
