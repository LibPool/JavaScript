# version-check-js

> 标签: checker, etag, version, version-check, version-checker, 前端更新, 版本检测, 自动轮询

## 简介

version-check-js极简配置的前端版本检测工具，自动判断ETag/版本文件模式，默认自动轮询，保留手动检测 。原生javascript实现。不局限于框架使用
