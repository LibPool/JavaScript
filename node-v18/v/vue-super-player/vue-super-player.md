# vue-super-player

> 标签: aliplayer, flv, hls, http-flv, live, m3u8, mpegts, multi-kernel, player, video-player, vue, vue3

## 简介

多内核视频播放器组件（Vue 3 + TS）：原生 / hls.js / mpegts.js / Aliplayer 可插拔，自动检测播放格式
