> 标签: async resource, composition api, computed, effect scope, fine-grained reactivity, lazy computed, reactive engine, reactivity, signal, signal adapter, signals, state management, typescript, vue, vue composable, vue3

## 简介

Lightweight signal-based reactive engine adapter for Vue 3. Lazy computed, scoped effects and async resources powered by intentx-core-z.
