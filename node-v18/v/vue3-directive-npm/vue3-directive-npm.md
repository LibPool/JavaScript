# vue3-directive-npm

> 标签: JavaScript

## 简介

vue3常用自定义指令 + v-copy 复制文本 + v-click-outside 点击外部区域关闭当前元素 + v-scroll-to 滚动到指定位置或元素 + v-table-scroll 表格拖动（只支持ant-design-vue表格） + v-waterMark 图片添加水印 + v-debounce 输入框防抖
