# vue-nice-dates

> 标签: calendar, date-picker, datepicker, vue

## 简介

A responsive, touch-friendly, and modular date picker library for Vue. This is a Vue version of [react-nice-dates](https://www.npmjs.com/package/react-nice-dates).
