# videojs-ima-player

> 标签: videojs, videojs-ads, videojs-plugin

## 简介

[IMA SDK](https://developers.google.com/interactive-media-ads/docs/sdks/html5/v3/apis) integration for video.js. Based on customized videojs player, tech and UI tailored for ad playback.
