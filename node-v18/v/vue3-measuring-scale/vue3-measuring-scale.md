# vue3-measuring-scale

> 标签: JavaScript

## 简介

`vue3-measuring-scale` 是一款为 **Vue 3** 开发的高性能、高定制性、交互优雅的 **Canvas 刻度尺（标尺选择器）组件库**。它专为移动端及大屏可视化表单场景设计，可用于身高、体重、温度、年龄等任何连续或离散数值的直观滑动选择。
