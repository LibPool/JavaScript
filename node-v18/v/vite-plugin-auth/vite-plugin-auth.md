# vite-plugin-auth

> 标签: access-control, auth, authentication, basic-auth, dev-server, login, password, security, vite, vite-plugin

## 简介

Password-based authentication plugin for Vite. Protects dev servers, preview deployments, and internal tools with a login form, session persistence, and IP allowlisting.
