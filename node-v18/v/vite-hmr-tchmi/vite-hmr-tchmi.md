# vite-hmr-tchmi

> 标签: beckhoff, hmr, tchmi, twincat, vite

## 简介

A utility library to enable Hot Module Replacement (HMR) for Beckhoff TwinCAT HMI (TcHmi) Framework Controls when using Vite.
