# vuepress-plugin-flexsearch-td

> 标签: search, vuepress, vuepress-plugin, vuepress-plugin-flexsearch-td, vuepress-search

## 简介

本项目在[vuepress-plugin-flexsearch-pro](https://github.com/QYueWang/vuepress-plugin-flexsearch-pro)的基础上进行修改。可以替换vuepress自带的搜索控件，支持单个vuepress站点的国际化搜索（针对不同语言进行全文搜索）。
