# vite-variant-group

> 标签: grouping, plugin, scss, summary, tailwind, variant-group, vite, vue

## 简介

Utility to use Windi CSS / UnoCSS style variant groups in Vite projects with Tailwind CSS. Supports Vue, HTML, and SCSS (including @apply).
