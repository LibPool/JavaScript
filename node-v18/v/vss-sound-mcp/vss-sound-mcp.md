# vss-sound-mcp

> 标签: claude, elevenlabs, game-audio, mcp, model-context-protocol, sfx, sound-effects, vfx

## 简介

MCP server for VFX Sound Studio (vss.ai.kr) — generate layered game sound effects and monster voices from text, straight into your project folder.

## 官网

- 官网：https://vss.ai.kr
- npm 页面：https://www.npmjs.com/package/vss-sound-mcp
