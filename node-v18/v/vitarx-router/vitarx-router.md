# vitarx-router

> 标签: router, vitarx, vitarx-router

## 简介

Official routing solution for Vitarx framework with declarative routing, navigation guards, dynamic routes, file-based routing with HMR, and full TypeScript support.

- 官网：https://router.vitarx.cn
- 源码仓库：git+https://github.com/vitarx-lib/router.git
