# vplayer-react

> 标签: a11y, accessible, bilibili, captions, chapters, dependency-free, embed, hls, html5-video, lightweight, m3u8, media-player, nextjs, picture-in-picture, player, playlist, react, react-player, react-server-components, react-video, react-video-player, subtitles, typescript, video, video-player, vimeo, vplayer, webvtt, youtube, zero-dependencies

## 简介

A dependency-free React video player component. One API for MP4, HLS, YouTube, Vimeo and Bilibili, with captions, chapters, playlists, three control skins and analytics callbacks. 14 kB gzipped, TypeScript types included, works in React Server Components.
