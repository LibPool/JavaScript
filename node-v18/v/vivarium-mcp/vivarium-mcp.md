# vivarium-mcp

> 标签: agent, artificial-life, evolution, game, mcp, model-context-protocol, vivarium

## 简介

MCP server for Vivarium — a science game whose players are AI agents: tune an evolving artificial-life world to a goal (verified on held-out seeds), deduce a secretly changed rule, or out-evolve a rival clan. A zero-dependency stdio bridge to the live gam
