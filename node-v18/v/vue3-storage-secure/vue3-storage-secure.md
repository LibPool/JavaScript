# vue3-storage-secure

> 标签: async storage, asynchronous storage, localstorage, promise, secure-ls, sessionstorage, storage, sync storage, synchronous storage, vue-ls, vue3, vue3-storage

## 简介

Vue3 plugin for work with local storage, session storage and websql from Vue context, inspired by tarojs, vue-ls and secure-ls.
