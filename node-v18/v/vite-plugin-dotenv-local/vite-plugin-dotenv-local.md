# vite-plugin-dotenv-local

> 标签: dotenv, dotenv-local, env, environment-variables, import.meta.env, vite, vite-plugin

## 简介

Vite plugin that plugs dotenv-local into Vite's config lifecycle, so env files are loaded identically in `vite dev` and `vite build`.

- 官网：https://github.com/yracnet/dotenv-local
- 源码仓库：git+https://github.com/yracnet/dotenv-local.git
- npm 页面：https://www.npmjs.com/package/vite-plugin-dotenv-local
