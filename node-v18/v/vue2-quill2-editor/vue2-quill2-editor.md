# vue2-quill2-editor

> 标签: editor, html-editor, quill, quill2, rich-text-editor, vue, vue2, wysiwyg

## 简介

A rich text editor component for Vue 2 based on Quill 2, supporting tables, image upload/resize, color picker and custom HTML blocks.
