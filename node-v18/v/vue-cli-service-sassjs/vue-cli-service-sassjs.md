# vue-cli-service-sassjs

> 标签: JavaScript

## 简介

vue sass 依赖node-sass ，但是这个包不好安装 ，所以只好修改 不依赖node-sass与sass-loader（替换为sass.js与sassjs-loader 但是需要安装 npm i sass.js sassjs-loader
