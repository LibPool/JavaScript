# vite-plugin-xq-cp-dep

> 标签: cp-dependencies-to-public, cp-src-assets-to-public, cp-to-public, vite, vite-cp, vite-plugin

## 简介

A vite plugin that copies all package.json 'dependencies' and project 'assets' into the public directory.一个将 package.json 的 dependencies 全部依赖包和项目 assets 自动复制到 public 目录的 Vite 插件。
