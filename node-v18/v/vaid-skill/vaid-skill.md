# vaid-skill

> 标签: agent-identity, agent-skill, claude-code, delegation, ed25519, synthera, vaid, verifiable-credentials

## 简介

Agent Skill for VAID (Verifiable Agent Identity): mint, present, verify and revoke agent credentials from Claude Code, Codex, Cursor, Gemini CLI and Copilot. A thin wrapper over the published vaid-mint SDK.
