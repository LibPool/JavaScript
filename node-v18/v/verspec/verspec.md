# verspec

> 标签: cli, compare-versions, prerelease, range, satisfies, semantic-version, semver, sort-versions, version, version-compare, version-range, zero-dependency

## 简介

Tiny, zero-dependency SemVer toolkit: parse, compare, sort, diff, increment, and test versions against ranges (^, ~, x-ranges, hyphen, ||) with correct prerelease precedence — plus a CLI. Node, Deno, Bun & browser.
