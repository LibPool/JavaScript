# vue-time-sliced-render

> 标签: composable, large-list, performance, render, time-slice, time-sliced, vue, vue3

## 简介

Vue 3 组合式函数:将大数据列表按帧分批追加渲染,避免一次性创建大量 DOM 导致卡顿
