# vue-csv-exporter

> 标签: browser, csv, csv-exporter, cyrillic, export, exporter, no-dependencies, russian, vue, vue-csv, vuejs

## 简介

Простой и надежный экспорт данных в CSV для Vue.js. Без зависимостей, с поддержкой кириллицы и TypeScript.
