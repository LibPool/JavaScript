# v-watermark-plugin

> 标签: JavaScript

## 简介

v-watermark-plugin 是一款实用的网页水印添加工具，配置选项丰富灵活，用户可按需自定义水印样式和布局。

## 官网

- npm 页面：https://www.npmjs.com/package/v-watermark-plugin
