# vue-time-axis-plus

> 标签: JavaScript

## 简介

基于 **Canvas 双层渲染**的 Vue 3 时间轴组件，专为**监控录像回放**场景设计：支持录像片段可视化、点击/拖动定位、播放指针跟随、跨空白续播、双进度条概览、移动端手势缩放。**零运行时依赖**、**CSS 已内联**、**组件与原生 class 双模式**。
