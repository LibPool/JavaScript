# vue-263-player

> 标签: JavaScript

## 简介

一个基于Alipayer和owt 开发并封装成vue组件的集成播放器.可播放,m3u8,mp4....视频.支持直播流与点播的基础功能外,视频的加密播放、清晰度切换、直播时移、连麦等业务场景
