# vite-breeze

> 标签: cli tool, context Api, project generator, react, react boilerplate, react cli, react router, react vite starter, state management, tailwindcss, vite, vite project generator, vite react boilerplate, vite template

## 简介

A simple CLI tool to quickly generate a React project using Vite, React Router, and a pre-configured context folder, with Tailwind CSS already set up.
