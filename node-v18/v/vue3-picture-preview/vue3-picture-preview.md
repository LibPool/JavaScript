# vue3-picture-preview

> 标签: image, preview, vue, vue3

## 简介

一个基于vue3的图片预览插件，可以缩放图片，移动图片，旋转图片，目前只支持pc端。

## 官网

- 官网：https://gitee.com/xiangxxx/vue3-picture-preview
- npm 页面：https://www.npmjs.com/package/vue3-picture-preview

## 历史版本号

- 当前版本：1.0.0

- 1.0.0

## 获取地址

- npm 安装：`npm install vue3-picture-preview`
- npm registry：https://registry.npmjs.org/vue3-picture-preview
