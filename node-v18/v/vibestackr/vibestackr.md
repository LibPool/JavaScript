# vibestackr

> 标签: JavaScript

## 简介

A Simple UI, Task Runner, and MCP server that brings up your local stack in dependency order, watches liveness, wires up keyboard shortcuts, and lets your agent see exactly what you can see. All driven by a single config file in your monorepo or meta-repo
