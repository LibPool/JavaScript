# vue-native-navigation

> 标签: router, vue, vue-app-navigation, vue-native, vue-native-navigation, vue-page, vue-page-stack, vue-router

## 简介

开发者先根据实际场景为每个路由设置页面深度，然后组件会在路由跳转时根据对应的页面深度判断是否缓存页面，以及如何展示过渡动画。
