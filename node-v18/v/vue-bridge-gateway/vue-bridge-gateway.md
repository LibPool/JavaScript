# vue-bridge-gateway

> 标签: Bridge, Bridge Gateway, Nuxt, Vue

## 简介

Vue-Bridge-Gateway is a wrapper of **WebviewJavascriptBridge** (`$bridge`) to make building Mini apps simple and easy.
