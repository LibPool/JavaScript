# variantkit

> 标签: ai, claude-code, cursor, design, dev-tools, dialkit, react, ui, variants

## 简介

The configuration panel for AI-built UI: your agent generates variants with a full contextual control panel, you tweak and finalize, the losers get pruned from the codebase. Built on DialKit.
