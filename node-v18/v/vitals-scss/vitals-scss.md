# vitals-scss

> 标签: css, flexbox, fluid, grid, grid-layout, layout, modern, sass, sass-library, scss, scss-library, semantic, vitals, vitals-grid

## 简介

A minimalistic bundle of a few CSS/Sass tools for building modern, flexible websites: an improved normalize, shorthand stuff for flexbox and grid, and a fluid sizing function.
