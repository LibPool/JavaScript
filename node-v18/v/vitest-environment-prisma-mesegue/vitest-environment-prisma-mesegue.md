# vitest-environment-prisma-mesegue

> 标签: e2e, mesegue, prisma, test

## 简介

Este pacote fornece um ambiente personalizado para testes com Vitest e Prisma. Cada execução cria um schema de banco de dados isolado, garantindo testes consistentes e sem interferências. Ideal para projetos que utilizam Prisma e precisam de um ambiente d
