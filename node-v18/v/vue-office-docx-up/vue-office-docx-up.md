# vue-office-docx-up

> 标签: docx, docx-preview, excel, excel-preview, pdf, pdf-preview, ppt, vue

## 简介

支持多种文件(**docx、excel、pdf、pptx**)预览的vue组件库，支持vue2/3。也支持非Vue框架的预览。
