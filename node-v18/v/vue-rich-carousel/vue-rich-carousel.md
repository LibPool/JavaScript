# vue-rich-carousel

> 标签: carousel, plugin, scroll, vue

## 简介

A plugin of carousel for Vue.js project,It provides multi-directional, multi-effects methods, including conventional carousels, seamless scrolling, fade-in and fade-out, and other common effects.
