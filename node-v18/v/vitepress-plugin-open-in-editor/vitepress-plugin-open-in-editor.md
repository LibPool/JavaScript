# vitepress-plugin-open-in-editor

> 标签: click-to-source, markdown-it, open-in-editor, remote-ssh, vite-plugin, vitepress, vscode

## 简介

Hover any paragraph, code block, table or list in a VitePress site and jump straight to the exact source line in your local editor. Works with VS Code Remote SSH and 20+ editors.
