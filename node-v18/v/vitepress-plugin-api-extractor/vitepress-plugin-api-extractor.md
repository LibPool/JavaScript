# vitepress-plugin-api-extractor

> 标签: api-extractor, documentation, plugin, twoslash, typescript, vitepress

## 简介

VitePress adapter for generating API documentation from TypeScript API Extractor models: markdown pages over the @tsdoctor/pages IR, a sidebar from its navigation tree, and Twoslash type-checking over the same virtual file system the RSPress plugin resolv
