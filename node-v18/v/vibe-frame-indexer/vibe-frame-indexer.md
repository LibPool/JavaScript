# vibe-frame-indexer

> 标签: JavaScript

## 简介

VibeFrame deterministic indexer: tree-sitter symbol extraction, import resolution (TS/JS via oxc-resolver, Python via a built-in resolver), test mapping, filesystem watching, git catch-up.
