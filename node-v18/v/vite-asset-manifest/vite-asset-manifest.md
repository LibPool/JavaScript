## 简介

Vite 8 plugin that emits an asset manifest (manifest.json) mapping source filenames to hashed output paths. API-compatible port of rspack-manifest-plugin / webpack-manifest-plugin for backend asset pipelines (Rails, Phoenix, Django, Laravel, server-render
