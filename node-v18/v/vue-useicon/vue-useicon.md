# vue-useicon

> 标签: bootstrap, icon, simplise, svg, vue

## 简介

Iconコンポーネントで簡単にIconを利用できます。 [Material Icon](https://material.io/) [Bootstrap Icon](https://icons.getbootstrap.jp/) [Line Awesome](https://icons8.com/line-awesome) に対応しています。
