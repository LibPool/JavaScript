# vello

> 标签: api, axios, browser, client, error-handling, fetch, http, http-client, http-error, http-interceptor, http-request, http-request-interceptor, http-response, interceptor, json, nextjs, react, request, retry, timeout, typescript, universal

## 简介

An enhanced HTTP client that improves upon fetch API limitations with automatic error handling, JSON conversion, timeout support, retry, and interceptors.
