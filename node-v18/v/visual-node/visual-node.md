# visual-node

> 标签: backend-builder, code-generation, express, fastify, flow-based-programming, low-code, no-code, node-based, nodejs, visual-programming

## 简介

Visual, node-based backend builder for Node.js. Drag-and-drop flows compile to real, readable Express.js source code.
