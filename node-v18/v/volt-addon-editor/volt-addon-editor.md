# volt-addon-editor

> 标签: cms, editor, rte, volt, volt-addon, wysiwyg

## 简介

A standing, role-gated WYSIWYG editor for Volt (RTEPro) that writes markdown pages. The WordPress-editor experience, hardened: secret ADMIN_PATH + magic-link auth + an allowlist, content stays markdown-on-disk.
