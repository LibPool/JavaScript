# vue3-elementplus-component-ah

> 标签: JavaScript

## 简介

安装 - 项目中需要先安装Vue3、Element Plus - yarn add element-plus - yarn add vue3-elementplus-component-ah  - 在入口文件中导入样式 `import 'vue3-elementplus-component-ah/dist/style.css'`
