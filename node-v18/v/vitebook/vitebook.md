# vitebook

> 标签: alternative, esm, fast, lightweight, markdoc, markdown, modern, ssg, vite, vitebook

## 简介

This package extends Vite with an SSG environment. The foundation is library-agnostic and is built to be extended via plugins. The client-side implementation is provided by other packages such as `@vitebook/svelte`.
