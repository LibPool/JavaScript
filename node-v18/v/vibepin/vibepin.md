# vibepin

> 标签: ai, annotation, antigravity, claude-code, codex, coding-agent, cursor, devtools, electron, feedback-loop, mcp, ui, visual-feedback, vite

## 简介

Drop a pin on any UI element, write what to change, and your AI coding agent edits the source. In-browser visual annotation for Claude Code, Cursor, and any MCP agent — web + Electron.
