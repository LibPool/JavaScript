# vue-marknote

> 标签: block-editor, editor, markdown, marknote, notion, prosemirror, rich-text, tiptap, vue, vue3, wysiwyg

## 简介

MarkNote — a Notion-style block editor for Vue 3 with markdown in and out: slash commands, drag handles, bubble menus, callouts, toggles, tables, columns, media, math, mentions, emoji and more.
