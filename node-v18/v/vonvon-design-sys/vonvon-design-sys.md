# vonvon-design-sys

> 标签: JavaScript

## 简介

React 19 기반의 컴포넌트 디자인 시스템입니다. TypeScript로 작성되었고, 개발 편의를 위해 Vite, Storybook을 사용하며 배포 번들은 Rollup으로 생성합니다. 스타일은 Tailwind CSS 유틸리티 클래스를 활용하여 빌드 시 정적 CSS로 추출됩니다.
