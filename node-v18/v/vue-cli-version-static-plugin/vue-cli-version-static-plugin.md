# vue-cli-version-static-plugin

> 标签: JavaScript

## 简介

- 为实现vuecli脚手架打包后，项目可以通过手动切换版本号来控制客户端具体展示页面，这在当前端页面出错，服务器上直接修改静态资源版本号来还原/回滚到之前代码。而不需要重新编译！ - 为解决vuecli项目中直接引用public中的static资源打包后无法正确展示的问题。
