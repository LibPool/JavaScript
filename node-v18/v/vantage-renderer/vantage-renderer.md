# vantage-renderer

> 标签: JavaScript

## 简介

Vantage-renderer is an open-source 3D projection renderer built with Three.js.  It provides a modular framework for projecting media (images and videos) onto 3D environments using custom web components. Designed for fact-checkers, investigative journalist
