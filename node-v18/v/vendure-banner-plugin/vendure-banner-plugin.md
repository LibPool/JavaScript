# vendure-banner-plugin

> 标签: banner, cms, dashboard-extension, ecommerce, marketing, promotion, translatable, vendure, vendure-banner-plugin, vendure-plugin

## 简介

Vendure plugin for dynamic, multi-section promotional banners with translatable content and drag-and-drop reordering.
