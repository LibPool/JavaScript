# vali-valid

> 标签: async-validation, field-validation, form-validation, framework-agnostic, i18n, rule-builder, schema, typescript, vali-valid, validation, validators

## 简介

ValiValid — framework-agnostic TypeScript validation engine. 74 built-in validators, fluent RuleBuilder, i18n (en/es/pt/fr/de). Use with vali-valid-react, vali-valid-vue, or vali-valid-svelte.
