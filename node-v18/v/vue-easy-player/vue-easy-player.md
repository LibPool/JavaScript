# vue-easy-player

> 标签: easyplayer, flv, h265, hevc, hls, live, m3u8, player, streaming, video, vue

## 简介

Vue 2 视频播放器组件，支持 H265/HEVC 编码的 HLS(m3u8)、HTTP-FLV、WS-FLV，集成 WASM 软解码，即装即用
