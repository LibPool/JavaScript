# vite-node-api

> 标签: api, backend, fullstack, node, plugin, vite, vue

## 简介

A Vite plugin for adding Node.js API routes to your Vite + Vue project. JSON-only, single-port backend and frontend, similar to Next.js API routes but for Vite.
