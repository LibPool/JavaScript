# vibe-is-positive

> 标签: ai, is-positive, positive, sentiment, vibe

## 简介

A tiny meme library that uses OpenAI to check if a number is positive, negative, or zero. Supports both number and bigint. Because why use math when you can ask AI? 🤖➕
