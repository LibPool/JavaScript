# vue3-tiptap-richtext

> 标签: ant-design-vue, editor, rich-text, richtext, tiptap, tiptap-v3, vue3, wysiwyg

## 简介

Vue 3 + TipTap v3 富文本编辑器组件库，内置字体/行高/背景色/视频/锚点/分页符/查找替换等自定义工具。基础版免费开源，高级功能见 Pro 套餐。
