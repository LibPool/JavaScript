# veneerui

> 标签: JavaScript

## 简介

CLI to add Veneer UI theming to an existing React + Tailwind v4 app (init, add, list). For a new app, use `npm create veneerui`.

## 官网

- 官网：https://veneerui.dev
- 源码仓库：git+https://github.com/offthegully/veneerui.git
- npm 页面：https://www.npmjs.com/package/veneerui
