# vue-tianditu-component

> 标签: component, gis, map, tianditu, vue, vue2, vue3

## 简介

基于 Vue 2/3 的天地图二次封装组件，提供简洁的 API 接口，支持地图初始化、标注管理、地理编码搜索等功能。
