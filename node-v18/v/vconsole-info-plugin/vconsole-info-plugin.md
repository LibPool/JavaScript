# vconsole-info-plugin

> 标签: debug, devtools, h5, useragent, vconsole, vconsole-plugin

## 简介

通用 vConsole 信息面板插件：设备环境、页面路由、全局变量、性能指标，支持搜索 / 复制 / 打印 / 自定义分组
