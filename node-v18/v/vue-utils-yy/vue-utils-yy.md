# vue-utils-yy

> 标签: component, directive, scroll, table, utils, vue, 前端, 封装, 工具, 指令, 组件

## 简介

YINAOR收集的一些vue开发可能用到的'工具'。目前组件：YTable(基于ElTable封装的更多功能表格)，YScrollContainer(可让滚动内容向上或向下滚动的容器)；目前指令：clipboard(复制内容到剪切板)，highlight(高亮显示指定文本)，selecttext(划词选择显示对应的菜单按钮)；其他js工具
