# vite-plugin-absolute-dynamic-imports

> 标签: absolute-url, aem, clientlib, dynamic-import, vite, vite-plugin

## 简介

Rewrites relative import specifiers in built chunks to absolute URLs — useful when your build output is served from a different base path than where it's built (e.g. AEM clientlibs).
