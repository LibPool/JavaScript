# verdaccio-ssh-upload

> 标签: plugin, publish, sftp, ssh, upload, verdaccio

## 简介

Plugin do Verdaccio que envia tarballs publicados para um servidor remoto via SSH (SFTP)

- npm 页面：https://www.npmjs.com/package/verdaccio-ssh-upload

- npm registry：https://registry.npmjs.org/verdaccio-ssh-upload
- Node 要求：>=18
