# vue-mescroll

> 标签: mescroll, vue, vue组件, 上拉加载, 下拉刷新

## 简介

精致的下拉刷新和上拉加载 js框架.支持vue,完美运行于移动端和主流PC浏览器 ( a great JS framework for pull-refresh and pull-up-loading )
