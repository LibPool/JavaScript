# vue-simpleui-mobile

> 标签: JavaScript

## 简介

一个适用于移动端的简单vue组件，用来学习vue练手的，目前只添加了日历组件和选择日历范围组件。 ### 安装 ``` npm run vue-simpleui-mobile ```
