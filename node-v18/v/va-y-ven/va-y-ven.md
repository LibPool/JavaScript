# va-y-ven

> 标签: mercadopago, recargas, tarjetas, va-y-ven, yucatan

## 简介

Módulo Node.js para interactuar con la API de recargas Va y Ven (Yucatán). Permite validar tarjetas, consultar saldo, obtener paquetes y generar links de pago.
