# vue-sticker-table

> 标签: css-sticky, mobile-table, sticky-table, table, vue-table

## 简介

基于 css sticky 特性实现的 Table 组件, 通过 columns 和 slot 灵活配置, 支持 Vue2.0 / Vue3.0
