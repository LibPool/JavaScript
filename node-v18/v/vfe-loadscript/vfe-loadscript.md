# vfe-loadscript

> 标签: JavaScript

## 简介

ready    类似于JQuery的ready     autoLoad  自动分析 v- 标签，按照先后顺序加载     autoCheck  自动分析 v- 标签，检测资源可用性     imports 手动引入资源，返回promise     check 手动检测资源，返回promise     config 设置配置项         baseURLs: []  // 资源可用的域名         parsePath: function // 资源文件的名称修改方式，默认是 path.name
