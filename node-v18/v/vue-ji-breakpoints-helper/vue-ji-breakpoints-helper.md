# vue-ji-breakpoints-helper

> 标签: breakpoints, responsive, vue, vue3

## 简介

`vue-ji-breakpoints-helper` is a lightweight **Vue 3 library** for handling **responsive breakpoints** in your project.   It allows you to control element visibility or run logic based on screen size in a **reactive** and easy-to-use way.
