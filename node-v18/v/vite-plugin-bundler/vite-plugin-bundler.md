# vite-plugin-bundler

> 标签: assets, brotli, build, build-report, bundle-size, compress, compression, gzip, integrity, optimization, performance, pre-compression, react, static-compression, typescript, vite, vite-plugin, vite-plugin-compress, worker-threads, zstandard, zstd

## 简介

A high-performance Vite plugin that compresses build assets using Brotli, Gzip, and Zstandard with worker thread support.
