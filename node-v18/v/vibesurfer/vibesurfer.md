# vibesurfer

> 标签: agent, agentic, ai-agents, browser, browser-automation, claude, cli, computer-use, e2e, e2e-testing, headless-browser, llm, mcp, mcp-server, model-context-protocol, playwright-alternative, rust, selenium-alternative, web-scraping, webkit

## 简介

A browser for LLMs, not humans. Real WebKit over a line protocol built for agents. Try it with npx vibesurfer.
