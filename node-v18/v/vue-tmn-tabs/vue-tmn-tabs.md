# vue-tmn-tabs

> 标签: component, tabs, vue, vue-tabs

## 简介

The main idea of this package is to have a standalone tabs component that provides CSS classes to make it fit your project's style guide. Supports [WAI ARIA for tabs with automatic activation](https://www.w3.org/TR/wai-aria-practices-1.1/examples/tabs/tab
