# verteiler

> 标签: distribute, weighted

## 简介

Verteiler ([[fɛɐ̯ˈtaɪ̯lɐ], meaning: distributor](https://en.wiktionary.org/wiki/Verteiler)) distributes an array of weighted items to a given number of recipients.
