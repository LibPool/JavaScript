# vue-cli-plugin-svgicons

> 标签: JavaScript

## 简介

Vue CLI plugin to handle loading SVG files in specific folder as components and to optionally create from them global components.

## 官网

- npm 页面：https://www.npmjs.com/package/vue-cli-plugin-svgicons
