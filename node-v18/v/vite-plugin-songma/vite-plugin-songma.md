# vite-plugin-songma

> 标签: jsx, react, songma, transpiler, vietlang, vietnamese, vite-plugin

## 简介

Vite plugin to transpile and bundle SongMa (.smjs / .smts / .smjx / .smtx) files in React, Vue, Svelte and Vanilla projects
