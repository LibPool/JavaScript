# vps-launch

> 标签: caddy, cli, cloudflared, deploy, devtools, docker, hosting, https, letsencrypt, ngrok-alternative, self-host, server, ssh, systemd, tunnel, ufw, vps

## 简介

Auto-configure any Linux VPS with Caddy + HTTPS + UFW + systemd, or share locally via Docker tunnel with live request inspector. No ngrok, no middlemen.
