# vibedonate

> 标签: agentic, claude-code, cli, codex, inference, local-first, mcp, mesh, vibe-suite, vibedonate

## 简介

BitTorrent-style mesh for AI inference — donate spare local compute across agentic CLIs. Opt-in, metered, your hardware. Local-first. v0: local-compute node + metering + allow-list.
