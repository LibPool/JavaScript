# vuex-persistor

> 标签: vue, vue2, vue3, vuex, vuex-persist, vuex-persist-state, vuex-persisted, vuex-persistor

## 简介

A Vuex4, Vue3 and Nuxt - ready plugin that saves and rehydrates the state of your application between page reloads
