# vite-vue-route-generator

> 标签: Vite, Vue, Vue Router, generator, routing

## 简介

Automate the tedious task of creating Vue Router configurations. Simply define your page components, and let this plugin handle the rest.  根据页面文件目录树，自动生成路由配置。
