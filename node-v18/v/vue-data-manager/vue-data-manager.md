# vue-data-manager

> 标签: JavaScript

## 简介

------- ### 介绍 为什么需要vue-data-manager ？ + 轻松的实现跨组件、跨路由改变数据状态 + vuex等工具需要花时间入手，结构复杂繁琐。vue-data-manager api与vue 原生语法一致，贴切易入手。 + 使用了vue本身api进行扩展、轻量、对vue友善。
