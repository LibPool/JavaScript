# vite-plugin-oss-cdn

> 标签: ali-oss, aliyun, cdn, oss, oss vite, oss-cdn, vite-plugin

## 简介

将打包后的静态资源上传至阿里云oss，可先删除指定目录文件（预防一直上传占用空间）兼容vite 4.x 和 5.x 版本
