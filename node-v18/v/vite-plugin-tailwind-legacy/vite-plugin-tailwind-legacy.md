# vite-plugin-tailwind-legacy

> 标签: browser-support, compatibility, fallback, legacy, plugin, postcss, tailwindcss, tailwindv4, vite

## 简介

Plugin Vite para gerar CSS Tailwind v4 compatível com navegadores antigos, utilizando PostCSS e gerando arquivo como fallback
