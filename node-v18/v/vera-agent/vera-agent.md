# vera-agent

> 标签: agent, ai-testing, browser-testing, ci, cli, e2e, e2e-testing, end-to-end-testing, localhost, mcp, playwright, test-automation, testing, vera

## 简介

Local test runner for Vera, the AI-native end-to-end testing platform. Runs your Playwright tests on your own machine — against localhost, no tunnels — and reports to the Vera cloud over an authenticated API.
