# vite-plugin-vue-critical-css

> 标签: above-the-fold, critical-css, fcp, fouc, lcp, lighthouse, performance, render-blocking, speed-index, ssr, vite, vite-plugin, vue, vue-sfc, vue3

## 简介

Extract <style critical> blocks from Vue 3 SFCs into a single inline-able payload. Per-route splitting, scoped-style aware, dev HMR, SSR-friendly. Drops your Speed Index and LCP without adding a headless browser to your build.
