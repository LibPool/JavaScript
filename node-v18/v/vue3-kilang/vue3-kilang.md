# vue3-kilang

> 标签: k, kilang, vue, vue-i18n, vue-kilang, vue-lang, vue3-kilang

## 简介

vue-kilang是一款以中文为第一语言的国际化插件，基于vue-i18n二次开发。对比vue-i18n，翻译操作更简洁，只需要导入挂载插件，并按下方教程编写，即可翻译

## 官网

- npm 页面：https://www.npmjs.com/package/vue3-kilang
