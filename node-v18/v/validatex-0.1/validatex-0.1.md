> 标签: batch-validation, credit-card, date-validation, email, form-validation, ip-address, javascript, luhn, nodejs, password, phone, postal-code, typescript, url, username, validation

## 简介

A lightweight and flexible validation library for JavaScript and TypeScript. Supports email (with typo suggestions), password, username, phone, URL, credit card (with card type detection), date, postal code, IP address, and batch validation.
