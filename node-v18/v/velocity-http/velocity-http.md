# velocity-http

> 标签: abort-controller, abort-signal, ajax, api, async, axios-alternative, browser, cancellation, client, fetch, fetch-wrapper, hooks, http, http-client, interceptors, isomorphic, lightweight, node, polling, promise, request, rest, retry, retry-request, sequential-polling, timeout, typescript, universal, velocity, velocity-http, zero-dependency

## 简介

A lightweight, zero-dependency universal HTTP client and fetch wrapper with built-in sequential polling, retry, interceptor hooks, timeout, cancellation, and full TypeScript support. A modern alternative to Axios.
