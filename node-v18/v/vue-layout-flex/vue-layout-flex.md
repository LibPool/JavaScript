# vue-layout-flex

> 标签: directive, flex, layout, vue

## 简介

vue-layout-flex是一个flex布局系统，它使布局与表现分开，在vue的模板中进行布局甚至设置元素大小，剩下的工作只需要在css中写好表现样式。
