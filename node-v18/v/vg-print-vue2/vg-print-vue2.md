# vg-print-vue2

> 标签: CSDN, npm, vg-print, vue, 打印, 插件

## 简介

vg-print supports visual drag and drop design templates, with functions such as previewing and exporting PDFs/images. Silent printing can be achieved in conjunction with a dedicated client
