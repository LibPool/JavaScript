# vite-plugin-css-modules-swc

> 标签: css-modules, swc-plugin, vite

## 简介

这是一个 SWC 插件，用于在 JSX 中无感知地使用 CSS Modules。它是 [babel-plugin-jsx-css-modules](https://github.com/CJY0208/babel-plugin-jsx-css-modules) 的 SWC 版本。

## 官网

- 官网：https://swc.rs
- 源码仓库：git+https://gitee.com/ws18250840411/swc-vite-plugins.git
- npm 页面：https://www.npmjs.com/package/vite-plugin-css-modules-swc
