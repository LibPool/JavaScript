# vitakey-mcp

> 标签: claude, cursor, health, mcp, model-context-protocol, nutrition, vitakey

## 简介

MCP (Model Context Protocol) server for VitaKey. Lets Claude Desktop, Cursor, and other MCP-compatible clients read your VitaKey data using a Personal Access Token.
