# vue3-vuecmf-table

> 标签: JavaScript

## 简介

基于vue3、Element Plus和TypeScript的多功能列表组件，支持树形列表数据，内置搜索、筛选、分页、行展开、详情、新增、编辑、删除、导出和导入EXCEL等功能
