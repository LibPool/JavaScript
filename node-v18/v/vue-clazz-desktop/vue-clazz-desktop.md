# vue-clazz-desktop

> 标签: class, clazz, decorator, desktop, framework, model, pc, reactive, typescript, viewmodel, vue, vue-clazz, vue3

## 简介

A PC UI framework based on vue-clazz-decorator. Write Vue 3 desktop applications with Class + Decorators, featuring MVVM pattern, metadata system, and reactive model layer.
