# vue-svgicon-ts

> 标签: icon, svg, svgicon, vue, vue2.0

## 简介

A tool to create svg icon components. Fork of https://github.com/MMF-FE/vue-svgicon with TS support. Needed to use this mod so created a separate package, will swap back to main once the PR is merged.
