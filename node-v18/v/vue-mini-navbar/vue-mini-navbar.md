# vue-mini-navbar

> 标签: capsule, menu-button, miniprogram, navbar, plugin, safe-area, statusbar, uni-app, uniapp, vue, vue2, vue3, wechat

## 简介

兼容 Vue2 与 Vue3 的小程序顶部距离信息插件，一键获取状态栏高度、胶囊按钮位置、自定义导航栏高度与安全区，结果本地缓存
