# vue-translate-auto

> 标签: auto-translate, baidu-translate, google-translate, i18n, internationalization, translate, vue, vue-translate-auto, youdao

## 简介

Vue 国际化自动翻译工具 - 自动提取 $t 包裹的字符串并生成多语言文件，支持增量翻译和多种翻译API
