# v-backtop

> 标签: backtop, vue

## 简介

> Vue组件：滚动到页面顶部 ## 使用方法 ### 安装 ```bash npm i v-backtop --save ``` ### 使用 ```js import BackTop from 'v-backtop' import 'v-backtop/dist/v-backtop.css' Vue.use(BackTop) ``` ```html   <div id="app">    <BackTop/>   </div> ```
