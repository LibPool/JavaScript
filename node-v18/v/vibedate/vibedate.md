# vibedate

> 标签: agentic, claude-code, cli, codex, local-first, mcp, tokens, vibe-suite, vibedating

## 简介

Dating by tokens — matched by usage league across agentic CLIs. Raw usage stays local; only your league is shared. CLI + local web app + MCP. Local-first.
