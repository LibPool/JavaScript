# vite-plugin-mithril-jsx

> 标签: esbuild, jsx, mithril, mithriljs, oxc, rolldown, vite, vite-plugin

## 简介

Vite plugin that configures JSX for Mithril.js — works with all Vite versions (esbuild ≤ 5, rolldown/OXC 7+).
