# vite-plugin-vanner-cache

> 标签: cache, fetch cache, vite plugin

## 简介

一款采用 sw 开发的 Vite 开发、生成缓存插件，可对后端响应慢的请求实现毫秒级缓存加载。其缓存时间窗口取决于接口的响应时间。
