# vue3-teleport-mount

> 标签: function render, mount teleport, provide teleport, vue3 mount, vue3 teleport

## 简介

Similar to the built-in Vue3 component `<Teleport>`, it renders components functionally to a specified location, solving the problem that when rendering components functionally, the components cannot obtain the `provide` values of their ancestor component
