# vite-plugin-lazy-thumbnails

> 标签: lazy, plugin, thumbnail, vite, vite-plugin, vite-plugin-lazy, vite-plugin-lazy-thumbnails, 图片懒加载, 插件, 缩略图片加载

## 简介

一个 Vite 插件，用于生成图片缩略图并在页面加载时实现渐进式图片加载效果
