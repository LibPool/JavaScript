# vue-tv-focusable

> 标签: vue-tv-focusable tv-focusable tv-focus tv-auto-focus tv tv-focus vue-tv

## 简介

TV focusable is a framework for managing focus movement when developing web pages on TV. With the simplest API, front-end web development can automatically manage focus just like Android development
