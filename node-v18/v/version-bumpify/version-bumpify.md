# version-bumpify

> 标签: automation, badge, bump, changelog, cli-tool, npm, package-lock.json, package.json, readme, semantic-versioning, version, versioning

## 简介

A Node.js CLI tool to automatically update version numbers in package.json, package-lock.json, and multiple README.md badges.
