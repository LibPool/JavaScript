# vue-image-editer

> 标签: JavaScript

## 简介

## 介绍     基于canvas开发的vue画板组件，类似于微信的截图编辑功能，包括画笔、橡皮、箭头、直线、矩形、椭圆，前进后退、清空、保存等常规画板功能。
