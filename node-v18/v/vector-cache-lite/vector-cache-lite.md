# vector-cache-lite

> 标签: ai, cosine, embeddings, similarity, typescript, vector

## 简介

Lightweight in-memory vector similarity cache — cosine-similarity nearest-neighbor lookup over a small in-memory vector set, for when a full vector DB is overkill.
