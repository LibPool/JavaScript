# vibeqa

> 标签: cloudflare, d1, e2e, mcp, nextjs, opennext, playwright, qa, regression-testing, scaffold, workers

## 简介

A proven Playwright E2E regression harness for Next.js-on-Cloudflare apps (D1 + Workers), scaffolded into any repo with one command. CLI + MCP. Part of the getvibe.dev vibe* family.
