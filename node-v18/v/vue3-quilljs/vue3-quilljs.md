# vue3-quilljs

> 标签: quilljs, rich-text-editor, text-editor, vue3

## 简介

This is Vue 3 Quill Rich Text editor created by 7uvss from https://7uvss.github.io/vue3-quill-editor/ and this package only add placeholder to the text editor.
