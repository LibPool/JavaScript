# virtual-game-joystick

> 标签: game, joystick, mobile, virtual

## 简介

For mobile virtual joystick, you can use it to trigger keyboard events, suitable for all kinds of HTML game emulators.移动端虚拟摇杆，可用于触发键盘事件，适用于所有HTML游戏模拟器。
