# vue-magic-scroller

> 标签: dynamic height items, dynamic virtual scroll, virtual scroll, virtual scroller, vue, vue3, vuejs

## 简介

A `Vue 3` + `Typescript` + `VueUse` virtual scroller for dynamic/fixed height items with no styles attached.
