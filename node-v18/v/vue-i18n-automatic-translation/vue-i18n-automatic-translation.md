# vue-i18n-automatic-translation

> 标签: chinese, i18n, translation, vite, vue, vue-i18n

## 简介

Scan Chinese text in Vue projects, wrap with $t(), and auto-translate locale JSON files. Configure via vite.config i18nAuto.
