# validatecpf

> 标签: JavaScript

## 简介

**Esta biblioteca se destina à validação de CPF, para uso em aplicações web.** Na versão atual valida números de CPF a partir da fórmula definida pela Receita Federal, com validação pelo dígitos verificadores.
