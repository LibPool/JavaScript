# vaid-mint

> 标签: agent-identity, attenuation, delegation, ed25519, mint, synthera, vaid

## 简介

The open, self-hostable reference mint (TypeScript) for the VAID standard: mint a root VAID and mint attenuated child VAIDs (scope/capability-contained delegation), byte-identical to the Rust and Python mints.
