# vue-config-wrapper

> 标签: vue, wrapper

## 简介

一个vue项目配置的包装器.   当项目依赖的模块更换配置项时, 根据 项目已有配置 和 实际安装的版本, 给出提示或直接修补配置, 使开发者可以比较平滑地升级项目依赖, 获得更好的开发体验. ## 指令
