# vue-synth

> 标签: JavaScript

## 简介

vue-synth 基于element-plus,综合各类ui库优缺点,搭建UI核心包 如何使用: ``` import VueSynth from 'vue-synth' import App from './App.vue' var app = createApp(App) app.use(VueSynth) app.mount('#app') ```
