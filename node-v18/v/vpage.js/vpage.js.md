# vpage.js

> 标签: SPA, hash, history, jquery, onhashchange, onpopstate, plugin, router, vpage

## 简介

利用 jQuery 製作路由或簡單的 SPA。有兩種方式可以觸發事件，一種是 History 另外一種是 Hash。
