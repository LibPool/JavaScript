# vuehtml-cli

> 标签: react多文件打包, vue多文件打包, 多文件打包脚手架

## 简介

多文件打包脚手架,支持html,css,js压缩,图片转base64,多html压缩,自动添加css前缀,支持es7,es6转es5,可适配html引用不同js
