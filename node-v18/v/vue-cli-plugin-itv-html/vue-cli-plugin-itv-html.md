# vue-cli-plugin-itv-html

> 标签: JavaScript

## 简介

vue-cli 3.0 提供了 preset 入口，让我们能够自定义项目内容。<br/> 比如：添加安装需要的npm包、自定义的文件、修改App.vue等。
