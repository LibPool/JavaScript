# verifymailjs

> 标签: checker, email, email-address-validation, email-check, email-checker, email-syntax-check, email-validation, email-validation-library, email-validation-tool, email-validator, email-verification, mx-record, regex, temp email check, validation, validator

## 简介

A robust and modern JavaScript library for validating and categorizing email addresses. You can check if an email address is valid, disposable, role-based, free, or from a temporary email provider.
