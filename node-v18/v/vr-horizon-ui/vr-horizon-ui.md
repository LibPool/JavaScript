# vr-horizon-ui

> 标签: JavaScript

## 简介

vr-horizon-ui is a component-library for React, containing the building blocks for VR-Horizon's web-apps. The components are made using [`emotion`](https://github.com/emotion-js/emotion) and [`styled-system`](https://github.com/styled-system/styled-system
