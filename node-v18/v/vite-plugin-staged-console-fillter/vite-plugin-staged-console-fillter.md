# vite-plugin-staged-console-fillter

> 标签: JavaScript

## 简介

用于清除 development 环境下 console.log 的 vite 插件，本插件会检查 git 暂存区，如果暂存区有文件，会保留当前 git 用户的 console.log，否则清除所有 console.log
