# vue-lerna-mfe

> 标签: JavaScript

## 简介

Follow below steps 1. npm install 2. npm run boot 3. npm run build 4. npm link 5. test in local with npm link vue-lerna-mfe 6. npm publish (change version before publish in package.json)
