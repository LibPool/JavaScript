# vue-note-editor

> 标签: editor, markdown, note, vditor, vue, vue3

## 简介

A Vue 3 <NoteEditor> component built on Vditor (IR mode) with a tag bar, debounced autosave, and a status bar. Loads Vditor from CDN at runtime.
