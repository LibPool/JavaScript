# vue3-useworker

> 标签: JavaScript

## 简介

`vue-useWorker` 是一个基于 Vue 3 的工具，用于在 Web Worker 中运行耗时的任务，从而避免阻塞主线程。

## 官网

- npm 页面：https://www.npmjs.com/package/vue3-useworker
