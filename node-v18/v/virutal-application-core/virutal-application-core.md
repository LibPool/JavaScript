# virutal-application-core

> 标签: Vue Framework, web, web-pc

## 简介

虚拟应用核心，使Web前端工程更接近一个PC应用工程，主要约束工程的整体运行框架。强调“应用”，“窗口”等概念，加强应用（窗口）之间的通信交互能力。
