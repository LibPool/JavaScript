# vuepress-plugin-copy-page

> 标签: ai, chatgpt, claude, clipboard, copy, copy-content, copy-page, documentation, export, llm, markdown, share, vuepress, vuepress-2, vuepress-plugin, vuepress2

## 简介

A VuePress 2 plugin that adds a Copy Page button to copy page content as Markdown. Perfect for sharing documentation with ChatGPT, Claude, and other AI/LLM tools.
