> 标签: ai-coding, claude, claude-code, cursor, deploy, git, low-code, mcp, mcp-server, no-code, rollback, safety, undo, version-control, vibe-coders, vibe-coding

## 简介

Natural language version control for vibe coders — save, ship, and roll back your AI-generated code without touching Git. Works with Cursor, Claude Code, and any MCP client.
