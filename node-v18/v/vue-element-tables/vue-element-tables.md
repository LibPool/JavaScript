# vue-element-tables

> 标签: admin-template, better-scroll, element-ui, svg, table, vue, vue图标封装, 可折叠表格, 自定义表头表格, 虚拟滚动

## 简介

基于vue和element UI组件二次封装的功能库其中包含（可折叠表格，普通表格，表头二次搜索，表字段过滤，svg图标库，虚拟滚动等等组件），每一种表格包含虚拟滚动，分页，已经封装好的，开箱即用
