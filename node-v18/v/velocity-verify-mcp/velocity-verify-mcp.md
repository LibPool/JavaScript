# velocity-verify-mcp

> 标签: ai, citations, claim, fact-check, grounding, hallucination, llm, mcp, model-context-protocol, modelcontextprotocol, verification

## 简介

MCP server for verification-as-a-service — check a claim against sources and get a confidence verdict (supported | refuted | mixed | insufficient) with citations. Deterministic, zero runtime dependencies, honest about uncertainty.
