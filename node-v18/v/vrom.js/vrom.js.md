# vrom.js

> 标签: ai-agent, browser, embeddings, hnsw, offline, opfs, rag, transformers.js, vector-database, wasm, web-worker, webassembly

## 简介

Zero-boilerplate RAG for browser AI agents. WASM HNSW vector search + background ONNX embedding + OPFS-cached vROM cartridges.
