# vibe-splain

> 标签: architecture, claude, coding-agent, cursor, documentation, gemini, mcp, model-context-protocol, static-analysis, tree-sitter

## 简介

Static-analysis dossier engine for codebases: Tree-Sitter powered architectural analysis and interactive UI. Language-agnostic core, optimized for TypeScript/JavaScript.
