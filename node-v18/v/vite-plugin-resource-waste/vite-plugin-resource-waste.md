# vite-plugin-resource-waste

> 标签: bundle-waste, dead-code, resource-waste, tree-shaking, vite, vite-plugin, vite-plugin-resource-waste, 前端性能优化, 包体积优化, 无效资源检测, 构建分析报告, 资源浪费, 资源浪费分析

## 简介

基于 Vite 的前端构建资源浪费分析插件，利用 Module Graph 检测未使用 JS、不可达组件、缓存失效与重复依赖，量化传输/解析开销并输出可执行优化报告，支持 CI 构建阈值拦截
