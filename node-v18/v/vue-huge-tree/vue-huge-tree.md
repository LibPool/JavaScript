# vue-huge-tree

> 标签: JavaScript

## 简介

> 当数据量很大时, 树形图渲染会异常卡顿, 用户体验极差 > > 本组件有效的解决了这个问题, 渲染速度比普通树形图提高 N 倍 > > 海量数据建议不要放到 data 里，vue 依赖收集会导致内存占用过多。所以此插件没有使用 props 传递海量数据，而是通过 `setData(data)` 方法
