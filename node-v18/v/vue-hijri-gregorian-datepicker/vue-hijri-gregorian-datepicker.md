# vue-hijri-gregorian-datepicker

## 简介

A standalone Vue 3 date picker component with bilingual support (Arabic & English) for both Gregorian and Hijri (Islamic) calendars. Zero external dependencies except Vue 3. Perfect for Islamic applications and Middle East markets.
