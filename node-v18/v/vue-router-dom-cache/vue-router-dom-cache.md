# vue-router-dom-cache

> 标签: router, routing, vue

## 简介

基础vue-router开发了新组件router-views，用于SPA切换路由时保存之前页面的dom，效果类似framework7的实现方式，同样也类似于子路由的方式，但是本组件不是嵌套组件，而是并列。详细效果可以查看examples中的router-views demo
