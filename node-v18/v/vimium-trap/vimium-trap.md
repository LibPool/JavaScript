# vimium-trap

> 标签: canvas, godot, itch.io, keyboard, surfingkeys, tridactyl, unity-webgl, vimium, web-game

## 简介

Stop Vimium, Tridactyl, Surfingkeys, and Firefox search-when-you-type from stealing keyboard input from canvas web games.
