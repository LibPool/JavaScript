# volvelle

> 标签: dsl, rpg, tabletop, ttrpg, vtt

## 简介

Reserved for the Volvelle system-definition DSL: declare a tabletop RPG system as data and run it on the Volvelle virtual tabletop. In active development; not yet published as a usable library.
