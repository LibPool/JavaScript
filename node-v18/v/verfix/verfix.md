# verfix

> 标签: ai-agent, assertions, browser-testing, ci-cd, cli, coding-agent, deterministic-testing, devtools, docker, playwright, ui-testing, verification

## 简介

Browser verification CLI for AI coding agents — run deterministic browser flows, assert UI state, and get structured failure reports. Local-first: needs only Node 20+, no Docker.
