# vietnam-provinces-js

> 标签: administrative, analytics, autocomplete, communes, districts, export, fuzzy-search, geography, lazy-loading, performance, provinces, search, tree-shaking, typescript, validation, vietnam

## 简介

High-performance Vietnam administrative data library with advanced search, analytics, validation, and export features. Includes 63 provinces, 696 districts, and 10,051 communes with lazy loading and O(1) lookups.
