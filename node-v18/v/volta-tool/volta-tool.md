# volta-tool

> 标签: JavaScript

## 简介

一个基于 [Volta](https://volta.sh/) 的交互式 Node.js 版本切换工具，通过简洁的命令行菜单快速切换已安装的 Node 版本。

## 官网

- npm 页面：https://www.npmjs.com/package/volta-tool

## 历史版本号

- 1.0.0
- 1.0.1

## 获取地址

- npm 安装：`npm install volta-tool`
- npm registry：https://registry.npmjs.org/volta-tool
