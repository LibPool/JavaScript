# vue-grid-sf

> 标签: Vue, actions, bulk, checkbox, component, events, grid, rows, select, sortable

## 简介

A rather handy grid UI component for Vue.js. Define the columns, bind the data and off you go. Column headings are sortable by default, triggering an event.
