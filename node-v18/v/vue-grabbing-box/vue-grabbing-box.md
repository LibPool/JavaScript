# vue-grabbing-box

> 标签: canvas, container, drag, grab, scale, svg, touch, vue, zoom, 多指缩放, 画布, 画布拖拽, 画布缩放

## 简介

vue-grabbing-box is a container component that allows you to grab to change view-box and also with scaling
