# vanilla-signal

> 标签: jsx, jsxs, module, reactivity, runtime, signal, solid, state management, umd, vanilla

## 简介

A fine-grained reactive runtime that brings Signal-based reactive design to framework-free, dependency-free, build-free vanilla JS.
