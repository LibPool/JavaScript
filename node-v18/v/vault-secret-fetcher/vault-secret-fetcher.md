# vault-secret-fetcher

> 标签: bao, cubbyhole, fetch, hashicorp, kv1, kv2, node-fetch, secret, vault

## 简介

A simple Node.js package to fetch secrets from Vault (Bao), supports cubbyhole, kv1, kv2 engines.
