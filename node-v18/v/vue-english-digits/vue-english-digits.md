# vue-english-digits

> 标签: arabic, convert, directive, farsi, numbers, nuxt, nuxt3, persian, vue, vue3

## 简介

A Vue 3 directive to convert non-English (Persian/Arabic) numbers to English numbers in real-time on input fields.
