# vue-transable

> 标签: drag, resize, rotate, vue3

## 简介

### 功能  - [x] 旋转 - [x] 拖拽 - [x] 拖拽四个角 - [x] 拖拽四个边的中点 - [x] 坐标展示 - [ ] 等比缩放   - [ ] 控制组件内元素缩放 `(scale(x, y))`
