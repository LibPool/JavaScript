# volt-preline

> 标签: components, laravolt, preline, remix, remix-3, remix-ui, tailwindcss, ui-kit, volt

## 简介

Preline UI (free tier, MIT) components for Remix 3 UI — same component API as volt-catalyst, interactions via remix/ui primitives (no preline.js).
