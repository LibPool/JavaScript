# vite-plugin-astro-prerender

> 标签: astro, astro-integration, components, css, html-fragments, lazy-load, lazy-loading, optimization, performance, prerender, ssg, ssr, static-html, tailwind, tailwindcss, tree-shaking, vite, vite-plugin

## 简介

A Vite plugin for Astro that prerenders components to static HTML and generates optimized CSS with Tailwind tree-shaking for lazy-loading below-the-fold content
