# vpx-to-viewport

> 标签: css, fluid-design, mobile-first, postcss, postcss-plugin, responsive, vh, viewport, vite, vite-plugin, vpx, vpx-to-viewport, vw, webpack, webpack-loader

## 简介

Universal VPX to viewport units converter. Supports PostCSS plugin, Vite plugin, and Webpack loader. Converts vpx, maxvpx, minvpx, cvpx, and linear-vpx() for fluid responsive design across all build tools.
