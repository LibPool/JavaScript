# victor-react-native

> 标签: cross-platform, elpian, expo, godot, mini-apps, no-jit, react-native, sandbox, vm

## 简介

Run the Elpian VM as a cross-platform Expo engine: a mini-app management system that hosts many isolated Elpian JS programs, each rendering its own React Native (2D) widget tree with embedded Godot (3D) Scene3D worlds — no JIT, App-Store-legal, web + nati
