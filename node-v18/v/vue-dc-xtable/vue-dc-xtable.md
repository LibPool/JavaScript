# vue-dc-xtable

> 标签: dc-table, element-plus, table, typescript, vue, vue-component, vue3, x-table

## 简介

基于 Element Plus 二次封装的 Vue3 表格组件，支持列配置驱动、动态单元格渲染、远程数据加载、分页、完整类型支持。
