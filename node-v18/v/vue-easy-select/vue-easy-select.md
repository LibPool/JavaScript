# vue-easy-select

> 标签: a11y, combobox, dropdown, form, multiselect, select, typescript, vue, vue-component, vue3

## 简介

Flexible select component for Vue 3 — composable primitives plus a ready-to-use opinionated select. Single/multiple, searchable, slot-driven, form-friendly.
