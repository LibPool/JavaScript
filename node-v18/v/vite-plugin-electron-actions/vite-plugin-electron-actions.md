# vite-plugin-electron-actions

> 标签: electron, electron-actions, vite, vite-plugin

## 简介

This plugin brings a React `"use server"`-style workflow to Electron. Add `"use node"` to an async function to run it in the main process while calling it like a local function from the renderer. The plugin generates the IPC bridge, replaces the renderer
