# vdf-webview-miniapp-sdk

> 标签: bridge, miniapp, sdk, super-app, vdf, webview

## 简介

SDK phía WebView cho Super MiniApp — giao tiếp giữa WebView (JS/TS) và app Native (Android/iOS) qua bridge event. API type-safe sinh tự động từ events.json.
