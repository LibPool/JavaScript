# vistoazul-mcp

> 标签: ai-agent, claude, mcp, model-context-protocol, pix, vistoazul, whatsapp, whatsapp-api

## 简介

Servidor MCP da Visto Azul: opere o WhatsApp (texto, midia/audio/nota de voz, PIX, enquete/botoes/menu, convite de calendario, ler conversas, campanhas, contatos, chatwoot, webhook) direto de agentes de IA como Claude, ChatGPT e Cursor, pela API REST do V
