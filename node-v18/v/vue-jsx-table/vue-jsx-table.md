# vue-jsx-table

> 标签: element table, element-ui, jsx, table, vue, vue jsx, vue table

## 简介

此组件基于element-table二次开发，以实际业务出发，封装了常用的功能，通过配置的方式生成表格， 并且实现**多级表头** **expand展开项** **自定义表头**功能等
