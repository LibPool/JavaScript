# versions-from-filenames

> 标签: JavaScript

## 简介

Get package names & versions from filenames (e.g. ['foo-1.2.3.tgz', 'foo-1.3.0.tgz', 'bar-2.0.0.tgz'] -> { foo: ['1.2.3', '1.3.0'], bar: ['2.0.0'] }
