# vue-element-complex

> 标签: es6, npm, vue-element-table, vue-table

## 简介

vue-element 复合封装组件 避免重复代码，涵盖所有table,form,panel,calender操作和回调函数,可选择包含http请求的高阶复用性很强的组件,based on vue2.5.9
