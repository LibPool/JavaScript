# vite-plugin-stylus-alias-next

> 标签: JavaScript

## 简介

一个vite插件，通过读取vite里的别名配置对stylus里的引入进行一个路径转换。注意：`1.0.0`不支持正则转换，从`1.1.0`开始支持。
