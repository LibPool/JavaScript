# vite-plugin-convention-routes

> 标签: convention-routes, dynamic-routes, file-system-routes, layout-routes, lazy-loading, meta-data, nested-routes, route-meta, routes, vite, vite-plugin, vue-router

## 简介

一个类似Umi的约定式路由Vite插件，自动根据文件结构生成路由配置，支持多级动态路由参数、布局组件、元数据和懒加载
