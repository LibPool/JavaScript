> 标签: markdown, vue-markdown, vue-markdown-mini, vue3.0, 代码块复制, 代码高亮, 流式渲染, 语法高亮

## 简介

- 一个基于Vue的Markdown渲染组件，支持实时预览、主题切换和自定义扩展，适用于快速构建内容丰富的Web应用。
