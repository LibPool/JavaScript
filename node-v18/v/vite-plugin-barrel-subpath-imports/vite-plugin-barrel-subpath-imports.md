# vite-plugin-barrel-subpath-imports

> 标签: barrel, dev-server-performance, sourcemap, tree-shaking, vite, vite-plugin

## 简介

Vite plugin that rewrites barrel-file imports into per-subpath imports at transform time, avoiding the full-barrel inline-sourcemap cost that hangs DevTools on every dev-server page load.
