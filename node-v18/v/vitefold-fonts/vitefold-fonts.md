# vitefold-fonts

> 标签: font-face, fonts, privacy, self-hosted-fonts, ssg, vitefold, woff2

## 简介

Hermetic self-hosted web-font plugin for vitefold (local woff2, optimized @font-face, preload, no CDN request)
