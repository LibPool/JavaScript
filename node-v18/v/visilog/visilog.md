# visilog

> 标签: ai-assistant, browser-logs, console-streaming, debugging, developer-experience, development-tools, file-based-logs, llm, log-visibility, no-mcp, real-time-logs, typescript, vite-plugin, webpack-plugin, websocket-logging

## 简介

Stream browser console logs to files for LLM debugging. Zero-config setup with simple imports. No MCP required - just tell your LLM to read the log files.
