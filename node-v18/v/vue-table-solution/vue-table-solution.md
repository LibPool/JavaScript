# vue-table-solution

> 标签: JavaScript

## 简介

vue-table-solution 是 基于 Vue 3 + Vite 4 + Ant Design Vue 3 + Surely Vue Table 实现的“高端”组件。致力于解决大数据渲染、图表集成等复杂高频问题，使用该组件可以流畅滚动 10 万行、10 万列的数据...
