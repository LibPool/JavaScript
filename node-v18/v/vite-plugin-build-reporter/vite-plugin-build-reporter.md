# vite-plugin-build-reporter

> 标签: analyzer, build, bundle, cli, report, rolldown, rollup, vite, vite-plugin

## 简介

一个 Vite 插件，在 build 之后把构建分析（耗时、产物体积、Top chunk、gzip）打印到终端，不生成任何报告文件。
