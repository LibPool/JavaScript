# vmoth

> 标签: axios, mock, vmoth

## 简介

**vMoth** 是一個基於 `axios` 和 `axios-mock-adapter` 的輕量級 HTTP 請求模擬工具，它可以幫助您在測試中模擬 HTTP 請求的行為。
