# vue-ai-hooks

> 标签: JavaScript

## 简介

Vue 3 Composable library for building AI-powered applications, with optional React chat, completion, object, image, video, prompt suggestion, and agent entries. useChat, useCompletion, useEmbedding, useImage, useVideo, useSpeech, useTranscription, useRera
