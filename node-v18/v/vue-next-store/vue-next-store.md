# vue-next-store

> 标签: persistent, store, vue

## 简介

基于 Vue3 实现的超轻量全局状态管理 + 自动本地持久化，无 watch、无额外依赖、极简 API、自带 TS 类型，适合中小型 Vue3 项目替代。
