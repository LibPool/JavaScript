# vue3-tool-box

> 标签: Vue3, vertify-slider, vite, vue3-vertify-slider

## 简介

是一款基于 vue3/vite/js 开发的滑动验证码 这个滑动验证码组件是一个可用于验证用户身份的工具。它可以很容易地集成到你的网站或应用程序中，提供一种用户友好的验证方式，以防止机器人或其他自动化程序的攻击。
