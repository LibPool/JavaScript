# vue3-print-designer

> 标签: Lodop打印设计器, vue3打印设计器, vue静默打印, 打印设计器

## 简介

一个基于Vue3、element-plus、Lodop、pinia、vite、的打印模板设计器。实现打印模板的设计、预览和打印功能。
