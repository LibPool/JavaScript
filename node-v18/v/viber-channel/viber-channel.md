# viber-channel

> 标签: channel, claude-code, mcp, transcription, viber, voice

## 简介

Voice + text MCP channel between a Claude Code session and the Viber UI (https://viber.dgypx.dev). Push transcripts to Claude; send_message tool delivers text back to the UI.

## 官网

- 官网：https://viber.dgypx.dev
- 源码仓库：git+https://github.com/dgx80/viber.git
- npm 页面：https://www.npmjs.com/package/viber-channel
