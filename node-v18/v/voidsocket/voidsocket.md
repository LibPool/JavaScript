# voidsocket

> 标签: broadcast, realtime, server, socket, tls, websocket, websocket-client, websocket-server, ws, wss

## 简介

High-throughput, zero-dependency WebSocket client and server for Node.js. Built for mission-critical ingestion pipelines, broadcast engines, automated connection lifecycle, backpressure control, and zero-allocation stream parsing.
