# vue2-image-label

> 标签: vue-component, vue2-label-image

## 简介

Vue2 图片内容标记组件，用于圈出图片四边形内容并获取标记点坐标。**React**版本请参考组件[image-label](https://github.com/nhdeng/image-label)
