# vcast-cli

> 标签: cli, vcast-cli

## 简介

1. vcast --help 查看使用帮助 2. vcast -V | --version 查看工具版本号 3. vcast list 列出所有可用模板 4. vcast init <template-name> <project-name> 基于指定的模板进行项目初始化 ...
