# vonage-opentok-server

> 标签: JavaScript

## 简介

A custom plugin (Beta version) for Strapi that simplifies setting up a basic Node.js OpenTok server, streamlining video communication capabilities. This plugin provides easy integration and configuration, enabling rapid deployment of essential OpenTok fun
