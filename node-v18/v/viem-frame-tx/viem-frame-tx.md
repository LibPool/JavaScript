# viem-frame-tx

> 标签: account-abstraction, eip-8141, ethereum, frame-transaction, rlp, viem

## 简介

Unofficial viem-based encoder for EIP-8141 frame transactions (type 0x06) — RLP serialization + sig-hash computation, ground-truthed against ethrex's reference implementation. No native viem support exists yet; use this directly rather than through viem's
