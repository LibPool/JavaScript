# verifiera

> 标签: Burgerservicenummer, CPR-Nummer, D-nummer, Fødselsnummer, Henkilötunnus, PESEL, Personbeteckning, Personnummer, Samordningsnummer, denmark, finland, identification, netherlands, norway, number, perosnal, poland, sweden, verifification

## 简介

A JavaScript library to perform common operations on Personal Identification Numbers (Social Security Numbers), like: Validation, censoring the individual digits, calculating age and detecting gender.
