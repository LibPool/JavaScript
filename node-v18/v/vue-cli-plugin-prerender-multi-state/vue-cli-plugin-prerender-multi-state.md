# vue-cli-plugin-prerender-multi-state

> 标签: JavaScript

## 简介

This plugin is based on [vue-cli-plugin-prerender-spa](https://github.com/SolarLiner/vue-cli-plugin-prerender-spa) but allows multiple initial Vuex states.
