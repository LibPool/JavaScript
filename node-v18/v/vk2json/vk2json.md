# vk2json

> 标签: JavaScript

## 简介

Инструмент для конвертации html-файлов из [архива с выгруженными данными ВКонтакте](https://vk.com/data_protection?section=rules) в машиночитаемый JSON-формат.

## 官网

- npm 页面：https://www.npmjs.com/package/vk2json
