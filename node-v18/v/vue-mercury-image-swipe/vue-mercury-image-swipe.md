# vue-mercury-image-swipe

> 标签: vue-image-swipe, vue-photoswipe

## 简介

基于 photoswipe 的 vue 预览组件 在 vue-image-swipe 组件基础上处理 根据业务需要将图片转成 base64 后展示 感谢 vue-image-swipe
