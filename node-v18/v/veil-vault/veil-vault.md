# veil-vault

> 标签: JavaScript

## 简介

Encrypted-at-rest credential storage for [Veil](https://github.com/SiyahKale0/veil), with zero-knowledge sync. Keys never leave the device; a sync server only ever holds an opaque, encrypted blob.
