# vue-print-last

> 标签: print, vue-print, vue-print-nb, vue3-print, vue3-print-nb

## 简介

Vue 打印插件，简单、快速、方便、轻巧，支持 Vue 2 和 Vue 3。This is a directive wrapper for printed, Simple, fast, convenient, light.
