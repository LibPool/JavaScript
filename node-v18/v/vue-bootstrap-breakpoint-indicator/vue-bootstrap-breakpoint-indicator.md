# vue-bootstrap-breakpoint-indicator

> 标签: bootstrap, breakpoint, debugging, indicator, responsive, vue

## 简介

A Vue component that displays an indicator of the current Bootstrap breakpoint (e.g. XS, SM, MD, LG or XL).
