# vue-rem

> 标签: JavaScript

## 简介

插件说明: 本插件的主要目的在于将设计稿尺寸完美的在设备上复现.   使我们在开发时只用关注于设计稿,不用对不同的屏幕尺寸的设备做过多的关注.   和阿里的lib-flexible有类似之处,不过简化和新增了一些在vue上能直接使用的接口
