# vali-storages

> 标签: AES, AES-GCM, TTL, browser-storage, cross-tab, encryption, expiration, localStorage, namespace, prefix, sessionStorage, sliding-expiration, storage, typed-storage, typescript

## 简介

TypeScript browser storage library with AES-GCM encryption, TTL expiration, namespacing, cross-tab sync, batch operations, and a fully type-safe API.
