# vite-plugin-element-plus-optimize-deps

> 标签: element-plus, optimize-deps, plugin, vite

## 简介

A Vite plugin that checks for version mismatches between your package.json and installed dependencies, ensuring consistency across development environments and preventing version-related issues.
