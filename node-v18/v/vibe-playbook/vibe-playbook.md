# vibe-playbook

> 标签: agent, ai, claude, claude-code, llm, playbook, scaffold, template, vibe-coding, workflow

## 简介

Vibe-coding playbook for Claude Code — methodology + two ready-to-copy project templates: orchestrated (multi-session, for software developers) and solo (single session + subagents, for vibe coders), with human gates, living-docs, and enforcement hooks.
