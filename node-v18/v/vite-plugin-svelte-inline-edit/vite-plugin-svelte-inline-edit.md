# vite-plugin-svelte-inline-edit

> 标签: contenteditable, devtools, dx, inline-edit, svelte, sveltekit, visual-editing, vite, vite-plugin

## 简介

Edit text in the browser and have it written back to your .svelte source. No agent, no CMS — the compiler records where each string lives and the dev server splices the file.
