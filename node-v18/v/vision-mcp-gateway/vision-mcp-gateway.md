# vision-mcp-gateway

> 标签: JavaScript

## 简介

MCP server exposing a local/remote OpenAI-compatible vision model (e.g. oMLX Qwen2.5-VL) as describe_image tool. stdio transport, works with npx in supergateway.

## 官网

- npm 页面：https://www.npmjs.com/package/vision-mcp-gateway

- npm registry：https://registry.npmjs.org/vision-mcp-gateway
