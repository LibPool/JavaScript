# vecstore-js

> 标签: ai, browser, client-side, database, embeddings, hnsw, indexeddb, machine learning, semantic search, typescript, vector, vector search

## 简介

A pluggable, browser-native vector database using IndexedDB with support for HNSW and local embeddings.
