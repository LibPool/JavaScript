# vite-plugin-aliyun-oss

> 标签: aliyun, oss, plugin, rollup, vite-plugin

## 简介

在项目中引入此插件便可在打包时自动将打包后的js文件上传到阿里云oss上去，然后就可以进行CDN加速以及其他处理。
