# vue-jsonapi-orm

> 标签: eloquent, json:api, jsonapi, orm, vue, vuex, vuex-orm

## 简介

Vue + Vuex ORM and client for any json:api server. Highly inspired by Laravel Eloquent and optimized for large project use cases.
