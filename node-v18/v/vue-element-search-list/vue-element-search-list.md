# vue-element-search-list

> 标签: JavaScript

## 简介

基于 Vue 3 + Element Plus 的高封装搜索列表组件，集成了搜索栏、表格、分页和操作栏。通过配置化方式快速生成列表页，支持丰富的自定义插槽和事件回调。
