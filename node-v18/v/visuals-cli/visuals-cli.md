# visuals-cli

> 标签: claude-code-skill, document-parsing, mineru, ocr, qwen, text-only-llm, vision

## 简介

Eyes for text-only LLMs — see images (Qwen3-VL-Plus, 10-dimension description) and parse documents (MinerU precision, tables/formulas preserved) from the command line. No MCP, no Claude Code dependency.
