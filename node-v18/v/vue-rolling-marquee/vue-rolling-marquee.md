# vue-rolling-marquee

> 标签: auto roll, auto roll marquee, marquee, rolling, vue, vue2

## 简介

这是一个Vue组件，提供一个自动滚动的字幕(跑马灯)。This is a Vue component that provides an auto-scrolling marquee.
