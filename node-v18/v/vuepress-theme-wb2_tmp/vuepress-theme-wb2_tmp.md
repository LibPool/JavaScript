# vuepress-theme-wb2_tmp

> 标签: docs, documentation, dynamic layout, multilanguage, rtl, vuepress-theme, vuepress-theme-wbc, vuepress2, wbc

## 简介

A custom VuePress 2 theme featuring WBC components for a seamless documentation experience. It provides dynamic layouts, multi-language, and RTL/LTR support, all controlled via configuration.
