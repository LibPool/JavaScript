# vue-email-personaliser

> 标签: CSV Editor, Email sender, TSV Editor, TailwindCss, Vue Js

## 简介

Vue Web Component for formatting email message based on CSV file content. An example of a backend (Laravel package) using this package is at https://github.com/damms005/laravel-personalised-email-sender
