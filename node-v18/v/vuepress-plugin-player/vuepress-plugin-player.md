# vuepress-plugin-player

> 标签: blog-theme, theme-plugin, vuepress, vuepress-plugin, vuepress-plugin-music, vuepress-plugin-player, vuepress-theme

## 简介

这是vuepress2版本的一个音乐播放器插件，支持本地歌曲和网易云歌曲，提供单曲顺序播放，随机播放等功能

- 源码仓库：git+https://github.com/vuepress-aurora/vuepress-plugin-music-player.git
