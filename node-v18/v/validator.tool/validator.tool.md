# validator.tool

> 标签: assert, sanitisation, sanitise, sanitization, sanitize, validate, validation, validator, validator.js, validator.tool

## 简介

Lightweight JavaScript form validation, that had minimal configuration and felt natural to use. No dependencies, support UMD.
