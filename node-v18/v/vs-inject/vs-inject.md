# vs-inject

> 标签: container, decorators, dependency-injection, di, inversion-of-control, ioc, typescript

## 简介

Minimal typed dependency-injection container for TypeScript: tokens as parameter decorators, lazy singletons, circular-dependency detection. Zero dependencies.
