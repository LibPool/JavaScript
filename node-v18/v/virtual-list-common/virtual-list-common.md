# virtual-list-common

> 标签: big-data, dom-pool, dynamic-height, framework-agnostic, grouping, horizontal-scroll, infinite-scroll, lazy-load, masonry, react, typescript, virtual-list, virtual-scroll, virtualization, vue, windowing

## 简介

A Vue and React universal virtual list for efficiently rendering large lists with large data, only rendering elements in the visible area and reusing DOM.
