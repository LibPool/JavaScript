# vue-use-wake-lock

> 标签: prevent-sleep, screen-wake-lock-api, typescript, vue, vue3, wake, wake-lock

## 简介

useWakeLock is the lightweight Vue 3 hook for managing the Wake Lock API — prevents your device from going to sleep.
