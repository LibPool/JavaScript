# vue-permission-demo

> 标签: JavaScript

## 简介

路由权限的业务     1.定义好全部的路由地址     2.通过用户不同像后台请求不同的用户权限数据     3.对用户权限做对比：请求数据 == 全部的路由  取出来作为路由配置
