# vo-element

> 标签: JavaScript

## 简介

基于Vue3.2.4.1 + element-plus2.3.3 + vxe-table4.2.4-beta.1，快速搭建ERP通用界面架构的框架。 ## **特性** - 全局通用配置，支持预设一些全局统一参数； - 支持typeScript，完善的语法提示； - 组合式组件，支持单独使用界面架构内查询框、单选框、弹出表单、表格等组件； - 支持左侧树形、多标签页、单击表格列跳转等多表联动功能； - 支持将数据表通过定义模型(models)管理搭配使用； - 字典自动读取，字典的读取方式只
