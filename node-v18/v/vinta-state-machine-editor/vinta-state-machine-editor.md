# vinta-state-machine-editor

> 标签: canvas, custom-element, editor, state-machine, typescript, web-component

## 简介

Framework-agnostic Web Component to create, edit and visualize state machines on a pan/zoom canvas, with ordered side effects and JSON parameters.
