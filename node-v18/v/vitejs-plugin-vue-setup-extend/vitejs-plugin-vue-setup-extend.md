> 标签: inheritAttrs, name, script-setup, vite, vite-plugin-vue-setup-extend, vitejs-plugin-vue-setup-extend, vue, vue-setup-extend, vue3

## 简介

为 Vue 3 `<script setup>` 语法扩展支持定义组件的 `name` 和 `inheritAttrs` 属性的 Vite 插件。
