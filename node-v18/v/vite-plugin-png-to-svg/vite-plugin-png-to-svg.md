# vite-plugin-png-to-svg

> 标签: png, png转换svg, react, svg, vite, vue3

## 简介

一款基于NodeJs的Png图片转换Svg格式的Vite插件，可将Png小图标转换为Svg，从而更好的适应页面的需求，可有效减少服务器接收和发送请求，提高页面加载速度。支持Vue、React等所有框架
