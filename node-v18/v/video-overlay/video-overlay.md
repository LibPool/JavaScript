# video-overlay

> 标签: JavaScript

## 简介

A plugin to display simple overlays for HTML5 video - similar to YouTube's "Annotations" feature in appearance - during video playback.  This is based on the video.js overlay plugin developed by Brightcove - [videojs-overlay](https://github.com/brightcove
