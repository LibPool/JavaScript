# vue-dialog-instance

> 标签: dialog, instance, vue

## 简介

统一注册，可在页面任何地方通过注册时的 key ，获取到 dialog 组件实例。继而就可以对 dialog 进行任何操作。dialog组件只会实例化一次，意味着每一次用 this.$dialogs.dialogName.open() 打开的dialog都是同一个。
