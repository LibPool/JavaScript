# v-lazy-load-img

> 标签: JavaScript

## 简介

- RENDER_SIZE   渲染图片并发个数 - MAX_LENGTH    图片src缓存个数 - IMG_LOAD_SRC  加载中的图片 - IMG_LOAD_BEFORE_SRC   加载前的图片 - IMG_LOAD_ERROR_SRC    加载失败的图片
