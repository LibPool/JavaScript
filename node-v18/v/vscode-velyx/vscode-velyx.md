# vscode-velyx

> 标签: compiler, florynx, frontend, reactive, signals, velyx, vx

## 简介

Official VS Code extension for VELYX .vx Single-File Components. Syntax highlighting, file icons, snippets and hover information for the VELYX compiler-first reactive framework.
