# videojs-quality-hls-selector

> 标签: videojs, videojs-plugin

## 简介

This is copy of existing package videojs-hls-quality-selector by Chris Boustead with 1 feature added to specify default quality to options. Adds a quality selector menu for HLS sources played in videojs.
