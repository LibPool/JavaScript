# virtualsms-sdk

> 标签: 2fa, account-verification, ai-agents, mcp, otp, phone-verification, sms-api, sms-verification, typescript-sdk, virtual-number

## 简介

Official Node.js and TypeScript SDK for the VirtualSMS API: SMS verification, number rentals, and matching-country proxies on real carrier-issued mobile numbers (not VoIP), across 2500+ services in 145+ countries.
