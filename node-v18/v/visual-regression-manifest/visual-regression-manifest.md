# visual-regression-manifest

> 标签: CTRF, Cypress, JSON schema, Playwright, image diff, run manifest, screenshot testing, test report, visual diff, visual regression testing

## 简介

The visual regression run manifest: one JSON file per test run listing every screenshot comparison, built upon CTRF. JSON Schema, TypeScript types, reader, writer, merger and converters (CTRF, Playwright JSON report, plain image triples) for a runner-agno
