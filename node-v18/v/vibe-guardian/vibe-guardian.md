# vibe-guardian

> 标签: ai-code-security, ai-generated-code, api-key-leak, claude-code, claude-code-plugin, cursor, git-hooks, hardcoded-secrets, lovable, pre-commit, rls, sast, secret-scanning, secrets-detection, security, security-scanner, sql-injection, static-analysis, supabase, vibe-coding, xss

## 简介

Pre-commit security gate for vibe coding — blocks hardcoded API keys, SQL injection, XSS, and Supabase RLS misconfigurations in AI-generated code (Cursor / Claude Code / Lovable). 100% local static rules, no LLM calls, zero dependencies.
