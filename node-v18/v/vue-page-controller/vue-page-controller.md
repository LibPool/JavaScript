# vue-page-controller

> 标签: JavaScript

## 简介

**解决问题** * 页面前进（暂存、创建）、后退（销毁、复用）、替换时，组件实例能按栈数据结构做创建、销毁 * keep-alive 组件复用为堆数据结构，且只能按组件复用 * vue-router 页面之间无法传递对象及函数参数
