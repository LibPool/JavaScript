# vue3-popup-layer

> 标签: popup-layer, vue-popup, vue3-popup, vue3-popup-layer

## 简介

用于创建一个可以弹出的弹窗页面或者组件,组合式函数实现了弹窗的核心逻辑,包括打开/关闭、历史状态管理、z-index 自动获取等功能,提供了一个功能完备的弹窗解决方案
