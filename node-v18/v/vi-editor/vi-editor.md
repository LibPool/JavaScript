# vi-editor

> 标签: JavaScript

## 简介

A fully custom, from-scratch WYSIWYG rich text editor built for Vue 3 using the Composition API (`<script setup>`). It depends entirely on vanilla DOM `contenteditable` and the standard Selection API, without relying on external heavy rich-text libraries
