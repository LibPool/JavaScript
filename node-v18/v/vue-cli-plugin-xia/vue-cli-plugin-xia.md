# vue-cli-plugin-xia

> 标签: JavaScript

## 简介

这是[宁皓网](https://ninghao.net)内部项目使用的一个 Vue CLI 插件，在使用了 TypeScript 的 Vue 项目里，可以用命令生成应用需要的组件与 store 模块。

## 官网

- npm 页面：https://www.npmjs.com/package/vue-cli-plugin-xia

## 历史版本号

- 当前版本：1.0.0

- 1.0.0

## 获取地址

- npm 安装：`npm install vue-cli-plugin-xia`
- npm registry：https://registry.npmjs.org/vue-cli-plugin-xia
