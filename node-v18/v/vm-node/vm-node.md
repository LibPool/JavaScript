# vm-node

> 标签: JavaScript

## 简介

`vm-node` 是一款Node端代码沙箱，在`vm2`的基础上，额外解决了代码死循环、各类异常捕获等问题，沙箱内能`共享`所处运行环境的node_module中已安装的包
