# vue-image-label

> 标签: JavaScript

## 简介

Vue 图片内容标记组件，用于圈出图片四边形内容并获取标记点坐标。**React**版本请参考组件[image-label](https://github.com/nhdeng/image-label)

## 官网

- npm 页面：https://www.npmjs.com/package/vue-image-label

- 1.0.0
