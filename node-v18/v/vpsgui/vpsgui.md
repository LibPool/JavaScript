# vpsgui

> 标签: api-client, cli, command-line, devops, docker, infrastructure, linux, monitoring, sdk, server, ssh, telemetry, terminal, vps, vpsgui

## 简介

Official CLI and Node.js/TypeScript SDK for the VPSGUI agent - sign in to a host, read telemetry, run commands, and drive Docker, files, firewall, secrets and backups.
