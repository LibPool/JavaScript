# vir-lang

> 标签: compiler, jit, programming-language, vietnamese, vir, virgori, vm

## 简介

Vir Programming Language — Multilingual syntax (VI/EN/ZH/JA/KO), Q-IR VM, JIT, self-patching binary, SIMD native core. Includes Virgex pattern matching engine.
