# volaro

> 标签: agent, ai, codegen, compiler, language, volaro

## 简介

Volaro — an application language written to be authored by an AI agent and read by a person. Ships the language reference and a working compiler for a supported subset (volaro check / build / dev). CLI: `volaro` (alias `vl`).
