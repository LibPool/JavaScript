# vuepress-cqy

> 标签: anime-blog, blog, blog-theme, theme, vue, vuepress, vuepress-theme, vuepress-theme-ccds

## 简介

This is an anime blog theme based on vuepress, the theme is simple, colorful, versatile, and supports customization, providing multiple components to set the theme
这是一个基于vuepress的动漫类型主题，简洁，界面漂亮，多色彩，多自定义，多功能，海报分享，相册等等，满足你搭建博客的一切需要
