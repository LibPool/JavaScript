# vscode-islstudio

> 标签: ai-safety, auth, code review, gate, javascript, linter, pii, pull request, security, truthpack, typescript, vibecheck

## 简介

Unified code gate. Truthpack validation (routes, env, imports) + 25 security rules (auth, pii, payments, rate-limit, intent). SHIP or NO_SHIP with evidence.
