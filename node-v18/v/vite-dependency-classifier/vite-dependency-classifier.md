# vite-dependency-classifier

> 标签: audit, bundle, ci, classification, cli, dependencies, devDependencies, package.json, production, vite

## 简介

Check that a Vite project's dependencies/devDependencies split matches what the production build actually contains, and that production source does not import an undeclared package.
