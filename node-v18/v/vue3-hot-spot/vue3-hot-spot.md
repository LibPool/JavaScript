# vue3-hot-spot

> 标签: hotspots, vue, vue-hotspots, vue3, vue3-hot-spot

## 简介

A simple vue3 library for creating hotspots with adaptive and fully customizable hints. ## Getting started ### Installation First step is to install it using npm ```  npm i vue3-hot-spot ```
