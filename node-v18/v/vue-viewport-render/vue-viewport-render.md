# vue-viewport-render

> 标签: deferred-render, intersection-observer, lazy-load, lazy-render, performance, viewport, vue, vue3

## 简介

Vue 3 component that mounts content on viewport entry and exposes live visibility, so off-screen work can be gated at the data source.
