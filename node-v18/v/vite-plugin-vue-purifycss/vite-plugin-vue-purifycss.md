# vite-plugin-vue-purifycss

> 标签: css, js, less, purifycss, scss, ts, vite, vue, 样式按需打包

## 简介

一个支持vue的css样式引入文件(包括css和scss和less文件)按需打包vite插件(现已可以自动按需打包vue文件中的style标签下已使用的样式)
