# v-resize-cmu

> 标签: JavaScript

## 简介

1. npm init 2. tsc init => 生成tsconfig.json (tsc 如果是无效命令，需要npm i -g typescript) 3. vite.config.ts 4. npm i vue -D : 这个项目一定是给vue使用的，所以不需要在安装插件的时候再安装一遍vue， -D devdependence 5. npm i vite -D
