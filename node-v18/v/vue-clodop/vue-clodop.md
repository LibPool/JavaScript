# vue-clodop

> 标签: JavaScript

## 简介

A web printer component which is based on CLODOP, so before you begin to use this component, you must make sure that the CLODOP is installed on you computer.

## 官网

- 源码仓库：https://gitee.com/lining-whu/vue-clodop.git
- npm 页面：https://www.npmjs.com/package/vue-clodop
