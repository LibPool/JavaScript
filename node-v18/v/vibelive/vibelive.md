# vibelive

> 标签: claude-code, cli, codex, local-first, mcp, multiplayer, terminal, vibe-suite, vibelive

## 简介

Multiplayer for agentic coding terminals — shared Claude Code/Codex/Gemini sessions with live cursors, presence, and in-terminal chat. Local-first, e2e, self-hostable relay.
