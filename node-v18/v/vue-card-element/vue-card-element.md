# vue-card-element

> 标签: business card, card, flipping card, info box, info card, vue, vue 2, vue.js

## 简介

vue-card-element is a Vue component to create a multipurpose card. vue-card-element has many options and can be used in different situations like: - dashboard statistic information - business card - product card
