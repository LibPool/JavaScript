# vue-plugins-pxtorem

> 标签: JavaScript

## 简介

1. `main.ts`中引入 ``` typescript import { createApp } from "vue"; import pxToRem from "vue-plugins-pxtorem" import App from "./App.vue"; const app = createApp(App); app.use(pxToRem) ``` 2. 参数说明 `pxToRem(options)`接受一个对象 * `rootValue`:根节点字体大小,默认16px
