# vocabflow

> 标签: JavaScript

## 简介

在终端中复习单词的 CLI 工具，基于间隔重复算法 (SM-2)。搭配 [VocabFlow](https://vocab.now) 网页端使用，在命令行中高效复习你的生词本。
