# vite-plugin-fonts-auto

> 标签: fonts, plugin, preload, tailwind, vite, woff2

## 简介

Плагин для Vite: автоматическая конвертация шрифтов в WOFF/WOFF2, добавление подключения в preload, css и Tailwind @theme
