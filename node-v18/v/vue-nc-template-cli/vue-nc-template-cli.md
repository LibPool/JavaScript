# vue-nc-template-cli

> 标签: JavaScript

## 简介

这是一个基于Vue3.0 + ts + vue-router + pinia 的前端项目工程模版，用于快速搭建前端项目。 ## 项目介绍 该项目是基于vue3.0的前端工程模版，包含了前端常用的约定规范，以及一些常用的工具库，方便开发者快速开发项目。 ## 前端规范 ESLint  | js/ts代码规范
