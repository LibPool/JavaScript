# visinvue

> 标签: vis, visjs, vue

## 简介

> Vue2 component that helps with <a href="http://visjs.org/">Visjs</a> interaction. This is a fork of the [vis2vue](https://github.com/alexcode/vue2vis) and https://www.npmjs.com/package/vue-visjs  Network module only, without Graph2d and Timeline
