# v-electron-windows

> 标签: JavaScript

## 简介

增强 Electron 窗口管理能力。主要功能有记录窗口状态，为每个窗口增加自定义数据记录等功能。

## 官网

- npm 页面：https://www.npmjs.com/package/v-electron-windows
