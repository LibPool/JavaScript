# vtit-core-dynamic-form

> 标签: JavaScript

## 简介

Thư viện Angular tạo form động, hỗ trợ các loại input: Text, Password, Checkbox. Dễ dàng mở rộng, tích hợp PrimeNG, truyền validators, custom template, chia nhóm/cột.
