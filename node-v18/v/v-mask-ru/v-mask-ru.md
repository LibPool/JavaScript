# v-mask-ru

> 标签: v-mask, v-mask-ru, v-mask-rus, v-mask-russian, vue, vue-mask, vue.js

## 简介

Tiny input mask library for Vue.js based on text-mask-core (~4kb) exposed as directive. No dependencies (with support russian language)
