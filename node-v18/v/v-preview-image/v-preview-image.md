# v-preview-image

> 标签: image, preview, vue, vue-preview, vue-preview-image, vue2, vue3

## 简介

一个基于vue3的图片预览插件，可以缩放图片，移动图片，旋转图片，目前只支持pc端。

## 官网

- 官网：https://github.com/zhangchuqiang/v-preview-image
- npm 页面：https://www.npmjs.com/package/v-preview-image
