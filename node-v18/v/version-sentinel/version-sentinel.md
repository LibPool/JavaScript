# version-sentinel

> 标签: checker, typescript, update, version, web

## 简介

一个轻量级的版本检查工具,用于检测Web应用是否有新版本。支持多种版本比较策略(ETag、Last-Modified、自定义),提供完整的事件系统和错误重试机制。
