# vuex-common-mutations

> 标签: mutautions, vuex, vuex-mutations

## 简介

It's a vuex mutations generator which we use commonly to make changes in state like set a state value, push, update, delete a item in an array, reset the whole state. Using this package you don't have to write any mutations to make changes in state it has
