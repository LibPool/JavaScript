# vue-vantext

> 标签: JavaScript

## 简介

建立vue组件步骤 1. npm init 2. 复制 package.json  npm i 3. .npmignore  建立 src dist 4. 建立index.js  及组件文件 5. npm run build 6. npm publish    直接在根目录发布
