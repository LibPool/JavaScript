# vitrio

> 标签: chromatic-aberration, displacement-map, effect, feDisplacementMap, frosted-glass, glassmorphism, lens, liquid-glass, react, refraction, svg-filter, ui, vue, web-component

## 简介

Cross-browser liquid-glass refraction (Chrome / Safari / Firefox). Real optical displacement with magnification, chromatic aberration and a normal-based specular highlight. Zero dependencies. JS class + <liquid-glass> web component + React/Vue wrappers.
