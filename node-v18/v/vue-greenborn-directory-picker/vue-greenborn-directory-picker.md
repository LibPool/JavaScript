# vue-greenborn-directory-picker

> 标签: directory, directory-picker, filesystem, folder-picker, greenborn, tree-view, vue, vue3

## 简介

Selector de directorios para Vue 3 sobre vue-greenborn-tree-view: navega el árbol de carpetas que devuelve una función `cargarDirectorios(nodoPadre)` provista por el consumidor (vía API, IPC, etc.) y permite elegir una ruta. No asume ningún backend concre
