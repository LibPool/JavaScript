# vite-plugin-refresh

> 标签: dependencies, hmr, plugin, refresh, reload, vite, vite-plugin, vitejs, watch

## 简介

Enhances the Vite dev server by adding dependencies to the watcher, and optionally doing full page reloads on changes.
