# vite-svg-sprite-compose

> 标签: combine, merge, optimize, sprite, svg, svgo, vite

## 简介

Vite SVG Sprite Merge Plugin is a Vite plugin that simplifies and automates the merging of multiple SVG icons into a single sprite. It allows you to combine SVG icons from various directories, apply optional SVGO optimization, and generate a unified SVG s
