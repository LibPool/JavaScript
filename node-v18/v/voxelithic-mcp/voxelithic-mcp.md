# voxelithic-mcp

> 标签: agents, dex-aggregator, mcp, model-context-protocol, robinhood-chain, tokenized-equities

## 简介

MCP server for Voxelithic on Robinhood Chain: quote, route, build unsigned swaps, verify fills and read the buyback
