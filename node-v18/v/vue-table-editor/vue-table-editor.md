# vue-table-editor

> 标签: datatable, infinite-scroll, lazy-loading, table, table-editor, vue, vue3

## 简介

Tabla genérica reutilizable y autocontenida para Vue 3: redimensionable, reordenable, preferencias de columnas, lazy loading server-side, edición inline, CSV export, paginación e infinite scroll. Sin dependencias de UI (CSS propio, iconos SVG embebidos).
