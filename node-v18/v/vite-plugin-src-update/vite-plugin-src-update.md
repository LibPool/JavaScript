# vite-plugin-src-update

> 标签: vite, vite-plugin

## 简介

`vite-plugin-src-update` is a Vite plugin that automatically updates a template file with development or production script tags for your project assets, ensuring the correct scripts are loaded depending on your build environment. It supports configuration
