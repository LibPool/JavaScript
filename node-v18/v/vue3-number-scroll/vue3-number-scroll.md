# vue3-number-scroll

> 标签: JavaScript

## 简介

​	**该组件用于创建具有动画效果的数字显示，可以配置起始值、结束值、动画持续时间等属性。** ​	**它是基于 vue-count-to 升级改造,由于  [vue-count-to](https://panjiachen.github.io/countTo "原仓库地址") 不支持vue3,以及长时间没有更新的原因,我在项目中的大屏项目需要使用,所以顺便升级维护一下。**
