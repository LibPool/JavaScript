# vue-axios-optimize

> 标签: axios, vue, vue2, vue3

## 简介

vue项目对axios请求的优化，实现精准控制全局加载动画，轻松实现重复请求时取消前面的请求或者阻止后面的请求，实现接口数据缓存，自主可中断请求，超时重发请求，最大高并发请求数量控制等
