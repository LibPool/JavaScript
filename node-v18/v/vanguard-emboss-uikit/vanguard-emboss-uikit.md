# vanguard-emboss-uikit

> 标签: components, design-system, emboss, neumorphism, radix-ui, react, soft-ui, tailwindcss, typescript, ui-kit

## 简介

Premium neumorphic (soft UI) React component library with 45° light-source emboss effects. Built with Radix UI primitives and Tailwind CSS.
