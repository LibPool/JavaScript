# vite-plugin-eruda-local

> 标签: JavaScript

## 简介

> 帮助你在开发环境自动打开 eruda 调试工具的vite插件，eruda从本地加载，不影响刷新后页面加载速度。

## 官网

- 源码仓库：https://gitee.com/thesadboy/vite-plugin-eruda-local
- npm 页面：https://www.npmjs.com/package/vite-plugin-eruda-local
