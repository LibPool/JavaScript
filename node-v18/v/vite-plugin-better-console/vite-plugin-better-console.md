# vite-plugin-better-console

> 标签: console, debug, development, logger, logging, typescript, vite, vite-plugin

## 简介

Zero-dependency Vite plugin for beautiful dev-only console logging. Grouped output, caller detection, log levels, TypeScript support — silent in production.
