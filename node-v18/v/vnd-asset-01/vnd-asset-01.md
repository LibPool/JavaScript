# vnd-asset-01

> 标签: JavaScript

## 简介

Este é um plugin responsável por adicionar funcionalidades personalizadas ao serviço de asset no GSeller Vendure. Agora você pode associar os assets diretamente a usuários e acessar essas funcionalidades extras conforme necessário
