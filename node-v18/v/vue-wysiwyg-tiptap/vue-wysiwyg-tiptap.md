# vue-wysiwyg-tiptap

> 标签: editor, headless, markdown, mentions, rich-text, slash-commands, tiptap, vue, vue3, wysiwyg

## 简介

Headless WYSIWYG editor for Vue 3 built on Tiptap 3, with slash commands, mentions, AI assist, and markdown paste.
