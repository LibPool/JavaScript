# vue-tel-num-input

> 标签: phone-input, tel-input, telephone-input, vue, vue-component, vue-tel-num-input, vue3, vue3-component, vue3-phone-input, vue3-tel-input, vue3-tel-num-input, vue3-telephone-input, vue3-telnum-input

## 简介

A flexible and fully customizable Vue 3 component for phone number input with country code selection, flags, masking, and localization.
