# vue-sketch-svg

> 标签: hand-drawn, roughjs, sketch, svg, vue

## 简介

Wraps svg2roughjs in a Vue component to easily embed SVGs as sketchy, hand-drawn SVGs.

- npm 页面：https://www.npmjs.com/package/vue-sketch-svg
