# vysk

> 标签: build-tools, cli, image-compression, image-converter, image-optimization, image-optimizer, jpeg-to-webp, nextjs, npm, png-to-webp, react, rust, vysk, web-performance, webp

## 简介

Rust-powered image optimization CLI for any web project. Convert PNG and JPEG to WebP, cache results, and safely update image references. Install via npm, no Rust required.
