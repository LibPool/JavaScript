# @hadron-memory/distri-machine

> 标签: ab, ab-testing, bucketing, distribution, experiment, feature-flag, jsonlogic, randomization, traffic-split

## 简介

A small traffic-bucketing library for A/B testing: fraction-balanced or JsonLogic-filter assignment, with host-owned state.
