# blackout-mcp

> 标签: agents, crusoe, exactly-once, idempotency, mcp, model-context-protocol, nemotron, reliability

## 简介

Exactly-once side effects for AI agents: an MCP gateway that journals every action before it runs, suppresses repeats, and reconciles from receipts after a crash. Plus the full Blackout runtime (frozen definition of done, code-only verifier).
