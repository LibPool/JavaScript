# @hyxf/code2md

> 标签: chatgpt, claude, cli, code2md, codebase, llm, markdown, prompt

## 简介

A modern CLI tool to convert your codebase into a single Markdown file for LLM prompts (ChatGPT, Claude, DeepSeek).
