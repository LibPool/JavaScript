> 标签: claude, claude-code, claude-desktop, cursor, fiuto, mcp, model-context-protocol, stdio, user-research

## 简介

Local stdio MCP server for Fiuto — exposes study CRUD, traces, and export to MCP-capable clients (Claude Code, Claude Desktop, Cursor).
