# @upst/iframe-funding-form

> 标签: JavaScript

## 简介

Upstart's `@upst/iframe-funding-form` SDK enables partners to embed Upstart's funding form on to their own sites via an iFrame. Partners will simply call this clientside SDK to open offer URLs.
