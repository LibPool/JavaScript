# @apiratorjs/async-context

> 标签: async hooks, async propagation, async-context, context management, context merging, context overriding, execution context, nodejs, per-request, state propagation, typescript

## 简介

A Node.js async context library leveraging the node:async_hooks module, supporting context merging and overriding.
