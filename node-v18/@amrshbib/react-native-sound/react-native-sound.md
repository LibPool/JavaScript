# @amrshbib/react-native-sound

> 标签: android, click, feedback, ios, keypress, react-native, sound, sound-effect, sounds, system-sound, tick, ui-sounds

## 简介

Semantic UI sounds for React Native. The system's own keyboard and feedback sounds, named for what happened — a tick, an untick, a refusal. No audio files, no audio session, no bundle weight.
