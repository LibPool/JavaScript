# @hevcjs/shaka-plugin

> 标签: browser, codec, dash, h.265, h265, hevc, hls, media-source-extensions, mediasource, mse, ott, shaka, shaka-player, shaka-plugin, streaming, transmuxer, video, wasm, webassembly

## 简介

Shaka Player plugin for HEVC/H.265 playback — registers a Shaka Transmuxer that decodes HEVC streams via @hevcjs/core
