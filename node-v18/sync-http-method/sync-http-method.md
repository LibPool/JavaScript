# sync-http-method

> 标签: atomic, braid, catch-up, cdn, consistency, delta, http, http-method, json-patch, live-updates, merge-patch, multipart, offline, query, rest, server-sent-events, sse, sync, synchronization, transactions

## 简介

Keep many HTTP resources in sync with QUERY: per-resource patches for any media type, consistent snapshots, live watches, atomic multi-resource writes, and catch-up that shared caches can serve.
