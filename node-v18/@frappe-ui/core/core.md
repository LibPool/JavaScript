# @frappe-ui/core

> 标签: components, design-system, frappe, frappe-ui, headless, tailwind, ui

## 简介

Unofficial community port — Framework-free heart of frappe-ui-universal: class recipes, headless behaviour controllers, DOM helpers and icons. No framework dependency.
