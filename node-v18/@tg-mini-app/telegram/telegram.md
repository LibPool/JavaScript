# @tg-mini-app/telegram

> 标签: bot-api, mini-app, react, telegram, webapp

## 简介

Typed React bridge for the Telegram Mini Apps WebApp API (Bot API 9.6) — provider, back-button queue, native buttons, storage, capabilities, sensors, layout/theme.
