# @occa/gateway-claude-code

> 标签: ai-agents, anthropic, byort, claude, claude-code, gateway, occa

## 简介

Claude Gateway — a thin HTTP service that wraps the `claude` CLI so OCCA can run Claude Code agents on a box it does not own (BYORT).
