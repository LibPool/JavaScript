# @caohaitao/v-scroll-bar

> 标签: JavaScript

## 简介

一个基于 Web Components 的轻量级自定义滚动条组件。使用 **Vite 7** 构建，利用 **Shadow DOM** 封装内部结构，支持通过 **Import Map** 或构建工具别名灵活切换主题。
