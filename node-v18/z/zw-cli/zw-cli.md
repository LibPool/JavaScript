# zw-cli

> 标签: JavaScript

## 简介

inquirer.js:     guide风格命令行开发工具：     guide风格的命令行，指 提问-回答 模式的命令行，inquirer.js支持常见的input输入,单选,多选,是/否等常见提问类型，并暴露了增加自定义类型的接口，参考官方文档很容易使用。
