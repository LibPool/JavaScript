# ziti-electron-fetch

> 标签: electron, fetch, http, nodejs, promise, ziti

## 简介

A module that intercepts all window.fetch calls in an Electron renderer process and routes them over a Ziti network

## 官网

- 官网：https://github.com/netfoundry/ziti-electron-fetch
- 源码仓库：git+https://github.com/netfoundry/node-fetch.git
