# zyw-aitools-manager

> 标签: ai, manager, nextjs, openai, pgvector, prisma, tools

## 简介

AI工具管理器 - 为Next.js项目提供AI工具管理和动态加载功能，添加了工具的创建、更新、删除、搜索等客户端功能，解决客户端导入服务器端工具的错误，继续优化客户端功能，添加分页搜索,参数去掉shape。自定义库取代@ai-sdk/react，解决swr问题,添加tool的模拟运行。添加一键生成工具。
