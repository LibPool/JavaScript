# zuripay

> 标签: JavaScript

## 简介

Node.js SDK for the ZuriPay Payment Gateway. This SDK simplifies integration with the ZuriPay API, providing a type-safe and validated interface for managing payments, customers, payouts, callbacks, payment links, and wallets.
