# zephyr-framework-mcp

> 标签: ai-agent, claude-desktop, mcp, model-context-protocol, ui-framework, web-components, zephyr

## 简介

MCP server for Zephyr Framework — expose Zephyr UI components as AI agent tools via the Model Context Protocol. Bridges MCP hosts (Claude Desktop, Cursor, etc.) to a browser running Zephyr components.
