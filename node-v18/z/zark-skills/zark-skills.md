# zark-skills

> 标签: ai-context, claude-code, dossie, frontend, presentations, scaffold, skills, zark

## 简介

ZARK Claude Code Skills Pack — 5 skills nativas (zark-skill, zark-dossie, zark-ensaios, zark-frontend, zark-slides) + dependências _shared. `npx zark-skills install` instala tudo (skills + copy-squad + brand) em ~/.claude/skills/. O zark-skill agora guia
