# zeitgeist-agents-mcp

> 标签: JavaScript

## 简介

A [Model Context Protocol](https://modelcontextprotocol.io) (MCP) server for [Zeitgeist Agents](https://zeitgeist-agents.com) — gives AI agents read-only access to your projects, digests, and research runs.
