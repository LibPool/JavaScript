# zhfix

> 标签: autocorrect, chinese, cjk, claude-code, claude-code-skill, html, markdown, punctuation, 全角, 半角

## 简介

Fix Chinese (CJK) punctuation in a single Markdown / HTML file via a Claude Code /zhfix skill — a thin wrapper on top of AutoCorrect.
