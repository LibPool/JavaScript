# zapier-dev-mcp

> 标签: automation, claude, developer-tools, integration, lint, mcp, mcp-server, model-context-protocol, zapier, zapier-platform

## 简介

MCP server for Zapier integration developers — inspect, lint, and validate zapier-platform-cli projects. Review-readiness checks for triggers, creates, searches, and auth.
