# zayra-format

> 标签: file-format, parser, registry, validator, zayra

## 简介

Official format engine for ZAYRA's custom file formats — parsing, validation, and conversion for .zs, .zcfg, .zproj, .zpkg, .zmod, .zplug, .zflow, .zagent, and .zmodel files.
