# zui-svg-icon

> 标签: icon, svg, 图标, 彩色, 换色

## 简介

一款适用于 uni-app 的 SVG 图标组件。全端适配：APP-Plus、小程序、H5。支持多色 SVG 图标；支持换色；支持 URI 和 Base64 格式；支持 spin 动画；SVG 优化
