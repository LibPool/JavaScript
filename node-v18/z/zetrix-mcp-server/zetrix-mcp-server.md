# zetrix-mcp-server

> 标签: ai, blockchain, claude, cryptocurrency, encryption, mcp, mcp-server, model-context-protocol, rpc, sdk, smart-contracts, web3, websocket, zetrix

## 简介

MCP server for Zetrix blockchain with 55 tools - HTTP RPC, WebSocket (protobuf), SDK transactions, Crypto, and smart contract development. Supports stdio and HTTP transport.
