# zhihuikeji-ui

> 标签: JavaScript

## 简介

1. 首先运行npm run changeset 生成更改文件 2. 然后运行npm run version 选择此次修改的版本 3. 在运行git add和commit常规操作 4. 最后运行npm run publish 发布到npm上
