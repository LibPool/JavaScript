# z-parser

> 标签: document, extraction, markdown, ocr, parser, pdf, rag

## 简介

Client SDK for the z-parser document extraction service — bytes in, RAG-ready Markdown out (PDF/OCR, Office, images, manuscripts, audio/video, EPUB, e-mail).
