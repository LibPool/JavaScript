# zi-toolkit-meta-package

> 标签: dependencies, meta-package, zi-toolkit

## 简介

This is a meta package for zi-toolkit. This meta-package simplifies depenndency management for zi-toolkit. Additionally to avoid network restrictions and ensure smooth package retrieval, this package routes fetching outside VPN-Zones.
