# zero-two-one

> 标签: ai-agents, claude-code, lifecycle, product-framework, spec-driven-development, speckit

## 简介

Zero Two One — an agentic product framework that takes new products from point 0 (idea) to point 1 (MVP) via project-level refinement loops and Spec Kit-driven feature delivery.
