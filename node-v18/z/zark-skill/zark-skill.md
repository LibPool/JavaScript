# zark-skill

> 标签: ai-context, claude-code, dossie, frontend, presentations, scaffold, skills, slides, zark

## 简介

Pacote de skills do Claude Code da ZARK. Instala 5 skills em ~/.claude/skills/ com um comando: zark-skill (projetos de site), zark-dossie (dossie de cliente), zark-ensaios (prompts de ensaio fotografico), zark-frontend (frontend anti-generico) e zark-slid
