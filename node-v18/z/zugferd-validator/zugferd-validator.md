# zugferd-validator

> 标签: cii, e-invoice, en16931, factur-x, invoice-validation, xrechnung, zugferd

## 简介

Parse and validate ZUGFeRD/Factur-X e-invoices (CII XML): profile detection, EN 16931 arithmetic checks, IBAN validation. Framework-free, no DOM dependency.
