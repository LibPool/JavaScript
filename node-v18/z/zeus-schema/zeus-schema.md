# zeus-schema

> 标签: ajv, json, json-schema, json-schema-faker, json-schema-validator, jsonschema, schema, validator

## 简介

这是一个Schema工具库，实现链式调用方式快捷生成schema对象并集成ajv验证和json-schema-faker进行数据模拟，更多功能还在挖掘中...
