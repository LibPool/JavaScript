# zod-wretch

> 标签: JavaScript

## 简介

`zod-wretch` is a small utility library for [elbywan/wretch](https://github.com/elbywan/wretch/tree/master) to bring in first-class support for [zod](https://github.com/colinhacks/zod) schema validation.
