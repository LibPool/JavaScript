# zlb-node-sdk

> 标签: JavaScript

## 简介

众乐邦node-sdk，用于客户直接调用众乐邦后台接口，有以下便利 + npm引入即可调用，可用于node项目的api开发和前端项目的接口调用 + sdk内部处理http调用，客户只需调用接口函数，省去客户的http调用 + sdk内部处理加密解密操作，客户只需要传入加密参数即可 + 简化api参数的调用
