# zenwit-plugin-mochi

> 标签: desktop-pet, mochi, writing-companion, zenwit, zenwit-plugin

## 简介

Mochi：常驻工作区的创作伙伴。跟随写作节奏变换表情，用头顶气泡提示当前进度，可拖拽、可记忆位置。
