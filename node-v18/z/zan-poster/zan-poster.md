# zan-poster

> 标签: canvas, cax, component, json2canvas, miniprogram poster, poster, weapp, web, web component

## 简介

通过json在canvas上绘制图像, 基于cax画图框架开发, 本画图组件是json2canvas库的改造、优化版本 (详情查看README.md文档末说明)。
