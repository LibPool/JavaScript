# z-vue-swipe

> 标签: JavaScript

## 简介

> 这个vue组件实现了横向和垂直方向的无缝滚动，常见的场景如：banner切换（横向），公告切换（纵向）。 #### 使用方法 > 目前实现功能较为简单，只有定时滚动
