# zwift-api

> 标签: api, api-client, cycling, fitness, indoor-cycling, protobuf, reverse-engineered, unofficial, zwift

## 简介

Unofficial, read-only Node client and data model for Zwift's undocumented API: auth, profile, achievements, events, quests, and the public game catalogue. Zero dependencies.
