# zynitex-core

> 标签: id-generator, prisma, sequence, typescript, uin, unique-id

## 简介

Reusable, framework-independent building blocks for Zynitex Node.js + TypeScript + Prisma projects. First feature: configurable UIN (Unique Identification Number) generator.
