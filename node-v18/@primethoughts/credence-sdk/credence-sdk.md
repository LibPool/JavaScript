# @primethoughts/credence-sdk

> 标签: credence, did, sdk, ssi, trust-os, verifiable-credentials

## 简介

TypeScript SDK for Credence Trust OS — typed client for 150+ gateway endpoints covering W3C VCs, OID4VCI/OID4VP, DIDComm, Trust Registry, billing, and DPP lifecycle
