# @cofcoai/ui

> 标签: cofco, components, design-system, react, scaffold, tailwind

## 简介

COFCO design-system scaffold. `npx @cofcoai/ui` copies the React + Tailwind components, the design skill, and the rules straight into your project — no dependency, no build.
