# @magic-seven-ai/magic-seven-mcp

> 标签: ai, claude, magic-seven, mcp, stdio, video-editor

## 简介

MCP stdio bridge for the Magic Seven desktop video editor. Launches the app if needed and proxies MCP traffic over stdio.
