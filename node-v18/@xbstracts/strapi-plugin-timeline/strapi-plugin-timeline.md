# @xbstracts/strapi-plugin-timeline

> 标签: audit-log, content-versioning, history, restore, strapi, strapi-plugin, strapi5, timeline, version-control

## 简介

Content history and version control plugin for Strapi 5. Track changes, browse history, compare diffs, and restore previous versions.
