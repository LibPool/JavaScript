# @82label/react

> 标签: barcode, korean, label, label-printer, print, qrcode, react

## 简介

React component for 82label: label preview and printing (roll labels, Formtec A4 sheets, barcodes, QR codes) with mm-accurate browser printing and silent printing through the 82label Windows agent.
