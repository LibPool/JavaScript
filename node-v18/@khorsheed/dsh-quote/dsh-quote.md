# @khorsheed/dsh-quote

> 标签: cordis, dsh, dsh-plugin, quote, selection, sidechat

## 简介

Quote anything: selecting text pops an action menu — quote into the current session (to the composer), quote into a side chat (as a side-chat ref), copy; other plugins register their own action rows through the ctx.quoteActions registry, and the side-chat
