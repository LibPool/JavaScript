# @aryacode/dsh-engineering

> 标签: automation, bundle, cordis, deepseek-harness, dsh, engineering, factorytalk, motionworks, plc, plugin, studio-5000

## 简介

AryaCode engineering bundle: one install surface for the Studio 5000 L5X, FactoryTalk View ME, MotionWorks IEC and FactoryTalk Optix surfaces, one row per product, with the ladder and display previews.
