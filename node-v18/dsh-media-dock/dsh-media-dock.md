# dsh-media-dock

> 标签: deepseek-harness, douyin, dsh, dsh-bundle, dsh-plugin, sidebar, speech-to-text, transcribe, youtube, yt-dlp

## 简介

DSH 右侧栏的媒体台：把抖音/YouTube 链接丢进来，本机 yt-dlp 下载、ffmpeg 转 16k 单声道 WAV、官方 speechToText（SenseVoice）转写，字幕进面板，Agent 一键总结。
