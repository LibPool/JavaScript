# @cloudbase/framework-plugin-deno

> 标签: JavaScript

## 简介

云开发 Tencent CloudBase Framework Deno Server Plugin 插件，将项目下的 Deno 应用一键部署云开发环境，提供自动弹性伸缩的高性能 Deno 服务
