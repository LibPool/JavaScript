# @stitchapi/elysia

> 标签: bun, elysia, fetch, plugin, principal, seam, sse, stitchapi

## 简介

Elysia plugin for StitchAPI — put a request-scoped seam on the context, stream a stitch's SSE output, and map Stitch errors to HTTP. Web-standard (Fetch-only, no node:*).
