# @mocanetwork/air-ai-services

> 标签: account-abstraction, cli, eip-1271, erc-4337, ethereum, mcp, signing, smart-account, userop, wallet

## 简介

Wallet-primitive tools for AIR smart-contract accounts — sign, send, approve, NFT transfer — exposed as an MCP server and a standalone CLI sharing one tool registry.
