# @yatmo/react

> 标签: isochrone, listing, map, neighbourhood, nextjs, poi, points-of-interest, property, proptech, react, react-components, real-estate, seo, yatmo

## 简介

Add real estate maps, points of interest and neighbourhood data to React applications: YatmoMap, YatmoPois and YatmoNeighbourhoodText components and hooks for property pages, with server rendering support. The official React SDK for Yatmo.
