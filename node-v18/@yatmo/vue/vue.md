# @yatmo/vue

> 标签: isochrone, listing, map, neighbourhood, nuxt, poi, points-of-interest, property, proptech, real-estate, seo, vue, vue-components, vue3, yatmo

## 简介

Add real estate maps, points of interest and neighbourhood data to Vue and Nuxt applications: YatmoMap, YatmoPois and YatmoNeighbourhoodText components and composables for property pages, with server rendering support. The official Vue SDK for Yatmo.
