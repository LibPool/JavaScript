# @youverus/dsh-ssh

> 标签: JavaScript

## 简介

Remote SSH operations for dsh: host store (~/.dsh/youverus-ssh.json), persistent ssh2 connection pool, exec, and agent tools (ssh_list / ssh_exec). SFTP, tunnels, cluster, and the web UI half are on the roadmap.
