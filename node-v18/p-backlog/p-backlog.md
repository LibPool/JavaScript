# p-backlog

> 标签: agent-skills, ai-agents, anthropic, backlog, claude, claude-code, cli, coding-agent, developer-tools, local-first, markdown, productivity, task-management, tech-debt, todo

## 简介

Keep pull requests clean and audit findings safe: a local, autonomous backlog for Claude Code. The agent files out-of-scope issues as Markdown tasks with context and re-checks them as code changes. Optional web UI with metrics.
