# crl-elevate-auth

> 标签: authorization, express, fastify, guard, jwt, middleware, nestjs, permissions, rbac

## 简介

Framework-agnostic JWT validation and API permission checking, configured at bootstrap. Adapters for Express and NestJS (Express or Fastify).
