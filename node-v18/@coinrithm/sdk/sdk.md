# @coinrithm/sdk

> 标签: agents, coinrithm, crypto, market-data, openapi, paper-trading, prediction-markets, sdk, tradfi

## 简介

Typed TypeScript SDK for the CoinRithm Agent Trading API: paper trading plus keyless prediction-market, crypto and TradFi market data, generated from the OpenAPI 3.1 contract.
