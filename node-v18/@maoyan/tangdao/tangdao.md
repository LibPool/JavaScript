# @maoyan/tangdao

> 标签: @maoyan/tangdao, redux-saga, reudx

## 简介

唐刀是一款基于 redux + redux-saga 以 model 为核心的数据流管理工具，它将 store 和 saga 统一为 model 的概念，写在一个 js 文件中，以对象配置的概念维护 state、 reducers、effects 等。
