# @goopil/clusterkit-file-watcher

> 标签: chokidar, cluster, clusterkit, env, file-watcher, hot-reload, rolling-restart

## 简介

File watcher hot restart plugin for @goopil/clusterkit: watches files, .env, and process.env for changes and triggers rolling worker restarts
