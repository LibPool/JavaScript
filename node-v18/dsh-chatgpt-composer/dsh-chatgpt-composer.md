# dsh-chatgpt-composer

> 标签: cdp, chatgpt, composer, deepseek-harness, dsh, dsh-plugin, puppeteer-core

## 简介

ChatGPT composer with a Mirror transcript view for DSH. Reuses the existing browser, connection and Markdown attachment flow; account and port controls remain in the chat card.
