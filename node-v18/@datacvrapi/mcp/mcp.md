# @datacvrapi/mcp

> 标签: anthropic, claude, cvr, danmark, mcp, norge, virksomhedsdata

## 简介

MCP-server for DataCVR API. Brug Claude, Cursor og ChatGPT til at slå danske og norske virksomheder op via Erhvervsstyrelsens CVR-register og Brønnøysundregistrene.
