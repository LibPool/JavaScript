# @coroama/svelte-box

> 标签: $state, box, container, observable, proxy, reactive, reactivity, runes, signals, state, store, svelte, svelte-5, svelte5, sveltejs, wrapper

## 简介

Tiny reactive container for Svelte 5. Wraps $state so it can be passed across functions, classes, and components without losing reactivity.
