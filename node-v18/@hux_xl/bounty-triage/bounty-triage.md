# @hux_xl/bounty-triage

> 标签: agent, ai-agents, bounty, decision-making, mcp, model-context-protocol, nz1labs, revenue, taskmarket, triage

## 简介

MCP server: judges bounty/task descriptions against NZ1Labs' battle-tested 5-criteria triage policy (evolved through 40+ real agent submissions). Returns TAKE or SKIP with reason and confidence — prevents agents from wasting cycles on lottery bounties.
