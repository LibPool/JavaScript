# hytong-agent-hub

> 标签: JavaScript

## 简介

输出与运行各种 Agent 的基础运行时（第一版：BaseAgent），内置工具调用（Tool Calling）、技能（Skill）加载与匹配，并支持 MCP（Model Context Protocol）接入外部工具。
