# html-to-amp

> 标签: JavaScript

## 简介

Small module to transform html pages to amp, using [html-to-article-json](https://www.npmjs.com/package/html-to-article-json) & [article-json-to-amp](https://www.npmjs.com/package/article-json-to-amp)
