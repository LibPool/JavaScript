# homebridge-rainmachine-zones

> 标签: homebridge-plugin, irrigation, rainmachine, sprinkler, supports-hap

## 简介

Expose RainMachine sprinkler zones to HomeKit via Homebridge using RainMachine's local API directly (no cloud, no dependencies).
