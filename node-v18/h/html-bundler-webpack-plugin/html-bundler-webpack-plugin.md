# html-bundler-webpack-plugin

> 标签: JavaScript

## 简介

Generates complete single-page or multi-page website from source assets. Built-in support for Markdown, Eta, EJS, Handlebars, Nunjucks, Pug. Alternative to html-webpack-plugin.
