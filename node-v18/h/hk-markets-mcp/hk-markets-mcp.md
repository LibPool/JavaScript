# hk-markets-mcp

> 标签: claude, finance, fintech, hibor, hkma, hong-kong, interest-rates, mcp, model-context-protocol

## 简介

MCP server exposing Hong Kong Monetary Authority data as typed tools: the HKMA Base Rate, HIBOR fixings, and the USD/HKD peg band with the Aggregate Balance.
