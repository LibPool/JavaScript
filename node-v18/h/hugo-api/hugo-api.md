# hugo-api

> 标签: api-client, cache, etag, fetch, hooks, react, react-native, rest, retry

## 简介

Call any REST endpoint by its own line ("GET /api/songs") and read it into React with one cached hook — retries, ETag, request coalescing and auto-refresh after writes
