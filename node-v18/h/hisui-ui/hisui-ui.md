# hisui-ui

> 标签: ark-ui, cli, components, hisui, react, registry, shadcn, tailwindcss, ui

## 简介

React component registry. Ark UI + Tailwind v4 で組んだ primitive を shadcn 方式 (copy-paste) で配布する CLI.
