# hostwares-mcp

> 标签: ai, claude, cursor, deploy, devops, hostwares, mcp, model-context-protocol

## 简介

Deploy and manage Hostwares from Claude, Cursor, ChatGPT or any MCP client. Local stdio bridge to the hosted Hostwares MCP server.
