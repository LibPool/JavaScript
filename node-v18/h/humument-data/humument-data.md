# humument-data

> 标签: a-humument, creative-coding, dataset, erasure-poetry, ocr, tom-phillips

## 简介

Per-page OCR data (words, bboxes, whitespace gutters, navigation graph) for the 1892 one-volume edition of W. H. Mallock's A Human Document — the data layer consumed by humument.
