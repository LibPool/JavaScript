# homebridge-ruuvi-sensors

> 标签: bluetooth, gateway, homebridge, homebridge-plugin, matter, ruuvi, ruuvitag, weather

## 简介

A modern Homebridge Dynamic Platform for Ruuvi sensors. Supports Ruuvi Gateway webhooks, local Bluetooth scanning, and all Ruuvi data formats including encrypted format 8.
