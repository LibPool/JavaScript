# header-sentinel

> 标签: ci, cli, content-security-policy, csp, devsecops, github-action, headers, hsts, http, mozilla-observatory, owasp, sarif, security, security-headers

## 简介

CI-friendly CLI and API that fails builds when deployed URLs are missing or misconfigure HTTP security headers (HSTS, CSP, COOP, cookies...) with specific fixes. Mozilla Observatory-style A–F grades, JSON & SARIF output.
