# html-paged-pdf

> 标签: browser, frontend, html-to-pdf, html2canvas, jspdf, paged.js, pagination, pdf

## 简介

纯前端 HTML 自动分页并生成 PDF。基于 paged.js + html2canvas + jsPDF，简化架构，更易使用。
