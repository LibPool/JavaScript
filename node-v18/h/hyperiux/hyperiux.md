# hyperiux

> 标签: animations, cli, components, effects, gsap, hyperiux, nextjs, three, ui, webgl

## 简介

CLI for adding Hyperiux Vault effects to your Next.js project. This package is a CLI installer only - it is not an importable JavaScript/TypeScript library.

## 官网

- 官网：https://vault.hyperiux.com
- 源码仓库：git+https://github.com/Hyperiux-Immersion-Labs/hyperiux-components.git
