# herdr-dashr

> 标签: ai-agent, aws-xray, e2e-testing, herdr, herdr-plugin, jaeger, opentelemetry, sequence-diagram, tracing

## 简介

End-to-end testing by traces: your AI agent instruments a feature with OpenTelemetry, you browse and edit the code behind every span, and every service's spans (local, AWS X-Ray, Azure, Google Cloud, Jaeger, Zipkin) meet in one live sequence diagram check
