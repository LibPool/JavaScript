# haversine-toolkit

> 标签: bounding-box, coordinates, distance, geo, geolocation, geospatial, gis, gps, haversine, javascript, latitude, location, longitude, maps, midpoint, node, radius, typescript

## 简介

A modern TypeScript geospatial toolkit for calculating Haversine distance, bounding boxes, geographic midpoints, and radius-based location queries.
