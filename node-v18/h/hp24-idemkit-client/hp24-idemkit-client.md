# hp24-idemkit-client

> 标签: browser, client, fetch, idempotency, idempotency-key, retry

## 简介

Universal (browser + Node) idempotent fetch wrapper: generates and persists an Idempotency-Key per logical request and safely retries with backoff. Zero dependencies.
