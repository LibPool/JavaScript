# hinglish-openai

> 标签: hinglish, openai

## 简介

This package provides an easy-to-use function for generating text in English by using OpenAI's GPT-3 model. It can take a message in any language as input (especially in hinglish), translate it to English and generates a reply. It uses the text-davinci-00
