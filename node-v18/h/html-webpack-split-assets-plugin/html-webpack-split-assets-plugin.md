# html-webpack-split-assets-plugin

> 标签: assets, body, create-react-app, head, html-webpack-plugin, plugin, react-app-rewired, split, webpack

## 简介

This webpack plugin splits the head and body assets in two different files. These files can be consumed by backend templates like JSPs.
