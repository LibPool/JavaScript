# hoolix

> 标签: ai-agents, claude, cli, cursor, documentation, filesystem, github, grok, llms.txt, mcp, model-context-protocol, postgres, rag, tui

## 简介

Forge documentation into powerful, secure Hoolix MCP servers. Production-grade CLI for turning docs URLs into hostable MCP servers for Grok, Claude, Cursor, and other agents.
