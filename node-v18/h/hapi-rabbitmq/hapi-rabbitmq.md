# hapi-rabbitmq

> 标签: amqplib, hapi, publish, pubsub, queue, rabbitmq, subscribe, task, work-queue, worker

## 简介

A HAPI server plugin implementing PubSub and job queue patterns in RabbitMQ with librabbitmq.
