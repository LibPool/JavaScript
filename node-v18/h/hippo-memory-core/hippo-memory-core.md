# hippo-memory-core

> 标签: agent, context-window, deepseek, deepseek-runtime, dsh, embedding, hallucination, hippocampus, llm, long-term-memory, memory, rag, sqlite

## 简介

Hippocampus-inspired long-term memory engine for LLM agents: sparse encoding with pattern separation, cue-driven retrieval, source monitoring, conflict versioning, consolidation, and adaptive forgetting. Zero external services (SQLite + local vector index
