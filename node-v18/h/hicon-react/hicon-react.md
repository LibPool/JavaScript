# hicon-react

> 标签: components, hicon, icons, react, react-icons, svg, tailwind, tailwindcss, ui

## 简介

Official React icon library for Hicon (+1,370 icons across Bold, Outline, and Linear variants). Fully stylable with Tailwind CSS, custom colors, and size props.
