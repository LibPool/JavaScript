# harmost

> 标签: adr, ai, architecture, ci, claude-code, fitness-functions, governance, invariants, merge-gate

## 简介

Make architectural invariants enforceable in AI-assisted development: an ADR ledger in git, a coverage gate in CI, and deterministic context delivery to coding agents.
