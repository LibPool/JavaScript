# hono-cloudflare-rate-limit

> 标签: 429, abuse-protection, api-security, brute-force, cloudflare, cloudflare-rate-limiting, cloudflare-workers, edge, hono, hono-middleware, middleware, rate-limit, rate-limiter, rate-limiting, ratelimit, ratelimits, serverless, throttle, throttling, too-many-requests, typescript, workerd, workers, wrangler

## 简介

Hono rate limit middleware for Cloudflare Workers using the native Rate Limiting binding. Throttle requests per IP, user, or API key and return 429 Too Many Requests.
