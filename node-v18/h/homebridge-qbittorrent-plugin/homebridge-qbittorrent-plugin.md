# homebridge-qbittorrent-plugin

> 标签: bandwidth, homebridge, homebridge-plugin, qbittorrent, speed-limits, supports-hap, torrent

## 简介

A Homebridge plugin that exposes a HomeKit switch for each qBittorrent server, toggling its alternative speed limits.
