# hangar-uploader

> 标签: JavaScript

## 简介

## 简介 本项目基于vue-simple-uploader，在此基础上添加了文件的MD5验证、图片在线预览和PDF在线预览的功能，该插件需要后台配合使用 注：本项目不兼容VUE3.0项目
