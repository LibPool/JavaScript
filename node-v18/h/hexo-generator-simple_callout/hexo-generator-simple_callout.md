# hexo-generator-simple_callout

> 标签: callout, hexo

## 简介

让你可以在 hexo 的 markdown 文件中使用类似 obsidian 的 callout 语法，插件使用 cheerio 对 hexo 的生成内容后处理实现 callout 的 html。
