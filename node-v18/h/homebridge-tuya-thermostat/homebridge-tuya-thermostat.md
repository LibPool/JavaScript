# homebridge-tuya-thermostat

> 标签: homebridge-plugin

## 简介

This project is to be used with Tuya-compatible thermostats. This uses TuyAPI under the hood and will need [device ID and key](https://github.com/codetheweb/tuyapi/blob/master/docs/SETUP.md) to be populated in the config beforehand.
