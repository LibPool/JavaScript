# homebridge-navimow

> 标签: homebridge, homebridge-plugin, homekit, lawn-mower, navimow, robotic-mower, segway

## 简介

Homebridge platform plugin for Navimow robotic mowers with HomeKit controls, live telemetry, and a guided OAuth setup flow.
