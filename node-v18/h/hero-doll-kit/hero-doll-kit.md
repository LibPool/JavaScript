# hero-doll-kit

> 标签: JavaScript

## 简介

雷曼式部件骨架成品包：41 个动作(含六个大招) + 四槽换装 + 可选的战斗表现层与残影层，Cocos Creator 3.8。npm 装包后跑 hero-doll-sync 把资源同步进工程 assets/resources/。
