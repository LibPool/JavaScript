# hanlp

> 标签: hanlp, node-hanlp

## 简介

HanLP v1.5.0 自然语言处理 for nodejs  ===== * 支持中文分词（N-最短路分词、CRF分词、索引分词、用户自定义词典、词性标注），命名实体识别（中国人名、音译人名、日本人名、地名、实体机构名识别），关键词提取，自动摘要，短语提取，拼音转换，简繁转换，文本推荐，依存句法分析（MaxEnt依存句法分析、CRF依存句法分析） * 官方文档：http://www.hankcs.com/nlp/hanlp.html * 修改 java 源码添加 init 方法,自定义引入 hanLP.
