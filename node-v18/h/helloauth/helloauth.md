# helloauth

> 标签: async-auth, auth-service, authentication, browser-auth, dexly, event-driven, frontend-auth, helloid, identity, javascript, login, oauth, oauth-client, oauth2, popup-auth, sdk, security, token-exchange, web-sdk, webauth

## 简介

Hello ID OAuth Service es un SDK de autenticación ligero para aplicaciones web, diseñado para proporcionar flujos de inicio de sesión OAuth seguros, autenticación mediante ventanas emergentes, integración basada en eventos e intercambio asíncrono de token
