# hijri-rrule

> 标签: calendar, date, hijri, icalendar, islamic, recurrence, recurring, rfc5545, rrule

## 简介

A JavaScript library for working with recurrence rules (RRULE) for the Hijri (Islamic) calendar, compatible with RFC 5545
