# html-img-pdf

> 标签: html-to-image, html2pdf, jspdf, pdf, typescript

## 简介

高性能 HTML -> PDF 工具：按需加载依赖以减小体积，支持进度回调、资源超时控制与元素过滤，基于 html-to-image 与 jsPDF
