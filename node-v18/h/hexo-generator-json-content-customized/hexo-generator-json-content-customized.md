# hexo-generator-json-content-customized

> 标签: content, generator, hexo, json, templating

## 简介

Hexo plugin to generate a JSON file with the contents of posts and pages to generic use or consumption, like AJAX site search, Twitter typehead or public content API. Base on hexo-generator-json-content 4.2.3
