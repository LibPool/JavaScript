# hledit-mcp

> 标签: ai-agent, claude-code, claude-desktop, coding-agents, context-safe, cursor, file-editing, hash-anchored, hashline, hledit, local-first, mcp, mcp-server, model-context-protocol, stale-edit, stale-write

## 简介

MCP server for hledit hash-anchored file edits. Rejects stale writes before they happen for standard MCP clients.
