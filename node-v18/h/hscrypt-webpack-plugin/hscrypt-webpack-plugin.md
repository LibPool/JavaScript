# hscrypt-webpack-plugin

> 标签: JavaScript

## 简介

Use `hscrypt` to encrypt a Javascript bundle built by Webpack and inject code into the page to fetch, decrypt, and inject the bundle (based on a decryption key provided as a URL fragment)
