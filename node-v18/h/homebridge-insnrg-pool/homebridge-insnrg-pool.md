# homebridge-insnrg-pool

> 标签: chlorinator, homebridge, homebridge-plugin, homekit, insnrg, pool, spa, supports-hap

## 简介

Homebridge plugin for INSNRG (Vi/Hub) pool equipment via the INSNRG cloud API — pool/spa heating, outlets, valves, lights, pump speed, chlorinator, pH/ORP.
