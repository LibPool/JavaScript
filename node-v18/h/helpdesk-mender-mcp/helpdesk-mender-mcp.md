# helpdesk-mender-mcp

> 标签: ai-agents, customer-support, freshdesk, helpdesk, helpscout, mcp, mcp-server, model-context-protocol, support, ticketing, zendesk

## 简介

One MCP server, one consistent tool vocabulary, for Zendesk, Freshdesk, and Help Scout write operations: create/update tickets, add replies/notes, change status. No separate integration code per platform.
