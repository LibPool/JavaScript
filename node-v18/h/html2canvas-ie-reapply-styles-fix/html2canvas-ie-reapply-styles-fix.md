# html2canvas-ie-reapply-styles-fix

> 标签: JavaScript

## 简介

This package is forked from html2canvas v1.0.0-rc.3 to fix problem when during document clone IE falls in quirks mode and misunderstand styling info. Solution is to change width of cloned iframe so that IE re-applies, re-calculates styles. Solution URL -
