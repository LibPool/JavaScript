# html-to-plain

> 标签: cloudflare-workers, decode-entities, edge, edge-runtime, entities, esm, excerpt, html, html-entities, html-to-plain, html-to-plain-text, html-to-text, isomorphic, no-dom, plain-text, plaintext, prosemirror, remove-html-tags, rich-text, search-index, strip-html, strip-tags, text-extraction, tiptap, workerd, wysiwyg, zero-dependency

## 简介

Convert HTML to plain text: strip tags, decode HTML entities, collapse whitespace. Zero dependencies, no DOMParser — works on Cloudflare Workers, edge runtimes, browsers, and Node.js.
