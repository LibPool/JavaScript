# hbor-angular-cli-library

> 标签: JavaScript

## 简介

ngx-hbor-lib je Angular Library koji abstraktira ostale module koje koristimo unutar naših aplikacija. Ima sve značajke koje se očekuju za razvoj jednostavnih i kompleksnih aplikacija. Ugrađuje lokalizaciju te određene maske u polja koja to trebaju podrža
