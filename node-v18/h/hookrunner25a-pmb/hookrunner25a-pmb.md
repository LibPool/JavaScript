# hookrunner25a-pmb

> 标签: async, await, event, eventemitter, events, hook, hooks, promise, promises, promising, series, shared state, subscribe

## 简介

Rudimentary EventEmitter-style event manager for running serially async handler chains that update a shared state object unless the chain is aborted.
