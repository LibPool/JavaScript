# homebridge-bosch-thermostats

> 标签: bosch, floor-heating, homebridge, homebridge-plugin

## 简介

This is a simple plugin that exposes Bosch room thermostats to HomeKit. I built it since they are, as of October 2020, not yet officially supporteed.

## 官网

- npm 页面：https://www.npmjs.com/package/homebridge-bosch-thermostats

## 历史版本号

- 当前版本：1.0.0

- 1.0.0

## 获取地址

- npm 安装：`npm install homebridge-bosch-thermostats`
- npm registry：https://registry.npmjs.org/homebridge-bosch-thermostats
- Node 要求：>=12.0.0
