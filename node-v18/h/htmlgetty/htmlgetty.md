# htmlgetty

> 标签: axios, body, cheerio, code, crawl, crawler, div, dom, extract, find, footer, get, head, href, html, javascript, js, link, links, p, scrape, scraping, search, tag, title, url, web, webcrawler, webscraping

## 简介

This is a function that accepts 3 arguments, "url", "tag" and "output", and writes to a file, in the "output" path, the content of an html "tag", relative to a specific "url".
