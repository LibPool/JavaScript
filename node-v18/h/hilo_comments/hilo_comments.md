# hilo_comments

> 标签: comments, embed, widget

## 简介

Widget assets for Hilo (self-hosted comments) — embed.js, embed.css, and themes/*.css. Source here is plain, readable JS/CSS; `npm run build` minifies it into dist/, which is what actually gets published.
