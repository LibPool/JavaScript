# homebridge-hdfury-diva

> 标签: diva, hdfury, homebridge-plugin

## 简介

Homebridge plugin that finds an HDFury Diva on the local network and exposes a reboot switch in HomeKit.

## 官网

- npm 页面：https://www.npmjs.com/package/homebridge-hdfury-diva

## 历史版本号

- 1.0.0

## 获取地址

- npm 安装：`npm install homebridge-hdfury-diva`
- npm registry：https://registry.npmjs.org/homebridge-hdfury-diva
- Node 要求：^20.9.0 || ^22.12.0 || ^24.0.0
