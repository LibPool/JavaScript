# homebridge-protect-alarm

> 标签: alarm, homebridge-plugin, homekit, protect, security-system, ubiquiti, udm, unifi, unifi-protect

## 简介

Bring your UniFi Protect alarm system into Apple HomeKit as a native Security System — Away, Night, and Disarm — using a single UniFi OS API key. Arm profiles are discovered automatically.
