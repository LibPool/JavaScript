# hitoiki

> 标签: INP, cooperative-multitasking, coroutine, generator, main-thread, non-blocking, requestIdleCallback, scheduler, scheduler.postTask, time-slicing

## 简介

Run heavy work on the main thread without blocking the UI: write it as a generator, run it synchronously or in time slices.
