# homebridge-binary-load-lifter

> 标签: accessibility, dihool, esp32, ewelink, homebridge, homebridge-plugin, homekit, motor-controller, scissor-lift

## 简介

Homebridge plugin to control DIHOOL IPS-S2 scissor lifts via the eWeLink LAN protocol and custom ESP32 sensor package.
