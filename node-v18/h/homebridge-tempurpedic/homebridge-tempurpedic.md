# homebridge-tempurpedic

> 标签: adjustable bed, bed, ergo, homebridge, homebridge-plugin, homekit, matter, smart base, supports-hap, supports-matter, tempur-pedic, tempurpedic

## 简介

Homebridge plugin for Tempur-Pedic Smart Bases. Control vibration, positions, and flat via HomeKit and Alexa. No Java or external dependencies required.
