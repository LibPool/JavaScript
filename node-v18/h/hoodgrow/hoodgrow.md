# hoodgrow

> 标签: agent, ai-agent, defi, hoodgrow, morpho, robinhood-chain, stock-tokens, tokenized-equities, uniswap, x402

## 简介

TypeScript SDK for the HoodGrow Robinhood Chain (and Base B20) stock token API — live price, corporate-action adjusted supply, DeFi depth (Morpho/Uniswap), and corporate actions. Pay per call via x402 (USDC on Base) or a bearer API key.
