# homebridge-reolink-hksv-doorbell

> 标签: camera, doorbell, hksv, homebridge-plugin, homekit-secure-video, reolink, video-doorbell

## 简介

Homebridge plugin for Reolink doorbells and cameras with HomeKit Secure Video (HKSV) support, fully configurable via Homebridge UI.
