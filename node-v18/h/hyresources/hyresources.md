# hyresources

> 标签: $promise, $resource, Angular, AngularJs, Api, Apis, JS, Module, Modules, Resources, Rest, Restfull, custom, headers, ngResources, promise

## 简介

hyResources is a restful resource manager. it helps you configure resources and store them in one module.
