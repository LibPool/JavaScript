# herkos

> 标签: agent, claude-code, codex, credentials, guard, hooks, prompt-injection, security

## 简介

Your never-list, enforced everywhere: block agents from reading credentials or running fetched code — one policy, compiled into every agent harness on your machine, in every mode.
