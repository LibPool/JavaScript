# has-btn

> 标签: JavaScript

## 简介

按钮权限校验， 菜单配置的权限须保存在Vuex ，this.$store.state.permission.myRouterData下，按钮名称全局不可重复。 按钮权限类型须menuType设置为2，校验的按钮名称字段为frontUrl
