# hbl-payment-gateway

> 标签: hbl, hbl-nepal, himalayan-bank, hosted-checkout, mastercard, mpgs, nepal, npr, payment-gateway, payments, typescript

## 简介

TypeScript client for the Himalayan Bank Limited (HBL Nepal) payment gateway, which runs on Mastercard Payment Gateway Services. Hosted checkout, result verification, capture, refund and void — zero dependencies, works in Node, Next.js and edge runtimes.
