# hex-color-utils

> 标签: color, hsl, hue, number, rgb

## 简介

JavaScript primitive `number` between `0` ( === `0x000000` ) and `16777215` ( === `0xffffff` ) inclusive can be used as color. `hex-color-utils` is the utils for it.
