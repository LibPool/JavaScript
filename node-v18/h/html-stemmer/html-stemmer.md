# html-stemmer

> 标签: html, html-stemmer, nlp, porter, porter2, stem, stemmer, stop-words, stopwords, unescape, unescaper

## 简介

Extracts all [porter2] stemmed words from an HTML file, with the goal of aiding web-based NLP
