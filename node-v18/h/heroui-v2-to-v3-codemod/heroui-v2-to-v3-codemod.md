# heroui-v2-to-v3-codemod

> 标签: codemod, heroui, jscodeshift, migration, nextui, v2, v3

## 简介

Deterministic codemod that migrates a React/Next.js UI directory from HeroUI v2 to HeroUI v3. No LLM at runtime.
