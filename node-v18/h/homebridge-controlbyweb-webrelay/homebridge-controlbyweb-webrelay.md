# homebridge-controlbyweb-webrelay

> 标签: controlbyweb, homebridge-plugin, homekit, relay, webrelay, xytronix

## 简介

Homebridge plugin to control ControlByWeb / Xytronix WebRelay devices (single and 4-relay) over HTTP + state.xml.
