# halfpennymac

> 标签: JavaScript

## 简介

Command line and MCP server for Halfpenny Mac: list your rented Macs, check they are online, fetch credentials, restart, rotate passwords, update macOS.

## 官网

- 官网：https://halfpennymac.com/docs/api
- 源码仓库：git+https://github.com/pauldodd123/halfpenny-mac.git
- npm 页面：https://www.npmjs.com/package/halfpennymac
