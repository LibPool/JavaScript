# h5xxpp

> 标签: JavaScript

## 简介

1.注册npm账户 2.将源切换至npm（用过nrm切换到taobao源的 需要执行这个步骤） 3.初始化项目 `$ npm init -y` 4创建入口文件 5开发 6登录npm账号 `$ npm adduser` 7发布项目 `$ npm publish`
