# heroicons-x-qwik

> 标签: heroicons, icons, qwik, qwikjs

## 简介

[Heroicons](https://heroicons.com/) is great, but it doesn't work with [Qwik](https://qwik.builder.io/) out of the box, this library aims to solve that issue.
