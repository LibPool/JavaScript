# hilma-mcp-server

> 标签: apify, claude, finland, hankinta, hilma, mcp, model-context-protocol, open-data, procurement, tenders

## 简介

Open bridge to the hosted Finnish Public Procurement (HILMA) MCP server on Apify — search Finnish public tenders, awards and procurement plans from any MCP client using your own Apify API token.
