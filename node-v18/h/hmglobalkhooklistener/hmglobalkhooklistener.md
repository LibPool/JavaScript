# hmglobalkhooklistener

> 标签: JavaScript

## 简介

Un écouteur de touches de clavier global (Global Key Hook) pour Electron. Rapide, léger et utilisant des binaires natifs pour éviter la lourdeur d'un environnement Python complet.
