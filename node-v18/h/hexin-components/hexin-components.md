# hexin-components

> 标签: JavaScript

## 简介

本项目是基于 vue-cli 创建的 vue 项目，并添加了 storybook 及其 storybook-addon-vue-info 插件，以及 vue 的 Typescript 组件写法支持的配置。eslint + prettier 配置支持 vscode save autofix
