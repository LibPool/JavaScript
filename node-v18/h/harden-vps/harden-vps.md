# harden-vps

> 标签: canarytokens, clamav, debian, devsecops, docker-firewall, fail2ban, falco, firewall, hardening, linux, malware-detection, nftables, security, server-hardening, ssh-hardening, supply-chain-security, tailscale, trivy, unattended-upgrades, vps

## 简介

One-command Linux VPS security hardening for Debian: nftables firewall (Docker-safe), key-only SSH, fail2ban, Falco, ClamAV, Trivy, Tailscale, unattended-upgrades and supply-chain malware checks.
