> 标签: ai-agents, applicant-tracking, ats, bamboohr, candidate-management, greenhouse, hiring, hr, mcp, mcp-server, model-context-protocol, recruiting

## 简介

One MCP server, one consistent tool vocabulary, for BambooHR and Greenhouse ATS write operations: create/update candidates, advance/move/reject applications. No separate integration code per platform.
