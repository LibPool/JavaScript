# husher

> 标签: JavaScript

## 简介

1. ⭐️ hush - encode input string into hidden text with zero-width characters 2. ⭐️ dehush - reverse the process and discover the hidden text 3. ⭐️ sanitize - sanitize the text from hidden text characters 4. Support dehush of flag emojis, utf-8 and other m
