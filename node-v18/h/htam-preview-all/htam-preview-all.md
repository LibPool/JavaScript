# htam-preview-all

> 标签: file-preview, htam, htam-preview-all, json, markdown, office, txt, ui, vue3

## 简介

> 这是华泰资产管理有限公司基于 vue3、element-plus 封装的文件预览组件，目前仅支持预览以（pdf、docx、xlsx、pptx、txt、json、md）格式结尾的文件以及常规格式的图片，并提供水印功能（水印可根据业务需求自行选择使用）。
