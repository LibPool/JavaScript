# homebridge-sonos-cloud-doorbell

> 标签: audioclip, doorbell, homebridge-plugin, smart-home, sonos

## 简介

Doorbell chime on Sonos via the Cloud audioClip API — ducks and auto-restores playback instead of dropping it.
