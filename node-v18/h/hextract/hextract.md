# hextract

> 标签: accessibility, color, contrast, extraction, framework-agnostic, hex, image, rgb, typescript, wcag

## 简介

A modern, lightweight utility library for color extraction and accessibility calculations in React applications. Extract dominant colors from images and ensure your color combinations meet WCAG contrast guidelines.
