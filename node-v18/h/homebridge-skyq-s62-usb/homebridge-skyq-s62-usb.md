# homebridge-skyq-s62-usb

> 标签: epg, gnome, homebridge-plugin, multiroom, now playing, rs232, s6.2, serial, sky, sky q, skyq, systemline, usb

## 简介

Homebridge plugin that polls Sky Q boxes for now-playing data and forwards it to a Systemline S6.2 multi-room audio system via USB-to-RS232 serial cables. Reconstructs the Sky Gnome RS232 protocol so the S6.2 touch screen displays channel and programme in
