# html-surface-three

> 标签: 3d-ui, canvas, html, interaction, react, texture, three.js, webgl

## 简介

Manage interactive HTML UI as Three.js mesh surfaces with texture rendering, UV mapping, occlusion-aware input, and lifecycle control.
