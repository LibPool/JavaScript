# homebridge-solax-local

> 标签: homebridge-plugin, homekit, hybrid, inverter, local, photovoltaics, solar, solax

## 简介

Homebridge plugin for Solax inverters via the local dongle API (Pocket WiFi 3.0 / LAN). No cloud, no TokenID. X3-Hybrid-G4 supported, extensible to other models.
