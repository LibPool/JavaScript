# homebridge-porsche

> 标签: ev, homebridge-plugin, homekit, porsche, taycan

## 简介

Homebridge plugin for the Porsche Taycan via the Connect/PPA API — climate, charging, lock and more in Apple Home, without Docker or Home Assistant
