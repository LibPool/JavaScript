# honeypot-v2

> 标签: bot-detection, cybersecurity, express, honeypot, middleware, nextjs, rate-limiting, scraping-protection, security, tarpit, typescript, waf

## 简介

Behavioral honeypot for web applications — graduated response from passive observation to active tarpitting. Zero external dependencies in memory mode. Optional Upstash Redis for production persistence.
