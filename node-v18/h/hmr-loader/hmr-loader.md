# hmr-loader

> 标签: accept, hot, module, webpack

## 简介

Tiny webpack plugin that adds `module.hot.accept` to the bottom of modules.  Use with something like [`babel-plugin-react-hot`](https://github.com/loggur/babel-plugin-react-hot).
