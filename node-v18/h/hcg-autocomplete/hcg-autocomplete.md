# hcg-autocomplete

> 标签: accessible, aria, async, autocomplete, chips, combobox, hcg-autocomplete, no-dependencies, tags, typeahead, vanilla-js

## 简介

Pure vanilla JavaScript autocomplete combobox for input fields. No dependencies. Local and async sources, multi-select chips, free-text values, match highlighting, and keyboard navigation.
