# hugeicons-proxy

> 标签: @hugeicons/core-free-icons, @hugeicons/react, customizable-icons, design-system, icon-library, icons, react, react-component-library, react-icons, scalable-icons, ui-components, vector-icons, web-icons

## 简介

A lightweight React helper for Hugeicons. Import once and use any icon as a React component by name. No manual imports, no icon mapping, full TypeScript support and autocomplete. Built to stay simple, predictable and easy to extend.
