# hexo-img-path

> 标签: hexo, image, path

## 简介

将hexo中的markdown图片的相对路径更改为绝对路径,使得在markdown预览和发布状态下都能看到图片

## 官网

- 源码仓库：https://gitee.com/andyge/hexo-img-path.git
- npm 页面：https://www.npmjs.com/package/hexo-img-path
