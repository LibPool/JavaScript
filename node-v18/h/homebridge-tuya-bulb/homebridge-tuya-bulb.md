# homebridge-tuya-bulb

> 标签: color-light, homebridge, homebridge-plugin, homekit, local-lan, siri, smart-bulb, tuya

## 简介

Homebridge plugin for Tuya v3.4 Color Light bulbs. Local LAN control after one-time cloud key bootstrap. No ongoing cloud dependency.
