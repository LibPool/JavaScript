# hive-publisher

> 标签: blockchain, content, crypto, decentralized, hive, publishing, social, typescript, voting, web3

## 简介

A ultra-simple, enterprise-ready TypeScript library for Hive blockchain operations. Works out-of-the-box with just 'new HiveClient()' - no configuration needed!
