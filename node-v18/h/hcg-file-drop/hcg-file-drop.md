> 标签: drag-and-drop, dropzone, file-drop, file-upload, javascript, no-dependencies, ui-component, vanilla-js

## 简介

Lightweight dependency-free vanilla JavaScript drag-and-drop file upload widget with type filtering, file limit, duplicate detection, removable file list, and disabled state.
