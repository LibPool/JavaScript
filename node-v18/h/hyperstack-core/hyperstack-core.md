# hyperstack-core

> 标签: agent-coordination, ai-agents, graph-memory, hyperstack, knowledge-graph, mcp, memory, multi-agent, openclaw, typed-relations

## 简介

Typed graph memory for AI agents. Replace GOALS.md with queryable cards + relations. Works with OpenClaw, Claude Desktop, Cursor.
