# hash-check-cli

> 标签: checksum, cli, hash, md5, sha1, sha256, sha512, verify

## 简介

CLI tool for computing file hashes (MD5/SHA1/SHA256/SHA512). Supports batch files, output to file, and verification mode. Zero dependencies.
