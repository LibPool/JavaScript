# homebridge-smart-occupancy

> 标签: delay, homebridge, homebridge-plugin, homebridge-smart-occupancy, homekit, motion sensor, occupancy sensor, sensor, smart home, switch

## 简介

Create flexible and customizable occupancy sensors for Homebridge with extra switches and triggers to control sensor and occupancy delay behavior.
