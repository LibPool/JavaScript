# lightndb

> 标签: database, document, embedded, embeddings, json, lightndb, lmdb, local, mongodb, nosql, sqlite-vec, vector-search

## 简介

A lightweight, schemaless, local JSON document database for Node.js, wrapping LMDB for storage and exposing a MongoDB-like query API with vector search support
