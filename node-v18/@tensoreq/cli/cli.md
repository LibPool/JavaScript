# @tensoreq/cli

> 标签: agent, cli, gateway, mcp, tensoreq

## 简介

TensorEQ CLI — the session-first agent terminal for the TensorEQ model gateway. Zero-dependency; runs on Windows, macOS and Linux with Node 18+.
