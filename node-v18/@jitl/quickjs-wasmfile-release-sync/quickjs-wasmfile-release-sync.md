# @jitl/quickjs-wasmfile-release-sync

> 标签: JavaScript

## 简介

Variant of quickjs library: Variant with separate .WASM file. Supports browser ESM, NodeJS ESM, and NodeJS CommonJS.

- 源码仓库：https://github.com/justjake/quickjs-emscripten
