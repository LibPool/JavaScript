# @meta-quest/hzdb

> 标签: JavaScript

## 简介

Compatibility shim for @meta-quest/hzdb - now @meta-quest/metavr (Meta VR CLI). Installs and re-exports @meta-quest/metavr; install @meta-quest/metavr directly for the current name.
