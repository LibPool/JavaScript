# @workflowbuilder/temporal

> 标签: durable-execution, orchestration, plugin, temporal, temporalio, typescript, workflow, workflow-builder, workflow-engine

## 简介

Run Workflow Builder diagrams as durable Temporal Workflow Executions: a Temporal Plugin that registers the node-execution activities, plus the workflow-side runner to re-export from your own workflows module.
