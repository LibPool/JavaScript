# @openvidstudio/mcp-server

> 标签: claude, demo-video, mcp, model-context-protocol, playwright, remotion, video

## 简介

MCP server exposing openvidstudio's mechanical pipeline tools: project scaffolding, beats validation, scene stubs, composition stitching, render, QC frame extraction, and zoom-compensated screenshot/screen-recording capture.
