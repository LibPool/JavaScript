# @cicada-design/cicada-cli

> 标签: cicada-cli, cicada-design

## 简介

Cicada Cli 是一个 Vue3.* 组件库构建工具，通过 Cicada Cli 可以快速搭建一套功能完备的 Vue3.* 组件库。
