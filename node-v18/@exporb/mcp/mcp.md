# @exporb/mcp

> 标签: ai, crm, exporb, leads, mcp, tradeshow

## 简介

Local stdio MCP server for the Exporb agent API — trade-show contacts and AI enrichment as MCP tools. Same 9 tools as the remote server at app.exporb.com/api/mcp, for clients that only support stdio.
