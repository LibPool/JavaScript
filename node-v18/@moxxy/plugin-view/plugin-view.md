# @moxxy/plugin-view

> 标签: agent, moxxy, present-view, tools, ui

## 简介

Agent-authored UIs for moxxy. A present_view tool parses the agent's JSX-like view-spec (via the active view renderer) into a validated AST that channels render as rich interactive UI.
