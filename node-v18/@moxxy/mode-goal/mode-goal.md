# @moxxy/mode-goal

> 标签: agent, autonomous, goal, mode, moxxy

## 简介

Goal mode: state a goal once and the agent works autonomously across many turns until it calls goal_complete (or goal_abandon), guarded by an iteration cap, a token budget, a stuck-loop detector, no-progress detection, and the user's abort.
