# @moxxy/plugin-oauth

> 标签: auth, moxxy, oauth, pkce, plugin

## 简介

Generic OAuth 2.0 + PKCE client. Loopback callback server, vault-backed token storage, refresh helpers. Bundled skills for Google Workspace + arbitrary providers.
