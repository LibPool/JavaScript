# @moxxy/plugin-vault

> 标签: encryption, moxxy, plugin, secrets, vault

## 简介

Encrypted secret storage for moxxy. AES-256-GCM at rest. Master key from OS keychain (@napi-rs/keyring) or passphrase fallback.
