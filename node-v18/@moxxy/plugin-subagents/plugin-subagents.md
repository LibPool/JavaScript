# @moxxy/plugin-subagents

> 标签: agent, fan-out, moxxy, subagents, tools

## 简介

Spawn typed subagents in parallel. Plugins contribute agent kinds via the AgentDef registry; this plugin exposes the dispatch_agent tool and an auto-detection skill.
