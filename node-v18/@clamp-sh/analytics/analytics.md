# @clamp-sh/analytics

> 标签: analytics, cdn, cookieless, error-tracking, event-tracking, gdpr, mcp, nextjs, pageviews, privacy-first, product-analytics, react, revenue-tracking, sessions, shopify, tracking, typescript, web-analytics, webflow, wordpress

## 简介

Privacy-first analytics SDK for Clamp Analytics. MCP-native — your AI agent can query the same events. Auto-pageviews, sessions, revenue, errors. Browser, server, React, and one-tag CDN install for Webflow / Shopify / WordPress and other hosted platforms.
