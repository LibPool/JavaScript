# @clamp-sh/event-schema

> 标签: analytics, codegen, event-schema, events, schema, tracking-plan, typescript

## 简介

Reference CLI for the Event Schema spec — a portable, typed YAML format for declaring product analytics events. Validate event-schema.yaml against the spec and generate TypeScript types from it.
