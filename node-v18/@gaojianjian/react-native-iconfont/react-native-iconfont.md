# @gaojianjian/react-native-iconfont

> 标签: icon, iconfont, iconfont.cn, icons, react-native, react-native-iconfont

## 简介

用纯JS把iconfont.cn的图标转换成RN组件，不依赖字体，支持多色彩，支持热更新
