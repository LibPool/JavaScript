# @deenruv/merchant-plugin

> 标签: JavaScript

## 简介

Plugin for exporting product catalog data to merchant platforms like Google Merchant Center and Facebook Commerce. It supports a strategy-based approach for transforming product data into platform-specific formats and managing platform integration setting
