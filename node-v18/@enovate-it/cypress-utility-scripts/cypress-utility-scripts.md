# @enovate-it/cypress-utility-scripts

> 标签: automation, cleanreport, cypress, emailotp, enovate, reports, utils

## 简介

utility scripts to send emails, read OTP from emails, clean reports folder, combine individual report and send over email and some generic commands to perform actions like select, select from dropdown, Bypass Google SSO login, custom actions over elements
