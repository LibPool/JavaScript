# @schemastud/rjsf-registry

> 标签: JavaScript

## 简介

Generally-useful additions over react-jsonschema-form: predicate-based widget resolution, uiSchema derivation from schema-carried hints, configurable extension-keyword tolerance, an injected $ref fetcher seam, and a base SchemaForm. Host-agnostic — no ven
