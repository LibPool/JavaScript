# @whyshu/argent-gateway

> 标签: JavaScript

## 简介

Argent on DSH — 飞书网关（hermes gateway 的 dsh 官方化实现，决策⑱）：lark-cli 事件消费 + ctx.agents 常驻持久会话 agent，每 Bot 路由到独立 agent，@ 准入 + 多轮上下文跨轮保留；任务驱动（自动审查/自主模式）+ 角色管理 UI
