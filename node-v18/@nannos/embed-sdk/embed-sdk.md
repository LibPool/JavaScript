# @nannos/embed-sdk

> 标签: a2a, agent, ai-sdk, chat, embed, nannos, react, shadow-dom, web-component

## 简介

Embeddable Nannos: headless core (protocol + object registration + client-action) and a styleable React UI kit, distributed as a Shadow-DOM web component.
