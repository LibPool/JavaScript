# @obipascal/vtpass-nodejs-sdk

> 标签: APIs, Library, Node.js, Nodejs, SDK, VTPass

## 简介

VTPass Node.js SDK for interacting with VTPass api on Node.js environment. The library support both ES6 and CommonJS. It's well documented and typed.
