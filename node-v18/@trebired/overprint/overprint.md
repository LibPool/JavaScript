# @trebired/overprint

> 标签: canvas, dither, halftone, overprint, print, risograph, rust, webassembly

## 简介

Risograph-style prints as layered vector SVG: one plate per ink, halftone and dither screens, knockouts, misregistration and motion, rendered as markup in Bun or as a React component, with the pixel work in Rust compiled to WebAssembly.
