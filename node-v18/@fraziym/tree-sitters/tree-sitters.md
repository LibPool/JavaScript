# @fraziym/tree-sitters

> 标签: axodex, axoniz, fraziym, grammar, node-gyp, parser, prebuilt, tree-sitter

## 简介

FRAZIYM-maintained tree-sitter grammar collection. Vendored from upstream tree-sitter-* npm packages that have no prebuilds and fail native compilation on Node 22+ Windows CI runners. Each grammar ships as a sub-package with platform prebuilds (linux-x64,
