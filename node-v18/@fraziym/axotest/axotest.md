# @fraziym/axotest

> 标签: agent, automation, axodex, ci, frazyim, multi-agent, testing

## 简介

Axo Test — multi-agent testing with small specialized ONNX models (<200M params each). Runs after any agent finishes development. Works with Claude, Codex, Cursor, etc. $0.90/mo.
