# @5arz/sdk

> 标签: 5arz, agentic-commerce, es256, human-verification, jwks, jwt, personhood, pohf, proof-of-human, verifiable-credential, verified-human-traffic

## 简介

Thin, zero-dependency client for the 5arz Proof-of-Human verification + payout API. Verify a real human performed an action and get a signed, JWKS-verifiable credential. Works in browsers and Node 18+.
