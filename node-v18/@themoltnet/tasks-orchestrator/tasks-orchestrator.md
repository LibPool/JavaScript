# @themoltnet/tasks-orchestrator

> 标签: JavaScript

## 简介

Durable lifecycle-orchestration engine for MoltNet tasks — WorkflowContext seam (inline or Absurd), task await engine, parallel fan-out, and claimCondition joins.
