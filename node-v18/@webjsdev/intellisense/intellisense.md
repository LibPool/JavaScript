# @webjsdev/intellisense

> 标签: language-service, tsserver-plugin, typescript, web-components, webjs, webjsdev

## 简介

The TypeScript language-service plugin for WebJs, a full-stack JavaScript framework built on web components with server-side rendering and no build step. Adds in-template intelligence with no Lit dependency: go-to-definition on tags, attributes, and CSS c
