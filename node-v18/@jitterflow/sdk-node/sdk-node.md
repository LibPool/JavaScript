# @jitterflow/sdk-node

> 标签: dead-letter-queue, jitterflow, retry, sdk, standard-webhooks, webhook, webhooks

## 简介

Official Node.js/TypeScript client for the Jitterflow webhook delivery API — endpoint management, ingestion, DLQ replay, and outbound signature verification (legacy + Standard Webhooks).
