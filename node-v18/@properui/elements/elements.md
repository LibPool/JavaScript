# @properui/elements

> 标签: angular, astro, components, custom-elements, design-system, svelte, tailwindcss, vue, web-components

## 简介

Proper UI as framework-agnostic custom elements (<pui-button>, <pui-modal>, ...) for Vue, Angular, Svelte, Astro and plain HTML. Light DOM, no framework runtime.
