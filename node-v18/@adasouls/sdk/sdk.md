# @adasouls/sdk

> 标签: adasouls, agent-payments, ai-agents, alma, sdk

## 简介

TypeScript SDK for AdaSouls: a typed, zero-dependency client over the AdaSouls API that gives agent runtimes a domain-verb API (agent.execute({ capability: 'pay', ... })).
