# @chzky/cest

> 标签: JavaScript

## 简介

`@chzky/cest` 旨在提供一个简洁直观的 API，用于编写和组织你的测试。它支持异步测试、跳过测试、以及按顺序执行的步骤测试，并提供了一套断言工具来帮助你验证代码行为。
