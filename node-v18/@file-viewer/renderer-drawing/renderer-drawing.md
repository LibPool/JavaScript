> 标签: bpmn, diagram, document-preview, document-viewer, drawio, excalidraw, file-preview, file-viewer, mermaid, plantuml, renderer, self-hosted

## 简介

Draw.io, Excalidraw, Mermaid, and PlantUML renderers for File Viewer, with an opt-in BPMN viewer.
