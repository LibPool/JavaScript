# @file-viewer/renderer-word

> 标签: doc, document-preview, document-viewer, docx, file-preview, file-viewer, odt, office-viewer, renderer, rtf, self-hosted, word

## 简介

Standalone DOCX, DOC, and OpenDocument renderer for File Viewer; RTF parsing is an explicit opt-in capability.
