# @kulesy/annotator

> 标签: annotation, astro, comments, feedback, github-issues, react, review, vercel

## 简介

Floating in-browser annotation tool that posts to GitHub Issues. Click any element, leave a comment. Framework-agnostic core with React and Astro wrappers.
