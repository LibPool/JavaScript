# atlas-owner

> 标签: claude, graph, mcp, memory, opencode, plugin, product-owner, skill

## 简介

Product Owner graph memory for any project. Modular auto-sharded JSON graph + CLI (init/record/query/get/check) + opencode enforce plugin. Scales to 10k nodes, zero dependencies.
