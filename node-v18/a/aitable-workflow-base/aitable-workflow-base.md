# aitable-workflow-base

> 标签: JavaScript

## 简介

与运行环境无关的公共代码：前后端共享的 HTTP/SSE 契约、Stage × Phase 状态机、澄清表单语义、运行态 reducer。不依赖 Node 也不依赖 DOM，因此两端都能直接消费。
