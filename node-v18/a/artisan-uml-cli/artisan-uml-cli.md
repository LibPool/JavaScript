# artisan-uml-cli

> 标签: agentic, ai, architecture, class-diagram, claude-code, codex, csharp, opencode, scaffolding, uml, unity

## 简介

Human-first class diagrams for agentic coding. Scan C# into an editable UML diagram, track human vs AI changes, scaffold back into code.
