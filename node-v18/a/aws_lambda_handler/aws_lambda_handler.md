# aws_lambda_handler

> 标签: JavaScript

## 简介

Returns a lambda handler that when invoked with a Sns/dynamodb event and lambda context object, it will invoke the `eventHandler` with a parsed json message and a node callback. The `eventHandler` callback is an async.each `iterator` function. Each Record
