# a2a-codex

> 标签: a2a, agent-to-agent, ai-agents, codex, codex-sdk, interoperability, mcp, model-context-protocol, multi-agent, openai, repository-sandbox, streaming

## 简介

A2A (Agent-to-Agent) protocol wrapper for OpenAI Codex SDK. Drop a JSON config file in, get a fully-spec-compliant A2A server out. Supports repository sandboxing, MCP tools, streaming sideband events, and multi-agent delegation.
