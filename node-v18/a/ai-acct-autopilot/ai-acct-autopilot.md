# ai-acct-autopilot

> 标签: account-switcher, autopilot, claude, claude-code, cli, codex, dashboard, macos, menu-bar, menubar, multi-account, rate-limit, usage

## 简介

Native macOS menu bar autopilot for multiple Claude Code and Codex accounts: live usage bars, auto-switch before rate limits, sessions resumed on the fresh account.
