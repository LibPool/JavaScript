# appstore-precheck

> 标签: agent-skill, app-store, claude-code, fastlane, grok-build, ios, precheck

## 简介

Read-only iOS App Store pre-submission check, packaged as a portable Agent Skill with native Claude Code, Cursor, Codex, and Grok Build plugins, plus an npx CLI.
