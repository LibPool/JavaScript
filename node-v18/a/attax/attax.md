# attax

> 标签: JavaScript

## 简介

Attax est un outil permettant le scrapping de linkedin pour des utilisateurs lambda. Vous pouvez convertir une liste d'utilisateurs (nom, prénom) en liste de lien linkedin. Vous pouvez aussi ajouter une liste d'amis, visiter des profils ou encore dumper l
