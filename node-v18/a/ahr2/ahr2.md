# ahr2

> 标签: ahr, browser, cors, file, http, https, jsonp, xdm, xhr, xhr2, xmlhttprequest

## 简介

An Abstract Http Request for Node.JS (http/https) and the Browser (XMLHttpRequeuest2). For `npm install ahr2` for Node and `pakmanager build` for Ender / Pakmanager. It should be required as `var request = require('ahr2')`
