# agent-feedback-loop-dsh

> 标签: agent, dsh, dsh-plugin, feedback, hooks, memory, reflection

## 简介

Native DeepSeek Harness plugin: feeds every prompt into the local agent-feedback-loop capture pipeline and injects compiled recurrence rules back as context.
