# agent-session-inspector

> 标签: agent, ai-agent, claude, claude-code, codex, copilot, copilot-chat, cost, cursor, gemini-cli, hermes, llm, observability, opencode, session, token-usage, tokens, transcript, vscode

## 简介

See where a coding-agent session's tokens and dollars went: a local inspector for Claude Code, Codex, GitHub Copilot, Cursor, Gemini CLI, OpenCode and Hermes sessions, with a step-by-step timeline, per-step cost and analytics.
