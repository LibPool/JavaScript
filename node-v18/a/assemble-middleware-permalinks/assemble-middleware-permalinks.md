# assemble-middleware-permalinks

> 标签: SEO, assemble, assemblecollection, assembleplugin, blog, front, generator, handlebars-helper-eachitems, handlebars-helper-paginate, links, matter, moment, moment.js, parse, permalink, permalinks, post, pretty, site, slug, static, uri, url, yaml

## 简介

Permalinks plugin for Assemble, the static site generator for Grunt.js, Yeoman and Node.js. This plugin enables powerful and configurable URI patterns, [Moment.js](http://momentjs.com/) for parsing dates, much more.
