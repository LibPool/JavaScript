## 简介

```bash # 当前目录执行，安装文档系统依赖。（文档系统使用的webpack3.） $ npm i # 进入webpack4目录，安装webpack4环境，打jar包使用的webpack4. $ cd webpack4 && npm i ``` 为了独立安装webpack4，webpack4打包的代码在f12的sources面板是模块化的形式(不是很多代码在一整页的js里)，方便调试。
