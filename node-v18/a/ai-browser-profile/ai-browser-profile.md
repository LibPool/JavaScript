# ai-browser-profile

> 标签: ai-agent, autofill, browser-data, browser-profile, claude, claude-code, embeddings, identity, knowledge-base

## 简介

Extract user identity (name, emails, accounts, addresses, payments) from browser data into a self-ranking SQLite database. Install as a Claude Code agent skill.
