# autoaidev

> 标签: agent, ai, automation, autonomous, claude, copilot, loop, opencode, task, todo

## 简介

Autonomous AI task loop: reads TODO.md, sends tasks to Claude CLI, Copilot CLI, or OpenCode, tracks progress, supports session resume, Discord, and webhooks
