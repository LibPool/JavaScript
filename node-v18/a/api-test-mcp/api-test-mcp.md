# api-test-mcp

> 标签: ai-agents, api, api-testing, claude, claude-code, contract-testing, cursor, developer-tools, devtools, json-schema, llm-tools, mcp, mcp-server, model-context-protocol, openapi, rest-api, schema-validation, swagger

## 简介

MCP server that lets AI agents load an OpenAPI spec, call real endpoints, validate responses against the documented schema, run a full contract-test pass, diff two spec versions for breaking changes, and health-check a set of endpoints.
