# angular-ui-xmomen

> 标签: JavaScript

## 简介

基于bootstrap，angular等前端主流框架自主开发的前端UI框架，涵盖表单，表格，导航及菜单等基本元素样式， 以及表单校验，日期选择器，分页及树形菜单等组件（基于angular的指令），极大的提高了前端人员的开发效率， 平台现处于开发优化阶段，如有任何问题及建议，请及时反馈至平台开发小组。
