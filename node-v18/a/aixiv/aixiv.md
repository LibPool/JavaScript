# aixiv

> 标签: agent-traces, ai, aixiv, arxiv, claude-code, codex, cursor, latex, mathematics, preprint, publish, research

## 简介

Command-line client for aiXiv (aixiv.online): log in once in the browser, publish a LaTeX paper from its folder (server-side compile, dry run first, timestamped SHA-256 record), add versions, and attach the raw session files of Claude Code, Codex CLI, Gem

- npm 页面：https://www.npmjs.com/package/aixiv
