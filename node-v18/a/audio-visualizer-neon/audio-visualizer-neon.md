> 标签: animation, audio, audio-visualizer, canvas, equalizer, javascript, music-visualizer, react, spectrum, three.js, vanilla-js, visualizer, vue, web-audio-api, webaudio

## 简介

Visualizador de audio JavaScript para web en tiempo real. MP3, WebM, WAV, OGG. Canvas 2D y Three.js 3D. Compatible con React, Vue, vanilla JS.
