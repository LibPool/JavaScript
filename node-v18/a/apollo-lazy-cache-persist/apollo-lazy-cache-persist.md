# apollo-lazy-cache-persist

> 标签: apollo, apollo-client, cache, graphql, indexeddb, lazy, optimization, performance, persist, react, react-native

## 简介

Lazy per-query cache restore for Apollo Client (v3 & v4) to reduce startup time and memory usage.
