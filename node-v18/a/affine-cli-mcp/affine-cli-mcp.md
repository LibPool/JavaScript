# affine-cli-mcp

> 标签: affine, ai, claude, knowledge-base, mcp, model-context-protocol

## 简介

Command Line Interface (CLI) and a Model Context Protocol (MCP) server for interacting with AFFiNE. Enables AI assistants to interact with AFFiNE workspaces, documents, and collaboration features.
