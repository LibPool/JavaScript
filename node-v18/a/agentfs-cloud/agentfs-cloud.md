# agentfs-cloud

> 标签: agent, agent-memory, agent-swarm, agentfs, ai, cloud-filesystem, cloud-storage, context-engineering, file-system, filesystem, fuse, llm, mcp, mount, persistent-storage, posix, shared-filesystem, suite, tool-use

## 简介

Persistent cloud native virtual filesystem for AI agents. Install Suite to give agents scoped read/write access to files through normal filesystem paths.
