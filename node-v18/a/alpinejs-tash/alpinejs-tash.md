# alpinejs-tash

> 标签: alpine, alpinejs, alpinejs-plugin, interpolation, mustache, templating

## 简介

Alpine JS plugin that enables mustache-like templating syntax for simpler data binding and rendering in your Alpine JS applications 🚀
