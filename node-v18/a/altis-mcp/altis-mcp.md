# altis-mcp

> 标签: altis, app-store, app-store-optimization, aso, claude, keywords, mcp, model-context-protocol

## 简介

MCP server for Altis ASO (tryaltis.com): reads the local Altis macOS app database and queries the App Store for live keyword data.
