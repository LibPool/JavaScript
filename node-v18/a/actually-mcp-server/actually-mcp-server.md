# actually-mcp-server

> 标签: ai-agents, claude, mcp, mcp-server, model-context-protocol, news, polymarket, prediction-markets, probability, trading

## 简介

MCP server that matches news text to Polymarket prediction markets and returns the market's current probability - plus optional trading tools (place, sell, redeem) using your own wallet.
