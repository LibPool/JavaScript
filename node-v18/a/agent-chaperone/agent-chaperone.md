# agent-chaperone

> 标签: agent-security, ai-agent, claude-code, firewall, guardrails, llm-security, mcp, model-context-protocol, prompt-injection, tool-calling

## 简介

A calibrated firewall for AI agent tool calls: screens them before they run, and screens tool results before the agent reads them. Covers MCP servers through a proxy and a client's built-in tools through a hooks adapter.
