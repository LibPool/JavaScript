# ai-relational-memory

> 标签: agent, ai-agent, cli, driver, memory, migrations, pg, postgres, postgresql

## 简介

Механика реляционной памяти ИИ-сотрудника: доступ к PostgreSQL драйвером JavaScript, миграции с учётом применённого и принятием живой базы — CLI и программный API; внешний клиент psql не нужен
