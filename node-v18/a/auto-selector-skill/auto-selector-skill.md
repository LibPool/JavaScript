# auto-selector-skill

> 标签: ai-agent, claude-code, codex, cursor, gemini-cli, plugin, router, selector, skill

## 简介

Always-on skill & plugin selector for AI coding agents. Scans installed skills/plugins, analyzes user tasks, selects the best match, asks for confirmation before invoking.
