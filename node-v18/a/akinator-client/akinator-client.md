# akinator-client

> 标签: akinator, akinator-api, akinator-client, cloudflare, discord-bot, game, guess, nodejs, proxy, session, typescript

## 简介

A modern, fully typed Node.js client for Akinator that actually works. Bypasses Cloudflare 403, with proxy, retry, session persistence, 16 languages and Discord bot example.
