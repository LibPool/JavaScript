# ascii-motion-mcp

> 标签: ai, animation, ascii-art, llm, mcp, model-context-protocol

## 简介

MCP (Model Context Protocol) server for Ascii-Motion - enabling LLM-powered tools to create, animate, import, and export ASCII art
