# astro-cloudflare-cms

> 标签: astro, astro-integration, cloudflare, cms, d1, r2, react

## 简介

Drop-in D1+R2 CMS for Astro + Cloudflare + React sites — an Astro integration that injects admin UI, public /news, auth, and media.
