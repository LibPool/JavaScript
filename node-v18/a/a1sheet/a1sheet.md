# a1sheet

> 标签: csv, csv-parser, data-grid, editor, excel, excel-export, excel-viewer, formula, formula-engine, grid, headless, ooxml, parser, react, react-component, react-spreadsheet, sheet, spreadsheet, spreadsheet-component, typescript, viewer, workbook, xlsx, xlsx-parser, zero-dependency

## 简介

React spreadsheet component with Excel (XLSX) and CSV import/export, a formula engine, and a virtualized editable grid. Zero runtime dependencies.
