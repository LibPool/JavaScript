# arckit-pay-mcp

> 标签: arc, arckit, arcpay, gift-cards, mcp, model-context-protocol, usdc

## 简介

MCP server that gives your AI a wallet on Arc and lets it buy gift cards and mobile top-ups with USDC through ArcPay.

- 官网：https://arc-tools.vercel.app/pay
- npm 页面：https://www.npmjs.com/package/arckit-pay-mcp
