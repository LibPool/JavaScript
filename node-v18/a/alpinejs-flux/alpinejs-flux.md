# alpinejs-flux

> 标签: Alpine, Alpine JS, Alpine JS Flux, Alpine JS Plugin, Alpine JS Plugins

## 简介

Simplifies the process of applying CSS classes with x-transition as a template and makes them reusable within single attribute.
