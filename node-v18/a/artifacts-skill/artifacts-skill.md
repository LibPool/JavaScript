# artifacts-skill

> 标签: agent-skill, ai-agent, claude-code, document-verification, mcp, pdf

## 简介

A local-first verification and evidence-generation engine for AI-generated documents: inspect, plan, execute, render, verify, and receipt PDF/PPTX/DOCX/XLSX/image/HTML/SVG artifacts, locally.
