# appflare

> 标签: JavaScript

## 简介

A generate-first backend framework for **Cloudflare Workers**. Write a schema and handlers, and the Appflare CLI generates a Hono server, a typed client and your `wrangler.json`. The generated backend includes D1 with Drizzle, Better Auth, R2 storage, a Q
