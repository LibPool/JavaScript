# alkahest-ts

> 标签: JavaScript

## 简介

TypeScript SDK for [Alkahest](https://github.com/arkhai-io/alkahest), a library and ecosystem of contracts for conditional peer-to-peer escrow. Built on [viem](https://viem.sh/).
