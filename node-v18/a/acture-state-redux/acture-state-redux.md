# acture-state-redux

> 标签: acture, command-dispatch, redux, redux-toolkit, rtk, state

## 简介

acture StateAdapter for Redux Toolkit (RTK). Wraps an RTK store as a PatchCapableAdapter via RTK's bundled Immer.
