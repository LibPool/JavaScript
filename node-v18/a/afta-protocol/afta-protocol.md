# afta-protocol

> 标签: afta, agent-fair-trade, agent-payments, ai-agents, ed25519, open-standard, receipts, x402

## 简介

Reference implementation of the Agent Fair-Trade Agreement (AFTA): an open standard for API publishers fair to AI agents. Code-enforced no-charge guarantees, Ed25519-signed receipts, transparent pricing, inference-only license.
