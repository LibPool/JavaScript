# aws-selenoid

> 标签: JavaScript

## 简介

This is a small side project to create a library which uses AWS and Selenoid to provide test infrastructure.   Selenoid can be used to provide and manage containerized browsers. It puts each browser into its own container, which can be provisioned on-dema
