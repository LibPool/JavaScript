# agent-observability-trace-cli

> 标签: agent-trace, agentic-ai, ai-agents, cli, debugging, langgraph, llm, observability, openai, python-cli, record-replay, tracing

## 简介

npm-installable CLI wrapper for agent-trace, deterministic record and replay for LLM agent HTTP traffic. Forwards straight to the real Python agent-trace CLI. Requires Python 3.10+ and the agent-observability-trace-cli PyPI package.
