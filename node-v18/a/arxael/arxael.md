# arxael

> 标签: agents, ai, build, ci, merge, monorepo, orchestrator

## 简介

Run many AI coding agents on one box without breaking `main` — a merge gate that lands their PRs onto a shared main (auto-reverting anything red) plus one warm, bounded, shared build/test executor.
