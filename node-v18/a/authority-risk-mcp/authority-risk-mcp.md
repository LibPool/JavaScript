# authority-risk-mcp

> 标签: ai-agents, defi, mcp, model-context-protocol, security, smart-contracts

## 简介

Read-only MCP server: who can change a smart contract, how fast, and how strong the setup is. Reads the signed files of the Authority Risk Oracle Watch. A thin launcher around the Python server (needs python3 3.9 or newer).
