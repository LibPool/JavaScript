# aioli-design

> 标签: accessibility, agents, ai, atomic-design, component-generation, design-system, design-tokens, dtcg, figma, free, mcp, model-context-protocol, open-source, react, style-dictionary, svelte, vue, wcag

## 简介

Free, open-source AI design system engine. Natural language to React, Vue, Svelte, or HTML components with WCAG AA accessibility, 1,754 design tokens, 6 theme presets, and MCP server integration.
