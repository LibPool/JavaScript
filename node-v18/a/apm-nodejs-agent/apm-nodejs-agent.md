# apm-nodejs-agent

> 标签: NodeJs, 探针

## 简介

APM的nodejs探针，通过实时采集接口调用、外部调用以及各种中间件的指标、调用链数据，帮助用户全面掌握 nodejs 应用的运行情况，快速定位线上故障的根源。
