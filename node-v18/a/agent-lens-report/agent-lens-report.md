# agent-lens-report

> 标签: agentic, ai-coding, antigravity, claude-code, codebase-visualization, codex, cursor, project-status, vibe-coding

## 简介

See where an agent-built project actually stands. Reads git, plan files, and local coding-agent session logs, and writes one self-contained HTML report.
