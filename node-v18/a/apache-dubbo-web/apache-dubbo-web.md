# apache-dubbo-web

> 标签: JavaScript

## 简介

Dubbo is a family of libraries for building and consuming APIs on different languages and platforms. [apache-dubbo](https://www.npmjs.com/package/apache-dubbo) brings type-safe APIs with Protobuf to TypeScript.
