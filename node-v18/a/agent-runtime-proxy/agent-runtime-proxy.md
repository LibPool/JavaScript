# agent-runtime-proxy

> 标签: agent-runtime, agent-security, command-injection, correctover, credential-protection, ed25519, fail-closed, mcp, mcp-proxy, mcp-security, model-context-protocol, runtime-interception, second-enforcement-layer, ssrf, stdio-proxy, supply-chain-security

## 简介

Agent runtime proxy — transparent fail-closed stdio proxy in front of an MCP server (Agent 运行时全栈拦截). Only tools/call is intercepted and verified; denied verdicts, verifier errors and timeouts are never forwarded. Ed25519 receipts. Zero dependencies.
