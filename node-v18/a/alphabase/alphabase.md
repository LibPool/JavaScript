# alphabase

> 标签: audit-logging, backup, cache, caching, connection-pool, database, embedded-database, encryption, event-emitter, file-based, health-checks, http-server, https, indexing, json, jwt-authentication, key-value, lightweight, lru, metrics, monitoring, nodejs-database, performance, query-engine, rate-limiting, rest-api, rsa-encryption, soft-delete, streaming, transactions, ttl, typescript, validation, zero-dependency

## 简介

Lightweight embedded TypeScript database with advanced querying, streaming, monitoring, and validation features for single-process Node.js applications. Validated up to 250K records with near-linear scaling.
