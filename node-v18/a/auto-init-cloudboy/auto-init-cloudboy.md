# auto-init-cloudboy

> 标签: CI/CD, CLI, CLI Tool for Developers, Firebase, Frontend Setup, GitHub Actions, Modern Web Development, Project Automation, React, Tailwind CSS, Vite, Web App Starter, auto-init, auto-init-cloudboy

## 简介

`auto-init-cloudboy` is a **CLI tool** that simplifies the setup process for modern web projects by automating the creation of **React** applications using **Vite**, installing **Tailwind CSS**, configuring **Firebase**, and setting up **GitHub Actions**
