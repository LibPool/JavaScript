> 标签: Cross-Site Scripting, DOM, HTML, HTML to DOM, JavaScript, XSS, agnostic HTML, convert HTML, document.createElement, innerHTML, node creation, parser, safe DOM, sanitization, sanitizer, secure HTML parsing, security, vanilla JS

## 简介

A utility function that safely parses HTML strings into DOM nodes, avoiding the use of innerHTML for security reasons.
