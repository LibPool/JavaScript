# agent-feedback-ledger

> 标签: agent, feedback, learning, ledger, prompt, self-improvement, skills

## 简介

Append-only feedback ledger for agents: record human reactions, let a learner propose changes to skills and prompts, and apply them through a versioned, revertible gate.
