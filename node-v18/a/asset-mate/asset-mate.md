# asset-mate

> 标签: amazon, assets, auto, autogenerate, autoprefix, aws, babel, browserify, ecma6, es6, gulp, process images, react, rewrite, s3, sass

## 简介

Asset-Mate autogenerates a gulpfile based on a manifest, which enables you to easily compile, rewrite, copy, or deploy Javascript, ES6 and React with Browserify, SCSS, CSS and images
