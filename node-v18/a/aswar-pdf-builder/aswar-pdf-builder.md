# aswar-pdf-builder

> 标签: pdf, pdf-designer, pdf-generation, pdf-viewer, react, typescript

## 简介

TypeScript base PDF generator and React base UI. Open source, developed by the community, and completely free to use under the MIT license! (Based on PDFme of hand-dot)

## 官网

- 官网：https://pdfme.com
- 源码仓库：git+ssh://git@github.com/pdfme/pdfme.git
- npm 页面：https://www.npmjs.com/package/aswar-pdf-builder
