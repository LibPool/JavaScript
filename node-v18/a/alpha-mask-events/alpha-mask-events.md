# alpha-mask-events

> 标签: alpha-mask, avif, click-through, image-transparency, png, pointer-events, transparency-detection, transparent, webp

## 简介

Enable click‑through on transparent regions of images (PNG, WebP, AVIF, GIF, SVG) using alpha masks.
