# aedibase-install

> 标签: aedibase, agent, baas, claude-code, codex, copilot, cursor, install, mcp, windsurf

## 简介

One command to connect AI coding agents (Claude Code, Cursor, Windsurf, Copilot, Codex, …) to your aedibase backend via MCP. Zero-install: npx aedibase-install --client claude-code --env AEDIBASE_TOKEN=aedu_...
