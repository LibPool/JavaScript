# agent-token-meter

> 标签: agent, ai-coding, burn-rate, claude, claude-code, cli, context-window, cost-tracking, cursor, developer-tools, monitoring, tokens, windsurf

## 简介

Burn-rate meter for AI coding agents. Surfaces quadratic session cost and reasoning-workspace drift; nudges curated handoffs at 50/75/90% via a bundled agent protocol so context resets at position 0 instead of /compact summarizing under pressure. Zero dep
