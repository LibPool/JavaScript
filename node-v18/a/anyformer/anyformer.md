# anyformer

> 标签: agent, browser, diffusion, diskformer, gguf, inference, llm, localmind, onnx, transformers, webgpu, webmcp

## 简介

One call to run a model in a browser tab: anyformer reads the Hub repo, probes the browser, and picks the back end (transformers.js, LocalMind's WebGPU kernels, diskformer, kohra) that fits the model's format, architecture and your GPU budget.
