# ailc-mcp

> 标签: code-quality, compliance, devsecops, mcp, offline, owasp, sarif, sast, security, taint-analysis

## 简介

ailc (AI Life Cycle): автономный оркестратор качества и безопасности кода как MCP-сервер. Обёртка скачивает готовый бинарь для вашей платформы и запускает его.
