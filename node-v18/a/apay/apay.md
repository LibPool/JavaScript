# apay

> 标签: JavaScript

## 简介

Apay计划打造成多平台支付模块,目前已经完成微信支付模块,后续会陆续加入支付宝支付等模块.模块采用全ts实现,拥有良好的类型提示,支持ts和js两种语言使用. ## 安装 pnpm add apay
