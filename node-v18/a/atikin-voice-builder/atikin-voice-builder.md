# atikin-voice-builder

> 标签: Atikin, Verse, atikin builder, atikin verse voice builder, atikin voice, atikin voice builder, builder, voice

## 简介

A library for adding customizable text-to-speech features to web apps. Includes natural voices, multi-language support, and inline text highlighting.
