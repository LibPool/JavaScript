# axle-storybook

> 标签: a11y, accessibility, ada, axe-core, storybook-addons, wcag, wcag-aa

## 简介

Storybook addon — runs axe-core 4.11 against every story and displays WCAG 2.2 AA violations in a Storybook panel. Same engine as axle CI, so what you see in the panel is what the GitHub Action will block on PR.
