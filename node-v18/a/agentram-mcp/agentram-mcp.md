# agentram-mcp

> 标签: agent-memory, agent-memory-api, agentram, ai-memory, anthropic, claude, claude-desktop, cline, cursor, llm-memory, mcp, memory, model-context-protocol, persistent-memory, temporal-memory, windsurf

## 简介

MCP server for AgentRAM. Persistent memory for AI agents with temporal memory support. No vector database, no embeddings, set up in about a minute. 15 tools for personal, shared, and versioned agent memory.
