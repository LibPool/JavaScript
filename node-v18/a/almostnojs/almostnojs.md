# almostnojs

> 标签: ajax, animation, custom-elements, data-binding, dom, dom-diffing, event-handling, framework, http-requests, javascript, lightweight, minimalist, no-dependencies, reactive, simple, small-library, state-management, template-literals, utility, web-components

## 简介

A minimalist, dependency-free JavaScript framework featuring tagged template rendering, DOM morphing, custom elements, state management, event handling, animations, and HTTP requests.
