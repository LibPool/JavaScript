# auditok

> 标签: audio, audio-activity-detection, segmentation, silence-detection, silence-removal, speech, tokenizer, vad, voice-activity-detection, webaudio

## 简介

Audio activity detection and segmentation: turn audio into events with min/max duration and silence semantics. JavaScript port of the Python auditok package. Zero dependencies.
