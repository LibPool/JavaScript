# aether-browser

> 标签: agent-browser, ai-agents, automation, browser, chrome, computer-use, human-in-the-loop, novnc, self-hosted

## 简介

Client and CLI for Agent Browser by Aether AI: drive one self-hosted Chrome session over a closed HTTP API and watch or take over that same session through noVNC.
