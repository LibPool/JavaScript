# athena-express-ng

> 标签: amazon, athena, aws, aws-sdk-v3, database, services, sql, web

## 简介

AthenaExpressNG makes it easier to execute SQL queries on Amazon Athena by consolidating & astracting several methods in the AWS SDK V3
