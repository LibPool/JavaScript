# agent-rewind

> 标签: ai-agents, audit, mcp, model-context-protocol, safety, undo

## 简介

Flight recorder + undo button for AI agents. MCP interception proxy: journals every tool call, snapshots state before destructive actions, holds oversized ones for approval, and gives operators per-action Undo, Rewind-to-T, and a kill switch.
