# ai-response-parser

> 标签: ai, ai-chat, ai-code-converter, ai-parser, ai-response, ai-response-parser, chat-ui, chatgpt, code-blocks, code-formatter, gemini, llm, markdown-parser, markdown-renderer, react-markdown, response-formatter, syntax-highlighting

## 简介

React component to parse and format AI/LLM responses with beautiful markdown, syntax-highlighted code blocks, tables, and dark mode support. Perfect for ChatGPT, Gemini, and AI chatbot UIs.
