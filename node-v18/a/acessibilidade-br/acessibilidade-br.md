# acessibilidade-br

> 标签: a11y, accessibility, acessibilidade, dyslexia, portugues, text-to-speech, tts, wcag, widget

## 简介

Biblioteca de acessibilidade web em portugues - widget flutuante com 14 ferramentas de acessibilidade e perfis rapidos (dislexia, baixa visao, TDAH, fotossensibilidade, dificuldade motora)
