# aoejs

> 标签: IntersectionObserver, animate-on-scroll, animations, effect, fadeIn, intersetion, on-scroll, scroll, scroll-effects, scroll-trigger, viewport

## 简介

Animate On entrance (AOE) is a lightweight, dependency free, insanely fast scroll animation library built on top of Intersection Observer API
