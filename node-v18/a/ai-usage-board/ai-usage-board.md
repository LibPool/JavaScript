# ai-usage-board

> 标签: ai, antigravity, claude-code, cli, cost, dashboard, gemini-cli, local, opencode, token, usage

## 简介

Claude Code / Gemini CLI / OpenCode / Antigravity のローカルログを読み取り、AIコーディングツールの使用量とコストを1画面にまとめるCLIツール。データは外部に送信しません。
