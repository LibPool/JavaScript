# airdcpp-sfv-folder-checker

> 标签: airdcpp, airdcpp-extensions, airdcpp-extensions-public

## 简介

Hub command /sfvcheck <folder> that recursively checks a folder for .sfv files and compares their CRC32 against the real files on disk. Works together with airdcpp-release-fixxer.
