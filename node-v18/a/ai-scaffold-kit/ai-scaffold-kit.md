# ai-scaffold-kit

> 标签: JavaScript

## 简介

A **one-stop UI kit for AI developers**: copy-paste components and AI patterns (chat UIs, prompts, agents) with consistent imports. Built with Radix UI and Tailwind CSS. Works with Cursor and Copilot.
