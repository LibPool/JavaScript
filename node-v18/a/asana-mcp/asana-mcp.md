# asana-mcp

> 标签: ai, api-client, asana, claude, mcp, model-context-protocol, project-management, tasks, typescript

## 简介

MCP server + typed TypeScript client for the Asana API. Read tools plus guarded, configurable write access (read_only / restricted / full). No delete operations by design.
