# audio2textjs

> 标签: AI, ASR, NLP, Whisper, audio, audio analysis, audio-to-text, automatic speech recognition, deep learning, language model, machine learning, natural language processing, processing, real-time transcription, sound processing, speech analysis, speech decoding, speech processing, speech-to-text, sst, transcription, voice conversion, voice recognition, voice-to-text

## 简介

A Node.js library for audio processing and transcription using the Whisper tool. It supports converting audio files to text using various pre-trained models
