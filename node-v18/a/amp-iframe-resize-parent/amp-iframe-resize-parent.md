# amp-iframe-resize-parent

> 标签: JavaScript

## 简介

A teeny tiny (0.27 kb before gzip) resize handler for parent iframes, that supports the [AMP-style resize event messages](https://ampbyexample.com/components/amp-iframe/#resizable-iframes).
