# angular-boss-pdf

> 标签: JavaScript

## 简介

This is library creates a bridge to use pdfmake library optimized for Angular V9. The Original code was forked from;  - https://github.com/BennyFranco/ng-pdf-make (Angular 2)  - http://pdfmake.org/
