# app-binary-info

> 标签: JavaScript

## 简介

Zero-dependency (besides a zip reader) parser for Android APK and iOS IPA app metadata - package/bundle id, version name and code, straight from the binary.

## 官网

- npm 页面：https://www.npmjs.com/package/app-binary-info
