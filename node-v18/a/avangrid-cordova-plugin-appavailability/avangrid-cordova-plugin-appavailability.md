# avangrid-cordova-plugin-appavailability

> 标签: Android, Cordova, Name, Package, PackageName, PhoneGap, Scheme, URI, URIScheme, app, availability, cordova-android, cordova-ios, ecosystem:cordova, iOS, installed, plugin

## 简介

This plugin for Cordova and PhoneGap allows you to check if an app is installed. It requires an URI Scheme (iOS) or a Package Name (Android).
