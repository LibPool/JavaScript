# autoclip-mcp

> 标签: ai, autoclip, claude, clips, mcp, model-context-protocol, shorts, video

## 简介

Model Context Protocol server for the AutoClip API — turn any long video into viral short-form clips from Claude, Cursor, or any MCP client.
