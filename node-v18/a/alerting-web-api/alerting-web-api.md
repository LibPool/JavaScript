# alerting-web-api

> 标签: JavaScript

## 简介

Alerting Web API enables you to schedule and send `alerts` or `notifications` to different channels. Supported channel is `EMAIL` and more will be implemented.
> `API Test Token` -> `Use generated Token from your Application.`
