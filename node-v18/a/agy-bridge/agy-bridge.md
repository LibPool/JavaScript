# agy-bridge

> 标签: agy, antigravity, claude-code, delegation, gemini, mcp

## 简介

MCP bridge that lets Claude Code delegate heavy tasks to the Antigravity CLI (agy) — purpose-built tools, model routing with fallback, and multi-turn session continuity.
