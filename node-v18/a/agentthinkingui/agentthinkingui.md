# agentthinkingui

> 标签: agent, agentic, ai, context-engineering, llm, observability, react, replay, tool-use, trace, visualization

## 简介

Framework-agnostic player that replays an agent's runtime footprint (a recorded trace) as an animated, scrubbable story — the LLM brain calling tools and getting back data (reason), an instruction (act), or both.
