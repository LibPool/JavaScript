# agent-quick-browse

> 标签: agent, browser-automation, chrome, claude-code, clef, jev, mcp

## 简介

Fast, cheap browser actions for agents: a decision model (Jev or Clef) drives your real, logged-in Chrome. CLI + MCP server.
