# ace-throttle

> 标签: api, atomic, bun, circuit-breaker, distributed, fixed-window, lua, rate-limit, rate-limiter, redis, sliding-window, throttle, token-bucket

## 简介

Distributed API rate limiting for Bun + Redis. Token Bucket, Sliding Window & Fixed Window algorithms via atomic Lua scripts. Zero race conditions across replicas.
