# aes-ctr-concurrent

> 标签: aes, aes-256, aes-256-ctr, block-cipher, byte-offset, cipher, concurrent, crypto, cryptography, ctr, decipher, decryption, encryption, iv-offset, nodejs, promise, secure, stream, typescript

## 简介

Native TypeScript Node.js library for AES-256-CTR, enabling concurrent encryption/decryption with precise IV offset handling down to any byte level, not just full blocks.
