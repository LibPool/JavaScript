# aur-icon

> 标签: JavaScript

## 简介

Aurora Icon es un proyecto dedicado a generar iconos para la interfaz de usuario (UI) del proyecto Aurora. Su set de iconos poseen la capacidad de ser animados y coloreados de manera muy sencilla, permitiendo una personalización rápida y sin mayores compl
