# automatic-scatter-labelling

> 标签: JavaScript

## 简介

Place labels in a scatter plot without overlapping. Implements the NOLOOKAHEAD described in https://www.think-cell.com/en/career/talks/pdf/think-cell_article_aaai2006.pdf
