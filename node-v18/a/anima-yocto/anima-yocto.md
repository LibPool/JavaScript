# anima-yocto

> 标签: anima, anima-yocto, anima-yocto-ajax, anima-yocto-core, anima-yocto-event, anima-yocto-touch

## 简介

Yocto is a javascript dom library for mobile from Anima, rebuild and simplify some modules from Zepto.
