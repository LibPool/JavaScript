# atlas-mcp-search

> 标签: ai-agents, anthropic, atlas, claude, github-search, mcp, model-context-protocol, npm-search, search, web-search

## 简介

Unified search across DuckDuckGo, GitHub, npm, PyPI, Stack Overflow, Wikipedia and Hacker News — for AI agents. No API keys required. Part of Atlas — infrastructure for AI agents.
