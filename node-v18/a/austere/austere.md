# austere

> 标签: BuckleScript

## 简介

A no-frills cli argument parser for reason. Forked from [minimist.re](https://github.com/jaredly/minimist.re),  which is inspired by [minimist](https://www.npmjs.com/package/minimist) and [yargs](https://www.npmjs.com/package/yargs).
