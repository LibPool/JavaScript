## 简介

Claude Code plugin wrapping Google's Antigravity CLI (agy / Gemini 3.x): deep web research with citations, branded HTML reports with infographics from a markdown source (TRAID Design System, 5 templates), one-shot prompts, git-diff code review, code/task
