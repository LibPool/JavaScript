# angularjs-sha512

> 标签: HMAC, cryptography, encryption, hash, sha, sha2, sha384, sha512, sha512/224, sha512/256

## 简介

This is a simple SHA-512, SHA-384, SHA-512/224, SHA-512/256 hash functions for AngularJs supports UTF-8 encoding.
