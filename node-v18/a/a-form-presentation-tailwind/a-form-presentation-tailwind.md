# a-form-presentation-tailwind

> 标签: JavaScript

## 简介

Adapter de apresentacao para `a-form-react` orientado a Tailwind CSS. O pacote nao instala nem injeta Tailwind: o host continua responsavel pela pipeline de CSS e pode substituir o fallback por suas classes utilitarias.
