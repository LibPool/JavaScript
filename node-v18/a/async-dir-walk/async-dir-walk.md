# async-dir-walk

> 标签: async, deep, dir, dir-files, dir-walk, directory, directory-contents, dirwalk, files, folder, folder-files, fs, map, nesting, node, recursive, walk

## 简介

Walks through a directory and all subdirectories (including nested) at the same time and returns a promise resolving to an array of file paths.
