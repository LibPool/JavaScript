# autorebase

> 标签: JavaScript

## 简介

Обновляет актуальность ветки в нескольких репозиториях. ## Установка ``` npm i autorebase -g ``` ## Запуск ``` autorebase [-b=branch] [-d=dir] [-m=modules] ``` ### Параметры  `-b --branch` string - Ветка
