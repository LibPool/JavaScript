# await-parallel-limit

> 标签: abort, abortsignal, allsettled, array, async, await, batch, cancel, concurrency, concurrency-limit, limit, p-limit, p-map, parallel, pool, promise, promise-pool, rate-limit, settle, throttle, typescript, zero-dependency

## 简介

Run async functions with a concurrency limit. Zero-dependency promise pool with ordered results, settle-all mode, a map helper, and AbortSignal cancellation. TypeScript tuple inference included.
