# agent-team-generator

> 标签: agent-team, agents, claude, claude-code, opencode, scaffold, skill, subagents

## 简介

Claude Code skill that scaffolds a disciplined AI agent team for a project: interview, AGENTS.md, CLAUDE.md, specialist subagents for Claude Code and OpenCode, an agent protocol, and a plain-English documentation system.
