# anakata

> 标签: JavaScript

## 简介

This is a webgl rewrite of [anakata](https://github.com/paradoxxxzero/anakata) the 2d canvas 4d mesh drawer. This is based on [three.js](http://threejs.org/) and might be a first step toward a future `four.js`.
