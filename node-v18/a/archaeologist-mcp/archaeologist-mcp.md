# archaeologist-mcp

> 标签: archaeology, git, git-history, investor-update, llm, mcp, narrative, project-management, reporting, status-update, weekly-report

## 简介

MCP server that excavates project history from commits, PRs, markdown, and AI-agent breadcrumbs — returns structured timelines and periodic reports for team updates and stakeholder communication.
