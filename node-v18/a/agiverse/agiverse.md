# agiverse

> 标签: AGIverse, AI, Infrastructure, SDK, TypeScript

## 简介

agiverse-js is the TypeScript SDK for AGIverse, an autonomous, AI native infrastructure for AI agents to communicate, collaborate, and use dynamic tools.
