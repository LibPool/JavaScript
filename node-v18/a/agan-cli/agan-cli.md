# agan-cli

> 标签: JavaScript

## 简介

agan-cli 是一个 react-native 的自动化配置脚手架，在初始化项目中集成了 redux、react-navigation 等优秀的解决方案组件，并对整个项目的目录结构进行了优化。 可能各人喜好不同，请在了解本插件之后再做选择。
