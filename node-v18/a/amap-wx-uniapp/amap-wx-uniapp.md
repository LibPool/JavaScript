# amap-wx-uniapp

> 标签: amap-wx

## 简介

高德地图微信小程序SDK ## 安装 ``` npm install amap-wx-uniapp --save ``` ## 使用 ```js var amapFile = require('amap-wx-uniapp') var myAmapFun = new amapFile.AMapWX({key:'高德Key'}) ``` ## 其他API 参考[高德地图微信小程序SDK文档](http://lbs.amap.com/api/wx/summary/)
