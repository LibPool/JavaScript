# ai-sheet-sdk

> 标签: JavaScript

## 简介

基于 [Univer](https://github.com/dream-num/univer) 的在线表格 SDK，提供可编辑和只读预览两种模式。通过 IR（Intermediate Representation）中间格式与后端交互，支持懒加载、自动保存、增量保存和 RTL 文本。
