# agent-liedetector-skill

> 标签: agent, ai, calibration, claude, claude-code, codex, cursor, hallucination, integrity, lie-detector, skill, uncertainty

## 简介

A confidence-calibration skill for any AI coding agent. Tags every claim 🟢 [VERIFIED] / 🟡 [INFERRED ~80%] / 🟠 [GUESSED ~30%] / 🔴 [UNKNOWN] so you can scan how much to trust each line.
