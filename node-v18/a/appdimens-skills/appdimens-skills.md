## 简介

Skills for AI coding agents (Claude Code, Codex, Gemini CLI, OpenClaw, Hermes, Cursor, Copilot, Windsurf) that implement layouts with AppDimens: base screen, layout intent, every AppDimens library, and a validation CLI.
