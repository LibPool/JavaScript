# aoi.scan

> 标签: JavaScript

## 简介

aoi.scan is an extension for aoi.js, this module adds more functions to use with aoi.js related to scanning. You need a [IPQualityScore](https://www.ipqualityscore.com/) api key to use some custom functions.
