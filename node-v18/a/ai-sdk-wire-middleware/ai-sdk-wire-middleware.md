# ai-sdk-wire-middleware

> 标签: ai-sdk, llm, middleware, tokens, tool-calling, vercel-ai, wire-format

## 简介

Compact-syntax tool-call middleware for the Vercel AI SDK v6 — drop tool-call output tokens by 19–60% with a <call>tool key=value</call> wire format.
