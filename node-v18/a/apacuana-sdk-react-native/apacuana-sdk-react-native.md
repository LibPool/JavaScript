# apacuana-sdk-react-native

> 标签: android, apacuana, ios, react-native, sdk

## 简介

Apacuana SDK React Native es un wrapper completo construido alrededor de `apacuana-sdk-core`. Proporciona una serie de Hooks y un Proveedor de Contexto de React (`Context Provider`) para facilitar la integración de los servicios de Apacuana en aplicacione
