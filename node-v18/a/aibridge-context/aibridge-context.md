# aibridge-context

> 标签: ai, briefing, changelog, cli, context, developer-tools, diff, express, git, watcher

## 简介

Zero-config CLI that auto-generates an AI briefing file for any project — tracks code changes with real diffs, errors, fixes, file structure, API routes and dependencies. One command: npx aibridge-context start
