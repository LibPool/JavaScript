# abcwallet-embed

> 标签: JavaScript

## 简介

## 简介 ABCWallet Embed 是一个简单、安全的秘钥管理方案。用户可以以熟悉的方式来进入区块链世界，降低了用户理解区块链的门槛。 开发者可以非常简单地把 ABCWallet Embed 集成到 Dapps 里面，从而降低用户的获取成本，提高 Dapp 收益。
