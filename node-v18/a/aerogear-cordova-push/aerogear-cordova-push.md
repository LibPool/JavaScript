# aerogear-cordova-push

> 标签: aerogear, cordova, cordova-android, cordova-firefoxos, cordova-ios, cordova-windows, cordova-wp8, ecosystem:cordova, push, unified, ups

## 简介

This plugin allows your application to receive push notifications, using the AeroGear UnifiedPush Server.
