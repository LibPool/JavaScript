# ai-text-watermark

> 标签: ai-content-detection, ai-provenance, ai-text-watermark, content-credentials, distortion-free-watermark, eu-ai-act, gumbel-watermark, llm-watermark, synthid, synthid-text, text-watermark, wasm

## 简介

Invisible, key-verifiable watermarks for AI/LLM text (SynthID-Text style) in Rust + WebAssembly. Generate, detect, embed a secret provenance message, and run an ultra-low-latency decode-loop proxy — Node and browser. Standalone wrapper around @claude-flow
