# alpharesin

> 标签: backtesting, converter, indicators, parser, pine, pinescript, technical-analysis, trading

## 简介

Pine in, many forms out: a clean-room parser and converter for Pine-compatible scripts (v5 and v6), with the runtime they run on and a command line. Not affiliated with TradingView.
