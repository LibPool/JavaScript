# agent-cost-controller

> 标签: agents, cost, finops, langchain, langgraph, mastra, observability, openai, telemetry, tokens, vercel-ai-sdk

## 简介

Wrap your OpenAI, Vercel AI SDK, Mastra, LangChain, or OpenAI Agents calls to track token usage and cost. Never touches keys, prompts, or completions.
