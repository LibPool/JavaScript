# astro-chat-widget

> 标签: ai, astro, astro-component, chat, chatbot, sse, streaming, widget, withastro

## 简介

Self-contained AI chat widget for Astro sites: streaming SSE answers, native <dialog>, iOS-keyboard-proof mobile sheet, zero framework runtime.
