# action-cycle

> 标签: JavaScript

## 简介

Small libary for reducing boilerplate related to action creators. It's provide way to define action creators for actions that includes more than 1 step, specificaly it includes: \ \ start - start action that will be something like GET_DATA \ end - GET_DAT
