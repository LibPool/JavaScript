# agent-webbridge

> 标签: agent-webbridge, ai-agent, automation, browser-automation, cdp, chrome, chrome-devtools-protocol, chrome-extension, chrome-profiles, claude-code, mcp, multi-account, multi-profile, parallel, puppeteer-alternative, real-browser, web-automation

## 简介

Clean-room, open-source browser automation for AI agents — drive your real Chrome (real logins) across multiple profiles IN PARALLEL. A lightweight Node daemon + MV3 extension, no closed-source dependency.
