# ac-spreadsheet

> 标签: JavaScript

## 简介

### 简介 **ac-spreadsheet** 是一个在线电子表格组件,依赖于[handsontable](https://github.com/handsontable/handsontable).该组件提供了列宽拖拽、列交换、排序、在线编辑、增减行、动态获取焦点行数据等操作。 ### 安装
