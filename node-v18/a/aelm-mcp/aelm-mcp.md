# aelm-mcp

> 标签: aelm, ai, cad, circuit, claude-code-plugin, eda, electronics, mcp, schematic

## 简介

MCP server + skills for the Aelm circuit-CAD toolchain. Lets an AI parse, render, analyze, and edit text-based electronic circuit diagrams.
