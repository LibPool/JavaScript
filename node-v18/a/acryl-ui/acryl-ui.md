# acryl-ui

> 标签: JavaScript

## 简介

ACRYL UI library for the Web and Desktop client: themed building blocks over the app's own primitives (Stack, Card, Field, SwitchField, SettingsRow, SelectField, Segmented, Tabs, Dialog, EmptyState), semantic color roles and slot helpers
