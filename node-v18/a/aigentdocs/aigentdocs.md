# aigentdocs

> 标签: agents-md, ai-agents, cli, docs-as-code, documentation, lint, scaffold

## 简介

CLI for the AIGentDocs docs-as-code standard: scaffold, validate, and maintain AI-agent-ready project documentation. Deterministic — no LLM involved.
