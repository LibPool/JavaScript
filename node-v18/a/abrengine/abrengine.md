# abrengine

> 标签: abr, adaptive-bitrate, dash, hls, onnx, onnxruntime, pensieve, reinforcement-learning, vhs, video, videojs

## 简介

Run a trained reinforcement-learning ABR controller (Pensieve-style A3C) as the adaptive-bitrate algorithm in JavaScript video players. Framework-agnostic core + Video.js/VHS adapter.
