# avifify

> 标签: avif, cli, compression, converter, git-hook, image, optimize, pipeline, pre-push, sharp

## 简介

Production-ready CLI tool to convert images to AVIF. Run standalone, in CI/CD pipelines, or as a git pre-push hook.
