# aolib-ts

> 标签: ao, ao1, ao2, attorney-online, protocol, typescript, websocket

## 简介

Self-contained TypeScript library for the Attorney Online protocol. Owns every packet schema, both wire formats (fantacode + JSON), encode/decode, and the typed dispatch surface.
