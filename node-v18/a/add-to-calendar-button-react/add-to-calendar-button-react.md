> 标签: add-event, add-to-calendar, add-to-calendar-button, apple, calendar, component, css, event, free, generator, google, javascript, microsoft, outlook, react, snippet, widget

## 简介

Convenient React wrapper for the add to calendar button snippet, which lets you reliably create beautiful buttons, where people can add events to their calendars.
