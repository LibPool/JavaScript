# alexandria-search

> 标签: agent, brave, daemon, exa, llm, rag, search, searxng, serper, tavily

## 简介

Local search daemon for LLM apps: provider-neutral search gateway with a hard token budget (Brave, Tavily, SearXNG, Serper, Exa, Google CSE).
