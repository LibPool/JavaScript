# astroplayground-bridge

> 标签: agent, astro, claude, mcp, playground

## 简介

MCP bridge that lets a local coding agent (Claude Code, Claude Desktop) edit an Astro Playground browser tab

## 官网

- 官网：https://astroplayground.com
- npm 页面：https://www.npmjs.com/package/astroplayground-bridge

- 0.1.0

- npm registry：https://registry.npmjs.org/astroplayground-bridge
- Node 要求：>=18
