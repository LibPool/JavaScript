# astmend

> 标签: JavaScript

## 简介

**Astmend は、TypeScript コードを AST ベースで安全に変更する Semantic Patch Engine です。**   文字列置換ではなく構文木を使って変更することで、LLM 連携時の「壊れた修正」を減らし、変更差分を明確に返します。
