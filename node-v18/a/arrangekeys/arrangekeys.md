# arrangekeys

> 标签: browser, deno, deno-edition, deno-entry, denoland, es2022, export-default, keys, module, node, objects, typed, types, typescript

## 简介

Returns a copy of a JavaScript object with the keys arranged in a specified order. Useful for formatting JSON files.
