# aegis-vault

> 标签: agent, ai-agent, autonomous-agents, dilithium, human-takeover, key-management, post-quantum, pqc, self-custody

## 简介

Aegis Vault Agent Autonomous Key Security — PQC (Dilithium2) keys, AES-256-GCM encryption, three-tier key derivation, and human takeover. Private keys never leave the agent/browser.
