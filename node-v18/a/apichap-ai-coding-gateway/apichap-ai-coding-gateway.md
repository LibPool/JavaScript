# apichap-ai-coding-gateway

> 标签: ai-agents, apichap, claude, claude-code, dashboard, guardrails, hooks, permissions

## 简介

apichap AI Coding Gateway: guardrails and a live dashboard for Claude Code. Checks every tool call against allow/deny rules, logs it locally, and collects approval requests.
