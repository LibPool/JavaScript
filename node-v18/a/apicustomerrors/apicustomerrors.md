# apicustomerrors

> 标签: API, API error responses, CustomError, Error, Error handling, Express middleware, HTTP API, INTERNAL SERVER ERROR, JSON error format, Not found, Problem Details, RFC 9457, errors

## 简介

Módulo para manejar errores HTTP siguiendo RFC 9457 Problem Details for HTTP APIs. Incluye clases de error predefinidas, middleware para Express y soporte completo para el formato estándar de Problem Details.
