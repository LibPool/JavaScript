# amap-tianditu-layer

> 标签: JavaScript

## 简介

高德地图天地图图层插件，由于高德地图使用 GCJ-02 坐标，天地图使用 CGCS2000，当在高德地图中混合使用天地图时会有偏移问题。本插件借助高德 API 提供的 CustomLayer 接口，自定义瓦片计算过程渲染天地图，修正偏移。
