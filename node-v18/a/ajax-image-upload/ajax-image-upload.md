# ajax-image-upload

> 标签: ajax, ajax-image-upload, image-upload, jquery, plugin

## 简介

jQuery图片上传插件，支持批量上传、预览、删除、放大、上传数量和尺寸限制以及上传前、上传中和上传后的回调函数
