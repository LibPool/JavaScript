# app-attest-server

> 标签: Apple, app, assertion, attest, attestation, devicecheck, express, nodejs, server, validation

## 简介

A robust and easy-to-use npm package that provides server-side validation of Apple App Attest artifacts and assertions. Simple toolkit for iOS device attestation.
