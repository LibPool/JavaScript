# astro-ts-prettier-eslint

> 标签: astro, eslint, prettier, tailwindcss, ts-standard, typescript

## 简介

A configuration package for Astro projects using TypeScript, Prettier, ESLint, and TailwindCSS. It sets up your project with best practices and required dependencies.
