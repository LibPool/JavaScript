# airdcpp-share-backup

> 标签: airdcpp, airdcpp-extensions, airdcpp-extensions-public

## 简介

Hub command /sharebackup [path] that saves a self-verified snapshot of your own share (folder names, file names, sizes, TTH) to a local backup file, with optional bz2 compression.
