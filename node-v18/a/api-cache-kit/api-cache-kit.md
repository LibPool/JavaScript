# api-cache-kit

> 标签: api-cache, cache, cache-invalidation, caching, express-middleware, memory-cache, nodejs, redis-cache, stale-while-revalidate, ttl

## 简介

A lightweight caching utility for Node.js and Express applications with memory cache, Redis support, TTL, and cache invalidation.
