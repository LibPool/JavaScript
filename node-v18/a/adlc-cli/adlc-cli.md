# adlc-cli

> 标签: adlc, agent, claude-code, cli, codex, commands, copilot, cursor, events, gemini, hooks, npx-skills, opencode, skills, slash-commands

## 简介

Dual-mode CLI for coding agents: skill management (install skills, generate slash commands, wire lifecycle events) + headless task execution (run any agent CLI with a task).
