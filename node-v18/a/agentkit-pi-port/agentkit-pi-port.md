# agentkit-pi-port

> 标签: adapter, agentkit, claude-code, migration, pi, pi-coding-agent, port

## 简介

One-shot port ALL AgentKit assets (~/.claude) → Pi agent (~/.pi/agent). Local bridge — never downloads AgentKit content from the internet.
