# ai-integration-generator-cli

> 标签: ai, api, chat, cli, generator, mcp, model-context-protocol, scaffold

## 简介

Terminal wizard for the AI Integration Generator - create a customized AI Server, MCP Server, AI Chat Client and docs for any existing API, right from the command line (create-vite / create-next-app style).
