# angular-schema-form-previewer

> 标签: Angular Schema Form, HTML, JSON, JSON Schema, form, preview, schema

## 简介

Previewer add-on for Angular Schema Form. No batteries included: user provides previewer functions (e.g., for HTML, markdown, etc.).
