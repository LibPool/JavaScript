# aidevix

> 标签: ai, aider, claude, cli, codex, copilot, developer-tools, fzf, gemini, launcher, ollama, tui

## 简介

One command, 47+ top AI CLIs. An interactive launcher that lists, installs and runs terminal AI coding agents (Claude Code, Codex, Gemini, Aider, Ollama, and more). English & Uzbek UI.
