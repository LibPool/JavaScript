# akeypair

> 标签: cert, certificate, encryption, https, key, keypair, keys, pem, private, public, rsa, self-signed, tls, x509

## 简介

Async generate a RSA PEM key pair and self-signed cert (X.509) from pure JS (slower) or compiled (faster)
