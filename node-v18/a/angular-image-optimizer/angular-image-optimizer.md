# angular-image-optimizer

> 标签: NgOptimizedImage, angular, avif, esbuild, image, image-loader, optimization, webp

## 简介

Build-time image optimization for Angular — generates multi-width WebP/AVIF variants and wires them into NgOptimizedImage via a custom IMAGE_LOADER.
