# autoforma-react

> 标签: array-fields, autoforma, custom-fields, custom-renderers, dynamic-forms, form, form-builder, form-generator, forms, json-form, object-fields, react, react-form, react-forms, react-hook-form, schema-driven, schema-form, typescript, validation

## 简介

Schema-driven React form generator built on React Hook Form with TypeScript, validation, dynamic schemas, custom renderers, custom field types, object fields, and array fields.
