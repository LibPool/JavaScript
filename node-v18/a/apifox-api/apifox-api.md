# apifox-api

> 标签: JavaScript

## 简介

一个命令行工具，把当前工作目录绑定到 Apifox 项目，搜索接口并生成 TypeScript 类型。数据来自 Apifox 的 OpenAPI 导出 API，按 Module 缓存到本地。
