# ampersand-sync-promise

> 标签: ampersand, backbone, rest, sync

## 简介

Standalone, modern-browser-only version of Backbone.Sync as Common JS module. Fork of the original ampersand-js-sync, but instead returns a promise.  All credit to original Ampersand JS team.
