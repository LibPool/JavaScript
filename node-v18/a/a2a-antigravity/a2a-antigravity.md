# a2a-antigravity

> 标签: a2a, agent-to-agent, ai-agents, antigravity, gemini, google, google-antigravity, interoperability, mcp, model-context-protocol, multi-agent, streaming, vertex-ai

## 简介

A2A (Agent-to-Agent) protocol wrapper for Google Antigravity SDK. Exposes Antigravity through the shared HTTP/JSON-RPC/REST/SSE A2A surface using a private Python SDK bridge.
