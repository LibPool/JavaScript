# ad-file-upload

> 标签: JavaScript

## 简介

Directives Angular pour l'upload de fichiers : sélection via `<input type="file">` et glisser-déposer, avec gestion de file d'attente, filtres (taille, type MIME), progression et hooks sur chaque étape du cycle d'upload.
