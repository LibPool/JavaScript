# athreix

> 标签: ai, automation, b2b, crm, lead-generation, linkedin, outreach, playwright, sales

## 简介

Athreix Outreach — self-hosted LinkedIn outreach automation: AI lead-gen, ban-safe pacing presets, and team-wide dedup. The npm package wraps the bundled Python app; `athreix setup` provisions a venv, dependencies, the Playwright browser, and the database
