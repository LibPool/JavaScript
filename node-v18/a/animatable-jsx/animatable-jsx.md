# animatable-jsx

> 标签: animatable, animatable-js, animation, canvas, canvas animation, client-side, curved animation, expansion, front-end, jsx, jsx animation, lightweight

## 简介

This extension package of animatable-js allows for easy and lightweight implementation of linear or curved animations in a JSX/TSX environment.
