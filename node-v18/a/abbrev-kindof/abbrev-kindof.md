# abbrev-kindof

> 标签: abbrev, abbreviations, array, check, kind, kindof, letter, object, polyfill, shim, single, string, tower, type, typeof, validate, validating

## 简介

Use abbreviations for checking type of given value. Like `kindof(val, 'soa')` to check that value is string, object or array.
