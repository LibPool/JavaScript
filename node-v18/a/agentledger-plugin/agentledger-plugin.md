# agentledger-plugin

> 标签: agentledger, ai-agent, claim-detection, claude-code, claude-code-plugin, coding-agent, guardrails, trust, verification

## 简介

The trust layer for AI coding agents. Catches false completion claims in real-time, blocks protected file writes, and tracks claim accuracy across sessions. Claude Code plugin.
