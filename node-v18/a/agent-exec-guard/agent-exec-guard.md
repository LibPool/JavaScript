# agent-exec-guard

> 标签: ai-agent, approval, claude, command-validation, cursor, mcp, model-context-protocol, sandbox, security, shell

## 简介

MCP server that fully parses and classifies shell commands (SAFE/BLOCKED/UNCERTAIN) before AI coding agents execute them, requiring a human-signed single-use token for anything uncertain.
