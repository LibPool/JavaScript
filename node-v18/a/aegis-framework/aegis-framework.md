# aegis-framework

> 标签: appimage, desktop, desktop-app, electron-alternative, framework, gtk, lightweight, linux, python, webkit, webkit2gtk

## 简介

Lightweight AppImage framework using WebKit2GTK and Python - An alternative to Electron that creates ~200KB apps instead of 150MB!
