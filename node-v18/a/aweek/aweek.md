# aweek

> 标签: ai-agents, claude-code, claude-code-plugin, scheduling, subagents, weekly-planning

## 简介

Claude Code plugin for managing multiple AI agents on scheduled weekly plans. Each agent is a 1-to-1 wrapper around a Claude Code subagent with its own goals, objectives, tasks, and token budget.
