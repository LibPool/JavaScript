# async-process-limit

> 标签: ESP32, ESP8266, async, async-limit, async-process-limit, async-task, espruino, process-limit, promise

## 简介

This library can be used in the 'NodeJs', 'Browser' and 'Espruino' , but platform need support 'Promise' or 'async/await' only.
