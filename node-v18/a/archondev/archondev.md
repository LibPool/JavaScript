# archondev

> 标签: ai, architecture, autonomous, claude, cli, copilot, cursor, development, governance, llm

## 简介

Local-first development governance for AI-assisted code. Architecture-aware, dependency-tracked, BYOK. Includes the two-audience marketing toolkit: truth layer, agent clarity audit, AI-washing risk register, human memory map.
