# ant-design-extension

> 标签: JavaScript

## 简介

这是用于ant-design-pro开发的扩展组件，对ant-design的table,form,tree,button,textbox封装，符合面向对象的调用方式，提供给非前端的开发人员，用于开发商业管理系统等
