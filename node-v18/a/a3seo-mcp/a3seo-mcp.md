# a3seo-mcp

> 标签: a3seo, ai, claude, mcp, model-context-protocol, publishing, seo

## 简介

Model Context Protocol server for A3SEO — let AI assistants (Claude Desktop, Cursor, Cline, …) publish articles directly to your A3SEO project sites.
