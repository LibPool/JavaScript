# astro-woocommerce

> 标签: api, astro, astro-integration, commerce, e-commerce, headless, rest, tooling, typescript, utility, utils, withastro, woocommerce, wordpress

## 简介

Type-safe WooCommerce integration for Astro. Fetch products, categories, and manage cart state with full TypeScript support. Perfect for building fast, headless e-commerce sites with Astro.
