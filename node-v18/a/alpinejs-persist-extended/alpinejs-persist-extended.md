# alpinejs-persist-extended

> 标签: alpine, alpinejs, alpinejs-plugin, expiry, localstorage, persist, storage, ttl

## 简介

Extends the official Alpine JS `$persist` plugin with expiring values and imperative read, write, delete and clear helpers 📦
