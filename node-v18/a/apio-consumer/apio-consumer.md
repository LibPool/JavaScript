# apio-consumer

> 标签: REST, consumer, hypermedia

## 简介

Apio Consumer for JS is part of the Apio project, which aims to promote the creation of APIs designed to evolve over time. The Apio Consumer is a client-side library to facilitate the creation of consumers of any hypermedia API.
