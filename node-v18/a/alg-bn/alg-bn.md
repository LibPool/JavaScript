# alg-bn

> 标签: baretto, bn, curves, naehrig

## 简介

Baretto-Naehrig (BN) curve arithmetic, defaulting to the alt_bn128 (BN254) curve used by Ethereum precompiles. Built on top of [`alg-field`](https://www.npmjs.com/package/alg-field).
