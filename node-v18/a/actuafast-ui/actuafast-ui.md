# actuafast-ui

> 标签: JavaScript

## 简介

**actuafast-ui** es una librería de componentes personalizados para todos los productos digitales de **Actuaria Consultores SA**. Construida con **React** y **Material UI**, proporciona una colección de componentes reutilizables y estilizados para acelera
