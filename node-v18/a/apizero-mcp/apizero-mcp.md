# apizero-mcp

> 标签: api, apizero, claude, cline, cursor, mcp, model-context-protocol, modelcontextprotocol, openapi

## 简介

Official MCP server for ApiZero (极数本源) — let Cursor / Claude / Cline and any MCP client call 90+ aggregated HTTP APIs (weather, IP, OCR, AI, finance...) with a single API Key.
