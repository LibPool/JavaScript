# ai-commit-reviewer

> 标签: ANR, ai, ai-code-review, anthropic, code-review, commit-hook, crash-detection, gemini, git-hook, hydration, javascript, linter, mobile, next.js, nextjs, openai, pre-commit, pre-commit-hook, react, react-native, security, self-improving, senior-dev, static-analysis, typescript

## 简介

Self-improving AI code reviewer for React, React Native and Next.js. Runs on every git commit. Catches crashes, ANRs, security holes, hydration errors, and bad patterns before they hit production.
