# angular-greenborn-image-detail

> 标签: angular, angular21, detail, fullscreen, greenborn, image, modal, pan, viewer, zoom

## 简介

Visor de detalle de imagen (zoom, pan, pantalla completa, descarga) y modal de detalle con navegación prev/next para aplicaciones Angular 21. Componente standalone extraído de GFC-Front.
