# atlassian-confluence-mcp-server

> 标签: ai-tools, atlassian, atlassian-confluence, claude, confluence, confluence-api, confluence-cloud, confluence-data-center, confluence-server, mcp, mcp-server, model-context-protocol, nodejs, typescript, wiki, windsurf

## 简介

Model Context Protocol (MCP) server for Atlassian Confluence. Enables AI assistants like Claude and Windsurf to read, create, search, and manage wiki pages on Cloud, on-premise Server, and Data Center.
