# api-simulator

> 标签: API, REST, api, mock, mockapi, sandbox, server, simulator

## 简介

When frontend and backend team started working on some feature parallely, many cases the frontend team needs to wait for backend api/endpoint to progress on frontend development. 
To avoid those wait times, we could use this api simulator to mock backend
