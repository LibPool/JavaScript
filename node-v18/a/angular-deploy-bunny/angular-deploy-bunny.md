# angular-deploy-bunny

> 标签: angular, architect-builder, bunny, bunny.net, bunnycdn, cdn, deploy, ng-deploy, static-site, storage-zone

## 简介

Angular Architect builder (ng deploy) that syncs your build output to a Bunny.net CDN Storage Zone with SHA256-based incremental diffing, then purges the Pull Zone.
