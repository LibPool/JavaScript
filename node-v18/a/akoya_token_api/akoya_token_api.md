# akoya_token_api

> 标签: JavaScript

## 简介

AkoyaTokenApi - JavaScript client for akoya_token_api Akoya Token APIs for data recipients. Default servers are set to override for the Akoya sandbox environment. This SDK is automatically generated by the [Swagger Codegen](https://github.com/swagger-api/
