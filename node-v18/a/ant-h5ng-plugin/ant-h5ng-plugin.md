# ant-h5ng-plugin

> 标签: JavaScript

## 简介

H5NG是蚂蚁国际客户端团队研发的一款轻量化容器（拥有类似PWA中的资源离线化能力）该插件主要用于生成各种前端工程打包产物对应的 manifest.json
