# agent-resume

> 标签: claude, claude-code, cli, codex, restore, resume, session, terminal, tmux, tmux-continuum, tmux-resurrect

## 简介

Run several Claude Code or Codex conversations in one repo and every pane resumes its own session after a reboot. Agent CLIs scope sessions to the directory; agent-resume adds per-pane binding on top of tmux-resurrect.
