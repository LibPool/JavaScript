# aegiscode

> 标签: aegis, aegiscloud, aegiscode, cli, llm, terminal

## 简介

aegiscode — the command-line version of AEGIS Desktop. The shared tool surface in your shell, over the same thin transport and tool registry as the MCP plugin and the desktop app. Ships transport + UI only; no brain.
