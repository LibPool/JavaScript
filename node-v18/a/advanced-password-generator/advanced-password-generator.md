# advanced-password-generator

> 标签: custom-password, custom-password-generator, gen, generator, pass, pass gen, pass generator, passgen, passgenerator, password, password gen, password generator, password-generator, passwordgen, passwordgenerator, secure-password-generator

## 简介

This advanced password generator creates customizable passwords with lowercase letters, uppercase letters, numbers, symbols, and hyphens. It can also generate Apple-style passwords (20 characters long) and assess password strength.
