# @wwwallet/server-core

> 标签: JavaScript

## 简介

This package aims to implement OAuth 2.0 family protocols at server level. It exposes the logic behind the protocols to apply the required security rules for a safe interaction with a client in a federated point of view or a wallet within decentralized id
