# @fiodos/react

> 标签: JavaScript

## 简介

Fiodos agent React (web) bindings — orchestrator hook, embeddable orb, browser navigation/voice/storage adapters and HTTP client over @fiodos/core. Web equivalent of @fiodos/react-native.
