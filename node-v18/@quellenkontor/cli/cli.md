# @quellenkontor/cli

> 标签: api, cli, feiertage, german, germany, hr, hr-data, mindestlohn, minimum-wage, payroll, public-holidays, social-security

## 简介

Kommandozeile für die Quellenkontor-API: HR-Daten im Terminal abfragen und als CSV oder JSON exportieren. Query German HR reference data from the terminal, export as CSV or JSON.
