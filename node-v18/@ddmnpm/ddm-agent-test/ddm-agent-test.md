# @ddmnpm/ddm-agent-test

> 标签: JavaScript

## 简介

Validate OpenCode agents from current source directories by installing them into OpenCode, generating prompt-based test cases from their manifests and descriptions, running opencode CLI verification, judging the results, and uninstalling them cleanly.
