# @knowledge-medium/agent-dispatch

> 标签: agent, automation, claude, codex, daemon, knowledge-medium

## 简介

Dispatch note-graph triggers to local agent CLIs: backlink mentions, query-change watchers, durable graph lifecycle state, and optional channel delivery.
