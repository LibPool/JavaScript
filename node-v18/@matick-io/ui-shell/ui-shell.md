# @matick-io/ui-shell

> 标签: JavaScript

## 简介

Shared app shell for Matick apps: AppLayout (title bar + window-controls slot), the customizable icon sidebar (pinned / More-overflow) and its Customize-navigation dialog. Data-driven from a per-app NavItem registry; chrome-less and host-agnostic so web a
