# @lvy-jsd/dsh-tool-manager

> 标签: deepseek-harness, dsh, lazy-loading, mcp, tools

## 简介

Browse every DeepSeek Harness tool as a directory (category -> group -> tool) and load tools on demand per agent. Provides the toolCatalog service for classifier, metadata, hook and visibility extensions.
