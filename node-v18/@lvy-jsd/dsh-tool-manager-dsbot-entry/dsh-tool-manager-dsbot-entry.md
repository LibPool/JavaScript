# @lvy-jsd/dsh-tool-manager-dsbot-entry

> 标签: deepseek-harness, ds-bot, dsh, dsh-tool-manager

## 简介

Adds a "Tool manager" entry to the ds-bot settings dialog that opens the dsh-tool-manager panel, without changing ds-bot.
