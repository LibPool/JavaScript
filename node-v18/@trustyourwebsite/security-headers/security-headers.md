# @trustyourwebsite/security-headers

> 标签: auditor, checker, ci, cli, compliance, content-security-policy, csp, devops, gdpr, hsts, http-headers, nodejs, owasp, scanner, security, security-headers, typescript, web-security, x-frame-options, xss, zero-dependencies

## 简介

Zero-dependency Node.js tool that grades website security headers (HSTS, CSP, X-Frame-Options, etc.) with A+ to F scoring. CI-friendly with configurable minimum grade threshold.
