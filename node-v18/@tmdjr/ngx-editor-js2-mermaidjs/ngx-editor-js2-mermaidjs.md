# @tmdjr/ngx-editor-js2-mermaidjs

> 标签: JavaScript

## 简介

Render [Mermaid](https://mermaid.js.org/) diagrams directly in [Ngx-Editor-Js2](https://www.npmjs.com/package/@tmdjr/ngx-editor-js2). An overlay editor lets you write Mermaid syntax and preview the resulting diagram.
