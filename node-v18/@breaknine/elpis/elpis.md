# @breaknine/elpis

> 标签: JavaScript

## 简介

Elpis 是一个基于 Node.js + Koa2 + Vue3 的全栈低代码开发平台，旨在通过配置化的方式快速构建企业级管理系统。项目采用模块化架构设计，支持多项目管理。
