> 标签: AI, Bard, Google, LaMDA, chat, coding, conversational, library, math, node, writing

## 简介

A Node.js library for interacting with Google Bard, an experimental conversational AI chat service powered by Google's Language Model for Dialogue Applications (LaMDA). Use this library to leverage the capabilities of Bard, including coding, math problem
