> 标签: ai-tools, claude, claude-desktop, fitness, mcp, model-context-protocol, openapi, stdio, strava, swagger

## 简介

Strava MCP toolkit — Model Context Protocol server for the Strava v3 API. Read + write tools for athletes, activities, segments, segment efforts, clubs, gear, routes, uploads, and streams. Includes dry_run snippet generation, an OpenAPI describe meta tool
