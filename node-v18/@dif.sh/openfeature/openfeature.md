# @dif.sh/openfeature

> 标签: ab-testing, dif.sh, experimentation, feature-flags, feature-management, feature-toggles, flags-as-code, openfeature, openfeature-provider, typescript

## 简介

OpenFeature server provider for dif feature flags and A/B tests. Resolves evaluations against the experiments registered by dif/generated/client.ts.
