# @leviai/webwatch-mcp

> 标签: ai-tools, change-detection, claude, competitor-tracking, css-selectors, cursor, diff, mcp, mcp-server, model-context-protocol, price-monitoring, snapshots, sqlite, web-monitoring, web-scraping, website-changes

## 简介

Website change monitoring MCP server — track URL changes, compare snapshots, extract content with CSS selectors. Monitor competitor sites, pricing pages, job boards. SQLite-backed with diff history.
