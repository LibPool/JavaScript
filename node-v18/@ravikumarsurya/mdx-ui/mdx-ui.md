> 标签: accordion, ai, astro, callout, cli, code-block, components, data-structures, docs, documentation, katex, llm, markdown, math, mcp, mdx, mermaid, nextjs, react, remark, shadcn, syntax-highlighting, tabs, tailwindcss

## 简介

Transform LLM Markdown into rich, interactive UI components. Token-efficient bridge between any LLM and React — 50+ copy-paste MDX components, CLI, MCP server, and a remark plugin.
