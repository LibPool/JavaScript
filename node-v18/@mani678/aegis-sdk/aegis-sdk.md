# @mani678/aegis-sdk

> 标签: cow-protocol, defi, ethereum, order-protection, slippage, twap, uniswap, web3

## 简介

Large order execution protection for DeFi interfaces. Classifies trades by risk tier and enforces TWAP execution for orders that would cause catastrophic slippage.
