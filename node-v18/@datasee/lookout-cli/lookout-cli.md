# @datasee/lookout-cli

> 标签: claude, cli, error-monitoring, error-tracking, lookout, mcp, self-hosted, sentry

## 简介

CLI for lookout, the self-hosted Sentry-compatible error tracker. Browse and triage issues from the terminal, hand errors to Claude Code to fix (`lookout fix`), or run as an MCP server (`lookout mcp`).
