# @we8/astro

> 标签: aeo, astro, astro-integration, cms, headless-cms, seo, we8

## 简介

The Astro integration for we8: build-time content helpers, the visit beacon, analytics loaders, consent that appears only when it is needed, progressive-enhancement forms, and sitemap merging.
