# @bintangtimurlangit/threads-mcp

> 标签: automation, instagram, mcp, meta, model-context-protocol, social-media, threads

## 简介

An MCP server for Meta's Threads via a logged-in browser session — read profiles, posts, replies, timeline & search, and post/reply/like/repost/follow. No developer account: it uses your own cookie session.
