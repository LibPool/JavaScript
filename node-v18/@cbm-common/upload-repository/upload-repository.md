# @cbm-common/upload-repository

> 标签: JavaScript

## 简介

Repositorio Angular para la gestión completa de archivos en sistemas empresariales CBM. Implementa operaciones de subida, descarga, eliminación y listado de archivos con soporte para importaciones masivas, anexos y archivos específicos de facturación elec
