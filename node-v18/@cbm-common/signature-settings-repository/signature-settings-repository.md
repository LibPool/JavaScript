# @cbm-common/signature-settings-repository

> 标签: JavaScript

## 简介

Esta librería contiene un cliente HTTP para consumir los endpoints relacionados con la configuración de firmas (signature settings) del backend. Está diseñada para integrarse en aplicaciones Angular dentro del monorepo y ofrece un servicio con operaciones
