# @monlite/kv

> 标签: cache, key-value, kv, monlite, redis, sqlite, ttl

## 简介

Redis-like key-value cache for monlite: get/set/incr with TTL, sorted sets, pub/sub — on SQLite (@monlite/core) or Postgres (@monlite/postgres).
