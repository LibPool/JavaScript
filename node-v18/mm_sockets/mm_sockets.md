# mm_sockets

> 标签: json-rpc, mm_adapter, mm_in_adapter, mm_mod, socket, web socket管理器, websocket

## 简介

WebSocket管理器，基于json-rpc2.0协议实现前后端双向通讯，可用于即时通讯、消息推送等（基于 mm_corejs，内置管理器池，无全局/原型扩展依赖）
