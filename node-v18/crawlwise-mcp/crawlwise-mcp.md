# crawlwise-mcp

> 标签: crawlwise, mcp, model-context-protocol, monitoring, rss, sitemap, techstack, webhooks

## 简介

MCP (Model Context Protocol) stdio server for Crawlwise Data: techstack, feed, sitemap, monitors, account balance. Auth via CRAWLWISE_API_KEY.
