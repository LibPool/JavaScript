# @trackless-telemetry/sdk-web

> 标签: analytics, ccpa, cookieless, gdpr, no-cookies, privacy, privacy-first, telemetry, tracking, usage-analytics, web-analytics, zero-dependency

## 简介

Privacy-first web analytics SDK — zero dependencies, zero cookies, zero client persistence. Collects only aggregate feature usage counts.
