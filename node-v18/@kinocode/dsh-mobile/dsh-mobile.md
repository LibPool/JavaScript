# @kinocode/dsh-mobile

> 标签: android, approval, deepseek-harness, dsh, dsh-plugin, mobile, plugin, push-notifications, relay

## 简介

DeepSeek Harness host plugin for the DSH Mobile Android app: pair with a QR, use DSH on the phone through its own HTTPS gateway, answer approvals and questions from notifications, push turn completion.
