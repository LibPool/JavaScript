# @viritura/score-engine

> 标签: engraving, mnx, music, notation, score, sheet-music, smufl, wasm

## 简介

Framework-free music notation rendering kernel: MNX layout (Rust/WASM), ink-only Canvas paint, SVG, geometry queries and a playback timeline.
