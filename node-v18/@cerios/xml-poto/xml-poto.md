# @cerios/xml-poto

> 标签: bi-directional, cerios, converter, decorators, deserialization, mapper, metadata, namespaces, serialization, typescript, validation, xbrl, xml, xml-parser, xml-serializer, xmlattribute, xmlelement, xmlroot

## 简介

TypeScript XML serialization library with decorator-based metadata. Supports namespaces, custom converters, validation, wrapped/unwrapped arrays, and bidirectional XML-object mapping.
