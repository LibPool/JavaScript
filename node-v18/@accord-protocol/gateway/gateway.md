# @accord-protocol/gateway

> 标签: accord-402, accord-protocol, agent-payments, connect-middleware, express-middleware, http-402, paid-api, x402-compatible

## 简介

Accord/402 HTTP middleware. Express/Connect-compatible. Turn any HTTP endpoint into a paid, verifiable Accord engagement: 402 challenge with agreement template, replay-protected payment verification, structured error envelope. Rail-agnostic. See specs/ACC
