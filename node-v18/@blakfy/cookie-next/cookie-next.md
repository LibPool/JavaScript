> 标签: app-router, blakfy, ccpa, cookie-consent, gdpr, google-consent-mode, kvkk, next.js, nextjs, pages-router, react, react-19, ssr-safe

## 简介

Next.js / React wrapper for Blakfy Cookie Consent. SSR-safe, no FOUC. Supports React 18+19, Next.js 14+15.
