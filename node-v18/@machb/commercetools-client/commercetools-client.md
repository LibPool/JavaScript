# @machb/commercetools-client

> 标签: JavaScript

## 简介

Machb Commercetools Client Adapter Module provides an integration layer between the Machb user domain and the Commercetools platform. It implements the UserService interface, enabling user signup, signin, and retrieval by ID using Commercetools APIs.
