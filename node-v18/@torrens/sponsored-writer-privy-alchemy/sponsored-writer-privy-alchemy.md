# @torrens/sponsored-writer-privy-alchemy

> 标签: JavaScript

## 简介

Concrete gasless-write bridge for Torrens apps: builds an EIP-7702 + Alchemy Gas Manager sponsored writer from a Privy embedded wallet and injects it into @torrens/wallet-provider's useSponsoredWrite chokepoint. Kept OUT of the portable @torrens/wallet-pr
