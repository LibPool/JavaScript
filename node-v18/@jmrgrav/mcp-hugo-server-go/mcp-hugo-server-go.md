# @jmrgrav/mcp-hugo-server-go

> 标签: content-management, hugo, mcp, model-context-protocol, static-site

## 简介

MCP server for Hugo sites, distributed as a precompiled Go binary (esbuild/ripgrep pattern) — no separate install of the Go server required.
