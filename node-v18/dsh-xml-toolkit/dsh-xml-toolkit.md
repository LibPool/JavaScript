# dsh-xml-toolkit

> 标签: dsh, format, minify, parser, plugin, pretty-print, query, xml

## 简介

Lightweight XML toolkit for DeepSeek Harness: parse XML into readable JSON or a raw tree, query nodes with a simplified path syntax, and pretty-print or minify XML while keeping comments and CDATA. Zero runtime dependencies, read-only.
