# simphp

> 标签: emscripten, interpreter, php, php4, wasm, webassembly, zend

## 简介

The original PHP 4.1.1 engine (Zend Engine 1) compiled to WebAssembly, runnable from Node and Web Workers

- 官网：https://simphp.infinitefun.com
- 源码仓库：git+https://github.com/jbn/simphp.git

- npm registry：https://registry.npmjs.org/simphp
