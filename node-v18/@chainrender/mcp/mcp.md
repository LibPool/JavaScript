# @chainrender/mcp

> 标签: ai, chainrender, ethereum, mcp, model-context-protocol, onchain

## 简介

Model Context Protocol server for building ChainRender apps with AI — exposes the SDK (vocabulary, compose, compile, grade, validate) as tools so an AI assistant can build verifiable, Grade-A on-chain apps.
