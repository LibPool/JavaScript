# @fortmesa/verdaccio-security-filter

> 标签: malware-detection, npm-registry, osv, supply-chain-security, verdaccio, verdaccio-plugin, webhook

## 简介

Verdaccio filter plugin: blocks versions that are too new, published after a date threshold, match a synced OSV malicious-package blocklist, match a manual block/allow list, or newly introduce install scripts, and (optionally, as a middlewares plugin) rej
