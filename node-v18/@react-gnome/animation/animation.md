# @react-gnome/animation

> 标签: JavaScript

## 简介

Animation primitives for React Gnome — AnimatedValue + timing/spring driven by a GLib frame tick. Drop-in shape compatible with React Native's Animated API, plus a Tamagui driver subexport.
