# @natsuneko-laboratory/react-native-twitter-text

> 标签: android, ios, macos, react-native, windows

## 简介

A React Native plugin that provides Twitter's twitter-text parsing library via native Objective-C (macOS and iOS), C++ (Windows) and Java (Android) implementations. Especially fast for CJK text compared to the JavaScript implementation.
