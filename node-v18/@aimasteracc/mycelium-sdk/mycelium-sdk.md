# @aimasteracc/mycelium-sdk

> 标签: ai, code-graph, code-intelligence, mcp, mycelium, sdk, static-analysis, tree-sitter

## 简介

Thin, typed Node/TypeScript SDK for the Mycelium code-intelligence engine. Wraps the prebuilt mycelium CLI — no Rust/Cargo toolchain required.
