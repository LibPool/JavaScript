# @banhosdev/sdd

> 标签: ai, claude, cli, scaffold, sdd, spec-driven-development, verboo

## 简介

Spec-Driven Development (SDD) framework: interactive CLI that scaffolds .ai/ workspace and installs AI agent skills (sdd-* ) into your project.
