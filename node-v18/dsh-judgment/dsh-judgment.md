# dsh-judgment

> 标签: ai-agents, calibration, cordis-plugin, decision-model, deepseek-harness, dsh, dsh-plugin, jev, judgment, structured-decisions, typesafe

## 简介

Structured judgment plugin for DeepSeek Harness: ask batched named questions (choice, score, yes-probability) and get calibrated probabilities from TypeSafe Jev, Luna, or any compatible endpoint. Strict validation, per-connection config, audit ledger, bud
