# @omnicross/ui

> 标签: JavaScript

## 简介

Omnicross Control Panel — the React frontend over the daemon admin HTTP API. Published as prebuilt static assets (dist/), served by @omnicross/daemon at /ui; also the frontend for the Tauri desktop shell.
