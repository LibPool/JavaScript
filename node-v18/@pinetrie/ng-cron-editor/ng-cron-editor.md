# @pinetrie/ng-cron-editor

> 标签: angular, angular-cli, cron, cron-expression, quartz

## 简介

A cron expression generator to be used in Angular applications. This is a fork of https://github.com/claudiuconstantin/cron-editor via https://github.com/ShawinMendis/cron-editor to support Angular 18
