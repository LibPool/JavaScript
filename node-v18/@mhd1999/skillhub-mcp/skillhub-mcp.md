# @mhd1999/skillhub-mcp

> 标签: JavaScript

## 简介

SkillHub MCP server — delivers project-scoped skills + docs to MCP-aware AI clients (Codex, Gemini, Cursor, Claude Desktop). Supports PAT auth and a docs-only mode.
