# @craftzbay/create-app

> 标签: craftzbay, create-app, design-system, react, scaffold, tailwind

## 简介

Scaffold a new project preconfigured with @craftzbay/ui. Invoke via `npm create @craftzbay/app my-app`.

## 官网

- 官网：https://ui.craftzbay.com
- 源码仓库：git+https://github.com/craftzbay/craftzbay-ui.git
- npm 页面：https://www.npmjs.com/package/@craftzbay/create-app
