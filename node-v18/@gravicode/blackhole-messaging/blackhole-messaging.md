# @gravicode/blackhole-messaging

> 标签: batching, binary-protocol, iot, ipc, messaging, named-pipe, pubsub, rpc, streaming, tcp, unix-socket

## 简介

Node.js client for BlackHole Messaging: RPC, Pub/Sub, Streaming and Batching over TCP, a Unix domain socket, or a named pipe.
