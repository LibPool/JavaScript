# @huloglobal/vendure-plugin-visitor-analytics

> 标签: analytics, funnel, session-journey, vendure, vendure-plugin, visitor-tracking

## 简介

Full-funnel visitor analytics for Vendure storefronts — pageviews, time-on-page, session journey, exit pages, funnel drop-off, and per-visitor profile drawer with parsed user-agent + MaxMind GeoLite2 enrichment. Auto-issues visitor + session cookies on fi
