# @mzimt625/datapulse-sdk-web-sender-image

> 标签: JavaScript

## 简介

使用 GET 图片请求发送事件。适用于受限旧环境；URL 有长度限制，因此按单事件拆分，并要求服务端开启 `/api/v1/track.gif` 协议。
