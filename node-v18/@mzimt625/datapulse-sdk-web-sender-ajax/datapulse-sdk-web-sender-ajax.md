# @mzimt625/datapulse-sdk-web-sender-ajax

> 标签: JavaScript

## 简介

使用 Fetch/Ajax 发送事件批次的默认 Sender。支持 `keepalive`，服务端非 2xx 时抛出错误并由 SDK 核心回滚队列。
