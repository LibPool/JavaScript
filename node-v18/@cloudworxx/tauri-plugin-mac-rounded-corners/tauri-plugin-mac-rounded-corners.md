# @cloudworxx/tauri-plugin-mac-rounded-corners

> 标签: app-store, auto-reposition, cocoa, frameless-window, fullscreen, macos, rounded-corners, tauri, tauri-plugin, tauri-v2, traffic-lights, window-decorations

## 简介

Tauri v2 plugin for native macOS rounded corners with customizable Traffic Lights positioning. Auto-repositions after fullscreen. App Store compatible.
