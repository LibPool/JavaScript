# @freereportjs/server

> 标签: @freereportjs/core, cron, email, pdf, report, scheduler

## 简介

Scheduled FreeReport reports on a server: render PDF, Excel and Word without a browser on a schedule (daily, weekly, monthly, cron) and e-mail, file, post or print them, with per-recipient parameters, retries and a JSONL audit log.
