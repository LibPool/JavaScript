# @kutlaytunc/us3-react

> 标签: animation, behaviour-tree, blendspace, drei, game-ai, r3f, react-three-fiber, three, us3

## 简介

React Three Fiber bindings for us3: <AnimatedCharacter> + a hook per runtime — useBehaviorTree, usePerceptionSystem, useNavAgent, useEnvQuery, useMontage, useLookAt — plus debug visualizers.
