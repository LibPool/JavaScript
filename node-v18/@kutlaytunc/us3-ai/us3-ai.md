# @kutlaytunc/us3-ai

> 标签: behavior-tree, behaviour-tree, eqs, game-ai, navmesh, npc, pathfinding, perception, r3f, react-three-fiber, us3

## 简介

Headless, R3F-native game-AI runtime: behaviour tree, perception (sight cone / line-of-sight), navmesh path-following and EQS. Navmesh-agnostic via @kutlaytunc/us3-core's NavProvider. Zero runtime dependencies.
