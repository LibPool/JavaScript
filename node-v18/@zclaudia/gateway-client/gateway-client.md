# @zclaudia/gateway-client

> 标签: client, gateway, reverse-tunnel, websocket, zclaudia

## 简介

Client SDK for the zclaudia gateway: control connection, channels, topics with retained payloads, reconnect. WHATWG WebSocket, injectable socket factory.
