# @stardeck-customer-apps/testing

> 标签: pglite, stardeck, testing, vitest

## 简介

Vitest test harness for Stardeck customer apps — in-process Postgres (PGlite) plus a control-plane simulator so the real Stardeck SDKs run unmodified in tests
