# @hyzyn/dsh-codegraph

> 标签: JavaScript

## 简介

DSH Web GUI 的 Codegraph 集成插件：在设置 → 插件 里提供 Codegraph 状态、符号搜索、callers/callees/impact 查看和一键 sync/index，托管 codegraph MCP 服务器的项目目录，并向 agent 注入 Codegraph 能力提示。
