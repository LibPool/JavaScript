# @hyzyn/dsh-profile

> 标签: JavaScript

## 简介

DSH Web GUI 的 Profile 管理插件：官方设置 → 插件 里的「Profile 管理」卡片，可视化查看/创建/复制/删除 DSH profiles，管理 ~/.dsh/profiles 下的 profile 目录。
