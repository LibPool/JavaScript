# @dotrino/install

> 标签: add-to-home-screen, beforeinstallprompt, cross-app, custom-element, dotrino, install, ios, pwa, web-component

## 简介

Botón de "Instalar app" (PWA) unificado del ecosistema Dotrino: Web Component <dotrino-install> que captura beforeinstallprompt temprano, maneja iOS con un modal de instrucciones (sin alert) y se oculta si ya está instalada. Vue o vanilla. Sin JS de terce
