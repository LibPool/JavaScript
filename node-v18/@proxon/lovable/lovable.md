# @proxon/lovable

> 标签: agent-cost, ai, edge-functions, llm, lovable, proxon, supabase

## 简介

Proxon telemetry for apps built on Lovable's AI Gateway (POC, PRX-2767): a drop-in fetch replacement for Supabase edge functions that reports each AI call's tokens + model to Proxon ingest as native agent-cost events.
