# @paymentsnp/sdk

> 标签: checkout, esewa, fonepay, khalti, nepal, payments, paymentsnp

## 简介

Official TypeScript/JavaScript SDK and CLI for the Paymentsnp payment API (eSewa, Khalti and Fonepay checkout for Nepal).
