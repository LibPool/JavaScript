# @xiaoliyo/pi-ask-question

> 标签: ask, clarify, coding-agent, pi, pi-extension

## 简介

ask_question tool for the pi coding agent: lets the LLM ask the user to clarify requirements or make choices, with single/multi-choice, free-text, and multi-question dialogs
