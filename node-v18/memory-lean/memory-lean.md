# memory-lean

> 标签: ai-agent, claude, claude-code, cursor, knowledge-graph, mcp, mcp-server, memory, model-context-protocol, tokens

## 简介

A token-lean MCP memory server: a knowledge graph your AI agent can search without reading the whole thing. Drop-in replacement for @modelcontextprotocol/server-memory.
