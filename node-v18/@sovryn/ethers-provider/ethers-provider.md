# @sovryn/ethers-provider

> 标签: JavaScript

## 简介

Helper to use and configure ethers JsonRPC provider. Provider is for reading data from nodes and sending already signed transactions and not for signing it. For signing transactions use `@sovryn/onboard-core`.
