# @napplet/skills

> 标签: agent, claude, cursor, napplet, nip-5d, nostr, skills

## 简介

Agent skills (make / design / build / port / test) that let a coding agent create a napplet end-to-end, plus a napplet-skills installer for Claude Code, Codex, Cursor, Windsurf, Amp, Gemini, and Copilot
