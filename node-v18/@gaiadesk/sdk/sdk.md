# @gaiadesk/sdk

> 标签: ai-agents, exec, gaiadesk, mcp, remote-desktop, sdk, typescript

## 简介

Drive GaiaDesk desks from TypeScript and Node.js: devices, exec, shell, file copy, background jobs, stats, scoped tokens and MCP, through GaiaDesk's native library (@gaiadesk/sdk-native), gaiadesk-cli, or the hosted GaiaDesk API (fetch only).
