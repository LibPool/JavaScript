# @gaiadesk/cli

> 标签: ai-agents, cli, gaiadesk, mcp, remote-desktop, ssh

## 简介

GaiaDesk's command line, gaiadesk-cli: run commands, open shells, copy files and serve MCP tools on your GaiaDesk desks. Installs the prebuilt binary for your platform.
