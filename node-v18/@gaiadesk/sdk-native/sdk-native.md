# @gaiadesk/sdk-native

> 标签: gaiadesk, napi, native, remote-desktop, sdk

## 简介

GaiaDesk's client library as a prebuilt native binary for Node.js. Used by @gaiadesk/sdk when installed; no gaiadesk-cli needed.

## 官网

- 官网：https://gaiadesk.net/docs/sdk
- npm 页面：https://www.npmjs.com/package/@gaiadesk/sdk-native
