# @budhash/gomanize

> 标签: devanagari, hindi, indic, nlp, romanization, romanize, transliterate, transliteration, wasm, webassembly

## 简介

Romanize Hindi (Devanagari) into readable, diacritic-free Latin script — the gomanize engine compiled to WebAssembly.
