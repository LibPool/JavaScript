# @kadal/theme-crayon

> 标签: classroom, kadal-deck, kadal-theme, pastel, playful, presentation, slides, theme, workshop

## 简介

Crayon, a theme for Kadal Deck (@kadal/deck). A playful pastel theme for workshops and classrooms: rounded shapes, a friendly display face, and sticker-like callouts.
