# @guuey/config

> 标签: agent, config, guuey, mcp, schema, zod

## 简介

Open-source schemas + loaders for the three guuey config files: agent.json (declarative agent definition), guuey.json (hosted-deploy overlay), and the helper types around them. Consumed by @guuey/cli, the guuey backend, and devs writing their own agent or
