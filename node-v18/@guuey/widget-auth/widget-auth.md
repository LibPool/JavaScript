# @guuey/widget-auth

> 标签: auth, embed, guuey, identity, jwt, widget

## 简介

Mint end-user identity tokens for a guuey embeddable widget from your own backend. One call, zero runtime dependencies — your app secret stays on your server and the platform holds the signing key.
