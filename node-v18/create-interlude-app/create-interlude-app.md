# create-interlude-app

> 标签: create-app, foundry, interlude, monad, nextjs, scaffold, session-keys

## 简介

Scaffold a Foundry + Next.js project whose contract runs on an Interlude node: one wallet signature, then gasless calls (a few ms next to the node, ~40 ms round trip) that settle on Monad.
