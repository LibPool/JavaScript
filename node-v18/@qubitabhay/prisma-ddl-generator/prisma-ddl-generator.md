# @qubitabhay/prisma-ddl-generator

> 标签: ddl, mariadb, mysql, postgres, prisma, sql, sqlite

## 简介

This package generates SQL DDL statements from a Prisma schema for various SQL dialects, including MySQL, PostgreSQL, SQLite, and MariaDB.
