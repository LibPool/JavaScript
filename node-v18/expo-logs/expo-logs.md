# expo-logs

> 标签: android, console, expo, expo-go, expo-updates, file-logger, ios, log-rotation, logger, logging, logs, react-native, react-native-file-logger, typescript, web

## 简介

File logger for Expo apps (iOS, Android, Web) written in pure TypeScript. Works in Expo Go and ships over expo-updates: no native code. Log rotation, console capture, share and email logs.
