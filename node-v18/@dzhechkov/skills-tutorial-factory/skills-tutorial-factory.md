> 标签: agent-skills, agentskills.io, claude-code, edu-site, gamification, head-first, meta-skill, pedagogy, skill-pack, tutorial

## 简介

package-tutorial-factory — a meta-skill that turns any harness-hub package into a Head-First-style gamified edu-site learning course. Composes skills-book-digitizer (IP-safe distillation), edu-site-generator (render), and the code-skills-creator meta-fact
