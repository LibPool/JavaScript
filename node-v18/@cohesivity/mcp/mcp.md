# @cohesivity/mcp

> 标签: agent-native, ai-agents, cohesivity, mcp, model-context-protocol, stdio

## 简介

Standalone Cohesivity MCP server. Provisions tenants, resources, and project bootstrapping over stdio. Run with `npx -y @cohesivity/mcp`.
