# @cargoflow/gateway

> 标签: cargoflow, cold-chain, data-logger, ed25519, gateway, iot, telemetry

## 简介

CargoFlow evidence gateway: watches data-logger exports, USB loggers and serial streams, signs readings with an Ed25519 key and delivers them to the CargoFlow API with a durable offline queue.
