# @superdata/basic-data-service

> 标签: JavaScript

## 简介

前端基础数据服务。<br /> 用于对接基础模块的数据。<br /> 提供用户认证、角色权限、功能模块、字典、系统配置、埋点日志、消息管理等基础数据服务支持。<br /> 支持下载数据保存到不同数据源（localStorage、indexedDB、redux、mobx）的策略。<br /> 该服务仅依赖外部接口、数据管理器，不依赖任何UI组件库。<br />
