# @greenflags/vue

> 标签: composables, feature-flags, greenflags, vue

## 简介

Vue 3 composables for GreenFlags feature flags: plugin, useFlag and useFlags on top of @greenflags/client. Billing-safe snapshot reads, opt-in polling.
