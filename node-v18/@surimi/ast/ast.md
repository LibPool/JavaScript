# @surimi/ast

> 标签: JavaScript

## 简介

This is a very minimal CSS AST builder used in surimi. It replaced PostCSS for us, as we really only need the AST building and stringifying parts. You probably don't want to use this for whatever you're doing. Use PostCSS, CSSTree etc. instead.
