# @invoiceforge/core

> 标签: b2b, billing, e-invoice, einvoice, en16931, eu-invoice, invoice, peppol, ubl, xml, xrechnung

## 简介

Convert JSON invoice data to e-invoice XML — targeting XRechnung 3.0 UBL and Peppol BIS 3.0 (CII and more formats coming).
