# @svene/juanfi-admin

> 标签: admin, hotspot, juanfi, mikrotik, piso-wifi, vendo

## 简介

Typed admin client for JuanFI v4.x/v5 firmware. Drives /admin/api/* routes with pipe-delimited response parsing.
