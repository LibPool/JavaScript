# @winstonsayno/mcp-gateway-client

> 标签: client, llm, mcp, mcp-gateway, model-context-protocol, tools

## 简介

Typed, dependency-free client for mcp-gateway (REST API + MCP over /mcp). Works in browsers, Node 18+, Deno, Bun and React Native.
