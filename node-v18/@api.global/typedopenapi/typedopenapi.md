# @api.global/typedopenapi

> 标签: API contracts, JSON Schema, OpenAPI, TypeScript, code generation, typed requests

## 简介

Generates JSON Schema, TypeScript declarations and OpenAPI 3.1 documents from typed-request contracts and a route table.
