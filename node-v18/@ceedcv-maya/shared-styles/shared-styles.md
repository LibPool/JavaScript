# @ceedcv-maya/shared-styles

> 标签: ceedcv, css, design-tokens, maya, tailwind-v4, tailwindcss

## 简介

Shared Tailwind v4 design tokens, color palette (Odoo/Maya), animations and reset CSS for the @ceedcv-maya React component packages. CSS-only — import once at app entry.
