# @simplix-react-native/ui

> 标签: expo, nativewind, react-native, simplix-react, ui

## 简介

Standard mobile UI kit for simplix-react on React Native: layout primitives, page skeletons, controls, sheet-first overlays, FormFields / DetailFields, EntityList + useEntityFeed, theme token sheet
