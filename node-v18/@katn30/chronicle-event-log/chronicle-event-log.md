# @katn30/chronicle-event-log

> 标签: autosave, change-tracking, chronicle, event-log, event-sourcing, events, typescript, undo-redo

## 简介

Event log for TypeScript models: records every change as an event, with undo/redo and validation, and saves them as one batch.
