# @vensst/vue-widget-plus

> 标签: @vensst, @vensst/vue-widget-plus, vue-widget, vue-widget-plus

## 简介

@vensst/vue-widget-plus 一个基于 Vue 3 + TypeScript 的轻量级组件库，提供常用 UI 组件与业务组件封装，支持 按需引入 / 全量注册 / 插件化配置，并内置对 ECharts 的统一注入方案。
