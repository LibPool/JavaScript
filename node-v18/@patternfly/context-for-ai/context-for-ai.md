# @patternfly/context-for-ai

> 标签: ai-tooling, cursor, design-system, patternfly, react, semantic-ui, typescript

## 简介

Codemod tool that automatically adds semantic data-* attributes to all PatternFly components in your codebase, making them AI-friendly. No library imports needed - just run the codemod.
