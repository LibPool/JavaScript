# @lacspace/agent

> 标签: agent, agent-loop, ai, ai-agent, chatbot, function-calling, isomorphic, keyless, llm, llm-agent, orchestration, prompt-engineering, provider-agnostic, react-agent, reasoning, tool-calling, tool-use, tools, typescript, zero-dependency

## 简介

A tiny, zero-dependency, keyless tool-calling / ReAct agent loop — bring any chat model and any tools as injectable, duck-typed interfaces and it drives the call → tool-dispatch → repeat loop with a full observable trace, maxSteps guard and error recovery
