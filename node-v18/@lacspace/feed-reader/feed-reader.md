# @lacspace/feed-reader

> 标签: atom, autodiscovery, feed-health, feed-parser, feed-reader, isomorphic, json-feed, newsroom, rss, rss-parser, typescript, zero-dependency

## 简介

Read the feeds you follow — parse fetched RSS 2.0, RSS 1.0 (RDF), Atom 1.0 and JSON Feed 1.1 into one normalized shape, autodiscover the feeds a web page advertises, and score each source's health (staleness vs cadence, duplicate/poisoned items, volume sp
