# @lacspace/postal-code

> 标签: address-validation, cep, isomorphic, pin-code, postal-code, postcode, typescript, zero-dependency, zip-code, zipcode-validation

## 简介

Validate and normalise postal codes for 100+ countries — ZIP, postcode, PIN, CEP — with the correct spacing and casing. Zero-dependency, isomorphic.
