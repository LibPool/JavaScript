# @lacspace/screen

> 标签: admission-control, classifier, content-moderation, devanagari, gazetteer, isomorphic, keyword-scoring, lexical, llm-gate, negation, nepali, screener, sensitivity, triage, typescript, zero-dependency

## 简介

A cheap, zero-dependency lexical content screener and LLM admission gate — score text against your own weighted term lexicons (multi-language, with negation and proximity windows and an optional named-entity gazetteer) and get back a clear / review / bloc
