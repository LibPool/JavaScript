# @lacspace/commentguard

> 标签: abuse, comment-moderation, doxxing, hate-speech, moderation, nepali, newsroom, pii, spam, typescript, zero-dependency

## 简介

Comment moderation for English, romanized Nepali and Devanagari — scores spam, abuse, hate, doxxing and link-spam and returns an allow / review / flag / hide action, with PII detection (Nepali phone, email, URLs/shorteners) and FAQ auto-reply suggestions.
