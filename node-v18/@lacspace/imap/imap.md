# @lacspace/imap

> 标签: bodystructure, dovecot, email, gmail, hostinger, idle, imap, imap-client, mail, outlook, typescript, webmail, xoauth2, zero-dependency

## 简介

Zero-dependency IMAP4rev1 client for Node (RFC 3501 + IDLE, MOVE, UIDPLUS, CONDSTORE, SPECIAL-USE, LIST-EXTENDED, LITERAL+, SASL-IR, QUOTA, ID). Implicit TLS and STARTTLS with verification on, LOGIN / PLAIN / XOAUTH2 / OAUTHBEARER, streaming byte-accurate
