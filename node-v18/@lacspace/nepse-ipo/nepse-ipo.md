# @lacspace/nepse-ipo

> 标签: hermes, ipo, mutual-fund, nepal, nepal-time, nepalipaisa, nepse, npt, parser, react-native, sebon, share-market, stock-market, typescript

## 简介

Pure parsers for Nepal (NEPSE) IPO data, with no fetching inside. Turns the nepalipaisa.com GetIpos JSON into clean Issue objects: ordinary/local/migrant-worker tranches mapped to general/locals/foreign_employment eligibility, mutual-fund detection by sec
