# @lacspace/email-builder

> 标签: bulletproof-button, dark-mode, email, email-builder, email-template, html-email, mail-merge, mso, newsletter, outlook, responsive-email, templates, typescript, vml, wcag

## 简介

Block-based email template builder: a JSON document of blocks (header, text, image, button, divider, spacer, columns, social, footer, html, quote, list, table) renders to bulletproof table-based responsive email HTML for Outlook desktop, Gmail, Apple Mail
