# @lacspace/og

> 标签: card-layout, dynamic-image, gradient-presets, image-embed, isomorphic, next-og, og-image, og-template, open-graph, opengraph, satori, seo, social-card, social-image, svg, text-fit, twitter-card, typescript, vercel-og, zero-dependency

## 简介

Dynamic Open Graph images — a share-card design system you configure once and call per page. Produces a next/og element tree AND a zero-dependency SVG from the same options, with auto-fitting titles, presets, badges and gradients. Zero-dependency, isomorp
