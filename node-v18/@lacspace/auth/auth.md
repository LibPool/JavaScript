# @lacspace/auth

> 标签: access-token, auth, auth-client, authentication, authorization, auto-refresh, bearer-token, isomorphic, jwt, jwt-decode, lacspace, login, oauth, oidc, pkce, rbac, refresh-token, roles, scopes, session, token-expiry, token-refresh, typescript

## 简介

Authentication flows (login, register, token, refresh) for Lacspace APIs, with PKCE, JWT expiry math, scope/role checks and proactive token refresh.
