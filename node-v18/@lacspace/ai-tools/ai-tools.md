# @lacspace/ai-tools

> 标签: agent-loop, agents, ai, anthropic, argument-validation, function-calling, gemini, isomorphic, json-schema, llm, openai, parallel-tool-calls, prompt-engineering, schema-validation, tool-call-parsing, tool-calling, tool-registry, tool-result, tool-use, type-safe, typescript, zero-dependency

## 简介

Define LLM function-calling / tool-use tools once and use them with any provider — generate the OpenAI, Anthropic or Google tool spec AND get a runtime dispatcher that validates arguments and calls your handler. Zero-dependency, provider-agnostic, keyless
