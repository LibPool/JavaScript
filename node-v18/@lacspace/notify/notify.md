# @lacspace/notify

> 标签: accessible, alert, framework-agnostic, in-app-notifications, notifications, notify, promise-toast, react-toast, snackbar, toast, toaster, typescript, vanilla, zero-dependency

## 简介

Beautiful in-app toast notifications with zero dependencies — a framework-agnostic store, a drop-in vanilla DOM renderer, and a React binding (<Toaster/> + useToast). Promise toasts, actions, positions, auto-dismiss, accessible. Works in any site; React i
