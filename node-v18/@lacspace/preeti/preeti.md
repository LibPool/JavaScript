# @lacspace/preeti

> 标签: converter, devanagari, font, legacy-font, nepali, preeti, react-native, typescript, unicode

## 简介

Preeti ⇄ Unicode for Nepali: convert legacy Preeti-font ASCII text ("g]kfn") to Unicode Devanagari (नेपाल) and back. Handles short-i and reph reordering, half letters, ra-kaar (| and «), conjunct keys (क्ष ज्ञ त्र श्र …), Preeti numerals, the full Latin-1
