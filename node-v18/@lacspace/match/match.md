# @lacspace/match

> 标签: automation, conditions, evaluate, filter, match, predicate, query, redos, rule-engine, rules, safe-regex, typescript, where

## 简介

Safe, generic condition evaluator for rules, filters and automations: evaluate a list of { field, op, value } conditions against any object with all/any matching, dotted paths, array fields (any element matches), case-insensitive strings, numbers and date
