# @lacspace/nepali-typing

> 标签: devanagari, ime, input-method, keyboard, nepali, react-native, romanized, transliteration, typescript, typing

## 简介

Romanised Nepali → Devanagari typing with per-word candidates, like a phonetic input method: "namaste" → नमस्ते, "mero desh" → मेरो देश, "kathmandu" → काठमाडौं, "netaharulai" → नेताहरूलाई. A frequency lexicon matched by a loose key that forgives romanisat
