# @lacspace/mailer

> 标签: address-parser, attachments, batch-email, connection-pooling, email, email-builder, email-retry, email-sending, hostinger, html-to-text, inline-images, mailer, memory-transport, mime, mime-builder, node-smtp, nodemailer-alternative, rate-limit, rfc2047, rfc5322, send-email, smtp, smtp-client, smtp-pool, smtp-send, tls, transactional-email, typescript, zero-dependency, zero-dependency-smtp

## 简介

A tiny zero-dependency SMTP client for Node backends — send email over raw net/tls with STARTTLS, AUTH, attachments and provider presets (Hostinger, Gmail, Outlook, Zoho…). One-line setup.
