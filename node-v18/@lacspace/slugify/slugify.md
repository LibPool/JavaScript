# @lacspace/slugify

> 标签: ascii, diacritics, is-slug, kebab-case, locale, permalink, seo, seo-url, slug, slug-generator, slug-validator, slugger, slugify, strict-slug, transliterate, truncate, typescript, unique-slug, url-friendly, url-slug

## 简介

Turn any text into a clean, SEO-friendly URL slug — transliterates diacritics, collapses separators, and guarantees uniqueness against an existing set. Zero-dependency, isomorphic.
