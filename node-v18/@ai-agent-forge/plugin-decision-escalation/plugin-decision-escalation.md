# @ai-agent-forge/plugin-decision-escalation

> 标签: agent-forge, decision-escalation, plugin

## 简介

Decision escalation capability plugin for Agent Forge (formal fork-decision ask with a local confirmation page, timeout de-escalation to an independent adjudication chain, and an irreversible redline)
