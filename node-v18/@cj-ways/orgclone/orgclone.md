# @cj-ways/orgclone

> 标签: automation, bulk-clone, cli, clone, clone-repos, developer-tools, devtools, git, git-clone, github, github-org, github-organization, gitlab, gitlab-group, group, org, organization, repos, repositories, sync

## 简介

Clone entire GitHub organizations or GitLab groups with one command. Supports public and private repos, SSH, token auth, and config files.
