# @release-health/adapter-expo-updates

> 标签: adapter, expo, expo-updates, ota, react-native, release-health

## 简介

expo-updates adapter for react-native-release-health: maps the expo-updates state machine to the OtaAdapter contract (recommendation-only; expo-updates has no client-side rollback API).
