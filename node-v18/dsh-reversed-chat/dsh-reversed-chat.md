# dsh-reversed-chat

> 标签: composer, cordis, deepseek-harness, dsh, dsh-plugin, plugin, reversed-reading, ui

## 简介

DSH client plugin: reverses the conversation reading layout — the composer pins to the TOP of an active conversation (centered on a new one) and the transcript plus turn navigator render newest-first, so replies appear right under the composer.
