# rasso-plugin-hosts-switcher

> 标签: JavaScript

## 简介

本地 Hosts 配置管理与分组切换器：支持按注释分组管理、一键启停特定规则、新建与编辑条目、自动生成快照备份并支持误操作一键回滚
