# @luziyang2026/dsh-question-nav

> 标签: JavaScript

## 简介

In-session question navigator for the DSH web GUI: a vertical minimap of round dots overlaid on the edge of the conversation column (left or right, configurable in settings), one dot per user question — hovering focuses a magnified window and a vertical c
