# @whd4/foreman

> 标签: agent, claude-code, cli, context-window, cost, goose, mascot, observability, pixel-art, statusline, svg, tokens, tui

## 简介

See what your coding agent is doing and what it's costing. Reads cost and context straight from the agent's own transcript, and puts it on screen as a character that reacts to the work.
