# vidia-api

> 标签: ai-video, api, korean, sdk, shorts, text-to-video, video-generation, vidia, youtube-shorts

## 简介

Official zero-dependency Node.js client for the VIDIA AI video API — quote, produce, track and download AI videos. 비디아 AI 영상 제작 API 공식 Node.js SDK.
