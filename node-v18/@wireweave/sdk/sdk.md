# @wireweave/sdk

> 标签: ai, claude, client, dsl, llm, sdk, ui-design, wireframe, wireweave

## 简介

Wireweave SDK - typed HTTP client, auth, and local tools for the Wireweave API. Sole owner of api-server contract for mcp-server, cli, and skill packages.

- 源码仓库：git+https://github.com/wireweave/wireweave.git
- npm 页面：https://www.npmjs.com/package/@wireweave/sdk
