# @lamsal-de/eslint-config

> 标签: JavaScript

## 简介

Install this package, then create a prettier and a eslint config. There are eslint configs for available for  svelte, vue and react as-well as a prettier config. Those are referencable as relative exports, i.e.: - @lamsal-de/eslint-config/svelte - @lamsal
