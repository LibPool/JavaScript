# @pzwik/gcloud-function-deployment-plugin

> 标签: Monorepo, cloud function, google cloud, nx, serverless

## 简介

This library was being developed to support the deployment of Google Cloud Functions via one simple command while working with the [Nx](https://nx.dev) Monorepo.
