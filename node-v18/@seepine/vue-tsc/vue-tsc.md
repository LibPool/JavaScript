# @seepine/vue-tsc

> 标签: language-plugin, tsc, type-check, typescript, volar, vue, vue-tsc, vue3

## 简介

vue-tsc 的 Node 入口：在标准 tsc 之上注入 Volar Vue 语言插件，使命令行与编辑器都能获得对 .vue 单文件组件的类型检查支持
