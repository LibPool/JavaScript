# @fieldia/testing

> 标签: JavaScript

## 简介

Test the Fieldia forms in your app as people use them: fill, pick, check and press by the words people read, a field's errors and value read back — for Testing Library and Playwright — and fieldia-check, which keeps stored pages valid in CI.
