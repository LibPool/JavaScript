# @orboto/mail

> 标签: dsgvo, email, eu-hosted, gdpr, orboto, ses, transactional-email, typescript-sdk

## 简介

Official TypeScript SDK for the Orboto Mail Service. Drop-in transactional-mail client with auto-quota-tracking, retry-with-backoff, EventEmitter for quota lifecycle events, and full TypeScript types. EU-hosted, GDPR-compliant.
