# @renewapp/nestjs-eventstore

> 标签: cqrs, event, event-streaming, eventstore, nest, nestjs, store

## 简介

An implementation of the @eventstore/db-client for the Nestjs framework and working in cooperation with the built-in Nestjs CQRS infrastructure.
