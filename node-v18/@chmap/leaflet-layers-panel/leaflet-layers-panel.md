# @chmap/leaflet-layers-panel

> 标签: gis, leaflet, map

## 简介

The floating panel for leaflet's base and over layers. It doesn't occupy any space of the map component and users can add any WMTS layer on their own. This is the first independent feature of the CHMap project belonging to MPIWG.
