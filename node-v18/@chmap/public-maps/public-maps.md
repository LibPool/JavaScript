# @chmap/public-maps

> 标签: gis, leaflet, map

## 简介

The floating panel for public maps which the CHAmp project collected. Users can filter them by a geo-coordinate and preview a public map on the leaflet map component. Additionally, users could add them into the leaflet-layers-panel.
