# @pimcore/copilot-bundle

> 标签: pimcore, pimcore-copilot, pimcore-studio-ui

## 简介

This npm package provides TypeScript type definitions for the Pimcore Copilot Studio integration. The UI components are delivered via module federation at runtime.
