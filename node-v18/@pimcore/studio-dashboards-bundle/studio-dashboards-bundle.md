# @pimcore/studio-dashboards-bundle

> 标签: pimcore, pimcore-studio-dashboards, pimcore-studio-ui

## 简介

This package provides TypeScript support for the Pimcore Studio Dashboards bundle, enabling type-safe integration and development when building and extending dashboards within the Pimcore Studio ecosystem.
