# @energy8platform/harness

> 标签: JavaScript

## 简介

A renderer- and platform-agnostic **dev harness** for Energy8 games: it frames the game in an `<iframe>`, provides screen presets (device testing), the Settings / Replay UI, a docked right sidebar, and a `wrapper ↔ iframe` message bus.
