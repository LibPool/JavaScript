# @focus-reactive/payload-plugin-analytics

> 标签: analytics, cms, nextjs, payload, payload-plugin, payloadcms, plugin, react, typescript

## 简介

A GA4-backed analytics plugin for [Payload CMS](https://payloadcms.com/) v3 + Next.js. Adds a full analytics dashboard **inside the Payload admin** — KPIs, traffic, top pages/sources/events, devices, geography, sessions, journeys, and lead-action conversi
