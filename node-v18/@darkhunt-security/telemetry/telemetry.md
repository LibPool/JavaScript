# @darkhunt-security/telemetry

> 标签: data-masking, llm, observability, opentelemetry, otel, otlp, pii, tracing

## 简介

TypeScript SDK for sending LLM traces, generations, and observations to the Darkhunt platform for persistence and security data enrichment. Built on OpenTelemetry primitives, with built-in client-side data masking.
