# @here.build/arrival-sugarcoat

> 标签: arrival, formatter, lisp, s-expressions, scheme, sweet-expressions

## 简介

Sugarcoat lens for Arrival — Scheme↔sugarcoat source rendering (indentation I-expressions, curly-infix, => lambda, method-dot, accessor subscripts, colon kwargs, at-expressions). Leaf relative to the interpreter; parseSexprs lives in @here.build/arrival-s
