# @here.build/y-control-channel

> 标签: JavaScript

## 简介

Yjs-agnostic control plane over MessagePort. Allocates per-resource MessageChannels and transfers one end to the peer; carries hello/open/close/ping/pong/status. Composes with @here.build/y-messageport but doesn't depend on Yjs.
