# @nizalix/arrange-nestjs-adapter

> 标签: accessible, api, arrange, dnd, drag and drop, drag-and-drop, express, headless, keyboard, nestjs, node, optimistic-update, persistence, typescript, validation

## 简介

Server contracts for persisting Arrange moves (list reorder, Kanban, tree): request validation, rule and permission checks, optimistic-update client helpers. Works with NestJS, Express or any Node backend.
