# @afuteam-nx/plugin-exec-eslint

> 标签: @afuteam-nx, @afuteam-nx/plugin-add-eslint-type, @afuteam/eslint-plugin-fe, nx, nx-plugins

## 简介

对代码仓库执行代码质量检查，支持批量项目。 输出结果包含仓库的 `eslint错误数` `空行数` `代码行数` `注释行数` `复杂度统计(不包含switchcase类型)`
