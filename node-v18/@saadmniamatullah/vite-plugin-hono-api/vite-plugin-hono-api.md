# @saadmniamatullah/vite-plugin-hono-api

> 标签: api, bun, deno, development, hono, multi-runtime, nodejs, plugin, server, ssr, typescript, vite

## 简介

Low-config Vite plugin that mounts a Hono API at /api and bundles it alongside your frontend. Supports Node.js, Bun, and Deno runtimes.
