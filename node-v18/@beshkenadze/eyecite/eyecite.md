# @beshkenadze/eyecite

> 标签: case-law, citations, cites, court-documents, courts, extraction, eyecite, legal, legal-tech, nlp, text-processing, typescript

## 简介

TypeScript library for extracting legal citations from text strings. A complete port of the Python eyecite library.
