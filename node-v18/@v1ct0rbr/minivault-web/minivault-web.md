# @v1ct0rbr/minivault-web

> 标签: backup, bootstrap, der, minivault, postgresql, react

## 简介

Módulo independente de gerenciamento de backups (minivault). Consumível como pacote npm em qualquer app React. Cliente do minivault REST API (acesso tipicamente via proxy autenticado).
