# @codeenthusiast09/create-express-app

> 标签: boilerplate, cli, drizzle, express, generator, mongodb, mongoose, postgresql, prisma, scaffolding, sqlite, template, typescript

## 简介

CLI tool to generate production-ready Express TypeScript projects with flexible database options (MongoDB, PostgreSQL with Prisma or Drizzle, or SQLite with Drizzle)
