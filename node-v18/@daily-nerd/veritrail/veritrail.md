# @daily-nerd/veritrail

> 标签: a2a, agent-receipts, ai-agents, attestation, audit, ed25519, jcs, jws, mcp, provenance, tamper-evident, verifiable

## 简介

The verifiable trail of agent actions — signed, tamper-evident execution receipts for AI agents (MCP & A2A): JWS signing/verification, JCS canonicalization, lineage chains, and co-signing middleware.
