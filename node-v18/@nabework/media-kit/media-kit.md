# @nabework/media-kit

> 标签: 360, 3d-viewer, gltf, hospitality, media-viewer, panorama, real-estate, street-view, three.js, virtual-tour, vr-tour

## 简介

Framework-agnostic media viewer kit: images, video, documents, panoramas, 3D models and guided VR tours (with optional Google Street View lead-in). Usable via npm or a single <script> tag from a CDN.
