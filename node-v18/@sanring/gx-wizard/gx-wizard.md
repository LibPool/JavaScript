# @sanring/gx-wizard

> 标签: JavaScript

## 简介

一個功能完整的 Angular 步驟導航組件，提供直觀的多步驟流程體驗。採用 Angular Standalone Components 架構實現，適合用於表單嚮導、註冊流程、多階段任務等場景。
