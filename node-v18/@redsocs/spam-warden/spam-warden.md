# @redsocs/spam-warden

> 标签: anti-spam, browser, client-side, content-moderation, dlp, edge-security, lightweight, moderation, naive-bayes, nlp, pii-masking, redsocs, security, siem, soc, spam-detection, spam-filter, telemetry, text-classification, thai, thai-nlp, threat-intelligence

## 简介

Lightweight universal JavaScript library for real-time spam detection. Trained on Thai spam data using Bernoulli Naive Bayes.
