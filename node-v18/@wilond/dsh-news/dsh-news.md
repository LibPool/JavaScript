# @wilond/dsh-news

> 标签: deepseek-harness, dsh, news, news-aggregator, plugin, rss

## 简介

DSH Web GUI 新闻插件：侧边栏入口 + 弹窗聚合浏览国际新闻、知识科普、历史科普、AI 大模型新闻。Host 端 RSS 抓取/正文提取/图片代理（SSRF 防护 + 缓存），Client 端弹窗三视图（列表/阅读/设置）。
