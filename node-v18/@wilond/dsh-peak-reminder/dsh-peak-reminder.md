# @wilond/dsh-peak-reminder

> 标签: deadline, deepseek-harness, dsh, floating-widget, peak, plugin, price, valley

## 简介

DSH Web GUI 峰谷提醒插件：浮动圆弧小窗实时指示 DeepSeek 官方峰谷定价时段 —— 波峰红色「梁文峰」/波谷绿色「梁文谷」。Host 端权威时间与配置持久化路由，Client 端可拖拽/可展开/可自定义时段的小窗。
