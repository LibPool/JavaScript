# @autocache/waybackify-verify

> 标签: internet-archive, s3, verify, wayback

## 简介

The wayback mirror verifier — the four-layer root to bucket parity check, its retrying undici dispatcher, and its resumable checkpoint store. Node-only audit code over the serving core of waybackify-serve. The waybackify CLI runs it as `bucket verify`.
