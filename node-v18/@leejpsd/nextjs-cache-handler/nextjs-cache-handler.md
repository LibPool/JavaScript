# @leejpsd/nextjs-cache-handler

> 标签: ISR, cache, cache-components, cache-handler, compression, ioredis, multi-instance, next, next-15, next-16, next.js, nextjs, opentelemetry, redis, self-hosting, sentinel, swr, use-cache

## 简介

Redis cache handler for Next.js 15/16 — the only one shipping both cacheHandler (ISR) and cacheHandlers ('use cache') with built-in compression, Redis Sentinel, and OpenTelemetry. Production-validated on multi-instance AWS: reconnect backoff, cross-instan
