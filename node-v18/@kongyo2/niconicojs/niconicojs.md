# @kongyo2/niconicojs

> 标签: api, client, comments, dms, hls, niconico, nicovideo, nvapi, ranking, typescript, unofficial

## 简介

Unofficial TypeScript client library for Niconico (nicovideo.jp) web APIs — videos, search, ranking, mylists, series, users, comments, and DMS/HLS streaming.
