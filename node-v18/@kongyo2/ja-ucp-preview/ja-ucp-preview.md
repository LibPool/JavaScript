# @kongyo2/ja-ucp-preview

> 标签: ansaikuropedia, ja-ucp, mediawiki, preview, typescript, uncyclopedia, wikitext

## 简介

Offline Japanese Uncyclopedia preview renderer for TypeScript/Node.js. Bundles MediaWiki 1.39.3 + the parser-affecting Japanese Uncyclopedia extensions and runs them under PHP/WASM (no system PHP required).
