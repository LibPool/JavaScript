# dsh-cds-theme

> 标签: appearance, cds, claude, deepseek, deepseek-harness, design-system, dsh, dsh-plugin, theme

## 简介

DeepSeek Harness 的 Claude Design System 主题插件：把宿主的 --dsw-* 令牌整体重映射到 CDS 的暖灰表面阶梯、陶土橙品牌色、双环焦点与有机动效，并对输入框、侧栏、消息行、代码块做组件级细化。明暗两套配色，配色/圆角/阴影走 ctx.theme.overrideTokens，组件细化走插件自有样式表。 / Claude Design System theme for DeepSeek Harness: remaps the host's --dsw-* tok
