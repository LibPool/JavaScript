# @arcsig-labs/ai

> 标签: ai, anthropic, automation, claude, code-generation, llm, workflow

## 简介

Build and edit arcflow flows with an LLM: a model-agnostic adapter, JSON output and a repair loop that feeds validation issues back until the flow is valid.
