# @angelitolm/holagram

> 标签: bot, chat, chat-widget, contact, email-verification, live-chat, nextjs, react, redis, resend, telegram, upstash, webhook

## 简介

A chat widget for your website that reaches you on Telegram: email verification with Resend, replies routed back to each visitor, state in Upstash Redis
