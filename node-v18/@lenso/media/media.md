# @lenso/media

> 标签: JavaScript

## 简介

Storage Files 之上的图片派生包。普通 async 服务负责请求、查询、取消与取得内部文件引用；已有 `@lenso/tasks` 负责持久化任务、租约、重试和有界执行。不是上传系统、Files 替代品、CDN、视频平台或新的任务系统。
