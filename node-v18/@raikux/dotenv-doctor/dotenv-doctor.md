# @raikux/dotenv-doctor

> 标签: audit, ci, cli, developer-tools, dotenv, env, environment, lint, secrets, security

## 简介

Zero-dependency CLI that audits .env hygiene: missing vars, placeholder secrets, committed credentials, and type mismatches.
