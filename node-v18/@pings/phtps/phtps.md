# @pings/phtps

> 标签: axios-alternative, browser, cache, encryption, fetch, http, http-client, ndjson, node, pagination, queue, request-deduplication, retry, sse, streaming, typescript

## 简介

A modern HTTP client built on native fetch — with plugins for retry, auth, cache, queue, encryption, streaming (SSE/NDJSON), pagination, and payment security.
