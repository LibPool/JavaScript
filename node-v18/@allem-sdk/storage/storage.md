# @allem-sdk/storage

> 标签: allem-sdk, cookies, key-value, localStorage, nextjs, react, react-hooks, sessionStorage, ssr, storage, typescript

## 简介

Provider-agnostic key-value storage for React. Adapters for localStorage, sessionStorage, cookies, and in-memory. useStorage, useStorageItem. SSR-safe.
