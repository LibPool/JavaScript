# cursor-search-mcp

> 标签: cursor, cursor-agent, mcp, mcp-server, model-context-protocol, search, web-search

## 简介

Cursor web search as an MCP tool. Pure protocol client (RunSSE + BidiAppend) — no cursor-agent binary. API key + OAuth login (CLI: cursor-search-mcp login). Zero deps.
