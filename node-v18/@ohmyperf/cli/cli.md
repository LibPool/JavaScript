# @ohmyperf/cli

> 标签: cdp, chrome-devtools-protocol, cli, cls, command-line, core-web-vitals, cwv, inp, lcp, lighthouse-alternative, ohmyperf, oopif, perf-cli, perf-measurement, performance, playwright, web-performance

## 简介

Real-machine, real-browser web performance measurement CLI. Measures Core Web Vitals (LCP/INP/CLS), runs on your hardware, and produces self-contained HTML reports + slide decks.
