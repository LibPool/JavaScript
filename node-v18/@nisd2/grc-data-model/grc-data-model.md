# @nisd2/grc-data-model

> 标签: compliance, data-model, dpa, eu, gdpr, nis2, ropa, toms, zod

## 简介

Relational data model for EU GRC: RoPA, DPA, TOMs, supplier-core, asset-core, risk, incident schemas, plus NIS2↔GDPR mappings. Zod source of truth, JSON Schema export.
