# @nwire/storage

> 标签: adapter, blob, nwire, object-storage, s3, storage

## 简介

Nwire — object-storage contract + InMemoryStorage default + storagePlugin. Adapters (S3, filesystem) live in separate packages (@nwire/storage-s3, @nwire/storage-fs).
