# @nwire/mail

> 标签: adapter, email, mail, nwire, smtp

## 简介

Nwire — transactional-mail contract + InMemoryMailer default + mailPlugin. Adapters (SMTP/nodemailer, SES, SendGrid, …) live in separate packages.
