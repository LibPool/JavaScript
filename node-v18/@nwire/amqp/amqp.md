# @nwire/amqp

> 标签: adapter, amqp, bus, messaging, nwire, rabbitmq

## 简介

Nwire — RabbitMQ-backed EventBus adapter. Topic exchange pub/sub with optional durable queues — same EventBus contract as @nwire/nats.
