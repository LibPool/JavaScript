# @nwire/dead-letter

> 标签: dead-letter, dlq, nwire, reliability

## 简介

Nwire — DLQ contract + InMemory default. Production adapters: @nwire/dlq-mongo, @nwire/dlq-bullmq. The runtime routes exhausted-retry failures here.
