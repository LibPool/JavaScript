# @nwire/config

> 标签: config, env, environment, nwire

## 简介

Nwire — typed configuration layer. env reader with coercion + aggregated fail-fast, defineConfig slices, loadConfig registry. Laravel/Adonis-grade configuration for @nwire apps.
