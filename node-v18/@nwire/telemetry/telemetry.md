# @nwire/telemetry

> 标签: jsonl, nwire, observability, reporter, telemetry

## 简介

Nwire — local telemetry reporters. Writes the canonical telemetry stream to disk as JSONL run files (.nwire/telemetry/<runId>.jsonl) for Studio history and post-mortem review. Cloud/OTLP forwarding lives in @nwire/telemetry-otel.
