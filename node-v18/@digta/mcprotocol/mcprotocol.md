# @digta/mcprotocol

> 标签: 3e, ascii, fx3u, industrial, iot, mc-protocol, mcprotocol, melsec, mitsubishi, plc, qna3e, tcp

## 简介

Mitsubishi MELSEC MC (MELSEC Communication) protocol client for Ethernet PLCs. Fork of mcprotocol 0.1.2 with a TCP framing fix for ASCII 3E responses.
