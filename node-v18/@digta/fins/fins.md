# @digta/fins

> 标签: cp2e, data-acquisition, fins, industrial, iot, omron, plc, scada, tcp

## 简介

Omron FINS TCP client for PLC data acquisition (CP2E/NX) that forwards inputs to a DCS over a TCP socket.
