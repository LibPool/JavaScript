> 标签: agent-identity, ai-agent, audit-trail, code-review, did, ed25519, github, mcp, model-context-protocol, prmaat, verifiable-audit, verifiable-credentials

## 简介

Verifiable audit trails for AI agent actions on GitHub. MCP server that lets an AI agent post PR comments/reviews with a PrMaat-anchored receipt — any third party can verify which agent passport, device key, and model produced the comment without trusting
