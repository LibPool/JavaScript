# @page-view/svelte

> 标签: a11y, carousel, daisyui, pageview, pagination, rtl, runes, slider, svelte, svelte5, tailwindcss

## 简介

Headless, Flutter-PageView-inspired paginated scroll/carousel primitive for Svelte 5 (runes) — gestures, wheel, keyboard, autoplay, RTL and lazy-loading built in.
