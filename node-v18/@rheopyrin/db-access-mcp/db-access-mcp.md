# @rheopyrin/db-access-mcp

> 标签: ai-agents, aws-secrets-manager, aws-ssm, claude, claude-code, cli, database, hashicorp-vault, mcp, model-context-protocol, mssql, mysql, postgres, rds-iam, redshift, sql-server, ssh-tunnel, typescript

## 简介

MCP stdio server that gives AI agents access to Postgres, MySQL, Redshift and SQL Server — with SSH/AWS SSM tunnels and pluggable secret providers (env, Vault, AWS Secrets Manager, RDS IAM).
