# @opscogs/octools

> 标签: agent, json-schema, mcp, tools, zod

## 简介

OpsCogs standard interface for AI agent tools: the OCTool descriptor, result envelopes, a conformance validator and plain-object converters to the MCP and Anthropic tool shapes.
