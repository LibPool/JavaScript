# @fishjam-cloud/ios-expo-voip

> 标签: callkit, expo, fishjam, pushkit, voip

## 简介

AppDelegate glue for Fishjam VoIP on iOS — registers PushKit at launch and routes Siri/Recents call intents. Install alongside @fishjam-cloud/react-native-client when VoIP options are enabled.
