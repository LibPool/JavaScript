# @fefeding/typeorm-storage

> 标签: datasource, json, orm, persistence, query-builder, repository, sql, storage, typeorm

## 简介

TypeORM-compatible JSON file storage engine — datasource facade, repository shim, query builder and in-memory SQL evaluator, with injectable storage root (framework-agnostic).
