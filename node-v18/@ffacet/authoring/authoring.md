# @ffacet/authoring

> 标签: authoring, concept, embedding, facet, llm

## 简介

facet 개념(concept) authoring 메타데이터. 호스트 LLM 파이프라인이 글에 넣을 시각화를 고르고(definition 임베딩), 고른 시각화의 내용을 writer 에게 전달(briefing)하는 데 쓰는 단일 출처.
