# @ryankleindev/cybs-jwt-client

> 标签: authentication, cybersource, jwt, message-level-encryption, mle, payments, rest

## 简介

A small, transparent toolkit for Cybersource REST API JWT authentication (standard + meta key) with per-call Message-Level Encryption — built to be read and debugged, not to be another heavyweight SDK.
