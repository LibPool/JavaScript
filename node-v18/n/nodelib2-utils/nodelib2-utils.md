# nodelib2-utils

> 标签: Array extras, Function extras, Number extras, Object extras, String extras, String sorting, debounce, defineProperty, merge, nodelib2, trace

## 简介

A JavaScript utility library that provides practical global methods. And provide extras for built-in objects such as Object, Function, Array, Number, String, etc
