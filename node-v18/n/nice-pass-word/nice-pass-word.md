# nice-pass-word

> 标签: nice pass wrod, nice-pass-wrod, nicepassword, pass-word, password

## 简介

基于原生javascript的实现的密码框，支持无痕密码模式（无填充，无记录，不会触发浏览器记住密码操作），兼容主流浏览器及ie，适用于任何框架。
