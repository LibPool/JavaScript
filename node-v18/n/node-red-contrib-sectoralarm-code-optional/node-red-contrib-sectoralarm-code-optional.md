# node-red-contrib-sectoralarm-code-optional

> 标签: alarm, node-red, sectoralarm

## 简介

Adds the ability to react to changes in armed status of Sector Alarm sites, as well as change the alarm status. This module removes the need for the alarm code to arm the system.
