# n8n-nodes-lens

> 标签: automation, blockchain, decentralized, graphql, lens, lens-chain, lens-protocol, n8n, n8n-community-node-package, nft, polygon, social-graph, social-media, web3

## 简介

A comprehensive n8n community node for Lens Protocol providing 14 resources and 60+ operations for decentralized social graph interactions. Includes profiles, publications, follows, reactions, collects, feeds, groups, and poll-based triggers.
