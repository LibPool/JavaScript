# notebook-js-ts

> 标签: JavaScript

## 简介

An interactive coding environment for JavaScript (and Typescript), resembling Jupyter Notebook. The app allows the user to create code or text snippets, execute code and view the output in a preview window. Code transpiling+bundling is performed directly
