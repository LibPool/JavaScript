# nextu-cli

> 标签: ai, cli, marketing, mcp, nextu

## 简介

Next U CLI —— 用終端機/腳本驅動 Next U 廣告製作精靈：建案、匯入商品網址、上傳本機圖、取生成提示、回存。薄殼打既有 /api/mcp/* 端點；零執行期相依。
