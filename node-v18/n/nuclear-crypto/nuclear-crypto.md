# nuclear-crypto

> 标签: 1984, B92, BB84, Bennett&Brassard, Distribution, E91, Key, QKD, Quantum, crypto, nuclear, nuclear-crypto

## 简介

это TypeScript-библиотека, которая симулирует квантовое распределение ключей (QKD) с использованием протокола BB84 и предоставляет инструменты для шифрования и расшифрования данных на основе полученного квантового ключа.
