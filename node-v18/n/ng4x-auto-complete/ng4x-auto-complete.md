> 标签: ajax, angular, angular4, angular5, angular6, auto, auto-list, complete, javascript, ng, ng4, ng4x, ng6, remort, remort-list, url

## 简介

Remote autocomple for andular 4, 5, 6. Setup the url and field names      of database which value will show in list, Multiple fiels can be set      by comma separator. The data format of return value of remote url      should be JSON. After start typing i
