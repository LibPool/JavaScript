# n8n-nodes-airparser

> 标签: ai document parser, airparser, airparser.com, automation, data extraction, document parser, email parser, excel parser, html parser, image parser, jpg parser, n8n-community-node-package, parser, pdf parser, png parser, word parser

## 简介

Official n8n Airparser node. Use Airparser in n8n to extract structured data from emails, PDFs, images, web pages, and other documents, then route the extracted data anywhere in your automation.
