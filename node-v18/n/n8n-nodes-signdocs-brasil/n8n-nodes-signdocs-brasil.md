# n8n-nodes-signdocs-brasil

> 标签: assinador, assinatura, assinatura-de-documentos, assinatura-digital, assinatura-eletronica, biometria, brasil, brazil, certificado-digital, digital-signature, document-signing, e-signature, electronic-signature, esignature, icp-brasil, n8n, n8n-community-node-package, n8n-node, signdocs, signdocs-brasil

## 简介

Nó community n8n para a SignDocs Brasil: assinatura eletrônica e digital com ICP-Brasil (A1/A3), biometria facial, OTP e clickwrap, conforme a MP 2.200-2. n8n community node for the SignDocs Brasil e-signature API.
