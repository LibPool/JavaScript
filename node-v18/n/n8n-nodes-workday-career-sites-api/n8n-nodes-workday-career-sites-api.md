# n8n-nodes-workday-career-sites-api

> 标签: ai-tool, apify, career-sites, companies-using-workday, hiring, job-board, lead-generation, myworkdayjobs, n8n, n8n-community-node-package, n8n-nodes, recruiting, workday, workday-careers, workday-customer-list, workday-tenant

## 简介

Find the companies using Workday and every career site each one runs: tenant, datacenter, careers URL, direct jobs API URL, and live open-role count as structured items. Apify-backed n8n community node, pay-per-result, and usable as an AI agent tool.
