# nestjs-interface-transformer

> 标签: abstract class, ast, interface, metadata, nestjs, plugin, reflection, transformer, typescript

## 简介

NestJS TypeScript compiler plugin that transforms interfaces into abstract classes to make interface metadata accessible at runtime
