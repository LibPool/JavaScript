# nv-facutil-switch

> 标签: switch.async

## 简介

nv-facutil-switch ================== - nv-facutil-switch  is a simple-util to avoid using-of-switch-case - support async matcher AND async handler - if match, the default-action-after-handle is break, NOT continue
