# name-to-gender

> 标签: baby names, census, demographics, detect gender, female, first name, first name gender, gender, gender detection, gender guess, gender prediction, guess gender, infer gender, male, name gender, name to gender, names, predict gender, sex, social security, ssa, typescript

## 简介

Guess gender from a first name using US Social Security data. Returns a probability and the raw birth counts. TypeScript, ESM + CJS, zero dependencies.
