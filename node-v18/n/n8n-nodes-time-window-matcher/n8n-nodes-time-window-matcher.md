# n8n-nodes-time-window-matcher

> 标签: closest-match, enrichment, join, matcher, n8n, n8n-community-node-package, time-window

## 简介

n8n node that enriches records in one stream with a value from the closest matching record in another stream, joined by a time window and optional exact-match fields
