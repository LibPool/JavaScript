# noserve

> 标签: express, expressjs, fetch route handler, fetch route handler with middlewares, fetch route handlers, no express server, no express server route invoker, no server, no server route invoker

## 简介

npm module express-noserve allows you to access the express route fetch, access, and invoke applicable Layer Objects of Middlewares and Handler/s without having to listen to a Server.
