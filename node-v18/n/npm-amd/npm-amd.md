# npm-amd

> 标签: amd, browserify, npm, package

## 简介

Scans installed npm modules, browserifies them if they are not AMD, and produce a path object to be consumed by RequireJS and the like.

- 源码仓库：git://github.com/jpka/npm-amd.git
