# n8n-nodes-truveil

> 标签: audit, compliance, governance, n8n-community-node-package, truveil

## 简介

Truveil audit node for n8n: register, log action, log decision, request approval, request a consequential-decision checkpoint, check run readiness. Types and orders the events it writes so they can be scored; asks for the judgments it cannot know. Fail-so
