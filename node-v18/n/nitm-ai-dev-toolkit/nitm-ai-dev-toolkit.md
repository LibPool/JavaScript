# nitm-ai-dev-toolkit

> 标签: agents, ai, bootstrap, claude, copilot, cursor, opencode, subagents

## 简介

Scaffold AI agent config (Cursor, GitHub Copilot, Claude Code, OpenCode) into any repo, then hand off to your AI agent to finish setup.
