# node-red-contrib-asyntai

> 标签: ai, asyntai, chatbot, customer-support, knowledge-base, leads, node-red

## 简介

Node-RED nodes for Asyntai: ask the AI chatbot, read leads and conversations, update the knowledge base, and start a flow on chat events.

## 官网

- 官网：https://asyntai.com/documentation/integrations/node-red/
- npm 页面：https://www.npmjs.com/package/node-red-contrib-asyntai

## 历史版本号

- 当前版本：1.0.0

- 1.0.0

## 获取地址

- npm 安装：`npm install node-red-contrib-asyntai`
- npm registry：https://registry.npmjs.org/node-red-contrib-asyntai
- Node 要求：>=18.0.0
