# noren-astro-theme

> 标签: astro-theme, ecommerce, gsap, japanese, noren, snipcart, store, tailwindcss

## 简介

Noren is a Japanese-inspired e-commerce Astro theme with an aizome indigo palette, noren stripe motifs, and GSAP curtain animations.
