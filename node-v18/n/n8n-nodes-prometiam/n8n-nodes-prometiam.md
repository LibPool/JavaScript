# n8n-nodes-prometiam

> 标签: company-data, company-search, europe, insolvency, know-your-business, kyb, lei, n8n, n8n-community-node-package, prometiam, sanctions-screening, vat-validation

## 简介

n8n community node for the Prometiam API: search and look up European companies, screen names against sanctions lists (beta), check corporate insolvency notices, validate VAT numbers and LEIs.
