# n8n-nodes-frappe

> 标签: doctype, erpnext, frappe, frappe-framework, n8n-community-node-package, rest-api

## 简介

Generic n8n node for Frappe and ERPNext: create, read, update, delete, submit, cancel and rename any doctype, and call whitelisted methods
