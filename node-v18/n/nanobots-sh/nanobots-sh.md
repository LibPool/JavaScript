# nanobots-sh

> 标签: agents, automation, autoresearch, claude, daytona, github, kanban, sandbox

## 简介

Self-improving agent loops for any GitHub repo — an outer loop that triages and learns, nanobot workers that build in a Daytona sandbox and ship PRs
