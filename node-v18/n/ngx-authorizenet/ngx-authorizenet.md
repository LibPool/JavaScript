# ngx-authorizenet

> 标签: JavaScript

## 简介

An Angular Wrapper for [AuthorizeNet](https://authorize.net) AcceptJS (client-side) only.   This project provides an easy-to-use Button to process secure payment using authorize.net Accept Form on your UI, before implementing Server-side Authorization.
