# node-red-contrib-dmx-for-ha

> 标签: building-automation, button, color-temp, dmx, dmx512, home-assistant, lighting, motion-sensor, mqtt, mqtt-discovery, node-red, pir, relay, rgb, rgbw, smart-home

## 简介

DMX lighting control for Home Assistant via Node-RED and MQTT. Place a node, fill in the settings, deploy. Full HA device registry integration with RGBW/RGBWW/CCT/brightness colour modes, transitions, effects, and group control.
