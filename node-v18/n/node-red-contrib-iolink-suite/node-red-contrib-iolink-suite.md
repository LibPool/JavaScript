# node-red-contrib-iolink-suite

> 标签: automation, ifm, industrial, io-link, iodd, iolink, iot-core, node-red, sensor

## 简介

Node-RED nodes for IO-Link masters: read and write process data decoded through the device's IODD, read and write ISDU parameters by name, and decode raw IO-Link bytes from any source.
