# nit-html-to-image

> 标签: canvas, capture, dom, html, image, screenshot, svg, vector

## 简介

Generates an image from a DOM node using HTML5 canvas and SVG. Forked from html-to-image. Bugfixes and additional features by Norin IT and the community.
