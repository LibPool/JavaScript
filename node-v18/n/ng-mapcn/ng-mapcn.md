# ng-mapcn

> 标签: angular, angular-18, geolocation, map, map-components, maplibre, maplibre-gl, markers, routes, shadcn, theme-aware

## 简介

Beautiful maps for Angular, made simple. MapLibre GL components for Angular 18+ with theme-aware styling inspired by shadcn/ui.
