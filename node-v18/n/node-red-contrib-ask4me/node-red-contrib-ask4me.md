# node-red-contrib-ask4me

> 标签: apprise, ask4me, human-in-the-loop, node-red, server-chan

## 简介

一个用于向 Ask4Me 服务发送请求的 Node-RED 节点，支持 MCD 和 JSON 表单的可视化编辑器。
