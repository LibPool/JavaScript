# n8n-nodes-linkedin-posts-api

> 标签: ai-tool, apify, content, engagement, linkedin, linkedin-posts, n8n, n8n-community-node-package, n8n-nodes, posts, social-media

## 简介

Collect public LinkedIn posts from profile URLs or specific post URLs, with text, reactions, comments, shares, media, and author details. Apify-backed n8n community node, pay-per-result, and usable as an AI agent tool.
