# nttuapi

> 标签: api, eclass, nttu, scraper

## 简介

高效的 NTTU 網路學園 3.0 自動化整合套件，內建圖形驗證碼辨識、登入階段維持、以及通用的課程與首頁資料抓取機制，適合做為其他專案的底層資料來源。 > 注意:本專案部分代碼使用Gemini3.1編寫 ## 安裝
