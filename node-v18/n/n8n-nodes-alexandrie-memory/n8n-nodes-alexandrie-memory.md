# n8n-nodes-alexandrie-memory

> 标签: JavaScript

## 简介

Nodes do n8n para indexação e busca híbrida (vetorial + full-text) de arquivos Markdown do Alexandrie usando PostgreSQL + pgvector, totalmente dentro do n8n.

## 官网

- npm 页面：https://www.npmjs.com/package/n8n-nodes-alexandrie-memory

## 历史版本号

- 1.0.0

## 获取地址

- npm 安装：`npm install n8n-nodes-alexandrie-memory`
- npm registry：https://registry.npmjs.org/n8n-nodes-alexandrie-memory
- Node 要求：>=18
