# nexo-editor

> 标签: Accessible Markdown Editor, Custom Toolbar Editor, Customizable Markdown Editor, Editor with Floating UI, Extendable Editor for React Projects, Lightweight Editor for React, MDX Editor, Nexo Editor Component, Radix UI Editor, React Editor with Plugins, React Markdown Editor, React Markdown Editor with Hooks, React Text Editor Component, React TipTap Extensions, Rich Text Editor, SSR Friendly Markdown Editor, ShadCN Editor Integration, Tailwind CSS Editor Component, TipTap React, WYSIWYG Markdown Editor

## 简介

A lightweight, customizable React Markdown Editor built on TipTap, designed for modern React projects with support for SSR, Tailwind, ShadCN UI, and plugin extensibility based on `@tiptap/react`
