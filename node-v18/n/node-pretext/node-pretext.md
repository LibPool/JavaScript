# node-pretext

> 标签: canvas, excalidraw, font-metrics, layout, node-canvas, pdf, pretext, server-side, svg, text-measurement, text-width

## 简介

Server-side text measurement for Node.js. Accurate font-aware width/height calculation without a browser, powered by node-canvas. The missing piece for programmatic layout in SVG, PDF, Canvas, Excalidraw, and beyond.
