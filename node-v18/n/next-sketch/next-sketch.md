# next-sketch

> 标签: 3d, animation, canvas, creative-coding, game, nextjs, p5js, react, simulation, sketch, three, threejs, webgl

## 简介

p5.js-style canvas sketches for React/Next.js — headless hooks plus drop-in <CanvasSketch>/<ThreeSketch> components, SSR-safe and DPR-aware, with an optional Three.js engine behind its own subpath export and a shared WebGL context budget.
