# ng-advanced-table

> 标签: accessibility, angular, data-table, i18n, signals, table, tanstack-table, ui

## 简介

Signals-first Angular data table built on TanStack Table — core primitives plus composable UI, utilities, virtualization, and i18n via subpath entry points (ng-advanced-table/components, /render-metrics, /virtualization, /locale).
