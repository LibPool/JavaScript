# node-cosmos

> 标签: azure, client, cosmos, cosmosdb, documentdb, light, mongodb, node, sdk, typescript

## 简介

A light weight azure cosmosdb client aiming at ease of use for creating REST API. Supports json filter, sort and offset/limit
