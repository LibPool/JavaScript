# node-sass-migrate

> 标签: codemod, dart-sass, deprecated, migration, node-sass, sass, scss, vite, webpack

## 简介

Automated migration CLI — replaces node-sass with sass (Dart Sass) in your project. Fixes breaking syntax changes automatically.
