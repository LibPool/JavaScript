# n8n-nodes-meta-dataset-standalone

> 标签: api, conversion-api, facebook, n8n, n8n-community-node-package, n8n-nodes

## 简介

Standalone fork of n8n-nodes-meta-dataset-noti-vn (MIT) with the noti.vn license-key check removed. Sends events straight to Facebook Conversions API using your own Dataset ID + Access Token.
