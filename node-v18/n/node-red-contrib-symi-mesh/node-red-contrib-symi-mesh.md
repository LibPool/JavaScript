# node-red-contrib-symi-mesh

> 标签: bluetooth, home-assistant, iot, mesh, mqtt, node-red, smart-home, symi, 亖米, 智能家居, 蓝牙网关

## 简介

Node-RED节点集合，用于通过TCP/串口连接Symi蓝牙Mesh网关，支持Home Assistant MQTT Discovery自动发现和云端数据同步
