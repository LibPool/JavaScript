# n8n-nodes-codetoimage

> 标签: code-beautifier, code-screenshot, code-snippet, code-to-image, developer-tools, documentation, image-generation, n8n, n8n-community-node-package, n8n-nodes, shiki, syntax-highlighting

## 简介

Convert code snippets into beautiful syntax-highlighted images (SVG/PNG/Base64) with 18+ language support, 8 themes, and customizable styling. Perfect for documentation, social media, and presentations.
