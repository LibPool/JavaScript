# ngx-barcode-scanner

> 标签: JavaScript

## 简介

Angular components for [QuaggaJS](https://serratus.github.io/quaggaJS/) barcode reader. It uses the new [Quagga2](https://github.com/ericblade/quagga2) supported version. Supporting Angular 10+
