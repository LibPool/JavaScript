# n8n-nodes-directsaz

> 标签: automation, directsaz, instagram, instagram-dm, n8n-community-node-package, roxjet

## 简介

n8n community node for Directsaz — Instagram DM/comment automation. Trigger on Instagram events (DMs, comments, story replies) and send replies through the Directsaz Developer API.
