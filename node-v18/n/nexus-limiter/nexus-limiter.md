# nexus-limiter

> 标签: express, fastify, fixed-window, hono, middleware, nestjs, nodejs, rate-limit, rate-limiter, redis, sliding-window, throttle, throttling, token-bucket, typescript

## 简介

Production-ready rate limiter for Node.js — token bucket, sliding window, fixed window. Express, Fastify, NestJS, Hono support. Redis and in-memory stores.
