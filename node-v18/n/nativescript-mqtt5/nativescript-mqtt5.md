# nativescript-mqtt5

> 标签: Android, IoT, JavaScript, MQTT, MQTT 5.0, MQTT5, NativeScript, TypeScript, WebSocket, iOS, messaging, pub/sub

## 简介

NativeScript MQTT client with full MQTT 5.0 support. Features include Session Expiry, Message Expiry, User Properties, Content Type, and more.
