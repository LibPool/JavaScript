# noatmark-text-hygiene

> 标签: ai text, clean text, csv injection, formula injection, invisible characters, llm output, prompt injection, rag sanitization, text cleaning, text hygiene, unicode, zero-width

## 简介

Strip invisible characters (zero-width, BOM), clean LLM formatting artifacts, escape CSV formula injection, and sanitize untrusted text for RAG. Companion to noatmark.com.
