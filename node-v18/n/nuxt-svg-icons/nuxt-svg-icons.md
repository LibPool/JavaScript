# nuxt-svg-icons

> 标签: nuxt-icons, nuxt-module, nuxt-svg-icons, nuxt3, nuxt4, svg, svg-component, svg-icon, vite

## 简介

A module for Nuxt 3 that allows you to use your own SVG icons as a component, url or raw text.
