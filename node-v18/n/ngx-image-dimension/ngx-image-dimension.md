# ngx-image-dimension

> 标签: JavaScript

## 简介

Directive imageCenteredSize makes image centered, as background (background-position: 50% 50%; background-size: cover; background-repeat: no-repeat;) but it is remains tag (`<img src='#' alt="#">`)
