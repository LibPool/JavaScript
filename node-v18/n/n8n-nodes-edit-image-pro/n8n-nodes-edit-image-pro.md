# n8n-nodes-edit-image-pro

> 标签: automation, crop, drop-shadow, font, glow, graphic-design, image, image-processing, instagram, meme, n8n, n8n-community-node-package, n8n-nodes-edit-image-pro, no-code, node, quote, resize, sharp, social-media, template, text-effects, typography, watermark, youtube-thumbnail

## 简介

Advanced image editing node for n8n — powered by Sharp (libvips). Supports templates, text effects, watermarks, fonts, quote images, meme generation, drop shadows, glows, outlines, and 20+ image operations. No GraphicsMagick required.
