# n8n-nodes-city-timezone-lookup

> 标签: city, coordinates, country, dst, geocoding, iana, lookup, n8n, n8n-community-node-package, n8n-nodes, time, timezone, utc

## 简介

Lookup timezone ID, local time, UTC offset, and DST status by city + country (or coordinates) in n8n workflows, with optional nearest-match fallback.
