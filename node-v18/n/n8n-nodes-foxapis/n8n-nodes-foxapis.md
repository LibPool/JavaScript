# n8n-nodes-foxapis

> 标签: clinicaltrials, companies, company-registry, data-api, foxapis, investors, n8n-community-node-package, patents, pubmed, uk-companies

## 简介

n8n community node for FoxAPIs - one API key for verified investors, UK company registry with ownership data, and public science and registry endpoints (biomedical papers, clinical trials, regulatory records, patents, on-chain, and labor data).
