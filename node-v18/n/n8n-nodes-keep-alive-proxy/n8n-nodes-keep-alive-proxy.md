# n8n-nodes-keep-alive-proxy

> 标签: n8n-community-node-package

## 简介

n8n community node: HTTP(S) request through a forward HTTP proxy with a persistent keep-alive agent, so consecutive requests reuse the tunnel instead of paying TCP+CONNECT+TLS setup every time. The stock HTTP Request node does not reuse proxied connection
