# newman_runner_tg

> 标签: integration, newman, qa, reports, telegram, testing

## 简介

With this script, you will be able to run your Postman collections using the Newman library and send your reports to your Telegram channel. For initial setup, you need to specify the token of your Telegram bot and specify the Telegram channel.
