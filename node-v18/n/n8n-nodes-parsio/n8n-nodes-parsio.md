# n8n-nodes-parsio

> 标签: ai document parser, automation, data extraction, document parser, email parser, excel parser, html parser, image parser, jpg parser, n8n-community-node-package, parser, parsio, parsio.io, pdf parser, png parser, word parser

## 简介

Official n8n Parsio node. Use Parsio in n8n to extract structured data from emails, PDFs, images, and other documents, then route the extracted data anywhere in your automation.
