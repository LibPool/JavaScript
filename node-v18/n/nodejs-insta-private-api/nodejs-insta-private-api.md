# nodejs-insta-private-api

> 标签: android, api, automation, baileys, bot, bulk-messaging, client, device-emulation, direct, disappearing-media, dm, instagram, ios, ipad, iphone, iphone-15, iphone-16, media-download, message-management, messages, mqtt, notifications, pixel, private, realtime, samsung, session-persistence, stories, upload, view-once

## 简介

Complete Instagram MQTT protocol with FULL iOS + Android support. 33 device presets (21 iOS + 12 Android). iPhone 16/15/14/13/12, iPad Pro, Samsung, Pixel, Huawei. Real-time DM messaging, view-once media extraction, sub-500ms latency.
