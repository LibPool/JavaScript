# noblockr

> 标签: audit-trail, client-approval, decision-log, noblockr, project-acceptance

## 简介

Reserved namespace for the official NoBlockr SDK — a decision log for resolving open project questions between freelancers/agencies and clients. The actual SDK is not yet released. Visit https://noblockr.com for updates.
