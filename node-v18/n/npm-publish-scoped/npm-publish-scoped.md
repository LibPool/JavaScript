# npm-publish-scoped

> 标签: JavaScript

## 简介

Publish any package temporarily to your @user scope, while you wait for them cut a release. Useful when your PR is merged and you don't want to wait.

- npm 页面：https://www.npmjs.com/package/npm-publish-scoped
