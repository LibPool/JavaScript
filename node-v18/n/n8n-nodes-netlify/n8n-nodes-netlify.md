# n8n-nodes-netlify

> 标签: automation, deployment, dns, forms, functions, jamstack, n8n, n8n-community-node-package, netlify, serverless, web-hosting, webhooks

## 简介

A comprehensive n8n community node for Netlify providing 12 resources and 60+ operations for site management, deployments, forms, functions, DNS, and A/B testing. Includes webhook triggers for deploy and form events.
