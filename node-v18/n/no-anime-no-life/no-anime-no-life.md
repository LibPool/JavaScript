# no-anime-no-life

> 标签: JavaScript

## 简介

无限、自由创建你的动画、漫画、游戏分享图片的工具 - 标题、小标题可自定义 - 支持添加和删除，点击图片可修改，列表为空时删除整个列表 - 列表可拖拽排序，单个元素可全局拖拽排序
