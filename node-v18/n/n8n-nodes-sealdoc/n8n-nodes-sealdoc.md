# n8n-nodes-sealdoc

> 标签: compliance, e-invoicing, factur-x, n8n, n8n-community-node-package, ocr, pdf, pdfa, pdfa-3, peppol, sealdoc, tesseract, xrechnung, zugferd

## 简介

n8n community node for SealDoc — convert documents to PDF/A-3 (with optional OCR for scanned input), render Markdown/HTML directly to sealed PDFs, generate Factur-X 1.0 / XRechnung-DE invoices from JSON (incl. BT-72 delivery date), validate Factur-X / ZUG
