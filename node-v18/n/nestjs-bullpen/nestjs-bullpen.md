> 标签: board, bull, bull board, bull dashboard, bullmq, bullmq admin, bullmq board, bullmq dashboard, bullmq monitor, bullmq ui, dashboard, jobs, monitor, nest, nestjs, nestjs bullmq, nestjs bullmq dashboard, nestjs dashboard, nestjs queue, nestjs queue dashboard, queue, queue dashboard, redis, redis queue dashboard, ui

## 简介

The NestJS-native BullMQ dashboard. Auto-discovers your queues, shows the processors behind them, runs on Express and Fastify, pluggable auth, zero runtime dependencies.
