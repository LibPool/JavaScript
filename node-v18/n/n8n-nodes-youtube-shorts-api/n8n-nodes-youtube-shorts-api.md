# n8n-nodes-youtube-shorts-api

> 标签: api, apify, creator-research, hashtags, n8n-community-node-package, shorts, shorts-analytics, social-media, tags, video-analytics, youtube, youtube-analytics, youtube-shorts

## 简介

YouTube Shorts analytics for any channel or Short link in n8n: views, likes, comment counts, exact publish dates, hashtags and creator tags as structured JSON, via the YouTube Shorts API on Apify.
