# n8n-nodes-segment

> 标签: analytics, cdp, customer-data-platform, gdpr, n8n, n8n-community-node-package, personas, privacy, segment, tracking

## 简介

A comprehensive n8n community node for Segment CDP providing 16 resources and 80+ operations for customer data collection, management, and GDPR compliance. Includes Tracking API, Public API, Personas, and audit trail support.
