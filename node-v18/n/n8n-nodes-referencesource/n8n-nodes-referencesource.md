# n8n-nodes-referencesource

> 标签: apify, citations, fact-checking, n8n, n8n-community-node-package, provenance, reference-data, verify

## 简介

n8n community node for referencesource.org: look up a regulatory threshold, certification status or compatibility fact and get back the value plus its source URL and a verbatim quote — or check a value you already have against the published record.
