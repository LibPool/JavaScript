# notifyd

> 标签: abhishek, abhishekd01, background, deshpande, init, init5, inti6, linux, notification, notifid, system, systemd

## 简介

Sends request to server to send notification to mobile app of NotifyD with title, message and datetime about successful or incomplete execution of any systemd process with custom success and fail scripts.
