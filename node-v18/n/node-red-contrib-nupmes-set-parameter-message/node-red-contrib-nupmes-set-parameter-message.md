# node-red-contrib-nupmes-set-parameter-message

> 标签: node-red

## 简介

This Node-RED node generates a rest request to the mes interface, inserting a new entry into the table parameter_messages. Machine ID and Parameter ID must be specified, incoming messages must contain the parameter value and optionally a timestamp.
