## 简介

Vue 3 library for a viewport-fixed Neko-style desktop pet: NekoPet component, useNeko composable, loadNekoRuntime, and TypeScript types. Ships the pet engine inside the package (dynamic import). Peer: vue ^3.4 || ^3.5.
