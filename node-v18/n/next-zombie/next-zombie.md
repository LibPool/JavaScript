# next-zombie

> 标签: ENOENT, auto-restart, buildManifest, cache-corruption, cache-error, cli, crash, dev-server, developer-experience, dx, next.js, next13, next14, next15, next16, nextjs, turbopack

## 简介

Fix ENOENT _buildManifest.js.tmp error. Auto-restart Next.js Turbopack dev server on crash. Supports Next.js 13.4+.
