# n8n-nodes-honeycomb

> 标签: alerts, apm, debugging, events, honeycomb, metrics, monitoring, n8n, n8n-community-node-package, observability, slo, telemetry, tracing, triggers

## 简介

A comprehensive n8n community node for Honeycomb observability platform providing 12 resources and 50+ operations for querying telemetry data, managing datasets, boards, triggers, SLOs, and events.
