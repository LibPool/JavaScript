# node.ts-streams

> 标签: async-iterable, async-iterator, backpressure, batch, concurrency, etl, map, merge, object-mode, pipeline, stream, streams, typescript

## 简介

Typed, chainable wrapper around Node object-mode streams: backpressure, concurrency-controlled map, merge, split, batching and async iteration
