# nuxt-font-fallback

> 标签: capsize, cls, font-fallback, font-metrics, fontaine, nuxt, nuxt-module

## 简介

Automatic font metric fallback for Nuxt. Reads font files, computes metric overrides, and generates CSS @font-face declarations to eliminate CLS from web font loading.
