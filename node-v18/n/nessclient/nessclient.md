# nessclient

> 标签: d16, d16x, d8, d8x, ness

## 简介

Library for interfacing with Ness D8x and D16x alarm systems, via an RS232 network server.

- 源码仓库：https://github.com/kbortnik/nessclient-d8x-d16x.git
