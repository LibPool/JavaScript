# n8n-nodes-xing-jobs-scraper

> 标签: apify, n8n, n8n-community-node-package, n8n-nodes, scraping

## 简介

Scrape XING job listings for the DACH market (Germany, Austria, Switzerland). Returns job ID, title, company, location, salary, employment type, posted date, and description snippet. No login required. Paginated search with keyword + optional location fil
