# next-app-trpc

> 标签: boilerplate, decimal.js, nextjs, react-query, superjson, trpc

## 简介

A Node.js package for seamless integration of tRPC into existing Next.js projects. It simplifies setting up tRPC clients/servers, managing API routes, and ensuring compatibility with import aliases.
