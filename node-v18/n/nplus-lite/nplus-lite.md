# nplus-lite

> 标签: dataBind, dom, html, lite, template

## 简介

轻量化的模板解释器，支持数据双向绑定，支持页面元素遍历，二维数据结构遍历，纯数字遍历，数据和页面分离，HTML模板结构，组件和页面分离，组件的生命周期，同名前缀Less自动引入。
