# nightglass-mcp

> 标签: ai-agent, api, headless-browser, mcp, model-context-protocol, nightglass, og-image, playwright, screenshot, website-screenshot, x402

## 简介

MCP server for the nightglass screenshot API. Take website screenshots from any MCP-compatible client (Claude Desktop, Cursor, Windsurf, etc).
