# npm-hono-proxy

> 标签: JavaScript

## 简介

軽量な「許可範囲付き npm プロキシ」。許可されない/安全でないと判断されたパッケージやバージョンを「存在しないもの」として扱い、`npm install` 時に `ETARGET` で気づけるようにします。

## 官网

- npm 页面：https://www.npmjs.com/package/npm-hono-proxy
