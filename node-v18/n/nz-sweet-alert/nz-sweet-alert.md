# nz-sweet-alert

> 标签: JavaScript

## 简介

A super lightweight, "promising" Angular wrapper for [SweetAlert](http://tristanedwards.me/sweetalert), a beautiful replacement for Javascript's "Alert".

- 官网：https://github.com/nozzle/nzSweetAlert
