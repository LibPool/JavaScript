# nepal-localbodies-react

> 标签: JavaScript

## 简介

It is a custom react hook  which returns 4 value: 1. localBodySelected: array of local bodies for selected district 2. districtSelected: array of districts for selected state 3. stateSelected: selected state 4. template: template for local body form
