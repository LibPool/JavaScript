# n8n-nodes-ceneo-price-scraper

> 标签: apify, n8n, n8n-community-node-package, n8n-nodes, scraping

## 简介

Scrape Ceneo.pl, Poland's largest price-comparison site. Per product: name, lowest price, number of offers, rating, review count, image and URL. Search any keyword. Ideal for price monitoring, market research and competitor analysis.
