# nutra-jasmine-coverage-preset

> 标签: N.U.T.R.A., behavior-driven, coverage, istanbul, jasmine, node, preset, test, testing, unit

## 简介

The "nutra-jasmine-coverage-preset" module makes available the "jasmine" framework, "Istanbul" code coverage tool, and "commonjs" module loader to the "N.U.T.R.A." unit test runner.
