# nodejsfunction-plus

> 标签: cdk, httpkeepalive, lambda, nodejs

## 简介

The NodejsFunction from the @aws-cdk/aws-lambda-nodejs package but with the AWS_NODEJS_CONNECTION_REUSE_ENABLED automatically set.
