# n8n-nodes-99acres-listings

> 标签: apify, n8n, n8n-community-node-package, n8n-nodes, scraping

## 简介

This actor reads property search results and listing pages on 99acres. Records include listing titles, prices, locations, property types, bedrooms, area details, descriptions, and listing URLs when available.
