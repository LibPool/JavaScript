# node-focas

> 标签: automation, cnc, fanuc, focas, iot, node-focas, nodejs

## 简介

Node.js wrapper for the FOCAS library used to comunicate with Fanuc CNC. The main dependecy is koffi, used to load the FOCAS dll at runtime. This package doesn't include the FOCAS library itself.
