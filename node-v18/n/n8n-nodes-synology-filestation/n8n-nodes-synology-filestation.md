# n8n-nodes-synology-filestation

> 标签: ai-agent, automation, backup, cloud sync, dsm, file management, file station, files, filestation, n8n-community-node-package, nas, storage, synology, trigger

## 简介

n8n community nodes for Synology DSM File Station — manage NAS files (upload, download, copy, move, rename, delete, share links, search, archives, checksums, thumbnails), trigger workflows on file changes, control Cloud Sync connections, and expose it all
