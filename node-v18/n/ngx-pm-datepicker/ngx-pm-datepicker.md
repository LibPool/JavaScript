# ngx-pm-datepicker

> 标签: angular, calendar, date-picker, datepicker, farsi, jalali, persian, rtl, shamsi, signals

## 简介

Signal-based, dual-calendar (Jalali/Gregorian) date & time picker for Angular, RTL-first with themeable CSS variables.
