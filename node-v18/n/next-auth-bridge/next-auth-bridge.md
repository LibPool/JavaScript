# next-auth-bridge

> 标签: auth.js, authentication, chips, iframe, next-auth, nextjs, oauth, partitioned-cookies, passkeys, pwa

## 简介

Cross-context authentication bridge for Next.js / Auth.js (popup + PWA-shell transports) backed by a one-time-use transfer store.
