# n8n-nodes-dexpaprika

> 标签: blockchain, crypto, cryptocurrency, defi, dex, dexpaprika, market-data, n8n, n8n-community-node-package

## 简介

n8n community node for DexPaprika: keyless DEX and on-chain market data across 36 blockchains (pools, token prices, OHLCV, search).
