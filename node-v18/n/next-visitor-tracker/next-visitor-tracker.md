# next-visitor-tracker

> 标签: analytics, dashboard, next.js, nextjs, self-hosted, utm, visitor-tracking

## 简介

Self-hosted visitor tracking for Next.js — sessions, page views, custom actions, UTM/Google Ads attribution, and a built-in dashboard with filtering and sorting.
