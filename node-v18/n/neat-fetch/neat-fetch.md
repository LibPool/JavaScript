# neat-fetch

> 标签: api, axios-alternative, browser, error-handling, fetch, http, http-request, javascript, json, neat-fetch, nodejs, promise, react-native, request, rest, retry, safe, timeout, try-catch, tuple, type-safe, typescript

## 简介

Neat Fetch is a modern, lightweight, and type-safe wrapper around the native `fetch` API that makes HTTP requests predictable, readable, and enjoyable.
