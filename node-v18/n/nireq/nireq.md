# nireq

> 标签: browser, client, fetch, http, nireq, timeout, xhr

## 简介

Tiny fetch HTTP client: URL allowlist (incl. redirects), default timeout, opt-in retry, blob/stream, axios-compatible subset. Zero dependencies.
