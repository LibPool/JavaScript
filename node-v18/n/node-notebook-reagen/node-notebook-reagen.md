# node-notebook-reagen

> 标签: JavaScript

## 简介

- 执行note命令，即可展示当前所有的todo任务 - 一级菜单支持: 退出、新增任务、选择进入一条todo任务 - 进入一条todo任务支持二级菜单操作: 将其标记为已完成、未完成、删除、退出以及修改todo的标题 - 修改todo的标题，在输入框中输入想要更新的标题，即可完成修改标题
