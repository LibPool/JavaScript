# n8n-nodes-lolik

> 标签: ai-agents, content, lolik, n8n, n8n-community-node-package, trend-intelligence, trends, virality

## 简介

n8n community node for Lolik Trend Radar — live trend intelligence (what's rising, why, and how to act) as workflow steps. The honest replacement for the 'ask an LLM what's trending' guess-step.
