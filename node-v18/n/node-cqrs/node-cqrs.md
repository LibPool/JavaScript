# node-cqrs

> 标签: command-bus, cqrs, ddd, domain-driven-design, event-bus, event-sourcing, event-store, eventsourcing, nodejs, projection, rabbitmq, redis, saga, sqlite, typescript, worker-threads

## 简介

TypeScript CQRS/Event Sourcing toolkit for Node.js with DI, sagas, projections, and optional Worker, RabbitMQ, and SQLite adapters
