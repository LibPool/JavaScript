# nimbleservice

> 标签: REST, api, api only, express, framework, micro service, microservice, mongoose, node api, rest generator, service

## 简介

A node Js Framework for rapidly building microservice API's. A Wrapper around express and mongoose with some built in transformations. Currently we are supporting services that use (of course Node) but also Mongo DB (hence the mongoose ODM), and Redis for
