# native-websocket-vue3

> 标签: auto-reconnect, composable, composition-api, pinia, reactive, realtime, socket, typescript, useWebSocket, vue, vue3, vuex, websocket

## 简介

Native WebSocket implementation for Vue 3 with Composition API, Vuex, and Pinia support. Features auto-reconnect, TypeScript definitions, and useWebSocket composable.
