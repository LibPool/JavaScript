# notoriety

> 标签: APN, GCM, android, iOS, iPad, iPhone, nexus

## 简介

A Node.js module for Push Notifications to iOS (iPhone/iPad APNS), Android (GCM), Amazon (ADM), Windows Phone (MSDN), Windows 8, Blackberry, and FirefoxOS devices!
