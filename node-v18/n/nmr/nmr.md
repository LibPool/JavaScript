# nmr

> 标签: delete, node_modules, remove, unlink, windows

## 简介

Delete/remove Node.js 'node_modules' on Windows using 'subst' to avoid 'The file name is to long' error

- 官网：https://github.com/jaguard/nmr
- 源码仓库：git://github.com/jaguard/nmr.git
- npm 页面：https://www.npmjs.com/package/nmr

- npm 安装：`npm install nmr`
- npm registry：https://registry.npmjs.org/nmr
- Node 要求：>=0.8.0
