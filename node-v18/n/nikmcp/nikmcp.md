# nikmcp

> 标签: ai, claude, luau, mcp, model-context-protocol, roblox, roblox-studio

## 简介

Custom Roblox Studio MCP server (dual-context): MCP stdio server + local HTTP bridge that the Studio edit plugin and F5 runtime agent poll. Drop-in superset of robloxstudio-mcp.
