## 简介

Node-RED nodes for Omron NX/NJ/NX1P2 EtherNet/IP tag data links (Class 1 cyclic I/O). The PC running Node-RED is the passive adapter/target; the Omron controller is the scanner. Includes a step-by-step setup wizard (paste from Sysmac -> validate -> genera
