# node-blead-sl

> 标签: BLE, Bluetooth, Bluetooth Low Energy, Bluetooth smart, beacon, buzzer

## 简介

The node-blead-sl is a controller of BLE beacon "BLEAD-SL" equipped with a buzzer. Note that "BLEAD-SL" is available only in Japan.
