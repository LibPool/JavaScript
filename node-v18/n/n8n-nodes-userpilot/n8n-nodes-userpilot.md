# n8n-nodes-userpilot

> 标签: analytics, automation, n8n, n8n-community-node-package, nps, product-growth, user-onboarding, user-tracking, userpilot

## 简介

A comprehensive n8n community node for UserPilot with 12 resources: Users, Companies, Events, Flows, NPS Surveys, Checklists, Resource Center, Segments, Data Export, Jobs, Spotlights, and Banners. Includes webhook trigger support.
