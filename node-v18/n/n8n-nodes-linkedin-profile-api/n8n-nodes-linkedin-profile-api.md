# n8n-nodes-linkedin-profile-api

> 标签: ai-tool, apify, enrichment, lead-generation, linkedin, linkedin-profile, n8n, n8n-community-node-package, n8n-nodes, people, profile, prospecting, recruiting

## 简介

Collect public LinkedIn profiles and return name, headline, location, company, experience, education, and follower counts. Apify-backed n8n community node, pay-per-result, and usable as an AI agent tool.
