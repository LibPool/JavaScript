# node-milight-rf24

> 标签: LED, Milight, RF24, SmartHome, WifiLight, nrf24

## 简介

This module can communicate with an Arduino with the sketch from https://github.com/henryk/openmili to communicate with milight and OEM equivalents auch as Rocket LED, Limitless LED Applamp, Easybulb, s`luce, iLight, iBulb, and Kreuzer 2.4GHz LED Bulbs
