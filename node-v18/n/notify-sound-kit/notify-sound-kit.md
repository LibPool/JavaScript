# notify-sound-kit

> 标签: alert, cross-platform, expo, headless, modal, notification sound, notifications, react, react-native, sound, toast

## 简介

A cross-platform notification + sound system for React (Web), React Native (Bare), and Expo. Toast, Alert, Modal with built-in sound effects, volume control, and fully customizable themes.
