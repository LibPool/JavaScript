# nstantpage-agent

> 标签: agent, dev-server, development, local-dev, nextjs, nstantpage, preview, tunnel, vite

## 简介

Local development agent for nstantpage.com — run your projects locally, preview in the cloud. Replaces cloud containers for faster builds.
