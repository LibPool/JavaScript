# netlify-publisher

> 标签: ci, deploy, html-report, netlify, playwright, publish, report

## 简介

Zip a Playwright (or any static) HTML report and publish it to Netlify as a deploy, returning a shareable URL.

## 官网

- npm 页面：https://www.npmjs.com/package/netlify-publisher

## 历史版本号

- 1.0.0

## 获取地址

- npm 安装：`npm install netlify-publisher`
- npm registry：https://registry.npmjs.org/netlify-publisher
- Node 要求：>=18
