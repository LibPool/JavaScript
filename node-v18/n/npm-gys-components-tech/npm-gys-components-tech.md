# npm-gys-components-tech

> 标签: JavaScript

## 简介

1、支持组件之间通信  2、给全局参数赋值，如 ${orgId} 3、支持组件点击跳转 包含url跳转和router 跳转 4、初始化时需要加载数据 5、 弹出窗口布局 6、多个元数据 实现tab切换
