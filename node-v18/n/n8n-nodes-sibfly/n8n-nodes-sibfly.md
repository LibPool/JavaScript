# n8n-nodes-sibfly

> 标签: geospatial, ground-motion, insar, n8n, n8n-community-node-package, nasa, sibfly, subsidence

## 简介

n8n community node for SibFly — satellite-measured ground motion (subsidence/uplift, mm/year) per US address from NASA InSAR. Check motion, coverage, portfolios and account from your workflows.
