# n8n-nodes-arbeitsagentur-jobs-scraper

> 标签: apify, n8n, n8n-community-node-package, n8n-nodes, scraping

## 简介

Scrape job listings from Germany's Federal Employment Agency (Arbeitsagentur.de) via its official Jobsuche API. Returns title, employer, full description, location, salary, contract type and more. Pay per job delivered.
