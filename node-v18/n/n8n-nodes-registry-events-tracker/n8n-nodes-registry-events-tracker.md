# n8n-nodes-registry-events-tracker

> 标签: n8n, n8n-community-node-package, n8n-nodes

## 简介

n8n community node: track fresh company registry events (new registrations, dissolutions, insolvencies) for France (BODACC) and the UK (Companies House) as B2B sales signals.
