# nazar-audit

> 标签: allowlist, audit, ci, cli, cli-tool, dependencies, devsecops, exceptions, nodejs, npm, package-manager, pnpm, sca, scanner, security, security-scanner, supply-chain, typescript, vulnerabilities, vulnerability, yarn

## 简介

A modern, security-conscious package vulnerability scanner for the JavaScript ecosystem. Wraps npm/pnpm/yarn audit with exception management, multiple output formats, and fix availability reporting.
