# nyxpi

> 标签: calculator, cas, cli, math, plot, repl, symbolic, terminal

## 简介

Mathematica energy in the terminal — an exact-first math CLI with symbolic calculus, matrices, plotting, user functions, and honest errors. No LLM, pure local math.
