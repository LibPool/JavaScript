# ngx-animate-ref

> 标签: JavaScript

## 简介

The goal of this project is to get for Angular2+ the same animation available for angularJS called animation anchoring: https://docs.angularjs.org/api/ngAnimate#animation-anchoring-via-ng-animate-ref-
