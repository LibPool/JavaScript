# n8n-nodes-whatsapp-cloud-full

> 标签: graph-api, messaging, meta, n8n, n8n-community-node-package, whatsapp, whatsapp-business, whatsapp-cloud-api

## 简介

Full-coverage n8n community node for the WhatsApp Business Cloud API: messages, templates with dynamic parameter mapping, media, phone numbers, groups, analytics and a signature-verified webhook trigger
