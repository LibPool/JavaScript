# nuomi

> 标签: nuomi, nuomi-redux, nuomi-router, nuomijs, redux, router

## 简介

nuomi是基于react和redux开发的一套数据流解决方案，也可以看成轻量级业务框架，它可以规范和简化使用redux 进行状态管理的开发流程，与 路由 完美结合可以更高效开发单页应用。
