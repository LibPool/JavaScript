> 标签: JavaScript

## 简介

- 添加 ts 支持   - pnpm install @rollup/plugin-typescript tslib typescript -D - 添加 rollup 相关插件   - pnpm install rollup @rollup/plugin-commonjs @rollup/plugin-node-resolve -D - 添加 Babel，也可以直接 ts 指定就行   - pnpm install @rollup/plugin-babel @babel/core @babe
