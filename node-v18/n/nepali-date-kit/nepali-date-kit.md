# nepali-date-kit

> 标签: ad-to-bs, bikram-sambat, bs, bs-to-ad, calendar, date, date-picker, moment, nepal, nepali-calendar, nepali-date, nepali-date-kit, nepali-datepicker, range-picker, react, react-native

## 简介

Complete Nepali (Bikram Sambat) date toolkit — a moment-style immutable date object, AD/BS conversion, formatting, and React date pickers and calendar.
