> 标签: centralized, config, configuration, data, devop, devops, editor, expression, external, http, ide, javascript, js, language, nexl, nexl-engine, nexl-js, rest, scripting, server, service, storage, web

## 简介

nexl is a configuration hosting server. Configuration is stored in native JavaScript files, exposed via standard HTTP protocol and can be accessed by special expression language
