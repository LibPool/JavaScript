# npmir

> 标签: manage, mirror, mirror manage, npm mirror, npmir, test mirror

## 简介

这是一个轻量无第三方依赖、操作易用、终端美观的npm镜像管理库，提供了友好的中文终端界面，可批量测试镜像地址的有效性，更多详细内容请参阅README文档
