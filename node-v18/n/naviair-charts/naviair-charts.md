# naviair-charts

> 标签: aeronautical-information, aip, airac, aviation, charts, denmark, efb, faroe-islands, greenland, ifr, naviair, pdf, vfr

## 简介

Stable, AIRAC-proof links to NAVIAIR (aim.naviair.dk) AIP/VFG charts. Resolve a chart name to its current PDF URL.
