# n8n-nodes-openrouter-multimodal

> 标签: ai, audio, gemini, gpt, multimodal, n8n, n8n-community-node-package, openrouter, pdf, transcription, video, vision, whisper

## 简介

n8n community node for OpenRouter multimodal capabilities: chat, image analysis, audio analysis, speech-to-text (transcription), document/PDF analysis and video analysis with dynamic model capability discovery.
