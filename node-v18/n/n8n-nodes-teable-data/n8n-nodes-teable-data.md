# n8n-nodes-teable-data

> 标签: n8n-community-node-package

## 简介

一款专为 N8N 设计的插件，无缝集成 Teable API 核心能力，支持对 Teable 表格记录执行**创建、获取、更新、删除**全生命周期操作，无需手动拼接 API 请求，可视化配置即可快速打通 Teable 数据流转。
