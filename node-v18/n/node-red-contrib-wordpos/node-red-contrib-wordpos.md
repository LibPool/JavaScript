# node-red-contrib-wordpos

> 标签: contrib-wordpos, node-red, wordpos

## 简介

This package is written to be used in Node-Red framework.It uses npm package https://github.com/moos/wordpos which uses WordNet database for extracting information in js part.It takes msg.payload and msg.endpoint as parameters and outputs related informat
