# n8n-nodes-google-hotels-api

> 标签: accommodation, ai-tool, apify, autocomplete, google-hotels, hotel-photos, hotel-reviews, hotel-search, hotels, lodging, n8n, n8n-community-node-package, n8n-nodes, reviews, travel, vacation-rentals

## 简介

Search hotels and vacation rentals, and get guest reviews, photo galleries, and autocomplete suggestions with names, nightly rates, and ratings. Apify-backed n8n community node, pay-per-result, and usable as an AI agent tool.
