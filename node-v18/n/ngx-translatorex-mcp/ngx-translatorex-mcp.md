# ngx-translatorex-mcp

> 标签: agent, ai, angular, claude, copilot, i18n, internationalization, llm, localization, mcp, model-context-protocol, ngx-translate, translate, translation

## 简介

MCP server to localize Angular / ngx-translate apps with an AI agent (Claude, Copilot): scan hard-coded strings, extract i18n keys, and translate — from any MCP client.
