# notecraftapp

> 标签: ai, astro, claude, cli, documentation, interactive, markdown, mdx, notecraft, notecraftapp, notes, viewer, visualization

## 简介

由 AI 生成視覺化與動態互動元件、嵌入筆記的個人筆記 Web App。用 npx 一行指令在任何 md/mdx 資料夾啟動漂亮 UI。
