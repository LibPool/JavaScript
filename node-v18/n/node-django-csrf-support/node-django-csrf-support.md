# node-django-csrf-support

> 标签: JavaScript

## 简介

> Set a csrftoken header in AJAX requests using jQuery every time in Django. > Based on the document [csrf in Django](https://docs.djangoproject.com/en/dev/ref/contrib/csrf/). > Only compatible with requirejs right now.
