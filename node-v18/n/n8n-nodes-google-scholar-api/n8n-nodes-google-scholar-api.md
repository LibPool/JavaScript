> 标签: academic-papers, ai-tool, apify, citations, google-scholar, n8n, n8n-community-node-package, n8n-nodes, research-papers, scholar, scholarly

## 简介

Search Google Scholar and return academic papers with titles, publication info, and links. Apify-backed n8n community node, pay-per-result, and usable as an AI agent tool.
