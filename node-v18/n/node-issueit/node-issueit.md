# node-issueit

> 标签: JavaScript

## 简介

Create an issue on the git repository if the error occurs 3 times. Auto close if issue doesn't occur next time

## 官网

- 源码仓库：https://github.com/gitless/node-issueit
- npm 页面：https://www.npmjs.com/package/node-issueit
