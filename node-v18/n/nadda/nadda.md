# nadda

> 标签: Acceptance, Automated, BDD, browser, chromedriver, ci, iedriver, nightwatch, phantomjs, selenium, testing, yadda

## 简介

A zero config plugin for BDD acceptance testing in the browser using a combination of yadda and nightwatch
