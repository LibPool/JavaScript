# n8n-nodes-spec2schematic

> 标签: cad, dxf, eda, electrical, n8n, n8n-community-node-package, netlist, schematic, spec2schematic, svg

## 简介

n8n community node that turns a text netlist/spec into a schematic (SVG + lint findings) or a DXF drawing, via the hosted spec2schematic service.
