# n8n-nodes-shirtigo

> 标签: n8n-community-node-package, pod, print-on-demand, shirtigo

## 简介

Connect n8n with the Shirtigo Cockpit REST API for print-on-demand automations. Create and manage designs, products, projects, orders and webhooks directly inside your workflows. Made by Hemmilicious - Prints4Friends.de
