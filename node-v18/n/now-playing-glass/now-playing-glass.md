# now-playing-glass

> 标签: dynamic-island, framer-motion, glassmorphism, lastfm, liquid-glass, now-playing, react, spotify, ui

## 简介

A presentational React "now playing" widget — an album disc that taps open into a Dynamic-Island-style glass card (shared-element cover morph, equalizer, ambient backdrop, marquee). Bring your own data source (Last.fm, Spotify, Apple Music…).
