# n8n-nodes-opentweet

> 标签: n8n, n8n-community-node-package, opentweet, scheduling, social-media, tweet, twitter, x

## 简介

n8n community node to post, schedule, and manage X (Twitter) content with OpenTweet. One API key, no X developer account.
