# n8n-nodes-privy

> 标签: authentication, blockchain, embedded-wallet, ethereum, mpc, n8n, n8n-community-node-package, privy, self-custodial, solana, waas, wallet, wallet-as-a-service, web3

## 简介

A comprehensive n8n community node for Privy wallet-as-a-service platform, providing user management, embedded wallets, server wallets, delegated wallets, and authentication operations for Web3 applications.
