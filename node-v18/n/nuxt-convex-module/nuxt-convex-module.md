# nuxt-convex-module

> 标签: auth, auth0, authentication, backend, better-auth, billing, clerk, convex, database, file-storage, live-queries, nuxt, nuxt-module, polar, realtime, ssr, vue

## 简介

Connects a Nuxt app to a Convex backend: live queries, mutations, actions, pagination, file storage and SSR, auto-imported and typed against your deployment. The same Vue client runs without Nuxt; Better Auth, Clerk, Auth0 and Polar are opt-in.
