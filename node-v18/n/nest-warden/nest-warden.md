# nest-warden

> 标签: abac, authorization, casl, multi-tenant, nestjs, permissions, rbac, rebac, tenant, typeorm

## 简介

nest-warden — tenant-aware authorization for NestJS + TypeORM, built on @casl/ability. First-class tenant scoping, relationship-graph traversal, and TypeORM reverse lookups (accessibleBy).
