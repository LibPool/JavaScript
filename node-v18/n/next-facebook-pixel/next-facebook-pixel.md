# next-facebook-pixel

> 标签: analytics, conversion-tracking, facebook, facebook-conversion, facebook-pixel, fbq, meta, next, nextjs, pixel, tracking, typescript

## 简介

All-in-one, framework-aware Facebook Pixel for Next.js. Typesafe events, SPA route-change PageView tracking, auto loaded via layout component.
