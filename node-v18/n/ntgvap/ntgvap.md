# ntgvap

> 标签: JavaScript

## 简介

在3分钟内快速将地理智能可视化工具加载到你的vue项目中。 ## 使用示例 ### 组件注册 ```ts import GVAP from "ntgvap"; app.use(GVAP); ``` ### 如何在目标组件中使用 ```ts <template>   <div class="container">     <gvap />   </div> </template> <script setup lang="ts"></script> ```
