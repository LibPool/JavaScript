# nodebb-plugin-account-retention

> 标签: data-protection, gdpr, inactive-accounts, nodebb, nodebb-plugin, privacy, retention

## 简介

GDPR-friendly inactive account retention for NodeBB. Configurable inactivity threshold, escalating warning emails, audit log, dry-run mode and one-click keep-alive links. Native deleteAccount preserves posts as guest content.
