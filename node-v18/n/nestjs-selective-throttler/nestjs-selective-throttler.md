# nestjs-selective-throttler

> 标签: api-throttling, guard, named-throttlers, nestjs, nestjs-guard, nodejs, rate-limit, rate-limiting, request-limiting, route-throttling, selective, selective-throttling, throttle-decorator, throttler, throttler-override, typescript

## 简介

A NestJS package that provides true selective throttling capabilities, applying only the named throttlers explicitly declared in route decorators.
