# n8n-nodes-prisjakt-price-scraper

> 标签: apify, n8n, n8n-community-node-package, n8n-nodes, scraping

## 简介

Scrape Prisjakt.nu, Sweden's leading price-comparison site. Pick any category and get a clean row per product: lowest price, rating, URL and image. Pay per result; residential proxy built in.
