# n8n-nodes-timergy

> 标签: calendar, doodle, n8n, n8n-community-node-package, polls, scheduling, timergy, when2meet

## 简介

n8n community node for Timergy scheduling polls. Create polls, collect votes, suggest best times, and finalize meetings.
