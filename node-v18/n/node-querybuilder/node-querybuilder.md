# node-querybuilder

> 标签: active record, activerecord, codeigniter, mongo, mssql, mysql, node, nodejs, postgres, query builder, querybuilder, sqlite, translator

## 简介

Modeled after Codeigniter's QueryBuilder. Build and execute queries in a safe and database-agnostic way.
