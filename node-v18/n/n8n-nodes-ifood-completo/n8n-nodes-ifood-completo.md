# n8n-nodes-ifood-completo

> 标签: conciliacao, delivery, ifood, merchant-api, n8n, n8n-community-node-package

## 简介

Nodes n8n modulares para Merchant API iFood: autenticação, lojas, eventos, pedidos, financeiro, análise de conciliação, catálogo, produtos de catálogo, logística, shipping e avaliações.
