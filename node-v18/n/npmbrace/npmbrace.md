# npmbrace

> 标签: npm

## 简介

Node Package Manager with brace expansion that switches between NPM versions, NPM 2 to NPM 6

- 官网：https://github.com/ex-machine/npmbrace
- 源码仓库：git+https://github.com/ex-machine/npmbrace.git
- npm 页面：https://www.npmjs.com/package/npmbrace
