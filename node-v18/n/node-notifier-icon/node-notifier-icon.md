> 标签: growl, mac os x 10.8, notification, notification center, notify, notify-send, terminal-notifier, toaster, windows 8 notification

## 简介

A Node.js module for sending notifications on native Mac, Windows (post and pre 8) and Linux (or Growl as fallback), This is just a fork from mikaelbr/node-notifier@5.2.1 replaced the alloy/terminal-notifier with a custom notification icon, pending add mo
