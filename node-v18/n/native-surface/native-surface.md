# native-surface

> 标签: canvas, embed, react-native, renderer, skia, vite, wasm, yoga

## 简介

Run real React Native component trees inside any React DOM app - a canvas renderer (Yoga WASM layout + Skia/CanvasKit paint, custom reconciler) with a one-call Vite preset. Not react-native-web.
