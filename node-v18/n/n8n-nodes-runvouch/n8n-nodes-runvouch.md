# n8n-nodes-runvouch

> 标签: ai-agents, cron, dead-mans-switch, heartbeat, monitoring, n8n-community-node-package, observability, runvouch, schedule

## 简介

n8n community node for RunVouch: heartbeat and dead man's switch monitoring for scheduled workflows. Start run, end run with evidence, or both in one step. Alerts when a Schedule Trigger stops firing or a workflow finishes green without doing the work.
