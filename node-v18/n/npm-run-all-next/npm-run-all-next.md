# npm-run-all-next

> 标签: cli, command, commandline, npm, npm-scripts, parallel, retries, retry-failed, retry-failed-task, run, sequential, serial, task, tool

## 简介

A CLI tool to run multiple npm-scripts in parallel or sequentially, with support for retrying failed tasks.
