# n8n-nodes-alphasac

> 标签: alphasac, atendimento, crm, instagram, n8n-community-node-package, whatsapp

## 简介

n8n community node para a API de Integração do AlphaSac — enviar mensagens (texto, mídia, botões, lista, carrossel, template WABA), agendar posts do Instagram, transferir tickets para setor/agente, aplicar etiquetas e fechar atendimentos.
