# ng-boxed

> 标签: ancestors, angular, bootstrap, boxed, dom, layout

## 简介

The 'boxed" is an Angular directive which provides an easy way to wrap a DOM element and apply classes to style it. [DEMO](https://stackblitz.com/edit/angular-tis4gd)
