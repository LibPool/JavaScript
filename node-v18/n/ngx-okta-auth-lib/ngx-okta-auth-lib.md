# ngx-okta-auth-lib

> 标签: Angular, ng-okta-auth, ng6Okta, oktaAngular, oktaLibrary

## 简介

This is an okta Angular integeration Library to use with angular 6 and latest version. the token and auth api's/services are exposed in it to be use in any angular project with okta
