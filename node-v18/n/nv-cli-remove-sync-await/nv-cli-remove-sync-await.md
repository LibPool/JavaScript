# nv-cli-remove-sync-await

> 标签: JavaScript

## 简介

nv-cli-remove-sync-await ===================== - nv-cli-remove-sync-await is a simple cli-tool    - find AwaitExpression  AND for await...of  IN input - and Check along their ancestors func/method/lambda  - IF is NOT async , REMOVE await
