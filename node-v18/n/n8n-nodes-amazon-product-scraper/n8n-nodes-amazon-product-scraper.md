# n8n-nodes-amazon-product-scraper

> 标签: amazon, amazon-scraper, apify, asin, ecommerce, n8n, n8n-community-node-package, n8n-nodes, price-tracking, product-data, reviews

## 简介

n8n community node for the Apify Amazon Product Scraper - scrape Amazon products by search or URL with no API key. Get titles, live prices, ratings, review counts, ASIN, seller, brand, Prime status and stock.
