# nodejs-mobile

> 标签: bridge, java, javascript, mobile, node

## 简介

Biblioteca simples para comunicação bidirecional entre Node.js e Java via stdin/stdout, com suporte a mensagens de texto e JSON.

- npm 页面：https://www.npmjs.com/package/nodejs-mobile
