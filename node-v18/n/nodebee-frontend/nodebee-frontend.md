# nodebee-frontend

> 标签: display, ecobee, frontend, logging, mysql, node, nodejs

## 简介

A frontend for data logged by [NodeBee](https://github.com/netbymatt/nodebee). The data is plotted using [Plotly](https://github.com/plotly/plotly.js/).
