# n8n-nodes-przypominamy

> 标签: 2fa sms, api sms polska, bramka sms, n8n, n8n-community-node-package, otp sms, przypominamy, sms, sms api, sms polska, wysylka sms

## 简介

Węzeł n8n dla API SMS przypominamy.com — wysyłka SMS i wiadomości głosowych, kontakty, grupy, czarna lista, raporty oraz trigger webhooków ze statusem doręczenia. Polska bramka SMS, REST, webhooki HMAC.
