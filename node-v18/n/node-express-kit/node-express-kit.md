# node-express-kit

> 标签: authentication, boilerplate, express, jwt, mongodb, mvc, nodejs, starter-kit

## 简介

A simple and ready-to-use Express.js starter kit with MongoDB, JWT authentication, password reset, and proper folder structure using the MVC pattern.
