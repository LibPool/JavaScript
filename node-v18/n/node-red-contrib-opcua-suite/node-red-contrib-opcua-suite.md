# node-red-contrib-opcua-suite

> 标签: automation, industrial, iot, mqtt, node-red, opc-ua, opcua, opcua-pubsub, pubsub, uadp

## 简介

A modern OPC UA suite for Node-RED — Client/Server plus OPC UA PubSub (UDP-UADP / MQTT) with shared connections, batch operations, drag-and-drop certificates, and a clean msg-driven API
