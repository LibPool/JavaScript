# nuxt-mongo

> 标签: mongo, mongoDB, nuxt, nuxt layer

## 简介

The module will expose **dbClient** variable which contains your mongo client connection. It will be available globally without import. Based on [Nuxt3 Layers](https://nuxt.com/docs/getting-started/layers)
