# n8n-nodes-smartrecruiters-job-scraper

> 标签: apify, n8n, n8n-community-node-package, n8n-nodes, scraping

## 简介

Scrape job postings from any SmartRecruiters-powered company board via the public API. Get title, location, seniority, remote_type, department, employment_type, descriptions, and parse_confidence. Multi-company batch, keyword filters, zero auth, zero prox
