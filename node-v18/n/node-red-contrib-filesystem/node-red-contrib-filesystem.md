# node-red-contrib-filesystem

> 标签: JavaScript

## 简介

Node-RED nodes to work with filesystem. You can copy, move, link, delete files, create, list and remove folders and get info.

- 官网：https://gitlab.com/advantech-czech/node-red-contrib-filesystem
- 源码仓库：git+https://gitlab.com/advantech-czech/node-red-contrib-filesystem.git
- npm 页面：https://www.npmjs.com/package/node-red-contrib-filesystem
