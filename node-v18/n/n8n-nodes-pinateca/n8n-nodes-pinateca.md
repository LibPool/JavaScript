# n8n-nodes-pinateca

> 标签: kanban, n8n, n8n-community-node-package, pinateca, task-management

## 简介

Pinateca（カンバン・ガント・カレンダーを1つにしたタスク管理）の n8n ノード。カードの作成や更新に加えて、カードが動いた瞬間を受け取れます。

## 官网

- 官网：https://pinateca.com
- npm 页面：https://www.npmjs.com/package/n8n-nodes-pinateca

- 0.1.1

- npm registry：https://registry.npmjs.org/n8n-nodes-pinateca
- Node 要求：>=20.15
