# ncglobe

> 标签: geospatial, globe, hdf, modis, netcdf, satellite, sentinel-5p, tropomi, viewer

## 简介

Browser viewer for NetCDF/HDF files: folders, slices, satellite L2 swaths, composites and a rotating globe
