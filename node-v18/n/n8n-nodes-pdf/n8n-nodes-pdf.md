# n8n-nodes-pdf

> 标签: n8n-community-node-package

## 简介

n8n community node for local, in-process PDF operations (merge, split, rotate/reorder/delete pages, generate from template/Markdown/images, fill and read forms, watermark and page numbers, text/metadata/image extraction) with zero external services.
