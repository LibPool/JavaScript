# nav-type

> 标签: back, expand, forward, history, history expand, history 扩展, info, information, load, nav, nav info, nav type, navigation, navigation identity, navigation information, navigation type, push, replace, 导航, 导航信息, 导航标识, 导航类型, 扩展

## 简介

nav-type 对 History 进行了扩展，使其能标识出导航的类型（如：back、forward、push、replace、load等）并提供更多的导航信息
