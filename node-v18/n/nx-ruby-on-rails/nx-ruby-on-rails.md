# nx-ruby-on-rails

> 标签: bundler, docker, gemfile, monorepo, nx, nx-plugin, rails, ruby, ruby-on-rails

## 简介

Nx plugin for Ruby and Ruby on Rails: Gemfile-based project inference, path-gem project-graph edges, and Bundler analogues of prune-lockfile / copy-workspace-modules for folder-scoped Docker builds.
