# n8n-nodes-flashscore-scores-scraper

> 标签: apify, n8n, n8n-community-node-package, n8n-nodes, scraping

## 简介

Scrape Flashscore live scores, fixtures and results by sport, date or league. Returns home/away teams, score, status (live/finished/scheduled), kickoff time, league, country, match ID and URL. Supports soccer, tennis, basketball and 15+ more sports.
