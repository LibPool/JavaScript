# n8n-nodes-katto

> 标签: ai-video-clipper, captions, clips, katto, n8n, n8n-community-node-package, shorts, video, video-to-shorts

## 简介

n8n community node for Katto: turn long videos, podcasts and Twitch VODs into scored, captioned 9:16 clips.
