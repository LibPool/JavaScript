# nitro-popup

> 标签: 16, @nitro, angular, contextmenu, custom, dialog, ecosystem:angular, library, menu, modal, nitro, nitro-popup, plugin, popup, right-mouse-button, typescript

## 简介

Nitro Popup is an Angular Library Component for creating animated / non-animated Popups & even also for overriding Browser context menu with custom Menu also.
