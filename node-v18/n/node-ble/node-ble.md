# node-ble

> 标签: ble, bluetooth, bluetooth-le, bluetooth-low-energy, bluetooth-peripherals, bluez, bluez-dbus

## 简介

Bluetooth Low Energy (BLE) library written with pure Node.js (no bindings) - baked by Bluez via DBus
