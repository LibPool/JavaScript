# nestjs-infisical

> 标签: bootstrap, ci-cd, config, configuration, dotenv, environment-variables, http, infisical, nestjs, nodejs, secret-management, secrets, typescript

## 简介

CLI-free Infisical secrets loader for NestJS that fetches secrets via the HTTP API before application bootstrap and injects them into process.env.
