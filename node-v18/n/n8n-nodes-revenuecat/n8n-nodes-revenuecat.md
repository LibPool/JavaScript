# n8n-nodes-revenuecat

> 标签: android, in-app-purchases, ios, mobile, monetization, n8n, n8n-community-node-package, payments, revenue, revenuecat, subscriptions

## 简介

A comprehensive n8n community node for RevenueCat providing 11 resources and 40+ operations for in-app subscription management. Includes subscriber management, entitlements, products, offerings, packages, purchases, analytics, and webhook triggers.
