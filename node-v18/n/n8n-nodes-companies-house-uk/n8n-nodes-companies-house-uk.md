# n8n-nodes-companies-house-uk

> 标签: apify, n8n, n8n-community-node-package, n8n-nodes, scraping

## 简介

Search UK companies by name or number via the official Companies House API. Returns company number, name, status, type, incorporation and cessation dates, and full registered address. Optional officers/directors enrichment. No proxy. Free API key required
