# nemean-theme

> 标签: JavaScript

## 简介

统一样式管理库，包括两部分内容： 1. `Ant Design`中暴露出来的允许自定义的`LESS`变量。 2. 没有提供自定义变量接口的，通过外置`LESS`文件来覆盖。
