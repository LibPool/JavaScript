> 标签: angular, angular-material, component, country-code, dial-code, form-control, global, input, international, libphonenumber, material, mobile, ngx, phone, reactive-forms, telephone, typescript, validation

## 简介

A comprehensive Angular library for international phone number input with country selection, validation using Google's libphonenumber, auto-detection, and Material Design integration.
