> 标签: apify, n8n, n8n-community-node-package, n8n-nodes, scraping

## 简介

Scrape job postings from Fortune-500 companies running SmartRecruiters — Visa, Tesla, Bosch, McDonald's — via the official public API. Returns title, location, seniority, remote_type, department, and parse_confidence per posting. Zero auth, zero proxy, ze
