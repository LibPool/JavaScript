# nodeflare-agentkit

> 标签: action-provider, agent, agentkit, ai-agents, blockchain, coinbase, coinbase-agentkit, ethereum, evm, multichain, nodeflare, onchain, rpc, web3

## 简介

Coinbase AgentKit action provider for NodeFlare — read on-chain data across 23 EVM chains (incl. young chains like Robinhood, Plasma, Ink) through one provider, addressed by chain name. No per-chain RPC setup.
