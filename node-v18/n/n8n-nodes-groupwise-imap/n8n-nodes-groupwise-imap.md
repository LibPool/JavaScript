# n8n-nodes-groupwise-imap

> 标签: draft, email, groupwise, imap, micro-focus, n8n, n8n-community-node-package, opentext

## 简介

n8n community node for Micro Focus / OpenText GroupWise IMAP — create drafts, list mailboxes, fetch, move & delete emails with built-in retry logic and GroupWise-specific compatibility fixes.
