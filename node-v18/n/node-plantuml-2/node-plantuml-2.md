# node-plantuml-2

> 标签: diagram, diagram-generator, markdown, plantuml, png, svg, uml

## 简介

Node.js PlantUML renderer with Java backend. Multiple output formats (PNG, SVG, EPS, ASCII, Unicode) with full UTF-8 support
