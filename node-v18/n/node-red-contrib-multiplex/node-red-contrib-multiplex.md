# node-red-contrib-multiplex

> 标签: JavaScript

## 简介

Sends new msgs for every element in msg array. Built on top of node-red-contrib-splitter, but creates a new msg object for every msg send (I has some problems with splitter in async operations ... msg was overrriten).
