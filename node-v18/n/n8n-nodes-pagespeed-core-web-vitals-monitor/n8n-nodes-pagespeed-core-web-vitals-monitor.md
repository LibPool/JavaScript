# n8n-nodes-pagespeed-core-web-vitals-monitor

## 简介

n8n community node: bulk Google PageSpeed Insights + real-user Core Web Vitals (LCP, INP, CLS) for many URLs or a sitemap, with trends, top fixes and regression alerts, via the Apify PageSpeed & Core Web Vitals Monitor Actor.
