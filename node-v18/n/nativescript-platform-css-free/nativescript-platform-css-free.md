# nativescript-platform-css-free

> 标签: NativeScript, android, css, ios, notch, platform, softnav

## 简介

A NativeScript plugin to deal with Declarative UI and Platform CSS. Since the original plugin requires a subscription now, this plugin is my attempt to maintain it to the point where it does not break.
