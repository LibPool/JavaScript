# node-telegram-bot-emtbus

> 标签: bot, bus, emt, node, telegram

## 简介

Telegram bot that runs in node.js. The purpose of the bot is to reply to inline requests and return bus arrival estimations to a certain bus stop in Madrid, Spain.
