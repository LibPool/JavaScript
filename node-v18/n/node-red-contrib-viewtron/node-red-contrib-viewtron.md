# node-red-contrib-viewtron

> 标签: access control, alpr, anpr, camera api, cctv, face detection, gate access, human detection, intrusion detection, ip camera, license plate, license plate recognition, lpr, mqtt, ndaa, node-red, people counting, person detection, security camera, surveillance, vehicle detection, viewtron

## 简介

Receive AI detection events from Viewtron IP cameras — license plate recognition (LPR/ALPR), human detection, vehicle detection, face detection. On-camera AI, no cloud required.
