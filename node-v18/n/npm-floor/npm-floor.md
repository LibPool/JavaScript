# npm-floor

> 标签: baseline, bots, download-count, download-stats, downloads, floor, mirrors, npm, scanners, statistics, supply-chain, version-pumping

## 简介

How many downloads would your package get if nobody used it? Tells you that number (the floor: mirrors, CI caches, security scanners) and whether your actual count stands out from it. — 利用者ゼロでも付く DL は何件か。自分のパッケージはそれを超えているか。
