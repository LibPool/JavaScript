# nestjs-smsir

> 标签: nest, nestjs, nestjs-module, otp, sms, sms-gateway, sms.ir, smsir, verification-code

## 简介

NestJS integration for sms.ir - Dependency Injection, forRoot/forRootAsync configuration, and a zero-dependency client for the sms.ir REST API.
