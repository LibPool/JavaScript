# ngx-advanced-toast

> 标签: a11y, accessibility, alert, angular, angular21, dialog, notification, signals, snackbar, standalone, toast

## 简介

Advanced Angular 21 toast notifications built on the native <dialog> element. Signals-first, zero RxJS, CSS-only animations, fully accessible.
