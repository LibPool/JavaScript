# npm-metadata-mirror

> 标签: metadata, mirror, npm

## 简介

Monitor NPM changes and keep an up-to-date mirror of modules metadata (not the whole data, i.e. including attachments info, but not attachments body)

## 官网

- 源码仓库：git://github.com/naholyr/node-npm-metadata-mirror.git
- npm 页面：https://www.npmjs.com/package/npm-metadata-mirror
