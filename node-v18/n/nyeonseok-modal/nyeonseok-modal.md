# nyeonseok-modal

> 标签: JavaScript

## 简介

React 프로젝트에서 **간단하게 모달**을 띄울 수 있는 라이브러리입니다.   CSS, SVG 등 필요한 리소스는 모달 내부에서 자동으로 처리되므로, **Modal 컴포넌트만 import**하면 바로 사용 가능합니다.
