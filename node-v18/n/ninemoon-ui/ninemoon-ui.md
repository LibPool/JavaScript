# ninemoon-ui

> 标签: UI, vue3

## 简介

淘钉钉商城UI组件 ## 引入方式 ### **`css`**: - 首先引入dist/style.css ### **`js`**: - 全局引入，直接import Lib from 'tdd-ui',并且use(Lib) - 按需引入，引入需要的组件并且component绑定 ## VSCODE显示支持 - tsconfig.json的参数compilerOptions.types:["./node_modules/tdd-ui/dist/index.d.ts"]
