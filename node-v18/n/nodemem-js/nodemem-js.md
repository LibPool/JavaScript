# nodemem-js

> 标签: chat agent, chatbot, cosine similarity, embedding, embeddings, in-memory, inmemory, javascript, langmem, large language model, llm, memory, node.js, nodejs, rag, retrieval augmented generation, semantic search, similarity search, vector database, vector store

## 简介

Inspired by LangMem, nodemem-js is a fast, in-memory vector database for Node.js, designed for efficient similarity search of vector embeddings. Perfect for building chat agent memory and semantic retrieval systems.
