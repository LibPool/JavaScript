# normalize-stringify-length

> 标签: ETL, JSON, length, maxlen, normalize, parser, serialize, stringify

## 简介

Stringify an object to JSON, shortening each property such that the total length of the string output is less than an upper bound. Takes all syntax characters and escapes into account. Always produces valid JSON. No dependencies.
