# n8n-nodes-trustfetch

> 标签: n8n-community-node-package, payments, prompt-injection, security, web-fetch, x402

## 简介

Prompt-injection scanning and clean webpage fetching for AI agents via TrustFetch, paid per call in USDC on Base through x402 -- no API keys.
