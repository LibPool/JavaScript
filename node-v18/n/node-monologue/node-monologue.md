# node-monologue

> 标签: EventEmitter, emitter, event, eventing, listener, monologue, node-monologue, observer, postal, pub, pub/sub, publisher, sub

## 简介

EventEmitter replacement with AMQP-style bindings and other advanced features. Compatible with postal.js's API.
