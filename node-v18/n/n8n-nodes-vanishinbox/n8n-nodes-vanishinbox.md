# n8n-nodes-vanishinbox

> 标签: disposable-email, email, n8n-community-node-package, otp, temp-email, vanishinbox

## 简介

n8n community node for VanishInbox — generate disposable email inboxes and catch inbound mail (including OTPs) as an n8n trigger.
