# ngx-easy-theme-switcher

> 标签: angular, angular-library, bootstrap-icons, dark, dark theme, dark-mode, fontawesome, icon, light, light-mode, material-icons, ng, service, theme, theme-switcher, themes, toggle, typescript, utils

## 简介

A lightweight Angular service and component for seamless dark/light theme switching. Supports FontAwesome, Material Icons, Bootstrap Icons, custom SVG icons, and popular icon fonts out of the box. Persistent theme selection with localStorage.
