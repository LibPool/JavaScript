# ng-network-loader

> 标签: angular, angular network loader, http network call, loading display, loading icon, network loader, spinner

## 简介

ng-network-loader displays a loading icon on a part of the screen to give the user an idea that the app is not broken but responding to a request.
The loading icon disappears at the end of all network request.
