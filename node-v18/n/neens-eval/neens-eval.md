# neens-eval

> 标签: agent, ci, evals, evaluation, gate, llm, neens, opentelemetry, pre-prod, regression-testing

## 简介

Neens pre-prod evaluation runner — the CI one-liner (PULL/PUSH) with gate-as-code, for TypeScript/Node CI. TypeScript parity port of the Python neens-eval SDK.
