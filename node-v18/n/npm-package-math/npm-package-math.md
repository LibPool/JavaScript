# npm-package-math

> 标签: core, helper, library, math, mathematics, package, template, tutorial

## 简介

This is a simple npm package math template that exports a single function called add, which takes two arguments a and b and returns their sum. The function can be used in any Node.js project by including it as a dependency and importing it in the project
