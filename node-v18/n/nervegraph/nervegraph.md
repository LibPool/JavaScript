# nervegraph

> 标签: architecture, cli, code-visualization, codebase, css, dependency-graph, go, graph, html, java, javascript, liquid, monorepo, php, python, ruby, rust, shopify, static-analysis, theme, typescript, visualization, vue

## 简介

Obsidian Graph View, but for source code — scan a JS/TS, Vue/Svelte/Astro, HTML/CSS, Python, Ruby, Rust, Go, PHP, Java/Kotlin, C/C++ or Shopify Liquid project into a dependency graph and browse it interactively.
