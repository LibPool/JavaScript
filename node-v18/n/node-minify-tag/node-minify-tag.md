# node-minify-tag

> 标签: CSS minifier, CSSO, Clean-css, GCC, Google Closure Compiler, Javascript minifier, Sqwish, UglifyJS2, YUI Compressor

## 简介

You can use this code to minify your css and js code between begin and end comment tags in a given html file.
