# npm-login-yubikey

> 标签: 2fa, adduser, authentication, automated, automation, cli, console, headless, login, noninteractive, npm, security, terminal, yubikey

## 简介

Automated or semi-automated NPM login with a YubiKey as 2FA, simple, no dependencies, auditable.
