> 标签: analytics, app-router, cls, core-web-vitals, inp, lcp, nextjs, open-source-analytics, pages-router, performance-monitoring, react, real-user-monitoring, rum, web-vitals

## 简介

A client-side collector for the Blazity Next.js CWV Monitor. Lightweight React SDK for capturing Core Web Vitals and custom events with automatic route normalization and privacy-first session handling.
