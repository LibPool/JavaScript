# noxen-css

> 标签: accessibility, animations, antigravity, components, css, dark-mode, design-system, framework, grid, intent-api, theming, tokens, ui

## 简介

The world's first intent-based CSS framework. Design intent, not class names. 7 themes, Antigravity Engine, Auto-ARIA, AI Palette, Cross-platform tokens — all in 74KB.
