# n8n-nodes-split-message

> 标签: chunk, dividir, mensagem, message, n8n, n8n-community-node-package, ninelabs, split

## 简介

Nó da comunidade n8n que divide uma mensagem longa em um array de mensagens menores respeitando um limite máximo, sem cortar palavras. Desenvolvido por zanini · ninelabs.
