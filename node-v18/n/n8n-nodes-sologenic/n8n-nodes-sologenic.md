# n8n-nodes-sologenic

> 标签: blockchain, cryptocurrency, dex, n8n, n8n-community-node-package, nft, solo, sologenic, tokenized-assets, trading, xrp, xrpl

## 简介

A comprehensive n8n community node for Sologenic ecosystem on XRPL providing 12 resources and 40+ operations for account management, SOLO token operations, DEX trading, market data, NFT marketplace, and staking capabilities.
