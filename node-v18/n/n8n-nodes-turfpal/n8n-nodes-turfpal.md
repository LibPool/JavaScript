# n8n-nodes-turfpal

> 标签: automation, n8n, n8n-community-node-package, turf-management, turfpal

## 简介

n8n community node for Turfpal — turf management platform. Manage tasks, equipment, members, sites, observations, inventory, workflows, reports, and emissions.
