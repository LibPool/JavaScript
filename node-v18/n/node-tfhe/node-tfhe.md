# node-tfhe

> 标签: cryptography, encryption, fhe, fully, homomorphic

## 简介

TFHE-rs is a fully homomorphic encryption (FHE) library that implements Zama's variant of TFHE.

## 官网

- 官网：https://zama.org/
- 源码仓库：git+https://github.com/zama-ai/tfhe-rs.git
- npm 页面：https://www.npmjs.com/package/node-tfhe
