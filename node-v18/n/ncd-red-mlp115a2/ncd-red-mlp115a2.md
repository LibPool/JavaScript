# ncd-red-mlp115a2

> 标签: MLP115A2, i2c, iot-training-controller, ncd, pressure-sensor

## 简介

This library provides a class for the MLP115A2 series, it relies on the `ncd-red-comm` library for communication, and includes a node-red node for MLP115A2. The MPL115A2 pressure sensor’s small form factor, low power capability, precision, and digital out
