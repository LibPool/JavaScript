# n8n-nodes-aloware

> 标签: aloware, calls, contact-center, cpaas, n8n-community-node-package, sms, trigger, two-legged-call, voice, webhook

## 简介

n8n community node for Aloware — trigger on call, SMS and AloAi events; send SMS/MMS, place two-legged calls, manage contacts, sequences and power dialer lists via the Aloware API.
