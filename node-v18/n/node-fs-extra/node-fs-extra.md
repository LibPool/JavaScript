# node-fs-extra

> 标签: copy, create, delete, directory, extra, file, file system, fs, json, mkdir, mkdirp, mkdirs, output, read, recursive, remove, text, touch, write

## 简介

fs-extra contains methods that aren't included in the vanilla Node.js fs package. Such as mkdir -p, cp -r, and rm -rf.
