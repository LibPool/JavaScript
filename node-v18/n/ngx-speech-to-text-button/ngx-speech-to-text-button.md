# ngx-speech-to-text-button

> 标签: accessibility, angular, dictation, reactive-forms, speech-recognition, speech-to-text, voice-input, web-speech-api

## 简介

A standalone Angular component that adds voice dictation (Web Speech API) to any ReactiveForms control, with built-in undo history and mobile-safe auto-restart. No third-party UI library required.
