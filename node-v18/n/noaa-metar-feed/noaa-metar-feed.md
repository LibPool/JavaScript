# noaa-metar-feed

> 标签: Airfields, ICAO, METAR, NOAA, Weather

## 简介

Pulls the latest coded METAR collectives from NOAA as described here http://www.nws.noaa.gov/tg/datahelp.php and decodes to JSON format.
