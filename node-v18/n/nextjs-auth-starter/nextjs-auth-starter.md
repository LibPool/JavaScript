> 标签: authentication, better-auth, cli, drizzle-orm, email-verification, google-auth, mailjet, nextjs, oauth, password-reset, postgresql, setup-tool, shadcn-ui, starter, typescript

## 简介

CLI tool to set up Next.js authentication with better-auth, PostgreSQL, and Drizzle ORM. Usage: npx nextjs-auth-starter init
