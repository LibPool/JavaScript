# nameai-sdk

> 标签: api, api-client, client, domain-names, domain-search, domains, mcp, name.ai, nameai, registrar, sdk, tld, whois

## 简介

Official JavaScript SDK for the Name.ai public API: domain search/availability, WHOIS lookup, TLD registration pricing and registry requirements, marketplace listings with cursor pagination, and batched reads.
