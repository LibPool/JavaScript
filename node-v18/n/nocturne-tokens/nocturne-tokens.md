# nocturne-tokens

> 标签: css-variables, cyberpunk, design-system, design-tokens, nocturne

## 简介

Design tokens for the Nocturne design system: colors, typography, spacing, radii, shadows and motion as CSS variables, SCSS, JSON and typed JS.
