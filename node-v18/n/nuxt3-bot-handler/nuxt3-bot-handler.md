# nuxt3-bot-handler

> 标签: bot, crawler, dns, middleware, nuxt, nuxt3, protection, seo, user-agent

## 简介

🛡️ Nuxt 3 middleware to block suspicious bots, protect SEO crawlers with reverse DNS checks, and enforce User-Agent rules.
