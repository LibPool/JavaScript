# ngx-tablize

> 标签: angular, angular-material, dynamic-table, mat-table, ngx-tablize, table

## 简介

ngx-tablize est une bibliothèque Angular permettant de créer facilement des tables dynamiques basées sur Angular Material avec une configuration JSON flexible.
