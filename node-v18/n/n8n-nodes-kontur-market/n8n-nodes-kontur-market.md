# n8n-nodes-kontur-market

> 标签: n8n-community-node-package

## 简介

Нода для интеграции Контур.Маркет с платформой автоматизации n8n. Позволяет получать данные из Маркета о товарах, остатках, продажах, клиентах и акциях, а также управлять товарами и остатками.
