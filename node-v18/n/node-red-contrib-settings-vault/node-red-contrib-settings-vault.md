# node-red-contrib-settings-vault

> 标签: centralized, config, configuration, credentials, encrypted, environment, multi-environment, node-red, node-red-contrib, secrets, settings, vault

## 简介

Centralized settings management for Node-RED. Store credentials, API endpoints, database settings, and any other configuration values in one encrypted location with no external dependencies. Perfect for managing multiple environments.
