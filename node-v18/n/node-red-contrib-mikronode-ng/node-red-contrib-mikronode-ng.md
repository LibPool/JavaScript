# node-red-contrib-mikronode-ng

> 标签: mikronode, mikrotik, node-red, node-red-contrib, routeros

## 简介

Node-RED node for monitoring MikroTik RouterOS devices (traffic, wifi registration, routes, OVPN clients) via mikronode-ng
