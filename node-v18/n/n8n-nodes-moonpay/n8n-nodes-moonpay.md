# n8n-nodes-moonpay

> 标签: blockchain, crypto, cryptocurrency, fiat, moonpay, n8n, n8n-community-node-package, off-ramp, on-ramp, payment, web3

## 简介

A comprehensive n8n community node for MoonPay crypto payment infrastructure providing 8 resources and 20+ operations for fiat-to-crypto on-ramps, crypto-to-fiat off-ramps, quotes, transactions, and customer management.
