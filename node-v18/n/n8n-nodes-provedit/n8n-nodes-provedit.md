# n8n-nodes-provedit

> 标签: agent, ai, audit, compliance, governance, n8n-community-node-package, policy, provedit

## 简介

n8n community node for Provedit. Record AI tool invocations to a tamper-evident chain, check policy decisions, and gate workflows on allow/require_approval/deny.
