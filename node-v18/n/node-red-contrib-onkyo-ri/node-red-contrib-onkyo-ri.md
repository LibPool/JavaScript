# node-red-contrib-onkyo-ri

> 标签: node-red, onkyo, onkyo-ri, onkyo-rpi

## 简介

Wrapper for onkyo-rpi which is inspired on ahaack/onkyo-rpi and lets you control almost any Onkyo Ri capable device, that's connected through a custom build cable (2.5mm mono jack plug, terminated by 10k resistor, tip=data, shield=gnd) connected to the Ra
