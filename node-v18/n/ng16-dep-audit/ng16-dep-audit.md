# ng16-dep-audit

> 标签: 16, angular, ivy, ng, ngcc, upgrade, viewengine

## 简介

Audit your dependencies to see if you can upgrade to Angular 16. You can only do that if your dependencies support ivy engine. Since ngcc removal in Angular 16, view engine dependencies are no longer supported
