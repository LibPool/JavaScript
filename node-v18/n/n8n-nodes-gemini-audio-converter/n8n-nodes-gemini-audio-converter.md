# n8n-nodes-gemini-audio-converter

> 标签: audio, converter, gemini, google, mp3, n8n, n8n-community-node, text-to-speech, tts

## 简介

Um nó n8n para converter áudio Base64 (PCM s16le 24kHz) da API Gemini TTS para o formato MP3.
