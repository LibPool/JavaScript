# n8n-nodes-saramin-jobs

> 标签: apify, n8n, n8n-community-node-package, n8n-nodes, scraping

## 简介

Collect Korean job postings from Saramin (saramin.co.kr): job title, company, location, career level, education, employment type, skill keywords, closing date and apply links. No login, keyword + page filters.

## 官网

- 官网：https://apify.com/bovi/saramin-jobs
- npm 页面：https://www.npmjs.com/package/n8n-nodes-saramin-jobs
