# n8n-nodes-attio-triggers

> 标签: attio, crm, n8n-community-node-package, trigger, webhook

## 简介

n8n community node with an Attio Trigger for reacting instantly to Attio CRM events (records, lists, list entries, notes, tasks, comments, call recordings) via Attio's webhooks API.
