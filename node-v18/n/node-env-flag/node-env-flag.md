# node-env-flag

> 标签: boolean, booleans, env, false, flag, flags, process, true

## 简介

Little util function for simpler extracting Boolean values from ENV-variables in Node.js, i.e. true values (true, TRUE, 1) vs. false values (false, FALSE, 0).
