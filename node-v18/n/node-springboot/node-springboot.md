# node-springboot

> 标签: annotations, api, decorators, dependency-injection, entity, framework, jpa, mysql, nodejs, orm, rate-limiting, relationship-mapping, repository-pattern, rest, security, spring, spring-boot, typescript

## 简介

A Node.js framework that mimics Spring Boot's structure using TypeScript decorators. Features JPA-like ORM, dependency injection, REST controllers, relationship mappings, rate limiting, and security features.
