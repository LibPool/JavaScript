# nepal-pay

> 标签: epaisa, epayment, esewa, fintech, fonepay, gateway, khalti, nepal, nextjs, payment, sdk, typescript

## 简介

Unified, type-safe Nepal payment gateway SDK for eSewa (ePaisa V2), Khalti (V2), and Fonepay. Works with Node.js, Bun, Next.js, and TypeScript.
