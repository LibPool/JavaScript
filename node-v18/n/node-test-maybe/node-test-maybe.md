# node-test-maybe

> 标签: assert, assertion, chai, check, create-by-yarn-tool, expect, jest, test, testing

## 简介

基於 Node.js 原生測試執行器（`node:test`）的非阻斷測試工具：讓某些測試「可以通過，也可以失敗」，且失敗時不影響整次執行的結束狀態（exit code）
