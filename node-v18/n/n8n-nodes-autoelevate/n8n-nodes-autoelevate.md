# n8n-nodes-autoelevate

> 标签: autoelevate, cyberfox, msp, n8n, n8n-community-node-package, pam, privilege-management

## 简介

n8n community node for the AutoElevate Partner API (beta): companies, computers, locations, elevation requests/events/sessions/rules, audit log, and per-company active-agent counts for billing. Reads by default; approve/deny are gated behind a credential
