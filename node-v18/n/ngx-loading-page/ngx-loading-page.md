# ngx-loading-page

> 标签: angular, angular loader, angular loading, angular preloader, angular spinner, angular ui loader, bootstrap loader, full page loader, loading, loading indicator, loading page, loading screen, ngx, ngx loader, ngx-loading-page, preloader

## 简介

A modern and customizable loading page component for Angular applications. Supports multiple loader styles, dynamic themes, background customization, and responsive card-based UI using Bootstrap.
