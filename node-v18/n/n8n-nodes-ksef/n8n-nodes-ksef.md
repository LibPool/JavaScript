# n8n-nodes-ksef

> 标签: e-faktura, invoice, ksef, n8n-community-node-package, poland

## 简介

n8n community node for Poland's KSeF (Krajowy System e-Faktur) e-invoicing API — query, download, and manage invoices with token or certificate authentication
