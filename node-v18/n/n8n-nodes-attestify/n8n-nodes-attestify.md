# n8n-nodes-attestify

> 标签: attestify, certificate, ceu, course, credential, n8n, n8n-community-node-package, verifiable, verifiable-certificates, verification, verify-page

## 简介

Issue verifiable certificates from n8n — each gets a permanent, tamper-evident public verify page (Ed25519-signed) anyone can check. Free Attestify API, no signup.
