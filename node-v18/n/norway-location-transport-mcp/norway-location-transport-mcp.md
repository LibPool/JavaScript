# norway-location-transport-mcp

> 标签: elevation, entur, geocoding, geonorge, kartverket, mcp, modelcontextprotocol, norway, public-transport

## 简介

MCP server for Norwegian public transport (Entur) and geospatial data (Kartverket): trips, departures, realtime, shared mobility, addresses, place names, elevation, coordinate transforms, and administrative lookups.
