# n8n-nodes-hazelchat

> 标签: enquiries, hazelchat, leads, n8n-community-node-package, website chat

## 简介

Hazelchat nodes for n8n: start a workflow when a visitor leaves an enquiry or asks something your Hazelchat website agent could not answer, find enquiries, and add answers to its draft.
