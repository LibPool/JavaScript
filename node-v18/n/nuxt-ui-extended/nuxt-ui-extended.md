# nuxt-ui-extended

> 标签: autoform, components, dialog, form, markdown, modal, nuxt, nuxt-module, nuxt-ui, shiki, ui, vue, zod

## 简介

Extended components for Nuxt UI: schema-driven AutoForm (Zod), programmatic dialogs (confirmation, inputs, selection) and Markdown rendering with Shiki highlighting
