# noober-mcp

> 标签: claude, ios, mcp, model-context-protocol, network-inspector, noober, qa, simulator, testing, websocket, xcode

## 简介

MCP server for iOS app testing — see inside your running app: network calls, WebSocket frames, logs, UserDefaults, screen layout, and API mocking. Works with Claude Code, Cursor, Codex, Windsurf.
