# ngx-dock-layout

> 标签: angular, dock, docking, drag-drop, layout, panel, resizable, signals, split, tabs

## 简介

Angular library for building resizable, dockable panel layouts with split panes, movable tabs, drag & drop, and undo/redo — driven by signals.
