# nuxt-i18n-micro-types

> 标签: JavaScript

## 简介

`nuxt-i18n-micro-types` provides TypeScript type definitions and interfaces for the `nuxt-i18n-micro` ecosystem. This package is designed to enhance type safety and developer experience when working with translations, locales, and routing in a Nuxt.js app
