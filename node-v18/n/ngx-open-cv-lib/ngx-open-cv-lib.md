# ngx-open-cv-lib

> 标签: JavaScript

## 简介

This is a library that integrates Angular v16+ with OpenCVJS, the Javascript port of the popular computer  vision library. It will allow you to load the library (with its WASM components) and use it in your application. The loading is done asynchrosnously
