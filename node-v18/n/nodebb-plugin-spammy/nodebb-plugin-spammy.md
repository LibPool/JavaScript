# nodebb-plugin-spammy

> 标签: email, filtering, gmail, nodebb, patterns, plugin, prevention, regex, registration, security, spam, wildcard

## 简介

NodeBB spam prevention plugin that blocks registrations where username matches email local-part and provides configurable pattern-based email filtering
