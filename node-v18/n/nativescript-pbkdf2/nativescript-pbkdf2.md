# nativescript-pbkdf2

> 标签: hash, kdf, nativescript, nativescript-pbkdf2, pbkdf2, salt

## 简介

This library provides the functionality of PBKDF2 with the ability to use any supported hashing algorithm returned from crypto.getHashes()
