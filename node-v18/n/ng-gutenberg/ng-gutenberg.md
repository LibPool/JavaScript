# ng-gutenberg

> 标签: angular, gutenberg, wordpress

## 简介

This library was generated with [Angular CLI](https://github.com/angular/angular-cli) version 8.0.3.   It is an Angular version of the [Wordpress Gutenberg Block Editor](https://wordpress.github.io/gutenberg/).   The packages uses the latest Gutenberg ver
