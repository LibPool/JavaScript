# npm-high-impact-cli

> 标签: high, impact, npm, popular

## 简介

Fetch the npm packages a user is a maintainer of and figure out which of them (if any) are considered high-impact

## 官网

- npm 页面：https://www.npmjs.com/package/npm-high-impact-cli

## 历史版本号

## 获取地址

- npm 安装：`npm install npm-high-impact-cli`
- npm registry：https://registry.npmjs.org/npm-high-impact-cli
- Node 要求：>=14.14
