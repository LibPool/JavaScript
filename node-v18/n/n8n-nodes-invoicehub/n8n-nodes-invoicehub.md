# n8n-nodes-invoicehub

> 标签: compliance, e-invoicing, en16931, factur-x, invoice, n8n, n8n-community-node-package, peppol, ubl, vat, xrechnung, zugferd

## 简介

n8n node for InvoiceHub — validate, generate, convert and read EU e-invoices (UBL 2.1, UN/CEFACT CII, XRechnung 3.0, Factur-X) against the official EN 16931 rules.
