# n8n-nodes-chainscope

> 标签: blockchain, multi-chain, n8n-community-node-package, payments, wallet, x402

## 简介

Multi-chain wallet and transaction intelligence (balances, activity, contract metadata, OFAC sanctions screening) via ChainScope, paid per call in USDC on Base through x402 -- no API keys.
