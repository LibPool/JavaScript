# noibu-nuxt-sourcemaps

> 标签: ecommerce-monitoring, error-tracking, noibu, nuxt, nuxt3, sourcemaps, vite

## 简介

Nuxt 3 (Vite) module and CLI to upload client sourcemaps to Noibu during nuxt build.

## 官网

- npm 页面：https://www.npmjs.com/package/noibu-nuxt-sourcemaps

## 历史版本号

- 0.2.0

## 获取地址

- npm 安装：`npm install noibu-nuxt-sourcemaps`
- npm registry：https://registry.npmjs.org/noibu-nuxt-sourcemaps
- Node 要求：>=18
