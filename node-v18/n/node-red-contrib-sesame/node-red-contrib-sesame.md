# node-red-contrib-sesame

> 标签: SESAME, node-red

## 简介

node-red-contrib-sesameは[Sesame API](https://doc.candyhouse.co/ja/SesameAPI)を使用するためのNode-REDノードです。 Sesame3/4に対応しています。
