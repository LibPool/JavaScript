# nopjs

> 标签: binding, framework, javascript, router

## 简介

NOPJS is a library for building web solutions that require speed in the development and execution. NOP wants to be simple and intuitive and enclose into the thing you need in a few instructions. Is lightweight and powerful scripting easy to use with bindi
