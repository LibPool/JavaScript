# npm-trusted-publisher

> 标签: automation, changelog, ci-cd, continuous-delivery, drop-in, github-actions, npm, npm-publish, oidc, provenance, publish, release, semver, trusted-publishing, workflow

## 简介

A zero-config CLI tool and GitHub Actions workflow for secure, automated npm publishing. Replaces NPM_TOKEN with OIDC, automatically syncs versions, updates changelogs, commits build artifacts, and enables provenance-backed releases.
