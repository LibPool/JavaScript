# nuxt-calendar

> 标签: calendar, database, events, i18n, ical, ics, nuxt, nuxt-module, nuxthub, scheduling, timezone, typescript

## 简介

A fully customizable, strongly-typed calendar module for Nuxt with i18n, timezone support, .ics export/import.
