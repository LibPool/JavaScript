# node-lifx-lan

> 标签: Home Automation, LIFX, Smart Bulb, Smart Home, Smart Light

## 简介

The node-lifx-lan is a Node.js module which allows you to communicate with the Wi-Fi LED smart light products "LIFX" using the LAN protocol.
