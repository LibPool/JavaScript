# n8n-nodes-hash

> 标签: blake2, checksum, crc32, fingerprint, hash, hashing, hmac, n8n-community-node-package, ripemd160, sha1, sha256

## 简介

Hash text, files and JSON in n8n with algorithms the built-in Crypto node does not offer, including SHA1, BLAKE2, RIPEMD-160, SM3 and CRC32, plus base64url output and optional salt and pepper.
