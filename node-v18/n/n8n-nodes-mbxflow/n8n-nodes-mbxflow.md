# n8n-nodes-mbxflow

> 标签: mbx flow, mbxflow, n8n, n8n-community-node-package, scheduling, social media

## 简介

MBX Flow nodes for n8n: save drafts, schedule posts to your connected social accounts, and start a workflow when a post is published or fails.
