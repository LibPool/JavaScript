# n8n-nodes-mqtt-rpc

> 标签: mqtt, mqtt-rpc, n8n-community-node-package, rpc

## 简介

The n8n-nodes-mqtt-rpc package, version 0.1.0, is a community-contributed node package for n8n, an extendable workflow automation tool. This package introduces functionality for MQTT RPC (Remote Procedure Call) within n8n, allowing users to establish MQTT
