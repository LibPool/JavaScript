# ng-draggable-tree

> 标签: angular, cdk-tree, checkbox, draggable, lazy-load, tree

## 简介

基于 @angular/cdk/tree 的 Angular 树组件：扁平化渲染、三态复选框、懒加载、拖拽排序与实时过滤
