# ngx-kel-agent

> 标签: amateur radio, angular, ham radio, hamlib, wsjtx

## 简介

This is a client library for Angular applications to integrate with [`kel-agent`](https://github.com/k0swe/kel-agent). It provides an Angular service that creates and manages the websocket connection.
