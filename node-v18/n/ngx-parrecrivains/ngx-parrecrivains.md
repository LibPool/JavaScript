# ngx-parrecrivains

> 标签: angular, angular-library, cree, français, google-docs, i18n, isbn, literary, manuscript, pdf, quebec, reading, validator

## 简介

Angular library for the literary industry — manuscript reader, word count pipes, reading time estimation, ISBN validator (fr/en/cr), i18n and PDF/Google Docs support.
