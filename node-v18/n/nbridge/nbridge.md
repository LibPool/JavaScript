# nbridge

> 标签: android, bridge, hybrid, iframe, ios, native, postmessage, react, webview, wkwebview

## 简介

Type-safe real-time bridge between web apps and native Android/iOS WebViews or iframes. Bring-your-own-validator via Standard Schema.
