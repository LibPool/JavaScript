# n8n-nodes-agendavet

> 标签: agenda, agendavet, clinica, n8n, n8n-community-node-package, veterinaria, veterinario, whatsapp

## 简介

Nodes e tools do Agenda Vet para o n8n: agenda veterinária (doutores, horários livres, agendamentos) e envio de mensagens no WhatsApp da clínica, prontos para agentes de IA.
