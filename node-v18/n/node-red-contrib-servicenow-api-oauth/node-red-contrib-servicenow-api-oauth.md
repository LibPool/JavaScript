# node-red-contrib-servicenow-api-oauth

> 标签: attachment, file-upload, node-red, oauth2, service-now, servicenow

## 简介

Node-RED nodes for ServiceNow Table API and Attachment API with OAuth 2.0 authentication. Provides CRUD operations for tables and file attachment management (upload, download, metadata, delete).
