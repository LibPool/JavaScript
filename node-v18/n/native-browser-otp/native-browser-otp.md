# native-browser-otp

> 标签: 2fa, 2fa-authentication, authentication, browser, browser-security, cryptography, hotp, lightweight, native, one-time-password, otp, security, totp, two-factor, web-crypto, web-security

## 简介

Lightweight library for generating TOTP and HOTP codes using browser's native Web Cryptography API. Perfect for implementing two-factor authentication (2FA) in web applications.
