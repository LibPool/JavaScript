# nexus-ppfl

> 标签: differential-privacy, edge-ml, federated-learning, libp2p, onnxruntime, privacy-preserving, secure-aggregation

## 简介

Privacy-Preserving Federated Learning engine native to Node.js - convenience package re-exporting @nexus-ppfl/crypto, @nexus-ppfl/network, and @nexus-ppfl/ml-engine under one install.
