# nexus-gateway

> 标签: api-gateway, gateway, health-check, http, https, load-balancer, load-balancing, nodejs, proxy, rate-limiter, reverse-proxy, tls, zero-dependency

## 简介

Zero-dependency reverse proxy / API gateway for Node.js — load balancing, health checks, rate limiting, TLS, auth, WAL, and a live dashboard. Usable as a CLI or embedded via a programmatic API.
