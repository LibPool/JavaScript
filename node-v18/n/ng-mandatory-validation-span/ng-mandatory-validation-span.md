# ng-mandatory-validation-span

> 标签: angular, angular-cli, codemod, developer-tool, forms, maxlength-validation, reactive-forms, required-validation, template-transformer, validation, validation-spans

## 简介

Zero-dependency Angular CLI tool and library to automatically inject reactive form mandatory and maxlength validation spans across Angular 8 to 19+ component templates.
