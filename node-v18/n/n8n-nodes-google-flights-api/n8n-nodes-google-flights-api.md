# n8n-nodes-google-flights-api

> 标签: ai-tool, airfare, airline-tickets, apify, flight-prices, flight-search, flights, google-flights, n8n, n8n-community-node-package, n8n-nodes, travel

## 简介

Search flights and fares by route and date, returning airlines, times, durations, stops, and prices. Apify-backed n8n community node, pay-per-result, and usable as an AI agent tool.
