# n8n-nodes-mondaycom

> 标签: automation, boards, columns, graphql, groups, items, monday, monday.com, n8n, n8n-community-node-package, project-management, teams, work-os, workflow, workspaces

## 简介

A comprehensive n8n community node for Monday.com providing 16 resource categories and 100+ operations for board, item, column, group, workspace, user, team, and document management. Includes webhook triggers and full GraphQL API support.
