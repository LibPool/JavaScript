# node-merge-images

> 标签: combine-images, concat-images, image-composite, image-grid, image-layout, imagemagick, join-images, merge-images

## 简介

Merge multiple images into one with ImageMagick. Supports vertical/horizontal merging, custom spacing, free-form positioning, and grid layouts.
