# ngx-stacker

> 标签: JavaScript

## 简介

Una direttiva Angular 18+ ultra-leggera per gestire layout Flexbox utilizzando i Signal nativi.  Nessuna classe CSS chilometrica, nessuna dipendenza esterna, solo puro HTML reattivo.
