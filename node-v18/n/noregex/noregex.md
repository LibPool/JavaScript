# noregex

> 标签: regex, regexp

## 简介

noRegex is a lightweight javascript library with no dependencies, made for those who don't want to blow their mind with regex syntax.   noRegex do not replace regex, it only simplify basic needs to validate what's inside a string, but do not test a patte
