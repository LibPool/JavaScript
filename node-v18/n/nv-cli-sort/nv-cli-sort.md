# nv-cli-sort

> 标签: JavaScript

## 简介

nv-cli-sort ========== - cli tool, generate a simple-sort-code for variables IF variable-count <=6 - the generated  stupid sort-function is  5~10 times faster  than built-in  sort  IF  elements <= 8 - suitable for params sort
