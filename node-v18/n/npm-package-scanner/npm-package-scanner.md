# npm-package-scanner

> 标签: BSD, ISC, MIT, javascript, js, licence, license, license-scanner, lisence, node, npm, package, package-scanner, package.json, scanner

## 简介

Scan npm packages and get their package.json, get license and other information, indicate the possible impact on the project.
