> 标签: ai-agents, junctionary-pulse, market-data, n8n-community-node-package, stock-briefings

## 简介

n8n nodes for Junctionary Pulse — finished per-ticker stock briefings for AI agents. Pull briefings, history, trends and alerts; trigger workflows on new briefings via signed webhooks.
