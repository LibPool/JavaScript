# ngx-pos-print

> 标签: a4, angular, bluetooth, document, esc/pos, escpos, point-of-sale, pos, print, print-dialog, printer, receipt, silent-printing, standalone, thermal, web-bluetooth, webusb

## 简介

Angular library for POS and document printing, thermal receipts over Bluetooth, Network, USB or a local agent, and A4 documents printed silently through the host's own drivers.
