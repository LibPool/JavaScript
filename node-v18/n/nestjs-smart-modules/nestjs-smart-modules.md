# nestjs-smart-modules

> 标签: composable, config, configurable, configuration, dependency-injection, modules, nestjs, smart, type-safe, typescript

## 简介

A lightweight, type-safe library that simplifies NestJS module configuration. Build composable applications with centralized configuration and zero boilerplate.
