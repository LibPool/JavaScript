# n8n-nodes-smb-pro

> 标签: ai-agent, ai-tool, cifs, n8n, n8n-community-node-package, ntlmv2, samba, smb, smb2, windows-share

## 简介

n8n community node for SMB2/SMB3 shares with NTLMv2 support. Usable as an AI Agent tool. Proper n8n credentials, list (recursive, parallel, permission-tolerant)/upload/download/delete/move/mkdir operations, retry logic and clear errors.
