# npm-badge-maker

> 标签: badge, badges, cli, developer-tools, devtools, documentation, generator, github, markdown, npm, open-source, readme, shields, shields.io

## 简介

Generate README badges for npm packages. One command, instant shields.io badges for version, downloads, license, and node version.
