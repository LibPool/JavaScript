# noop-stream

> 标签: blank, dev, devnull, drain, empty, fixture, noop, null, readable, readablestream, stream, test, testing, writable, writablestream

## 简介

Create a readable Node.js stream that produces no data (or optionally blank data) or a writable stream that discards data
