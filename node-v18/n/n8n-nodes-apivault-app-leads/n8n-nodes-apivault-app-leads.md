# n8n-nodes-apivault-app-leads

## 简介

n8n community node for App Developer Leads — find app & extension developer leads (company, website, email, phone) from Google Play, App Store, Chrome, Firefox, Microsoft Store and VS Code Marketplace. B2B prospecting, no login. Pay-as-you-go via Apify.
