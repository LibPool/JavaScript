# ngx-np-datepicker

> 标签: angular, angular datepicker, angular nepali datepicker, bikram sambat, bs datepicker, datepicker, nepali bs datepicker, nepali calendar, nepali datepicker

## 简介

A lightweight and customizable Nepali (Bikram Sambat) date picker for Angular with support for reactive forms, date conversion, and modern UI customization.
