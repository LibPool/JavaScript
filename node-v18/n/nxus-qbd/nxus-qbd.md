> 标签: accounting, api, bun, node, nxus, qbd, quickbooks, quickbooks-desktop, sdk

## 简介

Official TypeScript SDK for the Nxus QuickBooks Desktop API. Runs on Node.js 18+ and Bun 1.0+.
