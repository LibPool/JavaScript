# n8n-nodes-wafixer

> 标签: baileys, messaging, n8n, n8n-community-node-package, wafixer, whatsapp

## 简介

n8n community nodes for WAFixer — send WhatsApp messages, listen for incoming messages, react to webhooks. Powered by wafixer-sdk.
