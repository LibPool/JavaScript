# n8n-nodes-qdrant-context-retriever

> 标签: Qdrant, context retrieval, n8n, n8n-community-node-package, semantic search, text embeddings, vector database

## 简介

n8n community node for Qdrant — retrieves semantically relevant context from a Qdrant vector database using text embeddings, for RAG and semantic search workflows.
