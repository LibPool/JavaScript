# node-minify

> 标签: JavaScript

## 简介

Javascript / CSS minifier based on Babel-minify / Butternut / YUI Compressor / Google Closure Compiler / UglifyJS2 / Sqwish / Clean-css / CSSO

- 源码仓库：git+https://github.com/srod/node-minify.git
