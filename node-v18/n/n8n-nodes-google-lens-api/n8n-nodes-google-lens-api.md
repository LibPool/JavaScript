# n8n-nodes-google-lens-api

> 标签: apify, google-lens, google-lens-api, image-attribution, image-search, n8n, n8n-community-node-package, n8n-nodes, product-matching, reverse-image-search, stolen-images, visual-search

## 简介

Google Lens API for n8n: reverse image search from any image URL. Get visually similar results, shoppable product matches with prices, or every page carrying the exact image, as structured items. Apify-backed community node, pay-per-result, usable as an A
