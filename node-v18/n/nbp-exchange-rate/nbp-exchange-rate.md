# nbp-exchange-rate

> 标签: api, bank, central-bank, currency, exchange-rate, exchange-rates, forex, fx, narodowy, nbp, official-rates, pln, poland, polski, typescript

## 简介

Official Narodowy Bank Polski (Poland) daily exchange rates — 32 currencies vs PLN, history since 2016. Zero-dependency Node.js/TypeScript client.
