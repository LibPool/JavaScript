> 标签: automation, deno, deno-deploy, deployment, devops, edge, javascript, kv-database, n8n, n8n-community-node-package, n8n-node, serverless, subhosting, typescript, webassembly

## 简介

A comprehensive n8n community node for Deno Deploy providing 12 resources and 50+ operations for managing organizations, projects, deployments, domains, KV databases, and analytics. Includes polling trigger for deployment monitoring.
