# nlpgraph

> 标签: biaffine, compliance, dependency-parser, deterministic, nlp, offline, onnx, pos-tagger, regtech, tokenizer, typescript, universal-dependencies

## 简介

Offline, deterministic Universal-Dependencies dependency parser in pure TypeScript (ONNX runtime), for Node and the browser. MIT-licensed.
