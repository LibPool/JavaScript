# nyxis-ui

> 标签: ai, design-tokens, nyxis, react, tailwindcss, theme

## 简介

Theme system for the Nyxis ecosystem. Components are distributed via the shadcn registry; install them with `npx shadcn@latest add @nyxis/<name>`.
