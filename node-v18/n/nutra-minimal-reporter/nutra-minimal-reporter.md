# nutra-minimal-reporter

> 标签: N.U.T.R.A., jasmine, minimal, node, reporter, test, testing, unit

## 简介

The "nutra-minimal-reporter" module is a (nearly) silent testing framework reporter for the "N.U.T.R.A." unit test runner.
