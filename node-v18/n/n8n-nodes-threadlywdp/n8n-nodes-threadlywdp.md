# n8n-nodes-threadlywdp

> 标签: contact-center, crm, n8n, n8n-community-node-package, omnichannel, threadly, whatsapp

## 简介

n8n community node for Threadly (AI omnichannel contact center): contacts, tickets, messages, leads, core events and sequences over the public v1 API, plus a signed-webhook trigger.
