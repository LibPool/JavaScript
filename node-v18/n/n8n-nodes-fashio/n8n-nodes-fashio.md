# n8n-nodes-fashio

> 标签: AI, ecommerce, fashion, n8n-community-node-package, virtual-try-on

## 简介

Fashio generates publish-ready e-commerce fashion photos and video with AI — put a garment photo on an AI fashion model, or animate/enhance/reframe an existing shot.
