# namidb-vault

> 标签: claude-code, codex, cursor, graph-database, knowledge-graph, markdown, mcp, model-context-protocol, namidb, notes, obsidian, rag, semantic-search, vault

## 简介

Sync a local Obsidian/markdown vault to NamiDB Cloud as a queryable graph for AI coding agents (Claude Code, Cursor, Codex). Note nodes + LINKS_TO/EMBEDS/TAGGED edges; backlinks, n-hop, orphans, shared-tags and semantic search over MCP. Zero-dependency.
