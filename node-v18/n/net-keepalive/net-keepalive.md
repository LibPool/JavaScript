# net-keepalive

> 标签: alive, ffi, getsockopt, keep, keep alive, keep-alive, keepalive, net, ref, setsockopt, tcp

## 简介

Provides high-level access to socket options like TCP_KEEPIDLE, TCP_KEEPINTVL, TCP_KEEPCNT
