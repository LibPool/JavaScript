# node-alarm-dot-com

> 标签: alarm, alarm-dot-com, alarm.com, alarmdotcom, frontpoint, homebridge, homebridge-plugin, homekit, node-only, security

## 简介

An interface module written in node.js to arm and disarm Alarm.com security systems.
