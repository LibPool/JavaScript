# note-mcp-server

> 标签: cursor, mcp, model-context-protocol, notes, stdio

## 简介

MCP (stdio) server for Notes API v2 — list/read/write notes, put/read clipboard tunnel, upload images, Web Push from Cursor and compatible clients.
