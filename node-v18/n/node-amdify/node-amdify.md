# node-amdify

> 标签: JavaScript

## 简介

Converts node.js code to amd style modules, so it can be used in a browser

## 官网

- 源码仓库：git://github.com/Termina1/node-amdify.git
- npm 页面：https://www.npmjs.com/package/node-amdify

- npm registry：https://registry.npmjs.org/node-amdify
- Node 要求：>=0.6.1
