# ngc-search-input

> 标签: angular, bootstrap, input, search

## 简介

This component is a search input field built on Angular 8 and Bootstrap 4. It listens for input, pauses for a set duration (default 500 ms), checks for unique values, and then emits the text in the search field. Can be used to auto search a datasource aut
