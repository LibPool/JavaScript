# neonplay-player

> 标签: hls, html5-video, m3u8, player, vanilla-js, video, video-player, web-player

## 简介

轻量纯 JS 视频播放器：自定义黑色霓虹控制条，自动支持原生与 HLS(m3u8) 视频。一行初始化，无需框架。
