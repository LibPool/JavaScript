# novagate

> 标签: abuse-detection, analytics, api, api-auth, api-gateway, api-key, api-security, authentication, authorization, burst-limit, ddos-protection, gateway, logging, middleware, monitoring, nodejs-security, quota, rate-limit, security, suspension, throttle, usage-tracking

## 简介

Novagate is a flexible and fast API key middleware system for Node.js apps.   It provides authentication, usage limits, burst protection, suspension, logging, and analytics.
