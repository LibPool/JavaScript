# node-hooked-changelog

> 标签: JavaScript

## 简介

Installs a post-commit hook that triggers a changelog update whenever a commit containing a new version number is created, this works best with `npm version`.

- 源码仓库：http://github.com/SupplyFrame/node-hooked-changelog
