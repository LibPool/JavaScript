# nativescript-getters

> 标签: android, angular, attributes, classes, document, dom, elements, getters, identifiers, ios, model, nativescript, ng, ns, object, pairs, plugin, properties, property, react, styles, svelte, tags, tns, ts, types, typescript, values, views, vue, {N}

## 简介

A NativeScript plugin that adds six new getters – in addition to the native "getViewById" method – to retrieve one or more views by tag, type, class, property, value pair or style.
