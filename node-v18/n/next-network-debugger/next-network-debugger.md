# next-network-debugger

> 标签: api, debugger, developer-tools, devtools, fetch, inspector, network, nextjs, react, telemetry

## 简介

A zero-dependency, drop-in network telemetry inspector for Next.js apps. Intercepts client & server API calls with a beautiful dark-themed UI.
