# ngx9-virtual-material-keyboard

> 标签: JavaScript

## 简介

Onscreen virtual keyboard for Angular ≥ 9 (https://angular.io/) using Material 9 (https://material.angular.io/). This is a fork of the ngx-material-keyboard which supports Angular 9.
