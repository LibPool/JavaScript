# node-red-contrib-schneider-modbus-tags

> 标签: clp, float, m221, m241, modbus, node-red, plc, schneider, string

## 简介

Read Schneider M221/M241 memory (%MW, %MF, %MD) over Modbus TCP and get real values (float, dint, int, bool, string) straight into Node-RED.
