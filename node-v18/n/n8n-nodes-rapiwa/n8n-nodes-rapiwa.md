# n8n-nodes-rapiwa

> 标签: n8n, n8n-community-node-package, n8n-nodes, rapiwa, whatsapp

## 简介

Rapiwa is a Low-Cost WhatsApp API for Developer and Users. This node package allows you to use Rapiwa in n8n.
