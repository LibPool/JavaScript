# n8n-nodes-karrito

> 标签: catalog, ecommerce, karrito, n8n-community-node-package, orders, whatsapp

## 简介

n8n nodes for Karrito, the simplest online store with WhatsApp checkout: orders, products, customers, categories, discounts and a new-order trigger.
