# next-dynamic-metadata

> 标签: app-router, dynamic-metadata, json-ld, metadata, nextjs, open-graph, react, seo, twitter-cards, typescript

## 简介

A powerful Next.js package that simplifies metadata management by allowing you to define all your SEO metadata in a single configuration file. Perfect for App Router applications.
