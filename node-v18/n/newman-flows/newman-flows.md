# newman-flows

> 标签: api-testing, cli, flows, newman, postman, postman-flows

## 简介

Multi-step Postman flow runner for the free plan — no Enterprise required. Sits on top of Newman and adds flow orchestration: define ordered sequences of named requests inside your Postman collection, run them with a single CLI command.
