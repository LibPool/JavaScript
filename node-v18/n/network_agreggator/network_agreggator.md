# network_agreggator

> 标签: Aggregation, Aggregator, Arista, Dell, Mapping, Network, Networking

## 简介

An attempt to map out using API's of Dell and Arista switches using LLDP neighbors and mac address tables to IP, assumes all passwords need to be the same.
