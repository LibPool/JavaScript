# nv-buf-utf8-ab

> 标签: JavaScript

## 简介

nv-buf-utf8-ab ======================= - get/decode  code-points directly from valid-utf8-array-buffer - similiar to  for(let ch of str) { yield(ch.codePointAt(0))} , just from array-buffer, NOT from string - this pkg just rewrite v8/src/third\_party/utf8
