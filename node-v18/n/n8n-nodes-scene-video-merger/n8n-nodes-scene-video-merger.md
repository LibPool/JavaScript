# n8n-nodes-scene-video-merger

> 标签: concat, ffmpeg, media, n8n, n8n-community-node-package, video, video merger

## 简介

n8n community node that downloads a set of scene video clips and concatenates them into one video using ffmpeg, with automatic normalization (fps/resolution/codec/audio) for mismatched source clips.
