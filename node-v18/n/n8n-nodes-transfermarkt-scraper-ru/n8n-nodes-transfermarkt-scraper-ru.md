# n8n-nodes-transfermarkt-scraper-ru

> 标签: apify, n8n, n8n-community-node-package, n8n-nodes, scraping

## 简介

Данные Transfermarkt по игрокам сборной России и СНГ — рыночная стоимость, трансферная история, статистика по клубам. 25+ полей: клуб, позиция, возраст, контракт, агент. Без логина и прокси. Prefill игроков сборной (Головин, Миранчук, Оздоев) для CIS-анал
