# n8n-nodes-bitwarden

> 标签: automation, bitwarden, credential-management, directory-sync, n8n, n8n-community-node-package, organization-management, password-manager, secrets-manager, sso, workflow

## 简介

A comprehensive n8n community node for Bitwarden providing 12 resources and 80+ operations for organization management, member provisioning, collections, groups, policies, events, SSO, directory sync, and Secrets Manager integration.
