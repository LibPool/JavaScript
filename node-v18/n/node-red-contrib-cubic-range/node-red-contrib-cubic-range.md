# node-red-contrib-cubic-range

> 标签: cubic-interpolation, cubic-spline, node-red, range

## 简介

Maps values from the input to an output value using cubic interpolation of values based on supplied table. Uses cubic-spline by Morgan Herlocker to do the heavy lifting.
