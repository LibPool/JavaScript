# nanoprogress

> 标签: a11y, accessibility, aria, csp, loading, loading-bar, nprogress, progress, progress-bar, router, rtl, typescript, zero-dependencies

## 简介

Accessible slim progress bar for the top of the page. Drop-in replacement for nprogress: same API, real ARIA progressbar, RTL, CSP-safe, router support, zero dependencies.
