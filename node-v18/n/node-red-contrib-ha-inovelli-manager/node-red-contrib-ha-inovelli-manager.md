# node-red-contrib-ha-inovelli-manager

> 标签: home assistant, inovelli, matter, node-red, notification, scene control, z-wave, zigbee, zigbee2mqtt, zwave-js

## 简介

Nodes for easily managing scenes, parameters, and notifications of Inovelli Red Series (Z-Wave JS), Blue Series (Zigbee2MQTT), and White Series (Matter) switches paired through Home Assistant
