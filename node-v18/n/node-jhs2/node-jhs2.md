# node-jhs2

> 标签: dynamic, html, jhs, nodejs, server-side-rendering, template, template-engine, views, vm, xss

## 简介

A dynamic template engine for Node.js using <?jhs ?> delimiters — PHP-like syntax with JavaScript and XSS protection.
