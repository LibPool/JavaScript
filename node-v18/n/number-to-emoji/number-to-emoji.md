# number-to-emoji

> 标签: emoji, emoji-to-number, emoji-to-numbers, number-to-emoji, numbers, numbers-to-emoji

## 简介

Converts a number like 1337 to emoji sequence like 1️⃣3️⃣3️⃣7️⃣. Or vice versa!
