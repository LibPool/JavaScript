# ng-mat-icon-bar

> 标签: JavaScript

## 简介

The component creates an icon-bar which expands a list of Material icons on click. See the demo for the effect: ![NgMatSearchBar demo](https://raw.githubusercontent.com/tommueller/ng-mat-icon-bar/master/docs/demo.gif)
