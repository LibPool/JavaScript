# nv-facutil-simple-enum

> 标签: JavaScript

## 简介

nv-facutil-simple-enum ======================= - simple util to create a enum-like class - to avoid using switch/case, switch/case is hard for auto-generating-code - only two method : add\_branch AND match - its a simple version of nv-facutil-switch - onl
