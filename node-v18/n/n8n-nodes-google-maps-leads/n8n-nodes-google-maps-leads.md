# n8n-nodes-google-maps-leads

> 标签: apify, email-scraper, google-maps, google-maps-leads, lead-generation, n8n, n8n-community-node-package, n8n-nodes, scraper, web-scraping

## 简介

n8n community node for the Apify Google Maps Email Scraper - extract business leads from Google Maps complete with emails, phones and social profiles for lead generation. No API key required.
