# n8n-nodes-personio-job-scraper

> 标签: apify, n8n, n8n-community-node-package, n8n-nodes, scraping

## 简介

Scrape job postings from any Personio-powered company careers page via the public XML feed. Get title, location, department, team, seniority, remote-type, employment type, schedule, descriptions and parse_confidence. Multi-company batch, keyword filters,
