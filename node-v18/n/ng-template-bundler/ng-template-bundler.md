# ng-template-bundler

> 标签: angular, bundler, cli, html2js, template, templateCache

## 简介

Standalone node script to bundle Angular templates into javascript modules. Based on Brian Park's (yaru22@gmail.com) original ng-html2js project.

## 官网

- 官网：https://github.com/tarsolya/ng-html2js
- 源码仓库：git@github.com:tarsolya/ng-html2js.git
- npm 页面：https://www.npmjs.com/package/ng-template-bundler
