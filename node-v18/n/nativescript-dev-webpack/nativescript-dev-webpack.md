# nativescript-dev-webpack

> 标签: JavaScript

## 简介

This repository contains the code for the nativescript-dev-webpack plugin which helps in webpacking [NativeScript](https://www.nativescript.org/) apps.

## 官网

- 官网：http://www.telerik.com
- 源码仓库：git+https://github.com/NativeScript/nativescript-dev-webpack.git
- npm 页面：https://www.npmjs.com/package/nativescript-dev-webpack
