# nestjs-metrics-core

> 标签: analytics, charts, dashboard, drizzle, fluent-api, metrics, mysql, postgresql, prisma, sql, sqlite, time-series, trends, typeorm, typescript

## 简介

ORM-agnostic metrics & trends engine. Build chart-ready time-series from TypeORM, Prisma, Drizzle or any SQL driver via a fluent API.
