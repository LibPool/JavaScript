# neo-register

> 标签: neo-editor自定义组件模型, neo自定义组件, neo自定义组件注册器

## 简介

Neo 自定义组件注册器（支持 react 和 vue2.0 技术栈），主要用于注册 Neo 自定义组件和自定义组件模型。
