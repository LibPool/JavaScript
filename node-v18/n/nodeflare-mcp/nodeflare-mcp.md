# nodeflare-mcp

> 标签: agent, ai-agents, blockchain, claude, cursor, ethereum, evm, json-rpc, mcp, mcp-server, model-context-protocol, modelcontextprotocol, multichain, nodeflare, onchain, rpc, web3, x402

## 简介

MCP server for NodeFlare RPC — blockchain data on 23 EVM chains for AI agents. Free public tier, API key, or pay-per-call with x402 (USDC on Base/Polygon/Arbitrum).
