# ngx-signal-loading-bar

> 标签: angular, angular-library, angular16, http-interceptor, loading-bar, ngx, progress-bar, signals, typescript, zoneless

## 简介

A lightweight, signal-based, zoneless loading bar for Angular 22. Tracks HTTP requests via HttpClient and provides a reactive progress bar component with standalone components and interceptors.
