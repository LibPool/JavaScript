# nepali-big-calendar-kit

> 标签: bikram-sambat, bs, calendar, date-picker, datepicker, nepal, nepali, react, shadcn, tailwind

## 简介

Bikram Sambat (Nepali) + Gregorian calendar components for React, Tailwind and shadcn/ui: a big event calendar, a month grid, a date picker, and a headless BS↔AD conversion core.
