# npmsvr

> 标签: nodejs, publish, registry, testing

## 简介

Simpler command line interface for `npm-server` registry simulator. Helps test NodeJS libs/apps prior to performing `npm publish`.

- npm 页面：https://www.npmjs.com/package/npmsvr
