# n8n-nodes-townwork-jobs-scraper

> 标签: apify, n8n, n8n-community-node-package, n8n-nodes, scraping

## 简介

Scrape part-time and casual (arubaito) job listings from townwork.net (Recruit, Japan) by keyword or area URL. Returns title, company, wage (hourly/daily, min-max JPY), employment type, nearest station, job URL and ID. Optional full descriptions. Browser-
