# net-proxy

> 标签: CONNECT_METHOD, forwarding, forwarding-proxy, http, https, net, node, proxy, smartProxy

## 简介

A simple net http https forwarding proxy! Like smartProxy and vpn's! You can use it with your browser or your system to go out! So if set in an external server! You can change your IP using it!
