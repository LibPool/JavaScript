# ngx-version-check

> 标签: angular, angular 10, angular 11, angular 12, angular 13, angular 8, angular 9, angular library, ngx, service, version check, version checking

## 简介

Angular 8+ library for version checking.  When a new build is deployed, and customers are currently using the application, this will monitor the version of the application, and provides a way to notify the user of an update.
