# normalize-svg

> 标签: canvas, flatten, normalize, path, resvg, svg, usvg, wasm, webassembly

## 简介

Flattens arbitrary SVG into a minimal subset — CSS, <use>, nested <svg> and shapes all become plain <path> — via usvg compiled to WebAssembly. Fonts for text and emoji are embedded, so output is identical on every OS with no font downloads.
