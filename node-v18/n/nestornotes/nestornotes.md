# nestornotes

> 标签: cli, fastmcp, knowledge-base, mcp, nestornotes

## 简介

Command-line client for the NestorNotes knowledge base. Thin wrapper around the Python `nestornotes` CLI on PyPI; runs it via `uvx`.
