# nodemailer-postal

> 标签: api, email, mail, nodemailer, nodemailer-transport, postal, postalserver, transport

## 简介

Nodemailer transport that delivers mail through the Postal HTTP API instead of SMTP. Works with nodemailer 8, 9 and 10.
