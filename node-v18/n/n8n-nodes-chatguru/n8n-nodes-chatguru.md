# n8n-nodes-chatguru

> 标签: n8n-community-node-package

## 简介

Custom node for integrating the ChatGuru API with n8n. This node provides various operations such as sending messages, adding notes, updating chat context and custom fields, managing chat names, and more, enabling efficient chat automation.
