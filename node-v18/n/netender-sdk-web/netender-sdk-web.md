# netender-sdk-web

> 标签: JavaScript

## 简介

NETender SDK Web SDK 是网易会议招采场景专用的 SDK，提供了招采会议场景下的核心接口服务，不包含 UI 组件。它是 tender-kit-web 的核心服务层。
