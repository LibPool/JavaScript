# ngx-firebase

> 标签: angular, angular-fire, firebase, firebase-auth, firestore, providers, rxjs, zoneless

## 简介

A lightweight, drop-in, and zoneless-friendly wrapper around the native Firebase JS SDK for Angular 22+.
