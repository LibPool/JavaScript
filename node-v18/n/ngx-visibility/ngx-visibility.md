# ngx-visibility

> 标签: JavaScript

## 简介

Angular 21.x library to monitor when elements are visible in the DOM. When you have a huge list of components, this is more performant than other libraries because it keeps the number of observers to a minimum. It uses IntersectionObserver to do the work.
