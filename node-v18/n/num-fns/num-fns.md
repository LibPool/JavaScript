# num-fns

> 标签: az, currency, en, en-GB, es, formatting, i18n, internationalization, l10n, locale, localization, money, notation, number, number-to-words, numbers, ordinal, parsing, percentage, roman-numerals, ru, spell-number, typescript

## 简介

Modern internationalized number utility library for JavaScript — format and parse numbers, money and percentages, spell numbers out in words, ordinals, short/long notation and roman numerals. Like date-fns, but for numbers.
