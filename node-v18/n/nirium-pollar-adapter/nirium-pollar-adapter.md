# nirium-pollar-adapter

> 标签: adapter, nirium, pollar, soroban, stellar, x402

## 简介

Nirium adapter for the Pollar SDK — x402 pay-per-request and IPFS audit anchoring using the wallet a user onboarded through Pollar. Signs SEP-43 auth entries; the facilitator sponsors network fees.
