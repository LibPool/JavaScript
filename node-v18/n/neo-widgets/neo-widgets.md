# neo-widgets

> 标签: neo-editor自定义插件, neo自定义组件, neo自定义组件注册器

## 简介

neo自定义组件注册器（支持 react 和 vue2.0 技术栈），主要用于注册 neo 渲染器、neo-editor 插件。
