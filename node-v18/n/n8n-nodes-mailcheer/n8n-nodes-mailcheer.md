# n8n-nodes-mailcheer

> 标签: email, email-marketing, mailcheer, n8n, n8n-community-node-package, newsletter, transactional-email, webhook

## 简介

n8n nodes for Mailcheer: send emails, manage subscribers and tags, create and send campaigns, read your quota, and trigger workflows on Mailcheer events.
