# n8n-nodes-facebook-ad-library

> 标签: ad-library, apify, competitor-analysis, facebook, facebook-ads, instagram-ads, marketing, meta-ads, n8n, n8n-community-node-package, n8n-nodes

## 简介

n8n community node for the Apify Facebook Ad Library Scraper - spy on competitor Facebook and Instagram ads with no login. Pull every active ad creative, copy, run dates and landing page from the Meta Ad Library.
