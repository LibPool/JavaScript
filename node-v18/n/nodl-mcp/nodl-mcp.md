# nodl-mcp

> 标签: claude, cursor, mcp, model-context-protocol, nodl

## 简介

Model Context Protocol server for Nodl — give your AI client a live map of your system: areas, sub-areas, integrations, databases, and the change graph. Document features back into the Nodl inbox for human review.
