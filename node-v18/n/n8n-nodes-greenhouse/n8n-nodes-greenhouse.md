# n8n-nodes-greenhouse

> 标签: applicant-tracking, ats, candidates, greenhouse, hiring, hr, human-resources, n8n, n8n-community-node-package, recruiting, workflow-automation

## 简介

A comprehensive n8n community node for Greenhouse ATS providing 16 resources and 100+ operations for candidate management, applications, jobs, offers, interviews, and more. Includes webhook triggers and full GDPR compliance features.
