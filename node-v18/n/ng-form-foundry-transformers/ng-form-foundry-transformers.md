# ng-form-foundry-transformers

> 标签: form, json, json-schema, netconf, network-management, ng-form-foundry, restconf, rfc7950, rfc7951, transformer, typescript, yaml, yang

## 简介

Framework-agnostic Node + TypeScript catalog of source-format transformers: turn a YANG model (and more) into an ng-form-foundry schema and revert the edited form value back to the source format.
