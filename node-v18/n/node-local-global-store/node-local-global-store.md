# node-local-global-store

> 标签: JavaScript

## 简介

旨在解决本机私有数据多项目共享。 在本机全局安装并存储数据，在项目中添加依赖后可获取数据。

## 官网

- npm 页面：https://www.npmjs.com/package/node-local-global-store

## 历史版本号

- 当前版本：0.0.5

- 0.0.5

## 获取地址

- npm 安装：`npm install node-local-global-store`
- npm registry：https://registry.npmjs.org/node-local-global-store
- Node 要求：>=16.15.1
