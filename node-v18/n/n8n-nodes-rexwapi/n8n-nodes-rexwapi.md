# n8n-nodes-rexwapi

> 标签: automation, chat, messaging, n8n, n8n-community-node-package, rexwapi, trigger, webhook, webhook-trigger, whatsapp, whatsapp-api

## 简介

RexWapi nodes for n8n: a webhook trigger for inbound WhatsApp messages, status updates, reactions, delivery updates and read receipts, plus a node to send text, image, audio, video and files, reply and react.
