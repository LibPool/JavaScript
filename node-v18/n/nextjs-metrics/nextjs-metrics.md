# nextjs-metrics

> 标签: analytics, charts, dashboard, drizzle, fluent-api, kysely, metrics, mysql, nextjs, postgresql, prisma, sqlite, time-series, trends, typescript

## 简介

Generate chart-ready metrics and trends in Next.js or any Node runtime over Prisma, Drizzle or Kysely. Built on nestjs-metrics-core.
