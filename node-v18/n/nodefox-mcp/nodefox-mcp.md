# nodefox-mcp

> 标签: ai-agents, claude, mcp, model-context-protocol, nodefox

## 简介

MCP server that connects Claude, Codex, Cursor and other coding agents to a live NodeFox workspace. No token, no workspace in the config.

- 官网：https://nodefox.ai
- npm 页面：https://www.npmjs.com/package/nodefox-mcp
