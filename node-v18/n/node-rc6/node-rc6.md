# node-rc6

> 标签: adb, firetv, harmony, hue, kodi, rc6, remote, xbmc

## 简介

Small home automation project. Controls Fire TV + Kodi (via adb) and hue lights (via API) using a Harmony One + RC6 USB IR receiver (on a Raspberry Pi).
