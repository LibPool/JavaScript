# numshrink

> 标签: abbreviate, cli, compact-number, format-number, human-readable, humanize, kmb, number, numshrink, typescript

## 简介

Tiny, dependency-free library for compact number formatting ("1.2M") with a built-in reverse parser, plus a CLI.
