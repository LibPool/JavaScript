# noisetoy

> 标签: glsl, noise, perlin, procedural, simplex, texture, threejs, tsl, webgl, webgpu, wgsl, worley

## 简介

Noise functions with TypeScript, GLSL, WGSL and Three.js TSL parity, plus a layer compositor that emits any of them
