# n8n-nodes-prismic

> 标签: automation, cms, content-api, content-management, headless-cms, jamstack, localization, multi-language, n8n, n8n-community-node-package, prismic, slicemachine, workflow

## 简介

A comprehensive n8n community node for Prismic headless CMS providing 8 resources and 35+ operations for content retrieval, querying, multi-language support, and workflow automation. Includes polling trigger for content change detection.
