# ngx-fetch-api

> 标签: angular, fetch, javascript, restful, typescript

## 简介

A library for Angular 6+ using [JavaScript fetch API](https://developer.mozilla.org/en-US/docs/Web/API/Fetch_API) to access RESTful API.
