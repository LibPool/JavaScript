# node-grumble

> 标签: client, grumble, mumble, typescript, voice

## 简介

`node-grumble` is a Node.js client for Mumble written in Typescript.  The name is inspired by the Mumble Server implementation in Go called [Grumble](https://github.com/mumble-voip/grumble/).
