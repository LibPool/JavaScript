# node-rsa-build

> 标签: assymetric, crypto, decryption, encryption, node, oaep, pkcs1, pss, rsa, sign, verify

## 简介

这是node-rsa的构建版本，解决原依赖在vite构建工具中不支持问题，如果你使用vite，那么还需要在vite.config.js中配置下optimizeDeps。
