# n8n-nodes-goodfirms-agency-directory

> 标签: apify, n8n, n8n-community-node-package, n8n-nodes, scraping

## 简介

Search the GoodFirms B2B agency directory by category. Returns each listed agency's rating, review count, hourly rate, employee range, location, founding year, website, and (best-effort) email/phone/full address/services.
