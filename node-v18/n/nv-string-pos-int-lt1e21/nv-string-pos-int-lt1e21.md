# nv-string-pos-int-lt1e21

> 标签: JavaScript

## 简介

nv-string-pos-int-lt1e21 ======================= - same as Number.toString() - but only work  WHEN  number is integer AND number >0  AND number < 1e21 - slightly faster than built-in .toString()
