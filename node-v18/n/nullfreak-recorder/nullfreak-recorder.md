# nullfreak-recorder

> 标签: JavaScript

## 简介

`nullfreak` is a JavaScript library designed to capture user interactions in web applications for analytics and monitoring purposes. It provides easy-to-use APIs to track user activities like clicks, inputs, and scrolls, and sends them to a specified endp
