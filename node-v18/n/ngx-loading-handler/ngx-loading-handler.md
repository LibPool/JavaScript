# ngx-loading-handler

> 标签: angular, command, loading, mutation, ngx, signals, state, zoneless

## 简介

A minimal Angular library that wraps any mutation in a signals-based command object exposing loading, error, and result state. Signals-first, zoneless-compatible, zero runtime dependencies.
