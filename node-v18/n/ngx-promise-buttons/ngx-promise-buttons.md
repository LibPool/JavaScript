# ngx-promise-buttons

> 标签: angular, angular-directive, async, button, loading, loading-button, ngx, promise, promise-button, rxjs, spinner, standalone, subscription, typescript

## 简介

Add loading spinners to Angular buttons from promises, RxJS subscriptions, or booleans. Standalone directive for Angular 9-22.
