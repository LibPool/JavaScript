# node-red-contrib-mqtt-sparkplug-plus-wmonitor

> 标签: MQTT, Sparkplug, node-red

## 简介

Fork of node-red-contrib-mqtt-sparkplug-plus with Sparkplug B birth/death lifecycle and publish timing fixes. Same node type names as the original, so the two cannot be installed side by side.
