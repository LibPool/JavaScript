# node-windows2

> 标签: daemon, elevate, event, event logging, logging, ngn, service, sudo, task, windows

## 简介

Fork of Corey Butler's node-windows v.0.1.11 with several fixes (Support for Windows services, event logging, UAC, and several helper methods for interacting with the OS).
