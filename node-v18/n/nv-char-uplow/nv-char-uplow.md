# nv-char-uplow

> 标签: JavaScript

## 简介

nv-char-uplow ======================= - simple util to check if a char/code-point  is  lower-case OR upper-case OR both-case OR neither-case - coz some special-char  .toUpperCase().toLowerCase()   NOT  same as self
