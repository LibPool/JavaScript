> 标签: Android, AutoComplete, JavaScript, NativeScript, Pro-UI, ProUI, RadAutoComplete, RadAutoCompleteTextView, auto-complete, iOS

## 简介

Improve data entry speed and accuracy by triggering auto-completion for text entries. Part of Progress NativeScript UI - a set of professional ui components built for NativeScript (also known as Pro UI).
