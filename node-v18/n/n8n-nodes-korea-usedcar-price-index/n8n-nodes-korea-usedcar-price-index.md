# n8n-nodes-korea-usedcar-price-index

> 标签: apify, n8n, n8n-community-node-package, n8n-nodes, scraping

## 简介

Get Korea's official used-car appraisal price matrix from Bobaedream (bobaedream.co.kr) dealguide: maker, model, trim, registration year, price (KRW), plus new-car price. This is a valuation reference index, not individual seller listings. Pay per result.
