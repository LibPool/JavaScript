# ntent-archive

> 标签: JavaScript

## 简介

Archive by ntent.art curates an art history archive of artworks, interviews, artist notes/back of napkins, etc using decentralized technologies. This utility extends nft.storage to easily managing upload of content in a way it can be found later.
