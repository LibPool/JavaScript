# node-red-contrib-myhome-own-mqtt

> 标签: bticino, homeassistant, legrand, mqtt, myhome, node-red, openwebnet, own, scs, thermoregulation

## 简介

BTicino / Legrand MyHome SCS (OpenWebNet) to MQTT bridge for Node-RED: lights, covers, thermoregulation, contacts, CEN/CEN+ buttons, with dual output (MQTT and raw OWN) and optional Home Assistant auto-discovery
