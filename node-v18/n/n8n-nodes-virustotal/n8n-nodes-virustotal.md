# n8n-nodes-virustotal

> 标签: n8n-community-node-package, security, threat-intelligence, virustotal

## 简介

Nodo de n8n para la API publica (v3) de VirusTotal: reportes de archivos, URLs, dominios e IPs, escaneos, comentarios y votos.
