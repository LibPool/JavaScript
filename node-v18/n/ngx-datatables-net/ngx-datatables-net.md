# ngx-datatables-net

> 标签: angular, angular-20, angular-21, angular-22, angular-data-grid, angular-datatables, angular-grid, angular-table, cell-editor, data-grid, datagrid, datatables, datatables-angular, datatables.net, edit-in-place, editable, grid, inline-edit, ngx, signals, standalone, table, zoneless

## 简介

Modern Angular wrapper for DataTables (datatables.net) using its non-jQuery API, standalone, signal-based, zoneless-ready. Supports Angular 20, 21 and 22.
