# number-packer

> 标签: bigint, binary, bit, bit-packing, bitmask, buffer, compact, network, pack, protocol, serialization, typescript, unpack

## 简介

A versatile and efficient TypeScript library for packing/unpacking numbers of varying bit-lengths into compact binary buffers.
