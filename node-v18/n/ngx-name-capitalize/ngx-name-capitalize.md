# ngx-name-capitalize

> 标签: angular, angular-pipe, capitalize, latin-names, name, name-capitalize, namecase, pipe, typescript, unicode

## 简介

Angular pipe for smart capitalization of person names. Handles particles, compound surnames, hyphenated names and Unicode characters.
