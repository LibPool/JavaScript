# node-nvrtc

> 标签: cuda, javascript, nvrtc

## 简介

`node-nvrtc`是一个简易的使用`nvrtc`的`node.js`扩展，目前只包含简单的`nvrtc`功能和`cuda`内存交换相关功能。
