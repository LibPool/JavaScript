# nest-temporal

> 标签: activities, decorator, microservices, nestjs, orchestration, temporal, temporalio, worker, workflow

## 简介

NestJS integration for Temporal.io — decorator-based activity registration, auto-discovery workers, and dynamic module configuration inspired by @nestjs/bullmq
