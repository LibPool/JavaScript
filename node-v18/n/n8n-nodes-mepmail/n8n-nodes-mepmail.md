# n8n-nodes-mepmail

> 标签: ai-agent, deliverability, email, inbound-email, mailbox, mepmail, n8n, n8n-community-node-package, resend, ses, transactional-email

## 简介

n8n community nodes for MepMail — send transactional email, manage contacts, domains, broadcasts and suppressions, and trigger on and answer Correio mailboxes, on MepMail cloud or any self-hosted instance (Resend wire-compatible).
