# nuomi-request

> 标签: axios, mock, nuomi, nuomi-request, request

## 简介

nuomi-request是基于axios封装的请求库，可以对接口进行集中式管理，方便接口的使用和维护，配合mock功能在开发阶段便于程序的测试。
