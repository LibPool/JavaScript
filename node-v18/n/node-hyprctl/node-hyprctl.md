# node-hyprctl

> 标签: JavaScript

## 简介

A TypeScript/Node.js wrapper for [hyprctl](https://wiki.hyprland.org/Configuring/Using-hyprctl/), the command-line utility for controlling the Hyprland Wayland compositor.
