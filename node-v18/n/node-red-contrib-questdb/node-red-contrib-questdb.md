# node-red-contrib-questdb

> 标签: agriculture, analytics, data-ingestion, database, energy, fleet-tracking, healthcare, hvac, ilp, industrial, influx-line-protocol, iot, manufacturing, metrics, modbus, monitoring, mqtt, node-red, observability, questdb, scada, sensors, smart-building, smart-meter, telematics, telemetry, time-series, vitals, weather

## 简介

Node-RED nodes for writing high-performance time-series data to QuestDB using Influx Line Protocol (ILP). Supports IoT, industrial monitoring, smart buildings, fleet telematics, healthcare, agriculture, and more.
