# node-red-contrib-easye4-modbus

> 标签: easy, easye4, eaton, modbus, modbus-tcp, node-red, plc, sps, steuerung

## 简介

Node-RED nodes for the Eaton easyE4 via Modbus TCP: read/write inputs, outputs, markers, NET markers, analog values and the clock – no extra dependencies (English/Deutsch)
