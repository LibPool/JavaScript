# ngx-quill-attachment

> 标签: attachmentHandler, imageHandler, ngx-quill, quill, videoHandler

## 简介

A module for images, videos and pdfs to be uploaded to a server instead of being base64 encoded, in ngx-quill from toolbar editor.
