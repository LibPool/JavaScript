# npm-install-star

> 标签: JavaScript

## 简介

Very simple node.js utility to install freshest versions of all the dependencies in your `package.json` marked as "*" without mutating `package.js`.

## 官网

- 官网：https://github.com/panta82/npmstar#readme
- 源码仓库：git+https://github.com/panta82/npmstar.git
- npm 页面：https://www.npmjs.com/package/npm-install-star
