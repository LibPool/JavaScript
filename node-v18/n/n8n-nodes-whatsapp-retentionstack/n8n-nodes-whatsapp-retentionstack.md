# n8n-nodes-whatsapp-retentionstack

> 标签: messaging, n8n, n8n-community-node-package, otp, rapidapi, whatsapp, whatsapp-api

## 简介

n8n nodes for the WhatsApp Messaging API by Retention Stack. Send WhatsApp text, images, files and OTPs, and trigger workflows on incoming messages. No Meta approval needed.
