# n8n-nodes-source-documents-retriever-qa-chain

> 标签: langchain, n8n, n8n-community-node-package, retrieval-qa

## 简介

A custom n8n node for question-answering using retrieved documents, with optional source document output for enhanced traceability and transparency.
