# ngx-error-summary

> 标签: a11y, accessibility, angular, angular-forms, angular-signals, aria, error-messages, error-summary, focus-management, form-errors, form-validation, forms, reactive-forms, screen-reader, signals, standalone, validation, validation-messages, wcag, zoneless

## 简介

Accessible validation error summary for Angular reactive forms. Signal-based, zoneless, standalone — one message pipeline shared by the summary block and inline field errors.
