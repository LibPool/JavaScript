# ngx-mat-phone-input

> 标签: angular, code, country, dial, flag, i18n, input, international, intl-tel-input, material, mobile, ng-intl-tel-input, ng10, ng11, ng12, ng13, ng14, ng2, ng4, ng5, ng6, ng7, ng8, ng9, phone, phone number, telephone, validation

## 简介

An Angular Material package for entering and validating international telephone numbers. It adds a flag dropdown to any input, detects the user's country, displays a relevant placeholder and provides formatting/validation methods.
