# nv-file-vfs-base

> 标签: JavaScript

## 简介

nv-file-vfs-base ============== - simple virtual file  - only support 6 actions:  - cd(nvpath) | touch(nvpath) | mkdir(nvpath) |   - ln(linkto\_nvpath,linkfrom\_nvpath)  /*softlink ln -s*/ |  - rm(nvpath)  | erase(nvpath)  /*removed AND cant recycle*/ - n
