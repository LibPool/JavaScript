# network-modifier

> 标签: charles, debugging-proxy, devtools, fiddler, http, https, intercept, mitm, proxy

## 简介

A cross-platform debugging proxy that intercepts and mutates HTTP/HTTPS requests and responses (Fiddler / Charles style) with rules, scripts and breakpoints.
