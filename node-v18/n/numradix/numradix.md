# numradix

> 标签: base, base conversion, base58, base62, bigint, binary, decode, encode, hexadecimal, number system, octal, radix

## 简介

Number base conversion toolkit — bases 2–36, BigInt precision, custom alphabets, formatting. Zero dependencies. TypeScript-first.
