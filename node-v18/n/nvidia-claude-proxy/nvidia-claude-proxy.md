# nvidia-claude-proxy

> 标签: anthropic, api, chat, claude, llm, nvidia, proxy

## 简介

Proxy that exposes Anthropic/Claude-style POST /v1/messages, converts to OpenAI Chat Completions, and forwards to NVIDIA API
