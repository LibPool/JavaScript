# n8n-nodes-prosody

> 标签: amharic, emotion, ethiopia, n8n, n8n-community-node-package, parselmouth, praat, prosody, text-to-speech, tts

## 简介

n8n community node for the self-hosted Prosody Shaping Service — applies emotion-driven pitch/tempo/intensity transforms (Praat/parselmouth PSOLA) to existing TTS audio without regenerating speech content.
