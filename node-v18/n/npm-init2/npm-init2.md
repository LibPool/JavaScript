# npm-init2

> 标签: cli, init, npm, tool, util, workspace, workspaces, yarn, yarn-tool

## 简介

a lazy npm init for create new package, support yarn workspace. make we without use `mkdir xxx && cd xxx && [npm|yarn] init` with `npx npm-init2 xxx`
