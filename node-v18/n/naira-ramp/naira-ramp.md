# naira-ramp

> 标签: african-fintech, base, bsc, crypto, crypto-payments, defi, ethereum, fintech, naira, ngn, nigeria, nigeria-fintech, off-ramp, offramp, on-ramp, onramp, optimism, polygon, quidax, react, react-native, sdk, solana, stablecoin, tron, typescript, usdc, usdt, web3, webhook, yellowcard

## 简介

Unified crypto on-ramp and off-ramp SDK for Nigeria. Abstracts YellowCard and Quidax into a single API with React hooks, widgets, multi-chain support (Ethereum, Tron, Base, Optimism, BSC), and webhook handling.
