# ngx-app-shell

> 标签: admin-template, angular, angular-components, angular-library, app-shell, breadcrumbs, chatbot, dashboard-template, llm, navigation, sidebar, standalone-components, tree-menu, ui, ui-kit, ui-library

## 简介

A free, MIT-licensed Angular UI library providing a ready-made application shell: a collapsible tree navigation sidebar, a header with breadcrumbs and a user menu, a footer, and a bring-your-own-LLM chat widget.
