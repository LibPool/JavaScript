# node-red-localfilesystem-one-file-per-tab

> 标签: node-red, thethingbox, timesquair, tsa, ttb

## 简介

It's a fork from localfilesystem Node-RED storage module. It permits to separate each flow tab into separate flow files.

- npm 页面：https://www.npmjs.com/package/node-red-localfilesystem-one-file-per-tab
