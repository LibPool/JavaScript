# nuttle-mcp

> 标签: claude, comments, local-first, mcp, model-context-protocol, nuttle, reddit

## 简介

MCP server for Nuttle: let Claude Desktop and other stdio MCP clients query the posts, comment trees and videos you've browsed (Reddit, X and more), saved locally by the Nuttle desktop app.
