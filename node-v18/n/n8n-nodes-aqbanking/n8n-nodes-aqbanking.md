# n8n-nodes-aqbanking

> 标签: aqbanking, automation, banking, fintech, fints, german-banks, hbci, n8n, n8n-community-node-package

## 简介

n8n community node to interact with German banks using FinTS/HBCI protocol for account balance queries and transaction retrieval - Development/Testing version without aqbanking-cli dependency
