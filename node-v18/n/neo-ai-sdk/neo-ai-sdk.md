## 简介

Unified TypeScript SDK for OpenAI, Anthropic Claude, Gemini, Mistral, DeepSeek, xAI Grok, Qwen and Llama — one API with streaming, tool calling, structured output, guardrails, memory and multi-agent orchestration.
