# n8n-nodes-google-maps-directions-api

> 标签: ai-tool, apify, directions, google-maps-directions, maps, n8n, n8n-community-node-package, n8n-nodes, navigation, routes, travel-time

## 简介

Get Google Maps directions between two places with distance, duration, and route options. Apify-backed n8n community node, pay-per-result, and usable as an AI agent tool.
