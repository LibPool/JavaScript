# n8n-nodes-autocount

> 标签: accounting, autocount, autocount cloud accounting, e-invoice, malaysia, myinvois, n8n, n8n-community-node-package

## 简介

n8n community node for AutoCount Cloud Accounting (Malaysia): customers, suppliers, products, sales and purchase documents, payments, journals and stock, plus a polling trigger.
