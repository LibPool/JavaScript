# node-tradfri-thkl

> 标签: ikea, tradfri

## 简介

Async Node Module To Control IKEA Tradfri Lights with Node.js Argon (v4.x) support. Refactored version of Marton Papps original - node-tradfri.New module for homematic-virtual-interface
