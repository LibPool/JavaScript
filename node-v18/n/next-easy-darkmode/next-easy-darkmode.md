# next-easy-darkmode

> 标签: animation, dark-mode, next.js, react, theme, typescript, view-transition

## 简介

A simple but powerful dark mode solution for Next.js built on next-themes and View Transitions API, providing smooth theme transitions with no flash of unstyled content
