# nw-cli

> 标签: JavaScript

## 简介

nw-cli 是一款专为 Vue.js 开发者设计的现代化前端脚手架工具，致力于简化项目初始化过程中繁琐的配置工作。通过简单的命令行指令，快速集成 Vue 生态系统中最流行的状态管理和路由解决方案，让开发者能够专注于业务逻辑而非配置细节。
