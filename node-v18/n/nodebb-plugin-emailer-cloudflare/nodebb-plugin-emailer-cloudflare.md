# nodebb-plugin-emailer-cloudflare

> 标签: cloudflare, cloudflare-email, email, email-sending, emailer, forum, nodebb, nodebb-plugin, notifications, transactional-email

## 简介

Send NodeBB emails through Cloudflare Email Sending REST API. No SMTP required. Includes admin UI, credential verification, test email, safety policies, and rate limiting.
