# node-observe

> 标签: alerts, apm, express, ioredis, latency, memory-leak, metrics, mongodb, mongoose, monitoring, observability, percentiles, performance, redis, slack

## 简介

Lightweight backend observability for Node.js — API latency, MongoDB & Redis query timing, memory-leak detection, and Slack alerts. Datadog-lite for small teams, with no agent and minimal dependencies.
