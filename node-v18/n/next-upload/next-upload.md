# next-upload

> 标签: file upload, image upload, next, next file upload, next r2, next s3, next upload, next uploads, next-upload, next.js uploads, s3 upload, signed upload, upload

## 简介

A turn-key solution for integrating Next.js with signed & secure file-uploads to an S3 compliant storage service such as R2, AWS, or Minio.
