# nicehire-mcp-mentor

> 标签: jobs, mcp, mentor, model-context-protocol, nicehire

## 简介

Mentor-persona launcher for the NiceHire MCP connector. Same proxy, same endpoint as nicehire-mcp; the tool set comes from your mentor account's access token.
