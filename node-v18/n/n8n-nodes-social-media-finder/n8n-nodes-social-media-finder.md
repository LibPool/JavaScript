# n8n-nodes-social-media-finder

> 标签: apify, n8n, n8n-community-node-package, n8n-nodes, scraping

## 简介

Given a person's name, username, email, or phone — find their social-media profiles across 15+ platforms: LinkedIn, Twitter/X, Instagram, TikTok, GitHub, Reddit, YouTube, Facebook, Pinterest and more. Output: platform, profile URL, display name, match con
