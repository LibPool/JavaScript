# nv-facutil-recur-ctx

> 标签: JavaScript

## 简介

nv-facutil-recur-ctx ======================= - to avoid using recursive-function-call, coz consteval recursion-function in compile-time is hard(especially for indirect/non-tail )  - nvlang has a compile-feature to convert recursive-function-call to while+
