# n8n-nodes-tiktok-events-api

> 标签: advertising, attribution, capi, conversions-api, events-api, n8n, n8n-community-node-package, pixel, server-side-tracking, tiktok

## 简介

Send server-side conversion events to the TikTok Events API from n8n, with customer information normalized and SHA-256 hashed to TikTok's spec.
