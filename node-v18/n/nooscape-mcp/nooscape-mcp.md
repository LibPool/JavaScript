# nooscape-mcp

> 标签: ai-agents, erc-8004, mcp, model-context-protocol, nooscape, x402

## 简介

MCP server for Nooscape: ask what is on record about an AI agent, a wallet or an endpoint before you pay it or rely on it. A read-only client of the public Nooscape API.
