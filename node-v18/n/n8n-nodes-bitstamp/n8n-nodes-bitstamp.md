# n8n-nodes-bitstamp

> 标签: automation, bitcoin, bitstamp, crypto, cryptocurrency, ethereum, exchange, n8n, n8n-community-node-package, staking, trading, workflow

## 简介

A comprehensive n8n community node for Bitstamp cryptocurrency exchange providing 6 resources and 40+ operations for trading, account management, market data, deposits, withdrawals, and staking.
