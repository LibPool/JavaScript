# n8n-nodes-postwire

> 标签: cross-posting, instagram, linkedin, n8n-community-node-package, postwire, scheduling, social media, tiktok, youtube

## 简介

Publish one idea natively to TikTok, Instagram, YouTube, LinkedIn, X, Bluesky, Mastodon, Telegram, Discord and Reddit from n8n — a different post written for each network, via PostWire.
