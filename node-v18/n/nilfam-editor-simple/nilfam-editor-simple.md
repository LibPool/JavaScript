# nilfam-editor-simple

> 标签: code-block, content-editing, custom-table, font-styling, nilfam-editor, nilfam-editor-simple, react, rich-text-editor, rtl-support, tailwindcss, text-editor, tiptap, wysiwyg

## 简介

A customizable rich-text editor built with TipTap, React, and Tailwind CSS. Supports RTL/LTR text, resizable media (images/videos), tables, code blocks, font styling, and more for an enhanced content creation experience.
