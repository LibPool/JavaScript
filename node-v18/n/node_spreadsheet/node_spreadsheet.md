# node_spreadsheet

> 标签: CSV, PHPExcel, excel, spreadsheet

## 简介

Node spreadsheet is a module to read and write Excel and CSV files using PHPExcel from phpexcel.codeplex.com.

## 官网

- 源码仓库：http://github.com/jessedpate/node_spreadsheet.git
- npm 页面：https://www.npmjs.com/package/node_spreadsheet

## 历史版本号

- 当前版本：1.0.0

- 1.0.0

## 获取地址

- npm 安装：`npm install node_spreadsheet`
- npm registry：https://registry.npmjs.org/node_spreadsheet
- Node 要求：>= 0.6.6
