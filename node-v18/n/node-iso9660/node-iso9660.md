# node-iso9660

> 标签: iso, iso9660

## 简介

This Node.js library uses C# WebAssembly to read files inside ISO files. The C# part leverages DiscUtils to manipulate the ISO file and Bootsharp to generate the WebAssembly and JavaScript glue code.
