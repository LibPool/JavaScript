# node-koa-cli

> 标签: generate-code, koa-cli, mongoose, mysql2, node-cli, restful, sequelize

## 简介

It is not only the project building tool of KOA, but also can quickly generate restful API and the most basic background management template. You only need to input one line of command and write some configuration files. Node koa cli will help you complet
