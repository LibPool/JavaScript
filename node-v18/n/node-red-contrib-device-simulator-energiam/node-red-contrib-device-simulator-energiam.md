# node-red-contrib-device-simulator-energiam

> 标签: energiam, iot, node-red, simulator, zigbee2mqtt

## 简介

Node-RED node to simulate IoT devices (e.g. zigbee2mqtt) injecting configurable JSON objects with variable fields and flexible trigger intervals
