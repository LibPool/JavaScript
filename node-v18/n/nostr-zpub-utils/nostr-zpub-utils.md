# nostr-zpub-utils

> 标签: bip32, bip39, bip84, bitcoin, commonjs, dual-module, esm, hd-wallet, litecoin, nostr, receiving-keys, slip-132, typescript, watch-only, zpub

## 简介

Derive Bitcoin/Litecoin receiving keys (BIP84 zpub → addresses) from the same BIP39 seed root that yields a Nostr identity. Seed-side derivation is enclave-only and outputs PUBLIC material exclusively; the watch-only public side mirrors hj-pay byte-for-by
