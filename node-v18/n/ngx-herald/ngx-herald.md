# ngx-herald

> 标签: alert, angular, ngx, notification, signals, toast, toastr, zoneless

## 简介

A lightweight, modern Angular toast notification library. Signals-first, zoneless-compatible, zero runtime dependencies, and an easy-to-use alternative to ngx-toastr.
