# nestjs-shared-auth

> 标签: auth, jwt, nestjs, shared

## 简介

A reusable JWT Authentication module for NestJS microservices. This package provides a shared JwtAuthSharedModule, JwtAuthGuard to handle authentication across multiple services with minimal setup.
