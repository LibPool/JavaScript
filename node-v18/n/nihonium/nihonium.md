# nihonium

> 标签: astronomy, cron, dawn, dusk, geolocation, scheduler, solar, sunrise, sunset, task

## 简介

A geolocation-aware solar task scheduler that triggers actions relative to astronomical solar cycles like sunrise, sunset, dawn, and dusk.
