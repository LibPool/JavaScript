# normalizedim

> 标签: N-dimensions, dimensions, geometry, math, micro-package, normalize, proportional, scaling, utilities

## 简介

Normalizes an N-dimensional array by setting one specific dimension to an exact value, while maintaining proportions for all other dimensions. It's an atomic, pure, and performant.
