# n8n-nodes-popbill

> 标签: korea, n8n, popbill, tax-invoice

## 简介

Unofficial n8n community node for the Popbill API (Korean e-tax invoice, cash receipt, SMS, fax). Not affiliated with Popbill. Work in progress.
