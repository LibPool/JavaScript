# normalize-human-name

> 标签: apostrophe, capitalization, case, crm, data-cleaning, data-normalization, formatting, forms, honorific, human-name, hyphenated, identity, input-cleanup, mac, mc, name, name-format, name-parser, normalize, normalize-human-name, normalizer, parser, proper-case, signup, string, string-utils, suffix, text, title-case, unicode

## 简介

🎓 Normalize real human names the way they’re actually written — fixes casing, particles, honorifics, suffixes, hyphenation, Mc/Mac and O’ prefixes into clean, properly formatted names.
