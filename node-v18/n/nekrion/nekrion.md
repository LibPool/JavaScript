# nekrion

> 标签: chainable, comparator, composable, data-analysis, data-evaluator, dataset, dynamic-methods, filter, functional, logic, nexkrion, search, typescript

## 简介

Type-safe, chainable dataset evaluator that dynamically generates logic-based search methods from a user-defined comparator.
