# news-volume-api

> 标签: analytics, growth-rate, journalism, media-monitoring, news-api, news-mentions, news-volume, trend-data, trendsmcp

## 简介

News article mention volume over time via REST API. Weekly series, period-over-period growth. No media database subscription required. Powered by trendsmcp.ai
