# ntag213-ndef

> 标签: ios, ndef, nfc, nfc-tag, ntag, ntag213, rfid, type-2-tag, web-nfc

## 简介

NDEF bytes that iOS background tag reading actually accepts, plus an NTAG213 lock verifier that reads the right page.
