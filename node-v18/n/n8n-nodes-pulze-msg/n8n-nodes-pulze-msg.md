# n8n-nodes-pulze-msg

> 标签: n8n-community-node-package, pulze, whatsapp

## 简介

Send and receive WhatsApp messages from n8n via the Pulze API — text, media, interactive buttons, instance management and a signature-verified webhook trigger.
