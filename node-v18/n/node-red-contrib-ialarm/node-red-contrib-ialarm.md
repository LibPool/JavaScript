# node-red-contrib-ialarm

> 标签: Antifurto365, Emoolux, Meian, alarm, iAlarm, node-red, tcp ip alarm

## 简介

A node-red node to control iAlarm (Antifurto365) or other chinese "TCP IP" alarm system like Meian and Emooluxr
