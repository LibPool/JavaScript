# n8n-nodes-eutexa

> 标签: crm, eutexa, n8n, n8n-community-node-package, pipeline, sales

## 简介

n8n community node for Eutexa CRM: contacts, companies, deals, tasks, tickets, sequences and email, plus a polling trigger.
