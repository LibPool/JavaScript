# nox-mongo-driver

> 标签: dynamic-schema, mongoose-alternative, multi-tenant, nox-mongo-driver, runtime-validation, sanitizer, schema, validation

## 简介

A fast runtime schema-driven sanitizer & validator for dynamic schemas — alternative to Mongoose validation for multi-tenant apps.
