# ngx-roslib

> 标签: ROS, angular, ngx-roslib, robot, ros, rosbridge, roslib, roslibjs, roslibts

## 简介

This package is an Angular service created to be an efficient ROSLIB interface in an Angular application. This package is based on the official Rosbridge Protocol 2.0
