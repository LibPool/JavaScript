## 简介

n8n node for Boomerang (GoHighLevel) AGENCY-level operations — create sub-accounts, apply snapshots, invite users. Uses its own boomerangProvisioningOAuth2Api credential (agency scopes only) with no location-token exchange. Sibling package to n8n-nodes-bo
