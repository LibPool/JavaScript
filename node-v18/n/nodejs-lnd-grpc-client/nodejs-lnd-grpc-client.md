## 简介

This package is a grpc client for [lnd](https://github.com/lightningnetwork/lnd)  v0.2.1-alpha. It is generated code from [rpc.proto](https://github.com/lightningnetwork/lnd/blob/2486097554baf8fe61b4e531e42d3c725dd0fca5/lnrpc/rpc.proto).
