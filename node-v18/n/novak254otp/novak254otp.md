# novak254otp

> 标签: one time code, one time password, one time pin, one time pincode, otc, otp, phone, react-native, sms, verifcation code, verification

## 简介

is a tiny JS library for one time passcode (OTP). Supports smart input suggestion on iOS and code autofill on Android (it will be filled when you press the copy button on the SMS notification bar), credit to the original authors
