# node-red-nfc

> 标签: JavaScript

## 简介

This is a Node-Red Module for reading and writing NFC cards with the AC122U. Based on Pokusew's npm module nfc-pcsc.

## 官网

- npm 页面：https://www.npmjs.com/package/node-red-nfc
