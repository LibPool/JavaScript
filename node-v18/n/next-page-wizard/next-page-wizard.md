# next-page-wizard

> 标签: nextjs, pages, wizard

## 简介

A lightweight and intuitive Next.js package for managing multi-step navigation in wizard-style applications.   With `next-page-wizard`, you can define a sequence of pages and seamlessly navigate between them using simple hooks and methods.
