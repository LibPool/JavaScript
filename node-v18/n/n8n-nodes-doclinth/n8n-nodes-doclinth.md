# n8n-nodes-doclinth

> 标签: doclinth, documents, html-to-pdf, invoice, n8n-community-node-package, pdf, pdf-generation, receipt, template

## 简介

n8n community node for Doclinth — generate pixel-perfect PDFs (invoices, receipts, reports, certificates) from templates + JSON. Deterministic rendering, no Chromium to run.
