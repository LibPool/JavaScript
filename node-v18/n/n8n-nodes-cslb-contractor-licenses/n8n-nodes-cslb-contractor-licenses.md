# n8n-nodes-cslb-contractor-licenses

> 标签: apify, n8n, n8n-community-node-package, n8n-nodes, scraping

## 简介

Look up California Contractors State License Board (CSLB) records by license number, city or classification. Returns business info, license status, classifications, bonding, workers' comp and personnel. Pay per result.
