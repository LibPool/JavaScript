# node-paperclip

> 标签: JavaScript

## 简介

paperclip like plugin that currently only is working with mongoose, but possibly other databases in the future.  The name is a reference to this library https://github.com/thoughtbot/paperclip which it tries to emulate but is currently not as complete in
