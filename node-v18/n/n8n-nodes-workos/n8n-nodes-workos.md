# n8n-nodes-workos

> 标签: authentication, directory-sync, enterprise, identity, n8n, n8n-community-node-package, oidc, saml, scim, sso, user-management, workos

## 简介

A comprehensive n8n community node for WorkOS providing 12 resources and 70+ operations for SSO, Directory Sync, user management, organizations, and audit logging. Includes webhook triggers for real-time event automation.
