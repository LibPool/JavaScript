# nod-package

> 标签: app-launcher, cli, desktop, fzf, launcher, nod, phosphorous, terminal, tiling

## 简介

A terminal-first app launcher — type an app name, it opens the GUI. Ships nod-grid for tiling on X11. From phosphorous.
