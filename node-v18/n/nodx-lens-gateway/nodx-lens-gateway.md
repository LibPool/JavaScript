# nodx-lens-gateway

> 标签: chrome-extension, claude, claude-code, gateway, local-ai, nodx

## 简介

Local AI gateway backed by the Claude Code CLI (claude -p). Lets nodx Lens (Chrome extension) and nodx desktop talk to your locally-authenticated Claude Code session — subscription or key, no API key pasted anywhere. Zero dependencies.
