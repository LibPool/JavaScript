# node-red-contrib-formulize

> 标签: condition-monitoring, drift-detection, equation-discovery, formulize, hvac, iot, machine-learning, modbus, mqtt, node-red, physics, predictive-maintenance, regression, sensor-analytics, sindy, solar, symbolic-regression

## 简介

Node-RED nodes for symbolic regression, prediction, and drift detection via the formulize.dev hosted API. Turn sensor/telemetry streams into human-readable physics equations, then use those equations for prediction and drift alarms.
