# npm-util

> 标签: auto, installer, npm, npm-wrapper, wrapper

## 简介

A Node.JS module, provides an object oriented wrapper util for the NPM API. It allow to automatically install modules for Node.js

## 官网

- 源码仓库：git://github.com/EladElrom/npm-util.git
- npm 页面：https://www.npmjs.com/package/npm-util
