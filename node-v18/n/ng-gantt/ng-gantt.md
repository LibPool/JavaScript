# ng-gantt

> 标签: angular, gantt, jsgantt, jsgantt-improved, ng-gantt

## 简介

Angular Gantt Editor (wrapper for [jsgantt-improved](https://github.com/jsGanttImproved/jsgantt-improved)). View/Edit Gantt file with formatting.
