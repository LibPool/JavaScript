# naija-id

> 标签: bvn, cac, naija, nigeria, nin, nuban, rsa-pin, tax-id, tin, vnin

## 简介

Zero-dependency validators, formatters and PII redaction for Nigerian identifiers — phone (E.164), NIN, vNIN, BVN, Tax ID, TIN, CAC, NUBAN, plate, passport, driver's licence and RSA PIN.
