# node-rtc-connection

> 标签: datachannel, dtls, encryption, ice, nat-traversal, p2p, peer-connection, peer-to-peer, real-time, relay, rtc, stun, tls, turn, webrtc

## 简介

WebRTC DataChannel implementation for Node.js with STUN, TURN, NAT traversal, and encryption. Pure Node.js, no native dependencies.
