# node-red-contrib-opcua-compact-server

> 标签: JavaScript

## 简介

A maintained fork of node-red-contrib-opcua-server: a compact, programmable OPC UA server for Node-RED, with sandbox timer/error-handling fixes and ongoing production-stability improvements.
