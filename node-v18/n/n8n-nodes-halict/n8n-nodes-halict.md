# n8n-nodes-halict

> 标签: form, halict, n8n, n8n-community-node-package, survey

## 简介

Halict（1問ずつ聞くフォームと、届いた回答の仕分け）の n8n ノード。フォームの作成や回答の更新に加えて、回答が届いた瞬間を受け取れます。

## 官网

- 官网：https://halict.com
- npm 页面：https://www.npmjs.com/package/n8n-nodes-halict

- 0.1.0

- npm registry：https://registry.npmjs.org/n8n-nodes-halict
