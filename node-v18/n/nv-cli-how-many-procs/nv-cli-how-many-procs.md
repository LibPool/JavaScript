# nv-cli-how-many-procs

> 标签: JavaScript

## 简介

nv-cli-how-many-procs ========== - cli tool - to test how many procs (nodejs )  could be created on your machine - each proc only has a http-server AND a aggressive SetInterval(timeout 1)
