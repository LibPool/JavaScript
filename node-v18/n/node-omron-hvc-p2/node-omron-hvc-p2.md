# node-omron-hvc-p2

> 标签: AGE ESTIMATION, BLINK ESTIMATION, EXPRESSION ESTIMATION, FACE DETECTION, FACE DIRECTION ESTIMATION, FACE RECOGNITION, GAZE ESTIMATION, GENDER ESTIMATION, HAND DETECTION, HUMAN BODY DETECTION, HVC-P2, Human Vision Components, OKAO, OMRON

## 简介

The node-omron-hvc-p2 is a Node.js module which allows you to communicate with the image sensing device "OMRON Human Vision Components (HVC-P2)" through a USB serial port.
