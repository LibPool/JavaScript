# nikud.js

> 标签: hebrew, nikud, niqqud

## 简介

jQuery plugin for [Hebrew Niqqud](https://en.wikipedia.org/wiki/Niqqud).
This plugin adds a Niqqud Toolbar to any HTML input element.
