# node-sbus-amqp10

> 标签: amqp, amqp 1.0, amqp-1-0, azure, messaging, queues, servicebus, topics

## 简介

Adapter for node-sbus module to use node-amqp-1-0 module for all AMQP calls.  node-amqp-1-0 has no native code.
