# npm-registry-fixer

> 标签: cnpm, mirror, nlark, npm, npmmirror, package-lock, pnpm-lock, registry, taobao, yarn.lock, 源修复, 镜像源

## 简介

修复 lock 文件与 .npmrc 中失效的 npm 镜像源域名(如 registry.nlark.com、registry.npm.taobao.org),一键替换为可用的 registry.npmmirror.com。零依赖,可通过 npx 直接运行。

## 官网

- npm 页面：https://www.npmjs.com/package/npm-registry-fixer

## 历史版本号

- 当前版本：1.0.0

- 1.0.0

## 获取地址

- npm 安装：`npm install npm-registry-fixer`
- npm registry：https://registry.npmjs.org/npm-registry-fixer
- Node 要求：>=14
