# n8n-nodes-dns-doctor

> 标签: dkim, dmarc, dns, email-security, n8n-community-node-package, propagation, spf

## 简介

n8n community node for DNS Doctor: scan, diagnose and fix a domain's SPF, DMARC and DKIM, check DNS propagation from six locations, audit SPF includes, and read monitoring alerts. Deterministic verdicts and copy-paste records from dnsdoctor.dev.
