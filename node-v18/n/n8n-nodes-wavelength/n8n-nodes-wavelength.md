# n8n-nodes-wavelength

> 标签: diagram, flowchart, mermaid, n8n-community-node-package, process map, wavelength

## 简介

n8n node for Wavelength: generate process flow diagrams from call notes and transcripts with the Wavelength REST API, then edit, review, summarize, and export them.
