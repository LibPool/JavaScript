# n8n-nodes-bybit

> 标签: api, automation, bybit, cryptocurrency, derivatives, exchange, futures, n8n, n8n-community-node-package, options, perpetual, spot, trading

## 简介

A comprehensive n8n community node for Bybit cryptocurrency exchange providing 11 resources and 100+ operations for spot trading, derivatives, options, account management, and more. Includes Unified Trading Account support and polling triggers.
