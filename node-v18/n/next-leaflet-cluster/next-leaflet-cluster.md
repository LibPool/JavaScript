# next-leaflet-cluster

> 标签: cluster, leaflet, map, marker-cluster, nextjs, react, react-leaflet-v4

## 简介

next-leaflet-cluster is a plugin for react-leaflet with nextjs. A wrapper component of Leaflet.markercluster.
