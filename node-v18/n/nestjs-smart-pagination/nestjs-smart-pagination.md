# nestjs-smart-pagination

> 标签: api, database, decorator, dto, interceptor, mongoose, nestjs, nodejs, orm, pagination, prisma, typeorm, typescript

## 简介

Smart, flexible pagination package for NestJS applications with support for TypeORM, Prisma, and Mongoose. Zero boilerplate, consistent API, and multi-ORM support.
