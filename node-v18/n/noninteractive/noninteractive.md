# noninteractive

> 标签: agent, ai-agent, automation, claude-code, cli, interactive, login, non-interactive, oauth, pty, terminal, tty

## 简介

Run interactive CLI commands (login flows, setup wizards, installers) non-interactively — a real-PTY session wrapper built for AI coding agents.
