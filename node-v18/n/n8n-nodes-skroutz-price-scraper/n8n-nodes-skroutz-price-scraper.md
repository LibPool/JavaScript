# n8n-nodes-skroutz-price-scraper

> 标签: apify, n8n, n8n-community-node-package, n8n-nodes, scraping

## 简介

Scrape Skroutz.gr, Greece's largest price-comparison site. Search any product and get the lowest price, number of offers, rating, review count, brand, URL and image — one clean row per product. Pay per result; residential proxy built in.
