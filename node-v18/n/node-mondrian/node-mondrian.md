# node-mondrian

> 标签: JavaScript

## 简介

Brings k-anonymity and l-diversity to nodeJS by using [Mondrian](https://github.com/qiyuangong/Mondrian) and [Mondrian_L_Diversity](https://github.com/qiyuangong/Mondrian_L_Diversity) under the hood.
