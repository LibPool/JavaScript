# no-axios

> 标签: HTTP, axios, noaxios, node

## 简介

NoAxios 是一个专为 Node.js 设计的轻量级 HTTP 客户端，支持拦截器、自动重试、代理池复用、智能响应解析（JSON/文本/流）、可定制重定向策略和连接复用，提供类 axios 的 API 设计但无浏览器依赖，具备请求超时控制、大文件流式处理和智能错误重试机制。
