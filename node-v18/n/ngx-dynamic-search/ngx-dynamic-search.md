# ngx-dynamic-search

> 标签: angular, angular-filter, angular-search, deep-search, dynamic-search, filter-pipe, frontend, nested-search, ngx, search-pipe, standalone-pipe, typescript, utility

## 简介

A high-performance, standalone Angular pipe for dynamic, deep search filtering across nested objects and arrays. Supports case sensitivity and property exclusion.
