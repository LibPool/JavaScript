# n8n-nodes-wecom-approval

> 标签: approval, n8n, n8n-community-node-package, wechat-work, wecom, weixin-work, workflow, 企业微信, 审批

## 简介

n8n 节点：批量导出企业微信审批流数据。支持按日期范围查询审批单号、批量获取审批详情、多条件过滤、自动分页与容错。
