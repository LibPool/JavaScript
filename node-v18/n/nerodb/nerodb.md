# nerodb

> 标签: commonjs, database, db, embed, embedded-database, encryption, es5, es6, esm, fast, file-based, josh, json, key-value, lightweight, nosql, persistence, storage, transactions, typescript, universal

## 简介

A lightweight, fast, and flexible JavaScript/TypeScript key-value database with JSON file persistence. Works with ES5, ES6, CommonJS, ESM, and TypeScript.
