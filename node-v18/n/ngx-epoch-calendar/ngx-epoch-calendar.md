# ngx-epoch-calendar

> 标签: JavaScript

## 简介

Welcome, this is an open source Angular event calendar component which was built to improve and replace FullCalendar in our booking-system. The goal is to improve both design flexibility but also improve performance when venues have a large amount of gues
