# noleak

> 标签: audit, crates, credentials, docker, leak-prevention, maven, noleak, npm, nuget, pre-publish, publish, pypi, security, source-map, vscode

## 简介

Pre-publish security gate for packages. Scans 10 ecosystems (npm, PyPI, Docker, Maven, etc.) for source maps, credentials, and sensitive files before they ship.
