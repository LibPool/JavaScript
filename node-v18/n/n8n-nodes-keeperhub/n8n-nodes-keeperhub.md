# n8n-nodes-keeperhub

> 标签: agent, automation, blockchain, ethereum, keeperhub, n8n-community-node-package, onchain, web3

## 简介

Execute onchain transactions from n8n via KeeperHub, simulate-first, idempotent, with retries, gas handling and a full audit trail. Usable as an AI Agent tool.
