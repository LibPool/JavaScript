# n8n-nodes-fondaro

> 标签: activities, automation, call-log, calls, crm, deals, fondaro, leads, n8n, n8n-community-node-package, real-estate, webhooks

## 简介

n8n community node for Fondaro CRM: manage leads, deals, tasks, notes and tags, report calls by recorded owner, read registered own-listing viewings, discover leads through semantic CRM history search and listing matching, and trigger signed CRM webhooks.
