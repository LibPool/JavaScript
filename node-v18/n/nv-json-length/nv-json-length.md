# nv-json-length

> 标签: JavaScript

## 简介

nv-json-length ======================= - get json's string-length  AND buffer-size without stringify-it - its simple, just using a fixed length-lookup-array to increase the speed - slightly faster  IF size < 1M;   30%~50% faster IF size >8M
