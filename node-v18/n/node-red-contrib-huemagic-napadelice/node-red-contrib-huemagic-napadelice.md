# node-red-contrib-huemagic-napadelice

> 标签: api, contrib, home-automation, hue, iot, node-red, node-red-contrib, philips, smart-home

## 简介

Philips Hue node to control bridges (including Bridge Pro), lights, groups, scenes, rules, taps, tap dial, switches, buttons, motion sensors, temperature sensors and Lux sensors using Node-RED. Fork of node-red-contrib-huemagic with added Bridge Pro suppo
