# next-dev-inspector

> 标签: app-router, click-to-component, component-inspector, debug, debugging, dev-inspector, devtools, dx, i18n, inspector, next, nextjs, open-in-editor, re-render, react, react-devtools, source-map, turbopack

## 简介

Dev-only floating inspector for Next.js + React 18/19: click any DOM element to open its source file in your editor (click-to-component), view live props and store state, reverse-lookup i18n keys, flash component re-renders, and copy element context for A
