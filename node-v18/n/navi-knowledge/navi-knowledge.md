# navi-knowledge

> 标签: knowledge, mcp, memory, model-context-protocol, navi

## 简介

Navi 认知 MCP server —— 让 Claude Code / Codex / Cursor 等工具通过 MCP 查询、更新 Navi 认知库，说「记住xxx」即可写入 Navi「记忆」
