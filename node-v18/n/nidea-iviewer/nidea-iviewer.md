# nidea-iviewer

> 标签: canvas, image, image-previewer

## 简介

A powerful yet lightweight JavaScript library for previewing images on a canvas. No frameworks, no fluff—just raw, pixel-moving, zoom-loving, crosshair-placing goodness.
