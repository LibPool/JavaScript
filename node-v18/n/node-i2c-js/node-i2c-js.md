# node-i2c-js

> 标签: JavaScript

## 简介

Forked from node-i2c@0.2.5, converted to async/promise based responses. Native bindings for i2c-dev. Plays well with Raspberry Pi and BeagleBone. Updated to remove coffee script and underscore dependancies, add extra functionality
