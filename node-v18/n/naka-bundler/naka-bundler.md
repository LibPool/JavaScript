# naka-bundler

> 标签: JavaScript

## 简介

The naka bundler is a light CLI wrapper around [bun](https://bun.sh/). It lives as an executable that bundles and transpiles JavaScript/TypeScript files. It's used under the hood in naka to transform files for browser automation.
