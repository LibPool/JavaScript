# nixparse

> 标签: cli, df, du, free, ip, lsof, mount, parser, ps, ss, typescript, unix, uptime, zod

## 简介

Type-safe parsers for Unix command output (ps, df, du, free, lsof, mount, who, uptime, ip, ss) with runtime validation via Zod
