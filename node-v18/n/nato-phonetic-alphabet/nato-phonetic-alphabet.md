# nato-phonetic-alphabet

> 标签: Alfa, Alpha, Alphabet, Aviation, Beta, Bravo, Converter, JSON, List, NATO

## 简介

This tiny npm package contains the full NATO phonetic alphabet (present "International aviation" variant), a basic string converter and placeholder generator.
