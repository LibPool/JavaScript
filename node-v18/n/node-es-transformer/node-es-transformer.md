# node-es-transformer

> 标签: arrow, bulk-indexing, csv, data-ingestion, data-transformation, elasticsearch, elasticsearch-8, elasticsearch-9, elasticsearch-client, etl, json, large-files, migration, nodejs, parquet, reindex, streaming

## 简介

Stream-based library for ingesting and transforming large data files (CSV/JSON) into Elasticsearch indices. Supports ES 8.x and 9.x with cross-version reindexing.
