# node-bpg

> 标签: bpg, node-bpg

## 简介

A nodejs wrapper that generating bpg image files by using pre-compiled libbpg (http://bellard.org/bpg/).

## 官网

- 官网：https://github.com/thammin/node-bpg
- 源码仓库：git+https://github.com/thammin/node-bpg.git
- npm 页面：https://www.npmjs.com/package/node-bpg

## 历史版本号

- 当前版本：1.0.0

- 0.1.1
- 1.0.0

## 获取地址

- npm 安装：`npm install node-bpg`
- npm registry：https://registry.npmjs.org/node-bpg
- Node 要求：>=4
