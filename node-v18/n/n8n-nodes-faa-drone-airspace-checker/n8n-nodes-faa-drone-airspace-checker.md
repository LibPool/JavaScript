# n8n-nodes-faa-drone-airspace-checker

> 标签: airspace authorization, apify, drone airspace, drone compliance, faa, laanc, n8n, n8n-community-node-package, n8n-nodes, no-fly zone, part 107, uas

## 简介

n8n community node for the Apify FAA Drone Airspace Checker actor: batch lat/lon to FAA UAS airspace verdicts -- LAANC ceilings and availability, charted Class B/C/D/E surface areas, prohibited areas, national-defense TFR areas and special use airspace.
