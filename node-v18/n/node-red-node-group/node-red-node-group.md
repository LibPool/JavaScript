# node-red-node-group

> 标签: node-red

## 简介

A Node-RED node to allow flows containing groups to be imported into Node-RED 1.0.x or earlier.

## 官网

- 源码仓库：https://github.com/node-red/node-red-nodes/tree/master/utility/group
- npm 页面：https://www.npmjs.com/package/node-red-node-group
