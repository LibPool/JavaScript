# n8n-nodes-krova

> 标签: automation, cloud, cube, cubes, firecracker, iaas, infrastructure, krova, krova-cloud, microvm, n8n, n8n-community-node-package, n8n-node, provisioning, server, vm

## 简介

n8n community node for Krova Cloud — create, start, power off, restart, list, and delete Cubes (Firecracker microVMs), manage domains, snapshots and TCP mappings, and read regions, images and pricing via the Krova Cloud API.
