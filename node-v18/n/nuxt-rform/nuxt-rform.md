# nuxt-rform

> 标签: form-builder, forms, i18n, mask, nuxt, nuxt-module, nuxt4, tailwindcss, typescript, validation, vue, zod

## 简介

Composable form fields for Nuxt: the model, the types and the validation all come from the field itself. Zod rules, input masks, dynamic schemas and i18n included.
