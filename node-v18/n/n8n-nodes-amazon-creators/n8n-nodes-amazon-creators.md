# n8n-nodes-amazon-creators

> 标签: affiliate, amazon, creators-api, e-commerce, n8n-community-node-package, paapi, product-search

## 简介

n8n community node for Amazon Creators API (replacement for PA-API 5.0): SearchItems, GetItems, GetBrowseNodes, GetVariations with OAuth 2.0 auth and token caching.

## 官网

- 官网：https://affiliate-program.amazon.com/creatorsapi/docs/en-us/introduction
- 源码仓库：git+https://github.com/vmarquesz/n8n-nodes-amazon-creators.git
- npm 页面：https://www.npmjs.com/package/n8n-nodes-amazon-creators
