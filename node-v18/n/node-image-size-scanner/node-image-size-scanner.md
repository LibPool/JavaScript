# node-image-size-scanner

> 标签: bytes, cli, dimensions, filesize, image, jpeg, jpg, monitor, monitoring, png, scan, scan for missing images, scanner, size, tool, utility, web, website

## 简介

For a given URL, report image file sizes and paths that exceed a threshold value as well as non-200 status codes. Follows redirects.
