# n8n-nodes-n8nchatui

> 标签: chat, n8n-community-node-package, n8nchatui, webhook

## 简介

n8n community nodes for n8nChatUI: a webhook trigger and a response node for building n8nChatUI-connected chat workflows without an AI-tool/LangChain dependency.
