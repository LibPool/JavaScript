# n8n-nodes-truthbear

> 标签: n8n, n8n-community-node-package, official-data, provenance, truthbear, verification

## 简介

Official-source records for AI agents: source URL, offline-recomputable record_hash, freshness and a did:key signature. Free lookups plus a live price quote; this node never pays and never takes a key.
