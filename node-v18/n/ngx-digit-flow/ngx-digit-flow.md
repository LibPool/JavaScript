# ngx-digit-flow

> 标签: angular, animation, counter, digit, number, odometer, signals, slot-machine, waapi

## 简介

Slot-machine digit animations for Angular 17+. No animation libraries. Signals-first. SSR-safe. Built on Web Animations API.
