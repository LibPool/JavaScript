# ngx-form-rules

> 标签: angular, angular validation, bl2, conditional forms, declarative forms, dynamic forms, form control, form management, form rules, form utility, ngx-form-rules, reactive forms

## 简介

Powerful rules engine for Angular Reactive Forms. Dynamically enable, disable, and control form fields using declarative rules without manual subscriptions.
