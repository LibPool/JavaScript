> 标签: blockchain, defi, ethereum, evm, layer2, matic, n8n, n8n-community-node-package, nft, polygon, smart-contracts, web3, zkevm

## 简介

A comprehensive n8n community node for Polygon blockchain (PoS and zkEVM) providing 7 resources and 30+ operations for accounts, transactions, tokens, NFTs, smart contracts, and real-time event monitoring.
