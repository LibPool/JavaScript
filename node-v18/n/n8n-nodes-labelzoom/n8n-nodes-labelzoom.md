# n8n-nodes-labelzoom

> 标签: barcode, dpl, epl, label, labelzoom, n8n-community-node-package, pdf-to-zpl, thermal-printer, tspl, zebra, zpl

## 简介

n8n community node for LabelZoom — convert barcode labels between ZPL, EPL, TSPL, DPL, PDF and images, and print them to cloud-connected thermal printers
