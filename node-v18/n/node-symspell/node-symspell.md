# node-symspell

> 标签: JavaScript

## 简介

JavaScript port of SymSpell 6.6 based on the [original C# version by Wolf Garde](https://github.com/wolfgarbe/SymSpell) and the [Python version by mammothb](https://github.com/mammothb/symspellpy).

## 官网

- npm 页面：https://www.npmjs.com/package/node-symspell

## 历史版本号

- 当前版本：0.1.0

- 0.1.0

## 获取地址

- npm 安装：`npm install node-symspell`
- npm registry：https://registry.npmjs.org/node-symspell
- Node 要求：12.x
