# ng-inapp-dev-tool

> 标签: angular, assets, change-detection, components, debugging, developer-tools, devtools, in-app, inspector, ngrx, ngxs, profiler, routes, seo, signals, state

## 简介

In-app developer tools for Angular — inspect and edit component state, browse routes, profile change detection, audit SEO tags, and watch NgRx/NGXS state directly inside your running app. Inspired by Nuxt DevTools.
