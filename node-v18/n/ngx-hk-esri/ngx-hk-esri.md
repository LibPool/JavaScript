# ngx-hk-esri

> 标签: angular, esri, hk-esri

## 简介

A modern Angular 20 library powered by ArcGIS Maps SDK for JavaScript and Hong Kong vector-tile services Supports Pin-Point, Image, and Simple markers with optional text labels.
