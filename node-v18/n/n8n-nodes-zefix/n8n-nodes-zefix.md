# n8n-nodes-zefix

> 标签: commercial-register, handelsregister, n8n-community-node-package, switzerland, uid, zefix

## 简介

Read the Swiss commercial register (Zefix) from n8n: look a company up by UID or EHRA ID, and search the register by name
