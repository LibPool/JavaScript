# ngx-accessible-dropzone

> 标签: a11y, accessibility, angular, angular-component, drag-and-drop, dropzone, file-input, file-upload, ngx, standalone

## 简介

A tiny, zero-dependency, fully accessible drag-and-drop file upload component for Angular (standalone). Keyboard-operable, screen-reader friendly, themeable, with optional size validation.
