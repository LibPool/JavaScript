# n8n-nodes-concordance

> 标签: corroboration, data, n8n-community-node-package, payments, search, x402

## 简介

Cross-source search, corroboration, and structured data (18 real-time sources: news, SEC filings, court opinions, academic papers, economic indicators, market data) via Concordance, paid per call in USDC on Base through x402 -- no API keys.
