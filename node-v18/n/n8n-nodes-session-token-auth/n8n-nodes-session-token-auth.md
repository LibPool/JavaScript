# n8n-nodes-session-token-auth

> 标签: authentication, credential, n8n, n8n-community-node-package, session-token

## 简介

n8n credential type (plus a small helper node) for APIs that log in with username/password, get back a session token, and send that token in a header on every subsequent request.
