# nano-wc

> 标签: astro, custom-elements, lightweight, nanostores, reactive, typescript, web-components

## 简介

Tiny Web Components wrapper with nanostores reactivity. No Shadow DOM, typesafe builder, props/refs, automatic cleanup, all under 3 KB.
