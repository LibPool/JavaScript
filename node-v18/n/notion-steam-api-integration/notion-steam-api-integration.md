# notion-steam-api-integration

> 标签: notion, notion-api, notion-database, notion-integration, steam, steam-api, steam-app-id

## 简介

Notion integration that watches a database for Steam App IDs and fills in game data (name, cover, tags, reviews, price and more) from the Steam API.
