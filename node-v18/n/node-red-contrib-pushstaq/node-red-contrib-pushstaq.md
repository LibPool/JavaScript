# node-red-contrib-pushstaq

> 标签: alert, bookmark, chat, flows, node-red, nodes, notification, push, web push

## 简介

The most simple way to trigger real time push notifications from Node-Red to your mobile and desktop devices. Official PushStaq node for Node-Red.
