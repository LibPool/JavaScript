# node-c-tape

> 标签: JavaScript

## 简介

This is a C++ variant of my [json-tape](https://github.com/matthewpalmer/json-tape) library with bindings for Node.js. This lets you replay a set of mutations to an initial JSON state. Take a look at that repo for more information on the instruction forma
