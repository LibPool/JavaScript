# navalone

> 标签: drawer, dropdown, hamburger, mega-menu, menu, mmenu-alternative, mobile-menu, navbar, navigation, off-canvas, responsive

## 简介

A free, open-source responsive main-menu plugin — desktop dropdowns, multi-level menus and mega menus that collapse to a sliding mobile drawer. A free alternative to mmenu.js.
