# nestjs-axios-undici

> 标签: @nestjs/axios, axios, drop-in, fast, http, http-client, httpmodule, httpservice, interceptors, nest, nestjs, undici

## 简介

Drop-in @nestjs/axios replacement built on Undici: the same HttpModule/HttpService API and axios-compatible responses, errors and interceptors, with much lower latency.
