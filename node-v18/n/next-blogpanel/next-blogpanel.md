# next-blogpanel

> 标签: blog, blog-engine, cms, editor, gridfs, mongodb, nextjs, seo, tiptap

## 简介

A drop-in blog engine for Next.js — admin panel, block editor, SEO, and media, all backed by your own MongoDB.
