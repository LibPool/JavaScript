# nextjs-dev-browser

> 标签: browser, dev-server, developer-tools, localhost, next.js, nextjs, playwright

## 简介

Ephemeral, localhost-only Playwright browser that auto-opens when `next dev` starts and wipes cache/cookies/storage on close — without touching your everyday browser profile.
