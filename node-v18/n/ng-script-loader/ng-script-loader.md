# ng-script-loader

> 标签: JavaScript

## 简介

`ng-script-loader` is a very simple external script loader for Angular 6+. You can use it to load 3rd part scripts dynamically, or settings from your server.

- 源码仓库：https://github.com/ankemp/mono
