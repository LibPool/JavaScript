# ngx-seedkit

> 标签: JavaScript

## 简介

**ngx-seedkit** is a lightweight and customizable **wallet connection library** for **Angular**, inspired by RainbowKit. Built on top of **ngx-wagmi**, it provides an elegant solution to integrate Web3 wallet connection features into your Angular applicat
