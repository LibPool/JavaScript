# nearly-cli

> 标签: agent-supervision, claude-code, code-review, coding-agent, hooks, pull-request

## 简介

A pull request tells you what changed. Nearly tells you what nearly happened: the commands a human refused, the pushes policy blocked, the turns rolled back.
