# n8n-nodes-keenable

> 标签: ai-agent, ai-tool, fetch, keenable, n8n, n8n-community-node-package, scraping, search, web-search

## 简介

Keenable web search + page fetch nodes for n8n. Keyless by default (1,000 req/hour); an API key raises the limits.
