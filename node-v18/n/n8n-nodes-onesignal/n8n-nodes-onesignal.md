# n8n-nodes-onesignal

> 标签: automation, email, messaging, mobile, n8n, n8n-community-node-package, notifications, onesignal, push-notifications, sms

## 简介

A comprehensive n8n community node for OneSignal providing 8 resources and 30+ operations for push notifications, email, SMS, user management, segments, templates, and analytics.
