# n8n-nodes-zefix-shab

> 标签: commercial-register, handelsregister, n8n-community-node-package, shab, switzerland, uid, zefix

## 简介

Read the Swiss commercial register (Zefix) and its official gazette (SHAB) from n8n: company lookup, name search, publications, and a polling trigger with event classification
