# ngx-logger-icy

> 标签: angular, angular2, log, logger, ng, ng2, ngx-log, ngx-logger

## 简介

angular9+以上的版本可以使用；继承console上的方法，可以根据环境变量控制log是否输出，解决开发环境需要打印一些log日志但是生产环境并不需要
