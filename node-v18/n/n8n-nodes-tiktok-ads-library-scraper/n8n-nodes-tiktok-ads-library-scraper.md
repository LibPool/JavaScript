# n8n-nodes-tiktok-ads-library-scraper

> 标签: apify, n8n, n8n-community-node-package, n8n-nodes, scraping

## 简介

Scrape TikTok's Commercial Content Library via the official open.tiktokapis.com API. Search ads by keyword or advertiser business ID across EU/EEA/UK regions. Returns creatives, video URLs, reach buckets, targeting, and advertiser metadata. Official API =
