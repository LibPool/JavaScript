# n8n-nodes-trendsmcp

> 标签: amazon, google-trends, market-research, n8n, n8n-community-node-package, reddit, seo, tiktok, trends, trendsmcp, youtube

## 简介

n8n community node for TrendsMCP. Query behavioral trend data across Google, YouTube, TikTok, Reddit, Amazon, Wikipedia, npm, Steam and more. One API key, three operations: time series, growth, and live top trends.
