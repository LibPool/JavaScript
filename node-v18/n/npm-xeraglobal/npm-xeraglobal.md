# npm-xeraglobal

> 标签: npm, npm-cli, npm-cli-modifier, npm-xeraglobal, npmx, xeraglobal

## 简介

Tool for one-time installation of modules for each project to %HOMEPATH%/.npm_modules (Windows and Linux only)
