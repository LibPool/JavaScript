# n8n-nodes-letsbot

> 标签: crm, letsbot, n8n, n8n-community-node-package, n8n-node, whatsapp

## 简介

n8n community nodes for LetsBot: send WhatsApp messages and templates, manage contacts and labels, and trigger workflows from LetsBot events.
