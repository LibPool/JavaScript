# ngx-pdf-export

> 标签: angular, client-side-pdf, dom-to-pdf, html-to-pdf, pdf, pdf-export

## 简介

DOM-aware, client-side Angular library that exports rendered HTML into a real, text-selectable PDF (no screenshot rasterization).
