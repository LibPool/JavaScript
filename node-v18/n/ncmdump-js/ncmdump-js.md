# ncmdump-js

> 标签: browser, decrypt, flac, mp3, ncm, ncmdump, netease, netease-cloud-music

## 简介

纯前端解密网易云音乐 ncm 加密文件，输出 mp3/flac，支持写入歌曲信息与封面
