# node-red-contrib-dwd-rainradar

> 标签: dwd, node-red, radar, radolan, rain, weather

## 简介

A Node-RED node to access the German Weather Service (DWD) rain radar data (RADOLAN). Supports summary values, full grid extraction and optional image output.
