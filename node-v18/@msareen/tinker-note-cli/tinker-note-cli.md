# @msareen/tinker-note-cli

> 标签: agent-skill, api, cli, llm, markdown, notes, tinker-note

## 简介

Headless, LLM-friendly CLI and programmatic API for a tinker-note vault. Authenticates with a per-user Ed25519 API key and reads/writes notes over the REST API.
