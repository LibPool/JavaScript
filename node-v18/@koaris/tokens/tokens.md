# @koaris/tokens

> 标签: colors, koaris, tokens

## 简介

Design tokens for the Koaris Technologies's bloom-ui design system. These tokens define the visual design primitives such as colors, typography, spacing, etc., providing a consistent style across the entire bloom-ui design system.
