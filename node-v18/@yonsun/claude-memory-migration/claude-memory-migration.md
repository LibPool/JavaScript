# @yonsun/claude-memory-migration

> 标签: ai-tool, backup, claude-code, export, import, memory, migration, skill

## 简介

Claude Code unified memory migration tool. Export all memories and configs from old computer, restore them on new computer with unified project management. Solve path dependency issues for seamless migration.
