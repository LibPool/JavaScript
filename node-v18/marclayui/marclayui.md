# marclayui

> 标签: claymorphism, component-library, components, css, dark-mode, design-system, neumorphism, nextjs, react, theming, ui

## 简介

Claymorphism + neumorphism React component library with light/dark theming and runtime color control. Zero runtime dependencies, TypeScript-first, Next.js ready.
