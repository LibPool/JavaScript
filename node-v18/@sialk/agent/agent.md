# @sialk/agent

> 标签: JavaScript

## 简介

What an agent needs to write a Sialk sketch: the frozen contract, the kinds Sialk plays (GLSL, p5, Three.js), three worked examples, and a static check for what it wrote. An MCP server over stdio, a command line, and a skill.
