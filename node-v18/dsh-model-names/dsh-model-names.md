# dsh-model-names

> 标签: display-name, dsh, dsh-bundle, dsh-plugin, llm

## 简介

内置 provider / 模型显示名的全量数据库：载入时按环境里实际启用的 provider 与模型覆盖显示名，只影响 UI，不改路由、请求与凭据。
