# @medicine-wheel/github-ceremony

> 标签: ceremony, four-directions, github-ceremony, indigenous-research, medicine-wheel, relational-accountability, webhook

## 简介

GitHub-ceremony processing — witness GitHub webhook events (issues, pull requests, merges, commits) through a ceremonial lens and record them as relational ceremony beads. Pure, framework-free functions that take a parsed payload and a @medicine-wheel/sto
