# @intenttext/pdf

> 标签: erp, intenttext, invoice, pdf, print, server

## 简介

Server-side PDF generation for IntentText (.it) documents — merge, seal, and render real PDF bytes for emailing and archiving. Opt-in companion to @intenttext/core.
