# @struggler/vite-plugin-mpa

> 标签: html, mpa, multi-page, vite, vite-plugin

## 简介

Vite MPA: input keys map to dist HTML paths; virtual resolve, dev middleware (pre), relative script rewrite, optional HTML minify.
