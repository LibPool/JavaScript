# @vyonio/player

> 标签: JavaScript

## 简介

Shared Shaka playback lifecycle with optional audio or video presentation. Video uses bundled Plyr styles/icons and falls back to native `<video controls>` if Plyr initialization fails. Audio uses its own accessible controls and never creates Plyr. Stream
