# @mysten-incubation/memwal-mcp

> 标签: ai, claude, cursor, mcp, memory, memwal, model-context-protocol, walrus, walrus-memory

## 简介

Walrus Memory MCP client — single-binary stdio MCP server that bridges Cursor / Claude Desktop / Antigravity / Claude Code to the Walrus Memory relayer. Handles browser-based wallet login on first run.
