# @hivetrail/mcpaccess-core

> 标签: access-control, authentication, authorization, mcp, modelcontextprotocol, nodejs, security

## 简介

Core library for Model Context Protocol (MCP) access control. Includes essential types, interfaces, and utility functions to build consistent authentication and authorization across MCP tools, resources, and prompts in Node.js environments.
