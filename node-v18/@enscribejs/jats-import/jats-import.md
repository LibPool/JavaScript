# @enscribejs/jats-import

> 标签: academic-publishing, enscribe, import, jats, scholarly-publishing, xml

## 简介

JATS XML import for enscribe — parses a JATS article and produces an Enscribe mdast tree (the reverse of @enscribejs/jats-export).
