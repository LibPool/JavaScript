# @enscribejs/cli

> 标签: academic-publishing, cli, command-line, enscribe, jats, scholarly-publishing

## 简介

The `enscribe` command-line tool — render Enscribe documents to HTML, exchange JATS XML (export and import), import other formats via a pandoc bridge, and rewrite source between authoring registers.
