# @openfaster-standard/write-client

> 标签: citation, github, openfaster, rdf, shacl

## 简介

OpenFASTER's write client -- commits a re-citation (a corrected XPath selector on an existing SHACL property shape) via GitHub's Content API, client-side, no backend.
