# @juancarlosrmr/node-sftp-deploy-sp

> 标签: client, deploy, deployment, file, files, protocol, server, sftp, transfer, upload

## 简介

Clase que facilita el despliegue de archivos con SFTP mediante nombre de usuario y contraseña y el uso de eventos. Desarrollado para proyectos de Centro de observación y teledetección espacial.
