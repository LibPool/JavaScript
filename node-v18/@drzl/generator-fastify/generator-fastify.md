# @drzl/generator-fastify

> 标签: ajv, codegen, drizzle, drizzle-orm, fastify, rest

## 简介

Generate Fastify 5 plugins from a Drizzle schema, one route module per table, with generated schemas fed straight into Fastify's own AJV validation and fast-json-stringify serialization.
