# @kibowork/mcp

> 标签: claude, kibo, llm, mcp, model-context-protocol, project-management, tasks

## 简介

Stdio bridge to Kibo's MCP endpoint, for clients that cannot open a remote URL (Claude Desktop, Cursor, …). The tool catalogue is served by Kibo itself; this only forwards messages and holds the API key, which the LLM never sees.
