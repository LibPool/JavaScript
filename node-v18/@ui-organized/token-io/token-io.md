# @ui-organized/token-io

> 标签: design-tokens, dtcg, export, import, tokens-studio

## 简介

Serialize/deserialize the project document and import/export adapters (DTCG, Tokens Studio, GitHub, Supabase) plus the non-destructive reconciler. Pack-agnostic.
