# @liha-css/reset

> 标签: JavaScript

## 简介

`@liha-css/reset` は **Void Reset（全破壊型リセットCSS）** を配布します。 ブラウザ標準の見た目（margin / padding / font-size / font-weight / list marker / form UI …）を **ほぼすべて消し飛ばし**、アプリ側でゼロから再構築する前提です。
