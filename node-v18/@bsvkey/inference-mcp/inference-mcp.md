# @bsvkey/inference-mcp

> 标签: agents, bsv, claude, grok, http-402, inference, mcp, micropayments, model-context-protocol, pay-per-token, x402, xrp, xrpl

## 简介

MCP server: buy Claude & Grok inference metered per token through the hosted inference.bsvkey.com gateway. Pay with BSV (channels or per-call x402) or per call in XRP on the XRP Ledger.
