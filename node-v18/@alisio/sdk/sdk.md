# @alisio/sdk

> 标签: agent-harness, ai, coding-agent, llm, openai-compatible, plugins, sdk, typescript

## 简介

Typed plugin SDK for Alisio: the stable contract for tools, commands, context, compaction and session hooks, model completions and storage. Types only plus tiny helpers; zero runtime dependencies.
