# @alisio/plugin-laya

> 标签: alisio-plugin, decision-intelligence, decisions, laya, local

## 简介

Local Laya decision provider for Alisio: fast select, boolean and ordinal decisions from a managed, isolated Laya server, with explicit-consent setup and no data leaving the machine.
