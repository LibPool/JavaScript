# @alisio/plugin-swarm

> 标签: agent-swarm, alisio-plugin, git-worktree, methodology, multi-agent

## 简介

Runs a handoff-driven swarm of specialised agents, each in its own git worktree, with durable handoffs, deterministic quality gates and a human approval gate.
