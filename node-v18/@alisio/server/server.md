# @alisio/server

> 标签: agent-harness, ai, coding-agent, server, sse, web-ui

## 简介

Local HTTP + SSE server behind `alisio serve`: multi-workspace, multi-session web access to the Alisio agent core with a launch-token cookie, strict Host/Origin checks and fail-closed approvals. node:http only; runs on Node >=22.16 and Bun.
