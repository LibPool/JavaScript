# dsh-cross-workspace-memory

> 标签: cross-workspace, deepseek-harness, dsh, dsh-plugin, memory, recall

## 简介

Cross-workspace long-term memory for DeepSeek Harness: one machine-local store shared by every workspace, a compact index injected at session start, and a searchable tool for the details.
