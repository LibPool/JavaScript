# static-link-sentinel

> 标签: 404, astro, broken-links, ci, dead-links, dist, eleventy, github-action, hugo, link-checker, markdown, netlify, nextjs, redirects, sarif, sitemap, static-site, vercel, vite, vite-plugin, webpack-plugin

## 简介

Crawl a static build (dist/, build/, out/, public/, _site/) before deploy and fail CI on broken internal links, missing assets, case-mismatched paths, missing #anchors and dead or redirecting external links. CLI, API, Vite and webpack plugins, GitHub Acti
