# @spree/dashboard-ui

> 标签: admin, commerce, dashboard, ecommerce, react, spree

## 简介

Spree Dashboard design system — shadcn primitives, headless composed components, and design tokens. Source-only package; consumers compile via their own Vite/Tailwind setup. Developer Preview.
