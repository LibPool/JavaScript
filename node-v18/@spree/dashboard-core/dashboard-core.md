# @spree/dashboard-core

> 标签: admin, commerce, dashboard, ecommerce, plugin, react, spree

## 简介

Spree Dashboard framework — registries (table, nav, slot, settings-nav), providers (auth, permission, store), admin SDK client, generic infra hooks, and the defineDashboardPlugin extension API. Developer Preview.
