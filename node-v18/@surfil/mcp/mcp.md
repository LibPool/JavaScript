# @surfil/mcp

> 标签: ai, mcp, observability, session-tracking, surfil

## 简介

Surfil MCP server — bridges MCP-capable editors (Cursor, VS Code, Codex, Zed, Continue, Windsurf, etc.) to the local surfil CLI. Canonical npm name; republishing after npm 24h lock expires.
