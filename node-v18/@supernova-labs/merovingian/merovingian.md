> 标签: agents, bun, claude-code, cli, codex, governance, mcp, merovingian, purpose-graph, surrealdb

## 简介

Merovingian OS — a declarative engine that projects a tenant's purpose graph into scoped Claude Code and Codex workspaces, and reconciles it with `deploy`.
