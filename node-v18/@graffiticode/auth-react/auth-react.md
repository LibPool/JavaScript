# @graffiticode/auth-react

> 标签: JavaScript

## 简介

Shared Graffiticode auth: SIWE (wallet) + Privy email sign-in + Firebase token exchange + cross-app SSO. Consumed by app.graffiticode.org and console.graffiticode.org.
