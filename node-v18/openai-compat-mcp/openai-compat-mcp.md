# openai-compat-mcp

> 标签: claude, cursor, deepseek, gateway, llm, mcp, mcp-server, openai, openai-compatible, qwen, zhipu

## 简介

Bridge any OpenAI-compatible API (DeepSeek / Zhipu / Qwen / Moonshot / self-hosted vLLM) into a Model Context Protocol server for Claude Desktop, Cursor and other MCP clients.
