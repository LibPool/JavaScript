# @mediansh/widget

> 标签: ai, bug-report, chat, contact-form, customer-support, feedback, helpdesk, modal, support, widget

## 简介

The Median widgets: a support panel an AI agent answers first, the same panel as a modal, a contact form that starts the conversation, and a feedback panel a model files for you. One component each, or one mount call.
