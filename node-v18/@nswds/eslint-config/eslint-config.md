# @nswds/eslint-config

> 标签: eslint, eslint-config, eslintconfig, flat-config, nextjs, nsw-government, nswds, prettier

## 简介

Shared ESLint flat config for the NSW Design System fleet — Next.js ('.') and framework-free ('./base') entry points, both with Prettier as a rule.
