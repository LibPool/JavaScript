# @anyreplay/tauri

> 标签: anyreplay, desktop, session-recording, session-replay, tauri

## 简介

Session replay for Tauri v2 apps: records the window with the AnyReplay browser SDK, reports the app's identifier and version, and flushes when the window loses focus.
