# @clawchat-agent/cli

> 标签: agent, clawchat, cli, hermes, openclaw

## 简介

Runtime-neutral command to connect an agent to ClawChat: install + activate the clawchat-agent plugin into a supported runtime (OpenClaw, Hermes).
