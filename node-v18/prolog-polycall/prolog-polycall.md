# prolog-polycall

> 标签: foreign-interface, libpolycall, peer-to-peer, polycall, prolog, swi-prolog

## 简介

SWI-Prolog foreign library for the Polycall binding ABI v1 (libpolycall >= 1.1.0): config validation, RPC calls and peer nodes
