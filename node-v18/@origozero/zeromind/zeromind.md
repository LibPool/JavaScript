# @origozero/zeromind

> 标签: claude-code, cline, codex, continue, cursor, gemini-cli, mcp, opencode, origozero, windsurf, zed, zero-engine, zeromind

## 简介

Links a machine to ZeroMind and points an agent harness at the ZeroMind MCP server at origozero.ai/mcp (Claude Code, Cursor, Codex, Gemini CLI, OpenCode, Cline, Continue, Windsurf, Zed, …)
