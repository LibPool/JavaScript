# @loworbitstudio/visor-tailwind-preset

> 标签: design-system, design-tokens, preset, tailwind, tailwindcss, visor

## 简介

Tailwind CSS preset for the Visor design system — exposes every Visor CSS custom property as a Tailwind theme key so consumers never re-declare hex values, spacing scales, or motion tokens.
