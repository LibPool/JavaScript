# @ek-aiot/2d-editor-core

> 标签: JavaScript

## 简介

`@ek-aiot/2d-editor-core` 是 2D 编辑器的框架无关能力层。它以浏览器为主要运行环境， 使用 ESM 发布，并将文档事务、无头状态、Konva 舞台、运行时数据和共享协议组合成一套 不依赖 Vue、React 或 Pinia 的编辑器内核。
