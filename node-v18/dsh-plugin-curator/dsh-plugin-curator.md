# dsh-plugin-curator

> 标签: audit, cordis, deepseek-harness, dsh, plugin, profile, startup

## 简介

官方「插件」页里的插件管家标签页与插件详情小节：实测每个插件对 DSH 启动的开销、统计活跃度、给出禁用建议，并清理不兼容/未启用条目且可找回。
