# @spore-host/advisor-ts

> 标签: aws, bedrock, browser, ec2, hpc, instance-selection, research-computing, spore-host, tool-use, typescript

## 简介

Browser-native AI advisor for research computing on AWS — answers "what should I run this on?" and "what will it cost?" by calling the spore.host tools for every hardware fact, with Amazon Bedrock supplying only the workload reasoning.
