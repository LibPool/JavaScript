# @leaf233/dsh-model-gateway

> 标签: codebuddy, deepseek-harness, dsh, dsh-plugin, gateway, model-relay, openai, openai-compatible

## 简介

Model relay station for DeepSeek Harness (模型中转站): serve any registered DSH LLM provider (e.g. @tnnevol/dsh-codebuddy) over an OpenAI-compatible /v1 API, so other projects can call those models with a standard OpenAI client.
