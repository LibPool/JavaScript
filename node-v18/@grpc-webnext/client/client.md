# @grpc-webnext/client

> 标签: browser, fetch, grpc, grpc-web, h2ts, http2, protobuf, rpc, streaming, websocket

## 简介

Full bidirectional gRPC client for the browser and Node — real HTTP/2 tunneled over WebSockets via h2ts, plus JSON over Fetch + WebSocket.
