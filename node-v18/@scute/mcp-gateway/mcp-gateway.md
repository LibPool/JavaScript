# @scute/mcp-gateway

> 标签: agents, authorization, guardrails, mcp, model-context-protocol, oauth, scute

## 简介

Put Scute in front of any MCP server: users sign in with your app, every tool call passes your agent guardrails, and changed tool definitions are held for review.
