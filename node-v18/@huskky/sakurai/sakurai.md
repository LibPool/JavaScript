# @huskky/sakurai

> 标签: JavaScript

## 简介

Sakura 是一个独立的中文 Coding Agent CLI。它基于 Pi Coding Agent SDK 提供的模型会话、流式交互、多模态输入、会话管理和基础代码工具，重点补充项目理解、需求确认、代码审查、回归检查和受控 Git 交付流程。
