# @orgops/coax

> 标签: anthropic, json-schema, llm, openai, provider-agnostic, structured-output, typescript, zod

## 简介

Typed, provider-agnostic, self-repairing structured output from LLMs. Pure TypeScript — no native modules, no codegen, no vendor lock-in.
