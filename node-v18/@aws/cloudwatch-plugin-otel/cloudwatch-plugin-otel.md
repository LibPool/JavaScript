# @aws/cloudwatch-plugin-otel

> 标签: adot, amazon, aws, metrics, nodejs, opentelemetry, otel, red-metrics, spanmetrics

## 简介

Generates span-derived RED metrics inside the OpenTelemetry JS SDK, from 100% of spans, before trace sampling.
