# @scoova/weather-react-native

> 标签: forecast, react-native, scoova, scoova weather, sdk, weather

## 简介

Weather SDK for React Native — scoova weather compatible client for the Scoova weather gateway. Pure TypeScript, no native modules required. Locale-aware.
