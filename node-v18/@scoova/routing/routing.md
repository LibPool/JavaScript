# @scoova/routing

> 标签: directions, isochrone, mapmatch, matrix, polyline, routing, scoova, the Scoova routing engine

## 简介

Routing client for the Scoova routing gateway (api.scoo-va.info/api/v1/routing) — route, optimizedRoute, isochrone, matrix, height (elevation), mapMatch, locate, status. Polyline6 decode included.
