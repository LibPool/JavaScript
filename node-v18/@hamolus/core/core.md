# @hamolus/core

> 标签: cloudflare, d1, drizzle, hamolus, headless-cms, hono, multi-tenant, workers

## 简介

The Hamolus core API: a Hono + Drizzle Cloudflare Worker that turns collection metadata into a dynamic, multi-tenant CRUD API on D1, with KV settings, R2 media/file libraries, panel ACLs and an MCP-ready surface.
