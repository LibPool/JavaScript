# @ahtmljs/insights

> 标签: agent-web, ahtml, ai, insights

## 简介

Agent-traffic analytics for AHTML publishers — classifies verified agents (RFC 9421), bots, and humans; records snapshot fetches, action outcomes, and x402 payments behind the @ahtmljs/kv abstraction.
