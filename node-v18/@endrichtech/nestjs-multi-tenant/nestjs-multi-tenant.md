# @endrichtech/nestjs-multi-tenant

> 标签: async-local-storage, multi-tenancy, multi-tenant, nestjs, prisma, row-level-security, saas

## 简介

Row-level multi-tenant isolation for NestJS + Prisma: a Prisma Client Extension that auto-scopes every query by tenantId, plus an AsyncLocalStorage-backed NestJS integration layer. No more `where: { tenantId }` on every service method.
