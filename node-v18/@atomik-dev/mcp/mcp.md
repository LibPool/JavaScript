# @atomik-dev/mcp

> 标签: anthropic, atomik, claude, elementor, mcp, model-context-protocol, wordpress

## 简介

MCP server que conecta Claude ao editor do Elementor via extensão Atomik. Permite construir páginas Elementor em linguagem natural.
