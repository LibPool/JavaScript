# @loom-js/highlight

> 标签: code tokens, loomjs, prism, syntax highlighting

## 简介

Syntax highlighting for loom UI libraries: a pure text→tokens tokenizer (Prism) behind a lazy-import activity, with a UI-library-agnostic token vocabulary.
