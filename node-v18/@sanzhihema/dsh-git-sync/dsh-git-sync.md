# @sanzhihema/dsh-git-sync

> 标签: cordis, deepseek-harness, dsh, git, github, multi-device, plugin, sessions, sync

## 简介

Per-session opt-in multi-device sync of DeepSeek Harness sessions and memory over git (GitHub). Turn on a session, set a remote, and it syncs automatically across devices.
