# @argszero/cordis-plugin-image-offload-fallback

> 标签: attachment, cordis, cordis-plugin, deepseek-harness, dsh, image

## 简介

Recover a session wedged by an image its route cannot serve: translate a decode rejection, or probe for an attachment object that is gone, into the harness's existing image-offload recovery
