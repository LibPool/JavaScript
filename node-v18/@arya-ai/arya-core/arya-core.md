# @arya-ai/arya-core

> 标签: JavaScript

## 简介

Arya host stack: WebSocket channels, serveHost lifecycle, service controller (systemd/launchd), and doctor primitives — the autonomous-host layer that sits on top of the mu-coding SDK.
