# @devmilon/license-guard

> 标签: admin-dashboard, anti-piracy, cloudflare-workers, code-protection, ed25519, fingerprint, license, license-key, licensing, obfuscation, passkey, self-hosted, telemetry, webauthn

## 简介

Self-hosted licensing and deployment tracing for private Node.js code: Ed25519 licence tokens, encrypted core modules, machine fingerprints, and a Cloudflare Worker licence server with a passkey-protected admin dashboard. No SaaS, no per-seat fees.
