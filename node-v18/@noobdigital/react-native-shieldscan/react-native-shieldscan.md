# @noobdigital/react-native-shieldscan

> 标签: VAPT, android, debugger-detection, emulator-detection, frida, ios, jailbreak, mobile-security, react-native, root-detection, security, tamper-detection

## 简介

Runtime security checks for React Native: jailbreak/root detection, Frida, debugger, emulator detection, and screen security. Works in both Old and New Architecture using classic NativeModules.
