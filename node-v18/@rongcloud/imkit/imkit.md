# @rongcloud/imkit

> 标签: JavaScript

## 简介

IMkit 基于 IMLib 通用化的 UI 封装，定位于通用的聊天会话场景（单聊/群聊），帮助开发者快速搭建一个功能集相对完整的即时 IM 通讯产品，提高接入效率。
