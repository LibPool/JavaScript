# @hollis-labs/plugin-outlets

> 标签: extension-point, outlet, plugin, react, slot

## 简介

Named extension points for plugin UIs: a priority-ordered multi-occupant PluginOutlet and a single-occupant PluginSlot over a plugin registry.
