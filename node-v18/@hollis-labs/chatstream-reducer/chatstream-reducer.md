# @hollis-labs/chatstream-reducer

> 标签: ai, chat, llm, reducer, stream

## 简介

A pure reducer from chat-stream events to a normalized assistant message: parts, tool calls, usage, steps, approvals, gaps and status. No I/O, no timers, no framework.
