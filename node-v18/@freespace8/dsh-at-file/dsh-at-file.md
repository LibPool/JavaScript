# @freespace8/dsh-at-file

> 标签: at-file, codex, cordis, deepseek-harness, dsh, mention, plugin, web-ui, workspace

## 简介

Codex-style @ path mentions for the DeepSeek Harness Web GUI: type @ to pick a workspace file/folder and reference its path; the host validates and marks it on send without reading file contents. Codex 风格 @ 路径引用。
