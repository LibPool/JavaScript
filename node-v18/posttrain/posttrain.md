# posttrain

> 标签: cli, dpo, evaluation, fine-tuning, grpo, llm, post-training, reinforcement-learning, rl, sft, slurm

## 简介

PostTrain: run and track post-training (data, RL environments, SFT, preference tuning, RL, evals, deploy) from the terminal or the browser.
