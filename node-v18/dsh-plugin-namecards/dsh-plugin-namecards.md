# dsh-plugin-namecards

> 标签: chinese, deepseek-harness, dsh, dsh-plugin, icons, name-cards, plugin-manager

## 简介

插件名片：给插件换图标、中文名和说明，按文件夹/收藏整理，支持拖拽排序、列表/铺陈视图与启停开关；只改显示，不动插件本身。
