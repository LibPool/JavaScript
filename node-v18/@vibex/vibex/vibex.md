## 简介

Architecture diagrams and checkable documentation from your codebase: ERD, C4, API endpoints and lifecycle diagrams, plus a fact graph whose claims fail CI when the code moves. Imports OpenAPI, GraphQL SDL and Prisma. One standalone HTML file, zero depend
