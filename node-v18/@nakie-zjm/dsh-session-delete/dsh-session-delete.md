# @nakie-zjm/dsh-session-delete

> 标签: conversation, deepseek-harness, dsh-plugin, permanent-delete, privacy, session, session-delete

## 简介

Permanent session delete for DeepSeek Harness: one sidebar menu action that removes the Session log and projection cache and unaccounts it from its Workspace
