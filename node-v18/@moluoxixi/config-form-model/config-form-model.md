# @moluoxixi/config-form-model

> 标签: JavaScript

## 简介

`@moluoxixi/config-form-model` 是 ConfigForm 的项目文档与编辑事务领域层。它负责当前版本的 `ProjectDocument` / `PageGraph` 契约、Registry 锁定、语义命令、原子事务、撤销历史和项目仓库，不包含 Vue UI 或渲染逻辑。
