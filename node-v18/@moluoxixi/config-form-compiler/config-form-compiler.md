# @moluoxixi/config-form-compiler

> 标签: JavaScript

## 简介

`@moluoxixi/config-form-compiler` 将当前 ConfigForm 项目快照与 Registry 契约编译为不可变 Canonical IR。它负责完整项目编译、单页增量编译、Registry/能力诊断和 committed/draft 缓存协调，不负责编辑事务、Vue 渲染或 Workbench 状态。
