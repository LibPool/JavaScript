# @moluoxixi/config-form-prototype-runtime

> 标签: JavaScript

## 简介

ConfigForm 可交互 Demo 的共享执行层。包根入口和 `/session` 提供无 DOM 的严格合同、 Safe Expression 求值和纯会话 reducer；`/vue` 提供按实例隔离的 Surface/overlay host。
