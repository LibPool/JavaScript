# @moluoxixi/excel

> 标签: JavaScript

## 简介

无 UI 依赖的 Excel/CSV 导入导出工具包。它只处理数据、列契约和工作簿生成，不内置按钮、文件选择器、下载器、弹窗或 Vue/Element Plus 依赖。
