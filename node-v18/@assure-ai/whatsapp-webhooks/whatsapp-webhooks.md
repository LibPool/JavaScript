# @assure-ai/whatsapp-webhooks

> 标签: cloud-api, hmac, meta, webhooks, whatsapp, x-hub-signature-256

## 简介

Framework-neutral WhatsApp Cloud API webhook primitives — subscription challenge verification, raw-body X-Hub-Signature-256 verification, typed parsing, and normalized events.
