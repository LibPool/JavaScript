# @assure-ai/whatsapp-types

> 标签: cloud-api, graph-api, meta, types, whatsapp, whatsapp-business

## 简介

TypeScript types for Meta's WhatsApp Business Platform Cloud API — branded identifiers, message and template contracts, webhook envelopes, and Assure's normalized event union.
