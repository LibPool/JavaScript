# @assure-ai/whatsapp-api

> 标签: api-client, cloud-api, graph-api, meta, whatsapp, whatsapp-business

## 简介

Stateless client for Meta's WhatsApp Business Platform Cloud API — messages, templates, phone numbers, webhook subscriptions, and Embedded Signup code exchange.
