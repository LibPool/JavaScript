# @uptimizr/db

> 标签: analytics, clickhouse, duckdb, events, postgres, query, storage, uptimizr

## 简介

OSS storage contracts (dialect-agnostic query layer, neutral event/metadata types) and the single-file DuckDB store for Uptimizr.
