# @uptimizr/heatmap

> 标签: 3d, analytics, heatmap, privacy, uptimizr, visualization, webgl, webgpu

## 简介

Framework-agnostic 3D heatmap overlay core + Babylon adapter. Draws a world-space (voxel) heatmap into the developer's own scene (Tier 0 overlay, ADR 0010).
