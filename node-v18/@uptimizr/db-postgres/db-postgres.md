# @uptimizr/db-postgres

> 标签: analytics, events, postgres, postgresql, query, storage, uptimizr

## 简介

Optional single-tenant PostgreSQL store for Uptimizr — composes the @uptimizr/db dialect-agnostic query layer and CollectorStore contract for self-hosters who already run Postgres and want a multi-writer relational backend.
