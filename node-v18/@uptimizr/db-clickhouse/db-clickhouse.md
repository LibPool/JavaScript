# @uptimizr/db-clickhouse

> 标签: analytics, clickhouse, events, query, storage, uptimizr

## 简介

Optional single-tenant ClickHouse store for Uptimizr — composes the @uptimizr/db dialect-agnostic query layer and CollectorStore contract for high-volume, concurrent self-hosting.
