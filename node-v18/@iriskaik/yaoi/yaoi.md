# @iriskaik/yaoi

> 标签: active-record, decorators, migrations, orm, postgres, postgresql, query-builder, repository, schema-builder, typescript

## 简介

YAOI — Yet Another ORM Implementation. A TypeScript ORM for PostgreSQL with decorator-based entities, two-pipeline DML/DDL architecture, and a programmatic migration runner with checksum enforcement.
