# @cef-ai/chain

> 标签: JavaScript

## 简介

CEF-owned blockchain-ops layer (ADR-035), wrapping [polkadot-api (papi)](https://papi.how). The only package — with `@cef-ai/account` — permitted to import a chain library; every consumer above it stays chain-lib-free.
