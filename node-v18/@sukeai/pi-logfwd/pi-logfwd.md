# @sukeai/pi-logfwd

> 标签: extension, log-forwarder, logs, pi, pi-extension, pi-package, pty, streaming

## 简介

pi package: replaces the built-in bash tool with real-time log forwarding via the pi-logfwd Go binary (PTY, JSONL events, optional log file) / pi 实时命令日志转发扩展（bash 覆盖内置）
