# @yosuku/mcp

> 标签: agent, ai, bitcoin, claude, codex, deepbook, llm, mcp, predict, prediction-market, sui, yosuku

## 简介

MCP server for Yosuku — read live BTC prediction markets on DeepBook Predict 7-29, trade through a capped delegated vault the agent can never drain, and remember trade lessons across sessions (MemWal/Walrus). Sui testnet.
