# @pbpeterson/typed-fetch

> 标签: api, client, error-handling, fetch, go-style, http, json, no-throw, rest, type-safe, typed, typescript

## 简介

A type-safe HTTP client that returns request errors as values. Inspired by Go's error handling pattern.
