# @darksun/apodjs

> 标签: JavaScript

## 简介

ApodJS is an api wrapper for Nasa APOD (Astronomy Picture of the Day) using Axios for api calls, allows API_KEY and DATE query params from official docs, HD param not included, it's legacy and didn't work.
