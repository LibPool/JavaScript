# @ibanzajoe/uploader

> 标签: drag-and-drop, file-upload, filestack, image-editor, picker, react, s3, upload

## 简介

Drop-in React file-upload picker (drag-and-drop + dialog), headless upload client, in-picker image editor, and transform-URL builder.
