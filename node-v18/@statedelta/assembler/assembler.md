# @statedelta/assembler

> 标签: assembler, merge, middleware, pipe, reassembly, statedelta, typescript

## 简介

StateDelta assembler — the stream middleware between packchain and the receiver: reassembles partitioned packages, merges, validates. Composable, standalone, with a v1 conformance.
