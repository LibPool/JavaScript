# @statedelta/actions-printer

> 标签: JavaScript

## 简介

O motor de CODEGEN do actions: IR → código. Hoje, o target de PERFORMANCE (IR → JS tight via new Function, unrolled) que serve o modo de runtime `jit` — inlina o hot path e DELEGA os caminhos frios (catch/block) aos runners do @statedelta/actions-interpre
