# @designesy/score

> 标签: accessibility, ci, core-web-vitals, design-contract, design-system, design-verification, designesy, quality-gate, wcag

## 简介

Design quality gate for AI-generated UI: score any URL on 45 deterministic checks, A–F grade. Runs locally; browser checks return MANUAL. No required dependencies.
