# @stealthscale/plugin-catalogue

> 标签: catalogue, plugins, react, specimen

## 简介

Renders the catalogue: an index per section and group, a page per component and foundation a build indexed with its scenes, source, props and audit, the rail, and the devices a scene is shown in.
