# @cujuju/solidjs-pill-date-picker

> 标签: date-picker, dte, expiration, options, popout, solidjs

## 简介

Compact expiration / DTE picker for SolidJS — collapsed pill with a hover DTE tooltip, portalled pop-out ladder, caller-supplied dates, per-row state (available / adjusted / disabled), a full row escape hatch, and deterministic DTE math.
