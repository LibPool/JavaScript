# @cujuju/solidjs-virtual-log

> 标签: bottom-anchored, chat, ios, log, solidjs, virtual, virtual-scroll, virtualization

## 简介

Bottom-anchored virtual log for SolidJS (chat, logs, feeds): measured rows, no scroll writes while the user scrolls or flings (iOS-safe), older-row paging with a runway, keyboard row navigation.
