# @cujuju/solidjs-anchored-popover

> 标签: anchored, floating-ui, flyout, menu, popover, solidjs, tooltip

## 简介

Anchored popover primitive for SolidJS — HTML Popover API in manual mode, 8 placements, viewport clamping, parent/child popover coordination, wireable dismiss-skip.
