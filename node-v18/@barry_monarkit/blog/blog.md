# @barry_monarkit/blog

> 标签: JavaScript

## 简介

Runtime de blog pour les sites Monark : lit des fichiers Markdown versionnés dans Git (écrits par le **Monark Content Hub** ou à la main), expose des composants React prêts à l'emploi, le SEO (metadata, JSON-LD, sitemap, RSS) et une feuille de style par d
