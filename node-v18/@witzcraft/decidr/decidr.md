# @witzcraft/decidr

> 标签: agent, ai-agent, claude-code, cli, decision, human-in-the-loop, mcp, swipe, triage

## 简介

Swipe-to-decide surface for agent sessions. An agent loads a deck, you answer each card with one directional input, structured answers return to the session.
