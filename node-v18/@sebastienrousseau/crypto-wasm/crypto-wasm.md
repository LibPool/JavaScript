# @sebastienrousseau/crypto-wasm

> 标签: crypto-lib, cryptography, wasm, webassembly

## 简介

Placeholder for a WebAssembly accelerator for crypto-lib. It ships runtime detection and an accelerator interface only; no WebAssembly module yet, so operations run in JavaScript.
