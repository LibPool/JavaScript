# @sebastienrousseau/crypto-lsp

> 标签: cryptography, language-server, linter, lsp, neovim, pem, post-quantum, pqc, quantum-safe, static-analysis, vscode

## 简介

Language Server Protocol (LSP) server for cryptography: flags broken hashes, weak ciphers, short keys, quantum-vulnerable algorithms, hardcoded secrets and malformed PEM, with quick fixes.
