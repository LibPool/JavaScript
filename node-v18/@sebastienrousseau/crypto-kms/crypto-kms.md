# @sebastienrousseau/crypto-kms

> 标签: aws-kms, cryptography, encryption, envelope-encryption, key-management, key-rotation, kms, typescript

## 简介

Key management interface for envelope encryption and key rotation, with AWS KMS and local providers. Google Cloud KMS, Azure Key Vault and HashiCorp Vault providers are stubs.
