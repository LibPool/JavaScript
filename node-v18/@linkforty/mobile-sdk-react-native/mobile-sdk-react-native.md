# @linkforty/mobile-sdk-react-native

> 标签: adjust-alternative, app-attribution, app-links, appsflyer-alternative, branch-alternative, deep-linking, deferred-deep-linking, firebase-dynamic-links, linkforty, mobile-attribution, open-source, privacy-focused, react-native, self-hosted, universal-links

## 简介

React Native SDK for LinkForty - open-source alternative to Branch.io, AppsFlyer OneLink, and Firebase Dynamic Links. Deferred deep linking, attribution, and smart routing.
