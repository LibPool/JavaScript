# @hz-9/a4-cache

> 标签: a4, a4-cache, cache, cache-manager, nest

## 简介

A library for cache management in `@hz-9/a4-*` applications. It internally utilizes [cache-manager](https://www.npmjs.com/package/cache-manager) for management.
