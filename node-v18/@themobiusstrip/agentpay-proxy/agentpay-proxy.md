# @themobiusstrip/agentpay-proxy

> 标签: agent, agentic-payments, base, eip-3009, fail-closed, mcp, payment-proxy, spend-limit, usdc, x402

## 简介

Guarded x402 payment proxy for AI agents: x402 client + agentpay-guard + signer in one out-of-agent process. Standalone per-payment ceiling and cumulative caps apply below the model, fail-closed.
