# @specstream/pi-package

> 标签: agent-skills, lead-lists, mcp, pi-extension, pi-package, pi-skill, specstream, web-data, web-search

## 简介

SpecStream for Pi: ask for any list in plain words and get every match from the live web, each row with its source. Adds the SpecStream MCP server and four agent skills.
