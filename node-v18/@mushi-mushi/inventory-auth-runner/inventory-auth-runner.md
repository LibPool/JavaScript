# @mushi-mushi/inventory-auth-runner

> 标签: auth, authentication, cookie-refresh, e2e, inventory, mushi-mushi, playwright, qa, test-automation

## 简介

Runs the inventory.yaml auth.scripted block via Playwright and seeds the resulting cookies into project_settings so the Mushi crawler + synthetic monitor can hit auth-gated routes.
