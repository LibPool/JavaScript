# @grida/fx-linux-arm64-gnu

> 标签: JavaScript

## 简介

The grida-fx engine for Linux on arm64 with glibc 2.28 or later. @grida/fx installs it; use @grida/fx.

## 官网

- 官网：https://grida.co/fx
- 源码仓库：git+https://github.com/gridaco/fx.git
- npm 页面：https://www.npmjs.com/package/@grida/fx-linux-arm64-gnu
