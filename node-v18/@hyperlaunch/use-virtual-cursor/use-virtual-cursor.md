# @hyperlaunch/use-virtual-cursor

> 标签: JavaScript

## 简介

The `useVirtualCursor` hook creates a virtual cursor that can be moved freely within the viewport via arrow key presses, and trigger click events on elements like buttons and links via the enter key. It's designed for environments such as touch screen kio
