# @actdim/msgmesh

> 标签: async, event-bus, event-driven, in-memory, message-bus, message-mesh, microfrontends, pubsub, reactive, request-response, rpc, rxjs, service-bus, type-safe, typescript

## 简介

High-performance, type-safe message bus for TypeScript. Pub/sub, async/await RPC, streaming, and channel-based routing powered by RxJS.
