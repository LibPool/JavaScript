# @mcpfusion/oauth

> 标签: ai, authentication, device-flow, llm, mcp, mcpfusion, oauth, rfc-8628, token-manager

## 简介

OAuth 2.0 Device Authorization Grant (RFC 8628) for MCP servers built with MCP Fusion. Provides secure token storage, device flow authentication, and middleware integration.
