> 标签: a2a, agent-card, agent-to-agent, ai, json-rpc, llm, mcp, mcpfusion, multi-agent, protocol-bridge, task-delegation

## 简介

A2A Protocol Bridge for MCP Fusion — expose MCP servers as A2A-compliant agents with Agent Cards, task delegation, and structured message exchange.
