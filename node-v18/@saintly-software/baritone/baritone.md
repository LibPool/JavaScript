# @saintly-software/baritone

> 标签: base-ui, design-system, oklch, react, vanilla-extract, whitelabel

## 简介

A whitelabel-first React design system built on vanilla-extract + base-ui, using an Intent/Saliency colour model with oklch relative-colour interaction states.
