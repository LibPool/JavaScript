# @auto-skeleton/vue

> 标签: auto-skeleton, dom, loading, placeholder, shimmer, skeleton, skeleton-loader, ui, ux, vue, vue3, zero-config

## 简介

Zero-config skeleton loaders for Vue 3. Scans the live DOM at runtime — no manual shapes, no CLI, no config files.
