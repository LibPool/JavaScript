> 标签: auto-skeleton, dom, lit, loading, placeholder, shimmer, skeleton, skeleton-loader, ui, ux, web-components, zero-config

## 简介

Zero-config skeleton loaders for Lit and Web Components. Scans the live DOM at runtime — no manual shapes, no CLI, no config files.
