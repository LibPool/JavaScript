# @fsegurai/marked-extended-core

> 标签: extensions, javascript, library, markdown, marked-extended-core, markedjs, sanitizer, ssr, typescript

## 简介

Shared, framework-agnostic and SSR-safe helpers for the marked-extended packages: content-hash IDs, HTML escaping, class-token configuration, scoped runtimes and bubbling CustomEvents.
