# @mohammedelmor/simple_rate_limiter_middleware

> 标签: simple_rate_limiter_middleware

## 简介

A simple rate limiter express middleware implementation using Token Bucket Rate Limiting technique, this is for the sake of experimenting and learning and its not for production, its very far from production-ready module
