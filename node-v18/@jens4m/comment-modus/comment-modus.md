# @jens4m/comment-modus

> 标签: annotations, astro, astro-integration, comments, feedback, review, supabase, unbase

## 简介

Comments on an Astro site itself (?comment), on the Unbase backend: pins on elements, threads, who is online, and a CLI that hands the comments to a coding agent.
