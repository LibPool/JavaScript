# @kpanks/game

> 标签: charter, engine, game, praetor, web

## 简介

Praetor web-native game engine. A charter declares a GameSpec; the renderer emits a single self-contained HTML game playable in any browser. Companion to @kpanks/game-assets (Godot scaffolder).
