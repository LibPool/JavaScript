# @usegraft/mdx-safety

> 标签: agent, ai, cms, content-security, graft, headless-cms, mcp, mdx, sandbox, security, typescript

## 简介

Refuse executable MDX before it is stored or rendered. MDX is code, and rendering evaluates it on the server.
