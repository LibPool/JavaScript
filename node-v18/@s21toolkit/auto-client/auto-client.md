# @s21toolkit/auto-client

> 标签: JavaScript

## 简介

Клиент для внутреннего GQL API платформы edu.21-school.ru. Предназначен для использования с [s21auto](https://github.com/s21toolkit/s21auto) для генерации запросов (`src/api.ts`) из HAR логов платформы (см. [Генерация методов](#генерация-методов)).
