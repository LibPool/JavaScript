# @mosadd/detection-sdk

> 标签: JavaScript

## 简介

Pluggable detection pipeline (Detector, Signal, Verdict) for voice deepfake, phishing, baseband anomaly and other threat classifiers used by mosadd B2C and mosadd-gov.
