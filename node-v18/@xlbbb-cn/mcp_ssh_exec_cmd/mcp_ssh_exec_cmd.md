# @xlbbb-cn/mcp_ssh_exec_cmd

> 标签: agent, cli, llm-tools, mcp, model-context-protocol, remote-execution, ssh, stdio

## 简介

Standalone stdio MCP server that exposes SSH host storage and remote command execution as MCP tools. Sibling to the FastAPI app in this monorepo; launched via `npx`.
