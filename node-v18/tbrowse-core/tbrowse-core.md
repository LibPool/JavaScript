# tbrowse-core

> 标签: bioinformatics, brapi, ensembl, genotype, gramene, newick, nexus, phylogenetics, phyloxml, tbrowse, tree, upgma

## 简介

Headless companion to the tbrowse tree viewer: data model, tree algorithms, file parsers, REST adapters and data-source loaders (Ensembl, Gramene, BrAPI), UPGMA clustering, fetch helpers and view-state logic. Runs in browsers and Node.
