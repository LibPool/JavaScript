# @semantic-ui-react/craco-less

> 标签: JavaScript

## 简介

This is a [craco][1] plugin that adds Less support to [create-react-app][2] version >= 2. Designed to be used with [Semantic UI React][3] and adds proper configs for [Semantic UI Less][4].
