# @ticatec/logger-api

> 标签: abstraction, commonjs, console, contract, dependency-injection, dual-module, esm, interface, keelson, logger, logging, nodejs, provider, structured-logging, ticatec, typescript, zero-dependency

## 简介

The zero-dependency logging contract shared by the Keelson framework. Packages log against a minimal Logger interface; the application injects the implementation, and falls back to the console when it does not.
