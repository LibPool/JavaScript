# @usdd/mcp-server-usdd

> 标签: agent, ai, bsc, defi, ethereum, makerdao, mcp, model-context-protocol, stablecoin, tron, usdd, vault

## 简介

MCP server for the USDD protocol across TRON, Ethereum, and BSC. Supports vaults, PSM swaps, USDD Savings, protocol monitoring, and AI-guided risk workflows.
