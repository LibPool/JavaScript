# @antiylabs/iep-scan-mcp

> 标签: antivirus, antiy, mcp, modelcontextprotocol, security, virus-scan

## 简介

安天 IEP 病毒检测 MCP 服务（stdio）。让 AI 客户端直接调用 scan_file / scan_hash 做文件查毒与哈希黑白查询。引擎与病毒库随包分发，扫描时引擎会走云查。
