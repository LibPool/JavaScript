# @taku128/java-schematic

> 标签: deepslate, java, litematic, litematica, minecraft, nbt, schem, schematic, sponge, structure, worldedit

## 简介

Convert Java Edition schematic formats (.litematic / .schem / .nbt) to Java Structure NBT. Browser- and Node-compatible. Classic MCEdit .schematic and Bedrock .mcstructure are detected and rejected with descriptive errors.
