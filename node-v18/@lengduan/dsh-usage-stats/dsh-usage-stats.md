# @lengduan/dsh-usage-stats

> 标签: deepseek-harness, dsh, dsh-plugin, sqlite, token-usage, usage-stats

## 简介

DSH 用量统计插件：SQLite 本地账本，按天 / 按模型统计输入、输出、缓存命中、总计；区分对话调用与内部调用，只统计用量不做费用计算。
