# @relayt/sdk

> 标签: control-plane, entitlements, error-reporting, feature-flags, heartbeat, licensing, relayt, remote-config

## 简介

Connect a running app to its Relayt control plane: self-registration, heartbeat, per-deployment config, entitlements/licensing, signed named commands, and error reports that become issues. Zero dependencies.
