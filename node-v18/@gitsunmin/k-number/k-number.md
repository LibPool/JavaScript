# @gitsunmin/k-number

> 标签: formatting, i18n, korean, korean-number, korean-numeral, localization, number, number-to-korean, 만, 변환, 수사, 숫자, 숫자변환, 억, 조, 한국어, 한글

## 简介

숫자를 입력하면 한글 수사를 반환하는 기능을 제공하는 라이브러리입니다. (ex. 1234 -> 천이백삼십사)
