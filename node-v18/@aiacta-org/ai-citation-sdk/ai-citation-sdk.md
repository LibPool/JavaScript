# @aiacta-org/ai-citation-sdk

> 标签: ai-attribution, ai-copyright, ai-transparency, aiacta, attribution, citation, citation-webhook, content-attribution, content-creators, express-middleware, hmac, idempotency, open-standard, publisher-rights, sdk, signature-verification, web-standard, webhook

## 简介

Webhook receiver SDK for AIACTA citation events. HMAC-SHA256 signature verification, idempotency, and Express middleware (AIACTA Proposal 2, §3.4)
