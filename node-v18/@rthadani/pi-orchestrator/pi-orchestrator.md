# @rthadani/pi-orchestrator

> 标签: failover, models, orchestrator, pi, pi-package, prompt, roster, subagents, workflow

## 简介

A pi extension that ships a default agent workflow, injects it where an AGENTS.md goes, and enforces delegation before direct file work.
