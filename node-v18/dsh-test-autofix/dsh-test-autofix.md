# dsh-test-autofix

> 标签: agent, automation, cordis, debugging, deepseek, deepseek-harness, developer-tools, devtools, dsh, dsh-plugin, harness, jest, plugin, pytest, tdd, test-runner, testing, vitest

## 简介

DSH 测试修复循环插件：自动识别项目测试框架，运行测试并结构化解析失败信息，把「哪个文件、哪一行、什么断言失败」精准注入对话，让 agent 直接进入修复循环；同一处失败超过阈值自动停止，避免死循环烧钱。支持中文断言（自动处理 Windows 编码）与参数化测试。
