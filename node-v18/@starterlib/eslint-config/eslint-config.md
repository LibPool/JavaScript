# @starterlib/eslint-config

> 标签: eslint, eslintconfig, socle-frontal, starter, stylelint

## 简介

Configuration ESLint d'une SPA du socle frontal starter, parametree par son prefixe, et configuration stylelint de ses feuilles. Remplace les eslint.config.mjs recopies.
