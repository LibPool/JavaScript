# @livevariant/tools

> 标签: ab-testing, agent-tools, mcp, multi-armed-bandit, openapi

## 简介

LiveVariant's tool definitions: one registry describing every operation an assistant can perform, from which the MCP server, the REST API, the OpenAPI document and the agent SKILL are all generated
