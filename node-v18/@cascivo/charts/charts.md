# @cascivo/charts

> 标签: cascivo, charts, css, data-visualization, design-system, react, signals, svg

## 简介

Chart components built from scratch — scales, shapes, and signal-driven rendering, zero dependencies. Colors come from @cascivo/themes; components from @cascivo/react. Docs offline: npx @cascivo/docs
