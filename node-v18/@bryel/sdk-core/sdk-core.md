# @bryel/sdk-core

> 标签: bryel, llm, observability, openinference, opentelemetry, otlp, tracing

## 简介

Framework-agnostic core of the bryel tracing SDK: an OpenTelemetry OTLP exporter and span processor that ship LLM and agent traces to bryel from any framework.
