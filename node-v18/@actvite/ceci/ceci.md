## 简介

Agent skill for Claude Code, Codex, Grok, Cline, Goose, and Hermes that turns a goal into a job graph, runs ready jobs in dependency order, stops at human gates before contact, posting, payment, or pricing, places GPU jobs, and gates code changes with /rd
