# @forgedapps/backstage-catalog-webhook-plugin

> 标签: atlassian, backstage, compass, plugin, webhook

## 简介

Publish a Backstage catalog to a remote webhook. Designed by Forged Apps to synchronize Backstage with Atlassian Compass, but it can be used to push your catalog to any HTTP endpoint.
