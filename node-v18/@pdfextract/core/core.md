# @pdfextract/core

> 标签: browser, image-extraction, nodejs, pdf, pdf-extraction, pdfjs, png, structured-text, text-extraction, typescript

## 简介

Whole-PDF text extraction, structured layout and lossless embedded-image export for browsers and Node.js, powered by a self-hosted PDF.js engine.
