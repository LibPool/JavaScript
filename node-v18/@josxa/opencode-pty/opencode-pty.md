# @josxa/opencode-pty

> 标签: background-process, bun, cli, dev-server, interactive, opencode, opencode-plugin, pseudo-terminal, pty, shell, terminal

## 简介

OpenCode plugin for interactive PTY management - run background processes, send input, read output with regex filtering, and capture terminal snapshots
