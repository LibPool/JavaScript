> 标签: agent, agentic, ai, ai-agent, claude, claude-code, coding-agent, copilot, cursor, devtools, github-copilot, instructions, llm, mcp, mcp-server, model-context-protocol, prompt-engineering, reasoning-loop, scaffolding, self-correcting, sync_loop, syncloop

## 简介

Self-correcting 7-stage agent reasoning loop (SENSE→GKP→DECIDE+ACT→CHALLENGE-TEST→UPDATE→LEARN→REPORT). MCP server + CLI that scaffolds instruction files for GitHub Copilot, Cursor, and Claude Code.
