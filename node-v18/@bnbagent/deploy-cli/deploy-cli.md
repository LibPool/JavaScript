# @bnbagent/deploy-cli

> 标签: JavaScript

## 简介

The bnbagent-deploy CLI — batteries-included over @bnbagent/deploy-core, bundling and pre-registering first-party providers so `bunx --bun @bnbagent/deploy-cli deploy` works without a project package.json.
