# @bnbagent/deploy-provider-azure

> 标签: JavaScript

## 简介

Azure provider for @bnbagent/deploy — deploys agents to Microsoft Foundry Agent Service (Hosted agents) via the direct REST API: zip (source-zip remote_build), container/image (local amd64 build to ACR), CustomKeys-connection secrets.
