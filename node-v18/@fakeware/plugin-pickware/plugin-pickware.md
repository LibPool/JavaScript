# @fakeware/plugin-pickware

> 标签: fakeware, fakeware-plugin, fixtures, pickware, seed, shopware

## 简介

Pickware ERP plugin for fakeware. Seed bin locations, suppliers, product-supplier configurations and return orders into a Shopware 6 shop running Pickware
