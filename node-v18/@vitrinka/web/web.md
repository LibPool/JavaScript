# @vitrinka/web

> 标签: devtools, nextjs, react, recorder, rrweb, session-recording, testing, vitrinka

## 简介

vitrinka toolkit for React DOM apps — the journey recorder: capture manual-testing sessions (rrweb DOM stream, clicks, navigation, network, console, notes) straight into vitrinka boards.
