> 标签: ai, books, classics, claude, lindy-effect, mcp, model-context-protocol, reading-list

## 简介

MCP server exposing The Lindy Library catalog — 140+ classic books curated using the Lindy Effect. Use with Claude Desktop, Cursor, or any MCP-compatible client.
