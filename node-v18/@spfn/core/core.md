# @spfn/core

> 标签: ai-coding-agent, api, backend, claude-code, crud, database, drizzle-orm, file-based-routing, framework, full-stack-framework, fullstack, hono, nextjs, orm, postgres, redis, repository-pattern, rest-api, spfn, transaction, type-safe, typescript

## 简介

Full-stack TypeScript backend for Next.js: file-based typed routes, Drizzle entities and repositories, PostgreSQL transactions and a generated end-to-end client, in one fixed vertical slice per feature
