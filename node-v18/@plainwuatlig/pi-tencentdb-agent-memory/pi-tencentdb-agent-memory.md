# @plainwuatlig/pi-tencentdb-agent-memory

> 标签: agent-memory, extension, pi, pi-package, tdai, tencentdb

## 简介

TencentDB Agent Memory (tdai) for pi: 8 memory/knowledge tools + automatic L0 conversation capture + visible L2/L3 (once per session) and L1 (every turn, deduped) memory injection as a reviewable transcript message.
