# @alfavit/sdk

> 标签: alfavit, alphabet, api, client, transliteration, uzbek

## 简介

Zero-dependency client for the Alfavit transliteration API (api.alfavit.uz): Uzbek Cyrillic / old Latin → the 2026 Latin alphabet.
