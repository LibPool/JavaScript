# agent-approval-machine

> 标签: agents, ai, angular, approval, framework-agnostic, headless, human-in-the-loop, react, state-machine, svelte, vanilla-js, vue, zero-dependency

## 简介

Framework-free approval state machines for AI agents: edit before approve, partial failure with retry, undo windows, and a queue for items that arrive mid-flight. Zero dependencies, no UI, works in any JavaScript runtime.
