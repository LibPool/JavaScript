# @csadi/dsh-plugin-manager

> 标签: JavaScript

## 简介

Plugin manager tab for the dsh web GUI Plugins settings section: installs plugins from npm or git through the official host channels, lists installed plugins with next-start enablement switches, surfaces install-time conflict actions with undo, and hands
