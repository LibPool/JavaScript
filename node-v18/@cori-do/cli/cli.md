# @cori-do/cli

> 标签: agents, cli, cori, mcp, temporal, workflows

## 简介

The cori command line (init, workflow new, check, run, deploy, login, up…) as a prebuilt binary for macOS and Linux: `npm install -g @cori-do/cli`, or `npx @cori-do/cli` in a sandbox or CI, with no Rust toolchain.
