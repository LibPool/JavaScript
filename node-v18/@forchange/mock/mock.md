# @forchange/mock

> 标签: JavaScript

## 简介

基于 koa 的本地 mock 服务 - 长链接 - socket - 自定义错误状态 - 接口之间的隔离 - 接口之间可以联动处理（数据传递） - 简单易用，容易扩展
