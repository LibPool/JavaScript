# mm_cmd

> 标签: chat, cmd, command, mm_adapter, mm_in_adapter, mm_mod, 指令管理器

## 简介

指令框架，用于以聊天的方式操作程序，前端发送字符串，后端判断是否为指令并执行（基于 mm_corejs，内置管理器池，无全局/原型扩展依赖）
