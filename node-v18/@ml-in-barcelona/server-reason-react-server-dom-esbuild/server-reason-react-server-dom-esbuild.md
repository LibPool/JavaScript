# @ml-in-barcelona/server-reason-react-server-dom-esbuild

> 标签: esbuild, reason-react, server-reason-react

## 简介

React Server Components bindings for DOM using Esbuild. This is intended to be integrated into meta-frameworks. It is not intended to be imported directly.
