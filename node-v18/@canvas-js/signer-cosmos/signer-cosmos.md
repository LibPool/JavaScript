# @canvas-js/signer-cosmos

> 标签: JavaScript

## 简介

The Cosmos session signer takes an injected Cosmos signer, which may be an `EthereumSigner`, `AminoSigner`, or `BytesSigner`, and uses it to authenticate a new session.
