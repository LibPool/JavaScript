# @decoding/pubsum

> 标签: academic, cli, crossref, docx, literature-review, openalex, publications, research, science, summariser

## 简介

Search and summarise academic publications from the terminal. Outputs to terminal, .docx, Markdown, or JSON. Powered by OpenAlex & CrossRef — no API key required.
