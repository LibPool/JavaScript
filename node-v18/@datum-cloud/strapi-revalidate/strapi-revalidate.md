# @datum-cloud/strapi-revalidate

> 标签: astro, cache, nextjs, nuxt, revalidate, ssr, strapi, strapi-v5, sveltekit, webhook

## 简介

Framework-agnostic runtime cache invalidation for Strapi v5 in SSR frontends. Receives Strapi publish webhooks, clears affected cache tags, next request serves fresh data.
