# @qawolf/pom

> 标签: JavaScript

## 简介

`@qawolf/pom` is a TypeScript toolkit for building Page Object Models (POMs) on top of Playwright: base classes for page objects, construction of sibling page objects by class or by name, and automatic popup and route-hook installation.
