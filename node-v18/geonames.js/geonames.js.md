# geonames.js

> 标签: JavaScript

## 简介

REST api to fetch countries, regions, cities etc. A flexible library for browser and node.js usage built on top http://www.geonames.org/

## 官网

- 官网：https://github.com/kinotto/geonames.js
- 源码仓库：git+https://github.com/kinotto/geonames.js.git
- npm 页面：https://www.npmjs.com/package/geonames.js
