# @stefanprobst/remark-extract-yaml-frontmatter

> 标签: JavaScript

## 简介

[remark](https://github.com/remarkjs/remark) transformer plugin to parse `yaml` nodes and expose parsed data on `vfile.data.frontmatter`. Works on `yaml` nodes created by [`remark-frontmatter`](https://github.com/remarkjs/remark-frontmatter).
