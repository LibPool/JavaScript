# @richardmcquiston01/error-log-adapter-rethinkdb

> 标签: adapter-pattern, error-logging, logger, rethinkdb, rethinkdb-ts, typescript

## 简介

RethinkDB adapter for @richardmcquiston01/error-log-adapter: stores each error as a document whose primary key is the entry id, so retries never duplicate.
