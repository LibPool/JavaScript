# @tengence/geo-agent

> 标签: agent, deepseek-harness, geo, mcp, opencode, pi

## 简介

Tengence GEO Agent: pluggable run-loop launcher for DeepSeek Harness / opencode / Pi — set DEEPSEEK_API_KEY and it runs (MCP bridge to @tengence/geo-mcp)
