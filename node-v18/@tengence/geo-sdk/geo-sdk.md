# @tengence/geo-sdk

> 标签: content, geo, markdown, mcp, multi-tenant, seo, wordpress

## 简介

GEO/SEO content engine library: multi-site content ingestion, gates, WordPress publishing, search inclusion, AI monitoring and multi-platform distribution. Dual storage drivers (SQLite default / MySQL production).
