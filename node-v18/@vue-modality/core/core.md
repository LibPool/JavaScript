# @vue-modality/core

> 标签: dialog, guard, lightweight, modal, namespace, popup, promise, sidebar, toast, typescript, vue, vue3

## 简介

Lightweight modal library for Vue 3 with namespace queues, guard system, and promise-based prompt pattern. Zero dependencies.
