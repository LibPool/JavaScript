# @nexus-aethra/dshell-commands

> 标签: JavaScript

## 简介

dshell commands and tools: /new on ctx.commands, plus the model-facing dshell_get_agent_terminal tool that hands the agent its own shell, and dshell_terminal_read / dshell_terminal_output for reading the user's shell (read-only).
