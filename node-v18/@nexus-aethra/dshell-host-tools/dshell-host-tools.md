# @nexus-aethra/dshell-host-tools

> 标签: JavaScript

## 简介

Host capabilities belong to local sessions. Provides the browser-use provider (upstream's dsh-browser-use registry) and denies the desktop tools of upstream's computer-use provider in every session bound to an SSH device.
