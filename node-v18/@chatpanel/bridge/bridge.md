# @chatpanel/bridge

> 标签: ai-agents, antigravity-cli, bridge, chatpanel, chrome-extension, claude-code, codex, gemini-cli

## 简介

Local bridge that exposes the AI coding agents installed on your machine — Claude Code (CLI), Codex (CLI), and Antigravity CLI (formerly Gemini CLI, which remains available for business/enterprise) — to the ChatPanel Chrome extension over a localhost SSE
