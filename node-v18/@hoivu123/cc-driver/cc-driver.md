# @hoivu123/cc-driver

> 标签: agent, anthropic, automation, claude, claude-code, driver, glm, headless, llm, orchestration

## 简介

TypeScript driver library — orchestrate Claude Code headless (multi-session, stream events, pools, goal/loop/background) and call LLMs directly with schema validation. GLM(z.ai)/Claude multi-provider.
