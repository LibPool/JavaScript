# @excitedjs/feishu-channel

> 标签: JavaScript

## 简介

Built-in Feishu plugin for Dreamux: contributes the feishu channel provider (builtin:feishu) and publishes the extension api. Owns Feishu channel session logic, inbound normalization, access/trust, and MCP tool backing on top of @excitedjs/feishu-transpor
