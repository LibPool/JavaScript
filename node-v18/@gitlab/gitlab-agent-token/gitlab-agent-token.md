# @gitlab/gitlab-agent-token

> 标签: agent, gitlab, gitops, kubernetes

## 简介

Registers a new GitLab Kubernetes Agent with your GitLab instance, and retrieves its secret token

- 官网：https://gitlab.com/gitlab-org/cluster-integration/gitlab-agent-token/

- npm 页面：https://www.npmjs.com/package/@gitlab/gitlab-agent-token
