# @knapsack-pro/jest

> 标签: CI, automation, integration, jasmine, jest, knapsack, knapsack pro, parallelisation, runner, test, test suite parallelisation, testing

## 简介

Knapsack Pro Jest splits Jest tests across CI nodes and makes sure that tests will run in optimal time on each CI node.
