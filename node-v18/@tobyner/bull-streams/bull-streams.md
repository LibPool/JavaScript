# @tobyner/bull-streams

> 标签: consumer-group, dead-letter, event-bus, events, ioredis, nestjs, opentelemetry, pubsub, redis, redis-streams

## 简介

A Redis Streams event bus: publish/subscribe over consumer groups, with per-group cursors, automatic reclaim of abandoned messages, a per-group dead-letter stream, delayed delivery, native OpenTelemetry tracing, a NestJS integration and an operations dash
