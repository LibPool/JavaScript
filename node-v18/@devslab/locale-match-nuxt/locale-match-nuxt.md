# @devslab/locale-match-nuxt

> 标签: accept-language, i18n, locale, nuxt, nuxt-module, ssr

## 简介

Nuxt module for @devslab/locale-match — resolves the locale during SSR from Accept-Language, so the page never changes language after it paints.
