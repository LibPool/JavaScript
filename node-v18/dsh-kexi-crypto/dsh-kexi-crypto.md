# dsh-kexi-crypto

> 标签: agent-preset, analysis, cordis, crypto, deepseek-harness, dsh, visualization

## 简介

K析研判团 DSH 插件包：加密货币趋势研判 6 人专家团（主理人 K析 + 数脉/指北/望潮/守拙/证伪），可选接入 CEX 实盘，零第三方依赖 Python 分析脚本链（取数→指标→组装→契约校验→token压缩→自包含 HTML 看板）。v1.5.0：重大能力升级与项目历史实操经验建档交付——①选币质量升级（P1）：新增 position.py（90日区间位置、距高点回撤、20日涨幅分位、放量持续天数拥挤度扣分、窄幅横盘识别）、timeframe.py（周月线重采样与共振/逆大周期反弹判定）、bac
