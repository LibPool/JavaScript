# @jurijsk/codon-explorer

> 标签: css-custom-highlight-api, find, find-in-page, highlight, minimap, occurrences, scrollbar-markers, search

## 简介

Explore a long document: paint every occurrence of a selected or searched term with the CSS Custom Highlight API (the DOM untouched), count them, step through them like a find bar, pin terms, and draw them as scrollbar markers. Works on a document in a sa
