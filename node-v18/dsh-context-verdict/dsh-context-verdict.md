# dsh-context-verdict

> 标签: compaction, context, cordis-plugin, deepseek-harness, deterministic, dsh, dsh-plugin, no-per-block, phocinae, verdict

## 简介

DeepSeek Harness plugin: one session-level verdict on whether compaction would lose unlanded state. Structurally incapable of per-block screening, which was measured wrong.
