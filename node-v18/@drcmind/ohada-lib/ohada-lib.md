# @drcmind/ohada-lib

> 标签: accounting, africa, balance, bookkeeping, cameroon, chart-of-accounts, congo, cote-divoire, decimal, drc, finance, grand-livre, journal, ohada, senegal, syscohada, typescript

## 简介

A developer-friendly OHADA / SYSCOHADA accounting library that transforms business events into type-safe journal entries, manages stock movements, tracks expenses, and generates compliant financial reports.
