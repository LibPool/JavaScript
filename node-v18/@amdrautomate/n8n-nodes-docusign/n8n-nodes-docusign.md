# @amdrautomate/n8n-nodes-docusign

> 标签: connect, contract, docusign, e-signature, envelope, esignature, n8n, n8n-community-node-package, signing, webhook

## 简介

n8n community node for DocuSign eSignature: create and send envelopes from documents or templates, embed signing, track status, download signed PDFs, manage recipients, templates, bulk sends and Connect webhooks, plus a trigger for envelope and recipient
