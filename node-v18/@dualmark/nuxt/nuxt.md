# @dualmark/nuxt

> 标签: aeo, ai-search, answer-engine-optimization, dualmark, llms-txt, markdown, nuxt, nuxt-module

## 简介

Nuxt module for the Dualmark AEO framework. Auto-generates .md endpoints from collection config + injects Link rel=alternate middleware + generates llms.txt.
