# @just-every/plugin-recall

> 标签: claude-code, codex, history, hooks, memory, recall

## 简介

Memory plugin for Codex and Claude Code: brings back the small things you said earlier that matter for the request in front of the agent, using embeddings plus cheap narrow Decisions API judgements.
