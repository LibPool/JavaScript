# @mrbd/payments

> 标签: glasses, meta-ray-ban-display, mrbd, payments, stripe, subscriptions, wearables

## 简介

Client for MRBD payments (Stripe Connect): products, a shared wallet, PIN purchases, subscriptions, and entitlements for Meta Ray-Ban Display web apps.
