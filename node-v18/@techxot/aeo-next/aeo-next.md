# @techxot/aeo-next

> 标签: aeo, ai-crawlers, headless, json-ld, llms.txt, next, nextjs, seo, structured-data, techxot, umbraco

## 简介

Next.js adapters for Techxot AI Readiness on a headless Umbraco site: serve llms.txt, llms-full.txt and per-page Markdown, advertise the Markdown alternate, emit page + site JSON-LD, report AI-crawler traffic to InMotion, and revalidate on publish.
