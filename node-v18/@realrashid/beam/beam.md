# @realrashid/beam

> 标签: echo, file-transfer, laravel, reverb, screen-share, video-call, webrtc

## 简介

Real-time calls, screen sharing and peer-to-peer file transfer for Laravel. The browser half: one class, framework-free, with Vue, React and jQuery adapters.
