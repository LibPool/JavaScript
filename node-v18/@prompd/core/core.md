# @prompd/core

> 标签: browser, compiler, nunjucks, prompd, prompt

## 简介

Environment-agnostic core for Prompd: .prmd parser, compilation pipeline (Nunjucks templating), formatters, and an injectable file-system/package-resolver. Runs in Node, the browser, and the backend. No Node-only imports.
