# dsh-cost-balance-indicator

> 标签: balance, cost, deepseek, deepseek-harness, dsh, dsh-plugin, off-peak, peak, pricing

## 简介

DSH Web 成本与余额指示器：峰谷时段徽标 + 本会话/本轮 token 费用 + DeepSeek Key 余额 + 悬停自定义配色（RGB 轮盘，可整体或单个调色）——合并 dsh-peak-indicator 与 dsh-balance-indicator
