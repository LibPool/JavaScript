# @getomnichain/omnichain

> 标签: bitcoin, blockchain, ethereum, evm, multichain, omnichain, sdk, solana, stellar, ton, tron, utxo, web3

## 简介

Multi-chain SDK for EVM, Solana, UTXO (BTC/LTC/DOGE/DASH/ZEC/BCH), Stellar, Tron, and TON. TypeScript parity port of omnichain-py.
