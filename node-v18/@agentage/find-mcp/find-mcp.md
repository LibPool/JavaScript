# @agentage/find-mcp

> 标签: agentage, claude, cursor, find-mcp, mcp, mcp-catalog, mcp-registry, mcp-server, model-context-protocol

## 简介

Find MCP - the npm client for the agentage MCP directory: thin stdio MCP proxy bridging stdio-only clients (Claude Desktop, Cursor, VS Code) to catalog.agentage.io/mcp - search 17,000+ MCP servers from any MCP client.

## 官网

- 源码仓库：git+https://github.com/agentage/find-mcp.git
