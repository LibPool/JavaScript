# @agentage/design-system

> 标签: accessibility, agentage, component-library, design-system, design-tokens, oklch, radix-ui, react, react-19, react-server-components, rsc, tailwind-v4, tailwindcss, typescript, ui-components, wcag

## 简介

Agentage Design System - OKLCH design tokens and 60+ accessible React 19 components. RSC-safe (per-module "use client"), Tailwind CSS v4, tree-shakeable ESM with per-component subpath exports.
