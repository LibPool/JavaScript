# @buildtree/cli

> 标签: ad-hoc, android, apk, app-center-alternative, beta-testing, build, buildtree, diawi-alternative, distribution, expo, fastlane, firebase-app-distribution-alternative, flutter, install-link, ios, ipa, mobile, qa, qr-code, react-native, testflight-alternative

## 简介

Share Android and iOS builds with testers: upload an .apk or .ipa, get an install link and QR code. Works with Expo, React Native, Flutter and native apps, locally or in CI.
