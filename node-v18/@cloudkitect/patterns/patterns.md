# @cloudkitect/patterns

> 标签: aws, cdk, cdk constructs, cloud compliance, cloud components, cloudkitect, freemium, infrastructure as code, patterns, terraform, well architected

## 简介

CloudKitect freemium patterns are built on top of CloudKitect freemium components which comply to various standards. Using these patterns you can host your website, or run your containerized app using ECS Fargate within a couple hours
