# @futuremachine/core

> 标签: async-persistence, durable-execution, futures, long-running-tasks, persistent-collections, persistent-promises, process-recovery, resumable-workflows, state-management, typescript

## 简介

A TypeScript library for Futures, persistent Promises that survive process restarts and can be resolved by ID.
