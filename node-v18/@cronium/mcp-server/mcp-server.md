# @cronium/mcp-server

> 标签: ai-agent, automation, claude, cronium, mcp, model-context-protocol, scheduling, workflows

## 简介

Local (stdio) MCP bridge to a Cronium instance's /api/mcp endpoint — build, run, and fix Cronium events and workflows from an AI app.
