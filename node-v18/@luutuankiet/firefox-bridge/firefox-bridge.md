# @luutuankiet/firefox-bridge

> 标签: firefox, hyperdht, mcp, p2p, socks5, tunnel

## 简介

Zero-ingress P2P bridge that exposes a remote host's localhost to the firefox-docker-mcp browser over HyperDHT
