# @hibira-io/lobby

> 标签: hibira, laravel-echo, lobby, matchmaking, multiplayer, presence, pusher, pusher-js, realtime, room, websocket

## 简介

Room lobby for pusher-js and Laravel Echo on presence channels: seats, host, ready flags, settings, kick, start and room chat, with no game server
