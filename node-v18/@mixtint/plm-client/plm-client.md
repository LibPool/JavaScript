# @mixtint/plm-client

> 标签: JavaScript

## 简介

从 THAPE PLM 的 OpenAPI 3.1 快照生成的 Promise / Effect 客户端。默认服务器为 `https://plm.thape.com.cn`，认证使用显式传入的 Bearer token。
