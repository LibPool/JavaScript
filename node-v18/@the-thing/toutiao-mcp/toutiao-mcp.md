# @the-thing/toutiao-mcp

> 标签: automation, mcp, model-context-protocol, puppeteer-core, toutiao, 今日头条

## 简介

An MCP server that publishes articles to Toutiao (今日头条) via browser automation. 扫码登录+发布文章，只需配置一行 MCP 即可使用。
