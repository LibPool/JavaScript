# @tanzhenxing/zx-lucky-grid

> 标签: zx-lucky-grid, 幸运转盘, 幸运转盘组件, 转盘

## 简介

一个基于 uni-app、Vue3 <script setup> 语法开发的高兼容性幸运转盘组件，适配 H5、小程序、App。可嵌入于 zx-list 组件中，支持丰富的内容、图标、角标、开关、跳转等功能，适合自定义各类列表场景。
