# @tanzhenxing/zx-refresh

> 标签: JavaScript

## 简介

一个基于 uni-app、Vue3 <script setup> 语法开发的高兼容性下拉刷新组件，适配 H5、小程序、App。支持 nvue 原生刷新、H5/小程序自定义刷新动画，支持多种状态文本、事件，适合自定义各类下拉刷新场景。
