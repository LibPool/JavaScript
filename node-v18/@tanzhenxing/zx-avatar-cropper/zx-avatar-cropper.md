# @tanzhenxing/zx-avatar-cropper

> 标签: avatar, cropper

## 简介

zx-avatar-cropper 是一个功能强大的头像裁剪组件，支持图片选择、裁剪、旋转、缩放等功能。组件采用纯 JavaScript 实现，兼容 H5、小程序和 App 平台。
