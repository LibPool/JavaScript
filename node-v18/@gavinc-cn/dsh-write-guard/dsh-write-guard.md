# @gavinc-cn/dsh-write-guard

> 标签: JavaScript

## 简介

第六权限档「完全权限（拦截）」的逐调用写入闸门：读放行、项目内/白名单写放行、越界写弹框并自动学习白名单、判不出的命令交当前会话模型判定。
