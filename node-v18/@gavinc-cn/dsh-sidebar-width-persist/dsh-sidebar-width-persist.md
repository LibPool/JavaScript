# @gavinc-cn/dsh-sidebar-width-persist

> 标签: JavaScript

## 简介

把 DSH Web GUI 左侧边栏的拖动宽度持久化到 localStorage: 刷新页面后仍是上次拖出来的宽度; 收起侧栏不丢宽度, 再展开时回到该宽度 (原生语义是回默认 280)。
