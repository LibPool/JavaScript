# @gavinc-cn/dsh-superpowers-priming

> 标签: JavaScript

## 简介

DSH 原生插件：会话重开（agent/created source=resume）时，若会话历史里没有 superpowers 开场说明（桥接 hooks-claude-code 或本插件注入过），补注入一次 using-superpowers 全文；已有则跳过，避免重复占用上下文。
