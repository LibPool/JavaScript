# @bosonprotocol/x402-client-fetch

> 标签: boson-protocol, buyer, client, escrow, fetch, payments, web3, x402

## 简介

Native-fetch adapter for the Boson Protocol x402 buyer-side SDK — intercepts 402 escrow-scheme responses and retries with the X-PAYMENT header produced by @bosonprotocol/x402-client.
