# @sodacore/discord

> 标签: @bun, bot, bots, bun, decorator, discord, discord-bot, discord.js, engine, framework, soda, sodacore, sodacore-plugin, typescript

## 简介

Sodacore Discord is a plugin that offers Discord SSO/OAuth2 support and the ability to create bots in a similar controller pattern.
