# @stuga/dsh-plugin

> 标签: deepseek-harness, dsh-plugin, mcp, stuga

## 简介

Connect a DeepSeek Harness profile to Stuga: its MCP tools, the key's workspace and its conventions in the system prompt, and playbook skills for reviewed edits.
