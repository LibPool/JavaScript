# @integrobr/mcp-server

> 标签: brasil, cte, fiscal, integrobr, mcp, model-context-protocol, nfe, nfse, nota-fiscal

## 简介

Servidor MCP da IntegroBR: deixa um agente de IA consultar as notas fiscais eletrônicas (NFS-e, NF-e e CT-e) monitoradas pelo CNPJ da empresa, em modo somente leitura.
