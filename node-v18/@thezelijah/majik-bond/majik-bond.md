# @thezelijah/majik-bond

> 标签: bond, cashflow, finance, financial-calculator, financial-modeling, investment, javascript, tax, typescript, yield

## 简介

Majik Bond is a lightweight TypeScript/JavaScript library for modeling bonds, calculating cashflows, yields, and tax effects. Ideal for investors, finance tools, or applications that need precise bond planning and return estimation.
