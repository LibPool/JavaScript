# @padiworks/padiworks-ui-system

> 标签: JavaScript

## 简介

A React project bootstrapped with **Vite**, styled using **TailwindCSS**, and documented with **Storybook**.   Unit and component tests are handled with **Vitest** + **Storybook Addon Vitest**.
