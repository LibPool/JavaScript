# @fvc/tabs

> 标签: antd, design-system, fe-vis-core, fvc, react, react-component, tabs, ui

## 简介

`@fvc/tabs` provides FE-VIS styled tabs on top of Ant Design. It preserves Ant Design's tablist, tabpanel, keyboard, focus, and panel-mounting behavior while applying the AVIS UI kit pill design.
