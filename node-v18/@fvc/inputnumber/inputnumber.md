# @fvc/inputnumber

> 标签: antd, design-system, fe-vis-core, fvc, inputnumber, react, react-component, ui

## 简介

`@fvc/inputnumber` provides the FE-VIS styled numeric field on top of Ant Design. It keeps the Ant Design `InputNumber` behaviour familiar — parsing, formatting, clamping, keyboard stepping and ARIA semantics — while restyling it to the AVIS UI kit design
