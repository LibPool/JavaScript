# @wiztheagent/openclaw-ironmesh

> 标签: agent, channel, decentralized, ironmesh, mesh, openclaw, p2p, plugin

## 简介

OpenClaw channel plugin that uses IronMesh as transport. Lets OpenClaw agents see other mesh peers as contacts and exchange messages over the encrypted local-first mesh.

- 官网：https://ironmesh.org
- 源码仓库：git+https://github.com/WizTheAgent/IronMesh.git
