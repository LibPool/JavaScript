# @permaura/gateway

> 标签: agents, ai, capabilities, gateway, mcp, permaura, permissions, security

## 简介

Run the Permaura gateway with one command — give your AI agents permission, not keys. `npx -y @permaura/gateway --pair <code>` installs the gateway, starts it, and connects it to your permaura.com account.
