# @estoc/folder-object

> 标签: cid, content-addressing, did, folder-object, merkle, unixfs

## 简介

An object is a folder: UnixFS merkle hashing (IPIP-499 unixfs-v1-2025), the folder-object format (read, validate, hash), did:key object cards (sign, verify), and the signed-object layout. Pure functions, no IO; runs in Node, workerd, and the browser.
