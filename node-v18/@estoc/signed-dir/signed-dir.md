# @estoc/signed-dir

> 标签: cid, content-addressing, ipld, merkle, signed-directory

## 简介

Owner-signed directory trees: IPLD-notation merkle hashing (raw file CIDs + dag-json dir nodes) and the signed root card. Pure functions, no IO; runs in Node, workerd, and the browser.
