# @tarcisiopgs/devsweep

> 标签: cleanup, disk, docker, linux, macos, node_modules, simulator, tui, windows, worktree

## 简介

Find and remove what a developer's machine accumulates: build artifacts, agent worktrees, simulators, emulators, Docker leftovers and dev caches.
