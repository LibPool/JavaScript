# @treatjs/ant-sdk-linux-x64-musl

> 标签: JavaScript

## 简介

Prebuilt Treat Ant native SDK for linux-x64-musl (x86_64-unknown-linux-musl). Consumed by treat-ant-bridge's default build via TREAT_ANT_SDK_PATH / node_modules discovery.
