# reborn-pixelrag

> 标签: claude, claude-code, korean, pixelrag, pixelshot, plugin, scraping, screenshot

## 简介

웹페이지를 사진으로 찍어 클로드가 눈으로 읽게 하는 PixelRAG 의 pixelbrowse 플러그인(StarTrail-org/PixelRAG · Apache-2.0)을 공식 명령으로 설치해 주고, 한국어 안내 스킬을 넣어 줍니다. pixelshot 명령(uv → pipx → pip)까지 깔고 실제로 도는지 확인합니다. 본체는 제작자의 것이며 대신 만들지 않습니다.
