# @belloai/bello-version

> 标签: JavaScript

## 简介

因为Github Actions 线上版本构建部署是通过Tag来触发的，并且Tag要按照一定的规则来，以完成线上版本的控制。为了减少人工打Tag带来的失误，因此开发一个CLI命令行工具辅助上线前的打Tag工作。
