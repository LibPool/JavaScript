# @echo-agent/tui

> 标签: agent, ai-agent, bun, llm, terminal, tui

## 简介

Echo's terminal shell: the interactive TUI and the first-run credential setup, packaged as the terminal implementation of the assembly layer's shell port. Requires Bun.
