# @gamedaysuits/i18n-autopilot

> 标签: auto-translate, i18n, internationalization, l10n, localization, multilingual, openrouter, seo, translation

## 简介

Automatic translation companion for next-intl and i18next projects. Keep 35+ locale files in sync via LLM translation with cultural tone registers.
