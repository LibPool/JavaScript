# @tailor-ai/node

> 标签: ab-testing, experimentation, feature-test, personalization, server-side, tailor

## 简介

Run Tailor tests in your own server code. Picks a test's variant in memory, with no network call per request, and records conversions alongside the Tailor tag on your page.
