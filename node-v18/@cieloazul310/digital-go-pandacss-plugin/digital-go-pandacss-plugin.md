# @cieloazul310/digital-go-pandacss-plugin

> 标签: JavaScript

## 简介

このパッケージはデジタル庁デザインシステムの[Design Tokens]をPanda CSSに移植したプラグインです。   このパッケージは[Pandaプリセット]に含まれていますが、単体での利用も可能です。
