# infinite-coastlines

> 标签: canvas, coastline-paradox, fractal-dimension, fractals, javascript, koch-snowflake, mandelbrot, math, richardson, self-similarity

## 简介

An interactive guide to the coastline paradox and fractal dimension: measure an island with shrinking rulers, build a Koch snowflake, and zoom into the Mandelbrot set.
