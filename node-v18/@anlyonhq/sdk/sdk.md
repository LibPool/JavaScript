# @anlyonhq/sdk

> 标签: agent-actions, ai, ai-agents, anlyon, api, approvals, human-in-the-loop, idempotency, sdk, secrets, typescript, webhook

## 简介

Official TypeScript SDK for Anlyon. Your agent invokes a named action. Anlyon holds the credentials, evaluates policy, waits for approval when required, and makes the production call.
