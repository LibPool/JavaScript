> 标签: auth-api, auth-library, authentication, facebook-login, github-oauth, google-oauth, javascript, jwt, login, nodejs, oauth, oauth2, unified-auth

## 简介

One authentication layer for every platform. Watchman JS is a developer-friendly OAuth library that provides a unified API for Google, GitHub, Facebook, Apple and more with minimal setup.
