# @transtyle/exporter-mantine

> 标签: css-variables, design-system, design-tokens, dtcg, mantine, mantine-theme, react, theming

## 简介

Transtyle exporter for Mantine 9: a createTheme object with one virtual colour per role, and a cssVariablesResolver carrying the per-scheme colours.
