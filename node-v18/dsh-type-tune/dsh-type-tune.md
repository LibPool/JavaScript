# dsh-type-tune

> 标签: deepseek-harness, dsh, dsh-plugin, font, plugin, readability, typography, wallpaper, web-ui

## 简介

DSH Web GUI typography & readability tuner: wallpaper-aware contrast repair, edge recolor and hue-cycle effects, per-content rules (bold+underlined links, tinted headings) and a floating WYSIWYG preview window.
