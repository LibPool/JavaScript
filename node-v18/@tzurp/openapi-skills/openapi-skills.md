# @tzurp/openapi-skills

> 标签: agent, api, cli, graphql, openapi, schema, skills, swagger, testing, validator

## 简介

CLI toolkit for exploring OpenAPI and GraphQL schemas, generating operation artifacts, validators, and tests. Includes an agent skill bundle that teaches AI tools how to operate the CLI safely and efficiently.
