# @usemosaik/plugin-tanstack-query

> 标签: JavaScript

## 简介

The TanStack Query Plugin implementation: adds @tanstack/react-query, a configured query client at src/libs/queryClient.{ts,js}, and wraps the app in a QueryClientProvider by overwriting src/main.{tsx,jsx}.
