# @knewbeing/vitepress-plugin-autosidebar-toc

> 标签: blog, documentation, markdown, navigation, sidebar, typescript, vite-plugin, vitepress, vue3

## 简介

Auto-generate sidebar, navigation, and blog components for VitePress. Provides Markdown scanning, metadata extraction, and ready-to-use components (AutoToc, SidebarArticleList).
