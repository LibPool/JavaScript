# @bender0oo0/postgres

> 标签: client, database, db, driver, pg, postgre, postgres, postgres.js, postgresql, postrges, sql

## 简介

postgres 3.4.9 with the nextWrite null-socket fix from porsager/postgres#1209 backported, plus a write-buffer reset on close so a reconnect after a buffered write does not hang. Temporary until an upstream release ships it.
