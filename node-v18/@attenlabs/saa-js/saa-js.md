# @attenlabs/saa-js

> 标签: addressee-detection, barge-in, browser, conversational-ai, device-directed-speech, elevenlabs, javascript, livekit, llm, openai-realtime, pipecat, pre-stt, real-time, selective-auditory-attention, speech-recognition, stt, turn-detection, twilio, vad, voice-agents, voice-ai, wake-word, webrtc

## 简介

Browser/JavaScript SDK for SAA, the addressee layer for voice agents — emits a turn_ready event per device-directed utterance so only speech meant for your agent reaches your STT, LLM, or TTS. No wake word.
