# @zpos/capacitor-d3-printer

> 标签: capacitor, cloudpos, d3, escpos, printer, thermal-printer

## 简介

Capacitor plugin for D3 onboard thermal printer — uses the CloudPOS SDK PrinterDevice API for raw ESC/POS output.
