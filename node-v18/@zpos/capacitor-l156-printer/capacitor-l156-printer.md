# @zpos/capacitor-l156-printer

> 标签: capacitor, escpos, l156, printer, thermal-printer

## 简介

Capacitor plugin for L156 onboard thermal printer (Android POS device). Wraps the vendor AutoReplyPrint USB SDK; payload is base64 to preserve binary ESC/POS bytes through the bridge.
