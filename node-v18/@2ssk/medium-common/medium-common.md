# @2ssk/medium-common

> 标签: JavaScript

## 简介

A TypeScript utility library that provides Zod schemas and TypeScript types for handling common inputs such as authentication and post management. This library can be used to validate input data for user signup, and post creation or updates in a TypeScrip
