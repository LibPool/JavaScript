# @selego/mongoose-elastic

> 标签: elasticsearch, mongodb, mongoose

## 简介

Mongoose Elastic is a [mongoose](http://mongoosejs.com/) plugin that can automatically index your models into [elasticsearch](https://www.elastic.co/).
