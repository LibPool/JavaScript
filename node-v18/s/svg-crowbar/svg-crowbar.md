# svg-crowbar

> 标签: png-crowbar, svg-crowbar

## 简介

A library based on a Chrome-specific bookmarklet that extracts SVG nodes and accompanying styles from an HTML document and downloads them as an SVG file

## 官网

- 官网：https://svg-crowbar.js.org/
- 源码仓库：git+https://github.com/cy6erskunk/svg-crowbar.git
- npm 页面：https://www.npmjs.com/package/svg-crowbar
