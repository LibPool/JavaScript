# stick-drift-detect

> 标签: analog-stick, controller, controller-test, deadzone, drift, game-controller, gamepad, gamepad-api, joystick, stick-drift

## 简介

Pure, zero-dependency stick-drift verdict logic for the Gamepad API — feed raw (x,y) samples, get a PASS / DRIFTING / FAIL verdict. The verdict engine behind controllertester.co.
