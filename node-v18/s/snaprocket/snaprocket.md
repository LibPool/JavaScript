# snaprocket

> 标签: automation, cli, full-page, headless-chrome, puppeteer, responsive, screenshot, screenshots, viewport, visual-testing

## 简介

Command line tool that captures full-page screenshots of a website at several viewport widths in one run, using Puppeteer.
