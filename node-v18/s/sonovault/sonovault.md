# sonovault

> 标签: apple-music, audio-recognition, beatport, discogs, isrc, iswc, metadata, music, music-api, musicbrainz, spotify, tidal

## 简介

TypeScript/Node client for the SonoVault music metadata API — ISRC, ISWC, genre, labels, release dates, and cross-platform IDs for 93M+ tracks.
