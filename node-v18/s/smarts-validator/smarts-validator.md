# smarts-validator

> 标签: cheminformatics, chemistry, molecular, parser, smarts, smiles, validator

## 简介

A standalone, zero-dependency JavaScript validator for SMARTS (SMiles ARbitrary Target Specification) patterns and reaction SMARTS
