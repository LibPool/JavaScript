# sgi3-crypto

> 标签: certificate-transparency, experimental-crypto, fujisaki-okamoto, hash-based-signature, merkle, module-lwe, research, rfc6962, sponge, sugaku, unreviewed, wots, xmss

## 简介

実験的な自己完結型暗号スタック — ARX-M置換 / スポンジハッシュ / モジュールLWE(K=4/FO変換付き, 古典255bit・量子232bit=Kyber1024/NIST Category5) / ハッシュベース署名 / PKI運用層(RFC6962透明性ログ・CRL・OCSP相当)。v5.0.0 で module-LWE を K=3→K=4 に強化(鍵・暗号文の形式が変わるため v4.x と非互換)。第三者査読を受けていないため実運用非推奨。
