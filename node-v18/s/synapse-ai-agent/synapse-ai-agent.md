# synapse-ai-agent

> 标签: agent, ai, ai-agent, assistant, automation, cli, github, llm, synapse, terminal

## 简介

One-command installer for Synapse Agent - the self-improving AI agent with terminal access, GitHub integration, and a messaging gateway. Bootstraps the official Python install.
