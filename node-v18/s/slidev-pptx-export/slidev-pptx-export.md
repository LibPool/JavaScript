# slidev-pptx-export

> 标签: export, markdown, powerpoint, pptx, presentation, slidev

## 简介

Convert a Slidev markdown deck into a fully editable native .pptx - real PowerPoint text boxes, tables, shapes and charts, not a screenshot-per-slide export.
