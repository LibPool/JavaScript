# sentinel-cli

> 标签: agent, ai, cli, coding-assistant, gemini, groq, llm, mcp, ollama, openai

## 简介

Minimalist AI coding assistant for the terminal (Pi-style). Multi-LLM, local tools, sessions, MCP — no servers, no telemetry.
