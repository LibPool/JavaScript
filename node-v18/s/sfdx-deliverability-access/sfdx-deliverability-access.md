# sfdx-deliverability-access

> 标签: salesforce, sfdx, sfdx-cli, sfdx-plugin

## 简介

SFDX Plugin to set Email Deliverability Access Level for an org via command line. This project uses Puppeteer and headless browsing to open Setup in the target org and set Email Deliverability Access Level to the desired value.
