# specrail

> 标签: ai-agent, claude-code, contract-first, gherkin, prd, spec-driven, workflow

## 简介

以 PRD 為核心的規格驅動開發工作流——為 AI coding agent 設計的十步流程（skills / rules / hooks / templates），npx specrail init 一鍵導入專案
