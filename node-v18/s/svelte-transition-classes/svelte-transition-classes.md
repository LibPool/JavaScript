# svelte-transition-classes

> 标签: svelte, svelte-transition, tailwindcss

## 简介

svelte-transition-classes adds a set of base classes, a set of classes the be on the element at the start of the transition and then a set of classes that replace the initial classes on the initial tick. CSS animations or transitions included in the class
