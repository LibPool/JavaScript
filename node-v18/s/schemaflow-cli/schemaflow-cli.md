# schemaflow-cli

> 标签: cli, database, er-diagram, erd, orm, prisma, schema, sql, visualization

## 简介

Interactive, code-based DB schema visualizer with diagram⇄SQL, auto join-paths, migrations, export and an advisor. Reads SQL, Prisma, Django, SQLAlchemy and TypeORM.
