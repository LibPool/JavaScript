# skillrl

> 标签: agent-skills, ai, ai-tools, aws, bedrock, claude, claude-code, cursor, developer-tools, gemini, kiro, llm, mcp, model-context-protocol, openclaw, recursive-language-models, rlm, skill-distillation, skillrl, trajectory-learning

## 简介

Automatic skill distillation, retrieval, and evolution from coding agent trajectories. Implements SkillRL (arXiv:2602.08234v1) for Kiro, Claude Code, Cursor, and OpenClaw. Supports Gemini, Amazon Bedrock, and Claude providers.
