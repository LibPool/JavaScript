# swagger-type

> 标签: JavaScript

## 简介

## 三个入参 @SwaggerUrl：字符串：SwaggerUI请求的url ，@type：字符串 包含type字符串的url都将请求， @exclude：字符串数组 ,数组中存在的url将不请求。
