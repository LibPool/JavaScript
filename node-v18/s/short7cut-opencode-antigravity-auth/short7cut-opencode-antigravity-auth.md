# short7cut-opencode-antigravity-auth

> 标签: antigravity, auth, claude, gemini, google, oauth, opencode, plugin

## 简介

Google Antigravity OAuth plugin for OpenCode (Desktop-friendly fork) - multi-account manager with per-account quota/usage display. Access Gemini 3 Pro and Claude 4.6 using Google credentials.
