# simple-json-order

> 标签: config-files, json, json-formatter, json-keys, json-order, json-sort, json-stringify, json-utils, map-to-json, ordered-json, ordered-keys, preserve-order, serialization, stable-json

## 简介

A lightweight JavaScript utility to preserve the insertion order of top-level keys in JSON objects — ideal for config files, logs, or any use case where key order matters.
