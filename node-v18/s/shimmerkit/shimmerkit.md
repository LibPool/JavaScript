# shimmerkit

> 标签: a11y, accessible, angular, content-placeholder, css-animation, custom-elements, framework-agnostic, frontend, loader, loaders, loading, loading-indicator, loading-placeholder, loading-spinner, loading-state, nextjs, placeholder, preact, react, shimmer, shimmer-effect, skeleton, skeleton-loader, solid, spinner, spinners, ssr, suspense-fallback, svelte, tree-shakeable, ui, ui-components, vue, web-components, zero-dependency

## 简介

Zero-dependency, framework-agnostic animated loaders & skeleton placeholders. One tuned engine, drops into React, Vue, Svelte, or plain HTML via Web Components. Accessible by default.
