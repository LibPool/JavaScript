# socketx-client-public

> 标签: mte, mte-relay, socketx, websocket

## 简介

SocketX Client is the JavaScript WebSocket client for the SocketX server in the Eclypses marketplace images. It bundles the MTE library and its license, so it installs with no setup. See https://socketx.eclypses.com.
