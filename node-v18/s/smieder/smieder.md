# smieder

> 标签: JavaScript

## 简介

Simple node express middleware to concat and/or compress javascript files on the fly.  It basically is a middleware for [node-minify](https://www.npmjs.com/package/node-minify) taking care of modification of the scriptfiles, no file watchers are used.
