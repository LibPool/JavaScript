# soap-powercenter

> 标签: soap

## 简介

A minimal node SOAP client based off node-soap by vpulim http://github.com/isaacs/npm and adapted to work with powercenter

## 官网

- 源码仓库：git+https://bitbucket.org/WGU_SF/soap-powercenter.git
- npm 页面：https://www.npmjs.com/package/soap-powercenter

- 当前版本：0.1.0

- 0.1.0

## 获取地址

- npm 安装：`npm install soap-powercenter`
- npm registry：https://registry.npmjs.org/soap-powercenter
- Node 要求：>=0.8.0
