# strands-dynamodb-storage

> 标签: agent, aws, dynamodb, memory, session, storage, strands, strands-agents

## 简介

Amazon DynamoDB storage backend for the Strands Agents SDK — one Storage implementation for Session Manager, Memory Manager, and any subsystem, with optional S3 offload for large values and an optional native vector-search hook.
