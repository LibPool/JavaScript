> 标签: customizable-skin, markdown, syntax-highlighting, vue

## 简介

Non-traditional markdown, finally is to generate web pages, using vue2 custom components grammatical relation, customizable skin, automatically generated directory , supports syntax highlighting.Used to write static blog open source project documentation,
