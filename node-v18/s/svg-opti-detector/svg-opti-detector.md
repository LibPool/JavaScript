# svg-opti-detector

> 标签: analysis, cli-tool, duplicate-detection, file-size, html, optimization, optimization-report, svg, svgo, web-performance

## 简介

A powerful Node.js tool to analyze, optimize, and detect duplicate inline SVGs in HTML from URLs or local files. Provides detailed optimization reports with color-coded output and potential file size savings.
