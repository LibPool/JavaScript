# storiesfly

> 标签: api-client, follower-tracker, instagram, instagram-analytics, instagram-api, instagram-stories, shadowban, stories, telegram-mini-app, typescript, unfollowers

## 简介

TypeScript client for the StoriesFly API: Instagram stories, profiles, highlights, media URLs, shadow ban checks and follower/unfollower tracking.
