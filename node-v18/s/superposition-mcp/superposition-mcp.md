# superposition-mcp

> 标签: agentic-ai, ejentum, mcp, metacognition, model-context-protocol, premature-collapse, superposition

## 简介

MCP server for Superposition: one keyless tool that returns a two-pole terrain map so your agent can locate which reading of an ambiguous task it has collapsed onto. Calls the public api.ejentum.com/superposition endpoint, or runs the published heuristic
