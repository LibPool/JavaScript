# screenshot-pdf-api

> 标签: api wrapper, headless browser, html to image, html to pdf, metadata, og tags, pdf, rapidapi, screenshot, url to pdf, url to png, webpage capture

## 简介

Official Node.js wrapper for the Screenshot & PDF API. Capture screenshots, generate PDFs, extract metadata, and render HTML to images.
