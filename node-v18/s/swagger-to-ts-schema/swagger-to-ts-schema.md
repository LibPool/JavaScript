# swagger-to-ts-schema

> 标签: JavaScript

## 简介

命令参数： url：swagger路径 或 配置json文件 className：api命名空间，默认为$api output：输出的文件路径 默认为 ./ fileName：输出的文件名称，默认为 api force：是否强制覆盖文件 debug：debug模式 type： 1. schema：默认，输出所有api 2. valid：只生成项目内已使用的api
