# specship-cli

> 标签: ai, claude-code, mcp, specship, workflow

## 简介

Unscoped CLI shim for @selvakumaresra/specship. Lets users run `npx specship-cli …` without remembering the scope. The `specship` binary it installs is identical to the scoped package's.
