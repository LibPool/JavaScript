# soft-frosted-icons

> 标签: custom-element, duotone, frosted, glass, glassmorphism, icon-set, icons, react, soft-ui, svg, web-component

## 简介

136 frosted glass SVG icons in two finishes, outline and duo-tone, on one 48px grid. Web component, SVG strings, React wrapper and plain SVG files. No dependencies.
