# semantic-release-pnpm-deps

> 标签: changelog, dependencies, deps-analyzer, github, pnpm, publish, release, semantic-release, semantic-release-monorepo

## 简介

It's a semantic-release plugin to analyze dependencies updates in pnpm workspace and auto publish a new version if necessary.

## 官网

- npm 页面：https://www.npmjs.com/package/semantic-release-pnpm-deps

- npm registry：https://registry.npmjs.org/semantic-release-pnpm-deps
- Node 要求：>=14.17
