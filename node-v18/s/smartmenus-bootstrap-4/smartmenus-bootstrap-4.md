# smartmenus-bootstrap-4

> 标签: accessible, bootstrap, ecosystem:jquery, jquery-plugin, menu, mobile, navigation, responsive, ui

## 简介

Provides support for creating zero config advanced Bootstrap 4 navbars with the SmartMenus jQuery plugin (smartmenus).
