# simple-blog-ui

> 标签: component-library, dark-mode, design-system, highlight-js, lit, mkdocs, monospace, react, react-components, shadow-dom, simple-blog, storybook, terminal-style, typography, ui, ui-kit, ui-library, vue, vue3, web-components

## 简介

Terminal-style UI component library for simple-blog. 45 Web Components that work in plain HTML, React, and Vue. Built with Lit. Monospace, uppercase, 2px solid borders, zero rounded corners.
