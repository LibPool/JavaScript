# salesdock

> 标签: api, client, cloudflare-workers, crm, energy, salesdock, sdk, serverless, telecom, typescript

## 简介

Unofficial, universal, fully-typed TypeScript SDK for the Salesdock API. Not affiliated with Salesdock. Runs on Node.js, Cloudflare Workers, Deno, Bun, and the browser.
