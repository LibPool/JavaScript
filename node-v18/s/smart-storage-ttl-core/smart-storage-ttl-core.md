# smart-storage-ttl-core

> 标签: cache, localstorage, storage, ttl, zero-dependency

## 简介

A zero-dependency, ultra-lightweight JavaScript library that supercharges the browser's native localStorage with intelligent expiration times (TTL), automatic memory cleanup, and smart fallbacks.
