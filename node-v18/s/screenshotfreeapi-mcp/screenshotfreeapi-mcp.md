# screenshotfreeapi-mcp

> 标签: ai-tools, claude, mcp, model-context-protocol, playwright, screenshot, screenshotfreeapi, web-capture

## 简介

MCP server for ScreenshotFreeAPI — capture websites and app store listings from any MCP-compatible AI client (Claude Desktop, Cursor, VS Code Copilot, Cline, etc.)
