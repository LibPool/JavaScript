# standard-schema-faker

> 标签: arktype, effect, fake-data, faker, json-schema, mock, mocking, standard-schema, test-data, valibot, zod

## 简介

Fake data for any Standard Schema validator — Zod, Valibot, ArkType, Effect Schema, and friends. Seeded, typed, zero config. Root entry is a zero-dependency JSON-Schema-driven walker; `standard-schema-faker/faker` and `standard-schema-faker/chance` add ba
