# sanity-prefixed-slug

> 标签: input, sanity, sanity-plugin, slug, url

## 简介

A replacement for the default Sanity slug input component that provides better features and UX. Adapted from https://github.com/hdoro/sanity-plugin-prefixed-slug/ with support for Sanity v4 and React v19.
