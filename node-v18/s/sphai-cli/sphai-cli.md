# sphai-cli

> 标签: claude, cli, codex, finder, mcp, transcript, wechat, 视频号

## 简介

视频号工具箱 CLI / MCP:提取微信视频号的基础数据、下载链接与文案,可在 Claude Code / Codex 等工具中使用;浏览器授权、无需手动密钥
