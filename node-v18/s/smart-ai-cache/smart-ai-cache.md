# smart-ai-cache

> 标签: ai, ai-tools, anthropic, api-cache, cache, caching, chatgpt, claude, cost-reduction, embeddings, gemini, google, gpt, llm, machine-learning, middleware, nodejs, openai, performance, redis, semantic, semantic-cache, typescript, vector-search

## 简介

TypeScript-native semantic cache for LLM responses (OpenAI/Anthropic/Google). Sub-millisecond exact-match plus an optional zero-API-key semantic layer that serves paraphrased prompts. Memory or Redis.
