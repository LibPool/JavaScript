# signal-lib

> 标签: react, reactive, realtime, signal, svelte, sync, typescript, vue, websocket

## 简介

Signal-lib makes real-time variable sync as simple as saying hello — define a shared variable, and it stays in sync across server and all connected clients over WebSocket automatically. No manual messaging, no polling, no boilerplate — just signals.
