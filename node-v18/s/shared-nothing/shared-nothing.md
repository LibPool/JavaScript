# shared-nothing

> 标签: SharedArrayBuffer, concurrency, lock-free, napi, rust, shared-memory, worker-threads

## 简介

Serialization-free, lock-free shared-memory object graph for Node.js worker threads, written in Rust (N-API). Powered by Vexify · Apache-2.0.
