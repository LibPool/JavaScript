# shbat

> 标签: JavaScript

## 简介

ShBat is a TypeScript library that allows you to generate both Windows Batch (.bat) and Unix Shell (.sh) scripts using a simple chained API. It supports variables, output, directory operations, file copy/delete, program launching, conditional statements,
