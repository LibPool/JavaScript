# swagger-ui-relative

> 标签: JavaScript

## 简介

This is a package to add support for relative paths to the openAPI schema $ref tags. This package provides a wrapper to use around your swaggerSpec json to automatically resolve any relative paths. Now you can have your schema references point to jsonsche
