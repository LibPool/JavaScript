# spfx-check-locale

> 标签: nodejs, sharepoint-framework, spfx, vscode, webpack

## 简介

Dynamically checks the consistency of your localization files inside SharePoint Framework projects, i.e. localization files match the schema inside "mystrings.d.ts".
