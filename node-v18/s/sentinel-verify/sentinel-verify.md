# sentinel-verify

> 标签: ai-agents, claude, code-verification, copilot, cursor, local-first, mcp

## 简介

A fully local, open-source verification layer for AI coding agents. Plugs into any MCP-compatible agent and lets it self-check its work before a human sees it.
