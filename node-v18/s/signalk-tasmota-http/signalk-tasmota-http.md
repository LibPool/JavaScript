# signalk-tasmota-http

> 标签: http, signalk-category-digital-switching, signalk-category-hardware, signalk-node-server-plugin, smart-plug, tasmota

## 简介

Control Tasmota smart plugs/relays from Signal K over HTTP (no MQTT, no Node-RED), with optional energy metering
