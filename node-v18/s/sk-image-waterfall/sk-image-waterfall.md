# sk-image-waterfall

> 标签: lazyload, masonry, miniprogram, skeleton, waterfall, weapp, wechat, wechat-miniprogram, 瀑布流, 骨架屏

## 简介

微信小程序通用图片瀑布流组件：预留高度防抖动 + 骨架屏 + 淡入 + 多列 + 触底加载。A WeChat Mini Program image waterfall/masonry component with zero layout-shift, skeleton shimmer and fade-in.
