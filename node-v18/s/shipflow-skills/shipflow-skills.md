# shipflow-skills

> 标签: agent-skills, azure-devops, claude-code, copilot, jira, pull-request

## 简介

Speckit-shaped Agent Skills that take an ADO/Jira work item to an opened PR. `npx shipflow-skills init` installs them into a repo for Claude Code and GitHub Copilot.
