# structureai

> 标签: ai, cli, contact, data-extraction, email, extraction, invoice, json, nlp, parser, receipt, resume, structured-data, text-extraction

## 简介

Extract structured JSON from messy text using AI. Supports receipts, invoices, emails, resumes, contacts, and custom schemas.
