# sealed-env

> 标签: 2fa, aes-gcm, argon2, cli, cross-platform, dotenv, encryption, env, sealed-env, secrets, spring-boot, supply-chain-security, totp, vault

## 简介

Encrypted .env files with optional TOTP unsealing for production deploys. Cross-stack with the Java port. One minimal CLI dependency.
