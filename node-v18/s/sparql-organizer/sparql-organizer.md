# sparql-organizer

> 标签: JavaScript

## 简介

Add component via NPM command: ``` npm install sparql-organizer ``` Then import it just like any other React component: ``` import Organizer from "sparql-organizer/lib/sources/Organizer"; ``` Also you will need to import some .css files for stylin
