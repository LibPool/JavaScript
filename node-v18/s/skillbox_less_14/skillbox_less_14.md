# skillbox_less_14

> 标签: JavaScript

## 简介

Mодуль «Кнопка», который содержит кнопку для вставки на веб-страницу. Кнопка обладает простой функциональностью: при каждом клике на ней отображается количество сделанных кликов (1 клик, 2 клика, 3 клика и т.д.).
