# strapi-plugin-knowledge-base

> 标签: content-manager, documentation, knowledge-base, plugin, redmine, strapi, strapi-plugin, textile

## 简介

In-context documentation for the Strapi 5 admin: a 👀 button next to every content type, component and field opens a Textile (Redmine-style) description of what it is and where it's used. Content lives in per-language JSON files, not the database.
