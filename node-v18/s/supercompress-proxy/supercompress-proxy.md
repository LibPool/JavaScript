# supercompress-proxy

> 标签: agent-plugins, aider, claude-code, codex, coding-agents, context-compression, cursor, fx, grok, grok-build, hermes, llm-cost, mcp, openclaw, opencode, prompt-compression, supercompress, token-compression, vercel, xai

## 简介

SuperCompress for coding agents — run setup once to auto-install MCP + hooks and cut ~65% of LLM input tokens. Benchmarks at supercompress.dev/benchmarks.
