# safe-json-repair

> 标签: deepseek, fix-json, json, json-repair, llm, openai, parser, repair, structured-output, tolerant, tool-calling

## 简介

A JSON repair library that never throws and never silently drops data — keeps the sibling keys LLMs orphan with a stray closing delimiter.
