# shapeshifter

> 标签: alias, definitions, entity, flow, generate, graphql, interface, prop, prop-types, react, schema, schematic, shape, shift, shifter, struct, transpile, type, typescript

## 简介

Generate relational schemas, PropTypes, Flow aliases, and TypeScript interfaces from JSON, JS, or GraphQL schematic files.
