# solana-agent-kit-plugin-pulse

> 标签: drainer, mcp, rug-check, safety, sendai, solana, solana-agent-kit, transaction-simulation, x402

## 简介

Solana Agent Kit plugin for Solana Pulse: check a transaction before signing (drainers, wrong recipient or amount, failures), token safety verdicts, fees and plain-words explanations, from live mainnet data with sources.
