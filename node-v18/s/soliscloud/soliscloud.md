# soliscloud

> 标签: api, client, ginlong, inverter, pv, solar, solis, soliscloud, typescript

## 简介

Framework-agnostic TypeScript client for the SolisCloud Platform API (V2.0.3). Covers all device and plant interfaces with full request signing.
