# solana-execution-mcp

> 标签: ai-agents, claude, mcp, model-context-protocol, solana, spl-token, web3

## 简介

A Model Context Protocol server exposing read-only Solana tools: SOL price, wallet balance, SPL token balances, and recent transactions.
