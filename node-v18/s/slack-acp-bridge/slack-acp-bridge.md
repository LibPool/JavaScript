# slack-acp-bridge

> 标签: acp, agent-client-protocol, bridge, claude, claude-code, codex, coding-agent, gemini, slack, slack-bot, socket-mode

## 简介

Slack (Socket Mode) bridge to ACP coding agents — one Slack thread = one agent session. Claude Code bundled; Codex, Gemini CLI and any ACP agent pluggable.
