# sve-ui

> 标签: a11y, accessible, bits-ui, component-library, css-variables, dark-mode, design-system, headless-ui, runes, svelte, svelte5, sveltekit, ui-components

## 简介

Styled, accessible Svelte 5 components built on Bits UI. No Tailwind, no config — install, import, and theme with CSS variables. Light and dark out of the box.
