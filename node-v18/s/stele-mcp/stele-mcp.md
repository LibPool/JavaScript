# stele-mcp

> 标签: adr, claude, claude-code, decision-log, mcp, provenance, sqlite

## 简介

实录 / Stele — carve decisions as they're made, traceable ever after. Local MCP server + SQLite decision-provenance store; primary client is Claude Code.
