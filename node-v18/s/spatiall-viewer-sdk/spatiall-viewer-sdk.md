# spatiall-viewer-sdk

> 标签: 3d-mapping, 3d-point-cloud-viewer, ai-infrasolutions, geospatial, sdk, viewer

## 简介

TypeScript SDK for integrating a 3D/panorama viewer for Spatiall Studio data into any web-based project.
