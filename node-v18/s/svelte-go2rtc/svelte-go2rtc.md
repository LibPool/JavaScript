# svelte-go2rtc

> 标签: JavaScript

## 简介

This library provides a Svelte component to display a video stream from a [go2rtc](https://github.com/AlexxIT/go2rtc) server. The component was ported from [WebRTC Camera](https://github.com/AlexxIT/WebRTC).
