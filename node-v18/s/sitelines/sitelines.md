# sitelines

> 标签: claude-code, claude-skill, dead-links, information-architecture, link-checker, navigation, site-map, sitemap, static-analysis, user-flow

## 简介

Map, audit, and edit a website's navigation. Scans every page and every link between them, serves an interactive map with live page previews, flags dead links and orphans, and queues your edits for an agent to implement.
