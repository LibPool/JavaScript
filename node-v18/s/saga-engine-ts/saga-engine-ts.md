# saga-engine-ts

> 标签: compensating-transactions, distributed-transactions, event-driven, idempotency, microservices, orchestration, saga, saga-pattern, typescript, workflow

## 简介

Framework-agnostic orchestration-based saga engine for multi-step async workflows with step-level idempotency, compensating transactions, and crash recovery.
