# storno-cli

> 标签: ai-tools, anaf, claude, cursor, e-factura, e-invoicing, invoicing, mcp, model-context-protocol, romania, storno

## 简介

MCP server for the Storno.ro e-invoicing API — enables AI tools (Claude, Cursor, Windsurf) to manage invoices, clients, companies, and the full e-Factura workflow
