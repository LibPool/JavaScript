# stripe-web

> 标签: JavaScript

## 简介

- This lib is WIP - TypeScript typings for Stripe web bundle - `loadStripe()` loads Stripe bundle from `https://js.stripe.com/v3/` - `getStripe()` returns global Stripe object, if one present
