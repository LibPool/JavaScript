# single-task-button

> 标签: JavaScript

## 简介

If you keep click a react-native button as quick as possible, it will execute the `onPress` method multiple times. This `SingleTaskButton` is to resolve this problem, by waiting **300** milliseconds. So keep in mind this button can not keep things execute
