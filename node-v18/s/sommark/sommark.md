# sommark

> 标签: documentation, dsl, html, json, language, mapper, mapping, markdown, markup, markup-language, mdx, parser, transpiler, xml

## 简介

SomMark is a template language that compiles to multiple output formats — HTML, JSON, YAML, TOML, CSV, Markdown, XML, and more.
