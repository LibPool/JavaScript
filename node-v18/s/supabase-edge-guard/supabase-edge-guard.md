# supabase-edge-guard

> 标签: cli, lovable, nextjs, rls, row-level-security, sarif, security, static-analysis, supabase, tanstack-start

## 简介

Cross-boundary static analyzer for Next.js, TanStack Start, Lovable and Supabase apps. Catches getSession() spoofing, service_role bypasses, exposed SECURITY DEFINER RPCs and RLS mistakes before deploy.
