# stream2multipart

> 标签: axios, binary, download, multipart, pdf, simple, stream, xls, xlsx

## 简介

Receive stream chunks and convert it into an easy to use object array, which can include plain text, JSON, or binaries like PDFs, JPEGs, XLS, XLSX.
