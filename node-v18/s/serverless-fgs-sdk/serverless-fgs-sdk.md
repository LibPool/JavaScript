# serverless-fgs-sdk

> 标签: JavaScript

## 简介

为 `Serverless Devs` 和 `Serverless Framework` 提供函数创建、更新、删除，触发器创建、更新、删除的功能。 当前已支持触发器的类型有`TIMER、DEDICATEDGATEWAY(APIG专享版)、OBS、KAFKA、SMN、LTS、CTS、DIS、DDS、RabbitMQ、EG OBS应用事件源`
