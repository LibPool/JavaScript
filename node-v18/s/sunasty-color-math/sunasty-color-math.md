# sunasty-color-math

> 标签: accessibility, color, contrast, hex, hsl, oklab, oklch, palette, quantization, srgb, tailwind, wcag

## 简介

Zero-dependency sRGB, HEX, HSL, and perceptual OKLCH color conversion engine with WCAG 2.1 contrast calculation, AA lightness auto-fix, Tailwind CSS shade matching, and RGBA palette quantization.
