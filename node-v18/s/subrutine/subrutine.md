# subrutine

> 标签: JavaScript

## 简介

Init subrutine config ```shell npx subrutine init ``` Add example button by subrutine ```shell npx subrutine add buttons/Black1 ``` ## Demo https://subrutine-buttons-demo.vercel.app/
