# sweepp

> 标签: ast, babel, cleanup, cli, code quality, dead code, import cleanup, javascript, linter, monorepo, pnpm, turborepo, typescript, unused imports

## 简介

Zero-config fast CLI to sweep unused JS/TS imports & detect unused code (heuristic) with monorepo support.
