# stream-sheet-export

> 标签: csv, excel, export, ooXML, spreadsheet, stream, vite-plugin, xlsx

## 简介

Browser-side streaming Excel/CSV exporter. Supports remote CSV/Excel URLs (CORS transform or direct download), JSON rows, AsyncIterable, custom formats and cell styles.
