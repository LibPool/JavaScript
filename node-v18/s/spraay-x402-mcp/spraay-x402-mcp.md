# spraay-x402-mcp

> 标签: ai-agents, base, batch-payments, defi, ethereum, mcp, micropayments, solana, spraay, usdc, x402

## 简介

Auto-syncing MCP server for the Spraay x402 Gateway. Auto-creates a wallet on first run — no env vars, just fund and go. Pay-per-call x402, USDC, no API keys.
