# stylerefs

> 标签: analyze, annotate, asset, ast, browser, compiler, css, dependency, exports, file, graph, gruntplugin, less, lesscss, link, merge, meta, metadata, module, parser, preprocess, reference, relationship, require, resource, sass, scss, source, static, static-reference, style, styles, stylesheet, stylus, view

## 简介

walk the dependency graph of your modules to look for CSS/LESS/SASS/Stylus file reference annotations. These files can then be bundled into a single CSS file.
