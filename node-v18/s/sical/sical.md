# sical

> 标签: Mathematics, area, bin2dec, binary, binary to decimal, combination, conversions, decimal to fraction, factorial, hexadecimal, n2f, number to fraction, octal, permutation, volume

## 简介

`sical` is a Node.js package that provides a collection of mathematical conversions, functions, trigonometric calculations, and geometrical computations for 2D and 3D shapes.
