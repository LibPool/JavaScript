# sortedkit

> 标签: avl-tree, bst, ceiling, floor, range, sorted, sortedcontainers, sortedmap, sortedset, treemap, treeset, typescript, zero-dependencies

## 简介

Zero-dependency TypeScript sorted collections: SortedSet and SortedMap backed by AVL tree. Port of Python sortedcontainers, Java TreeSet/TreeMap, C# SortedSet/SortedDictionary.
