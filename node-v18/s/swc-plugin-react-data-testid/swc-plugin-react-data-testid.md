# swc-plugin-react-data-testid

> 标签: automation, build-time, codegen, cypress, data-cy, data-test, data-test-id, data-testid, e2e, end-to-end-testing, jest, jsx, nextjs, playwright, react, selectors, swc, swc-plugin, test-automation, test-id, test-ids, testid, testing, testing-library, unique-ids, vite, vitest, wasm

## 简介

SWC plugin that automatically adds unique data-testid attributes to every React JSX element at build time — stable selectors for Playwright, Cypress and Testing Library, including per-item ids inside .map() loops. Zero config.
