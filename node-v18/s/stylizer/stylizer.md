# stylizer

> 标签: JavaScript

## 简介

Stylizer makes it super easy to integrate [Stylus](https://learnboost.github.io/stylus/), and stylus plugins, into a [Node.js](http://nodejs.org/)/[moonboots](https://github.com/HenrikJoreteg/moonboots) project.
