# spiderhunt

> 标签: cache, crawler, distributed, eventemitter, queue, rabbit, rabbitmq, redis, scalable, simple, simplecrawler, spider, spiderhunt

## 简介

Very straightforward web crawler. Uses EventEmitter. Based on Simplecrawler but using a distributed queue system.
