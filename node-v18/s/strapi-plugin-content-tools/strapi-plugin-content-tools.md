# strapi-plugin-content-tools

> 标签: content-manager, data-transfer, filters, i18n, media, plugin, strapi, strapi-plugin

## 简介

Content Manager productivity tools for Strapi 5: sticky per-content-type filters, move entries between languages, and pull content + media from another Strapi environment.
