# scalar-field-react

> 标签: canvas, colormap, gaussian, heatmap, interpolation, jet, react, scalar-field, typescript, visualization

## 简介

Render 2D scalar fields from scattered data points to an HTML canvas with Gaussian interpolation, polygon masking, and color maps — a small, typed React library.
