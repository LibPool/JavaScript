# sails-sql

> 标签: adapter, mssql, mysql, oracle, postgresql, sails, sails.js, sql, sql-server, sqlite3, waterline

## 简介

Flexible SQL adapter for Sails/Waterline.  Supports MySQL, PostgreSQL, SQL Server (MSSQL), Oracle, & SQLite.
