# spoil-wordle

> 标签: spoil, wordle

## 简介

Returns the answer to today's wordle. Time is specified by the system the package runs on. To get tomorrow's wordle, pass 1 as a parameter. To get the day after tomorrow's wordle, pass 2, etc.
