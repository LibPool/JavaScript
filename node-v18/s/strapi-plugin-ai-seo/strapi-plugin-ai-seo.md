# strapi-plugin-ai-seo

> 标签: ai, ai-seo, llm, meta-tags, og-tags, plugin, schema-markup, seo, strapi, strapi-plugin, twitter-card, yoast

## 简介

AI-powered SEO tag generator for Strapi. Reads yoastHeadJson or SEO component data from entries, generates meta tags, OG tags, Twitter cards, and schema markup using LLM, with copy and apply functionality.
