# ssbu-component-library

> 标签: JavaScript

## 简介

React component library built on **Tailwind CSS**, **Radix UI** / **Base UI**, and **TanStack Table**. It ships a large set of UI primitives (similar in spirit to shadcn/ui) plus a composable **data table** with toolbar filters, pagination, and URL-synced
