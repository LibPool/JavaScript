# smart-editor-v3

> 标签: JavaScript

## 简介

smart-editor-v3 是一款基于 Tiptap 编辑器核心进行深度二次开发的富文本编辑器引擎。项目初衷源自团队在实际业务中使用 WangEditor 5 所面临的功能扩展困难与性能瓶颈。为更好地支持电子教材创作中复杂的排版、嵌入式内容、多媒体管理等需求，我们从底层架构出发，打造了这套高可定制、插件化、模块化的编辑解决方案。
