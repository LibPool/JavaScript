# solarsql

> 标签: cloudflare, d1, durable-objects, migrations, sql, sqlite, typed-sql, typescript, workers

## 简介

Typed SQL for SQLite on Cloudflare D1 and Durable Objects: types from the real engine at build time, a command as one transaction, failures as values.
