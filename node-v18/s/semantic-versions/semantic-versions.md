# semantic-versions

> 标签: build-metadata, comparator, parser, precedence, range, ranges, semantic-versioning, semantic-versions, semver, version, versions, vlt

## 简介

The reference parser for Semantic Versions (semver.xyz): parse, validate, compare and range-match versions, with build metadata that participates in precedence.
