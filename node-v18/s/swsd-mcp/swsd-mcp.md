# swsd-mcp

> 标签: copilot-studio, itsm, knowledge-base, mcp, model-context-protocol, samanage, service-desk, solarwinds, swsd, ticketing

## 简介

MCP server for SolarWinds Service Desk (SWSD / Samanage). Dual transport: stdio for local agents, Streamable HTTP for Copilot Studio and hosted deployments. Not affiliated with SolarWinds.
