# scale-controller

> 标签: controller, div, scale, scale-controller, scale-controller-div, scale-controller-touch, scale-controller-zoom, scale-controller-zoom-div, scale-controller-zoom-touch, touch, zoom

## 简介

指定的div 元素，使其可以双指缩放，用于为网页元素添加触摸缩放功能。
