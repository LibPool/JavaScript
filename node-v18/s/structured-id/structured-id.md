# structured-id

> 标签: alphanumeric-id, checksum, id, id-generator, identifier, luhn, mod36, mullvad, numeric-id, random, structured-id, typescript, unique-id, validation

## 简介

Generate and validate structured IDs — numeric or alphanumeric, with optional Luhn or mod36 checksums. Zero dependencies. TypeScript.
