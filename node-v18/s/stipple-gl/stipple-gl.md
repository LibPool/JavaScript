# stipple-gl

> 标签: animation, canvas, morph, morphing, particle-system, particles, react, stipple, svg, typescript, webgl, webgl2

## 简介

GPU-rendered WebGL2 particle field that morphs into any SVG. Zero dependencies, framework agnostic, with a first-class React binding.
