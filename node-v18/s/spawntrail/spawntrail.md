# spawntrail

> 标签: async-hooks, asynclocalstorage, bullmq, context, contextual-logging, correlation-id, distributed-tracing, express, job-context, logger, logging, mapped-diagnostic-context, mdc, middleware, observability, opentelemetry, otel, pino, queue, request-id, structured-logging, trace, traceid, tracing, winston

## 简介

Contextual logging for Node via AsyncLocalStorage and Mapped Diagnostic Context (MDC). Attach request-scoped context to every log line, with any logger (winston, pino) and any framework (express, fastify, koa). Zero dependencies, TypeScript-first.
