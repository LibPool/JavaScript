# sic-mapping-toolkit

> 标签: Angular, GIS, Maps, Openlayers, SIConsultores, Web Mapping

## 简介

SICMapping Toolkit es una biblioteca para Angular que permite la creación de aplicaciones de Web Mapping por medio de OpenLayers
