# smz-g-diagram-lib

> 标签: diagram, electrical, g-language, svg, vue3

## 简介

基于 Vue 3 的电力单线图渲染组件，支持 **G 语言格式** 的图形文件解析、设备故障高亮、悬浮/固定气泡提示、缩放平移等交互功能。
