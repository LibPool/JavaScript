# sftp-to-papertrail

> 标签: aws, lambda, papertrail, s3, sftp

## 简介

A Node module that retrieves one or more log files via SFTP, and logs new entries to Papertrail. Deploys to AWS Lambda and uses S3 for maintaining state.
