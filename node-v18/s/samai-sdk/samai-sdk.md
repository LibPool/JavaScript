## 简介

SamAI SDK is a provider-agnostic TypeScript AI SDK for building AI agents, chatbots, tool calling, RAG, MCP, streaming, voice agents, and multi-provider LLM applications using OpenAI, Claude, Gemini, Groq, Mistral, Ollama, Azure OpenAI, and AWS Bedrock.
