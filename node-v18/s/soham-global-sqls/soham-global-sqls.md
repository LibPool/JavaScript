# soham-global-sqls

> 标签: claude, database, mcp, model-context-protocol, mssql, mysql, oracle, postgres, postgresql, sql

## 简介

Multi-engine SQL MCP server (MSSQL, MySQL, PostgreSQL, Oracle) with named connection profiles, audit logging, and a one-command setup wizard.
