# shot-drop-opencode

> 标签: images, opencode, opencode-plugin, screenshots

## 简介

OpenCode plugin that auto-saves pasted/dropped chat images as real files in the current project, so they get a path agents can use.

- npm 页面：https://www.npmjs.com/package/shot-drop-opencode
