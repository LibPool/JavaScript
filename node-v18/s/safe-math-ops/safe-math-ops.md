# safe-math-ops

> 标签: prevent weird decimal, safe math, weird decimal prevent

## 简介

The goal of this package was to prevent weird decimals from appearing when doing operations (e.g. 9.99 - 8 = 1.9900000000000002 instead of 1.99)
