# scuttledeck

> 标签: claude, claude-code, cost, github-actions, observability, opentelemetry, self-hosted

## 简介

Fleet monitoring for the Claude Code GitHub Action — self-hosted dashboard for runs, PRs, and true per-run cost. This package currently ships a pointer CLI; the full CLI is on the roadmap.
