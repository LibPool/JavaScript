# stripe-mock-sdk

> 标签: fintech, jest, malawi, mock, mwk, payments, stripe, testing, typescript, unit-test, vitest

## 简介

TypeScript drop-in mock of the Stripe SDK for unit testing payments, subscriptions, and webhooks — no network calls, no API keys.
