# svg-sprite-kit

> 标签: angular, cli, icon-sprite, icons, nextjs, react, sprite, sprite-generator, spritesheet, svelte, sveltekit, svg, svg-icons, svg-sprite, svg-sprites, typescript, vite, vite-plugin, vue, webpack, webpack-plugin, zero-dependencies

## 简介

Bundles SVG icons from a folder into a single SVG sprite file. Zero dependencies, recursive scanning, id isolation, IconName types. React, Vue, Svelte and Angular — through Vite, webpack, a CLI, or Next.js without a plugin.
