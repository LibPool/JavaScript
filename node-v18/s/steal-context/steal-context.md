# steal-context

> 标签: ai, claude, claude-opus, coding-agent, context, context-window, continues, cursor, developer-tools, fireworks, fireworks-ai, glm, glm-4-6, glm-5, glm-5-2, handoff, kilo-code, llm, mcp, opus-4, slash-command

## 简介

Type /steal in one AI coding chat to pull the latest conversation context from the OTHER tool (e.g. Cursor <-> Kilo Code). A thin, model-aware UX layer on top of `continues`.
