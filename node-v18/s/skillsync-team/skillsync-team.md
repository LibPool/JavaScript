# skillsync-team

> 标签: claude-code, claudeception, cli, git, skills, sync, team

## 简介

Git-native skill sharing for Claude Code teams. Semantic search, archive lifecycle, interactive picker, auto version bump, tab completion (bash/zsh/fish).
