# sql-watch

> 标签: CI/CD, Postgresql, Sql, Sql migration, Sql runner, bdd, behavior driven development, fdd, feature driven development, migration, migration tool, runner, tdd, test driven development, watch

## 简介

sql-watch is a command line utility that enables rapid SQL development by automatically applying idempotent SQL scripts to a database on file change.
