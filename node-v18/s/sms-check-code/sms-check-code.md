# sms-check-code

> 标签: vue插件, 仿原生效果的短信验证码组件, 短信验证码组件

## 简介

一个仿原生效果的短信验证码组件，vue2.6插件，无依赖。验证失败时动画加标红颜色显示，点击手机验证码平铺填充等
