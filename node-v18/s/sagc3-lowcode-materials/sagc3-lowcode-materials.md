# sagc3-lowcode-materials

> 标签: JavaScript

## 简介

`sagc3-lowcode-materials` 是当前仓库使用的低代码物料包，负责维护运行时组件、低代码元数据和构建产物，供 `apps/web` 中的低代码编辑器加载和注册。
