# solidity-crodwsale

> 标签: ERC20, contract, crowdsale, ethereum, solidity, update-from

## 简介

This package recovers the old OpenZeppelin 2.5.1 crowdsale contracts and get them updated to latest OpenZeppelin and solidity compiler versions
