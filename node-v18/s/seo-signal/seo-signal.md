# seo-signal

> 标签: core-web-vitals, indexnow, keyword-research, search-console, seo, sitemap

## 简介

Zero-dependency SEO scripts for sites whose pages live in a git repo: keyword-gap mining from autocomplete, content staleness scoring, sitemap sync, and an honest index-ping.
