# seenit

> 标签: ai-agents, claude-code, clone-detection, code-quality, copy-paste-detection, duplicate-code, jscpd, mcp, mcp-server, tree-sitter

## 简介

Has this already been written? Asks a copy/paste detector the question it does not answer — before you write, not after. Matches through renames and reformatting.
