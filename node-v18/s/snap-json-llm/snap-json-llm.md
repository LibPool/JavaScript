## 简介

Structured outputs for LLMs: force OpenAI, Anthropic Claude & Google Gemini to return valid JSON matching your schema. Zero-dependency Instructor alternative with JSON Schema enforcement, streaming partial JSON parsing, auto-repair & self-healing retries.
