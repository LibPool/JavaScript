# specialkey-emulator

> 标签: IOKit, brightness, emulator, hid, input, keyboard, keypress, mac, media, mediakey, mute, osx, playback, simulator, skip, specialkey, volume

## 简介

Emulate special keys (e.g. brightness, play/pause, increase volume) by emitting low-level global keyboard events - using NodeJS.
