# steel-lib

> 标签: alloy, gost, metallurgy, similarity, steel, гост, металлургия, стали

## 简介

Engine для сравнения и подбора аналогов марок сталей по ГОСТ. Поиск похожих марок, сравнение химического состава и механических свойств.
