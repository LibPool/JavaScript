# splitclaude

> 标签: anthropic, claude, claude-code, cli, quota, statusline, tokens, usage

## 简介

Per-machine usage gauge for a Claude Code account shared across n machines: 5h session + weekly + premium gauges in your statusline, with 50/80/100% share warnings.
