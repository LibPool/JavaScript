> 标签: agent, bridge, esc/pos, local, pos printer, pos printer agent, pos printer bridge, pos printer bridge agent, pos printer driver, pos printer driver agent, pos printer driver bridge, pos printer driver bridge agent, printer, siyaho

## 简介

JavaScript client for Siyaho Printer Agent — local ESC/POS bridge for web POS apps. Install the Windows agent from pos.siyaho.com, then use this SDK in your browser app.
