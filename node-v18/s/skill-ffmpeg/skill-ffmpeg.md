# skill-ffmpeg

> 标签: audio, claude-code, claude-skill, ffmpeg, ffmpeg-static, ffprobe, fmode, transcode, video

## 简介

Claude Code skill: run ffmpeg/ffprobe for audio & video processing via a bundled static binary (ffmpeg-static). No system ffmpeg install required. Provides `npx skill-ffmpeg exec`/`probe`/`which` passthrough plus a Claude Code skill.
