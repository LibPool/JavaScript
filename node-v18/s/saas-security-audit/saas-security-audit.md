# saas-security-audit

> 标签: appsec, bola, claude-code, cli, devsecops, idor, multi-tenant, nextjs, owasp, rls, row-level-security, saas, saas-security, sast, secret-scanning, security, security-audit, security-scanner, supabase, tenant-isolation

## 简介

SaaS security scanner CLI: finds tenant isolation gaps, IDOR/BOLA, missing Supabase RLS, leaked secrets, SQL injection, CORS and webhook flaws. Maps evidence to 22 controls. Local, read-only, no network.
