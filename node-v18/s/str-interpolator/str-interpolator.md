# str-interpolator

> 标签: Angular, Javascript, React, Vue, dynamic-strings, dynamic-template, keypath-interpolation, nested-templates, object-path-replacement, placeholder-replacement, string-formatting, string-interpolation, string-replacer, string-template, template-engine, template-interpolator, template-strings, template-variables, value-substitution

## 简介

A TypeScript utility function to replace placeholders in a string with values from an object, supporting both simple and nested object paths.
