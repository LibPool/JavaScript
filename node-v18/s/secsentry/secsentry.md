# secsentry

> 标签: api-keys, aws, git, github-actions, leaked-credentials, pre-commit, sarif, secret-scanning, secrets, security

## 简介

Git incident scanner for leaked secrets — working tree and history, blob-level dedup, masked case files. This package wraps the Go CLI.
