# sails-angular2-isomorphic

> 标签: API, REST, express, mvc, orm, sails.js, sailsjs, socket.io, web-framework

## 简介

API-driven framework for building realtime apps, using MVC conventions (based on Express and Socket.io), associated with angular2 using server rendering to have a powerful fullstack framework.
