# showonscroll

> 标签: ecosystem:jquery, jquery-plugin, reveal, scroll, show

## 简介

A client side module using jQuery to initially hide selected elements and then reveal them when scrolled over. Multiple different elements can be passed. Using CSS transitions that can be modified from the module's settings. Use with Browserify for client
