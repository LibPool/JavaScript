# simplex-js

> 标签: double-ratchet, e2e, encrypted, privacy, simplex, smp, websocket, x3dh

## 简介

Pure JavaScript implementation of the SimpleX Messaging Protocol. WebSocket transport, E2E encryption, X3DH, Double Ratchet, AES-256-GCM.
