# selwise-akinon-appmaker

> 标签: akinon, appmaker, personalization, react-native, selwise

## 简介

Selwise plugin for Akinon App Maker (rn-env 7). Subscribes to the app's own AnalyticsService, so tracking, identity, recommendations and order attribution work without editing screens.
