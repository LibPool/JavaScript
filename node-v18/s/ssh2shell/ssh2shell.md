# ssh2shell

> 标签: SSH, automation, cipher, client, command, commands, connection, console, deploy, fingerprint, hash, host, hosts, multiple, persistent, prompt, sequential, server, session, shell, ssh2, su, sudo, tunnel, validation

## 简介

A wrapper class for ssh2 to run multiple sequential commands in an SSH shell session, handle command responses, and tunnel through to other hosts using nested host objects
