# sankey_d3

> 标签: JavaScript

## 简介

`om_charts_sankey` — это React-компонент для создания диаграмм Сэнкей. Этот пакет предоставляет простую интеграцию диаграммы в React-приложениях, работающих в эко системе Оптимакрос.
