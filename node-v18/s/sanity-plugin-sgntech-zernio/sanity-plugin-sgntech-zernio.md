# sanity-plugin-sgntech-zernio

> 标签: facebook, instagram, sanity, sanity-plugin, scheduling, social-media, studio-tool, zernio

## 简介

Plan, preview and publish Instagram and Facebook posts from inside Sanity Studio, through the Zernio API — calendar, previews and per-type validation included.
