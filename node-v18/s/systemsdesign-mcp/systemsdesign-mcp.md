# systemsdesign-mcp

> 标签: architecture, blueprint, claude, diagram, mcp, mermaid, model-context-protocol, system-design

## 简介

MCP server that lets AI agents draw technical/system-design diagrams into your Blueprint (systemsdesign.site) account and get a shareable, editable link.
