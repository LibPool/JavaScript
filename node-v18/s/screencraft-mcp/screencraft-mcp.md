# screencraft-mcp

> 标签: ai-agents, claude, demo-videos, macos, mcp, modelcontextprotocol, screen-recording, screencraft

## 简介

MCP server that lets AI agents drive ScreenCraft on macOS: start/stop screen recordings, then export polished videos with automatic zoom choreography generated from the agent's real clicks.

## 官网

- 官网：https://www.screencraft.live/mcp
- npm 页面：https://www.npmjs.com/package/screencraft-mcp

- npm registry：https://registry.npmjs.org/screencraft-mcp
