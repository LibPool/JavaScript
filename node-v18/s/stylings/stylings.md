# stylings

> 标签: animations, colors, composable-styles, css-in-js, design-system, flexbox, grid, inline-components, react, semantic-styling, style-composers, styled-components, styling, theme, typography

## 简介

An opinionated and joyful library for writing semantic, composable, and reusable styles in React using styled-components. Features chainable style composers, inline components, theming system, and automated style variants.
