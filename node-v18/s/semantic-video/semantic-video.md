# semantic-video

> 标签: ai-video, computer-vision, content-analysis, ffmpeg, frame-extraction, gpt-4-vision, gpt-5, nodejs, openai-vision, semantic-search, token-estimation, typescript, video-ai, video-analysis, video-indexing, video-moderation, video-processing, video-search

## 简介

Intelligent video analysis powered by OpenAI Vision API. Extract frames, analyze content, search videos semantically, and estimate token costs with FFmpeg and GPT-4/GPT-5 models.
