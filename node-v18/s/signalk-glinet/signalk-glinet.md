# signalk-glinet

> 标签: glinet, signalk-category-communication, signalk-node-server-plugin

## 简介

SignalK plugin that publishes status (system, WiFi, WAN, services, and cellular signal if present) from GL.iNet routers (stock firmware, e.g. GL-X3000 Spitz AX) via GL.iNet's JSON-RPC /rpc API.
