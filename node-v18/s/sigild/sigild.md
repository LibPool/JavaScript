# sigild

> 标签: agent, anthropic, claude, claude-code, eip-1559, eip-191, eip-712, ethereum, key-management, mcp, model-context-protocol, signing, supply-chain, wallet-security

## 简介

Claude can sign, but never see. MCP server + CLI that keeps private keys out of the LLM's context window.
