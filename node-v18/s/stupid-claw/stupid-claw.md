# stupid-claw

> 标签: JavaScript

## 简介

回归纯粹的极简本地 Agent：   基于 `pi-mono` 底座。业余时间开发，主要用于简单代码学习交流使用，欢迎反馈。   严格限制在指定目录，以纯文本格式读写记忆。没有数据库的黑魔法，只有你能完全掌控的代码。
