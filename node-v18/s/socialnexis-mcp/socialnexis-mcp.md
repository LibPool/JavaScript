# socialnexis-mcp

> 标签: ai-detector, claude, humanizer, linkedin, mcp, mcp-server, modelcontextprotocol, post-analyzer, post-ideas, social-media, twitter

## 简介

MCP server for SocialNexis free post tools: AI detector and humanizer for LinkedIn/X posts, post quality analyzer, and structured post idea generator. No API key required. From socialnexis.com/mcp.
