# storage-async

> 标签: async-storage, async-store, atomic-storage, cache, cache-storage, database, file-storage, file-store, json-store, key-val, keyv, storage-async, store, ttl, ttl-storage, ttl-store

## 简介

Lightweight, asynchronous, key-value JSON storage for Node.js applications. Supports TTL, atomic updates, self-repairing and more.
