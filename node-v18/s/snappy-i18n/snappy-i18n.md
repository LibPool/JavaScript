# snappy-i18n

> 标签: i18n, internationalization, localization, translation, typescript

## 简介

A lightweight, TypeScript-based internationalization (i18n) and localization (l10n) library for JavaScript applications. Designed to be framework-agnostic, extensible, and performant, @snappy/i18n provides robust features for managing translations, format
