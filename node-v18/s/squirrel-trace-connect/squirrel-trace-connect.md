# squirrel-trace-connect

> 标签: callbacks, llm, observability, openai, squirrel, squirrel-trace, telemetry, tracing

## 简介

Official integrations for squirrel-trace — wrap an OpenAI client or plug a chain-framework callback handler and every call is recorded in Squirrel with input, output, model, token usage and duration.
