# students-affairs-system

> 标签: bootstrap, crud, data-management, education, es6, json-server, oop, pagination, search, sorting, student-management, students-affairs, vanilla-js, vite

## 简介

A comprehensive web application for managing student, course, instructor, and employee data within a Students Affairs department. Features CRUD operations, pagination, search, and sorting capabilities.
