# strabomicrodev

> 标签: JavaScript

## 简介

StraboMicro provides tools for image management and data reporting for geologic data that is observed and analyzed at the microstructural scale (e.g., from thin sections). StraboMicro is part of the StraboSpot ecosytem (https://strabospot.org)
