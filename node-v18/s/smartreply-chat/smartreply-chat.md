# smartreply-chat

> 标签: add-to-cart, ai-chatbot, ecommerce, live-chat, nextjs, product-cards, react, rivet, rivet-chat, shopify, shopping-assistant, smartreply, woocommerce

## 简介

Lightweight React/Next.js loader for the Rivet Chat AI shopping assistant. Page-aware product cards, real-time inventory answers, and add-to-cart attribution for ecommerce stores.
