# sos-kit

> 标签: JavaScript

## 简介

sos-kit — 1-command installer for the sos CLI + full sister toolset (doctor/ship/docs-gate/inv-gate/...). Postinstall fetches install.sh@v0.1.0 (pinned tag, sha256-verified, fail-CLOSED) and runs it.
