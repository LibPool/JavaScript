# simple-apm-agent

> 标签: agent, apm, cpu, memory, middleware, monitoring

## 简介

This is a simple APM Agent middleware for node.js, which will send data to the APM-Server using API Connection. It will transfare CPU, Memory, Disk and all Requests.
