# superfastmongoexpress

> 标签: ReST, express, model, mongodb, mongoose, node, restify

## 简介

Create a REST interface for mongoose models and easily manipulate your database tables in html files your serve from your express server; Handle all the boilerplate needed to set up an express-mongo server into a single line of code
