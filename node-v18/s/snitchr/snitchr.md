# snitchr

> 标签: alerting, file-integrity, heartbeat, intrusion-detection, linux, macos, monitoring, security, self-hosted, server-monitoring, ssh-monitoring, uptime

## 简介

Self-hosted server monitoring powered by a zero-dependency bash agent. Runs on Cloudflare Workers, Node.js, and Bun.
