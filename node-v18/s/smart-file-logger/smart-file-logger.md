# smart-file-logger

> 标签: express-middleware, file-logger, log-rotation, logger, nodejs, typescript, weekly-logs, zero-dependency

## 简介

A production-ready, zero-dependency Node.js file logger with weekly log rotation, retention policy, Express middleware, and full TypeScript support.
