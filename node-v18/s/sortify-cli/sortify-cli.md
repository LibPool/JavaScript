# sortify-cli

> 标签: cli, declutter, downloads-folder, file-management, file-organizer, productivity, sort-files

## 简介

Organize the files in a folder into meaningfully named subfolders by content type (Images, Documents, Videos, ...), with an interactive wizard, undo, and AI-optional smart naming.
