# sportwizzard-mcp

> 标签: ai-agent, arbitrage, claude, dfs, mcp, model-context-protocol, odds, sports-betting, sportwizzard

## 简介

Model Context Protocol (MCP) server for the SportWizzard sports-betting data API — query live odds, edges, arbitrage, player/team stats and reference data from any MCP-capable AI agent.
