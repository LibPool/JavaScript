# samethru

> 标签: claude-code, codex, cursor, data-consistency, gemini-cli, mcp, opencode, playwright, testing

## 简介

Same data, from database to screen. Checks that values match across your database, API and rendered page, as a local MCP server for AI coding tools: Claude Code, Cursor, Codex, Gemini CLI and OpenCode.
