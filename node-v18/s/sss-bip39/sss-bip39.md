# sss-bip39

> 标签: JavaScript

## 简介

Applies [Shamir's Secret Sharing Scheme](https://en.wikipedia.org/wiki/Shamir%27s_Secret_Sharing) to [BIP39 mnemonics](https://github.com/bitcoin/bips/blob/master/bip-0039.mediawiki).
