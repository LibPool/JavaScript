# spacedock-mcp

> 标签: claude, deploy, mcp, modelcontextprotocol, spacedock

## 简介

MCP server for SpaceDock — deploy a directory to a live HTTPS URL and read back what happened: startup errors, logs, screenshots, SQL over its database, fork-with-state.
