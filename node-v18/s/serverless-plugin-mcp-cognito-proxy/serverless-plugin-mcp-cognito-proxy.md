# serverless-plugin-mcp-cognito-proxy

> 标签: cognito, mcp, oauth, serverless, serverless-plugin

## 简介

Serverless Framework plugin: registration-free, stateless OAuth proxy (DCR + CIMD) in front of an existing AWS Cognito pool.
