# smart-naive-icon

> 标签: icon-picker, icon-renderer, iconify, icons, naive-ui, offline, vue, vue3

## 简介

Offline-first icon renderer and picker for Vue 3 + Naive UI, powered by Iconify. Render and browse bundled icon sets offline, inject your own local SVGs, or use any online Iconify icon.
