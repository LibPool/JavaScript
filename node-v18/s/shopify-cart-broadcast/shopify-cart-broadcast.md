# shopify-cart-broadcast

> 标签: ajax-cart, cart, cart-api, customevent, ecommerce, events, fetch, shopify, storefront, theme, xhr

## 简介

Reliable cart events for any Shopify theme. Intercepts the Fetch & XHR Cart APIs and re-broadcasts them as clean DOM CustomEvents.
