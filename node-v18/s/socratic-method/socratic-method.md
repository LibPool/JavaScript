# socratic-method

> 标签: agent-skill, ai, claude, claude-code, codex, cursor, llm, predict-then-run, self-correction, skill.md, socratic, windsurf

## 简介

An Agent Skill that makes an AI coding agent cross-examine its own work before it ships: predict-then-run, gated, and mostly silent. Run via npx to install SKILL.md into your agent's skills directory.
