# socket.io-amqplib

> 标签: MQ, amqplib, mq, socket, socket.io, socket.io-adapter, socket.io-parser, socket.io-redis, 分布式, 消息中间件, 集群

## 简介

使用 amqplib 作为 SocketIO 的消息中间件, 提供比 redis 更稳定可靠的消息机制
