# ssh-chat-mcp

> 标签: ai, claude, kilo-code, llm, lm-studio, mcp, model-context-protocol, sftp, ssh, zero-config

## 简介

Zero-config SSH/SFTP MCP server. All connection data is passed at runtime from chat, never persisted to disk or MCP config.
