# sshx-mcp

> 标签: automation, cli, linux, mcp, model-context-protocol, remote, server, ssh, typescript, windows

## 简介

MCP server exposing SSH control for Linux and Windows systems — with exec, sudo-exec, upload and download tools. | 支持 Linux/Windows 的 SSH MCP 服务器，含文件传输功能。
