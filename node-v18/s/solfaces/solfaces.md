# solfaces

> 标签: ai-agent, avatar, defi, deterministic, deterministic-name, function-calling, generative, identity, mcp, name-generator, pfp, profile, react, sha256, solana, solnames, svg, tool-use, wallet, web3

## 简介

Deterministic wallet avatars and names for the Solana ecosystem. SHA-256 name derivation, zero-dependency trait engine with React, vanilla JS, and server-side rendering support.
