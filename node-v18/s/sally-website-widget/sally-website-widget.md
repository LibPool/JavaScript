# sally-website-widget

> 标签: JavaScript

## 简介

Building bundle for enterprise platform - Navigate to ./src/index.tsx - Set const AS_PACKAGE as false - run: npm run-script build-bundle - bundle.js and styles.css will be present in ./dist/
