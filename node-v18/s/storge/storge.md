# storge

> 标签: JavaScript

## 简介

基于localStorage和sessionStorage封装的一个简易插件,设计初衷就是为了可以更加简便的使用本地存储功能。 ## 引入 > 通过CDN或手动下载和链接HTML中的storgejs ```js <script src="./storge.js"></script> <script>    storge.set('key', 1)   </script> ``` > 通过npm安装。您将需要在系统上安装Node.js。 ```js npm i storge ```
