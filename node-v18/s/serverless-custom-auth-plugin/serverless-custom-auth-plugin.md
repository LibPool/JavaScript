# serverless-custom-auth-plugin

> 标签: amazon, amazon web services, api gateway, aws, aws lambda, lambda, serverless applications, serverless custom auth, serverless plugins, serverless.com

## 简介

Serverless Custom Auth Plugin - A serverless plugin that adds the possibility to configure AWS_IAM or Cognito Auth for your API Gateway endpoints and 'Invoke with caller credentials'
