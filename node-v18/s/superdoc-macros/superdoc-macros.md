# superdoc-macros

> 标签: autotext, docm, docx, editor, macro-recorder, macros, otzaria, snippets, superdoc, vba

## 简介

Macro toolkit for SuperDoc-based editors: sandboxed scripted macros, a Word-style macro recorder, snippets with auto-text expansion, and read-only VBA import from .docm files.
