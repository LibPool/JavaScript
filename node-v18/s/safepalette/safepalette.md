# safepalette

> 标签: a11y, accessibility, color-blindness, colorblind, colorblind-safe, colors, cvd, data-visualization, okabe-ito, palette

## 简介

Generate, check, and fix colorblind-safe color palettes — protanopia, deuteranopia, tritanopia. Built on the published OpticQuiz engine (Machado 2009 + CIEDE2000) with the Okabe-Ito safe palette.

## 官网

- 官网：https://opticquiz.com/checker/
- 源码仓库：git+https://github.com/vince-gonzalez/opticquiz.com.git
- npm 页面：https://www.npmjs.com/package/safepalette
