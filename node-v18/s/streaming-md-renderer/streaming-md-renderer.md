# streaming-md-renderer

> 标签: chat, katex, latex, llm, markdown, react, real-time, streaming, tokenizer

## 简介

A real-time streaming markdown tokenizer and React renderer. Processes LLM output chunk-by-chunk with support for code blocks, tables, LaTeX math, and inline formatting.
