# skylab-clean-folder-claudia

> 标签: JavaScript

## 简介

El programa recoge por un parámetro de entrada (-f o --folder) un nombre de carpeta, obligatorio. Si la carpeta no existe, imprimirá un error y terminará la ejecución del proceso.
