# specshot

> 标签: api-mock-server, cli, codegen, custom-templates, dx, mocking, openapi, openapi-to-typescript, openapi-to-zod, swagger, type-safe, typescript

## 简介

Fire an OpenAPI spec, get strictly-typed TypeScript code and a robust API mock server — zero-dependency, Zod-validated, and highly customizable.
