# stacked-scroll

> 标签: deep-link, editorial, full-page-scroll, fullpage, gsap, pin, pinned-sections, scroll, scroll-effect, scroll-jacking-alternative, scrolltrigger, scrollytelling, section, stacked-pages, stacked-scroll

## 简介

A small, hardened library that turns your sections into a stack of pages: each header stays pinned while you read, then hands off cleanly to the next page as it slides up from below.
