# scanic-ml

> 标签: JavaScript

## 简介

Optional ML document-corner detector assets for scanic, a channel-slimmed SimCC model (DocCornerNet) and a custom minimal ONNX Runtime Web WASM build (1.5 MB, ~88% smaller than stock ort-web).
