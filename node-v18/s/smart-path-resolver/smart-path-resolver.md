# smart-path-resolver

> 标签: async-path-resolver, data-traversal, deep-access, javascript, map-set-resolver, nested-properties, object-path, path, resolver, typescript

## 简介

A lightweight and fast JavaScript/TypeScript library for resolving object paths with support for arrays, Maps, Sets, and function calls.
