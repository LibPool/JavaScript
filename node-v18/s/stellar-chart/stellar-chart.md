# stellar-chart

> 标签: JavaScript

## 简介

A standalone javascript web component to display a stellar graph, as described by Alexandre Morin-Chassé in [Off the “radar”? Here are some alternatives ](https://www.significancemagazine.com/science/684-off-the-radar-here-are-some-alternatives).
