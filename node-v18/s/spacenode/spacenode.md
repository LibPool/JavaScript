# spacenode

> 标签: REST API, SSR, WebSocket, api, auto-discovery, dependency-injection, event-bus, framework, guards, http, microservices, modular, pipeline, rest, server, spacenode, templates, zero-dependencies

## 简介

SpaceNode - Node.js microservice framework. Auto-discovery modules, SSR, REST API, static-site, pipeline middleware, DI container (singleton/transient/scoped), event bus, guards, WebSocket, dto and zero dependencies - all in one box.
