# smpltrek-builder

> 标签: builder, config, drum, exporter, smpltrek, sonicware

## 简介

Packs a drum-pattern-engine song into a device-loadable Sonicware SmplTrek project Config. Includes SmplTrek genre presets. No runtime dependencies.
