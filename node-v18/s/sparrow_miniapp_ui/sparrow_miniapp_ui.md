# sparrow_miniapp_ui

> 标签: JavaScript

## 简介

sparrow_miniapp_ui 是北京汉光百货前端团队自主开发的微信小程序ui组件库，旨在帮助开发者快速开发微信小程序。 > 注意：目前该组件库还处于beta阶段，图标库还未完善。非团队成员请先不要使用该组件库。
