# shopify-geo-toolkit

> 标签: aeo, ai-seo, answer-engine-optimization, generative-engine-optimization, geo, llms-txt, seo, shopify

## 简介

Open-source GEO/AEO toolkit for Shopify. Generates llms.txt, audits Product schema, and checks AI-crawler access via robots.txt.
