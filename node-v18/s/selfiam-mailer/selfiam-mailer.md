# selfiam-mailer

> 标签: api, api-keys, email, email-api, email-sdk, mailer, rate-limiting, resend, selfiam, smtp-alternative, transactional-email

## 简介

Official Node.js / TypeScript SDK for the SelfIAM Mailer API — send transactional emails, manage API keys, track delivery with rate limiting built in.
