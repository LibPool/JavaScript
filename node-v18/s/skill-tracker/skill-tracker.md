# skill-tracker

> 标签: agents, analytics, anthropic, claude-code, cli, cost-tracking, jsonl, skills, token-usage

## 简介

CLI tool to analyze Claude Code skill and agent usage from JSONL conversation files. Shows which skills cost the most tokens, agent spawn frequency, and estimated USD costs with turn-based attribution.
