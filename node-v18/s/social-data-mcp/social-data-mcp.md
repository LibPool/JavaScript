# social-data-mcp

> 标签: apify, mcp, mcp-server, model-context-protocol, scraper, tiktok, twitter, x, youtube

## 简介

MCP server exposing three pay-per-result social data tools (X/Twitter profiles & tweets, YouTube videos & channels, TikTok profiles & videos) hosted on Apify. Thin stdio wrapper around @apify/actors-mcp-server.
