# segmented-input

> 标签: duration, input, ipv4, ipv6, mac, picker, rgba, segmented, uuid

## 简介

A library for creating segmented text inputs that behave like <input type="date">. Supports IPv4, IPv6, RGBA, duration, UUID, MAC addresses, and any custom format.
