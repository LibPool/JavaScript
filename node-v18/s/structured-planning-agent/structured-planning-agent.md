# structured-planning-agent

> 标签: agent, llm, orchestration, planning, spa, state-machine

## 简介

结构化独立规划引擎 CLI 的 npm 入口（spa）。底层引擎为 Python 包 structured-planning-agent（PyPI），本包提供跨平台命令包装：npx spa / npm i -g structured-planning-agent
