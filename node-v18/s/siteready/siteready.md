# siteready

> 标签: afdocs, agent-readiness, ai-agents, astro, claude-skill, cli, cloudflare-pages, is-agentic, llms.txt, ora

## 简介

Scan a website with agent-readiness scanners (afdocs, Vercel Is Agentic, Ora), get a unified scorecard, auto-fix supported issues (Astro + Starlight, or plain Astro, + Cloudflare Pages, Netlify, or GitLab Pages; Next.js + Vercel or Netlify; Jekyll + GitHu
