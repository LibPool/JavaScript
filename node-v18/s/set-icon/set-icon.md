# set-icon

> 标签: JavaScript

## 简介

Node.js wrapper around [NSWorkspace.setIcon(_:forFile:options:)](https://developer.apple.com/documentation/appkit/nsworkspace/1529882-seticon). You can use this to change icons for .apps.
