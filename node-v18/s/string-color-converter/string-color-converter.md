# string-color-converter

> 标签: hsl2hsv, hsl2rgb, hsv2hsl, rgb2hex, rgb2hsl, rgba2hexa, str2rgb, string-color-converter

## 简介

ColorConverter convert string color value to color values object having all values required to any programmer to handle color related coding. It also have collection of methods that convert color values from one type to another type.
