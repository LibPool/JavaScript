# samsung-notes-mcp

> 标签: claude, handwriting, mcp, model-context-protocol, samsung-notes, sdocx

## 简介

Let Claude read your Samsung Notes: typed text, handwriting pages, photos and PDFs. MCP server that never changes your notes.
