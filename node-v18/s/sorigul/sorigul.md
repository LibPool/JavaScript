# sorigul

> 标签: hangul, korean, korean-letters, machine-learning, ml, tts, 한글

## 简介

한글 낱자(자모)를 소리나는 대로의 낱자(자모)로 변환해주는 패키지입니다. A package that convert Korean Hangul to how they sound like in Hangul.
