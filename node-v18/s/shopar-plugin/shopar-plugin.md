# shopar-plugin

> 标签: 360° product viewer, 3D preview, AR, DeepAR, ShopAR, VTO, Virtual try-on

## 简介

Plugin for the Web that seamlessly integrates into your webpage to create embedded virtual try-on and 3D preview capabilities.
