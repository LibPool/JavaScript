# slidev-theme-raft

> 标签: neo-brutalism, raft, slidev, slidev-theme, theme

## 简介

A neo-brutalism Slidev theme in the visual language of Raft — Raft Ink borders, hard shadows, Cotton Core cream, and Soft Signal yellow.
