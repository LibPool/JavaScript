# steam-trends-mcp

> 标签: ai-tools, claude, cursor, gaming, mcp, model-context-protocol, steam, steam-mcp, steam-trends, trendsmcp

## 简介

Steam player trends as an MCP tool. Plug into Claude, Cursor, or any MCP-compatible AI host. Weekly series, growth percentages, and live Steam most-played games. Powered by trendsmcp.ai
