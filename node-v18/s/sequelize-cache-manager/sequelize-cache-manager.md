# sequelize-cache-manager

> 标签: cache, caching, orm, redis, sequelize, stale-while-revalidate, ttl, typescript

## 简介

Lightweight cache manager for Sequelize models with TTL, stale-while-revalidate, auto-refresh, LRU eviction, multi-model orchestration, and optional Redis backend.
