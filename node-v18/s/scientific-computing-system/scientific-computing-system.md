# scientific-computing-system

> 标签: cli, launcher, machine-learning, ode-solvers, quantum, scientific-computing, statistics

## 简介

Scientific Computing System launcher - a thin Node wrapper that forwards to the pure-Python `cds` CLI. This npm package ships NO Python code: it requires the Python distribution to be installed (`pip install scientific-computing-system`), otherwise `scs`
