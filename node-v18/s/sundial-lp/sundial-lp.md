# sundial-lp

> 标签: linear-programming, optimization, solver, wasm, webgpu

## 简介

GPU linear-programming solver (restarted PDHG) running as WebGPU compute shaders — in the browser, no CUDA, no server. Every Optimal is CPU-f64-verified.
