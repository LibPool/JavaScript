# solooutpost-mcp

> 标签: claude, digital-nomad, freelancer, immigration, mcp, modelcontextprotocol, passport, relocation, solooutpost, solopreneur, tax, visa

## 简介

MCP server for the SoloOutpost Visa & Tax API: relocation, visa, and tax data for ~150 countries, by passport or by country. Built for solopreneurs and freelancers.
