# shim

> 标签: array, cujo, es5, es6, function, json, object, polyfill, shim, string, xhr

## 简介

shim.js is the a collection of UMD modules that shim (aka "polyfill") old environments to support modern (aka "ES5-ish" and "ES6-ish") javascript.

## 官网

- 官网：https://github.com/cujojs/poly
- 源码仓库：https://github.com/cujojs/poly
- npm 页面：https://www.npmjs.com/package/shim
