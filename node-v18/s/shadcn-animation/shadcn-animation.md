# shadcn-animation

> 标签: animate, animation, css, design, motion, plugin, preset, tailwind, tailwindcss

## 简介

Shadcn Animation is a Tailwind CSS Plugin made by Manfromexistence. It’s a simple, yet powerful, animation library for Tailwind CSS specially useful when working with Shadcn/Ui.

- 官网：https://manfromexistence-ui/animation
- 源码仓库：git+https://github.com/manfromexistence/ui.git
- npm 页面：https://www.npmjs.com/package/shadcn-animation
