# sour.js

> 标签: arweave, decentralized, ens, ethereum, ethers, ipfs, ipns, web3

## 简介

ENS name resolution, decentralized content fetching (IPFS/IPNS/Arweave), and ENS domain registration (Citron) — core logic only, no UI.
