# snowping-apis

> 标签: JavaScript

## 简介

Sebuah module API wrapper untuk layanan Snowping API. Module ini mengambil referensi endpoint secara dinamis dari file JSON dokumentasi, sehingga Anda tidak perlu repot menghafal URL endpoint-nya.
