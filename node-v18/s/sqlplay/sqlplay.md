# sqlplay

> 标签: console, database, h2, in-memory, learn-sql, playground, practice, sql, sql.js, sqlite, wasm

## 简介

An H2-Console-style SQL playground for JavaScript. Practice SQL in a real in-memory SQLite database that runs 100% in your browser — zero backend, zero setup.
