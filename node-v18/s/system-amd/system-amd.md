# system-amd

> 标签: JavaScript

## 简介

[system.js](https://github.com/systemjs/systemjs) is magic, however it dit not provide an es package.  This module can be used by `import system from 'system-amd'` and `await system.import('https://url/to/any/amd/module')`.
