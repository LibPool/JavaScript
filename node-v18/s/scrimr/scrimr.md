# scrimr

> 标签: animation, lightweight, loading, loading-effect, react, scrambled-text, shimmer, skeleton, tailwindcss, typescript, ui-components

## 简介

🎲 A simple React shimmer component that displays animated random text while loading. Lightweight alternative to skeleton screens.
