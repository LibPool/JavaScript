# styles-from-html

> 标签: css, get, grab, html, parse, rule, separate, style, stylesheet, tag

## 简介

Given html, will return all css styles from style tags as a concatenated string, as well as the resulting html with these style tags removed. Useful when you need to pass in css that is separated from html to another library while having declared css rule
