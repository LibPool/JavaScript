# sumlyzer

> 标签: cli, github-actions, junit, junit-xml, monorepo, monorepo test output, node --test, node test runner, npm test readability, npm workspaces logs, npm workspaces test output, parallel test output, workspace test logs

## 简介

Run every npm workspace's test script, only show output for the ones that fail, and finish with an aggregated pass/fail summary.
