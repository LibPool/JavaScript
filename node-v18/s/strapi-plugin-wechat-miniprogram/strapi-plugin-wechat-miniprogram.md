# strapi-plugin-wechat-miniprogram

> 标签: miniprogram, plugin, strapi, wechat

## 简介

A Strapi v5 plugin for WeChat Mini Program APIs. This plugin creates a collection table WechatUser and a simple table WechatConfig. The WechatUser table stores WeChat user information, with a user field linking to the wechat_user relation in the User tabl
