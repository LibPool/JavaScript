## 简介

Static analyzer for AI coding-agent context, and an Agent Skill. Measures always-on context cost of CLAUDE.md, AGENTS.md and Agent Skills; finds skills that will not load, stale paths, duplicates. Claude Code, Codex, Cursor, Gemini CLI. Research project.
