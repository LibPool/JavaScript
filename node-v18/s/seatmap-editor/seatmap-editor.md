# seatmap-editor

> 标签: canvas, dxf, editor, konva, seat-map, seat-selection, seating, seatmap, stadium, svg, theater, venue, vue, vue3, 场馆, 座位图, 选座

## 简介

基于 Vue 3 与 Konva 的场馆绘座与选座编辑器：区域绘制、复合区域孔洞、DXF/SVG 导入、票档分配与分阶段发布计划。
