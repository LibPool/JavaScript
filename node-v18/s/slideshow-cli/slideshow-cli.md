# slideshow-cli

> 标签: cli, cloudflare, ffmpeg, pexels, slideshow, tiktok, typescript, video, workers-ai

## 简介

Generate TikTok-style multiple-image slideshow videos from a prompt with Cloudflare Workers AI, Pexels, and ffmpeg.
