# scrum-poker

> 标签: JavaScript

## 简介

A "Scrum Poker" estimation picker component published as a **native Web Component** (`<scrum-poker>`) in TypeScript, built once in Vue and consumable from other frameworks (Vue, React and Angular) without rewriting the UI for each one.
