# safe-to-prompt

> 标签: agent, ai-agent, ci, cli, headless, interactive, non-interactive, prompt, tty, zero-dependency

## 简介

Should your CLI prompt, or ask for a flag? Under a coding agent, a prompt can end your CLI with exit code 0 having done nothing, or wait forever. Says no under agents and CI, with a reason you can print. Zero dependencies.
