> 标签: ES6, backend, file, framework, fs, host, http, https, javascript, link, middleware, module, navigation, node, nodejs, read, request, route, router, routing, script, server, static

## 简介

ServScript is a lightweight and configurable Node.js module for handling HTTP requests and serving static files with customizable routing and advanced callbacks.
