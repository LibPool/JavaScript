# stock-sdk

> 标签: A股, JavaScript, TypeScript, ai, akshare, browser, cli, indicators, kline, mcp, node, sdk, stock, 港股, 美股, 行情

## 简介

零依赖股票行情 SDK：A股/港股/美股/基金/期货/期权，浏览器 + Node.js 双端，内置 CLI 与 MCP server。Zero-dependency stock market data SDK (CLI + MCP) for browser & Node.js.
