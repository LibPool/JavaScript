# scenef-mcp

> 标签: california, cinema, film, hawaii, honolulu, los-angeles, mcp, modelcontextprotocol, movies, san-diego, san-francisco, showtimes

## 简介

Movie showtimes across California, Florida and Hawaii over MCP — 56 regional boards, chains, indies, and repertory houses, verified against each theater's own calendar. Local stdio server, read-only, no API key.
