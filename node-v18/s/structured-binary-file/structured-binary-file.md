> 标签: binary, circular, database, dbase, decode, embedded, encode, file, fixed, flat, length, persistence, record, struct, structure, structured, unpack

## 简介

Reads and writes data records stored in fixed width binary. CircularFile adds 'fixed record count' files to the mix
