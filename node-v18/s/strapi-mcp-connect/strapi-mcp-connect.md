# strapi-mcp-connect

> 标签: ai, anthropic, claude, cms, cursor, llm, mcp, modelcontextprotocol, strapi, strapi-mcp

## 简介

Model Context Protocol (MCP) server for Strapi CMS. Connects Claude Desktop, Cursor, VS Code, and AI IDEs to Strapi REST API.
