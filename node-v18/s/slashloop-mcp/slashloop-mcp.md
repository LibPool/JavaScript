# slashloop-mcp

> 标签: content-research, mcp, model-context-protocol, reels, shorts, tiktok

## 简介

Viral short-form video research MCP server — track sources, find outliers, run Gemini video analysis, generate hooks/briefs. Local stdio (Claude Code) or remote OAuth HTTP.
