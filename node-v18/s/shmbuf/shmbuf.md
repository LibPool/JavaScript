# shmbuf

> 标签: SharedArrayBuffer, atomics, cross-process, ipc, mmap, napi, native, shared-memory, shm

## 简介

Cross-platform shared memory for Node.js — returns a SharedArrayBuffer backed by OS shared memory, usable with Atomics across processes
