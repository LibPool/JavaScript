# sheet-view

> 标签: bottom-sheet, dialog, drawer, headless, modal, react, scroll-snap, sheet, showModal, unstyled

## 简介

Headless bottom-sheet / modal built on native <dialog> + CSS scroll-snap. Framework-agnostic core, thin React adapter, optional default theme.
