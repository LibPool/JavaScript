# schriftskala

> 标签: font scale, schriftskala, typescale, typo scale, typographic scale, typography, typography scale

## 简介

This is a simple utility to calculate the font sizes for a typographic scale. It is based on the [modular scale](http://www.modularscale.com/) principles.
