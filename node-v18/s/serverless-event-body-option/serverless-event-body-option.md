# serverless-event-body-option

> 标签: amazon, amazon web services, aws, lambda, serverless, serverless framework plugin, serverless.com

## 简介

The serverless plugin that provides the extra CLI option '--body/-b' for the invoke (local) command to support passing the HTTP body data directly.
