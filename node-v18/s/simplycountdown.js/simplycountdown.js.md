# simplycountdown.js

> 标签: clock, countdown, countup, plugin, react, simplyCountdown, vanilla, vue

## 简介

A lightweight (<5KB) JavaScript countdown library with zero dependencies. Create customizable countdown timers with multiple themes, TypeScript support, and a modern API for websites and web applications.
