# slicer-render

> 标签: JavaScript

## 简介

1. Copy a gcode file to `./example/example.gcode` 2. Copy an infinite z printer gcode file to `./example/example-infinite-z.gcode` 2. Copy a stl file to `./example/example.stl` 3. `nvm use` 4. `cargo watch -s ./start.sh`
