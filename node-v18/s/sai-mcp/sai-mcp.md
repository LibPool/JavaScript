# sai-mcp

> 标签: defi, graphql, mcp, model-context-protocol, nibiru, perpetuals, sai, sai.fun

## 简介

MCP server for the Sai.fun perpetual futures protocol on Nibiru Chain. Exposes the sai-keeper GraphQL API as MCP tools.
