# skolcal

> 标签: JavaScript

## 简介

Aplikace **Skolcal** slouží k **automatickému přenosu a synchronizaci školního rozvrhu ze systému Škola OnLine (SOL) do osobních kalendářů studentů** (Google Kalendář, Apple Kalendář, Outlook apod.) s podporou pro suplování, vlastní barvy předmětů a notif
