# ssrf-safe-fetch

> 标签: fetch, node, private-ip, redirect-validation, security, server-side-request-forgery, ssrf, url-validation

## 简介

SSRF protection for server-side requests: URL validation, private/reserved IP blocking (IPv4 + IPv6), and a fetch wrapper that re-validates every redirect hop.
