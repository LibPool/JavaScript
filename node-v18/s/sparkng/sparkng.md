# sparkng

> 标签: angular, bootstrap, component library, fluent, material, sparkng, tailwind, ui library

## 简介

SparkNG is an open source UI library for Angular featuring a rich set of 90+ components, design-token based theming with presets such as Aura, Lara, Material and Nora, and a pass-through API for full styling control.
