# stateful-process-command-proxy

> 标签: bash, command, command line, commandline, dos, exec, execute, powershell, process, shell, unix

## 简介

Module for executing commands in shells (bash or powershell etc) against a pool of stateful child processes such as bash or powershell via stdout and stderr streams
