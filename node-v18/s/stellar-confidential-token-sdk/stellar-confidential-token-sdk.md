# stellar-confidential-token-sdk

> 标签: confidential-tokens, noir, openzeppelin, soroban, stellar, ultrahonk, zero-knowledge

## 简介

Conformant TypeScript client for OpenZeppelin Confidential Tokens on Stellar — implements the SDK.md client obligations (key derivation, witness building, UltraHonk proving, local state, selective disclosure).
