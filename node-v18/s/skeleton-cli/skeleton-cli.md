# skeleton-cli

> 标签: JavaScript

## 简介

skeleton-cli 是一个通过项目模版来创建项目的构建工具，借鉴了[vue-cli@2.x](https://github.com/vuejs/vue-cli/tree/v2.9.3)的实现。
