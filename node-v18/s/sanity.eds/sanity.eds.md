# sanity.eds

> 标签: a11y, accessibility, aem, aem-live, aem-sidekick, audit, core-web-vitals, edge-delivery-services, eds, franklin, lighthouse, linter, performance, sanity-check, seo, sidekick-plugin

## 简介

AEM Sidekick plugin for Edge Delivery Services (EDS) sites — scans a live page for performance, SEO, security, accessibility, and aem.live-limits issues, with click-to-locate on the actual offending element.
