# silkcode

> 标签: agent, ai, cli, coding-agent, llm, model-agnostic

## 简介

npx launcher for Silk Code, the model-agnostic AI coding agent: phone-first GUI, permission gates, provenance-scanned tools. Bootstraps the Python app and its Chromium into an isolated environment on first run.
