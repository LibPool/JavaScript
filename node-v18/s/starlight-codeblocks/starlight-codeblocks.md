# starlight-codeblocks

> 标签: astro, astro-integration, code-blocks, documentation, expressive-code, starlight, starlight-plugin, syntax-highlighting, withastro

## 简介

A plugin for Starlight and Astro that adds focus, line states, comment notation, annotations, API auto-linking and more features to code blocks, on top of Expressive Code.
