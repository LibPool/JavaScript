# supabase-lite

> 标签: browser-database, cli, database, pglite, postgresql, psql, repl, sql, supabase

## 简介

Command-line interface for Supabase Lite - browser-based PostgreSQL database. Compatible with Supabase CLI commands starting with psql functionality.
