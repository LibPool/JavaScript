# smullyan

> 标签: applicative, bluebird, combinator, combinatory-logic, compose, currying, either, fixed-point, flow, fp, functional-programming, functor, kestrel, maybe, mockingbird, monad, option, pipe, point-free, reader, result, smullyan, starling, task, tree-shakable, type-level, type-safe, typescript, y-combinator, zero-dependency

## 简介

A fully typesafe functional programming library for TypeScript: combinatory-logic bird combinators plus Option, Result, Task, Reader, pipe and flow.
