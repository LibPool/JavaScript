# specloom-kit

> 标签: agentic-delivery, ai-agents, claude-code, codex, cursor, qoder, spec-driven, specloom

## 简介

SpecLoom — Spec-Driven Agentic Delivery。一条命令安装「需求→设计→原型→编码→验收」全链路多 AI 工具代理编排配置（Claude Code / Codex / Cursor / Gemini / Trae / Windsurf / Qoder）。专有软件，需登录授权设备后使用。
