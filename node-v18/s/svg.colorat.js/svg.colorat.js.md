# svg.colorat.js

> 标签: colorpicker, gradient, svg.js

## 简介

An extension for svg.js which allows to pick a color from a gradint at a specific position

## 官网

- 官网：https://github.com/svgdotjs/svg.colorAt.js
- 源码仓库：git+https://github.com/svgdotjs/svg.colorAt.js.git
- npm 页面：https://www.npmjs.com/package/svg.colorat.js
