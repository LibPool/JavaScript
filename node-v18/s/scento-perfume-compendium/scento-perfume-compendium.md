# scento-perfume-compendium

> 标签: chatgpt, claude, cologne, eau-de-parfum, fragrance, fragrance-api, mcp, mcp-server, model-context-protocol, niche-perfume, perfume, perfume-api, perfume-database, perfume-mcp, perfume-notes, scent, scento

## 简介

Free perfume & fragrance API and MCP server for AI assistants: notes, scent families, similar perfumes, raw materials and houses for 700+ perfumes, each linked to scento.com. No key.
