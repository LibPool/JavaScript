# smock-it

> 标签: create test data salesforce, force, mock data, mock data generation, salesforce, salesforce qa test data, salesforce synthetic test data, salesforce synthetic test data generator, salesforce test data generator, sf-plugin, smock-it, synthetic data generator for salesforce, synthetic test data, synthetic test data generator, test data, test data automation, test data library, test data salesforce

## 简介

Smock-it is a CLI plugin for generating synthetic test data in Salesforce, helping SF devs, QAs, and admins create realistic data without using live customer info—boosting efficiency and privacy.
