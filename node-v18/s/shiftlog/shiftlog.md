# shiftlog

> 标签: ai-agents, claude-code, codex, handoff, memory, session-continuity

## 简介

Shiftlog — cross-agent session handoff for coding agents. One agent wraps a session into a handoff report; a different agent picks it up cold, no re-briefing. Name reservation; the kit lives at github.com/alexschar/wrap-pickup.
