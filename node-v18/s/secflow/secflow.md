# secflow

> 标签: ai, ci, cli, devsecops, github-action, gitleaks, npm-audit, pre-commit, scanner, secret-scanning, secrets, security, trivy, vulnerability

## 简介

SECflow — zero-cost security scanning for AI-driven repos: secrets (gitleaks), dependency vulns (trivy / npm audit), custom regex rules, AI-ready fix reports, re-attack verification, and baseline snapshots.
