# shoplazza-components

> 标签: JavaScript

## 简介

店匠基础组件库- Button 按钮 - Card 卡片块 - EmptyTable 无数据提示 - Icon 图标 - IconText 文字+图标+链接 - LoadingIcon 加载图标动画 - Modal 对话框 - Pagination 分页 - Select 选择器 - Title 标题
