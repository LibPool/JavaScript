# smart-mailto

> 标签: contact-form, email, gmail, mailto, outlook, protonmail, react-hook, smart-mailto, webmail, zero-backend

## 简介

Zero-dependency, zero-backend smart email dispatcher for modern web apps. Replaces broken desktop mailto: with Gmail, Outlook, Yahoo, Proton, and native fallback.
