# sup-kit

> 标签: JavaScript

## 简介

supbin开发脚手架工具，便于拉去代码，方便使用 1. npm install sup-kit -g 2. sup init \<name\> 3. 选择你需要的框架信息 4. 填写需要的内容 5. 安装后自动使用
