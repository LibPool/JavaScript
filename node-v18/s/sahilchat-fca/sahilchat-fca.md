# sahilchat-fca

> 标签: api, bot, chat, facebook, facebook-chat-api, fca, messenger, sahilchat-fca

## 简介

sahilchat-fca — A powerful Facebook Chat API for Node.js. Supports cookie string login, 15 and 16 digit group messaging, stickers, reactions, and more. A Facebook Group Chat API for Node.js. Built by S4hiilAns4ri.
