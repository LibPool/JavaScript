# s3-file-id

> 标签: aws, aws-s3, bun, file-id, file-management, fileid, identifier, lifecycle, node, object-storage, s3, s3-file-id, s3-object, scheduled-delete, storage-id, storage-utils, typescript, unique-id, utility

## 简介

File ID is a unique identifier for a file. It is used to identify a file in a storage system and to delete it on storage (scheduled).
