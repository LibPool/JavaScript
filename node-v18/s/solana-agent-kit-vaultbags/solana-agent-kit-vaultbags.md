# solana-agent-kit-vaultbags

> 标签: agent, ai-agents, bags, defi, mcp, rwa, solana, solana-agent-kit, treasury, vaultbags, x402

## 简介

Solana Agent Kit v2 plugin for VaultBags: read the autonomous RWA treasury (today's allocation with its on-chain receipt, market signals, honest track record, treasury stats, the certified Solana RWA registry, the protocol meter and autonomy score) run it
