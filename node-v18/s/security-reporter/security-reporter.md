# security-reporter

> 标签: ci-cd, cli, code-quality, dependencies, nodejs, npm-audit, owasp, reporter, secret-scanning, security, security-report, security-reporter, typescript, vulnerability-scanner

## 简介

Security and quality reporter for Node.js projects. Scans for vulnerabilities, secrets, outdated dependencies, and generates comprehensive reports (console, Markdown, PDF).
