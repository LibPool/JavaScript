# squirrel-trace

> 标签: agent, evaluation, llm, observability, squirrel, telemetry, testing, tracing

## 简介

Lightweight tracing SDK for Squirrel — send runs, turns, tool calls and token usage from any Node.js app to a local Squirrel instance for LLM observability.
