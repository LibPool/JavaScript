# shahnevis-react

> 标签: JavaScript

## 简介

**Shahnevis React** is a **React-based code editor** powered by `shahnevis-core`. It features syntax highlighting, minimap, multi-cursor support, and a **plugin system**, making it easy to integrate into any project.
