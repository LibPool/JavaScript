# snippy-copy

> 标签: code display, code formatting, code sharing, code snippet, copy code, copy-paste, copy-to-clipboard, highlighted code, lightweight library, snippet, syntax highlighting

## 简介

A lightweight JavaScript library for displaying and copying code snippets with syntax highlighting. Easy to integrate and supports multiple formats (ESM, CJS, UMD).
