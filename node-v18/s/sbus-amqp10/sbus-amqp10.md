# sbus-amqp10

> 标签: amqp, amqp 1.0, amqp-1-0, amqp10, azure, messaging, queues, servicebus, topics

## 简介

Adapter for node-sbus module to use amqp10 module for all AMQP calls (amqp10 has no native code).
