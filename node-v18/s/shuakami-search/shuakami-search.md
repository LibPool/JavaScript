# shuakami-search

> 标签: browser, chinese, cjk, client-side, fast, flexsearch-alternative, fulltext, fuse-alternative, fuzzy, inverted-index, lunr-alternative, minisearch-alternative, search, small, static-site, tokenizer, varint, zero-dependency

## 简介

Tiny, zero-dependency full-text search for JavaScript. Builds a binary index once, then queries in microseconds — in the browser, in Node, or anywhere JS runs.
