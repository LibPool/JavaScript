# serialize-error-cause

> 标签: cause, cause-chain, circular, circular-reference, cloudflare-workers, edge, error, error-cause, error-logging, error-serialization, error-to-json, json-stringify-error, logging, observability, safe-json, sentry, serialize, serialize-error, serialize-error-cause, stringify, structured-logging, truncate, typescript

## 简介

Serialize any JavaScript Error, including the nested cause chain and custom fields, into safe, size-bounded JSON for logging. Circular-safe, zero dependencies, runs on Node, browsers, and Cloudflare Workers.
