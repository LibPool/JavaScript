# svelte-lancer

> 标签: JavaScript

## 简介

Lightweight utility class (<5kb) that makes using [SvelteKit's enhance actions](https://kit.svelte.dev/docs/form-actions#progressive-enhancement) easy and compact using the power of stores! Get rid of repetitive code that tracks if your form is still load
