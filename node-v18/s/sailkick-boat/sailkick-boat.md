# sailkick-boat

> 标签: cache, influxdb, offline, proxy, sailkick, signalk, signalk-category-ais, signalk-category-chart-plotters, signalk-category-instruments, signalk-node-server-plugin, signalk-webapp

## 简介

Run the sailkick app on board with no internet: charts, weather, climatology, trends and AIS all served from the boat itself. With a sailkick account it also syncs your metrics to the cloud in real time. Alpha, invite-only — info@sailkick.io
