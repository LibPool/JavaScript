# solar-time

> 标签: astronomy, day-angle, day-of-year, daylight, earth-orbit, equation-of-time, latitude, local-solar-time, local-time, longitude, solar, solar-calculator, solar-energy, solar-panel, solar-time, sun, sun-position, time, time-calculation, time-correction

## 简介

This library provides functions to calculate local solar time, also known as local apparent time, based on a given location and date.
