# sync-config.js

> 标签: JavaScript

## 简介

同步前端构建工具配置文件的命令行工具，保持不同项目间的配置文件一致，统一不同项目里代码的风格。   目前能够保持同步的配置文件： - .eslintrc - .eslintignore - .prettier - .editorconfig - .babelrc - .gitignore
