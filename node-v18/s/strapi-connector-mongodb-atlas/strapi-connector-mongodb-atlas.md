# strapi-connector-mongodb-atlas

> 标签: atlas, hook, mongodb, mongoose, nosql, orm, strapi

## 简介

MongoDB Atlas hook for the Strapi framework. Forked from the original Strapi mongoose hook to make it work with MongoDB Atlas. USE WITH CAUTION!
