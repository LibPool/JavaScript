# sign-in-with-pully

> 标签: authentication, ed25519, identity, login, oidc, passwordless, pully, sign-in-with-pully

## 简介

Server-side client for "Sign in with Pully" — the no-redirect backchannel flow (the user types their Pully ID and approves on their phone). Handles the Ed25519 signing envelope + register / start / poll so you don't hand-write crypto. Ships a separate ./b
