# stringwise

> 标签: NLP, bigram, compare strings, esm, fuzzy matching, jaro-winkler, levenshtein, natural language processing, ratcliff-obershelp, string comparison, string matching, string similarity, text distance, typescript, utility

## 简介

Effortless and fast string similarity comparison using multiple algorithms, including bigrams, Levenshtein, Jaro-Winkler, and Ratcliff/Obershelp. Perfect for fuzzy search, NLP, and intelligent text matching.
