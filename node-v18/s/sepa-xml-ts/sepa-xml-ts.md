# sepa-xml-ts

> 标签: credit-transfer, direct-debit, iso20022, pain.001, pain.008, sct, sdd, sepa, sepa-credit-transfer, sepa-direct-debit, typescript, xml, zod

## 简介

Type-safe SEPA payment file library for pain.001 credit transfers and pain.008 direct debits. Parse, write, and validate ISO 20022 XML with output verified against the official ISO 20022 XSD.
