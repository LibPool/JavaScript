# smooth-scroll-lite

> 标签: anchor, animation, behavior, lightweight, links, scroll, scrolling, smooth

## 简介

SmoothScrollJs is a lightweight JavaScript library that enables smooth scrolling behavior for anchor links on a web page. It provides a smooth animated transition when navigating to target sections within the same page.
