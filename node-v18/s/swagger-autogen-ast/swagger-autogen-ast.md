# swagger-autogen-ast

> 标签: ast, auto, autogen, automatic, documentation, express, generate, generator, inference, openapi, swagger, swagger-autogen, typescript

## 简介

A zero-config OpenAPI 3.0 generator for Express. The AST-based spiritual successor to swagger-autogen with automatic type inference.
