# sentinel-healer

> 标签: assistant, autonomous, claude, cli, error-handling, gemini, llm, self-healing, terminal

## 简介

An autonomous self-healing CLI manager that intercepts terminal command failures and automatically diagnoses and patches them using LLMs.
