# shade-coder

> 标签: china-mirror, hud, screen-capture, speech-to-text, voice, xfyun-asr

## 简介

One-click launcher for the shade hidden-HUD window (Windows): auto-installs Python + voice deps from China mirrors (npmmirror / Tsinghua) and starts the app. Voice STT: iFlytek cloud dictation (keys in .env); per-source mixing + silence gate kill the junk
