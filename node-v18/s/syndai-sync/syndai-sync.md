# syndai-sync

> 标签: JavaScript

## 简介

Local-first sync for web apps: a typed store with optimistic writes, SSE and WebSocket transports, and a sync server (Cloudflare Durable Object, plus a node:sqlite dev server) graded by one conformance suite.
