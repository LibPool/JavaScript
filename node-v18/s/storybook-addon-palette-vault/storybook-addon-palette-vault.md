# storybook-addon-palette-vault

> 标签: accessibility, color, colour, contrast, design-system, oklch, storybook-addon, storybook-addons

## 简介

Shows which colors a story actually renders, ranked by how much of the component each one covers, with OKLCH values and contrast.
