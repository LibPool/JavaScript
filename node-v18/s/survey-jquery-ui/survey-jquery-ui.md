# survey-jquery-ui

> 标签: Bootstrap, JavaScript, Library, Survey, jquery, jquery-plugin

## 简介

survey.js is a JavaScript Survey Library. It is a modern way to add a survey to your website. It uses JSON for survey metadata and results.
