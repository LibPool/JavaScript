# select-and-send

> 标签: JavaScript

## 简介

Аналог Orphus. Пользователь выделяет часть текста мышкой (подразумевается, что это орфографическая ошибка), затем нажимает сочетания  клавиш Ctrl + Enter, появляется модальное окно с выделенным текстом и контекстом, а также кнопкой отправки данных.
