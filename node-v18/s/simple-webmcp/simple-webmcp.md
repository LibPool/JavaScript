# simple-webmcp

> 标签: ai, mcp, nextjs, react, sdk, tool, typescript, webmcp

## 简介

Turn any JS/TS function into a WebMCP tool — function-first, type-safe, lean. One line: webmcp(fn) still callable, auto-registers with React lifecycle or globally.
