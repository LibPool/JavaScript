## 简介

Open-source AI agent CLI and native MCP (Model Context Protocol) client for your terminal. Automatic tool-calling, Human-in-the-Loop approval, 5-layer security guardrails, optional Docker sandbox, and LangSmith observability — powered by NVIDIA NIM.
