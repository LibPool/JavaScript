# sanity-plugin-studio-smartling

> 标签: sanity, sanity-plugin

## 简介

This plugin provides an in-studio integration with Smartling. It allows your editors to send any document to Smartling with the click of a button, monitor ongoing translations, and import partial or complete translations back into the studio.
