# smile-translator-replacer

> 标签: cli, i18n, nuxt, replacer, translation, vue

## 简介

NPX tool to replace translation function calls ($trans, $transF, $transL, $transT, $transU) with their non-prefixed versions and auto-generate local-translate.ts
