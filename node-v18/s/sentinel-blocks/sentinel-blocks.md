# sentinel-blocks

> 标签: ai, anthropic, function-calling, json, llm, openai, parser, prompt-engineering, robust-parsing, structured-output

## 简介

Robust extraction of structured payloads from LLM output via sentinel blocks (<<<TAG>>> … <<<END>>>). Survives quotes, newlines, and braces that shatter a naive JSON.parse.
