# sharpwave-core

> 标签: JavaScript

## 简介

The memory engine behind sharpwave (MCP server) and openwave (OpenClaw plugin): graph store, FSRS-6 forgetting curve, spreading activation, sleep-style consolidation, LLM extraction.
