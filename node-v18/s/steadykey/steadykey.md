# steadykey

> 标签: deduplication, deterministic, dynamodb, exactly-once, idempotency, idempotency-key, memcached, middleware, mongodb, mysql, postgresql, redis, sqlite, typescript

## 简介

Deterministic idempotency key manager for JSON payloads with multi-backend storage, an execute-once runner, and HTTP middleware. Zero dependencies.
