# sukuna-ui

> 标签: a11y, accessible, ai-agents, base-ui, component-library, dark-mode, design-system, design-tokens, headless-ui, llms-txt, nextjs, react, react-components, react-server-components, rsc, ssr, tailwind-v4, tailwind-variants, tailwindcss, themeable, typescript, ui, ui-kit, wcag, zero-runtime

## 简介

SSR-safe, accessible React component library — 30 dark-first components built on Base UI and Tailwind v4 design tokens, WCAG AA, zero-runtime styling, RSC-ready, and documented for AI coding agents (llms.txt).
