# slogx

> 标签: logger, smart-logger

## 简介

slogx is a smart, flexible, and developer-friendly logger for Node.js. It supports colorful console logging, daily log file rotation, redaction of sensitive data, context-aware debugging (file & line number), and structured metadata.
