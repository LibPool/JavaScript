# seekx

> 标签: bm25, cli, embeddings, hybrid-search, knowledge-base, local-first, markdown, oceanbase, rag, search, seekx, sqlite, vector-search

## 简介

CLI for hybrid local search: BM25 + vector embeddings, incremental indexing, and realtime file watch. Requires Bun.
