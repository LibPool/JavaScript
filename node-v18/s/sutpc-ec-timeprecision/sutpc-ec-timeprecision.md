# sutpc-ec-timeprecision

> 标签: echarts, resize, time precision

## 简介

depend on sutpc-ec-resize,can fullfill x data when set timeprecision 5分钟 15分钟 时，增加了一个配置项预处理方法optionHandler，允许在设置echart option之前由外部自行处理echart option
