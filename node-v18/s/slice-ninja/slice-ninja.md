# slice-ninja

> 标签: adr, architecture, claude, claude-code, claude-skill, product-planning, vertical-slice

## 简介

Plan, design, and document product features as vertical slices using the 5-block compact framework. Installs the slice-ninja Claude skill + 8 slash commands into any project.
