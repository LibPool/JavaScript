# screen_color_plugin

> 标签: button screen, button screen color, escreen efects, front-end, jquery, plugin, screen color, switch screen color

## 简介

This is a jQuery plugin that enables developers to add a screen color change button to their web pages. With this plugin, users can customize the background colors with the button.
