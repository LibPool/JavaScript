# skygazer-mcp

> 标签: asteroid, astronomy, claude, mcp, model-context-protocol, nasa, space, stargazing

## 简介

A Model Context Protocol (MCP) server for space data and stargazing planning: NASA APOD, near-Earth objects, geomagnetic storms/aurora forecasts, JPL asteroid/comet lookups and close approaches, moon phase, and naked-eye planet visibility.
