# sophone

> 标签: cli, e164, edahab, evc, fintech, jeeb, mobile, mobile-money, phone, sahal, somalia, telecom, validator, wallet, zaad

## 简介

🇸🇴 Professional Somali phone number validation, formatting, operator detection & mobile wallet identification. Supports EVC, Sahal, ZAAD, eDahab, and Jeeb with CLI tools, TypeScript support, and beautiful error handling.
