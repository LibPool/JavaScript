# sedum-cli

> 标签: ai, browser-testing, e2e, end-to-end, llm, plain-english, playwright, test-runner, testing, typescript

## 简介

Plain-English browser tests on Playwright. Write steps as sentences, keep TypeScript, and run the suite on every pull request.
