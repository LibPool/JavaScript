# screeps-integration-tests

> 标签: integration-tests, javascript, screeps, screeps-bot, screeps-server-mockup

## 简介

Portable integration test framework for Screeps bots. Run your bot against a full local game server — verify behavior, collect metrics, no game subscription needed.
