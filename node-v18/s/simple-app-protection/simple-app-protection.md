# simple-app-protection

> 标签: javascript, password, protection

## 简介

* Simple app protection - simple static site app password protection. * DO NOT USE IN PRODUCTION!!! - can be easily turned off in browser * Use case: when you want to show static site (for example hosted in S3) without any sensitive data to you client d
