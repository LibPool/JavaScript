# stackstreak-sdk

> 标签: bitcoin, clarity, game, sdk, stacks, stackstreak, web3

## 简介

TypeScript-ready SDK for the StackStreak family of on-chain games on Stacks (Bitcoin L2): Daily Streak, Tic-Tac-Toe, Coin Flip, RPS, Higher-or-Lower, Connect Four, Lucky Reels, Daily Quests.
