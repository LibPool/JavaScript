# systerm-permissions

> 标签: JavaScript

## 简介

- `@import` 是 css 提供的一种语法规则，只有导入样式表的作用，但是 `link` 标签是 html 提供的一种标签，具有 rel 连接属性等。 - `link` 标签导入的 css 样式将会在页面加载时同时加载，而 `@import` 导入的 css 将会在页面加载完成之后再进行加载。 - `link` 标签不存在兼容性问题，`@import` 在 IE5+ 才能被支持。 - 可以通过 JS 操作 DOM ，插入 `link` 标签来改变样式；由于 DOM 方法是基于文档的，无法使用
