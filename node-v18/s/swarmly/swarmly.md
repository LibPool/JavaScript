# swarmly

> 标签: agents, claude, claude-code, cli, multi-agent, orchestration, swarm

## 简介

A small open-source CLI for orchestrating multi-agent Claude Code swarms. Filesystem-coordinated, no GUI, no MCP, no subscription.
