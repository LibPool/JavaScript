# s11a

> 标签: components, copy-in, design-system, react, registry, shadcn, tailwind

## 简介

Copy-in components from ui.shreshtharora.com — `s11a add postcard` drops the source into your app via the shadcn CLI. 162 pieces: prose blocks, travel scrapbook artifacts, chat bubbles for eleven platforms, CSS-drawn objects.
