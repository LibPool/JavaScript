# swyftstack-mcp

> 标签: ai, backups, claude, cursor, database, mcp, model-context-protocol, object-storage, postgres, postgresql, swyftstack

## 简介

Official Swyftstack MCP server — manage databases, storage, backups, imports, IP allow-lists, RLS, SSL and billing from AI assistants. Connect with one command via browser device login (no API key to paste) or SWYFTSTACK_API_KEY. Talks only to the Swyftst
