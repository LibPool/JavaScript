# syncmesh

> 标签: chat, cloudflare-d1, cloudflare-r2, cold-storage, database-adapter, gun, gundb, mongodb, mysql, postgresql, realtime, sync, tiered-storage

## 简介

Real-time GunDB sync + tiered storage: Cloudflare R2 for cold blobs, and your choice of D1 / MongoDB / MySQL / PostgreSQL for the metadata index. Built for chat apps that can't afford unbounded RAM growth.
