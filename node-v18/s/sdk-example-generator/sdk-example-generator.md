# sdk-example-generator

> 标签: JavaScript

## 简介

我们拥有多个语言的sdk，都基于 swagger 定义生成，我们需要给每个 api 写示例，实际上是一个比较重复的过程，但是每种 sdk 构建参数的行为不一样。 我们需要定义一套规则，用于描述每个 api 的参数构建行为，然后根据这个规则，生成对应语言的示例代码。 从而只需要输入一份json文件，以及就可以生成多种语言的示例代码。
