# subtlepq

> 标签: dhkem, dilithium, encapsulation, fips203, fips204, hpke, kem, kyber, ml-dsa, ml-kem, polyfill, post-quantum, rfc9180, subtlecrypto, webcrypto

## 简介

Post-quantum polyfill for the Web Cryptography API: ML-KEM (FIPS 203) and ML-DSA (FIPS 204) per the WICG Modern Algorithms draft, with native delegation
