# shopify-compressor

> 标签: assets, avif, bundler, compressor, css, image-optimization, javascript, liquid, minifier, performance, sass, scss, shopify, shopify-theme, svg, webp

## 简介

A powerful asset compressor and optimizer for Shopify themes. Supports modern image formats (WebP, AVIF), CSS/JS minification, and Liquid templating.
