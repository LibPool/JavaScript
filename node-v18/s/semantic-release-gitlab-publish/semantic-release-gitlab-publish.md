> 标签: .releaserc.json, changelog, git, gitlab, gitlab-package-registry, gitlab-publish, npm, npm-publish, publish, release, release.config.js, releaserc, semantic-release, semantic-release-config

## 简介

Sharable configuration for semantic-release, extends experience for publishing to NPM & Gitlab registry: generates release-notes, changelog, publishes new version.
