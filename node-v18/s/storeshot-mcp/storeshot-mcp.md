# storeshot-mcp

> 标签: app-store-screenshots, claude, mcp, model-context-protocol, storeshot

## 简介

Local MCP connector for Storeshot — let an AI agent build and edit your App Store / Google Play screenshots in a running Storeshot tab. No clone, no folder: your AI client runs it via npx.
