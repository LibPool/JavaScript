# search2ai

> 标签: agent, ai, brave, cloudflare-workers, exa, gateway, hono, mcp, perplexity, search, search1api, searxng, serper, tavily

## 简介

Self-hosted search gateway for AI agents: one Perplexity-compatible API over Search1API, Serper, Tavily, Brave, Exa, SearXNG and more, with provider fallback. Use it as a library, an HTTP service, or an MCP server.
