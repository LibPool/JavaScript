# segmo

> 标签: alpha-matting, auto-framing, background-blur, background-removal, background-replacement, gpu-accelerated, livekit, media-stream, mediapipe, real-time, segmentation, track-processor, video-conferencing, video-matting, video-processing, virtual-background, web-worker, webgl2, webrtc

## 简介

Ultra-optimized background segmentation for web video calls. GPU-accelerated pipeline with ROI cropping, alpha matting, foreground recovery, and adaptive quality. Drop-in for LiveKit, WebRTC, or any MediaStreamTrack.
