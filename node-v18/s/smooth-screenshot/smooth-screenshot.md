# smooth-screenshot

> 标签: canvas, capture, data-url, dom, dom-to-image, dom-to-pdf, dom-to-png, download, element-to-image, export, html-to-canvas, html-to-image, html-to-png, html2canvas, image, jpeg, non-blocking, pdf, png, screenshot, snapshot, svg, typescript, web-worker, webp, zero-dependencies

## 简介

Capture any DOM element to PNG, JPEG, WebP, SVG or PDF without ever freezing the UI. Cancellable, progress-reporting, handles huge content via tiling. Zero dependencies.
