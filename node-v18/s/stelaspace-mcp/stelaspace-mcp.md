> 标签: artifacts, claude, claude-code, claude-desktop, codex, cursor, dashboard, html, mcp, model-context-protocol, publishing, stelaspace

## 简介

Local MCP server for publishing HTML files to StelaSpace from Claude Code, Codex, and other MCP clients — permanent, sandboxed, shareable links for AI-generated artifacts.
