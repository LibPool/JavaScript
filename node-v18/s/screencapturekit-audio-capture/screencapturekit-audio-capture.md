# screencapturekit-audio-capture

> 标签: addon, app-audio, audio, audio-monitoring, audio-streaming, capture, core-audio, float32, macos, napi, native, pcm, per-app-audio, real-time, recording, screen-recording, screencapturekit, ventura

## 简介

Native Node.js addon for capturing per-application audio on macOS using ScreenCaptureKit framework. Real-time audio streaming with event-based API.
