# sjopps-search-filter-divi

> 标签: JavaScript

## 简介

This is a fork of the original plugin "Search & Filter Pro - Divi Extension" `v1.0.3` It extends the integration to the custom Blog module created in SJOpps Theme. Find the labels in code "APB - START" and "APB - END" to see what has been customised.
