# skillibary-mcp

> 标签: JavaScript

## 简介

MCP server for the Skillibary agent skill registry. Thin HTTP client over the public registry — no Supabase or embedding credentials needed.

## 官网

- 官网：https://skillibary.com/docs/install
- 源码仓库：git+https://github.com/Nainounen/SkillHub.git
- npm 页面：https://www.npmjs.com/package/skillibary-mcp
