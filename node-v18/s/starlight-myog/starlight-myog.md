# starlight-myog

> 标签: astro, og-image, open-graph, social-card, starlight, starlight-plugin, twitter-card, withastro

## 简介

Starlight plugin that adds a MyOG.social og:image and twitter:image to every docs page, generated from each page's URL

- 官网：https://myog.social/docs/starlight
- 源码仓库：git+https://github.com/MyOG-social/starlight-myog.git
- npm 页面：https://www.npmjs.com/package/starlight-myog
