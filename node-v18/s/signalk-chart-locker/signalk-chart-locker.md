# signalk-chart-locker

> 标签: chartplotter, container, offline-charts, pmtiles, signalk-category-chart-plotters, signalk-category-utility, signalk-node-server-plugin, signalk-plugin-configurator, tile-cache

## 简介

Signal K plugin that runs a Rust container alongside the server for a boat-wide tile cache, a PMTiles chart provider, and saved downloadable map regions.
