# sxn_operationdirectory

> 标签: JavaScript

## 简介

删除、复制等文件及目录操作，removeDir为删除，传入要删除的路径，copyDir为拷贝，传入要拷贝的路径及目标路径，flatDir为扁平化传入要拷贝的路径及目标路径
