# storage-bucket-js

> 标签: api, bucket, cloud-storage, cors, file-upload, javascript, storage, typescript

## 简介

A comprehensive JavaScript/TypeScript library for storage bucket operations with API key authentication. Supports upload, download, list, and delete operations with CORS handling.
