# smart-state

> 标签: broadcast-channel, cookie, cross-tab, debounce, hooks, localStorage, nextjs, persisted-state, persistent, react, sessionStorage, ssr, standard-schema, state, state-management, ttl, typescript, use-local-storage, useState, valibot, zod

## 简介

React's useState, grown up: persistent, shared across components and tabs, TTL expiry, schema validation, cookie storage, debounced writes, SSR/Next.js-safe. No provider, zero dependencies, ~2 kB.
