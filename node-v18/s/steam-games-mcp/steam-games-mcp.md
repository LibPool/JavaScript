# steam-games-mcp

> 标签: games, mcp, model-context-protocol, steam, steamworks

## 简介

Enables LLMs to search and evaluate Steam games — prices, discounts, reviews and Steam Deck compatibility with no API key, plus a player's library, achievements and friends via the official Steam Web API.
