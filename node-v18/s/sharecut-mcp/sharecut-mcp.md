# sharecut-mcp

> 标签: claude, dynamic-qr, link-analytics, link-in-bio, mcp, mcp-server, model-context-protocol, qr, qr-code, qrcode, sharecut, short-link, url-shortener

## 简介

MCP server for ShareCut — create short links, re-point them after the QR is printed, read click analytics, and generate QR codes (free, no API key) from Claude, Cursor or any MCP client.
