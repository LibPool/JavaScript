# swipe-pagination

> 标签: bootstrap, daisyui, pagination, paginator, react, responsive, shadcn, svelte, swipe, tailwind, touch, virtual-scroll, vue

## 简介

A responsive, swipeable pagination strip. Thousands of pages, only the visible ones rendered. Vanilla core with React 17+, Vue 3 and Svelte 3/4/5 components.
