# slinky-sdk

> 标签: api, blinks, blockchain, integration, sdk, slinky, typescript

## 简介

Slinky SDK es una biblioteca TypeScript que permite a los desarrolladores integrar fácilmente miniaplicaciones con contratos inteligentes en diversas blockchains Layer 1. Esta SDK proporciona funciones para generar metadatos y enviar mensajes cross-chain,
