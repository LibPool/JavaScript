# search-it

> 标签: ecosystem:jquery, filter, filtering, jquery-plugin, live filtering, live searching, material design, materialize filtering, materialize searching, materialize.css, materialize.scss, materializecss, search, searching

## 简介

Search-it is a jQuery plugin that makes any block of content searchable by filtering content. It also provides more intuitive filtering when using the Materialize Collapsible component.
