# sensibljs

> 标签: data-binding, declarative, directives, dom, frontend, html-attributes, lightweight, no-build, no-dependencies, reactive, two-way-binding, ui, vanilla-js

## 简介

Reactive UI in ~5KB gzipped (18KB minified). No build step. No virtual DOM. No dependencies. Just HTML attributes.
