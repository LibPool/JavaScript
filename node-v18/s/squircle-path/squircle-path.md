# squircle-path

> 标签: bezier, canvas, clip-path, path, rounded-corners, squircle, superellipse, svg, typescript

## 简介

Tiny TypeScript utility for generating smooth squircle SVG paths for SVG, CSS clip-path, and Canvas.
