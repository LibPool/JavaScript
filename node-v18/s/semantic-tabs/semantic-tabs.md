# semantic-tabs

> 标签: javascript, semantic, tabs, typescript, vanillajs

## 简介

SemanticTabs is a pure JavaScript or VanillaJS library built on TypeScript that can convert semantic HTML tags to tabs. It is only 1.09 kB.
