# shopify-express-rdj

> 标签: express middleware, express.js, shopify

## 简介

Fork of the official Shopify Express module. Doing this because I was getting errors while trying to use it. Get up and running quickly with Express.js and the Shopify API. Offical version at: https://github.com/Shopify/shopify-express
