# snap-pair-core

> 标签: broadcastchannel, controller, firebase, multi-device, pairing, partykit, proximity, qr-code, react, second-screen, ultrasonic, web-audio, webrtc

## 简介

Pair phones and screens by QR code, room code, PIN, or experimental ultrasonic sound: React hooks, components, and transports (Firebase, PartyKit, WebRTC, BroadcastChannel) for multi-device experiences, plus the `snap-pair` setup CLI
