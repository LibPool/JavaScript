# swagger-typescript-parser

> 标签: api, interface, openapi, parser, swagger, transform, typescript

## 简介

只需要一个命令，自动将swagger文档转换为typescript的interface和api，能自动定义接口、自动定义API、自动类型推导、静态检查参数错误...
