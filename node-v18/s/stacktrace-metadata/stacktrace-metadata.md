# stacktrace-metadata

> 标签: check, clean, clean-stack, clean-stacktrace, column, err, error, error-stack, error-stack-traces, line, meta, metadata, relative, short, short-stack, show, show-stack, showstack, stack, stacktrace, traces, typeof

## 简介

Modify given `err` object to be more useful - adds `at`, `line`, `column`, `place` and `filename` properties and also cleans stack traces.
