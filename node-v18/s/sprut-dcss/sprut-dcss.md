# sprut-dcss

> 标签: css, dcss, parser, parsing, stringify

## 简介

Парсинг, перевод в строку синтаксиса dcss, сборка browser-dcss-модуля и сборка через html с динамически встраиваемыми стилями при использовании классов и генераторов в рантайме
