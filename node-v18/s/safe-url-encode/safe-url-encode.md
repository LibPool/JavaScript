# safe-url-encode

> 标签: JavaScript

## 简介

```ts import { encode, decode } from 'safe-url-encode' const str = encode('你 好 🤔') //'5L2gIPCfkI4g5Li%2FIOS6hg%3D%3D' const raw = decode(str) // '你 好 🤔' ```
