# schedula-core

> 标签: framework-agnostic, gantt, gantt-chart, gantt-component, javascript, no-dependencies, planning, production-planning, project-planning, resource-scheduler, scheduler, scheduling, timeline, vanilla-js

## 简介

Fast, lightweight Gantt chart & resource scheduler component in vanilla JavaScript. Zero dependencies, framework-agnostic, single <script> tag. MIT core with optional PRO plugins (drag & drop, resize, dependency links, calendar).
