# silver-mouse

> 标签: JavaScript

## 简介

`npm install `npm run build 本库实现json文件的解析，生成、操作、已经渲染的核心流程。 json数据大的部分分为两个部分：界面描述JSON文件， 动效描述JSON文件。 以场景为一个完整的逻辑单元。 整个文档或者舞台（stage）包含多个场景（scene）组成。
