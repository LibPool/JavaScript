# stagehand-proxyhat

> 标签: ai-agent, browser-automation, browserbase, proxy, proxy-rotation, proxyhat, residential-proxy, stagehand, sticky-session, web-scraping

## 简介

Route Stagehand's local browser through ProxyHat residential proxies — a pinned sticky IP per agent session, geo-targeting, and rotating IPs.
