# short-video-maker

> 标签: faceless video, generator, instagram, mcp, model context protocol, reels, remotion, short video, shorts, tiktok, video, video creation, youtube, youtube shorts

## 简介

Creates short videos for TikTok, Instagram Reels, and YouTube Shorts using the Model Context Protocol (MCP) and a REST API.
