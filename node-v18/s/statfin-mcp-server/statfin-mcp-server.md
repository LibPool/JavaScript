# statfin-mcp-server

> 标签: apify, claude, finland, mcp, model-context-protocol, open-data, statfin, statistics-finland, tilastokeskus

## 简介

Open bridge to the hosted Statistics Finland (StatFin) MCP server on Apify — query Finnish official statistics (population, economy, labour, regions) from any MCP client using your own Apify API token.
