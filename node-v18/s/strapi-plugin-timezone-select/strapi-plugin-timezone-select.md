# strapi-plugin-timezone-select

> 标签: JavaScript

## 简介

A Strapi custom field to select a Olson/IANA time zone (e.g. Africa/Ndjamena America/New_York, Asia/Bangkok, Europe/Paris, Oceania/Sydney)
