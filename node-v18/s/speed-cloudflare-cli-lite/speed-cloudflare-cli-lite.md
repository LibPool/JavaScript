# speed-cloudflare-cli-lite

> 标签: bandwidth, connection, download, internet, latency, network, ping, speed, speedtest, test, upload

## 简介

Measure the speed and consistency of your internet connection using speed.cloudflare.com. Doesn't run 100MB download speed test or color/bold output text by default.
