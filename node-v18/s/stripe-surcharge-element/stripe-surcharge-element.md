# stripe-surcharge-element

> 标签: card fee, checkout, convenience fee, deferred-intent, payment, paynow, react, stripe, stripe-elements, surcharge

## 简介

A drop-in Stripe Elements component that surcharges the card fee to the customer and keeps bank rails like PayNow flat. Unofficial / community.
