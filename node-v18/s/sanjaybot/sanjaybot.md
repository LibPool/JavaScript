# sanjaybot

> 标签: ai-bot, chatbot, customer-care, react-chatbot, sanjay-ai, support-bot, vue-chatbot, widget

## 简介

Customizable, embeddable React & Web Chatbot Library for Sanjay.Ai Customer Care Platform. Compatible with React, Next.js, Vue, and standalone websites.
