# safe-img

> 标签: blurred-backdrop, broken-image, echo-pillarboxing, fallback, framework-agnostic, image, image-fallback, img, lazy-loading, placeholder, react, retry, safe-img, svelte, vanilla-js, vue, web-component

## 简介

Framework-agnostic broken-image fallback with retry, LRU failed-URL cache, and an optional YouTube-style blurred backdrop. Programmatic API, data-attribute auto-init, and a <safe-img> Web Component.
