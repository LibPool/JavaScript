# strapi-provider-email-volanea

> 标签: email, ses, strapi, strapi-email, strapi-provider, strapi-provider-email, transactional-email, volanea

## 简介

Volanea email provider for Strapi v5 — send Strapi's transactional email (admin invites, password resets, user confirmations) through the Volanea API.
