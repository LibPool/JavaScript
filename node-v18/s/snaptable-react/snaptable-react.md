# snaptable-react

> 标签: columns, customizable, drag-drop, headless, headless-ui, hooks, mobx, react, react-table, resizable, sticky-columns, table, typescript, unstyled

## 简介

A truly headless React table library providing only hooks and logic for building custom tables. Features column resizing, drag & drop, and layout persistence with zero styling opinions.
