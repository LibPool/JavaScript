# subnetter

> 标签: JavaScript

## 简介

*Deutsch/German* Ein kleines Programm, in das man eine Liste von Netzen mit gegebener Hostanzahl eingeben kann. Bei entsprechender Angabe des IP-Adressbereichs wird dann alles gesubnettet und als Tabelle ausgegeben.
