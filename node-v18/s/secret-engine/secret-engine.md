# secret-engine

> 标签: aes-gcm, api-keys, constant-time, encryption, hkdf, nodejs, secrets, tokens, typescript

## 简介

SecretEngine is a context-bound encryption and secret utility toolkit for TypeScript applications that need to store API keys, tokens, verification codes, and other sensitive values safely.
