# supawrapper

> 标签: crud, database, postgres, realtime, sdk, supabase, supawrapper, typescript, wrapper

## 简介

A TypeScript package that wraps the Supabase client in a reusable class and exposes common methods for Create, Read, Update, and Delete operations.
