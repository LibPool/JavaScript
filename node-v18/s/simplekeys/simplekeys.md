# simplekeys

> 标签: api-key, api-key-crypto, api-key-decryption, api-key-encryption, api-key-encryption-decryption, apikey, crypto, decryption, encryption

## 简介

A simple node js library for cyptograhic api key generation. Encode information in api keys and validate keys without making api calls.
