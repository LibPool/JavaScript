# spanish-cities-info

> 标签: cities, geolocation, municipios, provinces, spain, spanish-cities, typescript

## 简介

8,132 Spanish municipalities verified against official INE data. Search by name, province, INE code, or radius (km). Modular imports by province/community. Postal codes available as an optional separate import. TypeScript, ~330KB (gzip: 125KB) for the mai
