# scrappey-wrapper

> 标签: api-client, axios, browser-automation, crawler, data-extraction, fetch, headless-browser, html-parser, http-client, playwright, proxy, proxy-rotation, puppeteer, residential-proxy, rest-client, scraper, scraping-api, scrappey, session-management, typescript, web-automation, web-crawler, web-data, web-scraping

## 简介

Official Node.js client for the Scrappey web scraping API. Render and retrieve web pages, automate browser actions, manage persistent sessions, and route through residential proxies for reliable collection of publicly available data. Ships with TypeScript
