# safejsoncontext

> 标签: RHI, aes-256-gcm, agent, agenticRHIContext, atomic, config, context, credential-manager, encryption, file-lock, json, jsonContext, jsonData, keychain, libsecret, llm-context, lock, safe, standard-schema

## 简介

A JSON context file with per-field access, AES-256-GCM field encryption under an OS-held key, Standard Schema validation, and a cross-process lock on every mutation.
