# secretcheck

> 标签: api-key, credentials, git, git-hook, pre-commit, secret-scanning, secrets, security

## 简介

Git pre-commit secret scanner (Go binary under the hood). Blocks commits that contain API keys, tokens, and credentials, with a clear option to override.
