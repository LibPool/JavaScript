# sdleafletdraw

> 标签: leaflet

## 简介

ES6 + Babel port of Leaflet.draw, a plugin that adds drawing and editing tools to Leaflet powered maps. (c) 2012-2017, Jacob Toye, Jon West, Smartrak, Leaflet https://github.com/Leaflet/Leaflet.draw http://leafletjs.com
