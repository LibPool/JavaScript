# slider-images-gp

> 标签: JavaScript

## 简介

Vamos a tener un Slider con diferentes opciones de controles props: width/height pero tambien se pueden controlar desde el padre imgs => array de imagenes para usar el slider arrows => booleano si quieren flechas o no (true default) previous_arrow: ht
