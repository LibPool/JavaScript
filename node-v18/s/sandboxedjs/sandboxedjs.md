# sandboxedjs

> 标签: ai-agent-sandbox, bash, browser-ide, code-execution, container, coreutils, emulator, javascript-sandboxing, linux, nodepod-alternative, posix, python, sandbox, secure-sandbox, shell, untrusted-code, vfs, virtual-filesystem, webcontainer, webcontainer-alternative

## 简介

A zero-infra JavaScript and Python sandbox for AI agents and browser IDEs. A lightweight, secure alternative to WebContainers and NodePod for running untrusted code with a full POSIX shell.
