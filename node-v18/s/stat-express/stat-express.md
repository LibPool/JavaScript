# stat-express

> 标签: ddos-stat, dstat, dstat-counter, express-logging, express-stat, req-log, request info, request-counter, request-info, request-logger, request-logging

## 简介

A nice request logging middleware similar to express-logging. Comes with request stats, request logs, and configurable path blocking.
