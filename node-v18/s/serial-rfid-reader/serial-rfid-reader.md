# serial-rfid-reader

> 标签: rfid

## 简介

A wrapper library to easily incorporate serial RFID readers (such as Sparkfun's 215khz, used for this lib) into a node program.

- npm 页面：https://www.npmjs.com/package/serial-rfid-reader
