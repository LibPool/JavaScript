# sequelize-transactional-typescript

> 标签: JavaScript

## 简介

A Transactional Method Decorator for sequelize that uses cls-hooked to handle and transactions between different repositories and service methods. Inspired by https://github.com/odavid/typeorm-transactional-cls-hooked
