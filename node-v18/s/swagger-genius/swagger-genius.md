# swagger-genius

> 标签: api-documentation, class-validator, express, fastify, joi, nestjs, openapi, swagger, typescript, zod

## 简介

🚀 Instantly generate Swagger/OpenAPI 3.0 API contracts from your TypeScript code. Zero config, supports Zod/Joi/Class-Validator schemas, works with Express/Fastify/NestJS. Perfect swagger.json files in seconds!
