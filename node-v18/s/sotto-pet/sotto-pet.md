# sotto-pet

> 标签: agent, claude-code, desktop-pet, electron, mcp, tts

## 简介

A desktop pet for Claude Code. Renders Codex pet sprites in an always-on-top window, reacts to agent events via hooks, and speaks results with speak-mcp.
