# ssqsignon-auth-proxy

> 标签: auth, authorization, client, code, confidential, proxy, secret, slave, sso, ssq, ssqsignon

## 简介

A connect middleware (e.g. for express.js) that proxies requests to the ssqsignon /auth endpoint.
