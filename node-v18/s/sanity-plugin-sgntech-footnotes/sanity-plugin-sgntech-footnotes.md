# sanity-plugin-sgntech-footnotes

> 标签: annotation, citations, footnotes, portable-text, references, sanity, sanity-plugin, sources

## 简介

Footnotes and sources for Sanity Studio — mark a passage, write the note; numbering is derived from the text, so it never drifts. Ships a React renderer with a linked list and backlinks.
