# serverless-dependency-install

> 标签: amazon, amazon web services, aws, custom, custom dependency, custom dependency management, dependencies, dependency, dependency management, install, install dependency, npm, serverless applications, serverless framework plugin, serverless plugins, serverless.com, shared, shared dependency

## 简介

Executes npm install for all the package.json files inside serverless project directory with a single command.This plugin also allows to define local shared dependencies in package.json.
