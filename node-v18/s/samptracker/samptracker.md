# samptracker

> 标签: SAMP, SAMPTRACKER

## 简介

is a Node.js API that allows you to query **San Andreas Multiplayer (SA:MP)** servers for information about the server status, rules, and connected players. It uses the SA:MP UDP query protocol to retrieve real-time data from any accessible SA:MP server.
