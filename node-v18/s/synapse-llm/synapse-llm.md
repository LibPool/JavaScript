# synapse-llm

> 标签: aider, anthropic, cache, claude, codex, cursor, llm, openai, proxy, synapse

## 简介

One-command setup for the Synapse LLM proxy. Auto-detects Claude Code, Cursor, Aider, Codex CLI, Continue, and wires them up.
