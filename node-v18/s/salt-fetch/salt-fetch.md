# salt-fetch

> 标签: JavaScript

## 简介

独立的`ajax/jsonp`模块。`Salt.fetch`底层由[NattyFetch](https://github.com/Jias/natty-fetch)实现。为了给`Salt`的使用者提供一致的开发体验，故将`NattyFetch`工具以`fetch`属性的方式集成在`Salt`命名空间下。
