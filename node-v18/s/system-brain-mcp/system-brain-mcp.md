# system-brain-mcp

> 标签: code-audit, deploy, introspection, mcp, model-context-protocol

## 简介

MCP server that gives your coding agent a queryable, honest view of your own system — where code actually deploys, what's fabricated, what's open, whether the feedback loop closes, and what the evidence says to do next.
