# strapi-plugin-s3import

> 标签: JavaScript

## 简介

A plugin to import existing assets inside s3 into strapi media library.

## 官网

- npm 页面：https://www.npmjs.com/package/strapi-plugin-s3import

## 历史版本号

- 当前版本：1.0.0

- 1.0.0

## 获取地址

- npm 安装：`npm install strapi-plugin-s3import`
- npm registry：https://registry.npmjs.org/strapi-plugin-s3import
- Node 要求：>=10.16.0 <=14.x.x
