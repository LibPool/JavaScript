# shoudao-cli

> 标签: cli, shoudao

## 简介

1. 初始化package.json    npm init 2. 安装依赖   commander(cli基本依赖)   chalk(颜色插件)   download(下载)   git-clone(模板克隆)   inquirer(cli 问答收集模块)   ora(node-loading效果)   fs-extra node的fs封装化   figlet(logo) 无法使用中文 3. package.json 添加bin    命令行识别，别名定义   npm link
