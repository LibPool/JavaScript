# school-schedule-app

> 标签: JavaScript

## 简介

This code creates a simple drawing application where users can draw on an HTML canvas using their mouse. The JavaScript code sets up event listeners to detect mouse movements and draw on the canvas accordingly. The application uses basic styling with CSS
