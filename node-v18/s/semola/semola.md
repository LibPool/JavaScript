# semola

> 标签: api-framework, authorization, backend, bun, caching, cron, durable-workflow, framework, i18n, internationalization, job-scheduler, middleware, openapi, policy, pubsub, queue, redis, rest-api, resumable-workflow, scheduler, type-safe, typescript, utilities, validation, workflow, zero-dependency

## 简介

Zero-dependency TypeScript utilities for Bun. Type-safe APIs, Redis queues, pub/sub, i18n, caching & auth with tree-shakeable imports.
