# solmachina-verify

> 标签: agent, ed25519, merkle, proof-of-delivery, receipt, solana, solmachina, verify, x402

## 简介

Offline verifier for SolMachina Intelligence Receipts (SIR) + transparency-log Merkle proofs — verify a paid x402 answer's authenticity and delivery without trusting the API or any server.
