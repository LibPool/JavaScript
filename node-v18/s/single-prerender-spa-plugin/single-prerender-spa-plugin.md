# single-prerender-spa-plugin

> 标签: prerender-spa-plugin

## 简介

Prerenders static HTML in a single-page application via single thread(started one phantomjs application) based on Prerender-spa-plugin.

## 官网

- npm 页面：https://www.npmjs.com/package/single-prerender-spa-plugin

## 历史版本号

- 1.1.0

## 获取地址

- npm 安装：`npm install single-prerender-spa-plugin`
- npm registry：https://registry.npmjs.org/single-prerender-spa-plugin
- Node 要求：>=4.0.0
