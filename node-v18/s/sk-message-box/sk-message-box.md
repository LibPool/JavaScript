# sk-message-box

> 标签: dialog, message, message-box, vue, vue3

## 简介

基于**Vue3**的消息弹窗&模态窗的轻量级组件，带TS类型，大小仅不到8kb，分为组件式调用以及指令时调用,可用于一些小型项目，在仅需要弹窗or模态窗操作时可使用该库，方便简洁。
