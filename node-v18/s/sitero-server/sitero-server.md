# sitero-server

> 标签: JavaScript

## 简介

`sitero-server` is Sitero's framework-neutral application core. It owns resource operations, policies, execution contracts, and cache semantics; it does not depend on Next.js, HTTP, Prisma, Redis, or UI code.
