# showcase-mcp

> 标签: claude, cursor, html, mcp, model-context-protocol, publish, showcase, static-hosting

## 简介

MCP server: publish a local static-site directory and get back a stable, shareable link. Reads disk and encodes binaries — the model is not a file bus.
