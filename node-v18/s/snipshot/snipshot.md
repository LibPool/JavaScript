# snipshot

> 标签: ansi, carbon, cli, code, code-image, highlight, png, screenshot, shiki, snippet, svg, syntax-highlighting, terminal

## 简介

Generate PNG, SVG or ANSI-colored screenshots of code snippets with syntax highlighting, line numbers, and colored annotations from the CLI
