# sanity-plugin-smart-asset-manager

> 标签: asset-management, asset-manager, media-library, media-manager, sanity, sanity-plugin, sanity-plugin-smart-asset-manager

## 简介

An advanced asset management plugin for Sanity Studio with smart filtering, size analysis, unused asset detection, broken asset checks, and usage tracking.
