# static-version-injection-html-webpack-plugin

> 标签: hash, html-webpack-lugin, md5, static-version-injection, version

## 简介

this is a pulgin for webpack,using along with html-webpack-plugin,to add a content related hash version string when inject script or link tags into a html file
