# sfec-client

> 标签: certification, congo, e-facture, efacture, erp, facturation, fiscal, sfec, tcc, tfc

## 简介

Client JavaScript zero-dependency pour l'API SFEC (Systeme de Facturation Electronique Certifiee, Republique du Congo). Supporte les modes ERP, TCC et TFC.
