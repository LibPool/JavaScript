# security-hub-scanner

> 标签: express, nextjs, sast, security, sql-injection, static-analysis, tree-sitter, vulnerability-scanner, xss

## 简介

Tree-sitter based SAST engine for Node.js/Express and Next.js apps: SQL injection, XSS, command injection, path traversal, SSRF, CSRF, IDOR, broken access control and more.
