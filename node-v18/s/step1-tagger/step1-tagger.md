# step1-tagger

> 标签: babel, component, component-map, data-cid, debugging, jsx, mapping, plugin, react, tracking, tsx, vite

## 简介

A Vite plugin that automatically injects data-cid attributes into React components and generates a component mapping file for component tracking and debugging
