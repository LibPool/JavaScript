# sortedcontainerskit

> 标签: binary-search, bisect, btree, ordered, rank, sorted, sorted-list, sorted-map, sorted-set, sortedcontainers, typescript, zero-dependency

## 简介

Sorted containers: SortedList (with duplicates), SortedSet, SortedMap. O(log n) bisect, rank, floor/ceiling, range queries. Port of Python sortedcontainers. Zero dependencies, TypeScript.
