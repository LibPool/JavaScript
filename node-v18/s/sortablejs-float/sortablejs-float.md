# sortablejs-float

> 标签: angular, drag, meteor, mixin, ng-sortable, react, reorder, sortable

## 简介

This is a fork of git://github.com/rubaxa/Sortable.git that corrects an issue with placement while dragging in 'floating' containers (where contents wrap from row to row).
