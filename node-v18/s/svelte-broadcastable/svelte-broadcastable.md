# svelte-broadcastable

> 标签: JavaScript

## 简介

Svelte broadcastable is a store wrapper for the [Broadcast Channel API](https://developer.mozilla.org/en-US/docs/Web/API/Broadcast_Channel_API). It syncs any data across a given channel.
