# system-monit

> 标签: JavaScript

## 简介

A little lib that returns current cpu and memory usage. ## examples ### cpu usage ```javascript const { getCpuUsage } = require('../dist') getCpuUsage(200).then(res => console.log(`cpu usage: ${res}`)) ```
