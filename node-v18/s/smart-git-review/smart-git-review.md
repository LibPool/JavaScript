# smart-git-review

> 标签: ai, claude-code, cline, code-review, git, hooks, kilo-code, post-merge, pre-commit, pre-push, vibe-coding

## 简介

基于 Git Hooks 和 AI 大模型的自动化代码审查工具。支持 commit/push/pull 时自动审查，可植入质量规范到 Claude Code / Kilo Code / Cline 等 AI 编码工具。
