# smart-ocr

> 标签: image, ocr, optical character recognition, pdf, pdf ocr, pdf text extraction, pdfjs, png, scanned-pdf, tesseract, text-extraction

## 简介

OCR library for both scanned and text-based PDFs in .pdf or image format using tesseract.js with AI-powered structured output support.
