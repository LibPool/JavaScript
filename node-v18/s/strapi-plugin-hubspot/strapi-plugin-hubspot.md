# strapi-plugin-hubspot

> 标签: conditional-fields, crm, custom-field, form-builder, forms, hubspot, leads, plugin, strapi

## 简介

The form builder for HubSpot in Strapi — multi-step forms with conditional fields mapped to real CRM properties, a public submit pipeline with retries, and save-time mapping validation.
