# skynet-ui

> 标签: ai, components, css, dark-theme, framework, llm, no-build, tailwind, ui

## 简介

A tiny dark-first CSS + JS UI framework built for LLMs: 70+ components, 9 themes, Tailwind-compatible utilities, zero dependencies, zero build steps.
