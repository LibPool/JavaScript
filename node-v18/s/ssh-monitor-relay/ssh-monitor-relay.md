# ssh-monitor-relay

> 标签: monitor, port-forward, relay, sftp, ssh, tunnel

## 简介

Local relay agent for SSH Monitor. Tunnels SSH, SFTP, databases and agent web UIs from your machine to your server without opening inbound ports.
