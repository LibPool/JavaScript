# specfront-ai

> 标签: agent, ai, angular, cli, jira, specfront

## 简介

SpecFront AI — interactive CLI client for the SpecFront agent server. Talks to a self-hosted or Azure-hosted server over HTTP+SSE. Zero Python dependency.
