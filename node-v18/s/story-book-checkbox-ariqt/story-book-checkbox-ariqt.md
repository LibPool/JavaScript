# story-book-checkbox-ariqt

> 标签: storybook-checkbook-ariqt

## 简介

This is a reusable checkbox component used for checkboxes like input element ,if we want to use it in our application, we will import it and will pass props like "boolean checked value, boolean disable value and boolean primary values"
