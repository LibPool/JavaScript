# shot-put

> 标签: auto, automate, automatically, automation, cleanup, cli, desktop, dir, directory, file-system, fs, macOS, osx, screencap, screenshot, transfer

## 简介

CLI tool to watch desktop for files of a given extension and automatically move them to a given directory
