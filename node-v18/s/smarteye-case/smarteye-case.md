> 标签: ai, android, claude-code, design-qa, figma, ios, screenshot-diff, skill, test-case-management, visual-regression

## 简介

SmartEye测试平台：App 视觉还原测试用例管理。Figma 增量生成用例（可附带 AI 生成的用例内容）、按模块管理、上传 iOS/Android 截图、自动视觉对比、一键生成 AI 修改建议。附带 Claude Code skill：从 Figma + PRD 生成用例内容。
