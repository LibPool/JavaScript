# storeship

> 标签: agent, ai-agent, altool, app-store-connect, claude-code, expo, ios, react-native, release, screenshots, xcodebuild

## 简介

Ship an Expo / React Native iOS app to the App Store from your Mac, built for an agent to drive: one JSON envelope, stable error codes, `state` says what to run next. Archive, export, upload, metadata, media, review submission, offer codes. Zero dependenc
