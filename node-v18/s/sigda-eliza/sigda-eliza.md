# sigda-eliza

> 标签: agent, ai-agent, ai16z, decentralized, eliza, elizaos, ethereum, robinhood-chain, sigda, wallet-signed

## 简介

ElizaOS plugin for SIGDA — give any Eliza agent a wallet-signed inbox on Robinhood Chain. Cross-platform DMs, hold-to-chat ERC-20 gated rooms, federated identity.
