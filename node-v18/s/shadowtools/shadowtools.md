# shadowtools

> 标签: access-keys, admin-panel, cli, dashboard, outline, outline-br, outline-vpn, qrcode, shadowbox, shadowsocks

## 简介

Manage Outline VPN (Shadowbox) servers and access keys from a local admin dashboard, the command line, or your own code: list, create, rename, delete, set data limits, report usage and show QR codes
