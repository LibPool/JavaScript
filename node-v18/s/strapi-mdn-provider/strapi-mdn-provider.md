# strapi-mdn-provider

> 标签: check, mdn, provider-upload, strapi, strapi-provider, strapi-upload, upload

## 简介

Strapi v5 upload provider for Check's MDN media service (mdn.check-dc.com). Stores the absolute MDN URL.
