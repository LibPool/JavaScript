# sql-template-tag

> 标签: es2015, es6, mysql, oracle, oracledb, pg, postgres, sql, sqlite, string, tag, template

## 简介

ES2015 tagged template string for preparing SQL statements, works with `pg`, `mysql`, `sqlite` and `oracledb`
