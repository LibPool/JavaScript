# sanctionsai-mcp

> 标签: ai-agents, compliance, kya, mcp, model-context-protocol, ofac, risk, sanctions, sdn, x402

## 简介

MCP server: OFAC sanctions screening for AI agents. Screen names, wallets, and entities against the US Treasury SDN list (1,050 sanctioned wallets, 19,389 names, daily-refreshed source). Free tier, no API key.
