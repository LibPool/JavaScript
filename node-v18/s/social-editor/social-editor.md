# social-editor

> 标签: editor, library, social, ui, web

## 简介

A headless editor framework for building editors like facebook and twitter with @mentions, #hashtags and auto-linking support, based on Prosemirror.

- 官网：https://social-editor-box.netlify.app/
- 源码仓库：https://www.seeratawan.me/
- npm 页面：https://www.npmjs.com/package/social-editor
