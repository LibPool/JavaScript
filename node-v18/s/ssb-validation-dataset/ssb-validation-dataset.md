# ssb-validation-dataset

> 标签: JavaScript

## 简介

A small dataset of messages that help you build a validator for Secure Scuttlebutt messages. Having a validation dataset lowers the barrier to entry for writing software that validates SSB messages, and helps us identify and resolve edge-cases where valid
