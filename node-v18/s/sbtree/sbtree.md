# sbtree

> 标签: B Tree, B+, B+ Tree, Bplus, Tree, b plus, big data storage, bplus tree, database, metadata indexing, n-ary tree, optimized data store

## 简介

Optimised document store using B+ Tree for fields. Adapters support for In-Memory and FileSystem
