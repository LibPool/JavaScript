# squab-ui

> 标签: JavaScript

## 简介

|__ packages: 用于存放所有的组件。最后也是把它打包成库。【真正组件库只需要这个目录就可以了，字体文件也放在这个目录】   |__ examples: 用于进行测试，把src改成 examples。不修改src目录名也没毛病，只是 examples更符合组件库的功能的含义，而不是项目功能。【这个目录不是必须的，只是为了测试】 |
