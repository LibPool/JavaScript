# super-remix

> 标签: agent-skills, ai-agents, boilerplate, cli, create-app, generator, hmr, hot-reload, javascript, modular, npx, remix, remix-3, remix-run, remix3, scaffolding, starter, tailwind, tailwindcss, typescript

## 简介

Modular Remix 3 scaffolding for JavaScript or TypeScript, with optional Tailwind 4 and hot reloading that works in both, always on the newest Remix 3 release. AI agent skills and more modules on the way.
