# slimsemver

> 标签: esm, range, satisfies, semantic, semver, slim, tree-shakeable, version, versioning, zero-dependency

## 简介

A zero-dependency, ESM-first drop-in replacement for semver. Same API, same semantics, a fraction of the size, and linear where semver is quadratic.
