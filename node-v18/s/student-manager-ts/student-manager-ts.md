# student-manager-ts

> 标签: JavaScript

## 简介

A TypeScript-based command-line application built using Node.js, Inquirer, and Chalk. This tool allows users to manage students and courses with functionality to add, edit, delete, and view both students and courses. All data is stored persistently in JSO
