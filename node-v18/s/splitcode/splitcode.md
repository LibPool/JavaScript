# splitcode

> 标签: code-splitting, html, javascript, modularity, python, refactoring, split, static-analysis, typescript

## 简介

SplitCode — split large JS, TS, HTML or Python files into smaller dependency-ordered files with pure static analysis. No bundler, drop-in loader.
