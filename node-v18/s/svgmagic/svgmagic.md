# svgmagic

> 标签: nextsvg, svg, svgm, svgmagic, tailwindsvg

## 简介

SVGMagic, dynamic SVG loader with theme support for utility classes called in just one little line.

- 源码仓库：git+https://github.com/brohvis/svgmagic.git
