# stipendex

> 标签: agent-payments, llm-agents, mcp, payments, stipendex

## 简介

Stipendex — an open payment protocol for LLM agents: wallet kernel, signed mandates, and a trust registry. Name reserved; SDKs will live under the @stipendex scope.
