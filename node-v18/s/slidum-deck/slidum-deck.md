# slidum-deck

> 标签: agent-skills, claude-code, deck, presentation, skill, slides, slidum

## 简介

Install the slidum-deck agent skill: your coding agent generates single-file HTML presentations that play natively on Slidum (slidum.com).

## 官网

- 官网：https://slidum.com/skill
- 源码仓库：git+https://github.com/slidum/slidum.git
- npm 页面：https://www.npmjs.com/package/slidum-deck
