# slides-autovideo

> 标签: JavaScript

## 简介

This repository automatically generates videos from Google Slides. Basically, it records each slide, reads the speaker notes+sends them to 11 labs to generate audio, then puts everything together. Using these slides: https://docs.google.com/presentation/d
