# svg-to-jsx-go

> 标签: JavaScript

## 简介

A fast golang program for converting all `.svg` files in a directory to to `.jsx`.

## 官网

- npm 页面：https://www.npmjs.com/package/svg-to-jsx-go

## 历史版本号

- 当前版本：1.0.0

- 1.0.0

## 获取地址
