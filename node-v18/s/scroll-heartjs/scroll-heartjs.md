# scroll-heartjs

> 标签: bottom-scroll, celebration, flying-hearts, hearts, hearts-animation, react, react-plugin, scroll-heartjs, scroll-trigger

## 简介

A lightweight, zero-dependency React plugin that triggers floating flying hearts from bottom to top when users scroll to the end of the page.
