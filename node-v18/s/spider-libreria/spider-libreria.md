# spider-libreria

> 标签: JavaScript

## 简介

Esta librería proporciona un componente de gráfico tipo araña (spider chart) para Angular, utilizando DevExtreme para la visualización.

## 官网

- npm 页面：https://www.npmjs.com/package/spider-libreria
