# sharepoint-pages

> 标签: cli, json-patch, sharepoint, sharepoint-pages

## 简介

SharePoint Pages authoring CLI: RFC 6902 patch + schema validation pipeline, page normalization, and bundled reference docs/schemas. Zero runtime dependencies.
