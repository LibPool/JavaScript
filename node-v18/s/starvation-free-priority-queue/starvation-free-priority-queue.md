# starvation-free-priority-queue

> 标签: ES2020, aging-tasks, balance, bounded-delay, frontier, greedy-per-batch, nodejs, pre-allocated, prioritization, prioritized-task, priority, priority-queue, scheduling, starvation, starvation-free, starvation-free-priority-queue, task-schedule, task-scheduling, tasks-queue, ts, typescript, weighted-tasks

## 简介

An in-memory priority queue that prevents starvation by balancing priority and arrival time. Items are greedily prioritized within each batch of the longest-waiting items, ensuring fairness alongside prioritization and bounded delays for low-priority task
