# switch-jdk-version

> 标签: cli, cross-platform, java, java-home, jdk, jdk-switch, jdk-version, linux, macos, switch-jdk, windows

## 简介

JDK 版本一键切换工具 — 快速切换 JDK 版本，自动更新 PATH 和 JAVA_HOME，支持 Windows / macOS / Linux
