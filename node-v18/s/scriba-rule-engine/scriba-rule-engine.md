# scriba-rule-engine

> 标签: JavaScript

## 简介

A flexible **rule engine (zero dependencies)** for evaluating dynamic conditions and executing actions on records. Ideal for **validation, automation, and configurable workflows** in TypeScript/Node.js projects.
