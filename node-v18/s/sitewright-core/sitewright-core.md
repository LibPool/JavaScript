# sitewright-core

> 标签: accessibility, audit, cms, cookie-consent, gdpr, geo, llms-txt, nextjs, payload, payloadcms, seo

## 简介

Shared runtime for Next.js + Payload CMS sites: image backup and versioning, public-form abuse brakes, real cookie consent, generated legal pages, SEO/GEO helpers, and an audit CLI that gates deploys.
