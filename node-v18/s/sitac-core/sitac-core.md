# sitac-core

> 标签: audit, compliance, copy-before-write, gdpr, history, iso27001, mysql, postgres, postgresql, soc2, soft-delete, stable-identity, temporal, versioning

## 简介

Stable-Identity Temporal Audit Chain — production-ready copy-before-write versioning with stable foreign keys, restoration that preserves deletion evidence, and child-table archival. Designed to support auditability and compliance controls. Supports MySQL
