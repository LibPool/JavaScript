# simui-code

> 标签: JavaScript

## 简介

Frontend Pure CSS/JS library, useful for creating reactive and responsive web frontend within your HTML code, it is super lightweight, uses grids, BEM style and is less opionated than other frameworks such as Bootstrap or Foundation
