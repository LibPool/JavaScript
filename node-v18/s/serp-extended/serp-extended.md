# serp-extended

> 标签: SEO, SERP, extended, google, google scraper, scrape google results, scraper, search

## 简介

This module is an extention to 'serp' module. It adds an option to exclude whichever websites you want from your search results. It provides different options for scraping the google results (either the list of the referenced sites or the number of result
