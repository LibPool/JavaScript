# scbe-agent-bus

> 标签: agent-bus, agent-orchestration, agentic-cli, ai-safety, audit-chain, chain-of-custody, governance, harmonic-wall, scbe, workspace

## 简介

SCBE agent-bus: typed Node surface over the SCBE governed event runner. Routes AI/human/AI events through the harmonic-wall pipeline, creates, exports, and verifies local bus workspaces, and returns a typed envelope.
