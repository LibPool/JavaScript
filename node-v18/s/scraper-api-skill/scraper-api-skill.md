# scraper-api-skill

> 标签: agent-skill, claude, mcp, scraper-api, scraping, social-media

## 简介

Installer for the scraper-api.com agent skills — copies the SKILL.md skills into ~/.claude/skills so Claude, Cursor and other skill-aware agents can query the scraper-api.com scraping API from natural language.
