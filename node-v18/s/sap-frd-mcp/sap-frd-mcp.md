# sap-frd-mcp

> 标签: abap, frd, ibm-bob, mcp, rfc, sap, soap

## 简介

IBM Bob MCP server — connects to the SAP FRD system (nonprodfrun.hec.edst.ibm.com) via SOAP/RFC and WebGUI (ITS). Read tables, browse transactions, run reports.
