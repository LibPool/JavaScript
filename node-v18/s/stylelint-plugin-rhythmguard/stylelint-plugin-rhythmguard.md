# stylelint-plugin-rhythmguard

> 标签: css, design-system, design-tokens, eslint-plugin, linting, logical-css, spacing, spacing-scale, stylelint, stylelint-plugin, tailwindcss

## 简介

Nobody chose 13px. Catches off-scale spacing in CSS and Tailwind class strings and snaps it to your scale or tokens. Stylelint rules, an ESLint companion, and an audit CLI.
