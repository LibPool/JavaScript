# san-cli-docit-theme

> 标签: docit, docit-theme, loader, markdown, san, san-docit, san-loader, webpack

## 简介

san-cli-docit-theme 是 [San](https://github.com/baidu/san) CLI 工具中 Markdown 文档建站中的主题模板部分，可以作为[自定义模板](https://ecomfe.github.io/san-cli/)的参考例子。
