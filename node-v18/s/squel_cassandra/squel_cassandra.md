# squel_cassandra

> 标签: cassandra, cql, squel

## 简介

This repo is intended to serve as a plugin for Squel(>3) to support  CQL(Cassandra Query Language)(>3.1) as it's specified [here](https://docs.datastax.com/en/cql/3.1/pdf/cql31.pdf)
