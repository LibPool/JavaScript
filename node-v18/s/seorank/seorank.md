# seorank

> 标签: cli, mcp, mcp server, model context protocol, moshpit, on-page seo, seo, seo audit, technical seo, tui

## 简介

seo.rank: a free, open-source on-page SEO audit. Web app, JSON API, CLI, TUI and an MCP server (stdio, no API key).
