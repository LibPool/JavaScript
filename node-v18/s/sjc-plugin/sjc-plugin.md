# sjc-plugin

> 标签: Webpack4, Webpack4 插件, sjc-plugin

## 简介

SJCPlugin 是 Webpack 一款插件，用来在 Webpack 打包项目后生成的 index.html 文件中，为生成 js 文件的添加时间戳。
