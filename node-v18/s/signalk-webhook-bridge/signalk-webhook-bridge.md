# signalk-webhook-bridge

> 标签: signalk, signalk-category-utility, signalk-node-server-plugin, signalk-plugin-configurator, webhook

## 简介

Send selected Signal K data paths to an external webhook with unit conversion, persistent queueing and automatic retry.
