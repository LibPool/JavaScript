# scr-to-svg

> 标签: JavaScript

## 简介

Small utility to convert rubik's cube scramble to svg patron. Supports Cubes from 2 to 7 + Megaminx + Square 1

## 官网

- 源码仓库：https://codeberg.org/Nogesma/scr-to-svg
- npm 页面：https://www.npmjs.com/package/scr-to-svg
