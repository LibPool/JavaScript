> 标签: automation, browser automation, captcha, death by captcha, node, recaptcha, rpa, selenium, selenium captcha, selenium captcha solver, selenium sdk, text captcha, typescript, web automation

## 简介

Simple and lightweight Node.js SDK for Selenium that facilitates the automation of text CAPTCHA and reCAPTCHA in enterprise browser automation workflows.
