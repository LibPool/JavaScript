# scratchboard

> 标签: agent-skills, agents, board, cli, issues, kanban, markdown, mattpocock, skills, tickets, wayfinder

## 简介

Render the markdown tickets already in your repo as a kanban board. Reads the file layout the mattpocock/skills agent skills write. Read-only by choice, zero config.
