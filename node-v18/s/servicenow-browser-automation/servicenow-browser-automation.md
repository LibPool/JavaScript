# servicenow-browser-automation

> 标签: anchorbrowser, browser-automation, itsm-automation, nodejs, playwright, puppeteer, servicenow, snow

## 简介

Browser automation for ServiceNow — create/update incidents, manage CMDB records, run reports, and automate ITSM workflows when the REST API is locked down.
