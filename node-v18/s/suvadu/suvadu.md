# suvadu

> 标签: ai, claude, coding-agent, context, cursor, developer-tools, git, github, jira, mcp, memory

## 简介

Long-term memory for AI coding agents — indexes git history, PRs, Jira, and review comments into local SQLite and exposes them over MCP.
