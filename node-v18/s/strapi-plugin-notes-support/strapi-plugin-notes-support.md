# strapi-plugin-notes-support

> 标签: notes, plugin, strapi, strapi plugin, strapi-plugin

## 简介

A plugin for Strapi Headless CMS that provides the ability to add notes to entity records. support for node 18 pr higher credit: ComfortablyCoding
