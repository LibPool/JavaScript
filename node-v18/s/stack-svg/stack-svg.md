# stack-svg

> 标签: icomoon, stack svg, svg fragment identifiers, svg fragments, svg sprite, svg-stack, svgstack

## 简介

A module to convert icomoon symbol-defs.svg to a svg stack with fragments for usage in <img src='' />, background-image, mask-image, ...
