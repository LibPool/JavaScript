# shieldql

> 标签: auth, authentication, authorization, cybersecurity, graphql, insure, protect, query, querysanitization, safer, safergraphql, safest, safety, sanitization, secure, security, shield, shieldql

## 简介

A lightweight JavaScript library for GraphQL that adds authentication, authorization, and query sanitization to prevent malicious queries and injection attacks.
