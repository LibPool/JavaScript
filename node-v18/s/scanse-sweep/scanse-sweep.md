# scanse-sweep

> 标签: 2d-lidar, bun, lidar, range-finder, robotics, scanning, scanse, sensors, serial, sweep

## 简介

Bun-native driver for the Scanse Sweep 2D scanning LiDAR. Pure JavaScript over bun-serialport, no native addons.
