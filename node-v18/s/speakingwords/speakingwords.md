# speakingwords

> 标签: agent, claude-code, cli, codex, codex-cli, hooks, lexicon, linter, output-style, stop-hook, style

## 简介

An output parser for agent replies. Installs a style contract as configuration, in memory mode or hook mode, in a terse or conversational voice.
