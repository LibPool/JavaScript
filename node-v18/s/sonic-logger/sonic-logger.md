# sonic-logger

> 标签: apm, datadog, distributed-tracing, event-loop, fast, grafana, logger, logging, loki, metrics, ndjson, nestjs, new-relic, nodejs, observability, opentelemetry, otlp, pino-alternative, prometheus, request-logging, resource-monitor, route-analytics, sonic-logger, structured-logging, tempo, tracing, traffic-monitoring, typescript, winston-alternative

## 简介

Lightweight, fast, clear structured logging for Node.js & NestJS — auto error classification, request/response tracing with payload logging, an event-loop block watchdog, a resource monitor, and zero-dep OTLP logs/traces/metrics export to Loki, Tempo, Pro
