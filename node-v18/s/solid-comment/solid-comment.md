# solid-comment

> 标签: comment, indico, solid

## 简介

A simple Solid application meant to read and write comments into users’ [pods](https://solidproject.org/users/get-a-pod). This application is only the gateway to Solid and still needs a storing mechanism in a parent application – meaning your application
