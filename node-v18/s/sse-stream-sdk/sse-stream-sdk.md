# sse-stream-sdk

> 标签: h5, miniprogram, react, sse, vue

## 简介

跨平台 SSE（Server-Sent Events）流式接收 SDK，支持 **Web / Vue 3 / React / 微信小程序**，内置心跳保活、断线重连、`Last-Event-ID` 断点续传与消息节流能力。适用于 AI 大模型流式输出、实时消息推送等场景。
