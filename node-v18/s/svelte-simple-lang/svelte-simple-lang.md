# svelte-simple-lang

> 标签: i18n, lang, locale, ssl, svelte, svelte-i18n, svelte-lang, svelte-locale, svelte-simple-lang, sveltekit, typescript

## 简介

**Svelte Simple Lang** is a lightweight library to manage **multi-language** (i18n) for your Svelte project. It comes with a simple setup, built-in support for lazy loading of language files, nested keys, pluralization, parameter interpolation, and type s
