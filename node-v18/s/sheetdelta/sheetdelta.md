# sheetdelta

> 标签: cli, compare, diff, excel, mcp, spreadsheet, vba, workbook, xlsb, xlsm, xlsx

## 简介

Compare Excel workbooks from the command line — cell, formula, VBA, and structural diffs. Launcher for the SheetDelta CLI (prebuilt binaries coming soon).
