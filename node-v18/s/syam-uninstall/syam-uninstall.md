# syam-uninstall

> 标签: auto-detect, bun, cli, deno, npm, package-manager, pnpm, remove, syam, uninstall, yarn

## 简介

Smart uninstall CLI that auto-detects your package manager (npm, pnpm, yarn, bun, deno) from lock files.
