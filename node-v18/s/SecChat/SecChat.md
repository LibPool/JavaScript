# SecChat

> 标签: JavaScript

## 简介

Node.js+Socket.io+CryptoJS（AES）实现的简易聊天网站。   目前会丢失消息 也没有数据库。但是，安全。   （请自行修改AES的salt的计算方法，现在是每天更换一次，所以，仍然有一些不太安全的地方，更多逻辑待添加）
