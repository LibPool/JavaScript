# stathead-mcp

> 标签: ai, claude, dynasty, fantasy-football, mcp, model-context-protocol, nfl, sports-analytics

## 简介

Full set of fantasy football data analysis tools — NFL stats, play-by-play, Next Gen Stats, dynasty values, projections, prospects, Sleeper league analysis, and editable Excel projections/rankings — as an MCP server for Claude and any MCP client.
