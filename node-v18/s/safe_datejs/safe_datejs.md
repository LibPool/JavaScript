# safe_datejs

> 标签: date, date.js, datejs, safe

## 简介

A safe(node.js VM isolated) wrapper around datejs.com library. Safe to be used with mongoose

## 官网

- 官网：http://www.datejs.com
- 源码仓库：git://github.com/firebaseco/safe_datejs.git
- npm 页面：https://www.npmjs.com/package/safe_datejs

- npm registry：https://registry.npmjs.org/safe_datejs
