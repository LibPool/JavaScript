# site-inspect

> 标签: Youssef Oubelaid, site-inspect

## 简介

site-inspect is a powerful command-line tool for checking the status of websites, identifying errors and issues like server errors, parked domains, and HTTP status codes. It also generates reports on page length and content after parsing HTML.
