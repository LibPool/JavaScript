# skim-mcp

> 标签: agent, ai, claude, cursor, markdown, mcp, model-context-protocol, reader, skim, web-scraping, x402

## 简介

MCP server for Skim — URLs to clean markdown. Card API key (sk402_) default; wallet/x402 optional. Batch, extract, crawl, PDF, watch, signals.
