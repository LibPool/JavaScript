# soma-style

> 标签: JavaScript

## 简介

The soma ecosystem's universal design system — tokens (NativeWind/Tailwind preset) + React Native components (Text, Button, Card, Pill, Badge, Input, Bar, Ring, Modal, SegmentedControl, NavBar) that render on web and native. Modeled on macro-engine.
