# storypole

> 标签: agent-skills, feature-registry, pdlc, prd, prototype, storypole

## 简介

Storypole - a shared reference for teams building a prototype together: a git-backed feature registry with owner locks, a generated PRD, and PDLC phase gates. Pre-release placeholder; no stable API yet.
