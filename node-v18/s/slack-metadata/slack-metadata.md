# slack-metadata

> 标签: channel, metadata, slack, slack-channel, slack-channel-data, slack-channel-metadata, slack-channel-scraper, slack-data, slack-metadata, slack-scraper, slack-team, slack-team-data, slack-team-metadata, slack-team-scraper

## 简介

A tool that captures Slack channel metadata of all users and bot users in a selected timeframe. No qualitative data or message text are read or captured.
