# svelte-number-format

> 标签: credit-card, currency, currency-input, date-input, formatted-input, i18n, input-mask, internationalization, intl, masked-input, number-format, numeric-input, numeric-text, pattern-format, pattern-text, percentage, phone-number, ssr, svelte, svelte-component, svelte5

## 简介

Lightweight currency, number and masked input components for Svelte 5. NumericFormat (currency, percent, decimal) & PatternFormat (phone, credit card, date) inputs, plus NumericText & PatternText for SSR-safe display.
