# supremo-cli

> 标签: bootstrap, cli, device-flow, mcp, scaffold, supremo

## 简介

CLI do Supremo — prepara o workspace local de um projeto (device flow: clona, configura .env.local, instala e roda o baseline) e serve a ponte MCP.
