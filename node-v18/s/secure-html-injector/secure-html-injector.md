# secure-html-injector

> 标签: JavaScript

## 简介

A lightweight React library for securely injecting HTML strings into your React components. This library uses DOMPurify to sanitize HTML content and converts it to React elements, preventing XSS attacks while maintaining the ability to render dynamic HTML
