# sharepointconnector

> 标签: Node.js wrapper for O365 REST API, O365, SharePoint NPM, sharepoint, sharepoint npm, sharepointconnector

## 简介

SharePoint library which supports multiple authentication strategies, file streaming, fetching details by the list Title, Pagination, extendable record fetch limit, added support to query Operators and supports Concurrent user login
