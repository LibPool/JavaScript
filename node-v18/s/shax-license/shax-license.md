# shax-license

> 标签: drm, hwid, license, license-server, licensing, nextjs, node, nuxtjs, shax, software-protection, typescript

## 简介

Official TypeScript & Node.js SDK for Shax License Server (https://license.webda.in). Built-in Next.js and Nuxt.js support with hardware fingerprinting, offline caching, and route protection.
