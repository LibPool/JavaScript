# screen-shot-fix

> 标签: JavaScript

## 简介

基于web端自定义截屏插件(Vue3版)的项目，增加了截图完成时截图区域位置信息的回调，删除了其它工具栏

## 官网

- 官网：https://github.com/likaia/screen-shot#readme
- npm 页面：https://www.npmjs.com/package/screen-shot-fix

- 1.0.0
