# svgo

> 标签: minify, optimize, svg, svgo

## 简介

SVGO is a Node.js library and command-line application for optimizing vector images.

- 官网：https://svgo.dev
- 源码仓库：git://github.com/svg/svgo.git
- npm 页面：https://www.npmjs.com/package/svgo
