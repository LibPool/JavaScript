# sprite-machine

> 标签: glb, gltf, low-poly, pixel-art, sprite, three, threejs, visual-hull, voxel

## 简介

Turn a sheet of pixel-art face sprites into a low-poly, textured glTF binary — the engine behind Sprite Machine.
