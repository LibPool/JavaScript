# spfn

> 标签: ai-coding-agent, backend, boilerplate, claude-code, cli, crud-generator, dev-tools, framework, full-stack-framework, generator, nextjs, scaffolding, spfn, type-safe, typescript

## 简介

Scaffold a full-stack TypeScript backend onto a Next.js app built with an AI coding agent: auth, database, typed routes and codegen, one fixed vertical slice per feature
