# sxz-devide-html-css-js

> 标签: css, devide, devide style/javascript from html, html, javascript, sxz, sxz-devide-html-css-js, 石星周

## 简介

提供了将HTML文件里的css和js代码从HTML代码里分离出来的方法，该方法将内联css和js转成外联，并自动链接
