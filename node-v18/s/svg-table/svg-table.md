# svg-table

> 标签: JavaScript

## 简介

A tiny TypeScript library to turn tabular data into a styled SVG table. It separates three concerns: - Data: describe your table structure (data, headers, footer) with TableData. - Formatting: convert raw values into display strings with TableFormatter. -
