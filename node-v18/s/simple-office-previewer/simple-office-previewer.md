# simple-office-previewer

> 标签: angular, docx, office, pptx, preview, wasm, webassembly, xlsx

## 简介

Client-side, high-fidelity DOCX/XLSX/PPTX preview for Angular — renders entirely in the browser via a .NET WASM engine, no upload, no server round-trip.
