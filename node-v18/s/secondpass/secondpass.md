# secondpass

> 标签: agentos, bun, cli, deepsec, prompt-injection, sast, security, static-analysis, vulnerability-scanner

## 简介

Two-stage security scanner: a free deterministic regex pass, then an AI pass that adjudicates each candidate inside an agentOS sandbox. An Apache-2.0 derivative of Vercel's deepsec, with no Vercel dependency.
