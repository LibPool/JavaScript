# sht4x

> 标签: Adafruit, Humidity, Pi, Raspberry, SHT40, SHT41, SHT45, SHT4X, Sensor, Temperature

## 简介

Reads humidity and temperature from the SHT40, SHT41, and SHT45 sensor via I2C.
