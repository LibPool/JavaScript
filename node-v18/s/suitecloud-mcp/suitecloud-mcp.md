# suitecloud-mcp

> 标签: mcp, netsuite, sdf, suitecloud, suitescript

## 简介

MCP server for the NetSuite SuiteCloud (SDF) CLI: deploy, validate, import objects and files from any MCP client. Not affiliated with Oracle or NetSuite.
