# semachunk

> 标签: BERT, chunk, chunking, cosine, embeddings, ml, nlp, rag, semantic, sentence, similarity, splitting, text-processing, transformers, transformers.js, xenova

## 简介

Semantic chunking of large texts. Plug any embedding provider/API. Batch embeddings for efficiency and handling API rate limits.
