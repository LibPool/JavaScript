# socialfanout-mcp

> 标签: ai-agents, bluesky, claude, cursor, mcp, model-context-protocol, social-fanout, social-media, social-publishing

## 简介

Local MCP server for Social Fanout — one safe tool for your AI agent to publish to every social network. A tiny, zero-dependency stdio client over the Social Fanout REST API.
