# sparse-boolean-codec

> 标签: base64, bitset, boolean-array, codec, compression, rle, run-length-encoding, url-safe

## 简介

URL-friendly, run-length-compressed encoding for a boolean array that can grow (more false values appended) without changing the encoded prefix.
