# scl339-git-branch-cleaner

> 标签: branch-delete, cli-tool, developer-tools, git-branch, git-branch-cleaner, git-cleanup, git-housekeeping, git-tools, merged-branches, stale-branches

## 简介

Interactive CLI to clean up local Git branches — merged branches, stale branches (no commit in 30 days), or user-selected. Dry-run mode, safety confirmations.
