# solparse-lib3

> 标签: blockchain, library, solana, tokens

## 简介

This project is a TypeScript module for interacting with the Solana blockchain, specifically for retrieving token associated accounts. It provides a simple and efficient way to access and manage token accounts on the Solana network.
