# sad-loading

> 标签: ljy, loading, sad-loading

## 简介

Loading 组件是一个加载状态展示组件，适用于在网页上展示加载状态，并提供一些可选的动画效果。该组件适用于需要在数据加载或特定事件发生时显示加载状态的场景。
