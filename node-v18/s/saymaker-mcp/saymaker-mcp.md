# saymaker-mcp

> 标签: ai-image-generator, ai-video-generator, image-to-video, kling, mcp, model-context-protocol, nano-banana, saymaker, seedance, veo

## 简介

MCP server for SayMaker (saymaker.ai) — generate and edit images and video from any MCP client on Veo 3.1, Kling 3.0, Seedance 2.0, Nano Banana 2, GPT Image 2.5, Seedream 5.0 and more, on one credit balance.
