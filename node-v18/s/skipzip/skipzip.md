# skipzip

> 标签: JavaScript

## 简介

CLI tool to package application to .zip for deployment (skipping node_modules). Ignores .szignore glob patterns, similiar to .gitignore.

## 官网

- npm 页面：https://www.npmjs.com/package/skipzip
