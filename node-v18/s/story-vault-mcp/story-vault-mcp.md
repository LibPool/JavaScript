# story-vault-mcp

> 标签: mcp, model-context-protocol, sqlcipher, story-vault, writing

## 简介

MCP server for Story Vault — lets external AI clients (Claude Desktop, Cursor, Cline, Qwen Chat…) read and write your local encrypted writing vault.
