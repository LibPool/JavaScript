# sourcedump

> 标签: cli, devtools, extract, recover, reverse-engineering, source-map, sourcemap, sourcemaps, unpack

## 简介

Recover a website's original source files from its published JS/CSS sourcemaps, like the Sources panel in Chrome DevTools
