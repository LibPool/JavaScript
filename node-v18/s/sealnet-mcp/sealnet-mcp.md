# sealnet-mcp

> 标签: claude, cursor, e2ee, mcp, model-context-protocol, seal, secure-handoff

## 简介

Model Context Protocol server for SEAL — model never holds capability by default (handoff mode); explicit opt-in to forward mode with strict TTL/recipient policy.
