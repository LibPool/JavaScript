# swaggerapi-typescript-api

> 标签: JavaScript

## 简介

根据服务端swagger文档，自动生成ts定义和api接口代码，节省大量写接口的时间，目前测试的是swagger 2.x版本的文档，同理如果有需要只需升级openapi-typescript，然后做相应转换调整
