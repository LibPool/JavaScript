# signalk-bandg-hydra-nmea0183

> 标签: autopilot, b&g, bandg, gps, h2000, h3000, hercules, hydra, legacy, nmea, nmea0183, signalk, signalk-category-instruments, signalk-category-nmea-0183, signalk-node-server-plugin

## 简介

Feeds position and navigation data into the NMEA 0183 input of older B&G H2000 processors (Hydra, Hercules), which only accept an outdated sentence format
