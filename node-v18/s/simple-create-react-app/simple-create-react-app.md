# simple-create-react-app

> 标签: create-react-app, react

## 简介

这是一个100行代码的简化版的` create-react-app `，去除了环境检测、版本检测、离线包检测等代码，只保留了创建` react ` 项目的核心代码。只用作学习，其他用途不承担任何风险责任。线上项目，请使用官方的` create-react-app `
