# signalk-sailplan-ui

> 标签: signalk-category-utility, signalk-node-server-plugin, signalk-webapp

## 简介

Signal K webapp: upload a sail plan diagram and click on sails/reefs to set which are currently flying. Writes state via @signalk/sailsconfiguration.
