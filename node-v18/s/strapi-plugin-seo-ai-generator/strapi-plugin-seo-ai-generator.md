> 标签: ai, gemini, groq, llm, meta, openai, seo, strapi, strapi-plugin

## 简介

A Strapi v5 plugin that generates SEO metadata using LLM APIs (Google Gemini, Groq, OpenAI) with dynamic field mapping.
