# serverless-dependson-plugin

> 标签: aws lambda dependson, cloudformation dependson, serverless RequestLimitExceeded, serverless dependson, serverless plugin, serverless request limit exceeded, throttled EC2 rate limit RequestLimitExceeded

## 简介

Serverless plugin that automatically generates DependsOn references for AWS Lambdas to prevent AWS RequestLimitExceeded errors
