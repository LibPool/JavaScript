# sslpin

> 标签: certificate, cli, fingerprint, pins, pki, spki, ssl, sslpin, tls

## 简介

A lightweight CLI tool to extract SHA1, SHA256, SPKI pins and certificate fingerprints for SSL/TLS pinning from the target domain
