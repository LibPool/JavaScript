# ska-list

> 标签: JavaScript

## 简介

1. Crie um arquivo chamado **.npmrc** no root de seu projeto. 2. Em Azure Artifacts selecione a biblioteca **ska-list** 3. Clique em **connect to feed** 4. Copie as informações de registro e cole em seu arquivo **.npmrc**
