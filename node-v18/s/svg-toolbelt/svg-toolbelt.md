# svg-toolbelt

> 标签: d3, diagrams, mermaid, pan, svg, svg-pan, svg-toolbelt, touch, typescript, visualization, zoom

## 简介

A lightweight, zero-dependency library to add zoom, pan, touch, keyboard, and export support to any SVG.
