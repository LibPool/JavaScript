# storm-node

> 标签: JavaScript

## 简介

Simple implementation of [storm-multilang protocol](https://github.com/nathanmarz/storm/wiki/Multilang-protocol) for nodeJS apps. Handles reading, emitting, acking, failing, and handshaking.
