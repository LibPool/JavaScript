# slack-mcp-server-http

> 标签: context, mcp, model, model context protocol, protocol, slack, slack-api

## 简介

Model Context Protocol (MCP) server for Slack Workspaces. This integration supports Stdio, SSE, and HTTP transports with SLACK_MCP_XOXP_TOKEN header authentication, proxy settings and does not require any permissions or bots being created or approved by W
