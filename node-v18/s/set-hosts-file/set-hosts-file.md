# set-hosts-file

> 标签: /etc/hosts, change hosts, etc hosts, home king, hostname, hosts file

## 简介

这是一个配置hosts文件的脚本,如果你用的macOs 或者 Linux, hosts文件默认在 `/etc/hosts`. window默认在 `C:/Windows/System32/drivers/etc/hosts`.
