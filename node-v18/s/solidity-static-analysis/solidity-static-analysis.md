# solidity-static-analysis

> 标签: JavaScript

## 简介

The goals of this project is to create a way to add [Remix's](https://github.com/ethereum/browser-solidity/tree/master/src/app/staticanalysis)  static analysis to your [Truffle](https://github.com/trufflesuite/truffle) workflow.
