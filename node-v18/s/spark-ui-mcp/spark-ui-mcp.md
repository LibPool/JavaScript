# spark-ui-mcp

> 标签: ai, apache-spark, claude, mcp, model-context-protocol, monitoring, spark, spark-ui

## 简介

MCP server for Apache Spark UI REST API — inspect jobs, stages, SQL executions, executors and more. Supports SOCKS5 proxy for Kubernetes clusters.
