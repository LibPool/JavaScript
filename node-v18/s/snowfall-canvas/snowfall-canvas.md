# snowfall-canvas

> 标签: animation, background, browser, canvas, dpr, effect, html5-canvas, particles, performance, snow, snowfall, typescript, ui, visual, winter

## 简介

SnowfallCanvas is a high-performance snowfall animation for any HTMLCanvasElement with automatic DPR and performance adaptation.
