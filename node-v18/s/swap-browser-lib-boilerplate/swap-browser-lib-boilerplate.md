# swap-browser-lib-boilerplate

> 标签: SWAP, SWAP App, browser, lib, library, webpack

## 简介

This is a boilerplate project for SWAP browser libraries. This project is used as a reference to design the swap-browser-lib generator (generate-swap-browser-lib), a Generate generator. It relies on Yarn, ESNext, StandardJS, ESlint, BabelJS, Yarn Scripts,
