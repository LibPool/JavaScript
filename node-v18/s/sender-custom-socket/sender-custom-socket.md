# sender-custom-socket

> 标签: JavaScript

## 简介

Sender is a lightweight and easy-to-use wrapper around **Socket.IO**, designed to simplify real-time communication in your Node.js and frontend applications. With Sender, you can quickly establish WebSocket connections and send messages using a clean API.
