# sap-abap-mcp-ibm

> 标签: abap, basis, erp, ibm-bob, mcp, rfc, s4hana, sap, soap

## 简介

IBM Bob MCP server — connects to any SAP ABAP system via SOAP/RFC and WebGUI (ITS). Read tables, browse transactions, run reports, manage users and transports.
