# scroll-date-indicator

> 标签: chat, date, indicator, matrix, matrix-js-sdk, matrix-rust-sdk, react, scroll, timeline, typescript

## 简介

Floating, date indicator for chronological timelines. Framework-agnostic core with optional React bindings. Works with any chat or feed UI with focus on Matrix-based clients.
