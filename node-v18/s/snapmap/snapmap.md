# snapmap

> 标签: automatically delete data, data expiration, data structure, dictionary, es6, expiration, key/value, map, map expiration, object expiration, ttl

## 简介

A tiny (< 1kb minified & gzip'd) and dependency-free extension of the ES6 Map object that lets you set an expiration time for key/value pairs.
