# secpac

> 标签: cli, config, dotenv, env, environment, node, secrets, security, tool

## 简介

Secure Environment Config & Protected Access Controller (SECPAC) - A high-security, encrypted alternative to .env. Stop storing secrets in plain text and start using password-protected environment management.
