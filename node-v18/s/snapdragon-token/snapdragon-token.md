# snapdragon-token

> 标签: ast, capture, compile, compiler, convert, lex, lexer, parse, parser, render, snapdragon, token, tokenize, transform

## 简介

Create a snapdragon token. Used by the snapdragon lexer, but can also be used by plugins.
