# sfdx-retrieve-deploy-companion

> 标签: sfdx-plugin

## 简介

SFDX plugin to selectively retrieve metadata of a particular type from an org to a specified directory in source format and to deploy a particular module, directory or a component in source format to an org. Both source tracked and non source tracked orgs
