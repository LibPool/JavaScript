# suwaku

> 标签: apple-music, audio, deezer, discord, discord-bot, discord.js, lastfm, lavalink, lavalink-client, lyrics, music, music-bot, player, queue, soundcloud, streaming, suwaku, youtube

## 简介

A powerful and flexible Lavalink-based music player for Discord bots. Built with Node.js, featuring multi-source support, advanced queue management, and comprehensive event system.
