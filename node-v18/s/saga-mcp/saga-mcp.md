# saga-mcp

> 标签: agent-tools, ai-agent, ai-agents, claude, claude-code, issue-tracker, jira-alternative, llm-tools, mcp, mcp-server, model-context-protocol, project-management, project-tracker, sqlite, task-manager, task-tracker

## 简介

A Jira-like project tracker MCP server for AI agents. SQLite-backed, per-project scoped, with full hierarchy (Projects > Epics > Tasks > Subtasks), activity logging, and a dashboard — so LLMs never lose track.
