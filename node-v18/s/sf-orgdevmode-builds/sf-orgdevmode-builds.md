# sf-orgdevmode-builds

> 标签: force, salesforce, salesforcedx, sf, sf-plugin, sfdx, sfdx-plugin

## 简介

A sf plugin enabling deploy of releases that requires multi steps in order to be deployed. It supports deploy of metadata, datapacks (SFI) and shell commnads.
