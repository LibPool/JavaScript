# skills-organizer

> 标签: ai-agents, claude-code, cli, codex, dotfiles, gemini-cli, opencode, skills, symlink

## 简介

Consolidate AI coding harness skills (Claude Code, Gemini CLI, opencode, Codex, ...) into one directory, symlinked from every harness, via a local review UI.
