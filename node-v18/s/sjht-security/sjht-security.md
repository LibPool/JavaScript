# sjht-security

> 标签: JavaScript

## 简介

一个基于 axios 的自动加解密拦截器工具，提供透明的请求加密和响应解密功能，支持 SM4 加密算法。  **注意：后端必须接入对应版本的sdk，才能正常使用该工具。**
