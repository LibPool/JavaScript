# stepper-sdk

> 标签: cpu, ethereum, evm, nand, netlist, processor, verify

## 简介

The STEPPER ST-8 processor as a library: 2,161 NAND gates, an assembler, and a verifier that replays a chip's whole on-chain history and checks it.
