# strapi-plugin-grid-view

> 标签: admin, content-manager, grid, image-preview, list-view, media, plugin, strapi, strapi-plugin

## 简介

A card grid for the Strapi content manager list view, similar to the Media Library. Plus full-size previews for the images in it.
