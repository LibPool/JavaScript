# sql2

> 标签: builder, database, javascript, mariadb, microsoft sql server, mysql, nodejs, oracle, postgresql, query, sql, sqlite, template-strings, typescript

## 简介

A TypeScript library for writing SQL queries using template strings with automatic parameterization and nested statement support.
