# subschema-plugin-type-checkboxes

> 标签: JavaScript

## 简介

Render an array of checkboxes. Has an itemTemplate, and groupTemplate property that can be set to change the decoration around each checkbox, or group of checkboxes respectively. See the [example]("http://subschema.github.io/subschema/#/Checkboxes")
