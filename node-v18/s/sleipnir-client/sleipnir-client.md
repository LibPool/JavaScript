# sleipnir-client

> 标签: browser, isomorphic, node, rest, rpc, signalr, sleipnir, typescript, websocket

## 简介

Isomorphic JavaScript/TypeScript client for the Sleipnir multi-transport RPC framework (REST + WebSocket + SSE events). Browser + Node.
