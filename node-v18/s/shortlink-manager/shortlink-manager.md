# shortlink-manager

> 标签: encurtado, encurtador, link, mongodb, shortlink, url

## 简介

shortlink-manager é um pacote npm que permite criar links encurtados utilizando um banco de dados (MongoDB). Ideal para desenvolvedores que desejam integrar um encurtador de URL em seus projetos, proporcionando uma maneira pratica de redirecionar URLs.
