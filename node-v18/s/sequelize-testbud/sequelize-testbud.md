# sequelize-testbud

> 标签: chai, jest, mocha, sequelize, test, tests

## 简介

Sequelize-TestBud helps to make sure that you write less code when you write tests that produce/update data in your database  by providing APIs to do stuff such as restoring model state, deleting created data at the end of a test, and much more.
