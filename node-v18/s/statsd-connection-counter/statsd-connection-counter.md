# statsd-connection-counter

> 标签: connections, graphite, metrics, statsd

## 简介

A small lib using node-statsd-client to count incoming connections as well as globalAgent connections and queue length by host

## 官网

- 源码仓库：git://github.com/addisonj/node-statsd-connection-counter.git
- npm 页面：https://www.npmjs.com/package/statsd-connection-counter
