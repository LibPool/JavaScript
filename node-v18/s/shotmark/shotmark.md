# shotmark

> 标签: annotation, browser-screenshot, canvas, capture, drawing, highlight, image-annotation, markup, mosaic, react, screen-capture, screenshot, screenshot-tool, web-capture

## 简介

Lightweight React screenshot annotation library. Capture, draw, copy & download in one line. Zero UI dependency, privacy-first, plugin-based shapes.
