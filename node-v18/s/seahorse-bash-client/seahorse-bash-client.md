# seahorse-bash-client

> 标签: agent, bash, mcp, pty, reverse-connection, seahorse, shell

## 简介

Reverse MCP client implementing the Seahorse Bash Protocol v1 (bash_run / bash_session_open / bash_input / bash_output / bash_kill / bash_list). Zero native dependencies — portable PTY via python3.
