# sparql-inferenced

> 标签: HyLAR, OWL, RDF, SPARQL, inference

## 简介

An RDF inferencer that extends the HyLAR (https://github.com/ucbl/HyLAR-Reasoner.git) inferencing engine to allow inferencing with SPARQL Construct queries
