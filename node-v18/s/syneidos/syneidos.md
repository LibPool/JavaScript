# syneidos

> 标签: eidos, graph, knowledge, pkm, typed-links

## 简介

Core data model of the Syneidos personal knowledge system: eide (entities preserved across versions and instances), nodes, typed directed edges, axes, situations — and the storage-backend treaty.
