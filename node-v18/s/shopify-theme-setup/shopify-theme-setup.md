# shopify-theme-setup

> 标签: dawn, horizon, scaffold, shopify, tailwind, theme

## 简介

Scaffold a new Shopify Dawn or Horizon theme project with Encircle's standard tooling (Tailwind v4, Prettier, ESLint, Husky, Theme Check)
