# strapi-plugin-global-filters

> 标签: content-manager, filters, list-view, plugin, strapi, strapi-plugin

## 简介

Always-on, sticky list filters for the Strapi 5 Content Manager: pick which fields become quick filters per content type; selections persist across reloads and navigation.
