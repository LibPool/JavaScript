# sectoralarm

> 标签: alarm, sector, sectoralarm

## 简介

A simple Node.js library to check the status and history of Swedish Sector Alarm sites. Library also includes a notify functionality that executes a callback as the alarm status changes. This library uses https://minasidor.sectoralarm.se, and is intended
