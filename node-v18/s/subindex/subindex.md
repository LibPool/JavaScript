# subindex

> 标签: engine, index, indexer, indexes, indexing, leveldb, levelup, mongodb, optimize, optimizer, queries, query, query-engine, sublevel

## 简介

Generic pluggable indexing system for leveldb/levelup. Designed to be used with the level-queryengine query engine.
