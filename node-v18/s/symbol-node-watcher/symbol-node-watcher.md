# symbol-node-watcher

> 标签: JavaScript

## 简介

設定したノードの稼働を監視します。 もし、他のノードと大きくブロック高が離れていたら`symbol-shoestring`を`docker-compose down`し`up -d`します。また、設定していれば Discord にて通知します。 ※bootstrap でも使えます。run と stop コマンドを書き換えてください。
