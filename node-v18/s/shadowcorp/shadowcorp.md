# shadowcorp

> 标签: api, blockchain, near, sdk, shadowcorp, typescript

## 简介

Official JavaScript and TypeScript SDK for the ShadowCorp NEAR Blockchain API - providing typed, easy-to-use access to network stats, blocks, transactions, accounts, tokens, NFTs, validators, alerts, RPC proxy, and read-only graph queries.
