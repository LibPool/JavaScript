# safe-image-size

> 标签: avif, bmp, cur, dimensions, gif, heic, heif, height, icns, ico, image, jpeg, jxl, png, psd, resolution, size, svg, tga, tiff, webp, width

## 简介

Security fork of image-size@2.0.2 with the ICNS (CVE-2025-71330) and JXL (CVE-2025-71329) infinite-loop DoS parsers patched. Drop-in replacement to override the vulnerable, unmaintained upstream and clear Checkmarx/SCA findings.
