# suplagentics-mcp-server

> 标签: agents, ai, mcp, memory, model-context-protocol, opencode

## 简介

Standalone MCP server exposing SuplAgentics's real capabilities (Import History, Improvement suggestions, and more over time) to any MCP-capable client — opencode, Claude Code, Claude Desktop — not just one dashboard.
