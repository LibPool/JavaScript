# seaport-data-js

> 标签: codes, country, geography, harbor, logistics, maritime, nga, port, ports, pub150, seaport, seaports, shipping, un-locode, unlocode, world-port-index

## 简介

A comprehensive TypeScript library providing easy retrieval of seaport data based on UN/LOCODE, country codes, harbor characteristics, and facilities. Sourced from the NGA World Port Index. Includes LLM tool definitions for AI integration.
