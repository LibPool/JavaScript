# smsir-sdk

> 标签: nextjs, nodejs, react, sms, sms.ir, smsir, typescript

## 简介

Modern TypeScript/JavaScript SDK for the SMS.ir REST API — works in Node.js, React, Next.js (App & Pages Router, Server Actions, Edge/Node runtimes).
