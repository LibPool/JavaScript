# strapi-plugin-collection-exporter

> 标签: collection, csv, data-export, data-viewer, excel, export, filter, pagination, plugin, search, strapi, strapi-plugin, xlsx

## 简介

Export collection data to CSV and Excel (XLSX) with advanced filtering, search, column selection, and pagination directly from the Strapi admin panel.
