# secure-node-auth

> 标签: auth, authentication, auto-setup, bcrypt, express, fastify, jwt, login, mysql, mysql2, pg, postgres, postgresql, refresh-token, register, security, token, zero-config

## 简介

Blazing fast, zero-config authentication system with JWT for MySQL and PostgreSQL. Set up secure auth in seconds with auto-schema setup and extensible custom fields.
