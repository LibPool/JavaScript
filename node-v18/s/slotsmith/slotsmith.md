# slotsmith

> 标签: accessible, data-table, dropzone, file-upload, headless, react, rtl, slots, table, tanstack, unstyled, uploader

## 简介

A headless React component library: every part is a slot you can replace, with plain-HTML fallbacks. Starting with the data table.
