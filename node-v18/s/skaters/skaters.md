# skaters

> 标签: anomaly-detection, browser, calibration, crps, density, distributional, forecasting, garch, laplace, log-likelihood, microprediction, online, pit, probabilistic, quantile, time-series, zero-dependency

## 简介

Fast univariate online distributional time-series forecasting: a zero-dependency JavaScript port of the Python skaters package, numerically identical to 1e-6.
