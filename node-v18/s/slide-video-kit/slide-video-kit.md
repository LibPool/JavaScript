# slide-video-kit

> 标签: animation, canvas, canvaskit, editor, keyframes, mp4, react, slides, slideshow, timeline, video, webcodecs

## 简介

DSL-driven slide/video engine with a frame-accurate timeline, CanvasKit rendering, React editor components and in-browser MP4 export.
