# stop-ai-slop

> 标签: agent-skill, ai-code, ai-slop, claude-code, code-comments, code-quality, code-review, comment-policy, cursor, git-hooks, linter, mcp, mcp-server, opencode, pre-commit, static-analysis

## 简介

Zero-dependency linter that blocks AI-generated comment slop. Enforces a one-line, why-only comment policy via pre-commit hook, IDE plugin and CI.
