# shuriken-sdk

> 标签: bitcoin-sv, bsv, icp, iframe, metanet, postmessage, sdk, wallet, web3, zk-proof

## 简介

The official SDK for apps on the Metanet social network (metanet.page). One typed, signature-verifying bridge to the parent platform: identity, BSV/ICP/KDA payments, feed posts, ZK proofs, transactions, geolocation, QR. Works in React or any JS/TS project
