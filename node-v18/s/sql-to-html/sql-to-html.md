# sql-to-html

> 标签: JavaScript

## 简介

This package provides a simple utility to convert SQL queries (such as `CREATE TABLE`, `INSERT INTO`, and `SELECT`) into an HTML table format. It takes SQL statements as input and generates an HTML representation of the resulting data.
