# sam-scrollback

> 标签: agents, ai, claude, codex, devin, history, kimi, mcp, qwen, recall, search, session

## 简介

The open-source admin plane for every coding agent — recall past AI conversations across Claude Code, Codex, Devin, OpenCode, Qwen, Gemini, Kimi, Factory, Continue, Copilot CLI, Cursor, Zed and more. Reads local session storage; nothing is uploaded.
