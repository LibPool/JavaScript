# shoutout-libphonenumber-js-utils

> 标签: JavaScript

## 简介

This repo is a compiled and minified version of the utilities functions from the [googlei18n's libphonenumber](https://github.com/googlei18n/libphonenumber) library. The functions are exposed to `window.intlTelInputUtils` inside browser environment.
