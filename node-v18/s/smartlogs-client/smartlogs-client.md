# smartlogs-client

> 标签: apm, express, grafana, logging, monitoring, performance, prometheus, telemetry

## 简介

A Zero-Config monitoring toolkit for Node.js. Auto-tracks routes, CPU, memory, and code bottlenecks via Prometheus and Grafana.
