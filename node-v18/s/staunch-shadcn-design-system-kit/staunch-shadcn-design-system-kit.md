# staunch-shadcn-design-system-kit

> 标签: cli, component-library, design-system, nextjs, scaffold, shadcn, shadcn-ui, tailwind-v4, tailwindcss, theme-editor, vite

## 简介

CLI that scaffolds a full shadcn/ui component set, a token-driven Tailwind v4 theme system, a /design-system showcase page, and a live /theme-editor into a Next.js (App Router) or Vite + React + TypeScript project.
