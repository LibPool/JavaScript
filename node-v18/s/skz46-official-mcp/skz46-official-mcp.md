# skz46-official-mcp

> 标签: mcp, model-context-protocol, sakurazaka46, 櫻坂46

## 简介

Zero-dependency stdio MCP server for Sakurazaka46 (櫻坂46) official-site public data: news, blogs, schedule, formation, discography, MEET&GREET, greeting cards, special pages, goods store.
