# semantic-release-yarn-workspaces

> 标签: JavaScript

## 简介

Plugins for `semantic-release` allowing it to be used with a monorepo, with yarn workspace dependency tracking.

## 官网

- npm 页面：https://www.npmjs.com/package/semantic-release-yarn-workspaces
