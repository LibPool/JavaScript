# safex-webgl

> 标签: 2d, cocos, game, safe-engine, safex

## 简介

**safex-webgl** is a lightweight 2D WebGL game engine written in **TypeScript**, inspired by and partially refactored from the HTML5 implementation of **Cocos2d-x (Cocos2d-JS)**.
