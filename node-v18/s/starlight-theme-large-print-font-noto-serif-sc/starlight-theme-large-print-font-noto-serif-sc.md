# starlight-theme-large-print-font-noto-serif-sc

> 标签: chinese, cjk, font, noto-serif-sc, starlight, starlight-theme

## 简介

Self-hosted Noto Serif SC (Simplified Chinese) font pack for starlight-theme-large-print. Google Fonts unicode-range woff2 subsets served from your own site.
