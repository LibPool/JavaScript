# scratch-up

> 标签: boilerplate, framework, infrastructure

## 简介

Creates code structure with frontend, backend, proxy, database & cache layer. With maintaining focus on ease of development on local & deployment as a container system. Has abstract functions and services for basic functionalities. Written in Typescript.
