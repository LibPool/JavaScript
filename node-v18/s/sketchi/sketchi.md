# sketchi

> 标签: cli, diagram, excalidraw, flowchart, mindmap, sketchi

## 简介

Local Sketchi authoring CLI with offline workflows and four credential-free network commands for generation, Universal Canvas compilation, and encrypted Excalidraw sharing.
