# svg-icon-transformer

> 标签: JavaScript

## 简介

Clean and prepare SVG icons for use; a fork of github.com/floatingdino/Icon-Transformer to fix some yarn and pre-v7 npm issues. Tested with node.js v12.18.4 and node.js v13.14.0, yarn 1.22 and npm 6,7.
