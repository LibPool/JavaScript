# sakura-renderer

> 标签: JavaScript

## 简介

这是一款基于 vue 3 开发的简易前端文本渲染器，由用户提供文章，前端进行渲染。语法简单，文档全面，在编写文章方面基本上不需要html代码。支持多种模板语法，为用户提供一个简单美观的文本渲染器。
