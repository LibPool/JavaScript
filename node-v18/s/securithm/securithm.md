# securithm

> 标签: audit, blockchain, ethereum, securithm, security, smart-contract, smart-contract-audit, smart-contract-security, solana, solidity, web3

## 简介

Securithm SDK + CLI — Ship secure contracts. Scan & auto-fix Solidity from the terminal (securithm scan Contract.sol --fix), or integrate via the typed client.
