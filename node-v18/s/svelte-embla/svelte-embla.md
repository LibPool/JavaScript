# svelte-embla

> 标签: JavaScript

## 简介

Svelte Embla is a Svelte Action Wrapper for [Embla Carousel](https://www.embla-carousel.com/) which allows you to easily integrate any kind of carousel to your heart disires using Embla Carousel in a Svelte project.
