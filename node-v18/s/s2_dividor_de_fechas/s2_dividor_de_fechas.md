# s2_dividor_de_fechas

> 标签: JavaScript

## 简介

Este es un algoritmo que recibe una serie de fechas( Especialmente para usarse en s2_histograma ) y este te lo subdivide en una forma tal que te permite mostrar las fechas de divisiones del histograma de una forma que contenga el diagrama
