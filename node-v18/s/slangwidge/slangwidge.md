# slangwidge

> 标签: BuckleScript

## 简介

A scripting language for NPCs. Built with OCaml/Reason and inspired by [zzt-oop](http://apocalyptech.com/games/zzt/manual/langref.html) from the classic ZZT by Tim Sweeney.
