# seasonly

> 标签: banner, calendar, colombia, custom-elements, holidays, i18n, javascript, latam, no-build, particles, seasonal, shadow-dom, themes, vanilla, web-components, zero-dependencies

## 简介

Tiny, zero-dependency seasonal theming for any website. Date-aware banners and particles with a pluggable calendar system. LATAM-first (Colombia bundled), extensible to any country, religion, or custom calendar. Web Component, browser-native, framework-ag
