# sanity-plugin-time-seconds

> 标签: audio, field, input, playback, sanity, sanity plugin, sanity studio, sanity-plugin, scrubbing, video

## 简介

For entering values in `mm:ss` format, like `03:45` and reflecting them in your sanity model as second numeric values.
