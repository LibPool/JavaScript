# sage-reminder

> 标签: alarm, clock, countdown, deepseek-harness, dsh, plugin, reminder, timer

## 简介

时间提醒（reminder）— DSH 会话头部的时间模块：现在时间 / 距上次发言 / 提醒 / 倒计时。定位是会话内的短期提醒（纯 client 半，数据存浏览器本地）
