# search-sieve

> 标签: coverage, deepseek, dsh, evaluation, harness, plugin, rag, search, tool, web-research

## 简介

SearchSieve — a DeepSeek Harness tool plugin: sifts web search results against the user's question — selection ratio, answer completeness (expectedPoints or auto keywords), representativeness & redundancy — with a switchable pink/blue/white web coverage c
