# sveltekit-grab

> 标签: clipboard, coding-agent, component-inspector, dev-tool, productivity, svelte, svelte-devtools, sveltekit

## 简介

Select Svelte component context directly from your website. Hover any element → press ⌘C/Ctrl+C to instantly copy component name, source file, and HTML. Makes coding agents like Cursor, Claude, Copilot 3× faster and more accurate.
