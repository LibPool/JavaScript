# string-at

> 标签: ES6, ES7, String, at, code point, ecmascript, polyfill, string, unicode

## 简介

A robust & optimized ES3-compatible polyfill for the `String.prototype.at` proposal for ECMAScript 6/7 - based on https://mths.be/at
