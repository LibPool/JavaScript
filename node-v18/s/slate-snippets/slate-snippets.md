# slate-snippets

> 标签: JavaScript

## 简介

This slate extension uses [vscode's snippet parser](https://github.com/microsoft/vscode/blob/main/src/vs/editor/contrib/snippet/snippetParser.ts) to enable user defined snippets in slate.
