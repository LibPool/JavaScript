# stable-deviceid

> 标签: axios, browser-fingerprint, device-fingerprint, device-id, device-identity, fraud-prevention, risk-control, sso

## 简介

跨端一致的现代浏览器设备身份库：结构化稳定设备 ID（生成/校验/自愈）、canvas+WebGL 指纹（默认关闭）、响应头身份同步、SSO 跨 origin 归一、axios 一站式接入
