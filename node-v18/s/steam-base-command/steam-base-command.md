# steam-base-command

> 标签: gamediscovery, gamenews, gameprice, ipublishedfileservice, isthereanydeal, itad, openid, queryfiles, specialsgame, sta, steam, steam-base-command, steam-cli, steam-mod, steam-webapi, steam-workshop, steamid64, steamworks.js, wishlist, workshop-mod, workshop-search

## 简介

Steam Base Command：统一的 sta CLI，覆盖 Steam 登录（OpenID / steamworks.js 静默）、用户资料、游戏与 Mod 详情、Workshop 搜索、新闻、价格（含 ITAD）、发现榜单、心愿单、特价、Workshop Mod 订阅与取消订阅、游戏安装/卸载/商店页与本机扫描。
