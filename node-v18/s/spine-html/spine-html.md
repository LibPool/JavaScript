# spine-html

> 标签: 2d, animation, character-animation, css-transform, dom, mesh-deformation, renderer, skeletal-animation, spine, spine2d

## 简介

Render Spine skeletal animations as plain DOM — rigid slots as <img> posed by CSS matrix, deform meshes on small per-part canvases, interleaved in one stacking context.
