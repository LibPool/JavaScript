# superandom

> 标签: browser, crypto, csprng, drbg, entropy, fortuna, hmac-drbg, random, randomness

## 简介

Browser entropy SDK. Harvests randomness from pointer, keyboard and sensor activity, folds it with the platform CSPRNG, and emits a verifiable audit receipt. Zero network calls.
