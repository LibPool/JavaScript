# seasonify

> 标签: JavaScript

## 简介

seasonify is a command that colors the strings passed to it as arguments or standard input. ## Installation ``` $ npm install seasonify ``` ## Usage Pass some text or pipe it to seasonify, shown as below:   ``` $ seasonify Hello, world! ``` or ``` $ echo
