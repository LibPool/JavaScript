# @jverneuer/beds24-mcp-server

> 标签: ai, beds24, llm, mcp, mcp-server, openapi, schema-validation, sdk, semantic-search, vector-index

## 简介

MCP server + CLI host for Beds24. Depends on beds24-sdk-client (typed API client) and beds24-knowledge (hybrid vector+FTS search). Exposes tools, prompts, and resources for an LLM via @modelcontextprotocol/sdk.
