# @zwodder/plugin-auto-unpack-natives

> 标签: JavaScript

## 简介

Auto Unpack Natives plugin for Electron Forge, automatically adds native node modules to asar.unpacked

- 官网：https://github.com/electron-userland/electron-forge#readme
- 源码仓库：git+https://github.com/electron-userland/electron-forge.git
