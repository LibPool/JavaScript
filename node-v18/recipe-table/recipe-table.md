# recipe-table

> 标签: cooking, cooking-for-engineers, react, recipe, table, tabular-recipe

## 简介

Render recipes as tabular recipes (ingredients are rows, steps are columns) in React. Plain-CSS theming, JSON Schema, agent-friendly.
