# @kaide-labs/osa

> 标签: agents, ai, claude-code, cli, code-generation, codex, copilot, mcp, one-shot, opencode

## 简介

OSA -- One-Shot Anything: a local, headless harness that takes one prompt, locks a baby PRD, and runs a build with an independent reviewer across Claude Code, Codex CLI and Antigravity CLI, driven by CLI or as a local MCP server.
