# @movevom/ai-api-manager-core

> 标签: ai, anthropic, llm, openai, router, sdk, streaming, tool-calling, typescript

## 简介

核心 SDK：定义统一的消息/请求/响应类型，提供路由器 `createAiRouter()`、策略引擎（PolicyEngine）与通用工具（SSE 解析、错误规范等）。
