# @movevom/ai-api-manager-adapters-web

> 标签: adapter, ai, browser, llm, router, typescript, web

## 简介

浏览器侧适配：提供 `fetch` HttpClient、localStorage KeyProvider、localStorage MetricStore，以及基于 WebCrypto 的加密 KeyProvider。
