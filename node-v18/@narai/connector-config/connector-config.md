# @narai/connector-config

> 标签: agent, claude, config, connector, narai

## 简介

Shared configuration loader for @narai/* connectors and the connector-hub. Reads ~/.connectors/config.yaml and ./.connectors/config.yaml, applies environment + consumer overrides.
