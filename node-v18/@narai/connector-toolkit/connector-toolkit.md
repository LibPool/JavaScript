# @narai/connector-toolkit

> 标签: agent, approval-gate, audit, claude, cli, connector, framework, policy-gate

## 简介

Framework for @narai/* agent connectors: createConnector factory, approval gate (kinds + aspects), JSONL audit, hardship logging + curation, CLI harness, and shared security/fetch helpers.
