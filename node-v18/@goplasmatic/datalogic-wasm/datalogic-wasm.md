# @goplasmatic/datalogic-wasm

> 标签: browser, business-rules, expression-engine, feature-flags, flagd, json-logic, json-logic-js, jsonlogic, openfeature, rules-engine, wasm, webassembly

## 简介

JSONLogic (json-logic) rules engine for browsers, edge, Deno, Bun, and Node — Rust core compiled to WebAssembly. A fast alternative to json-logic-js with identical semantics across 8 runtimes; flagd-compatible operators for OpenFeature-style feature flags
