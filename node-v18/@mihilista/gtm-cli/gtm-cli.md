# @mihilista/gtm-cli

> 标签: analytics, cli, ga4, google-tag-manager, gtm, meta-pixel, oauth, tag-manager, tagmanager-api

## 简介

A small CLI for Google Tag Manager: list accounts, audit-dump live container config, and push a GTM export JSON into a real container via the Tag Manager API v2 (OAuth).
