# brandrune

> 标签: branding, claude-code, claude-code-plugin, domains, namelix, naming, rdap

## 简介

Brandrune is a free Claude Code skill for naming what you build: plain-text names, registry-checked domains, real filters. Install it in Claude Code, see the README.
