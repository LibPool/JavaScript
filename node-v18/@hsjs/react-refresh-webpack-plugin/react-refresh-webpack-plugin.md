# @hsjs/react-refresh-webpack-plugin

> 标签: edit, hmr, hot, hotreload, javascript, live, livereload, react, refresh, reload, webpack

## 简介

An **EXPERIMENTAL** Webpack plugin to enable "Fast Refresh" (also previously known as _Hot Reloading_) for React components.
