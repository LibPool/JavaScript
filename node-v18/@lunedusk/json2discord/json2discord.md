# @lunedusk/json2discord

> 标签: builder, components-v2, cv2, discord, discord.js, embed, json, lunedusk

## 简介

JSON → Discord.js Embed and Components V2 builders. Build embeds and CV2 message components from declarative JSON layouts with {{variable}} interpolation.
