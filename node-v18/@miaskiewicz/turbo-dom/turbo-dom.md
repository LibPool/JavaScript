# @miaskiewicz/turbo-dom

> 标签: dom, happy-dom, html, html5ever, jest, jsdom, napi, parser, test-environment, testing, vitest, wasm

## 简介

Faster, more spec-correct DOM for test runners — native html5ever (Rust/WASM) parser + lazy copy-on-write DOM. A drop-in-style alternative to jsdom/happy-dom for vitest & jest.
