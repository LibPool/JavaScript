# @prescriptive/tokens

> 标签: css-variables, design-tokens, dtcg, prescriptive, tailwind, theme

## 简介

Design tokens for Prescriptive — CSS custom properties, a Tailwind v4 preset, theme overlays, and a typed JS export. Generated from the framework's W3C DTCG tokens.
