> 标签: api-server, async-handling, cookie-parser, dependency-injection, global-error-handling, http-server, json-body, kaze, kaze-js, kazejs, middleware, params-validation, query-validation, rest-api, route-grouping, routing, schema-validation, static-files, typescript, validator, web-server

## 简介

A flexible Node.js web framework built with TypeScript, focusing on dependency injection, routing, middleware, and schema validation. Supports dynamic routes, global middleware, static files, and customizable error handling for scalable apps.
