# @ambre-ds/mcp

> 标签: ai, ambre, design-system, llm, mcp, model-context-protocol, web-components

## 简介

The Ambre design system for AI agents: an MCP server that looks up every amb- element, finds the right one for a need, serves complete examples, and validates markup against the component contracts.
