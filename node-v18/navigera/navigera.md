# navigera

> 标签: browser-automation, cdp, chrome, cli, headless

## 简介

Drive headless Chrome from the shell, one command per step: a native Rust CDP CLI for AI agents (accessibility-tree refs, sessions, tabs, iframes, dialogs) plus a JSON-lines serve mode.
