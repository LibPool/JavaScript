# glassy-liquid

> 标签: components, custom-elements, glassmorphism, ios, liquid glass, liquid-glass, react, refraction, svelte, ui, vue, web-components, webgl

## 简介

Apple-style Liquid Glass for the web: real refraction, specular light and fluid iOS 26 controls as framework-agnostic Web Components with React, Vue and Svelte bindings.
