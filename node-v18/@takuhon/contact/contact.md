# @takuhon/contact

> 标签: contact, form, portable, takuhon, turnstile

## 简介

Portable, framework-agnostic contact-form core for takuhon — validation, a stateless inquiry pipeline, and challenge/email transport interfaces. Host wiring (e.g. Cloudflare Turnstile + send_email) lives in the adapters.
