# tabby-better-sidebar

> 标签: better-tabby, bookmarks, connection-manager, connection-status, drag-and-drop, favorites, file-browser, file-manager, file-transfer, ftp, icon-picker, icons, notes, port-forwarding, profile-manager, sftp, sftp-browser, sftp-client, sidebar, snippets, ssh, ssh-tunnel, tabby, tabby-plugin, terminal, transfer-manager, tunneling, workspace, workspaces

## 简介

Enhanced connection sidebar for Tabby: a contextual SFTP browser inside the sidebar itself, pinned favorites, live connection status, active sessions, workspaces, SSH tunnels, drag & drop (including dragging remote files out to the OS), a transfer manager
