# tactual

> 标签: a11y, accessibility, aria, assistive-technology, mcp, mcp-server, model-context-protocol, navigation, playwright, sarif, screen-reader, wcag

## 简介

Screen-reader navigation cost analyzer. Measures how hard it is for AT users to discover, reach, and operate web content.
