# test-pro-scaffold

> 标签: JavaScript

## 简介

该模板提供了路由、菜单、状态、权限、Mock、前后端通信、国际化等领域的完整方案，且内置了丰富的区块，主要用于展示现有区块的分类以及区块组合的效果，使用时需要根据需求进行删除和添加
