# tanstack-query-typed

> 标签: hooks, mutation, mutation-key, query, query-client, query-key, react, react-query, tanstack, tanstack-query, type-safe, typed, typescript

## 简介

A tiny, fully-typed layer over TanStack Query: strongly typed keys, payloads, responses, and a typed QueryClient for queries and mutations.
