# taro-dynamic-subpackage

> 标签: JavaScript

## 简介

一个支持组件和 npm 包按需导入、动态放置分包的 Taro Webpack 插件，帮助优化小程序包体积。

## 官网

- npm 页面：https://www.npmjs.com/package/taro-dynamic-subpackage

## 历史版本号

- 1.0.0

## 获取地址

- npm registry：https://registry.npmjs.org/taro-dynamic-subpackage
