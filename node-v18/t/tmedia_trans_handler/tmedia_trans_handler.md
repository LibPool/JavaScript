# tmedia_trans_handler

> 标签: tmedia, transhandler

## 简介

eosjs 를 확장하여 transaction 결과를 콜백 받는 구현이 있다. eos js 를 사용하는 프로덕트들은 해당 패키지를 사용하여  eos 체인과 통신하는 것을 추천한다.
