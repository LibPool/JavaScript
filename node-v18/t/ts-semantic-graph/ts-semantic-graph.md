# ts-semantic-graph

> 标签: JavaScript

## 简介

Callers, callees, symbol references, and module dependencies for TypeScript projects, resolved through the TypeScript compiler instead of text matching. Comes as a lookup CLI, a query daemon, an MCP server, and an importable library.
