# tenon-naive-iconify-picker

> 标签: icon-picker, iconify, icons, naive-ui, offline, vue, vue3

## 简介

Offline-first icon picker for Vue 3 + Naive UI, powered by Iconify. Browse bundled icon sets offline, inject your own local SVGs, or use any online Iconify icon.
