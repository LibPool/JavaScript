# tuninator

> 标签: audioworklet, chord-detection, guitar, music, onset-detection, pitch-detection, typescript, web-audio

## 简介

UI-free browser library turning guitar microphone input into a streaming musical event recognizer: Notes that start early and are revised as the evidence improves.
