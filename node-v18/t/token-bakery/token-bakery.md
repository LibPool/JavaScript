# token-bakery

> 标签: compression, headless, hygiene, llm, minify, openai, prompt, prompt-watcher, token-saver, tokens

## 简介

Cook the prompt in the box — before it hits the API. Local, zero-dependency, no LLM: live prep highlights, token counts, JSON minify, and secret/PII flags for any textarea.
