# totstype

> 标签: JavaScript

## 简介

- 将 JSON 数据转换为 TypeScript 类型定义。 - 支持嵌套的复杂类型，如数组和对象。 - 支持自定义类型名称和命名空间。 - 支持将转换后的 TypeScript 类型定义保存为文件。
