# ts-node-sdk

> 标签: JavaScript

## 简介

This is an simple SDK for the saas scrapeautomate.com used for automation. Scrapeautomate is an automation tool which allows for you to run an browser and give instructions to the browser to perform, such as fill in input fields, take screenshot etc.
