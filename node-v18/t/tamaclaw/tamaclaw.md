# tamaclaw

> 标签: companion, display, kiosk, mascot, openclaw, openclaw-plugin, tts

## 简介

Companion display for OpenClaw: an animated mascot that speaks, emotes, and shows notifications and dashboards on a small screen. OpenClaw plugin + bridge + display in one package.
