# to-explorer

> 标签: browser, chrome, cli, cross-platform, default-application, explorer, non-blocking, open, profile, shell, start, xdg-open

## 简介

Open files, folders, and URLs with the OS default application (or a configured app/browser) without ever blocking the terminal. Ships a cross-platform CLI plus a programmatic API usable from any language via JSON.
