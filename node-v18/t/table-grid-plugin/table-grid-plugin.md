# table-grid-plugin

> 标签: fixed-column, grid, merge-cell, mobile-card, table, tree-table, typescript, virtual-scroll, vue, vue3, xdatagrid

## 简介

开箱即用的 Vue3 高性能数据表格组件。纯 div + 虚拟滚动实现，支持百万级数据流畅渲染、树形、固定列与表头、多级表头、选择、自定义列模板与插槽、单元格合并、展开行与移动端卡片模式。渲染层统一 TSX，运行时零依赖。
