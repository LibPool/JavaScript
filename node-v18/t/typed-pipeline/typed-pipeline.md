# typed-pipeline

> 标签: async, chain, compose, concurrency, flow, functional, inference, pipe, pipeline, retry, timeout, type-safe, typed, typescript, workflow

## 简介

Type-safe TypeScript pipelines with inferred steps, saveAs snapshots, retries, parallel fan-out, and async timeouts.
