# trello-mcp-complete

> 标签: api, checklist, kanban, mcp, mcp-server, trello

## 简介

A complete Model Context Protocol (MCP) server for Trello. Integrates Boards, Lists, Cards, Labels, Checklists, Organizations, Members, Search, and Notifications.
