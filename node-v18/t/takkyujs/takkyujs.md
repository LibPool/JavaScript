# takkyujs

> 标签: delivery, japan, japanpost, kuroneko, kuroneko-yamato, sagawa, tracking, yamato

## 简介

日本の配送追跡サービス用の非公式ライブラリです。各配送会社の追跡情報を取得できます。

- 官网：https://github.com/nananankona/TakkyuJS#readme
- 源码仓库：git+https://github.com/nananankona/takkyujs.git
- npm 页面：https://www.npmjs.com/package/takkyujs
