# tutorialsmith

> 标签: agent, cli, deepseek, documentation, llm, markdown, tutorial

## 简介

教程匠（TutorialSmith）：基于项目生成技术教程的 Agent。扫描项目 → 写作前复现 → 生成大纲 → 逐章撰写 → 质量审查，多 LLM 可分工（默认 DeepSeek），零依赖
