# telegram-send-mcp

> 标签: ai, bot, mcp, model-context-protocol, notification, telegram

## 简介

MCP server for Telegram Bot API: send text/photo, edit and delete messages. Multi-bot, multi-group, purpose-based targeting baked into config.
