# tracegist-relay

> 标签: live-session, relay, tracegist, websocket

## 简介

Relay server for TraceGist Remote Live Sessions. Pairs a tester's browser extension with a developer's MCP bridge and forwards end-to-end encrypted frames — the relay never sees plaintext.
