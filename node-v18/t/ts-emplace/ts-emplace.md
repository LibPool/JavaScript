# ts-emplace

> 标签: Map, WeakMap, emplace, polyfill, upsert

## 简介

This package includes the [core-js](https://github.com/zloirock/core-js) polyfill for `Map#emplace` and `WeakMap#emplace`, along with TypeScript typings.
