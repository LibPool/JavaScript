# ts-summarizer

> 标签: extractive, frequency-based summarization, natural language processing, nlp, sentence ranking, summarization, text summarizer, text-analysis, textrank, tf-idf, typescript

## 简介

A lightweight, zero-dependency NLP summarization package built with TypeScript. Inspired by traditional NLP techniques like those in Python's NLTK — but without any API or AI calls.
