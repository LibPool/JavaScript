# trustagent-mcp

> 标签: agent, base, claude, erc-8004, mcp, model-context-protocol, ofac, sanctions-screening, web3, x402

## 简介

MCP server for counterparty verification: OFAC sanctions screening, sybil-filtered ERC-8004 reputation, and contract bytecode analysis. Three tools work with no wallet and no signup.
