# toolport-openapi-mcp

> 标签: ai-tools, api, mcp, model-context-protocol, openapi, rest, swagger, toolport

## 简介

Turn any OpenAPI/Swagger spec into an MCP server: one tool per endpoint. A showcase for Toolport (toolport.app).
