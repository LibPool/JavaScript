# teacher-sab

> 标签: SKILL.md, agent-skills, claude-code, codex, cursor, learning, opencode, retrieval-practice, skills, spaced-repetition, teaching

## 简介

A teaching system that works in any AI harness - opencode, Claude Code, Codex, Cursor, pi, plain chat. The teach skill reads the learner's profile every session, probes before explaining, and spaces review across sessions. Pedagogy by amosblomqvist/learn
