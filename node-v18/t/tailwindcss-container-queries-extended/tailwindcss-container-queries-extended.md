# tailwindcss-container-queries-extended

> 标签: JavaScript

## 简介

> [!NOTE] > As of Tailwind CSS v4.0, container queries are supported in the framework by default and this plugin is no longer required. >  > You should only used this if you are using TailwindCSS v3.2+ and need to use max-width container queries.
