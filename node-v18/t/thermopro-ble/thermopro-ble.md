# thermopro-ble

> 标签: ble, bluetooth, bluetooth-le, bluez, dbus, home-automation, humidity, iot, sensor, temperature, thermopro, tp350s, tp357, tp358, tp359

## 简介

Read temperature and humidity from ThermoPro TP350S / TP35x Bluetooth LE sensors on Linux (BlueZ over D-Bus, no native build, no root)
