# translator-sync

> 标签: ai, automated-translation, i18n, i18n-cli, i18n-workflow, i18next, localization, localization-tool, nextjs, openai, react, react-i18n, react-translation, translation, translation-automation, translation-cli, translation-sync, vue, vue-i18n, vue-translation

## 简介

Automate React/Vue i18n translation workflow with AI. Sync translation files automatically, reduce costs 50,000x vs services. Works with react-i18next, vue-i18n, JSON, Fluent.
