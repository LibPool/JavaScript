# tacet-element

> 标签: custom-elements, icon-set, icons, svg, web-components

## 简介

Tacet icon set as custom elements: <tacet-icon>, <tacet-digits>, <tacet-text>, <tacet-text-field> and <tacet-digits-field> for any stack without React. 454 outline glyphs with self-drawing animation.
