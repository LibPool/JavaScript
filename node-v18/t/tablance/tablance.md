# tablance

> 标签: data, interactive, large, spreadsheet, table

## 简介

A library used for creating highly interactive tables that can handle large amounts of data and which spreadsheet-capabilities, meaning cells can be marked as editable. Also, rows can be expanded if needed, revealing more data can be structured with compo
