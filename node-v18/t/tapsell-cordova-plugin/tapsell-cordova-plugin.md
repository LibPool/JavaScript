# tapsell-cordova-plugin

> 标签: ad, cordova, cordova-android, ecosystem:cordova, monetisation, plugin, tapsell

## 简介

Ultimate Cordova Plugin for Tapsell to monetize hybrid apps. Show mobile Ad with single line of JavaScript. Compatible with Cordova CLI, PhoneGap Build, Ionic, etc.
