# transcriptfetch-mcp

> 标签: ai, ai-agents, captions, claude, cursor, instagram, llm, mcp, mcp-server, model-context-protocol, speech-to-text, tiktok, transcript, transcription, youtube, youtube-transcript

## 简介

Model Context Protocol (MCP) server for TranscriptFetch, a production transcript API: give Claude, Cursor, or any MCP client transcripts from YouTube, TikTok, Instagram and media URLs, with automatic AI transcription when captions don't exist - plus video
