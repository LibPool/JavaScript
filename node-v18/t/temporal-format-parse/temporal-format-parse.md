# temporal-format-parse

> 标签: date, date-fns, date-formatting, date-parsing, datetime, dayjs, format, iso8601, luxon, moment, nanosecond, parse, strftime, tc39, temporal, temporal-api, time, timezone, token

## 简介

Token-based format and numeric parse for TC39 Temporal — format(value, "yyyy-MM-dd") and parse("07/13/2026", "MM/dd/yyyy", "PlainDate") directly on Temporal values, no JS Date round-trip. Zero runtime dependencies; works on native Temporal or any polyfill
