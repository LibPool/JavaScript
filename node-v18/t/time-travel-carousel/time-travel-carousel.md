# time-travel-carousel

> 标签: accessibility, carousel, document-viewer, file-preview, gallery, headless, image-viewer, lightbox, media-preview, modal, pdf-viewer, react, react-component, revisions, typescript, unstyled, version-history, zero-dependency

## 简介

A React carousel where every slide has a version history. Images, video and PDFs; left/right between items, up/down through their revisions. Zero runtime dependencies, stylable from plain CSS.
