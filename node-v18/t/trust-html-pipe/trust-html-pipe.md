# trust-html-pipe

> 标签: angular, angular2, html, inject, pipe, trust, trust-html, trust-html-pipe, trustHtml, trustHtmlPipe

## 简介

Pipe for angular2+ projects which allows you to inject non-escaped HTML content into your templates.
