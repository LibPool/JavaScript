# turkey-data-mcp

> 标签: ai-tools, claude, earthquakes, exchange-rates, fuel-prices, gold-prices, kandilli, llm, mcp, model-context-protocol, prayer-times, tcmb, turkey, turkiye

## 简介

MCP server for live Turkey data: gold & silver prices, TCMB exchange rates, fuel prices, prayer times, and Kandilli earthquake feed — powered by the free turkpidya.com public API.
