# tenantguard-win32-x64

> 标签: JavaScript

## 简介

Prebuilt tenantguard binary for win32/x64 (Windows on Intel/AMD). Installed automatically as an optional dependency of the tenantguard-cli npm package; not meant to be installed directly.
