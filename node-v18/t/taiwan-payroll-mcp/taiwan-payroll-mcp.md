# taiwan-payroll-mcp

> 标签: mcp, model-context-protocol, payroll, taiwan, 健保, 勞保, 勞退, 台灣, 薪資

## 简介

台灣勞健保勞退計算 MCP server — 勞保、健保、勞退、補充保費、薪資扣繳、老年給付；支援 npx (stdio) 與遠端 Streamable HTTP。
