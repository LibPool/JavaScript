# tailfill

> 标签: css, extended, polyfill, postcss, selector, selectors, style, styles, styling, tailwind, tailwindcss

## 简介

An exhaustive polyfill plugin for Tailwind CSS, filling in the gaps for properties not (yet) supported in core Tailwind CSS Core.
