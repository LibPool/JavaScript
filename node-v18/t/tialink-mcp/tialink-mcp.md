# tialink-mcp

> 标签: bridge, industrial-automation, mcp, mcp-gateway, mcp-server, model-context-protocol, openness, plc, scl, siemens, tia-portal

## 简介

stdio to Streamable HTTP bridge for TiaLink, the TIA Portal MCP gateway by 汇智网 (hubwiz.com). Lets clients that only speak stdio drive a TiaLink gateway.

## 官网

- 官网：https://tia.hubwiz.com/tia-link
- 源码仓库：git+https://github.com/tia-forge/tialink.git
