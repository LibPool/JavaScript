# token-shrinker

> 标签: ai, ai-tools, anthropic, claude, compression, context, context-compression, cursor, llm, mcp, model-context-protocol, openai, optimization, summarization, token, token-reduction, tokens

## 简介

Model Context Protocol (MCP) server for compressing AI context to reduce token usage. Provides tools to shrink text, summarize files, and cache repository content.
