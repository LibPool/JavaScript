# tabby-quick-scripts-chenlei

> 标签: tabby-plugin

## 简介

Display shortcut script buttons above the terminal. Clicking a button executes the preset commands sequentially.在终端上方显示快捷脚本按钮，点击即可按顺序执行预设命令
