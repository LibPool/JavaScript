# thailang

> 标签: compiler, programming-language, thai, thailang, typescript-like, wasm

## 简介

ภาษาโปรแกรมมิงไทย — Thai-first programming language. Compiles to JS; ships as a Node-only CLI (no Rust toolchain needed at install time).
