# tagparse

> 标签: ast, bot, chat-bot, discord, discord-bot, discord-template, discord-templating, discord.js, embed-template, handlebars-alternative, interpolation, lexer, message-template, mustache, mustache-alternative, parser, placeholder, slack-bot, string-interpolation, string-template, tag-parser, template, template-engine, templating, tokenizer, typescript

## 简介

AST-first templating library for Discord and chat bots. Parse {variable}, {if:cond|then|else}, {each:items|template} placeholder syntax with safe rendering helpers.
