# tracelane

> 标签: apm, canvas, causal-tree, data-visualization, dataviz, distributed-tracing, flamegraph, framework-agnostic, gantt, observability, opentelemetry, otel, span-waterfall, timeline, timeline-visualization, trace, trace-viewer, tracing, typescript, virtualization, waterfall, zero-dependency

## 简介

Zero-dependency TypeScript Canvas library for full-link trace and user-behavior waterfalls: zoomable time axis, causal tree, sibling folding, virtualized rows.
