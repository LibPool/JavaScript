# ts-leaky-bucket

> 标签: JavaScript

## 简介

Port of [leaky-bucket](https://github.com/linaGirl/leaky-bucket) to Typescript.  Original package was using experimental modules which required a runtime flag and also didn't have nice Typescript types.
