# tfs-mcp

> 标签: JavaScript

## 简介

TFS MCP 服务器是一个基于 Node.js 的工具，用于连接 TFS (Team Foundation Server) 系统，查询工作任务和代码权限。它实现了 MCP (Model Context Protocol) 协议，为客户端提供了一系列与 TFS 交互的功能。
