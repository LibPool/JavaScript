# tbl-ai-code-review

> 标签: ai-review, code-review, copilot, coverage, jacoco, java, review, slash-command, vscode

## 简介

Reusable AI code-review workflow for Java repos — installs the .ai-review package and a /review slash command for VS Code Copilot Chat (context → review skills → impact analysis → unit tests → JaCoCo coverage gate → Vietnamese report)
