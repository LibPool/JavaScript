# toolkit-react-cli

> 标签: axios, boilerplate, cli, command-line, create-react-app, frontend, generator, javascript, npx, react, react-router-dom, scaffold, tailwind, toolkit, utilities, vite

## 简介

A CLI tool to quickly generate React projects with Vite, Tailwind CSS, axios, react-router-dom and utilities. Use with 'npx toolkit-react-cli project-name'.
