# threat-guardian

> 标签: audit, cli, corporate, env-leak, frozen-lockfile, guardian, install-scripts, lockfile, malware, npm, obfuscation, pnpm, security, seguridad, supply-chain, threat-detection, typosquatting, yarn

## 简介

Sistema de seguridad corporativo para npm: análisis profundo de amenazas, instalación con lockfile congelado, detección de typosquatting, ofuscación y filtración de variables de entorno.
