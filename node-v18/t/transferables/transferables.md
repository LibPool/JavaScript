# transferables

> 标签: arraybuffer, float32array, float64array, int16array, int32array, int8array, messagechannel, messageport, readablestream, streams, structuredClone, transferable, transferable-objects, transformstream, typescript, uint16array, uint32array, uint8array, uint8clampedarray, webworker, worker, writablestream

## 简介

Utility library that lists out all transferable objects that can be transfered between Workers and the main thread.
