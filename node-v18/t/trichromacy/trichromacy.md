# trichromacy

> 标签: anomalous-trichromacy, color-vision, colorblind, cvd, deuteranomaly, protanomaly, simulate, trichromacy, tritanomaly

## 简介

Normal (three-cone) color vision and anomalous trichromacy (protanomaly/deuteranomaly/tritanomaly) — the mild, partial deficiency. Built on cvdsim / the OpticQuiz engine.
