# tasra-sdk

> 标签: access-control, agent-skills, bls, bls12-381, credentials, dcql, encryption, ethereum, frost, keykeeper, oid4vp, revocation, sd-jwt, skills, threshold-cryptography, threshold-signatures

## 简介

Product-agnostic TypeScript access gate to a Tasra Network: a managed client (sessions with auto-renewing JWTs + encrypt/decrypt/sign) over composable threshold-crypto primitives — shard fetch + MSK assembly, DCQL-gated JWTs, FROST/ECDSA signing, BLS encr
