# trickle-sdk

> 标签: celo, celo-blockchain, cusd, minipay, payroll, stablecoin, streaming, trickle, viem, web3

## 简介

TypeScript SDK for Trickle — real-time payroll streaming on Celo (TrickleVault + StreamRegistry). Addresses, ABIs, and helpers for building MiniPay-native payroll dApps.
