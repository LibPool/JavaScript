# trello-to-markdown-table

> 标签: markdown

## 简介

Small library that connects to a trello board, downloads all the cards and  places them in markdown table

## 官网

- npm 页面：https://www.npmjs.com/package/trello-to-markdown-table

- npm registry：https://registry.npmjs.org/trello-to-markdown-table
- Node 要求：>= 8.0.0
