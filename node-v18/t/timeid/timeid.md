# timeid

> 标签: JavaScript

## 简介

此库用来创建一个 App 生命周期内不重复的 id，在单应用内，而非集群中，我们有时候需要简单快速生成唯一的 key； 如 React 对象的 key，生成 key 的行为会非常频繁，我们需要比 uuid 和 nanoid 更高的性能，才能满足 UI 的条件
