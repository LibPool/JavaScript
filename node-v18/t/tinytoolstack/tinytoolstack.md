# tinytoolstack

> 标签: base64, cli, hash, json, jwt, slugify, tools, url-encode, uuid

## 简介

Tinytoolstack developer tools as a CLI and library — slugify, base64, hashes, JSON formatting, JWT decoding, UUIDs, text stats, URL encoding, dice.
