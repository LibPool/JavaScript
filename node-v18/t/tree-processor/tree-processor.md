# tree-processor

> 标签: array, at, deduplicate, depth, every, filter, find, indexOf, map, menu, navigation, pop, push, shift, some, tree, tree-processor, unshift

## 简介

Lightweight tree-structured data processing library with 50+ APIs (traversal, search, modification, conversion, query, analysis, validation). Supports ESM/CJS/UMD, tree-shaking, zero dependencies
