# tailwind-angular-material-theme

> 标签: angular, angular-material, tailwind, tailwindcss, theme

## 简介

Este paquete expone todas las variables y tokens de Angular Material como utilidades que puedes usar en tu tema de Tailwind CSS. Ideal para aplicar los estilos de Angular Material sin redefinir colores, tipografías ni espacios manualmente.
