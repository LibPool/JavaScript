# trialslayer

> 标签: abuse-detection, device-fingerprint, disposable-email, fraud-prevention, free-trial, saas, trial-abuse

## 简介

Catch free-trial abuse in one server-side call — disposable/relay email, reused devices, alias reuse — returns allow or restrict.
