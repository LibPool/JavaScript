# trpg-dice

> 标签: d&d, d20, dice, dragons, dungeons, fate, keep, roll, rpg, tabletop, trpg

## 简介

Tabletop RPG dice-roller with a multiple dice-types, rolling methods, minimum and maximum values, string output, and error-first callbacks.
