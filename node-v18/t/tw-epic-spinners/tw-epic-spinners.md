# tw-epic-spinners

> 标签: astro, css-animation, css-spinner, epic-spinners, frontend, loader, loading, loading-indicator, loading-spinner, nextjs, no-js, nuxt, plugin, pure-css, react, spinner, spinners, svelte, tailwind, tailwind-plugin, tailwindcss, tailwindcss-plugin, tailwindcss-v3, tailwindcss-v4, tw-epic-spinners, ui, vue

## 简介

20 pure-CSS loading spinners as a Tailwind CSS plugin (v3 & v4). Zero JS, framework-agnostic — works with Vue, React, Svelte, Astro, Next.js, Nuxt, or plain HTML. A Tailwind port of Epic Spinners by EpicMax.
