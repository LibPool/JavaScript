# tacet-core

> 标签: animated-icons, icon-set, icons, svg

## 简介

Data and engine of the Tacet icon set: 454 outline glyphs where the cut is data — icons, digits and capitals that draw themselves — plus per-glyph guidance for AI agents. No dependencies.
