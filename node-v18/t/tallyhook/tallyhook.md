# tallyhook

> 标签: agent, ai, ai-cost-tracking, claude-code, cli, codex, cost, llm, mcp, model-context-protocol, token-usage, tokens, usage

## 简介

Reads the session logs Claude Code and Codex CLI already write on your machine and works out what they cost. Per repo, per model, per session. Includes an MCP server. Zero dependencies.
