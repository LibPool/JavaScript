# thunderkit

> 标签: agent-skills, ai-agents, claude-code, codex, context-engineering, cursor, hermes, monorepo, multi-model, opencode, parallel, skills

## 简介

Opinionated Agent Skills for shipping big changes in big repos — decompose into parallel lanes, route each to the best model across a heterogeneous fleet (Claude, Codex, Bedrock), review cross-family, ship on evidence.
