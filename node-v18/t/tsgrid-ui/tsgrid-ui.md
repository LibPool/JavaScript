# tsgrid-ui

> 标签: components, datagrid, esm, form, grid, layout, popup, sidebar, tabs, toolbar, tooltip, typescript, ui

## 简介

TypeScript-native UI components: data grid, forms, fields, layout, sidebar, tabs, toolbar, popup, tooltip. ESM + CJS dual bundle, .d.ts rollup, zero runtime dependencies.
