# temp-require

> 标签: dynamic, npm, require, temp

## 简介

A utility for Node.js to require npm packages dynamically. If the package is not found, it is installed in a temporary directory and then required.

## 官网

- npm 页面：https://www.npmjs.com/package/temp-require
