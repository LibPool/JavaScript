# tabs-broadcast

> 标签: broadcast, broadcastchannel, communication, cross-tab, eventemitter, events, leader-election, micro-frontend, multi-tab, primary-tab, pubsub, tab-sync, tabs, typescript, web-locks

## 简介

Tiny zero-dependency TypeScript library for inter-tab communication over the BroadcastChannel API, with primary-tab (leader) election via Web Locks.
