# tiny-patch

> 标签: diff, json, jsondiff, jsonpatch, patch, rfc6902

## 简介

Implementation of JSONPatch (RFC6902) with diff and patch support, optimized for performance in a JS environment, with support for a minified output to reduce bandwidth
