# tsgf-sdk-miniapp

> 标签: connection, game, network, online, sync, ts

## 简介

ts-gameframework(TSGF) client sdk for use in miniapp. TSGF is An open source platform that supports frame synchronization online. Select the corresponding SDK, such as tsgf-sdk-browser or tsgf-sdk-miniapp, based on your platform.
