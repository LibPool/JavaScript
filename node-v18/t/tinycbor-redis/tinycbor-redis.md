# tinycbor-redis

> 标签: addon, cbor, tinycbor

## 简介

An expansion of node-tinycbor which provides access to select Redis commands with internal CBOR encoding/decoding

## 官网

- 源码仓库：https://gitlab.com/controlenvy/lib/node-tinycbor.git
- npm 页面：https://www.npmjs.com/package/tinycbor-redis
