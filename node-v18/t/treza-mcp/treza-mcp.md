# treza-mcp

> 标签: ai-video, mcp, model-context-protocol, pipelines, tiktok, treza, youtube

## 简介

Treza MCP server: build, run, schedule, and publish AI video pipelines. Runs as a stdio bridge to the hosted Treza endpoint.
