# ts-tableau

> 标签: html, markdown, pandoc, preprocessor, quarto, remark, table, table-layout, tables, typescript, unified

## 简介

A library that simplifies table layout by separating data from layout, for use as a preprocessor for Markdown and similar markup languages.
