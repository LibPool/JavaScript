# three.js-3d

> 标签: JavaScript

## 简介

基于three.js的组件库 实现了组件化创建三维模型 ## 安装 ``` npm install three.js-3d ``` ## main.js 中引入 ``` import Vue from 'vue' import App from './App.vue' import Three3d from 'three.js-3d' import 'three.js-3d/three.js-3d.css'
