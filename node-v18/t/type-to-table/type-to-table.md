# type-to-table

> 标签: codegen, docgen, docs, interface, jsdoc, markdown, options-table, props-table, react, react-docgen-typescript, readme, type-to-table, typescript

## 简介

Turns a TypeScript type's JSDoc into a markdown table so your docs never fall out of sync with the code. React props tables via the type-to-table/react subpath.
