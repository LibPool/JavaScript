# tetris-toolkit

> 标签: canvas, deterministic, engine, game, guideline, replay, srs, tetris, tetromino

## 简介

Headless, deterministic, Guideline-compliant Tetris game engine with replay, events, and serialization. Pure TypeScript with zero framework dependencies.
