> 标签: 2d, browser-game, canvas, game-development, game-engine, gamedev, html5-game, mobile, mobile-first, pwa, touch, typescript, webgl-free, zero-dependencies

## 简介

A mobile-first, browser-based 2D game engine built with TypeScript. Zero external runtime dependencies, pure Web APIs.
