# tspace-mysql

> 标签: ORM, backup, blueprint, cli, commit, database, deeply nested relations, migrate, model, mysql, mysql2, object relation model, orm, query builder, relations, repository, rollback, transaction, tspace, tspace-mysql, tspaceMysql, type safety, typescript

## 简介

Tspace MySQL is a promise-based ORM for Node.js, designed with modern TypeScript and providing type safety for schema databases.
