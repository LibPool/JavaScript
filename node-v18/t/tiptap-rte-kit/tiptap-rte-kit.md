# tiptap-rte-kit

> 标签: editor, heroui, react, rich-text-editor, rte, tiptap

## 简介

A batteries-included Tiptap rich text editor + read-only renderer + toolbar, built on @heroui/react. Extracted from Bridgeto so it can be reused across projects.
