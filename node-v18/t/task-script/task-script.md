# task-script

> 标签: build, gradle, gradle-like, groovy, groovy-like, json, json-script, script, task, task-script

## 简介

Groovy-like Launguage base on nodeJS.Arrange core logic as part of json field.Support dynamic action-wrapped statements appart from static parameters.Single action-task can be included by other action-task,support complicated task by building a task-tree.
