# tls-sentinel

> 标签: certificate, cipher, cli, expiry, github-action, https, monitoring, sarif, security, ssl, ssl-checker, tls, tls1.3, x509

## 简介

TLS endpoint checker: certificate expiry, hostname mismatch, untrusted or incomplete chains, self-signed certs, weak keys and signatures, TLS 1.0/1.1 and weak ciphers, missing TLS 1.3, long-lived certs. Uses Node's TLS stack, no OpenSSL binary needed. CLI
