# toneperfect-mcp

> 标签: claude, cursor, language-learning, mandarin, mcp, mcp-server, model-context-protocol, pronunciation, pronunciation-assessment, speech, tones

## 简介

MCP server for the TonePerfect pronunciation assessment API, 10 languages: sentence, word and sound scores for a recording of a known text.
