# transcribe-cli

> 标签: audio, cli, diarization, faster-whisper, live-audio, local, offline, speech-to-text, streaming, transcription, video, whisper

## 简介

Local audio/video transcription with speaker diarization and live audio support. No API keys. Powered by faster-whisper.
