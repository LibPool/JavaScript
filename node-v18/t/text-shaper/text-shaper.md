# text-shaper

> 标签: arabic, bidi, font, freetype, glyph, harfbuzz, hinting, indic, lcd-rendering, opentype, rasterizer, shaping, text, texture-atlas, truetype, typography, variable-fonts

## 简介

TypeScript-first text shaping engine with OpenType layout, TrueType hinting, and selectable FreeType-style or libass-style rasterization
