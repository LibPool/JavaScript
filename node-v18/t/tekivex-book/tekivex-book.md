# tekivex-book

> 标签: JavaScript

## 简介

Component playground for tekivex-ui. Pure Vite + React. Tabbed addons: Controls, Docs (MDX), A11y (axe-core), Viewport (device frames), Snapshot (visual diff), Interactions (record/replay). CSF-compatible.

- npm 页面：https://www.npmjs.com/package/tekivex-book
