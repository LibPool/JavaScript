> 标签: agents, ai-graveyard, ai-tool-directory, ai-tools, claude, mcp, mcp-server, model-context-protocol

## 简介

MCP server for the AI Tool Directory — search 2,000+ AI tools, compare them, find alternatives, and check whether a tool is still active, defunct, or acquired.
