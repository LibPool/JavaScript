# tirelesscoding

> 标签: agents, ai, claude, claude-code, codex, coding-agent, git-worktree, mcp, openai, openrouter, orchestration, parallel, tirelesscoding, tirelesscrew

## 简介

TirelessCoding: run several AI coding agents on one project at once, each in its own git worktree, and merge only what passes your tests. Claude Code, Codex, Anthropic/OpenAI APIs, OpenRouter, custom providers; web UI and MCP server.
