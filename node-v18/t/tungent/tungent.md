# tungent

> 标签: agents, expose, https, localhost, ngrok, ssh, tunnel, webhooks, wireguard

## 简介

The tunnel that doesn't rot, built for agents: a public HTTPS hostname for a local port, over ssh or WireGuard. Zero dependencies.
