# timeline-lens

> 标签: animation, css-animations, debugger, devtools, gsap, motion, web-animations-api

## 简介

Read-only, in-browser visual debugger for GSAP, Motion, CSS animations/transitions, and the Web Animations API. Not affiliated with GreenSock/GSAP or Motion. Mounts a dev-only panel that detects whichever of these engines a page is already using and shows
