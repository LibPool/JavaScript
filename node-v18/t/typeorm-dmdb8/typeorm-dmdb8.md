# typeorm-dmdb8

> 标签: JavaScript

## 简介

Data-Mapper ORM for TypeScript, ES7, ES6, ES5. Supports MySQL, PostgreSQL, MariaDB, Dmdb, SQLite, MS SQL Server, Oracle, MongoDB databases.
