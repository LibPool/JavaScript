# truffle-declarative

> 标签: Truffle, declarative, errors, exec, fault, network, playback, script, tolerant, yaml

## 简介

Run complex playbooks of blockchain scripts using simple declarative syntax. Records entire result including failed tests for easy retry of only failed methods.
