# tekivex-3d

> 标签: 3d, card-3d, holographic, interactive, logo-3d, model-viewer, particle-field, react, tekivex, three, threejs, tilt, webgl

## 简介

True WebGL 3D components for tekivex-ui — TkxScene, TkxCard3D, TkxLogo3D, TkxModel, TkxOrbitView. Vanilla three.js peer dep, no React reconciler. Theme-aware lighting + tone mapping.
