# tweakit

> 标签: color-picker, controls, dat.gui, debug, gui, leva, oklch, panel, parameters, tweakpane, wide-gamut

## 简介

A dependency-free, code-split real-time parameter panel — sliders, toggles, a wide-gamut OKLCH colour picker, curve editors and more, from a plain schema.
