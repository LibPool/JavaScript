# tildify-commonjs

> 标签: backend, bash, collapse, commonjs, convert, directory, expand, expansion, home, homedir, path, shell, tilde, tildify, unexpand, user

## 简介

Convert an absolute path to a tilde path: `/Users/YourUserName/dev` → `~/dev`
