# tracking-manager

> 标签: google-analytics, track-event, track-page-view, tracking, tracking-manager

## 简介

Tracking Manager allows to manage all your Google Analytics events directly in HTML or Javascript with a simple and extensible configuration and public functions to track events with dynamic variables
