# ts-leaflet-canvas-grid

> 标签: JavaScript

## 简介

Leaflet plugin to Show grid scalar or vectorial data on a map. This project is a fork and a typescript translation from https://github.com/IHCantabria/Leaflet.CanvasLayer.Field
