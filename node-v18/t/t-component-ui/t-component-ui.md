# t-component-ui

> 标签: JavaScript

## 简介

### TComponent是什么 TComponent的中文名称是泛型组件，灵感来自于编程概念中的泛型，致力于使用通用方式编写组件，满足同个需求在多端上有不同UI表现。 它基于开源的Vue组件框架：ElementUI,Vant作为底层进行封装实现。
