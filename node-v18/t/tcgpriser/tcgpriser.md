# tcgpriser

> 标签: pokemon, pokemon-tcg, price-api, tcg, tcgpriser, trading-card-game

## 简介

Typed Node.js/browser client for the tcgpriser.se API: Pokémon TCG price data, catalog, shop matches and bargains.

## 官网

- 官网：https://tcgpriser.se
- 源码仓库：git+https://github.com/SebbeJohansson/tcgpriser-js.git
- npm 页面：https://www.npmjs.com/package/tcgpriser
