# total-recall-memory

> 标签: ai, claude, claude-code, codex, cross-session, knowledge, llm, memory, multi-machine, persistence, qdrant, semantic-search, sessions

## 简介

Persistent cross-session memory for Claude Code and Codex. Automatically stores decisions, patterns, and lessons learned with Qdrant hybrid retrieval so every session starts with full context. Supports multi-machine sharing via HTTP server with web UI.
