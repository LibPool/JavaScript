# tiger-js-mcp

> 标签: ai-agent, mcp, model-context-protocol, tiger

## 简介

An MCP server for Tiger apps: tiger_check and tiger_map as live tools any MCP-compatible AI agent can call, no shell required. Same engine as tiger-js-cli.
