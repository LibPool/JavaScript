# t7-react-kendo

> 标签: components, kendo, kendo-ui, react, react-component, react.js, telerik, widgets

## 简介

Updated to use external ReactDOM. React Component Library for Kendo UI Widgets. There exists a React Component named for every Kendo widget in the kendo.ui namespace. Tested on React 0.12 and KendoUI 2014.3.1411.
