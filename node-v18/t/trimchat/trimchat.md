# trimchat

> 标签: ai-sdk, anthropic, chat, chat-history, claude, context-window, conversation, llm, memory, openai, prompt, token, token-budget, tokens, trim, truncate

## 简介

Trim chat history to fit a token budget without breaking it. Drops the oldest turns first, keeps system prompts and tool call/result pairs together, and works with OpenAI, Anthropic and Vercel AI SDK messages. Zero dependencies.
