# tgtrack-mcp

> 标签: analytics, claude, mcp, mcp-server, model-context-protocol, otkuda-podpiski, telegram, tgtrack

## 简介

MCP-сервер для управления tgtrack / «Откуда Подписки»: панель settings.tgtrack.ru (каналы, интеграции, скрипт-настройки, цели, ссылки — JWT + подпись H=md5(md5(JSON+T)+T)) и Bot API bot-api.tgtrack.ru (события старта/стопа, глубокие цели, add_event, get_u
