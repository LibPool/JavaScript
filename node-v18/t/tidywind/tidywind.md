# tidywind

> 标签: class-names, cli, clsx, code-formatter, css, formatter, jsx, react, tailwind, tailwindcss, typescript, utility-first

## 简介

Global CLI tool to format and group Tailwind CSS classes in React components with support for join() and clsx()
