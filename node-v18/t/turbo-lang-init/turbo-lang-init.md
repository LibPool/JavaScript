# turbo-lang-init

> 标签: JavaScript

## 简介

Turbo Lang Init is a CLI tool to initialize multi-/multi-framework projects in a Turborepo environment. It supports JavaScript, TypeScript, Rust, Solidity, Next.js, React, and their TypeScript variants.
