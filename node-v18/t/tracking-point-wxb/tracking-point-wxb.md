# tracking-point-wxb

> 标签: analytics, directive, page-view, pv, track, tracking, vite, vue3, 埋点

## 简介

Vue3 + Vite 系统埋点自定义指令库：支持点击埋点、页面浏览(PV)与停留时长自动追踪，可打包发布为 npm 依赖。
