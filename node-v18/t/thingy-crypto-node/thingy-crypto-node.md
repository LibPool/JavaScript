# thingy-crypto-node

> 标签: crypto, diffie-hellman, ed25519, el-gamal, encryption, signature, thingy

## 简介

The thingy-crypto-node is the keeper of an ed25519 keypair, implementing all basic crypto functionality for this specific keypair
