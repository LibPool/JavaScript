# tdc-ui

> 标签: JavaScript

## 简介

`tdc-ui` 是为腾讯设计云生态相关的站点提供的通用组件库，使用基于 `Web Components` 的 `Lit` 提供服务，方便各个业务接入统一的公共组件。
