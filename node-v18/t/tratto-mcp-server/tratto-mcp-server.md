# tratto-mcp-server

> 标签: JavaScript

## 简介

Local MCP server that lets your AI draw technical-analysis markup (support/resistance, trendlines, Fibonacci, and more) onto a finance chart already open in your browser, using the page's own drawing engine. Personal, non-commercial, fully local, no cloud
