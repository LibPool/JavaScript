# tristate-radio

> 标签: materal-ui, material design, react, react-component

## 简介

A Yes/No Radio button React component that's powered by a true/false/undefined/null prop/state. If nil then the radio button is unselected. "Yes" button is selected for true and "no" button is selected for false.
