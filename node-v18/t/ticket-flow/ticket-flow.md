# ticket-flow

> 标签: agents, claude-code, codex, cursor, github-copilot, linear, opencode, skills, tickets, workflow

## 简介

Generate a portable ticket-driven development workflow (next → describe → execute → review → merge) for Claude Code, Codex, GitHub Copilot, Cursor, and opencode from one canonical source.
