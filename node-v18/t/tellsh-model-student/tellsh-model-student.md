# tellsh-model-student

> 标签: intent-classification, polish, tellsh

## 简介

Distilled student model for tellsh (3-layer encoder, int8 weights for tellsh's pure-JS runtime, ~17 MB, no onnxruntime): consulted only when the linear cascade's confidence is below 0.6.
