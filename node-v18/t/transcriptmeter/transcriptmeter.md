# transcriptmeter

> 标签: claude-code, cli, codex, context-engineering, cost, prompt-caching, token-efficiency, transcripts

## 简介

What your agent sessions cost, from the transcripts on your disk: tokens by class, cache hit ratio, peak context, estimated cost, tool output by command — for Claude Code and Codex CLI, sizes only, nothing leaves the machine.
