# treapkit

> 标签: bst, data-structure, order-statistics, ordered-map, ordered-set, sorted-map, sorted-set, treap, typescript

## 简介

Zero-dependency ordered set and map with O(log n) operations and order statistics — TypeScript-first npm equivalent of Java TreeSet/TreeMap, Python SortedList, C# SortedSet, Go treap.
