# tailwind-plugin-no-scrollbar

> 标签: scrollbar, scrollbar-hide, tailwind, tailwind-plugin, tailwind-plugin-no-scrollbar

## 简介

Tailwind CSS plugin that adds utilities to hide scrollbars (no-scrollbar / scrollbar-none) without disabling scrolling
