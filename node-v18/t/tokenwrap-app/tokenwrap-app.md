# tokenwrap-app

> 标签: ai, claude, claude-code, copilot, cursor, dashboard, local-first, tokens, tracker, usage

## 简介

TokenWrap — local, private AI usage tracker. Captures real token/quota usage from Claude Code, GitHub Copilot, Cursor, Antigravity, Windsurf and browser AI sites, and serves a live dashboard at http://localhost:5175. All data stays on your machine.
