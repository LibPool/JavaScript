# trustoss-cli

> 标签: agent-skill, claude-code, dependency-analysis, fake-stars, github, repository-health, supply-chain-security

## 简介

GitHub repository health reports from trustoss.org — quality score, deep scan (CI health, vulnerabilities, bus factor) and star audit (growth curve + fake-star detection). Ships an agent SKILL.md for Claude Code and other AI coding tools.
