# tiny-pi-camera

> 标签: Camera, Photo, Pi, Picture, Raspberry, Video, pi-camera, picamera, raspicam, raspistill, raspivid

## 简介

A very lightweight promise based Node.js wrapper for the native Raspberry Pi Camera CLI tools.
