# ts-npm-lint

> 标签: lint, npm, package, tsd, typescript

## 简介

Utility to create typescript based npm modules. Can also strip reference paths for .d.ts files and check TSD configs.

- 官网：https://github.com/mweststrate/ts-npm-lint#readme
