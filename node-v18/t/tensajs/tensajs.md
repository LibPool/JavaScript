# tensajs

> 标签: animation, css, json, scroll, timeline, tween, web-animation

## 简介

Tensa is a JavaScript animation engine with a real physics layer built in. Animate DOM elements, CSS properties, and plain JavaScript objects with tweens, timelines, gravity, springs, collisions, soft bodies, and more. Add cinematic text effects, scroll-d
