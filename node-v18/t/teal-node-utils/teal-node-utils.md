# teal-node-utils

> 标签: JavaScript

## 简介

初衷是写脚手架会引入好几个库，但这些库功能单一，不复杂，所以这个库主要集中一些常用的脚手架函数，比如root-check，user-home，path-exists等，会逐渐的完善，方便写脚手架，使得引入支持ES和CJS
