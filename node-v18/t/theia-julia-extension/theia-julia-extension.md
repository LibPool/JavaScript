# theia-julia-extension

> 标签: theia-extension

## 简介

An extension for the [Theia-IDE](https://github.com/theia-ide/theia) to support the [Julia Language](https://github.com/JuliaLang/julia), using the [Julia Language Server](https://github.com/JuliaEditorSupport/LanguageServer.jl).
