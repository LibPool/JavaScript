# taiwan-data-mcp

> 标签: mcp, model-context-protocol, open-data, real-estate, taiwan, 公司登記, 台灣, 實價登錄, 防詐

## 简介

MCP server for Taiwan public data — 實價登錄、公司登記查核、165 防詐、藥品查詢、政府標案、農產行情。Query real Taiwan data from Claude, Cursor, etc.
