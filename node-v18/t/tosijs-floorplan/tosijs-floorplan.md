# tosijs-floorplan

> 标签: accessibility, affordance, agent, floorplan, schematic, svg, tosijs, webmcp, wireframe

## 简介

Render an agent-surface map (plain records) as a floorplan SVG — the affordance grammar as a pure, dependency-free function. No DOM, no framework. Formerly tosijs-schematic.
