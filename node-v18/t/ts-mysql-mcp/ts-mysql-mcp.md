# ts-mysql-mcp

> 标签: JavaScript

## 简介

基于 **Model Context Protocol (MCP)** 的 MySQL 数据库交互服务器，使用 **TypeScript** 实现。通过受控、安全的接口，让 AI 助手（Claude Code / Claude Desktop 等）能够操作 MySQL 数据库，包括列出表、读取数据、执行 SQL 等功能。
