# tekivex-pdf

> 标签: biodata, certificate, invoice, pdf, puppeteer-alternative, react-pdf, react-to-pdf, resume, tekivex, ticket, watermark

## 简介

TekiVex PDF — render React components to pixel-stable PDFs and PNGs without a headless browser. Wraps @react-pdf/renderer with the tekivex-ui design system.
