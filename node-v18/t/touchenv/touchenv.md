# touchenv

> 标签: biometrics, credentials, dotenv, dotenvx, env, keychain, macos, secrets, security, touchid

## 简介

Keychain-aware dotenvx for macOS: keep the dotenvx private key in the Keychain behind Touch ID instead of a plaintext .env.keys. Plain dotenvx passthrough off macOS.
