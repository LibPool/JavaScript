# trussfy

> 标签: ai, audit, claude, claude-code, context, cost, mcp, tokens

## 简介

Your AI Waste Report — see what Claude Code really read & burned (npx trussfy --audit), and measure token savings on your own repo (npx trussfy --benchmark). 100% local, no signup.
