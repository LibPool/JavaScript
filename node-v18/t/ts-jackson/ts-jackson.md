# ts-jackson

> 标签: api-adapter, api-mapper, camel-case, data-transfer-object, decorator, decorators, deserialization, deserializer, dto, jackson, json, json-mapper, json-parser, json-path, json-to-class, json-transformer, marshalling, naming-strategy, nested-json, object-mapper, polymorphism, reflect-metadata, safe-parse, serialization, serializer, snake-case, strict, type-safe, typescript, typescript-json, unmarshalling, validation

## 简介

Serialize and deserialize deeply nested JSON into TypeScript classes with decorators. Deep lodash-style path mapping, TC39 standard decorator support, strict type checking, zod-style safe parsing, polymorphism, Maps and naming strategies.
