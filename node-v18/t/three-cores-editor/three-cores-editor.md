# three-cores-editor

> 标签: 3d, editor, javascript, three.js, webgl

## 简介

- **开箱即用**：`new ThreeEditor(DOM)` 一行完成场景、相机、渲染器、控制器、后期管线与性能面板的初始化。 - **可扩展**：通过 `addComponent` 注入自定义物体，通过 `addEffect` 注入自定义后期特效。 - **可存档**：`getEditorStorage()` / `setEditorStorage()` 支持场景状态的完整导出与还原。 - **内置编辑器面板**：`openEditorPanel()` 打开悬浮面板，可视化调整渲染、相机、环境、后
