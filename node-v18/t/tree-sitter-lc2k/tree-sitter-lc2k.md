# tree-sitter-lc2k

> 标签: JavaScript

## 简介

This project aims to provide a parser for the [LC2K/LC-2K](https://eecs370.github.io/project_1_spec/#2-lc-2k-instruction-set-architecture) architecture used in EECS 370 at the University of Michigan - Ann Arbor. I intend to incorporate this into a LSP cli
