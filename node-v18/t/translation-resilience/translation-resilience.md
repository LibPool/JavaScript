# translation-resilience

> 标签: chrome, dom, google-translate, i18n, insertbefore, mutationobserver, notfounderror, page-translation, react, removechild

## 简介

Stops browser page translation (Google Translate) from crashing React and silently freezing translated text, by re-adopting displaced text nodes instead of swallowing errors.
