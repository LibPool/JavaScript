# tmp36

> 标签: analog, analog board, gpio, pcf8591, q2w, quick2wire, raspberry, raspberry pi, rpi, temperature, tmp36, wiring pi, wiringpi

## 简介

Temperature reading from TMP36 sensor via PCF8591 analog/digital converter using WiringPi GPIO command line utility.
