# third-brain-mcp

> 标签: claude, cursor, knowledge-base, mcp, model-context-protocol, rag, third-brain

## 简介

Connect MCP clients (Claude Desktop, Claude Code, Cursor) to a Third Brain server: device-code sign-in, one-command client install, and a stdio-to-HTTP MCP bridge. Zero dependencies.
