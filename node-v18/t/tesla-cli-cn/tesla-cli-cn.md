# tesla-cli-cn

> 标签: agent, automation, cli, ev, fleet-api, oauth, tesla, tesla-cn, vehicle-command

## 简介

Tesla Fleet API command line tool — Agent-friendly with semantic exit codes, JSON envelopes, PKCE OAuth, and EC P-256 signed vehicle commands. Tested live against Tesla CN.
