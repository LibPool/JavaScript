# taco-team-build

> 标签: JavaScript

## 简介

taco-team-build is a node module designed to avoid common pitfalls when building Cordova apps in a Team or Continuous Integration environment. It was put together for a set of tutorials for the Visual Studio 2015 Tools for Apache Cordova (TACo) featureset
