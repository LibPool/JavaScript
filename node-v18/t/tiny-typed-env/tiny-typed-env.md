# tiny-typed-env

> 标签: cli, dotenv, env, environment, environment-variables, standard-schema, typescript, valibot, validation, zod

## 简介

Tiny typed environment loader. Zero runtime deps. Built-in schemas or Zod/Valibot. Fails at boot. Works in Node, Bun, Deno, and Workers.
