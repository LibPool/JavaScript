# trackle-wolf-dtls

> 标签: JavaScript

## 简介

Node wolfSSL DTLS 1.3 server with Raw Public Key (RFC 7250), session tickets (fixed STEK) and Connection ID (RFC 9146). API-compatible with trackle-mbed-dtls so it can sit behind the same demux router on :5684.
