# transcriptfetch

> 标签: ai-agents, api, captions, instagram, llm, mcp, rag, sdk, speech-to-text, subtitles, tiktok, transcript, transcription, typescript, youtube, youtube-transcript

## 简介

Official Node.js/TypeScript SDK for the TranscriptFetch API: a production transcript API for YouTube, TikTok, Instagram and direct media URLs - captions in about a second, automatic AI speech-to-text when none exist - plus search, channel and playlist lis
