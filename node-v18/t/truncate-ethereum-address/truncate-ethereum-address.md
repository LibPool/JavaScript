# truncate-ethereum-address

> 标签: JavaScript

## 简介

Easily format an Ethereum address (eg. `'0xab5801a7d398351b8be11c439e05c5b3259aec9b'`) to a truncated version (eg. `'0xab58[…]ec9b'`).
