# toolchestrator

> 标签: ai, claude, mcp, orchestration, runtime, toolchestrator

## 简介

Node client for Toolchestrator, the runtime for vibe-coded apps. Connect a local app you built with Claude Code to your hub without moving it off the machine it runs on, and deploy it to a teammate's runner as always-on failover.
