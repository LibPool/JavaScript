# tita-media-ai-styleguide

> 标签: component-library, design-system, react, styleguide, tailwindcss, tita-media, typescript, ui-components

## 简介

UI component library (React + TypeScript) with Tita Media theme styles. Includes design tokens (colors, typography, spacing, borders, shadows) and reusable components.
