# tissues

> 标签: ai, circuit-breaker, cli, dedup, git, github, issues, safety

## 简介

AI-enhanced GitHub issue creation with built-in safety guardrails. Wraps gh CLI with circuit breakers, rate limiting, dedup, and templates.
