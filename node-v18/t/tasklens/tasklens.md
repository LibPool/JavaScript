# tasklens

> 标签: agent, cli, registry, shadcn, tasklens, vue

## 简介

TaskLens 源码分发 CLI：npx tasklens add 把 Agent 执行 UI 的 .vue 源码复制进你的仓库（shadcn 模式，零运行时依赖）
