# tronbyt-mcp

> 标签: led-matrix, mcp, model-context-protocol, pixlet, tidbyt, tronbyt

## 简介

MCP server for Tidbyt/Tronbyt LED displays — push text, images, and apps; manage brightness, night mode, and installations via tronbyt/server.
