# trpc-action-state-adapter

> 标签: adapter, formdata, nextjs, react19, server-actions, trpc, useactionstate, zod

## 简介

A lightweight adapter that wraps a tRPC v11 Server Action for use with React 19's useActionState hook, parsing FormData into nested JSON and formatting Zod validation errors into fieldErrors.
