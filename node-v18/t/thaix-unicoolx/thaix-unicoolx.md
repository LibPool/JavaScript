# thaix-unicoolx

> 标签: JavaScript

## 简介

โปรเจกต์ตัวอย่างสำหรับการใช้งาน **thaiUnicool**   Library ที่ช่วยให้คุณ filter, find, map ข้อมูลโรงเรียนและมหาวิทยาลัยของไทยได้ง่าย ๆ   ข้อมูลมาจาก JSON ของ **กระทรวงศึกษาธิการ** และ **Thai University List** บน GitHub
