# take4-console

> 标签: ansi, chart, cli, console, controls, layout, nerdfonts, progressbar, sparkline, terminal, tui, ui, widgets, window, yaml

## 简介

A terminal cell-grid rendering library for Node.js — windowed UI with styles, borders, layouts, keyboard/mouse input, and a YAML layout builder.
