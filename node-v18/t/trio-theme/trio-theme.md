# trio-theme

> 标签: JavaScript

## 简介

`trio-theme` is a React/Next.js-based theming system built on Tailwind CSS. It simplifies dynamic theming with configurable color shades, support for RGB and HEX formats, and flexible storage options (localStorage or cookies).
