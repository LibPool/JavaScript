# tokentriage

> 标签: instrumentation, llm, observability, proxy, tokentriage, tracing

## 简介

Zero-dependency instrumentation SDK for the TokenTriage proxy — forwards x-tt-* recipes and reads back the receipt the server stamped. It forwards and reads; it never computes.
