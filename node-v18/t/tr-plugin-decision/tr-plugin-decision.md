# tr-plugin-decision

> 标签: JavaScript

## 简介

White-label Total Recall decision plugin: typed decisions (choice, yes/no, score) from a System One decision model with confidence gates, fallbacks and SSSS decision records; the layout engine for composing UI from SSSS documents.
