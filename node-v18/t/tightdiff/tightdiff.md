# tightdiff

> 标签: ai-agents, ci, cli, code-quality, code-review, diff, git-hook, lint, pre-commit, slop

## 简介

A linter for AI code slop. Parses your diff and blocks debug leftovers, disabled tests, weakened checks, placeholders, out-of-scope edits, and committed build output. Zero dependencies.
