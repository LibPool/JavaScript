# trainmath

> 标签: chinchilla, flops, fsdp, gpu, h100, llm, machine-learning, memory-estimate, mfu, pretraining, scaling-laws, training-cost, transformer, typescript

## 简介

Plan and sanity-check LLM pretraining runs in TypeScript - parameter counts, FLOPs per token, MFU from measured throughput, expected tokens/sec, Chinchilla token budgets, per-GPU memory under DDP, ZeRO and FSDP, hours and cost on H100, A100, B200, MI300X
