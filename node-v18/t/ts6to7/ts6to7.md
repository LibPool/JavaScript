# ts6to7

> 标签: codemod, migration, ts5to7, tsgo, typescript, typescript-5, typescript-7

## 简介

Codemod that migrates a TypeScript 5 or 6 project to TypeScript 7 (tsgo): rewrites tsconfig.json options removed in TS7 and flags changes that need manual review.
