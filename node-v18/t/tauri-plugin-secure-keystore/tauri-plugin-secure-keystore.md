# tauri-plugin-secure-keystore

> 标签: android, desktop, encryption, ios, keychain, keystore, secure-storage, tauri, tauri-plugin

## 简介

JS bindings for tauri-plugin-secure-keystore: encrypted key-value storage backed by the Android Keystore, iOS Keychain, and the desktop OS credential store.
