# tailwind-schemes

> 标签: CSS, custom-themes, dark-mode, dynamic-color, light-mode, multi-theme, plugin, tailwind, tailwindcss, tailwindcss-plugin, theme

## 简介

A TailwindCSS plugin for dynamic multi-theme color schemes, enabling easy customization and switching between themes like light and dark mode.
