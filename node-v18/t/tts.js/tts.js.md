# tts.js

> 标签: Text-To-Speech, espeak, speak, tts

## 简介

tts.js is a Text-To-Speech compiled from eSpeak using Emscripten and it supports multiple languages.

## 官网

- npm 页面：https://www.npmjs.com/package/tts.js

- Node 要求：>= 0.6.x
