# tabsmith-lint

> 标签: chrome-extension, chrome-web-store, chrome-web-store-rejection, cli, extension-publishing, linter, manifest-v3, mv3, permissions, purple-potassium, static-analysis, unused-permissions

## 简介

Pre-submission compliance linter for Manifest V3 Chrome extensions: flags likely Chrome Web Store rejection risks (unused/excessive permissions, MV3 violations, broken packaging) before you submit.
