# tracefold

> 标签: JavaScript

## 简介

Tracefold - verified undo and offline-verifiable receipts for AI agent actions. This npm name is a reservation and ships no code; the working release is the Rust crate tracefold 0.1.2 (cargo install tracefold, binary gx).
