# typeorm-firebird

> 标签: JavaScript

## 简介

Data-Mapper ORM for TypeScript, ES7, ES6, ES5. Supports Firebird dialect 1, MySQL, PostgreSQL, MariaDB, SQLite, MS SQL Server, Oracle, MongoDB databases.
