# tipe-loader

> 标签: JavaScript

## 简介

install our loader ```bash npm install tipe-loader ``` Add our tipe-loader to your Webpack config `module.rules` and replace `YOUR_ORG_SECRET_KEY` and `YOUR_API_KEY` with your keys on Tipe.
