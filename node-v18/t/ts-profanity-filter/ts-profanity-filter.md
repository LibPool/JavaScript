# ts-profanity-filter

> 标签: ai, angular, batch, censor, claude, cli, compliance, content-moderation, deutsch, digital-services-act, dsa, filter, gemini, german, hate-speech, i18n, llm, moderation, multilingual, ollama, pii, profanity, react, schimpfwoerter, streaming, typescript, vue

## 简介

TypeScript profanity filter that returns text segments for UI rendering. English and German built in, any language registrable, false positives like Klassik and classic cleared, leetspeak and lookalikes matched — plus an optional AI check for hate, threat
