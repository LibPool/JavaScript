# true-up

> 标签: agent-native, cli, code-generation, content-hashed, dependency-graph, deterministic, git-native, staleness-detection, true-up, truing-up

## 简介

Deterministic, git-native truing-up for any repo: a content-hashed dependency graph that detects what a change makes stale, regenerates the mechanical, and worklists the advisory.
