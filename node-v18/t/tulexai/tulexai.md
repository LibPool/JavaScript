# tulexai

> 标签: agent, ai, anthropic, budget, claude-code, cli, llm, openai, opencode, tulexai

## 简介

Point Claude Code or opencode at TulexAI: 48 models on one flat monthly budget with hard caps. tulexai connect writes your agent config with backups, a printed diff, and a clean undo.
