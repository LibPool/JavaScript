# tool-minifier-sdk

> 标签: ai-agents, cli, context-window, json, llm, mcp, minify, model-context-protocol, tiktoken, tokens, tool-output, toon, typescript

## 简介

Zero-friction, production-ready SDK that compresses raw AI tool outputs (JSON arrays, DB rows, API responses) into token-optimized TOON/tabular formats before they re-enter an LLM context window. Ships with a local, offline MCP server.
