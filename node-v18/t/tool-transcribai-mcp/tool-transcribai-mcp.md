# tool-transcribai-mcp

> 标签: image-to-text, llm, mcp, model-context-protocol, ocr, tesseract, transcriber

## 简介

Servidor MCP para transcribir texto de imágenes (OCR local) y generar descripciones breves con bajo consumo de tokens. Compatible con ChatGPT, Claude, opencode y cualquier cliente MCP.
