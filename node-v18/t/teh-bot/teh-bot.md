# teh-bot

> 标签: api, bot, cjs, esm, lightweight, nodejs, polling, telegram, telegram-bot, telegram-bot-api, typescript, webhook

## 简介

Lightweight, high-performance Telegram Bot API library with zero dependencies. Supports polling, webhooks, and all Telegram Bot API methods.
