# theengs-decoder

> 标签: ble, bluetooth, bluetooth-low-energy, decoder, iot, theengs, wasm, webassembly

## 简介

Decode BLE advertisements from supported sensors and devices using TheengsDecoder, in Node.js via WebAssembly.
