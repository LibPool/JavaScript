# tinycollection

> 标签: collection, database, geojson, in-memory, indexing, mongodb, query, typescript

## 简介

A lightweight, in-memory database for Node.js and browsers, offering a MongoDB-style API, advanced querying, and indexing capabilities, all written in TypeScript.
