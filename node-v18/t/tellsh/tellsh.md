# tellsh

> 标签: bash, cli, intent-classification, natural-language, nl2bash, offline, polish, powershell, shell, slot-filling, terminal, zsh

## 简介

Offline natural-language (Polish & English) to shell command CLI: tool->intent->slot cascade of tiny linear models + templates for bash/zsh/sh/PowerShell (fish/cmd best effort). No LLM at runtime, no native dependencies (pure JS).
