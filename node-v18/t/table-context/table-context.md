# table-context

> 标签: JavaScript

## 简介

Table-Context é uma biblioteca de gerenciamento de contexto altamente tipada para React, voltada para tabelas dinâmicas. Oferece hooks personalizados como useRow para acessar e manipular registros com segurança e flexibilidade. Suporta schemas genéricos,
