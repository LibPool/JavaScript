# treesitter-to-unist

> 标签: ast, syntax, tree, tree-sitter, treesitter, unist

## 简介

A typescript library to transform a [Tree-sitter](http://tree-sitter.github.io/) tree to a [Universal Syntax Tree](https://github.com/syntax-tree/unist).
