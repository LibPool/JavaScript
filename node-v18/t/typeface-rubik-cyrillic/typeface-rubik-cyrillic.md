# typeface-rubik-cyrillic

> 标签: JavaScript

## 简介

Rubik is a sans serif font family with slightly rounded corners designed by Philipp Hubert and Sebastian Fischer at Hubert & Fischer as part of the Chrome Cube Lab project.
