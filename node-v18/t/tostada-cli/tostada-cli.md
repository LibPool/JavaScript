# tostada-cli

> 标签: JavaScript

## 简介

Scaffold full-stack [Phoenix](https://www.phoenixframework.org/) + Vite projects with your choice of client framework, from the [tostada](https://github.com/gamedev-company/tostada) boilerplate.
