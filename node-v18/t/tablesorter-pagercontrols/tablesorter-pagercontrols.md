# tablesorter-pagercontrols

> 标签: buttons, control, ecosystem:jquery, jquery-plugin, pager, sort, table, tablesorter

## 简介

This jQuery plug-in is an add-on for mottie's tablesorter, more explicitly its pager add-on. It programmatically adds pager controls below a table and applies the pager add-on for large HTML tables, so that you don't have to insert the controls to the HTM
