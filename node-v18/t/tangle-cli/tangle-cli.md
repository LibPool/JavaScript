# tangle-cli

> 标签: JavaScript

## 简介

该项目为生成下载文件模板的脚手架 ### 使用方法 ``` npm install tangle-cli -g ``` ### 内置功能 ``` tangle add template-name template-url tangle delete template-name tangle list ```
