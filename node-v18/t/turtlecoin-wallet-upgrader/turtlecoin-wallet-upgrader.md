# turtlecoin-wallet-upgrader

> 标签: cryptocurrency, cryptonote, turtlecoin, wallet-upgrader

## 简介

A wrapper for TurtleCoin wallet-upgrader, which can upgrade wallets from the new to old format.

- 官网：https://turtlecoin.lol/
- npm 页面：https://www.npmjs.com/package/turtlecoin-wallet-upgrader
