# telegram-mcp-connect

> 标签: ai-agent, chat, claude, claude-code, codex, cursor, mcp, mcp-server, model-context-protocol, modelcontextprotocol, mtproto, telegram, telegram-client, telegram-mcp, windsurf

## 简介

Telegram MCP server that runs locally. Connect Telegram to Claude Code, Codex, Cursor and other MCP clients to read chats, search messages and summarise conversations. Your session stays on your machine.
