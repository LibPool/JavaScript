# terminal-driver-mcp

> 标签: agent-tools, ai-agents, automation, claude, e2e-testing, headless-terminal, llm, mcp, mcp-server, model-context-protocol, node-pty, pseudo-terminal, pty, repl, terminal, tui, tui-testing, vim, xterm

## 简介

A real interactive terminal for AI agents (MCP). Run and test vim, htop, gdb, REPLs, and any TUI — things the built-in fire-and-forget terminal can't touch.
