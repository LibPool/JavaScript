# tensor-argparse

> 标签: argparse, args, cli, option, parser

## 简介

Tensor's fork of a argparse library by nodeca - Very powerful CLI arguments parser. Native port of argparse - python's options parsing library

- 官网：https://github.com/nodeca/argparse
- 源码仓库：git://github.com/nodeca/argparse.git
- npm 页面：https://www.npmjs.com/package/tensor-argparse
