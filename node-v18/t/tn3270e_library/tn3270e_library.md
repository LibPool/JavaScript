# tn3270e_library

> 标签: 3270, ebcdic, ibm, mainframe, mvs, sna, telnet, tn3270, tn3270e, vtam, zos

## 简介

A full TN3270/TN3270E protocol library for Node.js. Handles Telnet negotiation, LU binding, 3270 datastream parsing, EBCDIC conversion, and AID key encoding.
