# tmdb-kit

> 标签: bun, cjs, deno, edge, esm, node, sdk, themoviedb, tmdb, typescript

## 简介

A tiny, typed, zero-runtime-dependency TMDB SDK for Node.js, Bun, Deno, and edge runtimes.
