# tanya-stack

> 标签: JavaScript

## 简介

1. const Stack = require('tanya-stack'); 2. const stack = new Stack(); 3. stack.push(1) // добавить элемент в стек 4. stack.pop() // взять элемент сверху, и удалить его из стека 5. stack.isEmpty() // true если пустой, false если нет 6. stack.peek() // пок
