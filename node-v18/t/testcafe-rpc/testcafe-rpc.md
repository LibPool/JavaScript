> 标签: RPC, TestCafe, functional, remote, remoting, testing

## 简介

TestCafe RPC ====== RPC library for the [TestCafé](http://testcafe.devexpress.com/). It allows you to create a single TestCafé instance and then interact with it programmatically from any machine in your network.
