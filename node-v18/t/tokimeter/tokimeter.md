# tokimeter

> 标签: anthropic, claude-code, cli, cline, codex, copilot-cli, cost-tracking, cursor, finops, grok, llm, openai, opencode, token-usage

## 简介

Local-first usage & cost meter for AI coding agents (Claude Code, Codex, Cursor, Grok Build, Hermes, opencode, Cline, Copilot CLI). Inline status-line HUDs, zero-setup reports, 5h-window limits, budgets — no telemetry.
