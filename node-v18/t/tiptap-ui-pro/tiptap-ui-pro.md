# tiptap-ui-pro

> 标签: prosemirror, react, rich-text-editor, table, tiptap, tiptap-extension

## 简介

Styled, resizable TipTap 3 table extensions with a full editing UI: bubble menu, context menu, column/row/table resize handles, cell & table property dialogs, border and background color controls.
