# toxicity

> 标签: bad-words, censor, chat, game, leetspeak, moderation, profanity, profanity-filter, toxicity

## 简介

Fast bad-word detection for real-time game chat. Resistant to leetspeak, spacing and homoglyph evasion, with low false positives.
