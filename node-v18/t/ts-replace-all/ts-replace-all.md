> 标签: String, all, global, many, match, matches, modify, multiple, needle, polyfill, replace, replace-all, replaceAll, replacement, replacer, search, string, sub-string, substring, text

## 简介

This package includes the [core-js](https://github.com/zloirock/core-js) polyfill for `String#replaceAll`, along with TypeScript typings.
