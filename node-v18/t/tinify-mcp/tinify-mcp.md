# tinify-mcp

> 标签: JavaScript

## 简介

MCP服务器实现图片压缩功能，使用TinyPNG API。支持单个和批量图片压缩，提供详细的压缩统计和错误处理。

## 官网

- npm 页面：https://www.npmjs.com/package/tinify-mcp

- 1.0.0

## 获取地址

- npm registry：https://registry.npmjs.org/tinify-mcp
- Node 要求：>=18.0.0
