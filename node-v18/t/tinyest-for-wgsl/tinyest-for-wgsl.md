# tinyest-for-wgsl

> 标签: JavaScript

## 简介

Transforms JavaScript into its 'tinyest' form, to be used in generating equivalent (or close to) WGSL code.

## 官网

- 官网：https://docs.swmansion.com/TypeGPU
- 源码仓库：git+https://github.com/software-mansion/TypeGPU.git
