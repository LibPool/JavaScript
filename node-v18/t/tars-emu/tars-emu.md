# tars-emu

> 标签: JavaScript

## 简介

* emu框架tars版，保留原先功能并对tars进行适配和改造 * 框架服务支持taf和web(koa)两种类型 * 推荐使用happ-generator脚手架生成项目结构 * 也可以直接安装使用 ```npm i -S tars-emu```
