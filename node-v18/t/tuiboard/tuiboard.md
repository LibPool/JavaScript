# tuiboard

> 标签: bun, kanban, markdown, obsidian, opentui, productivity, task-board, terminal, tui

## 简介

Terminal kanban for markdown task boards, with optional Today/Tomorrow planner, 24h agenda + calendar overlay, and a live view of your coding-agent sessions (Claude Code, Codex, OpenCode, Pi). Use only the panels you want.
