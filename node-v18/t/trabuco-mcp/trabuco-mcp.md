# trabuco-mcp

> 标签: ai, code-generation, java, maven, mcp, model-context-protocol, spring-boot, trabuco

## 简介

Generate production-ready Java projects via AI coding agents — MCP server for Trabuco CLI. A native Claude Code plugin is also available: /plugin marketplace add arianlopezc/Trabuco
