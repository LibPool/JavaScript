# trama-sdk

> 标签: ecommerce, headless, next.js, react, storefront, tanstack-query, trama, wix

## 简介

React SDK for Trama — connect any React frontend to Wix, Shopify, or Webflow (products, cart, CMS, checkout) without migration.
