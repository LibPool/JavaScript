# taro-vite-plugin-split-chunk

> 标签: plugin, split-chunk, taro, vite

## 简介

一个专为 Taro 4.x 小程序项目设计的 Vite 插件，用于智能分包和代码分割优化。该插件能够根据小程序的分包配置自动将代码分割到对应的子包中，优化小程序的加载性能。
