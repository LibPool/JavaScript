# traceflow-indexer

> 标签: cli, events, indexer, mantle, web3

## 简介

TraceFlow is an indexer-in-a-box for Mantle. This repo contains the CLI that scaffolds a full stack (indexer, Postgres schema, REST API, Docker Compose) from a contract ABI.
