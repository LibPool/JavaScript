# tacet-react

> 标签: animated-icons, icon-set, icons, react, svg

## 简介

Tacet icon set for React: 454 outline glyphs where the cut is data, self-drawing animation, four cut densities, 64 musical instruments, digits and a text line that write themselves, and input fields drawn in the same glyphs.
