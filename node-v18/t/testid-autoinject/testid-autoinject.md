# testid-autoinject

> 标签: appium, automation, babel-plugin, data-testid, e2e, eslint-plugin, expo, nextjs, nuxt, playwright, qa, react-native, testid, vite, vue

## 简介

Zero-touch build-time injection of stable testID / data-testid for React Native (Expo) and Next.js. Frontend writes nothing; QA automation (Appium, Playwright) gets stable selectors.
