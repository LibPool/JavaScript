# true-random-tools

> 标签: atmospheric-noise, entropy, integers, random, random-number-generator, random.org, rng, true-random

## 简介

There is no really random value in pure computation—all are pre-calculated. Real randomness comes from physical entropy like atmospheric noise. Fetch true random numbers from Random.org with customizable parameters.
