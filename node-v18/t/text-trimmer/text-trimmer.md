# text-trimmer

> 标签: customisation, customization, ellipsis, post, preview, react, shortner, slice, string, string-shortner, text, text length customisation, text length customization, trim, trimmer

## 简介

This package simply allows you to shorten strings to the required character length you input and concats a "..." to the end of the new string.
