# typescript-vue-shared-module-across-repositories

> 标签: code-sharing, multi-repository-type-sharing, reusable-code

## 简介

This project tries to figure out the possibilities and limitations of how to share one's repository code as one or multiple separeted (npm) modules for the usage in other repositories
