# tower-mcp

> 标签: ai-agents, claude, codex, coordination, cursor, developer-tools, mcp, model-context-protocol

## 简介

Multiplayer for AI coding agents — delegate tasks across machines, see every claim, task and reply on one shared board, and catch collisions before the first keystroke. Over MCP, model-agnostic (Claude Code, Cursor, Codex).
