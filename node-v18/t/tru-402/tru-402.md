# tru-402

> 标签: 402, agent, commerce, express, middleware, payment, stripe, tru

## 简介

One-line Express middleware for agent commerce. Wrap paid endpoints; unauthenticated requests get a self-documenting 402 that tells agents how to authenticate and pay.
