# ts-openapi-codegen

> 标签: axios, client, codegen, fetch, generator, json, node, openapi, swagger, typescript, xhr, yaml

## 简介

Library that generates Typescript clients based on the OpenAPI specification. It bases on openapi-typescript-codegen
