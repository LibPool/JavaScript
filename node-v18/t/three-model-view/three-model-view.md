# three-model-view

> 标签: model, threejs

## 简介

1. 版本基于 threejs vue3 写的一个 3D 模型预览器，可以加载 GLB 和 GLTF 格式文件,支持模型动画播放预览控制； 2. 关键接口参数定义：    export type LightType = 'single' | 'all';    export type ModelType = 'GLTF' | 'OBJ' | 'FBX';
