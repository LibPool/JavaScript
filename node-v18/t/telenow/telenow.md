# telenow

> 标签: app-platform, crm, hmac, marketplace, plugin, react, sdk, telenow, voice-ai, webhook

## 简介

Telenow App Platform SDK — build installable apps for the Telenow voice AI dashboard: a React UI that renders in the dashboard, verify signed agent tool calls & event webhooks, and read/write your app's data. Includes the `telenow build` packaging CLI.
