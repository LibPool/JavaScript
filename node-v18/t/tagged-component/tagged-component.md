# tagged-component

> 标签: hook, props, react, react-native, tag

## 简介

use js proxy to add prop callback hooks for jsx components written like this tagged.tag1.tag2.Button; everything can be customized including which prop to hook, which framework(react or react-native); easy to config: provide a { tag1: { tag2: data } } ali
