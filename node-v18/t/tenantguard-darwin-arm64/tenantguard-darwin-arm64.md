# tenantguard-darwin-arm64

> 标签: JavaScript

## 简介

Prebuilt tenantguard binary for darwin/arm64 (Apple Silicon macOS). Installed automatically as an optional dependency of the tenantguard npm package; not meant to be installed directly.
