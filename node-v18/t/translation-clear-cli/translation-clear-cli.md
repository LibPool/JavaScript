# translation-clear-cli

> 标签: JavaScript

## 简介

背景：前端各个项目下有大量的翻译文件，但是随着产品的迭代， 会产生废弃的无用翻译，但是手工清理效率极其低下，需要寻找一种自动的清理方法。

- npm 页面：https://www.npmjs.com/package/translation-clear-cli
