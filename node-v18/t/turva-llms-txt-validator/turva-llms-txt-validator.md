# turva-llms-txt-validator

> 标签: agent-readiness, ai-agents, cli, llms-txt, llms.txt, validator

## 简介

Validate a site's llms.txt structure: eight checks as pass/warn/fail plus two llms.txt v2 discovery checks that read pass or info and never move the summary, JSON output. Same checks as the hosted validator at turva.dev/llms-txt-validator.
