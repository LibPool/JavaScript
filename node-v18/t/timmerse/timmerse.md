# timmerse

> 标签: 娱乐聊天, 需求评审, 音视频

## 简介

您可以通过 Timmerse Web SDK 进行音视频连麦、收发聊天消息实时互动引擎、创建/解散等房间管理服务、静音/踢人等会议控制服务，并且提供美颜等趣味玩法。
