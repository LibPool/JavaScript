# treasury-fiscaldata

> 标签: api-client, debt-to-the-penny, exchange-rates, finance, fiscal-data, fiscaldata, fixed-income, government-data, interest-rates, national-debt, treasury

## 简介

Typed, zero-dependency client for the US Treasury FiscalData API — Debt to the Penny, average interest rates, exchange rates, and any endpoint with typed pagination, sorting, and filtering. No API key required.
