# thud

> 标签: api, framework, functional, javascript, library, object-oriented, programming

## 简介

thud is an object-oriented & functional programming library – for modern javascript engines – which correctly extends JavaScript Natives, as well as providing other useful Classes. Giving you a – relatively – safe and easy to use API, to help make your code more succinct and efficient.
