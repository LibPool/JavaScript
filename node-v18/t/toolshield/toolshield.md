# toolshield

> 标签: agents, ai, anthropic, circuit-breaker, function-calling, llm, openai, reliability, retry, tool-calling

## 简介

A reliability layer for AI agent tool calls: retries, timeouts, circuit breakers, validation, and fallbacks — provider-agnostic.
