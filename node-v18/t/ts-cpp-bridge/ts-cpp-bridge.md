# ts-cpp-bridge

> 标签: bindings, bridge, c++, codegen, cpp, decorators, generator, glue-code, napi, native, node-addon-api, performance, type-safe, typescript

## 简介

TypeScript-to-C++ bridge generator for Node.js N-API. Automatically generates C++ glue code and type-safe TypeScript wrappers from decorators.
