# ts-subject-create

> 标签: JavaScript

## 简介

## 介绍 之前在刷`type-challenges`的时候，为了记录自己的学习过程，每次都要创建一个题目，有题目内容`template.ts`， 和测试文件`test-cases.ts`。所以写了一个cli根据`type-challenges`中的题目序号自动创建这两个文件。
