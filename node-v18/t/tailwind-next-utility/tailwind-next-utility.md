# tailwind-next-utility

> 标签: JavaScript

## 简介

This is a tailwind and next utility I created in order to avoid reinstalling and adding tailwind over and over in new next projects. Its still a work in progress but here is the first version. Folow these steps and this utility will be installed globally

## 官网

- npm 页面：https://www.npmjs.com/package/tailwind-next-utility
