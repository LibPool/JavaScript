# three-state-counter

> 标签: analytics, async, counter, crash-safe, fast-counter, lightweight, metrics, persistent, sqlite, sync, wal, write-ahead-log

## 简介

A lightweight, crash-safe, persistent counter for Node.js with sync/async modes using in-memory + WAL + SQLite layers.
