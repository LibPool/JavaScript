# tab-sync-lite

> 标签: broadcast-channel, broadcastchannel, cross-tab, framework-agnostic, hook, logout, react, redux, state, store, sync, tab-sync, tabs, zustand

## 简介

Sync any store (Zustand, Redux, signals, useState, plain objects) across open browser tabs in one line. New tabs get the current state. Zero dependencies, any framework.
