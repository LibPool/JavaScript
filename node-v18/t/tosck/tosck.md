# tosck

> 标签: async, compress, confurable, curl, decompress, deflate, fetch, follow, get, got, gzip, http, https, minimal, redirects, request, simple, url, utils

## 简介

Asynchronous page request - simple and configurable. Follow redirects and decompress gzip/deflate request bodies on-the-fly.
