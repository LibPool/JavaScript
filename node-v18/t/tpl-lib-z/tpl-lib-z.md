# tpl-lib-z

> 标签: JavaScript

## 简介

- [x] 使用 javascript 编写 - [x] 支持编写前端功能库和 nodejs 软件包 - [x] 使用 rollup，支持打包为 cjs, umd, iife, esnext - [x] 使用 jest 进行单元测试 - [x] 使用 playwright 进行 e2e 自动化测试 - [x] 使用 svrx 作为前端组件开发测试服务器 - [x] 使用 vitepress 编写文档 - [x] 使用 gulp 实现自动化操作 - [ ] 使用 npm 对外发布，使用 * 本地发布
