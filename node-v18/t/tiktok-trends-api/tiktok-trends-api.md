# tiktok-trends-api

> 标签: analytics, growth-rate, hashtag-volume, social-media, tiktok, tiktok-api, tiktok-trends, trend-data, trendsmcp, viral

## 简介

TikTok hashtag volume over time via REST API. Weekly series, period-over-period growth, and live TikTok trending hashtags. No TikTok API approval needed. Powered by trendsmcp.ai
