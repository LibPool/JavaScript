# taskflow-mcp-core

> 标签: json-rpc, mcp, orchestration, subagents, taskflow, workflow

## 简介

Host-neutral MCP server for taskflow: a dependency-free stdio JSON-RPC server exposing the taskflow_* tools, plus the DAG SVG/outline renderer. Shared by the codex/claude/opencode/grok/hermes adapters — depends only on taskflow-core.
