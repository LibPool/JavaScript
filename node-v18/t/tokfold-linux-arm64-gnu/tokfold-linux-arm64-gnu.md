# tokfold-linux-arm64-gnu

> 标签: JavaScript

## 简介

Prebuilt tokfold binary for Linux on arm64 (glibc). Installed automatically as an optional dependency of the 'tokfold' package; there is no reason to depend on this directly.

## 官网

- 官网：https://github.com/IvanBBaev/tokfold
- 源码仓库：git+https://github.com/IvanBBaev/tokfold.git
- npm 页面：https://www.npmjs.com/package/tokfold-linux-arm64-gnu
