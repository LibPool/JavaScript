# tc-npm-mirror

> 标签: JavaScript

## 简介

安装后自动切换npm镜像到http://nexus.17usoft.com/repository/npm-all/，并提供命令行启用/禁用镜像。

## 官网

- npm 页面：https://www.npmjs.com/package/tc-npm-mirror

## 历史版本号

- 当前版本：1.0.0

- 1.0.0

## 获取地址

- npm 安装：`npm install tc-npm-mirror`
- npm registry：https://registry.npmjs.org/tc-npm-mirror
