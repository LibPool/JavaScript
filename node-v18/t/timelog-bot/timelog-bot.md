# timelog-bot

> 标签: JavaScript

## 简介

This is a simple tool to allow easier logging of time and hopefully more accurate detailed timelogs.   It presently requires: A. The specific XLSX timelog file (or one with identical cell structure/formatting). This is provided in both a 5-day and 15-day
