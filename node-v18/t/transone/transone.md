# transone

> 标签: component, cross-platform, framework, frontend, miniprogram, reactive, router, transpile, typescript

## 简介

TransOne 是跨端前端框架：一份 TypeScript 源码，编译期静态转换为 Web 与多端小程序原生产物，产物不携带框架运行时
