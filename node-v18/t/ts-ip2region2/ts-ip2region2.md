# ts-ip2region2

> 标签: geolocation, high-performance, ip-lookup, ip2region, ipv4, ipv6, native-addon, typescript, xdb

## 简介

TypeScript-first ip2region implementation with native Node.js addon. Ultra-fast IPv4/IPv6 geolocation queries.
