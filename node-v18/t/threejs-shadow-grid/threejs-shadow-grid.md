# threejs-shadow-grid

> 标签: 3d, background, glb, gltf, grid, shadow, stl, three.js, threejs, webgl

## 简介

A configurable, infinitely-tiling 3D object grid background for Three.js, with a mouse/touch-driven light that casts moving shadows.
