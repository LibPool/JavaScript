# timepicker-ui

> 标签: angular, css, customizable, design, javascript, lightweight, material, material-design, react, svelte, themeable, time-picker, timepicker, typescript, ui, vanillajs, vue

## 简介

timepicker-ui is a customizable time picker library built with TypeScript, inspired by Google's Material Design. Lightweight, themeable, and easy to integrate.
