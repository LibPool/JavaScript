# tap-react

> 标签: animated-ui, comment-reactions, emoji-reactions, facebook-reactions, feed-ui, framer-motion, interactive-ui, like-system, linkedin-reactions, micro-interactions, react, react-component, reaction-button, reaction-system, social-ui, tailwindcss, twitter-reactions, typescript, ui-library

## 简介

A highly customizable animated reaction system for React (like Facebook, LinkedIn, and X reactions). Built with React, TypeScript, and Framer Motion.
