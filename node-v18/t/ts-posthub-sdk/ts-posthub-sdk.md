# ts-posthub-sdk

> 标签: JavaScript

## 简介

TypeScript SDK для работы с PostHub API. Подходит для React (web) и Expo (mobile). Включает удобный REST API-клиент, типы и утилиты для аутентификации, управления пользователями, постами и лайками.
