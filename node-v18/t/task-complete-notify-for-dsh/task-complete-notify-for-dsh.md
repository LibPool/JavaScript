# task-complete-notify-for-dsh

> 标签: agent, chime, deepseek, deepseek-harness, desktop-notification, dsh, dsh-plugin, notification, notify, 插件, 桌面通知, 通知

## 简介

DSH plugin: desktop notification + chime when a run finishes. Notifies on completion, error, and approval requests, with a configurable duration threshold. / DSH 桌面通知插件：运行完成/出错/等待审批时提醒，可配置时长阈值与提示音。
