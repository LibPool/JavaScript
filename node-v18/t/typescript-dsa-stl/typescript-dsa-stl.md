# typescript-dsa-stl

> 标签: algorithms, binary-search, collections, data-structures, deque, double-ended-queue, dsa, graph, list, map, multimap, multiset, ordered-map, ordered-multimap, ordered-multiset, priority-queue, queue, sdk, set, stack, stl, typescript, unordered-map, vector

## 简介

STL-style data structures and algorithms for TypeScript: Vector, Stack, Queue, Deque (double-ended queue), List, PriorityQueue, Map, Set, sort, binarySearch, graph utilities. Use like C++ STL.
