# tar-iterator

> 标签: .tar, .tar.bz2, .tar.gz, .tar.xz, .tgz, Symbol.asyncIterator, asyncIterator, decompress, decompress-bz2, decompress-gz, decompress-tar, decompress-tgz, decompress-xz, extract, extract-bz2, extract-gz, extract-tar, extract-tgz, extract-xz, iterator, stream, tar, tar-stream, tar.bz2, tar.gz, tar.xz, tgz

## 简介

Extract contents from tar archive type using an iterator API using streams or paths. Use stream interface and pipe transforms to add decompression algorithms
