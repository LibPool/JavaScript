# terminalhire

> 标签: bounties, claude, claude-code, developer, job-matching, jobs, spinner, terminalhire

## 简介

Developer jobs and paid bounties, matched in the terminal — ambient matches in the Claude Code spinner. Claim a scoped bounty and get paid when the poster accepts it.
