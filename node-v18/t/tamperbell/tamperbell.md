# tamperbell

> 标签: baseline, claude-code, cli, config, integrity, mcp, security, tamper-detection, watcher

## 简介

Pins your Claude Code configs to a signed baseline and rings the moment anything tampers with them - with a risk-ranked MCP-aware diff, one-keypress restore, and an evidence receipt.
