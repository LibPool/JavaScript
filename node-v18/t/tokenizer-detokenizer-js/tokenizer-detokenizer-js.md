# tokenizer-detokenizer-js

> 标签: decoder, detokenizer, encoder, javascript, tokenizer, tokenizer-detokenizer-js, typescript, unicode

## 简介

A lightweight, object-oriented **tokenizer and detokenizer** library for JavaScript and TypeScript.   Works in **Node.js**, modern browsers, and via `<script>` tags.
