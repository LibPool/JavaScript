# tropic-browser-host

> 标签: browser, browserless, self-hosted, tropic

## 简介

Run Tropic's browser on your own machine, so agent sign-ins never cross the browser other Tropic users share.

## 官网

- 官网：https://tropic.bot
- npm 页面：https://www.npmjs.com/package/tropic-browser-host

## 历史版本号

- 当前版本：1.0.0

- 1.0.0

## 获取地址

- npm 安装：`npm install tropic-browser-host`
- npm registry：https://registry.npmjs.org/tropic-browser-host
- Node 要求：>=18
