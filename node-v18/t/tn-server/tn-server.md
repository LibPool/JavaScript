# tn-server

> 标签: JavaScript

## 简介

可以在任意目录下启动一个静态文件服务器，并且把当前目录 做为静态文件根目录 ``` tn-server  -d 指定静态文件根目录  -p 指定端口号  -o 指定监听的主机  ```
