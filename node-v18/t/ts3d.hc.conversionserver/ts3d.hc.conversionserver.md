# ts3d.hc.conversionserver

> 标签: JavaScript

## 简介

* Conversion Queue for multiple simultaneous CAD conversion jobs. * Multiple connected conversion queue machines can all pull jobs from the same queue. * S3 Storage option with direct S3 upload via tokens (optional). * Local Model Caching for Streaming
