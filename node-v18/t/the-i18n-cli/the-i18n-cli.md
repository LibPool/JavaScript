# the-i18n-cli

> 标签: cli, developer-tools, i18n, internationalization, l10n, laravel, locale, localization, nextjs, nuxt, react, translation, vue

## 简介

Find missing translations, remove dead keys, rename across all locales at once — for Nuxt, Laravel, Vue, React/Next.js, or any project with JSON/PHP locale files
