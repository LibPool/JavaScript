# tsl-material-graph

> 标签: material, node-editor, shader, shader-graph, three, threejs, tsl, vite-plugin, webgpu

## 简介

Visual node editor (Unity Shader Graph style) for Three.js TSL materials, with a runtime that loads graphs saved as JSON.

- npm 页面：https://www.npmjs.com/package/tsl-material-graph
