# terminalwatch

> 标签: bun, linux, monitoring, opentui, pty, shell, ssh, strace, sysadmin, terminal, tui, watch

## 简介

Live-mirror any logged-in user's terminal on a Linux server. Sysadmin TUI built with OpenTUI.
