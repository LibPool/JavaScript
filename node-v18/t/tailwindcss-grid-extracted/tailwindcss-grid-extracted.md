# tailwindcss-grid-extracted

> 标签: JavaScript

## 简介

Extracted grid and flex utilities from Tailwind CSS. Useful for projects that need to use Tailwind grid and flex utilities but don't want to include the entire library.

## 官网

- npm 页面：https://www.npmjs.com/package/tailwindcss-grid-extracted
