# three-envmap-helper

> 标签: JavaScript

## 简介

three-envmap-helper ======= Quickly add an HDR IBL envMap to your materials in a scene.  envMap and code pulled from [threejs webgl hdr environment map example](https://threejs.org/examples/webgl_materials_envmaps_hdr.html)
