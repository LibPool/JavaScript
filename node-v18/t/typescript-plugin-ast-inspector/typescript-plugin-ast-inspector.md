# typescript-plugin-ast-inspector

> 标签: TypeScript, TypeScript Language Service, plugin

## 简介

TypeScript Language Service plugin with tools oriented to TypeScript developers, most important is one that let evaluate code in the editor itself for faster understanding of AST and plugin prototyping.
