# terra-enzyme-intl

> 标签: Cerner, Terra, enzyme, i18n, intl, jest, react, react-intl, terra-enzyme-intl

## 简介

Enzyme helpers for fortifying tests that depend on react-intl by decoupling the need for actual translations.
