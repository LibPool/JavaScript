# tooltip-js

> 标签: angular tooltip, js tooltip, react tooltip, tooltip, tooltip js

## 简介

Easily implement tooltips using minimal javascript. Supports Meteor, AngularJS, React, Polymer and any CSS library, e.g. Bootstrap.
