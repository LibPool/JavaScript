# tanuki-context

> 标签: anthropic, claude, compression, context, context-window, cost-optimization, gemini, llm, logs, mcp, model-context-protocol, openai, proxy, pxpipe, token-savings, tokens

## 简介

Cut 79-91% of the input tokens your logs and command output cost. MCP server or drop-in proxy: park bytes outside the conversation, fetch exact slices, draw a slice as dense PNG pages when that is cheaper - and it says when plain text is cheaper instead.
