# trodomcp

> 标签: analytics, claude, cursor, mcp, model-context-protocol, stdio, trodo

## 简介

Stdio wrapper for Trodo's MCP server. Lets Claude Code CLI, Cursor, MCP Inspector and any stdio MCP client connect to mcp.trodo.ai with a direct API key.

## 官网

- 官网：https://docs.trodo.ai/mcp
- 源码仓库：git+https://github.com/trodoai/app.git
- npm 页面：https://www.npmjs.com/package/trodomcp
