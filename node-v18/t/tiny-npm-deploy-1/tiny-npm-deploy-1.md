# tiny-npm-deploy-1

> 标签: JavaScript

## 简介

1. make sure our package name is unique 2. specify which files should be sent to NPM when we publish 3. split dependencies and devDependencies 4. set package to be publicly accessible 5. if building CLI, configure the file to run 6. add prePublish sc
