# tkjs-route

> 标签: JavaScript

## 简介

tkjs-route is a mini-framework that provides a simple opinionated API to build a backend on top of express. It provides the facilities to build static & dynamic websites, GRAPHQL APIS, REST APIs and simple ACL management.
