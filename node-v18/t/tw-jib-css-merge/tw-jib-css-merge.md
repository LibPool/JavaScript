# tw-jib-css-merge

> 标签: tailwind, tailwind-merge, tailwindcss, tw-jib-css, twmerge

## 简介

tailwind-merge config for tw-jib-css and tw-jib-css-experimental, so twMerge keeps jib classes that compose and resolves the ones that conflict.
