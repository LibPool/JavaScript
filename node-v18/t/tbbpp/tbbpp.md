# tbbpp

> 标签: JavaScript

## 简介

This is a pp calculator that is fully implemented with Javascript for the new delta_t algorithm. This was primarily made for [The Beautiful Bot](https://github.com/moorad/the-beautiful-bot) but I thought it would be a good idea to make it its own package
