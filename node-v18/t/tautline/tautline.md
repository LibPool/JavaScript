# tautline

> 标签: agents, ai, claude, codex, delivery, framework, governance

## 简介

Tautline - the governor for AI coding agents. Enforced completion gates, per-project adapters, and lifecycle guards for AI-driven delivery. Tautline is a Python CLI: install it with pipx install tautline.
