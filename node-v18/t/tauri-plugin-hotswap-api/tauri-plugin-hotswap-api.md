# tauri-plugin-hotswap-api

> 标签: hot-reload, hotswap, ota, tauri, tauri-plugin, update

## 简介

Open-source OTA frontend updates for Tauri v2 apps. Self-hosted, signed bundles, auto-rollback, runtime channels.
