# twinkle-sdk

> 标签: ai-agents, crypto, ethereum, gasless, mnee, payments, permit2, stablecoin, usdc, x402

## 简介

Gasless payments for AI agents using MNEE. SDK for the x402 protocol with USDC-to-MNEE bridge support.
