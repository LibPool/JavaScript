# turbine-orm

> 标签: database, json-agg, nested-queries, orm, postgres, postgresql, prisma-alternative, query-builder, sql, turbine, typescript

## 简介

Postgres-native TypeScript ORM, runs on Neon, Vercel Postgres, Cloudflare, Supabase. Streaming cursors, typed errors, single-query nested relations. One dependency, no WASM engine
