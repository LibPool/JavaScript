# ts-sql-query

> 标签: jooq, linq, mariadb, mysql, oracle, orm, postgre sql, postgresql, query, query builder, querydsl, sql, sql server, sql-server, sqlite, sqlserver, type safe sql, type sql, type-safe sql, type-sql, typesafe sql, typescript, typesql

## 简介

Type-safe SQL query builder like QueryDSL or JOOQ in Java or Linq in .Net for TypeScript with MariaDB, MySql, Oracle, PostgreSql, Sqlite and SqlServer support.
