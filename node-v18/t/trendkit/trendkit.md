# trendkit

> 标签: candlestick, charts, drawing-tools, fibonacci, finance, lightweight-charts, technical-analysis, trading, trendline

## 简介

Drawing tools and indicators for TradingView's Lightweight Charts — trendlines, rays, Fibonacci, zones and a measure tool, built on the v5 plugin API.
