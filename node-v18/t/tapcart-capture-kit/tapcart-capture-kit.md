# tapcart-capture-kit

> 标签: JavaScript

## 简介

Tapcart Capture Kit is a suite of self-contained web applications / widgets that can be used to add functionality to a Merchant's Shopify store. These tools are used for funneling web and mobile web consumers into our Merchants' native mobile apps.
