# tinylrs

> 标签: autoreload, browser page, cmd R, command line, f5, livereload, no browser extension, refresh, separate tiny, server, watch files, websocket

## 简介

A tiny server that watch files changed and refresh browser page,via livereload.js and websocket,based on tiny-lr
