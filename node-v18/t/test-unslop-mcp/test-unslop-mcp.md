# test-unslop-mcp

> 标签: anti-slop, antigravity, claude, codex, go-test, jest, junit, mcp, model-context-protocol, pytest, skill, test-quality, testing, tests, unit-test, vitest, xctest

## 简介

MCP server + agent skill that catches fake and fragile AI-written tests (no assertions, tautologies, swallowed failures, .only, sleeps, snapshot-only, mock-heavy), runs the real test runner and flags zero-test runs. JS/TS, Python, Go, Swift, Kotlin/Java.
