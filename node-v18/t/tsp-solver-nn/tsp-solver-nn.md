# tsp-solver-nn

> 标签: 2-opt, 3-opt, nearest-neighbor, travelling-salesman-problem, tsp

## 简介

A Typescript implementation of the Nearest Neighbor with 2-opt and 3-opt optimizations to solve the travelling salesman problem (TSP).
