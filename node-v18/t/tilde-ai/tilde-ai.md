# tilde-ai

> 标签: ai, identity, mcp, mcp-server, profile

## 简介

Your AI agents' home directory — privacy-first MCP server for portable AI identity. Configure once, use everywhere. Supports profile management, skills, resume import, and team sync. A thin wrapper to run the tilde MCP server via Python/uv
