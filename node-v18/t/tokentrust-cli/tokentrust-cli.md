# tokentrust-cli

> 标签: ai-coding-agent, benchmark, cli, context-window, llm-cost, mcp, model-context-protocol, regression-testing, token-reduction, tokenizer, typescript, verification

## 简介

Vendor-neutral CLI and MCP server that verifies the token and cost savings AI-coding-agent context-reduction proxies (rtk, headroom) actually deliver, measured against a real 23-task labeled corpus with a local tokenizer instead of the proxy's own claimed
