# tiny-string-tools

> 标签: capitalize, clean-spaces, get-initials, mask-text, slugify, string, string-manipulation, truncate, typescript, utility, utils, validation

## 简介

A lightweight, zero-dependency, highly optimized utility library for common string manipulations like slugify, truncate, capitalize, and text masking.
