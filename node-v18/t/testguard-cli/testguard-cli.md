# testguard-cli

> 标签: ai-agents, claim-verification, claims, fault-injection, github-actions, mutation-testing, quality-gate, test-generation, test-quality, testing, verification, vitest

## 简介

Breaks your code on purpose and reports every promise your tests did not notice breaking. Mutation testing bound to the claims a project makes — vitest, jest, Playwright, pytest and unittest.
