# toto-the-cat

> 标签: cat, deepseek-harness, desktop-pet, dsh, dsh-plugin, pet, plugin, pomodoro, toto, web-ui

## 简介

托托（Toto）桌宠 —— DeepSeek Harness Web 界面里的一只小猫。自定义像素画/立绘外观、番茄闹钟、经验等级成长、有关托托的30个事实解锁。零依赖、零构建。
