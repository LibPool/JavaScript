# tewip-ai

> 标签: ai-agent, ci, devops, flaky-tests, github-action, jest, junit, mcp, playwright, pytest, qa, root-cause, sdet, test-automation, test-failures, triage, vitest

## 简介

Tewip finds why each failing test failed - real bug, flaky test, environment, test data or changed selector - for any stack, from the command line, CI, or your editor.
