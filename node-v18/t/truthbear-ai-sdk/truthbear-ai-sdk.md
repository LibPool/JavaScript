# truthbear-ai-sdk

> 标签: ai-sdk, mcp, official-data, provenance, tools, vercel-ai-sdk, verification, x402

## 简介

Official-source records for AI agents: source URL, an offline-recomputable record_hash, freshness and a did:key signature. Free lookups need no key; the paid tool returns a live x402 payment challenge and never charges silently.
