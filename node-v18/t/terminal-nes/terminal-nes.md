# terminal-nes

> 标签: cli, emulator, iterm2, kitty-graphics, nes, retro, terminal-game, tui, vue-tui

## 简介

🎮 Real NES emulator in your terminal — jsnes core, pixel-perfect 256×224 frames via kitty/iTerm2 graphics, keyboard → NES controller, share-to-X with screenshot.
