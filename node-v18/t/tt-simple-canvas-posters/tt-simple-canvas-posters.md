# tt-simple-canvas-posters

> 标签: canvas, posters, share, simple, tt

## 简介

一款用 canvas 绘制朋友圈分享海报的简单工具，优点支持相对位置布局，无需计算绝对位置，会根据相对图层的位置改变布局。目前仅支持字节小程序，可在 mpvue, nui-app 中使用
