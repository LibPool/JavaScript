# tj-vue2-tools

> 标签: base64加密, base64原生对象, base64解密, tj-avue-local-option组件, tj-vue2-tools, 下载excel数据[blob]到文件, 下载图片, 下载数据[blob]到文件, 下载文件, 保存avue自定义配置, 加载avue自定义配置, 工具集, 模拟sleep()方法, 设置avue-column（非）必填, 还原/重置avue自定义配置

## 简介

tj-vue2-tools，vue通用插件库（包含类、方法及组件），类用$***调用，方法用$***()调用，组件用<tj-***></tj-***>调用，所依赖的插件库根据调用情况引入，不是必要条件
