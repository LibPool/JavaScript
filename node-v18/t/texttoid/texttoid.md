# texttoid

> 标签: auto increment, autoincrement, benzersiz id, benzersiz numara, kelimelerden benzersiz numara oluşturma, sentences to id, sentences to number, string to id, string to number, text to id, text to number, unique id

## 简介

This module convert a text to unique id. Unique ID is autoincrement number. It return always the same number for the same text. Only for Nodejs
