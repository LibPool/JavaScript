# tokentelemetry

> 标签: claude, claude-code, dashboard, observability, telemetry

## 简介

Install and run the Claude Telemetry Enterprise console (local FastAPI backend + React dashboard, with Claude Code hook wiring) as a global tool on Windows, macOS, and Linux.
