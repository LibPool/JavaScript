# transparentcars-mcp

> 标签: automotive, budget-cars, cars, mcp, model-context-protocol, portugal, used-cars

## 简介

MCP server for TransparentCars — search budget used cars in Portugal, check whether an asking price is fair, estimate a car's yearly running cost, and get in touch. Thin wrapper over the public transparent.pt API.
