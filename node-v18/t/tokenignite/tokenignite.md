# tokenignite

> 标签: cli, continuous-injection, css-custom-properties, css-variables, design-system, design-tokens, figma, figma-plugin, figma-variables, human-in-the-loop, live-sync, runtime-validation, token-sync, tokenignite

## 简介

Stream Figma variables as live CSS custom properties into your running app — validate design tokens without rebuilds, then export native CSS. Continuous Injection for design systems.
