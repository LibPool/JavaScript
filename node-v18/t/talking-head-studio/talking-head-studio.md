# talking-head-studio

> 标签: 3d, accessories, audio-recording, avatar, avatar-editor, cross-platform, expo, face-tracking, gesture, gizmo, glb, lip-sync, lipsync, llm, motion, react-native, react-three-fiber, self-hosted, talking-head, threejs, tts, voice, webview

## 简介

Cross-platform 3D avatar component for React Native & web — lip-sync, gestures, accessories, and LLM integration. Powered by TalkingHead + Three.js.
