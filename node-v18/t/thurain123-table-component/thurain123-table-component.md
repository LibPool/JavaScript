# thurain123-table-component

> 标签: component, framer-motion, pagination, react, react-table, sorting, table, tanstack-table, thurain, ui-component

## 简介

A customizable and reusable React table component with features like sorting, pagination, and expandable rows. Built with React Table (TanStack Table), Framer Motion, and Rollup.
