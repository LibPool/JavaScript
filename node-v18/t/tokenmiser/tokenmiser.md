> 标签: ai, anthropic, claude, claude-code, codebase-index, context, developer-tools, token-optimizer, tokens

## 简介

Slash Claude Code token usage by 40–70%. Generates a compact codebase index, smart ignore rules, and optimized CLAUDE.md — so Claude navigates straight to the right file instead of reading everything.
