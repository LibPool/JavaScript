# turbium

> 标签: axios, brotli, circuit-breaker, client, compression, connection-pooling, deflate, dns-cache, efficient, es-modules, esm, fast, fetch, gzip, http, http2, http2-client, javascript, node, nodejs, performance, pooling, stream, streaming

## 简介

A fast and efficient HTTP/2 client library for Node.js with built-in connection pooling, DNS caching, circuit breaker, and request/response compression.
