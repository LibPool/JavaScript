# ts-aes-cbc

> 标签: aes, aes-cbc, cbc, cryptography, fips197, sp800-38a, typescript

## 简介

TypeScript port of WjCryptLib's AES-CBC (NIST SP 800-38A §F.2). AES-128/192/256.
