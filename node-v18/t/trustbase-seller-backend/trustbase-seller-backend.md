# trustbase-seller-backend

> 标签: cosmos, insurance, marketplace, seller, trustbase, trustchain

## 简介

TrustBase Seller Backend (merchant edition) — 商品上链/订单/支付/质押 write API for TrustBase 保障链生态. 单卖家自托管形态: 签名 key 即卖家身份, 私钥不出门.
