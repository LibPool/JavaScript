# typespec-openapi-document

> 标签: documentation, openapi, openapi3, scalar, swagger, typespec, typespec-emitter

## 简介

TypeSpec emitter: export the OpenAPI document @typespec/openapi3 writes as a typed module, with the import resolved for you, framework-agnostic, so you can serve it from anything.
