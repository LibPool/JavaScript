# tcsl-websocket-framework

> 标签: JavaScript

## 简介

一个基于typescript封装websocket的业务SDK，重点是简单性、可靠性和可扩展性。主要目的是保证web客户端和服务端的连接，具有心跳检测和自动重连机制。当客户端设备出现网络中断或服务器错误导致websocket断开连接时，程序将自动重新连接，直到重新连接成功。
