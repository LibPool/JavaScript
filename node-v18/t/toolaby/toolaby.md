# toolaby

> 标签: chrome-extension, cli, licensing, toolaby

## 简介

The Toolaby command line: sign in once, then wire any Chrome extension to your tool on the Wall — sign-in, the Free plan, licences and subscriptions — or start a new one; check it, and give coding agents the Wall as an MCP server.
