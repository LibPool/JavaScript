# terminal-bridge-setup

> 标签: agent, arthas, bridge, chrome-extension, jumpserver, native-messaging, terminal, xterm

## 简介

一次性安装器：释放终端桥接（JumpServer / Arthas / Yearning）的本地代理 + Chrome 插件，并注册 native messaging host。让 Agent 能通过浏览器 xterm 终端执行命令并拿回输出。
