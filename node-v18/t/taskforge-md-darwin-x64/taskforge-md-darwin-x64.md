# taskforge-md-darwin-x64

> 标签: JavaScript

## 简介

taskforge CLI binary — macOS (universal2: arm64 + x64 in one Mach-O; this package installs on x64 hosts). Same binary as taskforge-md-darwin-arm64 — lipo already fused both slices, npm's os/cpu gating just needs a package per arch.
