# tesseractdb

> 标签: JavaScript

## 简介

Authenticated, peer-to-peer data synchronization, powered by [`PouchDB`][PouchDB], [`webrtc-explorer`][WebRTC], and [`OpenPGP.js`][OpenPGP].
