# typeorm-postgrejs

> 标签: no-native-bindings, node-postgres, orm, pg, pg-compatible, postgrejs, postgres, postgresql, sql, typeorm, typeorm-driver, typescript, wire-protocol

## 简介

A pg-compatible facade over PostgreJS - run TypeORM on PostgreJS's wire-protocol client instead of pg

- npm 页面：https://www.npmjs.com/package/typeorm-postgrejs
