# ts-morph-readonly-mcp

> 标签: find-references, mcp, model-context-protocol, monorepo, nx, pnpm, read-only, ts-morph, typescript

## 简介

Read-only MCP server for cross-package TypeScript symbol traversal in Nx/pnpm monorepos, via ts-morph.
