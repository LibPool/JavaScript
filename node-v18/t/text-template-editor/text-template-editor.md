# text-template-editor

> 标签: JavaScript

## 简介

用途：在低代码平台中需要有编辑字符串模版，例如一个字符串部分是静态字符串，一部分是由数据库中字段的值替换，下图的例子中，我们编辑了一个字符串模版，并把这个字符串模版翻译成了最后的实际值
