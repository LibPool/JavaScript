# tessyn

> 标签: claude-code, daemon, developer-tools, search, session-management, sqlite, workflow

## 简介

Background daemon that indexes Claude Code sessions into searchable SQLite with full-text search. Cross-session search, session history, and CLI for developer workflow tools.
