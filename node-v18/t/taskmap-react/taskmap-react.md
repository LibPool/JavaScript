# taskmap-react

> 标签: JavaScript

## 简介

Este é um projeto de um todo list (lista de tarefas) desenvolvido com React, Node e MongoDB, desenvolvido para funcionar como uma forma de ajudar os usuários finais com as suas tarefas, onde coloquei meus conhecimentos em React, Node e MongoDB em prática
