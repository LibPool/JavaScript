# tape-six-puppeteer

> 标签: browser, bun, chrome, chromium, cross-runtime, deno, es-modules, esm, firefox, harness, headless, iframe, nodejs, parallel, puppeteer, tap, tape-six, tape6, test, test-runner, testing, unit-test

## 简介

Puppeteer-based browser test runner for tape-six. Runs each test file in its own browser context (Chromium or Firefox). Works with Node, Deno, and Bun.
