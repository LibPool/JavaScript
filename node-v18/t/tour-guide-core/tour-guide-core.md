# tour-guide-core

> 标签: guide, javascript, onboarding, product-tour, spotlight, tooltip, tour, vanilla, walkthrough

## 简介

Framework-agnostic step-by-step product tour / onboarding guide: spotlight, popover, keyboard navigation. Zero dependencies. Works with plain JS; powers tour-guide-react and ngx-tour-guide.
