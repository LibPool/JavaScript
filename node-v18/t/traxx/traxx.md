# traxx

> 标签: alerts, analytics, bullmq, express, google-chat, logging, metrics, middleware, mongoose, monitoring, notifications, observability, performance, redis, routes, slack, teams, tracing, traxx

## 简介

Asynchronous route-level analytics for Express.js. Tracks latency, request data, and errors. Supports notifications via Teams, Slack, and Google Chat. MongoDB + BullMQ + Redis.
