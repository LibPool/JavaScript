# typeorm-test-factory

> 标签: e2e, factory, factory-bot, fixtures, integration-test, seed, seeding, test-data, testing, typeorm

## 简介

Version-safe test data factories for TypeORM. Define factories once, create realistic entities in integration and e2e tests — without coupling to a specific TypeORM version.
