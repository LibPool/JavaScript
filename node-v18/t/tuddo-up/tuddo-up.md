# tuddo-up

> 标签: agent, cli, installer, tuddo

## 简介

One-command Tuddo agent installer: downloads, installs, and connects the CLI + gateway daemon to an Tuddo server.

## 官网

- npm 页面：https://www.npmjs.com/package/tuddo-up

## 历史版本号

- 当前版本：0.1.0

- 0.1.0

## 获取地址

- npm 安装：`npm install tuddo-up`
- npm registry：https://registry.npmjs.org/tuddo-up
- Node 要求：>=18
