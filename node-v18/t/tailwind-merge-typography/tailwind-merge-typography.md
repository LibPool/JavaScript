# tailwind-merge-typography

> 标签: clsx, cn, plugin, prose, tailwind, tailwind-merge, tailwindcss, twmerge, typography

## 简介

A tailwind-merge plugin that teaches twMerge to resolve @tailwindcss/typography prose-* conflicts.
