# tokendamper-deep

> 标签: context-optimization, token-reduction, tokendamper, tree-sitter

## 简介

Deep mode for TokenDamper: tree-sitter (WASM) parser backends. C and C# reduce only through it; it also answers for TypeScript, Python and Go.
