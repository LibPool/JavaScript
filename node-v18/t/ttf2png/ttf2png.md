# ttf2png

> 标签: JavaScript

## 简介

把ttf文件中的每个字(或者是某几个字)转成某个宽度的png格式图片

## 官网

- 官网：https://github.com/Kuaizr/ttf2png#readme
- 源码仓库：git+https://github.com/Kuaizr/ttf2png.git
- npm 页面：https://www.npmjs.com/package/ttf2png
