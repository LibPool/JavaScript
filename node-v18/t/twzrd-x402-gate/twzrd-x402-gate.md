# twzrd-x402-gate

> 标签: agent, blockrun, clawrouter, mcp, preflight, readiness-card, solana, trust, twzrd, usdc, x402

## 简介

Core: buyer-side x402 trust gate. Free TWZRD preflight (ReadinessCard) before signing USDC to any merchant, with optional $0.001 paid trust escalate on warn — blocking spend on bad intel, no human in the loop. Optional: createTwzrdSettleGuard for resource
