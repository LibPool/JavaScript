# trimhook

> 标签: claude-code, codex, context-engineering, hooks, plugin, token-efficiency, tool-output, truncation

## 简介

Tool output trimmed at the source: a PostToolUse hook for Claude Code and Codex CLI that keeps the head and tail of a long shell result, spills the whole of it to a file the model can read, and reports what it saved.
