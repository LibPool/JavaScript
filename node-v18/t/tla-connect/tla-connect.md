# tla-connect

> 标签: apalache, formal-methods, itf, mbt, model-based-testing, model-checking, state-machine, testing, tla, tla+

## 简介

Model-based testing with Apalache TLA+ model checker - generate ITF traces, replay against JS drivers, detect state divergence.
