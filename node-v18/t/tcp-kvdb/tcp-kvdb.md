# tcp-kvdb

> 标签: database, key-value, kv, tcp, typescript

## 简介

A lightweight TCP-based Key-Value database built in TypeScript. It supports basic commands like `SET`, `GET`, `DELETE`, and `LIST`, with automatic JSON file persistence.
