# tsyntax

> 标签: dsl, parsing, runtime-validation, template-literals, type-level, type-safe, typescript, validation

## 简介

A lightweight ~13 KB parser for scalar TypeScript-syntax DSL strings, validated at the type level and at runtime - one string, two walls
