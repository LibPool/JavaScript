# ts-analyzer

> 标签: analyzer, angular, ast-analyzer, code-quality, code-smells, complexity, cyclomatic-complexity, duplicate-code-detector, node, react, static-analysis, ts, type-coverage, type-safety, typescript, typescript-metrics, vue

## 简介

Static code analyzer for TypeScript and JavaScript. Measures type coverage, type safety score, cyclomatic complexity, duplicate code, and detects code smells / anti-patterns.
