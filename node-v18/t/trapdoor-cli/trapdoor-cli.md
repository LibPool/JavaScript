# trapdoor-cli

> 标签: cli, debug, debugging, http, inspector, localhost, ngrok, request-bin, shopify, stripe, tunnel, webhook, webhooks

## 简介

Catch and inspect HTTP requests from your terminal, and forward them to localhost. A webhook debugger you can npx.
