# telegraf-ecosystem

> 标签: bot, bot framework, botapi, telegraf, telegraf-ecosystem, telegram, telegram bot api

## 简介

Фреймворк созданный на основе Nest.js/Typescript/Awilix для тех, кто хочет писать расширяемых telegraf ботов. В исходном коде вы найдете паттерны, конструкции и поведенческие паттерны с объяснениями
