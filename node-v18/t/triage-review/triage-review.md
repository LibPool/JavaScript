# triage-review

> 标签: cli, code-review, developer-tools, diff, git, pull-request, risk, static-analysis, triage

## 简介

A risk-ranking pre-reviewer for git diffs. Instead of adding more review noise, it tells a human the exact order to read a diff — must-read vs. safe-to-skim — using blast radius, bug-fix history, test-coverage gaps, change complexity, and sensitive-path d
