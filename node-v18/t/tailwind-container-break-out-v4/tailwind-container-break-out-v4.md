# tailwind-container-break-out-v4

> 标签: break-out, container, full-bleed, margins, pull, tailwind, tailwindcss, tailwindcss-plugin

## 简介

A TailwindCSS v4 (and v3) compatible plugin for breaking child elements out of a `.container`. Fork of tailwind-container-break-out, fixed for v4's stricter utility-selector rules.
