# tribunal

> 标签: ai, ai-safety, audit, claude-code, code-review, codex, copilot, cursor, devops, governance, secret-scanning, tdd, tribunal

## 简介

Quality gates for AI-generated code -- TDD enforcement, secret scanning, and audit trails for coding agents. v3 is Python-first; this npm package is a cross-platform launcher that installs and runs the official Python CLI.
