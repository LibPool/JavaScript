# tsvue-dts

> 标签: JavaScript

## 简介

这是一个基于 `ts-morph` 和 `@vue/compiler-sfc` 的工具，用于从 Vue 3 项目中自动提取和生成 TypeScript 类型声明文件。该工具能够解析 Vue 单文件组件（SFC）中的 `<script setup>` 语法，提取 Props、Emits 等类型信息，支持提取非vue的ts类型，并生成统一的类型声明文件。
