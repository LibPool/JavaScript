# text-to-speech-tts

> 标签: a11y, accessibility, atlasvoice, audio, speech-synthesis, speechSynthesis, text-to-speech, tts, voice, web-speech-api

## 简介

A standalone JavaScript SDK for adding text-to-speech to any website using the browser's built-in speechSynthesis API.
