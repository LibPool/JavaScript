# tocsystems-detector-mcp

> 标签: mcp, modelcontextprotocol, opencode, skills, upconta

## 简介

MCP que detecta proyectos TocSystems en rutas configurables y sincroniza el skill upconta desde un repo git privado vía SSH (sin tokens).
