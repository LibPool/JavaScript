# tabby-router-event-highlight

> 标签: cisco, error-highlight, highlight, huawei, juniper, router-console, router-event-highlight, tabby-plugin

## 简介

Tabby terminal plugin to highlight router console events: 'Error:' in red, 'UP' in green, and 'DOWN' in orange
