# tls-certificate-transparency-log-alerter

> 标签: TLS, cert, certificate, logs, tls, transparency, transparency logs, x509

## 简介

A super simple program to check TLS certificate transparency logs for one or more domain name patterns and alert on new or unexpected certificates
