# triepack

> 标签: binary-format, compression, dictionary, key-value, prefix-search, prefix-tree, serialization, trie, triepack, trp

## 简介

Compressed trie dictionary format (.trp) — compact binary key-value storage with fast lookups and prefix search. Native JavaScript implementation, no dependencies.
