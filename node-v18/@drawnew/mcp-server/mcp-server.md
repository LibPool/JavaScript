# @drawnew/mcp-server

> 标签: agent, ai, claude, drawnew, image-generation, mcp, model-context-protocol

## 简介

MCP server for DrawNew AI image generation. Exposes generate_image / get_task / batch_get_tasks tools to any MCP-compatible LLM agent (Claude Desktop, Cursor, Cline, …).

- 官网：https://drawnew.com/?tab=api
