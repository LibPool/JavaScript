# dsh-prompt-enhance-cn

> 标签: deepseek-harness, dsh, dsh-plugin, prompt, prompt-engineering, prompt-enhancement, tiers

## 简介

Four-tier prompt enhancement for the dsh web GUI: base / standard / professional / system. Rewrites the composer draft through the harness LLM service, previews or fills back in place, and always keeps the original draft recoverable.
