# @pyde-net/host

> 标签: assemblyscript, blockchain, borsh, contract, pyde, wasm

## 简介

The AssemblyScript SDK for Pyde contracts: the full pyde::* host ABI plus pointer-free ergonomic wrappers — LE codecs, 128-bit math, borsh, ctx/calldata/exit/hash, and factory child-address helpers.
