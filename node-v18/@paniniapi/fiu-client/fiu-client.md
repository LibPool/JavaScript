# @paniniapi/fiu-client

> 标签: account-aggregator, dpi, fintech, fiu, india, open-finance, rebit, sahamati

## 简介

Open, zero-dependency FIU client for India's Account Aggregator ecosystem — consent lifecycle, X25519/ECDH key exchange, AES-256-GCM FI decryption per the ReBIT spec, multi-AA handle routing and bounded fan-out orchestration, and schema validation. Inject
