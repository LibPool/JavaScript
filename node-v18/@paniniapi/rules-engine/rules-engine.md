# @paniniapi/rules-engine

> 标签: account-aggregator, fintech, india, normalization, ocen, parsing, upi

## 简介

Community-extendable JSON grammar sets for Indian bank narration formats — 14 banks plus generic archetypes, entity dictionaries, and a corpus coverage gate.
