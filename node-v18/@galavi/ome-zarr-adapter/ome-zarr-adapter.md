# @galavi/ome-zarr-adapter

> 标签: galavi, microscopy, ome-zarr, visualization, webgpu, zarr

## 简介

OME-Zarr adapter for Galavi: opens OME-Zarr stores via zarrita and exposes a Galavi-compatible tile source.
