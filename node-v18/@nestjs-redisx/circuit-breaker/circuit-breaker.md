# @nestjs-redisx/circuit-breaker

> 标签: circuit-breaker, fault-tolerance, half-open, nestjs, redis, resilience, state-machine

## 简介

Distributed circuit breaker plugin for NestJS RedisX (closed/open/half-open) with a pure, time-injected state machine core
