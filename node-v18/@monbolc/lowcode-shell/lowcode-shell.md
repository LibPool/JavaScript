# @monbolc/lowcode-shell

> 标签: engine, facade, lowcode, plugin, shell

## 简介

SapuLowcodeEngine shell — the host-facing facade (L6). Sapu stance: no proxies, no deprecation layer. Plugins get a plain object with the engine + workspace + project references. ~790 lines vs upstream 5,155 (~85% smaller).
