# @intyga/sdk

> 标签: ai-agents, audit, authorization, human-approval, mcp, passkey, receipts, webauthn

## 简介

INTYGA SDK — require a cryptographically-signed human approval for any high-risk backend action (AI agents, humans, services), with zero-knowledge policy encryption.
