# @lunar-adk/storage-unknown-planet

> 标签: JavaScript

## 简介

`@lunar-adk/storage-unknown-planet` implements Lunar's `StorageBundle` with a scoped Unknown Planet `Planet` client. Its SQL capability must use PostgreSQL transactions.
