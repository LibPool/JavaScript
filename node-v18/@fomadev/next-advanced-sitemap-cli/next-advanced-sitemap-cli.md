# @fomadev/next-advanced-sitemap-cli

> 标签: ci, cli, link-checker, nextjs, seo, sitemap

## 简介

CI-friendly command-line sitemap checker for next-advanced-sitemap: validates schema, catches broken (404/5xx) links, and reports file size — designed to fail your build before Google ever sees a broken sitemap.
