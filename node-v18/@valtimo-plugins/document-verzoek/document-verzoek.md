# @valtimo-plugins/document-verzoek

> 标签: JavaScript

## 简介

Angular admin-UI library for the **Document Verzoek** GZAC/Valtimo plugin. It contributes the plugin's configuration screen to the Valtimo admin console so an administrator can create and manage `document-verzoek` plugin configurations.
