# @underscode/react-pdf-previewer

> 标签: headless, pdf, pdf-preview, pdf-viewer, pdfjs, previewer, react, react-pdf, typescript

## 简介

A headless-first React PDF previewer: unstyled hooks plus a themeable, dependency-light UI that works with or without Tailwind.
