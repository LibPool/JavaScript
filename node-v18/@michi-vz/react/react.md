# @michi-vz/react

> 标签: a11y, accessibility, ai, canvas, charting, charting-library, charts, d3, data-visualization, dataviz, framework-agnostic, graph, llm, llm-ready, mcp, michi-vz, react, react-charts, react-component, reactjs, responsive, svg, typescript, visualization, webgpu

## 简介

React charts - SVG, canvas & WebGPU rendering, accessible by default, with an LLM-ready data context. Thin wrapper over the framework-agnostic @michi-vz engine.
