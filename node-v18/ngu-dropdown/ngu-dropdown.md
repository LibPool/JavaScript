# ngu-dropdown

> 标签: angular, combobox, dropdown, pagination, select, server-side, signal-forms, virtual-scroll

## 简介

An Angular select that pages through the server as you scroll: search, virtual scrolling over the whole result set, and one fetchFn instead of loading logic in every component.
