# @vidge-ai/vidgedb

> 标签: agent, database, digital-twin, graph, industrial, json-rpc, time-series, vidgedb

## 简介

JavaScript/TypeScript client for VidgeDB — drive the `vidgedb --service` JSON-RPC subprocess from Node. Zero runtime dependencies (ESM + CJS, typed).
