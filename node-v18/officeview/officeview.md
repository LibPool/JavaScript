# officeview

> 标签: canvas, docx, office-documents, ooxml, pptx, react, xlsx

## 简介

React components that render Office documents (Word, PowerPoint, Excel) on <canvas> — pixel-faithful, not HTML translation. Works on desktop and mobile.
