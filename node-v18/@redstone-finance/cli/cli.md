# @redstone-finance/cli

> 标签: JavaScript

## 简介

RedStone CLI is a tool that helps to deploy all necessary contracts for the [RedStone Push Model](https://docs.redstone.finance/docs/dapps/redstone-push/) and run the relayer responsible for pushing prices on-chain
