# dsh-model-status

> 标签: JavaScript

## 简介

模型连通状态指示灯：在聊天框模型选择器旁实时显示当前所选模型是否连通（已连通/异常/不可用/检测中），基于产品自身的模型目录与路由状态，纯客户端实现。
