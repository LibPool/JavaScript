# real-vibe-coding

> 标签: midi, music, pi, pi-coding-agent, pi-extension, pi-package, tui

## 简介

A Pi extension that performs the agent's output — prose, reasoning and tool text alike — in time with MIDI music: a beat-synced stage panel, a look-ahead print queue, and a pluggable audio backend.
