# fast-sorted-set

> 标签: gaming-leaderboard, in-memory, leaderboard, priority-queue, ranking, redis, skiplist, sorted-set, system-design, typescript, zset

## 简介

Production-grade, zero-dependency in-memory Sorted Set engine for Node.js and TypeScript. Powered by Redis-style SkipList with Span pointers for O(log N) rank operations, real-time gaming leaderboards, and priority queuing.
