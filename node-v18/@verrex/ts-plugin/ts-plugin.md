# @verrex/ts-plugin

> 标签: effect, language-service-plugin, typescript, verrex, volar, vx

## 简介

Volar-based TypeScript Language Service plugin for .vx files — diagnostics, hover, go-to-definition, find-references, inlay hints, and JSX tag-pair highlights.
