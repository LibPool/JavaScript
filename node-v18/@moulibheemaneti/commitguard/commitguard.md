# @moulibheemaneti/commitguard

> 标签: cli, commit-msg, developer-tools, git, git-hooks, husky, lefthook, pre-commit

## 简介

A CLI tool to manage Git hooks (pre-commit, commit-msg, pre-push) in any Node.js / JS / TS project. Similar to husky and lefthook.
