# @factumono/sdk

> 标签: afip, arca, argentina, cuit, factumono, factura-electronica, monotributo

## 简介

Build a Factumono Voucher URL: a link that opens the create-comprobante screen prefilled from your own system. Typed, validated against ARCA's real rules, two dependencies.
