# @qlover/tailwind-theme

> 标签: design-tokens, tailwind, tailwind-theme, theme

## 简介

面向 Tailwind CSS v4 的设计令牌与主题 CSS 生成器。提供内置多主题色板、`data-theme` 切换、以及可编程生成 CSS 文件。
