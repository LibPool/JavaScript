# plugin-guarddog

> 标签: elizaos, guarddog, honeypot, plugin, safety, security, token

## 简介

GuardDog token safety for ElizaOS: CHECK_TOKEN_SECURITY action auto-checks every token before swap/buy (PASS/WARN/BITE, 23ms), plus a conversation risk evaluator. BITE auto-aborts trades. Free 50 calls/day.
