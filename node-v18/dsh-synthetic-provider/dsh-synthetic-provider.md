# dsh-synthetic-provider

> 标签: deepseek-harness, dsh-plugin, synthetic, web-search

## 简介

Synthetic-backed WebSearchProvider for the DeepSeek Harness web seam. First boot seeds an llm-pi-ai Synthetic chat route so chat and search share SYNTHETIC_API_KEY; search itself is POST /v2/search.
