# @teamhelper/otter-flow

> 标签: JavaScript

## 简介

工作流（Workflow）可视化编辑器 SDK，基于 @xyflow/react。对外是单个黑盒组件 `<OtterFlow>`，通过 `services` 依赖注入对接后端（增删改查 / 执行 / 资源 / 宿主能力）。**自包含：导入组件即自动注入样式，宿主无需任何 Tailwind 配置。**
