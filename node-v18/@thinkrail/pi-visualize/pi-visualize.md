# @thinkrail/pi-visualize

> 标签: diagram, extension, mermaid, pi, pi-coding-agent, pi-package, visualize

## 简介

A pi extension adding a `visualize` tool: mermaid diagrams and option comparisons, rendered as box-drawing in the terminal and as rich cards in hosts that have a renderer.
