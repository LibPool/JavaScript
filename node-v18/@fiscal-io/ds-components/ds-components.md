# @fiscal-io/ds-components

> 标签: JavaScript

## 简介

Design System Angular da Fiscal.io. A partir da **v8**, o pacote é fatiado em entry points para o bundler não puxar Gantt, PDF Viewer, File Manager, Charts etc. quando a aplicação só usa botão, grid ou layout.
