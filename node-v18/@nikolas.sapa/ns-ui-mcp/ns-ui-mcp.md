# @nikolas.sapa/ns-ui-mcp

> 标签: component-library, mcp, model-context-protocol, react, registry, shadcn, tailwind

## 简介

MCP server for the ns-ui component registry: search components, read full source, and get the token/theming conventions an agent needs to build in the same design language.
