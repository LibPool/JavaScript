# @ojesusmp/explica

> 标签: claude, claude-code, claude-skill, documentation, explica, html, project-status, report, skill, truepointagents

## 简介

Claude Code skill that generates a self-contained graphical HTML+CSS guide explaining the current state of any prompt, project, program, or decision-point at an 18-year-old reading level.
