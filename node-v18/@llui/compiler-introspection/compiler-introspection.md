# @llui/compiler-introspection

> 标签: compiler, introspection, llui, schema

## 简介

LLui compiler — runtime introspection metadata (opt-in). Schema/annotation/hash emission consumed by @llui/agent-bridge (end-user agent) and @llui/mcp (dev MCP).
