# @systemfsoftware/trace-spec

> 标签: contract-testing, effect, effect-ts, observability, opentelemetry, trace-based-testing, tracing, vitest

## 简介

Trace contracts as executable specs — own a trace id, observe the finished trace through an in-memory exporter, and relate the decoded span graph to a declared taxonomy.
