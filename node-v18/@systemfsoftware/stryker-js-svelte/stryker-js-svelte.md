# @systemfsoftware/stryker-js-svelte

> 标签: framework, mutation-testing, plugin, stryker, stryker-mutator, svelte

## 简介

Stryker framework plugin for Svelte components: claims .svelte files, resolves the svelte compiler from the project install, and refuses the run with a typed reason when the compiler is missing or too old.
