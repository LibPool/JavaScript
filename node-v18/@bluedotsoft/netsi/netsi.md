# @bluedotsoft/netsi

> 标签: agents, ai-agents, cli, mcp, netsi, sdk, shared-expenses, splitsi

## 简介

CLI and SDK for netsi, the personal agent network (and splitsi, its shared-expense app). Tools are read live from the API: new tools work without updating this package.
