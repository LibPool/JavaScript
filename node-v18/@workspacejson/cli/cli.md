# @workspacejson/cli

> 标签: aaif, ai-agents, ai-coding-agents, cli, codebase-intelligence, developer-tools, json-schema, open-standard, producer, workspace.json

## 简介

The workspace.json producer — scans a repository and generates .agents/workspace.json deterministically, preserving human-authored manual evidence.
