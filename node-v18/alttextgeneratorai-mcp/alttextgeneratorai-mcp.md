# alttextgeneratorai-mcp

> 标签: accessibility, ai, alt-text, claude, image-description, images, mcp, model-context-protocol, seo, wcag

## 简介

MCP server that writes SEO-friendly, accessible alt text for images with AI, and finds images missing alt text on any web page. Works with AltTextGeneratorAI.com.

- 官网：https://alttextgeneratorai.com
