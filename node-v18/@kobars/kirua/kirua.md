# @kobars/kirua

> 标签: components, design-system, radix-ui, react, server-components, tailwind, tailwindcss, ui

## 简介

A React design system with a playful, cut-out look: bold outlines, hard offset shadows, rounded corners and a vivid blue brand. React 19, Tailwind CSS v4 and Radix Primitives.
