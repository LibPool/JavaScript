# @marcusok/progress-overlay

> 标签: loading, monorepo, overlay, progress, spinner, ui

## 简介

Framework-agnostic full-screen progress overlay: spinner for indeterminate work, percentage bar for streamed progress, glass panel with light/dark themes. Shared UI layer for @marcusok packages.
