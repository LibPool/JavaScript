# @polst-web/sdk

> 标签: embed, openapi, polst, react, sdk, typescript

## 简介

Public POLST SDK — typed PolstClient + React wrappers for embedding polsts, campaigns, and brand feeds. Wraps the public POLST HTTP surface.
