# @ipseonet/assert-safe-url

> 标签: cloud-metadata, dns, fetch, metadata, private-ip, security, ssrf, url, validation

## 简介

Zero-dependency SSRF guard: reject server-side fetches to private, loopback, link-local, CGNAT, and cloud-metadata addresses.
