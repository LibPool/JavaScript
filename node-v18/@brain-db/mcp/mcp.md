# @brain-db/mcp

> 标签: ai-agents, brain, mcp, memory, model-context-protocol

## 简介

Managed MCP server for the Brain memory database. Exposes Brain's tenant surface — memory, reasoning, typed entities, graph, schema, identity — as 25 MCP tools over remote Streamable HTTP, in front of the Brain gateway (hosted) or brain-edge (self-host).
