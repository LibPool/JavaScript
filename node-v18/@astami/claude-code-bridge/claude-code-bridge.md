# @astami/claude-code-bridge

> 标签: ai, bridge, claude-code, mcp, model-context-protocol, subagent

## 简介

A small, hardened MCP server that bridges an MCP client (Claude Desktop, Cowork, etc.) to the Claude Code CLI. One-shot execution and persistent Q&A sessions over stream-json.
