# @agentable-ui/lang

> 标签: agent, components, generative-ui, genui, mcp, react, streaming, webmcp

## 简介

Agentable Lang: a compact, streaming-first language for model-generated UI. Parser, streaming parser, prompt generation and serializer, framework-free.
