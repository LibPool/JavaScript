# @gapit/node-red-contrib-gapit-results

> 标签: gapit, node-red

## 简介

A Node-RED node which converts the msg.gapit_results property (e.g. from gapit-snmp) into the format required by the 'influx batch' node (from node-red-contrib-influxdb).
