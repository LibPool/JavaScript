# @lineai/workflow-tools

> 标签: JavaScript

## 简介

Template for a workflow-tools server: a per-project MCP server whose tools each carry out one business workflow for a voice agent over the project collections or another declared backend. npm install, copy template/ out, implement tools.js and backend.js,
