# officeparser

> 标签: JavaScript

## 简介

A robust, strictly-typed Node.js and Browser library for parsing office files (.docx, .pptx, .xlsx, .odt, .odp, .ods, .odg, .pdf, .rtf, .csv, .md, .html, .epub) and generating high-fidelity outputs in DOCX, ODT, Markdown, HTML, CSV, RTF, PDF, EPUB, and RA
