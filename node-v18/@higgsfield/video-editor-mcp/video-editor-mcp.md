# @higgsfield/video-editor-mcp

> 标签: claude, claude-desktop, higgsfield, mcp, mcpb, video-editor

## 简介

Higgsfield Video Editor for the Claude Desktop app (Chat, Cowork and Code), installed as a desktop extension: a local MCP server over stdio that edits TSX video projects on this Mac with the higgsedit CLI and serves the editor panel.
