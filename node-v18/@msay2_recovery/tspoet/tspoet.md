# @msay2_recovery/tspoet

> 标签: File, Generate, TSPoet, TypeScript

## 简介

TSPoet is a mean to create TypeScript source files.
The created files is Class, Enumeration, Interface and Custom Element.
TSPoet allows you to include properties, constants, methods and your code block.
