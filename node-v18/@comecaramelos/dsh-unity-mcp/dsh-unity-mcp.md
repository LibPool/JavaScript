# @comecaramelos/dsh-unity-mcp

> 标签: JavaScript

## 简介

DSH plugin: Unity MCP bridge (the `unity-ai-relay` executable shipped by com.unity.ai.assistant, launched as `<relay> --mcp [extraFlags]`) integration (wraps @deepseek-ai/dsh-mcp-client)
