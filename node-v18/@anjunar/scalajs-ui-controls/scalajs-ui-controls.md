# @anjunar/scalajs-ui-controls

> 标签: JavaScript

## 简介

The TypeScript controls API of Scala JS UI 1.0: tabs, carousel, and the virtualized table / data grid / list, projected onto the ui.control components that run in the Scala.js runtime published as @anjunar/scalajs-ui-bridge.
