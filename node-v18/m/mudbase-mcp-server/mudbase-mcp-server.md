# mudbase-mcp-server

> 标签: baas, claude, claude-code, database, mcp, model-context-protocol, mudbase, storage

## 简介

MCP server that exposes Mudbase's database, storage, and search capabilities as tools for Claude Code and other MCP clients, gated by a Mudbase API key.
