# mcp-oauth-proxy

> 标签: authentication, bearer-token, client-credentials, http-proxy, mcp, mcp-client, modelcontextprotocol, oauth, oauth-client, oauth2, perforce, proxy, stdio

## 简介

OAuth 2.1 Client Credentials Flow proxy for MCP STDIO servers. Automatically fetches tokens and proxies JSON-RPC requests with Bearer authentication.
