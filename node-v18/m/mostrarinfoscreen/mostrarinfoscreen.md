# mostrarinfoscreen

> 标签: alerts, notifications, popup, svg, tutorial, ui

## 简介

es una **librería de JavaScript versátil** para mostrar notificaciones en pantalla en aplicaciones web. Incluye soporte para texto, imágenes, emojis, iconos (SVG y PNG Base64), audio, inputs, botones interactivos, modo etiqueta minimalista, gestión inteli
