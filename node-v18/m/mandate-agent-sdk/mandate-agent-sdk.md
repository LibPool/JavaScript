# mandate-agent-sdk

> 标签: agentic-payments, ai-agent, arc, ens, privy, wallet, web3

## 简介

Framework-agnostic SDK for an AI agent to read its own ENS spending mandate and pay against it on Arc — plug into any agent runtime.
