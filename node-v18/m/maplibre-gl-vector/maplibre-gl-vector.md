# maplibre-gl-vector

> 标签: duckdb, duckdb-wasm, flatgeobuf, geojson, geolibre, geopackage, geoparquet, gis, map, maplibre, maplibre-gl, mvt, plugin, react, shapefile, typescript, vector, vector-tiles

## 简介

A MapLibre GL JS plugin for visualizing vector data (GeoJSON, GeoPackage, Shapefile, GeoParquet, FlatGeobuf, CSV) powered by DuckDB-WASM with dynamic vector tiles
