# mini-tw-core

> 标签: atomic-css, css, css-framework, tailwind, utility, utility-first

## 简介

Shared CSS utility generator — the engine powering mini-tw. Generates atomic CSS classes from config (spacing, colors, typography, flexbox, grid, borders).
