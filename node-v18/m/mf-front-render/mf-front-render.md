# mf-front-render

> 标签: JavaScript

## 简介

* 基于typescript开发，用tsc编译生成esm，最终发布之后只使用lib文件夹里的东西 * 编译完成支持css直接引入和scss的引入 * 部分组件依赖next环境，所以需要引入next * 所有组件和样式位于src下
