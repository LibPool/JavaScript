# mock-server-dev

> 标签: auto reload, mock-server, mock服务, mock服务热更新, node, 热更新

## 简介

mock-server 热更新。监听文件的变化，重启服务进程。一般会用在开发环境服务配置修改之后，重启服务使配置生效。
