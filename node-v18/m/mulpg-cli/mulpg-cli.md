# mulpg-cli

> 标签: JavaScript

## 简介

多页应用脚手架 ### 安装依赖 ``` npm install ``` ### 生成外链(需要先执行该命令) ``` npm run dll ``` ### 开发环境启动项目 ``` npm run dev  npm start http://localhost:8080/app.html ``` ### 生产环境 ``` npm run build ``` ### 配置 pages目录主要是用来配置多页面的入口
