# mimo-opencode-connect

> 标签: bridge, free-models, llm, mimo, mimo-desktop, mimocode, openai-compatible, opencode, opencode-zen, proxy

## 简介

将 OpenCode 的免费模型接入 MiMo Desktop：本地 OpenAI 兼容桥，零账号、零 API key。Bring OpenCode free-tier models into MiMo Desktop via a local OpenAI-compatible bridge.
