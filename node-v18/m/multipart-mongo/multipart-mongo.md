# multipart-mongo

> 标签: JavaScript

## 简介

Middleware for Connect (node.js) which handles multipart/form-data uploads and stores uploaded files in mongodb's GridFS

## 官网

- 官网：https://github.com/oreh/multipart-mongo
- npm 页面：https://www.npmjs.com/package/multipart-mongo
