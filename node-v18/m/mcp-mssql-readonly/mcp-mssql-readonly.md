# mcp-mssql-readonly

> 标签: database, mcp, model-context-protocol, mssql, read-only, sql-server

## 简介

A read-only MCP (Model Context Protocol) server for Microsoft SQL Server. AI agents can safely explore database schemas and query records — without any risk of modifying data or structure.
