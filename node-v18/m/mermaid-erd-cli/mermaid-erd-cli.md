# mermaid-erd-cli

> 标签: cli, database, diagram, er-diagram, erd, mermaid, mysql, postgresql, schema, sqlite

## 简介

Generate a Mermaid ER diagram from a live database (PostgreSQL/MySQL/SQLite) or a schema dump. Outputs an interactive HTML viewer or raw Mermaid/JSON to stdout. No ORM or framework required.
