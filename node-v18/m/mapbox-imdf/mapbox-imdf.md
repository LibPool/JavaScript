# mapbox-imdf

> 标签: JavaScript

## 简介

This module has 3 components - `layers` which is a array of strings with names of the layers in IMDF - `load_vectortiles(url, map)` adds IMDF to mapbox map with standard styling - `load_geojson(url,map)` adds IMDF to mapbox map with standard styling
