# maskdial

> 标签: a11y, accessibility, country-selector, e164, flag-icons, formatting, input, international, jQuery, libphonenumber, mask, mobile, number, phone, phone-input, plugin, react, telephone, typescript, validation, vue, wcag, yup, zod

## 简介

Modern phone number formatting library with React/Vue components, TypeScript support, Zod/Yup validators, and WCAG 2.2 accessibility. Drop-in replacement for intl-tel-input.
