# mcp-osrs

> 标签: JavaScript

## 简介

MCP server for Old School RuneScape Wiki + game data + Grand Exchange prices. Live data from the OSRS Wiki with proper redirect handling, retry/backoff, identifying User-Agent, and section + wikitext + extracts tools.
