# mw-ocg-zimwriter

> 标签: openzim, wikitext, zim

## 简介

Converts mediawiki collection bundles (as generated by mw-ocg-bundler) to ZIM files

## 官网

- 源码仓库：git://github.com/wikimedia/mediawiki-extensions-Collection-OfflineContentGenerator-zim_renderer
- npm 页面：https://www.npmjs.com/package/mw-ocg-zimwriter

## 历史版本号

- 当前版本：0.0.0

- 0.0.0

## 获取地址

- npm 安装：`npm install mw-ocg-zimwriter`
- npm registry：https://registry.npmjs.org/mw-ocg-zimwriter
- Node 要求：>=0.8
