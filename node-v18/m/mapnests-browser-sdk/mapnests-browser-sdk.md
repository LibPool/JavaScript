# mapnests-browser-sdk

> 标签: distance-matrix, distance-matrix-details, mapnests, reverse-geocode, sdk, typescript

## 简介

TypeScript SDK for Mapnests API integration (Distance Matrix, Distance Matrix Details, Pairwise Route Summary, Multi Source Route Summary, Search, Reverse, Autocomplete, Autocomplete Without Zone, Multi Stop Points, Details By Place ID, Search By Radius,
