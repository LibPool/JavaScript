# micropather.cxx

> 标签: a-star, astar, c, engine, game, library, pathfinding

## 简介

MicroPather is a path finder and A* solver (astar or a-star) written in platform independent C++ that can be easily integrated into existing code. MicroPather focuses on being a path finding engine for video games but is a generic A* solver; Lee Thomason
