> 标签: agent-infrastructure, ai-agents, artifacts, capability-urls, claude, file-exchange, file-sharing, file-storage, mcp, model-context-protocol, provenance, pulr

## 简介

MCP server for pulr.ai — secure FILE exchange infrastructure for AI agents: upload, share, fetch, and revoke durable, verified, expiring file artifacts (reports, CSVs, images, PDFs) with provenance, scanning, and audit. Backend file handoff — not a UI str
