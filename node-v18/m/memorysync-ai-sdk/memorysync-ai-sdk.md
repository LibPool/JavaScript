> 标签: agent-memory, ai, ai-agents, ai-sdk, generateText, llm, long-term-memory, memory, memorysync, middleware, streamText, vercel, vercel-ai-sdk

## 简介

MemorySync memory for the Vercel AI SDK: recall + persistence middleware for generateText/streamText, standalone helpers, and agent memory tools. Supports AI SDK v6 and v7.
