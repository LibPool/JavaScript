# madura-land

> 标签: cli, interpreter, madura, madura-land, programming-language

## 简介

Madura Land — basa pemrograman eksperimental dengan sintaksis terinspirasi Basa Madura. CLI resmi (dengan REPL berwarna) untuk menjalankan file .madura.l.
