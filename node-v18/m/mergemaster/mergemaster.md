# mergemaster

> 标签: agent, ai, anthropic, claude, code-generation, coding-assistant, developer-tools, gpt, openai, terminal, tui

## 简介

AI-powered coding assistant with an interactive terminal interface. Multi-model support (GPT-5.1, GPT-4o, Claude Sonnet 4.5, Opus, Haiku). Session persistence, command approval, and real-time streaming.
