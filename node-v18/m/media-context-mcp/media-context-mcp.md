# media-context-mcp

> 标签: ai, ai-agents, audio, claude, copilot, cursor, ffmpeg, frame-extraction, frames, image, llm, local, mcp, mcp-server, model-context-protocol, multimodal, ocr, privacy, screen-recording, screenshot, speech-to-text, tesseract, transcribe, transcription, video, video-analysis, video-to-text, video-understanding, vision, vscode, whisper, youtube, youtube-transcript, yt-dlp

## 简介

Local MCP server to analyze video, audio & images — extract frames, transcribe speech, and OCR on-screen text. Lets Claude, Cursor & VS Code watch videos, read screen recordings, and transcribe audio. No API keys, no cloud.
