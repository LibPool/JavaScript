# moonviz-engine-sdk

> 标签: ai-agent, ddp, design-engine, mbt, mcp, moonbit, moonviz, prototype, svg

## 简介

Node.js integration SDK for the MoonViz prototype design engine (pure MoonBit). Spawn-and-drive the MoonViz CLI from any Node host: sessions, templates, operations, flows, render, dual-gate export, DDP encrypt/decrypt.
