# multiai

> 标签: ai, anthropic, claude, cli, codex, deepseek, glm, nim, nvidia, opencode, openrouter, router

## 简介

Route multiple AI CLIs (Claude Code, Codex, OpenCode) with isolated env profiles — native Go binary, SHA256-verified download, embedded Anthropic-to-OpenAI bridge (free NVIDIA models in Claude Code)
