# marked-cjk-friendly

> 标签: chinese, cjk, japanese, korean, markdown, marked, marked-extension

## 简介

Marked.js extension to make Markdown emphasis (`**`) in CommonMark more friendly with Chinese, Japanese, and Korean (CJK)

- 源码仓库：https://github.com/tats-u/markdown-cjk-friendly
