# mcp-jnm

> 标签: ai, cli, llm, mcp, model-context-protocol, repl, ssh, tools

## 简介

Lightweight pure-CLI client for Model Context Protocol (MCP) servers: interactive REPL shell, tool discovery & invocation, connection profiles.
