# mcp-boatpartsmanual

> 标签: boat, canonical, catalog, marine, mcp, model-context-protocol, oem, parts, sku

## 简介

Canonical product identity for marine parts - resolve SKUs, OEM numbers, and part numbers across manufacturers, vendors, and retailers. Pre-launch stub; the real MCP runtime ships shortly.
