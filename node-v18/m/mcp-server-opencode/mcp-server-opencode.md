# mcp-server-opencode

> 标签: agent, ai-agents, async, claude-code, codex, delegation, mcp, mcp-server, model-context-protocol, opencode, orchestration, subagent

## 简介

MCP server that lets any MCP host (Claude Code, Codex CLI, Cursor, etc.) drive OpenCode and delegate tasks asynchronously to its agents
