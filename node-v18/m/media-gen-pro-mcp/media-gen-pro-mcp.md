# media-gen-pro-mcp

> 标签: ai-sdk, claude, gemini, gpt-image, image-generation, llm-tools, mcp, minimax, model-context-protocol, nano-banana, recraft, seedance, seedream, vercel-ai-gateway, video-generation

## 简介

Image and video generation as an MCP tool. GPT Image 2, Gemini, Recraft, Seedream, Grok, Arrow SVG, plus MiniMax and Seedance video; reference images and context supported; returns file paths, not megabytes of base64.
