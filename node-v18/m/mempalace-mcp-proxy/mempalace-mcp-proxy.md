# mempalace-mcp-proxy

> 标签: cursor, mcp, model-context-protocol, stdio

## 简介

Cursor stdio MCP proxy to memory API (Streamable HTTP) with MEM_X-User-Id; legacy debug server via MEM_LEGACY_DEBUG_SERVER=1.
