# modbus-mqtt

> 标签: bridge, gateway, iot, modbus, modbus-mqtt, mqtt

## 简介

This module bridges Modbus and MQTT in both directions. It publishes Modbus read/write results to MQTT and accepts MQTT commands that write to Modbus devices.
