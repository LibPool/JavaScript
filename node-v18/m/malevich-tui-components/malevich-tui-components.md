# malevich-tui-components

> 标签: cli, components, terminal, tui, ui

## 简介

A headless, renderer-agnostic TUI component library: layout and interaction algorithms only. Color, text measurement, key semantics, and terminal compositing are all host-supplied ports; components run unmodified against any host matching the Component/Fo
