# mcp-cloud-remote

> 标签: aws, claude, cloud-remote, cursor, ec2, locaweb, mcp, mcp-server, modelcontextprotocol, ssh, ssm, vps

## 简介

MCP Server em Node.js para infraestrutura em nuvem: Locaweb (VPS/API, SSH) e AWS (CLI v2, SSO, EC2, SSM). Os dois provedores ficam desligados até serem habilitados.
