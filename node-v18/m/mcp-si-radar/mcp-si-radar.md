# mcp-si-radar

> 标签: arnes, domain, domain-investing, dynadot, fast-checkout, mcp, model-context-protocol, si-domain, slovenia, spaceship, whois

## 简介

Authoritative direct registry socket scanner, real-time availability checker, GEMINI Rule 10 evaluator, and instant checkout generator for .si (Slovenia) ccTLDs. Bypasses registrar web bottlenecks, Cloudflare queues, and rate limits.
