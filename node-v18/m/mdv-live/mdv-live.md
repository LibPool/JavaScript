# mdv-live

> 标签: diff, file-tree, hot-reload, live-reload, markdown, marp, preview, review, search, slides, viewer

## 简介

Markdown Viewer - File tree + Live preview + Marp support + Hot reload + change-review surface (full-text search, diff highlighting, unread tracking)
