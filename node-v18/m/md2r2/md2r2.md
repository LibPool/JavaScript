# md2r2

> 标签: cdn, cli, cloudflare, image, markdown, npx, r2, upload

## 简介

CLI: 提取 Markdown 中的本地图片/资源并上传到 Cloudflare R2，自动把链接替换为公开 CDN 地址

- 官网：https://github.com/xuqssq/md2r2#readme
- 源码仓库：git+https://github.com/xuqssq/md2r2.git
- npm 页面：https://www.npmjs.com/package/md2r2

## 获取地址

- npm 安装：`npm install md2r2`
- npm registry：https://registry.npmjs.org/md2r2
- Node 要求：>=18
