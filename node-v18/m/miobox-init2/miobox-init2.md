# miobox-init2

> 标签: comunicaciones, inicializacion, miobox, node-red

## 简介

Nodo de inicializacion de variables globales y normalizacion de tiempos. Transforma tiempo universal a la local dependiendo el uso horario. Este nodo es fundamental para la lectura posterior de variables.
