# mui-menu

> 标签: JavaScript

## 简介

基于八维专高5月考题型限制，复杂度超出了学员理解范围，但为了项目完整度，必须要使用菜单功能，所以封装了这个插件，以便让学员们更好地去提升业务能力而不是纠结于底层实现。因时间有限，当前的项目并不符合标准插件的规范，后续有时间再修改调整
