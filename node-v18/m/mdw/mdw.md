# mdw

> 标签: JavaScript

## 简介

服务器启动了就会启动webpack开始编译，这个编译和我们的wcf这个tool有关系，因为dora-webpack-plugin会通过wcf来获取通用的配置！然后通过这个配置来开启webpack编译过程
