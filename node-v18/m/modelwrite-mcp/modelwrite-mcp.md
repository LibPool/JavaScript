# modelwrite-mcp

> 标签: gate, mcp, model-driven, modelwrite, okf, round-trip

## 简介

The modelwrite MCP server (mw-mcp): validate, gate, diff and read OKF documents, and optionally read-and-propose over a modelwrite repository.
