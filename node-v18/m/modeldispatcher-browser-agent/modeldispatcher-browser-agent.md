# modeldispatcher-browser-agent

> 标签: ai-agent, anthropic, browser, gemini, groq, llm, ollama, openai, streaming

## 简介

Browser-native, bring-your-own-key AI agent core with cross-provider/cross-key fallback dispatch: multi-provider (Gemini/OpenAI/Anthropic/Groq/Ollama), streaming and non-streaming, no backend and no vendor SDK required. The client-side sibling to model-di
