# maplibre-gl-3dtiles-terrain

> 标签: 3d-tiles, cesium, elevation, maplibre, quantized-mesh, raster-dem, terrain

## 简介

Use Cesium-style 3D Tiles quantized-mesh terrain as a normal raster-dem source in MapLibre GL JS: setTerrain, queryTerrainElevation, hillshade and draping with no core changes
