# muxmepls

> 标签: ass with mkv, font with ass, merge, merge-ass-mkv, mkv-ass-muxer, mux, mux-ass

## 简介

MuxMePls is a nodejs utility to mux ".ass" subtitles together with the fonts specified in a font folder into mkv container
