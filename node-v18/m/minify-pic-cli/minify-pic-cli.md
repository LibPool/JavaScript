# minify-pic-cli

> 标签: cli, compress, image, sharp, 命令行工具, 图片压缩

## 简介

一个简单易用的图片批量压缩命令行工具，支持 PNG、JPEG、GIF 格式，适合前端和设计师快速优化图片体积。
