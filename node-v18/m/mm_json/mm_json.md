# mm_json

> 标签: async, await, compatible, database, file, index, json, json-db, mm_mysql, nosql, promise, search, storage

## 简介

JSON文件数据库操作模块，提供与mm_mysql完全兼容的API接口，以JSON文件存储数据，支持字段索引快速搜索
