# mongoose-legacy

> 标签: MongoDB, Node.js, backwards compatible, callbacks support, compatibility layer, deprecated methods, mongoose, mongoose backward compatibility, mongoose callback, mongoose migrate, mongoose migration, mongoose v4, mongoose v5, mongoose v6, mongoose v7, mongoose-compat, seamless migration

## 简介

Mongoose-Legacy library provides backward compatibility support for the latest version of Mongoose (v7). It allows seamless migration and enables callbacks for deprecated methods. Compatible with Node.js and MongoDB.
