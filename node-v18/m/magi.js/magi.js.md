# magi.js

> 标签: JavaScript

## 简介

> *Magi.js* 一款轻量级的适用于微信小程序的 JavaScript 动画引擎。使用“黑科技”来突破微信小程序 `wx.createAnimation` 实现上局限性，然你像使用 css transition 那样自由使用 JavaScript 动画。
