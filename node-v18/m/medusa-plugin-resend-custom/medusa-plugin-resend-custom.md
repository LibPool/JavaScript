# medusa-plugin-resend-custom

> 标签: email, handlebars email, medusa-plugin, medusa-plugin-notification, react email, resend, transactional email

## 简介

Resend email plugin to send transactional emails for Medusa.Forked from the original version by Lacey Pevey.Modified the extension mechanism for new events, 1. Supporting dynamic addition of new events in the options definition within medusa-config.js, 2.
