# mermaid-interactive

> 标签: diagram, flowchart, interactive, mermaid, sequence-diagram, stepper

## 简介

Turn rendered Mermaid v10 diagrams into step-through, click-to-inspect interactive diagrams. Zero runtime dependencies.
