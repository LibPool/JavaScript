# medusa-transform-webhooks

> 标签: ecommerce, headless, medusa, medusa-plugin, medusa-plugin-notification, medusa-transform-webhooks, postgres, sqlite, typescript

## 简介

A MedusaJS Plugin for inititating webhooks for particular events which can dynamically transform the event data and send to respective target location.
