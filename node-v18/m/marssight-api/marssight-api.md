# marssight-api

> 标签: bitcoin api, bitcore, blockchain, blockchain api, insight, insight api, json, litecore, marscoin

## 简介

An open-source Marscoin blockchain API. The Insight API provides you with a convenient, powerful and simple way to query and broadcast data on the Marscoin network and build your own services with it. Built on Litesight-api and Bitpay Bitcore
