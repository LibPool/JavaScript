# myrsu-mcp

> 标签: claude, concentration-risk, mcp, model-context-protocol, myrsu, personal-finance, rsu, stock

## 简介

MyRSU MCP server — concentration & exposure analysis for tech workers with RSU comp, with international support (US/IN/CA/UK/EU/AU). Lets Claude / Cursor / Continue answer 'how risky is my company stock concentration?' with real numbers.
