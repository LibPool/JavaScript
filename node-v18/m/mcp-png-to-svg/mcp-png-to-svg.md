# mcp-png-to-svg

> 标签: animation, centerline, mcp, png, reanimated, svg, trace

## 简介

MCP server that converts PNG logos to animation-ready centerline SVG (for stroke-dashoffset path drawing).

## 官网

- npm 页面：https://www.npmjs.com/package/mcp-png-to-svg

## 历史版本号

- 当前版本：0.1.0

- 0.1.0

## 获取地址

- npm 安装：`npm install mcp-png-to-svg`
- npm registry：https://registry.npmjs.org/mcp-png-to-svg
- Node 要求：>=18.17
