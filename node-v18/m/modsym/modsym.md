# modsym

> 标签: cli, coding-agents, declarations, developer-tools, dts, npm, symbols, typescript

## 简介

Find the TypeScript declaration (.d.ts) for an exported symbol in an npm package — or truthfully abstain. Small CLI for coding agents.
