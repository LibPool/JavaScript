# mcp-conduct

> 标签: a2a, agent, conduct, mcp, model-context-protocol, trust, verification

## 简介

Check an MCP server's conduct before an agent connects to it. Reads the MCP Verification Gate (free, no key), recomputes verdict hashes locally, and applies a policy you choose. Zero dependencies.
