# multirtc

> 标签: Library, Node.js, RTCMultiConnection, RTP, SCTP, WebRTC-Experiment, audio, audio-video, broadcasting, file, file-sharing, hangout, javascript, many-to-many, multi-user, one-way, renegotiation, screen-sharing, skype, text-chat, video, video-conferencing, webrtc

## 简介

1) It is a skype-like demo using WebRTC for realtime connections! 2) It allows you enable/disable webcams; and join with or without webcams! 3) It allows you share screen using existing peer connections! 4) It allows you share files with preview and downl
