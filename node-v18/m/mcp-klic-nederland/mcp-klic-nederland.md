# mcp-klic-nederland

> 标签: graafmelding, graven, kabels, kadaster, klic, leidingen, mcp, model-context-protocol, nederland, wibon

## 简介

MCP server voor KLIC-meldingen, WIBON-wetgeving en kabels & leidingen in Nederland. Geeft elke AI-assistent (Cursor, Claude, VS Code) directe toegang tot KLIC-kennis.
