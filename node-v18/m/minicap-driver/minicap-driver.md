# minicap-driver

> 标签: JavaScript

## 简介

一个对 [minicap](https://github.com/openstf/minicap) 的 node.js 封装，不需要关注 minicap 的底层原理，让你轻松实现电脑浏览器实时投影 android 设备，并保证高帧率。

## 官网

- 官网：https://github.com/huruji/minicap-driver#readme
- npm 页面：https://www.npmjs.com/package/minicap-driver
