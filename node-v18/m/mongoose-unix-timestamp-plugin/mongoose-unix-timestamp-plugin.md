# mongoose-unix-timestamp-plugin

> 标签: createdAt, mongodb, mongoose, plugin, timestamps, unix, updatedAt

## 简介

Mongoose plugin that adds timestamps (createdAt and updatedAt) in your schema in a unix timestamp
