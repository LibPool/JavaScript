# muster-cli

> 标签: cli, dev-server, mcp, orchestration, process-manager, tui, vscode

## 简介

Terminal dashboard and CLI for Muster — run, stop, and monitor dev server groups defined in .vscode/muster.json via the Muster VS Code/Cursor extension.
