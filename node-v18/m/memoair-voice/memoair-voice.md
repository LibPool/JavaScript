# memoair-voice

> 标签: llm, memoair, memory, rag, sdk, voice, voice-agents

## 简介

Node.js voice memory client for MemoAir. Manages the local voice-runtime sidecar and exposes load/create-index, search, and save-response over the frozen runtime contract.
