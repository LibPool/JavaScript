# mdlinks-versioncli-sigrun

> 标签: JavaScript

## 简介

Este modulo cli,se encarga de verificar el status code http de links que se encuentren dentro de un archivo markdown,tambien realiza recursion sobre carpetas para buscar archivos markdown y extraer los links
