# mui-icloudinn

> 标签: app, icloudinn, mui

## 简介

为了做云游的app，会需要定制mui的样式和各种组件，还要考虑是否和vue结合。所以需要一个稳定的mui版本拿下来长期维护。现在用的是官网的（3.7.0）

## 官网

- npm 页面：https://www.npmjs.com/package/mui-icloudinn

## 历史版本号

- 当前版本：1.0.0

- 1.0.0

## 获取地址

- npm 安装：`npm install mui-icloudinn`
- npm registry：https://registry.npmjs.org/mui-icloudinn
- Node 要求：~0.10.1
