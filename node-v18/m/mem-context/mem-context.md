# mem-context

> 标签: ai-agents, brain-mode, claude-code, context-window, infinite-context, mcp, mem-evolved, never-compact, subagent

## 简介

Brain Mode — never fill your context window again. Delegate heavy work to Claude Code subagents with permanent memory (mem-evolved). Your conversation stays at 5-15 messages forever.
