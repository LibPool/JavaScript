# mdsimdg

> 标签: JavaScript

## 简介

MDSIMDG is a user-friendly Markdown WYSIWYG editor designed with a focus on simplicity and extensibility. Whether you are new to Markdown or a seasoned user, MDSIMDG provides an effortless composing experience, allowing everyone to visualize their content
