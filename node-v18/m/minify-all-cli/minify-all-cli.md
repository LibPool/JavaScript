# minify-all-cli

> 标签: Compress, Minify, Minify All, Minify All CLI, Minify All CSS, Minify All HTML, Minify All JS, cssnano, gzip, html-minifier, uglifyjs

## 简介

Minify All JS, CSS and HTML files in a folder by using UglifyJS, CSSNano and HTMLMinifier with an option to gzip all the files as well.
