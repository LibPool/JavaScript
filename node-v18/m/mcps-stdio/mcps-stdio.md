# mcps-stdio

> 标签: agent, ecdsa, mcp, mcps, proxy, security, signing, stdio, trust

## 简介

MCPS stdio-to-HTTP proxy for MCP servers. Adds ECDSA signing, replay protection, and trust level enforcement to any stdio-based MCP server.
