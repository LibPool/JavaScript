# mcp-secrets-runner

> 标签: 1password, claude, claude-code, hashicorp-vault, infisical, machine-identity, mcp, model-context-protocol, secret-management, secrets, vault

## 简介

Run MCP servers with secrets injected from Infisical, 1Password or HashiCorp Vault. No plaintext API keys in .mcp.json, no login sessions that expire.
