> 标签: agent-memory, ai-agent-memory, ai-memory, conversation-memory, cross-ai-memory, mcp-memory, memory, memoryrouter, openclaw, openclaw-memory, openclaw-plugin, persistent-memory, rag

## 简介

Persistent memory for OpenClaw, powered by MemoryRouter. Relay-based AI agent memory across sessions, compaction, and model changes.
