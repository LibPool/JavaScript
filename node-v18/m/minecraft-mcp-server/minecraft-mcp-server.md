# minecraft-mcp-server

> 标签: ai, bot, claude, llm, mcp, minecraft, mineflayer, model-context-protocol

## 简介

A Minecraft bot powered by large language models using the Model Context Protocol (MCP) to enable Claude and other models to control a Minecraft character
