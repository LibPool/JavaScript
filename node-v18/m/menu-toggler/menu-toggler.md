# menu-toggler

> 标签: JavaScript

## 简介

If you want an amazing looking menu and have it work without javascript, this library is perfect for you. This is a toggle menu that works without Javascript by using css checkboxes. HTML/CSS can be really powerfull and Javascript isn't always neccessary.
