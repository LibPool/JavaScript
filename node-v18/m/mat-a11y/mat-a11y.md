# mat-a11y

> 标签: a11y, a11y-linter, accessibility, accessibility-linter, angular, angular-cdk, angular-material, aria, color-contrast, lighthouse, mat-components, material-design, screen-reader, static-analysis, template-linter, wcag, wcag21

## 简介

Angular Material accessibility linter (v12+). 82 WCAG checks for mat-* components, Angular templates & SCSS. Static analysis with color contrast calculation.
