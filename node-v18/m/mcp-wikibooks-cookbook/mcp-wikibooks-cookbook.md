# mcp-wikibooks-cookbook

> 标签: cookbook, cooking, ingredient-scaling, mcp, model-context-protocol, recipes, wikibooks, wikimedia

## 简介

MCP server for the Wikibooks Cookbook. Search recipes, read ingredients and steps, and rescale quantities without ending up with 2.4 eggs. No API key required.
