# mk-databridge

> 标签: DOM, MVC, data, data binding, data manipulation, dom-template, ecosystem:jquery, form, forms, jquery, jquery-plugin, mapping, serialization, serialize, template, unserialization, unserialize, view

## 简介

A jQuery plugin to read/set data to forms. Supports nested objects, boolean and array checkboxes, on fly data formatting, non-input elements.
