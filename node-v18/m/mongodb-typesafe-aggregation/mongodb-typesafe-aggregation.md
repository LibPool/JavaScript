# mongodb-typesafe-aggregation

> 标签: aggregation, builder, fluent, mongodb, mongoose, pipeline, type-safe, typescript

## 简介

A type-safe, fluent builder for MongoDB aggregation pipelines. Works with both Mongoose and the native MongoDB driver.
