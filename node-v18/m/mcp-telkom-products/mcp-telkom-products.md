# mcp-telkom-products

> 标签: JavaScript

## 简介

Model Context Protocol (MCP) server that Langflow can use to crawl Telkom Website on the fly. Langflow’s new MCP integration allows it to connect to external MCP servers as tools​. Our goal is to create an MCP server (runnable with a simple npx -y command
