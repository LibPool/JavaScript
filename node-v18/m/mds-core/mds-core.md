# mds-core

> 标签: ai, contract, document, gfm, llm, markdown, schema, validation

## 简介

MDS — Markdown Document Schema: validate Markdown against .mds contracts from files, strings or streams — deterministic structure, types, constraints and LLM-readable semantic expectations with structured diagnostics.
