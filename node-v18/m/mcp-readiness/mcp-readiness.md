# mcp-readiness

> 标签: agent-tools, agents, ai, anthropic, audit, chatgpt, claude, lint, linter, llm, mcp, model-context-protocol, readiness

## 简介

Lighthouse for MCP servers — grade any public Model Context Protocol server against 10 spec-bound readiness criteria (dual-stack protocol entry, tool quality, safety annotations, anti-ghost content, token efficiency, honest errors) + a Claude/ChatGPT dire
