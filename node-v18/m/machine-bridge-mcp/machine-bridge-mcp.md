# machine-bridge-mcp

> 标签: agent-skills, automation, browser-automation, cloudflare-workers, coding-agent, cross-platform, desktop-automation, durable-objects, local-machine, managed-jobs, mcp, oauth, remote-mcp, ssh, stdio, wrangler

## 简介

Cross-client MCP bridge for local agent context, structured browser and application automation, files, Git, processes, resources, and durable jobs over stdio or OAuth relay.
