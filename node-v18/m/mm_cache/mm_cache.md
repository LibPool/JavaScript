# mm_cache

> 标签: add, async, await, cache, del, exec, get, promise, query, run, set

## 简介

一个统一的缓存操作框架，为多种缓存方式（Redis、MongoDB、CacheBase、Memory）提供统一的API接口，实现无缝切换和兼容
