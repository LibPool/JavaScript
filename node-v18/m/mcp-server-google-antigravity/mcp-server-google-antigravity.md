# mcp-server-google-antigravity

> 标签: agy, ai-agent, anthropic, antigravity, claude, codebase-analysis, gemini, google-antigravity, mcp, model-context-protocol

## 简介

MCP server exposing Google Antigravity (agy CLI / Gemini) to Claude and other MCP clients: async task jobs, large-codebase analysis, filesystem tools, model selection and more.
