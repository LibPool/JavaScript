# morphschemax

> 标签: alter-table, database, dual-write, expand-contract, mariadb, migration, morph, mysql, postgresql, schema, shadow-read, zero-downtime

## 简介

Zero-downtime database schema migration framework for PostgreSQL and MySQL. Dual-write, shadow-read, and expand-contract strategies built-in.
