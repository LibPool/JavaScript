# meta-rewrite-proxy

> 标签: facebook, meta, open-graph, proxy

## 简介

Sets up a proxy to rewrite meta tags to bring pages within your app's domain. Useful to leverage existing meta data and url locations while creating new (namespaced) Facebook apps.
