# msgraph-cli

> 标签: JavaScript

## 简介

Command-line interface for the [Microsoft Graph API](https://learn.microsoft.com/en-us/graph/overview). 68 commands across 10 domains — auth, users, Teams chats, messages, mail, calendar, rooms, transcripts, files, and a raw API passthrough.
