# meso-fitness

> 标签: api, fitness, hypertrophy, mcp, meso, periodization, sdk, strength-training, workout

## 简介

Official TypeScript/JavaScript SDK for the Meso API — a periodized strength-training program that designs and rebuilds block-periodized programs.
