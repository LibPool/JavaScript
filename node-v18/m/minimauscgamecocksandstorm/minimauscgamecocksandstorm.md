> 标签: jekyll-template, south-carolina, university-of-south-carolina, usc-gamecock-sandstorm

## 简介

USC Gamecock Sandstorm theme GitHub template, for alumni, students, faculty, staff, and fans. Built using Jekyll 4.3.4, customized color theme of minima 2.5.2, a one-size-fits-all Jekyll theme for writers.
