# media-gen-mcp-server

> 标签: agnes-ai, claude-code, image-generation, mcp, model-context-protocol, video-generation

## 简介

All-in-one image-generation MCP server for Claude Code: AI imagery/video (Agnes AI + Zhipu) + structured local rendering (diagrams, charts, formulas, cards, icons, QR codes). Provider- and engine-pluggable.
