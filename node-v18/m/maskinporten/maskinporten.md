# maskinporten

> 标签: altinn, digdir, jwt, maskinporten, norway, oauth2, samarbeidsportalen, systembruker, token

## 简介

TypeScript-first client for Norway's Maskinporten: one-call cached tokens, Altinn token exchange, and systembruker support.
