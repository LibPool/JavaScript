# mcp-oauth-compliance

> 标签: compliance, jwt, mcp, oauth, pkce, rfc7591, rfc8414, rfc9068, rfc9728

## 简介

Web-based tool for testing MCP server OAuth compliance with RFC 9728, RFC 8414, RFC 7591, and OAuth 2.1
