# minion-desktop

> 标签: ai-agents, automation, browser-automation, computer-use, desktop, llm, mcp, mcp-server, tool-calling, vercel-ai-sdk, virtual-desktop

## 简介

Zero-dependency TypeScript client for Minion: instant Linux desktops for AI agents (Vercel AI SDK, Mastra, LangChain.js or plain fetch). `npx minion-desktop mcp` starts its MCP server.
