# mcp-trustcard

> 标签: agents, audit, authorization, healthcheck, mcp, model-context-protocol, oauth, provenance, scopes, security, supply-chain, tool-identity, trust

## 简介

Cryptographic trust infrastructure for MCP servers — content-addressed tool identity, signed manifests, TOFU pinning, capability descriptors, a two-gate invocation policy, signed+chained receipts, publisher key rotation, and per-agent OAuth 2.1 auth scope
