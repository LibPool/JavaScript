# mpv-uosc-lsp

> 标签: language-server, lsp, mpv, uosc

## 简介

Standalone stdio language server for mpv/uosc configuration files (mpv.conf, input.conf, uosc.conf): completion, hover, diagnostics, formatting and cross-file include graph.
