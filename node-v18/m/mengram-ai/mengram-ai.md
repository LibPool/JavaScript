# mengram-ai

> 标签: agents, ai, ai-agents, auto-memory, claude-code, cognitive-profile, embeddings, episodic-memory, hooks, knowledge-graph, llm, mcp, mem0-alternative, memory, mengram, openclaw, procedural-memory, rag, second-brain, semantic-search, webhooks

## 简介

Human-like memory for AI agents — auto-save, auto-recall, cognitive profile. Claude Code hooks, MCP server (29 tools), OpenClaw plugin, semantic/episodic/procedural memory. Free Mem0 alternative.
