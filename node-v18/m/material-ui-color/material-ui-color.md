# material-ui-color

> 标签: color, color picker, colorpicker, material design, material-ui, picker, react, react-color, react-component, tiny, typescript

## 简介

The lightest colorpicker for React Material-Ui. No dependencies. It uses Hooks and support Typescript, and more !
