# marrow-setup

> 标签: ai-agents, installer, marrow, mcp, setup, web-scraping

## 简介

Set up Marrow in your AI agent (MCP) with one disposable command — run once via npx, nothing to install. Gets a free key, wires up MCP, installs the scout→read skill.
