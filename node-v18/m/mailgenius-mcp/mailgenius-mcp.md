# mailgenius-mcp

> 标签: claude, cursor, mailgenius, mcp, model-context-protocol

## 简介

Stdio launcher for the MailGenius MCP server. Bridges stdio JSON-RPC to https://mcp.mailgenius.pro/v1.

## 官网

- 官网：https://docs.mailgenius.pro/mcp
- 源码仓库：git+https://github.com/mail-genius/mcp.git
- npm 页面：https://www.npmjs.com/package/mailgenius-mcp

## 历史版本号

- 当前版本：0.1.0

- 0.1.0

## 获取地址

- npm 安装：`npm install mailgenius-mcp`
- npm registry：https://registry.npmjs.org/mailgenius-mcp
- Node 要求：>=18
