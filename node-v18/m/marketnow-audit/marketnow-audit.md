## 简介

Free security intelligence CLI for the agent economy, powered by LIVE MarketNow endpoints. Audit any domain (scam-check: URL shorteners, suspicious TLDs, typosquatting, punycode, RDAP registry age + TLS server-side), verify any Agent Trust Card (ATC) cryp
