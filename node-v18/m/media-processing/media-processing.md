# media-processing

> 标签: aac, audio, av1, camera, capture, codec, decoder, demuxer, encoder, ffmpeg, flac, getdisplaymedia, h264, h265, hevc, insertable-streams, media, mediarecorder, mediastream, mp3, muxer, opus, polyfill, realtime, rtp, screen-capture, svc, temporal-layers, track-processor, video, vp8, vp9, webcodecs, webrtc

## 简介

WebCodecs-compatible media API for Node.js - encode, decode, mux, demux with zero native bindings. Backed by FFmpeg child processes.
