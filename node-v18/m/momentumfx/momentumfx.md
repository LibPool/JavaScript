# momentumfx

> 标签: MomentumFX, inertia scroll, inertia scrolling, momentum scroll, momentum scrolling, momentumfx, smooth scroll, smooth scrolling

## 简介

MomentumFX is a React Library that allows you implementing high perfermance smooth scroll cross browsers. It is using all scroll event to perform a momentum based scrolling (aka inertial scrolling) on modern browsers.
