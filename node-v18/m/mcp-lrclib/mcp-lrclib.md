# mcp-lrclib

> 标签: ai, claude, cursor, karaoke, llm, lrc, lrclib, lyrics, mcp, mcp-server, model-context-protocol, modelcontextprotocol, music, no-api-key, synced-lyrics

## 简介

MCP server for LRCLIB. Search tracks and fetch plain or time-synced (LRC) lyrics. No API key required.
