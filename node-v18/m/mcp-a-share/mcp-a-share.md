# mcp-a-share

> 标签: A股, a-share, china, chinese-market, claude, mcp, stock, 股票

## 简介

MCP server for Chinese A-share stock market: real-time prices, technical analysis, top gainers/losers, sector performance. Works with Claude Desktop and any MCP client.
