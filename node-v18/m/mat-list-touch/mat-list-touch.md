# mat-list-touch

> 标签: Angular, Angular10, Angular9, angular-mat-list-swipe, angular-mat-list-touch, mat-list-swipe, mat-list-touch

## 简介

This is a list module with touch events (swipe/tap) for Angular 10 projects, based on Angular's mat-list and mat-list-item.
