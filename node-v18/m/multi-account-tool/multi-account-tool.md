# multi-account-tool

> 标签: account, ai, claude, cli, codex, credentials, gemini, ink, profile, switcher, tui

## 简介

여러 AI CLI(Claude Code, Codex, Gemini CLI, Aider, Kimi, Qwen, Crush, OpenCode, Goose, Grok Build) 계정을 하나의 TUI에서 전환해 사용하는 도구. OAuth refresh-token rotation 인지 + mat exec/session/freshness CLI.
