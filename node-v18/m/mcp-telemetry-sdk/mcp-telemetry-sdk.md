# mcp-telemetry-sdk

> 标签: ai-agent, claude-code, long-running-tasks, mcp, mcp-server, model-context-protocol, monitoring, notifications, observability, progress, telemetry

## 简介

Zero-dependency instrumentation library for MCP servers — emit job/step/log/cost telemetry that any mcp-telemetry-server (or your own collector) can pick up.
