# matauang

> 标签: chf, cny, currency, dkk, duit, eur, gbp, idr, jpy, matauang, money, rub, sar, sek, usd

## 简介

Node Package to format integer or string of number to Currency Format (NOT CURRENCY CONVERSION!). Pakcage untuk merubah string atau integer ke format mata uang. Daftar mata uang / Currenct List : idr, usd, gbp, eur, cny, jpy, sar, rub, chf, dkk, sek
