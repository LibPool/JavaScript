# mt-vue-cli

> 标签: JavaScript

## 简介

mt-vue-cli是一个快速生成mt-vue项目的生成器，类似于vue-cli。将mt-vue-cli安装在全局环境下，提供了终端里的 `mt-vue` or `x` 命令。
