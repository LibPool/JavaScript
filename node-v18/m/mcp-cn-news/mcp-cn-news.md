# mcp-cn-news

> 标签: A股, china, claude, eastmoney, finance, mcp, news, 东方财富, 财经

## 简介

MCP server for Chinese financial news: real-time headlines, stock announcements, hot topics from Eastmoney (东方财富). No API key needed.
