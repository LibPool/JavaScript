# mcp-mysql-apifox

> 标签: JavaScript

## 简介

- 在多个命名 MySQL 配置中执行 SQL - 管理 Apifox 接口文档 - 解析并执行 curl 命令 - 通过多个命名 FTP、FTPS 或 SFTP 配置操作远程目录
