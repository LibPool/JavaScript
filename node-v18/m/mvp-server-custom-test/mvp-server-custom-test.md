# mvp-server-custom-test

> 标签: JavaScript

## 简介

Este repositório contém um **servidor Model Context Protocol (MCP)** em Node.js que se comunica via **stdin/stdout** (transporte STDIO). Ele expõe um conjunto de ferramentas úteis, incluindo um gerador de saudações e um cliente para buscar notícias de tec
