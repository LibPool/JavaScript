# minimal-swagger-docs

> 标签: express, swagger

## 简介

This package is meant for generating minimal Swagger documentation without having to configure anything. The package uses the route stack of Express to generate a Swagger 2.0 JSON file without descriptions, bodies or responses. The JSON file is then serve
