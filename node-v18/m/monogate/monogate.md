# monogate

> 标签: algebra, cost-analysis, elementary-functions, eml, exp-minus-log, mathematics, monogate, numerical-precision, pfaffian, symbolic-computation

## 简介

A single binary operator eml(x,y) = exp(x) − ln(y) that generates all elementary functions. Implementation of arXiv:2603.21852 (Odrzywołek, 2026). Includes Pfaffian cost analysis (analyze) and float64 numerical-precision-loss prediction (predict_precision
