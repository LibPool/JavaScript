# mediasfu-shared

> 标签: angular, framework-agnostic, live streaming, live subtitles, mediasfu, mediasfu runtime, mediasfu sdk, mediasfu shared, mediasfu-shared, mediasoup, react, real-time communication, recording, room management, screen sharing, sfu, socket.io, svelte, translation, typescript, video call, video conferencing, vue, webinar, webrtc, whiteboard

## 简介

mediasfu-shared – framework-agnostic WebRTC runtime for MediaSFU. Room helpers, mediasoup signaling, socket management, media state, and TypeScript types for React, Vue, Angular, Svelte, and plain TS.
