# mi-note-cli

> 标签: ai, cli, cloud-note, export, markdown, mi, note, xiaomi

## 简介

A full-featured CLI for Xiaomi Cloud Notes (i.mi.com) — read, create, update, delete, move, pin notes, manage folders, upload images, bidirectional sync, and export to Markdown. Designed to be AI-friendly.
