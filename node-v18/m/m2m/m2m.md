# m2m

> 标签: automation, client-server, cloud, cloud-computing, dcs, distributed-control-systems, distributed-systems, edge, edge-computing, gpio, iiot, industrial control system, industry 4.0, iot, m2m, machine-to-machine, microservices, node-m2m, pi, plc, pub-sub, raspberry pi, rpi, scada, software-defined automation, telematics, telemetry

## 简介

m2m is a client library for creating distributed endpoints using the node-m2m machine-to-machine framework for cloud and edge computing using the internet.
