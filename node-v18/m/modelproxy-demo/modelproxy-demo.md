## 简介

代码演示了mockjs和jquery的engine效果； >## 安装  下载源码，进入代码目录执行  ```   npm install  ```  进入public目录执行  ```   npm install  ```  回到源码根目录执行  ```   node .  ```  启动浏览器，打开：[http://localhost:3000](http://localhost:3000)查看效果
