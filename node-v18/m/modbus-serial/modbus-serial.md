# modbus-serial

> 标签: arduino, com, modbus, port, rtu, serial

## 简介

A pure JavaScript implementation of MODBUS-RTU (Serial and TCP) for NodeJS. The serialport package is an optional dependency (use npm install --no-optional to skip).
