# mcp-vision-bridge

> 标签: agent, claude-code, codex, llm, mcp, model-context-protocol, multimodal, ocr, opencode, vision

## 简介

Give text-only LLM coding agents (DeepSeek V4 Flash/Pro, Qwen, Kimi) vision via any multimodal model. One analyze_image tool — paste or drag in one or many images, analyzed in a single call, scoped to the current session. Works with Claude Code, opencode,
