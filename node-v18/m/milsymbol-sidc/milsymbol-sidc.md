# milsymbol-sidc

> 标签: app-6, app6, app6e, builder, c2, fluent-api, joint-military-symbology, mil-std-2525, mil-std-2525e, military, military-symbology, milstd2525, milstd2525e, milsymbol, nato, sidc, symbol-identification-code, symbology, tactical-graphics, typescript

## 简介

Fluent TypeScript builder for MIL-STD-2525E / APP-6 numeric (20-character) SIDC strings, for use with milsymbol.
