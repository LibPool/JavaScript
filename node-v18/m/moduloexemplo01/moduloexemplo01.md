# moduloexemplo01

> 标签: JavaScript

## 简介

Este projeto contém a função `widget()`, responsável por gerar avatares procedurais em SVG de forma dinâmica e consistente a partir de uma *seed* (chave). O avatar é composto por várias camadas, como fundo, rosto, cabelo, olhos, boca e acessórios opcionai
