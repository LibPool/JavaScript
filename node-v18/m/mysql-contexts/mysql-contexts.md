# mysql-contexts

> 标签: C#, context, cross join, database, deleteMany, deleteOne, get, getAll, hasMany, hasOne, include, insert, insertMany, insertOne, join, left join, listener, mysql, queries, query, relationships, right join, table, truncate, update, updateMany, updateOne

## 简介

Provides an easy way to interact with the mysql2 connector by creating Contexts connected to a table in your MySQL database. This also supports joining tables on each other to create read-only joined contexts.
