# memkin

> 标签: agent-memory, ai-agent, claude-code, cli, codex, conversation-mining, feishu, knowledge-graph, lark, local-first, mcp, personal-knowledge-management, pglite, self-hosted, signal-extraction

## 简介

Local-first personal memory system — extracts signals from Feishu/Lark chats and AI-agent sessions into a private knowledge graph, served to any agent via MCP
