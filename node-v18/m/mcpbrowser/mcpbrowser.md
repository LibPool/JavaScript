# mcpbrowser

> 标签: ai-assistant, authentication, automation, browser, captcha, cdp, chrome, claude, cloudflare, devtools, edge, github-copilot, interactive, javascript-rendering, login, mcp, mcp-server, model-context-protocol, puppeteer, scraper, spa, sso, web-automation, web-browser, web-scraping

## 简介

MCP browser server — loads and interacts with web pages using the user's Chromium-based browser with full JavaScript execution. Handles authentication, SSO, and anti-bot protection automatically via the user's existing browser session.
