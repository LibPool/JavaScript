# mcpack-cli

> 标签: cli, curseforge, installer, minecraft, modpack, neoforge

## 简介

Production CLI for installing CurseForge manifest-based Minecraft modpacks without launcher-specific apps.

## 官网

- npm 页面：https://www.npmjs.com/package/mcpack-cli

## 历史版本号

## 获取地址

- npm 安装：`npm install mcpack-cli`
- npm registry：https://registry.npmjs.org/mcpack-cli
- Node 要求：>=18.17
