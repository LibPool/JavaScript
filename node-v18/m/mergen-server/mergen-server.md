## 简介

Mergen — the Execution & Security Gateway for AI agents. Deterministic local gate that blocks destructive tool calls in <1ms before they execute, holds risky calls for Slack HITL approval, and keeps a tamper-evident audit trail. Claude Code/Windsurf PreTo
