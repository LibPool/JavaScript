# memcore

> 标签: c-plus-plus, cache, cluster, concurrency, data-processing, high-performance, in-memory, inter-process-communication, ipc, lock-free, low-latency, multithreading, n-api, napi, native-addon, nodejs, performance, performance-engineering, posix, realtime, shared-memory, systems-programming, worker, worker-threads, zero-copy

## 简介

Lock-free shared in-memory cache for Node.js workers. POSIX shared memory, N-API native addon. Cross-process, zero external services, ultra-low latency.
