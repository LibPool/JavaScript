# mikser-io-mcp-app

> 标签: ai-agent, mcp, mcp-apps, mikser, mikser-io, model-context-protocol, ui

## 简介

MCP Apps (SEP-1865) for mikser-io. Layouts declaring `mcpApp` frontmatter become interactive apps: a predeclared ui:// shell resource, per-entity rendering into it, and user actions delivered back as tool calls or to a webhook.
