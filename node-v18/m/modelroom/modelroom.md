# modelroom

> 标签: agent-agnostic, ai-agents, claude-code, codex, coding-agents, design, design-system, design-workflow, live-preview, opencode, spec-driven, ui-design

## 简介

A local workspace to design UI screens with any coding agent — one room per screen: BRIEF, SPEC, BEHAVIOUR and the artifact.
