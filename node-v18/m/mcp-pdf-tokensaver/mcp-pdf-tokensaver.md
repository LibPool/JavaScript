# mcp-pdf-tokensaver

> 标签: ai, claude, cursor, layout-analysis, llm, mcp, pdf, token-saver

## 简介

A layout-aware MCP server that analyzes PDF structures to save up to 90% context tokens for LLMs. Powered by GoLocalPDF.
