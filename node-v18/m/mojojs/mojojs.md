# mojojs

> 标签: JavaScript

## 简介

Mojo.js is a customizable, modular JavaScript framework inspired by Node.js and Backbone.js. The framework is entirely modular - everything is broken out into smaller, more manageable libraries that allow you to cherry-pick exactly what features you want
