# maki-downloader

> 标签: download, mp3, mp4, youtube, yt-dlp

## 简介

Biblioteca Node.js para baixar vídeos e áudios do YouTube (MP3/MP4) usando yt-dlp via child_process

## 官网

- npm 页面：https://www.npmjs.com/package/maki-downloader

## 历史版本号

- 当前版本：1.0.0

- 1.0.0

## 获取地址

- npm 安装：`npm install maki-downloader`
- npm registry：https://registry.npmjs.org/maki-downloader
- Node 要求：>=18
