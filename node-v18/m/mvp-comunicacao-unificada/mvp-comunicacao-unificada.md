# mvp-comunicacao-unificada

> 标签: JavaScript

## 简介

Uma aplicação web React moderna para visualização e gestão das comunicações integradas dos sistemas CACO, SGA ADA e INTEGRA do Tribunal de Contas do Estado do Paraná.
