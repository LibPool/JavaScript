# mongoose-version-history

> 标签: diff, documenthistory, documentversion, history, jsondiff, jsonpatch, mongo, mongodb, mongoose, patch, version, versionhistory

## 简介

Mongoose plugin that tracks version history of documents by storing diffs in JSON Patch format.
