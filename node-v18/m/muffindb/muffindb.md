# muffindb

> 标签: async, asynchronous, await, cache, clear, client, database, db, delete, derivated work, enmap, ensure, evict, evict all, evictAll, evictall, fetch, fetch all, fetchAll, fetchall, get, has, lodash, map, mongo, mongodb, muffin, persistant, piece, promise, push, set, size

## 简介

Uses Mongo and allows you to create pieces of muffin, which allows you to interact with the database as if you were using a Map. It has also an optional cache.
