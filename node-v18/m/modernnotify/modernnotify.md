# modernnotify

> 标签: a11y, accessible, alert, dependency-free, frontend, javascript, message, notification, notifications, popup, rtl, snackbar, toast, toast-notification, typescript, ui, vanilla-js

## 简介

A dependency-free notification library for the web. Toasts, alerts, themes, progress bars, action buttons, grouping, RTL, and TypeScript types.
