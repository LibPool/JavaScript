# macaw-tabs

> 标签: accessible, css, ecosystem:jquery, html, jquery, jquery-plugin, responsive, tabs

## 简介

Macaw Tabs is jQuery plugin for HTML, CSS tabs. It is lightweight and easy to use. It implements the W3 design patterns for tabs.
