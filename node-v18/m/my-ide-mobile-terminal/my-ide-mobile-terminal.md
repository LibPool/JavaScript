# my-ide-mobile-terminal

> 标签: cli, cloud, mobile, pty, terminal, xterm, xterm.js

## 简介

Mobile-friendly cloud terminal built with full xterm.js + touch key bar (Ctrl, Alt, arrows, etc.) for phones that can't use cloud VS Code's terminal
