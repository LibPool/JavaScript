# @uxfront/layer-ui

> 标签: homepage, nuxt, nuxt-layer, webgl

## 简介

Nuxt layer for the uxfront.com family of homepages: registers @uxfront/ui, self-hosts its fonts, adds useUxHead() and keeps the first paint free of scripts and web fonts.
