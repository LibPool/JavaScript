# @oadank/dsh-input-tools

> 标签: JavaScript

## 简介

DSH 语音能力一体化插件（bundle 单包双入口）：host=语音工具/TTS六引擎/ASR/克隆/自动回复；client=输入框工具条/语音设置页/复制按钮。dsh plugin --profile web add @oadank/dsh-input-tools 一键安装注册
