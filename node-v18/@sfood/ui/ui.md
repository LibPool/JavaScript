# @sfood/ui

> 标签: JavaScript

## 简介

에쓰푸드 사내 프로젝트에서 공용으로 쓰는 React + Tailwind CSS 컴포넌트 라이브러리입니다. 색상·간격 같은 디자인 결정을 토큰으로 관리하고, 반복되는 업무 화면/서비스 화면을 템플릿으로 제공해 어느 프로젝트에서든 일관된 UI를 빠르게 만들 수 있게 합니다.
