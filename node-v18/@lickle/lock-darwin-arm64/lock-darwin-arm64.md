# @lickle/lock-darwin-arm64

> 标签: cross-process, exclusive-lock, file-lock, flock, lock, mutex, napi, native, read-write-lock, shared-lock

## 简介

File-based locking for Node.js using native OS locks (`flock` on Unix, `LockFileEx` on Windows).
