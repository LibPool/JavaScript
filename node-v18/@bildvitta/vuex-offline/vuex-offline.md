# @bildvitta/vuex-offline

> 标签: JavaScript

## 简介

Vuex offline é um gerador de modulos genérico para o vuex integrado com o [rxdb](https://rxdb.info/), utiliza o PouchDB como storage e Couchdb para replicação.
