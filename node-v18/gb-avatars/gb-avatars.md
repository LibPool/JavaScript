# gb-avatars

> 标签: 3d-avatar, avatar, eye-tracking, grok-bot, procedural-avatar, react-avatar, spring-physics, svg, vector-3d

## 简介

Interactive procedural 3D vector avatar engine and React component with pure CPU SVG rasterization, dynamic perspective eye tracking, and spring physics. Zero WebGL, zero canvas.
