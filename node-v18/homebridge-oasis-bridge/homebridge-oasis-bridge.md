# homebridge-oasis-bridge

> 标签: dontek, homebridge-plugin, oasis, oasis smart, pool, spa

## 简介

Homebridge plugin for Oasis Smart (Dontek) pool controllers: pump, heater, lights, jets and blower in HomeKit, plus a local REST API
