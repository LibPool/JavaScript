# @areumtecnologia/mysql-db-handler

> 标签: JavaScript

## 简介

High-scale enterprise Micro-ORM and MySQL Data Mapper with connection pooling, read/write splitting, eager loading, keyset pagination, soft deletes, and fluent query builder for Node.js.
