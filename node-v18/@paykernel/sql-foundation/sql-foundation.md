# @paykernel/sql-foundation

> 标签: claims, idempotency, migrations, paykernel, payments, postgres, sql, sqlite, typescript

## 简介

Shared relational schemas, codecs, migrations, and claim algorithms for PayKernel durable SQL store adapters. Not a general ORM.
