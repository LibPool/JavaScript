# @eva/plugin-timer

> 标签: eva.js, godot, plugin, timer

## 简介

Godot Timer 等价物 — DSL 可声明 wait/oneShot/autostart/signal,基于 plugin-tick 的 dt 累加,emit timer:timeout / timer:tick。
