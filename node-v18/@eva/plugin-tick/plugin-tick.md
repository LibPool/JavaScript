# @eva/plugin-tick

> 标签: eva.js, plugin, scheduler, tick

## 简介

Reliable game-tick scheduler for Eva.js — wraps Component.update with onTick/onFixedTick/onLateTick hooks and a setInterval fallback (WallTicker) for environments where RAF is throttled.
