# @sveltia/i18n

> 标签: i18n, internationalization, l10n, localization, messageformat, mf2, svelte, translation

## 简介

An internationalization (i18n) library for Svelte applications that uses Unicode MessageFormat 2 (MF2) to format messages.

## 官网

- 源码仓库：git+https://github.com/sveltia/sveltia-i18n.git
- npm 页面：https://www.npmjs.com/package/@sveltia/i18n
