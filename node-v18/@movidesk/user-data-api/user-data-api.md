# @movidesk/user-data-api

> 标签: JavaScript

## 简介

Lib para recuperar informações do usuário que estão codificadas no cookie. Caso **NÃO** houver **cookie** do usuário no navegador, a lib retornará **null**. Veja [aqui](https://github.com/movidesk/user-data-api) as informações que o objeto do usuário ir
