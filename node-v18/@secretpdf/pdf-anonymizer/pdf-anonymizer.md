# @secretpdf/pdf-anonymizer

> 标签: anonymization, anonymize, pdf, pdf-lib, pii, privacy, redact, redaction, typescript

## 简介

Finds and replaces words directly in PDF content streams (binary text replacement), with an optional black-box redaction overlay. Ships as a library - no CLI, no filesystem/network access.
