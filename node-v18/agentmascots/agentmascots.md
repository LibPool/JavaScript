# agentmascots

> 标签: ai-agent, animation, avatar, chatbot, mascot, nextjs, react, svg

## 简介

Animated, cursor-tracking React mascots for AI agents. Idle, listening, thinking, working, speaking, celebrating and sleeping states. Zero dependencies beyond React.
