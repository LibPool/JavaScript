# @opentiny/tiny-editor-collaborative-editing-backend

> 标签: collaborative, mongodb, opentiny, websocket, yjs

## 简介

A lightweight collaborative editing backend (Yjs + WebSocket + MongoDB provider) for the OpenTiny fluent editor.
