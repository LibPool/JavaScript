# @3nuc/eslint-config

> 标签: JavaScript

## 简介

Base eslint configs for my projects since I'm tired of setting it up from scratch all the time. The goal heare is that you can write in your .eslintrc "extend: "@3nuc/eslint"". Inspired by https://github.com/antfu/eslint-config
