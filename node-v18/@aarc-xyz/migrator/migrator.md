# @aarc-xyz/migrator

> 标签: aarc, alchemy, api kit, assets transfer, biconomy, etherspot, forward, gasless, migration, permit, protocol, protocol kit, safe global, uniswap, zerodev

## 简介

Migrator is a TypeScript library that makes it easy for developers to transfer assets from Externally Owned Accounts (EOA) to any destination address. It simplifies the asset transfer process by supporting various token standards, such as ERC20 and ERC721
