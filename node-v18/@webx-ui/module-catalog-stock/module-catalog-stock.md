# @webx-ui/module-catalog-stock

> 标签: admin, availability, catalog, cms, e-commerce, stock, vue, webx-ui

## 简介

Stock statuses for the catalogue of the WebX UI admin panel: in stock, out of stock, on order — a reference book, a field of the product form, a column and a filter of the list.
