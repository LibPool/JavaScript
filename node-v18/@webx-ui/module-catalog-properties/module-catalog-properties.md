# @webx-ui/module-catalog-properties

> 标签: admin, attributes, catalog, cms, e-commerce, facets, properties, specifications, vue, webx-ui

## 简介

Properties of products for the catalogue of the WebX UI admin panel: reference books with colours and pictures, numbers with units, texts and yes/no, sets inherited down the categories, the specifications tab of the product form and columns of the list.
