# @webx-ui/module-notifications

> 标签: admin, cms, notifications, telegram, vue, webx-ui

## 简介

Notification channels for the WebX UI admin panel: Telegram and e-mail, Mustache templates in every language of the site with highlighting, suggestions and a live preview, and the log of every delivery.
