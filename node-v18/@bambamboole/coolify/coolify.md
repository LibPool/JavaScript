# @bambamboole/coolify

> 标签: JavaScript

## 简介

Manage resources on a Coolify instance: projects, shared variables, databases and their backups, private keys, GitHub Apps, servers, S3 storage, applications, services, storages and their volume backups, scheduled tasks and deployments.
