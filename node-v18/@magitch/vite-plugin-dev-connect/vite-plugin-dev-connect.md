# @magitch/vite-plugin-dev-connect

> 标签: dev-tools, iframe, magitch, postmessage, preview, vite-plugin

## 简介

Vite plugin for Magitch dev environment — injects preview bridge (preview-protocol) for cross-origin communication between IDE and sandbox preview, and receives runtime error reports from it into a log file the AI can read.
