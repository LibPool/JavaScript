# @silencetao/ccapi

> 标签: AI, ccapi, claude, claude code, config, settings.json

## 简介

A tool for quickly switching Claude Code configurations, supporting URL, API_KEY, AUTH_TOKEN, MODEL quick switching, one-click management of system environment variables, delay speed measurement, automatic optimal line selection, and internationalization
