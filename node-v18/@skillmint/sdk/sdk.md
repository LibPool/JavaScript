# @skillmint/sdk

> 标签: 0g, agent, ai-skills, nft, sdk, skillmint, web3

## 简介

SDK for agents to discover, execute, pay (x402 + W0G), and verify AI skills on SkillMint (0G Chain). Supports prompt skills (TEE-attested inference) and agent skills (Claude/Codex folder bundles).
