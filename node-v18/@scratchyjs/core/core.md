# @scratchyjs/core

> 标签: JavaScript

## 简介

Core runtime package for the Scratchy framework. Provides the Fastify server factory with pre-wired security plugins (helmet, CORS, rate-limit, sensible), a Zod-based config loader, a structured error handler, graceful shutdown, and a plugin helper.
