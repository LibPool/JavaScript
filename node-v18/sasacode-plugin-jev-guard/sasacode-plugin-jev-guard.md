# sasacode-plugin-jev-guard

> 标签: jev, sasacode, sasacode-plugin, typesafe

## 简介

A second opinion on tool calls from TypeSafe's Jev before they run: stops dangerous calls that would run unasked, hands safe softDeny calls to you
