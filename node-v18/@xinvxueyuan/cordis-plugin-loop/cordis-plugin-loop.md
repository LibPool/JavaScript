# @xinvxueyuan/cordis-plugin-loop

> 标签: command, cordis, cron, deepseek-harness, dsh, loop, plugin, schedule

## 简介

Cordis (DeepSeek Harness) plugin: the /loop command — run a task now, then keep it going on a fixed cadence or a model-chosen one
