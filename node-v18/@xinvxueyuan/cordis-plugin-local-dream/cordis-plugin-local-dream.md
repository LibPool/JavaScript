# @xinvxueyuan/cordis-plugin-local-dream

> 标签: adb, android, cordis, deepseek-harness, dsh, local-dream, plugin, sse, stable-diffusion, tool

## 简介

Cordis (DeepSeek Harness) plugin: drive the Android Local Dream Stable Diffusion app over its embedded HTTP backend — LAN-first, USB/adb fallback — with automatic device connection management
