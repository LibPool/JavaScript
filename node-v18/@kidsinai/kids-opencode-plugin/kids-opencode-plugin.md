# @kidsinai/kids-opencode-plugin

> 标签: agentic, education, k-12, kids, opencode, opencode-plugin

## 简介

opencode plugin that turns opencode into a kid-safe coding mentor: kid-safe system prompt, tool whitelist (no shell), DeepRouter routing, audit emission.
