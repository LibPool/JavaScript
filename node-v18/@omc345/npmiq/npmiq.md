# @omc345/npmiq

> 标签: agent, cli, compare, dependency, mcp, npm, npmiq, package, picker

## 简介

CLI and MCP server for discovering and comparing npm packages. Scores candidates using downloads, GitHub health, Reddit signal, and State of JS retention.
