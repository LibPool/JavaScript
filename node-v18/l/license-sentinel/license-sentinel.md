# license-sentinel

> 标签: attribution, cli, compliance, cyclonedx, devsecops, github-action, gpl, license, license-checker, license-compliance, licenses, notices, open-source, sarif, sbom, spdx, supply-chain-security

## 简介

License compliance gate for npm projects: reads node_modules and npm/pnpm/yarn lockfiles, resolves SPDX expressions and LICENSE texts, enforces allow/deny lists, presets and project-license compatibility, and emits CycloneDX 1.6 and SPDX 2.3 SBOMs, NOTICE
