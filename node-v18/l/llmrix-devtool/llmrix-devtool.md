# llmrix-devtool

> 标签: acp, agent, ai, coding-assistant, jetbrains, llmrix, llmrix-devtool, zed

## 简介

An AI coding assistant that runs as an [ACP] server over stdio. Works with **Zed**, **JetBrains IDEs**, and any other ACP-compatible client.
