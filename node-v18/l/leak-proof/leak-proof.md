# leak-proof

> 标签: api-key, credential-scanner, devops, devsecops, env, git, git-hooks, hooks, husky, leak-prevention, pre-commit, secret-detection, secrets, security

## 简介

Zero-config Git pre-commit hook that blocks secrets (AWS keys, API tokens, .env files) from being committed. Auto-installs for your entire team.
