# lore-memory

> 标签: ai, architecture, claude, cli, context, decisions, developer-tools, knowledge-base, lore, mcp, memory

## 简介

Persistent project memory for developers. Captures decisions, invariants, gotchas, and graveyard entries — automatically and manually — and injects them into AI coding sessions.
