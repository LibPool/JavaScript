# lossless-context-mcp

> 标签: agent, claude, claude-code, context, cost, diff, lossless, mcp, tokens

## 简介

The flight recorder for your agent context: a persistent ledger of every file version the model was shown - working-set restore after compaction, cache-ready context packs for subagent fan-outs, and git-bound signed receipts.
