# logo-draw-animation

> 标签: animation, draw, draw-svg, line-drawing, logo, logo-animation, react, stroke, stroke-dashoffset, svg, svg-animation

## 简介

Turn any SVG into a self-drawing stroke animation. Zero runtime dependencies, SSR-safe, tree-shakable. ESM + CJS.
