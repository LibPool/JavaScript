# local-first-auth-simulator

> 标签: decentralized-identity, dev-tools, did, local-first, local-first-auth, mini-apps, qr-code, simulator, web3, webview

## 简介

Development tool for testing Local First Auth mini-apps. Injects window.localFirstAuth into a regular browser to help you test Local First Auth host apps while in development environments.
