# langchain-react-chinese-parser

> 标签: agent, baichuan, chatglm, chinese, ernie, glm, langchain, llm, minimax, output-parser, qwen, react

## 简介

一个专门为中文大模型提供的 LangChain ReAct 输出解析器集合，支持通义千问、ChatGLM、百川、智谱GLM、文心一言、Minimax 等主流中文模型
