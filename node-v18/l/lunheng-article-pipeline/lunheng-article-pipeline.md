# lunheng-article-pipeline

> 标签: agent, article-pipeline, bundle, deepseek-harness, dsh, skill, 论文流水线

## 简介

论衡（lunheng-article-pipeline）— 多 Agent 深度长文流水线技能包（DeepSeek Harness 原生插件）：定题→并行检索（文献/数据/案例）→分析→大纲人在环确认→写作→批判→审计→审稿→修订→配图→终检交付，9 个独立角色 T1-T9 互不可替代（文献/数据/案例/分析/写作/批判/审计/终检/审稿），主控 = T0 调度 + T8 终检亲执行（T8 独立角色，执行者主控担任，不 spawn），T9 审稿可选默认选中学术必选，三角验证 + M 机械化硬门 + F 失
