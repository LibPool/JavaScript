# langsys-js-server

> 标签: i18n, internationalization, l10n, langsys, localization, sdk, server-side-rendering, ssr, translation, typescript

## 简介

Request-scoped server-side translation for Langsys — renders translated, crawler-visible HTML during SSR on Node, Deno, Bun and Workers.
