# linuxify-cli

> 标签: aider, android, cli, cline, codex, developer-tools, linux, package-manager, proot, termux

## 简介

Run Linux developer tools on Android. One command: linuxify. Installs Ubuntu, Node, Python, and AI coding CLIs (Cline, Codex, Aider) on Android via Termux + proot.
