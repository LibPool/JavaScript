# local-lambdas

> 标签: amazon, aws, faas, lambda, serverless, sls

## 简介

Mocks an AWS Lambda environment, allowing Lambdas to be invoked locally via the AWS SDK. Useful for testing interaction with lambdas locally without having to make a round-trip to AWS every invocation.
