# logsdiegopolverelli

> 标签: JavaScript

## 简介

Clase para armar un log básico.  Instanciar, enviando el path del log en el contructor. Luego invocar el método grabaLog, enviando datos, usuario, y fecha. Datos es el único obligatorio. Usuario y fecha pueden omitirse, en cuyo caso se tomará el nombre
