# loudness-worklet

> 标签: audio-worklet, ebu-r128, itu-r-bs1770, loudness, web-audio

## 简介

A lightweight and efficient AudioWorklet for real-time loudness measurement in the browser, compliant with the ITU-R BS.1770-5 standard.
