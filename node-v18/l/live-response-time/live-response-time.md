# live-response-time

> 标签: JavaScript

## 简介

live-terminal-logger is a Node.js middleware that provides real-time color-coded logging of HTTP requests and responses in a separate terminal. It masks sensitive data like passwords and tokens and allows customizable logging levels based on status codes.
