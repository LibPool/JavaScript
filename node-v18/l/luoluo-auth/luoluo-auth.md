# luoluo-auth

> 标签: auth, authentication, jwt, nestjs, oauth2, oidc, rbac, security, session, sso

## 简介

A NestJS authentication framework inspired by Java Sa-Token. Supports JWT, Redis, RBAC, SSO, OAuth2, microservice auth, and API signature verification.
