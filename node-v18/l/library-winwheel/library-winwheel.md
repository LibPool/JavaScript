# library-winwheel

> 标签: angular-library, angular10, rotate, spin, wheel, win

## 简介

This library is based on WinWheelJS library (http://dougtesting.net/winwheel/docs). This is under development, it just tells how you can create an angular library of vanilla JS libraries and use them in way you like. Angular 10 is used for development.
