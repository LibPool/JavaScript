# lynxhub-mcp

> 标签: claude, lynxhub, mcp, model-context-protocol

## 简介

MCP server that connects Claude (Desktop or Code) to a LynxHUB fashion content & asset management instance — search, create, edit and delete products, KOLs, links and media right from chat.
