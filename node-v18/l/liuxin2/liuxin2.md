# liuxin2

> 标签: JavaScript

## 简介

1. 注册npm账号 2. 将npm源切换回npm(如果没有切换过npm源则 忽略) 3. 初始化项目`$ npm init [-y]` 4. 创建入口文件 5. 开发项目 6. 登录npm的账号 `$ adduser` 7. 发布项目 `$ npm publish`
