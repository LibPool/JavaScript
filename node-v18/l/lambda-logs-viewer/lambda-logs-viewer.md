# lambda-logs-viewer

> 标签: aws, cli, cloudwatch, devtools, lambda, log-viewer, logs, serverless

## 简介

Local web UI to browse AWS Lambda invocations and their CloudWatch logs — search, level filters, per-invocation metrics and reconstructed status.
