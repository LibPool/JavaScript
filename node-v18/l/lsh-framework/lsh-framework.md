# lsh-framework

> 标签: audit-log, cli, credential-management, cross-platform, devops, dotenv, encryption, env-manager, environment-variables, immutable-records, ipfs, multi-environment, secrets, secrets-manager, security, team-sync

## 简介

Simple, cross-platform encrypted secrets manager with automatic sync, IPFS audit logs, and multi-environment support. Just run lsh sync and start managing your secrets.
