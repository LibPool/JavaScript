# lockhound

> 标签: EBUSY, EPERM, delete, esbuild, file-in-use, handle, kill, lock, locked, node_modules, process, rename, restart-manager, unlock, vite, windows

## 简介

Find out which process is locking a folder (so it won't delete/rename) and kill it. Windows, zero dependencies. Built for the classic Vite/esbuild/node orphan-process lock.
