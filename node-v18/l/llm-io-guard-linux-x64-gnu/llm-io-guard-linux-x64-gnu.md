# llm-io-guard-linux-x64-gnu

> 标签: ai, edge, gdpr, guardrails, llm, napi-rs, pii, prompt-injection, redaction, secrets, security, wasm

## 简介

Offline, in-process input/output safety guard for LLM apps (PII vault, prompt-injection, secrets, malicious URLs, package hallucination). Rust core, Node (napi) + edge/browser (WASM). Defense-in-depth, not a guarantee.
