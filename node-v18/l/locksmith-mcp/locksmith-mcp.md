# locksmith-mcp

> 标签: database, ddl, lint, locks, mcp, migration, model-context-protocol, postgres, postgresql, safety

## 简介

Locksmith — an MCP server that lints SQL migrations for dangerous locking operations and suggests safe rewrites (PostgreSQL).
