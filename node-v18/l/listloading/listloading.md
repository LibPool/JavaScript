# listloading

> 标签: JavaScript

## 简介

`listloading.js` 是一个移动端的上拉、下拉加载更多的组件。主要依赖于iscroll.js v5.1.2基础上开发的组件，基础库可以使用jquery.js或者zepto.js操作dom节点，目前我是使用了jquery.js作为基础库操作dom，以jquery插件的形式存在。
