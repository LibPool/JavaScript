# libvrf

> 标签: cryptography, ecvrf, elliptic-curve, p256, proof, random, rfc9381, rsa, rsa-fdh, rsa-pss, sha256, verifiable-random-function, vrf

## 简介

Verifiable Random Functions (VRF) for Node.js and browsers - RFC 9381 RSA-FDH/PSS-NOSALT; simplified EC VRF (not RFC-interoperable)
