# link-meta-extractor

> 标签: extractor, javascript, link-scraper, meta-extractor, meta-scraper, metadata-extractor, node.js, scraper, url-meta-extractor, url-meta-scraper, url-scraper

## 简介

Link Meta Extractor. Extract metadata information from any http/https url. Simply pass a url string to the function and wait for the metadata results.
