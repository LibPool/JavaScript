# lab-units-mcp

> 标签: biomarker, clinical, healthcare, lab, mcp, model-context-protocol, si-units, unit-conversion

## 简介

MCP server for converting and normalising clinical lab values between conventional and SI units, and resolving lab-marker names across languages.
