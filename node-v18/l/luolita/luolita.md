# luolita

> 标签: coffeescript, generation, jade, parse, pug, stylus, tools

## 简介

A like-vue Single-File Components generator that parses HTML+CSS+JS ".luoli" into 3-Syntactic sugar: coffeescript, pug, and stylus.
