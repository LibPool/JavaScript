# loom-learning-sections

> 标签: cdn, components, education, event-storming, flowchart, interactive, learning, react

## 简介

Standalone React component library for rendering interactive learning sections from JSON data. Load via CDN, provide OKF JSON, get rendered sections. Full documentation included in docs/.
