# lib-texsa

> 标签: JavaScript

## 简介

`Lib-Texsa` é uma biblioteca de componentes React estilizados com TailwindCSS. Esses componentes foram criados para serem reutilizáveis em qualquer projeto React que esteja configurado com TailwindCSS.
