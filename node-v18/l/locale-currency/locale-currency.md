# locale-currency

> 标签: BCP 47, ISO 3166-1, ISO 4217, country code, currency, i18n, internationalization, locale

## 简介

A map of locale codes to ISO 4217 currency codes. Supports BCP 47, i18n, and ISO 3166-1 alpha-2 formats.
