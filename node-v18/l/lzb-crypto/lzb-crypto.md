# lzb-crypto

> 标签: JavaScript

## 简介

加密插件（内部包装第三方插件crypto-js插件）  支持MD5、(AES/DES对称算法)、BASE64加密解密  主要作用：保存本地数据加密、接口API加密、导航路由加密、文件加密
