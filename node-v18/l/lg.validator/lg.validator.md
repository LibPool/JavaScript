# lg.validator

> 标签: JavaScript

## 简介

数据校验器，支持复杂嵌套校验，不限制嵌套层级，支持数组嵌套对象嵌套，内置丰富的校验规则，支持自定义全局规则，规则配置简单而不失扩展性
