# lovestatus

> 标签: channel, discord, discord.js, discordjs, lovestatus, status, voice, voice channel

## 简介

LoveStatus is a lightweight library for managing custom statuses in Discord Voice Channels. It helps you set the vibe and change voice statuses with ease.
