# llm-keyrot

> 标签: 429, ai, anthropic, api-key, claude, deepseek, failover, fallback, gemini, groq, key-rotation, llm, openai, openrouter, pool, quota, rate-limit, rate-limiting, resilience, retry

## 简介

Auto-failover API key pool for LLM providers — when one key hits a rate limit, rotate to the next; when all keys are exhausted, wait for recovery; optionally fall back to another provider.
