> 标签: circular, countdown, javascript, timer, vue, vuejs

## 简介

1. 安装依赖 ``` npm install l-ynet-timer-project ``` 2. 注册到main.js ``` import Vue from 'vue'; import TimerProject from 'l-ynet-timer-project'; Vue.use(TimerProject); ```
