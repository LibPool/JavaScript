# lmw-fabric

> 标签: JavaScript

## 简介

由于 OpenseadragonFabricjsOverlay 需要对 fabricjs 的源码进行修改才能够使用，但是官方的 npm 包中修改的 fabricjs 版本仅只有 1.1.7，问题比较多，所以构建了这个包，这个包修改的是 4.0 版本的 fabricjs

## 官网

- npm 页面：https://www.npmjs.com/package/lmw-fabric

## 历史版本号

- 1.0.3
- 1.0.4
- 2.0.0
