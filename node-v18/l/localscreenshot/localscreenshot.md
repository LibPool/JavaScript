# localscreenshot

> 标签: ai-agents, cli, full-page-screenshot, mcp, screenshot, screenshot-api, url-to-image, web-capture, website-screenshot

## 简介

Screenshot API client and CLI. Take a screenshot of any public web page from the command line, from 227 countries.
