# logic-first

> 标签: bun, c4, library, logic, logic-first, mermaid, plantuml, typescript

## 简介

This project produces a 'logic-first' library used to instrument your application  in order to generate architecture diagrams (e.g. C4 or mermaid/planuml sequence diagrams) from your code.
