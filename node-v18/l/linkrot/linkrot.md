# linkrot

> 标签: broken-links, ci, cli, docs, github-actions, link-checker, links, markdown, obsidian, redirects, wiki

## 简介

Find broken links (local and external) and orphan pages in a folder of markdown — for docs sites, ADRs, and Obsidian-style vaults.
