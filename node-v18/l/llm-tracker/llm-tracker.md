# llm-tracker

> 标签: agent, ai, bloomberg, claude, cli, cursor, dashboard, kanban, llm, project-tracker, swimlane, task-manager, terminal-ui

## 简介

File-system-as-database project tracker for LLM agents and humans. Hub-authoritative merge, Bloomberg-terminal UI, two write modes (file patches or HTTP).
