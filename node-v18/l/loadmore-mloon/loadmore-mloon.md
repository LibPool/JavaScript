# loadmore-mloon

> 标签: JavaScript

## 简介

后台一次性返回大量的数据，为了提高用户体验，那么可以在业务组件外层套用loadmore这个组件    作者：zyj    ## 一、安装    npm i loadmore-mloon --save    ## 二、使用    在vue项目的入口文件main.js写入一下代码    import mloonloadmore from 'loadmore-mloon'
