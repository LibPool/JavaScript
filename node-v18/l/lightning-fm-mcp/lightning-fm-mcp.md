# lightning-fm-mcp

> 标签: bitcoin, lightning-fm, lightning-network, mcp, model-context-protocol, music, nostr

## 简介

MCP server for Lightning FM's Nostr-native music catalog — search tracks, look up artists, and check what's live now. Wraps the same relay + Blossom surfaces the platform itself uses; no separate agent API.
