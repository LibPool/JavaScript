# llm-coalesce

> 标签: ai, cache, coalesce, dedupe, llm, micro-frontend, multicast, streaming

## 简介

Request coalescing and stream multicasting for LLM calls in multi-widget apps — dedupe concurrent completions and share one live token stream across independently-deployed UI code, without a shared module instance.
