# logstash-relay

> 标签: AWS Support, Docker Support, JSNLogs, client, elasticsearch, error, log4javascript, log4js, logging, logstash, nodejs, relay, service

## 简介

A simple NodeJS service to relay JSNLogs or Log4Javascript/Log4JS(client) event messages to Logstash.
