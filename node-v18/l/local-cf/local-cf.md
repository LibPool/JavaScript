# local-cf

> 标签: cloudflare, d1, devtools, durable-objects, kv, local-cf, miniflare, r2, workers

## 简介

A local-first studio for Cloudflare Workers: browse and edit the exact D1/KV/R2/DO/Queues your worker is using, offline.
