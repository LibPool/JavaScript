# livecontext

> 标签: ai-automation, docker, livecontext, n8n-alternative, self-hosted, workflow-engine

## 简介

One-command launcher for LiveContext Community Edition. Runs the self-hosted Docker stack (workflows, AI agents, apps) with a single npm command.
