# leon-cli-package

> 标签: JavaScript

## 简介

``` monorepo中，用命令生成pnpm-workspace.yaml文件，pnpm install或者pnpm add报错 pnpm add --workspace @leon/cli --filter @leon/demo --workspace只安装工作空间中的包 --filter在根目录下执行命令将依赖安装在指定包中 ```
