# leash-monad-mcp

> 标签: ai-agents, erc-8004, mcp, model-context-protocol, monad, spend-limits, x402

## 简介

MCP server that lets any AI agent pay inside its Leash on Monad: check a seller, see today's budget, pay, or fetch a paid (402) URL. The agent can never spend past what its owner's passkey allowed.
