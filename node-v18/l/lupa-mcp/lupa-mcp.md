# lupa-mcp

> 标签: file-search, hwp, korean, local-search, lupa, macos, mcp, modelcontextprotocol, ocr, pdf, 문서검색, 파일검색

## 简介

MCP server for Lupa — search your Mac's files by name and document content (PDF, DOCX, XLSX, PPTX, HWP, scanned PDFs via OCR). Korean-aware, ~30ms, fully local.
