# llmswitch-config-core

> 标签: JavaScript

## 简介

目标：提供单一路径、无推测与无回退的配置解析引擎。把系统蓝图（module.json）与用户配置（config.json）映射为唯一“解释体”（CanonicalConfig），并导出装配输入（pipeline_assembler.config）与最终镜像（merged-config.json）。
