# lightningimg-node-darwin-x64

> 标签: N-API, NAPI, Rust, napi-rs, node-addon, node-addon-api

## 简介

A transparent and safe image converter for Node.js, written in Rust. Encodes PNG, JPG, TIFF to WebP
