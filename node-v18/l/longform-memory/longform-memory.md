# longform-memory

> 标签: ai-writing, cloudflare-workers, context-window, continuity, llm, long-context, mcp, memory, rag, token-budget, vector-search

## 简介

Constant-size memory for long-form AI writing. Chapter 1000 gets the same token budget as chapter 10. Zero dependencies, runs anywhere JS runs.
