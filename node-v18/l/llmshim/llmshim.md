# llmshim

> 标签: anthropic, gemini, llm, llmshim, openai, proxy, sse, xai

## 简介

TypeScript client for the llmshim proxy (multi-provider LLM API) — bundles a prebuilt binary and auto-starts it, or connects to a proxy you run yourself.
