# logika-sdk-react-native

> 标签: JavaScript

## 简介

Logika TypeScript SDK for React Native / Expo: an AsyncStorage BufferBackend + identity-encoding fetch transport + AppState flush lifecycle, pure JavaScript with no native module of its own (OTA/EAS-Update shippable).
