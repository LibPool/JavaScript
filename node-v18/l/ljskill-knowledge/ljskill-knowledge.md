# ljskill-knowledge

> 标签: knowledge, knowledge-graph, obsidian, wiki, wiki-knowledge, 知识管理

## 简介

将散落的 Markdown 笔记转化为结构化、可检索的知识 Wiki。支持六层模型（M1-M5 + P-index）提取、知识图谱构建、领域自动发现、Obsidian 兼容输出。
