# lighthouse-automation

> 标签: audit, automation, lighthouse, performance, playwright, qa, testing, web-performance

## 简介

Automated Lighthouse performance testing for Playwright projects. Automatically generate and run Lighthouse audits for multiple URLs/routes with minimal configuration.
