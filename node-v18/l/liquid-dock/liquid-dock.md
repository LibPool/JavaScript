# liquid-dock

> 标签: astro, dock, liquid, metaball, react, shader, tab-bar, ui, vue, web-component, webgl

## 简介

A liquid tab indicator — a spring-driven metaball rendered in raw WebGL2, packaged as a web component for Vue, React, Astro, and plain HTML.
