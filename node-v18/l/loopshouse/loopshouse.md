# loopshouse

> 标签: JavaScript

## 简介

Loops House events from your terminal or AI agent, for everyone in them — builders ideate, mine knowledge graphs and submit; hosts track enrollments, submissions and judging; sponsors and judges review. CLI, MCP server and agent skill in one binary.
