# ld-egg-frame

> 标签: egg, egg-framework

## 简介

#### 端信息校验（auth/webAuth）     主要功能：登录用户身份信息校验     说明：依据client头字段进行不同端的校验，框架提供默认的`web=>app/middleware/webAuth.js`中间件，用户可以自定义其他端的中间件校验。     如果配置了接口权限校验，会根据用户信息进行接口权限校验。
