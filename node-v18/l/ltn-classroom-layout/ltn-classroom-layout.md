# ltn-classroom-layout

> 标签: classroom, education, no-framework, plan-de-classe, seating-chart, vanilla-js

## 简介

Standalone vanilla JS module for an interactive classroom seating chart: desk grid, round/oval tables, rotation/color, student assignment, border objects (wall/board/door/window), wheel zoom, print / PDF export, JSON import/export.
