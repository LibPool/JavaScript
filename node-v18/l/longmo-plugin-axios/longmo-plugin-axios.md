# longmo-plugin-axios

> 标签: axios-cache-adapter, axios-plugin, axios-throttle-adapter

## 简介

基于 `axios-cache-interceptor` 增强的 axios 插件（见 `./llms-full.txt` ），提供开箱即用的缓存、错误处理、loading 等功能。
