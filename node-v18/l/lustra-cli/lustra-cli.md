# lustra-cli

> 标签: agent-skill, claude-code, code-quality, dead-code, lint, security

## 简介

Stack-agnostic code-hygiene skill for AI coding agents: clean AI slop, find security flaws, dead code, dependency rot, design and logging issues; lint, format, type-check, test, review, migrate dependencies, and fix project structure.
