# llm-provider-compat

> 标签: anthropic, compat, deepseek, llm, normalize, openai, payload, provider, reasoning, thinking

## 简介

Universal LLM provider compatibility layer — normalizes provider-specific payload differences (thinking formats, output budgets, tool pairing, media transport) into a single dispatch pipeline.
