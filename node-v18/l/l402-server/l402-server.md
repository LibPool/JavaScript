> 标签: 402, agent, ai, api, bitcoin, l402, lightning, lightning-network, macaroon, monetization, payment

## 简介

L402 server SDK for Node — mint Lightning invoices + macaroons and verify L402 tokens. Thin TypeScript wrapper around Lightning Enable's hosted producer API.
