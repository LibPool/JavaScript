# libetherjot

> 标签: JavaScript

## 简介

Libetherjot contains the primitives for the static blog generator [Etherjot Web](https://github.com/ethersphere/etherjot-web) and CLI importer [Etherjot](https://github.com/ethersphere/etherjot)
