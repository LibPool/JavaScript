# llmasking

> 标签: anonymization, llm, masking, pii, privacy, redaction, security, sse, streaming

## 简介

Mask sensitive data before it reaches an LLM, restore it after — including in SSE streams where a placeholder is split across chunk boundaries. Zero runtime dependencies.
