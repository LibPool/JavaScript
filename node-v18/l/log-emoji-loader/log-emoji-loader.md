# log-emoji-loader

> 标签: emoji, loader, webpack

## 简介

Webpack loader that prepends "😊" or "😡" in all the console.log/console.error instructions.

## 官网

- 官网：https://github.com/iampava/log-emoji-loader
- 源码仓库：git+https://github.com/iampava/log-emoji-loader.git
- npm 页面：https://www.npmjs.com/package/log-emoji-loader
