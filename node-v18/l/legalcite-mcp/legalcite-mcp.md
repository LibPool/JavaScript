# legalcite-mcp

> 标签: ai, case-law, citations, courtlistener, fact-checking, hallucination, law, legal, llm, mcp, model-context-protocol, verification

## 简介

MCP server that verifies legal case citations against real court records (CourtListener) and flags hallucinated/fake or misattributed cites — so AI agents stop citing cases that don't exist.
