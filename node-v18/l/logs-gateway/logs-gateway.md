# logs-gateway

> 标签: console, correlation, debug-capture, file, json, logger, logging, node, opentelemetry, pii, privacy, sanitization, scope-record, scoping, security, shadow-logging, story-output, test-logging, tracing, trails, troubleshooting, typescript, yaml

## 简介

Standardized logging gateway for Node.js with PII sanitization, correlation trails, Shadow Logging for test/debug capture, scoping with text filters, story output, troubleshooting integration, and multi-format output (JSON/YAML/text)
