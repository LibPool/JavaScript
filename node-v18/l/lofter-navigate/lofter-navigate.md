# lofter-navigate

> 标签: JavaScript

## 简介

目前LOFTER APP内支持使用scheme唤起新WebView打开指定的H5 url，该功能带来的浏览体验比使用`location.href`跳转要好（页面滚动位置的保留、手势支持、过场动画等），所以在端内页面的跳转推荐优先使用scheme方案。 同时，需要与客户端约定能够同时打开WebView的最大个数，以防占用过大内存或者性能造成APP崩溃、卡顿等问题。
