# li-add-unpaywall

> 标签: istex

## 简介

Le module **LI-ADD-UNPAYWALL** permet d’ajouter des enrichissement ‘Unpaywall’ celui-ci étant récupéré par le web service ‘biblio-tools/v1/unpaywall/corhal’. L'objectif est de récupérer la ou les URL(s) pointant vers le fulltext si celui-ci est librement
