# langterm

> 标签: ai, automation, bash, cli, command-generation, command-line, command-templates, context-aware, context-awareness, cross-platform, enhanced-context, extensible, hooks, linux, llm, local-ai, location-aware, macos, mcp, model-context-protocol, natural-language, ollama, pattern-learning, project-memory, reusable-commands, security, shell, template-system, terminal, unix, windows, zsh

## 简介

Secure CLI tool that translates natural language to shell commands using local AI models via Ollama, with project memory system, reusable command templates (hooks), MCP (Model Context Protocol) support, and dangerous command detection
