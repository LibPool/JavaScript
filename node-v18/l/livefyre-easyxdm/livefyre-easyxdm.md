# livefyre-easyxdm

> 标签: JavaScript

## 简介

Tools for using [easyXDM](https://github.com/oyvindkinsey/easyXDM) with Livefyre Hosts (currently only api.livefyre.com). This module is meant to be used in a browser, and built with browserify.
