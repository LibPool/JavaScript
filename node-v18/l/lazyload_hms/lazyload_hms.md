# lazyload_hms

> 标签: JavaScript

## 简介

* lazyload(config) - 初始化一个图片延迟加载 	* config.placeholder - 图片占位符，默认'http://b0.hucdn.com/img/h5/spaceball.gif' 	* config.initload - 插件初始化之后立即载入图片 	* config.event - 触发图片载入事件，scroll滚动，click点击，默认scroll 	* config.defaultTap - 点击事件使用click或者tap，默认click，目前不支持tap 	*
