# lantaidua-universal-auth

> 标签: auth, authentication, backend, clerk, database, github-auth, google-auth, lantaidua, microsoft-auth, nextjs, oauth, saml, single-sign-on, sso, supabase, universal

## 简介

A universal SSO authentication wrapper for Clerk with Supabase backend integration in Next.js. Clerk handles authentication & user management, Supabase provides database and backend services. Simplify SSO implementation with easy-to-use functions.
