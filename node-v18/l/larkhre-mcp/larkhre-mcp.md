# larkhre-mcp

> 标签: agent, ai, education, french, langage, larkhre, mcp, model-context-protocol

## 简介

Serveur MCP du langage Larkhré : permet à n'importe quel agent IA (Claude, etc.) d'ÉCRIRE et d'EXÉCUTER du code Larkhré pour de vrai — sortie console, dessins SVG, mémoire persistante.
