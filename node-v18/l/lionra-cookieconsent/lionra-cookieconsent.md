# lionra-cookieconsent

> 标签: consent-management, cookie-banner, cookie-consent, gdpr, i18n, privacy, rgpd, typescript, vanilla-js, zero-dependency

## 简介

Zero-dependency, plug-and-play cookie consent banner for any web page. Auto-display, granular categories, easy withdrawal button, light/dark theme, i18n, TypeScript types.
