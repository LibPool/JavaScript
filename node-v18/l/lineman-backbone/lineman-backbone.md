# lineman-backbone

> 标签: JavaScript

## 简介

This is a plugin to get started with backbone.js using [Lineman](http://linemanjs.com). We recommend you look at our [backbone template project](https://github.com/testdouble/lineman-backbone-template/) as a starting point.
