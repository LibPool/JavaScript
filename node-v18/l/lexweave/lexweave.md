# lexweave

> 标签: bilingual-reading, cli, comprehensible-input, diglot-weave, epub, graded-reader, immersion, language-learning, novel

## 简介

Turn any long-form text into a progressively bilingual learning edition (diglot weave / graded reader) from the command line — compile once with an LLM, render offline forever.
