# leafer-game

> 标签: 2d, canvas, engine, graphic, html5, leafer, leafer game, leafer-game, leafer-ui, leaferjs, leaferui, renderer

## 简介

**leafer-game** 在 [leafer-ui](https://github.com/leaferjs/leafer-ui) 的基础上，集成了 Robot、状态、 动画、运动路径插件，适用于小游戏场景。
