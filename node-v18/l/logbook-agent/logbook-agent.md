# logbook-agent

> 标签: agent-observability, ai-agents, audit, local-first, mcp, prompt-injection, security, tamper-evident

## 简介

Local-first, tamper-evident audit trail for AI agents. The operator holds the only key; the agent vendor can neither read nor forge the record. Includes an MCP proxy that records what an agent actually did, not what it self-reports.
