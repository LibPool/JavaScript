# loony-fetch

> 标签: ajax, browser, client, fetch, http, https, interceptors, node, promise, request, secure, xhr

## 简介

Lightweight, secure Promise-based HTTP client for Node.js and the browser. Supports interceptors, redirect following, AbortController, and hardened against prototype pollution, header injection, and XSRF token leakage.
