# lpg-modeler-cli

> 标签: cypher, data modeling, ddl, falkordb, gql, graph, kuzu, labeled property graph, ladybugdb, linkml, lpg, memgraph, neo4j, ontology, owl, pg-schema, property graph, rdf, schema, shacl

## 简介

Design a property graph once. Generate every schema from it: LadybugDB, Neo4j, FalkorDB, Memgraph, GQL, PG-Schema, SHACL, OWL and LinkML.
