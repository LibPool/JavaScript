# lineman-docs

> 标签: JavaScript

## 简介

This is a plugin to make it easy to use [docco](http://jashkenas.github.io/docco/) and [gh-pages](https://github.com/tschaub/grunt-gh-pages) with [Lineman](http://linemanjs.com) app.

- 源码仓库：git://github.com/jewelsjacobs/lineman-docs.git
