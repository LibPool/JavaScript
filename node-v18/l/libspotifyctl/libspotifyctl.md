# libspotifyctl

> 标签: audio, automation, cli, ffi, koffi, media, media-controls, now-playing, smtc, spotify, spotifyctl, win32, windows

## 简介

Offline control and observation of the Spotify desktop app on Windows (SMTC + Core Audio, no Web API).
