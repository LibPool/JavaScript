# lushapp

> 标签: ambient, audio-player, cava, cli, curses, lofi, music, python, radio, synthwave, terminal, tui, visualizer

## 简介

A hyper-aesthetic terminal radio player with 560+ live stations, real-time CAVA DSP audio visualizers, ambient soundscapes, and artist discographies.
