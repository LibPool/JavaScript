# locstore

> 标签: aes, browser-cache, cache, cache-api, cookie, encryption, frontend, indexeddb, localstorage, locstore, memory-storage, sessionstorage, storage, timespan, ttl, typescript, web

## 简介

A tiny TypeScript-first browser storage library with TTL, TimeSpan, sync/async APIs, adapters, and optional encryption.
