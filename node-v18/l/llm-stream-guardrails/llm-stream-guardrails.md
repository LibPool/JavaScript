# llm-stream-guardrails

> 标签: ai, ai-guardrails, ai-sdk, anonymization, anthropic, chatbot, data-loss-prevention, dlp, guardrails, llm, llm-guardrails, llm-security, masking, openai, pii, pii-redaction, redact, redaction, secret-scanning, secrets, streaming, vercel-ai-sdk

## 简介

Redact PII and secrets from an LLM response while it streams, without buffering it. Streamed output is byte-identical to filtering the whole string at once, at any chunk boundary. Zero dependencies, TypeScript, ESM.
