# loopclub-mcp

> 标签: claude, drum-machine, loopclub, mcp, megaeth, model-context-protocol, music, onchain

## 简介

Jam with Claude — an MCP server that turns a described beat into a loopclub link, ready to audition and rent on-chain. A pure encoder over loopgen; holds no keys, signs nothing.
