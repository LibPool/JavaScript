# @brainstorm-os/block-protocol

> 标签: JavaScript

## 简介

Transport-agnostic Block Protocol core for Brainstorm — the BP message envelope, the module router, and the hook-module router. Host bindings (e.g. the graph module → vault entities) live in the shell.
