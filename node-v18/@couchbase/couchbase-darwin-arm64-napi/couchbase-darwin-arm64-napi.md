# @couchbase/couchbase-darwin-arm64-napi

> 标签: JavaScript

## 简介

Couchbase Node.js SDK platform specific binary for napi runtime on darwin OS with arm64 architecture and boringssl.

## 官网

- 官网：http://www.couchbase.com/communities/nodejs
- 源码仓库：git+ssh://git@github.com/couchbase/couchnode.git
