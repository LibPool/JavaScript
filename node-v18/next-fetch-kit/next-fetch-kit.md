# next-fetch-kit

> 标签: api, auth, client, csr, fetch, http, next, nextjs, refresh-token, ssr, typescript

## 简介

A lightweight, type-safe fetch wrapper for Next.js — works in SSR & CSR with built-in auth refresh & cookie forwarding
