# @ihc/terminal-cloud-client-effect

> 标签: JavaScript

## 简介

Effect-TS wrapper around @ihc/terminal-cloud-client. Provides Tagged errors, a Service Tag, and Layer factories. Same Service targets either the cloud REST API or an on-LAN proxy — picked by the configured baseUrl.
