# @editrajs/react

> 标签: JavaScript

## 简介

React 19 adapter for Editra. `useEditra()` owns exactly one editor for its mounted content element and returns `{ editor, contentRef }`. `initialContent` is uncontrolled; later replacement is explicit through `editor.setContent()`. `EditraContent` renders
