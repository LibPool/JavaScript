# @neosyn-ee/event-management-common-nestjs

## 简介

Questo repository contiene un boilerplate per creare librerie riutilizzabili utilizzando il framework [NestJS](https://nestjs.com/). È progettato per agevolare lo sviluppo di moduli condivisi e funzionalità modulari per applicazioni NestJS.
