# @alkhipce/strapi-plugin-llm-translate

> 标签: ai, anthropic, claude, gpt, i18n, internationalization, llm, localization, openai, plugin, strapi, strapi-plugin, translation

## 简介

Auto-translate localized content into every enabled locale using an LLM provider (Anthropic Claude or OpenAI), right from the Content Manager edit view.
