# @wntediluvian/dsh-backup

> 标签: JavaScript

## 简介

Automated, UI-managed backup and restore for DeepSeek Harness: full+incremental backups of sessions, memory, user-installed plugins, skills, and config, with a settings card showing history and a restore button.
