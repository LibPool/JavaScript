# @nivalis/hubloot

> 标签: JavaScript

## 简介

CLI Hubloot : `npx @nivalis/hubloot validate` vérifie hors ligne que la Policy est cohérente avec le code, `npx @nivalis/hubloot summary` en imprime le résumé généré (ou son diff avec `--diff`).
