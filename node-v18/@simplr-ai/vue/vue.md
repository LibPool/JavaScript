# @simplr-ai/vue

> 标签: ai-delegation, behavioral-biometrics, composables, device-fingerprinting, feature-flags, fraud-detection, rum, simplr, vue, vue3

## 简介

Idiomatic Vue 3 adapter for the Simplr platform — composables, components and directives wrapping the @simplr-ai/js browser core (device fingerprint, behavioral biometrics, fraud/order checks, feature flags, RUM, profiles, AI delegation).
