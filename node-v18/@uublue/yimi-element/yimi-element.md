# @uublue/yimi-element

> 标签: action, dialog, element, element ui, modal, operation, table, vue, yimi, 弹窗, 表格

## 简介

yimi-element 是一个 Element UI 的增强组件库，目前包含组件：表格、模态框、操作、下载器、多选框组、开关面板、控制面板等。
