# @lordekeen/pi-chafa

> 标签: ansi-art, chafa, iterm2, kitty-graphics, pi, pi-extension, pi-package, terminal-image

## 简介

Show image files to the user in the pi terminal — native kitty/iTerm2 where supported, Chafa ANSI symbols everywhere else.
