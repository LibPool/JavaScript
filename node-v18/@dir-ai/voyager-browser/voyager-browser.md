# @dir-ai/voyager-browser

> 标签: accessibility, ai-agents, model-context-protocol, security, voyager, web

## 简介

Voyager's web-page sense: a safe, read-only observation of ONE live URL — structure, forms, links, scripts, security posture (CSP/HSTS/mixed-content) and accessibility signals. Static HTML, no JS execution, no headless browser.
