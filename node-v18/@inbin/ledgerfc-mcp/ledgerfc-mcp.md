# @inbin/ledgerfc-mcp

> 标签: arbitrage, cli, football, kalshi, ledgerfc, mcp, model-context-protocol, predictions, soccer, sports, stdio, tennis

## 简介

Stdio MCP wrapper for Ledger FC: gives Claude Desktop and other stdio-only MCP clients grounded sports predictions plus European soccer and tennis arbitrage data from Ledger FC's remote HTTP MCP endpoint. Free tools need no key.
