# @ctruhtech/verse-react

> 标签: 3d, ctruh, gltf, react, verse, viewer, web-component

## 简介

React wrapper for <verse-viewer>, the Verse Engine web component: typed props, callbacks for the viewer's events, a ref to the embed SDK API. SSR-safe (Next.js, Remix, Gatsby).
