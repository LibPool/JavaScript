# @traveler123/t-scanner

> 标签: camera, canvas, document, edge-detection, headless, homography, perspective, react, scanner

## 简介

Headless document scanner for the browser: edge detection, auto corner detection, perspective warp and scan filters. Framework-agnostic core + optional React hook and UI.
