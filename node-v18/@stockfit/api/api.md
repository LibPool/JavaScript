# @stockfit/api

> 标签: api, edgar, etf, financials, fundamentals, sdk, sec, stockfit, stocks

## 简介

Official TypeScript/Node.js SDK for the StockFit API (developer.stockfit.io) — SEC EDGAR financials, filings, fund data, ownership, and earnings.

## 官网

- 官网：https://developer.stockfit.io
- 源码仓库：git+https://github.com/Second-Dot-LLC/stockfit-api.git
- npm 页面：https://www.npmjs.com/package/@stockfit/api
