# @lyxx/dsh-session-autotitle

> 标签: autotitle, deepseek-harness, dsh, plugin, session-title

## 简介

DSH 会话自动命名：全消息 LLM 总结标题（首条提示词/handoff 自动 + 会话头按钮/命令手动），标题调用强制关思考，标题语言与最大字节数可设置。适配 DSH ≥ 0.1.2-rc.1。
