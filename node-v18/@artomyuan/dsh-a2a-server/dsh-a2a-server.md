# @artomyuan/dsh-a2a-server

> 标签: a2a, agent2agent, ai-agent, cordis, deepseek-harness, dsh-plugin

## 简介

A2A (Agent2Agent) server bundle for DeepSeek Harness: exposes dsh agent sessions over the A2A protocol so remote agents (e.g. Hermes) can interoperate with a dsh profile.
