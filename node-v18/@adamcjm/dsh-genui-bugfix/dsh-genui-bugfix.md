# @adamcjm/dsh-genui-bugfix

> 标签: bugfix, deepseek, deepseek-harness, dsh, dsh-plugin, dsh-ui, genui, overflow, table

## 简介

DeepSeek Harness plugin that stops dsh-ui table cells from painting their text over the next column, and lets long cells wrap instead of forcing a horizontal scrollbar.
