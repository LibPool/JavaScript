# @light-merlin-dark/merlin-cli

> 标签: agent-friendly, argv-parser, bun, cli, cli-framework, command-line, commander-alternative, conformance, deno, dependency-injection, exit-code, json-output, lazy-loading, machine-readable, middleware, ndjson, node, service-registry, typescript, zero-dependencies

## 简介

A TypeScript CLI framework whose commands are readable by machines: honest exit codes, --json and --ndjson for free, and a manifest that describes the whole tool in one call.
