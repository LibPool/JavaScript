# @le5le/live-player

> 标签: flv, gb28181, h265, hevc, live-player, webrtc, ws-flv

## 简介

浏览器摄像头与直播播放器：WS-FLV / HTTP-FLV / WebRTC 直播 + 录像回放，一个地址自动识别容器，专治 H265 切后台断流与多路同屏带不动 | Browser player for IP cameras and live streams: WS-FLV / HTTP-FLV / WebRTC live plus recording playback, transport auto-detected from the URL, built to fix H265 stalls af
