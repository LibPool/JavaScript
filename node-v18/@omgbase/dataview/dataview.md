# @omgbase/dataview

> 标签: dataview, dql, obsidian, omgbase, oqx, query, query-language, translator

## 简介

A Dataview Query Language (DQL) to OQX translator: TABLE / LIST / TASK / CALENDAR queries become one OQX string plus a render shape for an omgbase client
