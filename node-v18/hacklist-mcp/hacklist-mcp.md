# hacklist-mcp

> 标签: ai, chatgpt, claude, hackathon, hacklist, mcp, web3

## 简介

MCP server for HackList (hacklist.io): search AI & Web3 hackathons, grants and programs, see when they were listed, and rank the non-generic ones worth building for.
