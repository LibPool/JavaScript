# @spendguard/botpress-integration

> 标签: agent, botpress, budget, generateContent, guardrails, integration-sdk, llm, llm-provider, spend, spendguard

## 简介

SpendGuard Botpress LLM-provider integration — fail-closed, pre-dispatch budget reservation for Botpress LLM spend. Implements the Botpress `generateContent` action: reserves spend against the SpendGuard sidecar HTTP companion before forwarding to the ups
