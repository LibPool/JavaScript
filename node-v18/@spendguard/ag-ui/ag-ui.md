# @spendguard/ag-ui

> 标签: ag-ui, agent, budget, events, llm, spend, spendguard

## 简介

SpendGuard spend-event family for AG-UI — display-only CUSTOM event builders (budget snapshot, reservation lifecycle, deny reasons). Enforcement stays in the SpendGuard adapters and sidecar.
