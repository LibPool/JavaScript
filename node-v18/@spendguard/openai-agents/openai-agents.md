# @spendguard/openai-agents

> 标签: agent, agents-sdk, budget, guardrails, llm, openai, openai-agents, spend, spendguard

## 简介

OpenAI Agents SDK (TypeScript) adapter for SpendGuard budget guardrails — drop-in via `withSpendGuard(model, opts)` on any `@openai/agents` Model.
