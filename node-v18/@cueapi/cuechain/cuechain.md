# @cueapi/cuechain

> 标签: accountability, agent, agent-infrastructure, agents, ai, ai-agents, claude, contract, cueapi, gemini, gpt, llm, llm-chain, llm-observability, llm-workflow, pipeline, quality-gate, typescript, verification, workflow, zod

## 简介

TypeScript primitive for verifying contracts between LLM pipeline steps. Typed inputs/outputs via Zod, quality gates with retry, and failure context that makes silent agent failure impossible.
