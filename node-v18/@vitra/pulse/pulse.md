# @vitra/pulse

> 标签: JavaScript

## 简介

Use Vitra Pulse from Claude Code, Codex or any MCP client: see what Pulse can do on this Mac, start and follow jobs, ask the person for an OK. A thin launcher for the vitra-pulse MCP server bundled in Vitra Pulse.app.
