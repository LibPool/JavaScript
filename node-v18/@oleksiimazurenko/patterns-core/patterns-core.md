# @oleksiimazurenko/patterns-core

> 标签: accordion, container-queries, css, fit-text, parallax, patterns, server-first, slider, zero-js

## 简介

Framework-agnostic core for react-patterns — pure CSS building blocks (fit-text, parallax, accordion, slider, …) with zero runtime JS. Each recipe is a subpath export.
