# dsh-client-ui-webchat

> 标签: deepseek, dsh, dsh-client-ui, dsh-plugin, electron, webchat

## 简介

DeepSeek web chat inside the DSH desktop GUI: a native panel for chat.deepseek.com with two-way handoff between the page and an agent session. The embedded browser session is per app launch, so the page asks for a login once per start.
