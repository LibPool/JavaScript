# @zkstables/sdk-react-native

> 标签: encrypted-balance, noir, privacy, react-native, ultrahonk, zk

## 简介

React Native bindings for the native UltraHonk-Keccak ZK prover and Boosted-Kangaroos dlog solver (Rust via UniFFI). Android and iOS.
