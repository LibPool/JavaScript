# @atlasprotocol/types

> 标签: atlas, atlas-protocol, schemas, types

## 简介

Shared TypeScript type definitions for the ATLAS Protocol — events, ticket types, manifests, purchase challenges, W3C VC receipts, and IPFS pinner abstractions.
