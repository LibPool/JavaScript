# @atlasprotocol/mpp

> 标签: agent-commerce, atlas, http-402, jws, machine-payments, mpp, stripe, tempo, x402

## 简介

Standalone implementation of the Machine Payments Protocol (MPP) envelope: challenge / credential / receipt encode + sign + verify. Optional JWS wrapping layer for signed envelopes. Optional x402 client (on-chain USDC) and stripe-mpp client (Stripe SPT) f
