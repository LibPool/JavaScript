# @quadcore-lib/storage-server

> 标签: JavaScript

## 简介

Subida de archivos/imágenes con **driver intercambiable** (local/S3/R2). Validación de tamaño y MIME, URLs firmadas. Upload/borrado **admin**. Trae `LocalStorageDriver` por defecto. Alimenta el campo `images` de products.
