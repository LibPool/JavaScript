# @osm-editor-kit/live-touched

> 标签: conflicts, editor, iD, live, openstreetmap, osm

## 简介

See live which OSM objects other mappers are editing near you, before they upload. Editor-agnostic wiring (API, sync, polling, status); each editor brings its own UI.
