# @canwork/boxwood

> 标签: absolute-coordinates, box-model, canvas-layout, declarative-layout, layout-engine, remotion, svg-layout, vector-graphics

## 简介

A Declarative Box-Split and Collision Engine for Vector Graphics. It provides a CSS-like layout grammar (padding, gap, cols, rows, auto-height), but outputs a clean JSON coordinate tree that any visual canvas (SVG, <canvas>, WebGL) can use to draw pixels,
