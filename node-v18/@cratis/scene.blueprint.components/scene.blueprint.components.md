# @cratis/scene.blueprint.components

> 标签: blueprint, cqrs, cratis, event-sourcing, react, scene, templates, ui

## 简介

A blueprint of Arc-bound screen and dialog templates: full pages built from Cratis Components composites, so a data list, a command form or a master-detail screen is a template rather than something you assemble.
