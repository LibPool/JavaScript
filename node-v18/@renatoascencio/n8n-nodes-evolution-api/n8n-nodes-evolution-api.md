# @renatoascencio/n8n-nodes-evolution-api

> 标签: baileys, chatbot, chatwoot, evolution-api, messaging, n8n, n8n-community-node-package, whatsapp

## 简介

n8n community node for Evolution API v2 (WhatsApp) - manage instances, send messages, chats, groups, labels, webhooks and the Chatwoot/chatbot integrations. Works with Evolution API 2.3.x and 2.4.x
