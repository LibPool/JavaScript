# @cra-agent/mcp

> 标签: agent-payments, ai-agents, arc, circle, circle-gateway, claude, cli, mcp, mcp-server, micropayments, model-context-protocol, nanopayments, usdc, x402

## 简介

MCP server and CLI that let an AI agent pay for x402 APIs in USDC on Arc, under a spending policy the model cannot change.
