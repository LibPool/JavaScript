# @alexa-games/sfb-story-debugger

> 标签: Alexa, game, skill, story, voice

## 简介

Alexa Skill Flow Builder Framework (SFB-F) story debugger. Can run terminal runtime test with StoryMetadata imported by sfb-f core module.
