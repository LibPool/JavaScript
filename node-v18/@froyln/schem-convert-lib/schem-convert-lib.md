# @froyln/schem-convert-lib

> 标签: litematic, litematica, minecraft, nbt, schematic

## 简介

Converts Litematica .litematic schematics between Minecraft versions, rewriting the block/item palette so unsupported blocks and items get substituted instead of silently disappearing.
