# @qcom.io/qcom-cli

> 标签: @qcom.io, @qcom.io/qcom, CLI, HTMLElement, Web Elements, Web components, javascript framework, javascript library

## 简介

Qcom CLI is a comfortable environment for creating Web Components in QcomJs, and is the best way to start building a new single-page application by creating custom web elements in QcomJs.
