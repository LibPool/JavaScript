# @tokenmix/opencode-plugin

> 标签: ai, coding-agent, llm, opencode, opencode-plugin, tokenmix

## 简介

OpenCode plugin that adds tokenmix.ai account tools (top-up, model catalog, balance hints) and a chat session usage tracker.
