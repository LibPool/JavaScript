# @astergaze/commentor-core

> 标签: annotation, bug-report, comments, feedback, widget

## 简介

Framework-agnostic in-app comment capture engine. Point at an element, type, and an issue exists with the element, URL, viewport and screenshot attached. Works inside focus-trapping modals (Radix/shadcn, Mantine); not inside a native <dialog>.showModal(),
