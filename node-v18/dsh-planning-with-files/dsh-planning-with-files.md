# dsh-planning-with-files

> 标签: ai-agents, coding-agent, context-engineering, cordis, deepseek-harness, dsh, dsh-plugin, long-running-agents, planning, planning-with-files

## 简介

Native DeepSeek Harness (dsh) plugin for planning-with-files: per-turn plan injection, write reminders, compaction recovery, a turn-stopping completion gate, /pwf and /pwf-status commands, and pwf_init / pwf_status / pwf_check tools.
