# @solana-mobile/mobile-wallet-adapter-walletlib

> 标签: JavaScript

## 简介

A React Native wrapper of the Solana Mobile, Mobile Wallet Adapter Wallet Library. Wallet apps can use this to handle dapp requests for signing and sending.
