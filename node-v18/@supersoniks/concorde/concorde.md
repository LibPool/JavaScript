# @supersoniks/concorde

> 标签: JavaScript

## 简介

`@supersoniks/concorde` — framework de composants Web basé sur Lit avec système de thèmes, data binding (décorateurs `@subscribe` / `@publish` / `@handle` / `@bind`...) et composants réutilisables.
