> 标签: academic, affiliations, author-disambiguation, bun, mcp, mcp-server, model-context-protocol, orcid, research-profiles, researcher-identity, scholarly, scientific-publishing, stdio, streamable-http, typescript

## 简介

Search and retrieve researcher profiles, works, affiliations, funding, and peer review records from the ORCID registry via MCP. STDIO or Streamable HTTP.
