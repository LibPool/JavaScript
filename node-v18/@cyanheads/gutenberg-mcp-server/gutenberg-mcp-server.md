> 标签: ai-agent, books, bun, ebooks, gutenberg, literature, mcp, mcp-server, model-context-protocol, project-gutenberg, public-domain, stdio, streamable-http, typescript

## 简介

Search, browse, and read 78,000+ public-domain books from Project Gutenberg with full plain-text retrieval and offset/limit chunking via MCP. STDIO or Streamable HTTP.
