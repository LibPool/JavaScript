# @cyanheads/transitland-mcp-server

> 标签: ai-agent, bun, departures, gbfs, gtfs, gtfs-realtime, mcp, mcp-server, model-context-protocol, public-transit, stdio, streamable-http, transit, transit-feeds, transitland, typescript

## 简介

Global transit data from the Transitland v2 registry — operators, GTFS/GTFS-RT/GBFS feeds with license terms, routes, stops, and real-time-aware departures via MCP. STDIO or Streamable HTTP.
