# @cyanheads/fbi-crime-mcp-server

> 标签: bun, cde, crime-data, crime-statistics, fbi, law-enforcement, leoka, mcp, mcp-server, model-context-protocol, public-safety, stdio, streamable-http, typescript, ucr

## 简介

Exposes the FBI Crime Data Explorer API — monthly UCR offense rates and counts by national, state, or agency scope, plus LEOKA officer-safety statistics via MCP. STDIO or Streamable HTTP.
