# @anisirji/kb-client

> 标签: ai, chromadb, embeddings, knowledge-base, machine-learning, openai, pinecone, rag, retrieval, semantic-search, similarity-search, typescript, vector-database, vector-search

## 简介

Universal vector database client for ChromaDB and Pinecone with OpenAI embeddings. Simple addData() and getData() API for semantic search, RAG applications, and knowledge base management.
