# @icos-desktop/react-components

> 标签: ant-design, antd, components, desktop, icos, react, typescript, ui, 台账, 实体资源, 视频播放

## 简介

ICOS 前端组件库是一个基于 React 和 Ant Design 的企业级组件库，提供了丰富的业务组件，帮助开发者快速构建 ICOS 桌面应用。包含 31+ 个业务组件，覆盖台账管理、实体资源、视频播放等场景。
