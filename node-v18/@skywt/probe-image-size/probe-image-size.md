# @skywt/probe-image-size

> 标签: avif, bmp, gif, heic, ico, image, jpeg, jpg, png, psd, size, svg, tiff, webp

## 简介

Get image size without full download (JPG, GIF, PNG, WebP, BMP, TIFF, PSD, AVIF, HEIC)
