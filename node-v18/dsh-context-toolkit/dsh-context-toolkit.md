# dsh-context-toolkit

> 标签: context, deepseek-harness, dsh, dsh-plugin, fts5, token-saving

## 简介

DeepSeek Harness bundle: native ctk_* sandbox tools, a routing gate that keeps bulk output out of the transcript, and a local full-text knowledge base. No third-party runtime dependencies.
