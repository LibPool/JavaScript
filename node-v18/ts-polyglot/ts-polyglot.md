# ts-polyglot

> 标签: addon, c, content-mapper, cpp, ffi, import, napi, native, node-api, rust, typescript

## 简介

Import functions from C, C++ and Rust files into TypeScript. A content mapper types them; a Node-API addon built on import runs them.
