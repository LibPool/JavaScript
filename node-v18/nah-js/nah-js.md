# nah-js

> 标签: agent, ai-sdk, harness, http, nah, nextjs, route-handler, sse, streaming, web

## 简介

The standalone name for not-another-harness/js: a Web runtime for building agents in your own application. Mount the harness on any Request -> Response handler, stream its events over SSE, and let a paused turn resume on the next request.
