# @lyhalal/dsh-notification-center

> 标签: JavaScript

## 简介

通知中心：对话/任务完成、报错、等待批准等事件触发浏览器通知 + 21 种匹配音效，每类事件独立配置（音效/文件/URL/音量/开关）。
