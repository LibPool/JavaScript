> 标签: css-custom-properties, design-system, design-tokens, every-layout, motion, presets, style-dictionary

## 简介

Design system for nicohaberkorn.com: layered design tokens (palette -> reference -> role -> component) resolved at build time into preset-scoped CSS (marginalia, modern-classic, technology, solarpunk), plus intrinsic layout primitives and motion component
