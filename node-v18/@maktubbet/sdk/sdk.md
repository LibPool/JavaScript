# @maktubbet/sdk

> 标签: JavaScript

## 简介

Embeddable iGaming components for casino game integration. Available games: Dice, Limbo, Mines, Keno, Plinko, Roulette, Wheel, Coin Flip, Blackjack, and Hi-Lo.
