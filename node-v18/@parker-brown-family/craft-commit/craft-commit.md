# @parker-brown-family/craft-commit

> 标签: commit, doctrine, git, hook, lint, narrative

## 简介

Lint git commit messages for the narrative doctrine: a subject sentence and three why-focused paragraphs, no Conventional-Commits prefix, no 50/72 cap, no AI attribution. Written for the agent who reads the history next.
