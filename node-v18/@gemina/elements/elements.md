# @gemina/elements

> 标签: chat, document-intelligence, embeddable, gemina, invoice, rag, react

## 简介

Embeddable browser UI for Gemina Document Intelligence — a drop-in React chat component plus a security-hardened session-token manager. The API key never enters the browser.
