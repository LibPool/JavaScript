# @agent-tools-kiko/n8n-mcp

> 标签: ai-agent, automation, claude, llm-tools, mcp, model-context-protocol, n8n, workflow

## 简介

MCP server for n8n — build, deploy, debug and manage workflows with Claude. Supports stdio (Claude Code) and HTTP (Claude Desktop custom connector).
