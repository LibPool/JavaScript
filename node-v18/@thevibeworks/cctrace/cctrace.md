# @thevibeworks/cctrace

> 标签: anthropic, claude, claude-code, cli, debug, http, inspector, mitm, proxy, tls, trace

## 简介

TLS-intercepting HTTP tracer for the Claude Code, Codex, and Grok CLIs — captures every API call (messages, OAuth, usage/credits, MCP) with a live web UI: reconstructed sessions, replay, cost/cache/latency chips. External hosts pass through as byte-counte
