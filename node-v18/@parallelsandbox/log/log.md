# @parallelsandbox/log

> 标签: browser, error-tracking, logging, parallelsandbox, sourcemap

## 简介

Browser SDK that ships console output and uncaught errors from your app (and the ParallelSandbox box it runs in) to log.parallelsandbox.com.

- 官网：https://github.com/parallel-sandbox/parallelsandbox_log_server#readme
