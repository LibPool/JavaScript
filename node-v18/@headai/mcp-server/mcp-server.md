# @headai/mcp-server

> 标签: ai, anthropic, chatgpt, claude, headai, knowledge-graph, mcp, model-context-protocol, openai, skills, workforce-intelligence

## 简介

MCP server for Headai Core Engine — knowledge graphs, skill analytics, recommendations, scorecards, and signals. Connect Claude, ChatGPT, or any MCP client to Headai's AI workforce intelligence APIs.
