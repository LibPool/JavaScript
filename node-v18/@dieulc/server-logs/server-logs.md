# @dieulc/server-logs

> 标签: devops, docker, journal, pi-package, server-logs, ssh, systemd

## 简介

Pi extension: inspect Docker containers and systemd services on a remote VPS over SSH, or locally. Custom tools for logs, ps, compose, and journal.
