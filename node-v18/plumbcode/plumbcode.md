# plumbcode

> 标签: agent-readiness, claude-code, claude-code-plugin, code-review, codegraph, evidence, express, spec-driven-development, specs, traceability

## 简介

Know what your code really does, with proof, before you change it. Evidence-backed specs, honest test coverage and an agent-readiness report for existing codebases.
