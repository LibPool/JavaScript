# @sophat/cookies

> 标签: browser-cookies, browser-storage, client-storage, cookie-getter, cookie-handler, cookie-management, cookie-parser, cookie-setter, cookie-utility, cookies, javascript-cookies, typescript, web-cookies, web-storage

## 简介

This project provides a set of utility functions for interacting with browser cookies. The `Cookies` class offers methods to set, get, update, remove, and clear cookies, as well as retrieve all cookie keys.
