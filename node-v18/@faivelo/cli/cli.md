# @faivelo/cli

> 标签: agent inbox, ai agent, cli, custom domain, dns, email, faivelo, mailbox, mcp

## 简介

Email from the terminal: npx faivelo inbox gives an agent a free inbox and key with no sign-in; npx faivelo init sets up your own domain
