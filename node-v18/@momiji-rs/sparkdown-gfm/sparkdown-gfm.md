# @momiji-rs/sparkdown-gfm

> 标签: commonmark, gfm, github, html, markdown, parser, strikethrough, tables, wasm, webassembly

## 简介

Fast CommonMark + GitHub Flavored Markdown → HTML (strikethrough, task lists, autolinks, tag filter, tables), as WASI-free WebAssembly. Zero dependencies; runs in Node, browsers, bundlers, Deno, and edge runtimes.
