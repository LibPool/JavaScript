# dsh-llm-sampling-params

> 标签: deepseek-harness, dsh, dsh-plugin, llama-server, llama.cpp, min_p, openai-compatible, repeat_penalty, repetition_penalty, sampling, sglang, top_p, vllm

## 简介

DSH plugin: inject per-model sampling parameters (top_p, top_k, min_p, repeat_penalty/repetition_penalty, presence_penalty, frequency_penalty) into every chat-completions request sent to an OpenAI-compatible gateway (llama.cpp, SGLang, vLLM).
