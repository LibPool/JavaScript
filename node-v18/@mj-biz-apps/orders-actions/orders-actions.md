# @mj-biz-apps/orders-actions

> 标签: JavaScript

## 简介

Action subclasses for BizApps Orders — the CodeGen-maintained generated set. Hand-authored server-side actions live in @mj-biz-apps/orders-server; this package is `shared` and must stay browser-safe.
