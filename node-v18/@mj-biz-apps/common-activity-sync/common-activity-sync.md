# @mj-biz-apps/common-activity-sync

> 标签: JavaScript

## 简介

Activity Sync Engine contracts for BizApps Common — provider plugin base class, qualification cascade, and the in-process extension contract that lets downstream apps enrich an Activity inside its own write transaction.
