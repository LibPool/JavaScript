# dsh-conv-calendar

> 标签: calendar, contribution-calendar, contribution-graph, deepseek, deepseek-harness, dsh, dsh-plugin, heatmap, stats, tokens, usage

## 简介

GitHub-style conversation calendar for DeepSeek Harness: prompts, sessions and token usage per day, drawn as a contribution grid in the Web GUI.
