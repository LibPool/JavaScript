# @brandsystem/mcp

> 标签: agent-tools, ai-agents, ai-branding, ai-tools, brand, brand-compliance, brand-governance, brand-guidelines, brand-identity, brand-runtime, brand-voice, claude-design, design-system, design-tokens, mcp, mcp-server, model-context-protocol, visual-identity

## 简介

Use existing brand guidelines with AI. This MCP server turns websites, PDFs, and Figma libraries into a portable .brand runtime with design tokens, voice rules, provenance, and compliance checks.
