# opencode-usage-insights

> 标签: bun, cache-affinity, cost-tracking, observability, opencode, opencode-plugin, opencode-tui, prompt-cache, sqlite, telemetry, token-usage, tui, typescript, usage-statistics

## 简介

OpenCode V2 plugin: a live turn telemetry line plus a persistent SQLite usage record, read back by an interactive /usage panel — models, providers, prompt cache, periods and latency.
