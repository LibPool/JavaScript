# @solidnative/metro

> 标签: android, bundler, css, fabric, ios, metro, native, react-native, solid, solidjs, solidnative

## 简介

Metro config preset and transformer for solidnative on Solid: Solid's native JSX transform, build-time CSS compiler, icon inlining and clean reload.
