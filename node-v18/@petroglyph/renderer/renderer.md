# @petroglyph/renderer

> 标签: markdown, obsidian, pkm, rehype, remark, renderer, wikilinks

## 简介

Markdown renderers for Petroglyph. Supports Obsidian-flavored Markdown with wikilinks, callouts, and embeds.
