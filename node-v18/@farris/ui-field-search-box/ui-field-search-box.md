# @farris/ui-field-search-box

> 标签: JavaScript

## 简介

用于数据过滤：按多个字段挑选过滤字段、逐个配置「比较运算符 + 值」，最终产出一组查询条件交给宿主（表格、列表等）去过滤数据。
