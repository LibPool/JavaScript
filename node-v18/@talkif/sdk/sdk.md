# @talkif/sdk

> 标签: JavaScript

## 简介

Official TypeScript / Node.js client for the [Talkif API](https://docs.talkif.ai/api-reference) — programmable AI voice agents: place and receive calls, manage flows, contacts, campaigns, phone numbers and billing.
