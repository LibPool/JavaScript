# @openguardrails/opencode-auto-mode

> 标签: agent, ai, approval, auto-mode, guardrails, ogr, opencode, openguardrails, permissions, plugin, security

## 简介

Auto mode for opencode: permission prompts answered by OpenGuardrails policy instead of a human — agent-configurable text/regex guardrails, or your own model as the judge. No core changes.
