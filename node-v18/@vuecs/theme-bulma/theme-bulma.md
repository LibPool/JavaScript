# @vuecs/theme-bulma

> 标签: bulma, theme, vuecs

## 简介

Bulma theme for vuecs components. Targets Bulma 1.0+ (CSS-variable-based theming); the version number tracks vuecs theme breaking changes, not Bulma's.
