# @fusionkit/session-hermetic

> 标签: JavaScript

## 简介

Hermetic session backend for Warrant runners: a simulated bash interpreter (just-bash) with a virtual filesystem and interpreter-enforced network allowlists. No real processes or sockets to escape with.
