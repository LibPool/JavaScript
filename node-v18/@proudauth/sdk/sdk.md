# @proudauth/sdk

> 标签: bff, introspection, jwt, oauth2, oidc, proudauth, resource-server

## 简介

ProudAuth backend SDK for Node.js: offline JWT access-token verification, strict-online introspection with the support-access contract, an OIDC backend-for-frontend client and a typed administration client.
