# @gracile-labs/functional

> 标签: custom-elements, fc, functional-component, hooks, lit, lit-fc, render-tree, signals, ssr, web-components

## 简介

Lightweight hooks and context primitives for signal-based render trees. Works anywhere a render function can be scoped, with Lit or similar templating libraries. Uses the TC39 Signal Proposal for its backend.
