# @setheum.js/eth-rpc-adaptor

> 标签: JavaScript

## 简介

A node service that allows existing Ethereum dApp to be able to interact with [Setheum EVM](https://github.com/Setheum-Labs/Setheum/tree/master/lib-serml/evm).
