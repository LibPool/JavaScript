# @uxlint-net/uxlint

> 标签: a11y, accessibility, audit, code-review, design, lighthouse, mcp, mcp-server, modelcontextprotocol, ux

## 简介

Audit any website's UX the way a design-literate reviewer would — contrast, tap targets, type scale, copy, scan patterns, resilience — with a concrete fix for every finding. Runs in the Chrome you already have; built for coding agents (MCP).
