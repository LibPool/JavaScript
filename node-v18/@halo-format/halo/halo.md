# @halo-format/halo

> 标签: ai-agents, content-addressed, halo, llm, merkle, tool-results

## 简介

Halo core: encode a value into a content-addressed navigable tree and read it back, verified. Zero runtime deps beyond a hashing primitive and a JCS canonicalizer.
