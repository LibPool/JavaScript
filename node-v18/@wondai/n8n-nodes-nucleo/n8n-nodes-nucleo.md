# @wondai/n8n-nodes-nucleo

> 标签: ai-tool, crm, n8n, n8n-community-node-package, nucleo, odonto, padaria, wondai

## 简介

Node n8n para o Núcleo Wondai — atendimento multi-vertical e relay seguro de canal com HMAC v1. Tenant vem do token; credenciais Evolution nunca chegam ao n8n.
