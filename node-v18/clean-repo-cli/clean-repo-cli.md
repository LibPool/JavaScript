# clean-repo-cli

> 标签: bloat, cli, developer-tools, git, gitignore, leak-detection, repo-hygiene, secret-scanner, security

## 简介

Fast, zero-dependency repository hygiene auditor and secret leak sentinel. Scans for credential leaks, git bloat, and repairs .gitignore rules automatically.
