# @insler/platform

> 标签: JavaScript

## 简介

The insler platform in one package — fleet scanning and a desired-state model, a pluggable deployment-artifact generator, and a plan/diff reconciler, each importable as its own subpath entrypoint (/fleet, /generator, /reconciler).
