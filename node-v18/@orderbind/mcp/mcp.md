# @orderbind/mcp

> 标签: JavaScript

## 简介

Orderbind procurement agent toolkit: MCP server (search, sourcing, basket planning, par-level replenishment, cryptographically signed order commits), onboarding wizard, and a cron-friendly replenishment runner. Keys and mandates stay on your machine — Ord
