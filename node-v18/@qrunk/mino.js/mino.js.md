# @qrunk/mino.js

> 标签: controller, gamecube, gamepad, gaming, input, mayflash, melee, nintendo, raphnet, smash

## 简介

GameCube controller library for the browser. Supports Nintendo, Mayflash, and Raphnet adapters via the W3C Gamepad API.
