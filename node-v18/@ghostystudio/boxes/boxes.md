# @ghostystudio/boxes

> 标签: animation, avatar, canvas, ghosty, mascot, react, robot, web-component

## 简介

Ghosty's animated box robots: a canvas TV-head with moods, screens, themes and finishes, plus the box detail sheet and hover card. Web component, React components, or a plain <script>.
