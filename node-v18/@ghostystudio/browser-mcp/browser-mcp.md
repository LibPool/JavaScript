# @ghostystudio/browser-mcp

> 标签: browser, browser-automation, chrome, claude-code, codex, cursor, ghosty, mcp, model-context-protocol

## 简介

MCP server that gives any coding agent (Claude Code, Cursor, Codex…) the user's own Chrome through the Ghosty for Chrome extension — locally via native messaging or remotely via Ghosty Studio.
