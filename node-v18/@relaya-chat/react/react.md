# @relaya-chat/react

> 标签: chat, community-chat, component-library, embeddable, live, moderation, radio, react, react-component, real-time, realtime, ugc, websocket

## 简介

Drop-in community chat component for React apps — real-time, moderated, WebSocket-based. Connects to the Relaya™ SaaS at api.relaya.chat. Embed with one line or go headless with hooks.
