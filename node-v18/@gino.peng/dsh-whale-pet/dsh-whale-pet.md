# @gino.peng/dsh-whale-pet

> 标签: JavaScript

## 简介

DeepSeek Harness 屏幕鲸鱼宠物插件：内置/自定义形象（SVG 粘贴 + 图片上传）、拖拽移动、随机巡游、点击俏皮回复（可选 DeepSeek API 模型生成）。
