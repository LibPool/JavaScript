# @konce-pt/chart

> 标签: charts, data-visualization, design-system, koncept-ui, kpt, svg

## 简介

Chart geometry core for Koncept UI — scales, line and area paths, bar layout, pie and radar geometry. Framework-free TypeScript, zero runtime dependencies.
