# @evancnavarro/changelog-react

> 标签: JavaScript

## 简介

React changelog page: grouped entries, deep-link highlight, copy-link, search, back-to-top. Consumes @evancnavarro/changelog-core + @evancnavarro/anchor-highlight. Portable (semantic classes + themeable CSS, no Tailwind).
