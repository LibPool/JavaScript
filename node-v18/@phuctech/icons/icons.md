# @phuctech/icons

> 标签: JavaScript

## 简介

Hướng `soft` đã được duyệt với 50 icon; hướng `geometric` vẫn được giữ trong thư mục prototype để đối chiếu lịch sử, không được sinh vào API runtime. Đây là bước M3/M4 trong [DESIGN-SYSTEM-ICON-PLAN.md](../../DESIGN-SYSTEM-ICON-PLAN.md).
