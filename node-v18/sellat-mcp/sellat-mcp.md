# sellat-mcp

> 标签: bitcoin, eidas, mcp, model-context-protocol, opentimestamps, polygon, proof-of-existence, qualified-timestamp, rfc3161, timestamping

## 简介

MCP server for SELLAT: proof of existence from Claude, Cursor or any MCP client. Hashes locally — your files never leave your machine. Polygon, Bitcoin and the FNMT qualified eIDAS seal.
