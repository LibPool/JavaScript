# @simplymsg/mcp

> 标签: agent, ai, claude, cursor, mcp, messaging, model-context-protocol, simplymsg, whatsapp

## 简介

Official Model Context Protocol (MCP) server for SimplyMsg — call WhatsApp messaging tools from Claude, Cursor, ChatGPT, and any MCP-capable AI host.
