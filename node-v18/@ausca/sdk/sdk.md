# @ausca/sdk

> 标签: agents, ausca, payments, sdk, x402

## 简介

Typed client for Ausca metered agent infrastructure services: catalog-bound invocations paid per call under a hard USD cap, through pluggable payment authorities (x402 v2 today), with receipt-backed results.
