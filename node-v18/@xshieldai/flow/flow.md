> 标签: agent-governance, agent-safety, agentic-flow, claude-code-hooks, delegation, governed-turn-protocol, least-privilege, xshieldai

## 简介

One agentic flow, end to end: GTP flow identity for tool calls, subagents and events (flow, turn, parent, mandate, session), narrowing that only shrinks (child = parent & requested), refusal of a missing parent, and a mapper from Claude Code hook input. P
