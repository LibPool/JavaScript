# @wolfstar/plugin-logger

> 标签: consola, evlog, http-framework, logger, logging, plugin, sentry, winston, wolfstar

## 简介

Plugin for @wolfstar/http-framework providing a pluggable logger with swappable transports (console, Sentry, consola, evlog, winston)
