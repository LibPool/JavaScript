# @worldwideview/wwv-plugin-maritime

> 标签: ais, cesium, globe, maritime, ships, vessel-tracking, worldwideview, worldwideview-plugin, wwv-plugin-maritime

## 简介

WorldWideView plugin for real-time vessel tracking via AIS feeds. Color-coded by vessel type with speed and heading indicators
