# @worldwideview/wwv-plugin-military

> 标签: adsb, aircraft-tracking, cesium, globe, military, military-aviation, worldwideview, worldwideview-plugin, wwv-plugin-military

## 简介

WorldWideView plugin for real-time military aircraft tracking via adsb.fi. Features altitude-based coloring, flight trail rendering, and aircraft type filters
