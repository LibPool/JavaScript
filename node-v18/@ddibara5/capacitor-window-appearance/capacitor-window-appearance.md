# @ddibara5/capacitor-window-appearance

> 标签: appearance, capacitor, capacitor-plugin, dark-mode, ios, overrideUserInterfaceStyle

## 简介

Capacitor 8 iOS plugin: set the window's light, dark or system appearance (overrideUserInterfaceStyle) so native bars follow an in-app choice.
