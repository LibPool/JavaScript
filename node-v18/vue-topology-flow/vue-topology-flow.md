# vue-topology-flow

> 标签: JavaScript

## 简介

基于 AntV X6 的拓扑图绘制组件 (含告警状态(红色外框+右上角角标)、分组、右键菜单可配置等能力), 提供手动/自动拓扑编排与只读预览模式
