# @rickydata/notebooklm-mcp

> 标签: JavaScript

## 简介

Robust, deployable NotebookLM MCP driven by NotebookLM's internal batchexecute RPC API (no DOM scraping at runtime): create notebooks, add sources, generate + download Audio Overviews. Per-wallet Google session stored encrypted in the gateway vault. Brows
