# @rickydata/kfdb-code-mcp

> 标签: JavaScript

## 简介

Read-only KFDB code-intelligence MCP: semantic + full-text code search, symbol lookup, call-graph navigation, and agent context bundles. Supports a hardened bench mode that scopes every call to a single pinned repo corpus.
