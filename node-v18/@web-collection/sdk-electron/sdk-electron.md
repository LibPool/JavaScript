# @web-collection/sdk-electron

> 标签: JavaScript

## 简介

Web Collection SDK for Electron (main process app-level telemetry + renderer IPC bridge). Event types reuse the existing backend whitelist; electron APIs are dependency-injected (never imported) so the package stays unit-testable.
