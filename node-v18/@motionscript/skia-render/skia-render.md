# @motionscript/skia-render

> 标签: JavaScript

## 简介

Backend-agnostic Skia/CanvasKit renderer for Motion Script. Holds the shape, fill, stroke, effect, text and 3D logic; platform specifics (surface creation, media decode, encoding, audio) are injected.
