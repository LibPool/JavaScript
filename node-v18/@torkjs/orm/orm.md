# @torkjs/orm

> 标签: bun, migrations, mysql, orm, postgres, query-builder, sql, sqlite, tork

## 简介

Type-safe, Bun-native ORM on Bun.SQL for Postgres, MySQL, and SQLite. Query builder, relations, and migrations. Framework agnostic, with a native Tork plugin.
