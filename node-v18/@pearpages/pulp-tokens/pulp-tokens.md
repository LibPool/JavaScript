# @pearpages/pulp-tokens

> 标签: css-custom-properties, dark-mode, design-system, design-tokens, dtcg, react-native, tailwind, theming

## 简介

pulp design tokens. W3C Design Tokens (DTCG) JSON in, CSS custom properties and a resolved JSON manifest out. Two brands, light and dark via light-dark().
