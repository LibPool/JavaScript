# @wp-docs-toolkit/demo-site

> 标签: blueprint, documentation, playground, screenshots, wordpress

## 简介

The WordPress Playground environment the documentation screenshots are taken in: pinned WordPress and PHP, the Ipsum theme, a clean wp-admin and a deterministic demo content pack with a per-block showcase.
