# @athenox/talos

> 标签: backend, h3, language-model, mysql, nuxt, onnx, sql, sqlite

## 简介

Talos: a backend you describe instead of write. Declare a schema, write the rules in plain language, map URLs to sentences; a small built-in model turns them into query plans.
