# @thinkhuman/payload-plugin-auth

> 标签: authentication, oauth, oauth2, oidc, openid-connect, payload, payload-plugin, payloadcms, saml, single-sign-on, sso

## 简介

Single sign-on plugins for Payload CMS 3: OAuth 2.0 / OpenID Connect and SAML 2.0 with linked accounts, provider presets and multi-tenant connection resolution.
