# @cognitiondesk/storefront

> 标签: catalog, cognitiondesk, ecommerce, mounaji, react, storefront

## 简介

Presentational building blocks for a public product-catalog storefront: header, item grid with search/filter, item card, item gallery, contact links, share button — themed via --mn-* tokens
