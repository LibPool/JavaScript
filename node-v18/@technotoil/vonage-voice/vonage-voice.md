# @technotoil/vonage-voice

> 标签: android, ios, react-native

## 简介

React Native bridge for Vonage Voice (uses VonageClientSDKVoice). Provides call, answer, reject, hangup, mute, unmute, sendDTMF and event listeners. Requires microphone + network permissions on Android/iOS. Android uses com.vonage:client-sdk-voice:2.1.2;
