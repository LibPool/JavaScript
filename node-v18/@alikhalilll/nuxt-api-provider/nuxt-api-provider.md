# @alikhalilll/nuxt-api-provider

> 标签: api, fetch, http-client, interceptors, nuxt, nuxt-module, retry

## 简介

Strongly-typed fetch client for Nuxt 3/4 with interceptors, retry/backoff, and a framework-agnostic core.
