# pi-skill-inline-autocomplete

> 标签: autocomplete, coding-agent, pi, pi-package, skills, tui

## 简介

Inline /skill autocomplete for the pi editor — type / + letters anywhere in the prompt (not just at the start of line 0) to fuzzy-find skills; completion inserts /skill:name.
