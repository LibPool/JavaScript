# homebridge-nuki-mqtt-events

> 标签: fingerprint, homebridge-plugin, homekit, keypad, mqtt, nuki

## 简介

Momentary HomeKit switches that pulse when a Nuki lock is opened by fingerprint or keypad code. Built-in MQTT broker — no Home Assistant needed.
