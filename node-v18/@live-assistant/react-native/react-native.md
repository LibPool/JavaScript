# @live-assistant/react-native

> 标签: expo, gemini-live, react-native, realtime, voice, voice-assistant

## 简介

One install for a voice assistant in a React Native or Expo app: the session, a Gemini Live connection, microphone and playback, React bindings and a ready-made widget, all re-exported from one place.
