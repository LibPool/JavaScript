# @hellomavens/plugin-security-review

> 标签: JavaScript

## 简介

Salesforce CLI plugin that runs the HelloMavens security review against a target Salesforce org. Wraps @hellomavens/security-review-for-salesforce-engine + scan-core in an `sf` plugin shell.
