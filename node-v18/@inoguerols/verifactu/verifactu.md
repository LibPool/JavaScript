# @inoguerols/verifactu

> 标签: aeat, antifraude, factura, facturacion, hacienda, invoice, spain, tax, verifactu

## 简介

Librería y CLI TypeScript libres (MIT) para VeriFactu (AEAT): huella encadenada SHA-256, QR de cotejo, verificador de cumplimiento, generación de XML (XSD oficial), envío al web service (TLS mutuo), firma XAdES y servidor MCP. Sin APIs de pago ni terceros
