# @mailkaro/angular

> 标签: angular, angular-email-editor, drag-and-drop-email, email-builder, email-editor, email-templates, embeddable, mjml, newsletter-builder, unlayer-alternative, white-label

## 简介

White-label, embeddable drag-and-drop email editor for Angular — a drop-in for angular-email-editor and an Unlayer alternative. Loads from a hosted iframe (no editor code ships), and renders email-safe HTML + MJML from the API.
