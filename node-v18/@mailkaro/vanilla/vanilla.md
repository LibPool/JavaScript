# @mailkaro/vanilla

> 标签: drag-and-drop-email, email-builder, email-editor, email-templates, embeddable, iframe, javascript, mjml, newsletter-builder, unlayer-alternative, vanilla-js, white-label

## 简介

White-label, embeddable drag-and-drop email editor for vanilla JavaScript — a drop-in for Unlayer's embed.js. Loads from a hosted iframe (no editor code ships), and renders email-safe HTML + MJML from the API.
