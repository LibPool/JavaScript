> 标签: admin-sdk, backend-sdk, email-builder, email-editor, email-html, email-rendering, entitlements, mailkaro, mjml, node, node-email, render-mjml, sdk, server-side-rendering, unlayer-alternative

## 简介

Mailkaro backend SDK for Node.js — render designs to email-safe HTML and MJML on the server, and resolve entitlements server-to-server with a secret sk_live_ key. The Admin SDK paired with the @mailkaro/editor frontend (a drop-in Unlayer alternative). Lik
