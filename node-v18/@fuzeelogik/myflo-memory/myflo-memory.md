# @fuzeelogik/myflo-memory

> 标签: JavaScript

## 简介

myflo memory module — AgentDB + HNSW vector indexing, hybrid SQLite/sql.js backend. The agentdb-backed backend for @fuzeelogik/myflo when FLO_MEMORY_BACKEND=agentdb. Forked from @claude-flow/memory.
