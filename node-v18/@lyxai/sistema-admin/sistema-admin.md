# @lyxai/sistema-admin

> 标签: admin-de-sistema, lyx, rbac, react

## 简介

Painel Admin de Sistema + perfil/troca de senha reusável pelos fronts Lyx. Consome /admin/sistemas/:slug/*, /me/profile e /sistemas/catalog do monolito. Ver lyx-monolith ADR-0006.
