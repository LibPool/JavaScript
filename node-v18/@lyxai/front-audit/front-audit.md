# @lyxai/front-audit

> 标签: audit, coverage-gate, eslint-config, lyx

## 简介

Config de auditoria compartilhada dos fronts Lyx: ESLint flat config (complexidade + missing-spec), preset dependency-cruiser, exclude de coverage do vitest, e os bins coverage-gate + audit-report.
