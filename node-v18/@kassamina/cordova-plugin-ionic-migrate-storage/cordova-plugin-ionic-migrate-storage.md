# @kassamina/cordova-plugin-ionic-migrate-storage

> 标签: cordova, cordova-ios, cordova-plugin, ecosystem:cordova, ios, localstorage, uiwebview, wkwebview

## 简介

Cordova plugin that migrates localStorage datafrom `cordova-plugin-ionic-webview` 1.x to 4.x This works for iOS only!
