# @nl-framework/openapi

> 标签: bun, documentation, nl-framework, openapi, swagger

## 简介

OpenAPI 3.1 document generation for nl-framework: derives schemas from class-validator DTOs, enumerates routes, serves the JSON document plus a self-contained viewer. No CDN or network at runtime.
