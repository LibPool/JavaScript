> 标签: browser-ide, code-editor, code-sandbox, file-system, ide, javascript, material-ui, monaco-editor, online-editor, python, react, syntax-highlighting, virtual-fs, vite

## 简介

Browser-based VS Code-like IDE with Monaco Editor, React, and Material-UI. Features virtual file system, dark/light themes, and project export.
