# @tirzahlabs/zoe-translate-mcp

> 标签: bible-study, mcp, model-context-protocol, openai, translation

## 简介

Minimal MCP server that drafts Bible-study lesson translations via the OpenAI API, with Scripture-placeholder preservation and glossary-term reuse. Built for the Zoe Bible Study Series collection, reusable across any series repo.
