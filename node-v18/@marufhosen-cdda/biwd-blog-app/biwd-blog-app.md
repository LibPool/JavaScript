# @marufhosen-cdda/biwd-blog-app

> 标签: biwd, blog, embedded-app, radix, react, router, shadcn, shadcn-ui, tailwindcss, themable

## 简介

An embeddable React blog app with shadcn/ui components, runtime theme overrides via props, internal routing, and a mockup login page. Mount with <BlogApp apiKey="BLOG-1234" onLoginAccepted={setKey} theme={{ primary: "#ff0000" }} />.
