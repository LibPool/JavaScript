# @houssemeddine/calendar

> 标签: accessibility, calendar, custom-elements, drag-and-drop, gantt, i18n, kanban, month-view, recurring-events, rrule, rtl, scheduler, theming, timeline, timezone, web-components, week-view

## 简介

Eleven framework-free, localizable, themeable calendar Web Components (month, week, day, year, agenda, feed, kanban, timeline, gantt, compact, heatmap) with drag and drop, recurring events, time zones, RTL and a built-in event editor.
