# @plumbox/ui

> 标签: css-variables, custom-elements, design-system, panel, plu, plum, plum-box, plumbox, web-components

## 简介

Plum Box design system for .plu panels: the phone apps' tokens (colors, spacing, radii, type) as CSS custom properties, plus eight framework-free web components.
