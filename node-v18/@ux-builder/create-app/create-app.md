# @ux-builder/create-app

> 标签: JavaScript

## 简介

Scaffold a React + Vite app that is on the AI-UI SDK from its first commit, as the empty shell for its modalities: npm create @ux-builder/app my-app -- --modality responsive-web --theme databricks (FEAT-004 SDK-08, SDK-09; FEAT-014).
