# @de-otio/agent-safety-pack

> 标签: agent, ai, claude, coding-agent, hooks, llm, prompt-injection, safety, security, threat-detection

## 简介

Safety checks and pattern databases for AI coding agents. Intercepts tool calls to block destructive commands, credential exposure, prompt injection, and data exfiltration.
