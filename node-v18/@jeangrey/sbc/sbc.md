# @jeangrey/sbc

> 标签: cli, generator, initializr, monorepo, scaffold, spring-boot, spring-initializr

## 简介

A vue-cli style interactive CLI to scaffold, search and run Spring Boot projects (monorepo-aware), powered by Spring Initializr.
