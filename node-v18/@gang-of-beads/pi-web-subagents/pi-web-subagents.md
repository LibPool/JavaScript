# @gang-of-beads/pi-web-subagents

> 标签: pi-package, pi-subagents, pi-web, pi-web-plugin

## 简介

PI WEB plugin for pi-subagents: a Subagents tab listing the session's runs with their output, a reply card for a child's supervisor request, and short rows for subagent notices.
