# @common-agent/crypto

> 标签: canonical-json, common-agent, ed25519, jcs, nkeys, rfc8785

## 简介

The crypto the Common Agent contracting standards share: RFC 8785 canonical JSON, SHA-256 digests, Crockford identifiers, nkey public keys and Ed25519 signatures in their canonical spellings.
