# @mahmood-khalil57/nuxt-auto-animate

> 标签: JavaScript

## 简介

Animation with no code for Nuxt: a template transform puts v-auto-animate around every v-for and v-if in the app, and route changes crossfade with View Transitions, all honouring reduced motion
