# @agent-scope-ca/graph-canvas

> 标签: canvas, d3-force, graph, react, svg, topology, visualization

## 简介

Semantic Field canvas: weaveworks-derived SVG shape stack, Semantic Link envelope rendering, and a projection registry for laying out the same node set along different control-plane dimensions.
