# @heejun/deskcloud

> 标签: browser, deskcloud, saas, sdk, tree-shakeable, typescript

## 简介

Unified, browser-first, zero-runtime-dep, tree-shakeable TypeScript SDK for the DeskCloud SaaS family. Public (pk_) clients from '@heejun/deskcloud', admin (sk_) clients from '@heejun/deskcloud/server'.
