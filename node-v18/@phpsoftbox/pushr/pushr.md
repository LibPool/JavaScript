# @phpsoftbox/pushr

> 标签: JavaScript

## 简介

Браузерный клиент Pushr: WebSocket, восстановление соединения, управляемые подписки на каналы и React-хук. Сервер публикует события в именованные каналы; компоненты страницы приобретают канал на время своей работы.
