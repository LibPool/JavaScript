# @iznogoudd/pi-devin

> 标签: cognition, custom-provider, devin, devin-local, pi-coding-agent, pi-extension, pi-package, swe-2

## 简介

Devin Local models in Pi — SWE-2, Opus 5, Fable 5, Sol and friends. Auth via the local Devin CLI/Desktop session; the live model catalog comes straight from the GetCliModelConfigs RPC.
