# @spiderjew/npm-audit-pdf-cli

> 标签: audit, cli, cybersecurity, npm, pdf, report, security, vulnerabilities

## 简介

CLI to generate styled PDF reports from `npm audit --json` output. Groups vulnerabilities by severity with details &amp; fixes. Pro unlocks full severity levels &amp; no watermarks.
