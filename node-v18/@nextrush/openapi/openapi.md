# @nextrush/openapi

> 标签: api-docs, middleware, nextrush, openapi, standard-schema, swagger, swagger-ui

## 简介

Zero-config OpenAPI 3.1 generation for NextRush — reads route metadata (validate() schemas + endpoint()) and serves /openapi.json + docs. The first renderer of the Route Metadata System.
