# @ciromaciel/analytics

> 标签: JavaScript

## 简介

Operations Analytics from the terminal and from code: `analytics web init` puts the tracker in a site, `analytics mcp init` measures an MCP server, and withAnalytics/trackGoal (from /mcp) report every tool call.
