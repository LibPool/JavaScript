# @proteles/svelte

> 标签: authentication, oauth2, oidc, proteles, svelte, sveltekit

## 简介

Svelte components and stores for Proteles authentication, plus SvelteKit server handlers. Works with Svelte 4 and 5; tokens never reach the browser.
