# @proteles/fastify

> 标签: authentication, bff, fastify, oauth2, oidc, proteles

## 简介

Fastify plugin for the Proteles Backend-for-Frontend: registers /api/auth/*, adds a preHandler guard, and decorates the request with the session over @proteles/bff. Tokens never reach the browser. Needs a Proteles account: sign up for free at proteles.com
