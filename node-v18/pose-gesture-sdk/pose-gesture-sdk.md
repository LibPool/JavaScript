# pose-gesture-sdk

> 标签: gesture, hand-raising, mediapipe, pose, sign-language

## 简介

基于 MediaPipe Tasks（PoseLandmarker）的手语/手势采集状态机 SDK，纯本地运行、零外网依赖。举手保持 startSeconds 秒返回 start，手放下/手消失保持 endSeconds 秒返回 end。
