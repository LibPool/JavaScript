# @routers-org/wasm

> 标签: component-model, gis, map-matching, openstreetmap, routing, wasm, webassembly

## 简介

Map-match, route, and run proximity queries in the browser or Node: the Routers engine as a WebAssembly component, transpiled to typed ES modules.
