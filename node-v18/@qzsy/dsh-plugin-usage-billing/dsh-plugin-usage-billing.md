# @qzsy/dsh-plugin-usage-billing

> 标签: billing, cost, deepseek-harness, dsh, plugin, token-usage, usage-billing

## 简介

计费显示：从既有会话日志聚合真实 token 用量，按事件时刻价格写时锁定费用；侧栏 / 输入框下方入口 + 点击弹层 + 设置页用量视图。
