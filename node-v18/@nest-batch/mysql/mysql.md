# @nest-batch/mysql

> 标签: batch, drizzle, job-repository, mikro-orm, mysql, nestjs, persistence, prisma, typeorm

## 简介

MySQL driver shells for @nest-batch/core. Provides 4 MySQL adapter shells (MikroORM MySQL, TypeORM MySQL, Drizzle MySQL, Prisma MySQL) and the shared test-contracts e2e harness against a real MySQL 8.x testcontainer.
