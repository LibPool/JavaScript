# @khawa/spree-storefront-api-v2-sdk

> 标签: JavaScript

## 简介

Node module to easily integrate your JavaScript or TypeScript application with Spree API V2. You can create an entirely custom Storefront in JS/TS with this package including one page checkout, Single Page Apps, PWAs and so on

## 官网

- 官网：https://guides.spreecommerce.org/api/v2
- 源码仓库：git+https://bitbucket.org/ordumonde/spree-storefront-api-v2-js-sdk.git
- npm 页面：https://www.npmjs.com/package/@khawa/spree-storefront-api-v2-sdk
