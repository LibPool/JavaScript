# @wecdev/webpack-file-operations

> 标签: attach, create, delete, hook, merge json, modify, webpack, zip

## 简介

File and directory operation collection for webpack build. You can attach any of these operations (delete, create, modify, merge json, etc...) to any webpack hook with webpack-hook-attacher
