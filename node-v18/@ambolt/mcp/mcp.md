# @ambolt/mcp

> 标签: ai-agents, company-data, mcp, model-context-protocol, solana, x402

## 简介

stdio bridge to the hosted Ambolt MCP server: company registers, tenders, documents, rates, on-chain facts and a non-custodial Solana swap, each answer with source and date
