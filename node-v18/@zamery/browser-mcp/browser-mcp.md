# @zamery/browser-mcp

> 标签: ai-agents, browser-automation, codex, firefox, mcp, model-context-protocol

## 简介

Standalone MCP server that lets a local agent use a user's already-running Firefox through the Zamery BrowserProvider V2 contracts.
