# @ministryofmany/membership

> 标签: JavaScript

## 简介

Semaphore group-membership proofs - per-context Merkle group, snapshots, client-side proving and server-side verification - with app-supplied storage and a choice of proof engine: a MerkleGroupProvider (the per-app eligible leaf set), an optional Snapshot
