# @yukihong/schema-admin-x

> 标签: JavaScript

## 简介

一个面向后台管理系统的前后端一体化框架，内置 Koa 服务端和 Vue3 + Element Plus 前端模板，通过配置化 Schema 快速生成列表、表单、搜索等常见业务页面，并提供可插拔的自定义路由、组件和构建配置扩展能力，以 npm 包形式在多个项目中复用。
