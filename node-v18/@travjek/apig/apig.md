# @travjek/apig

> 标签: api-client, api-generator, api-testing, cli, code-generator, codegen, e2e-testing, faker, mock-service-worker, msw, openapi, openapi-generator, openapi3, playwright, react-hook-form, react-query, rest-api, rhf, schema-validation, sdk, sdk-generator, swagger, swagger-codegen, swr, tanstack-query, typescript, typescript-generator, valibot, yup, zod

## 简介

OpenAPI code generator for TypeScript with a plugin system — generates types, typed request functions, Zod/Valibot/Yup schemas, TanStack Query / SWR hooks, React Hook Form resolvers, Faker factories, MSW handlers and Playwright API clients
