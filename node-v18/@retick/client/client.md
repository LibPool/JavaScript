# @retick/client

> 标签: browser, client, cursor, event-sourcing, facts, idempotent, projection, retick, state, typescript

## 简介

Client for Retick: publish facts, read your own scope by cursor, and read the current state of your entities from a browser, cut to the sources each user may see.
