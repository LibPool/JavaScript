# @toanalien/ahha

> 标签: apprise, discord, email, notifications, ntfy, shoutrrr, slack, telegram, webhook

## 简介

Notification library for Node.js. Send messages to Slack, Discord, Telegram, Email, and more through URL-based configuration.
