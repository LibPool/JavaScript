# @denaro-config/eslint-config-check-file

> 标签: check-file, denaro, eslint, eslint-config, eslint-config-check-file

## 简介

前端工程化中的 eslint 通用配置, 提供校验、规范文件或文件夹命名, 一般适用于规范单元测试文件和存放单元测试的目录。
