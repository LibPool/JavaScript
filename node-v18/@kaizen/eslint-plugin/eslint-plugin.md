# @kaizen/eslint-plugin

> 标签: JavaScript

## 简介

`@kaizen/eslint-plugin-kaizen` is a collection of ESLint rules for Kaizen. It aims to solve some of the following problems: - Large-scale migrations of Kaizen packages - Encourage Kaizen best practices and anticipate common mistakes
