# @knights-eye-chess/ai-analysis

> 标签: JavaScript

## 简介

Build a chess question-and-answer feature around a model, legal chess tools and engine evidence. AI Analysis prepares an exact game or position context, lets the model request bounded investigations, and checks references in the final answer.
