# eslint-plugin-unicode-guard

> 标签: ai-generated-code, ascii-smuggling, confusables, eslint, eslint-plugin, eslintplugin, homograph, invisible-characters, llm, prompt-injection, security, supply-chain, trojan-source, unicode, zero-width

## 简介

ESLint plugin that makes AI-generated code safe to merge: flags invisible, bidirectional, confusable, private-use and other non-standard Unicode characters in code, comments, strings, JSON, Markdown, CSS, YAML, TOML, HTML and plain text files
