# @methodts/pacta-provider-claude-agent-sdk

> 标签: JavaScript

## 简介

Pacta agent provider that delegates the inner agent loop to @anthropic-ai/claude-agent-sdk. Supports both direct (raw API key) and Cortex-pluggable (via @methodts/pacta-provider-cortex/anthropic-transport) modes.
