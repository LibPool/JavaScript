# @sonawaneyogesh/live-api-tracing

> 标签: api-tracing, call-tree, code-coverage, express-middleware, istanbul, nyc, request-tracing, runtime-coverage

## 简介

Reusable Istanbul/nyc coverage tracer for Express apps: a guarded HTTP route that dumps global.__coverage__ to disk on demand.
