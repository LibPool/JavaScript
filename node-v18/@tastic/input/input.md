# @tastic/input

> 标签: expo, gesture, input, keyboard, react-native, swipe, vec2

## 简介

Pure, worklet-safe input resolvers for local-multiplayer arcade games: swipe/vector-to-direction classification, keyboard scheme mapping, drag aim vectors (pull/push), and flick-throw velocity
