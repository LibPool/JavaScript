# winden-tokens

> 标签: bridge, design-tokens, figma, figma-plugin, mcp, model-context-protocol, winden

## 简介

Drive the Figma file you have open from outside Figma: the Winden Tokens UI full-size in a browser tab, and an MCP server for your design tokens. Local relay + prebuilt UI, loopback only.
