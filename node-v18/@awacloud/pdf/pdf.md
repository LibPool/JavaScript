# @awacloud/pdf

> 标签: acroform, browser, iso-32000, pades, pdf, pdf-2.0, pdf-a, pdf-ua, pkcs7, tagged-pdf, worker-safe, xmp

## 简介

Browser-safe PDF 2.0 reader/writer — ISO 32000-2:2020, PDF 1.7 legacy read, typed object graph, AES-256 encrypted write, PKCS#7/PAdES signatures (sign + verify). Zero runtime dependency beyond @awacloud/fw and @awacloud/fonts.
