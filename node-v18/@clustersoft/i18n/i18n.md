# @clustersoft/i18n

> 标签: bot, clustersoft, i18n, internationalization, intl, localization, mgr, pluralization, translation

## 简介

Universal, zero-dependency internationalisation for JavaScript and TypeScript — nested keys, namespaces, CLDR plural rules, Intl formatting and fallback chains, with optional ClusterSoft MGR bot integration.
