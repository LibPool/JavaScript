# @anarchitects/forms-angular

> 标签: JavaScript

## 简介

Angular domain UI components for consuming the Anarchitecture Forms platform. This package wires together configuration, data-access, state, feature, and UI layers so Angular applications can request contract-driven form definitions, render them dynamical
