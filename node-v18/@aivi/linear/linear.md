# @aivi/linear

> 标签: JavaScript

## 简介

Linear module: one app receiving every webhook, the assistant for people, workers in git worktrees, and the Linear MCP proxy. Agent sessions run on the host's channel machinery — a delegation becomes one bound conversation and one worker turn of the lane'
