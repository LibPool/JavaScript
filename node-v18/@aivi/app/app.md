# @aivi/app

> 标签: JavaScript

## 简介

The installed server: the `aivi` binary that composes configured modules and launches the host. The thin CLI (`@aivi/cli`) forwards every operator command here. `aivi serve` starts the host with Discord, Slack, and Linear modules; the other commands talk
