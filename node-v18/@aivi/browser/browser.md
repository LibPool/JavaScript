# @aivi/browser

> 标签: JavaScript

## 简介

Chrome DevTools MCP with a persistent profile and session-owned tabs. Drives one persistent Chrome for unattended sessions and shared logins — distinct from OpenCode's own `browser.*` tools, which drive the desktop app's browser.
