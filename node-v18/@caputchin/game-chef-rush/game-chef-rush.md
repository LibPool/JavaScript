# @caputchin/game-chef-rush

> 标签: captcha, caputchin, caputchin-game, cooking, excalibur, game, reaction

## 简介

Read the order and chop the ingredients it needs, skipping the wrong and rotten ones, to prove you're human. An Excalibur.js cooking-reaction captcha. A Caputchin first-party game.
