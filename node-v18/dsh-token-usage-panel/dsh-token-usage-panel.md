# dsh-token-usage-panel

> 标签: analytics, deepseek, deepseek-harness, dsh, dsh-plugin, panel, sidebar, token, usage

## 简介

Token 用量面板 / Token usage panel: 侧边栏入口，概览（活动热力图、每日趋势、模型排名）与会话明细（筛选、排序、导出）。零依赖、无金额、无定价。
