# @buildaharness/personal-assistant

> 标签: agent-harness, ai-assistant, chat-agent, human-in-the-loop, llm, open-source, openclaw-alternative, personal-assistant, self-hosted, tool-approval

## 简介

An open-source AI chat assistant that runs the full 11-layer Build A Harness every turn — light for a fact lookup, and it stops for approval before it sends an email or runs a shell command. CLI, browser, and desktop.
