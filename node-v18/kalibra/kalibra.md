# kalibra

> 标签: ai, evals, evaluation, llm, llm-as-judge, mcp, speech-to-text, testing, wer

## 简介

Local-first, open-source evaluation for AI applications: datasets, HTTP/WebSocket targets, layered checks (WER, LLM judge, …), runs and comparisons. Run with `npx kalibra`.
