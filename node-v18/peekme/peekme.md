# peekme

> 标签: claude-code, codex, command-line-utilities, copilot, development-tools, kiro, terminal

## 简介

Select text in Claude Code, Codex CLI, GitHub Copilot CLI or Kiro CLI output and get a short explanation right under it, inside the terminal
