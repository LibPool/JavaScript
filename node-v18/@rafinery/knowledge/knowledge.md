# @rafinery/knowledge

> 标签: JavaScript

## 简介

The knowledge-graph plane — the node/edge schema GENERATED from the OKF file-class registry, typed edge derivation with trust grades, and the query planner the served read path and the benchmark both run. Pure functions, no I/O.
