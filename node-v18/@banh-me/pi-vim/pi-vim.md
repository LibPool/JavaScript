# @banh-me/pi-vim

> 标签: coding-agent, modal-editor, pi, pi-coding-agent, pi-extension, pi-package, vim, vim-key-bindings, vim-mode

## 简介

Vim modal editing for the pi coding agent prompt: INSERT/NORMAL/REPLACE/VISUAL/V-LINE with operators, text objects, registers, undo/redo, dot-repeat, OS-clipboard mirror and configurable escape sequences.
