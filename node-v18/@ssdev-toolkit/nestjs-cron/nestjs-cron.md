# @ssdev-toolkit/nestjs-cron

> 标签: JavaScript

## 简介

Scheduled jobs (Quartz-style expressions) that enqueue work through a queue port. Persistence of job definitions is a host port (`CRON_JOB_STORE_PORT`).
