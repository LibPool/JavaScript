# @ngraveio/ur-sync

> 标签: Blockchain Commons, bc-ur, cbor, coin, crypto, detailed account, metadata, ngrave, portfolio, portfolio coin, sync, uniform resources, wallet, watch-only

## 简介

Provides BC-UR types for syncing multiple coins and accounts from cold wallets to watch only wallets.
