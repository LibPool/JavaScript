# @pi-in-go/pigpen-extension-equivalence

> 标签: equivalence, extension, extension-porting, pig-package, pigpen

## 简介

Differential harness that proves a Go port of a Pi extension behaves like the TypeScript original, plus a static check for Pi APIs the Go SDK lacks
