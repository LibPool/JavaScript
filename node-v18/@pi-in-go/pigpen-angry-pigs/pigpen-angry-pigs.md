# @pi-in-go/pigpen-angry-pigs

> 标签: extension, game, pig-package, pigpen, pixel-art

## 简介

Angry Pigs: a pixel-art slingshot game with towers, birds and physics, opened with /angry-pigs (Go). Nothing runs until you type the command.
