# @pi-in-go/pigpen-jev

> 标签: extension, guardrails, jev, pig-package, pigpen, safety, typesafe

## 简介

Jev for PiG: a typed judge for tool calls and tool output, plus a jev_ask tool. Opt-in, tells you what leaves the machine, and judges with the model PiG is configured with or the TypeSafe API. Go port of y0usaf/pi-jev.
