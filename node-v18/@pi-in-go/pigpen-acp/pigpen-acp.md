# @pi-in-go/pigpen-acp

> 标签: acp, agent-client-protocol, editor, extension, pig-package, pigpen, zed

## 简介

Agent Client Protocol (ACP) for PiG: pig-acp lets an editor such as Zed drive a PiG agent over stdio JSON-RPC. A Go port of pi-acp.
