# @pi-in-go/pigpen-bun-runtime

> 标签: bun, extension, pig-package, pigpen, runtime

## 简介

The Bun TypeScript runtime slot for PiG (Go): installs a pinned, signature-checked Bun and runs TypeScript and JavaScript extensions on it instead of Node.
