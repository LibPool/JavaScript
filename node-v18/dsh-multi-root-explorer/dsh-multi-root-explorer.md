# dsh-multi-root-explorer

> 标签: deepseek-harness, dsh, dsh-plugin, explorer, file-tree, sidebar, workspace

## 简介

Workspace Explorer for DeepSeek Harness: replaces the native sidebar workspace region with a multi-root browser — a conversation tree grouped by each session's real working directory, plus a read-only resource tree that previews files in the native right
