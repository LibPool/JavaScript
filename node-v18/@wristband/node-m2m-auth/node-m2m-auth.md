> 标签: api, authentication, express, jwt, m2m, machine-to-machine, multi-tenancy, multi-tenant, node.js, oauth, oidc, sdk, secure, security, typescript, wristband

## 简介

An SDK that lets Wristband Machine-to-machine OAuth2 clients retrieve and cache an access token in NodeJS.
