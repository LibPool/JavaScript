# wallet-evidence

> 标签: audit, diagnostics, evidence, rpc, solana, transaction, web3

## 简介

Read-only Solana transaction evidence reports: slot, block time, execution error, parsed instructions, fee, and an RPC response hash. Returns UNKNOWN when the RPC cannot see a transaction
