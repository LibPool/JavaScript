# @lovett/geosearch

> 标签: JavaScript

## 简介

Consumer SDK for the geosearch API. Backend-agnostic — ships a Rust adapter (production, calls the Fly.io geocoder service) and a Supabase adapter (migration shim, kept until the Rust backend is fully live). Both honor the GeosearchApi interface from @lov
