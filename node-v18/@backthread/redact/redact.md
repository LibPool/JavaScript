# @backthread/redact

> 标签: ai-agent, backthread, claude-code, privacy, redaction, transcript

## 简介

The one redaction fence — pure, zero-dependency string transforms that strip source code and tool I/O out of an AI coding-agent session transcript before anything leaves the machine. Keeps only natural-language rationale.
