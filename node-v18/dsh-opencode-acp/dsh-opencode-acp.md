# dsh-opencode-acp

> 标签: acp, agent-client-protocol, deepseek, deepseek-harness, delegation, dsh, dsh-plugin, opencode, plugin, subagent

## 简介

Run opencode as an ACP subagent inside DeepSeek Harness: a delegation tool, a settings page, and a run history with opencode session ids and token usage.
