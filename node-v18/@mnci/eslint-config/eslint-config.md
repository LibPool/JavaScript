# @mnci/eslint-config

> 标签: eslint, eslintconfig, flat-config, mnci, nx

## 简介

The shared ESLint flat config every mnci-generated monorepo uses — one root config, non-stylistic rules only, covering TS/JS, React, JSON/JSONC/JSON5, YAML, Markdown, CSS and HTML.
