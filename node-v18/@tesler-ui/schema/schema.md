# @tesler-ui/schema

> 标签: JavaScript

## 简介

This package includes schemas shared by [Tesler](https://github.com/tesler-platform/tesler) and [Tesler-UI](https://github.com/tesler-platform/tesler-ui) in form of Typescript types, their corresponding JSON schemas and utilities to extend built-in types
