# @xingying/koishi-plugin-keyword-blocker

> 标签: JavaScript

## 简介

⚠️ 本插件主要为个人使用开发，其他人使用可能会遇到兼容性问题，使用风险自负。关键词拦截中间件（前缀/包含/艾特），每条规则可独立设置是否区分大小写。
