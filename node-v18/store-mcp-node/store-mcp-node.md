# store-mcp-node

> 标签: ai, crud, gql, mcp, model-context-protocol, nodejs-store

## 简介

MCP (Model Context Protocol) adapter that auto-generates tool surfaces for nodejs-store schemas (schema-driven CRUD + sandboxed GQL query + optional ask), stdio transport
