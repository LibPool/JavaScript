# crowbar-cli

> 标签: agent, claude-code, codex, cursor, cve, epss, exploit, kev, mcp, mcp-server, nvd, offline, opencode, security, vulnerability

## 简介

Retrieve CVEs and index them inside your codebase. One SQLite+FTS5 index, one CLI, one MCP server. Never answer a CVE from memory again.
