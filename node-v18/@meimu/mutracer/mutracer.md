# @meimu/mutracer

> 标签: oidn, openpbr, path tracing, pbr, raytracing, renderer, three.js, webgl, webgpu

## 简介

MuTracer: a physically based WebGPU path tracer with WebGL 2 fallback, OpenPBR materials, TinyBVH and OIDN denoising.
