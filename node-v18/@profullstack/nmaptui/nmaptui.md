# @profullstack/nmaptui

> 标签: bun, cli, hqtui, network, nmap, port-scanner, scanner, security, sysadmin, terminal, tui

## 简介

An admin console for nmap in the terminal: build scans from profiles, watch them run live, browse hosts and services, triage findings, diff scans over time and export reports. Bun and Node, built on HQTUI.
