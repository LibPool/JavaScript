# @profullstack/sh1pt-target-deploy-ssh

> 标签: JavaScript

## 简介

Railway-style deploys to a server you own: git push in, a running app with a domain, TLS, a database and secrets out. No Docker, no Kubernetes, no PaaS. Code goes to the box over ssh, runs under systemd, and sits behind nginx.
