# @profullstack/live-translate

> 标签: coinpay, dubbing, elevenlabs, interpreter, live, meetings, speech, subtitles, translation, webrtc

## 简介

Live speech translation for streams and meetings: hear (ElevenLabs Scribe), translate (pluggable), re-voice (ElevenLabs Flash), with per-listener language choices, shared pipelines, CoinPay passes and a free daily allowance. Extracted from nixamp.
