# @profullstack/media2md

> 标签: cli, ffmpeg, markdown, rag, transcription, whisper, yt-dlp

## 简介

Turn any video, audio file or book into a chaptered Markdown bundle you can hand to an LLM. Open-source tools only, no AI in the pipeline.
