# @profullstack/pairux-embed

> 标签: e2ee, embed, end-to-end-encryption, livekit, pairux, screen-sharing, video-call, voice-chat, webrtc

## 简介

End-to-end encrypted voice, video and screen sharing for any web app, on PairUX's SFU. The host app supplies the media key; the server only forwards ciphertext.
