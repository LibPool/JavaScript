# @eventfabric/sagas

> 标签: compensation, cqrs, ddd, domain-driven-design, event-sourcing, eventfabric, orchestration, process-manager, saga, state-machine, typescript, workflow

## 简介

Saga / process manager primitive for EventFabric: typed state machines that react to events and timers, emit commands transactionally, and persist instance state. Backend-agnostic — pair with @eventfabric/sagas-postgres for PG storage and @eventfabric/sag
