# @eventfabric/sagas-postgres

> 标签: cqrs, ddd, domain-driven-design, event-sourcing, eventfabric, orchestration, postgres, postgresql, process-manager, saga, typescript

## 简介

Postgres-backed storage for @eventfabric/sagas: saga instance state, command queue, and timer scheduler tables. Pair with the abstract saga runtime.
