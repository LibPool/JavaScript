# @liaogn/vue-drag-resize-rotate

> 标签: drag, draggable, resizable, resize, rotatable, rotate, vue, vue3

## 简介

Vue 3 component for dragging, resizing, and rotating DOM elements. Simple, dependency-free, supports nesting / aspect-lock / flipping.
