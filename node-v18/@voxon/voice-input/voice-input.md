# @voxon/voice-input

> 标签: audio-worklet, mistral, react, realtime, speech-to-text, transcription, voice, voxon, voxtral

## 简介

React hooks for real-time voice transcription with Voxon + Mistral Voxtral. Streaming capture, two-phase stop, and a prompt input controller for the live-transcript UX.
