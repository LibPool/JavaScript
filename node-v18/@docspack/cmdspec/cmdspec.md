# @docspack/cmdspec

> 标签: agents, ai, cli, cmdspec, command-line, documentation, json-schema, kdl, llm, opencli, specification, usage

## 简介

cmdspec: a machine-readable description of a command-line interface. Validate it, convert it to and from Usage and OpenCLI, and render a per-command digest for an agent.
