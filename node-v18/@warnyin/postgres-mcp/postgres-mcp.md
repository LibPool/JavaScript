# @warnyin/postgres-mcp

> 标签: anthropic, claude, database, llm, mcp, model-context-protocol, pg, postgres, postgresql, warnyin

## 简介

MCP server for managing PostgreSQL databases — query, execute, schema introspection, indexes, and EXPLAIN — runnable via npx.
