# @depixapp/mcp

> 标签: ai-agents, bitcoin, charges, cobranca, depix, lightning, liquid, mcp, model-context-protocol, non-custodial, payments, pix, stablecoin, wallet

## 简介

The DePix App MCP server: hosted receive-only Pix gateway (26 tools), or local via npx with a non-custodial Liquid wallet signing on your own machine (62 tools). Checkouts, products, charges, support tickets, send/convert, Lightning and gift cards.
