# @nesercode/gpt-api

> 标签: JavaScript

## 简介

Chat GPT api (in Openai.com) help you to build a Node.js server(Express.js) to connect with Openai GPT API. This server contain some simple api to request, and all usage will be simple and easy to use in offical way.
