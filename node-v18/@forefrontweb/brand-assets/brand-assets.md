# @forefrontweb/brand-assets

> 标签: assets, brand, forefront, forefrontweb, logo

## 简介

ForeFront Web brand image assets (logos + icons) for automated report generation. Non-sensitive brand marks, published so build sandboxes can retrieve the exact bytes via npm.
