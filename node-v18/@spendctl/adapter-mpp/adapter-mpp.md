# @spendctl/adapter-mpp

> 标签: JavaScript

## 简介

Machine Payments Protocol (MPP) adapter for spendctl: parses Payment challenges and delegates credentials to mppx.

- npm 页面：https://www.npmjs.com/package/@spendctl/adapter-mpp
