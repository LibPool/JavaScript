# @ck0/pnpm-plugin-config

> 标签: config-dependency, pnpm, pnpm-plugin, pnpmfile

## 简介

pnpm config-dependency plugin: re-applies the settings pnpm 11 no longer reads from a global ~/.config/pnpm/config.yaml, so they apply per-project from one pinned source. Auto-loaded by pnpm because the name matches @*/pnpm-plugin-*.
