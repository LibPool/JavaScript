# @dietdev/binary-storage

> 标签: binary, browser, compact, localstorage, schema, serialization, sessionstorage, state, storage, typescript

## 简介

Типизированная обёртка над localStorage: частичные обновления, события, подменяемое хранилище и компактный бинарный формат с проверкой совместимости схемы
