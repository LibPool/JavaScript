# @ak-103u/pi-ui-plus

> 标签: localization, notification, pi, pi-coding-agent, pi-extension, pi-package, tui

## 简介

Pi extension package: fold tool calls and previous replies, localize the native Pi UI, and send a system notification when the agent settles.
