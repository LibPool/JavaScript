# @lumenlang/lumenmcp

> 标签: ai, claude, lumen, lumenlang, mcp, minecraft, model-context-protocol, scripting

## 简介

MCP server for the Lumen scripting language. Documentation lookup, pattern + type search, real-compiler script validation, and live debugging of running Minecraft servers (snapshots, overrides, snippet execution).
