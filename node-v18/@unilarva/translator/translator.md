# @unilarva/translator

> 标签: bcp-47, dom, esm, framework-independent, i18n, internationalization, interpolation, intl, language-switcher, localization, multilingual, rich-text, ssr, translation, translator, typescript, zero-dependency

## 简介

Zero-dependency TypeScript i18n with runtime catalogs, optional typed keys, ordered language fallbacks, Intl helpers, semantic rich text, and optional DOM bindings.
