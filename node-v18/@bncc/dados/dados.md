# @bncc/dados

> 标签: base nacional comum curricular, bncc, brasil, curriculo, educacao, habilidades, mec

## 简介

A BNCC (Base Nacional Comum Curricular) como dados estruturados e verificados, com API de consulta tipada. Inclui o complemento de Computação (1.721 aprendizagens). Em desenvolvimento: a v1.0 sai junto da release dados-v1.0.0 do bncc-dados.
