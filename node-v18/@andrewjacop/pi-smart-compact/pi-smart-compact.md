# @andrewjacop/pi-smart-compact

> 标签: clef, compaction, context-window, jev, llm, pi, pi-coding-agent, pi-package, summarization

## 简介

Decision-model compaction for pi: a decision backend classifies each compactable message keep/summarize/drop, a targeted LLM summarizes only the summarize class, and any failure falls back to native compaction.
