# @tiaohsun/vue-datatable

> 标签: dark-mode, data-table, datatable, i18n, table, tailwindcss, vue-component, vue3

## 简介

A self-contained Vue 3 data table (Tailwind 4-styled, no Tailwind install required) with dark mode, i18n, sorting and selection.
