# @joshdcuneo/tsm

> 标签: JavaScript

## 简介

TSM is a type first finite state machine library inspired by [xstate](https://github.com/davidkpiano/xstate) and [robot](https://github.com/matthewp/robot).  The API aims to strike a balance between small bundle size, ergonomics and type safety.
