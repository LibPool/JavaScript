# @asentum/connect

> 标签: asentum, connect, dapp, react, wallet, web3

## 简介

Drop-in wallet connect for AsentumChain dapps — <ConnectButton /> + hooks (useWallet, useAsentum). Zero CSS imports, zero heavy deps.
