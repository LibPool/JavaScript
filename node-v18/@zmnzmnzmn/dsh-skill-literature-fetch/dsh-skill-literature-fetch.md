# @zmnzmnzmn/dsh-skill-literature-fetch

> 标签: carsi, deepseek-harness, doi, dsh, dsh-plugin, dsh-skill, literature, open-access, pdf, skill

## 简介

DSH skill: batch-download full-text PDFs for a list of DOIs/titles through a real browser, using the user's own institutional access (CARSI / campus SSO / VPN) plus open-access routes. Packaged as an installable dsh bundle so the skill reaches every agent
