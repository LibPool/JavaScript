# @chromatrix/core

> 标签: browser-automation, chrome, chrome-devtools-protocol, orchestration

## 简介

Domain core for chromatrix: identity registry, session/tab-pool orchestration, single-writer profile locking, health checks, and the orphaned-Chrome-tree reaper. Consumed by apps/gateway. Populated after S1/S3.
