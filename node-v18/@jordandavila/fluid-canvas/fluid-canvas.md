# @jordandavila/fluid-canvas

> 标签: accessibility, design-system, design-tokens, figma, fluid-typography, responsive, tailwind-v4, tailwindcss, tailwindcss-plugin, wcag

## 简介

Proportional canvas design system for Tailwind CSS — poster scaling from your Figma frame, with rem floors and a user text-size multiplier. Ships a v3 plugin and a v4 CSS-first build from one source of truth.
