# self-captcha

> 标签: captcha, express, image-captcha, react, recaptcha-alternative, self-hosted, stateless

## 简介

Self-hosted visual CAPTCHA — generate distorted text/math images and verify them with a stateless signed token. No Google, no Cloudflare, no external calls. Includes an Express helper and a React widget.
