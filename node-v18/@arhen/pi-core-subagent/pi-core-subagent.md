# @arhen/pi-core-subagent

> 标签: agent-orchestration, dag, graph-protocol, pi, pi-coding-agent, pi-extension, pi-package, subagent, task-graph

## 简介

pi extension: fast in-process subagents with a dependency-graph scheduler (needs edges gate tasks and carry upstream output into dependent prompts), plus background runs, intercom and agent-to-agent mailbox. Leader defines agents inline.
