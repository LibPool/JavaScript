# @todosgg/sdk

> 标签: agent, api, client, mcp, sdk, tasks, todo, todos, todos.gg, typescript, webhooks

## 简介

Official, fully-typed TypeScript/JavaScript SDK for the todos.gg API — tasks, AI smart-views, webhooks, API keys, and MCP. Download, add your API key, and go.
