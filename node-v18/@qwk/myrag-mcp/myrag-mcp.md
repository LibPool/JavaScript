# @qwk/myrag-mcp

> 标签: JavaScript

## 简介

这是一个本地 stdio MCP Server：作为“薄代理”把 `tools/call(query_pdf)` 转成对 `http://111.229.207.222/query` 的 HTTP 请求，再把结果包回 MCP。

## 官网

- npm 页面：https://www.npmjs.com/package/@qwk/myrag-mcp

- 0.1.0

## 获取地址

- npm 安装：`npm install @qwk/myrag-mcp`
- npm registry：https://registry.npmjs.org/@qwk/myrag-mcp
- Node 要求：>=18
