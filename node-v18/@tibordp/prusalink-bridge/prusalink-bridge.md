# @tibordp/prusalink-bridge

> 标签: 3d-printing, browser-extension, gcode, plotter, prusa, prusalink

## 简介

Page-facing client for the Bridge for PrusaLink browser extension (unofficial; not affiliated with Prusa Research). Pure postMessage, zero runtime dependencies; lets a web app drive the user's own PrusaLink printers via the extension, with explicit per-or
