# @xiongcao/smart-git-commit

> 标签: ai-review, branch, changelog, cli, code-review, commit, conventional-commits, git, hook, webhook

## 简介

智能 Git 提交助手 - 自动检测修改并生成 Conventional Commits 格式的提交日志，支持分支管理、提交历史查看、AI 代码审查等功能
