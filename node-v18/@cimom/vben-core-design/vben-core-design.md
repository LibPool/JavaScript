# @cimom/vben-core-design

> 标签: JavaScript

## 简介

该包提供了 Vue Vben Admin 项目的核心设计系统，包括设计令牌（Design Tokens）、CSS 变量、BEM 规范工具和全局样式。它是整个项目样式系统的基础，确保了界面风格的一致性和可定制性。
