# @bunny.net/openapi-client

> 标签: api-client, bunny, bunny.net, bunnycdn, cdn, dns, edge-storage, openapi, stream, typescript

## 简介

Type-safe TypeScript client for the bunny.net APIs (CDN, DNS, Edge Storage, Stream, Shield, Magic Containers), generated from official OpenAPI specs.
