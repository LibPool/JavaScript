# @amfi/connect-wallet

> 标签: blockchain, chain, coinbase-wallet, coinbasewallet, connect blockchain, crypto, cryptocurrency, metamask, wallet, wallet-connect, wallet-link, walletconnect, walletlink

## 简介

Connect Crypto Wallet by using CoinbaseWallet (WalletLink), KardiaChain, MetaMask browser extentions or mobile application and WalletConnect service by scanning Wallet Qr-code.
