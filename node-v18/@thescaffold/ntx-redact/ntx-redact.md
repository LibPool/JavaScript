# @thescaffold/ntx-redact

> 标签: JavaScript

## 简介

Outbound text/JSON redaction for scaffold apps — regex + json-path rules + optional classifier hook. Framework-agnostic engine with a thin NestJS wrapper; exposes RedactionRuleStore + RedactionTelemetrySink ports.
