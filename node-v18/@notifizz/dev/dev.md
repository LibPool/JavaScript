# @notifizz/dev

> 标签: JavaScript

## 简介

Notifizz dev tunnel — lets Notifizz reach your LOCAL app (discovery + enrichers) without a public URL, by bridging a Centrifugo channel to your localhost over a dev-only relay. Backend SDK agnostic (Node / PHP / Java).
