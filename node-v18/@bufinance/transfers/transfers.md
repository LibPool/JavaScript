# @bufinance/transfers

> 标签: JavaScript

## 简介

The single wallet-level transfer adapter. One mega-style 3-line API (initialise → transfer) that aggregates private on-chain (Hinkal via @bufinance/ghost), public on-chain (transfer-core), and fiat payouts (transfer-fiat) behind one Destination + one poli
