# @bufinance/ramps-ui

> 标签: JavaScript

## 简介

Shared fiat on/off-ramp for BUFI apps. Phase 1: the Stripe (Bridge) crypto-onramp provider — server-side session creation, webhook verification + event parsing, outbound Svix fan-out, and @bufinance/events analytics — plus the client widget loader. App-ag
