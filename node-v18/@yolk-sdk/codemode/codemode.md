# @yolk-sdk/codemode

> 标签: agents, codemode, effect, quickjs, sandbox, tools

## 简介

Code mode for Yolk agents: one tool that runs model-written JavaScript calling the host's resolved tools, plus a Node executor on a confined QuickJS sandbox.
