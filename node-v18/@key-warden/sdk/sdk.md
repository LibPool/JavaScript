# @key-warden/sdk

> 标签: activation, ed25519, key-warden, keywarden, licence, license, licensing, offline-verification, software-licensing

## 简介

Official Node.js client for Key-Warden - validate software licences online (seat- and revocation-aware) and verify the signed Ed25519 GRANT offline, bound to one licence key and one machine.
