# @nickpaustian/requester

> 标签: cache, fetch, http, queue, request, retry, typescript

## 简介

One request interface for web, Node and React Native: a queue with concurrency and priority, instances with a base URL and headers, a cache with a TTL, de-duplication, retries and aborts, over a swappable transport (fetch by default) and a swappable store
