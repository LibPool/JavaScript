# @jspreadsheet/properties

> 标签: data-grid, data-spreadsheet, data-table, excel, grid, grid-editor, jexcel, jspreadsheet, spreadsheet, spreadsheets, table, tables

## 简介

This plugin includes a properties option on the context menu. So, the user can update some basic spreadsheet settings in real-time.
