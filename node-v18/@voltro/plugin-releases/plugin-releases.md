# @voltro/plugin-releases

> 标签: framework, typescript, voltro

## 简介

Release channels, artefacts and rollouts for the apps a Voltro api serves — the self-hosted update server behind Tauri, Expo OTA, electron-updater and PWA update feeds, with a reactive release policy every client subscribes to.
