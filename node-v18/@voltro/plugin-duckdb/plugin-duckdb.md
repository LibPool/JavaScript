# @voltro/plugin-duckdb

> 标签: framework, typescript, voltro

## 简介

Embedded DuckDB AnalyticsSink. Runs DuckDB in-process for real OLAP performance without an external service. Events land in a DuckDB column-store table; aggregate / timeseries / topN queries execute vectorized.
