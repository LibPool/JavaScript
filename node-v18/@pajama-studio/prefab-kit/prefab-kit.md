# @pajama-studio/prefab-kit

> 标签: blueprint, ecs, game, prefab, react-three-fiber, scene-graph, serialization, three

## 简介

Standalone, serializable linked-prefab (Blueprint) framework: templates, instances, per-instance overrides, exposed params, callable actions, recursive nesting — zero dependencies, domain-agnostic, plain JSON.
