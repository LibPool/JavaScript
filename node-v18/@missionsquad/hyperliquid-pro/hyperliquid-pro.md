# @missionsquad/hyperliquid-pro

> 标签: agent, ai, blockchain, crypto, cryptocurrency, dex, hyperliquid, llm, mcp, perpetuals, perps, trading

## 简介

Read-only MCP server for the Hyperliquid exchange (perps, spot, HIP-3/4, HyperEVM, vaults, staking, builder fills). No signing, no trading. Optional Mission Squad hidden-secret injection for third-party API keys (CoinGecko/Dune).
