# @majesticfudgie/col-reader

> 标签: JavaScript

## 简介

A TypeScript library for parsing GTA collision (`.col`) files - COLL (v1, GTA III/VC), COL2 (SA PS2), and COL3/COL4 (SA PC/XBOX). Works in both **Node.js** and the **browser** (uses `Uint8Array` input).
