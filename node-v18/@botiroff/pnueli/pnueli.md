# @botiroff/pnueli

> 标签: concurrency, formal-methods, liveness, model-checking, partial-order-reduction, state-space, symmetry-reduction, temporal-logic, verification

## 简介

An explicit-state model checker: exhaustive search with symmetry reduction, partial-order reduction and liveness under weak fairness, validated against unreduced ground truth.
