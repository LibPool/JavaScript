# partpin

> 标签: agent, catalog, cli, distributor, mcp, mro, part-number, resolver

## 简介

Command-line client for PartPin: resolve part numbers against your own catalog, browse/register catalog items, and run a zero-result query autopsy. Same API and same API key as the PartPin MCP server.
