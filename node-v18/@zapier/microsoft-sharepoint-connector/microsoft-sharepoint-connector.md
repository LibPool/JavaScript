# @zapier/microsoft-sharepoint-connector

> 标签: agent, ai, automation, collaboration, connector, documents, files, mcp, microsoft-365, microsoft-sharepoint, sharepoint, skills, tools, zapier

## 简介

Agent-callable Microsoft SharePoint tools — find sites and document libraries, browse, search, upload, move and share files, manage lists and list items, and author site pages. Use when the user mentions SharePoint or wants to work with SharePoint sites,
