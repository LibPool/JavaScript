# @zapier/firecrawl-connector

> 标签: agent, ai, automation, connector, firecrawl, mcp, skills, tools, zapier

## 简介

Agent-callable Firecrawl tools — scrape a URL to clean Markdown, crawl a site, search the web, map site URLs, and extract structured data. Use when the user wants to read, scrape, crawl, or search web pages, even if they don't name Firecrawl.
