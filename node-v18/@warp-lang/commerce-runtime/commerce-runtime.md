# @warp-lang/commerce-runtime

> 标签: JavaScript

## 简介

A reference, self-host durable-execution runtime for the Warp commerce model — feed it proposed commerce actions, it runs each through createSession + guardAction, persists an append-only audit log (in-memory or file-backed), and can replay the log to rep
