# @burnt-labs/abstract-signers

> 标签: JavaScript

## 简介

This package contains utilities to interact with the xion chain abstract account module e.g. creating abstract accounts, signing messages and broadcasting to the chain. These libraries are an extension of the Stargate library for interacting with Cosmos c
