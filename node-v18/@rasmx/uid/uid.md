# @rasmx/uid

> 标签: base62, id-generator, nanoid, performance, rust, ulid, uuid, v7, wasm

## 简介

Blazing fast WASM ID generation library powered by Rust. Support for UUID (v1-v7), ULID, NanoID, and Base62 shortening.
