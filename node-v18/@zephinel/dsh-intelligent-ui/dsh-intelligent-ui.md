> 标签: agent-ui, deepseek-harness, dsh, dsh-bundle, dsh-plugin, generative-ui, intelligent-ui, openui, openui-lang

## 简介

Intelligent UI for DeepSeek Harness: render OpenUI Lang answers as interactive maps, photos, charts, forms, drawings, working tools or a reading article inside the Web chat. Global defaults live on the Plugins detail page; the composer overrides enablemen
