# @auroraflow/code-darwin-x64

> 标签: JavaScript

## 简介

Aurora 编程 Agent 是基于 OpenAI Codex CLI 二开的 Aurora 自有编程代理。它的目标是提供类似 Codex 的本地编程体验，但身份、模型目录、API Key 与运行时路由都接入 Aurora 体系。
