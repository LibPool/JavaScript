# @fyrx/fyrx-assisted

> 标签: auto-responder, canned-replies, discord-bot, discord.js, fyrxlab, support-bot

## 简介

Drop-in, fully-configurable canned-reply addon for discord.js bots — prefix shortcodes, keyword auto-detection, and slash commands, all toggleable per server. No env vars required.
