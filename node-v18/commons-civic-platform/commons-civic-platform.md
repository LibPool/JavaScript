# commons-civic-platform

> 标签: angular, commons-civic, platform-commons

## 简介

Shared runtime of the Commons Civic admin: session, tenant config, i18n, RBAC, HTTP and the UI kit. Shared as a singleton by the shell and every micro-frontend.
