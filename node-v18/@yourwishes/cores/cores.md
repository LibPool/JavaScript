# @yourwishes/cores

> 标签: JavaScript

## 简介

This is a simple build script that takes the cores built by https://github.com/EmulatorJS/build and stores them in an NPM package so that they can be may be included within a JS package.

- npm 页面：https://www.npmjs.com/package/@yourwishes/cores
