# @mounaji_npm/chat-core

> 标签: chat, headless, mounaji, polling, sse, streaming, transport

## 简介

Headless chat core — unified turn model + transports (mounaji SSE stream protocol, correlated-events polling). Framework-agnostic: consumed by chat-interface (React) and web-widget (vanilla)
