# @patrickdk77/pdf-defuse

> 标签: attachments, cdr, cleaner, cleaning, decrypt, defang, defuse, detect, disarm, encrypted, inspect, pdf, sanitise, sanitize, scanner, scrub, security, strip

## 简介

Sanitize and clean PDF files. Detects and removes JavaScript, attached files, launch actions, unsafe links and empty-password encryption, scores the risk, and writes a disarmed copy with bounded memory and no runtime dependencies.
