# @bynovl/optimize-sources

> 标签: external-sources, integrity, internal-sources, novl, optimize, scripts, source-validation, sources, static-site, stylesheets, validation

## 简介

Source validation submodule for the NOVL Optimize project. Checks HTML for external and internal source references, script and stylesheet integrity, and best practices for static sites.
