# @serverless-devs/rds-mongodb-initialzer-plugin

> 标签: JavaScript

## 简介

`@serverless-devs/rds-mongodb-initialzer-plugin` 插件，使用该插件需要在环境变量里设置 `mongo_url` 参数, 然后你可以在 `baseHandler` 里 通过 `request.internal` 里拿到 `dbClient` 和 `MongoClient`
