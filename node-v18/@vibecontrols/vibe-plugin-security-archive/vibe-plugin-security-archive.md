# @vibecontrols/vibe-plugin-security-archive

> 标签: archive, bun, offboard, retention, security, tombstone, vibe, vibe-plugin, vibecontrols

## 简介

Archive / offboard handler for the archive.offboard lifecycle stage. Walks the agent SQLite scan_runs table for the vibe and writes a tombstone.json evidence artifact summarising final state. Honors retention policies from input.config.
