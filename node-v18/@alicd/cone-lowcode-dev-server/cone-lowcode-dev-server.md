# @alicd/cone-lowcode-dev-server

> 标签: JavaScript

## 简介

- tnpm run dev - 访问 http://127.0.0.1:4200 - 通过 htmlUrl 来设置要渲染的 html, http://127.0.0.1:4200/?htmlUrl=http://127.0.0.1:4201 - 通过 dev 来设置渲染日常发布的 html, http://127.0.0.1:4200/?dev=true - 通过 version 来设置 html 的版本, http://127.0.0.1:4200/?dev=true&version=0.1.0
