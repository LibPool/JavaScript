# @topo/connect-sdk

> 标签: JavaScript

## 简介

本文面向接入 Topo Connect 钱包的 DApp 开发者，按本仓库 `@topo/connect-sdk@0.2.0` 的接口编写。 默认通过浏览器弹窗请求连接、查询账户、签名和提交交易；Google 登录与 Keyless 会话由钱包处理。 0.2.0 新增可选 `transport`、`storage` 配置、`RelayTransport`、`createExtensionRelayTransport` 和 `resumePendingRequest()`，供 Extension / iOS
