# @pocket-network/agentic-portal-mcp

> 标签: agentic, base, mcp, model-context-protocol, pocket-network, usdc, x402

## 简介

MCP server for the Pocket Network agentic marketplace: search paid data services and call them, paying per request in USDC with x402. Holds your key locally, with spend limits checked before anything is signed.
