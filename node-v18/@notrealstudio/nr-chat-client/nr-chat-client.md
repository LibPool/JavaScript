# @notrealstudio/nr-chat-client

> 标签: JavaScript

## 简介

Тонкий клиент nr-ui-protocol без зависимостей: createClient (сессии, ран по SSE через fetch, respond/cancel, профили, модели, auth) и createHttpBackend (ProtocolBackend поверх HTTP). Браузер и Node.
