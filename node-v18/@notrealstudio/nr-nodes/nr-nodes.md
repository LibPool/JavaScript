# @notrealstudio/nr-nodes

> 标签: auto-layout, graph, node-editor, nodes, pipeline, react, visual-programming

## 简介

Node-graph editor: headless core (registry, graph ops, validation, groups, layered auto-layout) and a React canvas with ports, connections, inspector and undo.
