# @notrealstudio/keymap

> 标签: hotkeys, keybindings, keyboard, keymap, shortcuts, zero-dependency

## 简介

Hot keys as data: a table of bindings in layers (scheme → plugins → user overrides), chords by physical key (any keyboard layout), `when` contexts, collisions, hints for tooltips. Zero dependencies, no DOM.
