# @aiverse/workflow-catalog

> 标签: JavaScript

## 简介

Block and tool catalog for @aiverse/workflow — 250+ block configs and the declarative tool runtime. Runtime ships as raw TypeScript (executed by tsx/Vite); published types are pre-emitted .d.ts so consumers never compile the source.
