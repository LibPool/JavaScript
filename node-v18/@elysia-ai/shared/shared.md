# @elysia-ai/shared

> 标签: JavaScript

## 简介

Elysia A.I. 共享工具库：服务注册、数值/刺激工具、AI 相关性选择器基类、Mongo 仓储基类与连接器、插件工厂（被各 koishi-plugin-elysia-ai-* 共享）。
