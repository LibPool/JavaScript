# @rythra/connector-oceanic

> 标签: JavaScript

## 简介

Official **Oceanic.js** connector for [Rythra](https://github.com/Ekretos/Rythra). Bridges Oceanic.js gateway events and voice states with Rythra's framework-agnostic audio runtime.
