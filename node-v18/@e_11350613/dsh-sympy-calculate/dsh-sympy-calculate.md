# @e_11350613/dsh-sympy-calculate

> 标签: agent-preset, deepseek-harness, dsh, dsh-bundle, sympy

## 简介

A third-party DeepSeek Harness agent preset based on minimal. It adds one stateless tool, sympy_calculate, which runs a complete Python script in a fresh process against a local SymPy development checkout.
