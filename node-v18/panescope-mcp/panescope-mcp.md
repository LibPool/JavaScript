# panescope-mcp

> 标签: accessibility, chrome-extension, mcp, model-context-protocol, panescope, responsive, testing

## 简介

MCP server for Panescope: lets AI coding agents open pages on many devices, take screenshots, read console errors, run accessibility and responsive audits, and interact with the page.
