# @junejuly-lockstep/cli

> 标签: ci, cli, crawl, journey-map, lockstep, mcp, msw, playwright, visual-regression

## 简介

Lockstep CLI: one-command install into a client app (init), crawl the built app into a reality map with deterministic screenshots and post it (check), diagnose the wiring (doctor), and give coding agents ticket context (mcp, work-order).
