# @fullcalendar/list

> 标签: calendar, event, full-sized, fullcalendar, list-view

## 简介

FullCalendar v6 only (in v7, this plugin is built into each framework package, e.g. @fullcalendar/react/list). Display events on a calendar view that looks like a bulleted list

## 官网

- 官网：https://fullcalendar.io/docs/list-view
- 源码仓库：git+https://github.com/fullcalendar/fullcalendar.git
- npm 页面：https://www.npmjs.com/package/@fullcalendar/list
