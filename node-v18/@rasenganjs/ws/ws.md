# @rasenganjs/ws

> 标签: JavaScript

## 简介

NestJS-inspired WebSocket Gateways for Rasengan Server — module-native registration, rooms, broadcasting, and pluggable storage (in-memory or Redis), built on RFC-0001's runtime-agnostic app.websocket().
