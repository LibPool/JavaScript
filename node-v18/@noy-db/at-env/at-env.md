# @noy-db/at-env

> 标签: aes-256-gcm, at-env, encryption, env, managed-secret, noy-db, rubber-hose-resistant, sealing-key-provider, zero-knowledge

## 简介

Env-var sealing key provider for noy-db managed-secret mode — AES-256-GCM under a key from process.env. Smallest production-shape provider; pair with Kubernetes Secrets / Heroku env / AWS Secrets Manager.
