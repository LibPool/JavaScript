# @noy-db/as-xlsx

> 标签: as-xlsx, excel, export, noy-db, ooxml, plaintext, spreadsheet, xlsx, zero-knowledge

## 简介

Excel spreadsheet plaintext export for noy-db — produces a real .xlsx (Office Open XML) from one or more collections. Multi-sheet, Unicode-safe via shared-strings table. Zero runtime deps beyond the workspace zip encoder. Gated by `vault.assertCanExport('
