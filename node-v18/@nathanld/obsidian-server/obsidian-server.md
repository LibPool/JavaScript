# @nathanld/obsidian-server

> 标签: bun, claude, cli, mcp, model-context-protocol, obsidian, rest-api

## 简介

Point any Obsidian vault at an MCP server + REST API with Bearer-token auth out of the box, backed by the official Obsidian CLI.
