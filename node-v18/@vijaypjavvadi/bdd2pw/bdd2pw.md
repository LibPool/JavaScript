# @vijaypjavvadi/bdd2pw

> 标签: bdd, cucumber, gherkin, mcp, page-object, playwright, scaffold, test-automation

## 简介

Scaffold runnable Playwright TypeScript tests from Gherkin .feature files. Detects existing Page Objects, scans live pages via Microsoft Playwright MCP, emits POMs + specs, ready for execution. CLI + HTTP service. Optional governed LLM fallback (Anthropic
