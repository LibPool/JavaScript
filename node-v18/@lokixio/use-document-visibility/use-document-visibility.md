# @lokixio/use-document-visibility

> 标签: JavaScript

## 简介

Хук, который показывает: активная ли страница, сколько раз с момента инициализации компонента вкладка становилась неактивной и предоставляет функцию, в которой можно подписаться на изменение видимости текущей вкладки
