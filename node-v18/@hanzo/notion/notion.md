# @hanzo/notion

> 标签: JavaScript

## 简介

Hanzo AI for Notion — summarize a page, draft/expand content, extract action items into a database, and ask about a page/workspace. Model calls route through the api.hanzo.ai gateway; Notion access via OAuth2 (public integration) + REST v1 with a server-s
