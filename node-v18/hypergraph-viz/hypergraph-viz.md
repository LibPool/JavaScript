# hypergraph-viz

> 标签: bubble-sets, g6, hypergraph, layout, visualization

## 简介

Hypergraph rendering on G6 v5: hypergraph layout, node-only bubble sets, hover and selection, plus an explorer UI with database and inspector panels and an admin console
