# @iskl/dev-journal

> 标签: agent-skill, agentskills.io, changelog, claude-code, code-review, codex-cli, cursor, dev-journal, gemini-cli, journal, skill

## 简介

An Agent Skill that generates structured developer journals (modification summary, future-reader guide, collaborator-facing API notes, and a self-review) to <project>/.journal after a coding session. Cross-platform: installs into Claude Code, Cursor, Gemi
