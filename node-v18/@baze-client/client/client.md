# @baze-client/client

> 标签: auth, baze, database, nextjs, postgres, postgrest, ssr, supabase

## 简介

TypeScript client for Baze projects - a PostgREST query builder and project auth, with the call surface of @supabase/supabase-js and first-class SSR support.
