# @codedgar/glassworks

> 标签: glass, glassmorphism, liquid-glass, refraction, snapdom, ui, webgl

## 简介

Liquid glass for the web — turns any positioned element into a refracted, glossy WebGL glass pane. Rebuilt on snapdom for ~4× faster captures.
