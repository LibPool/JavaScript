# @zennopay/react-native

> 标签: android, ios, payments, promptpay, qr, react-native, turbomodule, vietqr, zennopay

## 简介

Zennopay PaymentSheet for React Native — a thin native bridge over the native Zennopay iOS/Android checkout sheets (scan → amount → confirm → status). One call in, one PaymentResult out.
