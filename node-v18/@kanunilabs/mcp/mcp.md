# @kanunilabs/mcp

> 标签: ai, datagrid, documentation, kanunilabs, mcp, model-context-protocol, pivotgrid

## 简介

MCP server that gives AI coding assistants the KanuniLabs DataGrid and PivotGrid documentation and API reference. Runs locally over stdio; the docs ship inside the package, nothing is fetched.
