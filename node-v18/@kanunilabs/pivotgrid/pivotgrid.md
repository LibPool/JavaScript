# @kanunilabs/pivotgrid

> 标签: aggregation, analytics, cross-tab, drag-and-drop, i18n, javascript, no-framework, olap, pivot, pivot-grid, pivot-table, pivotgrid, rtl, typescript, umd, vanilla-js, virtualized, web-worker

## 简介

High-performance pivot table for vanilla JavaScript — no framework required. Drag-and-drop pivoting, a Web Worker aggregation engine, filtering, totals and theming, with a UMD build for script-tag use.
