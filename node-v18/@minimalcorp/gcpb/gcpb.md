# @minimalcorp/gcpb

> 标签: branch, branch-management, cli, dev-container, devcontainer, developer-tools, docker, git, git-clone, git-workflow, git-worktree, interactive-cli, nodejs, typescript, vscode, worktree, worktree-alternative

## 简介

Simple alternative to git worktree with full dev container support. Clone git repositories per branch with an interactive CLI. Perfect for parallel feature development.
