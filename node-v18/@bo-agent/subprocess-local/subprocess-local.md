# @bo-agent/subprocess-local

> 标签: JavaScript

## 简介

Local subprocess provider: detached process-tree spawn, per-stream stdio, tail-keep collection with spill, POSIX process-group and Windows taskkill tree signalling, and SIGTERM→SIGKILL escalation (standalone product, forked from the DeepSeek Harness)
