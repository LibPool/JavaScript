# @donchong/mini-agent

> 标签: JavaScript

## 简介

A lightweight coding agent designed for small LLMs (e.g., GPT-5 mini, MiniMax M2.7, Claude Haiku). Focuses on reliability under model limits, with benchmarks comparing performance against agents like OpenCode.
