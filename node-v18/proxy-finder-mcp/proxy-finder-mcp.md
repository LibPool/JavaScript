# proxy-finder-mcp

> 标签: claude, claude-code, free-proxy, geolocation, mcp, model-context-protocol, proxy, proxy-list, socks5

## 简介

MCP server that finds and validates working free HTTP/HTTPS/SOCKS proxies by country, for geofenced requests and debugging blocked curls.
