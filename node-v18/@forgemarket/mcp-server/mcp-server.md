# @forgemarket/mcp-server

> 标签: ai-agents, ai-marketplace, claude, claude-code, cursor, forgemarket, internal-tools, mcp, publisher

## 简介

ForgeMarket CLI + MCP server. Scaffold internal AI apps with `init`, publish them with `publish`, or run as an MCP stdio server for Claude Code / Cursor.
