# @yun520-1/agent-trust-layer

> 标签: agent, ai, discriminator, guardrail, llm, mcp, output-filter, security, trust, verification

## 简介

Agent Trust Layer — rule-based discriminator engine for AI agent output verification. 47 dimensions, 9 check layers, 131 MCP tools. Zero LLM dependency. Checks what AI says before it reaches humans and says "no" when something is wrong.
