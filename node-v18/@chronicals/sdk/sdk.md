# @chronicals/sdk

> 标签: app, internal tool, ui, ui builder

## 简介

The frontendless framework for high growth companies. Chronicals automatically generates apps by inlining the UI in your backend code. It's a faster and more maintainable way to build internal tools, rapid prototypes, and more.
