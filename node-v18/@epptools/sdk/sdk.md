# @epptools/sdk

> 标签: dnssec, domains, epp, registrar, registry, rfc5730, rfc5731, sdk

## 简介

Dependency-free Node.js client for EPP domain registries (RFC 5730-5734 over TLS), with a registry's own extensions discovered from its greeting.
