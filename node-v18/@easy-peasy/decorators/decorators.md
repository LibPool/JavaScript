# @easy-peasy/decorators

> 标签: JavaScript

## 简介

This version wraps `@easy-peasy/core` to provide decorators for creating your store models. Inspired from [issue/359](https://github.com/ctrlplusb/easy-peasy/issues/359) ``` npm install @easy-peasy/decorators yarn add @easy-peasy/decorators ```
