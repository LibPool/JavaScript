# @icreate/ics-chromely-plugin-core

> 标签: JavaScript

## 简介

提供Ics Chromely Client核心本地操作插件js sdk，包含本地日志、主窗体控制、打开三方浏览器、打印机列表、硬件IP和Mac地址、本地配置获取和注册表读写等
