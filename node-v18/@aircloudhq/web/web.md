# @aircloudhq/web

> 标签: action-view, aircloud, functions, helpers, i18n, rails, react, site

## 简介

The application package of an Air-Cloud product: the Rails Action View helpers, i18n over the product's locale bundle, resource pages over its models, and React bindings, for its site and its JavaScript functions.
