# @aircloudhq/testing

> 标签: aircloud, functions, node-test, test-doubles, testing, wasm, wit

## 简介

In-memory capability doubles for Air-Cloud JavaScript functions, generated from the aircloud:capability WIT contract, plus the fetch-event harness for node:test unit tests.
