# @rhombus-std/config.transformer

> 标签: compiler, config, configuration, ioc, transformer, ts-patch, typescript

## 简介

The @rhombus-std/config ts-patch transformer: rewrites .withType<T>() on a ConfigurationBuilder into a generated .withSchema({...}) runtime schema literal at compile time.
