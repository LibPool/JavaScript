# @rhombus-std/logging.core

> 标签: abstractions, ioc, logging, typescript

## 简介

Logging abstractions: ILogger/ILoggerFactory/ILoggerProvider/ILoggingBuilder + LogLevel/EventId, plus the real-runtime logInformation/logError/... convenience wrappers. Depends on @rhombus-std/di.core for the Manifest type ILoggingBuilder wraps.
