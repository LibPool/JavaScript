# @rhombus-std/hosting

> 标签: generic-host, hosted-service, hosting, ioc, lifetime, typescript

## 简介

The Generic Host runtime: HostBuilder / HostApplicationBuilder, the static Host factory, HostOptions, the console lifetime, and the composition that wires di, config, and logging together.
