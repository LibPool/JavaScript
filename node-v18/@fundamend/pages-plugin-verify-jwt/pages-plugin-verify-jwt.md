# @fundamend/pages-plugin-verify-jwt

> 标签: JavaScript

## 简介

_pages-plugin-verify-jwt_ is a [Cloudflare Pages plugin] used by the [fundamend.dev] ecosystem. It offers a [middleware] for verifying [JWT]s with a verification key.
