# @tetrac/echoblocks-ts-sdk

> 标签: anchor, devnet, rpc-failover, sdk, shadowspace, social, solana, web3

## 简介

Node/TypeScript SDK for the ShadowSpace Solana program — post, like, comment, follow, communities & polls, with multi-provider RPC failover and a mainnet/devnet switch.
