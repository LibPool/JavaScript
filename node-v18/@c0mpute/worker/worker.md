# @c0mpute/worker

> 标签: c0mpute, distributed, gpu, inference, llm, ollama, worker

## 简介

Native CLI worker for the c0mpute.ai distributed inference network. Runs LLM inference via ollama and connects to the orchestrator via Socket.io.
