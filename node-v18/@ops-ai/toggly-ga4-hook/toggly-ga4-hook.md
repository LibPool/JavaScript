# @ops-ai/toggly-ga4-hook

> 标签: ab-testing, analytics, experimentation, feature-flags, feature-management, feature-toggles, ga4, google-analytics, gtag, hooks, monitoring, toggly, tracking

## 简介

Google Analytics 4 hook for Toggly Feature Flags SDK. Automatically pushes feature flag data to GA4 for analytics and user behavior correlation.
