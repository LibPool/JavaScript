# @ops-ai/react-feature-flags-toggly

> 标签: feature-flags, feature-management, toggly

## 简介

Provides feature flags support for React applications allowing you to enable and disable features easily. Can be used with or without Toggly.io.

## 官网

- 官网：https://docs.toggly.io/sdks/javascript/react
- 源码仓库：git+https://github.com/ops-ai/Toggly.FeatureManagement.git
- npm 页面：https://www.npmjs.com/package/@ops-ai/react-feature-flags-toggly
