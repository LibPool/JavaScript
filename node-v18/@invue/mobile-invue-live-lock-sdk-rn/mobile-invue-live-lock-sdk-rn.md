# @invue/mobile-invue-live-lock-sdk-rn

> 标签: android, ios, react-native

## 简介

A cross-platform React Native SDK for integrating and managing Live Lock based smart locks via Bluetooth Low Energy (BLE), providing secure access control, device discovery, and lock management APIs
