# @nasriya/cachify

> 标签: cache, cache-engine, caching, cold-start, extensible, fast-cache, file-cache, key-value, lifecycle-management, memory-cache, multi-storage, nodejs, persistent-cache, redis

## 简介

A lightweight, extensible in-memory caching library for storing anything, with built-in TTL and customizable cache types.
