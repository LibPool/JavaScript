# @ai2web/nuxt

> 标签: agentic, ai-agents, ai2web, mcp, nitro, nuxt, nuxt-module, vue

## 简介

Nuxt module that serves all AI2Web routes (/ai2w, /.well-known/ai2w, llms.txt, agent.json, actions) from one manifest.
