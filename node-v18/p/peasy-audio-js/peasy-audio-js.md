# peasy-audio-js

> 标签: audio, convert, ffmpeg, merge, mp3, peasy, trim, wav

## 简介

Audio processing library for Node.js — convert, trim, merge, normalize, fade, speed. FFmpeg-powered, TypeScript-first.
