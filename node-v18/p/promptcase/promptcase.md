# promptcase

> 标签: ai, capture, claude-code, cli, cline, codex, copilot, cursor, daemon, prompt-library, prompt-management, prompts, sync

## 简介

Background daemon that captures the prompts you write across 9 AI coding tools (Claude Code, Claude in VS Code, Claude Desktop, OpenAI Codex, GitHub Copilot Chat, Cline, Blackbox, Cursor, Antigravity) and syncs them to your PromptCase account.
