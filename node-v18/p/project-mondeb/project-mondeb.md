# project-mondeb

> 标签: JavaScript

## 简介

This is my first attempt at creating a repo housing a Termux Monet app pak (https://github.com/Termux-Monet) for android devices,  and scripts to update Termux and get a Debian Distro up with xfce4 desktop in proot.
