# product-studio

> 标签: ai-image, ai-video, claude-skill, ecommerce, product-photography, seedance, seedream, volcengine-ark

## 简介

商品素材工厂 (Product Asset Factory)：1 张商品图 → 抖店上架图 + 千川投放视频。火山方舟 Seedream/Seedance 驱动，Claude Code 技能 + CLI 双形态。Jewelry product photo/video asset factory on Volcengine Ark (Seedream image + Seedance video), usable as a Claude Code skill or standalone CLI.
