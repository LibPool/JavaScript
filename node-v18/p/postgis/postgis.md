# postgis

> 标签: bounding-box, database, geobuf, geojson, geospatial, gis, mapbox, mvt, nearest-neighbor, node-postgres, nodejs, pg, postgis, postgres, postgresql, spatial, srid, typescript, vector-tiles, wgs84

## 简介

A lightweight, type-safe Node.js library for interacting with PostGIS-enabled PostgreSQL databases. Supports GeoJSON, Geobuf, MVT tiles, spatial queries, and more.
