# promptrix-cli

> 标签: agents-md, ai, ci, claude, claude-code, claude-md, cli, code-quality, cursor, developer-tools, gemini, gpt, optimization, prompt, prompt-engineering, prompt-linter, prompt-quality, promptrix, static-analysis

## 简介

Scan your repo for prompts — prompt files, CLAUDE.md, AGENTS.md, embedded system prompts — score them 0-100 offline with a deterministic engine, and improve them with reviewable diffs. CI-friendly, no API key needed to score.
