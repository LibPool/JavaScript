# proximal-onyx-widget

> 标签: ai, chat, chatbot, embed, onyx, rag, web-component, widget

## 简介

Proximal build of the Onyx chat widget: legacy-stream compatible, with built-in diagnostic logging. Embed an AI chat assistant on any site with a single script tag.
