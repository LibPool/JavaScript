# proxy-checker-modern

> 标签: checker, https, proxies, proxy, proxy server, socks, socks4, socks5

## 简介

Check HTTP, HTTPS, SOCKS4 and SOCKS5 proxy servers with timeout support, Promise/async API and concurrency control.
