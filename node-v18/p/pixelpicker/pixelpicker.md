# pixelpicker

> 标签: anchor-positioning, color, colorpicker, colour, input, no-dependencies, picker, popover

## 简介

A lightweight, dependency-free color picker. Uses the Popover API and CSS Anchor Positioning, with a JavaScript fallback.
