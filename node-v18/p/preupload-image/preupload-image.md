# preupload-image

> 标签: browser, canvas, client-side, compress, file-upload, image, image-compress, image-convert, image-processing, image-resize, preupload, resize, upload, webp

## 简介

Lightweight browser-side image processing before upload — compress, convert to WebP, and resize using Canvas API. No server needed.
