# pixi-silk

> 标签: anti-aliasing, antialiasing, charts, gradient, graphics, hidpi, oklab, pixi, pixi.js, pixijs, retina, sdf, shader, signed-distance-field, squircle, typescript, vector, webgl

## 简介

Smooth vector graphics for PixiJS v8: analytic anti-aliased SDF primitives, squircles, arcs, polylines, dashes, OKLab gradients, glows and DPR-exact canvases, one draw call per object.
