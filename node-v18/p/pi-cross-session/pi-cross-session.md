# pi-cross-session

> 标签: coding-agent, cross-session, ipc, pi, pi-extension, pi-package

## 简介

Pi ↔ Pi same-machine cross-session messaging: discover live sessions and exchange plain-text peer messages over per-instance IPC (Unix socket / named pipe)
