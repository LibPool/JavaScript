# pictools

> 标签: JavaScript

## 简介

这个命令行程序可以帮助你批量压缩图片，将它们的宽度调整到指定的大小并保存到一个新的目标文件夹中。使用这个程序可以减小图片文件的大小，方便在互联网上共享和发布。
