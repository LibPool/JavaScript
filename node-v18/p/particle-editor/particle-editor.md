# particle-editor

> 标签: animation, canvas, effect, engine, particle, particles, renderer

## 简介

Framework-agnostic particle-effect player/parser engine for configs exported by the particle-editor tool. Works in any frontend framework (React/Vue/Svelte/vanilla) and via plain CDN <script> tags.
