# pulse-heatmap-mansregin

> 标签: activity, analytics, appstudio, colix, contributions, heatmap, widget

## 简介

GitHub-style activity heatmap widget for Colix AppStudio. Turns any time-stamped table into a contribution grid with streaks and day-press events.
