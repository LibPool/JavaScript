# pattapatta

> 标签: boolean, circle-packing, clipper, geometry, halftone, hatching, pen-plotter, pgs, svg, voronoi

## 简介

Pen-plotter geometry library (PGS-inspired): hatching, image halftone, packing, boolean paths for SVG
