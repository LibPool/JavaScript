# pi-knock

> 标签: notification, osc, pi, pi-extension, pi-package, terminal, tmux

## 简介

Native terminal notification the moment Pi finishes — via OSC 777 / 99 / tmux DCS passthrough. No daemon, no push service, no remote GUI.
