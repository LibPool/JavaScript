# playwright-coverage-reporter

> 标签: automation, coverage, e2e, element-coverage, istanbul, lcov, playwright, reporter, test-coverage, testing, typescript, ui-testing

## 简介

🎯 Native Playwright coverage reporter with runtime element discovery. Seamlessly integrates with your Playwright test suite to analyze UI element coverage, discover interactive elements during test execution, and generate comprehensive reports with Istan
