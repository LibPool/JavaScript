# propellerkit-custom-scrollbar

> 标签: css, custom-scrollbar, framework, front-end, js, material design, mobile-first, propellerkit, responsive, scroll, scrollbar, scss

## 简介

Propeller’s custom scrollbar is used to get rid of browser default scroll bar by utilizing  the feature-rich jQuery custom content scroller plugin. It allows you to customize scrollbars exactly as you need them. It features vertical/horizontal scrolling,
