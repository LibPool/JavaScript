# pixtega

> 标签: avif, image, picture, pixtega, resize, srcset, url, webp

## 简介

URL builders for Pixtega, the on-demand image derivation service. Pure string helpers: pixtegaUrl, pixtegaSrcSet, pixtegaPicture.
