# pi-rename

> 标签: extension, naming, pi, pi-coding-agent, pi-extension, pi-package, rename, session, session-name, terminal, terminal-title, title, vscode

## 简介

Pi coding agent extension — auto-name a new session after the first turn, /rename from the last 5 turns, and mirror the session name into the terminal tab title (VS Code pwsh / Git Bash; patches terminal.integrated.tabs.title on Windows)
