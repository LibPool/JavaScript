# pantone-tcx

> 标签: Pantone, color, color-library, color-matching, color-utilities, color_name, design-tools, hex-to-color, hex-to-pantone, hex-to-tcx, nearest-pantone, pantone-matching, pantone-tcx, similar-colors

## 简介

Find the nearest Pantone TCX color by HEX, get similar colors within a specified range, and return details like name, TCX code, or HEX value.
