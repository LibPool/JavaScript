# pi-zcode-headers

> 标签: glm, pi-extension, pi-package, zai, zcode, zhipu

## 简介

让 pi 伪装成官方 ZCode 客户端 | Make pi pretend to be the official ZCode client — injects ZCode identity headers so the Zhipu backend treats pi traffic as ZCode traffic.
