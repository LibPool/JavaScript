# pq-governance

> 标签: developer-tools, governance, pqdc, pqdx

## 简介

pq-governance — Shared .pqdx governance runtime for the pq__ suite: .pqdx/ resolution, state-file finder, registry resolution (PQDX_REGISTRY), atomic write + backup-rotation + rollback, dry-run, posture, ISO-8601 date validation (the H9 gap pqdx leaves op
