# postcss-color-hex-alpha-2

> 标签: alpha, color, colour, css, hexa, postcss, postcss-plugin

## 简介

PostCSS plugin to transform W3C RGBA hexadecimal notations (#RRGGBBAA or #RGBA) to more compatible CSS (rgba())
