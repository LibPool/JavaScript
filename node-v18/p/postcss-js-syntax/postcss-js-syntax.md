# postcss-js-syntax

> 标签: css, css-in-js, cssinjs, javascript, js, json, jss, parser, plugin, postcss, postcss-syntax, preprocessor, syntax

## 简介

For use powerful JavaScript syntax for compile CSS instead legacy preprocessors: SASS, LESS, Stylus, etc.
