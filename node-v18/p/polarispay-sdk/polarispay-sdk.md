# polarispay-sdk

> 标签: bnpl, buy-now-pay-later, checkout, ethereum, evm, payments, polaris, stablecoin, subscriptions, web3

## 简介

One object, three payment modes: pay now, subscribe, or split into instalments. On-chain BNPL for any EVM checkout.
