# phototology

> 标签: agentic-ai, ai, claude-code, computer-vision, cursor, image-analysis, image-recognition, mcp, model-context-protocol, photo-intelligence, phototology, sdk, vision

## 简介

Phototology — persistent memory for visual intelligence. The working packages are @phototology/sdk (TypeScript SDK) and @phototology/mcp (MCP server). See phototology.com.
