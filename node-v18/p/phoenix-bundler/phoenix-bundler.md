# phoenix-bundler

> 标签: Backend development, Frontend development, JavaScript build tool, Library package builder, React package builder, Rspack Wrapper

## 简介

Rspack Wrapper is an intuitive and efficient npm package designed to streamline the development of React, Node.js, and library packages. By leveraging the powerful capabilities of Rspack, this wrapper simplifies the build process and enhances performance,
