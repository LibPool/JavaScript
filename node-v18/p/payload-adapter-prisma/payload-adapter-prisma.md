# payload-adapter-prisma

> 标签: database-adapter, payload, payload-cms, payload-plugin, postgres, prisma

## 简介

Payload CMS database adapter for an existing Prisma schema. Payload keeps its own state in a second database, yours stays exactly as Prisma wrote it.
