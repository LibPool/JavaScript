# prelude-ps

> 标签: array, coffeescript, functional, javascript, library, list, livescript, ls, object, prelude, string, utility

## 简介

prelude.ps is a functionally oriented utility library. It is powerful and flexible. Almost all of its functions are curried. It is written in, and is the recommended base library for, LiveScript.
