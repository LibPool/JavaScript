# polysql

> 标签: alloy, alloydb, bigquery, cockroach, cockroachdb, data adapter, data warehouse, database, duckdb, maria, mariadb, mssql, mysql, postgres, postgresql, redshift, snowflake, sqlite, sqlserver, timescale, timescaledb, universal, yugabyte, yugabytedb

## 简介

A simple data adapter that provides a single, consistent interface for querying across PostgreSQL, MySQL, SQL Server, SQLite DuckDB, BigQuery, and Snowflake
