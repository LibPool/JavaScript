# playwright-visual-debug

> 标签: debugging, dom-diff, playwright, reporter, screenshot, testing, visual-regression

## 简介

Playwright reporter and fixtures that capture before/after screenshots and DOM of every interacted element, so failing tests show exactly what changed.
