# pi-prometheus

> 标签: coding-agent, context-window, cost-tracking, grafana, metrics, observability, pi, pi-coding-agent, pi-extension, pi-package, prometheus, tokens, victoriametrics

## 简介

See what your Pi session actually costs: a per-source context breakdown in the terminal showing which extension, skill or MCP server eats your window, plus a /metrics endpoint and Grafana dashboards.
