# playwright-attach-chrome

> 标签: api-inspection, cdp, chrome, devtools, har, mcp, model-context-protocol, network-capture, playwright, reverse-engineering

## 简介

Attach Playwright to a real Chrome session — capture & filter network traffic from a logged-in window. Export HAR. CLI + MCP server.
