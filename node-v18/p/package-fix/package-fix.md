# package-fix

> 标签: dependencies, fix, package-fix, package.json, version

## 简介

package-fix主要用于固定package.json中的dependencies和devDependencies版本，防止依赖版本更新导致项目无法正常运行。

## 官网

- npm 页面：https://www.npmjs.com/package/package-fix
