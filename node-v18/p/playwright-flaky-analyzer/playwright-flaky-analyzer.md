# playwright-flaky-analyzer

> 标签: ci-cd, dashboard, flaky-detection, flaky-test, flaky-trend, playwright, playwright-reporter, qa, quality-gate, test-analyzer, test-automation, test-health, test-reporter, testing

## 简介

Compare Playwright test runs to tell genuinely broken tests from flaky ones. Deterministic root-cause rules, failures grouped by shared cause, and triage inside the report itself. Offline, no AI required. Interactive HTML dashboard plus JSON and Markdown,
