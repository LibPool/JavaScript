# project-loop

> 标签: agent-loop, agent-skills, claude-code, cli, codex, cursor, definition-of-done, orchestration, qa, security, spec-driven-development, verification

## 简介

Closed-loop, evidence-gated build system for AI coding agents. Plan, Spec, Build, Verify — with a separate Judge role that holds the exit gate and issues rework orders until the frozen Definition of Done is met.
