# protocolprobe-selftest

> 标签: mcp, model-context-protocol, security, testing

## 简介

Runs ProtocolProbe's MCP security checks against YOUR OWN MCP server, from your machine: a local stdio server, or your Streamable HTTP server after it proves control of its exact URL (with your own credential from an environment variable when it needs one
