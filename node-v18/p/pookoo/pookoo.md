# pookoo

> 标签: audit, cli, config, config-docs, configuration, developer-tools, devtools, dotenv, dx, env, env-example, environment-variables, monorepo, nextjs, nodejs, react, security, static-analysis, vite

## 简介

Deterministic CLI to audit, document, and manage environment variables. Detects unused, undocumented, and misconfigured config vars across Next.js, Vite, React, and Node.js projects.
