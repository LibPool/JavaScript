# pi-piper

> 标签: coding-agent, pi, pi-package, pwa, remote-control, tailscale

## 简介

Remote control for live pi coding-agent sessions from your phone over a private Tailscale network. Rust Hub + the pi-piper-agent pi extension (adds /rc) + a mobile PWA.
