# provenance-mcp

> 标签: agentic-payments, algorand, mcp, modelcontextprotocol, reputation, trust, wash-trading, x402

## 简介

MCP server that checks the wash-traffic / organic-revenue risk of Algorand x402 endpoints before your agent trusts or pays them. Free quick checks; paid deep reports via x402.
