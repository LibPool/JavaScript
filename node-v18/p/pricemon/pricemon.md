# pricemon

> 标签: alert, cdp, chrome, cli, monitor, price, scraper, tracker

## 简介

Monitor prices on any website and get alerts on changes. Uses Chrome CDP for JS-rendered pages.

- npm 页面：https://www.npmjs.com/package/pricemon
