# postiz-mcp

> 标签: automation, mcp, model-context-protocol, openclaw, postiz, scheduling, social-media

## 简介

Canonical Postiz client for any MCP-compatible client: full coverage of the Postiz public API (integrations, posts, uploads, analytics, video) with env-gated writes, confirm-required deletes, and a built-in 30/hr rate-limit guard. MCP server + first-class
