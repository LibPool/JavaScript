# pr-hero

> 标签: JavaScript

## 简介

A multi-agent PR-review engine. Specialty hunter agents fan out in parallel over a repo checkout and its diff, a mechanical dedupe merges their drafts, an adversarial refuter challenges every severe finding, and deterministic code — never a model — assign
