# pg-loader-cli

> 标签: cli, csv, import, json, loader, migration, mysql, pgloader, postgres, postgresql, sqlite

## 简介

A high-performance Node.js CLI tool similar to pgloader to migrate/load data from CSV, JSON, SQLite, and MySQL to PostgreSQL using streaming COPY.
