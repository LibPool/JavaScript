# payway-ts

> 标签: aba, aba-bank, aba-pay, aba-payway, ababank, abapay, api-client, cambodia, khmer, khqr, nextjs, nodejs, payment, payment-gateway, payment-integration, payments, payout, payway, pre-authorization, riel, sdk, typescript

## 简介

Unofficial TypeScript SDK for ABA PayWay (ABA Bank Cambodia) — ABA PAY, KHQR, cards, pre-authorization and payout, with HMAC-SHA512 signing. ESM + CommonJS, zero dependencies.
