# pi-agent-stack

> 标签: agent, ai, personas, pi, pi-package, project-management

## 简介

A chartered project-manager agent plus the specialist team it delegates to: kernel/charter pm, pack-based intake interview, researcher, oracle, worker, and the ship-gate reviewers. Bundles the subagent runtime and the execution pipeline.
