> 标签: agents-md, ai-coding, claude-code, codex, cursor, gemini-cli, scaffolding, sdd, spec-driven-development

## 简介

Pragmatic Spec-Driven Development — npm CLI that scaffolds the SDD pipeline (specs, prompts, skills, ADR/runbook conventions) into any project. Tool-agnostic via AGENTS.md.
