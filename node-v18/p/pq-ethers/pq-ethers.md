# pq-ethers

> 标签: bip39, blockchain, crystals-dilithium, dilithium, ethereum, ethers, evm, fips-204, keystore, lattice-cryptography, ml-dsa, ml-dsa-87, mldsa, nist, post-quantum, post-quantum-cryptography, pqc, quantum-resistant, quantum-safe, signature, signer, wallet, web3

## 简介

ethers for the post-quantum era: drop-in ethers v6 API for quantum-resistant EVM chains. Wallets, transactions, contracts and EIP-191/712 signing with ML-DSA-87 (FIPS 204 / CRYSTALS-Dilithium) instead of ECDSA.
