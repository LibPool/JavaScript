# promptlike-mcp

> 标签: agent, ai, claude, developer-tools, llm, mcp, model-context-protocol, prompt, prompt-engineering, prompt-library

## 简介

MCP server for PromptLikeEngineer - gives AI agents read-only access to your prompt library (list, search, get, fill variables).
