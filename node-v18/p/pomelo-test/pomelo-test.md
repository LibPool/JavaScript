# pomelo-test

> 标签: JavaScript

## 简介

Pomelo is a fast, scalable game server framework for [node.js](http://nodejs.org). It provides the basic development framework and a lot of related components, including libraries and tools.  Pomelo is also suitable for realtime web application, its distributed architecture makes pomelo scales better than other realtime web framework.
