> 标签: agents, claude, claude-code, cockpit, sessions, terminal

## 简介

Precentor - one seat, many voices. A desktop cockpit for Claude Code sessions: durable terminals, honest dispatch reports, and a master chat that conducts them all. Public release in preparation.
