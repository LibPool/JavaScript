# pixiv-token-getter

> 标签: api, authentication, cli, credential-manager, gppt, login, oauth, pixiv, pixiv-api, pkce, puppeteer, refresh-token, sdk, token

## 简介

Node.js Pixiv credential manager and authentication facade - token cache, refresh-token lifecycle, profiles, PKCE OAuth + Puppeteer login, optional gppt interoperability. Library and CLI (ptg). TypeScript types included.
