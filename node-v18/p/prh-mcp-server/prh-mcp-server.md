# prh-mcp-server

> 标签: company-registry, finland, finnish, kaupparekisteri, mcp, model-context-protocol, prh, yritysrekisteri

## 简介

MCP server for PRH (Finnish Patent and Registration Office) — Look up Finnish company data, board members, financial reports. Free public API, no auth required.
