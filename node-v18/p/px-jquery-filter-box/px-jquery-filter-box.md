# px-jquery-filter-box

> 标签: filter-box, groupbox, input, jquery, object-group, px, select, sort-box

## 简介

Used to group objects used jquery-filter-box filter. When the filtering objects are many, up to 2 or more lines, jquery-filter-box allows you to group these objects as many times as you want. For example, you can use Filter 1, Filter 2, Filter 3, Filter 4
