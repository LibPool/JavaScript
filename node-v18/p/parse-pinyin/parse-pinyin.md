# parse-pinyin

> 标签: json, parse-pinyin, pinyin, pinyin-pro, storage, 中文, 拼音, 汉字

## 简介

一个高效的汉字拼音查询库，兼容浏览器和nodejs，提供ESM、commonjs、iife格式的构建，支持拼音反查,解析获取中文拼音、韵母、声母、声调、前后鼻音等
