# puntoenv

> 标签: dot-env, dotenv, dotenv-expand, env, env config, env file, env loader, env parser, env reader, env variables, env vars, environment, environment variables, load-env, next-env, process env

## 简介

Simple package that enables you to load .env files in to process.env and also do variable expansion in a predetermined order based on the NODE_ENV environment variable value.
