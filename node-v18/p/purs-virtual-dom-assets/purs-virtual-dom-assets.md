# purs-virtual-dom-assets

> 标签: JavaScript

## 简介

CLI that convets a folder of XML files (like SVG, HTML, ...) into a folder of PureScript modules containing [virtual-dom](https://github.com/thought2/purescript-virtual-dom) views.
