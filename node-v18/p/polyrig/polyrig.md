# polyrig

> 标签: JavaScript

## 简介

Universal AI harness pack protocol and context assembly system. `npx polyrig install` stages the runtime and installs the /polyrig, /polyrig-pack-author, and /polyrig-pack-install skills for your local agent platforms (Claude Code, Codex, Cursor, Gemini C
