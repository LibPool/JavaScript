# plugin-wallettriage

> 标签: base, elizaos, evm, exploit, plugin, risk, security, usdc, wallet, web3, x402

## 简介

Real-time wallet risk check for ElizaOS agents — active ERC20 approvals cross-referenced with a live exploit threat feed, paid per query via x402 (USDC on Base). No signup, no API key.
