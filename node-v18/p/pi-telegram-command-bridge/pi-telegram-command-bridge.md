# pi-telegram-command-bridge

> 标签: bridge, commands, pi, pi-extension, pi-package, telegram

## 简介

Companion extension for @llblab/pi-telegram: executes pi extension commands (e.g. /project) and skill commands (/skill:name) natively from Telegram-originated prompts
