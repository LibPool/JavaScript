# power-electron

> 标签: electron

## 简介

This is a version of electron that allows a chromium V8 memory cage with a maximum size of 32GB.

## 官网

- npm 页面：https://www.npmjs.com/package/power-electron

- npm registry：https://registry.npmjs.org/power-electron
- Node 要求：>= 10.17.0
