# preview-pictrue

> 标签: css, html, js, vue

## 简介

支持直接点击就可以对图片的预览支持放大缩小旋转等功能，对富文本解析出来的图片也都是可以支持，   不需要包裹组件使用，直接通过js操作，非常的便捷灵活
