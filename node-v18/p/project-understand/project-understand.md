# project-understand

> 标签: JavaScript

## 简介

Công cụ CLI và ứng dụng web tĩnh để trực quan hóa kiến trúc phần mềm dưới dạng đồ thị tri thức tương tác. Phân tích mã nguồn, tạo đồ thị cấu trúc, và xem trước trên trình duyệt — tất cả không cần AI agent.
