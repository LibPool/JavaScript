# pnp-blob-storage-arg

> 标签: JavaScript

## 简介

- Typescript Node.js package that exports class which ingests Azure configuration info and provides functions to consume and manage Microsoft Azure Data Lakes - Removes need for manual implementation of boilerplate code for saving to and fetching from Dat
