# phaser-isometric

> 标签: depth-sort, gamedev, isometric, isometric-game, phaser, phaser-plugin, phaser4, tilemap, typescript

## 简介

Isometric plugin for Phaser 4: projection, elevation-aware picking, deterministic depth ordering, O(1) culling and correct world bounds.
