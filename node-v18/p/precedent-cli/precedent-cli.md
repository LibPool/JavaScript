# precedent-cli

> 标签: agents, ai, claude, codex, coding-agents, cursor, decisions, governance, guardrails, precedent

## 简介

The decision layer for AI coding agents — retrieve, govern, record, and retire team decisions. One `npx precedent-cli init` to install into any repo.
