# propellerkit-datatables

> 标签: Bootstrap, DataTables, css, filter, framework, front-end, js, mobile-first, responsive, sort, table

## 简介

Propeller’s data tables refers to a matrix of information, like an excel spreadsheet with columns, rows, and data. We have used Bootstrap Data table as base and customized it by applying material design principles to it.
