# pgai

> 标签: JavaScript

## 简介

Thin wrapper for postgresai CLI (provides `npx pgai ...` or `bunx pgai ...`)

- 官网：https://gitlab.com/postgres-ai/postgres_ai
- 源码仓库：git+https://gitlab.com/postgres-ai/postgres_ai.git
