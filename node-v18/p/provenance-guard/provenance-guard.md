# provenance-guard

> 标签: agentic-payments, algorand, guard, payments, provenance, reputation, safety, trust, wash-trading, x402

## 简介

A seatbelt for agent payments: pre-payment wash-risk check for x402 clients. Wraps any x402-paying fetch and blocks payments to endpoints whose on-chain revenue looks fabricated, via the free Provenance API.
