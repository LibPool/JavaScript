# pi-extension-subagent

> 标签: ai, coding-agent, llm, pi, pi-extension, pi-package, subagent, tmux

## 简介

pi 插件：spawn_sub 工具。把多步或上下文很重的任务委派给 tmux 里隔离运行的 pi 子 agent，交付物写到 /tmp/pi-sub-<name>/result.md。
