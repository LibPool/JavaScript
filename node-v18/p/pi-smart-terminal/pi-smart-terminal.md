# pi-smart-terminal

> 标签: bash, pi, pi-extension, pi-package, pi.dev, pty, shell, smart-terminal, terminal

## 简介

Persistent PTY terminal sessions for pi: overrides the built-in bash tool with a stateful shell, adds terminal_* tools, a live session overlay (/term) and footer status. Powered by smart-terminal-mcp.
