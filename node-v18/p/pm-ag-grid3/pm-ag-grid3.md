# pm-ag-grid3

> 标签: pm-ag-grid3表格组件, wangruichang

## 简介

`pm-ag-grid3`组件基于`ag-grid-vue`组件库二次封装，支持列表，树形列表两种形式展示表格数据 ### *props | 参数 | 说明 | 类型 | 可选值 | 默认值 | | ------ | ------ | ------ | ------ | ------ | | columnDefs | 表格列设计（详见columnDefs说明） | Array | 必须 |  |  | rowData | 表格数据 | Array | 非必须 |  |  | getRowId | 表格行标
