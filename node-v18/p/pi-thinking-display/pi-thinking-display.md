# pi-thinking-display

> 标签: fold, pi-extension, pi-package, reasoning, thinking, tui

## 简介

Thinking-block display for pi: keep only the thinking run that is still streaming expanded, plus a fold marker with hover highlight and click-to-toggle, with a settings panel.
