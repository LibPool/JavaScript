# pixelate-mcp

> 标签: claude, codex, mcp, model-context-protocol, pixel-art, pixelaoi, pixelate

## 简介

MCP server to drive the PixelAOI editor: see the canvas, paint pixel art, pixelate images locally, run editor commands, and build node-based blueprints.

## 官网

- 官网：https://pixelaoi.pro
- npm 页面：https://www.npmjs.com/package/pixelate-mcp
