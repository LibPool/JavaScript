# pi-speed-inhibitor

> 标签: coding-agent, pi, pi-extension, pi-package, speed

## 简介

pi extension that sleeps a configurable amount of milliseconds before every tool call, adjustable live via ctrl+up / ctrl+down or /speed-inhibit
