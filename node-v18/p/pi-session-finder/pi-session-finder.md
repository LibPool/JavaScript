# pi-session-finder

> 标签: find, navigation, pi, pi-extension, pi-package, pi.dev, resume, search, session

## 简介

Cross-project session search & jump for pi. Adds /find <keywords> that full-text searches every past session across all projects and switches to the match — like /resume, but driven by content search.
