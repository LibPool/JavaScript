# pindouai-mcp-server

> 标签: ai-generator, claude, cursor, mcp, mcp-server, perler-beads, pindouai, pixel-art

## 简介

An official Model Context Protocol (MCP) server for PindouAI. Generate Perler beads and pixel art patterns directly from Cursor and Claude.
