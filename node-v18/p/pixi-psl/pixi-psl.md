# pixi-psl

> 标签: glsl, pixi, pixijs, shader, tsl, webgl, webgpu, wgsl

## 简介

PSL -- a node-based shader language for PixiJS. Write once in TypeScript, run on WebGL (GLSL 300 es) and WebGPU (WGSL).
