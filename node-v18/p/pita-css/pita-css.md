# pita-css

> 标签: css, css-framework, docs, documentation, pita-css, vue

## 简介

ドキュメント型サイトに最適化されたClassレスベースのCSSフレームワークです。HTMLタグだけで見やすいデザインが完成し、必要に応じて低水準のユーティリティClassを段階的に追加できます。
