# postman-collection-url-updater

> 标签: bulk, collection, newman, postman, update, updater, url

## 简介

Postman collection url updater is a command line utility project that can update urls across multiple postman requests in your postman collection. It allows to update postman request urls in bulk inside the postman collection. it also support migrating mu
