# playwright-generator

> 标签: accessibility, e2e, negative-testing, page-object, playwright, qa, test-generator, test-intelligence, typescript

## 简介

Generate maintainable Playwright TypeScript tests from a live URL or source tree — page objects, fixtures, and happy/negative/boundary/a11y coverage.
