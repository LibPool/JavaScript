# pict-provider-progress

> 标签: eta, operation, pict, progress, retold

## 简介

Unified operation progress, event-logging and outcome reporting for the Retold ecosystem: a dependency-free core that turns a phased-operation state (Fable Operation / ProgressTracker shape) into a display model with per-phase and whole-operation percent
