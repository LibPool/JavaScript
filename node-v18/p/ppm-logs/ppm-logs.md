# ppm-logs

> 标签: clarity, cloudflare, logger, loglevel, web-worker

## 简介

Logger para proyectos front basado en loglevel: procesa en segundo plano (Web Worker), escribe directo en Cloudflare Workers Logs y marca sesiones en Microsoft Clarity

## 官网

- npm 页面：https://www.npmjs.com/package/ppm-logs

- 0.1.0

- npm registry：https://registry.npmjs.org/ppm-logs
- Node 要求：>=18
