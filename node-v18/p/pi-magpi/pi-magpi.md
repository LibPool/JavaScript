# pi-magpi

> 标签: cache, extension, fetch, markdown, pi, pi-coding-agent, pi-extension, pi-package, readability, scraping, search, web-fetch, web-search

## 简介

Token-frugal web fetch & search for pi. Smart handlers (GitHub, GitLab, package registries, Wikipedia, Stack Exchange, Reddit, HN, arXiv, PDFs, llms.txt), timestamped disk cache, extensible handler system. No API keys.
