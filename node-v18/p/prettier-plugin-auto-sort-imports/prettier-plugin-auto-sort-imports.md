# prettier-plugin-auto-sort-imports

> 标签: formatting, import-order, imports, javascript, monorepo, nestjs, next, node, nuxt, organize-imports, plugin, prettier, prettier-plugin, react, sort, sort-imports, svelte, typescript, vue

## 简介

Zero-config Prettier plugin that sorts and groups imports with blank lines between groups. Discovers your tsconfig/jsconfig path aliases automatically - no regex configuration. Works with TypeScript and JavaScript, frontend and backend.
