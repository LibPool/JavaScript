# pi-lean-host

> 标签: api, data, http, pi-extension, pi-package, rest, scraping

## 简介

Read-only REST API client for Pi. Your agent authors and calls YAML recipes handling the tedious parts: pagination, OAuth2, rate limits, backoff. Credentials live in a local store, injected in code, never in agent context. Churn-free research + retrieval
