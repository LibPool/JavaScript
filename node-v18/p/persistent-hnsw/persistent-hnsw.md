# persistent-hnsw

> 标签: ann, cosine, embedding, euclidean, hnsw, knn, nearest-neighbor, search, similarity, vector

## 简介

Pure-TypeScript HNSW vector search. No native dependencies, no WASM. Sub-millisecond search with pluggable persistence, automatic sharding, and three distance metrics.
