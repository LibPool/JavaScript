# pyramid-test-helper

> 标签: pyramid-scan

## 简介

Projeto desenvolvido para scanear o repositorios e localizar testes automatizados a fim de mapear e criar piramide de testes. Utilizando json como arquivo de configuração e regex para identificar os testes. Após encontrar os testes o mesmo se integra a Ap
