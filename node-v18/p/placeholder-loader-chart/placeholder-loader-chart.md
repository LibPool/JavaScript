# placeholder-loader-chart

> 标签: JavaScript

## 简介

A lightweight **Angular** component for showing elegant loading placeholders for charts, graphs, and visual data.   Supports **circle** (pie/donut chart) and **line** (bar/line chart) skeletons with smooth shimmer animations.
