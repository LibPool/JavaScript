# proxy-from-env

> 标签: environment, http_proxy, https_proxy, no_proxy, proxy

## 简介

Offers getProxyForUrl to get the proxy URL for a URL, respecting the *_PROXY (e.g. HTTP_PROXY) and NO_PROXY environment variables.
