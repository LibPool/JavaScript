# pi-ask-side

> 标签: coding-agent, pi, pi-extension, pi-package, side-question

## 简介

Ask the LLM token-efficient side questions in an isolated context while the main agent keeps working. Three modes: no context, last exchange (+ on-demand fetch), and deep (full session context + read-only repo tools).
