# postcss-merge-selectors

> 标签: combine-selectors, css, css-optimization, css-refactor, dedupe, deduplicate, duplicate-rules, merge-selectors, postcss, postcss-plugin, selectors, stylesheet

## 简介

PostCSS plugin to combine selectors that have duplicate rules. Can be configured to skip or only apply to specific rules.
