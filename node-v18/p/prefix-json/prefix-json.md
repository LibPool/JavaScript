# prefix-json

> 标签: config, configuration, configure, ini, json, jsonc, postfix

## 简介

除了JSON本身的特性之外，还支持这样的一些特性： * 允许为json字符串增加前缀，例如: 可以使用`D"../static"`来表示目录（*前缀可以自定义*）。 * 支持注释，支持“//”注释。 * Object类型或Array类型的最后一个元素允许以“`,`”结束。 * json中键不用加引号
