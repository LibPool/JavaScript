# pagewire

> 标签: analytics, browser, client-side, console, dom-mutations, errors, javascript, monitoring, network, performance, tracking, user-interactions, web-vitals, webhook

## 简介

Comprehensive browser monitoring script that captures everything happening in a browser tab and forwards it to a configurable webhook URL
