# pith-cli

> 标签: cli, git, pith, scaffold, workflow, 组合命令

## 简介

Git 常用组合命令脚手架：一个命令完成 add+commit+push、rebase 同步、分支管理等高频工作流，支持自定义组合命令，兼容 Node.js 14+
