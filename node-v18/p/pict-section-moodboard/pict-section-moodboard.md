# pict-section-moodboard

> 标签: JavaScript

## 简介

Free-form moodboard canvas (draggable, resizable image tiles, source-linked drawings rendered as SVG, notes, big text, and stickers, with board backgrounds and curated fonts) built on pict-section-flow
