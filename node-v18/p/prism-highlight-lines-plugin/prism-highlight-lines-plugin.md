# prism-highlight-lines-plugin

> 标签: annotation, code-highlight, diff, highlight, line-highlight, plugin, prism, prismjs, syntax, syntax-highlighting

## 简介

A Prism.js plugin for highlighting code lines with annotations - supports multiple highlight types (highlight, add, remove) with flexible range syntax
