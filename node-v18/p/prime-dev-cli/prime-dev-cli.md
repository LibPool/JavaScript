# prime-dev-cli

> 标签: JavaScript

## 简介

`prime-dev-cli` 是一个用于管理多前端项目开发环境的工具，当前包含： - CLI - 本地 Web UI - 浏览器扩展 - 通用 skill 源与 Claude Code 适配层
