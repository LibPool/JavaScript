# puid-js

> 标签: entropy, random, random ID, random string, security, token, uuid

## 简介

Simple, fast, flexible and efficient generation of probably unique identifiers (`puid`, aka random strings) of intuitively specified entropy using pre-defined or custom characters, including unicode
