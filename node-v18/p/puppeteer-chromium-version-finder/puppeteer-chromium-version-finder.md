# puppeteer-chromium-version-finder

> 标签: chromium, puppeteer, version

## 简介

Finds the version of Chromium expected by the version of Puppeteer that is in use. Puppeteer, Puppeteer-core or a package which depend on Puppeteer or Puppeteer-core must be installed. This package doesn't install them.
