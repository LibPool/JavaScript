# public-client-sdk

> 标签: anti-replay, axios, client-sdk, deds, douyin, formatter, miniprogram, router-lock, signature, storage, uni-app, websocket, wechat

## 简介

跨端前端通用微内核 SDK - 提供 DEDS 多维动态安全签名、网络拦截器、跨端排他路由锁、跨端持久化缓存、高可用 WebSocket、常用业务格式化工具等 (零 Node 依赖，极小包体，兼容 Uni-app、微信/抖音小程序、Web 与移动端 App)
