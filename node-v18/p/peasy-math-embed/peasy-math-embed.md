# peasy-math-embed

> 标签: calculator, converter, embed, graph, math, number, peasy, peasymath.com, shadow-dom, widget, zero-dependencies

## 简介

Embed PeasyMath widgets on any website. Lightweight (<8KB gzipped), zero dependencies, Shadow DOM isolation, 3 themes.

- 官网：https://widget.peasymath.com
