# pyusd-payments-sdk

> 标签: JavaScript

## 简介

Utilities for interacting with Arx HaLo–secured wallets from the browser. The SDK wraps the [`@arx-research/libhalo`](https://github.com/arx-research/libhalo) web API to perform PYUSD transfers.
