# polar-h10-web

> 标签: accelerometer, ble, bluetooth, ecg, h10, heart-rate, polar, web-bluetooth

## 简介

Library for the Polar H10 chest-strap sensor that uses Web Bluetooth - ECG, accelerometer, HR/RR and managing recorded exercises.
