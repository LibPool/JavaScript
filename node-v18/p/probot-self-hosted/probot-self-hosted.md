# probot-self-hosted

> 标签: ai, anthropic, chatbot, component, openai, probot, react, self-hosted

## 简介

Self-hosted ProBot chatbot as an npm package. Drop the <ProbotBot /> React component (or vanilla script) into any web app; configure persona, knowledge, provider, and (optionally) your ProBot dashboard token for analytics.
