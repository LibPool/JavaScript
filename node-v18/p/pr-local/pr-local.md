# pr-local

> 标签: dev-environment, git-worktree, local, local-development, monorepo, multi-repo, pr, preview, pull-request, review, run-pr

## 简介

Run an unmerged PR on your own machine in minutes: minimum stack from the diff, diff-scoped seed data, self-healing bring-up. Local, pre-merge, never a shared environment.
