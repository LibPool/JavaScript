# press-picture

> 标签: JavaScript

## 简介

-   入参     -   param = {temoFilePath:String,level:String}         +   temoFilePath:图片url         +   level:压缩级别             +   easy:   轻压缩，清晰度较高             +   mid:    中压缩，清晰度一般             +   hard:   重压缩，清晰度低 ### uniapp使用     -   需要创建一个canvas组件
