# pwa-edgejs

> 标签: JavaScript

## 简介

Edge.js: run .NET and Node.js in-process on Windows, Mac OS, and Linux. This is just an npm publish of Tomasz Janczuk great work so we can internally benefit from the latest version that compiles with Node 8. All credits goes to him.
