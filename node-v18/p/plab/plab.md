# plab

> 标签: a/b testing, a/b 테스트, abtest, bayesian, plab, skplanet

## 简介

A/B Testing Javascript SDK. A/B 테스트 시작하기 !! 두 버전의 웹 페이지/앱을 비교하여 어떤 버전이 나은지 솔루션(툴) 통계 결과를 보고 결정하는 방법입니다. 넷플릭스, 페이스북, 구글에서도 많은 테스트를 통해 UI 개선에 노력합니다. React, Angular, Vue.js, Java, Android, ES6, Javascript 등 최신 Runtime 환경에서 쉽게 진행 할 수 있습니다. 마케팅 도구로 활용해보세요
