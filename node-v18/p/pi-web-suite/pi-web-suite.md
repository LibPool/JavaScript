# pi-web-suite

> 标签: extract, fetch, pi-extension, pi-package, pi-web-suite, web-search

## 简介

Web search, URL fetching, PDF extraction, and content extraction tools for the Pi coding agent. Cascading providers: Exa, AnySearch, Tavily.
