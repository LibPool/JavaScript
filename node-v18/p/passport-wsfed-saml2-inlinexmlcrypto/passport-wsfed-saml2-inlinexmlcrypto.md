# passport-wsfed-saml2-inlinexmlcrypto

> 标签: acs, auth, authentication, authn, azure, identity, passport

## 简介

WS-federation with SAML 2 and 1.1 tokens for Passport (used on Microsoft products like Windows Azure Active Directory / Access Control Service and ADFS).
