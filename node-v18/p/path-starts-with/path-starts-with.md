# path-starts-with

> 标签: directory, file, file path, filepath, folder, fs, inside, path, posix, relative, slash, slashes, starts, startsWith, util, utility, utils, windows

## 简介

Returns true if a filepath starts with the given string. Works with windows and posix/unix paths.
