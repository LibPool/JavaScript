# preflight-cli

> 标签: Automated Testing, Browser Testing, Build, Continuous Delivery, Continuous Integration, DevOps, Integration Testing, Quality Assurance, Release, UI Testing

## 简介

PreFlight is a code-free automated UI testing tool. This package allows you to run your PreFlight tests.
