# pi-banana

> 标签: ai-image, gemini, gemini-api, google, image-editing, image-generation, imagen, nano-banana, nano-banana-2, nano-banana-pro, pi, pi-coding-agent, pi-extension, pi-package, terminal

## 简介

Generate, edit, and analyze images in pi using Google Nano Banana (image gen) and Gemini Vision (analysis). Inline terminal preview, reference-image editing, auto-save.
