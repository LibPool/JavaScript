# pi-browser-actions

> 标签: automation, browser, pi, pi-package, playwright, web-fetch, web-search

## 简介

Stateful Playwright browser automation for Pi with headed or headless launch, browser attachment, web search, exact URL fetching, rendering, and Markdown extraction.
