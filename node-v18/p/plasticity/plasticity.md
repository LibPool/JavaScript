# plasticity

> 标签: dashboard, layout, react, react-component, reactjs

## 简介

A reactjs dashboard component.  It provides varying layouts and the ability to plugin react components dynamically.  Provides all components with the ability to  minimize, maximize, close, go fullscreen...
