# psm-cost-per-project

> 标签: analytics, cost, pi, pi-session-manager, plugin, psm, spend, tokens

## 简介

Pi Session Manager plugin: total AI spend broken down by project (working directory), with session/token counts, per-model cost splits, and estimated cost for unpriced models.
