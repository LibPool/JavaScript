# pi-imagefiles

> 标签: deepseek, files-api, image, pi, pi-package, vision

## 简介

DeepSeek vision image offload for pi: Files API file_id references on the official gateway (deepseek-v4-flash-vision-exp), offload trimming on third-party gateways — kills the 50 MB 413 ceiling.
