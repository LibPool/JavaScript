# phnodelayer

> 标签: AWS Lambda, Fortune, JSONAPI, TypeScript

## 简介

*简化前端逻辑层的使用方式，屏蔽底层接口与逻辑，只需要配置MODEL即可实现接口协议为JSONAPI功能*
