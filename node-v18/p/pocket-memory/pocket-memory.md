# pocket-memory

> 标签: agent-skill, ai, claude-code, codex, cursor, grok, image-editing, memory, photography

## 简介

Turn one real photo into a cinematic four-frame memory sequence through source-faithful reframing, visual paths, and a quiet handwritten subtitle—giving a captured instant room to become felt time.
