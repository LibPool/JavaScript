# postcss-any-hover

> 标签: any-hover, css, hover, postcss, postcss-any-hover, postcss-plugin

## 简介

A PostCSS plugin that wraps `:hover` selectors with `@media (any-hover: hover) {}` to ensure hover effects only apply on hoverable devices
