# poketokenbar-sync

> 标签: opencode, pi-extension, pi-package, pokemon, poketokenbar, token-usage

## 简介

Pi coding agent extension that syncs your pi token usage into PokeTokenBar's OpenCode data path (legacy storage/message JSON).
