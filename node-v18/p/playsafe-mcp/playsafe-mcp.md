# playsafe-mcp

> 标签: JavaScript

## 简介

When using AI agents to explore websites, there is no guarantee that they won't interact with unsafe elements. Playsafe allows sensitive or dangerous elements to be masked from the agent so that they don't know they exist and aren't able to interact with
