# pkg-to-dist

> 标签: JavaScript

## 简介

Simple library that moves package.json to dist folder and changes exports. Use to publish a library in a dist folder ```sh npm i --save-dev pkg-to-dist ``` ```sh npm run build && pkg-to-dist && cd dist && npm publish ```
