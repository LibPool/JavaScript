# puppeteer-extra-plugin-recaptcha-advanced

> 标签: 2captcha, captcha, hcaptcha, puppeteer, puppeteer-extra, puppeteer-extra-plugin, recaptcha

## 简介

A puppeteer-extra plugin to solve reCAPTCHAs and hCaptchas automatically. This version has support for proxies.
