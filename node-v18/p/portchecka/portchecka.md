# portchecka

> 标签: dashboard, lsof, macos, network, ports, process

## 简介

Dashboard: alle Ports sehen, was läuft, seit wann – Suche, Kill, Fixieren. npx portchecka startet das Tool, npx portchecka install installiert es global.

## 官网

- npm 页面：https://www.npmjs.com/package/portchecka

- 当前版本：1.0.1

- 1.0.1

## 获取地址

- npm 安装：`npm install portchecka`
- npm registry：https://registry.npmjs.org/portchecka
- Node 要求：>=18
