# promptcraft-unificando

> 标签: cli, llm, prompt-engineering, unificando

## 简介

Refina prompts em 1 passo: monta o prompt de engenharia a partir de texto cru e delega a execução a um CLI de LLM local (claude/gemini), com opção --raw para o meta-prompt bruto agnóstico de LLM.
