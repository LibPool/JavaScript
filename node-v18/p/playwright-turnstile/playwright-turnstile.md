# playwright-turnstile

> 标签: browser-automation, captcha, ci, cloudflare, cloudflare-turnstile, e2e-testing, playwright, playwright-fixtures, qa-automation, synthetic-monitoring, test-automation, testing, turnstile, typescript

## 简介

Playwright helper for Cloudflare Turnstile — find the widget, read its sitekey, wait for or inject a token, and run suites against Cloudflare's official test sitekeys.
