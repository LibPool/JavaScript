# plantkit-mcp

> 标签: claude, garden, mcp, modelcontextprotocol, plantkit, recipes, travel

## 简介

MCP server for PlantKit — recipes, trips & notes, shopping lists, meal calendar, gardens, wine, coffee, inventory. Wraps the hosted PlantKit API; auth via PLANTKIT_TOKEN.
