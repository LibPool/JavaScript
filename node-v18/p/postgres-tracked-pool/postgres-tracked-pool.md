# postgres-tracked-pool

> 标签: database, debugging, monitoring, observability, pg, pool, postgres, postgresql, query, sql, tracking

## 简介

A PostgreSQL connection pool wrapper that automatically adds tracking comments to SQL queries with function name, file path, and line number
