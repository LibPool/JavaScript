# parity-studio-mcp

> 标签: anthropic, claude-code, codex, cursor, decompose, design-to-code, mcp, model-context-protocol, openai, parity, ui-generation, ui-kit

## 简介

MCP server for Parity Studio. Lets coding agents capture existing app routes, decompose them into ui_kit/ bundles, and import them for iteration.
