# peepshow

> 标签: ai, animated-webp, apng, claude-code, claude-code-plugin, ffmpeg, frames, gif, llm, notion, obsidian, postgres, s3, scene-detection, sinks, slides, sqlite, video, webhook

## 简介

Turn videos + animated images (GIF/APNG/WebP) + HLS/DASH/RTSP live streams into a timeline of still frames + audio transcript + a self-contained HTML report so LLMs can 'watch', 'listen', and write their analysis back. Auto-detects embedded subtitles, cha
