# prisma-nestjs-automachine

> 标签: cli, code-generator, crud, dto, generator, nestjs, prisma, scaffold

## 简介

CLI tool to generate NestJS CRUD boilerplate (module, controller, service, DTOs) from Prisma schema models

## 官网

- npm 页面：https://www.npmjs.com/package/prisma-nestjs-automachine

- 1.0.0

## 获取地址

- npm 安装：`npm install prisma-nestjs-automachine`
- npm registry：https://registry.npmjs.org/prisma-nestjs-automachine
- Node 要求：>=16.0.0
