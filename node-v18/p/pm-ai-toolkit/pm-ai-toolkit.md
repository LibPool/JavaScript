# pm-ai-toolkit

> 标签: architecture, brainstorming, brd, changelog, cursor, cursor-plugin, diagrams, email, eml, exit-criteria, features, figma, fsd, prd, product-management, requirements, scope-analysis, tasks, test-cases, user-stories, versioning

## 简介

A Cursor plugin for Product Managers: transform FSD, BRD, PRD, Figma designs, images, and email (.eml) into features, user stories, tasks, test cases, exit criteria, and architecture diagrams with version tracking and scope analysis
