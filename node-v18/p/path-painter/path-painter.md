# path-painter

> 标签: api, app, express, framework, http, rest, restful, router, web

## 简介

A dynamic and intuitive library for Node.js, enabling developers to 'paint' their application's routes effortlessly. Leveraging the power of decorators, it transforms controller definitions into beautifully crafted, easy-to-manage routes (ChatGPT). <br
