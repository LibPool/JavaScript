# pythonlib

> 标签: collections, combinations, counter, datetime, defaultdict, deque, enumerate, functools, itertools, lru-cache, permutations, python, range, regex, stdlib, typescript, zip

## 简介

Python standard library for TypeScript - itertools, functools, collections, datetime, re, and more. Zero dependencies. Full TypeScript support.
