# pi-interactive-lite

> 标签: coding-agents, interactive, pi-extension, pi-package, pi-skill, pty, tmux, user-input

## 简介

Lightweight interactive-shell alternative for pi: drive terminal programs (agent CLIs, auth flows, anything needing a PTY) through tmux via plain bash, plus a minimal user_input tool to prompt the user for free-form answers. ~150 tokens/round instead of ~
