# pi-bot-connect

> 标签: bot, bridge, discord, pi, pi-extension, pi-package, remote-control

## 简介

Bridge a live pi coding session to Discord: share current work as a digest and keep going from chat. Text and image prompts, one progress card per turn, no bot SDK dependencies.
