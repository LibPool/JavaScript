# pi-inline-marker

> 标签: extension, marker, pi, pi-coding-agent, pi-package, todo

## 简介

通用内联标记工具包 —— 让 LLM 在回答正文里写 [[tool:op:...]] 标记来驱动纯状态工具（todo、通知等），免除工具调用往返。
