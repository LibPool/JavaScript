# pixi-vania

> 标签: 2d, ldtk, level-editor, pixi, pixijs, rapier, tiled, tilemap

## 简介

Tilemap level editor and .svlevel runtime for PixiJS v8 + Rapier2D. Auto-tiling, collision layers, entity types, localization.
