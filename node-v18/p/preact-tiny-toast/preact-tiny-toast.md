# preact-tiny-toast

> 标签: preact, preact-notifications, preact-tiny-toast, preact-toast-notifications, toast-notifications

## 简介

This is a fork of [react-tiny-toast](https://github.com/ashr81/react-tiny-toast/tree/master/packages/react-tiny-toast), which has been rewritten for preact. This means there are no React dependencies anymore and can therefore be included in preact project
