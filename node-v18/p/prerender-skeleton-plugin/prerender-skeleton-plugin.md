# prerender-skeleton-plugin

> 标签: prerender, serverside-rendering, spa, ssr

## 简介

本插件从预渲染插件`prerender-spa-plugin`改写而来，其中骨架屏的实现主要是参考网易考拉的骨架屏实现方式`awesome-skeleton`。 取两者之精华，并且修复了一些bug并且增加了一些功能。
