# pairbook-mcp

> 标签: ai, beta, claude, correlation, diversification, etf, finance, mcp, mcp-server, modelcontextprotocol, portfolio, portfolio-analysis, portfolio-overlap, risk, stocks

## 简介

MCP server and CLI for PairBook: whole-portfolio risk analysis (Euler risk contributions, diversification ratio, ETF-overlap warnings between held funds), plus pair correlation, holdings overlap, beta and volatility for 4,700+ US stocks and ETFs. Free, no
