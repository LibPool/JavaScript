# prima-scholar-search-mcp

> 标签: academic, arxiv, claude, cowork, crossref, mcp, prima, pubmed, research, semantic-scholar

## 简介

MCP server for academic literature search across 10 databases — PubMed, arXiv, Semantic Scholar, CrossRef, OpenAlex, Europe PMC, DBLP, ERIC, bioRxiv, CORE. Search wizard with discipline detection and open-access filtering.
