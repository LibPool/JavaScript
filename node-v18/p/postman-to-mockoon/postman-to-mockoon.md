# postman-to-mockoon

> 标签: JavaScript

## 简介

This repository provides a CLI tool for converting Postman collections (only v2 at the moment) to files that can be imported into Mockoon.

## 官网

- npm 页面：https://www.npmjs.com/package/postman-to-mockoon

## 历史版本号

- 当前版本：1.0.0

- 1.0.0

## 获取地址

- npm 安装：`npm install postman-to-mockoon`
- npm registry：https://registry.npmjs.org/postman-to-mockoon
