# pi-sliding-context-window

> 标签: bm25, coding-agent, context-window, conversation-history, llm, mcp, pi, pi-package, retrieval, rocksdb, semantic-search

## 简介

A sliding context window for Pi coding agents. When a chat gets long, old messages are saved to a small local database instead of being dropped — so your agent can search them and pull the exact one back whenever it needs it.
