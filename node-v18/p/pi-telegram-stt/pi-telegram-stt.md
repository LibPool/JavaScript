# pi-telegram-stt

> 标签: JavaScript

## 简介

STT orchestrator + bundled OpenAI-compatible STT provider for the Pi coding agent + @llblab/pi-telegram bridge. Wraps the inbound voice/audio pipeline (downloads voice notes, runs STT via the in-package OpenAI client, sends a 🎙️ echo to the user, and fee
