# picgo-plugin-squeeze

> 标签: compress, compression, crash, optimization, picgo, picgo-gui-plugin, picgo-plugin, sharp, squeeze

## 简介

基于 sharp、TinyPNG 和色彩笔的 PicGo 图片压缩插件，支持本地压缩、在线压缩和自定义压缩规则
