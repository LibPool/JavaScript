# presentations-mcp

> 标签: ai, mcp, model-context-protocol, powerpoint, pptx, pptxgenjs, presentation, slides

## 简介

MCP server for creating PowerPoint presentations programmatically. Provides tools to create, edit, and save .pptx files via the Model Context Protocol.
