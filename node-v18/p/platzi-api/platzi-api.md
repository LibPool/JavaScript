# platzi-api

> 标签: JavaScript

## 简介

pequeña api que permite obtener los datos de los cursos aprobados de cualquier estudiante en Platzi, esto con el fin de poder ser utilizados en un portafolio web profesional (el perfil de estudiante debe ser publico)
