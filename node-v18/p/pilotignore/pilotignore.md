# pilotignore

> 标签: agent, copilot, copilot-hooks, copilotignore, firewall, github, hook, ignore, pre-tool-use, security

## 简介

Prevent Copilot from reading your secrets using .pilotignore. Works like .gitignore but for GitHub Copilot.
