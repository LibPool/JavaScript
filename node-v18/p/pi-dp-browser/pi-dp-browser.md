# pi-dp-browser

> 标签: automation, browser, drissionpage, pi, pi-coding-agent, pi-package, skill

## 简介

DrissionPage-based persistent browser control skill for pi: open/switch tabs, click, input, select, press keys, scroll, run JS, screenshot, and take human-visible page snapshots (links/buttons/inputs/selects/text/headings/images, no CSS/JS internals). Bro
