# pi-skill-chrome-cdp-auto

> 标签: cdp, chrome-cdp, devtools, pi, pi-package, pi-skill, skill

## 简介

Pi skill package for chrome-cdp with auto-launch: zero-config browser debugging that starts a dedicated Chrome instance when no CDP endpoint is found.
