# peasy-tools-embed

> 标签: compress, convert, developer, embed, file, peasy, peasytools.com, shadow-dom, tools, utility, widget, zero-dependencies

## 简介

Embed PeasyTools widgets on any website. Lightweight (<8KB gzipped), zero dependencies, Shadow DOM isolation, 3 themes.
