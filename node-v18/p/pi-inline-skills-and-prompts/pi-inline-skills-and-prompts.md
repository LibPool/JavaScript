# pi-inline-skills-and-prompts

> 标签: autocomplete, pi-extension, pi-package, prompts, skills

## 简介

Inline $skills and $prompts autocompletion in pi: type $ inside a message to fuzzy-complete and insert a skill/prompt command without leaving the current line.
