# pi-output-classifier

> 标签: coding-agent, output-rules, pi, pi-extension, tldr

## 简介

Pi extension that classifies every final assistant reply against markdown output rules and asks the model to rewrite violations. Ships with an ASD-STE100 Simplified Technical English + TLDR rule.
