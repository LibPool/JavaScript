# palschema-validate

> 标签: ajv, json-schema, migrate, modding, palschema, palworld, ue4ss, validate, version-diff

## 简介

Validate Palworld PalSchema mod JSON/JSONC files against the palschema-hub schema registry, and scan them for fields removed/renamed between game versions (--migrate).
