# pi-vision

> 标签: accessibility, clipboard, extension, handoff, image, model-selector, multimodal, paste, pi, pi-coding-agent, pi-package, vision

## 简介

Give text-only pi models vision — describe images with a vision model you pick via an interactive picker, then hand off the text description to non-vision models. Includes direct clipboard paste (image-paste integration).
