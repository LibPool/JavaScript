# postalcodes-india

> 标签: address, browser, code, find, find city by postalcode, find county by postalcode, find geo by postalcode, find state by postalcode, geo, india, isomorphic, location, lookup, pin, pincode, postal, postalcode, universal, zip, zipcode

## 简介

Fast and lightweight Indian postal code (PIN) lookup library with hierarchical location data - states, districts, sub-districts, and coordinates. Zero dependencies and full TypeScript support.
