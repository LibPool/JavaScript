# postcss-transform-unit

> 标签: css, pixel, postcss, postcss-plugin, px, rpm, unit

## 简介

A CSS post-processor that converts rem to rpx. 允许指定转换xxx单位为xxx，并允许指定任意单位及其转换函数，支持指定黑名单prop 改自插件{postcss-pxtorpx-pro}
