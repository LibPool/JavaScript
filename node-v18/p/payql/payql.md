# payql

> 标签: agents, ai, base, graphql, mcp, model-context-protocol, onchain, payments, subgraph, thegraph, usdc, x402

## 简介

MCP server that discovers and queries The Graph's subgraphs, paying per query in USDC over x402 — gasless, keyless, bring-your-own-wallet. Lets any AI agent get live on-chain data on demand.
