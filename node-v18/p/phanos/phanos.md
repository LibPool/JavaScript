# phanos

> 标签: load, load-test, performance, site crawler, spider, stress, stress-logs, stress-test, stresslogs, stresstest, test

## 简介

Simple human like stress test tool.
This tools doesn't provide any stat info, or special logging functionality.
 This tool just walking on yours site as true user.
