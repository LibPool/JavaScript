# pythscribe

> 标签: aot, compiler, edge, python, pythscribe, react, transpiler, wasm

## 简介

PythScribe — Python for the browser and the edge, compiled. The pyths AOT compiler CLI (provides the `pyths` command), distributed as a prebuilt native binary.
