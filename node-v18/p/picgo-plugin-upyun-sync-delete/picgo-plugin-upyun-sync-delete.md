# picgo-plugin-upyun-sync-delete

> 标签: album, gallery, picgo, picgo-gui-plugin, picgo-plugin, sync-delete, upyun, 删除, 又拍云, 相册

## 简介

Sync-delete UpYun (又拍云) files when removing images from PicGo album. 在 PicGo 相册删除图片时同步删除又拍云云端文件。
