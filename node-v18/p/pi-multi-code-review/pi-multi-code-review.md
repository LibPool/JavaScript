# pi-multi-code-review

> 标签: code-review, ocr, oracle, parallel-review, pi-package, pi-skill, spec, standards

## 简介

Pi skill + subagent: three parallel code-review channels (OCR / Standards / Spec) reviewing the same diff bound under one scope, then an oracle deduplicates, resolves conflicts and re-grades them into a single adjudicated report (00-adjudication.md). Pure
