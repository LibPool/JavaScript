# prima-scholar-library-mcp

> 标签: claude, cowork, docx, fts5, library, mcp, pdf, prima, research, sqlite

## 简介

MCP server for a local research library with SQLite FTS5 full-text search. Imports PDFs and Word documents, tags, organises, and searches across your private corpus.
