# pptx-thumbnailer

> 标签: libreoffice, microservice, png, powerpoint, pptx, preview, slides, thumbnail

## 简介

Slide thumbnails (PNG/JPEG) from PowerPoint .pptx files via headless LibreOffice — usable as a library, CLI or tiny HTTP microservice (Docker).
