# pursr

> 标签: accessibility, audit, axe-core, baseline, devtools, diff, har, mcp, model-context-protocol, playwright, pursr, screenshot, testing, visual-qa, visual-regression

## 简介

pursr — Visual QA, audit, and MCP for the browser. One CLI + one MCP server for screenshots, sweeps, baselines, diffs, axe-core a11y audits, HAR capture, and auth state — with parallel sweep workers, auto-healing selectors, and a plugin system. Zero brows
