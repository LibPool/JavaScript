# preview-pm

> 标签: JavaScript

## 简介

This is a simple preview component, can be applied to PC and mobile terminal, can preview video, pictures, document files (need to preview the file address, can not use the download file address), and simple word preview.

## 官网

- npm 页面：https://www.npmjs.com/package/preview-pm
