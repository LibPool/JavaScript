# push-state-tree

> 标签: Lazy Load, MVC, SPA, Single Page Application, URI, app, apps, controller, dispatch, event, events, hashchange, history, location, navigation, navigator, pushstate, route, router, routes, routing, shim, url

## 简介

A standalone powerful library to manage browser routing with nested level support, complex match expressions and on-fly rules change (convenient to lazy module loading).
