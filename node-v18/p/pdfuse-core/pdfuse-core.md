# pdfuse-core

> 标签: browser, canvas, client-side, combine-pdf, file, javascript, merge, pages, pdf, pdf-lib, pdf-merge, pdfjs, pdfjs-dist, pdfuse, preview, render, thumbnail, typescript

## 简介

Browser PDF toolkit: load, merge selected pages, and render previews to canvas. Built on pdf-lib and pdfjs-dist. TypeScript, ESM & CJS.
