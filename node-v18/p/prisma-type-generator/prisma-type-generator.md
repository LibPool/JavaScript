> 标签: dto, interface, monorepo, prisma, prisma-types, prisma.d.ts, schema-generator, type-guards, types, typescript, utility-types, zod

## 简介

Prisma type generator for generating types from Prisma schema, with support for JSON type mapping and split by schema and many more.
