# paidwithtab

> 标签: agents, api-monetization, claude, http-402, mandates, mcp, mcp-server, micropayments, payments, robinhood-chain, usdg, x402

## 简介

Give your agents spending power. tab prices any HTTP API in a JSON spec and gets it paid per request over HTTP 402, spending capped by signed mandates, settled in USDG on Robinhood Chain. Zero runtime dependencies.
