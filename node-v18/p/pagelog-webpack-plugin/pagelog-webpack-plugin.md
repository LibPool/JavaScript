# pagelog-webpack-plugin

> 标签: console, node, pagelog, plugin, webpack

## 简介

将内容打印到指定浏览器页面，方便展开阅览打印内容。

- npm 页面：https://www.npmjs.com/package/pagelog-webpack-plugin
