# pmpt-eject

> 标签: deprecation, migration, openai, prompt-management, prompts, responses-api

## 简介

Rescue your OpenAI reusable prompt objects before v1/prompts shuts down on 2026-11-30, then keep hot-fixing prompts with no redeploy. Zero dependencies.
