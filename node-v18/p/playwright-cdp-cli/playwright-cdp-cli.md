# playwright-cdp-cli

> 标签: automation, browser-automation, cdp, chrome-devtools-protocol, cli, playwright, puppeteer, selenium, uc-mode, undetected-chrome

## 简介

CLI tool to control Playwright browsers via Chrome DevTools Protocol (CDP). Connect to existing Chrome instances with UC mode support.
