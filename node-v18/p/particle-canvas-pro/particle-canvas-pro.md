# particle-canvas-pro

> 标签: animation, canvas, fps, particle, particle-system, requestanimationframe, 全屏背景动画, 动画, 可配置粒子, 粒子动画, 粒子系统, 高性能粒子

## 简介

🚀 🚀 一款基于requestAnimationFrame的高性能Canvas粒子系统，专为 Web 场景提供流畅、可配置的视觉动效方案，支持全屏背景与独立画布，提供实时控制、丰富视觉效果与流畅交互体验。
