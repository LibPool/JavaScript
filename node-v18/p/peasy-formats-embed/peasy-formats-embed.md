# peasy-formats-embed

> 标签: comparison, embed, extension, file-format, format, formats, peasy, peasyformats.com, shadow-dom, specification, widget, zero-dependencies

## 简介

Embed PeasyFormats widgets on any website. Lightweight (<8KB gzipped), zero dependencies, Shadow DOM isolation, 3 themes.
