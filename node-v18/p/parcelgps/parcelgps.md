# parcelgps

> 标签: cadastral, cadastre, europe, geojson, gis, land-registry, parcel, parcel-api, real-estate, sdk

## 简介

Parcel GPS: cadastral parcels in 29 European countries by reference, coordinates or Spanish address (official client, same as catastrogps)

- 官网：https://www.parcelgps.com/developers

- npm registry：https://registry.npmjs.org/parcelgps
