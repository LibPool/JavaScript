# peasy-css-embed

> 标签: color, css, embed, format, minify, peasy, peasycss.com, preview, shadow-dom, stylesheet, widget, zero-dependencies

## 简介

Embed PeasyCSS widgets on any website. Lightweight (<8KB gzipped), zero dependencies, Shadow DOM isolation, 3 themes.

- 官网：https://widget.peasycss.com
