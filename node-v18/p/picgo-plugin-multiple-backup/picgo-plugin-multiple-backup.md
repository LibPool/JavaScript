# picgo-plugin-multiple-backup

> 标签: backup-upload, image-backup, image-hosting, multi-uploader, multiple-backup, picgo, picgo-plugin

## 简介

PicGo插件：多图床备份上传，在主图床上传成功后自动备份到其他存储服务，确保图片链接路径一致
