# prefix-enum

> 标签: camelcase, category, enum, keyword, mapping, normalize, prefix, snake-case, type-safe, typescript

## 简介

카테고리별로 prefix를 붙여 고유한 enum 키를 생성하고 관리하는 TypeScript 라이브러리. 포맷 불일치와 중복 값 충돌 문제를 해결합니다.
