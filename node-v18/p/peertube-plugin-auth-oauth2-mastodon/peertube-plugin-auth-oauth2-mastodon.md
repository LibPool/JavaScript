# peertube-plugin-auth-oauth2-mastodon

> 标签: auth, mastodon, oauth2, peertube, plugin

## 简介

A PeerTube server plugin that adds support for external authentication via a Mastodon OAuth 2.0 provider. The callback URL path is /plugins/auth-oauth2-mastodon/router/callback
