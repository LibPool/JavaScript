# pinex

> 标签: JavaScript

## 简介

A typesafe interface for creating vuex modules, inspired by [pinia](https://github.com/posva/pinia)/[Vuex 5 RFC](https://github.com/kiaking/rfcs/blob/vuex-5/active-rfcs/0000-vuex-5.md), with some extras.
