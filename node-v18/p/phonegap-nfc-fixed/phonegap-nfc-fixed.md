# phonegap-nfc-fixed

> 标签: cordova, cordova-android, cordova-blackberry10, cordova-ios, cordova-windows, cordova-wp8, ecosystem:cordova, ndef, nfc

## 简介

Fix for phonegap Field Communication (NFC) Plugin. Read and write NDEF messages to NFC tags and share NDEF messages with peers.
