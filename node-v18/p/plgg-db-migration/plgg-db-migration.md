# plgg-db-migration

> 标签: JavaScript

## 简介

Minimal, dependency-free schema-migration tool — dbmate-style single-file up/down, a schema_migrations ledger, and on-demand per-tenant SQLite — built from scratch on plgg + plgg-sql
