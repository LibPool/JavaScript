# pdf-poppler-binaries-aws-2

> 标签: amazon-linux-2, aws, binaries, lambda, pdf, pdf2image, poppler, serverless

## 简介

Poppler binaries for AWS Lambda (Amazon Linux 2). Compatible with GLIBC 2.26. Includes Xvfb for headless PDF rendering.
