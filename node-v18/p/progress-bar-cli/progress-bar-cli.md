# progress-bar-cli

> 标签: alert, bar, cli, console, javascript, job, js, loop, monitor, node, nodejs, notification, process, progress, progressbar, sound, stdout, task, tracking

## 简介

A CLI ProgressBar for nodeJS and JS to monitor any long running job/process in a loop and alert the user with sound notification when the task ends.
