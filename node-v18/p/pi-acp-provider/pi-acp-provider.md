# pi-acp-provider

> 标签: acp, agent-client-protocol, pi, pi-extension, pi-package

## 简介

Pi agent provider extension that delegates execution to any Agent Client Protocol (ACP) agent, such as GitHub Copilot CLI or Gemini CLI.
