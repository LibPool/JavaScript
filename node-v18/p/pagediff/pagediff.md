# pagediff

> 标签: canvas, cli, phantomjs

## 简介

Node based cli tool using PhantomJS to take screenshots of a webpage and compare it to a previous version

## 官网

- 官网：https://github.com/TateMedia/pagediff
- 源码仓库：git@github.com:TateMedia/pagediff.git
- npm 页面：https://www.npmjs.com/package/pagediff

## 历史版本号

- 当前版本：0.1.0

- 0.1.0
- 0.3.1

## 获取地址

- npm 安装：`npm install pagediff`
- npm registry：https://registry.npmjs.org/pagediff
- Node 要求：>=0.10
