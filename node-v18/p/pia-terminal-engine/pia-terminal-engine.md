# pia-terminal-engine

> 标签: command-line, esm, repl, shell, terminal, typescript, web-terminal

## 简介

The reusable terminal/shell engine behind PIA — command registry, pipe/sequence parsing, filename globbing, a full-screen screen-app host, and a DOM renderer. Zero runtime dependencies, ESM, TypeScript types.
