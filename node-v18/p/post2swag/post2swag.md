# post2swag

> 标签: JavaScript

## 简介

CLI tool to convert Postman collection to swagger (OpenAPI) by providing Postman API key, collection Id and output swagger into file or std-out.

## 官网

- npm 页面：https://www.npmjs.com/package/post2swag
