# polyops-linux-x64-gnu

> 标签: boolean, clipping, geojson, geometry, intersection, martinez, napi-rs, native, polygon, union, xor

## 简介

Fast Martinez-Rueda polygon Boolean operations (intersection, union, difference, xor) for Node.js — Rust under the hood. Drop-in replacement for martinez-polygon-clipping.
