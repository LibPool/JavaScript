# prisma-no-offset

> 标签: cursor based pagination, infinite scroll, keyset pagination, no offset, no offset paging, no-offset, no-offset paging, pagination optimization, pagination without offset, paging, prisma, query optimization

## 简介

This package is a lightweight utility package that helps you conveniently use no-offset paging when using prisma orm.
