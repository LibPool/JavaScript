# picchat-mcp

> 标签: claude, mcp, model-context-protocol, picchat, whatsapp

## 简介

Servidor MCP oficial da PicChat — expõe envio de WhatsApp, webhooks, templates, entregas e saldo da conta INFRA como tools para o Claude.
