# postcss-rpx2vw

> 标签: css, plugin, postcss, postcss-plugin, rpx, vite, vmax, vmin, vw, webpack

## 简介

基于 postcss 实现的一个 css 单位转换插件（支持自定义单位），可以使用 rpx 作为单位书写
