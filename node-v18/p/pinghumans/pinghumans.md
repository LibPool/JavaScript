# pinghumans

> 标签: agent, clone, css, devtools, diff, pixel-perfect, visual-regression, workflow

## 简介

PingHumans: human-in-the-loop review for AI-built web pages. Install the MCP server, clone sites pixel-perfect with the enforced ppk pipeline, or point your agent at any draft and say "fix it with ppk".
