# print-it-now

> 标签: bitmap, bun, cups, headless, linux, macos, napi, node-api, pdf, pdfium, print, printer, printing, silent, windows, winspool

## 简介

Headless PDF and bitmap printing for Node.js and Bun on Windows, macOS and Linux. PDFium + winspool on Windows, CUPS everywhere else.
