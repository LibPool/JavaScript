# postcss-adapt-datav

> 标签: adapt, hpx, postcss, postcss-plugin, px, transfrom, vh, vw

## 简介

it`s a plugin of postcss, it can transform that the size of your code like wpx or px or hpx to vw or vh for adapt screen
