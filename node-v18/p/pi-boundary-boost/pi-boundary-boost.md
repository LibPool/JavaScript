# pi-boundary-boost

> 标签: autocomplete, file-completion, pi, pi-coding-agent, pi-extension, pi-package

## 简介

Rank direct directory children first in pi's @ file completion — @dir/prefix reads the directory directly and merges fd fuzzy results after, so deep matches never crowd out the obvious hit
