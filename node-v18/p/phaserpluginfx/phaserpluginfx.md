# phaserpluginfx

> 标签: JavaScript

## 简介

Una libreria di effetti visuali (FX) modulare, estensibile e performante per **Phaser 3**, progettata per aggiungere micro-interazioni dinamiche a qualsiasi GameObject (Sprite, Image, Testi, Forme geometriche).
