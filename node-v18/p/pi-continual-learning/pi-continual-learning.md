# pi-continual-learning

> 标签: consolidation, continual-learning, guardrails, memory, pi-package, policy

## 简介

Continual learning for Pi at the harness and prompt surfaces — declarative tool-call guardrails plus memory retrieval, injection, and consolidation. Model weights are out of scope.
