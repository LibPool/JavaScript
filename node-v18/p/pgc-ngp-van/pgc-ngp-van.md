# pgc-ngp-van

> 标签: JavaScript

## 简介

A [`pg-compose`](https://github.com/politics-rewired/pg-compose) package for integrating with [NGP VAN](https://www.ngpvan.com/). Currently only mirroring saved lists and fetching them is implemented.
