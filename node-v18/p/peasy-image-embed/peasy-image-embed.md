# peasy-image-embed

> 标签: compress, convert, embed, image, jpg, peasy, peasyimage.com, png, resize, shadow-dom, webp, widget, zero-dependencies

## 简介

Embed PeasyImage widgets on any website. Lightweight (<8KB gzipped), zero dependencies, Shadow DOM isolation, 3 themes.
