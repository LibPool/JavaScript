# pi-lmstudio-evict

> 标签: gpu, llm, lm-studio, lmstudio, local-llm, local-models, model-loading, model-management, model-switch, pi, pi-coding-agent, pi-extension, pi-package, prewarm, vram

## 简介

Pi extension for LM Studio: on /model switch it unloads the old model and preloads the new one, so only one model holds your VRAM. Reloads models evicted by idle TTL, covers what Auto-Evict misses, and keeps models.json in sync.
