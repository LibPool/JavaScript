# paperese

> 标签: JavaScript

## 简介

Markdown → LaTeX assembler for academic papers. Built on [markdsl](https://github.com/EvolvingPrograms/markdsl) (front-matter, schema/values, marker grammar) plus a system `pandoc` for the AST → LaTeX heavy lifting. The goal: a markdown source ~half the s
