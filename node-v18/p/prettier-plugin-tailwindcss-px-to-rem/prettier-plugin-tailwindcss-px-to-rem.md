# prettier-plugin-tailwindcss-px-to-rem

> 标签: Arbitrary values, PX to REM, Prettier plugin, Tailwind CSS

## 简介

A Prettier plugin that converts pixel (px) values to rem units in Tailwind CSS classes with arbitrary values, ensuring scalable and responsive design.
