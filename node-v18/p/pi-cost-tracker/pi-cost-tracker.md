# pi-cost-tracker

> 标签: coding-agent, cost-tracking, llm, pi, pi-coding-agent, pi-extension, pi-package, token-usage

## 简介

Token & cost accounting extension for pi coding agent: per-turn attribution, per-model breakdown, cache efficiency, budget alerts, and a cross-session cost ledger.
