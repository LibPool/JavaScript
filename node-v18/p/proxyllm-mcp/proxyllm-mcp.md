# proxyllm-mcp

> 标签: agent, codex, http-402, llm-gateway, mcp, modelcontextprotocol, openai-compatible, proxyllm

## 简介

MCP server for ProxyLLM, the OpenAI-compatible LLM gateway. Model catalog, plan-savings calculator, routing-key introspection and provisioning, and autonomous email-OTP account signup.
