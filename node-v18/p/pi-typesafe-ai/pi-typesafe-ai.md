# pi-typesafe-ai

> 标签: jev, pi-coding-agent, pi-extension, pi-package, system-one, typesafe

## 简介

Generic TypeSafe (Jev / System One) capability for the pi coding agent: agent-owned credential storage, a thin SDK client, and a question-bundle helper.
