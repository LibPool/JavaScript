# pi-telegram-tts

> 标签: JavaScript

## 简介

TTS synthesis provider for the Pi coding agent + @llblab/pi-telegram bridge. Registers a synthesis provider against the bridge's public voice API so getVoicePromptContribution works. Direct `fetch` to the configured provider (MiniMax or OpenAI) — no bundl
