# public-data-br

> 标签: bovespa, brazil, cvm, data, public

## 简介

Este módulo contém métodos para extração de dados de fontes públicas do Brasil. É uma iniciativa própria de consolidar os produtores de dados em uma única biblioteca node.js para ser utilizada em sistemas de mineração de dados.
