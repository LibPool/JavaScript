# propellerkit-datetimepicker

> 标签: bootstrap, calendar, css, datepicker, datetimepicker, framework, front-end, js, material design, moment, propellerkit, scss, timepicker

## 简介

Propeller’s datetimepicker component allows user to select a date from a calendar and time from a visual analog clock; it also accepts values via direct input. We have used Bootstraps’ datetimepicker and applied material design principles to it.
