# pi-cavallo

> 标签: alibaba, dashscope, happyhorse, pi, pi-coding-agent, pi-extension, pi-package, terminal, video-generation

## 简介

Generate and edit video in pi using Alibaba video models: HappyHorse 1.1/1.0, Wan 3.0, Wan 2.7 (T2V, I2V, R2V, Video-Edit). Auto-selected defaults, per-task-type overrides.
