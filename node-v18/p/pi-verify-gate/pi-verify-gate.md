# pi-verify-gate

> 标签: local-ci, pi, pi-coding-agent, pi-extension, pi-package, test, typecheck, verify

## 简介

Local verification status for the Pi coding agent: run the project's own check (npm/pnpm/yarn/bun script, cargo test, go test, pytest, make check) only when the working tree actually changed, with a zero-token footer badge, an on-demand verify_status tool
