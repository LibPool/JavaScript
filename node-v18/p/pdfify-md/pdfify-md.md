> 标签: cli, diagrams, documentation, headless-chrome, html-to-pdf, markdown, markdown-to-pdf, mermaid, modern, pdf, pdf-generation, puppeteer, typescript

## 简介

Modern, powerful CLI tool for converting Markdown files to PDF with Mermaid diagram support, syntax highlighting, and advanced customization.
