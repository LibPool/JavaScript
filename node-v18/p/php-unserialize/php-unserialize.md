# php-unserialize

> 标签: JavaScript

## 简介

tool to unserialize data taken from PHP. It can parse "serialize()" output, or even serialized sessions data.

## 官网

- 源码仓库：git://github.com/naholyr/js-php-unserialize.git
- npm 页面：https://www.npmjs.com/package/php-unserialize
