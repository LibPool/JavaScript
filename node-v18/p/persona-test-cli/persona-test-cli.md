# persona-test-cli

> 标签: JavaScript

## 简介

运维 CLI for persona-test — admin 和已审核通过的普通用户都能用；设备码浏览器授权登录，管理分享链接(campaigns)和画像(personas)，普通用户只能看到/编辑自己创建的。
