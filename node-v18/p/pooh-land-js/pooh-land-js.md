# pooh-land-js

> 标签: JavaScript

## 简介

[Pooh Land Node Module](https://github.com/poohgithub/pooh-land-js) is a new marketplace protocol for safely and efficiently buying and selling NFTs. This is a JavaScript library intended to make interfacing with the contract reasonable and easy.
