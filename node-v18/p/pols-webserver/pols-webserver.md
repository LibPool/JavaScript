# pols-webserver

> 标签: JavaScript

## 简介

Un wrapper de **Express** para Node.js y TypeScript que proporciona enrutamiento automático basado en el sistema de archivos (Filesystem-based Routing). Diseñado para evitar el registro manual de rutas y estructurar tu API de forma limpia e intuitiva medi
