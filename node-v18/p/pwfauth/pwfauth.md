# pwfauth

> 标签: activation, auth, authentication, drm, hwid, license-key, licensing, pwfauth, sdk

## 简介

Official Node.js client for PWF Auth (pwfauth.com): license-key activation, hardware-ID binding, encrypted sessions with a server-driven kill switch, free trials, remote texts/slides, and OTA update checks.
