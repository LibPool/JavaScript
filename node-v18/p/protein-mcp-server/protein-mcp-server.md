# protein-mcp-server

> 标签: ai, bioinformatics, cloudflare-workers, dependency-injection, ligand-binding, mcp, mcp-server, model-context-protocol, observability, opentelemetry, pdb, pdbe, protein-structure, rcsb, structural-biology, structure-alignment, typescript, uniprot, zod

## 简介

A powerful Model Context Protocol server providing programmatic access to 3D protein structural data from RCSB PDB, PDBe, and UniProt. Features multi-provider orchestration, comprehensive structural analysis tools, and full observability.
