# prisma-effect-schema-generator

> 标签: dmmf, effect, effect-schema, orm, prisma, prisma-generator, schema, typescript, validation

## 简介

Prisma generator that emits Effect Schema values, relation schemas, and runtime introspection maps (primary keys, soft-delete columns, table descriptors) for every model — drop-in validation for your database rows.
