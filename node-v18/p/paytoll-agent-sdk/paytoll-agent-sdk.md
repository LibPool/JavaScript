# paytoll-agent-sdk

> 标签: ai-agent, fetch, http-402, monetization, paywall, solana, usdc, x402

## 简介

Drop-in client SDK for AI agents that need to pay HTTP 402 paywalls. Handles x402 challenges, USDC settlement on Solana, retries, and safety guards automatically.
