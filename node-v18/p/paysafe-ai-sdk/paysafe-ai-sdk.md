# paysafe-ai-sdk

> 标签: ai, ai-agents, ai-sdk, payments, prompt-injection, security, tools, usdc, vercel, x402

## 简介

PaySafe payment security for the Vercel AI SDK: scan-before-you-pay tools for x402 payments, plus an onStepFinish handler that auto-tags provenance for prompt-injection detection, and guardedPayment for enforcement by construction.
