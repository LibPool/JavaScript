# pdf-fetch

> 标签: cli, imagemagick, jpg, pdf

## 简介

使用 ImageMagick 导出 PDF 页面为 JPG，或把图片目录合并为 PDF 的命令行工具（CLI 命令：pdf-fetch）

## 官网

- 源码仓库：git+ssh://git@github.com/Tairraos/pdf-fetch.git
