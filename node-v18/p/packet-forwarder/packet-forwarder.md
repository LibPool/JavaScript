# packet-forwarder

> 标签: LoRa, LoRaWAN, forwarder, packet, packet forwarder

## 简介

Virtual LoRa packet forwarder that forwards RF packets from API to a server through a IP/UDP link, and emits RF packets that are sent by the server.
