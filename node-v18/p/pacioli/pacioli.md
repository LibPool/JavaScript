# pacioli

> 标签: accounting, bun, cli, financial-documents, freelance, invoice, pdf, quotation, receipt

## 简介

CLI tool for generating professional financial documents (invoices, quotations, receipts) for freelancers. Named after Luca Pacioli, father of accounting.
