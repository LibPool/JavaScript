# pr-age-gate

> 标签: ci, github, github-actions, pull-request

## 简介

Verify (and, as a GitHub Action, enforce) that a pull request has been open for a configurable minimum number of hours before it's considered mergeable. Public-repo checks work with no token at all. Plain TypeScript, no runtime dependencies: the Action ru
