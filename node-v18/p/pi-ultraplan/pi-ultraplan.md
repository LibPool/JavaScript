# pi-ultraplan

> 标签: adversarial-review, code-generation, pi-package, planning, ultraplan

## 简介

Provider-agnostic ultraplan engine for Pi — fan-out planning, adversarial verification, structured plans, worktree-isolated execution. Reference adapter: fairy-tales-deepseek-openai / deepseek-v4-pro.
