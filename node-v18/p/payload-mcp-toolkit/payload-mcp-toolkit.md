# payload-mcp-toolkit

> 标签: ai, cms, content-management, mcp, model-context-protocol, payload, payload-plugin, payloadcms

## 简介

Standalone schema-aware MCP plugin for Payload CMS v3 — owns the /api/mcp endpoint, scoped API keys, draft workflow, and AI-friendly tools so non-technical editors can manage content via AI chat.
