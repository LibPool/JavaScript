# p5-sketch-module

> 标签: JavaScript

## 简介

Simple package that gives a basic p5 setup, with p5 and p5.sound, and a structure for running multiple sketches that can seamlessly  be rotated through in real time. A basic express server is included if you want to load images or songs.
