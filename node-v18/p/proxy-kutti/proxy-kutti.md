# proxy-kutti

> 标签: caching-proxy, http-proxy, https-proxy, mitm, proxy

## 简介

A Simple and transparent caching forward proxy with minimal dependencies. Cached files are stored in filesystem by preserving the structure. Cache never expires. Useful for caching various package manager files like rpm, deb etc with in local network, esp
