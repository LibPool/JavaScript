# prayer-times

> 标签: JavaScript

## 简介

PrayerTimes is a Node.JS module which is a port of the original JavaScript library, 'PrayTimes.js' developed by Hamid Zarrabi-Zadeh <http://praytimes.org/> providing a set of handy functions to calculate prayer times for any location around the world, based on a variety of calculation methods currently used in Muslim communities
