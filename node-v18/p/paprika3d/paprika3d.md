# paprika3d

> 标签: agent, claude-code, claude-code-plugin, game, gamedev, headless, mcp, mcp-server, paprika, paprika3d, react-three-fiber, testing, three.js, threejs, webgl

## 简介

paprika3D: the toolset that makes any coding agent a better three.js developer. A Claude Code plugin and MCP server that lets the agent see, play, inspect, build and speed up the three.js, React Three Fiber and WebGL pages it writes.
