# pi-show-minimax-quota

> 标签: minimax, pi-extension, pi-package, quota, token-plan

## 简介

Shows MiniMax Token Plan quota (5h and 7d windows) in the pi TUI status bar. Reads the API key from ~/.pi/agent/auth.json (the minimax-cn provider entry).
