# pareto-frontier

> 标签: Nash equilibrium, Pareto front, Pareto optimality, Pareto set, economics, maximum vector problem, pareto optimal, skyline, skyline query, statistics

## 简介

The Pareto frontier, or Pareto set, is the set of choices which optimizes a system. This package calculates the optimal set of points in a 2D system.
