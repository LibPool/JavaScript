# pdf-toolkit-mcp

> 标签: ai-tools, claude, claude-code, iloveapi, mcp, model-context-protocol, pdf, pdf-toolkit

## 简介

Unofficial MCP server exposing PDF operations (merge, split, compress, OCR, convert, watermark, protect, and more) via the iLoveAPI REST API. Not affiliated with iLovePDF SL.
