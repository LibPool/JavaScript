# pg-migrate-runner

> 标签: advisory-lock, database, dry-run, migrate, migration, migrations, postgres, postgresql, rollback, schema, sql

## 简介

A lightweight, config-driven PostgreSQL migration runner with advisory locking, dry-run, and pluggable logging.
