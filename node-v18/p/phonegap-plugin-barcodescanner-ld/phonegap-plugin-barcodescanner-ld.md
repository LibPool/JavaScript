# phonegap-plugin-barcodescanner-ld

> 标签: cordova-android, cordova-blackberry10, cordova-browser, cordova-ios, cordova-windows, cordova-windows8, cordova-wp8, ecosystem:cordova, ecosystem:phonegap

## 简介

You can use the BarcodeScanner plugin to scan different types of barcodes (using the device's camera) and get the metadata encoded in them for processing within your application.
