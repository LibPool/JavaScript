# plain-env

> 标签: common env, conf, config, configuration, dotenv, dotenv expand, dotenv ts, env, env deploy, env file, env file parser, env parser, env schema, env var, environment, gen ts env, node, node conf, node env, node env conf, parser, plain conf, plain env, process env, ts dotenv, ts env

## 简介

`plain-env` is a framework-agnostic `.env` and `Webpack.DefinePlugin` replacement, making business code cleaner, safer, better support `tree-shaking` and code inspection.
