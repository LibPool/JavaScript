# payload-locale-snapshot

> 标签: blocks, data-loss, i18n, locale, localization, payload, payload-plugin, payloadcms, postgres, postgresql

## 简介

Prevents silent data loss of localized blocks and arrays in Payload CMS with the PostgreSQL adapter.
