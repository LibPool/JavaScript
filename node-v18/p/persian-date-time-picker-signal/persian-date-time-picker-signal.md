# persian-date-time-picker-signal

> 标签: afghanistan, angular, angular-material, angular2, calendar, datepicker, datetime, hijri, iran, jalali, moment-jalaali, ngx-datepicker, persian, rangepicker, shamsi, time, timepicker

## 简介

A lightweight, customizable Angular date/time picker with full Persian (Jalali/Shamsi) calendar support. Supports date ranges, time selection, and seamless integration with Angular Material.
