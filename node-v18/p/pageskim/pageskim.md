# pageskim

> 标签: agents, ai, llm, llms-txt, markdown, pageskim, seo, tokens

## 简介

Make any web page readable by LLMs and agents at 10-50x fewer tokens. Browser SDK (ESM + <script> builds) and CLI for the PageSkim static sibling-file format.
