> 标签: a2a, agent, agent-to-agent, agent2agent, bonjour, collaboration, lan, mdns, multi-agent, p2p, pi-extension, pi-package, pi-skill

## 简介

Agent-to-agent message bus for pi — decentralized LAN P2P, agents discover each other via mDNS and talk point-to-point, no server required
