# poissimple

> 标签: 1d, 2d, 3d, any dimension, blue noise, periodic, point pattern, poisson, poisson disk sampling, repulsive point process, tileable

## 简介

Simple and tileable Poisson disk sampling, allowing for the generation of a specified number of points in any number of dimensions
