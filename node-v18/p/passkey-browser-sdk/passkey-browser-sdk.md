# passkey-browser-sdk

> 标签: browser, passkey, passwordless, sdk, touch-id, webauthn, windows-hello

## 简介

Browser SDK for PassKey SaaS — wraps WebAuthn OS APIs (Windows Hello, Touch ID, Face ID) and communicates with your customer backend.
