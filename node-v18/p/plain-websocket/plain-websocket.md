# plain-websocket

> 标签: JavaScript

## 简介

- 本项目不能单独启动，也不能单独调试； - 本项目是为了plain-editor实现协同编辑，基于websocket进行简易封装的websocket库，目的在于制定可扩展的类型以及api快速实现客户端与服务端之间的websocket通信；
