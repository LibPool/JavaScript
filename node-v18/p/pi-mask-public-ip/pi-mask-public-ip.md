# pi-mask-public-ip

> 标签: extension, ip-address, masking, pi, pi-coding-agent, pi-package, privacy

## 简介

Pi coding agent extension that masks public IP addresses and identifying MAC addresses in the outbound conversation, restoring them when the model echoes a placeholder back into a tool call.
