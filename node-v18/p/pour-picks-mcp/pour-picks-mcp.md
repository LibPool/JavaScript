# pour-picks-mcp

> 标签: bourbon, mcp, model-context-protocol, pour-picks, spirits, tasting-notes, whiskey, whisky

## 简介

MCP server exposing the Pour Picks bourbon & whiskey database (4,700+ bottles) as read-only tools for AI assistants. Search the catalog, compare bottles, find cheaper alternatives, and get pour suggestions — with citation-ready attribution.
