# plugin-dgjw

> 标签: analyzer, dgjw, manifest, metadata, package.xml, salesforce, sf, sf-plugin

## 简介

Da Ga Jeo Wa - Salesforce manifest analyzer plugin. Generates full metadata manifest from an org, analyzes component counts, and produces markdown reports.
