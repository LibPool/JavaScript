# pi-referee

> 标签: auto-mode, guardrails, pi, pi-coding-agent, pi-package, reviewer, tool-approval

## 简介

A second model referees the pi coding agent's tool calls against per-session policies: safe calls run, risky or doubtful ones ask you.
