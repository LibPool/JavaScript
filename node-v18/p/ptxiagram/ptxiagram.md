> 标签: architecture-diagram, claude-skill, dataflow-diagram, diagram, hancom, hanshow, lifecycle-diagram, office-automation, powerpoint, pptx, sequence-diagram, workflow-diagram

## 简介

Generate native, editable PowerPoint (PPTX) architecture, workflow, sequence, dataflow, and lifecycle diagrams from a small JSON file — real shapes and connectors, not an embedded image. Ships with a Claude Skill (SKILL.md) and a CLI.
