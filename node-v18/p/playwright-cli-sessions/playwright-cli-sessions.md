# playwright-cli-sessions

> 标签: auth, browser-automation, cli, playwright, sessions

## 简介

Session management layer for @playwright/cli — named saved logins, service probes, clone safety. Reads/writes ~/.playwright-sessions/ (interop with playwright-sessions MCP).
