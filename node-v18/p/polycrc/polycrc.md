# polycrc

> 标签: crc, crc10, crc16, crc24, crc32, crc32c, crc6, crc8, polynom, pycrc

## 简介

Fast Javascript calculation of custom CRC checksum. Prebuilt models for CRC-6, CRC-8, CRC-10, CRC-16, CRC-24, CRC-32, CRC-32C.
