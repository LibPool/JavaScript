# pi-lean-portal

> 标签: browser, pi-extension, pi-package, playwright, web

## 简介

Interactive Playwright web browsing for Pi. Chromium and Firefox built in; author stealth backends on either engine. Snapshots and screenshots cache to disk, saving context. Configurable profiles/cookies. Agents write site guides, auto-matched by domain.
