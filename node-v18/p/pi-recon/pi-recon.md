# pi-recon

> 标签: asset-collection, information-gathering, pentest, pi, pi-extension, pi-package, port-scan, recon, red-team, subdomain, vulnerability-scanner

## 简介

Pi extension for red-team recon and asset discovery. 14 tools: ICP lookup, subdomain enum, DNS/cert/ASN, asset search (Shodan/FOFA/Hunter/Quake), port scan, web probe, dir brute, backup finder, 403 bypass, vuln check, JS analysis.
