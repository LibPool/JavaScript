# perkoon

> 标签: file-transfer, p2p, peer-to-peer, perkoon, send-files, webrtc

## 简介

File transfer for humans and the things replacing them. P2P CLI — send files directly between devices via WebRTC. No upload, no size limit. Agent-friendly: --json NDJSON output, --source attribution, --server override for self-hosted, deterministic exit c
