# periodicjs.ext.clouduploads

> 标签: amazon s3, periodicjs, pkgcloud, rackspace cloudfiles, uploads

## 简介

An asset upload manager that uses pkgcloud to upload to the various cloud service providers (amazon s3, rackspace cloud files, etc)
