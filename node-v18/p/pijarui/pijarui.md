# pijarui

> 标签: accessibility, components, dark-mode, design-system, nextjs, react, shadcn, tailwind, tailwindcss, ui

## 简介

Dark-first React design system on Tailwind v4. Accessible by construction — 44px touch targets, WCAG AA contrast, and focus states you cannot forget to write.
