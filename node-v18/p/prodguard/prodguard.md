# prodguard

> 标签: agent-skills, ai-agents, ci, ci-gate, claude-code, copilot, cors, cursor, devsecops, firebase, github-action, guardrails, jwt, migration-linter, nextjs, postgres, postgresql, rls, rls-policies, rls-scanner, row-level-security, security, service-role-key, static-analysis, stripe, supabase, supabase-rls, supabase-security, vibe-coding

## 简介

Fails your CI when an AI coding agent disables Supabase Row Level Security, widens a Postgres grant, exposes a service_role key, or skips Stripe webhook verification. Zero-dependency Node CLI and GitHub Action, 22 rules.
