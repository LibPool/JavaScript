# pg4al

> 标签: admin, backup, cli, database, migration, pgadmin, postgres, postgresql

## 简介

Лёгкий и быстрый CLI-инструмент для администраторов PostgreSQL и pgAdmin 4. Поддерживает подключения, бэкапы, восстановление, мониторинг, миграции и автоматизацию рутинных задач.
