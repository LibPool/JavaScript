# pi-keyrouter

> 标签: ai-coding, api-key, fallback, key-rotation, pi, pi-extension, pi-package, rate-limit

## 简介

API key rotation for pi-coding-agent. Multiple keys per provider, automatic 429/401 fallback, max-retries guard.
