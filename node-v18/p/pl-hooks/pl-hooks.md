# pl-hooks

> 标签: JavaScript

## 简介

This project includes Tanstack Query-based functions for remote state management for Mastodon API clients. The project is currently not aiming at providing stable API, so if you're interested in something more stable, I recommend trying [pl-api](../pl-api
