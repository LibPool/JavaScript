# parseguard

> 标签: browser, coerce, crash-protection, deep-copy, error-handling, fallback, graceful, json, json-parse, json-sanitizer, json-validation, localStorage, nodejs, parse, required-fields, safe-clone, safe-json, safe-parse, type-coercion, utility, validation

## 简介

A lightweight utility that safely parses JSON without crashing applications. Supports fallback values, error logging, and required field validation.
