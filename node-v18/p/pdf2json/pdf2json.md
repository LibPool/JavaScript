# pdf2json

> 标签: JSON, PDF binary to text, PDF canvas, PDF form extractor, PDF text extractor, PDF to text, command line utility to parse pdf to json, convert pdf form to json, convert pdf to json, javascript, pdf, pdf parser, pdf2json, port pdf.js to node.js, server side PDF parser

## 简介

PDF file parser that converts PDF binaries to JSON and text, powered by porting a fork of PDF.JS to Node.js
