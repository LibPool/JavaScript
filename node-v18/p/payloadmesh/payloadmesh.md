# payloadmesh

> 标签: api, bandwidth, binary, compression, delta, express, fastify, json, microservices, payload, performance, realtime, serialization, state-sync, websocket

## 简介

Adaptive zero-dependency payload optimizer for Node.js with compact binary encoding, delta sessions, WebSocket integration, framework adapters, and wire-size analytics.
