# pseudo-shuffle

> 标签: browser, browser-compatible, cjs, ems, es, esm, format-preserving-encryption, fpe, javascript, js, module, shuffle, shuffle-algorithms, ts, typescript, umd, web-crypto

## 简介

Make the index look like it is shuffled according to the range so that it is not conflicted without the actual shuffle. Works in both Node.js and browser environments.
