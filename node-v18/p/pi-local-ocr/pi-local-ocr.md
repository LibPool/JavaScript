# pi-local-ocr

> 标签: extension, ocr, pi, pi-coding-agent, pi-package, screenshot, vision

## 简介

Local OCR for Pi — extract text and pixel coordinates from any image via macOS Vision. No network, no API keys. Ideal for reading simulator screenshots when the model cannot see images.
