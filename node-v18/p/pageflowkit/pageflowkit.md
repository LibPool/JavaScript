# pageflowkit

> 标签: next, pagination, react

## 简介

A lightweight, fully customizable React pagination component with support for page limits, active page styling, responsive layout, and dropdown for per-page selection. Built with native CSS (no Tailwind or external UI libraries required). Perfect for SaaS
