# prowork-ui

> 标签: JavaScript

## 简介

统一平台交互，提升用户体验，能够让产品显得更专业，保障组件研发质量，组件稳定性，组件可维护性，在改善平台体验的同时，挖掘组件的亮点功能 ## 方案目标  - 统一的界面视觉效果  - 统一的不同页面杂乱组件  - 统一的交互规则  - 基于组件已有功能对组件进行增强（功能，性能）  - 组件场景拓展（基于业务场景拓展组件，挖掘场景价值）
