# pdf-a11y

> 标签: a11y, accessibility, alt-text, european-accessibility-act, pdf, pdf-ua, pdfkit, puppeteer, tagged-pdf, wcag

## 简介

Accessibility checker for generated PDFs. Verifies tag tree, alt text, language, table headers and reading structure so PDFs from pdfkit or puppeteer are usable by a screen reader.
