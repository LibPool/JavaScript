# pmcp-server

> 标签: ai-context, claude-code, cline, context-management, cursor, mcp, project-init, prompts

## 简介

通用 MCP Server — 自动生成项目 prompts 体系、传递链日志、模块记录、需求澄清与计划生成。可接入任意项目。
