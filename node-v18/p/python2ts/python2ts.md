# python2ts

> 标签: ai, ast, code-generation, compiler, converter, machine-learning, migration, python, transpiler, type-inference, typescript

## 简介

AST-based Python to TypeScript transpiler. Convert Python code to clean, idiomatic TypeScript with full type preservation.
