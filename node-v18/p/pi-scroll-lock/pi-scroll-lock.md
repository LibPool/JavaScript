# pi-scroll-lock

> 标签: pi, pi-package, reading-mode, scroll, scroll-lock, scrollback, tui

## 简介

Freeze the pi TUI screen on demand (Alt+S) so the terminal scrollback stops yanking you to the bottom while the agent keeps streaming.
