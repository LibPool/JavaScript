# pi-async

> 标签: async, background-tasks, coding-agent, delayed, pi, pi-extension, pi-legion, pi-package, shell, task-manager, watch

## 简介

Pi extension for async shell tasks: background/delayed/sync modes, output-matching watches, event-driven waiting, settle guard for legion children, and a TUI task rail — completion notifications wake your session.
