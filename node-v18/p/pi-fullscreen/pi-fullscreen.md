# pi-fullscreen

> 标签: fullscreen, pi-coding-agent, pi-package, tui

## 简介

Pi package that gives the TUI a calm, immersive fullscreen layout like Claude Code: clears the screen and scrollback on start/exit and pins the editor and footer to the bottom.
