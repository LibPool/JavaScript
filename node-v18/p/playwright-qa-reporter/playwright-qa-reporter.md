# playwright-qa-reporter

> 标签: allure-alternative, e2e, html-report, playwright, playwright-test, qa, reporter, test-report, testing

## 简介

A single-file, offline, zero-dependency HTML reporter for Playwright Test with failure intelligence, API capture, history trends and one-click bug reports.
