# prottime-flow-mcp

> 标签: automation, claude, mcp, model-context-protocol, prottime, prottime-flow, workflow

## 简介

Servidor MCP de Prottime Flow: le da a un modelo el catalogo real de nodos de tu instalacion, le revisa el JSON de importacion y puede dejar el flujo creado.
