# portbook

> 标签: ai-agents, containers, dashboard, devtools, docker, mcp, port-allocation, ports, registry, reservation

## 简介

A machine-wide port reservation registry + ecosystem dashboard so multiple dev servers, containers, and AI agents stop colliding on ports.
