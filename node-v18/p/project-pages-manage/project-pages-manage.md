# project-pages-manage

> 标签: JavaScript

## 简介

以小程序目录结构为例: - 所有的页面都位于`pages`目录下 - 所有页面都是一个个独立的文件夹, 在文件夹内包含固定的4个文件, 然后每个文件也许都有些默认的代码、内容 - 创建好文件后还需要去`app.json`目录添加路由
