# pdf2md-library

> 标签: academic, agent, dsh, library, markdown, mineru, ocr, pdf

## 简介

学术 PDF 图书馆：基于 MinerU 官方 API，将 PDF 解析为 Markdown，支持关键词检索、页码换算与图书馆索引，让文本模型用少量 token 阅读书籍
