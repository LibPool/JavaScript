# panoon-mcp

> 标签: ai-agent, mcp, modelcontextprotocol, panoon, street-view, streetview

## 简介

MCP server for PanoOn — let AI agents scan Street View areas into PanoIDs and download imagery (opencode, Claude Code, Codex, dsh, ...).
