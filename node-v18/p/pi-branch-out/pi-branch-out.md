# pi-branch-out

> 标签: pi, pi-coding-agent, pi-package

## 简介

Fork the current Pi session into a split terminal pane or new tab with rotating layout policies, and with optional model and message queuing, and support for cmux, tmux, iTerm2, Terminal.app, Ghostty, and Orca.
