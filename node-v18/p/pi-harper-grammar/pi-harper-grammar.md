# pi-harper-grammar

> 标签: extension, grammar, harper, oh-my-pi, omp, pi, pi-package, spell-check, writing

## 简介

Type it right, make the agent guess less — live grammar-check (and one-key alt+g fix) for the Pi/OMP chat input, powered by Harper.
