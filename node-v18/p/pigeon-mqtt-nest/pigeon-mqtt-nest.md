# pigeon-mqtt-nest

> 标签: aedes, mqtt, mqtt-server, nest, nest-mqtt-server, nestjs

## 简介

pigeon-mqtt-nest is an NPM package that simplifies the process of integrating an MQTT broker into Nest JS applications.
