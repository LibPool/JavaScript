# pi-not-enough-info

> 标签: cache, info-density, pi, pi-coding-agent, pi-extension, pi-package, pi-theme, status-line

## 简介

A Pi TUI status/info theme extension: Pi-native cache rates (CH), history rates (HCH), and turn output speed (OUT) in a dense status line.
