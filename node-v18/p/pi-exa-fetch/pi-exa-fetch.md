# pi-exa-fetch

> 标签: JavaScript

## 简介

为零配置 Pi 环境提供最短网页检索闭环的本地扩展（`0.2.0`）：只注册 `web_search` 与单 URL `web_fetch`，经 Exa 托管端点完成有界搜索与正文读取。合成汇报由正常 Pi host 完成，扩展不自动串联工具、不重试。
