# peertube-plugin-hive-tube

> 标签: peertube, plugin

## 简介

The Hive-Tube server plugin monetizes & syndicates any streaming media via the Hive and Fediverse networks, plus RSS. Stream anything P2P (even 4K Livestreams). No more worries of bans, account deletion or demonetization. Reach new audiences, earn more.
