# pinoccio-serial-unofficial

> 标签: pinoccio, serial, serial-port

## 简介

serial tools for your pinoccio built on the node-serial interface. send commands, find wifi, program wifi, bootload and more. Note peer dependency on a serial port implementation of some kind.
