## 简介

这里的每个包每次更改都需要记得 npm publish 到我的 npm 仓库中 我的npm仓库账号记录在自己的有道云笔记本中：账号是 microler 那个 这里的几个包的依赖关系如下 pinyinwx 是主包，其他3个包都是数据包，pinyinwx主包把其他3个包通过 npm install xxx 到自己包内使用，而其他3个包都是各自独立的没有任何依赖关系 pinyinwx 主包使用的时候一定要到它目录下 即 /pinyinwx/，npm install 一下才可以使用
