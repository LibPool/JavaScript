# pdf-2-llm

> 标签: JavaScript

## 简介

`pdf-2-llm` is an implementation-stage PDF-to-Markdown toolkit for turning PDF documents into Markdown plus machine-readable sidecars that are suitable for LLM, search, RAG, archival, and review workflows.
