# pi-shell-completions

> 标签: pi-package

## 简介

Pi extension that adds native shell completions (fish/zsh/bash) to ! and !! bash mode commands

## 官网

- 源码仓库：https://github.com/laulauland/dotfiles
- npm 页面：https://www.npmjs.com/package/pi-shell-completions
