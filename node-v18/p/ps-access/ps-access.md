# ps-access

> 标签: access-controller, accessibility, adaptive-controller, assistive-technology, hid, node-hid, playstation, ps5, remapping, webhid

## 简介

Read/write PlayStation Access Controller profiles from a PC (no PS5). CLI + WebHID tool + PC input bridge.
