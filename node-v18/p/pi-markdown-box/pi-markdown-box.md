# pi-markdown-box

> 标签: codeblock, markdown, pi-extension, pi-package, table, tui

## 简介

Pi extension that renders inline Markdown fenced code blocks and tables as terminal boxes (╭─╮ style). Fork of pi-codeblock-box with broader scope.
