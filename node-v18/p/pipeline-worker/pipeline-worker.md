# pipeline-worker

> 标签: agent, automation, ci, claude, copilot, github, gitlab, merge-request, pi, pi-coding-agent, pull-request, tui

## 简介

Automated git-worktree workflow, run from an interactive TUI: captures intent from a diff via Claude Code or GitHub Copilot CLI, runs build/lint/test, opens a GitLab MR or GitHub PR, and auto-fixes failing pipelines.
