# pdfjs2png

> 标签: pdf

## 简介

Simple CLI tool convert PDF file into png image with pdf.js and node-canvas

## 官网

- npm 页面：https://www.npmjs.com/package/pdfjs2png

## 历史版本号

- npm 安装：`npm install pdfjs2png`
- npm registry：https://registry.npmjs.org/pdfjs2png
- Node 要求：>=12
