# projectmind-agent

> 标签: JavaScript

## 简介

Desktop agent (macOS/Windows/Ubuntu) that heartbeats to ProjectMind and runs claimed task jobs via Cursor SDK, Cursor CLI, Codex CLI, Antigravity CLI, or LLM API
