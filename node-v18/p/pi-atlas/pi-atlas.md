# pi-atlas

> 标签: ai-agent, automation, coding-agent, extensions, infra, pi, pi-package, sre

## 简介

Event-driven coding extensions for the pi agent — async tasks, goal-driven auto-continue, and Feishu notifications for unattended infra/SRE runs. Meta package: installs every pi-atlas extension.
