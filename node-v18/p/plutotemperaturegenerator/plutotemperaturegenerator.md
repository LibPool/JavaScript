# plutotemperaturegenerator

> 标签: astronomy, pluto, random, temperature

## 简介

A simple Node.js package that generates randomized temperatures, logically matching conditions on Pluto. This package can be used for simulation, games, or any project where you need to create realistic (yet random) temperature values for Pluto.
