# prd-flaw-checker

> 标签: ambiguity-detection, analysis, claude-code, first-principles, opencode, prd, product-requirements, skill

## 简介

PRD 缺陷审查 OpenCode / Claude Code Skill —— 三轮深度分析(第一性原理 / 一致性 / 歧义检测),自动回写澄清结果到 PRD,支持导出 Markdown 报告与交互式 HTML 决策表单。
