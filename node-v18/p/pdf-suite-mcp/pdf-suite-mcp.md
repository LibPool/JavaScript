# pdf-suite-mcp

> 标签: mcp, merge-pdf, model-context-protocol, pdf, pdf-forms, pdf-lib, pdf-tools, redact, split-pdf, unpdf, watermark

## 简介

Comprehensive MCP server for PDF operations — 37 tools for reading, creating, merging, splitting, watermarking, stamping, form filling, redacting, searching, comparing, and more. Built on pdf-lib and unpdf. No cloud, no API key.
