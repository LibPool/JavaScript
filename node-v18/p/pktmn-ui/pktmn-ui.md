# pktmn-ui

> 标签: JavaScript

## 简介

pktmn-ui is a React component library inspired by theme-heavy game UI like Pokémon Emerald. Transpiled with Vite library mode, pktmn-ui ships with styles organized via Tailwind CSS theming, defined in pktmn-ui/foundations.css.
