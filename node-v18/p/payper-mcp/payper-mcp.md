# payper-mcp

> 标签: agentic, ai-agents, gpu, mcp, model-context-protocol, payments, robinhood-chain, usdg, x402

## 简介

Payper MCP server — let any AI agent rent GPUs and pay per second in USDG over x402 on Robinhood Chain.
