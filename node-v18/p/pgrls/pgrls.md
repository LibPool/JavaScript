# pgrls

> 标签: drizzle, drizzle-orm, multi-tenant, multitenancy, postgres, postgresql, rls, row-level-security, security, sql, tenant-isolation

## 简介

Postgres row-level security you can actually verify. Policies as TypeScript, tenant context as a transaction, and one test that proves no table is exposed.
