# passport-firebase-azure-ad

> 标签: ad, auth, authenticate, authorise, authorize, azure, firebase, graph, microsoft, passport

## 简介

A modified passport-azure-ad module that allows a user to authenticate and authorise Microsoft Azure-ad accounts using __session cookies whilst working in a firebase environment.
