# prisma-postgrejs

> 标签: driver-adapter, no-native-bindings, orm, postgrejs, postgres, postgresql, prisma, prisma-adapter, sql, typescript, wire-protocol

## 简介

Prisma driver adapter for PostgreJS - run a Prisma schema on PostgreJS's wire-protocol client
