# piconvert

> 标签: AI, Adobe Illustrator, Convert, GitHub Actions, Inkscape, SVG

## 简介

Convert pictures to other formats. Supports ai, cdr, vsd, pdf, and more formats. GitHub Actions & CLI Tool.
