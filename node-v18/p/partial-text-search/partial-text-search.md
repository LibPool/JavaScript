# partial-text-search

> 标签: binary search, document collection, full text, full text search, postfix search, query, search, searching algorithms, string matching, substring matching, suffix array, text, text search, wildcard

## 简介

A JavaScript library that finds string patterns in a collection of documents. It efficiently finds matches even if the words in each document do not begin with the query pattern.
