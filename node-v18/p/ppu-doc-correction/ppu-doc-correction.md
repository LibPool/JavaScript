# ppu-doc-correction

> 标签: bun-compatible, computer-vision, document-ai, document-correction, document-processing, image-processing, image-unwarping, onnx, onnxruntime, orientation-detection, paddle-paddle, paddlepaddle, uvdoc

## 简介

Lightweight, type-safe document image correction for Node.js, Bun, and browsers. Provides orientation classification, text unwarping (UVDoc), and text line orientation correction.
