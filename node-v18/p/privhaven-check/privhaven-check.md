# privhaven-check

> 标签: audit, compliance, evidence, gdpr, pii, privhaven, redaction, reproducible, sha256, verifier

## 简介

Engine-free, offline verifier for PrivHaven compliance reports. Confirms a report against your own copy of the file using public algorithms only. No PrivHaven engine, no upload.
