# prettier-plugin-uncomment

> 标签: comments, prettier, prettier-plugin, remove-comments, strip-comments, uncomment

## 简介

Prettier plugin that strips comments from JS/TS/JSX/Flow files, keeping tooling directives and developer-flagged comments.
