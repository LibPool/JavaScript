# pi-proof

> 标签: agent-workflow, coding-agent, jest, pi, pi-extension, pi-package, proof, proof-first, pytest, red-green-refactor, rspec, testing, vitest

## 简介

Proof-first Pi extension that uses a red-green-refactor cycle when behavior should be specified in tests first, with built-in parsing for popular test frameworks.
