> 标签: fetch, minecraft, minecraftbe, minecraftbedrock, minecraftjava, minecraftje, minecraftpinger, pinger, pingerminecraft

## 简介

A Nodejs library that allows you to get information about the minecraft server using https://api.mcsrvstat.us/
