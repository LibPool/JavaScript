# precise-typeof

> 标签: array, instance, instanceof, kind, kindof, object, plain object, pojo, precise, type, typeof

## 简介

Better 'typeof'. Detects real type of the objects like 'Array()', 'new Number(1)', 'new Boolean(true)', etc.
