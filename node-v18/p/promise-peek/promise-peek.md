# promise-peek

> 标签: promise

## 简介

Augmentation to ES6 Promise, that allows to peek at the promise results without interfering

## 官网

- 源码仓库：git@github.com:hypescript/promise-peek.git
- npm 页面：https://www.npmjs.com/package/promise-peek

- 1.0.1

- npm registry：https://registry.npmjs.org/promise-peek
- Node 要求：>=6.0.0
