# playwright-power-automate-reporter

> 标签: adaptive-card, ci, microsoft-teams, playwright, playwright-reporter, power-automate, teams

## 简介

Playwright reporter and standalone CLI that posts an Adaptive Card run summary to Microsoft Teams via a Power Automate HTTP trigger.
