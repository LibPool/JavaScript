# parsec-gulp-rev

> 标签: asset, assets, cache, expire, gulpplugin, hash, optimize, rev, revision, revving, static, version, versioning

## 简介

Static asset revisioning by appending content hash to filenames: unicorn.css => unicorn.css?v=84bd1b9a2c
