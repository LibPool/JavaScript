# p2pme-encrypted-payment-proof

> 标签: JavaScript

## 简介

Headless client SDK for P2P payment proofs. Framework-agnostic API client + sign-in helper used by the user, merchant, and ops UIs. Proofs are stored raw and gated by role-authorized APIs.
