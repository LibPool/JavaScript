# pixel-skyline

> 标签: cli, contribution-graph, github, github-actions, github-readme, pixel-art, svg

## 简介

A pixel-art city that grows from your GitHub contribution graph, rendered as an animated SVG for GitHub profile READMEs. Under active development — full functionality coming soon.
