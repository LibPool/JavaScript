# pi-status-indicator

> 标签: coding-agent, indicator, pi, pi-extension, pi-package, spinner, status, tui

## 简介

Claude Code-style status indicator for pi: a ping-ponging half-circle while working, a hand while waiting on you, a check when done, and a 2-4 word session theme in the header.
