# pi-claude-sandbox

> 标签: claude, pi-extension, pi-package, sandbox

## 简介

Claude-style OS-level sandboxing for pi with interactive permission prompts. Coexists with pi-tool-display and other bash-overriding extensions. Forked from carderne/pi-sandbox.
