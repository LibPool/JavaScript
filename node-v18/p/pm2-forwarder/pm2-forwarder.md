# pm2-forwarder

> 标签: api, cli, devops, forwarder, hono, npx, pm2, process-manager, rest

## 简介

Tiny zero-config REST API that forwards PM2 process control (list/restart/stop/reload/delete) over HTTP. Run with npx.
