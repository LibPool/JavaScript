# promised-websocket

> 标签: promise, promise-api, promises, websocket, websockets, ws

## 简介

A WebSocket client library providing Promise-based API for connecting, disconnecting and messaging with server. Original developed by Vitaliy Potapov(noginsk@rambler.ru).
