# piivacy

> 标签: anthropic, llm, openai, pii, privacy, pseudonymization, redaction, tokenization

## 简介

PIIvacy — PII scrubber for LLM calls. Three substitution modes (token, realistic, pass-through), pluggable patterns, BYO-LLM helpers, optional in-browser/local-model name redaction. Two functions, no proxy, no server.
