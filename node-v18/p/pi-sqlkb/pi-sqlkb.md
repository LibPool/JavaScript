# pi-sqlkb

> 标签: knowledge-base, pi, pi-coding-agent, pi-package, schema, sql

## 简介

Pi extension for a progressive-disclosure SQL knowledge registry. Reuses the same ~/.agents/sqlkb knowledge base (tables/ + examples/ markdown with front-matter) as the DSH sqlkb plugin, exposing sqlkb_list / sqlkb_search / sqlkb_get tools so Pi can look
