# pi-dsh-optimizer

> 标签: dsh-router-standard, extension, pi, pi-package, react, reasoning-mode, router, spec, weak

## 简介

The auto-shifter for pi: task-aware reasoning-mode router. Ported from dsh-router-standard — classifies each task and routes the session to spec (planner) / react (doer) / weak (self-route), with persona + first-turn tool injection and two tuning tools.
