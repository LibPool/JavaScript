# paste.gg

> 标签: api, paste.gg, wrapper

## 简介

An easy-to-use library for interacting with the Paste.GG API. Contains examples, strong JSDocs, TypeScript types, and support for Node.js 12+. Works in both JavaScript and TypeScript.
