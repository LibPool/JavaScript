# package-cli-service

> 标签: package, package-cli, package-cli-service

## 简介

构建、打包、发布、运行测试 package；支持自动处理version、自动生成CHANGELOG，集成typescript、husky、eslint、commitlint、storybook、analyzer等；支持构建vue、react、jslib等web前端package

- npm 页面：https://www.npmjs.com/package/package-cli-service
