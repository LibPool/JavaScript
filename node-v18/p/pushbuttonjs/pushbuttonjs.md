# pushbuttonjs

> 标签: JavaScript

## 简介

移动端从下往上推动画效果端弹出列表选择框，适应所有主流移动端机型，支持Node引入，require引入,demo:http://gtdalp.github.io/pushbutton/demos/pushbutton.html
