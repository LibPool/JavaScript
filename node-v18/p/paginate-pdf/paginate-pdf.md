# paginate-pdf

> 标签: dom-to-pdf, html-to-pdf, html2canvas, jspdf, page-break, pagination, pdf, print

## 简介

Turn any DOM element into a paginated PDF that never cuts through a line of text or an image — page breaks always land in an empty gap.
