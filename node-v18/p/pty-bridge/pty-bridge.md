# pty-bridge

> 标签: agent, ai, cli, interactive, node-pty, pty, repl, ssh, terminal, tui

## 简介

Manage interactive terminal sessions (SSH, REPLs, databases, TUI apps) via CLI. Designed for AI agents that need PTY support.
