# posthtml-link-noreferrer

> 标签: html, link, nofollow, noopener, noreferrer, posthtml, posthtml-plugin

## 简介

This plugin add `rel="noopener"` and `rel="noreferrer"` to all links that contain the attribute `target="_blank"`.
