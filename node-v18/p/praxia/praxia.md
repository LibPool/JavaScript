# praxia

> 标签: agents, ai, architecture, bug fixing, copilot, developer-assistant, optimization, praxia, refactoring

## 简介

Praxia is the action layer for Cognia reports. It reads analysis from cognia/, then proposes and, after explicit approval, applies scoped fixes or writes suggestions to praxia/.
