# pinia-workspace-plugin

> 标签: broadcastchannel, cross-tab, leader-election, multi-tab, multi-window, pinia, state-sync, vue

## 简介

Vue 3 / Pinia 3 runtime for coordinating multiple browser windows/tabs as one application: window roles, presence, typed request/response commands, state ownership, and leader election.
