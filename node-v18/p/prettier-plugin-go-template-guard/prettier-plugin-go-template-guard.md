# prettier-plugin-go-template-guard

> 标签: go-template, html, prettier, prettier-plugin

## 简介

Wraps prettier-plugin-go-template and fixes multiline Go template actions inside HTML attribute values, which otherwise render as literal whitespace in the attribute.
