# protean.js

> 标签: JavaScript

## 简介

The goal in this project is to create a JavaScript library will add some of the usefull helper methods that Ruby has available to it to JavasScript types like String, Number, Date, etc. WARNING: this project will modify the prototypes of many objects including String, Number, etc.
