# petbox-wire

> 标签: claude-code, factory-droid, mcp, opencode, petbox, wiring

## 简介

Wire any project to PetBox (Claude Code, opencode, Factory Droid) — global hooks, MCP configs and skills — with a single npx command, no repo clone.
