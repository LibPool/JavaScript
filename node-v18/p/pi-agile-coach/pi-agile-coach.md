# pi-agile-coach

> 标签: agile, ai, backlog, coaching, pi-coding-agent, pi-package, project-management, scrum, sdd, skills, sprint, workflow

## 简介

Universal agile coach for pi and Claude Code — structures any project (software, design, hardware, marketing, operations) into sprints with full SDD cycle: backlog, sprint planning, verification, retro, and decision memory. Integrates with any skill.
