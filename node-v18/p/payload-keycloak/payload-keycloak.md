# payload-keycloak

> 标签: auth, keycloak, oidc, payload, payload-plugin, payloadcms, pkce, sso

## 简介

Keycloak SSO authentication for Payload CMS 3: OIDC auth strategy, admin login/logout, silent refresh and permission-based access control
