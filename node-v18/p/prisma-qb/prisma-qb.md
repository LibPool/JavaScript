# prisma-qb

> 标签: backend, filter, node, prisma, prisma-query, prisma-query-builder, query-builder, rest-api, search, sorting, typescript, zero-dependencies

## 简介

A lightweight, strict Prisma query builder that converts HTTP query parameters into safe where and orderBy objects. Zero dependencies.
