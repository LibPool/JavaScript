# path-picker

> 标签: cross-platform, directory, filepicker, folderpicker, linux, macos, native, nodejs, path, picker, windows

## 简介

Cross-platform Node.js library for selecting file or folder paths without admin rights. Uses native Windows API (via C++ addon) and shell tools on macOS/Linux to provide a simple file and directory picker.
