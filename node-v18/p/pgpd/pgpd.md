# pgpd

> 标签: JavaScript

## 简介

`pgpd` (**P**ostgreSQL **P**rotocol **D**escribe) is a CLI and API tool that talks directly to the PostgreSQL **Wire Protocol** and retrieves **SQL metadata** using the `Parse` / `Describe` flow.
