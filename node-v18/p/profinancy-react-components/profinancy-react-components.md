# profinancy-react-components

> 标签: JavaScript

## 简介

1. Скачать проект 2. Запустить команду `webpack`. Если не работает, то попробовать установить глобально пакеты. Команда: `npm install -g webpack webpack-cli` 3. Должен скомпилированный код попасть в папку `dist`
