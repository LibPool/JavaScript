# pi-trail

> 标签: ai, claude-code, journal, pi, pi-package, productivity, tracking, zcode

## 简介

Automatically record every input you type into your AI coding agents (pi, zcode, claude-code, ...) and review it as a self-writing work journal — conversations, projects, memos, reminders, and AI-powered project progress analysis. Multi-machine sync via g
