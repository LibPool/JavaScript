# parcel-transformer-extension-name

> 标签: JavaScript

## 简介

A transformer plugin for Parcel that replaces __EXTENSION_NAME__ with the name from your extension.json

## 官网

- npm 页面：https://www.npmjs.com/package/parcel-transformer-extension-name

## 历史版本号

- 当前版本：1.0.0

- 1.0.0

## 获取地址

- npm 安装：`npm install parcel-transformer-extension-name`
- npm registry：https://registry.npmjs.org/parcel-transformer-extension-name
- Node 要求：>= 16.0.0
