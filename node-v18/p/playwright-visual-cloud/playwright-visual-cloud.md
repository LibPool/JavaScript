# playwright-visual-cloud

> 标签: chromatic, cloudflare, playwright, r2, screenshot, snapshot, visual-regression

## 简介

Cloud visual snapshot testing for Playwright, backed by Cloudflare R2 + D1. Self-hosted, open-source alternative to Chromatic.
