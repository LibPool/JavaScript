# parse-columns-cli

> 标签: cli, cli-app, cmd, col, column, columns, command, csv, jq, json, output, parse, parser, row, sh, shell, str, string, table, term, text, underscore, unix

## 简介

Parse text columns, like the output of unix commands. Returns JSON that you can manipulate with tools like jq or underscore-cli.
