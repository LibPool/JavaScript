# page-mcp

> 标签: agent, browser, browser-automation, cdp, coding-agent, devtools, dom, mcp, model-context-protocol, webmcp

## 简介

A WebMCP tool provider: drop one <script> into a web UI and the page hosts DOM/UI/devtools tools on document.modelContext for coding agents to call.
