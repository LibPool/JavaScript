# postalkit

> 标签: address, checkout, format, iso-3166, postal-code, postcode, validation, zero-dependencies, zip, zip-code

## 简介

Validate and format postal codes for 252 countries. Forgiving input, one canonical output, a reason for every rejection. Zero dependencies, 4.2 kB gzipped.
