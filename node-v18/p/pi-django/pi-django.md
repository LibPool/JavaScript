# pi-django

> 标签: django, djangorestframework, ninja, pi-package, scaffold, uv

## 简介

Pi extension that scaffolds Django projects using uv, following the Django Styleguide conventions. Asks for the framework (standard / DRF / Ninja) and Python version, and generates a base project with a ready-to-use users app.
