# pi-agent-notify

> 标签: JavaScript

## 简介

Pi Coding Agent extension: registers the notify / get_messages / check_message_status / check_responses_* tools that talk to the agent-notify macOS notification server (TTS audio alerts, iTerm2 inline images, agent-to-agent message stream).
