# pi-pipelines

> 标签: agent-loops, agentic, ai-agents, llm, multi-agent, orchestration, pi, pi-coding-agent, pi-package, pipelines, review-loops, self-refine, workflows

## 简介

Predefined, reusable agent loops for Pi: declarative YAML pipelines with review gates, scoring, and goal-loop convergence. Built on pi-subagents.
