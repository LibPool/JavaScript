> 标签: cli, dashboard, developer-tools, development-workflow, electron, go, nodejs, port-management, project-management, project-tracker, python, rest-api, rust, script-runner, terminal-ui, test-detection

## 简介

Cross-platform project management dashboard for tracking local development projects. Features CLI, Terminal UI, Desktop app, REST API, and built-in tools for test detection, port management, and script execution.
