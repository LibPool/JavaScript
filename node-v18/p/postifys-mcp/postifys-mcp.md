# postifys-mcp

> 标签: facebook, instagram, linkedin, mcp, model-context-protocol, n8n, pinterest, postifys, social-media, tiktok, youtube

## 简介

Official Postifys MCP server: publish to Facebook, Instagram, YouTube, Pinterest, LinkedIn, and TikTok via the production Postifys API. Includes media upload and Content Queue tools.
