# poi-plugin-auto-login

> 标签: auto-login, credentials, kancolle, poi-plugin

## 简介

A poi plugin for automatically filling KanColle login credentials. Designed for switching between devices. Note: Credentials are stored in plaintext locally, recommended for personal devices only.
