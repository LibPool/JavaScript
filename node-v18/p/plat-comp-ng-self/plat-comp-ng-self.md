# plat-comp-ng-self

> 标签: JavaScript

## 简介

基础平台通用组件，包括顶部导航栏模块、侧边栏模块、以及环境切换模块 ## 导航栏模块 - 调用 `<app-flat-navbar [env]="env" (menuList)="onChange($event)"></app-flat-navbar>` > env: 当前环境id > menuList: 返回导航栏的所有数据信息。
