# pdf-to-printer

> 标签: electron, electron-print, invoice-printing, label-printer, node.js, nodejs-printer, pdf, pdf-printer, print-pdf, printer, rollo-printer, shipping-label, silent-print, sumatra, thermal-printer, win32, windows, zebra-printer

## 简介

Print PDF files and images to Windows printers from Node.js and Electron. Supports Zebra, Rollo, and other label printers with duplex, paper size, tray selection, and silent printing.
