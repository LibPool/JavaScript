# purifai

> 标签: backend, bounded-memory, browser, cross-site-scripting, edge-runtime, escape-html, fast, frontend, html, html-sanitizer, html-to-text, lightweight, nodejs, plain-text, polyglot, reader-text, sanitize, sanitizer, secure, security, streaming, strip-tags, transform-stream, typescript, xss, xss-prevention, zero-dependencies

## 简介

Bounded streaming conversion from untrusted HTML to readable plain text, with zero dependencies and no DOM.
