> 标签: agent-instructions, benchmarks, context-plus, kv-store, mcp, memory, memory-graph, model-context-protocol, peek-cache, pmll, q-promise, semantic-search, solution-engine

## 简介

PMLL Memory MCP Server — short-term KV cache (peek), Q-promise dedup, SQLite-backed Context+ memory graph with stable hashing embeddings, and solution engine. Designed to improve context retention and retrieval for coding agents.
