# paykit-bd

> 标签: bangladesh, bkash, nagad, payment, payment-gateway, sns, sslcommerz, tokenized-checkout, typescript, webhook

## 简介

Typed, zero-dependency payment clients for Bangladeshi gateways. bKash tokenized checkout with a correct token lifecycle and real AWS SNS webhook verification.
