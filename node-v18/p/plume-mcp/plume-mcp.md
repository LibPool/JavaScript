# plume-mcp

> 标签: agent, claude-code, editor, markdown, mcp, model-context-protocol, plume

## 简介

MCP server + CLI for Plume — the human pane for agentic coding. Open files in the Plume editor, read the user's typed steering directives, and write revisions they review as an accept/reject diff.
