# prtruth

> 标签: acceptance-criteria, ai, ci, code-review, coding-agents, developer-tools, github, github-actions, pull-request, pull-request-verification, verification

## 简介

Verify GitHub pull requests against issue acceptance criteria using deterministic evidence from CI, diffs, and repository artifacts.
