# pi-op-approval

> 标签: approval, confirmation, destructive, guard, pi, pi-extension, pi-package, safety

## 简介

Pi extension — intercepts destructive agent operations (file delete, Docker, process/service stop, Git, database, orchestrators, install/uninstall) and requires explicit user approval before execution.
