# pixsqueeze

> 标签: compress, compressor, front-end, heic, image, image-compressor, image-converter, javascript, lossy-compression, tiff, web

## 简介

JavaScript image compressor with server-side conversion for HEIC, TIFF, and other formats browsers can't read natively.
