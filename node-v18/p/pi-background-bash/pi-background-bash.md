# pi-background-bash

> 标签: ai-agent, async, background, bash, coding-agent, developer-tools, long-running-commands, pi, pi-extension, pi-package, terminal

## 简介

Pi extension that makes long-running bash commands async with background:true and automatic 30s backgrounding.
