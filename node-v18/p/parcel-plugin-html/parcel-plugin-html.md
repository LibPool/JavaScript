# parcel-plugin-html

> 标签: JavaScript

## 简介

Adds `data-src` to the list of all attributes that may produce a dependency. Supported elements are `<script>`, `<img>`, `<audio>`, `<video>`, `<source>`, `<track>`, `<iframe>` and `<embed>`.
