# paseo-readable-agent-activity

> 标签: json, paseo, paseo-plugin, readability, tool-calls

## 简介

Formatted and highlighted tool-call JSON, twenty-line previews, tool icons and the main argument on collapsed cards, for Paseo 0.8 or later. Tool cards need Full detail.
