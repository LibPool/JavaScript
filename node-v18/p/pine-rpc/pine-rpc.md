# pine-rpc

> 标签: asset-hub, eth-rpc, ethereum, json-rpc, light-client, node, pallet-revive, polkadot, smoldot, web3

## 简介

Pine Is Not an Emulator — a standalone Ethereum JSON-RPC node backed by a smoldot light client, for pallet-revive on Polkadot Asset Hub. Run it as a daemon and point ethers / hardhat / foundry / MetaMask at it.
