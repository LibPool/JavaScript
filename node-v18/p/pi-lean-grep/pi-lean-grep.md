# pi-lean-grep

> 标签: agent-tools, context-optimization, developer-tools, grep, llm-tools, pi, pi-package, productivity, search, token-optimization

## 简介

A lightweight upgrade for pi’s built-in grep. Fewer noisy results, lower token burn, and a cleaner path from search to read.
