# pdf-poppler-binaries-linux

> 标签: aws, binaries, lambda, linux, pdf, pdf2image, poppler, serverless

## 简介

Linux binaries for pdf-poppler. Includes Poppler utilities compiled for Linux (x64) with optional Xvfb support for headless environments.
