# pathurizer

> 标签: JavaScript

## 简介

URLやパスを解析し、ファイル名部やプロトコル部やフラグメント部などに分けて文字列を管理する事が出来る他、各部を変更した後にURLやパス文字列に戻したりする事が出来ます。
