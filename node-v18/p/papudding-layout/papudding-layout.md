# papudding-layout

> 标签: layout

## 简介

一个基于 Vue3 + TypeScript + Vite 的 SPA 开发骨架库，依赖 Element-Plus UI 组件与 Vuex4 进行状态管理，提供开箱即用的导航栏、侧边栏布局，适合中后台管理系统的快速原型开发。
