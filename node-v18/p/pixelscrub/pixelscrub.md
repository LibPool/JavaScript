# pixelscrub

> 标签: browser, canvas, exif, gdpr, image, metadata, privacy, resize, upload, webp

## 简介

Zero-dependency, client-side image sanitizer. Strips EXIF metadata, resizes, and re-encodes images entirely in the browser via <canvas>.
