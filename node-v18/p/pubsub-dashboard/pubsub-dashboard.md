# pubsub-dashboard

> 标签: cli, dashboard, developer-tools, gcp, google-cloud, local-first, pubsub

## 简介

Local-first developer dashboard for Google Cloud Pub/Sub — runs entirely on 127.0.0.1, authenticates via gcloud ADC, zero telemetry.
