# pi-print-stream

> 标签: cli, pi, pi-coding-agent, pi-package, stream

## 简介

Pi extension adding a --stream flag: run non-interactively and stream the turn (thinking, text, and tool activity) to stdout as it happens — no TUI, no JSON.
