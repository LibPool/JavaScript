# pi-agent-bus

> 标签: agent, bus, coordination, event-driven, messaging, orchestration, pi-agent, pi-extension, pi-package, pubsub

## 简介

Pi Extension bridging pi-agent-bus-node agents with pi.tools and pi-link. Includes the core MessageBus, Agent, and TaskQueue runtime.
