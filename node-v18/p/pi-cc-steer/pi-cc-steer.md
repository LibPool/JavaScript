# pi-cc-steer

> 标签: claude-code, pi-coding-agent, pi-extension, pi-package, queue, steering

## 简介

Claude Code-style mid-turn steering for pi: messages typed while the agent works go in together at the next tool boundary, framed for the model, editable with up or esc.
