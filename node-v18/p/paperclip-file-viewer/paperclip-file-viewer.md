# paperclip-file-viewer

> 标签: code-review, file-viewer, paperclip, plugin, review

## 简介

A Paperclip plugin for browsing and reviewing files linked to issues. Manage a review queue, approve or reject files, and keep a full review history — all from within Paperclip.
