# picard-timothee-ci-cd

> 标签: JavaScript

## 简介

Ce projet est un formulaire Next.js qui effectue une vérification des données saisies par l'utilisateur avant soumission. Il s'agit d'un projet web avec des fonctionnalités de validation côté client et, si nécessaire, des appels à des APIs pour la validat
