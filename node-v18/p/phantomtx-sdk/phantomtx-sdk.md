# phantomtx-sdk

> 标签: JavaScript

## 简介

**PhantomTX** is a client-side transaction obfuscation SDK for EVM-based chains. It enables users to "ghost" their transactions by mixing in dummy txs with randomized gas, delay, and nonce — without requiring relayers or mixers.
