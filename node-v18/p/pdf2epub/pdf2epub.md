# pdf2epub

> 标签: cli, converter, ebook, epub, markdown, marker-pdf, ocr, pdf, pdf-to-epub, pdf2epub

## 简介

CLI wrapper that installs and runs overcuriousity/pdf2epub: convert PDF files to structured Markdown and EPUB with AI layout detection (marker-pdf). Bootstraps its own Python environment on first run.
