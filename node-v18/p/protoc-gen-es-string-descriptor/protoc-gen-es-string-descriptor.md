# protoc-gen-es-string-descriptor

> 标签: buf, codegen, diff-friendly, file-descriptor, protobuf, protoc-gen-es

## 简介

A protoc-gen-es drop-in replacement that makes file descriptors diff-friendly by splitting them into multi-line raw byte string literals
