# preact-old-types

> 标签: components, dom diff, framework, front-end, preact, react, ui, user interface, vdom, virtual dom

## 简介

Fork of preact which uses types from 10.24.3, but dist from 10.28.1. This fixes some bugs, while not breaking backwards type compatibility.

- 官网：https://preactjs.com/
- 源码仓库：https://github.com/preactjs/preact.git
- npm 页面：https://www.npmjs.com/package/preact-old-types
