# pointsbuild

> 标签: react

## 简介

* @param {number} cartesianMaxY y轴最大值，默认为0，表示DOM定位方式 * @param {number} width 占位宽度 * @param {number} height 占位高度 * @param {bool} multi 多点连续输出，默认单点输出 * @param {string} formatter 数据输出格式，使用${x}${y}占位 * @param {url} background 占位背景 * @param {json} style 占位styl
