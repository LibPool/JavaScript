# pex

> 标签: cli, pex, plask

## 简介

Pex is a javascript 3d library / engine allowing for seamless development between Plask and WebGL in the browser.

## 官网

- 官网：https://github.com/pex-gl/pex
- 源码仓库：git+https://github.com/pex-gl/pex.git
