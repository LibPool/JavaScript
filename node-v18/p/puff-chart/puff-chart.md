# puff-chart

> 标签: bar, canvas, chart, charts, echarts, line, on-demand, pie, radar, tree-shaking

## 简介

Lightweight JavaScript chart library inspired by ECharts. Canvas 2D based, zero dependency, tree-shakable on-demand imports.
