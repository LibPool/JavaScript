# photoswipe-deep-zoom-plugin

> 标签: deepzoom, dzi, iif, pan, photoswipe, tile, zoom, zoomify

## 简介

A plugin that adds tile-based zoom support to PhotoSwipe. Supports Deepzoom and Zoomify tile formats.
