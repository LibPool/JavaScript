# p2p-chplayer

> 标签: JavaScript

## 简介

网页视频播放器，html5优先，兼容移动端，支持mp4,flv,f4v以及m3u8格式，支持rtmp。支持点播和直播 官网：http://www.chplayer.com 演示：http://www.chplayer.com/down/v1.0/
