# pdf-direct-print

> 标签: pdf-print, pdf-print-support, pdf-support

## 简介

PDF direct print support for non-chromium browsers (browsers that does not support direct print of pdf). This package can be used to print a pdf directly to the printer machine without need to download.

- 源码仓库：https://github.com/sirajwebs
- npm 页面：https://www.npmjs.com/package/pdf-direct-print
