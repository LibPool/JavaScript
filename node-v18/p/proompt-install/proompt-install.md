# proompt-install

> 标签: ai-agent, claude-code, mcp, proompt, scaffold

## 简介

Drop Proompt's steering substrate (anchored spec + MCP servers + universal skills) into any repo. Runs inside Claude Code on your own subscription — no separate AI bill. `init` to install, `update` to refresh.
