# pqdx-conformance

> 标签: developer-tools, governance, pqdc, pqdx

## 简介

pqdx-conformance — Canonical conformance test fixture set for any pqdx universal state protocol implementation in any language. Apache 2.0, separately versioned from any specific implementation.
