# pi-herdr-doc-review

> 标签: extension, herdr, nvim, pi, pi-coding-agent, pi-package, review, spec, vim

## 简介

Review the documents your pi agent writes in an editable nvim or vim pane beside it in Herdr: proposed specs open on their own, agent edits reload live, and your saved edits go back to the agent as a diff without blocking it
