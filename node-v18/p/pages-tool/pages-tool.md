# pages-tool

> 标签: JavaScript

## 简介

pages-tool是一个辅助uni-app的pages.json配置文件的开发工具。 该工具只为简化开发人员工作,优化多人开发模式,负责将pages.json中的配置分解再合并的自动化工作。 解决pages.json混乱的问题，pages.json 可通过监听初始化的配置文件然后将配置文件自动合并同步。
