# perfstack

> 标签: dashboard, express, memory, mern-packages, merndev, mongodb, nodejs, npm-pm, observability, performance, perfstack, profiling, tracing, typescript

## 简介

Fullstack performance profiler: HTTP latency, slow MongoDB queries, memory snapshots, span tracing, and a built-in dashboard endpoint.
