# proxyconfdump

> 标签: backup, cli, export, nginx-proxy-manager, reverse-proxy, self-hosted, sqlite

## 简介

Read-only export of a self-hosted Nginx Proxy Manager SQLite database into sorted, secret-free JSON that you can commit to a git repository.
