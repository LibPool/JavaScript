# playmix

> 标签: audio, editor, headless, mixdown, playback, scheduler, timeline, video, web-audio

## 简介

Headless multi-track playback engine for the browser. Plays a timeline through the browser's own decoders and renders it offline through the same mix model, so preview and export cannot drift apart. Zero dependencies, framework-agnostic, SSR-safe.
