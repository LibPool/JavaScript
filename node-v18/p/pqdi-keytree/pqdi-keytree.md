# pqdi-keytree

> 标签: developer-tools, governance, pqdc, pqdx

## 简介

pqdi-keytree — Rust reference implementation of the pqdi-keytree hierarchical key-derivation spec (non-BIP-39-rooted, HKDF with string identifiers). Apache-2.0; backend-agnostic core. Backends below.
