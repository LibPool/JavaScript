# pyui-official

> 标签: JavaScript

## 简介

components 文件下分为 Common Form Table ViewPage       Common 存放按钮 和弹窗 以及抽屉       Form Table ViewPage 文件夹下的self存放自己的文件       Form Table ViewPage 文件夹下的components存放自己的子组件，每个子组件必须使用文件夹来存放自己的文件，且必须存在index.ts导出自己的vue组件，        必须有types.ts文件导出自己组件的参数
