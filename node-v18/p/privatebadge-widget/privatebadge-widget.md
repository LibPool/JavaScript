# privatebadge-widget

> 标签: JavaScript

## 简介

The **PrivateBadge Widget** is an open, embeddable JavaScript SDK for verifying user eligibility — such as age or jurisdiction — using the [PrivateBadge protocol](https://github.com/privatebadge/privatebadge-spec).
