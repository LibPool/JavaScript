## 简介

```   "postcss-px-to-viewport":{       viewportWidth: 750,      // 视窗的宽度，对应的是我们设计稿的宽度，一般是750         viewportHeight: 1344,    // 视窗的高度，根据750设备的宽度来指定，一般指定1334，也可以不配置。       unitPrecision: 3,        // 指定`px`转换为视窗单位值的小数位数（很多时候无法整除）。       viewportUnit: 'vw'
