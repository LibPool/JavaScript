# playback-web-middleware

> 标签: JavaScript

## 简介

A "middleware" which serves as the glue between [playback-web-player](https://github.com/getndazn/playback-web-player) (the player library) and the catalogue "chapter" of any target application which is built upon the web stack (HTML/CSS/JavaScript).
