# pi-lossless

> 标签: coding-agent, context, lcm, memory, pi, pi-package

## 简介

Lossless Context Management for the Pi coding agent: long sessions keep working past the point where the model would forget, and every verbatim message stays searchable and readable (lcm_grep / lcm_describe / lcm_expand_query).
