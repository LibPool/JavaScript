# password-virtual-keyboard-vue

> 标签: keyboard, password, virtual, vue

## 简介

``` 本组件是在闲暇之余随便写的一个简单的密码模拟键盘，支持数字、特殊字符、字母大小写，同时目前还未正式完善，因此在有时间的情况下会进行补充完善 ```
