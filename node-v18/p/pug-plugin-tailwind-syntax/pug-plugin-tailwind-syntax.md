# pug-plugin-tailwind-syntax

> 标签: eleventy, plugin, pug, regex, syntax, tailwind, tailwindcss

## 简介

A Pug plugin that allows you to use Tailwind CSS arbitrary values, fractions, and responsive modifiers in Pug's dot notation.
