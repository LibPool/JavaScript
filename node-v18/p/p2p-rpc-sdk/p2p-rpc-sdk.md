# p2p-rpc-sdk

> 标签: JavaScript

## 简介

The p2prpc SDK is a JS/TS library for connecting to the [p2prpc](https://github.com/jungoai/p2p-rpc) network, a decentralized peer-to-peer layer for blockchain RPCs.
