# pi-pam

> 标签: architecture, cartography, maps, monorepo, pi-package, pi-skill

## 简介

Project Architectural Maps — living, multi-layer cartography for monorepos. A Pi skill that maintains visual maps, significance ratings, dependency graphs, and third-party repo evaluation.
