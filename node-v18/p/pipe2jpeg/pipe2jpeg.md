# pipe2jpeg

> 标签: ffmpeg, image2pipe, jpeg, mjpeg, mpjpeg, singlejpeg

## 简介

Parse individual jpegs from an ffmpeg pipe when output codec is set to mjpeg and format is set to image2pipe, singlejpeg, mjpeg, or mpjeg.
