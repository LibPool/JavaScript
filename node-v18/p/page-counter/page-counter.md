# page-counter

> 标签: analysis, blog, bomb, counter, es6, leancloud, pv, serverless

## 简介

基于Serverless开发的的极简网页计数器，支持基于Hexo、Jekyll、Octopress、ReactJS、VueJS等框架开发的博客、网站、中后台等任何应用。
