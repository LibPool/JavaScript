# passport-minter

> 标签: JavaScript

## 简介

Minter command is a tool for minting pending Sapien passports. General flow: 1. Read from database pending passports to be minted 2. Prepare transactions in batches 3. Call Passport contract with addresses belonging to a batch 4. Update passport metadata
