# parcel-plugin-tensorflowjs-blob

> 标签: blob, inline, machine-learning, parcel, parcel-bundler, parcel-plugin, script tag, tensorflow, tensorflowjs

## 简介

Inline TensorFlowJS models in your app bundle. Simply import weight manifest .bin file and get associated model.json as a blob URL
