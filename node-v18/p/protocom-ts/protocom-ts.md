# protocom-ts

> 标签: JavaScript

## 简介

A TypeScript library for building protocol-based REST and JSON-RPC servers and clients, inspired by Python frameworks like Flask and FastAPI. Includes decorators, middleware, error handling, and type-safe client/server abstractions.
