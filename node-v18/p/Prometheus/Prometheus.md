# Prometheus

> 标签: canvas, html, javascript

## 简介

> 普罗米修斯，canvas渲染动画平台库，使用flash as3模式构建的，利用canvas这一特性， 作为motion场景，类似 flashplayer平台，进行舞台渲染动画，可以放入外部图片，内置多边形，矩形，圆形，三角形等对象 目前是初始版本
