# push-liquid-action

> 标签: cleos, dsp, eos, eosio, liquidapps

## 简介

A simple tool for pushing actions from a [LiquidAccount](https://docs.liquidapps.io/en/v2.0/developers/vaccounts-getting-started.html) onto a [DSP](https://docs.liquidapps.io/en/v2.0/dsps.html)
