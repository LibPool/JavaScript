# playwright-failure-rate-monitor

> 标签: environment-resilience, failure-rate, monitoring, playwright, reporter, testing

## 简介

A Playwright reporter that monitors test failure rates in real-time and terminates execution if the failure rate exceeds a configurable threshold.
