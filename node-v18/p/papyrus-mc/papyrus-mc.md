# papyrus-mc

> 标签: JavaScript

## 简介

Currently, the mod can perform authentication, download all needed assets and launch for both vanilla and Fabric. It has been confirmed to work with 1.19.3 and most recent versions *should* work however legacy versions do not work yet.
