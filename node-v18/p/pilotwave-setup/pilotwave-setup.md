# pilotwave-setup

> 标签: ai-agent, automation, browser, claude, cursor, mcp, pilotwave

## 简介

One-command setup for Pilotwave — installs the native host and configures your AI tools (Claude Code, Cursor, VS Code, Windsurf, Continue, JetBrains, Zed)
