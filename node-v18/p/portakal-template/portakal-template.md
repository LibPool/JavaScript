# portakal-template

> 标签: label, label-printer, printer, receipt, template, thermal-printer, tsc, tspl, typescript, zpl

## 简介

Percentage-layout label templates on top of portakal-lite. Declarative JSON template + data → TSC/TSPL2 + ZPL II printer-ready strings, with auto-scaling layout. Device-agnostic: the label size/DPI are supplied at compile time, not stored in the template.
