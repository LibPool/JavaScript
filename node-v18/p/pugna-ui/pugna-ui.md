# pugna-ui

> 标签: accessible, admin, css, dark-mode, dashboard, design-system, design-tokens, framework-agnostic, headless

## 简介

A framework-agnostic design system: themeable CSS, design tokens, and headless behaviors that work in any SSR or CSR app.
