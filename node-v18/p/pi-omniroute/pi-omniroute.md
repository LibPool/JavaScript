# pi-omniroute

> 标签: ai, extension, gateway, llm, omniroute, openai-compatible, pi, pi-package, provider, proxy, router

## 简介

OmniRoute provider extension for pi — one self-hosted gateway endpoint routing 350+ AI providers (Claude, GPT, Gemini, Kimi, GLM, DeepSeek, MiniMax, …) with free tiers, quota-aware auto-fallback, and token compression.
