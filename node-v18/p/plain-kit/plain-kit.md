# plain-kit

> 标签: JavaScript

## 简介

- 管理后台生态圈   - 推荐直接使用管理后台脚手架搭配代码生成器 可以做到开箱即用   - 文档略长 是考虑到了开发中个性化的方方面面 尽可能实现动态可配 照顾到各种特殊情况 - 趁手小型组件 - 常用工具函数
