# pi-init-extension

> 标签: agents, agents.md, init, pi, pi-package, scaffold

## 简介

Scaffold AGENTS.md for the current project. Detects project type (Next.js, React, Vue, Node, Python, Go, Rust, .NET) and writes a stack-appropriate template.
