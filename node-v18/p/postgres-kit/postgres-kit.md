# postgres-kit

> 标签: pg, pg kit, pg-kit, postgres, postgres kit, postgres-kit, postgresql, sql

## 简介

postgres-kit is a lightweight and easy-to-use PostgreSQL client library for Node.js, providing a simple and intuitive API for interacting with PostgreSQL databases.
