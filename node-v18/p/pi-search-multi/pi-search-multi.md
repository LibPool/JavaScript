## 简介

Unified web search + content extraction extension for pi with 12 backend providers — DuckDuckGo, Jina AI, Marginalia, Serper, Brave, Tavily, Exa, Firecrawl, LangSearch, WebSearchAPI.ai, Perplexity Sonar, and SearXNG. RRF combine mode, env/shell credential
