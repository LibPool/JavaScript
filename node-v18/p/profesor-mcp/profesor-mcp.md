# profesor-mcp

> 标签: claude, explicacion, llm, mcp, model-context-protocol, pedagogia

## 简介

Servidor MCP que impone una prosa clara, directa y explicativa: cinco moldes de explicacion (clasico, Cornell, Feynman, manual, libre) con dialogo interactivo.
