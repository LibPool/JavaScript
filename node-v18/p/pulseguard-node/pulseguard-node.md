# pulseguard-node

> 标签: bug-tracking, error-tracking, monitoring, observability, pulseguard, security

## 简介

Drop-in automatic bug and threat monitoring for Node.js apps. Reports uncaught exceptions and unhandled rejections to PulseGuard automatically.
