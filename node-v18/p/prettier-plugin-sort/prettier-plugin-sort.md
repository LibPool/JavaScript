# prettier-plugin-sort

> 标签: imports, order, organize, package.json, plugin, prettier, prettier-plugin, sort, tsconfig

## 简介

A Prettier plugin for sorting ES module imports, export specifiers, and fields in package.json and tsconfig.json.
