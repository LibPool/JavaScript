# postcss-enumerates-in-line

> 标签: compile, css, minify, postcss, postcss-plugin, syntax

## 简介

This [PostCSS] plugin extend to multiple CSSes from shrinked it which described in 1 line like `@apply` syntax of TailwindCSS.
