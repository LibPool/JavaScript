# pi-cost-lens

> 标签: billing, cost, currency, pi, pi-coding-agent, pi-package, pricing, tui

## 简介

Pi 编码代理的模型 API 费用统计与本地货币显示扩展：按厂商官方价格（人民币/美元）重新计算真实 Token 费用，支持峰谷、阶梯、缓存、推理与自定义价格。
