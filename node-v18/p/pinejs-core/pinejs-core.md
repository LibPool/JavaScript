# pinejs-core

> 标签: alpinejs, cdn, declarative, fine-grained, lightweight, micro-framework, reactivity, signals

## 简介

Next-generation fine-grained reactive declarative micro-framework for the modern web with CDN support, signals, and ultra-fast DOM updates.
