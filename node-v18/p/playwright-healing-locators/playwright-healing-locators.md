# playwright-healing-locators

> 标签: auto-heal, automation, e2e-testing, fallback, healing, playwright, resilient, selectors, test-stability, testing

## 简介

A robust helper library for Playwright that improves test stability by automatically resolving broken selectors through fallback strategies and auto-healing.
