# pi-bimface-web

> 标签: bimface

## 简介

基本BIMFACE的功能封装工具库，主要为了解决BIMFACE执行流程的代码赘余，集成常见的基础功能，包含构件绘色、构件定位、模型缩放等等，最大化提高BIMFACE的开发效率 # 基于BIMFACE的底层API封装
