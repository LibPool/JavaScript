# passport-magic-code

> 标签: Authentication, LoginStrategy, MagicCode, MagicLogin, OneTimePassword, Passport, PassportStrategy, otp

## 简介

A passwordless passport strategy to send a magic code (One time password) to let the user authenticate themselves.
