# payload-access-control

> 标签: access-control, payload, payloadcms, permissions, plugin, rbac, roles

## 简介

Role-based access control plugin for Payload CMS 3 — Roles collection with permission matrix UI, role/isAdmin fields on your auth collection, admin-panel gate that keeps roleless users out, and ready-made access helpers.
