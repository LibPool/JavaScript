# pdf-to-json-converter

> 标签: canvas, document-parsing, extract-pdf, invoice-parser, json, parse-pdf, pdf, pdf-editor, pdf-extraction, pdf-layout, pdf-parser, pdf-to-json, pdf-to-json-converter, pdfjs, pdfjs-dist, text-extraction, typescript

## 简介

A high-fidelity, structural, and color-aware PDF parsing engine. Extract perfectly-segmented 1:1 document layouts into structured JSON for PDF editors, invoices, and data extraction.
