# prettier-plugin-pascal

> 标签: code-formatter, code-style, delphi, developer-tools, formatter, formatting, fpc, freepascal, lazarus, object-pascal, pascal, prettier, prettier-plugin, source-code

## 简介

A modern, opinionated Prettier plugin that automatically formats Pascal code—including Delphi, Object Pascal, Free Pascal, and Lazarus—with fast, consistent, and reliable styling for a seamless development experience.
