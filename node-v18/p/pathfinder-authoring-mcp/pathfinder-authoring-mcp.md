# pathfinder-authoring-mcp

> 标签: authoring, claude, mcp, model-context-protocol, pathfinder

## 简介

MCP server bridging an AI client (Claude Desktop/Code) to the Pathfinder authoring API for creating use cases and templates as drafts.
