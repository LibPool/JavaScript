# php-bulk-installer

> 标签: bulk, php, php-bulk, portable, static-php-cli

## 简介

Automatically installs the latest portable PHP (bulk on Linux/Mac, Windows vs16 ZIP, with configured php.ini).

## 官网

- npm 页面：https://www.npmjs.com/package/php-bulk-installer

## 历史版本号

- 当前版本：1.1.2

- 1.1.2

## 获取地址

- npm 安装：`npm install php-bulk-installer`
- npm registry：https://registry.npmjs.org/php-bulk-installer
