# pk-validators-react

> 标签: cnic, input, pakistan, passport, phone, react, react-hook-form, validation, zod

## 简介

React hooks, masked input components, and Zod/react-hook-form resolvers for Pakistani CNIC, phone, and passport validation. One install — no separate core/resolvers packages required.
