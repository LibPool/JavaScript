# paidcrawer-tasks

> 标签: JavaScript

## 简介

投研任务 CLI：飞书(哈勃小助手)登录后，创建 onetimeCompany/trackCompany 抓取任务。登录一次、后续自动带用户身份。也可被 agent 作为库调用。
