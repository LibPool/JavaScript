# pi-material-black-simple

> 标签: dark-theme, material, pi, pi-coding-agent, pi-extension, pi-package, pi-theme, theme, tui

## 简介

Material black theme for the pi coding agent - near-black UI, green user messages, and a highlighted final answer so you can see where a run ended at a glance.
