> 标签: agent-skill, ai-agent, claude, claude-desktop, cursor, direct-mail, handwritten, mcp, mcp-server, model-context-protocol, openclaw, physical-mail, postals, postcards, usps

## 简介

Postals — the agent skill that turns any AI into a direct mail machine. One MCP tool call mails a physical handwritten postcard (real pen-and-ink, USPS 3-5 day delivery, $4.99 per card). Works with Claude Desktop, Cursor, Claude Code, OpenClaw, n8n, LangC
