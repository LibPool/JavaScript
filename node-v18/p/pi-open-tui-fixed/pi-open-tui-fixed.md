# pi-open-tui-fixed

> 标签: pi, pi-coding-agent, pi-extension, pi-package, starship, theme, tui

## 简介

Fork of pi-open-tui for the Pi coding agent: same TUI, but working-state refresh defaults to event-driven so terminal scrollback stays stable while the model works.
