# pulseflow-mcp

> 标签: dart, devtools, flutter, mcp, modelcontextprotocol, performance, profiling, pulseflow

## 简介

MCP server for PulseFlow — let coding agents (Cursor, Claude, Command Code) read a live Flutter performance session and find, fix, and verify problems.
