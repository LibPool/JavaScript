# payload-ai-conductor

> 标签: agent, ai, chatbot, cms, mcp, model-context-protocol, payload, payload-plugin, payloadcms

## 简介

Compose and edit Payload CMS pages through a chat agent grounded in your block library — with an in-panel BYOK chat and a standalone MCP server, both backed by the same propose-then-approve tool layer.
