# pino-api-logger

> 标签: api, api-logger, archive, archive-logs, bun, daily-rotation, logger, logging, logs, node, pino, self-hosted

## 简介

Self-hosted server-side API logger with multi-stream writing (to console and file), daily rotation, buffered writes, and monthly archiving for Node/Bun projects.
