# pewjs

> 标签: JavaScript

## 简介

Pew.js is a tiny progressive enhancement library whose main concern is to enhance HTML DOM fragments with Javascript objects while respecting the separation of concerns principles. That means that you can leave your HTML untouched, and let Pew enhance it
