# pi-web-console

> 标签: cli, coding-agent, pi, pi-package, pi.dev, rpc, web-ui, websocket

## 简介

把 Pi CLI（pi.dev）的全部能力通过 Web UI 暴露出来 —— 后端为每个会话孵化 pi --mode rpc 子进程做 JSONL 双向桥接，Web 前端经 WebSocket 与之对话，原生复用 Pi 全部能力。

## 官网

- npm 页面：https://www.npmjs.com/package/pi-web-console

- 1.0.0

## 获取地址

- npm 安装：`npm install pi-web-console`
- npm registry：https://registry.npmjs.org/pi-web-console
- Node 要求：>=18.17
