# plugin-auditor

> 标签: JavaScript

## 简介

审计插件的插件：按 dsh-plugin-authoring 规范静态审查任意 DSH 插件（组件形状/效应/依赖/错误/信号/cwd/安全/清单/测试），输出 PASS/WARN/FAIL 报告
