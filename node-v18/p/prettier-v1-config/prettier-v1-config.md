# prettier-v1-config

> 标签: JavaScript

## 简介

Use this shared configuration file if you need to update to prettier@2, but would like to continue use prettier@1 configuration - Prettier docs for sharing configuration file https://prettier.io/docs/en/configuration.html#sharing-configurations - Prettier
