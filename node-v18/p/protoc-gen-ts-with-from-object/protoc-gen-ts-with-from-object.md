# protoc-gen-ts-with-from-object

> 标签: TypeScript, gRPC, grpc-tools-node-protoc-ts-with-from-object, protobuf, protoc

## 简介

Generate .d.ts definitions for the generated JavaScript files from grpc_tools_node_protoc, ensuring that the fromObject method is included in the definition file.
