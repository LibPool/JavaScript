# payt-mcp

> 标签: claude, cursor, debt-collection, mcp, model-context-protocol, payments, payt, paytsoftware

## 简介

Model Context Protocol server for the Payt (paytsoftware.com) Public API v1. Lets MCP-compatible clients (Cursor, Claude Desktop, etc.) call Payt endpoints as tools.
