# particulus

> 标签: 3d, animation, canvas, morph, obj, particle-system, particles, point-cloud, react, rotation, svg, visualization, web-component, webgl

## 简介

Particle system that morphs between shapes — SVG paths, text, images, OBJ models — with 3D rotation, a WebGL renderer and a Canvas2D fallback.
