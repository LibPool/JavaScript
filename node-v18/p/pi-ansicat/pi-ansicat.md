# pi-ansicat

> 标签: ansi, clipboard, coding-agent, foot, image, pi, pi-extension, pi-package, preview, terminal, truecolor, vision, wayland, x11

## 简介

Paste clipboard images into the pi coding agent with a truecolor ANSI preview and a vision fallback for text-only models
