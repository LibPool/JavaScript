# payment-token-efi

> 标签: API, Efí, cartão de crédito, payment_token, token de pagamento

## 简介

Módulo Javascript que permite a criptografia dos dados do cartão do cartão a partir do browser do cliente para gerar o payment_token e identificar a bandeira do cartão.

## 官网

- 官网：https://dev.efipay.com.br/docs/api-cobrancas/cartao/#obten%C3%A7%C3%A3o-do-payment_token
- 源码仓库：git+https://github.com/efipay/js-payment-token-efi.git
- npm 页面：https://www.npmjs.com/package/payment-token-efi
