# poc-kit

> 标签: cli, demo, design-system, mockup, offline, poc, proof-of-concept, prototype, wireframe

## 简介

Build one self-contained, offline, design-system-styled interactive POC from a requirement — mocked logic, verified by driving it in a headless browser.
