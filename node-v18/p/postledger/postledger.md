# postledger

> 标签: accounting, ai-agent, append-only, audit-trail, benford, bookkeeping, claude, cli, double-entry, general-ledger, idempotency, idempotent, ledger, llm, mcp, mcp-server, model-context-protocol, plaintext-accounting, sqlite, tamper-evident

## 简介

Double-entry bookkeeping that assumes the bookkeeper is not trustworthy. Idempotent writes, append-only journal, DB-enforced balance, tamper-evident hash chain. Unix CLI + MCP server. Zero dependencies.
