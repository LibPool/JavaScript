# promptlock-cli

> 标签: claude-code, cli, codex, coding-agent, cursor, focus, hooks, macos, promptlock, screen-time

## 简介

PromptLock for the Mac: watches Cursor, Claude Code and Codex, and tells your iPhone when an agent is working so it can unlock your apps only while one is.
