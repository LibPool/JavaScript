# postcss-custom-prop-vars

> 标签: JavaScript

## 简介

Write [CSS Custom properties](https://developer.mozilla.org/en-US/docs/Web/CSS/--*) using SASS variable syntax. They remain dynamic and have all the strengths of CSS properties, they're just a bit easier to type.
