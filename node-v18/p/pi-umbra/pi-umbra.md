# pi-umbra

> 标签: meta, pi-extension, pi-package, pi-theme, tui

## 简介

Every small thing pi does not build in, in one install: seven themes and the chrome around them, the input bar, session rename, a shimmer through the working indicator, mid-prompt skill completion, ask, copy-chat, preview and help.
