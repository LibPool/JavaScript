# playwright-injected

> 标签: DOM, accessibility, aria, codegen, getByRole, getByTestId, getByText, locator, playwright, selector, testing

## 简介

Playwright's browser-side engine (InjectedScript, selector engine, locator utils, accessibility/ARIA utils, DOM utils) extracted as a standalone module.
