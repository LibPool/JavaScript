# packet-cli

> 标签: config, esbuild, eslint, overboost, package.json, packet, prettier, tsconfig, unified

## 简介

Unified project configuration manager: combine package.json, tsconfig, eslint, prettier into a single packet.ts / packet.json or embedded package.json with overboosted build system
