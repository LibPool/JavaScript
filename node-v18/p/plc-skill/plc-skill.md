# plc-skill

> 标签: agent-skills, claude-code, openclaw, opencode, plc

## 简介

> 生产级的工业控制编程 AI Agent 技能。采用“通用工程 + 品牌特化”的双层架构，既能处理通用的 IEC 61131-3 逻辑，又能为西门子、罗克韦尔、三菱、欧姆龙等主流 PLC 品牌提供深度、准确的路由和规范。
