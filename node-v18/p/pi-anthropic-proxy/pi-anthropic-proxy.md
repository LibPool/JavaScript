# pi-anthropic-proxy

> 标签: anthropic, claude, pi-agent, pi-coding-agent, pi-package, provider, proxy

## 简介

Pi coding agent provider extension exposing an Anthropic-compatible proxy (via ANTHROPIC_BASE_URL / ANTHROPIC_API_KEY) with Claude Sonnet 5, Opus 5, and Haiku 4.5 models.
