# primecaptcha

> 标签: captcha, captcha-generator, fast-captcha, human-verification, image-captcha, math-captcha, node-captcha, security

## 简介

High-performance, buffer-first image captcha library for Node.js. Zero disk I/O, crypto-secure randomness.
