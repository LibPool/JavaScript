# @5minds/node-red-openapi-generator

> 标签: node-red, open-api, swagger

## 简介

A set of tools for generating OpenAPI3/Swagger documentation based on the HTTP nodes deployed in a flow. An updated version of the Node-RED Swagger Documentation Generator to support OpenAPI3, based of the @digital-tvilling/node-red-openapi-generator.
