# @aura3d/lean

> 标签: aura3d, browser-3d, game-runtime, gltf, typescript, webgl2

## 简介

Lean Aura3D browser runtime for production rendering, typed glTF products, and deterministic arcade games without physics, navigation, editor, or Node media dependencies.
