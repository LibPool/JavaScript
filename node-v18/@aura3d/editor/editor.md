# @aura3d/editor

> 标签: 3d, 3d-editor, aura3d, browser-3d, editor, gizmos, inspector, picking, play-mode, selection, typescript, web-3d

## 简介

Canonical Aura3D editor package exposing runtime editor commands, selection, picking, inspector models, play mode, and transform gizmos.
