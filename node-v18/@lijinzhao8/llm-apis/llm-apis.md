# @lijinzhao8/llm-apis

> 标签: api-proxy, llm, load-balancer, local-proxy, multi-account, openai-compatible

## 简介

极度轻量化的本地大语言模型 API 代理。无需服务器，开机即用。支持多账号池化、负载均衡、用量监控。
