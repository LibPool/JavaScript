# @silviosln/tenant-guard

> 标签: multi-tenancy, mysql, postgres, rls, row-level-security, security, sql, tenant

## 简介

Lightweight, framework-agnostic multi-tenancy library for Node.js. Manages tenant context, intercepts SQL queries to inject security scopes, and automates database connection switching.
