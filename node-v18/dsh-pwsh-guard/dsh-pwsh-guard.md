# dsh-pwsh-guard

> 标签: coding-agent, cordis, deepseek-harness, dsh, dsh-plugin, powershell, tool-guard

## 简介

DSH (DeepSeek Harness) plugin: reject shell text I/O - Select-String, Get-Content, findstr, rg, cat, node -e - in pwsh/bash/ops_bash, and point the agent at read/grep/glob.
