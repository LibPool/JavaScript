# pi-image-paste-cards

> 标签: attachments, clipboard, image, paste, pi, pi-extension, pi-package, screenshot, wsl, wslg

## 简介

Paste clipboard images into pi as real attachments, with OMP-style 📷 #N chips and rounded preview cards, from Windows Terminal/WSLg, Wayland, X11 or an OSC 5522 terminal.
