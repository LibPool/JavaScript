# @frixaco/anitrack

> 标签: JavaScript

## 简介

1. Install [Bun](bun.sh) 2. Install [mpv](github.com/mpv-player/mpv) player. 3. (Optional) On desktop, set up [**Anime4K**](https://github.com/bloc97/anime4k) anime upscaler for **mpv** 4. `bunx @frixaco/anitrack`
