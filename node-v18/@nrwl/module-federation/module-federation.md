# @nrwl/module-federation

> 标签: CLI, Module Federation, Monorepo, Node, Web, Webpack

## 简介

The Module Federation plugin for Nx contains a Webpack Plugin and helpers to enable Module Federation for your Angular and React apps in your Nx Workspace.
