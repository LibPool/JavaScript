# @hotcakes/rehype-table-of-contents

> 标签: anchors, contents, headings, mdx, of, rehype, table, table of contents

## 简介

MDX plugin that (1) generates a table of contents based on headings tags found in the content, (2) converts the headings into links and (3) appends it to the mdx frontmatter
