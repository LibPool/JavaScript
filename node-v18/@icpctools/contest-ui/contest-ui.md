# @icpctools/contest-ui

> 标签: JavaScript

## 简介

Reusable [Svelte 5](https://svelte.dev) components for displaying ICPC contest data: clocks, logos, problems, judgements, floor maps, video streams, and sortable/animated tables for scoreboards and submission lists.
