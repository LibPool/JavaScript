# @kernelforge/shellcode-runner

> 标签: JavaScript

## 简介

x64 raw-shellcode harness: Windows (TEB/PEB/Ldr + synthetic kernel32/ntdll with real EATs + NT syscall surface) and Linux (syscall model) — records behavior and unpacked buffers
