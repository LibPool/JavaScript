# @lynx-js/rsbuild-plugin

> 标签: Lynx, ReactLynx, rsbuild

## 简介

An Rsbuild plugin that builds a Lynx app with the Rsbuild CLI directly, without the Rspeedy CLI.

- 源码仓库：https://github.com/lynx-family/lynx-stack.git
