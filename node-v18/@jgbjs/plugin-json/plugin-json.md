# @jgbjs/plugin-json

> 标签: JavaScript

## 简介

支持 json 编译的插件，会自动查找.json 中符合小程序引用规则的资源，例如 app.js 中的 pages 的相关四个文件、分包、 usingComponents 中的组件等资源
