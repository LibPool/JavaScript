# @spinekit/pricelist

> 标签: arc, classytic, dealer-pricing, erp, pricelist, pricing, spine

## 简介

Arc module for @classytic/pricelist — price lists + rules (dealer tiers, cost-plus markup, volume brackets) as one composable resource. BYO-engine or module-created; resolvePrice stays an in-process port for the catalog PricingBridge, never HTTP.
