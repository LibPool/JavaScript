# @spinekit/platform

> 标签: arc, classytic, config, configuration, registry, scoped-config, settings, spine

## 简介

Scoped, typed platform configuration registry for @classytic/arc apps — mongokit-native. Domain + jurisdiction packs register typed config sections (Zod); values resolve through a company→channel→branch overlay with per-field provenance; writes are target
