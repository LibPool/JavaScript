# ideascape

> 标签: 3d, claude-code, force-graph, knowledge-graph, pca, report, skill, three.js, visualization

## 简介

Turn a report or a table into an interactive 3D map: one offline HTML file you can open, explore and share. A /ideascape skill for Claude Code, Codex, Gemini CLI, Cursor and more.
