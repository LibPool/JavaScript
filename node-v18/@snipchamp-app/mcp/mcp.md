# @snipchamp-app/mcp

> 标签: ai, claude, codex, llm, mcp, model-context-protocol, snipchamp, video-editing

## 简介

Model Context Protocol (MCP) server for SnipChamp — lets Claude Desktop, Codex, and other AI tools operate on a SnipChamp video workspace (read library + transcripts, manage notes, drive the clip assembler, trigger exports) via a scoped Personal Access To
