# @metanodejs/fiai-sdk

> 标签: JavaScript

## 简介

`@metanodejs/fiai-sdk` là Kernel SDK chịu trách nhiệm thiết lập cầu nối giao tiếp bảo mật, bất đồng bộ (Request/Response & Events) giữa ứng dụng chính (Host) và các ứng dụng con trong iframe (Frames) theo giao thức bảo mật mã hóa và quản lý Service Worker
