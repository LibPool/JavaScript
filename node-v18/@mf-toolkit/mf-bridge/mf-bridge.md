# @mf-toolkit/mf-bridge

> 标签: angular, bridge, css-isolation, lazy-loading, microfrontend, module-federation, prop-streaming, react, shadow-dom, ssr-hydration, svelte, vue

## 简介

Mount microfrontend components from any Module Federation remote — lazy loading, prop streaming, bidirectional events, CSS isolation via Shadow DOM, framework-agnostic remote support, and SSR hydration bridge.
