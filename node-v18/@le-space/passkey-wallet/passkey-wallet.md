# @le-space/passkey-wallet

> 标签: account-abstraction, calibur, eip-7702, erc-4337, fhevm, p256, passkey, viem, webauthn, zama

## 简介

A passkey as the admin key of a Uniswap Calibur account (EIP-7702, ERC-4337 EntryPoint v0.8), signed with the WebAuthn DID provider's P-256 primitives, and session keys for Zama user decryption.
