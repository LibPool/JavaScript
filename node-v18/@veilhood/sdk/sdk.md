# @veilhood/sdk

> 标签: confidential-compute, consent, depin, differential-privacy, privacy, robinhood-chain, veil, x402

## 简介

Isomorphic contributor client for VEIL — seal device data on-device to the enclave epoch key with local consent enforcement, then submit to the VEIL gateway. No raw data ever leaves the device readable.
