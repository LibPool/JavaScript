# @rnet-ai/rnet-caller

> 标签: ai, browser, proxy, rnet, rnet-ai, rnet-protocol

## 简介

Frontend library for the rNet Protocol — forwards requests through the local rNet Client so AI calls use the user's token, not the developer's.
