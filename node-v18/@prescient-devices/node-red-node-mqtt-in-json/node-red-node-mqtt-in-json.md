# @prescient-devices/node-red-node-mqtt-in-json

> 标签: node-red

## 简介

MQTT input node that JSON-parses payload if possible, and optionally ignores empty topics. Paired with @prescient-devices/node-red-node-mqtt-out-json it is able to receive a whole message, not just the payload
