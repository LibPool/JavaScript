# @egistr/linkedin-mcp

> 标签: agent, ai, api, claude, linkedin, mcp, model-context-protocol, opencode, typescript

## 简介

Open-source LinkedIn MCP server for AI agents (Claude Code, OpenCode, Cursor). TypeScript, official LinkedIn API, OAuth PKCE, image upload.
