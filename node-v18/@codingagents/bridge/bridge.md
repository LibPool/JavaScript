# @codingagents/bridge

> 标签: JavaScript

## 简介

Bridge: one typed model for coding-agent sessions. Reads Claude Code, Codex, Cursor, Gemini CLI, OpenCode, Pi, Antigravity and ACP history into the same canonical events.
