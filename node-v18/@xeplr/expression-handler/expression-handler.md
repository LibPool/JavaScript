# @xeplr/expression-handler

> 标签: evaluator, expression, filter, formula, predicate, rules, xeplr

## 简介

The one formula engine for xeplr: its own parser (no eval, no dependencies), one function list, compiled-once formulas, totals over lists, AND/OR conditions. Runs in Node and the browser.
