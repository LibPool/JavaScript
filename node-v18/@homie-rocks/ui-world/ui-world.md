# @homie-rocks/ui-world

> 标签: JavaScript

## 简介

The arithmetic between a 3D world and a 2D panel: principal-axis fit, oblique ribbon projection, screen projection, marker relaxation, paint order, canvas marks and a bake/blit plate. No minimap, no colours.
