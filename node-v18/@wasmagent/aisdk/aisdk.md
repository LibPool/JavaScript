# @wasmagent/aisdk

> 标签: agent, ai, executor, llm, portable, sandbox, typescript, wasm, wasmagent

## 简介

Drop wasmagent sandbox kernels into the Vercel AI SDK as a `tool()` — edge-safe code execution with one capability manifest, no E2B / OS sandbox needed
