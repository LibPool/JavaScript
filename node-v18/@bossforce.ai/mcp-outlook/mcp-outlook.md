# @bossforce.ai/mcp-outlook

> 标签: JavaScript

## 简介

MCP server for **Outlook** (Microsoft Graph v1.0 mail). Search and read messages, send email, and list mailbox folders. Reuses `@bossforce.ai/mcp-microsoft` for the token source and Graph client.
