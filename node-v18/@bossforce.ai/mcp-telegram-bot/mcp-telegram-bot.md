# @bossforce.ai/mcp-telegram-bot

> 标签: JavaScript

## 简介

MCP server for the Telegram **Bot API** (a bot identity created via @BotFather). For acting as a personal Telegram account (MTProto), see a future `telegram-user` server — that is a different API with different auth and risks.
