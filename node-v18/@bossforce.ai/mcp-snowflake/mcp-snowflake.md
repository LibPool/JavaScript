# @bossforce.ai/mcp-snowflake

> 标签: JavaScript

## 简介

MCP server for **Snowflake**, built on the [SQL REST API v2](https://docs.snowflake.com/en/developer-guide/sql-api/index). Fetch-based — no native driver. A good fit for analytics, reporting and data lookups.
