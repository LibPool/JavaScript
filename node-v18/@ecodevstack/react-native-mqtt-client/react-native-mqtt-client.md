# @ecodevstack/react-native-mqtt-client

> 标签: android, broker, emqx, expo, expo-plugin, hivemq, internet-of-things, ios, iot, messaging, mosquitto, mqtt, mqtt-client, native-module, new-architecture, publish-subscribe, pubsub, react-native, react-native-mqtt, real-time, ssl, tls, turbo-module, websocket

## 简介

A lightweight, high-performance MQTT client for React Native with native Android and iOS support. Supports MQTT 3.1.1, TLS/SSL, QoS 0/1/2, and Expo config plugin.
