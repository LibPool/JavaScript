# @mstamp/protocol

> 标签: audit, canonicalization, crypto, ed25519, receipts, rfc8785, signing, typescript

## 简介

mstamp protocol: receipt types, RFC 8785 canonicalization, SHA-256 hashing, redaction, response validation, the fetch-interception client, and the fail-open telemetry queue.
