# @llamaranch/wizard

> 标签: cli, installer, llama.cpp, llamaranch, local-llm, wizard

## 简介

One command to set up LlamaRanch: the llama.cpp engine, models fit to your machine, config, and the desktop app. Nothing leaves the valley.
