# @payspawn/sdk

> 标签: agent, ai, base, crypto, payments, payspawn, usdc, web3, x402

## 简介

Financial infrastructure for AI agents. Wallet delegation, x402 payments, on-chain spending limits, agent-to-agent payments with signed receipts. V5.3 on Base.
