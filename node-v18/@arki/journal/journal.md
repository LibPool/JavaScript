# @arki/journal

> 标签: arki, drizzle, event-log, events, jobs, journal, postgres, projection, typescript

## 简介

A journal for Drizzle entities: every change is an immutable event row, the current state is a normal table row, and both are written in one transaction. Inline projections run in the same transaction; effects run after commit from a job table.
