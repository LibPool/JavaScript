# @arki/http

> 标签: arki, dot, hono, http, openapi, sse, streaming, typescript

## 简介

Typed HTTP for ARKI — route contracts as data, zod-validated handlers, request-scope derivers, SSE streaming, OpenAPI generation, and the DOT http() plugin.
