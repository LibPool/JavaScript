# @monitext/ndata

> 标签: error-handling, monitext, ndata, primitive, result, result-type, struct, typescript, utility

## 简介

Utility helpers for working with typed result objects and primitive data structures (Result, PrimitiveStruct, and helpers). Zero-dependency, TypeScript-first.
