# @gramstax/lmdb

> 标签: bun, database, gramstax, key-value, kv, lmdb, nodejs, repository, sub-database, transaction, typescript

## 简介

LMDB-backed key-value database with schema-declared repositories, embedded indexes, TTL, queues, and transactions. Multi-runtime (Bun, Node.js).
