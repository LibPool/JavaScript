# @ansstory/file-viewer

> 标签: ansstory, apng, bmp, docx, file-viewer, gif, heif, jpe, jpeg, jpg, mov, mp4, pdf, png, pptx, svg, vue, webm, webp, xlsx

## 简介

> - 支持多种文件: `png,apng,bmp,jpg,jpe,jpeg,gif,svg,webp,heif,mp4,webm,mov,docx,xlsx,pdf,pptx`预览的vue3组件 > - 其中`docx,xlsx,pdf,ppt`来自大佬[@vue-office](https://github.com/501351981/vue-office) > - 对于`@vue-office中pdf`不兼容的浏览器使用`embed`进行兜底
