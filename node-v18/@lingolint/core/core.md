# @lingolint/core

> 标签: i18n, icu, l10n, lint, localization, placeholders, qa, translation

## 简介

The LingoLint translation QA engine: parsers, deterministic rules, scoring and the issue model. Pure TypeScript, no I/O, runs in Node and the browser.
