# dsh-remote-local-plugin

> 标签: deepseek-harness, dsh, dsh-plugin, remote-development, ssh

## 简介

DSH remote-development local plugin: host registry, SSH tunnels, remote workspace/session discovery, an authenticated Connection RPC surface, agent tools, and a Settings page.
