# @bytesalt/qtumjs-lib

> 标签: bitcoin, qtum, qtumjs, smart contract

## 简介

An extend lib for bitcoinjs-lib, it supports two new network of qtum and qtum-testnet, and it can generate contract creating and sending transactions
