# @jjspscl/nestjs-slack

> 标签: JavaScript

## 简介

- Used in many production workloads. - Building blocks with [slack-block-builder]. - Supports sending messages directly to Slack Web API. - Supports Slack webhooks. - Supports Google Logging.
