# @bimetal/alerting

> 标签: alerting, event-driven, headless, notifications, rules

## 简介

Alert engine + orchestrator: pure rule evaluation (host-driven clock tick, no scheduler in core) wiring domain events to the @bimetal/alert-data lifecycle and pluggable @bimetal/channel delivery. Idempotent — replay never re-delivers.
