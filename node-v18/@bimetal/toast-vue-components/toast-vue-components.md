# @bimetal/toast-vue-components

> 标签: components, feedback, notification, snackbar, toast, vue

## 简介

Default Vue 3 toast viewport — queue, auto-dismiss, pause-on-hover, variants, positioning, a11y. A thin binding over the canonical toast controller. No domain dependency (no calendar, no undo/redo).
