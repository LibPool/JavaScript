# @bimetal/whiteboard-headless

> 标签: canvas, controller, drag, framework-agnostic, headless, undo, whiteboard

## 简介

Canonical, framework-agnostic whiteboard controller (createWhiteboardController) on @bimetal/headless-core. Owns all free-canvas interaction semantics — shape drag/resize, marquee + multi-select, z-order, the edit dialog, keyboard nudge, undo — in LOGICAL
