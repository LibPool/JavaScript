# @bimetal/toast-svelte-components

> 标签: components, feedback, notification, snackbar, svelte, toast

## 简介

Default Svelte 5 toast viewport — canonical .bm-toast* render layer over the headless controller: queue, auto-dismiss, pause-on-hover, variants, positioning, a11y. Bound-only (the app owns the controller it pushes to).
