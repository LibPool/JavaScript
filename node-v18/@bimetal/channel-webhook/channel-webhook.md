# @bimetal/channel-webhook

> 标签: alerting, channel, http, notifications, webhook

## 简介

Generic HTTP-POST webhook adapter for @bimetal/channel. Posts the notification message as JSON to the recipient URL via the standard fetch (injectable). Zero external npm dependencies.
