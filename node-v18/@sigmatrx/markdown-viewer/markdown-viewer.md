# @sigmatrx/markdown-viewer

> 标签: gfm, katex, markdown, react, react-markdown, renderer

## 简介

Lightweight, read-only React Markdown renderer with GFM tables, GitHub alerts, KaTeX math, footnotes, and image-link previews.
