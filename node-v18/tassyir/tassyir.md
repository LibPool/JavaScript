# tassyir

> 标签: cli, deploy, developer, tassyir, tassyir-app, webhooks

## 简介

The Tassyir developer CLI: sign in, create apps, validate and deploy tassyir.app.toml, manage client secrets, dev stores and test webhooks. --json on every command.
