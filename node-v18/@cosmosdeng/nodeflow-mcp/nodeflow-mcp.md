# @cosmosdeng/nodeflow-mcp

> 标签: electron, flowchart, mcp, model-context-protocol, nodeflow, opencode, workbuddy

## 简介

NodeFlow MCP stdio adapter — lets AI agents (WorkBuddy / MCP clients) operate a running NodeFlow via its local Agent Bridge (http://127.0.0.1:8787).
