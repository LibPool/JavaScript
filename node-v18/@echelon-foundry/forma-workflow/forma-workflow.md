# @echelon-foundry/forma-workflow

> 标签: accessibility, diagram, editor, embeddable, forma, workflow

## 简介

Embeddable Forma workflow renderer and editor (<forma-workflow>), built on the Forma portable workflow format. Optional runtime companion to the zero-runtime @echelon-foundry/design-system.
