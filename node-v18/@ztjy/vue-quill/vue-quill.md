# @ztjy/vue-quill

> 标签: JavaScript

## 简介

基于 [vue-quill-editor](https://github.com/surmon-china/vue-quill-editor) 改造且适用于 vue3 的 quill 富文本编辑器，用法与 [vue-quill-editor](https://github.com/surmon-china/vue-quill-editor) 保持一致。
