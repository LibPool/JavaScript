# @liyang8246/fxxk-xf

> 标签: ai-sdk, openai-compatible, opencode, provider, race, sse

## 简介

Race provider wrapper: 8 parallel connections to an OpenAI-compatible endpoint, first valid SSE chunk wins, rest aborted. Failures signal opencode to retry immediately via retry-after-ms:0.
