# @liyang8246/solid-inheritattrs

> 标签: attribute-forwarding, babel, class, inheritAttrs, solid, solidjs, style, vite-plugin

## 简介

Vite plugin for SolidJS that automatically forwards class and style attributes from parent components to child components' root elements.
