> 标签: angular, axios, axios-request-timeout, fetch, javascript, nelson, nelsonomuto, omuto, react, reactjs, timeout, vuejs

## 简介

wrapper to add timeout to axios request - [x] will throw an error when the timeout is passed and the code in the catch block will be executed.
