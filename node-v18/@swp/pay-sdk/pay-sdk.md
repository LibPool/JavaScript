# @swp/pay-sdk

> 标签: cryptocurrency, pay, sdk, swipe, swp

## 简介

SwpPaySDK é um SDK para Node.js, desenvolvido pela Swipe com o objetivo de facilitar a integração com a API de pagamento em criptomoedas.
