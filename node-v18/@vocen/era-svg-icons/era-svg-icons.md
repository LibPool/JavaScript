# @vocen/era-svg-icons

> 标签: JavaScript

## 简介

- svg图标库是基于设计稿而制定的一套svg图标集、可兼容 APP端和H5端。 - 图标分为单色和多色（一般是双色），如需更改颜色或者大小等，可参考配置 - 图标列表可访问 [svg图标库](http://10.0.7.126/icon/)
