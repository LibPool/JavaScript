# @wisemen/danger

> 标签: JavaScript

## 简介

Reusable [Danger JS](https://danger.systems/js/) rules and a composite GitHub Action for running them, built for monorepos laid out as `apps/api` + `apps/web` (or any number of `apps/<name>` folders).
