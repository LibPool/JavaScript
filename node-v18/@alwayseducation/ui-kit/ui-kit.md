# @alwayseducation/ui-kit

> 标签: JavaScript

## 简介

Reusable Angular 22 UI components for AlwaysConnected applications. The v2 library is standalone, signal-first, form-compatible, responsive, and styled with CSS tokens. It does not require Tailwind at runtime.
