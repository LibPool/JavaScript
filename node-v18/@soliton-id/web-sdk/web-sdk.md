# @soliton-id/web-sdk

> 标签: identity, kyc, liveness, soliton, verification

## 简介

Soliton identity verification for the browser: opens the hosted verification flow in a full-viewport overlay iframe on your page and reports lifecycle events. Verdicts and portraits are fetched by your backend, never exposed in the browser.
