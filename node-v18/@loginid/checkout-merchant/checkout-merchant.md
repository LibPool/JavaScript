# @loginid/checkout-merchant

> 标签: authentication, biometrics, checkout, fido2, merchant, passkey, passwordless, payments, webauthn

## 简介

The LoginID Checkout SDK for Merchants enables seamless passwordless authentication using passkeys within embedded  checkout experiences. This SDK is designed to integrate with iframes and orchestrate user authentication in a secure way.
