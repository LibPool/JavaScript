# @naanatin/node-red-simple-slack-listener

> 标签: chatbot, listener, node-red, redbot, slack, socket-mode

## 简介

Simple Slack listener node for Node-RED. Supports both Socket Mode and HTTP Receiver mode. Outputs messages compatible with RedBot format for easy integration with existing flows.
