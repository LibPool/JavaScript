# @posty5/oauth-angular

> 标签: angular, continue-with-posty5, login, oauth, oauth2, oidc, openid-connect, pkce, posty5, sign-in, sign-in-button, sso, ssr

## 简介

Login with Posty5 for Angular: a ready, fully customisable "Continue with Posty5" button, PKCE sign-in, callback handling and in-browser ID-token verification (OpenID Connect). Standalone APIs, SSR-safe.
