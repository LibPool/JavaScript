# @codeastra/proxy

> 标签: ai, anthropic, compliance, data-protection, gdpr, hipaa, llm, openai, pci-dss, phi, pii, proxy, security

## 简介

Zero-code data protection proxy for AI. PHI, PCI, PII, images, audio, video, code and documents — all scanned and redacted before reaching any LLM.
