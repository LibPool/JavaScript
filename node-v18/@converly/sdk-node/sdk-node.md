# @converly/sdk-node

> 标签: attribution, converly, conversion-tracking, conversions-api, enhanced-conversions, form-tracking, ga4, google-ads, hmac, lead-tracking, meta-capi, saas-signup, server-side-tracking, typescript, webhook

## 简介

Server-side conversion tracking for Node backends. Report any conversion your code confirms (SaaS signups, custom form leads, bookings) to Converly, which fires it to Google Ads, Meta, GA4 and more via their server-side APIs (Enhanced Conversions, CAPI) a
