# @techspokes/typescript-wsdl-client

> 标签: JavaScript

## 简介

Turn legacy WSDL/SOAP services into typed TypeScript clients, OpenAPI 3.1 specs, and production-ready Fastify REST gateways. Built for enterprise SOAP modernization.
