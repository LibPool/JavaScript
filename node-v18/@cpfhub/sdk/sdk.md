# @cpfhub/sdk

> 标签: api-client, brasil, brazil, cpf, cpf-api, cpf-consulta, cpf-lookup, cpf-validation, cpfhub, fintech, identity-verification, kyc, lgpd, node, nodejs, onboarding, receita-federal, sdk, typescript, validacao-cpf

## 简介

Official Node.js/TypeScript SDK for CPFHub.io — Brazilian CPF lookup API. Get name, gender and date of birth from any CPF in ~300ms.
