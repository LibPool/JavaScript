# @liuch0812/dsh-thinking-block

> 标签: chat, deepseek-harness, dsh, plugin, reasoning, thinking, ui, web

## 简介

Cherry-Studio-style reasoning (深度思考) display for the DSH web chat: a stable collapsible think block with spinner, elapsed seconds, a stabilized one-line preview, and an auto-following scroll body — no more per-token flicker.
