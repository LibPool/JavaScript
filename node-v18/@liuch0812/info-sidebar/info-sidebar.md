# @liuch0812/info-sidebar

> 标签: cordis, deepseek-harness, dsh, opencode, plugin, sidebar, web

## 简介

An opencode-style info sidebar for DeepSeek Harness (DSH): session/runtime status, token & cost, and live activity. Static DSH Cordis plugin — install with `dsh plugin --profile web add @liuch0812/info-sidebar`.
