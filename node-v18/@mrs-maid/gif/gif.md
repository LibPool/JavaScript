# @mrs-maid/gif

> 标签: anime, api-client, discord, discord-bot, gif, gif-api, mrs-maid, reactions, typescript

## 简介

TypeScript client for the Mrs. Maid GIF API. Random anime reaction gifs by rating and category, no runtime dependencies.
