# @tmhs/steam-mcp

> 标签: ai-tools, cursor, mcp, model-context-protocol, steam, steamworks

## 简介

MCP server for Steam & Steamworks APIs - 26 tools (19 read, 5 write, 2 SDK guides) for store data, player stats, reviews, pricing, achievements, workshop, leaderboards, inventory, and lobbies.
