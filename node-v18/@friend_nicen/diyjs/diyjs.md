# @friend_nicen/diyjs

> 标签: DIY, DIY定制, DIY手机壳, DIY衣服, DIY设计

## 简介

DIY.JS 是一款基于Canvas原生接口开发的业务级图形库，专注于为商品定制提供强大的图形交互功能，帮助开发者轻松实现商品的个性化设计，适用于 T 恤、手机壳、抱枕等多种商品的定制场景。
