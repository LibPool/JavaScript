# @cat_tom/file-content-extractor

> 标签: docx, encoding, extract, file, markdown, no-garbled, ocr, pdf, txt

## 简介

从 txt / docx / xlsx / pdf / md / 图片 中提取纯文本，内置多编码乱码处理。前端通用 TS 库，Vue/React/原生 JS 都能直接用。
