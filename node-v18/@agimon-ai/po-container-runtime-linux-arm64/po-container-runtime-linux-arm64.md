# @agimon-ai/po-container-runtime-linux-arm64

> 标签: arm64, coding-agent, container, linux, native-runtime, po, sandbox

## 简介

Read-only Po server payload for Linux arm64 sandbox containers, mounted at /opt/po and run with Node 24.
