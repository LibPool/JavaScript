# @mks2508/consumer-bus

> 标签: JavaScript

## 简介

Local pub/sub bus for multi-consumer daemons (CLI/MCP/menubar/desktop/web): single-writer choke-point, subscribe-before-act, snapshot+delta, typed topics, in-process + unix-socket transports
