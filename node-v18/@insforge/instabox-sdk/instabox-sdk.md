# @insforge/instabox-sdk

> 标签: dev-machine, firecracker, insforge, instabox, microvm, sandbox

## 简介

TypeScript SDK for instabox: create sandboxes on Firecracker dev machines, run commands, move files, pause, resume, snapshot and SSH in.
