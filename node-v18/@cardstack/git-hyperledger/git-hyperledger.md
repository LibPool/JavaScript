# @cardstack/git-hyperledger

> 标签: cardstack-plugin, ember-addon

## 简介

Git data source plugin for @cardstack/hub that also pushes commits to hyperledger blockchain

## 官网

- 源码仓库：https://github.com/cardstack/cardstack
- npm 页面：https://www.npmjs.com/package/@cardstack/git-hyperledger
