# @windower/framekit

> 标签: chromium, compat, ffmpeg, framekit, react, renderer, video

## 简介

framekit: programmatic React video renderer (headless Chromium capture, ffmpeg encode). One package, subpath exports: core, transitions, bundler, renderer, cli, plus compat layers.
