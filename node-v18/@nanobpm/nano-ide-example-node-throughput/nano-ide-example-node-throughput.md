# @nanobpm/nano-ide-example-node-throughput

> 标签: camunda, falcon, nano-ide-example, nano-ide-ext, nanobpm, node, throughput, typescript

## 简介

Distributable example app for the Nano RAD IDE: a Node/TypeScript throughput demo (async producer flood + JobWorker on @nanobpm/nano-sdk) that runs one code path against Camunda 8 (REST) or Nano (Falcon).
