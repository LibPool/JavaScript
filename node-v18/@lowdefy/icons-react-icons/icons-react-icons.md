# @lowdefy/icons-react-icons

> 标签: lowdefy, lowdefy icons, lowdefy plugin, react-icons

## 简介

Lowdefy icon set with every react-icons 5.6.0 icon under its react-icons name. A migration aid for apps moving to Lucide.
