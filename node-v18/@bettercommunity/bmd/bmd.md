# @bettercommunity/bmd

> 标签: bettercommunity, callouts, directives, documentation, gfm, markdown, mdx-alternative, mermaid, openapi, react, rehype, remark

## 简介

B.MD (better.markdown): 65 blocks on GitHub-flavoured Markdown (callouts, cards, tabs, steps, timelines, stats, FAQ, API cards from OpenAPI, embeds, live values, Mermaid diagrams) as one React component, with a public AST, a link checker, an HTML exporter
