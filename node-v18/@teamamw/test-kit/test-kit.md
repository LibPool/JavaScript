# @teamamw/test-kit

> 标签: JavaScript

## 简介

AMW shared test harness — env-safety guards, test-tenant auth, synthetic fixtures, secret-scan, a toggleable CI gate, and Vitest/Stryker presets. Dev-time only; never ships to runtime.
