# @amazon-devices/kepler-epg-provider

> 标签: JavaScript

## 简介

The `@amazon-devices/kepler-epg-provider` package provides a comprehensive set of APIs for KeplerScript applications to manage electronic program guide (EPG) data, including  channel lineups, program schedules, and live event information.
