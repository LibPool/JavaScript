# @edsdk/blk42-ckeditor5

> 标签: ckeditor, ckeditor 5, ckeditor5, ckeditor5-feature, ckeditor5-plugin

## 简介

Blk42 is a plugin for CKEditor 5 for building a Bootstrap/Tailwind 4 structure with support of creating, sharing and reusing custom user blocks across own websites.
