# @datamesh/factcode-mcp-adapter

> 标签: agent, factcode, mcp, model-context-protocol

## 简介

MCP-client adapter for FactCode. Fork of pi-mcp-adapter (MIT, Nico Bailon), repointed to the FactCode SDK forks (@datamesh/factcode-ai / -tui) so it no longer pulls the upstream @earendil-works/pi-ai (and its @aws-sdk dependency).
