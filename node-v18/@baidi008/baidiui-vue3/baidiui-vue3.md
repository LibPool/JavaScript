# @baidi008/baidiui-vue3

> 标签: JavaScript

## 简介

Baidiui 作为一套基于Vue开发的UI框架，拥有完整、样式统一的UI风格，开箱即用的Vue组件以及高自由度的调用方式。适用于网站、系统后台以及各类web应用。
