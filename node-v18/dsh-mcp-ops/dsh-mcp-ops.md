# dsh-mcp-ops

> 标签: deepseek, dsh, harness, mcp, model-context-protocol, plugin

## 简介

MCP 服务管理：增删改查与启停、连接测试、工具按需检索与全量注入、进程级与服务级环境变量（含密钥）；MCP service management: CRUD, connection tests, tool injection, environment variables and secrets
