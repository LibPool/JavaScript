# @dsh-git/github

> 标签: api, deepseek, dsh, dsh-plugin, git, github, harness, pull-requests

## 简介

GitHub adapter for gitPlatform: REST endpoints over Node fetch, normalized into the gitPlatform vocabulary. The reference implementation for every other adapter.
