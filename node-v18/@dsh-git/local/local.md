# @dsh-git/local

> 标签: cli, deepseek, dsh, dsh-plugin, git, harness, shell, version-control

## 简介

Local git provider: implements the gitLocal Service Definition by shelling to the git binary through ctx.shell (submodules, LFS, and hooks handled by git itself).
