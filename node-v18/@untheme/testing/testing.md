# @untheme/testing

> 标签: JavaScript

## 简介

Test helpers and mocks for code that uses untheme. The package builds a theme from a terse spec, boots a service over the theme, and mocks the output of [`@untheme/kit`](../kit). A test suite runs without DTCG JSON, without a kit build, and without Terraz
