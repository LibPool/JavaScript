# @ansio/next-schema

> 标签: JavaScript

## 简介

React Server Components — fetch a page's Ansio JSON-LD schema, FAQPage Q&A, and/or raw entity data server-side, rendered as <script> tags so non-JS crawlers see them without a build step. Drop <AnsioSchema .../>, <AnsioFaq .../>, and/or <AnsioEntityData .
