# @trustpager/mcp-server

> 标签: JavaScript

## 简介

TrustPager MCP server for stdio-only clients (Claude Desktop, etc.) -- a thin proxy to the live TrustPager-NewMCP server at connect.trustpager.net. All tool logic (62 resource-grouped tools, self-correction, discovery) lives server-side and stays in sync
