# @e412/rnui-themes

> 标签: JavaScript

## 简介

CSS themes for [`@e412/rnui-react`](../react) — 8 built-in presets, a `data-theme` attribute system, full Tailwind CSS v4 integration, and the OKLch color space for perceptually uniform palettes.
