# @qithird/dsh-paste-input-plus

> 标签: context-menu, cordis, deepseek-harness, drag-drop, dsh, file-input, paste, plugin, webui

## 简介

DSH WebUI 文件输入增强插件（完善版）：Ctrl+V 粘贴（首次告知弹窗）、拖拽、点击选择三种输入；发送时复制至会话工作区临时目录；输入框与输出区均支持右键复制/粘贴菜单。
