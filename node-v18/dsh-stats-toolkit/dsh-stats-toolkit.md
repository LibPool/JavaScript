# dsh-stats-toolkit

> 标签: dsh, iqr, mad, outliers, plugin, quantile, regression, statistics, trend, zscore

## 简介

Numerical statistics plugin for DeepSeek Harness: descriptive stats (R type-7 quantiles, sample/population variance, skewness, kurtosis), three-method outlier detection (IQR / z-score / MAD modified z-score), and trend analysis (least-squares regression,
