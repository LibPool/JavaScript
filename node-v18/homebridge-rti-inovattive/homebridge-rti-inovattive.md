# homebridge-rti-inovattive

> 标签: homebridge, homebridge-plugin, homekit, inovattive, rti, rti-control, supports-hap

## 简介

Brings items controlled by an RTI control system into Apple Home (HomeKit), via the Inovattive Home HomeKit Bridge RTI driver.
