# @symbiome-forge/cow-sdk-wasm

> 标签: app-data, cow-protocol, cowswap, defi, eip-1193, eip-1271, eip-712, ethereum, orderbook, sdk, trading, typescript, wasm, wasm-bindgen, webassembly

## 简介

JavaScript and TypeScript SDK for CoW Protocol, compiled from Rust to WebAssembly — typed orderbook, trading, signing (EIP-712/1271/1193), and app-data.
