# @v2litop/image-mcp

> 标签: image, image-generation, mcp, model-context-protocol, openai, xbai

## 简介

极简 Node.js MCP 服务器，封装 OpenAI 兼容图片接口（文生图 + 图生图），默认指向 https://api.xbai.top/v1。
