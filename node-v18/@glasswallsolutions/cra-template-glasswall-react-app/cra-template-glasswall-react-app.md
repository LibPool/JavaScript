# @glasswallsolutions/cra-template-glasswall-react-app

> 标签: JavaScript

## 简介

A Glasswall template for CRA with a Glasswall NPM library pre-loaded. To enforce a consistent codebase and allow for our frontend styles to come together from pre-packaged NPM modules.
