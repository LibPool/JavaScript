# @volcengine/imagex-mp-weixin

> 标签: JavaScript

## 简介

基于火山引擎 [veImageX 图片服务](https://www.volcengine.com/products/imagex) 的图片加载组件，旨在优化抖音小程序中的图片资源，其核心能力有：图片格式自适应、分辨率自适应、图片懒加载、图片占位、错误兜底、稳定性布局。
