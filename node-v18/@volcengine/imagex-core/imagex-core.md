# @volcengine/imagex-core

> 标签: Volcano Engine, veImageX

## 简介

基于火山引擎 [veImageX 图片服务](https://www.volcengine.com/products/imagex) 的各框架的图片加载组件的公共依赖，提供抽象的核心能力，包括但不限于图片格式自适应、分辨率自适应、图片懒加载等。
