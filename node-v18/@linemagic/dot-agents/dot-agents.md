# @linemagic/dot-agents

> 标签: agents, claude-code, dotfiles, monorepo, skills, symlink

## 简介

把散落在 .claude/ .codex/ .cursor/ 等各个点目录里的 skills / commands / agents / hooks 收敛成唯一源 .agents/，其余目录只留软链
