# @story-telling-reporter/react-puzzle-photo-infra

> 标签: audio, autoplay, react, scroll, twreporter

## 简介

為開發中的專案，完成了初步開發。 目的是可以快速產生多種多圖的畫面構圖。 每一個生成的構圖是以方塊為基底，方塊有三種形狀，每一種都有十一種版面組合，且皆會因應螢幕寬度不同有所不同。 - 方塊形狀     - 正方     - 橫方     - 直方 - 版面組合     - 1A：一張照片，完全撐滿畫面     - 1B：一張照片，照片和方塊之間天地左右均保留 50px 間距     - 2A：二張照片，照片間距和方塊之間的間距相同、照片群組水平居中、照片比例3:2     - 2B：二張照片，照片間距和
