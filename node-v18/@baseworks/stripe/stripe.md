# @baseworks/stripe

> 标签: JavaScript

## 简介

Stripe connector: typed HTTP client, event catalog, projections, and CLI plugin for stripe-service (config, plan/product sync, checkout links, webhook reconciliation). Contract-first, versioned with the service.
