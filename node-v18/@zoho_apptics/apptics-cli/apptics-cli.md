# @zoho_apptics/apptics-cli

> 标签: JavaScript

## 简介

Guided CLI that authenticates, downloads your Apptics config, detects your project, and integrates the Apptics SDK — across Android, iOS, Flutter, React Native, KMP, Windows, and JavaScript.
