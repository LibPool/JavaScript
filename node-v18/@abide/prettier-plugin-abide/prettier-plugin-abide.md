# @abide/prettier-plugin-abide

> 标签: abide, formatter, prettier, prettier-plugin

## 简介

Prettier plugin for abide single-file components (.abide) — formats <script> as TypeScript, <style> as CSS, and every {…} expression, leaving template markup verbatim
