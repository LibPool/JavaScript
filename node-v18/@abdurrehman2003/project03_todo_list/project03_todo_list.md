# @abdurrehman2003/project03_todo_list

> 标签: JavaScript

## 简介

This to-do list application allows users to manage their tasks via a command-line interface. Users can add new tasks, view all tasks, and mark tasks as complete. It provides an interactive way to keep track of and organize tasks efficiently.
