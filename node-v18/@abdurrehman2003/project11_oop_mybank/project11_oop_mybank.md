# @abdurrehman2003/project11_oop_mybank

> 标签: JavaScript

## 简介

This OOP MyBank console application allows users to manage their bank accounts. Customers can deposit or withdraw money, check their balance, and handle transactions with realistic conditions like fees for large deposits.
