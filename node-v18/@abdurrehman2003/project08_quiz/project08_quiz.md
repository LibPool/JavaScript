# @abdurrehman2003/project08_quiz

> 标签: JavaScript

## 简介

This TypeScript-based quiz system presents students with multiple-choice questions using Inquirer. It collects answers, checks correctness, and provides a final score, allowing users to assess their knowledge interactively.
