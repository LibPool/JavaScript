# @horizon-integrations/publisher-crm-client

> 标签: client, crm, horizon, imobiliario, integration, publisher, real-estate, techbins

## 简介

Client HTTP tipado pra consumir a API do horizon-integrations-hub (rotas /api/providers/publisher/v1/*). Instalado nos sites das imobiliárias pra o reconcile do Publisher (backstop pull), preservando Anti-Corruption Layer.
