# @justweb3/efp-plugin

> 标签: JavaScript

## 简介

The **@justweb3/efp-plugin** extends the **JustWeb3 Widget** with **Ethereum Follow Protocol (EFP)** functionalities, allowing users to **follow** others, **view followers**, and **following** directly within your dApp.
