# @ggui-ai/agent-server

> 标签: agent, ggui, hono, mcp, mcp-apps

## 简介

Brand-agnostic Hono-based HTTP backend for GGUI-aware agents. Owns the wire shape, MCP discovery, tool-result resource inlining, server-allocated chat ids, and guest + bearer auth with chat ownership so per-SDK samples only have to implement a thin AgentA
