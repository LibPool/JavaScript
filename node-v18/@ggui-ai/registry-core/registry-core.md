# @ggui-ai/registry-core

> 标签: conformance, ggui, marketplace, mcp, registry, storage-interface

## 简介

Pure-TypeScript registry operations and storage interfaces for the GGUI marketplace. No I/O, no HTTP — operations take typed inputs plus a storage deps bag and return discriminated-union results.
