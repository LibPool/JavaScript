# @ggui-ai/dev-stack

> 标签: dev-server, esbuild, generative-ui, ggui, mcp, ui-registry

## 简介

Shared local dev engine for the GGUI protocol: local UI registry discovery, compile-on-demand, filesystem watcher with SSE, and a read-only HTTP surface for dev tooling. Framework-neutral — agent runtime supervision plugs in via an adapter seam, so no age
