# @ggui-ai/sandbox

> 标签: ggui, process-isolation, sandbox, spawn, subprocess

## 简介

Bounded process-isolation runner for untrusted Node subprocesses. Spawns a child with explicit cwd, env allowlist, wall-clock timeout, output caps, and (for Node children) a V8 heap cap. Honest scope — does NOT attempt network egress blocking, filesystem
