# @netlify/identity

> 标签: auth, authentication, edge-functions, gotrue, identity, jwt, login, netlify, oauth, serverless, signup

## 简介

Headless auth functions for Netlify Identity. Import { login, getUser } and call them. No init, no class, no UI.
