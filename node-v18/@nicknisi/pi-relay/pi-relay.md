# @nicknisi/pi-relay

> 标签: pi, pi-coding-agent, pi-package

## 简介

Brokerless session-to-session messaging for pi — a file mailbox that outlives the process, with ask/reply coordination. Formerly @nicknisi/pi-intercom.
