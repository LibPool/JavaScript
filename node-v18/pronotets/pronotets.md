# pronotets

> 标签: api-client, educonnect, ent, pronote, pronotepy, scolarite

## 简介

Full TypeScript port of pronotepy - an unofficial PRONOTE API client with the same encryption, protocol, ENT/SSO support and data model, for Node.js.

## 官网

- npm 页面：https://www.npmjs.com/package/pronotets

- 1.0.0

## 获取地址

- npm 安装：`npm install pronotets`
- npm registry：https://registry.npmjs.org/pronotets
- Node 要求：>=18.14
