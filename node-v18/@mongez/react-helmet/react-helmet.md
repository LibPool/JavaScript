# @mongez/react-helmet

> 标签: canonical-url, description, favicon, head, helmet, keywords, meta-tags, metadata, og, open-graph, react, react-head, react-helmet, seo, ssr, title, twitter-cards

## 简介

Document <head> manager for React: titles, descriptions, keywords, OG/Twitter meta, canonical URL, and <html> attributes — declarative via <Helmet>, cleans up on unmount.
