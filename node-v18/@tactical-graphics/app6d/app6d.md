# @tactical-graphics/app6d

> 标签: app6d, maplibre, mil-std-2525, military-symbology, nato, parametric-graphics, sidc, tactical-graphics

## 简介

Reusable parametric graphic engine + APP-6D/MIL-STD-2525 symbol catalog, adapter-agnostic overlay rendering and editing handles, with a MapLibre adapter and React hooks.
