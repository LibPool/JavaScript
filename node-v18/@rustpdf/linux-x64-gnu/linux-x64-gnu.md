# @rustpdf/linux-x64-gnu

> 标签: JavaScript

## 简介

Prebuilt rust-pdf native library (libpdf_ffi) for Linux x64 (glibc). Installed automatically as an optional dependency of `rustpdf`.

## 官网

- 官网：https://rustpdf.dev
- 源码仓库：git+https://github.com/rustpdf/rustpdf.git
- npm 页面：https://www.npmjs.com/package/@rustpdf/linux-x64-gnu
