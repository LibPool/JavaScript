# @jeryjs/pi-keyrouter

> 标签: api-key, api-key-rotation, api-keys, authentication, credentials, failover, model-routing, multi-account, oauth, oauth2, pi, pi-coding-agent, pi-extension, pi-package, provider-agnostic, rate-limit, rate-limiting, rotation, typescript, workarounds

## 简介

Credential pools for pi. Automatically rotate api keys and oauth credentials for built-in providers on 429 failovers in pi-coding-agent. No custom providers, no fetch hacks.
