# @ctrlback/crypta-drizzle

> 标签: adapter, bytea, column, crypta, drizzle, drizzle-orm, encryption, encryption-at-rest, orm, postgres, typescript

## 简介

Drizzle ORM bytea column builders for @ctrlback/crypta: a raw bytea column and a sealedBytea column branded with the core Ciphertext type.
