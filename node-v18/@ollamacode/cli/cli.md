# @ollamacode/cli

> 标签: agent, cli, coding-assistant, huggingface, llm, local-llm, offline, ollama, ollama-code, terminal-agent, wasm

## 简介

Local-first terminal coding agent. Runs against your own Ollama models; also speaks HuggingFace Inference. WebAssembly-powered core. Not affiliated with Ollama.
