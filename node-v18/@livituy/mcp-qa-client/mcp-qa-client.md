# @livituy/mcp-qa-client

> 标签: cursor, firstdue, jira, mcp, model-context-protocol, qa, testrail

## 简介

Cliente MCP TestRail + Jira para QAs; el template de Cursor incluye también el MCP de Playwright (@playwright/mcp). Instalable con npm; configuración directa en mcp.json (env) sin .env manual.
