# @reservi/calendar

> 标签: bundle, calendar, fullcalendar, react, scheduler

## 简介

Build autocontenido de Reservi Calendar para React: núcleo + UI + tema en un solo paquete, con sus dependencias inlineadas (solo react y react-dom quedan como peers).
