# @tangen/connectors-resend

> 标签: JavaScript

## 简介

The Resend connector pack for Tangen: an email sending connection an operator manages, a verified-domain picker, a typed email service, a Flow action and a form destination. Tangen ships no connectors of its own - install the providers you use
