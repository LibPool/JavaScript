# @antjones315/lighthouse-scanner

> 标签: audit, cloudflare-workers, core-web-vitals, lighthouse, pagespeed, performance, psi, seo

## 简介

Run a Google Lighthouse audit on any URL via the PageSpeed Insights API. Returns scored Performance / SEO / Accessibility / Best Practices and a plain-English summary. Workers-safe (no Node-only APIs).
