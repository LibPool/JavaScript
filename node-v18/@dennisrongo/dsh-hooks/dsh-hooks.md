# @dennisrongo/dsh-hooks

> 标签: ai-coding-agent, claude-code-alternative, deepseek-harness, dsh, dsh-plugin

## 简介

Claude Code-compatible hook lifecycle for DeepSeek Harness (dsh) — run shell commands at PreToolUse, PostToolUse, UserPromptSubmit, SessionStart/End, Stop, SubagentStop and Notification, plus contextual skill hints beside the composer
