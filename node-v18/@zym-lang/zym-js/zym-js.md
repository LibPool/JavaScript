# @zym-lang/zym-js

> 标签: embed, interpreter, language, sandbox, scripting, vm, wasm, webassembly, zym, zym-lang

## 简介

JavaScript / WebAssembly bindings for the Zym scripting language. Embed a Zym VM in Node, the browser, or a Web Worker — compile and run scripts, register JS functions as Zym natives, define globals, save/load bytecode, and call script functions from JS.
