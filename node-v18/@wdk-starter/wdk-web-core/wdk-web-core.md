# @wdk-starter/wdk-web-core

> 标签: bitcoin, comlink, eip-3009, evm, self-custodial, solana, tether, vault, wallet, wdk, web3, webcrypto

## 简介

Framework-agnostic engine powering WDK browser wallet products (Next.js Template + Browser Extension). Provides vault, chain loaders, EIP-3009 builder, Comlink/MV3 message-bus surfaces, and typed account registry.
