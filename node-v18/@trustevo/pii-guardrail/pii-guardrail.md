# @trustevo/pii-guardrail

> 标签: ai, claude-code, cursor, mcp, on-device, pii, privacy, redaction, zero-egress

## 简介

On-device PII firewall for AI coding tools. Tokenizes MCP tool results before the model sees them and restores surrogates at trusted boundaries — zero data egress, reversible, on-device.
