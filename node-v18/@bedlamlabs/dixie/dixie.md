# @bedlamlabs/dixie

> 标签: agent, browser, cli, dom, happy-dom, headless, jsdom, react, spa, testing

## 简介

DOM-level CLI browser for AI agents. Render pages, query elements, run tests, capture network activity — all without a real browser.
