# @curaelabs/node-wifi-scanner

> 标签: Node.js, WiFi, airport, iwlist, netsh, nmcli, scanner

## 简介

node.js module for WiFi network detection, based of of Christian Kuster's `node-wifi-scanner`. This has `npm` vulnerabilities removed and the latest version pubished.
