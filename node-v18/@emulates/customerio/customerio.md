# @emulates/customerio

> 标签: cdp, customer.io, customerio, emulates, outbox, service, transactional-email

## 简介

Stateful emulator of Customer.io: Segment-compatible CDP (identify/track/batch, SDK drop-in), App API transactional email/SMS/inbox sends with an outbox, message catalog, link-click tracking, and signed reporting webhooks.
