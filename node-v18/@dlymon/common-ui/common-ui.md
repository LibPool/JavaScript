# @dlymon/common-ui

> 标签: JavaScript

## 简介

该目录用于存放项目中集成的通用组件，继承了 `@dlymon-core/form-ui` 包、`@dlymon-core/popup-ui` 包、`@dlymon-core/shadcn-ui` 包等，并在此基础上扩展了更多的功能和配置。每个组件都包含了可重用的逻辑、配置和组件，方便在项目中进行统一管理和调用。
