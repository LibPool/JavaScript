# @styloviz/password-strength

> 标签: angular, password, strength, styloviz, tailwind, ui-kit

## 简介

A dependency-free password guidance meter that pairs alongside any text input — a segmented bar, a strength band, and up to three suggestions. Length carries three of the four points and character variety adds the fourth, so a passphrase outranks a short
