# @phssakaigawa/obsidian-vault-mcp

> 标签: claude, markdown, mcp, modelcontextprotocol, notes, obsidian

## 简介

MCP server for reading and searching an Obsidian vault directly from the filesystem. No Obsidian plugin, no REST API, no running Obsidian required.
