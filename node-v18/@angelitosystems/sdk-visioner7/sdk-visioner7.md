# @angelitosystems/sdk-visioner7

> 标签: cpe, dni, guia-remision, nestjs, peru, ruc, sdk, sunat, visioner7

## 简介

SDK independiente para NestJS y TypeScript que facilita la integración con un servicio externo contratado para consultas RUC-DNI, Tipo de Cambio, Guías de Remisión y CPE.
