# @hyuga/skills-lint

> 标签: agent, agent-skills, ai, ci, claude, language-agnostic, linter, reference-integrity, skill.md, trigger-collision

## 简介

Lint Anthropic Agent Skills (SKILL.md) in CI: referential integrity of referenced files + name/trigger collisions between skills. Language-agnostic, zero-dependency.
