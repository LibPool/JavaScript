# wafixer-sdk

> 标签: baileys, messaging, sdk, typescript, wafixer, whatsapp

## 简介

Official WAFixer TypeScript SDK — focused on WhatsApp message operations (send text, media, audio, buttons, list, location, contact, reaction, poll, presence, mark as read).
