# web-component-bundler

> 标签: bundle, component, custom, element, web

## 简介

This package takes in a JavaScript file that defines a CustomElement, looks for css/html files with the same name, and inserts them into the JavaScript file, allowing you to develop your component in separate files, but deliver it in a single JS file.
