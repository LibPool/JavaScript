# wg-config-generator

> 标签: cli, config, configuration, curve25519, generator, vpn, wg-quick, wg0, wireguard, x25519

## 简介

Generate a WireGuard server wg0.conf and N client .conf files with real Curve25519 (X25519) keypairs. CLI + zero-dependency browser tool. Keys are created locally and never transmitted.
