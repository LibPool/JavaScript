# web-agent-bridge-sdk

> 标签: ai-agent, bridge, sdk, wab, web-automation

## 简介

SDK for building AI agents that interact with Web Agent Bridge (WAB) — includes auto-discovery fallback, ShieldQR verifier, and governance layer.
