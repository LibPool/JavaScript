# webext-sync

> 标签: browser, chrome, data, extension, firefox, manifest-v2, manifest-v3, mv2, mv3, state, store, sync, web-ext, webext, webextension

## 简介

Sync data between a web extension's background, popup, options and content scripts. Works cross-browser, with MV3 and MV2.
