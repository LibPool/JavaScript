# wiring-diagram-mcp

> 标签: 12v, battery, boat, camper, electrical, mcp, model-context-protocol, off-grid, power-budget, rv, solar, vanlife, voltplan, wire-gauge, wiring-diagram

## 简介

MCP server that generates 12V/24V/48V wiring diagrams and sizes wires, fuses, batteries, solar arrays, and inverters for campers, boats, and off-grid systems.
