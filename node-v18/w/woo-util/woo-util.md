# woo-util

> 标签: JavaScript

## 简介

Install ``` npm install woo-util ``` Import ```js import {XlPdf} form "woo-util" ``` Use ```js    const xlPdf = new XlPdf({         el: document.getElementById("root"),         name:"下载文件"     })     xlPdf.save(); ```
