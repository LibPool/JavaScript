# workers-tcp-socket

> 标签: cloudflare, database, edge, postgresql, redis, socket, sql-server, tcp, tunnel, workers

## 简介

TCP socket adapter for Cloudflare Workers. Connect to SQL Server, PostgreSQL, Redis, and other TCP services from the edge.
