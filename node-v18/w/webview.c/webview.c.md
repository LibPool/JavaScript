# webview.c

> 标签: c, cross, desktop, edge, gui, library, platform, webkit, webview, webview2

## 简介

Tiny cross-platform webview library for C/C++. Uses WebKit (GTK/Cocoa) and Edge WebView2 (Windows); Serge Zaitsev (2017).
