# wannabuild

> 标签: agents, claude-code, cli, codex, cursor, factory, installer, spec-driven, wannabuild, workflow

## 简介

One-command installer for WannaBuild: a spec-driven, trust-hardened build workflow for Claude Code, Codex, Factory, and Cursor. Installs the real Rust gate runtime into every detected host.
