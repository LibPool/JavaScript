# wikidata-lang

> 标签: ISO 639-1, ISO 639-2, ISO 639-3, ISO 639-6, lang, language code, wikidata

## 简介

A database of languages and their Wikidata id, Wikimedia language code, ISO 639-1, ISO 639-2, ISO 639-3, ISO 639-6 codes
