# webchatagent

> 标签: ai, chat, chatbot, live-chat, sdk, sse, streaming, typescript, webchatagent

## 简介

Typed client for the WebChatAgent chat API. Build your own chat UI with streaming, file upload, feedback, lead forms and human handover.
