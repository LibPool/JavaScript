# wdio-workflo

> 标签: allure, functional system testing, jasmine, selenium, wdio-workflo, webdriver, webdriverio

## 简介

Wdio-workflo is a framework for writing behavior-driven automated functional system tests. It is based on a customized version of webdriverio v4.13.
