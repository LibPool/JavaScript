# websocket-tscat

> 标签: JavaScript

## 简介

1. 注册npm账号 2. 将npm源切回npm 3. 初始化项目 `$ npm init [-y]` 4. 创建入口文件 5. 开发项目 6. 登录npm账户 `$npm adduser` 7. npm publish
