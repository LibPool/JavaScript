# white-label-mediator

> 标签: application-events, browser, customevent, event-bus, events, eventtarget, framework-independent, incremental-adoption, javascript, mediator, node, progressive-enhancement, pub-sub, server-side, serverless, typed-events, typescript, universal, web-standards

## 简介

Lightweight standards-based TypeScript event bus for loosely coupled browser, Node.js, and progressively enhanced applications with optional typed events.
