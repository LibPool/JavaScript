# wifi-tally

> 标签: JavaScript

## 简介

An affordable and reliable Tally Light that works via WiFi based on NodeMCU / ESP8266. Supports multiple video mixers.

- 官网：https://wifi-tally.github.io/
- 源码仓库：git+https://github.com/benaja/wifi-tally.git
