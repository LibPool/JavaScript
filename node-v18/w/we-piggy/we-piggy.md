# we-piggy

> 标签: LLM, js, wechat, wechaty, wx

## 简介

A YAML file-configurable WeChat chatbot based on the wxchaty library, embedded with a large model. The code is simple and low-coupling, and most locations can be easily modified to achieve custom effects
