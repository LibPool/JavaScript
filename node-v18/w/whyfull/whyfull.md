# whyfull

> 标签: cache, cleanup, devtools, disk, disk-space, docker, huggingface, lmstudio, node_modules, ollama

## 简介

Find where disk space went on a dev machine (AI caches, package stores, build output), ranked by how safe each is to delete. Read-only.
