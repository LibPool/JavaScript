# within-view

> 标签: dom-listener, element-in-sight, element-in-view, element-within-sight, element-within-view, hooks, preact, preact-hooks, react, react-hooks, scroll, scroll-direction, scroll-event-listener, scroll-position, within-sight, within-view

## 简介

within-view uses preact/react hook to detect scroll event changes and checking if the wanted element(s) is within view and appending a class to the element if desired.
