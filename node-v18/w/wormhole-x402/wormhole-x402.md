# wormhole-x402

> 标签: agent, agent-security, agentic-commerce, ai-agent, mcp, payments, prompt-injection, quote-scanning, security, solana, spl-token, transaction-security, x402, x402-security

## 简介

Refuse an agent payment (Solana or EVM x402) that does not match what the agent was quoted, and scan the quote's own text for prompt injection before the model reads it. Offline, no RPC.
