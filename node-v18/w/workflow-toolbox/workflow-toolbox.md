# workflow-toolbox

> 标签: claude-code, multi-agent, orchestration, workflow

## 简介

Name guard + pointer for the Workflow Toolbox. The real packages are @workflow-toolbox/runtime, @workflow-toolbox/patterns and @workflow-toolbox/build (which ships the `workflow-toolbox` CLI). Do not depend on this package.
