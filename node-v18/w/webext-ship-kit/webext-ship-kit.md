# webext-ship-kit

> 标签: browser-extension, chrome-web-store, edge-addons, firefox-addons, manifest-v3, webextension

## 简介

Config-driven build and pre-submission validation for shipping one Manifest V3 browser extension source tree to Chrome, Edge and Firefox.
