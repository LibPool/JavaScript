# wikipilot

> 标签: claude-code, cli, codebase, developer-tools, docs, docs-generator, documentation, documentation-generator, markdown, mermaid, static-site-generator, wiki

## 简介

Generate a documentation wiki from your codebase. Every page records the source files it was built from, so you can see which docs have drifted from the code.
