# workbuddy-multi-mail-connector

> 标签: JavaScript

## 简介

WorkBuddy 多邮箱连接器 MCP Server：读取/搜索/发送 QQ、163、126、新浪等主流邮箱邮件。默认只读，写操作需显式授权与人工确认。
