# workstree

> 标签: agents, bootstrap, cli, git, worktree

## 简介

Worktrees that work on the first try — a repo convention (worktree.toml) + tiny CLI that turns a fresh git worktree into a working environment. This package reserves the name; the tool is distributed via GitHub releases for now.
