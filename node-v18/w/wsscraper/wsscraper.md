# wsscraper

> 标签: JavaScript

## 简介

Easy scraping and auth for JSON/XML web services. Based on node-scraper so it does web page scraping using jQuery too.

## 官网

- 源码仓库：https://github.com/davej/node-wsscraper.git
- npm 页面：https://www.npmjs.com/package/wsscraper
