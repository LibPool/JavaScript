# webstore-lint

> 标签: browser-extension, chrome-extension, chrome-web-store, compliance, lint, linter, manifest-v3, mv3, policy, rejected, rejection, review, static-analysis, webextension

## 简介

Check an unpacked Chrome extension against the Chrome Web Store program policies before you submit it. Every finding cites Google's own notification ID and verbatim policy text. Covers the 1 August 2026 policy updates.
