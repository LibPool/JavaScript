# wpress-extract2

> 标签: all-in-one-wp-migration, archive, backup, cli, extract, migration, wordpress, wpress

## 简介

A simple CLI tool for extracting .wpress archive files generated by the All-in-one-Wp-Migration Wordpress plugin.
