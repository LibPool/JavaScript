# wupeng-strfilter

> 标签: JavaScript

## 简介

安装模块 npm i wupeng-strfilter 导入模块 const str = require('wupeng-strfilter') 使用：有三个参数，第一个为字符串，第二个为需要过滤的字符，第三个为过滤后替换的新字符 str.getStr('abc','a','ddd') //把字符串abc中的a替换成ddd
