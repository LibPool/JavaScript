# waitlister-js

> 标签: alias, waitlist, waitlister

## 简介

Alias for the official `waitlister` package (the Waitlister SDK). Installing this installs `waitlister` — prefer `npm install waitlister`.

- 官网：https://waitlister.me
- npm 页面：https://www.npmjs.com/package/waitlister-js
