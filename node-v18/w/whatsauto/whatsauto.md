# whatsauto

> 标签: automation, bulk, csv, google-meet, group, meet, messaging, whatsapp, whatsapp-web.js

## 简介

WhatsApp bulk automation NPM library — send detailed personalized messages (number, name, session, Google Meet link, group name) via CSV and create/update WhatsApp groups (adds new members if group exists)
