# wantjcli

> 标签: cli, node, vue

## 简介

* 一个快速搭建和开发前端VUE项目的脚手架 * 本项目仅用于个人学习理解Node ## 安装 ``` npm install wantjcli -g ``` ## 介绍 脚手架基于vue，安装后自带axios，vue-router，vuex，vue.config.js ### 创建项目 ``` wan create <projectName> ``` 会使用此脚手架生成vue项目模板，安装依赖，打开浏览器 ### 创建Vue组件
