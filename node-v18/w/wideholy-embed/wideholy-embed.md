# wideholy-embed

> 标签: api, embed, multi, scripture, shadow-dom, verse, wideholy, wideholy.com, widget, zero-dependencies

## 简介

Embed WideHoly scripture widgets on any website. Lightweight (~5KB gzipped), zero dependencies, Shadow DOM isolation, 3 themes (light/dark/sepia).

- 官网：https://widget.wideholy.com
