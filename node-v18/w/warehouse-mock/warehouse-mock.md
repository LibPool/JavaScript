# warehouse-mock

> 标签: api, dev-server, mock, plugin, rpc, typescript, vue, webpack

## 简介

一个专为 Vue 项目设计的 Webpack 插件，支持 RPC 风格接口 mock，零业务代码侵入，实时更新（基于 warehouse-mock-core）
