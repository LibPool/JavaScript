# willcore.bootstrap

> 标签: Assignables, Binding, Proxies

## 简介

WillCore.Bootstrap contains Bootstrap 4.5 files and assignables. The assignables are wrappers that translate the Bootstrap's JQuery API to WillCore.UI assignables.
