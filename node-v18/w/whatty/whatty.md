# whatty

> 标签: JavaScript

## 简介

A terminal UI WhatsApp client — like WhatsApp Web, but in your terminal. Built on [Baileys](https://github.com/WhiskeySockets/Baileys) and [OpenTUI](https://github.com/sst/opentui) (with React bindings).
