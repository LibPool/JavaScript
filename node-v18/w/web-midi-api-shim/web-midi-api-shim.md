# web-midi-api-shim

> 标签: jazz plugin, midi, music, sound, webmidi api

## 简介

Shim for the WebMIDI API, intended to be used in environments that don't have the WebMIDI API implemented: Nodejs and all browsers except Chrome, Chromium and Opera

## 官网

- 官网：https://github.com/cwilso/WebMIDIAPIShim
- 源码仓库：git+https://github.com/cwilso/WebMIDIAPIShim.git
