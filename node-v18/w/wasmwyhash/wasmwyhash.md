# wasmwyhash

> 标签: JavaScript

## 简介

This WebAssembly module provides a high-performance implementation of the [wyhash algorithm](https://crates.io/crates/wyhash) by Wang Yi, ported from Rust for seamless JavaScript and browser usage.
