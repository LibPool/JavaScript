# w36-web3

> 标签: JavaScript

## 简介

这个库目前提供了一个简单的 Node.js 接口，用于与 Binance Smart Chain (BSC) 的官方节点进行交互，执行一些基本的操作，如获取节点信息、获取最新的区块号以及获取指定地址的余额。
