# ws-recorder

> 标签: diagnostics, indexeddb, ndjson, recorder, troubleshooting, vue, websocket

## 简介

Record field-level changes from WebSocket frames in the browser, store them in IndexedDB, and export a self-contained diagnostic report — for troubleshooting "the UI stopped updating" issues on machines where you cannot install anything.
