# warpsock-linux-x64-gnu

> 标签: async, browser, chrome, client, fingerprint, http, http2, http3, impersonate, llm, native, scraping, sse, streaming, tls, ttfb, websocket

## 简介

Node.js bindings for Warpsock, a browser-fingerprint HTTP client with TLS, HTTP/1.1, HTTP/2, HTTP/3, and WebSocket support. Improved TTFT and TPS for LLMs.
