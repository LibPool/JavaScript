# wechat-clawbot-mcp

> 标签: ai-agent, clawbot, mcp, wechat, wechat-clawbot

## 简介

MCP server for wechat-clawbot (multi-user WeChat ClawBot). Talks to the running wechat-clawbot HTTP API over stdio. No Coze / no AI tokens bundled.
