# whats-my-external-ip

> 标签: external-ip, ip, public-ip, whats-my-external-ip

## 简介

A CLI tool to get your public IP address with **0 dependencies** using the following services: - https://checkip.amazonaws.com - https://api.ipify.org - https://ipinfo.io/ip
