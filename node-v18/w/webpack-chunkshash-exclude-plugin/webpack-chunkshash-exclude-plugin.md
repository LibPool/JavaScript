# webpack-chunkshash-exclude-plugin

> 标签: 取消指定chunk的chunkhash，取消html模版中注入的js、css文件的chunkhash

## 简介

根据传入参数确定部分chunk打包时忽略chunkhash，html注入js、css文件地址是否取消chunkhash

## 官网

- npm 页面：https://www.npmjs.com/package/webpack-chunkshash-exclude-plugin
