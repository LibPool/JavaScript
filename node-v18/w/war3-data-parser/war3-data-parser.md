# war3-data-parser

> 标签: ability, compressed, data, database, gamedata, gzip, hero, item, parser, unit, war3, warcraft, warcraft3

## 简介

War3英雄、单位、技能、物品等完整数据解析库，包含836个单位、799个技能、273个物品等数据，开箱即用。支持Gzip压缩，包体减少96%
