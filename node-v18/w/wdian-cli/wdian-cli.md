# wdian-cli

> 标签: JavaScript

## 简介

- 多次造轮子，项目升级 - 代码规范，无法统一 - 组件、业务组件，无法统一等等 - 重复性工作，繁琐而且浪费时间 - copy过来的模板容易存在无关的代码 - 项目中有很多需要配置的地方，容易忽略一些配置点，进而埋坑 - 人工操作永远都有可能犯错，建新项目时，总要花时间去排错 - 内部框架也在不停的迭代，人工建项目往往不知道框架最新的版本号是多少，使用旧版本的框架可能会重新引入一些bug
