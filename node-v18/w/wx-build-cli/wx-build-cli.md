# wx-build-cli

> 标签: JavaScript

## 简介

有可能出现的问题 weixin-cli 命令找不到 解决方法  1、 配置全局变量   控制面板\系统和安全\系统\高级系统设置  编辑PATH变量 并新增 变量路径  （weixin-cli的安装路径） 例如：D:\Program Files\nodejs\node_global\node_modules\weixin-cli
