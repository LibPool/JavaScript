# wanvil

> 标签: JavaScript

## 简介

wanvil is a local blockchain explorer and control plane for [Foundry Anvil](https://book.getfoundry.sh/anvil/). Runs on each user’s machine: a small **control server** (Node + Socket.io) plus a **Vite** UI.
