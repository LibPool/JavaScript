# with-custom-cursor

> 标签: component, component cursor, cursor, custom, custom cursor, custom-cursor, library, mouse, mouse cursor, mouse-cursor, react

## 简介

A Higher-Order Component (HOC) library for React that enables you to easily add a custom cursor to any component.
