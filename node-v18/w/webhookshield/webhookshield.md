# webhookshield

> 标签: clerk-webhook, edge-ready, github-webhook, hmac, lemon-squeezy-webhook, resend-webhook, security, sha256, shopify-webhook, signature, stripe-webhook, verification, webhook, webhookshield, zero-dependency

## 简介

Unified, zero-dependency, edge-compatible webhook signature verification library for Node.js and TypeScript. Supports Stripe, GitHub, Clerk, Shopify, Lemon Squeezy, and Resend.
