# web3trackers-mcp

> 标签: analytics, attribution, crypto, defi, marketing, mcp, modelcontextprotocol, utm, web3

## 简介

MCP server for web3 and crypto marketing attribution: build UTM tracking URLs, estimate campaign ROI, compare web3 attribution tools, and look up DeFi marketing benchmarks. No API key required.
