# wsproxyxpro

> 标签: robrowser, roproxy, websocket-proxy, ws2tcp, wsproxy, xpro

## 简介

This is a websocket to tcp proxy, written in node.js. It is dynamic and will proxy to various tcp servers.

## 官网

- 源码仓库：https://https://gitlab.com/xpro1/wsproxyxpro.git
- npm 页面：https://www.npmjs.com/package/wsproxyxpro
