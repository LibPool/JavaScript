# whistle.view-base64

> 标签: JavaScript

## 简介

该插件是在 Network / Inspectors 自定义 Tab 的示例（whistle >= `v2.8.9`），通过在该自定义的 Tab 可以查看请求 URL 和请求内容 base64的响应内容
