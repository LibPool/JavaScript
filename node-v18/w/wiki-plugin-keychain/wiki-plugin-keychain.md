# wiki-plugin-keychain

> 标签: JavaScript

## 简介

Password Tool for a laptop wiki: save the clipboard into the macOS login Keychain, list Keychain entries by name, copy a value to the clipboard or reveal it briefly — the value never touches a page, a URL or a log.
