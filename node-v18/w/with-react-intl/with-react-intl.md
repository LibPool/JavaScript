# with-react-intl

> 标签: format, formatting, globalization, hoc, i18n, internationalization, intl, locale, localization, navigator, react, reactjs, translate, translation, translations, yahoo

## 简介

Internationalize React apps with a simple HOC and retrieve localized message either by a Component (with yahoo/react-intl) or as a String.
