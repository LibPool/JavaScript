# webpack5-node-polyfill-plugin

> 标签: node, polyfill, webpack, webpack-plugin

## 简介

A Webpack 5 plugin that provides polyfills for Node.js core modules, enabling smoother execution of Node.js-dependent projects in the browser environment.
