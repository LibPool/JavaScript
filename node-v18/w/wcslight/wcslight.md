# wcslight

> 标签: astronomy, astrophysics, browser, coordinates, fits, healpix, hips, projection, wcs, world-coordinate-system

## 简介

Lightweight JavaScript/TypeScript library for astronomical World Coordinate System (WCS), FITS, HiPS and HEALPix projections.
