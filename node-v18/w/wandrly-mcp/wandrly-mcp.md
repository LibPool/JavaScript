# wandrly-mcp

> 标签: claude, mcp, modelcontextprotocol, travel, trip-planning, wandrly

## 简介

MCP server for Wandrly — lets AI tools read your trips and propose draft plans. Thin wrapper over the Wandrly API; config is a token + base URL only.

## 官网

- 官网：https://wandrly.ai
- npm 页面：https://www.npmjs.com/package/wandrly-mcp
