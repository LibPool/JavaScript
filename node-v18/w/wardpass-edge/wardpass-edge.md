# wardpass-edge

> 标签: agent-payments, clearance, policy-passport, pre-settle, screen, trust-network, wardpass, x402

## 简介

Free hosted WardPass control plane (1 agent seat): Policy Passports, reserve→settle, oversight heartbeat, admin console. OSS client + receiver POST /v1/screen. Not a full self-hosted gateway.
