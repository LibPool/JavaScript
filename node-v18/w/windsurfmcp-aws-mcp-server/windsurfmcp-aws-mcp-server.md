# windsurfmcp-aws-mcp-server

> 标签: aws, claude, mcp, websocket, zoho

## 简介

Claude Desktop用のAWS MCPサーバーパッケージです。WebSocketを通じてAWS上のLambda関数に接続し、ZohoのCRM/Desk/Books APIとの連携機能を提供します。
