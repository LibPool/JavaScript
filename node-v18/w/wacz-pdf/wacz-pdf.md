# wacz-pdf

> 标签: archiving, cdx, pdf, playwright, replay, wabac, wacz, warc, web-archive, webrecorder

## 简介

Render the HTML pages in a WACZ web archive to PDF, one per page, via wabac.js replay in headless Chromium
