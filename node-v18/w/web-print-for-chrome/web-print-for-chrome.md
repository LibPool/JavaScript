# web-print-for-chrome

> 标签: JavaScript

## 简介

**web-print-for-chrome**是一个基于vue2与element-ui的可复用组件，旨在简化chrome网页端的标签打印功能。通过渲染页面再转换为图片进行网页的打印，内置静默打印与多条码打印。
