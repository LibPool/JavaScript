# webmcp-retrofit-bridge

> 标签: bridge, cdp, claude-code, cursor, mcp, model-context-protocol, puppeteer, webmcp

## 简介

Generic stdio MCP bridge: exposes whatever WebMCP tools a page registers on document.modelContext to MCP clients (Claude Code / Cursor) over CDP. Page-agnostic, no hardcoded tool list.
