# wiki-plugin-chat

> 标签: JavaScript

## 简介

Federated Wiki chat item — an ntfy room in the page. Compose gates on wiki login, messages carry mask-tier identity (owner name + author page), and Proof of Understanding reply kinds make the log trust-graph data.
