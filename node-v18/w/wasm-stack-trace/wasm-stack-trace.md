# wasm-stack-trace

> 标签: DWARF, WebAssembly, backtrace, callstack, debugging, stack trace, symbols, wasm

## 简介

Wasm stack traces with demangled symbols and file/line/column information. Uses DWARF data to symbolicate stack traces.
