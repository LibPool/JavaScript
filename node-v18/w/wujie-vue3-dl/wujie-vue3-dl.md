# wujie-vue3-dl

> 标签: JavaScript

## 简介

wujie-vue3是根据wujie封装的vue3版本的wujie框架。 这个项目我们基于wujie的组件，使用`vue3+webpack+swc`封装的自己的wujie的vue3版本的框架。
