> 标签: free-map, geocoding, leaflet, location-picker, map, mapbox, mapbox-gl, multi-provider, openstreetmap, vector-map, vue, vue-leaflet, vue-map, vue3, vue3-geocoding, vue3-leaflet, vue3-location-picker, vue3-map, vue3-openstreetmap, vue3-vector-map, wakeb, wakeb-map

## 简介

A free Vue 3 multi-provider map library (Leaflet + Mapbox GL JS + extensible) with location picking, markers, geocoding, drawing, tracking, and more. No API key required for Leaflet. Works offline!
