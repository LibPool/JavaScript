# whisper-id

> 标签: agent, dns, egress, identity, ipv6, proxy, whisper

## 简介

Give any Node agent the Whisper security graph (keyless reads, no client-side gate), a real routable Whisper IPv6 identity, safe egress, and the full control plane.
