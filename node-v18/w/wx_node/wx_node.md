# wx_node

> 标签: wx_node

## 简介

微信服务,需要手动添加配置文件wxConfig.json,格式为{Wx_AppID:公众号后台获取,Wx_AppSecret:公众号后台获取,Wx_host:api.weixin.qq.com,host:服务器地址},不支持集群
