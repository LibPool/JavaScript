# webpage_analyzer

> 标签: JavaScript

## 简介

Webpage Analyzer accepts a URL input and outputs the following details: * HTML version * Page title * Number of headings and which heading level * Total number of links * Number of internal links * Number of external links * Number of broken links * Exist
