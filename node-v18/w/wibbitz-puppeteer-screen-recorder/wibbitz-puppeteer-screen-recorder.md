# wibbitz-puppeteer-screen-recorder

> 标签: FFMPEG, automatic, automation, cast, devtool, devtool protocol, headfull, headless, pptr, pptr.dev, puppeteer, record, screeenCast, screeenCasts, screeencast, screeencasts, screen, screen cast, screen frame, screen recorder, shot, test case capture, video, video capture, video recorder

## 简介

A puppeteer Plugin that uses the native chrome devtool protocol for capturing video frame by frame. Also supports an option to follow pages that are opened by the current page object
