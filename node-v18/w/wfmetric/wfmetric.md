# wfmetric

> 标签: vmware, wavefront

## 简介

Library to send metrics to a wavefront proxy when using the powerful vmware wavefront monitoring and analytics tool.  Official Wavefront NPM package is https://www.npmjs.com/package/wavefrontmetrics
