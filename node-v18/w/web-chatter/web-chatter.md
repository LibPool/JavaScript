# web-chatter

> 标签: admin-panel, authentication, bcrypt, chatbot, express, session, sqlite, user-management, web-server

## 简介

Simple Express-based web server for chat bots with user authentication, SQLite persistence per user, admin controls, and customizable authenticated routes
