# ws-workspace

> 标签: agent, cli, collaboration, dashboard, kanban, real-time, todo, websocket, workspace

## 简介

A real-time workspace dashboard with WebSocket-powered components — kanban, todo, tables, forms, and decision cards. Control it from CLI, browser, or agent API.
