# weather-china-mcp

> 标签: ai, air-quality, aqi, china, china-weather, claude, claude-code, claude-desktop, cline, cursor, forecast, free, llm, mcp, mcp-server, model-context-protocol, no-api-key, opencode, pm25, realtime-weather, weather, weather-forecast, weather.com.cn, windsurf, 中国天气网

## 简介

MCP server for China weather (weather.com.cn) — real-time weather, 5-day forecast, air quality. No API Key required. Works with Claude Desktop, Claude Code, Cursor, Cline, Windsurf, OpenCode.
