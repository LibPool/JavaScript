# webext-ui-sim

> 标签: browser-extension, chrome-extension, dev-server, firefox-addon, i18n, mock, shim, simulator, storage, webextension

## 简介

Run any browser-extension UI page in a plain browser tab. Zero-dependency dev server that injects a WebExtension API shim (storage, runtime messaging, i18n, downloads) with JSON-defined storage defaults and pluggable background message handlers.
