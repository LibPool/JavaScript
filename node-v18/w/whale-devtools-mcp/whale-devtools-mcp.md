# whale-devtools-mcp

> 标签: JavaScript

## 简介

Naver Whale browser automation via Chrome DevTools Protocol — includes Whale-exclusive sidebar panel toggle, pinned extension click, and bookmark navigation on top of full CDP/Puppeteer support.
