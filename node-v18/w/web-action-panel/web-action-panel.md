# web-action-panel

> 标签: action-panel, bottom-sheet, custom-element, dialog, drag-to-dismiss, drawer, spring, web-component, zero-dependency

## 简介

A zero-dependency action panel web component: side panel on desktop, drag-to-dismiss bottom sheet on mobile, with interruptible spring physics.
