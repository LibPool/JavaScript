# wp-sass

> 标签: JavaScript

## 简介

WP Sass adalah sebuah modul node.js yang digunakan untuk mempercepat proses pengembangan tema wordpress yang dilengkapi dengan compiler sass.

## 官网

- npm 页面：https://www.npmjs.com/package/wp-sass
