# wp-conf

> 标签: JavaScript

## 简介

为了便于进行多个项目webpack构建的管理，避免复制webpack.config.js，将构件配置文件抽离成一个npm模块，各项目进行引用

## 官网

- npm 页面：https://www.npmjs.com/package/wp-conf
