# webext-rpc

> 标签: browser, browser-extension, chrome, chrome-extension, extension, firefox, firefox-extension, rpc, safari, safari-extension, type-safe, web-ext, webext, webextension

## 简介

A type-safe RPC for all webextension, client side code does not contain the actual called code, supports async generator functions
