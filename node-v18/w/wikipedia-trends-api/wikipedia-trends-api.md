# wikipedia-trends-api

> 标签: analytics, growth-rate, page-views, research, trend-data, trendsmcp, wikipedia, wikipedia-api, wikipedia-trends

## 简介

Wikipedia page view time series and growth via REST API. Weekly data, period-over-period growth, zero dependencies. Powered by trendsmcp.ai
