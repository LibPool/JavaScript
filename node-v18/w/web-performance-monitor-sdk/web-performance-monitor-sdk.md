# web-performance-monitor-sdk

> 标签: analytics, browser-performance, cls, core-web-vitals, fcp, fid, lcp, monitoring, performance, performance-metrics, performance-observer, real-user-monitoring, rum, sendBeacon, ttfb, web-performance, web-vitals

## 简介

A modern, lightweight performance monitoring SDK for web applications. Monitor Core Web Vitals (LCP, FCP, FID, CLS, TTFB) with sendBeacon support.
