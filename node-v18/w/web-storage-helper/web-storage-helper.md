# web-storage-helper

> 标签: IndexedDB, Temp, browser-stash, browser-storage, cookie, cookies, encrypt-storage, encrypted-storage, encryption, indexeddb, local-storage, localStorage, react, secure-storage, session-storage, sessionStorage, storage, storage-helper, typescript, web-storage, web-storage-helper

## 简介

A TypeScript library providing a unified API for managing browser storage with support for multiple storage types (localStorage, sessionStorage, cookies, IndexedDB, Temp) and optional encryption for secure data storage.
