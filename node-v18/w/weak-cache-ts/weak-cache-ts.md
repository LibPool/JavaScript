# weak-cache-ts

> 标签: async-cache, cache, deduplication, dispose, finalizationregistry, garbage-collection, gc-friendly, memoization, memory-management, object-cache, observable, promise, promise-deduplication, typescript, watcher, weak-cache, weakref

## 简介

Garbage-collectable cache for TypeScript/JavaScript using WeakRefs: synchronous and asynchronous object caching with auto-cleanup, deduplication, flexible keys (string/symbol), safe insertion modes, and GC-friendly memory management for browsers/Node.js.
