# wordpress-block-editor-po-to-json

> 标签: JED1.x compatible JSON file, Wordpress Gutenberg block internationalization, Wordpress Gutenberg block translation, Wordpress block editor json file for translations, Wordpress po file to json file conversion, Wordpress single json file from po file, Wordpress single json file with handle

## 简介

Generate JED1.x compatible json files from po files for use in Wordpress Gutenberg block translations and internationalization.
