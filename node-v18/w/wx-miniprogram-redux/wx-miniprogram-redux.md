# wx-miniprogram-redux

> 标签: miniprogram, redux

## 简介

可以在微信小程序中使用 redux + redux-saga + redux-logger 的工具库，并实现了类似 reselect 处理 redux 数据变动的功能，可以减少与该页面无关的 redux 数据变动带来 setData 的性能消耗
