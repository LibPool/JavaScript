# webpack-jso-obfuscator

> 标签: anti-tamper, bundle, code-protection, javascript, javascript-obfuscator, javascriptobfuscator, javascriptobfuscator-com, minify, obfuscation, obfuscator, protect, source-code-protection, webpack, webpack-obfuscator, webpack-plugin

## 简介

Obfuscate and protect your webpack bundle with JavaScript Obfuscator. Official webpack plugin for javascriptobfuscator.com: string encryption, control-flow flattening, member renaming.
