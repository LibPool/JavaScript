# watchandlearn

> 标签: claude-code, developer-tools, flashcards, fsrs, ink, learning, spaced-repetition, tui

## 简介

Companion TUI for Claude Code: spaced-repetition micro-practice generated from the code Claude just wrote in your repo, plus a live plain-language feed of what Claude is doing. Learn to code by not coding.
