# wane-eliza

> 标签: agent-security, ai-agent, antibody, base, eliza, elizaos, herd-immunity, onchain, plugin, threat-screening, wane

## 简介

elizaOS plugin for Wane: screen any recipient against the on-chain antibody registry before an agent signs (free, no API key), and publish novel threats back so the whole agent herd goes immune.
