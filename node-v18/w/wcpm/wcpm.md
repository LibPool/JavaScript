# wcpm

> 标签: JavaScript

## 简介

Web Component Package Manager [WCPM] is a package manager, like NPM, for Web Components. It is designed to be as simple and as fast as possible.

## 官网

- npm 页面：https://www.npmjs.com/package/wcpm
