# webpack-shebang-plugin

> 标签: #!, #!/, #!/usr/bin/env, #!/usr/bin/env node, bin, executable, hashbang, loader, node, nodejs, npm, plugin, shebang, shebang-loader, shebang-plugin, shebang-webpack, shebang2-loader, unix, webpack, webpack-shebang, webpack-shebang-plugin

## 简介

This is an all-in-one webpack plugin which prepends hashbangs automatically to the generated bundle files and make it executable -- all revived from your entry source file.
