# wisepanel-mcp

> 标签: ai, claude, decision-support, deliberation, gemini, mcp, model-context-protocol, multi-agent, perplexity, wisepanel

## 简介

MCP server for Wisepanel multi-agent deliberation platform. Run deliberations, stream results, and publish to the Wisepanel Commons from any MCP client.
