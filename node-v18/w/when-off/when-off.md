# when-off

> 标签: calendar, date, holiday, workday, 工作日, 工作日安排, 日历, 法定节假日, 节假日, 节假日安排, 调休, 调休安排

## 简介

一个用于处理日期、日历、节假日和工作日的 TypeScript 工具库, 并且提供各个国家法定节假日和调休安排信息数据
