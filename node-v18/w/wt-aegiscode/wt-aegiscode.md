# wt-aegiscode

> 标签: aegiscode, ci, cicd, code-scanning, devsecops, sarif, sast, sca, security, vulnerability

## 简介

WT-AegisCode CLI — queue security scans and fetch SARIF / JUnit / JSON results from CI/CD or a local shell. Talks to a WT-AegisCode server's public API with a Bearer token.
