# webpack-public-resource-aliyun-oss-plugin

> 标签: aliyun, oss, webpack

## 简介

配合 [webpack-aliyun-oss-plugin](https://github.com/mfylee/webpack-aliyun-oss-plugin) 使用，增加上传未经 webpack 编译的 public 文件夹静态资源到阿里云 OSS
