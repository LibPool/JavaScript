# wizinsight

> 标签: alerting, api-health, api-monitoring, automatic-monitoring, client-side, discord-alerts, error-handling, health-check, hyperwiz, javascript, lightweight, metrics, monitoring, nodejs, optimization, performance, performance-tracking, production-ready, request-tracking, typescript, uptime-monitoring, webhook, zero-config

## 简介

A lightweight performance monitoring & health tracking library for hyperwiz with Discord alerts and smart request optimization. Track API requests, monitor endpoint health, and get instant alerts when issues arise.
