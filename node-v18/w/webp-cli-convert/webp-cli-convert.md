# webp-cli-convert

> 标签: batch, cli, compress, converter, image, interactive, jpg, png, sharp, webp

## 简介

Zero-fuss CLI to convert images (JPG, PNG, GIF, TIFF, AVIF, BMP) to WebP, with an interactive folder browser and options wizard
