# web-pty

> 标签: browser, command, exec, express, koa, linux, openssh, pty, scp, secure, shel, shell, socket, socket.io, ssh, term, terminal, tty, web, web-pty, websocket, xshell

## 简介

web-pty是一个浏览器端的ssh工具，通过此工具，可以在浏览器中远程连接到linux服务器并进行管理，同时web-pty支持express和koa框架
