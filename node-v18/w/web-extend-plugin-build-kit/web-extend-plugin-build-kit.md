# web-extend-plugin-build-kit

> 标签: plugin, vite, vue2, web-extend-plugin, webpack

## 简介

Build kit for Vue 2.7 web extend plugins: manifest validate, pack to plugins/web layout, Vite/Webpack presets (var global + dev ping/SSE)
