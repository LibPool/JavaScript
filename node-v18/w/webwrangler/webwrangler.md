# webwrangler

> 标签: cheerio, chrome, cli, cli-app, puppeteer, scraper, scraping, web, web scraper, web scraping

## 简介

WebWrangler is a NodeJS library which allows to scrape and interact with websites using Puppeteer with YAML (NODE12 Support for Meteor)
