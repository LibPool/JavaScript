# whatsapp-messaging-api-mcp

> 标签: ai-agent, automation, claude, claude-desktop, mcp, mcp-server, messaging, model-context-protocol, rapidapi, whatsapp, whatsapp-api, whatsapp-bot

## 简介

MCP server for sending WhatsApp messages from Claude and other MCP clients. No Meta Business approval, no WhatsApp Business account — scan a QR code and send.
