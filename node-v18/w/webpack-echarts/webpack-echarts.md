# webpack-echarts

> 标签: JavaScript

## 简介

Enterprise Charts，基于Canvas，纯Javascript图表库，提供直观，生动，可交互，可个性化定制的数据可视化表。

## 官网

- 官网：http://echarts.baidu.com
- 源码仓库：git://github.com/ecomfe/echarts.git
- npm 页面：https://www.npmjs.com/package/webpack-echarts
