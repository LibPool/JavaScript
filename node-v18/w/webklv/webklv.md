# webklv

> 标签: binary, klv, metadata, misb, parsing, smpte-336, st0601, uas

## 简介

A fully web-compatible KLV (Key-Length-Value) data parsing library for JavaScript/TypeScript, with MISB ST 0601 and ST 0102 support.
