# wick-dom-observer

> 标签: custom-command, cypress, loading, modal, plugin, spinner, testing, toast

## 简介

A Cypress plugin that watches DOM changes after clicks to detect fast loading spinners and async UI transitions. It improves test reliability by waiting for real visual completion instead of fixed delays or intercepts.
