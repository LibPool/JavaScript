# web-miner

> 标签: bitcoin, coinhive, crypto, cryptocurrency, currency, miner, mining, monero, web-miner, xmr

## 简介

Uses javascript on the client-side to mine Monero to a specified wallet. Faster than setting up Google or amazon ads and avoids most adblockers.
