# whiskops-sdk

> 标签: device-control, iot, sdk, whisk

## 简介

Client SDK for the Whisk device External API (status, turn, stop) with built-in idempotency-key handling and retry/backoff.

- npm 页面：https://www.npmjs.com/package/whiskops-sdk
