# wang-create-code

> 标签: JavaScript

## 简介

+ fresh： 刷新验证码，该值变化就会刷新验证码 + contentWidth：宽度 ，默认100 + contentHeight：高度，默认35 + fontSizeMin：最小字号 ，默认18 + fontSizeMax：最大字号，默认36
