# win-clean

> 标签: cache, cleaner, cli, ink, temp, tui, windows

## 简介

Brutalist terminal cleaner for Windows 11 — temp files, browser caches, recycle bin, package caches, old downloads. Runs manually or on a schedule, then exits.
