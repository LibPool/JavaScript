# webunify

> 标签: build tool, web app, web app build tool, webunify

## 简介

A config based build and packaging tool for monolithilic web applications having multiple meaningful sub-applications. This tool then helps you to build and deploy each sub applications separately, thus removing inter sub application deployment dependency
