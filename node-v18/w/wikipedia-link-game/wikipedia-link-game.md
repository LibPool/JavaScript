# wikipedia-link-game

> 标签: JavaScript

## 简介

Play the Wikipedia game [Getting To Philosophy](https://en.wikipedia.org/wiki/Wikipedia:Getting_to_Philosophy) by opening a Wikipedia page and keep following the first link until a page with no links or a circle is found.
