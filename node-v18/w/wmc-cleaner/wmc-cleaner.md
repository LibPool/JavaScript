# wmc-cleaner

> 标签: ai, metadata, publishing, text-cleaning, unicode, watermark

## 简介

Remove AI text artifacts, AI phrases and file metadata before you publish. Detects and strips invisible unicode characters, losslessly cleans image metadata.
