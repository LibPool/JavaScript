# ws-file-drawer

> 标签: deepseek-harness, dsh, file-browser, file-drawer, plugin, workspace

## 简介

DSH 静态插件:工作区文件浏览器(悬浮可拖动按钮 + 文件树 + 内容/图片预览),随 dsh web 启动自动加载,支持多工作区与跟随当前会话工作区。
