# wpgoldmine

> 标签: cli, indie-hackers, market-research, plugins, saas-ideas, side-project, woocommerce, wordpress

## 简介

CLI to find WordPress plugin opportunities — abandoned, low-rated, or poorly-supported plugins with large user bases you could replace. Powered by wpgoldmine.io.
