# wasmley

> 标签: audio, browser, canvas, embedded, emscripten, fetch, functional, game, graphics, http, interpreter, json, lua, lua54, openal, runtime, scripting, wasm, webassembly, webgl

## 简介

Lua 5.4 runtime compiled to WebAssembly - run Lua in the browser with OpenAL audio, WebGL graphics, HTTP fetch, and 15+ embedded libraries and JIT
