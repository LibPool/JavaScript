# wonderui-tokens

> 标签: css-variables, design-system, design-tokens, tailwind, wonderui, wui

## 简介

WonderUI Tokens는 팀이 일관된 UI를 빠르게 만들 수 있도록 돕는 디자인 토큰 패키지입니다.   색상, 간격, 타이포그래피, 라운드, 그림자, 테두리 굵기 등 핵심 디자인 규칙을 CSS 변수로 제공해 어떤 프로젝트에서도 바로 사용할 수 있습니다.
