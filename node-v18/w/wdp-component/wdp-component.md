# wdp-component

> 标签: frontend, quark, web components

## 简介

基于本工程，您可以构建属于自己的跨技术栈/无框架 组件。并允许被发布到 npm 平台供他人使用。

## 官网

- npm registry：https://registry.npmjs.org/wdp-component
- Node 要求：>=12.0.0
