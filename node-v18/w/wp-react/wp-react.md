> 标签: authentication, cli, graphql, headless, headless-wordpress, hooks, jwt, react, react-query, rest-api, typescript, wordpress, wp, wp-graphql, wp-react, wp-rest-api

## 简介

A modern, fully-typed React toolkit for headless WordPress featuring REST/GraphQL hooks, JWT auth, React Query integration, and a setup CLI.
