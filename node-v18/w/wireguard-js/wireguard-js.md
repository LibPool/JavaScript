# wireguard-js

> 标签: bun, cloudflare, dns-over-https, doh, node, noise-protocol, tunnel, vpn, warp, wireguard

## 简介

Pure-JavaScript WireGuard VPN client. No CGo, no kernel drivers, no root required. Bun-native with Node.js fallback.
