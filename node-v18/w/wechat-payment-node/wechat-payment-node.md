# wechat-payment-node

> 标签: node, node 支付, nodejs, payment, wechat, wechat node, wechat nodejs, wechat payment, weixin, weixin node, weixin nodejs, weixin payment, weixin zhifu, 公众号支付, 微信, 微信支付, 支付

## 简介

微信支付 for nodejs,创建统一支付订单,查询订单,关闭订单,申请退款,查询退款详情,企业付款，即转账到个人微信钱包,查询企业付款详情 Payment API of Weixin (WeChat) for APP and also JSAPI
