# workbuddy-weknora-connector

> 标签: connector, mcp, proxy, rag, weknora, workbuddy

## 简介

WeKnora MCP Connector for WorkBuddy —— 代理 WeKnora 的 Streamable HTTP MCP 服务，动态暴露其全部工具，支持可自定义的服务端地址与 Bearer API Key 鉴权。
