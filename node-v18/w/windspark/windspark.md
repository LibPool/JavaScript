# windspark

> 标签: angular, cli, react, setup, tailwindcss, ui-library, vue, windspark

## 简介

WindSpark is a powerful CLI tool that quickly integrates Tailwind CSS, UI libraries, and custom configurations into React, Vue, and Angular projects.
