# wujie-instanceof-plugin

> 标签: JavaScript

## 简介

一个用于解决 wujie 微前端框架中，Element UI 和 T Design 等组件库在火狐（Firefox）浏览器环境下 Popper 弹出框显示异常问题的插件。
