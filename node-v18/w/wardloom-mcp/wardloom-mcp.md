# wardloom-mcp

> 标签: mcp, model-context-protocol, pre-deploy, security, ship-gate, wardloom

## 简介

MCP server for Wardloom — trigger pre-deploy security scans, poll the ship-gate verdict, fetch remediation roadmaps and Dev/AI handoff prompts, and run zero-network local prechecks, all from your IDE's AI agent.
