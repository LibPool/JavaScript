# webjsdev

> 标签: alias, cli, unscoped, webjs

## 简介

WebJs is a full-stack JavaScript framework built on web components, with server-side rendering and no build step. Runs on Node 24+ or Bun. This package is the unscoped alias for @webjsdev/cli and installs the `webjs` command.
