# workspaces-effect

> 标签: affected-packages, bun-workspaces, change-detection, dependency-graph, effect, effect-ts, lockfile, lockfile-parser, monorepo, npm-workspaces, package-manager, pnpm-workspaces, publishability, topological-sort, typescript, workspace, workspaces, yarn-workspaces

## 简介

Effect-TS library for monorepo workspace tooling — discover workspaces, analyze dependency graphs, detect changes, parse lockfiles, and check publishability across npm, pnpm, yarn Berry, and Bun.
