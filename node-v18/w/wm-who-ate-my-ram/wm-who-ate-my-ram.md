# wm-who-ate-my-ram

> 标签: cli, inspector, leak, memory, nodejs, process, profiler, ram

## 简介

Process memory inspector that watches your running Node processes and flags the one quietly ballooning over time. No setup, no API key. Resident evil for memory leaks.
