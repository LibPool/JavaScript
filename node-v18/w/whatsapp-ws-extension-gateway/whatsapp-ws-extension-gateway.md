# whatsapp-ws-extension-gateway

> 标签: api, automation, chrome-extension, gateway, messaging, websocket, whatsapp

## 简介

WebSocket gateway server for WhatsApp Chrome Extension automation with API key authentication, session management, and support for sending messages, images, videos, and documents.
