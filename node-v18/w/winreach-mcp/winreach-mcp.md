# winreach-mcp

> 标签: ai-agents, claude, claude-code, cloudflare-tunnel, codex, computer-use, mcp, mcp-server, model-context-protocol, powershell, remote, remote-execution, windows, windows-server

## 简介

Give your AI agent its own Windows machine: remote PowerShell, file transfer, screenshots, and full desktop control (computer use) over HTTP, secured with per-user keys, roles, command policies, mTLS, and an audit log.
