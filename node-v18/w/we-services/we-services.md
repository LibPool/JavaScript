# we-services

> 标签: JavaScript

## 简介

``` 一款好用的接口自动化生成接工具，前后端联调的好帮手 ``` ### 存在痛点：     * 接口文档不规范，后续开发人员不能快速上手     * 前端需要手动复制接口到service     * 前后端联调耗时长，大部分时间在对参数，调接口
