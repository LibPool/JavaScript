> 标签: api-client, auth-refresh, axios, branded-types, http-client, middleware, react-query, request-cancellation, retry, tanstack-query, type-safe, zod

## 简介

Type-safe HTTP client with branded validation, request deduplication, retry with backoff, auth token refresh, and middleware pipeline. Built for TanStack Query + Redux Thunk.
