# wasm_excel

> 标签: JavaScript

## 简介

纯前端导出 excel 。使用 rust 编译为 wasm , 兼容性好。可前端自由控制导出的数据，及数据样式。包含单元格颜色、背景色等。 暂时还不支持单元格合并，还在设计如何传参
