# watermark-video

> 标签: ffmpeg, video, watermark

## 简介

Simple tool to add watermarks to video files. Note that you need ffmpeg installed on your machine for this to work.

## 官网

- 官网：https://github.com/brunobasto/node-watermark
- 源码仓库：git@github.com:brunobasto/node-watermark.git
- npm 页面：https://www.npmjs.com/package/watermark-video

- npm registry：https://registry.npmjs.org/watermark-video
