# wa-spatialite

> 标签: geos, gis, proj, spatial, spatialite, sqlite, wa-sqlite, wasm, webassembly

## 简介

SpatiaLite (GEOS, PROJ) linked into wa-sqlite as a single WebAssembly module for the browser or workers.
