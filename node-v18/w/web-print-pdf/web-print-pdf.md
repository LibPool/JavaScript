## 简介

Silent printing SDK — Lodop / C-Lodop / hiprint alternative. Print HTML/PDF/images from browser to local printers via WebSocket with no print dialog. Vue, React. Receipts, thermal labels, invoices. Requires Web Print Expert Client.
