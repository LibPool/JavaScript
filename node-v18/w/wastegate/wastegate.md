# wastegate

> 标签: actions, ci, ci-cost, cost, cost-optimization, devops, finops, gh, gh-extension, github-actions, waste

## 简介

Dollar-denominated waste forensics for GitHub Actions. Audits your run history and prints which specific waste is costing you — with the exact YAML fix. Local, read-only, uses your gh auth.
