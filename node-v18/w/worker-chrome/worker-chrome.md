# worker-chrome

> 标签: agents, cdp, chrome, claude-code, headless, patchright, playwright, xvfb

## 简介

One always-on, real, logged-in Google Chrome on a headless Linux box for AI agents to drive. Real GPU, persistent profile, no headless or webdriver tells.
