# whitebox-pro-client

> 标签: analytics, browser, tracking, whitebox

## 简介

Whitebox browser client core — transport, identity, event emitter, plugin host. Channels (mail, voip, engagement, conversions, consent) ship as separate whitebox-pro-client-plugin-* packages.
