# work-with-llamacpp

> 标签: extension, llama.cpp, llamacpp, local-ai, pi-package, translation, vision

## 简介

Pi extension that bridges your local llama.cpp server to the agent — vision, translation, and general text tasks without cloud tokens. / Pi 扩展：让 agent 调用本地 llama.cpp（看图、翻译、通用文本任务），不消耗云端 token。
