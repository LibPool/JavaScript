# webpack_es6_polymer_demo

> 标签: JavaScript

## 简介

I need to avoid the <link rel="import" Polymer spagetti. The goal: be able to use ES6 modular code with ES6 import/exports and have one or multiple application bundles. So basically have a proper Javascript build process.
