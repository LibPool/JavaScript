# webhook-sig

> 标签: cli, crypto, github, hmac, security, shopify, signature, slack, standard-webhooks, stripe, svix, twilio, verification, verify, webhook, webhooks

## 简介

Verify and generate webhook signatures locally for Stripe, GitHub, Shopify, Slack, Twilio, and Svix. No network, no telemetry — pure node:crypto.
