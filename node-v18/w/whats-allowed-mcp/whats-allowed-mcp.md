# whats-allowed-mcp

> 标签: agents, audit, claude, claude-code, guardrails, hooks, mcp, model-context-protocol, permissions, security, settings

## 简介

MCP server that shows what your coding agent can do without asking you: every settings file that contributes permission rules, which one wins, what runs unattended, and the rules Claude Code accepts and then ignores.
