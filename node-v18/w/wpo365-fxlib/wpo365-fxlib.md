# wpo365-fxlib

> 标签: JavaScript

## 简介

wpo365-fxlib is a tiny helper library intended to offer developers that want to build custom integrations for WordPress and Microsoft Office 365. It expects WordPress Single Sign-on plugin wpo365-login(-premium) to be installed, activated and configured.
