# webpack-persagy-zip

> 标签: node读取git信息, vue创建version, vue打包zip

## 简介

vue-cli创建的项目，打包时自动读取git相关的信息并创建version文件, 然后压缩打包成zip

## 官网

- 源码仓库：https://gitee.com/wang1006008051/webpack-version-zip.git
- npm 页面：https://www.npmjs.com/package/webpack-persagy-zip
