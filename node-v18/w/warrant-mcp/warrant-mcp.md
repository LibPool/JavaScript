# warrant-mcp

> 标签: agent-guardrails, ai-agent, ai-safety, anthropic, claude, claude-code, guardrails, hook, llm, mcp, model-context-protocol, permissions, policy

## 简介

Write the rules for your AI agent once, in plain English. Deterministic code checks every tool call, and a Claude Code hook blocks the ones your rules forbid.
