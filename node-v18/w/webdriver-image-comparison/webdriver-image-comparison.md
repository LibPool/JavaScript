# webdriver-image-comparison

> 标签: JavaScript

## 简介

An image compare module that can be used for different NodeJS Test automation frameworks that support the webdriver protocol

## 官网

- 官网：https://webdriver.io/docs/visual-testing
- 源码仓库：git+https://github.com/webdriverio/visual-testing.git
- npm 页面：https://www.npmjs.com/package/webdriver-image-comparison
