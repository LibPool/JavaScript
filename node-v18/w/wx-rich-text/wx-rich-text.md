# wx-rich-text

> 标签: rich-text, wechat-mini-program, wx-rich-text

## 简介

项目是对[wxParse](https://github.com/icindy/wxParse)开源项目的封装，做成插件的形式方便使用。封装的过程中优化了在开发中遇到的一些问题：超链接会单独成为一行、video受富文本中的样式控制会出现超出屏幕的问题、图片长度超出限定长度后会有滚动条等等问题。
