# wolai-clipboard-mcp

> 标签: automation, chrome, clipboard, mcp, model-context-protocol, wolai

## 简介

A local stdio MCP server that focuses a Wolai page in the locally logged-in Google Chrome session on macOS, selects all content, copies it to the system clipboard, and optionally returns the copied text.
