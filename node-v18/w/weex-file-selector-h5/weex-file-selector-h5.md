# weex-file-selector-h5

> 标签: Vue, WeexModule, camcorder, camera, file, h5, html5, microphone, selector, weex

## 简介

weex-file-selector-h5 提供 weex 选择文件的组件。支持调取相机，摄像，录音。仅支持h5。
