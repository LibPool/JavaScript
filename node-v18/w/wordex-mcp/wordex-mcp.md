## 简介

WordEX — A fully local MCP server for reading, writing, and editing Word (.docx), Excel (.xlsx), PDF, and PowerPoint (.pptx) files from GitHub Copilot and any MCP-compatible AI. 20 tools. Zero data leaves your machine.
