# wimui

> 标签: a11y, accessibility, components, design-system, i18n, react, storybook, typescript, ui

## 简介

React component library with design tokens, dark mode, i18n (en/ja/pt-BR), and WAI-ARIA compliant accessibility. 200+ components documented in Storybook.
