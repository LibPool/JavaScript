# wappler-mqtt-server

> 标签: iot, mqtt, nodejs, server-connect, wappler, wappler-extension

## 简介

MQTT module for Wappler Server Connect (NodeJS) - background subscriptions and publishing from the server, using raw MQTT over TCP/TLS.
