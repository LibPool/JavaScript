# webfilteringdatabase

> 标签: acceptable use policy, cipa, content filtering, dns filtering, domain categorization, domain intelligence, firewall categories, iab taxonomy, parental controls, secure web gateway, url categorization, url database, web filtering, website classification

## 简介

Node.js client for the Web Filtering Database API: classify any domain or URL into 59 web filtering categories plus IAB content categories, from a database of 120M+ categorized domains built for firewalls, DNS resolvers and secure web gateways.
