# wiacode

> 标签: barcode, batch, cli, icalendar, offline, qr, qrcode, vcard, wia, wiacode, wifi

## 简介

WIA Code CLI — make a WIA Code (offline-capable code with a booster QR) from the command line. Wi-Fi, contact cards, calendar events, and batch. 설치 없이: npx wiacode card --name "홍길동"
