# websearch-tool

> 标签: ai-agent, brave-search, chromium, headless, llm-tool, markdown, mojeek, multi-engine, playwright, search, web-scraping, websearch

## 简介

Headless Chromium web search and page fetching tool for Node.js AI agents. Returns results as clean markdown with embedded hyperlinks.
