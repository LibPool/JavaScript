# workerdeck

> 标签: agent, anthropic, claude, claude-code, cli, dashboard, server

## 简介

Turnkey WorkerDeck instance: `npx workerdeck` runs the session gateway and the full dashboard on one port. The @workerdeck/* packages are the libraries you embed; this is the service you run.
