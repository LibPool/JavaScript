# wit-protocol

> 标签: agents, ai, claude-code, coordination, copilot, cursor, git, locking, merge-conflicts, multi-agent, tree-sitter

## 简介

Coordinate multiple AI coding agents on the same codebase. Declare intents, lock symbols, detect conflicts — before code is written.
