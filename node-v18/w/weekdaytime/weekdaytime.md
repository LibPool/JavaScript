# weekdaytime

> 标签: calendar, interval, recurring, schedule, time, typescript, week, weekday

## 简介

Represent a repeating set of time intervals (00:00-23:59) during the week from a JSON string containing days of the week and corresponding time intervals separated by commas. Transform this input into a structured array representing weekday times in a nor
