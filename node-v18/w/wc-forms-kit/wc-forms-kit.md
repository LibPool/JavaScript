# wc-forms-kit

> 标签: alpine forms, angular forms, form generation, formkit, forms, react forms, vanilla js, vue forms, wc-forms-kit, web components

## 简介

Is a modular, 100% vanilla js, form inputs group, based on [Vue FormKit](https://formkit.com/getting-started/what-is-formkit) library.
