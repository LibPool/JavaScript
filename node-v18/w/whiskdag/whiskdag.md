# whiskdag

> 标签: dagular, dsl, gradual-typing, openwhisk, serverless, type-checking, workflow, wsk

## 简介

Dagular: a functional DSL and CLI for typed, parallel serverless workflows on Apache OpenWhisk. Ships the dagular-enabled wsk CLI (wsk dag compile/deploy).
