# wolo-editor

> 标签: block-editor, chinese, contenteditable, editor, markdown, notion, rich-text, wolai, wysiwyg, 可视化编辑器

## 简介

wolai/Notion 风格的块级 Markdown 可视化编辑器。零依赖单文件，支持斜杠菜单、拖拽排序、跨块撤销、搜索高亮、已阅标记、深浅主题、GitHub 表格、图片视频上传。Block-style Markdown editor like wolai/Notion, zero-dependency.
