# wp-native-shell

> 标签: abilities-api, expo, expo-router, framework, mobile-app, react-native, wordpress

## 简介

React Native app shell for wp-native. expo-router-native: providers + DrawerContent slot + ability-driven screens. Turn any WordPress site into a real native app.
