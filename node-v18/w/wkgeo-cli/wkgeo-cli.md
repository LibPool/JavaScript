# wkgeo-cli

> 标签: cli, cloudbase, oauth, pkce, wkgeo, 云站

## 简介

云站平台官方命令行客户端：授权登录一次，之后建站 / 下单 / 钱包支付 / 查余额都不用再登录（OAuth 授权码 + PKCE，公共客户端，零第三方依赖）
