# web-worker-enhance

> 标签: Vite, Vite-plugin, Web Worker, rollup-plugin

## 简介

基于 Web Worker 实现的后台计算方法，提供了 Vite 钩子，可让 Vite 项目中的 JS 模块多线程运行
