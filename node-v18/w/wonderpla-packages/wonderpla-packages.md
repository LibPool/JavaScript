# wonderpla-packages

> 标签: JavaScript

## 简介

Commands flow 1. setup git repo 2. npx create-react-app wonderpla --template typescript 3. npx storybook@latest init 4. It will start installing storybook in your project 5. npm run storybook 6. npm install @mui/material --save 7. npm install @mui/icons-m
