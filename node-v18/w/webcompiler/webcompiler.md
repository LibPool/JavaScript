# webcompiler

> 标签: compile, ecosystem-react, es6, es7, flow, gzip, isomorphic console.log, javascript, jsdoc, jsx, lint, markdown, minify, package, react, sass, syntax highlighter, typecheck, uglify, watcher, yaml

## 简介

Lint, type-check, compile, package and gzip JavaScript (ES6 + Flow static types + JSX), for the browser as well as NodeJS; lint, compile, auto-prefix, minify and gzip SASS.
