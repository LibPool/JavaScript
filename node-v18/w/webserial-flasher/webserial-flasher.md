# webserial-flasher

> 标签: arduino, atmega, attiny, avr, avr109, avrdude, esm, firmware, flasher, picoboot, raspberry-pi-pico, rp2040, stk500, stk500v2, typescript, updi, webserial, webusb

## 简介

Multi-protocol firmware flasher — STK500v1, STK500v2, AVR109, UPDI, PICOBOOT (RP2040) — ESM, TypeScript, Node.js + WebSerial browser support.
