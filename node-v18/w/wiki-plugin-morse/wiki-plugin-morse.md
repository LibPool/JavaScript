# wiki-plugin-morse

> 标签: cw, federated wiki, liquidsoap, morse, plugin, radio, wiki

## 简介

Federated Wiki - Morse Plugin: key short texts as Morse code from a wiki item — hear it, watch the tape, export a WAV, send it to the station
