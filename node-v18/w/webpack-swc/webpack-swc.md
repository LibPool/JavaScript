# webpack-swc

> 标签: swc, webpack, webpack-swc

## 简介

极速 webpack 构建工具，底层基于 SWC 编译。零配置开箱即用，可在 React 和 Vue 3 项目中无缝切换使用。

## 官网

- npm 页面：https://www.npmjs.com/package/webpack-swc

- 1.0.0-beta.1
