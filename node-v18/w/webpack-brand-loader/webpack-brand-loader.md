# webpack-brand-loader

> 标签: JavaScript

## 简介

Webpack Loader to apply brands to files, eg. with a WEBPACK_BRAND environment variable of mybrand set, it would look for files of the format filename.mybrand.extension and then fall back to filename.extension if the file doesn't exist
