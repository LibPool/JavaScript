# whisper-pi

> 标签: agent-identity, cypher, egress, ipv6, mcp, model-context-protocol, pi, pi-package, security-graph, threat-intelligence, whisper

## 简介

Native Pi extension: give a Pi coding agent a real, routable Whisper IPv6 /128 identity - keyless verify/RDAP; the full control plane, /128 egress, and the whisper.security graph (Cypher + 29 recipes) with a key.
