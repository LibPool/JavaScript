# website-assets-generator

> 标签: cli, favicon, icons, manifest, pwa, sharp

## 简介

CLI pour générer automatiquement les assets web (favicons, icônes, manifest, browserconfig, meta tags) à partir d'un logo.

- npm 页面：https://www.npmjs.com/package/website-assets-generator

- npm registry：https://registry.npmjs.org/website-assets-generator
- Node 要求：>=18
