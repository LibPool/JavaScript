# @mapled/client

> 标签: browser, client, cms, headless-cms, mapled, sdk, typescript

## 简介

Mapled's JavaScript client — read published content from any JavaScript runtime: a browser, Node, an edge function. Preview, publish notifications and forms included; no framework, no dependencies.
