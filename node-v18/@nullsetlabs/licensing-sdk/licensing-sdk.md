# @nullsetlabs/licensing-sdk

> 标签: JavaScript

## 简介

Cliente Node pro hub de licenciamento da NullsetLabs (NullsetLicensing) — consultar status de licença, reportar uso, checagem cacheada com fallback, signup/faturas/pagamento self-service.
