# gindim-captcha

> 标签: aj-captcha, captcha, gindim, slider

## 简介

Gindim 行为验证码。Node 服务端签名转发，网页滑块与 Flutter SDK 使用同一套样式和 sliderOffset 算法。

- 官网：https://gindim.tahoe.top
- npm 页面：https://www.npmjs.com/package/gindim-captcha

- npm registry：https://registry.npmjs.org/gindim-captcha
