# @alpacachen/dsh-kanban

> 标签: deepseek-harness, dsh, dsh-plugin, kanban, plugin

## 简介

A kanban board plugin for DeepSeek Harness: a 'Board' tab, card comments and 16 kanban_* AI tools, with per-workspace isolation and disk persistence.
