# @towns-protocol/vodozemac

> 标签: JavaScript

## 简介

These are the Javascript bindings for [vodozemac](https://github.com/matrix-org/vodozemac). Web based environments are supported as well as node based ones.

## 官网

- npm 页面：https://www.npmjs.com/package/@towns-protocol/vodozemac

## 获取地址

- npm 安装：`npm install @towns-protocol/vodozemac`
- npm registry：https://registry.npmjs.org/@towns-protocol/vodozemac
- Node 要求：>= 18
