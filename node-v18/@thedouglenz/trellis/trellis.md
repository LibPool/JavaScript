# @thedouglenz/trellis

> 标签: agents, ai, claude-code, cli, codex, cursor, gui, opencode

## 简介

A GUI for driving coding agents on your own machine, from web, desktop or phone. Fork of T3 Code (pingdotgg/t3code) adding agent-built plan graphs.
