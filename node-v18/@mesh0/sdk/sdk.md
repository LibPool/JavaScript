# @mesh0/sdk

> 标签: events, logging, mesh0, observability, otlp, sse, telemetry, tql, tracing, websocket

## 简介

Official JavaScript/TypeScript client for the mesh0 telemetry platform — send events, query with TQL, tail with SSE/WebSocket.
