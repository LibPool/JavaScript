> 标签: ai, claude, cursor, image-editing, interior-design, mcp, model-context-protocol, modelcontextprotocol, pedra, proptech, real-estate, renovation, virtual-staging

## 简介

Official Model Context Protocol (MCP) server for the Pedra API — use Pedra's AI real-estate photo editing (virtual staging, renovation, enhancement, sky replacement, object removal/blur, and video) from Claude, ChatGPT, Cursor, and other MCP clients.
