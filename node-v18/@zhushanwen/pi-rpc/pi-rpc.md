# @zhushanwen/pi-rpc

> 标签: JavaScript

## 简介

Shared pi process RPC layer for taiji: spawn argv builders (main-agent / subagent templates), LF-only NDJSON framing with pending registry + tiered timeouts, command frame assembly, SIGCONT-first kill chain, and pi outbound env composition. Extracted verb
