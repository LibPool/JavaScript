# @zhushanwen/pi-ext-guards

> 标签: guard, idempotency, pi, pi-package, shared

## 简介

Shared runtime-environment guards for Pi extensions — oncePerProcess(key, fn) dedupes cross-session side-effect operations against pi factory re-invocation and handler accumulation (shared library, not a Pi extension, zero dependencies).
