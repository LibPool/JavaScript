# @cognitiveproof/c2pa-react-ddex-component

> 标签: c2pa, component, content-credentials, ddex, ern, music, provenance, react

## 简介

A React plugin for c2pa-react-component that renders DDEX (Digital Data Exchange) ERN release, resource, party, and deal data from a C2PA manifest.
