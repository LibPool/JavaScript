# @deverjak/tenantkit-plugin-sms

> 标签: JavaScript

## 简介

Reference SMS plugin for tenantkit, behind a swappable SmsProvider port (Twilio / SMSbrana). requiresTier: 'pro'. Touches the system only through the five plugin seams.
