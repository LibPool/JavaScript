# @nestjs-yalc/crud-gen

> 标签: JavaScript

## 简介

Factory-driven CRUD generator for NestJS with TypeORM and GraphQL/REST helpers (resolvers/controllers, services, dataloaders, repositories, DTO/field mapping).
