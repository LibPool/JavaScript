# @hdwebsoft/hdcode-agent-team

> 标签: agent, concurrency, coordination, file-reservation, inbox, multi-agent, opencode, plugin, task-management, team

## 简介

OpenCode plugin for multi-agent team coordination — per-agent inboxes, task management with dependency tracking, file reservation/locking, and atomic mkdir-based concurrency control.
