# dsh-plugin-minecraft

> 标签: ai-agent, deepseek-harness, dsh, dsh-plugin, mcp, minecraft

## 简介

Let DeepSeek Harness play Minecraft: connects DSH to the mc-agent-mcp mod (MCP server inside the game) with zero configuration.
