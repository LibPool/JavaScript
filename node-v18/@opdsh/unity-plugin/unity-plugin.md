# @opdsh/unity-plugin

> 标签: cordis, deepseek-harness, dsh-plugin, unity

## 简介

DeepSeek Harness plugin: control the Unity Editor through the unity CLI — project management, live-editor pipeline commands, and C# eval as agent tools.
