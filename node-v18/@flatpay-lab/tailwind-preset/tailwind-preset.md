# @flatpay-lab/tailwind-preset

> 标签: JavaScript

## 简介

Tailwind v4 CSS-first preset for Flatpay prototypes. Re-exports the @flatpay-lab/ui token CSS and wires the @theme inline / @source directives so prototypes drop a single @import line into their globals.css.
