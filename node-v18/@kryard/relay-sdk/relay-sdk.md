# @kryard/relay-sdk

> 标签: 7702, account-abstraction, eip-7702, gasless, kryard, paymaster, relayer, sponsored-transaction, turnkey, viem

## 简介

Thin client for Kryard's managed EIP-7702 relay: signAuthorization → sponsored execute, with optional ERC-20 gas payment.
