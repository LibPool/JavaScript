# @kanso-protocol/mcp

> 标签: ai, angular, claude, design-system, kanso, mcp, model-context-protocol

## 简介

Kanso Protocol — Model Context Protocol server. Exposes the component / pattern / token catalog to AI agents so they can author Kanso UI without leaving the editor.
