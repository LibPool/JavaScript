# @gotong/im-adapter

> 标签: JavaScript

## 简介

Gotong IM bridge SDK — abstract ImBridge interface + command parser + BindingResolver contract that concrete bridges (@gotong/im-telegram, @gotong/im-matrix, etc.) build on top of.
