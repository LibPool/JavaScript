# @1001-digital/ponder-ens

> 标签: JavaScript

## 简介

Reusable ENS profile resolution and caching for [Ponder](https://ponder.sh) indexers. Provides on-demand ENS lookups via viem, 30-day cache TTL, and ready-to-mount Hono API routes.
