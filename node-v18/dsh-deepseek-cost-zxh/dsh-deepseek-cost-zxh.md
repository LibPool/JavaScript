# dsh-deepseek-cost-zxh

> 标签: billing, deepseek, deepseek-harness, dsh, dsh-plugin, token-cost, web-ui

## 简介

在 DSH Web 的「Token 用量」弹窗最后一行追加「实际花费」：按 DeepSeek 官方价目（含高峰/空闲时段）估算本次会话的花费。
