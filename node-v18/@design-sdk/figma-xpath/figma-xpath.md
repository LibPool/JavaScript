# @design-sdk/figma-xpath

> 标签: JavaScript

## 简介

For most cases, xpath on design is used for locating same child on main component, etc.. in this navigating scenario, we only need fraction of xpath's feature, optimized for design format. Light mode xpath is not a real xpath, it only mocks the navigating
