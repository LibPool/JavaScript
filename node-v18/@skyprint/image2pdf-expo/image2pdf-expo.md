# @skyprint/image2pdf-expo

> 标签: expo, heic, image, jpg, pdf, png, react-native, wasm

## 简介

Expo / React Native bridge for image2pdf — converts JPG/PNG/HEIC images to a single A4 PDF entirely on-device.
