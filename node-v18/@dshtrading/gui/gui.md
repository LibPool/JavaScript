# @dshtrading/gui

> 标签: JavaScript

## 简介

GUI-plane bundle for dsh-trading: the browser-half rows (settings shell, stage views, language packs, updater dialog) and the web-host-only dual-half row (IM). Split out of @dshtrading/base on 2026-10-01 so the bot install closure carries no @dshtrading/c
