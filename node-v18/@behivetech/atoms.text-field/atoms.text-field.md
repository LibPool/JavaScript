# @behivetech/atoms.text-field

> 标签: JavaScript

## 简介

A bare text input — the native `<input>` is this component's own root element. It has no built-in label/hint/error; wrap it in `FormField` for that chrome. Works standalone too — not every input needs the full form suite.
