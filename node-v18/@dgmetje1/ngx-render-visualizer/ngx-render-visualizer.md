# @dgmetje1/ngx-render-visualizer

> 标签: angular, change-detection, devtools, onpush, performance, profiler, render, signals, visualizer, zoneless

## 简介

See what Angular change detection does: flashes checked and re-rendered components, shows why each cycle ran, and live render metrics. Dev-only, one provider line, or a script tag.
