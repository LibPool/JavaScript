# @casoon/opengrid

> 标签: accessibility, datagrid, pivot, react, svelte, vue, wasm, web-components

## 简介

Accessible data grid, table and pivot as web components, driven by a portable Rust/WASM query engine — with React, Vue and Svelte components.
