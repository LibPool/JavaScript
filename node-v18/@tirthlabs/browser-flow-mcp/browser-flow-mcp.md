# @tirthlabs/browser-flow-mcp

> 标签: ai-agents, browser-automation, claude, cursor, llm-tools, mcp, model-context-protocol, playwright, rpa, web-scraping, workflow-automation, yaml

## 简介

Write browser automations in YAML and run them from the CLI, cron, or as MCP tools that AI agents (Claude, Cursor, VS Code) can call. Powered by Playwright.
