# @ts-ioc-container/bundler

> 标签: bundler, cli, codegen, component-scan, dependency-injection, di, ioc, ts-ioc-container, tsconfig-paths

## 简介

Bundles your dependencies into a single container module for ts-ioc-container: the `tic` CLI scans folders (by path or tsconfig alias) and generates one typed bundle that registers every class — `container.useModule(new AppBundle())`.
