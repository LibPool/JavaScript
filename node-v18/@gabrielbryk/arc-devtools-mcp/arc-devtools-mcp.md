# @gabrielbryk/arc-devtools-mcp

> 标签: JavaScript

## 简介

Arc-compatible MCP server for Chrome DevTools. Fork of chrome-devtools-mcp that adds an --arc mode so new_page reuses a blank tab instead of crashing Arc.
