# @opensquad/dsh-voice-input

> 标签: asr, cordis, deepseek-harness, dsh-plugin, sensevoice, speech-to-text, voice, voice-input

## 简介

SenseVoice 语音输入插件 for DeepSeek Harness：在对话输入框旁添加麦克风按钮，录音后调用本地 SenseVoice 服务转成文本填入输入框。首次使用自动下载模型并显示进度，后端由插件自动启动。
