# @causeline/next

> 标签: debugging, devtools, next, nextjs, opentelemetry, spring-boot, traceparent, tracing

## 简介

Causeline for Next.js: puts route handlers, server actions, rendering and server-side fetches in the same trace as the React click and the Spring Boot request.
