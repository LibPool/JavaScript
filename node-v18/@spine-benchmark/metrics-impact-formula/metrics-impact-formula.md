# @spine-benchmark/metrics-impact-formula

> 标签: JavaScript

## 简介

Canonical Rendering / Computational Impact formulas shared by every Spine Benchmark scorer. Zero runtime dependencies so leaf consumers (e.g. pixi-crawler) can pull it in without dragging in the analysis pipeline.
