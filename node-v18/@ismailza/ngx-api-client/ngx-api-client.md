# @ismailza/ngx-api-client

> 标签: angular, backoff, http, httpclient, interceptor, pagination, problem-details, retry, rfc7807, rfc9457

## 简介

A typed, interceptor-driven HTTP layer for Angular: versioned URLs, RFC 9457 problem+json error normalisation, retry with backoff, and pluggable error/success handlers.
