# @cyberdione/aegis-vault-web

> 标签: argon2, browser, ed25519, hsm, indexeddb, vault, webauthn

## 简介

Encrypted browser identity vault — passphrase + WebAuthn-PRF, AES-256-GCM at rest, HSM-shaped per-purpose Ed25519 signing slots. Vanilla core + Web Component widget + optional framework adapters.
