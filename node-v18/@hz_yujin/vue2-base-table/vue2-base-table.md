# @hz_yujin/vue2-base-table

> 标签: JavaScript

## 简介

Vue 2 ProTable / ProPageTable：搜索、valueType、筛选、持久化、树表、行内编辑、批量操作、骨架屏、导出打印、移动端卡片、ProDialog（兼容 Vue 2.6 + @vue/composition-api / Vue 2.7）
