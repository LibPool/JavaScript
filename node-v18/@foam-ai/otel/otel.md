# @foam-ai/otel

> 标签: JavaScript

## 简介

Foam's Node.js base package: a thin, safe wrapper around the official OpenTelemetry libraries that turns on automatic instrumentation, ships the data to foam, and provides a small set of bulletproof helpers.
