# @ts-task/fetch

> 标签: JavaScript

## 简介

This library is a wrapper of the [fetch API](https://developer.mozilla.org/en-US/docs/Web/API/Fetch_API/Using_Fetch) to use with [Tasks](https://github.com/ts-task/task) instead of promises.
