# @tuwaio/satellite-core

> 标签: connect, core, headless, immer, typescript, wallets, web3, zustand

## 简介

Layer 3 (L3) of the TUWA Ecosystem. Framework-agnostic core state store for tracking multi-chain connection lifecycles and active wallet sessions.
