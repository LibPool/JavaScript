# @uploadcn/core

> 标签: chunked, file-upload, multipart, r2, resumable, s3, shadcn, tus, upload

## 简介

Framework-agnostic upload engine: queueing, concurrency, retries, chunked and resumable uploads, validation and storage adapters.
