# @eljefedelrodeo/canvas-datagrid

> 标签: component, data, data-grid, data-table, datagrid, datatable, grid, table

## 简介

Canvas based data grid web component.  apable of displaying millions of contiguous hierarchical rows and columns without paging or loading, on a single canvas element.
