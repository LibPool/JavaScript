# @scalarislab/docsmirror-mcp

> 标签: agents, docs, documentation, markdown, mcp, model-context-protocol

## 简介

Model Context Protocol server for DocsMirror. Serves a project's documentation map, what exists, what it covers, and which code depends on it, to coding agents.
