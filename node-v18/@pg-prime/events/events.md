# @pg-prime/events

> 标签: event-log, events, listen-notify, pg-prime, postgres, postgresql, pubsub

## 简介

Typed LISTEN/NOTIFY channels, a durable event log with subscriptions, and tails for pg-prime. Pre-alpha — the API will change.
