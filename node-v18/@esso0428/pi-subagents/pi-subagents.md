# @esso0428/pi-subagents

> 标签: agent, autonomous, pi, pi-extension, pi-package, subagent

## 简介

A pi extension that brings smart Claude Code-style autonomous sub-agents to pi, with npm:pi-subagents-style JSON agent overrides.
