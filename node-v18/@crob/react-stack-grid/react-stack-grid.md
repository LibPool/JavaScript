# @crob/react-stack-grid

> 标签: grid, layout, masonry, react, stack, typescript

## 简介

A responsive and dynamic stack grid component for React, designed to make it easy and efficient to create dynamic, responsive grid layouts. It automatically arranges items based on the available container width, ensuring a visually appealing presentation
