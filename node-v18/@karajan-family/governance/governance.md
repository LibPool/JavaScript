# @karajan-family/governance

> 标签: agents, audit, governance, karajan, policy

## 简介

Governance kernel for agent actions — Policy, Decision and Exception as first-class objects. Deterministic, local, domain-agnostic: adapters map each domain's actions and artifacts (karajan-code is the first consumer, not the owner).
