# @lottiefiles/dotlottie-io-linux-arm64-musl

> 标签: N-API, NAPI, Rust, napi-rs, node-addon, node-addon-api

## 简介

Rust library for creating, modifying and updating .lottie files. Contains bindings for Node and WASM.
