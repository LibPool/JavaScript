# opal-sprites

> 标签: alpha, gamedev, pixi, pixijs, sprites, transparent, video, wasm, webcodecs, webgl

## 简介

Transparent video sprites for web games: play .opal files with a ~15 KB WebGL2 runtime, or as PixiJS textures.
