# @mseep/motionspec

> 标签: a11y, accessibility, accessibility-testing, ai-generated, animation, compiler, css, deterministic, gsap, json-schema, llm, mcp, mcp-server, motion, motion-accessibility, mseep, prefers-reduced-motion, reduced-motion, scroll, scrolltrigger, waapi, wcag, web-animation

## 简介

Open-core motion layer for the web: deterministic compiler + MCP server. Validates motion specs fail-closed, reports WCAG 2.2.2 pause-path candidates, and flags missing reduced-motion guards (2.3.3, an AAA best practice).
