# @grafloria/engine

> 标签: dashboard, diagram, erd, flowchart, graph, layout, mermaid, node-editor, svg, uml

## 简介

Headless diagram engine — graph model, commands and undo, layout engines (ELK, dagre, force, tree), Mermaid-compatible text format, collaboration op-log
