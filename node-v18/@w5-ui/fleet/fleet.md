# @w5-ui/fleet

> 标签: dash-ui, dashboard, design-system, fleet, svelte, svelteflow, topology

## 简介

Fleet-board: a grouped SvelteFlow topology canvas + drill-down panel for operator dashboards, driven by an injectable backend contract. Part of Webber's design systems.
