# @qpher/sdk

> 标签: cryptography, dilithium, encryption, fips-203, fips-204, fips-205, kem, kyber, ml-dsa, ml-kem, nist-pqc, post-quantum, pqc, qpher, quantum-safe, signatures, slh-dsa, sphincs-plus, x-wing

## 简介

Official Node.js SDK for the Qpher Post-Quantum Cryptography API — ML-KEM-768 (FIPS 203) encryption, ML-DSA-65 (FIPS 204) digital signatures, and SLH-DSA (FIPS 205) hash-based signatures. Alternative to liboqs.
