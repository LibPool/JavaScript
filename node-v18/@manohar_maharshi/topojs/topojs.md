# @manohar_maharshi/topojs

> 标签: TDA, Vietoris-Rips, computational topology, cubical complex, javascript, persistent homology, topological data analysis

## 简介

Pure-JavaScript persistent homology library (H0, H1, H2, cubical). No WASM, WebGL, WebGPU, or server required.
