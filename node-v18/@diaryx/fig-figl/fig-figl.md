# @diaryx/fig-figl

> 标签: comment-preserving, config, fig, figl, parser, wasm, webassembly

## 简介

Figl, fig's authoring dialect for @diaryx/fig: fig's own parser, printer and editing rules for the language, written in Rust and compiled to a WebAssembly module of its own. Pass it to registerLanguage.
