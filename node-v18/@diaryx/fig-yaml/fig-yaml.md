# @diaryx/fig-yaml

> 标签: comment-preserving, config, fig, parser, wasm, webassembly, yaml

## 简介

YAML for @diaryx/fig: fig's own parser, printer and editing rules for the language, written in Rust and compiled to a WebAssembly module of its own. Pass it to registerLanguage.
