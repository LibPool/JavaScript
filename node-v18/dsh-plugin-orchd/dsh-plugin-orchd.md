# dsh-plugin-orchd

> 标签: deepseek-harness, dependency-graph, dsh, dsh-plugin, orchd, panel, read-only, task-board

## 简介

Read-only orchd panel for the DSH right sidebar: task board, dependency graph, ideas and review timeline for the project of the current session. · 把 orchd 项目状态带进 DSH 右侧栏的只读面板。
