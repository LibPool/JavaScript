# @xlsama/md

> 标签: autocorrect, browser, bun, editor, markdown, meowdown, oxfmt, wysiwyg

## 简介

Edit local Markdown in your browser: one `md` command, live sync with AI-agent edits, auto-format on save. 浏览器里的本地 Markdown 编辑器。
