# sf-plugin-preflight

> 标签: devops, impact-analysis, oclif-plugin, salesforce, sf, sf-plugin, sfdx

## 简介

Salesforce CLI plugin for sf-preflight: see what a Salesforce change sets off before it ships. Adds `sf preflight analyze`, `tests`, `agents`, `incidents`, `monitor`, `rollback` and more.
