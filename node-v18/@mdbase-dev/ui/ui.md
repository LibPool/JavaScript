# @mdbase-dev/ui

> 标签: JavaScript

## 简介

The shared visual foundation of mdbase apps: Editor, Reader, Writer, and any app that wants to look like part of the family. Nothing here is required to build on mdbase Connect.

- 官网：https://mdbase.dev
- 源码仓库：git+https://github.com/mdbase-dev/mdbase-connect.git
