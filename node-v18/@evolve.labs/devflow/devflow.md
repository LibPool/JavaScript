# @evolve.labs/devflow

> 标签: ai-agents, anthropic, claude, claude-code, devflow, multi-agent, software-development

## 简介

Multi-agent system for software development with Claude Code. 8 specialized agents (Strategist, Architect, System Designer, Builder, Guardian, Sentinel, Challenger, Chronicler) as slash commands.
