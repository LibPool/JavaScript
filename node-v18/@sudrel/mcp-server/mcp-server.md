# @sudrel/mcp-server

> 标签: brasil, cte, fiscal, mcp, model-context-protocol, nfe, nfse, nota-fiscal, sudrel

## 简介

Servidor MCP da Sudrel: deixa um agente de IA consultar, em modo somente leitura, as notas fiscais recebidas pelo CNPJ da empresa (NFS-e, NF-e e CT-e) e as NFS-e que ela emite.
