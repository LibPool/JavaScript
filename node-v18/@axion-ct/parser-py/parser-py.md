# @axion-ct/parser-py

> 标签: JavaScript

## 简介

Python front-end for Code Translator: parses Python source into the shared parser contract defined in `@axion-ct/core` (`ParseResult`, spans, tokens, scopes — see `docs/architecture.md` §4).
