# @workmate/nuxt-auth

> 标签: access-token, auth-guest-middleware, auth-middleware, authentication, authorization, composables, cookies, github-auth, google-auth, jwt, local-auth, middleware, multi-provider, nuxt, nuxt-module, nuxt3, nuxt4, oauth, redirects, refresh-token, route-middleware, schema-validation, typescript, useAuth, useAuthFetch, useAuthUser, zod

## 简介

Authentication module for Nuxt 3 and Nuxt 4 with local credentials, GitHub, and Google OAuth — Zod schema validation, refresh tokens, cookie management, route middleware, and typed  composables.
