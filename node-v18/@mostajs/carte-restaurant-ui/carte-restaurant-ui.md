## 简介

Vues PURES (view-model → HTML) de la carte : LISTE DE TRAVAIL de ce qui reste à saisir, fiche technique, prix daté, réglage de livraison. Compose @mostajs/app-shell-ui. Aucune logique métier, aucun accès données — le moteur est @mostajs/carte-restaurant.
