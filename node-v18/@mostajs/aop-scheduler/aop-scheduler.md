# @mostajs/aop-scheduler

> 标签: JavaScript

## 简介

Orchestrateur de veille d'appels d'offres (ingestion → matching d'alertes) placé JUSTE AVANT le trigger : émet les événements vers @mostajs/trigger. Compose ingestion/core/alerts + hub injectés.
