# @mostajs/jsonlogic-editor

> 标签: abac, access-control, editor, jsonlogic, mostajs, pap, pbac, react, rules

## 简介

Éditeur visuel de règles jsonLogic (PAP) pour l'access-control @mostajs — cœur headless typé (catalogue d'opérateurs, describe, validate, round-trip) + composant React no-build. Émet du jsonlogic consommable par abac/pbac ; preview live via @mostajs/rules
