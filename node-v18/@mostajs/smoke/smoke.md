# @mostajs/smoke

> 标签: deploy, healthcheck, http, mostajs, routes, smoke, test

## 简介

Sonde HTTP zéro-dépendance des routes d'une app (pré-déploiement / test) : publiques → 200, protégées → 303/401, sans suivre les redirections. Piloté par un manifeste. Membre de mosta-deploy-stack.
