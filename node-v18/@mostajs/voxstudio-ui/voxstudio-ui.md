# @mostajs/voxstudio-ui

> 标签: html, live, media, mostajs, podcast, ui, voxstudio

## 简介

Vues PURES (view-model → HTML) du média VoxStudio : accueil, fiche épisode (lecteur audio/vidéo/embed), fiche live (lecteur + Q&A). Compose @mostajs/app-shell-ui ; l'app charge la donnée (@mostajs/voxstudio) + construit les fragments dynamiques (embed/QR)
