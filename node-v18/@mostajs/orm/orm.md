# @mostajs/orm

> 标签: browser, cockroachdb, database, db2, edge, hana, hibernate, mariadb, mongodb, mssql, multi-dialect, mysql, oracle, orm, pglite, postgres-wasm, postgresql, repository-pattern, spanner, sql.js, sqlite, sybase, typescript, wasm, webcontainer

## 简介

Hibernate-inspired multi-dialect ORM for Node.js/TypeScript — One API, 19 databases, zero lock-in, runs in the browser/WebContainer via WASM (SQLite & Postgres)
