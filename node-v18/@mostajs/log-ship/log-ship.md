# @mostajs/log-ship

> 标签: collector, http, log-shipping, logdriver, logs, no-build, observability, zero-dependency

## 简介

Expédition (shipping) de logs vers un collecteur HTTP : un LogDriver @mostajs/logger qui POUSSE chaque entrée (>= niveau) en JSON-lines, fire-and-forget. Zéro dépendance.
