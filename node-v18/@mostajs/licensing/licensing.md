# @mostajs/licensing

> 标签: activation, license, licensing, mostajs, rsa

## 简介

Client de licences : demande de code, téléchargement de licence signée, vérification RSA (PKCS1v15-SHA256), notification d'activation. Pour activer/désactiver des applications via un serveur de licences MostaGare.
