# @mostajs/dialect-registry

> 标签: connection, dialect, mostajs, multi-tenant, named-connection, orm, registry

## 简介

Multi-dialect connection registry — orchestrate N parallel dialects per process (default, meta, per-tenant…). Sibling concern of @mostajs/orm (which owns the dialect implementations).
