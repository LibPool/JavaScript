# autocad-skill

> 标签: agent, autocad, cad, installer, mcp, opencode, skill

## 简介

Installer, updater, and doctor for the Engineering CAD Agent Skill (OpenCode). Copies plain Markdown/JSON skill files into place; never bundles autocad-mcp.
