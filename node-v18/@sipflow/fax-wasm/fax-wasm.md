# @sipflow/fax-wasm

> 标签: fax, pcap, rtp, sip, spandsp, t30, t38, tiff, udptl, voip, wasm, webassembly

## 简介

Decode T.30 (audio) and T.38 (UDPTL) faxes to TIFF in the browser or Node via WebAssembly (spandsp + libtiff)
