# dsh-sandboxed

> 标签: cordis, deepseek-harness, dsh, dsh-plugin, isolation, sandbox, sandboxed, security

## 简介

Sandboxed plugins for DeepSeek Harness: Run DeepSeek Harness plugins sandboxed: scoped fs, no shell, allowlisted hosts, and a full activity log. Name reserved; first release in development.
