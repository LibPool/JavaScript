# @stratless/mcp

> 标签: ai-agents, competitive-intelligence, mcp, model-context-protocol, stratless

## 简介

The stratless MCP server — gives any agent the `analyze` tool (competitive field mapping) + the free classify/extract schemas. A thin wrapper over the stratless API (ADR 0040).
