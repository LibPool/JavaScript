# @appxiom/ios-skills

> 标签: antigravity, appxiom, claude, coding-agent, copilot, cursor, ios, skills, swift, swiftui

## 简介

CLI to install Appxiom iOS SDK integration skills (core, swiftui & screens, network, goal tracking, activity trails, test issue, symbolication) into a project's coding agent skills directory.
