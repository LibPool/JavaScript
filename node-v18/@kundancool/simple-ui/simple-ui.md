# @kundancool/simple-ui

> 标签: components, dashboard, element-plus, simple-ui, ui, vue, vue3

## 简介

Simple UI — lightweight Vue 3 component library with S-prefixed components (s-input, s-button, s-dialog…) that coexist with Element Plus.
