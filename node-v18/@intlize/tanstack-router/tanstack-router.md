# @intlize/tanstack-router

> 标签: adapter, i18n, internationalization, localization, react, routing, tanstack-router

## 简介

TanStack Router adapter for @intlize/core. Adds route-aware i18n support, locale-prefixed paths, and seamless navigation utilities for TanStack Router apps.
