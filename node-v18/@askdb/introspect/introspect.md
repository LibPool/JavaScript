# @askdb/introspect

> 标签: askdb, introspection, schema, schema-v2

## 简介

AskDB schema introspection: engine-agnostic Connector contract + orchestrator + Schema v2 renderer. Integration packages (e.g. @askdb/postgres) supply connectors.
