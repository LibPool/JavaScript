# @gemstack/connector-github

> 标签: agents, ai, connector, gemstack, github, mcp, orchestration

## 简介

GitHub connector for GemStack AI orchestration: read and act on issues, pull requests, and repo files over the GitHub REST API. Built with @gemstack/connectors.
