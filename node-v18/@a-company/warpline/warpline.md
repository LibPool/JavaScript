# @a-company/warpline

> 标签: merge, oracle, paradigm, semantic-diff, symbol-graph, warpline

## 简介

Warpline — version control for meaning (experimental). The Convergence/Divergence Oracle plus a native hash-chained fabric: pick/admit/resolve multi-writer history, a content-addressed object store, and git-absent restore.
