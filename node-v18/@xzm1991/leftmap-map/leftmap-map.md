# @xzm1991/leftmap-map

> 标签: cluster, h5, heatmap, leaflet, map, marker, mobile, plugin, polygon, polyline, tianditu, uni-app, unibest

## 简介

移动端 H5 地图插件：基于 Leaflet，封装天地图/高德/OSM 等底图与点/线/面/圆/热力图/聚合等数据上图工具，专为 unibest (uni-app + Vue 3) 设计
