# @zappdev/runtime

> 标签: JavaScript

## 简介

TypeScript frontend API for [Zapp](https://github.com/zappdev/zapp) desktop apps. Use the same imports in webview code, webview-spawned workers, and headless workers — internal fast paths are automatic.
