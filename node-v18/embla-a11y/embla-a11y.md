# embla-a11y

> 标签: a11y, accessibility, aria, carousel, embla, embla-carousel, slider, wcag

## 简介

Accessibility plugin for Embla Carousel 8.6 and 9. Keeps visible slides readable, puts users in control of motion, targets WCAG 2.2 AA.
