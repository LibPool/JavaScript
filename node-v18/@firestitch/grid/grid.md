# @firestitch/grid

> 标签: angular, grid, pivot

## 简介

A virtual-scrolling grid for Angular 18 that shows either a pivot (row levels, column levels and values) or a source's own lines (details), with sorts and filters on every column header, expandable groups, total rows and columns, and a layout panel docked
