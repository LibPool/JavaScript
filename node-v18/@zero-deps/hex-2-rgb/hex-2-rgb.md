# @zero-deps/hex-2-rgb

> 标签: alpha, color, convert, hex, rgb, rgba, typescript

## 简介

lightweight typed function to convert hexes of format #rrggbb to rgb(x,y,z) or rgba(x,y,z,a) without runtime dependencies
