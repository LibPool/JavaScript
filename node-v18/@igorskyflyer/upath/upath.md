# @igorskyflyer/upath

> 标签: cross-platform, file, file-path, filesystem, igor dimitrijević, igorskyflyer, network-path, nodejs, normalize, os, path, slash, typescript, unc, unix, upath, utility, windows

## 简介

🎍 Provides a universal way of formatting file-paths in Unix-like and Windows operating systems as an alternative to the built-in path.normalize(). 🧬
