# @dsh-use/wallpaper-engine

> 标签: deepseek, deepseek-harness, dsh, dsh-plugin, scene, three.js, wallpaper, wallpaper-engine, webgl

## 简介

为 DSH（DeepSeek Harness）Web GUI 提供 Wallpaper Engine 壁纸背景：Scene 壁纸由 Three.js（WebGL2）+ Rust/WASM 粒子模拟在浏览器实时渲染，视频壁纸直接播放、Web 壁纸加载，其余回退 preview 图 + Ken Burns。
