# @kira905/dsh-firstaid

> 标签: deepseek-harness, diagnostics, drill, dsh, dsh-plugin, incident-response, rollback, runbook, zero-dependency

## 简介

只读诊断 + 回滚演练的急救台：把「起不来 / 假死 / 要撤销改动 / 数据被删」压成一个入口，产出可整段交给 AI 或同事的现场体检报告（零第三方依赖）
