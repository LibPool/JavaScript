# @junerver/vue-touch-ime

> 标签: chinese, ime, keyboard, pinyin, soft-keyboard, touch, touchscreen, vue, vue3, 中文输入, 拼音, 触摸屏, 软键盘, 输入法

## 简介

Vue 3 触摸屏软键盘（内置中文拼音输入法）- 零接线焦点接管、按输入类型限制（数字/小数/文本）、中英数三模式，适配无物理键盘的触屏工控/车载/自助终端
