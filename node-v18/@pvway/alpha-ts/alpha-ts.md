# @pvway/alpha-ts

> 标签: angular, api, cache, enum, extensible, i18n, localStorage, localization, multilingual, pvway, sessionStorage, signal, standalone, translation, typescript, utility

## 简介

Type-safe, extensible translation and enum utilities for Angular 20+. Provides local and remote translation cache, enum wrappers, and easy integration for multilingual Angular apps.
