# @holm/currency-codes-ts

> 标签: 4217, api, banking, code, codes, conversion, country, currencies, currency, data, exchange, finance, financial, fintech, global, i18n, international, iso, iso4217, json, localization, lookup, money, payment, rate, symbol, typescript, utility, utils

## 简介

A TypeScript library for ISO 4217 currency codes. Efficiently lookup and validate currency codes, retrieve associated countries, and more.
