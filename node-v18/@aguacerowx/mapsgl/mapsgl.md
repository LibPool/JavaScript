# @aguacerowx/mapsgl

> 标签: JavaScript

## 简介

Mapbox GL weather layers for Aguacero. Model grids, NEXRAD, and satellite all go through `WeatherLayerManager`. Satellite uses the same tiled catalog and WebGL layer as aguacero.com.
