# app-packager

> 标签: android, apk, cli, dsh-plugin, hap, harmonyos, hbuilderx, ios, ipa, packager, uni-app, uni-app-x

## 简介

AppPackager CLI: package uni-app x projects into iOS IPA, Android APK and HarmonyOS HAP from one command, on macOS today and Windows through a Git-Bash/WSL bridge.
