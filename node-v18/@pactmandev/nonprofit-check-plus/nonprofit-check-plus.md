> 标签: bmf, charity, compliance, ein, irs, nonprofit, ofac, pactman, pub78, sdk

## 简介

Official Node.js SDK for the Pactman Nonprofit Check Plus API — verify US nonprofits by EIN against IRS BMF, Publication 78, Automatic Revocation and OFAC data.
