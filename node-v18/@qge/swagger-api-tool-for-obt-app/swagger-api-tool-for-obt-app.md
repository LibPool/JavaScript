# @qge/swagger-api-tool-for-obt-app

> 标签: JavaScript

## 简介

```bash obt-api find-api <API路径> ``` - 功能：在Swagger文档中定位指定API - 参数：   - `<API路径>` 需要查找的API路径（如：/obt/hotel/search） - 特性：   - 自动打开Chrome浏览器并定位到API文档位置   - 支持OSS/OBT两种项目类型
