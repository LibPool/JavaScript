# @eternalheart/angular-file-preview

> 标签: angular, audio-player, code-viewer, document-viewer, excel-viewer, file-preview, image-viewer, markdown-viewer, office-viewer, pdf-viewer, powerpoint-viewer, ppt-viewer, pptx-viewer, video-player, word-viewer

## 简介

A modern, feature-rich file preview component for Angular with support for images, videos, audio, PDFs, Office documents (Word, Excel, PowerPoint), Markdown, and code files.
