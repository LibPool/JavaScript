# @wodzik/cubecore

> 标签: bluetooth, cfop, cube, react, roux, rubiks-cube, scramble, smart-cube, solver, speedcubing, three, web-components, zz

## 简介

A 3×3×3 cube library for the web, built around smart (Bluetooth) cubes: state, notation, methods, solvers and scrambles, a three.js renderer with skins, pictures, web components, React bindings.
