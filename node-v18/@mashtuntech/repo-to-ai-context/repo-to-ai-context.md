# @mashtuntech/repo-to-ai-context

> 标签: JavaScript

## 简介

Node.js CLI application reads all files in the current directory, excluding those specified in the `.gitignore`
file and a hardcoded blacklist, and aggregates them into a single output file named `fullrepo.txt`.
