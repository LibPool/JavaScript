# @esfaenza/dpe-builder

> 标签: JavaScript

## 简介

Editor visuale delle definizioni DPE: componenti standalone Angular, con tutto il traffico verso il backend dietro un'unica classe astratta (il contratto e' la classe astratta, ADR 0007; il client HTTP e' una sua implementazione opzionale, ADR 0020).
