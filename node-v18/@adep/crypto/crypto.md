# @adep/crypto

> 标签: JavaScript

## 简介

云函数沙箱内可用的密码学工具集（HS256 JWT / PBKDF2 口令哈希 / AES-256-GCM），纯 WebCrypto 零依赖，替代 jsonwebtoken + bcrypt + node:crypto。
