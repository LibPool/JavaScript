# @adep/vite-plugin

> 标签: JavaScript

## 简介

云函数 Vite 插件（IDE-030，自 CLI-014 @adep/cli/vite 抽出）：vite dev 进程内启动本地 adep dev server 并代理 /{prefix}/* 到云函数；同时 serve /@adep/fn-proxy.js（Web IDE 预览 fetch 拦截器）。本地运行时与配置加载经 createDevServer / loadConfig 注入端口接入，供 CLI / Web IDE / 非 CLI 用户独立使用。
