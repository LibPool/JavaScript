# @adep/web-container

> 标签: JavaScript

## 简介

adep 平台浏览器原生开发环境对外 SDK（FN-012）：虚拟文件系统 + 进程/shell + JS 运行时适配接口 + npm-relay 客户端，对标 WebContainers API，Node 可测、浏览器可跑。
