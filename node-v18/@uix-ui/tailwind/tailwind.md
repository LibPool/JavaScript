# @uix-ui/tailwind

> 标签: design-system, design-tokens, shadcn, tailwindcss, theme

## 简介

UIX design tokens as Tailwind CSS v4 themes: colours (light + dark), type scale, spacing, radius, shadows. One theme per UIX preset.
