# @x-viewer/core

> 标签: 2d-viewer, 3d-viewer, autocad, bim, buildingsmart, cad-viewer, drawing, dwg, dwg-viewer, dxf, dxf-viewer, floor-plan, gis, gltf, ifc, javascript, obj, pdf, pdf-viewer, stl, three.js, threejs, typescript, wasm, webgl

## 简介

WebGL-based 2D/3D viewer engine built on Three.js. View DWG/DXF/PDF files in the browser with no server required. Supports glTF, OBJ, FBX, IFC, STL and BimTiles formats.
