# @markieboy1991/cordova-universal-links-plugin

> 标签: android, cordova, cordova-android, cordova-ios, deep links, ecosystem:cordova, ios, links, universal, universal links

## 简介

Cordova plugin to add in your application support for Universal Links (iOS 9) and Deep Links (Android). Basically, open application through the link in the browser. Fork of nordnet/cordova-universal-links-plugin with Cordova 9+ compatibility fixes.
