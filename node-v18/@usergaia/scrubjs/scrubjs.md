# @usergaia/scrubjs

> 标签: ast, cleanup, cli, console, console.log, debug, developer-tools, javascript, jsx, lint, logging, react, remove, tsx, typescript

## 简介

AST-precise CLI to safely remove or comment out leftover debug statements (console.*, debugger) in JS, TS, JSX, and TSX.
