# @wujianfu/code-formatter

> 标签: miniprogram, 小程序, 格式化

## 简介

调用prettier 格式化文件，支持 js,ts,tsx,wxs,vue,html,css,less,scss,wxss,json,json5,md,yaml,wxml，其中 wxml 文件使用 cny_js_beautify 进行格式化。
