# @dowel-ui/themes

> 标签: accessible, contrast, css, dark-mode, design-system, design-tokens, dowel, oklch, tailwind, tailwindcss, theme, theming, wcag

## 简介

Two-tier OKLCH design tokens in plain CSS for Dowel, with thirteen presets that all pass WCAG AA contrast in light and dark.
