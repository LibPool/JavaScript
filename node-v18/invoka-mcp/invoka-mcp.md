# invoka-mcp

> 标签: cedula, ecuador, factura, facturacion-electronica, invoka, mcp, model-context-protocol, ruc, sri

## 简介

Servidor MCP de Invoka: deja que un asistente de IA consulte el SRI (RUC, cédula, razón social), revise comprobantes y emita facturas electrónicas de Ecuador por la API de Invoka

## 官网

- npm 页面：https://www.npmjs.com/package/invoka-mcp
