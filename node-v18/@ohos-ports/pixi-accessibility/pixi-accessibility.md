# @ohos-ports/pixi-accessibility

> 标签: accessibility, harmonyos, ohos-ports, openharmony, pixi

## 简介

Accessibility Plugin for visually impaired users (HarmonyOS port of @pixi/accessibility@7.4.3 with jsdom DOM polyfill for openharmony)
