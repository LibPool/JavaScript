# @ohos-ports/cockroachlabs-cluster-ui

> 标签: JavaScript

## 简介

Cluster UI is a library of large features shared between CockroachDB and CockroachCloud (OpenHarmony port; dist/ restored from official 23.1.6 tarball with UMD window->globalThis + SSR shim for Node/HarmonyOS loading)
