# @ohos-ports/parcel-watcher-openharmony-arm64

> 标签: JavaScript

## 简介

A native C++ Node module for querying and subscribing to filesystem events. Used by Parcel 2. OpenHarmony arm64 build (aarch64 OHOS, signed, inotify backend) of the @parcel/watcher platform addon.
