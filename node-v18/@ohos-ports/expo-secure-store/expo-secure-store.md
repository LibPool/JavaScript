# @ohos-ports/expo-secure-store

> 标签: encryption, expo, expo-secure-store, harmonyos, huks, ohos, react-native, secure, store

## 简介

Provides a way to encrypt and securely store key-value pairs locally on the device (HarmonyOS port with AES-256-GCM encryption).
