# @ffrysz/randomid-generator

> 标签: JavaScript

## 简介

Package used for generating random ids from following chracters ('ABCDEFGHIJKLMNOPQRSTUVWXYZabcdefghijklmnopqrstuvwxyz0123456789'). User can define length of the ID.
