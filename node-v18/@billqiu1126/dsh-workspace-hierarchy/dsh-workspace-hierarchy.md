# @billqiu1126/dsh-workspace-hierarchy

> 标签: deepseek-harness, dsh, plugin, workspace

## 简介

DeepSeek Harness web plugin: hierarchical workspace browser. Nests workspaces by directory path (main/sub-workspace) and adds an "Add sub-workspace" action to each workspace's + menu.
