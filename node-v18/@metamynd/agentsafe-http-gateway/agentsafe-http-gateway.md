# @metamynd/agentsafe-http-gateway

> 标签: JavaScript

## 简介

Generic HTTP interception gateway (SAFR §17) — a zero-dependency reverse proxy that governs arbitrary HTTP calls through the AgentSafe gate before forwarding upstream.
