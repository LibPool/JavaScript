# figrelay

> 标签: claude, cursor, design, figma, figma-mcp-console, mcp, model-context-protocol

## 简介

Figma MCP server (fork of figma-mcp-console) for AI coding assistants — real-time read/write via a Figma Desktop plugin. No API token, no rate limits.
