# @mlagie/sql-connector

> 标签: builder, connector, database, mariadb, migration, model, mysql2, orm, pool, query, rdbms, schema, sql, sync

## 简介

The sql-connector module allows you to manage connections to a MySQL database, define table schemas, and interact with data in a simple and efficient way.
