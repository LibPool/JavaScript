# @mammoth-protocol/sdk

> 标签: ai-agent, cycle-based-issuance, launchpad, mammoth, multi-round-fundraising, solana, token

## 简介

Solana-native cycle-driven token issuance SDK for Mammoth Protocol. Multi-round raises, rights-based anti-dilution, and deterministic treasury routing.
