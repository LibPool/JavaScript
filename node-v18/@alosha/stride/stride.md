# @alosha/stride

> 标签: activity, activity-analysis, chart, chartjs, cli, fit, fit-file, fit-parser, fitness, garmin, gpx, gpx-parser, heart-rate, heart-rate-zones, pace, running, splits, strava, tcx, tcx-parser

## 简介

Parse GPX, TCX and FIT files and compute running metrics — pace, HR zones, splits, and Chart.js dashboards. Zero config.
