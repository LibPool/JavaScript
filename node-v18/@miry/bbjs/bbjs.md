# @miry/bbjs

> 标签: JavaScript

## 简介

`@miry/bbjs` は、Blackbox.ai API を簡単に利用するための TypeScript/JavaScript ライブラリです。このライブラリを使用することで、AI と対話するためのメッセージを送信し、応答を受け取ることができます。
