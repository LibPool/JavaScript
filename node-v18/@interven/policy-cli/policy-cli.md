# @interven/policy-cli

> 标签: ai-security, cli, interven, policy-as-code, yaml

## 简介

Policy-as-Code CLI for Interven. Validate, diff, and apply YAML policy files against a tenant. Designed for Git-managed policy workflows + CI/CD.
