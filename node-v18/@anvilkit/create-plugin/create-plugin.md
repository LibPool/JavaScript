# @anvilkit/create-plugin

> 标签: JavaScript

## 简介

Scaffolder for @anvilkit/* StudioPlugin packages. Generates a buildable plugin skeleton with tests, rslib build, biome config, and a minimal createXxxPlugin() factory.
