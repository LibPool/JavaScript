# @anvilkit/plugin-export-canvas

> 标签: JavaScript

## 简介

Canvas export formats (PNG / JSON / SVG / PDF) for AnvilKit Studio — headless wrappers around @anvilkit/canvas-core serializers, registered via StudioPluginRegistration.exportFormats.
