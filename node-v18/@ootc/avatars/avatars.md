# @ootc/avatars

> 标签: avatar, boring-avatars, deterministic, gravatar, identicon, react, ssr, svg

## 简介

Deterministic SVG avatars for React, generated from a seed string. Three styles: identicon, gradient, and cartoon face. SSR-safe, no network or image files.
