# @jottocraft/rtsk-middleware

> 标签: JavaScript

## 简介

Middleware API interface for authenticating ratatoskr sessions on Cloudflare Workers. Provides an easy to use, strongly typed, and consistent interface to the session consumption APIs exposed by `ratatoskr-core`.
