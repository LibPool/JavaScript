# react-native-wheel-kit

> 标签: android, date-picker, datepicker, expo, haptics, ios, ios-picker, picker, react-native, reanimated, scroll-picker, time-picker, timepicker, typescript, wheel, wheel-picker

## 简介

Wheel pickers for React Native that look and feel the same on iOS and Android: a snapping WheelPicker, plus ready-made TimePicker and DatePicker. Haptic tick per row, virtualised, UI-thread animation, accessible. Built on Reanimated.
