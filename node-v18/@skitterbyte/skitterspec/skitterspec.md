# @skitterbyte/skitterspec

> 标签: claude, claude-code, scaffold, sdd, skills, spec-driven-development

## 简介

Spec-driven development for Claude Code — a tracker-free filesystem workflow: lifecycle skills and per-spec isolation. For Linear sync, install @skitterbyte/skitterspec-linear instead.
