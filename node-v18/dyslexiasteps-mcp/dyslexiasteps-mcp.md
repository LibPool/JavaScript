# dyslexiasteps-mcp

> 标签: cvc-words, dolch, dyslexia, mcp, model-context-protocol, phonics, reading, sight-words, teachers, word-lists

## 简介

MCP server for Dyslexia Steps word lists: phonics and sight word lists placed by grade (Pre-K to Grade 3) with the source of each placement, plus lists in German, Spanish, French, Dutch and Brazilian Portuguese. Read-only.
