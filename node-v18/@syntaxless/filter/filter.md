# @syntaxless/filter

> 标签: filter, natural-language, nlp, offline, on-device, parser, plain-english, predicate, query, search, sqlite, syntaxless, text-to-sql, typescript, where, zero-dependency

## 简介

Convert plain English filters to parameterized SQLite WHERE clauses and JavaScript predicates. On-device natural-language parser for TypeScript and JavaScript, offline, zero dependencies.
