# @syntaxless/sort

> 标签: comparator, natural-language, nlp, offline, on-device, order-by, ordering, parser, plain-english, sort, sorting, sqlite, syntaxless, typescript, zero-dependency

## 简介

Convert plain English sort orders to SQLite ORDER BY clauses and JavaScript comparators. On-device natural-language parser for TypeScript and JavaScript, offline, zero dependencies.
