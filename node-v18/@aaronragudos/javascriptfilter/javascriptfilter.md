# @aaronragudos/javascriptfilter

> 标签: ES6 MODULE, JS FILTER, Javascript Filter, javascript filter

## 简介

This is a library that takes two sets of data input which is of type array[]. The first data would be the one you would like to filter or check if any of its characteristics match with your second data.
