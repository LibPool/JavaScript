# @yashjain99/mandate-mcp

> 标签: agents, ledger, mandate, mcp, model-context-protocol, usdc

## 简介

MCP server that lets Claude Desktop / Cursor / any MCP client operate a Mandate account: plan, simulate, guardian-approve and execute on-chain steps under a bounded mandate.
