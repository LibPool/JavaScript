# @randajan/esbuild-plugin-image-size

> 标签: ajax, api, error-handling, fetch, http, json, network, request, rest, wrapper

## 简介

An ESBuild plugin that processes images, extracts their dimensions (width, height), and generates importable objects with file paths, supporting flexible filtering with entries.
