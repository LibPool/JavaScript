# @canopycanopycanopy/b-ber-grammar-soundcloud

> 标签: JavaScript

## 简介

The `b-ber-grammar-soundcloud` package renders b-ber's custom `soundcloud` Markdown extensions (directives) into HTML. More information about b-ber directives can be found in the [All directives](https://github.com/triplecanopy/b-ber/wiki/all-directives)
