# @mcpskillsio/server

> 标签: ai-skills, claude-code, cursor, mcp, mcp-server, safety-scanner, security, trust-score

## 简介

Use the MCPSkills pre-install trust layer from Claude Code, Cursor, or any MCP client. Accepts GitHub repos, npm packages, Smithery URLs, and OpenClaw skills. 15 signals (incl. OSV/KEV/EPSS vulnerability intelligence), safety scanning, OpenClaw frontmatte
