# @open-wysiwyg-editor/vue

> 标签: a11y, accessibility, arabic, editor, rich-text-editor, rtl, vue, vue3, wysiwyg

## 简介

Vue 3 component for open-wysiwyg-editor: <RichTextEditor v-model />. Accessible (WCAG 2.2 AA), RTL-first, CSP-safe, SSR-safe.
