# @open-wysiwyg-editor/nuxt

> 标签: a11y, accessibility, arabic, editor, nuxt, nuxt-module, rich-text-editor, rtl, vue, wysiwyg

## 简介

Nuxt module for open-wysiwyg-editor: auto-imported <RichTextEditor v-model /> and styles. Accessible (WCAG 2.2 AA), RTL-first, CSP-safe.
