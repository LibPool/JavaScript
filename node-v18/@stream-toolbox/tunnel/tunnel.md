# @stream-toolbox/tunnel

> 标签: agent, duplex, pipe, proxy, socket, stream-toolbox, tunnel

## 简介

Forward data bidirectionally between two duplexes, like `a.pipe(b).pipe(a)`, but with better handling for various cases.
