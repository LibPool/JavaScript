# @sigvault/wasm

> 标签: browser, cloudflare-workers, cryptography, deno, dilithium, ml-dsa, post-quantum, pqc, quantum-safe, wasm, webassembly

## 简介

Sigvault WebAssembly build — ML-DSA-87 post-quantum tokens in ~127 KB of wasm. Runs in browsers, Node, Deno, Bun, Cloudflare Workers.
