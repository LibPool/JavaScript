> 标签: cryptography, dilithium, falcon, jwt-alternative, ml-dsa, nist-fips-204, post-quantum, pqc, quantum-safe, sha3, tokens, xchacha20

## 简介

Sigvault post-quantum token SDK — ML-DSA-87 (Dilithium-5) + XChaCha20-Poly1305 + SHA3-256. Works in Node, Deno, Bun, Cloudflare Workers, and modern browsers.
