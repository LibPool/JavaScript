# @derektest/react-ui-components

> 标签: JavaScript

## 简介

DerekButton は、さまざまなスタイルやサイズを持つカスタムボタンコンポーネントです。このコンポーネントは、React を使用して簡単にカスタマイズ可能なボタンを作成するために使用できます。
