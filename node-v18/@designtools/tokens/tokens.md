# @designtools/tokens

> 标签: a11y, accessibility, apca, cli, color, color-ramp, color-scale, colour, contrast, contrast-checker, css-variables, custom-properties, dark-mode, design-system, design-tokens, deterministic, dtcg, generator, oklch, palette, palette-generator, tailwind, tailwind-v4, tailwindcss, theme, theming, wcag

## 简介

Turn one brand colour into a complete design-token system: perceptual OKLCH ramps, contrast-checked semantic tokens (WCAG or APCA), light and dark, as CSS custom properties, Tailwind v4/v3 or DTCG. Deterministic CLI, safe for agents.
