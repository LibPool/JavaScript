# @pharmatools/redacta

> 标签: anonymisation, de-identification, healthcare, nhs, phi, pii, privacy, pseudonymisation, redaction, typescript

## 简介

Pseudonymise patient identifiers and PII in text (and restore them) — a dependency-free TypeScript engine. Names, relatives, general PII, self-check, re-identification, and a PrivacyGateway for agent workflows.
