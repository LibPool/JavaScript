# @mcjxy/task-pool

> 标签: async, cluster, cluster-pool, clusterpool, cpu-bound, manage, manage-tasks, parallel, parallelism, pool, process, queue, task, task-manager, task-pool, taskpool, tasks, thread, thread-pool, threadpool, threads, worker, worker-pool, worker_thread, worker_threads, workerpool, workers

## 简介

Easy way to manage a pool of workers, support cluster mode(run tasks in different process), thread mode(run tasks in different thread) and normal mode(run tasks in current thread)!
