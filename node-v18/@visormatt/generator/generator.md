# @visormatt/generator

> 标签: scaffolding, templates

## 简介

A simple, customizable, command line tool. 
Written in ES6 & TypeScript this generator allows the end user to configure unique, per-project templates... 
Spend less time writing boiler-plate code and more time writing the fun stuff.
