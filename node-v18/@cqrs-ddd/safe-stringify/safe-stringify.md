# @cqrs-ddd/safe-stringify

> 标签: cache-key, deterministic, json, redaction, stable-stringify

## 简介

Deterministic JSON for identity (cache keys, fingerprints) and safe, redacting JSON for logs, with no dependencies and no framework.
