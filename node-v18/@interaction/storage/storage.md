# @interaction/storage

> 标签: JavaScript

## 简介

`npm i --save @interaction/storage` ### 使用 `import storage from '@interaction/storage';` ### API #### setItem(key, value[, time]) - **key**: string - **value**: string - **time**: Date|number|string,过期时间，如果取值时间大于该值，将自动删除，并返回null, 可选
