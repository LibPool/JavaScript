# @twin.techies/india-pincode

> 标签: address, autocomplete, india, india-post, indian-pincode, pincode, postal-code, zipcode

## 简介

Offline Indian pincode lookup library — 23k+ pincodes, 40k+ post offices bundled. Synchronous API, zero runtime dependencies, full TypeScript support.
