# node-red-storage-sequelize

> 标签: context, context-storage, contextstore, database, mariadb, mssql, mysql, node-red, node-red-plugin, orm, postgres, postgresql, sequelize, sqlite, storage, storage-plugin

## 简介

Node-RED storage module AND context store backed by Sequelize: persists flows, credentials, settings, sessions, library and global/flow/node context in any database Sequelize supports
