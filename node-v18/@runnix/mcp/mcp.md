# @runnix/mcp

> 标签: ai-agents, hetuh, mcp, model-context-protocol, orchestration, runnix, workflow

## 简介

MCP (Model Context Protocol) server for Runnix: lets AI agents inspect functions, runs, and events, trigger work, and re-run or cancel it.
