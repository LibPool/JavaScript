# @estebanforge/pi-zendesk-me

> 标签: coding-agent, pi-extension, pi-package, rest-api, support, tickets, zendesk

## 简介

Zendesk Support read tools for Pi. Adds 7 LLM-callable tools (zendesk_*) that query the Zendesk Support API v2 over HTTPS: fetch a ticket (by id or agent URL), read the comment thread, search tickets, look up users and organizations, download attachments
