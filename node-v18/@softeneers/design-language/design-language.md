# @softeneers/design-language

> 标签: ai, codemod, css-variables, design-system, design-tokens, hsl, preview, theme

## 简介

A design language as one interactive design.html (HSL :root = source of truth) + DESIGN.md rules, with five verbs: create, get (extract & centralize a frontend), edit, apply (exact-match codemod), and a live-reload preview.
