# @jokerized/tesserae

> 标签: agents, cli, context-engine, knowledge-graph, llm, tesserae, wrapper

## 简介

Node convenience wrapper for Tesserae — a context engine that compiles agent-ready knowledge from your project. Forwards to the Python CLI.
