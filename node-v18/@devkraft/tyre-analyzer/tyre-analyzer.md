# @devkraft/tyre-analyzer

> 标签: barcode, dot, inspection, ocr, serial, sidewall, tire, tyre

## 简介

Client for the Tyre Analyzer API: read a tyre sidewall, barcode, serial number, defects or a balancer report from a photograph.
