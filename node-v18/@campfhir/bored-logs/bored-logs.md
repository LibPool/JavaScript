# @campfhir/bored-logs

> 标签: JavaScript

## 简介

Structured PostgreSQL-backed logging for React + Node — adapter-based logger, typed message templates, boolean log search with nested-attribute queries, HTTP log shipping with opt-in end-to-end encryption, React UI components, and Kysely migrations.
