# @cpreston321/nuxt-cv

> 标签: cv, nuxt, nuxt-layer, nuxt3, vue

## 简介

A Nuxt & Vue port of [Bartosz Jarocki's CV web app](https://github.com/BartoszJarocki/cv) that renders a minimalist CV with a print-friendly layout.
