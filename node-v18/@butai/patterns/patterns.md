# @butai/patterns

> 标签: JavaScript

## 简介

The shared vocabulary the rest of butai is built on. It defines what a design spec looks like, the contract every theme's tokens must satisfy, and the catalog types the kits generate. If the other packages are the actors, this is the script they all read
