# dsh-jev-ultrafast

> 标签: browser-automation, cordis, deepseek-harness, dsh, dsh-plugin, jev, typesafe

## 简介

Drive a browser from one natural-language goal: TypeSafe Jev picks the next operation and target from an indexed element table, so a DeepSeek Harness session spends one tool call instead of one turn per click.
