# @kimposoft/plugin-sdk

> 标签: JavaScript

## 简介

Kimpo 插件前端 SDK：契约类型 + 少量运行时代码（挂载点 / 登录页 / 打印方案登记、沙箱框架桥、多语言等，会打进插件 bundle），无第三方运行时依赖；以 TypeScript 源码发布（exports 指向 src/*.ts），需用能编译 TS 的构建工具（vite、esbuild、tsc 等）
