# @kimposoft/ui-kit

> 标签: kimpo, naive-ui, vue, vue3

## 简介

Kimpo 组件库：KDialog / KDialogFooter / KLayerStack / KControlSize 等 Vue 3 + Naive UI 组件；以 TypeScript / Vue SFC 源码发布（exports 指向 src），需用能编译 TS 与 .vue 的构建工具（如 vite + @vitejs/plugin-vue）
