# @nativescript/compiler

> 标签: JavaScript

## 简介

Compiles a NativeScript app written with Vue, Angular, Svelte, React, Solid or Octane into a native iOS or Android app with no JavaScript runtime.

## 官网

- 官网：https://docs.nativescript.org/guide/publishing/compiled
- 源码仓库：git+https://github.com/NativeScript/NativeScript.git
- npm 页面：https://www.npmjs.com/package/@nativescript/compiler
