> 标签: agent-skills, android, angular, claude-code, codex, copilot, cursor, ios, nativescript, react, skills, solid, svelte, tanstack-intent, vue

## 简介

Agent Skills for NativeScript, organised by area (core, iOS, Android, frontend flavors, UI, device, testing, tooling, plugins). Works with Claude Code, Cursor, Codex, Copilot, Gemini CLI and any Agent Skills client; ships as skills/<category>/<name>/SKILL
