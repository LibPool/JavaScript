# @knervous/blender-web

> 标签: 3d, babylon-lite, babylonjs, blender, gltf, threejs, wasm, webassembly

## 简介

Blender compiled to WebAssembly, embedded in the page: ships the runtime and a core adapter that keeps a Babylon.js, Babylon Lite or three.js scene in sync with a persistent in-tab Blender session.
