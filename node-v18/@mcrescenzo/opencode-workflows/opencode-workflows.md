# @mcrescenzo/opencode-workflows

> 标签: opencode, opencode-plugin, orchestration, workflow

## 简介

opencode plugin providing durable, resumable multi-agent workflow orchestration: the architecture for building, running, and supervising workflows (no bundled workflows).
