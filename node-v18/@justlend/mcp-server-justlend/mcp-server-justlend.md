# @justlend/mcp-server-justlend

> 标签: agent, ai, borrowing, defi, jtoken, justlend, lending, mcp, model-context-protocol, tron

## 简介

MCP server for JustLend DAO on TRON. Covers JustLend V1 (supply/borrow/repay/withdraw, sTRX staking, energy rental and direct purchase, governance, mining) and V2/Moolah (isolated markets, ERC4626 vaults, liquidation), TRX<->WTRX wrap/unwrap, general TRON
