# tradingagentstack-mcp

> 标签: ai-agents, broker, market-data, mcp, model-context-protocol, trading

## 简介

Read-only MCP server for the TradingAgentStack directory: search AI trading tools, broker MCP servers and APIs, compare them, and see who places the order. Every answer carries sources and last-checked dates.
