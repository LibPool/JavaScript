# @livteam/agents-cli

> 标签: JavaScript

## 简介

이 안내는 처음 설치하는 사람을 위한 순서입니다. `agents`는 Codex와 OpenCode에 이 저장소의 에이전트 설정을 설치하고 관리하는 명령입니다. OpenCode 플러그인 id는 호환성을 위해 계속 `buyong-agents`입니다.
