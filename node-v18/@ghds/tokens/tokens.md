# @ghds/tokens

> 标签: css-variables, design-system, design-tokens, dtcg, ghds, react-native, style-dictionary

## 简介

Single source of truth for GHDS design values — W3C DTCG tokens (ref/sys/comp) built to CSS, TS, React Native, and platform-agnostic JSON via Style Dictionary.
