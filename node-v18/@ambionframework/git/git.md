# @ambionframework/git

> 标签: agents, ambion, git, just-git, templates, workspace

## 简介

A git backend for an Ambion workspace: read-only templates, forks, and pushes, over an in-process just-git server.

- 官网：https://ambionframework.com
- 源码仓库：git+https://github.com/ambionframework/ambion.git
- npm 页面：https://www.npmjs.com/package/@ambionframework/git
