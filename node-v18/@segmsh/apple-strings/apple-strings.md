# @segmsh/apple-strings

> 标签: JavaScript

## 简介

Apple strings processor for [segm.sh](https://segm.sh). This package parses `.strings` localization files into a document (AST + segments) and stringifies them back, treating values as translatable segments while leaving everything else byte-for-byte inta
