# @aero-js/starter-fullstack

> 标签: JavaScript

## 简介

Full-stack Aero template with Nitro enabled from day one. Includes `nitro.config.ts`, API routes, Nitro cache/storage/database examples, a task, a plugin, and a `preview:api` command.
