# @edmingle/web-video-sdk

> 标签: drm, edmingle, nextjs, player, react, sdk, video, vimeo

## 简介

Web SDK to fetch Edmingle teaching materials and play their videos in an embedded player, with resume, dynamic watermarking, DRM support and progress reporting. Framework-agnostic core plus a React/Next.js adapter.
