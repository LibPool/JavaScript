# @bysivin/jumpbar

> 标签: command-bar, command-palette, fuzzy-search, headless, spotlight, vue

## 简介

Lightweight command palette for Vue 3: a framework-free ranking core with fuzzy matching, sections, pages, prefixes and frecency, plus a native <dialog> shell with async sources.
