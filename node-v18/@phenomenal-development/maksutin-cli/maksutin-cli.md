# @phenomenal-development/maksutin-cli

> 标签: agent, ai, cli, commerce, maksutin, mcp, shopping, storefront, ucp

## 简介

Agent-facing CLI for Maksutin shops: discover a shop, search its catalog, inspect products and build a checkout link the human buyer approves.
