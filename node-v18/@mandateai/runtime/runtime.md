# @mandateai/runtime

> 标签: agent-orchestration, agents, chronicle, constitution, imperial-court, mandate, multi-agent, runtime, yaml

## 简介

Mandate runtime — constitution loader, terms resolver, chronicle (JSONL append), memory lifecycle, and model fallback resolver. The execution engine for self-governing multi-agent imperial courts.
