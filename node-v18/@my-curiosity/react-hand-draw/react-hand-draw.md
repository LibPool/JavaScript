# @my-curiosity/react-hand-draw

> 标签: canvas, draw, handpose, machine-learning, react, tfjs, typescript, webcam

## 简介

A ReactJS component for drawing using hand movements in the air. Utilizes [mediapipe](https://developers.google.com/mediapipe/solutions/vision/hand_landmarker/web_js)/[tfjs](https://github.com/tensorflow/tfjs-models/tree/master/hand-pose-detection) handpo
