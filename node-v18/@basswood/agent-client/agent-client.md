# @basswood/agent-client

> 标签: agent, browser, chat, claude, claude-code, local-first

## 简介

Browser client for @basswood/agent-host: connect a page to the visitor's own Claude Code or Codex, open a session with the page's own tools, stream a turn. Framework-free ESM, no dependencies.
