# @rellavo/install

> 标签: claude, claude-code, claude-desktop, cursor, installer, mcp, model-context-protocol, rellavo

## 简介

One-command installer that wires @rellavo/mcp into Claude Desktop, Cursor, and the Claude Code CLI. Run `npx @rellavo/install rk_live_<your-token>`.
