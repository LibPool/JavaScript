# @hasdata/yelp-mcp

> 标签: hasdata, local-business, local-seo, mcp, model-context-protocol, reviews, scraper, yelp, yelp-mcp

## 简介

MCP server for Yelp through HasData's hosted API: business search, place details and the full review feed. No Yelp Fusion key, no waitlist. 1,000 free credits every month.
