# @stellarsight/express

> 标签: agent-payments, bazaar, discovery, express, http-402, middleware, paywall, soroban, stellar, stellarsight, x402

## 简介

x402 paywall middleware for Express — sell any endpoint for a Stellar token and have it listed in the STELLARSIGHT bazaar before its first payment.
