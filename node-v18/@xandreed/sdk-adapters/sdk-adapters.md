# @xandreed/sdk-adapters

> 标签: adapters, ai-agent, effect, effect-ts, llm, sdk

## 简介

efferent SDK — Layer implementations of the sdk-core ports: multi-provider LLM router, auth, conversation/context stores (SQLite + Postgres), settings, fs/shell/http. Side effects live here.
