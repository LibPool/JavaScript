# @omnifex/ui-angular

> 标签: JavaScript

## 简介

Native Angular 22 components for the Omnifex design system. Standalone, OnPush, signal-based, and styled only with `@omnifex/styles` tokens. No Stencil, Web Components, React or extra token system.
