> 标签: divider, dock, drag, flex, flex-layout, flexLayout, layout, panel, panes, react, resizable, resize, rxjs, split, split-pane, splitter, typescript, ui, vscode

## 简介

A React UI layout component for building resizable split views. Wrap panes with FlexLayout and drag the divider to resize horizontally or vertically.
