# @massing/commands

> 标签: aec, cad, command-bus, command-palette, macro, undo

## 简介

The command bus: every action is one serializable invocation, and interactive prompt loops are a pure reducer. Yields undo, a palette, an AutoCAD command line, keybindings, macros, the plugin API and an audit log from one mechanism.
