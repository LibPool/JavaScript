# @massing/ribbon

> 标签: accessibility, aec, ribbon, toolbar, ui

## 简介

An Office-style ribbon in vanilla DOM — responsive group collapse, roving-tabindex keyboard navigation, and dimmed-with-a-reason controls. No framework, so massing and a React shell can both render it.
