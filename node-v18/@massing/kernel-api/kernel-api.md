# @massing/kernel-api

> 标签: aec, authoring, bim, contract, ifc, kernel

## 简介

The KernelProvider contract: one interface for authoring IFC, satisfied by an in-browser offline kernel and by a remote authoring service. Types and error taxonomy only, no implementation.
