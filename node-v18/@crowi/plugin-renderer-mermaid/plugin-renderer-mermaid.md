# @crowi/plugin-renderer-mermaid

> 标签: JavaScript

## 简介

Mermaid diagram renderer for Crowi 2.x. Renders ```mermaid fenced blocks server-side (browserless, child-process isolated) to a sanitized, base64-encoded SVG <img>. Registered in apps/crowi-runner's crowi.config.json (spec §10).
