# @crowi/plugin-renderer-plantuml

> 标签: JavaScript

## 简介

PlantUML diagram renderer for Crowi 2.x. Sends ```plantuml fenced blocks to a PlantUML server and inlines the returned SVG (or PNG). Cache TTL 1h.
