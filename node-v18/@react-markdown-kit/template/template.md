# @react-markdown-kit/template

> 标签: markdown, personalization, placeholders, plugin, react, template, template-variables, templating, variables

## 简介

Markdown templating for React Markdown Kit, as plugins: template({ data }) resolves typed placeholders while the renderer parses; templateVariables() edits them as chips. No standalone API.
