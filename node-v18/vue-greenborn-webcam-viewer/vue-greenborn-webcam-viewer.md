# vue-greenborn-webcam-viewer

> 标签: bounding-box, camera, capture, detecciones, getusermedia, greenborn, overlay, video, vue, vue3, webcam

## 简介

Visor de webcam para Vue 3: obtención de permisos, selección de cámara, captura de frames/fotos y visualización del stream con una capa de bounding boxes y slots para overlays extra. No asume ningún backend ni API de detección: el consumidor decide qué ha
