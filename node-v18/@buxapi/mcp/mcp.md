# @buxapi/mcp

> 标签: buxapi, crypto, mcp, model-context-protocol, payments, stablecoin, usdc

## 简介

MCP server for the BuxAPI crypto payment API. Gives an AI coding assistant real tools against your wallet: create invoices, read deposits, verify webhook signatures.
