# @lijian-ui/dsh-im-gateway

> 标签: cordis, deepseek-harness, dingtalk, dsh, dsh-plugin, feishu, im-gateway, lark, qq, wechat, wechat-work, wecom, weixin

## 简介

Multi-channel IM gateway plugin for DeepSeek Harness (dsh): DingTalk / QQ / WeChat(iLink) / Feishu(Lark) / WeCom with QR-scan binding, streaming replies, and a unified ctx.imGateway service. 为 DeepSeek Harness 提供钉钉/QQ/个人微信/飞书/企业微信多 IM 通道接入。
