# @mintid/engine

> 标签: JavaScript

## 简介

Mint engine SDK (ADR-0025 D1): the org-locked token-exchange client + typed Mint ops for BEING an engine. Depends on @mintid/client for the single-source domain canonicalizer + birth_seed.
