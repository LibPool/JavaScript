# @devo-bmad-custom/tmux

> 标签: ai-agents, bmad, claude, developer-tools, tmux, wsl

## 简介

tmux setup for AI agent workflows — Catppuccin theme, pane title sync, clipboard integration, and Claude Code multi-agent scripts. Supports Windows (WSL2) and Linux (Fedora/Ubuntu/Arch).
