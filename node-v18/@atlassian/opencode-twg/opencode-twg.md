# @atlassian/opencode-twg

> 标签: atlassian, opencode, teamwork graph, teamwork graph cli, twg

## 简介

OpenCode setup bridge for Atlassian Teamwork Graph CLI (twg). Installs no runtime and handles no credentials.

- 官网：https://developer.atlassian.com/cloud/twg-cli/
