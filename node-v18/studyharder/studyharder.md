# studyharder

> 标签: JavaScript

## 简介

Live loader for github.com/xf8n/svg: index.html's assets/ bundle is fetched from GitHub at view time; the service worker and its vendored files are bundled here so it can register same-origin.

## 官网

- 官网：https://github.com/xf8n/svg
- 源码仓库：git+https://github.com/xf8n/svg.git
- npm 页面：https://www.npmjs.com/package/studyharder
