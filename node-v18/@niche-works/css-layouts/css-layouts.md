# @niche-works/css-layouts

> 标签: css, layout, style

## 简介

`@niche-works/css-layouts` is a niche library specialized in controlling child element layout with CSS. It returns class names and CSS custom properties as an object based on the given options. Framework-agnostic and SSR-compatible.
