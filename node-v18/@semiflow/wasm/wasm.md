# @semiflow/wasm

> 标签: chernoff, diffusion, numerics, operator-semigroup, pde, wasm, webassembly

## 简介

WebAssembly bindings for semiflow — Chernoff approximation of operator semigroups (experimental, API unstable pre-1.0).
