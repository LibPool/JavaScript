# repo-bridge-mcp

> 标签: agentic, ai-agent, ai-coding-assistant, automation, chatgpt, chatgpt-connector, coding-agent, developer-tools, git, mcp, mcp-server, model-context-protocol, oauth2, self-hosted

## 简介

MCP server that turns ChatGPT Web into a real coding agent on your own repositories: read, search, edit, build, test, git, pull requests. OAuth 2.1. No OpenAI API key.
