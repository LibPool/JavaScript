# rulebridge

> 标签: casbin, converter, expr-eval, expression-eval, filtrex, interop, interoperability, jexl, json-logic, json-logic-engine, json-logic-js, json-rules-engine, jsonlogic, rules, rules-engine

## 简介

Convert rules between json-rules-engine, JsonLogic, json-logic-engine, filtrex, jexl, expr-eval, expression-eval and Casbin matchers via a canonical intermediate representation. Zero runtime dependencies, Rust-style Result API.
