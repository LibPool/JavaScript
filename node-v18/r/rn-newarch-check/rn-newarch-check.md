# rn-newarch-check

> 标签: bridgeless, ci, cli, codegen, compatibility, dependency-check, fabric, lockfile, migration, new-architecture, newarch, react-native, turbomodules

## 简介

Accurate React Native New Architecture compatibility checker that runs in CI. Verifies the version your lockfile actually resolved, not a flag about the library's newest release.
