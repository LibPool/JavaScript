# react-native-system-navigation-bar

> 标签: android, bar-style, contrast-enforced, defer-system-gestures, divider-color, edge-to-edge, fullscreen, gesture-navigation, hide-navigation-bar, home-indicator, immersive, ios, lean-back, navigation-bar, navigation-bar-color, new-architecture, react-native, status-bar, status-bar-color, sticky-immersive, system-navigation-bar, turbo-module

## 简介

Control the Android system navigation and status bars from React Native: hide and show, immersive modes, colors and icon styles, edge-to-edge detection — with iOS home indicator support.
