# rate-forge

> 标签: backend, ddos-protection, dos-protection, fixed-window, gcra, leaky-bucket, memory, middleware, mongodb, postgresql, rate-limiter, redis, security, sliding-window, sliding-window-counter, sliding-window-log, token-bucket, traffic-control, typescript

## 简介

Framework-agnostic rate limiter for Node.js supporting multiple algorithms and storage backends including Memory, Redis, MongoDB, and PostgreSQL.
