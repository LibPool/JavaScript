# root-scoped-bootstrap

> 标签: css, framework, front-end, mobile-first, responsive, sass, web

## 简介

Bootstrap fork to apply bootstrap styles to .root element childs. This is useful, when you don't want bootstrap to conflict with other site styles, and you dont have ability to use shadow dom features.
