# react-media-library-revived

> 标签: drag-and-drop, file-manager, file-manager-ui, filemanager, react, react-bootstrap, react-dom, reactjs

## 简介

React Media Library Revived is a UI package similar to the WordPress media library, but for React. It features file drag-and-drop as well as a library to select previously uploaded files.
