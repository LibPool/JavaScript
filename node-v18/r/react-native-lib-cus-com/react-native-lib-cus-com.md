# react-native-lib-cus-com

> 标签: lib-cus-com, react-native, react-native-lib-cus-com, react-native组件库, ui库, 二维码, 加载图, 图表, 屏幕方向操作, 截屏和截UI图, 打开文件, 文件操作, 条码, 极光推送, 水印, 组件库, 网路请求, 视频操作, 适配屏幕, 页面导航, 页面统一框

## 简介

react-native 自定义辅助组件库，完美的网路请求，带加载条，可上传、下载文件，等等多种ui，可自定义删除;可节省应用级软件的开发时间
