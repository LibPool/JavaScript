# rcswitch-peterstrapp

> 标签: 433, outlet, power, raspberrypi, rcswitch, rf, rpi, wireless

## 简介

Control your wireless power outlet sockets and listen for sensor input on 315Mhz/433Mhz with RCSwitch for the Raspberry Pi
