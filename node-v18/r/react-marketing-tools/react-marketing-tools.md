# react-marketing-tools

> 标签: analytics, attribution, consent, consent-mode, conversions-api, datalayer, facebook-pixel, ga4, gdpr, google-analytics, google-tag-manager, gtag, gtm, marketing, measurement-protocol, meta-pixel, nextjs, privacy, react, server-side-tagging, typescript, utm, web-vitals

## 简介

One track() call for Google Tag Manager, Google Analytics 4 and the Meta Pixel, with Consent Mode v2, UTM attribution and personal-data redaction built in. React bindings included.
