# riichi-mahjong

> 标签: mahjong, miniprogram, riichi, scoring, yaku

## 简介

针对微信小程序优化的日本麻将（日麻）计算引擎，支持牌型识别、役种和点数计算，适用于小程序和 Node.js 项目。
