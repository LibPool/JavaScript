# react-native-pdf-text-search

> 标签: android, ios, pdf, pdfbox, pdfkit, react-native, search, text-search

## 简介

Full-text search inside PDFs for React Native, returning normalized match rectangles you can draw as highlights. Native on iOS (PDFKit) and Android (PdfBox-Android).
