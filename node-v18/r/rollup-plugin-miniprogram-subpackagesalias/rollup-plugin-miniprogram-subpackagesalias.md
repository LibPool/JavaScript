# rollup-plugin-miniprogram-subpackagesalias

> 标签: alias, miniprogram, plugin, rollup, uni-app

## 简介

uni-app(Vue3)小程序，分包别名插件。用户处理不同分包下别名相同的情况，通过别名使用者的所在分包目录自动分配对应的分包
