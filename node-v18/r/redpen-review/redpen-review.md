# redpen-review

> 标签: annotation, claude-code, codex, coding-agent, feedback, html, markdown, opencode, review

## 简介

Collect red-pen feedback on Markdown, HTML, or plain-text files in the browser. Feedback is printed to stdout for a coding agent to act on.
