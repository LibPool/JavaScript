# reveal.js-tablechart

> 标签: chart, charts, dataviz, presentation, reveal.js, reveal.js-plugin, svg, waterfall

## 简介

A Reveal.js plugin for simple charts: column, bar, line, waterfall and donut, with annotations. The data is an HTML or Markdown table.
