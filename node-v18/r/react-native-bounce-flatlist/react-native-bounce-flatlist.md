# react-native-bounce-flatlist

> 标签: android, boucne, flatlist, ios, react-native

## 简介

基于FlatList封装的Bounce-FlatList, 支持下拉刷新, 分页加载等等常规特性, 特点在于android端也有弹簧效果.
