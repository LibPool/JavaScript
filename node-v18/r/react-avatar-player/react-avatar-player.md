# react-avatar-player

> 标签: animation, assistant, avatar, avatar-generator, chat, component, hooks, lip-sync, lipsync, react, svg

## 简介

Animated SVG avatar components and hooks for React. Blinking, eye movement, head idle motion and lip sync, rendered as pure vector SVG with no images or runtime assets.
