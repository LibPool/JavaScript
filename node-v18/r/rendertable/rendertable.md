# rendertable

> 标签: ai-native, csv, data-table, filter, html-table, nested, search, sort, table, vanilla, zero-dependency

## 简介

Render any JSON, object, or CSV into a sortable, searchable, filterable HTML table. Nested fields auto-unwrapped. Zero dependencies.
