# react-voyager

> 标签: coachmark, guide, guided-tour, highlight, onboarding, product-tour, react, showcase, spotlight, tooltip, tour, typescript, user-onboarding, walkthrough

## 简介

React library for building interactive product tours, onboarding walkthroughs and coachmarks: spotlight mask, smart popper positioning and a fully controllable step state machine.
