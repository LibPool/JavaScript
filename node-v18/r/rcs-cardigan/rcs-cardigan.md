# rcs-cardigan

> 标签: JavaScript

## 简介

Cardigan is a framework over Express.js to quickly spin up a node js back end server. It handles all the basic stuff a 90% of web apps needs. The framework is over Express.js so you can extend it and use any Express.js library and even integrate it with S
