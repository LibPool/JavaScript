# react-dev-panel

> 标签: component-graph, developer-logs, devtools, inspector, nextjs, react, vite-plugin, web-vitals

## 简介

A framework-agnostic, self-contained floating dev panel for React: Developer Logs, Page Performance, and a Component Graph Inspector (hover-to-source, component tree, open-in-editor).
