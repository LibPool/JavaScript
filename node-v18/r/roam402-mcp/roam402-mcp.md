# roam402-mcp

> 标签: agents, algorand, mcp, modelcontextprotocol, roam402, x402

## 简介

MCP server for Roam402 — give any agent the whole x402 economy, paid in USDC on Algorand. Tools: catalog, trust, precheck, paid service calls, balance.
