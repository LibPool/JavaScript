# reborn-connectors

> 标签: claude, claude-code, composio, connector, firecrawl, korean, mcp, perplexity, playwright, skill

## 简介

클로드 코드에 커넥터 넷(Perplexity 실시간 검색 · Firecrawl 페이지 통째 읽기 · Playwright 브라우저 조작 · Composio 앱 연결 관리)을 붙일 때 무엇을 어떤 순서로 쳐야 하는지 알려 주는 클로드 코드 안내 스킬입니다. 넷 중 키도 계정도 없이 바로 붙는 건 Playwright 하나이고, Composio 는 `claude mcp add` 가 아니라 플러그인 경로라는 갈림을 먼저 짚습니다. 각 커넥터는 다른 회사·프로젝트
