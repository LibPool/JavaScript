# ruler-function

> 标签: ruler, ruler-function

## 简介

The exponent of the largest power of 2 which divides a given number 2n. The values of the ruler function for  n=1, 2, ..., are 1, 2, 1, 3, 1, 2, 1, 4, 1, 2, ...
