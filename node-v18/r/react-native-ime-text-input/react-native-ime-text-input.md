# react-native-ime-text-input

> 标签: cjk, fabric, ime, japanese, react-native, textinput, uikit

## 简介

Drop-in replacement for React Native's TextInput, backed directly by UIKit on iOS, restoring the Japanese/CJK IME composition underline that Fabric drops.
