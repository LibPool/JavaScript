# rf24sn

> 标签: mqtt, mqtt-sn, nrf24l01, rf24sn

## 简介

Server for RF24SN. Connects sensors/actuators to MQTT broker. Simpler than MQTT-SN. Runs on nRF24L01 hardware.

- 官网：https://github.com/VaclavSynacek/RF24SN
