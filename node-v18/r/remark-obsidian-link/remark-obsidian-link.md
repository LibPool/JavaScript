# remark-obsidian-link

> 标签: JavaScript

## 简介

This lib turns Obsidian-style wiki-links to mdast-links. It uses [remark-wiki-link](https://www.npmjs.com/package/remark-wiki-link) internally to parse wiki-links from markdown, and then [visits](https://www.npmjs.com/package/unist-util-visit) each wiki-l
