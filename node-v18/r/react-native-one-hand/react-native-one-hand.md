# react-native-one-hand

> 标签: accessibility, android, expo, ios, modal, one-hand, one-handed, one-handed-mode, reachability, react-native, window

## 简介

One-hand mode for React Native: scales the entire app — including native modals, alerts and action sheets — and docks it into a bottom corner, within thumb's reach. iOS + Android.
