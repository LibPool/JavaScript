# reporting-api

> 标签: content-security-policy, csp, express, reporting, webappsec

## 简介

Express middleware to collect Reporting API reports. Supports CSP, COOP, COEP, Permissions-Policy, Document-Policy, Network Error Logging, crash, deprecation and intervention reports, plus legacy CSP report-uri
