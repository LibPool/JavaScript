# react-native-tauri

> 标签: app, application, cross-platform, desktop, electron-alternative, gui, javascript, linux, macos, multi-platform, react, react-native, rust, tauri, typescript, vite, web, webview, windows

## 简介

A modern JavaScript/TypeScript module that integrates React Native with Tauri for building multi-platform desktop, web, and cross-platform applications. Write once in React, deploy to Windows, macOS, Linux, and Web.
