# ruby-console-mcp

> 标签: console, irb, mcp, model-context-protocol, racksh, rails, repl, ruby

## 简介

MCP server for Ruby console interaction. Execute Rails console, IRB, or Racksh commands through Model Context Protocol with persistent session support.
