# randomx.js

> 标签: crypto, cryptocurrency, hash, mining, monero, pow, randomx, wasm, webassembly

## 简介

RandomX.js is a zero-dependency implementation of the ubiquitous Monero POW algorithm RandomX in JavaScript.
