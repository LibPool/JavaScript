# react-modular-datepicker

> 标签: calendar, calendar-component, customizable, date, date-picker, date-range, date-range-picker, datepicker, daterangepicker, dayjs, headless, headless-ui, hooks, i18n, localization, modular, react, react-component, react-hook, tailwind, tailwindcss, typescript

## 简介

A modular, lightweight, and type-safe React datepicker and calendar component with headless hooks for single, multiple, and range selection.
