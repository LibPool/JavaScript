# react-native-edge-glow

> 标签: animation, border, edge, gemini, glow, gradient, rainbow, react-native, reanimated, screen-edge, siri

## 简介

Siri / Gemini-style animated gradient glow around the screen edges for React Native. Runs on the UI thread via Reanimated and follows the display's real corner radius on Android 12+.
