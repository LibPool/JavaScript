# read-remote-pkg

> 标签: JavaScript

## 简介

Read the package.json of an npm module without installing it. Supports reading it from npmjs.com, github, and from the local file-system.

## 官网

- npm 页面：https://www.npmjs.com/package/read-remote-pkg

## 历史版本号

- 当前版本：0.0.1

- 0.0.1

## 获取地址

- npm 安装：`npm install read-remote-pkg`
- npm registry：https://registry.npmjs.org/read-remote-pkg
