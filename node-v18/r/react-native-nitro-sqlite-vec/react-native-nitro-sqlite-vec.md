# react-native-nitro-sqlite-vec

> 标签: android, ios, nitro-modules, react-native, sqlite, sqlite-vec, vector, vector-search

## 简介

Vector search (sqlite-vec) for react-native-nitro-sqlite. Native sqlite-vec is statically linked into the core's single sqlite3 — no second SQLite, no runtime extension loading.
