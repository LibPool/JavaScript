# react-native-phone-country-input

> 标签: calling-code, country-code, country-picker, country-selector, dial-code, expo, form, input, international, ipad, keyboard, mask, phone, phone-field, phone-input, phone-mask, phone-number, phone-number-input, react-native, tablet, typescript

## 简介

Phone number input for React Native & Expo — country picker, dial code selector, per-country masking, custom keyboard (no system keyboard flicker). Supports 270+ countries, tablets, iPad.
