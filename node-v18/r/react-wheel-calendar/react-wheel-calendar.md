# react-wheel-calendar

> 标签: calendar, circular, date-picker, interactive, react, scheduler, svg, time-picker, typescript, ui-component, wheel

## 简介

A flexible and customizable React library for creating circular calendar interfaces with interactive wheel-based displays, perfect for scheduling applications and time selection interfaces.
