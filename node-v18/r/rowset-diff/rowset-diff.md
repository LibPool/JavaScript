# rowset-diff

> 标签: compare, comparison, csv, dataset, diff, keyed, migration, primary-key, reconcile, reconciliation, result-set, rows, rowset, snapshot, sql, table, tabular, testing

## 简介

Diff two sets of rows by key — added, removed, and field-level changed. Order-independent, composite keys, ignore volatile fields. Zero dependencies.
