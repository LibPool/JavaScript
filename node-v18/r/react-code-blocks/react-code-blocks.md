# react-code-blocks

> 标签: code-blocks, code-snippets, mdx, react-syntax-highlighter

## 简介

Modified Atlaskit's Code Block to support more languages (i.e graphql, reasonml, etc) and theme (i.e railscast, dracula, monokai, etc) code snippets!
