# reorder-attributes

> 标签: attr, attrib, attribute, attributes, attrs, beautify, element, format, html, lint, order, prettify, re-format, re-order, tag, tags

## 简介

Re-format attributes in HTML tags to flow in a specific order. If you always prefer `class` before `id` or whatever, this module does that.
