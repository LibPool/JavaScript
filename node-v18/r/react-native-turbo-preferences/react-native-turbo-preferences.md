# react-native-turbo-preferences

> 标签: android, app-extension, app-group, app-groups, expo, ios, ios-widget, key-value, new-architecture, nsuserdefaults, preferences, react-native, share-extension, sharedpreferences, storage, suite, turbo-module, userdefaults, watchos, widget, widgetkit

## 简介

Share preferences between your React Native app and iOS widgets, watch apps & app extensions. Modern TurboModule for NSUserDefaults (App Groups) and Android SharedPreferences.
