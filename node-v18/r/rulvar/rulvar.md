# rulvar

> 标签: agents, durable-execution, llm, typescript, workflow

## 简介

Pointer to the Rulvar umbrella package: install @rulvar/rulvar (or this alias, which re-exports it). An embeddable TypeScript engine for durable, budget-bounded, testable multi-agent LLM workflows.
