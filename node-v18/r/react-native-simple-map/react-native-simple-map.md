# react-native-simple-map

> 标签: android, choropleth, d3-geo, geographies, ios, maps, react-native, svg, topojson

## 简介

Create beautiful, interactive SVG maps in React Native with d3-geo and TopoJSON. A React Native port of react-simple-maps.
