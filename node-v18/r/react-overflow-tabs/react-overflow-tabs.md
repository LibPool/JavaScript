# react-overflow-tabs

> 标签: bootstrap, dropdown, headless, headless-ui, hook, intersection-observer, menu, mui, navbar, navigation, overflow, overflow-tabs, react, react-hook, react-tabs-overflow, resize-observer, responsive, responsive-tabs, tab-navigation, tabbar, tabs, tailwind, ui-agnostic

## 简介

A lightweight React hook for responsive tab navigation with automatic overflow handling. Works with any UI framework (Tailwind, Bootstrap, MUI, custom CSS).
