# react-native-veyetals-native

> 标签: react-native, rppg, veyetals

## 简介

RNVeyetalsNative is an Android only component and it can be used to scan user vitals i.e heart rate, oxygen saturation, stress level etc. using smartphone camera. This version supports gradle version 7.2.0+ and JDK 11
