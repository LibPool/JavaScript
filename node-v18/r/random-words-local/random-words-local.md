# random-words-local

> 标签: cli, crypto, cryptographically-secure, diceware, entropy, generator, memorable-password, mnemonic, passphrase, passphrase-generator, passphrase-generator-cli, password, password-generator, random, random-password-generator, random-string, secure-password, strong-password, wordlist, words, xkcd, xkcd-password

## 简介

Generate secure, memorable random word passphrases from a 275,000+ word English dictionary. Perfect for creating strong passwords, passphrases, mnemonic phrases, and diceware-style wordlists. CLI tool with cryptographically secure random generation.
