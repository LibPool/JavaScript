# ryzek

> 标签: agent-skills, ai-agents, mcp, model-context-protocol, owasp, prompt-injection, sast, scanner, security, skill-md, static-analysis, supply-chain

## 简介

Static security scanner for AI agent skills and tool manifests. Detects prompt injection, hidden instructions, credential exfiltration, over-broad permissions, and post-approval tampering — with a confidence score on every finding.
