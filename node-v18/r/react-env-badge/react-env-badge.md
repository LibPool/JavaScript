# react-env-badge

> 标签: badge, chip, devtools, env, environment, nextjs, react, version, vite

## 简介

Chip fijo que muestra la versión y el ambiente activo en proyectos React. Sin dependencias. Compatible con Vite, Next.js y CRA.
