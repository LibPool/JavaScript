> 标签: accessibility, ai, brand, branding, campaigns, claude, content-design, creative-studio, design, design-system, image-generation, mcp, model-context-protocol, principles, service-blueprint, service-design, tokens, ui-patterns, ux, ux-research, ux-writing, video-generation, visual-design, voice-and-tone

## 简介

An MCP server for coding agents — click any element in your locally running app, say what should change, and get back the selector, computed styles, and design tokens, plus an audit of the result.
