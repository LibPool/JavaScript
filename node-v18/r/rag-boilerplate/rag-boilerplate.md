# rag-boilerplate

> 标签: ai, anthropic, boilerplate, chatbot, chroma, cli, create-app, drizzle, embeddings, gemini, llm, multi-tenant, nextjs, ollama, openai, pgvector, pinecone, qdrant, rag, retrieval-augmented-generation, scaffold, starter, typescript, vector-database, weaviate, workspaces

## 简介

Scaffold a full-stack Next.js RAG (retrieval-augmented generation) chat app — create-next-app style, with workspaces, image retrieval and an admin panel, tailored to the AI providers and vector store you choose.
