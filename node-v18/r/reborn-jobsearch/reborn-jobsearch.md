## 简介

ai-job-search(MadsLorentzen · MIT · 별 40.6k) — 클로드 코드 위에 얹은 AI 구직 지원 프레임워크를 받기 전에 무엇이 막는지 알려 주는 안내 스킬입니다. --check 가 이 컴퓨터에서 다섯 가지(Claude Code · Bun · Python 3.10+ · lualatex · xelatex)를 실제로 재 줍니다. 결과물인 이력서·자기소개서는 LaTeX 로 굽기 때문에, 막히는 자리는 받는 것이 아니라 굽는 것입니다.
