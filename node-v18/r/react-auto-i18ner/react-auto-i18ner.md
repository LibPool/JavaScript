# react-auto-i18ner

> 标签: automation, cli, extract, i18n, internationalization, jsx, next.js-coming-soon, nextjs-planned, npx, one-command, react, react-i18next, transform, translation, typescript, zero-config

## 简介

One-command React i18n transformation tool - Just run 'npx react-auto-i18ner' to automatically extract texts, create translation files, and transform JSX components. Next.js support coming soon!
