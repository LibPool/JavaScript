# react-uidevkit

> 标签: annotation, claude, claude-code, devtool, dx, feedback, overlay, qa, react, screenshot, ui

## 简介

In-app UI feedback overlay for React: pick an element or drag a box, describe the issue, and submit a rich context bundle (component chain, DOM, styles, console, screenshot). Dev mode queues captures for the /uidevkit Claude Code command; QA mode submits
