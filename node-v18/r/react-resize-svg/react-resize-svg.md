# react-resize-svg

> 标签: JavaScript

## 简介

基于React实现的可以拖拽和缩放的SVG组件库，组件库核心两个组件：`ResizeSvg`和`ResizeSvgHOC`。其中`ResizeSvgHOC`是高级组件，作用是实现组件包装和Props传递。
