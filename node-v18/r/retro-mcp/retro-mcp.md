# retro-mcp

> 标签: agile, ai, claude, github, jira, mcp, model-context-protocol, retro, retrospective, scrum, slack, sprint

## 简介

Generate a data-grounded sprint retrospective from your real Jira, Slack, and GitHub activity. What went well, what didn't, and action items, each backed by evidence, not vibes. An MCP server: local, read-only, model-agnostic.
