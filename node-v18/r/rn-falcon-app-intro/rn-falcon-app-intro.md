# rn-falcon-app-intro

> 标签: App, Intro, ProductTour, android, ios, react-component, react-native, swiper

## 简介

rn-falcon-app-intro is a react native plugin implementing a parallax effect welcome page using base on react-native-swiper , similar to the one found in Google's app like Sheet, Drive, Docs...
