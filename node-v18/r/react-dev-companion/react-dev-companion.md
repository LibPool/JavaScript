# react-dev-companion

> 标签: break-reminder, companion, devtools, floating-widget, focus, fun, interactive, pet, pomodoro, productivity, react, react-component, timer, virtual-pet, widget

## 简介

An interactive React companion widget that follows the Pomodoro timer — a fun floating pet that wakes up, walks, and gets tired as you code.
