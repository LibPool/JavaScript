# react-native-onboarding-parallax

> 标签: animation, carousel, intro, onboarding, pager, parallax, react-native, swiper, walkthrough

## 简介

A parallax onboarding carousel for React Native with per-layer depth, slot-based pages, and first-class RTL and reduced-motion support.
