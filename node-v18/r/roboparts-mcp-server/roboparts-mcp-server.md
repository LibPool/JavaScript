# roboparts-mcp-server

> 标签: actuator, ai-agent, bom, compatibility, humanoid-robot, mcp, model-context-protocol, robot-parts, robotics, sensor, servo

## 简介

MCP server for RoboParts — 798 humanoid robot component entities across 20 categories with compatibility, mechanical interface and parameter-comparability data. Vendor-neutral: we neither manufacture nor resell any part.
