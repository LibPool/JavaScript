# relative-search

> 标签: pinyin, search

## 简介

> * 支持拼音全拼漏拼首字母搜索&单词首字母搜索 > * 支持指定ascll和非ascll字符的最大匹配间隔（默认ascll字符相邻匹配，非ascll字符可在任意间隔匹配） > * 支持各种模式混合搜索 > * 支持动态增删搜索素材
