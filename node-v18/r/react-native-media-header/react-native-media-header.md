# react-native-media-header

> 标签: android, animation, blur, carousel, expo, header, ios, media, parallax, react-native, scroll, stretchy-header

## 简介

Parallax + blur media header for React Native detail screens: paging photos, scroll-linked blur, page dots, chip slot, background colour that follows the photo. Zero dependencies.
