# react-native-pure-bottom-sheet

> 标签: auto-fit, bottom-sheet, drag-to-dismiss, drawer, expo, fit-content, keyboard-avoiding, lightweight, modal, react-native, sheet, snap-points, zero-dependency

## 简介

A lightweight, zero-dependency, performant drag-to-dismiss bottom sheet for React Native and Expo with spring snap points, keyboard avoiding, auto-fit content sizing, and ScrollView integration.
