# react-native-optimized-pdf

> 标签: android, annotations, annots, big-pdf, catiledlayer, fast-pdf, ios, large-pdf, memory-efficient, pdf, pdf-display, pdf-performance, pdf-reader, pdf-renderer, pdf-viewer, pdfium, pdfkit, react-native, react-native-pdf, react-native-pdf-viewer, tiled-rendering, zoom

## 简介

React Native PDF viewer with high performance, zoom, and support for large PDF files. Fast, memory-efficient, and supports annotations (annots) on iOS and Android.
