# redas-protocol

> 标签: accountability, agent, ai, audit, canonical-json, commitment, construction, deterministic, function-calling, hash, llm, protocol, sha256, tool-use, trust, verification

## 简介

Deterministic SHA-256 hashing and offline verification for the Redas Commitment Protocol — a tiny open spec that gives every commitment a portable, hash-anchored identity. Zero dependencies; pure stdlib.
