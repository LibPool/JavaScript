# roble-client

> 标签: api-client, auth, crud, javascript, node, openlab, react, react-native, roble, typescript, uninorte

## 简介

Cliente para la plataforma ROBLE de Uninorte OpenLab. Autenticación y CRUD sobre bases de datos PostgreSQL. Funciona en Node, navegador, React y React Native.
