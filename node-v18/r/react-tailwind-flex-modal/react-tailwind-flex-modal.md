# react-tailwind-flex-modal

> 标签: a11y, accessible, animation, approval-modal, bottom-sheet, dialog, focus-trap, modal, multipurpose-modal, react, react tailwind modal, react tailwind multipurpose modal, tailwind

## 简介

Accessible, animated React modal built with Tailwind CSS 4 — ready-made and composable layouts, focus trap, inert background, enter/exit animations, mobile bottom sheet, dark mode, zero dependencies
