# rpi-cam-lib

> 标签: cam, camera, pi, raspberry, raspberry-cam, raspberry-cam-library, raspberry-pi, raspberry-pi-cam, raspberry-pi-cam-library, rpi, rpi-cam, rpi-cam-lib, rpi-cam-library, rpicam, rpicamera

## 简介

A lightweight library to control CSI-2 camera modules via any raspberry pi can read camera module but is dependent to shell.
