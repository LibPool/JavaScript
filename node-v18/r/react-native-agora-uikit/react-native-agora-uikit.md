> 标签: 16kb, agora, agora-rn-uikit, audio-call, page-size, react-native, react-native-agora, uikit, video-call, voice-call, webrtc

## 简介

Community fork of agora-rn-uikit. Video and audio calling for React Native with built-in UI, speaker/earpiece routing, and Android 16KB page-size support. Not affiliated with Agora.
