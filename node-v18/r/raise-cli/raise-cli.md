# raise-cli

> 标签: agent, claude-code, cli, codex, dashboard, monitor, tmux

## 简介

One page that shows every agent session on your machine - Claude Code, Claude Desktop, pi and Codex - tells you which one is waiting for you, and jumps to that window when you click it.
