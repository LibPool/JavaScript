# react-native-kevy-nitro

> 标签: jsi, kevy, nitro, react-native

## 简介

kevy for React Native via Nitro (JSI): a C++ HybridObject calling kevy-ffi directly — synchronous cmd() with ArrayBuffer payloads, and native->JS push pub/sub — bypassing the Expo-module dispatch + JNI crossing tax.
