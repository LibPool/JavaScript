# reborn-erase

> 标签: agent-skills, chatgpt, chatgpt-work, claude, claude-code, data-removal, korean, opt-out, privacy, right-to-be-forgotten, skill, 개인정보

## 简介

챗GPT Work 모드로 인터넷에 흩어진 내 정보를 찾아 삭제 요청하는 절차를 시작하기 전에 무엇이 막고 무엇이 조용히 멈추는지 알려 주는 클로드 코드 스킬. Work 가 유료 전용이라는 것, 대화를 지우면 주간 재확인 예약이 소리 없이 멈춘다는 것, 클라우드 브라우저에 로그인 세션이 남는다는 것, 가입만 해둔 곳은 한 줄도 안 나온다는 것을 먼저 말하고, 삭제 요청 원장을 대신 들고 간다.
