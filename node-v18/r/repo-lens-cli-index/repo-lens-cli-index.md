# repo-lens-cli-index

> 标签: bm25, embeddings, local-llm, ollama, rag, repo-lens, retrieval, semantic-search

## 简介

Optional semantic retrieval plugin for repo-lens. Builds shareable JSONL embeddings from generated docs and source files so queries can use embedding-aware ranking alongside BM25.
