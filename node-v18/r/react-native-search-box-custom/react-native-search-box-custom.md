# react-native-search-box-custom

> 标签: android, custom-search-box, ios, react-native, skiddolo

## 简介

A simple search box with animation and custom keyword, inspired from ios search bar. Lightweight, fast, flexible, customizable. Support both iOS/Android devices. Merged from anhtuank7c
