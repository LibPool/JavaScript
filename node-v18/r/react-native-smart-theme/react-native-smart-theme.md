# react-native-smart-theme

> 标签: accessibility, adaptive, apca, dark-mode, expo, image-theme, light-mode, material-you, palette, react-native, stylesheet, theme, themed-styles, wcag

## 简介

Dark/light mode theme engine for React Native & Expo — mode switcher (light/dark/system), one-seed palettes, themed styles/components, image→theme, Material You, optional smart contrast
