# rn-pdf-decrypt

> 标签: 128-bit, 256-bit, AES, AES-256, RC4, browser, decryption, hermes, password-removal, pdf, pdf-decrypt, pdf-decryption, pdf-lib, pdf-security, pdf-unlock, react-native

## 简介

React Native compatible PDF decryption with AES-256 (V=5, R=5/6) and RC4 support. Fork of @pdfsmaller/pdf-decrypt with @noble/hashes + @noble/ciphers instead of Web Crypto API.
