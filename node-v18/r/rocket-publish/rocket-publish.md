# rocket-publish

> 标签: cli, node, publish, rocket-publish

## 简介

rocket-publish 是一款专为前端开发者设计的本地一键部署工具，旨在简化 npm 包从构建到发布的整个流程，帮助开发者高效、快捷地完成项目的部署与发布

## 官网
