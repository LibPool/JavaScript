# rails-doctor

> 标签: 37signals, agent-skill, claude-code, codex, cursor, linter, rails, ruby, static-analysis

## 简介

Your agent writes bad Rails. This catches it. A static-analysis CLI for Ruby on Rails that scores your codebase 0-100 and installs as an agent skill for Claude Code, Codex, Cursor, and Copilot.
