# react-leaflet-easyprint

> 标签: leaflet, leaflet-easyprint, react, react-leaflet, react-leaflet-easyprint

## 简介

React wrapper of leaflet-easyPrint. A simple leaflet plugin which adds an icon to print or export a map.
