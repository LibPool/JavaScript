# react-3d-dice

> 标签: 3d, board-game, d20, d6, dice, dnd, react, rpg, tabletop, three.js

## 简介

3D dice renderer for React using Three.js. Supports D4, D6, D8, D10, D12, D20 with face labels, settle animations, and dot pips.
