# rsa-javascript

> 标签: RSAKeyPair, encryptedString, java加密, js加密, rsa, rsa-js, rsa-js-java, setMaxDigits

## 简介

RSA前端js加密，后端java解密 ；由后端产生公钥给前端加密，前端拿到公钥加密参数给后端。
