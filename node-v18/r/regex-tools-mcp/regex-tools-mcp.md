# regex-tools-mcp

> 标签: JavaScript

## 简介

An MCP server that provides regex utilities for AI coding agents: test patterns against strings, extract matches, replace text, explain regex in plain English, and generate regex from natural language descriptions. Built with AI by Craftpipe
