# re-gulp

> 标签: JavaScript

## 简介

使用Gulp构建项目，包括以下功能：  - 自动替换html中的引用文件路径  - 自动编译sass文件  - 自动合成雪碧图  - 自动将utf8编码的文件转换为gbk编码  - 支持css、js、html文件的压缩  - 自动转换es6语法
