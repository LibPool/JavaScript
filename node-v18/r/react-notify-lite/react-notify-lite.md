# react-notify-lite

> 标签: alert, lightweight, message, notification, notifications, notify, react, react-alert, react-component, react-notification, react-toast, snackbar, toast, toast-notification, typescript

## 简介

A lightweight and customizable React notification library with TypeScript support. Features multiple notification types, 6 positioning options, auto-dismiss, and smooth animations.
