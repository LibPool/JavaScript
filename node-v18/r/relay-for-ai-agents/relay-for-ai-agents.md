# relay-for-ai-agents

> 标签: agent-tools, ai-agents, anthropic, browser-automation, chrome-extension, claude, cline, codex, cursor, edge-extension, mcp, model-context-protocol, openai, opencode

## 简介

Remote browser infrastructure for AI agents. Connect any MCP-compatible host (Claude Desktop, Cursor, Cline, opencode, Codex CLI, custom agents) to a Chromium-based browser, locally or over a private overlay network.
