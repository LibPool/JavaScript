# romatsa-uav-zones

> 标签: JavaScript

## 简介

Fetch, normalize, and query Romania's ROMATSA UAV restriction zones (permanent zones + NOTAMs) in any JavaScript runtime.

- npm 页面：https://www.npmjs.com/package/romatsa-uav-zones

- Node 要求：>=18
