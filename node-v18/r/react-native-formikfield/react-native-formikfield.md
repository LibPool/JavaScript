# react-native-formikfield

> 标签: android, country-detection, form, formik, input, ios, label, password-strength, react-native, svg-icon, typescript, validation, yup

## 简介

Ultra-lightweight (~25-30KB) drop-in Formik field for React Native — label above the field, real-time Yup validation, password-strength bullets, auto-country phone detection, and fully customizable styles. One install, zero extra setup.
