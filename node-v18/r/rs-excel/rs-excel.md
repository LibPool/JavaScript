# rs-excel

> 标签: browser, excel, export, javascript, mit, sheetjs, styled excel, xlsx

## 简介

Librería ligera para exportar datos a Excel (.xlsx) con filtros, autoajuste y múltiples hojas. Sin dependencias externas en runtime.
