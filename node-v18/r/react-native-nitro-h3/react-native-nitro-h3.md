# react-native-nitro-h3

> 标签: android, expo, geospatial, h3, hex-grid, hexagon, hexagonal-grid, high-performance, ios, jsi, maps, nitro, nitro-modules, react-native, react-native-h3, react-native-nitro-h3, spatial-index, typescript, uber-h3

## 简介

Native H3 geospatial indexing for React Native, about 800x faster than h3-js on compactCells. Uber's H3 C library exposed through Nitro Modules, with bigint cell indexes, typed-array results and batch operations.
