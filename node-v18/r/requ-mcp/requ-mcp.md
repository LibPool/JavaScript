# requ-mcp

> 标签: conductor, coverage, cucumber, e2e, mcp, model-context-protocol, requirements, traceability

## 简介

MCP server to track requirements coverage and its evolution across phases/releases. Pairs with Conductor for e2e tests; links scenarios to user stories via @US-xxx tags.
