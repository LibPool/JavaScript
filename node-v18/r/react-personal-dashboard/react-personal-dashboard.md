# react-personal-dashboard

> 标签: dashboard, todo list, weather

## 简介

Personal dashboard featuring: Weather of a chosen location, Clock, Changing background based on time of day, Greeting based on time of day, Focus of the day, 3 to-do lists (inbox, today and done) with enabled flow of information between them, Inspirationa
