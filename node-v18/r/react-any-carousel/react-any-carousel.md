# react-any-carousel

> 标签: JavaScript

## 简介

AnyCarousal is a carousal component which is powerful, highly adaptable, and covers real use cases like custom content, snapping, auto scroll, and responsive layout. It works for all kinds of Content, so not just Images, Videos, but also any Custom Compon
