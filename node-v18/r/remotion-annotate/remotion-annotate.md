# remotion-annotate

> 标签: agentation, annotate, click-to-edit, overlay, remotion, remotion-plugin, studio, visual-editor

## 简介

Click-to-edit visual overlay for Remotion Studio. Select any element in the preview, tweak props/text visually, annotate for your AI agent, and edit the source directly.
