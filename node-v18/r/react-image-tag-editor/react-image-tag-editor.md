# react-image-tag-editor

> 标签: component-library, image-crop, image-editor, react, tag-management, typescript

## 简介

基于React的完整图片编辑器界面，开箱即用，支持图片裁剪、格式转换、水印处理、高清优化及灵活标签化管理。注意：需要安装 tailwindcss 作为样式依赖。
