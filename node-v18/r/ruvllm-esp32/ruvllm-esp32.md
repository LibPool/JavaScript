# ruvllm-esp32

> 标签: ai, edge-ai, embedded, esp32, esp32-s3, hnsw, inference, iot, llm, machine-learning, microcontroller, neural-network, offline-ai, quantization, rag, riscv, semantic-memory, tiny-ml, vector-search, xtensa

## 简介

RuvLLM ESP32 - Tiny LLM inference for ESP32 microcontrollers with INT8 quantization, RAG, HNSW vector search, hyperbolic embeddings (Poincaré/Lorentz), and multi-chip federation. Run AI on $4 hardware.
