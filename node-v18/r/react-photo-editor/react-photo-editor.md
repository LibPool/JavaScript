# react-photo-editor

> 标签: canvas, editor, image, image editing, image editor, image manipulation, photo editor, photo manipulation, react, react component, react image editor, react photo editor, react-image-editor, react-photo-editor, reactjs

## 简介

React component and hook for image editing, offering controls for brightness, contrast, saturation, and grayscale, along with features to rotate, flip, pan, draw, and zoom photos.
