# react-props-parser

> 标签: docgen, documentation, props, react, react-docgen, storybook, typescript, vite-plugin, webpack-loader

## 简介

TypeScript-aware React props parser: expands discriminated unions, unions of objects, and nested object props into structured data (via the TypeScript compiler API) instead of stringifying types like react-docgen-typescript does. Ships with a Vite plugin
