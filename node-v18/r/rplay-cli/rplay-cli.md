# rplay-cli

> 标签: ai-agent, analytics, attribution, claude-code, cli, codex, rplay, session-replay

## 简介

Rplay from the terminal: everything the dashboard shows and does, as JSON — session replay analytics, checkout funnels, attribution, ad spend, alerts, postbacks. Built for scripts and AI agents; installs its own agent skill.
