# react-face-login

> 标签: ai, ai-login, components, face-login, facebook-login, login, nextjs, nextjs-facebook-login, react, react-face-login, react-facebook-login

## 简介

is a React package that allows you to integrate facial recognition login functionality into your React applications. It uses external APIs like Face++ for face detection and comparison to authenticate users.
