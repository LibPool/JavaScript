# react-animation-css

> 标签: JavaScript

## 简介

`react-animation-css` 是 `Animate.css` 的 `React` 版本，其优势无需引入`css`样式文件，即可使用所有动画效果，并且利用`rollup`的打包机制，整个包只有十几kb大小，非常适用各种动画场景。
