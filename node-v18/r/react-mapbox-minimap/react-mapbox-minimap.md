# react-mapbox-minimap

> 标签: map, mapbox, mapbox-gl, maplibre, minimap, reactjs

## 简介

This package provides a minimap control for Mapbox GL or Maplibre GL maps. The minimap displays a smaller version of the main map, highlighting a portion of the view with a tracking rectangle. The minimap can be customized, moved, and resized based on you
