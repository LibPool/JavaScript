# react-atom-fork

> 标签: react

## 简介

Minimal, Atom-specific fork of React. Allows us to opt out of selection restoration and event dispatch.

## 官网

- 官网：https://github.com/facebook/react/tree/master/npm-react
- 源码仓库：https://github.com/facebook/react
- npm 页面：https://www.npmjs.com/package/react-atom-fork
