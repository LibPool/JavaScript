# runhttp

> 标签: api, api-testing, cli, curl, devtools, dothttp, http, http-client, rest, rest-client, vscode-rest-client, zero-dependency

## 简介

Run .http files (VS Code REST Client format) from the command line. Zero dependencies — a tiny, unbloated alternative to Postman.
