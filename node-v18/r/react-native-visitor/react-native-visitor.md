# react-native-visitor

> 标签: Native, React, Visitor

## 简介

基于React开发方式，jsx对象一旦生成将无法修改。但如果你有对jsx生成对象二次修改的需求时，ReactDOM可以通过ref获取到Element引用进行修改，但ReactNative则无能为力……ReactNativeVisitor便是提供你对jsx产生的对象进行二次修改的能力，想改啥就改啥！
