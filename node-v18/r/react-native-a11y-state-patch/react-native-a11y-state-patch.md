# react-native-a11y-state-patch

> 标签: a11y, accessibility, accessibilityState, accessibilityValue, android, ios, react-native, screen-reader, voiceover

## 简介

Native iOS patch that fixes stale VoiceOver announcements for React Native checkboxes, toggles, and radio buttons. Zero config — installs automatically.
