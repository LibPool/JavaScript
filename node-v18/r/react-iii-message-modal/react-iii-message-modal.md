# react-iii-message-modal

> 标签: JavaScript

## 简介

画面中央に通知用のモーダルを表示できます。   DOM要素は自身で生成し、表示終了時にDOMツリーから消去されます。   テキストを表示することを目的としており、エラー（赤系）、注意（黄色系）、正常（青系）のヘッダーカラーを表示時に指定できます。   また、クローズ時にwindowオブジェクトに対して特定のイベントをdispatchするので、必要に応じてモーダルを閉じる際のイベントを登録してください。
