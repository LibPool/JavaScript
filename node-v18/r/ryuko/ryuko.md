# ryuko

> 标签: audio, autoplay, discord, lavalink, lavalink-v4, music, music-bot, nodelink, queue

## 简介

A full-featured Lavalink v4 / NodeLink v3 music framework for Node.js with built-in queue, autoplay, filters, and plugin support
