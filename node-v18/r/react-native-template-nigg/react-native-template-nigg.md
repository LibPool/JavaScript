# react-native-template-nigg

> 标签: axios, babel-root-import, eslint, prettier, react-native, react-navigation, reactotron, template

## 简介

Template for projects in React Native, with Custom Folder Structure, Global Styles, ESLint + Prettier + Babel Plugin Root Import, React Navigation, Reactotron and configured Axios.
