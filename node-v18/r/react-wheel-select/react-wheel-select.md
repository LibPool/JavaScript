# react-wheel-select

> 标签: a11y, accessible, combobox, component, dropdown, form, input, ios, ios-picker, listbox, picker, react, scroll, scroll-select, select, typescript, ui, wheel, wheel-picker

## 简介

A beautiful, accessible iOS-style wheel picker component for React. Features smooth scroll snapping, keyboard navigation, full customization via CSS variables, and TypeScript support.
