# rabiskko-mcp

> 标签: JavaScript

## 简介

MCP server that lets an AI assistant (e.g. Claude Desktop) draw into the running Rabiskko app over a local WebSocket bridge.

## 官网

- npm 页面：https://www.npmjs.com/package/rabiskko-mcp

- Node 要求：>=18
