# react-error-boundary-rc

> 标签: JavaScript

## 简介

This component catches JavaScript errors anywhere in their child component tree, log those errors, and display a fallback UI instead of the component tree that crashed. Error boundaries catch errors during rendering, in lifecycle methods, and in construct
