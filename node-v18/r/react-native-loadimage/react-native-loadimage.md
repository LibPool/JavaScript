# react-native-loadimage

> 标签: app, es6, js, jsx, reactnative

## 简介

是一款图片预加载插件,带有原生loading加载器,通常在列表显示时,没有一个loading,总是不是很好的感觉,所以封装了一个,自己的项目也在用
