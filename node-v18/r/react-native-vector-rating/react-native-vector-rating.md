# react-native-vector-rating

> 标签: android, ios, rating, rating-component, ratings, react-native, react-native-component, react-native-stars, react-native-ui, react-native-ui-library, react-native-vector-rating, reactjs, reactnative, stars, ui-components, vector

## 简介

A lightweight and rating component for **React Native** that works with **most widely used icon libraries** such as **Lucide Icons** and **Expo Vector Icons**. You can also use custom SVG icons.
