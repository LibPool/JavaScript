# reslug-mcp

> 标签: ai, analytics, claude, cursor, link-management, mcp, model-context-protocol, modelcontextprotocol, qr-code, reslug, short-links, url-shortener

## 简介

Model Context Protocol server for Reslug: create short links, pull analytics, generate QR codes, and manage tags from any MCP client.
