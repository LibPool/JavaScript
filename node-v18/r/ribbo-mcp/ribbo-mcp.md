# ribbo-mcp

> 标签: ai-tools, billing, claude, cursor, mcp, model-context-protocol, recurring, ribbo, subscriptions

## 简介

Servidor MCP (Model Context Protocol) da Ribbo — expõe a API de cobrança recorrente como ferramentas para o seu assistente de IA: gerenciar assinaturas, consultar entitlements, estornar pagamentos e gerar links de pagamento/renovação.
