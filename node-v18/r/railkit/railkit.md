> 标签: api-wrapper, india, indian-railways, irctc, live-train-status, nodejs, pnr-status, rail-api, railkit, railway, railway-api, railway-sdk, sdk, seat-availability, station-codes, train, train-schedules, train-status, typescript

## 简介

🚂 Complete Node.js SDK for Indian Railways - Check PNR status, train schedules, live running status, seat availability, station information and more. Promise-based API with TypeScript support.
