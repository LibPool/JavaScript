> 标签: animation, css-animation, dots, equalizer, gradient, grid, indicator, loader, loading, loading-animation, loading-indicator, oklab, progress, react, react-loader, react-spinner, spinner, typing-indicator

## 简介

Composable React loading indicators — grids, bars and dots driven by phase fields, motion envelopes and OKLab gradients. Zero dependencies, compositor-only animation.
