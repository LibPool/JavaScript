# reborn-spector

> 标签: claude, claude-code, korean, nvidia, scanner, security, skills, skillspector

## 简介

엔비디아 SkillSpector(Apache-2.0)로 클로드 코드 스킬을 검사하고, 걸린 줄을 코드/설명 글로 갈라 한국어로 읽어 주는 스킬을 스킬 폴더에 놓고, 파일이 실제로 늘었는지 다시 셉니다. uv 가 있으면 검사기도 엔비디아 저장소에서 받아 깔고, 방금 깐 스킬을 실제로 검사해 봅니다.
