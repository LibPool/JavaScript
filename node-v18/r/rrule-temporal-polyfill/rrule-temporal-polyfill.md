# rrule-temporal-polyfill

> 标签: date, plaindate, plaindatetime, recurrence, rrule, temporal, time

## 简介

Fork of rrule-temporal with temporal-polyfill support. Recurrence rule (rrule) processing using Temporal PlainDate/PlainDateTime, with cross-timezone and cross-calendar rrule support
