# roomvana-mcp

> 标签: ai, home-design, interior-design, mcp, modelcontextprotocol, roomvana

## 简介

MCP server for Roomvana — browse room types & design styles and get a direct link to the Roomvana studio. Redesign any room from a photo in ~30s at https://roomvana.ai

## 官网

- 官网：https://roomvana.ai
- npm 页面：https://www.npmjs.com/package/roomvana-mcp
