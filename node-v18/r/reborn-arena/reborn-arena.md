## 简介

클로드 답이 마음에 안 들 때 같은 과제를 하위 에이전트 여럿에게 풀게 하고 토너먼트로 한 답만 남기는 원본 arena 스킬(Jakeschincariol/arena-skill · MIT)을 실행할 때 GitHub 에서 받아 스킬 폴더에 놓고, 한국어 안내 스킬을 더하고, 파이썬이 도는지 확인합니다. 원본은 이 패키지에 들어 있지 않습니다.
