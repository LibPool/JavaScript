# rx-tiny-flux

> 标签: flux, lightweight, ngrx, redux, rxjs, state-management, tiny, zeppos

## 简介

A lightweight, minimalist state management library for pure JavaScript projects, inspired by NgRx and Redux, and built with RxJS.
