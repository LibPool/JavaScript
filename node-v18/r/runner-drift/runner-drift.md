# runner-drift

> 标签: actions, ci, deprecation, drift, github-actions, migration, runner-images, ubuntu-22.04, ubuntu-26.04, ubuntu-latest

## 简介

Detect and attribute GitHub Actions runner-image tool drift: lock the tool versions your CI actually uses, diff them on every image bump, and plan a runner label migration before the deprecation deadline.
