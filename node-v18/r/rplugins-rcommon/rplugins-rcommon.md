# rplugins-rcommon

> 标签: extensions, jquery, js

## 简介

提供了常用的javascript数据类型的扩展函数，包括string、number、array等。同时提供一些常用操作函数。

- 官网：https://www.rplugin.com
- npm 页面：https://www.npmjs.com/package/rplugins-rcommon
