# reborn-council

> 标签: advisors, claude, claude-code, decision, korean, llm-council, skill

## 简介

되돌리기 어려운 결정을 조언자 5명과 의장 2명에게 돌리는 클로드 코드 스킬 TorpedoD/claude-council 을 받아 스킬 폴더에 놓고, 파일이 실제로 늘었는지 다시 셉니다. 한국어 안내 스킬이 같이 깔립니다. --check 가 깔기 전에 이 컴퓨터를 재 줍니다. 저장소는 남이 만든 MIT 오픈소스이고 저희는 제휴 관계가 없습니다 — 저희가 만든 것은 설치기와 한국어 안내 하나입니다. 따로 받는 API 키는 없습니다.
