# reborn-ytlearn

> 标签: claude, claude-code, gemini, korean, skills, transcript, video, youtube

## 简介

클로드 코드가 유튜브 영상의 말(자막)과 화면(장면 시트)을 읽게 하는 스킬 두 개를 스킬 폴더에 놓고, 파일이 실제로 늘었는지 다시 셉니다. 제미나이 API 키로 유튜브 주소를 그대로 넘기는 길과, 그 둘을 재료로 전담 담당자를 짜는 법을 한국어 안내 스킬로 같이 깝니다. --check 가 깔기 전에 이 컴퓨터(ffmpeg · yt-dlp)를 재 줍니다.
