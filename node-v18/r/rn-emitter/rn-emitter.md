# rn-emitter

> 标签: emitter, react, react-native, vue

## 简介

`rn-emitter` 是一个轻量级的前端事件发布/订阅（EventEmitter）库，适用于 Web 和 React Native 场景。它提供了简单易用的 API，支持事件的添加、移除、触发等操作，方便在组件间或模块间进行事件通信。
