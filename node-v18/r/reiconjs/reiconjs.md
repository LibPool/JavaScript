# reiconjs

> 标签: cdn, filled, icon-library, icons, javascript, no-dependencies, outline, reicon, svg-icons, tree-shakeable, typescript, vanilla-js

## 简介

Vanilla JS SVG icon functions for 2680+ icons in 2 weights (Outline & Filled). Zero dependencies, tree-shakeable, TypeScript-ready.
