# react-dczs-image-preview

> 标签: JavaScript

## 简介

- 基于 react17.x 开发的预览图片组件 - 支持 放大、缩小、复原、下载、打印、旋转、拖拽等功能 - 支持 png、jpg、jpge、bmp、gif 等常见图片格式 - 支持查看多个图片 - 开箱即用 只需传图片数据 轻便简单
