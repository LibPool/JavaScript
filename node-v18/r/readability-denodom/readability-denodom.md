# readability-denodom

> 标签: JavaScript

## 简介

Fork from Mozilla's Readability module, changed to work with deno-dom. A standalone version of the readability library used for Firefox Reader View.

## 官网

- 官网：https://github.com/henningko/readability
- 源码仓库：git+https://github.com/henningko/readability.git
- npm 页面：https://www.npmjs.com/package/readability-denodom
