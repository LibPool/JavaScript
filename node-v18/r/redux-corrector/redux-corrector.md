# redux-corrector

> 标签: "bhanu1106"], "bhanuloshali", "magicbox", "redux-magicbox", ["redux"

## 简介

It's a middleware for Redux, which filters the data of actions at runtime based on the template provided.If data is not meeting certain criteria it's changed to the default value as per the template if "required" field is true
