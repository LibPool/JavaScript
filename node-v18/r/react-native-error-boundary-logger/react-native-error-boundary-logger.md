# react-native-error-boundary-logger

> 标签: breadcrumbs, crash-reporting, deduplication, error-boundary, error-handler, error-logging, rate-limiting, react-native, typescript

## 简介

A production-ready React Native Error Boundary with built-in logging utilities — deduplication, rate-limiting, breadcrumbs, metadata, snapshots, and a global JS error handler
