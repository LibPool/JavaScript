# rnxorm

> 标签: database, entity-framework, mariadb, mssql, mysql, orm, postgresql, typescript

## 简介

A lightweight TypeScript ORM for PostgreSQL, MSSQL, and MariaDB, inspired by Entity Framework Core. See CHANGELOG.md for release notes.
