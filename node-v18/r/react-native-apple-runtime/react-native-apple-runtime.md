# react-native-apple-runtime

> 标签: designed-for-ipad, device-detection, expo, interface-idiom, ios, ipad, ipados, isiosapponmac, mac-catalyst, macos, platform, react-native, uiuserinterfaceidiom

## 简介

Authoritative Apple runtime detection for React Native and Expo. Tell an iOS app running on macOS (Designed for iPad) apart from a real iPad, and read the UIUserInterfaceIdiom — things Platform and expo-device can't. iOS only. Built with the Expo Modules
