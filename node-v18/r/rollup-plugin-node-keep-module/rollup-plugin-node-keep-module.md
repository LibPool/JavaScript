# rollup-plugin-node-keep-module

> 标签: JavaScript

## 简介

nodejs应用使用rollup打包的时候，不是所有的代码都可以正常打包成一个bundle，比如有循环引用的代码。 因此可以把有问题的包单独定义出来，则build的时候不会把包代码打包进去，同时会在output.dir里面生成一个package.json， 来包含这些包。
