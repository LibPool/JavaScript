# receive-email-api

> 标签: agent email, ai agents, courier, email api, inbox api, otp api, receive email api, smtp receiver, temporary email, verification api

## 简介

Receive email API for AI agents. HTTP API to create inboxes and retrieve OTP codes, magic links, and verification emails. No signup. No OAuth.
