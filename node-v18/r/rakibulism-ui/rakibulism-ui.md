# rakibulism-ui

> 标签: a11y, accessible, button, component-library, components, css-modules, css-variables, design-system, design-tokens, input, modal, react, react-components, tabs, tailwind-colors, themeable, toast, tooltip, typescript, ui

## 简介

Code-first React design system: 43 accessible, type-safe components with a deep-green brand palette and Tailwind-sourced semantic tokens. Tree-shakeable ESM+CJS, themeable via CSS variables, zero styling dependencies.
