# rabitwallet

> 标签: embedded-wallet, ethereum, non-custodial, onramp, rabit, solana, wallet, web3

## 简介

Embedded non-custodial wallet SDK with built-in fiat on/off-ramp — email/Google sign-in, split-key, EVM + Solana. One install, one import.
