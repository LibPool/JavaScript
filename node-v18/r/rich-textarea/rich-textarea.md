# rich-textarea

> 标签: autocomplete, autosize, combobox, contenteditable, editor, form, highlight, input, react, react-component, richtext, tagging, textarea, wysiwyg

## 简介

A small customizable textarea for React to colorize, highlight, decorate texts, offer autocomplete and much more.
