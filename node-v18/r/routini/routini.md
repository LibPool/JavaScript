# routini

> 标签: code-splitting, history, lazy-loading, lightweight, navigation, react, router, routing, spa, tiny, typescript, view-transitions

## 简介

A tiny router for React with lazy routes, an error boundary, View Transitions, reactive search params, scroll restoration, and link preload — ~3.2 KB gzipped, zero dependencies
