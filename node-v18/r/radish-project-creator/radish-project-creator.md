# radish-project-creator

> 标签: boilerplate, cli, create-project, generator, interactive, project-generator, scaffold, starter, template, typescript

## 简介

一个基于 Node.js 与 TypeScript 的交互式 CLI 脚手架, 通过多级菜单选择编程语言与项目类型, 一键生成标准化的项目模板.
