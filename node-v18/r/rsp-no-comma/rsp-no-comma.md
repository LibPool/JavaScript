# rsp-no-comma

> 标签: combobox, form, input, multiselect, react, react-component, select, ui

## 简介

A fork of [HubSpot/react-select-plus](https://github.com/HubSpot/react-select-plus). A comma is no longer trigger onChange in Select.Creatable.
