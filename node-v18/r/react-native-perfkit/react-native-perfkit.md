# react-native-perfkit

> 标签: cdp, doctor, expo, flashlist, fps, hermes, performance, react-native

## 简介

On-device React Native performance doctor: JS fps, React commits, host-view census, dev warnings, CPU profile, Android gfxinfo and emulator GPU checks over Metro CDP, adb and simctl.
