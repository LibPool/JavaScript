# react-gdrive-picker

> 标签: component, drive, drive-picker, file-picker, google, google-api, google-drive, picker, react, widget

## 简介

A customizable, inline Google Drive file picker component for React. Browse folders, search files, preview thumbnails, and select single or multiple files.
