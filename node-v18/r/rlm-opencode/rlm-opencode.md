# rlm-opencode

> 标签: context, kernel, opencode, plugin, python, recursive-language-model, rlm, subagents

## 简介

RLM (Recursive Language Model) for OpenCode: persistent Python kernel, background subagents, and a context lake that keeps large data out of the LLM prompt
