# rollup-plugin-consolelogplus

> 标签: console.log, rollup-plugin, vite-plugin

## 简介

自动改造 console.log 打印出该 console 所处的文件和代码在原文件（未经过任何编译）中所在行数，如果是变量的话还会加上变量名。兼容rollup和vite。
