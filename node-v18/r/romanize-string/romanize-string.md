# romanize-string

> 标签: arabic, cantonese, chinese, cyrillic, greek, indic, japanese, korean, latin, mandarin, multilingual, non-latin, persian, pinyin, romanization, text-processing, thai, transliteration, urdu

## 简介

A fully typed, general-purpose utility for unidirectional string transliteration (non-Latin script => Latin script).
