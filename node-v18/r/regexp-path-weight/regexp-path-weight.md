# regexp-path-weight

> 标签: JavaScript

## 简介

> 对 path-to-regexp 表示的路由 进行权重分析，并给出路由的 权重，可以利用生成的权重进行路由排序问题。避免因手动排序造成的路由混乱且不可控的情况
