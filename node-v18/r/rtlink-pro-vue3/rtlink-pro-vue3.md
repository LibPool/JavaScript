# rtlink-pro-vue3

> 标签: element-plus, element-ui, rtlink, rtlink-pro, rtlink-ui, rtlink-ui-plus

## 简介

本项目是适用于 vue3 框架的前端开源项目，瑞太智联自用的UI组件库。 要求 vue3 版本 >= 2.5.17。 本项目UI部分依赖于 element-plus。
