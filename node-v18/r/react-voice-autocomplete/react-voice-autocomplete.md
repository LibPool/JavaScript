# react-voice-autocomplete

> 标签: algolia, autocomplete, component, configurable, dropdown, fuse.js, headless, manual, meilisearch, modern, react, search, speech-to-text, typescript, ui, voice, voice search

## 简介

Modern, headless React autocomplete components with both voice and manual (typed) search support, including Algolia, Meilisearch, Fuse.js, API, and mock data options. Fully configurable UI.
