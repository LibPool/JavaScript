# react-scroll-velocity

> 标签: animation, marquee, react, react-component, react-hook, react-scroll-velocity, scroll, scroll-animation, scroll-speed, scroll-velocity, skew, velocity

## 简介

React hook & components for scroll-speed-based animations. Velocity text skew, speed-reactive marquee, parallax. Zero dependencies.
