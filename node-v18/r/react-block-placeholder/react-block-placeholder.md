# react-block-placeholder

> 标签: block placeholder, react components, 块级占位符

## 简介

1. 传入参数    1. w?:元素宽度    2. h?:元素高度    3. isGuideLines?:是否显示辅助线，展示边距    4. isCSSStyle?:是否展示css样式    5. color?:占位符的背景色，可传入渐变色，有默认值
