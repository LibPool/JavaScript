# rendemo-plugin

> 标签: claude-code, claude-code-plugin, demo, embed, mcp, onboarding, product-tour, rendemo

## 简介

The Rendemo Claude Code plugin. Authors hosted sandbox demos, installs published demos, and builds marker-anchored codebase tours through the Rendemo MCP.
