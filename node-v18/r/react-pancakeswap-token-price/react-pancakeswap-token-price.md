# react-pancakeswap-token-price

> 标签: BEP-20 token, live price, pancakeswap, pancakeswap API, pancakeswap API v2, pancakeswap api, pancakeswap public api, react, react pancakeswap, react pancakeswap packages, token price

## 简介

`react-pancakeswap-token-price` is a React.js package that uses `pancakeswap` REST API to provide a live price of a particular BEP-20 tokens and other necessary information. 📉📈
