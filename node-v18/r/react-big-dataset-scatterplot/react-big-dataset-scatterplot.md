# react-big-dataset-scatterplot

> 标签: JavaScript

## 简介

This is a customizable React component library for scatterplots. Unlike many other charting libraries out there, the `<Scatterplot/>` component can handle tens of thousands of datapoints without any problems or significant lag. This is made possible by us
