# request-coalescer

> 标签: async, cache-stampede, coalescing, concurrency, deduplication, promise-sharing, request, thundering-herd

## 简介

A production-quality TypeScript library to merge duplicate concurrent asynchronous requests into a single execution by sharing the same Promise.
