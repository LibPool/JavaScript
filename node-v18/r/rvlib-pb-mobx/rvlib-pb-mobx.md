# rvlib-pb-mobx

> 标签: JavaScript

## 简介

PocketBase + MobX data layer: observable paged lists and paged relations (server side filter/sort/page), aggregates that answer null rather than a number they cannot prove, record/query caches, optimistic updates, 50ms write batching, PocketHost rate limi
