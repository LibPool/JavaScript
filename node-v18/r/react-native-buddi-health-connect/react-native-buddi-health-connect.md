# react-native-buddi-health-connect

> 标签: android, buddi, fitness, health, health-connect, heart-rate, react-native, sleep, steps, wellness

## 简介

A React Native bridge for Android Health Connect, developed for the Buddi Life OS project. Provides seamless access to health data including steps, heart rate, and sleep sessions.
