# react-native-outbox-mutation-queue

> 标签: async-storage, backoff, mutation, offline, offline-first, queue, react-native, retry, sync

## 简介

A focused offline mutation queue for React Native — queue API writes while offline, retry with exponential backoff, deduplicate, persist across restarts.
