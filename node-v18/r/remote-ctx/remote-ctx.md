# remote-ctx

> 标签: JavaScript

## 简介

一个可以远程调试 JavaScript 环境的库，只要目标环境支持 `WebSocket`，就可以把目标上下文的对象暴露到另一个工作上下文（例如一个 NodeJs 脚本中），也可以在工作上下文调用目标上下文的函数。
