# react-native-jet-gallery

> 标签: gallery, image-viewer, lightbox, nitro, photo, react-native, shared-element

## 简介

A photo gallery for React Native with shared-element transitions, multi-image paging with looping, GIF support, and custom actions. Powered by Nitro Modules.
