# requirejs-zhangxd6

> 标签: requirejs

## 简介

Node adapter for RequireJS, for loading AMD modules. Includes RequireJS optimizer.This extended orginial requirejs by jrburke @ http://github.com/jrburke/r.js by providing the out option for modules and skip parameter
