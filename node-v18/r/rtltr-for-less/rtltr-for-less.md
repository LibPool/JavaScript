# rtltr-for-less

> 标签: JavaScript

## 简介

This is an extension module that adds automatic rtl/ltr file generation for code that uses https://npmjs.org/package/less-middleware for less generation.

## 官网

- 源码仓库：https://github.com/Pomax/node-rtltr-for-less.git
