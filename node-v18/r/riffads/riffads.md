# riffads

> 标签: ads, ai, cli, riffads, ugc, video

## 简介

The RiffAds command line client. Generate AI UGC video ads from a script and an actor, and pay per generation in credits.

- 官网：https://docs.riffads.com/cli/setup
- npm 页面：https://www.npmjs.com/package/riffads
