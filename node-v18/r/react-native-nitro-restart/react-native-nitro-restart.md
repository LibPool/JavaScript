# react-native-nitro-restart

> 标签: android, app-control, app-exit, app-lifecycle, app-management, app-reload, app-restart, background, cross-platform, exit, hybrid-object, ios, kotlin, lifecycle, mobile, native, native-module, nitro, nitro-modules, pid, process, process-id, react-native, reload, restart, suspend, swift, terminate, typescript

## 简介

App restart and process management for React Native built with Nitro Modules. Provides native app restart, safe exit, and process ID functionality with cross-platform support for iOS and Android.
