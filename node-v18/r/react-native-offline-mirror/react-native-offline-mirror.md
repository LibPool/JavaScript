# react-native-offline-mirror

> 标签: async-storage, conflict-resolution, encrypted-queue, exponential-backoff, graphql, mmkv, mutation-queue, netinfo, offline, offline-first, react-native, rest, sync, synchronization

## 简介

Offline-first mutation synchronization proxy for React Native: an encrypted local mutation queue between storage engines (MMKV/AsyncStorage abstractions) and remote REST/GraphQL APIs, with exponential backoff and pluggable conflict resolution.
