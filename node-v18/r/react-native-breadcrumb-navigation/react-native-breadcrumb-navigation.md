# react-native-breadcrumb-navigation

> 标签: breadcrumb, breadcrumb navigation, react native breadcrumb, react native breadcrumb navigation

## 简介

A basic react-native breadcrumb component library for both Android and ios. The component accounts for any number of trails that you input as an array to 'trailData' prop. The component is also dynamic and can handle for custom background colour, fontSize
