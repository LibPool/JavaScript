# redgin-store

> 标签: batch-updates, custom-elements, lightweight, localstorage, micro-state, observable, persistence, reactive, redgin, state-management, store, typescript, web-components

## 简介

A lightweight state management library for web components, built on top of Redgin. Provides a simple and efficient way to manage state in your web applications.
