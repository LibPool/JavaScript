# rtm-mcp

> 标签: deviniti, hexygen, jira, mcp, model-context-protocol, qa, requirements-test-management, rtm, test-management

## 简介

MCP server for the RTM (Requirements & Test Management) REST API v2 — exposes Requirements, Test Cases, Test Plans, Test Executions, Defects, Tree Structure and Automation as MCP tools.
