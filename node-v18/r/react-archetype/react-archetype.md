# react-archetype

> 标签: CSR, Client-side rendering, Lerna, NX, Nextjs, React18, SSR, Server-side rendering, Turbo, Vite, Webpack5, module federation, next, react, webpack

## 简介

React-archetype is a cli tool (or a generator) that will generate apps based on the rendering pattern (CSR,SSR, SSG, ISR etc) of your choice.
