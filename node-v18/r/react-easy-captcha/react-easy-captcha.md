# react-easy-captcha

> 标签: a11y, accessible, captcha, image-captcha, nextjs, react, react-component, security, self-hosted, typescript

## 简介

First-party image CAPTCHA for React: typed EasyCaptcha widget plus Node challenge issue/verify with pluggable storage. No third-party CAPTCHA provider.
