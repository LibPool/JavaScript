# roadsign

> 标签: JavaScript

## 简介

## What is it? RoadSign is a Node.JS console DDNS utility that updates (or creates) an AWS Route53 'A' record with the public IP discovered through the [icanhaz](https://github.com/major/icanhaz) service.
