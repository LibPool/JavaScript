# redis-parser-ts

> 标签: decoder, encoder, network, parser, protocol, redis, resp, server, streaming, tcp, typescript

## 简介

A blazing-fast, fully-typed TypeScript library for decoding and encoding Redis RESP protocol. Build custom Redis servers, proxies, or developer tools with ease.
