# react-native-streaming-markdown

> 标签: ai, ai-chat, anthropic, chat, chatgpt, expo, formatting, llm, markdown, markdown-display, markdown-renderer, openai, partial-markdown, react, react-native, react-native-markdown-display, streaming, text, typescript

## 简介

Markdown renderer for React Native built for streaming AI responses. Renders partial markdown without flicker, handles unclosed code fences and emphasis, and keeps node identity stable across frames. Zero dependencies.
