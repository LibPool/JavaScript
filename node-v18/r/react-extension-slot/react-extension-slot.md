# react-extension-slot

> 标签: extension, extension-slot, plugin, react, slot

## 简介

A lightweight, plugin-style **extension–slot mechanism** built with **React + TypeScript + Zustand**.   This architecture allows you to dynamically register reusable UI components (“extensions”) and render them in specific placeholder areas (“slots”).
