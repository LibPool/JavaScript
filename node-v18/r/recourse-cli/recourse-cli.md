# recourse-cli

> 标签: ai-agents, blast-radius, claude, consequence-analysis, infrastructure, llm, mcp, mcp-server, model-context-protocol, safety, terraform

## 简介

MCP server for AI agents to evaluate consequences before destructive actions. Analyzes Terraform plans, shell commands, and MCP tool calls.
