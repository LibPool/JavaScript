# remark-typescript-tools-prettier-ignore

> 标签: JavaScript

## 简介

A fork of [remark-typescript-tools](https://github.com/phryneas/remark-typescript-tools) Respects `// prettier-ignore` inside the ```` ```ts```` block but doesn't include it in the compiled code neither for TypeScript nor JavaScript.
