# rtmlib-ts

> 标签: 3d-mesh, 3d-pose, browser-ml, computer-vision, dwpose, efficientdet, human-pose, instanthmr, mediapipe, mhr, mhr70, object-detection, onnx, onnxruntime, onnxruntime-web, pose-estimation, rtmo, rtmpose, rtmw, rtmw3d, sharedarraybuffer, typescript, ultralytics, wasm-threads, webassembly, webgl, webgpu, webnn, yolo, yolo12, yolo26, yolo26n, yolov12n, yolov8, yolov8n

## 简介

Browser-only AI library for real-time object detection (YOLOv8n / YOLOv12n / YOLOv26n, MediaPipe EfficientDet-Lite0) and 3D pose estimation (RTMW3D-X COCO-WholeBody 133-keypoint 3D, InstantHMR MHR70 mesh) on ONNX Runtime Web — wasm, WebGL, WebGPU, WebNN.
