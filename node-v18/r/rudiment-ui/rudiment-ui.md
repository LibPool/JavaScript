# rudiment-ui

> 标签: a11y, accessibility, component-library, design-system, design-tokens, layout-primitives, react, react-aria, theming, ui-components

## 简介

Accessible React component library built on React Aria, with layout primitives, charts, and a three-tier design token architecture supporting eight built-in themes.
