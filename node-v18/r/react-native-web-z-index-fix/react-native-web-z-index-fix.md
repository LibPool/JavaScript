# react-native-web-z-index-fix

> 标签: expo, overlay, react-native, react-native-web, stacking, stacking-context, tooltip, web, z-index

## 简介

Fixes React Native Web giving every View z-index:0 (which traps earlier siblings below later ones). Import once on web to reset z-index:auto on RNW's css-view-* classes so stacking follows declaration order, like on native.
