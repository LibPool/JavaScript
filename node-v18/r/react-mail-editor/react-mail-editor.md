# react-mail-editor

> 标签: django, drag-and-drop, email, email-builder, email-editor, email-template, html-email, laravel, newsletter, react, shadcn, tailwind, wordpress, wysiwyg

## 简介

A customizable, extensible drag-and-drop email template builder for React 19, built with shadcn/ui. Framework-agnostic: drop it into WordPress, Laravel, Django, Flask or any React app.
