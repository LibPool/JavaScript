# rishav-antigravity-auth

> 标签: antigravity, auth, claude, gemini, google, oauth, opencode, plugin

## 简介

Google Antigravity IDE OAuth auth plugin for Opencode - access Gemini 3 Pro and Claude 4.5 using Google credentials (Fixed rate limit rotation)
