# react-persist-state-hook

> 标签: cache, expiry, hook, localStorage, nextjs, persist, react, ssr, state, tab-sync, typescript, useState

## 简介

A drop-in replacement for React.useState that persists state to localStorage with expiry, cross-tab sync, SSR, and sessionStorage support.
