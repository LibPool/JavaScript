> 标签: language, react, react-component, react-language-selector, react-language-selector-component, react-language-selector-ui, react-language-switcher, selector, switcher, widget

## 简介

A quick little language switcher drop-down select menu written in React.js. Well commented and supports unlimited languages using JSON files for use on any website.
