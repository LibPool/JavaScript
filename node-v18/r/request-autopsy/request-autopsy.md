# request-autopsy

> 标签: api, api-testing, debug, debugger, diagnostics, express, express-middleware, http, logger, logging, middleware, monitoring, performance, request, request-autopsy, response, security, sql-injection, validation, xss

## 简介

Express middleware that auto-analyses every request and reports issues: wrong HTTP method, missing fields, security threats (XSS, SQLi, path traversal), performance problems, auth errors, oversized payloads, and more.
