> 标签: ES2015, ES6, boilerplate, browser, bundle, chai, framework, intellisense, isomorphic, istanbul, microsoft, mocha, node, react, rollup, server, transpile, ts, typescript, universal, vscode, workflow

## 简介

Fast, and lightweight TypeScript boilerplate that export a single file. Tests in Mocha & Chai. TSLint for better code quality.
