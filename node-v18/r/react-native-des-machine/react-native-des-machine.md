# react-native-des-machine

> 标签: android, base64, cbc, cipher, crypto, cryptography, decrypt, decryption, des, des-decryption, des-encryption, ecb, encrypt, encryption, hex, ios, mobile-encryption, native-module, pkcs7, react-native, react-native-crypto, react-native-encryption, react-native-security, security, text-encryption, turbo-module, turbomodule

## 简介

React Native DES encryption and decryption library with TurboModule support. Encrypt and decrypt text using DES algorithm with multiple cipher modes (ECB, CBC, CFB, OFB, CTR), padding schemes (PKCS7, ISO10126, Zero, None), and output formats (Base64, Hex)
