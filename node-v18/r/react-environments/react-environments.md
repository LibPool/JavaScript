# react-environments

> 标签: easy react environment npm, environment, environments, environments with ease, react environment, react like angular environments, react-environment, react-environments

## 简介

node package used to have environments like in angular for react applications, create environment.env files under /environments/ folder and pass env name like 'module --env = qa'
