# rad-designer

> 标签: JavaScript

## 简介

- 搭建前端架子 基于vue2搭建 ###  编辑器----4d - 构建画布 - 参考线 - 吸附线、组件对齐 - 拖拽改变组件形状 - 元素: 复制（画布） - 元素: 删除（画布） - 元素: 编辑（画布 - 快速预览 - 撤销、重做 ### 组件系统（基于element封装和添加）----接入已有组件实现配置化 5d + 封装定制组件 3d（8d） - 文字 - 普通按钮 - 输入框 - 富文本 - 图片 - 图片选择器 - 页眉页脚.(固定区域) - 表格 --表格编辑器 - 单选框 - 多选框
