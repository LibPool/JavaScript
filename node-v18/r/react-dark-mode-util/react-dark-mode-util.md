# react-dark-mode-util

> 标签: JavaScript

## 简介

Con esta librería, puedes agregar fácilmente un interruptor de modo oscuro en su página web, lo que permite a los usuarios cambiar el color de fondo y texto a una paleta de colores más oscura y cómoda para la vista.
