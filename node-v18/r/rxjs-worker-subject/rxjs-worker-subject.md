# rxjs-worker-subject

> 标签: messaging, observable, observer, postmessage, reactive, reactive-programming, rxjs, stream, subject, typescript, webworker, worker

## 简介

Reactive Web Worker communication using RxJS — subscribe to worker output as an Observable, send input as an Observer.
