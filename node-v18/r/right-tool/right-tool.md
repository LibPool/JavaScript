# right-tool

> 标签: JavaScript

## 简介

Lets you setup scripts in package.json such that they use the same tool (npm/npx | yarn | pnpm | bun) or (node | bun) that you used to execute it. Also detects container implementation (docker|podman|kubectl|buildah|incus|nerdctl|colima).
