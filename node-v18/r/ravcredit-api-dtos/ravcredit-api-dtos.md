# ravcredit-api-dtos

> 标签: JavaScript

## 简介

Shared **TypeScript DTO library** for backend development.   This package provides a consistent set of **base DTO objects** used for **validation, verification, and standardization ** across services (commonly in **NestJS** apps using `class-validator`
