# reservoirkit

> 标签: algorithm-l, algorithm-r, fisher-yates, random-sample, reservoir-sampling, sampling, shuffle, stream-processing, typescript, vitter, weighted-sampling, zero-dependency

## 简介

Zero-dependency reservoir sampling for TypeScript: Algorithm L (Vitter), weighted sampling, Fisher-Yates shuffle, stream sampling. Port of Python random.sample on iterables.
