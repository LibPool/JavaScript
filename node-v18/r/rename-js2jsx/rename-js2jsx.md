# rename-js2jsx

> 标签: JavaScript

## 简介

将 js 或 ts 后缀且内容含有 jsx 语法的文件重命名为 jsx（tsx）后缀的文件。 背景：项目庞大后开发构建速度慢，改为 vite 开发模式提升开发体验，vite 是基于后缀名是否为 jsx 或 tsx 来决定是否按照 jsx 解析文件，但是之前项目后缀名不是很规范都是 js 后缀，于是就写了该脚本工具。
