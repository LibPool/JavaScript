# react-native-velora-sheet

> 标签: android, bottom-sheet, footer, headless, ios, keyboard, keyboard-avoiding, keyboard-aware, modal, react-native, safe-area, safe-area-inset

## 简介

Lightweight React Native bottom sheet with a measured bottom safe-area inset and a footer that lands exactly on the keyboard (iOS + Android). Ships no UI.
