# rn-power-optimization-prompt

> 标签: ASUS, HTC, HUAWEI, LETV, OPPO, Protected, SAMSUNG, VIVO, XIAOMI, android, apps, data, optimization, plugin, power, react-component, react-native, saver, settings

## 简介

Show a dialog prompting the user to go to their phone's power optimization settings, depending on their device, where they can set exclude their phone from power optimization which usually stops the phone from receiving notifications when the screen is of
