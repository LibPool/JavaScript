# react-image-magnifier-wzb

> 标签: image, magnifier, react, react-component

## 简介

#####**使用方法** ``` npm install react-image-magnifier-wzb ``` --- #####**参数** - url (必需，图片的路径) - width (可选，图片的宽度) - height (可选，图片的高度) - scale (可选，放大镜的比例，基于你填的图片宽度，默认为3倍)
