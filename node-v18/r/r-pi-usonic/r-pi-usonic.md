# r-pi-usonic

> 标签: gpio, hcsr04, mmap, pi, raspberry, sensor, ultrasonic

## 简介

A high performance, memory mapped, Node.js API for the HC-SR04 ultrasonic sensor connected to a Raspberry Pi.
