# rubiks-js

> 标签: 3x3, 3x3x3, cube, image, jsdoc, mobile, phone, picture, rubiks, rubiks cube, state, touch

## 简介

A rubiks cube with no dependencies. Can use custom images for faces. The state of the cube can be safed.
