# reborn-web5

> 标签: animejs, bklit, claude, claude-code, kokonut-ui, korean, motion, skills, web-animation

## 简介

클로드로 웹을 만들 때 쓰는 다섯 곳(anime.js · Motion · Kokonut UI · Bklit UI · Manus)을 내 프로젝트에 맞게 가르는 한국어 스킬을 스킬 폴더에 놓습니다. 지금 폴더의 React/Next/Vue · Tailwind · shadcn 여부를 재서 바로 쓸 것 · 준비가 필요한 것 · 안 맞는 것 · 유료 서비스를 나눠 보여 주고, 라이브러리는 대신 깔지 않습니다.
