# react-upload-indexeddb

> 标签: antd, chunked-upload, file-upload, indexeddb, react, resumable-upload, upload

## 简介

基于 IndexedDB + 分片传输的大文件上传/下载 React 组件（断点续传、秒传、刷新续传），支持 Bearer Token / 同域 Cookie 鉴权注入。
