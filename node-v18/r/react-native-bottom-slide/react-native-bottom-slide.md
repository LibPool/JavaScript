# react-native-bottom-slide

> 标签: android, ios, react-native

## 简介

A lightweight and customizable bottom sheet library for React Native and. Features smooth animations, gesture support, multi-state layouts, and seamless compatibility across Android, iOS, and Web. Perfect for creating modals, menus, and expandable views.
