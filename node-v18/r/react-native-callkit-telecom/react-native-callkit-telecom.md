# react-native-callkit-telecom

> 标签: android, ios, react-native

## 简介

Native CallKit and Android Telecom integration for React Native CLI VoIP applications. Supports incoming and outgoing calls, PushKit, FCM, audio routing, mute, hold, and native call lifecycle events.
