# renkin

> 标签: cheminformatics, chemistry, drug-discovery, retrosynthesis, wasm

## 简介

Ultra-fast retrosynthesis engine for computer-aided synthesis planning (CASP) — pure Rust, WASM-ready, Python bindings via PyO3
