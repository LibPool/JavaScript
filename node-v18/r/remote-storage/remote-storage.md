# remote-storage

> 标签: Javascript, browser, device, feature flags, local, local storage, localStorage, remote, remote storage, remoteStorage, storage, user flags, web

## 简介

remoteStorage is a simple library that combines the localStorage API with a remote server to persist data across browsers and devices.
