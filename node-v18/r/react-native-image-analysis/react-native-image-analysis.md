# react-native-image-analysis

## 简介

On-device image analysis for React Native: OCR text + geometry on both platforms, barcodes, image classification, background removal, and an interactive text-selection image view — Apple Vision/VisionKit on iOS, Google ML Kit on Android. New Architecture
