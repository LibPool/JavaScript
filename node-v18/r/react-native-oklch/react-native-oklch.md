# react-native-oklch

> 标签: color, gamut-mapping, interpolation, oklab, oklch, react-native, reanimated, worklet

## 简介

Perceptual OKLCH color interpolation and gamut mapping for React Native, on the UI thread — worklet-safe, zero-dependency scalar math returning packed RGBA ints.
