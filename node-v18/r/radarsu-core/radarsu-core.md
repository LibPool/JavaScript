# radarsu-core

> 标签: JavaScript

## 简介

Web framework for building swagger-compliant REST APIs using Typescript, with integrated REST and websocket handling. Providing logger and database connection. Setup combined of: express (server), uws (websockets), tsoa (routing decorators + swagger), win
