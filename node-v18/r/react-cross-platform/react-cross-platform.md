# react-cross-platform

> 标签: react, react cross platform, react fetch, react native, react navigator, react web, react-cross-platform, react-native, react-web, reactjs

## 简介

Write code for React Web and React Native using one simple framework. Maximizes code re-use, readability, and wraps necessary functions into promises.
