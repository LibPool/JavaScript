# react-ts-audio-recorder

> 标签: audio, hooks, mp3, react, recorder, wav, web-audio, webm

## 简介

Framework-agnostic multi-format audio recorder with MP3 and WAV support. Built on top of Kagami/vmsg for MP3 encoding, with custom PCM→WAV encoder.
