# recital-score

> 标签: alignment, asr, double-metaphone, language-learning, memorization, needleman-wunsch, phonetic, recitation, scoring, speech, transcript, word-accuracy

## 简介

Score a spoken recitation against text you already know, by sequence alignment with asymmetric gap costs, so false starts, repetitions, self-corrections and recognizer noise are free, and a genuinely forgotten clause is not.
