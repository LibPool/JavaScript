# react-onedivloaders

> 标签: animated loaders, animated loading spinners, animated preloaders, loaders, loading spinners, preloaders, react, react.js

## 简介

React component for onedivloaders, an open-source collection of monochrome loaders (loading spinners) built with pure CSS and one div element.
