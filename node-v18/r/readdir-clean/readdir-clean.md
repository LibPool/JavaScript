# readdir-clean

> 标签: array, async, asynchronous, clean, contents, directory, enumerate, file, files, filter, fs, list, promise, readdir

## 简介

Like `fs.readdir`, but excludes autogenerated contents for example .DS_Store and Thumbs.db
