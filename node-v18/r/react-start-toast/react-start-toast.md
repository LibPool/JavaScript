# react-start-toast

> 标签: cookie, cookie-flash, flash, flash-message, flash-toast, headless, headless-toast, notification, notifications, react, react-toastify, redirect-with-toast, remix-toast, server-toast, sonner, start-toast, tanstack, tanstack-start, tanstack-start-toast, toast, toaster, tss, tss-toast

## 简介

Headless server-set toast notifications for TanStack Start (TSS). Flash toasts via h3 cookies and server fns — a 1:1 adaptation of remix-toast. Bring your own UI (sonner, react-toastify, etc.).
