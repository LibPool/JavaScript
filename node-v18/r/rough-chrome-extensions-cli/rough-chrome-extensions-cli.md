# rough-chrome-extensions-cli

> 标签: chrome-extensions, parcel

## 简介

___   ### 描述   这是一个cli程序，将会为你创建一个chrome-extensions开发模板。   特点：   - parcel 构建 - ts文件具有 --- chrome.xxx 语法提示 - 支持框架编译 (parcel自带)
