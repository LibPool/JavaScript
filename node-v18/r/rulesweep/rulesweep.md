# rulesweep

> 标签: agent-harness, audit, claude-code, claude-md, cli, context-window, token-optimization

## 简介

CLAUDE.md audit CLI (free edition): measure the per-turn token cost of CLAUDE.md / .claude/rules, and count duplicate lines, contradictions and broken references. No API key required.
