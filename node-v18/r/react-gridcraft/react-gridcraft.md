# react-gridcraft

> 标签: data-grid, editable-grid, excel-like, grid, react, spreadsheet, table

## 简介

A lightweight, high-performance editable data grid for React - virtualized rows, sticky/grouped headers, per-cell editing, keyboard navigation. Not tied to any specific app or vendor.
