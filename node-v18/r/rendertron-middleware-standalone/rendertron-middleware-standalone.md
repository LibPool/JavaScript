# rendertron-middleware-standalone

> 标签: JavaScript

## 简介

Simple middleware for rendertron using [rendertron-middleware](https://github.com/GoogleChrome/rendertron/tree/main/middleware).   Opinionatedly configured to skip static resources and every bot (including GoogleBot).
