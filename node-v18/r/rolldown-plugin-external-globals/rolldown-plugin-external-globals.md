# rolldown-plugin-external-globals

> 标签: external-globals, oxc, rolldown, rolldown-plugin, rollup-plugin, rust

## 简介

Transform external imports into global variables for Rolldown. A Rust/oxc port of rollup-plugin-external-globals that reuses Rolldown's own AST tooling instead of re-parsing in JS.
