# react-skip-logic

> 标签: branching, form, headless, multi-step, onboarding, quiz, react, skip-logic, survey, wizard

## 简介

Headless branching / skip-logic engine for multi-step forms, surveys and quizzes in React. Describe your flow as JSON, bring your own UI. Live demo: https://mankarsandesh.github.io/react-skip-logic/
