# reborn-v3code

> 标签: agent-skills, byok, claude, claude-code, code-editor, cursor, korean, mcp, skill, v3code, vscode

## 简介

영상에서 소개한 V3Code(지속 메모리를 얹은 VS Code 포크 에디터)를 받기 전에 먼저 재 주는 안내 스킬입니다. 에디터는 0원이지만 AI 기능은 내 API 키로 돈다는 것(BYOK), 리눅스는 지금 안 내려간다는 것, MCP 로 붙일 에이전트가 이 컴퓨터에 있는지를 직접 재 줍니다.
