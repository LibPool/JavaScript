# react-mobile-viewport

> 标签: hooks, matchMedia, media-query, mobile, next, nextjs, react, responsive, ssr, viewport

## 简介

SSR-safe React hooks to detect mobile, tablet, and desktop viewports. Works with Next.js App Router.
