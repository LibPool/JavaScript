# remix-cn-js

> 标签: JavaScript

## 简介

Remix是以太坊官方开源的Solidity在线集成开发环境，可以使用Solidity语言在网页内完成 以太坊智能合约的在线开发、在线编译、在线测试、在线部署、在线调试与在线交互， 非常适合Solidity智能合约的学习与原型快速开发。
