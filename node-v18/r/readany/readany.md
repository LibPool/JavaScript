# readany

> 标签: converter, document, docx, epub, extract, markdown, ocr, parse, pdf, pptx, rtf, wasm, xlsx

## 简介

Route and read documents into clean Markdown — Word, Excel, PowerPoint, OpenDocument, RTF, EPUB, CSV and text-layer PDF. Names the pages it could not read instead of dropping them silently. Text recognition is not included: it needs a native runtime.
