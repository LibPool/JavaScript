> 标签: flex, flexbox, grid, infinite, infinite-scroll, list, react, react infinite scroll, react infinite scroll hook, react-component, react-hooks, react-virtualized, scroll, scrolling, useInfiniteScroll

## 简介

A react hook for creating simple, fast and lightweight components with infinite scrolling in any direction, supporting both windowed and scrollable elements.
