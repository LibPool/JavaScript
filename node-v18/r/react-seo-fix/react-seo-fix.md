# react-seo-fix

> 标签: base44, bolt, cursor, lovable, prerender, react, seo, ssg, vite

## 简介

Add full SEO optimisation to any React/Vite SPA in one command. Adds pre-rendering, per-page meta tags, sitemap, and robots.txt.
