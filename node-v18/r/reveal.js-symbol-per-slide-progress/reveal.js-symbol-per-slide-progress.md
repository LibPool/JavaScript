# reveal.js-symbol-per-slide-progress

> 标签: reveal, reveal-js, reveal-js-plugin, reveal-plugin, revealjs

## 简介

An alternative progress plugin for reveal.js to show every slide as single symbol and the symbol of the current active slide in a different color
