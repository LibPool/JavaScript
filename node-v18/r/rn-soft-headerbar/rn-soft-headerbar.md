# rn-soft-headerbar

> 标签: component, header, navbar, react-native, ui

## 简介

react-native-headerbar is a customizable and feature-rich HeaderBar (AppBar) component built specifically for React Native apps. It provides a flexible and modern UI out-of-the-box, offering built-in support for title, subtitle, back button, icons, search
