# react-native-smart-permissions

> 标签: android-permissions, expo, ios-permissions, mobile, permission-flow, permission-manager, permissions, react-native, react-native-permissions, typescript

## 简介

A complete, customizable permission workflow manager for React Native. Handle rationale UI, permission requests, denial, blocked access, settings redirection and rechecking on return.
