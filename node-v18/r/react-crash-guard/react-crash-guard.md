# react-crash-guard

> 标签: async-errors, aws, cloudwatch, componentdidcatch, crash-reporting, error-boundary, error-boundary-hook, error-handling, error-recovery, error-reporting, fallback-ui, observability, react, react-error-boundary, react-hooks, react18, saas, sentry, typescript

## 简介

React error boundary library that also catches async errors — global, route, and feature-level isolation with pluggable Sentry, CloudWatch, and custom reporting. TypeScript-first, zero runtime dependencies.
