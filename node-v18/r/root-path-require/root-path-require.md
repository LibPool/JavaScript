# root-path-require

> 标签: JavaScript

## 简介

Provides a function to require standard local modules without using relative paths. Suported modules are the one located under BASE_PATH (parameter) with the folowing allowed name: 'config', 'controller', 'middleware', 'model', 'routes', 'utils'
