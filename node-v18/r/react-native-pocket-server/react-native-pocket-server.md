# react-native-pocket-server

> 标签: api, expo, express, http, http-server, lan, local-server, middleware, react-native, rest, router, server, tcp, web-server

## 简介

Tiny Express-style HTTP server that runs inside your React Native app — routing, middleware, routers, CORS and file serving over TCP. Zero runtime dependencies.
