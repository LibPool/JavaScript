# react-native-mrzscannerlib

> 标签: mrz, ocr, passport, react-native, scanner

## 简介

MRZ Scanner reads all machine-readable zones on traveling documents following the ICAO 9303 Specification on Passports (2 – lines) for TD3 size Machine Readable Passports; MRV-B Visas (2 - lines) as described in part 7 of ICAO 9303 documentation; and ID c
