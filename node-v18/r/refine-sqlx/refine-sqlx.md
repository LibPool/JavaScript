# refine-sqlx

> 标签: JavaScript

## 简介

A type-safe, framework-agnostic data provider with Drizzle ORM for SQLite, PostgreSQL, MySQL databases (Bun, Node.js, Cloudflare D1). Compatible with Refine, svadmin, and any DataProvider-based framework.
