# react-native-youtube-iframe-player

> 标签: android, ios, react-native

## 简介

React native youtube iframe player is a youtube iframe that is cloned from the react-native-youtube-iframe library that solves the issue of showing the developer options when pressing on the iframe if using the youtube iframe inside the pressable componen
