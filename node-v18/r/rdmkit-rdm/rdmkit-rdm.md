# rdmkit-rdm

> 标签: typography

## 简介

RDM is an script for resizing elements in the DOM to a height closest to the nearest multiple of the baseline height. This is meant to be a tool for web typography nerds that want to attempt to follow a strict baseline throughout their web pages.
