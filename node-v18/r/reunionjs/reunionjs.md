# reunionjs

> 标签: Algorithms, Data-Structures, Disjoint-Set, Math, Union-Find

## 简介

A JavaScript (WASM) API for the Rust backend of `reunion`, i.e. a Union-Find w/ Rank data structure for JavaScript that runs WebAssembly.
