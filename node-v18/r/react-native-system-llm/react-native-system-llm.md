# react-native-system-llm

> 标签: aicore, android, apple-foundation-models, apple-intelligence, gemini-nano, ios, llm, on-device, on-device-llm, react-native

## 简介

Unified React Native API for the OS-provided on-device LLM: Apple Foundation Models on iOS 26+, Gemini Nano on Android. No bundled weights, zero app-size hit.
