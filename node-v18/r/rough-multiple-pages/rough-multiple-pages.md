# rough-multiple-pages

> 标签: multiple-pages, rough-multiple-pages, 多页面

## 简介

___ 一个使用 **gulp** 构建的项目初始化工具。   倾向于使用原生 html + css (less) + js 去开发页面。如果需要依赖于 vue / react 那可能不太适合。
