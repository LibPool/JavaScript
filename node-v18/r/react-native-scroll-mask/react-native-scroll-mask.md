# react-native-scroll-mask

> 标签: android, expo, fade, fade-edges, flatlist, gradient, ios, mask, react-native, reanimated, scroll, scrollview

## 简介

Fade the edges of any scrollable in React Native based on scroll position. Works on iOS and Android, powered by Reanimated and SVG.
