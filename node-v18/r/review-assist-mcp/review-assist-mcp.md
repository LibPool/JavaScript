# review-assist-mcp

> 标签: ai-agents, claude-code, code-review, codex, github, intent-document, mcp, model-context-protocol, pull-request

## 简介

MCP server that turns an AI agent's coding session into a reviewable Intent Document — a two-agent author/reviewer distillation, gatekept by a deterministic validator. Works with Claude Code and Codex.
