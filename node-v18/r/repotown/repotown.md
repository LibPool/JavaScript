# repotown

> 标签: 3d, city, code-map, codebase, github, repo-visualizer, three.js, visualization

## 简介

Turn any codebase into a 3D city you can walk through. Paste a GitHub URL at repotown.vercel.app or run locally against any repo.

## 官网

- 官网：https://repotown.vercel.app
- 源码仓库：git+https://github.com/CharlonTank/repotown.git
- npm 页面：https://www.npmjs.com/package/repotown
