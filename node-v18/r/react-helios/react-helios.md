## 简介

Production-grade React video player with HLS, playlist support, Up Next overlay, zero-cost audio mode, adaptive quality, live streams, subtitles, VTT sprite thumbnail preview, skip buttons, mobile-responsive controls, and a standalone HLS-capable AudioPla
