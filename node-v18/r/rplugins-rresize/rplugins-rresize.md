# rplugins-rresize

> 标签: jquery, js, layout, resize

## 简介

主要提供以下两大功能：自动计算容器高度使其铺满父容器；动态给body添加类以实现响应式页面

- npm 页面：https://www.npmjs.com/package/rplugins-rresize
