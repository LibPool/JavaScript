# rei-kit

> 标签: a11y, accessible, claymorphism, component-library, components, dark-mode, design-system, design-tokens, glassmorphism, neobrutalism, neumorphism, palettes, pwa, supabase, tailwind, tailwindcss, themes, typescript, ui-kit, vue, vue3

## 简介

One kit, every look. 105 accessible Vue 3 + Tailwind 4 components, four materials (quiet, glass, brutal, soft) and ten WCAG-checked palettes, each switched with one attribute.
