# redisjson-memory-server

> 标签: json, mock, redis, redis-prebuilt, redis-stack, redisjson, stub

## 简介

Redis Server with RedisJSON module support for testing. Spins up real Redis instances with JSON capabilities, allowing parallel integration tests isolated from each other.
