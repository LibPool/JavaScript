# react-form-rewind

> 标签: draft, form, history, hooks, keyboard-shortcuts, localStorage, persistence, react, redo, state, time-travel, undo

## 简介

Zero-dependency React state engine with auto-saved history stacks, time-traveling undo/redo, keyboard shortcuts, and draft persistence for forms.
