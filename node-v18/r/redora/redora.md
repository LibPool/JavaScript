# redora

> 标签: cache, caching, interceptor, ioredis, nestjs, redis, sdk, ttl

## 简介

Redis SDK for NestJS with a typed command API and declarative HTTP caching (interceptor, decorator, cache keys, TTL presets), built on ioredis.
