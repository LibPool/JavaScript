# responsive-image-loader

> 标签: JavaScript

## 简介

Webpack loader to create responsive images. Uses responsive-loader with sharp adapter under the hood with custom predefined options. <br /> <br /> Can be used with babel-plugin-named-asset-import (create-react-app) to export responsiveImage instance like
