# rubick-translate

> 标签: JavaScript

## 简介

超级强大的多服务翻译工具，内置国内可用的谷歌翻译服务、OCR、朗读发音等多数基础功能全免费，为插件会员用户精心定制Mini窗口及多样聚合翻译服务。
