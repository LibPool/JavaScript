# react-native-nitro-storage

> 标签: android-keystore, async-storage, biometric-storage, biometrics, encrypted-storage, expo-secure-store, fast-storage, indexeddb, ios-keychain, jotai, jsi, keychain, mmkv, native-module, nitro, nitro-modules, performance, persistence, react-native, react-native-mmkv, react-native-secure-storage, react-native-storage, secure-storage, secure-store, state-management, storage, synchronous, synchronous-storage, zustand

## 简介

Synchronous React Native storage powered by Nitro Modules and JSI: typed Memory, Disk, Keychain/Android Keystore secure storage, biometric auth, MMKV migration, Expo, Zustand/Jotai persistence, and web IndexedDB support.
