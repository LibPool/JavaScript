# react-if-breakpoint

> 标签: breakpoint, conditional rendering, if, media query, react, react component visibility, react show hide on screen size, responsive

## 简介

> React component for responsive, condition-based rendering. Use JSX like `<If mobile>` or `<IfSEO desktop>` — with support for both live-resize interactivity and SEO.
