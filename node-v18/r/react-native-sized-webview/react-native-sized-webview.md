# react-native-sized-webview

> 标签: android, auto-height, auto-size, component, content-measurement, dynamic-height, hook, html-rendering, ios, javascript-bridge, layout, mobile, native, performance, react-native, responsive, sizing, typescript, web-content, webview

## 简介

React Native WebView that auto-sizes to match its HTML content—whether you load local HTML or full external websites—without manual measurements, timers, or layout flicker.
