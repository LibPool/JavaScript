> 标签: expo, hole-punching, ios, iroh, iroh-ffi, networking, p2p, peer-to-peer, quic, react-native, turbo-module, uniffi

## 简介

React Native bindings for the official iroh-ffi: the full iroh p2p API surface (QUIC connections, streams, relays, discovery) as a prebuilt Turbo Module — no Rust toolchain required
