# react-native-animated-view

> 标签: animation, control animation, custom animation, react native animated view, react native animation, react native 动画, 控制动画, 自定义动画

## 简介

你可以像jQuery那样只给结果样式就能操作各种动画,你可以控制每一个样式的动画时间、动画函数甚至每一帧等。总之,你可以随意搭配轻松如意地操纵react-native动画。
