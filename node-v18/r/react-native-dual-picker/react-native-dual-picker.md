# react-native-dual-picker

> 标签: android, calendar-picker, date-picker, date-range-picker, day-picker, dual-picker, dual-wheel-picker, from-to-picker, ios, month-picker, range-picker, react-native, react-native-picker, react-native-ui, scroll-picker, two-column-picker, typescript, ui-component, weekday-picker, wheel-picker, year-picker

## 简介

React Native dual wheel picker: from/to range selection with scroll wheels — numeric range, date & calendar range (Y/M-D), month, day, weekday, year, alphabet, decimals; min/max gap, ISO/EU/US date layouts, TypeScript.
