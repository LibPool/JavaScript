# rambogogo-chatroom

> 标签: JavaScript

## 简介

留言板 1、注册功能 2、登录功能 3、不登录也能看到别人的留言列表 4、登录后才能留言 5、留言信息中有登录名 6、留言信息持久化到本地文件 7、登录、注册、留言要有加法和图片验证码
