# react-native-board-view

> 标签: accessibility, board, drag-and-drop, expo, flash-list, kanban, react-native, reanimated, swimlanes

## 简介

Kanban and swimlane boards for React Native and Expo. Virtualized columns, long-press drag, a Move to… sheet, and optimistic moves with rollback. Your items stay the source of truth.
