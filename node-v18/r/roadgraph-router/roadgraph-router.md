# roadgraph-router

> 标签: a-star, browser, geojson, offline, openstreetmap, osm, pbf, road-graph, routing, turn-restrictions

## 简介

Compile any OpenStreetMap PBF extract into compact, range-addressable routing bundles and route over them with A* in Node.js or the browser.
