# ricelang

> 标签: burmese, karen, mon, myanmar, nlp, ricelang, segmentation, shan, syllable, tokenization, tokenizer

## 简介

Regex-based syllable tokenization for Burmese and Myanmar-script ethnic languages (Karen, Mon, Shan). A JS/TS port of the ricelang Python package's syllable tokenizer.
