# ragtor-mcp

> 标签: claude, cursor, llm, mcp, model-context-protocol, rag, ragtor

## 简介

Ragtor MCP server — ask the web layer for LLMs (ask_ragtor → /v1/answers) and expose any Ragtor-indexed site as tools for Claude Desktop, Cursor, and any MCP-compatible client.
