# rasso-plugin-authenticator

> 标签: JavaScript

## 简介

桌面双因素动态验证码 (2FA / TOTP) 管理器：支持手动输入与屏幕截屏识别二维码、30秒平滑圆环倒计时、纯本地加密持久化、搜索直达与一键回车复制
