# reborn-sysprompt

> 标签: anthropic, claude, claude-code, claude-md, korean, prompt-engineering, prompting, skills, system-prompt

## 简介

앤트로픽이 공식으로 공개해 둔 Claude 시스템 프롬프트를 읽고, 거기서 뽑은 설계를 내 프롬프트·CLAUDE.md·스킬에 옮기게 돕는 안내 스킬입니다. 인터넷에 도는 「유출본」을 찾을 일이 아닙니다 — 2024년 8월부터 모델마다 공개돼 있습니다. --check 가 문서에 직접 붙어 지금 공개된 모델 수와 합계 길이를 세어 주고, 공개본이 claude.ai 웹·앱 전용이라 API 에는 안 붙는다는 것까지 알려 줍니다. 원문은 담지 않습니다.
