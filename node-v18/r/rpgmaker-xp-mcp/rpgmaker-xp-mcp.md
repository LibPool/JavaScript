# rpgmaker-xp-mcp

> 标签: game-development, marshal, mcp, model-context-protocol, rgss, rgss1, rpg-maker-xp, rpgmaker, rxdata

## 简介

Author RPG Maker XP games in natural language — an MCP server that reads, writes, and renders RGSS1 .rxdata projects (actors, skills, items, maps, events, scripts) directly.
