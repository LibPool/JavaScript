# rule-trace

> 标签: agent-skills, ai-agents, claude-code, codex, governance, opencode, rules, skills.sh, tracing

## 简介

Make AI-agent rule application visible and auditable: stable rule IDs, a catalog, trace blocks, usage counters, and a deterministic validator. Installable across Claude Code, OpenCode, and Codex via the Agent Skills standard.
