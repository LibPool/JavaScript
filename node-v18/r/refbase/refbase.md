# refbase

> 标签: ccli, cli, knowledge-base, refbase

## 简介

rb 命令：打印本地 ~/refbase-workspace/data 资料区中指定索引的 Markdown 内容，支持按 Agent runtime（codex/cursor）优先匹配专属版本。
