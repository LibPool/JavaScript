# react-components-boilerplate-cli

> 标签: boilerplate code generator, react, react components create

## 简介

This cli lets you to create react components with boilerplate code generation for jsx imports, render body and props with PropTypes validations, you can create respective scss and test files for component.

 type crc -help for assist
