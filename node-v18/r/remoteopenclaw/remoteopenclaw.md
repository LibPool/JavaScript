# remoteopenclaw

> 标签: aggregator, claude-code, codex, cursor, directory, hermes, mcp, model-context-protocol, openclaw, plugins, skills

## 简介

Search Remote OpenClaw (13,870+ MCP servers, 4,384+ agent skills, and plugins) from your terminal or AI agent. Works as a CLI (npx remoteopenclaw search <query>) and as an MCP server.
