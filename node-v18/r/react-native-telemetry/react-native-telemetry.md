# react-native-telemetry

> 标签: JavaScript

## 简介

Telemetry is a super simple API for sending point metrics to [Influxdb](https://docs.influxdata.com/influxdb) in batches at a given time interval. It's just a simple wrapper for Influxdb's REST API. As points are created they're timestamped and cached on
