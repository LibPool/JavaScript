# regexp-map

> 标签: RegExp, curried, function, functional, hash, higher-order, map, regexp, regexp-map, regular expression, regular-expression, regularexpression, string

## 简介

Curried function which takes a map of `RegExp` string keys which when successfully matched given string, resolves to mapped value.
