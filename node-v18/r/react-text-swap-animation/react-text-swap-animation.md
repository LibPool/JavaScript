# react-text-swap-animation

> 标签: anagram, animation, hero-text, kinetic-typography, letter-animation, letters, morph, react, react-component, rearrange, ssr, swap, text, text-animation, text-swap, typescript, typography, word-animation, zero-dependencies

## 简介

Animate between any two words or phrases in React - letters glide to their new positions, and unmatched ones fade in and out. Zero dependencies, SSR-safe, TypeScript types included.
