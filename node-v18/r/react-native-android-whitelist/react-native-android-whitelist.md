# react-native-android-whitelist

> 标签: android, battery, react-native, whitelist

## 简介

Many android manufactuers have power saving optimizations that prevents applications from receiving push notifications while the app is not active. This package will help you alert the user to whitelist your app so that push notifications will arrive more
