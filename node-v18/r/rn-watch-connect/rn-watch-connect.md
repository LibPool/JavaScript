# rn-watch-connect

> 标签: RnWatchConnect, apple-watch, apple-watch-communication, apple-watch-connectivity, apple-watch-data-transfer, apple-watch-file-transfer, apple-watch-message-transfer, expo, react-native, rn-watch-connect, watchconnectivity

## 简介

A React Native module that enables seamless communication between an iOS app and its paired Apple Watch using WatchConnectivity. It provides an easy-to-use interface for sending messages, transferring files, syncing data, and monitoring connection status
