# react-simply-carousel

> 标签: carousel, carousel-component, infinite-carousel, react, react-carousel, react-component, react-slider, responsive-carousel, slider, slider-component, touch-enabled-carousel, typescript, typescript-carousel

## 简介

A simple, lightweight, fully controlled isomorphic (with SSR support) React.js carousel component. Touch enabled and responsive. With support for autoplay and infinity options. Fully customizable
