# route-picker-umi3-plugin

> 标签: umi3 plugin, umi3 开发效率, umi3 热更新, umi3 路由

## 简介

减少 umi 热更新时间, 仅适用于 umi3. 开发时通过指定关注的路由, 提高编译速度.
