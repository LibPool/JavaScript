# reasonix-vision-mcp

> 标签: deepseek, image-compression, image-description, mcp, mcp-server, model-context-protocol, reasonix, siliconflow, vision

## 简介

Vision Bridge MCP Server — 让 DeepSeek（纯文本模型）通过 MCP 调用视觉模型来「看到」图片。支持 SiliconFlow / OpenAI 兼容 API，含图片压缩功能。
