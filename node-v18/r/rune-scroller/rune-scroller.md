# rune-scroller

> 标签: animations, dom, intersection-observer, lightweight, performance, scroll-animations, scroll-trigger, svelte, svelte5, vanilla-js

## 简介

Framework-neutral scroll animations for the DOM with a Svelte 5 action. 29 primary animations plus 7 legacy aliases, zero dependencies.
