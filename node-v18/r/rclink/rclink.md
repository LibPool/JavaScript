# rclink

> 标签: JavaScript

## 简介

### 介绍 RCJS(RepChain Client library for JavaScript)，是基于JavaScript实现的用于与[RepChain](https://gitee.com/BTAJL/repchain)区块链网络进行交互的工具包，可作为开发RepChain DApp(Decentralized Application)的SDK。
