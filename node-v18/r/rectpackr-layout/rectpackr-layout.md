# rectpackr-layout

> 标签: best-fit, custom-element, custom-elements, dom, layout, masonry, masonry-layout, rectangle-packing, responsive, responsive-layout, strip-packing, web-component, web-components

## 简介

A web component that creates layouts by packing HTML elements as rectangles using a best-fit 2D strip-packing algorithm. Automatically measures dimensions and handles mixed content.
