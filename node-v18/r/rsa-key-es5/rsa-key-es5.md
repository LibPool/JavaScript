# rsa-key-es5

> 标签: DER, PEM, PKCS1, PKCS8, convert, crypto, detect, es5, format, formats, key, keys, node, private, public, rsa

## 简介

[ES5 version] Converts between RSA key formats, detecting input format (PEM, DER, PKCS1, PKCS8). No OpenSSL needed.
