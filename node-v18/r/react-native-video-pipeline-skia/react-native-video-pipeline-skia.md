# react-native-video-pipeline-skia

> 标签: pipeline, react-native, skia, video, worklet

## 简介

Skia helper for react-native-video-pipeline — wraps Skia offscreen surface + readPixels/writeBytes in a single drawWithSkia() callback so consumer code stays Skia-boilerplate-free while the main library keeps zero Skia dependency.
