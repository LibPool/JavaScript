# react-flow-auto-layout

> 标签: auto-layout, dag, dagre, flowchart, graph, layout, react-flow, xyflow

## 简介

Auto layout for React Flow, built on dagre: variable-size nodes, true bounding-box centering, and straightened linear segments (no kinked connectors).
