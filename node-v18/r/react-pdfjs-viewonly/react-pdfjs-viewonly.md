# react-pdfjs-viewonly

> 标签: pdf, pdfjs, react

## 简介

`react-pdfjs-viewonly` is a simple React component that integrates the `pdf.js` library to display PDF documents in your React App. The viewer supports viewing options like zoom, navigation, and find in document, but restricts actions such as downloading,
