# rehype-highlighter

> 标签: code, highlighting, markdown, md, plugin, rehype, shiki, syntax, theme

## 简介

A rehype plugin that highlights code blocks in Markdown using Shiki. Supports highlighting for fenced code blocks and inline code snippets in multiple themes
