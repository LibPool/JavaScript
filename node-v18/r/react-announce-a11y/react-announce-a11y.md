# react-announce-a11y

> 标签: HTML5, NVDA, Windows Narrator, a11y, accessibility, chrome, edge, javascript, narrator, react, screen reader, typescript

## 简介

Used to have the screen reader announce messages to the user. Great for things like searches, filtering, loading, and error messages.
