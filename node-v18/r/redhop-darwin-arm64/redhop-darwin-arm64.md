# redhop-darwin-arm64

> 标签: context, embeddings, llm, nlp, rag, retrieval

## 简介

Reasoning-aware context runtime for RAG — chunk, retrieve, and allocate document context, with citations and a Decision Report. No vector DB, in-process.
