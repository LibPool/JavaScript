# rgb-led-matrix

> 标签: blinkstick, firmata, i2c, led, matrix, neopixel, rgb

## 简介

Universal RGB Matrix controller for Node.js. Supports realtime frame streaming (eg. Ambilight). BlinkStick RGB LED controller given as example.
