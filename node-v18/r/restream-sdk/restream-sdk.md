# restream-sdk

> 标签: kick, multistream, react, restream, sdk, streaming, twitch, youtube

## 简介

Plug-and-play headless React hooks to add multi-platform restreaming (connect socials, go live, live chat + viewers, collaborative split-screen) with zero client backend.
