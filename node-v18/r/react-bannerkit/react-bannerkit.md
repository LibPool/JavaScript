# react-bannerkit

> 标签: banner, banner-builder, carousel, page-builder, react, shadcn, template-editor, visual-editor

## 简介

A visual banner template builder and renderer for React. Split banners into panels, fill them with content, tune three independent breakpoints, and ship the result with a self-contained renderer.
