# react-native-location-notification-permissions

> 标签: authorization, permissions, react native, react-native, react-permissions

## 简介

This is a fork from react-native-community/react-native-permissions. It uses just location and notification permissions, so we can avoid Apple's reject for the unnecessary permissions on iOS
