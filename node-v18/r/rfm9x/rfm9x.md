# rfm9x

> 标签: adafruit, iot, lora, raspberry, rfm95, rfm96, rfm97, rfm98, rfm9x, rpi, sx127x, wireless

## 简介

Node.js module for SPI communication with RFM9x wireless modules on Raspberry Pi (e.g. Adafruit Radio Bonnet)
