# recalld

> 标签: claude-code, coding-agents, embeddings, local-first, mcp, memory, sqlite-vec

## 简介

Local-first cross-agent memory for coding agents. Captures your Claude Code sessions, embeds them on your machine, and auto-injects relevant past context into new sessions. No cloud, no account, no API key.
