# react-native-app-usage-stats

> 标签: android, app-usage, digital-wellbeing, foreground-time, ios, react-native, screen-time, usage-stats

## 简介

React Native module for querying per-app foreground usage time on Android. iOS returns a graceful NOT_SUPPORTED error.
