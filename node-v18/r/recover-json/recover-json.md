# recover-json

> 标签: agent, extract, json, llm, markdown, openai, parse, prose, repair, structured-output

## 简介

Recover the JSON a model emitted from the prose it wrapped around it: fenced or bare, with braces inside strings, trailing commas, comments and single quotes.
