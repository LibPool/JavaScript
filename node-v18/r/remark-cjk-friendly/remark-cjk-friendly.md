# remark-cjk-friendly

> 标签: chinese, cjk, japanese, korean, markdown, mdast, remark, remark-plugin, unified

## 简介

remark plugin to make Markdown emphasis (`**`) in CommonMark (and MDX) more friendly with Chinese, Japanese, and Korean (CJK)
