# rn-splash-util-tool

> 标签: launch image, launch-image, react-native, react-native-splash-generate, react-native-splash-image-generate, react-native-splash-images, splash screen, splash-images, splash-screen

## 简介

Easily generate splash/launch images for both iOS and Android with a single command. This tool creates all the required image sizes and automatically generates the Android launch_screen.xml file. Save time and simplify your splash screen setup for React N
