# reactive-agents

> 标签: a2a, agent-framework, agents, ai, ai-agents, autonomous-agents, effect-ts, guardrails, llm, mcp, model-context-protocol, multi-agent, observability, ollama, react-loop, reasoning, typescript

## 简介

A composable TypeScript framework for building reliable, custom LLM agents on a harness you fully control. The same code runs the full agent loop on every model tier — local 4B to frontier — with tool-call healing, output verification, and durable crash-r
