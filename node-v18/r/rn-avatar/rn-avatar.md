# rn-avatar

> 标签: android, animated, avatar, ios, react, react-component, react-native, react-native-animated-user-initials, react-native-avatar, react-native-component, react-native-user-avatar, react-user-avatar, rn-avatar, user-initials

## 简介

React Native Avatars can be used to represent people in a graphical way with support for falling back to using the user's initials on a colored background as the avatar if valid source is not present.
