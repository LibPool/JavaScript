# red-form

> 标签: checkbox, custom-fields, dialog, dropdown, dynamic-forms, form, form-builder, form-validation, formik, hooks, input, json-form, modal-form, react, react-component, react-library, schema, search, switch, tags, typesafe, typescript, ui, validation

## 简介

A powerful, type-safe React form library that lets you create dynamic dialog-based forms using schema definitions — inspired by Formik but designed for real-time UI rendering and reusability.
