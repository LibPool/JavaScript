# ref-wchar-napi-lite

> 标签: abi, c, c++, ffi, ref, string, type, wchar, wchar_t, wide

## 简介

A ref "type" implementation of `wchar_t *` (a.k.a. wide string) backed by "iconv-lite". Supports Node 16+.
