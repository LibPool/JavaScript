# react-setup-pro

> 标签: cli, react, setup, starter, tailwind, template, vite

## 简介

React + Tailwind + Firebase + Axios starter setup by Mysterio. Don't use npm i react-setup-pro, it will only install the dependencies. Use 'npx react-setup-pro <project-name>' to create a new project.
