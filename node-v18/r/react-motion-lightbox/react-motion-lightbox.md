# react-motion-lightbox

> 标签: animation, carousel, dialog, framer-motion, gallery, image-gallery, image-viewer, lightbox, modal, motion, photo-gallery, pinch-zoom, react, react-component, react-lightbox, slider, swipe, thumbnails, typescript, zoom

## 简介

A React lightbox and image gallery that opens out of the photo you click and closes back into it: swipe, pinch and wheel zoom, thumbnails, video, focus-point crops. Built on Motion.
