# rm-element

> 标签: JavaScript

## 简介

rm 的 模仿element实现的简易组件库 实现了如下组件 1. myalert 2. myinput 3. mylink 4. mybutton 5. myform 6. myformitem 7. myswitch 8. mydialog 9. mymessage
