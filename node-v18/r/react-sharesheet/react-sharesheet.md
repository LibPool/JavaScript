# react-sharesheet

> 标签: drawer, headless, mobile-first, native-share, og-preview, open-graph, react, share, share-sheet, sharesheet, social, tailwind, telegram, twitter, web-share-api, whatsapp

## 简介

A mobile-first share sheet for React with native share support, Open Graph previews, 15+ social platforms, and headless APIs. Tailwind-styled by default, fully customizable.
