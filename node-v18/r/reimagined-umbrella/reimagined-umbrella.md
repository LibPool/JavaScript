# reimagined-umbrella

> 标签: bitcoin, coinbase, cryptocurrency, defi, ethereum, influxdb, nodejs

## 简介

A simple Node.js® project that subscribes to the Coinbase WebSocket API and streams ticker data into InfluxDB.
