# reference-path

> 标签: circular, cyclic, json, object, path, reference, serialize

## 简介

Transform repeated references (including circular references) in JavaScript object structures into dot-separated path strings. 将 JavaScript 对象结构中重复出现的引用（包括循环引用）转换为以点分隔的路径字符串。
