# react-zustand-form

> 标签: react, react-zustand-form, typescript

## 简介

Concurrent-safe, user-first form state for React 18/19 powered by Zustand. Supports uncontrolled or controlled fields, coalesced server updates (dirty-first), async validation, and a tiny vanilla store.
