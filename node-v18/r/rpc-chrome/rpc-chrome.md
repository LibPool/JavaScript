# rpc-chrome

> 标签: chrome, chrome-communication, chrome-extension, chrome-messaging, extension, messaging, rpc, typed-messaging, typescript

## 简介

A simple library for typed messaging between different parts of a Chrome extension (background script, content script, popup, etc.)
