# rabbitmq-common

> 标签: amqp, consumer, event-driven, message-queue, microservices, nodejs, producer, pubsub, queue, rabbitmq, typescript

## 简介

A TypeScript-first RabbitMQ utility for Node.js with reliable producer/consumer lifecycle management and topology-aware DLQ support.
