# richform

> 标签: JavaScript

## 简介

* richform表单组件     * 数据驱动     * 校验规则采用标准的JsonSchema,[JsonSchema文档](https://github.com/jingyuLin1999/richform/blob/main/JSON-Schema.md)     * 可拓展性，widgets下可自定义一些子组件 * 表单设计器      * 基于richform表单的拓展，可动态设计表单     * 表单设计所见即所得     * 可设置字段属性和校验规则 * 签核流程
