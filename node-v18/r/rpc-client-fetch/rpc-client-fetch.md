# rpc-client-fetch

> 标签: browser, client, fetch, http, node, react-native, rpc, scf, serverless, web

## 简介

A universal, zero-dependency RPC client based on Fetch API. 基于 Fetch API 的通用 RPC 客户端，适用于 Web、Node.js 和 React Native。
