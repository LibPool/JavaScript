# react-activity-keepalive-kit

> 标签: activity, cache, component-cache, keep-alive, keepalive, lru, react, react19, router-cache, tab-cache

## 简介

A KeepAlive component for React 19.2+ built on top of the official <Activity> API, with LRU/PRE cache strategies and an imperative ref API.
