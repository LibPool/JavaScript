# react-modal-back-button

> 标签: android, back button, back-button, browser-back, close-modal, dialog, dismiss, history, history-api, ios, mobile, mobile-ux, modal, modal-dialog, navigation, overlay, popstate, popup, pwa, react, react-hook, typescript, user-experience, ux, webview

## 简介

A lightweight React hook that enables native back button support for modals and dialogs. Press the back button to close modals instead of navigating away.
