# react-native-autofill-credentials

> 标签: android, autofill, credentials, ios, react-native, turbo-module

## 简介

System-wide autofill (Android AutofillService + iOS Credential Provider Extension, with TOTP support) for React Native apps, via a Turbo Native Module.
