# rosalana-dev

> 标签: cli, components, developer-tools, nuxt, rosalana, vue

## 简介

Rosalana-dev is a powerful CLI for effortlessly downloading and sharing composables, complete with pre-built components. It streamlines collaboration and reveals key functions used in Rosalana projects, enabling developers to contribute and innovate.
