# rect-observer

> 标签: IntersectionObserver, IntersectionObserver API, RectObserver, ResizeObserver, ResizeObserver API, UI, browser, change-detection, intersection-observer, rectangle, resize-observer, responsive-layout

## 简介

Executes a callback whenever the bounding rectangle of an element changes. It uses `IntersectionObserver` under the hood, eliminating the need for a polling loop.
