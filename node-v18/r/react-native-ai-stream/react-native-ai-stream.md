# react-native-ai-stream

> 标签: ai, ai-chat, anthropic, chat, chatbot, chatgpt, claude, event-stream, eventsource, expo, gemini, gpt, hooks, live-updates, llm, ndjson, ollama, openai, polling, react, react-native, react-native-sse, realtime, server-sent-events, sse, stream, streaming, text-streaming, token-streaming, typescript, usechat

## 简介

Stream AI responses and live updates in React Native. Server-Sent Events (SSE) and NDJSON with POST support, auto-reconnect, cancellation, and hooks for OpenAI, Anthropic and Ollama. A maintained EventSource alternative. Zero dependencies, works with Expo
