# rentbamboo-mcp

> 标签: agent, ai, crm, mcp, panda, pm, rentbamboo

## 简介

Stdio MCP bridge to the RentBamboo MCP server. Exposes the RentBamboo Panda tools (read-only) to any MCP-capable AI agent.
