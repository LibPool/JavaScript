# route-bridge

> 标签: api, client, codegen, contract, express, fetch, flask, nextjs, route-bridge, typescript

## 简介

route-bridge lets you define backend APIs once and automatically use them in frontend apps as simple function calls. It generates a typed client from a shared contract, removing fetch boilerplate and supporting Express, Flask, Next.js, and Node.js with cl
