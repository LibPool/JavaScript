# react-cal-kit

> 标签: calendar, drag-and-drop, event, fullcalendar-alternative, react, scheduler, timeline

## 简介

Zero-dependency React calendar component library with Month, TimeGrid, List, DayGrid, MultiMonth and Timeline views, event CRUD and drag & drop. Google Calendar-style theme.
