# random-seedable

> 标签: 128, 32, 64, LCG, Mersenne, PCG, Twister, Xorshift, Xorshift128, Xorshift128+, Xorshift64, Xorwow, bit, generator, number, numbers, plus, prng, pseudorandom, random, random-seedable, rng, seed, seedable

## 简介

Fully-fledged collection of both 32 and 64 bit seedable random number generators whose output precisely matches their original c/c++ implementations.
