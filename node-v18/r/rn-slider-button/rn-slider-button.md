> 标签: RnSlideButton, animated-button, button-animation, custom-button, draggable-button, gesture-button, interactive-button, react-native, react-native-components, react-native-slider, react-native-ui, react-native-ui-kit, rn-slide-button, rn-slider-button, slide-action, slide-button, slide-to-confirm, slider, sliding-component

## 简介

RnSlideButton is a customizable React Native component for implementing a sliding button. It features smooth animations and various customization options for the button’s appearance. It requires zero dependencies and works out of the box.
