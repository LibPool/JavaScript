# react-native-figma-shadow

> 标签: android, box-shadow, css, elevation, fabric, figma, ios, new-architecture, react-native, shadow

## 简介

Paste a CSS box-shadow from Figma and get a pixel-identical shadow on iOS and Android. New Architecture, zero peer dependencies.
