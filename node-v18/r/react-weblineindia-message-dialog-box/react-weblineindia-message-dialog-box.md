# react-weblineindia-message-dialog-box

> 标签: alertbox, message-dialog-box, react components, react-message-dialog-box, react-weblineindia-message-dialog-box, reactjs, reactjs component, reactjs-message-dialog-box

## 简介

ReactJS based MessageDialog component used for showing custom dialog with message. You can even change number of buttons on that. You can also hide header and cross icon.
