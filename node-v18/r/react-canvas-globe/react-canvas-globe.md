# react-canvas-globe

> 标签: canvas-globe, data-visualization, interactive-globe, no-webgl, react-canvas-globe, react-globe, world-map

## 简介

React component for interactive 3D globes and world maps rendered with Canvas 2D, powered by canvas-globe.
