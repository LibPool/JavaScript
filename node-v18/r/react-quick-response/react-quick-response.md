# react-quick-response

> 标签: generator, no-dependencies, png, qr, qr-code, qr-code-generator, qr-code-with-logo, qr-generator, qr-logo, qrcode, qrcode-react, react, react-qr-code, rounded-qr, ssr, svg, typescript

## 简介

Lightweight React QR code component — generate customizable QR codes as SVG with a centered logo overlay, dot/rounded module shapes, and zero runtime dependencies beyond quick-response-core.
