# react-native-gifted-touch

> 标签: android, click, double click, double press, double tap, ios, long click, long press, react-component, react-native, single click, single press, single tap, touch

## 简介

`RNGiftedTouch` is a react native component that allows to handle single, double and long presses on a single element effortlessly.
