# rm-copilot-chat

> 标签: angular, chat, copilot, ia, rm, streaming, totvs, widget

## 简介

Widget de chat com IA para Angular. Exibe um botão flutuante arrastável que abre um painel de conversa conectado à API do RM Copilot via streaming.
