# run-dj

> 标签: bpm, cadence, dj, playlist, running, shuffle, soma, spotify

## 简介

Pure core of Soma's running DJ: HR-to-BPM formula, anti-clustering shuffle, playlist scoring, the live queue decision, genre buckets, and the ReccoBeats and Spotify clients over injectable I/O.
