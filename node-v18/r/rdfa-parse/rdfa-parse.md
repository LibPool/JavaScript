# rdfa-parse

> 标签: browser, linked-data, n3, parser, rdf, rdfa, rdfjs, semantic-web, streaming, web-worker

## 简介

A lightweight, browser-native RDFa 1.1 parser with N3.js compatibility. Designed for web-workers and modern web applications without Node.js dependencies. Supports full RDFa Core 1.1 spec including CURIE expansion, vocabulary handling, and streaming quad
