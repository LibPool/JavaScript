# rundeck-job-proxy

> 标签: cd, ci, delivery, deployment, devops, github, gitlab, http, integration, proxy, rundeck

## 简介

Proxy server for Rundeck job executions. Converts the request's JSON payload to job arguments (e.g. Gitlab & Github)
