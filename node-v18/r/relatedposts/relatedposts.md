# relatedposts

> 标签: astro, blog, category matching, content recommendation, cosine similarity, embeddings, machine learning, nlp, related content, semantic search, string similarity, tag matching, text matching, text similarity

## 简介

A utility package to find related posts or blogs based on semantic similarity of titles, categories, and tags. Works with standard content objects and Astro blog collections.
