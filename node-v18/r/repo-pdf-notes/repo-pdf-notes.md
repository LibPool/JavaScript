# repo-pdf-notes

> 标签: cli, course, docs, documentation, ebook, github, markdown, notes, pdf, puppeteer, table-of-contents

## 简介

Convert any markdown-based GitHub repo into a beautifully formatted, navigable PDF with a cover page, clickable table of contents, and real page numbers.
