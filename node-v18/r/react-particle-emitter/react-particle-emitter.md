# react-particle-emitter

> 标签: animation, confetti, expo, particle-emitter, particles, physics, react-native, reanimated, skia

## 简介

Physics-based particle emitter for React Native, rendered with native Skia. A port of the Compose Multiplatform ParticleEmitter library.
