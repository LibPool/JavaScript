# retold-mcp

> 标签: agents, ai, mcp, meadow, model-context-protocol, rest, retold

## 简介

Serve any meadow-endpoints REST API to AI agents over the Model Context Protocol (stdio and streamable HTTP). Catalog-driven: knows MCP and meadow conventions, not any application's entities.
