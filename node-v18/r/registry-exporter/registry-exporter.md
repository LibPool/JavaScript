# registry-exporter

> 标签: JavaScript

## 简介

This cli was created to export metadata from the registry to a format consumable in a @shipengine/connect app.

## 官网

- 官网：https://connect.shipengine.com/
- 源码仓库：git+https://github.com/shipstation/integrations-platform.git
