# react-native-stage-sheet

> 标签: bottom-sheet, card-stack, expo, gesture, ios, modal, react-native, reanimated, sheet

## 简介

A draggable bottom sheet for React Native & Expo that recedes the parent screen into an iOS-style card stack behind it.
