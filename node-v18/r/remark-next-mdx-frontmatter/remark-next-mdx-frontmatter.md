# remark-next-mdx-frontmatter

> 标签: JavaScript

## 简介

This module allows you to use `Frontmatter` with [`@next/mdx`](https://nextjs.org/docs/advanced-features/using-mdx#nextmdx) which doesn't officially support frontmatter.
