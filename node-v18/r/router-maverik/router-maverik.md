# router-maverik

> 标签: alpine, alpinejs, hash, history-api, navigation, router, routing, seo, spa, vanilla

## 简介

Roteador de URLs limpas (History API) para Alpine.js e vanilla JS. Rotas indexáveis sem hash, com params, query e meta dinâmica.
