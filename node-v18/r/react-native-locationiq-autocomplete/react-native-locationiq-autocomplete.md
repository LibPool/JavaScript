# react-native-locationiq-autocomplete

> 标签: android, geocoder, geocoding, ios, locationiq, react-native

## 简介

A React Native module to transform geographic coordinates (latitude and longitude) into a description of a location (i.e. street address, town, city, country, etc.) and vice versa.
