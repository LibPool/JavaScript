# receipt-image-printer

> 标签: 80mm, arabic, chinese, escpos, image, multilingual, pos, printer, receipt, thermal, turkish

## 简介

Convert receipts to images for thermal printers - supports any language including Arabic, Chinese, Turkish, etc. via image rendering
