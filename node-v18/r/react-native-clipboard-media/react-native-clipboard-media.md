# react-native-clipboard-media

> 标签: android, audio, clipboard, copy, file, image, ios, media, paste, pdf, react-native, video

## 简介

A React Native library for copying various media types (text, images, videos, PDFs, audio, files) to the clipboard on both iOS and Android
