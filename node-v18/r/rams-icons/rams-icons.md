# rams-icons

> 标签: JavaScript

## 简介

1. Download svg files that you need and import it in svg file 2. Create your own new config(you can dublicate some of them) 3. Make sure that you changed all fill, stroke, color values to currentColor, or you can add the colors that you met on your svg fi
