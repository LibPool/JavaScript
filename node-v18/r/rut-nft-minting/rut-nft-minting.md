# rut-nft-minting

> 标签: JavaScript

## 简介

本指南将引导您如何使用 Ethereum 和 Next.js 建立一个全栈的 NFT Minting dApp。该项目使用 Solidity 编写智能合约，并用 React 和 TailwindCSS 构建前端界面。
