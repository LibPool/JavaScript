# read-file-yaml

> 标签: file, filesystem, fs, lib, library, loader, promise, read-file, read-yaml, util, utility, yaml, yaml-parser, yml, yml-parser

## 简介

Reads YAML 1.2 from a file. Returns null if file does not exist (or is a directory) instead of throwing an Error.
