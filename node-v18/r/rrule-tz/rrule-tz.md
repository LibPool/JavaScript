# rrule-tz

> 标签: calendar, dst, icalendar, recurrence, recurring-events, rfc5545, rrule, scheduling, timezone, typescript

## 简介

Timezone-safe wrapper around rrule — true-UTC occurrence queries, independent of the host machine's timezone.
