# react-native-screenshot-shield

> 标签: android, fabric, flag-secure, ios, privacy, react-native, screen-capture, screen-recording, screenshot, screenshot-prevent, secure-view, security, turbomodule

## 简介

Prevent screenshots & screen recording in React Native (iOS + Android). Fixes the iOS secure-view bug that shrinks the React Navigation bottom tab bar. Supports both the old bridge and the new architecture (Fabric/TurboModules).
