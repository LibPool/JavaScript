# react-native-anydoc

> 标签: converter, doc, document, docx, epub, nitro, odt, pptx, react-native, rtf, rust, xlsx

## 简介

Any office document (docx, doc, pptx, xlsx, odt, rtf, epub…) to a structured DocumentIR, converted natively in Rust, off the JS thread
