# rjx

> 标签: React, jamstack, json, json jsx, json-react, jsx, jsx-json, react-json, react-json-schema, reactive, rjx, server-side-react

## 简介

React JSON Syntax - Construct React elements, JSX and HTML with JSON without transpilers. RJX support React Function and Class Components, React Lazy and Suspense Content, and full support for React Hooks
