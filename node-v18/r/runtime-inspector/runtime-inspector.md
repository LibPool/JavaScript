# runtime-inspector

> 标签: ai-agents, cli, dashboard, developer-tools, inspector, localhost, observability, process, runtime, terminal

## 简介

Local-first runtime inspection tool for developers. Scans processes, groups them into sessions, and serves a real-time dashboard on localhost.
