# remzi-bot

> 标签: JavaScript

## 简介

- Responds to /i /t with images -->  `/i hello guys` - Responds to /w with the first wikipedia entry it finds --> `/w mozart` - Responds to `gunaydin` and its variations with a good morning message (once per day)
