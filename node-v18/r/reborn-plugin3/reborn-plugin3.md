## 简介

유료로 내던 것을 무료로 갈아 끼우는 클로드 코드 스킬 셋. free-for-dev(무료 티어 목록 1,311개) · public-apis(무료 API 1,770개 · 52분야) · Scrapling(Cloudflare Turnstile 우회 스크래핑) 세 오픈소스를 클로드가 실제로 쓰게 만든다. 남의 목록을 패키지에 베껴 넣지 않고 쓸 때마다 원본을 받는다.
