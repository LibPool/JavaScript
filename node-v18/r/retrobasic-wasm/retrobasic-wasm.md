# retrobasic-wasm

> 标签: basic, emulator, interpreter, lex, ms-basic, retro, retrobasic, wasm, webassembly, yacc

## 简介

Run classic BASIC programs in Node.js and the browser, powered by a WebAssembly build of the RetroBASIC interpreter.
