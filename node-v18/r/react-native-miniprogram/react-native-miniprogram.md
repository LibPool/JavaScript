# react-native-miniprogram

> 标签: miniapp, react, react-component, react-native, weapp, wechat-miniprogram

## 简介

React Native for WeChat Mini Program (and compatible mini-app platforms). Port the React Native component/API surface to the Mini Program host, inspired by react-native-web.
