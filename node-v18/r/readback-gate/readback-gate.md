# readback-gate

> 标签: ai, ai-agent, claude-code, cli, codex, coding-agent, developer-tools, guardrail, hook, prompt, prompt-engineering

## 简介

Coding agents read back what they understood, before they act on it. A runtime prompt gate for AI coding agents.
