# redux-local-enhancer

> 标签: local, react, redux

## 简介

Create virtual local stores from redux root store, you can use virtual stores as usual, virtual store support all existing redux middlewares, the action dispatched from a virtual store won't influence the other virtual stores, so this is a great solution
