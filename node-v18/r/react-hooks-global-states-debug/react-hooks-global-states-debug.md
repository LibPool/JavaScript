# react-hooks-global-states-debug

> 标签: debug, development, devtools, global-state, global-states, hooks, react, react-global-state-hooks, react-hooks-global-states

## 简介

DevTools debug package for react-hooks-global-states (and react-global-state-hooks). Side-effect import that connects your global stores to the React Global States Hooks DevTools browser extension.
