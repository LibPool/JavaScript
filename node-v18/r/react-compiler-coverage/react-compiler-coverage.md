# react-compiler-coverage

> 标签: babel, ci, coverage, memoization, performance, react, react-compiler, regression

## 简介

Coverage reporting and a CI regression gate for the React Compiler. See which components are actually optimized, silently unoptimized, opted out, or erroring.
