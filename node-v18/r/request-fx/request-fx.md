# request-fx

> 标签: JavaScript

## 简介

request-fx,Request Framework 是基于request二次开发封装的http请求模块，使用typescript进行封装，一般来说 只要传入url,即可拿到返回值并在回调中对返回值进行自定义的处理，说起来好像更传统的request模块没有太大的区别，那区别在哪呢， 各位看官没想错，确实就是省略了一些无关回调参数，并对原始的返回值进行了Json.Parse，awsl,对不起，可能异常处理也是有风险的， 不过request-fx毕竟是初次迭代，陆续必定会解决这些问题，敬请期待，如可
