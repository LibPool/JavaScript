# re-phoenix

> 标签: BuckleScript

## 简介

Hello! These are basic ReasonML bindings for the [Phoenix JS library](https://hexdocs.pm/phoenix/js/). Most of the library already has bindings and I hope to cover the lacking functions ASAP.
