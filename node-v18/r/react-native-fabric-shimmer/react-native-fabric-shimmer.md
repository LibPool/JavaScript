# react-native-fabric-shimmer

> 标签: fabric, loading, react-native, reanimated, shimmer, skeleton

## 简介

Dynamic shimmer skeletons for React Native — wraps the real component, measures at runtime via Fabric JSI, paints shimmer at exact positions.
