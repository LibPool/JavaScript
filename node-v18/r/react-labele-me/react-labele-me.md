# react-labele-me

> 标签: annotation, canvas, computer-vision, image-annotation, image-labeling, konva, react

## 简介

一个基于 React + Konva.js 的图像标注库，专门为图像标注场景打造。支持矩形/圆形标注、涂鸦/马赛克、撤销重做、缩放旋转等功能。
