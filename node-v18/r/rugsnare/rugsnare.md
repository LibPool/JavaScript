# rugsnare

> 标签: ai-agents, audit, ci, gateway, integrity, mcp, model-context-protocol, rug-pull, security, supply-chain, tool-poisoning

## 简介

Runtime integrity gateway for AI agents: pin MCP tool descriptions, snare rug-pulls and drift, log every tool call.
