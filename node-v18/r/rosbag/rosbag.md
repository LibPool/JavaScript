# rosbag

> 标签: JavaScript

## 简介

`rosbag` is a node.js & browser compatible module for reading [rosbag](http://wiki.ros.org/rosbag) binary data files.

- 官网：https://github.com/cruise-automation/rosbag.js
- 源码仓库：git+https://github.com/cruise-automation/rosbag.js.git
