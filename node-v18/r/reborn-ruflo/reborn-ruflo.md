# reborn-ruflo

> 标签: agent-harness, agent-swarm, claude, claude-code, claude-flow, korean, mcp, multi-agent, orchestration, ruflo

## 简介

ruflo(옛 claude-flow · ruvnet · MIT · 별 71.7k)를 쓰기 전에 무엇이 막는지 알려 주는 안내 스킬입니다. --check 가 이 컴퓨터에서 다섯 가지(노드 20+ · 클로드 코드 · 설치 경로 · MCP 등록 · 모델 값)를 실제로 재 줍니다. 가장 많이 틀리는 자리는 설치 경로입니다 — 플러그인으로 깔면 슬래시 명령만 오고 훅·MCP·데몬이 안 옵니다. 저장소 코드는 담지 않습니다.
