# react-viz-composer

> 标签: 2d, canvas, chart, charts, data-visualization, dataviz, declarative, graph, react, react-charts, react-components, renderer, svg, visualization

## 简介

Declarative SVG/Canvas hybrid rendering engine. Compose visualizations from Rect, Ellipse, Line, Path, Text, Image, Group, Animation primitives, plus Axis/Grid/Tooltip helpers.
