# roll-parser

> 标签: d20, dice, dice notation, dice-notation, dice-parser, dice-roller, die, dnd, notation, parser, pathfinder, roll, roller, rpg, tabletop, ttrpg

## 简介

Dice notation parser and roller for tabletop RPGs — D&D 5e, Pathfinder, Fate. Typed results, seeded rolls, zero dependencies. TypeScript, Node, Bun, browser.
