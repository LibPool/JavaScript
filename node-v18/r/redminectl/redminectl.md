# redminectl

> 标签: ai-agent, cli, issue-tracker, project-management, redmine

## 简介

AI Agent friendly Redmine CLI tool. This npm package is named 'redminectl' because 'redmine' was already taken on npm. The installed binary is still 'redmine'.
