# randomuuid

> 标签: guid, rfc4122, uuid

## 简介

Stub project for polyfilling `randomUUID` as proposed for standardization in https://github.com/WICG/uuid and implemented in Node.js v15.6.0 https://github.com/nodejs/node/pull/36729
