# react-native-advanced-checkbox

> 标签: accessibility, advanced-checkbox, animation, checkbox, group-checkbox, haptic, react-native, react-native-advanced-checkbox, react-native-checkbox

## 简介

Customizable, animated checkbox component for React Native with group support, haptic feedback, and accessibility features, compatible with React Native 0.72.0 and above.
