# react-native-scrollable-tab-view-universal

> 标签: ios, react-component, react-native, react-native-component, scrollable, tab

## 简介

I need `react-native-scrollable-tab-view` to be placed inside a ScrollView, for both iOS and Android (thus the name). It didn't work on Android because of ViewPagerAndroid. So, I modified the code and make the code the sama for both iOS and Android.
