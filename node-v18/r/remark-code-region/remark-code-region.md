# remark-code-region

> 标签: astro, code-blocks, code-import, code-region, documentation, docusaurus, markdown, remark, remark-plugin, snippets, tested-code, unified

## 简介

Every code block in your docs is extracted from a passing test. Pull tested code from your test suite into Docusaurus, Astro, or any remark-powered docs.
