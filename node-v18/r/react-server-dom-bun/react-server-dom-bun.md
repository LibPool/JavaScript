# react-server-dom-bun

> 标签: JavaScript

## 简介

React Server Components bindings for DOM using Bun. This is intended to be integrated into meta-frameworks. It is not intended to be imported directly.

## 官网

- 官网：https://react.dev/
- 源码仓库：https://github.com/facebook/react.git
- npm 页面：https://www.npmjs.com/package/react-server-dom-bun
