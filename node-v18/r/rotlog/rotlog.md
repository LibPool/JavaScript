# rotlog

> 标签: bun, ffi, gcs, gzip, log-rotation, logger, logging, logrotate, request-logging, rust

## 简介

Fast rotating logger for Bun (Rust core via bun:ffi): time/size rotation, gzip, Google Cloud Storage upload, request logging, rotlog CLI
