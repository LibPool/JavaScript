# rhodochrosite

> 标签: generator, inline, markdown, metalsmith, site, ssg, static, tags, website

## 简介

wrapper around a static site generator called metalsmith, adding neat mind-mapping features including inline hashtags and automatic tag pages. also utility features like image minification, gallery pages and pre-configured rss/atom feeds. written in types
