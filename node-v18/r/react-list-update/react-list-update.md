# react-list-update

> 标签: axios, crud, fetch, react, update

## 简介

<p>It's a function build for react, but it can be use with others frameworks or even typecript/javascript vanila.</p> <p> This package will help you to update your states (array of objects only) after request (post, put or delete), without a new request
