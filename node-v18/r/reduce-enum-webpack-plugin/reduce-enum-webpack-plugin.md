# reduce-enum-webpack-plugin

> 标签: enum, node, plugin, reduce enum, typescript, webpack

## 简介

将ts enum 转 js 的产物减少一半，e[e['xxx']=0]='xxx'] => e['xxx']=0,e[e.xxx=0]='xxx' => e.xxx=0
