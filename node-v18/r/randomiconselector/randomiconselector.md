# randomiconselector

> 标签: JavaScript

## 简介

Let's you select a pool of random icons or choose one from every icon Use `Rightclick` on icons to add them to the random pool or remove them Use `Leftclick` on the Random button to select a random icon from the pool Use `Rightclick` on the Random butt
