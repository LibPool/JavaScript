# rpc-bastion

> 标签: JavaScript

## 简介

RPC Bastion — one-line install for the Solana RPC & transaction resilience SDK. Re-exports the @rpc-bastion/* runtime libraries (core, fees, sender, wallet, observability); chaos testkit under the ./testkit subpath.
