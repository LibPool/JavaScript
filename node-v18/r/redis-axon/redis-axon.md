# redis-axon

> 标签: backoff, circuit-breaker, cluster, connection-pool, ioredis, reconnection, redis, resilient

## 简介

A resilient Redis client with circuit breaker, connection pooling, cluster support, and automatic reconnection with exponential backoff.
