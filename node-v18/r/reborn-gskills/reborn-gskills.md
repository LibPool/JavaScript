# reborn-gskills

> 标签: agent-skills, claude, claude-code, gemini, google, google-ads, google-analytics, google-cloud, korean, oauth

## 简介

google/skills(구글 공식 Agent Skills · Apache-2.0 · 별 19.5k · 스킬 131개)를 쓰기 전에 무엇이 막는지 알려 주는 안내 스킬입니다. --check 가 이 컴퓨터에서 다섯 가지(Node 18+ · 스킬이 심겼나 · gcloud CLI · client_secrets.json · OAuth 자격 5종)를 실제로 재 줍니다. 심는 건 명령 한 줄이지만 API 를 실제로 부르려면 인증 파라미터가 다섯 개 더 필요합니다.
