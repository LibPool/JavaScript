# redirect-chain-checker

> 标签: 301, 302, cli, frostrank, http, redirect, redirect-chain, seo

## 简介

CLI tool to trace the full HTTP redirect chain of a URL, flagging mixed 301/302 chains and long redirect hops. By FrostRank.
