# re-exp

> 标签: backend, cli, command-line tool, export, file generation, frontend, index file, javascript, jsx, module index, module management, node, re-export, tsx, typescript

## 简介

Creates an index file (.js, .ts, .jsx, .tsx) in a directory and re-exports variables from modules within that directory.
