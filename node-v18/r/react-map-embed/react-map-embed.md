# react-map-embed

> 标签: embed, geocoding, google-maps, leaflet, map, maps, nextjs, openstreetmap, react

## 简介

Embed interactive maps in React and Next.js without a Google Maps API key. Leaflet + OpenStreetMap by default, with an optional Google Maps Embed provider.
