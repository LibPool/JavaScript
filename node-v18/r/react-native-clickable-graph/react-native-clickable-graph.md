# react-native-clickable-graph

> 标签: area, bar, chart, charts, donut, graph, line, pie, react-native

## 简介

The most complete library for Bar, Line, Area, Pie, Donut and Stacked Bar charts in React Native. Allows 2D, 3D, gradient, animations and live data updates, also forks added long press on bar graph and line reference on bar chart original author Abhinanda
