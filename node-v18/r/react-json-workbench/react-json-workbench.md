# react-json-workbench

> 标签: codemirror, developer-tools, json, json-editor, json-tree, json-viewer, react, typescript

## 简介

A lightweight, extensible JSON viewer and editor for React with tree inspection, CodeMirror editing, contextual actions, formatting, and theming.
