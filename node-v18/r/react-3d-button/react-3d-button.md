# react-3d-button

> 标签: 3d, 3d-button, awesome-button, button, component, customizable, interactive, nextjs, react, react-component, switch, tactile, themes, toggle, toggle-button, toggle-switch, typescript, ui

## 简介

A beautiful, customizable 3D button component for React with Next.js support, toggle mode, multiple themes, and easy CSS variable customization. Built on top of react-awesome-button with enhanced mobile touch support and Next.js compatibility.
