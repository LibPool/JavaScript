# react-sql-report-builder

> 标签: csv, docx, excel, express, pdf, react, report-builder, reporting, sql

## 简介

Pluggable SQL reporting toolkit: an Express router for connections/report definitions/paginated queries + CSV/Excel/PDF/Word export, plus ready-made React components for the UI.
