# react-native-pro-camera

> 标签: android, camera, camerax, gallery, pro-camera, react-native

## 简介

An elegant, high-performance camera library for React Native powered by CameraX and AVFoundation. Features zero-config installation, automatic permissions, native tap-to-focus, flash toggle, grid overlays, and instantaneous photo capture.
