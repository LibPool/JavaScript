# rowstore

> 标签: adaptive, auto-index, collection, database, in-memory, index, lokijs, query, selectivity, typescript

## 简介

An in-memory row store that decides its own indexes by watching the queries you actually run. No index declarations, no configuration: it counts predicate shapes, builds an index the moment the arithmetic says it pays, maintains it incrementally through m
