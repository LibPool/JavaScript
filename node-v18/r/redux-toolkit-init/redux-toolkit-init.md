# redux-toolkit-init

> 标签: boilerplate, formik, react, redux-toolkit, scaffold, tailwindcss, vite, yup

## 简介

Personal Vite + React scaffolding CLI — auth flow, redux toolkit, protected/public routes, dynamic formik+yup forms, axios, toastify, tailwind. Only touches its own managed files; self-removes from package.json after setup.
