# react-native-battery-optimization-check

> 标签: IGNORE_BATTERY_OPTIMIZATION_SETTINGS, REQUEST_IGNORE_BATTERY_OPTIMIZATIONS, android, battery, battery optimization, battery optimization check, check, doze, optimization, react-component, react-native, react-native-battery-optimization-check, standby, wakelock

## 简介

A react-native solution to check if your app runs under battery optimization on Android devices and makes it easy for the user to disable it.
