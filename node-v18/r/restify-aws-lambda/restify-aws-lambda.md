# restify-aws-lambda

> 标签: aws, dynamoDB, function, lambda, lambda-local, local-dynamo, restified, restify, serverless

## 简介

Restified aws lambda function using TypeScript, reflect-metadata, dynamoDb, lambda-local, local-dynamo, decorators in jax-rs, spring @RestCrontroller style
