# resume-scorer-mcp

> 标签: anthropic, ats, claude, evaluation, hiring, mcp, model-context-protocol, resume, scoring

## 简介

MCP server that scores a structured resume against a deterministic 4-category engineering rubric (open source, self projects, production, technical skills). Returns category scores, evidence, bonuses, deductions, key strengths, and areas for improvement.
