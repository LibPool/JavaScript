> 标签: angular, boilerplate, build, bundling, cli, cross-platform, deno, desktop, desktop-app, generator, package, renweb, renweb-cli, scaffold, scaffolding, starter, template, vite, webview

## 简介

CLI tool for scaffolding, building, running, and packaging RenWeb desktop apps. Supports Angular, Vite, Deno, and vanilla project templates.
