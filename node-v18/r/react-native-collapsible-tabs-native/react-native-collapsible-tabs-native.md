# react-native-collapsible-tabs-native

> 标签: android, collapsible, collapsible-tab-view, collapsible-tabs, collapsing-header, fabric, flash-list, ios, new-architecture, profile-header, react-native, sticky-header, sticky-tab-bar, tab-view, tabs, uiscrollview, viewpager2

## 简介

Native collapsible tabs for React Native (Fabric): collapsing header + pinned tab bar over a native pager, driven by UIKit/ViewPager2 so header and list move in the same frame.
