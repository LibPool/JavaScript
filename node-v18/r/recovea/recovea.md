# recovea

> 标签: ai, anthropic, attribution, baseline, cost, llm, openai, passive-tap, recovea, tokens, usage

## 简介

The Baseline package (the passive tap): one line beside the OpenAI or Anthropic client you already use reports each call's envelope — never a prompt, never a completion, never a provider key — to your Recovea Baseline.
