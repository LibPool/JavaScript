# react-native-device-corners

> 标签: concentric, corner-radius, device, display, react-native, rounded-corners, safe-area, screen, squircle, windowinsets

## 简介

Read the physical corner radius of the device's display in React Native. Returns the real per-corner values on Android 12+ via the OS WindowInsets API, with a sensible fallback everywhere else.
