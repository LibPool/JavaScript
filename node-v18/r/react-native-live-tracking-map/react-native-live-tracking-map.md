# react-native-live-tracking-map

> 标签: delivery-tracking, directions, driver-tracking, geolocation, google-directions, google-maps-api-key-setup, live-tracking, map, mapbox, navigation, react-native, react-native-maps, routing, traffic

## 简介

Drop-in live tracking map for React Native — customer side (watch a moving partner) and driver side (device GPS, compass heading, follow camera, throttled location reporting, arrival + off-route detection) in one component. Includes automatic Android Goog
