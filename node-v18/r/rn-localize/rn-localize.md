# rn-localize

> 标签: android, ast, automation, babel, cli, codemods, developer-tools, extract-strings, i18n, i18next, internationalization, ios, l10n, localization, parser, react native, react-i18next, react-native, react-native-localization, react-native-localize, rn-localize, translation, typescript

## 简介

Auto-extract hardcoded strings from React Native projects for localization. A zero-config CLI that parses your AST, generates translation keys, and rewrites your source code.
