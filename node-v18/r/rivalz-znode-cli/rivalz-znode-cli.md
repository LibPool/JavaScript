# rivalz-znode-cli

> 标签: rivalz, rivalz-znode, znode

## 简介

This project is a Node.js application that uses various libraries and frameworks such as `axios`, `ioredis`, `node-machine-id`, `commander`, `ethers`, `croner`, and `mindee`.
