> 标签: declarative, effects, led, led board, led matrix, leds, polygons, raspberry pi, raspberrypi, rgb led matrix, rgb matrix, rpi, rpi-led-matrix-painter, typescript

## 简介

Add drawing facilities to rpi-led-matrix. Manage sections of the board independently, draw shapes, text, and images.
