# retic-react-snapsheet

> 标签: bottom-sheet, dialog, drawer, modal, react, snap-sheet

## 简介

Drawer/snap-sheet component for React — a patched fork of vaul that dismisses cleanly from a snap point (no pop-back-up on swipe-to-close).
