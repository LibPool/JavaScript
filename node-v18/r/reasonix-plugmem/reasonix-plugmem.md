# reasonix-plugmem

> 标签: agent-memory, long-term-memory, mcp, memory, plugmem, reasonix, sqlite

## 简介

PlugMem MCP Server — SQLite-backed memory graph with 15 tools for LLM agents. Supports semantic, procedural, and episodic memory with BM25+Token+RRF hybrid search.
