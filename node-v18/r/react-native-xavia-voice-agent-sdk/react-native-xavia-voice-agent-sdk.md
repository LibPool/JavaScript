# react-native-xavia-voice-agent-sdk

> 标签: audio, call, react-native, sip, voice, voice-agent, voip, webrtc, xavia

## 简介

Headless React Native SDK for SIP-based voice agents. Zero UI, pure functionality. Supports multiple independent agent instances with WebRTC audio.
