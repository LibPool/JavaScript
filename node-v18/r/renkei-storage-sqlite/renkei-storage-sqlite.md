# renkei-storage-sqlite

> 标签: JavaScript

## 简介

SQLite storage for renkei. Zero dependencies on Node 22.13+ (built-in node:sqlite); better-sqlite3 and Bun via a 3-method driver interface; Cloudflare D1 via renkei-storage-sqlite/d1.
