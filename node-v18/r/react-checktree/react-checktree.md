> 标签: checkbox, checkbox-tree, checktree, hierarchical, lightweight, menu-tree, nested-tree, react, react-checkbox-menu-tree, react-component, recursive, rtl, searchable, tree, tree-menu, treeview

## 简介

A lightweight, zero-dependency React tree menu component with hierarchical checkboxes, search, RTL/LTR support, and custom theming via CSS variables.
