# react-tailwind-click-frame-animation

> 标签: animation, click-animation, component, frame-animation, mouse-events, react, tailwind, tailwindcss, ui

## 简介

A lightweight, customizable React frame-by-frame animation component for mouse events (click, context menu, drag, and scroll) styled with Tailwind CSS.
