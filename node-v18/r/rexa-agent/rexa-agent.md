# rexa-agent

> 标签: agent-harness, ai-agent, autonomous-coding, bun, cli, developer-tools, gemini, guardrails, rexa, sandboxing

## 简介

REXA — a general-purpose, single-agent development harness that understands tasks, gathers context, plans solutions, writes code, runs checks, and reports results through one continuous conversation.
