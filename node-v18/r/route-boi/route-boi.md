# route-boi

> 标签: client-side-routing, dynamic-routing, lightweight-routing, programmatic-navigation, react, react-hooks, react-navigation, react-router, router, routing

## 简介

A small and easy-to-use routing library for React, inspired by React Router DOM. Built from scratch to help you understand how client-side routing really works under the hood.
