# react-mobile-keyboard-opener

> 标签: android, click, focus, hook, input, ios, keyboard, mobile, react, react-component, react-hook, safari, soft-keyboard, touch, trigger, user-gesture, virtual-keyboard

## 简介

React hook and component to focus an input and trigger the mobile on-screen keyboard (iOS Safari, Android Chrome) from a click on another element.
