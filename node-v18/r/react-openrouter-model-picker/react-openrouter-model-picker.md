# react-openrouter-model-picker

> 标签: combobox, llm, model-picker, openrouter, pricing, react, select

## 简介

Searchable React picker over every OpenRouter model, with live USD-per-1M-token prices, vendor filter, sorting and keyboard navigation. No Tailwind or state library required.
