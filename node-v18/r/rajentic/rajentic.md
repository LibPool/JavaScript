# rajentic

> 标签: agent, agent-sdk, ai, anthropic, gemini, llm, openai, tools, typescript

## 简介

A from-scratch, provider-agnostic TypeScript SDK for building tool-using AI agents — with handoffs, guardrails, sessions, structured output, streaming, and tracing built in.
