# read-file-json

> 标签: file, filesystem, fs, json, json-parser, json5, json5-parser, lib, library, load-file, loader, promise, read-file, util, utility

## 简介

Reads JSON and JSON5 from a file. Returns null if file does not exist (or is a directory) instead of throwing an Error.
