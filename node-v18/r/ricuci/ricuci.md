# ricuci

> 标签: cli, converter, dst, embroidery, exp, hus, jef, pec, pes, pyembroidery, sewing, stitch, vip, vp3, zhs

## 简介

Universal embroidery file converter (VIP, ZHS, PES, DST, JEF, VP3, HUS, EXP and more) — 100% local. Run with: npx ricuci in.vip out.zhs
