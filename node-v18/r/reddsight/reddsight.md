# reddsight

> 标签: bitcore, blockchain, blockexplorer, front-end, insight, reddcoin

## 简介

An open-source frontend for the Reddsight API. The Reddsight API provides you with a convenient, powerful and simple way to query and broadcast data on the Reddcoin network and build your own services with it.
