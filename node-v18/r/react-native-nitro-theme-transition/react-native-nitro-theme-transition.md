# react-native-nitro-theme-transition

> 标签: android, animation, circular-reveal, dark-mode, ios, nitro, nitro-modules, react-native, theme, transition, unistyles

## 简介

GPU-driven theme-change transitions for React Native — sixteen effects including circular reveal, iris, wipe, split, blinds, blur, Liquid Glass, pixelize, dissolve, ripple and shatter, without Skia, Reanimated or any JS animation library.
