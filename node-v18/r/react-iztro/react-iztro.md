# react-iztro

> 标签: astrolabe, astrology, horoscope, iztro, ziweidoushu, 紫微斗数

## 简介

基于iztro实现的react紫微斗数星盘组件。A react component used to generate an astrolabe of ziweidoushu based on iztro.
