# repolar-parse

> 标签: bear app, polar bear, repolar

## 简介

Parser for [**unified**][unified]. Parses [Polar Bear markup language](https://bear.app/faq/Markup%20:%20Markdown/Polar%20Bear%20markup%20language/) to an [**MDAST**][mdast] syntax tree.
