# react-specter

> 标签: ai, babel-plugin, claude-code, click-to-edit, devtools, inspector, mcp, nextjs, react, select-to-edit, vite-plugin, webpack-loader

## 简介

Select-to-edit for React apps: click an element in your running dev app, describe the change in plain language, and your AI coding agent edits the real source file.
