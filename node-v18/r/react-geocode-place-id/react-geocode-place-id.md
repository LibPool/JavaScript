# react-geocode-place-id

> 标签: geocode, geocoder, geocoding, google

## 简介

A module to transform a description of a location (i.e. street address, town name, etc.) into geographic coordinates (i.e. latitude and longitude) and vice versa. This fork mangage also the place_id requests.
