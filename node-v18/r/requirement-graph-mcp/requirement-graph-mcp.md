# requirement-graph-mcp

> 标签: codex, document-graph, local-first, markdown, mcp, model-context-protocol, requirement-graph, requirements, requirements-management, sqlite

## 简介

A local-first requirement & document graph: import Markdown/TXT/JSON/CSV into a per-project SQLite database and query or visualise it through an MCP server and a local web UI.
