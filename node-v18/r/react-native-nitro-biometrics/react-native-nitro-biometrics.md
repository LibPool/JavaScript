# react-native-nitro-biometrics

> 标签: android, authentication, biometric-prompt, biometrics, face-id, fingerprint, ios, nitro, nitro-modules, react-native, react-native-new-architecture, security, touch-id

## 简介

A blazing-fast, type-safe React Native biometric authentication library powered by Nitro Modules. Supports Face ID, Touch ID, Optic ID, Android BiometricPrompt (Fingerprint, Face, Iris) and device passcode fallback with direct JSI bindings.
