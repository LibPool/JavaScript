# req-real-ip

> 标签: address, express-ip, express-real-ip, express-real-ip-address, express-real-ip-address-middleware, express-real-ip-address-middleware-js, express-real-ip-address-middleware-node, express-real-ip-address-middleware-nodejs, express-request-ip, forwarded, header, ip, modified, real, request, user-ip, x-client-ip, x-cluster-client-ip, x-forwarded-for, x-proxy-user, x-real-ip

## 简介

This library allows you to get the real ip address of a user. It gives you the real ip address even if the request header is modified.
