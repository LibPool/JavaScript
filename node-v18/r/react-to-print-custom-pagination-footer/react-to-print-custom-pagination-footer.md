# react-to-print-custom-pagination-footer

> 标签: footer custom react to print, paging custom react to print, print bulky with reset paging, reset paging print bulky

## 简介

custom footer tulisan bagian bawah kiri berisi timestamp dan tulisan bawah kanan berisi paging. package ini diperuntukan untuk print dari web browser chrome yang tidak support custom pagination. dengan contoh kasus misalnya dibutuhkan print bulky mengguna
