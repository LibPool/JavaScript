# react-native-alpha-video-ffmpegkit

> 标签: alpha, alpha-channel, android, fabric, ffmpeg, ffmpegkit, ios, libvpx, metal, opengl-es, react-native, react-native-component, react-native-web, transparency, transparent-video, video, video-player, vp9, webm, yuva420p

## 简介

Transparent video for React Native: VP9 WebM with alpha on iOS and Android, decoded by FFmpegKit from plain Java and Swift, drawn with Metal / OpenGL ES or as bitmaps. Falls back to <video> on the web.
