# ratio-app-ecosystem-mcp-dev-server

> 标签: JavaScript

## 简介

Neeti fork of Ratio App Ecosystem dev MCP — path-split (NEETI_PROJECT_ROOT vs NEETI_BUILD_ROOT), auto-starts dev servers on 0.0.0.0, POSTs to arya-be internal hooks. Drop-in replacement for upstream when Neeti env vars are absent.
