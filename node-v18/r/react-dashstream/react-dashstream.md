# react-dashstream

> 标签: aiops, busaud, dashboard, dashstream, react, toolkit

## 简介

Dashstream is a holographic 3D infrastructure monitoring dashboard for React. Pure CSS-3D — no WebGL, no canvas, no dependencies beyond React.
