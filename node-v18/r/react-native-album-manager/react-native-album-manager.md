# react-native-album-manager

> 标签: JavaScript

## 简介

A customizable image swiper/gallery component for React Native, powered by **Reanimated v3** and **Gesture Handler**. Supports pinch-to-zoom, rotate, swipe between images, and smooth fullscreen transitions like Instagram.
