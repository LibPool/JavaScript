# react-fabric-canvas-designer

> 标签: canvas, canvas-designer, canvas-editor, customizable-canvas, design-tool, drawing-tools, fabric, fabric-canvas, fabric-wrapper, fabricjs, google-fonts, graphic-editor, json-export, json-import, object-manipulation, react, react-canvas, react-component, react-fabric, vector-editor

## 简介

A React-based wrapper for Fabric.js to create interactive and customizable canvas-based designs. This library provides tools for drawing, editing, and managing objects on a canvas with React-friendly APIs.
