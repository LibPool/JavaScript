# ram-chunker

> 标签: algorithm, cdc, chunker, chunking, content defined chunking, content dependent chunking, deduplication, ram, rapid asymmetric maximum

## 简介

Rapid Asymmetric Maximum (RAM) is a high throughput, hash-less, byte shift-resistant content-defined chunking algorithm for data deduplication.
