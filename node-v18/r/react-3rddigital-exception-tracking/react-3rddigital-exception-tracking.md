# react-3rddigital-exception-tracking

> 标签: 3rddigital, error-boundary, exception-tracking, javascript-errors, react

## 简介

Lightweight exception tracking SDK for React web applications, built on react-error-boundary, that reports JavaScript errors to 3rdDigital exception ingestion APIs.
