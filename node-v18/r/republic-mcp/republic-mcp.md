# republic-mcp

> 标签: camera-deputati, italian-parliament, linked-data, mcp, model-context-protocol, open-data, parliament, senato, sparql

## 简介

MCP Server for Italian Parliament Open Data (Camera, Senato e OpenPolis) — SPARQL tools over the official Camera dei Deputati and Senato della Repubblica endpoints, plus curated OpenPolis/Openparlamento data (indice di forza, presenze, votazioni, decreti)
