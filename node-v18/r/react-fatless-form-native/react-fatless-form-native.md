# react-fatless-form-native

> 标签: android, expo, form, form-bindings, form-hooks, form-library, form-management, form-submit, form-validation, forms, headless, ios, keyboard-handling, mobile-form, react-native, react-native-form, react-native-forms, react-native-hooks, react-native-input, react-native-validation, return-key, setFocus, typescript, useSwitchField, useTextField, yup

## 简介

React Native bindings for react-fatless-form - useTextField, useNumberField, useSwitchField, and useFormSubmit, each wired for RN's built-in components. Re-exports the entire core API, so this is the only package a native app needs to import from.
