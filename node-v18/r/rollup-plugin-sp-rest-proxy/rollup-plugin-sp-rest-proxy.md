# rollup-plugin-sp-rest-proxy

> 标签: SharePoint, plugin, rollup, rollup-plugin, sp-rest-proxy, vite, vite-plugin

## 简介

[Rollup](https://rollupjs.org) / [Vite](https://vitejs.dev) plugin that wires [sp-rest-proxy](https://github.com/koltyakov/sp-rest-proxy) into the dev server so SharePoint REST calls resolve locally while you build.
