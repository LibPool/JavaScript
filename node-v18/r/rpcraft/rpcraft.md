# rpcraft

> 标签: api, http, jsonrpc, rpc, schema-validation, typescript

## 简介

A platform-agnostic, type-safe RPC toolkit that crafts end-to-end types — a first-class API for command definitions, link composition, and streaming. Inspired by tRPC.
