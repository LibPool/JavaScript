# react-fancy-loader

> 标签: load-lab, loaders, loadlab, react, react-fancy-loader, react-loader, react-loaders, react-spinner, react-spinners, spinners, styled-components

## 简介

A lightweight set of fancy loaders for your React applications. The package uses ESM, which enables tree shaking.
