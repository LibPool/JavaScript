# resilient-llm

> 标签: ai, backoff, circuit-breaker, fail-safe, failover, fault-tolerant, limit, llm, rate, rate-limit, resilient, resilient-llm, resilient-llm-js, resilient-llm-node, retry, throttle

## 简介

ResilientLLM is a resilient, unified LLM interface with in-built circuit breaker, token bucket rate limiting, caching, and adaptive retry with dynamic backoff support.
