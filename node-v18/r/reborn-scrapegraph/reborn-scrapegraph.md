# reborn-scrapegraph

> 标签: agent-skills, claude, claude-code, crawler, korean, ollama, playwright, scrapegraphai, scraping, skill, web-scraping

## 简介

영상에서 소개한 ScrapeGraphAI(MIT 오픈소스 파이썬 스크래퍼)를 실제로 쓸 수 있게 만드는 안내 스킬입니다. 무료인 건 라이브러리이고 모델은 내 키 또는 Ollama 라는 것을 먼저 말하고, playwright 브라우저 엔진이 왔는지·파이썬이 몇 개인지를 이 컴퓨터에서 직접 재 줍니다.
