> 标签: ai, claude, components, cursor, documentation, mcp, model-context-protocol, react-native, reacticx, windsurf

## 简介

MCP server for Reacticx React Native component library documentation. Works with Claude Code, Cursor, Windsurf, VS Code, and any MCP-compatible client.
