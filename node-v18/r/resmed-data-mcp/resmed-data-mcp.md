# resmed-data-mcp

> 标签: airsense, cpap, flashair, macos, mcp, model-context-protocol, quantified-self, resmed, sqlite

## 简介

Mac Mini indexer + MCP server: archives raw ResMed AirSense CPAP data from a FlashAir-enabled SD card into SQLite, queryable over the LAN by any MCP client
