# reborn-mem3

> 标签: agent-skills, claude, claude-code, claude-mem, find-skills, korean, memory, security, skills, vibesec

## 简介

클로드 코드에 붙이는 무료 스킬 셋(claude-mem · find-skills · VibeSec)을 한 번에 깔아 주고, 언제 무엇을 부르는지 안내 스킬을 심습니다. --check 가 이 컴퓨터에서 다섯 가지(Node 18+ · npx · git · Bun · ~/.claude/skills 쓰기)를 실제로 재 줍니다. 셋 다 남의 오픈소스이고 저장소 코드는 담지 않습니다 — 공개된 설치 명령을 대신 돌릴 뿐입니다.
