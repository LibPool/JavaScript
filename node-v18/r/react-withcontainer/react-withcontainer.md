# react-withcontainer

> 标签: container, container-presenter, high-order-component, higher-order-component, hoc, inversion, inversion-of-control, ioc, presenter, react, typescript, ui

## 简介

HOC that allows ioc for presenter (Uis) to wrap themselves in containers passing themselves to the container as props.container.
