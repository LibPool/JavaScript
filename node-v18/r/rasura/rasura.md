# rasura

> 标签: browser, client-side, pdf, pdf-edit, pdf-editor, pdf-generation, redaction, typescript, wasm, webassembly

## 简介

True PDF editing in the browser: read a document as paragraphs, change it, and write it back with the untouched bytes intact
