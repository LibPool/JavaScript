# riksbank-exchange-rate

> 标签: api, central-bank, currency, exchange-rate, exchange-rates, forex, fx, official-rates, riksbank, sek, sveriges, sweden, typescript

## 简介

Official Sveriges Riksbank (Sweden) daily exchange rates — 29 currencies vs SEK, history since 2016. Zero-dependency Node.js/TypeScript client.
