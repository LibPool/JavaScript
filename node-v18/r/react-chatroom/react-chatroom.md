# react-chatroom

> 标签: JavaScript

## 简介

1.使用dva-cli创建项目 2. 进入server目录  cnpm i ，然后 node app 启动服务 3.在自己的项目中 引入 import Hello from 'react-chatroom';   4.代码种 书写 "<Hello />" 5. emoji 可能有问题，可以把assents文件下载下来，自己写。
