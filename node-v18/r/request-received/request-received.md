# request-received

> 标签: Symbol, airbrake, bunyan, cabin, connect, date, diff, difference, express, for, high, hrtime, http, koa, log, logger, logging, loggly, morgan, ms, pino, process, process.hrtime, received, request, resolution, sentry, service, signale, start, started, timber, time, timer, timestamp, timing, tool, utility, winston, x-response-time

## 简介

Route middleware for Koa and Express that adds a request received high-resolution timer and Date to the request object using easily accessible Symbols to prevent request object pollution.  Made for Cabin.
