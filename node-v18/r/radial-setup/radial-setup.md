# radial-setup

> 标签: installer, macos, radial

## 简介

Install the Radial app (visual editor for marketing-site codebases) on an Apple Silicon Mac. Thin wrapper over the canonical installer at https://radial.to/install.

## 官网

- 官网：https://radial.to
- npm 页面：https://www.npmjs.com/package/radial-setup

## 历史版本号

- 当前版本：0.1.0

- 0.1.0

## 获取地址

- npm 安装：`npm install radial-setup`
- npm registry：https://registry.npmjs.org/radial-setup
- Node 要求：>=16
