# rig-play

> 标签: 2d, animation, character-animation, css-transform, dom, mesh-deformation, renderer, rig-c, rigc, skeletal-animation

## 简介

Plays skeleton.model.json written by rigc build as plain DOM elements — rigid slots as <img> posed by CSS matrix, deform meshes on small per-part canvases — or as one canvas.
