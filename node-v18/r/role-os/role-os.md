# role-os

> 标签: agents, ai-workflow, claude, coding-agents, contracts, developer-tools, handoffs, multi-agent, review, role-contracts, role-os, workflow

## 简介

Role OS — a repo-native operating layer that staffs coding-agent work through 61 role contracts, packs, missions, conflict detection, escalation, and structured evidence. Claude Code adapter ships; the contracts are markdown any harness can consume.
