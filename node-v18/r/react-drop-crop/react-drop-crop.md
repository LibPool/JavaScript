# react-drop-crop

> 标签: avatar, crop, cropper, drag-and-drop, dropzone, image, image-crop, image-upload, react, react-component, resize, upload, webp

## 简介

Beautiful by default, you bring the upload — a drop-in React image upload + crop component: drag-drop, pan/zoom or resize-box cropping, EXIF-correct WebP output, and bring-your-own upload with progress. Zero dependencies, TypeScript-first.
