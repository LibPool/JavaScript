# reposhield-scan

> 标签: malware, obfuscation, sarif, scanner, security, static-analysis, supply-chain

## 简介

Read-only-by-default security scanner that detects suspicious, obfuscated, or compromised JavaScript/TypeScript code before it can execute, with opt-in cleanup for flagged VS Code task entries.
