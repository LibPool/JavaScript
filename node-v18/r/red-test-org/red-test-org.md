# red-test-org

> 标签: JavaScript

## 简介

WEB版 各种分离： 实例和类分离； 配置和代码分离； 视图、控制器、模型分离（MVC）； 应用框架和界面分离； 主界面和视图分离； 视图和控件分离。 各种动态： 动态加载JS、HTML、CSS； 动态拼装HTML； 动态加载视图； （杀Angular） 动态读取配置生成应用程序； 动态远程获取数据。 各种重用： 各种基础库的重用（序列化/反序列化库、各种动态加载、代理……）； 控件的重用； 视图的重用； 配置的重用； 各种特色功能： 远程透明代理； 用配置的方式装配（杀Angular）； 客户端和Nod
