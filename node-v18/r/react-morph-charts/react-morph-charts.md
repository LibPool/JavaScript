# react-morph-charts

> 标签: animation, bar-chart, bubble-chart, chart, component, dataviz, morphing, pie-chart, react, transition, typescript

## 简介

A reusable React/TypeScript component that displays data as a bubble, bar, or pie chart, with animated morphing transitions between views.
