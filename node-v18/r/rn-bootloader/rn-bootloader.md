# rn-bootloader

> 标签: android, ios, javascript, library, optimizations, react-native

## 简介

A lightweight and extensible lifecycle boot manager for React Native apps.Organize, prioritize, and execute startup tasks (e.g. analytics, CodePush, async storage, Redux init) across multiple phases — all before or after your app UI is ready.
