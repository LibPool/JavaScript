# rn-sticky-data-table

> 标签: data-table, expo, finance-table, gesture-handler, react-native, reanimated, spreadsheet, sticky-columns, table

## 简介

A performant, horizontally-scrollable React Native data table with sticky columns, nested rows, a totals footer row, and a fully themeable design system.
