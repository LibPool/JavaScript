# react-magneto

> 标签: board, canvas, dnd, drag, drag-and-drop, draggable, fridge-magnet, headless, layout, magnet, moodboard, pinboard, react, react-component, sticker, stickers, typescript, whiteboard

## 简介

Drag-and-drop sticker board for React — a draggable fridge-magnet canvas with render-free dragging, layout export/import, and per-magnet layer, rotation and size.
