# realtime-tts-mcp

> 标签: kokoro, mcp, model-context-protocol, text-to-speech, tts, voice

## 简介

MCP server for ReadAloud's realtime streaming text-to-speech API (Kokoro-82M) as a single synthesize_speech tool. Free API key, 10,000 free characters, sub-second warm latency. Returns playable WAV audio.
