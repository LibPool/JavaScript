# react-router-isomorphic-link

> 标签: ReactRouter, anchor, href, i18n, link, react, react-router, to

## 简介

A wrapper component around React Router's Link / NavLink components and the native anchor element. One component to rule them all! Render an anchor tag for outgoing links and a React Router Link / NavLink for everything else! Also supports automated final
