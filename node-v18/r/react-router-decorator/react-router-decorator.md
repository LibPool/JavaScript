# react-router-decorator

> 标签: decorator, decorator-route, react, react-decorator, react-router, react-router-dom, react-router-dom-decorator, route, router, router-decorator

## 简介

基于 react-router-dom 封装的路由工具，提供装饰器/函数模式设置路由，自动排序，支持嵌套路由
