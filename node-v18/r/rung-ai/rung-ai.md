# rung-ai

> 标签: agent, ai, ai-agent, ci, claude, code-review, evidence, gate, llm, verification, verify

## 简介

Did your AI agent run what it says it verified, or only claim it did? rung turns an agent's verification into a record you can re-check. (npm entry currently redirects to the pip / pipx / uv / Homebrew / container install.)
