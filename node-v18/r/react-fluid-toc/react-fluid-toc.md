# react-fluid-toc

> 标签: anchor, animated, docs, outline, react, scroll-spy, scrollspy, svg, table-of-contents, toc

## 简介

A portable React table-of-contents with a fluid animated SVG rail, range scroll-spy highlight, and a travelling dot. Zero runtime deps, themed via CSS variables.
