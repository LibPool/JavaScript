# readbeyond-plugin-mediarb

> 标签: cordova, cordova-android, cordova-ios, ecosystem:cordova, mediarb

## 简介

This is a tweaked version of the official Cordova Media Plugin, with no dependency from File Plugin, play-only functions (recording removed), playback rate setting, support for Android and iOS, and a few bug fixes to work around Cordova bugs management.
