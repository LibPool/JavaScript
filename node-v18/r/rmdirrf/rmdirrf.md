# rmdirrf

> 标签: JavaScript

## 简介

Recursively remove all files and directories like rmdir -rf, but in node.js.

## 官网

- 源码仓库：git://github.com/Schoonology/node-rmdirrf.git
- npm 页面：https://www.npmjs.com/package/rmdirrf
