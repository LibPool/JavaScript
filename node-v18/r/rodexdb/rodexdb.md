# rodexdb

> 标签: cloudflare, database, dynamodb, mcp, rest, rodexdb, serverless

## 简介

Official TypeScript client for RodexDB — per-app keys & tables on DynamoDB, one clean API. Point it at any RodexDB gateway (your own deploy or the live instance).
