# rn-ticket-card

> 标签: boarding-pass, card, custom-component, notch, react-native, svg, ticket, voucher

## 简介

A customizable React Native component to create SVG-based ticket-shaped cards with support for rounded corners and notches (inward or outward) on all four sides. Perfect for event tickets, vouchers, or boarding passes.
