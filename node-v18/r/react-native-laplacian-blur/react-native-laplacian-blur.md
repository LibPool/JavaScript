# react-native-laplacian-blur

> 标签: JavaScript

## 简介

A high-performance native VisionCamera Frame Processor plugin for detecting image blur and calculating average luminance using Laplacian variance calculation. Supports both iOS (Objective-C) and Android (Kotlin).
