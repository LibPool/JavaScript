# react-native-barcode-sked

> 标签: barcode, react-native

## 简介

React Native component to generate barcodes. Uses [JsBarcode](https://github.com/lindell/JsBarcode) for encoding of data. SKED forked this project to add support for svg since the original library used ART which is no longer supported.
