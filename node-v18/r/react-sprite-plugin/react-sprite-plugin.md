# react-sprite-plugin

> 标签: JavaScript

## 简介

本插件的用处在于对html,css,js文件中符合要求的图片进行图集合并以及替换。 符合要求的图片的含义为该图片只是按照原尺寸进行展示，而不涉及拉伸，平铺等其他功能。 符合要求的图片目前需要人为的进行识别，当确定该图片为可图集合并图片后，可将图片名称中加入"_sprite"来进行标识，之后使用该插件即可在webpack打包过程中自动进行图集合并以及url替换。
