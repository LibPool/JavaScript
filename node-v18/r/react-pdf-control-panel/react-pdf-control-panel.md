# react-pdf-control-panel

> 标签: control panel, pdf, react

## 简介

PDF reader to add to your projects with a basic control panel built in and print functionality. Based on react-pdf and react-to-print plus fontawesome for icons. As it is the first version it just recieve the document as props with the name pdfFile.
