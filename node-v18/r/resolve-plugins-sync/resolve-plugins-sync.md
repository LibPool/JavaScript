# resolve-plugins-sync

> 标签: browserify, cfg, complex, config, config-management, configuration, load, load-config, load-plugin, load-transform, manage, management, plugin, plugins, presets, resolve, resolver, resolving, sync, synchronous, transform, transforms

## 简介

Synchronously resolve plugins / transforms / presets just like Babel and Browserify does it, using CommonJS `require` builtin. For example, useful for loading complex configs from `package.json` file.
