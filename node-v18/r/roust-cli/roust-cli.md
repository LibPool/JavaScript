# roust-cli

> 标签: bm25, cli, code-search, coding-agent, context, localization, retrieval, rust, tree-sitter

## 简介

Recall-first code retrieval for coding agents: one ranked, token-budgeted bundle of relevant code per query, across Python, JS/TS, Java, Go, Rust, C and C++. No model, no embeddings, no API key. Installs the roust binary.
