> 标签: banner, raect native scroll, react native, react native banner, react native carousel, react native swiper, scroll, swiper

## 简介

a powerful and simple banner component for react-native, compatible with Android and IOS. 一款用于`react native`的轮播图组件，支持无缝滚动、定时滚动、指示器显示、标题显示，可轮播图片或自定义组件。
