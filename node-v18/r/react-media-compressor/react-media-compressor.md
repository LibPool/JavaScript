# react-media-compressor

> 标签: android, compress, compress-image, compress-video, expo, file-size, heic, image-compression, image-optimization, image-resizer, ios, jpeg, max-file-size, media, mp4, react, react-native, reduce-image-size, reduce-video-size, resize, target-size, thumbnail, upload, video-compression, web, webp

## 简介

Compress images and videos in React and React Native. Set an exact size limit like 300 KB and get it, or use auto presets. Works on iOS, Android and web with no FFmpeg and no dependencies.
