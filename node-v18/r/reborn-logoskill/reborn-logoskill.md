# reborn-logoskill

> 标签: app-icon, branding, claude, claude-code, favicon, korean, logo, logo-design, skill

## 简介

사업 설명 한 줄로 로고 시안 3개를 그리고 팔레트·앱 아이콘·파비콘까지 만드는 클로드 코드 스킬 kaankiziltug/logo-design-skill(MIT · v1.4.3)을 고정 판으로 받아 스킬 폴더에 놓고, 파일이 실제로 늘었는지 다시 셉니다. 한국어 안내 스킬이 같이 깔립니다. --check 가 깔기 전에 이 컴퓨터를 재 줍니다. 저장소는 남이 만든 오픈소스이고 저희는 제휴 관계가 없습니다 — 저희가 만든 것은 설치기와 한국어 안내 하나뿐입
