# react-llm-github-issue-builder

> 标签: JavaScript

## 简介

Transform your problem statements into detailed GitHub issues effortlessly **and privately**! This React application leverages the power of **MLC LLM** to generate comprehensive GitHub issues from your prompts and JSON schemas. With built-in dark mode sup
