# relintio

> 标签: bot-detection, bot-mitigation, cli, init, middleware, relintio, scaffold, security, threat-protection, waf

## 简介

Install and verify Relintio application protection in any project. Detects your runtime, installs the right agent SDK, wires the middleware, and confirms the license is live.
