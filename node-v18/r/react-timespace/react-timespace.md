# react-timespace

> 标签: component, meeting-planner, react, scheduling, time-zones, timeline, timezone, world-clock

## 简介

Multi-timezone timeline React component — drag time intervals across timezone rows with collision-resolved clock labels. Extracted from SyncContact.
