# react-native-sse-bridge-client

> 标签: classic-bridge, eventsource, http2, okhttp, react-native, server-sent-events, sse, urlsession

## 简介

Native Server-Sent Events (SSE) client for React Native's classic bridge — reuses the platform's HTTP/2 connection pool across reconnects (URLSession on iOS, OkHttp on Android) for apps that can't use the New Architecture / Nitro Modules.
