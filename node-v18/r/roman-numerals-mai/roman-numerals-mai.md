# roman-numerals-mai

> 标签: JavaScript

## 简介

En un módulo de JavaScript (instalable via npm) que permita al usuario converir números arábigos en números romanos y viceversa. El paquete (lo que instalamos a través de npm) también debe incluir un script ejecutable que nos permita usar la librería desd
