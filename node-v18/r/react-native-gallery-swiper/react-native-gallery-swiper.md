# react-native-gallery-swiper

> 标签: Lue Hang, LueH LABS, LueHsoft, album, android, animated, animation, camera roll, double tap, gallery, images, ios, luehang, photo, pictures, pinch, react-native, react-native-gallery-swiper, sensitive guesture, sensitive swipes, swiper, zoom

## 简介

An easy and simple to use React Native component to render a high performant and easily customizable image gallery with common gestures like pan, pinch and double tap.  Supporting both iOS and Android.
