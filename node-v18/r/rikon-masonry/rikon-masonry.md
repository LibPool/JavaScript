# rikon-masonry

> 标签: JavaScript

## 简介

`rikon-masonry` - это React-приложение для создания и отображения заметок. Пользователи могут создавать заметки, каждая из которых содержит заголовок, дату создания, содержание и возможность выделения части содержания жирным шрифтом. Заметки отображаются
