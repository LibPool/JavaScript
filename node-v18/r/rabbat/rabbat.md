# rabbat

> 标签: JavaScript

## 简介

Rabbat — a framework for hostable apps: a reactive relational database on Postgres, a type-safe TypeScript functions API, a sync client, and the `rabbat` CLI (dev/build/start/deploy), served behind one port.
