# dsh-plugin-danmu

> 标签: bilibili, danmaku, danmu, deepseek-harness, dsh, plugin

## 简介

Live danmu overlays for DeepSeek Harness (dsh) that visualize agent activity and status, such as reasoning, tool calls, and task progress.
