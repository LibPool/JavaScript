# @queryjs/drizzle

> 标签: adapter, drizzle, orm, query, query-parser, queryjs

## 简介

Drizzle adapter for QueryJS: translates validated ResourceQuery objects into Drizzle SQL where and orderBy fragments plus skip and take.
