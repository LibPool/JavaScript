# @parhelia/astro

> 标签: JavaScript

## 简介

The Astro adapter of @parhelia/head for a rendering head written in Astro, with or without React: the integration (base path below Parhelia's rendering proxy, the build values inlined) and ParheliaSlot, ParheliaBridge and ParheliaRefresh as Astro componen
