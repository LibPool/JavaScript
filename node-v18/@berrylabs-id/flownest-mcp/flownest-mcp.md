# @berrylabs-id/flownest-mcp

> 标签: claude-code, flownest, mcp, model-context-protocol, oauth, project-management

## 简介

MCP server for FlowNest. Drive FlowNest (tasks, comments, cycles, branches) from Claude Code, Claude Desktop, claude.ai web, or any MCP client via a Personal Access Token - locally over stdio, or hosted over Streamable HTTP with OAuth 2.1.
