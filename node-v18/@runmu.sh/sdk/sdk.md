# @runmu.sh/sdk

> 标签: extension, muclient, mud, runmu, sdk

## 简介

Types and helpers for μClient extensions. Install it as the @muclient/sdk alias ("@muclient/sdk": "npm:@runmu.sh/sdk@^1.13.0"): at runtime μClient supplies @muclient/sdk through its import map, so this package is for the type checker and stays external in
