# @fffangchenghao/dsh-web-search

> 标签: anysearch, bing, deepseek-harness, dsh, dsh-plugin, search, web-fetch, web-search

## 简介

DSH bundle: a key-free web search provider. Leads with the anonymous AnySearch API and falls back to public result pages (DuckDuckGo, Bing, 360), merged by reciprocal-rank fusion with a bilingual region policy, an engine cooldown and a TTL cache.
