# @hiogawa/vite-plugin-simple-hmr

> 标签: JavaScript

## 简介

Simple HMR to reassign all exports, which can be useful for [SSR HMR](https://github.com/vitejs/vite/pull/12165) to accompany with React plugin's client HMR.
