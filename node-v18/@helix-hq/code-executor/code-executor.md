# @helix-hq/code-executor

> 标签: json-schema, monaco, quickjs, sandbox, typescript, untrusted-code, wasm

## 简介

Run untrusted TypeScript in a QuickJS WASM sandbox, typed by JSON Schema, with a Monaco editor for authoring it.
