# @pyworkload/3x-ui-mcp

> 标签: 3x-ui, mcp, model-context-protocol, proxy, reality, v2ray, vless, vpn, xray

## 简介

MCP server for the 3x-ui Xray/V2Ray proxy panel: manage inbounds, clients, routing, nodes and Xray itself from an LLM agent.
