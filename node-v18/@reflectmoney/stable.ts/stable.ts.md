# @reflectmoney/stable.ts

> 标签: JavaScript

## 简介

A TypeScript SDK for interacting with the [Reflect](https://docs.reflect.money) protocol on Solana. The SDK ships codama-generated bindings for every on-chain instruction plus high-level `Stablecoin` classes that hide the per-venue plumbing behind `mint()
