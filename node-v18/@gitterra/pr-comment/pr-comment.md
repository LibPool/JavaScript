# @gitterra/pr-comment

> 标签: automation, cd, ci, comment, game, github, gitlab, gitterra, map, pr, pull-request

## 简介

A Node.js module use in CI/CD pipeline to leave a comment on Pull Requests about the GitTerra map that was generated when said pull request was merged.
