# @magicleap/magicleap-helio-webxr-polyfill

> 标签: Helio, MagicLeap, WebXR

## 简介

Polyfill providing backward compatibility with the newest WebXR API and the WebXR API currently implemented in Helio (Lumin 0.96.0).
