# @forjio/linksnap-node

> 标签: analytics, forjio, linksnap, qr-codes, short-links, url-shortener

## 简介

Official Node.js SDK for LinkSnap — short links, QR codes, tags, custom domains, click analytics. Powered by @forjio/sdk for OIDC device-flow auth + multi-profile session store + typed API client.
