# @forjio/plugipay-node

> 标签: checkout, forjio, indonesia, payments, plugipay, subscriptions

## 简介

Official Node.js SDK for Plugipay — hosted checkout, subscriptions, invoices, receipts, refunds, gift cards & store credit, webhooks, adapters (Xendit/PayPal/Midtrans/Manual), templates, uploads, workspaces, API keys, billing, account management, admin po
