# @forjio/pawpado-node

> 标签: aws, forjio, gaming, gpu, pawpado

## 简介

Official Node.js SDK for Pawpado — single-user AWS GPU gaming portal. Sessions (start/stop/poll/pair/connect), credits (me/topup), billing (storage), settings, admin (reconcile/orphans). Powered by @forjio/sdk's Bearer auth (Huudis device flow).
