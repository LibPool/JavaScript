# @dsh-client/ui-question-anchors

> 标签: anchors, client, conversation, deepseek-harness, dsh, plugin

## 简介

DeepSeek Harness Web question-anchor plugin: a right-side floating panel listing every user question in the current conversation; clicking an item smoothly scrolls the chat to that message
