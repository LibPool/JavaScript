# @zhengjunyao/dsh-jike

> 标签: deepseek-harness, dsh, dsh-plugin, jike, panel, social, submitToTopic, 即刻

## 简介

Jike (即刻) for DeepSeek Harness: a self-contained Jike web-API client exposed as jike_* agent tools (QR login, following feed, post detail, user posts, search, topic feed, notifications) plus a web settings panel; publishing, commenting, liking and deletio
