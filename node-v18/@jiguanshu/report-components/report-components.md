# @jiguanshu/report-components

> 标签: components, element-plus, jiguanshu

## 简介

一个快速创建组件库的工程模板，模板基于vue3、typescript、element-plus、StoryBook。该模可以让你快速创建基于Element-plus组件库的自有组件，开发过程中可以使用StoryBook预览和测试，完成后可发布成组件文档。
