# @anil-labs/dnd-solid

> 标签: dnd, drag-and-drop, draggable, list, reorder, solid, solidjs, sortable

## 简介

SolidJS bindings for @anil-labs/dnd-core — the createDraggable primitive for sortable lists, cross-list groups, multi-drag and keyboard a11y.
