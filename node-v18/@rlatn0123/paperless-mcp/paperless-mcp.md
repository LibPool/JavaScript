# @rlatn0123/paperless-mcp

> 标签: ai, claude, document-management, mcp, model-context-protocol, paperless, paperless-ngx

## 简介

Model Context Protocol (MCP) server for paperless-ngx. Exposes the complete paperless-ngx REST API — documents, tags, correspondents, document types, storage paths, custom fields, bulk operations, workflows, mail rules and administration — to AI assistant
