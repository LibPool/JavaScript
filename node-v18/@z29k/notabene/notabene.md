# @z29k/notabene

> 标签: agent, ai, astro, claude-code, comments, docs, docs-as-code, documentation, markdown, mdx, review, technical-writing

## 简介

Navigable docs renderer + human↔agent review loop. Leave review comments right on your rendered docs; an agent reads .notabene/, applies the feedback, and journals it.
