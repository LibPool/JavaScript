# @wcstack/view-transition

> 标签: animation, custom-elements, declarative, framework-agnostic, page-transition, view-transition, view-transitions-api, wc-bindable, web-components, zero-dependencies

## 简介

Declarative View Transition arbiter for Web Components. Framework-agnostic policy tag that animates @wcstack/router route swaps and @wcstack/state list/branch updates via the transition-runner protocol.
