# @wcstack/storage

> 标签: custom-elements, declarative, framework-agnostic, localStorage, persistent, sessionStorage, storage, wc-bindable, web-components, zero-dependencies

## 简介

Declarative persistent storage component for Web Components. Framework-agnostic localStorage/sessionStorage via wc-bindable-protocol.
