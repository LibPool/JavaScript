# @wcstack/eyedropper

> 标签: color-picker, custom-elements, declarative, eye-dropper, eyedropper, framework-agnostic, wc-bindable, web-components, zero-dependencies

## 简介

Declarative EyeDropper component for Web Components. Framework-agnostic EyeDropper.open() primitive via wc-bindable-protocol.
