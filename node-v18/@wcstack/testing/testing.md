# @wcstack/testing

> 标签: data-wcs, happy-dom, testing, vitest, wcstack, web-components

## 简介

Headless test helpers for wcstack pages: mount HTML under happy-dom, await bindings, read/write state, settle updates - the README recipe as one import.
