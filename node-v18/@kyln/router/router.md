# @kyln/router

> 标签: JavaScript

## 简介

File-based routing primitives for the Kyln framework: scan a routes directory into a route tree, match a path (with dynamic and catch-all segments), and navigate on the client. Wired up for you by `@kyln/cli`; available directly when you need the primitiv
