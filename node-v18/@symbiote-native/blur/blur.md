# @symbiote-native/blur

> 标签: angular, blur, blur-view, expo-blur, react, react-native, solid, svelte, symbiote-native, vue

## 简介

expo-blur wrapped for SymbioteNative — one framework-agnostic core, built once and reachable from the React, Vue, Svelte, Solid, and Angular adapters. A native view that blurs the content behind it, plus the Android blur target.
