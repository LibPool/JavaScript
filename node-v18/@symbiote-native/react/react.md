# @symbiote-native/react

> 标签: android, cross-platform, fabric, ios, mobile, react, react-native, reconciler, renderer, symbiote-native

## 简介

SymbioteNative's React adapter — a react-reconciler host config (mutation mode) driving real native iOS/Android views through stock React Native Fabric.
