# @symbiote-native/navigation

> 标签: angular, native-stack, react, react-native, react-native-screens, solid, svelte, symbiote-native, vue

## 简介

Native stack navigator for SymbioteNative, built on react-native-screens' native view primitives (RNSScreen/RNSScreenStack) — one framework-agnostic core, reachable from the React, Vue, Svelte, Solid, and Angular adapters.
