# @symbiote-native/task-manager

> 标签: angular, background, expo-task-manager, react, react-native, solid, svelte, symbiote-native, task, vue

## 简介

expo-task-manager wrapped for SymbioteNative — one framework-agnostic core, built once and reachable from the React, Vue, Svelte, Solid, and Angular adapters. Defines and tracks background tasks that native code invokes headlessly.
