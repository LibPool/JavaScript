# @symbiote-native/location

> 标签: angular, expo-location, geocoding, geofencing, geolocation, react, react-native, solid, svelte, symbiote-native, vue

## 简介

expo-location wrapped for SymbioteNative — one framework-agnostic core, built once and reachable from the React, Vue, Svelte, Solid, and Angular adapters. Foreground/background position and heading, geocoding, motion activity, and geofencing.
