# @symbiote-native/linear-gradient

> 标签: angular, expo-linear-gradient, gradient, linear-gradient, react, react-native, solid, svelte, symbiote-native, vue

## 简介

expo-linear-gradient wrapped for SymbioteNative — one framework-agnostic core, built once and reachable from the React, Vue, Svelte, Solid, and Angular adapters. A native view that paints a multi-color linear gradient behind its children.
