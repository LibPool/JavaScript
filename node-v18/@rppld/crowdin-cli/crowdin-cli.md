# @rppld/crowdin-cli

> 标签: JavaScript

## 简介

A little helper to sync messages with [Crowdin](https://crowdin.com/). It uses [`@formatjs/cli`](https://formatjs.io/docs/tooling/cli/) to extract messages from your application.
