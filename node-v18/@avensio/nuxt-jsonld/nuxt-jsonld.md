# @avensio/nuxt-jsonld

> 标签: json-ld, jsonld, nuxt, nuxt-module, schema.org, seo, structured data

## 简介

Nuxt module for building one route-aware Schema.org JSON-LD graph with typed creators, @id deduplication, reusable presets, and a single SSR-friendly head script.
