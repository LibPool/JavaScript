# @zero-to-100/plugin-workflow-javascript-node

> 标签: JavaScript

## 简介

This plugin adds a simple JavaScript workflow node for NocoBase. The node executes custom JavaScript code with dynamic arguments that can reference constants, scope variables, node results, trigger variables and system variables.
