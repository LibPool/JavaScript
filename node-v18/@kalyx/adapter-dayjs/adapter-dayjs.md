# @kalyx/adapter-dayjs

> 标签: adapter, datepicker, dayjs, kalyx

## 简介

dayjs adapter for @kalyx/core — implements the DateAdapter contract using dayjs (UTC mode). Timezone work is delegated to @kalyx/core's Intl-based utilities.
