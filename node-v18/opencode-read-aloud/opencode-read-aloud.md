# opencode-read-aloud

> 标签: elevenlabs, opencode, opencode-plugin, opencode-tui, read-aloud, speechify, text-to-speech, tts, tui

## 简介

OpenCode TUI plugin: read the last answer aloud with Speechify or ElevenLabs, highlighting each word as it is spoken.
