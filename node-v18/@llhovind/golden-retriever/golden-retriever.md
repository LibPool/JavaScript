# @llhovind/golden-retriever

> 标签: accessor, collector, deep nested, esm, mitigate type error, nested, object traversal, optional property, property accessor, property collector, property resolve, resolve, resolve nested, resolve path, tree traversal, wildcard resolve

## 简介

Resolver that finds properties from [deeply] nested objects/arrays given a path or pattern. It also collects properties from multiple branches, without throwing Type Errors.
