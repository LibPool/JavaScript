# @superinstance/starter-shell

> 标签: agent, bootstrap, cli, fleet, keel, plato, superinstance

## 简介

Starter shell — bootstrap CLI for the SuperInstance fleet. Detects hardware, spawns the agent loop, wires PLATO and keel. This npm package wraps the Python distribution.
