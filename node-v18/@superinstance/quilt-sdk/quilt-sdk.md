# @superinstance/quilt-sdk

> 标签: cell, quilt, substrate

## 简介

Agent substrate primitives for Quilt: resolveArtifact, validateManifest, publishArtifact, publishRunTrace, resolveTemplate. The five functions that turn Quilt sheets into executable, auditable, replayable artifacts.
