# @alexstormwood/camo-multi

> 标签: data, database, datastore, db, document, es6, model, nedb, nosql, odm, query, schema

## 简介

A class-based Object-Document Mapper (ODM) for NeDB, with support for disconnecting and reconnecting to databases during an app's runtime.
