# @trydaleel/ingest

> 标签: daleel, on-device, provenance, rag, retrieval

## 简介

Generic offline ingestion pipeline: dataset + grades → normalize → chunk → embed → versioned bundle. Parameterized by a DomainPack; runs on the operator's compute, never at user runtime.
