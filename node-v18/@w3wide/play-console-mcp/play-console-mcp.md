# @w3wide/play-console-mcp

> 标签: aab-upload, ai-agent, android, android-publisher, android-vitals, anr-rate, app-release, app-reviews, claude, crash-rate, cursor, devops, google-api, google-play, google-play-developer-api, llm-tools, mcp, mobile, model-context-protocol, play-console, play-store, release-management, store-listing

## 简介

MCP server for Google Play Console — manage app releases, reply to reviews, query Android Vitals (crashes/ANRs), update store listings, upload screenshots, and manage release tracks from any AI agent (Claude, Cursor, Copilot).
