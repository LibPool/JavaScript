# @a11y-ngx/icon

> 标签: a11y, accessibility, accessible, angular, component, html, icon, image, template, wrapper

## 简介

A polymorphic icon wrapper that enables your Angular libraries to accept and render any icon format (HTML, images, Components, or TemplateRefs).
