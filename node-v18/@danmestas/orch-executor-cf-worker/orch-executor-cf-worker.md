# @danmestas/orch-executor-cf-worker

> 标签: JavaScript

## 简介

orch executor backend: provisions Cloudflare Worker open-agent bridges from a SpawnSpec YAML on stdin and emits a WorkerHandle YAML on stdout. Implements orch proposal 0002 / executor-protocol.
