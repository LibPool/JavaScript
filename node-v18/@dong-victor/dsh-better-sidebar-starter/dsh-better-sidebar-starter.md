# @dong-victor/dsh-better-sidebar-starter

> 标签: deepseek-harness, dsh, dsh-better-sidebar, intellij, plugin, run-config, starter

## 简介

dsh-better-sidebar 的运行配置插件：模仿 IntelliJ IDEA 运行/调试配置，支持 npm/springboot/python/custom 命令执行、历史保存、快捷启动、实时日志查看，单 Tab 内分栏布局（左配置树 + 右日志流）
