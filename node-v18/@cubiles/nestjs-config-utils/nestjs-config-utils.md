# @cubiles/nestjs-config-utils

> 标签: config, env, nestjs, validation

## 简介

This is extended from the official Config-Module of [NestJs](https://github.com/nestjs/nest). The main function of the packages is a typesafe validation([class-validator](https://github.com/typestack/class-validator))  of the env.
