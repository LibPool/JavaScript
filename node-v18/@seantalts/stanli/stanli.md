# @seantalts/stanli

> 标签: bayesian, mcmc, nuts, stan, statistics, wasm, webassembly

## 简介

Full Stan in the browser: stanc3 compiles the model in JS, a WASM runtime lowers it to an op graph and runs NUTS. No server, no C++ toolchain.
