# @spanexx/angular-ui-components

> 标签: accessible, angular, components, design-system, directives, shadcn, standalone, typescript, ui

## 简介

A professional Angular component library with 36+ directives following shadcn/ui design principles. Includes Icon, Toast, Dialog, Select, DatePicker, and Loading directives. Fully accessible, tree-shakeable, and production-ready.
