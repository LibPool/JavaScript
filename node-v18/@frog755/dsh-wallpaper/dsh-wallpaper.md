# @frog755/dsh-wallpaper

> 标签: background, deepseek-harness, dsh, dsh-plugin, wallpaper, web-ui

## 简介

Persistent image and locally compressed MP4 wallpaper for DeepSeek Harness with opacity, blur, and a fixed web origin.
