# @samerecord/cli

> 标签: cli, entity-resolution, samerecord

## 简介

Operations CLI for samerecord. Apply schemas, seed data, run match queries, explain scoring, confirm/decline active-learning feedback, calibrate thresholds, list duplicates and variant clusters. Talks to a @samerecord/server matcher over HTTP.
