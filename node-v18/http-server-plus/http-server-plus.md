# http-server-plus

> 标签: JavaScript

## 简介

Drop-in replacement for `http.Server` that can listen on multiple ports/sockets and mix HTTP, HTTPS and HTTP/2 on a single instance

- 官网：https://github.com/JsCommunity/http-server-plus
- 源码仓库：git+https://github.com/JsCommunity/http-server-plus.git
