# @aphrody/x

> 标签: aphrody, aphrody-web, bun, client, graphql, headless, twitter, x

## 简介

Headless X (Twitter) client for Bun: a thin import over the Rust crate aphrody-x (aphrody-ffi), with batch jobs for mass scripting. Cookie-auth GraphQL + REST, no API key. Includes local For You algo (x-algorithm port), store, and X function tools (XTools
