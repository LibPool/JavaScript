# @codefusion-cc/testing

> 标签: accessibility, aria, contrast, e2e, focus, getstats, id-token, openid-connect, overflow, playwright, screenshot, testing, visual, wcag, webrtc

## 简介

What the apps' tests share: Playwright checks for UI nobody can see that still takes clicks or focus, for text too faint against what is behind it (WCAG 2.2 contrast, canvas and images included) and for pages that scroll sideways, visual comparison agains
