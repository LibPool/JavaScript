# @codefusion-cc/host-setup

> 标签: bash, curl, rootless-docker, secrets, setup, ssh

## 简介

A bash library for setup scripts that run as root on a host over SSH: API calls that retry 429 and 5xx with the token never in an argument, secrets kept on the host before any step that can fail, rootless Docker mount checks, and the script sent in one ar
