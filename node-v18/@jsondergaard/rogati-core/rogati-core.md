# @jsondergaard/rogati-core

> 标签: analytics, consent, consent-mode, cookie, eprivacy, gdpr, posthog

## 简介

Consent decisions for the browser: a synchronous gate that is denied until somebody says otherwise, with adapters for PostHog, Google Consent Mode, Plausible, Fathom and Meta Pixel.
