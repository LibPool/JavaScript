# selenit-mcp

> 标签: browser-automation, cdp, chrome, e4b, gemma, gemma-4, lm-studio, local-llm, mcp, model-context-protocol, selenium, web-automation

## 简介

Browser automation MCP server tuned for small local models like Gemma E4B: compact e1-style refs, loop guards, CDP attach, audit log. Selenium-based, 23 tools. One-command install: npx selenit-mcp setup lmstudio --install (Ruby/gem/Chrome checks + config)
