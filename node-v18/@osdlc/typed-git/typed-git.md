# @osdlc/typed-git

> 标签: cli-wrapper, dependency-injection, git, git-client, typescript, worktree

## 简介

A typed git client for TypeScript, sync and awaitable. Each verb declares what absence means for it; every other failure throws. git.try.* inspects, raw() bypasses — over an injectable backend that drives the git CLI or any other implementation.
