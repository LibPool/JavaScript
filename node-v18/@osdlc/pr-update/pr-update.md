# @osdlc/pr-update

> 标签: cli, github, pull-request, rebase, stacked-prs

## 简介

Survey and update out-of-date, stacked pull requests against their base: drift measured locally, conflicts predicted with merge-tree, PRs read through the @osdlc/code-host port.
