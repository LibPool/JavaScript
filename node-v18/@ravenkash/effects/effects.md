# @ravenkash/effects

> 标签: JavaScript

## 简介

Raven Effects — a reusable real-time video effects pipeline (filters, presets) shared by Raven RTC and Raven Live Streaming. Provider-agnostic: takes a MediaStreamTrack, returns a processed MediaStreamTrack.
