# @willow-hq/roots

> 标签: JavaScript

## 简介

Shared client-side package for Willow customer sites: attribution capture, the lead form island, CallRail dynamic number insertion, and JSON-LD helpers. Built for Astro sites with React 19 islands, deployed per customer on Cloudflare.
