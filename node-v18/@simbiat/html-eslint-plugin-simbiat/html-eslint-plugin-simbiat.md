# @simbiat/html-eslint-plugin-simbiat

> 标签: accessibility, eslint, eslint-plugin, eslintplugin, html, html-eslint, twig, typescript

## 简介

Custom @html-eslint rules used in simbiat.eu project: anchor text-node wrapping, button/input preference, redundant alt text, and checkbox label structure.
