# @solid-stack/di

> 标签: decorators, dependency-injection, di, inversion-of-control, ioc, stage-3-decorators, typescript

## 简介

A lightweight, type-safe dependency injection framework with support for Stage 3 decorators, multi-tokens, value tokens, and async factories.
