# @voyantjs/admin-contracts

> 标签: JavaScript

## 简介

The Admin API contract layer for Voyant — typed, versioned, transport-agnostic descriptors for the operations an authenticated operator can perform against a Voyant-powered admin deployment. Web admin, the Expo mobile admin, Max/AI tool wrappers, and Voya
