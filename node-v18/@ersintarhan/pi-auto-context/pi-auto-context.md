# @ersintarhan/pi-auto-context

> 标签: anchor, context-management, pi, pi-extension, pi-package, pi-skill, pivot

## 简介

Automatic context management for pi sessions: anchors, pivots, and cross-session recall — with a status line and auto-truncation of stale tool results.
