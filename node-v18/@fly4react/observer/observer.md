# @fly4react/observer

> 标签: component, hooks, intersection-observer, lazy-loading, performance, react, scroll, typescript, visibility, visibility-detection, visibility-sensor

## 简介

一个基于 Intersection Observer API 的现代 React 工具库，提供懒加载、可见性检测、位置跟踪和滚动方向检测功能
