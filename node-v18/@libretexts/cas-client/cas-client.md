# @libretexts/cas-client

> 标签: CAS2, CAS3, apereo, cas, cas-client, client, express, http, koa, node

## 简介

A fork of the inactive http-cas-client package at https://github.com/produck/cas-client. A complete implement of CAS Client middleware for Node.js, support CAS 1.0, 2.0+, 3.0+ protocol.
