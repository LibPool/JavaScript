# @a9i5k4/dsh-mini-window

> 标签: always-on-top, app-mode, client-plugin, compact, deepseek-harness, dsh, floating-ball, mini-window, plugin

## 简介

DSH mini window: a floating ball that pops out a real 520x720 always-on-top browser window (Chrome/Edge app mode, zero extra download), plus an in-page compact single-column view via ?dsh-mini=1.
