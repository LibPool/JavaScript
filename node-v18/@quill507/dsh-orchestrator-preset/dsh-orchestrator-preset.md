# @quill507/dsh-orchestrator-preset

> 标签: aegis, agent-preset, deepseek-harness, dsh, orchestration

## 简介

A thin-shell agent preset for DeepSeek Harness: nine named lanes with declared tool boundaries, resident routing sections, four self-authored skills, and an evidence-based completion gate.
