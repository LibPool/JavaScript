# @mintplayer/polyglot-target-csharp

> 标签: csharp, plugin, polyglot, transpiler

## 简介

MintPlayer Polyglot C# / .NET target — a pure-JSON language plugin (spec + emission rules + capabilities + std bindings) for the polyglot transpiler.
