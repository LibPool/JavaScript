# @3sln/deck

> 标签: component, documentation, markdown, playground, plugin, rspack, vite, web-dev-server, webpack

## 简介

Scalable, zero-config, Markdown-based component playgrounds and documentation sites. Runs on Vite, @web/dev-server, Rspack/webpack, or its own bundler-free dev server.
