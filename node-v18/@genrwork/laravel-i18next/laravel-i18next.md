# @genrwork/laravel-i18next

> 标签: i18n, i18next, i18next-backend, i18next-vue, inertiajs, laravel, react, react-i18next, svelte, vite-plugin, vite-plugin-laravel, vue

## 简介

Use your Laravel translation files with i18next in React, Vue 3 or Svelte: PHP files are converted to i18next JSON at build time, one namespace per language file.
