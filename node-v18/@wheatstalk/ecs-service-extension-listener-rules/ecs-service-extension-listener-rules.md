# @wheatstalk/ecs-service-extension-listener-rules

> 标签: JavaScript

## 简介

This module provides an [ECS Service Extension](https://www.npmjs.com/package/@aws-cdk-containers/ecs-service-extensions) that registers your service with an application load balancer by way of listener rules.
