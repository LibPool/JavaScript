# @syansunyang/pi-context-prune

> 标签: coding-agent, context-pruning, context-window, llm, pi-package

## 简介

Pi coding-agent extension that summarizes finished tool-call output out of context and keeps the originals one query away. Fork of championswimmer/pi-context-prune 1.4.0, with fixes for pruned-result handling, errored turns, reload and abort.
