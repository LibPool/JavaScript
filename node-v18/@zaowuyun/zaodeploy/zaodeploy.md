# @zaowuyun/zaodeploy

> 标签: agent, deploy, hosting, mcp, systemd, zaodeploy

## 简介

轻量常驻应用一键部署:常驻服务 + 独立子域 + 自动 HTTPS + 应用中心。任意 Agent 凭 API key 即可部署。
