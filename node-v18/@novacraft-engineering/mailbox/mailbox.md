# @novacraft-engineering/mailbox

> 标签: email, mailbox, nextjs, self-hosted, sqlite, webmail

## 简介

A shared webmail app: one codebase, one deployment per mailbox. Threads, a rich composer with signatures, attachments on S3-compatible storage, sharing links, full-text search, web push and PWA install.
