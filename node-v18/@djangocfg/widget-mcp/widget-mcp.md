# @djangocfg/widget-mcp

> 标签: chatgpt, claude, codex, cursor, mcp, model-context-protocol, oauth, react, typescript, vscode

## 简介

Connect an AI assistant to a django-cfg MCP server in one press, with the user's own key; plus the OAuth consent page. 17 locales.
