# @camped-ui/tooltip

> 标签: camped, camped-ui, components, next.js, tooltip

## 简介

Tooltip component is a popup that displays information related to an element when the element receives keyboard focus or the mouse hovers over it. It provides a non-intrusive way to convey additional details, explanations, or context about a specific elem
