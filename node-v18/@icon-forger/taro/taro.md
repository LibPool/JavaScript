# @icon-forger/taro

> 标签: JavaScript

## 简介

> Taro 场景下的 SVG 图标编译插件，把业务中的 `.svg` 组件引用转换成统一的 `BaseIcon` 运行时，并在构建阶段自动生成和注入 iconfont 资源。
