# @avokjs/core

> 标签: avok, eip-7702, passkey, smart-eoa, wallet

## 简介

Avok core: passkey/access-vault smart-EOA wallet engine. Wallet primitives, EVM (7702) tx, client, provider, shared-origin channel. Framework-agnostic.
