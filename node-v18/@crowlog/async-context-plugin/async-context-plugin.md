# @crowlog/async-context-plugin

> 标签: async, asynclocalstorage, context, correlation-id, crowlog, logger, logging, plugin, request-id, tracing

## 简介

Request-scoped logging context plugin for Crowlog using Node.js AsyncLocalStorage. Perfect for tracking request IDs and user context across async operations.
