> 标签: ai, claude, cursor, mcp, model-context-protocol, prompt, typescript, windsurf

## 简介

MCP 서버로, 사용자 작업 요구사항에 따라 미리 설정된 prompt 템플릿을 제공하여 다양한 작업을 더 효율적으로 수행할 수 있도록 도와줍니다
