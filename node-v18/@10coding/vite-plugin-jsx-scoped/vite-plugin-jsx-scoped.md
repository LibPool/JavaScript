# @10coding/vite-plugin-jsx-scoped

> 标签: JavaScript

## 简介

Vite plugin for Vue-like scoped styles in JSX/TSX (React): scopes *.scoped.{css,scss,less} imports and inline <style scoped> with a data-v-{hash} derived from the component file path
