# @flowkoi/sdk

> 标签: agents, api, claude, flowkoi, sandbox, sdk

## 简介

Official TypeScript SDK for the FlowKoi API — trigger sandboxed Claude-CLI agents, stream output, send follow-up messages, verify webhooks.
