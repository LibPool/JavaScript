# @angify/workspace

> 标签: angify, angular, angular-library, board, drag-drop, gantt, kanban, project-management, task-management, workspace

## 简介

A flexible, professional Angular board workspace library with Kanban, List, and Gantt views. Fully customizable with drag-and-drop, generic card types, and configurable themes.
