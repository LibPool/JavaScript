# @webmcpui/tokens

> 标签: css-custom-properties, design-tokens, style-dictionary, webmcpui

## 简介

Design token dictionary for webmcpui — source of truth in tokens/*.json, built with Style Dictionary into CSS custom properties, TS types, and a Figma import.
