# onevideo

> 标签: agent-skill, claude, claude-code, claude-desktop, ffmpeg, motion-graphics, playwright, skill, video

## 简介

Agent skill that turns a prompt into a finished short video, rendered locally with free tools. One command installs it for Claude Code and Claude Desktop.
