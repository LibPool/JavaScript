# @pyai/sdk

> 标签: compliance, openai-compatible, pyai, realtime, speech, stt, transcription, tts, voice-agents, voice-ai

## 简介

Official TypeScript/JavaScript SDK for PyAI, speech-to-text (Hear), text-to-speech (Speak), realtime voice agents (Omni), and call compliance (Trace).

## 官网

- 官网：https://pyai.com
- 源码仓库：git+https://github.com/atomsai/pyai-platform-backend.git
- npm 页面：https://www.npmjs.com/package/@pyai/sdk
