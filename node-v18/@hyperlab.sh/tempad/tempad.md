# @hyperlab.sh/tempad

> 标签: bun, claude-code, git, monday, sessions, time-tracking, timesheet

## 简介

Reconstructs work history hour by hour from git, Monday.com and Claude Code sessions into SQLite, then generates timesheet reports.
