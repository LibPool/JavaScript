# @propellerads/checkbox

> 标签: JavaScript

## 简介

A checkbox, the way shadcn draws one, on [Base UI's Checkbox](https://base-ui.com/react/components/checkbox). Every colour, gap, corner and duration comes from [@propellerads/tokens](../Tokens/README.md).
