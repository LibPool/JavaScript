# @csvbox/mcp-server

> 标签: claude, csv, csvbox, cursor, importer, mcp, model-context-protocol

## 简介

Universal MCP server for CSVBox — create, update, patch, generate, validate and scaffold CSVBox importer sheets from any MCP-compatible client.
