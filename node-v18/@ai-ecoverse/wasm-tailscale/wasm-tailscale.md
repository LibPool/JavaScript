# @ai-ecoverse/wasm-tailscale

> 标签: slicc, tailscale, tsconnect, wasm, wireguard

## 简介

Tailscale's tsconnect client (Go, js/wasm) with the APIs SLICC needs to use a tailnet as a network transport: streaming fetch, raw dial, WebSockets, exit nodes, status; shields up
