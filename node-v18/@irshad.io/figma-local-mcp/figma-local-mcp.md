# @irshad.io/figma-local-mcp

> 标签: design-to-code, figma, figma-plugin, figma-to-code, flutter, html, mcp, mcp-server, model-context-protocol, react, tailwind

## 简介

Local MCP server for Figma: a development plugin streams the open file over a localhost WebSocket, so design reads never touch the Figma API. Writes Flutter, React or HTML reference code.
