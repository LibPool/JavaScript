# @chimok/jpegtran-js

> 标签: crop, flip, ijg, image-transformation, jpeg, jpegtran, libjpeg, lossless, rotate, transpose, wasm, webassembly

## 简介

Lossless JPEG transformations (rotate, flip, crop) in the DCT domain as a WebAssembly module, built from IJG libjpeg 10.
