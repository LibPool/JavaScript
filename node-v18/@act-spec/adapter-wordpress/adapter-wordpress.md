# @act-spec/adapter-wordpress

> 标签: JavaScript

## 简介

WordPress adapter for ACT (Agent Content Tree). Consumes the WordPress REST API (`wp/v2/{posts,pages,categories,tags,users,media}`) and emits ACT envelopes against the shared adapter framework. Maps posts to leaf nodes, categories and pages to branch node
