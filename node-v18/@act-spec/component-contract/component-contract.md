# @act-spec/component-contract

> 标签: JavaScript

## 简介

PRD-300 component-instrumentation contract framework for the ACT (Agent Content Tree) v0.1 reference implementation. Defines the canonical contract object every framework binding (PRD-301 React, PRD-302 Vue, PRD-303 Angular) desugars into, the page-level
