# @khoralabs/memories-node

> 标签: JavaScript

## 简介

Individual memory node: client, ontology, contracts, backends, projections, attestation, autolink. ./sqlite requires Bun (bun:sqlite); ./libsql and ./turso-serverless are Node-safe.
