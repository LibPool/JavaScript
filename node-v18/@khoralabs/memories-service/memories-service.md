# @khoralabs/memories-service

> 标签: JavaScript

## 简介

Multi-tenant memory service: lifecycle, HTTP, auth, storage. ./storage/sqlite requires Bun; ./storage/libsql and ./storage/turso-serverless are Node-safe.
