> 标签: ai-skill, chat, live-streaming, mcp, real-time-communication, sdk-integration, sdk-log, troubleshooting, trtc, video-conference, webrtc

## 简介

Installer for the TRTC Agent Skills suite (Chat, Call, RTC Engine, Live, Conference) plus manual SDK runtime log troubleshooting and knowledge base, with one-command MCP setup for Claude Code / Cursor / CodeBuddy / Codex.
