# @euriklis/message

> 标签: bold italic and underline text in the console, colors in the terminal, mathematical symbols and expressions in the console, styling of the console output for nodejs

## 简介

A javascript library which allows you to write style-designed messages, mathematical/logical expressions and special symbols in the terminal.
