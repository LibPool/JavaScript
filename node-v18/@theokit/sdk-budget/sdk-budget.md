# @theokit/sdk-budget

> 标签: JavaScript

## 简介

USD-cost-aware BudgetTracker impls for @theokit/sdk — extends the counter-based reference with per-model pricing. Consumes the kernel-facing BudgetTracker port from sdk-core.
