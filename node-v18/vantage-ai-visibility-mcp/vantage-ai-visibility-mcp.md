# vantage-ai-visibility-mcp

> 标签: aeo, ai-search, ai-visibility, chatgpt, citations, geo, llm-visibility, mcp, mcp-server, model-context-protocol

## 简介

AI visibility MCP server: checks whether ChatGPT, Gemini, Perplexity and Google AI Overviews cite your site. Connects any stdio MCP client to the hosted Vantage server.
