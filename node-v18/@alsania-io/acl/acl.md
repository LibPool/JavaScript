# @alsania-io/acl

> 标签: acl, alsania, authorization, permissions, sovereign, zero-dependency

## 简介

Sovereign object-level ACL for Alsania. Principals (user/group/public) granted numeric permission bits on resources. Extracted from AlsaniaMCP; extended with namespace/storage/secret resource types. Zero dependencies.
