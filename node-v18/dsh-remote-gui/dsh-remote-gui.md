# dsh-remote-gui

> 标签: deepseek-harness, dsh, dsh-plugin, port-forward, remote, remote-gui, ssh, tunnel

## 简介

Embed a remote DeepSeek Harness GUI in the local DSH window over an SSH tunnel, list the remote sessions, and switch between the local instance and any remote host. Standalone implementation using the DSH 0.2.x credential-cookie and typert RPC contract.
