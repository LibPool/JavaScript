# @kashdao/protocol-sdk

> 标签: base, erc-4337, ethereum, kash, kashdao, non-custodial, prediction-markets, protocol, sdk, viem

## 简介

Official non-custodial TypeScript SDK for the Kash prediction-market protocol. Bring your own RPC, signer, and bundler. Native fetch + viem; zero internal dependencies.
