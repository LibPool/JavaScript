# @moonsox/trust

> 标签: agent, bot, ed25519, http-message-signatures, identity, moonsox, rfc9421, trust, web-bot-auth

## 简介

Moonsox Trust for bots and sites: Ed25519 bot identity, Web Bot Auth (RFC 9421) request signing and verification, and registry-signed bot cards. Zero dependencies.
