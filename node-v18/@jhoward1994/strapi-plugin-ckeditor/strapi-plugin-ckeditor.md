# @jhoward1994/strapi-plugin-ckeditor

> 标签: ckeditor, ckeditor 5, ckeditor5, editor, rich text, strapi, wysiwyg

## 简介

Integrates CKEditor 5 into your Strapi project as a fully customizable custom field. (Unofficial integration). Forked from https://github.com/nshenderov/strapi-plugin-ckeditor as a refactor for Strapi V5 compatibility
