# @listen-fire/web

> 标签: JavaScript

## 简介

The six bundled plugins (fetch a page, scan a message for links worth fetching, find a person's profile, read what they are doing now, find a company's own site, research a subject) as one plugin module. Loaded in process by the platform with its own tool
