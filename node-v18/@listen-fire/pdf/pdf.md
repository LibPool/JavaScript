# @listen-fire/pdf

> 标签: JavaScript

## 简介

Draws text as a PDF file: the plugin `pdf.render(text)`. The default writer is thin (Helvetica, no font to ship); a character it cannot draw prints as "?" with a warning, and a module that embeds a font can replace it. Loaded in process by the platform, s
