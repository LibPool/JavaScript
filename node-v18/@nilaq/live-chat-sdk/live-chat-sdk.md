# @nilaq/live-chat-sdk

> 标签: android, chat, intercom, ios, live-chat, livechat, nilaq, react-native, react-native-sdk, support, widget, zendesk

## 简介

NilaQ live-chat-sdk for React Native — embeds the same CDN/local widget.js (Home, Messages, Help, Tickets) in a fullscreen WebView so CDN uploads update the mobile UI automatically
