# @velion-la/onboarding-sdk-react-native

> 标签: expo, kyc, liveness, ocr, onboarding, react-native, velion

## 简介

Native React Native SDK for the Velion Onboarding (KYC) flow: ID document OCR, passive + active liveness, device fingerprint, OTP verification, address picker, and personal / legal information forms.
