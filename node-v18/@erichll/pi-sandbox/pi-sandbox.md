# @erichll/pi-sandbox

> 标签: pi, pi-extension, pi-package, sandbox, sandbox-runtime, security

## 简介

Linux (bubblewrap) and macOS (Seatbelt) process sandbox for Pi backed by Anthropic's @anthropic-ai/sandbox-runtime. Fail-closed static filesystem policy plus per-connection network approval from pi-auto-review; sandboxes main-agent Bash and built-in subag
