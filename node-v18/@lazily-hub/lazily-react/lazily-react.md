# @lazily-hub/lazily-react

> 标签: lazily, preact, react, reactive, signals, state, useSyncExternalStore

## 简介

React/Preact bindings for @lazily-hub/lazily-js: drive React state from lazily reactive Source/Computed handles via useSyncExternalStore. Glitch-free, equality-guarded re-renders.
