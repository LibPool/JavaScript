# @jpmart/nx-drizzle

> 标签: JavaScript

## 简介

This is an [Nx](https://nx.dev) plugin for [Drizzle](https://orm.drizzle.team) integration. It helps you to generate the Drizzle configuration file for an application, and it adds the target for running the drizzle-kit cli.
