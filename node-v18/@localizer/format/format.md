# @localizer/format

> 标签: date formatting, formatting, globalization, i18n, internationalization, l10n, localization, localizer, number formatting

## 简介

Type-safe localization, formatting and translation library. Provides utilities for formatting dates, numbers, lists, and display names in a locale-aware manner.
