# @adhd/apigen-plugin-ir-cache

> 标签: JavaScript

## 简介

Extract-stage IR cache plugin (FEAT-002, Revision 2): caches the derived IR (`Operation[]`) of one `ExtractCall` so repeat extraction of unchanged source is answered from disk instead of re-running the extractor (~3.4s of the backlog CLI's cold-start cost
