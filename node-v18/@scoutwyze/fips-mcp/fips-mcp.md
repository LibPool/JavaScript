# @scoutwyze/fips-mcp

> 标签: cmmc, cmvp, compliance, fips, fips-140-3, mcp, model-context-protocol, nist, scoutwyze, x402

## 简介

MCP server for ScoutWyze FIPS: is this product version FIPS 140-3 validated, in NIST's queue, or expiring? Answers from NIST CMVP lists with receipts. Stateless pass-through: holds no private keys, never signs or settles a payment itself.
