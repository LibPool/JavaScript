# @scoutwyze/compute-mcp

> 标签: ai-agent, compute, gpu, mcp, model-context-protocol, runpod, scoutwyze, x402

## 简介

MCP (Model Context Protocol) server for ScoutWyze Compute — ranks current RunPod GPU offers by price and freshness, with native x402/USDC-on-Base micropayment support. Stateless pass-through: holds no private keys, never signs or settles a payment itself.
