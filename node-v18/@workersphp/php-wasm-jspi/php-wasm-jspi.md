# @workersphp/php-wasm-jspi

> 标签: JavaScript

## 简介

PHP 8.5 compiled to WebAssembly for Cloudflare Workers: JSPI, wasm exceptions, pdo_cfd1 and the cfbindings bridge extension.

- 官网：https://workersphp.dev
- 源码仓库：git+https://github.com/workersphp/core.git
- npm 页面：https://www.npmjs.com/package/@workersphp/php-wasm-jspi
