# @lakutata/template-electron-vue

> 标签: electron, lakutata, lakutata-template, template, vite, vue

## 简介

The Electron template of the lakutata projects with Vue: the main process is a lakutata application serving the actions of its controllers to the Vue renderer (Vite) over IPC, packaged by electron-builder.
