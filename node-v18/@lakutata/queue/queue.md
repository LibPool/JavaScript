# @lakutata/queue

> 标签: amqp, bullmq, dead-letter, jetstream, kafka, lakutata, message-queue, nats, queue, rabbitmq, redis, typescript

## 简介

The message queues of the lakutata framework: messages added by the Queue component and processed by controller actions (@QueueAction), acknowledged, retried and dead-lettered alike over memory, Redis, NATS JetStream, Kafka or RabbitMQ.
