# @lakutata/mcp

> 标签: agent, ai, lakutata, llm, mcp, model-context-protocol, tools, typescript

## 简介

The MCP channel of the lakutata framework: controller actions served as the tools of a Model Context Protocol server, over stdio or HTTP.
