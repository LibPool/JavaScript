> 标签: a11y, accessibility, animation, bottom-sheet, drawer, gesture, mobile, mobile-first, navigation, pwa, react, sidebar, spring-physics, swipe, touch, typescript, zero-dependencies

## 简介

Gesture driven React sidebar with spring physics. Touch and mouse support, native app feel for mobile first web interfaces. Tiny bundle, zero runtime dependencies.
