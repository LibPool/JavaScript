# @meir-labs/agent-research-analyst

> 标签: agents, claude, claude-code, competitive-analysis, meirlabs, research, subagent

## 简介

A Claude Code subagent that maps a market and watches the competition — builds a sourced market map (segments, competitors, positioning, pricing), then diffs against it on repeat runs and briefs only what changed. npx installs the agent definition into .c
