# @leanroute/langchain

> 标签: anthropic, chat-model, langchain, langchain-integration, leanroute, llm-gateway, openai

## 简介

LangChain integration for Leanroute. Drop-in `ChatLeanroute` chat model — same interface as `ChatOpenAI`, but routes across 13 LLM providers (OpenAI, Anthropic, Google, DeepSeek, Groq, xAI, and more) with cost caps, failover, and MCP support baked in.
