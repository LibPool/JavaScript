# @trackit.io/shopify-cart

> 标签: cart, ecommerce, graphql, headless, react, shopify, ssr, storefront

## 简介

Production-ready Shopify Storefront Cart API library with optimistic updates, complete Cart API coverage, and zero-config React integration for Next.js, React Router, TanStack Start, Expo, and Vite
