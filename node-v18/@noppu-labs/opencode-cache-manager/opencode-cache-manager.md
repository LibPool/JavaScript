# @noppu-labs/opencode-cache-manager

> 标签: anthropic, bun, cache-keepalive, cache-ttl, claude, keepalive, opencode, opencode-plugin, prompt-caching, tui, typescript

## 简介

Anthropic prompt-cache manager for OpenCode V2: per-session 5m / 1h / hybrid TTL, keepalive pings for idle sessions, and a sidebar cache status
