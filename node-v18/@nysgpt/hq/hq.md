# @nysgpt/hq

> 标签: claude, claude-code, cost, dashboard, mcp, observability, tokens, transcripts

## 简介

Localhost observability + control layer for Claude Code — live transcript mirror, token & cost accounting, cross-repo search, two-way session channel. Disk is the database: no DB, no auth, no telemetry.
