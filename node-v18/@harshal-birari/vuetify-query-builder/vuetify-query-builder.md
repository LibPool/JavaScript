# @harshal-birari/vuetify-query-builder

> 标签: filter, query, query-builder, vue, vue3, vuetify

## 简介

The query builder can be used by simply importing the component and using inside a vue component:  ```vue <template>   ...   <query-builder v-model="filter" :filter-fields="filter_fields" :color="color">   </query-builder>   ... </template>
