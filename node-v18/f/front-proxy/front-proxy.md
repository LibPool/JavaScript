# front-proxy

> 标签: ai-agents, claude-code, cli, etc-hosts, hosts, https, local-domain, localhost, mcp, mcp-server, mkcert, model-context-protocol, proxy, reverse-proxy

## 简介

Map/link custom local domains to apps running on local ports, at the OS level. Includes an MCP server so code assistants can manage the domains.
