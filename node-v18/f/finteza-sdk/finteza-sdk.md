# finteza-sdk

> 标签: analytics, finteza, proxy, statistics, tracking

## 简介

The official sdk for sending events to Finteza servers and proxying analytical requests via the website.

- 官网：https://www.finteza.com
- 源码仓库：git+https://github.com/finteza/web-sdk-nodejs.git
- npm 页面：https://www.npmjs.com/package/finteza-sdk
