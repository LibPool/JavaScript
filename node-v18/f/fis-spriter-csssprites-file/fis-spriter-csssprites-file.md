# fis-spriter-csssprites-file

> 标签: css, csssprites, fis, gif, jpeg, node-images, node-pngcrush, png, pngcrush

## 简介

基于fis的csssprite，支持分组合并图片，@media处理，合并路径指定，为每个文件分配不同的属性
