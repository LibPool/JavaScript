# frida-python-bridge

> 标签: bridge, cpython, frida, frida-gum, frida-gum-bridge, instrumentation, python, reverse-engineering

## 简介

A Frida module to introspect and drive a live CPython interpreter at runtime (the CPython analog of frida-il2cpp-bridge / frida-java-bridge).
