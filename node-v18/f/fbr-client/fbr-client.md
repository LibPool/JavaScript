# fbr-client

> 标签: arraybuffer, buffer, buffers, chunkifier, data-channels, datachannel, file, file-buffer, file-reading, file-sharing, fragmenter, javascript, javascript-library, library, muaz, muaz-khan, webrtc, webrtc-experiment

## 简介

FileBufferReader is a JavaScript library reads file and returns chunkified array-buffers. The resulting buffers can be shared using WebRTC data channels or socket.io. Share files same as Skype do!
