# fontana

> 标签: JavaScript

## 简介

Tool for building custom icon font. Generates fonts ttf, woff, woff2 and eot from svg icons. Specimen is generated as html page - for correct work needs some http server (e.g. https://www.npmjs.com/package/http-server).
