# finnish-trade-mcp-server

> 标签: apify, claude, customs, exports, finland, foreign-trade, imports, mcp, model-context-protocol, open-data, trade-statistics, tulli

## 简介

Open bridge to the hosted Finnish Foreign Trade (Tulli) MCP server on Apify — query Finnish import/export statistics by commodity, country and period from any MCP client using your own Apify API token.
