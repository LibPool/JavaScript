# flashcard-mcp

> 标签: claude, flashcard, fsrs, mcp, spaced-repetition

## 简介

MCP server for Memento Note (flashcard) app — proxies deck/card CRUD, FSRS-5 review, and stats to the macOS app via Unix Domain Socket
