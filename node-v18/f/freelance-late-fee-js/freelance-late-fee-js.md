# freelance-late-fee-js

> 标签: cli, freelance, invoice, late-fee, npx, zero-dependencies

## 简介

Compute the late fee owed on an overdue freelance invoice and which reminder stage to send. Zero dependencies, runs via npx straight from GitHub.
