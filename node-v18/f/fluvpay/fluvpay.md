# fluvpay

> 标签: fluvpay, gateway, pagamentos, payments, pix, sdk

## 简介

SDK oficial da FluvPay para Node.js e TypeScript. Cobrancas PIX, saques, transferencias internas e verificacao de webhooks.

## 官网

- 官网：https://docs.fluvpay.com
- npm 页面：https://www.npmjs.com/package/fluvpay

- npm 安装：`npm install fluvpay`
- npm registry：https://registry.npmjs.org/fluvpay
- Node 要求：>=18
