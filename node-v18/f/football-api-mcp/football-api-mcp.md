# football-api-mcp

> 标签: ai, chatgpt, claude, football, football-api, live-scores, mcp, mcp-server, model-context-protocol, odds, soccer, soccer-api, sports-data

## 简介

MCP server for the 5DollarFootballAPI — give Claude, ChatGPT or Cursor live football scores, fixtures, standings, odds and full odds movement history (stdio + Streamable HTTP)
