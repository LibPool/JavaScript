# fingular-swagger-graphql

> 标签: JavaScript

## 简介

``` npx fingular-swagger-graphql <SPEC-URL> -o <OUTPUT_FILE> ``` or ``` npx fingular-swagger-graphql <SPEC-JSON-FILE> -o <OUTPUT_FILE> ``` ### example: ``` npx fingular-swagger-graphql http://0.0.0.0:8901/modelspec -o result2.graphql ```
