# fhir-location-status

> 标签: JavaScript

## 简介

&gt;fhir-location-status&lt; adds status of the location to page.  This component is a coded concept and hence the value set is hardcoded as per FHIR standard-maturity level 3.   Uses select to choose options.   In typical use, just use &gt; fhir-location
