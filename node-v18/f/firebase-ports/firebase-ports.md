# firebase-ports

> 标签: ci, detox, emulators, firebase, firebase-emulator, ports, testing

## 简介

A localhost daemon that hands each caller its own isolated Firebase emulator sandbox — pool-assigned ports, fresh data, reaped when the caller exits. No port collisions, no shared instances, no pkill.
