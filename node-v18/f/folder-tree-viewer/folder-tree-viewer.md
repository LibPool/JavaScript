# folder-tree-viewer

> 标签: Command line utility, Directory listing, Directory tree, File hierarchy, File system viewer, Folder navigation, Folder structure, Node.js tool, Path structure, Tree structure display

## 简介

Folder Tree Viewer is a Node.js utility that displays the structure of files and directories in a tree-like format in the command line interface.
