# find-dep-breakpoint

> 标签: breakpoint, cli, dependencies, dependency, dependency analyzer, dependency removal, finder, minimal upgrade, npm, npm audit, package resolution, security, supply chain, transitive dependency, upgrade path, version, version finder, vulnerability

## 简介

Find the earliest parent package version where a target (direct or transitive) dependency is removed or reaches a required minimum version.
