# flexible-persian-datepicker

> 标签: calendar, datepicker, jalali, persian, persian-datepicker, react, react-datepicker, rtl, shamsi, solar-hijri, typescript

## 简介

Flexible, responsive Jalali (Solar Hijri) datepicker for React with editable inputs, custom formats, disabled ranges and bundled Persian font.
