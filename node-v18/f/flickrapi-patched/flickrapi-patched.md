# flickrapi-patched

> 标签: api, flickr, flickrapi, oauth

## 简介

A Node.js, and client-side, implementation of the Flickr API (for use with an API key, server-side oauth enabled). This is a patched version to use until JSON parsing error is fixed in master version.
