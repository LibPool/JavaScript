# formodel

> 标签: builder, fluent, form, form-builder, form-config, forms, framework-agnostic, model, schema, type-safe, typed, typescript, ui

## 简介

Typed, model-seeded fluent builder that turns a plain data model into a strongly-typed UI form config. Framework-agnostic TypeScript — no runtime dependencies.
