# folyn-extension-dev-skill

> 标签: agent, create-folyn-extension, extension, folyn, publish, scaffold, skill

## 简介

Code-Agent skill for developing Folyn extensions end to end: scaffold with create-folyn-extension, build contribution points against folyn-extension-sdk, and publish to the Folyn extension store (GitHub Releases + catalog.json).
