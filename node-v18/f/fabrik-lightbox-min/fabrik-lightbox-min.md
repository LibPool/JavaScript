# fabrik-lightbox-min

> 标签: JavaScript

## 简介

Lightbox based on top of Magnific. Can display inline HTML, iframes (YouTube video, Vimeo, Google Maps), or an image gallery. Animation effects are added with CSS3 transitions. For jQuery or Zepto.
