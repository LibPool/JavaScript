# flowsnap-mcp

> 标签: browser-automation, claude, claude-code, debugging, flow-recorder, mcp, modelcontextprotocol

## 简介

MCP server exposing browser flows recorded by the FlowSnap Chrome extension — steps, console errors, network calls and screenshots — to Claude Code.
