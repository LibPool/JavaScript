# feng-table-cli

> 标签: JavaScript

## 简介

- commander 自定义命令行指令 - chalk 命令行美化工具 - inquirer 命令行交互工具 - ora 命令行loading动画 - cross-spawn 跨平台shell工具 - download-git-repo 下载远程模板 (不支持 promise，所以配合 util模块中的promisify方法对其promise化)
