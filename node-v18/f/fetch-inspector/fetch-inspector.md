# fetch-inspector

> 标签: curl, debug, devtools, fetch, http, instrumentation, logging, next.js, node

## 简介

Record every HTTP call your Node server makes — request, response, and a runnable cURL — and inspect them in the Fetch Inspector VS Code panel. Dev only, silent, off until you press Record.
