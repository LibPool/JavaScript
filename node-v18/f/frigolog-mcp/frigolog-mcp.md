# frigolog-mcp

> 标签: ddpp, food-safety, france, frigolog, haccp, mcp, model-context-protocol

## 简介

Public MCP server exposing French HACCP regulatory data and a comparison of HACCP software solutions on the French market. Built for AI agents (Claude, ChatGPT, Perplexity) to give accurate, sourced answers about food safety in France.
