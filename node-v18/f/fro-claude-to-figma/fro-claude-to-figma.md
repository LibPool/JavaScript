# fro-claude-to-figma

> 标签: ai, claude, claude-code, design, figma, figma-plugin, mcp, model-context-protocol, websocket

## 简介

Bridge your own Claude Code to your own Figma. Claude designs real nodes on your canvas via an MCP server + a localhost WebSocket relay + a Figma plugin. No accounts, no cloud, localhost-only.
