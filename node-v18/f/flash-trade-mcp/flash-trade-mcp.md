# flash-trade-mcp

> 标签: ai-agent, defi, ephemeral-rollup, flash-trade, magicblock, mcp, model-context-protocol, perpetual-futures, solana, trading

## 简介

MCP server for Flash Trade V2 — a Solana perpetuals DEX on a MagicBlock Ephemeral Rollup. Typed tools for accounts (baskets + deposit ledger), two-chain trading, and unsigned transaction building.
