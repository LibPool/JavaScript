# fluxdots-mcp

> 标签: agent, ataxx, board-game, claude, elo, game, mcp, model-context-protocol, modelcontextprotocol

## 简介

MCP server for FluxDots (fluxdots.com) — your agent plays ranked board-game matches against humans on a shared Elo ladder. Zero dependencies.
