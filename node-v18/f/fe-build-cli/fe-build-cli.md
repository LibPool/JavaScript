# fe-build-cli

> 标签: build, cli, deploy, dingtalk, frontend, git, ssh, stash

## 简介

前端项目打包部署 CLI 工具，支持多服务器部署、分支管理、回滚、钉钉通知、智能处理本地改动等功能
