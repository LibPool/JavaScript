# fe-publish-ssh

> 标签: JavaScript

## 简介

使用 node-ssh 模块，实现一条命令，自动打包（自动执行 npm run build）并将打包文件快速更新到服务器对应路径，可用于快速发布；支持错误回滚及多环境配置。
