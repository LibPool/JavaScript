# fast-qjs

> 标签: Fast api generate, lowcode, qjs

## 简介

**qjs**是一个基于**fastify**实现的轻量框架，通过使用`约定式`来进行api的快速生成，如果你想快速使用nodejs进行`RESTful API`开发，那么**qjs**是一个非常不错的选择
