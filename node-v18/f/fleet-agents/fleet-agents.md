# fleet-agents

> 标签: agents, ai, claude, claude-code, git-worktree, parallel, tmux

## 简介

Run multiple Claude Code agents in parallel, each in its own git worktree — tmux on macOS/Linux/WSL, separate terminal windows on Windows.
