# figpea-mcp

> 标签: adobe-xd, ai-agent, claude, design, figma, figpea, llm, mcp, mcp-server, model-context-protocol, psd, svg

## 简介

MCP server for AI agents to open, inspect, and export PSD, Adobe XD, Figma, SVG & PDF files in a live Figpea editor — runs locally over stdio, files never leave your machine.
