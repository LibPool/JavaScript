# fakegps

> 标签: cli, cross-platform, developer, fakegps, gps, gui, ios, iphone, location, mock, pymobiledevice3, spoof, virtual

## 简介

FakeGPS - Cross-platform iPhone virtual GPS location tool via USB. Set fake GPS location on iPhone without jailbreak or Xcode. Supports macOS and Windows.
