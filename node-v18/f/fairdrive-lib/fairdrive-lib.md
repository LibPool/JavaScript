# fairdrive-lib

> 标签: JavaScript

## 简介

Fairdrive lib is a javascript library to connect any (d)app to Fairdrive. It gives the (d)app a Userobject (username, avatar) and a private key with which the (d)app can write data in the user's Fairdrive.
