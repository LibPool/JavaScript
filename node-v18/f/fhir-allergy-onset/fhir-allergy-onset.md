# fhir-allergy-onset

> 标签: JavaScript

## 简介

&lt;fhir-allergy-onset&gt; adds allergy onset date to the page. Uses input type datetime in mm/dd/yyyy hh:mm:ss format  * In typical use, just use &lt;fhir-allergy-onset url=""/fhir-allergy-onset&gt;
