# format-converter

> 标签: avif, browser, canvas, converter, format, jpeg, jpg, pdf, png, resize, webp

## 简介

Lightweight browser-side image format conversion: WebP, PNG, JPEG, AVIF, PDF — with optional resize. Works with any framework.
