# font-proof-mcp

> 标签: font-proofing, fonts, glyphs, mcp, model-context-protocol, type-design, typography

## 简介

MCP server launcher for Hellbox (formerly Font Proof), the macOS font proofing app. Lets AI tools create and edit .fontproof documents.

## 官网

- 官网：https://hellbox.com
- 源码仓库：git+https://github.com/jakefleming/font-proof-mcp.git
