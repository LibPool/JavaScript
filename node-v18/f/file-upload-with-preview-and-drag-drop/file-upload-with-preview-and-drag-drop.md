# file-upload-with-preview-and-drag-drop

> 标签: bootstrap, file, image, preview, upload, uploader

## 简介

A simple file-upload utility that shows a preview of the uploaded image. Written in pure JavaScript. No dependencies. Works well with Bootstrap 4 or without a framework. Forked from file-upload-with-preview by John Datserakis <johndatserakis@gmail.com>
