# fastsearch-client

> 标签: agent, bm25, function-calling, hybrid-search, langchain, llm, rag, search, tool-use, vector-search

## 简介

Zero-dependency TypeScript SDK for the fastsearch REST API — hybrid search over docparse chunks, with first-class helpers for LLM agent development (tool definitions, RAG context, retrievers).
