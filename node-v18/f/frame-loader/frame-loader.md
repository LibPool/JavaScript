# frame-loader

> 标签: IFrameLoader, iframe, pageloader, react-iframe.js

## 简介

React Frame loader component allows you to load external webpages in your web application. In addition to just add webpages it provides choice to add loading animations till the time imported webpage loads in your webpage.
