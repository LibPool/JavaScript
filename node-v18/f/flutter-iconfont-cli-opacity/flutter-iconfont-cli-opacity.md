# flutter-iconfont-cli-opacity

> 标签: flutter, flutter-iconfont, icon, iconfont, iconfont.cn, icons

## 简介

用纯JS把iconfont.cn的图标转换成Flutter Widget，不依赖字体，支持多色彩
