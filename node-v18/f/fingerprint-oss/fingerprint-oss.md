> 标签: audio-fingerprint, browser-fingerprint, canvas-fingerprint, device-detection, device-fingerprint, fingerprinting, font-detection, identification, privacy, security, system-info, tracking, user-agent, web-analytics, webgl-fingerprint

## 简介

A comprehensive JavaScript library for device fingerprinting and system information collection. Provides robust, deterministic fingerprinting for web applications with privacy-conscious design.
