# file-to-mongodb-cli

> 标签: CSV to MongoDB, Command-Line Tool, Data Import Tool, Excel to MongoDB, JSON to MongoDB, Large File Handling, MongoDB Import, Node.js CLI

## 简介

Node.js command-line interface (CLI) tool designed to easily import data within chunks from large files, such as Excel, CSV, or JSON, into a MongoDB collection
