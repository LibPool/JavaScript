# fastcgi-server

> 标签: fastcgi, http, server

## 简介

A FastCGI server implementing an API similar to node's HTTP server. Nice for fast switching HTTP -> FCGI.

- 源码仓库：https://github.com/davidfoliveira/node-fastcgi-server
