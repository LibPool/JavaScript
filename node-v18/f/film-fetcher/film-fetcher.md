> 标签: api, cinema, cli, csv, data-fetching, database, entertainment, excel, export, film, imdb, json, movie-database, movies, omdb, research, sql, tmdb

## 简介

A comprehensive CLI tool to fetch movie data from multiple APIs (OMDB, TMDB, IMDB) and export to JSON, CSV, Excel, SQL formats with advanced filtering and enrichment capabilities
