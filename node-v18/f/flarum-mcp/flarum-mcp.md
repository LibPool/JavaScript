# flarum-mcp

> 标签: ai, claude, flarum, forum, mcp, model-context-protocol, reverser.id

## 简介

MCP server for Flarum forums — search, read, and post discussions from any MCP client (Claude Code, Claude Desktop). Ships preconfigured for reverser.id.
