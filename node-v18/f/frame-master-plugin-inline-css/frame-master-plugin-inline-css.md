# frame-master-plugin-inline-css

> 标签: build, css, fouc, frame-master, html, inline, plugin

## 简介

Frame-Master plugin that inlines CSS stylesheet links into <style> tags during the build finally HTML hook to prevent FOUC / style flicker.
