# fold-ng

> 标签: a11y, accessible, angular, angular-22, angular-components, angular-ui, component-library, css-variables, dark-theme, design-system, design-tokens, dialog, overlay, signals, signals-first, ssr, standalone, theme, theming, ui-components, ui-library, wcag, zoneless

## 简介

Accessible, dark-first Angular 22 UI component library & design system — signals-first, standalone, zoneless, SSR-ready. Design tokens + WCAG-minded components, themeable to the bone.
