# factorymap-map

> 标签: JavaScript

## 简介

FactoryMap 是一个基于 **Fabric.js（Canvas）** 的“工厂/场景地图编辑器”示例项目，提供矩形/圆形站点、文字、图片与路线（连接线）等基础能力，并将画布交互与业务表单解耦：业务层只需要面向 `Map` 的 API 操作，不需要直接接触 Fabric 对象。
