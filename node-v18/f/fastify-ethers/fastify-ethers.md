# fastify-ethers

> 标签: binance-smart-chain, bsc, eth, ethereum, ethers, ethersjs, fastify, fastify-plugin, fastifyjs, matic, polygon

## 简介

fastify-ethers is a plugin for the Fastify framework that provides EVM utilities for fastify based on ethers.js.
