# foldkit-sidenav

> 标签: effect, elm-architecture, foldkit, navigation, rail, sidebar, sidenav

## 简介

Grouped side navigation for Foldkit: task groups that expand in place, an icon rail with an overlay, and a full mode for phone drawers.
