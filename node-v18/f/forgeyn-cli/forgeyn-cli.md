# forgeyn-cli

> 标签: baas, cli, forgeyn, mcp, postgres, supabase

## 简介

Forgeyn Base CLI — manage your Forgeyn Base account from the terminal: projects, orgs, SQL, gateway apps and API keys. Like the Supabase CLI, but for Forgeyn Base.
