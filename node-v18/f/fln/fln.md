# fln

> 标签: agent, ai, cli, codebase, codebase-context, compiler, context, json, llm, llm-context, markdown, mcp, model-context-protocol, prompt, rag

## 简介

A local, explainable context compiler for AI coding agents. Analyze, plan, and emit optimal context — with diagnostics. Retrieval without embeddings, context without a server.
