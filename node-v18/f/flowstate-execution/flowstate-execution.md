> 标签: async, cloud-functions, database-storage, deno, edge-functions, execution, fetch, firebase, flow-control, javascript, library, mysql, node, pause, postgresql, quickjs, redis, resume, serverless, sqlite, state-management, supabase

## 简介

Production-grade React-free JavaScript execution library with automatic pause/resume on fetch calls and custom database storage. Built for edge functions, serverless environments, and any JavaScript runtime. Optimized for Deno and Node.js execution.
