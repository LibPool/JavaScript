# fullstack-react-ssr-app-template

> 标签: axios, express, front-end, react, redux, route, scaffold, server-side-rendering, ssr, template, typescript, webpack

## 简介

This repository is a full-stack sample web application based on React+TypeScript+Babel+Webpack+Jest (+Redux+Express) that creates a simple whole-website architecture with Server-Side Rendering (SSR).
