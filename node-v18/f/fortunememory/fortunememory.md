# fortunememory

> 标签: agent, memory, opencode, sqlite, vector-search

## 简介

Mémoire durable locale pour agents : search hybride (lexical + vectoriel RRF), conflits, contextes attribués. Zéro réseau par défaut, provider sqlite natif.
