# fabric-browserify

> 标签: HTML5, SVG, canvas, graphic, graphics, node-canvas, object model, parser

## 简介

Object model for HTML5 canvas, and SVG-to-canvas parser. Version without server support.

- 官网：http://fabricjs.com/
- 源码仓库：https://github.com/exine/fabric-browserify
- npm 页面：https://www.npmjs.com/package/fabric-browserify

- npm registry：https://registry.npmjs.org/fabric-browserify
