# feedme-mcp

> 标签: claude-code, crm, feedme, feedmeet, mcp, model-context-protocol

## 简介

MCP server da Rede FeedMe: opera o CRM (projetos, equipe, tarefas, financeiro), lê reuniões do FeedMeet e publica HTML, direto do Claude Code sem acesso ao código.
