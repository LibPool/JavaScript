# filestab

> 标签: cordis, deepseek-harness, dsh, file-browser, files, git, jj, plugin

## 简介

Read-only, session-workspace-scoped VCS file viewer for the dsh web GUI — its own Filestab tab in the right column, alongside the built-in file browser (generic connection.rpc host channel + web client).
