# freightutils-mcp

> 标签: adr, air-freight, calculator, cbm, customs, dangerous-goods, freight, hs-codes, iata, incoterms, ldm, logistics, mcp, model-context-protocol, road-freight, sea-freight, shipping, transportation, unlocode

## 简介

Neutral freight reference + validation layer for AI agents — ADR dangerous goods, HS codes, airlines, airports, UN/LOCODE, Incoterms, identifier validation and freight math. Every tool declares a typed output schema and returns a source-cited response env
