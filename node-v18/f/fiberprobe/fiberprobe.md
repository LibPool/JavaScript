# fiberprobe

> 标签: ckb, fiber, fnn, htlc, lightning, nervos, payment-channel, probing, sdk, typescript

## 简介

TypeScript SDK for Fiber Network Node (FNN) — typed RPC client, static route estimation, live HTLC-based liquidity probing, inbound capacity checks, and event-driven payment lifecycle.
