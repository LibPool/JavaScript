# figma-to-cocos

> 标签: cocos, cocos-creator, converter, design-to-code, figma, prefab, ui

## 简介

Convert Figma designs to Cocos Creator 2.x prefabs. Supports _merge auto-export, btn_ Button component, common/custom asset splitting, invisible node preservation.

## 官网

- npm 页面：https://www.npmjs.com/package/figma-to-cocos
