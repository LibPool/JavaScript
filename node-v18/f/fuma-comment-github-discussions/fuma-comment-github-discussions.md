# fuma-comment-github-discussions

> 标签: comments, fuma-comment, fumadocs, giscus, github-discussions, next

## 简介

Store fuma-comment comments in GitHub Discussions — a storage + auth adapter so a fuma-comment UI is backed by GitHub Discussions (readers sign in with their own GitHub account), no database required.
