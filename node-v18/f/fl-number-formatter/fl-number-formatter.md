# fl-number-formatter

> 标签: JavaScript

## 简介

Number Formatter for [Angular](http://angular.io); Transforms the number into human readable format when in Thousands, Millions and Billions. * 37474 -> 37.5K * 1222130 -> 1.2M * 12414770 -> 12.4M * 19121364128 -> 19.1B
