# framethrower-ai

> 标签: ai-agents, api, cinematography, creative-tools, film, film-frames, frames, framethrower, lookbook, mcp, mcp-server, moodboard, movie-stills, previs, sdk, search, shot-list, storyboard, visual-reference, visual-search

## 简介

Official client for the FrameThrower API — a film stills database of 5,489 films, indexed frame by frame on lighting, lens, shot size, colour and mood. Search in plain language, by image, or by colour.
