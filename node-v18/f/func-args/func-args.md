# func-args

> 标签: args, arguments, arrow, arrow-function, arrows, async, dependency, deps, extract, fn, func, function, function-arguments, generator, generators, get, inject, injectors, parameters, params, parse, regular, tostring, useful

## 简介

ECMAScript Function Arguments parser, Get arguments of a function, useful for and used in dependency injectors. Works for regular functions, generator functions and arrow functions.
