# frontmatter-matters

> 标签: ast, code-analysis, frontmatter, llm, mcp, sidecar, tree-sitter

## 简介

Auto-generate code metadata sidecars for LLM-optimized navigation. No AST dumps, no embeddings — just structured YAML.
