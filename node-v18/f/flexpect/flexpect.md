# flexpect

> 标签: automation, css, design-validation, frontend, headless-browser, layout, pixel-perfect, playwright, responsive, testing, tooling, ui-testing, viewport, visual-regression, web-testing

## 简介

Automated layout validation tool using Playwright. Ensures responsive design accuracy across multiple viewports by inspecting element positions and visual alignment.
