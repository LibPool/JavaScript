# fastmcp-backlog-server

> 标签: JavaScript

## 简介

BacklogのAPIと連携するModel Context Protocol (MCP) サーバーです。このプロジェクトは、AI アシスタントがBacklogのプロジェクト管理システムと対話できるようにするためのインターフェースを提供します。
