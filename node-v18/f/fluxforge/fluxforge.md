# fluxforge

> 标签: MD5, Web Workers, chunk upload, client-side, concurrent upload, file, file chunk, file upload, resumable upload, upload progress, 上传进度, 上传重试, 分块上传, 大文件上传, 并发上传, 文件上传, 文件分片, 文件切片, 文件哈希, 文件处理, 断点续传

## 简介

基于 Web Worker 的文件分片库，提供并发处理、可暂停/取消任务控制、自动重试与 MD5 校验。
