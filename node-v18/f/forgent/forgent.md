# forgent

> 标签: agent, ai, claude, claude-code, codex, copilot, cursor, prompts, registry, shadcn, skills

## 简介

shadcn-style installer for AI agent skills. Pick from a remote registry and copy the source into your agent's local skills directory (Claude Code, GitHub Copilot, OpenAI Codex CLI, or Cursor). You own the copy.
