# fast-feed

> 标签: atom, feed, rapidxml, rss, syndication, xml

## 简介

Node.JS module for parsing newsfeeds (RSS 2 and Atom). It should be one of the fastest feed parsers. Uses [RapidXML](http://rapidxml.sourceforge.net/).
