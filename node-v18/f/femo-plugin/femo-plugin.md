# femo-plugin

> 标签: deepseek-harness, dsh, dsh-plugin, femo, multi-agent, orchestration, script

## 简介

femo (Flow Emerges Mag Opus) — 用写剧本的方式编排多智能体世界。dsh 插件版：引擎、桥接器、可视化编辑器全在一个文件夹里，自包含，整个文件夹搬走即用。
