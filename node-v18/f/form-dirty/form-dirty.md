# form-dirty

> 标签: beforeunload, changed-fields, dirty, form, unsaved-changes, zero-dependency

## 简介

Unsaved changes detection. Snapshot form state, expose isDirty + changedFields, handle beforeunload. Framework agnostic. Zero dependencies.
