# fs-cachebox

> 标签: cache, cache-manager, disk-cache, file, file-cache, filebase, filesystem, fs-cache, key-value, lightweight-cache, local-cache, node-cache, nodejs, persistent-cache, storage

## 简介

A lightweight file-based caching library for Node.js. Stores key-value data on the filesystem with optional TTL support.
