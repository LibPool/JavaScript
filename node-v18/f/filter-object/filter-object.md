# filter-object

> 标签: arr, array, expand, filter, find, function, glob, globbing, globs, key, keys, match, matcher, minimatch, obj, object, order, pattern, patterns, sort, wildcard

## 简介

Filter an object by its keys or values. Returns a copy of an object filtered to have only keys or values that match the given glob patterns.
