# featherpic

> 标签: GraphicsMagick, compess, gm, image, lightweight, microservice, node, npm, picture, server, webp

## 简介

Lightweight npm package to compress images to webp format using GraphicsMagick. Perfectly fits for compressing images that users upload to your web app.
