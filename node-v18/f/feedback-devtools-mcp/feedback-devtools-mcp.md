# feedback-devtools-mcp

> 标签: bug-reports, claude-code, cursor, devtools, feedback, mcp, model-context-protocol

## 简介

MCP server exposing the Feedback DevTools backlog to a developer's own IDE agent (Cursor / Claude Code / Windsurf) — reads feedback context and marks items resolved, no hosted agent or stored GitHub push token required.
