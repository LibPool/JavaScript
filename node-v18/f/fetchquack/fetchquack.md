# fetchquack

> 标签: angular, bun, client, deno, duck, event-source, fetch, http, node, quack, server-sent-events, sse, stream, streaming, typescript

## 简介

A lightweight HTTP client with support for streaming, SSE, progress monitoring and interceptors. Works in the browser, Node.js, Bun and Deno. Includes an Angular wrapper.
