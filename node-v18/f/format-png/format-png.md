# format-png

> 标签: animated-png, animation, apng, chunks, compression, decoder, encoder, exif, icc, image, metadata, optimize, png, wasm, webassembly

## 简介

A fast, lossless PNG and APNG decoder and encoder for the browser and Node, compiled from Rust to WebAssembly: every color type and bit depth, animated PNG, metadata, chunk inspection, palette optimization and chunk stripping.
