# fsa1-cli

> 标签: agents, cli, excel, filesystem, spreadsheet, xlsx

## 简介

Command line tool for FSA1: read and edit spreadsheets as a file tree. Tabs are folders, cells are files.

## 官网

- 官网：https://fsa1.sh
- 源码仓库：git+https://github.com/fredrikolis/FSA1.git
