# fragment-bohd4n-api

> 标签: JavaScript

## 简介

A modern asynchronous Node.js wrapper for the [Fragment API](https://fragment.bohd4n.dev/docs), allowing you to send Telegram Stars and purchase Telegram Premium for users programmatically.
