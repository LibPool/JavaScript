# formulakit

> 标签: arithmetic, calculator, evaluator, expression, formula, math, parser, safe-eval, typescript, variables, zero-dependencies

## 简介

Zero-dependency safe arithmetic expression evaluator: parse/evaluate math formulas with variables and functions, no eval(). TypeScript-first, ESM+CJS. Port of Python simpleeval / Go expr / C# DynamicExpresso.
