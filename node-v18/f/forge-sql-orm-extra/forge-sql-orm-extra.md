# forge-sql-orm-extra

> 标签: atlassian-forge, cache, drizzle, drizzle-orm, extension, forge, forge-sql, forge-sql-orm, forge-sql-orm-extension, forge-sql-orm-extra, kvs, orm, rovo

## 简介

Extension package for forge-sql-orm. Use it when you need global @forge/kvs query caching (SQL-parser cache invalidation, cache contexts, cacheable reads/writes) or Rovo integration for secure dynamic analytics. Core forge-sql-orm covers Drizzle + @forge/
