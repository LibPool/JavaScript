# find-research-papers-mcp

> 标签: ai-agent, anthropic, arxiv, claude, claude-code, literature, mcp, mcp-server, papers, research, scholar, scientific

## 简介

MCP server for scientific grounding: search and discover open-source research papers and scholarly literature via NPX. Spawns the Python package through uvx with full stdio passthrough.
