# font-slim

> 标签: JavaScript

## 简介

该工具是一个用于优化字体文件的 npm 库。它可以分析项目文件中使用的文本，并根据这些文本以及指定的字体文件，创建一个仅包含必要字形的压缩后的字体文件。
