# ffmpeg-mp3-node

> 标签: WebAssembly, audio, encoder, ffmpeg, in-memory, memfs, mp3, nodejs, pcm, server-side, wasm

## 简介

Node.js FFmpeg WASM for PCM to MP3 conversion with in-memory filesystem (memfs). Server-side audio processing without disk I/O.
