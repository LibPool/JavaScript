# ffmpeg-generator

> 标签: cli, command-line, ffmpeg, ffmpeg-automation, ffmpeg-cli, ffmpeg-generator, ffmpeg-hls, ffmpeg-node, ffmpeg-wrapper, hls, hls-streaming, media, node-cli, streaming, transcoding, video, video-encoding, video-processing, video-quality, video-transcoder

## 简介

Generate multi-resolution FFmpeg HLS commands from any .mp4 file via a smart CLI. Auto-detects streams, builds playlists, and speeds up your video pipeline.
