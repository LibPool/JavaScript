# freeman.gdpr.cookiebannersettings

> 标签: bootstrap 4, ecosystem:jquery, gdpr, jquery-plugin

## 简介

This is a jquery plugin to display a cookie acknowledgement banner with the option to control opt-in settings for browser cookies set by the application
