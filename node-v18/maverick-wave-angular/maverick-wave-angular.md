# maverick-wave-angular

> 标签: angular, components, forms, maverick-wave, signals, ui

## 简介

Angular components for the MaverickWave CSS framework - dialogs, forms, toasts, header, kanban and more, rendering the same mw-* markup as maverick-wave-astro.
