# @corefra/sdk

> 标签: ai, captions, corefra, drm, live, sdk, streaming, video, vod, watermark

## 简介

Official TypeScript SDK for CoreFra — live streaming, DRM-protected VOD, AI captions + dubbing, forensic watermarking. Works in Node, Bun, Deno, Edge runtimes, and browsers.
