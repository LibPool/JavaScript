# @agentegrity/openai-agents

> 标签: agent, agentegrity, observability, openai, openai-agents, security

## 简介

Zero-config agentegrity adapter for the OpenAI Agents JS SDK (@openai/agents). Mirrors the Python agentegrity.openai_agents module.
