# @jvidalv/react-analytics

> 标签: analytics, expo, next.js, react, react-native, react-router, tracking, universal

## 简介

A universal analytics library for any React application (web, React Native, Expo, Next.js). Plug and play with automatic navigation tracking, built-in storage adapters, and support for multiple routers.
