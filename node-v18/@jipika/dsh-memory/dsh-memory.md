# @jipika/dsh-memory

> 标签: context, deepseek-harness, dsh, dsh-plugin, long-term-memory, memory

## 简介

Progressive long-term memory for DSH: sharded markdown bodies under ~/.dsh/memory/topics/, with only a live-generated index (shard · count · path · per-entry line numbers) injected into the system prompt — so the prompt cost stays flat however large the m
