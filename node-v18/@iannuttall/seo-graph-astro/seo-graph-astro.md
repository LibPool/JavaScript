# @iannuttall/seo-graph-astro

> 标签: JavaScript

## 简介

Astro layer for @iannuttall/seo-graph-core: build integration for agent markdown + llms.txt + manifests, collection markdown endpoints, schema endpoints, IndexNow key route, Cloudflare content negotiation.
