# @crazygl/hero-textfill

> 标签: animation, canvas, component, crazygl, fill, frontend, hero, hero-section, interactive, landing-page, progress, react, textfill, three, typography, ui, webgl

## 简介

Text Fill — Headline that fills bottom-up with a progress colour — like a loading bar disguised as type. The fill loops 0 → 100% on a configurable cycle. A customizable CrazyGL animated hero section — WebGL, React, drop-in.
