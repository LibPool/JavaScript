# nulltick-mcp

> 标签: game-development, mcp, model-context-protocol, multiplayer, nulltick, unity

## 简介

MCP server for NullTick multiplayer: gives a coding agent the feature index, the step-by-step guide, log explanations and a read-only project check, so it reuses NullTick's components instead of writing its own.
