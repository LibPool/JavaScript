# easy-onvif-web

> 标签: browser, dart, ip-camera, onvif, ptz, rtsp, wasm

## 简介

Browser ONVIF client compiled from the Dart `easy_onvif` package with dart2wasm. Uses fetch + digest auth; WS-Discovery is unavailable because browsers cannot open UDP sockets.
