# @wuipkg/tsconfig

> 标签: tsconfig

## 简介

集中管理和抽象剥离出不同运行场景中规范使用的 TypeScript 配置基线字典集合保障体系，防止业务出现由于环境差异配比产生的各种推断类型诊断失效的潜在雷点灾难。
