# @xbxie1/create-front-dev-cli

> 标签: JavaScript

## 简介

```bash # 创建并进入 demo 目录 $ mkdir demo && cd demo # 使用脚手架工具初始化项目 $ pnpm create @xbxie1/front-dev-cli # 安装需要的依赖 $ pnpm install # 启动开发服务器 $ pnpm run dev ```
