# @easy-cms/plugin-ecommerce

> 标签: cart, checkout, easy-cms, easy-cms-plugin, ecommerce, shop, stripe

## 简介

A shop for Easy CMS: products and variants, prices in several currencies, carts (guests too), checkout with Stripe or bank transfer, orders, stock, customer accounts, and React and Vue hooks (experimental)
