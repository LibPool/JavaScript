# @iflow-mcp/sqlite-bun

> 标签: JavaScript

## 简介

A Model Context Protocol (MCP) server implementation that provides database interaction and business intelligence capabilities through SQLite. This server enables running SQL queries, analyzing business data, and automatically generating business insight
