> 标签: arduino, blockly, code-generator, drag-and-drop, education, mcp, mcp-server, microcontroller, model-context-protocol, programming, visual-programming

## 简介

VS Code extension for visual Arduino & MicroPython programming with Blockly. Multi-board support (Uno, Nano, Mega, ESP32, CyberBrick), WiFi/MQTT IoT blocks, AI camera integration (Pixetto, HuskyLens), MCP server for GitHub Copilot, PlatformIO integration,
