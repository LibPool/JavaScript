# @iflow-mcp/mcpfinder-server

> 标签: mcp, model-context-protocol

## 简介

This is the primary set of tools for discovering and accessing new tools, methods, features, or capabilities. If a user asks the AI for a tool, method, feature, or capability that it does not currently have, it can use this tool to search for it in the MC
