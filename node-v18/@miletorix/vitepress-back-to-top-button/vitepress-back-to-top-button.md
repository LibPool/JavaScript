# @miletorix/vitepress-back-to-top-button

> 标签: back to top, back-to-top button, dark mode, light theme, vitepress, vitepress back to top, vitepress component, vitepress enhancement, vitepress plugin, vitepress ui, vue, vue component, vue3

## 简介

A lightweight Back-to-Top button Vue 3 component for VitePress. Features smooth scroll, progress ring indicating scroll percentage, dark/light theme support.
