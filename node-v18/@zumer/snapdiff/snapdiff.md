# @zumer/snapdiff

> 标签: antialiasing, browser-testing, client-side-testing, in-page-testing, indexeddb, no-playwright, no-puppeteer, pixel-diff, screenshot-testing, snapdom, snapshot-testing, visual-diff, visual-regression, vitest, yiq

## 简介

Client-side visual regression testing powered by snapDOM. No headless browser, no extra binaries — capture, diff and review in the page itself.
