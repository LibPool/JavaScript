# @yaotoshi/cahub-sdk

> 标签: api, cafin, cahub, sdk, typescript

## 简介

SDK TypeScript untuk muka depan API cahub — tipe di-generate dari openapi.json, error RFC 9457 terpetakan, nol dependensi runtime.
