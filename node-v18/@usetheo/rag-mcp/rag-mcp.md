# @usetheo/rag-mcp

> 标签: JavaScript

## 简介

MCP (Model Context Protocol) stdio server for TheoRag — exposes the RAG journeys (create_collection, ingest_document, retrieve, ask) as Claude tools over the @usetheo/rag-sdk.
