# @aicontextgateway/search-react

> 标签: JavaScript

## 简介

Embeddable AiContextGateway smart search bar: deterministic (no-AI) fuzzy/facet search as a React component and a self-contained <aicontextgateway-search> web component, with an optional AI answer layer.
