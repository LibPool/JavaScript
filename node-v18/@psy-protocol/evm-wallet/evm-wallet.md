# @psy-protocol/evm-wallet

> 标签: JavaScript

## 简介

EVM wallet integration for the Psy network: sign in and authorize every Psy operation (deposit, withdraw, transfer, private transfer, claim, UPS proof sessions, inbox, activity) with any EVM wallet via personal_sign — no held key, no seed phrase.
