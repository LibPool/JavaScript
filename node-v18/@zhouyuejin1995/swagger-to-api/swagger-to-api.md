# @zhouyuejin1995/swagger-to-api

> 标签: api-client, axios, codegen, fetch, openapi, swagger, typescript

## 简介

Swagger 2.0 → TypeScript API client code generator. Pulls a Swagger doc (URL or file), emits typed request functions + DTOs into your project.
