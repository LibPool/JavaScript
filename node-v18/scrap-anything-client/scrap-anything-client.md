# scrap-anything-client

> 标签: client, headless, scraper, scraping, web-scraping

## 简介

Client for the scrap-anything API: schedule a scrape, wait for it or get a signed webhook, get the rendered HTML or the downloaded file. Retries safely, never schedules a job twice. No dependencies (fetch, WebCrypto).
