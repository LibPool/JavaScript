# @wecity/mp-rate-limiting

> 标签: JavaScript

## 简介

提供给微信小程序的前端限流 SDK，通过限流配置对 wx.request/wx.cloud.callContainer 进行前置拦截，从而对后端网关进行特殊时期的保护。
