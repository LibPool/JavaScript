# @michelangelo-land/sdk

> 标签: api-client, fetch, michelangelo-land, oauth2, openapi, pkce, sdk, typescript

## 简介

Official Michelangelo Land SDK — dynamic OAuth 2.1 + PKCE auth with in-memory tokens (opt-in persistence) and a typed client generated from the OpenAPI contract (api.michelangelo.land/v1/openapi.json).
