# @jalipata/mcp-memory

> 标签: ai, ai-memory, knowledge-graph, mcp, memory, model-context-protocol, sqlite

## 简介

Agnostic persistent memory server for AI tools via MCP. Knowledge graph stored in SQLite with FTS5 keyword search, multi-tenant by namespace.
