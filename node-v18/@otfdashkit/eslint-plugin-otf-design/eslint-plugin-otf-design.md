# @otfdashkit/eslint-plugin-otf-design

> 标签: design-system, design-tokens, eslint, eslint-plugin, eslintplugin, otfdashkit, tailwind

## 简介

ESLint rules for OTF design-system compliance. Bans hex literals and default Tailwind palette classes (gray/blue/etc.) so feature code uses tokens from @otfdashkit/tokens.
