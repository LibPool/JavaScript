# @material-index/mi-uploader

> 标签: claude, material-index, mcp, modelcontextprotocol, upload

## 简介

Local MCP server that streams a local file to a Material Index signed upload URL, so Claude Desktop can bulk-attach images and documents to assets without sending the file bytes through the model context.
