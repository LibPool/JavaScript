# resilio-resilience

> 标签: api, backoff, circuit-breaker, fallback, fault-tolerance, fetch, idempotency, resilience, retry, timeout

## 简介

Wrap any API call with timeout, retry with backoff, a per-service circuit breaker and your own fallback. Zero dependencies.
