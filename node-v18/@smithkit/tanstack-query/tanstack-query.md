# @smithkit/tanstack-query

> 标签: JavaScript

## 简介

Thin wrapper around @tanstack/react-query for typed GET/POST/PATCH/PUT/DELETE requests with global middleware, headers, pagination, and key tracking. Works in React and React Native.
