# @intuitui-labs/rn-terrain-scanner

> 标签: ast, capabilities-radar, expo, legacy-fence, migration, react-native, rn-terrain, scanner, tcdi, temporal-intelligence

## 简介

AST-based legacy fence and capabilities radar for any React Native project. Powered by TCDI temporal intelligence — accumulates all signals between v_start and v_current across your project's full version history.
