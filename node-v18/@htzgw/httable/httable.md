# @htzgw/httable

> 标签: configuration-driven, dataset, editable-table, element-plus, master-detail, table, typescript, vue, vue3

## 简介

Vue 3 + Element Plus 的配置驱动可编辑表格：编辑控件常驻，跨页跨查询条件保留修改，统一校验与保存，支持主子表。
