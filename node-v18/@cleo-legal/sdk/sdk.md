# @cleo-legal/sdk

> 标签: api, compliance, eurlex, gdpr, law, legal, legifrance, rag, regulation, sdk, typescript

## 简介

Official TypeScript SDK for the LegalData by Cleo public API — search 50+ jurisdictions, retrieve legal documents, translate, bulk-fetch, stream changes, and run customs/compliance workflows.
