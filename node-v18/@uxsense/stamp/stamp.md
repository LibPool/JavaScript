# @uxsense/stamp

> 标签: babel-plugin, behavioral-drift, instrumentation, jsx, uxsense

## 简介

UXSense build-time component stamping — adds data-uxs identity attributes to JSX component roots and emits a build manifest for behavioral drift detection.
