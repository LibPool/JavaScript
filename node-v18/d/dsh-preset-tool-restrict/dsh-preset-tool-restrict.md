# dsh-preset-tool-restrict

> 标签: JavaScript

## 简介

在指定 Agent 预设的范围内屏蔽宿主层注册的工具族（默认 mcp__playwright-mcp__* 与 mcp__droidmind__*），不影响同一进程内的其他预设。显式写出的 denyPrefixes 即为权威，空数组表示该预设不屏蔽任何工具。
