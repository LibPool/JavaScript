# domsculptor

> 标签: browser, dependency-free, dom, progressive-enhancement, reactive, signals, widgets

## 简介

A tiny, dependency-free, client-side reactive DOM toolkit for widgets, browser extensions, embedded interfaces, progressive enhancement, and small applications.
