# dsh-slash-match

> 标签: deepseek-harness, dsh, dsh-plugin, fuzzy, match, slash

## 简介

为斜杠菜单提供模糊匹配:不用从首字母输入,记得名称中段/后缀也能搜到(如 /me 命中 grill-me);运行时接管官方搜索函数,不改官方代码。
