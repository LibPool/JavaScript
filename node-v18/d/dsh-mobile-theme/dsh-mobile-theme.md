# dsh-mobile-theme

> 标签: cordis, deepseek-harness, dsh, mobile, responsive, theme

## 简介

Mobile-adaptation theme plugin for the DeepSeek Harness Web surface: phone layout (overlay sidebar and fullscreen right preview, touch-size controls, safe-area insets, fullscreen settings) plus an automatic viewport theme layer stacked through the officia
