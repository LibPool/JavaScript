# dsh-hitl

> 标签: ai-agent, approval, bundle, cordis-plugin, deepseek-harness, dsh, hitl, human-in-the-loop, plugin, web-ui

## 简介

Human-in-the-loop gate for DSH tool calls: mount any tool behind an approve / modify / reject decision card in the DSH Web UI, with an optional countdown.
