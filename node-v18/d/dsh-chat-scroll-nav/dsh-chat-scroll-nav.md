# dsh-chat-scroll-nav

> 标签: chat, deepseek, dsh, dsh-plugin, harness, navigation, plugin, scroll

## 简介

DSH 对话右侧快速导航条：在聊天区右缘渲染一条竖向迷你导航（类似手机通讯录快速索引），每个用户/AI 消息一个可点击圆点，点击或拖动即可快速滚动定位到对应消息，当前视口消息高亮并悬浮显示消息摘要。纯 client DOM 注入，热插拔挂载，不改 DSH 源码。
