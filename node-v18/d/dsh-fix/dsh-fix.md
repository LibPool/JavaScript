# dsh-fix

> 标签: cli, cordis, cross-platform, deepseek-harness, diagnose, doctor, dsh, plugin, repair

## 简介

Standalone cross-platform repair tool for DeepSeek Harness (DSH): diagnose and fix startup failures caused by installed plugins. 独立的 DSH 插件故障诊断与修复工具，不依赖 DSH。

## 官网

- 源码仓库：git+https://github.com/SherlockGougou/dsh-plugins-fix.git
- npm 页面：https://www.npmjs.com/package/dsh-fix
