# dd-rc-multipicker

> 标签: JavaScript

## 简介

面向待选择的数据长度过大提供分页功能，以及搜索和全选/非全选功能。 ### Props:   | 属性 | 说明 | 类型 | 默认值 |   | ---- | ---- | ---- | ------ |   | data            | 选择原数据      | Array | [] |   | selected        | 已选项          | Array | [] |   | current         | 当前分页        | Number | 1 |   |
