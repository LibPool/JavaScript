# dsh-model-select-plus

> 标签: composer, dsh, dsh-plugin, model-select, model-selector

## 简介

A richer model-selection popup for DeepSeek Harness: provider-grouped models with descriptions, inline reasoning-effort chips, search and pinned favorites — replaces the composer's default ModelSelect.
