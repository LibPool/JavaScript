# documesh

> 标签: api-client, cli, developer-docs, documentation, documesh, federated-search, mcp, sdk, search, webmcp

## 简介

Official SDK and CLI for Documesh — federated developer documentation search across 38 vendors (Cloudflare, Netlify, Vercel, Kubernetes, React, PyTorch, Stripe, Sentry, and more). Version-cited, license-attributed results via REST API and MCP.
