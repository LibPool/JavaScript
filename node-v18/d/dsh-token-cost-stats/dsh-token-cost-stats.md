# dsh-token-cost-stats

> 标签: cost, dashboard, deepseek-harness, dsh, plugin, stats, token, usage

## 简介

Token 用量与费用统计插件（DeepSeek Harness / DSH）：llm/stream 全量采集 + 历史回填，用户自定义模型价格，侧边栏入口的全屏仪表盘（总览卡片 / 使用趋势 / 请求日志 / 按模型统计 / 价格设置）。Token usage & cost dashboard plugin for DeepSeek Harness.
