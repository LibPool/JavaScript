# dsh-minecraft-theme

> 标签: dsh, dsh-plugin, minecraft, pixel-ui, theme, wallpaper

## 简介

Minecraft-style theme for the dsh web GUI: blocky pixel components, photo wallpapers with local upload, bundled Minecraft UI sound samples (with synthesized fallback), and local BGM with a crossfading playlist
