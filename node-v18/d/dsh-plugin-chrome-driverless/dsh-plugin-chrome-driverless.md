# dsh-plugin-chrome-driverless

> 标签: automation, browser, cdp, chrome, deepseek-harness, dsh, dsh-plugin, playwright

## 简介

DeepSeek Harness plugin: drive a Docker-hosted headed Chrome (chrome-driverless) from the agent — navigate, screenshot, click/type, tabs, profiles, login-state export.
