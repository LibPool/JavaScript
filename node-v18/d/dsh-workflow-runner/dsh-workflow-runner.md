# dsh-workflow-runner

> 标签: agents, cordis, deepseek, deepseek-harness, dsh, llm, orchestration, workflow

## 简介

Bring ZCode-style dynamic-workflows semantics into dsh: write JS workflow scripts that spawn parallel LLM agents and shell gates; live progress streams to the chat UI as overlay cards.
