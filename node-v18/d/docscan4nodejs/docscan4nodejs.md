# docscan4nodejs

> 标签: Document Scanning, ICA, SANE, Scan API, Scanner access, TWAIN, WIA, eSCL

## 简介

Node.js API for Dynamsoft Document Scanning Service. Supports TWAIN, SANE, ICA, WIA, eSCL scanners.
