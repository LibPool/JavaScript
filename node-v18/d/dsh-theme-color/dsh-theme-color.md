# dsh-theme-color

> 标签: cordis, deepseek-harness, dsh, plugin, theme, 主题

## 简介

自定义主题色：在设置-外观中添加一个调色盘方块，选择品牌主色后仅替换当前黑白主题中带颜色的按钮与图标（业务蓝一族），页面整体保持黑白。
