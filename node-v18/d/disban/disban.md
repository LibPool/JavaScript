# disban

> 标签: burner-email, disposable-email, email-validation, fraud, mcp, signup, temporary-email

## 简介

Detect disposable email at signup. Classifies an email domain as disposable, free, alias, testing, parked or unknown. Works without an API key; includes a CLI and an MCP server.
