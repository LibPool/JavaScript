# dsh-startup-guard

> 标签: boot, deepseek, deepseek-harness, dsh, dsh-plugin, guard, preflight, self-heal, startup

## 简介

Boot-time guard for DeepSeek Harness: repairs corrupt session logs, snapshots manifests + linked sources, preflights bundle resolution and composition, vm-checks client artifacts, smokes host apply() in a child process and quarantines crash-causing bundle
