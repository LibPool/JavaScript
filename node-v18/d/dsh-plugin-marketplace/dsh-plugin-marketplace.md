# dsh-plugin-marketplace

> 标签: deepseek-harness, dsh, dsh-plugin, marketplace, web-ui

## 简介

DeepSeek Harness Web UI 内置插件市场：在设置页直接浏览 github.com/topics/dsh-plugin，支持搜索、按 Star 排序、查看安装方式。
