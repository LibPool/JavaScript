# dsh-color-swatch

> 标签: color, deepseek-harness, dsh, dsh-plugin, swatch

## 简介

色块：对话正文里的颜色编码（HEX / rgb() / hsl()）可点，点一下就用那块颜色盖住编码文字本身，点覆盖关一块、点别处全关。零 token 成本。
