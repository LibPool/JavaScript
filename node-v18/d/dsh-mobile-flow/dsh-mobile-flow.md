# dsh-mobile-flow

> 标签: css, deepseek-harness, dsh, dsh-plugin, mobile, web-ui

## 简介

Mobile fixes for the DeepSeek Harness Web UI: on narrow (≤720px) screens the input bar and AI confirmation cards scroll with the page instead of pinning to the viewport floor, edges slim down, session switches no longer auto-focus the input, workspace row
