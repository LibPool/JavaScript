# dsh-plugins-tui-ops

> 标签: JavaScript

## 简介

TUI brick: 工程化命令集 /doctor /login /logout /add-dir /hooks /mcp /cost /tokens /thinking /settings — env self-check, credential status (no secret values), policy scope, MCP status, token/cost details, thinking display toggle, config sources. Ported from ccch
