# dsh-geek-archive

> 标签: cordis, deepseek-harness, dsh, dsh-plugin, web

## 简介

归档会话管理：在设置面板加一节「归档管理」，列出已归档会话，可放回对话或永久删除，补上 DSH 缺失的归档反向操作。
