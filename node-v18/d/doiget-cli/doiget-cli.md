# doiget-cli

> 标签: arxiv, bibliography, crossref, doi, mcp, modelcontextprotocol, open-access, research, unpaywall

## 简介

Turn DOIs and arXiv IDs into local PDFs and metadata via official Open-Access APIs. CLI + stdio MCP server. Never bypasses paywalls.
