# django-copilot-agent-kit

> 标签: cli, copilot, custom-agent, django, github-copilot, scaffold, vscode

## 简介

Scaffold a Django Developer custom agent kit for GitHub Copilot (.github/agents, instructions, skills, prompts) into any project.
