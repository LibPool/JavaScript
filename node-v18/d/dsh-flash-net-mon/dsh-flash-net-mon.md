# dsh-flash-net-mon

> 标签: JavaScript

## 简介

Network monitor & outbound audit provider for the `dsh-flash` Quick Control panel — registers a network-alert provider and the opt-in network audit (fetch tracer) via ctx.get('dockFlashAlerts').
