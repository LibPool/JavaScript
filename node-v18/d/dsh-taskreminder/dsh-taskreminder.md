# dsh-taskreminder

> 标签: cordis, deepseek-harness, ding, dsh, notification, plugin, sound, task-reminder

## 简介

A DSH (DeepSeek Harness) Cordis plugin that plays a crisp 'ding' the moment the agent finishes a task. / DSH 任务完成提醒插件：智能体完成任务时播放一声清脆的叮声。
