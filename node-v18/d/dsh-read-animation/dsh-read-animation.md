# dsh-read-animation

> 标签: animated-webp, animation, deepseek-harness, deepseek-harness-plugin, dsh, dsh-plugin, frames, gif, multimodal, vision

## 简介

Let a DeepSeek Harness agent actually see an animated GIF or animated WebP: decode every frame, sample the animation across time, and hand the model a labelled sequence of real frames instead of the single first frame the harness otherwise delivers.
