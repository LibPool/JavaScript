# dsh-deskpet

> 标签: custom, deepseek-harness, deskpet, dsh, pet, plugin, 桌宠

## 简介

主人想让我出现在桌面上——不想一个人太无聊。DSH Web 自定义桌宠：上传透明图/GIF、会走路、可拖动缩放、台词系统（点击/休闲/早中晚特殊台词，权重可编辑）、活跃度、多宠物、一键导入导出(.petpkg)。
