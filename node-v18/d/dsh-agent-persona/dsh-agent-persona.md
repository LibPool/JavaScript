# dsh-agent-persona

> 标签: deepseek-harness, dsh, persona, plugin, settings-panel, system-prompt, workspace

## 简介

Workspace personas for DeepSeek Harness (DSH): create many system-prompt personas and scope each one by workspace path or session id (exact / prefix / regex / contains), managed from a Web settings page with Markdown editing and AI tuning.
