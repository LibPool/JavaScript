# dsh-markji-bridge

> 标签: agent-tools, cordis, deepseek-harness, dsh, flashcards, maimemo, maimemo-openapi, markji, plugin, spaced-repetition, sqlite, sync

## 简介

Give a DSH agent Markji (maimemo) cards through four consolidated tools: decks and chapters, card reads/writes/syntax/archive/move, sync/state/failures/conflict resolution, and uncached file upload/query. Local SQLite cache with inline content, formatting
