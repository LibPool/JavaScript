# direct-drop-area

> 标签: drag, drag-and-drop, drop, dropzone, file, file-input, file-upload, image-upload, paste, preview, react, react-component, upload

## 简介

A lightweight, feature-rich drag-and-drop file upload component for React. Supports multiple files, validation, previews, paste, and more.
