# deepseek-harness-rtl

> 标签: arabic, bidi, client-plugin, cordis, deepseek-harness, dsh, rtl, ui

## 简介

Arabic (RTL) text fix for the DeepSeek Harness web UI — a browser-side Cordis client plugin that injects an RTL stylesheet.
