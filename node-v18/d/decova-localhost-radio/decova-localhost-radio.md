# decova-localhost-radio

> 标签: JavaScript

## 简介

Provides a fast way for communication on proadcasting paradigm only in localhost on purpose of facilitating communication among processes. You typically inistantiate a ProadcastServer and ProadcastClient(s) with tiny configuration for each.
