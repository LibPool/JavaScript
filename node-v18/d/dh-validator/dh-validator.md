# dh-validator

> 标签: async-validation, composable, conditional-validation, form, form-validation, graceChecker, schema, type-safe, useValidator, validation, validator, vue, vue3

## 简介

A modern, type-safe form validation library: chainable Schema API, structured errors, cross-field & conditional validation (when), async rules, Vue 3 composable useValidator, extensible plugin system. 30+ built-in business rules including Chinese ID card
