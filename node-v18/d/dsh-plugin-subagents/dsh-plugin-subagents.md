# dsh-plugin-subagents

> 标签: acp, agent-client-protocol, claude-code, codex, cordis, deepseek-harness, grok, subagent, unified

## 简介

Unified subagent provider plugin for the DeepSeek Harness: native in-process subagents with per-call overrides and ACP/Claude Code/Codex bridge subagents with a declarative role library, a delegation permission ceiling, and durable session recovery.
