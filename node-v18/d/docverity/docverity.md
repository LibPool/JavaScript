# docverity

> 标签: agent, ai, ci, claude, doc-rot, docs, documentation, drift, lint, mcp, model-context-protocol, readme

## 简介

AI made documentation rot an epidemic. Docverity checks your docs' claims against the source and fails CI when they drift. Also runs as an MCP tool for coding agents.
