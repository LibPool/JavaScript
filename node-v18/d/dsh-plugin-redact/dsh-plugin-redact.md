# dsh-plugin-redact

> 标签: cordis, deepseek-harness, dsh, dsh-plugin, plugin, redact, redaction, session, tui

## 简介

In-place redaction and row-level rollback for DSH session logs (session.vN.jsonl.zstd), usable from inside dsh-tui.
