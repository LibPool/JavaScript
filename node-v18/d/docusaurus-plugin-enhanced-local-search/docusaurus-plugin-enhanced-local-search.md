# docusaurus-plugin-enhanced-local-search

> 标签: algolia-alternative, cmdk, command-palette, docusaurus, docusaurus-plugin, enhanced-search, fuzzy-search, i18n, local-search, offline-search, search

## 简介

Local, Algolia-like search for Docusaurus v3: Cmd+K modal, navbar and footer mini bar, big hero search bar, typo-tolerant ranking. No external service.
