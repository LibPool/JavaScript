# dify-components-v2

> 标签: JavaScript

## 简介

#### 功能描述 `Assistance.vue` 是一个辅助组件，用于展示和管理多个助手（Assistants）。它通过 `FloatButton` 提供一个浮动按钮，点击后可以显示助手列表或直接选择一个助手进行交互。如果只有一个助手，则直接跳过选择步骤，进入对话界面。
