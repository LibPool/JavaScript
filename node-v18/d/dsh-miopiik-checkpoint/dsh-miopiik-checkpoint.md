# dsh-miopiik-checkpoint

> 标签: checkpoint, cordis, deepseek-harness, dsh-plugin, memory

## 简介

Compatibility auto-checkpoint plugin for MiOpIIk 0.1.x-style installs; MiOpIIk 0.2 default runtime moves this behavior into dsh-miopiik-tool-recovery. 兼容包：0.2 默认由 recovery 承担自动检查点
