# dsh-daily-log

> 标签: JavaScript

## 简介

Daily work log plugin for DeepSeek Harness: /daily scaffold plus daily_log_write (merge-on-write with .bak backups), daily_log_read, and daily_log_list tools; YYYY-MM-DD.md and a theme-aware YYYY-MM-DD.html
