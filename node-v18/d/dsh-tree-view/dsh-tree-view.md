# dsh-tree-view

> 标签: branch, conversation-branching, cordis-plugin, deepseek-harness, dsh, dsh-plugin, tree-view, version-tree

## 简介

Tree-view conversation branching for DeepSeek Harness: keep one entry in the sidebar, branch and switch versions inside a tree, promote a branch to a formal session, and rename branches. A fork of dsh-plugin-message-edit (MIT).
