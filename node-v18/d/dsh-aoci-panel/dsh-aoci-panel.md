# dsh-aoci-panel

> 标签: aoci, cordis, deepseek-harness, dsh, plugin, ui

## 简介

AOCI 认知面板：在会话视图标签中展示当前项目的 AOCI 索引概览、治理状态与条目浏览，并为未接入的项目提供引导式安装。
