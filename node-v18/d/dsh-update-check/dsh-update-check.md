# dsh-update-check

> 标签: deepseek-harness, dsh, plugin, update-check

## 简介

DeepSeek Harness update check: at startup (rate-limited) compares the installed @deepseek-ai/dsh version with the npm latest and surfaces the result — console notice, $DSH_HOME/update-check.json, an `updateCheck` host service, an `update-check/checked` ho
