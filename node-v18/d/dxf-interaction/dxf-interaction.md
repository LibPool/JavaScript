# dxf-interaction

> 标签: cad, dxf, dxf-viewer, highlight, interaction, measure, measurement, picking, selection, snap, three, three.js, threejs, typescript

## 简介

Framework-agnostic DXF viewer interaction controllers (measure / snap / picking / highlight / rectangle-select) built on dxf-render + Three.js. Shared by dxf-vuer, dxf-react and dxf-lit.
