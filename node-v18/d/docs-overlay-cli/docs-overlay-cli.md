# docs-overlay-cli

> 标签: cli, docs, docs-as-code, docs-overlay, documentation, documentation-versioning, docusaurus, docusaurus-versioning, monorepo, versioned-documentation, versioning

## 简介

Command line for docs-overlay: cut a version, check content, prune files a version repeats, and materialise the tree Docusaurus reads.
