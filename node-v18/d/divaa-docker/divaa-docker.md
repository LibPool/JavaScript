# divaa-docker

> 标签: agent-skill, ai, claude, claude-code, codeigniter, divaa-docker, docker, laravel, mutagen, opencode, skill, traefik, vite, webpack

## 简介

CLI to install the divaa-docker Agent Skills — one-command onboarding of Laravel (Vite or Laravel Mix/webpack) and CodeIgniter 3/4 apps onto the shared divaa-docker homelab host — into AI coding assistants like Claude Code and opencode.
