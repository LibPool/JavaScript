# dsh-plugin-teamflow

> 标签: agent-team, coding-agent, deepseek-harness, dsh, kanban, llm-agent, multi-agent, pipeline, plugin, teamflow

## 简介

TeamFlow 团队研发流水线（TypeScript）：需求→PRD→设计→架构→技术方案→并行开发→QA→验收；backlog 持久化 + 断点续跑 + 完成汇报 + 防假交付；Web 团队工作台（conversation.view tab + 拖拽看板）
