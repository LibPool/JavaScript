# dsh-web-focus

> 标签: cordis, deepseek, deepseek-harness, dsh, markdown, navigation, web-ui

## 简介

Web UI enhancements for the DeepSeek Harness (dsh) browser surface: a message navigation rail with full-history loading, a tool-activity visibility toggle, and markdown reading enhancement
