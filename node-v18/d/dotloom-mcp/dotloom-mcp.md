# dotloom-mcp

> 标签: ai, animation, electron, mcp, model-context-protocol, pixel-art, sprite, tilemap

## 简介

dotloom-mcp is a pixel-art engine for humans and AI agents, with a scriptable CLI and Model Context Protocol server.
