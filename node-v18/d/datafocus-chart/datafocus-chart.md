# datafocus-chart

> 标签: JavaScript

## 简介

这是 DataFocus 发布的 Vue 2 画图组件，旨在帮助开发者在 Vue 2 项目中快速集成多种图形绘制功能。该组件支持超过三十种图形类型，包括柱状图、折线图、饼图、环形图等，满足不同的可视化需求。
