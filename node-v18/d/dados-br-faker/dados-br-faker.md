# dados-br-faker

> 标签: boleto, brasil, brazil, cep, cnh, cnpj, cnpj-alfanumerico, cpf, fake-data, faker, mock, pix, renavam, seed, testing, typescript

## 简介

Modern, TypeScript-first Brazilian fake-data generator with internally coherent entities (CEP↔city↔state↔DDD), valid check digits, deterministic seeding, and the new alphanumeric CNPJ (2026).
