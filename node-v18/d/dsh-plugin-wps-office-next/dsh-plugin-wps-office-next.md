# dsh-plugin-wps-office-next

> 标签: agent-skill, com, deepseek-harness, dsh-plugin, mcp, windows, wps-office

## 简介

用中文对话操控 WPS 表格 / 文字 / 演示的 DeepSeek Harness 插件（仅 Windows x64 / COM）。自带 MCP server、常驻 COM 宿主与技能文档，免装 WPS 加载项、免配环境变量。
