# dsh-global-todo

> 标签: agent, cordis, deepseek, deepseek-harness, dsh, dsh-plugin, handoff, productivity, task-list, task-management, todo, todo-list, todos, 全局待办, 待办

## 简介

Cross-session todo list for DeepSeek Harness: one JSON file a person and an agent both write to, with step plans that ship as a numbered hand-off, session read-back, and a human confirmation before an agent's "done" counts.
