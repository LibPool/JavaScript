# dsh-chrome-bridge

> 标签: agent, browser, browser-automation, cdp, chrome, chrome-devtools-protocol, deepseek-harness, dsh, dsh-plugin, native-messaging

## 简介

DSH plugin: native browser_* tools that drive the Chrome you are already using — over native messaging + CDP. No WebSocket, no port, no Connect button. The native host and the MV3 extension ship inside this package and are installed automatically on first
