# directory-box

> 标签: JavaScript

## 简介

一个支持目录树形结构，自定义目录高亮的锚点计算位移,且支持选中该目录后锚点对应的内容。这里只提供左边的组件思路，右边展示对应的内容最好自己自定义组件控制更为灵活，会提供思路。
