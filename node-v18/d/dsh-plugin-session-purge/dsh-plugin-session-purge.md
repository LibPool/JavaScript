# dsh-plugin-session-purge

> 标签: deepseek-harness, delete, dsh, dsh-plugin, session

## 简介

Delete DeepSeek Harness sessions for good - via a recycle bin: move, restore, then the next start wipes the log, projection cache, spill files and workspace accounting.
