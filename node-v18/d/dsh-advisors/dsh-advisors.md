# dsh-advisors

> 标签: advisor, deepseek-harness, dsh, plugin, review, watchdog

## 简介

Advisor models plugin for DeepSeek Harness — a background reviewer model watches the main agent's turns and injects severity-graded notes (nit / concern / blocker) back into the session.
