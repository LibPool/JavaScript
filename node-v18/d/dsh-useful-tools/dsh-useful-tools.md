# dsh-useful-tools

> 标签: dsh, dsh-plugin, mark-read, minihost, plugin-sync, preview, test-env

## 简介

DSH 有用小工具箱：命令读文件自动算已读（mark_read）+ 快捷命令（quick_command）+ 插件同步（sync_plugin）+ 后端模拟（minihost）+ 前端预览（preview）+ UI 静态骨架检查（ui_check）+ 插件验证（verify_plugin）+ 测试环境（test_env）+ 工具清单（useful_tools）
