# dreadmore

> 标签: css, dreadmore, dreadmore.js, dsekon, html, javascript, more, native, plugin, readmore, readmore.js, sass, scss

## 简介

The plugin for collapsing and expanding long blocks of text. min-height: 1px - 1 line. DISABLE it using CSS!
