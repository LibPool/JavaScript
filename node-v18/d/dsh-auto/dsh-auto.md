# dsh-auto

> 标签: JavaScript

## 简介

dsh 的 Auto 决策插件。填写自己的 API Key 后直连 `jev-1.13-free` 获取结构化决策，插件通过 dsh 原生会话、工具和子代理接口落实决策。主代理和子代理使用配置的执行模型。插件不包含智能体执行运行时。未配置 `apiKey` 时按原生模式运行，不调用任何网络服务。
