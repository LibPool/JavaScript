# dsh-pomodoro

> 标签: deepseek, deepseek-harness, dsh, dsh-plugin, pomodoro, productivity, timer

## 简介

A DeepSeek Harness Web Pomodoro plugin with configurable focus and break intervals, sidebar access, and a draggable floating panel
