# discora

> 标签: autocomplete, bot commands, button interactions, command handling, community-driven, custom interactions, developer tools, discora, discord, discord API, discord bot development, discord bot framework, discord.js, event management, framework for Discord bots, modal handling, node.js, open-source, slash commands, typescript, user experience

## 简介

Discora is a structured framework for building Discord bots using Discord.js. It enhances readability and simplifies command handling, event management, and customizable interactions.
