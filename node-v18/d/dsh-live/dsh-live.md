# dsh-live

> 标签: JavaScript

## 简介

右侧悬浮多平台直播窗口：摄像头/麦克风、屏幕选区直播（画中画）、多平台多选同时推流（视频号/抖音/快手/斗鱼/B站/YY/虎牙/CC），ffmpeg 引擎真实 RTMP 推流。Cordis bundle 插件（DSH）。
