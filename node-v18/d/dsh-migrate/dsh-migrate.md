# dsh-migrate

> 标签: backup, deepseek, dsh, dsh-plugin, harness, migration, profile, restore

## 简介

DSH 配置迁移工具：导出/打包/导入 + 校验回滚（同 OS，新建 profile）。Export/package/import DSH config with verification and rollback.
