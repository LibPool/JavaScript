# dsh-image

> 标签: cordis, deepseek, dsh, harness, image, multimodal, vision

## 简介

DeepSeek Harness 插件：注册声明支持 image 的 provider「deepseek-vision」（显示为「多模态LLMs」），把图片先转成文字再交给纯文本的 DeepSeek；转图用的多模态 provider/model 可在设置页配置。
