# dsh-token-cost

> 标签: cost, deepseek, dsh, harness, plugin, pricing, token

## 简介

Token cost tracking for DeepSeek Harness: per-session and per-message cost projection with a web summary surface. Official DeepSeek prices are synced automatically by a daily script.
