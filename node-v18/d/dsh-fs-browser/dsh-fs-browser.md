# dsh-fs-browser

> 标签: dsh, file-browser, plugin, workspace

## 简介

DSH workspace file browser: an embedded right-side file column sharing the frame with the conversation — file list, Shiki-powered text preview with line numbers, image preview, copy-on-select, and per-workspace remembered state.
