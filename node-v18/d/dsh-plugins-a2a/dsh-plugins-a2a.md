# dsh-plugins-a2a

> 标签: JavaScript

## 简介

Native A2A (Agent-to-Agent, v1.0 JSON-RPC) server for dsh: expose this dsh as a callable agent over HTTP with tasks/send|get|cancel|list, bearer-token auth, and agent-per-task execution.
