# directus-extension-polymorphic-reference

> 标签: directus, directus-custom-bundle, directus-extension, directus-extension-bundle, display, interface, m2a, morph, polymorphic, relation

## 简介

Resolve polymorphic (collection + id) references into navigable, templated links — Laravel-style morphTo for Directus. Ships an interface (reads the collection from a sibling field) and a display (for self-describing values).
