# door-frame-calc

> 标签: calculator, construction app, door frame calculator

## 简介

A module that calculates the max door size for the rough opening that is built, calculates the frame size if it is bi-fold door and calulates the casing needed for both a bi-fold door and a pre-hung door installation.
