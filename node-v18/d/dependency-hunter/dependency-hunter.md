# dependency-hunter

> 标签: dependencies, dependency, devDependencies, devDependency, find, github, module, organization, package.json, repo, repositories, repository, search, user

## 简介

Find node.js dependencies in github repositories. Goes through package.json in each repository so you can easily find dependencies and devDependencies
