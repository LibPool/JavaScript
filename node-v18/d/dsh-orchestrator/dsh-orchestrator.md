# dsh-orchestrator

> 标签: agent-mesh, cordis, deepseek-harness, dsh, multi-agent, orchestration, subagent

## 简介

【编排模式】为 DeepSeek Harness 提供多智能体编排模式：主智能体分解分派、worker 全网格互通，支持逐 worker 指定模型与思考强度
