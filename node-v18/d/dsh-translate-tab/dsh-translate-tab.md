# dsh-translate-tab

> 标签: deepseek-harness, dsh, dsh-plugin, i18n, translate, translation

## 简介

DeepSeek Harness plugin: a Translate entry under Plugins in the sidebar that swaps the main area for a two-pane translator with model, effort and prompt controls.
