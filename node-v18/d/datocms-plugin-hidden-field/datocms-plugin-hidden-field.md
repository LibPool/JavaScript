# datocms-plugin-hidden-field

> 标签: boolean-field, color-field, date-field, date-time-field, datocms, datocms-plugin, field-editor, float-field, hide-field, integer-field, json-field, string-field, text-field

## 简介

This is the simplest field editor ever! A plugin that allows you to simply hide a field that you don't want anyone to edit or that is taking too much space in your editor view. You can apply this plugin to every field type
