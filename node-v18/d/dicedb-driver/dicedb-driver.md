# dicedb-driver

> 标签: Database, Database driver, DiceDB, In-memory database, Key-value store, Redis, client, js-driver, kv-store

## 简介

DiceDB Driver is a lightweight, promise-based database driver for DiceDB with built-in connection pooling.
