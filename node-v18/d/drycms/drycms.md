# drycms

> 标签: astro, astro-component, astro-integration, cloudflare, cloudflare-workers, cms, content-management, drycms, drystack, git-cms, headless-cms, keystatic

## 简介

A CMS for Astro, inspired by Keystatic. Ships the Astro integration, admin UI and visual inline editor, backed by Cloudflare R2.
