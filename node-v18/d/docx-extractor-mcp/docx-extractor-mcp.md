# docx-extractor-mcp

> 标签: anthropic, claude, docx, mcp, model-context-protocol, word

## 简介

MCP server that wraps the docx-extractor CLI — extract text, tables, footnotes, comments, tracked changes, and images from .docx files as JSON.
