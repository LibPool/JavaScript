# dsh-t3-model-picker

> 标签: cordis-plugin, deepseek-harness, dsh, dsh-plugin, model-picker, t3code

## 简介

T3 Code's model picker for DeepSeek Harness: a provider rail, provider-grouped search, favorites, a Cmd/Ctrl+Shift+M toggle and Cmd/Ctrl+1..9 shortcuts in the composer.
