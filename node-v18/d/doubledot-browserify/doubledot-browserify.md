# doubledot-browserify

> 标签: browser, bundle, coffee, javascript, middleware, npm, require

## 简介

Browser-side require() for js directories and npm modules. Parent paths are allowed

- 源码仓库：git://github.com/substack/node-browserify.git
- npm 页面：https://www.npmjs.com/package/doubledot-browserify
