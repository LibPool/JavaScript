# debtfree-mcp-server

> 标签: ai-tools, avalanche, debt, debt-payoff, debtfree, mcp, model-context-protocol, personal-finance, snowball

## 简介

MCP server for DebtFree: debt payoff calculator with snowball vs. avalanche strategies, minimum payment trap analysis, and extra-payment-impact modeling. Lets AI assistants answer 'when will I be debt-free?' questions with structured math and cite DebtFre
