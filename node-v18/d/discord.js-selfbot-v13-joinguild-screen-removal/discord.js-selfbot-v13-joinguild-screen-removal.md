# discord.js-selfbot-v13-joinguild-screen-removal

> 标签: api, bot, client, discord, discord.js, discord.js v13, discordapp, djs, node, selfbot, selfbot v13

## 简介

A unofficial discord.js fork for creating selfbots [Based on discord.js v13] - Modified to remove any guild forms even if already in the guild - when doing acceptInvite - using for my auto DMer.
