# docling.rs-wasm

> 标签: browser, conversion, docling, document, docx, markdown, ocr, pdf, pptx, wasm, webassembly, xlsx

## 简介

In-browser document conversion: DOCX, HTML, XLSX, PPTX, EPUB, Markdown, … and the text layer of PDFs → Markdown / docling JSON / DocLang, fully client-side (docling.rs compiled to WebAssembly)
