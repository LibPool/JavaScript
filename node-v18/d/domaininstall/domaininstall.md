# domaininstall

> 标签: dns, dnslink, install, npm, package-manager, provenance, supply-chain, typosquatting

## 简介

Install an npm package by domain name. The domain owner declares the mapping with DNS; domaininstall verifies continuity, previews the command, and installs with scripts disabled.
