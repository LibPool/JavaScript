# dsh-harness-backup

> 标签: JavaScript

## 简介

Back up and restore a DeepSeek Harness deployment across machines: profiles, plugin bundles, custom model configuration, plugin private data, workspace docs, and encrypted credentials. Standalone CLI plus DSH plugin tools. Zero runtime dependencies.
