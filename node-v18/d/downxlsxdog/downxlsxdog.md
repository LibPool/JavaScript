# downxlsxdog

> 标签: JavaScript

## 简介

1. exportXlsx函数下载xlsx， 调用格式 exportXlsx(['表头字段'， '表头']，[{ key: '数据', value: '数据' }， '下载完成的名称.xlsx']), xlsx后缀必填选项 。  2. uploadData函数上传xlsx，调用格式uploadData(文件).then(res => res) res就是转化后的数据
