# dsh-client-url-shim

> 标签: browser, cordis, deepseek-harness, dsh, plugin, polyfill, rolldown, shim, tsdown, url

## 简介

Browser url shim for DeepSeek Harness client bundles: a tsdown plugin that inlines a node:url polyfill so dependencies like @pixi/utils build and run in the web module table.
