# draftjs-to-html-with-settings

> 标签: JavaScript

## 简介

All credit goes to jpuri here. Forked from https://github.com/jpuri/draftjs-to-html. A library for draftjs to html conversion. Going to add settings for specifying HTML tags i.e. <strong> or <b>.
