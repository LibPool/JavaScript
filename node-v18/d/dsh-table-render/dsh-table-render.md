# dsh-table-render

> 标签: align, cjk, dsh, plugin, table

## 简介

Table render plugin for DeepSeek Harness: render ascii/unicode/markdown tables with CJK-aware column alignment (wide chars count as 2 columns), alignment control, width compression, and display-width measurement. Zero runtime dependencies.
