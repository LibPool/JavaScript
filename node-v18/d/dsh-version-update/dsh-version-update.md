# dsh-version-update

> 标签: deepseek-harness, dsh, dsh-plugin, rollback, self-update, settings, update

## 简介

Version management for the dsh Web GUI settings panel: inspect the installed @deepseek-ai/dsh against every npm channel or version line, install or downgrade with one click under a live progress bar, fall back to the Taobao mirror when a source is slow, r
