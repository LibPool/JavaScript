# dotnet-datatable

> 标签: .net, ado.net, asp.net, aspnet, change-tracking, csharp, data-table, database-result, datarelation, datarow, dataset, datatable, dataview, dotnet, in-memory-table, javascript, nodejs, query-result, rowstate, schema-inference, sql-result, typed-columns, vbnet

## 简介

.NET-style DataTable, DataRow, DataView and DataSet for JavaScript/Node.js with schema inference, RowState tracking and query result mapping from any database client.
