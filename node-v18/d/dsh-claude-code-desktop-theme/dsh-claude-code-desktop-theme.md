# dsh-claude-code-desktop-theme

> 标签: claude, deepseek-harness, desktop, dsh, effort-slider, plugin, reasoning-effort, theme, usage-overview, voice-input

## 简介

Claude Code desktop look for the DeepSeek Harness Web GUI: warm cream surfaces, terracotta accent, embedded serif UI, composer HUD + voice input, diff review drawer, usage overview and a themed reasoning-effort slider.
