# dsh-plugin-stats

> 标签: cost, deepseek-harness, dsh-plugin, stats, telemetry, throughput, tokens-per-second

## 简介

General usage stats for DeepSeek Harness: throughput, tokens, cost, tool calls, and activity — charted in the Web UI. TypeScript superset of dsh-plugin-tokspeed.
