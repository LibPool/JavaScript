# dom-event-filter

> 标签: context, dom, event, event-delegation, event-filter, event-routing, filter, hotkey, keyboard, keymap, shortcut

## 简介

Split your page into contexts and route DOM events (hotkeys, clicks, forms) by mask-objects from config
