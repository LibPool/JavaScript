# dpdk-dpi

> 标签: dpdk, dpi

## 简介

this project is a DPI (Deep Packet Inspection) application based on DPDK. By binding the Linux NIC to the user mode driver provided by the DPDK, we can read the NIC port in the user mode through the interface provided by the DPDK Library.
