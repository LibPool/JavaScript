# dsh-plugin-sops-vault

> 标签: age, cordis, deepseek-harness, dsh-plugin, password-manager, secrets, sops, vault

## 简介

DeepSeek Harness plugin: manage a local sops+age encrypted credential vault from a sidebar panel. Agents see structure only; plaintext flows only on human click.
