# dsh-mobile-upgrade

> 标签: deepseek, dsh, dsh-plugin, harness, mobile

## 简介

Mobile UI fixes for the DeepSeek Harness web profile: a restart row, input-modality switches, a narrow-screen drawer and settings tabs, a full-width model menu, a stuck-request network chip, a scrollable question region, a throttled reaction to streaming
