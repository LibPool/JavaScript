# devlim

> 标签: JavaScript

## 简介

This is a package which provides the series expansion of the usual functions expansion around zero, up to the 3th order. It mainly covers the following functions : e, sh, ch, sin, cos, tan, th, arctan, argth, arcsin, argsh
