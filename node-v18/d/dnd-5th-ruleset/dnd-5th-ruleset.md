# dnd-5th-ruleset

> 标签: JavaScript

## 简介

A package exporting rules for D&D 5e edition based on https://github.com/safety-orange/Imports-for-MPMB-s-Character-Sheet/ and https://github.com/morepurplemorebetter/MPMBs-Character-Record-Sheet/

## 官网

- 源码仓库：https://github.com/senorihl/dnd-5e-ruleset.git
- npm 页面：https://www.npmjs.com/package/dnd-5th-ruleset
