# device-lab

> 标签: adb, android, artifact, cli, control-plane, device, devtools, emulator, ios, lease, mcp, mobile, registry, server, simulator, sqlite, xcode

## 简介

A small lab control plane for iOS simulators, Android emulators and physical devices: lease a device, run actions on it, track what is installed. One server, four thin adapters (HTTP, MCP, CLI, dashboard).
