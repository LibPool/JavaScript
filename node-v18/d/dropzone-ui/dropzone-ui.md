# dropzone-ui

> 标签: drag, drag and drop, drag-drop, dragndrop, drop, dropzone, file, file upload, framework, front-end, kamui, material, react, react-dropzone, typescript, upload

## 简介

React Library Component for drag’n’drop files. Easy to use. Material design style. Multilanguage support. Upload to server support.
