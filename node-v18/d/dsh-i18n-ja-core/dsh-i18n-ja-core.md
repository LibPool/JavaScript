# dsh-i18n-ja-core

> 标签: dsh, dsh-bundle, dsh-plugin, i18n, japanese, language-pack, locale, 日本語

## 简介

DSH Web GUI 日本語ロケールパック（コア）: registers the 日本語 language and carries the ja dictionaries for every DSH core plugin namespace (common, settings.*, chat, workspace, …). Independent of dsh-i18n-ja (dsh-web-all family); missing keys fall back to English through
