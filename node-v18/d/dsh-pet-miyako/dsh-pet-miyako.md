# dsh-pet-miyako

> 标签: JavaScript

## 简介

Miyako desktop pet for the DSH web GUI — custom sprite animations (idle / waiting / working / click), purple theme, free resize + lock, click sound. Customized from @linxin666/dsh-pet.
