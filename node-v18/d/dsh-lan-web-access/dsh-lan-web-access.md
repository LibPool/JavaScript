# dsh-lan-web-access

> 标签: deepseek-harness, dsh, dsh-plugin, lan, remote-access, tailscale

## 简介

DeepSeek Harness（dsh）局域网 Web 访问插件：局域网 / 异地组网里多台设备同时访问同一台 dsh；允许列表 + 管理密码，本机与 SSH 隧道免 token，Desktop 与 Web 通用。
