# dsh-context-triage

> 标签: context, dsh, dsh-plugin, pruning, token, triage

## 简介

会话上下文分诊插件：为 DeepSeek Harness (dsh) 自动筛查过期与冗余的上下文内容，以判决式处理节约 token 预算。
