# dsh-baton-mcp

> 标签: claude-code, codex, deepseek, deepseek-harness, mcp, multi-agent, orchestration

## 简介

Pass the baton from Claude Code, Codex or any MCP client to a local DeepSeek Harness: an MCP server that hands off tasks, continues a specific session, shows the run live in Harness and hands the result back when it is done.
