# dyslexiasteps-embed

> 标签: dyslexia, education, embed, iframe, phonics, reading, sight-words, teachers, web-component, word-games

## 简介

Free reading games for any website: a <dyslexiasteps-game> web component and a React wrapper. Listen-and-find, build-the-word, choose-the-word and dictation in English, German, Spanish, French, Dutch and Brazilian Portuguese. No tracking in the frame.
