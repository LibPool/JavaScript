# dsh-web-import

> 标签: chat, conversation, deepseek, deepseek-harness, dsh, import, workspace

## 简介

Import DeepSeek Web (chat.deepseek.com) chat history into DeepSeek Harness as resumable, workspace-grouped sessions with original titles. 把 DeepSeek 网页版聊天记录导入 DeepSeek Harness，自动分组并保留原标题。
