# directus-extension-pixozip-cloud

> 标签: avif, directus, directus-custom-operation, directus-extension, directus-extension-operation, image-optimization, pixozip, sandbox, webp

## 简介

Cloud-compatible (sandboxed) Directus operation that optimizes an image into AVIF/WebP via the Pixozip URL API. Wire it into a Flow on files.upload. Works on Directus Cloud.
