# deflate-string

> 标签: base64url, compress, compression, deflate, localstorage, lz-string, share-link, string, url, zero-dependency

## 简介

Compress a string to a string with the runtime's own deflate. Smaller than lz-string at every size measured, for URLs, localStorage and cookies. Zero dependencies.
