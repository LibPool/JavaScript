# dsh-git-rollback

> 标签: checkpoint, deepseek-harness, dsh, git, rollback

## 简介

DSH turn-level Git rollback plugin: /rollback /redo /checkpoints /undo commands, per-turn checkpoints in hidden refs, non-destructive workspace restore, scoped turn undo, checkpoint-SHA restore; web client half adds turn-level Restore-checkpoint dividers
