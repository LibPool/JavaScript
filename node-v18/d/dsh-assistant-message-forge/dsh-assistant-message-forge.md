# dsh-assistant-message-forge

> 标签: assistant-message, client-plugin, deepseek-harness, dsh, session-log, testing

## 简介

DSH 助手消息锻造台：可创建/修改/注入测试用 assistant 消息，并可导入识别 session.jsonl(.zstd) 会话日志。
