# dsh-plugin-verifier

> 标签: audit, deepseek-harness, dsh, dsh-plugin, plugin, security, static-analysis, supply-chain

## 简介

Read-only health auditor for DSH plugins — admission checks plus static security scan, with a 建议安装/谨慎安装/不建议安装 verdict. Never executes the code it audits.
