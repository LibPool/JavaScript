# dsh-mobile-xc

> 标签: deepseek-harness, dsh, mobile, plugin, ui, web

## 简介

DSH Web 移动端 UI 适配集大成插件：overlay 抽屉、安全区、canary 防升级失效；<=1023px 生效，桌面零影响。
