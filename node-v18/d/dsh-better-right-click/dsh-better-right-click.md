# dsh-better-right-click

> 标签: better-right-click, context-menu, deepseek-harness, dsh, dsh-plugin, explorer, file-menu, open-with

## 简介

Better Right-Click — right-click menu on file references in the DSH transcript: copy the absolute path, reveal the file in Explorer, or open it with any app registered for that file type. Bilingual (follows the DSH locale). Windows only.
