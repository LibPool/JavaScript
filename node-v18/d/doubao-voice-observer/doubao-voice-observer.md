# doubao-voice-observer

> 标签: auto-send, dictation, doubao, fsm, input-method, ios, observer, safari, voice, voice-input, webkit

## 简介

Deterministic iOS dictation completion detector based on a Finite State Machine (FSM) for the Doubao (豆包) input method. Supports multi-round AI refinement with an adaptive verification window.
