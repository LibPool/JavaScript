# dsh-skills-manager-plus

> 标签: deepseek, dsh, dsh-plugin, harness, skills, slash-commands

## 简介

Skills & commands manager settings page for DeepSeek Harness: view, enable/disable, edit, delete and add skills, plus save reusable prompts as /commands — all from the browser.
