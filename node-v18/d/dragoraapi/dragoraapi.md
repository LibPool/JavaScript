# dragoraapi

> 标签: api-client, dragora, dragoraapi, game-panel, game-server, minecraft, pterodactyl

## 简介

Official Dragora panel API client for Node.js. Supports user (dlpu_) and admin (dpla_) API keys.

- Node 要求：>=14.0.0
