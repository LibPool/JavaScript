# dargs

> 标签: args, arguments, argv, binary, cli, command, commander, construct, flags, inverse, invert, minimist, nopt, opposite, options, parse, parser, reverse, switch

## 简介

Reverse minimist. Convert an object of options into an array of command-line arguments.
