# dsh-sql-query

> 标签: aggregate, csv, dsh, json, jsonl, plugin, query, select, sql

## 简介

Zero-dependency SQL-subset query engine for DeepSeek Harness: run SELECT/WHERE/GROUP BY + aggregates/ORDER BY/LIMIT over JSON, CSV, JSONL or table text, with an explain_sql plan tool. Uses only Node built-ins.
