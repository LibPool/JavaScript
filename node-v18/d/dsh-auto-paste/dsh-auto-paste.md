# dsh-auto-paste

> 标签: attachment, deepseek-harness, dsh, dsh-plugin, paste

## 简介

dsh-auto-paste — a DeepSeek Harness plugin (tool template, extended with a web client paste listener): 在输入框粘贴大段文本时自动保存为附件文件。
