# dsh-provider-info

> 标签: badge, deepseek-harness, dsh, dsh-plugin, model, provider

## 简介

在模型座左侧显示当前模型所属提供商（显示名称优先，回退 Provider ID）。纯运行时装饰，不改动原生页面源码。
