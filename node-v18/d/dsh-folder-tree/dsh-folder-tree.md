# dsh-folder-tree

> 标签: directory-tree, dsh, folder-structure, plugin

## 简介

Folder tree plugin for DeepSeek Harness: render directory trees with depth control, ignore lists (node_modules/.git) and symlink-cycle protection, plus structure statistics by extension. Read-only, zero runtime dependencies.
