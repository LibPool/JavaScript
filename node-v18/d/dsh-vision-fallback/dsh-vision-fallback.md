# dsh-vision-fallback

> 标签: deepseek-harness, dsh, dsh-plugin, fallback, image, vision, 多模态

## 简介

DSH 静默视觉增强：主模型照常选择，图片自动交给固定视觉模型后以隐藏上下文返回主模型。
