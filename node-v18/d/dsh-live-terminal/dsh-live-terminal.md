# dsh-live-terminal

> 标签: agent-tools, cordis, deepseek, deepseek-harness, dsh, dsh-plugin, pty, screenshot, sidebar, terminal, xterm

## 简介

Visible terminal panel for DeepSeek Harness: stream agent shell commands into an in-app terminal live and let the agent take text screenshots of the terminal screen. DSH 可见终端面板：agent 命令实时显示 + 终端屏幕截图。
