# dojo-in-react

> 标签: Dojo, React

## 简介

A convenient wrapper that turns Dojo widgets into React components mimicking React's high-order component functionality. > **Dojo-In-React** only works in a runtime environment, as it relies on Dojo's `window.require` (AMD loading) to load widgets in runt
