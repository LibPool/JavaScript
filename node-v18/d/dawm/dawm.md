# dawm

> 标签: data-extraction, dom, dom-manipulation, dom-parser, headless, html-parser, living-dom, query-selector-all, rust, selectors, serialization, server-side, tree-walking, virtual-dom, wasm, web-scraping, xml-parser

## 简介

High-performance headless DOM toolkit with an HTML/XML parser written in Rust, and DOM APIs implemented in TypeScript. Purpose-built for server-side workflows like web scraping and static site generation.
