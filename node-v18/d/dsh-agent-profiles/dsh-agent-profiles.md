# dsh-agent-profiles

> 标签: agent-profile, cordis-plugin, deepseek-harness, dsh, dsh-plugin, memory, persona, role-play, system-prompt

## 简介

Multiple AI agent profiles — role, avatar, personality, speaking style, ground rules and long-term memory — assignable per conversation, with a memory-injection toggle, import/export and restore-defaults.
