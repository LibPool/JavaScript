# dsh-highlighter

> 标签: cordis, deepseek-harness, dsh, highlighter, plugin, resaltador, web-ui

## 简介

Resaltador tipo web highlighter para la GUI web de DeepSeek Harness: selecciona texto, elige un color y los resaltados sobreviven a re-renderizados, streaming y scroll.
