# ds18x20

> 标签: ds1820, ds18b20, ds18s20, ds18x20, pi, raspberry, raspberry pi, sensor, temperature, thermometer

## 简介

A node.JS implementation for using the DS1820, DS18S20 and/or DS18B20 temperature sensor with Raspberry Pi.
