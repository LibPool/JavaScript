# dsh-zhipin

> 标签: boss, boss-zhipin, crawler, deepseek-harness, dsh, dsh-plugin, job, job-hunting, recruitment, scraper, zhipin

## 简介

BOSS直聘 (zhipin.com) job hunting plugin for DeepSeek Harness: reusable login session (QR scan once), configurable job search & crawl (keyword / city / salary / experience / degree), local job store, agent tools, and a visual Web GUI panel with search-condi
