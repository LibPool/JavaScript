# db-connect-yash

> 标签: auto-connect, backend, connector, database, database-connector, database-tool, db, db-helper, easy-connect, fullstack, mongodb, mysql, node, nodejs, orm, postgresql

## 简介

A simple Node.js package to easily connect to databases. Supports MongoDB, MySQL, and PostgreSQL via connectDB({ type, uri }).
