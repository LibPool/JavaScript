# dsh-string-case

> 标签: case, dsh, plugin, slugify

## 简介

String case plugin for DeepSeek Harness: convert between camelCase/PascalCase/snake_case/kebab-case/CONSTANT_CASE/dot.case/Title Case, auto word splitting across mixed styles, format detection, and URL slugify with CJK support. Zero runtime dependencies.
