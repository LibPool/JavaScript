# dsh-typesafe

> 标签: decision, deepseek-harness, dsh, dsh-plugin, guardrail, jev, system-one, typesafe

## 简介

TypeSafe Jev (System One decision model) for DeepSeek Harness: typed decisions in three question primitives, confidence-gated routing, a cost meter, and an automatic prompt-injection guard over untrusted tool results.
