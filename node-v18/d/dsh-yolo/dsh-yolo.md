# dsh-yolo

> 标签: approval, cordis, dsh, llm, plugin

## 简介

Zero-config LLM approval gate for DeepSeek Harness: under the "Approve for me" preset every approval request is reviewed by the requesting session's own model; allow becomes allowed-once, anything else falls back to the human.
