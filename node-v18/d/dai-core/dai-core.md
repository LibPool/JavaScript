# dai-core

> 标签: air-gapped, cli, container, dai, mcp, offline, portable, single-file, sqlite, tamper-evident, vite-plugin, wasm

## 简介

Compile a web app into a single air-gapped .dai.html file that holds its own SQLite database, runs from a double-click with nothing installed, and is tamper-evident. Command line, MCP server and Vite plugin.
