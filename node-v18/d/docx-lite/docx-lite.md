# docx-lite

> 标签: browser, client-side, document, docx, no-dependencies, office, offline, ooxml, table, word, zip

## 简介

Build a real .docx in the browser: headings, bold, links, lists, tables, compression. No dependencies, 18 KB, works offline and under a strict CSP.
