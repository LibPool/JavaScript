# dsh-waystation

> 标签: deepseek-harness, dsh, github, issue-tracker, mattpocock, plugin, skills, wayfinder, waystation

## 简介

DSH（DeepSeek Harness）上的 Waystation 控制面板插件，配合 Matt Pocock skills（github.com/mattpocock/skills）的 wayfinder / triage / grilling / handoff 等技能使用：右侧 details 列面板（GitHub issue 地图/列表/技能/环境检查）、输入区状态栏胶囊、动作注入与交接开新会话。打开形式仅右侧 details 列（无 PiP/悬浮）。npm 标准安装（bundle 装配，一条命
