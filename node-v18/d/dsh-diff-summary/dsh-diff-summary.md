# dsh-diff-summary

> 标签: cordis, deepseek-harness, diff, dsh, edit, toolview, web-ui, write

## 简介

Per-turn diff summary for file mutations: individual edit/write rows are suppressed, and after each completed turn a single card lists every mutated file once — repeated edits of the same file merge in call order — with click-path-to-open and click-row-to
