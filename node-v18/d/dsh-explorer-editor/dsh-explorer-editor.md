> 标签: deepseek-harness, dsh, editor, file-explorer, file-manager, markdown, monaco, plugin

## 简介

A VS Code-style file manager plugin for DeepSeek Harness Web — DeepSeek Harness 的 VS Code 风格文件管理器插件（浏览、打开、编辑当前对话工作区的文件）.
