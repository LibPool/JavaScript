# dsh-plugin-tool-management

> 标签: cordis, deepseek-harness, dsh, mcp, mcp-server, plugin, skill, skills

## 简介

DSH plugin: one settings panel for MCP servers, skills, scenes, memories, subagent personas and AGENTS.md presets — a scene switches the whole environment, and the model can drive it from chat too.
