# disruption-cascade-plugin

> 标签: ai, claude, claude-code, investment-thesis, jtbd, odi, strategy

## 简介

6-move ODI-based investment thesis engine for Claude Code. Takes a C-suite role and industry segment, produces a defensible Go / Conditional Go / No-Go recommendation.
