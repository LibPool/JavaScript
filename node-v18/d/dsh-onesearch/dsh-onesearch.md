# dsh-onesearch

> 标签: deepseek-harness, dsh, dsh-plugin, fallback, meta-search, search-provider, web-search

## 简介

DeepSeek Harness 搜索插件：把内置网络搜索换成一条可排序的搜索引擎链，每个引擎单独开关、拖动决定优先级，失败自动顺延下一个。
