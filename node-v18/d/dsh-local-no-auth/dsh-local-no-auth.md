# dsh-local-no-auth

> 标签: auth, cordis, deepseek, deepseek-ai, dsh, localhost, loopback, plugin, token

## 简介

DSH plugin: skip the per-restart ?token= browser gate for loopback-only Web GUI deployments. Prints and opens a clean URL, serves / and /api without a token — but ONLY while the webserver is bound to 127.0.0.1 AND the request's Host header is a loopback n
