# drag-drop-plus

> 标签: Ally, accessibility, drag-drop, drag-drop-elements

## 简介

Drag any object in DOM and drop it anywhere in DOM. Works well with Mouse, Touch and Keyboard events. Suuports accessibility to some extent.
