# drm-datepickerjs

> 标签: datepicker, jalali-datepicker, jalali-multiselectpicker, jalali-picker, jalali-rangepicker, multiselectpicker, picker, rangepicker, react-datepicker, react-multiselectpicker, react-rangepicker

## 简介

An headless, event-base picker for JavaScript and any JavaScript base library/framework written in typescript, supports for DatePicker, RangePicker, MultiSelectPicker.
