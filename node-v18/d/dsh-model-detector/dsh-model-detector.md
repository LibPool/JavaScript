# dsh-model-detector

> 标签: dsh, dsh-plugin, llm, model-detection, models, models.dev, pi-ai

## 简介

DSH 模型检测：对任意 pi-ai 提供方（含 DeepSeek 官方 API 路由），拉取线上最新模型并用 models.dev 自动富化模态/容量/推理后写入；支持手动编辑现有模型参数（多模态、思考档位等）
