# dsh-session-eval

> 标签: agent-evaluation, deepseek-harness, dsh, dsh-plugin, regression, session-metrics

## 简介

Retrospective agent-session evaluation for DeepSeek Harness: deterministic grade cards from persisted session logs, cross-session regression diffs, era comparison — no benchmark runs, no LLM judges.
