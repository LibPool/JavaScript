# dean-validator

> 标签: dean, digital-euro, digital-euro-account-number, ecb, fintech, iban, iso-7064, mod97, payments, validator

## 简介

Validate, parse, format and generate a DEAN — the Digital Euro Account Number (18-char EU… identifier, ISO/IEC 7064 MOD 97-10). Zero dependencies, library + CLI.
