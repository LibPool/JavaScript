# dsh-bossintroduce

> 标签: agent-tools, boss-zhipin, browser-automation, cdp, deepseek-harness, deepseek-harness-plugin, dsh-plugin, job-application, job-hunting, resume, skill, zhipin

## 简介

DeepSeek Harness 插件：在 Boss 直聘求职者侧浏览岗位，为每条 JD 生成只属于它的自我介绍并发给 HR（可见浏览器 + CDP 状态机 + 文案护栏）
