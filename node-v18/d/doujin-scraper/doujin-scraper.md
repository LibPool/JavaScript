# doujin-scraper

> 标签: api-wrapper, doujin, doujindesu, eporner, hentai, hentaitv, nekopoi, nodejs, scraper, web-scraping, zero-dependency

## 简介

Standalone data-collection modules for manga / video cataloging sources. Zero-dependency ESM, runs on Node.js >= 18.17, Bun, Deno, or any JS runtime with global fetch.
