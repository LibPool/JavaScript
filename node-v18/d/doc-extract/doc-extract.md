# doc-extract

> 标签: document, docx, file-parser, nodejs, pdf, powerpoint, reader, text-extraction, typescript

## 简介

A Node.js library for reading and extracting text from various document formats (PDF, DOCX, DOC, PPT, PPTX, TXT)
