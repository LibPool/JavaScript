# dom-distiller

> 标签: agent, ast, automation, copilot, dom, dom-compiler, llm, playwright, sdet, testing

## 简介

A DOM compiler for LLM agents. Stops AI from reading the entire DOM by extracting a clean, token-optimized AST of interactable controls.
