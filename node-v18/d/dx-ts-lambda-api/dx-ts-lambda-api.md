# dx-ts-lambda-api

> 标签: JavaScript

## 简介

Build REST API's using Typescript & AWS Lambda. Support for decorator based routing and dependecy injection using InversifyJS. This project is built on top of the wonderful lambda-api package. Add some features, forked from ts-lambda-api
