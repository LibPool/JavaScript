# dsh-snapshot-manager

> 标签: deepseek, dsh, dsh-plugin, harness, rollback, snapshot

## 简介

会话快照 / 回滚（DeepSeek Harness 插件）：按轮次采集工作区快照，一键把文件与对话回退到某一轮之前。
