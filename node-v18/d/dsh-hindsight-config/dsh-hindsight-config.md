## 简介

Umbrella bundle for Hindsight coding-agent memory in DeepSeek Harness: the memory engine plus a visual configuration panel (local client settings, and server-side bank data over HTTP). · Hindsight 记忆的可视化配置面板（伞包：引擎 + 面板）。
