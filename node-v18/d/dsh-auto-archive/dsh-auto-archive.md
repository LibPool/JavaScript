# dsh-auto-archive

> 标签: archive, auto-archive, deepseek-harness, dsh, plugin, session, 闲置归档

## 简介

自动归档闲置会话：工作区会话闲置 N 天自动加入归档集合（列表隐藏，数据保留，支持 dry-run 预览）
