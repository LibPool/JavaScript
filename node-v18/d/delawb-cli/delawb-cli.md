# delawb-cli

> 标签: ai-agent, cli, decentralized, deploy, gitlawb, ipfs, siwe, static-site, web3

## 简介

CLI for delawb - deploy gitlawb repos to IPFS in one command. Wallet auth via SIWE. Multi-agent support.
