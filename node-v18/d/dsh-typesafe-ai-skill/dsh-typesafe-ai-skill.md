# dsh-typesafe-ai-skill

> 标签: classification, cordis, decision-model, deepseek, deepseek-harness, dsh, dsh-plugin, jev, routing, skill, system-one, typesafe, typesafe-ai

## 简介

把 TypeSafe / Jev（System One 判断模型）的构建技能注册进 DeepSeek Harness 的全局技能层：分类、路由、打分、抽取、置信度门控这类「让 AI 做判断」的任务，每个会话都能直接调用。不含任何密钥，API key 由使用者通过 OPENROUTER_API_KEY 环境变量提供。
