# damai-gsh

> 标签: JavaScript

## 简介

- 💝 纯前端实现的大麦网购票网站，利用gulp进行项目的基本构建。 - ✨ 数据接口基本来自原站，通过ajax请求获取数据并渲染页面。 - 🍻 登录注册、购物车功能利用cookie实现。 - ❌ 搜索功能暂未实现，后续版本持续迭代中...
