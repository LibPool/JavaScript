# dsh-notify-plugin

> 标签: clawbot, deepseek-harness, dsh, notification, plugin, webhook, wechat, wecom

## 简介

Notification plugin for DeepSeek Harness - supports system notifications, webhooks, WeCom bots, WeChat ClawBot and Telegram bots
