# dsh-secure-audit

> 标签: audit, compliance, deepseek-harness, dsh, jailbreak, pii, prompt-injection, redaction, security

## 简介

Read-only security & compliance toolkit for DeepSeek Harness: prompt-injection detection (rule engine with a pluggable model classifier), Chinese-PII and structured-JSON redaction, and a local configuration security audit that emits redacted, reproducible
