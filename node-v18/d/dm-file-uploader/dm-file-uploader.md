# dm-file-uploader

> 标签: ajax, dnd, drag, drop, ecosystem:jquery, file, form, forms, javascript, jquery, jquery-plugin, lightweight, multiple, progress, queue, upload, widget

## 简介

A very lightweight and configurable jQuery Plugin for file uploading using ajax(async); includes support for queues, progress tracking and drag and drop.
