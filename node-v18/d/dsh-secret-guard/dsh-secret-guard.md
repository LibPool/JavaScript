# dsh-secret-guard

> 标签: agent, cordis, deepseek-harness, dsh, guard, llm, plugin, redaction, secret, security, token

## 简介

DeepSeek Harness 敏感信息防护插件：拦截写入命令行的疑似密钥/Token（API key、私钥、JWT 等），防止密钥泄漏进日志与会话记录。Secret guard plugin for DeepSeek Harness.
