# deny-sh-vercel-ai

> 标签: ai-agents, credential-isolation, deniable, deny.sh, tool-calling, vault, vercel-ai-sdk

## 简介

Wrap a deny.sh vault entry as a Vercel AI SDK tool. The credential resolves inside execute(); only a narrowed DTO reaches the model. Fail-closed leak sweep.
