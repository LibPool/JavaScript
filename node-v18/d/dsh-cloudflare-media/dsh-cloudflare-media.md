# dsh-cloudflare-media

> 标签: cloudflare, deepseek-harness, dsh, dsh-plugin, image-generation, speech-to-text, text-to-image, text-to-speech, workers-ai

## 简介

Cloudflare Workers AI multimedia tools for DeepSeek Harness: text-to-image, text-to-speech and speech-to-text on the free Workers AI plan, with a settings page where each capability's default model is chosen.
