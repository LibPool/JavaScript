# dsh-session-input-history

> 标签: deepseek-harness, dsh, history, input, navigation, plugin, session

## 简介

DSH 会话隔离的输入历史导航插件（纯 client 双面）：对话输入框中按 ↑/↓ 方向键遍历当前会话发送过的消息（shell history 式交互），浏览中编辑或发送即退出。与全局历史插件的区别是历史严格限定在当前会话内。
