# dsh-lark-link

> 标签: bot, bridge, deepseek-harness, dsh, dsh-plugin, feishu, lark

## 简介

High-reliability Feishu/Lark bridge for DeepSeek Harness — QR one-click auth, multi-mode agents, card-based commands, zero-loss outbox, media in/out, session logs, reusable DSH Web GUI
