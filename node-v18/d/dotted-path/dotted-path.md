# dotted-path

> 标签: JavaScript

## 简介

Dot notation is widely used in popular library such as `lodash`, `mongodb`,`immutable.js` (not really dot notation but same same) etc. This library utilize Typescript's conditional type to help create a dotted path notation in a type-safed way. Requires T
