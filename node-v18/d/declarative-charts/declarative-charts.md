# declarative-charts

> 标签: bar-chart, charts, data-visualization, declarative, django, html-first, htmx, hypermedia, line-chart, lit, no-build, rails, server-rendered, visualization, web-components

## 简介

Charts written as HTML elements, one element per datapoint. Bar, line, area, bubble, scatter, pie, funnel, stage and radar, with axes, legends, patterns and accessibility.
