# digpm-mcp

> 标签: dig.pm, dnslog, jndi, mcp, model-context-protocol, pentest, security

## 简介

MCP server wrapping https://dig.pm/ public DNSLog capabilities (list domains, create/import sessions, generate probes, watch records over WebSocket).
