# dsh-llm-trace-plugin

> 标签: cordis, debugging, deepseek-harness, dsh, llm, plugin, trace

## 简介

Capture the literal HTTP request/response of every LLM provider call (by patching globalThis.fetch) and show them in a Wire Trace session tab
