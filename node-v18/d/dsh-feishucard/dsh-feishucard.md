# dsh-feishucard

> 标签: bot, cordis, deepseek-harness, dsh, feishu, lark, streaming-card

## 简介

DeepSeek Harness <-> Feishu (Lark) bridge with a streaming reply card: official-SDK long connection (no public URL), per-chat dedicated agent sessions, /new /switch /list /help commands, collapsible tool-call panels with status symbols, inline agent notes
