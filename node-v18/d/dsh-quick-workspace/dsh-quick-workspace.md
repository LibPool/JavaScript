# dsh-quick-workspace

> 标签: cordis, deepseek-harness, dsh, dsh-plugin, plugin, workspace

## 简介

Make the sidebar's Add workspace button work in a remote browser: prompt for a folder name and create it next to the current workspace, instead of opening a native OS chooser on the host machine.
