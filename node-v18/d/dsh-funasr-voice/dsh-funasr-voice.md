# dsh-funasr-voice

> 标签: deepseek-harness, dsh, funasr, offline-asr, sensevoice, speech-to-text, voice, voice-input

## 简介

DSH Web 本地离线语音输入插件：浏览器采集麦克风 → host 拉起本地 FunASR (SenseVoiceSmall) 识别 → 文字填入输入框。
