# dsh-reverse-image-search

> 标签: baidu, deepseek-harness, dsh, image-search, plugin, reverse-image-search

## 简介

Search by image for DeepSeek Harness: give it a picture, get back what it shows and where it comes from. Keyless and proxy-free, driven through Baidu 识图.
