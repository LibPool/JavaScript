# directus-extension-endpoint-playnative-signup

> 标签: directus, directus-custom-endpoint, directus-extension

## 简介

Allows an android play games services client to post an auth code to create a user in Directus and returns OAuth2 tokens for it. This is a directus.io endpoint extension that will allow you to potentially integrate with Google Play Games Services APIs fro
