# dsh-client-ui-dashboard

> 标签: cache, dashboard, deepseek-harness, dsh, metrics, plugin, token, visualization

## 简介

DSH web plugin: a real-time dashboard tab for the current conversation — token usage, cache hit rate, message-role distribution, and timing breakdowns, visualized.
