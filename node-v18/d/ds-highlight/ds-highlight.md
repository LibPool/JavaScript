# ds-highlight

> 标签: JavaScript

## 简介

**TextLine**은 React 애플리케이션에서 텍스트 내 특정 키워드를 강조하고, 사용자 상호작용을 처리하기 위한 컴포넌트입니다. 이 컴포넌트는 키워드 강조, 사용자 정의 스타일링, 클릭 이벤트 처리 등을 지원합니다.
