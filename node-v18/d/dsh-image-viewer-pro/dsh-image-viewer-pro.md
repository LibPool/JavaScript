# dsh-image-viewer-pro

> 标签: cordis-plugin, deepseek, deepseek-harness, dsh, dsh-plugin, image-gallery, image-viewer, lightbox, pan, screenshot, zoom

## 简介

A proper image viewer for DeepSeek Harness: zoom, pan, rotate, download, copy, open with the default app, and gallery browsing for images inside the chat.
