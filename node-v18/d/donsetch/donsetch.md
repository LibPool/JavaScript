# donsetch

> 标签: agent-tools, ai-agent, anti-bot, chrome, claude, cursor, extraction, markdown, mcp, mcp-server, model-context-protocol, no-api-key, ocr, pdf, pi-package, rust, screenshot, stealth, tls, web-crawler, web-fetch, web-research, web-scraping, web-search

## 简介

MCP server that gives AI agents the web: fetch, search, crawl and screenshot from one local Rust binary. Zero API keys, zero accounts, Chrome-true TLS.
