# datadog-frontend-toolkit

> 标签: alerts, apm, dashboard, datadog, error-tracking, framework-agnostic, frontend, logging, monitoring, observability, performance, rum, slo, typescript, web-vitals

## 简介

Enterprise-grade, framework-agnostic frontend observability toolkit for Datadog. Auto-instruments RUM, Logs, Error Tracking, Performance Monitoring, and provisions Dashboards, Monitors & SLOs.
