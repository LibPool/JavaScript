# dsh-usage-hud

> 标签: cost, dashboard, deepseek, deepseek-harness, dsh, heatmap, hud, plugin, token, usage

## 简介

DSH 用量悬浮面板：右下角常驻多 Tab HUD（实时 token / 会话记录 / 今日 / 历史 / 热力图 / 24h 曲线 + 费用估算），Host 半从持久化会话日志聚合跨会话历史，零 npm 依赖。
