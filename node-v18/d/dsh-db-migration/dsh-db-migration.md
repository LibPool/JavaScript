# dsh-db-migration

> 标签: database, ddl, deepseek-harness, dsh, dsh-plugin, migration, schema, 数据库, 迁移

## 简介

数据库迁移生成：对比两个 SQL DDL 文件（CREATE TABLE），检测新增/删除/变更的表与列，生成 ALTER TABLE 迁移 SQL
