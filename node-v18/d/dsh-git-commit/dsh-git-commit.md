# dsh-git-commit

> 标签: changelog, conventional-commits, deepseek-harness, dsh, dsh-plugin, git, semver, 提交, 版本

## 简介

Git 提交助手：分析仓库变更生成规范化 Conventional Commits 提交信息、按提交历史生成 CHANGELOG、按语义化版本建议下一个版本号
