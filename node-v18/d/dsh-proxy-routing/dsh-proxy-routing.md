# dsh-proxy-routing

> 标签: deepseek, dsh, dsh-plugin, harness, http, network, proxy, socks5

## 简介

DSH 网络出口路由插件：通过官方 proxy-routing settings namespace 接入用户已运行的 HTTP/SOCKS5 代理，按每次执行路由 shell 与 LLM provider 流量。
