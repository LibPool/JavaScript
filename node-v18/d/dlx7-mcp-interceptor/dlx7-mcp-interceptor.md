# dlx7-mcp-interceptor

> 标签: agent, ai-governance, copilot, cursor, mcp, prompt-injection, security, windsurf, zero-trust

## 简介

DLX7 Agent Zero Trust (AZT) MCP server — governance runtime for AI coding agents. Validates every file edit and shell command before execution. Works in VS Code, Cursor, Windsurf, and Claude Desktop.
