# dsh-balance-monitor

> 标签: api-balance, balance, deepseek, deepseek-harness, dsh, monitor, plugin

## 简介

DeepSeek Harness (DSH) API 余额监控插件：实时监控 DeepSeek API 余额，低于设定阈值时自动暂停任务并询问用户，支持一键跳转开放平台充值。
