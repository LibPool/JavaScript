# dsh-desktop-launcher

> 标签: bundle, deepseek-harness, desktop, dsh, launcher, plugin

## 简介

一个轻量的 dsh（DeepSeek Harness）插件：安装桌面双击启动器 —— macOS 上是带官方鲸鱼图标的 dsh.app，Linux 上是 .desktop 入口。零依赖，约 147 KB。（终端命令在独立的 dsh-launcher 包）
