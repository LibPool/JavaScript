# dockerizenv

> 标签: .env, auto-dockerfile, auto-env, docker, docker-compose, docker-composize, docker-env-generator, docker-node, docker-nodejs, dockerfile, dockerfile-generator, dockerize, dockerize-env, dockerizenv, dockerizing, dockerjs, dotenv, env, javascript-docker, kubernetes, kubernetes-env, kubernetesjs

## 简介

This package is to create basic **docker-compose.env**. It'll also create **docker-compose.yml** in the root directory and also **Dockerfile** in each sub projects if they're missing.
