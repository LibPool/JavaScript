# dsh-youtrack-tools

> 标签: JavaScript

## 简介

YouTrack 周报自动化插件：批量追加「关键进展」+ 新建 issue（截止日期默认一个月、项目/指派人可配置），token 自动从本机 Chrome 登录会话获取
