# dsh-agent-grid

> 标签: agent-dashboard, deepseek-harness, dsh-plugin, multi-agent, sidebar

## 简介

定员八席 —— 把 DeepSeek Harness 的侧栏换成 2×4 的常驻席位看板：八个 agent 各自的实时动作、状态与待办一眼看全。Not affiliated with DeepSeek.
