# d1-migration-guard

> 标签: cloudflare, d1, migrations, sql, wrangler

## 简介

Safety checks for Cloudflare D1 migrations: deterministic ordering, config validation, destructive-SQL flagging, and trigger-safety scanning before you run `wrangler d1 migrations apply`.
