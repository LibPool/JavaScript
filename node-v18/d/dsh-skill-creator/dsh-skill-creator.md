# dsh-skill-creator

> 标签: cordis, deepseek-harness, dsh, dsh-plugin, skill, skill-creator, 技能创作

## 简介

技能创作器：教 agent 按 agentskills.io 规范编写高质量 SKILL.md 技能（frontmatter、渐进式披露、触发描述）。改编自 Anthropic 官方 skill-creator（Apache-2.0）。
