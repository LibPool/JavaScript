# dsh-tool-autoexpand

> 标签: autoexpand, deepseek-harness, dsh, dsh-plugin, tool-call, ui

## 简介

在 DSH web 界面自动展开工具调用卡片，支持侧边栏开关。标准可安装的 dsh 客户端插件。
