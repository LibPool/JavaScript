# dsh-notify-sounds

> 标签: deepseek, deepseek-harness, dsh, notification, plugin, sound, web

## 简介

DeepSeek Harness Web GUI 提示音插件：智能体需要选择（提问/审批）或任务完成时播放短提示音，带开关与音量设置。
