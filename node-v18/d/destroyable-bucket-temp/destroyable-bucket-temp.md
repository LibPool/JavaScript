# destroyable-bucket-temp

> 标签: aws, bucket, cdk, cloudformation, construct, delete, destroy, non-empty, s3

## 简介

Construct that allows the CDK to destroy a non-empty bucket when employing the `cdk destroy` command. This is accomplised by emptying the bucket before destroying it.
