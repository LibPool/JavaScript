# dsh-code-metrics

> 标签: code, code-metrics, complexity, cyclomatic, dsh, hotspots, loc, metrics, plugin

## 简介

Code metrics for DeepSeek Harness: file_metrics (LOC / comment rate / function count / longest function), complexity (McCabe-approximated cyclomatic complexity per file and per function), hotspots (big × complex files ranked). Heuristic, zero runtime depe
