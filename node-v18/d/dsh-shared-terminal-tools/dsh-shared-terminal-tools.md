# dsh-shared-terminal-tools

> 标签: deepseek-harness, dsh, plugin, shared, terminal, tools

## 简介

Agent half of the shared terminal for DeepSeek Harness: shared_terminal_* tools that read from and type into the SAME persistent PTY the user sees in the Web GUI panel (dsh-shared-terminal). Mount as a row in an agent preset.
