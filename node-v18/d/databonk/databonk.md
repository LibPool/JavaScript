# databonk

> 标签: analytics, arrow, columnar, csv, data, dataframe, simd, typescript, wasm, webassembly

## 简介

Columnar WASM dataframe library for JavaScript — pandas-familiar ergonomics, WebAssembly-accelerated kernels, dual ESM/CJS, TypeScript types.
