# dsh-ghost-prompt

> 标签: autocomplete, deepseek-harness, dsh, dsh-plugin, ghost-text, prompt-suggestion

## 简介

Prompt suggestions for DeepSeek Harness (dsh): after each turn the model predicts your next message and shows it as ghost text in the composer; press → to accept
