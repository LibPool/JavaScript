# dsh-progress-bar

> 标签: deepseek-harness, dsh, dsh-bundle, dsh-plugin, progress, progress-bar, status

## 简介

A task progress bar for the DSH Web GUI. Host-inject mode: the host half serves /dsh-progress-bar/state and injects plain JS through webserver/index-inject; it deliberately declares no client half. The progress source defaults to $DSH_HOME/dsh-progress/st
