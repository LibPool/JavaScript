# declarative-mapper

> 标签: config-driven, data-mapper, data-transformation, json, json-mapper, json-to-json, json-transformation, json-transformer, mapper, mapping, nodejs, object-mapper, object-mapping, transformation, typescript

## 简介

Declarative JSON data transformation and object mapping library for JavaScript/TypeScript with mapping templates, schema-based helpers, and safe VM execution.
