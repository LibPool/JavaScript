# dsh-effort-slider

> 标签: deepseek, deepseek-harness, dsh, effort, plugin, reasoning, slider, webgl

## 简介

把 DSH 官方模型菜单里的「推理等级 / Effort」下拉替换为 Codex 风格连续滑块 + 流光粒子动效（WebGL2）。面板配色恒定跟随官方 Harness 主题（theme/change 实时切换），无需单独设置外观。零依赖宿主半边，克隆后 dsh plugin add 即可用。
