# dsh-user-rules

> 标签: cordis, deepseek-harness, dsh, llm, plugin, rule-compiler, rules, system-prompt, user-rules

## 简介

DSH 用户规则注入器：把用户自定义的长期规则持久化到本地，并在每次模型请求里注入系统提示；提供 /rules 斜杠命令、user_rules 模型工具、HTTP 管理接口与 Web 图形管理页（设置 → 用户规则）。1.1.0 起支持「一键优化」：用指定模型把自然语言需求编译成机器可读规则，确认后批量增改删。
