# dsh-ui-auth

> 标签: auth, authentication, deepseek-harness, dsh, dsh-plugin, login, passkey, two-factor, webauthn

## 简介

DSH Web UI 认证网关：登录保护全部 HTTP/WS 接口；用户管理、邀请码注册、TOTP 两步验证与通行密钥（Passkey/WebAuthn）登录。
