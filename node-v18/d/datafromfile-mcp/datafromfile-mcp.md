# datafromfile-mcp

> 标签: claude, datafromfile, extraction, mcp, model-context-protocol, pdf

## 简介

MCP server for Datafromfile — extract structured table data from local PDFs, images, CSV, JSON, and Excel files, from Claude Desktop, Claude Code, or Cursor.
