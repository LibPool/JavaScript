# dsh-token-metrics

> 标签: balance-monitor, budget-tracking, cost-tracking, deepseek, deepseek-harness, dsh-plugin, observability, performance-metrics, token-usage, usage-statistics

## 简介

统计所有经过 DeepSeek Harness 的模型调用：Token 用量、成本核算（含峰谷计价）、首字延迟与输出速度、供应商余额与配额、预算，并按模型/供应商/项目/来源/账号/日期拆分。
