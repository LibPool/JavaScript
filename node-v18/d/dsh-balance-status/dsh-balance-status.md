# dsh-balance-status

> 标签: balance, deepseek, deepseek-harness, dsh, plugin, quota, statusbar, usage, web

## 简介

DeepSeek 余额与用量状态栏插件：输入框下方一行显示余额 + 今日消费，悬浮看近 7 天消费；官方全账号口径（可选平台令牌）与本地估算双数据源
