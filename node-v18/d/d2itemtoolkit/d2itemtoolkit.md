# d2itemtoolkit

> 标签: d2, diablo-ii, diablo2, game, item, modding, reverse-engineering, tooltip

## 简介

Diablo II 1.14d item description engine, reimplemented from the disassembly. Renders the exact tooltip the game would draw, with the shipped tables embedded so it works with no game install.
