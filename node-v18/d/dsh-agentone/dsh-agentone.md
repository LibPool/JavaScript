# dsh-agentone

> 标签: agentone, dsh, dsh-plugin

## 简介

AgentOne 平台集成插件：飞书登录、平台模型（同步失败自愈重试）、SkillHub 技能（升级检测一键升级、装后即时刷新、套餐技能自动同步）、套餐申请、插件管理与自助升级、lark-cli / ccpg-cli 探测与一键安装（请求超时与错误码透传、令牌轮换 single-flight、凭据损坏容错与并发安全写入、状态页 UX 增强）
