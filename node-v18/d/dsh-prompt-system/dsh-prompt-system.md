# dsh-prompt-system

> 标签: deepseek-harness, dsh-plugin, prompt-enhancement, prompt-optimizer

## 简介

提示词优化插件：模型选择左侧「优化提示词」按钮，结合当前对话与工作区文件，把草稿优化为「目标/实现措施/约束」三段式精准提示词，支持一键撤销
