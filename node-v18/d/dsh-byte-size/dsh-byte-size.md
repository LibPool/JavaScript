# dsh-byte-size

> 标签: byte, deepseek-harness, dsh, dsh-plugin, size, 大小

## 简介

字节大小格式化：把任意字节数换算为 B/KB/MB/GB/TB 等人类可读格式，支持二进制与十进制前缀（Byte size formatting tool for DeepSeek Harness）
