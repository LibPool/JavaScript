# da-qr-watermark

> 标签: PDF, QR, api, document, qr-code, watermark

## 简介

An example of using the DocumentAlchemy API to generate a QR code and then stamp it on each page of a PDF as a watermark image.

## 官网

- 官网：https://documentalchemy.com
- 源码仓库：https://github.com/DocumentAlchemy/sample-code
- npm 页面：https://www.npmjs.com/package/da-qr-watermark
