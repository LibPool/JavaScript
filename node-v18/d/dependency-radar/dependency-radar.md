# dependency-radar

> 标签: analysis, audit, cli, dependencies, dependency, deprecated, html, license, maintenance, node, npm, report, scan, security, unmaintained

## 简介

Local-first dependency analysis tool that generates a single HTML report showing risk, size, usage, and structure of your project's dependencies.
