# dipend

> 标签: clean-architecture, container, dependency-injection, dependency-injection-container, dependency-inversion, dependency-management, di, dipend, injection, interface-based-injection, inversion-of-control, ioc, singleton, solid-principles, transient, typescript, typescript-dependency-injection, typescript-di, typescript-ioc, typescript-library

## 简介

This library implements a dependency injection (DI) system in JavaScript/TypeScript, making it easier to manage dependencies in modular applications.
