## 简介

Session Archaeologist — cross-session full-text search over local DSH sessions with SQLite FTS5, scoped filters, timeline summaries, and bounded bring-to-context excerpts. 会话考古：本地 session 全文检索 / 作用域过滤 / 结构化时间线 / 受限摘要注入当前上下文。
