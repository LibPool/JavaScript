# dsh-locale-zh-tw

> 标签: deepseek-harness, dsh, dsh-plugin, i18n, locale, zh-hant, zh-tw, 繁體中文

## 简介

DSH Web 介面繁體中文（台灣）語言包：npm install 即可加入 zh-TW 語系，全介面自動簡轉繁，繁中瀏覽器自動切換
