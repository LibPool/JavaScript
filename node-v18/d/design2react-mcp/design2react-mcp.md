# design2react-mcp

> 标签: ai, codegen, frontend, mcp, model-context-protocol, react

## 简介

MCP server: turn design screenshots into React+JS code via a 7-stage pipeline with human-in-the-loop checkpoints and a render-compare fidelity loop.
