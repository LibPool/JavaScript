# dsh-session-find

> 标签: conversation, ctrl-f, deepseek-harness, dsh, dsh-plugin, find-in-page, search

## 简介

Ctrl+F find-in-session for DeepSeek Harness: full-text search over the loaded conversation, with source labels, turn grouping, regex / case / whole-word options and Markdown export.
