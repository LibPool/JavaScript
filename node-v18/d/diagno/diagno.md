# diagno

> 标签: ai, anthropic, claude, cli, debugging, developer-tools, devx, docker, error-diagnosis, jest, testing, typescript

## 简介

AI-assisted CLI that diagnoses failed developer commands: deterministic checks first, AI as a fallback reasoning layer, and safe, explicit fixes you approve before they touch a file.
