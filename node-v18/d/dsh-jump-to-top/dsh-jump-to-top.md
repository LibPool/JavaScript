# dsh-jump-to-top

> 标签: back-to-top, chat, deepseek, deepseek-harness, dsh, dsh-plugin, plugin, scroll, ui

## 简介

A tiny DeepSeek Harness web plugin: floating back-to-top button next to the official toBottom button in the chat view.
