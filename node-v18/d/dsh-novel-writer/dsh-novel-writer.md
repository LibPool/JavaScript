# dsh-novel-writer

> 标签: ai-writing, chinese-novel, creative-writing, deepseek-harness, dsh, dsh-plugin, emotion-analysis, fiction, novel-writing, quantification, semantic-search, sentence-analysis, story-plot, style-analysis, text-analysis, vibe, webnovel, writing-assistant, writing-tool

## 简介

小说写作助手插件（v5.1.1）：句式/情感/意象分析、伏笔设定管理、本地语义检索、氛围光谱、风格画像报告、文笔六维基线带、原创模式与创作资料、写作哨兵（衔接/OOC/大纲）；附 stdio MCP 服务器（Claude Desktop / Cursor 可用）。
