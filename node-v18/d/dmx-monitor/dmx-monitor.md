# dmx-monitor

> 标签: art-net, artnet, cli, dmx, dmx512, e1.31, lighting, monitor, playback, recorder, sacn, stage-lighting, streaming-acn, terminal

## 简介

A Node.js console application for monitoring, recording, and playing back sACN (E1.31) and Art-Net DMX traffic in real-time.
