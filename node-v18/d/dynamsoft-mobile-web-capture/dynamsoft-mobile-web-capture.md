# dynamsoft-mobile-web-capture

> 标签: document scanning, javascript, js

## 简介

Dynamsoft Mobile Web Capture (MWC) is an advanced sample designed to extend the features of Dynamsoft Mobile Document Scanner (MDS) with multi-document management, annotation, and uploading.
