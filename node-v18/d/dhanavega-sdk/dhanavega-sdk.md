# dhanavega-sdk

> 标签: JavaScript

## 简介

Official TypeScript client for the Dhanavega API — generated types (openapi-typescript) over a thin openapi-fetch runtime core (auth, Idempotency-Key, problem+json, pagination). See issue #41, ADR 0037.
