# dsh-arrowkey-nav

> 标签: deepseek, dsh, dsh-plugin, harness, keyboard, navigation

## 简介

Arrow-key navigation for the DSH Web GUI: Up/Down switch sessions inside the current workspace, Left/Right switch workspaces.
