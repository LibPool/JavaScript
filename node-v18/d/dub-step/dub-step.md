# dub-step

> 标签: WAI-ARIA, accessibility, carousel, enhanced input, function as child, index, prop getter, react, slideshow, step, swipe

## 简介

A set of primitives for building step/index based UI widgets controlled by swipe, timers, and/or buttons.
