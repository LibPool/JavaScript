# dependency-fitness-mcp

> 标签: ai-agents, coding-agent, dependencies, dependency-audit, deprecated, deprecation, deps.dev, llm-tools, mcp, mcp-server, migration, model-context-protocol, modelcontextprotocol, npm, osv, package-fitness, safe-migration-target, slopsquatting, superseded, supply-chain, supply-chain-security, yanked

## 简介

MCP server that returns a cross-validated dependency FITNESS verdict for npm packages: deprecated / yanked / superseded status plus an inferred safe migration target — what to move to and how confident we are — cross-checked across the npm registry, deps.
