# dsh-theme-tarkov

> 标签: audio, bgm, dsh, dsh-plugin, status-line, tarkov, theme, web-ui

## 简介

Escape from Tarkov themed plugin for the DeepSeek Harness Web UI: hero Beta-warning banner, background music dock, event sound effects (done / approval / error), an Altyn desktop pet, and a randomized running-status line, with a Settings > Plugins panel.
