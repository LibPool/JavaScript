# dsh-moli

> 标签: deepseek-harness, dsh-plugin, headless-browser, markdown, moli, screenshot

## 简介

DeepSeek Harness tools for the local Moli headless browser: rendered fetches, markdown, semantic trees, screenshots, and PDFs.
