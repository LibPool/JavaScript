# dsh-client-ui-second-brain

> 标签: ai-notes, chatgpt, deepseek-harness, doubao, dsh, knowledge-management, obsidian, second-brain

## 简介

AI 第二大脑: 把每天和各种 AI 的对话（豆包 / ChatGPT / DeepSeek / Kimi / 通义…）提炼成结构化 Markdown 笔记写入 Obsidian 库。设置页新增「AI 第二大脑」面板，支持粘贴 / 文件导入 / 分享链接 / Harness 会话四种录入方式，版式偏好、多课题自动分篇、提炼后自检、视觉模型识别图片内容，服务商可任意切换（OpenAI 兼容）。
