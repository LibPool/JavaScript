# dsh-plugin-subscriptions

> 标签: chatgpt, claude, codex, deepseek-harness, dsh-plugin, github-copilot, google-antigravity, grok, llm, oauth

## 简介

Use ChatGPT (Codex), Claude, Grok (X Premium), GitHub Copilot, and Google Antigravity subscriptions as DeepSeek Harness LLM providers, with OAuth login from the web Settings page
