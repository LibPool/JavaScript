# dsh-context-length

> 标签: context, context-window, cordis, deepseek-harness, dsh, plugin, settings

## 简介

DSH (DeepSeek Harness) 插件：在「设置 - 模型」下方新增「上下文长度」页面，为指定渠道（提供方）的指定模型自定义上下文窗口长度，点击保存后才写入生效。
