# directus-typeforge

> 标签: JavaScript

## 简介

**Directus TypeForge** generates TypeScript definitions for Directus collections from a schema snapshot file or directly from a live Directus server. It supports both custom and system collections, providing accurate types for use with the Directus TypeSc
