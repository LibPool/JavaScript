# dsh-date-calc

> 标签: date, dsh, intl, plugin, workday

## 简介

Date calculation plugin for DeepSeek Harness: date arithmetic with month-end clamping, workday counting (holiday/weekend aware), and Intl-based formatting. Zero runtime dependencies.
