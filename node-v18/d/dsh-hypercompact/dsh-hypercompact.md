# dsh-hypercompact

> 标签: byte-budget, compaction, context-compression, context-window, deepseek-harness, dsh, dsh-plugin, dsh-plugins, llm, plugin

## 简介

Deterministic, zero-LLM, byte-budget context compaction for DeepSeek Harness, with byte-exact recall of compacted history.
