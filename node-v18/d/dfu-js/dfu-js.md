# dfu-js

> 标签: DFU, Nordic, Semiconductor, bluetooth, nRF5, nrf51, nrf52, web

## 简介

a web bluetooth library for performing DFU of Nordic Semiconductor SOCs. Includes Vue.js Mixin for simplifed use.
