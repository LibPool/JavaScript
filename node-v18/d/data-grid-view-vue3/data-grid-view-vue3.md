# data-grid-view-vue3

> 标签: data-visualization, datagrid, table, typescript, vtable, vue3

## 简介

基于 vTable 库封装的高性能数据表格组件，类似于 WinForm DataGridView，支持虚拟滚动、实时编辑、多主题等功能。
