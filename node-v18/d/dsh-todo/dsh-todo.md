# dsh-todo

> 标签: deepseek-harness, dsh, plugin, sidebar, todo

## 简介

DSH 侧边栏待办插件：零 token 的待办面板（sidebar 入口 + 悬浮面板），数据自动保存到工作区 desktop-todo/data/todos.json，AI 可直接读取用于日报/周报。
