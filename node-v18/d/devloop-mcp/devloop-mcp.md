# devloop-mcp

> 标签: ai-agents, browser, browser-automation, claude, claude-code, correlated-timeline, dev-server, devtools, electron, expo, logs, mcp, model-context-protocol, observability, puppeteer, react-native, repro

## 简介

Unified dev-loop: one MCP server exposing browser control + dev-server logs on a correlated timeline. Headless (stdio) or Electron cockpit (HTTP).
