# dx-grid-inspector

> 标签: design-system, design-tokens, devtools, inspector, react

## 简介

Inspect a real React UI in development, calibrate its radius, padding and colour tokens, and copy them out as CSS, JSON or an agent prompt. No backend and no AI calls.
