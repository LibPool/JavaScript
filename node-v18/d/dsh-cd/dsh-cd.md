# dsh-cd

> 标签: cd, cordis, cwd, deepseek-harness, directory-switch, dsh, dsh-plugin, relative-path, session, shell, working-directory, 会话目录, 切换目录, 工作目录, 相对路径

## 简介

Session working-directory override for DeepSeek Harness: a `cd` tool that makes relative paths in the file tools and the bash tool's default workdir follow the new directory, per-session and cache-safe, without moving the session or its workspace root. ds
