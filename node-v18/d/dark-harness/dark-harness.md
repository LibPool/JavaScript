# dark-harness

> 标签: JavaScript

## 简介

Dark Harness (dh) — a single-binary LLM agent harness for autonomous dark-factory software work, with console and web UIs. Name reservation placeholder; a real multi-platform release is coming (see https://github.com/stefanrusek/dark-harness).
