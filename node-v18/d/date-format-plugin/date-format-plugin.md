# date-format-plugin

> 标签: composition-api, date, date-format, date-format-plugin, date-formatting, datetime, formatter, i18n, intl, l10n, locale, localization, ssr, time, timezone, typescript, vue, vue-directive, vue-plugin, vue3, vuejs

## 简介

Lightweight, SSR-safe Vue 3 date formatting plugin with Composition API, Options API, and directive support. Multi-locale, timezone-aware date formatting built on the native Intl API, with full TypeScript types.
