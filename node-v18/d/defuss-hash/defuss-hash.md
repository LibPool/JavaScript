# defuss-hash

> 标签: consistent-hash, content-hash, deduplication, defuss, distributed-systems, federated-systems, hash, isomorphic, jit-optimized, json, rendezvous-hash, stable-hash

## 简介

A library of fast and stable special-purpose hashing functions: JIT-optimized content hashing with key-order stability and skip paths, rendezvous hashing, etc.
