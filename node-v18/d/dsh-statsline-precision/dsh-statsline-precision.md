# dsh-statsline-precision

> 标签: JavaScript

## 简介

dsh web GUI 客户端插件：以 slot shadow 覆盖官方 StatsLine（conversation.composer.dock id=stats），把「缓存命中」百分比显示改为 3 位精度（如 99.9%），其余统计行内容保持不变。

- npm 页面：https://www.npmjs.com/package/dsh-statsline-precision
