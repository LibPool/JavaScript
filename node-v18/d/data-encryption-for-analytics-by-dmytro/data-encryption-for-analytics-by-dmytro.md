# data-encryption-for-analytics-by-dmytro

> 标签: analytics, data, encryption, security

## 简介

JavaScript package for encrypting and decrypting data in analytics applications. Uses AES-256-CBC encryption with Initialization Vector (IV) for enhanced security.
