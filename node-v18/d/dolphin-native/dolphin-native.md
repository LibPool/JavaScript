# dolphin-native

> 标签: android, binary, camera, cross-platform, dolphin-native, dolphinjs, framework, gps, hardware, hot-reload, ios, jsx, mobile, native, react-native-alternative, sensors, titan, ui-framework

## 简介

DolphinJS — Hybrid UI framework that compiles JSX/HTML to 16-byte Titan binary and renders natively on Android. Full hardware access: Camera, GPS, Phone, SMS, Contacts, Audio, Video, File system, Sensors, Battery, Bluetooth, NFC, Fetch and more.
