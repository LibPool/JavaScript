# dsh-comments

> 标签: annotation, comments, cordis, cordis-plugin, deepseek-harness, dsh, dsh-plugin, review

## 简介

Comments for DeepSeek Harness: 劃選助手回覆的任意片段 → 選點評類型 + 寫意見 → 高亮標記,一鍵把全部點評組裝成「引用 + 意見」的結構化消息插入輸入框或直接發送。
