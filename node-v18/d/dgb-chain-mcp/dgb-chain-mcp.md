# dgb-chain-mcp

> 标签: ai-agents, blockchain-data, digibyte, digidollar, mcp, oracle

## 简介

Let any AI agent query DigiByte directly: network stats, DigiDollar supply, oracle health, prices, addresses, transactions. Read-only, works on mainnet.
