# dsh-node-compat

> 标签: compat, deepseek-harness, dsh, dsh-plugin, import.meta.main, node-version, silent-exit

## 简介

Runs DeepSeek Harness on a Node runtime where its import.meta.main entry guard silently no-ops, with a clear diagnosis instead of a silent exit.
