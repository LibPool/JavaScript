# dsh-code-diff-stat

> 标签: chat-ui, code-change, cordis, deepseek-harness, diff, diffstat, dsh, dsh-plugin

## 简介

DSH Web 插件：在聊天流中按轮次汇总代码改动量（+N −M），可展开查看每个文件明细。 · DSH plugin: per-turn code-change stats (+N −M) rendered directly in the chat flow, expandable to a per-file breakdown.
