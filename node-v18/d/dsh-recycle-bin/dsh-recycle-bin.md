# dsh-recycle-bin

> 标签: cordis, deepseek, dsh, dsh-plugin, recycle-bin, session, session-management, workspace

## 简介

Delete DSH sessions into a restorable recycle bin — subagent sessions follow their parent as one tree, and only purge destroys bytes.
