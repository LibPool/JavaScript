# dsh-balance-meter-web

> 标签: JavaScript

## 简介

Enhanced fork of dsh-balance-meter (Ghost011118, BSD-3-Clause): DeepSeek account balance and usage readout for the dsh web GUI, with previous-turn cost, 4-decimal banker's rounding, auto-refresh and phone layout.
