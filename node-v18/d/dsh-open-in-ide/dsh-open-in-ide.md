# dsh-open-in-ide

> 标签: cursor, deepseek-harness, dsh, dsh-plugin, editor, ide, intellij, jetbrains, pycharm, vscode, webstorm

## 简介

Open file references from the DeepSeek Harness chat output in your IDE (VS Code family or JetBrains, Visual Studio Code by default), positioned at the referenced line, in its project window, brought to the foreground, and self-updating from GitHub.
