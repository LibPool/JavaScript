# dsh-review-checkout

> 标签: deepseek, diff, dsh, dsh-plugin, harness, review

## 简介

File-change review for DeepSeek Harness sessions: per-turn change cards styled like the official deliverables card with one-click per-turn revert, a turn-scoped review tab (draggable split diff, syntax highlighting, real line numbers), and a three-step op
