# dsh-pause

> 标签: deepseek-harness, dsh, dsh-plugin, gate, pause, steer, tool-round

## 简介

DSH Web 暂停插件：agent 完成一轮工具交互、正要发出下一次模型请求之前暂停，保持 composer 输入框可用，人类以回车/发送放行并可携带补充文字；此暂停不打断任何在途 API 调用，模型上下文始终完整、无感知。纯插件自包含，不改 DSH 源码。
