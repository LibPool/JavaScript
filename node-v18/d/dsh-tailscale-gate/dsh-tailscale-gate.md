# dsh-tailscale-gate

> 标签: cordis, deepseek-harness, dsh, plugin-bundle, remote-access, serve, tailnet, tailscale, vpn, websocket

## 简介

DeepSeek Harness plugin that automates Tailscale-based remote access to the DSH Web UI on Linux: `tailscale serve --tcp` plus a header-rewriting proxy so tailnet devices reach the UI without `ssh -L` or `--trusted-host`, with optional PIN gate, tailnet ac
