# dsh-i18n-ja

> 标签: dsh, dsh-bundle, dsh-plugin, i18n, japanese, language-pack, locale, 日本語

## 简介

DSH Web GUI 日本語ロケールパック: registers the 日本語 language into the shared locale catalog and carries the ja dictionaries for every dsh-web-all family plugin namespace (missing keys fall back to English through the SDK chain).
