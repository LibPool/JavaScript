# dsh-hold-to-talk

> 标签: asr, deepseek-harness, dictation, dsh, dsh-plugin, hold-to-talk, plugin, push-to-talk, sensevoice, sherpa-onnx, speech-to-text, voice, voice-input, wechat

## 简介

Hold-to-talk voice input for the DeepSeek Harness Web composer: hold the mouse on the input box, speak, see the running transcript float above it, release to insert the text into the draft. Recognition runs locally (SenseVoice via sherpa-onnx) — no API ke
