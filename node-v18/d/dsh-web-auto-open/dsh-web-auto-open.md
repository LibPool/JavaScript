# dsh-web-auto-open

> 标签: auto-open, browser, bundle, deepseek-harness, dsh, launcher, one-step, plugin, web

## 简介

dsh plugin: auto-open the default browser as soon as the dsh web GUI server is listening — one-step startup for `dsh web`
