# dsh-focus-brief

> 标签: agent-answer, chat-ui, deepseek-harness, dsh, dsh-plugin, focus-view

## 简介

把 agent 每轮的回答压成一张结果卡：一句结论 + 默认收起的信息块（需要你确认 / 关键数据 / 产出文件 / 结论建议 / 风险提醒）。块的骨架写死在本地，内容由模型按同一份回答格式契约填，不额外调用模型。
