# @aicommander/agent

> 标签: agent, ai-agent, aicommander, background-jobs, claude, devops, gpu-compute, long-running-jobs, ml-training, remote, remote-execution, remote-jobs, ssh-alternative, sysadmin, systemd

## 简介

Remote-machine agent for AI Commander — lets Claude, Codex and other AI agents run shell commands and detached long-running jobs, builds, batch work, and GPU/ML training on your server or laptop. No exposed SSH, open ports, or VPN.
