# @teonord/useform

> 标签: api-client, file-upload, form, form-data, form-handling, form-management, form-state, form-submit, form-validation, frontend, hook, http-request, inertia, inertiajs, javascript, npm-package, react, react-form, react-hooks, react-library, typescript, typescript-react, ui, useform, web-development

## 简介

React form hook for managing form state, validation, and HTTP requests. TypeScript support, file uploads, and Inertia.js-like API. Standalone alternative to useForm.
