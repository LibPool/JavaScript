# @feedmepos/mf-upselling

> 标签: JavaScript

## 简介

The merchant settings microfrontend for Connect. All feature UI lives here; the API runs in report-query-service under `packages/node`. Connect imports the UI and supplies its existing authenticated context. No new service or menu editor.
