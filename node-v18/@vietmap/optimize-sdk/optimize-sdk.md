# @vietmap/optimize-sdk

> 标签: custom-elements, fleetwork, lit, optimize, react, route-optimization, sdk, vehicle-routing, vietmap, vrp, web-component

## 简介

SDK for the Fleetwork Optimize API (VROOM-style vehicle routing): headless core + web components + React bindings, in one package with subpath exports.
