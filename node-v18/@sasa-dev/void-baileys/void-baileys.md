# @sasa-dev/void-baileys

> 标签: automation, baileys, bot, buttons, interactive-messages, js-whatsapp, multi-device, pairing-code, typescript, void-baileys, whatsapp, whatsapp-api, whatsapp-bot, whatsapp-web

## 简介

Void Baileys is a full-featured TypeScript WhatsApp Web API library, built on the Baileys v7 engine with complete button support, interactive messages, albums, pairing-code push notifications and many extra features.
