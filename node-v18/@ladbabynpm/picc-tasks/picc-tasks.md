# @ladbabynpm/picc-tasks

> 标签: pi, pi-extension, pi-package, tasks, todo, tracking

## 简介

Claude Code style TaskCreate, TaskGet, TaskList, and TaskUpdate tools for pi, a more faithful port of Claude Code's harness than @tintinweb/pi-tasks.
