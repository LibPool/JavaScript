# @magdalenaromanowska/randomid-generator

> 标签: JavaScript

## 简介

- Random ID generator module that creates by default 10-digits ID (mixed letters and numbers). - One can change amount of digits by giving the number in:  ```javascript randomID(); ``` for example  ```javascript randomID(25); ```
