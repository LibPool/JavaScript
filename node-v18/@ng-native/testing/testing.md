# @ng-native/testing

> 标签: android, angular, angular-native, fabric, ios, native, node-test, react-native, testing, testing-library, vitest

## 简介

Test Angular Native components in Node with no simulator: a fake Fabric, Testing Library queries and events, and Vitest and node:test integration.
