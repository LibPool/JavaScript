# @ng-native/analog

> 标签: analog, analogjs, android, angular, angular-native, content, fabric, file-based-routing, ios, markdown, native, react-native, router

## 简介

Analog's file-based pages and content files for Angular Native: src/app/pages, routed by @analogjs/router on a native stack, and src/content read as @analogjs/content reads it.
