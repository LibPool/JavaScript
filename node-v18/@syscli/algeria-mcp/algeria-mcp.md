# @syscli/algeria-mcp

> 标签: algeria, algerie, commune, dz, mcp, model-context-protocol, wilaya

## 简介

MCP server for Algeria's wilayas and communes: search, lookups, GPS points, the 2019 and 2026 reforms, and checks for Algerian formats.
