# @syscli/mytpe

> 标签: algeria, api, cib, edahabia, mytpe, payment, payment-link, satim, sdk, webhooks

## 简介

Typed MyTPE Pay API client for Node. Payment links, terminals, forms, and webhooks for card payments in Algeria. Server-side only.
