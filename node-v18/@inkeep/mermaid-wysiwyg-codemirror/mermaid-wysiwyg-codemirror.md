# @inkeep/mermaid-wysiwyg-codemirror

> 标签: codemirror, diagram, editor, mermaid, visual-editing, wysiwyg

## 简介

CodeMirror 6 binding for mermaid-wysiwyg: two-way code sync, entity highlight decorations, shared undo authority.
