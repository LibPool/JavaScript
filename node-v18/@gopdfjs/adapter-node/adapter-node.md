# @gopdfjs/adapter-node

> 标签: JavaScript

## 简介

Node GopdfAdapter — loads shared @gopdfjs/wasm (feeds .wasm bytes to init), pdf.js, napi-canvas, OCR. Run pnpm --filter=@gopdfjs/wasm build:wasm first.
