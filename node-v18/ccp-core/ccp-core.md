# ccp-core

> 标签: JavaScript

## 简介

The TypeScript implementation of the Capability Contacts Protocol (draft v0.4), shaped by role: **Requester**, **Consumer**, **Runtime**, **Agent**. It reproduces the frozen v1, v2, and v3 vectors in `../../test-vectors/`.
