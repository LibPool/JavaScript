# @webnori/codescan-cli

> 标签: cli, code-search, fts5, git-blame, source-analyzer, tui

## 简介

CLI/TUI/GUI source-code scanner with FTS5 search and git blame. (npm wrapper around the prebuilt CodeScan binary.)
