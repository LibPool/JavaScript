> 标签: cli, cocoapods, expo, flutter, ios, migration, podfile-lock, react-native, swift-package-manager, swiftpm

## 简介

Shows which CocoaPods dependencies stop getting updates when CocoaPods trunk goes read-only on December 2, 2026, and which already ship a Swift package.
