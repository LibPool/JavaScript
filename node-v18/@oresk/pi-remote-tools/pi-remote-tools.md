# @oresk/pi-remote-tools

> 标签: pi, pi-coding-agent, pi-extension, pi-package, remote, ssh

## 简介

Remote SSH tools for pi coding agent. Provides ssh-read, ssh-write, ssh-edit, and ssh-bash with per-call host targeting.
