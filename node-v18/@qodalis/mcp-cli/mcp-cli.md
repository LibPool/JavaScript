# @qodalis/mcp-cli

> 标签: ai, claude, claude-code, cli, mcp, model-context-protocol, proxy, qodalis

## 简介

Model Context Protocol (MCP) server for Qodalis CLI servers: gives Claude Code the server's commands, files, data explorer and jobs through a resilient stdio proxy to the server's MCP endpoint.
