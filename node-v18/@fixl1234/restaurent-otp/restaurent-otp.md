# @fixl1234/restaurent-otp

> 标签: guest-auth, one-time-password, otp, phone-otp, phone-verification, restaurant, restaurant-sdk, smartdine, sms-otp, typescript

## 简介

SmartDine SDK OTP module — phone-based one-time password authentication for restaurant guests. Request OTP via SMS, verify the code, and receive a short-lived guestToken for placing window/takeaway orders without a full account.
