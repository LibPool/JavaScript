# @fc2cma/cli

> 标签: bun, cli, fc2, magnet, scraper, sukebei

## 简介

Unofficial CLI for the FC2 Content Market (Adult): subscribe to sellers, sync works into SQLite, track prices, cross-check sukebei magnets.
