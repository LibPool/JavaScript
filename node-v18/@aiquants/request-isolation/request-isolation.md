# @aiquants/request-isolation

> 标签: cross-origin, csrf, fetch-api, fetch-metadata, origin, request-isolation, sec-fetch-site, typescript

## 简介

Host-agnostic cross-origin check for server routes: one decision over Fetch Metadata and Origin, taken before authentication, that refuses requests started by a page of another origin (sibling subdomains included) unless the route serves that top-level do
