# @aiquants/contact-map

> 标签: contact-map, directory-tree, drizzle, fuzzy-search, mssql, ndjson, react-router, typescript, virtual-scroll, web-worker

## 简介

Reusable contact-map feature package: shared types/schemas, React (Router v7 / v8) UI with virtual scrolling + tree view + incremental Web Worker + fuzzy search + resize panels, and a drizzle (mssql) server layer with DI ports.
