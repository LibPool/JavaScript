# @consciousclouds/ui

> 标签: JavaScript

## 简介

ConsciousClouds UI Primitives — shadcn/ui-derived primitives (open MIT registry only) styled against the Token System's role names. Layer 2 of the Frontend Platform; consumes token roles as CSS classes only, carries no brand, no flavor, no product.
