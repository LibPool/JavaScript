# @consciousclouds/canvas-sdk

> 标签: JavaScript

## 简介

Conscious Clouds Canvas SDK — CanvasDefinition types, Component Registry allowlist, the IExperienceProvider adapter contract, a thin read client, and the ./storage write seam (durable Canvas write client). Framework-agnostic, domain-agnostic.
