# @busyexplore/zotonic-audio-util

> 标签: JavaScript

## 简介

A tiny utility for normalizing different binary input types (URLs, `Request` objects, `Blob`/`File`, `Buffer`, `ArrayBuffer`, typed arrays) into a single `ArrayBuffer`, wrapped in a small object with safe accessors.
