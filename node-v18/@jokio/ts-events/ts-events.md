# @jokio/ts-events

> 标签: Callback, Event, EventEmitter, Events, Signal, Signals, TypeScript, a-synchronous, asynchronous, event loop, event queue, eventloop, synchronous

## 简介

Various EventEmitter event replacements with synchronous, a-synchronous, and queued events. Made in TypeScript so usable with JavaScript and TypeScript.
