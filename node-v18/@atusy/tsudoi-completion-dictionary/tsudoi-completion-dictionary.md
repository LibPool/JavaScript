# @atusy/tsudoi-completion-dictionary

> 标签: JavaScript

## 简介

Completes each line of one or more UTF-8 dictionary files through `textDocument/completion`. A background Worker reads and hashes the files, then completion searches the last immutable in-memory snapshot rather than waiting for a changed file to be loaded
