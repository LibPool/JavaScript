# @blazes/webview-sdk

> 标签: JavaScript

## 简介

H5 页面需要在游戏内打开，往往借助了系统的 `webview`。而在刘海屏机型显示、键盘输入等会出现奇奇怪怪的现象。 不仅如此，H5 和游戏会有交互行为，如关闭 H5 界面。两者的联系是通过 SDK 桥梁，注册回调实现。
