# @sinete/ibs-cbs-dados

> 标签: brasil, cbs, cclasstrib, dfe, ibs, nfe, reforma-tributaria

## 简介

Dados oficiais do IBS/CBS versionados (CST, cClassTrib, cCredPres, aplicabilidade de NCM/NBS, tratamentos, atores), extraídos da Calculadora offline da RFB e do IT 2025.002 com proveniência por hash
