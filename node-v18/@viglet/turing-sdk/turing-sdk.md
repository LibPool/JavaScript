# @viglet/turing-sdk

> 标签: aem, edge-delivery-services, eds, enterprise-search, headless, sdk, search, semantic-navigation, turing, vanilla-js

## 简介

Vanilla JS SDK for Viglet Turing ES - framework-agnostic, zero-dependency client + observable controllers for enterprise search. Works in Adobe Edge Delivery Services (EDS), plain <script>, or any bundler.
