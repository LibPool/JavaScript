# @wuyaos/pi-zotero

> 标签: citation, csl, literature, pi-package, zotero

## 简介

Zotero 10 Local API 原生工具：搜索、集合导出、CSL 批量、引用审计、文献整理，供 pi agent 直接调用（不依赖 MCP）
