# @customercity/tokens

> 标签: JavaScript

## 简介

Customer City design tokens — multi-brand. DTCG source compiled by Style Dictionary to CSS (Tailwind v4 @theme), JS, and JSON. core.css = shared primitives; brands/<brand>.css = per-brand semantic colors scoped under [data-brand]. Consumed across web, mob
