# @flutter-builder/flutter-material-icons

> 标签: JavaScript

## 简介

Material icons definition is large, up to 7,000 lines, about 1mb. To optimize this on production, we provide `@flutter-builder/material-icon-types` as a types package that can be added on `devDependencies`
