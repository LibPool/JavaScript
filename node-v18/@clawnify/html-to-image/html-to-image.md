# @clawnify/html-to-image

> 标签: ai-agents, clawnify, html-to-image, og-image, openclaw, openclaw-plugin, satori, screenshot

## 简介

OpenClaw plugin — render an HTML string to a PNG file on disk (Satori + resvg, no headless browser). Lets agents turn HTML/CSS into images (status cards, summaries, simple charts) they can attach to any channel.
