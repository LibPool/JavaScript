# dsh-kb-lite

> 标签: bm25, deepseek, dsh, dsh-plugin, harness, knowledge-base, local, rag, retrieval

## 简介

Local knowledge base for DeepSeek Harness: ingest Markdown/TXT/PDF, hybrid BM25 + optional dense retrieval, explainable ranking weights (bm25/dense/RRF/source boost/recency), cited answers. Host-only plugin, five tools, no network.
