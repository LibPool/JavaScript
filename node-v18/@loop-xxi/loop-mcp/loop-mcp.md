# @loop-xxi/loop-mcp

> 标签: agent-payments, bitcoin, dual-rail, l402, lightning, mcp, micropayments, model-context-protocol, usdc, x402

## 简介

Dual-rail (x402/USDC + Lightning/L402) payment transport for the Model Context Protocol. Charge agents per tool call over either rail, settled into one canonical rail-tagged ledger.
