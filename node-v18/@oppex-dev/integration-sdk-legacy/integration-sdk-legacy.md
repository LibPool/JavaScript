# @oppex-dev/integration-sdk-legacy

> 标签: JavaScript

## 简介

Node.js SDK for posting incidents to Oppex (Node >=8, http/https transport). For Node >=18, use @oppex-dev/integration-sdk instead.

## 官网

- 官网：https://oppex.ai
- npm 页面：https://www.npmjs.com/package/@oppex-dev/integration-sdk-legacy

## 历史版本号

- 1.0.0

## 获取地址

- npm 安装：`npm install @oppex-dev/integration-sdk-legacy`
- npm registry：https://registry.npmjs.org/@oppex-dev/integration-sdk-legacy
- Node 要求：>=8.0.0
