# @oge-ui/react-charts

> 标签: accessibility, bar-chart, candlestick, chart, charts, line-chart, pie-chart, radar-chart, react, svg, typescript

## 简介

React charts from the OGE UI suite on a dependency-free SVG kernel: sixteen cartesian series types (line, spline, step, area, stacked, bar, range, scatter, bubble, candlestick), pie and doughnut, radar/polar charts and a range selector — calendar-true tim
