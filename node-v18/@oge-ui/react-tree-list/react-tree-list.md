# @oge-ui/react-tree-list

> 标签: accessibility, design-system, hierarchical-data, react, tree-grid, tree-list, treegrid, treelist, typescript, virtual-scroll

## 简介

React tree list (hierarchical data grid) from the OGE UI suite: flat parentId or nested data, lazy per-expansion child loading with remote match discovery, ancestor-preserving filtering (filter row, header filter, search, filter builder), sibling-scoped s
