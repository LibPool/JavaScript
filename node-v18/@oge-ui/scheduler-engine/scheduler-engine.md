# @oge-ui/scheduler-engine

> 标签: calendar, event-calendar, framework-free, headless, recurrence, rrule, scheduler, typescript

## 简介

Framework-free engine behind the OGE UI scheduler: view-model builders, transitive-overlap column layout, lane packing, an RFC 5545 RRULE-subset parser and expander, gesture math, keyboard maps, the editing/recurrence/CRUD core, default config and message
