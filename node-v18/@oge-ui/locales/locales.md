# @oge-ui/locales

> 标签: angular, i18n, l10n, locale, localization, react, rtl, translations, typescript

## 简介

Ready-made translations for every OGE UI message catalog — German, French, Spanish, Italian, Brazilian Portuguese, Turkish, Japanese, Simplified Chinese, Arabic and Hebrew. Framework-free data: one typed OgeLocalePack per language, each its own entry poin
