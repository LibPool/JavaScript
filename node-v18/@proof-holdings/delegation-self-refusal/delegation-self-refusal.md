# @proof-holdings/delegation-self-refusal

> 标签: agent-card, delegation, mcp, proof-of-delegation, revocation, self-enforcement

## 简介

A delegated MCP server that refuses its own tool calls once its Proof of Delegation is revoked, suspended, or expired — self-enforcement, not consumer verification
