# @rezaazk/docker-tree-master

> 标签: as

## 简介

This Docker recipe provides a Docker image of [Bitcore Wallet Service](https://github.com/bitpay/bitcore-wallet-service), based on the official node Docker image. It includes a Bitcore full node setup (Bitcoind and Insight-API).
