# @wave-av/dispatch

> 标签: agents, cost, dispatch, edge, llm, local-first, routing, wave, x402

## 简介

wave Dispatch — route each request to the cheapest capable model (local-first; escalate to your frontier model only when needed). BYO keys + infra; we return the routing decision.
