# @lascyb/monaco-editor-vue3

> 标签: JavaScript

## 简介

Monaco Editor 的 Vue 3 组件封装，提供单栏编辑器 `MonacoEditor` 和差异编辑器 `MonacoDiffEditor` 两种实现。
