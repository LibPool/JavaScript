# @martin_sol_95/n8n-nodes-pdf-convert

> 标签: document-conversion, image-conversion, n8n, n8n-community-node-package, pdf, pdf-convert, pdf-to-image, pdf-to-png, png

## 简介

n8n Community Node zum Konvertieren von PDF-Dokumenten in PNG-Bilder. Nutzt pdfjs-dist und Canvas für hochwertige Konvertierung ohne externe System-Dependencies. Jede PDF-Seite wird als separates Output-Item mit Binary Data zurückgegeben.
