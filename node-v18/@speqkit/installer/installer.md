# @speqkit/installer

> 标签: JavaScript

## 简介

Resolves plugins against the npm registry, verifies them, and puts them in the store. No npm CLI involved.

- 官网：https://github.com/speqkit/speqkit#readme
- 源码仓库：git+https://github.com/speqkit/speqkit.git
