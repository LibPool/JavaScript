# @zh-xx/antu

> 标签: agent, diagram, legal, mcp, model-context-protocol, visualization

## 简介

Antu: legal diagrams (fact, procedure, relationship, justification) from JSON, as one offline HTML page. The command line, the MCP server, and the entries to embed a diagram in an application.
