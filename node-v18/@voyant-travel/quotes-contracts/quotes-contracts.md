# @voyant-travel/quotes-contracts

> 标签: JavaScript

## 简介

Pure validation schemas for quotes, quote versions, quote lines, quote participants, quote products, pipelines, stages, and quote-facing enums, zod-only, for consumers that validate quote payloads without depending on the runtime package.
