# @voyant-travel/runtime

> 标签: JavaScript

## 简介

The public Node host for a generated Voyant project. Applications normally use `createVoyantProjectServerEntry()` for their server entry, while the external Voyant CLI uses `startVoyantProject()` for `voyant start`.
