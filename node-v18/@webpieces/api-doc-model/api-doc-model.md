# @webpieces/api-doc-model

> 标签: docs, mcp, openapi, typescript, webpieces

## 简介

TypeScript-compiler-API extractor producing one in-memory ApiDocModel from a webpieces API contract. No renderer, no runtime, no app-specific import.
