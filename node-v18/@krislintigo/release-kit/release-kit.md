# @krislintigo/release-kit

> 标签: changelog, commitlint, conventional-commits, git-hooks, npm, publint, release, release-config, semantic-release, semantic-release-config

## 简介

Opinionated, self-contained release toolkit: bundled semantic-release + commitlint defaults, a native git hook, publint, and a CLI to release and scaffold npm packages.
