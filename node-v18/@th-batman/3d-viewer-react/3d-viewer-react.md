# @th-batman/3d-viewer-react

> 标签: JavaScript

## 简介

Official React component wrapper for `@th-batman/3d-viewer-core`. Renders photorealistic 3D jewelry viewers, swatches, and customizers in Next.js, Remix, Vite, and standard React applications.
