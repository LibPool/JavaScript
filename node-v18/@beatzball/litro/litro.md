# @beatzball/litro

> 标签: declarative-shadow-dom, elena, fast-element, file-based-routing, framework, fullstack, lit, nextjs-alternative, nitro, nuxt-alternative, server-side-rendering, ssg, ssr, static-site-generation, typescript, vite, web-components

## 简介

Fullstack web framework for web components — choose Lit, FAST Element, or Elena via an adapter. File-based routing, streaming SSR, SSG, and Nitro deployment adapters. A standards-based Next.js / Nuxt.js alternative.
