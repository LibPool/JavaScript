# blastcss

> 标签: cascade-layers, container-queries, css, design-system, framework, oklch, popover, tokens, ui, view-transitions

## 简介

A modern, framework-agnostic CSS framework built on cascade layers, OKLCH tokens, container queries, and the popover API.
