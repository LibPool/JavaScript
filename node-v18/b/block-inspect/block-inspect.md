# block-inspect

> 标签: block, context menu, deterrent, dev tools, developer tools, disable copy, disable inspect, disable right click, disable selection, inspect, protect content, right click, security

## 简介

A simple JavaScript utility to deter users from opening browser developer tools (inspect element) and disable context menus, selection, and copy/paste on a website.
