# barte-sdk-web

> 标签: JavaScript

## 简介

SDK client-side da Barte para tokenização de cartão, checkout via carteira (wallet) e fingerprint antifraude, para uso em navegador. É publicado no npm como [`barte-sdk-web`](https://www.npmjs.com/package/barte-sdk-web).
