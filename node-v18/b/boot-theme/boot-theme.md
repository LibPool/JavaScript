# boot-theme

> 标签: Angular, Boot-theme, Javascript, React, Swagger, TypeScript, frontend, lab, npm, theme, theming

## 简介

Boot theme is a lightweight, configurable theming library to help you manage and apply themes in your app. Developed for easy use in any frontend framework or libraries with direct focus on development ease in setting up a fully fledged configurable theme
