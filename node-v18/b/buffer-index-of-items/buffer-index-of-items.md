# buffer-index-of-items

> 标签: JavaScript

## 简介

For when you need to find a set of tokens in a buffer. You can't use RegExp on Buffers without casting it to a string.  But you can use buffer-index-of-items, which will make you super sexy. See the API documents for MD or HTML in the same directory.
