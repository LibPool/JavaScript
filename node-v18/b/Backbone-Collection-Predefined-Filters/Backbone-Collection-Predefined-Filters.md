# Backbone-Collection-Predefined-Filters

> 标签: backbone, backbone-collection, backbone-collection-filtering, backbone-collection-filters, backbone-collection-predefined-filters, backbone-filtering, backbone-filters

## 简介

An extention of Backbone Collection that allows for predefined filter(s) to be added/removed/applied/unapplied on the collection
