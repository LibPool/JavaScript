# bd-offline-geocoder

> 标签: bangladesh, district, division, geocoding, geojson, gis, gps, maps, offline-geocoder, reverse-geocoder, union, upazila, ward

## 简介

Offline Bangladesh reverse geocoder. Convert GPS coordinates to division, district, upazila, union, and ward with no API key and no network.
