# brother-print-node

> 标签: JavaScript

## 简介

This module create a connection between your nodejs app and brother label printer. Tested on Brother QL-810w and QL-720NW only but should work on others.

## 官网

- npm 页面：https://www.npmjs.com/package/brother-print-node
