# babel-plugin-bonify-rocks

> 标签: JavaScript

## 简介

Babel plugin which transforms the `console.log(n)` calls to `console.log("Bonify rocks" + n)`.

- npm 页面：https://www.npmjs.com/package/babel-plugin-bonify-rocks
