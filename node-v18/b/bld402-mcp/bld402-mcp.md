# bld402-mcp

> 标签: ai-agent, deploy, mcp, model-context-protocol, no-code, postgres, run402, web-app-builder, x402

## 简介

MCP server for bld402 — build and deploy web apps on run402 from plain language. Handles wallet setup, payments, templates, and deployment automatically.
