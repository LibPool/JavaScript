# bunqueue-dashboard

> 标签: background-jobs, bull-board-alternative, bullmq-alternative, bun, bunqueue, cron, dashboard, dead-letter-queue, dlq, job-monitoring, job-queue-ui, queue-dashboard, react, redis-queue-ui, task-queue

## 简介

Web dashboard for a bunqueue server (queues, jobs, DLQ, cron, metrics, workers, live activity). Run with `bunx bunqueue-dashboard` (requires Bun 1.4.2).
