# bubble-maker

> 标签: animation, bubbles, canvas, hexagon, honeycomb, interactive, physics, ui

## 简介

Soap-bubble physics and rendering for the web: bubbles that grow, push each other and pack into a honeycomb. Framework-free, tiny, fully configurable.
