# beresta

> 标签: dom, dtd, native, node-api, parser, xml, xml-schema, xpath, xsd

## 简介

Берёста — быстрая XML-библиотека на C++17: DOM, XPath 1.0, XML Schema, DTD, восемь кодировок. Без зависимостей и без node-gyp.
