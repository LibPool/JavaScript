# bundle-id-cli

> 标签: CFBundleIdentifier, CFBundleName, applescript, bundle, bundleid, bundlename, cli, cli-app, id, identifier, macos, plist, uti

## 简介

Get bundle identifier from a bundle name (macOS): `Safari` → `com.apple.Safari`
