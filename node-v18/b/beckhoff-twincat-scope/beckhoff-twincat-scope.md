# beckhoff-twincat-scope

> 标签: ads, analytics, analytics-logger, beckhoff, csv, dataexchange, parser, scope, scope-view, svb, svdx, tad, tas, tay, twincat, twincat-analytics

## 简介

Parser for Beckhoff TwinCAT Scope-View .svdx / .svb recording files and TwinCAT Analytics .tas/.tad/.tay recordings. Reads and writes Analytics data, exports channel/acquisition data to CSV and generates .tcscopex projects.
