# bstm-cli

> 标签: JavaScript

## 简介

- [x] 添加api引用查找器（example:传入一个api地址，返回该api引用的api列表） - [ ] 功能模块生成器（example:传入一个功能模块名称，生成该模块的代码） - [x] word转vue组件（example:传入一个word文档，生成该文档的vue组件,感觉打印那边会用到） - [ ] 是不是可以通过配置的方式生成echarts图表 - [x] 通过命令修改镜像 - [x] 查看项目命令列表显示项目命令 - [ ] 是否可以等项目构建完成之后上传到服务器 - [
