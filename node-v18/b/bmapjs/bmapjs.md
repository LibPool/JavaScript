# bmapjs

> 标签: attribute, bitcoin, bmap, bsv, magic, protocol

## 简介

A transaction parser for Bitcoin data protocols like B, MAP, BAP, 1Sat Ordinals, SIGMA, METANET, and AIP/HAIP.
