# bk-schema-checker

> 标签: bk-schema-checker, cli, django, drf, mock, schema, schema-checker, typescript

## 简介

对照前端 services、Django REST 序列化器，以及可选的 bk-local-mock 响应，做接口协议检查。不启动 Django。
