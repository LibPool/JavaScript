# brain-memory

> 标签: ai-agent, claude-code, context-engineering, file-based, gemini-cli, hierarchical-memory, memory, neuroscience, openai-codex, opencode, slash-commands, spaced-repetition

## 简介

A brain-inspired hierarchical memory system for AI coding agents. Deep nested file structure that mimics human memory with time-decay and strength-based recall.
