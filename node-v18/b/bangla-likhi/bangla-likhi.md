# bangla-likhi

> 标签: Bangla, Bijoy2Unicode, Language, Unicode2Bijoy

## 简介

This is a bangla unicode-bijoy-unicode converter and bangla typing easy to using bijoy 52 supporting on this banglalikhi.com project.
