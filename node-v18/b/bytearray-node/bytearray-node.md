# bytearray-node

> 标签: AMF, AMF0, AMF3, Action Message Format, Actionscript, Adobe, Binary, Buffer, ByteArray, Flash, Javascript, Node

## 简介

A Node.js implementation of the Actionscript 3 ByteArray supporting AMF0/AMF3.
