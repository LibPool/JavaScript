# babel-plugin-yxbj-icon

> 标签: JavaScript

## 简介

该插件主要功能是在构建的过程中提取引入的 Icon 组件，按需从远程下载图标，保存到本地，并将引入路径替换为下载的 Icon 组件路径

## 官网

- npm 页面：https://www.npmjs.com/package/babel-plugin-yxbj-icon
