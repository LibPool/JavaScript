# bootstrap-touchspin

> 标签: bootstrap, input, number, range, spinbutton, spinner

## 简介

A mobile and touch friendly input spinner component for Bootstrap 3, 4 & 5. jQuery plugin with IIFE/UMD builds for backward compatibility.
