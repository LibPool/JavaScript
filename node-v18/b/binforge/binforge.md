# binforge

> 标签: big-endian, binary, binary-reader, binary-writer, binforge, bitpacking, buffer, dataview, decoder, deserializer, encoder, endianness, little-endian, serialization, serializer, typescript, uint8array, varint

## 简介

A compact, dependency-free binary serializer for TypeScript, with variant lengths, string interning, bit packing, and explicit little- and big-endian primitives.
