# blockdex-mcp

> 标签: blockdex, components, mcp, modelcontextprotocol, react, registry, shadcn

## 简介

BlockDex MCP server from Compound Labs. Searches shadcn-compatible components, blocks and hooks across public registries, with their dependencies. No key and no signup.
