# bubble-io-dead-code-detector

> 标签: audit, bubble, bubble.io, cli, dead-code, dependency-graph, linter, no-code, technical-debt

## 简介

Dead code detector, dependency analyzer & health scorer for Bubble.io applications. Finds unused workflows, orphaned UI elements, unused database fields, inactive plugins, and more.
