# blotboard

> 标签: agent, blotboard, canvas, local-first, mcp, nextjs, react-flow, whiteboard

## 简介

Blotboard · 泼墨画板 —— 人与任何 agent 共用的本地优先画板（Next.js + React Flow），数据自管，任务可接 ACP agent 或任意 HTTP Runner。
