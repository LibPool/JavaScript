# babel-plugin-text-break-resolver

> 标签: adjustsFontSizeToFit, android, babel-plugin, jsx-transform, metro, numberOfLines, react-native, rn, text-break-resolver, text-break-strategy, text-clipping, text-cutoff, text-overflow, text-rendering, text-truncation, textBreakStrategy

## 简介

Babel plugin that automatically fixes Android text rendering issues in React Native. Injects textBreakStrategy="simple" into every <Text> component at build time — zero runtime cost. Optionally adds numberOfLines and adjustsFontSizeToFit via config — full
