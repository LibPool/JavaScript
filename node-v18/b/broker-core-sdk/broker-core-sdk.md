# broker-core-sdk

> 标签: JavaScript

## 简介

Đây là bộ công cụ lõi (Core SDK) chứa toàn bộ logic nghiệp vụ, thuật toán học tập, hằng số (constants) và các định nghĩa dữ liệu (types) dùng chung cho toàn bộ hệ thống Adaptive Learning. SDK này được thiết kế theo hướng **Functional Programming**, hỗ trợ
