# babel-plugin-drei

> 标签: JavaScript

## 简介

Transform `drei` named imports to default imports ```jsx import { Box, Sphere } from "drei" ``` into default imports: ```jsx import Box from "drei/lib/Box" import Sphere from "drei/lib/Sphere" ```
