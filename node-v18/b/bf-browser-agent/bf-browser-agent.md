# bf-browser-agent

> 标签: agent, automation, browser, playwright, reverse-tunnel, workflow

## 简介

Tarayıcı ajanı — kendi bilgisayarınızdaki Chrome'u uzak bir workflow sunucusuna outbound bağlar; otomasyonlar bu makinede, sizin ağınızda çalışır. Sunucu adresi, ajan kimliği ve anahtar komut satırından parametreyle verilir.
