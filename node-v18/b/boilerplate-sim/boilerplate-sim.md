# boilerplate-sim

> 标签: boilerplate, turing

## 简介

This is a reference simulator for a steam / air pressure based turing tarpit. The world is a 2d space deep underground. You can empty out space, which can be pressurized with pumps. Pressurized air pushes (or pulls) shuttles, which can be used as switches
