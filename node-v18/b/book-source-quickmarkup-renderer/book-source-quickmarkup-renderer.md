> 标签: book, language, lightweight, markup, quickmarkup, renderer, source, string-kit, terminal, terminal-kit

## 简介

QuickMarkup (Terminal Kit, String Kit) text renderer for the Book Source parser, a lightweight markup language, inspired by Markdown.
