# bandle

> 标签: bandle, bandlejs

## 简介

Bandle is my original 2D game engine written in AssemblyScript and TypeScript, designed to run in a web environment.   In the future, I plan to add a native backend for building standalone `.exe` applications, which will require a dedicated SDK.
