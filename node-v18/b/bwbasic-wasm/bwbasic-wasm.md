# bwbasic-wasm

> 标签: ansi-basic, basic, bwbasic, bywater-basic, emulator, interpreter, oregon-trail, retro, wasm, webassembly

## 简介

Run classic BASIC programs in Node.js and the browser, powered by a WebAssembly build of the Bywater BASIC interpreter.
