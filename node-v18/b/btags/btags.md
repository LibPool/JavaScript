# btags

> 标签: JavaScript

## 简介

**btags** is a ctags generator for JavaScript. In particular, it's made in order to support ES2015/ES2016 features and beyond, by using [babylon](https://www.npmjs.com/package/babylon), which is babel's AST tool.
