# browser-console-logger-mcp

> 标签: browser, cli, console, cursor, debugging, error-tracking, logs, mcp, npx, socket.io

## 简介

一个用于捕获和集中显示浏览器控制台日志的工具，可以帮助开发人员快速定位和排查浏览器中的错误信息
