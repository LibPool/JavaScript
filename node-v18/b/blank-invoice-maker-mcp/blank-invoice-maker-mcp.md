# blank-invoice-maker-mcp

> 标签: ai-tools, blank-invoice-maker, claude, invoice, invoice-generator, invoice-template, mcp, model-context-protocol, modelcontextprotocol

## 简介

MCP server for Blank Invoice Maker — create free, no-signup invoices from your AI assistant. Exposes list_templates and create_invoice tools that return a deep link opening blankinvoicemaker.com pre-filled.
