# bio-dark-theme

> 标签: Bio, Dark Theme, Oceanic, Solarized, Studio Bio, Theme

## 简介

A super-cool dark theme for VS Code by studio.bio inspired by Oceanic Next and Solarized Dark. Optimized for JavaScript (React), PHP, HTML, and Sass/SCSS.
