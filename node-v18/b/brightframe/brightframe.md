# brightframe

> 标签: a11y, accessibility, buttons, cards, component-library, css-modules, dark-mode, date-picker, design-system, design-tokens, form-validation, formik, forms, react, react-components, react-hook-form, storybook, theme, time-picker, typescript, ui-kit, ui-library

## 简介

React UI component kit with buttons, cards, tags, form controls, and date/time pickers — themeable via a light/dark/high-contrast design token system and a drop-in ThemeProvider.
