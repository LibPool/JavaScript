# b2.mpm

> 标签: cli, multi project manager, npmtool, utility

## 简介

A Node utility to help you manage multiple projects on the same codebase. This is particularly useful for projects where you need to compile the same codebase with different themes or configs, such as Ionic or web projects, and where that's not supported
