# bun-gpu

> 标签: bun, compute, d3d11, ffi, gpgpu, gpu, gpu.js, hlsl, shader, typescript, warp, win32, windows

## 简介

GPU compute and headless rendering for Bun on Windows — runtime-compiled HLSL on D3D11, any vendor, zero native dependencies.
