# binpatch

> 标签: binary, bsdiff, bspatch, delta, ghcr, oci, patch, self-update, trdiff10, update, zstd

## 简介

Reusable binary delta-update engine: apply TRDIFF10/bsdiff+zstd patch chains to a binary and discover chains from a pluggable source (OCI/GHCR or GitHub Releases). Pure Node, zero product coupling.
