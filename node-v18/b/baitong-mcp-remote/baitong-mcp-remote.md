# baitong-mcp-remote

> 标签: baitong, bridge, mcp, model-context-protocol, stdio, streamable-http, workbuddy

## 简介

百通 MCP Remote — stdio↔Streamable HTTP 桥接，让仅支持 stdio 的 MCP 客户端（如 WorkBuddy）接入百通远程 MCP 服务
