# base-cli-process

> 标签: api, app, application, base, base-plugin, baseplugin, building-blocks, cli, command-line, commands, create, framework, plugin, plugins, process, tool, toolkit, tools

## 简介

Normalizers for common argv commands handled by the base-cli plugin. Also pre-processes the given object with base-cli-schema before calling `.process()`
