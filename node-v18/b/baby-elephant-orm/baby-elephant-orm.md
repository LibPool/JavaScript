# baby-elephant-orm

> 标签: npgsql, orm, postgresql, sql

## 简介

baby-elephant-orm is a custom build object relationship management package for PostgreSQL, which improves code readability, and code re-usability. It is easy to use and can support multiple types of conditions and various joins.
