# blackwall-eliza-guardrail

> 标签: ai-agents, ai-safety, blackwall, eliza-plugin, elizaos, guardrails

## 简介

BLACK_WALL pre-action guardrail for ElizaOS agents. Wraps every action handler with a forecast() check so STOP-rated actions abort before they run; gateCall() adds per-call gating for multi-step handlers.
