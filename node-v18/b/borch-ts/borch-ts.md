# borch-ts

> 标签: autograd, browser, deep-learning, in-browser-ml, jupyterlite, onnx, pyodide, pytorch, tensor, webgpu, wgsl

## 简介

PyTorch's API in a browser tab: a WebGPU runtime held to real torch's values, error messages and printed form — tensors, autograd, nn, optim, ONNX export, no dependencies
