# bp-address-auto-complete-wrapper

> 标签: JavaScript

## 简介

bp-Address-Auto-Complete-Wrapper is the main wrapper directive, that displays the output from the core directive on every user input  (‘Please fill in a house number …’) Used combined with bp-address-auto-complete-core
