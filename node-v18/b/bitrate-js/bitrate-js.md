# bitrate-js

> 标签: abr, adaptive-bitrate, browser, chunking, client-side, cmaf, ffmpeg-alternative, fmp4, h264, hls, m3u8, m4s, mp4, remux, rust, segmenter, serverless, streaming, transcode, transcoder, video, video-streaming, video-upload, wasm, webassembly, webcodecs

## 简介

Client-side HLS / adaptive-bitrate video packager. Chunk, transcode and upload large videos entirely in the browser — Rust/WASM + WebCodecs, no server.
