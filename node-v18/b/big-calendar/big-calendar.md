# big-calendar

> 标签: big-calendar, calendar, calendar-component, calendar-view, date-picker, event-calendar, fork, react, react-calendar, scheduler, tailwind

## 简介

React + Tailwind implementation of Big Calendar. Fork extending the original with host-app control: control views, events, and behavior via props and API from your app.
