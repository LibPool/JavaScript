# badep

> 标签: JavaScript

## 简介

具体问题：有个数组，里面有 9 个元素，现在要从里面删除 3 个元素。 要求：被删除的元素，应是**均匀分布**在数组里。 比如，不能删除前 3 个元素，也不能删除最后 3 个；可以删除第 2、5、8 号元素。
