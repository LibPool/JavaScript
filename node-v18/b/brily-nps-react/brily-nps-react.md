# brily-nps-react

> 标签: brily, feedback, net-promoter-score, nps, react, survey

## 简介

React component + hook for the Brily NPS widget. Drop <BrilyNps surveyKey="sk_nps_..." /> into any tree and a floating feedback bubble appears.
