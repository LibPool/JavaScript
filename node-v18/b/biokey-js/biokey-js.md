# biokey-js

> 标签: biometric, fingerprint, identity, passkey, sdk, webauthn

## 简介

Browser SDK for the BioKey protocol. Drop-in WebAuthn fingerprint identity — wraps enrollment, authentication, key derivation, and optional server sync.
