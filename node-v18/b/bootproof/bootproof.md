# bootproof

> 标签: ai-agents, attestation, ci, claude-code, health-check, proof, provenance, receipt, runtime-verification, signed, supply-chain, verification

## 简介

The honest run button for repos. Boots unfamiliar code when it safely can, tells the truth when it cannot, and signs proof of what happened.
