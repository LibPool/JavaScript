# babel6-brunch

> 标签: 6to5, babel, brunch, brunch-compiler, brunch-plugin, es2015, es2016, es5, es6, js

## 简介

Brunch plugin to turn latest ECMAScript standard code into vanilla ES5 with no runtime required.
