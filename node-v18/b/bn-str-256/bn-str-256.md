# bn-str-256

> 标签: 256, 256-bit, 32-byte, big number, big numbers, binary, blockchain, buffer, decimal, decimals, decode, encode, ethereum, functional, hexadecimal, int256, octal, simple, uint256

## 简介

Simple, functional big number library for up to 256-bit (32-byte) numbers that outputs decimal strings, with hex, binary, octal, and Buffer decoding/encoding.
