> 标签: ads api, advertising, bing ads api, bing ads sdk, bingads, campaign management, marketing api, microsoft ads, microsoft ads api, microsoft advertising, oauth2, rest api, sdk

## 简介

A lightweight Node.js SDK for Microsoft Advertising (Bing Ads) REST APIs with OAuth2 authentication and Campaign Management v13 support.
