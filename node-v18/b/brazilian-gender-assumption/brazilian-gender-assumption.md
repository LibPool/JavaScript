# brazilian-gender-assumption

> 标签: brazil, brazilian, fuzzy, gender, gender-detection, gender-guess, genderize, name, names, nlp

## 简介

Infer gender (male/female) from Brazilian first names using a 103k+ name database, with optional fuzzy matching. Fast, isomorphic (Node + browser), zero runtime dependencies.
