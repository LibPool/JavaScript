# bm25s

> 标签: bm25, bm25s, bun, deno, document-retrieval, fast, full-text-search, information-retrieval, lexical-search, multi-runtime, nodejs, performant, ranking, search, sparse-retrieval, text-search, typescript, zero-dependencies

## 简介

Ultra-fast BM25 full-text search for JavaScript. Zero dependencies, multi-runtime (Node.js, Bun, Deno). Eager sparse scoring with CSC matrices.
