# boilerpipe

> 标签: JavaScript

## 简介

A node.js wrapper for Boilerpipe, an excellent Java library for boilerplate removal and fulltext extraction from HTML pages.

## 官网

- 源码仓库：https://github.com/xissy/node-boilerpipe.git
