# b017

> 标签: bitcoin, bolt, bsv, fungible, layer-1, nft, smart-contract, token

## 简介

b017 — BOLT layer-1 token templates + off-chain scanner (mint/transfer/split/merge/melt). Pre-compiled contract; no sx compiler required at runtime.
