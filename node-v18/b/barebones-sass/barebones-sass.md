# barebones-sass

> 标签: SASS, framework

## 简介

Barebones is a boilerplate to help you quickly build your own SASS framework. It is not a fully fledged front-end framework, and simply provides a set of commonly used tools: a customisable grid system, automatically generated helper classes, and a range
