# base32kit

> 标签: base32, base32hex, crockford, decode, encode, isomorphic, rfc4648, totp, typescript, uint8array, zero-dependency

## 简介

Tiny, isomorphic Base32 codec — RFC 4648, base32hex, and Crockford, between string and Uint8Array. Zero dependencies.
