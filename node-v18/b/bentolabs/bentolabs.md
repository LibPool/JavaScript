# bentolabs

> 标签: bentolabs, llm, observability, opentelemetry, otel, telemetry, tracing

## 简介

Official BentoLabs TypeScript SDK. Drop-in OpenTelemetry span processor that ships traces to the BentoLabs ingest API over OTLP/HTTP+JSON.
