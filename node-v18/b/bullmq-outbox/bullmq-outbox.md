# bullmq-outbox

> 标签: bullmq, bullmq-pro, fallback, job-queue, outbox, outbox-pattern, queue, redis, reliability

## 简介

Outbox fallback for BullMQ: when Redis is out of memory or unreachable, jobs land in a store you own instead of disappearing. Works with BullMQ v5, v6 and Pro.
