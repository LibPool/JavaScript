# bootstrap-cli-dev

> 标签: bootstrap, cli, developer-tools, project-generator, scaffolding, template

## 简介

Launcher for the Cli developer bootstrap platform — installs the real `bootstrap` binary (github.com/intruder0007/Cli) for your platform and runs it with full terminal passthrough.
