# bower-to-jspm

> 标签: bower, github, jspm, migration, npm

## 简介

Utility to help migrate from bower to jspm. Finds packages on npm and github and generates install command lines for you

- 官网：https://github.com/Munter/bower-to-jspm
- 源码仓库：git+https://github.com/Munter/bower-to-jspm.git
