# babel-plugin-console-awesome

> 标签: babel-plugin, console.log, javascript, node

## 简介

babel plugin that will add a message before to any console.log so console.log(n) -> console.log('awesome', n)

## 官网

- npm 页面：https://www.npmjs.com/package/babel-plugin-console-awesome
