# babel-preset-forge

> 标签: babel, babel-preset, browserslist, cjs, esm, library, monorepo, preset, react, react-native, typescript

## 简介

A curated Babel preset system. One preset per project shape — node/browser library, React library, React Native library, bundler-driven app — instead of a hand-rolled babel.config.js per repo.
