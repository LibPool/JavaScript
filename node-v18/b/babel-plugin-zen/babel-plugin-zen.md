# babel-plugin-zen

> 标签: JavaScript

## 简介

提升setTimeout魔法值为顶层标识符。 ## Usage 你需要安装babel的cli: ```sh npm install @babel/core @babel/cli --save-dev ``` 然后安装本插件: ```sh npm install babel-plugin-zen --save-dev ``` 在根目录新建文件并写入如下内容: ```javascript module.exports={     plugins:['zen'] } ``` 执行
