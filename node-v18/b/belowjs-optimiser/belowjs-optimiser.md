# belowjs-optimiser

> 标签: compression, draco, glb, gltf, ktx2, meta, optimization, photogrammetry, quest, vr, webxr

## 简介

Optimises photogrammetry GLB models for WebXR on Meta Quest headsets. Applies Draco mesh compression, KTX2 texture compression, and automatic polygon simplification.
