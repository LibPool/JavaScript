# bcfetch

> 标签: AMM, balanceOf, batch, blockchain, bsc, call, data-transformation, defi, ethereum, fetch, http, json-extraction, liquidity, lpPrice, math-operations, polygon, postprocess, smart-contract, uniswap

## 简介

A Node.js library to perform multiple fetch operations based on type, including HTTP requests, blockchain data fetching, smart contract calls, AMM LP token price calculations, and flexible data postprocessing.
