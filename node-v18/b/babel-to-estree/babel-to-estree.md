# babel-to-estree

> 标签: JavaScript

## 简介

Translate a Babel AST to an ESTree-compliant AST. A "fork" of babel-eslint/babylon-to-espree.

## 官网

- 官网：https://github.com/lightscript/babel-to-estree
- 源码仓库：git+https://github.com/babel/babel-eslint.git
- npm 页面：https://www.npmjs.com/package/babel-to-estree
