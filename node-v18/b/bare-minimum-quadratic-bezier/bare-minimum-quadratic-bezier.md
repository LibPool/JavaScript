# bare-minimum-quadratic-bezier

> 标签: bezier, quadratic-bezier, svg, visualisation

## 简介

A plugin for [bare-minimum-2d](https://www.npmjs.com/package/bare-minimum-2d) for plotting polygons as quadratic bezier curves.
