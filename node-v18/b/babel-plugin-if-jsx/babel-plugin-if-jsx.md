# babel-plugin-if-jsx

> 标签: JavaScript

## 简介

这是一个<code>babel</code>插件, 能够在jsx语法中支持<code>v-if</code>、<code>v-else-if</code>、<code>v-else</code>, 支持自定义前缀 <code>rc-if</code>、<code>xx-if</code>。支持react 和 vue
