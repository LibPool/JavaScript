# bsdd-mcp

> 标签: aec, bim, bsdd, buildingsmart, buildingsmart-data-dictionary, classification, ifc, mcp, model-context-protocol, openbim

## 简介

MCP server for bSDD (buildingSMART Data Dictionary): query classifications, properties and isRequired data by country. Part of the Flinker OpenBIM toolchain.
