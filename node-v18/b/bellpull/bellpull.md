# bellpull

> 标签: agent, ai-agent, child-process, cli, cross-spawn, exec, execa, extensible, json, npm-run-path, plugin, plugins, spawn, subprocess, which, zero-dependency

## 简介

The cord you pull to ring a bell in another room. Subprocesses with executable resolution and a structured result every caller can read — human, JSON envelope or agent event. Drop-in paths for execa, cross-spawn and which. Zero dependencies.
