# browserstyles

> 标签: css, mixins, scss, utility

## 简介

A lightweight SCSS library that provides standardized browser styles in both CSS classes and SCSS mixins. It allows easy application of default browser styles to elements using class names (e.g., .h1, .p, .button) or direct integration in SCSS with mixins
