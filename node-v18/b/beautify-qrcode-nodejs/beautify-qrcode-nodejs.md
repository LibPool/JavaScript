# beautify-qrcode-nodejs

> 标签: JavaScript

## 简介

此项目来源于 QRBTF 的创意在原来的项目做了一些封装,有效解决了我的项目问题 <br> 当用户用图片作为背景的时候用户的大图给服务器造成了比较大的压力全部使用客户端来生成减少了服务器压力
