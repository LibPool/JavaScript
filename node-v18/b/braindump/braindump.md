# braindump

> 标签: agent, ai, braindump, claude, cli, codex, context, copilot, cursor, droid, gemini, handoff, opencode, relay, session

## 简介

A CLI tool that captures your AI coding agent session and generates a portable resume prompt so you can seamlessly continue in a different agent.
