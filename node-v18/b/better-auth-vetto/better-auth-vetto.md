# better-auth-vetto

> 标签: better-auth, better-auth-plugin, disposable-email, free-trial-abuse, signup, spam, temporary-email

## 简介

Better Auth plugin: block disposable sign-up emails offline (CC0 list), let privacy relays through, optional dead-domain (MX) check, and a Gmail canonical-email helper.
