> 标签: ArrayBuffer, ArrayBuffer from file, Buffer from file, Nodejs buffer from file, TypedBuffer from file, mmap, mmap file, wTools, zero copy

## 简介

The module in JavaScript provides convenient means for using files as standard ArrayBuffer making mmap behind the scene.
