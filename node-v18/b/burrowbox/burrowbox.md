# burrowbox

> 标签: ai-agents, browser, burrowbox, computer-use, linux, mcp, sandbox

## 简介

TypeScript client for the Burrowbox API: persistent Linux computers for AI agents, with a desktop, a signed-in browser, a credential vault and an MCP endpoint per machine.
