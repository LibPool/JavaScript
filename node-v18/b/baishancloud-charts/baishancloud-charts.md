# baishancloud-charts

> 标签: JavaScript

## 简介

因为echarts复杂的配置和繁多的api，出于简化和组件化原因，用react再做了一层封装，只对外部提供简单的配置接口。主要思想在于用最简单的配置完成所需要的图表，减少使用者了解echarts各个配置项的成本，替使用者做出最好的决定。 ## 目前支持的图表类型  1. 柱状图  2. 线图  3. 饼图/环图  4. 点图 ## 安装 ```  npm install echarts-react -save ```
