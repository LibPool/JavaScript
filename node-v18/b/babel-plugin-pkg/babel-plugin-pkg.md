# babel-plugin-pkg

> 标签: babel, babel-plugin, convert, name, package, package-json, pkg, resolve, resolver, transform, transformation, transpile, transpiler, version

## 简介

Resolves _PKG_VERSION to version from package.json - also works with any other field!
