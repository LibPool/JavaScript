# bw-pro-table

> 标签: ant-design-vue, component, crud, editable-table, excel, pro-table, table, vue3

## 简介

基于 ant-design-vue 的高级业务表格组件（ProTable），支持请求/数据源双模式、行内编辑、搜索筛选、列拖拽排序、导出导入、跨页多选、持久化等
