# buddys-simple-timer

> 标签: Dynamic delay node, Event scheduling Node-RED, Node-RED, Node-RED countdown timer, Node-RED flow timing management, Node-RED payload scheduling, Node-RED timer node, Node-RED timing status indicator, Payload delay function, Payload delay with reset, Real-time timer control Node-RED, Resettable timer, Scheduled trigger Node-RED, Timer status feedback, node-red-contrib

## 简介

A Node-RED timing node designed to forward the payload after a specified delay in seconds. The timer resets upon receiving a new payload. Includes status indication for the scheduled trigger time.
