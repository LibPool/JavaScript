# bun-nthread

> 标签: context-redirection, exoproc, memset, msvcrt, native, rop-stub, thread-redirection, windows, x64

## 简介

Non-invasive x64 Windows thread redirection library for Bun — delegate execution to existing threads without machineCode, remote allocation, or CreateRemoteThread.
