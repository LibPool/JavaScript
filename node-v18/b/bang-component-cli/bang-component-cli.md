# bang-component-cli

> 标签: JavaScript

## 简介

> 配置package.json中的bin字端 ### 2. 设置脚本的运行环境 > 在脚本中设置 #! /usr/bin/env node  以node环境运行脚本 ### 3. 使用commander处理用户命令行 ### 4. 使用inquirer和用户交互（选择、确认、输入） ### 5. 使用github api获取模版仓库和tag ### 6、使用download-git-repo 将git代码拉到本地
