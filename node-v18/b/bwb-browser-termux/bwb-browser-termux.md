# bwb-browser-termux

> 标签: android, automation, browser, browser-without-bloat, bwb, cdp, chrome-devtools-protocol, headless, mcp, model-context-protocol, termux

## 简介

Browser Without Bloat — a lightweight browser automation MCP server using raw Chrome DevTools Protocol. No Playwright. No Puppeteer. Just CDP. Works on Termux/Android.
