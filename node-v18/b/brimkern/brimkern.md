# brimkern

> 标签: chat-widget, gguf, in-browser, llm, local-ai, on-device, privacy, webgpu, wgsl

## 简介

On-device AI for your site: one script tag runs a real language model on your visitor's GPU (WebGPU). No server, no API key, no per-token cost, nothing leaves the browser.
