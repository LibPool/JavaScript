# bullmq-autoqueue

> 标签: autoload, background-jobs, bull, bull-board, bullmq, convention, dashboard, jobs, loader, queue, redis, worker

## 简介

Convention-based BullMQ queue loader with an automatic Bull Board dashboard. Drop a folder with a processor, get a fully wired queue + worker + dashboard — no central registry to edit.
