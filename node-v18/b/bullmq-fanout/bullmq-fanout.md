# bullmq-fanout

> 标签: bullmq, bullmq-pro, domain-events, event-driven, fan-out, fanout, message-bus, pubsub, queue

## 简介

Turn BullMQ into a message bus: publish one domain event to many queues, each with its own worker, retries and failure domain. Works with BullMQ v5, v6 and Pro.
