# branch-localhost

> 标签: branch, cli, dev, devserver, git, localhost, monorepo, next.js, port, subdomain, worktree

## 简介

Per-branch <branch>.localhost:<port> for local dev — deterministic port per git branch, free-port probing, env injection.
