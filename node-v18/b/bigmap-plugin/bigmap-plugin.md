# bigmap-plugin

> 标签: bigmap, bmgl, cesium, gis, map, map-plugin, vue, vue3

## 简介

基于 BigMap/Cesium (bmgl) 的工程化地图插件。独立 NPM 包，内置全部外部 JS 库、样式与资源，安装即用，支持 2D/3D 地图、点位管理、图形绘制、图层与弹窗管理。
