# pagedjs-cli

> 标签: JavaScript

## 简介

Render Html to PDFs using [Pagedjs](https://gitlab.pagedmedia.org/polyfills/pagedjs) and [Puppeteer](https://github.com/GoogleChrome/puppeteer).

## 官网

- 官网：https://pagedjs.org
- 源码仓库：https://gitlab.coko.foundation/pagedjs/pagedjs.git
- npm 页面：https://www.npmjs.com/package/pagedjs-cli
