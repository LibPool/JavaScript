# @jiuling/dsh-mobile-remote

> 标签: dsh, dsh-bundle, dsh-plugin, frp, mobile, remote, responsive, tunnel

## 简介

手机远程访问 DSH 的一站式插件：移动端 UI 适配 + 公网零配置访问。安装后无论用 frp / ngrok / Cloudflare Tunnel / 路由器端口转发，只要把本地端口映射到公网即可直接用，无需任何额外配置；自带 HTTP Basic Auth 门卫保护公网入口。
