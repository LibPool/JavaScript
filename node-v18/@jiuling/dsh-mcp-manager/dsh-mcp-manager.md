# @jiuling/dsh-mcp-manager

> 标签: deepseek-harness, dsh, dsh-bundle, dsh-plugin, dshapp-plugin, dshapp-plugin-featured, mcp, model-context-protocol, server-manager

## 简介

MCP 服务器管理器：在 DSH Web GUI 的设置界面中可视化新增 / 编辑 / 删除 / 启停 @deepseek-ai/dsh-mcp-client 配置行，直接读写当前 profile 的 cordis.patch.yml。1.0.3 起适配 DSH 0.2.1（官方删除 webRuntime 服务，信任校验改用 connection.requestRejection）。
