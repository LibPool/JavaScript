# @autonoma-ai/planner

> 标签: ai-agent, autonoma, e2e, end-to-end-testing, preview-environments, test-data, test-generation

## 简介

One command to set up Autonoma: a preview environment, an end-to-end test suite generated from your codebase, the SDK integration, and a dry run proving it works.
