# @runroom/payload-plugin-translator

> 标签: i18n, localization, openai, payload, payload-plugin, payloadcms, translation

## 简介

Payload CMS plugin that translates localized fields of collections and globals with AI, as drafts when the entity has them, without overwriting hand-edited text.
