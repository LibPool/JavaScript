# @useboardwalk/sdk

> 标签: agent, base, boardwalk, defi, erc-8021, non-custodial, token-launch, viem

## 简介

Framework-agnostic SDK + CLI for building unsigned Boardwalk transactions (launch, contribute, claim, refund, presale seed, BMX stake/unstake, fee/vesting/participation claims, LP, swap, visibility, vote).
