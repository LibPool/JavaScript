# @bosdev/zaps

> 标签: cli, dev-environment, developer-tools, ink, process-manager, react, service-orchestrator, tmux, tui

## 简介

Zero Ass Pain Setup — a tmux-based dev environment orchestrator: define services, dependencies, tasks, and layout in one config file, with ready detection, crash recovery, and a keyboard-driven TUI.
