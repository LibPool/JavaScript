# @defensestation/y-comments-blocknote

> 标签: blocknote, comments, comments-plugin, decorations, editor, yjs

## 简介

Comments for the BlockNote editor that never write to the document: Yjs relative-position anchors in an external store, rendered as ProseMirror decorations.
