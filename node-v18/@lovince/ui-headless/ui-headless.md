# @lovince/ui-headless

> 标签: accessibility, design-system, headless, headless-ui, state-machine, wai-aria

## 简介

Framework-independent headless behavior for Lovince UI — state transitions, keyboard policies and accessibility contracts. No framework, no DOM.
