# create-hamolus

> 标签: cloudflare-workers, cms, create-hamolus, generator, hamolus, init, scaffold, starter, template

## 简介

The `npm create hamolus@latest` initializer: asks twelve questions, then creates a Hamolus project with a core, and a console, MCP server, site or seed if you want one.
