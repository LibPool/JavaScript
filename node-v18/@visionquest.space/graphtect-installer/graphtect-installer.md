# @visionquest.space/graphtect-installer

> 标签: JavaScript

## 简介

The `graphtect` command: run it in any folder to sign in to Graphtect from your terminal, bind the folder to one of your Apps (or a new one), pick the tools (Claude Code, Codex, Antigravity) and install the BSANE skills, commands and graph tools there. On
