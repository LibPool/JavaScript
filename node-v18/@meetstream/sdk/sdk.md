# @meetstream/sdk

> 标签: ai-notetaker, google-meet, live-transcription, meeting-bot, meeting-bot-api, meeting-recording, meetstream, mia, microsoft-teams, sdk, speaker-diarization, transcription, typescript, voice-agent, webhooks, zoom

## 简介

Official MeetStream SDK for TypeScript and JavaScript — send AI meeting bots into Zoom, Google Meet and Microsoft Teams. Record, transcribe, summarize and stream meetings, and run MIA voice agents.
