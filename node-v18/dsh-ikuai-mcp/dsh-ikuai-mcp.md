# dsh-ikuai-mcp

> 标签: deepseek-harness, dsh, dsh-plugin, ikuai, lan, mcp, router, soft-router, 爱快

## 简介

DSH plugin: control iKuai (爱快) soft routers over their JSON API. Zero-dependency Node MCP stdio server exposing 11 read tools plus a write-gated generic API call; iKuai credentials live in the DSH credential store (mcp__ikuai__*).
