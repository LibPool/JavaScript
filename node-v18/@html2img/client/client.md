# @html2img/client

> 标签: api-client, html-to-image, html-to-pdf, html-to-png, html2img, image-generation, og-image, open-graph, pdf, screenshot, screenshot-api, typescript, url-to-image

## 简介

Official JavaScript and TypeScript SDK for the html2img HTML-to-image API: render HTML or CSS to PNG, screenshot live URLs, generate images from templates, and export PDFs.
