# @web-alchemy/eleventy-plugin-html-transform

> 标签: eleventy, eleventy-plugin, html, html-transform

## 简介

This plugin provides custom html post processing with DOM API via [LinkeDOM](https://github.com/WebReflection/linkedom). For example, you can add ids to headings, change url of images, etc.
