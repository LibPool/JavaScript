# @thmxsweb/jj-sdk

> 标签: api-client, freelance, join-jump, jump, portage, portage-salarial, sdk, typescript

## 简介

Type-safe, zero-dependency SDK for the Join-Jump (join-jump.com) API, with automatic token refresh, retries, and a full error hierarchy.
