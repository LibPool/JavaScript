# @midway3-components/cli

> 标签: JavaScript

## 简介

在 CLI 场景下运行 Midway 框架。 Web 是 [`Midway`](https://github.com/midwayjs/midway) 框架的主要目标场景，官方似乎并没有为命令行环境提供相应的组件（Framework）。 一个趁手的命令行工具无论对于调试还是后台管理都是非常必要的，所以就有了这个组件。 命令解析工作由 [`yargs`](https://github.com/yargs/yargs) 完成。
