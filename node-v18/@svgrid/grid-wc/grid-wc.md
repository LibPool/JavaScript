# @svgrid/grid-wc

> 标签: angular, angular data grid, angular-data-grid, custom element, custom-elements, data grid, data-grid, data-table, datagrid, datatable, framework-agnostic, grid, react, react data grid, react-data-grid, sv-grid, svelte, svelte5, svgrid, table, vanilla-js, virtual-scroll, vue, vue data grid, vue-data-grid, web component, web-components

## 简介

SvGrid as a framework-agnostic web component (<sv-grid> custom element, plus <sv-grid-shadow> for an open shadow root and <sv-chart> for the standalone chart). Drop into React, Vue, Angular, or plain HTML - no build step required.
