# @khalidsaidi/relayorb

> 标签: ai-agents, claude-code, cli, codex, cursor, debugging, developer-tools, json-rpc, llm, mcp, mcp-server, model-context-protocol, record-replay, regression-testing, testing

## 简介

Turn real AI agent sessions into tests for MCP servers: record what Claude Code, Cursor, or Codex sends to an MCP server, then check new builds against it or replay it offline.
