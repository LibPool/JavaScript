# @hecto/form

> 标签: JavaScript

## 简介

`@hecto/form/view` is an optional adapter. `useForm(options)` creates an owned service; `useFormService(service)` borrows one and releases only its field subscriptions and registrations. Call both inside a View owner. A borrowed idle service is activated
