# @open-rgs/core

> 标签: bun, gambling, lua, open-rgs, remote-game-server, rgs, slot, wasm

## 简介

Open-RGS core: orchestrator, session, promo free-rounds, Lua/WASM math loader, binary-msgpack transport, admin endpoints. Bun-native.
