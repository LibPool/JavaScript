# @mlightcad/cad-diff-viewer

> 标签: autocad, cad, cad-viewer, diff, dwg, dxf, mlightcad

## 简介

Reusable side-by-side / overlay CAD comparison widget. It depends on [`@mlightcad/cad-simple-viewer`](../cad-simple-viewer) and creates both WebGL canvases internally — the host only supplies a parent container.
