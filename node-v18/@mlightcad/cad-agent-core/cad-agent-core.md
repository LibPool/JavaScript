# @mlightcad/cad-agent-core

> 标签: JavaScript

## 简介

Transport-neutral CAD runtime for agents. It exposes a drawing-tool catalog and a checked JavaScript host on top of `@mlightcad/data-model` and `@mlightcad/cad-simple-viewer`.
