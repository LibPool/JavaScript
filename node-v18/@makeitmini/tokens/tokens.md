# @makeitmini/tokens

> 标签: baseline-grid, css-custom-properties, dark-mode, design-system, design-tokens, typography, vertical-rhythm

## 简介

A baseline-grid design token layer: two CSS custom properties derive every spacing step, type step, and baseline in the system, re-tunable at runtime with no build step.
