# @hype-stack/cli

> 标签: boilerplate, browser-extension, cli, expo, full-stack, fullstack, hono, kysely, mcp, monorepo, postgres, prisma, react, react-native, saas, saas-starter, scaffold, starter, tailwindcss, tanstack-router, template, typescript

## 简介

Scaffold a full-stack TypeScript app (React 19, Hono, Prisma, Kysely, Postgres) and compose features like auth, billing, and notifications into code you own. Deploys to Railway or Fly.io.
