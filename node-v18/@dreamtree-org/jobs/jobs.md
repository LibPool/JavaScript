# @dreamtree-org/jobs

> 标签: bullmq, cron, dreamtree, jobs, queue, scheduler, worker

## 简介

The shared BullMQ background-jobs layer for every Dreamtree product — define handlers, enqueue, run a worker; runs recorded in your database.
