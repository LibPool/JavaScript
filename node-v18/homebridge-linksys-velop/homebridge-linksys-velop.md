# homebridge-linksys-velop

> 标签: homebridge, homebridge-plugin, homekit, linksys, mesh, mx4200, parental control, parental-controls, presence, router, velop

## 简介

Linksys Velop parental controls in Apple Home: pause a device's internet, run one or more schedules, see whether it is connected, restart the router. Pick devices from a list of what is on your network. Tested on the Linksys Velop MX4200 only.
