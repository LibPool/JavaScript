# @ngx-misc/dropzone-overlay

> 标签: JavaScript

## 简介

Directive that will listen for drag & drop events on [`Window`](https://developer.mozilla.org/en-US/docs/Web/API/Window) object, render custom overlay and provide and set associated [`FormControl`](https://angular.io/api/forms/FormControl) instance value
