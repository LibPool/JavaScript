# @bizongo/go-bits

> 标签: boilerplate, components, react, shared

## 简介

React-bits is a library of React components which will be used across all Bizongo frontend projects. Live demo of components can be found at [https://Bizongo.github.io/react-bits](https://Bizongo.github.io/react-bits)
