# @machize/webhooks-sqlite

> 标签: machize, sqlite, store, typescript, webhooks

## 简介

Durable, SQLite-backed implementation of the @machize/webhooks WebhookStore (endpoint subscriptions), on Node's built-in node:sqlite. Zero external dependencies.
