# @candlelight-ds/tokens

> 标签: candlelight, css, design-system, design-tokens, tailwind

## 简介

The Candlelight token sheet — stage/ink ladders, voice colors, the fill ramp, structure, motion, physicality — as plain CSS custom properties, with an optional Tailwind v4 theme layer.
