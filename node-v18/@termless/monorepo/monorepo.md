# @termless/monorepo

> 标签: ansi, cross-terminal, ghostty, headless, terminal, terminal-emulator, terminal-testing, testing, tui, tui-testing, vitest, xterm

## 简介

Headless terminal testing library — like Playwright, but for terminal apps. Cross-terminal conformance, composable selectors, 21+ Vitest matchers.
