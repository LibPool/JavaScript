# @tuvren/kernel-grpc-client

> 标签: JavaScript

## 简介

Tuvren kernel-transport leaf: createGrpcRuntimeKernel and the generated gRPC client bindings for hosts that talk to a remote Tuvren kernel service, passed into createTuvren's kernel option.
