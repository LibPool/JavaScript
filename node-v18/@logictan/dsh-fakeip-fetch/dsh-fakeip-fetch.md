# @logictan/dsh-fakeip-fetch

> 标签: clash, deepseek-harness, dsh, fake-ip, plugin, sing-box, web-fetch

## 简介

DSH web_fetch provider that works behind a fake-ip DNS proxy (Clash / sing-box). Narrows the upstream non-public-address guard to the configured reserved range instead of removing it.
