# @logictan/dsh-lan-access

> 标签: authentication, deepseek-harness, dsh, dsh-plugin, lan, proxy

## 简介

DSH LAN access: serve the Web UI on one configurable port reachable from the LAN and from 127.0.0.1, with either the plugin's own password or no authentication at all, and no profile patch edits. DSH 局域网访问子插件。
