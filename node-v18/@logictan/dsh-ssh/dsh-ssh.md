# @logictan/dsh-ssh

> 标签: deepseek-harness, dsh, dsh-plugin, remote, sftp, ssh

## 简介

DSH SSH: run commands and move files on configured SSH hosts from the agent, addressing hosts by alias, with passwords kept in the credential store. DSH SSH 子插件。
