# @zentao-hub/sdk

> 标签: api-client, sdk, zentao, 禅道

## 简介

TypeScript SDK for ZenTao 20.x — HTTP client with token auto-refresh, plus credentials/keychain helpers shared by @zentao-hub/mcp and @zentao-hub/cli.
