# @tomsmart-ai/mapper-mcp

> 标签: agent-economy, ai-agents, base-mainnet, discovery, mcp, modelcontextprotocol, smartflow, x402

## 简介

MCP server for the SmartFlow x402 endpoint catalogue. 58,800+ catalogued endpoints (11,500+ strict-v2-valid as of May 2026), queryable by URL, registry source, chain, status, spec-validity, and actual on-chain facilitator address (v0.5.0+).
