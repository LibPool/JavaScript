# @hypit/narrative-speech-alignment

> 标签: JavaScript

## 简介

Provider-neutral deterministic timing locator for one authored Segment on a normalized local temporal domain. The package does not invoke Python, read audio, call a speech provider, use an LLM, infer speakers or retain multiple candidate paths. A runtime
