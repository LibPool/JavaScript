# @matdata/schema-explorer

> 标签: json-schema, schema, uml, web-component, xml-schema, xsd

## 简介

Visual explorer for XML Schema (XSD) and JSON Schema (also OpenAPI and AsyncAPI): UML-like diagrams, content-model trees and readable pages. Web app and <schema-explorer> web component.
