# @npmsolsentry/sdk

> 标签: ai-agents, defi-risk, mcp, solana, transaction-simulation, wallet-drainer

## 简介

TypeScript SDK for SolSentry: guard a Solana transaction before signing, detect wallet drainers, and score protocol risk from live sources.
