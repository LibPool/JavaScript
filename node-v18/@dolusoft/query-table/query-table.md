# @dolusoft/query-table

> 标签: datatable, filter, pagination, server-side, sorting, table, tanstack, vue, vue3

## 简介

A thin Vue 3 table for server-side data: it renders rows and emits sort, filter, search and paging changes. Built on TanStack Table.
