# @shamisoul/pi-cognee

> 标签: agent-memory, cognee, graphrag, knowledge-graph, memory, persistent-memory, pi, pi-extension, pi-package, rag

## 简介

Cognee persistent memory for the pi coding agent — native extension with auto-capture, auto-recall, and knowledge-graph tools. Fail-soft by design: pi keeps working when the cognee server is down.
