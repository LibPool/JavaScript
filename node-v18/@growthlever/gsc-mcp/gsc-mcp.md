# @growthlever/gsc-mcp

> 标签: claude, google-search-console, growthlever, mcp, model-context-protocol, seo

## 简介

Free, open-source Model Context Protocol (MCP) server that connects Claude to Google Search Console. Bring-your-own Google OAuth credentials -- runs entirely on your machine, no data ever touches GrowthLever's servers.
