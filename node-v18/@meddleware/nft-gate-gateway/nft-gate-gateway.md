# @meddleware/nft-gate-gateway

> 标签: JavaScript

## 简介

Cloudflare Workers implementation of the nft-gate gateway: a wire-identical, drop-in sibling of the Rust gateway that gates any HTTP upstream behind an access_gate NFT.
