# @envilder/sdk

> 标签: aws, aws-ssm, azure, azure-key-vault, configuration, envilder, environment, keyvault, nodejs, secret-management, secrets, ssm

## 简介

Load secrets from AWS SSM Parameter Store or Azure Key Vault directly into your Node.js process — no .env files needed.
