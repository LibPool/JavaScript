# crassus

> 标签: cascade, css, dead-css, regression-testing, specificity, visual-regression, zero-dependency

## 简介

Zero-dependency CSS cascade regression testing: provably dead declarations, cascade-flip diffs between builds, and real-browser usage and computed-style checks.
