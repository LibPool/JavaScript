# @cboxdk/id-react

> 标签: authentication, cbox-id, nextjs, oidc, react, user-button, widgets

## 简介

Embeddable React components for Cbox ID — a drop-in <SignIn/> form that draws itself in the customer's own colours, plus a user button, profile card, organization switcher and sign-in / sign-out buttons wired to your Cbox ID flows. Themeable, accessible,
