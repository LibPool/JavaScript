# @openagt/skill-suggest-tickets-to-work-on

> 标签: JavaScript

## 简介

The suggest-tickets-to-work-on command for coding agents: pick and rank the tickets worth working on next, each with the priority it should get on the agent queue. Changes nothing. A skill file only, no code.
