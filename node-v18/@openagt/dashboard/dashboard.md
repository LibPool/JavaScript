# @openagt/dashboard

> 标签: agent, ai, claude-code, cli, codegen, openagent, orchestration, turnkey

## 简介

OpenAgent: a local dashboard and daemon for coding agents. It starts an agent through the project's own start hook and shows every agent from the files it keeps; it runs no coding agent itself.
