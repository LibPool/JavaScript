# @openagt/agent-scheduler

> 标签: JavaScript

## 简介

Start coding agents on a schedule: a project's skills say which commands can run on a schedule, each with its check, its pace and how many at once, and each person switches them on for their own machine; the scheduler pulls the project's agent-data branch
