# @yumyum-player/core

> 标签: browser-player, cctv, h264, h265, hevc, hls, live-streaming, low-latency, mjpeg, mpeg-ts, rtsp, ultra-low-latency, video-decoder, video-player, video-surveillance, video-wall, vms, webcodecs, webgl, webgl2, yumyum

## 简介

Yum-yum Player — low-latency multi-codec browser video player engine for streaming, CCTV/VMS and video walls. H.264, HEVC/H.265, MJPEG via WebCodecs + WebGL2, HLS & MPEG-TS.
