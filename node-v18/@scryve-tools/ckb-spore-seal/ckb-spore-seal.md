# @scryve-tools/ckb-spore-seal

> 标签: authorship, ckb, dna, dob, nervos, nft, seal, spore

## 简介

Spore NFT minting utilities for CKB — encode/decode 16-byte DNA structures, define DOB/0 display patterns, generate cluster metadata, and estimate seal capacity.
