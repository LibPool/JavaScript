# @idhub/identity-provider-launchdarkly

> 标签: JavaScript

## 简介

identity-core IdentityProvider implementation for LaunchDarkly. Builds multi-kind contexts (user + device) on identify(); alias() is deprecated/removed on the Contexts model and is never called.
