# react-native-toast-message-library

> 标签: android, ios, notification, react-native, snackbar, toast, toast-notification

## 简介

Lightweight, customizable toast notifications for React Native: queue, themes, animations, actions, swipe-to-dismiss and accessibility. Pure JavaScript, no native modules.
