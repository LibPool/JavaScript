# @gkodama/mongoose-in-memory-autocomplete

> 标签: JavaScript

## 简介

This module will: * Fetch from mongodb the data you wish to autocomplete and insert this data in a prefix tree in memory. * Return all words starting with the requested string (autocomplete) * You can also bind data to a word inserted in the datastructure
