# @michaeljfalk/liveselect

> 标签: autocomplete, blaze, combobox, dropdown, ejs, express, mongodb, searchable, select, vanilla-js

## 简介

Framework-agnostic, dependency-free searchable dropdown / combobox with array or MongoDB sources, a [+ Add new] create flow, and a drop-in <select> replacement.
