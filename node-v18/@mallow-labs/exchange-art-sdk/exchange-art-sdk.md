# @mallow-labs/exchange-art-sdk

> 标签: JavaScript

## 简介

Unofficial, community-maintained TypeScript client SDK for the Exchange Art Solana programs (Market, Offers, AuctionV2). Not affiliated with or endorsed by Exchange Art.
