# @theme-ui/preset-polaris

> 标签: JavaScript

## 简介

Theme UI includes `@theme-ui/preset-polaris` which can be used as an example or starting point for extending your own themes. `@theme-ui/preset-polaris` is based on the Shopify design system, [Polaris](https://polaris.shopify.com/design/colors).
