# @q-agent/playwright-base

> 标签: playwright, q-agent, test-automation

## 简介

Q-Agent Playwright base framework — generic automation infrastructure (fixtures, evidence capture, auth state, API helpers, logging, assertions) shared by every generated automation project, so Q-Agent never regenerates it per feature.
