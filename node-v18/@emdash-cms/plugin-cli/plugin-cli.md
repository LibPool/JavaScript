# @emdash-cms/plugin-cli

> 标签: atproto, cli, cms, emdash, fair, plugin, plugin-cli, plugin-registry

## 简介

CLI for authoring, building, and publishing EmDash plugins. Covers init / build / dev / bundle / publish plus registry search and identity. Atproto OAuth, FAIR-shaped records, sandboxed-plugin-only.
