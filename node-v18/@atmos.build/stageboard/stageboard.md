# @atmos.build/stageboard

> 标签: agents, claude-code, codex, design, flows, mcp, nextjs, react, storybook, variants, vite

## 简介

Every screen, flow and component of your React app on one board. Point at what's wrong; your agent changes the real code, optionally as live variants.
