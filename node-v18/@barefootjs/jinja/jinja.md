# @barefootjs/jinja

> 标签: barefoot, flask, jinja, jinja2, python, ssr

## 简介

Jinja2 adapter for BarefootJS — compiles IR to .jinja templates and ships the Python BarefootJS rendering runtime; runs under any Python web framework (Flask, etc.)
