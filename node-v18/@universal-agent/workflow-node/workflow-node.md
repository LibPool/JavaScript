# @universal-agent/workflow-node

> 标签: acp, ai-agents, git-worktree, orchestration, sqlite, workflow

## 简介

Node.js host for the Universal Agent Workflow Kit: SQLite (node:sqlite + Drizzle) stores, UniversalAgentExecutor and ScriptExecutor, and WorkflowHost (workflow library, workspaces with per-run git worktrees, background run service)
