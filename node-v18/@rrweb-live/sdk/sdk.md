# @rrweb-live/sdk

> 标签: co-browsing, live, observability, recording, rrweb, session-mirroring, session-replay, socket.io

## 简介

Framework-agnostic browser SDK for live rrweb session mirroring over socket.io (record -> relay -> replay).
