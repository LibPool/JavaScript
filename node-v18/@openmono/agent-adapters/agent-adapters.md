# @openmono/agent-adapters

> 标签: adapter, agent, claude-code, codex, dedup, feno, openmono, tool-call, transcript

## 简介

Pure agent translators for coding-agent sessions — transcript bytes / SDK pump messages in, session events out. Covers Claude Code and Codex CLI transcript expansion with live/re-read dedup-key parity, cross-agent tool-call normalization, shell-command hu
