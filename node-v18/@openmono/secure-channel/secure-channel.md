# @openmono/secure-channel

> 标签: e2ee, feno, noise, openmono, secure-channel

## 简介

End-to-end encrypted channel between Feno clients (browser, mobile WebView) and the daemon: a Noise_IK_25519_AESGCM_SHA256 handshake and its transport ciphers, in pure JS so the daemon and every client run the same code.
