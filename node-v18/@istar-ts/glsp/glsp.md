# @istar-ts/glsp

> 标签: glsp, goal-model, istar, istar2, pistar

## 简介

A GLSP server for istar-ts models, on @eclipse-glsp/server: GModel, diagram configuration, dialect contributions, and Web Worker, in-page (MCP) and Node (WebSocket, MCP) launchers. Never depends on React.
