# @soluzioni-futura/openapi2ts

> 标签: JavaScript

## 简介

openapi2ts is a Node.js module that generates TypeScript interfaces from an OpenAPIv3 schema. It exports a `parse` function that takes an `Options` object as input and generates a `.ts` file containing TypeScript interfaces. The module also includes a CLI
