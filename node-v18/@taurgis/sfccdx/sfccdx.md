# @taurgis/sfccdx

> 标签: CLI, Cloud, Commerce, SFCC, Salesforce

## 简介

SFCCDX is a command line interface (CLI) for Salesforce Commerce Cloud. It can be used to easily manage (meta)data (import/export) in relation to your project.
