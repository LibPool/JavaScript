# @cda/archi-semantic-core

> 标签: archi, archimate, enterprise-architecture, parser, typescript, xml

## 简介

The foundational semantic core of the Continuous-Driven Architecture (CDA) ecosystem. Translates native Archi files into a faithful, typed semantic representation ready for automated governance and GitOps pipelines.
