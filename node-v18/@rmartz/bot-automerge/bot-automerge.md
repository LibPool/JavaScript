# @rmartz/bot-automerge

> 标签: auto-merge, bot-automerge, ci, dependabot, github-actions

## 简介

Enables GitHub-native auto-merge for trustworthy bot pull requests (Dependabot patch/minor bumps and release-please release PRs), distributed via rmartz/bot-automerge-action.
