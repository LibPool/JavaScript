# @rmartz/pr-policy

> 标签: check-run, conventional-commits, github-actions, merge-gate, pr-policy, pull-request

## 简介

Read-only PR content classifiers — CI-change classification, title-type rules, and more — reported as one blocking pr-policy check-run. Distributed as a pinned Action kept current by Dependabot.
