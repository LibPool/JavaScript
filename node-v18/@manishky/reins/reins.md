# @manishky/reins

> 标签: agent, claude, claude-code, guardrails, hooks, local-first, observability, sqlite, steering

## 简介

A local-first kit of Claude Code hooks: steer a running agent mid-flight, hard-block forbidden actions, get warned when it loops, and capture every run's trajectory to a queryable SQLite file. No daemon, no backend, no account.
