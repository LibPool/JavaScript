# @gby/event-bus

> 标签: EventTarget, event, event bus, 事件总线, 无依赖(零依赖)

## 简介

event-bus 是基于原生 EventTarget 类来开发的事件总线，无依赖（零依赖），充分复用原生的能力增加了易用性。拥有极少的代码就实现了 EventBus 的核心功能，而且还具备精确且完善的 TypeScript 类型系统
