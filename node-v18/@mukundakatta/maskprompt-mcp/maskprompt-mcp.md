# @mukundakatta/maskprompt-mcp

> 标签: claude, cline, compliance, cursor, mcp, model-context-protocol, pii, privacy, redaction, windsurf, zed

## 简介

MCP server: redact PII (emails, phones, credit cards, SSNs, IPs, AWS keys, GitHub tokens, JWTs) from text before it leaves your control. Built for Claude Desktop, Cursor, Cline, Windsurf, and Zed.
