# @strada.sh/otlp-json

> 标签: JavaScript

## 简介

Minimal JSON-only OTLP/HTTP exporters for traces and logs. Vendored from @opentelemetry/otlp-transformer (JSON path only) plus a tiny fetch-based exporter. No protobuf, no metrics — safe for Cloudflare Workers / workerd.
