# @mrscraper/sdk

> 标签: api-client, mrscraper, scraper, scraping, sdk, web-scraping

## 简介

Official Node.js SDK for the MrScraper API – fetch pages, Google SERP, run AI scrapers, rerun manual scrapers, and retrieve results.
