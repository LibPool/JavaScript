# @mrscraper/ai-sdk

> 标签: ai, ai-sdk, google-search, mrscraper, tools, vercel, web-scraping

## 简介

MrScraper tools for the Vercel AI SDK: retrieve public web pages as Markdown, HTML, or screenshots, search Google, and check account usage.
