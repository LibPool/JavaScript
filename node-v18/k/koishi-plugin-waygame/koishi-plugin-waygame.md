# koishi-plugin-waygame

> 标签: chatbot, koishi, onebot, plugin, qq, rpg, text-game, waygame, 文字游戏

## 简介

大型文字游戏框架，支持TXT，Markdown，图片绘制三种消息回复模式，注册打怪，结婚交友，地图闲逛等等
