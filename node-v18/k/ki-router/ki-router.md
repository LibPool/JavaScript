# ki-router

> 标签: ki-router, ki-router.js, router, sinatra

## 简介

[Sinatra](http://www.sinatrarb.com/) has a powerful url routing syntax that is used to identify different views in the application and the parameters used by the view. Javascript based apps can benefit from the same approach by using ki-router.js.
