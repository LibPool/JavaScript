# koishi-plugin-get-qq-bot-transfer-link

> 标签: chatbot, koishi, plugin

## 简介

🤖🔗⚙️ 利用NapCat获取官bot的uid，然后获取本群的 开放官bot的全量和主动的配置链接，然后群主用手机qq打开就可以配置了
