# kiot-cordova-plugin-misc

> 标签: android, capacitor, cordova, cordova-android, cordova-ios, display, ecosystem:cordova, edge-to-edge, feedback, haptic, ionic, ios, vibration

## 简介

Miscellaneous utilities for Cordova applications including EdgeToEdge display, cross-platform Haptic feedback, Universal Links / App Links (deeplinks), App Flip, and native iOS home-screen widgets + schedule notification actions.
