# kitty-graphics-agent

> 标签: agent, apc, cli, escape-sequence, graphics, images, kitty, llm, opencode, protocol, terminal

## 简介

Intercept Kitty Graphics Protocol images from CLI output and inject them into LLM context. A spec and OpenCode plugin for agent-CLI image passing.
