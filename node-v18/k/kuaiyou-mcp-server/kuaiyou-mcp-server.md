# kuaiyou-mcp-server

> 标签: android, automation, kuaiyou, mcp, model-context-protocol, reactive-skill

## 简介

A Model Context Protocol (MCP) server for Android reactive automation, enabling AI agents like Cursor and Claude to directly control Kuaiyou Master App.
