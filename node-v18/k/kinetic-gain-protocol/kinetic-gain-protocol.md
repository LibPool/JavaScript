# kinetic-gain-protocol

> 标签: ai-evidence, content-authenticity, ed25519, jcs, json-ld, kgp, provenance, rfc8785, verification

## 简介

Reference library and CLI for the Kinetic Gain Protocol (KGP): hash, sign, and verify provenance evidence objects for web claims. Zero dependencies.
