# ks-ui-components

> 标签: JavaScript

## 简介

Una librería de componentes UI construida con **React + TailwindCSS**, lista para usar en cualquier proyecto.   Incluye estilos precompilados en `dist/index.css`, por lo que no necesitas configurar Tailwind en tu aplicación para que los componentes funci
