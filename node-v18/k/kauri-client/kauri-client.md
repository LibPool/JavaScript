# kauri-client

> 标签: JavaScript

## 简介

Run ``` docker run -it \   -e "TOKEN=.eyJzd(...)" \   -e "SOCKET_PROTOCOL=wss" \   -e "WS_PROTOCOL=https" \   -e "WS_HOST=api.dev.kauri.io" \   -e "WS_PORT=443" \    kauriorg/kauri-scripts SCRIPT_NAME ARG1 ARG2 ARG3 ```
