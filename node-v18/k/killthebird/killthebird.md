# killthebird

> 标签: 3d, arcade, game, nextjs, react, shooter, three, threejs

## 简介

3D moorland bird-shooting arcade game (three.js) as a drop-in React / Next.js component. Parallax depth layers, edge scrolling, sound, bonus targets and score callbacks.
