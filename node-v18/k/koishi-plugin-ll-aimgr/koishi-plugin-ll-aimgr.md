# koishi-plugin-ll-aimgr

> 标签: ai, censor, group, keyword, koishi, moderation, plugin, review

## 简介

李浅浅自用插件。Koishi plugin: 群聊内容审查 —— 本地关键词闸门命中后送 AI 判定，按规则撤回/禁言；模型拒答或请求失败时转人工而不静默放过，避免 fail-open。支持观察模式、分级日志、词表热更新、图片 OCR/多模态。
