# koishi-plugin-qq-group-join-verification

> 标签: captcha, group, koishi, plugin, qq, verification

## 简介

Koishi 插件，用于 QQ 群加群验证，支持多适配器、多群独立配置、图片验证码、超时拒绝、白名单、数据库持久化、Console 可视化后台
