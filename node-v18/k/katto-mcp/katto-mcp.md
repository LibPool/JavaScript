# katto-mcp

> 标签: ai, ai-captions, ai-video-clipper, ai-video-editor, clips, katto, mcp, model-context-protocol, podcast-clips, repurpose-video, shorts, video, video-dubbing, video-to-shorts, youtube-to-shorts

## 简介

AI video clipping MCP server: turn long videos, podcasts and Twitch VODs into scored, captioned 9:16 shorts from Claude, Cursor, ChatGPT and any MCP client.
