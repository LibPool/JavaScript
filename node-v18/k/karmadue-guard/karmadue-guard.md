# karmadue-guard

> 标签: agents, mcp, npm, pip, security, supply-chain

## 简介

PinTree guard: known install traps with tested fixes, plus a safety check, before npm/npx/pnpm/yarn/pip/uv installs run. No account, no dependencies.
