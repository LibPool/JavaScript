# kd-swagger

> 标签: JavaScript

## 简介

自动生成swagger api 接口文件工具 ## 下载 下载安装kd-swagger ``` npm install -g kd-swagger ``` ## 使用 只传swagger文档地址 ``` kd-swagger -u http://192.168.3.173:8888/mvc/v2/api-docs  ```
