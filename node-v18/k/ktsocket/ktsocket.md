# ktsocket

> 标签: JavaScript

## 简介

1: 在使用socket的vue中或者全局vue中的created 注册 event信息.    2: 开启sokcet    3: 发送socket. 发送方法如下  socketHandler.send(cmd, content)   4: 在event中获取sokcet 回调信息, 回调信息已经封装成为: cmdMessage = { cmd: "n" , content: " ", timeStap : 1560000000 }    5: 获得event事件. 得到数据
