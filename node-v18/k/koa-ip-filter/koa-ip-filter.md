# koa-ip-filter

> 标签: array, blacklist, custom, filter, function, glob, id, ip, ips, koa, koajs, match, matcher, micromatch, middleware, minimatch, options, pattern, regex, regexp, string, support, whitelist

## 简介

Middleware for [koa][] that filters IPs against glob patterns, RegExp, string or array of globs. Support custom `403 Forbidden` message and custom ID.
