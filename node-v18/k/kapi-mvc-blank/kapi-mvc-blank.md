# kapi-mvc-blank

> 标签: api, mvc, node, prisma

## 简介

Framework MVC pour démarrer rapidement un projet d'API avec Node.js et Prisma (avec exemples d'authentification, upload de fichiers, documentation Swagger, logs avec Pino, etc.)
