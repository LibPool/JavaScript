# kaizoku-core

> 标签: JavaScript

## 简介

TypeScript scrapers used by [kaizoku.site](https://kaizoku.site): anime, movies/TV, torrents, live TV, plus TMDB / AniList / Kitsu metadata and a handful of video extractors.
