# kerplunk-foursquare-tweets

> 标签: kerplunk-plugin, kp:Foursquare, kp:Social Networking, kp:Swarm, kp:Twitter

## 简介

When tweets link to Foursquare/Swarm checkins, show them as activity on those checkins.
