# kanban-board-appstudio

> 标签: appstudio, board, colix, drag-and-drop, kanban, tasks, widget

## 简介

Drag-and-drop kanban board widget for Colix AppStudio. Turns any table with a status column into an interactive board with inline add, click-to-edit, and stage-change events.
