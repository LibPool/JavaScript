# kas-on-cloud

> 标签: cloud storage, document library, google drive, google drive api, microsoft graph api, multi-upload, nodejs upload, onedrive, sharepoint, typescript, upload file

## 简介

A unified Node.js library to upload files to SharePoint and Google Drive using Microsoft Graph API and Google Drive API.
