# korean-english-keyboard-converter

> 标签: converter, fix, hangul, input, keyboard, korean, language, mistyped, qwerty, typing

## 简介

QWERTY 레이아웃을 기반으로 잘못 입력된 한글-영어 키보드 입력을 변환하는 간단한 도구입니다. - A simple tool to convert mistyped Korean-English keyboard inputs based on QWERTY layout.
