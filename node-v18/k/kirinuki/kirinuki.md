# kirinuki

> 标签: background-removal, background-remover, birefnet, cutout, image, isnet, kirinuki, local, offline, privacy, product-photography, rembg, remove-background, transparent

## 简介

Remove image backgrounds locally - FastAPI + rembg (BiRefNet/ISNet/BRIA), drag & drop web UI, 100% offline. Handles hair, mesh and thin structures.
