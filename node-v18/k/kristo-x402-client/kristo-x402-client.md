# kristo-x402-client

> 标签: ai-agents, base, defi, http-402, kristo, langchain, payments, usdc, x402

## 简介

Zero-dependency x402 client for the Kristo Intelligence API — handles HTTP 402 paywalls, USDC payments on Base, and payment-proof retries automatically. Includes a LangChain tool factory.
