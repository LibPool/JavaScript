# keiri-core

> 标签: iDeCo, income-tax, inheritance-tax, japan, payroll, social-insurance, tax, ふるさと納税, 住民税, 手取り, 源泉徴収, 相続税, 確定申告, 社会保険料, 節税

## 简介

日本の給与・税・社会保険の計算ロジック（DOM非依存の純関数）。手取り・社会保険料・源泉徴収・住民税・ふるさと納税・iDeCo/小規模企業共済などの節税額・相続/贈与税ほか34種。公式の計算例・保険料額表と1銭まで照合したテスト付き。keiri-tools.com の計算エンジンそのもの。
