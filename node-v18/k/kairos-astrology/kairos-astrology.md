# kairos-astrology

> 标签: astrology, decision-support, electional, horary, swiss-ephemeris

## 简介

Astrology-based decision support: a Swiss Ephemeris engine that computes accurate charts (horary, transit, natal, electional) with classical dignities and returns calibrated verdicts.
