# karma-dojo-wrapper

> 标签: dojo, karma-adapter, karma-plugin

## 简介

A Karma plugin. Adapter for Dojo Toolkit.  Forked from https://github.com/karma-runner/karma-dojo.  It will bootstrap with the version of dojo you have or will download the latest version for you.
