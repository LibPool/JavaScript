# knownfy-mcp

> 标签: aml, compliance, due-diligence, knownfy, kyb, kyc, mcp, model-context-protocol

## 简介

MCP server for the Knownfy compliance intelligence API (KYC/KYB). Investigate entities, query relationship graphs, monitor watchlists and run bulk batches from Claude Desktop, Cursor or Claude Code.
