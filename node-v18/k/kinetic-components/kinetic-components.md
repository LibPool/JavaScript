# kinetic-components

> 标签: animatable, animate.style, animation, animations, animejs, component, css animations, orchestration, predicate animation, react, router primitives, sync

## 简介

Use CSS animations or your favorite JS animation library to animate a single React component or orchestrate animations amongst a collection of React components.
