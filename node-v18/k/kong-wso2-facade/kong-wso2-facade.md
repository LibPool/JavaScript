# kong-wso2-facade

> 标签: JavaScript

## 简介

Esta função é uma Lambda e serve como um *facade* para o endpoint de autenticação do WSO2am. Com o advento do Kong como API Gateway da plataforma Senior-X, o token OAuth2 fornecido pela autenticação no WSO2am não é o que é repassado ao usuário/aplicação,
