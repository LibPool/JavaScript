# khpay

> 标签: aba, cambodia, cli, khpay, khqr, payments

## 简介

Official KHPAY command-line tool. Generate QR & Bakong KHQR payments, manage transactions, webhooks, API keys, scheduled payments, tail logs and run test charges.
