# kinowatch-webapp-sdk

> 标签: kinowatch, mini-app, telegram, web-app

## 简介

kinowatch mini-app bundle: Telegram Web App SDK + app logic, served via jsDelivr/unpkg to load inside RU (telegram.org blocked; own domain throttled for large responses).
