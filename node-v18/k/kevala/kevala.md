# kevala

> 标签: browser, classification, decision-model, kev, laya, rust, system-one, webassembly, webgpu

## 简介

Run the Laya and Kev-0.8B decision models inside a web page, on WebGPU or WebAssembly: typed questions in, a probability for every option out, no server.
