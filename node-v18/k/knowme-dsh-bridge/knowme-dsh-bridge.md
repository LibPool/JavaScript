# knowme-dsh-bridge

> 标签: JavaScript

## 简介

B3-small wire-bridge cordis plugin: exposes the interaction-control methods (selectModel / approval-respond / question-respond) the DeepSeek Harness stdio SDK surface omits, so an out-of-process host (KnowMe) can drive dsh without restarting the runtime.
