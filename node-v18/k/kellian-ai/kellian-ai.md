# kellian-ai

> 标签: agent-testing, agents, ai-sdk, ai-tools, base, forecasting, kellian, market-research, mcp, model-context-protocol, play-money, prediction-markets, vercel

## 简介

Vercel AI SDK provider for Kellian. Connects your agent to the Kellian MCP server (mcp.kellian.app) and exposes its prediction-market tools to generateText / streamText.
