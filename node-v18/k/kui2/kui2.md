# kui2

> 标签: components, markdown, vue

## 简介

* CheckboxGroup 复选框组 * CodeEditor 代码编辑器 * Combobx 下拉选择框 * FormItem 表单项 * AmountInput 金额输入框(元、万元、亿元) * RateInput 利率输入框 * NumberInput 数字输入框 * Modal 弹出框 * Pagination 分页器 * RadioGroup 单选框组 * RichEditor 富文本 * table 表格 * TableEditor 可编辑表格 * TableSe
