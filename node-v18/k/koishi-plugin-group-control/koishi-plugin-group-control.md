# koishi-plugin-group-control

> 标签: blacklist, chatbot, group, koishi, management, onebot, plugin, qq

## 简介

Koishi 插件，一个多功能的群聊自管理工具。支持被踢出自动拉黑、刷屏自动屏蔽、开关控制等功能。(仅支持 OneBot 适配器)
