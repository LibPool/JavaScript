# kaheljs

> 标签: controller, decorators, dependency-injection, framework, functional, hono, http, ioc, module, router, typescript, web-framework

## 简介

A lightweight, type-safe framework for building scalable HTTP applications with Hono. Features dependency injection, modular architecture, controller-based routing, and zero-overhead abstractions.
