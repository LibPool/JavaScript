# koa-smart

> 标签: api, boilerplate, class, decorator, framework, koa-boilerplate, koa-decorator, koa-es6, koa-es7, koa-essential, koa-router, koa-smart, koa2-boilerplate, koa2-decorator, koajs, koajs-2, koajs-2-decorator, koajs-boilerplate, restfull, router

## 简介

A framework base on Koajs2 with Decorator, Params checker and a base of modules (cors, bodyparser, compress, I18n, etc…) to let you develop smart api easily
