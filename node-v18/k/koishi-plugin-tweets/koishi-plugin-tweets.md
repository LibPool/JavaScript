# koishi-plugin-tweets

> 标签: koishi, plugin, tweet, twitter, x

## 简介

自动解析聊天中的 Twitter/X 链接，并发送推文的文字、图片和视频，且可翻译设置模型翻译，可解析GIF。在koishi-plugin-twitter-link的基础上修改建立
