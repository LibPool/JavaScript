# katanakit-sysli

> 标签: cli, journalctl, sysadmin, systemd, tui

## 简介

ksys — lazysystemd: todo el ecosistema systemd (units, timers, journal, boot, network, sessions, devices) en una TUI. Requiere Linux + systemd.
