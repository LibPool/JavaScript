# km-api

> 标签: alova, api, api-config, api-schema, axios, endpoint, fetch, http-client, km-api, km-packages, openapi, openapi3, request, response, rest-api, schema-validation, swagger, swagger2, type-safe, typescript, zod

## 简介

Type-safe API schema builder for TypeScript — define HTTP endpoints with Zod validation, full OpenAPI 3.0 compatibility, and adapters for Axios, Fetch, and Alova.
