# kenkage-mcp

> 标签: agent, dom, kenkage, mcp, model-context-protocol, on-device, sandbox, wasm

## 简介

MCP server exposing kenkage's on-device, isolation-by-construction DOM+JS engine as agent tools: safely load/parse a page, query the DOM, and run untrusted JavaScript in a real WASM sandbox — no headless browser, no server round-trip.
