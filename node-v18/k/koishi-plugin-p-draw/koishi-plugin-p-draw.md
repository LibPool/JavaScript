# koishi-plugin-p-draw

> 标签: chatbot, koishi, plugin

## 简介

p点-绘图，连接本地 ComfyUI 生图。支持自然语言优化、尺寸选择、画师组、固定角色、生成队列，需要配合 p-qiandao 使用
