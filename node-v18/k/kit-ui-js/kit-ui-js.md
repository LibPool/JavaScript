# kit-ui-js

> 标签: cdn, component, design-system, html, material-design, material3, no-build, ui-kit, vue3

## 简介

UI-Kit — M3 黑白极简风格的 Vue 3 组件库（无构建，可直接通过 CDN 引入）。Buttons, Inputs, Select (searchable/multiple), Dialog, Confirm, Toast, Dropdown, Tabs, Table 等 22+ 组件。
