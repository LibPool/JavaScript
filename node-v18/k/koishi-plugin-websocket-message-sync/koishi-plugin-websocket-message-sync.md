# koishi-plugin-websocket-message-sync

> 标签: chatbot, koishi, minecraft, plugin, websocket

## 简介

简易的 WebSocket 服务端，应用于 Telegram 群组，可以用作《Minecraft》基岩版服务端消息互通插件
