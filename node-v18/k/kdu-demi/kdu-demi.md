# kdu-demi

> 标签: JavaScript

## 简介

- `<=2.6`: exports from `kdu` + `@kdujs/composition-api` with plugin auto installing. - `2.7`: exports from `kdu` (Composition API is built-in in Kdu 2.7). - `>=3.0`: exports from `kdu`, with polyfill of Kdu 2's `set` and `del` API.
