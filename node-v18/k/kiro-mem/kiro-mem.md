# kiro-mem

> 标签: acp, ai, context, kiro, kiro-cli, mcp, memory, persistence, sqlite

## 简介

Persistent cross-session memory system for Kiro CLI. Captures every turn, compresses via Kiro CLI ACP, and injects a compact memory index into later sessions.
