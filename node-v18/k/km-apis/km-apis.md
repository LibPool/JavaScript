# km-apis

> 标签: JavaScript

## 简介

```js //引入使用 apis 是一个函数库 import apis from 'km-apis'; // 防抖节流函数 第一个参数为防抖的函数，第二个为时间，第三个是否立即执行 apis.debounce(fn,time,flag); //获取dom节点信息,传入class名 apis.dom(className); //延时函数 apis.sleep(time); ```
