# kenkage

> 标签: agentic, ai-agent, browser, browser-use, dom, headless, html-parser, js-sandbox, kenkage, on-device, quickjs, sandbox, wasm, webassembly, zig

## 简介

Sandboxed browser engine (DOM + real QuickJS) compiled to WebAssembly — parse HTML, query the DOM, and run untrusted JavaScript on-device, in the browser, with no server round-trip
