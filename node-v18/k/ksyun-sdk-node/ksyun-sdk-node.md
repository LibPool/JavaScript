# ksyun-sdk-node

> 标签: JavaScript

## 简介

欢迎使用金山云开发者工具套件（SDK）。为方便 NODEJS 开发者调试和接入金山云产品 API，这里向您介绍适用于 NODEJS 的金山云开发工具包，并提供首次使用开发工具包的简单示例。让您快速获取金山云 NODEJS SDK 并开始调用。
