# koishi-plugin-ytdlp

> 标签: audio, download, koishi, plugin, video, youtube, ytdlp

## 简介

使用 yt-dlp 从视频链接（如YouTube）下载视频或音频，并支持智能画质选择。

## 官网

- npm 页面：https://www.npmjs.com/package/koishi-plugin-ytdlp

- 1.0.0

- npm registry：https://registry.npmjs.org/koishi-plugin-ytdlp
