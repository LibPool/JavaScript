# karma-phantomjs2-ext-launcher

> 标签: karma-launcher, karma-plugin, phantomjs

## 简介

A Karma plugin. Launcher using the phantomjs2-ext package. Using this version of phantom instead of phantomjs-prebuilt appears to fix out-of-memory issues when running a lot of tests at once.
