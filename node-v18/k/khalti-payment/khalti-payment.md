# khalti-payment

> 标签: api, gateway, khalti, payment

## 简介

A Node.js module for interacting with the Khalti payment gateway, enabling seamless payment initiation and status lookup. This package provides functions to initiate payments through Khalti's ePayment API and look up payment status based on transaction id
