# koishi-plugin-rss-subscribe

> 标签: bot, koishi, koishi-plugin, markdown, nitter, qq, roblox, rss, rss-subscribe

## 简介

自用RSS订阅 - Koishi v4 RSS订阅推送插件，支持QQ官方机器人Markdown格式消息发送，定时抓取RSS源并推送新内容到指定群聊
