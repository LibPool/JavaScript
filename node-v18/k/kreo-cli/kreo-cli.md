# kreo-cli

> 标签: baas, backend, cli, codegen, database, kreo, postgres, rest, types

## 简介

The KREO command-line tool (command: `kreo`) — read/insert/delete data, seed & export tables, generate types, run SQL, check status, and scaffold apps. Talks to your KREO project over the public API.
