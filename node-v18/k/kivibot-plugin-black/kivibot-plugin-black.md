# kivibot-plugin-black

> 标签: kivibot, kivibot-plugin

## 简介

QQ 机器人框架 KiviBot 的黑名单插件，支持将群和好友加入黑名单，检测到新增好友或者新增群在黑名单内时时自动删好友或者退出群聊
