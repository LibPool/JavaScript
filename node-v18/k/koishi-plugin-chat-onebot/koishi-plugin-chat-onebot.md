# koishi-plugin-chat-onebot

> 标签: Stapxs QQ Lite, chat-onebot, chatbot, koishi, plugin

## 简介

chat-onebot - 集成 Stapxs QQ Lite 2.0 到 Koishi 控制台。一个兼容 OneBot 的非官方网页 QQ 客户端。
