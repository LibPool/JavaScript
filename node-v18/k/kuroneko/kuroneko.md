# kuroneko

> 标签: adult, api-wrapper, catalog, crawler, doujinshi, manga, nodejs, scraper, serverless, web-scraping, zero-dependency

## 简介

Zero-dependency scraping modules for media cataloging — manga, video-posts, 2D streaming, tube, and blog/RSS feed sources. Framework-agnostic; works in Node.js >= 18.17, Bun, or any JS runtime with global fetch.
