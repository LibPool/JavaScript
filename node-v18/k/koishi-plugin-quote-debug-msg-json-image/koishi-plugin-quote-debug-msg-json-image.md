# koishi-plugin-quote-debug-msg-json-image

> 标签: chatbot, koishi, plugin

## 简介

📋把一条消息用json/yaml/toml的格式渲染成图片，🎨支持typst或者markdown。还支持用puppeteer渲染onebot的合并转发成图片🖼️
