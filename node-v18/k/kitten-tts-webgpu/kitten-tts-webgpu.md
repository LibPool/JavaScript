# kitten-tts-webgpu

> 标签: browser, kitten-tts, speech-synthesis, text-to-speech, tts, webgpu

## 简介

Run Kitten TTS (80M) locally in the browser via WebGPU. One function call: textToSpeech('Hello!') → WAV blob.
