# kuto

> 标签: JavaScript

## 简介

🌈 Kuto makes updating your site's JS better, faster, harder, stronger. It reduces your download size by re-using code you've already shipped. Read more [on the blog](https://samthor.au/2024/kuto/)! 🌈
