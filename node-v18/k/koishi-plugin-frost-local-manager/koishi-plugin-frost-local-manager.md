# koishi-plugin-frost-local-manager

> 标签: JavaScript

## 简介

白泽·本地插件管理台：网页界面中监控并编辑 Koishi 实例的本地 ./external 自有插件（自动列出所有本地自有插件、展示运行时状态、可编辑配置）。其它插件由 Koishi 自带管理，这里只管我们自己的本地插件。
