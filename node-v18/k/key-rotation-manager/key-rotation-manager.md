# key-rotation-manager

> 标签: api-key-rotation, credential-management, cryptography, encryption, key-management, key-rotation, nodejs, secret-management, typescript

## 简介

Production-ready cryptographic key management library for Node.js with automatic rotation, expiration, versioning, and flexible storage. Supports AES-256-CBC encryption, PBKDF2 key derivation, file-based storage, custom hooks, and TypeScript.
