# kitty-vt-wasm

> 标签: ansi, escape-codes, kitty, terminal, terminal-emulator, vt100, wasm, webassembly

## 简介

kitty's real terminal core (screen.c + vt-parser.c) compiled to WebAssembly, wrapped as a typed library with all I/O abstracted
