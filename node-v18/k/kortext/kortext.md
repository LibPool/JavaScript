# kortext

> 标签: agent, agentic-coding, agents-md, ai, analysis, claude, codex, documentation, gemini, local-first, project-planning

## 简介

The project brain for AI-driven development: a brief becomes approved analysis documents, then your own agent CLI (Claude Code, Codex, Gemini) writes the code.
