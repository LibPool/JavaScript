# koishi-plugin-oobabooga-testbot

> 标签: chatbot, koishi, plugin

## 简介

大语言模型(本地/在线)聊天机器人。支持AI视觉伪/真多模态，AI工具调用，Emb长期记忆，vits语音回复，AI自动判断调用绘图，更多娱乐功能请看插件简介。
