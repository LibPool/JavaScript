# kompo-extension

> 标签: DOM, Native extension, components, interface, javascript, react, view

## 简介

Builtin extensions for the Kompo library. Kompo is a react like library which tries to stay simple as possible. No virtual DOM or JSX. Kompo loves the DOM.
