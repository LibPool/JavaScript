# @prowl-ai/prowl-skill

> 标签: agent-skills, claude-code, competitive-analysis, hooks, market-intelligence, mcp, plugin, prowl, seo, status-line

## 简介

The Prowl plugin: install/usage skills, the hosted MCP config, and the live status widget that makes a running Prowl call, its progress and its cost visible in the terminal. This package is the installer CLI.
