# @nodeboot/netlify-server

> 标签: netlify, netlify-functions, nodeboot, serverless

## 简介

Node-Boot Netlify Functions server package. It provides a simple way to create Netlify Functions handlers using NodeBoot, with support for routing, middleware, and request handling.
