# @cosmicdrift/kumiko-server-runtime

> 标签: JavaScript

## 简介

Production server-boot runtime for Kumiko apps: connections, schema-drift-gate, seeds, lifecycle, graceful shutdown. Symmetric to kumiko-dev-server's runDevApp, without dev/scaffold tooling.
