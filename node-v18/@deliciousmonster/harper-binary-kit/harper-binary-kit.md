# @deliciousmonster/harper-binary-kit

> 标签: binary, cross-platform, harper, harperdb, npm-publish, optionaldependencies, platform-package

## 简介

Ship a native binary from a Harper component: one platform package per host, staged, verified, published, and resolved back at runtime
