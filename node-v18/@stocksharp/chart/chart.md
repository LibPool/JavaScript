# @stocksharp/chart

> 标签: algorithmic-trading, candlestick, canvas, chart, charts, financial-charts, footprint, indicators, market-profile, order-flow, stocksharp, technical-analysis, tpo, trading, typescript, volume-profile

## 简介

StockSharp JS Trading Charts — a dependency-free browser trading-chart engine: native panes, custom series, primitives, incremental indicators, exact order flow (footprint / volume profile / TPO) and a broker-agnostic trading layer, with a TypeScript API
