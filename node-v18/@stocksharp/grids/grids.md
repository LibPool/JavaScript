# @stocksharp/grids

> 标签: columns, data-grid, dom, export, grid, sorting, stocksharp, table, typescript, xlsx

## 简介

Browser data grid for StockSharp: column-driven table rendering, sorting, a column picker for server-rendered tables, and .xlsx export.
