# @stravica-ai/rcf-lite-core

> 标签: mcp, rcf, requirements, store, traceability

## 简介

Shared internals for the RCF Lite tooling suite: the RCF-chain store (read + write), the structured RcfError type, and the RCF-agnostic MCP protocol shell. Consumed by @stravica-ai/rcf-build-lite and @stravica-ai/rcf-verify-lite via workspace:*.
