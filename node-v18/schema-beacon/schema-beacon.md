# schema-beacon

> 标签: github-action, html, json-ld, microdata, rich-results, rich-snippets, sarif, schema-org, seo, static-site, structured-data

## 简介

Validate JSON-LD and microdata in a built static site against schema.org types and Google rich-result requirements: parse errors, unknown types, missing required/recommended properties, bad dates, prices, currencies, enums, durations, ratings and breadcru
