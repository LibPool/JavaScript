# @vogelweb/cursor-js

> 标签: CSS, UI, UI effects, UX, cursor, cursors, custom cursors, frontend, interactive, mouse, pointer, pointes, webdev

## 简介

Create simple yet effective cursor effects without writing JavaScript. You can use data attributes to configure cursors or use the Cursor class instance for more control.
