# @pi-harness/plugin-skill-guard

> 标签: cordis, pi-harness, pi-harness-plugin, plugin

## 简介

Audit each loaded Skill entry Markdown file with bounded heuristics for instruction override, secret exfiltration, destructive commands, and obfuscation; it reports risk labels and does not disable loaded Skills.
