# @pi-harness/plugin-browser-session

> 标签: cordis, pi-harness, pi-harness-plugin, plugin

## 简介

Control a loopback-only Chrome DevTools session with descriptor-safe commands, bounded discovery, cancellable operations, screenshot metadata protection, and validated fail-closed panel previews.
