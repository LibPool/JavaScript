# @pi-harness/plugin-readme-gen

> 标签: cordis, pi-harness, pi-harness-plugin, plugin

## 简介

Generate README reports from strictly bounded manifest metadata and a descriptor-safe loader inventory with Markdown-safe rendering, plus confirmed no-clobber atomic writes, explicit overwrite confirmation, and cancellable sequential execution.
