# @pi-harness/plugin-sql-lens

> 标签: cordis, pi-harness, pi-harness-plugin, plugin

## 简介

Inspect workspace-contained SQLite databases with strict descriptor-safe inputs, a single read-only statement, bounded results, symlink and replacement checks, timed worker execution, cancellation, and fail-closed panel reporting.
