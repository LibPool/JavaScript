# @pi-harness/plugin-turn-rewind

> 标签: cordis, pi-harness, pi-harness-plugin, plugin

## 简介

Scans a bounded current branch for user turns, supports queued serialized cancellable rewinds after the agent settles, and navigates the native session tree while preserving abandoned branches.
