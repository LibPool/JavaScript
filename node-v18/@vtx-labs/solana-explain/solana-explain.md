# @vtx-labs/solana-explain

> 标签: balance-diff, cli, decode, explain, simulate, solana, spl-token, token-2022, transaction, typescript, web3

## 简介

Turn any Solana transaction signature, raw/base64 transaction, or unsigned instruction set into a plain-English "what this actually does" report — net balance deltas, transfers, account creations, approvals, and program invocations. No IDLs required.
