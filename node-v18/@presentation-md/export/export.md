# @presentation-md/export

> 标签: JavaScript

## 简介

Round-trip PowerPoint for presentation-md decks — export Deck JSON to editable .pptx, and import .pptx back into Deck JSON.

- 源码仓库：git+https://github.com/isatimur/presentation-md.git
