# @ptlm-azulejo/page-header-feature

> 标签: JavaScript

## 简介

The `PageHeaderFeature` component renders a clickable action displayed in the feature area of a page header. It combines an Azulejo icon with a text label and is typically used for common actions such as search, notifications, help, or shortcuts.
