# @e10/admin-api-schema

> 标签: JavaScript

## 简介

The package serves as a single source of truth when validating requests coming into Luinq's Admin API endpoints. It uses [JSON Schema](https://json-schema.org/) definitions under the hood to describe expected format of validated data.
