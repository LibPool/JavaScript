# @yuthent/server

> 标签: ack, approval-token, authentication, biometric, device-trust, express, middleware, psea, yuthent

## 简介

Express middleware for verifying Yuthent SDK retry headers — Post-Session Execution Assurance (PSEA) on the server side.
