# @quereus/quereus

> 标签: async, browser-database, cross-platform, database, edge-computing, embedded-database, in-memory-database, local-first, no-wasm, offline-first, query-engine, react-native, sql, sql-engine, sqlite-alternative, typescript, virtual-table

## 简介

Pure TypeScript SQL engine — no WASM, no native bindings. Runs in browsers, Node.js, React Native, edge workers, and anywhere JS runs.
