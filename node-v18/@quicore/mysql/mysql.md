# @quicore/mysql

> 标签: fhir, healthcare, hl7, interoperability, mongodb, r4, repository, storage

## 简介

Production-grade MySQL connection pool helper for Node.js services. Wraps mysql2/promise with parameterized queries, transactions, structured errors, and metrics.
