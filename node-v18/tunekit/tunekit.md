# tunekit

> 标签: color-picker, controls, devtools, easing, gui, panel, react, spring, tuning, tweak

## 简介

Floating dev panel for tuning React UIs by eye — sliders, colors, springs and easings in a Shadow DOM panel you can drag, dock and copy back to code.
