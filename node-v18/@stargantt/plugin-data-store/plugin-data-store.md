# @stargantt/plugin-data-store

> 标签: gantt, gantt-chart, plugin-architecture, project-management, scheduling, timeline, typescript, zero-dependencies

## 简介

Official StarGantt plugin: holds every task, link, resource, assignment and custom field value, and turns each change into a reversible transaction.
