# @broberg/web-clipper

> 标签: broberg, browser-extension, clipper, dedupe, fingerprint, idempotent, web-clipper

## 简介

The fleet's one web-clipper base (Trail Web Clipper, Jam Clipper): /core fingerprint + chain + branch engine, /extract Extractor plug-in point + Trail's article extractor, /transport destinations + sender (only new units, idempotent resend, 401/5xx rules,
