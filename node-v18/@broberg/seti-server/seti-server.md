# @broberg/seti-server

> 标签: broberg, buddycloud, hono, proxy, set, seti, sse, streaming, terminal, tmux

## 简介

Mountable Hono proxy router for buddycloud.cc's SETI API v1 — embed SET/SETI live streaming chat in a host app while the consumer token stays server-side (no CORS, host-app auth in front).
