# @broberg/local-guard

> 标签: broberg, bun, csrf, daemon, dns-rebinding, hono, host-header, local-server, localhost, loopback, security

## 简介

One guard for a local HTTP daemon on 127.0.0.1: Host must name this loopback address on its own port (421 — closes DNS rebinding), and a write must be application/json (415 — a cross-site page cannot send that without a CORS preflight). Framework-free cor
