# @etium/core

> 标签: agents, claude-code, codex, coding-agents, loop-engineering, openhands, orchestration, pi, supervisor

## 简介

The outer loop for coding agents. Etium supervises headless harnesses: tasks, runs, budgets, gates, and an append-only event ledger.
