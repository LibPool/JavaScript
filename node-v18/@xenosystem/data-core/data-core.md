# @xenosystem/data-core

> 标签: JavaScript

## 简介

The shared data contract for the XENO data-panel family — XenoResultSet down, XenoQuery up — plus the pure pipeline (filter, sort, group, aggregate, paginate, format, pivot). Zero dependencies, zero DOM.
