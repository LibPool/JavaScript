# @dreamworld/workbox-installer

> 标签: pwa, service-worker, workbox

## 简介

A PWA service worker lifecycle manager built on [`workbox-window`](https://developer.chrome.com/docs/workbox/modules/workbox-window/) that handles SW registration, update detection, user confirmation flow, and activation — with optional Firebase/Firestore
