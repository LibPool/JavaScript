# dsh-gitbar-lite

> 标签: commit, deepseek-harness, diff, dsh, dsh-plugin, git, github-desktop, sidebar, source-control

## 简介

A GitHub Desktop-style Git panel for DSH: changed files, tick-to-stage, Summary + Description, Commit and Commit and Push, discard-to-trash, and diff preview, in the built-in right sidebar.
