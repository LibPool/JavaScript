# @tvuikit/fps-pixi-react

> 标签: fps, hud, pixi, react, tv, tvkit

## 简介

On-screen FPS HUD for Pixi-React TV UIs. Renders FPS, p95/max frame times, and stall counts as a Pixi overlay.
