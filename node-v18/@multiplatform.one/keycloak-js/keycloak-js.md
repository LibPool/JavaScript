# @multiplatform.one/keycloak-js

> 标签: auth, keycloak, keycloak-js, multiplatform.one, oidc

## 简介

Keycloak JS adapter vendored and patched (e.g. timeout overflow fix). Built from upstream keycloak-js at build time.
