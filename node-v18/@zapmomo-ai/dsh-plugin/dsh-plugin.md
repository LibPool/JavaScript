# @zapmomo-ai/dsh-plugin

> 标签: deepseek-harness, desktop-companion, dsh, dsh-plugin, zapmomo

## 简介

dsh（DeepSeek Harness）→ ZapMomo 桌宠任务事件桥：监听 agent/status 与 turn/end，把任务开始/完成/失败/中断推给 ZapMomo 的 loopback 桥，桌宠以气泡 + 语音播报。
