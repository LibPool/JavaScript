# @openmascot/web

> 标签: animation, character, custom-element, dom, mascot, openmascot, pseudo-3d, rigging, svg, web-components

## 简介

Browser runtime for OpenMascot: live DOM SVG renderer, animation player and the <open-mascot> custom element.
