# @ghost-ark/kernel-probe

> 标签: attestation, canonical-json, canonicalization, content-addressing, digest, duplicate-keys, identity, json, provenance, sbom

## 简介

Report which distinctions a JSON canonicalizer destroys: probe any parse->canonicalize->digest pipeline with a pre-registered pathology corpus, or bring your own corpus with --alphabet.
