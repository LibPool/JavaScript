# @varlock/alchemy-integration

> 标签: .env, alchemy, cloudflare, config, env, environment variables, leak protection, secrets, security, validation, varlock, varlock-integration

## 简介

Alchemy secret manager backed by varlock: validated env from .env.schema for your stack, typed Worker bindings, and the varlock runtime blob for in-Worker log redaction and leak detection
