# @rsv_ink/ink-hub-mcp

> 标签: anthropic, claude, ink-hub, mcp, model-context-protocol, proxy, stdio

## 简介

Local MCP client that bridges stdio-based MCP clients (Claude Desktop, Cursor, Zed) to the remote Ink Hub MCP server.
