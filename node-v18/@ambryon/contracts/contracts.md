# @ambryon/contracts

> 标签: JavaScript

## 简介

Wire contracts (Zod) for the ambryon API: library responses, the Rubi stream, projects, memories, revisions, attention, tiers and the internal endpoints, plus shared display metadata. Not the data standard (@ambryon/schema): the API's wire format.
