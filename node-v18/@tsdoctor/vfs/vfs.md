# @tsdoctor/vfs

> 标签: declarations, effect, twoslash, typescript, vfs, virtual-package

## 简介

Virtual TypeScript projects for documentation tooling: the Vfs currency type, declaration-backed virtual packages, @typescript/vfs environments, and the compiler-option resolution that configures them.
