# @4-ti/pinojs-logger

> 标签: koa, koa-pino-logger, logger, logging, logstash, pino, pino-pretty

## 简介

Shared pino-based logger. Encloses pino, pino-pretty and koa-pino-logger so consuming projects don't depend on pino directly.
