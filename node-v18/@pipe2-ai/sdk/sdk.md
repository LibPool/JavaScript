# @pipe2-ai/sdk

> 标签: ai, api, graphql, image-generation, pipe2, sdk, text-to-speech, text-to-video, video-generation

## 简介

Typed TypeScript client for the Pipe2.ai API — run AI media pipelines (video generation, image generation, text-to-speech, video reframing) and track their results.
