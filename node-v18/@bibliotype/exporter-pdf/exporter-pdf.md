# @bibliotype/exporter-pdf

> 标签: JavaScript

## 简介

PDF 导出：IR → 打印文档（@page 尺寸 / 预分页固定页）+ 打印辅助（window.print）+ 印前精排（对页 / 出血 / 裁切线 / DPI 与 CMYK 提示）- bibliotype 导出包
