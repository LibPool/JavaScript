# turnsignal

> 标签: ci, dashboard, e2e, flaky, flaky-tests, github-actions, mcp, playwright, playwright-reporter, reporter, test-reporting, test-results, testing

## 简介

Crash-proof Playwright reporter and CLI: know if your change broke the tests, which tests are flaky, and which never reported.
