# @extrimian/kms-algorithm-x25519

> 标签: JavaScript

## 简介

Primitiva X25519 (acuerdo de claves ECDH sobre bytes) del KMS de Verona Trust. Extraída de kms-suite-didcomm-v2. Paquete standalone e inyectable: cero dependencias @extrimian.
