# @tduyng/prettyoutput

> 标签: cli, colors, formatting, javascript, json, json-format, json-pretty-print, log, logging, output, performance, pretty, pretty-print, typescript, yaml

## 简介

Library to format JSON objects into a colorful, YAML-style output. Ideal for pretty printing logs with high performance.
