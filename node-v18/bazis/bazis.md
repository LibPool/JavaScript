# bazis

> 标签: bun, codegen, dependency-injection, framework, http, orm, postgresql, typescript, websocket

## 简介

Modular backend framework for Bun in TypeScript: DI wired by codegen, HTTP, a PostgreSQL ORM, JWT, WebSocket, agents and a CLI.
