# @dingshaohua.com/md-editor

> 标签: JavaScript

## 简介

基于 React、Milkdown、Monaco Editor 和 Tailwind CSS 的 Markdown 编辑器组件。项目同时包含组件库源码和 Vite 演示应用，支持所见即所得编辑、Markdown 源码编辑、自动保存状态展示，以及常用 Markdown 扩展能力。
