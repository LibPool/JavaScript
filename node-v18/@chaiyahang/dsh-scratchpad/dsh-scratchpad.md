# @chaiyahang/dsh-scratchpad

> 标签: client-plugin, deepseek-harness, dsh, dsh-plugin, markdown, notes, scratchpad, tags, todo

## 简介

Scratchpad panel for DeepSeek Harness: tagged notes, image and file attachments, Markdown preview with clickable tasks, send-to-chat with real attachments, a wake-up shortcut, JSON export/import, and Agent tools over Host-side storage.
