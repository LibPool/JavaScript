# @rupanshu/ttl-web-storage

> 标签: cache, expiration, expire, localStorage, sessionStorage, ssr, storage, ttl, typescript, web-storage

## 简介

Lightweight, zero-dependency TTL-aware wrapper for localStorage/sessionStorage with an in-memory fallback for SSR/Node.
