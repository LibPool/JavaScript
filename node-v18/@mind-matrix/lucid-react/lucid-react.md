# @mind-matrix/lucid-react

> 标签: createComponent, custom-elements, interop, lucid, react, web-components

## 简介

React 17/18 interop helpers for Lucid components. Provides createComponent() for binding custom-event-only components into JSX. Not needed for React 19 or components that dispatch native DOM events.
