# @simnode/http-proxy

> 标签: JavaScript

## 简介

Lightweight HTTP interceptor for deterministic simulation testing. Patches `http.request`/`https.request`, records calls, serves static mocks, and integrates with `@simnode/clock` for virtual latency.
