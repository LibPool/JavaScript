# @quarks.studio/installer

> 标签: JavaScript

## 简介

Safe, recursive skill installer. It resolves versions/dependencies, validates permissions, verifies SHA-256, audits and extracts TAR, applies mappings transactionally and writes `skill.lock.yml`.
