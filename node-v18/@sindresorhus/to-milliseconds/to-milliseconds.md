# @sindresorhus/to-milliseconds

> 标签: duration, interval, into, microseconds, milliseconds, ms, nanoseconds, object, parse, period, properties, range, time, to

## 简介

Convert an object of time properties to milliseconds: `{seconds: 2}` → `2000`
