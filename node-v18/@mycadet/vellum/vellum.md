# @mycadet/vellum

> 标签: JavaScript

## 简介

Migrate a vellum assistant workspace to cadet. Reads vellum 0.12.x data the same way the vellum assistant did, and writes it to the cadet layout.

## 官网

- 官网：https://github.com/vargasjr-dev/vellum-to-cadet#readme
- 源码仓库：git+https://github.com/vargasjr-dev/vellum-to-cadet.git
- npm 页面：https://www.npmjs.com/package/@mycadet/vellum
