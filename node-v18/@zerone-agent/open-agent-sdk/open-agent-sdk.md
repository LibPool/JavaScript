> 标签: agent, agentic, ai, coding-agent, llm, mcp, open-agent-sdk, sdk, tools, zerone

## 简介

Open-source Agent SDK. Runs the full agent loop in-process — no local CLI required. Deploy anywhere: cloud, serverless, Docker, CI/CD.
