# elizaos-plugin-pumpdata

> 标签: data, elizaos, elizaos-plugins, plugin, pump.fun, solana, x402

## 简介

pump.fun history for elizaOS agents from pumpdata.fun: launch, deployer, similar-launch and wallet records, paid per call in USDC over x402 on Solana, plus the free daily stats.
