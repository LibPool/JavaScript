# @angular-schule/prerender-format

> 标签: angular, angular-cli, builder, cloudflare pages, github pages, prerender, ssg, static site, trailing slash

## 简介

Angular application builder that writes prerendered routes as foo.html instead of foo/index.html (no trailing slash redirects)
