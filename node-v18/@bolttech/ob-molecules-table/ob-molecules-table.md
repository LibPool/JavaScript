# @bolttech/ob-molecules-table

> 标签: JavaScript

## 简介

A set of composable table components (`Table`, `TableHead`, `TableHeadColumn`, `TableBody`, `TableRow`, `TableColumn`) with optional column sorting and row highlighting.
