# @swayam5342/api2mcp

> 标签: api, claude, mcp, model-context-protocol, openapi, proxy, stdio, swagger

## 简介

Serve any OpenAPI 3.x / Swagger 2.x API as a local MCP (Model Context Protocol) server over stdio, proxying tool calls to the upstream HTTP API.
