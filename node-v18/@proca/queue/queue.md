# @proca/queue

> 标签: activism, advocacy, campaigning, civic-tech, digital-engagement, email-campaign, grassroots, mobilisation, nonprofit, petition, proca, social-change

## 简介

This package provides a **robust RabbitMQ consumer** for processing Proca **action** and **event** messages with strict retry, dead-letter, and crash semantics.
