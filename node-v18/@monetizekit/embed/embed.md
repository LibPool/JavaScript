# @monetizekit/embed

> 标签: JavaScript

## 简介

MonetizeKit vanilla-JS embed SDK for non-React apps — auto-renders pricing tables, paywalls, portals, and banners from data-mk-widget attributes. Ships an ESM/CJS module and a self-initializing IIFE (embed.js) for CDN <script> usage.
