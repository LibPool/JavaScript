# @cap-kit/redsys

> 标签: 3d-secure, 3ds, android, cap-kit, capacitor, capacitor-plugin, card-payment, hmac, in-app-payments, ios, mobile-payments, payment, payment-gateway, redsys, redsys-inapp, redsys-sdk

## 简介

Redsys InApp SDK bridge for Capacitor v8. Supports native Direct Payment and secure 3D Secure (3DS) WebView flows with unified cross-platform API and HMAC signature utilities.
