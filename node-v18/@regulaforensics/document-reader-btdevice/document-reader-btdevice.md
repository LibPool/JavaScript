# @regulaforensics/document-reader-btdevice

> 标签: capacitor, cordova, face, ionic, react, react-native, reader, regula, scanner

## 简介

This is an npm module for Regula Document Reader BTDevice. It allows @regulaforensics/document-reader connecting to external RFID readers via bluetooth.
