# @okinoxis/hero-scene

> 标签: cinematic, compound-component, hero, nextjs, parallax, react, vignette

## 简介

Cinematic hero sections for Next.js — compound component API with image rotation, parallax, vignette overlays, blur masks, and dot patterns.
