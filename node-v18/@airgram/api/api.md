# @airgram/api

> 标签: tdlib javascript, tdlib typescript, tdlib typings, tdlib wrapper, telegram

## 简介

This repository contains strict typed wrappers for all [TDLib](https://core.telegram.org/tdlib) (1.4.0) methods and classes.
