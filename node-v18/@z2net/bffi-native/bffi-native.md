# @z2net/bffi-native

> 标签: bffi, bun, ffi, native, rust

## 简介

The bffi-rs reference native module: prebuilt cdylibs for win32-x64/arm64, linux-x64/arm64 (glibc and musl) and darwin-x64/aarch64, loaded through the @z2net/bffi typed loader.
