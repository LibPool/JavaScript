# @dominionli/obsign-sdk

> 标签: JavaScript

## 简介

Obsign SDK — offline receipt verification, a REST/x402 API client, and a viem-based pinned chain reader (INV-6). @obsign/core is bundled so the published package verifies offline with no workspace dependency.
