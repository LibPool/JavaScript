# @jaimeortega/vaiven

> 标签: animation, canvas, figures, generative, generative-art, loop, web-component, zero-dependency

## 简介

Calm, perpetually looping generative figures for the web. Zero-dependency Canvas 2D engine — every animation is a JSON config. `npx vaiven` opens the local workspace to design and manage this project's figures.
