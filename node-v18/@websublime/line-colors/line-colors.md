# @websublime/line-colors

> 标签: JavaScript

## 简介

Radix-derived color palette: 31 hues (12-step base + 12-step alpha) plus four special scales (`blackA`, `whiteA`, `blackP3A`, `whiteP3A`). One CSS subpath per hue.
