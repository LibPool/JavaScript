# @velocut/runtime

> 标签: JavaScript

## 简介

Project editing services shared by Velocut Studio and external hosts. This package has no React dependency or imports from the editor application. It combines the pure engine, scene SDK and browser renderer; it does not make GPU rendering available in Nod
