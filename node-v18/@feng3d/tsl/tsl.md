# @feng3d/tsl

> 标签: JavaScript

## 简介

feng3d引擎的着色器语言库，使用typescript编写着色器语言，并生成WebGL/WebGPU的着色器代码。

- 源码仓库：git+https://github.com/feng3d-labs/tsl.git
- npm 页面：https://www.npmjs.com/package/@feng3d/tsl
