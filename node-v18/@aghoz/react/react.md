# @aghoz/react

> 标签: eventsource, hooks, live-updates, polling, pubsub, push, react, react-hooks, real-time, realtime, server-push, server-sent-events, sse, streaming, tanstack-query, typescript, usetopic, websocket-alternative

## 简介

React hooks for Aghoz edge event streams — useTopic, useTopicReducer and a provider that reports replay gaps. Replaces refetchInterval polling.
