# @tickerbot/mcp-server

> 标签: ai, claude, mcp, model-context-protocol, signals, stocks, tickerbot

## 简介

MCP server for Tickerbot — the stock market, in SQL. Scan, replay, or subscribe across ~12,000 US tickers and top 100 cryptos (338+ signal columns) from Claude, ChatGPT, Cursor, and other MCP clients.
