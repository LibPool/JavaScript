# n8n-nodes-whm

> 标签: automation, cpanel, hosting, n8n, n8n-community-node-package, webhost-manager, whm

## 简介

n8n community node for cPanel & WHM (WebHost Manager). Manage accounts, packages, DNS zones, SSL, resellers, services, backups and cPanel-level email, databases, domains and FTP through the WHM API, plus a trigger for WHM hook events.
