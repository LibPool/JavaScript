# @tillstack/secrets-edge

> 标签: cloudflare, config, edge, secrets, tilldev, tillsecrets, vercel

## 简介

TillSecrets client for any edge runtime (Cloudflare Workers, Vercel Edge, Deno, Bun) — pull encrypted config over one authenticated fetch, zero Node built-ins.
