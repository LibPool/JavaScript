# @qitech/1pwd-proxy

> 标签: 1password, op-cli, postman, proxy, secrets

## 简介

Local HTTP proxy that resolves 1Password secret references (op://) via the 1Password CLI. Cross-platform autostart for Postman Community and similar tools.
