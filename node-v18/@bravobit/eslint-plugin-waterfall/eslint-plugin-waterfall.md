# @bravobit/eslint-plugin-waterfall

> 标签: css, eslint, eslint-plugin, eslintplugin, imports, line-length, scss, sort, waterfall

## 简介

ESLint plugin that sorts imports and CSS/SCSS declarations by line length, longest first — the waterfall.
