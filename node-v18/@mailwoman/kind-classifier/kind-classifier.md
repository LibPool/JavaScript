# @mailwoman/kind-classifier

> 标签: JavaScript

## 简介

Stage 2.5 of the runtime pipeline — categorize inputs by query shape (postcode_only / locality_only / structured_address / intersection / po_box / landmark / vague). Rule-based for v1.
