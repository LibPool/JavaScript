# @sovrahq/holder-core

> 标签: JavaScript

## 简介

Platform-agnostic core for a Sovra credential holder/wallet: SD-JWT VC handling, OpenID4VCI/VP protocol flows, credential storage, and P-256/EIP-712 crypto utilities.
