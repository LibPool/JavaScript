# @riga-solutions/sdk

> 标签: audit, client, hash-chain, records, rest, riga, sdk

## 简介

TypeScript SDK for the RIGA substrate. Typed client over the public REST API (/api/v1) — records, datarooms, tasks, documents, audit export, bytes-binding evidence — with built-in retry, error class hierarchy, and inline chain verification via @val-protoc
