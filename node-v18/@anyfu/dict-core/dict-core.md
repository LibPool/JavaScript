# @anyfu/dict-core

> 标签: dict, dictionary

## 简介

`@anyfu/dict-core`是一个用于字典数据请求合并、缓存、重试、降级、LRU 管理 的高性能工具，适用于后台配置字典、状态枚举、选项列表等场景。
