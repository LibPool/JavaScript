# @dui-toolkit/plugin-markdown

> 标签: ansi, cli, markdown, renderer, syntax-highlighting, terminal

## 简介

Markdown renderer plugin for @bdocs/dui — renderiza markdown con colores, tablas y código resaltado en la terminal
