# @pingidentity-developers-experience/ping-oidc-client-sdk

> 标签: IAM, Ping Identity, PingFederate, PingOne, SDK, oauth, oidc

## 简介

An OAuth/OIDC SDK to simplify and fast track integration with OAuth/OIDC protocol endpoints in SPAs (browser-based apps). AuthCode and implicit grant types. PKCE, state, userInfo, revoke, configurable logging, and token storage options.
