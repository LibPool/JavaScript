# @hymond/homebridge-protect-alarm

> 标签: alarm, alarm-triggered, breach, homebridge-plugin, homekit, protect, security-system, ubiquiti, udm, unifi, unifi-protect

## 简介

Bring your UniFi Protect alarm system into Apple HomeKit as a native Security System — Away, Night, Disarm, and Alarm Triggered — using a single UniFi OS API key. Arm profiles are discovered automatically. Zero runtime dependencies.
