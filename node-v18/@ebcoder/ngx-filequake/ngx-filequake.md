# @ebcoder/ngx-filequake

> 标签: angular, angular5, directive, drag, drag and drop, drop, dropzone, file upload

## 简介

This Angular 5+ directive can be used on any element (host) to create a "Drag N' Drop" zone for multi-file upload. Clicking the zone can also launch the browser's default FileOpen dialog based on configuration.
