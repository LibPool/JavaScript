# @tivility/dsh-readonly-auth

> 标签: auth, deepseek-harness, dsh-plugin, lan, readonly

## 简介

Owner lock for a DeepSeek Harness web deployment: unlocked visitors read, the owner drives. Provides the ownerAuth service.
