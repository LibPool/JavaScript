# @tivility/dsh-web-kit

> 标签: deepseek-harness, dns-rebinding, dsh-plugin, http, path-containment

## 简介

Shared HTTP building blocks for out-of-tree DeepSeek Harness web plugins: the browser-trust fence, path containment, root resolution, and a static response pipeline.
