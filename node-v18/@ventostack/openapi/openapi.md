# @ventostack/openapi

> 标签: JavaScript

## 简介

VentoStack 的 API 契约与文档工具，将 Router 元数据转换为 OpenAPI 3.1 文档和交互式文档页面。

- 官网：https://github.com/Ventorium/VentoStack#readme
- 源码仓库：git+https://github.com/Ventorium/VentoStack.git
- npm 页面：https://www.npmjs.com/package/@ventostack/openapi
