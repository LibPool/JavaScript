# @twoactualeyes/slipcast

> 标签: JavaScript

## 简介

Convert Figma components into framework component files (Astro + React/Next.js). Auto-detects framework from your package.json. Infers component contracts from Figma Component Properties (Text/Boolean/Instance-Swap/Variant). Reconciles re-runs via section
