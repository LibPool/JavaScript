# @h2loop/matlab-plugin

> 标签: hydron, hydron-plugin, mathworks, matlab, mcp, simulink

## 简介

MATLAB plugin for Hydron: sets up the official MathWorks MATLAB MCP server on Windows, Linux and macOS and adds a MATLAB coding skill
