# zagens-office

> 标签: cli, docx, office, pdf, pptx, presentation, spreadsheet, xlsx, zagens

## 简介

Local structured Office engine (PPTX / XLSX / DOCX / PDF): declarative JSON in, valid editable document out. Windows x64 prebuilt binary, no Office install required.
