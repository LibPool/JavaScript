# sonne-core

> 标签: anti-ban, antiban, baileys, bot, buttons, cleanup, group-cache, native-flow, rate-limiter, scheduler, session, sqlite, storage, whatsapp

## 简介

Toolkit profissional para bots de WhatsApp com Baileys: anti-ban realista, botoes nativos, agendador, filtros e persistencia SQLite. Modular, testado e pronto para producao.
