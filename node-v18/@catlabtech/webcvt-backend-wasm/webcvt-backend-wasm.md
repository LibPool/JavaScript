> 标签: browser, convert, ffmpeg, ffmpeg-wasm, file-conversion, typescript, wasm, webcvt

## 简介

FFmpeg.wasm fallback backend for webcvt — lazy-loaded, idle-reaped, strict allowlist (~180 MIME pairs).
