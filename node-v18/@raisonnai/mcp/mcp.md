# @raisonnai/mcp

> 标签: ai, art, catalogue-raisonne, mcp, model-context-protocol, provenance

## 简介

Raisonnai Connect — AI-native art catalogue MCP server. Catalogue works, parse provenance, track exhibitions, record sales, and generate signed Records of Art Identity (RAIs).
