# @cmdzero/react

> 标签: cmdzero, devtools, jsx, nextjs, source-maps

## 简介

Dev-time JSX source stamping for CmdZero — bundler-agnostic (Turbopack, webpack, Vite). Set jsxImportSource to "@cmdzero/react" and every rendered element knows its source file:line.
