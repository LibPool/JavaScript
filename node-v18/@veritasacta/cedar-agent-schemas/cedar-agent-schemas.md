# @veritasacta/cedar-agent-schemas

> 标签: agent-governance, authorization, cedar, cedar-policy, owasp-agentic, policy

## 简介

Canonical Cedar schema library for agent action verbs (exec, open, connect, request_tool). TypeScript helpers for constructing Cedar requests against the schema.
