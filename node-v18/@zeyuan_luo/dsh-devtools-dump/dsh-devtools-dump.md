# @zeyuan_luo/dsh-devtools-dump

> 标签: JavaScript

## 简介

Headless JSON/JSONL black-box dump consumer for @zeyuan_luo/dsh-devtools-core: writes the devtools snapshot and buffered trace on shutdown or on demand, crash-tolerant in stream mode
