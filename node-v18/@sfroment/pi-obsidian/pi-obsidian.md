# @sfroment/pi-obsidian

> 标签: cli, obsidian, pi-extension, pi-package, vault

## 简介

Pi extension for the Obsidian CLI — search, read, browse, and edit an Obsidian vault via a typed tool (direct CLI, not MCP).
