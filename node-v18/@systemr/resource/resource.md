# @systemr/resource

> 标签: ajax, angular, api, http, orm, rest

## 简介

ORM-like API library for RESTful communication in Angular. Inspired by EF Core, Eloquent, TypeORM, Swagger, and Yehuda Katz' JSON API Spec
