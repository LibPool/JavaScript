# @adonis-agora/payments-dashboard

> 标签: admin, adonis, adonisjs, agora, billing, console, dashboard, payments, subscriptions

## 简介

Billing console (revenue/subscription/usage overview, payment history, webhook-event ledger) for @adonis-agora/payments — a React SPA served by a thin AdonisJS provider. Part of the Agora ecosystem.
