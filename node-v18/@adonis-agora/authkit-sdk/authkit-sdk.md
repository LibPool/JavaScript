# @adonis-agora/authkit-sdk

> 标签: admin-api, adonisjs, authentication, authkit, oidc, sdk

## 简介

Backend SDK for the AuthKit Admin API with one typed interface and two drivers: remote (HTTP/Bearer) and embedded (in-process when the IdP runs in the same AdonisJS app).
