# @adonis-agora/authz-react

> 标签: adonis, adonisjs, agora, authorization, authz, inertia, rbac, react, tanstack-intent

## 简介

React/Inertia bindings for @adonis-agora/authz: AuthzProvider, useAuthz, useCan, <Can>, and a server-side buildAuthzShare() for the Inertia share.
