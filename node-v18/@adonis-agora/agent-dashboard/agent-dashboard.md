# @adonis-agora/agent-dashboard

> 标签: adonis, adonisjs, agent, agora, ai, dashboard, governance, react, spa, spend, tanstack-intent, usage

## 简介

Read-only governance console (spend by model/actor, usage trend, recent threads & tool calls, quota) for @adonis-agora/agent — a dependency-light React SPA served by a thin AdonisJS provider. Part of the Agora ecosystem.
