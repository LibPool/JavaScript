# @minimalui/core

> 标签: design, expo, minimal, react-native, ui

## 简介

Don't reinvent the wheel. Create beautiful React Native apps by using Minimal UI, a set of usable components for all your basic needs. Extends the existing ones, create your own theme and build new modern apps.
