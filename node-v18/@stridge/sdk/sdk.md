# @stridge/sdk

> 标签: JavaScript

## 简介

TypeScript client for the Stridge Gateway API. Used internally by [`@stridge/kit`](https://www.npmjs.com/package/@stridge/kit) and exposed for backend / server integrations that need direct API access.
