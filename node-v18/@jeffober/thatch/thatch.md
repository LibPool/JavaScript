# @jeffober/thatch

> 标签: claude-code, embeddings, mcp, mcp-server, memory, opencode, opencode-plugin, sqlite

## 简介

Persistent memory for AI coding agents — local embeddings, SQLite stores, zero config. Works with OpenCode (as a plugin), Claude Code (as an MCP server), and Cursor (as an MCP server).
