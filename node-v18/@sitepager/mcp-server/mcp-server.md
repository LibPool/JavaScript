# @sitepager/mcp-server

> 标签: broken-links, lighthouse, mcp, model-context-protocol, seo, sitepager, visual-regression

## 简介

MCP server for Sitepager, enabling repeatable website review workflows for visual changes, broken links, SEO metadata, and performance checks before updates go live.
