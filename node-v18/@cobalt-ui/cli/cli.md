> 标签: cli, css, design system, design tokens, design tokens community group, design tokens format module, dtcg, sass, style system, style tokens, typescript, w3c design tokens

## 简介

CLI for managing design tokens using the Design Tokens Community Group (DTCG) standard and generating code for any platform via plugins.
