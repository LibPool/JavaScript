# @pitchfork-ui/core

> 标签: a11y, accessibility, design-system, focus-trap, framework-agnostic, headless, pitchfork-ui, positioning, web-components

## 简介

Framework-free behaviour for Pitchfork UI — anchored positioning, focus trapping, outside-interaction dismissal, list navigation and accessibility helpers, with no dependency on any UI framework.
