# @pitchfork-ui/tokens

> 标签: css-variables, dark-mode, design-system, design-tokens, pitchfork-ui, style-dictionary, theming

## 简介

Design tokens for Pitchfork UI — colour, spacing, radii, typography, shadow and motion, built with Style Dictionary and shipped as CSS custom properties and JSON.
