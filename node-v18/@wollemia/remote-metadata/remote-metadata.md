# @wollemia/remote-metadata

> 标签: JavaScript

## 简介

Read‑only snapshot of [Cavuno's](https://cavuno.com) country and timezone metadata, exported as a single JSON file for use in any language (TS/JS, Python, Ruby, etc.).
