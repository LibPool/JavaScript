# @kookapp/webapp-hooks

> 标签: hooks, kook, react, shared, webapp

## 简介

KOOK webapp（host + 所有 PC Remote）专用的 React hooks 仓库。承接 webapp 端 _shared/hooks/ 60+ 个 hooks（useDebounce / useThrottle / useEventListener / useMount / useSize 等）。React 走消费方 MF shared（singleton）拿到的 host 实例。
