# @shiyishiwoa/elementui-theme

> 标签: element-ui, qiankun, scss, theme

## 简介

基于 SCSS 的 Element UI 皮肤扩展包。旨在解决微前端（qiankun）架构下，主系统与子系统之间自定义颜色按钮（Button）和标签（Tag）的样式同步问题。
