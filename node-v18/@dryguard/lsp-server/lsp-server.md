# @dryguard/lsp-server

> 标签: JavaScript

## 简介

DryGuard Language Server — one implementation of DRY-violation diagnostics and quick fixes for every LSP-capable editor (VS Code, Neovim, JetBrains via LSP4IJ, Sublime, Helix, Emacs, ...).
