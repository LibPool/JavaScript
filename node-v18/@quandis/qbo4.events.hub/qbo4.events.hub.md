# @quandis/qbo4.events.hub

> 标签: qbo

## 简介

The ASP.NET Core host. It composes every other project, owns the composite authentication scheme, maps the identity/admin endpoints, publishes the API documentation surface (OpenAPI, AsyncAPI, Arazzo, Swagger, Scalar), and serves the Lit admin SPA.
