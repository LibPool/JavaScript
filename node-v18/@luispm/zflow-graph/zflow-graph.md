# @luispm/zflow-graph

> 标签: canvas, diagram, edge, editor, flowchart, graph, interactive, no-code, node, react-flow-alternative, visual-programming, wasm, webgl, workflow

## 简介

WASM-powered node-edge graph editor + runtime. No framework. 100k nodes at 60fps. Built-in execution engine, Yjs multiplayer, WebGL renderer.
