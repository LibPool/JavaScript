# @nepali-date-picker/web-component

> 标签: angular, bikram-sambat, calendar, custom-element, date-picker, datepicker, lit, nepali, react, svelte, vue, web-component

## 简介

Framework-agnostic <nepali-date-picker> custom element: a Bikram Sambat (Nepali) calendar date picker that works in React, Vue, Angular, Svelte, and plain HTML.
