# @rivetts/adapter-fastify

> 标签: JavaScript

## 简介

`createFastifyAdapter({ logger?, bodyLimit?, cors?, rateLimit?, compression?, securityHeaders?, trustRequestId?, requestTimeoutMs?, onRequestComplete?, onRequestError? })` реализует HttpAdapter на Fastify. logger по умолчанию false. host по умолчанию 127.
