# @lemonyc/region-editor

> 标签: 2d, canvas, drawing, region-editor, vue3

## 简介

基于 Vue 3 的区域绘图编辑器，支持 Canvas 绘制直线/矩形，自动识别封闭区域并设置颜色和标签
