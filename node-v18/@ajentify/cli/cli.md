# @ajentify/cli

> 标签: agents, ai, ajentify, cli, deploy, iac, manifest

## 简介

CLI and programmatic API for deploying Ajentify stages from a declarative ajentify.json manifest. Inlines prompt files, Python tool code, and Zod schemas so each resource can be authored in its own file.
