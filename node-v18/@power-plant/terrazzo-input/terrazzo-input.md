# @power-plant/terrazzo-input

> 标签: design-tokens, dtcg, power-plant, power-plant-input, storm-software, terrazzo

## 简介

A Power Plant input for reading the source specification from a Design Tokens Community Group (DTCG) schema document and parsing it into a Design Tokens format using Terrazzo.
