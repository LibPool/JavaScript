# @smileid/usesmileid_bridge

> 标签: biometric, document-capture, expo, expo-module, face-detection, identity-verification, kyc, react-native, smile-id

## 简介

Shared ML abstractions for the UseSmileID React Native (Expo) SDK: data models, analyzer interfaces, the scan-state machine, and the native EXIF tagger bridge.
