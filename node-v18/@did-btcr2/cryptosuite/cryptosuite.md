# @did-btcr2/cryptosuite

> 标签: bip340, bitcoin, cryptosuite, data integrity, data integrity bip340, data integrity bip340 cryptosuite, decentralized identifiers, decentralized identity, did, did method, did:btcr2, dids, schnorr, schnorr signatures, secp256k1, secp256k1 keys

## 简介

W3C Data Integrity proof suite using BIP-340 Schnorr signatures over JCS-canonicalized documents. Creates and verifies bip340-jcs-2025 proofs for did:btcr2 DID updates.
