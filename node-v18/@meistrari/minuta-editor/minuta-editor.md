# @meistrari/minuta-editor

> 标签: JavaScript

## 简介

Editor de minuta do defesa.ai sem framework: folha A4 paginada, edição rica, placeholders de variável e export DOCX fiel ao preview — monta em qualquer app (React, Vue, vanilla)
