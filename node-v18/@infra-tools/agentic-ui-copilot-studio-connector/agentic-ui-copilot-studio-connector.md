# @infra-tools/agentic-ui-copilot-studio-connector

> 标签: JavaScript

## 简介

Microsoft Copilot Studio Connector adapter for the @infra-tools/agentic-ui platform. Translates Zod tool schemas into a Power Platform Connector OpenAPI 3 manifest, verifies inbound Azure AD JWTs, and dispatches action handlers with optional Adaptive Card
