# @dynamicsninja/garminconnect-mcp

> 标签: claude, garmin, garmin-connect, mcp, model-context-protocol, workouts

## 简介

MCP server for Garmin Connect: create workouts and read your Garmin data from Claude. Built on garminconnect-js.
