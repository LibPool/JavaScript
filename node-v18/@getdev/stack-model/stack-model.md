# @getdev/stack-model

> 标签: getdev, infrastructure, manifest, secret-scanning, stack, verify, wiring

## 简介

Parse and validate getdev.yml stack manifests, infer wiring, check state for credentials, evaluate consequence rules and lay out the stack tree. Pure functions, no I/O.
