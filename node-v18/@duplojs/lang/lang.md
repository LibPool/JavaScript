# @duplojs/lang

> 标签: array-utils, constrained-types, curry, data-checker, date-utils, duplojs, either-utils, functional-programming, immutable, lang, modeling-ddd, number-utils, object-utils, pattern-matching, pipe, string-utils, typescript

## 简介

Type-driven language layer for TypeScript: immutable, pipeable functions, Either, and constrained primitives.
