# @saccadejs/core

> 标签: eye tracking, gaze, jsPsych, saccade.js, webcam

## 简介

saccade.js core: webcam eye tracking in the browser (MediaPipe face landmarks → ONNX eye embedding → ridge calibration), with a screen-to-webcam timing loopback
