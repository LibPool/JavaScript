# @bridge-tools/rng-node-crypto

> 标签: JavaScript

## 简介

This contains the node-crypto RNG function to be used with [@bridge-tools/generator](https://github.com/aaron-hutton/bridge-tools/tree/main/packages/generator) and is part of the `@bridge-tools` suite of open-source bridge libraries written in Typescript.
