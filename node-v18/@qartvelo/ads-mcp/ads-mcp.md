# @qartvelo/ads-mcp

> 标签: admob, ads, ai-agents, android, mcp, model-context-protocol, qartvelo, react-native

## 简介

MCP server for Qartvelo Ads: search the developer docs, generate SDK integration code and send test-mode ad requests from AI agents.
