# @k-foss/ts-esnode

> 标签: environment, loader-hook, node, runtime, ts, typescript

## 简介

TS-ESNode is a Node.JS v13 Experimental loader hook for transpiling ESNext TypeScript to ESNext ESModule Node.JS Code on the fly
