# @minato-32/statement-notify

> 标签: cross-platform, in-app, indexeddb, notifications, offline, reactive, store, useSyncExternalStore, webview

## 简介

Cross-platform, reactive in-app notification store for web apps: a durable notification feed with injectable transport and storage that survives IndexedDB-stripped WebViews by falling back from a host key-value store to browser storage to memory.
