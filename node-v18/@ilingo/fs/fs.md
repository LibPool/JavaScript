# @ilingo/fs

> 标签: file-loader, filesystem, fs, i18n, ilingo, internationalization, lightweight, locale, node, server-side, translation, typescript

## 简介

File-system store adapter for ilingo — lazy-loads locale catalogs from disk and persists translations as JSON.
