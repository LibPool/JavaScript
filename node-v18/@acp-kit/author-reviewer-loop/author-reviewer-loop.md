# @acp-kit/author-reviewer-loop

> 标签: acp, acp-kit, agent-client-protocol, agent-runtime, author-reviewer-loop, codex, coding-agent, context-isolation, copilot, multi-agent, multi-agent-review, split-context

## 简介

Split-context ACP Kit demo: one AUTHOR agent writes files, one REVIEWER agent inspects them in a separate context, and the loop continues until APPROVED.
