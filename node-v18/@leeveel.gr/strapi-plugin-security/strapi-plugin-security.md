# @leeveel.gr/strapi-plugin-security

> 标签: IP intelligence, audit, clamav, firewall, mfa, plugin, rate limit, security, strapi, threat intelligence

## 简介

Self-hosted, all in-one, security plugin for Strapi 5: admin MFA, audit logging, application firewall, upload malware scanning, custom WAF rules, threat intelligence, IP intelligence, configurable rate limits.
