# @abiregistry/error-decoder

> 标签: abi, abiregistry, custom-error, decoder, error, ethereum, foundry, revert, solidity, viem

## 简介

Decode Solidity custom errors from revert data. Extracts errors from Foundry/Hardhat artifacts, builds a fast selector registry, and produces human-readable output.
