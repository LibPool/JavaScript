# @etoe/webhooks

> 标签: JavaScript

## 简介

Etoe webhook delivery core — per-product endpoint registration, HMAC-SHA-256 signing, at-least-once delivery with exponential backoff, and a dead-letter queue for permanently failed deliveries. Zero runtime dependencies.
