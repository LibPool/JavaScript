# @etoe/sdk-node

> 标签: JavaScript

## 简介

Etoe Node/Electron SDK — E2EE client wrapping libsignal-protocol via Signal Foundation's audited N-API binding. The browser-target SDK lives in @etoe/sdk-web; cross-platform interop is guaranteed because both packages share @etoe/crypto-core-libsignal.
