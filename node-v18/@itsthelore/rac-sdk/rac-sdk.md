# @itsthelore/rac-sdk

> 标签: rac, requirements-as-code, sdk, validation

## 简介

Thin TypeScript client for RAC (requirements-as-code): typed access to the rac CLI's JSON contracts. Shells out to the installed rac binary; it never reimplements the engine (ADR-063).
