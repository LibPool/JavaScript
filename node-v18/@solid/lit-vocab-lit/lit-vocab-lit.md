# @solid/lit-vocab-lit

> 标签: JavaScript

## 简介

Bundle of vocabularies that includes the following:

  lit_core: The LIT Core Ontology. The LIT is intended to be a collection of utility libraries to ease the
 adoption of RDF for developers.

  lit_consent: Consent vocabulary defining LIT-specific terms
