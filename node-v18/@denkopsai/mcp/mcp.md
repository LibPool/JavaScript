# @denkopsai/mcp

> 标签: agent, denkops, deploy, mcp, model-context-protocol, stdio

## 简介

DenkOps MCP server (stdio) — deploy and operate micro-APIs on DenkOps from any MCP-capable agent (Codex, OpenClaw, Hermes, …). Requires DENKOPS_TOKEN (from the DenkOps dashboard → Connect) and DENKOPS_CONTROL_PLANE_URL.
