# @light0x00/qichacha-tool

> 标签: JavaScript

## 简介

基于 selenium 的自动操作工具, 可代替人工收集企查查上的企业数据, 输入一个含有若干公司名称的 Excel , 输出一个包含这些公司信息的Excel. (目前只收集了企业信用代码,但是只需稍加更改代码,即可收集其他信息)
