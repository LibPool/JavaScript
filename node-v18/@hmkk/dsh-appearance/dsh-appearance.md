# @hmkk/dsh-appearance

> 标签: deepseek-harness, dsh, dsh-plugin, font, theme

## 简介

轻量的 DSH 字体与主题插件：中英文字体分开选（只列本机已安装的），5 套官方色板预设（含代码块语法高亮），零依赖、零构建。
