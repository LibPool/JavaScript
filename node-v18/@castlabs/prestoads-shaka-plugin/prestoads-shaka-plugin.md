# @castlabs/prestoads-shaka-plugin

> 标签: JavaScript

## 简介

Adapts a [Shaka Player](https://github.com/shaka-project/shaka-player) for PRESTOads, so ad playback events are derived from the player rather than reported by hand. DASH `EventStream` and HLS `EXT-X-DATERANGE` breaks are scheduled off the media timeline;
