# @freikim/ng-input-number-i18n

> 标签: angular, angular18, decimal, directive, input, number, numbers, textarea

## 简介

Angular 20 compatible version of @danielzotti/ng-input-number-i18n. It's a special directive to format decimal numbers inside input and textarea, based on the current locale
