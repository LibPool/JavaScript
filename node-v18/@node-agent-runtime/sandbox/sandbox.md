# @node-agent-runtime/sandbox

> 标签: agent, node-agent-runtime, permissions, sandbox, security

## 简介

C4 sandbox package of the Agent runtime: run-level execution boundary — SandboxMode tiers, SandboxScope and the in-process LocalSandbox (path/network/time enforcement, sandbox:write visibility). Depends only on @node-agent-runtime/types.
