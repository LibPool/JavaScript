# @node-agent-runtime/types

> 标签: agent, contracts, json-schema, node-agent-runtime, types

## 简介

C1 shared leaf package of the Agent runtime: message/tool-call contracts, JSON Schema subset validator and zero-IO pure helpers. No internal dependencies.
