# @openweather/maps-ui-core

> 标签: maps, openweather, view-model, weather

## 简介

Framework-agnostic weather map UI view-models: legend, timeline, layer rail, overlays, point query, search flow — pure functions and stores consumed by both a DOM and a React renderer
