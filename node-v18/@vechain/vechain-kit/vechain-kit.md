# @vechain/vechain-kit

> 标签: blockchain, cross-app, dapp, ecosystem, embedded-wallet, login, nextjs, privy, react, smart-account, social, sync2, typescript, vechain, vechain-kit, vechain-thor, veworld, wallet, walletconnect, web3

## 简介

All-in-one React library for building VeChain applications with wallet integration, social logins, developer hooks, and pre-built UI components.
