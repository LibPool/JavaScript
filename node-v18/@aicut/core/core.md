# @aicut/core

> 标签: ai-relighting, canvas, capcut, component, davinci, editor, ffmpeg, filmora, final-cut, framework-agnostic, imovie, lighting, mp4, nle, premiere, three.js, timeline, timeline-editor, veed, video, video-clip, video-cutter, video-editing, video-editor

## 简介

Framework-agnostic core for the AiCut video editor — canvas timeline, data model, pluggable PlaybackEngine (HTML5 / Canvas / WebCodecs), plus opt-in 3D lighting picker.
