# @whorlid/whorlid

> 标签: bot-detection, browser-fingerprint, canvas-fingerprint, device-fingerprint, fingerprint, fingerprinting, fraud-detection, identification, visitor-id

## 简介

Open-source browser fingerprinting. Works offline with no backend, or connects to the WhorlID API for server-side device matching.
