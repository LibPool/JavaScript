# @pattonwebz/axe-a11y-report

> 标签: a11y, accessibility, axe-core, personas, report, wcag

## 简介

Turn axe-core JSON results into a Markdown or a polished self-contained HTML accessibility report, with optional GOV.UK/GDS persona-mapped findings. Framework-agnostic — library or CLI, GitHub Actions or anywhere else.
