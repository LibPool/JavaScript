# @quantech-services/twap-plugin

> 标签: algorithmic-execution, defi, orderly, orderly-network, perpetuals, trading, twap

## 简介

TWAP algorithmic execution for Orderly Network — taker and maker order entry with scheduled slicing. Shared markets only; broker-exclusive markets are not supported.
