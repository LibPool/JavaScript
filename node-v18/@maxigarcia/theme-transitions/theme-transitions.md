# @maxigarcia/theme-transitions

> 标签: css, dark mode, dark theme, javascript, library, light mode, light theme, theme, transition, utility, view transitions, view transitions api, web

## 简介

Lightweight, CSS-first theme transitions for the web. Wrap your theme change in the [View Transitions API](https://developer.mozilla.org/en-US/docs/Web/API/View_Transitions_API) and reveal the new theme with a **circular**, **sweep**, **fall**, or **page
