# @antoniocorraliza/foundry-cli

> 标签: angular, angular-19, cli, code-generation, enterprise-architecture, foundry-suite, scaffolding, signals, standalone-components, state-management

## 简介

The official command line interface for Foundry suite. Automates the generation of Angular 19 standalone components, local signal stores, and enterprise application scaffolding with zero dependencies.
