# @relaystacks/conduit-echo

> 标签: broadcasting, conduit, cpanel, laravel, laravel-echo, passenger, relaystacks, socket.io, unix-socket

## 简介

Passenger-compatible Node.js server for the Conduit ecosystem. Receives Laravel broadcasts over a Unix socket and delivers them to browsers via Socket.IO with Laravel Echo compatibility.
