# @npm-safe/core

> 标签: cli, dependency-scanner, llm, malware-detection, npm, scanner, security, static-analysis, supply-chain, tarball

## 简介

Local-first npm supply-chain scanner with metadata checks, bounded tarball inspection, CI gates, SQLite cache, and optional LLM analysis.
