# localelens

> 标签: devtools, i18n, localization, next-intl, nextjs, react, react-i18next, translations, vite

## 简介

CLI for LocaleLens: click text in your dev app to edit translations or extract hardcoded strings (React, Vite, Next.js). Personal project, provided as-is.
