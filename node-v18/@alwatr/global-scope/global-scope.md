# @alwatr/global-scope

> 标签: ECMAScript, alwatr, browser, cross-platform, esm, global, global-polyfill, global-shim, globalThis, globalThis-polyfill, globalThis-shim, javascript, module, nanolib, node, nodejs, typescript, util, utility, utils

## 简介

This TypeScript module provides a cross-platform alternative to `globalThis` named `globalScope`. This object works across different environments, including browsers (`window`), Node.js (`global`), and Web Workers (`self`).
