# @arc-lang/arc-search

> 标签: algolia, arc, bm25, fts5, full-text, meilisearch, search, sqlite

## 简介

Zero-dependency, SQLite FTS5-powered full-text search for Arc apps. BM25 ranking, prefix matching, highlighted excerpts.
