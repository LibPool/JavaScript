# @pithagoras/inline-ui

> 标签: generative-ui, interactive, pi-package, pithagoras, ui

## 简介

Inline UI for Pithagoras: the agent shows the person an interactive card of its own HTML in the chat, sandboxed and with no network, and what the person does in it comes back to the agent as events
