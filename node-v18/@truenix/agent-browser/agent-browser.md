# @truenix/agent-browser

> 标签: ai-agents, anti-detection, bot-detection, browser, cdp, chrome-devtools-protocol, cordis, dsh, fingerprint, headless-chrome, markdown, mcp, model-context-protocol, stealth, web-scraping, zero-dependency

## 简介

A hardened local browser for AI agents. Zero-dependency CDP client, CLI, MCP server and DSH/Cordis plugin. Clears standard bot-detection fingerprint checks; token-efficient Markdown extraction.
