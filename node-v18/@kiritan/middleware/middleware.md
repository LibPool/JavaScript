# @kiritan/middleware

> 标签: i18n, kiritan, machine-translation, middleware, translate, translation

## 简介

A layer that turns any translate function into a Kiritan translate middleware / 任意の翻訳関数をKiritanの翻訳ミドルウェアにする中間層
