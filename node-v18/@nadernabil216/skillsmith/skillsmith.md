# @nadernabil216/skillsmith

> 标签: agent, agent-skills, ai, claude, cli, llm, skill-library, skills

## 简介

skillsmith — a tool that carries a catalog of reusable AI-agent skills and installs any of them into the CLI agent you're using through a single line. One catalog, any agent (Claude, Codex, Gemini, Kimi, GLM, opencode), versioned and kept in sync.
