# @delkaos/solar-wallet_italian-plugin

> 标签: @arkecosystem, @solar-network, desktop-wallet, italian, language, plugin, translations

## 简介

Un plugin per tradurre Solar Desktop Wallet in italiano. Dopo aver installato il plugin, seleziona la lingua italiana dalle impostazioni del profilo.
