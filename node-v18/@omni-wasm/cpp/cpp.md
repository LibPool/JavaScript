# @omni-wasm/cpp

> 标签: browser, c++, c++23, clang, compiler, cpp, llvm, no-server, wasm, webassembly

## 简介

Browser-native C++23 compiler & runtime via Clang 23 WASM (LLVM 22.1.2 + 18 C++23 patches). No server required.
