# @summerisgood/paseo-next-check

> 标签: agents, paseo, paseo-plugin, productivity, unread

## 简介

Open the oldest unread agent reply across Paseo workspaces, with a native workspace Mark as unread shortcut and a Code review pill that triages native review findings.
