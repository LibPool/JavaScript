# @fish-under-sea/dsh-approval-guide

> 标签: approval, chinese, dsh, dsh-plugin, sandbox

## 简介

在 DSH Web GUI 的审批弹窗里追加中文说明：这次审批会做什么、有什么风险、依据是什么。原英文理由与命令原文保留显示。
