# @katok-mcp/loco-engine

> 标签: kakao, kakaotalk, loco, protocol

## 简介

@katok-mcp/loco-engine — KakaoTalk LOCO protocol engine (RSA + AES-128-CFB, Android auth, TCP persistent connection). Used by @katok-mcp/mcp-server.
