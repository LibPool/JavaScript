# @jsm-mit/chat-sharded-package

> 标签: JavaScript

## 简介

Wrapper TypeScript package for the chat group (coordinator, core, workers): projects, rooms, multi-party chats, messages and a poller for agent hosts. Takes the coordinator's id and finds the canister of every call.
