# @jsm-mit/chat-agent-package

> 标签: agent, chat, llm

## 简介

Agent framework: a configurable LLM-driven Agent class plus message-bus agent types (personal assistant, summarist, marketing), with a persistent CLI sandbox game for testing personas.
