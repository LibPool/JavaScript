# @jsm-mit/sultana-assets-rust-package

> 标签: JavaScript

## 简介

Wrapper TypeScript package for the sultana-assets-rust canister: chunked and single-shot uploads, salon images and transcoding reservations, the worker upload path, reads and asset URLs.
