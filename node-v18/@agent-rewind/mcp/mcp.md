# @agent-rewind/mcp

> 标签: ai-agents, checkpoint, claude-code, cursor, llm-proxy, mcp, model-context-protocol, rewind

## 简介

Rewind CLI + stdio MCP server: whole-workspace checkpoint/rewind, a refuse-and-record effect barrier on a tamper-evident chain, and a token-saving record/replay proxy — for Claude Code, Cursor, and Codex CLI. Run with `npx @agent-rewind/mcp`.
