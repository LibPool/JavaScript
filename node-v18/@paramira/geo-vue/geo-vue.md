# @paramira/geo-vue

> 标签: geo, map, paramira, svg, vue

## 简介

Vue SVG maps on @paramira/geo, with no tile server: a fitted, pannable, zoomable (wheel, drag, pinch) <GeoMap> and layers for regions (with agreement styling), pins, great-circle paths, flows sized by count, and count bubbles.
