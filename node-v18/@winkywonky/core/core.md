# @winkywonky/core

> 标签: accessibility, animation, framework-agnostic, gestures, headless, physics, spring, synthesized-audio, web-audio

## 简介

Headless physics engine for winky-wonky: one spring/damper implementation, pointer-drag gestures, synthesized UI audio, and prefers-reduced-motion/-sound/pointer helpers. Zero dependencies, SSR-safe, framework-agnostic.
