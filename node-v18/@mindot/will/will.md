# @mindot/will

> 标签: agent, ai, ai-agents, autonomous-agent, cognitive-architecture, deterministic, generative-agents, llm, mind, npc, persistent-memory, simulation

## 简介

Will — an engine for persistent machine minds. A Will is a continuously-ticking synthetic mind built from 38 cognitive faculties, a learning agency pipeline, and a dual-process executive — deterministic, persistent, and portable (PMA).
