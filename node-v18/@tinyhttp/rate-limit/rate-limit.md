# @tinyhttp/rate-limit

> 标签: attack, brute, brute-force, bruteforce, force, ip, limit, middleware, rate, rate-limit, ratelimit, security, tinyhttp-rate-limit, tinyttp

## 简介

Basic IP rate-limiting middleware for tinyhttp. Use to limit repeated requests to public APIs and/or endpoints such as password reset.
