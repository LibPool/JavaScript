# @waukeshamakerspace/react-components

> 标签: avatar, components, design-system, react, shadcn, spinner, tailwind, theme-toggle, ui-primitives, waukesha-makerspace

## 简介

Shared Waukesha Makerspace component library: shadcn-based UI primitives themed on design-tokens semantic variables (Tailwind v4 consumers), plus brand widgets (theme toggle, avatar, branded spinner) that work in any WMI UI stack
