# @waukeshamakerspace/auth-kit

> 标签: authentication, bff, keymaster, oidc, waukesha-makerspace

## 简介

Keymaster OIDC Backend-For-Frontend for Waukesha Makerspace services: discovery, PKCE, code exchange, id_token verification, and the signed session cookie. The SPA never sees a token.
