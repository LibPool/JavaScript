# @caribeng/ui

> 标签: angular, caribeng, component library, design, framework, frontend, ui library

## 简介

CaribeNG — sistema de diseño y librería de componentes para Angular 22+ (standalone, signals, OnPush, zoneless). 152 entry points tree-shakeables, accesibles (WCAG 2.2 AA) y tematizables.
