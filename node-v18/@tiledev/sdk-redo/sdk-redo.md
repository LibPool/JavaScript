# @tiledev/sdk-redo

> 标签: cart, package-protection, react-native, redo, returns, shopify, tile, tilepacket

## 简介

Redo coverage (free returns / package protection) for Tile apps on @tiledev/sdk-shopify: asks Redo for the cart's coverage, keeps exactly one Redo line when the shopper chooses cover, and keeps it right as the cart changes. Headless: no UI.
