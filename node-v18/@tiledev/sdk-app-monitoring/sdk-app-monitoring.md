# @tiledev/sdk-app-monitoring

> 标签: crash-reporting, error-boundary, expo, logrocket, react-native, sentry, session-replay, tile, tilepacket

## 简介

Crash reporting (Sentry), session replay (LogRocket), one captureError/captureWarning seam and a root ErrorBoundary for TilePacket apps. Real on iOS/Android release builds, console-only on web and in development.
