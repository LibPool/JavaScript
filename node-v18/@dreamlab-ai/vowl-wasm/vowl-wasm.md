# @dreamlab-ai/vowl-wasm

> 标签: graph, ontology, owl, visualisation, wasm

## 简介

VOWL ontology visualisation engine in Rust/WASM: OWL parsing, force-directed layout (Barnes-Hut, SIMD), and rendering data for web explorers. A clean-room reimplementation of the WebVOWL visual notation.
