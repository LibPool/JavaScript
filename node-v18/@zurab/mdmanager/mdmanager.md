# @zurab/mdmanager

> 标签: JavaScript

## 简介

MDManager — Nx-плагин и CLI для сборки распределённых *.ai.md в единый markdown/PDF/HTML/DOCX-паспорт с группировкой, фильтрами и валидацией frontmatter через JSON Schema
