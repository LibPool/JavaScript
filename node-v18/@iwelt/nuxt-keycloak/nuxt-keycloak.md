# @iwelt/nuxt-keycloak

> 标签: JavaScript

## 简介

This module exposes a wrapper around the official [Keycloak Javascript adapter](https://www.keycloak.org/docs/latest/securing_apps/index.html#_javascript_adapter) to make it work together with Nuxt (3).
