# dsh-session-toolbox

> 标签: deepseek-harness, draft-vault, dsh-plugin, session-move, trash-bin

## 简介

图片草稿保险箱、项目分组与会话迁移、归档池、文件检查点恢复、多引用回复、后续任务联想。第三方插件，数据只存本机。
