# @ephemushroom/opencode-hermes

> 标签: claude-code, context-injection, gateway, hermes, opencode, plugin

## 简介

OpenCode plugin that reports Claude Code-style context (environment, scratchpad, git status) as x-hermes-* request headers for gateway-side injection
