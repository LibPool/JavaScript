# @cocodintech/phonegap-plugin-barcodescanner

> 标签: cordova-android, cordova-browser, cordova-ios, cordova-windows, cordova:plugin, ecosystem:cordova, ecosystem:phonegap

## 简介

BarcodeScanner plugin is a fork of the original phonegap-plugin-barcodescanner, adapted for cordova-android 12.0.0. It allows scanning various barcode types using the device's camera and extracting encoded metadata for in-app processing.
