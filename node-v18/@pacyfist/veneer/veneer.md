# @pacyfist/veneer

> 标签: angular, anti-scraping, font, obfuscation, opentype, scraping

## 简介

Angular directives that scramble text in the DOM and render it correctly with a font generated at runtime, so scrapers, scripts and copy-paste get gibberish.
