# @sourenpash/agenttree

> 标签: agents, ai, causal-memory, cli, coding-agent, graph, llm, local-first, mcp, memory

## 简介

Local-first causal-memory CLI for humans and AI coding agents. Records tasks, attempts, and outcomes to an append-only .agenttree/ log so agents stop repeating failed work.
