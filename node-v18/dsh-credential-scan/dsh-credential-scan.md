# dsh-credential-scan

> 标签: credential, credential-scan, dsh, entropy, jwt, leak, plugin, scan, secret, token

## 简介

Credential scanning for DeepSeek Harness: detect AWS keys, GitHub tokens, private keys, JWTs, Slack/Stripe/Google/SendGrid/Discord tokens and generic API keys in text or recursively in a directory tree; entropy-based checks. Output is always masked — neve
