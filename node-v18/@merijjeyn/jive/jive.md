# @merijjeyn/jive

> 标签: agent, anthropic, bun, cli, graph, llm, openai, openrouter, terminal, tui

## 简介

A terminal coding agent that plans work as executable graphs: bash commands and bounded model decisions run locally as branches, loops, and parallel batches between planner turns.
