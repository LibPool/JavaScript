# opencode-usage-limit

> 标签: gauge, limit, opencode, plugin, rate-limit, tui, usage

## 简介

OpenCode plugin that shows today's remaining usage limit as a sidebar gauge, tracks 429 rate limits, and provides a /usage dashboard
