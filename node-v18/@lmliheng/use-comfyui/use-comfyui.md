# @lmliheng/use-comfyui

> 标签: adelie, aigc, comfyui, image-generation, plugin

## 简介

Install ComfyUI on a machine where Adelie owns the only exposed port, serve its UI and API through an Adelie workflow reverse proxy, point it at the model weights already on disk, and verify a real render end to end.
