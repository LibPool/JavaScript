# @json-express/cli

> 标签: api-generator, backend-framework, cli, command-line, developer-tools, graphql, headless-cms, json-express, jsonexpress, mock-api, nodejs, rest-api, scaffolding, typescript

## 简介

Developer workflow utility for JSON Express (scaffold projects, export collections to typed models). The server itself runs via the json-express binary shipped by @json-express/core.
