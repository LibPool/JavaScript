# @ldtdev/qa-system

> 标签: ai-testing, claude-code, experience-library, multi-agent, playwright, qa, self-healing, strategy-evolution, testing

## 简介

Self-learning QA framework for frontend apps. Detect conventions, generate tests (via Claude Code CLI), validate, execute, self-heal, learn, evolve strategy.
