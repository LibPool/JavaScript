# @tomo-inc/wlfi-wallet-connect-kit

> 标签: JavaScript

## 简介

A lightweight React SDK to integrate crypto wallet connection into your app. It ships with a configurable wallet list modal and basic account actions. The current focus is EVM, built on top of `@tomo-inc/wallet-adaptor-base`, and supports custom wallets a
