# @wazobiatech/shared-database

> 标签: JavaScript

## 简介

Shared Prisma schema and generated client for the Postgres database used by broker-service and arke. broker-service remains the sole owner of migrations -- this package only ships the schema and a ready-to-use, pre-compiled client.
