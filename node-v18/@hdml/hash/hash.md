# @hdml/hash

> 标签: JavaScript

## 简介

`@hdml/hash` is a lightweight utility library designed for hashing and generating unique identifiers. It provides various functions to handle hashing and timestamp-related operations, making it ideal for applications that require unique and consistent ide
