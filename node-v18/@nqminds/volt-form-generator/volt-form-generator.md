# @nqminds/volt-form-generator

> 标签: JavaScript

## 简介

A React package for building **online or offline collaborative**, **Yjs-synced** forms based on YAML || JSON Schema, with pluggable view metaphors (wizard, typeform, GDS) and a results dashboard.
