# @crvouga/mockingbird-service-aws-iot

> 标签: aws, aws-iot, iot-core, mockingbird, mqtt, mqtt5, service, sigv4

## 简介

Stateful emulator of the AWS IoT Core data plane: SigV4-signed HTTP Publish and the MQTT 5 message broker over TCP and WebSocket, with custom-authorizer policies and persistent sessions.
