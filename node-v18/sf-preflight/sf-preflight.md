# sf-preflight

> 标签: agentforce, apex, ci, devops, flows, impact-analysis, mcp, order-of-execution, salesforce, sfdx, static-analysis

## 简介

Preflight checks for Salesforce changes: follows a git diff through flows, triggers, validation rules, roll-ups and permissions to show what it will set off before it ships.
