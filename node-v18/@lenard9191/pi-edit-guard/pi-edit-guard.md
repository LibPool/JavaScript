> 标签: agent-harness, ai-agent, ai-coding-assistant, checkpoints, coding-agent, compare-and-swap, developer-tools, guardrails, llm, loop-detection, pi, pi-coding-agent, pi-extension, pi-package, pi-skill, revert, rollback, snapshots, stale-read, undo

## 简介

Pi (π) coding-agent extension: blocks edits to files that changed since the agent read them, snapshots the project before each run so /undo restores it exactly, and stops repeated identical tool calls.
