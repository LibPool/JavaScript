# @dtst/img

> 标签: agent, image-editing, image-generation, mcp, model-context-protocol, openai, openrouter

## 简介

MCP server for generating and editing images through any OpenAI-compatible API (OpenAI, OpenRouter, LiteLLM, local). Saves to the paths the agent asks for.
