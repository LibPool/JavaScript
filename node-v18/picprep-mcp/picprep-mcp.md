# picprep-mcp

> 标签: assistant, mcp, model-context-protocol, photos, picprep

## 简介

Connect any MCP assistant (Claude Code, Codex, Cursor, Antigravity, Devin CLI, OpenCode and others) to the PicPrep desktop app on your computer.
