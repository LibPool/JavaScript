# cc-readback

> 标签: claude, claude-code, claude-desktop, mcp, mcp-server, read-only, session-history

## 简介

Read-only, local MCP server that lets Claude Desktop and Claude Code read your Claude Code session history as redacted, token-budgeted digests.
