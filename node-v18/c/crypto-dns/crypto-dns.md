# crypto-dns

> 标签: bitcoin, blockchain, crypto, crypto-dns, cryptography, dns, dnssec, domain, encryption, ethereum, identity, security, wallet

## 简介

This packages translates domain names into crypto wallet addresses, using standard TXT records set by the DNS.
