# cloud-foundry-service-discovery

> 标签: axios, cloud-foundry, eureka, http, service-discovery, service-registry

## 简介

Axios based cloud foundry service discovery client for node.js. Enable nodejs application dynamically discover and call other regiesterd apps through cloud foundry service registry
