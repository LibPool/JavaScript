# chadware

> 标签: architecture, chad, configurancy, formal, fowler, methods, phoenix, verification

## 简介

chad (Claims, Artifacts, Harness, Drills): referee-and-ledger CLI for Chad Fowler's Phoenix architecture. Audits the evidence a system needs to regenerate from spec and keeps humans aligned with the codebase through configurancy and verification.
