# chunklet

> 标签: chunk, chunking, code, embeddings, html, llm, markdown, rag, retrieval, semantic-search, text-splitter, tokens

## 简介

Token-aware, structure-aware text chunking for RAG - exact source offsets, sentence, markdown, code and HTML modes, pluggable tokenizer, zero dependencies.
