# claude-code-map

> 标签: ai, claude, claude-code, codebase, codemap, context, index, tokens, tree-sitter

## 简介

Pre-index your codebase so Claude Code skips the exploration phase. Tree-sitter AST extraction, static markdown output, delta-aware regeneration.
