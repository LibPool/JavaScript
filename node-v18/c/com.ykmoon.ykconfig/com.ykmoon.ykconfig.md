# com.ykmoon.ykconfig

> 标签: core, lib, ykmoon

## 简介

YKConfig Library.
用来支持YKConfig。
记得要设置要Project Settings/YKConfig/Settings内的参数。
使用方式
1.TableConvert生成表数据和代码
2.调用YKConfig.ConfigCenter.Inittable来初始化。
3.YKConfig.表名.Get(ID)就可以获得对应ID的表数据了。
