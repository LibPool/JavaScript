# codebeamer-mcp-wiki

> 标签: alm, attachments, claude, codebeamer, custom-field, mcp, model-context-protocol, wiki-format

## 简介

MCP server for Codebeamer ALM with read and write capabilities, enhanced with Wiki format support (when creating or updating items) , custom field support (when creating or updating items) and attachments management (uploading, downloading, updating).
