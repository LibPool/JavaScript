# cortexai

> 标签: ai, api, chat, claude, deepseek, llama, llm, openai, sdk, typescript

## 简介

A lightweight TypeScript SDK for interacting with a multi-model OpenAI-compatible API, including Claude 3.5, LLaMA, and DeepSeek.
