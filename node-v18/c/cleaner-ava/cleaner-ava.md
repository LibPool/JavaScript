# cleaner-ava

> 标签: JavaScript

## 简介

Runs [ava](https://github.com/avajs/ava) but adds ability to retry, annotations so that the tests are picked up in github ci, and a helpful summary at the end with the test files that broke via [github annotations](https://docs.github.com/en/actions/using
