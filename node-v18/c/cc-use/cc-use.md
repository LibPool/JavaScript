# cc-use

> 标签: anthropic, anthropic-api, anthropic-compatible, claude, claude-code, claude-code-cli, cli, deepseek, developer-tools, glm, kimi, launcher, openrouter, qwen, volcengine

## 简介

Launch Claude Code with third-party Anthropic-compatible providers (DeepSeek, Kimi, GLM, Qwen, Volcengine, OpenRouter…). Shared native ~/.claude/ context by default; use `cc-use isolate` for per-profile isolated sessions.
