# claude-hub-lane

> 标签: agent, ai, claude, claude-code, cli, multi-agent, orchestration, skill, worktree

## 简介

Run many Claude Code sessions as one team: a hub session owns architecture and review, lane sessions implement in their own worktrees, over native cross-session messaging.
