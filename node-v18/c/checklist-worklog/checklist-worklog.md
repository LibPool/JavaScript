# checklist-worklog

> 标签: checklist, claude, claude-code, developer-tools, engineering-report, extension, pdf, plugin, worklog

## 简介

Claude Code extension that generates professional Development Checklists, Worklogs, progress tracking and daily engineering reports — with optional background tracking and multi-format export (PDF/Markdown/DOCX/HTML).
