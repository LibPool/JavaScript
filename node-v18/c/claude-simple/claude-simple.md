# claude-simple

> 标签: JavaScript

## 简介

A lightweight web UI for **Claude Code**, **OpenAI Codex**, **Grok**, **Google Gemini** (via `agy`), and **Cursor Agent**. No build step — pure ES Modules in the browser.
