# commerce-token-mcp

> 标签: JavaScript

## 简介

이 MCP 서버는 커머스 채널의 accessToken을 안전하게 조회해주는 서비스입니다. 외부망 API 호출 없이 Redash를 통해 DB에서 직접 accessToken을 조회합니다.
