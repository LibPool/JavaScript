# crustyimg-wasm

> 标签: avif, browser, client-side, convert, image, jpeg, optimize, png, resize, sharp-alternative, svg, wasm, webassembly, webp

## 简介

Resize, convert, and optimize images in the browser — the crustyimg engine compiled to WebAssembly. No native addon, no postinstall build, no server.
