# csv-stream-lite

> 标签: async, browser, csv, csv-parse, csv-parser, csv-stream, csv-stringify, csv-to-json, incremental, large-files, lightweight, low-memory, memory-efficient, nodejs, parse, parser, stream, streaming, streaming-csv, stringify, typescript, zero-dependencies

## 简介

A lightweight, memory-efficient, zero-dependency streaming CSV parser and stringifier for JavaScript and TypeScript. It works in both Node.js and browser environments.
