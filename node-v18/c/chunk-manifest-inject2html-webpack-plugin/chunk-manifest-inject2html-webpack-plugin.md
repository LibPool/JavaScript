# chunk-manifest-inject2html-webpack-plugin

> 标签: chunk, manifest, plugin, webpack

## 简介

Allows exporting a manifest that maps chunk ids to their output files, instead of keeping the mapping inside the webpack bootstrap. And can auto inject manifest json to html if you use html-webpack-plugin.
