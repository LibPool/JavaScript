# create-ether-dapp

> 标签: ethereum, ethers, hardhat, react, typescript, web3

## 简介

A template for building Full-Stack Blockchain Dapps using Next.js (React), TypeScript, Tailwind CSS, Hardhat, Solidity, and many more!
