# cloud9-cucumber

> 标签: JavaScript

## 简介

Cucumber plugin for Cloud9. It provide autocompletion of steps and tags and higlighting (I used syntax highlighters for Gherkin source https://github.com/cucumber/gherkin-syntax-highlighters).
