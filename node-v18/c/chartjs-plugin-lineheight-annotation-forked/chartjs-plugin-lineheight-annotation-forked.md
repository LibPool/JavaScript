# chartjs-plugin-lineheight-annotation-forked

> 标签: chartjs, chartjs-plugin, line chart plugin, react-chartjs, react-chartjs-2

## 简介

A ChartJS annotation plugin for Line charts. It creates a line from the base of the graph to the highest datapoint. Easy to style.
