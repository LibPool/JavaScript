# cellstate

> 标签: ansi, cellstate, cli, console, emoji, flexbox, ink-alternative, llm, markdown, nodejs, react, renderer, streaming, terminal, tui, typescript, unicode, yoga

## 简介

React terminal renderer with cell-level diffing, double-buffered rendering, and native scrollback. No alternate screen.
