# chava-permissions

> 标签: acl, authorization, chavajs, laravel, permissions, rbac, roles, spatie, wildcard-permissions

## 简介

Roles & permissions for JavaScript — Spatie Laravel Permission API parity (givePermissionTo, assignRole, syncPermissions, wildcards, guards) with O(1) lookups, zero dependencies, and adapters for memory/file/SQL. First-class chavaJs integration.
