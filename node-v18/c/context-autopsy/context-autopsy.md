# context-autopsy

> 标签: ai-agents, claude-code, cline, codex, coding-agents, context-window, cursor, gemini-cli, llm, observability, opencode, tokens

## 简介

Find out what's actually filling your coding agent's context window. Breaks Claude Code, Codex, Cursor, OpenCode, Pi, Gemini CLI, Qwen Code, Cline, Roo, Kilo, Droid, Amp and Goose sessions down into code, build logs, environment wrangling, errors, overhea
