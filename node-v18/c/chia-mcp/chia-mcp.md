# chia-mcp

> 标签: blockchain, cat, chia, chialisp, coinset, mcp, mcp-server, model-context-protocol, nft, utxo, xch

## 简介

MCP server exposing Chia blockchain full node RPC endpoints as tools for AI agents. Read-only full-node access via Coinset hosted nodes — not a wallet.
