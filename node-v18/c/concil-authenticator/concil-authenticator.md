# concil-authenticator

> 标签: JavaScript

## 简介

O Autenticador plugin de login customizado que utiliza a AWS Amplify para suprir as necessidades de autenticação do ConcilCardV4, Controle de Arquivo ou qualquer projeto que necessite desta feature poderá ser utilizada.
