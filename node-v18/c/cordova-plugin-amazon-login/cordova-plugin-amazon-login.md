# cordova-plugin-amazon-login

> 标签: Amazon, Amazon Login, Amazon Sign In, Amazon SignIn, AmazonSignIn, Authentication, Companion App, Identity, Login, Login with Amazon, OAuth, cordova, cordova-android, cordova-ios, ecosystem:cordova

## 简介

A Cordova Plugin for Login with Amazon. Use your Amazon account to authenticate with the app. Also supports Companion App APIs for registration of AVS devices.
