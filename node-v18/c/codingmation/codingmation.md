# codingmation

> 标签: cli, cm, codingmation, compiler, css, framework, html, javascript, react-alternative

## 简介

Codingmation (.cm) — declarative web framework. Write App.cm, npm run dev / npm run build. Works without native esbuild (Windows 7 friendly).
