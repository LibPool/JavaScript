# confdiff

> 标签: ci, cli, config, config-drift, csv, diff, dotenv, ini, json, jsonc, kubernetes, properties, redact, secrets, semantic-diff, structured-diff, toml, xml, yaml

## 简介

Semantic, format-aware diff for config & structured-data files (JSON, JSONC, YAML, TOML, INI, .env, .properties, CSV, XML) — see what actually changed, compare across formats, and redact secrets so passwords/tokens never leak into a PR.
