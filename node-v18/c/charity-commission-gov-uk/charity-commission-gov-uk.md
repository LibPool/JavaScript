# charity-commission-gov-uk

> 标签: charity, charity-api, charitycommission.gov.uk, commission

## 简介

This npm package is a promise based wrapper for V1 of the UK Charity Commission API. This package allows you to search the comissions data. You will need to register as a developer to receive your API key before you can use this package.
