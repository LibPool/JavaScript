# custom-resource-provider

> 标签: JavaScript

## 简介

TypeScript/Node.js - Boilerplate for creating, testing and deploying Lambda-backed, AWS Cloudformation Custom Resources. Includes several examples and some useful resources that make (Enterprise, but works for everyone) deployments easier.
