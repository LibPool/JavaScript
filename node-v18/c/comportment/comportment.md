# comportment

> 标签: aes-256-gcm, compartmentalization, encryption, field-encryption, hkdf, hmac-blinding, password-hashing, pbkdf2, pii, scope-isolation, zero-dependency

## 简介

Context-scoped field encryption with query-time access policy enforcement. HKDF scope isolation, sealed query primitives, deterministic hash lookups, password blinding. Zero external dependencies.
