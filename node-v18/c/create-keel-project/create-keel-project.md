# create-keel-project

> 标签: create-keel-project, keel, react-native, scaffold

## 简介

Scaffolding tool for new Keel apps — invoked via `npm create keel-project my-app` or `npx create-keel-project my-app`.  Follows the npm `create-<thing>` convention used by create-react-app / create-expo-app / create-vite / etc.
