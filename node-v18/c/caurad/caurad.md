# caurad

> 标签: JavaScript

## 简介

npx/npm wrapper for the Caura broker: downloads the platform binary from the public release mirror, SHA-256-verifies it, and executes it.

## 官网

- 官网：https://caura.ai
- 源码仓库：git+https://github.com/caura-ai/caura-daemon.git
- npm 页面：https://www.npmjs.com/package/caurad

- npm registry：https://registry.npmjs.org/caurad
