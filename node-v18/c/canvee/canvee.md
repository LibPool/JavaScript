# canvee

> 标签: JavaScript

## 简介

Canvee是一个轻量级的 canvas 绘图框架，它使用组件式的开发方式，并使用 canvas 原生方法来绘制组件，体积轻巧，避免了使用其他 canvas 渲染引擎需要了解的新概念和心智负担，也极大减少了应用体积，适用于小游戏制作和嵌入H5页面开发。
