# cronixui

> 标签: components, css, dark-mode, design-system, golang, python, rust, typescript, ui

## 简介

CronixUI - Cross-framework dark-themed UI toolkit with crimson accents. Supports React, Vue, Svelte, Solid, TypeScript, Python, Go, Rust, Flutter.
