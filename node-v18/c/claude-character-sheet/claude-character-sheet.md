# claude-character-sheet

> 标签: character-sheet, claude, claude-code, cli, radar-chart, stats, usage

## 简介

Turn your Claude usage into an MMORPG-style character sheet (radar chart of 6 stats + class + level). Local-only parsing, zero dependencies.
