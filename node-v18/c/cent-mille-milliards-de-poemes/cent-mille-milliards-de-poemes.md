# cent-mille-milliards-de-poemes

> 标签: JavaScript

## 简介

A TypeScript library that provides a digital implementation of Raymond Queneau's Cent mille milliards de poèmes (A Hundred Thousand Billion Poems), allowing you to generate its 100 trillion possible poems.
