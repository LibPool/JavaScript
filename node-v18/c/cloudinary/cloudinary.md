# cloudinary

> 标签: JavaScript

## 简介

Upload, transform, optimize, and manage images and videos with Cloudinary from Node.js.

## 官网

- 官网：https://cloudinary.com
- 源码仓库：git+https://github.com/cloudinary/cloudinary_npm.git
- npm 页面：https://www.npmjs.com/package/cloudinary
