# cncjs

> 标签: arduino, cnc, cncjs, g2core, gcode, grbl, pi, raspberry, react, smoothie, smoothieware, socket.io, tinyg

## 简介

A web-based interface for CNC milling controller running Grbl, Marlin, Smoothieware, or TinyG

## 官网

- 官网：https://github.com/cncjs/cncjs
- 源码仓库：git+ssh://git@github.com/cncjs/cncjs.git
- npm 页面：https://www.npmjs.com/package/cncjs
