# custom-vue-cli

> 标签: publish, ssh2, zip

## 简介

自定义脚手架工具，功能点如下：1、初始化项目；2、生成部署配置文件模板；3、根据指定的文件路劲生成组件模板；4、部署代码到指定服务器；5、服务器代码回滚；6、将指定文件夹压缩成压缩包；
