# cube-root

> 标签: JavaScript

## 简介

Polyfill for `Math.cbrt()` proposed in ES6 for getting the cube root of a number.

- 官网：https://github.com/jonschlinkert/cube-root
- 源码仓库：git://github.com/jonschlinkert/cube-root.git
