# condorita

> 标签: analytics, animation, condor, condorita, mouse, parallax, scroll, size, speed, tracking, velocity, window

## 简介

Condorita is a JavaScript library for tracking user interactions such as mouse movement, browser dimensions, and much more. It takes its name from the Andean condor, the largest flying bird in the world which has incredible eyesight.
