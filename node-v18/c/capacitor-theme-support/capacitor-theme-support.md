# capacitor-theme-support

> 标签: android, capacitor, dark-mode, edge-to-edge, ios, native, navigation-bar, plugin, status-bar, theme

## 简介

A comprehensive Capacitor plugin for native system UI control - edge-to-edge display, status bar, navigation bar, dark mode detection for Android and iOS.
