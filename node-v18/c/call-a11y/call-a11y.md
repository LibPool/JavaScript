# call-a11y

> 标签: a11y, accessibility, aria-live, captions, live-captions, react, screen-reader, video-call, wcag, webrtc

## 简介

Accessibility building blocks for real-time call UIs: batched screen-reader announcements for joins and leaves, live captions that do not spam the reader, and call shortcuts that respect WCAG 2.1.4. Zero dependencies; works with any WebRTC stack.
