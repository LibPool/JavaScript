# canvas-text-mirror

> 标签: canvas, dom, effects, mirror, particles, pixel-perfect, text, typography

## 简介

Pixel-perfect DOM text → Canvas 2D mirror. Clone any HTML subtree onto a canvas with exact fonts, colors, line breaks, and letter-spacing.
