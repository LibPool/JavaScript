# crossrev-ai

> 标签: agents, ai, claude, cli, code-review, codex, github, pull-request

## 简介

A cross-model pull request review loop. One model reviews, a second verifies and replies in-thread, then the first looks again. Runs on the AI subscriptions you already have.
