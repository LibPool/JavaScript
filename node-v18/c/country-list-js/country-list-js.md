# country-list-js

> 标签: borders, calling-code, capital, continent, countries, country, country-codes, currency, dialing-code, geography, iso-3166, iso2, iso3, iso3166, iso4217, phone, province, region, state, subdivision, timezone

## 简介

Country data for 250 countries and territories: ISO 3166-1 codes, names, capitals, currencies, dialing codes, subdivisions, borders and IANA time zones. No dependencies.
