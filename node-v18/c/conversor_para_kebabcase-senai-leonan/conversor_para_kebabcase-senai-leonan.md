# conversor_para_kebabcase-senai-leonan

> 标签: JavaScript

## 简介

Conversor para KebabCase:* Transforma strings separadas por espaços em palavras minúsculas divididas por hífen, ideal para classes CSS (Ex: "Botão Primário Grande" vira "botao-primario-grande").
