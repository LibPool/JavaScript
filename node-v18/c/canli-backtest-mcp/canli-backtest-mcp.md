# canli-backtest-mcp

> 标签: ai-agents, backtesting, deflated-sharpe, factor-investing, lookahead-bias, mcp, model-context-protocol, overfitting, point-in-time, quant, quantitative-finance, sec, xbrl

## 简介

MCP server for backtests that refuse lookahead: point-in-time factors from SEC filings, cross-sectional backtests of any signal on your own prices, costs on actual trades, and every variant counted in a trial ledger.
