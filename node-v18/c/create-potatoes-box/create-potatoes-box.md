# create-potatoes-box

> 标签: cli, nextjs, starter, template

## 简介

This is an out-of-the-box Next.js template containing deps and configuration for Typescript, Tailwind CSS, Shadcn UI, Custom Themes, Zod & more. It provides too a basic example of how to use these technologies together.
