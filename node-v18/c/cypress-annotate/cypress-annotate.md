# cypress-annotate

> 标签: annotate, annotation, bounding-box, ci, cypress, cypress-cloud, cypress-plugin, cypress-screenshot, debugging, e2e, e2e-testing, failed-test, github-actions, pixel-accurate, screenshot, screenshot-annotation, test-artifacts, test-failure, test-reporting, visual-testing

## 简介

Draw a box on exactly what failed. Every failed Cypress test gets an annotated screenshot, in CI, with no AI and no browser download.
