> 标签: analytics, cordova-android, cordova-ios, download, ecommerce, ecosystem:cordova, event, google, install, metrics, referral, screen, track, tracking, ua, universal, universal analytics

## 简介

Phonegap, Cordova, Intel XDK Google Analytics plugin for iOS/Android with full support for views, events, timings, ecommerce and social. Supports userId and campaign url.
