# call-latest

> 标签: abort, async, debounce-alternative, dedupe, fetch, latest, promise, race-condition, search, stale, typescript

## 简介

Only the latest async call should win. Zero-dependency utility that fixes stale fetch responses in search, tabs, routes, and every rapid-fire async UI.
