# cuttr

> 标签: clampin, content, cuttr, dotdotdot, dots, ellipsis, javascript, jquery, js, line, multi, multiline, overflow, semantic, shave, shorten, string, text, text-overflow, trim, truncate, truncated, truncating, truncation

## 简介

Cuttr is a javascript / jQuery plugin that truncates multi-line string content with multiple truncation methods and custom ellipsis.
