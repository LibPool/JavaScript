# compressed-folder

> 标签: JavaScript

## 简介

> 目的在于解决很多node项目node_modules依赖包太大的问题，经过压缩后依赖包的容量大概为原包的55%左右，但是同样会删掉所有依赖包的说明文档，可根据项目自身需求进行使用； （当然也可以用于压缩其他JS文件目录）
