# cordova-plugin-qrcode-barcode-scanner

> 标签: cordova-android, cordova-ios, cordova:plugin

## 简介

You can use the BarcodeScanner plugin to scan different types of barcodes or QR codes (using the device's camera) and get the metadata encoded in them for processing within your application.
