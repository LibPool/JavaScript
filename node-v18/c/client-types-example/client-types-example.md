# client-types-example

> 标签: JavaScript

## 简介

Configured to use the `aws-amplify@api-v6-models` library with the `amplify-api-next` and `amplify-api-next-types` packages from this repo. Let's us quickly manually test the client-side types (return values, mutation inputs) without linking or publishing
