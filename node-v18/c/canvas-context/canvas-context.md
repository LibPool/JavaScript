# canvas-context

> 标签: 2d, bitmaprenderer, canvas, context, experimental-webgl, gpupresent, offscreen, offscreen-canvas, webgl, webgl2, webgpu, worker

## 简介

Create a RenderingContext (2d, webgl, webgl2, bitmaprenderer, webgpu), optionally offscreen for possible use in a Worker.
