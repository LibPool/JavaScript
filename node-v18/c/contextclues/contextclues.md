# contextclues

> 标签: ai-agent, claude, claude-code, cli, context-window, dashboard, llm, observability, tokens

## 简介

A local, read-only dashboard showing what a running Claude Code session has in its context window: observed token usage, growth trajectory, composition, evidence, tools, and clues.
