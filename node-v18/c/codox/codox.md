# codox

> 标签: clerk, nextjs 13, nextjs-with-trpc, prisma, shadcn ui, trpc, typescript

## 简介

CoDox : A starter template for modern web development with nextjs 13 (app route), tailwindcss, typescript, trpc, clerk auth, and prisma.
