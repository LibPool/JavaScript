# create-lemon-mcp

> 标签: api-billing, create, lemoncake, mcp, model-context-protocol, monetize, paid-mcp, pay-per-call, x402

## 简介

Scaffold a paid MCP server in one command. Sandbox by default; set LEMONCAKE_SELLER_KEY to charge for real. Buyers pay by card, agents call with spend-capped Pay Tokens, no crypto.
