# clicktone

> 标签: AAC, MP3, OGG, WAV, audio, audioContext, browser, click, effects, frontend, html5, iOS, javascript, media, mobile, music, playback, sound, tone, web, webAudio, webapp

## 简介

A lightweight helper for UI sound feedback. It wraps the Web Audio API with a tiny, event-based API and a rock-solid iOS/Safari unlock.
