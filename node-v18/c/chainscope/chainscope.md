# chainscope

> 标签: build-tool, circular-dependency, dependency-graph, incremental-build, static-analysis, topological-sort

## 简介

A dependency graph analyzer and incremental build simulator for JavaScript/TypeScript projects. Detects circular dependencies and identifies exactly which files need rebuilding when a file changes.
