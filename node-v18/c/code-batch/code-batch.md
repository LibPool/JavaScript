# code-batch

> 标签: binary, char, charCodeAt, charcode, code, code-points, codepoint, decimal, decode, encode, hexidecimal, javascript, module, node, nodejs, string, utf-16, utf-32, utf-8

## 简介

Module for converting characters to code points, binary, hex. It fixes the javascript charCodeAt to use in loops. Can convert emojis.
