# creo-bin

> 标签: JavaScript

## 简介

- 创建一个名称为creo的bin指令。用于脚本执行。 - 脚本执行取根目录中的creo-bin.runtime.js文件中的导出函数

## 官网

- npm 页面：https://www.npmjs.com/package/creo-bin

## 历史版本号

- 当前版本：1.0.0

- 1.0.0

## 获取地址

- npm 安装：`npm install creo-bin`
- npm registry：https://registry.npmjs.org/creo-bin
- Node 要求：>= 10.13.0
