# conv3d

> 标签: 3d, cli, fbx, gltf, obj, react-three-fiber, three.js

## 简介

An interactive CLI tool for converting 3D models to GLB format and outputting React components to use with r3f. Supports FBX, OBJ, and glTF input formats.
