# chartjs-adapter-dayjs-plus

> 标签: adapter, chart.js, date, day.js, time

## 简介

A Day.js-based time scale adapter for Chart.js 4.x.   It activates the Day.js `utc`, `timezone`, `quarterOfYear`, `weekOfYear`, and `isoWeek` plugins, then overrides Chart.js' default `_date` adapter.
