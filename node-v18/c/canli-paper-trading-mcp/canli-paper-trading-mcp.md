# canli-paper-trading-mcp

> 标签: alpaca, kill-switch, mcp, mcp-server, model-context-protocol, paper-trading, pre-trade-checks, rebalancing, risk-limits, trading

## 简介

MCP server that sends orders to your Alpaca paper account only after a pre-trade check and a confirmation token: account, preview, send, rebalance to target weights, and a hash-chained local log of every order. Paper only; live keys are refused.
