# cordova-plugin-xgis-geolocation

> 标签: GnssStatus, cellular, cordova, cordova-android, ecosystem:cordova, geolocation, gps, location, network, phonegap, satellite, signal-strength, triangulation

## 简介

Android geolocation plugin for both GPS and NETWORK-based location providers. Also can return satellite info, cellular info and cellular network signal strength.
