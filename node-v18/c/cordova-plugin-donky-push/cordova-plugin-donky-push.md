# cordova-plugin-donky-push

> 标签: cordova, cordova-android, cordova-ios, ecosystem:cordova, notifications, phonegap, push

## 简介

This plugin allows you to receive push notifications and interactive push notifications, feedback the analytics and optionally display them. Powered by Donky (www.donkynetworks.com)
