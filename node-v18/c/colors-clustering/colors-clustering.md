# colors-clustering

> 标签: CIE67, clustering, color, k-means, lab

## 简介

Colors clustering based on K-means algorithm & CIE76.  The seeds are extended color keywords from CSS Color Module Level 3 (W3C Recommendation 07 June 2011).
