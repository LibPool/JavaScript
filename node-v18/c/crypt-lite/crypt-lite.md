# crypt-lite

> 标签: decrypt, encrypt, image, lightweight, obfuscate, text

## 简介

Lightweight text + image encrypt/decrypt. Key + rounds. Web, Node and CLI share the exact same algorithm (interop with the encrypt desktop/web/Android tools).
