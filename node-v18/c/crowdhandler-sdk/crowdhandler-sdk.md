# crowdhandler-sdk

> 标签: JavaScript

## 简介

The official JavaScript SDK for [CrowdHandler](https://www.crowdhandler.com) waiting room and queue management. Works in both Node.js and browser environments.

- 官网：https://www.crowdhandler.com
