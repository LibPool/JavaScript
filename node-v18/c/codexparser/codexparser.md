# codexparser

> 标签: apocrypha, bible, bible-reference, deuterocanon, lxx, masoretic, osis, parser, sbl, scripture, septuagint, versification

## 简介

A Javascript Bible parser and text scanner. It will search through texts and collate all scripture references into an array and parse them into objects, and it will parse passages into objects by book, chapter, verse, and testament.
