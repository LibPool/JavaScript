> 标签: UIAlertViewController, android-dialog, android-dialog-view, android-platform, cordova-android, cordova-ios, cordova-plugin, cordova-plugin-alert, cordova-plugin-dialogs, ecosystem:cordova

## 简介

Simple 'Cordova Native Alert(Dialog) Plugin' is Helps to use native dialog views and it will support both iOS and Android platforms.
