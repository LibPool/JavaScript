# codables

> 标签: api-serialization, bigint, circular-references, class-serialization, date, declarative-serialization, decorators, error-serialization, full-stack, json, map, nextjs, reference-preservation, regexp, remix, serialization, set, superjson-alternative, symbol, typed-arrays, typescript, url

## 简介

High-performance, type-safe JSON serialization library that extends JSON to support complex JavaScript types including Date, BigInt, Map, Set, RegExp, Symbol, typed arrays, circular references, and custom classes.
