# clinical-trials-api

> 标签: api, clinical-trial-matching, clinical-trials, clinicaltrials-gov, health, healthcare, medical

## 简介

Lightweight JavaScript/TypeScript client for the ClinicalTrials.gov API v2. Search recruiting trials by condition, location, and status.
