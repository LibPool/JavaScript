# city-polygon

> 标签: brasil, city, geography, geojson, gis, leaflet, map, nominatim, openstreetmap, polygon

## 简介

Biblioteca JavaScript para buscar e exibir polígonos de cidades no Leaflet usando a API do OpenStreetMap (Nominatim)
