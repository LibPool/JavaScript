# cs2-api

> 标签: api-client, counter-strike, counter-strike-2, cs2, cs2-api, csgo, csgo-api, esports, esports-api, hltv, hltv-api, live-scores, skin-prices, skins

## 简介

CS2 API client: Counter-Strike 2 live scores, match results, player stats, teams, rankings (world + VRS), events and skin prices. Zero dependencies, TypeScript types.
