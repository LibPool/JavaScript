# crypto-tus-ts-client

> 标签: JavaScript

## 简介

tus-js-client is a pure **JavaScript** client for the [tus resumable upload protocol](http://tus.io) and can be used inside **browsers**, **Node.js**, **React Native** and **Apache Cordova** applications.
