# claudedex

> 标签: always-on-top, anthropic, claude, claude-code, desktop-pet, electron, gacha, gamification, pokedex, pokemon, productivity, questlog, tray, widget

## 简介

An always-on-top RPG questlog for your Claude Code sessions — a Pokédex, a desktop buddy, missions, and a gacha, all fuelled by work you were already doing. Reads ~/.claude locally, costs zero extra tokens.
