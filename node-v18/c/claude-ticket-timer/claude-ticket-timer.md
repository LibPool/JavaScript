# claude-ticket-timer

> 标签: azure-devops, claude, claude-code, hooks, jira, statusline, time-tracking

## 简介

Measures how long a ticket actually takes in Claude Code — a prompt led by a card ID starts a clock, hooks accumulate active time with breaks removed, and a colored timer ticks in the status line.
