> 标签: a11y, accessible, autocomplete, combobox, dropdown, framework-agnostic, headless, select, vanilla-js, wai-aria

## 简介

A framework-independent, headless combobox engine providing state management, keyboard navigation, and accessibility — zero dependencies, zero UI opinions.
