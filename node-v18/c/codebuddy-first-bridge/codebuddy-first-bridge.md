# codebuddy-first-bridge

> 标签: agent, codebuddy, cordis, deepseek-harness, dsh, mcp, mcp-server

## 简介

codebuddy-first bridge for DeepSeek Harness (DSH): prioritize the local codebuddy CLI in every mode (full DSH control, no prompts), with a rate-limit/network fallback dialog, a live status light (dynamic form + home-level plugin), per-project token usage
