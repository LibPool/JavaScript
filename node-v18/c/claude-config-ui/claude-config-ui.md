# claude-config-ui

> 标签: agents, anthropic, claude, claude-code, cli, config, developer-tools, manager, mcp, settings, tui

## 简介

Local, open-source UI for editing every Claude Code config file — settings, CLAUDE.md, MCP servers, subagents, slash commands, credentials, hooks. User / project-shared / project-local / enterprise scopes, with community presets and tooltips.
