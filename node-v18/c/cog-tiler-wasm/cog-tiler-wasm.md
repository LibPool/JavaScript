# cog-tiler-wasm

> 标签: cog, geotiff, maplibre, raster, tiler, titiler, wasm, web-mercator, webassembly, xyz

## 简介

Serverless Cloud Optimized GeoTIFF (COG) dynamic tiling in WebAssembly. TiTiler-style XYZ tiles, no backend.
