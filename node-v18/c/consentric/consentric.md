# consentric

> 标签: consent, consent-mode, cookie-banner, cookie-consent, gdpr, i18n, localization, privacy, react

## 简介

Self-contained, configurable GDPR cookie consent for React. Google Consent Mode v2, 10 built-in languages, zero dependencies, zero Tailwind.
