# castsvg

> 标签: animated-svg, asciicast, asciinema, cli, recording, screencast, svg, terminal

## 简介

Record terminal sessions and render them as self-contained animated SVG. This npm package downloads the prebuilt castsvg binary (written in Rust) for your platform — no Node runtime baggage, same single static binary.
