# coderoom-cli

> 标签: agent, ai, claude, cli, codex, coding-assistant, llm, terminal

## 简介

Локальный агент для работы с кодом в терминале и браузере: читает и правит файлы, запускает команды. Десятки моделей по одному ключу. Без внешних зависимостей.
