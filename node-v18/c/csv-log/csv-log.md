# csv-log

> 标签: convert, csv, log

## 简介

Write Javascript objects to a log file in CSV format, so that it can be easily viewed using Excel or any other application that handles CSV files. Also includes utility functions to covert objects to CSV (with or without a header) and CSV to objects
