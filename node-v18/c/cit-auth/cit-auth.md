# cit-auth

> 标签: authentication, authorization, challenge-response, cryptography, express, intent-based, jwt-alternative, node, security, zero-trust

## 简介

A cryptographic intent-based authentication library for Node.js and Express that replaces JWTs with non-bearer, replay-resistant proofs.
