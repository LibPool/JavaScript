# coderecap

> 标签: cli, contribution-graph, developer-stats, git, git-history, git-log, git-stats, git-wrapped, gitwrapped, recap, spotify-wrapped, wrapped, year-in-code, year-in-review

## 简介

Spotify Wrapped for your git history — a beautiful, shareable year-in-code recap generated locally from any repo (public, private, or work). Nothing uploaded. Prints a terminal card and exports an SVG/JSON/Markdown recap.
