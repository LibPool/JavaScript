# cross-tab-kit

> 标签: cross-tab, dedupe, leader-election, localstorage, mutex, web-locks

## 简介

Framework-agnostic cross-tab coordination for the browser: a Web Locks mutex (waiting and skip-if-busy), timer-driven or caller-driven leader election, and a TTL dedupe cache.
