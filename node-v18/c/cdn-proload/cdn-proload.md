# cdn-proload

> 标签: JavaScript

## 简介

多个cdn资源引用加载器。若前面cdn挂掉则自动引用下一个cdn资源。若加载成功，停止该资源的加载。     可避免某个cdn资源挂掉造成的问题。     可加载css 及 js 资源。其它资源暂无处理（如图片，视频等资源， 后续可能更新） ### 使用方法 ```javascript // 引用 npm i cdn-proload -S ``` ``` js /*  *基本使用：  *第一个参数为所要加载的资源列表，以对象的形式  *第二个参数为资源加载完成的回调，用于资源加载完
