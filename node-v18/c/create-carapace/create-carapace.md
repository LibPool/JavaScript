# create-carapace

> 标签: blog, cms, git, mcp, static-site

## 简介

Scaffold a git-native, MCP-driven blog with no headless CMS, no API layer, and no admin UI — generates your two repos, your GitHub App, and a fully provisioned Cloudflare deployment.
