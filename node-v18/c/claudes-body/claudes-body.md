# claudes-body

> 标签: claude, claude-code, deno, desktop-overlay, electron, tts, vrm, webview

## 简介

Claude's Body — a draggable, animated Claude that speaks Claude Code responses with tone-driven expressions. Windows runs a lightweight Deno + WebView2 host (no Electron); macOS/Linux use Electron.
