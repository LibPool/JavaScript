# create-webjs

> 标签: create, framework, scaffold, starter, webjs

## 简介

WebJs is a full-stack JavaScript framework built on web components, with server-side rendering and no build step. Runs on Node 24+ or Bun. Scaffold an app with `npm create webjs@latest my-app`.
