# cpace

> 标签: autoreload, c, c++, cli, cpace, cpp, development, monitor, reload, restart, terminal

## 简介

Nodemon for C/C++ files. Monitor for any changes in your [.c] and [.cpp] application and automatically restart it - perfect for development
