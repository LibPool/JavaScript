# codexjournal-lite

> 标签: ai-work-log, claude-code, cli, codex, gemini-cli, jetbrains, journal, local-only, markdown, multi-source, opencode, privacy

## 简介

Local-only multi-source CLI + dashboard that turns AI coding session files (Codex, Claude Code, Gemini CLI, OpenCode, JetBrains) into a personal AI work journal. No GUI, no DB, no upload. Privacy by design.
