# copilotqa

> 标签: ai, ai-coding, claude, claude-code, cli, cursor, drift, drift-detection, git, project-management, roadmap, spec-driven, vibecoding

## 简介

Reads your real repo and tells you where your AI-built project drifted from your plan — a project brain (roadmap, specs, decisions, bugs, guided QA) for building with Claude Code or Cursor.
