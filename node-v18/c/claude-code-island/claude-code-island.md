# claude-code-island

> 标签: agents, claude, claude-code, dynamic-island, live-activity, macos, notch, statusline, terminal

## 简介

A live-activity island in your Mac's notch for Claude Code — see what every session is doing across all your terminals, and click to jump back to the right tab.
