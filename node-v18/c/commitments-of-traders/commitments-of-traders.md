# commitments-of-traders

> 标签: api-client, cftc, commitments-of-traders, cot, cot-report, disaggregated, finance, futures, positioning, socrata, traders-in-financial-futures, trading

## 简介

Typed, zero-dependency client for the CFTC Commitments of Traders (COT) reports — Legacy, Disaggregated, and Traders in Financial Futures, futures-only or combined, via the official Socrata API. No API key required.
