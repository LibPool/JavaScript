# clever-react-report

> 标签: JavaScript

## 简介

A webserver that analyze the dependencies of `@clever/ui` in the projects defined in `config.json`. Components dependent of Material UI are also tagged.

- npm 页面：https://www.npmjs.com/package/clever-react-report
