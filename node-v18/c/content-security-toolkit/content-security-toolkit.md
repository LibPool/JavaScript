# content-security-toolkit

> 标签: anti-screenshot, browser-security, content-protection, content-security, copy-protection, devtools-detection, frontend-security, javascript, typescript, watermark, web-security

## 简介

Lightweight TypeScript toolkit to protect web content: blocks copying/printing, detects devtools/screenshots, adds watermarks, and provides extensible strategies and detectors.
