# corellm

> 标签: adapter, ai, anthropic, llm, llm-apps, mistral, openai, retries, streaming

## 简介

Shared multi-provider LLM client for the llm-apps packages — one adapter layer with baseUrl proxying, retries, timeouts, and token-usage capture. Framework-agnostic (uses fetch).
