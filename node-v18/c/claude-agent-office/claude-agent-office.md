# claude-agent-office

> 标签: agents, animation, claude, claude-code, hooks, office, pixel-art, sprites, themes, visualizer

## 简介

A living virtual office that visualizes Claude Code agents walking around and working - driven by a scripted simulation or by real Claude Code hook events. Switchable themes with animated sprite casts.
