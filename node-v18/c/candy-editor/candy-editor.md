# candy-editor

> 标签: JavaScript

## 简介

**Candy Editor** 是一个功能丰富、高度可定制、为开发者设计的 Vue 3 富文本编辑器。它提供了现代化的 UI、可扩展的插件系统和强大的 API，旨在轻松集成到任何 Vue 项目中。
