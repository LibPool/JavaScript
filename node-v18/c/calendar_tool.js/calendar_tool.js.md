# calendar_tool.js

> 标签: calendar, component, react, tool

## 简介

> 前言： 最近在搬砖的过程中，需要构建几个不同类型的日历组件。在写一个日历组件需要知道：当月有多少天、当月第一天是星期几、当月最后一天是星期几、当月第一天之前和最后一天之后的星期，如果空缺需要补全day等，这些值都是我们构建一个日历组件必须的数据。 有两个地方代码一样，那就需要提取出来封装起来。
