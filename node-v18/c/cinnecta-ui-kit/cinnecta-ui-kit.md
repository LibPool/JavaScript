# cinnecta-ui-kit

> 标签: JavaScript

## 简介

LUIS (Lean User Interface System) é um design system desenvolvido para fornecer uma biblioteca de componentes React.js flexí­vel e eficiente, garantindo consistência visual e facilidade de uso em diferentes projetos.
