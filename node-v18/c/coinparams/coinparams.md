# coinparams

> 标签: altcoins, bip32, bip39, bip44, bitcoin, cryptocurrencies, cryptocurrency, genesis, slip44

## 简介

provides crypto currency specific information such as key prefixes, DNS seeds, network ports, bip32, bip44, genesis block, etc.  For hundreds of altcoins.
