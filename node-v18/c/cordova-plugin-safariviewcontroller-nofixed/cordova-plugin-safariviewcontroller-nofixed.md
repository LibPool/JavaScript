# cordova-plugin-safariviewcontroller-nofixed

> 标签: Chrome Custom Tabs, InAppBrowser, InAppSafariBrowser, Safari, Safari ViewController, cordova-android, cordova-ios, ecosystem:cordova

## 简介

Forget InAppBrowser for iOS - this is way better for displaying read-only web content in your PhoneGap app. This is a fork that removed the java version for compatibility
