# copy-dist-delete-jsmap-webpack-plugin

> 标签: copy-output-plugin, sourcemap-webpack-plugin, webpack, webpack-plugin

## 简介

一个webpack插件，在构建完成时，复制dist到新目录，并删除dist里面js.map文件
