# caustic-light

> 标签: animation, audio-reactive, background, caustics, custom-element, generative, light, shader, visual-effects, web-component, webgl, webgl2

## 简介

A web component that renders physically based caustic light (the webs and ribbons that glass, water and polished metal throw onto a wall) with WebGL2. Gradient maps, hover effects and music-reactive light. No dependencies.
