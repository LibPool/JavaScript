# cypress-snapshot-reporter

> 标签: cypress, cypress-snapshot-reporter, diff, excel, mochawesome, ocr, pixelmatch, reporter, screenshot, snapshot, tesseract, visual-regression

## 简介

Cypress plugin for visual pixelmatch testing with pixel-level diff, OCR, severity classification, and Excel + Mochawesome reporting. Works fully offline.
