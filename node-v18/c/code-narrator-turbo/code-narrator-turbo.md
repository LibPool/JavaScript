# code-narrator-turbo

> 标签: autodoc, documentation, gpt4-turbo, openai

## 简介

Uses OpenAI to generate documentation for your source code, as well create HowTo, FAQ, Tutorial and other custom pages. code-narrator-turbo documents it self and should be a validation of the documentation working, similar to a compiler compiling it self.
