# create-umi-app

> 标签: cli, ide, instant, move, scaffold, solidity, umi

## 简介

Instant Fullstack Scaffold where CLI generates fresh projects with Dual-VM Umi dApp support (Move + EVM) together with built-in MoveAI & SolidityAI browser IDE for opening the project in a browser, edit code, compile, and deploy
