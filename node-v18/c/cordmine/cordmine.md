# cordmine

> 标签: archive, discord, discord.js, fts5, library, search, sqlite

## 简介

Discord archive library (discord.js style API) — mirror guilds into local SQLite with FTS5 search; CLI for AI agents (bunx cordmine sync / search / status). Bun-first, cross-platform.
