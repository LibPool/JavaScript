# currency-icon-map

> 标签: currency, currency-symbol, fintech, fontawesome, forex, heroicons, icon, icons, iso-4217, lucide, mapping, money, react, svg, tabler

## 简介

Resolve any currency (ISO 4217 code, symbol, name, or country) to the right icon name for Lucide, Tabler, Font Awesome, and Heroicons — with a guaranteed default fallback. Zero runtime dependencies, fully offline, with optional React adapters.
