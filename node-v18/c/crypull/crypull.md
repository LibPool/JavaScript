# crypull

> 标签: api, binance, coingecko, crypto, defi, dexscreener, geckoterminal, price, token

## 简介

All-in-one Node.js package to fetch cryptocurrency prices and token info from CoinGecko, GeckoTerminal, Dexscreener, and Binance.
