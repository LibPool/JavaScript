# cornu-spline

> 标签: bezier, canvas, clothoid, cornu, curve, euler-spiral, interpolation, react, spiro, spline, svg

## 简介

Smooth Cornu (Euler-spiral / Spiro) interpolating splines through points — vanilla JS + React, with SVG, Canvas, text rendering, and animation.
