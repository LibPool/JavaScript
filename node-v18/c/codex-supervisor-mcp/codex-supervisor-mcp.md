# codex-supervisor-mcp

> 标签: claude, codex, mcp, model-context-protocol, multi-agent, orchestration, supervisor, worktree

## 简介

MCP server that dispatches and supervises parallel Codex CLI workers, one isolated Git worktree each, with a persisted work state machine.
