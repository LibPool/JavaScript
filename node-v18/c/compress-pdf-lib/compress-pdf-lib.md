# compress-pdf-lib

> 标签: astro, canvas, compress-pdf, compression, jpeg, pdf, pdf-lib, pdfjs, react, vite

## 简介

Client-side PDF compression: extract & recompress embedded images with hardware-accelerated native Canvas / libjpeg-turbo + pdf-lib rebuild. No server, no UI. Ships as raw ESM source for Vite-based apps (React + Vite, Astro).
