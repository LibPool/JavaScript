# common-select-package

> 标签: component, multi-select, select, single-select, vue3

## 简介

选择器组件库，基于 Ant Design Vue 开发,包含单选和多选组件,方便最终联合表单校验，支持虚拟滚动、搜索、批量操作等功能。
