# color-value-tools

> 标签: accessibility, cmyk, color, color-conversion, css, hex, hsl, oklch, rgb, typescript, wcag

## 简介

Parse, convert and manipulate colors across hex, RGB, HSL, Lab, LCH, OKLCH and CMYK, with WCAG contrast checks and CSS variables. Zero dependencies.
