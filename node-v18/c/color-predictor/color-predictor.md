# color-predictor

> 标签: classifier, color, color-classification, deeplearning, esm, javascript, nodejs, predict, rgb, rgb to color, tensorflow, tfjs

## 简介

Takes a full path to an image and returns its predicted color. Will be integrated to work with live cam in order to detect colors of objects in real time.
