# cosignals-arena

> 标签: async, atom, concurrent, concurrent-rendering, data-oriented, hooks, react, reactive, signals, state, state-management, store, suspense, transitions, typed-array

## 简介

The data-oriented build version of cosignals: the same concurrent signals API for React, with the reactive graph stored in typed-array records instead of linked JS objects. Probably faster; definitely harder to read.
