# create-fornix

> 标签: ai, anthropic, astro, blocks, claude, cli, cloudflare, create-app, generator, i18n, scaffolder

## 简介

Scaffold a production-ready Astro site in one command. 5 archetypes (SaaS, agency, portfolio, gym, restaurant), 13 hand-built blocks, 7 design palettes, multi-page sites, multi-deploy-target configs (Cloudflare/Vercel/Netlify), and AGENTS.md emission so C
