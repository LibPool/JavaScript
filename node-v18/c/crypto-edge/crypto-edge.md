# crypto-edge

> 标签: aes, aes-cbc, aes-gcm, browser, crypto, cryptography, decryption, ecdsa, encryption, hashing, hkdf, hmac, nodejs, pbkdf2, rsa, rsa-oaep, rsa-pss, security, sha256, sha512, signature, subtle-crypto, typescript, webcrypto, wrapper

## 简介

A wrapper library built on top of the Web Crypto API to abstract simple functionality like hashing, encryption and signing, with type-safe overloading and robust error handling.
