# cadence-tokens

> 标签: animation, css-custom-properties, design-system, design-tokens, design-tokens-resolver, dtcg, framer-motion, motion, reduced-motion, rive

## 简介

The Cadence motion token system: three motion personalities (Snappy, Standard, Cinematic) as data, with emitters for CSS custom properties, DTCG, flat JSON, Framer Motion, After Effects (a TOKENS Motion control layer script), a Flow easing library, and Ri
