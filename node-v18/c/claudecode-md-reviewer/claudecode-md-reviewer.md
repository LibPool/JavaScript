# claudecode-md-reviewer

> 标签: annotation, claude, claude-code, cli, local, markdown, review, review-loop

## 简介

Local, zero-dependency Markdown review loop: produce a .md, annotate it in the browser, read the annotations back. Built for the Claude Code workflow, useful for any human-in-the-loop Markdown review.
