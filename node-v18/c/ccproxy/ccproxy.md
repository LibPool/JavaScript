# ccproxy

> 标签: ai, anthropic, api, claude, cli, gemini, litellm, llm, openai, proxy

## 简介

A high-performance proxy server that translates Anthropic Claude API requests to LiteLLM (OpenAI) format for multi-provider LLM access
