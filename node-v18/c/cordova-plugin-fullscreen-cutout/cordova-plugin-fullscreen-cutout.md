# cordova-plugin-fullscreen-cutout

> 标签: android, cordova, cordova-android, ecosystem:cordova, fullscreen, immersive, lean

## 简介

Plugin for Cordova (or PhoneGap) 3.0+ to enable true full screen with coutouts on Android devices using lean and immersive modes
