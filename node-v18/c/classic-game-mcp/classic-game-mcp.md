# classic-game-mcp

> 标签: MCP, classic video game

## 简介

1. 安装依赖 ```npm install classic-game-mcp -g``` 2. 本地智能体安装    mcp配置文件添加 ```javascript "mcpServers": {   "classic-game-mcp": {     "command": "npx",     "args": ["-y", "classic-game-mcp"],     "env": {       "PORT": "3303" // 自定义运行端口号     }   } } ``` 然后你就可以告
