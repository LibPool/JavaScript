# calculator-coding-challenge

> 标签: Calculator, MQTT, REST-API

## 简介

This package contains an example of a calculator based on REST API and MQTT. The simple calculator adds two numbers given by the user and returns the result. The REST API returns the result and it also gets published by the MQTT-Broker.
