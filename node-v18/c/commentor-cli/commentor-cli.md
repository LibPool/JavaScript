# commentor-cli

> 标签: clean, cleaner, cli, code-cleaner, comment, commentor, comments, minify, remove-comments, source-code, strip, strip-comments

## 简介

Remove all comments from source code. Multi-language comment stripper for JavaScript, TypeScript, Python, Java, Go, Rust, C++, PHP, SQL, HTML, CSS and 25+ languages. Global CLI + library.
