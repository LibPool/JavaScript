# crane-element

> 标签: JavaScript

## 简介

Crane-Element 是一个基于 Vue 3、Vite、TypeScript 和 Element Plus 的二次封装项目。它提供了动态表单、动态表格、命令式弹窗和命令式抽屉（drawer）等功能，并为这些功能提供了各类动画效果。
