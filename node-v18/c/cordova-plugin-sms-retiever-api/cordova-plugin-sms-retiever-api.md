# cordova-plugin-sms-retiever-api

> 标签: Google SMS Retriver, Retriever API, cordova-android, ecosystem:cordova, read SMS

## 简介

An Android Cordova plugin that allows your app to read SMS by using Google's SMS Retriever API.
