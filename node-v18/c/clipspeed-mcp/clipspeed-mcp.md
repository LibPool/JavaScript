# clipspeed-mcp

> 标签: ai, captions, claude, clips, clipspeed, mcp, model-context-protocol, shorts, video

## 简介

ClipSpeed MCP server — turn any video into ready-to-post vertical clips from Claude, Cursor, Cline, or Windsurf. Wraps the ClipSpeed public API with your personal key.
