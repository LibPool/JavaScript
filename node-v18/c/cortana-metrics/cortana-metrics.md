# cortana-metrics

> 标签: api, capture, cli, collection, command-line, documentation, endpoint, express, headers, logging, middleware, monitoring, openapi, request, response, testing, tools, versioning

## 简介

A comprehensive npm module for capturing endpoint-related data including request body, response body, headers, and more. Includes CLI tools for managing OpenAPI specifications.
