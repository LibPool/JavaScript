# claude-discord-daemon

> 标签: bot, bridge, claude, claude-code, daemon, discord, mcp

## 简介

24/7 headless Discord bridge for Claude Code on Windows. Each allowlisted DM spawns a fresh claude -p with your full global config; live named-tool status card, rich embeds/choice buttons, 50MB attachments, Discord permission relay, and a logon-task daemo
