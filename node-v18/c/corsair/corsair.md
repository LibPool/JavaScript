# corsair

> 标签: ai-agents, api, connectors, corsair, integrations, mcp, multi-tenant, oauth, self-hosted, webhooks

## 简介

Open-source integration layer for AI agents and apps. Managed OAuth, webhooks, and one API for 350+ integrations, with credentials that stay in your own database.
