# codebase-synapse

> 标签: ai, claude, code-search, codebase, cursor, graph, knowledge-graph, llm, mcp, semantic-search, tree-sitter

## 简介

MCP server that indexes your codebase into a local knowledge graph. Gives AI agents (Claude Code, Cursor, Zed, etc.) semantic search, call graph traversal, git archaeology, and blast-radius analysis.
