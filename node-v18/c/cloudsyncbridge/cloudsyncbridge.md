# cloudsyncbridge

> 标签: backup, bidirectional, cloud-sync, external-drive, icloud, macos, sync, unison

## 简介

Bidirectional iCloud sync for any folder - sync external drives, projects, downloads, and any folder to iCloud with automatic bidirectional sync
