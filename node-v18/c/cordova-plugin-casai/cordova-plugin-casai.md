# cordova-plugin-casai

> 标签: ads, cordova, cordova-android, cordova-ios, echosystem:cordova, mediation, mobile, monetization

## 简介

The CAS.AI Cordova plugin allows you to easily monetize your apps for iOS and Android using lot of Ads SDKs in mediation.
