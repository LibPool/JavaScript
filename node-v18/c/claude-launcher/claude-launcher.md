# claude-launcher

> 标签: ai, claude, claude-code, cli, openrouter

## 简介

Launch Claude Code with multiple backends (Anthropic, Codex, Grok, Kimi, OpenRouter, Ollama, NVIDIA NIM, LM Studio) or mix them per role
