# cc-denied

> 标签: ai, anthropic, claude, claude-code, cli, denied, developer-tools, productivity, safety, session-analysis

## 简介

Every Bash command your human said NO to. 161 denials. 72% were pkill. One was rm. See what Claude Code tried to run that you stopped.
