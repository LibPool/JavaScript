# chromosomix

> 标签: 3d-genome, bigwig, bioinformatics, chromatin, cli, compartments, contact-map, cooler, genome-browser, genomics, hdf5, hi-c, hic, insulation, juicer, mcool, micro-c, tad, webassembly

## 简介

Genome browser for Hi-C and Micro-C contact maps, genome tracks and 3D models, and the command line that runs its analyses: insulation, compartments, loops, APA, P(s) and more.
