# codelapse-cli

> 标签: ai-tools, automation, cli, code-analysis, codelapse, codelapse-cli, configuration, developer-tools, diagnostics, git, github, semantic-search, snapshot, terminal, version-control, vscode

## 简介

Command-line interface for CodeLapse snapshots. Standalone: snapshot CRUD, file operations (files), filtering, rules, diagnostics, config, git, workspace info. Requires the VS Code extension over IPC: search, search-enhanced, analyze, chunk, watch, worksp
