# codegraphx

> 标签: ai-agents, ast, claude, code-analysis, code-graph, dependency-graph, gemini, impact-analysis, mcp, model-context-protocol, sqlite, tree-sitter

## 简介

Token-efficient codebase graph engine for AI coding agents. Tree-sitter parsing, SQLite semantic graph, impact tracing, and an MCP server with zero-config auto-indexing.
