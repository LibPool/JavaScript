# conversation-extension-framework

> 标签: api, conversation, easy, extension, framework, kit, starter, watson

## 简介

The Watson Conversation Extension Framework is a Node.js tool that allows developers quickly add dynamic functionality to their IBM Watson Conversation powered chatbots.
