# current-time-timezone-server

> 标签: current-time, dotenv, http, mcp, ntp, server, sse, time, timezone

## 简介

MCP服务器，提供NTP校准的当前时间和时区相关功能，支持stdio和HTTP/SSE，可配置host和protocol，支持.env文件，返回指定时区的本地时间
