# cloudy-handoff

> 标签: agent, ai, claude, claude-code, cloud-run, codex, gcp, handoff

## 简介

Hand off any Claude Code or Codex session into a Google Cloud Run job that runs until done — commits, pushes a branch, opens a PR. Bring-your-own-GCP.
