# congresschileapi

> 标签: JavaScript

## 简介

This is a wrapper for the chilean congress web service, written on Javascript, this was created based on LaraCongress for PHP, this project is part of https://www.2x3.cl team, that contribute to have most accesible info about politics to chilean people.
