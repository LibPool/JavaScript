# community-cordova-plugin-advanced-http

> 标签: cordova-android, cordova-ios, cors, csp, ecosystem:cordova, http, request, webhook

## 简介

Minimal native HTTP client for Cordova: send one request (GET/POST/PUT/DELETE) to a user-defined http(s) URL, bypassing WebView CSP and CORS.
