# car-registration-api-peru

> 标签: Chile, car, license, registration

## 简介

Get car information from an Peruvian number plate. An account username is required, which you can get from http://pe.placaapi.com/

## 官网

- 源码仓库：http://pe.placaapi.com/
- npm 页面：https://www.npmjs.com/package/car-registration-api-peru

## 历史版本号

- 当前版本：1.0.4

- 1.0.4
