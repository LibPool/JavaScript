# clipboard-service

> 标签: clipboard, copy, helper, paste, utils

## 简介

The clipboard-service package is a lightweight, easy-to-use library that simplifies interaction with the browser’s Clipboard API. With ClipboardService, you can easily read from and write to the clipboard with just a few lines of code.
