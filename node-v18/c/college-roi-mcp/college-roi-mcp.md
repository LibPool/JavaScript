# college-roi-mcp

> 标签: college, dataset, earnings, education, mcp, model-context-protocol, npv, roi, tuition

## 简介

MCP server for U.S. college ROI data: 30-year NPV for 500 colleges, lifetime ROI for 134 majors, best-value and out-of-state-penalty rankings. Free, keyless, CC BY 4.0.
