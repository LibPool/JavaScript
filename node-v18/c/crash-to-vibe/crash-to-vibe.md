# crash-to-vibe

> 标签: agent-skills, ai, android, automation, crash-analysis, crashlytics, firebase, flutter, ios, jira, mobile, skills, task-automation

## 简介

Installs an Agent Skills skill that auto-activates Firebase Crashlytics crash analysis and task creation in Claude Code, Gemini CLI, Codex, and GitHub Copilot
