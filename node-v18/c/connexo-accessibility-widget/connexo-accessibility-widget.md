# connexo-accessibility-widget

> 标签: a11y, accessibility, accessibility-widget, dyslexia, high-contrast, inclusive-design, no-dependencies, screen-reader, text-to-speech, vanilla-js, wcag, widget

## 简介

Widget de accesibilidad completo en un solo archivo, sin dependencias. 11 controles (contraste, dislexia, lector de voz, guía de lectura, cursor grande y más). Se integra en cualquier web en menos de 5 minutos.
