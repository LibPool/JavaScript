# cfdi-sat-nodejs

> 标签: carta porte, cfdi, json, nodejs, sat, xml

## 简介

Herramienta para generar y manejar CFDI 4.0. Incluye utilidades para trabajar con certificados digitales, generar XML o JSON sellados y sin sellar
