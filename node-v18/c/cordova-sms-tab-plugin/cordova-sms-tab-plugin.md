# cordova-sms-tab-plugin

> 标签: cordova, cordova-android, cordova-ios, cordova-windows, cordova-wp8, ecosystem:cordova, phonegap, sms

## 简介

Cross-platform plugin for Cordova / PhoneGap to to easily send SMS. Available for Android, iOS and WP.
