# cvdocs

> 标签: cli, docs, documentation, scaffold, ssg, template, vite, vue

## 简介

一条命令初始化一个 Vue 3 + Vite 静态文档站；渲染核心（路由/页面/状态/主题）随包附带，站点只需 docs 与配置
