# cleanfilesplugin

> 标签: JavaScript

## 简介

每次打包如果文件有修改会生成新的文件，文件的 hash 也会跟着变化，那么这个改变了的文件，他以前的文件就是无效的了，要把以前的文件清除掉，我们使用比较多的就是 clean-webpack-plugin，这里自己实现一个简单的文件清除 webpack 插件
