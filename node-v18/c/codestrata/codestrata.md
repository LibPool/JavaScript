# codestrata

> 标签: code-map, dependency-graph, graphql, monorepo, nx, static-analysis, typescript

## 简介

Local, open source code map for TypeScript monorepos: who uses what, from projects down to functions, with a GraphQL layer (schema → resolver → service → API). Work in progress.
