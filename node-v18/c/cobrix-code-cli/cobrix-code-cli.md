# cobrix-code-cli

> 标签: ai, chat, cli, coding-agent, electron, gguf, llm, ollama

## 简介

CobrIX Code CLI - A powerful AI coding companion and agent app for automating software engineering workflows. Supports open-source models via Ollama, LM Studio, and llama.cpp, with community-backed custom-hosted models coming soon.
