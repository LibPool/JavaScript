# create-react-cli-demo

> 标签: JavaScript

## 简介

`create-react-cli-demo` 是一个命令行工具，用于快速创建基于 Vue 或 React 的项目。该工具提供了项目模板，并支持用户自定义项目名称、描述和作者信息。
