# capacitor-faceantispoofing-cpp

> 标签: anti-spoofing, capacitor, face, liveness, native, ncnn, plugin

## 简介

Capacitor plugin for real-time passive liveness detection using the ncnn C++ engine (face detection + anti-spoofing), ported from the GreatDay kiosk engine. Supports Android and iOS.
