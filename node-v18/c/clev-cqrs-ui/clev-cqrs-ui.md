# clev-cqrs-ui

> 标签: clev-cqrs, clev-cqrs-ui, command-query-responsibility-segregation, cqrs, data, datastore, db, ddd, domain-driven-design, event-driven, event-driven microservice, event-sourcing, event-store, microservice, node-cqrs, query, storage

## 简介

Adds middleware to your express app to autogenerate a page that shows all the events that has ever happend to your entity using the clev-cqrs-ui bound to the clev-cqrs framework.
