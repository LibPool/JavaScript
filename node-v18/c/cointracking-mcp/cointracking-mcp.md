# cointracking-mcp

> 标签: anthropic, claude, cointracking, crypto, cryptocurrency, mcp, model-context-protocol, portfolio, tax

## 简介

MCP server exposing the CoinTracking API as read-only tools (trades, balances, historical summaries, gains) for Claude Desktop, Claude Code, Cowork, and other MCP clients.
