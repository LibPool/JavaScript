# convert2pdf

> 标签: api, cli, compress, convert, ghostscript, libreoffice, nodejs, pdf, powerpoint, pptx

## 简介

Convert files to PDF and compress PDFs. Currently supports .pptx/.ppt to PDF and .pdf compression. CLI and Node.js API.
