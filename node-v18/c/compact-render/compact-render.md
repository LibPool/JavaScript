# compact-render

> 标签: agent, compression, json, llm, mcp, token-optimization, tool-output, toon

## 简介

Fail-closed compact renderer for structured LLM tool outputs: emit JSON, or switch to TOON columnar encoding only where it is measurably smaller under o200k.
