# cache-pulse

> 标签: brotli, cache-control, caching, cloudflare-pages, github-action, immutable, netlify, performance, static-site, vercel

## 简介

Check static hosting caching for performance: long max-age + immutable on fingerprinted assets, revalidation on HTML, no long cache on unhashed files, Vary and Set-Cookie pitfalls, and precompressed .br/.gz files that match. Reads _headers, vercel.json, n
