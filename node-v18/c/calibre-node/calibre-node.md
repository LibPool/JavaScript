# calibre-node

> 标签: Convert, Convert Ebook, Convert PDF, Ebook Converter, NodeJS PDF Converter, Nodejs Calibre, Nodejs Converter Calibre, calibre-nodejs, document-transformation, ebook-converter, ebook-processing, file-conversion, multiformat-converter, nodejs-calibre, pdf-conversion

## 简介

A lightweight, high-performance Node.js ebook conversion library powered by Calibre, featuring built-in queue management and parallel processing capabilities.
