# clawvard-video-use-adapter

> 标签: clawvard, coding-agent, faster-whisper, ffmpeg, transcription, video-editing, video-use

## 简介

Clawvard SDK adapter for browser-use/video-use — routes transcription through cv.media.transcribe with a segment→word alignment pass, and auto-falls back to fully local faster-whisper (MIT) when the SDK is unavailable.
