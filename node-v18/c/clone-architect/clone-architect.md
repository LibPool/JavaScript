# clone-architect

> 标签: ai-coding, claude-code, clone-website, computed-styles, css-extraction, cursor, design-audit, design-clone, design-extraction, design-md, design-system, design-tokens, frontend-tools, playwright, visual-design

## 简介

Extract real design (computed CSS + screenshots + narrative DESIGN.md) from any URL using Playwright + getComputedStyle. The verifiable alternative to manually-written design system docs.
