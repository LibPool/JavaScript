# cv-tailor

> 标签: ai, ai-agent, ats, cli, cover-letter, curriculum-vitae, cv, docx, job-application, json-resume, mcp, mcp-server, model-context-protocol, pdf, pdf-generator, resume, tailor

## 简介

Turn your AI agent into your job-application assistant: an MCP server (and CLI) that tailors your CV to each job posting, tracks applications and generates PDF/DOCX/HTML/Markdown — all local, no API keys.
