# cra-prep

> 标签: components, cra, create-react-app, folders, lizkaufman, organise, organize, react, setup

## 简介

Automates the first few chores after running create-react-app, including making a components folder, setting up App folder, moving relevant files, and cleaning out extraneous demo code bits
