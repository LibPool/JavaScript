# create-angular-pro-app

> 标签: angular, angular-material, auth, bootstrap, crud, guards, jwt, scaffold, starter, template

## 简介

Scaffolds a production-ready Angular app with Bootstrap, Angular Material, JWT auth (login/guards/interceptor), URL guards, anonymous routes, and a working CRUD example. Always pulls the latest Angular.
