# cordova-plugin-privacyscreen-storyboard-yeetjia

> 标签: cordova, cordova-android, cordova-ios, ecosystem:cordova, privacy, storyboard

## 简介

Secures your app from displaying a screenshot in task switchers under Android and iOS. Keeps sensitive information private.
