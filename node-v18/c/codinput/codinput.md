# codinput

> 标签: composer, deepseek-harness, dsh, dsh-plugin, editor, markdown

## 简介

Codinput —— DSH Web 聊天输入框的代码编辑器风格替换插件：行号、Markdown 编辑/预览/分屏、底部/侧边/浮动停靠、Ctrl+Enter 发送纯文本 Markdown 源码。
