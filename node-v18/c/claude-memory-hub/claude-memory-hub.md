# claude-memory-hub

> 标签: claude, claude-code, context, embeddings, fts5, mcp, memory, persistent-memory, semantic-search, sqlite

## 简介

Persistent memory system for Claude Code. Zero API key. Zero Python. 7 hooks + MCP server + SQLite FTS5 + semantic search + knowledge graph + two-way Obsidian vault.
