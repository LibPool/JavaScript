# connect-gzip-static-html

> 标签: compress, connect, gzip, middleware

## 简介

gzip static middleware for connect with the default .html extension - serves compressed files if they exist, falls through to connect-static if they don't. Forked from connect-gzip-static ( https://github.com/code42day/connect-gzip-static )
