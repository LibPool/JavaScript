# crewdesk

> 标签: ai-agents, claude, claude-code, dashboard, developer-tools, hooks, multi-agent, permissions

## 简介

One local dashboard for all your Claude Code sessions: answer questions, approve permissions and send follow-ups, routed back to the exact session.
