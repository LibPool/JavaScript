# clickhouse-cargo

> 标签: clickhouse, database, db, performance

## 简介

Accumulates insert queries and commit them to clickhouse in batch jobs with retries on failure. 这个模块将向 Clickhouse 数据库的高频写入改为低频的批量插入。
