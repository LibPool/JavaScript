# crossexam

> 标签: ai, claude-code, cli, cross-examination, llm, multi-agent

## 简介

Same question, N AIs, N answers. Let them cross-examine each other. This name is reserved for the CrossExam protocol — the tool ships on PyPI (pip install crossexam). 本體在 PyPI，此為保留路標。
