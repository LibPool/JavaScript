# cursor-reads-xlsx

> 标签: ai, cli, converter, cursor, excel, spreadsheet, text, xlsx

## 简介

Converts .xlsx files into rich text dumps that AI coding agents (Cursor, Claude, etc.) can read — preserving values, formulas, formatting, colors, column widths, and frozen panes.
