# changelog-to-react-component

> 标签: anchor, changelog, github, html, keepachangelog, markdown, permalink, react

## 简介

CLI to convert a CHANGELOG.md following the http://keepachangelog.com convention to a react functional component with permalinks and a GitHub look and feel
