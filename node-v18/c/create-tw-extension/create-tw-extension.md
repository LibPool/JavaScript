# create-tw-extension

> 标签: cli, create, extension, generator, rolldown, rollup, rsbuild, rspack, scaffold, scratch, turbowarp, vite, webpack

## 简介

Scaffold a new TurboWarp/Scratch extension with the bundler of your choice (webpack, Rspack, Rsbuild, Rollup, Rolldown, or Vite).
