# com.echo.dailymission

> 标签: daily, dailymission, dailytask, echo, quest

## 简介

Daily-recurring quest engine for Echo games. One config-driven module that expresses both Daily Mission (fixed quest list, per-mission immediate rewards) and Daily Task (tiered random draw, star accumulator, auto-claimed milestones). Pluggable mission sel
