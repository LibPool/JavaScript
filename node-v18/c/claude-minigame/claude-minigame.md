# claude-minigame

> 标签: claude-code, clawd, crab, dino, game, minigame, terminal

## 简介

Clawd Runner — a Chrome-dino-style terminal minigame starring Clawd, the Claude Code crab. Ctrl+click the crab in your Claude Code statusline (or welcome screen) to play.
