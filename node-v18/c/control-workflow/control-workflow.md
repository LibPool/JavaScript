# control-workflow

> 标签: ai-workflow, claude, claude-code, drift-detection, framework, git-discipline, phased-development, session-management, state-machine

## 简介

Phased session-management framework for Claude Code. Every step closes with a commit, every phase with a tag. Mechanical drift detection between STATE.md and git keeps the work ledger always-correct.
