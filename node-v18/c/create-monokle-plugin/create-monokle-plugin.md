# create-monokle-plugin

> 标签: JavaScript

## 简介

Use this library to scaffold your custom Monokle validation plugin in seconds - which can then  be used locally or contributed to our [Monokle Community Plugins](https://github.com/kubeshop/monokle-community-plugins) repository.
