# cruncheevos-playtest

> 标签: achievements, cruncheevos, emulator, rcheevos, retroachievements, testing

## 简介

Playtest RetroAchievements achievements: record emulator memory as Test Scenarios, replay them against cruncheevos achievement logic in tests, and inspect every frame in a viewer
