> 标签: agent-skill, ai-coding-assistant, core-package, monorepo, pnpm, scaffolding, vue, vue3

## 简介

Transform Vue3 monolith projects into Monorepo core-package architecture (packages/core + apps/base-app). Supports 9 AI coding platforms with slash commands and 3 installation methods.
