# cors-somewhere

> 标签: cors, cross-domain, heroku, http-proxy, proxy

## 简介

CORS Somewhere is a fork of CORS Anywhere. CORS Anywhere is a reverse proxy which adds CORS headers to the proxied request. Request URL is taken from the path
