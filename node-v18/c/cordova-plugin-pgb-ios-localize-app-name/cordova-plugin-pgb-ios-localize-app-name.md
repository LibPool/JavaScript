# cordova-plugin-pgb-ios-localize-app-name

> 标签: .lproj, Application has localized display name, Bundle Display Name, CFBundleDisplayName, CFBundleLocalizations, CFBundleName, Info.plist, InfoPlist.strings, LSHasLocalizedDisplayName, appstore, cordova, cordova-ios, ecosystem:cordova, ios, localization, phonegap

## 简介

Allows localization of IOS App Name ('Bundle Display Name' or CFBundleDisplayName) when compiling PhoneGap/Cordova apps using build.phonegap.com (PhoneGap Build)
