# codevet-cli

> 标签: cli, dependency-audit, devsecops, gitleaks, sast, secrets, security, security-scanner, vulnerability-scanner

## 简介

Vet your code before it ships — a free, open-source security co-pilot that checks for leaked secrets, vulnerable dependencies, missing security middleware, and personal data flow, with real working fixes shown inline.
