# claude-can-speak

> 标签: claude, claude-code, hook, kokoro, piper, skill, speech, text-to-speech, tts, voice

## 简介

Let Claude Code decide what to say out loud: a skill that voices deliberate notifications (not every reply), plus an optional speak-everything Stop hook. Local neural TTS via Kokoro/Piper in Docker, gated on /voice.
