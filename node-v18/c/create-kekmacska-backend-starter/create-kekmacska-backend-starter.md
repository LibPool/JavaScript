# create-kekmacska-backend-starter

> 标签: backend, bun, express, minimal, mongodb, mongoose, node, nodejs, simple, starter

## 简介

A simple express backend project scaffolder. Doesn't contain much and doesn't help in cheating. Does even less than Vite on frontend, but can save quite a lot of time so you can start building your app instantly
