# character-evolution-dataset-1bit

> 标签: 1-bit, black-and-white, characters, chinese, dataset, evolution, glyphs, oracle-bone, zstd

## 简介

Single-file, random-access dataset of ~263k Chinese character-evolution glyph images, packed as 1-bit black & white into one ~35 MB file with a tiny reader for Node, the browser, and React Native.
