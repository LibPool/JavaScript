# cq-lerp

> 标签: clamp, container-queries, container-query, cqi, css, design-tokens, fluid, fluid-typography, interpolation, lerp, progress, responsive, sass, scss

## 简介

Make any CSS value scale with a container's width: degrees, seconds, font weights, percentages, plain numbers.
