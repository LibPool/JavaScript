# ccx-relay

> 标签: ai, claude, claude-code, cli, gemini, prompt-engineering, pty, terminal

## 简介

Transparent PTY wrapper for Claude Code (or any CLI) that lets you refine your prompt with Gemini AI before submitting it, without leaving your terminal session.
