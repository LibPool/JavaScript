# captcha-charle

> 标签: JavaScript

## 简介

1. lib 中写入自己的组件，如captcha.js 2. vite.config.js 引入captcha.js，并改名字 3. package.json中改name：captcha(文件名) + charles（标识符），和版本号 4. pnpm build 打包到dist中 5. 登录npm：npm login 后授权（我这里是我的谷歌邮箱） 6. 推到远程npm上：npm public 7. 项目中，npm i captcha.js
