# cascader-tree-select

> 标签: cascader, element, virtual-scroller, vue

## 简介

> 基于`element-ui`和`vue-virtual-scroller`的全量级联树选择器，结合虚拟列表逐级渲染，支持全选，在较大数据量上也有较高的性能
