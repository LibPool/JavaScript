# create-callback

> 标签: api, async, asynchronous, callback, cb, create, fn, function, handle, hybrid, hybridify, hybrids, is, is-async, isasync, promises, sync, synchronous, utils

## 简介

Create callback api from synchronous function. Same as `make-callback`, but won't handle generators and if async function is given returns it.
