# checktree

> 标签: JavaScript

## 简介

This component is a simple Angular implementation of Tree for heirarchical/categorical selection similar to [Angular Material Tree](https://material.angular.io/components/tree/examples#tree-checklist) with checkboxes. Please refer to this [implementation]
