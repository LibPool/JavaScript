> 标签: boilerplate, create-react-app, eslint, react, starter, tailwindcss, template, typescript

## 简介

This is a starter project for ReactJS applications. It is based on Create React App and includes some additional features like TailwindCSS, Typescript, ESlintrc and Husky, out the box.
