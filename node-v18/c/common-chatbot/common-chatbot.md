# common-chatbot

> 标签: JavaScript

## 简介

Utility abstraction layer meant to be used on top of Dialogflow (formerly API.AI) to allow you to write responses in one simple format, and it will subsequently build the code for the respective systems such as plain text API.AI responses, Facebook Messen
