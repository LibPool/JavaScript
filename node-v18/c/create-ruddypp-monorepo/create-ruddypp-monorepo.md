# create-ruddypp-monorepo

> 标签: create, express, monorepo, nextjs, starter, tailwind, turborepo, typescript, zod

## 简介

Scaffold a Turborepo monorepo with Express (TypeScript), Next.js (TypeScript + Tailwind) and a shared Zod package, always on the latest versions.
