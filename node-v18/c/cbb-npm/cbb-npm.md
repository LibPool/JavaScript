# cbb-npm

> 标签: baseball, basketball, beach, cbb, cfb, college, college football, field, football, hockey, hoops, ice, lacrosse, mbb, men, mens, ncaa, ncaa-w, ncaaf, ncaam, nfl, soccer-men, soccer-women, sports, statistics, volleyball, woemen, women, womens

## 简介

Retrieves sports data from a popular sports website as well as from the ncaa website, with support for men's and women's college basketball, NBA, WNBA, NFL and CFB.
