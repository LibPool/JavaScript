# callscript

> 标签: agents, ai-sdk, code-mode, llm, mcp, tool-calling

## 简介

a tool-calling script language for LLMs - the model authors ONE small script (plain JS, compiled to a validated, bounded, inert JSON plan - never executed) instead of calling tools one at a time. Adapter-based: mount AI SDK tools or plain { name, execute
