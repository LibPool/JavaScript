# claudecached

> 标签: cache, claude, claude-code, llm, mcp, model-context-protocol, token-savings

## 简介

Local caching/memory layer for Claude Code — avoids re-spending tokens on identical or near-duplicate queries. 100% local: SQLite + local embeddings, no telemetry, no external calls.
