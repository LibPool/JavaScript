# cereale

> 标签: class-transformer, class-validator, class-validator-alternative, decorators, dto, json, serialization, standard-decorators, typescript, validation

## 简介

Strongly typed JSON mapping and validation for TypeScript classes — validated domain objects, not validated data. A zero-dependency replacement for class-validator + class-transformer, on TC39 standard decorators.
