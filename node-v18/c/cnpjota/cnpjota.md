# cnpjota

> 标签: JavaScript

## 简介

cnpjota é um servidor MCP e CLI que oferece suporte à mudança do formato do CNPJ brasileiro prevista para 2026, fornecendo funcionalidades de validação, geração e auditoria para formatos numéricos atuais e alfanuméricos futuros.
