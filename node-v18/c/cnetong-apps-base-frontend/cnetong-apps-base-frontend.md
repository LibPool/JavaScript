# cnetong-apps-base-frontend

> 标签: JavaScript

## 简介

- api 旧的遗留的包,用来存放对服务器的 http 请求 - assets 开发代码静态资源,存放图片,json 等 - common 公共组件,可选 - libs 程序开发使用的工具包 - mock 写原型需要的后台数据模拟配置 - module 系统模块,业务逻辑代码 - plugin 自定义插件,必须引入,包含 panel pagetable 等 - resources 配置文件,国际化文件 - router vue-router 组件 - service 前端的'后台'服务,
