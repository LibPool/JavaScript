# cordova-plugin-file-remove-external

> 标签: cordova, cordova-android, cordova-ios, ecosystem:cordova, plugin

## 简介

Create a minimal cordova plugin which basically only consists of the plugin.xml where the WRITE_EXTERNAL_STORAGE permission is removed
