# cordova-open-admob

> 标签: ad, admob, ads, advertising, advertisment, cordova-android, cordova-ios, earn, ecosystem:cordova, flurry, google, iad, monetization, money, play, publicity, services, win

## 简介

Google AdMob Ads plugin for Cordova, Phonegap, Ionic/Angular and Intel XDK. Monetize your app with one javascript line. Android SDK v7.5, iOS SDK v7.3.1. Auto-detect internet connection.
