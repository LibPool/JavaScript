# cleancodejs

> 标签: angular, build-tools, clean, cli, comments, javascript, jsx, minify, node, production, react, remove, tsx, typescript, vue

## 简介

A fast CLI tool to remove JavaScript/TypeScript comments from files while preserving code functionality. Works with React, Angular, Vue, Node.js and all modern frameworks.
