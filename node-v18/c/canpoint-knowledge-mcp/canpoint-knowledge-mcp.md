# canpoint-knowledge-mcp

> 标签: knowledge-base, mcp, model-context-protocol, rag, search

## 简介

Knowledge base MCP for business projects: search and read project docs, hop reference links, and sync the latest docs after releases. Wrapper that runs the PyPI package via uvx.
