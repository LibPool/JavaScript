# cordova-plugin-measure-screenshot

> 标签: ar, arcore, arkit, cordova-android, cordova-ios, ecosystem:cordova

## 简介

Cordova plugin using ARKit(iOS) and ARCore(Android) to calculate distance of real world objects, with screenshots
