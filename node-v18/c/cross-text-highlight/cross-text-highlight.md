# cross-text-highlight

> 标签: vue, vue-search-highlight, 也对外暴露方法提供位置信息和文本, 关键字高亮, 匹配跨标签文本高亮并可带上标注序号, 可以选中文本右键点击复制

## 简介

``` npm i cross-text-highlight ``` # 基于vue-search-highlight 的跨标签可标注序号的文本高亮插件
