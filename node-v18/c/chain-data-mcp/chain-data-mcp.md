# chain-data-mcp

> 标签: ai-agent, arbitrum, base, blockchain, crypto, defi, erc20, ethereum, gas, mcp, model-context-protocol, onchain, optimism, polygon, portfolio, wallet, x402

## 简介

Live multi-chain on-chain data in ONE call for AI agents: a wallet's portfolio (native + ERC-20 + USD value) across Ethereum/Base/Polygon/Arbitrum/Optimism, token/contract info, live gas and token prices. MCP server + pay-per-call x402 API. No API key — p
