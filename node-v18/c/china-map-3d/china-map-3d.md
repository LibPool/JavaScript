# china-map-3d

> 标签: 3d-map, china-map, data-visualization, datav, gis, meshline, react-three-fiber, three.js, webgl

## 简介

基于 Three.js / React Three Fiber 的高质感 3D 浮雕中国地图与 GIS 数据可视化组件，支持 2D 转 3D 拔高生长动画、抛物线流光飞线、冲天动态光柱与立体云层。
