# cli-link

> 标签: JavaScript

## 简介

AgentPilot（npm 包 `cli-link`）提供一个手机端入口，把运行在个人电脑或开发机上的 Codex App Server 变成可以远程访问的工作台。你继续使用本机仓库、依赖、终端登录态和网络环境，手机上负责发任务、看输出、补充指令和查看代码变更。
