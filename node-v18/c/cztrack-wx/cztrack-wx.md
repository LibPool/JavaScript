# cztrack-wx

> 标签: JavaScript

## 简介

- 很多公司使用第三方埋点平台，自身无数据存储，而对于CDP等分析系统而言，数据源是前置条件，因此在不破坏业务方已存在的埋点体系下，额外采集并上报一份埋点数据。
