# curtiss-annotation-nomenclature

> 标签: annotation, book, can, curtiss, curtiss-annotation-nomenclature, nomenclature, note-taking, reading, typescript

## 简介

Official NPM package for The Curtiss Annotation Nomenclature (CAN) system - TypeScript-first with 100 standardized CAN codes, full type safety, validation, and formatting utilities for systematic annotations
