# cudos-blast

> 标签: blockchain, cosmos, cudos-blast, javascript, rust, smart-contracts, tooling

## 简介

Cudos Blast is a Node.js CLI tool designed to work with the Cudos blockchain. It allows you to scaffold, compile and test your Rust smart contracts.
