# com.mylads.arfoundationhelper

> 标签: ar, mylads, unity, utility

## 简介

AR Foundation is free and powerful. However, its editor user experience is not that good as other commercial SDKs like Vuforia oe EasyAR. (especially for Image Tracking) So I develop this tool to improve the editor experience. Forked from https://github.c
