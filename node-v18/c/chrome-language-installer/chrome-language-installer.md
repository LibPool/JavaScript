# chrome-language-installer

> 标签: installation

## 简介

"# ChromeLanguageInstaller"    This node js script will install the Chrome language pack provided in its directory(a .bdic file):   1. Language pack filename should be provided in settings.json   2. Language name should be provided in settings.json
