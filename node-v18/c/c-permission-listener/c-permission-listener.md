# c-permission-listener

> 标签: 上架, 安卓权限, 权限申请, 权限说明, 顶部蒙层

## 简介

uniapp项目，支持android平台全局监听权限的申请。基于uni.createRequestPermissionListener实现。解决软件在运行时，未见向用户告知权限申请的目的，华为上架被拒
