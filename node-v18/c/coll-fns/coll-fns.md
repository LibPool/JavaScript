# coll-fns

> 标签: composable, composite, denormalization, fetch, find, functional, hooks, joins, meteor, mongodb, protocol, publication, publish, query, reactive

## 简介

A functional interface to join MongoDB collections and add hooks before and after insertions, updates and removals.
