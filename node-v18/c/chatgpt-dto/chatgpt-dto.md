# chatgpt-dto

> 标签: DTO, GPT, OpenAI, ai, backend, chatgpt, class-transformer, class-validator, gpt-wrapper, json-schema, nodejs, openai-api, prompt-to-dto, server, typed-gpt, typescript

## 简介

A lightweight wrapper for OpenAI's GPT API with DTO support via class-validator and class-transformer. Designed for structured JSON output in TypeScript backends.
