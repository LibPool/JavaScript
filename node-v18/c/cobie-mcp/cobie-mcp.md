# cobie-mcp

> 标签: aec, asset-information, buildingsmart, cobie, facility-management, ifc, mcp, model-context-protocol, openbim

## 简介

MCP server for COBie (Construction Operations Building Information Exchange): asset and handover data from IFC for facility management. Part of the Flinker OpenBIM toolchain.
