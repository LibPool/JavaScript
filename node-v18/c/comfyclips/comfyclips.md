# comfyclips

> 标签: cli, dailymotion, facebook, instagram, linkedin, pinterest, reddit, rumble, snapchat, tiktok, twitter, video-downloader, vimeo, youtube, yt-dlp

## 简介

Interactive CLI to download video or audio from social media platforms (YouTube, TikTok, Instagram, Reddit, Pinterest, Vimeo, Dailymotion, Rumble, LinkedIn, Snapchat, Facebook, X/Twitter) via yt-dlp.
