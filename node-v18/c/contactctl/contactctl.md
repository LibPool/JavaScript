# contactctl

> 标签: ai-agents, b2b, cli, contacts, email-finder, email-verification, enrichment, gtm, sales

## 简介

CLI for AI agents to find, verify, and enrich B2B contacts. Work emails, phones, reverse email lookup, company/people search, and lookalikes — one command each, charged only when found.
