# create-blok-plugin

> 标签: blok, cli, generator, plugin, scaffold, useblok

## 简介

Scaffold a new plugin for the Blok visual editor. Zero-dep CLI that generates a typed plugin with a block, a custom field type, and a left-rail panel.
