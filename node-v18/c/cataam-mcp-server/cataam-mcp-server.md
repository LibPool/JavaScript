# cataam-mcp-server

> 标签: JavaScript

## 简介

MCP connector for Cataam — the GRC/compliance-automation platform (SOC2, GDPR, ISO27001). Exposes the /api/audit compliance surface and the OKF Context Engine as MCP tools.
