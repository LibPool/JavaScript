# cinebox

> 标签: cinebox, movie, moviebox, proxy, sdk, streaming, video

## 简介

MovieBox SDK for TypeScript — real movie data, search, play streams, and an optional /media proxy that streams video in the browser. Import it in your code; no API server needed.
