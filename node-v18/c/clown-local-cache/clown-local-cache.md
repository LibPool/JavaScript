# clown-local-cache

> 标签: JavaScript

## 简介

对 sessionStorage、localStorage、cookie的使用封装，便于开发使用。仅限于公司内部。 ### 安装 ``` yarn add clown-local-cache ``` ``` npm install clown-local-cache -S ``` ### 引用 ``` // web 环境下 import { LocalCache } from 'clown-local-cache' // uni 环境下 import { LocalCache }
