# corporate-taxid-checker-js

> 标签: EIN, EU, GST, ITIN, SSN, TIN, VAT, VATIN, VIES, checksum, company, compliance, finance, identification, international, javascript, node.js, number, tax, tax-id, tax-id-validation, tax-number, taxpayer, typescript, validation, validator, vat-number, vat-validation

## 简介

Validate tax identification numbers (TIN, VAT, EIN, GST, ITIN, SSN) for 150+ countries. Regex, checksum, and online VIES/government verification. TypeScript-first with LLM tool definitions.
