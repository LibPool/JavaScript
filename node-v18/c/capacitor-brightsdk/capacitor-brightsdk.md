# capacitor-brightsdk

> 标签: cordova-android, ecosystem:cordova

## 简介

Capacitor BrightSDK plugin (unofficial) enable [Capacitor](https://capacitorjs.com/) based apps to interact with the [Bright SDK](https://bright-sdk.com).
