# crashless

> 标签: async-errors, crashless, dashboard, error-handler, express, logging, metrics, middleware, monitoring, observability, prometheus, stability, telemetry, vegaa

## 简介

Production-ready observability for Node.js. Zero npm-dependency middleware that prevents Express servers from crashing and provides built-in monitoring.
