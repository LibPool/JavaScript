# claude-web-usage

> 标签: claude, claude-code, cli, monitoring, rate-limit, statusline, usage

## 简介

Reliable Claude Code usage monitoring via Claude Desktop's web session cookies. Bypasses OAuth API rate limiting with multiple sessions.
