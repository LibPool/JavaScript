# cep-parallel-search

> 标签: address, async, brasilapi, brazil, cep, correios, parallel, promise, viacep, zipcode

## 简介

Biblioteca Node.js para busca de CEP com múltiplas consultas em paralelo e tratamento robusto de erros, com cache que acelera a busca em até 5x
