# cordova-appivo-sibo-nfc

> 标签: cordova, cordova-android, ecosystem:cordova, nfc, plugin, rfid, sibo

## 简介

A Cordova plugin that enables reading NFc tags using RFID/NFC Reader for Sibo Tablet.
