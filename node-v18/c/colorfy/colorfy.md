# colorfy

> 标签: ansi, ansi color, ansi colors, ansicolor, ansicolors, cli, cli color, cli colors, clicolor, clicolors, color, color codes, colorfy, colorify, colorize, colors, colour, commandline, console, console color, console colors, terminal, tty, tty color, tty colors

## 简介

Colorfy colorize your console with pretty ansi color codes. It has static color methods and supports a chained colorization of your tty console output.
