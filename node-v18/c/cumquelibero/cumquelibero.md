# cumquelibero

> 标签: consectetur, focus, fugiat, javascript-polyfill, polyfill, whatwg, whatwg-dom

## 简介

JavaScript polyfill for the WHATWG spec of focusOptions, that enables a set of options to be passed to the focus method.
