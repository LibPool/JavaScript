# candramov

> 标签: box, canvas, chrome, cross browser support, draw, edge, firefox, library, lines, move shapes, pencil, rectangle, shapes, square, triangle

## 简介

This is a canvas library which anybody can use in browser to integrate drawing basic shapes functionality into your web applications such as Box, Triangle, Lines, Circle, ellipsis and change circle x and y radius using just your mouse to draw and enable s
