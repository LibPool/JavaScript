# create-repoctl

> 标签: create-app, monorepo, repoctl, scaffold, template

## 简介

Create a repoctl-managed pnpm and Turborepo workspace. Non-interactive: pnpm create repoctl@latest <dir> -- --yes --templates vue-hono
