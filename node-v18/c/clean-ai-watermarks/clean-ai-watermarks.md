# clean-ai-watermarks

> 标签: ai, ai-watermark, chatgpt, chatgpt-watermark, claude, claude-watermark, cli, codex, hidden-characters, invisible-characters, pre-commit, steganography, text-sanitizer, unicode, watermark-remover, watermarks-remover, zero-width-space, zwsp

## 简介

Find and remove hidden Unicode watermark carriers from text files. Streams any size, preserves every byte it does not delete, never touches visible text.
