# crontab-vue

> 标签: cron, crontab, vue, vue-crontab, vuecron

## 简介

vue 的 cron 组件，支持解析/反解析 cron 表达式，生成最近五次的符合条件时间，依赖 vue2 和 element-ui [demo](https://small-stone.github.io/vCrontab/dist/) ![](public/demo.png)
