# copy-dir-webpack-plugin

> 标签: JavaScript

## 简介

这是一个用于Webpack构建工具的插件，它提供了复制文件和文件夹的功能，可以在Webpack打包时自动地将指定的文件或文件夹拷贝到输出目录。
