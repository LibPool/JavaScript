# contextsmith

> 标签: ai, anthropic, component, embeddings, llm, llm-apps, openai, rag, react, retrieval-augmented-generation, vector-store

## 简介

Production-grade retrieval-augmented generation pipeline for React. Index files, URLs, or text — query with any LLM. In-memory vector store by default, pluggable for Pinecone, Weaviate, pgvector, and more.
