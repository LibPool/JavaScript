# config-driven-form

> 标签: drag-and-drop, form, form-builder, headless-ui, json-schema, react, tailwindcss, validation

## 简介

A highly scalable, production-ready React form library that dynamically generates beautiful, fully validated forms directly from standard JSON Schema, complete with a drag-and-drop Visual Form Builder.
