# celestial-chart

> 标签: astronomy, canvas, cartography, celestial, constellations, d3, planetarium, projection, sky map, star chart, svg, visualization

## 简介

Interactive celestial map for the browser — a modernised fork of d3-celestial (D3 v7, ES modules, TypeScript types, multiple maps per page)
