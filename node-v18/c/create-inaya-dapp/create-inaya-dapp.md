# create-inaya-dapp

> 标签: create-app, inaya, nextjs, scaffolding, web3

## 简介

npx scaffolding tool for Inaya Network dApps -- pre-wires a Next.js app with @inaya-network/custody-sdk, @inaya-network/react, Tailwind, and wagmi/viem.
