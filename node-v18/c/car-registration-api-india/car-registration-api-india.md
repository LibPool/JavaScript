# car-registration-api-india

> 标签: car, india, registration, vahan

## 简介

Get car information from a Indian number plate. An account username is required, which you can get from http://www.vehicleregistrationapi.com

## 官网

- 源码仓库：http://www.vehicleregistrationapi.com/
- npm 页面：https://www.npmjs.com/package/car-registration-api-india
