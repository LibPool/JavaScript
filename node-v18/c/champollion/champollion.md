# champollion

> 标签: anthropic, auto-translate, deepl, gemini, hugo, i18n, i18next, internationalization, l10n, language-pairs, localization, machine-translation, markdown, multilingual, next-intl, openai, openrouter, seo, toml, translation, yaml

## 简介

Research-grade translation engine for i18n projects. Pluggable methods, per-pair quality tiers, and deterministic script converters. Supports JSON (next-intl, i18next), TOML, and YAML (Hugo).
