# candy-logger

> 标签: angular, browser, console, console-panel, dark-mode, debug, developer-tools, devtools, logger, logging, mobile-debug, overlay, react, svelte, table, tags, typescript, ui, vue, zero-dependency

## 简介

A browser console panel that can't crash your app — ~6 kB gzipped core with a lazy-loaded UI, zero dependencies, TypeScript-first. Safe serialization (circular refs, Errors with stacks, Map/Set/BigInt), CSP-friendly, table view, tags, pins, search, dark/l
