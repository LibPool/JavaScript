# cmyk-preview-toolkit

> 标签: cmyk, color, color-conversion, color-management, color-palette, color-picker, color-space, delta-e, dual-color, hex-to-cmyk, palette, pdf, pdf-lib, pdfjs, prepress, press, preview, print, print-design, react-color, rgb-to-cmyk, srgb

## 简介

Dual CMYK/sRGB color handling for browser-based PDF editors. Convert between CMYK, RGB, HSL, and CIE Lab color spaces with press-accurate preview and palette snapping.
