# @dsh-xhl/dsh-live-inspector

> 标签: JavaScript

## 简介

Git Tree and live diff inspector for the DeepSeek Harness web surface: watch every file the agent touches, review changes turn by turn, and undo a specific turn or a single hunk — with the filesystem reached through the plugin's own Host HTTP routes.
