# @qkix/better-blocks-astro-renderer

> 标签: astro, background-color, better-blocks, blocks, blocks-renderer, cms, color, diagram, headless-cms, highlight, katex, latex, math, mermaid, renderer, rich-text, strapi, strapi-v5, text-color

## 简介

Astro renderer for Strapi v5 Blocks content with full Better Blocks plugin support - colors, tables, to-do lists, media embeds, alignment, and more. Native Astro components, zero client-side JavaScript.
