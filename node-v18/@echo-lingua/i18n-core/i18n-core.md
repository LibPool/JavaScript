# @echo-lingua/i18n-core

> 标签: echo-lingua, gettext, i18n, po

## 简介

Shared, dependency-free primitives for Echo Lingua i18n: the el-* flag vocabulary + conflict detection, CLDR plural tables, the catalog key, and the compiled-catalog types.
