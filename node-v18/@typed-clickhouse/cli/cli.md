> 标签: analytics, cli, clickhouse, data-engineering, database, ddl, migration, migrations, olap, schema, schema-as-code, sql, type-safe, typescript

## 简介

CLI for typed-clickhouse: diff your TypeScript-declared ClickHouse schema against a live database, review the migration plan, and apply it.
