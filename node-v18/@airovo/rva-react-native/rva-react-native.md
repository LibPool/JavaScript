# @airovo/rva-react-native

> 标签: adaptive, image, responsive, rva, visual-asset, wasm

## 简介

React Native adapter for RVA: renders the <rva-image> web component (WASM core) inside a WebView, with an optional native-module path over the shared C ABI.
