# @schaeferanjon/claude-code-wechat-channel

> 标签: ai-agent, channel, claude-code, clawbot, mcp, wechat

## 简介

Claude Code Channel plugin for WeChat — bridge WeChat messages into Claude Code sessions via the official ilink API. Fork with image/file sending support.
