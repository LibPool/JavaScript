# @hammerock/cca-sdk

> 标签: auction, cca, continuous-clearing-auction, ethereum, sdk, token-launch, uniswap, viem

## 简介

TypeScript SDK for Uniswap Continuous Clearing Auctions (CCA): discovery across every factory version, live state, Q96 math and bid construction. Ethereum, Base, Unichain, Arbitrum and their testnets.
