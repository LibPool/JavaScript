# @emeraldlabs/emvault-jade

> 标签: bitcoin, blockstream, hardware-wallet, jade, psbt, webserial

## 简介

Dependency-free Blockstream Jade WebSerial (USB) driver for the browser — Bitcoin PSBT signing and device onboarding over Jade's CBOR-RPC protocol.
