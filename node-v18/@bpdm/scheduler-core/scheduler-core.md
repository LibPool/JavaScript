# @bpdm/scheduler-core

> 标签: calendar, design-system, headless, layout-engine, scheduler, typescript

## 简介

Framework-agnostic core for the bpdm Scheduler — date math, an overlap layout engine, a data-source contract, and state. Zero runtime dependencies.
