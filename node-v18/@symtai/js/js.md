# @symtai/js

> 标签: directions, geocoding, isochrone, location-intelligence, map-matching, maps, matrix, openstreetmap, osrm, pakistan, routing, symt

## 简介

Official JavaScript/TypeScript SDK for the Symt maps & location-intelligence platform — routing, distance matrix, isochrones, geocoding, autocomplete and map-matching. Works in Node 18+, browsers and React Native.
