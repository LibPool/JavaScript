# @ngx-tc/list

> 标签: angular, angular UI, angular components, angular custom list, angular list, list, ng, ngx

## 简介

Angular library that provides customizable and reusable components for creating various types of lists in applications, making it easy to create robust and responsive list-based interfaces.
