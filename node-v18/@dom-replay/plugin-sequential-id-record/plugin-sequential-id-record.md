# @dom-replay/plugin-sequential-id-record

> 标签: dom-replay

## 简介

Use this plugin in combination with the [@dom-replay/plugin-sequential-id-replay](../core-plugin-sequential-id-replay) plugin to record and replay events with a sequential id. See the [guide](../../../guide.md) for more info.
