# @db-state/vue

> 标签: db-state, indexeddb, offline-first, reactive, realtime, state-management, sync, vue, vue3, websocket

## 简介

Tiny reactive Vue 3 client for db-state: typed tables, listRef / idsRef / countRef, login, sync, offline cache. ~5.4 KB brotli.
