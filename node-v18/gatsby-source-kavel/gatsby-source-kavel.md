# gatsby-source-kavel

> 标签: ai, gatsby, gatsby-plugin, gatsby-source-plugin, image-generation, kavel, text-to-image

## 简介

Gatsby source plugin for Kavel: generate AI images from prompts at build time and query their URLs with GraphQL. Free tier, no API key needed.
