# @rebilder/profiles

> 标签: agents, ars, json, profiles, schema, spec, vocabulary

## 简介

Open, versioned JSON vocabulary of the facts a given kind of page should expose to agents. Data, not logic: zero runtime dependencies, JSON is the distribution format so non-JavaScript implementations can consume it directly.
