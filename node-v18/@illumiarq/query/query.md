# @illumiarq/query

> 标签: JavaScript

## 简介

LumiARQ query bridge — framework-agnostic loader bridge. TanStack Query is the default adapter, not a required dependency. Use SWR, Apollo, or plain fetch via @lumiarq/query/core.
