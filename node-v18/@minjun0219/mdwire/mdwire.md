# @minjun0219/mdwire

> 标签: agent, ai, chatbot, codemirror, github, lezer, llm, markdown, notion, react, slack, slack-bot, streaming, telegram, telegram-bot, wasm

## 简介

Send LLM-generated Markdown to Telegram, Slack, GitHub and Notion without it breaking: repaired, rendered for each channel and split within its limit, streaming included. Also safe HTML and React.
