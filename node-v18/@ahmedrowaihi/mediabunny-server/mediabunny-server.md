# @ahmedrowaihi/mediabunny-server

> 标签: bun, codec, decode, decoding, deno, encode, encoding, ffmpeg, libav, libavcodec, mediabunny, node, nodeav, polyfill, server

## 简介

Adds full video and audio decoder and encoder support to Mediabunny for use in server-side environments (Node, Bun, Deno). Based on NodeAV.
