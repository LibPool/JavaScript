# @enjoys/voice-changer

> 标签: audio, audioworklet, dsp, pitch-shift, react, voice-changer, webassembly

## 简介

Plug-and-play real-time browser voice changer (pitch / robot / alien / villain / male / female) — Rust DSP compiled to WebAssembly, run in an AudioWorklet, with a framework-agnostic engine and a React hook.
