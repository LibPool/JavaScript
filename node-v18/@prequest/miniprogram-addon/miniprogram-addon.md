# @prequest/miniprogram-addon

> 标签: XMLHttpRequest, fetch, http, https, interceptor, middleware, request

## 简介

小程序附加包.提供了上传和下载文件的封装，可以与 `@prequest/miniprogram` 共享全局配置、全局中间件等功能。
