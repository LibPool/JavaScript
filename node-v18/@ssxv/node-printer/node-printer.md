# @ssxv/node-printer

> 标签: cross-platform, cups, napi, native, printer, printing, windows

## 简介

Cross-platform N-API native printing bindings for Node.js (Windows & POSIX/CUPS). Requires Node.js >=18 and libcups >=1.6 for POSIX builds.
