# n8n-nodes-mediasfu

> 标签: ai-agent, mediasfu, n8n-community-node-package, phone-calls, recording, sip, video, voice-ai, webrtc

## 简介

n8n nodes for MediaSFU: start AI agent phone calls, create video rooms, and trigger workflows when rooms start or end, recordings are ready, or calls end.
