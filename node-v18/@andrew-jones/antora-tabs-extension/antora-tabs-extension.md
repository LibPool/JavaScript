# @andrew-jones/antora-tabs-extension

> 标签: antora, antora-extension, asciidoctor, tabs

## 简介

An Antora extension that integrates @asciidoctor/tabs, automatically injecting the required CSS and JS assets and registering the Asciidoctor extension.
