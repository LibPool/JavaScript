# @qrcommunication/gigapdf-lib

> 标签: ocr, office-to-pdf, pdf, pdf-editor, pdf-forms, pdf-redaction, pdf-to-docx, wasm, zero-dependency

## 简介

TypeScript SDK for gigapdf-lib — a Rust→WASM document engine with no third-party PDF/Office/image library: read/edit/render, OCR, full-text search, AcroForm fields (read · fill · create), annotations, signing, encryption, PDF↔Office/HTML/RTF conversions,
