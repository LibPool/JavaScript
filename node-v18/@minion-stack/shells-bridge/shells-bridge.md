# @minion-stack/shells-bridge

> 标签: JavaScript

## 简介

In-VM bridge process for Minion Shells — speaks @minion-stack/shared frames upstream to the gateway and ACP/JSON-RPC downstream to the local harness (HERMES, Claude Code, Codex, etc.).
