# @nuxt-customer-portal/ui

> 标签: JavaScript

## 简介

Neutral shell primitives and fallback layouts for Nuxt Customer Portal. Hosts can override every layout and branded component while retaining the shared feature registry, session state, and navigation contracts from core.
