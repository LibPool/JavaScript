# @nodepay/vietqr

> 标签: JavaScript

## 简介

Unified VietQR bank-transfer driver interface over @nodepay/bluecom and @nodepay/payos — createPayment/queryStatus/handleWebhook behind one VietQrGateway contract, per driver subpath (./bluecom, ./payos) so importing one driver never resolves the other pr
