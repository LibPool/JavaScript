# @nodepay/gateway

> 标签: JavaScript

## 简介

Unified gateway/e-wallet driver interface over @nodepay/momo, @nodepay/vnpay, and @nodepay/zalopay — createSession/queryStatus/refund/capture/cancel behind one PaymentGateway contract, per driver subpath (./momo, ./vnpay, ./zalopay) so importing one drive
