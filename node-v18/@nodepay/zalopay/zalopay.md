# @nodepay/zalopay

> 标签: JavaScript

## 简介

ZaloPay payment gateway integration (Standard Payment, QuickPay, AgreementPay, Disbursement, ZOD) — framework-agnostic core usable from Express/Fastify/plain Node, plus an optional NestJS module (`@nodepay/zalopay/nestjs`) supporting single- and multi-ten
