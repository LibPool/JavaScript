# @ngbracket/a11y-testing

> 标签: a11y, accessibility, accessible-name, angular, aria-live, axe, axe-core, focus, focus-trap, keyboard, ngbracket, testbed, testing, vitest

## 简介

Accessibility helpers for Angular component tests in Vitest and TestBed: axe checks that name the owning component, key presses that do what the browser does, real Tab order, focus return and focus trap checks, computed names, tab-order snapshots, and liv
