# @yeets-ai/embed

> 标签: JavaScript

## 简介

Vanilla-JS SDK target for non-React apps (Vue, Angular, plain HTML) — also loadable as a plain <script> tag via a CDN-hosted global bundle (dist/embed.global.js). Wraps @yeets/core.
