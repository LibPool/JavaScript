# dsh-plugin-prompt-inspiration

> 标签: composer, deepseek-harness, dsh, dsh-plugin, llm, prompt, prompt-engineering

## 简介

DeepSeek Harness plugin: a sparkle button beside the composer that reads your draft and the project's docs, then rewrites the draft into a fuller, better-structured, more token-efficient prompt. Click again to undo.
