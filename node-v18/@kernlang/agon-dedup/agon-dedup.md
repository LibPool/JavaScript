# @kernlang/agon-dedup

> 标签: JavaScript

## 简介

Python sidecars for Agon AI — semantic embeddings (fastembed/MiniLM) and tree-sitter syntax validation. Bridged over stdin/stdout JSON. Ships .py files that the @kernlang/agon-core bridges spawn at runtime.
