# @kernlang/agon-engines

> 标签: agon, ai, claude, cli, engine, kernlang, pty

## 简介

Engine substrates that drive third-party CLI/API agents on behalf of agon. Polyglot: TS twin in this directory, Python twin in .py files side-by-side.
