# @accurona/core

> 标签: floor-plan, keymap, network-diagram, scene-format, units, zod

## 简介

Accurona's shared, framework-free core for Axonometra and Reticulyne: the scene format (a Zod schema, with a generated JSON Schema), length units and the shared keymap.
