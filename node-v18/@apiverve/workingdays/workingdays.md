# @apiverve/workingdays

> 标签: business days api, count working days, free working days api, number of working days per month, working days api

## 简介

Working Days is a working days and business days API that counts the working days and non-working days for any country and month. Pass a two-letter country code and month number to get total counts, working date lists, and non-working days marked with hol
