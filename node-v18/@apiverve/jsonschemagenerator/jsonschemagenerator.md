# @apiverve/jsonschemagenerator

> 标签: create a json schema, generate json schema from json, json schema, json schema generator, json to json schema

## 简介

JSON Schema Generator is a JSON to JSON Schema API: it inspects sample JSON payloads and generates Draft-07 JSON Schema definitions with inferred types and property formats. It identifies formats like emails and dates, applies custom titles, and lists all
