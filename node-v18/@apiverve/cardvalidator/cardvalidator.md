# @apiverve/cardvalidator

> 标签: bin lookup, card validator api, credit card brand detection, luhn algorithm check, validate credit card number

## 简介

Card Validator checks whether a card number is valid, identifies the card brand, and flags risk. It runs the Luhn checksum, detects the scheme (Visa, Mastercard, Amex and more), returns the PCI-safe BIN and last 4 digits, flags known processor test cards,
