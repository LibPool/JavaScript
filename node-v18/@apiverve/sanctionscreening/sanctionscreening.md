# @apiverve/sanctionscreening

> 标签: ofac api, ofac check api, ofac sanctions list api, ofac search api, sanctions screening api

## 简介

Sanctions Screening checks a person or company name against the US Treasury OFAC Specially Designated Nationals (SDN) list. It returns scored matches with aliases, dates of birth, addresses and sanctions programs so you can decide whether to block or revi
