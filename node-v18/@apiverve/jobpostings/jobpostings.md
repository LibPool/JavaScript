# @apiverve/jobpostings

> 标签: company jobs api, job listings api, job listings by company, job postings api, jobs api

## 简介

Job Postings is a jobs API that returns the open positions on a company's public career board. Every job comes back in the same shape: title, department, team, locations, remote and workplace type, employment type, posting date and apply link. Filter by k
