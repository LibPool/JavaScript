> 标签: angular, angular-command-palette, angular-component, angular22, cmd-k, cmdk, command-menu, command-palette, fuzzy-search, keyboard-navigation, navigation, ngx, search, spotlight

## 简介

A keyboard-driven command palette for Angular. Auto-registers routes from your Router config, supports custom commands and async search providers.
