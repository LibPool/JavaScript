# @the_viveksingh/vivek-ui

> 标签: accessible, ai-chat, aria, charts, chat-ui, component-library, css-variables, datatable, design-system, headless, nextjs, react, react-server-components, shadcn-alternative, tailwind-alternative, typescript, ui, wcag, zero-dependency

## 简介

A free React component library with zero runtime dependencies: 109 accessible, server-safe components and 10 SVG charts. Layout, forms, overlays, page sections, AI chat, DataTable. One install, one CSS import, no Tailwind, no config. React 18/19 and Next.
