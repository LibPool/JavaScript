# @uploadcare/cdn-url

> 标签: builder, cdn, image, parser, transformations, uploadcare, url, video

## 简介

Build and parse Uploadcare CDN URLs: transformations, groups, proxy, video/document conversions. Typed, atomic, tree-shakeable.
