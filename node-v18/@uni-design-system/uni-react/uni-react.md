# @uni-design-system/uni-react

> 标签: JavaScript

## 简介

EXPERIMENTAL — the React implementation of the Uni Design System. Version-matched to @uni-design-system/uni-angular but not at parity: a small subset of components, minimal tests. Not recommended for production.
