# @proteus-vue/devtools

> 标签: JavaScript

## 简介

Proteus DevTools 面板（devtools-plan UI 层）：十视图（时间轴/火焰图/状态·时间旅行·值编辑/路由/根因/组件/页面/依赖图/设备/所有权）+ 一键接入 + Vue DevTools 插件（Timeline/Inspectors）+ 开放数据源（WS/CDP 协议）——浏览器端 dev 工具，不随业务产物发布
