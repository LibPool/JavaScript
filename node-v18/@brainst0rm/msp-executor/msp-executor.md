# @brainst0rm/msp-executor

> 标签: JavaScript

## 简介

ToolExecutor implementation for @brainst0rm/endpoint-stub that bridges relay-side dispatch into BrainstormMSP's god-mode REST API. Translates a CommandEnvelope into POST /api/v1/god-mode/execute, preserving the relay's command_id end-to-end via X-Brainsto
