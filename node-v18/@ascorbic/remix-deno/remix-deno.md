# @ascorbic/remix-deno

> 标签: JavaScript

## 简介

`@remix-run/deno` package is temporarily inlined within this directory while Deno support is experimental. In the future, this directory would be removed and Remix + Deno apps would import `@remix-run/deno` from some URL.
