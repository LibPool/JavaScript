# @unified-communications/meeting-plugin

> 标签: JavaScript

## 简介

Vue 3 集成插件，安装后直接引用。插件提供应用分享建会组件和平台用户 iframe 组件，负责受限会话传递并承载 Unified Communications Platform 的原生会议页面，不包含 Jitsi/lib-jitsi。
