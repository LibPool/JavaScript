# @libs-ui/services-diagram-draw

> 标签: JavaScript

## 简介

> Bộ ba service Angular quản lý toàn bộ vòng đời diagram flow: tính toán tọa độ, render node động, vẽ SVG connector, quản lý kéo-thả và điều hướng luồng giữa các element.
