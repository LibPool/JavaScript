> 标签: checklist, code-quality, pi, pi-coding-agent, pi-package, plan, task-discipline

## 简介

Task-checklist discipline for pi coding agent: a session-only desktop_update_plan tool (never executes commands, never touches project files) plus the checklist guideline for systemPrompt injection. Split out of pi-desktop's built-in desktop-policy so CLI
