# @vcueto/agent-viz

> 标签: agent, claude, claude-code, copilot, copilot-cli, dashboard, github-copilot, hooks, multi-agent, observability, sse, tracing, visualizer

## 简介

Real-time visualizer for Claude Code and GitHub Copilot CLI sessions: live event stream, token tracking, multi-agent topology with per-source badges, plus a token observatory built on the bundled netgain analysis engine.
