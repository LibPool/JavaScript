# @hacky.software/opencode-autocompact

> 标签: autocompact, compact, compaction, context, opencode, opencode-plugin, session, tokens

## 简介

Claude Code-style autocompact for OpenCode V2 with a per-session threshold: /autocompact 500k compacts a session and its children once the live context reaches that many tokens.
