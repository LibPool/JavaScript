# @trismegisto/maps

> 标签: JavaScript

## 简介

Hermes Design System — mapas Angular independentes (mapas base embutidos do mundo e do Brasil, coroplético, marcadores, popups, vetores SVG e GeoJSON; tiles opcionais) com tema dos tokens, teclado e i18n
