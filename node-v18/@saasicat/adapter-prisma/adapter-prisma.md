# @saasicat/adapter-prisma

> 标签: JavaScript

## 简介

Prisma + PostgreSQL persistence for SaaSiCat: one standard bundle for core, catalog, entitlement, tenant billing, Admin resources and promo, plus individual adapters for custom compositions.
