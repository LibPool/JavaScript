# @jesse1004/swaggermock-server

> 标签: JavaScript

## 简介

主要功能： 1. 域名转发功能 2. 集成了mock功能 3. 可通过设置配置，一键导入swagger接口数据并生成mock数据 4. 可使用相同域名做转发或mock
