# @starci/stylelint-canon

> 标签: canon, starci, stylelint, stylelint-plugin

## 简介

The StarCi CSS lint canon (HFS R61): grammar tokens only, raw brand values only in brand.css, no !important, a global sheet that only imports and declares tokens, and no token redefined in a CSS module.
