# @jsonjoy.com/collaborative-monaco

> 标签: binding, collaborative, collaborative-editor, contenteditable, crdt, editor, input, json, json-crdt, monaco, monaco-editor, monaco-editor-binding, multiplayer, textarea

## 简介

Binding for collaborative editing support in Monaco Editor. Connects JSON CRDT str node to Monaco Editor.
