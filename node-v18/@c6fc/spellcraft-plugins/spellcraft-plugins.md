# @c6fc/spellcraft-plugins

> 标签: aws, gcp, spellcraft, terraform

## 简介

The SpellCraft plugin collection: AWS and GCP credentials, Terraform lifecycle and state backends, and resource factories, as one nested Jsonnet namespace.
