# @exav/viewer

> 标签: cad, docx, dwg, dxf, ifc, pdf, react, tiff, viewer, wasm, webassembly, xlsx

## 简介

An embeddable file viewer for the browser: PDF, images (TIFF, BMP and more through memory-safe WebAssembly), DWG and DXF drawings, Word, Excel, PowerPoint, CSV, IFC and STL models, video, audio, and what is inside an archive. Each format's engine loads on
