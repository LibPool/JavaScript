# koishi-plugin-chatluna-envsense

> 标签: chatbot, chatluna, koishi, napcat, onebot, plugin

## 简介

ChatLuna 环境感知工具集：为 Agent（plugin）模式按需注册群聊/用户信息查询与合并转发（聊天记录）读取工具，并修复 chatluna 对引用合并消息的处理（仅 NapCat/onebot 生效）
