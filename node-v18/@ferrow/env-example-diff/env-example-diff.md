# @ferrow/env-example-diff

> 标签: ci, diff, dotenv, env, environment-variables, secrets

## 简介

Keep .env and .env.example honest: parse dotenv format, diff two files for drift and leak risk, and generate a safe .env.example. Zero runtime dependencies.
