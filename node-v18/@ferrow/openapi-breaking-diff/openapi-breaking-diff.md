# @ferrow/openapi-breaking-diff

> 标签: api-diff, api-versioning, breaking-changes, ci, openapi, swagger

## 简介

Compare two OpenAPI 3 documents and categorize changes as breaking or non-breaking, with JSON paths. Zero runtime dependencies.
