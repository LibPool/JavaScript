# @ferrow/fuzzy-match-scorer

> 标签: agent-tools, damerau-levenshtein, fuzzy-match, jaro-winkler, levenshtein, string-similarity, token-set-ratio, typo-correction

## 简介

Zero-dependency fuzzy string matching: Levenshtein, Damerau-Levenshtein, Jaro-Winkler, and order-insensitive token-set scoring, with bestMatch/rankMatches helpers for resolving typo'd names against a candidate list.
