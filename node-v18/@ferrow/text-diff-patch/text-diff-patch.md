# @ferrow/text-diff-patch

> 标签: agent-tools, apply-patch, diff, myers-diff, patch, text-diff, unified-diff, word-diff

## 简介

Zero-dependency line-based Myers diff (O(ND)) producing unified-diff hunks, with fuzzy patch application, reject reporting, and word-level intra-line diff highlighting.
