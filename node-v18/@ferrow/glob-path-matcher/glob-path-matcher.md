# @ferrow/glob-path-matcher

> 标签: agent-tools, brace-expansion, gitignore, glob, glob-matcher, minimatch, path-matching, wildcard

## 简介

Zero-dependency glob path matching: *, **, ?, [abc]/[a-z] classes, {a,b} braces, negation, dotfile policy, case sensitivity, a compile() reusable matcher, and matchList() with .gitignore-style negation-order semantics.
