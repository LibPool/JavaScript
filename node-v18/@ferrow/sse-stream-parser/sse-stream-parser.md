# @ferrow/sse-stream-parser

> 标签: ai-agents, anthropic, llm, openai, parser, server-sent-events, sse, streaming

## 简介

Incremental Server-Sent Events parser for LLM streaming — handles multi-line fields, comments, CRLF/LF, chunk-boundary splits, [DONE] convention, and JSON-delta accumulation. Zero runtime dependencies.
