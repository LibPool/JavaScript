# @makerkit/postgres-schema

> 标签: ai-agents, claude-code, codex, database, mcp, postgres, schema, supabase

## 简介

Lets coding agents read a Postgres database schema: tables, columns, foreign keys, indexes, functions and enums, from the live database or from declarative SQL schema files.
