# @nodatachat/protect

> 标签: aes-256, ai-security, claude-code, dotenv, encryption, env, env-encryption, nodata, protect, secret-management, secrets, security, vault, zero-knowledge

## 简介

Encrypt .env secrets with AES-256-GCM. Decrypt in memory only. Cryptographic proof of every access. Claude Code Skill included.
