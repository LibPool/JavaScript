# @guidedreel/core

> 标签: react, reels, remotion, short-video, shorts, typescript, video-editor, video-generator

## 简介

GuidedReel video creation engine in one package: schemas, timeline engine, templates, React editor, storage, providers and the Remotion renderer. Apps depend on this alone.
