# @claxedo/sandbox-manager

> 标签: agents, boat, claxedo, cloudflare, docker, modal, sandbox, vercel

## 简介

Sandbox lifecycle manager with epoch-based leases and pluggable drivers for Modal, Vercel Sandbox, Cloudflare, Boat, and Docker
