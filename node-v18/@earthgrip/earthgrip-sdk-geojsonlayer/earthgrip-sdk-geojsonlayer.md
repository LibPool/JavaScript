# @earthgrip/earthgrip-sdk-geojsonlayer

> 标签: JavaScript

## 简介

实现了类似ArcGis的图层管理机制，只需要一个geojson的json文件或者json数据地址，即可加载这些json数据，提供了点线面三种形式的数据类型，可以对数据进行批处理进行加载，目前经过测试可以同时加载10万个点，10万个线，10万个面，并且加载完成之后可以流畅运行相关程序，另外提供了图层的标注显示，可以设置常显示与指定距离显示，目前因为性能问题指定距离暂时只能显示离摄像机最近的200个要素的标注，由于是本人初次写类似的工具库代码可能存在问题，可以随时提出与作者联系。具体使用方法见下文：
