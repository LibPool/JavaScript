# eslint-plugin-import-structure

> 标签: eslint, eslint-plugin, eslintplugin, import, import-structure, imports, oxlint

## 简介

ESLint and Oxlint rules that keep a module graph layered and free of cycles, with package.json "#" imports as the layer order.
