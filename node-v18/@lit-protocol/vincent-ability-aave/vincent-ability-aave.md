# @lit-protocol/vincent-ability-aave

> 标签: JavaScript

## 简介

A Vincent Ability that acts as a secure, gated signer for Aave v3 operations. It is designed to work with ERC-4337 Smart Accounts (UserOperations) and EOAs (Transactions).
