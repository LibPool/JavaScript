# @nizam-os/resource-core

> 标签: api, catalog, json-api, jsonapi, openapi, postgres, postgresql, schema, zod

## 简介

One declaration per PostgreSQL table, keyed by its database names and typed by the catalog @nizam-os/pg-catalog extracts, from which the public API follows: public names, Zod schemas, field metadata, error codes, localized messages, JSON:API and keyset de
