# @nizam-os/paraglide-intl

> 标签: bidi, i18n, inlang, intl, localization, paraglide, paraglide-js, rtl

## 简介

Paraglide JS messages whose interpolated values display in place in left-to-right and right-to-left text: compile() wraps every interpolation in Unicode isolates before Paraglide compiles the project. Re-exports @nizam-os/intl-core.
