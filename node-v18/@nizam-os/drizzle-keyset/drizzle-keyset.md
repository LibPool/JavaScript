# @nizam-os/drizzle-keyset

> 标签: cursor, cursor-pagination, drizzle, drizzle-orm, keyset, keyset-pagination, pagination, postgres, postgresql, seek

## 简介

Keyset pagination for Drizzle ORM on PostgreSQL: filters, relationship predicates, aggregate sorts, text search, totals, range requests, and HMAC-signed cursors, rendered from @nizam-os/keyset-core's query plan into a select over your Drizzle schema.
