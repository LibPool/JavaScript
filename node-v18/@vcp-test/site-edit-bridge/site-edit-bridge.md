# @vcp-test/site-edit-bridge

> 标签: JavaScript

## 简介

生成站点与 VCP Designer/preview 之间的受控桥接包。它在 `@vcp-test/site-edit-engine` 合同之上提供浏览器 client、window message codec、server/Next 开发服务器适配和调试 trace；不包含平台 UI，也不持有 VCP secret。
