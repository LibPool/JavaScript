# @typren/adapter-cloudflare

> 标签: cloudflare, cms, redirects, typren, workers

## 简介

Cloudflare Workers + Static Assets host adapter for typren: a Worker (directory-index rewrite + bare→slash canonicalization + KV-backed redirect lookup, fail-open) and a `typren-cloudflare` CLI that inits the wrangler config, bootstraps the KV namespace,
