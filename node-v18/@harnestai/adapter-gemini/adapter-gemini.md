# @harnestai/adapter-gemini

> 标签: JavaScript

## 简介

Google Gemini model adapter for Harnest, including multimodal input and provider-native context caching. Configure AI Studio credentials through a Harnest Connection or host provider; do not place API keys in a HarnessSpec.
