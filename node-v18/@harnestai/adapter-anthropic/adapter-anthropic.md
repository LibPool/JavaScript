# @harnestai/adapter-anthropic

> 标签: JavaScript

## 简介

Anthropic model adapter for Harnest. Install it with the matching `@harnestai/core` version and configure credentials through a Harnest Connection or host provider; do not place API keys in a HarnessSpec.
