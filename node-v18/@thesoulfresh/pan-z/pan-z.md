# @thesoulfresh/pan-z

> 标签: browser, dom, image, mobile, pan, svg, zoom

## 简介

Pan-Z is a framework agnostic, 0 dependency, mobile and desktop friendly, GPU accelerated and easy to use pan/zoom library with an programmatic API.
