# @limitlayer/express

> 标签: api, express, express-middleware, express-rate-limit, express-rate-limiter, fixed-window, leaky-bucket, limit-layer, limitlayer, middleware, nodejs, rate-limit, rate-limiter, rate-limiting, redis, rest-api, sliding-log, sliding-window, token-bucket, typescript

## 简介

Official Express middleware for LimitLayer, supporting Fixed Window, Sliding Window, Token Bucket, Sliding Log, Leaky Bucket, MemoryStore, and RedisStore.
