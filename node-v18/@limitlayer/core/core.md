# @limitlayer/core

> 标签: api, backend, distributed-rate-limit, fixed-window, leaky-bucket, limit-layer, limitlayer, memory-store, middleware, nodejs, rate-limit, rate-limiter, rate-limiting, redis, redis-store, rest-api, security, sliding-log, sliding-window, token-bucket, typescript

## 简介

Framework-agnostic rate limiting engine for Node.js and TypeScript supporting Fixed Window, Sliding Window, Token Bucket, Sliding Log, Leaky Bucket, MemoryStore, and RedisStore.
