# @dexwox-labs/paperclip-plugin-test-context

> 标签: paperclip, paperclip-plugin, playwright, test-context, testing

## 简介

Test Context Registry for Paperclip: per-project environments, seed manifests, stub maps, secret-ref credentials, ephemeral PR preview envs, and freshness checks - everything an agent needs before generating tests, with secrets never entering prompts.
