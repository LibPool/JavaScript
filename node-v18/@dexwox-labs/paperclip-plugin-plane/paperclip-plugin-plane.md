# @dexwox-labs/paperclip-plugin-plane

> 标签: paperclip, paperclip-plugin, plane, project-management, sync

## 简介

Bidirectional Plane CE sync for Paperclip: webhook intake with HMAC verification, agent tools for work items, status/comment mirroring, and a reconciliation backstop for unreliable webhooks.
