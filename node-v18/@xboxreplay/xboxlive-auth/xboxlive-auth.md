# @xboxreplay/xboxlive-auth

> 标签: auth, live, xbox, xboxlive, xboxnetwork, xboxreplay

## 简介

A lightweight, zero-dependency Xbox Network (Xbox Live) authentication library for Node.js with OAuth 2.0 support.
