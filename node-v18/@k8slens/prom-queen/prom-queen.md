# @k8slens/prom-queen

> 标签: hotbar, kubernetes, lens-extension, metrics, monitoring, prometheus

## 简介

Pin cluster metrics from Prometheus to Lens's hotbar: CPU, memory, disk, volumes, network, pod capacity and resource requests.
