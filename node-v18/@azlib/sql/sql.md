# @azlib/sql

> 标签: JavaScript

## 简介

A framework-agnostic, zero-dependency dynamic SQL query builder and AST compiler with first-class multi-dialect support for **PostgreSQL**, **MySQL**, **SQLite**, **SQL Server (MSSQL)**, and **Oracle**.
