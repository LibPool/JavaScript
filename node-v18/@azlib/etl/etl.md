# @azlib/etl

> 标签: JavaScript

## 简介

A high-performance, framework-agnostic **Extract-Transform-Load (ETL)** pipeline engine for TypeScript and Node.js. Built for resilience, backpressure, atomic batch commits, and zero data loss.
