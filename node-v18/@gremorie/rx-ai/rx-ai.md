# @gremorie/rx-ai

> 标签: ai, canvas, chat, prompt, react, ui, workflow

## 简介

React AI primitives for Gremorie - full Bridge parity. PromptInput family, Chatbot (Message, Conversation, Reasoning, Task, Tool, ...), Code (Artifact, CodeBlock, WebPreview), Workflow (Canvas, Node, Edge, ...), Utilities (Image, OpenInChat).
