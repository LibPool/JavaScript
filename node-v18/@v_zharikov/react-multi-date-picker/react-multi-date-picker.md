> 标签: arabic, calendar, component, date, date picker, datepicker, datetime, english, farsi, gregorian, hijri, hindi, indian, jalali, locales, multi, multiple, persian, picker, range, range picker, rangepicker, react, time, time picker, timepicker, week, week picker, weekpicker

## 简介

A simple React datepicker component for working with gregorian, persian, arabic and indian calendars with the ability to select the date by single, multiple, range and multiple range pickers.
