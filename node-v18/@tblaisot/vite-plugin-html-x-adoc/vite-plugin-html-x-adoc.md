# @tblaisot/vite-plugin-html-x-adoc

> 标签: asciidoc, asciidoctor, hmr, hot-module-replacement, html, vite, vite-plugin

## 简介

A Vite plugin that processes AsciiDoc files and injects them into HTML files with full Hot Module Replacement (HMR) support
