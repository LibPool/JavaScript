# @docsector/docsector-reader

> 标签: docs, docsector, documentation, i18n, markdown, quasar, vite, vue3

## 简介

A documentation rendering engine built with Vue 3, Quasar v2 and Vite. Transform Markdown into beautiful, navigable documentation sites.
