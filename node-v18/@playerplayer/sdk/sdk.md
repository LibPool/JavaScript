# @playerplayer/sdk

> 标签: JavaScript

## 简介

In-game chat copilot that answers level-design what-ifs with a re-simulated before/after delta heatmap. The popover and play-telemetry install into any web game; swarm simulation ships a Phaser headless adapter.
