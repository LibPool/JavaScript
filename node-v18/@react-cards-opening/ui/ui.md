# @react-cards-opening/ui

> 标签: animation, card-flip, card-opening, cards, case-opening, confetti, effects, gacha, gamification, gsap, loot-box, pack-opening, particles, rarity, react, react-component, reveal, trading-cards, typescript

## 简介

Card opening components for React: a pack that bursts, a reel that spins, a case that opens and a scan that hunts, one reveal for all of them, and 64 effects from sparks to shockwaves. GSAP inside, one stylesheet, no CSS framework.
