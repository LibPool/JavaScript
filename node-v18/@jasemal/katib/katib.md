# @jasemal/katib

> 标签: arabic, bilingual, claude-code, claude-skill, document-generation, jinja2, pdf, proposal, tutorial, weasyprint

## 简介

Bilingual (EN + AR) print-grade PDF document generation — a Claude Code skill. v2 alpha with user-tier custom recipes/components under ~/.katib/. For the stable v1 release, install @jasemal/katib@0 (v0.20.0).
