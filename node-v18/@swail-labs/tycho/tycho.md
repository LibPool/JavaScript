# @swail-labs/tycho

> 标签: agents, ai, claude-code, codex, cursor, deterministic, independent, local, offline, opencode, verification

## 简介

npx-installable wrapper that fetches and runs the standalone Tycho binary (the offline agent verifier). No Python required.
