# @effected/schemastore

> 标签: catalog, draft-07, effect, effected, json-schema, schema, schemastore

## 简介

Build, validate, version and publish SchemaStore-shaped Draft-07 JSON Schema documents from Effect Schema sources: document assembly, ajv strict-mode validation, structural lints, catalog entries, canonical JSON and a content-comparing emit pipeline.
