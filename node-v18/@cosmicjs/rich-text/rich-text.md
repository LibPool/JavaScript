# @cosmicjs/rich-text

> 标签: cms, cosmic, react, rich-text, shortcodes

## 简介

Official renderer for Cosmic rich-text (markdown + shortcode blocks and inline object embeds): React components plus a framework-agnostic HTML string renderer.
