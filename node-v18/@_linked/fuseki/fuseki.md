# @_linked/fuseki

> 标签: interoperable, lincd, linked data, semantic web, web3

## 简介

A store for `@_linked/core` that talks SPARQL over HTTP to Apache Jena Fuseki, dataset admin helpers, and the Fuseki **image** every linked app runs: `ghcr.io/linked-fw/fuseki`, whose datasets infer RDFS classes.
