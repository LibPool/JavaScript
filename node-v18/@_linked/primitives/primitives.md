# @_linked/primitives

> 标签: interoperable, lincd, linked data, semantic web, web3

## 简介

A UI component library: a headless behaviour source (Radix UI, cmdk, vaul, or hand-written) plus a CSS module reading @_linked/css design tokens — and no knowledge of data, of shapes, or of any particular application.
