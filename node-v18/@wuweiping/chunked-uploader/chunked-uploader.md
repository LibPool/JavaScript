# @wuweiping/chunked-uploader

> 标签: axios, chunked, multipart, presigned, resumable, s3, upload

## 简介

axios 驱动的分片断点续传上传器：预签名直传、分片上传、onUploadProgress 聚合进度、localStorage 断点存档、分片级自动重试，与 UI 框架解耦
