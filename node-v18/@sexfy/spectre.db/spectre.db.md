# @sexfy/spectre.db

> 标签: binary, bun, database, json, key-value, lmdb, napi, nodejs, rust, spectre, wal

## 简介

High-performance key-value storage in Rust for Node.js & Bun: binary v2 format (CRC32, WAL v3 + LSN, segmented incremental compaction), lazy cursors, secondary indexes, raw binary values, zstd compression, dual-engine with v1.1.0 JSON fallback.
