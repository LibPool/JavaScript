# @k.nirmal/gemini-kit

> 标签: ai, bard, chatbot, conversational-ai, gemini, gemini-api, google-ai, google-gemini, image-upload, large-language-model, llm, nodejs, text-to-speech

## 简介

Unofficial Node.js wrapper for Google Gemini — interact via cookies. Supports ask, speech, image upload, image extraction, sharing, and continuous conversations.
