# @morva/sdk

> 标签: arbitrum, checkout, crypto-payments, eip-7702, particle-network, universal-account, web3

## 简介

Headless TypeScript SDK for accepting crypto payments settled in a merchant's chosen token on Arbitrum One, from a buyer's cross-chain balance via Particle Universal Accounts (EIP-7702).
