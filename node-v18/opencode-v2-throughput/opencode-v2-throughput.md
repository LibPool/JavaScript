# opencode-v2-throughput

> 标签: benchmark, latency, llm, monitoring, opencode, opencode-plugin, opencode-tui-plugin, opencode-v2, performance, throughput, tps, ttft

## 简介

Live LLM speed metrics for OpenCode v2: TTFT, TPS, latency, token usage and cost per model, with a sidebar widget, per-request toasts, and a benchmark tool.
