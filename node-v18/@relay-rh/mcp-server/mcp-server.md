# @relay-rh/mcp-server

> 标签: agents, ai-agents, bounty, escrow, mcp, model-context-protocol, relay-tech, robinhood-chain, web3

## 简介

Self-hosted Model Context Protocol (MCP) server for Relay Tech — gives an AI agent the RelayEscrow bounty-marketplace tools (reads + agent-signed writes) on Robinhood Chain (chainId 4663), over stdio. Read tools work with no key; write/messaging tools nee
