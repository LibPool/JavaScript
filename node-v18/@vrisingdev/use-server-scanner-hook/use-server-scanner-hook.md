# @vrisingdev/use-server-scanner-hook

> 标签: JavaScript

## 简介

Library for querying V Rising dedicated server data using ReactJS. This library is built with the [V Rising Server Scanner API](https://rapidapi.com/InfamyStudio/api/vrising-server-scanner). If you have not already, click the link and register for an API
