# @relaybus/otel

> 标签: event-bus, kafka, metrics, nestjs, observability, opentelemetry, otel, outbox-pattern, rabbitmq, relaybus, traceparent, tracing, transactional-outbox, w3c-trace-context

## 简介

OpenTelemetry for relaybus: messaging metrics after the semantic conventions, outbox backlog gauges, and one trace from publish in one service to the handler in another, with W3C trace context in event headers.
