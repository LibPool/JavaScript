# @maykonpaulo/maestro-provider-elasticsearch

> 标签: JavaScript

## 简介

Elasticsearch provider for @maykonpaulo/maestro-core (ADR 0007) — real CRUD, mapping-based introspection, and missing-index creation. Indices are the entity; documents are records.
