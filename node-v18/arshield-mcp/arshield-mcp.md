# arshield-mcp

> 标签: ai-agents, arc, arshield, cryptography, dilithium, encryption, kyber, mcp, ml-dsa, ml-kem, model-context-protocol, post-quantum, quantum-safe

## 简介

ArShield MCP server — post-quantum file encryption for AI agents. Hybrid ML-KEM-768 + X25519, ML-DSA-65 signatures, AES-256-GCM. Runs fully local over stdio: keys never leave the machine.
