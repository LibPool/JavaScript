# @dskripchenko/wysiwyg

> 标签: contenteditable, dskripchenko, editor, rich-text, vue, vue3, wysiwyg, zero-dependencies

## 简介

Vue 3 WYSIWYG-редактор без сторонних editor-движков. Собственный contenteditable-engine, selection API, sanitize, history. UI на @dskripchenko/ui.
