# @egen-civitas/esm-ai-memory

> 标签: ai, egen, memory, microfrontends, persistence

## 简介

Persistance de conversation IA EGEN — historique par utilisateur, stockage local (IndexedDB) synchronisé avec un adaptateur backend interchangeable, sans réécriture au changement de stockage.
