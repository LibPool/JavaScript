# @ameenahmed/nosqlite

> 标签: bun, jsonb, mongodb, nosql, sqlite, typescript

## 简介

MongoDB-inspired document database for Bun backed by SQLite JSONB, with BSON, aggregation, indexes, change streams, and a MongoDB command adapter.
