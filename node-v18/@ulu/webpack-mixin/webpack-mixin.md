# @ulu/webpack-mixin

> 标签: autoprefixer, babel, config, configuration, defaults, drupal, image optimization, imagemin, less, mamp, mixin, preset, proxy, sass, scss, static site, vue, webpack, webpack-dev-server, webpack.config.js

## 简介

Reusable preset webpack configuration for traditional sites (Drupal, etc). Includes things commonly needed SASS/LESS, image optimization, extract CSS, local server proxy, Vue SFC, etc. Not a SPA setup
