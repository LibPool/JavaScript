# @ulu/vite-config-cms-theme

> 标签: CMS, Drupal, Eleventy, HMR, Hot module replacement, Javascript, SSG, Vite, Wordpress, config, dev server, static site generator, theme

## 简介

Creates vite config for Drupal theme (non-app traditional sites). Supports HMR, legacy bundling, image optimization and Vue. Can be used for other static sites as well (ie. Hugo, Eleventy).
