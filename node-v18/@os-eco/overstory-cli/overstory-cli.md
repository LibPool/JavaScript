# @os-eco/overstory-cli

> 标签: agents, ai, claude-code, cli, developer-tools, multi-agent, orchestration, swarm

## 简介

Multi-agent orchestration for AI coding agents — spawn workers in git worktrees via tmux, coordinate through SQLite mail, merge with tiered conflict resolution. Pluggable runtime adapters for Claude Code, Pi, and more.
