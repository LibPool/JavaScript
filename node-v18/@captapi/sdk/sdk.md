# @captapi/sdk

> 标签: api-client, captapi, instagram, reddit, scraping, sdk, social-media, tiktok, transcript, twitter, typescript, youtube

## 简介

Official typed TypeScript SDK for the Captapi social media API — 178 endpoints across 32 platforms (YouTube, TikTok, Instagram, Facebook, X, Reddit, Threads, Bluesky, Pinterest, LinkedIn, Twitch, Spotify, and more). Zero dependencies, built on fetch.
