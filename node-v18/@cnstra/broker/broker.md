# @cnstra/broker

> 标签: broker, cnstra, queue, resumable, resume, worker

## 简介

Broker-agnostic core for CNStra queue integrations: run one job as one stimulation, with observability + resumable execution. Shared by @cnstra/bullmq and @cnstra/pg-boss.
