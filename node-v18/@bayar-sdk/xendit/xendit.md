# @bayar-sdk/xendit

> 标签: credit-card, dana, e-wallet, indonesia, ovo, payment, payment-gateway, payment-request-api, qris, sdk, shopeepay, typescript, virtual-account, xendit

## 简介

Xendit provider adapter for bayar-sdk — create charges, check status, refund and verify webhooks via Xendit Payment Request API (virtual account, QRIS, OVO, DANA, ShopeePay, credit card).
