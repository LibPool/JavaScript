# @proxy-checkout/stripe-server-js

> 标签: checkout, payments, proxy-checkout, sdk, stripe

## 简介

Server-side Stripe adapter for Proxy Checkout acquisition, Checkout, SetupIntent, direct Subscription, and cart sync workflows.
