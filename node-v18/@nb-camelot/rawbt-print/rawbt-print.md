# @nb-camelot/rawbt-print

> 标签: bluetooth, escpos, printer, rawbt, receipt, thermal, web-bluetooth, web-serial

## 简介

Print Bridge web client: ESC/POS builder and transports (Print Bridge app local API on 127.0.0.1:8787, Web Bluetooth, Web Serial).
