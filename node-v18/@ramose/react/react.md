# @ramose/react

> 标签: database, hooks, live-query, ramose, react, realtime

## 简介

React bindings for Ramose: RamoseProvider owns one Client per subtree, useRamose hands it back, useDb memoises a Db from it. Hooks only — no UI, no styling.
