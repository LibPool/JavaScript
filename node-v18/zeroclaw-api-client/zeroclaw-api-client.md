# zeroclaw-api-client

> 标签: ai-agents, api-client, sdk, typescript, zeroclaw

## 简介

Independent, typed, resilient TypeScript client for the ZeroClaw gateway: HTTP API, events and chat. Works in browsers, Node, Deno and Bun.
