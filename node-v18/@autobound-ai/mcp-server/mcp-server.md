# @autobound-ai/mcp-server

> 标签: ai, autobound, b2b, mcp, signals

## 简介

MCP server for the Autobound Signal Intelligence API. 25 tools across search, enrichment, signal taxonomy, buyer intent (contact + company, incl. async exports), email verification, monitoring pool, and account/usage.
