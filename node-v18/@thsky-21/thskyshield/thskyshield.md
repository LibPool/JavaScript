# @thsky-21/thskyshield

> 标签: agent-governance, agent-guardrails, kill-switch, langgraph, loop-detection, openai-agents, tool-allowlist

## 简介

Runtime governance for autonomous AI agents — per-run tool allowlists, write ceilings, loop detection, step limits, and timeouts. Works with LangGraph, OpenAI Agents SDK, or any TypeScript agent framework.
