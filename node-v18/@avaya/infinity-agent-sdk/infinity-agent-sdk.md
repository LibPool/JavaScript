# @avaya/infinity-agent-sdk

> 标签: JavaScript

## 简介

The Avaya Infinity™ Agent SDK is a JavaScript/TypeScript library that lets you embed contact-center agent capabilities of the Avaya Infinity™ platform into client application of your choice. It is the single entry point for everything an agent needs to do
