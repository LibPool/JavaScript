# @uicast/core

> 标签: agent, component-catalog, generative-ui, jsonlines, llm, streaming, ui

## 简介

LLM-generated UIs from a stream of JSONLines — the framework-agnostic uicast engine: entry format, sandboxed expressions, reactive scopes, and prompt builders.
