# @ancora/core

> 标签: anchor, chat, headless, pin, scroll, stick-to-bottom, streaming, virtual-list, virtualization

## 简介

Framework-agnostic core for ancora: pin state machine, scroll-source discrimination, anchor math, and list-operation inference for pixel-stable chat/streaming lists.
