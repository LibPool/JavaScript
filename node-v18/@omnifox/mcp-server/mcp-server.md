# @omnifox/mcp-server

> 标签: ai-agent, claude, cursor, customer-messaging, instagram, mcp, messenger, model-context-protocol, omnifox, respond.io, whatsapp

## 简介

Official Omnifox.io Model Context Protocol (MCP) server — 48 tools over the Omnifox v1 REST API for Claude, Cursor, Continue and any MCP client. Every tool verified end-to-end against a live workspace.
