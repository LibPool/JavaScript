# @xcon-viewer/core

> 标签: converter, document, json, llm, markdown, parser, sketch, tagless, ui, validator, xcon, xcon-viewer, xml

## 简介

XCON core parser, validator, and object model. Parse SKETCH, JSON, XML, or TAGLESS syntax into a unified XCON Object Model. Built for the LLM era — safe, structured, and format-agnostic.
