# @opennotification/react-native

> 标签: apns, expo, fcm, opennotification, push-notifications, react-native

## 简介

React Native SDK for Open Notification (APNs direct on iOS, FCM data-only on Android). Native modules on both platforms, no Firebase or Notifee JavaScript packages.
