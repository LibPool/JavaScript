# @lxgicstudios/api-rate

> 标签: 429-status, api-benchmark, api-rate-limit, api-testing, burst-testing, cli, developer-tools, http-testing, load-testing, performance, rate-limit-headers, rate-limiting, stress-test, throttle-detection

## 简介

Test and measure API rate limits. Send increasing request bursts, detect throttling, show requests/second before 429, retry-after values, and rate limit headers.
