# @lxgicstudios/api-changelog

> 标签: api, api-design, breaking-changes, changelog, cli, diff, documentation, migration, npx, openapi, rest-api, spec, swagger, versioning

## 简介

Compare two OpenAPI/Swagger spec files and generate a human-readable changelog. Detect added, removed, and changed endpoints, new required fields, deprecations, and breaking changes.
