# @antimatter-web/schema

> 标签: accessibility, agent-tools, ai-agents, antimatter, ed25519, jcs, json-schema, llm, mcp, model-context-protocol, rfc8785, signing, typescript

## 简介

The signed trust artifact for Antimatter: Ed25519/JCS envelope types, the single selector resolver, and local risk re-derivation. Zero browser dependencies.
