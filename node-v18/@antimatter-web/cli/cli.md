# @antimatter-web/cli

> 标签: accessibility, agent-tools, ai-agents, antimatter, browser-automation, cli, ed25519, llm, mcp, model-context-protocol, playwright, typescript, web-automation

## 简介

Command-line compiler and validator for Antimatter: analyze a URL into a signed MCP schema, validate its signature, or serve it as a stdio MCP server.
