# dsh-self

> 标签: affective-computing, agent, deepseek-harness, dsh-plugin, emotion, self

## 简介

DeepSeek Harness 情绪×自我合一插件：感知/仲裁/内感受/调节/心境/安全对齐 + 侧边栏「聊天」页内陪聊（主对话式界面/多 agent/每 agent 独立情绪与自我状态/设置弹窗/模型切换/情绪调试条/存储文件夹镜像/模拟人生/日记/IM 接入：微信三模式（测试号/个人/iLink 扫码 Bot）+ 飞书自建应用 + QQ OneBot/NapCat，TypeScript + vitest）
