# @qlee/dockhand-cli

> 标签: cli, compose, container-management, docker, dockhand, generated-client, hawser, openapi

## 简介

Command-line client for the Dockhand API — every command is generated from the instance's OpenAPI document. Containers, images, volumes, networks, compose stacks, environments, backups, schedules.
