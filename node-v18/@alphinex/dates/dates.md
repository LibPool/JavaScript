# @alphinex/dates

> 标签: JavaScript

## 简介

Intl-based date/time engine + DatePicker, DateRangePicker, TimePicker, DateTimePicker and the shared month-grid cell engine. No date-fns/dayjs/luxon. See documentation/PRODUCT-RESEARCH-MASTER-PLAN.md §10.3 (Sprint 37).
