# @nithin-npm/secretguard

> 标签: api-key, cli, credentials, devsecops, git, secret-scanner, secrets, security

## 简介

A CLI tool that scans codebases and git history for leaked secrets — API keys, tokens, credentials, and private keys — using regex pattern matching and entropy analysis.
