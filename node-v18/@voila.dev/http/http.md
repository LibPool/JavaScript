# @voila.dev/http

> 标签: effect, effect-ts, fetch, http, retry, sns, ssrf, stripe, svix, twilio, webhooks

## 简介

Outbound HTTP for third-party integrations on Effect: timeouts, retries, spans, bounded reads, Schema decoding, a request log, and webhook signature checks.
