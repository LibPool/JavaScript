# @voila.dev/live

> 标签: effect, effect-ts, live, realtime, redis-streams, websocket

## 简介

Live updates over WebSocket on Effect: channels with a gate and a filter, a batching socket hub, a replay log on Redis streams, and a reconnecting browser client.
