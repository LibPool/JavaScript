# @ux-sting/seo-schema

> 标签: json-ld, rich-results, schema.org, seo, structured-data

## 简介

Typed schema.org JSON-LD builders, safe serialization and validation that separates schema.org validity from Google rich-result eligibility. Zero dependencies, framework-agnostic.
