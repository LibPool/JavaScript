# @doogi/cairn

> 标签: adr, agents, agents-md, claude-code, codex, copilot, cursor, documentation, gemini-cli, wiki

## 简介

Drop a record-keeping structure into any project — work journal, problem log, ADRs, concepts, experiments, plus a wiki consistency checker. Works with Claude Code, Codex, Cursor, Gemini CLI, Copilot, Windsurf, Cline.
