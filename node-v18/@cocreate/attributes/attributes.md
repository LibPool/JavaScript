# @cocreate/attributes

> 标签: cocreate, cocreate-framework, cocreatejs, cocreatejs-component, collaboration, html5-framework, javascript-framework, low-code, no-code, no-code-framework, realtime, realtime-framework, shared-editing

## 简介

Simple HTML5 & JavaScript component add, update & remove values in element's attributes from input, select or js api. Easily configured using HTML5 attributes and/or JavaScript API.
