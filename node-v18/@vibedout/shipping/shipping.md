# @vibedout/shipping

> 标签: cloudflare, envia, mexico, shipping, tracking, webhook, workers

## 简介

Provider-neutral shipping for Cloudflare Workers: one ShippingProvider interface for rates, labels, tracking, cancellation, pickups, reconciliation and signed webhooks, a Mexican address schema, parcel helpers, an Envia.com adapter and a test double.
