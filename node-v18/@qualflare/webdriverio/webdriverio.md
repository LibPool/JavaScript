# @qualflare/webdriverio

> 标签: appium, e2e, flaky-tests, mobile-testing, qualflare, test-reporter, test-reporting, test-results, wdio, wdio-reporter, webdriverio

## 简介

Native WebdriverIO reporter for Qualflare — web and mobile (Appium) runs, with per-attempt retry history, flakiness, the screenshots WebdriverIO takes, device capabilities and author-facing metadata, merged across workers.
