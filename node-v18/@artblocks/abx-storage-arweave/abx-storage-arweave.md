# @artblocks/abx-storage-arweave

> 标签: abx, ardrive, art-blocks, arweave, nft, storage, turbo

## 简介

Optional ArDrive Turbo (Arweave) uploader for @artblocks/abx-storage. Install this explicitly to enable the arweave storage backend.
