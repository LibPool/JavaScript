# @openpets/opensubtitles

> 标签: movies, opencode, openpets, opensubtitles, plugin, subtitles, tv-shows

## 简介

Search for and download subtitles from the OpenSubtitles.com database. Supports search by title, IMDB ID, file hash, and multiple languages.

## 官网

- 官网：https://www.opensubtitles.com
- 源码仓库：https://github.com/raggle-ai/pets/pets/opensubtitles
- npm 页面：https://www.npmjs.com/package/@openpets/opensubtitles
