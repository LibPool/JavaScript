# @openpets/land-registry

> 标签: hm-land-registry, land-registry, openpets, plugin, property, title, uk-government

## 简介

Check which register referred documents are available for immediate download from HM Land Registry. Use a title number to find out the Official Copy Document Availability status.

## 官网

- 官网：https://landregistry.github.io/bgtechdoc/services/official_copy_document_availability_v2/
- npm 页面：https://www.npmjs.com/package/@openpets/land-registry
