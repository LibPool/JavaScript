# @openpets/unifi-protect

> 标签: camera, doorbell, openpets, protect, security, unifi, video

## 简介

UniFi Protect is Ubiquiti's video security platform. This plugin provides AI tools to interact with UniFi Protect cameras, doorbells, motion events, and more via OpenAPI.
