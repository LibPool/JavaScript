# @openpets/quickfile

> 标签: accounting, invoicing, opencode, openpets, plugin, quickfile, uk

## 简介

OpenPets plugin for QuickFile UK accounting software. Manage invoices, clients, suppliers, bank transactions, and generate financial reports.
