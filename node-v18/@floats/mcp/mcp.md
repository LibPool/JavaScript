# @floats/mcp

> 标签: agent, canvas, flashcards, floats, mcp, modelcontextprotocol

## 简介

MCP server for Floats (thefloats.app) — give any AI app read/write access to your canvases and flashcards. Runs over stdio: npx @floats/mcp.

## 官网

- 官网：https://thefloats.app
- 源码仓库：git+https://github.com/Porche22/thefloats.git
- npm 页面：https://www.npmjs.com/package/@floats/mcp
