# @seirei/carousel

> 标签: carousel, react, react-native, react-native-carousel, react-native-carousel-component, react-native-carousel-slider, react-native-carousel-view, react-native-reanimated, react-native-reanimated-carousel, reanimated

## 简介

A reusable, auto-scrolling carousel component for React Native built using **React Native Reanimated v2**, offering customizable pagination indicators, smooth animations, and infinite looping.
