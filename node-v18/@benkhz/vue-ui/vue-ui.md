# @benkhz/vue-ui

> 标签: drawer, headless, layout, modal, pinia, sidebar, state-management, ui, vue, vue3

## 简介

UI-agnostic layout state orchestration for Vue 3 — drawers, modals, rails, overlays, toasts, and focus mode coordinated through a single Pinia store.
