# @gcu/plot

> 标签: auditable, canvas, chart, gcu, matplotlib, plot, plotting, visualization

## 简介

Matplotlib-style plotting for the browser: subplots, plot, scatter, imshow, hist, bar. Canvas-based, zero runtime dependencies.
