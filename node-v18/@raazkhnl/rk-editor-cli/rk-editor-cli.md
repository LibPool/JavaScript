## 简介

CLI scaffolder for RK Word Editor — `npx @raazkhnl/rk-editor-cli init` to bootstrap a new free, open-source Word/Google-Docs-style rich-text editor project (Vanilla JS, React, Vue, Svelte, Next.js).
