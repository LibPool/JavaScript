# dsh-hide-ui

> 标签: deepseek-harness, dsh, dsh-plugin, peek, wallpaper

## 简介

Right-click to hide selected DeepSeek Harness surfaces (sidebar, cards, input, conversation, trajectory, produced content, header, right sidebar) and reveal the background wallpaper.
