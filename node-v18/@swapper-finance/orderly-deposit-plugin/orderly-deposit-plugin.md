# @swapper-finance/orderly-deposit-plugin

> 标签: cross-chain, deposit, dex, onramp, orderly, orderly-plugin, swapper

## 简介

Orderly SDK plugin that makes Swapper the default deposit flow: fund an Orderly account from any chain, any token, a CEX or a card
