# @dforge-core/dforge-mcp

> 标签: JavaScript

## 简介

MCP server for dForge module authoring. Exposes 35 scaffold/patch/validate/pack/install tools and schema resources so AI agents (Claude Code, Cursor, Zed) can create and ship dForge modules.
