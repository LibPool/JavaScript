# @shaggytools/template-typescript-jest-jsdoc

> 标签: babel, better-docs, eslint, jest, jsdoc, node, npm, prettier, starter, template, typescript

## 简介

A starter template for getting started with Node, Typescript, Jest, and jsdoc. Includes prettier and eslintA package to verify and decode Vehicle Indentification Numbers (VIN), using the NHTSA.dot.gov public API.
