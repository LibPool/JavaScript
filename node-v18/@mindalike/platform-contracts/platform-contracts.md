# @mindalike/platform-contracts

> 标签: cloudflare-workers, contracts, csrf, jwt, mindalike

## 简介

Shared identity, CSRF, origin, cookie, and request-metadata contracts for all Mindalike workers. Single source of truth extracted from the platform core (landing-page).
