# @rezdevops/pii-scanner-engine

> 标签: csv, gdpr, pdf, pii, rgpd, scanner, web-worker, xlsx

## 简介

Orchestration de scan PII : parseurs CSV / XLSX / PDF / TXT / JSON / DOCX / HTML (binaires lazy-loadés), pool de Web Workers, agrégation des findings, génération des exports JSON / Markdown / HTML autonome.
