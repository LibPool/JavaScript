# @zonto/sdk

> 标签: achievements, cloud-saves, games, leaderboards, oauth, presence, sdk, zonto

## 简介

Zonto Games platform SDK — Sign in with Zonto (OAuth + PKCE), launch tickets, presence, playtime, achievements, leaderboards, and cloud saves for game clients.
