# @likemiens/voice-dock

> 标签: call, call-controls, mute, react, react-component, screen-share, spring-animation, svg, toolbar, voice

## 简介

The control bar of a live voice session as a React component: status, microphone, screen sharing, exit and a menu, drawn as beads on one thread.
