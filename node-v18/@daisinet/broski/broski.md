# @daisinet/broski

> 标签: ai, article-extraction, content-extraction, crawler, docx, llm, markdown, pdf, readability, scraper

## 简介

Extract clean article content from any URL (html, docx, xlsx, pdf) as JSON, Markdown, or reader-mode HTML.
