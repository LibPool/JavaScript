# @langgraph-toolkit/adapter-checkpointers

> 标签: checkpoint, langgraph, mongodb, mysql, postgres, redis, sqlite

## 简介

Database checkpointers for @langgraph-toolkit/core: SQL (SQLite/Postgres/MySQL), Redis, MongoDB. Drivers are injected, so no database library is a hard dependency.
