# @lossless.org/nosqldb

> 标签: database server, embedded database, in-memory database, local database, mongodb-compatible, rust, testing, wire protocol

## 简介

A MongoDB-compatible embedded database server with wire protocol support, backed by a high-performance Rust engine.
