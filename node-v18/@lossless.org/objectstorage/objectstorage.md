# @lossless.org/objectstorage

> 标签: AWS S3 Compatibility, Bucket Management, CI/CD Integration, Cloud Storage, Developer Onboarding, Development Tool, File Storage, File Upload, Local Development, Local Storage Server, Node.js, S3 Compatible, Storage Endpoint, Storage Simulation, Testing, TypeScript, objectstorage

## 简介

A Node.js TypeScript package to create a local S3-compatible storage server using mapped local directories for development and testing purposes.
