# @reportwright/engine

> 标签: docx, excel, jasperreports, pdf, pdf-a, pptx, rdl, report, report-engine, reporting, reportwright, ssrs, xlsx

## 简介

ReportWright report engine: JSON report definitions to pages, PDF (incl. PDF/A), Word, Excel, PowerPoint, HTML and CSV. Node and browsers. Fonts: @reportwright/fonts; CLI: @reportwright/cli.
