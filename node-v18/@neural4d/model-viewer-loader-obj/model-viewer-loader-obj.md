# @neural4d/model-viewer-loader-obj

> 标签: JavaScript

## 简介

The OBJ/MTL `ModelLoader` for Neural4D Model Viewer. It uses the official Three.js `OBJLoader` and `MTLLoader.parse()` while delegating MTL and texture transport to Core `ResourceProvider` and `assets-required` resolution.
