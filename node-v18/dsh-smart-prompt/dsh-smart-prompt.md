# dsh-smart-prompt

> 标签: deepseek-harness, dsh, dsh-plugin, prompt-engineering, prompt-enhancement

## 简介

Rewrite the composer draft into a clearer, agent-ready prompt in one click, with Revert and Retry. 一键把输入框草稿改写为更清晰、更贴 Agent 执行的提示词。
