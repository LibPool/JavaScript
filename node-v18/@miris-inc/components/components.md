# @miris-inc/components

> 标签: 3d, custom-elements, gaussian-splatting, miris, splats, streaming, web-components

## 简介

Web Components for the Miris 3D streaming SDK. Defines <miris-scene>, <miris-camera>, <miris-stream>, and <miris-group> custom elements.
