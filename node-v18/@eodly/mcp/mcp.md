> 标签: ai-agent, async-standup, claude, cursor, end-of-day-report, eodly, mcp, mcp-apps, mcp-ui, model-context-protocol, modelcontextprotocol, standup

## 简介

MCP server for Eodly. Read your team's end-of-day reports and roster from any MCP client (Claude, Cursor) using an Eodly API key.
