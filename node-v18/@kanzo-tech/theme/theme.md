# @kanzo-tech/theme

> 标签: JavaScript

## 简介

Kanzo design tokens — a catalogue of themes, each one flat block of CSS, plus the non-colour axes (radius / font / mono font / density) a user layers over them, driven by data-* attributes on <html>.
