# @rdkmaster/peity

> 标签: chart, ecosystem:jquery, graph, jquery-plugin, sparkline, svg

## 简介

Peity (sounds like deity) is a jQuery plugin that converts an element's content into a mini `svg` pie, line or bar chart.
