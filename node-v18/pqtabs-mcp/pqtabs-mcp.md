# pqtabs-mcp

> 标签: agents, arc, capability, mcp, model-context-protocol, payments, pqtabs, usdc

## 简介

Local stdio MCP server for PQTABS on Arc. Check capabilities, price research, and pay only inside an already-authorized USDC capability.
