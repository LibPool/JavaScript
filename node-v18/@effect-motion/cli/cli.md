# @effect-motion/cli

> 标签: cli, effect, motion, render, scaffold, studio, video

## 简介

Command line for effect-motion: preview scenes with hot reload (studio) and render videos from motion.config.ts (render). Scaffold new projects with `bun create effect-motion`
