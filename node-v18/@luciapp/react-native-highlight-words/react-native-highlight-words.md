# @luciapp/react-native-highlight-words

> 标签: highlight, highlighter, matches, occurrences, react, react-component, react-native, reactjs, search, substring, text, words

## 简介

A React Native port of react-highlight-words. This component is used to highlight words within a larger body of text.
