# @tcd-devkit/eslint-preset-react

> 标签: a11y, eslint, eslint-preset, eslintconfig, flat-config, lint, preset, react, tcd-devkit, typescript

## 简介

Comprehensive ESLint Flat Configuration Preset for React projects. This preset bundles various @tcd-devkit ESLint configurations for a complete React, TypeScript, and a11y linting setup.
