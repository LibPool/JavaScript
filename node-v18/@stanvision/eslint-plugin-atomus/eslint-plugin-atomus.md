# @stanvision/eslint-plugin-atomus

> 标签: ai-agents, atomus, design-system, design-tokens, eslint, eslint-plugin, eslintplugin, react, tailwind

## 简介

ESLint rules for the Atomus design system: semantic tokens instead of raw colours and primitives, real Atomus props and enum values, Atomus components instead of raw controls, labels on icon-only buttons and one primary button per view.
