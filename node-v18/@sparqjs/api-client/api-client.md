# @sparqjs/api-client

> 标签: JavaScript

## 简介

`@sparqjs/api-client` 是 Sparq 前端共享的 HTTP 传输层。它封装 Axios、请求配置、响应 envelope 解包和统一错误，不承载 Admin、Schema、Storage、Settings 或插件业务协议。
