# @metaxia/scriptures-source-stepbible-tipnr

> 标签: bible, genealogy, names, people, places, proper-nouns, scriptures, stepbible, strongs, tipnr

## 简介

Biblical proper nouns (people, places, and other named entities) from STEPBible's TIPNR dataset for @metaxia/scriptures. Unified Strong's numbers, all name forms, exhaustive references, genealogy, and geolocation.
