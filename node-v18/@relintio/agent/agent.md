# @relintio/agent

> 标签: antibot, bot-detection, bot-mitigation, express, middleware, relintio, relintio-agent, security, threat-protection, waf

## 简介

RelintioAgent in-process agent for Node runtimes. Provides bot mitigation, threat detection, and adaptive content protection as Express middleware or zero-code preload.
