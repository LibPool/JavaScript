# @agentpay-ai/mcp-server-arc

> 标签: JavaScript

## 简介

AgentPay's MCP server exposes Arc payment tools over stdio or Streamable HTTP. It supports Circle Agent Wallet setup and funding, autonomous budget reads and withdrawal, direct USDC sends, invoice payments and payment requests, batch payouts, x402 paid-se
