# postrail

> 标签: agent, atproto, bluesky, instagram, linkedin, llm, scheduler, social, threads, x-api, youtube

## 简介

Open-source social posting agent. An account registry, a slot engine that retries until a post lands, official API transports, cards, video cuts, an optional reply module that is off by default, and a review command that reads what was actually posted.
