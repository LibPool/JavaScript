# @genie-os/sdk

> 标签: email, genieos, marketing, mcp, schema-contract, sequences, transactional

## 简介

Official TypeScript / Node.js SDK for the GenieOS API. Templates, sequences, events, webhooks, schema-contract — typed, retried, idempotent.
