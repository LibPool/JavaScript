# @giszhc/three-model-viewer

> 标签: 3d, bounding-box, cad-viewer, clipping, measurement, model-viewer, mtl, obj, three, threejs, zip

## 简介

A modern, professional 3D model inspector and viewer SDK for Web applications. Features OBJ/MTL/ZIP loading, 3D measurements, dynamic dimensional bounding box, plane slicing, and high-res export.
