# @giszhc/mapbox-sketch

> 标签: annotation, canvas, draw, label, leader, mapbox, mapbox-gl, sketch

## 简介

零运行时依赖的 Mapbox 手绘标注引擎：点 / 线 / 面 / 路径文字 / 距离标注 / 面积标注 / 引线标注 / 坐标引线标注，全部绘制在自建 canvas 覆盖层上，支持点选已绘图形直接拖拽编辑。
