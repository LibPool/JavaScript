# @giszhc/geojson-to-kml

> 标签: geojson, kml

## 简介

一个 **简单、轻量、健壮** 的 JavaScript / TypeScript 库，用于将 **GeoJSON** 数据转换为 **KML (Keyhole Markup Language)** 格式。
