# @push.rocks/smartfile

> 标签: Node.js, SmartFile, StreamFile, TypeScript, VirtualDirectory, buffer operations, file content manipulation, file factory, file management, file representation, file streaming, in-memory files, memory-efficient file handling, virtual directory

## 简介

High-level file representation classes (SmartFile, StreamFile, VirtualDirectory) for efficient in-memory file management in Node.js using TypeScript. Works seamlessly with @push.rocks/smartfs for filesystem operations.
