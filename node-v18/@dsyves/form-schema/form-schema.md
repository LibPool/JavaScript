# @dsyves/form-schema

> 标签: class-validator, decorators, dynamic-forms, form-schema, metadata, nestjs, sdui, server-driven-ui, typescript

## 简介

Server-Driven UI form schema generator for NestJS. Reads UI decorators on DTO classes and produces typed, frontend-ready JSON form schemas. Optionally integrates with class-validator to automatically infer validation rules.
