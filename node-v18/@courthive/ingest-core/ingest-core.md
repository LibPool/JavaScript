# @courthive/ingest-core

> 标签: adapter, codes, ingest, normalization, sports-data, tennis, tods, tournament

## 简介

Federation-agnostic tournament ingestion toolkit: an adapter contract, a registry, TODS/CODES normalization, factory-backed integrity checking, and a generic sanction-policy engine. Bring your own site adapters.
