# @tenseuronp/cli

> 标签: ai, deepseek, mining, ollama, solana, tenseuron, validator

## 简介

Tenseuron Protocol CLI — mine and validate AI tasks from any machine. Cloud APIs (DeepSeek/OpenAI/Gemini/etc.) or local LLMs (Ollama/LM Studio).
