# dsh-intelligent-ui

> 标签: agent, artifacts, deepseek-harness, dil, dsh-plugin, generative-ui, genui, intelligent-ui, llm, sandbox, ui, worker

## 简介

DSH plugin for generative UI: the model writes an interface instead of describing one. Declarative DSL compiled and executed in a DOM-less Worker sandbox, then drawn by the host with native DOM; a sandboxed-frame escape hatch for anything the component in
