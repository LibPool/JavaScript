# @codimensional/brand

> 标签: JavaScript

## 简介

Generated brand primitives for CoDimensional projects: design tokens (`tokens.css` / `tokens.json` / typed `tokens.js`), an importable Python token map (`tokens.py`, for Django/Unfold), `fonts.css`, a Vuetify theme factory, the splash module, logo/favicon
