# @yzfe/syb-tunnel-client

> 标签: JavaScript

## 简介

隧道**客户端**：通过 WebSocket 连接服务端，注册配置的 TCP 代理（当前实现含 **SOCKS5** 插件），并在收到 `STREAM_OPEN` 等指令时经适配器建立本地 TCP。
