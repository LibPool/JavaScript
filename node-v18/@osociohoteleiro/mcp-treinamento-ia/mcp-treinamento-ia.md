# @osociohoteleiro/mcp-treinamento-ia

> 标签: mcp, model-context-protocol, onscreen-hotels, osh

## 简介

Servidor MCP para treinar a IA do OSH (conhecimento, configuração, tipos de quarto, SDRs de prospecção, rascunhos de anúncio Meta) a partir do Claude Code, Codex e afins. Uso interno da Onscreen Hotels — requer uma chave emitida na plataforma.
