# @mattthehat/astro-cms

> 标签: admin, astro, astro-component, cms, crud, withastro

## 简介

Config-driven admin CMS for Astro: one resource config renders a full list/create/edit/view/delete screen with search, filters, sorting and pagination, DB-agnostic via a small adapter interface.
