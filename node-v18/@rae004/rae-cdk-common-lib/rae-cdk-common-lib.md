# @rae004/rae-cdk-common-lib

> 标签: aws, cdk

## 简介

You should explore the contents of this project. It demonstrates a CDK Construct Library that includes a construct (`RaeCdkCommonLib`) which contains an Amazon SQS queue that is subscribed to an Amazon SNS topic.
