# @glassmorphism/tokens

> 标签: apple, css-variables, design-system, design-tokens, glassmorphism, theme

## 简介

Design tokens for the Glass Kit design system — colors, typography, spacing, motion, springs, elevation, blur, and more, as TypeScript constants and CSS variables.
