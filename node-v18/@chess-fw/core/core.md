# @chess-fw/core

> 标签: board-games, chess, chess-board, chess-engine, chess-framework, chess-game, event-driven, fen, headless-chess, pgn, puzzle-validator, stockfish, typescript

## 简介

Professional, event-driven, framework-agnostic chess engine core in TypeScript. Features time travel, event bus, PGN/FEN parsing, and Stockfish integration.
