# @forthtilliath/ts-kit

> 标签: JavaScript

## 简介

Framework-agnostic TypeScript utility functions — arrays, objects, strings, async control-flow, dates, numbers, browser file downloads, changelog/version parsing, and a couple of `Array` extensions with better type-narrowing.
