# @cavos/kit

> 标签: account-abstraction, device-signer, gasless, multi-chain, passkey, secp256r1, smart-wallet, solana, starknet, stellar, webauthn

## 简介

Embedded Stellar wallet SDK, embedded Solana wallet, and embedded Starknet wallet. Device-native self-custodial accounts for React Native and web.
