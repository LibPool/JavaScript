# dsh-url-router

> 标签: deep-link, deepseek-harness, dsh, plugin, router, url

## 简介

DSH Web GUI 地址栏路由插件：每个界面都有自己的链接（会话 / 主面板 / 插件页与组件页 / 任务看板），整行即真链接，只写 fragment。
