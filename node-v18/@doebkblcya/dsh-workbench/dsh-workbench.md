# @doebkblcya/dsh-workbench

> 标签: deepseek, dsh, file-explorer, git, source-control, vscode, workbench

## 简介

DSH Web GUI right-side workbench plugin: a VS Code-style single right panel with Files/Git tabs plus a Preview column — lazy file explorer, Source-Control-like changes + commit, branch switching, and an inline Git graph — driven by real host-side fs/git s
