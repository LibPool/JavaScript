# @rnby/racp-agent

> 标签: a2a, agent, mcp, oauth, racp, realtime

## 简介

Programmatic RACP agent factory with a live CLI: run an OAuth-backed responder, send/reply/ack across workspaces and federation, plus offline encode/decode.
