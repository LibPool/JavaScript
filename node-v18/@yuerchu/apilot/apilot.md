# @yuerchu/apilot

> 标签: api-documentation, api-explorer, api-testing, developer-tools, openapi, openapi-viewer, openapi3, redoc-alternative, rest-api, swagger, swagger-ui, swagger-ui-alternative

## 简介

**Apilot** 是一个现代化的 **Swagger UI 替代品** — 支持 500+ 端点不卡顿的 OpenAPI 文档查看与 API 测试工具。可直接替代 Swagger UI、Redoc、Scalar，提供 Schema 驱动表单、在线请求测试、模型关系图、多环境管理等功能。
