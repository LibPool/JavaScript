# @dimforge/rapier2d-compat

> 标签: dynamics, joints, physics, real-time, rigid

## 简介

2-dimensional physics engine in Rust - official JS bindings. Compatibility package with inlined webassembly as base64.

## 官网

- 官网：https://rapier.rs
- 源码仓库：git+https://github.com/dimforge/rapier.git
- npm 页面：https://www.npmjs.com/package/@dimforge/rapier2d-compat
