# @inso_web/els-react

> 标签: els, error-boundary, error-monitoring, error-tracking, inso, logging, monitoring, observability, react, sentry-alternative, typescript

## 简介

React bindings for the Error Logs Service (ELS): Provider, hooks, ErrorBoundary and a HOC for automatic component error reporting.
