# @yroshcha/node-red-plugin-grouped-flows

> 标签: flows, node-red, node-red-editor, node-red-plugin, tabs

## 简介

Replaces the built-in Node-RED flows tab bar with a grouped two-tier tab bar to improve navigation of large Node-RED environments. Fork of @shockers/node-red-plugin-grouped-flows with Node-RED 5.x compatibility fixes.
