# ng-typed-routes

> 标签: angular, codegen, navigation, router, routerLink, routes, routing, signals, standalone, type-safe, typed, typesafe, zoneless

## 简介

Type-safe routing for Angular. Generated from your existing app.routes.ts: typed links, typed params, typed navigation. A typo in a link is a compile error, not a 404.
