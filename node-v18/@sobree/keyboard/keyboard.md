# @sobree/keyboard

> 标签: editor, hotkeys, keyboard, shortcuts, sobree, wysiwyg

## 简介

Default keyboard shortcuts plugin for @sobree/core — undo/redo, text formatting, section breaks. Mount via the `keyboard()` factory in `createSobree({ plugins: [...] })`.
