# @bams-app/router

> 标签: JavaScript

## 简介

BAMS-Work 平台的路由包，提供完整的路由体系：静态路由表构建、全局权限守卫、菜单驱动的动态路由注册，以及 404 / 403 / 500 错误页与登录中间件。
