# @hfrancisla/pi-skill-tool

> 标签: agent-skills, pi-extension, pi-package, skills

## 简介

Claude Code-style skill tool for pi. Loads additional skills by exact name, supports skill delegation, and avoids duplicate loads for native /skill:name commands.
