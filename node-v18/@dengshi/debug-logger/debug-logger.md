# @dengshi/debug-logger

> 标签: browser-logging, console, debug, debug-tools, debugger, error-reporting, error-tracking, frontend, log-collector, logger, monitoring, network, performance-monitoring, web-debugging

## 简介

前端调试信息自动收集与上报模块 - 自动捕获控制台日志、网络请求、页面错误，支持控制台快照和批量上报
