# @rida-el-fagrouch/electron-audit

> 标签: asar, audit, cli, electron, fuses, hardening, sast, security

## 简介

A CLI that audits the security hardening of your own Electron app: Electron fuse settings and the JavaScript layer (webPreferences, IPC, contextBridge, network endpoints).
