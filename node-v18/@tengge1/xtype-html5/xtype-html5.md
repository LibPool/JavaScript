# @tengge1/xtype-html5

> 标签: html5, progressive, ui, xtype.js

## 简介

xtype-html5将常用的html5标签封装为类，可以像ExtJs那样通过javascript动态生成页面。这对于功能特别多、逻辑特别复杂的页面特别有用。
