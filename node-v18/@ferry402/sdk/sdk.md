# @ferry402/sdk

> 标签: agent-payments, base, eip-1271, eip-3009, hedera, micropayments, payments, usdc, x402

## 简介

Accept x402 payments from users on other chains. Non-custodial escrow settlement with Hedera Consensus Service as the clearing ledger.
