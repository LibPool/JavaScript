# @ensdomains/verifiable-factory

> 标签: factory, proxy, upgradable, verifiable

## 简介

Verifiable factory for deploying upgradeable smart contract proxies with deterministic CREATE2 addresses and ERC-7201 storage isolation using OpenZeppelin standards.
