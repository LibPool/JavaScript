# @ai-translate/provider-core

> 标签: ai, i18n, internationalization, l10n, llm, localization, structured-output, translation

## 简介

Vendor-neutral translation and semantic-audit engine for ai-translate: prompting, batching, structured output, validation and repair over a pluggable model transport.
