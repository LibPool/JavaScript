# @obilabs/documents

> 标签: JavaScript

## 简介

Pure, dependency-light document primitives for ObiLabs products: HTML sanitizer, markdown renderer, content + signature hashing, and attestation/certificate HTML. No DB, no network, no Aegis imports — the same functions run in the web view and in the PDF
