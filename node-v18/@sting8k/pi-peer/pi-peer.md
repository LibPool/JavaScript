# @sting8k/pi-peer

> 标签: herdr, peer, pi-extension, pi-package, talk

## 简介

Standalone peer-to-peer Pi communication over the Herdr workspace - talk_to, talk_sessions, and talk_latest tools with a resilient local mailbox.
