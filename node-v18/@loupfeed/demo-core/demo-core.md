# @loupfeed/demo-core

> 标签: JavaScript

## 简介

loupfeed demo engine core — human-like Playwright playback (eased cursor travel, visibility-gated clicks, wheel-step scrolling, typing cadence), a declarative scenario schema, and a player that records walkthrough videos.
