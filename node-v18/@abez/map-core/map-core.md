# @abez/map-core

> 标签: choropleth, geo, map, react, svg, topojson

## 简介

Shared engine for @abez country map packages: Albers projection, TopoJSON decoder, drill-down zoom, choropleth, accessible SVG unit rendering. Zero runtime dependencies.
