# @abez/kazakhstan-map

> 标签: choropleth, geo, kazakhstan, map, react, svg, topojson

## 简介

Customizable, accessible SVG map of Kazakhstan for React -- regions and districts, built-in metadata, choropleth, tooltips, and drill-down. Zero runtime dependencies.
