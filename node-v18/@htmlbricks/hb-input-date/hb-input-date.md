# @htmlbricks/hb-input-date

> 标签: JavaScript

## 简介

Native date control with Bulma `input` + `is-success` / `is-danger` and `help is-danger`. Optional `params` as `InputDateParams`: `min` and `max` are passed to `new Date(...)` and mirrored to the input’s `min`/`max` attributes when set. `schemaentry.value
