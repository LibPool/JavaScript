# dsh-artifacts-felix

> 标签: artifacts, cordis, deepseek-harness, dsh-plugin

## 简介

Claude-style Artifacts for DeepSeek Harness: the agent writes web pages, React apps, SVG, Mermaid diagrams, Markdown documents and code into a versioned, live-rendered side panel.
