# qantara

> 标签: agent, claude-code, codex, delegation, mcp, model-context-protocol, multi-agent

## 简介

Qantara (arched bridge): an MCP bridge that lets coding agents (Claude Code, Codex, Gemini) delegate tasks to each other.
