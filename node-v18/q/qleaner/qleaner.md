> 标签: asset-cleaner, ast, babel, bundle-size, cleaner, cleanup, cli, code-analysis, code-audit, code-cleaner, codebase, dead-code, dead-code-elimination, dependency-analysis, file-scanner, files, github-action, images, imports, javascript, jsx, list, maintenance, nextjs, nuxt, optimization, orphaned-files, qleaner, react, react-cleanup, refactoring, static-analysis, tsx, typescript, unused, unused-assets, unused-code, unused-files, unused-imports, vue

## 简介

A CLI tool for analyzing and identifying unused files, images, imports, and dead code in React, Vue, Nuxt, TypeScript, and JavaScript projects to help optimize bundle size and maintain clean codebases
