# querylex

> 标签: ai, cli, database, explain-plan, mariadb, mssql, mysql, natural-language, optimizer, postgresql, query, query-builder, schema, sql, sqlite

## 简介

AI-augmented SQL generation and optimization CLI — generates dialect-correct SQL from natural language using live database context. Supports MySQL, MariaDB, PostgreSQL, SQLite, and Microsoft SQL Server.
