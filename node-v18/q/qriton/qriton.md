# qriton

> 标签: agent, anthropic, claude, cli, coding-agent, grok, local-llm, ollama, openai, terminal, tui, xai

## 简介

Qriton CLI is a terminal coding agent that runs on infrastructure you control. Local models or any major model API, with a memory record, HLM, and Energy Language.
