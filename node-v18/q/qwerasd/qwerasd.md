# qwerasd

> 标签: character-analysis, consecutive, detection, keyboard, password, patterns, qwerty, security, sequence, typescript, validation, weak-password

## 简介

A TypeScript library for detecting consecutive keyboard characters (qwerty patterns, numbers, letters). Perfect for password strength validation.
