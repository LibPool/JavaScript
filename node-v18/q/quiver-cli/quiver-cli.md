# quiver-cli

> 标签: agent-skills, agents, claude-code, cli, codex, lockfile, mcp, opencode

## 简介

Install agent skills from direct GitHub sources, plus custom skills, commands, plugins and MCP servers from catalogs, as native configs for opencode, Claude Code and Codex with per-entry source pins and drift checks.
