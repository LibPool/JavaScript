# quillpdf-mcp

> 标签: bates, cli, local, mcp, merge, metadata, model-context-protocol, pdf, pdf-lib, privacy, rotate, split, watermark

## 简介

Local-first PDF tools — merge, split, rotate, watermark, Bates-number, clean metadata, page-count — as an MCP server and CLI. Your files never leave your machine.
