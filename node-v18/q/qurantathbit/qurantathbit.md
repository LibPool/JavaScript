# qurantathbit

> 标签: flashcards, godot, islam, memorisation, quran, spaced-repetition, web-game

## 简介

A quiet companion for keeping the Qur'an close — one deck, one card at a time, with your own GitHub as the cloud. Web build served from any static host or `npx qurantathbit`.
