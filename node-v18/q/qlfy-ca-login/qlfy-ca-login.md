# qlfy-ca-login

> 标签: qlfy-ca-login, typescript

## 简介

齐鲁风云统一认证登录插件是一个专为齐鲁风云项目内部使用的前端Vue组件插件，实现了与统一认证CA系统的无缝集成。该插件提供了完整的登录状态管理、token自动刷新、登录监听等功能，无需渲染任何UI元素，专注于登录逻辑处理。
