# qnsqy

> 标签: cryptography, encryption, fips-203, fips-204, fips-205, harvest-now-decrypt-later, hndl, hybrid, mcp, ml-dsa, ml-kem, model-context-protocol, post-quantum, pqc, quantum-resistant, quantum-safe, slh-dsa

## 简介

Post-quantum cryptography tool. NIST FIPS 203 / 204 / 205 algorithms hybridized with classical X25519, Ed25519, AES-256-GCM. Local-only execution. 84 MCP tools for AI agents.
