# qr-on-start

> 标签: nextjs, node.js, qrcode, reactjs

## 简介

`qr-on-start` is an NPM package that generates a QR code displaying the URL of your local Next.js development server. This QR code can be scanned to quickly open your development server on a mobile device or another device on the same network.
