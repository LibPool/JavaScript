# qsu

> 标签: array, base64, crypto, date, debounce, decrypt, encrypt, esm, file, format, hash, helper, lodash, math, object, slug, string, throttle, toolkit, tree-shaking, typescript, underscore, util, utility, utils, validation, verify, web, zero-dependency

## 简介

Everyday helpers you would otherwise write yourself: slugs, text case, date math, number and file size formatting, deep clone and merge, email and URL validation, debounce, throttle and hashing. No dependencies.
