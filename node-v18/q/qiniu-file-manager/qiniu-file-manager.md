# qiniu-file-manager

> 标签: node-qiniu, promise, qiniu, qiniu-sdk, upload

## 简介

使用`ES2016 promise`来操作文件的上传、下载、删除等操作，使用该工具可以不必熟读七牛官方`SDK`开发者文档，但是也需要了解一些基本知识，所以你也可去qiniu官方查看[七牛云官方SDK](https://developer.qiniu.com/sdk#official-sdk)。
