# qmd-bridge

> 标签: bridge, docker, gpu, proxy, qmd

## 简介

A lightweight HTTP proxy service and CLI tool for bridging Docker containers to host qmd executable with GPU acceleration.

- npm 页面：https://www.npmjs.com/package/qmd-bridge
