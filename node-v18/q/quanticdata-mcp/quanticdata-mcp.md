# quanticdata-mcp

> 标签: ai-agents, claude, crawl, cursor, mcp, model-context-protocol, proxy, quanticdata, residential-proxies, scraper, serp, web-scraping

## 简介

MCP server for the QuanticData API — scrape, search, map, crawl the web and pull residential/datacenter/mobile proxies for AI agents. Connect QuanticData to Claude, Cursor, and any MCP client.
