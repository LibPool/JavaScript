# qnyutils

> 标签: javascript, js, js-utils, library, node, validate

## 简介

vue项目开发常用js工具类，包括对象、时间、验证、手机号码、身份证、中文校验、英文校验等工具方法，减少多余包引用，增加工具类复用性，提高开发效率;
