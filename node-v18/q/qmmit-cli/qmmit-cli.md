# qmmit-cli

> 标签: agents, ai, aider, claude-code, code-analysis, codex, commits, copilot, cursor, devin, git, qmmit

## 简介

Measure how much of a git repository is committed by AI coding agents. Deterministic signature matching, no heuristics, runs fully locally on private repos.
