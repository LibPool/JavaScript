# q5play

> 标签: p5, p5.js, p5.play, p5js, p5play, p5xjs, q5

## 简介

A beginner friendly, web-based game engine that uses q5.js WebGPU for graphics and Box2D v3 WASM for physics.

- 源码仓库：git+https://github.com/q5play/q5play.git
