# quaesitor-web

> 标签: JavaScript

## 简介

An Angular 11 web interface for [*QUAESITOR*](https://github.com/dpl10/quaesitor). A [live version](https://www.nybg.org/files/scientists/dlittle/quaesitor-web/) is hosted at the New York Botanical Garden.
