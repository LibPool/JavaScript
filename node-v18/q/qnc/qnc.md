# qnc

> 标签: coverage, server, test

## 简介

实现一种查看线上node服务实时代码覆盖率统计的方案，相比本地跑单元测试获取覆盖率，具有对任意服务跑黑盒测试的便捷性。

- 官网：https://github.com/guxima/q-node-coverage#readme
- 源码仓库：git+https://github.com/guxima/q-node-coverage.git
- npm 页面：https://www.npmjs.com/package/qnc
