# quoti-sdk

> 标签: JavaScript

## 简介

Este package consiste de um SDK para API do Quoti, que possiblita que desenvolvedores chamem endpoints da API para realizar ações na platagorma do Quoti com mais facilidade, apenas usando os métodos das classes que o SDK disponibiliza. Isso traz a a vanta
