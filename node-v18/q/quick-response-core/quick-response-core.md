# quick-response-core

> 标签: no-dependencies, qr, qr-code, qr-code-generator, qr-code-with-logo, qr-generator, qr-logo, qrcode, rounded-qr, ssr, svg, svg-path, typescript, vanilla-js

## 简介

Framework-agnostic QR code generator — pure functions that return SVG paths (or a full SVG string) with customizable module shapes, styled finder patterns and a logo knockout. Zero dependencies.
