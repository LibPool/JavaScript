# querymesh

> 标签: data-migration, export, import, mongodb, mssql, mysql, nodejs, oracle, orm, postgresql, query-builder, querymesh, sql

## 简介

Lightweight multi-dialect query builder and ORM for Node.js (PostgreSQL, MySQL, SQL Server, Oracle, MongoDB).
