# qinglin-ui-locale-zh-tw

> 标签: i18n, locale, qinglin-ui, traditional-chinese

## 简介

Traditional Chinese (zh-TW) language pack for qinglin-ui. Install this alongside qinglin-ui to enable Traditional Chinese UI text.

## 官网

- npm 页面：https://www.npmjs.com/package/qinglin-ui-locale-zh-tw

- 1.0.1
