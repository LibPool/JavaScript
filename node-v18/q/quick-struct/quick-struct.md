# quick-struct

> 标签: arraybuffer, big-endian, bin, binary, buffer, c, convert, data layout, decode, encode, endianness, little-endian, rust, struct, structor, variable length

## 简介

C like style to write struct layout, and it can convert variable length array or string automatically. It can be used in Node.js and Browser
