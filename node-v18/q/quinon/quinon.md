# quinon

> 标签: a, algorithm, compare, comparison, culpa, diff, distance, edit, fast, fuga, fuzzy, id, in, levenshtein, similar, similarity, veritatis

## 简介

The most efficient JS implementation calculating the Levenshtein distance, i.e. the difference between two strings.
