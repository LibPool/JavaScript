# qa-probe

> 标签: api-testing, ast, devtools, express, fastapi, frontend, mcp, nextjs, openapi, qa, root-cause, smoke-testing

## 简介

Local QA agent — maps frontend routes to backend API calls, probes every endpoint live, scores pages 0–100, explains why data is missing. Works with any FastAPI/Express/Next.js app.
