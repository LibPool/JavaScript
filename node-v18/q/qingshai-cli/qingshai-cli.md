# qingshai-cli

> 标签: JavaScript

## 简介

1.创建bin/index.js 2.npm link 3.npm i commander 获取参数 4.npm i chalk 美化命令行 5.npm i inquirer 命令行交互工具 6.npm o ora   loading效果 7.npm i git-clone 拉取代码 8.figlet  艺术字
