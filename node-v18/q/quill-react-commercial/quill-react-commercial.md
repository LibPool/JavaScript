> 标签: code-highlight, editor, i18n, image-upload, markdown, quill, quill-react, quill2, react, react-component, rich-text-editor, richtexteditor, table, text-editor, typescript, wysiwyg, wysiwyg-editor, 富文本编辑器, 辰记

## 简介

A production-ready Quill 2 rich text editor for React: tables, image upload & resize, code highlighting with copy, markdown shortcuts, magic URL and i18n.
