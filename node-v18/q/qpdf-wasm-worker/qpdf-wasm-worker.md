# qpdf-wasm-worker

> 标签: client-side, decrypt-pdf, encrypt-pdf, pdf, privacy, qpdf, wasm, web-worker, webassembly

## 简介

qpdf compiled to WebAssembly, run off the main thread in a Web Worker — encrypt/decrypt PDFs entirely client-side, no upload.
