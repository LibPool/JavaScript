# quark-prebuilt

> 标签: JavaScript

## 简介

Install [Quark](https://github.com/freemountain/quark) prebuilt binaries for command-line use using npm without having to compile anything.

## 官网

- 官网：https://github.com/freemountain/quark#readme
- 源码仓库：git+https://github.com/freemountain/quark.git
- npm 页面：https://www.npmjs.com/package/quark-prebuilt
