# queue-runtime

> 标签: concurrency, dead-letter-queue, distributed-queue, exponential-backoff, job-processing, job-queue, queue, rabbitmq, redis, retry, sqs, task-queue, typescript, worker-pool, worker-redistribution

## 简介

A powerful, flexible multi-queue job processing runtime with global worker pool, automatic worker redistribution, and support for multiple queue drivers (Redis, RabbitMQ, AWS SQS, Memory)
