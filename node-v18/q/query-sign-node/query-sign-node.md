# query-sign-node

> 标签: cross-language, hmac, php-compatible, query-string, sign, signature, typescript, verify

## 简介

跨语言一致的请求数据签名（HMAC）库。TypeScript 实现，与 Composer 包 ajaxjs/query-sign-php 产生完全相同的签名。
