# qince-gantt-task-react

> 标签: chart, gantt, gantt chart, gantt-chart, react, react-gantt, svg, task, typescript

## 简介

Interactive Gantt Chart for React with TypeScript. 基于 gantt-task-react 0.3.9 定制版本，包含多段颜色进度条、自定义任务高度、任务条图标等功能。
