# qrcode-lib

> 标签: QRCode, qrcode, qrcodejs, 二维码, 二维码，支持logo, 支持logo

## 简介

QRCode.js is javascript library for making QRCode. QRCode.js supports Cross-browser with HTML5 Canvas and table tag in DOM. QRCode.js has no dependencies. Support logo.
