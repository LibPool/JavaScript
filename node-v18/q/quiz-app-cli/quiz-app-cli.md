# quiz-app-cli

> 标签: JavaScript

## 简介

Welcome to the Space Quiz App repository! This simple Node.js and TypeScript application lets you create and take quizzes about space and Earth-related topics. This README will guide you on how to modify the `quizData.json` file to add more quiz questions
