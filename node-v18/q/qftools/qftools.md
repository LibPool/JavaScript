## 简介

```js npm install qftools ``` ## 导入 ```js const qftools = require('./qftools') ``` ## 格式化 ```js //调用自定义格式化时间的方法 const time= qftools.dateFormat(new Date()) console.log(time); //2022 11 01 14:35:41 ```
