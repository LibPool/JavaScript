# quick-starter-ui

> 标签: npm

## 简介

A fast and modern React starter kit with Vite, Tailwind CSS, Material UI, ShadCN UI, and Redux Toolkit. Pre-configured for performance, scalability, and seamless UI development. Get started instantly!
