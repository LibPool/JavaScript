# querychips

> 标签: accessible, advanced-search, angular, data-filtering, dropdown, elasticsearch, filter, filter-component, framework-agnostic, graphql, javascript, keyboard-navigation, modern-ui, mongodb, query, query-builder, querychips, react, search, search-ui, sql, tags, typescript, ui, vue

## 简介

Framework-agnostic filter UI and query builder for TypeScript. Build tag-based filters in React, Vue, or vanilla JS and compile them to Elasticsearch, SQL, MongoDB, or GraphQL.
