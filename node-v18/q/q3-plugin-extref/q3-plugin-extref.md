# q3-plugin-extref

> 标签: JavaScript

## 简介

This plugin implements the [Extended Reference Pattern](https://www.mongodb.com/blog/post/building-with-patterns-the-extended-reference-pattern) to reduce lookups in your code. It connects to Mongoose's save middleware, so it will not fire on update opera
