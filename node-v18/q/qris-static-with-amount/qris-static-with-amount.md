# qris-static-with-amount

> 标签: bank-indonesia, checkout, dana, digital-payment, dynamic-qr, e-wallet, emv, emvco, gopay, indonesia, indonesian-payment, linkaja, merchant, ovo, payment, payment-gateway, point-of-sale, pos, qr-code, qrcode, qris, qris-generator, qris-indonesia, qris-payment, shopeepay, static-qris, tlv, transaction, type-safe, typescript

## 简介

TypeScript library for inserting transaction amounts into static QRIS (QR Code Indonesian Standard) strings. Supports GoPay, OVO, Dana, ShopeePay, and all Indonesian e-wallets.
