# qmac-editor-sany

> 标签: JavaScript

## 简介

React复杂文本编辑器组件，可插入日期、下拉框、单选框、多选框、单行文本输入框、多行文本输入框、固定字段等常用组件，同时提供文本编辑生成的页面支持动态交互(表单提交)、内容动态替换(设置默认值)和生成水印功能，生成的页面支持前端打印(表格分页带表头、表格横排打印、自定义打印样式)和导出word功能。
