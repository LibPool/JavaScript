# qa-convert-to-html

> 标签: converter, docx, html, inline-css, kiro, qa, testing

## 简介

Converte documentos de teste QA (.docx e .md) em HTML corporativo com CSS inline, pronto para colar em sistemas que sanitizam CSS.
