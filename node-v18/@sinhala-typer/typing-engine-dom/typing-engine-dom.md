# @sinhala-typer/typing-engine-dom

> 标签: dom, ime, input-method, sinhala, textarea, typing-engine

## 简介

Browser <textarea> adapter for @sinhala-typer/typing-engine — binds Edit descriptors to a real textarea, with caret placement and Ctrl+Z/Ctrl+Shift+Z undo/redo. The only package that touches document/window for text composition.
