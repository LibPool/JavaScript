# @sinhala-typer/typing-engine-tiptap

> 标签: ime, input-method, prosemirror, rich-text, sinhala, tiptap, typing-engine

## 简介

Tiptap/ProseMirror adapter for @sinhala-typer/typing-engine — binds Edit descriptors to a rich-text ProseMirror document via transactions, block-scoped resync, undo/redo delegated to Tiptap's own history.
