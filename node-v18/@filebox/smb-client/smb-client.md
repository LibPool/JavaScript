# @filebox/smb-client

> 标签: cifs, napi, napi-rs, smb, smb2, smb3, windows, wnet

## 简介

Cross-platform SMB client for Node.js via NAPI-RS (WNet on Windows, pure-Rust smb2 elsewhere)
