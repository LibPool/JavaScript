# @dunky.dev/state-machine-react

> 标签: JavaScript

## 简介

The **React bindings** for [`@dunky.dev/state-machine`](../core/README.md). The core engine is renderer-agnostic; this package is the thin React edge that drives it: it builds the machine + connector, runs the React lifecycle, bridges the connector's snap
