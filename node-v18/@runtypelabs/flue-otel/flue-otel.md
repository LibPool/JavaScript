# @runtypelabs/flue-otel

> 标签: flue, gen-ai, instrumentation, observability, opentelemetry, otel, runtype

## 简介

OpenTelemetry instrumentation for Flue agents that emits GenAI semconv spans plus Runtype's runtype.* extension vocabulary, so a Flue run lands in Runtype at full fidelity.
