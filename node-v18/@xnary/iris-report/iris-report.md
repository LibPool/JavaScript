# @xnary/iris-report

> 标签: JavaScript

## 简介

IrisReport 画布报告引擎：结构化文档模型 + 段落流式排版分页 + 纸张视口渲染 + PDF 导出（fontkit 度量同源），依赖 iris-common 统一内核（记录/事务/历史/分页/绘制同源层）。
