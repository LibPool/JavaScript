# @brushes/course-proxy-ordering

> 标签: pi-package

## 简介

代客下单(纯API版)——通过curl接口走完全流程：登录鉴权→选择客户→选购商品→加入购物车→购物车结算→确认订单→提交支付→验证订单。全程不依赖浏览器，零Playwright、零截图
