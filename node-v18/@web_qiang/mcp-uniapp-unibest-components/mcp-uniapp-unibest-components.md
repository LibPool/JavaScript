# @web_qiang/mcp-uniapp-unibest-components

> 标签: components, mcp, model-context-protocol, uniapp, unibest, wot-design-uni

## 简介

MCP server (v2 SDK) exposing unibest src/view/main/components business components as tools & resources (stdio + Streamable HTTP). Install once, usable via `npx -y @web_qiang/mcp-uniapp-unibest-components`.
