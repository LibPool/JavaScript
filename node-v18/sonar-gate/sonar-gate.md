# sonar-gate

> 标签: git-hook, java, maven, pre-push, python, quality-gate, sonar, sonarqube

## 简介

SonarQube pre-push 本地质量门禁：一条命令把 sonar-scanner 分析 + Quality Gate 判定（Java 模板先做 Maven 构建）前移到 git push 之前，内置 Java SpringBoot 与 Python 模板
