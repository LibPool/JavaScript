# @unirate/koa

> 标签: currency, currency-converter, exchange-rates, fintech, forex, fx, koa, koa-middleware, koa-router, middleware, money, unirate, vat

## 简介

Koa middleware and router for the UniRate currency-exchange API. unirate() attaches a typed client to ctx.state.unirate; unirateRouter() returns a @koa/router with /rate, /convert, /currencies, /vat JSON routes and full error mapping. Zero runtime deps; k
