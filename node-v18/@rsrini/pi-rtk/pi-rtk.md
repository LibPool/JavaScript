# @rsrini/pi-rtk

> 标签: ai, extension, pi, pi-coding-agent, pi-package, rtk, token-reduction

## 简介

RTK token reduction extension for pi-coding-agent - reduces LLM token consumption 60-90% by wrapping commands with external rtk binary and intelligently filtering tool output
