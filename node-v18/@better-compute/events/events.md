# @better-compute/events

> 标签: better-compute, dead-letter-queue, events, outbox, server-sent-events, signed-webhooks, sse, webhooks

## 简介

Event delivery for better-compute: per-tenant signed webhooks with retries and dead letters, and the SSE /watch stream, read from the outbox.
