# @better-compute/gateway

> 标签: agent, better-compute, daemon, fleet, gateway, grpc, http2, mtls

## 简介

The better-compute gateway: daemon sessions over gRPC/HTTP/2 mTLS, liveness, command dispatch and Join/Renew/Secret forwarding.
