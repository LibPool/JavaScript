# @null-pointer/mcp-archimate

> 标签: application-architecture, archimate, architecture-modeling, business-architecture, diagrams, enterprise-architecture, mcp, mermaid, model-context-protocol, technology-architecture, xml-export

## 简介

A Model Context Protocol (MCP) server for ArchiMate 3.2 enterprise architecture diagrams. Creates Mermaid and ArchiMate XML diagrams with validation against ArchiMate 3.2 specification.
