# @rhombuskit/tokens

> 标签: css-variables, dark-mode, design-system, design-tokens, rhombuskit, scss, theming

## 简介

Framework-agnostic design-token contract for RhombusKit — palette primitives plus light/dark semantic theme packs, emitted as CSS custom properties, SCSS, and TypeScript.
