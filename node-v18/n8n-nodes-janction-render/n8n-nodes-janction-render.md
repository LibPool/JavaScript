# n8n-nodes-janction-render

> 标签: 3d, blender, glb, gpu, n8n-community-node-package, product-photos, rendering, turntable

## 简介

n8n node for JANCTION Render: render Blender scenes and 3D models (GLB, FBX, USD, OBJ, STL) on cloud GPUs. Product shots, 360-degree turntables, animations and stills as PNG or MP4.
