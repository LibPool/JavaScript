# @ozjsey/v-select-text

> 标签: clipboard, contenteditable, copy, directive, input, range, select, selection, text-selection, textarea, vue, vue3

## 简介

Vue 3 directive for reactive text selection — select the rendered text of any element by range or pattern, optionally copying it, plus inputs, textareas and contenteditable
