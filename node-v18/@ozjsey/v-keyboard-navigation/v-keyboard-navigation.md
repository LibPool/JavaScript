# @ozjsey/v-keyboard-navigation

> 标签: a11y, accessibility, aria-activedescendant, arrow-keys, directive, focusgroup, hover, keyboard, keyboard-navigation, listbox, menu, radiogroup, roving-tabindex, scroll-into-view, tablist, toolbar, typeahead, vue, vue3

## 简介

Vue 3 directive that turns a group of controls into one tab stop — roving tabindex, arrow keys, typeahead, Home/End, real PageUp/PageDown — with the controlled scroll (focus preventScroll + block:'nearest') the browser's own focus scroll gets wrong
