# @biomate/connect

> 标签: bioinformatics, biomate, chatgpt, claude, codex, cursor, mcp

## 简介

One-line installer that connects BioMate to Claude Code, Claude Desktop, Cursor, Codex, and ChatGPT via OAuth 2.1 + PKCE.
