# @simantic/cloud-sim

> 标签: cloud-sim, firmware, mcu, simantic, simulator

## 简介

TypeScript client for the Cloud Sim API: run MCU firmware in the cloud, follow its output live, and compare simulation engines.

## 官网

- 官网：https://simantic.com/cloud-sim
