# @nativescript-community/sqlite-android-framework

> 标签: Android, JavaScript, NativeScript, SQLite

## 简介

Use the SQLite of the Android platform (android.database.sqlite) as the engine of @nativescript-community/sqlite-core: no SQLite library in the app.
