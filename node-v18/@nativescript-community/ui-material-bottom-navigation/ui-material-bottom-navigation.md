# @nativescript-community/ui-material-bottom-navigation

> 标签: Android, Angular, Bottom Navigation, Bytpher, Henry Chavez, JavaScript, Material Design, NativeScript, Typescript, Vue, iOS, preview|https://raw.githubusercontent.com/nativescript-community/ui-material-components/master/images/demo-bottom-navigation.png

## 简介

Material Design Bottom Navigation bars allow movement between primary destinations in an app. Tapping on a bottom navigation icon takes you directly to the associated view or refreshes the currently active view.
