# @forinda/kickjs-ws

> 标签: centrifugo, decorator-driven, decorator-websocket, heartbeat, kickjs, namespaces, nodejs, pubsub, realtime, redis, rooms, socket.io, typescript, websocket, ws

## 简介

Realtime for KickJS: decorator-driven WebSocket controllers on ws or Socket.IO, a Redis broker for multiple instances, and a Centrifugo integration
