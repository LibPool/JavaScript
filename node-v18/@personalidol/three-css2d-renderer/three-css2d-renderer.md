# @personalidol/three-css2d-renderer

> 标签: JavaScript

## 简介

Custom implementation of `three` `CSS2DRenderer` that is capable of running in the worker thread. Instead of rendering directly to DOM, it renders views supported by `dom-renderer` package and communicates via shared memory and message channels.
