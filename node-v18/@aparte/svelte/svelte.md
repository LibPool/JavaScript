# @aparte/svelte

> 标签: ai, ai-chat, aparte, chat, chat-ui, svelte, web-components

## 简介

Svelte wrapper for aparté — an ergonomic <AparteChat> component plus stores over the framework-agnostic web components. Works on Svelte 4 and 5.
