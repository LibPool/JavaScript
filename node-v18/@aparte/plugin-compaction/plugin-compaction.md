# @aparte/plugin-compaction

> 标签: agent, aparte, compaction, context-window, plugin, summary

## 简介

Conversation compaction for aparté — summarise the turns that no longer fit the model's window, keep the recent ones verbatim, and answer the context gauge's aparte-compact.
