# @xsolla/payment-client-core

> 标签: JavaScript

## 简介

1. установить node.js или nvm 2. `npm install -g npx` 3. `npm install -g @angular/cli` 4. `git clone git@gitlab.loc:pay-station/payment-client-core.git` 5. если не работает lint перед commit: `chmod +x .husky/pre-commit`
