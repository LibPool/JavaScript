# @xsolla/xui-b2c-popover

> 标签: JavaScript

## 简介

Responsive overlay panel for player-facing surfaces — a 400px floating panel on desktop and tablet, a full-screen page on mobile, optionally draggable and pinnable. The container behind the Xsolla ID profile popover.
