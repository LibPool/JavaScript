# @xsolla/xui-b2c-progress-bar

> 标签: JavaScript

## 简介

B2C quest/onboarding progress bar: a hatched 24px groove with an optional header. Distinct from the base `@xsolla/xui-progress-bar`, which is the generic loading/upload indicator.
