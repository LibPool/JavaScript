# @scribefinance/sdk

> 标签: agentic-economy, ai-agents, machine-payments, mpp, recurring-payments, robinhood-chain, scribefinance, subscriptions, usdg, x402

## 简介

The official Scribe Finance SDK: recurring payments, spending allowances, and metered usage for autonomous agents, settled in USDG on Robinhood Chain.
