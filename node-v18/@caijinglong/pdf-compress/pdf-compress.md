# @caijinglong/pdf-compress

> 标签: browser, compress, nodejs, pdf, pdf-lib

## 简介

一个面向 Node.js 和现代浏览器的 PDF 图片压缩库，专门压缩 PDF 中的位图图片内容，尽量不破坏文本、字体和矢量元素。
