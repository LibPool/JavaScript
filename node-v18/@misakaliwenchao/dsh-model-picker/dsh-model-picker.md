# @misakaliwenchao/dsh-model-picker

> 标签: deepseek, dsh, model-picker, plugin

## 简介

DSH 模型选择大面板：接管输入框模型席位，80vw×80vh 弹窗（渠道侧栏 + 模型卡片网格），按渠道分组、可搜索、显示每个模型的最近可用性与首字延迟，支持逐个/批量主动测试与渠道模型探测。可用性台账持久化于 ~/.dsh/dsh-model-picker-health.json。
