# @aurorah/wmep

> 标签: encapsulation, module-protocol, typescript-interface, web-module-export-protocol, wmep

## 简介

Web Module Export Protocol (wMEP) — file/module-level micro-protocol for wMCP. One typed interface per module is the only export across module boundaries.
