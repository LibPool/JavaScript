## 简介

Zero-config i18n for JavaScript/TypeScript with automatic translation. Works with Next.js, SvelteKit, and any Node or browser app. ICU MessageFormat compatible. Write strings in any language, render with i18n.t`...`. No message IDs, no catalogs, no API ke
