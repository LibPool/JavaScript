> 标签: compiler, fine-grained, framework, frontend, jsx, reactive, signals, ssr, typescript, zero-dependency

## 简介

Lithe v1.1: a zero-dependency TypeScript-first compiler, fine-grained frontend/full-stack framework built on browser APIs and Node.js built-ins.
