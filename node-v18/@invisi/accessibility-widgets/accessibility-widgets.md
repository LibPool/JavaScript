# @invisi/accessibility-widgets

> 标签: a11y, accessibility, ada, assistive-technology, colorblind, disabilities, dyslexia, frontend, high-contrast, inclusive, javascript, screen-reader, section508, ui, ux, voice-control, wcag, web-accessibility, widget

## 简介

A comprehensive, lightweight accessibility widget that enhances web accessibility for all users. Provides multiple accessibility features including screen reader support, voice control, high contrast mode, and more.
