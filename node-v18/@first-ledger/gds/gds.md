# @first-ledger/gds

> 标签: design, figma, system, tailwind, tokens, typography

## 简介

This project is a comprehensive design system that integrates design tokens and typography for the First Ledger and First Ledger Mobile applications, facilitating a cohesive visual experience across platforms.
