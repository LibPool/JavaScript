# @alstroemeria/claude-directory

> 标签: anthropic, claude, claude-code, cli, dashboard, directory, dotclaude, explorer, sessions

## 简介

Explore your Claude Code home (~/.claude) — a local, read-only, educational dashboard for sessions, transcripts, agents, skills, hooks, commands, memory, todos, plans, and history, with an explain mode aligned to Anthropic's official .claude directory doc
