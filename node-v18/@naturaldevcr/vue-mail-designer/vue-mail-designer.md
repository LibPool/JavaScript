# @naturaldevcr/vue-mail-designer

> 标签: drag-and-drop, email, email-builder, email-editor, html-email, newsletter, unlayer, vue, vue3

## 简介

A visual drag & drop email builder for Vue 3. Exports email-client-compatible HTML and a re-editable design JSON.
