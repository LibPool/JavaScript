# dsh-claude-delegate

> 标签: agent-sdk, anthropic, claude-code, deepseek-harness, dsh, dsh-plugin

## 简介

DSH tool plugin: delegate a self-contained task to your local Claude Code subscription (official Agent SDK). Fork of zhangjunjesse/dsh-claude-code, with a live output channel, resume and a monitor panel.
