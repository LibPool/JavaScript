# @joyapple/dsh-brand-custom

> 标签: JavaScript

## 简介

DSH 品牌定制插件：可配置的英雄区标语（hero.headline / hero.preview）与品牌 logo 替换。Brand customization plugin: configurable hero slogan and logo.
