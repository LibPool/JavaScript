# @ubhub/maps

> 标签: 3d, deck.gl, geocoding, maplibre, maps, mongolia, nextjs, react, routing, ubhub

## 简介

Official UBHUB SDK for React and Next.js: vector maps with 3D buildings and trees, place search, typed geocoding, reverse geocoding and routing for Mongolia.
