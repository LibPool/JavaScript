# @panphora/sapjs

> 标签: alpine, dom, html, hyperclay, malleable, no-build, reactive

## 简介

A reactive HTML library where the DOM is the only state store. Structure-first, one write path, transient rebuild. An Alpine alternative built for malleable, self-saving HTML.
