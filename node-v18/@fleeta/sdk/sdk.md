# @fleeta/sdk

> 标签: api-client, dashcam, driver-safety, fleet, fleet-management, fleeta, gps-tracking, sdk, telematics, typescript

## 简介

Official JavaScript/TypeScript client for the Fleeta Open API — fleet dashcam data, GPS tracking, safety events, video and driving reports. Zero-dependency, fetch-based.
