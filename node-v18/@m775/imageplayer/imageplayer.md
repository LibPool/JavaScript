# @m775/imageplayer

> 标签: 360 viewer, gentbo, image cache, image sequence, image-player, imageplayer, pointer events

## 简介

A lightweight high-performance JavaScript image sequence player with image preloading, decoding cache, touch dragging, progress control, playback control, loop, reverse playback, speed adjustment, and Pointer Events support.
