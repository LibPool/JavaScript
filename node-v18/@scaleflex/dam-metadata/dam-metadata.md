# @scaleflex/dam-metadata

> 标签: JavaScript

## 简介

Metadata schema engine for Scaleflex DAM: schema parse/validate, field components, dependency engine, taxonomies, ultratags, and product fields. Foundation for @scaleflex/bulk-edit.
