# statejar

> 标签: agents, llm, memory, statejar

## 简介

Typed JavaScript/TypeScript client for the hosted StateJar memory API. Not a memory engine: memory lives on the StateJar service.

## 官网

- 官网：https://statejar.com
- npm 页面：https://www.npmjs.com/package/statejar
