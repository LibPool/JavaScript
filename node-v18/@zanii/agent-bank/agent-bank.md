# @zanii/agent-bank

> 标签: JavaScript

## 简介

Treasury accounts for AI agents: spending policy (per transaction, per day, per merchant category, allowed counterparties) checked before money moves, a double-entry journal that always balances, and reconciliation of the journal against settled payments.
