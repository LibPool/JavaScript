# @zanii/cv

> 标签: JavaScript

## 简介

AgentCV — a signed, portable CV over data the ledger already holds. The summary is the ledger's own un-inflatable aggregate; curated entries each point at a verifiable receipt/cert. Proves the entries are real, never that the history is complete.
