# @zanii/escrow

> 标签: JavaScript

## 简介

Conditional payments between agents as verifiable agreements - co-signed terms, a deterministic release verdict when a matching receipt lands in the log with an inclusion proof, and signed release/refund instructions. Zanii never holds funds: money moves
