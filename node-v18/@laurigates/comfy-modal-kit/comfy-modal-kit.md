# @laurigates/comfy-modal-kit

> 标签: JavaScript

## 简介

Shared modal-shell + fzf-lite fuzzy-matcher primitives for ComfyUI custom-node packs. Single-sourced TypeScript, built to bundled ESM + declarations.
