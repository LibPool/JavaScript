# @logicsrc/openprd

> 标签: cli, logicsrc, openprd, prd, product-requirements, standards

## 简介

Reference implementation of the OpenPRD standard: numbered product requirements documents with front-matter, fixed sections, a lifecycle, and a LogicSRC task bridge.
