# @logicsrc/opencontext

> 标签: agents, context, json-schema, logicsrc, opencontext, permissions, provenance, standards

## 简介

Reference implementation of the LogicSRC OpenContext standard: durable, portable, permissioned, provenance-aware context resolved into deterministic bundles for humans and AI agents.
