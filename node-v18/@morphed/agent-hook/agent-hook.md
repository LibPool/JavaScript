# @morphed/agent-hook

> 标签: agent, claude-code, codex, crm, governance, guardrails, hook, hubspot, morphed, pre-tool, pretooluse

## 简介

Morphed CLI + pre-tool hook for Claude Code and Codex. `morphed login` signs in through your browser (OAuth) and `morphed send` delegates work to Morphed's managed HubSpot delivery service; the pre-tool hook gates writes through Morphed's decision service
