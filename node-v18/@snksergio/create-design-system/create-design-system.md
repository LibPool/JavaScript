> 标签: bootstrap, create, design-system, iGreen, react, tailwindcss, template, vite

## 简介

Bootstrap projects consuming the iGreen DS via shadcn registry (copy-in) — React 19 + Vite + Tailwind v4, cn/tv/theme + registry @igreen pre-configured, com manifesto + drift check (igreen:add / igreen:drift).
