# @sc0031/pixelvault

> 标签: blurhash, exif, image, resize, rust, wasm, web-worker, webassembly, webp

## 简介

Client-side image pipeline (resize, WebP/JPEG/PNG, EXIF strip + orientation fix, BlurHash) — Rust → WebAssembly, runs in a Web Worker.
