# @m2canvas/connect

> 标签: JavaScript

## 简介

Connect your local agent clients (Claude Code, Codex, Cursor, OpenCode, Qoder) to M2 Canvas over MCP in one command.

## 官网

- 官网：https://m2ui.ai/mcp
- npm 页面：https://www.npmjs.com/package/@m2canvas/connect

## 获取地址

- npm 安装：`npm install @m2canvas/connect`
- npm registry：https://registry.npmjs.org/@m2canvas/connect
- Node 要求：>=18
