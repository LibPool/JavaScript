# @deserialize/ultra-agg-sdk

> 标签: aggregator, defi, deserialize, ethereum, non-custodial, perps, rwa, solana, swap, web3

## 简介

TypeScript client for the Deserialize Ultra Aggregator: one API for DeFi data and actions across swaps, memecoins, perps, prediction markets and RWAs on Solana and EVM. Includes an executor for the steps[] action contract.
