# @nestim/koishi-plugin-qq-group-manager

> 标签: ai, chatbot, group, koishi, koishi-plugin, llonebot, memory, moderation, onebot, qq, vision

## 简介

Koishi QQ群管理插件（OneBot/LLOneBot）：群管命令、权限校验、图片菜单、状态卡片、复读、AI群聊回复、记忆库、识图与自动管控（禁言/踢人）。
