# skipverse

> 标签: ann, embeddings, from-scratch, hnsw, nearest-neighbor, similarity-search, vector-database, zero-dependency

## 简介

A from-scratch vector database: HNSW approximate nearest neighbor index, zero runtime dependencies, crash-safe WAL, deterministic replay, and a living search visualization.
