# pi-zip

> 标签: cache, compaction, context, pi-extension, pi-package

## 简介

Keeps long Pi sessions cheap without losing anything: folds older output when the savings pay for the rewrite, prepares summaries in the background, and recalls originals byte for byte. Zero config.
