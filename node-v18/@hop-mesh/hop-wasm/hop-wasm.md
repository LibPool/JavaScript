# @hop-mesh/hop-wasm

> 标签: JavaScript

## 简介

The wasm/browser binding of hop-core: a real Node<JsStore> (host-owned storage via a StoreBridge), JS-consumable via wasm-bindgen. Its primary consumer today is the browser swarm simulator.
