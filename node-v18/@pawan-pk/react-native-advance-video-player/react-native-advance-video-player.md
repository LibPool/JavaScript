# @pawan-pk/react-native-advance-video-player

> 标签: android, ios, react-native

## 简介

@pawan-pk/react-native-advance-video-player is a next-gen React Native video player supporting HLS and HTTP streaming for smooth, high-quality playback, with easy integration and customizable features for a seamless media experience.
