# @nutanix-scratch/lifecycle-js-client

> 标签: Nutanix Lifecycle Management APIs, nutanix

## 简介

The Javascript client for Nutanix Lifecycle Management APIs is designed for Javascript client application developers offering them simple and flexible access to APIs that manage Infrastructure, Software and Firmware Upgrades.
