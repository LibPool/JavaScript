# @nutanix-scratch/iam-js-client

> 标签: Nutanix Identity and Access Management APIs, nutanix

## 简介

The Javascript client for Nutanix Identity and Access Management APIs is designed for Javascript client application developers offering them simple and flexible access to APIs that nutanix APIs for managing users, user-groups, directory services, identity
