# @karzounchat/dashboard-sdk

> 标签: dashboard, iframe, karzoun, miniapps, postmessage, sdk

## 简介

Lightweight SDK for building Karzoun dashboard panel apps. Provides a typed postMessage bridge for executing miniapp actions, receiving conversation/customer context, and triggering host UI actions from sandboxed iframes.
