# @funpixel/sdk

> 标签: JavaScript

## 简介

Funpixel game SDK — host channel (ready/leaderboard/liveParams/gameState), device APIs (haptics/camera/geolocation/sensors/filesystem), assets, audio (iOS-safe), pathfinding, and engine fx for pixi/three, multiplayer (Room API over the relay).
