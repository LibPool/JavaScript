# @oustn/cloudflare-apns2

> 标签: apn, apns, apns2, apple, http2, ios, jwt, macos, notification, push, tvos, watchos

## 简介

Cloudflare worker client for connecting to Apple's Push Notification Service using the new HTTP/2 protocol with JSON web tokens.
