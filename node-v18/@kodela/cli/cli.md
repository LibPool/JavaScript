# @kodela/cli

> 标签: ai, claude, code-context, context, copilot, cursor, developer-tools, mcp, memory

## 简介

Kodela CLI — the system of record for AI-assisted development. One-line `kodela connect` wires the Kodela MCP server + silent-capture watcher into every AI coding tool.
