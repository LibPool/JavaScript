# @bopstack/oxc

> 标签: bopstack, javascript, lint, naming-convention, oxc, oxlint, typescript

## 简介

Oxlint plugin for Bopstack project conventions — naming, inline styles, colors, test extensions, empty catches, and ts-ignore.
