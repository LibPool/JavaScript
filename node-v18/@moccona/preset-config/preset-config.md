# @moccona/preset-config

> 标签: prettierrc, tsconfig

## 简介

A set of preset configs for standardizing and streamlining configuration across projects. Includes pre-configured settings for common tools like TypeScript, Prettier, and Browserslist to ensure consistent development workflows with minimal setup.
