# @guajiritos/services

> 标签: JavaScript

## 简介

`Guajiritos Services` es una librería para Angular que proporciona los servicios, interfaces, pipes y utilidades necesarios para el correcto funcionamiento de las plataformas de Guajiritos S.R.L.
