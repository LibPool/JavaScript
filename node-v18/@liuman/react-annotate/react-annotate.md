# @liuman/react-annotate

> 标签: annotation, bug-report, feedback, kanban, markup, react, screenshot, typescript, visual-feedback

## 简介

In-app visual annotation & kanban for React: pick any element, screenshot it, draw on it, and turn it into an assignable task — without leaving the app
