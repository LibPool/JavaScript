# @artesoft/timeout-scheduler

> 标签: adaptive, angular, cooperative, dynamic, freeze-proof, performance, priority, react, requestAnimationFrame, requestIdleCallback, scheduler, setTimeout, vue

## 简介

A performance-oriented, freeze-proof scheduler that provides a priority-based task system to prevent UI blocking.
