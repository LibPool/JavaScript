# @exortek/jwk

> 标签: backend, ec, ed25519, jose, jwk, node-crypto, rfc-7517, rfc-7638, rfc-8037, rfc-9278, rsa, security, thumbprint, x25519

## 简介

JSON Web Key (JWK) — RFC 7517 / RFC 7638 / RFC 8037 for Node.js. Generate, import, export, thumbprint EC / RSA / OKP / oct keys. Zero-dependency, built on node:crypto.
