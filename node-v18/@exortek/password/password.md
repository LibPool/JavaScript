# @exortek/password

> 标签: argon2, argon2id, backend, bcrypt, diceware, hash, have-i-been-pwned, hibp, needs-rehash, node-crypto, passphrase, password, password-generator, password-policy, password-strength, pbkdf2, peppering, phc, scrypt, security, verify

## 简介

Password hashing, verification, strength scoring, generation, policy validation, HIBP breach lookup, peppering and history helpers for Node.js — argon2id, scrypt, bcrypt, pbkdf2 under one coherent API with automatic algorithm routing on verify.
