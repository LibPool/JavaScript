## 简介

Zero-dependency cryptographic primitives for Node.js — hash / hmac / KDFs (PBKDF2, HKDF, scrypt), AES-GCM / ChaCha20-Poly1305 / RSA-OAEP ciphers, RS/PS/ES/EdDSA signatures, signed cookies, sealed timed tokens, CSPRNG (UUID v4/5/7, ULID, base58, crockford)
