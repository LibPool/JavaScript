# @arkstack/encryption

> 标签: aes-gcm, arkstack, cryptography, e2ee, ecdh, encryption, end-to-end, isomorphic, webcrypto

## 简介

Isomorphic end-to-end encryption for Arkstack: AES-256-GCM ciphers, ECDH key pairs, and key generation/comparison utilities that run identically in Node and the browser.
