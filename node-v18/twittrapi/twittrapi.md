# twittrapi

> 标签: nodejs, sdk, social media data, tweets, twitter api, twitter followers, twitter scraper, twitter search, twittrapi, typescript, x api

## 简介

Node.js and TypeScript SDK for TwittrAPI: read public Twitter/X tweets, profiles, followers and search results, and post, like, follow or send DMs as your own account. Pay as you go from $0.065 per 1,000 calls.
