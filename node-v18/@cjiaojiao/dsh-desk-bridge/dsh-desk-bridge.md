# @cjiaojiao/dsh-desk-bridge

> 标签: JavaScript

## 简介

Desk bridge for the dsh web GUI: capability detection plus a thin Tauri IPC bridge (window.__DSH_DESK__) with zero business logic. In a plain browser the bundle degrades to a no-op.
