# @ailink/sdk

> 标签: ai, ailink, automation, chat, claude, gemini, groq, llm, openai, typescript

## 简介

Turn any existing function into an AI-callable tool. Wrap any external SDK — LangChain, Vercel AI, and more — without touching your existing code. Multi-provider, role-based access, session memory, parallel execution, and automatic fallbacks.
