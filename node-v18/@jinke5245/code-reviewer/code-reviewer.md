# @jinke5245/code-reviewer

> 标签: JavaScript

## 简介

Code Reviewer is an early-stage AI-assisted code review CLI. It aims to provide a review experience similar to GitHub Copilot Code Review while keeping the core review engine portable across code hosting platforms.
