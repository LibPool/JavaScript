> 标签: ai-agent, claude, fica, futa, household-employer, household-employment, mcp, model-context-protocol, nanny, nanny-payroll, nanny-tax, payroll, schedule-h, tax, tax-calculator, w2

## 简介

MCP server for calculating US household employer (nanny) taxes. All 50 states. Works with Claude, ChatGPT, and any MCP-compatible AI agent.
