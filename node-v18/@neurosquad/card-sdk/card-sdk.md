# @neurosquad/card-sdk

> 标签: agents, canvas, card, neurosquad, plugin, sdk

## 简介

Build custom cards for NeuroSquad: a typed client for the card API, React hooks, an optional dark UI kit and the neurosquad-card CLI (create, dev, validate, pack).
