# @rbxts/vela-runtime

> 标签: classname, rbxts, roblox, roblox-ts, runtime, tailwind, tailwindcss, vela

## 简介

The runtime class resolver behind vela-rbxts. Installed as a dependency of vela-rbxts; transformed modules import it rather than carrying a copy.
