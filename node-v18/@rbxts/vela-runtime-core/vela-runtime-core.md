# @rbxts/vela-runtime-core

> 标签: classname, rbxts, roblox, roblox-ts, runtime, tailwind, tailwindcss, vela

## 简介

The framework-neutral half of the vela-rbxts runtime: class resolution, theme normalization, rem math and value parsing. Installed as a dependency of the host runtime a project's UI library needs.
