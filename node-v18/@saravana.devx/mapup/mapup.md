# @saravana.devx/mapup

> 标签: JavaScript

## 简介

Stamps debug IDs into builds and uploads their sourcemaps so error stack traces resolve to original source. CLI + Vite plugin + Metro config wrapper + Gradle/Xcode hooks for React Native release builds.
