# @ocero/dsh-fresh-environment-creator

> 标签: agent, dsh, environment, experiment, isolation, npx, plugin, profile, sandbox, scaffold, skills

## 简介

Scaffold a fully-isolated fresh dsh profile for agent experiments and plugin development (modeled on profiles/-exp): own settings/credentials/storage/sessions, empty skill catalog, and the code-noskill preset.
