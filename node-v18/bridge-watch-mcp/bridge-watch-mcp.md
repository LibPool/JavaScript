# bridge-watch-mcp

> 标签: address-labels, agent, base, crypto, ethereum, llm, mcp, modelcontextprotocol, usdc, x402

## 简介

Zero-dependency MCP stdio bridge for Bridge Watch: 104,209 on-chain address labels + 7 x402-metered tools on Base. 1 free anonymous call per tool per IP per day.
