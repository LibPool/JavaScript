# @emdzej/inpax-logger

> 标签: JavaScript

## 简介

Pino-backed structured logger for the INPAX workspace. Wraps `pino` with a tiny adapter so every package writes through the same namespaced logger, with log level controlled by `INPAX_LOG_LEVEL`.
