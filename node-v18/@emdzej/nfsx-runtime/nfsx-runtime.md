# @emdzej/nfsx-runtime

> 标签: JavaScript

## 简介

CABI-style IPO runtime for nfsx. Wraps the inpax VM with the NCSEXPER 99-slot CABI surface (via @emdzej/ncsx-inpax-cabi-provider) plus NFS-specific overrides for flash/FSC/AIF slots not in the NCSEXPER table.
