# @emdzej/nfsx-flash-data

> 标签: JavaScript

## 简介

Parsers + integrity checks for the firmware payloads winkfpt feeds to ECUs. Motorola S-records (S0/S1/S2/S3/S5/S7/S8/S9), memory-map coalescing, CRC32 verification.
