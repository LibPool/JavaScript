# @emdzej/bimmerz-rpc-core

> 标签: JavaScript

## 简介

JSON-RPC 2.0 over WebSocket client used by the bimmerz-box dongle's /rpc endpoints. Transport-only — protocol-specific clients (UART, CAN, ...) build on top.
