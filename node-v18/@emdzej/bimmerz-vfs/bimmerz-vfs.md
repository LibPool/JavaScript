# @emdzej/bimmerz-vfs

> 标签: JavaScript

## 简介

Read-only virtual file system abstraction for bimmerz tools — same interface over local File System Access API, remote HTTP index.json trees, and an OPFS / IndexedDB cache layer for the HTTP backend.
