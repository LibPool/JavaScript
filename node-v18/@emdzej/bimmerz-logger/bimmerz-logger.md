# @emdzej/bimmerz-logger

> 标签: JavaScript

## 简介

Shared structured logger for the bimmerz family — pino-shape API, hierarchical categories, runtime-mutable config, pluggable sinks. No env reads, isomorphic (Node + browser), tree-shake-friendly.
