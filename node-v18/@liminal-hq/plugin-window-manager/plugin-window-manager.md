# @liminal-hq/plugin-window-manager

> 标签: JavaScript

## 简介

Lets a frameless app reach window manager features a webview cannot: it reports which are supported, and asks the compositor to show its own window menu. On GNOME and other Wayland desktops that menu holds working "Always on Top", workspace moves and more
