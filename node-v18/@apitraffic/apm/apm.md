# @apitraffic/apm

> 标签: apitraffic, apm, instrumentation, opentelemetry, otel, telemetry, tracing

## 简介

Opt-in OpenTelemetry bridge for ApiTraffic. Maps finished OpenTelemetry spans (pg, mysql, mongodb, redis/ioredis, undici/fetch, kafka, amqp, aws-sdk, ...) onto the active ApiTraffic request as ApiTraffic spans + per-request rollup metrics, either as a spa
