# @buoy-gg/permissions

> 标签: PermissionsAndroid, debugging, devtools, expo, expo-camera, expo-location, expo-notifications, permissions, react-native, react-native-devtools, react-native-permissions, testing

## 简介

Permission state overrides for React Native: make your app see not asked, allowed, limited, denied or blocked for location, camera, notifications and more, without touching device settings. Works with Expo modules, PermissionsAndroid and react-native-perm
