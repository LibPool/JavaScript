# @fragmentsx/fragments-client

> 标签: JavaScript

## 简介

Клиентское ядро Fragments: загрузка и кеширование областей (area), фрагментов и css-чанков, метрики. Транспортный слой, на котором строится `@fragmentsx/runtime-react` — сам по себе фреймворк-агностичен и не зависит от React.
