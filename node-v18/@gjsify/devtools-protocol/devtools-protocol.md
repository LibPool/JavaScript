# @gjsify/devtools-protocol

> 标签: dbus, debug, devtools, gjs, gtk, mcp

## 简介

Transport-agnostic devtools contract (methods, JSON envelope, method-kinds, transport interface) shared by every gjsify devtools adapter and the MCP bridge
