# @gjsify/tls-native-linux-s390x

> 标签: JavaScript

## 简介

linux-s390x prebuilt native library + GObject-Introspection typelib for @gjsify/tls-native. Installed automatically on linux/s390x as an optionalDependency of that package (ADR 0017) and skipped everywhere else. Contains no JavaScript.
