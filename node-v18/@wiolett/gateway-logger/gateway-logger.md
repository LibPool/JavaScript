# @wiolett/gateway-logger

> 标签: JavaScript

## 简介

`@wiolett/gateway-logger` is a Node-first TypeScript SDK for sending application logs into Wiolett Industries Gateway. It handles Gateway ingest tokens, context merging, batching, retries, rate-limit backoff, trace/span identifiers, and graceful shutdown
