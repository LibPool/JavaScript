# @gsalgadotoledo/rt-app-cache

> 标签: JavaScript

## 简介

TTL cache-aside with stable content hashes. `new Cache().remember(namespace, input, ttlMs, loader)`. JSON values only, 64 KB maximum; memory is process-local.
