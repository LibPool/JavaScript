# @jamunlabs/gameu-controller-css-v1

> 标签: JavaScript

## 简介

Phone-controller chrome stylesheet for the gameu platform — body halftone background, gesture-pad surface, status banner, root layout, decorative phone-corner accents. Pairs with @jamunlabs/gameu-sdk's gameu-theme-v1.css design tokens.
