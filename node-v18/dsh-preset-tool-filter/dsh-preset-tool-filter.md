# dsh-preset-tool-filter

> 标签: agent-preset, cordis, deepseek-harness, dsh, tool-filter

## 简介

按 preset 裁剪模型可见工具目录的小插件：profile 层随行按 agent 跟踪 preset（创建/切换/销毁），通过 agent.ctx 注册 tools.restrict，把 profile 层全局工具（如 imagegen）从指定模式的会话里隐藏
