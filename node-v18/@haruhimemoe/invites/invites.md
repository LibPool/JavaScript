# @haruhimemoe/invites

> 标签: consent, invite, invites, osu, osu!, reminders, state machine, tournament, zod

## 简介

Invites as consent: zod schemas for invites and their terms, a pure state machine (pending, countered, accepted, declined, withdrawn, cancelled, expired), resend cooldowns, blocks, rate limits, reminder gating and inbox grouping. No dependencies besides z
