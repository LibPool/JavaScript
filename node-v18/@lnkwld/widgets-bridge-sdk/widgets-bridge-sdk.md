# @lnkwld/widgets-bridge-sdk

> 标签: JavaScript

## 简介

组件 bridge，主要用于定义「组件」<->「编辑器」的 interface。其中包含组件定义，编辑器需要提供的能力，编辑器与组件共同的运行环境 dll 实现 etc
