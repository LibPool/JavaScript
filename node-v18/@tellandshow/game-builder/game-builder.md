# @tellandshow/game-builder

> 标签: JavaScript

## 简介

The visual builder UI for Tell and Show's Game Studio. React + Vite app the kid opens via `tns builder`. Cards organized by intent (start a game, add a character, build a level, etc.); imports the wizard engine + AI Partner panel from @tellandshow/builder
