# @tellandshow/story-engine

> 标签: choose-your-own-adventure, education, kids, story-engine, tellandshow

## 简介

Branching choose-your-own-adventure runtime for Tell and Show's Story Studio. Loads a story tree (JSON nodes + edges), renders narration + SVG drawings + CSS-tween animations + video clips, tracks the reader's path in localStorage. Ships as plain JS — no
