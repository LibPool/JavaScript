# @tellandshow/site-builder

> 标签: JavaScript

## 简介

The visual builder UI for Tell and Show's Site Studio. React + Vite app the kid opens via `tns builder`. Cards organized by intent (start a site, add a page, add a section, pick a theme, edit metadata); imports the wizard engine + AI Partner panel from @t
