# @tellandshow/movie-assets

> 标签: JavaScript

## 简介

CC0 backgrounds, music loops, and SFX for Tell and Show's Movie Studio. Bundled with the kid's deployed movie. M1 = empty placeholder; M3 ships the real asset library.
