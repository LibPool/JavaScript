# @bamr87/fleet-feedback

> 标签: feedback, fleet, github-issues, web-component

## 简介

Universal 'Improve this page' widget: a zero-dependency <fleet-feedback> web component that files a prefilled GitHub issue with page context, environment, and captured console errors. Spec: bamr87/bamr87 specs/FEEDBACK.md.
