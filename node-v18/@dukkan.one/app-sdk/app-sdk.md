# @dukkan.one/app-sdk

> 标签: dukkan, e-commerce, oauth, platform-api, sdk, webhooks

## 简介

Official Dukkan app SDK: typed Platform API client, OAuth install and token rotation, signed webhook receiving, and commerce helpers.
