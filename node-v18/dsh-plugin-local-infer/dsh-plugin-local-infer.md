# dsh-plugin-local-infer

> 标签: ai-agent, cordis, cordis-plugin, deepseek, deepseek-harness, dsh, dsh-plugin, llama.cpp, llm, local-inference, ninfer, vllm, vram

## 简介

DeepSeek Harness plugin that manages local inference engines (llama.cpp, NInfer, Hyper-Qwen, Strata): configure, size, launch, and publish a local engine as a DSH model. Installable bundle that mounts the localInfer service, engine providers, model-facing
