# @ngxviewbuilder/plugin-docs

> 标签: angular, confluence, documentation, form-builder, low-code, plugin, view-builder

## 简介

Documentation plugin for the NGX View Builder designer: describe every field next to its properties and get a ready field reference table for Confluence, kept outside the view JSON.
