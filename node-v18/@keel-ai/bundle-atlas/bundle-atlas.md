# @keel-ai/bundle-atlas

> 标签: JavaScript

## 简介

Bundle size + dependency analyzer for Keel apps. Equivalent of webpack-bundle-analyzer for metro/Hermes bundles. Renders an interactive treemap or prints a plain-text summary.
