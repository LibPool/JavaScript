# xhr-mocker-panel-sdk

> 标签: JavaScript

## 简介

**描述**    xhr-mocker-panel-sdk 是一个基于 xhr-mocker 的项目，用于拦截和修改 AJAX/Fetch 请求响应。它提供了一个可视化的控制面板，基于monaco-editor的代码编辑器，用于实时监控请求和自定义配置 Mock 数据, 可再此基础上扩展ai-mock,json-schema-mock等功能。
