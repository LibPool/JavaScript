# x-request-pool

> 标签: ajax pool, axios pool, http pool, request pool

## 简介

> >Http的前端请求池，避免重复的请求。 > >使用单例模式，相同的请求会只发送一次，其余的则等待同请求返回后，再返回。 > > [Demo](https://mikexia930.github.io/xRequestPool/) ## 版本 - v1.0.14
