# xinyao-chat-embed-sdk

> 标签: chat, customer-service, embed, iframe, sdk, widget

## 简介

心耀智能客服「访客侧」聊天窗 iframe 控制层：把独立聊天页（chat-page）包进 iframe，控制宽高/移动/显示隐藏，通过 postMessage 注入 app_key/app_secret（不暴露在 URL），并透传页面事件。零依赖。
