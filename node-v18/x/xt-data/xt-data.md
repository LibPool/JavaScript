# xt-data

> 标签: JavaScript

## 简介

安装模块 npm i xt-data 导入模块 const str = require('xt-data') 使用: 有三个参数，第一个参数为字符串， 第二个为需要过滤的字符，第三个为过滤后替换的新字符 str.getStr('abc' , 'a' , 'bbb') // 把abc内容a过滤替换成bbb
