# x402-agent-suite-preflight

> 标签: agentic-payments, agentkit, ai-agents, dexter, guard, langchain, preflight, trust-layer, usdc, x402

## 简介

Drop-in preflight guard for AI agents — one call to the x402 Trust Layer (guard + security grade + attestation) before any paid x402_fetch. Works with any agent framework (LangChain, CrewAI, Coinbase AgentKit).
