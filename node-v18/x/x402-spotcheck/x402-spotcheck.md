# x402-spotcheck

> 标签: 402xagent, agents, base, guard, mcp, onBeforePaymentCreation, payments, pre-payment-check, router, solana, usdc, x402

## 简介

Check before you pay, for x402 clients and routers. Local rules by default (no network calls, no tracking); the 402xAgent service is opt-in. Unknown means pay; skip only with a reason code.
