# xheader-extend

> 标签: Header, Nav, Nav bar, Navigation, Navigation bar, XHeader, extend, vue, vux, vux extend, 导航条, 扩展

## 简介

xheader-extend 是对 Vux 中 XHeader 组件的扩展，提供了导航条选项的配置接口，使其支持转发 Header（导航条） 的配置，以便其它种类的导航条也能够统一应用配置
