# xero-sdk

> 标签: accounting, api, oauth2, payroll, sdk, typescript, xero

## 简介

Production-grade, dependency-free TypeScript SDK for the entire Xero API platform: Accounting, Assets, Files, Projects, Bank Feeds, Finance, Practice Manager, App Store, eInvoicing, and Payroll (AU/NZ/UK).
