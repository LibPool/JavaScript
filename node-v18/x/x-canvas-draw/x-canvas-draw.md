# x-canvas-draw

> 标签: JavaScript

## 简介

> x-canvas-draw是一款专为web端打造的强大工具插件，它能够将普通的 HTML5 Canvas 元素升级为一个高度交互式的创作平台。通过简单的 API 调用，用户可以在画布上自由地添加文字与图像，并且能够直观地调整这些元素的大小及位置，极大地增强了网页应用的灵活性与用户体验。
