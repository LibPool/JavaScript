# xueqiu-cli

> 标签: cli, portfolio, rebalance, xueqiu, 股票, 调仓, 雪球

## 简介

雪球（xueqiu.com）组合调仓命令行工具：复用浏览器 Cookie，支持整体调仓、单笔买卖、批量配置文件调仓。
