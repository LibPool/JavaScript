# xw-tpl-cli

> 标签: @vue/cli, cli, create, project, template

## 简介

通过命令 tpl create xx 去快速创建各种大前端框架模版。如 vue2、vue3、react、uniapp、RN、webRTC、three、node 等初始工程化项目。
