# xchange-rates

> 标签: currency, currency-conversion, currency-converter, currency-rates, exchange, exchange-api, exchange-rate, finance, financial-api, forex, forex-rates, fx, fx-rates, international, money, real-time

## 简介

A lightweight Node.js package to get real-time currency exchange rates for any base currency using a pivot currency, fetched directly from a CDN for fast and reliable access.
