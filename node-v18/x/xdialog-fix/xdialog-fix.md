# xdialog-fix

> 标签: Alert, Confirm, XDialog, vux, 弹窗, 遮罩

## 简介

xdialog-fix 解决了vux中的 XDialog 组件 和 基于 XDialog 实现的组件(如：Alert、Confirm)的遮罩下面的内容可交互的问题
