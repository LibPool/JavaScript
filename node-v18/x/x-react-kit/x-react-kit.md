# x-react-kit

> 标签: boilerplate, cli, generator, project-generator, react, react-router, redux, rtk-query, scaffolding, tailwind, typescript, vite

## 简介

Use via: npm create x-react-kit (or npx x-react-kit). Create React apps the easy way with Vite, TypeScript, Tailwind, and more.
