# x402-codesearch-mcp

> 标签: claude, code-search, embeddings, mcp, model-context-protocol, semantic-search, vector-search, x402

## 简介

Free MCP server: index a repo's files (free) into the live x402-codesearch Worker so it can be semantically searched. Open funnel twin of the paid x402-gated codesearch HTTP API.
