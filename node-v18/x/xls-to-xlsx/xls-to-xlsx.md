# xls-to-xlsx

> 标签: chainguard, converter, csv, docker, excel, ods, spreadsheet, wolfi, xls, xlsx

## 简介

Secure XLS → XLSX converter (also CSV/ODS/JSON). Pure-JS helpers + a tiny client SDK + a hardened, CVE-scanned Docker image.
