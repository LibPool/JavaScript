# xjgitdir

> 标签: JavaScript

## 简介

> 搭建一个 git 提交代码处罚进行 “自动 git-commit 注释规范检查” 、 “自动执行 ESLINT 代码语法检查” 、“自动执行 Prettier 代码规范格式化” 环境
