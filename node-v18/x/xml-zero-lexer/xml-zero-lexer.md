# xml-zero-lexer

> 标签: html, jsx, lexer, markup, parser, react, string, stringto, stringtoreact, token, tokenise, typescript, xml

## 简介

Friendly and forgiving HTML5/XML5/JSX lexer/parser with lots of tests. Memory-efficient and Web Worker compatible.
