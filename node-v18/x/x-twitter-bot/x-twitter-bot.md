# x-twitter-bot

> 标签: automation, bot, puppeteer, scraper, twitter, x

## 简介

Twitter/X automation library powered by Puppeteer. Cookie-based auth, tweet with media, like, scrape stats & comments, follow/unfollow users, edit profile.
