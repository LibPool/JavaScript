# xrechnung-generator

> 标签: e-invoice, e-rechnung, einvoice, erechnung, generator, x-rechnung, xrechnung

## 简介

A lightweight Node.js module for creating XRechnung-compliant invoices in the UBL (Universal Business Language) format.
