# xapikorea

> 标签: automotive, car data, encar, encar api, encar parser, encar.com, korean car api, korean used cars, typescript, used car api, vehicle data, xapi korea

## 简介

Encar API client for TypeScript and Node.js: search Korean used-car listings, prices, specs, photos and inspection history via XAPI Korea (independent, unofficial).
