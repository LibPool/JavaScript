# xbesh-adapter

> 标签: adapter, authentication, authjs, database, email, nextauth, pocketbase, xbesh

## 简介

xBesh-Adapter is a powerful and flexible adapter that seamlessly integrates xBesh and NextAuthJS into your NextJS application. The adapter provides support for authentication and session management using JWT, allowing you to easily and securely manage use
