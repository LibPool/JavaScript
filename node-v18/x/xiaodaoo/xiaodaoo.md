# xiaodaoo

> 标签: JavaScript

## 简介

1.注册npm账号 2.切换npm源至npm 3.初始化项目  `$npm init -y` 4.创建入口文件 5.开发 6.登录npm账号 `$npm adduser` 7.发布项目 `$npm publish`
