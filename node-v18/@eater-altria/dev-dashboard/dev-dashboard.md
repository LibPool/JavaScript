# @eater-altria/dev-dashboard

> 标签: JavaScript

## 简介

一个使用 [Ink](https://github.com/vadimdemedes/ink) 和 React 构建的终端开发者仪表盘。直接在命令行中管理你的待办事项（TODO）、分支记录，查看 **CPU、内存与磁盘** 等性能信息、**RSS 订阅**，以及 **天气日历**。
