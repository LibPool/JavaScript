# @alife-sdk/mapgen

> 标签: alife, autotile, mapgen, pathfinding, procedural, tilemap

## 简介

Procedural top-down map generator for the A-Life SDK — framework-agnostic, outputs MapDefinition consumed by Phaser or any renderer adapter
