# stori3d-mcp

> 标签: ai-agent, architecture, bim, mcp, model-context-protocol, stori3d

## 简介

MCP server that lets AI agents (Claude Code, OpenAI Codex, Google Antigravity, Gemini CLI, Cursor, VS Code) see and edit a Stori3D project open in the browser.
