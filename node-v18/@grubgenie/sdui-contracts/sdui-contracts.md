# @grubgenie/sdui-contracts

> 标签: JavaScript

## 简介

Shared contracts for the GrubGenie SDUI (Server-Driven UI) system — Zod schemas, TypeScript types, constants, and the `sduiCatalog` used by both the frontend and backend.
