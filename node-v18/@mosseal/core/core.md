# @mosseal/core

> 标签: cryptography, mosseal, share-links, wasm

## 简介

TypeScript wrapper for MOSSEAL consumer-compiled wasm (spec 04). Loads wasm, handles URL fragments, mirrors the wasm error taxonomy.
