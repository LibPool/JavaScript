# @wpbevel/upload

> 标签: bevel, elementor, mcp, upload, wordpress

## 简介

Send files to a Bevel MCP upload link from a shell: globs, SHA-256 receipts, retries. No dependencies.

## 官网

- 官网：https://wpbevel.com
- npm 页面：https://www.npmjs.com/package/@wpbevel/upload
