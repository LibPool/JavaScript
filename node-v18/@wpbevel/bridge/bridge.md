# @wpbevel/bridge

> 标签: bevel, elementor, mcp, model-context-protocol, wordpress

## 简介

Local MCP server that gives a desktop assistant file access to a Bevel site: list a folder, upload its files to the site with no user action.

- 官网：https://wpbevel.com
