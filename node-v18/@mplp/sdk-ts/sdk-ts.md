# @mplp/sdk-ts

> 标签: ai agents, ai-agent-lifecycle, facade, lifecycle, mplp, multi-agent, protocol, sdk, typescript

## 简介

Derived public TypeScript helper facade for MPLP v1.0.0; ships builders, runtime client helpers, schema mirrors, and Kernel Duty exports.
