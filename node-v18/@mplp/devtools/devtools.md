# @mplp/devtools

> 标签: developer-tooling, lifecycle, mplp, multi-agent, protocol

## 简介

Public developer-tooling convenience package for MPLP v1.0.0. Aggregates schema and conformance utilities and CLI helpers; not a direct protocol object mirror.
