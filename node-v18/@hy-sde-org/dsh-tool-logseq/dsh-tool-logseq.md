# @hy-sde-org/dsh-tool-logseq

> 标签: agent, deepseek, dsh-plugin, harness, logseq, tool, wiki

## 简介

Model-facing Logseq CLI tools (logseq_list/upsert/remove/query/show/search/graph/server) that drive a Logseq database graph from the terminal — headless-capable alternative to the desktop MCP bridge
