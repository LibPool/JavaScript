# @nocobase/hub-cli

> 标签: JavaScript

## 简介

Publishes a NocoBase application to a NocoBase Hub: adds the `nocobase hub` commands (remote, auth, deploy, upload) to the application that depends on it.

## 官网

- 源码仓库：git+https://github.com/nocobase/nocobase3.git
- npm 页面：https://www.npmjs.com/package/@nocobase/hub-cli
