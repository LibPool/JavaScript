# @megapixel99/didrun

> 标签: ci, empty-glob, evidence, exit-code, false-positive, guard, no-tests, silent-failure, smoke-test, subprocess, test-runner, verification, zero-dependency, zero-tests

## 简介

Run a command and get a tri-state answer: did it RUN, did it FAIL, and was the failure the RIGHT one. An exit code cannot tell you the first.
