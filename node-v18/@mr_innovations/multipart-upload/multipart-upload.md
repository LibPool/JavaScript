# @mr_innovations/multipart-upload

> 标签: app-router, chunked, file-type, large-file, mime-type, multipart, next, nextjs, react, resumable, sha256, upload

## 简介

Resumable multipart file uploads for Next.js — server route handlers, browser client and React hook. No database: the filesystem is the state.
