# @leaven-graphql/leaven

> 标签: api, apollo, bun, graphql, mercurius, server, typescript

## 简介

Meta-package for Leaven, a high-performance GraphQL library for the Bun runtime. Re-exports the runtime modules (core, http, ws, context, errors, plugins, playground) and selected schema helpers; the NestJS integration ships separately as @leaven-graphql/
