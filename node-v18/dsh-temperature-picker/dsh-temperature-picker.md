# dsh-temperature-picker

> 标签: deepseek, deepseek-harness, dsh-plugin, llm, sampling, temperature

## 简介

DeepSeek Harness plugin: a temperature picker button left of the model selector — ticked slider (0–1.2, step 0.1) plus range-checked input, applied to every provider via the agent/request waterfall, persisted through the profile patch.
