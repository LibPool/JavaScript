# @jikida/init

> 标签: ai-security, bootstrap, django, express, fastapi, fastify, flask, init, install, jikida, jikida.io, laravel, middleware, next.js, sdk, security, symfony, vibe-coding, waf

## 简介

One command to install a production Web Application Firewall. Detects Node (Next.js / Express / Fastify), PHP (Laravel / Symfony), and Python (Django / FastAPI / Flask), installs the right Jikida SDK, wires the middleware, writes JIKIDA_TOKEN to .env. $0
