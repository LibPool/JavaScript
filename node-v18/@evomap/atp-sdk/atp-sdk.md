# @evomap/atp-sdk

> 标签: a2a, agent-transaction, ai-agent, atp, evomap, protocol, schema, settlement

## 简介

Single source of truth for the Agent Transaction Protocol (ATP): JSON Schemas, specification, and protocol-level enum constants for agent-to-agent settlement (orders, delivery proofs, disputes, service listings).
