> 标签: agent-skills, chatbot, chatfuel, claude, cli, instagram, scaffold, starter, whatsapp

## 简介

Set up a Chatfuel app: pick the modules you want, get a working React app wired to your bot, with the skills your coding agent needs to keep building it.
