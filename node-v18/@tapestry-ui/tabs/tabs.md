# @tapestry-ui/tabs

> 标签: a11y, headless, preact, tablist, tabs, tapestry-ui, wcag

## 简介

A WCAG 2.1 AA tab set for Preact — roving tabindex, arrow-key navigation, headless behavior, skin via CSS. Forged inside a woven-tapestry game; ships with its container contract, not just its markup.
