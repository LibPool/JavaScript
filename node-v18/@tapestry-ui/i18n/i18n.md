# @tapestry-ui/i18n

> 标签: i18n, l10n, locale, preact, pseudo-locale, signals, tapestry-ui, translation

## 简介

A small i18n core for Preact apps — a typed catalog, per-key fallback, CLDR plurals, and a pseudo-locale that makes untranslated text visible. The app sets keys, the DOM resolves.
