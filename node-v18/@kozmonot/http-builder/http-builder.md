# @kozmonot/http-builder

> 标签: ajax, api, axios, builder, client, fetch, fluent, frontend, http, http-client, javascript, promises, request, type-safe, typescript, utility

## 简介

A simple and lightweight Publish/Subscribe (PubSub) utility for decoupled communication. Ideal for managing events between modules without direct dependencies.
