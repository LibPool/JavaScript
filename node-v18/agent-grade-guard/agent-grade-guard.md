# agent-grade-guard

> 标签: ai agents, ai-agents, blocklist, bots, cloudflare, cloudflare-workers, crowdsourced-security, express, honeypot, llms-txt, nextjs, prompt-injection, security

## 简介

Crowdsourced decoys that catch attack bots and AI agents on any site, and lock them out of every protected site: Cloudflare Worker, Next.js middleware, Express. Never blocks search engines or AI search bots.
