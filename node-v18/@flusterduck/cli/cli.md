# @flusterduck/cli

> 标签: cli, command-line, confusion-score, flusterduck, rage-click, ux-analytics

## 简介

Flusterduck CLI (scoped alias of flusterduck-cli). Set up rage click and UX friction tracking from your terminal. Check confusion scores, manage issues, record deploys.
