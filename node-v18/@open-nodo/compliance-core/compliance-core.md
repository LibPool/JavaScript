# @open-nodo/compliance-core

> 标签: JavaScript

## 简介

Jurisdiction-agnostic compliance abstraction for third-sector / nonprofit accounting: the JurisdictionPack contract (chart of accounts, statutory report schemas, filing thresholds, fiscal-year rules, locale-aware labels) + a registry. Each country/regime
