# @1delta/calldata-sdk-sol

> 标签: JavaScript

## 简介

⚒️ Builds Solana transactions for the lenders the SDK serves — the peer of @1delta/calldata-sdk: same entrypoints, instructions instead of composer calldata, artifacts that expire. No viem, no Solana runtime.
