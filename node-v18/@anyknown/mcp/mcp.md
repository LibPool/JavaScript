# @anyknown/mcp

> 标签: JavaScript

## 简介

TypeScript types for the RPC interface of the anyknown MCP hub, which other Workers call through a service binding. The root entry ships type declarations only, with no runtime code. `@anyknown/mcp/portable` ships the hub's adapters as runtime code: readi
