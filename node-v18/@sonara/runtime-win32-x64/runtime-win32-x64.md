# @sonara/runtime-win32-x64

> 标签: electron, runtime, sonara, text-to-speech, tts

## 简介

The Sonara runtime (sonarad.exe) for Windows x64, to bundle with an app (electron-builder extraResources). Use with @sonara/client.
