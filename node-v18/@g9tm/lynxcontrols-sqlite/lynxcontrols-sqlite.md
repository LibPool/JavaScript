# @g9tm/lynxcontrols-sqlite

> 标签: JavaScript

## 简介

SQLite persistence: lossless value codecs, driver contract, queries with C# null semantics, repositories, caches, migrations, interceptors, soft delete, filters. Drivers are separate packages.
