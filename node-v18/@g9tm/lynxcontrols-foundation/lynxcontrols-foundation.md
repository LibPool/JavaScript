# @g9tm/lynxcontrols-foundation

> 标签: JavaScript

## 简介

Pure TypeScript core: design tokens, theme model, culture (strings, digits, calendars, relative time, durations), icon model, safe execution, diagnostics, preference and capability contracts. No React, no UI.
