# @adara-network/mcp

> 标签: JavaScript

## 简介

Model Context Protocol (MCP) server for the Adara Protocol — exposes the protocol as agent-callable tools (register, ventures, task lifecycle, verify, settle) over @adara-network/sdk. No key custody: the agent runs the server with its own key.
