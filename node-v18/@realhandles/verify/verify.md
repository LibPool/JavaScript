# @realhandles/verify

> 标签: did, did:key, ed25519, identity, impersonation, jws, realhandles, self-sovereign-identity, verification

## 简介

Independently verify RealHandles signed identity proofs. Isomorphic and dependency-light (jose only), so the same verification runs in a browser, a serverless function, or anyone else's tooling.
