# @suss/contract-aws-apigateway

> 标签: api-contract, api-drift, api-gateway, aws, lambda, static-analysis, suss

## 简介

Turn an AWS API Gateway REST or HTTP API into a suss contract and check it against the Lambda handlers and clients that use it.
