# @agnamo/bingo

> 标签: bingo, bootstrap, cli, cloud, devops, harness, orchestration, python, terminal, vm

## 简介

Bingo - a rich terminal CLI wrapper and cloud harness for orchestrating Windows workstations and remote Linux VMs (VM bootstrap, package cheats, tool installs, harness dispatch).
