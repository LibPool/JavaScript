# @wangxiang0605/answer-first

> 标签: guard, pi, pi-extension, pi-package, workflow

## 简介

Pi extension: Enforces an answer-first workflow: edit/write tool calls are blocked until the model produces its first text reply in the run. / Pi 扩展：在模型动手之前强制「先回答、再复述、后确认」：本次运行中第一段文本回复出现前，edit / write 调用一律拦截。
