# @wangxiang0605/resource-manager

> 标签: extensions, pi, pi-extension, pi-package, resource-manager, skills

## 简介

Pi extension: Opens an overlay via `/res` to list and enable/disable extensions and skills (through `.disabled` renaming), with pagination. / Pi 扩展：用 `/res` 打开浮层，集中查看并启用 / 禁用扩展与技能（通过 `.disabled` 重命名），支持分页。
