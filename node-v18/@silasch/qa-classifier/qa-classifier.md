# @silasch/qa-classifier

> 标签: anthropic, ci, claude, qa, test-failure, triage

## 简介

AI-driven CI failure classifier (Claude) + persistence sidecars. Reads junit + logs + optional screenshots, returns structured classification + optional draft-PR proposal. Ships qa-persist-supabase + qa-persist-sentry bins for cross-run history + P0 escal
