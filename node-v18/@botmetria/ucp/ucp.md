# @botmetria/ucp

> 标签: agentic-commerce, ai-agents, catalog, chatgpt, ecommerce, express, ucp

## 简介

UCP (Universal Commerce Protocol) store-side SDK: make any Node.js shop visible and shoppable for AI agents — manifest, agent-readable catalog, checkout sessions with signed cart hand-off. Bundles the Botmetria AI-bot analytics collector as a second entry
