# circuitsherpa

> 标签: agent, bom, cli, digikey, electronics, mcp, mouser, parts, pricing

## 简介

Command-line client for Circuit Sherpa: search electronic parts across Digi-Key and Mouser, price a BOM at quantity, manage price alerts. Same API and same API key as the MCP server.
