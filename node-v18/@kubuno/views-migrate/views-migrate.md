# @kubuno/views-migrate

> 标签: JavaScript

## 简介

Codemod from React/TSX screens of Kubuno web modules to .kbview / .kbcontrol views with a TypeScript code-behind (vskubuno WEB-VIEWS.md §6.2, WV-11): @ui elements, Tailwind layout, i18next strings, state, handlers, lists and conditionals, with a per-file
