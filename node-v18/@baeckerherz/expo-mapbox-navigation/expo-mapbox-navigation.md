> 标签: alpha, directions, driving, expo, expo-module, mapbox, mapbox-navigation, mapbox-navigation-sdk, mapbox-navigation-v3, navigation, react-native, react-native-navigation, routing, turn-by-turn

## 简介

Expo module for turn-by-turn navigation (Mapbox Navigation SDK v3) on iOS and Android. Alpha. Single MapboxNavigation component, Expo config plugin.
