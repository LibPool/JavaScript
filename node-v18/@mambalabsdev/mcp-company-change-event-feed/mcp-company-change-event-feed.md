> 标签: apify, buying-signals, change-detection, clay, company-changes, delta-tracking, gtm-signals, mcp, model-context-protocol, sales-intelligence

## 简介

MCP server for the Mamba Labs Company Change-Event Feed actor on Apify. Monitor a company domain for changes across hiring, tech stack, funding, firmographics, and social since the last run, returned as flat Clay-ready JSON change events.
