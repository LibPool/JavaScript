# @mambalabsdev/mcp-review-platform-reputation-enricher

> 标签: apify, clay, company-data, mcp, model-context-protocol, reputation, reviews, trustpilot

## 简介

MCP server for the Mamba Labs Trustpilot Reputation Enricher actor on Apify. Resolve a company domain to its Trustpilot rating, review count and claimed status.
