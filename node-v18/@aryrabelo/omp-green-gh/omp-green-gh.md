# @aryrabelo/omp-green-gh

> 标签: coding-agent, extension, github, oh-my-pi, omp, pi, plugin, pull-request, status-bar

## 简介

OMP harness extension: the current branch's pull request status plus the repo's other open PRs in your statusline — what is green, and what is blocking it?
