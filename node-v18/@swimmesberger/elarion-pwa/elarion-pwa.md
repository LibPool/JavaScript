# @swimmesberger/elarion-pwa

> 标签: JavaScript

## 简介

The installable-app shell for Elarion frontends: install-prompt capture with iOS Home Screen instructions, a deploy-update watcher that reloads only on a safe page change, service-worker registration, a /sw module whose shell router never caches the API,
