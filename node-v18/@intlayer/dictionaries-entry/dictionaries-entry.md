# @intlayer/dictionaries-entry

> 标签: alias, dictionaries, dynamic, entry, fetch, intlayer, remote, unmerged

## 简介

Provides the entry points for the generated Intlayer dictionaries (merged, unmerged, remote, dynamic, fetch), designed to be aliased by bundlers like Webpack, Vite, Turbopack, esbuild and Metro.
