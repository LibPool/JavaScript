# @misaka10091/dsh-remote-control

> 标签: deepseek-harness, dsh, dsh-plugin, gateway, pairing, remote-access, remote-control

## 简介

Pairing-gated remote access for the dsh web GUI: a self-hosted reverse-proxy gateway, a device panel and a local audit trail, with an optional managed Cloudflare Tunnel and no relay unless you enable one. | DeepSeek Harness 远程控制插件：配对鉴权网关、设备管理面板与本地审计，可选内置
