# @stratavcs/mcp

> 标签: mcp, model-context-protocol, simplystream, strata, unreal, webgpu

## 简介

Strata MCP server — the shared tool surface for agent CLI backends (roadmap 5A.6). Wraps the Strata HTTP API (repos, builds, verify verdicts, doctor captures) as MCP tools over stdio, plus a hosted streamable-HTTP remote at mcp.stratavcs.com.
