# @falcontracker/rrweb-plugin

> 标签: error, rrweb

## 简介

在捕获的错误信息中添加上 rrweb 页面录制功能，用于方便查看错误产生根源。

- npm 页面：https://www.npmjs.com/package/@falcontracker/rrweb-plugin
