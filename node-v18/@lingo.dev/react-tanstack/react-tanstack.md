# @lingo.dev/react-tanstack

> 标签: JavaScript

## 简介

Lingo.dev for TanStack Start and TanStack Router: locale rewrite, bare-path redirect, message catalog, request context, head tags and a language switcher over @lingo.dev/locale-router.
