# @edium/auto-redact

> 标签: console, deep-redact, deep-redaction, gdpr, isomorphic, json, logger, logging, mask, masking, pii, redact, redaction, regex, sanitization, sanitize, secrets, security, typescript

## 简介

Deep, configurable redaction of secrets and PII from objects, arrays, and strings - by key, value pattern, or path. Isomorphic (Node + browser), zero dependencies, TypeScript-first.
