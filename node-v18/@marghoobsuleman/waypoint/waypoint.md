# @marghoobsuleman/waypoint

> 标签: claude-code, cursor, dashboard, mcp, model-context-protocol, project-tracker, sqlite, waypoint

## 简介

A local-first project tracker with a web dashboard, REST API, and an MCP server so AI editors (Claude Code, Cursor, Antigravity) can read and log your project context automatically.
