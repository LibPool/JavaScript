# @adapttable/mantine

> 标签: dark-mode, data-table, datagrid, mantine, mantine-datatable, react, responsive-table, rtl, server-side-pagination, table, typescript, url-state, virtualized-table

## 简介

Mantine adapter for AdaptTable — a batteries-included, themeable React data table with sorting, filtering, URL state, virtualization, RTL, dark mode, and responsive card rendering.
