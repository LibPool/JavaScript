# @zeitraum/client

> 标签: JavaScript

## 简介

The [`@zeitraum/client`](https://www.npmjs.com/package/@zeitraum/client) allows to start interface with the [Zeitraum](https://github.com/KennethWussmann/zeitraum) API. Build JavaScript and TypeScript based integrations without dealing with GraphQL or RES
