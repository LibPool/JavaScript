# @nanocodana/browser

> 标签: agent, ai, ai-sdk, browser, byok, client-side, coding-agent, indexeddb, llm, nanocodana, vercel-ai-sdk

## 简介

Run a full NanoCodana coding agent entirely in the browser, over an in-memory or IndexedDB filesystem. No server, no backend.
