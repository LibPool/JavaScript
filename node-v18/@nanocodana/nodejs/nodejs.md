# @nanocodana/nodejs

> 标签: agent, ai, ai-sdk, cli, coding-agent, filesystem, llm, nanocodana, nodejs, ripgrep, vercel-ai-sdk

## 简介

Run a NanoCodana coding agent over your real filesystem, with a sandboxed shell that can escalate to the host on approval.
