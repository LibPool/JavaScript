# @hlnx4/token-shrink

> 标签: ai, anthropic, chatgpt, claude, cli, compression, cost-reduction, gemini, llm, mcp, openai, prompt-engineering, tokens

## 简介

Compress LLM prompts to minimum tokens. Zero API calls. 30-60% token savings on every message.
