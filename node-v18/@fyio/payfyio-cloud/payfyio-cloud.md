# @fyio/payfyio-cloud

> 标签: client, fetch, payfyio, payment, saas, sdk, typescript

## 简介

Typed client SDK for the Payfyio Cloud SaaS API — a thin fetch wrapper over the dashboard / admin / API surface. Zero runtime dependencies.
