# @strav/publish

> 标签: bun, facebook, framework, google-business-profile, instagram, line, multi-tenant, oauth, publishing, strav, typescript, wordpress

## 简介

Unified multi-channel publisher for the Strav framework — Google Business Profile, Meta (Facebook + Instagram), WordPress, and LINE OA broadcasts behind a single Publisher interface with per-tenant OAuth credentials and auto-refresh
