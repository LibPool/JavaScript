# @shalldie/export-xmind

> 标签: JavaScript

## 简介

`@mind-elixir/export-xmind` is a plugin of [mind-elixir-core](https://github.com/ssshooter/mind-elixir-core). You can use `@mind-elixir/export-xmind` to export a `.xmind` file.
