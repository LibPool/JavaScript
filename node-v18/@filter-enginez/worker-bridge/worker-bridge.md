# @filter-enginez/worker-bridge

> 标签: comlink, faceted-search, filter, filter-enginez, filtering, off-main-thread, performance, typescript, web-worker, worker

## 简介

Run the Filter EngineZ filtering engine in a Web Worker, off the main thread, via Comlink. Engages automatically above 50k items by default.
