# @filter-enginez/redux-bridge

> 标签: faceted-search, filter, filter-enginez, filtering, middleware, redux, redux-toolkit, state-management, typescript

## 简介

Mirror Filter EngineZ filter state into a Redux store: a read-only slice plus middleware, with the engine as the single source of truth. Works with Redux Toolkit.
