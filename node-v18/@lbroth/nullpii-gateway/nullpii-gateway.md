# @lbroth/nullpii-gateway

> 标签: anthropic, anthropic-proxy, claude, claude-code, gateway, gdpr, hipaa, llm-proxy, local-pii, pii, privacy, proxy, redact, sanitize, self-hosted

## 简介

Self-hosted HTTP gateway that sanitizes PII before forwarding to Anthropic Claude, restores in the response. baseURL drop-in.
