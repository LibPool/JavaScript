# @typesql/prisma

> 标签: no-codegen, orm, postgres, postgresql, prisma, prisma-generator, raw-sql, sql, type-level, type-safe, typescript

## 简介

Use a Prisma schema as a TypeSQL schema: convert the generated client's types, or generate an exact schema with the typesql-prisma generator.
