# @blazing-customs/ppx-mcp-stdio

> 标签: ai, claude, cursor, mcp, ppx, vscode, zed

## 简介

Stdio MCP server that proxies to a PPX provider's HTTP MCP endpoint. Makes PPX-native tools available to editors (Claude Desktop, Cursor, Zed, VS Code) that speak stdio MCP.
