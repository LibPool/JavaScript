# @sapbruno/cf-btp

> 标签: bruno, btp, cloudfoundry, credential-provider, oauth2, sap, sapbruno, xsuaa

## 简介

SAP Cloud Foundry / BTP credential provider for sapbruno. Extracts xsuaa OAuth2 client_credentials from bound apps via cf CLI.
