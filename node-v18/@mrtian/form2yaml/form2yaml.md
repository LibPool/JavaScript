# @mrtian/form2yaml

> 标签: convert, form, form2yaml, typescript, yaml

## 简介

Form表单与YAML数据互转，支持注释、字段映射、校验等高级特性。来源至 form2yaml 只是转为了ts, 增加了类型定义
