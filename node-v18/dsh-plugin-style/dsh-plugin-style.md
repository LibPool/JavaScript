# dsh-plugin-style

> 标签: deepseek-harness, dsh, dsh-plugin, skin, theme, web-ui

## 简介

Multi-style skin collection for the DeepSeek Harness (dsh) web GUI. Each skin registers a theme (Settings → Appearance / sidebar-foot picker) plus scoped decoration CSS keyed to its active state.
