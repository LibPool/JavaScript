# dsh-notes-context

> 标签: compaction, context, context-window, deepseek-harness, dsh, dsh-plugin, notebook, notes, rollover

## 简介

Notes-backed context compression for DeepSeek Harness: replace LLM-summarized compaction with a model-written persistent notebook plus recoverable raw history — the rollover boundary itself costs zero model calls.
