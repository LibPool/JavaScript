# @yappa-rs/yappa-sdk

> 标签: JavaScript

## 简介

A lightweight, high-performance TypeScript SDK for the **Yappa Realtime Messaging Engine**. Built with a focus on low latency and ease of use in both Node.js and Browser environments.
