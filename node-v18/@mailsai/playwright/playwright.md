# @mailsai/playwright

> 标签: e2e, email, email-testing, magic-link, mails.ai, otp, playwright, playwright-email, playwright-fixture, verification-code

## 简介

Playwright fixture for mails.ai: give each test its own email address, then wait for the sign-up code or link sent to it.
