# @chiefaia/tool-output-sanitizer

> 标签: JavaScript

## 简介

Deterministic prompt-injection defense. Strips role-impersonation markers, [INST] blocks, ignore-previous-instructions variants, zero-width Unicode, ANSI escapes, and tool-redefinition payloads from MCP/HTTP/file-read responses BEFORE they reach the agent
