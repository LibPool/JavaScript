# tokenline-plugin-elizaos

> 标签: credit, eliza, elizaos, plugin, solana, tokenline

## 简介

Tokenline plugin for ElizaOS: credit scores for Solana agents from on-chain creator fees, and the agent's own pay-later compute line.
