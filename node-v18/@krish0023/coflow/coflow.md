# @krish0023/coflow

> 标签: claude-code, context, git, mcp, model-context-protocol, team

## 简介

Local-first MCP server that gives every teammate's Claude Code a live, shared picture of what the rest of the team is working on. Git is the source of truth; the vector index is a disposable cache; sync is driven by deterministic hooks.
