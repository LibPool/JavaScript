# @imehappen/next-carousel

> 标签: carousel, infinite-carousel, nextjs, react, slider, swiper

## 简介

A fully customizable, infinite-loop-capable carousel/slider component for Next.js (and any React 18+ app). Supports autoplay speed, direction, items-per-view sizing, swipe/drag, arrows, dots, and pause-on-hover.
