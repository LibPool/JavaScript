# @jontsnz/http-streaming

> 标签: videojs, videojs-plugin

## 简介

Play back HLS and DASH with Video.js, even where it's not natively supported. Handles for large media sequence gaps.

- 源码仓库：git@github.com:jontsnz/http-streaming.git
