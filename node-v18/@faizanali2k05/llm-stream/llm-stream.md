# @faizanali2k05/llm-stream

> 标签: ai, llm, partial-json, sse, streaming, typescript, zero-dependency

## 简介

Streaming LLM output toolkit: SSE parsing plus tolerant partial-JSON parsing, emitting typed object snapshots as tokens arrive. Zero deps.
