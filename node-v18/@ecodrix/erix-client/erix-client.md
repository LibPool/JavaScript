# @ecodrix/erix-client

> 标签: cache, ecodrix, erix-store, in-memory, pubsub, queue, rate-limit, serverless-data

## 简介

Type-safe HTTP client for ERIX Store — serverless cache, queues, and real-time messaging. Zero dependencies, uses native fetch.
