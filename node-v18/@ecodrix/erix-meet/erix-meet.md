# @ecodrix/erix-meet

> 标签: booking, calendar, ecodrix, iframe, meet, nextjs, react, scheduling, sdk, typescript, widget

## 简介

ECODrIx Meet SDK — embed your ECODrIx booking page on any site (CDN + React/Next.js), no API keys. Renders the hosted booking UI in a modal or inline iframe.
