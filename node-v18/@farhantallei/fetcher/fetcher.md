# @farhantallei/fetcher

> 标签: fetch, interceptor, middleware, request

## 简介

A lightweight, universal HTTP client designed for modern web and Node.js applications. Supports interceptors, authentication, form-data requests, and is fully composable for building scalable and reusable network layers across multiple projects.
