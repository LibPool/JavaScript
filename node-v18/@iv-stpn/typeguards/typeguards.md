# @iv-stpn/typeguards

> 标签: guard, narrowing, runtime, type-guard, type-guards, type-narrowing, typeguard, typescript, validation

## 简介

Zero-dependency runtime type guards for TypeScript. Narrow unknown values at trust boundaries (parsed JSON, webhook payloads, API responses) — one guard per file, maximum tree-shaking.
