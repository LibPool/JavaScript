# @weave-os/router

> 标签: anthropic, claude, claude-code, llm-router, pi, pi-package, router, weave

## 简介

One-command installer that points Claude Code, Codex, opencode, or pi at the Weave Router. For pi it also ships the routing extension, loaded via pi.extensions.
