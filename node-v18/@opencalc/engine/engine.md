# @opencalc/engine

> 标签: csv, excel, formula, headless, ooxml, opencalc, pivot-table, recalculation, rust, spreadsheet, wasm, webassembly, xlsx

## 简介

The OpenCalc spreadsheet engine as WebAssembly — read, recalculate and write .xlsx with no DOM and no CSS. Deterministic, and safe with untrusted files.
