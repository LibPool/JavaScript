# @tuain/form-exchange

> 标签: Exchange, Form, Framework, Platform, Tuain

## 简介

Motor de intercambio de formularios abstractos de la plataforma Tuain: transforma la definición y los datos de un formulario entre el frontend y el backend según las acciones ejecutadas en cada lado. Software propietario.
