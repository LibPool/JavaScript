# @candlefire/my-mcp-server

> 标签: JavaScript

## 简介

一个符合 **Model Context Protocol (MCP)** 的服务端，提供： - 工具（Tools）：`create_note`、`verifyBankCard3`、`verifyMobileThree` - 资源（Resources）：示例文本笔记 - 提示词（Prompts）：`summarize_notes`
