# @allowancejs/sdk

> 标签: JavaScript

## 简介

AllowanceJS browser SDK: init, shared Hub, and style-isolated <allowancejs-coin> / <allowancejs-bar> / <allowancejs-guard> web components (Lit + Shadow DOM), plus headless Tab, Ledger, and Receipt data objects for custom UI.
