# @ghaerdi/rustify

> 标签: error-handler, functional-programming, match, monad, options, pattern-matching, results, rust-lang, type-safety, typescript

## 简介

Rust-style algebraic types for TypeScript: Option (Some/None) and Result (Ok/Err) with functional combinators and pattern matching for safe error handling and null management.
