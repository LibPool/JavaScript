# @myfinal/config

> 标签: JavaScript

## 简介

[Dian](https://github.com/FinalDevHQ/Dian) 框架的配置读取与热重载服务，支持 `settings.yaml`、`bot.yaml`、`templates.yaml`，使用 [Zod](https://zod.dev) 进行 schema 校验。
