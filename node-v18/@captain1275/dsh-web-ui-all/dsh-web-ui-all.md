# @captain1275/dsh-web-ui-all

> 标签: JavaScript

## 简介

DSH Web UI 全家桶聚合插件：一键安装全部功能插件（task-board / git-graph / pet / live-stats / web-ui-settings / compat shim）+ 皮肤全家桶（dsh-skins，皮肤资产内置）。compat 桥接层已并入本包（src/client），无需独立 compat npm 包。
