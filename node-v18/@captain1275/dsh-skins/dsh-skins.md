# @captain1275/dsh-skins

> 标签: JavaScript

## 简介

皮肤全家桶聚合插件：装它 = 皮肤中心（skin-center）+ 全部皮肤资产（ths / ths / xp / blue-fantasy / dragon-heir / minecraft / miku / trading 等，内置在包的 skins/ 目录，无需每皮肤独立 npm 包）。皮肤启用互斥由 dsh-skin use 管理（~/.dsh/cordis.patch.yml managed 区段），因此皮肤只进 skins/ 资产、不进 patchFrom。
