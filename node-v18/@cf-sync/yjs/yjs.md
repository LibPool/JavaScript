# @cf-sync/yjs

> 标签: cloudflare, collaborative-editing, crdt, durable-objects, local-first, sync, yjs

## 简介

Collaborative-text add-on for cf-sync: Yjs fields living in the same Workspace Durable Object, exposed as an engine extension (server) and field handles (client)
