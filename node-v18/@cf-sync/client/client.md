# @cf-sync/client

> 标签: indexeddb, local-first, offline-first, optimistic-updates, presence, react, sync, sync-engine, tanstack-db

## 简介

Browser client for cf-sync: SyncClient (optimistic mutations, offline outbox, IndexedDB mirror, presence) and a TanStack DB collection adapter, with React hooks
