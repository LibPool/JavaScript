# @leapwallet/cosmos-snap-provider

> 标签: JavaScript

## 简介

The **`cosmos-snap-provider`** is specifically designed for seamless integration of the Leap Cosmos Snap with the [CosmJS](https://github.com/cosmos/cosmjs) client.
