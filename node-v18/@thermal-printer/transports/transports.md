# @thermal-printer/transports

> 标签: JavaScript

## 简介

Pluggable print delivery transports for @thermal-printer/core: browser print dialog, RawBT (Android), Web Bluetooth. Same Transport interface so new transports (WebUSB, network relay) can be added without touching callers.
