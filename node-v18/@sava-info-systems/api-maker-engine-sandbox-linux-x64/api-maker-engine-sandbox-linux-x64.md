# @sava-info-systems/api-maker-engine-sandbox-linux-x64

> 标签: JavaScript

## 简介

API Maker v4 : what the sandboxes of a Mac or a Windows machine (x64) run, which are Linux containers : the launcher am_agent and the agent libraries, nothing of the server. Installed by @sava-info-systems/api-maker-engine and by API Maker Launchpad.
