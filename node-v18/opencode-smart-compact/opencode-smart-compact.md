# opencode-smart-compact

> 标签: context-compression, conversation-summarization, opencode, opencode-plugin, smart-compaction

## 简介

OpenCode V2 plugin: verification-oriented smart compaction (Extract → Synthesize → Verify) with a configurable, cheaper compaction model. Port of pi-smart-compact's core.
