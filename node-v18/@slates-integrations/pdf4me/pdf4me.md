# @slates-integrations/pdf4me

> 标签: JavaScript

## 简介

Convert, merge, split, compress, and manipulate PDF and office documents. Perform OCR on scanned documents to extract text. Generate and read 150+ barcode and QR code types. Extract structured data from PDFs using templates. Classify documents by content.
