# @slates-integrations/paperform

> 标签: JavaScript

## 简介

Manage Paperform forms, submissions, products, coupons, and spaces. Read individual field configurations, product details, and incomplete submissions. Send, copy, move, and cancel Papersign eSignature documents, and organize them into folders. API access
