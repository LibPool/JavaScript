# @slates-integrations/dreamstudio

> 标签: JavaScript

## 简介

Generate images from text prompts using Stable Image Ultra, Core, and Stable Diffusion 3.5. Edit, relight, upscale, and guide images with sketch, structure, or style references. Download generated image files and GLB 3D models, recover asynchronous result
