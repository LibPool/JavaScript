# @slates-integrations/google-cloud-functions

> 标签: JavaScript

## 简介

Manage serverless cloud functions on Google Cloud. Create, update, deploy, list, and delete functions triggered by HTTP requests or cloud events. Configure runtimes (Node.js, Python, Go, Java, .NET, Ruby), event triggers (Cloud Storage, Pub/Sub, Firestore
