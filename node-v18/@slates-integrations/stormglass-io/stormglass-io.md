# @slates-integrations/stormglass-io

> 标签: JavaScript

## 简介

Retrieve global weather, marine, tide, astronomy, solar, and elevation data for any coordinate. Fetch weather forecasts and historical data including temperature, wind, precipitation, humidity, and cloud cover. Access marine parameters such as wave height
