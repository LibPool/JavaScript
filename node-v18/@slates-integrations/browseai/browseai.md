# @slates-integrations/browseai

> 标签: JavaScript

## 简介

Run trained Browse AI robots, retrieve captured text and tables, and download task data as JSON. Discover robots and bulk runs, inspect task history and retries, manage scheduled monitors, update session cookies, and configure webhook subscriptions.
