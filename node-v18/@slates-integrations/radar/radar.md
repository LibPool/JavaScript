# @slates-integrations/radar

> 标签: JavaScript

## 简介

Track user locations and manage geofences, trips, and location events. Create circle, polygon, or isochrone geofences; list and inspect users; create, update, list, inspect, and delete trips; perform forward, reverse, and IP geocoding; search nearby place
