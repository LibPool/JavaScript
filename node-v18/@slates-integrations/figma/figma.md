# @slates-integrations/figma

> 标签: JavaScript

## 简介

Access and inspect Figma design files, including full node trees, layers, properties, and metadata. Export file nodes as PNG, SVG, JPG, or PDF images. Read, create, and delete comments and reactions on files. Manage file version history. List team project
