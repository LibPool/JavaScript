# @slates-integrations/loomio

> 标签: JavaScript

## 简介

Create and manage group discussions, proposals, and polls for collaborative decision-making. Supports multiple voting methods including proposals, score voting, ranked choice, dot voting, and meeting polls. Create discussion threads with Markdown or HTML
