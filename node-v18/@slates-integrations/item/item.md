# @slates-integrations/item

> 标签: JavaScript

## 简介

Manage people, companies, and custom objects in item. List and retrieve flat object records across contacts, companies, and custom object types with pagination, search, sorting, and field-based filters. Create, update, soft-delete, and batch upsert record
