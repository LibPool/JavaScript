# @slates-integrations/blackbaud

> 标签: JavaScript

## 简介

Manage Raiser's Edge NXT fundraising data through Blackbaud's SKY API. Search, read, create, and update constituents and contact details; retrieve giving summaries; list, read, and create gifts; list, create, update, and read actions; inspect fundraising
