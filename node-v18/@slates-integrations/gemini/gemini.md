# @slates-integrations/gemini

> 标签: JavaScript

## 简介

Use Google's Gemini Developer API to generate text, process multimodal prompts, create images and Veo videos, generate embeddings, count tokens, upload and manage files, inspect model metadata, and manage explicit context caches.
