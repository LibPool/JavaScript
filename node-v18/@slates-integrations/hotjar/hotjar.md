# @slates-integrations/hotjar

> 标签: JavaScript

## 简介

Export survey response data and manage user data for privacy compliance. List surveys for a site, retrieve survey responses, perform user lookups by email or user ID, and submit deletion requests for GDPR compliance. Receive real-time webhook notification
