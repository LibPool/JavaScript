# @slates-integrations/bolt-iot

> 标签: JavaScript

## 简介

Control and monitor IoT devices connected via Bolt WiFi modules. Set and read digital GPIO pin states to control LEDs, relays, and motors. Read analog sensor values (e.g., temperature, light) and write PWM output for variable device control. Manage UART s
