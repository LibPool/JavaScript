# @slates-integrations/documint

> 标签: JavaScript

## 简介

Generate downloadable PDF documents by merging data into templates. List, retrieve, rename, and permanently delete templates. Create invoices, contracts, proposals, certificates, and reports using custom data. Original Documint PDF links expire after 24 h
