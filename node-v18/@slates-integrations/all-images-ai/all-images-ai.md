# @slates-integrations/all-images-ai

> 标签: JavaScript

## 简介

Generate AI images from text prompts using Midjourney AI, producing four image proposals per generation. Use simple mode with image parameters or advanced mode with a raw Midjourney prompt. Search stock images, purchase downloadable full-size and upscale
