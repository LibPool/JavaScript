# tailwindv4-date-input

> 标签: calendar, date, date-input, datepicker, dayjs, headlessui, react, react-hook-form, tailwind, tailwind-v4, tailwindcss

## 简介

A themeable, accessible date input (masked text field + popover calendar) for React, styled with Tailwind CSS v4. Ships default light and dark themes; fully restyleable via CSS theme tokens.
