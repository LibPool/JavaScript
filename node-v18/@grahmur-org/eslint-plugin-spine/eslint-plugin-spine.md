# @grahmur-org/eslint-plugin-spine

> 标签: agentic-coding, ai-agents, eslint, eslint-plugin, eslintplugin, multi-tenant, security, spine, spine-os

## 简介

ESLint rules that stop AI coding agents from shipping the shortcuts Spine OS guards against: hardcoded or client-exposed secrets, SQL built from strings, unscoped tenant queries, secrets in logs and buffered uploads.
