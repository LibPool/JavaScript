# @dithernaut/quanta-strike

> 标签: bitmap-font, css, font, monospace, pixel-art, pixel-font, typeface, webfont, woff2

## 简介

A pixel typeface with one font per size. Every strike is drawn by hand and stays sharp at the size it was drawn for.
