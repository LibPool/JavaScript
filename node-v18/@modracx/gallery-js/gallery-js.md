# @modracx/gallery-js

> 标签: accessibility, browser, focus-trap, gallery, grid, image-gallery, jquery-plugin, lightbox, masonry, modal, photo-gallery, photoswipe-alternative, swipe, zero-dependency, zoom

## 简介

Lightweight image gallery for web pages — responsive thumbnail grid or masonry, plus an accessible lightbox with zoom, swipe, keyboard and focus trapping. Zero dependencies.
