# @rshaker/context-detect

> 标签: browser, chrome, context, detection, extension, firefox, javascript, library, msedge, mv3, node, npm, playwright, typescript, webpack

## 简介

Detects which browser and JavaScript execution context (e.g. background worker, popup, extension page, isolated world, main world) a script is running in
