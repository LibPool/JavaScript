# @ybelik/scene-tracer

> 标签: JavaScript

## 简介

Image → traced SVG with a deterministic auto-tune ladder (the ybelik trace stage). Wraps wasm_vtracer; runs in browser and Node; writes settings-are-data sidecars from the CLI.
