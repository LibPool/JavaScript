# @ybelik/scene-compiler

> 标签: animation, bucketing, compiler, ink-wash, luminance, reveal, svg

## 简介

Bucket compiler for the ybelik story engine — sorts SVG paths by luminance and injects rp bN classes so reveal-engine can paint them light to dark. JS port, byte-parity with the Python original at jitter=0. Includes the input linter (auditMetrics).
