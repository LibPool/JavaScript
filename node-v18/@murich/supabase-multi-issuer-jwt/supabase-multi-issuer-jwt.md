# @murich/supabase-multi-issuer-jwt

> 标签: auth, federated-auth, jwt, microservices, multi-tenant, postgrest, rls, supabase

## 简介

Federated multi-issuer JWT auth for Supabase — multiple services write to a shared Supabase with scoped permissions, no service_role sharing
