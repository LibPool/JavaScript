# @tunnelmindai/receipt-verify

> 标签: agent-trust, attestation, ed25519, jcs, receipt, tunnelmind, verifier

## 简介

Reference verifier for the TunnelMind Receipt Format v1.0. Offline Ed25519 + JCS verification, key-bundle resolution, and revocation checking against the well-known feed. Zero runtime dependencies; runs on Node ≥18, Cloudflare Workers, Deno, Bun.
