# @johnsilver/nuxt-prometheus

> 标签: JavaScript

## 简介

Fork of @artmizu/nuxt-prometheus with enhanced cluster support. Allows you to better understand what's going on with your application and how to optimize performance and other things in production, including multi-worker cluster metrics.
