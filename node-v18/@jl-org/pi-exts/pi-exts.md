# @jl-org/pi-exts

> 标签: ai-agent, cli, pi-coding-agent, pi-extension, pi-package, statusline, tui

## 简介

Extension bundle for the Pi coding agent: ask_user dialog tool, /yank picker, statusline with provider quotas, session auto-rename, mid-sentence slash completion, and more
