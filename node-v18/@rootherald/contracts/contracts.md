# @rootherald/contracts

> 标签: JavaScript

## 简介

The **shared contract / type layer** for the Root Herald JavaScript SDKs. It is the single source of truth for the wire shapes and error classes that both the **client** package (`@rootherald/browser`) and the **server** package (`@rootherald/node`) build
