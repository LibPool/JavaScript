# @pance/tokens

> 标签: css-variables, design-system, design-tokens, dtcg, pance, tailwind

## 简介

Pance design tokens: 855 W3C DTCG tokens (primitives → semantic → components) as CSS variables, a Tailwind v4 theme, a typed JS object and JSON. Light and dark.
