# @starmesh/container

> 标签: codec, container, sdk, signature, starmesh

## 简介

StarMesh .sm v1 container: framing, codec registry (v1/v2/v3), SHA-256 checksum, Ed25519 signatures, resource limits, and atomic file IO.
