# @pracht/query

> 标签: data-fetching, hydration, pracht, preact, react-query, ssr, tanstack-query

## 简介

TanStack Query for Pracht: a per-request QueryClient on the server, server-fetched queries hydrated into the browser cache on first load and on every client navigation, and query invalidation after capability mutations.
