# afx-cli

> 标签: agents, ai, claude-code, cli, codex, copilot, cursor, git, governance, guardrails

## 简介

One front door to set up and govern AI coding agents (Claude Code, Cursor, Codex, Copilot, Replit Agent, Ollama agents) across a team's machines.
