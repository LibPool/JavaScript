# @searchstack/rich-answer

> 标签: ai-answers, citations, markdown, rag, searchstack, streaming, syntax-highlighting

## 简介

Renders AI answers as rich, safe HTML: highlighted code with copy and language tabs, images from the cited page, tables, step cards, callouts, side-by-side comparisons and citation chips. Streaming-safe, framework-free.
