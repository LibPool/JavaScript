# @servicocrm/servicocli-mcp

> 标签: claude, cursor, llm-tools, mcp, model-context-protocol, servico, servicocrm

## 简介

Local MCP server exposing the Servico CRM tenant API (api/v1) as typed tool calls for LLM agents like Claude Desktop and Cursor.
