# @ai11y/react

> 标签: JavaScript

## 简介

Thin React wrapper for ai11y. Uses the same **describe → plan → act** flow: wrap your app in `Ai11yProvider`, mark elements with `Marker`, and use `useAi11yContext()` for `describe` and `act`; call `plan()` from `@ai11y/core`.
