# @mobile-reality/mdma-renderer-react-native

> 标签: ai, android, forms, interactive-document, ios, llm, markdown, mdma, react-native, ui

## 简介

React Native renderer for [MDMA](https://github.com/MobileReality/mdma) documents — the native sibling of [`@mobile-reality/mdma-renderer-react`](../renderer-react). Renders all 9 MDMA component types plus inline Markdown as native iOS/Android UI.
