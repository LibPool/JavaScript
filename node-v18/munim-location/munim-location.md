# munim-location

> 标签: altimeter, android, background-location, compass, core-location, expo, fused-location-provider, geocoding, geofence, geofencing, geolocation, gnss, gps, heading, headless, ibeacon, ios, location, munim-technologies, nitro-modules, nmea, react-native, reverse-geocoding, significant-location-change, typescript, visits

## 简介

A comprehensive React Native location library: permissions, current and continuous positions, background and headless tracking, geofencing, iBeacons, heading, altimeter, GNSS, and geocoding for iOS and Android with Expo support
