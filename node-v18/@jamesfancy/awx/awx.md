# @jamesfancy/awx

> 标签: JavaScript

## 简介

使用 JavaScript Proxy 特性对微信小程序的 `wx` 进行封装，使之以返回 `Promise` 对象的形式进行调用。随后可以使用 `await` 关键字简化程序结构。
