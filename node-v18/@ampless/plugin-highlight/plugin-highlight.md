# @ampless/plugin-highlight

> 标签: ampless, ampless-plugin, cms, highlight, highlight.js, plugin, syntax-highlighting

## 简介

Syntax highlighting plugin for ampless — highlights `code.language-*` blocks on the public site via a lazily CDN-loaded highlight.js
