# @lanxing/dsh-galgame

> 标签: deepseek-harness, dsh, dsh-plugin, galgame, plugin, visual-novel, web-ui

## 简介

GalGame mode for the dsh web GUI: a third conversation view tab (after 轨迹) that renders the real agent session as a visual-novel stage — whale-girl (DeepSeek) portrait with diff switching + draggable thinking bubble, Markdown dialogue box with typewriter
