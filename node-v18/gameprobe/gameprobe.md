# gameprobe

> 标签: ai-agent, claude, game, gamedev, mcp, mcp-server, phaser, playtest, playwright, qa, testing, threejs, unity, webgl

## 简介

Let your coding agent actually play the game it just wrote. MCP server: virtual time, state watching, per-frame controllers for web games, a Unity plugin, and a screen-based fallback for any Windows game.
