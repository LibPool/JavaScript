# @rantingjs/framework

> 标签: bun, framework, ranting, typescript

## 简介

The ranting web framework: HTTP kernel, config, validation, sessions, cache, hashing, filesystem, events, the database component on Kysely + Bun.SQL, queue, mail, notifications, broadcasting, auth, schedule, translation, the testing kit, the CLI
