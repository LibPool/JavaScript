# @molecule/api-resource-journal-entry

> 标签: diary, encryption, journal, molecule, mood, resource

## 简介

Owner-scoped journal entry resource with optional at-rest encryption, mood linkage, daily streaks, and JSON/CSV/TXT export. Extracted from mental-health-journal flagship.
