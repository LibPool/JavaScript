# @molecule/app-feature-thread-tree-react

> 标签: comment-tree, molecule, react, thread-tree

## 简介

Nested comment tree with collapse / collapse-deep / parent-line indicator. Recursive renderer with depth-based indentation, per-node collapse, and reply / vote slots.
