# @molecule/app-e2e-playwright

> 标签: browser, e2e, molecule, playwright

## 简介

E2E bond that opens real Playwright browsers — the same specs that drive the live preview inside a molecule sandbox run here on your machine and in CI, with screenshots, traces and network interception.
