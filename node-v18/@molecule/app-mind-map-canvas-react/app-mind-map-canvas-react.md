# @molecule/app-mind-map-canvas-react

> 标签: canvas, horizontal-tree, mind-map, molecule, radial-layout, react, tree

## 简介

React mind-map canvas — tree-structured nodes with parent/child links, automatic radial/horizontal/vertical tree layout, fold/unfold subtrees, inline edit-on-double-click; thin domain wrapper over @molecule/app-feature-canvas-react.
