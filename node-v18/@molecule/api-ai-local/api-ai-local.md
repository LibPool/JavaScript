# @molecule/api-ai-local

> 标签: ai, local, molecule

## 简介

AIProvider bond for any OpenAI-compatible local inference server (Ollama, LM Studio, llama.cpp, vLLM) — configurable base URL, keyless by default, streamed via raw fetch.
