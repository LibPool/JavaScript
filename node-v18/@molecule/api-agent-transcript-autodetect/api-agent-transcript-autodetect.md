# @molecule/api-agent-transcript-autodetect

> 标签: agent, aider, claude-code, cline, codex, copilot, cursor, detect, gemini-cli, molecule, opencode, pi, transcript

## 简介

Picks the reader that recognizes a transcript and delegates to it; bundles readers for Claude Code, Codex CLI, the Molecule IDE, Gemini CLI, Cline / Roo Code, OpenCode, Pi, GitHub Copilot Chat, Cursor and Aider, plus a generic Markdown chat reader
