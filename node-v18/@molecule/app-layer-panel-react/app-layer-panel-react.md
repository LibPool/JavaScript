# @molecule/app-layer-panel-react

> 标签: layer-panel, layers, molecule, react

## 简介

Photoshop-style reorderable layer stack with visibility/lock toggles, opacity/blend-mode metadata, and inline rename — drag-to-reorder via pointer events
