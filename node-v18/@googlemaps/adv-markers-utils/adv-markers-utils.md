# @googlemaps/adv-markers-utils

> 标签: JavaScript

## 简介

The `@googlemaps/adv-markers-utils` package is a library to simplify common patterns for using [Advanced Markers][gmp-adv-markers-overview] in the Maps JavaScript API.
