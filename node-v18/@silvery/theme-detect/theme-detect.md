# @silvery/theme-detect

> 标签: ansi, color, color-scheme, oklch, osc, palette, terminal, theme, tui

## 简介

Framework-agnostic terminal color scheme detection — OSC probing + catalog fingerprinting. For any TUI/CLI that wants to adopt the user's terminal theme.
