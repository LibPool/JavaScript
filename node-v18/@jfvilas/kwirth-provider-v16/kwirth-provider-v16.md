# @jfvilas/kwirth-provider-v16

> 标签: JavaScript

## 简介

V16 beacon provider for Kwirth — polls the DGT DATEX2 traffic feed and dispatches only what changed (new, updated and cleared situations), with V16 emergency beacons flagged
