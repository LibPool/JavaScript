# @elacity-js/ddrm-reader-backend

> 标签: JavaScript

## 简介

Express-like backend: wallet handshake, ECDH WebSocket channel, CEK recovery, ddrm-decrypt.wasm, render-layer. Plaintext/CEK never leave here.
