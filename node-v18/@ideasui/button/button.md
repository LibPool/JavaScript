# @ideasui/button

> 标签: accessible-components, button, button-component, button-group, design-system, ideasui, react, tailwindcss, ui-components

## 简介

A high-performance, accessible Button and ButtonGroup component library for React, built with Tailwind CSS v4 and React Aria.
