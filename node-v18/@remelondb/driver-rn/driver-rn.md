> 标签: database, offline-first, remelondb, sqlite, sync, watermelondb

## 简介

remelonDB SqliteDriver for React Native: the default expo-sqlite adapter. For bundled SQLite without an Expo dependency, see @remelondb/driver-rn-cpp.
