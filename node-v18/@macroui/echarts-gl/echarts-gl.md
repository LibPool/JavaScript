# @macroui/echarts-gl

> 标签: JavaScript

## 简介

Extension pack of Apache ECharts™ providing 3D plots, globe visualization and WebGL acceleration, themed with MacroUI (DaisyUI).

## 官网

- 官网：https://echarts-gl.macroui.com
- 源码仓库：git+https://gitee.com/macroui/macroui-echarts-gl.git
- npm 页面：https://www.npmjs.com/package/@macroui/echarts-gl
