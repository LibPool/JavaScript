# @desenvolvimento-digital/add-theme

> 标签: cli, design-system, mui, theme

## 简介

CLI interativo que gera uma pasta theme/ com o tema MUI do Design System do time (cor, tom neutro, tipografia, espaçamento/elevação, componentes) — roda dentro de qualquer projeto que já use MUI.
