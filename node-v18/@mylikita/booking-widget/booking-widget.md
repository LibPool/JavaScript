# @mylikita/booking-widget

> 标签: appointment, booking, healthcare, hospital, mylikita, relay, widget

## 简介

Drop-in appointment booking widget for MyLikita hospital websites. Submits bookings through the MyLikita relay (POST /v1/bookings) and polls status (GET /v1/bookings/:ref). Themeable via CSS variables.
