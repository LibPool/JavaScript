# @staticcanvas/hawk

> 标签: command-palette, esm, pagefind, search, static-site, staticcanvas, themeable, ui-component, vanilla-js

## 简介

Themeable, pluggable command-palette search for static sites. Pagefind-powered indexing, swappable reveal animations (a TypeFlow typewriter driver ships built-in), swappable visual themes.
