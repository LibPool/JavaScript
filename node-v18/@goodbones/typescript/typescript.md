# @goodbones/typescript

> 标签: architecture, hexagonal, import-boundaries, lint, monorepo

## 简介

The TypeScript language pack for @goodbones/core: facts read through oxc-parser, specifiers resolved through unrs-resolver, behind the core's Language port.
