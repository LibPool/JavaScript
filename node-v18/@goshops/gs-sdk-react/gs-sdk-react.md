# @goshops/gs-sdk-react

> 标签: JavaScript

## 简介

`@goshops/gs-sdk-react` is a React.js hook wrapper for the `@goshops/gs-sdk` JavaScript SDK. It provides an easy way to integrate the GS SDK into your React applications.
