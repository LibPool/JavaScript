# @rollfuse/contracts

> 标签: JavaScript

## 简介

TypeScript types generated from openapi/openapi.yaml (a checked-in mirror of the rollfuse platform's OpenAPI document), for consumption by @rollfuse/sdk-js and other TypeScript clients.
