# @kooperativa_team/sdk

> 标签: api-client, b2b, data-enrichment, enrichment, kooperativa, sdk

## 简介

Official Node.js / TypeScript SDK for the Kooperativa API. Enrich and search professional profiles and companies, track hiring signals and job changes, and manage webhook monitors.

- 官网：https://kooperativa.io
