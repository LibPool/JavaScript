# @alltechzone/uiworld-mcp

> 标签: alltechzone, antigravity, blocks, claude, components, cursor, mcp, model-context-protocol, react, tailwind, ui, uiworld

## 简介

MCP server for UI World by Alltechzone: 436 free, copy-ready React + Tailwind blocks and 5 full page templates. Always current: fetches the live library from uiworld.pro, with an offline copy bundled in.
