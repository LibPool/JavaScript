# @flow2dream/dsh-msg-rewind

> 标签: JavaScript

## 简介

Conversation rewind commands for DeepSeek Harness web: /undo rolls the chat back one turn, /rewind <seq> cuts the conversation back to a chosen message (both the model context and the transcript, durably persisted). Host half truncates the live session lo
