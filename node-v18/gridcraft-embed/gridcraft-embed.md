> 标签: browser-spreadsheet, excel, excel-like, formulas, gridcraft, javascript, javascript-spreadsheet, react, react-spreadsheet, spreadsheet, spreadsheet-component, typescript, web-spreadsheet, webassembly, xlsx

## 简介

Excel-like spreadsheet for React and JavaScript in the browser, with formulas, XLSX import/export, dark mode and an embeddable Gridcraft UI.
