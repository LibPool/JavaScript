# @bloklabs/angular

> 标签: JavaScript

## 简介

Angular block editor — official Angular bindings for Blok, the headless Notion-like rich text editor. Standalone components that render blocks and save to JSON (APF partial-Ivy bundle).

- 源码仓库：git+https://github.com/JackUait/blok.git
