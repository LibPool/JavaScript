# @flaggr/plugin

> 标签: agent-skills, claude-code, claude-plugin, codex, codex-plugin, feature-flags, flaggr, mcp, openfeature, rollouts

## 简介

The Flaggr plugin for Claude Code and Codex: Flaggr's hosted MCP server (OAuth sign-in) and agent skills for flags, rollouts and incidents. Run npx @flaggr/plugin to install it.
