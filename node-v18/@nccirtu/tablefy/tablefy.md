# @nccirtu/tablefy

> 标签: data-grid, data-table, filament, forms, inertia, laravel, react, react-table, schema-driven, shadcn-ui, table, tailwind, tanstack-table, typescript, ui-components, wayfinder

## 简介

A schema-driven toolkit for React tables and forms, built with TanStack Table and shadcn/ui. Designed for Laravel + Inertia.js v2 + Wayfinder.
