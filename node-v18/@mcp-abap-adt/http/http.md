# @mcp-abap-adt/http

> 标签: abap, adt, mcp, mcp-server, model-context-protocol, sap, streamable-http

## 简介

The Streamable HTTP transport of the MCP ABAP ADT server: an Express app serving the ADT tools of @mcp-abap-adt/lib over MCP Streamable HTTP, with DNS rebinding protection and TLS.
