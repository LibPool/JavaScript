# @yiird/cesium-widgets

> 标签: 3D, geospatial, globe, map, webgl, widgets

## 简介

A widgets library for use with CesiumJS. CesiumJS is a JavaScript library for creating 3D globes and 2D maps in a web browser without a plugin.

## 官网

- 官网：https://cesium.com/cesiumjs/
- 源码仓库：git+https://github.com/CesiumGS/cesium.git
- npm 页面：https://www.npmjs.com/package/@yiird/cesium-widgets
