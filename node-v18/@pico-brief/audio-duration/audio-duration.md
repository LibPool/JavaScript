# @pico-brief/audio-duration

> 标签: aac, audio, duration, flac, m4a, mp3, ogg, wav

## 简介

Get the duration of an audio file in seconds from an ArrayBuffer. Supports MP3, WAV, OGG/Vorbis, FLAC, and AAC/M4A.
