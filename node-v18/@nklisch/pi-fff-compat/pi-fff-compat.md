# @nklisch/pi-fff-compat

> 标签: fff, find, grep, pi-extension, pi-package, ripgrep, search

## 简介

Fast FFF-backed file search through Pi-native find/grep semantics — glob-only file lookup and exact regex/literal grep with no fuzzy fallback.
