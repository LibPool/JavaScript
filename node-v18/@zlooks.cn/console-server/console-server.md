# @zlooks.cn/console-server

> 标签: JavaScript

## 简介

独立运行的 Zlooks 观测与发布服务。采用已确认的深蓝开放画布、桌面全屏自动缩放、**服务 / 订阅 / 发布**三个 Tab，所有详情统一由居中弹窗承载；长内容在弹窗内滚动，标题与关闭按钮保持可见，日志使用更宽布局。所有运行数据来自真实 Registry、Gateway、CLI 或实际任务文件，没有 Mock 数据、模拟阶段或编造的百分比。
