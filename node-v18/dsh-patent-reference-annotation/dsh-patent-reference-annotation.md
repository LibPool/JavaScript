# dsh-patent-reference-annotation

> 标签: annotation, cordis, deepseek-harness, dsh, dsh-plugin, patent, pdf, pdf-lib, 专利, 对比文件, 技术特征, 无效宣告, 说明书

## 简介

DSH 插件：读对比文件（说明书部分，中文专利或外文专利中文译文），依据涉案专利、无效请求书、意见陈述书，在每个公开了涉案专利技术特征的段落左侧画红色大括号 + 红字标签（独立权利要求按拆分特征标「权1-特征1-1」，照抄意见陈述书的特征编号；从属权利要求标「权2-附加特征」；同段多特征合并为「权1-特征1-1,1-5,1-6,1-7；权2-4-附加特征」）；老公告文本无 [00xx] 段号时用「页+段序」（p10-2）或原文片段定位，与请求书「第10页第二段」同口径；「对应关系说明」（标题 + 四张表）
