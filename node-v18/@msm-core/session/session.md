# @msm-core/session

> 标签: agent, ai, append-only, audit, event-log, msm, replay, session

## 简介

The session event log — an append-only, gap-checked record of what an agent actually did (user message, steps, model requests/responses, every tool call and its result, guards, replies), plus the pure derivation that turns that log back into conversation
