# @runtyped/type

> 标签: reflection, runtime, runtyped, types, typescript, validation

## 简介

@runtyped/type, the fastest universal TypeScript serializer and validator with JIT engine for frontend, backend, http-transport, RPC, and database, with built-in validations, for Browser/NodeJS.
