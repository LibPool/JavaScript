# @lq_lqq/elpis

> 标签: JavaScript

## 简介

> Elpis 是一个企业级全栈应用框架，通过声明式的 model 配置驱动前端页面生成，同时提供服务端启动与自定义扩展能力。本文档系统梳理 Elpis 的核心配置、服务端架构、前端构建及各类扩展点。
