# @asylia/btc-core

> 标签: asylia, bip370, bip380, bip48, bitcoin, bitcoin-descriptor, coin-selection, descriptor, hardware-wallet, multisig, p2wsh, psbt, psbt-v2, self-custody, sortedmulti, typescript, wsh

## 简介

Auditable Bitcoin TypeScript core for native-SegWit P2WSH multisig, BIP-48 derivation, BIP-380 descriptors, PSBT v2, signature verification, and coin selection.
