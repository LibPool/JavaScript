# @guygrigsby/pi-agent-select

> 标签: extension, pi, pi-package, routing, subagents

## 简介

Pick subagent models from pi's live registry with agent-select: cost or quality ranking, Jev task classification, scored by recorded test, CI and Jev verdicts ahead of declared scores.
