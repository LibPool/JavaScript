# @harrify/whatsapp

> 标签: @harrify/whatsapp, messaging, meta, typescript, webhook, whatsapp, whatsapp-cloud-api

## 简介

Lightweight TypeScript SDK for the WhatsApp Cloud API. Discord.js-style events, rich message objects, zero dependencies.
