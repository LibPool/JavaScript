# @astroway/widget

> 标签: astro, astrology, birth-chart, embed, ephemeris, horoscope, natal-chart, swiss-ephemeris, widget

## 简介

Embeddable natal chart calculator. Swiss Ephemeris runs in the browser, no API key, no birth data sent to a server.
