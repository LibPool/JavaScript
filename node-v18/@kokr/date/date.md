# @kokr/date

> 标签: anniversary, business day, holiday, typescript, 공휴일, 기념일

## 简介

Provides utilities for Korean dates. 날짜 관련 유틸리티를 제공합니다. 공휴일, 절기, 그리고 잡절 정보를 확인하고, 영업일 기준 날짜 계산을 지원합니다.
