# @fatherjake/agent-telemetry

> 标签: claude, claude-code, mcp, opentelemetry, otlp, sqlite, telemetry

## 简介

Capture Claude Code's OpenTelemetry output on your own machine, normalize it into SQLite, and query it from inside Claude Code over MCP.
