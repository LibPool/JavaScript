# @dingpenghui/dsh-supply-chain-switch

> 标签: cordis, cordis-plugin, deepseek, dsh, harness, minimumReleaseAge, pnpm, supply-chain

## 简介

DSH plugin: toggle the supply-chain (minimumReleaseAge) policy on/off — /supply-chain on|off|status lets you install just-published npm packages or restore DSH's default 24h cooldown
