> 标签: anime, avatar, desktop-pet, embed, iframe, live2d-alternative, postmessage, project-xiaochun, react, virtual-companion, vrm, web-component, xiaochun

## 简介

Embed Project XiaoChun (3D anime companion) into any web page via a lazy, origin-checked iframe. Zero-dependency SDK + <xiaochun-avatar> web component.
