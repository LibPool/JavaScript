# @expunct/mcp

> 标签: ai, claude, gdpr, hipaa, llm, mcp, model-context-protocol, pdf, pii, privacy, redaction

## 简介

MCP server for Expunct — PII detection and redaction tools for Claude Code, Claude Desktop, and any MCP-compatible AI client. Supports text, PDF, DOCX, images, video, and audio.
