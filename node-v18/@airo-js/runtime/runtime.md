# @airo-js/runtime

> 标签: airo, cartridge, framework, hydration, mount, runtime

## 简介

Airo runtime — cartridge mount orchestration. Single-call shell setup, data fetch, pipeline, and mount via createCartridgeApp; hooks for studio-side theme + error UI.
