# @blackbelt-technology/pi-dashboard-mcp-server-plugin

> 标签: JavaScript

## 简介

Dashboard plugin exposing a stateless MCP endpoint at POST /mcp implementing protocol revision 2026-07-28: no initialize handshake, no session ids, server/discover, and subscriptions/listen streaming over a curated allowlist of ServerPluginContext verbs.
