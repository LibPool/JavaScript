# @blackbelt-technology/pi-dashboard-context-mode-settings-plugin

> 标签: JavaScript

## 简介

Dashboard settings surface for the context-mode pi extension — persists logical tuning keys to ~/.pi/context-mode/settings.json and projects them to context-mode's environment for dashboard-spawned and terminal-launched sessions.
