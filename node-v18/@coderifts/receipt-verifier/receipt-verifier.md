# @coderifts/receipt-verifier

> 标签: agent-authorization, api-contract-preflight, mcp, offline-verifiable-authorization

## 简介

Signed, offline-verifiable authorization for API-contract changes. Only a granted change can proceed. This package verifies a receipt offline, with no key, no network and no call back.
