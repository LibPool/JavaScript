# @illusionforge/node-red-contrib-directus

> 标签: node-red

## 简介

A node collection for Node-RED to interact with Directus, a headless CMS. This package provides nodes to perform CRUD operations on Directus collections and items, upload and import files and syncing the schema of your instances.
