# @zukhruf/fencing

> 标签: distributed, fencing, fencing-token, lease, lock, stale

## 简介

Fencing tokens: a number that grows with each grant, so a protected resource refuses the writes of a stale holder. Token sources that count in memory, in files, or by epoch, and the fenced lease that carries a token.
