# @zukhruf/async

> 标签: abort, abortable, abortsignal, async, latch, poll, polling, promise

## 简介

Helpers for code that waits for promises: cancel a wait when an AbortSignal aborts, hold callers on a one-shot latch that never rejects, and poll an attempt until it gives a value.
