# @zukhruf/sqlite-federation

> 标签: attach, federated-query, federation, multi-database, node-sqlite, read-only, sqlite

## 简介

One read-only handle over many SQLite databases. Each statement attaches the databases that it names and detaches them when it ends. Thus a host can keep more databases than the attach limit of SQLite, and one statement can read up to 10 of them in additi
