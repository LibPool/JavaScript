# hash-sentinel

> 标签: circl, cli, dfir, github-action, hash, hash-lookup, hashlookup, incident-response, ioc, malware, malwarebazaar, misp, nsrl, sarif, security, sha256, threat-intelligence, virustotal

## 简介

Hash lookup CLI: hash files or take MD5/SHA1/SHA256/SHA512 values and check them offline against self-hosted feeds (hash lists, CSV, MISP events and MISP feed directories, cached URL feeds) and optionally CIRCL hashlookup (no key), MalwareBazaar or VirusT
