# @mollie/crowdin-cli

> 标签: JavaScript

## 简介

A helper tool to sync translation messages with [Crowdin](https://crowdin.com/), using [`@formatjs/cli`](https://formatjs.io/docs/tooling/cli/) for message extraction.
