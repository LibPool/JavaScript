# dsh-workspace-api-key

> 标签: api-key, billing, credentials, deepseek-harness, dsh, dsh-plugin, plugin, workspace

## 简介

A DeepSeek Harness plugin that binds a separate DeepSeek API key to each workspace, or to a single session, so the spend of one key stays with the sessions you choose.
