# @tuler/kext2

> 标签: cartesi, ext2, filesystem, genext2fs, image, reproducible

## 简介

Reproducible ext2 filesystem image builder (xgenext2fs command line), designed from the Linux kernel's ext2 driver, as a native Node.js module
