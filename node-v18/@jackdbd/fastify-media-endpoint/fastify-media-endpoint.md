# @jackdbd/fastify-media-endpoint

> 标签: IndieWeb, Micropub, POSSE, fastify, media, plugin

## 简介

Fastify plugin that adds a [Micropub Media endpoint](https://www.w3.org/TR/micropub/#media-endpoint) to a Fastify server.
