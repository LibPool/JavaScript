# @clan-europe/osrs-drops-sdk

> 标签: JavaScript

## 简介

Pre-generated SDK of OSRS boss/raid EHB rates and notable drop items with their probabilities, scraped from the Wise Old Man API and OSRS Wiki — so consumers never scrape live.
