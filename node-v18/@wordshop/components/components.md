# @wordshop/components

> 标签: JavaScript

## 简介

A lightweight React component library built with **TypeScript** and **Vite**.   Currently, it includes one component: **AnalyticsConsent** — a customizable consent banner for analytics tracking. Built by Wordshop. and one hook: **useAssetProps** — a hook
