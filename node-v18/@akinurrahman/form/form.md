# @akinurrahman/form

> 标签: async-select, cascading-select, form, multi-select, radix, react, react-hook-form, shadcn, tailwind, zod

## 简介

A modern form toolkit for React — react-hook-form + zod with bundled shadcn-style fields, cascading selects, and server-paginated async selects.
