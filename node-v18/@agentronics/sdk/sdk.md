# @agentronics/sdk

> 标签: agent-authentication, ai-agents, bot-verification, http-message-signatures, mtls, oauth2, rfc9421, spiffe, web-bot-auth, webmcp

## 简介

Authentication for AI agents — verify every agent on your site (WebMCP, browser agents, crawlers, API agents) with any method: Web Bot Auth, API keys, OAuth2, SSO, SPIFFE, mTLS.
