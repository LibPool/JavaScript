# @z-rack/core

> 标签: JavaScript

## 简介

z-rack エコシステムの基盤パッケージです。すべての z-rack パッケージが依存する共有の型定義、バリデーションスキーマ、エラークラス、インターフェース、ユーティリティーを提供します。
