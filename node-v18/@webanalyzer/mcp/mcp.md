# @webanalyzer/mcp

> 标签: agent, ai, mcp, model-context-protocol, seo, webanalyzer, webanalyzer.dev, website-analyzer

## 简介

MCP server connector for WebAnalyzer (webanalyzer.dev) — bridges stdio MCP clients (Claude Desktop, Cursor, Windsurf) to the hosted Streamable HTTP server. Score any public web page 0-100 across 8 quality dimensions. Free, keyless, zero dependencies.
