# @simplex2-sdk-util/device

> 标签: device, simplex2-sdk-util

## 简介

`Device` 类用于识别当前设备和浏览器类型，并根据配置自动为指定的HTML元素（默认是`<body>`）添加相应的CSS类。这有助于前端开发者根据不同的设备和浏览器进行样式定制。
