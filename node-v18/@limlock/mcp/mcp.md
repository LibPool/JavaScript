# @limlock/mcp

> 标签: a2a, agent, coordination, golf, limlock, mcp, model-context-protocol

## 简介

Model Context Protocol server for Limlock — coordinate group golf rounds from any MCP client (Claude Desktop, Cursor, Cline, Continue, Zed, Goose). v0.1 course inventory concentrated in Ontario, Canada.
