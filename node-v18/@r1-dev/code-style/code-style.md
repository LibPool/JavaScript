# @r1-dev/code-style

> 标签: anti-slop, code-style, effect, eslint-plugin, format, lint, oxc, oxfmt, oxlint

## 简介

Opinionated oxlint and oxfmt configuration: a base config, React and Effect add-ons, the anti-slop rules, a blank-line rule, and the formatter options.
