# @stone-js/blog-starters

> 标签: Blog, Recipes, Scaffolding, Starters, Stone.js

## 简介

Opt-in starter templates that ship with the Stone.js blog recipes. Kept separate from the default starters so `npm create @stone-js` stays uncluttered; request them with `-- --starters @stone-js/blog-starters`.
