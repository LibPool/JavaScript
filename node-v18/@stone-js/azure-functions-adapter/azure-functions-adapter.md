# @stone-js/azure-functions-adapter

> 标签: Stone.js, adapter, azure, azure-functions, connector, event-grid, faas, functions, queue, serverless, service-bus, timer

## 简介

General-purpose Azure Functions adapter for Stone.js, run any app on event-driven Azure Functions triggers, beyond HTTP. Supports Queue Storage, Service Bus, Event Grid, Event Hub, Timer and Blob.
