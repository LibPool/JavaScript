# @jsilvanus/seedeer

> 标签: clip, computer-vision, huggingface-transformers, image-captioning, image-embeddings, large-language-models, nodejs, object-detection, object-tracking, vision, visual-question-answering, vqa

## 简介

A Node.js vision-model toolkit: detection/tracking with zone triggers, visual question answering, captioning, and image embeddings (joint and vision-only), importable directly with no HTTP required.
