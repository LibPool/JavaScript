# @arkxio/ark-plugin

> 标签: JavaScript

## 简介

一个 Vue 运行时插件系统,用于管理组件扩展。它提供了一种灵活的方式来注册和渲染扩展点,允许插件/模块向应用程序的特定位置贡献组件。
