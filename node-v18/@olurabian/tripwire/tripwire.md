# @olurabian/tripwire

> 标签: agentic, agents, ai, evaluation, governance, llm, monitoring, observability, reliability, safety, testing

## 简介

Catch the silent wrong action, the thing an AI agent does that returns ok but is wrong. A read-only scanner for agent runs. Zero dependencies.
