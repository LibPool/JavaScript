# @geoseal/nativescript

> 标签: background-location, geofence, geoseal, location, nativescript

## 简介

Geoseal location / geofence / ingest SDK for NativeScript (iOS + Android). The TS layer drives the Capacitor-free native cores (GeosealCore pod / dev.geoseal:geoseal-core AAR) via the NativeScript runtime; all detection logic runs server-side.
