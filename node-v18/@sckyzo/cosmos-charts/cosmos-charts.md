# @sckyzo/cosmos-charts

> 标签: apexcharts, charts, cosmos, design-system, react, react-19

## 简介

React chart components for the Cosmos design system — themeable ApexCharts 5 wrappers (bar, line, area, donut, radial gauges, sparkline, treemap, realtime) with light/dark support.
