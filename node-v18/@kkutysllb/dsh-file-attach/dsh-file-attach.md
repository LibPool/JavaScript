# @kkutysllb/dsh-file-attach

> 标签: JavaScript

## 简介

dsh file attachment plugin: attach files and folders to conversation via a locate-then-reference chain (browser file picker + server-side locate RPC), injecting [attachment] path lines into the prompt. Images stay fully native — paste/drop of images is ne
