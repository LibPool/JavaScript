# @signaledi/mcp-server

> 标签: 810, 850, 856, accounting, ai, claude, cursor, edi, mcp, model-context-protocol, qbo, quickbooks, signaledi, x12

## 简介

Model Context Protocol (MCP) server for SignalEDI — parse, validate, send, and inspect X12 EDI documents, and sync EDI ↔ QuickBooks Online, from any MCP client (Claude Desktop, Cursor, Windsurf).
