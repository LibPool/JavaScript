# @ryofuu/agentflow

> 标签: agent, ai, automation, bun, claude, codex, dag, orchestration, pipeline, workflow

## 简介

Declarative workflow engine for orchestrating AI agents. GitHub Actions-like YAML syntax with DAG-based parallel execution and real-time PTY streaming.
