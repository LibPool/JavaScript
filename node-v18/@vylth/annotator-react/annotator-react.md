# @vylth/annotator-react

> 标签: annotation, developer-tools, feedback, react, widget

## 简介

React wrapper for the Vylth annotator widget. Drop <Annotator /> into a dev/staging build and click the bubble to send screenshot + diagnostic envelope to your local annotator API.
