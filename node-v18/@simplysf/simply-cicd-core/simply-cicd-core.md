# @simplysf/simply-cicd-core

> 标签: cicd, force, salesforce, salesforcedx, sf, sf-plugin, sfdx, sfdx-plugin

## 简介

ALM issue linking (Jira, GitLab Issues) and VCS API clients (GitHub, GitLab) — the library layer behind @simplysf/simply-cicd, published separately for direct consumption (e.g. a bot or script) without the CLI framework
