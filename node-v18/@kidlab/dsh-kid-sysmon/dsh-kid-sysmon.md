# @kidlab/dsh-kid-sysmon

> 标签: dsh, dsh-plugin, kid, sysmon, system

## 简介

给小朋友的「电脑体检 / 资源监控」启蒙插件：一个包 = 一张 🐻「小熊体检」卡片 + 一个 system_status 工具，查 CPU/内存/磁盘/网络/电池/负载/Top 进程的真实数据（免 sudo，零第三方依赖，无构建）。
