# @bezel-labs/bezel-kit

> 标签: css-custom-properties, css-variables, design-tokens, dtcg, style-dictionary, theming

## 简介

Convert a W3C Design Tokens (DTCG) file into a scoped variables.css, with one CSS scope per context.
