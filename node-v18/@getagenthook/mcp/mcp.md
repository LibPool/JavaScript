# @getagenthook/mcp

> 标签: agents, ai, image-generation, mcp, modelcontextprotocol, video-generation

## 简介

Local stdio MCP server for the AgentHook hosted media-generation API — make character-consistent UGC video, images, and captions from any MCP client.
