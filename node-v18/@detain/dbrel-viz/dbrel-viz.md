# @detain/dbrel-viz

> 标签: cytoscape, d3, database, dataviz, erd, graph, jointjs, relationships, schema, sigma, vis, visualization, xyflow

## 简介

Interactive database relationship visualization library with 20 swappable rendering engines (JointJS, Cytoscape, D3, Sigma, vis.js, GoJS, XYFlow, and more)
