# @formtrieb/tokens-recipe

> 标签: design-system, design-tokens, oklch, tokens-studio

## 简介

Generates a complete design-token model from a recipe — OKLCH ramps, roles, controls, type, motion — as a Tokens-Studio tree with checked contracts. Pure functions; CSS via @formtrieb/tokens-render.
