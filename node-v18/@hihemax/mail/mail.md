# @hihemax/mail

> 标签: email, email-accounts, hihemax, magic-link, otp, sdk, smtp, transactional, verification

## 简介

Official Node/TypeScript SDK for the Hihemax Mail Developer API — send transactional email, send as your own mailboxes, and verify addresses (OTP + magic link).

- 官网：https://mail.hihemax.com/docs/api
