# @openpromo/google-ads

> 标签: ad-group, ads, advertising, business-sdk, campaign, gaql, google, google-ads, google-ads-api, google-ads-sdk, marketing-api, protobuf, sdk, type-safe, typed, typescript

## 简介

Type-safe Google Ads API v25 SDK, runtime-agnostic, generated from protobuf. Customer-bound factory and typed GAQL query builder.
