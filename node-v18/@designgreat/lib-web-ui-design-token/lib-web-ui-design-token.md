# @designgreat/lib-web-ui-design-token

> 标签: JavaScript

## 简介

Designgreat's source of truth for UI design tokens. This package provides token authoring, Style Dictionary build pipeline (light/dark themes, CSS/JS outputs), theme utilities, and TypeScript runtime for downstream packages.
