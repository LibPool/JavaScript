# dsh-goodies

> 标签: deepseek-harness, dsh, dsh-plugin, effort, reasoning-effort, tokens-per-second, usage

## 简介

Small conveniences for the DeepSeek Harness Web GUI: a Codex-style effort slider in the model menu, a live tokens/second and turn-total readout, a per-answer report, and a completion notification when a turn finishes.
