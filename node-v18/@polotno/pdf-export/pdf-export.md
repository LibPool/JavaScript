# @polotno/pdf-export

> 标签: cmyk, javascript, json to pdf, pdf, pdf export, pdf/x-1a, pdf/x-4, polotno, print pdf, vector pdf

## 简介

Convert Polotno JSON into vector PDFs in browsers and Node.js, with custom-font embedding and natively written PDF/X-4 and PDF/X-1a print output

- 官网：https://polotno.com/docs/pdf-export
