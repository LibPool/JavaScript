# @vertexa/prisma-schema-wasm

> 标签: PSL, PostGIS, Prisma, WASM, WebAssembly, fork, formatter, geography, geometry, internal, parser, prisma-fmt, schema, vertexa

## 简介

Fork of @prisma/prisma-schema-wasm — WebAssembly build of the Prisma Schema Language parser and formatter (prisma-fmt). Adds Geometry/Geography scalar types and @db.Geometry/@db.Geography native type attributes. Internal package.
