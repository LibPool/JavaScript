# @metapages/dataref

> 标签: arraybuffer, base64, binary, data-url, dataref, dataurl, decode, encode, json, serialization, typed-array, url-encoding

## 简介

**Encode any JavaScript type including TypedArrays into data URL strings for embedding in URL parameters, shrinking JSON, and more.**
