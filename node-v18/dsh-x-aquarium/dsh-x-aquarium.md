# dsh-x-aquarium

> 标签: aquarium, decoration, deepseek-harness, dsh, dsh-plugin

## 简介

把 DSH-X 启动器主页的水面和大肥鱼搬进 dsh 网页：一块纯装饰的固定背景层（WebGL 水面 + 漂浮的大肥鱼），深浅色自适应，不碰任何界面功能。Bring the DSH-X launcher's water surface and big fish to the dsh web page as a pure-decoration background layer with day/night support.
