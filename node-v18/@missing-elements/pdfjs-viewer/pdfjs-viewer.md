# @missing-elements/pdfjs-viewer

> 标签: adobe-acrobat, embed-pdf, embed-pdf-viewer, javascript, pdf-document, pdf-lib, pdf-sdk, pdf-viewer, pdfjs, pdfjs-dist, pdfjs-viewer, react-pdf, typescript, vue-pdf, web-component

## 简介

A standalone, isolated, self-hostable, plug-in custom element for viewing PDF files, based on [PDF.js default viewer](https://mozilla.github.io/pdf.js/web/viewer.html).
