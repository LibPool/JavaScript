# @query-farm/flechette

> 标签: access, arrow, data, ipc, query-farm, vgi

## 简介

Fast, lightweight access to Apache Arrow data — Query Farm fork of @uwdata/flechette with per-record-batch custom_metadata, multi-batch IPC stream encoding (tablesToIPC/concatTables), and foreign Arrow type support for VGI.
