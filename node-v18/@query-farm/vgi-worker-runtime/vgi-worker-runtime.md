# @query-farm/vgi-worker-runtime

> 标签: duckdb, duckdb-wasm, emscripten, sharedarraybuffer, vgi, wasm, worker

## 简介

Browser (worker:) transport runtime for VGI workers — the JS/TS worker-side of DuckDB-WASM's SharedArrayBuffer channel. Rust→wasm (emscripten) and pure-TypeScript worker paths.
