> 标签: engine, express, expressjs, javascript, node, nodejs, rendering, server, ssr, template, templates, vue, vue-component, vue-components, vue2, vuejs, vuejs2

## 简介

Vue + Express.js = VueXpress / A server side rendering engine for Express.js. Use .vue files as your express.js templates.
