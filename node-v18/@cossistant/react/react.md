# @cossistant/react

> 标签: accessibility, ai-support, chat-widget, customer-support, headless-ui, helpdesk, live-chat, react, support-widget, tailwind, typescript, websocket

## 简介

Headless React SDK for building AI-powered support/chat widgets. Hooks + primitives, WS-driven, TypeScript-first. Next.js-ready, Tailwind optional.
