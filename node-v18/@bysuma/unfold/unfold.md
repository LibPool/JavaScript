# @bysuma/unfold

> 标签: animation, component, css, headless, menu, morph, popover, react, shadcn, ui

## 简介

A headless morphing menu for React with fluid CSS-driven animations. A fork of bloom (Josh Puckett), rewritten on a zero-dependency CSS transition engine.
