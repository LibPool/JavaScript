# @sigx/lynx-icons

> 标签: font-awesome, icon, icons, lucide, lynx, signalx, sigx

## 简介

Icon component and registry for sigx-lynx — works with adapter packages like @sigx/lynx-icons-fa-free and @sigx/lynx-icons-lucide.
