# @sigx/lynx-list

> 标签: flatlist, list, lynx, recycler, signalx, sigx, virtualized

## 简介

High-performance virtualized list for sigx-lynx — data-driven wrapper over the native <list> recycler with grid/waterfall layouts, header/footer/empty slots, edge-reached events and an imperative scroll API. Pure JS.
