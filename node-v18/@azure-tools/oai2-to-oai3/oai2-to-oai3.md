# @azure-tools/oai2-to-oai3

> 标签: async, autorest, azure, perks, typescript

## 简介

OpenAPI2 to OpenAPI3 conversion library that maintains souremaps for use with AutoRest

- 源码仓库：git+https://github.com/Azure/autorest.git
