# @forevka/wordcanvas

> 标签: canvas, collaboration, comments, contenteditable-alternative, devexpress-alternative, document, document-editor, docx, docx-editor, editor, embeddable, onlyoffice-alternative, pdf, rich-text, suggestions, syncfusion-alternative, track-changes, word, word-editor, word-processor, wysiwyg

## 简介

Open-source embeddable Word-style document editor: canvas-rendered, with live collaboration, track changes & comments, and DOCX/PDF import & export. A lightweight alternative to Syncfusion, OnlyOffice, and DevExpress document editors. Self-contained, zero
