# @dwk/oauth

> 标签: dpop, dynamic-client-registration, introspection, oauth2, par, revocation, rfc7009, rfc7591, rfc7662, rfc8414, rfc9126

## 简介

OAuth 2.0 server building blocks: RFC 8414 metadata, RFC 7662 introspection, RFC 7009 revocation, RFC 9126 PAR, RFC 7591 dynamic client registration. Cross-standard reusable; no Workers runtime dependency.
