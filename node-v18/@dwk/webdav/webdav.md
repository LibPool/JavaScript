# @dwk/webdav

> 标签: cloudflare-workers, network-drive, rfc4918, solid, solid-pod, webdav

## 简介

WebDAV (RFC 4918, Class 2) façade over a Solid pod: mount your own storage as a native network drive. Protocol core — bounded XXE-safe XML, app-password auth, If-header parsing.
