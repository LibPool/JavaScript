# robot-heads

> 标签: 3d, agent, ai, animation, avatar, avatars, bot, canvas, chatbot, led, llm, mascot, react, robot, status

## 简介

Animated 3D robot heads for React: glossy TV-headed bots in four shapes, with LED-matrix faces that show what an agent is doing (thinking, searching, listening, speaking and more). 2D canvas, no WebGL, no runtime dependencies.
