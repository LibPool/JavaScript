# @openswissdata/sdk

> 标签: compliance, customs, finma, isic, kyc, mcp, nace, noga, openswissdata, swiss, switzerland, tares, tariff

## 简介

Official TypeScript SDK for openswissdata.com — Swiss customs (TARES), classifications (NOGA/NACE/ISIC) and FINMA registry, via the live MCP JSON-RPC endpoint.
