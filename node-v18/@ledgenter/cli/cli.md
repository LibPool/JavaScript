# @ledgenter/cli

> 标签: JavaScript

## 简介

Ledgenter CLI (bin `ledgenter`) — thin headless wrapper over @ledgenter/core for cron/scripts. Commands mirror the MCP tools; --json output, proper exit codes, --soft-fail for the emit-agent-event.sh contract.
