# @kingdom_soldier/repo-analyzer

> 标签: ai, analyzer, cli, codebase, context, gitignore, json, llm, repository, tree

## 简介

Analiza un repositorio respetando .gitignore y exporta su estructura y contenido como JSON, ideal para dar contexto a una IA.
