# @keld/keld

> 标签: anthropic, bedrock, finops, keld, llm, observability, openai, opentelemetry, otlp, telemetry

## 简介

Drop-in observability SDK that reports OpenAI/Anthropic/Bedrock (and any OpenAI-compatible) inference calls to a Keld Atlas backend via OTLP logs, with zero call-site changes.
