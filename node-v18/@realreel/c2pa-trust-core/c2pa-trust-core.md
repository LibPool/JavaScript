# @realreel/c2pa-trust-core

> 标签: c2pa, content-authenticity, content-credentials, provenance, realreel, trust-list

## 简介

Part of the open-source RealReel C2PA signing/verification stack — shapes, trust list, action allowlists, and pure policy functions (no I/O, no native deps, no crypto). Shared between the RealReel client preflight gate and the Cloud Run verifier.
