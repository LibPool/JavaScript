# @agentum/mcp-server

> 标签: brasil, cep, cnpj, cpf-validation, fx, lei, mcp, payments, usdc, vat, x402

## 简介

Servidor MCP da AGENTUM — dados globais reais (CNPJ, CEP, taxas, validação de dígito de CPF — sem consulta de dado pessoal —, LEI, VAT, câmbio, indicadores, verificação de contraparte) pra qualquer agente de IA consumir via x402, pagando por chamada em US
