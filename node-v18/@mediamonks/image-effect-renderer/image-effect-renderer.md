# @mediamonks/image-effect-renderer

> 标签: effect, fragment shader, glsl, image, oneshader, react, shader, shadertoy, video, webgl

## 简介

The image-effect-renderer is a lightweight package for running fragment shaders on websites using WebGL. Apply effects to HTML image or video sources. Zero dependencies.
