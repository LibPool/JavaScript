# @renowide/ui-kit

> 标签: canvas-kit, react, renowide, sdui, tsx

## 简介

Canvas Kit v2 authoring components (TSX → JSON) and a standalone React renderer for developers shipping Renowide Path C (SDUI + custom_embed) agents.
