# @phoenix-plugin-registry/pflynn.quick.import

> 标签: CommonJS, RequireJS

## 简介

Shortcut for generating require() imports. Press Ctrl+I (⌘I on Mac) and type a filename to insert a require() at the top of your file - in an existing block if available, with '='s nicely aligned.
