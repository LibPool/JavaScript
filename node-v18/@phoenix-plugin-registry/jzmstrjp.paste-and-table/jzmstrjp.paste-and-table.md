# @phoenix-plugin-registry/jzmstrjp.paste-and-table

> 标签: html, table

## 简介

Please copy and paste from Excel or Google spreadsheets, and this extension makes table. If you put the word [th] at the beginning of the cell, it becomes a th tag. It's useful to use with the extension 'Table Editor'.
