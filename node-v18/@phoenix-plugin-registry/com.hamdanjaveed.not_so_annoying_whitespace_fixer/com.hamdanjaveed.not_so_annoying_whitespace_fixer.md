# @phoenix-plugin-registry/com.hamdanjaveed.not_so_annoying_whitespace_fixer

> 标签: JavaScript

## 简介

Trims trailing whitespace for entire file except the line the cursor is currently on. Also ensures a newline at the end of the file.
