# @phoenix-plugin-registry/brackets-gitbranch

> 标签: brackets, branch, github, switch

## 简介

Show project's git branch in status Brackets status bar. Only tested on WNDOWS, not yet tested under UNIX. So if you find any bug please submit an issue ;). NOTE: path to git exec must be setted in your global environement path variable
