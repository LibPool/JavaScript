# @phoenix-plugin-registry/mackenza.file-system-properties

> 标签: JavaScript

## 简介

Allows viewing of file or folder properties (such as file size, etc) and setting of permissions for items in the Project tree.  This extension is NLS-enabled and translation PRs are welcome!
