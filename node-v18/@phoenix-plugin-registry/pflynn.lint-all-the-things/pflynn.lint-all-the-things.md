# @phoenix-plugin-registry/pflynn.lint-all-the-things

> 标签: JavaScript

## 简介

Lint everything in your project in one batch! Optionally filter out certain files or folders, and see all the rest in a consolidated report. To get started, choose "View > Lint Whole Project".
