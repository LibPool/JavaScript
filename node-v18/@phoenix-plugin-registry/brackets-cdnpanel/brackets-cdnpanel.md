# @phoenix-plugin-registry/brackets-cdnpanel

> 标签: API, CDN, css, font, framework, icon, library, plugin, script, svg

## 简介

Get instant access to over 3000 Javascript libraries, plugins, CSS frameworks, fonts etc. Simply choose what you need from a list or find it by typing in a keyword. That way you are always just a few click from the latest version of what you need.
