# @phoenix-plugin-registry/close-all-files

> 标签: JavaScript

## 简介

Closes all open files (except primary focus) when Brackets app is closed. This allows Brackets to open with a mostly fresh, clean slate. Currently, this extension will still leave the last open file visible when Brackets is re-opened. My first extension -
