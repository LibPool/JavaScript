# @lpextend/lp-types

> 标签: JavaScript

## 简介

Canonical TypeScript types for the LivePerson REST APIs, plus the LP region/zone resolver (lp-regions.ts — the one module here with real runtime logic). Single source of truth across the extend monorepo.
