# @seemodo/vite-tanstack-config

> 标签: cloudflare-workers, hmr, nitro, seemodo, tanstack-start, vite

## 简介

One-call Vite config for Seemodo TanStack Start apps: TanStack Start, React, Tailwind, tsconfig paths, Nitro for Cloudflare Workers, sandbox dev server with HMR gate, error collector and build diagnostics.
