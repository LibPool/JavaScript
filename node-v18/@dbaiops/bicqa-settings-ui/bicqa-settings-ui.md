# @dbaiops/bicqa-settings-ui

> 标签: bic-qa, cordis, dsh, settings, ui

## 简介

BIC-QA 插件设置卡片（浏览器端，DSH dsh.client 双面包）：在 DSH 设置 → 插件配置 渲染 bicqa 命名空间的表单（API Key / 基础地址 / 超时 / 输出目录等）。
