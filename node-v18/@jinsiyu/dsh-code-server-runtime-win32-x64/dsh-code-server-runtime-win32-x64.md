# @jinsiyu/dsh-code-server-runtime-win32-x64

> 标签: JavaScript

## 简介

Prebuilt native modules for the VS Code server tree on win32-x64 (node-pty, @vscode/sqlite3, kerberos, @vscode/spdlog, …), so that installing the VS Code inner dependencies needs no build approval or C++ toolchain.
