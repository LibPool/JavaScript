# @swapdk/wdk-wallet-tron

> 标签: bip-32, swapdk, thorchain, tron, wallet, wdk

## 简介

WDK wallet module for TRON, extending @tetherto/wdk-wallet-tron with raw-calldata contract calls so sendTransaction can invoke arbitrary smart contracts (e.g. THORChain router depositWithExpiry). Fork of @tetherto/wdk-wallet-tron.
