# @kyomel/pi-omp-cc

> 标签: commandcode, oh-my-pi, omp, pi-extension, pi-package, provider

## 简介

Unofficial Command Code (commandcode.ai) provider for pi and Oh My Pi. Talks to the documented Provider API with your own API key. Not affiliated with or endorsed by Command Code.
