# @flowselections/core

> 标签: JavaScript

## 简介

Fundament-module: authenticatie, shell-layout (sidebar/header), instellingen en de gedeelde UI-componenten. Elke module heeft core als `peerDependency`; de shell bepaalt welke core-versie draait.
