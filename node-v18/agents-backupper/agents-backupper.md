# agents-backupper

> 标签: backup, claude-code, codex, coding-agent, hermes, hooks, undo

## 简介

Pre-execution backups for coding agents: a hook for Claude Code, Codex and Hermes that captures what a tool call is about to destroy, so the step can be undone.
