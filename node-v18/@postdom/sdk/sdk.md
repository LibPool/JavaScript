# @postdom/sdk

> 标签: ai agent, instagram reels api, mcp, schedule posts api, short-form video, social media api, social publishing, tiktok api, typescript, youtube shorts api

## 简介

Typed, zero-dependency Node and edge client for the Postdom short-form publishing API: upload media, connect TikTok, Instagram, and YouTube accounts, submit plans, publish videos, and read honest performance data.
