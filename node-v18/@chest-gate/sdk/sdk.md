# @chest-gate/sdk

> 标签: agent, chest-gate, mcp, skill, solana, x402

## 简介

Drop-in fetch() that pays x402 gates from any agent. Use a managed wallet (agent token) or a local keypair; credit a referrer with a publishable referrer key.
