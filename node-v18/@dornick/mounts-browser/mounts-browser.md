# @dornick/mounts-browser

> 标签: JavaScript

## 简介

Browser-API VFS mounts for Dornick — Clipboard, Geolocation, FileSystem Access, WakeLock, IdleDetection, BackgroundSync, ShareTarget, Battery, Online state, Notifications, Web Speech. Each capability-gated.
