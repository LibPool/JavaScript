# @kynnyhsap/envi

> 标签: JavaScript

## 简介

Envi is an env manager for TypeScript projects. A project defines its env in a typed `envi.config.ts`. Envi resolves the config once from a secret provider, caches the result, and injects the values into a runtime. 1Password is the only provider for now.
