# @cleepi/toolkit

> 标签: cleepi, cleevio, meta-package, pi-package

## 简介

The Cleevio agent in one install. Bundles @cleepi/sdd, base, coding, git, crew, atlassian, and ships a `cleepi-toolkit init` CLI to wire them up in one command.
