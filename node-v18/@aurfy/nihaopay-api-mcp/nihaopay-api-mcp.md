# @aurfy/nihaopay-api-mcp

> 标签: documentation, mcp, model-context-protocol, nihaopay, payments

## 简介

MCP server that serves Nihaopay v1.2 payment-API documentation to LLM agents. Bundles a docs snapshot with a BM25 retrieval index; runs fully offline over stdio.
