# @octanejs/tiptap

> 标签: JavaScript

## 简介

TipTap bindings for Octane, including editor hooks and contexts, EditorContent, custom node and mark views, and floating menus without a React runtime dependency.

- 源码仓库：git+https://github.com/octanejs/octane.git
