# @octanejs/styled-components

> 标签: JavaScript

## 简介

styled-components for the octane renderer — the full v6 web API (styled, css, keyframes, createGlobalStyle, theming, StyleSheetManager, ServerStyleSheet) over octane's ref-as-prop components and its automatic SSR css channel.
