# @stll/folio-nuxt

> 标签: docx, editor, nuxt, nuxt-module, ooxml, prosemirror, vue, word, wysiwyg

## 简介

Nuxt 3 & 4 module for folio: auto-imports an SSR-safe <DocxEditor> component built on @stll/folio-vue and ProseMirror.
