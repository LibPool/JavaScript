# rawstate-devtools

> 标签: debugging, devtools, inspector, rawstate, redux-devtools, state, store, time-travel, typescript

## 简介

Devtools for rawstate: every commit with its origin, time travel, a panel in the page and a bridge to the Redux DevTools extension. Nothing in production. About 3 KB gzipped.
