# ai-sdk-harness-workspace

> 标签: ai, ai-sdk, ai-sdk-harness, claude-code, codex, coding-agent, git, harness, patch, sandbox, workspace, worktree

## 简介

Git workspaces for AI SDK harness agents: a repository checked out in the sandbox, a worktree of its own for each session of Claude Code, Codex and friends, and its changes back as a patch — on any sandbox, credentials kept out of it.
