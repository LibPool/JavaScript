# @safecart/mcp

> 标签: gpsr, mcp, model-context-protocol, product-safety, recalls, safecart

## 简介

MCP server for the SafeCart Public API — EU Safety Gate recall checks, recalls search, Product Safety Passports, store scans, and monitoring status.
