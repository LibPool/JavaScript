# @tomtom-org/maps-sdk-plugin-flyover

> 标签: JavaScript

## 简介

A camera that flies a route on a TomTomMap: it follows the line, aims at the junctions ahead, frames them, clears the terrain it crosses, and parks the followed position where you want it on screen
