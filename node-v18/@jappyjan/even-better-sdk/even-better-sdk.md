# @jappyjan/even-better-sdk

> 标签: JavaScript

## 简介

A lightweight wrapper around `@evenrealities/even_hub_sdk` for building pages and elements that render inside the Even Hub app. It adds an opinionated API for page composition, partial text updates, shared SDK initialization, and configurable logging.
