# @vcarloto/resumablejs

> 标签: file, html5, upload

## 简介

A JavaScript library for providing multiple simultaneous, stable, fault-tolerant and resumable/restartable uploads via the HTML5 File API. Forked to addForked to add xhrTimeout.
