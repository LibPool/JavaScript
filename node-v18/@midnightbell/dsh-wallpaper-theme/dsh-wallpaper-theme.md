# @midnightbell/dsh-wallpaper-theme

> 标签: background, dsh, dsh-bundle, dsh-plugin, theme, wallpaper

## 简介

DSH 背景壁纸主题插件：设置页「背景主题」入口，渐变预设/本地图片/剪贴板/图片链接，设置持久化到 DSH_HOME，重启自动恢复。
