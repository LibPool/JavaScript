# @manya-hael/cortex

> 标签: cortex, manya, orchestration, reasoning, routing

## 简介

A reasoning fabric that routes tasks to the tools that already own them, gates dispatch through access control, and chains every decision into an auditable trail — composed from memory, unify, shield, and stamp.
