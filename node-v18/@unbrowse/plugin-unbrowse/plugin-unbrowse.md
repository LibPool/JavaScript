# @unbrowse/plugin-unbrowse

> 标签: browser, elizaos, elizaos-plugin, mcp, scrape, unbrowse, web

## 简介

elizaOS plugin for Unbrowse: read pages, run website tasks and use a cloud browser through the hosted Unbrowse MCP. Drop-in replacement for the default browser.
