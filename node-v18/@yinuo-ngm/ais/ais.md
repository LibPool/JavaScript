# @yinuo-ngm/ais

> 标签: AIS, ais, ngm, yinuo

## 简介

一个偏“纯算法”的 AIS/ASM 应用数据编码 + NMEA 封装核心库（TypeScript），用于把上层应用 payload 编码为 bit 流（DAC/FI + appBits），再转换为 6-bit payload，最终输出可直接喂给 AIS/ASM 设备外部接口的 ABM / BBM / AAB / ABB / AGB 等 NMEA 语句。
