# @activeit/frontend.core

> 标签: JavaScript

## 简介

Libreria de frontend escrita en TypeScript para construir interfaces modulares sobre navegador, con foco en integraciones Siebel/ActiveIT. El paquete expone vistas base, layouts, controles de formulario, modales, tablas, paginacion, iconografia y un clien
