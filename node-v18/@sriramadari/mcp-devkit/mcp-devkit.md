# @sriramadari/mcp-devkit

> 标签: agents, ai, assertions, cli, conformance, devtools, harness, inspector, llm, mcp, model-context-protocol, modelcontextprotocol, test, testing, tools

## 简介

A zero-dependency testing & inspection toolkit for Model Context Protocol (MCP) servers: in-memory and stdio test clients, fluent tool-result assertions, input-schema validation, and an automated conformance checker. Library + CLI.
