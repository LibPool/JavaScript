> 标签: azure, backblaze, esm, file-storage, gcs, minio, multipart, object-storage, r2, s3, signed-url, storage, streaming, street-framework, streetjs, supabase, typescript

## 简介

StreetJS unified storage framework: a strongly-typed, plugin-first, driver-based object storage layer with zero-dependency in-memory and filesystem drivers, streaming, validation, metadata, multipart, resumable uploads, signed URLs, versioning, lifecycle,
