> 标签: application-events, domain-events, esm, event-bus, event-emitter, events, middleware, pubsub, replay, street-framework, streetjs, typescript, wildcard

## 简介

StreetJS application event layer: a strongly-typed, plugin-first, in-process event system with local/async/ordered dispatch, wildcard subscriptions, once listeners, a composable middleware pipeline, optional event replay over a pluggable event store, heal
