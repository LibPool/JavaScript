# @streetjs/context

> 标签: context, cookies, esm, http, middleware, request, response, street-framework, streetjs, typescript

## 简介

StreetJS request/response context: a strict per-request StreetContext over Node's http req/res with JSON/text/HTML/send helpers, header and secure-by-default cookie handling, params/query/body/state, and a single-write guard.
