# @streetjs/multipart

> 标签: esm, file-upload, form-data, multipart, parser, streaming, street-framework, streetjs, typescript, zero-dependencies

## 简介

StreetJS multipart foundation: a streaming multipart/form-data parser that writes uploads directly to disk (never buffering the full upload in heap), with byte-limit enforcement, filename sanitization, and cleanup on failure. Zero runtime dependencies.
