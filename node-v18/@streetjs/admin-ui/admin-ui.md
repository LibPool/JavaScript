# @streetjs/admin-ui

> 标签: admin, audit, multi-tenancy, rbac, react, street, streetjs, ui

## 简介

Accessible, themeable React admin components for StreetJS (RBAC, audit logs, user management, multi-tenancy) built on @streetjs/react.
