# @streetjs/pool

> 标签: backpressure, connection-pool, database, esm, pool, postgres, postgresql, street-framework, streetjs, transactions, typescript

## 简介

StreetJS PostgreSQL connection pool: a bounded pool with lazy warm-up, health checking, idle sweeping, a backpressure wait queue, transactions, and streaming. Built on @streetjs/postgres.
