# @loopify/primitive-ui

> 标签: React, tailwindcss

## 简介

Primitive UI is a low level React component library that can be used as building blocks for more complex components built on top of tailwindcss. tailwindcss has been chosen because of its populirity, familiarity, and wide range of features that it support
