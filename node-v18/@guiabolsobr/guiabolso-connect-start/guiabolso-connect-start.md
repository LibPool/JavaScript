# @guiabolsobr/guiabolso-connect-start

> 标签: Connect, Connect Start, Guiabolso Connect, Guiabolso Connect Start, Guiabolso Start

## 简介

O Guiabolso Connect Start é um script para facilitar a integração do Guiabolso Connect, seja através de uma experiência embedada ou através de um botão de fácil acesso parao Guiabolso Connect.
