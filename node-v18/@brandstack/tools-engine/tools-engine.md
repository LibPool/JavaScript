# @brandstack/tools-engine

> 标签: brandstack, color palette, launch image resizer, og image, utm builder, webgl shaders

## 简介

The engine behind Brand Stack's free tools (brandstack.dev/tools): every tool's logic as pure, isomorphic TypeScript, with rendering pushed out into thin adapters. Consumed by the brandstack.dev web app and by @brandstack/cli.
