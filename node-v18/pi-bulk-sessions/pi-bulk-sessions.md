# pi-bulk-sessions

> 标签: bulk, checkbox, delete, multi-select, pi, pi-coding-agent, pi-extension, pi-package, resume, sessions, tui

## 简介

Multi-select chat deletion inside pi's own resume browser. /sessions adds a checkbox column to pi's SessionSelectorComponent: alt+s toggles, alt+a toggles all, alt+x deletes the checked chats (trash-safe).
