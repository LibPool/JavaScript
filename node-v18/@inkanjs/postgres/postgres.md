# @inkanjs/postgres

> 标签: inkan, jobs, pg, postgres, postgresql, rate-limit, session, store

## 简介

A PostgreSQL store for inkan: jobs, sessions, auth, idempotency keys and rate limits in one table, on the pool you already have.
