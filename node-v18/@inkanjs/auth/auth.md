# @inkanjs/auth

> 标签: auth, csrf, inkan, jwks, jwt, oauth, oidc, pkce, refresh-token, scrypt, session, totp

## 简介

Authentication for inkan without dependencies: sessions, JWTs, API keys, passwords, TOTP and OAuth on node:crypto alone.
