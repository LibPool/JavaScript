# @inkanjs/query

> 标签: inkan, react-query, server-sent-events, solid-query, svelte-query, tanstack-query, typed-client, vue-query, websocket

## 简介

The typed inkan client for TanStack Query: data typed from the contract, problems as errors, live events and WebSockets. React, Vue, Svelte, Solid.
