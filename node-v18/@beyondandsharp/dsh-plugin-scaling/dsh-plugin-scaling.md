# @beyondandsharp/dsh-plugin-scaling

> 标签: deepseek-harness, dsh, pane-zoom, plugin, ui-scaling, web

## 简介

Independent per-pane zoom for the DSH web shell: Ctrl+wheel over a pane, Ctrl+± / Ctrl+0 for the focused pane. Works with the official look and every skin.
