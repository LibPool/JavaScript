# @patimweb/pi-cron

> 标签: automation, cron, pi-extension, pi-package, scheduler

## 简介

Scheduled prompts for the pi coding agent: save a prompt + schedule + tool allowlist as a cron job. Runs inside pi on any OS, keeps configuration and run history, catches up missed and interrupted runs.
