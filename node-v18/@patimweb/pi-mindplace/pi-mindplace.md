# @patimweb/pi-mindplace

> 标签: ast, code-exploration, code-graph, code-navigation, graphify, knowledge-graph, louvain, mind-place, mindplace, pagerank, pi-extension, pi-package, static-analysis, token-optimization, tree-sitter

## 简介

graphify-style code knowledge graph for pi — build a queryable mind place that saves tokens on every session. Parses your code with tree-sitter (WebAssembly, no native binaries) into a navigable graph with community detection, PageRank, and token-budget-a
