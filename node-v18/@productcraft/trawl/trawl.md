# @productcraft/trawl

> 标签: productcraft, scraping, sdk, trawl, web-extraction

## 简介

AI web-extraction — submit a JSON Schema + natural-language description, get schema-conforming data extracted from the live web and delivered to an HMAC-signed webhook via ProductCraft Trawl. Generated from the production OpenAPI spec.
