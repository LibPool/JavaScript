# @bkmj/node-red-contrib-odbcmj

> 标签: database, db2, ibm i, mysql, node-red, odbc, postgresql, query, sql, sql server, streaming

## 简介

A powerful Node-RED node to connect to any ODBC data source, with connection pooling, advanced retry logic, and result streaming.
