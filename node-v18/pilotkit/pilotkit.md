# pilotkit

> 标签: ai-credits, atlassian, cli, confluence, copilot-sdk, github-copilot, jira, mcp, model-context-protocol, onboarding

## 简介

One command to set up GitHub Copilot with Jira and Confluence on a colleague's PC, plus a local desk that shows the AI credits every question costs.
