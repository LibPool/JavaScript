# @5dive/mcp

> 标签: 5dive, agent-fleet, ai-agents, cli, mcp, model-context-protocol

## 简介

Model Context Protocol (stdio) server for 5dive. Exposes the 5dive agent-fleet CLI (tasks, agents, digest) as MCP tools.
