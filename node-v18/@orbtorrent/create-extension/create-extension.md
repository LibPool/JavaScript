# @orbtorrent/create-extension

> 标签: bittorrent, create, extension, macos, orbtorrent, template

## 简介

Make a new extension for OrbTorrent, the BitTorrent app for macOS: npm create @orbtorrent/extension@latest <name>

## 官网

- 官网：https://orbtorrent.com/docs/extensions
- 源码仓库：git+https://github.com/sanjevirau/OrbTorrent.git
- npm 页面：https://www.npmjs.com/package/@orbtorrent/create-extension
