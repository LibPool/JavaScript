# @inrupt/lit-generated-vocab-ui-component

> 标签: JavaScript

## 简介

Bundle of vocabularies that includes the following:

  ui_welcome: The Inrupt Welcome Page vocabulary.

  ui_tictactoe: The Inrupt Tic-Tac-Toe game vocabulary.
