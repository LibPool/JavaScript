# md-chunkit

> 标签: chunker, chunking, embeddings, llm, markdown, rag, retrieval, semantic-chunking, text-splitter

## 简介

Adaptive structural-semantic Markdown chunker for RAG: heading breadcrumbs, atomic lists, table row groups, digit-density budgets and optional embedding-based semantic cuts.
