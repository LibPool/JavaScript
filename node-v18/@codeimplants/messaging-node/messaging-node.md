# @codeimplants/messaging-node

> 标签: 2factor, codeimplants, dlt, otp, sms

## 简介

Server-side client for Code Implants Messaging (msg.codeimplants.com): one-time codes and templated SMS through the shared 2Factor account, with per-app and per-user usage tracking. Zero dependencies.
