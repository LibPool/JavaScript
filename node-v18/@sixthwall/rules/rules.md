# @sixthwall/rules

> 标签: JavaScript

## 简介

YAML vulnerability detection rules for the SixthWall AI code security scanner. 33 rules for JavaScript, TypeScript, Supabase SQL and Firebase rules, targeting AI-generated code patterns.
