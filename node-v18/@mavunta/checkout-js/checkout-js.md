# @mavunta/checkout-js

> 标签: browser, checkout, crypto, kenya, mavunta, mavunta-pay, mpesa, payments

## 简介

Browser checkout for Mavunta Pay. Redirect to hosted checkout and poll payment status with a publishable key (M-Pesa, card, PayPal, crypto).
