# @tsiry/hlsd

> 标签: audio, coreaudio, dash, hls, pcm, streaming

## 简介

Serve live HLS (and optional MPEG-DASH) from a raw PCM s16le audio stream. Installs the prebuilt hlsd binary from GitHub Releases.

## 官网

- 官网：https://github.com/tsirysndr/hlsd
- 源码仓库：git+https://github.com/tsirysndr/hlsd.git
- npm 页面：https://www.npmjs.com/package/@tsiry/hlsd
