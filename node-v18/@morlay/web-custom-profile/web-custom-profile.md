# @morlay/web-custom-profile

> 标签: client-modules, dev, dsh, dsh-bundle, dsh-plugin

## 简介

Dev-only dsh profile bundle: mounts @morlay/dsh-client-modules (our vite + federated prebundle frontend chain) and disables the upstream module-table rows it replaces — shared by `dshdev web` and `dshdev desktop`.
