# @morlay/dsh-profile

> 标签: dsh, dsh-bundle, llm-pi-ai, sandbox

## 简介

Personal dsh profile: 配置初始化层——只给 llm route、welcome notice、搜索后端选择与沙箱访问规则这类 config 值；行的装配（禁官方行 / 插能力行）归各能力包自己的 bundle。
