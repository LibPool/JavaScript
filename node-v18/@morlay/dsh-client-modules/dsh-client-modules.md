# @morlay/dsh-client-modules

> 标签: client, dsh, dsh-plugin, host, vite

## 简介

Dev-form web layer for dsh: serves the page, the app entry and every client resource through an in-process vite dev server (middleware mode) — the node-side counterpart of upstream @deepseek-ai/dsh-client-modules, with the module table replaced by vite's
