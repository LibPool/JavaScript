# @morlay/dsh-session-mode

> 标签: dsh, dsh-bundle, persona, session-mode

## 简介

Personal dsh bundle: session modes (coding / chat) as data — a mode is a persona plus the tools it may use. The host applies the current mode to each session, and the new-session chip plus the session-header label replace the official agent-preset surface
