# @dongsa/mcp

> 标签: JavaScript

## 简介

Read-only Korean reference tools for Model Context Protocol clients. Uses the official MCP TypeScript SDK. The factory can be attached to SDK transports; a stdio entry point is included. Importing the factory does not open databases or load a Kiwi model.
