# @volter/twin-figma

> 标签: api, canvas, design, figma, fixtures, local, localstack, mirror, mock, sdk, simulator, testing, twin

## 简介

Local Figma twin — a faithful, stateful local Figma REST API (files, nodes, images, comments, versions, projects) your unmodified HTTP client talks to. Mirror, simulate, and fork. Built on @volter/world-core.
