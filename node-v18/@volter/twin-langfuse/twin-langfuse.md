# @volter/twin-langfuse

> 标签: api, fixtures, langfuse, llm-observability, local, localstack, mirror, mock, observability, opentelemetry, sdk, simulator, testing, tracing, twin

## 简介

Local Langfuse twin — a faithful, stateful local Langfuse LLM-observability API your real `langfuse` SDK (or `@langfuse/otel`) talks to unmodified. Ingest batched/OTLP trace events into a queryable local trace store, browse the Public API + trace-explorer
