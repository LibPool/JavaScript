# @volter/twin-gcs

> 标签: JavaScript

## 简介

Local Google Cloud Storage twin: buckets, objects with generations and preconditions, media/multipart/resumable uploads, Range-capable media downloads, copy/rewrite/compose, metadata patch, bucket IAM, and the V4 signed-URL surface (signature accepted loc
