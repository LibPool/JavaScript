# @volter/twin-mongodb

> 标签: JavaScript

## 简介

Local MongoDB twin: the MongoDB wire protocol (OP_MSG and the OP_QUERY handshake) served from the World state kernel, so an unmodified mongodb driver or mongoose app runs with nothing installed and no container.
