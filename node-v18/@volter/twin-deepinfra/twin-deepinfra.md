# @volter/twin-deepinfra

> 标签: JavaScript

## 简介

Local DeepInfra twin: OpenAI-compatible chat/completions, completions, embeddings, models, files, batches and rate_limit with the vendor's divergences enforced; inference is a labeled deterministic stub. Built on @volter/twin.
