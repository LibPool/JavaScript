# @volter/twin-supabase

> 标签: api, fixtures, local, localstack, mirror, mock, postgres, sdk, simulator, supabase, testing, twin

## 简介

Local Postgres for apps using Supabase database connections. Supabase Auth, Storage, REST APIs and supabase-js are not supported by this release.
