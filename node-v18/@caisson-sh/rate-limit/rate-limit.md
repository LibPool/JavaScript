# @caisson-sh/rate-limit

> 标签: JavaScript

## 简介

Shared abuse-throttle primitives: an in-memory per-IP token-bucket limiter for unauthenticated surfaces, and a Postgres-backed per-account token-bucket store for authenticated ones.
