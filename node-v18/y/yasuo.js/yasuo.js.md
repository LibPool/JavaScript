# yasuo.js

> 标签: api, client, league-of-legends, lol, rate-limiter, riot, riot-api, riot-games, sdk, teamfight-tactics, tft, twisted, typescript, wrapper

## 简介

The modern, fully-typed, zero-dependency Riot Games API client for TypeScript. The evolution of Twisted, with a proactive rate limiter, lazy relations and async pagination.
