# yougile-mcp-server

> 标签: ai-agent, claude, kanban, mcp, model-context-protocol, task-management, yougile

## 简介

MCP (Model Context Protocol) server for YouGile — connect an AI agent to your YouGile boards and tasks (read + safe writes). Supports stdio (local) and Streamable HTTP (remote) transports.
