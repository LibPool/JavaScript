# yanyanwhere

> 标签: JavaScript

## 简介

yanyanwhere是一款随启随用的静态资源文件服务器，可以随时随地将你的当前目录变成一个静态文件服务器的根目录。

## 官网

- npm 页面：https://www.npmjs.com/package/yanyanwhere
