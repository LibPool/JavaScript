# yo-cli

> 标签: JavaScript

## 简介

webpack配置文件太过杂乱，yo-cli可以用简单语义化的配置构建你的工程。 当然他其实就是一个webpack配置翻译器。 而且目前只是基础版本，很多情况都没有考虑和测试，暂时只是自用。
