# ydb-qdrant

> 标签: ann, embeddings, express, grpc, nearest-neighbor, nodejs, pino, qdrant-compatible, rag, semantic-search, typescript, vector-search, yandex-cloud, ydb, yql, zod

## 简介

Qdrant-compatible Node.js/TypeScript API that stores/searches embeddings in YDB using a global one-table layout with exact KNN search over serialized vectors.
