# ycc-sdk

> 标签: camera, electron, napi, native-addon, socket, ycc

## 简介

Node.js SDK for YCC (Yunxi Camera Communication), N-API addon with bundled ycc library, supports Node.js and Electron

- npm 页面：https://www.npmjs.com/package/ycc-sdk

- npm registry：https://registry.npmjs.org/ycc-sdk
- Node 要求：>=14
