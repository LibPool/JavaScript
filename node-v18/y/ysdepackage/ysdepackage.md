# ysdepackage

> 标签: JavaScript

## 简介

1. 注册npm账号 2. 切换npm源至 npm     nrm ls  查看     nrm use npm 切换至npm 3. 初始化项目   `$ npm init -y` 4. 创建入口文件 根据package.json中的main创建 5. 开发 6. 登陆npm账号  `$ npm adduser` 7. 发布项目     `$ npm publish`
