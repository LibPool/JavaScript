# yapi-plugin-mock

> 标签: mock, yapi, yapi-plugin-mock

## 简介

yapi-plugin-mock 是一款为yapi 定制的 mock 工具，方便的将本地需要 mock 的特定接口请求在发送时转到配置好的 yapi 上的 mock 地址，减少本地代码的修改；
