# yt-transcript-mcp

> 标签: ai, claude, http, mcp, model-context-protocol, remote, sse, subtitles, transcript, youtube

## 简介

MCP server that fetches YouTube video transcripts using yt-dlp - supports local (stdio) and remote (HTTP/SSE) deployment
