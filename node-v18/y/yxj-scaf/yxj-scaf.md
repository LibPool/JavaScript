# yxj-scaf

> 标签: ice-scaffold

## 简介

该模板基于社区的 CoreUI 改造而成，使用 react-scripts 构建，支持 CoreUI 的所有功能，同时也支持飞冰基础组件和区块的使用， 支持 Iceworks 一键创建项目和完整的 GUI 操作

## 官网

- npm 页面：https://www.npmjs.com/package/yxj-scaf

- 当前版本：1.0.0

- 1.0.0

## 获取地址

- npm 安装：`npm install yxj-scaf`
- npm registry：https://registry.npmjs.org/yxj-scaf
- Node 要求：>=8.0.0
