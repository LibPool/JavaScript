# ybais-rbac-rx

> 标签: JavaScript

## 简介

框架无关的 RBAC（基于角色的访问控制）响应式库。以 **RxJS 流** 作为跨框架契约，统一管理用户身份、扁平权限码与菜单树的联动过滤，适用于 React、Vue、Angular 等任意前端技术栈。
