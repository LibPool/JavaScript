# yamlover

> 标签: agent-memory, browser, editor, json5, knowledge-base, knowledge-graph, llm, markdown-alternative, pointers, spa, yaml, yamlover

## 简介

A local-first, editable knowledge graph for humans and LLMs: npx yamlover <root> serves a browser UI over a plain-text directory, with an editor, live queries, pointers, and an LLM-agent API.
