# y-peerjs

> 标签: collaboration, crdt, peerjs, realtime, webrtc, y-webrtc, yjs

## 简介

A Yjs connection provider built on PeerJS — like y-webrtc, but with explicit connect(id)/disconnect(id) control instead of room-based signaling. Includes a floating topology widget.
