# yaml-config-azure

> 标签: azure, configuration, yaml

## 简介

Manage your node.js app configuration based on NODE_ENV, all configuration defined in yaml and stored in Windows Azure blob storage

- npm 页面：https://www.npmjs.com/package/yaml-config-azure

- npm registry：https://registry.npmjs.org/yaml-config-azure
- Node 要求：>= 0.6.15
