# youtube-mp3-converter

> 标签: download, encode, fast, ffmpeg, mp3, parallel, streams, youtube

## 简介

A simple node module to download youtube videos and convert them to mp3s. A simple wrapper around the ytdl and ffmped library, which provides a nice and easy to use api to convert youtube links into mp3s.
