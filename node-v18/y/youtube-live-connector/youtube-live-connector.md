# youtube-live-connector

> 标签: connector, emoji-fountain, event-emitter, jewels, likes, live-chat, reactions, subscribers, superchat, supersticker, viewers, youtube, youtube-live, youtube-live-chat

## 简介

Connect to YouTube Live streams via URL or video ID to extract live chat comments, gifts (Super Chats, Super Stickers, Memberships, Jewels Gifts), emoji reactions, likes, and real-time live viewer counts. Event-driven API.
