# ys-angular-mentions

> 标签: angular, autocomplete, mention, multiple mention, ys-angular-mention

## 简介

Angular mentions from Dmacfarlane & Dessalines - angular-mentions and forked branch from Francis. Modified version of angular-mentions that has an optional function to format the selected item before inserting the text.
