# ydc-react-cron

> 标签: JavaScript

## 简介

该组件改编自 <a href="https://github.com/zhengxiangqi/react-cron-antd">react-cron-antd</a> <br />改编原因：作者长时间未更新组件 导致组件无法正常引用，除了修复了不能组件不能使用的问题外，<br /> 在原基础增加：getCronFns、footer、国际化等功能使组件更加灵活强大，修改 value 值传入后或者更新后自动重新渲染
