# yoni-mcscripts-lib

> 标签: minecraft, minecraft-addon, minecraft-bedrock, minecraft-sapi, scriptsapi

## 简介

为 Minecraft Script API 中的部分接口创建了 wrapper，并提供简单的事件管理器和任务管理器，另附有一些便于代码编写的一些小工具。
