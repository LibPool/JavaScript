# yi-http

> 标签: download, http, node, request

## 简介

对http请求进行了get，post的封装，增加了解码，跳转，超时，代理服务器等功能。

## 官网

- 源码仓库：git://github.com/avicha/http.git
- npm 页面：https://www.npmjs.com/package/yi-http
