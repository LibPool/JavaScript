# yuancode

> 标签: agent, ai, atomcode, coding-agent, embeddable, llm, mcp, tree-sitter, typescript

## 简介

Embeddable AI coding agent for Node.js / TypeScript. Layered after atomcode: neutral kernel, capabilities, coding runtime. Can run standalone, embed into other Node.js apps, and cooperate with other agents.
