# yq-store

> 标签: append-only, cache, database, embedded, fast, jsonl, key-value, kv, low-memory, nodejs, persistent, store, typescript, yq-store

## 简介

A high-performance, persistent and in-memory key-value store with TTL support, built for Node.js applications.
