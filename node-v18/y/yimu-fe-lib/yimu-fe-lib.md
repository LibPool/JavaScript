# yimu-fe-lib

> 标签: JavaScript

## 简介

yimu-fe-lib 是一牧公司前端统一的 Vue 2 组件库基础框架，基于 pnpm monorepo 管理，支持多个包拆分管理，集成 Storybook 做组件交互展示和开发调试。
