# ylazzari-angular-style

> 标签: JavaScript

## 简介

`angular-style` is an independent, MIT-licensed fork of [PrimeNG](https://github.com/primefaces/primeng), vendoring the full component library, its supporting `@primeuix/*` utility/style/theme packages, and PrimeIcons into a single self-contained npm pack
