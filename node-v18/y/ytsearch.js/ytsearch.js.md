# ytsearch.js

> 标签: nodejs, typescript, youtube, youtube-api-wrapper, youtube-channel-search, youtube-data-api-alternative, youtube-metadata, youtube-playlist, youtube-playlist-items, youtube-playlist-pagination, youtube-scraper, youtube-search, youtube-search-api, youtube-video-details, youtube-video-search, ytsearch, ytsearch.js

## 简介

TypeScript YouTube search and data library for Node.js. Search videos, channels, playlists, movies, and live streams, fetch video details and paginated playlist items, without the YouTube Data API.
