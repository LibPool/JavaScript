# yad-agent-mcp

> 标签: ai-agent, browser-automation, claude-code, mcp, model-context-protocol

## 简介

MCP server that lets an AI agent (Claude Code, Cursor, etc.) drive Yad, a local browser-automation companion, over its existing local HTTP API.
