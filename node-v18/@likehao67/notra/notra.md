# @likehao67/notra

> 标签: block-editor, editor, markdown, notion, rich-text, vue, vue3, wysiwyg

## 简介

A Notion-style block editor component for Vue 3, with slash menu, markdown shortcuts, drag-and-drop, multi-language code highlighting, math, and an outline TOC.
