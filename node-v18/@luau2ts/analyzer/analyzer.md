# @luau2ts/analyzer

> 标签: luau, luau-analyze, roblox, type-checker, wasm

## 简介

Luau type checker (Luau.Analysis compiled to WebAssembly). Optional companion to luau2ts that surfaces input-side type errors before translation.

- 官网：https://luau2ts.com
- 源码仓库：git+https://github.com/luau2ts/luau2ts.git
- npm 页面：https://www.npmjs.com/package/@luau2ts/analyzer
