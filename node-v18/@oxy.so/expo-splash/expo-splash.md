# @oxy.so/expo-splash

> 标签: branding, config-plugin, expo, oxyhq, react-native, splash-screen

## 简介

Shared native-splash toolkit for Oxy Expo apps — each app centers its own logo on the shared dark brand background with the Oxy "from Oxy" symbol pinned to the bottom of the native OS splash (the "Instagram, from Meta" pattern).
