# @horang-corp/avr-gcc-wasm

> 标签: arduino, atmega328p, avr, compiler, firmware, gcc, intel-hex, wasm, webassembly

## 简介

Compile Arduino AVR firmware (atmega328p / Uno) to Intel HEX entirely in the browser with AVR GCC + binutils built for WebAssembly.
