# @joloh/jspattern

> 标签: javascript like react, js class, js design patterns, js like react, js pattern, js redux, js state, jspattern

## 简介

A module for js project using classes and design patterns. Has it's own state manager and redux kind provider, update ui like react useEffect, No html except the index.html file
