# @scalegate/licensing-web-sdk

> 标签: domain-fingerprint, feature-flags, license-validation, licensing, multi-tenant, saas, scalegate, sdk, web

## 简介

Official Web SDK for ScaleGate SaaS License Manager. Browser and server-to-server license validation, domain fingerprinting, feature flags, and periodic health checks.
