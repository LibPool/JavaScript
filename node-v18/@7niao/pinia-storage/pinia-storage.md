# @7niao/pinia-storage

> 标签: localStorage, persist, persistence, pinia, plugin, sessionStorage, storage, vue, vue3

## 简介

基于 Vue 3 + Pinia 的轻量持久化存储插件，支持按 store 配置多存储策略（localStorage / sessionStorage / 自定义引擎）。
