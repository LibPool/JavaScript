# pyno-colorpicker

> 标签: alpha, angular, color, color-picker, colorpicker, eyedropper, hex, hsl, hsv, picker, pyno, rgb, standalone

## 简介

A lightweight, standalone, zero-dependency color picker for Angular. Supports Hex, RGB and HSL in any valid CSS format, alpha, eyedropper, popup or inline mode, and full theming via CSS variables.
