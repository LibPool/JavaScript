# @liquidglassjs/core

> 标签: astro, astro-component, displacement-map, fedisplacementmap, glass, glassmorphism, liquid-glass, refraction, svg-filter, tanstack-intent, webgl, withastro

## 简介

SVG-first liquid glass for the web (feDisplacementMap on live DOM), with WebGL + QR escape hatches. Recreated from the technique described in Aave's "Building Glass for the Web".
