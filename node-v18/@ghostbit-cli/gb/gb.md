# @ghostbit-cli/gb

> 标签: cli, decrypt, dotenv, encryption, env, ghostbit, secrets, steganography

## 简介

Decrypt Ghostbit stego images from the command line and turn them back into files (e.g. regenerate a .env from a committed env.png).
