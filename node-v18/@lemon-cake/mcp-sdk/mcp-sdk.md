# @lemon-cake/mcp-sdk

> 标签: ai-agent, billing, lemoncake, mcp, model-context-protocol, no-crypto, pay-per-call, payments, stripe

## 简介

Fiat usage-billing SDK for MCP/APIs. lc.charge() wraps MCP tools, lc.protect() wraps HTTP routes. Buyers pay by card, agents call with spend-capped Pay Tokens, no crypto. MIT-licensed open-core component of LemonCake.
