# @mnemopay/map3d

> 标签: 3d-map, buildings, city-map, digital-twin, glb, mnemopay, openstreetmap, osm, overpass, r3f, react-three-fiber, three, three-js, webgpu

## 简介

Browser-native 3D city map renderer. OSM → buildings + roads → R3F + Three.js → GLB. Drop-in for Dele, Forge, or any React app.
