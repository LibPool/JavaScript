# @josh-dovey/postcodes

> 标签: api-client, boundaries, gb, geocoding, geojson, onspd, postcode, postcodes, reverse-geocoding, uk

## 简介

Typed JavaScript/TypeScript client for the GB Postcodes API — lookup, autocomplete, boundaries, distance, radius, reverse geocode, and ONSPD geography.

## 官网

- 官网：https://postcodes-api.co.uk
- 源码仓库：git+https://github.com/Josh-Dovey/postcodes.git
- npm 页面：https://www.npmjs.com/package/@josh-dovey/postcodes
