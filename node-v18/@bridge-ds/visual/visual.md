# @bridge-ds/visual

> 标签: bridge, design-system, screenshots, visual-regression

## 简介

Bridge visual impact analysis: screenshots the stories and app screens a design system change touches, at the base and head refs, and pixel-diffs them into before/after/diff images and a JSON manifest.
