# @bridge-ds/core

> 标签: bridge, design-system, design-tokens, dtcg, wcag

## 简介

Bridge core: bridge.config.json, DTCG token loading (tiers and layered modes), alias resolution, WCAG contrast, diffs, minimal-diff edits, PR body, the shared risk tier classifier, changesets and a fetch-based GitHub client. No Figma API, no DOM; Node-onl
