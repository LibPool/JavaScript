# @redbuck/h5-handler

> 标签: JavaScript

## 简介

一个用于辅助`miniprogram-automator`的web操作库。   解决了小程序自动化测试中，无法操作小程序内嵌h5页面的问题。   基于websocket，在测试用例中，创建服务端。   在待测试的h5页面，引入客户端。
