# @solar_tiger/toggle-dropdown-menu

> 标签: The Odin Project, dropdown, experiment, learning

## 简介

Add dropdown toggle functionality to all dropdown menus that share a class name. This is intended for eeducational and learning purposes and may contain errors (Part of The Odin Project: Dynamic User Interface Practice)
