# @newbis/cloud-contracts

> 标签: JavaScript

## 简介

Client-facing protocol for the newbis-cloud platform: zod wire schemas + LP signing byte layout + stateless Ed25519 helpers (account, billing, entitlement, trial). One source of truth shared by the cloud and every client (daemon/web/React Native).
