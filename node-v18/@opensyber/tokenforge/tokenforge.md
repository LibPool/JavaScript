# @opensyber/tokenforge

> 标签: anti-session-hijacking, cisco-duo-alternative, cookie-theft-protection, dbsc, device-binding, ecdsa, session-management, session-security, tokenforge, trust-score, web-crypto

## 简介

Device-bound session security — W3C DBSC + ECDSA P-256 signatures + AitM detection. Drop-in for Auth0 / Okta / Clerk / Entra ID.
