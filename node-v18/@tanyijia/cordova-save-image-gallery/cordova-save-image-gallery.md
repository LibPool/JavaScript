# @tanyijia/cordova-save-image-gallery

> 标签: base64, cordova-android, cordova-ios, cordova-wp8, ecosystem:cordova, gallery, image, jpg, photo library, png, save

## 简介

Cordova plugin to save base64 data as a png/jpg image into the device and applying compression if needed
