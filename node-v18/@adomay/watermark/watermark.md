# @adomay/watermark

> 标签: canvas, ffmpeg, image, marca-de-agua, remove-watermark, text-watermark, tile-watermark, video, watermark

## 简介

Un modulo simple en JavaScript puro para agregar/quitar marcas de agua a imágenes/videos usando ffmpeg nativo y canvas.
