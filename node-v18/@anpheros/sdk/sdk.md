# @anpheros/sdk

> 标签: anpheros, api-client, fhir, healthcare, hl7, interoperability, medical, medical-data, oauth, patient-records, smart-on-fhir

## 简介

TypeScript client for Anpheros Platform, interoperable medical-data infrastructure: HL7 FHIR R4 records, patient consent (OAuth 2.1 / SMART on FHIR), provenance and an AI context API.
