# @atak-reactive/cli

> 标签: android, android-team-awareness-kit, atak, atak-plugin, cli, hot-reload, react, scaffolding, tak, typescript, vite

## 简介

CLI to scaffold and run React + TypeScript UIs inside ATAK (Android Team Awareness Kit) plugins, with hot reload for development and bundled builds for release.
