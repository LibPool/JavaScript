# @mashthekeys/response-console

> 标签: buffer, console, logging, middleware, response, server

## 简介

Adds a buffered console object onto a Response object, which outputs to its parent console when the response finishes. Comes with middleware for server logging by request. Intended to help logs remain coherent in high-concurrency applications.
