# @kinnet/discovery-client

> 标签: directory, discovery, kinnet, publish, rfc9421

## 简介

Client for a Kinnet discovery service: build the two self-records, publish key logs, profiles, nodes, claims, relationships and revocations as doubly-signed writes (spec 004), and read the public directory back.
