# @kinnet/verify

> 标签: agent-verification, express, kinnet, middleware, rfc9421

## 简介

Inbound-request verification for services receiving agent traffic: verify an RFC 9421 HTTP Message Signature and the caller's represents chain in ~5 lines (Node/Express + edge runtimes).
