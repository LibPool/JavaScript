# azure-vm-pricing-mcp

> 标签: azure, azure-vm, cloud-cost, finops, mcp, model-context-protocol, pricing

## 简介

MCP server for Azure VM sizes and prices: find the cheapest VM for your requirements, estimate monthly cost with reservations, compare sizes and regions. Weekly data from cld2day.com.
