# @kitefrost/core

> 标签: core, kitefrost, runtime, sdk

## 简介

Shared runtime core (transport, auth, errors, shared-core resource clients) that every per-pack KiteFrost SDK depends on (PPI-3, D-PPI-SDK-BUNDLING Option A).
