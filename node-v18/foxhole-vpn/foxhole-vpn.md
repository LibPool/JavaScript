# foxhole-vpn

> 标签: cli, firefox, firefox-vpn, free-vpn, http-proxy, ip-protection, linux, macos, mozilla, mozilla-vpn, privacy, proxy, socks5, socks5-proxy, system-wide-vpn, tui, tun, tun2socks, vpn, windows

## 简介

Free system-wide VPN for Linux, macOS and Windows using Firefox's built-in VPN (IP Protection): SOCKS5/HTTP proxy + TUN routing, in a terminal UI (unofficial)
