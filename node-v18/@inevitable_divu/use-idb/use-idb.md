# @inevitable_divu/use-idb

> 标签: aes-gcm, broadcast-channel, cache, concurrent-react, crypto, hooks, indexeddb, local-first, offline-first, react, react-19, state-management, storage, suspense, typescript, zero-dependency

## 简介

Zero-dependency, high-performance IndexedDB reactive state engine for React 19 & TypeScript. Features microtask write coalescing, AES-GCM (NIST AAD) encryption, cross-tab synchronization, and full Suspense support.
