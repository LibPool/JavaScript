# @diegesis/canvas-plugin-grid

> 标签: canvas, diegesis, grid, plugin, tabletop, vtt

## 简介

Grid plugin for @diegesis/canvas — renders the scene grid (square, hex, isometric) and contributes grid configuration via context menu.
