# @chaotic1988/pi-todo

> 标签: pi-package

## 简介

A [pi](https://github.com/mariozechner/pi) extension that gives the LLM persistent, file-based todo tracking. Create, update, list, and delete todos that survive across sessions, terminal windows, and reboots.
