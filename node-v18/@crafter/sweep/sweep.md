# @crafter/sweep

> 标签: cache, cleanup, cli, devtools, disk-space, monorepo, next, node_modules, reclaim, venv

## 简介

Recursively find and delete regenerable dev artifacts (node_modules, .next, .venv, dist, caches) to reclaim disk space.
