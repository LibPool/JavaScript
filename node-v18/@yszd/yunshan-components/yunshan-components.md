# @yszd/yunshan-components

> 标签: activity, components, miniprogram, shop, weapp, wechat, yszd, yunshan

## 简介

原生微信小程序 npm 业务组件包：商城业务（shop）与活动业务（activity）双业务线，按需引入，主项目通过 init 注入身份与请求能力。
