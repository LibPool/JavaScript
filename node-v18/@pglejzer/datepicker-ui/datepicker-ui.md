# @pglejzer/datepicker-ui

> 标签: angular, calendar, css, customizable, date-picker, date-selection, datepicker, design, javascript, lightweight, material, material-design, react, svelte, themeable, typescript, ui, vanillajs, vue

## 简介

datepicker-ui is a customizable date selection library built with TypeScript, designed to work seamlessly alongside timepicker-ui. Based on Google's Material Design, lightweight, themeable, and framework agnostic.
