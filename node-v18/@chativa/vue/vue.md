# @chativa/vue

> 标签: chat, chativa, nuxt, vue, vue3, web-component, wrapper

## 简介

Chativa Vue 3 — typed Vue components (ChatIva, ChatBotButton, GenUIMessage), a ChativaPlugin and composables wrapping the Chativa chat widget for Vue 3 / Nuxt 3 apps.
