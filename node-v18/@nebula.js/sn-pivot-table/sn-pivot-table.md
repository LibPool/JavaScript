# @nebula.js/sn-pivot-table

> 标签: nebula, qlik, stardust

## 简介

Display dimensions and measures as rows and columns in a table. Analyze data by multiple measures and in multiple dimensions at the same time. Use pivoting (rearranging the measures and dimensions) to get different views of the data.
