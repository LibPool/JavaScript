> 标签: ai, analytics, apple-podcasts, claude, mcp, model-context-protocol, podcast, reporter

## 简介

MCP server for Apple Podcasts Connect owner analytics via the Reporter protocol — plays, followers, and per-episode listening. Not the public iTunes catalog.
