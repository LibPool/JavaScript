# @workerdeck/ui

> 标签: agent, anthropic, claude, claude-code, components, react, tailwind, ui

## 简介

Styled agent-control component library for WorkerDeck: session panel, transcript with streaming, tool-call cards, permission prompts, session list, composer. Tailwind v4 + Base UI + cva. Pairs with the headless @workerdeck/react layer.
