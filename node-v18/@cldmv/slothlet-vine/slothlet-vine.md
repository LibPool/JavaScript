# @cldmv/slothlet-vine

> 标签: channel, forwarding, isolation, postmessage, proxy, rpc, slothlet, transport, web-worker, worker_threads

## 简介

Vines between slothlet api trees — location-transparent forwarding leaves over pluggable transports (Web Worker postMessage, worker_threads, process IPC, WebSocket), permission-gated by slothlet itself.
