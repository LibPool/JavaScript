# @cldmv/slothlet-i18n

> 标签: i18n, internationalization, l10n, languages, locale, localization, slothlet, translations

## 简介

Additional locale packs for @cldmv/slothlet — install alongside it to enable non-English error and warning messages. Slothlet auto-detects this package; you should not import it directly.
