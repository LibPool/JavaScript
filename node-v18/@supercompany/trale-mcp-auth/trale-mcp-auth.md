# @supercompany/trale-mcp-auth

> 标签: claude-agent-sdk, mcp, model-context-protocol, oauth, trale

## 简介

OAuth helper for Trale MCP — authorize once in your browser, then use it from Claude Agent SDK or any programmatic MCP client without daily re-auth.
