# @davindermahal/confluence-client

> 标签: JavaScript

## 简介

Shared Confluence Cloud transport: auth/config resolution, an HTTP client with retry/backoff, URL-to-page-ID parsing, and storage-format conversion. Transport only -- no product-specific policy.
