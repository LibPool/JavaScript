# @cybermu22/officebot

> 标签: agents, claude, claude-code, dashboard, hooks, observability, visualization

## 简介

A live pixel-art 'office' dashboard for your Claude Code sessions — watch your agents work, delegate, and clock out, with usage tracking. Zero dependencies, fully local. Not affiliated with, endorsed, or sponsored by Anthropic.
