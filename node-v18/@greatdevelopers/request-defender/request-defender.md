# @greatdevelopers/request-defender

> 标签: honeypot, ip-blocking, rate-limit, security, sveltekit

## 简介

SvelteKit handle that bans abusive IPs: honeypot paths, unknown-subdomain probing, route scanning, and file-backed IP / domain allow- and block-lists shared with GreatDevelopers.RequestDefender and GreatDevelopers.ApiDefender.
