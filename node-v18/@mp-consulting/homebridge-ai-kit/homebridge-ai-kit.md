# @mp-consulting/homebridge-ai-kit

> 标签: ai, anthropic, claude, homebridge, homebridge-plugin, homekit, llm, mcp, model-context-protocol, smart-home

## 简介

AI toolkit for Homebridge — an MCP server that lets AI assistants control accessories, manage plugins and monitor Homebridge, plus the shared AI building blocks used by Homebridge Glass UI and MP Consulting plugins.
