# @lotse/session

> 标签: acp, coding-agent, session

## 简介

What a lotse session IS: the record, the transcript, and the resume binding. Pure model plus a filesystem store — no ACP client, no agent adapter, no gi://. The store takes a path, so a test writes to a temp dir and the app writes to XDG.
