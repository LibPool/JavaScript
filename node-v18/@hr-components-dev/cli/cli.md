# @hr-components-dev/cli

> 标签: amis, cli, hr, hr-components-dev, hrisv, 淮然科技

## 简介

本项目是江西淮然科技有限公司专门开发的组件化脚手架工具，旨在提升前端开发效率，统一组件开发规范，并支持组件加密保护功能。
