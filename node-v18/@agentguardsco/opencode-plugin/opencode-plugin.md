# @agentguardsco/opencode-plugin

> 标签: guardrails, jailbreak-detection, llm-security, mcp, opencode, opencode-plugin, prompt-injection

## 简介

LLM security guardrails for OpenCode — jailbreak detection, prompt-injection and web-content scanning, and destructive-command authorization. Bundles enforcing hooks plus the AgentGuards MCP server.
