# @agentguardsco/claude-plugin

> 标签: claude-code, claude-code-plugin, guardrails, jailbreak-detection, llm-security, prompt-injection

## 简介

LLM security guardrails for Claude Code — jailbreak detection, prompt-injection and web-content scanning, data-exfiltration blocking, and destructive-command authorization. Enforced by hooks on every prompt, shell command, fetched page and file write.
