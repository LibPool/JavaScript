# @snowballmoney/metamask-snap

> 标签: JavaScript

## 简介

Modular Naming Service Snap is a fantastic addition to the MetaMask wallet, making it super easy to connect with MNS identities. With this feature, you can effortlessly send and receive assets using just an MNS identity name, streamlining your transaction
