# @ripast/core

> 标签: ai-agent, ast, claude-code, codemod, cursor, refactor, rename, ripgrep, tailwind, ts-morph, typescript

## 简介

AST refactor engine for AI coding agents. Deterministic rename, move, find-usages, and tailwind/CSS class migration across TypeScript. Framework adapters loaded via @ripast/<framework> packages.
