# @ripast/cli

> 标签: ast, cli, codemod, refactor, rename, ripast

## 简介

CLI for ripast. Deterministic AST refactors (rename, move, find-usages, tailwind/CSS class migration) for TypeScript and frontend frameworks. Auto-installs framework adapters as needed.
