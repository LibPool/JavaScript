# dsh-tidy-display

> 标签: accessibility, conversation, deepseek-harness, dsh, dsh-plugin, dshx, reasoning, streaming

## 简介

One plugin for a calmer DeepSeek Harness: reading view + message rail + smart history loading, for Harness 0.1.0-0.2.1 (all rc).
