# @novice1-react/react-router-paneling

> 标签: novice1, novice1-react, react, react-router, react-router-paneling

## 简介

A library for that turns each segment of a URL path into a panel. Stack multiple panels by simply navigating to deeper paths, each segment mapping to a panel component.
