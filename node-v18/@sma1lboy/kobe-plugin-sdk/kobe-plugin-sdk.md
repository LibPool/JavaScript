# @sma1lboy/kobe-plugin-sdk

> 标签: JavaScript

## 简介

Typed SDK for writing Rove plugins — env context, event types, daemon socket client, CLI helpers, and a tiny pane kit. Optional sugar over the plain env+CLI+socket contract.
