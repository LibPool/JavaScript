# @zhujiuyi/dsh-balance

> 标签: balance, billing, deepseek-harness, dsh, dsh-plugin, gateway, provider, quota

## 简介

DeepSeek Harness plugin: identify the provider behind the current route and query its API balance or subscription quota. No subprocesses, no exec permissions, official endpoints only.
