# @interdatalink/poe-budget

> 标签: 802.3af, 802.3at, 802.3bt, cli, network, networking, poe, poe-budget, power-over-ethernet, switch, upoe

## 简介

Check whether a set of PoE devices fits a switch's power budget and per-port limit. Command-line tool and library, zero dependencies.
