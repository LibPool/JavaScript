> 标签: audit, bloat, bundle-size, cli, dependencies, install-scripts, node_modules, npm, security, supply-chain

## 简介

Should I install this? Audit any npm package — or your whole project — before you install: real (npm-accurate) dependency count, disk, maintainers you'd trust, stale deps, and the literal install scripts that run code on your machine.
