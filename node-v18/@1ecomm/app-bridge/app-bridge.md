# @1ecomm/app-bridge

> 标签: 1ecomm, app-bridge, ecommerce, embedded-app, sdk

## 简介

Framework-agnostic client SDK a 1ecomm app imports to talk to the platform host (App Bridge protocol): signed context, session tokens, scope-enforced API access, resize/toast/modal/navigate.
