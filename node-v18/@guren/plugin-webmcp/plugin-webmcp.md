# @guren/plugin-webmcp

> 标签: ai-agents, bun, framework, fullstack, guren, mcp, typescript, webmcp

## 简介

Experimental WebMCP client for Guren: registers an app's agent tools on the browser's modelContext API (RFC 0016 Phase 3). The WebMCP specification is a W3C Community Group draft and its API churns.
