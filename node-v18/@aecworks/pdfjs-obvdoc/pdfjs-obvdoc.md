# @aecworks/pdfjs-obvdoc

> 标签: JavaScript

## 简介

OBVDoc 采用了 pdf.js 来展示 doc 类型的文件。基于 pdf.js 官方的 viewer.js 进行定制。 该仓库fork了github上的官方仓库：[pdf.js@github](https://github.com/mozilla/pdf.js)。 会定期的对官方的修改进行同步，解决重大的bug和功能的升级。
