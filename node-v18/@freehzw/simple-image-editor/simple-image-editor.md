# @freehzw/simple-image-editor

> 标签: JavaScript

## 简介

Fork自[vue-image-annotation](https://github.com/wawjqyh/vue-image-annotation), 基于`fabric.js`, 支持vue3，增加了裁切图片，取色器，滚轮缩放等功能。已升级到 fabric.js v7版本。
