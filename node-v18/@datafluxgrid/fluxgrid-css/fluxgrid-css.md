# @datafluxgrid/fluxgrid-css

> 标签: animations, atomic-css, bootstrap-alternative, css, css-framework, css-grid, css-utilities, css-variables, dark-mode, datafluxgrid, design-system, design-tokens, flexbox, fluxgrid, forms, frontend, lightweight-css, no-build, no-postcss, pure-css, responsive-design, tailwind-alternative, utility-css, utility-first, vanilla-css, zero-config

## 简介

Utility-first CSS framework with zero build step. No CLI, no PostCSS, no config — just drop in one CSS file and use utility classes. Includes dark mode, design tokens, animations, and form styles built in.
