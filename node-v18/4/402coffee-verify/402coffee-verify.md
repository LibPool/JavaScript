# 402coffee-verify

> 标签: 402.coffee, agent, base, conformance, payments, trust, usdc, verification, x402

## 简介

Gate payments on verified x402 agents. One free call to 402.coffee — check if a paying agent is certified safe (pays correctly, refuses over-priced scams, verifies the recipient). Zero dependencies.
