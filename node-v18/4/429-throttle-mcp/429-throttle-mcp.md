# 429-throttle-mcp

> 标签: 429, api-proxy, mcp, rate-limit, throttle, token-bucket

## 简介

带速率限制的 MCP 代理：模型长程任务自动控速不再 429；配套 rate-limit-operator 技能，非技术用户一句话完成打开/调参/关闭/复盘
