# 4brains-storage

> 标签: esm, garage, nas, object-storage, s3, self-hosted, sigv4, storage, zero-dependency

## 简介

Zero-dependency S3-compatible storage client for Garage. No aws-sdk — SigV4 signing and HTTP with Node built-ins only.
