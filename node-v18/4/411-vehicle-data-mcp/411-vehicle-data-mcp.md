# 411-vehicle-data-mcp

> 标签: ai-tools, automotive, claude, mcp, towing-capacity, vehicle-data

## 简介

MCP Server for 411 Vehicle Data API - 12 tools covering towing, bolt patterns, tires, oil, horsepower, wipers, battery, bulbs, and VIN decode. 98,363 records across 8 datasets.
