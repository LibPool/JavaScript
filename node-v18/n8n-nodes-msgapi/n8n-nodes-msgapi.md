# n8n-nodes-msgapi

> 标签: msg.api, n8n-community-node-package, whatsapp, whatsapp-api

## 简介

Envie e receba mensagens de WhatsApp no n8n com o msg.api: texto, mídia, enquetes, grupos e gatilho de mensagem recebida.
