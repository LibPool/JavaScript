# android-cleanup-agent

> 标签: adb, ai-agent, android, android-tv, bloatware, claude, claude-code, cleanup, cli, debloat, google-tv, no-root, performance, plugin, uninstall-system-apps, wireless-debugging

## 简介

Clean up and speed up an Android phone, tablet or TV over adb, without root: audit, explain, approve, apply, results. Every change is logged and reversible. A CLI and Claude Code plugin.
