# @silicon.js/map

> 标签: coordinates, geolocation, google-maps, gps, location, map-integration, map-provider, map-view, markers, mobile-maps, react-native, react-native-library, react-native-maps

## 简介

A React Native map management package built on top of `react-native-maps` for Expo with a powerful provider-based architecture for managing regions, markers, and selections.
