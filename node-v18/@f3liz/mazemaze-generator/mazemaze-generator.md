# @f3liz/mazemaze-generator

> 标签: JavaScript

## 简介

Generate a typed API client from an OpenAPI spec or a GraphQL schema as one Melange runtime with three natural surfaces — Melange, ReScript, and TypeScript (via JSDoc).
