# @aurigax-ai/ghostty-web

> 标签: ansi, ghostty, terminal, terminal-emulator, tty, vt100, wasm, web, webassembly, xterm

## 简介

Ghostty's terminal engine (libghostty-vt) in the browser: WebAssembly build, an xterm.js-shaped API and WebGL and canvas renderers. A hard fork of coder/ghostty-web.
