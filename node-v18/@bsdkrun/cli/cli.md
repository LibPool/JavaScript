# @bsdkrun/cli

> 标签: bsdkrun, cli, firecracker, freebsd, libkrun, microvm, netbsd, sandbox, vm

## 简介

Firecracker-style microVM launcher for BSD, Linux (OCI), and unikernel guests, built on libkrun. Installs the prebuilt bsdkrun host binary for your platform.
