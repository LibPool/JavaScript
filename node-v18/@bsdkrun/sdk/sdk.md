# @bsdkrun/sdk

> 标签: bsdkrun, freebsd, libkrun, microvm, netbsd, sandbox, vm

## 简介

TypeScript SDK for bsdkrun — boot and drive BSD/Linux/unikernel microVMs programmatically, à la Vercel/Deno Sandbox.
