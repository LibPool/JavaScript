# @freva-org/jupyterlite-freva-data

> 标签: dataset-tree, freva, jupyter, jupyterlab-extension, jupyterlite

## 简介

A site data panel for JupyterLite and JupyterLab: browse a Freva portal's dataset tree, open registered Python access examples in a notebook, insert them, inspect stores, and ask ClimateClaw.
