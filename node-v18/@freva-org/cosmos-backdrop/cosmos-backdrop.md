# @freva-org/cosmos-backdrop

> 标签: JavaScript

## 简介

The Cosmos backdrop: a still cross-section of an observing system, from orbit to the ocean floor, drawn behind a landing page and redrawn for the page's theme. Framework-free; the scene loads only on a page that has a .portal-cosmos element.
