# @freva-org/jupyterlite-freva-kernel

> 标签: jupyter, jupyterlab-extension, jupyterlite, jupyterlite-kernel

## 简介

The "Freva Python" kernel for JupyterLite: a prebuilt extension that runs notebook cells in @freva-org/browser-python, with sanitised rich output.
