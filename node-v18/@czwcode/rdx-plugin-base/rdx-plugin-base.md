# @czwcode/rdx-plugin-base

> 标签: JavaScript

## 简介

- 通过提供组件的任务流管理器，定向更新组件内容 - 减少重复渲染 - 避免任务重复执行 - 避免由于请求返回时间的不确定性，导致展示数据出现问题 - 记录所有当前节点的运行状态，避免用户进行过多无用的操作
