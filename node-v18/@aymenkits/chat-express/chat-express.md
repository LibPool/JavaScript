# @aymenkits/chat-express

> 标签: chat, express, messaging, realtime, socket.io, threads

## 简介

Express 4/5 handlers for the chat REST endpoints: list threads (with unread counts), history, send, mark read, unread total. Structural req/res typing, envelope-agnostic, auth-agnostic (getUserId seam).
