# @zoanlogia/spec-guard

> 标签: jest, openspec, spec-driven, test-coverage, traceability, vitest

## 简介

Deterministically check which OpenSpec scenarios are covered by a Vitest or Jest test. Never runs the tests, never calls an LLM.
