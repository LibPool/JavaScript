# @mxf-dev/dashboard

> 标签: dashboard, mxf, ui, vue

## 简介

MXF Framework Dashboard — Vue 3 + Vuetify web UI. Run it against any MXF server with `npx @mxf-dev/dashboard --api-url <server>`.
