# @openprx/openproxy

> 标签: ai, claude, cli, codex, cursor, llm, openai, proxy, router

## 简介

OpenProxy — single-binary AI router with embedded web dashboard. Routes Claude Code, Codex, Cursor, Cline, and other AI CLI tools to 40+ providers with auto-fallback and quota tracking.
