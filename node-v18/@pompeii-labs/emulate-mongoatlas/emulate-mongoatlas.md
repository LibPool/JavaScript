# @pompeii-labs/emulate-mongoatlas

> 标签: JavaScript

## 简介

MongoDB Atlas emulation with Atlas Admin API v2 and Atlas Data API v1 for local development and testing. In-memory document storage with CRUD, filtering, and aggregation.
