# @takazudo/zudo-doc

> 标签: documentation, framework, mdx, preact, zfb, zudo-doc

## 简介

zudo-doc framework primitives layer that sits on top of zfb's engine — sidebar, theme, TOC, breadcrumb, layouts, head injection, View Transitions, SSR-skip wrappers (per ADR-003).
