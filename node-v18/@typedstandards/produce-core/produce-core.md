# @typedstandards/produce-core

> 标签: browser, ed25519, jcs, producer, provenance, record-package, rekor, rfc3161, rfc8785, typed-standards

## 简介

Portable, I/O-free producer core for Typed Standards record packages — format-neutral envelope and attestation assembly, the Ed25519ph signing mechanism, and pure external-proof codecs, sharing one canonicalization/hash chain with @typedstandards/verify-c
