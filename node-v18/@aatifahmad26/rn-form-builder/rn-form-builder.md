# @aatifahmad26/rn-form-builder

> 标签: config-driven, dynamic-form, form, form-builder, input, react-native, validation

## 简介

Config-driven, validated forms for React Native. Describe your fields as a plain array of objects (title, type, max length, options, etc.) and render a complete, validated form.
