# @vladlearns/cy-scrolltoby

> 标签: auto-scrolling, cy, cy-scrolltoby, cypress

## 简介

Cypress custom command "cy.scrollToBy" for iterative scrolling in e2e tests. Scroll to a place on the page by some distance
