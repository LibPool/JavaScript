# @amj7/tailwindcss-px-to-nativescript-dpi

> 标签: nativescript, px to ns-dpi unit, tailwind, tailwindcss

## 简介

A Tailwind CSS plugin automatically converts all PX units to just integers without units in your Tailwind styles. NativeScript projects see unit-less values as DPI units.
