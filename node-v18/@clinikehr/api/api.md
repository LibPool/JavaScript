# @clinikehr/api

> 标签: clinical-data, clinikehr, ehr, fhir, healthcare, hipaa, openapi, sdk

## 简介

Server-side TypeScript SDK for the ClinikEHR API (api.clinikehr.com): typed paths generated from the OpenAPI document, retries, idempotency keys, cursor pagination and webhook verification.
