# @orchestral/agent

> 标签: agent-pattern, agents, ai, media-pipeline, multimodal, orchestral-pattern, orchestration, typescript

## 简介

Orchestral agent support — the first-party AgentPattern (the media orchestrator). Ships no agent loop and no provider SDK: the AgentRunImpl driving the loop is injected by the host. Optional extension; nothing in core/runtime/patterns depends on it.
