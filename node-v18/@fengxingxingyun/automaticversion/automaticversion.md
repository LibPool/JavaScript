# @fengxingxingyun/automaticversion

> 标签: auto-version, react, version, vite-plugin, vue, webpack-plugin

## 简介

一个兼容 Webpack / Vite（及 Vue / React 等框架）的自动版本写入插件，打包后生成 version.json 并复制 verifyVersion.js 到产物目录。
