# @opentagcloud/react

> 标签: component, nextjs, react, tag-cloud, tagcloud, word-cloud, wordcloud

## 简介

React adapter for openTagCloud — a dependency-free, self-packing, SSR-friendly tag cloud. Works in Next.js (ships 'use client').
