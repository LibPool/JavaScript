# @newgo/scale-frame

> 标签: JavaScript

## 简介

디자인 기준 폭(designWidth) 기반 레이아웃을 만들되, - `viewport >= designWidth` 에서는 부모 너비를 그대로 사용하고 - `viewport < designWidth` 에서만 기준 폭을 유지한 채 통축소(scale)하는 React 컴포넌트/훅.
