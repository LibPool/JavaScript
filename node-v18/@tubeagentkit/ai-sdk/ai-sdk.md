# @tubeagentkit/ai-sdk

> 标签: agents, ai, ai-sdk, captions, llm, mastra, subtitles, tools, transcript, vercel-ai-sdk, youtube, youtube-search, youtube-transcript, youtube-transcripts

## 简介

YouTube transcript tools for the Vercel AI SDK and Mastra: get YouTube video transcripts with timestamps, search YouTube, and list channel videos, via the GetYouTubeTranscript API.
