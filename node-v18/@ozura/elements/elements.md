# @ozura/elements

> 标签: card, iframe, ozura, pci, pci-dss, saq-a, tokenization, vault

## 简介

PCI-compliant card tokenization SDK for the Ozura Vault — collect card data in iframe-isolated fields and tokenize without PCI scope
