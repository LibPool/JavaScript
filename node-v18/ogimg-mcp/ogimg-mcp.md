# ogimg-mcp

> 标签: claude-code, codex, cursor, gemini-cli, mcp, model-context-protocol, og-image, ogimg, open-graph, social-preview

## 简介

MCP server exposing OGImg's dynamic Open Graph image API as a tool for any MCP-capable AI agent or editor (Claude Code, Cursor, Windsurf, VS Code, Codex CLI, Gemini CLI).
