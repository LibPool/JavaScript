# @muoceon/device-id

> 标签: adapter-pattern, browser-fingerprint, canvas-fingerprint, cross-platform, device-fingerprint, device-id, machine-id, nodejs, react-native, webgl

## 简介

Cross-platform device fingerprinting with adapter pattern — browser (canvas/WebGL/fonts), Node.js (machine-id/CPU/MAC), React Native. Stable, cacheable, change-detection ready.
