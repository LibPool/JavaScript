# @hnuguse/yamlw

> 标签: Build, JSON, VSTS, YAML

## 简介

A task to output YAML or JSON. Take build variables and write them to the build directory. Updates existing files or create them from scratch. Forked from https://github.com/jakkaj/yamlw, and adjusted to support loading external files with settings.
