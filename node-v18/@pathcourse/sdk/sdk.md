# @pathcourse/sdk

> 标签: a2a, agent-identity, agent-memory, agent-payment, agents, ai, autonomous-agent, base-l2, cert-registry, gateway, llm, llm-inference, multi-agent, path-score, pathcourse, usdc, x402

## 简介

Official JavaScript SDK for the PCH AI gateway. Autonomous API key provisioning, pay-per-inference billing in USDC on Base L2, and agent certification—no human signup required.
