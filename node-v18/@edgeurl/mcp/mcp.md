# @edgeurl/mcp

> 标签: ai-agent, anthropic, claude, edgeurl, json-rpc, mcp, model-context-protocol, stdio

## 简介

stdio MCP wrapper for the EdgeURL remote MCP server. Connects Claude Desktop, Cursor, Continue, and any stdio-only MCP client to mcp.edgeurl.io.
