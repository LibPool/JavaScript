# @snapserv/release-it-upstream-version

> 标签: bump, pattern, plugin, regex, regexp, regular expression, release-it, release-it-plugin, revision, upstream, version

## 简介

Version plugin for release-it which extracts an upstream version from a file using RegExp and appends an increasing revision as pre-release
