# vue-konva

> 标签: JavaScript

## 简介

Vue components for the Konva 2d canvas library. Build interactive graphics, design editors, and whiteboards in Vue.

## 官网

- 官网：https://konvajs.org/docs/vue/index.html
- 源码仓库：git+https://github.com/konvajs/vue-konva.git
