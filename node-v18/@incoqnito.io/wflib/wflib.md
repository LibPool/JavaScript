# @incoqnito.io/wflib

> 标签: JavaScript

## 简介

`@incoqnito.io/wflib` ist eine TypeScript-Bibliothek für Workflow-/Prozessmodellierung und -ausführung im Stil von BPMN 2.0 — Typmodell, struktureller Validator und eine Ausführungs-Engine.
