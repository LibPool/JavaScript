# @webority/mobile-chat

> 标签: ai, assistant, chat, react-native, streaming, webority

## 简介

AI assistant chat for Webority React Native apps: a streaming chat client, a store-agnostic chat hook, and the chat screen, thread, composer, past chats, reply rating and support action cards, built on @webority/mobile-ui.
