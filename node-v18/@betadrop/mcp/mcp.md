> 标签: ai, android, apk, betadrop, build-distribution, claude, copilot, cursor, ios, ipa, llm, mcp, model-context-protocol

## 简介

Model Context Protocol (MCP) server for BetaDrop. Lets AI assistants publish iOS/Android builds, manage tokens, and list build history — directly from your IDE.
