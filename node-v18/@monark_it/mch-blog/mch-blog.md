# @monark_it/mch-blog

> 标签: JavaScript

## 简介

Runtime de blog pour les sites Monark : liste, article, RSS, sitemap, SEO, thème et revalidation. Tout le contenu vient de la **release publiée par le Monark Content Hub** — aucun fichier Markdown local, aucune base de données côté site.
