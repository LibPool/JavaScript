# @tangzai/dsh-ui-archive-manager

> 标签: archive, archived sessions, deepseek harness, deepseek-harness, dsh, plugin, settings, ui, unarchive, 归档

## 简介

Beautified archive manager for DeepSeek Harness (dsh): a settings section listing archived sessions grouped by workspace, each with an unarchive action, with a flat session list, folder group headers, relative timestamps and hover unarchive buttons.
