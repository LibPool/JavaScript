# @a2aregistry/validate

> 标签: a2a, agent-card, ai-agents, cli, linux-foundation, offline, validator

## 简介

CLI and library validator for Agent-to-Agent (A2A) Protocol v1.0 agent cards. Pure protocol compliance — no registry-specific logic. Runs fully offline.
