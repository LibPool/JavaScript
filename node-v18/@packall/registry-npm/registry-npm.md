# @packall/registry-npm

> 标签: artifactory, effect, github-packages, gitlab, nexus, npm, npmrc, pnpm, registry, verdaccio

## 简介

npm-protocol registry backend for @packall/core, with .npmrc parsing, credentials and retries.
