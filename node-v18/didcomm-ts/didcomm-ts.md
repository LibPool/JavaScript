# didcomm-ts

> 标签: decentralized-identity, did, did-peer, didcomm, mediator, ssi, verifiable-credentials

## 简介

Independent DIDComm v2 implementation in TypeScript: authcrypt/anoncrypt/signed messages, routing, mediation and pickup, interop-tested against didcomm-rust and didcomm-python
