# @lexholden/visuoso

> 标签: jest, regression, testing, visual

## 简介

Visuoso is a basic library that combines several exisiting tools for visual regression testing (puppeteer, jsdom-screenshot) but wraps them in an optional docker wrapper, where the actual generation of the screenshot can be delegated to a docker container
