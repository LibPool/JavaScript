# @onesmall/ui

> 标签: accessibility, components, dark-mode, design-system, drag-and-drop, dropzone, react, scss, typescript, ui, wcag

## 简介

OneSmallUI (1SmUI): a futuristic, WCAG AAA accessible React + TypeScript + SCSS component library with light/dark themes, utilities, drag and drop, and upload drop zones.
