# @jamesalmeida/agent-avatars

> 标签: agent, ai, animation, assistant, avatar, chatbot, react

## 简介

An animated face for your AI agent: a squishy shape with two eyes that blinks, listens, thinks, writes, smiles and spins. React, zero dependencies.
