# @nitgrid/core

> 标签: data-grid, datagrid, grid-engine, nitgrid

## 简介

NitGrid Community engine — the private, framework-agnostic data-grid core bundled by @nitgrid/react and @nitgrid/angular. Not intended for direct use.
