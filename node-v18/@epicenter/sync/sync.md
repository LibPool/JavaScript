# @epicenter/sync

> 标签: CRDT, WebSocket, Yjs, epicenter, local-first, offline-first, real-time, sync

## 简介

Sync protocol for Epicenter workspaces. Yjs-based encoding, WebSocket transport, and broadcast channel sync.
