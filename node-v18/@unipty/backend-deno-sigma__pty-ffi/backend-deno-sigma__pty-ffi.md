# @unipty/backend-deno-sigma__pty-ffi

> 标签: JavaScript

## 简介

Official UniPty Backend adapting the third-party @sigma/pty-ffi (Rust portable-pty) substrate for Deno; self-contained npm package with vendored noinit closure and target dynamic libraries.
