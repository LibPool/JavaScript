# @ray-js/wechat-bluetooth-sdk

> 标签: JavaScript

## 简介

微信小程序面向开发者封装的业务蓝牙包，目前支持 蓝牙 LE 、 蓝牙 LE + Beacon 、Tuya Beacon 设备的本地连接控制，及蓝牙通道入网
