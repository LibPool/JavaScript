# @theopenweb/rubifyer

> 标签: japanese, ruby, ルビ, ルビー, 送り仮名

## 简介

Simple library for rubifying(Add ruby characters/tags) the page. Goal is to simply get mapped ruby characters from API and display for words in current page.
