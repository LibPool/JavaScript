# sse-wire

> 标签: ai, anthropic, eventsource, fetch, llm, openai, post, reconnect, server-sent-events, sse, stream, streaming, typescript

## 简介

Zero-dependency, fetch-based Server-Sent Events client for LLM streams — POST, custom headers, AbortSignal, and reconnection, in Node and the browser. The POST + headers EventSource can't do.
