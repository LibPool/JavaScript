# dsh-tableau-twb-viewer

> 标签: data-lineage, deepseek-harness, dsh, dsh-plugin, tableau, twb, visualization, workbook

## 简介

DeepSeek Harness (DSH) plugin — inspect a Tableau workbook (.twb) in the browser: 1:1 SVG dashboard layout, field-level lineage graph, datasource / calculated-field metadata. Read-only metadata; .twbx refused by design.
