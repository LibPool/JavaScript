# @saqif/vue-dicom-canvas

> 标签: dicom, dwv, medical-imaging, vue, vue3

## 简介

A TypeScript-ready Vue 3 DICOM viewer with slice navigation, zoom and window/level controls, drawing annotations, JSON import/export, and a live interactive demo.
