# @unityfreak/mcp-server

> 标签: ai-agents, claude, mcp, model-context-protocol, project-management, unityfreak

## 简介

UnityFreak MCP server: expose your UnityFreak projects, tasks, sprints and documents to Claude Desktop and other MCP clients (stdio, plus an embeddable Express SSE router).
