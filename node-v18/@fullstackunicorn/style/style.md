# @fullstackunicorn/style

> 标签: css, design-system, fullstackunicorn, react-native, responsive-design, scss, style-generator, utilities

## 简介

A development utility for generating responsive web and native styles (CSS, SCSS, JS, RN) from a declarative style.config.js file.
