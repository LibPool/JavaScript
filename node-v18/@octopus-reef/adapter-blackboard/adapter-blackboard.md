# @octopus-reef/adapter-blackboard

> 标签: JavaScript

## 简介

Shared cognition for parallel agents on one Reef session: a blackboard (octopus-blackboard) where agents claim tasks and note progress on a hash-chained timeline, so multi-agent coordination is itself auditable. Not an orchestrator — a shared memory.
