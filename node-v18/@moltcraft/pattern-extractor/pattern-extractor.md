# @moltcraft/pattern-extractor

> 标签: agent, knowledge-base, mcp, pattern-extraction, repo-crawler

## 简介

Extract documentation and patterns from GitHub repos for agent learning. Shallow-clones repos, reads key files (README, CLAUDE.md, AGENTS.md, etc.), and returns structured content.
