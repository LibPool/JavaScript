# @frontpanel/vue

> 标签: components, design-system, reka-ui, skeuomorphic, ui-kit, vue, vue3, y2k

## 简介

Vue 3 components for the Frontpanel early-2000s hardware skin: a scale-to-fit device frame, windows, chrome and gel buttons, caps, LCDs and LEDs, built on Reka UI.
