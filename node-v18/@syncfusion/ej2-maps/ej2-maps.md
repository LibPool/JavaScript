> 标签: OSM, azure maps, bing maps, bubble, cluster, color-mapping, custom-shapes, data-label, ej2, ej2-maps, feature-collection, geoJSON, geometry-collection, google maps, javascript, layer, linestring, maps, marker, multilinestring, multipoint, multipolygon, navigation-line, openstreetmap, pan, point, polygon, projection, shapes, sublayer, syncfusion, typescript, web-components, zoom

## 简介

The Maps component is used to visualize the geographical data and represent the statistical data of a particular geographical area on earth with user interactivity, and provides various customizing options
