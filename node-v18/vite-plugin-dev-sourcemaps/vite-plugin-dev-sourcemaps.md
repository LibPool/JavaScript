# vite-plugin-dev-sourcemaps

> 标签: dev-server, devtools, source-map, sourcemap, vite, vite-plugin, vitejs-vite-23549

## 简介

Externalize Vite dev-server inline source maps into separate .map responses to avoid Chrome/Edge DevTools freezes (vitejs/vite#23549).
