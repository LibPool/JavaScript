# dsh-plugin-relvato

> 标签: deepseek-harness, dsh-plugin, mcp, relvato, uptime, website-monitoring, wordpress

## 简介

Relvato website monitoring for DeepSeek Harness: adds Relvato's hosted MCP server (58 tools) through dsh-mcp-client, with a Relvato API key.
