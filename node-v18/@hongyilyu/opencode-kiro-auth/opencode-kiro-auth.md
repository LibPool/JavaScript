# @hongyilyu/opencode-kiro-auth

> 标签: amazon-q, aws-sso, codewhisperer, kiro, kiro-cli, opencode, opencode-plugin

## 简介

Use Kiro models in opencode with AWS Builder ID, IAM Identity Center, or Kiro API-key authentication. Includes Claude 5, GPT 5.6, effort variants, and built-in web search.
