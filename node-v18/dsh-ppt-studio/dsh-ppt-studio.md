# dsh-ppt-studio

> 标签: cordis, deck, deepseek-harness, dsh, plugin, powerpoint, ppt, pptx, presentation, slides

## 简介

在 DeepSeek Harness 里做 PPT：说需求 → 逐页制作 → 导出可编辑的 .pptx。含布局检查、Office 真渲染复核，以及可扩展的本地模板库
