# @positive-map/v-components

> 标签: JavaScript

## 简介

- 在 src/components 下新建组件文件夹，并在 src/components/index.ts 中导出 - 在 src/index.ts 中导出组件 - 在 docs/.vuepress/config.ts 中添加组件路由 - 在 docs/components 中添加组件文档
