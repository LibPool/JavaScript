# @interop/data-integrity-core

> 标签: dcc, did, ssi, vc, zcap

## 简介

TypeScript types, definitions, and base classes for the SSI ecosystem - cryptographic keys, DIDs, proofs, Verifiable Credentials, zCaps and related concepts.
