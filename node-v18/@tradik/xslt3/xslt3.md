# @tradik/xslt3

> 标签: json, transform, xml, xpath, xpath3, xslt, xslt2, xslt3

## 简介

XSLT 3.0 and XPath 3.1 in JavaScript: also runs XSLT 2.0 stylesheets and 1.0 ones in backwards-compatible mode, with no runtime dependencies
