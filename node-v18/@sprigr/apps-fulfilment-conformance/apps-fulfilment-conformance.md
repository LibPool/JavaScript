# @sprigr/apps-fulfilment-conformance

> 标签: JavaScript

## 简介

Conformance harness for the fulfilment-hub v1 interfaces: drives every op of fulfilment-hub/order_source and fulfilment-hub/fulfilment_provider against an adapter's handler map and checks the contract.
