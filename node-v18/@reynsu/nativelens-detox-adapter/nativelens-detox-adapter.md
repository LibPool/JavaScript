# @reynsu/nativelens-detox-adapter

> 标签: JavaScript

## 简介

Detox runner adapter for nativelens: drives step:set/step:ack against the harness so end-of-action snapshots arrive tagged with the correct stepId. Emits `frame` events when device.takeScreenshot() returns base64 data.
