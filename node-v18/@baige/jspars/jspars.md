# @baige/jspars

> 标签: JavaScript

## 简介

一个简单的js语法结构解析器,主要用来配合@baige/annotations模块实现注解,可以简单解析语法，函数中的结构不进行解析
 引入解析器后,有两个参数,参数1绝对文件路径,参数2(可选)文件内容
 执行后返回两个参数data是解析内容,info是对data的简单处理,简单提炼出变量,导入,注解三大集合
