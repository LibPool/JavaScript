# @voxelkloud/format-3dtiles

> 标签: 3d-tiles, 3dtiles, cesium, gltf, lidar, pnts, point-cloud, tileset, webgpu

## 简介

The 3D Tiles driver for voxelkloud: tileset.json, external tilesets, implicit tiling, and point cloud content as .pnts or glTF POINTS.
