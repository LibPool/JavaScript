# @voxelkloud/wasm-core

> 标签: frustum, lidar, lod, point-cloud, potree, rust, wasm

## 简介

Rust/wasm kernels for voxelkloud's LOD scheduler: frustum extraction, AABB classification and screen-space-error priority over the wasm linear memory.
