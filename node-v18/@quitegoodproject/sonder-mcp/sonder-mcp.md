> 标签: ai-safety, attention-gatekeeping, claude-mcp, cursor-mcp, egress-firewall, l402, mcp, model-context-protocol, quitegoodproject, sonder-protocol

## 简介

Model Context Protocol (MCP) Server for the Sonder Protocol (RFC-0114). Provides autonomous attention gating, cognitive headroom scoring, and cryptographic egress attestation for Claude Desktop, Cursor, and Windsurf.
