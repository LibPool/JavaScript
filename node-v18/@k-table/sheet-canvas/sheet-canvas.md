# @k-table/sheet-canvas

> 标签: JavaScript

## 简介

kt 表格画布/渲染层：Canvas 2D 绘制、React 编辑器与实例组件、打印/PDF 叠层（依赖 @k-table/sheet-core 引擎，React/echarts 为 external）
