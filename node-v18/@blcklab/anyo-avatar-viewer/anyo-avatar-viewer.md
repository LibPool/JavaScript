# @blcklab/anyo-avatar-viewer

> 标签: 3d, anyo, avatar, glb, gltf, sekai64, vanilla-js, viewer, vrm, vrma, webgl2, webgpu

## 简介

Framework-independent avatar viewer core with VRM/VRMA playback, expressions, look-at, Sekai64 navigation, visual quality, and browser recovery.
