# runeicons-mcp

> 标签: icons, mcp, modelcontextprotocol, rune-icons, runeicons, svg

## 简介

MCP server exposing the RuneIcons library (350+ icons, 900+ variants across 5 styles) and 1,100+ third-party brand logos to AI agents: search icons and brands, resolve metadata, and get ready-to-use SVG source.
