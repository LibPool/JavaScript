# @nodefortress/cip103-snap-adapter

> 标签: canton, canton-network, cip-0103, cip103, dapp, dapp-sdk, metamask, metamask-snap, snap, splice, wallet

## 简介

CIP-0103 MetaMask Snap ProviderAdapter for the Canton Network dApp SDK. Bridges the cc-snap's CIP-0103 methods to @canton-network/dapp-sdk via wallet_invokeSnap.
