# @usepolyglot/core

> 标签: agent, ai, coding-agent, llm, local-llm, mcp, ollama

## 简介

Provider-agnostic engine for Polyglot: tool-call repair, provider adapters, session/audit types. Bundled into @usepolyglot/cli at build time, and published standalone for other first-party services (e.g. the Gateway) to depend on as a normal npm package.
