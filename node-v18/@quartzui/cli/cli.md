# @quartzui/cli

> 标签: JavaScript

## 简介

`quartzUI` is a collection of pre-styled [TailwindCSS](https://tailwindcss.com/) components for form building with [React](https://react.dev/). It is designed to have minimal dependencies, easy to customise, and have first-class Typescript support.
