# @kumochart-sdk/core

> 标签: candlestick, canvas, chart, financial-charts, indicators, kline, sdk, technical-analysis, trading, volume-profile

## 简介

Framework-agnostic, high-performance Canvas trading chart SDK: a small core, and indicators, drawing tools, chart types, alerts, orders, markers, replay, volume profiles and a watermark as modules.
