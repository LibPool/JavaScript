# @jetrabbits/agentic

> 标签: agentic, ai-agents, claude, codex, gemini, mcp, opencode, sdlc

## 简介

Agentic Installer: self-contained CLI that installs AI-agent guidance (rules, skills, workflows, prompts) into any project. This npm package is a thin launcher that downloads the prebuilt Rust binary for your platform from GitHub Releases.
