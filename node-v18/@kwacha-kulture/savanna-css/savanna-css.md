# @kwacha-kulture/savanna-css

> 标签: adinkra, african, css, design-system, framework-agnostic, kente, kwacha, savanna, ui, vanilla-js

## 简介

Savanna — a proudly-African design system as framework-free CSS + vanilla JS + inline-SVG motifs (Adinkra, Kente, Bogolan). Drop into React, Vue, Svelte, Astro, WordPress — or plain HTML.
