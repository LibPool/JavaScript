# @aburi/plugin-registry

> 标签: JavaScript

## 简介

Plugin manifest validator and vocab registry: loads, validates, and tracks every @aburi/* plugin's owned extKind / effect id / framework namespaces, enforcing reservation and conflict rules, plus the shared guards that enforce the language plugin's input
