# @aburi/markdown-projection

> 标签: JavaScript

## 简介

Aburi Markdown projection: deterministic Markdown views (workspace L0, component L1+L2, aburi diff, aburi explain) derived from aburi.ir.v1 / aburi.diff.v1 with confidence badges, dropped fold-outs, symbol-id sanitization, and CI-facing --fail-on formatte
