# @shoplix-ai/cli

> 标签: JavaScript

## 简介

The command line a Shop developer lives in: create a project and a Composed or Code Block, lint it with the api's own rules, push a version with its package, pull one back into JSX, list versions and set one live. The JSX serializer between the body file
