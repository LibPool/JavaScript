# @shoplix-ai/sdui-schema

> 标签: JavaScript

## 简介

Zod source of truth for the Shoplix SDUI contract: documents, Bindings, tokens, block manifest, envelopes and display shapes. Consumers import parse helpers and inferred types; zod stays inside.
