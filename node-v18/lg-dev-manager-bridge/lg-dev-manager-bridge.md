# lg-dev-manager-bridge

> 标签: bridge, developer-mode, homebrew, lg, ssh, tv, webos

## 简介

Bridge for LG Dev Manager: lets the web app (the local page it serves, or lg.scoty.uk) manage LG webOS TVs over SSH, on your computer or a home server
