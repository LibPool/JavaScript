# @baton-tools/harness

> 标签: agentic, autonomous-development, claude-code, harness, holdout, openspec, spec-driven

## 简介

Spec-driven autonomous-development harness with frozen holdout contracts, tier-aware adversarial review, and an OpenSpec workflow. Project-agnostic core; per-repo config.
