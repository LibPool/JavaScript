# @tiertwo/sdk

> 标签: authentication, eddsa, jwks, jwt, mcp, proof-of-personhood, tiertwo, verified-human

## 简介

One-call merchant SDK to verify Tier Two verified-human signup tokens — offline EdDSA/JWKS verification, fail-closed, with a jti replay-dedupe helper.
