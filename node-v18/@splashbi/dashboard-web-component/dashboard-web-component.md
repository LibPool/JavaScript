# @splashbi/dashboard-web-component

> 标签: ag-grid, custom-element, dashboard, fusioncharts, gridstack, splashbi, web-component

## 简介

<sbi-dashboard-layout> - a framework-agnostic web component that renders a SplashBI dashboard (GridStack layout, FusionCharts, AG Grid) in any HTML page.
