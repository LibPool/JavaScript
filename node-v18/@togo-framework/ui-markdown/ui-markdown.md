# @togo-framework/ui-markdown

> 标签: JavaScript

## 简介

togo UI kit — markdown renderer (GFM, syntax highlighting, mermaid-ready) + editor. Depends on @togo-framework/ui-core and @togo-framework/ui-data-table.
