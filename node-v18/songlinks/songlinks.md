# songlinks

> 标签: api, credits, ipi, iswc, metadata, music, publishing, sdk, songlinks, songwriter

## 简介

Official TypeScript/JavaScript SDK for the Songlinks API: look up a songwriter by name and get the people behind every registration.

- 源码仓库：git+https://github.com/Alexkane/songlinks-js.git
- npm 页面：https://www.npmjs.com/package/songlinks
