# @lingc-sun/mcp-abap-adt

> 标签: abap, abap-adt-api, adt, mcp, model-context-protocol, sap

## 简介

MCP server wrapping abap-adt-api for full ABAP ADT development workflows (object CRUD, transports, locking, syntax check, activation, DDIC) against SAP systems
