# greedykrab-cli

> 标签: JavaScript

## 简介

Connect Greedy Krab's labelled ad line to Claude Code. A standalone terminal for members in Korea, Japan and the US earns rewards at a much lower rate after new connection consent and server approval; without a valid device login no terminal ad is shown.
