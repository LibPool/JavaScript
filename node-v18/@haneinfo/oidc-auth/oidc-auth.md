# @haneinfo/oidc-auth

> 标签: JavaScript

## 简介

OIDC interactive authentication for Haneinfo apps: JWKS/RS256 verification, (issuer, subject) identity mapping, JIT provisioning and inbound delegated (RFC 8693) trust profiles.
