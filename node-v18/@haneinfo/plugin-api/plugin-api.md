# @haneinfo/plugin-api

> 标签: JavaScript

## 简介

Haneinfo plugin contract: manifest v1 types and JSON Schema, stable capability tokens, definePlugin(), lifecycle/diagnostic contracts, manifest loader and dependency resolver.
