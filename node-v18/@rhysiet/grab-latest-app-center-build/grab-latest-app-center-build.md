# @rhysiet/grab-latest-app-center-build

> 标签: JavaScript

## 简介

This script is to run before tests to get the latest app builds from Microsoft App Center so you are running your tests against the very latest app build.  ## Install Install all packages with npm install.   Setup a .env file with your app center API key
