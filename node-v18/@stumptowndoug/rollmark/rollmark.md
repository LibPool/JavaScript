# @stumptowndoug/rollmark

> 标签: ai, charts, d3, llm, markdown, markdown-it, reports, svg, visualization

## 简介

Markdown-based document format and renderer for AI-generated reports with charts: a tiny LLM-friendly chart DSL, strict validation, and an opinionated SVG renderer.
