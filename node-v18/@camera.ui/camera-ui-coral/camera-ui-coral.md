# @camera.ui/camera-ui-coral

> 标签: camera-ui-plugin, coral, detection, edgetpu, object, tflite, tpu

## 简介

Coral Edge TPU (TFLite) detection backend for camera.ui. Runs object detection on a Coral Edge TPU with CPU fallback.
