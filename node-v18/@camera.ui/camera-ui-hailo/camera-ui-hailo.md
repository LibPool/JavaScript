# @camera.ui/camera-ui-hailo

> 标签: camera-ui-plugin, detection, edge-ai, hailo, hailo8, hailort, object

## 简介

Hailo Edge AI (HailoRT) detection backend for camera.ui. Runs object detection on a Hailo-8 / Hailo-8L accelerator.
