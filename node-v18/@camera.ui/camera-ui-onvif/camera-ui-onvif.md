# @camera.ui/camera-ui-onvif

> 标签: camera-ui-plugin, discovery, motion, onvif, ptz

## 简介

ONVIF integration for camera.ui. Provides camera discovery, PTZ control, and motion, object, audio and face events via ONVIF.
