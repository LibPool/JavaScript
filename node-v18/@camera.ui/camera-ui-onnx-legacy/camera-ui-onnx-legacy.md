# @camera.ui/camera-ui-onnx-legacy

> 标签: alpr, camera-ui-plugin, clip, clip-detection, cuda, detection, face, face-detection, legacy, license-plate, lpd, object, ocr, onnx

## 简介

ONNX Runtime detection backend for camera.ui with the older CUDA 12 runtime. For NVIDIA GPUs before GTX 1650 (Maxwell, Pascal, Volta) and for systems that stay on CUDA 12. Use the regular ONNX plugin on newer hardware.
