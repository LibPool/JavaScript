> 标签: binlog, cdc, change-data-capture, data-pipeline, database, event-sourcing, logical-replication, mssql, mysql, postgres, postgresql, real-time, replication, sql-server, streaming, wal

## 简介

Powerful Change Data Capture (CDC) for Node.js — supports MySQL (binlog replication), PostgreSQL (logical replication), and MSSQL (SQL Server CDC) in real-time.
