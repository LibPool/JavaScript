# @adsq/jsnq

> 标签: copy-on-write, immutable, jsnq, json, move, nested, pipeline, query, update, where

## 简介

Framework-agnostic JSON pipeline engine: where/update/move/copy/insert/delete over nested JSON trees, with copy-on-write fast paths. Zero runtime dependencies.
