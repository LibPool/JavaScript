# @cortadel/openclaw

> 标签: agents, ai, cortadel, knowledge-graph, llm, memory, openclaw, openclaw-plugin

## 简介

Cortadel memory plugin for OpenClaw — self-hosted long-term temporal graph memory as an OpenClaw memory corpus, agent tools, and automatic recall/capture hooks.
