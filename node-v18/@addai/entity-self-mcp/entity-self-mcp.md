# @addai/entity-self-mcp

> 标签: addai, entity-studio, mcp, self-edit

## 简介

MCP server that lets a +Ai entity read and update its own config, avatar and live status/progress (with a built-in Living Presence directive), manage its skills and schedules, propose learnings to the entity it is an instance of.
