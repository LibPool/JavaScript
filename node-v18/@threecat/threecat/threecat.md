# @threecat/threecat

> 标签: components, vue

## 简介

- npm run bootstrap    - 安装依赖 - make new (组件英文名字) (组件中文名字)   - 会执行build/bin下面的new.js，进行新组件的创建。     - 这里说明一下new.js中的逻辑       - 1. 在/packages目录下新建组件目录,并完成目录结构的构建，写入模板中配置好的组件基础代码       - 2. 创建语言的组件文档,/examples/docs/{lang}/t-dict-select.md       - 3. 创
