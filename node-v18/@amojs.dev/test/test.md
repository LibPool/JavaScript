# @amojs.dev/test

> 标签: amojs, fine-grained, happy-dom, signals, testing, vitest

## 简介

AmoJS test helpers — render, cleanup, flush, tick for component tests under vitest with a DOM environment. Zero dependencies; never loads the template parser.
