# @lijinhao315/dsh-question-index

> 标签: chat-history, deepseek, dsh, dsh-plugin, harness, question-index, ui

## 简介

Question index for DeepSeek Harness Web UI: an ordered, collapsible list of your asked questions floating on the right side of the conversation; click one to jump the session to that point. Auto-indexes the full history of every session on open and persis
