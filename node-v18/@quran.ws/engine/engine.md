# @quran.ws/engine

> 标签: arabic, canvas, mushaf, quran, qvp, rendering, wasm

## 简介

Rendering engine for interactive muṣḥaf pages: layout, hit-testing, styling and search over the QVP page format, as wasm with a Canvas2D wrapper.
