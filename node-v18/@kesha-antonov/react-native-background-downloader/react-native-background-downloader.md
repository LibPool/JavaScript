# @kesha-antonov/react-native-background-downloader

> 标签: android, background, background-download, background-upload, download, downloader, downloadmanager, expo, expo-plugin, file-download, file-transfer, file-upload, foreground-service, ios, large-files, new-architecture, nsurlsession, offline, offline-first, pause-resume, progress, react-native, resumable, resumable-download, turbomodule, typescript, upload, uploader, urlsession

## 简介

Background file downloads and uploads for React Native and Expo. Large files keep transferring on iOS and Android while your app is in the background or terminated. Pause/resume, progress events, TurboModules, TypeScript.
