# usageledger

> 标签: bigquery, claude-code, cli, codex, duckdb, sqlite, tokens, usage

## 简介

UsageLedger reads local Claude Code and Codex session logs, stores no paths, and writes token data to SQLite, DuckDB or BigQuery.
