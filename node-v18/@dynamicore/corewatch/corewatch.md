# @dynamicore/corewatch

> 标签: breadcrumbs, crash-reporting, error-boundary, error-monitoring, error-tracking, expo, logging, observability, react, react-native, redux, sentry-alternative

## 简介

Lightweight, Sentry-style error monitoring SDK for React, React Native (Expo) and the browser: errors, breadcrumbs, PII scrubbing and pluggable transports.
