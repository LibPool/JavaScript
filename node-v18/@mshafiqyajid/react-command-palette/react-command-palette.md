# @mshafiqyajid/react-command-palette

> 标签: command-palette, headless, hook, react, typescript

## 简介

Command palette (⌘K) hook and styled component for React. Fuzzy match, sections, recent items, keyboard nav. Zero dependencies, fully typed.
