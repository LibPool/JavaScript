# @ebowwa/sandbox

> 标签: isolated-execution, javascript, jupyter, multi-language, notebook, polyglot, python, repl, rust, sandbox, typescript, wasm

## 简介

Composable sandbox primitives for multi-language code execution - Jupyter/REPL style with Python+Rust+JS+TS+WASM support
