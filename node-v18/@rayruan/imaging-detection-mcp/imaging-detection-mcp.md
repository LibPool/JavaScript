# @rayruan/imaging-detection-mcp

> 标签: dicom, ich, mcp, medical-imaging, model-context-protocol, rib-fracture, stdio

## 简介

影像检测 MCP server：支持 stdio 和 Streamable HTTP，根据影像检测类型与 DICOM 7z URL 调用 AI Task API，返回诊断报告与 viewer url。
