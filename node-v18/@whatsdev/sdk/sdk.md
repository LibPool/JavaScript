# @whatsdev/sdk

> 标签: api-client, messaging, sdk, typescript, webhooks, whatsapp, whatsdev

## 简介

Official Node.js client for the WhatsDev WhatsApp API: sessions, messaging, contacts, bulk sends, templates and signed webhooks
