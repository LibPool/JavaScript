# @better-iam/client

> 标签: abac, access-control, authentication, authorization, browser, client, fetch, iam, multi-tenant, rbac, sdk, typescript

## 简介

Typed, browser-safe client for the Better IAM HTTP API, inferred from your server instance, with a session store and passkey helpers.
