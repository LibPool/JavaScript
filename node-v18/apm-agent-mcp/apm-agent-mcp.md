# apm-agent-mcp

> 标签: JavaScript

## 简介

把宿主机变成 Agent 工作区沙箱：文件读写、搜索与命令执行，经 MCP Streamable HTTP / stdio 暴露。

## 官网

- npm 页面：https://www.npmjs.com/package/apm-agent-mcp

## 历史版本号

- 0.0.1

- npm registry：https://registry.npmjs.org/apm-agent-mcp
- Node 要求：>=20.0.0
