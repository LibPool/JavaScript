# @structured-world/structured-email-address-ts

> 标签: email, email-address, normalization, psl, rfc-5321, rfc-5322, validation

## 简介

RFC 5321/5322/6531 email address parser, validator and normalizer in native TypeScript: subaddress extraction, provider-aware normalization, Public Suffix List validation, anti-homoglyph skeletons. Same results as the Rust crate.
