# @snap-x/mcp

> 标签: app-store-screenshots, branded-graphics, linkedin-banner, mcp, mcp-server, og-image, play-store, snap-x, youtube-thumbnail

## 简介

MCP server for snap-x: lets any agent (Claude Desktop, Cursor, Windsurf, …) render, check and preview platform-ready branded graphics, with built-in platform formats, safe-zone guides and a design guide.
