# @unleashwp/ai-forge

> 标签: JavaScript

## 简介

UnleashWP AI Forge — a hub for WordPress release tooling. Runs a browser UI, a zero-dependency CLI, and an MCP server (`uwp mcp`) so Claude Code and Codex can query its tools and skills live.
