# @sumomok/dsh-quote-message

> 标签: cordis-plugin, deepseek-harness, dsh, dsh-plugin

## 简介

Quote earlier content of the current session into the composer: select any passage in the chat and a native reference chip carries the text into the prompt, rendered back as a quote card above your message
