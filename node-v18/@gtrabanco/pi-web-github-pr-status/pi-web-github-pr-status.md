# @gtrabanco/pi-web-github-pr-status

> 标签: ci, github, merge, pi, pi-coding-agent, pi-web, pi-web-plugin, plugin, pr, pull-request

## 简介

PI WEB plugin that surfaces GitHub pull request status (PR number, link, CI ball, worktree state) and one-click guarded merge/close without leaving the workspace.
