# @sommelierx/mcp-server

> 标签: ai, claude, cursor, dining, food, food-pairing, llm, mcp, model-context-protocol, pairing, recipe, sommelier, tool, windsurf, wine, wine-pairing

## 简介

Wine pairing intelligence for AI assistants. Ask any MCP-compatible client (Claude, Cursor, Windsurf) for wine recommendations and get scored matches from a sommelier-grade algorithm. Authenticates with an API key; a free tier works without one.
