# @240xu/dsh-tech-lead

> 标签: cordis, deepseek-harness, dsh, governance, plugin, tech-lead

## 简介

Tech-lead lifecycle plugin for DeepSeek Harness: 21 read-only tools (classify/state/plan/evidence/gates/release/install audits, context/evidence/progress analysis, mutation preview). No writes, no subprocesses, no network.
